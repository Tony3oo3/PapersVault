## Problem

Existing open-vocabulary HOI detection methods suffer from two key limitations: (1) relying solely on last-layer CLIP visual features discards the local details (e.g., arm and face postures) captured by intermediate layers, degrading fine-grained interaction recognition; and (2) text classifiers built from category names or LLM-generated label descriptions fail to distinguish semantically similar interaction classes due to CLIP's class biases and the generic nature of single-label descriptions.
![Teaser figure](../imgs/CVPR20250039/cropped_page0_idx2.webp)

## Input / Output

The method takes a single RGB image as input and produces human-object bounding box pairs along with their interaction category labels, operating entirely without a pretrained object detector. The visual backbone is CLIP ViT-B/16 with 12 learnable visual prompt tokens per layer, while the text side uses 8 prefix tokens and 4 conjunctive tokens to adaptively encode interaction phrases. At inference, the final detection score is the product of the interaction classification score and the bounding box confidence raised to a power γ > 1 to suppress overconfident object predictions.

## Method

SGC-Net introduces two modules. The Granularity Sensing Alignment (GSA) module partitions CLIP's 12-layer ViT encoder into blocks (e.g., {6-8}, {9-11}, {12}), fuses features within each block using trainable distance-aware Gaussian weights that emphasize nearby layers, then aggregates across blocks while treating the last layer as a separate high-weight block to preserve pre-trained vision-language alignment; visual prompt tuning injects learnable tokens into each frozen layer to enable gradient-based alignment of intermediate features with text embeddings. The Hierarchical Group Comparison (HGC) module recursively constructs a class hierarchy by clustering LLM-generated descriptions with K-means, then for each group either directly queries GPT-3.5 for comparative descriptions (small groups) or first summarizes the group before querying (large groups); at inference, an iterative evaluator filters unreliable low-level descriptions by requiring monotonically increasing similarity scores, and the final classification score is a weighted average of the initial description score and the running average of accepted hierarchical scores.

## Results

On HICO-DET, SGC-Net achieves 23.27 mAP (Unseen), 28.34 mAP (Seen), and 27.22 mAP (Full), outperforming the closest detector-free baseline CMD-SE by 6.57% on Unseen. On the more challenging SWIG-HOI dataset (400 actions × 1,000 objects), SGC-Net reaches 23.67 mAP (Non-rare), 16.55 mAP (Rare), 12.46 mAP (Unseen), and 17.20 mAP (Full), surpassing the best method with a pretrained detector (HOICLIP) by 4.59% on Full mAP. The method is notable for requiring no pretrained object detector while matching or exceeding detector-based approaches.

## Baselines & Comparisons

SGC-Net outperforms all nine baselines on both datasets. Against the closest detector-free competitor CMD-SE [22], SGC-Net gains 6.57 mAP on Unseen and 4.87 mAP on Full for HICO-DET, and 1.91 mAP on Unseen and 1.94 mAP on Full for SWIG-HOI. On HICO-DET, SGC-Net (27.22 Full mAP) also surpasses detector-based methods including HOICLIP [40] (32.26 Full), GEN-VLKT [29] (30.56 Full), OpenCat [57] (31.38 Full), and SCL [15] (28.08 Full), though the paper notes this comparison is not entirely fair due to COCO pretraining overlap. On SWIG-HOI, SGC-Net leads CMD-SE [22] by 1.94 mAP (Full) and THID [48] by 3.94 mAP (Full), while also exceeding MP-HOI [52] (12.61 Full) and GEN-VLKT [29] (10.87 Full) which rely on pretrained detectors. The largest margins are over CHOID [46] (+10.56 Full mAP) and QPIC [43] (+6.08 Full mAP), reflecting the difficulty of scaling to SWIG-HOI's 1,000-object vocabulary without detection pretraining.

## Relation to Prior Work

This paper extends the detector-free OV-HOI detection framework established by CMD-SE [22], which removed reliance on pretrained object detectors by extracting HOI features directly from CLIP's image encoder. It departs from prior CLIP-based OV-HOI methods (GEN-VLKT, HOICLIP, CMD-SE) in two key ways: (1) instead of using only last-layer visual features, it aggregates multi-granularity features from intermediate transformer layers via a distance-aware Gaussian weighting scheme with block partitioning; and (2) instead of using LLM-generated descriptions from labels alone (as in Menon & Vondrick [38] or CMD-SE), it recursively groups and compares semantically similar classes through LLMs to produce discriminative hierarchical descriptions. The visual prompt tuning strategy connects to the broader line of CLIP adaptation work (ZEGCLIP, Cascade-CLIP) for preserving pre-trained alignment while enabling fine-tuning of intermediate layers.

## Why It Matters / Open Questions

The detector-free design is practically important for scaling OV-HOI to large vocabularies (SWIG-HOI's 1,000 object categories), where pretrained detectors struggle to generalize. The GSA module's block-partitioned Gaussian weighting offers a reusable technique for integrating multi-scale transformer features without disrupting pre-trained vision-language alignment, potentially applicable beyond HOI detection. However, the method's reliance on GPT-3.5 for iterative description generation introduces non-trivial computational overhead and potential quality variance, and the hierarchical comparison's effectiveness may degrade with very large class sets. Open questions include whether the hierarchical grouping strategy generalizes to other open-vocabulary tasks (e.g., open-vocabulary segmentation) and whether the LLM comparison step can be replaced by learned embeddings to reduce inference-time dependency on external LLMs.

## Problem

Zero-shot object customization from a single reference image remains unsolved for general objects: existing methods are either object-specific (requiring per-object fine-tuning) or object-agnostic but confined to narrow domains like faces or clothing. A fundamental blocker is the absence of a large-scale, multi-category dataset with consistent identity pairs spanning diverse object types, which this paper addresses alongside a general-purpose customization framework.
![Teaser figure](../imgs/CVPR20250510/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference image (masked with a segmentation mask isolating the target object) and a free-form text prompt as input, and produces a generated image that preserves the object's identity while altering non-ID attributes (pose, background, motion) per the prompt. The backbone is SD1.5 trained with multi-scale resolution handling (average training resolution ~1039×950), and inference uses 50 denoising steps with classifier-free guidance scale 7. The segmentation mask is applied via element-wise multiplication before feature extraction, so only the object region contributes ID information.

## Method

CustAny combines three modules: (1) a general ID extractor that fuses DINOv2 (rich structural detail) and MAE (color sensitivity) features from the masked reference image via a two-layer MLP, producing class tokens and patch tokens; (2) a dual-level ID injection strategy where global class tokens are merged with the class-word embedding in the text condition (preserving text editability) and local patch tokens are injected through additional cross-attention layers in each UNet upblock (preserving fine-grained detail); (3) an ID-aware decoupling module that, during training, routes non-ID information (motion, orientation) into a CLIP-based masked image feature via a trainable feature mask, while a contrastive loss enforces orthogonality between this masked feature and the fused class token, ensuring the model separates identity from scene context. The entire framework is trained end-to-end on the newly constructed MC-IDC dataset (315K reference-target pairs across 10K categories) with a combined denoising + contrastive objective.

## Results

On general object customization, CustAny achieves FID 47.09, CLIP-i 82.16, DINO-i 65.13, and DiverSim-i 74.38, substantially outperforming IP-Adapter (FID 70.32, DINO-i 44.94). In human customization, CustAny reaches FaceSim 78.54 and DINO-i 57.44, surpassing PhotoMaker (FaceSim 64.10) and InstantID (FaceSim 63.26). For virtual try-on, CustAny attains FID 50.65 and DINO-i 66.24, far exceeding MagicClothing (FID 126.09, DINO-i 29.10) and IP-Adapter (FID 104.47).

## Baselines & Comparisons

CustAny decisively outperforms IP-Adapter across all three domains on FID, CLIP-i, and DINO-i, with the largest gap in general objects (DINO-i 65.13 vs. 44.94) and virtual try-on (FID 50.65 vs. 104.47). Against the human-customization specialists PhotoMaker and InstantID, CustAny achieves a 14-point FaceSim advantage (78.54 vs. 64.10/63.26) and a 10–16-point DINO-i lead, though it trails both on CLIP-t prompt fidelity (30.88 vs. 32.13/32.89). In virtual try-on, CustAny dominates MagicClothing on every metric (FID 50.65 vs. 126.09; DINO-i 66.24 vs. 29.10) and edges out IP-Adapter on FID and DINO-i while matching it on DiverSim-i (71.27 vs. 71.28). The only metric where CustAny does not lead is CLIP-t in the virtual try-on domain (22.42 vs. IP-Adapter's 25.03), suggesting a slight trade-off between garment-detail fidelity and prompt adherence in that specific setting.

## Relation to Prior Work

CustAny extends the zero-shot object customization paradigm established by domain-specific methods (PhotoMaker for faces, InstantID for identity, MagicClothing for garments) to a general, category-agnostic setting. It departs from prior work in two key ways: (1) it replaces the single-model ID extraction (typically CLIP) with a complementary DINOv2+MAE combination to capture both fine-grained detail and color, and (2) it introduces an ID-aware decoupling training objective to separate identity from non-ID attributes like pose and orientation. The framework is built on the standard SD1.5 latent diffusion backbone and the cross-attention injection pattern popularized by IP-Adapter, but augments it with a dual-level (global class-token + local patch-token) injection strategy and a new large-scale training dataset (MC-IDC) that prior domain-specific methods lacked.

## Why It Matters / Open Questions

The MC-IDC dataset (315K samples, 10K+ categories) is the first large-scale resource for general-purpose zero-shot object customization, filling a gap that has kept prior methods confined to narrow domains. The finding that a single general framework can match or exceed specialized methods (e.g., beating InstantID on FaceSim and MagicClothing on FID in try-on) suggests that domain-specific fine-tuning may be less necessary than previously assumed. Open questions include whether the approach scales to 3D objects or video, how it handles highly occluded or multi-object references, and whether the modest ablation gains from the decoupling module (≈0.3 FID) justify its added training complexity at scale.

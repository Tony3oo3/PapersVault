## Problem

Existing in-context learning (ICL) frameworks for 3D point cloud processing, such as PIC, rely on task-agnostic Farthest Point Sampling (FPS) that cannot adapt to the distinct sampling preferences of different tasks (e.g., reconstruction vs. denoising) or to prompt-specific variability within a single task. This creates inter-task sensitivity, where a fixed sampling strategy performs inconsistently across tasks, and intra-task sensitivity, where different prompts for the same task yield divergent results. No prior work has introduced context-adaptive sampling at both the point and prompt levels within a point cloud ICL framework.

## Input / Output

The method takes a query 'input' point cloud X_q and a prompt pair (X_p, Y_p) of input-target point clouds, each with S points in 3D. The prompt encodes one of four tasks (reconstruction, denoising, registration, part segmentation) at one of five difficulty levels. The model outputs the predicted 'target' point cloud Y_q for the query via masked point modeling, and additionally produces per-prompt sampling scores used to select the optimal prompt from K candidates at inference time. Point clouds are converted into N point patches via KNN around sampled central points before being encoded as tokens for the transformer-based ICL backbone.

## Method

MICAS introduces two complementary adaptive sampling modules. First, task-adaptive point sampling uses a PointNet classification branch as a task encoder to extract task features F_task from the prompt, and a PointNet segmentation branch to extract per-point features; these are concatenated, projected through a fully connected layer to yield sampling weights, and then relaxed via Gumbel-softmax to produce differentiable, task-conditioned central point selection that replaces FPS. Second, query-specific prompt sampling trains a scoring network on pseudo labels derived from the ICL model's actual performance (CD or mIOU, max-min normalized across tasks), optimized with a list-wise ranking loss so that at inference the highest-scoring prompt among K candidates is selected for each query. The two modules are trained in a step-wise fashion—first the point sampling module with Chamfer Distance loss, then the prompt sampling module with the point sampling parameters frozen—to avoid entanglement and simplify convergence.

## Results

On the ShapeNet In-Context Dataset, MICAS (with PIC-Sep backbone) achieves the best overall performance: 4.3 CD on reconstruction, 5.1 CD on denoising, 3.7 CD on registration, and 86.8 mIOU on part segmentation. With the PIC-Cat backbone, MICAS reaches 87.9 mIOU on part segmentation (vs. 79.0 for PIC-Cat alone, a +8.9 gain) and 9.8 CD on registration (vs. 14.1, a +4.3 gain). MICAS outperforms all multi-task models (Point-MAE, I2P-MAE, ReCon) across every task and difficulty level, and surpasses the strongest task-specific model (ACT) on registration (3.7 vs. 5.9 CD) and part segmentation (86.8 vs. 81.2 mIOU).

## Baselines & Comparisons

Against the closest ICL baselines, MICAS (PIC-Sep) dominates PIC-Sep on all four tasks: reconstruction 4.3 vs. 4.7 CD, denoising 5.1 vs. 7.6 CD, registration 3.7 vs. 10.3 CD, and part segmentation 86.8 vs. 75.0 mIOU. MICAS (PIC-Cat) improves over PIC-Cat by 0.7 CD on denoising, 4.3 CD on registration, and 8.9 mIOU on part segmentation, though it trails PIC-Cat by 0.4 CD on reconstruction. Against the strongest task-specific model ACT, MICAS (PIC-Sep) wins on registration (3.7 vs. 5.9 CD) and part segmentation (86.8 vs. 81.2 mIOU) but loses on reconstruction (4.3 vs. 2.5) and denoising (5.1 vs. 2.3), reflecting the inherent trade-off of a single multi-task model. All multi-task baselines (Point-MAE, I2P-MAE, ReCon) are substantially outperformed by MICAS on every task, with the largest gaps in registration (3.7 vs. 14.5–31.5 CD) and part segmentation (86.8 vs. 5.4–22.6 mIOU). MICAS also surpasses the newer PIC-S variants (PIC-S-Cat, PIC-S-Sep) across all metrics, confirming that adaptive sampling at both point and prompt levels provides consistent gains over prior ICL approaches.

## Relation to Prior Work

This paper builds directly on PIC (Fang et al., NeurIPS 2024), which established in-context learning for 3D point clouds via masked point modeling with Farthest Point Sampling (FPS) for patch construction. MICAS departs from PIC by replacing its task-agnostic FPS with two adaptive mechanisms: a Gumbel-softmax-based task-adaptive point sampler (drawing on differentiable sampling from SkeletonNet and PAT) and a query-specific prompt sampler (inspired by list-wise ranking in UDR for NLP demonstration retrieval). The work also connects to the broader learnable point cloud sampling literature (SampleNet, IndexSample, LTA-PCS), but uniquely positions sampling as a context-adaptive component within an ICL pipeline rather than a standalone task-specific module.

## Why It Matters / Open Questions

MICAS identifies and addresses a previously underexplored bottleneck in point cloud ICL: the mismatch between fixed sampling strategies and task-specific or prompt-specific needs. The finding that a simple, widely-used method like FPS systematically degrades performance in denoising (by selecting noisy outliers) and that prompt choice within a single task causes significant variance is practically useful for anyone building ICL pipelines for 3D data. However, the evaluation is confined to the ShapeNet In-Context benchmark with four tasks and a single ICL backbone (PIC), leaving open whether the adaptive sampling gains transfer to other architectures, larger-scale real-world point clouds, or tasks beyond the four tested. The threefold inference-time increase from prompt sampling also raises questions about deployment in latency-sensitive settings.

## Problem

Diffusion-driven TTA methods project target data into the synthetic domain of an unconditional diffusion model rather than the true source domain, creating a source-synthetic domain misalignment that degrades source model performance by up to 21.8% despite the synthetic images appearing visually indistinguishable from source images. This misalignment has been overlooked because prior work assumed the diffusion-recovered data approximates the source domain.
![Teaser figure](../imgs/CVPR20250068/cropped_page0_idx1.webp)

## Input / Output

The framework consumes a pretrained source model, a conditional diffusion model (e.g., DiT), and an unconditional diffusion model (e.g., ADM), all pretrained on source data. At test time, each target image is adapted via the unconditional diffusion model with structural guidance (DDA-style), and the final prediction ensembles softmax outputs from both the original source model on the raw target image and the fine-tuned synthetic-domain model on the adapted image. The method outputs class labels for classification, pixel-level masks for segmentation, or multiple-choice answers for MLLM-based VQA.

## Method

SDA introduces a source-to-synthetic model adaptation phase between pretraining and test-time inference, using a Mix of Diffusion (MoD) technique to generate training data for fine-tuning. MoD first uses a conditional diffusion model to synthesize a labeled dataset (50K images by default) from class labels, then applies the same unconditional diffusion model used for target data adaptation to add noise (to timestep t*) and denoise each sample, bridging the domain gap between conditional and unconditional synthetic domains. The source model is then fine-tuned on this aligned synthetic dataset, transforming the cross-domain TTA problem into an in-domain prediction task where both model and data reside in the same synthetic domain. Even a single image per class (1K total) yields significant gains over DDA, indicating the model primarily learns to adapt to the synthetic domain's implicit features rather than class-specific knowledge.

## Results

On ImageNet-C (severity 5), SDA achieves average accuracy of 32.5% (ResNet-50), 42.5% (Swin-T), 47.0% (ConvNeXt-T), 47.4% (Swin-B), and 51.9% (ConvNeXt-B), consistently outperforming the strongest baseline DDA by 2.5–2.9%. On ImageNet-W, SDA gains 1.4–2.3% over DDA. On the smaller CIFAR-10-C benchmark, SDA achieves 72.4% average accuracy, a 7.1% improvement over DDA (65.3%). For semantic segmentation on PASCAL VOC-C, SDA reaches 39.8% mIOU (+1.2% over DDA), and for MLLM-based classification with LLaVA on ImageNet-C, SDA achieves 93.6% accuracy (+2.4% over DDA).

## Baselines & Comparisons

SDA consistently outperforms DDA (the primary diffusion-driven baseline) across all evaluated benchmarks: +2.5–2.9% on ImageNet-C, +1.4–2.3% on ImageNet-W, +7.1% on CIFAR-10-C, +1.2% mIOU on PASCAL VOC-C, +2.4% with LLaVA, and +2.3% on the UniTTA data-stream sensitivity benchmark. Against GDA (the recent SOTA diffusion-driven method), SDA achieves +2.2% with ConvNeXt-T on ImageNet-C, though GDA is not available for larger models. SDA substantially outperforms DiffPure (designed for adversarial purification) by 10–20+ points across all models, confirming that structural guidance and domain alignment are both necessary. Compared to the model-adaptation method MEMO, SDA wins on 4 out of 5 ImageNet-C model configurations (e.g., 51.9% vs. 45.8% for ConvNeXt-B). On the UniTTA benchmark, SDA (31.6%) surpasses all 13 traditional TTA methods tested (ranging from 4.2% for TENT to 24.9% for UniTTA itself), demonstrating that diffusion-driven data adaptation is inherently more robust to imbalanced data streams than weight-update-based approaches.

## Relation to Prior Work

This paper builds directly on diffusion-driven TTA methods, particularly DDA [17], which uses an unconditional diffusion model to project corrupted target data back toward the source domain via forward-noising and structure-guided reverse denoising. The key departure is the identification of a previously overlooked issue: the projected data actually lands in the synthetic domain of the diffusion model rather than the true source domain, creating a source-synthetic misalignment that degrades performance. SDA introduces a new TTA paradigm that simultaneously adapts the source model to this synthetic domain (via a Mix of Diffusion technique combining conditional and unconditional diffusion) while also adapting target data to the same domain, converting a cross-domain problem into an in-domain one.

## Why It Matters / Open Questions

The paper reveals that the core assumption in diffusion-driven TTA—that diffusion models faithfully reconstruct source-domain data—is empirically false, with up to 21.8% accuracy degradation on ImageNet despite visually indistinguishable outputs. This reframes how practitioners should think about diffusion-based adaptation: the synthetic domain is a distinct entity that must be explicitly accounted for. Open questions include whether the approach generalizes to more extreme or multi-modal domain shifts, whether the one-time synthetic data generation cost (50K images) is prohibitive in resource-constrained settings, and whether the alignment benefit persists as diffusion models improve in fidelity. The framework's generality (applicable to classifiers, segmenters, and MLLMs) suggests it could become a standard add-on to diffusion-driven TTA pipelines.

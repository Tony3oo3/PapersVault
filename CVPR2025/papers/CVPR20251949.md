## Problem

Collaborative autonomous driving (CAV) requires simultaneous multi-agent sensor data from the same scene, making large-scale dataset collection prohibitively expensive and limited to a few agents. Existing simulated datasets lack real-world diversity, while real CAV datasets (e.g., V2V4Real, DAIR-V2X) contain only two agents. The paper asks whether realistic point clouds from arbitrary reference viewpoints can be generated from a single ego-car's LiDAR data, effectively converting any single-agent dataset into a collaborative one.

## Input / Output

The method takes a voxelized ego-car LiDAR point cloud (512×512×20 binary occupancy over ±51.2 m in x/y and 4 m in z) and a binary BEV object-location map (512×512×1) as conditions. The ego point cloud is rigidly translated and rotated to center on the reference agent's position before encoding. The output is a reference-viewpoint LiDAR point cloud in the same voxelized format, decoded from a 64×64×8 VQ-VAE latent via a 200-step DDIM schedule followed by Gumbel-Softmax thresholding to recover occupied voxel centers. Semantic labels can be manually edited (e.g., adding occluded objects) before generation to enrich the reference view.

## Method

TYP uses a two-stage conditioned latent diffusion model with a VQ-VAE (Focal Loss for sparse occupancy) encoding both point clouds and object maps into 64×64 feature maps. Stage 1 trains P(x|y) on real single-agent data using only bounding-box conditioning to learn diverse, realistic scene generation. Stage 2 freezes the U-Net and adds a lightweight T2I-Adapter-style control module that injects the ego point cloud's VQ-VAE features additively into four multi-scale encoder layers, grounding generation on the ego perspective to ensure semantic and layout consistency. A GAN-style domain adaptation step (hinge-loss discriminator) aligns the source (simulated CAV, e.g., OPV2V) encoder/decoder features with the frozen target (real, e.g., Waymo) codebook, reducing the sim-to-real gap before Stage 2. A final enhancement stage fine-tunes the control module jointly on target-domain data with dummy ego (empty point cloud) and self-training pseudo-labels sampled at random reference locations, enabling generation quality in the target domain without any real reference-agent point clouds.

## Results

On OPV2V (simulated), TYP-generated reference point clouds achieve AP@0.5 of 0.46 (Early Fusion), 0.50 (Late Fusion), 0.72 (AttFuse), and 0.65 (V2X-ViT), closely matching oracle ground-truth values of 0.49, 0.55, 0.77, and 0.71 respectively. On the real-world V2V4Real dataset (where no V2V4Real data is used for generation training), TYP achieves 0.53, 0.63, 0.56, and 0.48 vs. oracle 0.60, 0.67, 0.61, and 0.61. Pre-training on the generated ColWaymo dataset (36K collaborative samples from 17.4K Waymo single-agent samples) yields substantial gains over training from scratch (e.g., 0.65 vs. 0.60 all-AP for Early Fusion at 32-scene fine-tuning) and consistently outperforms pre-training on simulated OPV2V.

## Baselines & Comparisons

The paper compares TYP-generated reference point clouds against ground-truth (oracle) references across four cooperative perception fusion methods: Early Fusion (Cooper [4]), Late Fusion and AttFuse (OPV2V [51]), and V2X-ViT [50]. TYP consistently achieves within 3–6 AP points of oracle across all methods and distance ranges on both OPV2V and V2V4Real, with the largest gap appearing in the long-range (50–100m) category (e.g., 0.40 vs. 0.50 for V2X-ViT on OPV2V). On the real-world V2V4Real dataset—where no V2V4Real data is used to train the generator—TYP still matches oracle within 3–7 AP points, demonstrating strong cross-domain transferability. In the ColWaymo pre-training experiments (Table 3), pre-training on TYP-generated collaborative Waymo data outperforms both training from scratch and pre-training on simulated OPV2V across all fusion methods and fine-tuning budgets (0, 5, 10, 32 scenes), with the advantage being most pronounced in the few-shot (5-scene) setting (e.g., 0.51 vs. 0.42 all-AP for Late Fusion). The gap to oracle narrows as more fine-tuning data is available, suggesting the generated data primarily benefits data-scarce regimes.

## Relation to Prior Work

This paper builds on latent diffusion models (LDM) and VQ-VAE for 3D point cloud generation, but departs from all prior ego-centric LiDAR generation work (LiDARGen, RangeLDM, UltraLiDAR, LidarDM) by introducing a fundamentally different conditioning: the ego-car's own point cloud as a spatial anchor for generating a *different* viewpoint's perception. The two-stage training recipe borrows the adapter mechanism from T2I-Adapter for lightweight control injection, and the domain adaptation step adapts ADDA-style adversarial training to bridge the sim-to-real gap between simulated CAV data (OPV2V) and real single-agent data (Waymo). Unlike prior CAV datasets that require simultaneous multi-agent deployment, TYP repurposes existing single-agent datasets as the training substrate, making the collaborative data collection problem a generation problem.

## Why It Matters / Open Questions

The practical impact is substantial: TYP can convert any large-scale single-agent LiDAR dataset (e.g., Waymo's 17,400 training samples) into a collaborative dataset (~36,000 paired samples), potentially eliminating the need for expensive multi-agent data collection that has bottlenecked CAV research. The ColWaymo dataset and the demonstrated transferability (pre-training on ColWaymo outperforms pre-training on simulated OPV2V) suggest a viable path to scaling CAV development. Limitations include focus on vehicle-like objects only, offline generation, and a persistent (if small) gap to oracle performance, particularly at long range. Open questions include extending to static infrastructure (traffic signs, signals), real-time generation, and whether the approach generalizes to sensor modalities beyond LiDAR.

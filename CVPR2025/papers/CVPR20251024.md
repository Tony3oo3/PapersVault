## Problem

Existing category-agnostic pose estimation methods extract support features via heatmap pooling and interact with query features through cross-attention on single-scale maps, which is too coarse for pixel-level keypoint localization. They also neglect to mine fine-grained and structure-aware features from both support and query images, and rely on zero padding to align varying keypoint counts across classes, providing sparse and semantically empty supervision.
![Teaser figure](../imgs/CVPR20251024/cropped_page0_idx0.webp)

## Input / Output

The method takes a query image from an unseen class, N support images with annotated keypoints, and a binary keypoint-link adjacency matrix for the category. All images are cropped to the object bounding box and resized to 256×256. The output is a set of K unified keypoint coordinates (K=70 by default) on the query image, where the original class-specific keypoint count (ranging 8–68 in MP-100) is expanded via mixup padding to a fixed number, and the model outputs incremental coordinate refinements over L=3 recurrent layers.

## Method

The framework consists of L stacked recurrent layers that alternately mine fine-grained and structure-aware (FGSA) features from support and query images using a deformable-attention-based module. For fine-grained mining, keypoints serve as reference points for deformable attention heads that sample multi-scale feature pyramid locations; for structure-aware mining, the M attention heads of each keypoint are assigned distinct reference points obtained via breadth-first search over the keypoint-link graph, so each head adaptively aggregates features around a different linked keypoint. A mixup padding strategy replaces zero padding by randomly interpolating linked keypoint pairs with a Beta-distributed coefficient, generating dense intermediate keypoints that provide richer L1 supervision during training. The recurrent pipeline updates support features conditioned on the previous layer's keypoint features, enabling targeted support extraction, and refines keypoint coordinates incrementally via a lightweight MLP offset.

## Results

On the MP-100 dataset, the proposed method achieves 73.42% mPCK in the 1-shot setting and 78.02% mPCK in the 5-shot setting (averaged over 5 splits), outperforming the strongest baseline SCAPE by +1.06% and +0.84% respectively. On the fine-grained PCK@0.05 metric (Split-1, 1-shot), the method reaches 57.30%, a +3.2% improvement over SCAPE (54.09%) and +2.22% over MetaPoint (55.08%). The method also leads on PCK@0.2 (91.82%) and PCK@0.1 (78.48%), confirming consistent gains across all thresholds.

## Baselines & Comparisons

The method outperforms all six baselines on both 1-shot and 5-shot mPCK across all 5 splits. Against the closest competitor SCAPE [30] (72.36% 1-shot, 77.18% 5-shot), the gains are +1.06% and +0.84% mPCK respectively, with the largest margin on the fine PCK@0.05 threshold (+3.2%). MetaPoint [8] (72.23% 1-shot) is the second-closest baseline; the paper attributes its smaller gap to MetaPoint also using deformable attention but only on the query image, whereas the proposed method recurrently mines FGSA features from both support and query. CapeFormer [45] (70.58%) and GraphCape [19] (68.97%) trail by 2.84% and 4.45% mPCK in 1-shot, with the paper noting that its deformable-attention-based structure-aware mining surpasses CapeFormer's cross-attention and GraphCape's graph network. ESCAPE [37] (66.47%) and POMNet [52] (64.53%) are the weakest baselines, lagging by 6.95% and 8.89% mPCK respectively, consistent with their reliance on single-scale heatmap pooling without recurrent refinement.

## Relation to Prior Work

This paper extends the category-agnostic pose estimation (CAPE) pipeline established by POMNet and CapeFormer by replacing their heatmap-pooling-plus-cross-attention feature extraction with a recurrent deformable-attention module that mines fine-grained, structure-aware features from multi-scale feature pyramids on both support and query images. The deformable attention mechanism is adapted from Deformable DETR, with the key departure being the use of breadth-first-search-derived reference points along keypoint links to capture structural relationships. The mixup padding strategy, inspired by Mixup and DensePose, departs from the zero-padding convention used across all prior CAPE methods by generating dense interpolated keypoints along links for richer supervision.

## Why It Matters / Open Questions

The recurrent design where query keypoint features guide support feature extraction in each layer is a clean architectural idea that could inform other few-shot dense prediction tasks. The +3.2% PCK@0.05 gain over SCAPE is meaningful for pixel-level localization, and the ablation confirms each component (recurrent mining, structure-aware reference points, mixup padding, mixup loss) contributes independently. However, evaluation is limited to MP-100 with a ResNet-50 backbone, and it remains open whether the recurrent FGSA mining generalizes to 3D pose estimation, larger-scale benchmarks, or transformer-based backbones. The mixup padding idea could potentially transfer to other tasks requiring variable-length output alignment.

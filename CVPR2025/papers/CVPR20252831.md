## Problem

Instance detection (InsDet) must generalize to unseen testing scenes and bridge domain gaps between clean visual references and occluded, variably-lit proposals. While off-the-shelf foundation models (FMs) like DINOv2 achieve high recall for proposal detection, they are not specifically optimized for instance-level feature matching, and existing methods only partially exploit the open-world data available for adaptation. This paper identifies that FM adaptation via metric learning with targeted data augmentation is the missing piece for closing the performance gap.

## Input / Output

The method takes a novel RGB scene image (unseen during training) and a set of visual reference images (support templates) captured from multiple camera views with QR codes for pose estimation. At test time, NeRF-synthesized novel-view images of the same instances can be appended to the reference set to improve matching. The output is a set of bounding boxes each assigned an instance ID corresponding to one of the visual references, produced by running stable matching on pairwise cosine similarities between proposal and reference features with a 0.4 similarity threshold.

## Method

IDOW adapts a pretrained vision foundation model (DINOv2) for instance-level matching via a triplet metric learning loss (margin α=0.5, inverse cosine distance) finetuned on open-world data. Two novel data augmentation techniques enhance this adaptation: (1) distractor sampling, where SAM is run on random background images to generate object-like segments serving as universal hard negatives across all instances, and (2) per-instance Zip-NeRF training on the given visual references to synthesize novel-view images that enrich both training triplets and the test-time reference set. Hard negative sampling selects the most confusing cross-instance or distractor example per batch to maximize gradient signal. The full pipeline combines an open-world proposal detector (GroundingDINO or SAM) with the finetuned DINOv2 feature extractor, followed by stable matching and thresholding to produce final instance assignments.

## Results

On the HR-InsDet dataset (CID setting), IDOW with GroundingDINO achieves 57.01 AP, surpassing the previous best OTS-FM with GroundingDINO (51.68 AP) by 5.3 AP and the best CPL-based method (CPL_DINO, 27.99 AP) by 29 AP. On RoboTools (NID setting), IDOW with GroundingDINO reaches 59.4 AP, outperforming OTS-FM with GroundingDINO (56.7 AP) by 2.7 AP and VoxDet (18.7 AP) by 40.7 AP. The method also shows strong performance on small objects (35.25 AP vs. 28.79 AP for OTS-FM_GroundingDINO in CID) and hard scenes (40.74 AP vs. 37.23 AP), indicating robustness to challenging conditions.

## Baselines & Comparisons

IDOW consistently outperforms all baselines in both CID and NID settings. In the CID setting on HR-InsDet, IDOW_GroundingDINO (57.01 AP) beats OTS-FM_GroundingDINO (51.68 AP) by 5.3 AP and OTS-FM_SAM (41.61 AP) by 15.4 AP, while all five CPL variants (19.54–27.99 AP) are surpassed by 29–37 AP. In the NID setting on RoboTools, IDOW_GroundingDINO (59.4 AP) exceeds OTS-FM_GroundingDINO (56.7 AP) by 2.7 AP, OTS-FM_SAM (46.5 AP) by 12.9 AP, and VoxDet (18.7 AP) by 40.7 AP; the older baselines OS2D (2.9 AP), DTOID (3.6 AP), and OLN_corr (14.4 AP) are far behind. The gains are most pronounced on small objects and hard scenes, where domain gaps between visual references and occluded proposals are largest. Notably, IDOW_SAM (48.75 AP in CID) also surpasses OTS-FM_SAM (41.61 AP) by 7.1 AP, confirming that the FM adaptation via metric learning and data augmentation is the key driver of improvement rather than the choice of proposal detector alone.

## Relation to Prior Work

IDOW builds directly on OTS-FM, which established the pipeline of using SAM/GroundingDINO for proposal detection and DINOv2 for instance-level feature matching in instance detection. The key departure is that OTS-FM treats these foundation models as fixed, non-learned components, whereas IDOW adapts the feature model (DINOv2) via metric learning with purpose-built data augmentations—distractor sampling from open-world imagery and NeRF-based novel-view synthesis. This positions the work as a natural extension of the open-world data-sampling philosophy already present in Cut-Paste-Learn (background sampling) and VoxDet (external 3D data), but applied specifically to FM adaptation rather than detector training.

## Why It Matters / Open Questions

The >10 AP gains over prior SOTA on both HR-InsDet and RoboTools demonstrate that even off-the-shelf FMs leave substantial room for task-specific adaptation, a finding that generalizes beyond instance detection to any FM-based matching pipeline. The practical limitation is that the pipeline inherits GroundingDINO's speed constraints and requires ~1 hour of NeRF training per instance, making real-time deployment non-trivial. An open question is whether the NeRF-synthesis benefit (particularly at test time) persists for textureless or highly deformable objects where per-instance NeRF quality degrades, and whether the distractor-sampling strategy scales to open-vocabulary settings with unbounded instance categories.

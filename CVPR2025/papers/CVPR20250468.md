## Problem

Existing dense video captioning methods suffer from temporal bias: models over-focus on events with certain temporal characteristics due to (1) uneven temporal distribution of ground-truth events in training data, causing out-of-distribution events to be ignored, and (2) long-duration events having more frame features that dominate self-attention, causing short-duration events to be overlooked or poorly localized.

## Input / Output

The method takes an untrimmed video sampled at 1 FPS, subsampled or padded to a fixed number of frames (100 for ActivityNet Captions, 200 for YouCook2), and extracts per-frame visual features using a pre-trained CLIP ViT-L/14 encoder. It outputs N event-caption pairs, each consisting of a start timestamp, end timestamp, and a generated sentence, along with a predicted total event count from a dedicated counter head. The number of event queries is set to 10 for ActivityNet and 100 for YouCook2, with the event counter's maximum count set to 10 and 20 respectively.

## Method

E²DVC introduces three components to treat all events equally. First, a non-trainable Event Perception Module applies agglomerative hierarchical clustering on visual features to generate pseudo-events, followed by a refinement mechanism that splits temporally discontinuous clusters and discards events shorter than a threshold τ, ensuring the perception is unaffected by training data distribution. Second, an Event-Enhanced Encoder concatenates pseudo-event label embeddings with frame features in a deformable transformer, enabling the encoder to model frame-event relationships so short-duration events are not overwhelmed during self-attention. Third, a Pseudo-Event Initialization module replaces random decoder query initialization by encoding the center timestamps of pseudo-events through an inverse-sigmoid and temporal encoder, explicitly directing each query to a specific pseudo-event location while also appending a small set of random queries to cover events not captured by clustering. The full model uses a parallel encoder-decoder with localization, LSTM captioning, and event-counting heads, trained end-to-end with Hungarian matching and a combined gIOU, classification, counting, and cross-entropy caption loss.

## Results

On ActivityNet Captions with CLIP features, E²DVC achieves BLEU4=2.43, METEOR=8.57, CIDEr=33.63, and SODA_c=6.13, outperforming the PDVC baseline (2.21/8.06/29.97/5.92) and CM² (2.38/8.55/33.01/6.18). On YouCook2 with CLIP features, E²DVC reaches BLEU4=1.68, METEOR=6.11, CIDEr=34.26, and SODA_c=5.39, surpassing PDVC* (1.40/5.56/29.69/4.92) and CM² (1.63/6.08/31.66/5.34). For event localization, E²DVC attains the highest F1 of 56.14 on ActivityNet and 28.87 (TSN) on YouCook2 among non-pretrained methods. The method also generalizes across feature backbones, improving over PDVC with C3D and TSN features as well.

## Baselines & Comparisons

E²DVC consistently outperforms the PDVC baseline across all three feature types (C3D, TSN, CLIP) on ActivityNet Captions, with the largest gains in CIDEr (+3.86 with CLIP, +0.95 with TSN) and SODA_c (+0.25 with CLIP). Against CM² (the strongest non-pretrained competitor using CLIP), E²DVC wins on BLEU4 (2.43 vs 2.38), METEOR (8.57 vs 8.55), and CIDEr (33.63 vs 33.01) on ActivityNet, though CM² edges ahead on SODA_c (6.18 vs 6.13). On YouCook2, E²DVC surpasses CM² on all four captioning metrics (BLEU4 1.68 vs 1.63, CIDEr 34.26 vs 31.66) and achieves the best localization F1 among non-pretrained methods (28.87 vs 28.43). The only method that outperforms E²DVC is Vid2Seq, a pretrained model using 1M extra videos, which achieves substantially higher scores on YouCook2 (METEOR 9.30, CIDEr 47.10) due to its large-scale pretraining advantage. For event localization on ActivityNet, E²DVC achieves the best F1 (56.14) and Precision (57.70) among all non-pretrained methods, exceeding CM² (55.21) and PDVC* (54.78).

## Relation to Prior Work

This paper extends the end-to-end dense video captioning pipeline (PDVC, CM²) by borrowing query-initialization strategies from the DETR family (Conditional DETR, Anchor DETR, DAB-DETR) and repurposing them for temporal event localization. Its key departure is introducing a non-trainable agglomerative hierarchical clustering step over visual features to generate pseudo-events, which then serve as both decoder query initializations (PEI) and additional label inputs to the encoder (EEE). Unlike prior DVC methods that rely entirely on learned, randomly-initialized queries to discover event locations, E²DVC grounds those queries in a data-agnostic visual similarity structure, explicitly targeting the temporal bias (uneven event distribution and duration imbalance) that the authors identify as a persistent weakness.

## Why It Matters / Open Questions

The paper demonstrates that a simple, non-trainable clustering heuristic can meaningfully reduce temporal bias in DVC, offering a lightweight and interpretable component that could be plugged into other event-based video understanding pipelines. However, the approach remains limited: the clustering is purely visual and ignores temporal continuity until the refinement step, the number of clusters N_c is a fixed hyperparameter that must be tuned per dataset, and long-duration event boundaries are still imprecise. Open questions include whether adaptive or learned clustering could replace the fixed N_c, whether the method extends naturally to streaming or hour-long video settings, and whether the visual-similarity assumption holds for visually homogeneous but semantically distinct events (e.g., repeated cooking steps).

## Problem

Existing text-to-video diffusion models struggle to follow complex prompts with multiple objects, often neglecting key objects or confusing them as one concept, and cannot control object motions, semantic transitions, or camera motion from text alone. Prior layout-guided approaches rely on 2D bounding boxes that lack perspective invariance and provide only coarse-grained, class-level conditioning, limiting fine-grained controllability and 3D scene synthesis.
![Teaser figure](../imgs/CVPR20250149/cropped_page1_idx1.webp)

## Input / Output

The method takes a global text prompt plus blob video representations as conditioning: per-frame, per-object blob parameters (a 5-vector [cx, cy, a, b, θ] defining a tilted ellipse for location, size, and orientation) and free-form blob descriptions (region-level captions) provided only at sparse anchor frames every k frames. Output is a generated video (or multi-view indoor scene images). Blob layouts can be manually specified, extracted from existing videos via segmentation and captioning pipelines, or auto-generated by GPT-4o from a text prompt via in-context learning with structured JSON output.

## Method

BlobGEN-Vid is a model-agnostic framework that inserts two new attention modules and a context interpolation module into a frozen pre-trained video diffusion backbone (U-Net or DiT). Masked spatial cross-attention restricts each blob embedding to attend only to visual features within its ellipse region per frame, enforcing frame-wise object-content alignment. Masked 3D self-attention flattens the (T, h, w) feature volume and applies an object-centric mask so that each object's features attend only to the same object across all frames (and background to background), enforcing temporal consistency at the object level. A context interpolation module linearly interpolates CLIP-encoded blob description embeddings between anchor frames to fill non-anchor frames, ensuring smooth semantic transitions without modality mismatch. Only the newly added layers are trained while all pre-trained weights remain frozen.

## Results

On YoutubeVIS-2021, BlobGEN-Vid (VC2 backbone) achieves mIOU 0.6119, a 24% improvement over the strongest baseline TrackDiffusion (0.4916), while also reducing FVD from 464 to 396 and improving rCLIP_i from 0.8041 to 0.8223. The CogVideoX-5B variant further lowers FVD to 317 and achieves the best rCLIP_t (0.2888) and rCFC (0.9580). On T2V-CompBench, the full GPT-4o + BlobGEN-Vid pipeline outperforms proprietary systems (Kling 1.0, Gen-3 Alpha, Dream Machine) on Dynamic-Attr (0.2650), Spatial (0.6725), Motion (0.3880), and Numeracy (0.3910). On ScanNet++ multi-view generation, BlobGEN-Vid achieves PSNR 22.20 and CFC 0.9453, substantially outperforming BlobGEN-3D (PSNR 15.23, CFC 0.9322).

## Baselines & Comparisons

BlobGEN-Vid outperforms all three layout-guided baselines (TrackDiffusion, LVD, VideoTetris) on every metric in Table 1, with the largest gap in mIOU: 0.6119 vs. 0.4916 (TrackDiffusion), 0.2814 (LVD), and 0.1658 (VideoTetris). TrackDiffusion is the closest competitor, matching rCFC closely (0.9403 vs. 0.9491) but trailing by 12 percentage points in mIOU and 1.8 points in rCLIP_i. On the compositionality benchmarks (Table 2), the GPT-4o + BlobGEN-Vid pipeline beats Kling 1.0 on Dynamic-Attr (0.2650 vs. 0.2256), Spatial (0.6725 vs. 0.6150), Motion (0.3880 vs. 0.2448), and Numeracy (0.3910 vs. 0.3044), and surpasses Gen-3 Alpha on Dynamic-Attr (0.2650 vs. 0.2078) and Motion (0.3880 vs. 0.3111), though Gen-3 Alpha retains an edge on TC-Bench Background Shift TC-Score (27.45 vs. 10.42). For multi-view indoor generation (Table 3), BlobGEN-Vid dominates BlobGEN-3D across all image and video metrics, with FVD dropping from 468 to 161 and PSNR rising from 15.23 to 22.20, confirming the benefit of the masked 3D attention for temporal consistency.

## Relation to Prior Work

This paper directly extends BlobGEN (Nie et al., ICML 2024), which introduced tilted-ellipse blob representations for compositional image generation, to the video domain by adding temporal dimensions to both the representation and the attention mechanisms. It departs from prior layout-guided video generation work (TrackDiffusion, Boximator, LVD, VideoDirectorGPT), which relies on 2D bounding boxes, by adopting blobs that offer perspective invariance and finer spatial control, and by replacing class labels with free-form object captions. The masked 3D self-attention module is a key architectural departure: unlike standard temporal self-attention in video diffusion that only links same spatial locations across frames, it uses blob masks to enforce object-level coherence, and the context interpolation module addresses the sparse-caption problem unique to video. The framework is explicitly model-agnostic, demonstrated on both U-Net (VideoCrafter2) and DiT (CogVideoX-5B) backbones.

## Why It Matters / Open Questions

The blob representation provides a practical, LLM-friendly layout format that bridges 2D video generation and 3D scene understanding (blobs can be projected from 3D point clouds), making it a potentially unifying interface for controllable generation across domains. The model-agnostic design means the masked 3D attention and context interpolation modules can be grafted onto any existing video diffusion model, lowering the barrier for adoption. However, the approach still requires an automated annotation pipeline (Grounding DINO + SAM2 + LLaVA-NeXT) to produce training data, and the blob representation, while more expressive than boxes, remains a 2D tilted ellipse that may struggle with highly occluded or multi-part objects. Open questions include whether the LLM-planning stage can be made more reliable for complex multi-object scenes, whether the method scales to longer videos, and whether the 3D attention overhead becomes prohibitive at higher resolutions or frame counts.

## Problem

Few-shot semantic segmentation methods struggle to generalize to novel classes because support images provide incomplete, appearance-biased feature representations. While LLMs have recently been applied to FSS (e.g., LLaFS), existing approaches require multi-stage training and remain text-centric, producing segmentation results as textual descriptions that must be post-processed into masks. The paper addresses the gap of a single-stage, end-to-end pipeline that directly integrates LLM-derived semantic cues with pixel-level visual correspondence for query image segmentation.
![Teaser figure](../imgs/CVPR20252360/cropped_page2_idx0.webp)

## Input / Output

The method takes a query image, K annotated support images with binary masks, and a class label as input. The class label is used offline to generate a detailed visual description via ChatGPT 4.0, which is then fed alongside CLIP-encoded query image features into the multimodal LLM. The output is a pixel-level binary segmentation mask for the query image; in the K-shot setting, K separate forward passes produce K masks that are combined via per-pixel majority voting with a normalized threshold.

## Method

DSV-LFS introduces a <SEM_prompt> token into the LLaVA-7B vocabulary (analogous to LISA's <SEG> token) so the multimodal LLM can emit a query-specific semantic prompt: given the query image (CLIP features) and a ChatGPT-generated class description, the LLM's last-layer embedding at the <SEM_prompt> position is projected via an MLP into a semantic prompt vector. In parallel, a dense matching module extracts multi-depth features from the SAM ViT backbone for both query and support images, computes 4D hypercorrelation tensors via cosine similarity, and processes them with center-pivot 4D convolutions followed by a convolutional decoder to produce a spatial visual prompt. Both prompts, together with query image features, are fed into the SAM prompt-based mask decoder (using multi-head attention and learnable queries) to produce the final segmentation. Training is single-stage and end-to-end: LoRA fine-tunes the LLM while vision backbones remain frozen, and the 4D encoder/decoder and mask decoder are jointly optimized with a combined cross-entropy text loss and BCE+Dice mask loss over 10 epochs on two A100 GPUs.

## Results

On COCO-20i, DSV-LFS achieves 71.33 mIoU (1-shot) and 71.90 mIoU (5-shot), surpassing the previous best LLM-based method LLaFS [68] by +17.43 and +11.9 mIoU respectively. On PASCAL-5i, DSV-LFS reaches 74.96 mIoU (1-shot) and 75.21 mIoU (5-shot), marginally outperforming LLaFS in 1-shot (73.5) but slightly trailing in 5-shot (75.6), which the authors attribute to dataset saturation. In the cross-domain COCO-20i→Pascal-5i setting, DSV-LFS achieves 80.67 mIoU (1-shot), exceeding the best dedicated cross-domain method IFA [33] (79.6) by +1.07 mIoU without any fine-tuning.

## Baselines & Comparisons

DSV-LFS decisively outperforms all non-LLM baselines on both datasets: on COCO-20i 1-shot it leads HDMNet (48.6) by +22.7 mIoU and MIANet (47.7) by +23.6 mIoU. Against the closest LLM-based competitor LLaFS [68], DSV-LFS gains +17.43 mIoU (1-shot) and +11.9 mIoU (5-shot) on COCO-20i, while on PASCAL-5i it edges out LLaFS by +1.46 mIoU in 1-shot but trails by −0.39 mIoU in 5-shot, a gap the authors attribute to PASCAL-5i's simpler single-object-per-image structure causing performance saturation. In the cross-domain COCO-20i→Pascal-5i transfer (Table 2), DSV-LFS (80.67) surpasses the best dedicated cross-domain method IFA [33] (79.6) and RTD [52] (69.7) by +1.07 and +10.97 mIoU respectively, despite not being explicitly designed for cross-domain evaluation. The ablation (Table 3) confirms that the semantic prompt alone already yields 68.99 mIoU on COCO-20i 1-shot (+15 over prior SOTA), and adding the visual prompt from dense matching contributes a further +2.34 mIoU.

## Relation to Prior Work

DSV-LFS sits at the intersection of three research threads: LISA's reasoning-segmentation paradigm (which introduced the <SEG> token linking LLM outputs to visual decoders), SAM's prompt-based segmentation architecture, and the 4D hypercorrelation dense-matching framework from HSNet. It departs most sharply from LLaFS, the prior LLM-based FSS method, by replacing LLaFS's multi-stage, text-output pipeline (where the LLM generates textual segmentation descriptions requiring post-processing) with a single-stage, end-to-end architecture where the LLM emits a learned <SEM_prompt> token whose embedding directly conditions a visual mask decoder. The key conceptual move is using a multimodal LLM not to *describe* the segmentation but to *adapt* a general class description to the specific query image, producing a context-aware semantic prompt that complements pixel-level visual correspondence.

## Why It Matters / Open Questions

The +17.4 mIoU gain on COCO-20i (1-shot) and the strong cross-domain transfer (COCO→Pascal without fine-tuning) suggest that LLM world knowledge can substantially compensate for the limited appearance variability captured by a few support images, a finding with implications beyond FSS for any low-data visual recognition task. However, the method's practical adoption is constrained by its reliance on a 7B-parameter multimodal LLM at inference time and an external ChatGPT call for class description generation, raising open questions about latency, cost, and whether the semantic-prompt mechanism can be distilled into a lighter model. The modest Pascal-5i margin over LLaFS (74.96 vs. 73.5) also hints that the large COCO gains may partly reflect the harder dataset benefiting more from semantic priors, leaving unclear how much of the improvement generalizes to other benchmarks.

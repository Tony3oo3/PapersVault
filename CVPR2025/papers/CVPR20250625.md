## Problem

Existing multi-task vision-language prompt learning methods (e.g., MVLPT, MmAP) ignore two critical challenges: spurious correlations from domain-specific biases that cause models to latch onto useless features (e.g., plates and forks co-occurring with apple pie), and dynamic task relationships that shift during joint training, leading to unresolved task conflicts. These issues degrade performance, particularly in few-shot and cross-domain settings where data is scarce.

## Input / Output

The method takes RGB images (patchified into tokens for a frozen CLIP ViT-B/16 encoder) and text prompts containing class labels as input, producing a predicted class label via cosine similarity in the shared vision-language embedding space. In the multi-task setting, N downstream classification tasks are jointly trained with task-shared and task-specific prompt tokens (16 tokens each) prepended to the image and text encoder inputs. A small development set sampled from validation data is additionally used to update the scheduler parameters during training.

## Method

JSCPT introduces a Multi-Task Vision-Language Prompt (MTVLP) model that learns task-shared and task-specific visual and text prompts, then applies a causal intervention network with task-specific learnable masks to filter visual prompt features, selecting only those with beneficial causal effects (I→U→Y) while suppressing confounder-driven spurious correlations. A task-prompt scheduler computes two signals per task: a Granger-causal effect score quantifying how much the selected features reduce task loss, and an inter-task affinity matrix derived from gradient direction and magnitude on shared prompts. These signals drive learnable per-sample, per-task scheduling weights that up-weight useful features and positively correlated tasks while down-weighting harmful ones. The entire system is solved via bi-level optimization: the lower level updates MTVLP parameters with the scheduled weighted gradient, while the upper level updates scheduler parameters using implicit differentiation approximated by an H-truncated Neumann series (H=3), with an M-step strategy (M=10) for computational efficiency.

## Results

On the Large-Scale MTL benchmark (10 tasks), JSCPT achieves 70.1% average accuracy under 1-shot, 77.2% under 5-shot, 80.8% under 10-shot, and 84.4% under 20-shot settings, consistently outperforming the strongest baseline MmAP by 1.3–1.5 percentage points. On Office-Home (20% split), JSCPT reaches 92.7% average accuracy across four domain tasks, surpassing MmAP (92.0%) by 0.7%. On MiniDomainNet (2% split), JSCPT attains 86.4% average accuracy, exceeding MmAP (85.6%) by 0.8%.

## Baselines & Comparisons

JSCPT outperforms all six baselines across every dataset and evaluation setting. The closest competitor is MmAP, the other multi-task prompt method; JSCPT beats it by 0.7% on Office-Home (20%), 0.8% on MiniDomainNet (2%), and 1.3–1.5% on the 10-task Large-Scale MTL benchmark. Among single-task baselines, MaPLe is the strongest (e.g., 81.7% at 20-shot on the Large-Scale benchmark), but JSCPT still leads by 2.7 points, demonstrating the benefit of joint multi-task scheduling. MVLPT, the prior multi-task prompt method, is consistently outperformed by JSCPT (e.g., 84.4% vs. 81.1% at 20-shot), confirming that causal feature selection and adaptive task scheduling provide gains beyond simple multi-modal prompt sharing. The ablation further shows that replacing the proposed task scheduling with CAGrad gradient optimization yields lower accuracy (87.1% vs. 87.9% on Office-Home 20%), indicating that the learned inter-task affinity is more effective than fixed gradient conflict resolution.

## Relation to Prior Work

This paper extends multi-task vision-language prompt learning (MVLPT, MmAP, HiPro) by introducing two orthogonal mechanisms: causal intervention via learnable masks to filter spurious features from prompt embeddings, and a dynamic task-prompt scheduler that jointly weighs tasks based on gradient-based inter-task affinity and Granger-causal feature effects. It departs from prior multi-task prompt methods that either pre-group tasks statically or simply sum task losses, instead formulating the scheduling problem as a bi-level optimization where the scheduler is updated via implicit differentiation (Neumann-series approximation) on a small dev set. The causal feature selection draws on Granger-causal objectives and counterfactual intervention literature, while the task scheduling builds on gradient-surgery and CAGrad-style conflict detection, but unifies both under a single learnable weighting scheme.

## Why It Matters / Open Questions

The paper addresses two practically important failure modes in multi-task VLM prompt learning—spurious correlations from domain bias and dynamic task conflicts—that prior methods largely ignore, and provides a principled (if computationally heavier) framework to handle both simultaneously. However, the improvements over the strongest baseline (MmAP) are modest (0.7–1.4% across datasets), the causal intervention is relatively simple (element-wise masks + MLP), and the bi-level optimization adds non-trivial training overhead (M-step lower-level updates plus Hessian-vector products). Open questions include whether the approach scales to many more tasks or non-classification tasks (detection, segmentation), whether the causal mask mechanism generalizes beyond the specific confounder patterns observed, and whether the bi-level optimization is worth its cost compared to simpler adaptive weighting schemes.

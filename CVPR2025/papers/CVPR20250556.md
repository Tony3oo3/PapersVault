## Problem

VQ-based visual frameworks face a fundamental trade-off: representation learning demands high-level semantic discrimination while generation demands fine-grained detail reconstruction, and both compete for the same latent embedding space. Moreover, standard VQ introduces gradient approximation bottlenecks and inevitably strips spatial information, degrading both tasks. The paper argues these objectives are intrinsically complementary rather than conflicting, but exploiting this complementarity requires explicitly decoupling semantics from spatial details while minimizing information loss.

## Input / Output

The tokenizer takes a 256×256 RGB image and produces K discrete semantic tokens (36, 144, or 256 depending on the G, G+R, or R variant) quantized via LFQ, along with a binary source matrix S ∈ {0,1}^{K×L} that records which of the original L=1024 spatial positions each merged token originated from. For generation, the model additionally consumes a class label and a merge instruction token, then outputs L tokens in raster order (MergeAR) or K tokens in random order (RandAR), which are expanded back to L tokens via the source matrix before pixel-level decoding. The source matrix is the key intermediate artifact: it is ground-truth during training but must be predicted by a lightweight Source Recovery module at inference time.

## Method

MergeVQ's encoder uses a hybrid CNN (ResNet blocks) + ToMe Attention architecture that progressively merges the L=1024 token sequence down to K tokens while maintaining a source matrix S that preserves spatial provenance. The K tokens are quantized with Look-up Free Quantization (LFQ, 18-bit binary codebook), and a Source Recovery Transformer decoder with L learnable positional embeddings predicts S from the K tokens, enabling contextual modeling and token expansion back to length L for reconstruction. Global alignment via DINOv2 self-distillation on CLS tokens is imposed on the K semantic tokens to boost representation quality. For second-stage generation, MergeAR constructs a causal mask from S that masks out duplicate tokens, then prunes redundant entries from the KV cache during inference to accelerate raster-order next-token prediction; alternatively, RandAR generates K tokens in random order and invokes the Source Recovery module to restore full spatial detail before decoding.

## Results

On ImageNet-1K class-conditional generation (256×256), MergeVQ(G) with RandAR-cfg achieves gFID 2.24 and IS 320.4 in 88 steps, while MergeVQ(G+R) with RandAR-cfg reaches gFID 2.63 and IS 279.5 in 64 steps. For self-supervised pre-training, MergeVQ(R) attains 79.8% linear probing and 84.2% fine-tuning accuracy using only 36 tokens (vs. 196 for DINOv2), and MergeVQ(G+R) reaches 77.9% Lin. / 82.0% FT with 144 tokens. For reconstruction, MergeVQ(G) with 256 tokens achieves rFID 1.06, outperforming MAGVIT-v2 (1.16) and LlamaGen (2.19) at the same token budget.

## Baselines & Comparisons

In class-conditional generation, MergeVQ(G) with RandAR-cfg (gFID 2.24, IS 320.4) outperforms the same RandAR generator paired with LlamaGen (gFID 2.55, IS 288.8) by 0.31 gFID, and surpasses OpenMAGVIT2-L (gFID 2.51) with fewer parameters (343M vs. 804M). MergeVQ(G+R) with MergeAR (gFID 3.25) improves over vanilla LlamaGen-L (gFID 3.80) by 0.55 gFID and substantially outperforms MAGE-L (gFID 6.93) and DiGIT (gFID 3.39) in the AR&PT category. For representation learning, MergeVQ(R) achieves 79.8% linear probing accuracy with only 36 tokens in 300 epochs, approaching DINOv2's 84.5% (196 tokens, 1000 epochs) while using 5.4× fewer tokens and 3.3× fewer epochs; MergeVQ(G+R) reaches 77.9% Lin. with 144 tokens in 200 epochs, competitive with MAGE-C (78.2%, 196 tokens, 1600 epochs). In reconstruction, MergeVQ(G) at 256 tokens (rFID 1.06) beats MAGVIT-v2 (1.16) and LlamaGen (2.19), while MergeVQ(G+R) at 144 tokens (rFID 1.48) remains competitive with MaskBiT (1.37) at the same token count. The KV-cache compression in MergeAR provides a 0.09 gFID improvement over vanilla LlamaGen with MergeVQ(G) (3.05 vs. 3.14), confirming its utility when the generated sequence is redundant.

## Relation to Prior Work

MergeVQ sits at the intersection of three research threads: token merging for ViT efficiency (ToMe), look-up free quantization for discrete visual tokenization (MAGVIT-v2/LFQ), and the unification of representation learning with autoregressive generation (BEiT, MAGE, DiGIT). Its key conceptual departure is repurposing ToMe's token merging not merely as an inference-time speedup but as a training-time mechanism that decouples coarse-grained semantics (K merged tokens) from fine-grained spatial details (preserved in a source matrix), thereby addressing the competing objectives of representation and generation in a single latent space. For second-stage generation, it builds directly on LlamaGen's raster-order architecture and RandAR's random-order paradigm, adding a KV-cache compression strategy (MergeAR) that exploits the redundancy introduced by token merging.

## Why It Matters / Open Questions

The practical significance lies in token efficiency: achieving competitive representation quality (79.8% linear probing) with only 36 tokens and strong generation (gFID 2.24) with 256 tokens, compared to 1024 tokens in prior VQ-based systems, suggests a path toward more efficient unified visual models. However, the evaluation is limited to ImageNet-1K at 256×256, and the trade-off between the three variants (G, G+R, R) indicates the unification is not yet seamless—each task still benefits from different merge ratios. Open questions include whether the source-matrix recovery generalizes to video or higher resolutions, whether the DINOv2 alignment target can be replaced by a learned objective, and whether the KV-cache compression in MergeAR scales to much longer sequences without quality degradation.

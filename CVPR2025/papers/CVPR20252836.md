## Problem

Zero-shot composed image retrieval methods encode the reference image as a single pseudo token in language space, creating a representation gap between the composed query embedding and target image embeddings in image space. This paper asks whether generating a pseudo-target image from the reference image and delta caption can bridge this multimodal gap and improve retrieval accuracy without requiring triplet training data.
![Teaser figure](../imgs/CVPR20252836/cropped_page1_idx0.webp)

## Input / Output

The method takes a reference image (any resolution, resized for CLIP encoding) and a short delta caption describing desired visual changes. During training, it consumes only image-caption pairs (490K from CC3M with keywords masked from captions) in a self-supervised reconstruction loop. At inference, it produces a pseudo-target image at the diffusion model's native resolution (512×512 for SD V1-5, 1024×1024 for SDXL), which is then re-encoded into text space to augment the retrieval query; the final output is a ranked list of target images from the database.

## Method

CIG fine-tunes a latent diffusion model (Stable Diffusion V1-5 or SDXL) to reconstruct images conditioned on composed prompt embeddings that fuse a textual-inversion pseudo token of the reference image with the caption via a template ('a photo of S* that {caption}'). Training is entirely self-supervised—only the cross-attention key/value projections are updated with a standard denoising objective—yet the model acquires the ability to generate pseudo-target images at inference that incorporate the delta caption while preserving reference image content. At retrieval time, the generated pseudo-target is mapped back through the same textual inversion network to produce a second composed text embedding, which is linearly combined with the original composed embedding (weighted by a trade-off hyperparameter λ) before computing cosine similarity against database image embeddings. This plug-and-play design requires no triplet data, no modification to the base CIR method's encoder, and adds only ~2 seconds (or ~140 ms with SDXL Turbo) of inference time per query.

## Results

On CIRR (ViT-L/14), CIG-XL turbo improves SEARLE's Recall@1 from 24.24 to 26.72 (+2.48) and LinCIR's from 25.04 to 26.17 (+1.13). On CIRCO (ViT-G/14), LinCIR+CIG-XL raises mAP@5 from 19.71 to 20.64 and mAP@50 from 24.18 to 25.20. On Fashion-IQ (ViT-L/14), LinCIR+CIG-XL turbo achieves an average R@10 of 26.60 vs. LinCIR's 26.28. The method also adds only ~0.14 s per image with SDXL Turbo, compared to 1.87 s for the LLM-based CIReVL baseline.

## Baselines & Comparisons

CIG consistently outperforms all three zero-shot CIR baselines (SEARLE, Pic2Word, LinCIR) across CIRR, CIRCO, Fashion-IQ, and GeneCIS. The largest gains appear on CIRR with SEARLE (ViT-L/14), where CIG-XL turbo lifts Recall@1 by 2.48 points (24.24→26.72) and RecallSubset@1 by 4.19 points (53.76→57.95). Against LinCIR (ViT-L/14), CIG-XL turbo adds 1.13 points on Recall@1 (25.04→26.17) and 0.97 on RecallSubset@1 (57.11→58.08). On CIRCO (ViT-G/14), LinCIR+CIG-XL improves mAP@5 by 0.93 points (19.71→20.64). Compared to the LLM-based CIReVL, CIG provides a smaller but consistent gain (CIRR R@1: 27.18→27.35; CIRCO mAP@5: 22.40→22.46) while running ~11× faster (0.17 s vs. 1.87 s per image), making it a practical drop-in add-on for both lightweight and LLM-based pipelines.

## Relation to Prior Work

This paper extends the zero-shot composed image retrieval (ZS-CIR) paradigm established by SEARLE, Pic2Word, and LinCIR, which all encode the reference image as a single pseudo token in the CLIP text embedding space and fuse it with the delta caption. The key departure is introducing a generative component: a latent diffusion model (Stable Diffusion / SDXL) is fine-tuned in a self-supervised regime to reconstruct images from composed prompt embeddings, and at inference time generates a pseudo-target image that provides additional visual information for retrieval. Unlike prior ZS-CIR methods that operate entirely in the language embedding space, CIG bridges the modality gap by producing an actual image that can be re-encoded, effectively adding a second visual signal alongside the reference image's pseudo token.

## Why It Matters / Open Questions

The paper demonstrates that a diffusion model trained purely to reconstruct its input (without ever seeing target images) can generate pseudo-targets that meaningfully improve retrieval, offering a plug-and-play add-on to any existing ZS-CIR pipeline without requiring triplet datasets. However, the practical gains are modest (typically 1–2.5 points on CIRR, under 0.5 on Fashion-IQ and GeneCIS), and the approach adds inference latency (though SDXL Turbo reduces this to ~100 ms). Open questions include whether the method scales to more complex multi-attribute compositions, whether the self-supervised training objective can be further refined to improve generation fidelity, and whether the gains persist as base diffusion models improve in quality.

## Problem

Existing unified segmentation models either scale across datasets but not tasks, or across tasks but not datasets, and none achieve true joint scalability. The paper identifies the root cause as the object query design: learnable queries excel at stuff-level (semantic) segmentation but fail at instance-level tasks, while conditional queries show the opposite pattern, preventing any single query strategy from generalizing across diverse segmentation tasks and datasets simultaneously.
![Teaser figure](../imgs/CVPR20250413/cropped_page1_idx0.webp)

## Input / Output

The model accepts an RGB image and a list of free-form textual prompts (class names, referring expressions, or arbitrary natural language descriptions) and outputs per-prompt segmentation masks, bounding boxes, and class predictions. Unlike prior unified frameworks that require strict stuff/thing class assignments or task-specific query allocation, MQ-Former treats all annotations uniformly as (class, bbox, mask) triplets where the class field can be any text string, enabling open-vocabulary and free-form inference without additional annotation.

## Method

MQ-Former introduces a mixed query mechanism that combines 100 learnable queries and 300 conditional queries, fused in each decoder layer via dual-query cross-attention (conditional-to-learnable and learnable-to-conditional modules). This enables sample-wise dynamic query selection: conditional queries naturally capture local instance-level features while learnable queries handle global background/stuff regions, with Hungarian matching applied jointly across all 400 queries without rigid type-to-task assignment. The architecture builds on Mask DINO's encoder-decoder with a CLIP text encoder for open-vocabulary support, and all segmentation tasks (instance, semantic, panoptic, referring, foreground, detection) are unified into a single training format. Scalability is further extended by generating synthetic segmentation masks (via SAM given bounding boxes) and synthetic object captions (via an OFA-akin model) offline, converting large detection datasets into segmentation training data and enriching semantic supervision without costly human annotation.

## Results

On the SeginW open-vocabulary in-the-wild segmentation benchmark, MQ-Former achieves 43.4 Mask AP, surpassing X-Decoder (32.3) by 11.1 points and OpenSeeD (36.1) by 7.3 points. On closed-set COCO instance segmentation, MQ-Former reaches 52.3 Mask AP (vs. 50.6 for Mask DINO and 46.7 for X-Decoder), and on RefCOCOg free-form referring segmentation it achieves 68.2 mIoU (vs. 64.6 for X-Decoder). The model is the only unified framework evaluated that simultaneously handles all six segmentation tasks (instance, semantic, panoptic, referring, foreground, and detection) while matching or exceeding specialist-model performance on most benchmarks.

## Baselines & Comparisons

MQ-Former's most striking win is on SeginW open-vocabulary segmentation, where it achieves 43.4 Mask AP versus 32.3 for X-Decoder (+11.1) and 36.1 for OpenSeeD (+7.3), validating the paper's core scalability claim. On closed-set COCO instance segmentation, MQ-Former (52.3 Mask AP) outperforms Mask DINO (50.6) and X-Decoder (46.7), and on RefCOCOg referring segmentation it beats X-Decoder (68.2 vs. 64.6 mIoU) though it trails the specialist PolyFormer (71.2). On ADE semantic segmentation, MQ-Former ties X-Decoder at 58.1 mIoU while surpassing OneFormer (57.0) and Mask2Former (48.1 on ADE SS). On BDD panoptic segmentation, MQ-Former (29.3 PQ) substantially outperforms OpenSeeD (19.4) and X-Decoder (17.8). The key differentiator is task coverage: MQ-Former is the only unified model that simultaneously handles instance, semantic, panoptic, referring, foreground segmentation, and object detection, whereas all baselines are restricted to a subset of these tasks.

## Relation to Prior Work

MQ-Former builds directly on the Mask DINO architecture for its encoder-decoder backbone and on X-Decoder's unified data format for joint multi-dataset, multi-task training, but departs from X-Decoder's reliance on purely learnable queries by introducing a mixed query mechanism that fuses learnable and conditional queries via dual-query cross-attention. The conditional query concept is borrowed from the object detection literature (Deformable DETR, DN-DETR, DAB-DETR) and adapted to segmentation, while the text encoder follows X-DETR for open-vocabulary support. Unlike prior unified segmentation frameworks (OneFormer, OpenSeeD, OMG-Seg) that impose rigid task or class-to-query assignments, MQ-Former uses a soft, annotation-flexible format that avoids requiring stuff/thing discrimination, enabling seamless integration of heterogeneous datasets.

## Why It Matters / Open Questions

The paper provides the clearest empirical evidence to date that jointly scaling both dataset diversity and task variety yields consistent, compounding gains in open-set generalization (7 points on SeginW), establishing a practical recipe for building ever-better segmentation models without architectural redesign. The synthetic data pipeline (SAM-based masks + OFA-based captions) offers a low-cost path to circumvent the annotation bottleneck, though its quality ceiling is bounded by the upstream generators. Open questions include whether the mixed query mechanism generalizes to video or 3D segmentation, how far synthetic data can substitute for human annotations before diminishing returns, and whether the scaling trend holds beyond the ~2.2M images explored here.

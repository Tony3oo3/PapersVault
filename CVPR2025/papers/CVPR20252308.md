## Problem

Open-vocabulary 3D scene segmentation is bottlenecked by the lack of large-scale, high-quality 3D mask-text pair datasets. Existing annotation pipelines rely on coarse bounding-box detectors or produce only simple attribute labels, and resulting datasets contain only a few thousand scenes—orders of magnitude smaller than the web-scale image-text corpora that enable 2D open-vocabulary models. This paper addresses all three requirements simultaneously: precise 3D region boundaries, rich per-region textual descriptions, and dataset scale sufficient for diverse visual-semantic coverage.

## Input / Output

At inference, the model consumes only a 3D point cloud and a free-form text query—no 2D RGB-D images are needed, unlike prior methods that project 3D regions onto multiple views for CLIP scoring. The encoder outputs per-point language-aligned features (D-dimensional vectors) used for semantic segmentation via dot-product similarity with text embeddings. The mask decoder additionally produces Q binary instance masks with objectness scores, enabling single-stage open-vocabulary instance segmentation without ground-truth category labels. Training data consists of 3D binary region masks (N-point vectors) paired with natural language captions of varying length, processed by Recap-CLIP as the text encoder.

## Method

The data engine combines Grounded-SAM2 (RAM++ → GroundingDINO → SAM2) for precise foreground object segmentation with SEEM for open-vocabulary panoptic segmentation of background stuff, then uses the region-aware VLM Osprey to generate detailed per-region captions conditioned on each mask. These 2D masks are projected onto 3D points via camera intrinsics/extrinsics with a depth-consistency check to form 3D mask-text pairs, yielding Mosaic3D-5.6M (30K+ scenes, 5.6M pairs, 30M tokens) from five source datasets. The model is a SparseUNet34C (43.7M params) trained in two stages: first, contrastive learning aligns per-point features with caption embeddings using a region-weighted InfoNCE loss; second, a Mask3D-based transformer decoder is trained with Hungarian matching, objectness/Dice/BCE losses, and a novel mask-caption contrastive loss that directly aligns mask embeddings with concatenated caption embeddings, enabling open-vocabulary instance segmentation in a single 3D forward pass.

## Results

On open-vocabulary 3D semantic segmentation, Mosaic3D trained on the full Mosaic3D-5.6M dataset achieves 68.1 f-mIoU on ScanNet20, 18.0 on ScanNet++, 13.1 on Matterport3D, and 15.7 on ScanNet200, setting new state-of-the-art on all four benchmarks. Even using only ScanNet training data, Mosaic3D reaches 65.0 f-mIoU on ScanNet20, surpassing OV3D (64.0) and RegionPLC (59.6). For open-vocabulary 3D instance segmentation on ScanNet200, Mosaic3D with Mask3D proposals achieves 11.8 mAP (vs. 8.8 for OpenIns3D), and the first single-stage open-vocabulary decoder (Mosaic3D w/Decoder) reaches 3.9 mAP with only 1.2s latency per scene.

## Baselines & Comparisons

Mosaic3D outperforms all prior annotation-free methods across every benchmark. On ScanNet20, it beats OV3D [48] by 4.1 f-mIoU (68.1 vs. 64.0) and RegionPLC [98] by 8.5 f-mIoU (68.1 vs. 59.6); on ScanNet200, it surpasses RegionPLC [98] by 6.6 f-mIoU (15.7 vs. 9.1) and OV3D [48] by 7.0 f-mIoU. Against the multi-dataset baseline RegionPLC+SceneVerse [44] (61.0 f-mIoU on ScanNet20), Mosaic3D gains 7.1 f-mIoU despite using fewer source scenes, highlighting the value of per-scene caption density. For instance segmentation, Mosaic3D with Mask3D proposals exceeds OpenIns3D [42] by 3.0 mAP (11.8 vs. 8.8) while running 285× faster (1.0s vs. 285.2s per scene); methods requiring 2D+3D inputs like Open3DIS [65] (23.7 mAP) and SAI3D [100] (12.7 mAP) achieve higher mAP but at 33–75s latency and with closed-vocabulary proposal networks. In the zero-shot setting (class names anonymized), Mosaic3D-5.6M retains 10.5 f-mIoU on ScanNet200, substantially outperforming LEO [39] (2.9), EmbodiedScan [94] (0.0), and MMScan [60] (8.5), confirming that rich caption diversity—not just class-name leakage—drives generalization.

## Relation to Prior Work

This paper extends the line of open-vocabulary 3D segmentation work (OpenScene, PLA, OV3D, RegionPLC) by addressing the data bottleneck that limits those methods: prior approaches relied on coarse bounding-box detectors or simple attribute labels, yielding imprecise masks and limited scale. The key architectural departure is the use of Grounded-SAM2 + SEEM for precise 2D segmentation and Osprey (a region-aware VLM) for detailed per-region captioning, replacing the generic image-level captioning or attribute-only labeling used before. For instance segmentation, the paper builds on Mask3D's transformer decoder and Segment3D's class-agnostic training losses, but introduces a caption-merging strategy (Algorithm 1) that enables the first single-stage open-vocabulary 3D instance segmentation without ground-truth labels, avoiding the multi-view CLIP inference required by OpenIns3D, OpenMask3D, and Open3DIS.

## Why It Matters / Open Questions

Mosaic3D-5.6M (5.6M mask-text pairs across 30K+ scenes) is an order of magnitude larger than prior 3D mask-text datasets and provides a practical, reproducible pipeline for generating such data at scale, which should accelerate the field. The zero-shot robustness analysis (anonymizing class names in captions) reveals that richer, more diverse captions from region-aware VLMs yield better generalization than clean GT labels (Mosaic3D-5.6M drops 5.2 f-mIoU vs. LEO's 11.9), suggesting that annotation quality and diversity matter more than label precision for open-vocabulary generalization. Open questions include whether the pipeline extends to outdoor or large-scale scenes, whether the relatively low instance segmentation mAP (3.9) can be improved with larger decoders or more data, and whether the reliance on 2D VFMs for annotation introduces systematic biases that limit 3D geometric understanding.

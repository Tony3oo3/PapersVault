## Problem

Document image segmentation tasks—layout analysis, multi-granularity text detection, and table structure recognition—are typically addressed by separate specialized models, resulting in redundant computational overhead, limited generalization across document types, and static architectures that cannot easily incorporate new datasets. No existing framework unifies these heterogeneous tasks into a single trainable model while preserving adaptability to diverse annotation formats and category sets.
![Teaser figure](../imgs/CVPR20250251/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB document image and a set of class names expressed as natural-language strings (e.g., 'text block', 'table cell', 'handwritten line'), which are embedded via Sentence-BERT into semantic queries whose count varies per dataset. It simultaneously produces per-pixel semantic masks, per-instance segmentation masks, instance class labels (computed as the softmax of dot products between instance and semantic queries rather than a fixed FC layer), and bounding boxes. Because classification relies on query similarity rather than a predefined output dimension, the model can accept arbitrary new class names at inference without architectural modification.

## Method

DocSAM decomposes all DIS tasks into a joint instance-and-semantic segmentation problem solved by a transformer decoder. A Swin-Transformer backbone with deformable attention extracts multi-scale image features, which are fused by an FPN into a single mask feature map; class names are embedded by Sentence-BERT into semantic queries that interact with learnable instance queries inside a stacked Hybrid Query Decoder (HQD). Within each HQD layer, the two query sets are concatenated for self-attention, then separately cross-attend with multi-scale features via two masked multi-scale decoders, and finally re-interact—enabling cooperative mask and class prediction. Instance classification is performed by computing the dot product between instance and semantic queries followed by softmax, effectively converting a closed-set FC classifier into an open-set prototype-matching scheme. Training employs heterogeneous mixed learning across ~48 datasets with curriculum learning (gradually adding task groups) and instance query selection (discarding low-confidence queries per HQD layer) to accelerate convergence and reduce memory.

## Results

After joint pre-training on 15 heterogeneous datasets, DocSAM-large achieves 0.830 mAP (instance) and 0.911 mIoU (semantic) on PubLayNet, 0.915 mAP and 0.951 mIoU on TableBank-latex, and 0.885 mAP and 0.821 mIoU on HJDataset. In the state-of-the-art comparison on M6Doc, DocSAM attains 0.663 Object mAP and 0.661 Instance mAP, surpassing TransDLANet (0.645/0.638) and ISTR (0.627/0.620) but trailing DAT (0.712 Object mAP). On scene text detection (CTW1500), DocSAM achieves an F-score of 0.842, notably below dedicated methods like DAT-SEG (0.917) and ESTextSpotter (0.900), which the authors attribute to the greater shape and background diversity of scene text.

## Baselines & Comparisons

On M6Doc, DocSAM outperforms TransDLANet (0.663 vs. 0.645 Object mAP), ISTR (0.663 vs. 0.627), Deformable DETR (0.663 vs. 0.572), Faster R-CNN (0.663 vs. 0.490), and Mask R-CNN (0.663 vs. 0.401), but trails DAT (0.712 Object mAP), though DAT does not report AP50/AP75. On SCUT-CAB physical layout, DocSAM achieves 0.811 Instance mAP, beating Mask R-CNN (0.795), Deformable DETR (0.779), VSR (0.787), and Faster R-CNN (0.753), yet falls short of SCNet (0.820). On SCUT-CAB logical layout, DocSAM (0.575 Instance mAP) underperforms all baselines including Deformable DETR (0.620) and SCNet (0.603), which the authors attribute to its single-modal (vision-only) design lacking textual cues. On scene text detection, DocSAM's F-scores (0.842 on CTW1500, 0.770 on Total-Text) are substantially below dedicated methods such as DAT-SEG (0.917/0.920), ESTextSpotter (0.900/0.900), and DPText-DETR (0.888/0.890), indicating that the unified framework struggles with the high shape and background diversity of natural scene text.

## Relation to Prior Work

DocSAM inherits its vision encoder (Swin-Transformer backbone with deformable attention) from Mask2Former and borrows the prompt-guided segmentation philosophy from SAM, but fundamentally reimagines the decoder as a Hybrid Query Decoder where Sentence-BERT-embedded class names serve as semantic queries that interact with learnable instance queries. This departs from prior unified document models (UPOCR, DocRes, OmniParser, DAT) that unify tasks through multi-task learning with task-specific heads, instead recasting all document segmentation tasks—layout analysis, multi-granularity text detection, table structure recognition—as a single instance-plus-semantic segmentation problem with an open-set, prototype-based classifier. The use of natural-language class names as both segmentation prompts and classification prototypes is the key conceptual departure from the standard FC+Softmax closed-set paradigm used in virtually all prior DIS methods.

## Why It Matters / Open Questions

DocSAM demonstrates that a single 207M–317M parameter model can handle roughly 48 heterogeneous document datasets spanning layout, text, and table tasks, reducing the need for a zoo of specialized models and enabling seamless fine-tuning to new tasks without architectural modifications. However, the paper is candid about limitations: single-modal features cause underperformance on logical layout analysis and scene text detection, and training convergence is slow. Open questions include whether a multi-modal extension (incorporating OCR text features) can close the gap with task-specific SOTA, and whether the curriculum-learning and instance-query-selection strategies generalize beyond the current dataset collection. The framework's open-set design also raises the possibility of continual learning as new document categories are introduced without retraining the classifier.

## Problem

State-of-the-art open-vocabulary object detectors (GroundingDINO, GLIP, T-Rex2) rely on large-scale pre-training or task-specific fine-tuning to improve detection, making them expensive to extend to rare or novel concepts. No existing training-free framework leverages the web as a continuously growing external memory to ground long-tail objects at inference time without any additional model training.
![Teaser figure](../imgs/CVPR20251159/cropped_page0_idx0.webp)

## Input / Output

Given an input RGB image and a text object label, the method retrieves 10 positive and 10 negative support images from Google at inference time, with negative queries (e.g., 'waves' for 'surfboard') generated by a Phi-3 LLM call. The output is a set of bounding boxes and segmentation masks for all instances of the queried object, produced by intersecting SAM region proposals with a binarized similarity heatmap. The entire pipeline runs in approximately 3.5 seconds per query on a single V100 GPU, with image scraping and segmentation executed in parallel.

## Method

SearchDet is a fully training-free inference pipeline that uses DINOv2 to embed web-retrieved positive and negative exemplar images, then constructs an adjusted query embedding via softmax-weighted attention over cosine similarities followed by subtraction of the weighted negative from the weighted positive embedding. SAM (HQ) generates region proposals via uniform-grid prompting, and a frequency-based adaptive thresholding algorithm (Algorithm 1) selects candidate masks by binning query-to-mask distances and requiring a single mask to occupy >80% of a bin, with a 3σ verification step against the reference distance distribution. A complementary pixel-level heatmap is produced by comparing the adjusted query embedding against upsampled DINOv2 patch features of the input image, binarized at threshold 50. Final detections are obtained by intersecting each SAM mask with the binarized heatmap, so that incomplete SAM regions are corrected by the heatmap and vice versa, yielding precise bounding boxes without any parameter updates.

## Results

On COCO val2017, SearchDet achieves 59.3 mAP, outperforming the strongest baseline T-Rex2 (Text) by 7.1 points (52.2) and GroundingDINO-L by 10.9 points (48.4). On LVIS-minival, SearchDet leads on the rare-class subset (mAPr = 55.9 vs. 43.8 for T-Rex2 Visual-G) and overall average (mAPavg = 33.1 vs. 27.8), though it trails T-Rex2 (Text) on frequent (40.4 vs. 50.2) and common (39.9 vs. 43.2) classes. On ODinW-35, SearchDet reaches 21.6 mAP, surpassing T-Rex2 Visual-G (20.5) and GroundingDINO-L (18.4), and on Roboflow-100 it achieves 27.9 mAP versus 18.5 for T-Rex2 Visual-G. In the 10-shot COCO setting, SearchDet attains 61.4 mAP, exceeding the prior SOTA DE-ViT (52.9) by 8.5 points.

## Baselines & Comparisons

SearchDet outperforms all five open-vocabulary baselines (GLIP-L, DINOv, GroundingDINO-L, T-Rex2 Text, T-Rex2 Visual-G) on COCO val (59.3 vs. best 52.2), ODinW-35 (21.6 vs. best 20.5), and Roboflow-100 (27.9 vs. best 18.5). On LVIS, SearchDet dominates the rare-class subset (mAPr 55.9 vs. 43.8 for T-Rex2 Visual-G) and the overall average (33.1 vs. 27.8), but trails T-Rex2 (Text) on frequent (40.4 vs. 50.2) and common (39.9 vs. 43.2) classes, which the authors attribute to T-Rex2's large-scale pre-training on abundant frequent-class data. In the 10-shot COCO comparison (Table 2), SearchDet (61.4 mAP) surpasses the previous best training-free method DE-ViT (52.9) by 8.5 points and the finetuned LVC (34.1) by 27.3 points. The paper notes that T-Rex2 (Visual-G) is the closest competitor on ODinW and Roboflow-100, where in-context visual prompting also leverages support images, yet SearchDet's attention-weighted positive/negative retrieval and frequency-based thresholding yield consistent 1–9 point gains. Overall, the results indicate SearchDet's advantage is most pronounced on long-tail and rare concepts, while its relative weakness on frequent LVIS classes is a direct consequence of using only 10 web-retrieved exemplars without any task-specific fine-tuning.

## Relation to Prior Work

SearchDet departs from the dominant paradigm in open-vocabulary object detection (GroundingDINO, GLIP, T-Rex2), which encodes object knowledge into model parameters through large-scale contrastive pre-training, by instead treating the web as an external, dynamically growing memory of object exemplars. Conceptually, it bridges few-shot object detection (where support images serve as class prototypes) and retrieval-augmented generation, but eliminates all training by relying entirely on frozen DINOv2 embeddings, SAM region proposals, and an attention-based positive/negative query construction. The heatmap generation component follows Blume et al. [3], and the frequency-based adaptive thresholding for mask selection is a novel contribution not seen in prior FSOD or OVD work.

## Why It Matters / Open Questions

The core implication is that for long-tail and rare-class detection, expensive continual pre-training or task-specific fine-tuning may be unnecessary if the concept has any web image presence, potentially eliminating annotation and training costs entirely. However, the approach's practical utility is bounded by web image availability and quality, label specificity (generic labels like 'boat' underperform versus 'aerial view of boat'), and ~3.5s inference time per query. Open questions include behavior when no web images exist for a concept, scalability to very large vocabularies, and whether the method's reliance on a specific search engine introduces systematic biases. The stability analysis—showing consistent embeddings across different retrieval days—partially addresses robustness concerns but does not fully resolve the dependency on web infrastructure.

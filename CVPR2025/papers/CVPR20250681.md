## Problem

Ad-hoc categories (e.g., 'things to sell at a garage sale') are dynamically created for specific tasks and differ fundamentally from fixed common categories, yet existing methods handle either closed-world classification (CLIP) or single-context category discovery (GCD) without supporting multiple context-dependent categorization rules. No prior approach can simultaneously discover known and novel classes while switching between diverse ad-hoc contexts (action, location, mood) on the same image set.
![Teaser figure](../imgs/CVPR20250681/cropped_page0_idx0.webp)

## Input / Output

Given a context defined by a set of known class names, 16 labeled exemplar images per known class, and a pool of unlabeled images, OAK predicts labels for both known and novel classes across all unlabeled images. The same image set is re-categorized under each context (e.g., an image is 'drinking' under Action but 'residential' under Location), and the model must be correct across all contexts simultaneously (Omni accuracy). Beyond class labels, OAK outputs interpretable saliency maps highlighting context-relevant regions (hands for Action, backgrounds for Location, faces for Mood) and assigns text names to discovered novel clusters by aligning them with CLIP's text embeddings.

## Method

OAK introduces a single learnable context token concatenated with image patch tokens in CLIP's frozen ViT-B/16 encoder, making the self-attention map context-aware so the model focuses on relevant regions (foreground for actions, background for locations). Training combines two objectives: GCD's contrastive loss (self-supervised on unlabeled + supervised on labeled images) to cluster visually similar patterns, and a text-guided regularization loss that aligns visual clusters with CLIP's frozen text embeddings via pseudo-labels from semi-supervised K-means and Hungarian matching. Only the context token is optimized per context while the entire ViT backbone and text encoder remain frozen, enabling adaptation to any ad-hoc categorization rule by simply swapping the token. This design unifies CLIP's top-down open-vocabulary classification with GCD's bottom-up data-driven clustering, allowing OAK to discover novel concepts both semantically (via contextual expansion) and visually (via image clustering).

## Results

On the Stanford dataset (Action, Location, Mood contexts), OAK achieves 87.4% novel accuracy on Mood, 88.4% on Location, and 85.1% on Action, surpassing CLIP-ZS + LLM vocab (35.4%, 34.2%, 38.6%) and GCD (40.6%, 80.8%, 67.8%) by over 50% on Mood. In the Omni context (requiring correct predictions across all contexts simultaneously), OAK reaches 70.3% overall accuracy, outperforming all baselines by 2–30%. On Clevr-4 (Texture, Color, Shape, Count), OAK achieves 100.0% novel accuracy on Color and 99.8% on Shape, and in the full-shot setting outperforms μGCD by 11% on Texture (66.5% vs. 55.5%) with an average novel accuracy of 83.3% vs. 78.0%.

## Baselines & Comparisons

OAK outperforms all four baseline groups across both datasets. Against CLIP-ZS + LLM vocab (top-down text guidance), OAK gains 52% on novel Mood accuracy (87.4% vs. 35.4%) and 27% on novel Location (88.4% vs. 34.2%), demonstrating that class-name expansion alone is insufficient for ad-hoc categories. Against GCD (bottom-up visual clustering), OAK improves novel Mood by 46.8% (87.4% vs. 40.6%) and novel Action by 17.3% (85.1% vs. 67.8%), while maintaining competitive known-class accuracy. In the Omni context, OAK achieves 70.3% overall accuracy on Stanford versus 52.3% for GCD and 43.0% for CLIP-ZS + LLM vocab, a 18–27% margin. On Clevr-4 full-shot, OAK surpasses the state-of-the-art μGCD by 11% on Texture (66.5% vs. 55.5%) and 2.4% on Count (67.6% vs. 65.2%), with near-perfect scores on Color (99.9%) and Shape (99.0%), confirming that contextualized feature learning generalizes across both natural and synthetic domains.

## Relation to Prior Work

This paper sits at the intersection of three research threads: CLIP's open-vocabulary zero-shot classification, generalized category discovery (GCD) for finding both known and novel classes, and visual prompt tuning for lightweight adaptation of frozen ViT backbones. It departs from GCD by extending single-context category discovery to a multi-context setting where the same images must be re-categorized under different ad-hoc rules (action, location, mood), and from CLIP by adding a bottom-up clustering objective that CLIP alone cannot support. The core mechanism—a single learnable context token concatenated to patch tokens, trained with GCD's contrastive loss plus a text-guided cross-entropy regularizer—is a minimal combination of existing ingredients (VPT + GCD + CLIP alignment) rather than a new architectural primitive.

## Why It Matters / Open Questions

The open ad-hoc categorization task is a concrete step toward AI agents that must dynamically switch categorization rules (e.g., a household robot shifting between action recognition, spatial navigation, and emotional reading), and the Omni accuracy metric captures this cross-context consistency in a way prior GCD benchmarks do not. The simplicity of the solution (one context token, frozen backbone) makes it easy to adopt, and the interpretable saliency maps (hands for action, faces for mood, backgrounds for location) add a transparency dimension absent from GCD. Limitations include evaluation on only two relatively small datasets, a single context token that may not scale to many simultaneous contexts, and reliance on LLM-generated candidate class names for novel clusters, which degrades in unfamiliar domains (Mood, Texture, Count). Extending to video, larger context sets, and more diverse real-world ad-hoc categories remains open.

## Problem

Existing text-based 3D editing methods (e.g., Instruct-NeRF2NeRF, Posterior Distillation) excel at modifying color, texture, and style but fail to handle edits requiring significant geometric or structural changes such as pose modifications or introducing new objects. The root cause is that fully optimized NeRF parameters reside in deep local minima of the score distillation loss landscape, preventing the generative ODE from following a natural trajectory toward the target distribution specified by the edit prompt.
![Teaser figure](../imgs/CVPR20251543/cropped_page0_idx0.webp)

## Input / Output

The method takes a source NeRF (parameterized via InstantNGP) and a free-form text edit prompt describing the desired modification (e.g., color, pattern, shape, pose, or object additions) as input, and produces a fully editable 3D NeRF as output. Unlike Posterior Distillation, it does not require a textual description of the original object. The multi-view diffusion backbone (MVDream) is used for all score distillation steps, and the output supports 360° novel-view rendering.

## Method

Perturb-and-Revise (PnR) introduces three key mechanisms. First, it performs parameter-level perturbation by linearly interpolating the source NeRF parameters with a random initialization (θ_perturbed = Lerp(θ_src, θ_0, η)), effectively reverting the optimization to a less-optimized state so the generative ODE can follow a natural coarse-to-fine trajectory under the new edit prompt. Second, it adaptively determines the perturbation amount η by simulating a few score distillation steps ahead and analyzing the local loss landscape (basin depth/volume), avoiding expensive grid search. Third, after the main editing phase, it applies an Identity-Preserving Gradient (IPG) that adds a pull toward the source parameters (via L1 + perceptual loss on rendered views) to the editing gradient, creating a tug-of-war that refines the result to resemble the source while maintaining edit fidelity. The full pipeline uses multi-view consistent score distillation with timestep annealing for quality.

## Results

On the fashion object editing benchmark (150 examples across color, pattern, shape, pose, and object edits), Perturb-and-Revise achieves the best averaged CLIP directional similarity (0.0565) and the best LPIPS on both AlexNet (0.1034) and VGG (0.1060), outperforming Instruct-NeRF2NeRF (0.0557 CLIP-Dir-Sim, 0.1112 LPIPS-Alex), Score Distillation (0.0438, 0.1533), and Posterior Distillation (0.0285, 0.0215). The method achieves a superior trade-off between edit faithfulness (CLIP-Dir-Sim) and source preservation (LPIPS), while qualitatively handling large geometric changes (pose changes, object additions) that all baselines fail to produce.

## Baselines & Comparisons

Perturb-and-Revise outperforms all four baselines on the averaged CLIP directional similarity (0.0565 vs. 0.0557 for Instruct-NeRF2NeRF, 0.0438 for SDS, and 0.0285 for PDS), confirming superior edit faithfulness. On LPIPS-AlexNet, PnR achieves the best score (0.1034) among methods that actually perform meaningful edits, beating Instruct-NeRF2NeRF (0.1112) and SDS (0.1533); PDS reports a lower LPIPS (0.0215) but at the cost of producing outputs nearly identical to the source (CLIP-Dir-Sim of only 0.0285), making it effectively non-editing. Qualitatively, PnR is the only method that successfully handles pose changes and object additions (e.g., making a standing person sit, adding windmills to a scene), while SDS produces blurry textures, Instruct-NeRF2NeRF cannot alter geometry, and PDS cannot deviate far from local minima. Against MVDream regeneration on Objaverse objects, PnR preserves the source object's identity while applying the edit, whereas full regeneration produces entirely different objects.

## Relation to Prior Work

This paper extends the score distillation framework (DreamFusion [40]) and the particle-based variational inference / generative ODE perspective (ProlificDreamer [60]) from 3D generation to 3D editing. The key conceptual departure is treating a fully-optimized NeRF as a particle trapped in a local minimum and using parameter-level interpolation with random initialization to push it back onto a natural generative trajectory, enabling geometric edits (pose changes, object additions) that prior text-based editing methods like Instruct-NeRF2NeRF [8] and Posterior Distillation [25] cannot achieve. The Identity-Preserving Gradient introduces a novel tug-of-war mechanism between edit fidelity and source preservation, and the adaptive perturbation amount (η) is determined via a lightweight loss-landscape probe rather than grid search.

## Why It Matters / Open Questions

The ability to perform geometric edits (pose changes, introducing new objects) via text prompts on NeRFs opens up a class of 3D customization tasks that were previously intractable with score-distillation-based methods, with direct implications for animation, gaming, and design pipelines. The parameter perturbation idea is simple and composable, potentially transferable to other 3D representations (e.g., 3D Gaussian Splatting) and other editing modalities. Open questions include scalability to complex multi-object scenes, the quality ceiling imposed by 2D diffusion backbones, and whether the loss-landscape heuristic for η generalizes reliably across diverse object categories and edit magnitudes.

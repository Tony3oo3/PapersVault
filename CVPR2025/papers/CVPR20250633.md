## Problem

Whether vision and language foundation models can be aligned in a fully unsupervised manner—without any parallel image-text pairs—remains untested. Prior work on cross-modal alignment (zero-shot stitching, Gromov-Wasserstein alignment) always assumes at least a sparse set of ground-truth correspondences or joint training. This paper investigates the extreme case of 'blind' matching, motivated by the platonic representation hypothesis that large-scale models converge to geometrically similar latent spaces.

## Input / Output

The method consumes two unpaired sets: a collection of images and a collection of text descriptions, with no image-text pairing required. For each semantic class, it computes L2-normalized average embeddings from a pre-trained vision encoder and a language encoder, then builds pairwise similarity matrices (kernels) within each modality. The output is a permutation matrix assigning each vision embedding to a language embedding; as a downstream application, this permutation provides class labels to K-Means clusters of image embeddings, yielding an unsupervised classifier.

## Method

The paper formulates blind vision-language matching as a Quadratic Assignment Problem (QAP) that depends only on pairwise distances within each modality, using the Gromov-Wasserstein distance as the distortion measure. The key technical contribution is a factorized Hahn-Grant solver that exploits the decomposable structure of common distortion measures (reducing the problem to a Koopmans-Beckmann QAP with two N×N cost matrices), cutting memory from O(N⁴) to O(N³), adding primal solution search via FAQ/2-opt initialization and LAP-byproduct evaluation, and replacing the Hungarian algorithm with the faster Jonker-Volgenant solver. Additionally, the paper formulates the selection of well-aligned class subsets as a p-dispersion-sum problem, solved approximately with Gurobi, enabling non-trivial matches at larger problem sizes (N > 10) where arbitrary category choices fail.

## Results

On small-scale matching (N=10, CINIC-10 with CLIP + all-mpnet-base-v2), the factorized Hahn-Grant solver achieves 60% matching accuracy and reaches the global optimum 100% of the time, matching Gurobi exactly. On larger-scale problems (CIFAR-100), the solver provably achieves global optimality up to N=40 and provides the tightest lower bounds across all sizes, surpassing Gurobi on N=30. For the unsupervised classification application on CIFAR-10, DINOv2 combined with All-Roberta-large-v1 achieves 51.5% accuracy—well above the 10% random baseline—without any image-text annotation.

## Baselines & Comparisons

The factorized Hahn-Grant solver ties Gurobi on small-scale problems (both reach 60% accuracy and 100% global optimum rate) but decisively wins on larger-scale problems: Gurobi exceeds its 1.5-hour time limit beyond N=60, while the proposed solver maintains tight bounds and achieves global optimality up to N=40, even surpassing Gurobi's primal solution at N=30. MPOpt [18] approaches the optimal objective (cost 0.36 vs. 0.34) but only reaches the global optimum ~50% of the time, yielding 49% accuracy. The three local/relaxation-based methods—LocalCKA [30], entropic OT [38], and FAQ [49]—all fail to produce meaningful matches: LocalCKA performs at random level (10%), while OT (2%) and FAQ (1%) are actually worse than random, confirming that local optima are insufficient for vision-language matching. The key finding is that only methods capable of reaching (or provably approaching) the global QAP optimum yield non-trivial correspondences.

## Relation to Prior Work

This paper extends the Hahn-Grant dual-ascent solver for quadratic assignment problems [13] with a factorized cost structure, primal heuristics, and a faster Jonker-Volgenant LAP solver, reducing memory from O(N⁴) to O(N³). Conceptually, it takes the zero-shot stitching literature [34, 35, 20, 29]—which recovers dense vision-language alignment from a sparse set of correspondences—to the extreme of zero correspondences, motivated by the platonic representation hypothesis [17]. It also departs from prior Gromov-Wasserstein alignment work [1, 4] by performing alignment between vision and language (rather than cross-lingual or cross-domain text) without any parameter training, and from Maniparambil et al. [30] by addressing the fully unsupervised setting they explicitly leave open.

## Why It Matters / Open Questions

The paper establishes, for the first time, that pairwise geometric structure in independently trained vision and language encoders is sufficient to recover semantic correspondences without any paired data, opening a path toward annotation-free semantic grounding. However, the practical scope is currently narrow: reliable matching requires selecting well-aligned class subsets (via a p-dispersion-sum optimization), problem sizes are limited to N ≈ 40–60 before the O(N⁵) solver becomes intractable, and abstract or modality-specific concepts remain unmatchable. Key open questions include whether scaling models and datasets will close the gap for arbitrary class sets, how to handle the symmetry/ambiguity of multiple equivalent local minima, and whether the approach can be made to scale to full ImageNet-scale classification.

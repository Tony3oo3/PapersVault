## Problem

Existing sketch generation methods either depend on human-drawn datasets (limiting diversity to predefined categories) or optimize all strokes simultaneously via differentiable rendering, producing final images whose intermediate steps carry no semantic meaning. This makes them unsuitable for the inherently sequential, stroke-by-stroke process of human sketching and for interactive collaboration or iterative editing. The paper asks whether an off-the-shelf multimodal LLM can be prompted to draw sketches sequentially, with each stroke carrying intent, without any additional training.

## Input / Output

The agent receives a natural-language prompt (e.g., "draw a shark") alongside a numbered 50×50 grid canvas that serves as its spatial coordinate system; for editing or collaboration, the previously rendered canvas image is fed back as visual context. The model outputs a structured text string specifying an ordered sequence of strokes, where each stroke is a list of grid-cell coordinates (e.g., x1y1, x15y20) paired with parameter t-values indicating where along the curve each point should be passed through. These coordinates are post-processed by fitting cubic Bézier curves via least squares and rendered as vector graphics onto the canvas, yielding a stroke-annotated sketch rather than a pixel image.

## Method

SketchAgent introduces a lightweight sketching language—string-based coordinate actions on a numbered grid—that is injected into a frozen multimodal LLM (default: Claude3.5-Sonnet) purely through in-context learning examples and a system prompt, requiring no fine-tuning. Chain-of-Thought prompting (via <thinking> tags) elicits a planning step where the agent describes components, ordering, and placement before emitting strokes. Each stroke's coordinate sequence is treated as sampled points along a curve (not Bézier control points), and a cubic Bézier is fitted by solving a least-squares system over the Bézier basis evaluated at the model-specified t-values; long strokes with high fitting error are recursively split. For collaborative sketching, an adjustable stopping token (</s{j}>) pauses generation at stroke j, allowing a human to add strokes that are reverse-converted into the agent's coordinate format and chained before the agent resumes. For chat-based editing, the rendered canvas is simply re-supplied as an image input with an updated text instruction, leveraging the model's multimodal reading of the existing drawing.

## Results

On the QuickDraw evaluation (500 sketches across 50 categories, scored with a CLIP zero-shot classifier), SketchAgent using Claude3.5-Sonnet achieves Top-1 accuracy of 0.23±0.05 and Top-5 accuracy of 0.44±0.03, approaching human-drawn QuickDraw sketches (0.27±0.07 Top-1, 0.49±0.06 Top-5). In a 2AFC user study with 150 participants, SketchAgent's sketches were judged more human-like than direct SVG prompting (74.90% chosen as human-drawn), while humans were slightly preferred over SketchAgent (54.68%). For chat-based editing, the agent correctly follows spatial and semantic instructions 92% of the time (94% for specified relations, 88% for inferred relations).

## Baselines & Comparisons

Against human-drawn QuickDraw sketches, SketchAgent (Claude3.5-Sonnet) achieves 0.23 Top-1 vs. 0.27 for humans and 0.44 Top-5 vs. 0.49, a gap of roughly 4–5 points, making it the closest model-based approach to human performance. Compared to SVGDreamer, which requires 2000 optimization iterations (~1.6 hours) and produces intermediate strokes lacking semantic meaning, SketchAgent generates sketches in real time with each stroke carrying a clear semantic label. Against SketchRNN, which is restricted to the 345 predefined QuickDraw categories, SketchAgent leverages the backbone LLM's broad prior knowledge to sketch arbitrary concepts (e.g., scientific diagrams, landmarks, engineering principles) without category constraints. In the collaborative sketching study, collaboratively produced sketches (user + agent) achieve CLIP recognition rates close to user-only sketches and significantly higher than agent-only sketches, confirming that both parties contribute meaningfully to the final output.

## Relation to Prior Work

SketchAgent departs from both data-driven sequential sketch generators (SketchRNN, DoodleFormer) that require training on human-drawn datasets, and optimization-based vector sketch methods (SVGDreamer, Clipasso) that simultaneously refine all strokes via differentiable rendering, losing the temporal ordering of the drawing process. Rather than training a new model, it repurposes an off-the-shelf multimodal LLM by introducing a novel grid-based sketching language through in-context learning and chain-of-thought prompting, then post-processes the LLM's coordinate output into smooth Bézier curves. This positions the work at the intersection of LLM tool-use (analogous to code-generation agents producing SVG or Python) and sequential sketch synthesis, but replaces rigid code output with a spatially grounded, stroke-by-stroke representation that better emulates freehand drawing.

## Why It Matters / Open Questions

The paper demonstrates that no training or fine-tuning is needed to turn a general-purpose multimodal LLM into a sequential sketching agent that can collaborate with humans in real time, opening a path toward general-purpose, interactive sketching tools unbounded by predefined categories. Key limitations remain: the agent inherits the backbone model's weak visual priors, producing overly abstract sketches of complex concepts and human figures, and struggles with letters and numbers. Open questions include whether the grid-resolution and stopping-token design choices generalize across domains, whether the approach scales as multimodal LLMs improve in spatial reasoning, and whether the collaborative loop can support richer multi-turn creative workflows beyond single-concept sketches.

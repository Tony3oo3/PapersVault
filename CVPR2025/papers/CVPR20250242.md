## Problem

Existing zero-shot goal-oriented navigation methods are designed for a single goal type (object category, instance image, or text description) with task-specific LLM pipelines, making them unable to generalize across goal types. Universal methods that handle multiple goal types (e.g., GOAT, PSL) require RL training on large-scale simulation data and suffer from weak real-world generalization. The paper asks whether a single training-free framework can handle all three goal types with a unified representation and reasoning pipeline.

## Input / Output

The agent receives a posed RGB-D video stream and a goal specified in one of three free-form formats: an object category string, a reference image of a specific instance, or a natural-language description. The method produces a sequence of discrete actions (move_forward, turn_left, turn_right, stop) and internally maintains an incrementally updated 3D scene graph with world-coordinate node positions. A key design constraint is that the same pipeline processes all three goal formats without any architectural modification; the goal is simply converted into a graph whose nodes and edges carry text descriptions and spatial relationships.

## Method

UniGoal represents both the 3D scene and the goal as attributed graphs (nodes = objects, edges = spatial/semantic relations) and performs explicit graph matching at each timestep using CLIP-embedding-based bipartite matching on nodes and edges plus a graph-editing-distance topology score. The matching score drives a three-stage exploration policy: (1) zero-matching triggers LLM-guided decomposition of the goal graph into correlated subgraphs, each converted to a text query for frontier-based exploration; (2) partial-matching uses a DFS-based coordinate projection (prompting LLM to infer 2D BEV coordinates from spatial relationship edges) followed by anchor-pair alignment via a 2D similarity transform (scale, rotation, translation) to predict the goal location; (3) perfect-matching applies a graph-convolution-like correction loop where LLM aggregates neighbor node/edge descriptions and VLM observations to refine the local scene graph, combined with a multi-factor confidence score for goal verification. A blacklist mechanism records failed matchings to prevent the agent from repeatedly exploring the same incorrect regions.

## Results

UniGoal achieves state-of-the-art zero-shot performance across all three goal-oriented navigation tasks with a single model. On Object-goal Navigation (ON), it reaches 41.0/16.4 SR/SPL on MP3D, 54.5/25.1 on HM3D, and 48.0/24.2 on RoboTHOR. On Instance-image-goal Navigation (IIN) on HM3D, it achieves 60.2/23.7 SR/SPL, surpassing the best zero-shot baseline Mod-IIN by 4.1% SR. On Text-goal Navigation (TN) on HM3D, it reaches 20.2/11.4 SR/SPL, outperforming the best supervised universal methods PSL (16.5/7.5) and GOAT (17.0/8.8) without any training.

## Baselines & Comparisons

Among zero-shot ON methods, UniGoal outperforms SG-Nav (the strongest zero-shot ON baseline) by 0.8% SR on MP3D (41.0 vs 40.2), 0.5% on HM3D (54.5 vs 54.0), and 0.5% on RoboTHOR (48.0 vs 47.5), and also surpasses ESC, OpenFMNav, and VLFM on all three benchmarks. For zero-shot IIN, UniGoal beats Mod-IIN by 4.1% SR and 0.4% SPL on HM3D (60.2/23.7 vs 56.1/23.3). Among universal methods, UniGoal outperforms the supervised PSL by +12.1 SR on IIN (60.2 vs 23.0) and +3.7 SR on TN (20.2 vs 16.5), and outperforms GOAT by +22.8 SR on IIN (60.2 vs 37.4) and +3.2 SR on TN (20.2 vs 17.0), all without any training. Notably, UniGoal also exceeds some supervised ON methods like SemEXP (36.0 SR on MP3D) and ZSON (25.5 SR on HM3D) while remaining entirely training-free. The paper notes that for ON the goal graph degenerates to a single node, so several UniGoal modules (graph decomposition, anchor pair alignment) are inactive, yet it still wins, validating the scene graph correction and goal verification in Stage 3.

## Relation to Prior Work

UniGoal builds directly on SG-Nav's online 3D scene graph construction and frontier-based exploration, extending them from a single task (object-goal navigation) to a universal framework. It departs from prior zero-shot methods (ESC, OpenFMNav, VLFM, SG-Nav) that are each specialized to one goal type, and from universal methods (GOAT, PSL) that require RL training on large-scale data. The key conceptual departure is representing both the scene and the goal as graphs, enabling explicit graph matching as a unifying mechanism that guides a multi-stage exploration policy — a formulation absent from both the task-specific zero-shot and the training-based universal lines of work.

## Why It Matters / Open Questions

This is the first framework to handle object-goal, instance-image-goal, and text-goal navigation in a single zero-shot model, outperforming both task-specific zero-shot baselines and supervised universal methods (PSL, GOAT) without any training. The graph-matching-driven multi-stage policy provides a principled, interpretable mechanism for progressive scene exploration that could be extended to additional goal types or real-world deployment. Limitations include reliance on LLM quality for coordinate projection and graph correction, evaluation limited to simulation (Habitat), and the fact that gains on ON are modest since the goal graph degenerates to a single node, leaving the full potential of the graph-matching approach underutilized for simple goals.

## Problem

Existing network quantization methods are complex, sensitive to hyperparameter choices, and lack generality across architectures and tasks, creating a speed-accuracy dilemma where fast PTQ methods sacrifice accuracy while accurate QAT methods require hundreds of training epochs. The paper challenges the assumption that a quantized network must retain the exact same structure as the original, proposing instead that lightweight additional modules can compensate for quantization-induced information loss.
![Teaser figure](../imgs/CVPR20250757/cropped_page3_idx0.webp)

## Input / Output

QwT takes a pre-trained full-precision model of any architecture (CNN, ViT, Swin, diffusion Transformer, LLM) and a small calibration set of 512 samples, then produces a quantized model augmented with per-block linear compensation modules. The resulting model accepts the same inputs as the original (RGB images, image-text pairs, text prompts) and produces the same outputs (class labels, bounding boxes with masks, generated images, text), with the compensation modules adding only ~3% overhead in size and latency over the baseline quantized model.

## Method

The key insight is to add a lightweight linear compensation module c(x) = Wx + b in parallel to each quantized block, so the block output becomes y^QwT = l^Z(x^Z) + c(x^Z). The parameters W and b are solved in closed form via linear regression (Eq. 6) that minimizes the output difference between the full-precision and quantized block, using only 512 calibration samples. Because compensation is applied sequentially block-by-block, each module implicitly accounts for accumulated information loss from all preceding blocks, making the overall correction non-linear despite each individual module being linear. The method is a black-box plugin: any existing PTQ method can quantize the model first, and QwT then adds and initializes the compensation modules in under 2 minutes with zero hyperparameters to tune. If R² of the linear fit is negative for a given block, the module is zeroed out to avoid degradation.

## Results

On ImageNet, QwT applied to RepQ-ViT on ViT-B at 4/4 bits improves top-1 accuracy from 68.5% to 76.3% (+7.8 pp), and with one epoch of finetuning (QwT*) reaches 78.5%, surpassing the prior SOTA IGQ-ViT (79.3%) by a narrow margin. Across all backbones and bit-widths in Table 1, QwT yields an average top-1 gain of ~2.6 pp, peaking at ~5 pp for 4-bit quantization. On COCO detection/segmentation, QwT adds an average 0.4 AP (box) with negligible size overhead. On LLaMA3-8B (GPTQ 4-bit), QwT improves zero-shot QA average from 64.90 to 65.18 while reducing WikiText2 perplexity from 6.65 to 6.63.

## Baselines & Comparisons

Against RepQ-ViT [27], QwT delivers the largest gains: +7.8 pp on ViT-B 4/4 (68.5→76.3), +3.2 pp on DeiT-T 4/4 (58.2→61.4), and +2.5 pp on Swin-T 4/4 (73.0→75.5). Against the prior SOTA IGQ-ViT [37], QwT* matches or exceeds it in most settings (e.g., Swin-T 4/4: 79.3 vs 77.8; DeiT-T 4/4: 64.8 vs 62.5) but falls slightly short on ViT-B 4/4 (78.5 vs 79.3). Against Percentile [23] on ResNet-50, QwT recovers 6.1 pp at 4/4 (68.4→74.5), nearly closing the gap to full-precision (76.6). Against PTQ4ViT [52] on ViT-B, QwT produces a dramatic +39.3 pp at 4/4 (30.7→70.0) and +1.5 pp at 6/6 (81.7→83.2). For LLMs, GPTQ+QwT [14] marginally improves over GPTQ alone (QA avg 64.90→65.18, WikiText2 PPL 6.65→6.63). For diffusion models, Q-DiT+QwT [5] reduces FID from 6.75 to 6.06 at W4A8 and from 5.45 to 5.35 at W8A8 on DiT-XL/2. Against the QAT method Q-ViT [25], QwT* adds a small but consistent boost (DeiT-S 2/2: 72.1→72.5; 3/3: 79.0→79.1) without retraining the backbone.

## Relation to Prior Work

QwT departs from the standard quantization paradigm that requires the quantized network to preserve the exact structure of the original (S^Z = S), instead proposing that the quantized structure can be S ∪ S_c with lightweight linear compensation modules. Rather than building on a specific prior quantization method, it positions itself as a black-box plugin compatible with any existing PTQ approach (RepQ-ViT, PTQ4ViT, Percentile, GPTQ, Q-DiT), accepting their quantization decisions and then correcting the residual output error in closed form. Conceptually, it repurposes the idea of auxiliary linear modules (analogous to residual connections) for a new purpose: compensating cumulative quantization information loss block-by-block, with the key insight that a sequence of simple linear corrections across many blocks can approximate the highly non-linear quantization error.

## Why It Matters / Open Questions

The practical impact is substantial: a zero-hyperparameter, 2-minute calibration step that can be appended to any existing quantization pipeline and consistently improves accuracy across CNNs, ViTs, diffusion models, and LLMs, narrowing the PTQ-to-QAT gap without requiring the hundreds of epochs QAT demands. Limitations include the added model size overhead (~4–10%), the failure of the closed-form initialization on already-converged QAT models (requiring zero-init + fine-tuning instead), and the heuristic R² threshold for deciding whether to activate a compensation module. Open questions include whether the approach extends to extreme low-bit (1–2 bit) PTQ settings, whether the linear compensation can be further compressed or merged into the quantized weights, and whether the per-block independence assumption holds for architectures with very different block semantics.

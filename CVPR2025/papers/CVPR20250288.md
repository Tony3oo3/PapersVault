## Problem

No dedicated method existed for functionality understanding in 3D scenes: interpreting natural language task descriptions to locate and segment fine-grained interactive objects (handles, knobs, buttons) in real-world 3D environments. This task is uniquely challenging because it simultaneously requires world knowledge (e.g., inferring that 'turn on the ceiling light' means finding the switch) and spatial perception to identify small objects, while existing open-vocabulary 3D segmentation methods segment large furniture rather than small functional parts and lack the reasoning to interpret implicit task descriptions.
![Teaser figure](../imgs/CVPR20250288/cropped_page0_idx0.webp)

## Input / Output

The method takes a scene point cloud (up to 13 million points), approximately 1800 posed RGBD images with intrinsic/extrinsic camera parameters, and a natural language task description that typically does not explicitly name the object to segment (e.g., 'open the bottom drawer of the cabinet with the TV on top' requires segmenting the handle, not the drawer). The output is a binary 3D segmentation mask on the point cloud, produced by thresholding a multi-view agreement heatmap at τ=0.7, where each point's score reflects the number of 2D mask pixels projecting onto it across selected views.

## Method

Fun3DU is a training-free, four-module pipeline. First, a frozen LLM (Llama 3.1-9B) uses Chain-of-Thought reasoning with a system prompt defining a robotic manipulator's action vocabulary to decompose the task description into a functional object F (e.g., 'handle') and a contextual object O (e.g., 'cabinet'). Second, OWLv2 + RobustSAM segments O in all views, and a novel visibility-based view selection scores each mask using KL divergence between its pixel distance/angle distributions and reference uniform distributions, combined with detection confidence, to select the top 50 views. Third, Molmo (a point-grounding VLM) is queried with the full task description to point to F in each selected view, and SAM converts these points into 2D masks. Fourth, 2D masks are lifted to 3D via point-to-pixel correspondences, accumulated into a per-point heatmap across all views, and thresholded to yield the final 3D functional object mask.

## Results

On SceneFun3D split0, Fun3DU achieves mAP 7.6, AP25 33.3, and mIoU 15.2, substantially outperforming all baselines. On the more challenging split1 (scenes with up to 13M points), Fun3DU still leads with mAP 6.1, AP25 23.1, and mIoU 11.5. Fun3DU is the only method to achieve AP25 above 0.4 and mIoU above 0.2 on both splits, surpassing the nearest competitor (OpenMask3D) by 32.9 and 23.1 points in AP25, and by 15 and 11.4 points in mIoU on split0 and split1 respectively.

## Baselines & Comparisons

Fun3DU decisively outperforms all three open-vocabulary 3D segmentation baselines on precision-oriented metrics. Against OpenMask3D, Fun3DU gains +32.9 AP25 (33.3 vs 0.4) and +15.0 mIoU (15.2 vs 0.2) on split0; on split1 the gap widens as OpenMask3D's 3D encoder degrades on larger point clouds (AP25 drops to 0.0). Against OpenIns3D, Fun3DU achieves +33.3 AP25 and +15.1 mIoU on split0, though OpenIns3D retains a slight edge in AR25 (51.5 vs 46.7), reflecting its tendency to over-segment contextual objects (e.g., entire cabinets) rather than the small functional parts. Against LERF, Fun3DU leads by +33.3 AP25 and +15.2 mIoU on split0, with LERF's per-scene NeRF training providing no advantage for fine-grained functional object localization. The consistent pattern across all baselines is high recall but near-zero precision: they segment large household furniture mentioned in the task description rather than the small interactive elements (handles, knobs, buttons) that the task actually requires.

## Relation to Prior Work

Fun3DU departs from the open-vocabulary 3D segmentation (OV3DS) paradigm, which relies on 3D proposal modules trained on large-object datasets (e.g., ScanNet, Matterport3D) and thus exhibits a strong bias toward segmenting whole furniture rather than fine-grained functional parts. Instead, it repurposes 2D VLMs (Molmo for point grounding, SAM for promptable segmentation) and an LLM (Llama 3.1 with Chain-of-Thought) to interpret task descriptions and localize functional objects in image space before lifting to 3D via multi-view aggregation. The view-selection mechanism, which ranks views using KL divergence on polar-coordinate distributions of contextual object masks, is a novel contribution not present in prior OV3DS pipelines. The method is entirely training-free, contrasting with OV3DS approaches that require task-specific fine-tuning or per-scene NeRF training (e.g., LERF).

## Why It Matters / Open Questions

This is the first method to address functionality segmentation in 3D scenes, a task critical for embodied AI agents that must interact with physical environments (e.g., turning on a light by finding the switch). The clear failure mode of OV3DS baselines—segmenting the contextual object (cabinet) rather than the functional part (handle)—highlights a fundamental gap in current 3D segmentation: the absence of compositional reasoning about object structure. However, absolute performance remains modest (mIoU ~15 on split0), and the method still fails on visually ambiguous scenes or when the functional object's texture blends with its surroundings. Open questions include whether incorporating additional contextual objects as priors (as the authors propose) can resolve remaining ambiguations, and whether the approach generalizes to multi-room or outdoor environments.

## Problem

State-of-the-art scene graph generation models produce noisy predictions due to long-tailed class distributions, linguistic ambiguity, and multiple viewpoint interpretations, yet existing uncertainty quantification methods are architecture-specific and lack formal statistical coverage guarantees. This paper addresses the need for a model-agnostic, post-hoc UQ framework that provides provable class-conditional coverage for SGG while also ensuring the resulting prediction sets remain practically interpretable.
![Teaser figure](../imgs/CVPR20252282/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and any pre-trained SGG model (e.g., MOTIFS, VCTREE, BGNN, SQUAT) as input, requiring only access to the object and predicate classifier heads' softmax outputs. It produces class-conditional prediction sets for objects, predicates, and combinatorially combined triplets, which are then truncated by an MLLM into a smaller set of visually and semantically plausible scene descriptions. Evaluation outputs include coverage validity, class-wise coverage gap, average set size, triplet coverage, and modified recall metrics (cR@K, cmR@K) that check ground-truth membership in prediction sets rather than exact class matching.

## Method

PC-SGG applies class-conditional conformal prediction to the object and predicate classifier heads of any SGG model, using 1 − softmax probability as the non-conformity measure and greedy IoU-based matching (threshold 0.5) during calibration to compute per-class conformal quantiles. At inference, prediction sets are formed by including all classes whose softmax probability exceeds the class-specific threshold, and object and predicate sets are combinatorially aggregated into triplet prediction sets with a proven coverage guarantee equal to the product of individual coverages (Theorem 1). To address the bloat of combinatorially large triplet sets, an MLLM-based post-processing unit (BLIP-2 + FLAN-T5-XL) converts each group of 5 triplet entries into a multiple-choice question paired with the cropped union bounding box region, using a one-shot in-context learning prompt with a system instruction. The MLLM's token likelihoods over the 6 answer choices (5 descriptions + 'no valid option') are thresholded at τ = 0.1 to retain only plausible entries, achieving >50% set size reduction while preserving empirical coverage.

## Results

On VG150, adding PC-SGG to each SGG method yields substantial recall improvements: the average cR@50 gain over standard R@50 is 15.70 percentage points, and the average cmR@50 gain over mR@50 is 21.57 percentage points. The best conformal SGG configuration is BGNN+PC-SGG, achieving cR@50 of 46.32 and cmR@50 of 32.52, compared to BGNN's standalone R@50 of 30.07 and mR@50 of 9.63. MLLM-based post-processing reduces average triplet prediction set size by over 50% (e.g., BGNN: 971.69 → 464.11) while preserving empirical triplet coverage (Cov_T remains at 80.45%).

## Baselines & Comparisons

PC-SGG is a post-hoc method, so the comparison is each SGG baseline against itself augmented with PC-SGG rather than a head-to-head between competing architectures. All five baselines (MOTIFS, MOTIFS-D, VCTREE, SQUAT, BGNN) show consistent and large improvements when PC-SGG is added: cR@50 gains range from +14.84 (MOTIFS) to +16.25 (BGNN) points over their respective R@50 values. The class-conditional metric cmR@50 shows even larger gains (e.g., MOTIFS: 4.52 → 25.49, a +20.97 point jump), confirming that the class-conditional conformal framework particularly benefits tail classes. Among the five SGG backbones, BGNN+PC-SGG achieves the highest absolute conformal recall (cR@50 = 46.32, cmR@50 = 32.52), while SQUAT+PC-SGG is competitive (cR@50 = 43.23) and has the smallest average predicate prediction set size (14.48). The MLLM post-processing step (Table 2) reduces triplet set sizes by 50–53% across all methods with negligible coverage loss (≤0.26 points), validating that the plausibility filter does not compromise the statistical guarantees.

## Relation to Prior Work

This paper extends class-conditional conformal prediction (Romano et al., NeurIPS 2020) from standard classification to the structured prediction setting of scene graph generation, where prediction sets must be constructed jointly over object and predicate classifiers and then combinatorially combined into triplet sets. It departs from prior UQ work in SGG (e.g., probabilistic modeling in [54], attentional graph convolutions in [55]) by being entirely post-hoc and model-agnostic rather than requiring architectural modifications. The MLLM-based plausibility filtering is a novel addition that repurposes the implicit world-knowledge priors of vision-language models (BLIP-2) as a set-compression mechanism, a use case not previously explored in the conformal prediction literature.

## Why It Matters / Open Questions

The framework provides a drop-in uncertainty quantification tool for any existing SGG model with formal statistical guarantees, which is critical for safety-critical downstream applications like robot planning and autonomous driving. A notable limitation is that none of the evaluated SGG models actually achieve the nominal 90% triplet coverage guarantee, pointing to unresolved distribution-shift challenges in SGG datasets that make exchangeability assumptions difficult to satisfy. Open questions include whether the approach generalizes to video SGG (acknowledged as future work), whether different MLLMs or prompting strategies yield materially different plausibility filtering, and how to handle the persistent coverage gap without inflating set sizes further.

## Problem

Transformer-based video action recognition models suffer from 'attention noise,' where attention disperses across irrelevant background elements rather than concentrating on action-relevant details. While global spatiotemporal features are well-captured, the representation of local, action-specific regions remains under-explored, and existing methods lack a mechanism to selectively focus on these details without requiring region-specific annotations that are unavailable in standard action recognition datasets.
![Teaser figure](../imgs/CVPR20251037/cropped_page0_idx0.webp)

## Input / Output

The method takes T sampled video frames (8, 16, or 32 frames at H×W×3) processed by a frozen CLIP ViT-B/16 or ViT-L/14 backbone, augmented with K=8 randomly initialized learnable action queries per frame (T×K×C). The output is a single action class label produced by a linear head on the element-wise sum of mean-pooled global video features and mean-pooled local query features. Notably, the queries require no region-specific labels; they are supervised via a contrastive reconstruction loss against offline pre-trained video features from the same batch.

## Method

FocusVideo introduces a dual-branch architecture: a global video branch (ST-Adapter-based spatiotemporal modeling) and a local action query streaming branch. The key mechanism is a parameter-free feature interaction operation that concatenates action queries with video features as the Q input to the existing multi-head self-attention in each video Transformer layer, thereby simultaneously performing self-attention on video tokens and cross-attention from queries to video tokens with zero additional parameters. The local branch uses a single set of shared Query Propagation (QP) layers applied autoregressively across all L layers, where each QP layer performs cross-attention between the current query state and the interacted query output, followed by an FFN. After the final QP layer, a local spatiotemporal self-attention block models dependencies across all T×K query tokens. Training combines standard classification cross-entropy with a frame-level contrastive reconstruction loss that aligns query features to offline pre-trained video features, guiding queries to capture action-relevant regions without explicit region labels.

## Results

On Kinetics-400, FocusVideo-B/16 achieves 84.1% top-1 accuracy with 8 frames (2.1% over the ST-Adapter baseline of 82.0%) and 84.7% with 32 frames. Scaling to ViT-L/14, FocusVideo reaches 88.0% top-1 on K400 (32 frames), surpassing DUALPATH (87.7%) and M2-CLIP (87.0%). On Something-Something-V2, FocusVideo-L/14 attains 72.9% top-1 (32 frames), outperforming M2-CLIP (72.1%) and DUALPATH (71.4%), while FocusVideo-B/16 with only 8 frames (68.4%) already exceeds the ST-Adapter baseline (67.1%) by 1.3%.

## Baselines & Comparisons

On K400 with ViT-B/16 and 8 frames, FocusVideo (84.1%) outperforms ST-Adapter (82.0%) by 2.1%, MViTv2 (82.9%), ActionCLIP (83.8%), and X-CLIP (83.8%), while matching M2-CLIP's 32-frame result (84.1%) with only 8 frames and fewer parameters (15M vs. 16M). At the ViT-L/14 scale, FocusVideo (88.0%, 32 frames) surpasses DUALPATH (87.7%), MoTE (87.2%), and M2-CLIP (87.0%), establishing a new SOTA on K400. On SSv2, FocusVideo-B/16 with 8 frames (68.4%) beats ST-Adapter (67.1%) by 1.3% and OST (60.3%) by 8.1%; with 32 frames it reaches 70.5%, edging out DUALPATH (70.3%) and M2-CLIP (69.3%). At the ViT-L/14 level on SSv2, FocusVideo (72.9%) leads M2-CLIP (72.1%) by 0.8% and DUALPATH (71.4%) by 1.5%. Overall, FocusVideo consistently wins or ties across both datasets and both backbone scales, with the largest margins on detail-sensitive SSv2 categories and in low-frame settings where its local query mechanism provides the greatest advantage.

## Relation to Prior Work

FocusVideo builds directly on ST-Adapter's parameter-efficient CLIP adaptation for video, extending it with a local action query streaming branch inspired by learnable query mechanisms from object detection (DETR) and slot attention. It departs from the broader PEFT-for-video line (EVL, M2-CLIP, MoTE, DUALPATH) by explicitly addressing the 'attention noise' problem: rather than treating the video as a holistic spatiotemporal signal, it introduces dedicated queries that selectively attend to action-relevant regions. The design is further grounded in the Global vs. Local Processing theory from visual cognition, positioning the method as a principled complement to purely global video Transformers rather than a replacement.

## Why It Matters / Open Questions

The parameter-free feature interaction (reusing the video branch's existing attention weights for cross-attention with queries) is a practical and elegant trick that any PEFT-based video pipeline could adopt with minimal overhead. The finding that shared autoregressive QP layers outperform layer-specific ones (7.9M vs. 46.9M parameters) suggests that iterative refinement with fewer parameters is more effective than per-layer specialization, a useful design principle for auxiliary branches. Limitations include evaluation only on K400 and SSv2 with frozen CLIP backbones, and the reliance on offline reconstruction features for query supervision, which introduces a dependency on a separately trained model. Open questions include whether the approach transfers to video detection or segmentation tasks, and whether the fixed 8-query setting generalizes across action complexity levels.

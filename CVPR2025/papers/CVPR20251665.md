## Problem

Certifiable defenses against adversarial patches have been developed for single-label classification and object detection, but multi-label classification—a task critical to autonomous driving, video surveillance, and retail systems—remains largely unprotected. The core difficulty is that multi-label prediction involves c simultaneous binary decisions, so a single patch can induce different failure modes (false positives vs. false negatives) across different classes, making it non-trivial to extend per-class certifiable guarantees into meaningful dataset-level robustness metrics.

## Input / Output

The method takes RGB images (448×448 for ResNet, 384×384 for ViT) and produces a binary prediction vector of length c (one bit per class) at inference time. The certification procedure additionally takes the ground-truth label and the set of allowable patch regions R, and outputs a certified lower bound on true positives (TP_lower) and upper bounds on false positives (FP_upper) and false negatives (FN_upper), from which certified precision and certified recall are derived. Security parameters include the mask grid size (k₁×k₂, default 6×6) and the assumed patch area fraction (default ~2% of image).

## Method

PatchDEMUX's core insight is that any multi-label classifier F: X→{0,1}^c can be decomposed into c isolated binary classifiers F[i], each of which can be individually protected by an existing single-label certifiable defense (CDPA). The inference procedure applies the single-label CDPA's SL-INFER to each F[i] and aggregates the c binary outputs; the certification procedure applies SL-CERT per class and accumulates results to compute TP_lower, FP_upper, and FN_upper, yielding certified precision and recall as provable lower bounds. A novel location-aware certification (Algorithm 3) tightens these bounds under the single-patch threat model by extracting per-class vulnerability status arrays λ over all patch locations, summing the inverted arrays for uncertified classes, and using the maximum overlap to determine the worst-case patch placement—exploiting the constraint that one patch can only occupy one location. The framework is instantiated with PatchCleanser (double-masking with a generated certification mask set) as the backbone, and models are fine-tuned with Random Cutout or Greedy Cutout to strengthen robustness.

## Results

On MS-COCO 2014 validation (ViT backbone, 6×6 masks, ~2% patch size), PatchDEMUX achieves 85.276% clean AP (vs. 91.146% undefended) and 44.902% certified robust AP using location-aware certification (vs. 41.763% with baseline certification). At 50% certified recall, the method attains 56.038% certified precision. On PASCAL VOC 2007 test, PatchDEMUX reaches 92.593% clean AP and 56.030% certified robust AP (vs. 96.140% undefended clean).

## Baselines & Comparisons

The paper does not compare against other multi-label certifiable defenses against patch attacks, as none exist in the literature. The primary comparison is between the undefended model and the PatchDEMUX-defended model: the defense retains ~94% of the undefended clean AP (85.276% vs. 91.146% on MS-COCO; 92.593% vs. 96.140% on PASCAL VOC), indicating minimal utility loss. The second key comparison is between the baseline certification (Algorithm 2) and the proposed location-aware certification (Algorithm 3): the latter improves certified AP by ~3.1 points on MS-COCO (44.902% vs. 41.763%) and provides tighter bounds, particularly in the mid-recall region. The only related multi-label certifiable defense, MultiGuard [15], targets ℓ₂-norm perturbations rather than adversarial patches and is not directly comparable. Ablation studies confirm that cutout-based fine-tuning (Random Cutout, Greedy Cutout) further boosts robustness, and that the defense degrades gracefully when reducing the computational budget from 36 to 16 masks (≤2 AP drop).

## Relation to Prior Work

This paper extends the line of certifiable defenses against adversarial patches (De-randomized Smoothing, BagCert, PatchGuard, PatchCleanser) from the single-label classification setting to multi-label classification. The core mechanism is a decomposition principle: treating each class in a multi-label problem as an independent binary classifier and wrapping it with an existing single-label CDPA. The only prior certifiable defense for multi-label classification is MultiGuard (Jia et al.), which addresses ℓ₂-norm perturbations rather than the physically realizable patch threat model. The location-aware certification procedure is a novel contribution that exploits the single-patch constraint to tighten bounds beyond what per-class certification alone provides.

## Why It Matters / Open Questions

Multi-label classifiers underpin safety-critical systems (autonomous driving, retail checkout, video surveillance) where a single printed patch can cause catastrophic failure, making certifiable guarantees practically important. The modular design means any future single-label CDPA improvement automatically transfers to the multi-label setting, giving the framework long-term relevance. However, the certified AP (~45% on MS-COCO) remains far below clean AP (~85%), and the gap is largely attributed to PatchCleanser's sensitivity to object occlusion from its mask set—a limitation inherited from the backbone. Open questions include whether the clean-to-certified gap can be narrowed with better backbones, whether the framework scales to very large class counts, and whether the location-aware extension generalizes to multi-patch or adaptive threat models.

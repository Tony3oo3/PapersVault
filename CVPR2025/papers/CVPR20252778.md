## Problem

Existing garment texture generation methods face a three-way trade-off: 2D diffusion-based approaches (e.g., TEXTure, Text2Tex) produce diverse textures but suffer from 3D inconsistency such as the 'Janus effect'; 3D-data-trained methods (e.g., TexOct, PointUV) ensure consistency but lack generalization to diverse garment styles; and most prior methods require multi-stage iterative pipelines that take minutes per texture. No prior method simultaneously achieves high texture diversity, global 3D consistency, and fast single-pass inference for garments.
![Teaser figure](../imgs/CVPR20252778/cropped_page0_idx0.webp)

## Input / Output

The method takes an untextured 3D garment mesh and a text prompt describing the desired texture. The mesh is rasterized via Nvdiffrast to produce a UV position map (each pixel encoding XYZ surface coordinates, normalized to [-1,1]) and a 5k-point 3D point cloud sampled from the surface. The output is a single 512×512 UV texture map generated in one inference pass (~4 seconds on a single V100), which can be directly applied to the mesh for rendering.

## Method

TexGarment builds on the pre-trained PixArt-α diffusion Transformer and introduces two modules to inject 3D garment structure into the 2D generation process. First, a 3D Structure Information Extraction module encodes the UV position map via a VAE encoder to obtain a 2D layout latent, separately embeds the 3D point cloud via a learnable positional embedding, and fuses them through cross-attention to produce a '3D structure latent' that encodes both UV layout and global 3D geometry. Second, a 3D Structure Guidance module injects this latent into every Transformer block via an additional cross-attention path (alongside the standard text cross-attention), so the denoising process is conditioned on both text semantics and 3D structure simultaneously. Training uses classifier-free guidance over both the text and 3D structure conditions, and the model is fine-tuned for 50k steps on 7.9k VRoidHub garments with newly added parameters initialized to zero and trained at a higher learning rate (2×10⁻⁵) than the frozen backbone (2×10⁻⁶).

## Results

TexGarment achieves a FID of 96.97 and KID of 0.63 on the VRoidHub test set, substantially outperforming the closest competitor Paint3D (FID 147.40, KID 2.86) by 50.43 in FID and 2.23 in KID. The method also attains the highest CLIP score of 32.37, indicating superior text-texture alignment over all baselines. Inference time is approximately 4 seconds per texture map, compared to 140–940 seconds for competing methods. In a user study with 30 participants, TexGarment scores 4.83/5 on image quality and 4.92/5 on text fidelity, versus 4.01 and 4.17 for the next-best method (Paint3D).

## Baselines & Comparisons

TexGarment outperforms all four baselines on every reported metric (FID, KID, CLIP score, and runtime). Against the strongest quantitative competitor, Paint3D [45], TexGarment reduces FID from 147.40 to 96.97 (a 34% relative improvement) and KID from 2.86 to 0.63, while also improving CLIP score from 28.72 to 32.37. Compared to TEXTure [37] and Text2Tex [7], TexGarment achieves roughly 40–70% lower FID and 4–7× lower KID, and is 35–235× faster in inference (4 s vs. 140 s and 940 s, respectively). TexPainter [46] is included only in qualitative comparison due to its very long processing time; visually, TexGarment produces more consistent front-back textures and finer detail. In the user study, TexGarment leads Paint3D by 0.82 points on image quality and 0.75 points on text fidelity (on a 5-point scale), confirming that the quantitative gains translate to perceived quality.

## Relation to Prior Work

TexGarment builds on PixArt-α, a pre-trained text-to-image diffusion transformer, repurposing it for 3D-consistent UV texture generation by injecting 3D garment structure information as an additional cross-attention guidance signal. It departs from the dominant multi-view painting paradigm (TEXTure, Text2Tex, Paint3D, TexPainter) that iteratively generates and fuses textures from multiple camera poses, instead performing the entire generation in a single UV-space inference pass. The UV position map concept appears in prior work (PointUV, Paint3D, TextureGen), but TexGarment is the first to combine it with a point-cloud-derived 3D structure latent as the sole conditioning signal in a single-stage diffusion transformer, rather than using it as a second-stage inpainting condition.

## Why It Matters / Open Questions

The 4-second single-pass inference (versus 140–940 seconds for baselines) makes high-quality garment texturing practically viable for interactive design tools and e-commerce pipelines, where prior methods were prohibitively slow. The clean separation of 2D layout guidance (UV position map) and global 3D structure guidance (point cloud) via cross-attention offers a reusable architectural pattern for other 3D texturing domains. However, the method is currently limited to the garment domain (trained on 8k VRoidHub items) and does not support image-conditioned generation, leaving open whether the 3D-structure-guidance approach generalizes to arbitrary object categories or can be extended to reference-image-driven texturing.

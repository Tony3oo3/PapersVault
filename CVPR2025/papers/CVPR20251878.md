## Problem

Zero-shot object recognition with event camera data is hindered by a fundamental misalignment: the spatial sparsity of event streams causes event embeddings to collapse into overly similar representations, so contrastive learning objectives fail to transfer CLIP's image-text alignment to the event-text pair. Existing reconstruction-based and contrastive approaches either accumulate errors across stages or leave the event embedding space under-constrained, resulting in poor zero-shot accuracy.
![Teaser figure](../imgs/CVPR20251878/cropped_page0_idx0.webp)

## Input / Output

The model consumes event frames (asynchronous pixel-wise brightness changes encoded as spatial-temporal tensors) and a free-form text prompt, producing a class label via cosine similarity between the event embedding and the frozen CLIP text embedding. For action recognition, a lightweight two-layer ViT (~0.35M parameters) temporally aggregates per-frame event embeddings before matching against text. Training is performed entirely on synthetic event-RGB pairs generated from ~180M static RGB images, so no real event camera data is needed during training.

## Method

The paper introduces a scalar-wise modulation loss that adaptively penalizes per-dimension deviations between paired event and image embeddings, with the penalty weight λ computed from how similar a given event embedding is to other event embeddings in the batch (more similar → stronger constraint). This is added to a standard symmetrized InfoNCE contrastive loss, and the combined objective is shown theoretically (Lemma 1) to close the gap that pure contrastive learning leaves between event and text embedding spaces. The event encoder is a ViT-B/16 initialized from EVA-CLIP, trained with the frozen CLIP image encoder providing the reference embeddings. To overcome the scarcity of paired event-RGB data, a synthesis pipeline applies random affine transformations (translation, scaling, rotation) to static RGB images and converts the resulting short video sequences into realistic event streams via V2E, yielding a large-scale diverse training set without requiring real event cameras.

## Results

On the N-ImageNet dataset (the largest event-based object recognition benchmark), EZSR achieves 47.84% zero-shot accuracy with a ViT-B/16 backbone, substantially outperforming all prior zero-shot methods (best prior: ECLIP^up at 25.05%) and approaching supervised baselines (EventBind 51.40%, MEM 57.89%). With optimized text embeddings (Ours^up), accuracy rises to 57.97%, matching the supervised MEM baseline. Across nine standard event datasets spanning object and action recognition, EZSR consistently achieves the best zero-shot performance, with particularly large margins on action recognition (e.g., 98.62% on DailyAction vs. 90.33% for EventBind).

## Baselines & Comparisons

EZSR decisively outperforms all three prior zero-shot CLIP-based frameworks (EventBind, ECLIP, EventCLIP) on N-ImageNet by 22.8–44.8 percentage points in standard zero-shot mode (47.84% vs. 3.05–8.72%). On action recognition datasets, the margins are even larger: on PAF, EZSR scores 90.44% versus 67.58% (EventBind), 53.88% (ECLIP), and 49.95% (EventCLIP); on DailyAction, 98.62% versus 90.33%, 85.64%, and 85.08% respectively. On N-Caltech101, EZSR (25.72%) trails the optimized-text-embedding variants of EventCLIP^up (65.60%) and ECLIP^up (63.37%), though Ours^up (59.60%) narrows the gap. On CIFAR-10-DVS, EZSR (84.72%) ties EventBind (84.72%) and Ours^up (88.89%) surpasses all zero-shot baselines. Against supervised dataset-specific methods, EZSR's zero-shot accuracy on N-ImageNet (47.84%) approaches EventBind (51.40%) and MEM (57.89%), while on N-MINIST it reaches 90.44%, close to the supervised EventBind (94.08%) and MEM (90.10%). The paper notes that on low-resolution datasets (CIFAR-10-DVS, N-MINIST), direct CLIP-on-event-frame methods remain competitive, suggesting the advantage of EZSR's scalar-wise modulation is most pronounced on higher-resolution, semantically diverse data.

## Relation to Prior Work

This paper builds directly on CLIP's zero-shot recognition paradigm, replacing the RGB image encoder with an event encoder while retaining the pretrained text encoder. It departs from prior event-based zero-shot methods (EventBind, ECLIP, EventCLIP) that rely on contrastive learning to align event and image embeddings, by identifying a theoretical bottleneck: the spatial sparsity of event data causes embeddings to collapse into an overly similar subspace, making the InfoNCE objective insufficient to guarantee alignment with the CLIP text space. The proposed scalar-wise modulation loss and the synthetic event data pipeline (affine warping + V2E) are the two key departures from prior work, addressing the alignment failure and the scarcity of paired event-RGB training data respectively.

## Why It Matters / Open Questions

The paper demonstrates that a zero-shot method trained entirely on synthetic event data (no real event-RGB pairs) can match or exceed supervised baselines on several benchmarks, which is practically significant given the extreme scarcity of paired event data. The theoretical analysis (Lemma 1) and the dramatic ablation (9.57% → 47.84% from adding scalar-wise modulation) reveal a fundamental limitation of contrastive learning for cross-modal alignment when one modality is inherently sparse — an insight potentially transferable to other sparse-sensor settings. Open questions include whether the synthetic data pipeline captures the full diversity of real event streams, whether the approach extends to a generalist event-based foundation model, and how performance scales with truly large-scale event data rather than synthetic surrogates.

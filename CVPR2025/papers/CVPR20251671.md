## Problem

Previous vision-centric 3D occupancy methods rely on implicit, loss-driven learning to model spatial and temporal structure, which limits the model's ability to capture fine-grained spatial details and degrades spatial discriminative capacity. The paper identifies that the occupied state of 3D space encodes direct geometric correspondence with scene structure but has been underutilized as an explicit prior for feature refinement.
![Teaser figure](../imgs/CVPR20251671/cropped_page0_idx0.webp)

## Input / Output

The method consumes a 6-camera video sequence (NuScenes) at 704×256 or 1408×512 resolution along with ego-vehicle pose for temporal alignment. It produces multi-resolution 3D voxel occupancy (semantic + geometric) via a cascade decoder and scene flow vectors for foreground voxels. Because the sparse sampling strategy yields variable per-frame compute, the reported memory figures reflect the maximum observed GPU usage (7.7–8.9 GB).

## Method

STCOcc introduces an explicit state-based cascade decoder that progressively renovates coarse LSS voxel features across three stages. At each stage, a Self-Recursive Occupancy Predictor (SROP) refines the occupied state layer-by-layer via a shared MLP with residual accumulation, providing increasingly accurate geometric priors. An Occlusion-Aware Spatial Cross-Attention (OA-SCA) then reweights sampled 3D reference points using a volume-rendering-inspired formula that combines bin-depth matching with occupancy weights, resolving the projection ambiguity that plagues vanilla SCA. For temporal modeling, an Occlusion-Aware Temporal Self-Attention (OA-TSA) gates deformable attention by occupied weights to focus on non-empty space, while a Sparse Temporal Fusion module decouples non-empty (long-term) and empty (short-term) regions into parallel SlowFast-style streams with a FIFO memory bank, reducing cost while preserving spatial detail. Training uses a multi-stage loss combining Scene-Class Affinity, focal, Lovász, L1 flow, and depth cross-entropy terms.

## Results

On Occ3D-nus, STCOcc achieves a state-of-the-art RayIoU of 41.7% (42.1% at 1408×512 input) and mIoU of 44.6% (45.0% at 1408×512) using only a ResNet-50 backbone and 704×256 input, while reducing training GPU memory to 7.7 GB (8.9 GB at higher resolution). On OpenOcc, STCOcc achieves RayIoU of 40.8% and mAVE of 0.44 for joint occupancy and scene flow prediction, substantially outperforming prior methods that use ResNet-101 backbones and larger inputs. The method requires only 36 training epochs compared to 100 for OPUS-L and 90 for FB-Occ.

## Baselines & Comparisons

STCOcc outperforms the closest competitor COTR (41.0% RayIoU, 18.3 GB) by 0.7% RayIoU while using 58% less GPU memory (7.7 GB) and 12 fewer epochs. It also surpasses OPUS-L (41.2% RayIoU, 12.1 GB) by 0.5% RayIoU with 36% less memory and 64 fewer training epochs. Against sparse-method baselines, STCOcc leads SparseOcc (35.1% RayIoU, 23.7 GB) by 6.6% RayIoU and FB-Occ (33.5% RayIoU, 9.6 GB) by 8.2% RayIoU. On OpenOcc for joint occupancy and scene flow, STCOcc achieves mAVE of 0.44, nearly halving the error of FB-Occ (0.83) and SparseOcc (0.87), and beating Let Occ Flow (mAVE 1.45) and OccNet (mAVE 1.61) which both use ResNet-101 with 1600×900 or 1408×512 inputs. In mIoU on Occ3D-nus, STCOcc (44.6%) edges out COTR (44.5%) and ViewFormer (41.9%) while using the lowest memory footprint among all compared methods.

## Relation to Prior Work

STCOcc builds directly on BEVFormer's spatial-temporal transformer architecture, modifying its Spatial Cross-Attention (SCA) and Temporal Self-Attention (TSA) into occlusion-aware variants, and on the LSS (Lift-Splat-Shoot) paradigm for initial 3D feature construction. The key conceptual departure is from the implicit, loss-driven feature learning used by prior sparse occupancy methods (SparseOcc, SGN, VoxFormer): instead of relying solely on supervision to shape 3D features, STCOcc explicitly uses the predicted occupied state as a geometric prior to guide feature renovation at every cascade stage. The sparse temporal fusion module additionally draws on SlowFast-style parallel stream decomposition, which is a departure from the purely recurrent temporal modeling in BEVFormer and OccNet.

## Why It Matters / Open Questions

The explicit state-based renovation paradigm offers a principled alternative to implicit loss-driven 3D feature learning, and the demonstrated 2.4× memory reduction (7.7 GB vs. 18.3 GB for COTR) while achieving higher RayIoU makes the approach practically attractive for resource-constrained deployment. However, the method still depends on the LSS pipeline for initial feature lifting, and the multi-stage cascade with FIFO memory banks adds architectural complexity that may limit straightforward extension to other 3D perception tasks (e.g., dense 3D detection or tracking). Open questions include whether the explicit occupied-state guidance generalizes beyond the NuScenes-scale scene size, whether the cascade depth can be reduced without performance loss, and how the approach behaves under significant domain shift (e.g., different sensor suites or urban environments).

## Problem

Cache-based test-time adaptation for CLIP suffers from two critical flaws: noisy pseudo-labels during cache construction contaminate stored feature-label pairs, and during querying, each class center encodes only single-class information, causing blind propagation of unreliable labels. These issues compound under distribution shift, significantly degrading adaptation accuracy on out-of-distribution and cross-domain benchmarks.
![Teaser figure](../imgs/CVPR20250603/cropped_page0_idx0.webp)

## Input / Output

The method consumes a single RGB test image and a set of K text class descriptions, processing 16 augmented views per image for confidence estimation. It maintains a streaming cache of historical test features (both CLIP and DINOv2) with pseudo-labels, growing over the test sequence. The output is a K-dimensional class probability distribution obtained by fusing three prediction streams: the original CLIP zero-shot logits, a CLIP Shared Semantic graph prediction, and an Auxiliary Fine-grained Visual graph prediction, combined via learned weights β₁, β₂, β₃.

## Method

COSMIC introduces two core components. First, the Dual Semantics Graph (DSG) constructs two complementary graph spaces: a CLIP Shared Semantic (CSS) space unifying text embeddings with cached visual class centers, and an Auxiliary Fine-grained Visual (AFV) space built from DINOv2 self-supervised features. Each space is transformed into a Second-Order Graph (SOG) via adjacency matrix products, capturing higher-order inter-class dependencies while remaining sparser than first-order graphs. Second, the Clique Guided Hyper-class (CGH) applies a modified Bron-Kerbosch algorithm to extract maximal cliques from both SOGs, then computes hyper-class centers as centroids of clique member nodes. Test features are matched against these hyper-class centers to select top-r correlated classes (inliers), producing binary masks that suppress outlier class logits. The final prediction averages text and image class probabilities within each masked graph space and fuses all three streams with adaptive weights, achieving 15.81% OOD and 5.33% cross-domain gains over prior cache-based methods without any gradient-based training.

## Results

On the OOD benchmark with CLIP RN-50, COSMIC achieves 62.30% average OOD accuracy, surpassing the strongest cache-based baseline DMN (46.49%) by 15.81% and the unadapted CLIP (40.69%) by 21.61%. With CLIP ViT-B/16, the OOD average reaches 72.83%, a 9.03% gain over DMN (63.80%). On the 10-dataset cross-domain benchmark, COSMIC achieves 68.65% (RN-50) and 72.81% (ViT-B/16) average accuracy, outperforming DMN by 5.33% and 2.51% respectively. The method is training-free and uses only 16 augmentation views per image, achieving a 15.47% gain over CLIP on Flower102 in 0.368s per image.

## Baselines & Comparisons

COSMIC outperforms all seven baselines across every dataset and both backbones. Against the unadapted CLIP baseline, gains range from 17.03% (RN-50 OOD avg) to 25.63% (ViT-B/16 OOD avg). Among few-shot prompt methods, COSMIC exceeds CoCoOp by 19.48% (RN-50) and 12.92% (ViT-B/16) on OOD average, despite requiring no training data. Among training-based zero-shot methods, COSMIC surpasses TPT by 18.41% (RN-50) and 12.02% (ViT-B/16), and DiffTPT by 16.61% and 12.18% respectively. Among training-free cache-based methods (the most direct competitors), COSMIC leads TDA by 15.67% (RN-50) and 8.94% (ViT-B/16) on OOD average, and DMN by 15.81% and 9.03%. On the cross-domain benchmark, COSMIC beats DMN (the strongest baseline) by 5.33% (RN-50) and 2.51% (ViT-B/16), with the largest per-dataset gains on Aircraft (+2.72% over DMN with ViT-B/16) and Flower102 (+7.65% over DMN with RN-50).

## Relation to Prior Work

COSMIC extends the cache-based test-time adaptation line initiated by TDA and DMN, which store pseudo-labeled visual features in a queue and query via similarity to per-class centers. It departs from this lineage in two key ways: (1) the cache is enriched with cross-modal text features and fine-grained DINOv2 visual features, moving beyond CLIP's coarse-grained visual embeddings alone, and (2) the query mechanism replaces flat Euclidean similarity with a graph-structured search over maximal cliques (Clique Guided Hyper-class), enabling multi-class correlated retrieval rather than single-class center matching. The method also draws on the self-supervised visual encoder literature (DINOv2) to complement CLIP's text-centric alignment objective.

## Why It Matters / Open Questions

The training-free design with only 16 augmentations (vs. 64–128 for competing methods) makes COSMIC attractive for real-world deployment where backpropagation and heavy augmentation are impractical. The 15.81% OOD gain over the strongest prior cache-based method (DMN) is substantial and consistent across both ResNet-50 and ViT-B/16 backbones. However, the maximal clique search introduces non-trivial computational overhead that the authors acknowledge as a limitation, and the approach is currently validated only on CLIP-based zero-shot classification. Open questions include whether the graph-clique formulation generalizes to other VLMs or dense prediction tasks, and whether sparsification techniques can reduce the clique search cost without sacrificing the multi-class correlation signal.

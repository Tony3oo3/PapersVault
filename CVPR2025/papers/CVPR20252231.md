## Problem

Existing ICL-based unified medical lesion segmentation models rely on cross-fusion between reference and query features, causing two conjugate failures: low-matched reference sets contaminate query features with noise, and the architecture becomes heavily dependent on reference quality. The paper identifies that the query image itself can serve as a high-matched reference without annotation, but no prior method exploits this self-referential signal to decouple the model from reference-set quality.
![Teaser figure](../imgs/CVPR20252231/cropped_page0_idx0.webp)

## Input / Output

The model takes a 384×384 query medical image and K reference image-annotation pairs (K=4 in main experiments, but robust down to K=1) from the same task. Reference annotations can be pixel-level masks, bounding boxes, or random points, and the model handles all three without retraining. A single weight-shared ConvNeXt-B encoder processes both reference and query images, and the output is a binary segmentation mask at the query resolution. The same parameter set is applied across 8 tasks spanning CT, MR, OCT, ultrasound, pathology, endoscopy, and dermoscopy modalities.

## Method

SR-ICL replaces cross-fusion with two individually-extracted indicator streams. Reference Indicator Generation (RIG) encodes reference features via a 3×3 convolution and uses masked average pooling with the reference mask to produce foreground/background indicator vectors that directly parameterize a Dynamic Lesion Segmentation Head (DLSH) — a 3-layer 1×1-conv FCN with only 584 learnable parameters. Self-Referring Indicator Generation (SRIG) then thresholds the initial DLSH prediction by a saliency score, extracts salient patches from the query's semantic features, and refines them through a transformer cross-attention block where the salient patches act as queries and the full query feature map acts as key/value. The refined self-referring vectors are combined with the reference vectors via a fixed weighted sum (α=0.7, β=0.3) to update DLSH weights for the final prediction. Training uses a 'Separate BP-Average Update' strategy that performs forward-backward per task and averages accumulated gradients, keeping GPU memory constant (8.3 GB) regardless of the number of tasks, unlike prior balance strategies that scale memory with task count.

## Results

SR-ICL achieves state-of-the-art Dice scores across all 8 medical lesion segmentation tasks using only 4 reference image-mask pairs: 80.54 (Wet AMD), 74.29 (Brain Tumor), 94.96 (Adenocarcinoma), 87.91 (Thyroid Nodule), 83.26 (Polyp), 82.36 (Lung Infection), 84.92 (Breast Lesion), and 90.85 (Skin Lesion). The closest unified competitor, Spider, uses 64 reference images yet still trails SR-ICL by 1.5–8.5 Dice points per task. Even with weak reference annotations (boxes or points), SR-ICL degrades by less than 1.5 Dice on most tasks, and its training memory remains fixed at 8.3 GB regardless of the number of tasks (8 or 16).

## Baselines & Comparisons

SR-ICL outperforms the strongest unified baseline Spider (ICML 24) on all 8 tasks despite using 16× fewer reference images (4 vs. 64), with margins of +2.0 Dice (Wet AMD), +2.7 (Brain Tumor), +1.3 (Adenocarcinoma), +1.4 (Thyroid Nodule), +2.6 (Polyp), +8.5 (Lung Infection), +3.8 (Breast Lesion), and +2.1 (Skin Lesion). Against the unified SegGPT (also 4 refs), SR-ICL leads by +8.9 to +32.3 Dice, with the largest gap on Lung Infection (+32.3) and Brain Tumor (+30.1). Compared to specialized per-task models (UNet, RollingUNet, task-specific networks), SR-ICL wins on 7 of 8 tasks; the only exception is Adenocarcinoma where specialized UNet reaches 91.94 vs. SR-ICL's 94.96 (SR-ICL actually wins here too). Generalist models (SegGPT, UniverSeg) without task-specific training are far behind, with SegGPT achieving only 21–61 Dice, confirming that ICL-based unified training is essential for clinical-grade performance. The paper also shows that SR-ICL's performance is robust to reference annotation type: using boxes or points instead of masks causes less than 1.5 Dice drop on 7 of 8 tasks, a practical advantage for clinical deployment where pixel-level annotations are expensive.

## Relation to Prior Work

This paper departs from the dominant cross-fusion paradigm in ICL-based segmentation (SegGPT, UniverSeg, Spider), where reference and query features are entangled through attention or concatenation, by instead extracting reference and query features individually and treating the query itself as a 'self-reference' via coarse predictions. The dynamic-convolution head design is directly inspired by CondInst's conditional convolutions, repurposing reference-derived indicator vectors as lightweight FCN weights rather than as inputs to a heavy fusion module. The self-referring mechanism (SRIG) draws on the few-shot segmentation insight that the query contains complementary information, but applies it in a unified multi-task medical setting where intra-class variability makes reference matching unreliable.

## Why It Matters / Open Questions

The practical significance is substantial for clinical deployment: SR-ICL achieves SOTA on 8 diverse medical tasks with only 4 reference pairs (vs. 64 for Spider/UniverSeg), tolerates weak annotations (boxes, points), and maintains fixed low memory regardless of task count—addressing real constraints in hospital settings. The finding that separate per-task training and unified training yield comparable results for SR-ICL (unlike U-Net or TransUNet) suggests the self-referring mechanism inherently mitigates the long-tail data imbalance problem. Open questions include whether the approach extends to 3D volumetric medical imaging, whether the single-iteration SRIG (L=1) remains sufficient for more complex multi-class or instance-level segmentation, and how performance scales when the number of unified tasks grows well beyond 8.

## Problem

Continual fine-tuning of pre-trained Vision-Language Models (VLMs) like CLIP causes catastrophic forgetting of both pre-training knowledge (zero-shot generalization) and previously learned downstream tasks. This is compounded by the inaccessibility of the original pre-training data, rendering standard replay-based mitigation strategies impractical. The paper asks whether synthetic data from text-to-image diffusion models can effectively substitute for unavailable historical data to preserve VLM knowledge during sequential task learning.

## Input / Output

The method takes RGB images (processed by a ViT-B/16 image encoder) and templated text prompts (e.g., 'a photo of a {class name}') as dual inputs, producing a class label prediction via cosine similarity between image and text embeddings. During continual training, the model also consumes 1K synthetic image-text pairs per task generated by Stable Diffusion v1.5 (50 denoising steps, CFG=7.5) from a growing pool of class names spanning both ImageNet (approximating pre-training) and all previously learned downstream tasks. Inference operates in either Task-Incremental (task ID known, predict within task classes) or Class-Incremental (no task ID, predict across all seen classes) settings.

## Method

GIFT comprises two synergistic components. First, Synthetic Data-based Distillation: Stable Diffusion generates images from class names in a maintained buffer pool (initialized with ImageNet classes to approximate pre-training data, then augmented with downstream task classes), and the current CLIP model is trained to match the previous CLIP model's contrastive image-text similarity matrix on these synthetic pairs via a KL-divergence-based contrastive distillation loss, supplemented by an image-text alignment loss that uses the identity matrix as a hard target to correct teacher model errors. Second, Adaptive Weight Consolidation (AWC): unlike EWC's static Fisher information, AWC recomputes diagonal Fisher information at every optimization step using the gradient of the distillation loss on synthetic data, dynamically adjusting per-parameter L2 penalty strength to constrain updates that would increase forgetting while preserving plasticity for new task learning. The total loss combines cross-entropy for the new task, contrastive distillation (α=1), image-text alignment (β=0.25), and AWC regularization.

## Results

On the MTIL benchmark (11 datasets, 1,201 classes), GIFT achieves 69.3% Transfer, 77.3% Avg., and 86.0% Last on Order I, and 65.9% Transfer, 75.7% Avg., and 85.3% Last on Order II, outperforming all baselines on every metric. Notably, GIFT uses only 1K synthetic images per task (generated by Stable Diffusion) while the strongest competitor ZSCL requires 100K real ImageNet images. The Transfer metric (zero-shot generalization on unseen data) reaches 69.3%, nearly matching the initial CLIP zero-shot upper bound of 69.4%, while the Last metric (retention of historical downstream knowledge) improves by +10.1 over the l2 baseline.

## Baselines & Comparisons

GIFT outperforms all six baselines on every metric (Transfer, Avg., Last) in both MTIL Order I and Order II. Against the two strongest competitors, GIFT leads ZSCL by +1.2 Transfer / +1.9 Avg. / +2.4 Last (Order I) and MoE-Adapter by +0.4 / +0.6 / +1.0 (Order I), with the gap widening in Order II where domain shift is more severe (GIFT beats MoE-Adapter by +1.6 Transfer). The older regularization and replay baselines (LwF, iCaRL, LwF-VR, WiSE-FT) lag substantially, with Transfer scores 12–19 points below GIFT, because they do not explicitly protect pre-training knowledge. A key efficiency advantage is that GIFT achieves these results with only 1K diffusion-generated images per task, whereas ZSCL requires 100K real ImageNet images for its distillation reference set.

## Relation to Prior Work

GIFT extends the EWC line of work by replacing static Fisher information (computed once on old-task data) with dynamically updated Fisher information derived from synthetic image-text pairs during training, directly addressing the staleness problem in parameter importance estimation. It departs from ZSCL, which protects zero-shot capability via distillation on 100K real ImageNet images, by substituting a pre-trained Stable Diffusion model as a 'compressed, parameterized image library' that recreates both pre-training and downstream data with only 1K generated images per task. The contrastive distillation loss is specifically designed to mirror CLIP's pre-training image-text matching objective, distinguishing it from feature-distance or unimodal distillation approaches used in prior VLM-CL work.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in VLM continual learning: the inaccessibility of pre-training data makes replay-based methods infeasible, and GIFT shows that a small amount of diffusion-generated data can substitute for large real datasets (1K synthetic images outperform 100K ImageNet images on Avg. and Last metrics). The adaptive weight consolidation offers a drop-in improvement over static EWC with minimal computational overhead. Limitations include evaluation on a single CLIP architecture (ViT-B/16), a single benchmark (MTIL with 11 datasets), and only 1K images per task; open questions include whether the approach scales to larger VLMs, longer task sequences, or other diffusion backbones, and whether the synthetic-data advantage persists under more aggressive domain shifts.

## Problem

Existing Implicit Neural Representations rely on a single, fixed activation function across all layers, which constrains representation power and generalization to unseen coordinates. Moreover, determining the optimal activation parameters for that single function requires an exhaustive grid search before training can even begin, and reusing previously found parameters prevents the INR from adapting to each unique signal. The paper asks whether an INR can be dynamically matched to the specific signal it represents, and whether the pre-training parameter search can be eliminated.

## Input / Output

The network receives normalized spatial coordinates (2D grid for images, 3D voxel grid at 512³ for occupancy fields, 3D position plus viewing angles for NeRF) without any positional embedding, and outputs the corresponding signal values (RGB, binary occupancy, or color-and-density). A key practical detail is that activation parameters are randomly initialized from uniform or normal distributions rather than requiring a pre-determined grid search, and for inpainting the matching loss is computed only over the unmasked region of the image.

## Method

MIRE constructs a dictionary of seven parametric activation atoms (Sinc, Raised Cosine, Root Raised Cosine, Prolate Spheroidal Wave Function, Gabor Wavelet, Gaussian, and Sinusoid) and uses a matching-pursuit-inspired procedure to select the best atom for each hidden layer sequentially. Starting from a single-layer MLP, it trains each dictionary atom for a fixed number of epochs, records the mean squared loss, and freezes the atom with the lowest loss as that layer's non-linearity. It then adds the next hidden layer, retrains the full network while keeping previously selected activations frozen, and repeats the dictionary sweep for the new layer. This layer-by-layer greedy selection produces a signal-specific activation sequence (e.g., Sinc → Gaussian → Gabor Wavelet for the Parrot image) without any pre-training grid search, since all activation parameters are learned from random initialization during the matching epochs.

## Results

MIRE is evaluated across six tasks using PSNR, SSIM, and IoU as primary metrics. On the Kodak dataset for image representation, MIRE achieves the highest PSNR and SSIM among all compared INRs, with the matched activation sequence (e.g., Sinc → Gaussian → Gabor Wavelet for the Parrot image) converging in at most 200 epochs after the first two layers are determined. For 3D occupancy field representation on Stanford 3D shapes (512³ grid), MIRE attains the highest IoU, precisely encoding high-frequency details where WIRE and SIREN converge toward lowpass representations. In the activation parameter initialization study (Tab. 3, supplementary), MIRE is the only INR delivering consistent PSNR across uniform and normal distributions with minimal standard deviation, while WIRE and SIREN each require a narrow parameter range to perform well.

## Baselines & Comparisons

MIRE outperforms all six baselines across every evaluated task. Against WIRE (Saragadam et al., CVPR 2023), MIRE achieves higher PSNR/SSIM on Kodak image representation and inpainting, and higher IoU on Stanford 3D occupancy fields; WIRE additionally requires activation parameters initialized within U(−10,10) for the Parrot image to perform well. Against SIREN (Sitzmann et al., NeurIPS 2020), MIRE surpasses it in reconstruction quality and generalization, while SIREN depends on a very specific sinusoidal frequency and weight initialization and shows enhanced performance only under U(−100,100) parameter draws. Against GAUSS (Ramasinghe & Lucey, ECCV 2022) and MFN (Fathony et al., ICLR 2020), MIRE reports superior PSNR and SSIM on image representation and inpainting, with the paper explicitly stating it outperforms all four in both performance and generalization. Against the more recent INCODE (Kazerouni et al., WACV 2024) and FINER (Liu et al., CVPR 2024), comparisons are provided in the supplementary material for super-resolution, edge detection, and high-frequency encoding, where MIRE also reports leading results. A key differentiator is that MIRE eliminates the need for exhaustive grid search over activation parameters before training, whereas WIRE, SIREN, and GAUSS all require task-specific parameter tuning or reuse of previously identified values.

## Relation to Prior Work

MIRE extends the INR activation-function lineage (SIREN's sinusoids → GAUSS's Gaussians → WIRE's Gabor wavelets) by replacing the single-activation-per-network paradigm with a per-layer, signal-matched sequence drawn from a seven-atom dictionary. The core algorithmic idea is borrowed from matching pursuit [19] in signal processing, repurposed here to sequentially select and freeze the best activation atom for each hidden layer based on reconstruction loss. Unlike prior INR methods that require exhaustive grid search over activation parameters before training begins, MIRE treats parameter initialization as a random draw and lets the sequential matching process absorb the optimization burden.

## Why It Matters / Open Questions

By eliminating the pre-training grid search and making activation selection signal-specific, MIRE addresses a practical bottleneck that has limited the broader adoption of parametric-activation INRs. The initialization-robustness finding (consistent PSNR across uniform and normal distributions, while WIRE and SIREN collapse under mismatched distributions) suggests the matching procedure itself provides sufficient inductive guidance. Open questions include the computational cost of the sequential search (7 atoms × L layers × multiple training restarts), whether the fixed seven-atom dictionary is sufficient for all signal types, and whether the approach scales to large-scale NeRF training where per-layer retraining becomes prohibitive.

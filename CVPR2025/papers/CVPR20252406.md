## Problem

Existing Transformer-based vision-language trackers rely on discrete context prompts extracted from bounding box predictions to model temporal information, which introduces error accumulation and lacks explicit cross-frame correlation. Moreover, most methods update only visual references while ignoring the need to jointly adapt language and visual reference features as the target's appearance and motion evolve over time.
![Teaser figure](../imgs/CVPR20252406/cropped_page0_idx0.webp)

## Input / Output

The tracker accepts a template video clip (L frames at 128×128), a search region (256×256), and optionally a natural language description (max 48 tokens) and/or an initial bounding box, supporting three reference settings (BBOX, NL, NL&BBOX). It outputs a target bounding box, a confidence score per prediction (used to update the template clip), and a target score map. The visual backbone is a 4-stage Vmamba-tiny with 1/16 downsampling, and the text encoder uses the first 4 layers of Mamba-130m.

## Method

MambaVLT introduces a Time-Evolving Multimodal Fusion (TEMF) module built on Mamba's selective state space. Its Hybrid Multimodal State Space (HMSS) block maintains a multi-level state space memory across frames, where each layer's final state space inherently encodes global temporal context; a modality-guided bidirectional scan (text-first α and template-first β) with shared B/C/D gates but distinct A update gates adaptively fuses and updates reference features. A Selective Locality Enhancement (SLE) block then applies a 1D sliding-window linear attention scan augmented by a global selective map A_l to strengthen intra-modal and inter-modal correlations in the current frame. A modality-selection module dynamically weighs language and template invariant clues to refine search region features. Training combines supervised localization losses (bbox, target score, center score) with intra-video and inter-video multimodal contrastive losses to align reference and search region representations.

## Results

On TNL2K, MambaVLT achieves 66.5 AUC (NL&BBOX), 58.4 AUC (NL), and 63.3 AUC (BBOX), outperforming the strongest baselines UVLTrack-B (63.1/55.7/62.7) and JointNLT (56.9/54.6) by 3.4%, 2.7%, and 0.6% respectively. On OTB99, it reaches 72.2 AUC (NL&BBOX) and 71.6 AUC (BBOX), surpassing UVLTrack-B by 2.9% and 2.3%. On MGIT, MambaVLT achieves 69.9 AUC and 58.9% precision (NL&BBOX), improving over JointNLT by 14.4% in precision. However, on LaSOT, MambaVLT trails DecoupleTNL by 4.6% AUC (NL&BBOX) and 9.1% AUC (NL), suggesting limitations with ambiguous textual descriptions on that benchmark.

## Baselines & Comparisons

MambaVLT outperforms UVLTrack-B [37], the strongest unified vision-language tracker, on TNL2K across all three reference settings (BBOX +0.6 AUC, NL +2.7 AUC, NL&BBOX +3.4 AUC) and on OTB99 BBOX (+2.3 AUC). Against JointNLT [58], the leading NL&BBOX tracker, MambaVLT gains 9.6 AUC on TNL2K and 14.4% precision on MGIT, though it trails on LaSOT NL&BBOX (66.6 vs 71.2 AUC) and OTB99 NL&BBOX (72.2 vs 73.8 AUC). DecoupleTNL [36] remains the strongest NL-only baseline on LaSOT (64.9 vs 55.8 AUC) and OTB99 (69.5 vs 58.9 AUC), indicating MambaVLT's state-space memory is less effective when the sole reference is an ambiguous text description. On MGIT, MambaVLT dominates all settings: 65.7 AUC (BBOX) vs GRM's 50.0% precision, and 69.9 AUC / 58.9% precision (NL&BBOX) vs JointNLT's 44.5% precision. The semi-reference-free tracking experiment further shows MambaVLT retains target information in its state space memory well enough to outperform UVLTrack-B under normal settings, validating the continuous temporal memory design.

## Relation to Prior Work

This paper extends the Mamba/SSM lineage (S4 → S5 → H3 → Mamba) and its visual adaptations (Vmamba, VideoMamba) into the vision-language tracking domain, where prior work has been dominated by Transformer-based architectures (JointNLT, QueryNLT, UVLTrack) that rely on discrete context prompts for temporal modeling. The key conceptual departure is replacing the discrete 'extract context prompt → decode' pipeline with a continuously evolving state space memory that autoregressively accumulates long-term target information across frames. The modality-guided bidirectional scan (text-first vs. template-first ordering) is a novel use of Mamba's scan directionality for adaptive reference feature updating, distinct from prior multi-directional scan approaches that use fully independent parameters per direction.

## Why It Matters / Open Questions

As the first Mamba-based vision-language tracker, this work demonstrates that linear-complexity state space models can effectively replace quadratic-attention Transformers for temporal multimodal tracking, which is practically important for long-video scenarios. The semi-reference-free tracking paradigm is a useful diagnostic for evaluating whether a tracker truly internalizes target identity versus relying on repeated reference lookups, though it is only qualitatively demonstrated here. Limitations include underperformance on LaSOT for BBOX-only tracking, the lack of quantitative benchmarks for the semi-reference-free setting, and the relatively modest gains over the strongest Transformer baseline (UVLTrack) on several datasets, leaving open whether the state space advantage grows with video length.

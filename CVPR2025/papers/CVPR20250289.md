## Problem

Existing drag-based image editing methods are confined to 2D plane manipulation and cannot achieve 3D object rotation. The optimization-based paradigm fails to handle the substantial feature changes caused by perspective shifts, while the training-based trajectory paradigm introduces ambiguity in whether the object translates or rotates along the drag path. This paper introduces the first drag-based 3D object rotation task, extending interactive editing from 2D to 3D space.
![Teaser figure](../imgs/CVPR20250289/cropped_page1_idx1.webp)

## Input / Output

The method takes a single 256×256 RGB image of an object (with or without background) and a double-point rotation trajectory specified as a sequence of point pairs [P₁₁,P₂₁], [P₁₂,P₂₂], …, [P₁ₙ,P₂ₙ]. Internally, 8 coherent frames from the trajectory are assembled as a video input to the SVD backbone. The output is a single novel-view image of the object from the perspective implied by the trajectory, generated in approximately 25 seconds. Unlike 3D generation baselines that require background removal, Dragin3D handles images with arbitrary backgrounds directly.

## Method

Dragin3D builds on Stable Video Diffusion with a ControlNet branch, using a double-point representation to map 3D object rotation onto a 2D line segment whose endpoints are tracked across views via camera intrinsic/extrinsic parameters. A Shape Distinguish Strategy assigns circular and square Gaussian heatmaps to the two tracking points, ensuring symmetric views produce distinct control signals. A Control Condition Inject Module extracts CLIP image embeddings from the first frame, projects them through a lightweight trainable mapping network, and replaces the Gaussian map features at the tracking-point locations with these object-specific features, so the control condition encodes both trajectory geometry and object identity. Only the mapping network and ControlNet parameters are optimized (20k steps, batch 6, lr 2e-5 on 8×A800), while SVD and CLIP remain frozen. Random backgrounds are affixed to the OmniObject3D training set to improve generalization to real-world images with complex scenes.

## Results

On the OmniObject3D test set (200 held-out objects), Dragin3D achieves FID 43.4, LPIPS 0.179, and FVD 584.6, outperforming SV3D (FID 52.5, LPIPS 0.410, FVD 944.6) across all three multi-view generation metrics. For drag trajectory accuracy on DragBench rotation cases, Dragin3D achieves an MD score of 9.38, substantially lower (better) than DragDiffusion's 33.01. In terms of functionality, Dragin3D is the only method that simultaneously supports multi-view generation, background-preserving editing, and fast inference (~25 s per generation).

## Baselines & Comparisons

Against SV3D, the closest multi-view generation baseline, Dragin3D wins on all three metrics: FID drops from 52.5 to 43.4 (−17%), LPIPS from 0.410 to 0.179 (−56%), and FVD from 944.6 to 584.6 (−38%), indicating substantially better image quality, perceptual similarity, and temporal consistency. Against DragDiffusion on the drag-accuracy MD metric, Dragin3D achieves 9.38 versus 33.01, a 3.5× improvement, showing far more precise control over rotation direction and magnitude. Against DragAnything, Dragin3D uniquely supports multi-view generation (DragAnything is limited to 2D translation) and is faster (~25 s vs. ~40 s), while both handle backgrounds. Against Wonder3D, Dragin3D adds background support (Wonder3D requires background removal) and is roughly 5× faster (~25 s vs. ~2 min), though Wonder3D produces higher-quality images on the six fixed views it was designed for. Overall, Dragin3D is the only method that combines multi-view rotation, background preservation, and interactive drag control in a single pipeline.

## Relation to Prior Work

This paper extends the drag-based image editing paradigm—previously confined to 2D point manipulation (DragGAN, DragDiffusion) or 2D trajectory following (DragAnything, DragNuwa)—into 3D space by formulating object rotation as a drag task. It builds on Stable Video Diffusion as the generative backbone and ControlNet for conditional injection, while adapting DragAnything's Gaussian-map control signal into a double-point representation with shape-distinguished encodings (circle vs. square) to disambiguate symmetric views. The key conceptual departure from prior drag methods is the explicit mapping of 3D rotational trajectory onto a 2D line-segment trajectory, combined with CLIP-based image feature injection to anchor the control condition to object identity.

## Why It Matters / Open Questions

Dragin3D is the first method to enable interactive 3D object rotation through simple point-dragging within a diffusion framework, and it generalizes to real-world images with complex backgrounds—a practical gap that prior 3D generation methods (SV3D, Wonder3D) cannot address. However, the current formulation is restricted to single-axis (z-axis) rotation, and the evaluation relies on a single synthetic dataset (OmniObject3D) with a modest 200-image test set, leaving open whether the approach scales to arbitrary 3D rotations, multi-object scenes, or larger-scale real-world deployment. The background-augmentation training trick is a simple but effective bridge between clean 3D datasets and messy real images, a strategy likely transferable to other view-synthesis tasks.

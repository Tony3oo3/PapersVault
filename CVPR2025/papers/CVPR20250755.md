## Problem

Existing 3D hand pose estimation methods are task-specific: HPE methods ignore hand-held objects while HOPE methods assume an object is always present, causing significant performance degradation when applied to the other scenario. No prior method can flexibly and robustly handle both hand-only and hand-object scenes within a single unified model.
![Teaser figure](../imgs/CVPR20250755/cropped_page0_idx0.webp)

## Input / Output

The method takes a single monocular RGB image (resized to 128×128) and always outputs 3D hand pose as MANO parameters plus 2D/3D joint and vertex coordinates. Object pose (2D keypoints with per-grid confidence scores) is output only when the internal object switcher predicts a positive grasping status (>95% accuracy). During training, a rendered hand depth map and hand-object mask are additionally consumed by the generative de-occluder to synthesize paired de-occluded images, but these are not required at inference.

## Method

UniHOPE builds on HFL-Net's dual-branch architecture and introduces three key mechanisms. First, an object switcher (MLP on FPN-extracted object features) predicts binary grasping status, gating the object pose branch at test time. Second, a grasp-aware feature fusion module uses the grasping confidence to selectively concatenate object features with hand features before a multi-head attention block, preventing irrelevant object-to-hand feature transitions in hand-only scenes. Third, for occlusion robustness, a ControlNet-based latent diffusion de-occluder (following Repaint's alternating-region reverse diffusion) generates realistic de-occluded hand images with adaptively selected control strengths, and multi-level self-distillation constraints (L1 losses at initial FPN, RoI, and MANO feature levels) transfer occlusion-invariant knowledge from de-occluded to occluded features, with occlusion-aware case filtering to exclude non-occluded samples.

## Results

On DexYCB (S3 split), UniHOPE achieves 13.03 mm J-PE and 12.59 mm V-PE across all scenes, outperforming the best HPE method (HandOccNet, 14.02 J-PE) and best HOPE method (HFL-Net, 14.32 J-PE). On HO3D, UniHOPE reaches 26.23 mm J-PE and 52.26% J-AUC, surpassing HFL-Net (28.45 J-PE, 50.34% J-AUC). In cross-dataset validation on FreiHAND, UniHOPE achieves 50.97 mm J-PE versus 58.02 mm for HFL-Net, demonstrating strong generalization to unseen bare-hand scenes. For object pose, UniHOPE attains 43.06% ADD-0.5D on unseen DexYCB objects, exceeding HFL-Net's 41.59%.

## Baselines & Comparisons

UniHOPE outperforms all seven baselines across every scene split on DexYCB. Against HPE methods, it improves J-PE by 0.99 mm over HandOccNet (13.03 vs. 14.02) and 1.75 mm over H2ONet (13.03 vs. 14.78) in the all-scenes setting. Against HOPE methods, it beats HFL-Net by 1.29 mm J-PE (13.03 vs. 14.32) and Keypoint Transformer by 6.13 mm (13.03 vs. 19.16). The strongest unified baseline (H2ONet†+HFL-Net‡, 14.12 J-PE) is surpassed by 1.09 mm, confirming that a single end-to-end model with an object switcher outperforms classifier-based model switching. On HO3D, UniHOPE leads HFL-Net by 2.22 mm J-PE and 1.92 points J-AUC. On FreiHAND (cross-dataset), the margin widens to 7.05 mm J-PE over HFL-Net, highlighting superior generalization to bare-hand scenes where object features are entirely absent.

## Relation to Prior Work

UniHOPE is architecturally derived from HFL-Net (Lin et al., CVPR 2023), adopting its dual-branch hourglass structure and hand-object feature interaction, but departs by adding an object switcher and grasp-aware feature fusion to handle the absence of objects. For the occlusion-robustness component, it repurposes the Repaint-style alternating-region inpainting mechanism within a latent diffusion framework (LDM + ControlNet) to synthesize paired de-occluded hand images, a creative application of generative models to pose estimation training data. Conceptually, the paper positions itself against the rigid HPE/HOPE dichotomy in prior work, arguing that the two tasks should be unified rather than treated as separate problems requiring separate models.

## Why It Matters / Open Questions

The unified formulation addresses a practical gap in VR/AR and HCI pipelines where a single model must handle both bare-hand and hand-held-object inputs without scene-specific model switching. The diffusion-based de-occlusion strategy for learning occlusion-invariant features is a transferable idea that could benefit other occlusion-robust estimation tasks. However, the approach relies on depth maps and hand-object masks for the de-occluder (not always available in the wild), the object pose estimation remains template-based (requiring known 3D models), and the evaluation is limited to relatively small-scale datasets (DexYCB, HO3D) with a single cross-dataset test (FreiHAND). Whether the unified framework scales to more diverse object categories or real-time deployment settings remains open.

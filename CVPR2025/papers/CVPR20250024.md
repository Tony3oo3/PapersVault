## Problem

Existing story visualization and subject-driven generation methods cannot simultaneously customize multiple characters across manga panels while dynamically adapting their expressions, poses, and motions to panel-specific text prompts. Subject-driven approaches produce rigid 'copy-paste' effects that limit expressive variation, and no large-scale dataset with multi-character, multi-state annotations existed to train such a system.
![Teaser figure](../imgs/CVPR20250024/cropped_page0_idx1.webp)

## Input / Output

For each manga panel, the model receives a text prompt describing the scene, one or more reference character images (compressed into a small set of tokens via a resampler rather than transferred at pixel level), per-character bounding boxes specifying layout positions, and dialogue bounding boxes for speech-bubble placement. The output is a single black-and-white manga panel image at variable resolution (handled via bucket-based grouping during training); dialogue text content is intentionally left to human post-editing, with the model only controlling bubble layout.

## Method

DiffSensei is a two-stage framework built on SDXL. In stage 1, a diffusion image generator is trained with (a) masked cross-attention injection that replicates key/value matrices so each character's compressed token features attend only to query positions within its bounding box (with a void placeholder elsewhere), and (b) a trainable dialog embedding added to the noised latent after the first convolution, masked by the dialog bounding box. Character features are extracted by CLIP plus a manga-specific encoder (Magi) and compressed by an IP-Adapter-style resampler into a few tokens per character. In stage 2, an MLLM (SEED-X) is fine-tuned via LoRA as a text-compatible character feature adapter: it takes source character tokens and the panel caption, and outputs adapted character tokens that reflect the narrative context. The MLLM is trained jointly with LM loss on special tokens, MSE loss against ground-truth target character features (leveraging cross-panel character ID annotations from MangaZero), and a diffusion loss through the frozen stage-1 generator, enabling characters to flexibly change expression and pose while preserving identity.

## Results

On the MangaZero evaluation set, DiffSensei achieves the best FID (0.407), DINO-I (0.618), DINO-C (0.651), and dialog F1 score (0.727) among all methods, with a CLIP score of 0.235. On the unseen-character Manga109 evaluation set, DiffSensei attains the highest F1 score (0.648) and competitive DINO-I (0.588) and DINO-C (0.600), demonstrating strong generalization to characters not seen during training. The closest competitor, MS-Diffusion†, trails by 0.008 in DINO-C and 0.007 in F1 on MangaZero, and by 0.047 in F1 on Manga109.

## Baselines & Comparisons

DiffSensei outperforms all five baselines on the MangaZero set in DINO-I, DINO-C, and F1 score, with the closest rival being MS-Diffusion† (DINO-C 0.641 vs. 0.651; F1 0.720 vs. 0.727). AR-LDM achieves the highest CLIP score (0.257) but suffers from poor character preservation (DINO-C 0.507) and near-zero dialog F1 (0.004), reflecting its inability to handle multi-character layout or dialog placement. SEED-Story and StoryDiffusion lag substantially on all character-related metrics (DINO-C ≤ 0.405 and 0.362 respectively), confirming their lack of explicit character control. On the Manga109 generalization set, DiffSensei maintains its F1 advantage (0.648 vs. 0.601 for MS-Diffusion†) while matching MS-Diffusion† on DINO-C (both 0.600), indicating robust transfer to unseen characters. In the human preference study, DiffSensei receives the highest ratings across overall preference, character consistency, and image quality, further validating its qualitative superiority over all baselines.

## Relation to Prior Work

DiffSensei builds on the IP-Adapter resampler architecture for compressing character images into a small set of tokens, and uses SDXL as the diffusion backbone. Its closest methodological ancestor is MS-Diffusion, which also performs multi-subject zero-shot personalization with layout guidance, but DiffSensei departs by inserting an MLLM (SEED-X) as a text-compatible character feature adapter that rewrites character tokens conditioned on panel captions, rather than feeding raw character features directly into cross-attention. The masked cross-attention injection for layout control is inspired by InstanceDiffusion and BoxDiff, but is applied here at the character-token level with a void placeholder for background regions. The broader story-visualization line (StoryDiffusion, AR-LDM, StoryGen, SEED-Story) is positioned as lacking explicit per-character control, which DiffSensei addresses through its multi-character conditioning pipeline.

## Why It Matters / Open Questions

The MangaZero dataset (43K pages, 427K panels with character IDs, bounding boxes, and dialog boxes) fills a clear gap: no prior large-scale manga dataset provides the multi-character, multi-state annotations needed to train text-adaptable character generation. The MLLM-as-adapter paradigm is a creative repurposing that could transfer to other domains requiring text-conditioned identity modification (e.g., multi-character animation, game asset generation). Open questions include whether the approach scales beyond the 48-series training set to truly diverse art styles, whether it extends to color manga or video/animation, and whether the modest quantitative gains over MS-Diffusion (CLIP +0.006, DINO-C +0.010) reflect a real qualitative advantage or are within noise for this task.

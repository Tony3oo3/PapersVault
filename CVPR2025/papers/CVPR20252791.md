## Problem

Existing learning-based point cloud sampling methods either generate entirely new point clouds (making results uninterpretable) or, as with APES, over-focus on edge points at the expense of global uniformity, degrading few-point sampling and making interpolation-based upsampling impractical. Moreover, all prior methods apply a uniform Top-M sampling strategy regardless of shape, ignoring the natural variation in point distribution (edge, close-to-edge, non-edge) across different geometries.

## Input / Output

The method takes raw 3D point cloud coordinates (no normals or colors) as input and produces a downsampled point cloud of a target size M. Internally, it computes point-wise sampling scores from a sparse attention map and learns per-shape bin sampling weights that determine how many points to draw from each score bin, enabling shape-specific allocation between edge and non-edge regions. The bin boundaries themselves are learned adaptively across the training set via momentum updates, so each shape's points are partitioned according to its own score distribution rather than fixed thresholds.

## Method

SAMBLE constructs a Sparse Attention Map (SAM) by computing a full global self-attention matrix and then zeroing out all cells except those corresponding to each point's k-nearest neighbors, yielding a sparse structure whose column-wise selection counts encode how frequently each point is chosen as a neighbor (a proxy for edge-ness). From this SAM, seven indexing modes (e.g., sparse column average, sparse column square-divided) compute point-wise sampling scores that balance local detail and global uniformity. Points are then partitioned into n_b bins using adaptively learned boundary values, and n_b learnable bin tokens are concatenated with point features during a cross-attention step; the resulting point-to-token attention sub-matrix, masked by bin membership, yields shape-specific sampling weights per bin. Within each bin, points are drawn via temperature-scaled softmax over their normalized scores, and a redistribution algorithm ensures the total sampled count matches the target M without exceeding any bin's capacity.

## Results

On ModelNet40 classification, SAMBLE achieves 94.2% overall accuracy, outperforming the previous best (93.8% by CurveNet, DeltaConv, and APES-global). On ShapeNet-Part segmentation, SAMBLE reaches 84.5% category mIoU and 86.7% instance mIoU, setting new state-of-the-art results. In the few-point sampling task (ModelNet40 with vanilla PointNet), SAMBLE achieves 89.45% at M=32, substantially outperforming APES without preprocessing (75.63%) and all other learning-based samplers (best: LighTN at 86.18%).

## Baselines & Comparisons

SAMBLE outperforms all 21 compared baselines on ModelNet40 classification, achieving 94.2% OA versus 93.8% for the strongest competitors (CurveNet, DeltaConv, APES-global). On ShapeNet-Part segmentation, SAMBLE leads in category mIoU (84.5% vs. 84.4% for PointNeXt) and ties PointNeXt and PointMetaBase on instance mIoU (86.7%), while surpassing APES-global by 0.8 points in Cat. mIoU. The most striking comparison is in few-point sampling: at M=32, SAMBLE scores 89.45% versus 75.63% for APES without its FPS preprocessing step, a 13.8-point gap, and still beats APES with preprocessing (88.56%) by 0.9 points. At M=512, SAMBLE (90.58%) slightly trails APES with preprocessing (90.81%) by 0.23 points, but surpasses it at every smaller sampling size. Against traditional methods (FPS, RS) and other learning-based samplers (S-Net, SampleNet, MOPS-Net, LighTN), SAMBLE dominates across all sampling sizes from 512 down to 32 points.

## Relation to Prior Work

SAMBLE builds directly on APES (Wu et al., CVPR 2023), which first introduced attention-based point-wise sampling scores for point cloud downsampling. It departs from APES in two key ways: (1) replacing the full attention map with a Sparse Attention Map that selectively retains only k-NN-neighbor cells, motivated by the observation that neighbor-selection frequency is asymmetric across points; and (2) replacing the uniform Top-M sampling strategy with a bin-based approach that learns shape-specific sampling weights per score bin. Earlier learning-based samplers (S-Net, SampleNet, MOPS-Net) generate entirely new point clouds, whereas SAMBLE, like APES, selects subsets of the original input points, preserving interpretability.

## Why It Matters / Open Questions

The shape-specific sampling strategy is a practical advance: by learning per-shape bin weights, SAMBLE avoids the one-size-fits-all bias of Top-M sampling and enables interpolation-based upsampling (unlike APES, which required a cross-attention upsampler). The few-point sampling results are particularly notable—SAMBLE retains ~89% accuracy at 32 points where APES without preprocessing drops to ~76%—suggesting the method's global uniformity preservation is critical in extreme compression regimes. Open questions include adaptation to point cloud scenes (beyond individual shapes), whether the bin-based mechanism generalizes to other downsampling architectures, and whether a more carefully designed upsampling layer could close the remaining gap to the full-resolution baseline.

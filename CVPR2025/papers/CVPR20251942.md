## Problem

Existing dehazing methods struggle with large, high-resolution images due to GPU memory constraints, forcing compromises like image slicing (which disrupts global context and causes block artifacts) or downsampling (which discards high-frequency details). Additionally, no ultra-high-resolution dehazing dataset existed prior to this work, limiting both training and evaluation at realistic resolutions.
![Teaser figure](../imgs/CVPR20251942/cropped_page0_idx0.webp)

## Input / Output

The method accepts a single hazy RGB image of arbitrary size (up to 10240×10240 pixels at inference, 8192×8192 in the 8KDehaze dataset) and produces a full-resolution dehazed image in one forward pass without slicing. During training, input pairs are randomly cropped to 2048×2048 pixels with a batch size of 2; at inference, the image is internally partitioned into fixed-size patches that are processed asynchronously in mini-batches to keep peak memory at ~21 GB (FP16) for 10K×10K inputs.

## Method

DehazeXL tokenizes the input image into uniform patches, each encoded by a shared Swin Transformer V2 encoder into a compact feature vector (token). A Bottleneck module built on Hyper Attention—incorporating locality-sensitive hashing and low-rank decomposition inspired by long-context LLM techniques—enables all tokens to attend to each other, injecting global haze distribution, color consistency, and brightness context into every local token. A Swin Transformer V2 decoder with Patch Expanding (transposed convolution) layers and skip connections from the encoder progressively upsamples tokens back to full patch resolution, which are then merged into the output image. Both encoder and decoder process patches sequentially in mini-batches rather than simultaneously, decoupling memory usage from total image size. The model is trained end-to-end with L1 loss using Adam (lr=0.001, cosine annealing) for 500 epochs on the newly constructed 8KDehaze dataset of 10,000 pairs of 8192×8192 aerial images synthesized via the atmospheric scattering model.

## Results

On the 8KDehaze dataset (8192×8192), DehazeXL achieves 32.35 PSNR and 0.9863 SSIM with an inference time of 4.62 s, outperforming the best baseline ConvIR-b (26.93 PSNR, 0.9775 SSIM) by 5.4 dB in PSNR. On 4KID (3840×2160), it reaches 26.62 PSNR / 0.9073 SSIM in 0.59 s, surpassing MixDehazeNet-b (23.22 PSNR) by 3.4 dB. On the real-world O-HAZE dataset, DehazeXL attains 21.49 PSNR / 0.7348 SSIM in 0.86 s, leading the next-best MixDehazeNet-b (20.67 PSNR) by 0.8 dB while also being the fastest method evaluated.

## Baselines & Comparisons

DehazeXL achieves the highest PSNR and SSIM on all three datasets while also being the fastest or near-fastest method. On 8KDehaze, it leads ConvIR-b (the strongest baseline) by 5.4 dB PSNR and 0.0088 SSIM, and is 1.9× faster (4.62 s vs 8.71 s); the gap widens dramatically against slicing-based methods like MB-TaylorFormer (26.41 PSNR, 120.5 s) and C2PNet (26.17 PSNR, 43.3 s). On 4KID, DehazeXL surpasses MixDehazeNet-b by 3.4 dB PSNR and is 3.5× faster (0.59 s vs 2.06 s), while 4KDehazing's direct-inference mode (the only other method supporting large-image inference) drops to 18.68 PSNR, a 7.9 dB deficit. On the real-world O-HAZE set, the margin narrows to 0.8 dB over MixDehazeNet-b, but DehazeXL still leads in SSIM (0.7348 vs 0.7293) and inference speed (0.86 s vs 2.59 s). Notably, 4KDehazing's direct-inference mode suffers severe degradation on 8KDehaze (20.41 PSNR vs 25.81 with slicing), confirming that simply avoiding slicing without proper global context modeling is insufficient.

## Relation to Prior Work

DehazeXL extends the patch-tokenization paradigm from Vision Transformers to the dehazing domain, but departs from standard ViT by treating each spatial patch as a token for a global attention bottleneck rather than processing the full image in one forward pass. The global attention mechanism draws directly from long-context LLM techniques (Hyper Attention with locality-sensitive hashing and low-rank decomposition), repurposing them to inject scene-wide haze and color context into local patch features. For interpretability, the Dehazing Attribution Map adapts the Integrated Gradients formulation (Sundararajan et al.) and the Local Attribution Map framework (Gu & Dong) to the specific structure of dehazing, using a pixel-intensity detector and a clear-image baseline.

## Why It Matters / Open Questions

The 8KDehaze dataset (10,000 pairs at 8192×8192) is the first ultra-high-resolution dehazing benchmark and will likely become a standard resource for evaluating large-image restoration methods. The patch-tokenization architecture offers a practical recipe for decoupling GPU memory from input resolution, a pattern potentially transferable to other restoration tasks (denoising, super-resolution) on very large images. Open questions include whether the synthetic haze generation (atmospheric scattering model) adequately captures real-world haze variability at 8K scale, whether the approach generalizes to video or multi-spectral dehazing, and whether the inference-time cost of sequential patch processing becomes prohibitive at even larger resolutions.

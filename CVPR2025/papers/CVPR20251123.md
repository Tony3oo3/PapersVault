## Problem

Existing adversarial attacks optimize a single surrogate loss function, and while multi-loss approaches have been explored, they lack a systematic, scalable framework for coordinating multiple loss functions without introducing additional hyperparameters. There is no principled method to determine which subsets of loss functions are synergistic, making it difficult to reduce the number of objectives while preserving attack efficacy.
![Teaser figure](../imgs/CVPR20251123/cropped_page2_idx1.webp)

## Input / Output

The method takes a clean RGB image with its ground-truth label, an ℓ∞ perturbation budget ε, and a set of m surrogate loss functions (8 in the MOS-8 variant), and produces a set of K adversarial perturbations (K ≤ m) along with identified loss synergistic patterns. The perturbations are individually projected onto the ℓ∞-ball, and the synergistic patterns are binary contribution vectors indicating which loss functions each dominant perturbation jointly maximizes, enabling construction of reduced-objective attacks like MOS-3*.

## Method

MOS Attack formulates multi-objective adversarial attack as a smooth set-based optimization problem: K adversarial examples (K < m) collectively maximize m surrogate losses via a Tchebycheff-style objective where each loss is maximized over the set, then smoothed using log-sum-exp approximations of max and min operators to ensure differentiability and avoid oscillation. The resulting objective is optimized with APGD's momentum-based update rule, extended with a set-based projection operator that constrains each perturbation individually within the ℓ∞-ball. A key geometric insight is that the set of K examples defines a 'virtual adversarial example' whose dimensions are the per-loss best values, which is pushed toward Pareto-optimal contour points. For pattern mining, a bi-objective problem (minimize optimization gap + minimize ℓ₀ norm of selected examples) is relaxed to a smooth ℓ₁-regularized formulation solved by gradient descent, yielding dominant perturbations whose loss contribution profiles define the synergistic patterns.

## Results

On CIFAR-10 (ε=8/255), MOS-8(5) achieves an average rank of 1.33 across 12 models, outperforming APGD-CE(5) by +1.85 to +3.51 percentage points in Attack Success Rate (ASR). On ImageNet (ε=4/255), MOS-8(5) achieves an average rank of 1.60 across 5 models, beating APGD-CE(5) by +2.02 to +3.87 pp. Notably, MOS-8(5) matches or exceeds the APGD-All ensemble (which uses 8 separate attacks) while using only 5 adversarial examples, and the ACG-CW attack (100 steps, 5 restarts) wins in only 3 out of 17 model configurations.

## Baselines & Comparisons

Against APGD-CE (Croce & Hein, ICML 2020), MOS-8(5) wins on all 17 model configurations, improving ASR by +1.85 to +3.87 percentage points (e.g., 44.18% vs. 41.76% on ResNet-18 CIFAR-10; 74.52% vs. 70.74% on ResNet-18 ImageNet). Against ACG-CW (Yamamura et al., ICML 2022), which uses 100 attack steps and conjugate gradient optimization, MOS-8(5) wins on 14 out of 17 configurations; ACG-CW only achieves the best ASR in 3 CIFAR-10 cases and none on ImageNet. Against the APGD-All ensemble (8 separate APGD attacks with different loss functions, 1 restart each), MOS-8(5) achieves comparable or slightly better results while using only 5 adversarial examples versus 8, yielding an average rank of 1.33 vs. 1.67 on CIFAR-10. The paper further shows that a reduced MOS-3* attack (3 loss functions selected via synergistic pattern mining) matches MOS-8(5) performance with K=1, confirming that the multi-objective framework identifies which loss combinations are most effective.

## Relation to Prior Work

This paper builds directly on the APGD attack framework (Croce & Hein, ICML 2020) for its gradient-based optimization engine, and on the Tchebycheff set scalarization and smooth Tchebycheff scalarization formulations (Lin et al., 2024) for its multi-objective optimization backbone. It departs from prior multi-loss adversarial attacks (e.g., alternating loss functions in Antoniou et al., or targeted-loss ensembles in Gowal et al.) by providing the first systematic, parameter-free multi-objective formulation that simultaneously optimizes K < m adversarial examples against m surrogate losses via a smooth set-based objective. The automated synergistic pattern mining is a novel analytical layer not present in any prior adversarial attack work.

## Why It Matters / Open Questions

The framework offers a scalable, extensible template for multi-objective adversarial attacks where adding new loss functions requires no additional hyperparameters, and the discovery that ~60% of adversarial examples simultaneously maximize all eight losses reveals a low-conflict structure that justifies the approach. The MOS-3* result—three carefully selected losses matching eight-loss performance—provides a practical recipe for reducing computational cost without sacrificing attack strength. Open questions include whether the framework extends to black-box or targeted settings, whether synergistic patterns transfer across domains or model families beyond the tested architectures, and whether the smooth set-based formulation can be adapted to other multi-objective security problems beyond adversarial examples.

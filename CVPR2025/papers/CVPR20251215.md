## Problem

Negative prompts in text-to-image diffusion models are typically handcrafted through trial-and-error over discrete language space, yielding suboptimal results. No prior work has learned negative embeddings directly via gradient-based optimization in the continuous text embedding space, nor has it integrated classifier-free guidance into the training loop to enable reward-guided gradient flow to the negative embedding.

## Input / Output

The method takes a positive text prompt and a negative embedding vector (initialized from the null-text embedding in the CLIP text encoder's output space) as input, and produces an optimized negative embedding of the same dimensionality. The global negative embedding is a single shared vector trained on 10,000 prompts, while the per-sample variant further adapts this vector to a specific prompt in ~10 additional steps. Because the output is just a vector in the text encoder's embedding space, it transfers seamlessly to any model sharing that encoder (e.g., SD1.5 → ControlNet, ZeroScope, VideoCrafter2) without retraining.

## Method

ReNeg treats the negative embedding as a set of learnable parameters and optimizes it via gradient descent guided by an image reward model (HPSv2.1). The key technical enabler is incorporating classifier-free guidance into the training process (previously used only at inference), which makes the gradient with respect to the negative embedding tractable. At an intermediate denoising timestep t (randomly sampled from [0,10] out of T=30), a one-step prediction x̂₀ is computed and the reward model scores it; gradients backpropagate through x̂₀ to update only the negative embedding while all other model weights remain frozen. A deterministic DDIM ODE solver is used for the T→t sampling to improve x̂₀ accuracy. A per-sample variant then fine-tunes the global embedding for each prompt with early stopping (patience P=3, max N=10 steps), guaranteeing it never underperforms the global embedding.

## Results

On the HPSv2 benchmark, ReNeg with per-sample negative embedding achieves 29.84 HPSv2.1 score, outperforming the best full-finetuning baseline TextCraftor (28.36) and the handcrafted negative prompt baseline SD1.5+N* (26.79) by 1.48 and 3.05 points respectively. On Parti-Prompts, ReNeg per-sample reaches 19.97 PickScore and 5.50 Aesthetic, again leading all baselines. The global negative embedding already achieves 29.16 HPSv2.1, surpassing all prompt-refinement and RL-based methods without any per-prompt adaptation.

## Baselines & Comparisons

ReNeg (per-sample) achieves 29.84 HPSv2.1, beating the strongest full-finetuning baseline TextCraftor (28.36) by 1.48 points while requiring only a single 768-dim vector instead of full UNet weight updates. Against prompt-refinement methods, ReNeg leads by a wide margin: over BeautifulPrompt (22.72) by 7.12 points, over Promptist (25.24) by 4.60 points, and over DNP (25.83) by 4.01 points. Among RL/preference-optimization baselines, ReNeg outperforms Diffusion-DPO (26.62) by 3.22 points, ReFL (27.97) by 1.87 points, and both DDPO variants (20.69/19.00) by 9+ points. The handcrafted negative prompt (SD1.5+N*, 26.79) is surpassed by 3.05 points, confirming that learned embeddings substantially outperform community-curated negative terms. Notably, ReNeg's global embedding (29.16) already exceeds all baselines without any per-prompt adaptation, and the per-sample variant adds a further 0.68-point gain at negligible cost (10 additional optimization steps).

## Relation to Prior Work

ReNeg builds directly on the reward feedback learning (ReFL) framework from ImageReward [39] and the classifier-free guidance (CFG) mechanism from Ho & Salimans [14], but departs from both in a key way: it incorporates CFG into the training loop (previously inference-only) so that gradients from the reward model can flow to a single negative embedding vector. This contrasts with prior negative-prompt approaches that search in discrete language space (DPO-Diff [33], DNP [9]) or require full-model fine-tuning (DDPO [2], Diffusion-DPO [31], TextCraftor [21]). The paper's Jacobian-based parameter-efficiency analysis provides a novel conceptual justification for why a single embedding vector is a more 'efficient' tuning target than the full model or LoRA adapters, framing negative embeddings as a lightweight alternative to parameter-level optimization.

## Why It Matters / Open Questions

The practical impact is significant: a single learned embedding vector (negligible storage cost) rivals or exceeds full UNet fine-tuning methods on human-preference benchmarks, and transfers seamlessly across any model sharing the same CLIP text encoder (demonstrated on ControlNet, ZeroScope, and VideoCrafter2). This makes it an attractive drop-in improvement for practitioners who cannot afford retraining. However, the method remains bounded by the base model's generative capacity and can exhibit semantic deviations from the prompt, and the per-sample optimization (10 steps per prompt) adds inference latency. Open questions include whether the approach generalizes to models with different text encoders and whether the reward model's biases (e.g., HPSv2.1's aesthetic preferences) are faithfully captured in the learned embedding.

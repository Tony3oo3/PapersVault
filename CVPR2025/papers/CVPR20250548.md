## Problem

In domain-incremental learning with pre-trained models, sequential updates overwrite both the backbone and classifier with the latest domain's knowledge, causing catastrophic forgetting of previous domains. Existing prompt-based PTM methods mitigate this by freezing the backbone, but the appended prompt modules still get overwritten across domains, leaving both feature-level and classifier-level forgetting unresolved.
![Teaser figure](../imgs/CVPR20250548/cropped_page4_idx0.webp)

## Input / Output

The method consumes RGB images from a stream of domains (e.g., real photos, clip art, sketches) under an exemplar-free setting where only the current domain's training data is accessible. It uses a ViT-B/16 backbone to extract the [CLS] token as a d-dimensional embedding, and a per-domain expanded cosine classifier (W ∈ R^{d×b|Y|}) to produce a class label via argmax over domain-specific weights followed by mod |Y|. The label space remains fixed across all domains; only the input distribution shifts.

## Method

DUCT performs dual consolidation at both the representation and classifier levels. For representation consolidation, it fine-tunes the pre-trained ViT on each incoming domain, computes the task vector (δ_φ = φ_i − φ_0), and additively merges all historical task vectors weighted by task similarity (cosine similarity of per-class centers in the frozen PTM space) to build a unified embedding that captures domain-specific features for all seen tasks. For classifier consolidation, it first retrains the new domain's classifier on the frozen consolidated features, then estimates the old classifier in the new embedding space via an optimal transport mapping: the Kantorovich transport plan is solved with Sinkhorn's algorithm using a cost matrix defined by squared Euclidean distances between class centers in the PTM space, and the transported classifier is interpolated with the original old classifier. This coordinated merging of backbones and classifiers requires storing at most two models in memory and yields a single unified model at inference time.

## Results

DUCT achieves state-of-the-art performance across all four DIL benchmarks with ViT-B/16 IN1K, reporting average accuracy (A̅) and final-stage accuracy (A_B). On Office-Home, DUCT reaches 86.27/86.91, outperforming the runner-up CODA-Prompt (84.70/85.07) by ~1.5%. On CORe50, DUCT attains 91.95/94.47, surpassing CODA-Prompt (87.92/91.57) by ~3%. On DomainNet and CDDB-Hard, DUCT leads with 67.16/67.01 and 84.14/85.10 respectively, exceeding the best competitors (S-iPrompt at 61.16/60.46 and RanPAC at 78.92/80.48) by 5–6%. Overall, DUCT outperforms all compared methods by 1–7% in final accuracy.

## Baselines & Comparisons

DUCT outperforms all 10 baselines on every dataset. Among prompt-based methods, CODA-Prompt is the strongest competitor, trailing DUCT by 1.57% on Office-Home (85.07 vs. 86.91 A_B), 7.02% on DomainNet (59.99 vs. 67.01), 2.90% on CORe50 (91.57 vs. 94.47), and 10.92% on CDDB (74.18 vs. 85.10). S-iPrompt, the best DIL-specific prompt method, lags DUCT by 6.45% on DomainNet (60.46 vs. 67.01) and 12.34% on CORe50 (83.38 vs. 94.47). RanPAC, which uses random projections rather than prompts, is the closest competitor on CDDB (80.48 vs. 85.10, a 4.62% gap) but falls behind on all other datasets. Exemplar-based methods (Replay, iCaRL, MEMO) show high variance across task orders (e.g., Replay on CDDB: 63.21±11.6) and are consistently outperformed by DUCT, which operates in the exemplar-free setting. DUCT also demonstrates the lowest forgetting measure (0.12) on CDDB, confirming its advantage in retaining prior domain knowledge.

## Relation to Prior Work

DUCT builds directly on the task arithmetic framework (Ilharco et al., ICLR 2023) for merging fine-tuned backbones, extending it with task-similarity-weighted accumulation (Eq. 7) to better balance domain-specific features. It departs from the dominant prompt-based DIL paradigm (L2P, DualPrompt, CODA-Prompt, S-iPrompt), which freezes the pre-trained backbone and relies on lightweight prompt modules that still suffer from sequential overwriting. The classifier consolidation via optimal transport (Peyré & Cuturi; Villani) is a novel application of the Kantorovich formulation to the problem of aligning old-domain classifiers with a shifting embedding space, using class-center distances in the pre-trained space as the transportation cost.

## Why It Matters / Open Questions

By addressing both representation-level and classifier-level forgetting in a unified framework, DUCT provides a principled recipe for exemplar-free DIL that avoids the prompt-overwriting problem inherent in prior PTM-based methods. The reliance on pre-trained model generalizability for both task-similarity estimation and semantic-guided transport is a clear limitation, and the authors explicitly note that extending to non-PTM scenarios remains open. The technique is lightweight (only two backbones in memory, standard SGD training) and the consistent 1–7% gains across four diverse benchmarks suggest broad practical applicability for streaming domain adaptation.

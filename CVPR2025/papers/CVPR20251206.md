## Problem

Most FSCIL methods rely on nearest-neighbor prototype classification with a frozen feature extractor, making them susceptible to the hubness phenomenon in high-dimensional feature spaces. The paper provides the first theoretical analysis showing that base class prototypes systematically become hubs under cosine distance, disproportionately attracting nearest-neighbor assignments and degrading incremental class accuracy. Prior approaches address this only through biased feature-space optimizations without tackling the underlying metric and distributional causes.

## Input / Output

The method operates on RGB images in a standard FSCIL protocol: a base session with sufficient samples across many classes (e.g., 60 base classes on miniImageNet/CIFAR-100, 100 on CUB-200), followed by incremental sessions in N-way K-shot format (e.g., 5-way 5-shot). The feature extractor is frozen after base training; incremental classification is performed by matching test features against class prototypes. The output is a single class label per image, predicted via a modified distance metric rather than the original cosine similarity.

## Method

D2A addresses hubness from two complementary angles. For diminishing attraction, it replaces the pure cosine distance at inference with a weighted blend of cosine and Manhattan distances (Eq. 11), where the blending weight γ is dynamically set via tanh of the MMD between base and incremental prototype distributions (Eq. 13), so the metric alteration intensifies when incremental classes are closer to base classes. For distributing attraction, it augments the base-session training loss with a gap loss (L_gap) that pushes interpolated samples between class boundaries to be classified by both adjacent classes, thereby seeding additional component distributions in the feature space. A random nearest-neighbor sampling strategy (Algorithm 1) selects which cross-class pairs form gap samples, balancing proximity to existing clusters with diversity to avoid over-concentrating on the same boundary regions.

## Results

On miniImageNet (60 base classes, 8 incremental sessions of 5-way 5-shot), applying D2A to SAVC yields the best overall accuracy of 57.72% and the best last-session incremental accuracy of 36.33%, surpassing M2SD (56.51% overall) and CLOSER (53.33% overall). D2A consistently improves every baseline it is applied to: Decoupled-Cosine gains +3.41% overall (45.92→49.33), CEC gains +3.71% (47.63→51.34), and CLOM gains +0.59% (47.95→48.54). The method is evaluated on three datasets (miniImageNet, CIFAR-100, CUB-200) with consistent gains in both incremental and overall accuracy across all settings.

## Baselines & Comparisons

D2A is applied as a plug-in to four incremental-frozen baselines (Decoupled-Cosine, CEC, CLOM, SAVC) and consistently improves both incremental and overall accuracy over each. The largest absolute gain is on SAVC (+1.75% overall, +9.20% incremental in the last session), where D2A pushes overall accuracy from 55.97% to 57.72%, surpassing M2SD (56.51%) which does not use D2A. Against CLOSER (53.33% overall, 25.78% incremental), SAVC+D2A leads by +4.39% overall and +10.55% incremental. TEEN (52.08%) and Bidist (52.22%) are outperformed by all D2A-augmented variants except CLOM+D2A (48.54%). OSHHG (46.75%) and EHS (49.06%) trail all D2A results. The paper notes that even SAVC, which already adapts to incremental classes via virtual contrastive constraints, benefits substantially from D2A, confirming that hubness mitigation is orthogonal to existing adaptation strategies.

## Relation to Prior Work

This paper builds on the classical hubness theory of Radovanovic et al. (2010), which characterizes how nearest-neighbor counts concentrate on a small subset of points in high-dimensional spaces, and connects it to the neural collapse phenomenon (Papyan et al., 2020) to explain why base class prototypes become hubs in FSCIL. It departs from prior FSCIL methods (e.g., SAVC, TEEN, C-FSCIL) that address incremental class underperformance through feature-space manipulations such as augmentation, fine-tuning, or prototype adjustment, by instead targeting the distance metric used at inference and the component structure of the output distribution during base training. The D2A method is designed as a plug-and-play module that layers on top of existing incremental-frozen FSCIL baselines (Decoupled-Cosine, CEC, CLOM, SAVC) without modifying their core architectures.

## Why It Matters / Open Questions

By identifying hubness as a fundamental, previously unacknowledged cause of incremental class degradation in FSCIL, the paper reframes the problem from a feature-quality issue to a metric-and-distribution-structure issue, offering a theoretically grounded and broadly applicable remedy. The plug-and-play design means practitioners can adopt the metric alteration (Eq. 11) or the gap-sample training loss (Eq. 15) with minimal engineering effort across many existing pipelines. Limitations include the restriction to the incremental-frozen paradigm (the feature extractor must remain frozen), the inapplicability of the Distributing Attraction component to fine-grained datasets with complex feature extractors (e.g., CUB200 with CLOM/SAVC), and the fact that the metric alteration is evaluated only with a small set of Lp and related distances. Open questions include whether the MMD-based adaptive γ generalizes to non-i.i.d. or out-of-distribution test data, and whether the gap-sample strategy remains effective as the number of incremental sessions grows very large.

## Problem

Open World Object Detection (OWOD) and Open Vocabulary Object Detection (OVD) address complementary but distinct challenges: OVD provides zero-shot generalization to new class names but cannot actively discover unannotated objects, while OWOD detects unknowns through incremental learning but lacks zero-shot inference. No prior detector unifies both capabilities, leaving the combined problem of open-world and open-vocabulary detection largely unexplored.
![Teaser figure](../imgs/CVPR20250234/cropped_page0_idx0.webp)

## Input / Output

The detector takes an RGB image and a set of text prompts (known class names) as input, processed through a CLIP-based text encoder and a YOLO-World visual backbone. It outputs bounding boxes labeled with known class categories alongside a parallel unknown-object score for each detection. Crucially, the unknown prediction is computed in a separate branch that does not modify the standard OVD inference pipeline, so adding new class names at test time requires no retraining.

## Method

OW-OVD builds on YOLO-World and introduces two key components. First, Visual Similarity Attribute Selection (VSAS) uses GPT-3.5 to generate descriptive attribute sentences for known classes, then selects the most generalizable subset by computing similarity distributions of each attribute against positive and negative visual embeddings (split via task-aligned assignment scores) and minimizing Jensen-Shannon Divergence between the two distributions, with a cosine-similarity penalty to enforce diversity among selected attributes. Second, Hybrid Attribute-Uncertainty Fusion (HAUF) predicts unknown objects by combining a top-gamma weighted attribute similarity score (distinguishing objects from background) with the entropy of known-class predictions (measuring model uncertainty), then gating by the complement of the maximum known-class confidence to suppress false unknowns. This parallel formulation preserves the standard OVD matching logic for known classes while adding an independent unknown-detection signal.

## Results

On the S-OWODB benchmark, OW-OVD achieves 76.2 U-Recall (Task 1) and 78.6 mAP, outperforming the previous best (SKDF: 60.9 U-Recall, 69.4 mAP) by +15.3 U-Recall and +9.2 mAP. Under the stricter U-mAP metric, OW-OVD reaches 23.0 (Task 1) versus 7.5 for MEPU-FS, a +15.5 gap. On M-OWODB, OW-OVD attains 50.0 U-Recall and 69.4 mAP in Task 1, doubling the U-Recall of ORTH (24.6) and surpassing KTCN (41.5) by +8.5. For incremental detection on PASCAL VOC, OW-OVD achieves 87.2 mAP (10+10 split), exceeding ORTH (72.3) by +14.9 AP.

## Baselines & Comparisons

OW-OVD outperforms all 15 baselines across both OWOD benchmarks and the incremental detection task. Among traditional OWOD methods (ORE, OW-DETR, PROB, CAT, RandBox, ORTH, Hyp-OW), OW-OVD leads by a wide margin: on S-OWODB Task 1, it exceeds ORTH by +51.6 U-Recall (76.2 vs 24.6) and CAT by +52.2 (76.2 vs 24.0). Among foundation-model-based methods, OW-OVD surpasses SKDF by +15.3 U-Recall (76.2 vs 60.9) and +16.3 mAP (78.6 vs 69.4) on S-OWODB Task 1, and beats KTCN by +8.5 U-Recall on M-OWODB Task 1. Under the stricter U-mAP metric (Table 2), OW-OVD achieves 23.0 on S-OWODB Task 1 versus 7.5 for MEPU-FS and 6.1 for SKDF, a gap of +15.5 and +16.9 respectively. For incremental detection on VOC (Table 3), OW-OVD achieves 87.2/86.9/86.8 mAP across the 10+10, 15+5, and 19+1 splits, outperforming ORTH (72.3/74.7/75.6) by +14.9/+12.2/+11.2 AP, and notably shows only 0.4 AP variance across splits versus 6.1 AP variance for PROB, indicating robustness to the number of known classes.

## Relation to Prior Work

This paper builds directly on YOLO-World as its base OVD detector and borrows the LLM-based attribute generation idea from FOMO (Zohar et al., 2023). However, it departs from FOMO's core mechanism—linear scaling of attribute similarity for unknown prediction—which the authors argue compromises OVD's zero-shot inference. Instead, OW-OVD introduces VSAS (selecting generalizable attributes via Jensen-Shannon Divergence between positive/negative similarity distributions) and HAUF (fusing attribute similarity with known-class uncertainty in parallel), positioning itself as the first unified framework that simultaneously supports both open-vocabulary and open-world detection without sacrificing either capability.

## Why It Matters / Open Questions

By unifying OWOD and OVD, this work addresses a practical gap: real-world deployment requires both the ability to detect arbitrary named categories (zero-shot) and to proactively flag unannotated objects for incremental annotation. The demonstrated insensitivity to the number of known classes (0.4 AP gap across splits vs. 6.1 for PROB) suggests the approach scales more gracefully to open environments with many categories. Limitations include evaluation restricted to COCO+VOC-based benchmarks, dependence on GPT-3.5 for attribute generation, and the iterative attribute selection adding training overhead. Open questions include whether the method generalizes to larger-scale datasets (e.g., LVIS, Open Images) and whether the LLM-generated attribute quality is a bottleneck for truly novel domains.

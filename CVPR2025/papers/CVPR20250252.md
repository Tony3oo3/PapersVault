## Problem

Online continual learning (OCL) frameworks must process high-frequency streaming data in real time while operating under varying memory budgets, yet existing OCL-specific frameworks either lack general applicability or fail to simultaneously minimize processing latency and maximize hardware utilization within memory constraints. This paper addresses the gap of achieving high online accuracy across diverse memory budgets by co-optimizing pipeline scheduling and memory management at the framework level, rather than relying solely on algorithmic improvements.
![Teaser figure](../imgs/CVPR20250252/cropped_page3_idx0.webp)

## Input / Output

The framework consumes high-frequency streaming data pairs (x, y) with time-sensitive, exponentially decaying value, along with a user-specified memory budget M. Data is discarded immediately after being used to update the model, reflecting the OCL setting where no historical data is retained. The system outputs updated model parameters θ^t, real-time predictions for incoming data, and an automatically determined optimal model partition scheme L* and pipeline configuration C* that maximize the Adaptation Rate under the memory constraint.

## Method

Ferret employs a fine-grained asynchronous pipeline parallelism strategy with 1F1B scheduling, deploying N workers that process interleaved data streams concurrently to minimize end-to-end latency. To manage memory under varying budgets, it combines four techniques—activation recomputation, gradient accumulation, back-propagation omission, and worker removal—each controlled by binary or integer parameters in a configuration vector C. To counteract stale gradients inherent in asynchronous parallelism, Ferret introduces an iterative gradient compensation algorithm that approximates ∇L(D^{t-1}; θ^{t+τ-1}) from ∇L(D^{t-1}; θ^{t-1}) by iteratively applying a first-order Taylor expansion with a diagonal Fisher information matrix approximation, and automatically optimizes the scaling hyperparameter λ via a regularized least-squares objective using exponential moving averages. The model partition scheme L* and pipeline configuration C* are jointly determined by solving a bi-level optimization problem: the inner loop iteratively deploys memory-saving techniques (T1–T4) to find the best C for a given L, while the outer loop brute-forces over a small solution space of consecutive-layer groupings to find the globally optimal L.

## Results

Ferret achieves up to 3.7× lower memory overhead to reach the same online accuracy compared to competing methods. In the pipeline parallelism comparison (Table 3, agm metric with DAPPLE as baseline), Ferret^M consistently leads: e.g., 7.13±0.18 on CORe50/ConvNet vs. Pipedream (6.03±0.17) and Pipedream_2BW (5.91±0.12), and 7.42±0.69 on CLEAR100/MobileNet vs. Pipedream (5.66±0.19). Ferret^M+ (unconstrained memory) achieves performance comparable to the Oracle (ideal sequential processing) across all 20 settings. The Iter-Fisher gradient compensation algorithm consistently improves online accuracy over Step-Aware, Gap-Aware, and Fisher baselines without requiring manual hyperparameter tuning.

## Baselines & Comparisons

Against the 1-Skip baseline (Table 1), Ferret^M and Ferret^M+ consistently achieve the highest agm scores across all 20 dataset/model settings, with Ferret^M+ reaching performance comparable to the Oracle (ideal sequential processing with zero delay). Compared to Camel [46], Ferret outperforms it across diverse memory budgets, while Camel's dedicated forgetting-mitigation component cannot be integrated with other OCL algorithms. In the pipeline parallelism comparison (Table 3), Ferret^M surpasses Pipedream, Pipedream_2BW, DAPPLE, Zero-Bubble, and all Hanayo variants (1W/2W/3W) on every setting, with the largest margins on CORe50/ConvNet (+1.10 over Pipedream) and CLEAR100/MobileNet (+1.76 over Pipedream). For gradient compensation (Table 4), Iter-Fisher consistently improves online accuracy over Step-Aware, Gap-Aware, and Fisher (Sapipe), whereas Step-Aware and Gap-Aware actually degrade performance significantly (e.g., −56.04 agm on MNIST) due to their simple step-size penalization approach. Ferret^M− (minimal memory) shows slightly lower agm than its counterparts but is the only method capable of learning under severely constrained memory, as illustrated in Fig. 4.

## Relation to Prior Work

This paper transplants pipeline parallelism techniques from distributed DNN training (Pipedream, DAPPLE, Hanayo) into the online continual learning setting, a combination not previously explored. The iterative gradient compensation algorithm builds on asynchronous SGD with delay compensation [85], but fixes the staleness window τ to 1 and introduces an automatic λ optimization via Fisher information matrix approximation to handle the varying staleness across pipeline stages. It departs from existing OCL frameworks (Camel, LifeLearner, Kraken) that either sacrifice latency for hardware utilization or lack general applicability, by jointly optimizing adaptation rate and memory footprint through a bilevel optimization over model partitioning and pipeline configuration.

## Why It Matters / Open Questions

Ferret addresses a practically critical gap: real-time OCL on resource-constrained devices where memory budgets vary and data arrives at high frequency. The 3.7× memory efficiency gain and the ability to remain the only viable method under severe memory constraints (Ferret_M-) make it directly relevant for edge and streaming applications. Open questions include whether the bilevel optimization and gradient compensation scale to much larger models (e.g., transformer-based), whether the exponential data-value decay assumption holds in all real-world streams, and how the framework performs under non-i.i.d. distribution shifts more extreme than those in the CLEAR benchmark.

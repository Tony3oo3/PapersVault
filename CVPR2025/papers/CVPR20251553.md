## Problem

Existing image realism evaluation methods produce only holistic, image-level scores without object-specific or aspect-specific (shape vs. texture) breakdowns. Unlike text-image alignment, which can anchor evaluation to semantic concepts in a prompt, image realism lacks a natural decomposition mechanism, making it difficult to identify which objects or which visual aspects (geometry vs. surface appearance) are unrealistic in a generated image.
![Teaser figure](../imgs/CVPR20251553/cropped_page1_idx0.webp)

## Input / Output

The model consumes three inputs simultaneously: the full RGB image (providing global scene context), a bounding-box crop of the target object (providing local detail), and the object category name as a text prompt (e.g., 'SOFA', 'SHIRT'). It outputs three continuous scores in the 1–5 range — shape realism, texture realism, and joint realism — each corresponding to the Likert-scale ratings collected from human annotators. The dual full-image-plus-crop input is unusual compared to prior IQA methods that use only a single crop or the whole image.

## Method

OLIP uses a frozen BLIP backbone to extract 512-dimensional multi-modal embeddings for both the full image and the object crop, with the object category name as the text prompt. Three dedicated multi-head attention heads (Shape, Texture, Joint) each take the full-image embedding as query and the crop embedding as key/value, allowing the model to attend to local object details conditioned on global scene context. Each attention head feeds into a separate 4-layer MLP regression projector (1024→768→384→1) with layer normalization and dropout, whose scalar output is mapped to the 1–5 range via a scaled sigmoid. The model is trained end-to-end (only the attention heads and MLPs are trainable) with MSE loss using AdamW (lr=1e-4, cosine annealing, weight decay 0.01). Ablations confirm that each design choice — full-image query, separate per-aspect heads, and the deeper (non-linear) projection — contributes 6–10% accuracy, with the full architecture achieving MAE 0.118 and ACC 0.539 on joint realism, substantially outperforming all baselines.

## Results

On the OcR dataset, OLIP achieves a Joint realism MAE of 0.118 and 53.9% accuracy, substantially outperforming all baselines. The best existing method, VQAScore, reaches only MAE 0.164 and 40.7% accuracy on Joint realism, while the strongest few-shot VLM (LLaVA-Critic) achieves MAE 0.178 and 41.4%. OLIP's advantage is most pronounced on shape realism (MAE 0.136 vs. 0.165 for the best baseline) and on heavily distorted objects where existing methods perform near-randomly.

## Baselines & Comparisons

OLIP outperforms all six baselines across every metric (shape, texture, average, and joint realism). The closest competitor is VQAScore, which achieves the best texture MAE (0.159) among baselines but still trails OLIP by 0.036 MAE and 7.2% ACC on Joint realism. LLaVA-Critic with few-shot in-context learning is the strongest VLM baseline (Joint ACC 41.4%), yet OLIP exceeds it by 12.5% ACC and 0.060 MAE. ImageReward and AestheticScore, designed for holistic human-preference scoring, perform poorly at object-level realism (Joint MAE 0.263 and 0.228 respectively), confirming that image-level preference models do not transfer to fine-grained object assessment. QualiCLIP, an image-quality-assessment method, is marginally better than the preference models but still lags OLIP by 0.081 MAE. Zero-shot LLaVA-OV sits in the middle (Joint MAE 0.174), showing that general-purpose VLMs have some implicit realism sensitivity but lack the specificity needed for object-level shape/texture decomposition.

## Relation to Prior Work

This paper carves out a new evaluation axis—object-centric realism (OcR)—by decomposing image fidelity into per-object shape and texture scores, drawing on the shape-surface mental model from 3D graphics rendering. Conceptually, it extends the divide-and-conquer evaluation paradigm (TIFA, VQAScore) from text-image alignment to the realism/fidelity dimension, and is closest in spirit to RichHF-18K's granular human feedback collection, but differs by scoring every individual object's shape and texture rather than localizing artifact heatmaps. The OLIP architecture repurposes the frozen BLIP backbone with a novel global-local multi-head attention design (full image as query, object crop as key/value) and separate regression heads for shape, texture, and joint realism, departing from prior holistic scoring approaches that use generic prompts like 'a good image.'

## Why It Matters / Open Questions

The paper establishes the first object-level realism benchmark and demonstrates that widely-used image-level metrics (ImageReward, QualiCLIP, zero-shot LLaVA) are nearly random at this granularity, which is a practical warning for anyone assuming image-level scores transfer to object-level assessment. The finding that averaging scores over just the five most salient objects predicts holistic image realism with 0.79 correlation offers a concrete, interpretable pathway for practitioners who need image-level scores but want object-level diagnostics. Key limitations include the narrow 17-category scope (fashion/home products), the per-object computational overhead requiring object grounding, and the open question of how well the framework generalizes to new generative models and artifact types as they emerge.

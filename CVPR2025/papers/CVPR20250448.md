## Problem

Embodied foundation models struggle to leverage cross-domain data because action spaces across different robots are fundamentally heterogeneous—different degrees of freedom, control interfaces (EEF position vs. velocity, joint vs. end-effector), and physical embodiments produce disjoint action manifolds. Existing approaches either naively normalize or discretize these incompatible spaces into a single representation (causing conflicting encodings) or manually aggregate all action dimensions (requiring extensive engineering and failing to exploit shared structure). This paper asks whether a learned, embodiment-agnostic action representation can unify heterogeneous robot data for effective cross-embodiment training.

## Input / Output

The model consumes third-person or wrist-view RGB images plus a natural-language task instruction (and optionally proprioceptive state) as input. It first produces a discrete universal action code selected from a 256×128 vector-quantized codebook, which is then passed through a lightweight embodiment-specific MLP decoder head (along with visual features from a shared vision backbone) to yield the final continuous or discrete control signal—e.g., relative/absolute EEF position, joint position, or velocity commands. The universal action code itself is embodiment-agnostic and can be reused across robots; only the small decoder head (≈4M parameters out of 500M total) needs to be trained for a new platform.

## Method

UniAct fine-tunes a 0.5B VLM (LLaVA-OneVision) as a universal action extractor that, given an observation and language goal, predicts a probability distribution over a 256-entry VQ codebook where each entry encodes a generic atomic behavior. Gumbel-Softmax reparameterization makes the discrete code selection differentiable during training, with a gradually decaying temperature for stable convergence. The codebook acts as an information bottleneck: all robots are forced to express their actions through the same shared set of codes, compelling the VLM to discover embodiment-agnostic behavioral primitives rather than memorizing platform-specific control patterns. Lightweight per-embodiment MLP decoder heads then map the selected universal action (plus visual features) back to precise control signals, and are trained with standard behavior cloning losses (MSE, Huber, or diffusion) on domain-specific batches. This global-shared / local-specific training scheme—updating the codebook and extractor jointly while heads adapt per-domain—enables fast adaptation to new robots by simply adding a new head while freezing the universal action space.

## Results

UniAct-0.5B (0.5B params) outperforms 14× larger baselines (OpenVLA-7B, LAPA-7B) on visual, motion, and physical generalization tasks in real-world evaluation (190 rollouts, 19 tasks), while achieving comparable performance on semantic generalization and language grounding. On the LIBERO benchmark (130 tasks, 5 suites), UniAct-0.5B surpasses all baselines in every suite. In fast adaptation to an unseen AIRBOT robot, UniAct requires only 0.8% of its parameters (4M/500M) for fine-tuning versus 1.4% for OpenVLA and 2% for Octo, while achieving superior success rates across all four controller interfaces.

## Baselines & Comparisons

Against OpenVLA-7B [31], UniAct-0.5B wins decisively on visual, motion, and physical generalization in real-world evaluation, while matching it on semantic generalization and language grounding—despite being 14× smaller. Against LAPA-7B [69], UniAct-0.5B similarly outperforms on visual/motion/physical axes, with the key difference that UniAct uses actual action supervision rather than purely visual-change-based latent actions. Against Octo-0.1B [61] and CrossFormer-0.1B [17], UniAct-0.5B surpasses both across all five LIBERO suites (Spatial, Object, Goal, Long, 90), attributed to its ability to bridge domain gaps via the universal action space. In the fast-adaptation experiment on unseen AIRBOT, UniAct-0.5B consistently outperforms both OpenVLA and Octo across all four controller types (relative/absolute EEF and joint positions), while fine-tuning only 0.8% of its parameters versus 1.4% and 2% respectively. The paper does not report any setting where UniAct loses to a baseline.

## Relation to Prior Work

UniAct builds on LLaVA-OneVision as a pre-trained VLM backbone, repurposing it as a universal action extractor that outputs discrete codes from a vector-quantized codebook conditioned on observation and language goal. It departs from prior VLA models (OpenVLA, Octo, CrossFormer) that either treat heterogeneous action spaces as equivalent or naively aggregate them, and from latent-action approaches (LAPA, IGOR) that derive actions from inter-frame visual changes. The key conceptual shift is using a VLM's visual-language reasoning to identify task-relevant atomic behaviors shared across embodiments, creating an information bottleneck that forces cross-domain generalization rather than merely encoding embodiment-specific control signals.

## Why It Matters / Open Questions

The finding that a 0.5B model with a discrete universal action space outperforms 14× larger VLA models suggests that the bottleneck of heterogeneous action spaces—not model capacity—is the primary barrier to cross-embodiment generalization, which could redirect community effort toward better action representations rather than simply scaling parameters. The fast-adaptation result (0.8% of parameters for a new robot) has direct practical implications for deploying foundation models across diverse robotic fleets. However, the current instantiation is limited to 0.5B parameters and mostly single-arm platforms; whether the universal action space scales to bimanual, quadruped, or autonomous-driving embodiments, and whether larger VLM backbones further improve the codebook quality, remain open questions.

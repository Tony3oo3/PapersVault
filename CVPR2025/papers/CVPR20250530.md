## Problem

Existing parameter-efficient fine-tuning (PEFT) methods for point cloud understanding rely solely on the final output of frozen pre-trained models, discarding intermediate layer features that the authors show contain complementary information nearly as important as the final features. This limitation is particularly harmful for fine-grained tasks like part segmentation, where point-level understanding benefits from multi-scale semantics. Additionally, constructing an ordered sequence from 3D point cloud data is non-trivial due to the inherent isotropy of 3D space, which prevents reliance on a fixed spatial scanning direction.
![Teaser figure](../imgs/CVPR20250530/cropped_page3_idx2.webp)

## Input / Output

The method takes a raw 3D point cloud as input, which is partitioned into patches via Farthest Point Sampling and K-Nearest Neighbors, then encoded by a PointNet-based extractor into token embeddings. The frozen Transformer backbone (Point-MAE, Point-BERT, or PointGPT-L) processes these tokens, and PMA extracts features from every layer to produce a unified sequence of length L×M (layers × patches). The output is task-specific: a single class label for classification, per-point part labels for segmentation, or class predictions under n-way m-shot few-shot settings, all generated by a lightweight task head receiving concatenated [CLS], final-layer, and Mamba-fused intermediate features.

## Method

PMA introduces an orthogonal Mamba adapter that sequentially processes features extracted from all L layers of a frozen Transformer backbone, treating them as a single long sequence of length L×M. A shared Geometry-constrained Gate Prompt Generator (G2PG) operates on each layer's features to produce two outputs: (1) a dynamic token ordering via KNN-based connectivity graphs and Argmax over a softmax probability distribution, enabling geometric semantic-aware sorting that adapts end-to-end per task, and (2) geometric prompts P that are added to the Mamba's output gate matrix C, allowing the state-space model to modulate its output based on spatial neighborhood structure rather than relying solely on preceding sequence states. The Mamba adapter fuses all multi-layer complementary semantics in linear time, and only the CLS token, G2PG, Mamba Adapter, and task head are trained (1.1M–4.9M parameters), achieving a 99% reduction in trainable parameters compared to full fine-tuning while matching or exceeding its accuracy.

## Results

On ScanObjectNN PB-T50-RS (the hardest variant), PointGPT-L w/PMA achieves 95.18% overall accuracy with only 4.9M trainable parameters, a 99% reduction from the 360.5M parameters required for full fine-tuning. On ModelNet40, PMA reaches 95.4% accuracy (with voting) and 94.9% (without voting). On ShapeNetPart segmentation, Recon w/PMA attains 84.10% mIoU_c and 86.3% mIoU_I with just 5.64M parameters, matching or exceeding full fine-tuning (48.54M params) performance. In few-shot learning on ModelNet40, PointGPT-L w/PMA achieves 96.7% (10-way 10-shot) and 97.5% (10-way 20-shot), surpassing the full fine-tuning PointGPT-L baseline (94.1% and 96.1%).

## Baselines & Comparisons

PMA (PointGPT-L) ties PointGST [24] on ScanObjectNN OBJ-BG (both 98.97%) but outperforms it on PB-T50-RS (95.18% vs. 94.83%) and ModelNet40 with voting (95.4% vs. 95.3%), while using 8× more parameters (4.9M vs. 0.6M). PMA clearly surpasses IDPT [52] and DAPT [62] across all ScanObjectNN variants and ModelNet40, e.g., on PB-T50-RS PMA reaches 95.18% versus 90.63% (IDPT) and 89.38% (DAPT). On ShapeNetPart segmentation, Recon w/PMA (84.10% mIoU_c, 86.3% mIoU_I) matches the full fine-tuning Recon baseline (84.52%, 86.4%) with only 5.64M vs. 48.54M trainable parameters, and outperforms IDPT and DAPT by 0.1–0.4% mIoU_I. In few-shot learning, PointGPT-L w/PMA exceeds PointGPT-L FFT by 2.6% on 10-way 10-shot (96.7% vs. 94.1%) and 1.4% on 10-way 20-shot (97.5% vs. 96.1%). PMA also outperforms NLP/image-domain PEFT methods (Adapter, LoRA, VPT, AdaptFormer) transferred to Point-MAE, which peak at 83.93% on PB-T50-RS versus PMA's 86.43%.

## Relation to Prior Work

PMA departs from the dominant PEFT paradigm for point clouds (IDPT, DAPT, PointGST), which injects small learnable parameters into each frozen Transformer layer and relies solely on the final-layer output. Instead, PMA treats the pre-trained backbone as a frozen feature extractor and introduces an orthogonal Mamba adapter that sequentially processes all intermediate layer features as a single long sequence, leveraging the linear-time complexity of state space models to handle the resulting L×M token length. The Geometry-Constrained Gate Prompt Generator (G2PG) is a novel component that addresses the 3D isotropy problem by learning task-specific spatial ordering and injecting geometric prompts into Mamba's output gate C, drawing on the observation that C corresponds to the query in a linear-attention interpretation of Mamba.

## Why It Matters / Open Questions

The empirical finding that the first 3 layers of a pre-trained point cloud Transformer retain nearly all the information of the full model (within ~2.6% on classification) challenges the implicit assumption in prior PEFT work that only the final layer carries useful semantics, and motivates multi-layer fusion as a general principle. The 99% parameter reduction while matching or exceeding full fine-tuning across three backbones (Point-BERT, Point-MAE, PointGPT-L) makes PMA practically relevant for deployment on resource-constrained devices. Open questions include whether the approach extends to non-Transformer backbones (e.g., PointNet++-style), whether the Mamba adapter's linear-time advantage is preserved at much larger sequence lengths (e.g., scene-level point clouds with tens of thousands of patches), and whether the G2PG's KNN-based graph construction scales efficiently to dense point clouds.

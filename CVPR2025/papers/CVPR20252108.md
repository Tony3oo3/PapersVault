## Problem

Unsupervised prompt learning (UPL) methods generate pseudo-labels exclusively through text classifiers built from class names, which fail when textual descriptions do not capture critical visual appearance (e.g., 'Thorn apple' conveys no information about the flower's white petals). This creates a dead-end: building an image-based auxiliary classifier would require ground-truth labels that are unavailable in the unsupervised setting, and the resulting pseudo-label errors compound across training iterations.

## Input / Output

The method consumes unlabeled RGB images, a list of class names, and a short dataset description string (e.g., 'Flowers:') as the only task-specific information. It produces two types of outputs: (1) refined pseudo-labels for each unlabeled image obtained by fusing text-classifier and synthetic-image-classifier predictions, and (2) optimized text or visual prompt vectors (prefix size 16) for the ViT-B/32 CLIP backbone. Additionally, the pipeline generates 120 synthetic images per class via LoRA-fine-tuned Stable Diffusion, which serve both as a one-shot auxiliary classifier (one representative image per class) and as labeled training data during prompt optimization.

## Method

AiR bridges text-image-pair classification to image-image-pair classification by using diffusion-generated synthetic images as visual class prototypes. First, Stable Diffusion is fine-tuned with LoRA on high-confidence CLIP zero-shot pseudo-labeled samples (conditioned on the dataset description) to ensure domain consistency while preserving generative diversity. Second, for each class, M synthetic images are generated and the single most semantically aligned sample is selected via cosine similarity with the CLIP text embedding, forming an auxiliary image-based classifier. Third, pseudo-labels are assigned by combining the original text-classifier probability p_c with the auxiliary image-classifier probability p̂_c (weighted by λ), yielding a richer discrimination that captures both semantic and visual perceptual information. The prompt is then optimized with a composite loss: cross-entropy on real images with the fused pseudo-labels (L_r) plus cross-entropy on synthetic images with their known class labels (L_s), weighted by β. This process iterates, with each round of prompt optimization feeding back into more accurate pseudo-label generation.

## Results

On the five benchmark datasets under the Unsupervised Learning (UL) paradigm with text prompts, AiR achieves an average top-1 accuracy of 60.1%, outperforming the strongest baseline CPL (57.5%) by 2.6% and GRIP (51.7%) by 8.4%. With visual prompts, AiR reaches 58.8% average UL accuracy, a 2.7% gain over CPL (56.1%). Across all three paradigms (UL, SSL, TRZSL), AiR consistently achieves the best results, with the largest absolute gains on RESISC45 (79.9% UL-TP vs. 77.3% for CPL) and EuroSAT (71.4% UL-TP vs. 67.2% for CPL).

## Baselines & Comparisons

AiR outperforms all five baselines (CLIP zero-shot, FPL, GRIP, CPL, and the supervised CoOp/VPT references) across every dataset and learning paradigm. Against the strongest unsupervised baseline CPL, AiR gains +2.6% average UL accuracy with text prompts (60.1% vs. 57.5%) and +2.7% with visual prompts (58.8% vs. 56.1%), with the largest per-dataset margins on EuroSAT (+4.2% TP-UL) and RESISC45 (+2.6% TP-UL). Compared to GRIP, the improvement is even more pronounced at +8.4% (TP-UL) and +6.2% (VP-UL), indicating that the diffusion-based auxiliary classifier addresses a fundamental limitation of iterative pseudo-label refinement alone. In the SSL and TRZSL settings, AiR still leads CPL by 1–3% on most datasets, confirming that the synthetic-image bridge is beneficial regardless of the amount of labeled data available. The only dataset where the gap narrows is FGVCAircraft, where fine-grained aircraft classes remain challenging for all methods (best UL-TP: 19.6% for AiR vs. 18.3% for CPL).

## Relation to Prior Work

AiR extends the unsupervised prompt learning (UPL) line of work (FPL, GRIP, CPL), which all depend on CLIP's text encoder to generate pseudo-labels, by introducing a diffusion-generated auxiliary image classifier that bridges text-image-pair classification to image-image-pair classification. It builds on Stable Diffusion and LoRA for domain-adaptive synthetic image generation, but departs from prior diffusion-in-prompt-learning work (DiffTPT, DataDream) that uses diffusion purely for data augmentation; here diffusion serves as a modality bridge to enrich pseudo-labeling. The method is designed as a plug-in module compatible with existing UPL pipelines, requiring only class names and a dataset description.

## Why It Matters / Open Questions

The paper identifies a concrete and recurring failure mode of text-only pseudo-labeling in UPL (visually similar but semantically distinct classes being confused) and shows that a simple auxiliary image classifier built from diffusion samples can correct a meaningful fraction of these errors. However, the gains are modest (~2.6% average), the approach incurs non-trivial compute for generating 120 synthetic images per class plus LoRA fine-tuning, and the ablation confirms synthetic samples cannot replace real data. Open questions include whether the approach scales to open-vocabulary or long-tail settings, whether larger diffusion models or fewer but higher-fidelity samples would improve the cost-benefit tradeoff, and whether the LoRA domain-alignment step remains necessary with more capable generative models.

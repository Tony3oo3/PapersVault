## Problem

Individual ReID feature vectors inevitably contain noise from background clutter, occlusions, and model limitations, degrading retrieval accuracy. While features of the same identity naturally cluster around an 'identity center' after training, obtaining diverse same-identity samples without labels is difficult, and prior GAN-based generation methods fail to maintain identity consistency across poses. This paper asks: can we reduce per-sample feature noise and strengthen identity representation at inference time, without retraining the ReID model?
![Teaser figure](../imgs/CVPR20250402/cropped_page0_idx1.webp)

## Input / Output

At inference, the method takes a single pedestrian image (resized to 512×256) and 8 pre-selected representative pose skeletons as input. The ReID model (e.g., TransReID, frozen) extracts a feature vector from the original image, while the diffusion model generates 8 pose-varied images of the same person conditioned on the identity feature and pose embeddings. The output is an L2-normalized centralized feature vector that aggregates the original feature with features from the generated images, scaled by a quality coefficient η. The NFC component additionally consumes the full set of query/gallery feature vectors and produces enhanced centralized features via mutual-neighbor aggregation, preserving the original feature distribution for downstream re-ranking.

## Method

The core insight is a theoretical analysis (via the Central Limit Theorem applied to cross-entropy, triplet, and center losses) showing that same-identity features follow a multivariate normal distribution around an identity center, so aggregating features reduces noise. The Identity-Guided Pedestrian Generation (IPG) module uses Stable Diffusion v1.5 with a reference UNet that injects identity features at timestep t=0 and a denoising UNet conditioned on pose embeddings; an Identity Feature Redistribute (IFR) module projects high-dimensional ReID features into low-dimensional blocks used as key/value in cross-attention to guide identity preservation. Eight representative poses are selected by finding the image whose feature is closest to the computed identity center for each ID. The Neighbor Feature Centralization (NFC) algorithm performs mutual nearest-neighbor aggregation (top-k₁/k₂ reciprocity check) over the feature distance matrix to discover hidden positive samples without labels, then adds neighbor features and applies L2 normalization to preserve the original distribution. The entire framework is training-free for the ReID model and can be applied post-hoc to any pretrained ReID backbone, even an ImageNet-pretrained ViT without ReID training.

## Results

The proposed training-free Feature Centralization framework (Pose2ID) consistently improves SOTA ReID models across three benchmarks. On Market1501, it boosts TransReID (w/o camid) from 79.88/91.48 to 90.39/94.74 mAP/Rank-1, and CLIP-ReID (CNN) to a new SOTA of 94.9/97.3. On Occluded-ReID, KPR improves from 79.05/85.4 to 89.34/91.0, and on SYSU-MM01 (All-search), SAAI reaches 76.44/79.33. Remarkably, with only ImageNet pre-trained ViT weights (no ReID training), the method achieves 52.81/78.92 mAP/Rank-1 on Market1501, up from 3.34/11.4 without any enhancement.

## Baselines & Comparisons

The method is a training-free plug-in enhancement applied on top of six SOTA ReID models, so all comparisons are base-model vs. base-model+Pose2ID. The largest absolute gains appear on Occluded-ReID: BPBReID improves by +15.64 mAP and +11.9 Rank-1, and KPR by +10.29 mAP and +5.6 Rank-1, reflecting the method's strength in handling partial visibility. On Market1501, TransReID (w/o camid) gains +10.51 mAP, while CLIP-ReID (CNN) reaches a new SOTA of 94.9/97.3 mAP/Rank-1. On the cross-modality SYSU-MM01 benchmark, PMT (ViT) benefits most in All-search mode (+9.3 mAP, +7.11 Rank-1), while SAAI (CNN) achieves new SOTA in both All (76.44/79.33) and Indoor (86.83/84.2) search modes. The method also works without any ReID-specific training: an ImageNet-pretrained ViT jumps from 3.34/11.4 to 52.81/78.92 mAP/Rank-1 with IPG alone, demonstrating that feature centralization can substitute for task-specific optimization.

## Relation to Prior Work

This paper positions itself at the intersection of diffusion-based image generation and person ReID feature enhancement. It builds architecturally on Stable Diffusion's latent diffusion framework (Rombach et al., CVPR 2022) and adopts the pose-conditioning mechanism from Animate Anyone (Hu, CVPR 2024), but repurposes both for a fundamentally different goal: generating multi-pose views of the same identity to aggregate features at inference time. Conceptually, it departs from the dominant ReID paradigm of designing better backbones and metric learning losses, and also supersedes earlier GAN-based pose-transfer approaches (FD-GAN, PoseTransfer) that struggled with identity drift. The neighbor feature centralization component repurposes the mutual-nearest-neighbor logic from k-reciprocal re-ranking, but applies it to feature aggregation rather than distance refinement, and crucially preserves the original feature distribution via L2 normalization.

## Why It Matters / Open Questions

The training-free (for the ReID model) nature of the framework makes it a drop-in enhancement applicable to any existing ReID architecture, which is practically valuable given the diversity of deployed models. The striking result that an ImageNet-pretrained ViT with zero ReID training reaches 52.81/78.92 mAP/Rank-1 on Market1501 (vs. 3.34/11.4 baseline) suggests that much of the 'ReID capability' can be recovered through multi-view feature aggregation alone, raising questions about how much of ReID training is truly necessary. Limitations include the non-trivial cost of training the generative model (~20 hours on one GPU) and generating 8 images per test sample, which may be prohibitive for real-time surveillance. Open questions include whether the approach extends to video ReID, whether the generative model must be retrained for new camera domains, and whether the CLT-based feature distribution assumption holds under distribution shift.

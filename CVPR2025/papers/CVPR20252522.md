## Problem

In practical industrial anomaly detection, training data is simultaneously long-tailed (some product classes have only 1–20 samples) and contaminated with defective images, yet no class or anomaly labels are available. Existing memory-based detectors face a fundamental tail-versus-noise trade-off: noise-robust methods (e.g., SoftPatch) discard both defect patches and the scarce few-shot class patches, while methods that capture rare classes well (e.g., PatchCore) also retain noise, degrading head-class performance.
![Teaser figure](../imgs/CVPR20252522/cropped_page0_idx0.webp)

## Input / Output

The model consumes RGB product images from multi-class industrial datasets (MVTecAD, VisA) whose training sets are modified to have long-tail class distributions (Pareto, step K=1, step K=4) and ~10% defective-sample contamination. A pretrained WideResNet-50 extracts patch-level feature maps; at inference, each patch's anomaly score is its nearest-neighbor distance to the memory bank, up-scaled to a pixel-level score map, with the image-level score taken as the pixel maximum. No class labels or anomaly labels are used at any stage.

## Method

TailedCore constructs a memory bank as the union of a noise-discriminated coreset (via LOF-based outlier filtering and greedy coreset sampling, as in SoftPatch/PatchCore) and an exclusively-sampled tail-class coreset. The key component, TailSampler, estimates each training sample's class size using a reflective-symmetry assumption on inter-class vs. intra-class embedding similarity: for each embedding, an adaptive angle is set to the p-th percentile (p=0.85) of the half-maximum-angle region, and the class size is the mode of neighborhood sizes within that angle (a 'neighborhoods of neighborhoods' vote). An elbow method on the sorted estimated class sizes determines the maximum tail-class size K_max, enabling exclusive sampling of all patches from classes with κ_i ≤ K_max. This design decouples noise removal (applied to head-class patches) from few-shot preservation (applied to tail-class patches), resolving the tail-versus-noise dilemma without requiring any labels.

## Results

On MVTecAD anomaly classification (image-level AUROC), TailedCore achieves 96.12% (Pareto), 95.71% (step K=4), and 94.43% (step K=1) overall, outperforming the best baselines by 4.6–12.2 points. On VisA classification, TailedCore reaches 90.85%, 89.64%, and 87.61% overall across the three tail distributions, again leading all competitors. For anomaly segmentation (pixel-level AUROC) on MVTecAD, TailedCore scores 95.29%, 94.74%, and 93.99% overall, surpassing the next-best method (SoftPatch at 93.41%, 87.24%, 80.99%) by up to 13 points in the most imbalanced setting.

## Baselines & Comparisons

TailedCore outperforms all 14 baselines across every tail distribution type and both datasets. The tail-versus-noise trade-off is stark among baselines: SoftPatch achieves 97.54% on head classes (step K=4) but collapses to 67.65% on tail classes, while PatchCore reaches 92.19% on tail but drops to 71.18% on noisy head classes. TailedCore eliminates this trade-off, maintaining >93% on both tail and head classes in all settings. Against the strongest foundation-model baselines (AnomalyCLIP at 91.48% and WinCLIP at 90.37% overall on MVTecAD Pareto), TailedCore gains 4.6–5.8 points. On the most extreme step(K=1) setting, TailedCore's 94.43% overall surpasses the next-best AnomalyCLIP (91.48%) by nearly 3 points, while SoftPatch and PatchCore fall to 75.40% and 80.01% respectively. On VisA, TailedCore similarly leads by 2–12 points over all baselines across all three tail distributions for both classification and segmentation tasks.

## Relation to Prior Work

TailedCore builds directly on the memory-based anomaly detection paradigm of PatchCore (greedy coreset sampling) and the noise-discrimination mechanism of SoftPatch (LOF-based outlier filtering), combining them into a unified memory bank. The key conceptual departure is the identification of a 'tail-versus-noise trade-off' — prior methods handle either noise contamination or class imbalance but not both simultaneously, as few-shot class features are statistically indistinguishable from defect noise in embedding space. The novel TailSampler component, which estimates class cardinality via angle-based neighborhood voting in the embedding space, departs from classical clustering and outlier detection by using instance-specific adaptive angles and a mode-of-neighborhood-sizes mechanism rather than global thresholds or fixed-radius neighborhoods.

## Why It Matters / Open Questions

This work addresses a highly practical industrial scenario (multi-product lines with varying production volumes and defect contamination) that prior anomaly detection methods handle poorly, and provides a clean decomposition strategy (noise-discriminate head classes, exclusively sample tail classes) that resolves the trade-off. A key limitation is the dependence on encoder discriminative quality: if defect samples geometrically resemble few-shot class instances in embedding space, TailSampler mis-samples, and the paper acknowledges this without a robust fix. Open questions include whether the angle-based class size predictor generalizes to non-WideResNet encoders (e.g., vision transformers), whether the reflective symmetry assumption holds for highly textured or multi-object scenes, and whether the approach extends to video or 3D anomaly detection.

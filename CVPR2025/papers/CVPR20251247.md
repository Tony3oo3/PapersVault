## Problem

Transformer-based learned image compression methods suffer from quadratic computational complexity that causes significant latency degradation at high resolutions, while CNN-based methods lack sufficient long-range dependency modeling. Although State Space Models offer linear-time global receptive fields, the concurrent MambaVC simply swaps in SSM blocks without SSM-specific architectural adaptations, yielding sub-optimal rate-distortion performance. MambaIC addresses this gap by designing SSM-tailored context modeling and entropy mechanisms that simultaneously improve compression quality and computational efficiency.
![Teaser figure](../imgs/CVPR20251247/cropped_page0_idx0.webp)

## Input / Output

The method takes standard RGB images as input and produces an arithmetic-coded bitstream plus a reconstructed image. Training uses Flickr30k (31,783 images), while evaluation spans Kodak (768×512), Tecnick (1200×1200), and CLIC Professional Valid (2048×1440), with the key finding that MambaIC's advantage over baselines grows substantially as resolution increases. The latent representation uses 320 channels split into 5 channel chunks, with a 128-channel hyperprior, and the entropy model outputs per-pixel Gaussian mean and variance parameters for arithmetic coding.

## Method

MambaIC integrates Visual State Space (VSS) blocks with 2D selective scan (SS2D) into both the nonlinear transform and the context model, where SS2D scans input patches along four traversal paths to build global receptive fields at linear cost. The context model combines channel-wise autoregressive modeling (splitting 320 latent channels into 5 chunks) with a parallel checkerboard spatial context model, using VSS blocks in place of standard convolutions to estimate entropy parameters from previously coded symbols. A window-based local attention (WLA) module is inserted after parameter aggregation to capture fine-grained spatial redundancy within 8×8 windows, complementing the global receptive fields of the SSM blocks. The full pipeline is trained end-to-end with MSE distortion and Lagrangian rate-distortion loss across five λ values, and the SSM-based context model reduces decoding latency to 39.42 ms while achieving −12.52% BD-rate versus VVC.

## Results

On Kodak, MambaIC achieves a BD-rate of −12.52% relative to the VVC anchor, the best among all compared learned and conventional codecs. It also attains the lowest decoding latency (39.42 ms) and moderate FLOPS (202.04 G) among the learned methods, compared to 107.24 ms decoding and 415.20 G FLOPS for the Mixed Transformer-CNN baseline. On higher-resolution datasets (Tecnick 1200×1200, CLIC Professional Valid 2048×1440), MambaIC maintains stable performance while existing methods degrade, with the BD-rate advantage growing as image resolution increases.

## Baselines & Comparisons

MambaIC outperforms all eight baselines on BD-rate. Against the closest SSM-based concurrent work MambaVC (Qin et al., 2024), MambaIC improves BD-rate by 5.21 percentage points (−12.52% vs −7.31%) while also reducing decoding latency from 41.67 ms to 39.42 ms. Compared to the strongest Transformer-CNN hybrid (Mixed, Liu et al., CVPR 2023), MambaIC gains 2.87% BD-rate while using roughly 50% of the encoding time (60.73 ms vs 154.41 ms) and 30% of the decoding time (39.42 ms vs 107.24 ms). Against the leading CNN-based method ELIC (He et al., CVPR 2022), the improvement is 8.57% BD-rate, and against the Transformer-based Contextformer (Koyuncu et al., ECCV 2022) it is 7.47%. MambaIC also surpasses the conventional VVC/VTM standard by 12.52% BD-rate, and beats BPG in qualitative comparisons. On higher-resolution evaluations (Tecnick, CLIC Professional Valid), the gap over all baselines widens as resolution increases, confirming the linear-complexity advantage of the SSM backbone.

## Relation to Prior Work

MambaIC extends the learned image compression (LIC) framework by replacing the dominant CNN/Transformer backbone with a State Space Model (specifically the Vision Mamba VSS block with 2D selective scan) in both the nonlinear transform and the context model. It builds directly on ELIC's hybrid checkerboard-plus-channel-wise autoregressive context model and the hyperprior entropy modeling paradigm, but departs from the concurrent MambaVC by adding SSM-specific adaptations: integrating VSS into the context entropy parameter estimators and introducing window-based local attention to complement the global receptive field of SSMs. The paper positions itself as the first to exploit SSMs in both the transform and context model simultaneously, rather than merely substituting SSM blocks for existing ones.

## Why It Matters / Open Questions

The practical significance lies in addressing the quadratic-complexity bottleneck of Transformer-based LIC for high-resolution images, where SSMs' linear-time scanning provides a clear efficiency advantage that grows with image scale. The finding that BD-rate improvement over prior methods becomes more substantial at higher resolutions (1200×1200, 2048×1440) suggests SSM-based compression may be particularly well-suited for the growing demand in high-definition transmission. Open questions include whether the approach extends naturally to video compression, whether the specific window size (8×8) and channel chunking (K=5) generalize across diverse image content, and whether further SSM variants (e.g., state-space duality, larger state dimensions) could close the remaining gap to the best Transformer-based methods at lower resolutions.

## Problem

Text-guided image editing models lack a widely-accepted standard evaluation methodology because the task admits multiple valid outputs per query, making pixel-level distances inadequate and single-metric approaches unreliable. Existing benchmarks are either too small for robust evaluation, restricted to trivially verifiable edits (e.g., grayscale conversion), or depend on manual user studies that cannot scale or be reproduced.
![Teaser figure](../imgs/CVPR20252687/cropped_page1_idx1.webp)

## Input / Output

The benchmark provides 18,226 real-world images (512×512, sourced from GQA and filtered to 76 COCO object classes) paired with 49,840 editing queries in both description-based (two captions) and instruction-based (single instruction) forms. Given an original image, a text query, and a model's edited output, HATIE produces five per-image scores (Object Fidelity, Background Fidelity, Object Consistency, Background Consistency) plus a set-level Image Quality score, aggregated into a single Total Score. Object and background regions are separated via Detectron2 instance segmentation before metric computation.

## Method

HATIE combines three components: a large-scale dataset with feasibility-constrained query generation (using statistical relation analysis from GQA annotations to restrict edits to plausible configurations), a multi-metric evaluation pipeline across five criteria, and a human-alignment calibration step. Object Fidelity fuses CLIP alignment, detection confidence, and size fidelity; Object/Background Consistency fuse LPIPS, DINO embedding similarity, L2 distance, and (for objects) position/size preservation; Image Quality uses FID. The convex-combination weights for each criterion and the final Total Score are fitted by grid search to maximize Pearson correlation with winning rates from a 24-participant user study (4,050 images, 6 models), ensuring the automated scores track human perception. Each edit type is evaluated only with a task-appropriate subset of criteria (e.g., Object Consistency is omitted for OBJECT REPLACEMENT), and the framework supports both description-based and instruction-based models without cross-type comparison.

## Results

On the HATIE benchmark (18,226 images, 49,840 queries, 76 COCO object classes), MagicBrush achieves the highest Total Score of 0.7329 among all 9 evaluated models, followed by IP2P (0.6960) and P2P (0.6858). Among description-based models, P2P leads with a Total Score of 0.6858, while MasaCtrl trails at 0.5936. The evaluation covers five criteria—Object Fidelity, Background Fidelity, Object Consistency, Background Consistency, and Image Quality—with weights calibrated via user study to align with human perception (Pearson r > 0.8 across all criteria).

## Baselines & Comparisons

Among description-based models, P2P achieves the best Total Score (0.6858), outperforming FreeDiff (0.6739), DiffuseIT (0.6682), Imagic (0.6682), DiffEdit (0.6552), and MasaCtrl (0.5936). P2P leads in Object Fidelity (0.3595) and Background Fidelity (0.6073), while Imagic dominates in Object Consistency (0.9237) and Image Quality (0.8406). MasaCtrl lags significantly in Image Quality (0.2685) and Object Consistency (0.6754), resulting in the lowest Total Score among description-based models. Among instruction-based models, MagicBrush leads across most criteria with the highest Object Fidelity (0.5378) and Total Score (0.7329), followed by IP2P (0.6960) and InstDiff (0.6639). InstDiff underperforms in Image Quality (0.4148) and Object Consistency (0.6870) relative to the other instruction-based models, though it is particularly strong on OBJECT RESIZING tasks. The paper emphasizes that description-based and instruction-based models are not directly comparable due to different input formats.

## Relation to Prior Work

HATIE carves new ground in the evaluation of text-guided image editing by repurposing existing perceptual metrics (CLIP, LPIPS, DINO, FID) into a structured five-criteria framework whose weights are calibrated to human judgment via user study. Prior benchmarks (TEdBench, EditBench, GIER, EditVal) were either too small, limited to pixel-level ground-truth tasks, or still relied on manual user studies for final assessment. The key conceptual departure is the explicit separation of fidelity (did the edit happen?) from consistency (was everything else preserved?) for both object and background regions, combined with a feasibility-aware query generation pipeline built on GQA scene-graph annotations and COCO class constraints.

## Why It Matters / Open Questions

HATIE provides the first large-scale (18K images, 50K queries, 76 object classes), fully-automated, and human-aligned evaluation pipeline for text-guided image editing, removing the reliance on costly and non-reproducible user studies that has bottlenecked progress in this area. The finding that individual conventional metrics (e.g., CLIP alignment) can even anti-correlate with human judgment underscores the necessity of the multi-criteria decomposition. Limitations include exclusion of certain edit types (object removal for description-based models, movement/rotation) and dependence on COCO's 80-class vocabulary, which constrains coverage of long-tail objects. An open question is whether the five-criteria decomposition and its fitted weights generalize to future editing paradigms (e.g., multi-step or compositional edits) that may not fit the single-instruction framing.

## Problem

No prior study has analyzed the difficulty of prompts in text-to-image generation based on human relevance judgments, and no joint benchmark exists to compare prompt difficulty across both generation and retrieval. It remains unclear whether the factors that make a prompt challenging for a generative model (complexity, specificity, ambiguity) are the same as those that make a query difficult for a retrieval system.

## Input / Output

The benchmark provides 10,200 text prompts/queries (10K diverse MS COCO captions selected via k-means clustering on sentence BERT embeddings, plus 200 DrawBench prompts) paired with ground-truth performance scores in both settings. For generation, each prompt is scored via HBPP (a value in [-1, 2]) derived from 247K+ four-level human relevance judgments (high/low/no relevance, unrealistic) over images from SDXL (1024×1024) and GLIDE (256×256). For retrieval, each query is scored by P@10 and reciprocal rank over CLIP and BLIP-2 results, grounded in 1.39M manually verified relevance judgments. Predictors consume either text alone (pre-generation/retrieval) or text plus generated/retrieved images (post-generation/retrieval) and output a single predicted performance score.

## Method

The core contribution is a large-scale human-annotated benchmark: 147 annotators label 40,800 generated images with a 4-level relevance scale (validated via Fleiss' κ = 0.55 and a control-prompt protocol), while 91 evaluators verify 1.39M retrieved images (reducing them to 530K relevant). Prompt performance is computed via majority voting on coarse relevant/irrelevant categories followed by averaging the fine-grained scores within the majority. The paper then evaluates five predictors spanning pre- and post-generation/retrieval: basic linguistic features (#synsets, #words), a fine-tuned BERT regression head, a fine-tuned Long-CLIP with a regression/classification head, and a correlation CNN operating on pairwise CLIP-embedding similarity matrices. A key empirical finding is that generation and retrieval difficulty are nearly uncorrelated (Pearson ≈ 0.07–0.14), and that the supervised pre-retrieval BERT predictor is a competitive alternative to post-retrieval predictors, achieving Pearson 0.566 on GLIDE generation without ever seeing the generated images.

## Results

On the generative task, the fine-tuned CLIP post-predictor achieves the highest correlation with human-based prompt performance (HBPP), reaching Pearson 0.649 / Kendall 0.474 on GLIDE and Pearson 0.380 / Kendall 0.246 on SDXL. The fine-tuned BERT pre-predictor is a strong second on generation (Pearson 0.566 on GLIDE) and is competitive on retrieval, achieving Pearson 0.511 on BLIP-2 P@10 and 0.451 on CLIP P@10. Simple linguistic features (#synsets, #words) yield consistently negative correlations (e.g., −0.112 Pearson for #synsets on GLIDE), indicating they fail to capture prompt/query difficulty. Cross-model evaluation shows large performance drops for generation (e.g., fine-tuned CLIP drops from 0.649 to 0.256 Pearson when transferring SDXL→GLIDE) but more stable results for retrieval.

## Baselines & Comparisons

The paper evaluates five predictor families rather than a single proposed method, establishing baselines for the new PQPP benchmark. On the generative task, the post-generation fine-tuned CLIP clearly outperforms all other predictors, achieving Pearson 0.649 on GLIDE versus 0.566 for fine-tuned BERT and 0.548 for the correlation CNN. On the retrieval task, no single predictor dominates: fine-tuned BERT leads on CLIP RR (0.221) and BLIP-2 P@10 (0.511), fine-tuned CLIP leads on CLIP P@10 (0.473) and BLIP-2 P@10 (0.498), and the correlation CNN leads on BLIP-2 RR (0.206). A key finding is that the pre-retrieval fine-tuned BERT, which never sees images, is a worthy competitor for post-retrieval predictors, consistently beating the correlation CNN and occasionally surpassing fine-tuned CLIP. Basic linguistic features (#synsets, #words) are uniformly ineffective, showing negative correlations across all settings, confirming that simple text statistics cannot capture multimodal prompt/query difficulty.

## Relation to Prior Work

This paper extends the iQPP image retrieval benchmark [36] by adding a text-to-image generation axis, creating the first joint prompt/query performance prediction benchmark. It builds on the correlation-matrix CNN approach of Sun et al. [46] for post-retrieval quality assessment and on linguistic-feature predictors from Mothe & Tanguy [32] for pre-retrieval difficulty estimation. Crucially, it departs from Bizzozzero et al. [6], the closest prior work on prompt performance prediction, by replacing automatically generated ground-truth with over 1.6M human relevance judgments, and by jointly covering both generation and retrieval in a single benchmark.

## Why It Matters / Open Questions

The benchmark provides the first human-annotated ground-truth for prompt difficulty in text-to-image generation, enabling practical applications such as automatic prompt refinement, resource allocation, and user feedback in generative systems. The finding that generation and retrieval difficulty are nearly orthogonal (Pearson ≈ 0.13) challenges the assumption that a single difficulty signal transfers across tasks, motivating task-specific predictors. Limitations include coverage of only two generative and two retrieval models on the MS COCO domain, and the authors note that combining multiple pre-retrieval predictors and organizing a shared task are important next steps.

## Problem

Existing adapter-based CIL methods create entirely new adapters for each incoming task, causing linear parameter growth at inference and failing to exploit shared knowledge across tasks. The core challenge is designing learnable modules that simultaneously preserve cross-task patterns (avoiding catastrophic forgetting of previously learned representations) and capture discriminative task-specific features without inter-task interference, all under the parameter-efficiency constraints of low-rank decomposition.
![Teaser figure](../imgs/CVPR20252214/cropped_page0_idx0.webp)

## Input / Output

The method takes standard RGB images (224×224 for ViT-B/16) and outputs a class label via prototype-based cosine similarity matching. At inference, each test sample is first processed through the shared adapters in the first l=6 transformer blocks, then routed through each task's specific adapters in the remaining 6 blocks to produce t task-specific features, which are matched against per-task class prototypes. The rehearsal-free setting means no exemplars from previous tasks are stored; only the learned adapter parameters and class prototypes are retained.

## Method

CL-LoRA introduces a dual-adapter architecture that splits the ViT's N=12 transformer blocks into two zones: the first l=6 blocks receive a task-shared LoRA adapter with a fixed random orthogonal down-projection matrix B_s (initialized via SVD of a Gaussian matrix) and a continuously updated up-projection A_s, while the remaining blocks receive task-specific LoRA adapters with learnable block-wise scaling factors. To prevent the shared adapter from forgetting, the method applies knowledge distillation at the early-exit point (l-th block) and reassigns its gradients by element-wise multiplication with L2-norm-based importance weights from the previous task's A_s, so that dimensions critical for prior knowledge receive stronger preservation signals. Task-specific adapters are regularized with an orthogonality loss on their block-wise weight vectors across tasks, encouraging each task to adapt different transformer blocks and reducing feature entanglement. The overall training objective combines local cross-entropy, the early-exit KD loss, and the block-weight orthogonality penalty, with only 0.3% of backbone parameters trainable.

## Results

CL-LoRA achieves the best final accuracy (A_T) on three of four benchmarks: ImageNet-R (74.51%), ImageNet-A (60.54%), and VTAB (94.29%), while using only 0.3% trainable parameters. On CIFAR-100 (T=20), it reaches 85.32% A_T and 91.02% average accuracy, slightly below RanPAC (87.62% A_T) which requires 10× more parameters (3.1%). Among LoRA-based methods, CL-LoRA outperforms O-LoRA and InfLoRA by 4–13 points in A_T across all benchmarks, with the largest gap on ImageNet-R (74.51% vs. 63.19%/64.51%).

## Baselines & Comparisons

CL-LoRA (0.3% params) decisively outperforms all LoRA-based baselines: on ImageNet-R it gains +10.3 and +10.0 points in A_T over O-LoRA (63.19%) and InfLoRA (64.51%), and on ImageNet-A it leads by +13.0 and +13.5 points respectively. Against adapter-based methods, CL-LoRA surpasses EASE (1.4% params) by +3.08 on ImageNet-R and +1.29 on ImageNet-A in A_T, while using roughly 5× fewer parameters. On CIFAR-100, RanPAC (3.1% params) retains a +2.3 A_T edge over CL-LoRA, making it the only baseline that wins on any benchmark. Among prompt-based methods, CL-LoRA leads CODA-Prompt (4.6% params) by +10.58 on ImageNet-R and +8.93 on ImageNet-A in A_T, with a 15× parameter advantage. Overall, CL-LoRA achieves the best A_T on 3 of 4 benchmarks and the best A̅ on all four, establishing a clear parameter-efficiency–performance trade-off advantage.

## Relation to Prior Work

This paper extends the PTM-based rehearsal-free CIL paradigm by introducing a dual-adapter LoRA architecture that splits the transformer into shared (early blocks) and task-specific (later blocks) regions, conceptually mirroring DualPrompt's general/expert prompt decomposition but applied to low-rank weight updates rather than prompt tokens. It builds directly on LoRA's low-rank decomposition (Hu et al., 2021) and adapts the author's own prior gradient reweighting technique (He, CVPR 2024) to the continual learning setting, while the fixed random orthogonal down-projection is motivated by recent theoretical work on LoRA matrix asymmetry (Zhu et al., 2024). Unlike prior LoRA-based CIL methods (O-LoRA, InfLoRA) that create entirely new adapters per task, CL-LoRA continuously updates a shared adapter with knowledge distillation and gradient reassignment, addressing the parameter redundancy and cross-task knowledge transfer gaps identified in the literature.

## Why It Matters / Open Questions

The dual-adapter design offers a practical path toward scalable CIL by reducing inference complexity from O(NT) to O(l+(N-l)T) and capping shared parameter growth, which becomes critical as task sequences lengthen. The paper identifies open questions around optimal split position l, applicability to online and blurry-task-boundary settings, and algorithmic selection of LoRA configurations (rank, MHSA layers) based on task characteristics. A limitation is that all experiments use a single backbone (ViT-B/16) and the method is tied to MHSA layers, leaving open whether the shared/specific split generalizes to other architectures or adapter insertion points. The work also suggests that the reliance on clear task identity during training could be relaxed, pointing toward more flexible continual learning formulations.

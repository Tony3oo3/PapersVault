## Problem

Existing video benchmarks evaluate models on complete video sequences with access to all frames, which fundamentally differs from real-world streaming scenarios where a model must reason incrementally without future context. Moreover, no prior benchmark jointly tests streaming temporal state awareness (action prediction, state grounding, multi-turn dependency) and proactive reasoning (speaker identification, proactive alerting, turn-taking/noise rejection) in a unified interactive setting, leaving a critical gap in assessing whether OmniLLMs can genuinely function as real-time interactive agents.

## Input / Output

The model consumes a streaming video as an infinite frame sequence V_∞, processing each incoming frame into a KV cache entry so that at time t only V_t (past frames) is available. Queries arrive as natural language text or synthetic audio, with interaction history H_t^n tracking prior question-answer pairs within a session (up to 3 turns for multi-turn tasks). Outputs are task-specific: free-form text for state grounding and multi-turn dependency, a selected action label from a predefined vocabulary for action planning, a speaker name for speaker identification, a timed proactive alert for surveillance, or explicit silence for noise rejection.

## Method

M4 (Multi-modal Multiplexing Modeling) is an inference-time framework that can be attached to any pre-trained VideoLLM without video-specific training. Its proactive generation mechanism, called 'highlight spot,' computes attention scores between the query and cached frames, stores indices exceeding μ+ασ in a max-heap, and triggers response generation when a frame index's occurrence frequency surpasses a threshold. Proactive interruption uses a perplexity-scaled threshold on the <bos> token probability to classify incoming queries as noise (discarded from KVCache) or legitimate, and an analogous <eos> probability check for stopping detection. Parallel decoding employs a combination of causal, prefix, and block masks to process a new query alongside ongoing generation in a single forward pass, maintaining low latency. The framework is fine-tuned on M4-IT, a small video-free synthetic instruction dataset (costing $4.91 to generate) comprising original instruction replay, interleaved image-text pairs, GPT-4-generated noise statements, and stop phrases.

## Results

On OmniMMI, the best commercial model (Gemini-1.5-Pro) achieves 16.33% average SG accuracy, 43.00% AP, 12.00% average MD, and 38.50% SI, while the best open-source model (LongVILA) reaches 4.33% SG, 39.50% AP, 3.00% MD, and 10.00% SI. The proposed M4 (Qwen2-7B) achieves 5.67% SG, 33.5% AP, 1.67% MD, 9.00% SI, 25.50% PA, and 62.00% PT, while M4-a achieves the best PT score of 68.5%. Notably, all models show severe degradation on multi-turn tasks (SG 3rd turn drops to 0–9.35% across all models), and no open-source model supports PA or PT natively except M4 and VITA.

## Baselines & Comparisons

M4 (Qwen2-7B) outperforms all open-source VideoLLMs on PA (25.50% vs. 0–0.50% for VideoLLM-online and VideoLLaMB) and is competitive on SG (5.67% avg vs. 1.33–4.67% for other open-source models), though it trails commercial models (Gemini-1.5-Pro at 16.33%, GPT-4o at 15.00%) by a wide margin. On AP, M4 (33.5%) is mid-pack among open-source models, below LongVILA (39.5%) and LongVA (37.5%) but above most 7B baselines. M4-a achieves the best PT score (68.5%) among all evaluated models, surpassing VITA (67.0%), but at the cost of significantly lower SG (2.00%) and AP (13.0%) scores. On SI, M4 (9.00%) trails IXC2.5-OL (23.0%) and commercial models (38.50%, 17.00%) but leads most open-source baselines. A key finding is that increasing model size (e.g., PLLaVA-34B at 3.67% SG vs. PLLaVA-7B at 3.33%) does not improve streaming performance, while longer context windows (LongVILA 128 frames at 4.33% SG) help modestly. Audio-capable models (VideoLLaMA2, VITA, MiniOmni2) do not outperform visual-only counterparts on SG or AP, indicating poor audio-visual alignment in current OmniLLMs.

## Relation to Prior Work

This paper extends the streaming video understanding line (VideoLLM-online, VideoLLaMB, StreamingBench) by introducing proactive reasoning and multi-turn interaction as first-class evaluation dimensions, and draws on DataMux's multiplexing modeling for parallel decoding of concurrent inputs. It departs from prior special-token-based approaches for proactive generation (e.g., VideoLLM-online's binary classification with threshold) by proposing an attention-based 'highlight spot' mechanism that requires no video-specific training. The M4-IT instruction-tuning data builds on the interleaved image-text paradigm from LLaVA-NeXT-Interleave and Mantis, repurposing it for turn-taking and noise-rejection rather than multi-image reasoning.

## Why It Matters / Open Questions

OmniMMI is the first benchmark to jointly evaluate streaming temporal awareness, proactive alerting, turn-taking, and multi-turn dependency in a single framework, exposing that current MLLMs collapse beyond one reasoning step in dynamic settings and that audio-visual integration provides no measurable benefit over vision alone. The finding that context length matters more than model size for streaming tasks challenges the prevailing scaling narrative. Open questions include how to achieve robust multi-turn state tracking without full-sequence access, how to properly align audio and visual streams for genuine multimodal advantage, and whether the lightweight M4 approach generalizes to longer horizons or more complex proactive behaviors.

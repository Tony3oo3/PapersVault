## Problem

Functional map methods, which dominate 3D shape correspondence, degrade significantly under non-isometric shape discrepancies common in artist-crafted or AI-generated characters. Registration-based alternatives handle non-isometric cases better but suffer from unstable deformations and require careful pre-alignment or high-quality initial 3D correspondences that are difficult to obtain in practice. This paper revisits the registration-for-correspondence paradigm to make it robust and practical for in-the-wild character matching.

## Input / Output

The method takes a source mesh and a target mesh (roughly aligned in rotation) and renders them into multi-view RGB or normal images from a fixed set of K camera poses. The 2D correspondence model produces 512×512 semantic flow maps per view, which guide the iterative deformation of the source mesh. The final output is a dense point-to-point correspondence: each source vertex is mapped to a barycentric coordinate on a target face, yielding a deformed source mesh aligned to the target shape.

## Method

Stable-SCore is a two-stage pipeline. First, a 2D character correspondence model repurposes frozen Stable Diffusion (U-Net intermediate features) and DINOv2 features through a lightweight adapter network trained with a CLIP-style contrastive loss plus a geometry-grounded negative loss that penalizes similarity between geodesically distant points, mitigating self-similarity (e.g., left vs. right hand). Second, Semantic Flow Guided Registration deforms the source mesh using Neural Jacobian Fields (per-face tangent-space Jacobians solved via a Poisson equation), where differentiable rendering (NVDiff) projects the deformed vertices into 2D flow maps that are supervised against the 2D semantic flow. The optimization combines flow loss, Chamfer distance, normal loss, an identity-preserving term, and a novel shear-resistant regularizer (penalizing deviation from the polar-decomposition rotational component), iteratively refining the per-face transformation matrices over 5,000 steps.

## Results

On the non-isometric benchmarks, Stable-SCore (Normal) achieves mean geodesic error ×100 of 2.61 on CharW, 4.23 on DT4D-H std, and 4.12 on DT4D-H hard in the cross-domain setting, substantially outperforming all prior methods. On the isometric FAUST benchmark, it achieves 1.83, second only to Hybrid ULRSSM (1.55). In the intra-domain setting, the method further improves to 3.11 on DT4D-H std and 3.38 on DT4D-H hard, maintaining its lead over all baselines on non-isometric tasks.

## Baselines & Comparisons

Stable-SCore dominates all non-isometric benchmarks by a wide margin. On CharW, it achieves 2.61 vs. the next-best DFR (6.52) and a far superior result over functional map methods like ULRSSM (32.6) and Hybrid ULRSSM (33.5), which degrade severely under non-isometric conditions. On DT4D-H hard, the gap is even more pronounced: 4.12 for Stable-SCore versus 22.1 for Hybrid ULRSSM and 40.8 for DeepShell. Among zero-shot methods, Diff3F (12.5 on CharW) is the closest but still 5× worse than Stable-SCore, highlighting that simply back-projecting foundation model features without a dedicated correspondence model is insufficient. On the isometric FAUST benchmark, Stable-SCore (1.83) is competitive but trails Hybrid ULRSSM (1.55) by a small margin, suggesting functional maps retain an edge when shape discrepancies are minimal. The supervised GeoFMap baseline (30.2 on CharW) confirms that even with ground-truth training data, purely spectral functional map approaches cannot handle the geometric and topological variations present in in-the-wild characters.

## Relation to Prior Work

This paper revives the registration-for-correspondence paradigm (Non-Rigid ICP, SmoothShell, DeepShell, DFR), which has been largely overshadowed by functional map methods (FMNet, DiffusionNet, ULRSSM, HybridGeoFMap) in recent years. It departs from prior registration methods by eliminating the need for high-quality initial 3D correspondences or careful pre-alignment, instead leveraging 2D foundation models (Stable Diffusion + DINOv2) to produce stable multi-view 2D correspondences that guide mesh deformation through differentiable rendering. The deformation backbone is Neural Jacobian Fields, previously used in text-driven mesh editing (TextDeformer), here repurposed as a stable, differentiable deformation model for iterative registration. The closest prior work, Diff3F, also back-projects 2D foundation model features to 3D but still relies on functional maps for the final correspondence, losing semantic detail; Stable-SCore instead preserves full-resolution 2D flow supervision throughout the registration loop.

## Why It Matters / Open Questions

The paper addresses a practical gap that has limited real-world adoption of shape correspondence: non-isometric character matching in the wild, where functional maps degrade and registration methods fail without reliable initialization. The introduction of CharW, the first in-the-wild character correspondence benchmark with significant geometric and topological variation, provides the field with a much-needed stress test beyond controlled datasets like FAUST. Downstream applications (re-topology, texture transfer, rig transfer, shape interpolation) demonstrate immediate utility for 3D content creation pipelines. Open questions include whether the approach generalizes beyond bipedal characters to arbitrary object categories, whether the supervised 2D correspondence model can be replaced by truly zero-shot foundation model features at comparable quality, and how the method scales to very high-resolution meshes or large pose discrepancies beyond the tested range.

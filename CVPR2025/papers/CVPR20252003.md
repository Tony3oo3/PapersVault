## Problem

Existing zero-shot monocular 3D shape reconstruction methods (e.g., LRM, ZeroShape) assume clean, object-segmented images without occlusions, relying on off-the-shelf segmentation models like SAM for in-the-wild use. This introduces two critical failures: error accumulation from imperfect segmentation and the removal of occluded object parts, both of which degrade reconstruction accuracy in real-world conditions. No prior regression-based method handles occlusion-aware 3D shape reconstruction directly from unsegmented in-the-wild images.

## Input / Output

The model takes a single 224×224 RGB image directly (no pre-segmentation required) and optionally a text prompt (category-specific like 'cup' estimated by LLaMA-VID, or category-agnostic 'object') that modulates features via CLIP embeddings. It jointly regresses camera intrinsics, a depth map, a visible object mask, and an occluder mask at the pixel level, then uses these to estimate occupancy values on 3D point queries at 128×128×128 resolution (inference), which are converted to explicit meshes via Marching Cubes. The entire pipeline runs in a single forward pass with 193.7M parameters, compared to >2400M for baselines that chain separate segmentation and reconstruction models.

## Method

ZeroShape-W employs a two-stage regression architecture built on a DPT-Hybrid backbone (ResNet50 + Dense Prediction Transformer). In the pixel-level stage, the backbone's global and fine-grained feature maps are used to regress camera intrinsics, a depth map, a visible mask (conditioned via FiLM-style affine modulation with CLIP text embeddings), and an occluder mask; the visible 3D shape is then derived by unprojecting depth through the estimated intrinsics. In the 3D point-wise stage, the visible 3D shape and occluder mask are encoded and used as keys/values in cross-attention layers, where 3D point queries (concatenating spatial coordinates and CLIP text embeddings) attend to these features to predict occupancy values, recovering both visible and occluded geometry. Training data is generated by a scalable synthesis pipeline: 3D shapes from ShapeNet and Objaverse are rendered, their appearances diversified via ControlNet (with SDEdit-style initial guidance to preserve silhouettes), backgrounds generated by an object-aware outpainting model, and occluders inserted on-the-fly via CopyPaste augmentation. An auxiliary scale- and shift-invariant MAE depth loss from Depth Anything V2 is applied over the full image to stabilize depth regression in non-object regions.

## Results

On the Pix3D benchmark, ZeroShape-W (category-agnostic) achieves FS@τ = 38.2 and CD = 0.097, outperforming the strongest baseline ZeroShape w/ SAM+pix2gestalt (FS@τ = 33.6, CD = 0.110) by 13.7% and 13.4% respectively. The model uses only 193.7M parameters, less than 1/12 of the >2400M parameters required by LRM w/ SAM+pix2gestalt. On occluded images specifically, the gap widens: ZeroShape-W scores FS@τ = 34.2 vs. 30.2 for ZeroShape w/ SAM, while on non-occluded images it reaches FS@τ = 43.6 vs. 34.6.

## Baselines & Comparisons

The paper compares against two regression-based baselines—LRM [25] and ZeroShape [29]—each augmented with SAM for modal segmentation and optionally pix2gestalt for amodal completion, since both assume clean, occlusion-free object images. ZeroShape-W wins decisively on all metrics: it surpasses ZeroShape w/ SAM+pix2gestalt by 4.6 points on FS@τ (38.2 vs. 33.6) and by 0.013 on CD (0.097 vs. 0.110), and beats LRM w/ SAM+pix2gestalt by 7.1 points on FS@τ (38.2 vs. 31.1). The advantage is most pronounced on occluded images (57.4% of Pix3D), where ZeroShape-W scores FS@τ = 34.2 versus 30.2 for ZeroShape w/ SAM and 29.1 for LRM w/ SAM. Crucially, ZeroShape-W achieves these gains with 193.7M parameters—roughly 1/11th of ZeroShape w/ SAM+pix2gestalt (>2100M) and 1/12th of LRM w/ SAM+pix2gestalt (>2400M)—by jointly regressing segmentation, depth, and shape in a single forward pass without any external model.

## Relation to Prior Work

This paper extends ZeroShape's two-stage regression architecture (pixel-level regression followed by 3D point-wise occupancy regression) by adding an occluder mask branch and FiLM-based category conditioning, enabling the model to reconstruct occluded geometry without external amodal completion. It departs from the prevailing pipeline paradigm (off-the-shelf segmentation via SAM + reconstruction + amodal completion via pix2gestalt) by unifying all components into a single end-to-end model. The data synthesis pipeline repurposes generative models (ControlNet for appearance, object-aware outpainting for backgrounds, CopyPaste for occluders) in a domain-randomization framework, drawing on the robotics literature on bridging the sim-to-real gap rather than relying on high-quality 3D asset collections.

## Why It Matters / Open Questions

By eliminating the dependency on off-the-shelf segmentation and amodal completion models, this work removes a major practical barrier to deploying zero-shot 3D reconstruction in real-world settings, while achieving a 12× parameter reduction. The scalable data synthesis pipeline offers a reusable recipe for generating diverse training data without expensive 3D asset curation, which could benefit other vision tasks facing similar data scarcity. Key limitations remain: the 128³ inference resolution (vs. 384³ for LRM) produces visibly smoother shapes, CopyPaste occluders introduce a domain gap versus natural occlusions, and boundary-clipped objects are not handled. An open question is whether the unified regression approach can scale to higher resolutions with sufficient compute, and whether more physically realistic occluder simulation would close the remaining gap to real-world performance.

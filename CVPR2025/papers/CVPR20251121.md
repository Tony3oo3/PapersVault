## Problem

Existing bias detection methods for visual classifiers all require task-specific labeled data to identify and quantify model biases, limiting their applicability to tasks where such annotations are available. A non-expert downloading a pre-trained model from the web typically lacks access to the training data or the resources to collect annotated test sets, making automated bias discovery infeasible for most real-world use cases.

## Input / Output

The method takes a pre-trained visual classifier of any architecture, a free-form natural language description of the classification task (input domain, output class list), and access to a large-scale unannotated image database (CC12M or the open web via Bing search). It produces a class-specific list of bias attributes with their constituent classes (e.g., expression → smiling/angry), a continuous bias score per bias class in [-1, 1] computed as the per-class accuracy difference relative to other classes of the same attribute, and a ranked ordering of bias categories by severity. No training, fine-tuning, or manual annotation is required at any stage.

## Method

C2B is a training-free, two-component pipeline combining an LLM (Llama 3.1 8B) for hypothesis generation and a contrastive vision-language model (CLIP) or web search engine for evidence collection. First, the LLM is prompted with the task description to propose a class-specific list of bias attributes and their classes, then prompted again to generate task-aware captions that jointly describe a target class and a bias class. These captions drive a top-k retrieval step over a large image database, constructing a pseudo-annotated dataset where both target and bias labels are inherited from the caption text. The pre-trained classifier is then evaluated on this retrieved set, and bias scores are computed as the difference between per-class accuracy on a given bias class and the mean accuracy across other bias classes of the same attribute. The modular design allows swapping in stronger LLMs, retrieval backends, or image databases without architectural changes.

## Results

On CelebA (FaceXFormer), C2B detects 12.3% of ground-truth biases (Bing retrieval) vs. only 4.5% for B2T, while missing 80.8% vs. 92.3% for B2T. On ImageNet-X across four classifiers, C2B (CC12M) detects 10.9–11.2% of ground-truth biases compared to 2.1–2.6% for B2T, with miss rates of 76.9–78.1% vs. 95.3–95.9%. In the VQA-based evaluation, C2B achieves 0.22–0.25 agreement on CelebA (vs. 0.10 for B2T) and 0.26–0.32 on ImageNet-X with Bing retrieval (vs. 0.19–0.20 for B2T). C2B incurs higher false-hit rates (6.9–12.0% vs. 1.7–3.1%) due to the open-ended nature of LLM-generated bias proposals and retrieval noise.

## Baselines & Comparisons

C2B is compared against B2T (Kim et al., CVPR 2024), the only existing open-set bias detection method, which requires task-specific labeled validation data to identify misclassified samples and extract bias keywords from captions. C2B outperforms B2T on every primary metric across both datasets: on CelebA, C2B (Bing) detects 12.3% of ground-truth biases vs. 4.5% for B2T (2.7× improvement), and on ImageNet-X, C2B (CC12M) detects 10.9–11.2% vs. 2.1–2.6% for B2T (~4–5× improvement). In the Detected→GT precision view, C2B achieves 12.8–14.2% on CelebA vs. 6.6% for B2T, and 2.5–3.0% on ImageNet-X vs. 0.6–0.8% for B2T. The VQA-based evaluation confirms this gap: C2B scores 0.22–0.25 agreement on CelebA vs. 0.10 for B2T, and 0.26–0.32 on ImageNet-X (Bing) vs. 0.19–0.20 for B2T. The trade-off is that C2B has roughly 2–3× higher false-hit rates (e.g., 6.9–7.8% vs. 3.1% on CelebA), attributed to the broader search space of LLM-generated proposals and retrieval noise, but this is an acceptable cost given the substantially higher recall and the fact that C2B operates without any labeled data.

## Relation to Prior Work

C2B carves new ground by combining two well-studied components—LLM-based reasoning and contrastive text-to-image retrieval (CLIP)—into a pipeline that eliminates the labeled-data requirement shared by all prior bias detection methods (UDIS, DebiAN, DIM, B2T). Conceptually, it extends the LLM-driven bias discovery line (OpenBias, GELDA) from generative models to discriminative classifiers, and repurposes retrieval-based failure-mode tools (Domino, AdaVision) by using LLM-generated captions as the query signal rather than model outputs. The key departure is that no prior method operates with zero task-specific annotations; C2B treats the textual task description as the sole input, making the entire bias-proposal and data-collection process unsupervised.

## Why It Matters / Open Questions

C2B addresses a practical bottleneck: non-expert users downloading pre-trained models cannot realistically collect or access the labeled data that existing bias detectors require, so biases go unreported. The framework is modular (swappable LLMs, retrieval backends, databases) and task-agnostic, positioning it as a building block for automated model auditing at scale. However, absolute detection rates remain low (10–12% HIT on CelebA, 7–11% on ImageNet-X) and false-hit rates are roughly 2–3× those of the supervised B2T baseline, indicating that retrieval noise and LLM hallucination are significant open problems. Future work must improve caption-to-image fidelity, handle intersectional biases, and scale beyond the two datasets tested.

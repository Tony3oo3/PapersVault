## Problem

Existing single-view 3D Gaussian modeling methods enforce a one-to-one correspondence between each Gaussian and either a 2D pixel or a 3D point cloud, causing Gaussians to overfit the correspondence rather than the object itself. This redundancy wastes resources, degrades geometry and texture accuracy, and in pixel-aligned methods leads to quadratic memory growth with input resolution.
![Teaser figure](../imgs/CVPR20252548/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image and its camera pose as input and outputs a fixed set of N=10,000 3D Gaussian parameters (depth-offset center, opacity, quaternion rotation, 3-axis scale, and third-order spherical harmonic coefficients) that are rendered into arbitrary novel views. Unlike pixel-aligned baselines, the number of Gaussians is independent of input resolution, keeping rendering time and memory nearly constant as resolution increases. The center is parameterized by ray depth plus 3D offsets rather than absolute coordinates to aid convergence.

## Method

LeanGaussian replaces pixel- or point-cloud-aligned Gaussian regression with a deformable Transformer decoder in which each of N learnable queries directly represents one 3D Gaussian ellipsoid. A fused feature extractor (UNet for pixel-aligned features + DINOv2 for depth-aware features, combined via an FPN-style block) provides image features that serve as keys and values in deformable cross-attention. The key design is a 3D reference point: the center of each Gaussian is projected onto the image plane under the pinhole camera model, and learned sampling offsets around this projection determine where to bilinearly sample image features for cross-attention. A multi-layer refinement scheme (inspired by DINO) iteratively updates both queries and Gaussian parameters at each decoder layer with per-layer rendering supervision (MSE + LPIPS), allowing progressive improvement of the 3D representation without any explicit pixel or point-cloud alignment.

## Results

On the ShapeNet SRN dataset (category level), LeanGaussian achieves an average PSNR of 25.44 (25.00 on Cars, 25.87 on Chairs), outperforming the previous best method Hierarchical Splatter Image (24.18/25.43) by approximately 0.8–1.4 dB. On the open-category GSO benchmark (trained on Objaverse LVIS), it reaches PSNR 22.36, SSIM 0.884, and LPIPS 0.105, surpassing Splatter Image (PSNR 21.06) by 1.3 dB. The method also achieves a 3D reconstruction speed of 7.2 FPS (0.14 s) and rendering speed of 500 FPS (0.0018 s per view), with total inference under 1 s for 250 novel views.

## Baselines & Comparisons

LeanGaussian outperforms all 11 baselines on both evaluation benchmarks. On ShapeNet SRN, it beats the closest competitor Hierarchical Splatter Image [40] by 0.82 dB (Cars) and 0.44 dB (Chairs) in PSNR, and surpasses Splatter Image [44] by 1.00 dB (Cars) and 1.44 dB (Chairs). On the open-category GSO benchmark, it leads Splatter Image [44] by 1.30 dB (22.36 vs 21.06) and Triplane-Gaussian [58] by 3.75 dB (22.36 vs 18.61), while also avoiding the 3D supervision that Triplane-Gaussian requires. Against NeRF-based methods (pixelNeRF [52], CodeNeRF [14], NeRFDiff [11]), the gains are 1.83–2.70 dB in PSNR on ShapeNet. In inference speed, LeanGaussian (0.590 s total for 250 views) is 1.1× faster than Splatter Image (0.647 s), 3.2× faster than Triplane-Gaussian (1.906 s), 9.0× faster than OpenLRM (5.32 s), and 13.4× faster than LGM (7.934 s), while its 3D reconstruction time of 0.14 s is 16× faster than OpenLRM (2.24 s) and 9× faster than Triplane-Gaussian (1.28 s).

## Relation to Prior Work

LeanGaussian repurposes the Deformable-DETR detection paradigm (queries, deformable cross-attention, reference points) for 3D Gaussian regression, adapting 2D reference points to 3D by projecting Gaussian centers onto the image plane under a pinhole camera model. It departs from the two dominant single-view 3D Gaussian modeling strategies—pixel-aligned regression (Splatter Image) and point-cloud/triplane-aligned regression (Triplane-Gaussian)—by eliminating the one-to-one correspondence entirely and instead using a fixed set of learnable queries refined layer-by-layer. The depth-offset parameterization and third-order SH color representation are inherited from Splatter Image, while the multi-layer refinement with per-layer supervision follows the DINO detection framework.

## Why It Matters / Open Questions

By removing the pixel or point cloud correspondence, LeanGaussian avoids the redundancy and overfitting that plagues prior methods (e.g., Splatter Image concentrating over half its Gaussians in a background plane), yielding both better geometry and a resolution-independent memory footprint. The 7.2 FPS reconstruction and 500 FPS rendering speeds make it practical for real-time applications, and the view-wise analysis revealing that prior methods 'shortcut' near views while degrading sharply for far views provides useful diagnostic insight. Open questions remain around background texture generation (no input image available) and self-occluded regions, which the authors acknowledge as significant limitations. Whether the query-based formulation scales to more complex scenes or larger Gaussian counts without the fixed-N constraint is unexplored.

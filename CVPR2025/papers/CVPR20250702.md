## Problem

While CLIP-based vision-language models are increasingly deployed in safety-critical applications, their prediction reliability remains underexplored. Applying split conformal prediction to these zero-shot VLMs is complicated by a domain drift between the inaccessible pre-training source and the target task, which degrades conformal set efficiency. Moreover, adapting the model using the calibration set (e.g., via few-shot linear probing) breaks the exchangeability assumption that underpins conformal coverage guarantees.

## Input / Output

The method consumes temperature-scaled cosine-similarity logits (K × (N+M) matrix) produced by a frozen CLIP encoder over a labeled calibration set and an unlabeled query set, with no access to the pre-training data. It outputs, for each query image, a set-valued prediction (subset of class labels) whose marginal coverage is guaranteed at a user-specified level (e.g., 95%). The conformal sets are generated by plugging the OT-derived soft codes into standard non-conformity scores (LAC, APS, RAPS), so the output structure is identical to any split conformal pipeline but with tighter, more adaptive sets.

## Method

Conf-OT is a training-free, transductive transfer step that replaces raw CLIP logits with soft class-assignment codes obtained by solving an entropic optimal transport problem over the joint calibration-and-query similarity matrix. The OT objective maximizes total similarity assignment subject to two marginal constraints: a uniform sample-marginal (even distribution across data points) and a label-marginal estimated from the calibration set's class frequencies, which anchors the solution to the target distribution. The Sinkhorn algorithm with a fixed entropic weight (τ=1) and only 3 iterations yields the transport plan in ~1.1 s even at ImageNet scale (K=1000, N+M=50000), requiring no GPU. Because the transfer is unsupervised and jointly applied to calibration and query points, the exchangeability assumption is preserved, and the resulting codes can be fed into any conformal score without additional data splits.

## Results

Across 15 image classification datasets, Conf-OT reduces average conformal set size by ~20% relative to the zero-shot baseline while maintaining the target coverage (e.g., LAC set size drops from 5.52 to 4.40 at α=0.10 with CLIP ViT-B/16). Top-1 accuracy improves by 2.9 points (63.8% → 66.7%) as a byproduct of the transductive transfer. The entire Conf-OT pipeline adds only 0.61 s of inference overhead on CPU with no GPU memory, compared to 11–12 s and 8–12 GB peak GPU for the transductive baselines TIM and TransCLIP.

## Baselines & Comparisons

Conf-OT outperforms both transductive baselines (TIM and TransCLIP) on every reported metric: Top-1 accuracy (66.7% vs. 64.7–65.1%), average set size (e.g., 4.40 vs. 7.73–8.30 for LAC), class-conditional coverage gap (9.48 vs. 10.41–11.02 for LAC), and inference time (0.61 s vs. 11–12 s, roughly ×15–20 faster with no GPU). TIM_KL variants actually *increase* set size relative to the zero-shot LAC baseline (5.52 → 7.73–8.30), indicating that their information-maximization objective conflicts with conformal set efficiency. TransCLIP achieves a marginally smaller LAC set size than the base (5.76 vs. 5.52 is actually worse; 5.76 > 5.52) and fails to meet the target marginal coverage (0.892 vs. 0.900), likely due to its Laplacian regularization not jointly optimizing calibration and test sets. The one exception is TIM_KL(m̂‖u_K) with the APS score, which yields a slightly smaller set (7.24 vs. 7.64), but the authors show this advantage does not persist across additional backbones or coverage levels. Overall, Conf-OT is the only method that simultaneously improves discrimination, set efficiency, class-conditional coverage, and computational cost.

## Relation to Prior Work

This paper extends split conformal prediction (Papadopoulos et al.; Vovk et al.) to the zero-shot VLM setting, where the base model is pre-trained on an inaccessible source domain, creating a domain gap absent in prior vision conformal work that assumed in-distribution specialized classifiers. The key methodological departure is the use of Sinkhorn optimal transport (Cuturi) as a training-free, transductive bridge between source and target domains, constrained by the calibration set's label-marginal distribution to preserve exchangeability. This contrasts with prior transductive conformal inference (Gazin et al.), which assumes access to source training data and requires retraining the base model, and with existing transductive VLM adaptation methods (TIM, TransCLIP) that operate inductive or require GPU-based optimization.

## Why It Matters / Open Questions

The work provides the first systematic conformal prediction framework for foundation VLMs with theoretical coverage guarantees, addressing a critical gap for safety-critical deployments (autonomous driving, medical imaging) where calibrated uncertainty is essential. The practical impact is significant: a 3-iteration CPU-only Sinkhorn procedure outperforms GPU-based transductive baselines by up to 20% in set efficiency while being ×15 faster, making conformal VLM inference viable in resource-constrained settings. Limitations include the transductive requirement (all test data must be available simultaneously) and the exchangeability assumption, which may not hold under severe distribution shifts. Open questions include whether the approach extends to other VLM architectures, open-vocabulary settings, or sequential/streaming inference scenarios.

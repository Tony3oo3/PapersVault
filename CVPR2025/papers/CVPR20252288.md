## Problem

Standard autoregressive (AR) modeling predicts the next token based solely on a single agent's preceding tokens, which is insufficient for physical-world multi-agent interactions where an agent's future behavior is shaped by the simultaneous states of other interacting agents. The paper argues that AR alone cannot capture these cross-agent dependencies and that a unified framework is needed to model how multiple agents influence each other's behavior across diverse interaction types.
![Teaser figure](../imgs/CVPR20252288/cropped_page0_idx1.webp)

## Input / Output

The model consumes a flattened sequence of N×T tokens (one or more tokens per agent per timestep), where tokens can be discrete codebook indices or continuous vectors (e.g., 60D action one-hot vectors, integer velocity/acceleration tokens, or 3D/4D pose vectors). For the trajectory task, relative locations of other agents are injected via a sincosine location positional encoding (LPE) summed to token embeddings. The output is the ego agent's predicted future state, generated one timestep at a time via greedy decoding, with the specific output format (action probabilities, xy coordinates, or 6DoF pose) determined by the task's tokenization.

## Method

PAR modifies standard AR in three ways: (1) same-agent next-timestep prediction, where the model predicts agent k's state at t+1 rather than agent k+1's state at t, enabling cross-agent attention within a single prediction step; (2) learned agent ID embeddings summed to token embeddings so the model can distinguish which token belongs to which agent; and (3) joint training where losses are computed on all agents' future predictions simultaneously. The backbone is a Llama transformer decoder (8 layers, 8 heads, 128 hidden dim, ~4.4M parameters) with rotary positional encoding, trained with teacher forcing. The same architecture and hyperparameters are used across all three case studies, with only data pre-processing and tokenization changing per task.

## Results

On AVA social action forecasting, 2-agent PAR achieves 42.6 mAP versus 40.7 mAP for 1-agent AR (+1.9 absolute), with a larger +3.5 mAP gain on 2-person interaction classes. On nuScenes trajectory prediction, 3-agent PAR with acceleration tokens and location positional encoding achieves 1.35 ADE / 3.34 FDE, outperforming 1-agent AR (1.44 ADE / 3.57 FDE) by 6.3% and 6.4% relative improvement respectively. On DexYCB object pose forecasting, 2-agent PAR (hand + object) reduces rotation error from 0.919 to 0.837 rad (8.9% relative improvement) and translation MSE from 3.68×10⁻³ to 2.17×10⁻³ (41.0% relative improvement) over object-only AR.

## Baselines & Comparisons

The primary comparison is between the proposed 2-agent (or 3-agent) PAR model and a single-agent AR baseline using the same 4.4M-parameter Llama transformer decoder. PAR consistently outperforms AR across all three tasks: +1.9 mAP on AVA, 6.3%/6.4% relative ADE/FDE on nuScenes, and 8.9%/41.0% relative rotation/translation improvement on DexYCB. Against simple non-learned baselines (Random Token, Random Trajectory, Nearest Neighbor, Multiagent NN, Mirror), both AR and PAR are substantially better; the strongest simple baseline is single-agent NN (13.17 mAP on AVA, 1.80 ADE on nuScenes, 1.69×10⁻² MSE on DexYCB), which is still far below the learned models. A key ablation finding is that naively applying multi-agent next-token prediction (2-agent AR) actually degrades performance below single-agent AR (38.0 vs 40.7 mAP on AVA), confirming that the same-agent next-timestep prediction and learned agent ID embedding are both necessary for PAR to succeed.

## Relation to Prior Work

This paper repurposes the autoregressive transformer paradigm from NLP (GPT-style next-token prediction) to multi-agent physical interaction prediction, but makes a key conceptual departure: instead of predicting the next token in a flattened multi-agent sequence (which would be the next agent at the same timestep), it predicts the same agent's next timestep while conditioning on all other agents' states. It draws on MotionLM's use of multi-agent tokens with learned agent ID embeddings and on the broader transformer-based social interaction literature (dyadic communication, social dance), but unifies these previously separate problem formulations—action forecasting, vehicle trajectory prediction, and hand-object pose forecasting—under a single PAR framework with only data-preprocessing changes. The architecture itself is a small Llama decoder with rotary positional encoding, and the location positional encoding (LPE) for trajectory prediction is a lightweight extension rather than a new architectural component.

## Why It Matters / Open Questions

The PAR framework offers a clean, minimal recipe for incorporating multi-agent context into prediction tasks, demonstrated across three diverse domains with a single 4M-parameter model, suggesting the approach is broadly applicable and easy to adopt. However, the evidence is proof-of-concept scale: small models, small datasets, and no environmental or visual context, so it remains open whether the gains persist with larger backbones, noisier tracking, or more agents. The authors identify natural extensions—dynamic attention for agent importance, pixel-level tokenization to relax tracking assumptions, and scaling—that could substantially broaden the framework's impact, but none are explored here.

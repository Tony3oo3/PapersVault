## Problem

Existing preference alignment methods for text-to-image diffusion models, such as Diffusion-DPO, optimize a single population-level reward and cannot capture the diverse, individual-level preferences of different users. Training a separate model per user is impractical and does not scale, and prior controllable-generation approaches (e.g., IP-Adapter) rely on single-image conditioning rather than learning from preference data. The paper asks whether a single diffusion model can be personalized to many users simultaneously and generalize to unseen users from only a handful of preference examples.

## Input / Output

At inference, the model takes a text prompt and a user preference embedding (a frozen hidden state from LLaVA-OneVision computed over 4 few-shot preferred/dispreferred image pairs) and produces a single generated image aligned to that user's taste. The user embedding can be set to zero for unconditional generation, or linearly interpolated across multiple reward directions to trade off objectives (e.g., CLIP alignment vs. aesthetic score vs. HPS) at test time without retraining. The base model is Stable Cascade Stage C, generating images at its native resolution with 30 DDIM steps.

## Method

PPD is a two-stage framework. In Stage 1, a VLM (LLaVA-OneVision) processes N=4 few-shot preference pairs per user and extracts a frozen intermediate hidden state as the user embedding, which the authors validate can classify users with 90% top-16 accuracy. In Stage 2, the Stable Cascade diffusion model is conditioned on this embedding via decoupled cross-attention layers (analogous to IP-Adapter): new key/value projections are added to each existing cross-attention layer in Stage C, and their outputs are summed with the text cross-attention output. Training uses a personalized variant of the Diffusion-DPO objective (Eq. 6) that adds the user embedding as an extra conditioning input to the denoiser, optimizing only the added cross-attention parameters while keeping the pretrained model frozen. A key design choice is random dropout of the user embedding during training, which enables both personalized and unconditional generation from the same model.

## Results

On the synthetic user alignment task (Table 1), PPD achieves CLIP 32.66, Aesthetic 5.92, and HPS 27.51, outperforming Stable Cascade (31.97/5.33/23.87) and Diffusion-DPO (32.48/5.46/25.96) across all three reward functions while approaching the per-reward Diffusion-DPO upper bounds (32.96/6.42/28.61). In the real-user setting evaluated with GPT-4o as judge, PPD achieves an 83% win rate on seen users and 78% on unseen users (81% aggregated) over Stable Cascade, using only 4 few-shot preference examples per user. The VLM-based user embeddings achieve 90% top-16 accuracy in a user classification probe, confirming they encode meaningful per-user preference signals.

## Baselines & Comparisons

PPD outperforms Stable Cascade on all three reward metrics (CLIP +0.69, Aesthetic +0.59, HPS +3.64) and achieves 60%/90%/93% win rates over it in the synthetic setting. Against Diffusion-DPO (which optimizes a single population-level preference), PPD wins on all three rewards (CLIP 32.66 vs 32.48, Aesthetic 5.92 vs 5.46, HPS 27.51 vs 25.96), demonstrating the advantage of multi-reward personalization over single-reward alignment. PPD also surpasses SFT with user conditioning by a large margin, particularly on Aesthetic (5.92 vs 5.56) and HPS (27.51 vs 25.78). The closest comparison is against per-reward Diffusion-DPO upper bounds, where PPD trails by 0.30 (CLIP), 0.50 (Aesthetic), and 1.10 (HPS), but crucially does so with a single model that can interpolate between objectives at inference time. In the real-user evaluation with GPT-4o as judge, PPD achieves 81% aggregate win rate over Stable Cascade, confirming practical personalization gains with only 4 preference examples per user.

## Relation to Prior Work

This paper extends Diffusion-DPO [45] by augmenting its objective with user-specific conditioning, transforming a single-reward alignment problem into a multi-reward, multi-user optimization. The conditioning mechanism borrows the decoupled cross-attention architecture from IP-Adapter [51], repurposing it to inject VLM-derived user preference embeddings rather than reference image features. The personalized optimal policy is derived from the DPO closed-form solution [32], generalized to a per-user reward function. The key conceptual departure from prior work is using a frozen VLM (LLaVA-OneVision) to extract few-shot preference embeddings as a compact, generalizable user representation, rather than training per-user models or relying on explicit user metadata.

## Why It Matters / Open Questions

Personalized text-to-image generation is a practical need that population-level alignment cannot address, and this paper shows that as few as 4 preference examples per user suffice for meaningful personalization with a single shared model. The ability to linearly interpolate between reward objectives at inference time (CLIP, Aesthetic, HPS) suggests the learned embedding space has a useful geometric structure, enabling flexible trade-offs without retraining. Limitations include the caption-agnostic selection of few-shot examples, reliance on a single base model (Stable Cascade), and evaluation on one dataset (Pick-a-Pic). Open questions include active preference selection, extension to video generation, and the trade-off between implicit behavioral preferences and explicitly stated ones.

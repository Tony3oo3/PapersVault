## Problem

Existing object compositing datasets are either synthetic, limited in scale, not publicly available, or designed solely for benchmarking without supporting model training. No large-scale, real-captured, public dataset provides factual-counterfactual image pairs across diverse scenes and multiple object positions, leaving a critical gap for training models that handle real-world lighting, shadows, and reflections.
![Teaser figure](../imgs/CVPR20250310/cropped_page0_idx0.webp)

## Input / Output

For object removal, the model takes an RGB image containing an object plus its segmentation mask and outputs the corresponding background-only image; for object insertion, it takes a target scene, a source object image, and the object mask, producing a composited image with the object naturally integrated. The U-Net consumes a 9-channel latent input (4 input latent + 4 condition latent + 1 binary mask channel), and all images carry annotations including captions, object points, bounding boxes, and SAM2-generated segmentation masks. Training further exploits raw DNG files to apply ISP-level color and lighting augmentations beyond what standard JPEG/PNG pipelines allow.

## Method

The core contribution is the ORIDa dataset: over 30,000 real-captured images of 200 objects across ~50 scenes each, structured as factual-counterfactual sets (one background-only image plus four object-positioned images per scene) and factual-only images for additional scene diversity. For experiments, the authors fine-tune a pretrained Stable Diffusion Inpaint model without architectural changes, feeding the 9-channel U-Net input described above. Training diversity is expanded by applying five ISP augmentations (as-shot, higher/lower temperature, higher/lower vibrance) to raw DNG files via Adobe Lightroom, and object insertion training additionally incorporates 60K COCO images with 250K object masks to preserve source identity. Crucially, no synthetic data is generated at any stage, avoiding the masked-refilling pipelines used by prior methods like ObjectStitch and ObjectDrop.

## Results

For object removal on the ORIDa held-out test set, the fine-tuned SD-Ours_r model achieves PSNR 25.60, DINO 0.902, CLIP 0.938, and LPIPS 0.088, substantially outperforming the SD-Inpaint baseline (PSNR 21.76, DINO 0.845, CLIP 0.903, LPIPS 0.108). In user studies (76 participants), SD-Ours_r receives a rating of 4.23/5 versus 2.78 for SD-Inpaint, 2.63 for LaMa, and 1.96 for MGIE. For object insertion (62 participants), SD-Ours_i achieves preference scores of 66% (identity), 79% (shadow/reflection), 71% (color harmonization), and 67% (overall quality), outperforming Copy & Paste, Paint-by-Example, AnyDoor, and ObjectStitch across all four criteria.

## Baselines & Comparisons

For object removal, SD-Ours_r (fine-tuned on ORIDa) decisively beats all three baselines: it improves PSNR by 3.84 dB over SD-Inpaint (25.60 vs. 21.76), reduces LPIPS by 18.5% (0.088 vs. 0.108), and gains 0.035/0.057 on DINO/CLIP similarity. In user studies, it scores 4.23/5 versus 2.78 (SD-Inpaint), 2.63 (LaMa), and 1.96 (MGIE), with the gap most pronounced against MGIE, which introduces artifacts from text-prompt-based editing. For object insertion, SD-Ours_i wins on all four user-study criteria against four baselines: it leads AnyDoor and ObjectStitch (the strongest competitors) by a clear margin on shadow generation (79% preference) and color harmonization (71%), while Paint-by-Example struggles most with identity preservation and Copy & Paste cannot generate object-to-scene effects like realistic shadows. The consistent advantage across both tasks validates ORIDa as a sufficient training resource without any synthetic data.

## Relation to Prior Work

ORIDa extends the factual-counterfactual data paradigm introduced by ObjectDrop [39]—where a scene is captured with and without an object to model object-to-scene effects—by scaling it from a single scene and single position per object to approximately 50 scenes with up to four object positions per scene, and by making the data publicly available with raw DNG files. Methodologically, the paper fine-tunes the Stable Diffusion inpainting architecture [27] without structural modifications, positioning itself against both synthetic-data-driven compositing methods (ObjectStitch [34], Paint-by-Example [42]) and training-free approaches (FreeCompose [3], TF-ICON [23]). The use of SAM2 for segmentation and GPT-4o/Gemini 1.5 Pro for captioning reflects a modern annotation pipeline, while the ISP augmentation via Adobe Lightroom on DNG files is a distinctive data-augmentation strategy not seen in prior compositing datasets.

## Why It Matters / Open Questions

ORIDa fills a critical gap as the first large-scale, publicly available, real-captured dataset purpose-built for object compositing, enabling training and evaluation without reliance on synthetic data whose realism is inherently limited. The inclusion of raw DNG files opens a new axis of augmentation (color temperature, vibrance) directly relevant to the harmonization challenge, and the capture of both object-to-scene and scene-to-object effects provides a more complete supervision signal than prior datasets. Limitations include the fixed object poses (limiting pose generalization), the 200-object scale (narrow compared to open-world scenarios), and the single-camera-position constraint within each F-CF set. Open questions include whether models trained on ORIDa generalize to unseen objects and whether the dataset's scene diversity is sufficient for truly open-world deployment.

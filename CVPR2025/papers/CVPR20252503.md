## Problem

LiDAR-based 3D object detection depends on expensive real-world annotations (≈10 min/frame) and cannot cover rare corner-case categories. While simulators like CARLA can generate labeled point clouds with corner cases at scale, directly mixing synthetic data into real training degrades performance due to low sample efficiency of simulation data and the sim-to-real gap in point distributions and feature channels.
![Teaser figure](../imgs/CVPR20252503/cropped_page2_idx0.webp)

## Input / Output

The method jointly consumes real LiDAR point clouds (xyz + intensity + timestamp, d=2 channels) and CARLA simulation point clouds (xyz only, d=0 channels) with 3D bounding box labels. It outputs 3D bounding boxes containing category, xyz-location, xyz-size, yaw orientation, and x/y velocities. A key constraint is the mismatched input dimensionality between domains, which the architecture must handle without discarding available information.

## Method

JiSAM is a plug-and-play module with three components applied on top of a standard sparse-convolution + BEV + detection-head pipeline (e.g., Transfusion). (1) Jittering Augmentation adds per-point Gaussian noise in spherical coordinates (r, θ, φ) to simulation point clouds during training, increasing surface diversity without generating more data. (2) A domain-aware backbone uses separate input convolution kernels for real (5-channel) and simulation (3-channel) inputs while sharing all subsequent 3D sparse convolution blocks, adding <0.025% parameters. (3) A memory-based Sectorized Alignment Loss divides the ego-vehicle neighborhood into 32 shape-context sectors × 32 heading bins × N categories, maintains object-level BEV feature memories updated via momentum from real data, and applies MSE alignment between simulation object features and the corresponding memory entries (bidirectionally for both domains), bridging the sim-to-real shape gap.

## Results

On NuScenes, JiSAM (Transfusion + simulation data + 2.5% real labels) achieves mAP 63.95 and NDS 69.36, nearly matching Transfusion trained on all real labels (mAP 64.51, NDS 69.31) while using only ~7,000 labeled real point clouds instead of ~280,000. In the corner-case experiment where motorcycle labels are removed from the real training set, JiSAM still achieves approximately 16% AP on motorcycle and a slightly higher overall mAP than the full-label SOTA baseline. Compared to Transfusion trained on the same 2.5% real labels without simulation data, JiSAM gains approximately 4 mAP and 3 NDS.

## Baselines & Comparisons

JiSAM (Transfusion + JiSAM, trained on simulation data only) achieves mAP 63.95 and NDS 69.36, essentially matching Transfusion trained on all real labels (mAP 64.51, NDS 69.31) with only a 0.56 mAP gap while using no real labels at all. It clearly outperforms VoxelNext (mAP 60.53, NDS 66.65) by 3.4 mAP, CenterPoint (mAP 59.22, NDS 66.48) by 4.7 mAP, SECOND (mAP 50.59) by 13.4 mAP, and PointPillars (mAP 44.63) by 19.3 mAP. Notably, JiSAM slightly exceeds Transfusion (full real) on NDS (69.36 vs. 69.31), suggesting the simulation data adds complementary diversity. In the corner-case setting (motorcycle labels removed from real training), JiSAM achieves ~16% AP on motorcycle and a marginally higher overall mAP than the full-label SOTA, while maintaining comparable APs on other categories (within 0.5%).

## Relation to Prior Work

JiSAM positions itself against two main streams of label-efficient LiDAR perception: semi-supervised learning (pseudo-labeling) and large-scale pre-training, both of which the authors note still lag far behind full-label SOTA and cannot handle unlabeled categories. It also departs from prior sim-to-real transfer attempts (e.g., adversarial training on point clouds, ResimAD) that directly incorporate synthetic data without addressing the sim-to-real gap. The method's components draw from distinct lineages: jittering augmentation from statistical LiDAR noise models, shape context for spatial sectorization, and RoI-grid pooling for object-level feature extraction, combined into a unified plug-and-play framework built on Transfusion.

## Why It Matters / Open Questions

The practical impact is substantial: reducing real labeling by 97.5% while maintaining SOTA-level detection performance directly addresses the primary bottleneck in deploying LiDAR perception systems. The corner-case capability (detecting categories absent from real training labels at ~16% AP) opens a path toward handling rare traffic participants that real datasets inherently underrepresent. However, the evidence is confined to a single dataset (NuScenes) and primarily one detector (Transfusion), and the method's transferability to other simulators, sensor configurations, or urban environments remains untested. An open question is how JiSAM interacts with emerging LiDAR generative models, which the authors note is orthogonal but unexplored.

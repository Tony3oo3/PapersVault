## Problem

Mainstream image tokenization methods face a fundamental trade-off between compression rate and reconstruction quality: high compression reduces computational cost for generation but sacrifices fidelity, while preserving quality demands prohibitively many tokens. This paper identifies that the most concise semantic representation of an image is its language description, and proposes leveraging text captions to offload high-level semantic learning from the tokenizer, freeing token capacity for fine-grained visual details.
![Teaser figure](../imgs/CVPR20250075/cropped_page0_idx0.webp)

## Input / Output

The tokenizer takes an RGB image (256×256 or 512×512) and a text caption (up to 75 words, encoded to 128 tokens by a frozen T5 encoder) and produces N continuous latent image tokens of dimension d=8, where N is flexibly set to 32, 64, 128, or 256. During detokenization, the same text tokens are concatenated with the image tokens and learnable patch tokens to reconstruct the image. For class-conditional generation, only the class label conditions the DiT generator; a caption is then sampled from a pre-generated list for that class and injected at detokenization time, so no caption is needed at generation time.

## Method

TexTok uses a ViT-Base backbone (~176M params) for both the tokenizer and detokenizer, adopting the 1D global-token paradigm. The key mechanism is in-context conditioning: frozen T5 text embeddings are linearly projected and concatenated with image patch tokens and N learnable image tokens in the tokenizer's self-attention layers, and similarly concatenated with image tokens and learnable patch tokens in the detokenizer. The tokenizer outputs only the N learned image tokens (projected to d=8), while the detokenizer reconstructs the image from the patch-token outputs. Training combines ℓ2 reconstruction, GAN (StyleGAN discriminator), perceptual, and LeCAM regularization losses. For generation, a vanilla DiT is trained on the TexTok latent tokens; only image tokens are generated, and text tokens are supplied at detokenization, yielding up to 93.5× inference speedup over the original DiT while improving FID.

## Results

TexTok-256 + DiT-XL achieves state-of-the-art FID of 1.46 on ImageNet 256×256 and 1.62 on ImageNet 512×512, surpassing all prior methods including MDTv2-XL/2 (1.58) and EDM2-XXL (1.81). Remarkably, TexTok-32 + DiT-XL uses only 32 latent tokens yet achieves FID 2.74 on ImageNet 512×512, outperforming the original DiT-XL/2 (FID 3.04) which requires 4096 tokens — a 93.5× inference speedup. On ImageNet 256×256, TexTok-64 + DiT-XL (FID 2.06) outperforms DiT-XL/2 (FID 2.27) while generating only 64 tokens versus 1024. For text-to-image generation, TexTok-128 achieves FID 2.82 and CLIP Score 29.23 on ImageNet 256×256.

## Baselines & Comparisons

TexTok-256 + DiT-XL (FID 1.46) outperforms the strongest prior latent diffusion methods on ImageNet 256×256: MDTv2-XL/2 (1.58), DiffiT (1.73), REPA+SiT-XL/2 (1.80), and DiT-XL/2 (2.27), while using a simpler vanilla DiT generator. On ImageNet 512×512, TexTok-256 + DiT-XL (FID 1.62) beats EDM2-XXL (1.81), DiT-XL/2 (3.04), and U-ViT-H (4.05). The most striking comparison is at extreme compression: TexTok-32 + DiT-XL (FID 2.74, 32 tokens) surpasses DiT-XL/2 (FID 3.04, 4096 tokens) on ImageNet 512×512, achieving a 93.5× inference speedup. TexTok-64 + DiT-XL (FID 1.99) also clearly beats DiT-XL/2 (3.04) on ImageNet 512×512. Against autoregressive baselines, TexTok-256 + DiT-XL (1.46) outperforms MAR (1.55), VAR (1.92), and LlamaGen-3B (2.18) on ImageNet 256×256. The only method that beats TexTok-256 on ImageNet 256×256 is MaskBit (1.52), but MaskBit does not report ImageNet 512×512 results, and TexTok's advantage is most pronounced at higher resolutions and lower token budgets.

## Relation to Prior Work

TexTok builds directly on the 1D global-token tokenizer paradigm introduced by TiTok (Yu et al., NeurIPS 2024) and the Diffusion Transformer (DiT) generation framework (Peebles & Xie, ICCV 2023), but introduces a fundamentally new ingredient: conditioning the tokenization process itself on detailed text captions via in-context concatenation of T5 text embeddings into both the ViT-based tokenizer and detokenizer. This departs from prior work on image-text alignment in tokenization (LG-VQ, LQ-VAE, SPAE), which enforces strict alignment between image tokens and text tokens in a frozen LLM codebook, by instead using text as a soft semantic prior that offloads high-level semantic learning from the tokenizer, freeing capacity for fine-grained visual detail. The paper is also the first to apply detailed (75-word) captions at the tokenization stage rather than reserving text conditioning for the generation stage alone.

## Why It Matters / Open Questions

The practical impact is substantial: simply replacing the tokenizer in DiT with TexTok yields a 93.5× inference speedup on ImageNet-512 while outperforming the original DiT, and achieves state-of-the-art FID (1.46/1.62) with a vanilla DiT generator. The conceptual insight—that explicit text semantics can replace the need for the tokenizer to learn image semantics, enabling 2×–4× higher compression rates without quality loss—opens a new design axis for image tokenizers that is orthogonal to and composable with existing generation architectures. A key limitation is the dependence on high-quality captions (generated here by Gemini), which, while readily available for text-to-image tasks, introduces a dependency for class-conditional settings; whether the gains persist on open-domain, uncurated image distributions beyond ImageNet remains an open question.

## Problem

Existing zero-shot composed image retrieval (ZS-CIR) methods map reference images directly to pseudo-word tokens in CLIP's language space, but they ignore visual content that is missing from the reference image yet required by the manipulation text (e.g., domain style, additional objects, specific attributes). This limits retrieval accuracy when key target elements are absent from the reference, and the coarse-grained CLIP embedding further loses fine-grained visual details critical for composed retrieval.

## Input / Output

At inference, the method takes a reference image and a manipulation text, producing a pseudo-word token S* in CLIP's token embedding space that is spliced into a prompt sentence (e.g., 'a photo of [S*], [manipulation text]') and embedded by CLIP's frozen text encoder to form a composed query for similarity matching against candidate images. During training, the model consumes image-caption pairs from Conceptual Captions (3M images), where each image is randomly cropped (crop size 0.2–0.25, aspect ratio 0.75–1.5) to create a source view, with the original image serving as the target view and the caption as the action signal. The CLIP visual encoder (ViT-L/14 or ViT-G/14) produces 257 patch-level feature vectors of dimension 1024 for each view.

## Method

PrediCIR introduces a prediction-based image-to-word mapping network built on the JEPA framework. A World View Generation module constructs training triplets by randomly cropping images from image-caption pairs, treating the crop as the source view, the original as the target view, and the caption as the action. The Target Content Predictor (TCP) is a 12-block self-attention transformer that takes the concatenation of the action embedding, source local patch features, and mask tokens (representing a randomly sampled block of target patches) as input, and predicts the missing target patch features in latent space via L2 regression. The Predictive Cross-Modal Alignment (PMA) module then adaptively fuses the predicted target patches and enhanced source patches through a learnable scalar gate, adds the global source feature, and maps the result to a pseudo-word token via a 3-layer FFN. The token is aligned to CLIP's text space using a symmetric contrastive loss between the composed prompt sentence embedding and the global target visual feature, requiring no additional supervision beyond image-caption pairs.

## Results

PrediCIR achieves state-of-the-art results across all six ZS-CIR benchmarks, with improvements of 1.73%–4.45% over the best prior methods. On CIRR (ViT-L/14), it reaches R@1=27.2, R@5=57.0, R@10=70.2, surpassing Context-I2W (25.6/55.1/68.5). On Fashion-IQ (ViT-L/14), the average R@10/R@50 is 30.1/52.3 vs. 27.8/48.9 for Context-I2W. The largest gain appears on ImageNet domain conversion (ViT-L/14), where PrediCIR achieves average R@10=16.4 vs. 12.9 for Context-I2W (+4.45%). On the larger ViT-G/14 backbone, PrediCIR extends its lead, e.g., CIRR R@10=77.9 vs. LinCIR's 76.1.

## Baselines & Comparisons

PrediCIR outperforms all five baselines on every benchmark and both backbones. Against the strongest zero-shot baseline Context-I2W (AAAI 2024), PrediCIR gains +1.6 R@1 on CIRR, +2.3 R@10 on Fashion-IQ, +2.7 mAP@5 on CIRCO, +1.6 R@1 on COCO, +3.5 R@10 on ImageNet, and +4.1 R@1 on GeneCIS. Against LinCIR (CVPR 2024), the closest competitor on ViT-G/14, PrediCIR leads by +1.7 R@10 on CIRR and +2.1 R@10 on Fashion-IQ. Against the semi-supervised diffusion-based CompoDiff (TMLR 2024), PrediCIR surpasses it by +3.4 R@10 on CIRR (ViT-G/14) while being 4× faster at inference (0.03 s vs. 0.12 s) and requiring no synthetic triplet data. Pic2Word and SEARLE-XL, the earlier pseudo-word mapping methods, are consistently outperformed by 2–4 points in R@10 across all tasks, confirming that predicting missing target content before mapping is more effective than direct image-to-word projection.

## Relation to Prior Work

PrediCIR extends the pseudo-word mapping paradigm established by Pic2Word and refined by SEARLE, LinCIR, and Context-I2W, which all map reference images directly into CLIP's language space. The key conceptual departure is borrowing the Joint Embedding Predictive Architecture (JEPA) and world-model prediction framework from visual representation learning (Assran et al. 2023; Garrido et al. 2024) to first predict target-relevant visual content missing from the reference image before performing the mapping. This positions the work at the intersection of self-supervised predictive learning and vision-language retrieval, departing from both masked CIR methods that require CLIP fine-tuning and diffusion-based approaches like CompoDiff that demand multi-step generation and synthetic triplets.

## Why It Matters / Open Questions

The prediction-before-mapping strategy addresses a fundamental gap in ZS-CIR: reference images frequently lack the very content the manipulation text specifies (e.g., a new domain, an absent object, a missing attribute), and existing methods cannot recover this information. The consistent 1.73%–4.45% gains across six heterogeneous tasks (domain conversion, object composition, attribute manipulation, scene editing) with a single unified mechanism and lightweight inference (0.03s) make this practically relevant for deployment. Open questions remain around handling complex multi-object or redundant manipulation texts (identified as common failure cases), scaling the predictor to larger models, and whether the world-model framing can be extended beyond patch-level prediction to more structured scene understanding.

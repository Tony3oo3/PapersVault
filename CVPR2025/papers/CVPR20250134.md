## Problem

Adapting pre-trained generative models to specific domains (e.g., a movie's visual style or character identities) typically demands large amounts of paired image-text data, which is scarce and impractical to collect at scale. This paper asks whether the bidirectional vision-language mappings already learned by a unified generative model can be exploited to perform domain adaptation using only unpaired images and texts, eliminating the need for manual annotation.

## Input / Output

The method consumes unpaired images (discrete visual tokens) and unpaired text sequences from the target domain, with no requirement that any image corresponds to any text. For the T cycle, the input is a text sequence and the output is the same text sequence (cycle-consistency loss); for the I cycle, the input is an image token sequence and the output is the same image tokens. The adapted Show-o model then performs standard text-to-image generation (discrete image tokens decoded to RGB) and image-to-text captioning. When paired knowledge is needed (e.g., binding a character name to a face), a small set of 1–3 annotated pairs per identity is mixed into the unpaired training batches.

## Method

DoraCycle builds on Show-o, a single-transformer unified model that autoregressively predicts both text and image tokens, and inserts LoRA adapters (rank 32) into attention Q/V projections of layers 7–24. The core mechanism is two multimodal cycles: a T cycle (text → pseudo-image → text) and an I cycle (image → pseudo-text → image), each computing cross-entropy loss only at the same-modality endpoint, so no paired supervision is needed. A slowly updated EMA copy of the model generates the intermediate pseudo-data (captions or image tokens) to stabilize training, while Gumbel-Softmax makes discrete token outputs differentiable. To prevent the faster-converging T cycle from collapsing the I cycle, gradient surgery projects the T-cycle gradient onto the orthogonal complement of the I-cycle gradient, and a loss reweighting factor β=0.1 further balances the two objectives.

## Results

On Storyboard20K, DoraCycle with 10% paired + 90% unpaired data achieves FID-1K of 25.37 and CIDEr of 40.90, closely matching DreamBooth trained on 100% paired data (FID 24.93, CIDEr 41.55) while using only 10% of the paired annotations. With fully unpaired data (100%U), DoraCycle reaches FID-1K 27.44 and CIDEr 38.17, already surpassing DreamBooth with only 10% paired data (FID 33.22, CIDEr 32.74). Human evaluation scores (out of 5) confirm these trends, with DoraCycle (10%P+90%U) scoring 4.12/3.81 versus DreamBooth 100%P at 4.13/3.96.

## Baselines & Comparisons

Against DreamBooth, DoraCycle with 10% paired + 90% unpaired data (FID 25.37, CIDEr 40.90) substantially outperforms DreamBooth at the same 10% paired budget (FID 33.22, CIDEr 32.74), demonstrating that the 90% unpaired data provides significant additional signal. DoraCycle's best setting is nearly on par with DreamBooth using 100% paired data (FID 24.93, CIDEr 41.55), meaning DoraCycle achieves comparable quality while requiring only 10% of the annotation effort. Against ITIT, which also leverages cycle consistency with unpaired data, DoraCycle wins on all three metrics at the same 10%P+90%U setting: FID 25.37 vs. 27.50, CIDEr 40.90 vs. 38.62, and human eval 4.12/3.81 vs. 3.85/3.52. The ablation within DoraCycle shows that both cycles are necessary—removing the T cycle degrades captioning (CIDEr drops to 30.54) while removing the I cycle degrades image quality (FID rises to 36.63).

## Relation to Prior Work

DoraCycle builds directly on Show-o, a unified single-transformer model that jointly predicts discrete text and image tokens, repurposing its bidirectional vision-language mappings as the substrate for self-supervised domain adaptation. Conceptually, it extends cycle consistency from single-modality settings (CycleGAN for images, back-translation for text) and from ITIT's separate-encoder/decoder architecture to a unified transformer where both modalities share one token space. The method also draws on EMA from semi-supervised learning and gradient surgery from multi-task learning to stabilize the two-cycle optimization, but the core departure from prior adaptation work (DreamBooth, Textual Inversion) is the elimination of paired data as a training requirement by converting cross-modal generation into same-modality reconstruction losses.

## Why It Matters / Open Questions

The practical significance is substantial: domain adaptation of generative models has been bottlenecked by the labor-intensive collection of paired image-text data, and DoraCycle demonstrates that 10% paired plus 90% unpaired data can approach the quality of 100% paired training, making large-scale personalization far more feasible. Limitations include evaluation on a single base architecture (Show-o) and a single quantitative benchmark (Storyboard20K), and the model still fails on novel concepts lacking any paired anchor (e.g., mislabeling dorayaki as doughnut). Open questions include whether the cycle framework generalizes to video or audio modalities, whether it works with continuous-latent unified models rather than discrete-token ones, and how it scales to domains with dozens of interacting identities and relationships.

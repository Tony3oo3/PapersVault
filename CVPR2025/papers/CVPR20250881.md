## Problem

Existing Language Bottleneck Models (LBMs) organize all class concepts in a flat, class-shared space, causing two critical failures: the concept classifier learns to rely on spurious cues (e.g., background or co-occurring non-essential concepts) rather than class-specific essential features, and the model cannot generalize to unseen classes because adding new classes requires expanding the concept space, invalidating the trained classifier.
![Teaser figure](../imgs/CVPR20250881/cropped_page1_idx1.webp)

## Input / Output

The method takes a single RGB image as input and produces a class label along with a structured concept activation score matrix of shape K×N_a (number of classes × number of attributes), where each entry represents the similarity between the image's per-attribute visual feature and the corresponding class-attribute concept description. Unlike standard CLIP which uses a single [CLS] token as the image representation, ALBM extracts N_a separate visual features—one per attribute—via dedicated visual prompts, making the bottleneck explicitly decomposed along attribute dimensions.

## Method

ALBM constructs an Attribute-formed Class-specific Concept Space (ACCS) where each class has its own set of concept descriptions organized under a unified cross-category attribute set (e.g., color, shape, texture), so classification is performed solely on class-specific essential concepts, eliminating spurious cue inference. Visual Attribute Prompt Learning (VAPL) introduces learnable visual prompts for each attribute, trained by aligning their output features with the textual embeddings of corresponding concept descriptions, enabling fine-grained per-attribute visual feature extraction. The Description-Summary-Supplement (DSS) strategy automates concept set construction via a three-step LLM pipeline: freely generating class concepts, summarizing the attribute set from those concepts, and supplementing missing attribute descriptions. For base-to-novel transfer, the concept classifier for unseen classes is synthesized by weighting base-class classifiers according to class-name embedding similarity, leveraging the structural correlations guaranteed by the shared attribute set.

## Results

In the zero-shot setting, ALBM achieves 2.0%–20.7% accuracy improvement over the best training-free language bottleneck on 8 of 9 datasets (e.g., 75.4% on Food101 vs. 52.2% for LaBo*, 83.1% on CIFAR-10 vs. 64.0%). In the base-to-novel setting, ALBM achieves 1.0%–80.7% improvement on base classes and 0.6%–15.9% on novel classes over all training-free language bottlenecks. Compared to trained Language Bottleneck Models (LaBo, CLBM), ALBM improves on 7 of 9 datasets by 1.3%–19.2% on base classes while remaining transferable to novel classes, which existing LBMs cannot do.

## Baselines & Comparisons

Against unexplainable CLIP (ZS-CLIP/LP-CLIP), ALBM is consistently lower, as expected for an interpretable method (e.g., 91.9% vs. 86.4% on CUB base, but 27.8% vs. 60.1% on CUB novel), reflecting the inherent accuracy-interpretability trade-off. Against training-free language bottlenecks (VD-CLIP, CuPL, CLIP-GPT), ALBM dominates across nearly all datasets in both base and novel settings, with the largest gap being 80.7% on CUB base (91.9% vs. 11.2% for CLIP-GPT) and 15.9% on ImageNet novel (73.9% vs. 58.0% for CuPL). Against the closest LBM competitor LaBo, ALBM wins on 7 of 9 datasets in base-to-novel (e.g., 91.9% vs. 76.9% on CUB, 78.6% vs. 77.0% on DTD) while uniquely providing novel-class predictions that LaBo cannot offer. Against CLBM, ALBM achieves comparable or superior base-class accuracy (e.g., 91.7% vs. 52.0% on Flowers102) and again provides novel-class transfer. The only notable losses are on Aircraft base (38.7% vs. 42.9% for LaBo) and a small gap on CUB novel, where the fine-grained bird categories challenge the unified attribute set.

## Relation to Prior Work

This paper extends the Language Bottleneck Model (LBM) paradigm introduced by LaBo (Yang et al., CVPR 2023) and CLBM (Yan et al., ICCV 2023), which learn a concept classifier over a class-shared concept space. The key departure is reorganizing the concept space into an Attribute-formed Class-specific Concept Space (ACCS), where each class has its own set of attribute-conditioned concepts drawn from a unified cross-category attribute set, rather than pooling all concepts into a single flat space. The Visual Attribute Prompt Learning (VAPL) component adapts the multimodal attribute prompting idea from MAP (Liu et al., 2024) by aligning visual prompts with attribute-specific concept descriptions rather than unstructured class descriptions. The DSS strategy for automatic concept generation modifies the CLIP-GPT (Maniparambil et al., 2023) pipeline by extracting attributes from freely generated class concepts rather than asking the LLM to directly enumerate useful attributes.

## Why It Matters / Open Questions

The attribute-formed class-specific structure addresses two concrete failure modes of existing LBMs—spurious cue inference and inability to transfer to unseen classes—without requiring retraining when new classes are added, which is practically important for open-world deployment. However, a substantial performance gap versus unexplainable CLIP persists (e.g., ~34% on CUB novel vs. 60% for ZS-CLIP), and the base-to-novel transfer relies on a simple similarity-weighted combination of base-class classifiers whose behavior on truly out-of-distribution novel categories remains untested. Open questions include whether the unified attribute set remains stable across very different domains, whether the approach scales to thousands of classes, and whether the modest gains from VAPL (+3.2% base) justify its additional training cost in practice.

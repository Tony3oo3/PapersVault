## Problem

One-stream visual trackers use a single Vision Transformer to jointly perform feature extraction and relation modeling, but different patch-to-patch interactions (e.g., background suppression vs. boundary emphasis) demand fundamentally different attention behaviors that handcrafted strategies can only address one or two at a time. The paper asks how to design a tracker that adaptively handles diverse relation modeling without relying on manually designed, inflexible mechanisms.
![Teaser figure](../imgs/CVPR20250897/cropped_page0_idx0.webp)

## Input / Output

The tracker takes a 196×196 template, a 378×378 search region, and N=3 historical tracked frames as reference inputs, all patchified into tokens with positional and type embeddings. A learnable target state token propagates across frames, accumulating temporal context. The output is a bounding box (via box regression) and a target center confidence score (via classification), produced by a decoupled double-MLP head that reweights search-region tokens using the propagated target state token before prediction.

## Method

SPMTrack introduces TMoE, a mixture-of-experts module that replaces every linear layer in both the multi-head self-attention (Q, K, V, and output projection) and the FFN layers of a ViT encoder, enabling finer-grained expert combinations than conventional MoE which only targets FFNs. Each TMoE module comprises a frozen shared expert (copying pretrained weights), a trainable compression expert that reduces input dimension from d to r, N_e=4 routed experts operating on the compressed representation, and a softmax router; all routed experts are densely activated and their weighted sum is added to the shared expert output. This design doubles as a parameter-efficient fine-tuning strategy: only the routed experts, compression expert, router, and prediction head are trained (~30% of total parameters), preserving pretrained DINOv2 generalization while enabling larger-scale models. Building on TMoE's flexible relation modeling, SPMTrack extends the one-stream paradigm from a single template to multi-frame spatio-temporal context by concatenating N reference frames with the search region and a propagating target state token, improving tracking accuracy with minimal additional parameters.

## Results

On LaSOT, SPMTrack-B (ViT-B backbone) achieves 74.9% AUC, SPMTrack-L reaches 76.8%, and SPMTrack-G reaches 77.4%. On GOT-10K (trained only on GOT-10K train split), SPMTrack-B achieves 76.5% AO while SPMTrack-L and SPMTrack-G reach 80.0% and 81.0% respectively. On TrackingNet, SPMTrack-B achieves 86.1% AUC, surpassing all prior trackers that use ViT-L or ViT-G backbones. Notably, SPMTrack-B trains only ~29.2M parameters (out of 115.3M total), reducing trainable parameters by nearly 80% compared to ARTrackV2.

## Baselines & Comparisons

SPMTrack-B (ViT-B) decisively outperforms all same-scale ViT-B baselines: it beats LoRAT-B by +2.0 AUC on LaSOT and +1.9 on TrackingNet, and surpasses ARTrackV2-B by +1.9 AUC on LaSOT. Against ViT-L trackers, SPMTrack-B is competitive but not uniformly superior: it matches ARTrackV2-L on TrackingNet (86.1 vs 86.1) and slightly trails LoRAT-L on LaSOT (74.9 vs 75.1) and GOT-10K (76.5 vs 77.5), while clearly beating ARTrackV2-L on LaSOT (74.9 vs 73.6). SPMTrack-L (ViT-L) dominates all ViT-L baselines across all three datasets, e.g., +3.2 AUC over ARTrackV2-L on LaSOT and +0.5 AO over ARTrackV2-L on GOT-10K. On TNL2K, SPMTrack-G achieves 64.7% AUC, outperforming the next best ODTrack-L (61.7%) by +3.0 points without using language descriptions. On UAV123, SPMTrack-B leads with 71.7% AUC over HIPTrack (70.5%), but on NfS it slightly trails HIPTrack (67.4 vs 68.1), which the authors attribute to the absence of consecutive target position modeling.

## Relation to Prior Work

SPMTrack extends the one-stream Transformer tracking paradigm (OSTrack, GRM, ROMTrack) by replacing handcrafted relation-modeling strategies with a learned mixture-of-experts mechanism (TMoE) applied to linear layers in both self-attention and FFN blocks. It builds directly on LoRAT's token-type embedding and decoupled double-MLP prediction head, and on SwinTrack's target-state token for temporal propagation, but departs from both by introducing multi-frame spatio-temporal reference inputs and by using TMoE as a parameter-efficient fine-tuning interface rather than full fine-tuning or LoRA. Unlike conventional MoE in NLP that replaces FFN layers with multi-layer experts, TMoE uses lightweight linear experts with a shared compression bottleneck, enabling finer-grained expert routing across all projection matrices.

## Why It Matters / Open Questions

The practical impact is significant: SPMTrack-B with only ~25% trainable parameters matches or exceeds trackers using ViT-L backbones, and the ~80% reduction in trainable parameters versus LoRAT makes large-scale tracking model training substantially cheaper. The finding that TMoE in attention projections yields larger gains than in FFN layers challenges the default assumption that MoE benefits are concentrated in feed-forward computation. Open questions include whether separate optimal expert counts exist for attention vs. FFN layers, whether further scaling of reference frames or expert count continues to help, and whether the spatio-temporal context mechanism generalizes to other video understanding tasks beyond tracking.

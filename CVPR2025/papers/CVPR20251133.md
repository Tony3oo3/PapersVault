## Problem

Visual Query Localization (VQL) requires finding the last appearance of an object in a long video from a single reference image, but prior methods either demand extensive task-specific training on large annotated datasets or rely on stage-wise pipelines that fail for small, briefly visible, or appearance-varying objects in long, untrimmed videos. No training-free baseline existed that could robustly handle cluttered scenes, partial visibility, and significant viewpoint changes typical of egocentric video.

## Input / Output

The method takes a long egocentric video (averaging 140 s at 5 FPS), a reference image with a bounding box around the query object, and a query time T, and outputs a spatio-temporal bounding box track {b_s, …, b_e} covering the latest visible occurrence of the object before T. Video frames are segmented at 1024×1024 via SAM ViT-H and feature-extracted at 384×512 via DINO ViT-B/8, producing region-level object tokens that are resolution-independent in count (≈130k tokens for a 1000-frame video vs. 3M+ for patch-based encoding).

## Method

RELOCATE is a training-free, five-stage pipeline: (1) Prepare — segment every frame with SAM ViT-H, extract dense features with DINO ViT-B/8, resize features to mask resolution, and average-pool within each binary mask to form compact object tokens; (2) Search — compute cosine similarity between the query token and all object tokens, apply intra-frame NMS (one candidate per frame) and inter-frame NMS (suppress neighbors until score drops below 80% of peak), then select up to k=10 candidates above a 0.7 threshold; (3) Refine — crop around each candidate and the query (object-centric crop, max 2.5× zoom), re-extract tokens, and re-score to improve spatial precision and remove spurious matches; (4) Track — bidirectionally track the latest refined candidate with SAM 2 to produce the response track; (5) Reiterate — generate additional query tokens from the predicted track, filter low-quality ones (low similarity, tiny bounding boxes, blurry frames), and re-search the video segment after the predicted track to capture later, differently-appearing occurrences. The key insight is that region-based representations from pretrained models provide a semantically rich yet compact encoding that enables effective object retrieval via simple cosine similarity without any task-specific training.

## Results

On the Ego4D VQ2D test set, RELOCATE achieves 0.35 stAP25 and 0.43 tAP25, surpassing the previous state-of-the-art VQLoC (0.24 stAP25, 0.32 tAP25) by 49% and 33% in relative improvement, respectively. On the validation set, RELOCATE scores 0.33 stAP25 and 0.41 tAP25, with 58.0% Success and 50.5% Recovery. All results are obtained without any task-specific training, relying solely on pretrained vision models (SAM ViT-H for segmentation, DINO ViT-B/8 for features, SAM 2 for tracking).

## Baselines & Comparisons

RELOCATE outperforms all three prior task-specific methods on every reported metric. Against the original Ego4D baseline SiamRCNN [17], RELOCATE improves stAP25 from 0.13 to 0.35 (test) and tAP25 from 0.21 to 0.43, a more than 2× gain. Against CocoFormer [46], which uses background object proposals as contextual cues, RELOCATE leads by 0.17 stAP25 and 0.17 tAP25 on the test set. The closest competitor is VQLoC [46], which incorporates negative frame sampling; RELOCATE still exceeds it by 0.11 stAP25 (49% relative) and 0.11 tAP25 (33% relative) on the test set, while also improving Success by 4.2 points and Recovery by 5.5 points. Notably, RELOCATE achieves these gains without any task-specific training, whereas all baselines require supervised training on the VQ2D dataset.

## Relation to Prior Work

RELOCATE builds directly on the region-based representation framework of Shlapentokh-Rothman et al. [41], which demonstrated that pooling DINOv2 features over SAM segments yields effective object retrieval. It follows the classic three-stage VQL pipeline (detect, match, track) established by the Ego4D baseline [17] and refined by subsequent works [45, 46], but departs from them by being entirely training-free and by replacing patch-level encodings with compact region tokens. The paper also contrasts with the end-to-end single-stage approach of Jiang et al. [20], which requires large annotated datasets, positioning RELOCATE as a practical alternative that encodes video once and reuses it across multiple queries.

## Why It Matters / Open Questions

The 49% relative stAP25 improvement over trained baselines without any task-specific training demonstrates that pretrained foundation models (SAM + DINO) already encode sufficient visual information for open-vocabulary video localization, challenging the assumption that VQL requires dedicated training. The training-free, query-independent video encoding is particularly relevant for episodic memory systems where a video must be indexed once and queried many times. Key limitations include the slow preparation stage (~24 minutes for 1000 frames) and evaluation on a single egocentric benchmark; open questions include whether the approach generalizes to third-person or longer videos, and whether the speed can be improved (e.g., via HNSW indexing or faster SAM variants) without sacrificing accuracy.

## Problem

Scientific visual tasks (e.g., estimating population density or biomass from satellite imagery) require models that reveal underlying mechanisms, not just predict outcomes. Existing interpretable approaches like concept bottlenecks are too simple to capture complex real-world relationships, while zero-shot LLM code generation fails on novel scientific domains where true variable relationships are undocumented. The paper asks: how can we automatically discover programs that are both accurate and interpretable for such open-ended scientific discovery tasks?

## Input / Output

The system takes as input a dataset of observations where each sample consists of a satellite image (Sentinel-2 at 10 m resolution), geographic coordinates, and optional environmental metadata (temperature, precipitation, nightlight, elevation), along with a natural-language description of the target quantity (e.g., 'population density'). It produces a human-readable Python program that interleaves open-vocabulary segmentation calls (via GRAFT), mathematical and logical operators, and a linear regressor over a predicted feature set, yielding a scalar prediction for each input location. Evaluation uses task-specific metrics: L2 error in log-space for population density, L1 for poverty, and L2 for aboveground biomass.

## Method

DiSciPLE performs evolutionary search over Python programs, replacing traditional symbolic crossover and mutation with LLM (LLaMA-3-8B) calls that leverage common-sense programming knowledge and the task's natural-language description to guide modifications. The initial population is seeded with zero-shot LLM programs rather than random ones, and each generation samples parent programs by fitness, then prompts the LLM to combine or mutate them. Three key improvements accelerate and refine the search: (1) feature-set prediction, where the LLM proposes a list of intermediate features and a linear regressor is trained on top, making the final program interpretable end-to-end; (2) a program critic that stratifies observations by land-use category (via segmentation) and prompts the LLM to fix underperforming strata; and (3) an analytical simplifier that prunes the program's AST/DAG by removing unreachable nodes and low-weight regression features. The loop runs for 15 generations with population size 100, using GRAFT as the open-world segmentation primitive shared across all three benchmark tasks.

## Results

On the population density task, DiSciPLE achieves a L2-Log error of 0.2607 (in-distribution) and 0.3807 (OOD), outperforming the strongest non-interpretable baseline (Deep-Large ResNet at 0.3974 in-dist, 0.4460 OOD) by ~34% and ~15% respectively. On poverty estimation, DiSciPLE reaches L1 error of 1.077 (in-dist) and 1.134 (OOD), beating Deep-Large (1.170 / 1.344). On aboveground biomass, DiSciPLE achieves L1 error of 24.79 (in-dist) and 31.10 (OOD), surpassing Deep-Large (21.15 / 35.41) on OOD while remaining competitive in-distribution. Across all three tasks, DiSciPLE also substantially outperforms zero-shot LLM programs and random search, confirming that the evolutionary loop with critic and simplification is essential for discovery.

## Baselines & Comparisons

Against Concept Bottleneck Models (Koh et al., ICML 2020), DiSciPLE achieves dramatically lower error across all three tasks: on population density, L2-Log drops from 0.8298 (CB) to 0.2607 (DiSciPLE) in-distribution and from 0.7951 to 0.3807 OOD, a roughly 69% and 52% relative improvement respectively. Against Deep Residual Networks (He et al., CVPR 2016), DiSciPLE outperforms the large ResNet variant on population density (0.2607 vs. 0.3974 L2-Log in-dist; 0.3807 vs. 0.4460 OOD) and on poverty (1.077 vs. 1.170 L1 in-dist; 1.134 vs. 1.344 OOD), while the ResNet retains a slight edge on in-distribution AGB (21.15 vs. 24.79 L1) but DiSciPLE clearly wins OOD AGB (31.10 vs. 35.41 L1). DiSciPLE also beats the zero-shot LLM baseline by a wide margin (e.g., 0.2607 vs. 0.4702 L2-Log on population density), demonstrating that the evolutionary search over observed data is critical for scientific discovery tasks where the underlying relationships are not in the LLM's training distribution. The random search baseline (same number of LLM calls but no evolutionary structure) is consistently worse than DiSciPLE, confirming that the fitness-guided crossover and mutation strategy accelerates convergence in the program space.

## Relation to Prior Work

DiSciPLE extends the LLM-guided evolutionary search framework from Chiquier et al. (ECCV 2024), which evolved interpretable concept bottlenecks, to instead evolve full Python programs that interleave open-vocabulary foundation models (GRAFT) with mathematical and logical operations. It departs from concept bottleneck models by offering program-level expressiveness rather than bag-of-words classifiers, and from symbolic regression by operating on high-dimensional visual data with complex primitives rather than low-dimensional mathematical formulas. The method also builds on LLM-based program synthesis (ViperGPT, VisProg) but addresses their key failure mode—poor performance on novel scientific domains—by using evolutionary search over observed data rather than relying solely on the LLM's prior knowledge.

## Why It Matters / Open Questions

The paper introduces the first benchmark for visual program discovery in scientific applications and demonstrates that interpretable-by-design programs can outperform deep networks on both in-distribution accuracy and out-of-distribution generalization for novel scientific tasks with no prior documented solutions. A key open question is whether the approach scales beyond geospatial problems and whether the limitation of only differentiable optimization in the final layer can be overcome to capture useful intermediate parameters. The finding that LLM common sense is essential (search collapses without it) suggests the method's applicability is bounded by the LLM's understanding of the primitive library, which may limit transfer to domains with highly specialized operators.

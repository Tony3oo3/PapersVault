## Problem

Space-time memory (STM) networks for semi-supervised video object segmentation rely on softmax attention to match query pixels against all spatiotemporal memory pixels, incurring O(THW × HW) complexity that causes out-of-memory failures as video length or resolution increases. This bottleneck limits STM methods to short, low-resolution videos and makes high-resolution (e.g., 4096p) inference infeasible on consumer-grade hardware.
![Teaser figure](../imgs/CVPR20252036/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB video frames (resized so the shorter edge is ≤ 480 px by default) and a first-frame segmentation mask as input, producing per-frame binary segmentation masks at the original resolution. A key property is that memory usage remains constant regardless of video length and grows only linearly with spatial resolution, enabling 4096p inference on a 32 GB GPU. For multi-object videos where new objects appear mid-sequence, a new constant-size state is instantiated per object at negligible cost.

## Method

LiVOS replaces the quadratic softmax attention in STM networks with gated linear matching, reformulating memory readout as a recurrent update over a constant-size 2D state S_t ∈ R^{Ck×Cv} (Ck=64, Cv=256) that accumulates key-value outer products across frames. A data-dependent forget gate G_t, computed via a depth-wise convolution on the image encoder's coarsest feature followed by spatial summation and sigmoid, is applied element-wise to the state before each update, controlling which information is retained or discarded. The architecture uses ResNet-50 as the key (image) encoder and ResNet-18 as the value (mask) encoder, and enriches the linear-matching readout with a sensory memory (element-wise addition) and an object memory (cross-attention transformer) borrowed from Cutie. Training uses cross-entropy plus soft dice loss with point supervision (K=12544 sampled points) over 125K iterations on 480×480 crops, relying solely on ImageNet pretraining without additional static-image or synthetic-video pretraining.

## Results

On short-video benchmarks (480p), LiVOS achieves 64.8 J&F on MOSE, 85.1 J&F on DAVIS-17 val, and 82.6 G on YouTube-VOS-2019 val (trained on all three datasets), surpassing all non-STM methods and trailing the best STM-based method Cutie-base by 3.5 J&F on MOSE. On long-term videos (LVOS), LiVOS* reaches 51.2 J&F on validation and 50.9 J&F on test, outperforming RDE (47.2/44.7) while using only 503M GPU memory versus RDE's 9.0G. On high-resolution videos, LiVOS is the only method capable of 4096p inference (30.4G on a 32G GPU), requiring 7.7G at 2048p where all STM-based methods hit out-of-memory (Cutie-base estimated at 150G).

## Baselines & Comparisons

LiVOS outperforms all non-STM baselines across every benchmark: on MOSE it leads RDE (46.8) by 18.0 J&F and Cutie-base† (52.6) by 12.2 J&F; on DAVIS-17 val it beats RDE (84.2) by 0.9 J&F and MobileVOS (83.7) by 1.4 J&F; on YouTube-VOS it surpasses RDE (81.9 G) by 0.7 G and MobileVOS (82.3 G) by 0.3 G. Against the strongest STM-based method Cutie-base, LiVOS trails by 3.5 J&F on MOSE, 3.7 J&F on DAVIS val, and 3.9 G on YouTube-VOS, but when Cutie is restricted to a single memory frame (Cutie†), LiVOS wins by 12.2 J&F on MOSE, 7.6 J&F on DAVIS val, and 3.1 G on YouTube-VOS. On long-term LVOS, LiVOS* (51.2 J&F val) beats RDE (47.2) by 4.0 J&F while using 503M GPU memory versus RDE's 9.0G. On high-resolution inference, LiVOS is the only method that completes 4096p (30.4G), whereas all STM methods OOM at 2048p and Cutie-base is estimated to need 150G at 2048p.

## Relation to Prior Work

LiVOS sits at the intersection of two research threads: space-time memory (STM) networks for video object segmentation (Oh et al. 2019, STCN, XMem, Cutie) and linear attention from sequence modeling (Katharopoulos et al. 2020, Yang et al. 2023). The key conceptual departure is replacing the quadratic softmax attention matrix in STM memory matching with a constant-size recurrent state updated via gated linear attention, borrowing the data-dependent gating mechanism from language modeling. Architecturally, it reuses Cutie's sensory memory, object memory, and mask decoder, positioning the contribution squarely in the matching mechanism rather than the surrounding pipeline.

## Why It Matters / Open Questions

The practical impact is significant: LiVOS enables 4096p video segmentation on a 32G consumer GPU and maintains constant memory regardless of video length, capabilities that are infeasible with softmax-based STM networks. This opens a path toward high-resolution video foundation models that were previously cost-prohibitive. The authors acknowledge that a single recurrent state may be suboptimal for very long or very high-resolution videos, and suggest that more expressive state spaces (e.g., Mamba-style selective state spaces) or multi-scale linear attention could close the remaining quality gap with STM methods. The 3.5 J&F gap on MOSE versus Cutie-base remains a reminder that the efficiency-quality trade-off is not fully resolved.

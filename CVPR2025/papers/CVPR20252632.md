## Problem

Existing model perceptual hashing methods (handcrafted-feature and dual-branch network-based) ignore model structure information, causing high false positive rates when distinguishing structurally dissimilar non-pirated models. This vulnerability not only degrades piracy detection accuracy but also enables adversaries to authenticate malicious models as legitimate ones in model repositories by exploiting hash-distance collisions.
![Teaser figure](../imgs/CVPR20252632/cropped_page0_idx0.webp)

## Input / Output

The method consumes two inputs per model: (1) raw parameter matrices (convolutional and fully connected layer weights, pruned to reduce redundancy) and (2) the model's architectural specification (layer types, input/output dimensions, kernel sizes), which is converted into a directed acyclic graph with a three-layer node strategy per layer. The output is a 100-bit binary perceptual hash formed by fusing a 50-bit parameter hash and a 128-bit structure hash through a fully connected merge layer; similarity is assessed via mean-squared-error distance between hash bit sequences.

## Method

The core contribution is a three-branch hashing architecture that, for the first time, encodes model structure into perceptual hashing. The structure branch converts diverse DNN architectures into DAGs using a novel node-connection strategy (intermediary nodes for FC/Conv layers) that eliminates multi-edges and cycles while reducing space complexity from O(mn) to O(m+n); a Graph Isomorphism Network pre-trained on MUTAG molecular graphs and fine-tuned with contrastive learning on model DAGs (similar = ≤5% node perturbation, dissimilar = >5% or new layers) produces the 128-bit structure hash. The parameter branch uses a dual-branch network with dynamic convolutional layers to handle variable-sized parameter tensors, yielding a 50-bit hash. Training proceeds in three stages: parameter hash generator (5,000 epochs, contrastive loss), structure hash generator (MUTAG pre-training + 200-epoch contrastive fine-tuning on 30% of TIMM-derived DAGs), and joint three-branch fine-tuning with a merge loss that pulls pirated-model hashes toward the original while pushing non-pirated hashes away.

## Results

On the TIMM benchmark (325 test models), the proposed method achieves a false alarm rate of only 2.69% for non-pirated model identification at T=0.1, compared to 9.50% for the baseline (Xiong et al.), while maintaining 97.31% identification accuracy. For pirated model detection, the method achieves 100% accuracy across fine-tuning, L1 pruning, and random pruning scenarios at T=0.1, with maximum hash distances of 0.02, 0.0131, and 0.013 respectively—roughly 10× smaller than the baseline's corresponding values (0.21, 0.24, 0.20). Under tampering (up to 50% parameter modification with σ=0.2), detection accuracy remains above 90% at T≥0.5.

## Baselines & Comparisons

The paper compares against a single baseline: the dual-branch DNN-based perceptual hashing method of Xiong et al. [28]. The proposed method decisively outperforms the baseline on the paper's primary metric—non-pirated model false alarm rate—reducing it from 9.50% to 2.69% at T=0.1 (a 3.5× reduction) and from 17.46% to 10.45% at T=0.5. On pirated model detection, the proposed method achieves 100% accuracy at T=0.1 for all three attack types (fine-tuning, L1 pruning, random pruning), whereas the baseline achieves only 96.88%, 96.35%, and 95.50% respectively. The hash distances for pirated models are also dramatically smaller with the proposed method (max 0.02 for fine-tuning vs. 0.21 for baseline), indicating tighter clustering of related models. The baseline's larger hash distance spread (mean 11.32 vs. 48.89 for non-pirated models) reflects its inability to leverage structural information, causing structurally dissimilar models to appear closer in hash space.

## Relation to Prior Work

This paper extends the model perceptual hashing line initiated by Chen et al. [2] (handcrafted NTS features) and Xiong et al. [28] (dual-branch CNN-based parameter hashing) by introducing a third structural branch. The key conceptual departure is converting diverse neural network architectures into directed acyclic graphs and learning their embeddings via a Graph Isomorphism Network (GIN), pre-trained on MUTAG and fine-tuned with contrastive learning on model DAGs. The resulting three-branch architecture (conv-parameter, FC-parameter, structure) merges into a unified 100-bit hash, addressing the false-positive problem that plagues purely parameter-based hashing when structurally dissimilar models are compared.

## Why It Matters / Open Questions

Reducing the false alarm rate from ~9.5% to ~2.7% in non-pirated model identification is practically significant for model repositories where high false positives enable adversaries to pass malicious models through authentication. However, the evaluation is limited to a single baseline (Xiong et al.), a narrow set of vision architectures (ResNet, VGG, MobileNetV2, ShuffleNet), and the DAG extraction strategy has not been validated on transformer-based or LLM architectures. The authors themselves note that extending the framework to LLMs—where parameter sequences are massive and architectural diversity is greater—remains an open challenge, as does robustness against adversarial attacks specifically targeting the hash generation pipeline.

## Problem

Existing region-based temporal 3D detectors sample a fixed large number of points per proposal regardless of instance complexity, causing exponential growth in storage and computation as the number of input frames increases. Additionally, their reliance on result-level concatenation of per-frame decoding outputs prevents effective global spatial-temporal information exchange, limiting performance on longer sequences.
![Teaser figure](../imgs/CVPR20250466/cropped_page0_idx1.webp)

## Input / Output

The method consumes a multi-frame LiDAR point cloud sequence (up to 32 frames from 5×64-line lidars at 10 Hz on Waymo) along with proposals from a 4-frame CenterPoint RPN. In the current frame, 4K=192 points are sampled per proposal; in each historical frame, only K=48 focal points are retrieved from a compact memory bank. The output is a set of 3D bounding boxes with class labels (Vehicle, Pedestrian, Cyclist) and confidence scores, refined through a dual-layer transformer decoder.

## Method

FASTer introduces an Adaptive Multi-Head Self-Attention (Ad-MHSA) mechanism that computes per-token contribution scores from attention maps and progressively selects top-scoring focal tokens, compressing each proposal's sequence from 4K to K tokens without manual hyperparameters or auxiliary supervision. Only these focal tokens are stored in a memory bank, reducing per-scene storage from ~180k to ~2.6k points. For temporal fusion, a Grouped Hierarchical Fusion strategy divides the long sequence into equal-step groups and applies an Intra-Group Fusion module (max-pooling, channel concatenation, and shared-weight compression) alternated with Ad-MHSA to progressively condense T frame sequences into a single dense token sequence. A dual-layer decoder then aggregates the single-frame (SSP) and multi-frame (MSP) outputs sequentially, with the first layer attending to current-frame geometry and the second to the fused temporal representation.

## Results

On the Waymo Open Dataset validation set, FASTer with 16 input frames achieves 81.49 mAPH (Level 1) and 75.92 mAPH (Level 2), surpassing the strongest single-frame detector ScatterFormer (79.3/73.6) by 2.19/2.32 points. With 32 frames, FASTer reaches 81.62/76.06 mAPH, outperforming the best prior region-based method PTT (64 frames, 81.32/75.71) by 0.30/0.35 points. On the test set, FASTer (32 frames) achieves 83.55/82.23 mAP/mAPH (L1) and 78.82/77.54 (L2), setting a new state-of-the-art. In terms of efficiency, FASTer (16 frames) runs at 75 ms latency with 2856 MB memory, compared to 101 ms/3752 MB for MSF (4 frames) and 99 ms/6938 MB for PTT (32 frames).

## Baselines & Comparisons

FASTer outperforms all 15 compared baselines on the WOD validation set. Against single-frame detectors, the 16-frame FASTer exceeds the best single-frame method ScatterFormer by 2.19 mAPH (L1) and 2.32 mAPH (L2), with particularly large gains on pedestrians (+2.51 APH L2). Among region-based multi-frame methods, FASTer (16 frames) beats MPPNet (16 frames) by 1.09/1.07 mAPH (L1/L2), MSF (8 frames) by 0.84/0.46, and PTT (32 frames) by 0.38/0.44, while using fewer frames and substantially less memory (2856 MB vs. 6938 MB for PTT). On the test set, FASTer (32 frames) leads MSF (8 frames) by 0.44/0.27 mAP/mAPH (L1) and 0.52/0.58 (L2). The per-category gains are most pronounced for cyclists (75.58 vs. 75.11 APH L2 over PTT-32f) and pedestrians (76.61 vs. 76.00), indicating that the adaptive focal token mechanism is especially effective for smaller, sparser objects. In efficiency, FASTer (16 frames) achieves the best mAPH (75.92) at the lowest latency (75 ms) and memory (2856 MB) among all region-based methods tested.

## Relation to Prior Work

FASTer extends the region-based temporal 3D detection lineage initiated by CT3D and advanced by MPPNet, MSF, and PTT, which all follow an encode-fuse-concatenate routine over fixed-size point samples from proposal regions. The key departure is the introduction of Adaptive Multi-Head Self-Attention (Ad-MHSA) for dynamic token compression, drawing inspiration from token merging in vision transformers (DynamicViT, ToMe) but adapted to the unsupervised, variable-length nature of point cloud sequences. Rather than the conventional result-level concatenation used by prior region-based methods, FASTer proposes Grouped Hierarchical Fusion with an Intra-Group Fusion module to progressively condense long temporal sequences, and stores only adaptively-selected focal points in a memory bank instead of full historical point clouds.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in temporal LiDAR detection: the exponential growth in storage and computation as frame count increases, which has limited prior methods to short clips (4–8 frames) or forced compromises like discarding historical point semantics (PTT). By demonstrating that objects can be faithfully represented with a small set of focal tokens (K=48) and that hierarchical fusion outperforms simple concatenation, FASTer opens the door to longer-sequence modeling at near-constant cost. Limitations include evaluation solely on Waymo, dependence on RPN quality (mitigated by Extra Point Augmentation), and a staged training strategy that adds implementation complexity. Open questions include whether the focal token concept generalizes to other sensors (camera, radar) or to tracking and motion prediction tasks.

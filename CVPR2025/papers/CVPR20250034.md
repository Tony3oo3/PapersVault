## Problem

Prior continual semantic segmentation methods rely on knowledge distillation and pseudo labels to handle catastrophic forgetting and background shift, but they treat all unknown classes as a single background cluster, producing non-discriminative features. Additionally, the fairness problem—where imbalanced pixel counts across classes cause systematically worse predictions for minor classes—remains largely unaddressed in the CSS literature, as existing fairness approaches assume ideal balanced data distributions that do not hold in practice.

## Input / Output

The method consumes RGB images (H×W×3) processed sequentially in a continual learning setting where at each step t only the current class set C^t has ground-truth labels while all previous and future classes are collapsed into a single background label. The segmentation backbone (DeepLab-V3+ResNet-101 or SegFormer+MiT-B3) produces per-pixel feature maps (H×W×D) from the decoder's last layer, which are then used by the contrastive clustering loss and the visual grammar model. The final output is a per-pixel segmentation mask (H×W) predicting class labels for all known classes encountered so far.

## Method

FALCON replaces knowledge distillation with a contrastive clustering paradigm where class knowledge is stored in centroid vectors that are frozen for old classes and momentum-updated periodically. To address fairness, a scaling factor α and a learnable transition vector v are introduced into the contrastive loss (Eqn. 4), which provably reduces the enforcement gap between major and minor classes (Proposition 2) so that minority-class features are not scattered in the latent space. For unknown class modeling, an Attention-based Visual Grammar model (12 Transformer blocks with multi-head self-attention) learns the topological distribution of features around each cluster center, enabling it to assign multiple unknown features to distinct clusters without supervision—unlike prior methods that collapse all unknowns into one cluster. Unknown clusters are initialized via DB-SCAN on current features, and a cluster regularizer prevents collapse of distinct class centroids.

## Results

On ADE20K, FALCON with SegFormer (Transformer) achieves 41.9% mIoU (all classes) on the 100-50 setting and 40.3% on 100-10, outperforming the prior best CoMFormer (38.4% and 28.3%) by +3.5% and +12.0% respectively. On Pascal VOC, FALCON with DeepLab-V3 reaches 73.50% mIoU on VOC 15-5, 69.83% on VOC 15-1, and 62.41% on VOC 10-1, surpassing SSUL by 2.28%, 2.22%, and 3.16% respectively. On Cityscapes, FALCON with DeepLab-V3 achieves 70.74%, 69.75%, and 55.24% mIoU on the 11-5, 11-1, and 1-1 settings, improving over FairCL by +3.78%, +3.14%, and +6.02%.

## Baselines & Comparisons

FALCON (Transformer/SegFormer) achieves the best mIoU on ADE20K 100-50 (41.9%) and 100-10 (40.3%), outperforming CoMFormer [3] by +3.5% and +12.0%, and CoMasTRe [25] by +2.7% and +5.9% respectively. On ADE20K 100-5, ECLIPSE [31] edges out FALCON by 0.7% (34.2% vs 33.5%), attributed to ECLIPSE's stronger Mask2Former backbone. On Pascal VOC, FALCON (DeepLab-V3) consistently beats SSUL [4] across all three settings (73.50 vs 71.22, 69.83 vs 67.61, 62.41 vs 59.25) and substantially outperforms FairCL [62] (e.g., 69.83 vs 60.30 on VOC 15-1). On Cityscapes, FALCON (DeepLab-V3) surpasses FairCL [62] by +3.78% (11-5), +3.14% (11-1), and +6.02% (1-1), and also outperforms RCIL [75] and PLOP [20] by larger margins. FALCON (Transformer) further narrows the gap to the upper bound on ADE20K 100-50 (41.9% vs 45.5%) compared to prior methods, demonstrating that the fairness objective does not sacrifice overall segmentation quality.

## Relation to Prior Work

This paper departs from the dominant knowledge-distillation + pseudo-label paradigm in continual semantic segmentation (PLOP, RCIL, CoMFormer) by reframing CSS as a contrastive clustering problem with learnable cluster centroids. It builds directly on ClusFormer's transformer-based clustering architecture for its visual grammar model and extends Joseph et al.'s open-world contrastive clustering by replacing the single unknown cluster (N_U=1) with multiple discriminative unknown clusters (N_U>1). The fairness contrastive clustering loss introduces a scaling factor α and a learnable transition vector per cluster, drawing on balanced contrastive learning ideas from long-tailed recognition, to counteract the inherent bias that Proposition 1 shows vanilla contrastive clustering imposes on minority classes.

## Why It Matters / Open Questions

By providing a theoretical explanation (Propositions 1–2) for why standard contrastive clustering is structurally unfair under imbalanced data, the paper gives practitioners a principled tool to promote fairness in CSS without requiring balanced data—a condition prior fairness methods (FairCL) assumed but cannot guarantee. The visual grammar model for unsupervised cluster assignment is a practical advance over nearest-neighbor or pseudo-label strategies for handling multiple unknown classes. Open questions remain around the sensitivity of the scaling factor α (which must be tuned per dataset), the DB-SCAN-based cluster initialization, and whether the approach scales gracefully to very large class counts or longer learning sequences.

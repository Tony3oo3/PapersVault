## Problem

Traditional OOD detection treats out-of-distribution samples as a single binary category, ignoring the varying degrees of semantic similarity between OOD samples and known ID classes. This paper addresses the unexplored problem of classifying OOD samples to their correct internal nodes within a given class hierarchy, so that an unseen dog breed is predicted as 'dog' rather than simply flagged as OOD alongside an airplane.

## Input / Output

The method takes 224×224 RGB images as input and produces a predictive probability distribution over all nodes in a directed rooted class hierarchy (leaf nodes for ID classes, internal nodes for OOD predictions). The final hard prediction is obtained by minimizing the expected hierarchical distance under this distribution rather than by argmax, and OOD predictions at internal nodes are mapped back to those nodes for evaluation. The hierarchy structure is fixed and provided externally; the model must predict which node (at any depth) best describes the input.

## Method

ProHOC constructs a probabilistic model by appending an OOD child node to every internal node of the class hierarchy, then factorizes the joint probability over paths using conditional independences induced by the tree structure. To approximate these conditionals without OOD training data, the method trains separate ResNet-50 classifiers at each hierarchy depth using standard cross-entropy with remapped ancestor labels, exploiting the observation that high-level networks capture broad-category features and express uncertainty on fine-grained OOD samples. The OOD probability at each node is modeled by combining the entropy of the normalized child distribution with the complementary probability mass outside the children, then normalizing to form a valid conditional. The final prediction minimizes expected hierarchical distance over the full predictive distribution, and no new hyperparameters are introduced beyond standard training hyperparameters for the underlying networks.

## Results

ProHOC (EntCompProb) achieves the best MixBMHD and MixBAcc across all three datasets, excluding the depth oracle upper bound. On FGVC-Aircraft, it reaches MixBMHD 0.81 and MixBAcc 50.3%; on iNaturalist19, MixBMHD 0.94 and MixBAcc 46.7%; and on SimpleHierImageNet, MixBMHD 1.21 and MixBAcc 46.4%. The OOD balanced accuracy (BAcc_ood) ranges from 22.7% (FGVC-Aircraft) to 35.6% (iNaturalist19), a substantial improvement over the leaf model which scores 0% on OOD. The depth oracle, which uses ground-truth depth for each sample, provides an upper bound of MixBMHD 0.58–0.93 and MixBAcc 74.2–76.1%.

## Baselines & Comparisons

The only external baseline is HSC (Linderman et al., CoLLA 2023), which uses separate model heads per internal node with threshold-based top-down inference. ProHOC (EntCompProb) outperforms HSC on all three datasets for both MixBMHD and MixBAcc: on FGVC-Aircraft, MixBMHD 0.81 vs. 0.94 and MixBAcc 50.3% vs. 46.1%; on iNaturalist19, MixBMHD 0.94 vs. 1.28 and MixBAcc 46.7% vs. 38.2%; on SimpleHierImageNet, MixBMHD 1.21 vs. 1.28 and MixBAcc 46.4% vs. 42.3%. The gap is most pronounced on iNaturalist19, where HSC's OOD balanced accuracy is only 8.4% compared to ProHOC's 35.6%. HSC tends to make overly deep predictions, maintaining ID accuracy close to the leaf model (e.g., 77.9% vs. 84.7% on FGVC-Aircraft) but failing to correctly identify OOD samples at internal nodes. ProHOC also outperforms the trivial leaf-model baseline, which predicts all samples as leaves and achieves 0% OOD accuracy, confirming the value of the hierarchical OOD formulation. Notably, HSC's thresholds were tuned on OOD test data, whereas ProHOC introduces no such hyperparameters.

## Relation to Prior Work

This paper carves out a new problem at the intersection of hierarchy-aware classification and OOD detection. It extends the multi-depth classifier idea from [9] (which trains only two levels: coarse and fine) to all hierarchy depths, and repurposes standard OOD scoring (entropy, max-prob, complementary probability) to model conditional OOD probabilities at each internal node. The closest prior work, HSC [16], also targets OOD in hierarchies but relies on per-node model heads with hand-tuned stopping thresholds; ProHOC departs by constructing a fully probabilistic factorization over the tree that requires no additional hyperparameters and avoids top-down threshold-based inference.

## Why It Matters / Open Questions

By reframing OOD detection from a binary flag to a semantically structured prediction, this work opens a practically important direction for safety-critical systems (e.g., autonomous driving) where knowing *what kind* of unknown object appeared is more actionable than a generic OOD alert. The main limitation is the assumption that the class hierarchy mirrors visual similarity, which may not hold for conceptual hierarchies. Open questions include whether the framework scales to very deep or broad hierarchies, whether stronger backbones or contrastive pretraining (e.g., DINOv2) improve the multi-depth conditionals, and how to handle hierarchies where sibling classes lack shared visual features.

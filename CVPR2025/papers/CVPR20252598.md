## Problem

Existing query-based transformer methods for continual image segmentation decouple mask generation from continual learning by freezing mask-related parameters, but this leads to two critical failures: a loss of plasticity (objectness diminishes or even hurts performance in short task sequences) and heavy reliance on input data order (high variance across random splits). The paper identifies that the built-in objectness emerges from query-to-semantic-prior alignment in image features but collapses over stages as queries progressively misalign with evolving semantic priors.
![Teaser figure](../imgs/CVPR20252598/cropped_page0_idx0.webp)

## Input / Output

The model consumes RGB images at 640×640 (panoptic) or 512×512 (semantic) resolution and outputs N object queries, each producing a (class score vector, binary mask) pair via bipartite matching. A key constraint is that at each continual learning stage t, only annotations for the current stage's class subset C^t are available, and the same image may reappear with entirely different labels across stages (background semantic shift). The virtual query mechanism additionally injects stored query features (up to 80 per batch) into the decoder, requiring only ~5.9 MB of storage versus ~21.9 MB for equivalent image replay.

## Method

SimCIS builds on Mask2Former and introduces three modules to preserve and exploit built-in objectness. (1) Lazy Query Pre-Alignment (QPA) replaces learned queries with pixel features directly selected from the image feature map by computing dot-product similarity against per-class prototypes, ensuring 'perfect alignment' with semantic priors; stop-gradient on selected features prevents disruption during training. (2) Consistent Selection Loss (CSL) applies KL divergence between similarity distributions of previously selected feature locations under old vs. current prototypes, forcing the same semantically significant spatial positions to be revisited across stages. (3) Virtual Query (VQ) stores decoder-matched query features in per-class queues, samples them according to a pseudo-distribution computed from the previous stage's model outputs, and feeds them into the decoder with a skip-attention design that bypasses self- and cross-attention layers (affecting only FFN) so virtual queries do not corrupt real query representations while still receiving class supervision.

## Results

On ADE20K continual panoptic segmentation (PQ), SimCIS achieves 35.4 (all classes) in the 100-5 setting, 38.1 in 100-10, and 40.0 in 100-50, consistently outperforming all baselines. On continual semantic segmentation (mIoU), SimCIS reaches 38.7 (all) in 100-5, 42.3 in 100-10, and 48.6 in 100-50. In the 100-50 CPS task, SimCIS nearly matches the joint (oracle) upper bound of 40.4 PQ, with base-class performance (44.7) even exceeding the joint result (43.6). The method also demonstrates superior robustness to random data ordering, with only +0.1% PQ variance compared to the default order.

## Baselines & Comparisons

SimCIS outperforms all eight baselines across every setting. Against the strongest query-based competitor ECLIPSE [38], SimCIS gains +5.3% PQ on new classes (100-5), +11.3% (100-10), and +7.6% (100-50), while also improving base-class PQ by +1.0 to +3.0 points. Compared to the Mask2Former-based BalConpas [11], SimCIS leads by +1.6 to +5.1 PQ on new classes and +1.0 to +6.0 on base classes depending on the task length. Against the regularization-based CoMFormer [6], SimCIS improves by +6.0 PQ on new and +7.7 on base classes in 100-5, with even larger margins in 100-10 (+13.0 PQ new). On continual semantic segmentation (Table 3), SimCIS surpasses SSUL [7] by +5.0 to +9.7 mIoU on new classes and ECLIPSE [38] by +3.4 mIoU on base classes in 100-5. Notably, SimCIS is the only method that maintains strong performance under random data ordering (Table 6), gaining +6.0 PQ over ECLIPSE and +0.1 over BalConpas on all classes in the 100-10 random-order setting.

## Relation to Prior Work

This paper builds on the Mask2Former query-based transformer architecture and the line of continual segmentation work that exploits its built-in objectness (CoMFormer, CoMasTRe, ECLIPSE, BalConpas). However, it departs from the prevailing decoupled paradigm—where mask-generation parameters are frozen to preserve objectness—by diagnosing that this decoupling causes loss of plasticity and fragility to input data order. Instead, SimCIS directly initializes queries from semantically significant image feature locations (QPA), enforces cross-stage selection consistency (CSL), and introduces a virtual-query replay mechanism (VQ) that stores query features rather than images, fundamentally changing how objectness is maintained and how forgetting is combated.

## Why It Matters / Open Questions

The paper provides a mechanistic explanation for why built-in objectness in query-based transformers emerges and then degrades across continual learning stages, offering a principled alternative to the ad-hoc parameter-freezing strategies used by prior methods. The virtual query mechanism is practically significant: it reduces replay storage by ~10×, is independent of input data order, and preserves dataset privacy, making continual segmentation more deployable in real-world settings. Limitations include evaluation on a single dataset (ADE20K) and a single architecture (Mask2Former with ResNet backbones); whether the QPA/CSL/VQ framework transfers to other backbones (e.g., Swin, ViT), other datasets, or online/streaming settings remains open.

## Problem

Multi-frame VLMs outperform 3D-LMMs on 3D question answering due to the scale and diversity of 2D training data, but they require a large number of visual tokens to capture fine 3D scene details. Existing token compression methods (pooling, pruning, merging) reduce token counts but lose the small-scale visual details essential for 3D QA, particularly under fast camera movements in 3D scans. The paper addresses how to intelligently preserve critical 3D scene details while reducing visual token usage by over 90%.

## Input / Output

The method takes 12 uniformly sampled posed RGB-D images from a 3D scene plus a text question. Depth information combined with known camera poses is used to project each 2D image patch's visual token into 3D world coordinates, forming a scene-level 3D feature map. The output is a free-form text answer generated by the LLM. The entire pipeline is training-free, requiring no additional fine-tuning of the base VLM (LLaVA-OneVision-7B with SigLIP encoder and Qwen2 language model).

## Method

Dynamic Token Compression (DTC) creates a dynamic-resolution 3D scene representation by iteratively compressing visual tokens at increasing voxel scales. Starting from a small initial voxel size (0.1 m), each iteration assigns tokens to voxels, then performs bipartite soft matching: tokens within each voxel are randomly split into sets A and B, edges are drawn from each token in A to its most similar token in B, and only the top 40% most similar edges across the entire 3D space are retained. For each connected pair, one token is kept (the one appearing first in 2D image order), and the voxel size increases by 0.02 m for the next iteration until the desired token count is reached. This mechanism allocates more tokens to regions with many small or semantically distinct objects while aggressively compressing redundant areas (e.g., walls), producing a non-uniform resolution 3D feature map that preserves fine details where they matter most.

## Results

On OpenEQA (LLM-Match), the base LLaVA-OneVision-7B model with 12 multi-view images achieves 56.2, and DTC at 26% visual token usage retains 54.1 (only −2.1), while at 8% tokens it still reaches 49.3. On ScanQA (EM@1), the base model scores 27.6, and DTC at 54% tokens actually improves to 27.8 (+0.2); even at the extreme 9% token setting, performance drops only to 26.1 (−1.5, retaining 94.6% of base performance). The method achieves a 47.6% throughput increase at 23% token usage on ScanQA while maintaining identical accuracy.

## Baselines & Comparisons

On OpenEQA, DTC at 56% tokens (55.3) surpasses MovieChat (54.9), GPT-4-V with 15 frames (54.6), and Video-LLaMA2 (49.2), while at 26% tokens (54.1) it still exceeds all open-source baselines including Chat-UniVi (42.3) and Video-ChatGPT (32.1). On ScanQA, DTC at 54% tokens (27.8) outperforms the strongest 3D-LMM baseline Scene-LLM (27.2) and LEO (24.5), as well as MovieChat (26.0) and 3D-LLM (20.5), all without any 3D-specific training. Compared to the base model, DTC at 26% tokens on OpenEQA loses only 2.1 points (54.1 vs. 56.2), whereas Vanilla Token Compression at the same budget drops 5.7 points (50.5), and simple frame sampling drops 6.8 points (49.2). On ScanQA at ~9% tokens, DTC (26.1) retains 94.6% of base performance while frame sampling (18.5) and temporal pooling (18.2) lose over 9 points. The key advantage over prior token compression methods (spatial/temporal pooling, frame sampling) is that DTC preserves fine-grained 3D scene details critical for spatial reasoning, as evidenced by its superior performance on object recognition and attribute recognition categories in OpenEQA.

## Relation to Prior Work

This paper positions itself at the intersection of 3D-LMMs (3D-LLM, Scene-LLM, LEO) and multi-frame VLMs (LLaVA-OneVision, MovieChat, Video-ChatGPT), arguing that the 3D training data bottleneck makes 2D multi-frame VLMs the stronger base for 3D question answering. It departs from prior token compression methods (FastV, spatial/temporal pooling, token merging) by introducing 3D spatial priors via voxelization combined with visual semantic similarity through bipartite soft matching, creating a dynamic-resolution 3D scene representation rather than a uniform one. The method is training-free and plugs into LLaVA-OneVision-7B without architectural modification, distinguishing it from 3D-LMMs that require dedicated 3D input encoders and 3D-specific fine-tuning.

## Why It Matters / Open Questions

The demonstration that a training-free, 3D-aware token compression can reduce visual tokens by over 90% while retaining ~95% of base-model performance on both OpenEQA and ScanQA offers a practical path to deploying multi-frame VLMs for 3D QA in resource-constrained or real-time settings. The finding that 2D multi-frame VLMs consistently outperform purpose-built 3D-LMMs reinforces the field's data-scarcity problem for 3D and suggests that 2D-based approaches with 3D-aware processing may remain dominant until 3D data scales. Open questions include whether the dynamic voxelization generalizes to larger or outdoor scenes, whether the bipartite matching overhead is acceptable for streaming/online applications, and whether the approach transfers to other VLM backbones beyond LLaVA-OneVision.

## Problem

Existing Visual Prompt Tuning (VPT) methods focus on modifying prompt connection structures (e.g., cross-layer gating, dynamic placement) but leave the fundamental distribution and correlation between prompts and image tokens unexplored. Prompts are typically initialized randomly and optimized solely by downstream task loss, with no mechanism to ensure they capture class-specific semantic information or to guide how they interact with visual tokens in the attention mechanism.

## Input / Output

The method consumes standard RGB images processed into ViT patch embeddings, along with class labels that are used not only for the classification head but also to construct semantic metric learning objectives in deep ViT layers. For recognition tasks it outputs a class label; for segmentation it outputs a pixel-wise mask. A key detail is that class labels drive a dynamic k-means clustering that maps C classes onto M prompts (M ≪ C), and this mapping is refreshed every epoch using updated class representations from the [CLS] token.

## Method

DA-VPT augments VPT-Deep with two Proxy-Anchor metric learning losses: one between prompts and visual tokens (pulling same-class tokens closer to their assigned prompt while pushing different-class tokens away) and one between the [CLS] token and prompts (aligning the class token with its relevant prompt). Classes are dynamically assigned to prompts via k-means clustering of [CLS] token representations, updated each epoch to maintain semantic coherence. Saliency patch selection uses the attention-layer output as a proxy for informative visual tokens, avoiding expensive attention-map extraction. The DA-VPT+ variant additionally fine-tunes the Key and Value bias terms in self-attention for extra distributional flexibility. A theoretical analysis (Theorem 1) formalizes how reducing prompt–token cosine distance increases the corresponding attention weight via the softmax gradient, establishing the mechanistic link between the metric guidance and improved class-specific information aggregation.

## Results

On the supervised ViT-B backbone, DA-VPT+ achieves 91.94% mean accuracy on FGVC (5 datasets) and 76.14% mean accuracy on VTAB-1K (19 datasets), improving over VPT-Deep by 2.83 and 4.18 percentage points respectively. With self-supervised backbones, gains are even larger: DA-VPT+ reaches 83.20% FGVC and 69.61% VTAB-1K with MAE (vs. 72.02% and 41.73% for VPT-Deep), and 86.16% FGVC and 73.53% VTAB-1K with MoCo-V3. On semantic segmentation (ADE20K, ViT-L), DA-VPT+ achieves 46.47 mIoU-SS, surpassing the VPT baseline (44.08) and SPT-LoRA (45.40) while using only 4.3% of full fine-tuning parameters (13.7M vs. 317.3M).

## Baselines & Comparisons

DA-VPT+ consistently outperforms all VPT-based baselines across all three backbone settings. On supervised ViT-B, it beats VPT-Deep by 2.83 pp on FGVC and 4.18 pp on VTAB-1K, and surpasses E2VPT (the strongest prior VPT variant) by 2.72 pp and 2.20 pp respectively, while using fewer parameters (0.24M vs. 0.64M and 0.33M). With MAE pre-training, the advantage is dramatic: DA-VPT+ gains 11.18 pp over VPT-Deep on FGVC and 27.88 pp on VTAB-1K, and outperforms E2VPT by 22.54 pp on VTAB-1K mean accuracy. On the per-dataset FGVC comparison (Table 3), DA-VPT+ (91.94% mean) exceeds the previous SOTA methods SNF (90.74%) and MoSA (89.90%), as well as full fine-tuning (88.54%), using only 0.32M tunable parameters. On semantic segmentation (ADE20K), DA-VPT+ (46.47 mIoU-SS) surpasses VPT baseline (44.08) and SPT-LoRA (45.40) but remains below full fine-tuning (47.60), achieving 95.7% of full fine-tuning performance with 4.3% of the parameters. The one case where a baseline wins is E2VPT on MoCo-V3 VTAB-1K Structured (87.28% vs. 84.71%), though DA-VPT+ still leads on the overall VTAB-1K mean (73.53% vs. 72.88%).

## Relation to Prior Work

This paper extends Visual Prompt Tuning (VPT) by Jia et al., which introduced learnable tokens at ViT layer inputs, and subsequent structural improvements like E2VPT and GateVPT that optimize prompt placement and quantity. The key departure is shifting focus from prompt architecture to prompt distribution: DA-VPT applies Proxy-Anchor metric learning to guide prompts toward class-specific visual tokens, using k-means clustering to dynamically map classes to prompts. This bridges two previously separate literatures—PEFT via prompt tuning and deep metric learning (NCA, Proxy-Anchor)—treating prompts as semantic proxies rather than purely task-agnostic learnable tokens.

## Why It Matters / Open Questions

The paper provides a principled explanation for why prompts work (as semantic bridges routing class-specific information to the [CLS] token via attention) and shows that explicitly constraining prompt distributions improves transfer learning across 24 recognition and 2 segmentation tasks. A notable negative finding is that data-mean prompt initialization, which helps standard VPT, actually hurts DA-VPT, suggesting homogeneous initialization conflicts with discriminative metric guidance. Open questions include whether the k-means class-to-prompt mapping is optimal, how the approach interacts with other PEFT methods (LoRA, adapters), and whether the semantic guidance generalizes to open-vocabulary or few-shot settings where class structure is less defined.

## Problem

Existing text-to-image models (GANs, diffusion) produce visually appealing but logically incoherent outputs for structured diagrams, while text-to-code approaches handle only simple charts and lack the flexibility for complex hierarchical diagrams. No comprehensive benchmark or dedicated framework exists for generating and editing diverse structured diagrams (flowcharts, architecture diagrams, mind maps) from natural language with post-generation modifiability.
![Teaser figure](../imgs/CVPR20251680/cropped_page1_idx0.webp)

## Input / Output

For generation, the system takes a natural language instruction (18–561 tokens) and produces diagram code in LaTeX/TikZ or DOT languages (60–75,612 tokens), which is then compiled into a rendered diagram image. For editing, it accepts an existing diagram image plus a modification instruction, first converting the image back to code via a vision-language model before applying targeted code changes. For diagram coding, a diagram image alone is mapped to its underlying structured code. The benchmark spans eight diagram categories with 6,983 generation/coding samples and 1,600 editing samples.

## Method

DiagramAgent is a four-agent pipeline: a Plan Agent (Qwen-72B) interprets and expands incomplete user instructions into complete queries; a Code Agent (Qwen2.5-Coder-7B, fine-tuned for 4 epochs at 8192-token context) generates or modifies diagram code; a Diagram-to-Code Agent (Qwen2-VL-7B) performs image-to-code translation for the coding and editing tasks; and a Check Agent performs two-stage validation—compiler-based debugging followed by GPT-4o-based completeness verification—with errors fed back for iterative correction. The Code Agent and Diagram-to-Code Agent are trained via supervised fine-tuning that minimizes a code-level loss against reference code. The key architectural insight is separating planning, generation, and verification into distinct agents, enabling the system to handle both from-scratch generation and targeted editing within a unified framework, with the Check Agent's dual debugging-and-verification loop being critical for maintaining both syntactic correctness and logical completeness.

## Results

On the diagram generation task, DiagramAgent (7B) achieves Pass@1 of 58.15, ROUGE-L of 51.97, and CodeBLEU of 86.83, outperforming the strongest baseline DeepSeek-Coder (33B) by 2.59 points on Pass@1 and 7.71 on ROUGE-L. On diagram editing, it reaches near-perfect scores of 98.00 Pass@1, 98.41 ROUGE-L, and 99.93 CodeBLEU. On diagram coding, DiagramAgent attains 68.89 Pass@1 and 48.99 ROUGE-L, surpassing GPT-4o (64.07 Pass@1, 39.95 ROUGE-L) by a substantial margin.

## Baselines & Comparisons

DiagramAgent (7B) outperforms all 16 baselines on every metric in the diagram generation task, with the closest competitor being DeepSeek-Coder (33B) at 55.56 Pass@1 vs. 58.15, and GPT-4o trailing by 8.34 points on Pass@1 (49.81). On diagram editing, DiagramAgent achieves 98.00 Pass@1 and 99.93 CodeBLEU, beating the best baseline DeepSeek V2.5 (95.00 Pass@1, 98.83 CodeBLEU) by 3.00 and 1.10 points respectively; however, it loses on PSNR (13.18) to WizardCoder (24.24) and Code-Llama (24.10), which the authors attribute to a trade-off favoring overall structural fidelity over pixel-level sharpness. On diagram coding, DiagramAgent surpasses GPT-4o by 4.82 points on Pass@1 (68.89 vs. 64.07) and 9.04 on ROUGE-L (48.99 vs. 39.95), while also outperforming all open-source VLMs by wide margins (e.g., Qwen2-VL 7B at 28.89 Pass@1). The 7B DiagramAgent consistently beats larger open-source models (33B DeepSeek-Coder, 34B Code-Llama, 34B Yi-1.5) and closed-source APIs (GPT-4o, Gemini, GLM-4-plus) across all three tasks, demonstrating that the multi-agent framework compensates for model scale.

## Relation to Prior Work

This paper carves out a new task—text-to-diagram generation—by arguing that both text-to-image models (diffusion, GANs, autoregressive) and text-to-code models (Qwen2.5-Coder, DeepSeek-Coder) are fundamentally misaligned with the logical-structure requirements of diagrams like flowcharts, architecture diagrams, and mind maps. Methodologically, it draws on multi-agent LLM pipelines (citing AutoAct for the planning mechanism) and fine-tunes code-generation and vision-language models (Qwen2.5-Coder-7B, Qwen2-VL-7B) as specialized agents, but the key departure is the four-agent architecture (Plan, Code, Check, Diagram-to-Code) that explicitly separates instruction interpretation, code synthesis, compilation-based debugging, and reverse diagram-to-code translation. The work also repurposes existing code-generation evaluation metrics (CodeBLEU, ROUGE-L, Pass@1) alongside image-quality metrics (LPIPS, CLIP-FID, MS-SSIM) to jointly assess both code correctness and visual fidelity of compiled diagrams.

## Why It Matters / Open Questions

As the first dedicated benchmark (DiagramGenBenchmark, ~7,000 samples across 8 diagram types) and the first framework supporting both generation and iterative editing of structured diagrams, this work provides a foundational reference point for a task that sits at the intersection of NLP, code generation, and visual communication. The stark performance gap between editing (98% Pass@1) and generation from scratch (58% Pass@1) highlights that reliable one-shot diagram synthesis remains an open challenge, particularly for complex spatial layouts. Limitations acknowledged by the authors include difficulty with intricate spatial relationships and the continued reliance on GPT-4o for verification, which constrains the system's self-containedness. Broader impact is significant for education, scientific publishing, and industrial documentation where editable, logically coherent diagrams are essential.

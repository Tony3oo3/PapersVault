## Problem

Existing task-driven image fusion methods still rely on predefined fusion loss terms that impose fixed, manually designed constraints on the fusion process, limiting the dynamic and adaptive influence of downstream tasks on how source information is aggregated. This mismatch between static fusion objectives and task-specific requirements reduces model flexibility and prevents the fusion network from selectively preserving task-relevant information from infrared and visible sources.
![Teaser figure](../imgs/CVPR20251766/cropped_page2_idx0.webp)

## Input / Output

The method takes a paired infrared-visible image pair (H×W single-channel each) and produces a single fused image of the same spatial dimensions. The loss generation module additionally outputs pixel-wise weight maps {w_a, w_b} ∈ R^{H×W} that satisfy w_a^{ij} + w_b^{ij} = 1 via a Softmax constraint, controlling per-pixel intensity preference between the two sources. The framework is architecture-agnostic: it can be paired with any fusion network and any downstream task network (demonstrated with SegFormer for segmentation and YOLOv8 for detection).

## Method

TDFusion introduces a learnable fusion loss whose intensity-term weights are generated by a dedicated loss generation module G (built on Restormer blocks) that takes both source images as input. Training follows a MAML-style meta-learning procedure: during inner updates, single-step gradient descent is applied to surrogate clones of the fusion and task networks using the learnable loss and task loss respectively; during outer updates, the task loss computed on meta-test images is backpropagated through the surrogate parameters to update G, ensuring the generated loss minimizes downstream task loss. The fusion loss combines this learnable intensity term with a fixed Sobel-gradient preservation term, and the entire training signal for G derives solely from the downstream task loss, making the framework independent of any specific task or architecture. The fusion network (also Restormer-based) is then updated on the full training set using the current G-generated loss, and this alternating cycle repeats across epochs so the fusion loss continuously adapts to the evolving fusion network state.

## Results

On downstream tasks, TDFusion achieves the best mIoU of 75.09 (MSRS) and 60.50 (FMB) for semantic segmentation, and the best mAP50 of 86.27 (M3FD) and 95.00 (LLVIP) with mAP75 of 59.71 and 69.18 respectively for object detection. For fusion quality, TDFusion attains the highest SCD (1.86 on MSRS, 1.76 on FMB, 1.83 on M3FD, 1.75 on LLVIP), VIF (0.50, 0.43, 0.41, 0.46), and Q^AB/F (0.67, 0.68, 0.65, 0.70) across all four datasets, while matching or approaching the best SSIM values. The method consistently outperforms all seven baselines on the majority of fusion and task metrics.

## Baselines & Comparisons

TDFusion outperforms all seven baselines on every downstream task metric: it leads in mIoU by 0.59 over EMMA (74.48) on MSRS segmentation and by 2.09 over SegMIF (58.41) on FMB segmentation. For object detection, TDFusion achieves mAP50 of 86.27 on M3FD, surpassing the next-best EMMA (83.71) by 2.56 points, and mAP75 of 59.71, exceeding SegMIF (58.23) by 1.48. On LLVIP detection, TDFusion reaches mAP50 of 95.00 (best) and mAP75 of 69.18, beating DCINN (68.34) by 0.84 on mAP75. In fusion quality, TDFusion dominates SCD and VIF across all four datasets (e.g., SCD 1.86 vs. 1.62 for EMMA on MSRS; VIF 0.50 vs. 0.49 for EMMA), while matching EMMA's SSIM of 0.70 on MSRS and FMB. The closest competitor overall is EMMA, which is competitive on SSIM and EN but consistently trails TDFusion on information-fidelity metrics (SCD, VIF, Q^AB/F) and all downstream task scores.

## Relation to Prior Work

This paper extends the authors' prior ReFusion framework (Bai et al., IJCV 2024), which used meta-learning to learn a reconstruction-guided fusion loss, by replacing the reconstruction objective with a downstream task loss as the meta-learning signal. It also draws directly on MAML (Finn et al., ICML 2017) for the inner-outer loop training structure, but applies it to a novel target: a loss generation module that outputs pixel-wise intensity weights for the fusion loss rather than network initialization parameters. The key departure from prior task-driven fusion methods (TarDAL, SegMIF, MRFS, TIMFusion) is that the fusion loss itself becomes a learned, task-adaptive function rather than a manually designed fixed term, making the framework agnostic to both the specific downstream task and the fusion/task network architectures.

## Why It Matters / Open Questions

The task- and architecture-agnostic design of the learnable loss generation module offers a practical path toward a single fusion framework that adapts to diverse downstream tasks without re-architecting the fusion network, which is a meaningful step toward general-purpose multi-modal fusion. However, the approach is validated only on infrared-visible fusion with two downstream tasks (segmentation and detection), and the meta-learning training procedure (inner + outer updates per step) introduces significant computational overhead that may limit scalability to larger datasets or more complex tasks. Open questions include whether the learned loss weights generalize to other fusion modalities (multi-exposure, multi-focus, hyperspectral), whether the loss generation module can be distilled into a lightweight inference-time component, and whether the meta-learning signal remains effective when the downstream task network is very large or the task distribution shifts substantially.

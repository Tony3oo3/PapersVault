## Problem

DiT-based flow models (e.g., FLUX, SD3) lack the coarse-to-fine hierarchical structure of UNets, making it unclear which layers should be targeted for attention injection in training-free image editing. While flow models exhibit reduced generation diversity—a property that could enable stable, consistent edits—no prior method has identified the correct subset of DiT layers to exploit this property for controlled editing.
![Teaser figure](../imgs/CVPR20252106/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB source image and a text editing prompt as input. For real (non-synthetic) images, the input is first inverted into the FLUX latent space via an inverse Euler ODE solver augmented with a latent nudging step (scaling the clean latent by λ=1.15). The output is a single edited image that applies the text-specified modification while preserving all unedited regions of the source. The same mechanism handles non-rigid deformations, object addition/removal, and global scene changes without task-specific modifications.

## Method

The paper introduces an automatic layer-importance analysis: each DiT layer is bypassed via its residual connection, and the perceptual deviation (measured with DINOv2) between the ablated and full-model outputs across 64 prompts and multiple seeds defines a 'vitality' score. Layers exceeding a threshold form the vital set V, which is distributed non-locally across the transformer. During editing, the source and target images are generated in parallel, and the image-embedding attention features of the target are replaced with those of the source exclusively within layers in V, striking a balance between preserving source content and incorporating the text prompt. For real-image editing, an inverse Euler ODE solver is used to invert the image into the FLUX latent space, with a small scalar perturbation (latent nudging, λ=1.15) applied to the clean latent to reduce reconstruction error and constrain edits to the intended regions.

## Results

On a 3,200-sample COCO-based evaluation set covering non-rigid editing, object addition, object replacement, and scene editing, Stable Flow achieves the best image similarity (CLIP_img = 0.92) and image-text direction similarity (CLIP_dir = 0.14) among all compared methods. Its text similarity (CLIP_txt = 0.23) is competitive but slightly below SDEdit and MagicBrush (both 0.24). In a user study, Stable Flow wins over all five baselines in overall edit quality, with win rates ranging from 60.33% (vs. Instruct-P2P) to 74.00% (vs. MagicBrush).

## Baselines & Comparisons

Stable Flow clearly outperforms all five baselines on image preservation (CLIP_img), achieving 0.92 versus the next-best MagicBrush at 0.88 and Instruct-P2P at 0.87, with a much larger gap over SDEdit (0.71) and MasaCTRL (0.76). On image-text direction similarity (CLIP_dir), Stable Flow leads with 0.14, ahead of MagicBrush (0.11), P2P+NTI (0.08), SDEdit (0.07), Instruct-P2P (0.07), and MasaCTRL (0.03). On text prompt adherence (CLIP_txt), Stable Flow (0.23) is marginally behind SDEdit and MagicBrush (both 0.24) but ahead of P2P+NTI (0.21), Instruct-P2P (0.22), and MasaCTRL (0.20). In the user study, Stable Flow wins against every baseline across all four criteria (prompt adherence, image preservation, realism, overall quality), with the largest margins against MasaCTRL (82.33% prompt adherence win rate) and SDEdit (70.66% overall win rate). The qualitative comparison highlights that SDEdit struggles with identity preservation, P2P+NTI and MasaCTRL fail at object addition, and Instruct-P2P and MagicBrush struggle with non-rigid editing, whereas Stable Flow handles all four edit types with the same mechanism.

## Relation to Prior Work

This paper extends the parallel-generation attention injection paradigm established by MasaCTRL [18] and P2P [33] from UNet-based diffusion models to DiT-based flow models (FLUX, SD3). The key departure is that UNet's well-understood coarse-to-fine structure made layer selection for injection straightforward, whereas DiT's homogeneous transformer blocks lack such a hierarchy, necessitating the paper's automatic vital-layer detection via ablation. Additionally, the paper repurposes the limited diversity of flow-matching models—typically viewed as a drawback—into a stabilizing mechanism for editing, and introduces latent nudging to fix the insufficient inverse ODE solver for real-image inversion in FLUX.

## Why It Matters / Open Questions

The fully automated vital-layer detection provides a general-purpose tool for understanding DiT architecture that could extend beyond editing to model pruning and distillation, as the authors note. The latent nudging trick (scaling the initial latent by 1.15) is a simple but effective fix for a practical inversion problem that likely affects other flow-model editing pipelines. However, the method's limitations in style transfer, spatial object manipulation, and background replacement remain open, and it is unclear whether the vital-layer concept generalizes across different DiT architectures or scales. The modest quantitative gains over strong baselines (e.g., CLIP_img 0.92 vs. 0.88) suggest the approach is solid but not yet a decisive leap.

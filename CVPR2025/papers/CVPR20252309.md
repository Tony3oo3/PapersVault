## Problem

Post-hoc calibration methods like temperature scaling require a validation set spanning all classes, but in class-incremental learning, old-task data is restricted to a small exemplar memory and reserving a validation subset would degrade training accuracy. No existing calibration approach can effectively optimize a temperature using only a new-task validation set while still accounting for the typically lower accuracy of old tasks.
![Teaser figure](../imgs/CVPR20252309/cropped_page1_idx0.webp)

## Input / Output

T-CIL operates on a trained CIL model (ResNet-32 or ResNet-18) and requires three inputs: the exemplar memory set M_t (containing a small number of samples from both old and new tasks, e.g., 200–4000 samples total), a small new-task-only validation set D_t,valid (e.g., 500 samples), and the model's feature extractor and classification layer parameters. It outputs a single scalar temperature T_adv that is applied to all output logits to produce calibrated class probabilities, with no per-class or per-sample adjustments.

## Method

T-CIL applies targeted FGSM adversarial perturbations to memory exemplars before optimizing the temperature, because using exemplars directly yields near-100% accuracy and an abnormally low temperature. The perturbation direction is asymmetric: old-task exemplars are pushed toward their closest class in feature space (easiest misclassification) while new-task exemplars are pushed toward their farthest class (hardest misclassification), leveraging the tendency that old tasks have lower accuracy than new tasks. A single perturbation magnitude ε_adv is found via binary search on new-task exemplars so that the resulting temperature matches the target temperature computed on the new-task validation set. The final temperature is then optimized on the full set of perturbed exemplars (both old and new), making the new-task-derived magnitude transferable to old tasks without requiring any old-task validation data.

## Results

On CIFAR-100, T-CIL achieves an ECE of 5.74% (AECE 5.75%), a 65.2% reduction over the best post-hoc calibration baseline (TS at 16.28%), while maintaining 56.25% average accuracy. On CIFAR-10, T-CIL reduces ECE to 17.70% (vs. 22.09% for IRM, the best baseline), and on Tiny-ImageNet it reaches 8.12% ECE (vs. 10.60% for PerturbTS). Across all three datasets, T-CIL preserves the same accuracy as the uncalibrated ER baseline, confirming that calibration is achieved without sacrificing predictive performance.

## Baselines & Comparisons

T-CIL outperforms all five post-hoc calibration baselines (Vanilla, TS, ETS, IRM, PerturbTS) on every dataset in terms of ECE and AECE. The most dramatic gain is on CIFAR-100, where T-CIL's 5.74% ECE is 65.2% lower than TS (16.28%) and 65.9% lower than PerturbTS (16.49%). On Tiny-ImageNet, T-CIL (8.12%) beats PerturbTS (10.60%) by 23.4%, and on CIFAR-10 it improves over IRM (22.09%) by 20.0%. When integrated with CIL techniques (Table 2), T-CIL consistently reduces ECE: with DER on CIFAR-100, ECE drops from 22.38% to 4.37% (80.5% reduction), and with EEIL on CIFAR-100 from 21.96% to 10.30%. The one exception is WA on Tiny-ImageNet, where T-CIL yields a slightly higher ECE (11.43%) than vanilla WA (10.97%), attributed to WA's implicit logit scaling for the new task. Accuracy is preserved or marginally improved across all CIL combinations, confirming T-CIL's compatibility as a drop-in calibration layer.

## Relation to Prior Work

T-CIL extends temperature scaling (Guo et al., ICML 2017) by replacing the standard validation-set-based temperature optimization with one performed on adversarially perturbed memory exemplars, using targeted FGSM (Goodfellow et al., 2014) as the perturbation mechanism. It departs from the only prior calibration-in-CIL study (Li et al., 2024), which still assumed access to an old-task validation set, by eliminating that requirement entirely through a feature-distance-based direction policy that differentiates old-task and new-task exemplars. The method is positioned as a drop-in post-hoc module compatible with any CIL technique (ER, EEIL, WA, DER), rather than a new learning algorithm.

## Why It Matters / Open Questions

T-CIL addresses a practical gap that becomes acute as CIL systems are deployed: memory constraints and privacy regulations make retaining old-task validation data infeasible, yet miscalibrated confidence undermines safety-critical decision-making. The 65% ECE reduction on CIFAR-100 and consistent gains across four CIL methods demonstrate that calibration and accuracy need not trade off in this setting. Open questions include whether the assumption that old-task accuracy is systematically lower than new-task accuracy holds in non-image domains or under extreme forgetting, and whether the single-magnitude strategy generalizes to very long task sequences where the accuracy gap widens substantially.

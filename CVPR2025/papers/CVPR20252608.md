## Problem

Existing model merging methods face two intertwined challenges: redundant parameters in task vectors create conflicts that limit merging performance, and storing full-precision task vectors for dynamic merging imposes storage costs several times that of the pre-trained model. The paper asks whether the structure of task vectors can be exploited to simultaneously reduce redundancy and storage while improving merged-model quality.
![Teaser figure](../imgs/CVPR20252608/cropped_page0_idx0.webp)

## Input / Output

The method consumes pre-trained model weights plus, per task, a binarized task switch consisting of a binary activation mask, a binary sign vector, and a scalar scaling factor (totaling 1–3% of full-precision parameter storage). For Auto-Switch, a small unlabeled example set per task is used to build a query set of backbone features; at inference, a single input (image or text) is encoded and KNN retrieval over the query set determines per-task switch weights. The merged model outputs class labels for vision tasks and task-specific metrics (Matthews correlation for CoLA, Pearson/Spearman for STS-B, accuracy for the rest) on GLUE language tasks.

## Method

The key empirical finding is that task vectors exhibit a pulse-like characteristic: parameters whose magnitude falls below a quantile threshold are redundant, and discarding them improves both individual fine-tuning and merging performance. Building on this, T-Switch decomposes each task vector τ_i into three lightweight components via a pulse-activation mask g_m (binary activation switch), a sign function g_b (binary polarity switch), and a scalar L2-norm ratio (switch knob), so that the fine-tuned weights are approximated as θ + λ_i · S_A^i ⊙ S_P^i. Auto-Switch extends this to automatic, training-free merging by constructing per-task query sets from unlabeled examples, performing KNN retrieval at inference to compute per-task switch weights w_i(x), and combining all task switches as θ + Σ λ_i w_i(x) · S_A^i ⊙ S_P^i. The entire pipeline requires no gradient-based router training and stores only binary masks and signs, reducing storage to 1–3% of full-precision task vectors while matching or exceeding the performance of full-precision dynamic merging baselines.

## Results

On eight vision datasets (ViT-B/32, full-rank task vectors), Auto-Switch achieves 90.39% average accuracy, outperforming the strongest dynamic baseline EMR-Merging (88.74%) by 1.83% and Twin-Merging (83.07%) by 7.18%, while requiring only 58.6 MB of additional storage (12.4% of EMR, 1.6% of Twin-Merging). T-Switch alone reaches 91.14% average accuracy, slightly surpassing the individual fine-tuned models (91.01%). On eight GLUE language tasks (RoBERTa-base), Auto-Switch achieves 0.8421 average score, beating Twin-Merging (0.8235) by 2.26% and EMR-Merging (0.8018) by 4.03%, with only 65.5 MB storage versus 3819.9 MB for Twin-Merging.

## Baselines & Comparisons

Auto-Switch decisively outperforms all static merging baselines: it exceeds AdaMerging++ (81.67%) by 8.72%, RegMean (78.23%) by 12.16%, TIES-Merging (73.77%) by 16.62%, Task-Arithmetic (70.23%) by 20.16%, DARE (71.58%) by 18.81%, Fisher Merging (70.46%) by 19.93%, and Weight-Averaging (65.85%) by 24.54% on average vision accuracy. Among dynamic methods, Auto-Switch beats EMR-Merging (88.74%) by 1.83% while using only 12.7% of its storage (58.6 vs. 461.0 MB), and surpasses Twin-Merging (83.07%) by 7.32% while requiring just 1.7% of its storage (58.6 vs. 3474.2 MB). On language tasks, Auto-Switch (0.8421) leads Twin-Merging (0.8235) by 2.26% and EMR-Merging (0.8018) by 4.03%, again with a fraction of the storage. T-Switch (the single-task binarized approximation) matches or slightly exceeds individual fine-tuned performance (91.14% vs. 91.01% on vision; 0.8446 vs. 0.8556 on language), confirming that binarization with pulse-based discarding preserves task capability. The only case where Auto-Switch trails T-Switch is on vision (90.39% vs. 91.14%), attributed to KNN difficulty on scene-classification datasets (SUN397, RESISC45) with high inter-class similarity.

## Relation to Prior Work

This paper extends the task-vector-based model merging framework introduced by Task Arithmetic (Ilharco et al., 2023) and the parameter-dropping strategy of DARE (Yu et al., 2024), but departs from both by replacing random or full-precision parameter retention with a magnitude-based pulse activation that binarizes task vectors into a binary mask, a binary sign vector, and a single scalar. While prior dynamic merging methods (Twin-Merging, EMR-Merging) store full-precision task vectors and learn or compute combination weights, T-Switch/Auto-Switch instead stores only 1-bit representations and uses KNN retrieval over a small query set for training-free combination. The binarization step draws conceptually from the binary neural network literature (BinaryConnect, XNOR-Net) but applies it to the task-vector storage problem rather than to network weight quantization during training.

## Why It Matters / Open Questions

The 1–3% storage requirement for dynamic model merging is a substantial practical win for resource-constrained deployments where maintaining multiple fine-tuned models is infeasible. The pulse-like characteristic finding—that small-magnitude task-vector parameters are not merely redundant but actively detrimental—offers a new lens on parameter redundancy that could inform other compression or merging strategies. Limitations include the KNN-based Auto-Switch struggling with highly similar tasks (e.g., SUN397 vs. RESISC45), the sensitivity of the discard ratio hyperparameter, and the requirement for a small labeled query set per task. Open questions include whether the pulse-like property holds for very large model families, for tasks with heterogeneous architectures, and whether the binary approximation degrades gracefully as the number of merged tasks grows beyond the 8-task setting tested here.

## Problem

Category-level pose estimation is inherently model-free and operates on partially observed RGB-D inputs, which limits the extraction of global geometric and semantic context. Existing approaches either introduce only geometric shape priors while neglecting category-level semantics, or rely on a single reference instance for semantic matching, making them vulnerable to intra-class shape variation and sensor noise. This paper addresses the gap by integrating both geometric and semantic global context priors into the pose estimation pipeline.

## Input / Output

The method takes a single RGB-D frame and a category instance mask as input; the RGB crop is resized to 224×224 and 1024 points are sampled from the depth-derived point cloud. It outputs a 6D pose (rotation parameterized via the 6D continuous representation in SO(3), translation as a residual from the point cloud centroid) and a 3D object size vector. The pipeline also produces intermediate NOCS coordinates for M=96 detected keypoints, which serve as the correspondence basis for the final pose regression.

## Method

GCE-Pose introduces a first-complete-then-aggregate strategy built on two modules. The Semantic Shape Reconstruction (SSR) module learns a per-category Deep Linear Semantic Shape Model consisting of a geometric prototype, deformation basis vectors, a scale parameter, and a category-level semantic prototype (constructed by projecting DINOv2 features from multi-view renders into 3D and averaging across instances); a deformation network predicts shape parameters from partial input to reconstruct the full geometry while inheriting the semantic prototype. The Global Context Enhanced (GCE) fusion module then bridges the domain gap between noisy camera-space keypoint features and normalized object-space global features by concatenating learnable positional encodings and applying cross-attention (keypoints as queries, global features as keys/values) with a residual connection. The enhanced keypoint features are passed through self-attention and MLPs to predict NOCS coordinates, which together with the fused features drive the final pose and size regression via separate MLP heads.

## Results

On HouseCat6D, GCE-Pose achieves 24.8% on the strict 5°2cm metric, 58.4% on 10°5cm, and 60.6% on IoU75, outperforming the strongest prior-free baseline AG-Pose (DINO) by 16% on 5°2cm and 14.3% on IoU75. On NOCS-REAL275, GCE-Pose reaches 57.0% on 5°2cm, 86.3% on 10°5cm, and 79.8% on IoU75, surpassing all shape-prior-based methods (RBP-Pose, Query6DoF, DPDN) and the semantic+shape method GS-Pose by over 23% on 5°2cm. The method matches AG-Pose (DINO) on 5°2cm (57.0%) and IoU50 (84.1%) for NOCS-REAL275 while leading on 5°5cm (65.1 vs 64.6) and 10°5cm (86.3 vs 84.7).

## Baselines & Comparisons

On HouseCat6D, GCE-Pose clearly wins against all baselines: it beats AG-Pose (DINO) by 3.5 points on 5°2cm (24.8 vs 21.3) and 7.6 points on IoU75 (60.6 vs 53.0), and surpasses SecondPose by 13.8 points on 5°2cm (24.8 vs 11.0). On NOCS-REAL275, GCE-Pose ties AG-Pose (DINO) on 5°2cm (57.0) and IoU50 (84.1) but edges ahead on 5°5cm (65.1 vs 64.6) and 10°5cm (86.3 vs 84.7), while slightly trailing on IoU75 (79.8 vs 80.1). Against shape-prior methods, GCE-Pose dominates: it outperforms RBP-Pose by 18.8 points on 5°2cm (57.0 vs 38.2), Query6DoF by 8.0 points (57.0 vs 49.0), and DPDN by 11.0 points (57.0 vs 46.0). The most striking comparison is against GS-Pose [71], the only other method using both shape and semantic priors: GCE-Pose leads by 36.3 points on 5°5cm (65.1 vs 28.8) and 16.6 points on IoU75 (79.8 vs 63.2), attributed to learning deformation across multiple instances rather than relying on a single reference prototype.

## Relation to Prior Work

GCE-Pose builds directly on AG-Pose's keypoint-based feature extraction pipeline and GAFA module, while adapting the deep linear shape model framework from Loiseau et al. to jointly parameterize geometry and semantics. It departs from prior category-level methods in two key ways: (1) unlike shape-prior-only approaches (SPD, RBP, DPDN, Query6DoF) that reconstruct geometry but ignore part-level semantics, and (2) unlike GS-Pose which anchors semantics to a single reference instance, GCE-Pose learns a per-category deformation field that couples DINOv2-derived semantic features to geometric prototypes, enabling robust completion of partial observations into full semantic shapes. The GCE fusion module then bridges the domain gap between noisy camera-space partial features and normalized object-space global context via cross-attention.

## Why It Matters / Open Questions

The paper addresses a core limitation of model-free category-level pose estimation: partial RGB-D observations inherently lack the global geometric and semantic context needed for robust correspondence, especially under occlusion. By demonstrating that a learned linear shape model can simultaneously complete geometry and propagate category-level semantics, GCE-Pose offers a practical recipe for incorporating rich priors without requiring per-instance CAD models. However, the per-category training requirement (separate deformation and scale networks for each category) limits scalability, and the authors acknowledge that their semantic prior does not extend to instance-level alignment. Open questions include whether a unified cross-category shape model could replace the per-category networks, and whether the approach generalizes to categories with extreme intra-class variation beyond household objects.

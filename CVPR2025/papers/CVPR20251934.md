## Problem

Existing multi-modal 3D alignment methods (e.g., ULIP-2, PointBind) assume complete, perfectly aligned data across all modalities for every object instance and rely on consistent semantic instance segmentation. Real-world 3D scenes rarely satisfy these conditions—modalities are often missing, incomplete, or lack consistent instance annotations—making prior approaches inflexible for practical scene-level understanding tasks like cross-modal retrieval and object localization.
![Teaser figure](../imgs/CVPR20251934/cropped_page0_idx0.webp)

## Input / Output

The method consumes five scene modalities—multi-view RGB images, real-world point clouds, CAD mesh models, text descriptions expressed as spatial 'object referrals' (e.g., 'the chair is left of the table'), and top-view orthographic floorplan images—without requiring all to be present simultaneously. It produces a fixed-size modality-agnostic embedding vector per scene or instance in a shared contrastive space, from which cross-modal scene retrieval, instance matching, and object localization are performed via nearest-neighbor search. Notably, the 2D encoder shares weights between RGB and floorplan inputs, and the 3D encoder processes meshes by surface point sampling without assuming geometric alignment with the scene.

## Method

CrossOver employs a three-stage training pipeline: (1) instance-level contrastive alignment of per-instance features from dimensionality-specific encoders (BLIP for 1D text, DinoV2 for 2D images/floorplans, I2PMAE for 3D point clouds/meshes) to a shared image-referenced embedding space; (2) scene-level fusion via weighted attention over modality-pooled instance features to produce a unified scene vector; (3) training of standalone dimensionality-specific scene encoders (including a Minkowski Engine sparse convolutional network for 3D) that directly process raw scene data without semantic instance labels. The key design choice is aligning all modalities to a single reference modality (images) rather than all pairwise combinations, which reduces data requirements and enables emergent cross-modal behavior for modality pairs never jointly trained. A symmetric InfoNCE contrastive loss with learnable temperature and modality-pair masking handles missing data during training, while at inference any query-target modality pair can be used without prior knowledge.

## Results

On ScanNet, CrossOver achieves scene-level matching recall of 98.08% (R@25%), 76.92% (R@50%), and 23.40% (R@75%) for I→P retrieval, compared to 1.28%/0.64%/0.24% for ULIP-2 and 6.73%/0.96%/0.32% for PointBind. For P→R retrieval, CrossOver reaches 99.31%/96.56%/70.10% versus 37.24%/16.90%/8.62% (ULIP-2) and 54.83%/27.93%/11.72% (PointBind). On 3RScan temporal instance matching (same-modal P→P), CrossOver achieves 92.31%/84.62%/57.69% scene-level recall, outperforming LivingScenes (87.50%/78.41%/50.00%) and MendNet (80.68%/64.77%/37.50%). For cross-modal scene retrieval on ScanNet (I→P), CrossOver attains 64.74% top-1 scene category recall versus 7.37% (ULIP-2) and 13.78% (PointBind).

## Baselines & Comparisons

CrossOver dramatically outperforms both ULIP-2 and PointBind on the most challenging modality pairs. For I→P scene-level matching on ScanNet, CrossOver achieves 98.08% R@25% versus 1.28% (ULIP-2) and 6.73% (PointBind) — a gap of over 90 percentage points. Similarly, for P→R, CrossOver reaches 99.31% R@25% compared to 37.24% (ULIP-2) and 54.83% (PointBind). On the I→R pair, where baselines perform more competitively due to strong text encoders, CrossOver still leads with 99.66%/98.28%/76.29% versus 98.12%/96.21%/60.34% (ULIP-2) and 98.22%/95.17%/62.07% (PointBind). For temporal instance matching on 3RScan (same-modal P→P), CrossOver surpasses LivingScenes by 4.81/6.21/7.69 points at R@25/50/75% and MendNet by 11.63/19.85/20.19 points. In cross-modal scene retrieval (Table 2), CrossOver leads ULIP-2 and PointBind by 57.37 and 50.96 points in top-1 scene category recall for I→P, though it slightly trails its own instance-level baseline on intra-category recall for I→R (29.04% vs. 28.00%), attributed to a less powerful text encoder.

## Relation to Prior Work

CrossOver extends the multi-modal alignment lineage from CLIP → ImageBind → PointBind/ULIP-2, which align individual objects across modalities using contrastive losses, by shifting the unit of alignment from objects to entire scenes and introducing a floorplan modality. It departs from scene-graph-based methods (SGAligner, SG-PGM, SceneGraphLoc) that require semantic instance segmentation and explicit 3D scene graphs at inference, replacing them with dimensionality-specific encoders (1D text, 2D image/floorplan, 3D point cloud/mesh) that operate on raw data without semantic labels. The three-stage training pipeline (instance-level → scene-level → unified dimensionality encoders) is a novel architectural choice that distills fine-grained modality interactions into a single scene embedding, and the use of a single reference modality (images) rather than all pairwise combinations is a deliberate simplification over PointBind's full-pairwise InfoNCE.

## Why It Matters / Open Questions

The practical motivation is strong: real-world 3D data (construction sites, robot navigation, AR/VR) is inherently incomplete, noisy, and lacks consistent instance segmentation across modalities, yet prior methods assume perfect alignment. The emergent cross-modal behavior—where P→M alignment emerges without any direct P-M training pair—is a conceptually interesting result suggesting that a shared reference modality can bootstrap untrained modality relationships. Key limitations include the assumption of a fixed base modality per dataset, indoor-only evaluation, and scene retrieval performance that, while strong, still leaves substantial room (e.g., ~14% top-1 scene matching recall for I→P). Open questions include whether the approach generalizes to outdoor scenes, dynamic environments, and whether the base-modality assumption can be fully relaxed.

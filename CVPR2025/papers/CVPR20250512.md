## Problem

Existing 3D LMMs rely on complicated pipelines—offline multi-view feature extraction, separate prompt encoders, and task-specific segmentation heads—to achieve fine-grained scene understanding and flexible human-agent interaction. No prior method unifies text generation (VQA, captioning) and point-level 3D referring segmentation within a single integrated architecture without auxiliary modules, making deployment complex and limiting generalizability.
![Teaser figure](../imgs/CVPR20250512/cropped_page0_idx0.webp)

## Input / Output

The model takes a raw point cloud (N×6: xyz coordinates + RGB color), a natural-language instruction, and an optional visual prompt (clicking point, bounding box, or binary mask) as input. The visual prompt is encoded by a parameter-free visual sampler (3NN interpolation for points, average pooling for boxes/masks) rather than a learned encoder, and the resulting prompt feature is appended to superpoint queries with masked attention. Output is a free-form text response for VQA/captioning tasks, or a per-point binary 3D segmentation mask triggered by a special [SEG] token in the LLM output; only 100 superpoint tokens (selected by objectness score) are fed to the LLM to control sequence length.

## Method

The core contribution is the Omni Superpoint Transformer (OST), a single Transformer module that simultaneously serves as a visual feature selector (retaining top-K superpoints by objectness score), a visual prompt encoder (reusing OST with masked attention to embed prompts into the visual token space), and a mask decoder (frozen OST that takes a segmentation query from the LLM's [SEG] hidden state to produce 3D masks). The 3D scene encoder is a Sparse 3D U-Net whose output is reduced via superpoint pooling (bottom-up clustering) to a few hundred tokens. Pretraining jointly trains the 3D encoder and OST under hybrid supervision: instance segmentation on ScanNet200 plus 2D-to-3D knowledge distillation, where CLIP-ViT-L features from LLaVA-1.5 are extracted from multi-view images and lifted to 3D superpoints via geometric correspondence. The LLM backbone is Vicuna-1.5-7B from LLaVA-1.5, fine-tuned with LoRA while keeping the 3D encoder, OST, and LLM body frozen; instruction tuning jointly optimizes next-token generation and mask prediction (weighted 0.1) across 295K samples from six datasets.

## Results

3D-LLaVA achieves 92.6 CiDEr on ScanQA, improving the previous best (Chat-Scene, 87.7) by 4.9 points, and 54.5% EM on SQA3D. For referring segmentation, it reports 43.3% mIoU on ScanRefer and 42.7% mIoU on Multi3DRefer, surpassing the prior best (SegPoint) by 1.6 and 6.6 mIoU respectively. On Scan2Cap dense captioning, it attains 78.8 CiDEr and 36.9 BLEU-4, the best among all compared 3D LMMs. The model uses only point cloud input (no multi-view images) while matching or exceeding methods that rely on both point clouds and images.

## Baselines & Comparisons

Against the strongest unified 3D LMM competitor Chat-Scene [25], 3D-LLaVA wins on ScanQA (92.6 vs. 87.7 CiDEr, +4.9), Scan2Cap (78.8 vs. 77.2 CiDEr), and both referring segmentation benchmarks (43.3 vs. – and 42.7 vs. – mIoU), while tying on SQA3D (54.5 vs. 54.6 EM); notably, Chat-Scene requires offline multi-view image features and instance-level 3D features, whereas 3D-LLaVA uses only online point cloud processing. For referring segmentation, 3D-LLaVA outperforms SegPoint [21] by 1.6 mIoU on ScanRefer (43.3 vs. 41.7) and 6.6 mIoU on Multi3DRefer (42.7 vs. 36.1). Compared to Grounded 3D-LLM [12] (also point-cloud-only), 3D-LLaVA gains 19.9 CiDEr on ScanQA (92.6 vs. 72.7). LEO [26] reports a higher ScanQA CiDEr (101.4) but under a different evaluation setting that accesses ground-truth object information, making it not directly comparable. On box-level 3D grounding (Table 3), 3D-LLaVA achieves 51.2% Acc@0.25, trailing Chat-Scene (55.5%) but surpassing Grounded 3D-LLM (48.6%) and 3D-LLM (30.3%), despite not being explicitly trained for box prediction.

## Relation to Prior Work

This paper builds directly on LLaVA-1.5 (Liu et al., CVPR 2024) as its LLM backbone and visual projector, but departs fundamentally from prior 3D LMMs in its architectural philosophy. Where 3D-LLM, Scene-LLM, and Chat-Scene rely on multi-view image features plus point clouds with separate prompt encoders or offline region proposals, and LL3DA uses a Q-Former as a single-function connector, 3D-LLaVA introduces the Omni Superpoint Transformer (OST) as a unified module that simultaneously performs visual token selection, visual prompt encoding, and 3D mask decoding. The pretraining strategy—jointly training a Sparse 3D U-Net and OST with instance segmentation supervision plus 2D-to-3D knowledge distillation from CLIP-ViT-L features—repurposes the 2D LMM's visual encoder as a teacher to bootstrap 3D-language alignment in the absence of a 3D foundation model.

## Why It Matters / Open Questions

The practical significance lies in eliminating the complex multi-stage pipelines (offline multi-view feature extraction, separate prompt encoders, dedicated segmentation heads) that have characterized prior 3D LMMs, making deployment and interaction substantially simpler while matching or exceeding their performance. The paper candidly identifies 3D data scarcity as the primary remaining bottleneck, and the current evaluation is confined to indoor ScanNet scenes, leaving open questions about scalability to outdoor environments, larger scenes, and real-time inference. The finding that a single transformer module can be frozen and reused for both prompt encoding and mask decoding (with only a projection layer updated) suggests a broader design principle for multi-task multimodal models that could transfer beyond 3D.

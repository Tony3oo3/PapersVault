## Problem

Anchor-based 3D Gaussian Splatting methods like Scaffold-GS face a fundamental trade-off: large anchor features (e.g., 32-dim) yield high-quality rendering but inflate model size, while reducing anchor features degrades Gaussian attribute prediction and introduces visible artifacts in rendered textures and geometries. No prior method simultaneously achieves superior rendering quality and reduced anchor/model size.
![Teaser figure](../imgs/CVPR20250636/cropped_page0_idx2.webp)

## Input / Output

The method consumes multi-view posed RGB images at Scaffold-GS resolutions and a COLMAP-initialized point cloud to define anchor positions. It produces a compact 3D Gaussian scene representation where each anchor stores only 12–16 dimensional features (versus 32 in Scaffold-GS), yet renders novel views in real-time via differentiable splatting and alpha-blending. The reduced anchor dimensionality directly translates to smaller model size without sacrificing rendering fidelity.

## Method

SOGS introduces two key mechanisms. First, a second-order anchor computes a correlation matrix across all anchor feature dimensions (via covariance normalization and eigendecomposition), selects the top-M=2 principal co-variation eigenvectors as global-shared patterns, and passes each eigenvector concatenated with the local anchor feature through a two-layer MLP to extract anchor-specific textural and structural information; these extracted features are concatenated with the original (reduced-dimension) anchor feature for augmentation before Gaussian attribute prediction. Second, a selective gradient loss applies Sobel operators to both the rendered image and ground truth to produce gradient maps, then uses the absolute per-pixel gradient difference as a dynamic weight map so that the loss adaptively emphasizes regions with large rendering errors in textures and structures, shifting focus throughout training. The total loss combines this selective gradient term with standard L1, D-SSIM, and volume regularization losses.

## Results

On Mip-NeRF360, SOGS with 16-dim anchors achieves PSNR 27.85, SSIM 0.815, and LPIPS 0.221, outperforming Scaffold-GS with 32-dim anchors (PSNR 27.50, SSIM 0.806, LPIPS 0.252). On Tanks&Temples and Deep Blending, SOGS further reduces anchor dimension to 12 while still surpassing Scaffold-GS (e.g., PSNR 24.14 vs 23.96 on Tanks&Temples; PSNR 30.29 vs 30.21 on Deep Blending). On the large-scale BungeeNeRF dataset, SOGS (16 dim) achieves PSNR 27.06 and LPIPS 0.171 versus Scaffold-GS's 26.62 and 0.241, demonstrating consistent gains across bounded and unbounded scenes.

## Baselines & Comparisons

SOGS is compared primarily against Scaffold-GS (the anchor-based 3D-GS baseline) and visually against 3D-GS. Against Scaffold-GS, SOGS wins on all three metrics (PSNR, SSIM, LPIPS) across all four datasets while using 50–62% fewer anchor feature dimensions (12–16 vs 32), directly translating to smaller model size. The most notable margin is on BungeeNeRF, where SOGS improves LPIPS from 0.241 to 0.171 (a 29% relative reduction) and PSNR from 26.62 to 27.06. Against 3D-GS, the paper provides only qualitative visual comparisons (Figure 4), showing SOGS produces finer textures with fewer artifacts at a significantly smaller model size. The authors explicitly exclude HAC and ContextGS from quantitative comparison, arguing those methods reduce storage size via compression rather than the actual anchor/model size used during training and rendering.

## Relation to Prior Work

SOGS extends Scaffold-GS (Lu et al., CVPR 2024), the first anchor-based 3D Gaussian splatting method that uses anchor points with MLPs to predict Gaussian attributes, by introducing second-order statistics (covariance/correlation across anchor feature dimensions) to augment each anchor's representation without increasing its stored dimensionality. The core rendering pipeline (anisotropic 3D Gaussians, differentiable splatting, alpha-blending) is inherited from 3D-GS (Kerbl et al., 2023). The paper explicitly positions itself against compression-based follow-ups like HAC and ContextGS, arguing that those reduce storage size rather than the actual anchor/model size used during training and rendering, whereas SOGS directly shrinks the anchor feature dimension (32→16 or 12) while maintaining or improving quality.

## Why It Matters / Open Questions

The paper addresses a practical and well-motivated trade-off in anchor-based 3D-GS: larger anchor features yield better rendering but inflate model size, while smaller features introduce visible artifacts. The second-order anchor concept—using cross-anchor covariance to extract principal co-variation patterns that augment individual anchor features—is a lightweight mechanism that could inform future compact scene representations. However, the improvements over Scaffold-GS are modest (e.g., +0.35 PSNR on Mip-NeRF360, +0.08 on Deep Blending), comparisons are limited to Scaffold-GS and 3D-GS without other recent 3D-GS variants, and the added PCA-like computation introduces slight overhead. Open questions include whether the approach generalizes to dynamic or very large-scale scenes, whether the fixed M=2 eigenvector selection is optimal, and whether the selective gradient loss's dynamic region weighting can be extended to other rendering objectives.

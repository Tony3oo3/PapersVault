## Problem

Decoder-only autoregressive image models enforce a fixed raster-order (row-major) sequencing, restricting them to one-directional context and preventing the flexibility that bi-directional masked models like MaskGIT enjoy for tasks such as inpainting, outpainting, and parallel decoding. The paper asks whether this raster-order inductive bias is truly necessary and how to equip causal decoder-only transformers with bi-directional modeling capability while preserving their simplicity and KV-cache compatibility.

## Input / Output

For class-conditional generation, the model takes a class label and produces a 256×256 RGB image by autoregressively predicting 256 discrete VQGAN tokens (16×16 grid, vocabulary 16,384) in a randomly permuted order. For zero-shot applications, it accepts partial image tokens plus a class label (inpainting), a full source image (outpainting to 256×1024 or resolution extrapolation to 512×512), or a complete image for bi-directional feature extraction. The key structural detail is that each predicted image token is preceded by a position instruction token encoding its 2D spatial coordinates, creating an interleaved sequence of length 2N.

## Method

RandAR enables random-order next-token prediction by inserting a position instruction token before each image token, where the token is a single shared learnable embedding rotated by 2D RoPE at the target spatial coordinates. During training, the 256 image tokens are randomly permuted (sampling from 256! possible orders), position instruction tokens are interleaved, and a standard causal decoder-only transformer (following LLaMAGen architecture with only one additional trainable embedding) is trained via next-token prediction. At inference, parallel decoding predicts multiple tokens per step by appending several position instruction tokens simultaneously, reducing steps from 256 to 88 and achieving 2.5× latency reduction with KV-cache support. The random-order training unlocks zero-shot capabilities: inpainting by placing visible tokens first, outpainting via full-sequence attention with extrapolated RoPE, resolution extrapolation using a hierarchical even-then-odd coordinate decoding schedule with spatial contextual guidance, and bi-directional feature extraction by passing the token sequence through the model twice.

## Results

On ImageNet 256×256 class-conditional generation, RandAR-XL (775M) achieves FID 2.25 and IS 317.77 with only 88 parallel decoding steps, comparable to its raster-order counterpart (FID 2.16, 256 steps). The larger RandAR-XXL (1.4B) reaches FID 2.15 and IS 321.97 at 88 steps, slightly outperforming the 775M raster-order model. Parallel decoding reduces inference latency by 2.5× (88 vs. 256 steps) without sacrificing quality, and RandAR additionally supports zero-shot inpainting, outpainting, and 256→512 resolution extrapolation—capabilities unavailable to raster-order decoder-only models.

## Baselines & Comparisons

Against its direct raster-order counterpart (same architecture, 775M, 256 steps, FID 2.16), RandAR-XL (88 steps) achieves FID 2.25—a small gap of 0.09 FID while using 2.9× fewer steps and 2.5× lower latency. The larger RandAR-XXL (1.4B, 88 steps) actually edges out the 775M raster-order model (FID 2.15 vs. 2.16) while using fewer steps. Compared to the base LLaMAGen-XL (775M, FID 2.62, 576 steps), RandAR-XL improves FID by 0.37 and reduces steps by 6.5×. Against stronger causal AR baselines like RAR-XL (1.5B, FID 1.48) and VAR 2.0B (FID 1.92), RandAR trails on FID, but those models use more parameters and do not support the zero-shot inpainting, outpainting, or resolution extrapolation capabilities that RandAR provides. The key differentiator is that RandAR is the only decoder-only method in the comparison that supports arbitrary generation orders, enabling parallel decoding, inpainting, outpainting, and bi-directional feature extraction without any architectural change beyond one learnable position-instruction embedding.

## Relation to Prior Work

RandAR builds directly on LLaMAGen's decoder-only autoregressive image generation framework, which arranges 2D image tokens in a fixed raster order and applies standard next-token prediction. The key departure is the removal of this raster-order inductive bias: by inserting a single learnable position instruction token (rotated with 2D-RoPE) before each image token, the model can generate in any spatial order while preserving the plain causal transformer architecture and KV-cache compatibility. Conceptually, this bridges the long-standing gap between unidirectional decoder-only AR models (GPT-style) and bidirectional masked AR models like MaskGIT and MAR, which enjoy flexible generation orders but lack KV-cache support and LLM compatibility.

## Why It Matters / Open Questions

The practical impact is significant: a single additional embedding unlocks parallel decoding (2.5× speedup), zero-shot inpainting, outpainting with full-sequence attention, resolution extrapolation (256→512), and bidirectional feature extraction from a causal model — capabilities previously exclusive to encoder-decoder architectures. The finding that 256! random permutations are learnable to comparable FID quality challenges the assumption that raster order is a necessary inductive bias for decoder-only image generation. Open questions include whether the resolution extrapolation approach generalizes to higher ratios and more complex high-frequency structures, and whether the random-order formulation scales effectively to larger token counts and multi-modal settings.

## Problem

Natural language, the dominant medium for human-robot interaction, inherently lacks spatial precision, producing ambiguity and verbosity when describing object positions, directions, and distances. Existing visual alternatives such as goal images and full trajectories are impractical for users to produce in real-world settings. This paper introduces Robotic Visual Instruction (RoVI), a hand-drawn symbolic paradigm using arrows, circles, colors, and numbers to convey precise spatiotemporal manipulation commands, and a pipeline (VIEW) to translate these 2D sketches into executable 3D robot actions.
![Teaser figure](../imgs/CVPR20252830/cropped_page0_idx0.webp)

## Input / Output

The system consumes a hand-drawn RoVI overlay (arrows for trajectories, circles for affordances, color-coded for temporal sequence: green/blue/pink for steps 1/2/3) rendered on a tablet, combined with an RGB observation image and a default text prompt. A YOLOv8 keypoint module extracts 2D coordinates (tail, waypoints, head of arrows; center of circles) from the RoVI symbols, which are then lifted to 3D via RGB-D depth data. The VLM outputs a hierarchical language response (task description + sub-goal planning) and Python code functions (e.g., move(), grasp()), while the low-level policy produces a sequence of SE(3) end-effector poses executed at 20 Hz.

## Method

VIEW is a three-stage pipeline: (1) a VLM (GPT-4o or LLaVA-13B fine-tuned via LoRA on the 15K-instance RoVI Book dataset) interprets RoVI through Chain-of-Thought reasoning, producing both a natural-language task plan and executable Python functions; (2) a dedicated YOLOv8 keypoint module, trained on 2K images, detects RoVI symbol components (arrow tails, shafts, heads, circle centers) to yield pixel-space spatiotemporal constraints, avoiding the fragility of open-vocabulary object detection to environmental distractors; (3) a keypoint-conditioned low-level policy maps 2D keypoints to 3D via depth, filters grasp poses using AnyGrasp, and executes a cost-minimization loop over SE(3) poses that separately handles translational (Euclidean distance) and rotational (angular deviation) costs. Multi-step tasks are decomposed by color identifiers into single-step subtasks, reducing temporal reasoning complexity. The RoVI Book dataset, built from Open-X Embodiment with 3–8 visual variants per task, enables lightweight VLMs to learn RoVI comprehension with minimal compute (one LoRA epoch at lr=2e-4 on a single A40 GPU).

## Results

On 8 unseen real-world manipulation tasks, VIEW-LLaVA-13B (fine-tuned on RoVI Book) achieves an 87.5% average success rate, substantially outperforming language-conditioned baselines CoPa (45%) and VoxPoser (43.8%). In the SIMPLER simulation environment, VIEW achieves 76.6% average success across 3 cluttered tasks, compared to RT-1-X (20%), Octo-goal-image (13.3%), and Octo-language (3%). The keypoint module (YOLOv8) achieves mAP 1.00 and mean distance error of 6.8–19.5 pixels, far surpassing open-vocabulary detectors (GDINO: mAP 0.00, MD 482–751 px; OWL-V2: mAP 0.00–0.64, MD 52–131 px).

## Baselines & Comparisons

VIEW-LLaVA-13B (87.5% avg) outperforms both language-conditioned baselines by a wide margin: CoPa (45%) and VoxPoser (43.8%) on real-world tasks, with the largest gaps on spatial-precision tasks (Task 4: 100% vs 60%/10%) and trajectory-following (Task 5: 70% vs 0%/0%). In simulation, VIEW (76.6%) dominates all end-to-end VLA baselines—RT-1-X (20%), Octo-goal-image (13.3%), and Octo-language (3%)—by 56–74 percentage points, indicating that language and goal-image inputs are insufficient for cluttered, multi-step manipulation. For VLM comprehension (Table 2), GPT-4o leads with 81% (real) and 97% (sim), while the fine-tuned LLaVA-13B (38% real, 64% sim) narrows the gap on simulation and notably excels on the longest multi-step task (Task 8: 82% vs GPT-4o's 55%). The YOLOv8 keypoint module achieves perfect mAP (1.00) and sub-20-pixel mean distance error, whereas open-vocabulary detectors (GDINO, OWL-ViT, OWL-V2) fail to reliably localize RoVI symbols (mAP 0.00–0.64, MD 52–751 px), confirming that task-specific keypoint extraction is critical for spatial precision.

## Relation to Prior Work

This paper departs from the dominant language-conditioned manipulation paradigm (RT-1/RT-2, VoxPoser, CoPa) by arguing that natural language is inherently imprecise for spatial-temporal robotic control, and instead introduces a hand-drawn symbolic instruction modality (RoVI) using arrows, circles, and color-coded sequences. It repurposes the visual prompting concept explored in VQA (VIP-LLaVA, Set-of-Mark) into a structured robotic command language, while drawing on keypoint-based manipulation work (ReKep, K-ViL) but inverting the keypoint extraction target from environmental objects to the instruction symbols themselves. The VIEW pipeline combines VLM-based planning (CoT reasoning, code generation) with a dedicated YOLOv8 keypoint detector and a SE(3) low-level policy, positioning itself between end-to-end VLA models (RT-1-X, Octo) and purely language-driven planners.

## Why It Matters / Open Questions

RoVI offers a silent, spatially precise, and user-friendly alternative to verbal HRI that could be particularly valuable in noise-sensitive or privacy-sensitive environments (hospitals, libraries). The finding that a 13B model fine-tuned on 15K RoVI Book instances matches or exceeds GPT-4o on full-pipeline execution (87.5% vs 82.5%) suggests that task-specific visual instruction understanding is learnable at modest scale, enabling edge deployment. Open questions include whether the paradigm generalizes beyond the five manipulation skills tested, how it handles truly free-form or ambiguous sketches, and whether the tablet-based drawing requirement limits real-world adoption. The dataset is relatively small (15K) and the evaluation covers only 11 tasks across two robot arms, leaving broader generalization claims under-tested.

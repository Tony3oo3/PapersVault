## Problem

Existing correspondence methods require separate, task-specific feature descriptors for geometric, semantic, and temporal matching, limiting flexibility when the matching type is unknown. While DIFT showed that diffusion model features can produce emergent correspondences, it still relies on distinct descriptors per task and lacks the accuracy of supervised methods. The paper asks whether a single unified feature can achieve state-of-the-art performance across all three correspondence types simultaneously.
![Teaser figure](../imgs/CVPR20252292/cropped_page0_idx0.webp)

## Input / Output

MATCHA takes a single RGB image as input and produces one unified feature descriptor F_m of shape H/8 × W/8 × 1024, used with nearest-neighbor matching for all correspondence tasks. For geometric matching, SuperPoint provides sparse keypoints on which the descriptor is evaluated; for semantic and temporal matching, the feature is queried at arbitrary pixel locations. The 8× spatial downsampling means the feature operates at reduced resolution, trading fine-grained geometric precision for broader semantic coverage.

## Method

MATCHA extracts three raw feature sets: a semantic descriptor F_h and geometric descriptor F_l from a pre-trained Stable Diffusion model (via DIFT), and an object-level descriptor F_d from DINOv2. The key architectural contribution is a dynamic fusion module built from k transformer blocks with self-attention and cross-attention, where geometric and semantic features mutually attend to each other and are jointly supervised with correspondence-level losses (dual softmax for geometric, CLIP contrastive + dense semantic flow for semantic). This learned fusion is critical: ablations show that naively concatenating raw or individually supervised features degrades performance, whereas the cross-attention mechanism enables each descriptor to extract complementary information from the other. The enhanced geometric F_g and semantic F_s are then statically merged via channel concatenation with DINOv2's F_d (downsampled to match spatial resolution) to form the final 1024-channel unified descriptor. Supervision is applied only to the fusion stage, preserving DINOv2's generalization while injecting precise correspondence knowledge into the diffusion-derived features.

## Results

MATCHA achieves the best average score of 79.6 across geometric (Aachen AUC@5/10/20: 51.7/61.0/68.5), semantic (PF-Willow PCK@0.05/0.1/0.15: 70.2/91.3/97.0), and temporal (TAPVid-Davis PCK@0.05/0.1/0.15: 87.8/93.5/95.5) matching using a single unified feature descriptor. This outperforms the next-best single-feature method DIFT.Uni+DINOv2 (avg 73.0) by 6.6 points and the unsupervised DIFT (avg 72.1) by 7.5 points. On semantic matching, MATCHA reaches 97.0 PCK@0.15 on PF-Willow, surpassing all supervised baselines except GeoASM (which requires dataset-specific models and object masks). On temporal matching, MATCHA achieves 95.5 PCK@0.15, exceeding DINOv2 (92.0) and DIFT.Uni+DINOv2 (93.5).

## Baselines & Comparisons

MATCHA (avg 79.6) outperforms all single-descriptor baselines across the three matching tasks, beating DINOv2 (61.1) by 18.5 points, DISK (45.0) by 34.6 points, and DeDoDe-G (65.1) by 14.5 points in overall average. Against the closest unsupervised competitor DIFT.Uni+DINOv2 (73.0), MATCHA gains 6.6 points, with the largest margin on temporal matching (92.3 vs 90.5) and semantic matching (86.2 vs 77.4). On geometric matching (Aachen), MATCHA (60.4) trails DeDoDe-G (69.9) by 9.5 points but surpasses DIFT (52.7), DINOv2 (26.6), and DISK (57.0). On semantic matching (PF-Willow), MATCHA (86.2) leads all methods including supervised baselines like SD4Match (80.9) and DHF (90.4 on PF-Pascal but not reported on PF-Willow). On temporal matching (TAPVid), MATCHA (92.3) exceeds DINOv2 (88.3) by 4.0 points and DIFT.Uni+DINOv2 (90.5) by 1.8 points, confirming that correspondence supervision on top of DINOv2's object-centric features further improves temporal robustness.

## Relation to Prior Work

MATCHA builds directly on DIFT, which showed that diffusion model features (Stable Diffusion) implicitly encode geometric and semantic correspondences without supervision, and on DINOv2, a self-supervised vision transformer with strong object-level semantic features. The key departure from DIFT is the introduction of explicit correspondence-level supervision (dual softmax loss for geometric, CLIP contrastive + semantic flow loss for semantic) combined with a learned dynamic fusion module using self- and cross-attention transformers, rather than the task-specific descriptor selection DIFT requires. Unlike SD+DINO, which simply concatenates features from different foundation models, MATCHA learns to extract mutually supportive information between geometric and semantic branches before static merging, addressing the finding that naive concatenation degrades performance.

## Why It Matters / Open Questions

This is the first demonstration that a single feature descriptor can achieve state-of-the-art across geometric, semantic, and temporal matching simultaneously, eliminating the need to maintain task-specific descriptors in practice. The finding that DINOv2 excels at temporal matching despite poor geometric performance reveals a non-obvious complementary structure in foundation model features that future unified matching systems should exploit. Limitations include resolution constraints (8× downsampling) that hinder fine-grained geometric matching and runtime efficiency concerns from the multi-backbone architecture. Open questions include whether the supervision requirement can be further reduced, whether the approach extends to additional correspondence types (e.g., cross-modal), and whether the fusion mechanism can be made more efficient for real-time deployment.

## Problem

Visual Auto-Regressive (VAR) modeling reduces decoding steps via next-scale prediction but at the cost of a 2.7× longer token sequence (680 tokens across 10 scales for a 16×16 image), causing prohibitive KV-cache memory consumption and substantial computational redundancy at larger scales where far fewer parameters are actually needed for accurate token prediction.

## Input / Output

Given a class label, the method generates a 256×256 RGB image by autoregressively predicting 10 multi-scale token maps (from 1×1 up to 16×16 tokens) that are decoded via a residual-style VQVAE decoder. The generation is split at a configurable drafting step N (e.g., N=6 or 8), after which the large model's KV cache is released and a smaller model takes over the remaining scales, reducing peak memory from ~39 GB to ~20 GB at batch size 64.

## Method

CoDe partitions VAR's next-scale prediction into a drafter (the original 2B VAR-d30 model) that generates the first N low-frequency token maps, and a refiner (a 0.3B VAR-d16 model) that predicts the remaining K−N high-frequency token maps using the drafter's output as a prefix. This exploits two key observations: parameter demands drop sharply at larger scales, and small/large scales learn exclusive (low- vs. high-frequency) patterns that interfere when trained jointly. Specialized fine-tuning further optimizes each model for its role: the drafter is fine-tuned with cross-entropy loss on its N scales, while the refiner is trained via knowledge distillation from the teacher VAR-d30 with a dynamic weighting schedule that gradually shifts emphasis from all tokens to only the refining tokens. The approach achieves 1.7× speedup with 50% memory reduction (FID 1.95→1.98) at N=8, and up to 2.9× speedup (41 images/s on a single 4090) with FID 2.27 at N=6.

## Results

On ImageNet-256 class-conditional generation, VAR-CoDe (N=8) achieves FID 1.98 with a 1.7× speedup (2.11s vs 3.62s) and 50% memory reduction (21 GB vs 39 GB) compared to the original VAR-d30 (FID 1.95). At the more aggressive N=6 setting, CoDe reaches a 2.9× speedup (1.27s, 50.39 it/s throughput) with FID 2.27, making it the fastest method to achieve FID below 2.3. The method also outperforms smaller VAR variants: CoDe N=8 matches VAR-d24's speed (1.7×) while improving FID from 2.11 to 1.98, and CoDe N=7 approaches VAR-d20's speed (2.3× vs 2.8×) with substantially better FID (2.11 vs 2.61).

## Baselines & Comparisons

Against the original VAR-d30, CoDe N=8 trades a negligible FID increase (1.95→1.98) for a 1.7× speedup and 50% memory reduction, while CoDe N=6 pushes to 2.9× speedup at FID 2.27. Compared to smaller VAR variants, CoDe dominates the efficiency-quality frontier: at the same 1.7× speedup as VAR-d24, CoDe N=8 improves FID by 0.13 (1.98 vs 2.11), and at a similar 2.3× speedup to VAR-d20, CoDe N=7 improves FID by 0.50 (2.11 vs 2.61). Against GPT-style LlamaGen-XXL, CoDe N=6 is 60× faster (1.27s vs 73.97s) while achieving a lower FID (2.27 vs 2.34). Against the diffusion baseline DiT-XL/2, CoDe N=6 is 15× faster (1.27s vs 19.20s) with a comparable FID (2.27 vs 2.26). Against Mamba-based AiM-XL and MAE-style MAR-B, CoDe N=6 is 7× and 23× faster respectively, with FID improvements of 0.29 and 0.04.

## Relation to Prior Work

This paper builds directly on VAR (Visual Auto-Regressive modeling), which replaced GPT-style next-token prediction with next-scale prediction to reduce decoding steps. It departs from VAR's single-model paradigm by introducing a collaborative decoding strategy that partitions the multi-scale sequence between a large drafter and a small refiner, drawing conceptual inspiration from speculative decoding (LANTERN, SJD) but adapting it to the next-scale prediction structure where entire token maps are predicted in parallel. The specialized fine-tuning of the refiner via knowledge distillation from the larger model connects to standard distillation practice, while the core insight—that parameter demands drop sharply at larger scales—repurposes the scalability observations from VAR into an architectural decomposition.

## Why It Matters / Open Questions

As VAR becomes a dominant paradigm for efficient image generation, the KV cache memory bottleneck (consuming ~12× more memory than forward computation) is a critical practical limitation that CoDe addresses with a 50% reduction and up to 2.9× speedup at minimal quality cost. The finding that a 0.3B model matches a 2B model at the final scale (38% of tokens) challenges the implicit assumption that uniform model capacity is needed across all scales, with implications for future VAR architecture design. Limitations include evaluation only on ImageNet 256×256 class-conditional generation, dependence on batch size for full speedup, and the need to maintain two models; open questions include whether this decomposition generalizes to higher resolutions, text-to-image, and other modalities where VAR is being extended.

## Problem

Existing mesh saliency prediction methods and datasets focus exclusively on non-textured meshes, leaving the interaction between geometric structure and surface texture in shaping visual attention unexplored. No prior dataset systematically captures saliency distributions for the same mesh under both textured and non-textured conditions, and no unified model integrates texture features into the topological framework of mesh saliency prediction.
![Teaser figure](../imgs/CVPR20252448/cropped_page2_idx0.webp)

## Input / Output

The model consumes a triangular mesh (vertices, face connectivity, normals, adjacency) and, for textured meshes, a 2D texture image that is aligned to the surface via UV mapping through an implicit neural representation (latent code map). The output is a dense per-face saliency value assigned to every triangle, produced by upscaling patch-level embeddings back to face resolution via distance-weighted voting interpolation over the three nearest FPS centers.

## Method

The architecture comprises three stages: (1) a graph convolution encoder that retrieves texture features at each triangle via UV-mapped queries into a latent code map, fuses them with geometric descriptors (spatial centers, normal-based curvature, face shape/angles), and propagates features along face adjacency; (2) a subgraph embedding module that selects L center faces via farthest point sampling and grows topology-preserving patches of length M through random walk sampling, avoiding the adjacency disruption caused by KNN spatial clustering; (3) a bidirectional Mamba block where each subgraph token undergoes feature diffusion (generating pseudo-adjacent faces) and aggregation (softmax-weighted neighborhood pooling) before being processed by forward and backward selective SSM layers in parallel. The model is trained end-to-end with L1 loss under a supervised paradigm, and the same architecture handles both textured and non-textured meshes by simply omitting the texture alignment branch.

## Results

On the proposed Mesh Saliency Dataset for textured meshes with full texture features, Mesh Mamba achieves CC=0.6305, SIM=0.7232, KLD=0.2888, and SE=0.0265, outperforming the strongest baseline Mamba3D (CC=0.5013) by 12.9% in correlation. On non-textured meshes using geometry only, the model reaches CC=0.6140 and SIM=0.7171, surpassing Mamba3D (CC=0.5993) and MeshNet (CC=0.5423). On the external SAL3D dataset, Mesh Mamba attains CC=0.6763 and KLD=0.2303, leading all 14 compared methods including MeshNet++ (CC=0.6513) and Mamba3D (CC=0.6181).

## Baselines & Comparisons

Mesh Mamba outperforms all 14 baselines across every metric and every evaluation condition (non-textured geometry, non-textured color, textured geometry, textured color, textured full, and SAL3D). The largest margin is against Mamba3D on textured meshes with texture features, where Mesh Mamba gains +12.9% CC (0.6305 vs. 0.5013) and reduces KLD by 24% (0.2888 vs. 0.3797), demonstrating the advantage of the graph convolution encoder's texture alignment over Mamba3D's point-based processing. Against mesh-native baselines, Mesh Mamba leads MeshNet by +7.0% CC on textured meshes and +13.4% CC on non-textured geometry, while MeshNet++ underperforms MeshNet in most settings, suggesting its architecture is less suited to saliency. Point-based methods (PointNet, PointNet2, PointTrans, PointMixer, StraTrans) consistently trail mesh-based methods by 5–15% CC, confirming that topological connectivity matters for saliency. The DSM methods (CNN and FCN variants) perform worst overall (CC ≈ 0.22), indicating that patch-scale descriptors are insufficient for global saliency. On the external SAL3D dataset, Mesh Mamba still leads the closest competitor MeshNet++ by +3.8% CC and −9.7% KLD, validating generalizability beyond the authors' own dataset.

## Relation to Prior Work

This paper extends mesh saliency prediction from the non-textured-only setting (Lee et al. 2005, SAL3D, DSM) to a unified framework handling both textured and non-textured meshes, using a state space model backbone inspired by Mamba. The local feature extraction relies on graph convolution over triangular face adjacency, while the global context modeling adapts Mamba's selective SSM with a bidirectional scan. A key methodological departure is the subgraph embedding via farthest-point-sampling centers and random-walk sampling, which preserves topological connectivity in a way that KNN-based spatial clustering (used in point cloud Mamba variants like Mamba3D) cannot. Texture features are injected through UV-mapped implicit neural representations (latent code maps), borrowing the continuous implicit representation paradigm from NeRF-style work.

## Why It Matters / Open Questions

The first paired textured/non-textured mesh saliency dataset collected via VR eye-tracking provides a controlled benchmark for studying how texture modulates visual attention on 3D surfaces, filling a gap where prior datasets only covered geometry or simple vertex colors. The finding that vertex colors consistently degrade performance across all methods—while full texture alignment improves textured-mesh prediction—offers practical guidance for feature selection in 3D attention modeling. Open questions include whether the VR-collected saliency generalizes to screen-based or in-the-wild viewing, how the model scales to meshes with millions of faces, and whether the subgraph-embedding strategy transfers to other mesh-level prediction tasks beyond saliency.

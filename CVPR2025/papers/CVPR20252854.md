## Problem

SAM 2, the state-of-the-art promptable video segmentation model, runs at only ~1 FPS on mobile devices, making on-device deployment impractical. Prior efficiency efforts for SAM focused solely on compressing the image encoder, but this paper's benchmark reveals that the newly introduced memory attention blocks—where densely stored frame-level memories are cross-attended with current frame features—are an equally critical latency bottleneck that replacing the backbone alone cannot resolve.
![Teaser figure](../imgs/CVPR20252854/cropped_page0_idx0.webp)

## Input / Output

The model consumes RGB video frames at 1024×1024 resolution along with user prompts (points, boxes, or masks) that can be applied at any frame in the sequence, following SAM 2's promptable video segmentation protocol. It produces per-pixel segmentation masks, mask confidence scores, and occlusion predictions, maintaining a FIFO memory bank of 7 frame-level memories and 16 object pointers across the video. The resulting EdgeTAM achieves 16 FPS on iPhone 15 Pro Max and 40.4 FPS on A100, compared to 1.3 FPS for SAM 2 on the same hardware.

## Method

EdgeTAM introduces a 2D Spatial Perceiver as a plug-in module that compresses each frame-level memory feature map (64×64×64) into a much smaller token set while preserving 2D spatial structure. The learnable queries are split into two groups: global latents (256) that perform standard Perceiver-style global cross-attention to produce a frame-level summary, and 2D latents (256) with spatial priors where each latent is restricted to attend only to a non-overlapping local patch via window partitioning, with 2D-RoPE positional embeddings added to the output. This reduces memory attention complexity from O(TCH²W²) to O(TCHW(Ng+Nl)), yielding an ~8× speedup in the memory attention stage. The backbone is replaced with RepViT-M1 and memory attention blocks are reduced from 4 to 2. A two-stage distillation pipeline further improves accuracy at zero inference cost: in the image pre-training stage, MSE loss aligns the student's image encoder features with the SAM 2-HieraB+ teacher, and in the video training stage, an additional MSE loss aligns the memory attention output between teacher and student, providing supervision to the memory-related modules.

## Results

EdgeTAM achieves 87.7 J&F on DAVIS 2017 val, 70.0 on MOSE val, 72.3/71.7 on SA-V val/test, and 86.2 G on YTVOS 2019 val, while running at 15.7 FPS on iPhone 15 Pro Max (22× faster than SAM 2 at 0.7 FPS) and 150.9 FPS on A100. On the challenging SA-V benchmark, EdgeTAM narrows the gap to SAM 2 (73.6/74.1) to within 1.3/2.4 J&F, while outperforming all other VOS methods by 10+ J&F. For image segmentation (SA-23), EdgeTAM reaches 81.7 mIoU with 5 clicks at 40.4 FPS on iPhone, matching SAM-H (81.3) despite being trained without SAM 2's internal datasets.

## Baselines & Comparisons

Against SAM 2 and SAM 2.1, EdgeTAM trades 1.3–4.5 J&F on SA-V and 2.5–3.2 J&F on DAVIS for a 22× speedup on iPhone (15.7 vs 0.7 FPS), making it the first unified segmentation-and-tracking model deployable on-device. On the SA-V benchmark specifically, EdgeTAM (72.3/71.7) outperforms all non-SAM2 VOS methods by a wide margin: Cutie-base+ (61.3/62.8), STCN (61.0/62.5), XMem (60.1/62.3), and DEVA (55.4/56.2), with gaps of 10–17 J&F. On standard VOS benchmarks (DAVIS, MOSE, YTVOS), EdgeTAM is competitive but slightly below the best dedicated VOS models: it trails Cutie-base+ by 0.4 J&F on DAVIS (87.7 vs 88.1) and 1.3 G on YTVOS (86.2 vs 87.5), while matching or exceeding them on MOSE (70.0 vs 71.7 for Cutie-base+). Compared to SimVOS-B, EdgeTAM achieves comparable DAVIS scores (87.7 vs 88.0) but dramatically outperforms on SA-V (72.3 vs 44.2), highlighting the advantage of training on the multi-granularity SA-V dataset. For the image segmentation task (SA-23), EdgeTAM (81.7 mIoU at 5 clicks) matches SAM (81.3) and approaches SAM 2 (81.7) at 40.4 FPS on iPhone versus 1.3 FPS for SAM 2, though it trails SAM 2.1 (83.5) by 1.8 mIoU.

## Relation to Prior Work

EdgeTAM builds directly on SAM 2's architecture (image encoder, mask decoder, memory encoder, memory attention) and the Perceiver family of learned compression modules. It departs from prior SAM efficiency work (EdgeSAM, EfficientSAM, FasterSAM) that focused exclusively on compressing the image encoder, by identifying the newly introduced memory attention blocks as the true latency bottleneck for video inference. The 2D Spatial Perceiver is a novel modification of the standard Perceiver that assigns 2D spatial priors to a subset of learnable latents, preserving the spatial structure of compressed memories—a design motivated by the dense-prediction nature of video segmentation. The distillation pipeline extends the image-only feature alignment used in prior SAM compression work to also supervise memory-related modules during video training.

## Why It Matters / Open Questions

EdgeTAM is the first model to run unified promptable segmentation and tracking on a mobile device at 16 FPS, opening the door to real-time on-device video understanding without cloud dependency. The identification of memory attention (rather than the image encoder) as the computational bottleneck for SAM 2 is a broadly useful diagnostic for anyone building efficient video foundation models. The 2D Spatial Perceiver is a plug-in module applicable to any SAM 2 variant, and the finding that naive spatial pooling or a structure-agnostic Perceiver degrades performance significantly underscores that spatial structure preservation is non-negotiable for dense prediction. Open questions include whether the approach scales to much longer video sequences, whether the spatial prior can be learned rather than fixed, and whether similar compression strategies apply to other memory-augmented architectures beyond SAM 2.

## Problem

Existing model-free 6D pose estimation methods require either complete textured CAD models or densely posed RGBD references that fully cover the object from all viewpoints. In real-world settings, only partial references (a few RGBD images or a single RGB photo) are available, and the resulting incomplete 3D model leads to unreliable pose estimates with no mechanism to assess confidence or iteratively improve the model during testing.

## Input / Output

The method accepts either a small set of reference RGBD images with known camera poses or a single unposed RGB image, plus a sequential RGBD test video and an initial 2D object mask (subsequent masks obtained via SAM video). It outputs per-frame 6D poses (SE(3) transforms), a progressively refined neural SDF object model with an explicit mesh, a binary uncertainty map labeling each mesh vertex as seen or unseen, and per-pose confidence scores (seen IoU and uncertainty rate) that gate which frames enter the memory pool for completion.

## Method

UA-Pose builds a hybrid object representation by training a neural SDF (geometry + appearance networks) from partial references, extracting a closed mesh via marching cubes, and assigning binary uncertainty labels to each vertex using a visual-hull visibility check against the reference viewpoints. Pose estimation reuses FoundationPose's two-stage render-and-compare pipeline (refinement network + selection network) but augments it with uncertainty-aware filtering: candidate poses are discarded if their rendered uncertainty rate exceeds a threshold or their seen IoU (overlap between certain mesh regions and the test mask) falls below a threshold. When seen IoU drops below a completion threshold, the method triggers online object completion by retraining the SDF on a subset of memory-pool frames selected via uncertainty-aware sampling—iteratively picking the viewpoint that reveals the largest unseen region. For the single-RGB-image setting, an image-to-3D model (InstantMesh) initializes the SDF and additionally renders augmented RGBD views to supervise geometry in unseen regions, while real test frames progressively replace the generated model.

## Results

On YCB-Video with only 2 reference RGBD images, UA-Pose achieves 92.8% ADD-S and 0.53 CD, outperforming FoundationPose (87.4% ADD-S, 0.57 CD) and substantially exceeding LoFTR (26.2% ADD-S) and FS6D-DPM (42.1% ADD-S) which use 16 references. With a single unposed RGB image plus image-to-3D generation, UA-Pose reaches 93.2% ADD-S and 0.62 CD versus FoundationPose's 88.9% ADD-S and 0.67 CD. On the more challenging YCBInEOAT (robot manipulation) and HO3D (hand-object interaction) datasets, the gains are even larger: UA-Pose achieves 89.99% ADD vs. FoundationPose's 68.52% on YCBInEOAT, and 91.51% ADD vs. 45.67% on HO3D.

## Baselines & Comparisons

UA-Pose consistently outperforms all five baselines across every dataset and metric. Against the primary baseline FoundationPose [41], UA-Pose gains +5.4 points in ADD-S on YCB-Video (92.8 vs. 87.4) with 2 references, and the advantage widens dramatically on YCBInEOAT (+21.5 ADD, +9.6 ADD-S) and HO3D (+45.8 ADD, +34.0 ADD-S), where FoundationPose struggles with frequent rotations and occlusions. Against the older model-free methods LoFTR [30] and FS6D-DPM [10], which require 16 reference images, UA-Pose with only 2 references surpasses them by a large margin (92.8 vs. 26.2 and 42.1 ADD-S on YCB-Video). In the additional study (Table 5) where no external references are given and the first test frame initializes the model, UA-Pose (88.38 ADD, 93.82 ADD-S, 0.75 CD) beats both pose-tracking methods BundleTrack [36] (87.34 ADD, 92.53 ADD-S) and BundleSDF [40] (86.95 ADD, 93.77 ADD-S) on all three metrics, while also offering the advantage of accepting reference images with meta-information.

## Relation to Prior Work

UA-Pose builds directly on FoundationPose's unified render-and-compare framework (pose refinement + pose selection networks) and BundleSDF's neural SDF training pipeline, but departs from both by explicitly modeling uncertainty in the object representation. Where FoundationPose assumes sufficient posed RGBD references to reconstruct a complete model, and BundleSDF tracks within a single video sequence, UA-Pose introduces a hybrid mesh that integrates texture, geometry, and a visual-hull-inspired uncertainty map to handle the practically common case of only 2 reference images or a single unposed RGB image. The online object completion with uncertainty-aware sampling extends BundleSDF's SDF refinement into a selective, confidence-gated process, and the single-image-to-3D initialization (via InstantMesh) repurposes generative 3D models as both pose priors and augmented training data rather than as final representations.

## Why It Matters / Open Questions

This work addresses a critical practical gap: in real-world robotics and AR, complete 3D CAD models or densely captured reference images are rarely available, yet existing model-free methods degrade sharply under partial observations. The uncertainty-aware framework provides not just better accuracy but also per-pose confidence scores, which is essential for safety-critical manipulation where the system must know when its estimate is unreliable. Open questions include how the approach scales to highly deformable or transparent objects, whether the uncertainty map can be made continuous (rather than binary) for finer-grained confidence, and how well the single-image-to-3D initialization generalizes beyond the YCB object set. The finding that generated 3D models have good geometry but insufficient texture in unseen regions highlights a fundamental limitation of current image-to-3D methods for pose estimation.

## Problem

Existing text-to-image diffusion model control methods handle 2D attributes (appearance, layout, style) or require dense 3D inputs (multi-view images, accurate 3D bounding boxes) for 3D control, but none provide precise per-object 3D orientation control in multi-object scenes. This paper asks whether a lightweight, object-centric orientation interface can be added to a standard T2I model without altering its original text-prompt interface.
![Teaser figure](../imgs/CVPR20252170/cropped_page0_idx3.webp)

## Input / Output

The method takes a text prompt listing N objects, a single orientation angle θ per object (rotation around the world up-axis, with θ=0 meaning facing right), and optional coarse 2D bounding boxes (padded by λ=1.2). It produces a single RGB image where each object is rendered in its specified orientation. The bounding boxes are loose and non-overlapping; at inference they can even be spawned heuristically rather than specified precisely, making the interface more user-friendly than methods requiring accurate 3D boxes.

## Method

The core mechanism introduces compass tokens—learned embeddings in the text encoder's input space, one per object, predicted by a lightweight 3-layer MLP from the orientation angle. These tokens are interleaved with the corresponding object tokens in the prompt and condition the denoising U-Net via standard cross-attention. The key technical contribution is Coupled Attention Localization (CALL): a binary mask (0 inside a loose bounding box, −∞ outside) is applied to the cross-attention maps of both the compass token and its object token at every diffusion timestep and attention layer, forcing the compass token's influence to be spatially restricted to its object region. This prevents the compass token from attending to irrelevant regions and disentangles orientation control across multiple objects. Training uses a two-stage procedure on a synthetic dataset of 10 3D assets (8900 rendered + 6010 ControlNet-augmented images): first single-object scenes to learn bounding-box adherence, then mixed single/two-object scenes, with LoRA (rank 4) fine-tuning of the Stable Diffusion v2.1 U-Net.

## Results

On single-object scenes, Compass Control achieves an angular error of 0.198 rad, nearly halving the error of the strongest baseline LooseControl (0.385 rad), while generating the intended object in 96.8% of cases (vs. 65.6% for LooseControl). On multi-object scenes, the method maintains a 96.4% object generation rate and 0.215 rad angular error, compared to 77.8% and 0.372 rad for LooseControl. Text alignment (CLIP similarity, lower is better) is slightly higher (worse) than LooseControl (32.98 vs. 31.60 for single-object), but the gains in orientation precision and object presence are substantial. A user study with 57 participants (5,130 single-object and 1,710 multi-object ratings) confirms that users prefer Compass Control across text alignment, object quality, and orientation consistency.

## Baselines & Comparisons

Compass Control outperforms all three main baselines on the primary metric of angular error: 0.198 rad vs. 0.385 (LooseControl), 0.509 (Cont-3D-Words), and 0.596 (ViewNeTI) on single-object scenes, and 0.215 vs. 0.372 (LooseControl) on multi-object scenes. It also achieves the highest object generation rate (96.8% single, 96.4% multi), far exceeding LooseControl (65.6%/77.8%) and Cont-3D-Words (73.2%), though ViewNeTI is competitive at 92.0% for single objects. The trade-off is a modest increase in CLIP text-alignment score (32.98 vs. 31.60 for LooseControl on single-object), suggesting slightly less prompt fidelity, but the user study shows users still prefer Compass Control overall. In the personalization setting, Compass Control matches CD-360 [31] in quality while requiring only ~10 unposed images versus ~100 posed images, making it substantially more practical. Cont-3D-Words and ViewNeTI are limited to single-object, global-view control and cannot handle multi-object orientation disentanglement, which is the core capability of Compass Control.

## Relation to Prior Work

This paper builds on latent diffusion models (Stable Diffusion v2.1) and parameter-efficient fine-tuning via LoRA, extending the text-conditioning interface by injecting orientation-specific 'compass tokens' predicted by a lightweight MLP encoder. It departs from prior 3D-control methods (ViewNeTI, Cont-3D-Words, LooseControl) that either require dense 3D inputs like multi-view images or 3D bounding boxes, or are limited to global view-angle control on single objects. The key architectural departure is the Coupled Attention Localization (CALL) mechanism, which constrains cross-attention maps of compass and object tokens to 2D bounding boxes—a technique borrowed conceptually from attention-based layout control but applied here to enforce per-object orientation binding and disentanglement.

## Why It Matters / Open Questions

Compass Control offers a practical, user-friendly interface for 3D orientation control that requires only coarse 2D boxes and an angle, avoiding the cumbersome 3D bounding box specification of prior methods. The strong generalization from 10 synthetic assets to unseen categories (humans, ships, prams) and from 2-object training to 5-object scenes suggests the approach could become a standard conditioning module for scene composition pipelines. However, the single-angle representation is too simplistic for non-rigid objects, and the method fails on heavily occluded or overlapping objects—open questions include whether richer orientation parameterizations (full 3D rotation, pose) and attention-based occlusion handling can close these gaps.

## Problem

State-of-the-art VPR methods achieve robustness to appearance changes (lighting, weather, season) primarily through increasingly complex training regimes, but their matching compute and memory scale with the number of distinct environmental conditions encountered. Existing multi-reference fusion approaches such as reference pooling and distance matrix averaging improve recall but incur linear increases in computational and storage complexity with each additional reference set, limiting scalability for long-term deployment.
![Teaser figure](../imgs/ICCV20251154/cropped_page0_idx0.webp)

## Input / Output

The method takes a single query RGB image and K reference sets of geo-tagged images (each set captured under a different condition such as sunny, night, rainy, or a different season), which are first encoded by any existing SOTA VPR descriptor into n-dimensional feature vectors. It produces a single fused HOPS descriptor per location with the same dimensionality n as the original descriptor, and ultimately a place match via minimum cosine distance. The key constraint is that the fused descriptor must be L2-normalized to preserve unit norm for cosine similarity, and the approach requires no modification to the underlying VPR feature extractor.

## Method

HOPS exploits the quasi-orthogonality property of high-dimensional spaces: by element-wise summing K reference descriptors from the same place captured under different conditions, salient structural features are reinforced while transient condition-specific noise is diminished, yielding a unified descriptor that is similar to all input conditions. This HDC bundling operation maintains O(M) matching complexity regardless of the number of fused reference sets K, in contrast to pooling or distance-matrix averaging which scale as O(K·M). The approach is entirely training-free and descriptor-agnostic, requiring only that the underlying VPR method produces fixed-dimension feature vectors. As a secondary capability, the same high-dimensional space properties enable Gaussian Random Projection to reduce descriptor dimensionality by up to 97% (for high-dimensional descriptors like SALAD and CricaVPR) while still exceeding full-size single-reference performance, and synthetic image augmentations can substitute for real multi-condition traverses when only a single reference set is available.

## Results

On Oxford RobotCar, HOPS fused descriptors achieve Recall@1 of 97.5% (CricaVPR, Sunny query) and 93.3% (SALAD, Sunny query), exceeding the best single-reference results by over 10% absolute in many cases. Across all three main datasets (RobotCar, Nordland, SFU Mountain), HOPS outperforms the best single-reference baseline in 61/84 cases and the best multi-reference baseline (dMat Avg or Pooling) in 69/90 cases, while maintaining O(M) matching complexity versus O(K·M) for baselines. On SFU Mountain, HOPS improves R@1 in 100% of cases over single-reference, and on Nordland achieves an average 2.9% absolute R@1 gain for SALAD. HOPS also enables up to 97% descriptor dimensionality reduction (SALAD: 8448D→256D) while still exceeding full-size single-reference performance.

## Baselines & Comparisons

Against single-reference baselines, HOPS consistently wins: on RobotCar it beats the best single-reference in 28/30 cases (e.g., SALAD Sunny: 92.8% vs 84.8%; CricaVPR Sunny: 97.5% vs 93.9%), on Nordland in 23/24 cases, and on SFU Mountain in all 36 cases. The only losses are minor (≤2.4% R@1) with low-dimensional CosPlace/EigenPlaces on RobotCar Night queries, attributed to insufficient dimensionality for HDC quasi-orthogonality. Against the multi-reference dMat Avg baseline [22], HOPS wins 22/30 cases on RobotCar, 18/24 on Nordland, and 29/36 on SFU Mountain; the dMat Avg approach is competitive on low-dimensional descriptors (CosPlace, EigenPlaces) where HDC bundling is less effective. Against the Pooling baseline, HOPS wins in the majority of high-dimensional descriptor cases (SALAD, CricaVPR, MixVPR) but loses on low-dimensional ones (CosPlace, EigenPlaces) where simply increasing the reference set size is more effective. Critically, HOPS achieves these gains at O(M) matching complexity, while both dMat Avg and Pooling scale to O(K·M), making HOPS the only approach that scales to arbitrary numbers of reference sets without compute penalty.

## Relation to Prior Work

This paper departs from prior HDC-based VPR work (Neubert et al., CVPR 2021), which fused descriptors from *different* VPR methods into a single representation, by instead fusing descriptors from the *same* VPR method captured under *different environmental conditions* of the same place. The core bundling operation (element-wise sum in high-dimensional space) is inherited from the broader Hyperdimensional Computing / Vector Symbolic Architecture literature, but its application to cross-condition reference stacking is new. The paper also positions itself against multi-reference VPR approaches (reference pooling, distance matrix averaging) that scale linearly in compute with the number of reference sets, and against training-based multi-condition methods (e.g., CricaVPR) that require expensive retraining to handle appearance change.

## Why It Matters / Open Questions

The practical significance is that HOPS provides a training-free, O(M)-complexity mechanism to improve VPR robustness by arbitrarily stacking reference conditions without increasing matching compute or memory — a property that directly addresses the scalability bottleneck of long-term autonomous navigation. The demonstrated 97% dimensionality reduction (for high-dimensional descriptors like SALAD) while maintaining or exceeding full-size single-reference performance opens a path to efficient deployment on resource-constrained platforms. Limitations include reduced effectiveness for low-dimensional descriptors (512D CosPlace/EigenPlaces), where quasi-orthogonality assumptions weaken, and the method's dependence on having aligned reference sets. Open questions raised by the authors include whether HOPS descriptors can serve as training targets for more robust feature extractors, whether fine-grained spatial features survive bundling, and whether entirely different datasets can be stacked into a single compressed representation.

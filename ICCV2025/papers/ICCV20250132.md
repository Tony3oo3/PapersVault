## Problem

Current AI approaches to histopathology diagnosis either divide gigapixel whole slide images (WSIs) into independently analyzed patches or use transformer architectures that cannot scale to WSI resolution, failing to replicate the iterative, multi-scale, holistic diagnostic workflow that expert pathologists employ. No existing system combines navigation, evidence gathering, and synthesis into a single interpretable pipeline that mimics how pathologists actually examine slides.
![Teaser figure](../imgs/ICCV20250132/cropped_page0_idx1.webp)

## Input / Output

The system takes H&E-stained histopathology WSIs (gigapixel scale) as input, internally dividing them into non-overlapping 512×512 patches at 10× magnification with background filtering (saturation < 15). It produces a four-class diagnostic label (mild/moderate dysplastic nevi, severe dysplasia/melanoma in situ, invasive melanoma pT1a, advanced invasive melanoma pT1b+), per-patch natural language descriptions, and spatial importance maps. Final predictions are aggregated via majority voting over 5 trajectories of 10 patches each, with 10 independent runs reported as mean performance.

## Method

PathFinder orchestrates four specialized agents in a sequential-iterative pipeline: a Triage Agent (transformer with Pyramid Position Encoding and squeeze-and-excitation blocks) first separates benign class 1 from the remaining three classes; a Navigation Agent (4-layer U-Net) generates importance maps over the WSI conditioned on T5-encoded textual descriptions from prior iterations, enabling text-guided patch selection; a Description Agent (instruction-tuned Quilt-LLaVA 7B) produces concise histopathological descriptions of each sampled patch; and a Diagnosis Agent (GPT-2 with a linear classification head) synthesizes all descriptions into a final label. The key mechanism is the iterative feedback loop where each new description updates the aggregated text embedding that conditions the next importance map, progressively refining the search region while masking previously visited patches. Training uses BCE loss for Triage and Navigation, instruction tuning on 102K GPT-4-generated samples for Description, and standard classification loss for Diagnosis, with LLaMA 3.1 used to paraphrase descriptions for data augmentation.

## Results

On the M-Path Skin Biopsy dataset, PathFinder with T5-Based Text-Conditioned Visual Navigator achieves 74% accuracy (F-1 = 0.74), surpassing the best SOTA baselines (ABMIL with CONCH or UNI2-h at 66%) by 8% and the average human expert performance (65%) by 9%. The F-1 score equals accuracy because the test set is balanced across the four diagnostic classes. Ablations show that removing the Triage Agent drops performance below baselines, and replacing the T5 text encoder with CLIP reduces accuracy from 74% to 62%.

## Baselines & Comparisons

PathFinder (74%) outperforms all 12 baselines on the M-Path melanoma classification task. The strongest SOTA baselines are ABMIL with CONCH (66%) and ABMIL with UNI2-h (66%), both of which PathFinder surpasses by 8 percentage points. PathFinder also exceeds the average human expert accuracy of 65% by 9%, making it the first AI system to surpass pathologist performance on this task. Among transformer-based baselines, ScAtNet variants range from 60–63%, while LLM prompting baselines (GPT-4o at 49%, LLaVA-Med at 43%, Quilt-LLaVA at 29%) perform substantially worse, indicating that simple prompting of off-the-shelf models is insufficient for WSI-level diagnosis. Ablations confirm that the iterative text-conditioned navigation is critical: a vision-only navigator (64%) and exhaustive search (68%) both underperform the full system, and replacing T5 with CLIP as the text encoder drops accuracy to 62%.

## Relation to Prior Work

PathFinder departs from the dominant WSI classification paradigm (MIL and transformer-based models like ABMIL and ScAtNet) that treats diagnosis as a single-pass patch aggregation problem, instead framing it as an iterative, multi-scale navigation process that mirrors how pathologists actually work. It draws on three distinct research threads: (1) multi-modal histopathology models (Quilt-LLaVA, Quilt-1M, PathAlign) that provide the Description Agent and patch-level representations but do not navigate gigapixel WSIs; (2) computational pathology studies of pathologist viewport data (M-Path, NaviPath) that characterize but do not automate navigation; and (3) multi-agent LLM systems from robotics and software engineering that demonstrate collaborative agent coordination but have not been applied to medical image analysis. The key architectural novelty is the text-conditioned visual navigator (a U-Net conditioned on T5-encoded descriptions) that closes the loop between visual patch selection and textual evidence accumulation across iterations.

## Why It Matters / Open Questions

PathFinder is the first AI system to surpass the average performance of human pathologists (74% vs. 65%) on the M-Path melanoma WSI classification task while providing inherent interpretability through natural language descriptions of diagnostically relevant patches. The finding that selective iterative navigation (74%) outperforms exhaustive search over all tissue patches (68%) challenges the assumption that more data is always better, and the ablation showing that a stronger text encoder (T5) can be detrimental when paired with lower-quality descriptions highlights an underexplored interaction between encoder capacity and input quality. Key limitations include the small test set (35 cases), reliance on only 32 pathologists' viewport data for training the navigator, use of GPT-2 (a relatively small LLM) for the Diagnosis Agent, and evaluation on a single tissue type (skin melanoma), leaving open whether the multi-agent framework generalizes to other histopathology domains.

## Problem

Existing zero-shot REC methods rely on hand-crafted rules and parsers for spatial/relation reasoning, which cannot adapt to varied natural language (e.g., 'lefty' vs. 'left'), and their use of isolated proposals for region-text matching inevitably loses global image context. Additionally, VLMs exhibit an inherent bias toward the visual modality in their cross-modal attention maps, which degrades the ability to align text queries with the correct regions.

## Input / Output

The method takes an RGB image (resized to 480×640) and a free-form natural language referring expression. An LLM first extracts the referring subject name and any other mentioned object names from the query; these names are fed to open-vocabulary detectors (GLIP-T or GDINO-T) to obtain candidate proposals. The output is a single bounding box for the referred object, selected by combining debiased attention-map scores with code-generated relation scores across all subject proposals.

## Method

The framework has two complementary scoring branches. First, a code-based relation reasoning module uses a general formulation that instructs an LLM (Qwen-plus) to decompose the query into simple independent relations, then generate executable Python code blocks for each computable relation (e.g., spatial positioning, clock-angle) while adaptively skipping non-computable attributes (e.g., color, action); the generated program takes proposal coordinates as input and outputs per-proposal matching scores. Second, a debiased cross-modal attention map is obtained by extracting the attention from a VLM's fusion layer (ALBEF cross-attention or BEiT-3 self-attention), subtracting the attention map computed from the image alone (to remove visual-modality bias via log-difference), and using the resulting positive map to score each proposal by area-normalized attention mass. The final prediction is the proposal maximizing the sum of normalized attention scores and all relation scores.

## Results

On RefCOCO (spatial understanding), the best configuration (GDINO-T w/ BEiT-3-vqa) achieves 78.81% Acc@0.5 on testA and 62.06% on testB, surpassing the previous zero-shot SOTA (GVLP w/VinVL-vqa at 69.21%/48.71%) by approximately 10% on average. On RefCOCO+ (appearance/abstract attributes), it reaches 76.02% on testA and 54.61% on testB. On RefCOCOg (longer, multi-step queries), it attains 72.21% on the test split, and on ReferItGame it achieves 58.25% test accuracy, both setting new zero-shot SOTA across all four datasets.

## Baselines & Comparisons

The paper's best configuration (GDINO-T w/ BEiT-3-vqa) outperforms all nine zero-shot baselines across every dataset and split. Against the strongest prior zero-shot method GVLP w/VinVL-vqa [49], it gains +9.6 points on RefCOCO testA (78.81 vs. 69.21), +13.4 on RefCOCO testB (62.06 vs. 48.71), +5.5 on RefCOCO+ testA (76.02 vs. 70.56), and +3.2 on RefCOCOg test (72.21 vs. 68.98). Compared to the region-text matching baseline StructSim w/CLIP [18], improvements are even larger on RefCOCO testB (+7.2) and RefCOCO+ testA (+13.5). The method also substantially surpasses the OVD-only baselines GLIP-T [29] and GDINO-T [34] used directly for REC, confirming that the code-based reasoning and debiased attention scoring add significant value beyond detection confidence alone. On ReferItGame, the method (58.25% test) beats the previous best zero-shot GDINO-T (51.20%) by over 7 points, while the prior SOTA GVLP [49] drops to only 20.11% due to its reliance on COCO category mapping.

## Relation to Prior Work

This paper synthesizes three existing research threads—VLM-based region-text matching (ReCLIP, StructSim, GVLP), GradCAM-style localization, and LLM-driven visual programming (ViperGPT, ZS3DVG)—into a unified zero-shot REC framework. It departs from prior region-text matching methods by replacing isolated proposal scoring with debiased cross-modal attention maps that preserve global image context, and from hand-crafted rule-based spatial reasoning (as in ReCLIP and StructSim) by having LLMs adaptively generate executable code for relation computation. The attention debiasing operation (log-subtraction of a visual-only bias map) is a novel contribution not present in prior GradCAM or attention-based localization work, while the code-based reasoning formulation generalizes beyond the fixed module composition used in VISPROG and ViperGPT.

## Why It Matters / Open Questions

The debiased attention map technique is simple, architecture-agnostic (validated across ALBEF, BEiT-3, TCL), and could transfer to other VLM-based localization or grounding tasks beyond REC. The code-based reasoning framework eliminates brittle hand-crafted parsers and rules, offering a more general path to spatial and relational understanding in zero-shot settings. However, the method still depends on external OVDs for proposal generation, cannot handle fine-grained spatial attributes (e.g., 'round at the bottom'), and shows notably weaker gains on ReferItGame due to out-of-COCO category distributions. Open questions include whether attention debiasing can be made more principled (beyond log-subtraction) and whether code-based reasoning can incorporate object part/component information for finer spatial discrimination.

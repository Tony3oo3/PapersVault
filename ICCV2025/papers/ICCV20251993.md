## Problem

Text-to-image models are highly sensitive to prompt phrasing and lack interpretability: when a prompt is ambiguous or casually written, the model silently produces misaligned outputs without explaining its internal understanding or knowledge gaps. Existing remedies—automatic prompt engineering, attention manipulation, or multi-turn selection—either require architectural modifications that reduce generalization or offer only coarse-grained user control (e.g., selecting among candidates rather than specifying attribute changes). No prior system unifies proactive prompt interpretation, flexible model selection, and iterative self-enhancement in a single training-free framework.

## Input / Output

The system accepts a free-form text prompt and an optional reference image, then optionally solicits user clarification responses (e.g., disambiguating 'Mustang' as car vs. horse) and post-generation feedback (e.g., 'I would like the side view'). Beyond the final generated or edited image, the pipeline emits a structured JSON Analysis Report containing extracted key elements, spatial relationships, background/composition/style descriptors, resolved ambiguities, and a refined detailed prompt, as well as per-sub-field evaluation scores (6 aesthetic + 4 alignment dimensions) with concrete improvement suggestions when regeneration is triggered.

## Method

T2I-Copilot is a training-free, three-agent pipeline built on LangGraph that orchestrates GPT-4o-mini as the reasoning MLLM around FLUX.1-dev (generation) and PowerPaint (reference-guided editing). The Input Interpreter Agent parses the prompt into a JSON Analysis Report, detects ambiguities, and resolves them either via MLLM creative filling (controlled by a LOW/MEDIUM/HIGH creativity parameter) or by querying the user; the Generation Engine Agent then selects the appropriate model based on task type (new generation vs. localized edit), reformulates the prompt for the chosen model, and invokes Referring Expression Segmentation (Grounding-SAM2) or an interactive drawing canvas for object-specific modifications; the Quality Evaluator Agent scores the output across six aesthetic and four text-image alignment sub-fields, and if the average falls below a threshold (8.0) or the user requests changes, it feeds structured improvement suggestions back to the Generation Engine for up to MAX_regen_count (3) regeneration iterations. The key design insight is that explicit LLM-based prompt structuring before generation and multi-dimensional automated evaluation after generation can close the alignment gap without any fine-tuning or architectural changes to the underlying diffusion models.

## Results

On GenAI-Bench, T2I-Copilot (LLM-only) achieves a VQAScore of 0.813 overall (0.892 basic, 0.747 advanced), and with human-in-the-loop reaches 0.839 overall (0.904 basic, 0.784 advanced). On DrawBench, the LLM-only variant scores 0.829 and the human-assisted variant scores 0.865. In the user study (2,442 votes), T2I-Copilot achieves a 94.5% win rate for text-image alignment and 77.7% for aesthetic quality. The system surpasses FLUX1.1-pro by 6.17% at only 16.59% of its cost, and outperforms FLUX.1-dev and SD 3.5 Large by 9.11% and 6.36% respectively on GenAI-Bench VQAScore.

## Baselines & Comparisons

T2I-Copilot (LLM-only) outperforms all open-source baselines on GenAI-Bench overall VQAScore, beating FLUX.1-dev (0.745) by 9.11%, SD 3.5 Large (0.764) by 6.36%, and Lumina-Image-2.0 (0.752) by 8.11%. Against proprietary models, it surpasses FLUX1.1-pro (0.786) by 6.17% at only 16.59% of the cost, and outperforms Midjourney v6 (0.772) and DALL-E 3 (0.791) by 8.22% and 6.68% respectively. On GenAI-Bench overall, T2I-Copilot (0.813) is competitive with Recraft v3 (0.811) and trails Imagen 3 v002 (0.839) by 2.6%, though the human-in-the-loop variant (0.839) matches Imagen 3 exactly. On DrawBench, the human-assisted variant (0.865) nearly matches Imagen 3 (0.866) and surpasses Recraft v3 (0.836) and FLUX1.1-pro (0.786). The agentic baseline GenArtist (0.588) is substantially outperformed, confirming the benefit of the structured three-agent pipeline over a single MLLM controller.

## Relation to Prior Work

T2I-Copilot carves new ground by repurposing existing T2I models (FLUX.1-dev for generation, PowerPaint for editing) and an MLLM (GPT-4o-mini) as a training-free orchestration layer, rather than modifying model architectures as prior work on attention-based semantic guidance (Chefer et al., Rassin et al.) or embedding optimization (Hu et al.) does. It extends the multi-turn generation line (PASTA, GenArtist, SLD) by unifying prompt interpretation, model selection, and iterative evaluation into a single pipeline, whereas prior agentic systems like GenArtist select models based solely on prompt keywords without pre-generation intent analysis, and PASTA limits user interaction to image selection rather than fine-grained refinement. The system is built on LangGraph and Grounding-SAM2 for spatial control, positioning itself as a model-agnostic middleware rather than a new generative architecture.

## Why It Matters / Open Questions

The practical value lies in providing a drop-in orchestration framework that improves any underlying T2I model without retraining, with the notable cost-efficiency result of matching proprietary models at ~16% of their inference cost. However, the ablation reveals that the Quality Evaluator (iterative regeneration loop) contributes only 0.92% versus 7.69% from the Input Interpreter, suggesting the bulk of the gain comes from structured prompt decomposition rather than the multi-turn refinement cycle that is a central architectural selling point. Open questions include whether the approach generalizes beyond the two tested generation models, whether the GPT-4o-mini dependency creates a single point of failure or cost bottleneck at scale, and whether the modest 3.17% human-in-the-loop improvement justifies the interaction overhead for production use.

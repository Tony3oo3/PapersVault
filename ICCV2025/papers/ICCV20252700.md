## Problem

Video Camouflaged Object Detection (VCOD) requires segmenting objects whose colors and textures closely mimic their background, a task where static appearance alone is insufficient. Existing video-based approaches either require multiple passes through the sequence, precomputed optical flow, or heavy external pretrained backbones (e.g., SAM), and none effectively exploit long-term memory information to guide segmentation of subsequent frames.
![Teaser figure](../imgs/ICCV20252700/cropped_page0_idx0.webp)

## Input / Output

The model consumes sequential RGB frames (512×512 during training; 352 or 512 resolution at inference) strictly in temporal order, with no access to future frames. For each frame it produces a binary foreground/background segmentation mask and a pixel-wise predicted error map (estimated MAE) of the same spatial dimensions. The error map is used internally to compute a scalar score that drives real-time reference-frame selection; for the first frame, previous and reference inputs are initialized to the frame itself with zero masks.

## Method

SRRNet is a 4-stage pyramid transformer (adapted from PVT/MiT) built around two key modules. The Reference-Guided Multilevel Asymmetric (RMA) Attention performs unidirectional cross-attention in which the reference frame queries both the current and previous frames, and the previous frame queries only the current frame, thereby fusing long-term memory cues with short-term motion information without the cost of full bidirectional attention. The Dual-Purpose Decoder simultaneously outputs the segmentation mask and a pixel-wise error score (predicted MAE) via a lightweight MLP branch; during inference, the frame with the lowest accumulated score is stored as the new reference, creating a scoring–remember–reference loop. Training uses a two-stage protocol (pretraining on COD10K static images, fine-tuning on MoCA-Mask) with a combined BCE + MSE loss, where the MSE term supervises the error map against the detached ground-truth-minus-prediction residual, providing self-generated auxiliary supervision that sharpens feature extraction without extra annotations.

## Results

On MoCA-Mask, SRRNet achieves Sα=0.727, Fβw=0.489, MAE=0.008, mDice=0.513, and mIoU=0.428, surpassing the previous best (TSP-SAM-Bbox) by 5.5% in Sα, 10.1% in Fβw, and 10.3% in mIoU. On the smaller CAD dataset, SRRNet reaches Sα=0.723, Fβw=0.541, MAE=0.025, mDice=0.553, and mIoU=0.452. The model uses only 53.79M parameters and requires a single sequential pass through the video, achieving 7.05 FPS at 512 resolution.

## Baselines & Comparisons

SRRNet outperforms all 12 baselines on MoCA-Mask across every reported metric. Against the closest competitor TSP-SAM-Bbox (CVPR'24), SRRNet gains +5.5% in Sα (0.727 vs 0.689), +10.1% in Fβw (0.489 vs 0.444), and +10.3% in mIoU (0.428 vs 0.388), while using fewer parameters (53.79M vs 725.42M total). Compared to IMEX (TMM'24), the improvement is even larger: +10.0% Sα, +31.8% Fβw, and +34.2% mIoU. On the smaller CAD dataset, SRRNet leads TSP-SAM-Bbox by +2.7% Sα and +3.2% Fβw, with more modest gains likely due to shorter video lengths limiting the memory-reference mechanism. All image-based COD methods (SINet, ZoomNet, FSPNet, etc.) trail significantly behind video-based approaches, confirming that temporal information is critical for camouflaged object detection. SRRNet also requires only a single sequential pass, whereas SLT-Net-Long needs two-stage inference, IMEX requires precomputed optical flow, and TSP-SAM depends on a frozen SAM backbone.

## Relation to Prior Work

SRRNet extends the VCOD line of work initiated by SLT-Net (implicit motion, sequence-to-sequence) and IMEX (implicit+explicit motion) by replacing external motion cues (optical flow) and multi-stage inference with a self-contained memory reference mechanism. Architecturally, it adapts the MiT encoder from SegFormer into a four-stage pyramid and draws on SimulFlow's cross-attention paradigm, extending it from optical-flow-to-image attention to a three-branch asymmetric scheme (current, previous, reference). The key conceptual departure from prior VCOD methods is the dynamic, score-driven selection of reference frames during a single sequential pass, inspired by human memory-recognition, rather than relying on first-frame ground truth (as in VOS) or post-hoc frame selection (as in UVOS).

## Why It Matters / Open Questions

The single-pass, 54M-parameter design that outperforms a 725M-parameter SAM-based model by ~10% on MoCA-Mask is practically significant for real-time deployment in wildlife monitoring or security applications where optical flow computation or large pretrained backbones are infeasible. The memory reference mechanism offers a generalizable template for exploiting long-term temporal context without multi-pass inference, potentially transferable to other video segmentation tasks lacking reliable initial references. Open questions include whether error accumulation degrades performance on longer sequences, whether the predicted error maps can be leveraged for iterative refinement, and whether the approach generalizes beyond the relatively small MoCA-Mask benchmark (87 sequences) to more diverse camouflage scenarios.

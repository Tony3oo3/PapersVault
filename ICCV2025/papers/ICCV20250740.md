## Problem

Existing scribble-based colorization methods directly predict color images, entangling image structure understanding with color propagation, which limits their ability to generalize to realistic sparse scribble inputs—especially for distant regions with similar texture. The paper addresses this by decoupling affinity learning (dependent only on the grayscale image) from color propagation (dependent on user scribbles), so that the network need not simultaneously learn both tasks.

## Input / Output

The method takes a grayscale (Y-channel) image and a set of sparse user-drawn color scribbles as input, and produces a full colorized RGB image. Training is performed at 128×128 resolution (with bilinear upsampling for final output), and the method scales to 256×256 and 512×512 with sublinear memory growth. The key design choice is that the affinity-prediction network consumes only the grayscale input and is entirely independent of the scribbles, while the scribbles enter only at the closed-form color-propagation stage.

## Method

LGA-Net replaces direct color prediction with a two-stage process: (1) a lightweight CNN (BFEnet + Non-local Block) maps each grayscale pixel to an H-dimensional feature vector, from which pairwise edge weights are computed via a Gaussian kernel, and (2) a training-free Laplacian Coloring Layer propagates scribble colors by solving a sparse linear system (M + αL + φL_adj)x = My, where L is a graph Laplacian encoding both local (8-neighbor) and global (evenly-spaced anchor points) affinities. The balancing weight α is predicted by a separate small network, and a weak adjacency regularizer φL_adj ensures the system is non-singular. The entire pipeline is trained end-to-end with a combined L1 + Laplacian pyramid + total variation loss on only 4K ImageNet images, yet outperforms methods trained on over 1M images.

## Results

On the 200-image D_manual test set (manually drawn sparse scribbles), LGA-Net trained on only 4K images achieves the best MSE (1.42×10⁻²) and PSNR (26.07 dB), outperforming the strongest baseline UC1M (trained on 1.3M ImageNet images) by 0.71 dB in PSNR. On the 3000-image D_auto set, LGA-Net again leads in MSE (0.90×10⁻²) and PSNR (29.89 dB), surpassing UC1M by 0.74 dB. In the user study (1500 votes, 50 participants), LGA-Net receives 44.6% of preference votes, nearly double the next-best method UC1M (~21.3%).

## Baselines & Comparisons

LGA-Net (4K training) beats all four baselines on MSE and PSNR across both test sets. Against the closest competitor UC1M (1.3M training), LGA-Net gains 0.71 dB PSNR on D_manual and 0.74 dB on D_auto, while UC1M retains a narrow edge in LPIPS (7.90 vs 10.49) and MS-SSIM (93.62 vs 92.78) on D_manual. The 1M-trained iC1M (Transformer-based) is outperformed by LGA-Net by 0.15 dB PSNR on D_manual and 1.14 dB on D_auto, and suffers visible artifacts under dense scribble hints. The 4K-trained versions of Zhang (Z4K) and iColoriT (iC4K) perform worst overall (PSNR 19.72 and 21.32 on D_manual), confirming their heavy reliance on large-scale training data. The classical Levin method, lacking any learned global affinity, trails LGA-Net by 4.59 dB PSNR on D_manual, with a 57% higher LPIPS, highlighting the critical role of global affinity for sparse-scribble propagation.

## Relation to Prior Work

LGA-Net builds directly on Levin et al.'s [20] graph-based optimization formulation for scribble colorization, replacing handcrafted intensity-similarity weights with neural-network-learned affinities. It departs conceptually from the dominant scribble-based paradigm (Zhang [45], iColoriT [41], UniColor [12]) that trains an end-to-end network to predict color images given grayscale input and scribble hints; instead, LGA-Net decouples the problem into (1) learning scribble-independent local and global pixel affinities from the grayscale image alone, and (2) propagating user colors via a closed-form MAP solve with a graph Laplacian regularizer. The non-local block [34] provides the global receptive field needed for long-range affinity, while the sparse linear-system solver keeps the Laplacian Coloring Layer training-free and memory-efficient.

## Why It Matters / Open Questions

The key practical implication is striking data efficiency: a model trained on 4K images matches or exceeds methods trained on 1.3M images, suggesting that explicitly modeling the propagation structure (affinities) is a more sample-efficient inductive bias than end-to-end color regression. However, the CPU-based sparse solver introduces significant training-time overhead (75 h/epoch at 512×512), and the global-affinity graph construction limits scalability to very large images. Open questions include whether the affinity-decoupling principle transfers to other propagation-based editing tasks (inpainting, relighting), and whether learned sparse solvers or GPU-native alternatives can close the efficiency gap without sacrificing the memory advantage.

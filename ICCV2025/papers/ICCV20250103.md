## Problem

Unsupervised 3D object detection relies on pseudo-labels generated by a single set of candidate boxes from motion or geometry heuristics, but these labels cannot simultaneously achieve high accuracy in both classification and regression. Stationary objects have ambiguous classes yet estimable shapes, while moving objects are separable from background but have inaccurate geometry, so directly training a detector on such labels degrades performance in both tasks.

## Input / Output

The method consumes LiDAR point clouds and synchronized RGB images (downsampled 4× before training to save GPU memory) and produces 3D bounding boxes with class labels and per-box detection confidence scores. A key structural detail is that the final student network is LiDAR-only, meaning the RGB images are used exclusively during the teacher/knowledge-discovery phase (MLE) and are not required at inference time. The method is plug-and-play: it accepts initial pseudo-labels from any existing unsupervised detector (CPD, OYSTER, DBSCAN) as its starting point.

## Method

Motal decouples pseudo-labels into two candidate sets using a Variance of Position Change (VPC) motion score: high-VPC labels seed classification, low-VPC labels seed regression. The MLE module then discovers classification knowledge via a 2D ViT-S heatmap network (inspired by CenterNet) trained with a Class Generalization Loss that converts high-confidence predictions into new positives to avoid overfitting to sparse seeds, and discovers regression knowledge via a two-stage CenterPoint detector trained with a Soft IoU Loss (squared IoU gap) and Soft IoU Scoring (lower 0.7 threshold) to prevent overfitting to noisy pseudo-label geometry. Box propagation refines stationary-object sizes and positions using temporal geometry consistency across consecutive frames. Finally, TMT transfers all knowledge to a single LiDAR-only student by computing separate indicator-function masks: the regression branch is supervised only where box confidence exceeds η_reg (0.4), and the classification branch only where heatmap confidence exceeds η_cls (0.9), so each task receives high-quality supervision without being corrupted by the other task's noisy labels.

## Results

On the WOD test set, Motal(CPD) achieves 42.10% mAP L1 and 38.08% mAP L2, improving the state-of-the-art CPD by 21.56% and 19.90% respectively. On the WOD validation set, Motal(CPD) reaches 50.85/38.93 mAP L1 (IoU 0.5/0.7) and 45.15/34.34 mAP L2 (IoU 0.5/0.7), roughly doubling CPD's 28.51/19.59 and 24.59/16.78. On KITTI val (trained on WOD), Motal(CPD) attains 96.19% 3D AP for easy cars at IoU 0.5, approaching the fully supervised CenterPoint (97.34%). The method also outperforms the weakly supervised CoIn (2% labels) by 4.63% vehicle AP L2 and 3.97% pedestrian AP L2 on WOD validation.

## Baselines & Comparisons

Motal consistently outperforms all unsupervised baselines by approximately 2× mAP. Against CPD (the strongest prior unsupervised method), Motal gains +20.56% mAP L2 on WOD validation and +19.90% on the test set, with the largest relative gains on cyclists (+26.88% mAP L2) and pedestrians (+18.78% mAP L2). Against OYSTER, the improvement is +10.93% mAP L2, and against the heuristic DBSCAN* baseline it is +10.30% mAP L2. In the motion-based comparison (Table 4), Motal achieves 58.4 BEV mAP versus LISO-CP's 25.7 and LSMOL's 13.3. Against fully supervised CenterPoint, Motal(CPD) reaches 73.54% of the vehicle AP L2 score without any annotations. Notably, Motal(CPD) surpasses the weakly supervised CoIn (2% labels) by 4.63% vehicle AP L2 and 3.97% pedestrian AP L2 on WOD validation, and outperforms the sparsely supervised baseline [37] by a wide margin (46.45% vs 28.82% vehicle AP L2). The only comparison where Motal does not lead is against fully supervised CenterPoint, where it trails by ~17% on vehicle AP L2, which is expected given zero training labels.

## Relation to Prior Work

Motal builds directly on the pseudo-label-based unsupervised 3D detection paradigm established by MODEST, OYSTER, and CPD, all of which generate a single set of candidate boxes (via motion or temporal-geometry heuristics) to jointly supervise classification and regression. The key departure is the decoupling of these two tasks into modality-specific knowledge streams: a 2D ViT heatmap network (inspired by CenterNet) discovers classification knowledge from image appearance, while a LiDAR-based CenterPoint detector discovers regression knowledge from point-cloud geometry. The Task-specific Masked Training (TMT) scheme further distinguishes Motal from prior multi-modal knowledge transfer work (SOCKET, X-Trans2Cap, CMKD), which assumed clean source-domain annotations, by explicitly masking low-quality pseudo-labels per task to prevent error propagation during self-training.

## Why It Matters / Open Questions

The plug-and-play design that boosts any existing unsupervised baseline by roughly 2× mAP makes Motal a practical tool for the autonomous-driving community seeking to reduce annotation costs, and the fact that it outperforms weakly supervised detectors using 2% labels on WOD underscores the value of modality-specific knowledge discovery. A notable limitation is the persistent gap to fully supervised performance (e.g., 46.45% vs. 63.16% vehicle AP L2) and the acknowledged weakness on small objects where few valid seed labels exist. Open questions include whether the modality-decoupling principle generalizes to other sensor combinations (e.g., radar, event cameras) and whether iterative self-training beyond the single teacher-student round could close the remaining gap to supervised detection.

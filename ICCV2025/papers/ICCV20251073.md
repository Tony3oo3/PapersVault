## Problem

Evaluating VLM responses to open-ended visual queries requires verifying multiple visual claims within free-form text, yet existing benchmarks either restrict to binary existence questions that don't reflect real usage or rely on LLM-as-judge with insufficient image context, leading to inconsistent scoring and false penalization of correct but additional information. There is no reliable, interpretable method to jointly measure both helpfulness and truthfulness of VLM responses at scale.

## Input / Output

The evaluation pipeline takes an RGB image, an open-ended question, and a VLM's free-form text response. It extracts Davidsonian Scene Graph tuples (entity, attribute, relationship) from both the response and the ground-truth answer using LLaMA-3.1-Instruct with in-context prompting, then computes two scalar scores: hscore (recall of response tuples against the question-refined ground-truth graph) and tscore (precision of response tuples against the full caption scene graph plus Grounding DINO visual entailment). A cosine-similarity threshold of θ=0.75 in Sentence-BERT embedding space determines tuple matches, and the benchmark itself comprises 10.6k QA pairs with average question length 10.3 words and answer length 13.4 words.

## Method

PROVE introduces a generate-then-verify pipeline for constructing a benchmark of programmatically verifiable open-ended visual QA pairs. From DOCCI hyper-detailed captions (avg. 136 words), high-fidelity scene graphs are built (avg. 40.9 tuples/image), and GPT-4o is prompted with a minified scene-graph API to generate 10–15 challenging QA pairs per image along with Python verification programs that query the scene graph. Only QA pairs whose programs execute successfully and return the correct answer are retained, yielding 10.6k grounded examples after ~50% text-based filtering. At evaluation time, the VLM response and ground-truth answer are each converted to scene graphs, and helpfulness is measured as tuple-level recall (with question-premise exclusion via set differencing) while truthfulness is measured as tuple-level precision against both the caption scene graph and the image itself via Grounding DINO visual entailment, replacing subjective LLM judgment with a deterministic, interpretable scoring rubric.

## Results

On the PROVE benchmark (10.6k open-ended visual QA pairs), GPT-4o achieves the highest helpfulness score (hscore = 57.89) and best average (71.81), while LLaVA-1.5 (7B) achieves the highest truthfulness score (tscore = 87.33). The paper reveals a concerning trade-off: only GPT-4o strikes a reasonable balance between both metrics, and the linear correlation between hscore and tscore across models is a mere 0.1, indicating that recent gains in model helpfulness have not translated to improved truthfulness. In human evaluation, PROVE's automated metrics correlate substantially better with human judgment (Pearson r = 0.81 for helpfulness, 0.57 for truthfulness) than LLM-as-judge baselines (GPT-4o-mini: 0.58/0.30; Prometheus-2: 0.57/0.32).

## Baselines & Comparisons

GPT-4o dominates on helpfulness, outperforming the next-best model InternVL2 (26B) by 3.25 points in hscore (57.89 vs. 54.64) and leading by 2.57 points in average score. However, LLaVA-1.5 (7B) achieves the highest truthfulness (tscore = 87.33), surpassing GPT-4o by 1.59 points, demonstrating that the most helpful model is not the most truthful. Scaling within model families (e.g., InternVL2 from 2B to 26B) consistently improves hscore but degrades tscore (83.67 → 82.24), confirming that larger models hallucinate more. In fine-grained analysis, GPT-4o outperforms LLaVA-1.5 (7B) by 7.13 and 7.85 percentage points on hscore for query and describe questions respectively, but trails by 1.0 and 2.61 points on tscore for the same splits. For evaluation methodology, PROVE's scene-graph-based metrics outperform all LLM-as-judge baselines: GPT-4o-mini (r = 0.58/0.30), LLaMA-3.1-8B (r = 0.41/0.20), and Prometheus-2 (r = 0.57/0.32) all show substantially lower Pearson correlation with human judgments than PROVE's 0.81/0.57.

## Relation to Prior Work

PROVE builds on the Davidsonian Scene Graph (DSG) representation for structured image understanding and the visual programming paradigm (ViperGPT, Visual Programming) for executing verification code over scene graphs. It departs from prior VLM hallucination benchmarks in two key ways: (1) instead of relying on LLM-as-judge scoring with incomplete image context, it generates QA pairs *alongside* executable verification programs and retains only programmatically verifiable pairs, and (2) instead of binary existence queries (POPE, NOPE) or templated Wh-questions (FIHA, DSG), it uses LLMs to generate diverse open-ended questions that simulate in-the-wild usage. The evaluation itself replaces subjective LLM scoring with scene-graph-based precision (truthfulness) and recall (helpfulness), providing an interpretable and auditable alternative.

## Why It Matters / Open Questions

The central finding — a near-zero (0.1) correlation between helpfulness and truthfulness across 12 VLMs, with the best truthfulness scores achieved by the simplest model (LLaVA-1.5) rather than the largest — challenges the assumption that aggregate benchmark improvements translate to more reliable VLMs. This has direct implications for model selection in high-stakes deployments where hallucination is unacceptable. Key limitations include the high-precision filtering that sacrifices recall (excluding hard-to-verify questions), dependence on potentially imperfect external models (Grounding DINO, Sentence-BERT) for subtasks, and the fact that even hyper-detailed captions cannot capture every image detail. Open questions include whether hallucination-mitigation strategies (contrastive decoding, preference optimization) can close the helpfulness-truthfulness gap on PROVE, and whether agentic approaches with planning and self-reflection can improve both metrics simultaneously.

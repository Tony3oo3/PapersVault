## Problem

Existing outfit recommendation systems focus on compatibility prediction or complementary item retrieval, with outfit items determined by pre-trained models rather than user-specified text prompts. Prior text-to-image retrieval approaches (e.g., GILL, FROMAGe) are designed for single-image retrieval and do not handle the multi-item, multi-category structure of outfits, leaving a gap in controllable, text-driven outfit generation.
![Teaser figure](../imgs/ICCV20251654/cropped_page0_idx0.webp)

## Input / Output

The framework accepts a free-form text prompt specifying outfit-level attributes (occasion, season) and item-level features (color, product descriptions) for text-to-outfit generation, or a seed item (image or text) plus a global outfit prompt for seed-to-outfit generation. It outputs a set of retrieved outfit item images (one per predicted category) and, in the seed-to-outfit setting, a predicted outfit composition (high-level and fine-grained category combination). The model uses 11 learnable image tokens corresponding to high-level categories (tops, bottoms, all-body, outerwear, shoes, bags, jewelry, accessories, sunglasses, hats, scarves), and item features are extracted via Fashion-CLIP 2.0 embeddings over both image and text.

## Method

The core architecture fine-tunes an OPT-6.7B LLM with LoRA (rank 64) to map text prompts to a set of category-specific retrieval embeddings, where each of 11 learnable image tokens produces a hidden state that is projected through a category-specific MLP head. A key technical contribution is an attention masking mechanism in the LLM's self-attention layers, trained with a binary cross-entropy mask loss, that prevents image tokens from attending to text descriptions of other categories (e.g., the top token should not attend to shoe descriptions). Training is end-to-end with three combined losses: an InfoNCE-based outfit retrieval loss for feature matching, the mask loss for cross-modal alignment, and a compatibility loss that maximizes a frozen OutfitTransformer score over the predicted embeddings. For seed-to-outfit generation, two additional MLP heads predict high-level and fine-grained outfit compositions via cross-entropy, enabling the model to select appropriate categories (e.g., excluding coats for summer) before retrieval.

## Results

On the Polyvore dataset, Text2Outfit with a fixed mask achieves 92.56% average P@10 for feature matching (color, product feature, season, occasion) and 82.51 compatibility score, while the learnable mask variant achieves 90.05% average P@10 and 84.05 compatibility score. The best single-item retrieval baseline (Fashion-CLIP, text-only) reaches 87.05% average P@10, and the closest outfit-level baseline (GILL + multiple categories) achieves only 63.23% average P@10. For seed-to-outfit generation, the method achieves 94% and 92% composition win rates (vs. Claude-3 evaluation) for seed-text and seed-image inputs respectively, with compatibility scores of 86.18 and 83.36.

## Baselines & Comparisons

Text2Outfit (fixed mask) outperforms the strongest single-item retrieval baseline, Fashion-CLIP (text-only, 87.05% avg P@10), by 5.51 points on average feature-matching precision, and surpasses GILL + multiple categories (63.23%) by 29.33 points. On compatibility score, the learnable mask variant (84.05) beats all baselines, including GILL + multi-category (74.26) by 9.79 points, while the fixed mask variant (82.51) also exceeds GILL by 8.25 points. Notably, the single-item retrieval baselines (CLIP, Fashion-CLIP, BLIP-2) are given the text-to-category correspondence as input, whereas Text2Outfit does not receive this information, making the comparison favorable to the baselines on feature matching. GILL + multi-category suffers a severe alignment problem (48.19% color P@10), which the paper attributes to the lack of an attention masking mechanism. For seed-to-outfit generation, Text2Outfit achieves 94%/92% composition win rates over the all-categories baseline, with compatibility scores of 86.18/83.36 vs. 80.82/72.88.

## Relation to Prior Work

This paper extends the LLM-based image token retrieval paradigm from GILL/FROMAGe (which retrieves single images) to multi-item outfit retrieval, where a set of category-specific image tokens must each attend to the correct portion of a multi-item text prompt. It departs from prior outfit recommendation work (compatibility prediction, fill-in-the-blank, complementary item retrieval) by making the entire outfit generation process text-controllable rather than relying on pre-trained compatibility models to select items. The attention masking mechanism for aligning text descriptions to category-specific image tokens is a novel architectural contribution not present in either the single-image retrieval or outfit recommendation literatures.

## Why It Matters / Open Questions

This is the first framework to unify text-controllable outfit generation with composition prediction, addressing a practical gap in fashion e-commerce where users want to specify desired attributes and receive a complete, compatible outfit. Key limitations include reliance on a single dataset (Polyvore), dependence on Claude-3 for both attribute annotation and evaluation (circularity concern), and the observation that the oracle fixed mask outperforms the learnable mask, suggesting the alignment problem may be more tractable with explicit category labels. Open questions include scalability to large product catalogs, handling multiple seed items, and whether the approach generalizes beyond the 11-category Polyvore taxonomy to more diverse retail settings.

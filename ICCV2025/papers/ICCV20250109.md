## Problem

Existing human motion synthesis works handle individual characters or a single type of interaction (human-scene or human-human), making them unable to concurrently generate plausible multi-character behaviors in crowded 3D scenes. Correctly assigning each character's behavior at the right time requires holistic spatio-temporal reasoning over dynamic human-human and human-scene relationships, a problem not previously addressed at scale.

## Input / Output

The framework takes a 3D scene with instance segmentation (CAD-based VR scenes or real-world point cloud/mesh reconstructions), a user-specified number of characters N, and optional free-text instructions as input. It produces temporally coordinated 3D motions for all N characters, where each character follows a collision-free trajectory to a target position and performs a designated action. The system operates online with infinitely long-horizon generation, and user instructions can be injected at any point to redirect the storyline.

## Method

The core contribution is an event-driven LLM planning pipeline that decomposes holistic multi-agent reasoning into a cascade of smaller subproblems. A scene describer converts a 3D scene graph (augmented with DBSCAN-based regional clustering for functional spaces) into a compact textual description; a narrator generates one semi-narrative event at a time, tracking ongoing/completed states; and an event parser uses a Python programming structure with spatial reasoning tools (e.g., get_distance_between) to resolve ambiguous locations into precise 3D coordinates via area-conditioned position sampling. This last step defines positions by their semantic relationship to anchor objects and samples coordinates within the corresponding region, compensating for LLMs' known weakness in numerical localization. The low-level motion synthesis module then plans collision-free paths with windowed cooperative A* and generates actions via motion matching, with group events requiring temporal synchronization across characters.

## Results

On the position inference (PI) benchmark, the proposed area-conditioned position sampling achieves success rates of 0.86–1.0 across all six LLM backbones (GPT-4o, GPT-4o mini, Llama-3.1-70B/8B, Qwen2.5-72B/7B), compared to 0.10–0.46 for direct coordinate inference by the LLMs. On the broader scene-aware planning benchmark (40 test cases covering object arrangement, regional context, and scene state reasoning), the full event-driven pipeline achieves the highest overall success rate across model sizes, with the largest gains in scene state reasoning (SS) under GPT-4o. The scalability analysis shows that the performance gap between the full method and the no-event ablation widens as the number of characters increases, while the full method maintains stable success rates.

## Baselines & Comparisons

The paper explicitly states that no existing baseline addresses multi-agent scene-aware behavior planning at this scale, so all comparisons are ablations of the proposed pipeline. Against the no-event ablation (w/o Event, which uses a single unified LLM module), the full event-driven pipeline shows consistent improvements, with the largest gains in scene state reasoning (SS) under GPT-4o and growing advantages as character count increases (Figure 7). Against the Object List scene description, the proposed scene describer substantially outperforms on RC (regional context) tasks—e.g., 0.51 vs. 0.28 success rate under GPT-4o—because the object list lacks spatial relationships. Against the raw Scene Graph description, the proposed method achieves comparable or better success rates while consuming significantly fewer tokens (Figure 8), as the scene graph's exhaustive detail interferes with LLM reasoning. For position inference, the area-conditioned sampling approach outperforms direct LLM coordinate output by 48–86 percentage points across all models, confirming that LLMs are unreliable at precise numerical localization.

## Relation to Prior Work

This paper extends contextual human motion synthesis from single-interaction-type or two-person settings to multi-character (4–5+) scene-aware behavior planning, leveraging LLMs as the high-level planner. It builds on SceneVerse [17] for automated 3D scene graph extraction, windowed cooperative A* [33] for collision-free multi-agent pathfinding, and motion matching [6] for low-level motion generation, but departs from prior LLM-planning works (CoELA, SMART-LLM, Voyager) by introducing an event-driven decomposition that isolates each planning step to a small subset of characters and objects, reducing the holistic spatio-temporal reasoning burden. The area-conditioned position sampling technique is a practical departure from prior LLM grounding approaches that rely on direct coordinate output, instead anchoring positions semantically to scene objects and sampling within defined regions.

## Why It Matters / Open Questions

This is the first benchmark specifically designed for scene-aware multi-agent behavior planning, providing evaluation criteria (object arrangement, regional context, scene state, position inference) that the field previously lacked for assessing LLM-driven character coordination. The framework's modular design and demonstrated robustness across LLM backbones (GPT-4o, Llama-3.1, Qwen2.5) make it a practical reference for building interactive virtual scenes in VR, games, and film. Open questions include scaling to even larger character counts, reducing dependence on pre-segmented scene graphs, and replacing the motion-matching action vocabulary with more expressive generative motion models to handle open-ended interactions.

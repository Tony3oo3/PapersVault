## Problem

Existing LLM-based 3D scene understanding methods that use learnable scene representations rely solely on geometric information such as object coordinates, overlooking the rich semantic relationships between objects (e.g., 'on', 'next to', 'larger than'). This limits the model's expressiveness and reasoning capability for tasks like object grounding, scene captioning, and visual question answering where relational context is critical.
![Teaser figure](../imgs/ICCV20250188/cropped_page0_idx0.webp)

## Input / Output

The method takes 3D point clouds of scene objects (from ground-truth or predicted instance segmentation via Mask3D/OneFormer3D), multi-view 2D images for DINOv2 feature extraction, and a natural language query as input. The scene is flattened into a compact sequence of object subgraphs (k=2 nearest neighbors each, with NMS and 1 cm minimum-distance filters), yielding ~800 tokens for 100 objects versus ~29,900 for a complete graph. Outputs are object identifier tokens for grounding, free-text scene captions, or text answers, all generated autoregressively by the LLM.

## Method

3DGraphLLM constructs a learnable 3D scene graph where each object is represented by an identifier token, a 2D DINOv2 feature, a 3D Uni3D feature, and k triplets (F_i^v, F_ij^e, F_j^v) encoding its relationships with k nearest neighbors. Semantic edge features are extracted from VL-SAT's latent GNN representations (before the classification head), capturing non-mutually-exclusive relationship combinations, and projected into the LLM's embedding space via trainable 3-layer MLPs alongside the 2D/3D object projections. The LLM (LLaMA3-8B-Instruct or Vicuna-7B) is fine-tuned with LoRA (rank 16) using a two-stage strategy: first pre-training on ground-truth instance segmentation to learn high-quality semantic projections, then fine-tuning on noisy predicted segmentation. This object-centric triplet representation is the first to map semantic scene graph edges directly into an LLM's token embedding space, enabling the model to reason about relational context during generation.

## Results

3DGraphLLM with LLAMA3-8B-Instruct achieves 56.6% Acc@0.5 on ScanRefer and 59.9% F1@0.5 on Multi3DRefer, outperforming the Chat-Scene baseline (Vicuna-7B) by +6.4% and +7.5% respectively. On Scan2Cap, it reaches 81.0 CIDEr@0.5 (+3.9% over baseline), and on ScanQA it scores 88.8 CIDEr (+1.1%). The method also achieves 55.9% EM on SQA3D. Inference speed is up to 5× faster than GPT4Scene (0.4s vs 1.9s per query on ScanRefer) due to using only 800 input tokens per scene versus 10,400.

## Baselines & Comparisons

Against the direct baseline Chat-Scene (same Vicuna-7B backbone), 3DGraphLLM improves ScanRefer Acc@0.5 from 50.2 to 53.0 (+2.8) and Multi3DRefer F1@0.5 from 52.4 to 57.3 (+4.9), with the gap widening to +6.4 and +7.5 when using LLAMA3-8B. Compared to Robin3D (Vicuna-7B), 3DGraphLLM with LLAMA3-8B wins on ScanRefer (56.6 vs 55.1) and Multi3DRefer (59.9 vs 59.7) but trails slightly on SQA3D (55.9 vs 56.0); notably Robin3D is trained on 1M instruction-following samples versus 370K for 3DGraphLLM. Against GPT4Scene-HDM (Qwen2-VL-7B), 3DGraphLLM is competitive on grounding (56.6 vs 57.0 on ScanRefer, 59.9 vs 59.8 on Multi3DRefer) but lags on captioning (81.0 vs 86.3 CIDEr) and QA (88.8 vs 96.3 CIDEr on ScanQA), while using 5× fewer input tokens and achieving 5× faster inference. Among expert models with task-specific heads, 3DGraphLLM (LLAMA3) surpasses 3D-VisTA (45.8) and PQ3D (51.2) on ScanRefer Acc@0.5, and exceeds PQ3D on Multi3DRefer (59.9 vs 50.1). The ablation (Table 4) confirms that the semantic edge features from VL-SAT are the primary driver of the grounding gains, with the k=2 nearest-neighbor subgraph contributing +2.1 Acc@0.5 over the zero-edge variant on LLAMA3-8B.

## Relation to Prior Work

This paper extends Chat-Scene [25], which introduced learnable object identifier tokens to bridge 3D scenes and LLMs, by augmenting the flat object list with semantic relationship edges extracted via VL-SAT. It departs from prior LLM-based 3D scene understanding methods (3D-LLM, Chat-3D v2, LLA3D, Grounded 3D-LLM) that encode only geometric information such as object coordinates or depth maps, arguing that the rich semantic relationships between objects are underutilized. The approach also draws on the robotics scene-graph literature (OVSG, 3DGraphQA, FFL-3DOG) but repurposes graph structure as a compact, learnable input to a general-purpose LLM rather than as a task-specific retrieval or reasoning mechanism.

## Why It Matters / Open Questions

The key practical contribution is a 5× reduction in inference tokens (800 vs. 10,400 for GPT4Scene) while matching or exceeding state-of-the-art grounding accuracy, making LLM-based 3D scene understanding feasible in near-real-time robotic settings. The ablation confirming that even two semantic edges per object yield substantial gains (+7.5% F1@0.5 on Multi3DRefer) over a coordinate-only baseline validates the hypothesis that relational semantics are a first-class signal for grounding. Open questions remain around scaling edge count without proportional token blowup, and making the VL-SAT relation encoder robust to noisy predicted segmentations without the two-stage GT-then-noisy training pipeline.

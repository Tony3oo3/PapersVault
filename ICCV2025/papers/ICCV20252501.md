## Problem

Video class-incremental learning (VCIL) faces a fundamental trade-off: storing temporally dense samples in episodic memory preserves temporal information needed for action recognition but is memory-inefficient, while storing temporally sparse samples saves memory but degrades performance due to insufficient temporal context. No existing method achieves a strong balance between memory-efficiency and accuracy across diverse VCIL benchmarks.
![Teaser figure](../imgs/ICCV20252501/cropped_page1_idx1.webp)

## Input / Output

The method takes a video clip of L uniformly sampled frames as input, processed by a frozen visual encoder (ViT or CLIP) to produce frame-level CLS-token features of dimension d. During incremental training, a learnable temporal encoder aggregates these into a clip-level vector for classification. During rehearsal, only l << L temporally sparse frame features per sample are stored in episodic memory, and the MR module reconstructs full L-frame dense features from these sparse inputs plus a task-level semantic prompt before feeding them to the temporal encoder.

## Method

ESSENTIAL introduces a Memory Retrieval (MR) module that retrieves temporally dense features from temporally sparse features via multi-head cross-attention, where a learnable semantic prompt (shared across all samples in a task) serves as the query and the sparse features serve as key and value, followed by a feed-forward network with residual connections. The MR module is trained with two matching losses: a static matching loss (frame-level L2 between retrieved and original dense features) and a temporal matching loss (clip-level L2 between features extracted from retrieved vs. original dense features), jointly optimized with the standard cross-entropy classification loss. A dedicated MR module is maintained per task to prevent the retrieval capability itself from suffering catastrophic forgetting. During rehearsal, the frozen MR module reconstructs dense features from stored sparse features, enabling effective rehearsal training with only a fraction of the memory required by temporally dense storage.

## Results

On the TCD benchmark, ESSENTIAL(CLIP) achieves 95.1% average incremental accuracy on UCF-101 (10×5 tasks), 65.7% on HMDB51 (5×5 tasks), and 48.9% on SSV2 (10×9 tasks), while using only 3.1M, 1.6M, and 8.4M of memory respectively. On the vCLIMB benchmark, ESSENTIAL(CLIP) reaches 77.3% average accuracy on ActivityNet (10 tasks) and 95.8% on UCF-101 (10 tasks) with just 37.7M and 9.7M of memory. ESSENTIAL achieves the best performance in 5 out of 7 TCD settings, with the exception being SSV2 where STSP(TSM) achieves higher accuracy (69.7%) but at ~67.9× the memory cost.

## Baselines & Comparisons

ESSENTIAL(CLIP) decisively outperforms ST-Prompt(CLIP) on UCF-101 by ~10 points (95.1% vs 84.8% on 10×5) and on HMDB51 by ~5 points (65.7% vs 60.5% on 5×5), while using less than 6% of the memory (3.1M vs 80.5M). Against rehearsal-based baselines like iCaRL, UCIR, L2P, and TCD (all ViT), ESSENTIAL(CLIP) leads by 10–25 points on UCF-101 and 15–25 points on HMDB51, with 300× less memory. On SSV2, STSP(TSM) achieves substantially higher accuracy (69.7% vs 48.9% on 10×9), but at ~67.9× the memory cost (570M vs 8.4M), making ESSENTIAL the superior choice when memory efficiency matters. On the vCLIMB benchmark, ESSENTIAL(CLIP) surpasses PIVOT(CLIP) on ActivityNet (77.3% vs 73.8%) with 29,000× less memory (37.7M vs 1.1T), and outperforms SMILE+BiC on Kinetics-400 (58.8% vs 52.2%) with 470× less memory. Overall, ESSENTIAL wins 5 of 7 TCD settings and all 6 vCLIMB settings, with the sole losses on SSV2 attributable to STSP's much larger memory budget.

## Relation to Prior Work

This paper sits at the intersection of rehearsal-based video CIL (TCD, FrameMaker) and prompt-based video CIL (ST-Prompt, PIVOT), but departs from both by decoupling what is stored from what is used during rehearsal. Prior rehearsal methods store temporally dense features to preserve temporal context at the cost of large memory, while sparse-storage methods (SMILE, FrameMaker) sacrifice performance. ESSENTIAL repurposes the learnable prompt paradigm from image CIL (L2P, DualPrompt) for a new role: not as a classifier adapter but as a semantic memory that, combined with cross-attention, reconstructs temporally dense features from sparse ones. The cognitive-science framing of episodic + semantic memory integration provides a conceptual justification for why a single shared prompt per task can supply the missing temporal information.

## Why It Matters / Open Questions

The dramatic memory reduction (e.g., ~375× less on UCF-101 TCD while improving accuracy) directly addresses scalability, privacy, and legal constraints that make dense rehearsal impractical in deployment. The MR module's ability to retrieve dense features from a handful of sparse frames plus a lightweight prompt suggests a general principle: temporal detail need not be stored explicitly if a compact semantic prior can reconstruct it. Open questions include whether the approach extends to very long video sequences, to audio-visual or multi-modal incremental settings, and whether the per-task MR module overhead becomes prohibitive in long task sequences. The paper does not explore online or few-shot variants of VCIL, which remain important practical scenarios.

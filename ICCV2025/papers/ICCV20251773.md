## Problem

Existing event-based video deblurring methods rely on CNNs with limited receptive fields or Transformers with quadratic complexity, making it difficult to model the long-range spatiotemporal motion information contained in event streams efficiently. Additionally, all existing real-world event-frame paired datasets use a single fixed exposure time ratio, failing to reflect the diverse blur conditions encountered in practice.

## Input / Output

The method takes T consecutive blurry RGB frames (T ∈ {3, 7, 11, 15}) and their corresponding event streams, which are converted into event voxels at 1024×768 resolution, and outputs T reconstructed sharp frames. A key practical advantage is that memory usage scales linearly with both temporal window length and spatial resolution, enabling longer sequences and larger inputs under fixed GPU memory (e.g., 3090) compared to attention-based alternatives. The T-RED dataset provides paired data at two exposure time ratios (1:3 and 1:9) to cover a broader range of blur severities.

## Method

EVDM comprises three Mamba-based modules operating on a dual-branch (event + image) architecture. MCEM flattens event features in temporal-first order and applies BiMamba to extract long-range motion clues, supplemented by a multi-scale convolution feedforward network (MSCFFN) and an event self-reconstruction loss that constrains the network to preserve structural details lost by Mamba's scanning. MIFM introduces a Motion-aware State Space (MSS) where the output projection matrix C is modulated by motion features via 3D convolutions, enabling the model to prioritize blurred regions during intra-frame cross-modal fusion at linear complexity. ITPM applies the same MSS across all T frames simultaneously (eliminating sliding temporal windows) to achieve global inter-frame information exchange, followed by deformable convolution for spatial alignment. The overall design leverages Mamba's global receptive field with approximately linear complexity to handle long temporal windows and high-resolution inputs that would be infeasible with attention mechanisms.

## Results

EVDM achieves state-of-the-art performance across all three datasets: 36.99 dB PSNR / 0.972 SSIM on GoPro, 31.64 dB / 0.934 on EVRB, and 29.99 dB / 0.914 on T-RED (using 3 input frames). Compared to the strongest event-guided video deblurring baseline CMTA-5, EVDM gains +0.44 dB on GoPro and +0.26 dB on EVRB. Against the best non-event video deblurring method BSSTNet, the improvement is +1.01 dB on GoPro. The model uses 11.7M parameters and 17.92T FLOPs (for 5 clips at 1024×768), comparable to or lower than several baselines.

## Baselines & Comparisons

EVDM outperforms all 10 baselines on every dataset where results are reported. Against the strongest event-guided video deblurring method CMTA-5 [22], EVDM gains +0.44 dB PSNR on GoPro (36.99 vs 36.55) and +0.26 dB on EVRB (31.64 vs 31.38), while also achieving the best SSIM on EVRB (0.934 vs 0.927). Compared to the best non-event video deblurring method BSSTNet [60], the improvement is +1.01 dB on GoPro and +0.75 dB on EVRB, demonstrating the value of event data. On the real-world T-RED dataset, EVDM surpasses the next-best event-guided method MAENet [48] by +0.96 dB (29.99 vs 29.03) and EFNet [46] by +1.02 dB (29.99 vs 28.97). Among image-based Mamba methods, EVDM exceeds EVSSM [25] by +2.49 dB on GoPro, highlighting the benefit of multi-frame and event information. Notably, EVDM achieves these gains with 11.7M parameters and 17.92T FLOPs, which is lower than BSSTNet (35.6M, 46.52T) and Mambair (16.4M, 128.79T), confirming the efficiency advantage of the Mamba-based architecture.

## Relation to Prior Work

This paper positions Mamba's selective state-space model as a middle ground between CNN-based event deblurring (limited local receptive field) and Transformer-based approaches (quadratic complexity), applying it specifically to the event-guided video deblurring task. It builds directly on Mamba [11] and BiMamba [66] for the core scanning mechanism, while the Motion-aware State Space (MSS) is a novel adaptation that injects motion features into the output projection (C matrix) to guide cross-modal fusion. The T-RED dataset extends prior real-world event deblurring benchmarks (EFNet [46], CMTA [22]) by introducing varying exposure time ratios via dual beam-splitter hardware, addressing a limitation the authors identify across all existing paired datasets.

## Why It Matters / Open Questions

The linear-complexity Mamba backbone enables processing longer temporal windows and larger spatial inputs under fixed GPU memory (Fig. 1), which is practically important for real-time or high-resolution deployment of event-guided deblurring. The T-RED dataset with two exposure ratios (1:3 and 1:9) at 1024×768 resolution provides a more realistic evaluation setting that existing fixed-ratio datasets cannot offer. Open questions include whether the event self-reconstruction loss generalizes to other Mamba-based restoration tasks, and whether the MSS mechanism can be extended to other cross-modal fusion problems beyond deblurring. The 0.44–0.96 dB gains over prior SOTA are solid but the field would benefit from testing at even longer temporal windows where Mamba's advantage should be most pronounced.

## Problem

Existing visual in-context learning approaches handle a single task per context, but real-world medical imaging pipelines require chaining multiple interdependent operations (e.g., denoise → rotate → segment) with one model. No prior work trains in-context learners on sequences of compositional tasks, and it remains unclear whether codebook-based token spaces can faithfully represent the diverse outputs such sequences demand.
![Teaser figure](../imgs/ICCV20251923/cropped_page0_idx0.webp)

## Input / Output

The model receives a context set C of n example sequences (each containing t images showing input→output relations for a task chain) and a single query image Q, all as 200×200 RGB images. It must produce a sequence of (t−1) intermediate output images O, one per task step in the chain. In token space, the full CQO sequence is bounded to 30 images (4,320 tokens at 144 tokens/image), and the context must contain all semantic classes present in the output to keep the task well-posed.

## Method

The paper introduces a synthetic compositional task generation engine that enriches 38 medical segmentation datasets with generative tasks (denoising, inpainting, super-resolution, color jitter, inversion, brightness), geometric transformations (flip, rotation), and discriminative tasks (segmentation, edges, bounding boxes, skeletons, points), then samples task sequences under a strict {generative}→{transformation}→{discriminative} structure with class sub-sampling and random recoloring guardrails. A VQ-GAN codebook is fine-tuned on both images and task outputs with data balancing and color-remapping augmentation to raise the reconstruction upper bound for discriminative outputs. The in-context learner is a 195M-parameter GPT-2 transformer trained via masked token prediction, where the optimal strategy (sequence-token masking) replaces all output-sequence tokens with random ones, forcing the model to learn long-range dependencies between context and output. Special ⟨i-END⟩ and ⟨c-END⟩ tokens (k=2) mark image and context-element boundaries, and training runs for 52 epochs on 222K synthetic compositional tasks.

## Results

The best configuration (sequence-token masking with k=2 END tokens, trained for 52 epochs) achieves 20.53 PSNR on denoising, 0.0169 MSE on rotation, and 61.21% IoU on segmentation, substantially outperforming the copy baseline (11.81 PSNR denoising, 0.0802 MSE rotation, 50.79% IoU). However, a significant gap remains to the upper codebook bound (22.53 PSNR denoising, 0.0098 MSE rotation, 86.72% IoU segmentation), indicating the in-context learner captures only ~70% of the codebook's representational capacity. Discriminative tasks (boxes, points, skeletons, edges) remain the weakest, with F-1 scores of 49.55–65.92% versus codebook bounds of 60.21–85.33%.

## Baselines & Comparisons

The paper does not compare against external in-context learning methods but instead ablates internal training strategies against two reference points: a copy baseline (predicting context samples) and the upper codebook bound (perfect token reconstruction). Sequence-token masking (masking all output tokens) is the clear winner over random token masking (15%) and image-token masking (5 images), improving denoising PSNR from 9.69 to 20.13 and segmentation IoU from 26.49% to 52.60%. The copy baseline already achieves 50.79% segmentation IoU and 63.49% box F-1, meaning the in-context learner must surpass simple context copying to be useful; the best model does so on segmentation (61.21% vs. 50.79%) but only marginally on boxes (65.92% vs. 63.49%). Random token masking performs worst across all metrics, even below the copy baseline on most tasks, confirming that local token-level reconstruction does not capture the long-range context-to-output dependencies needed for compositional tasks. The persistent gap to the codebook upper bound (e.g., 61.21% vs. 86.72% IoU) highlights that the transformer fails to fully exploit the codebook's representational capacity, particularly for fine-grained discriminative structures.

## Relation to Prior Work

This paper extends the sequential masked-token-prediction paradigm for visual in-context learning (Bai et al., 2023) from single-task settings to compositional task sequences, where the context encodes multiple interdependent tasks and the output is a sequence of intermediate results. It builds on VQ-GAN (Esser et al., 2021) as the codebook backbone but introduces task-informed codebook training with color remapping augmentation to better represent discriminative outputs like segmentation maps. The synthetic compositional task generation engine, which bootstraps diverse task sequences from existing segmentation datasets, is a novel data-centric contribution that departs from prior work relying on large heaps of naturally occurring task examples.

## Why It Matters / Open Questions

The paper opens a pathway toward flexible, user-defined medical imaging pipelines where a single model handles arbitrary sequences of processing steps at test time, with interpretable intermediate outputs. However, the results remain far from the codebook upper bounds (e.g., 52.6% vs. 86.7% segmentation IoU), and the models struggle significantly with fine-grained discriminative structures like edges, boxes, and skeletons. Key open questions include whether better codebooks or training objectives can close this gap, whether the approach generalizes to genuinely novel task distributions at test time, and whether the synthetic task generation strategy transfers to non-segmentation medical tasks.

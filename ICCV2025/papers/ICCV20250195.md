## Problem

Existing 3D visual grounding methods treat object attributes and spatial relationships in isolation, lacking a mechanism to systematically leverage the sequential attribute-to-location reasoning that humans naturally employ. Additionally, Transformer-based approaches suffer from quadratic self-attention complexity, limiting their ability to model long-range dependencies among multiple objects with shared attributes in complex scenes.
![Teaser figure](../imgs/ICCV20250195/cropped_page0_idx0.webp)

## Input / Output

The method takes a 3D point cloud scene and a natural language query as input. A pre-trained PointGroup detector generates n proposal boxes with 32-d features, each rendered as m multi-view images encoded by CLIP into d-dimensional patch features; the query is encoded into a d-dimensional text vector via CLIP. The output is a set of localized 3D bounding boxes with per-object confidence scores, supporting quantity-agnostic grounding (zero, one, or multiple target objects) evaluated by IoU-based accuracy or F1@0.5.

## Method

VGMamba introduces a three-stage attribute-to-location reasoning pipeline built entirely on Mamba (selective state-space) blocks for linear-complexity sequence modeling. First, the SVD-based Attribute Mamba decomposes each patch feature matrix via singular value decomposition and recombines singular vectors using sliding windows of three sizes to capture multi-scale attribute characteristics (coarse-grained to fine-grained), with independent Mamba blocks modeling inter-scale dependencies. Second, the Location Mamba encodes object center coordinates and bounding box dimensions, then performs cross-channel Mamba scanning over all n proposals (global) and over u nearest neighbors (local) to capture spatial relationships. Third, the Instructive Dual-Mamba (IDM) block achieves cross-modal fusion by replacing the state transition matrices A in the object-feature SSM with those derived from the text-feature SSM, so that language semantics directly govern how object hidden states are updated, enabling precise language-instructed grounding. Training uses a combined loss of grounding, text-object contrastive, and detection objectives, with a pre-trained PointGroup detector fine-tuned end-to-end.

## Results

On ScanRefer, VGMamba achieves state-of-the-art overall accuracy of 60.0% at IoU 0.25 and 53.9% at IoU 0.5, surpassing the previous best method PQ3D by 3.0% and 2.7% respectively. On Nr3D and Sr3D, VGMamba reaches 68.3% and 81.3% overall accuracy (and 61.4% / 74.4% on the Hard subsets), outperforming PQ3D by 1.6% and 1.6% overall. On the multi-object Multi3DRefer benchmark, VGMamba attains an F1@0.5 of 54.9 across all scenarios, exceeding the second-best D-LISA (51.2) by 3.7 points, with the largest margin in the multiple-target case (55.1 vs. 51.0).

## Baselines & Comparisons

VGMamba outperforms all 18 compared baselines across every evaluated dataset and metric. On ScanRefer, it leads the previous SOTA PQ3D [44] by 3.0% (IoU 0.25) and 2.7% (IoU 0.5) overall, and by 3.3% / 1.4% in the more challenging Multiple subset. On Nr3D/Sr3D, VGMamba surpasses PQ3D by 1.6% overall and 2.7% / 1.6% on the Hard subsets, while also beating the large-scale pre-trained Chat-Scene [13] and GPS [16] methods. On Multi3DRefer, VGMamba achieves the highest F1@0.5 in all five scenarios, with the largest gains in the multiple-target case (55.1 vs. 51.0 for D-LISA [41]) and the single-target-with-distractors case (46.7 vs. 43.6 for PQ3D [44]). Notably, VGMamba maintains consistent performance across Unique and Multiple settings, whereas methods like ConcreteNet [31] and Chat-Scene [13] show large drops in the Multiple subset, indicating VGMamba's superior robustness to ambiguous multi-object queries.

## Relation to Prior Work

This paper builds on the Mamba selective state-space model [11] and the M3DRef-CLIP multi-object grounding framework [42], replacing Transformer-based attention with SSMs for the first time in 3D visual grounding. Conceptually, it departs from prior two-stage detection-then-matching pipelines by introducing an explicit attribute-to-location reasoning mechanism inspired by human perception, where SVD-based multi-scale decomposition disentangles attribute features before location refinement. The Instructive Dual-Mamba block further departs from standard cross-attention fusion by transferring state-transition matrices from the language branch to the object branch, enabling cross-modal guidance within the SSM hidden-state space rather than in a separate attention layer.

## Why It Matters / Open Questions

VGMamba demonstrates that SSMs can match or exceed Transformer-based grounding accuracy at substantially lower FLOPs, making 3D visual grounding more practical for real-time embodied applications. The attribute-to-location decomposition also provides interpretability that black-box attention models lack, which is valuable for debugging and trust in safety-critical robotics. Open questions include whether the SVD sliding-window decomposition generalizes beyond rendered multi-view images to native point-cloud features, and whether the cross-modal state-transfer in IDM can be extended to longer or more complex language instructions. The paper does not explore failure modes in highly cluttered scenes or with very short/ambiguous queries.

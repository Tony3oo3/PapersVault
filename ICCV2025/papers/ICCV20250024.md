## Problem

Large-scale video-language models capable of real-time streaming understanding require prohibitive computational resources and scarce annotated datasets, making them impractical for academic research. Existing compression strategies (sampling, pooling, resampling) discard critical visual cues, while clip-based segmentation disrupts semantic flow. No prior method efficiently encodes entire long video sequences with preserved semantic continuity and long-term memory while remaining accessible on a single GPU.
![Teaser figure](../imgs/ICCV20250024/cropped_page2_idx0.webp)

## Input / Output

The model takes video frames resized to 224×224 (processed by ViT-L/14) and a text question as input, producing text answers, streaming captions with auto-detected scene boundaries, planning decisions, or frame retrieval results. Although trained on only 16 frames divided into 4 segments, it extrapolates to 320+ frames at inference with linear GPU memory scaling on a single A100. The proposed NIAVH benchmark additionally accepts text, image (DALL-E generated), or video (Sora generated) needles inserted into 320-second Ego4D haystacks at varying depths.

## Method

VideoLLaMB comprises three modules: (1) SceneTiling, a model-free segmentation algorithm that computes cosine similarity between adjacent ViT [CLS] tokens, derives depth scores, and splits the video into K semantically coherent segments using a mean-plus-variance threshold; (2) Recurrent Memory Bridge Layers, single-layer Transformer blocks that prepend a fixed set of memory tokens to each segment and recursively update them via self-attention, so that after K steps the memory tokens encode a condensed visual summary of all prior segments while the current segment's features are projected to the LLM; (3) a Memory Cache with Retrieval, where at each step the current memory token performs multi-head cross-attention over all previously cached memory tokens to preserve long-range dependencies and mitigate gradient vanishing. The overall architecture uses ViT-L/14 as the visual encoder and Vicuna-7B as the LLM, achieving O(K²) time and O(K) space complexity for the bridge layers and O(M²) for the LLM, where K is the number of segments and M is the memory token length.

## Results

On EgoSchema (zero-shot, 32 frames), VideoLLaMB achieves 53.8% accuracy, surpassing PLLaVA (45.6%) by 8.2 points and LLaVA-NeXT-Video-DPO (41.6%) by 12.2 points, despite being trained on only 16 frames. On NExTQA, it reaches 71.1% overall accuracy (+2.9 over PLLaVA), with a notable 4.6-point gain on temporal questions. On VideoMME, VideoLLaMBβ (trained on VideoChat2 data) achieves 41.41% overall, outperforming PLLaVA (38.22%) and VideoChat2 (33.7%). On EgoPlan, it attains 32.32% accuracy, the best among 7B video-language models (+2.06 over PLLaVA). The model processes up to 320 frames on a single A100 GPU with linear memory scaling.

## Baselines & Comparisons

VideoLLaMB consistently outperforms PLLaVA [70]—its primary baseline sharing the same Vicuna-7B backbone and training data—across all evaluated benchmarks: +8.2 pts on EgoSchema (53.8 vs 45.6), +2.9 pts on NExTQA (71.1 vs 68.2), +3.19 pts on VideoMME (41.41 vs 38.22), and +2.06 pts on EgoPlan (32.32 vs 30.26). It also surpasses LLaVA-NeXT-Video-DPO [79] by 12.2 pts on EgoSchema and Video-LLaVA [34] by 13.6 pts, and beats VideoChat2 [30] on VideoMME (41.41 vs 33.7) and MVBench (52.5 vs 51.1). On MVBench, VideoLLaMBβ (52.5 avg) approaches the 13B PLLaVA (50.1) while using only 7B parameters. However, it still trails GPT-4o (72.2 on EgoSchema, 76.0 on NExTQA) and fine-tuned retrieval-based methods like MC-ViT-L (62.5 on EgoSchema). On the NIAVH stress test, VideoLLaMB with retrieval preserves needle information better than adaptive pooling [70], position extrapolation [79], and resampler+retrieval [20], though it still exhibits forgetting of early content and occasional hallucination.

## Relation to Prior Work

VideoLLaMB departs from the dominant video compression paradigm (sampling, pooling, resampling) that discards visual information, instead adopting a recurrent memory strategy inspired by Recurrent Memory Transformers (RMT) but relocating the recurrence from the full LLM to lightweight bridge layers between the vision encoder and LLM. The SceneTiling algorithm repurposes the TextTiling subtopic-segmentation heuristic from NLP for video, replacing uniform or learned segmentation with a model-free, cosine-similarity-based approach. The memory cache with cross-attention retrieval addresses the gradient-vanishing problem of naive recurrence, drawing conceptually on retrieval-augmented memory models like MA-LMM but operating at the token level within bridge layers rather than at the feature-pooling level.

## Why It Matters / Open Questions

The practical accessibility is the paper's strongest contribution: a model trained on 16 frames handles 320 frames on a single A100 with linear memory scaling, making long-video research feasible for academic labs without large compute clusters. The NIAVH benchmark fills a genuine gap in evaluating fine-grained frame retrieval across modalities (text, image, video needles), though its current 320-second ceiling and single-needle design limit its diagnostic power. Key open questions remain: the model still forgets early information and hallucinates (e.g., 'holding book' → 'holding phone'), the 8× extrapolation shows diminishing returns beyond 32 frames due to the training-length domain gap, and the authors themselves flag the need to integrate LLM-internal memory with bridge memory for truly unbounded streaming.

## Problem

Off-the-shelf image captioners deployed on autonomous agents produce wrong or inconsistent descriptions of the same object when viewed from different viewpoints, particularly under occlusion or challenging viewing angles in cluttered indoor environments. Prior work addresses navigation, noisy captions, or caption comprehensiveness in isolation, but no existing method jointly tackles both the noise in individual captions and the cross-view coherence problem in a self-supervised embodied setting.
![Teaser figure](../imgs/ICCV20250180/cropped_page0_idx3.webp)

## Input / Output

During exploration, the agent consumes RGB-D observations at each timestep; an instance segmentation model (Mask2Former) produces bounding boxes and masks for six indoor object classes, which are cropped (with 10-pixel padding) and fed to a captioner. The 3D voxel map is built by projecting segmentation masks into depth, and objects are clustered via 26-connectivity connected components on detection logits. The final output is a fine-tuned captioner model (CoCa or BLIP2) that, given a single object crop, produces a concise caption consistent across all views of that object instance.

## Method

The framework operates in three phases. First, an agent navigates the environment using a learned policy (CLA) that maximizes a caption-disagreement map computed from SBERT cosine distances among captions of the same 3D-clustered object, building a semantic voxel map along the way. Second, LD-CPS prompts an LLM (LLaMA-3) with the full list of per-object captions weighted by their frequency plus in-context examples to distill a single concise pseudo-caption, filtering out low-frequency noisy descriptions. Third, the captioner is fine-tuned with a combined loss: standard cross-entropy on the pseudo-caption tokens plus a triplet loss (margin ε=2, weight λ=0.1) that pulls visual features of different views of the same object closer while pushing features of different objects apart, with LoRA applied to BLIP2's Q-Former for parameter efficiency.

## Results

On the Gibson test set, the best fine-tuned CoCa (triplet loss, Random policy) achieves CS=73.26, SPICE=35.58, and BLEU-4=19.85, surpassing off-the-shelf ChatGPT (CS=70.85, SPICE=36.26) on cosine similarity and BLEU-4. On HM3D, fine-tuned CoCa with triplet loss and Frontier policy reaches CS=73.99 and SPICE=30.21, outperforming ChatGPT (CS=68.41, SPICE=29.59) on both metrics. The triplet loss consistently improves intra-object caption consistency over standard fine-tuning, with the largest gains in SPICE (e.g., +2.46 p.p. for CoCa on Gibson Random). Pseudo-captioning via LD-CPS outperforms ECO and IC3 across all metrics, with the largest SPICE improvement of +4.87 p.p. over ECO (CoCa, Gibson, Random).

## Baselines & Comparisons

For pseudo-captioning (Table 1), LD-CPS outperforms both ECO and IC3 across nearly all metrics on both datasets. On Gibson with CoCa and Random policy, LD-CPS achieves SPICE=32.16 vs. ECO's 27.29 (+4.87 p.p.) and IC3's 10.58 (+21.58 p.p.); CS reaches 71.71 vs. ECO's 69.43 and IC3's 56.68. IC3 consistently produces the worst results (e.g., CIDEr≈0.00–0.02) because its LLM summary propagates errors from inaccurate input captions. For fine-tuning (Table 2), fine-tuned CoCa with triplet loss surpasses off-the-shelf ChatGPT on CS (73.26 vs. 70.85 on Gibson; 73.99 vs. 68.41 on HM3D) and BLEU-4, while ChatGPT retains a slight edge in SPICE on Gibson (36.26 vs. 35.58). Fine-tuned BLIP2 also exceeds Florence2 by a wide margin (e.g., CS 69.47 vs. 58.43 on HM3D) and approaches or matches ChatGPT on most metrics. The triplet loss provides consistent gains over standard fine-tuning in CS and SPICE (e.g., +3.15 p.p. CS for CoCa on Gibson Random), confirming that contrastive learning improves cross-view caption consistency.

## Relation to Prior Work

This paper builds directly on the LookAround exploration framework [32], adapting its disagreement-map-based curiosity policy from object detection to the captioning domain. It synthesizes three previously separate research threads—embodied navigation for captioning (CaBOT [10], embodied scene description [35]), noisy-caption handling (ECO [14], IC3 [3]), and contrastive learning in vision-language models (CoCa [45], BLIP2 [19])—into a unified three-phase self-supervised pipeline. The key conceptual departure from prior work is treating noise and cross-view coherence as jointly addressable challenges within a single agent loop, rather than as independent problems solved by caption re-ranking or LLM summarization alone.

## Why It Matters / Open Questions

The modular framework provides a practical recipe for domain-adapting captioners without manual annotation, which is valuable for deploying vision-language models in real indoor environments where off-the-shelf captioners produce inconsistent descriptions. The triplet-loss fine-tuning strategy for enforcing cross-view consistency is a lightweight, generalizable technique applicable beyond this specific setup. However, the framework's reliance on accurate depth estimation and camera pose for point-cloud segmentation, its vulnerability when the majority of initial captions are wrong, and its non-real-time nature limit immediate deployment on standalone robots. Open questions include whether the approach extends to dynamic scenes, whether the LLM-based pseudo-captioning can be replaced by learned distillation, and whether the gains transfer to open-vocabulary or outdoor settings.

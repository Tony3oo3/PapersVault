## Problem

Existing textual prompt learning methods for VLMs (e.g., CoOp, MaPLe) concatenate learnable soft tokens with a hard class token, restricting image-text alignment to predefined known categories during training. This one-dimensional, category-centric prompt form prevents the model from forming accurate associations with unknown categories, limiting zero-shot generalization. The paper asks whether incorporating universal attributes into the prompt structure can bridge images to unseen categories.

## Input / Output

The method takes an RGB image and a hybrid text prompt consisting of learnable soft tokens interleaved with fixed universal attribute tokens (e.g., 'color', 'shape') followed by a hard class token, all fed into the CLIP text encoder. The output is a standard class probability distribution via cosine similarity between image and text features. The attribute tokens are selected once per task via a differentiable search over a combinatorial pool of LLM-generated attribute bases, after which they remain fixed during fine-tuning.

## Method

ATPrompt anchors multiple fixed universal attribute tokens into the existing soft prompt template, transforming the prompt from a category-centric form to an attribute-category hybrid form that expands the soft token learning space from one-dimensional to multi-dimensional. Two variants are provided: a shallow version that places attribute tokens only at the input level, and a deep version that retains attribute tokens across all Transformer layers while selectively dropping and re-adding only class-related soft tokens at each layer. A differentiable attribute search method, inspired by DARTS, relaxes discrete attribute selection into a softmax-weighted sum over all candidate combinations from an LLM-generated pool, then alternately optimizes attribute weights (on validation loss) and soft prompt tokens (on training loss) for approximately 5 epochs. The selected attribute combination is then fixed and used for standard cross-entropy fine-tuning, making ATPrompt a plug-in that can be seamlessly integrated into any existing textual-based prompt learning method.

## Results

ATPrompt is evaluated as a plug-in on five prompt-learning baselines across 11 datasets using base-to-novel generalization (Harmonic Mean of Base and Novel accuracy). The average HM improvements are +2.99 for CoOp (71.66→74.65), +2.12 for CoCoOp (75.83→77.95), +1.16 for DePT (77.29→78.45), +0.66 for MaPLe (78.55→79.21), and +0.62 for PromptKD (83.73→84.35). The best overall configuration, PromptKD+ATPrompt, achieves 84.35% average HM, outperforming the strongest standalone baseline (PromptKD at 83.73%). Cross-dataset and domain generalization experiments confirm consistent gains of 0.33–1.38% in average accuracy.

## Baselines & Comparisons

ATPrompt is applied as a drop-in replacement to five existing prompt-learning methods, and it consistently improves the Harmonic Mean across all 11 datasets in every case. The largest gain is over CoOp (+2.99 HM), where the simpler architecture benefits most from the additional attribute-anchored learning space; CoCoOp also sees a substantial +2.12 improvement. For more sophisticated baselines that already incorporate regularization or distillation (MaPLe +0.66, PromptKD +0.62), the gains are smaller but still positive, which the authors attribute to these methods having additional learnable modules beyond the text prompt. Notably, PromptKD+ATPrompt (84.35 HM) surpasses all standalone baselines including ArGue (80.78) and CoPrompt (80.48), confirming that the attribute-anchored format is complementary to knowledge distillation. The paper does not report an ArGue+ATPrompt combination, so a direct head-to-head with ArGue's in-class attribute approach is not provided, though ATPrompt's universal (inter-class) attributes are argued to be more efficient for unknown categories.

## Relation to Prior Work

ATPrompt extends the foundational CoOp paradigm (soft tokens + hard class token) by anchoring fixed universal attribute tokens into the learnable prompt, transforming it from a category-centric to an attribute-category hybrid form. The differentiable attribute search mechanism is directly adapted from DARTS's softmax relaxation and alternating optimization, repurposed from network-level architecture search to a lightweight token-level selection problem. Unlike ArGue, which uses in-class attributes mined by LLMs as regularization targets, ATPrompt treats inter-class (universal) attributes as structural learning components within the prompt itself, and unlike MaPLe's deep prompt insertion, it selectively retains attribute tokens across layers while only dropping class-related soft tokens.

## Why It Matters / Open Questions

The core insight that universal attributes serve as bridges between known and unknown categories offers a principled explanation for why category-only prompts overfit to base classes, and the plug-in design means practitioners can adopt it with minimal engineering effort. However, the paper itself acknowledges this is a preliminary study: standalone ATPrompt does not match regularization-based methods (PromptKD, PromptSRC), and improvements shrink when the base method already includes additional learnable modules. Open questions include whether optimal anchor positions can be discovered automatically, whether the approach generalizes beyond 16-shot classification to denser or open-vocabulary settings, and whether the LLM-generated attribute pool quality is a bottleneck for domains where attribute vocabulary is less well-defined.

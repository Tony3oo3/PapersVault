## Problem

Existing segmentation models operate on a single image view, making them impractical for the Ego-Exo Object Correspondence task, which requires identifying and segmenting the same object across drastically different ego-centric and exo-centric perspectives. While PSALM demonstrates zero-shot capability on this task, it fails to accurately locate objects in complex exo-view backgrounds and struggles with significant appearance changes between views, leading to incorrect object associations.
![Teaser figure](../imgs/ICCV20250845/cropped_page0_idx0.webp)

## Input / Output

The method takes a temporally aligned pair of frames (one ego-centric, one exo-centric), an object mask in the query view, and a text description of the masked object generated by LLaVA. It produces the corresponding object segmentation mask in the target view. Notably, the text description is not provided by the benchmark but is synthesized at inference time by a pre-trained vision-language model from the query mask region, and the model can also operate with only the visual mask condition (dropping text) with only a slight performance drop.

## Method

ObjectRelator builds on PSALM (Swin-B visual encoder + Phi-1.5 LLM + Mask2Former-style mask generator) and introduces two modules. MCFuse fuses the ego text embedding and ego visual mask embedding via cross-attention (text as query, visual as key/value), then combines the result with the original visual embedding through a residual connection weighted by a learnable scalar k_lea, prioritizing visual cues while incorporating semantic text information. XObjAlign enforces cross-view consistency by minimizing the Euclidean distance between the ego and exo object-level embeddings produced by the LLM, acting as a parameter-free self-supervised alignment loss. Training proceeds in two stages: first, MCFuse is initialized with mask loss on a subset of data; then all modules are jointly optimized with the combined mask + XObjAlign loss. At inference, XObjAlign and the exo mask prompt are removed, leaving a lightweight model that adds only 0.26M parameters over PSALM.

## Results

On the Ego-Exo4D benchmark, ObjectRelator achieves state-of-the-art IoU of 45.4 (Ego2Exo) and 50.9 (Exo2Ego) with the Full TrainSet, improving over the PSALM baseline by +4.1 and +3.6 IoU points respectively. With the smaller TrainSet, it still reaches 44.3 and 49.2 IoU, outperforming all prior methods including Xmem+XSegTx (36.9/36.1) and SEEM (1.1/4.1 ZSL). On HANDAL-X, ObjectRelator achieves 84.7 IoU when retrained and 42.8 IoU zero-shot (transferred from Ego-Exo4D), surpassing PSALM by +1.3 and +2.9 IoU respectively.

## Baselines & Comparisons

ObjectRelator is built directly on PSALM [75] and consistently outperforms it: with the Small TrainSet, it gains +4.6 IoU on Ego2Exo (44.3 vs. 39.7) and +5.1 IoU on Exo2Ego (49.2 vs. 44.1); with the Full TrainSet, gains are +4.1 and +3.6 IoU. Against the Ego-Exo4D-native baselines (XSegTx, XView-XMem, XMem+XSegTx [13]), ObjectRelator leads by a wide margin—e.g., 45.4 vs. 36.9 IoU on Ego2Exo over the strongest prior method XMem+XSegTx. SEEM [77], adapted as a zero-shot universal segmentation baseline, performs poorly (1.1/4.1 IoU), confirming that generic segmentation models do not transfer well to cross-view correspondence. On HANDAL-X, ObjectRelator also beats PSALM in both zero-shot (42.8 vs. 39.9 IoU) and retrained (84.7 vs. 83.4 IoU) settings, validating that the gains generalize beyond Ego-Exo4D.

## Relation to Prior Work

This paper builds directly on PSALM (ECCV 2024), which unifies Mask2Former with an LLM for universal segmentation, and adapts it to the newly defined Ego-Exo Object Correspondence task from Ego-Exo4D (CVPR 2024). It departs from prior universal segmentation methods (UNINEXT, SEEM, PSALM) that operate on a single view by introducing two cross-view-specific modules: MCFuse, which for the first time fuses text descriptions (generated via LLaVA) with visual mask prompts to improve object localization across viewpoints, and XObjAlign, a parameter-free self-supervised consistency loss that enforces ego-exo embedding proximity. The work also positions itself against spatiotemporal baselines (XMem, XSegTx) from Ego-Exo4D, showing that a well-designed frame-level model can outperform temporal approaches without leveraging video.

## Why It Matters / Open Questions

Ego-Exo Object Correspondence is a nascent task with direct applications in VR, robotics, and embodied AI (e.g., enabling robots to learn from third-person demonstrations), yet prior work was limited to zero-shot transfers of general segmentation models that fail under viewpoint change. The introduction of HANDAL-X as a robotics-ready cross-view benchmark and the demonstration that a parameter-free alignment loss (XObjAlign) yields comparable gains to a parameterized fusion module (MCFuse) offer practical design insights. Key limitations include the frame-level-only formulation (no temporal modeling), dependence on LLaVA for text generation, and evaluation on a single large-scale dataset plus one adapted benchmark, leaving open questions about scalability to longer sequences, more extreme viewpoint changes, and real-time deployment.

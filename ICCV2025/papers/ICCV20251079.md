## Problem

Dense-token interactive segmentation methods achieve superior boundary precision but are prohibitively slow on CPU devices, while sparse-token approaches like SAM run fast but sacrifice segmentation quality. The root cause is uniform computation allocation across all tokens: existing models waste resources on already-determined object interiors while under-serving the critical boundary regions where subsequent clicks focus, and they fail to exploit boundary cues from previous masks for computational routing.

## Input / Output

The model takes an RGB image (encoded once into 768-dim tokens at 1/16 resolution via a ViT-Base encoder), a sequence of user clicks (foreground/background) converted into a 5-channel reference mask with values 0–4 encoding definite/possible foreground/background and uncertain regions, and the previous iteration's segmentation mask. It outputs a full-resolution binary mask at each interaction step. The encoder is CPU-compatible (SSM removed from HRSAM++), and the decoder operates on 256-dim tokens with 32-dim Q/K/V projections for efficiency.

## Method

Inter2Former optimizes computation allocation in dense-token processing through four adaptive mechanisms. Dynamic Prompt Embedding (DPE) crops the reference mask to a bounding box around clicks and foreground predictions, embedding only that local region and filling the rest with a learnable background vector. Dynamic Hybrid Attention (DHA) detects edges from the previous mask via local variance estimation, then routes boundary tokens through standard Full Attention (O(N²)) while non-boundary tokens use the proposed BSQ Attention (O(N)), which applies Binary Spherical Quantization to compress keys into an 8-bit binary codebook of 256 vectors, enabling linear-time attention via factorized matrix products. Hybrid Mixture of Experts (HMoE) applies the same edge-based routing in FFN layers: edge tokens are dispatched to a selected routed expert plus a shared expert with softmax-weighted combination, while non-edge tokens pass only through the shared expert; a token-rearrangement strategy groups tokens by expert ID into contiguous memory blocks for parallel CPU matrix operations, reducing latency by 56–85% over vanilla MoE. Dynamic Local Upsampling (DLU) first predicts a coarse mask via a lightweight MLP to localize the object, then performs four-stage deconvolutional upsampling exclusively within the detected bounding box, fusing multi-scale Canny edge features at each stage for precise boundary delineation.

## Results

On HQSeg-44K, Inter2Former-ViT-B2048 (COCO+LVIS+HQ) achieves 92.28% 5-mIoU, 4.58 NoC@90, and 7.79 NoC@95, setting SOTA across all three metrics. On DAVIS, the same model reaches 91.30% 5-mIoU, 4.33 NoC@90, and 8.45 NoC@95. The ViT-B1024 variant runs at 75 ms (20-SPC) / 50 ms (Online) on CPU, only marginally slower than HRSAM++ (65/40 ms) while delivering substantially higher accuracy (91.48% vs 90.32% 5-mIoU on HQSeg-44K). The CPU-optimized HMoE reduces inference time by 56–85% over vanilla MoE implementations.

## Baselines & Comparisons

Against the closest efficiency competitor HRSAM++-ViT-B1024, Inter2Former-ViT-B1024 improves 5-mIoU from 90.32% to 91.48% and NoC@95 from 10.14 to 9.29 on HQSeg-44K, at only 10 ms additional 20-SPC latency (75 vs 65 ms). Compared to the dense-token SegNext(SA×2), Inter2Former trades a marginal 0.27% 5-mIoU drop (91.48 vs 91.75) for a 20× speedup on CPU (75 ms vs 1519 ms 20-SPC). Against SAM-ViT-B1024, Inter2Former gains 5.32% 5-mIoU on HQSeg-44K (91.48 vs 86.16) while running at comparable online latency (50 vs 40 ms). Versus the original InterFormer, Inter2Former improves 5-mIoU by 8.86% (91.48 vs 82.62) and reduces 20-SPC CPU time from 1020 ms to 75 ms (a 13.6× speedup). On DAVIS, Inter2Former-ViT-B2048 achieves the best NoC@95 (8.45) among all compared methods, outperforming SegNext (10.73) and HRSAM++ (10.84) by over 2 clicks. The distillation-trained variant (†SA-1B+HQ) further pushes HQSeg-44K 5-mIoU to 92.68% and NoC@95 to 7.39, establishing clear SOTA across all reported metrics.

## Relation to Prior Work

Inter2Former sits at the intersection of two competing paradigms in interactive segmentation: the dense-prompt-token approach of InterFormer and SegNext (high accuracy, high cost) and the sparse-prompt-token approach of SAM and HRSAM (high speed, lower boundary precision). It builds directly on InterFormer's click-map prompt encoding and HRSAM's Flash Swin encoder, while introducing a unified 'adaptive computation allocation' principle that routes tokens through different computational paths based on boundary information from prior masks. The key technical ingredients—Binary Spherical Quantization (BSQ) for linear attention, DeepSeek-V3-style MoE with auxiliary-loss-free balancing, and dynamic region cropping—are individually established techniques that are here combined into a coherent architecture for the first time in the IS setting.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck for large-scale crowdsourced annotation: dense-token IS models are prohibitively slow on CPU, while sparse-token models sacrifice boundary precision. By demonstrating that selective, boundary-aware computation can close this gap (SOTA accuracy at only ~10ms more latency than HRSAM++), the work validates the broader principle that uniform token processing is wasteful in iterative refinement tasks. Open questions include whether the edge-map-based routing generalizes beyond click-based IS (e.g., scribble or box prompts), whether the 8-bit BSQ codebook is near-optimal, and whether the approach extends to video or 3D segmentation where boundary dynamics are more complex. The CPU-optimized MoE via token rearrangement is a practical technique likely to be adopted in other CPU-constrained transformer deployments.

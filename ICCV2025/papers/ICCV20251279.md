## Problem

Photorealistic 3D scene representations like NeRF and 3D Gaussian Splatting produce memory-intensive, non-modular encodings unsuitable for explicit spatial reasoning, while existing primitive-based decomposition methods either require category-specific training or rely on hand-crafted hierarchical heuristics that fail to generalize across diverse object geometries. No prior approach can decompose arbitrary 3D scenes into a compact, interpretable set of superquadrics in a class-agnostic manner.

## Input / Output

The method takes a 3D point cloud as input; for single objects, 4096 points are sampled via Farthest Point Sampling and the object is centered and rescaled to a unit sphere of radius 0.5. For full scenes, a scene-level point cloud is first segmented into object instances using Mask3D, and each instance is processed independently. The output is a set of up to P=16 superquadrics, each parameterized by 11 values (3 semi-axis scales, 2 shape exponents, 3 translation, 3 rotation) plus a learned existence probability, together with a soft N×P segmentation matrix assigning each input point to a superquadric.

## Method

SUPERDEC uses a PVCNN point encoder to extract local point features, which are cross-attended by P=16 superquadric queries (initialized with sinusoidal positional encodings) in a Transformer decoder adapted from the Mask3D segmentation architecture. Two prediction heads decode the refined features: a segmentation head producing the soft point-to-superquadric assignment matrix, and a superquadric head predicting the 11 geometric parameters plus an existence score per primitive. Training is fully self-supervised with no ground-truth annotations, combining a bidirectional Chamfer reconstruction loss (with a normal-based regularizer), a parsimony loss on the 0.5-norm of the assignment to encourage fewer primitives, and a binary cross-entropy existence loss. A lightweight Levenberg-Marquardt optimizer then refines the predicted parameters using radial-distance residuals, improving geometric accuracy without additional training data. The key design choice—leveraging local point features via cross-attention rather than a single global shape descriptor—is what enables class-agnostic generalization from ShapeNet training to unseen real-world objects.

## Results

On ShapeNet (in-category), SUPERDEC achieves an L2 Chamfer distance of 0.047 (×10²) with 5.8 primitives, reducing L2 by ~6× compared to the prior best learning-based method SQ (0.279) while using nearly half the primitives (5.8 vs. 10). In the out-of-category setting, SUPERDEC maintains L2 of 0.061 with 5.26 primitives, again outperforming SQ (0.354) and CSA (0.427). On real-world scenes, SUPERDEC achieves L2 of 0.11 on ScanNet++ and 0.19 on Replica, substantially beating all baselines (next best: CSA at 0.41 and 0.70 respectively) despite being trained solely on ShapeNet.

## Baselines & Comparisons

SUPERDEC decisively outperforms all three object-decomposition baselines on both in-category and out-of-category ShapeNet evaluations. Against SQ [32] (the closest learning-based competitor using superquadrics), SUPERDEC reduces L2 by ~6× (0.047 vs. 0.279 in-category) while using fewer primitives (5.8 vs. 10), and the gap widens out-of-category (0.061 vs. 0.354). Against CSA [57] (cuboid-based, learning), SUPERDEC achieves ~11× lower L2 in-category (0.047 vs. 0.527) with fewer primitives (5.8 vs. 9.21). Against EMS [23] (optimization-based superquadric fitting), SUPERDEC achieves ~20× lower L2 in-category (0.047 vs. 1.345) with a comparable primitive count (5.8 vs. 5.68), demonstrating the benefit of learned shape priors over purely optimization-based fitting. On real-world scenes (ScanNet++, Replica), SUPERDEC extends its lead: L2 of 0.11 vs. CSA's 0.41 and EMS's 2.11 on ScanNet++, and 0.19 vs. CSA's 0.70 and EMS's 2.12 on Replica. In the path-planning comparison (Table 3), SUPERDEC achieves 91.71% success rate with 0.042 MB memory, outperforming dense point clouds (89.57%, 19.286 MB) and cuboids via MonteBoxFinder [37] (61.23%, 0.024 MB) in success rate while using far less memory than point clouds.

## Relation to Prior Work

SUPERDEC repurposes the iterative query-decoding Transformer architecture from supervised segmentation models (Mask3D, Mask2Former) for the unsupervised task of predicting superquadric primitives, replacing pixel/point mask queries with superquadric parameter queries. It departs from prior learning-based decomposition methods (SQ, CSA) that rely on category-specific training and global shape descriptors, instead using local PVCNN point features in a class-agnostic setting. The method also diverges from optimization-based approaches (EMS, Marching Primitives) by providing a learned initialization that avoids the local-minima problems of from-scratch fitting, followed by a lightweight Levenberg-Marquardt refinement. The parsimony loss and existence-probability head are novel additions that jointly optimize compactness and accuracy without ground-truth annotations.

## Why It Matters / Open Questions

The paper demonstrates that a compact, explicit superquadric representation trained purely on synthetic ShapeNet data generalizes to real-world scenes (ScanNet++, Replica) without fine-tuning, addressing a key limitation of prior category-specific methods. This opens a practical path toward lightweight 3D scene representations suitable for robotics (path planning, grasping) and controllable generation, where the memory and interpretability overhead of NeRF/3DGS is prohibitive. Open questions include whether the approach scales to very large or dynamic scenes, how it handles objects with highly non-superquadric geometry (thin structures, complex topology), and whether the observed hierarchical decomposition behavior can be formalized into a principled multi-scale framework.

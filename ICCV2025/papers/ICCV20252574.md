## Problem

In machine unlearning, the retain and forget objectives are typically optimized simultaneously as a weighted sum, but their gradients frequently conflict in non-convex loss landscapes, causing the model to re-learn forgotten knowledge or degrade retained performance. Existing remedies either naively combine the two losses or explicitly project gradients to prevent conflicts, both of which are suboptimal or computationally expensive. The paper asks whether gradient alignment between retain and forget objectives can be achieved implicitly, without an explicit projection step, while still driving effective unlearning.

## Input / Output

The method takes a pre-trained model (ResNet-18/34 for classification, DDPM or Stable Diffusion for generation), a forget set specifying which data to erase (random samples, entire classes, or semantic concepts like NSFW content), and a retain set comprising all remaining data. For classification, the forget set provides image-label pairs and the retain set provides image-label pairs; for diffusion, the forget set provides image-prompt pairs and the retain set provides image-prompt pairs. The output is a set of unlearned model weights that, when deployed, either classify images (producing class labels) or generate images from text prompts, with the forgotten knowledge removed while preserving utility on the retain set.

## Method

LUR employs a bi-level optimization inspired by MAML: it first performs a small gradient descent step on the retain loss to obtain an intermediate parameter θ′ = θ − α∇L_r(θ), then optimizes the forget loss evaluated at θ′ with respect to the original θ. A Taylor-expansion analysis (Theorem 1) reveals that the resulting gradient contains an implicit regularization term proportional to −α∇(∇L_f · ∇L_r), meaning minimizing the objective automatically maximizes the inner product between retain and forget gradients, steering updates toward a conflict-free parameter region. This implicit alignment eliminates the need for explicit gradient projection (as in Scissor Hands), reducing memory and compute overhead. The framework is task-agnostic: for classification it uses negative cross-entropy as the forget loss and standard cross-entropy as the retain loss; for diffusion models it uses an MSE-based forget loss that associates the target prompt with a misaligned image, and standard denoising MSE as the retain loss, with the same bi-level update applied to the noise-predictor parameters.

## Results

On CIFAR-10 with 50% random data forgetting, LUR achieves an average gap (Avg. Gap) of 2.62 relative to exact retraining, outperforming SalUn (2.18) and SHs (3.29), while on CIFAR-100 with 50% forgetting it achieves 8.07 vs. SalUn (8.54) and SHs (15.08). For class-wise forgetting on Celeb-HQ-FIR at 50%, LUR achieves an Avg. Gap of 0.95, dramatically outperforming SalUn (14.45) and SHs (2.01). In generative unlearning, LUR achieves 100% unlearning accuracy with FID 9.76 on DDPM/CIFAR-10 (vs. Retrain FID 11.69) and 99.96% UA with FID 0.98 on SD/Imagenette (vs. SalUn FID 1.22).

## Baselines & Comparisons

LUR achieves the lowest Avg. Gap (closest to exact retraining) across all four classification settings in Table 1, beating SalUn by 0.47 on CIFAR-100/50% and by a large margin (8.07 vs. 15.08) on CIFAR-100/50% against SHs. On Celeb-HQ-FIR class-wise forgetting (Table 2), LUR dominates with Avg. Gap of 0.10 (10%) and 0.95 (50%), compared to SalUn's 2.93/14.45 and SHs' 2.82/2.01, indicating near-exact unlearning. In DDPM class-wise forgetting (Table 3), LUR matches Retrain and SalUn at 100% UA while achieving the best FID (9.76) among methods with full unlearning, outperforming Retrain (11.69) and SalUn (11.25); SA achieves lower FID (9.08) but fails to fully unlearn (UA=85.80%). On SD/Imagenette (Table 4), LUR achieves the best average UA (99.96) and FID (0.98), surpassing SalUn (99.82/1.22), ESD (99.40/1.50), and FMN (42.54/1.30). The simpler baselines (FT, GA, IU, BE, BS, ℓ₁-sparse) all show substantially higher Avg. Gap values (4.67–24.20), confirming that naive optimization strategies fail to balance forgetting and retention effectively.

## Relation to Prior Work

LUR builds on the generalized MU objective formulation of Liu et al. (2025) and the loss designs of SalUn (Fan et al., 2024) for both classification and diffusion unlearning, but departs from the standard practice of jointly optimizing retain and forget losses in a single step. The key conceptual departure is borrowing the bi-level (inner-outer loop) structure from MAML (Finn et al., 2017) to create an intermediate retain-loss update before computing the forget-loss gradient, which the authors show implicitly regularizes toward gradient alignment. This contrasts with SHs (Wu & Harandi, 2024) and related methods that enforce alignment through explicit gradient projection, and with SalUn, which treats the two objectives as a simple weighted sum prone to conflict.

## Why It Matters / Open Questions

The implicit gradient product regularization offers a lower-overhead alternative to explicit projection-based methods, which is practically relevant for large-scale unlearning where memory and compute are constrained. However, the empirical gains over strong baselines like SHs are modest in several settings (e.g., CIFAR-100 50% forgetting: 3.96 vs. 4.11 Avg.Gap), and the method's sensitivity to the inner-step hyperparameter α limits its plug-and-play applicability. Open questions include whether the implicit alignment mechanism scales to LLM unlearning or very large diffusion models, and whether the bi-level structure can be further generalized to multi-concept or sequential unlearning scenarios.

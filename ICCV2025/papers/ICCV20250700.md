## Problem

Existing 3D correspondence methods operate at the point or object level (semantic correspondence, scene graph matching) and cannot produce smooth, dense maps between scene regions that share similar spatial contexts. The paper introduces the 3D scene analogy task: finding a coherent dense mapping between contextually similar regions in two different scenes, which is necessary for applications like trajectory transfer in AR/VR and long demonstration transfer for imitation learning but has no prior formulation or solution.
![Teaser figure](../imgs/ICCV20250700/cropped_page0_idx2.webp)

## Input / Output

The method takes sparsely sampled 3D keypoints (via farthest point sampling) with per-object semantic labels, scene corner points (from floorplans or convex hulls), and a user-defined region of interest (RoI) as surface points of an object group. It outputs a dense map F: conv(S_tgt) → conv(S_ref) defined over the entire convex hull of the scene, decomposed into a global affine transform plus local radial-basis-function displacements, enabling queries at any arbitrary 3D point rather than only at input keypoints. Downstream, the map is applied to transfer motion trajectories (via direct point mapping or A* path planning on transferred waypoints) and object placements between scenes.

## Method

The core architecture is a Transformer-based context descriptor field that, for any query point, gathers nearby keypoints within a fixed radius and encodes them via learned distance and semantic embeddings as tokens, producing a fixed-dimension feature vector through a [CLS] token. Fields are trained with InfoNCE contrastive loss on procedurally generated triplets (source, positive with same-label object swaps, negative with pose noise), eliminating the need for densely annotated ground truth. Map estimation follows a coarse-to-fine strategy: a pool of candidate affine maps is generated by combinatorially pairing object centroids with sampled rotations/reflections, top-K are selected by descriptor-field alignment cost and refined via gradient descent, then local displacements parameterized as thin-plate-spline radial basis functions centered at RoI points are optimized to capture non-linear regional alignment. This holistic field-alignment approach reduces dependence on individual keypoints, yielding robustness to noisy scans, shape variations, and cross-domain (sim-to-real) gaps.

## Results

On 3D-FRONT procedurally generated scene pairs, the method achieves PCP@0.50 = 0.90, Bijectivity PCP@0.50 = 0.94, and Chamfer Accuracy@0.20 = 0.99, outperforming the strongest baseline (3D Point Feature Field) by 19, 26, and 10 percentage points respectively. On ARKitScenes (noisy real scans), the method similarly leads with PCP@0.50 = 0.90 and Bijectivity PCP@0.50 = 0.94 on procedural pairs, and Bijectivity PCP@0.50 = 0.62 on manually collected pairs. The method also demonstrates cross-domain capability, producing reliable sim-to-real and real-to-sim mappings between 3D-FRONT and ARKitScenes using a single set of descriptor fields.

## Baselines & Comparisons

The method decisively outperforms all four baselines across every metric on both 3D-FRONT and ARKitScenes. The closest competitor, 3D Point Feature Field (Wang et al., CoRL 2024), which uses Vector Neuron features with the same coarse-to-fine map estimation, trails by 19 points on PCP@0.50 and 26 points on Bijectivity PCP@0.50 on 3D-FRONT procedural pairs, indicating that the contrastive-learning-trained descriptor fields are substantially more discriminative than pre-trained 3D keypoint features. Visual Feature Field (Wang et al., ICLR 2024), which back-projects DINOv2 features from renderings, is competitive on Chamfer Accuracy (0.86 vs. 0.99) but lags significantly on point-level metrics (PCP@0.50: 0.66 vs. 0.90). Scene Graph Matching (Wald et al., CVPR 2020) and Multi-view Semantic Correspondence (El Banani et al., CVPR 2024) perform poorly on point-level accuracy (PCP@0.50: 0.42 and 0.20 respectively) because they reduce objects to sparse nodes or 2D correspondences, lacking the geometric granularity needed for dense scene-region mapping. On manually collected pairs (which include negative examples with no common object groups), the method maintains the largest margin over baselines on Bijectivity PCP, confirming its ability to correctly reject unmappable regions.

## Relation to Prior Work

This paper carves new ground by defining the 3D scene analogy task—estimating dense, smooth maps between scene regions sharing similar spatial contexts—which sits between instance-level dense matching (Neural Surface Maps, blended intrinsic maps) and group-level scene graph matching. Methodologically, it repurposes Transformer-based neural descriptor fields (analogous to neural descriptor fields for manipulation) but trains them via contrastive learning on procedurally generated triplets rather than supervised correspondence labels, and combines them with a classical coarse-to-fine map estimator (affine + thin-plate spline radial basis functions). The approach departs from scene graph methods by operating on continuous spatial regions including open space, and from foundation-model-based matching (DINOv2, Vector Neurons) by learning lightweight context-aware embeddings from sparse keypoints with semantic labels.

## Why It Matters / Open Questions

The task formulation opens practical pathways for trajectory transfer in AR/VR telepresence, long demonstration transfer for robot imitation learning, and context-aware object rearrangement—applications where scene-level spatial coherence matters more than individual object matching. Key limitations include the single-mapping output (no multi-modal correspondences for symmetric scenes), sensitivity to object position swaps that disrupt the affine initialization, and evaluation grounded in semantic/geometric similarity that may not align with all downstream task objectives. The sim-to-real capability is promising but tested only on indoor scenes, and the 'contrived' baselines (adapted pipelines rather than purpose-built competitors) leave room for stronger future comparisons.

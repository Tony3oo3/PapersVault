## Problem

Existing CLIP-based OOD detection methods focus on learning OOD-related knowledge—such as negative prompts, exposed outliers from ID images, or external auxiliary datasets—to improve detection, but these approaches show limited generalization to the infinite variety of real-world OOD data or incur significant resource overhead. The paper instead asks whether OOD detection can be improved by fully exploiting ID knowledge, i.e., by making the model better at recognizing in-distribution images rather than explicitly modeling what OOD looks like.

## Input / Output

The method takes RGB images encoded by CLIP's ViT-B/16 image encoder and produces both a class label (via the forced prompt for ID classification) and an OOD detection score computed as the maximum softmax-normalized cosine similarity between the image feature and the combined text features of both the forced and original prompts. Training requires only few-shot ID samples (1, 4, or 16 per class) with no external OOD data, and the score function can be flexibly swapped between MCM (global features only) and GL-MCM (global plus local patch features).

## Method

FA introduces a learnable forced prompt alongside a frozen original prompt, both initialized identically with the manual template 'a photo of a [class-c]' and sharing a single learnable vector across all classes (matching CoOp's parameter count). The key training signal is a forced cross-entropy (FCE) loss whose denominator includes both the forced prompt's and the original prompt's text-feature similarities, compelling the forced prompt to achieve strictly higher cosine similarity with ID image features than the original prompt—thereby learning richer, more diversified descriptions of ID classes beyond the class-label semantics. A forced coefficient K (set to 3) multiplies the original prompt's contribution in the denominator, further intensifying the pressure on the forced prompt to capture comprehensive connotations. At inference, the MCM or GL-MCM score normalizes similarities against both prompt sets, so OOD images—which lack the specific ID-class information the forced prompt has learned—receive lower scores, enabling effective ID/OOD separation without any external OOD data.

## Results

On the ImageNet-1k OOD benchmark (16-shot), FA_GL achieves an average FPR95 of 25.68% and average AUROC of 93.82%, outperforming the best baseline SCT_GL (27.27% FPR95, 93.31% AUROC). In the more challenging 1-shot setting, FA_GL reduces average FPR95 from 31.62% (SCT_GL) to 27.81% and improves average AUROC from 92.01% to 93.26%. On cleaner OOD datasets (OpenImage-O, NINCO, ImageNet-O), FA consistently outperforms all baselines in both FPR95 and AUROC. ID classification accuracy is preserved, with FA achieving 71.02% Top-1 on ImageNet-1k (16-shot) comparable to SCT (71.78%) and CoOp (70.99%).

## Baselines & Comparisons

FA_GL outperforms SCT_GL (NeurIPS 2024), the strongest OOD-knowledge-based baseline, by 1.59% in FPR95 and 0.51% in AUROC on the 16-shot ImageNet-1k benchmark, with a larger gap of 3.81% FPR95 and 1.25% AUROC in the 1-shot setting. Against LoCoOp_GL, which uses entropy maximization to separate ID text embeddings from local region embeddings, FA_GL achieves comparable FPR95 (25.68% vs. 18.46% in 16-shot) but substantially higher AUROC (93.82% vs. 95.15%), though LoCoOp_GL's lower FPR95 is partly due to its different score function calibration. FA_MCM surpasses SCT_GL even without the GL-MCM score function in the 1-shot setting (94.29% vs. 92.01% AUROC), demonstrating that the forced prompt learning itself provides strong OOD discrimination. Compared to IDLike (CVPR 2024), which constructs ID-like OOD samples, FA_GL achieves 1.13% lower FPR95 and 0.73% higher AUROC in 16-shot. Against zero-shot baselines MCM and GL-MCM, FA_GL improves FPR95 by 16.93% and 9.37% respectively in 16-shot, while CLIPN (which uses external OOD data) achieves 30.21% FPR95 in 1-shot versus FA_GL's 27.81%. FA maintains ID Top-1 accuracy (71.02%) on par with CoOp (70.99%) and SCT (71.78%), confirming that the forced prompt does not degrade classification performance.

## Relation to Prior Work

This paper builds directly on CoOp's prompt learning framework for CLIP, maintaining the same parameter budget (shared learnable vector + class label tokens) while introducing a second, trainable 'forced prompt' alongside a frozen original prompt. It deliberately departs from the dominant paradigm in CLIP-based OOD detection—where methods like SCT, LoCoOp, IDLike, NegPrompt, and LSN all learn OOD-related knowledge (negative prompts, exposed outliers, external OOD datasets)—by instead enriching ID knowledge through a forced cross-entropy loss that compels the prompt to capture richer semantic descriptions of ID classes. The conceptual motivation draws from open-set recognition literature showing that improving closed-set discrimination can improve open-set detection, applied here to the VLM setting.

## Why It Matters / Open Questions

The paper demonstrates that SOTA OOD detection is achievable without any external OOD data, negative prompts, or auxiliary datasets—only by making the model better at recognizing what IS in-distribution. This simplifies the practical pipeline and reduces resource overhead compared to methods requiring large-scale auxiliary datasets. However, the performance gains over the strongest baseline (SCT) are modest (e.g., ~3.8% FPR95 improvement in 1-shot), and the authors note a bottleneck in the forced coefficient K, suggesting the mechanism has limited capacity to capture ever-more-comprehensive ID semantics. Open questions include whether the forcing mechanism generalizes to other VLMs beyond CLIP, to larger backbones, and whether the approach extends naturally to multi-modal or video OOD detection.

## Problem

Existing remote sensing segmentation methods rely on implicit representation learning that cannot dynamically adjust class-specific semantic embeddings to contextual cues, leading to confusion among morphologically similar categories (e.g., thin vs. thick clouds, farmland vs. grassland). This limitation is especially pronounced in fine-grained scenarios where subtle intra-class heterogeneity and inter-class homogeneity degrade segmentation accuracy.
![Teaser figure](../imgs/ICCV20250463/cropped_page0_idx0.webp)

## Input / Output

The method accepts a single RGB remote sensing image (UAV or satellite) and outputs a per-pixel semantic segmentation mask of shape N×H×W, where N is the number of semantic classes. During training, a dual-branch architecture processes the same encoder features through both a static and a dynamic dictionary path; at inference, only the dynamic branch is used. The backbone (ConvNeXt-Base) produces four multi-scale feature maps that are aggregated into a single C′×H′×W′ tensor before dictionary interaction.

## Method

The framework explicitly models class ID embeddings as a learnable dictionary and refines them per-input via a modulator that generates an attention map from high-level encoder features (dual-branch GAP/GMP + MLP + softmax), converting a static dictionary into a dynamic one. In the decoder, the dynamic dictionary and image features alternately perform cross-attention queries over L=3 stages, progressively updating both representations. A contrastive loss (intra-class compactness divided by inter-class dispersion) is applied to the dictionary embeddings to enforce tight within-class clusters and wide between-class separation. Training jointly optimizes a static branch (fixed dictionary, standard CE+Dice loss) and a dynamic branch (updated dictionary, CE+Dice+contrastive loss) with a weighted total loss (λ_static=0.4, λ_dynamic=1).

## Results

The proposed dynamic dictionary learning framework achieves state-of-the-art performance across all six remote sensing segmentation benchmarks. On coarse-grained datasets, it reaches 55.3 mIoU on LoveDA (+0.4 over SFA-Net), 70.9 mIoU on UAVid (+0.5), and 94.7/91.9 mF1 on Potsdam/Vaihingen. On fine-grained datasets, it achieves 66.27 mF1 on Grass (+0.51 over SFA-Net) and 89.65 mF1 on Cloud (+5.01 over SFA-Net, +18.29 over HRCloudNet), demonstrating particularly strong gains in distinguishing morphologically similar classes.

## Baselines & Comparisons

The method outperforms all 26 baselines across every dataset and metric. The closest competitor is SFA-Net [24], which the method surpasses by +0.4 mIoU on LoveDA, +0.5 mIoU on UAVid, +0.9/+0.7 mF1 on Potsdam/Vaihingen, +0.51 mF1 on Grass, and a substantial +5.01 mF1 on Cloud. Among Transformer-based baselines, UNetFormer [46] (52.4 mIoU LoveDA, 67.8 mIoU UAVid) and AerialFormer [20] (54.1 mIoU LoveDA) trail by 2.9 and 1.2 mIoU respectively on LoveDA. On the fine-grained Cloud dataset, the gap widens dramatically: the method's 89.65 mF1 exceeds the previous best (SFA-Net, 84.64) by 5 points and HRCloudNet [26] (71.36) by nearly 19 points, highlighting the dynamic dictionary's advantage in resolving subtle cloud-thickness variations. On Grass, the method edges out KTDA [53] (65.01) and SFA-Net (65.76) with 66.27 mF1, while all classical baselines (FCN, PSPNet, DeepLabV3+, UNet, SegFormer, Mask2Former, DINOv2) remain 3–8 points below. On Potsdam/Vaihingen, the method sets new records at 94.7/91.9 mF1, surpassing AerialFormer (94.1/90.1) and SFA-Net (93.5/91.2), with the largest margin over Segmenter [41] (89.2/84.1) and DANet [17] (88.9/79.6).

## Relation to Prior Work

This paper repurposes the DETR/MaskFormer paradigm of learnable class queries interacting with image features, but transplants it into remote sensing semantic segmentation with two key departures: (1) a modulator that converts a static class-embedding dictionary into an input-specific dynamic one via attention maps from high-level features, and (2) a contrastive loss applied directly to the dictionary space to enforce intra-class compactness and inter-class separability. Conceptually, it sits between the CNN-Transformer hybrid segmentation methods (UNetFormer, AerialFormer, SFA-Net) that dominate the remote sensing literature and the explicit query-based approaches from detection, arguing that implicit representation learning in existing segmentation decoders is insufficient for fine-grained morphological distinctions. The contrastive constraint on class embeddings draws from CLIP-style representation learning but is applied at the dictionary level rather than the feature level.

## Why It Matters / Open Questions

The dynamic dictionary learning framework offers a principled mechanism for making class representations input-adaptive, which is particularly relevant for fine-grained remote sensing scenarios (thin vs. thick clouds, coverage-grade grassland) where a single fixed embedding per class is too rigid. However, the practical gains are modest on most benchmarks (0.4–0.5 mIoU), and the largest improvement (+5 mF1 on Cloud) may reflect dataset-specific sensitivity rather than a general breakthrough. Open questions include whether the iterative cross-attention decoder scales efficiently to very high-resolution imagery, whether the approach transfers beyond remote sensing to other fine-grained domains (medical, industrial), and whether the dynamic dictionary can be distilled into a lighter inference-time mechanism without the L-stage interaction loop.

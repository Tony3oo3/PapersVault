## Problem

Building generalist GUI agents is hindered by three interrelated issues: existing GUI interaction datasets lack sufficient scale and scenario diversity, heterogeneous action spaces across datasets complicate multi-task training, and no unified framework exists to effectively merge multiple data sources. These limitations prevent VLM-based agents from achieving robust, cross-platform GUI interaction.
![Teaser figure](../imgs/ICCV20251424/cropped_page0_idx0.webp)

## Input / Output

UIPro consumes a variable-resolution GUI screenshot (processed via an image-division strategy for any resolution), a natural-language user task, and the accumulated action history as input. It produces a predicted next action formatted as a JSON object containing the action type and its arguments (e.g., coordinates normalized to [0,1000], direction, distance), with the action vocabulary unified per platform (mobile, web, desktop). For grounding sub-tasks, the output is a single (x, y) point expected to fall within the target element's bounding box.

## Method

UIPro is a standard VLM (ViT visual encoder + projector + LLM backbone, instantiated as 3B SLiME-Gemma2B or 7B Qwen2-VL) trained in two stages. Stage 1 pre-trains on a newly curated 20.6M-sample, multi-platform GUI understanding dataset (13 task types including element grounding, functionality grounding, icon grounding, OCR, widget listing, and GUI Q&A) to establish strong element-localization capability; a systematic denoising pipeline removes blank, invisible, and invalid-bounding-box elements from raw sources. Stage 2 fine-tunes on merged heterogeneous agent-task datasets (380k mobile + 145k web samples from six and three sources respectively) using a proposed unified action space that resolves naming conflicts (e.g., swipe vs. scroll), standardizes arguments into a common superset definition, and formats all ground truths in a single JSON schema, enabling effective multi-source multi-task learning without per-source action-space fragmentation.

## Results

On the AITW mobile benchmark, UIPro-Qwen2VL (7B) achieves 70.4% overall Step SR, surpassing GPT-4V-OmniParser (57.7%) and OS-ATLAS (63.1%) by 12.7 and 7.3 points respectively. On Multimodal-Mind2Web, UIPro-Qwen2VL reaches 48.4% Step SR on Cross-Task, 43.6% on Cross-Website, and 45.5% on Cross-Domain, outperforming OS-ATLAS (36.7/35.7/37.2) and GPT-4V+SoM (32.7/23.7/20.3). On GUI grounding, UIPro-Qwen2VL attains 86.9% on ScreenSpot-v2, 81.9% on RefExp, and 94.9% on VisualWebBench Element Grounding, exceeding OS-ATLAS by 2.8, 15.4, and 12.3 points respectively. The 3B UIPro-SLiME variant also outperforms all open-source baselines of equal or larger size across all benchmarks.

## Baselines & Comparisons

UIPro-Qwen2VL (7B) outperforms all compared methods on AITW by a wide margin: it beats GPT-4V-OmniParser (57.7%) by 12.7 points, OS-ATLAS (63.1%) by 7.3 points, and SeeClick (59.3%) by 11.1 points in overall Step SR. On AndroidControl, UIPro-Qwen2VL achieves 85.5% Step SR (High-Low setting), surpassing OS-ATLAS (62.4%) by 23.1 points; the 3B UIPro-SLiME also exceeds ShowUI (29.5%) by 31.6 points. On GUIAct, UIPro-Qwen2VL reaches 69.1% web Step SR versus GPT-4o's 41.8% and Qwen2-VL's 23.6%, while UIPro-SLiME (3B) achieves 68.2% web Step SR, nearly matching the 7B model. On Multimodal-Mind2Web, UIPro-Qwen2VL leads all open-source and proprietary baselines across all three splits (Cross-Task 48.4%, Cross-Website 43.6%, Cross-Domain 45.5%), exceeding OS-ATLAS by 11.7, 7.9, and 8.3 points respectively. On GUI grounding, UIPro-Qwen2VL dominates RefExp (81.9% vs. OS-ATLAS 66.5%) and VisualWebBench EG (94.9% vs. 82.6%), while UIPro-SLiME (3B) surpasses the 18B CogAgent on ScreenSpot (60.7% vs. 47.4%) and MOTIF (73.3% vs. 46.7%). UIPro does not lose to any baseline on any reported metric in the main results tables.

## Relation to Prior Work

UIPro extends the VLM-based GUI agent lineage (SeeClick, CogAgent, OS-ATLAS, Ferret-UI) by addressing two practical bottlenecks: insufficient data scale and heterogeneous action spaces across training sources. Architecturally it follows the standard LLaVA-style ViT + projector + LLM design, but its core methodological departure is the unified action space that defines a superset of action definitions to merge previously incompatible trajectory datasets (AITW, AndroidControl, GUIAct, Mind2Web, WebLINX). The 20.6M-sample GUI understanding dataset also builds on prior GUI data efforts (RICO, WebUI, GUICourse, OS-ATLAS) but substantially exceeds them in scale, task diversity (13 task types), and platform coverage, while introducing a systematic denoising pipeline absent from prior collections.

## Why It Matters / Open Questions

The publicly released 20.6M GUI understanding dataset and the unified action space recipe provide the community with both the largest open-source grounding resource and a practical template for integrating multi-source agent data, lowering the barrier to training competitive GUI agents. The denoising procedure (revealing up to 29% noise in one source) is a useful community contribution that prior work overlooked. Limitations include the focus on mobile and web platforms (desktop data remains sparse), the reliance on existing base VLMs rather than novel architectures, and the observation that long-tailed actions (drag, hotkey) still suffer from data scarcity. Open questions include whether the unified action space generalizes to entirely new platforms without re-annotation and whether the grounding-to-agent-task correlation holds at even larger scales.

## Problem

State-of-the-art long-tailed anomaly detection (LTAD) methods are class-aware, requiring class labels that are unavailable in realistic online learning settings where data arrives as a stream. Meanwhile, existing online anomaly detection methods do not account for long-tailed class distributions, where head and tail classes can exhibit significant performance gaps. This paper introduces the long-tailed online anomaly detection (LTOAD) task and a class-agnostic framework that bridges both gaps.
![Teaser figure](../imgs/ICCV20250343/cropped_page1_idx3.webp)

## Input / Output

The method takes a single RGB image (H×W×3) as input without any class label, computing a soft concept score p ∈ [0,1]^(K̂) by measuring cosine similarity between the image's final visual embedding and learnable concept embeddings. It produces both a pixel-level anomaly segmentation map (H×W) via the harmonic mean of reconstruction and semantics branch predictions, and a scalar detection score obtained by reducing the map through AvgPool2d (kernel 16) followed by max. In the online setting, images arrive sequentially in batches of size Δ, and the model is updated at each step using an anomaly-adaptive algorithm with EMA smoothing.

## Method

LTOAD replaces hard class labels with a learned concept set Ĉ (|Ĉ| = K̂ < K) initialized via zero-shot majority voting over a foundation model's vocabulary, then refined with learnable embeddings. A soft switching mechanism composes concept-specific submodules weighted by the per-image concept score, enabling class-agnostic inference. The reconstruction branch uses a Concept-VQ (hierarchical vector-quantization VAE with concept-specific codebooks initialized around concept embeddings) plus a prompt-conditioned generator for pseudo-normal/abnormal feature augmentation. The semantics branch compares similarity maps between projected visual features and learnable normal/abnormal prompt features (multiple concept-specific abnormal prompts generated via conversational AI). For online learning, the proposed Anomaly Adaptive algorithm A^AA computes pseudo-abnormal maps from model predictions to modulate loss weighting (higher weight β for likely-abnormal samples) and applies EMA for stable parameter updates, mitigating overfitting on head classes and forgetting of tail classes.

## Results

On the offline MVTec long-tailed benchmark (exp100), LTOAD achieves 93.42% image-level AUROC for detection and 95.21% pixel-level AUROC for segmentation, outperforming the best class-aware baseline LTAD (88.86% Det.) by +4.56% without requiring class labels. Across all four MVTec settings, LTOAD gains +4.63% on detection and +0.58% on segmentation versus the second-best baseline. On the online MVTec benchmark (Table 4), LTOAD with the proposed Anomaly Adaptive algorithm A^AA achieves 95.28% average pixel-level AUROC for segmentation across 8 stream configurations, outperforming HVQ with naive online learning (95.23%) and LTAD with naive online learning (93.84%), while remaining class-agnostic.

## Baselines & Comparisons

LTOAD (class-agnostic) decisively outperforms all baselines on MVTec detection: it beats LTAD (88.86%) by +4.56%, HVQ (87.43%) by +5.99%, UniAD (87.70%) by +5.72%, and MoEAD (84.73%) by +8.69% on exp100 image-AUROC, all without requiring class labels or the number of classes. On segmentation, LTOAD leads by a smaller margin (+0.75% over HVQ on exp100) but still wins across all four imbalance settings. On VisA, the detection gap is similarly large (+5.26% over LTAD on exp100), while segmentation gains are more modest (+0.73% over HVQ). In the online setting (Table 4), LTOAD with A^AA (95.28% avg) narrowly edges out HVQ with naive online learning A^N (95.23%) and substantially outperforms LTAD with A^N (93.84%), while being the only method that does not require class labels during online updates. The class-aware variant LTOAD* confirms that the concept-based soft switching itself (not just class-agnosticism) drives the gains, as LTOAD* already surpasses LTAD by +4.26% on exp100 Det.

## Relation to Prior Work

This paper builds directly on LTAD (Ho et al., CVPR 2024), adopting its two-branch reconstruction-plus-semantics pipeline, and on HVQ (Lu et al., NeurIPS 2023), whose class-specific hierarchical vector-quantization modules are repurposed as concept-specific modules. The key conceptual departure is replacing hard class-label switching with a soft, learned concept set that approximates the true class set without requiring class names or counts, thereby enabling the framework to operate in the online setting where such labels are unavailable. The paper also extends the prompt-learning paradigm from prior VLM-based AD works by introducing learnable, concept-specific, multiple abnormal prompts initialized via a conversational AI, going beyond the single shared prompts used in most prior methods.

## Why It Matters / Open Questions

The LTOAD benchmark addresses a realistic deployment gap: industrial and medical AD systems must handle uneven class distributions and adapt to new data streams without knowing class identities in advance. The finding that a class-agnostic model can outperform class-aware SOTA by over 4% on MVTec detection challenges the assumption that explicit class information is always beneficial, suggesting that soft concept composition enables useful knowledge sharing across classes. Open questions include how the approach scales when the true number of classes far exceeds the concept set size, whether the modest online gains (+0.53%) grow with longer streams or more diverse data, and whether the reliance on a specific foundation model (ALIGN) limits generalizability to domains with very different visual semantics.

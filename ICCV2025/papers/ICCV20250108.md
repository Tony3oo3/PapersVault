## Problem

Applying SAM2 to 360° panoramic semantic segmentation faces two unresolved challenges: the large field-of-view gap between pinhole (70°×70°) and panoramic (180°×360°) images introduces severe distortion and object deformation that complicates cross-domain feature alignment, and SAM2 inherently produces instance-level masks without the pixel-level semantic class knowledge required for semantic segmentation. No prior work has adapted SAM2 to the unsupervised domain adaptation setting for panoramic semantic segmentation.
![Teaser figure](../imgs/ICCV20250108/cropped_page2_idx0.webp)

## Input / Output

Both source pinhole and target panoramic RGB images are consumed as overlapping sequences of 1024×1024 square patches generated by a sliding window (9 frames per image, with stride varying from 128 to 384 px depending on original resolution). The model outputs a fixed-class per-pixel semantic segmentation mask without requiring any external prompts (points or boxes), unlike vanilla SAM2. Panoramic inputs in equirectangular projection are first cropped to remove black border regions before patching.

## Method

OmniSAM fine-tunes SAM2's Hiera image encoder via LoRA on query/value layers (<3 MB trainable parameters) and replaces the prompt-based mask decoder with a semantic decoder that fuses multi-scale embeddings (high, medium, and memory-conditioned low) through linear projections, spatial upsampling, and a convolutional fusion head. The key architectural insight is treating the sliding-window patch sequence as a video frame sequence, so SAM2's memory encoder and memory attention mechanism naturally capture cross-patch correspondences and enforce prediction consistency along mask boundaries. For domain adaptation, the FoV-based Prototypical Adaptation (FPA) module computes per-frame class prototypes from the fused decoder features and aligns target prototypes to iteratively updated global source prototypes (from a frozen source model) via MSE loss. A dynamic pseudo-label updating mechanism processes each target image bidirectionally (forward and backward patch order), aggregates overlapping patch predictions, and assigns a pixel a class only if all overlapping patches unanimously agree and the minimum confidence exceeds a threshold, with pseudo-labels refreshed each epoch on a small random subset.

## Results

On the indoor Pin2Pan benchmark (SPin8-to-SPan8), OmniSAM-L with memory attention achieves 79.06% mIoU, surpassing the previous best 360SFUDA++ (68.84%) by 10.22%. On the outdoor Pin2Pan benchmark (CS13-to-DP13), OmniSAM-B with memory attention reaches 62.46% mIoU, outperforming DTA4PASS (57.16%) by 6.58%. In the Syn2Real scenario (SP13-to-DP13), OmniSAM-B with memory attention achieves 54.61% mIoU, edging out DATR-S with CFA (54.05%) by 0.56%. All OmniSAM variants use fewer than 26MB of trainable parameters via LoRA fine-tuning of the SAM2 backbone.

## Baselines & Comparisons

OmniSAM outperforms all seven baselines across all three evaluation scenarios. On SPin8-to-SPan8, OmniSAM-L w/ MA (79.06%) beats 360SFUDA++ (68.84%) by 10.22% and Trans4PASS+-S (67.16%) by 11.90%. On CS13-to-DP13, OmniSAM-B w/ MA (62.46%) surpasses DTA4PASS (57.16%, multi-source domain adaptation) by 5.30%, DATR-S with CFA (55.88%) by 6.58%, and Trans4PASS+-S (55.24%) by 7.22%. On SP13-to-DP13, OmniSAM-B w/ MA (54.61%) edges out DATR-S with CFA (54.05%) by 0.56% and Trans4PASS+-S (50.88%) by 3.73%, though the margin is smaller in this Syn2Real setting. Notably, even without memory attention, OmniSAM-S/B/L variants already surpass DATR-S on CS13-to-DP13, indicating the SAM2 backbone itself provides strong cross-domain generalization. The PVT-based baselines (Trans4PASS, Trans4PASS+, PVT) are consistently outperformed, suggesting the Hiera encoder with LoRA fine-tuning is a significant advantage over the PVT backbone used in prior panoramic UDA methods.

## Relation to Prior Work

This paper repurposes SAM2's video-segmentation memory mechanism for a spatial problem: by cropping panoramic and pinhole images into overlapping patch sequences via a sliding window, it treats cross-patch dependencies as pseudo-temporal ones, a conceptual departure from prior panoramic UDA methods (Trans4PASS, DATR, 360SFUDA++) that forward entire ERP images as if they were pinhole frames. The FoV-based Prototypical Adaptation module extends the prototypical alignment line of work to the patch/FoV level, and the dynamic pseudo-label updating strategy addresses a known weakness of static pseudo-labeling in iterative adaptation. The backbone is SAM2's Hiera encoder fine-tuned with LoRA, following the broader trend of adapting foundation-model encoders to dense prediction tasks.

## Why It Matters / Open Questions

This is the first demonstration that SAM2's architecture can be effectively adapted to panoramic semantic segmentation, opening a path for foundation-model backbones in the 360° domain where the large FoV gap (70°×70° vs. 180°×360°) has historically required task-specific distortion-aware designs. The sliding-window-plus-memory approach is a practical recipe that could transfer to other wide-FoV or multi-view segmentation settings. However, the Syn2Real scenario (SP13-to-DP13) still shows only modest gains, and the Large/Base variants' parameter counts (209M/72M) limit real-time deployment, leaving open the question of whether the memory mechanism's benefits can be achieved at Tiny/Small scale without sacrificing the cross-patch consistency it provides.

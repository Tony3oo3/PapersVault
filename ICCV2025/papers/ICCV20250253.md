## Problem

Diffusion Transformers rely on quadratic scaled dot-product attention, which becomes a severe computational bottleneck for high-resolution image generation and deployment on resource-constrained devices. Existing linear attention alternatives either fail when applied to DiTs (LinFusion) or require complex architectural modifications (SANA's MixFFN), and no prior work addresses the joint attention in Multimodal DiTs where image and prompt tokens are processed together.
![Teaser figure](../imgs/ICCV20250253/cropped_page2_idx0.webp)

## Input / Output

The method takes a text prompt as input and produces a photorealistic RGB image as output, operating at resolutions from 512×512 up to 8192×8192. In the MM-EDiT variant, the model jointly processes image latent tokens and prompt tokens within a single attention layer, with the number of image tokens typically far exceeding prompt tokens. The distilled models are evaluated on the PixartEval30K benchmark using CLIP similarity and FID metrics at multiple resolutions.

## Method

EDiT replaces self-attention in DiTs with a linear compressed attention mechanism: queries are processed through ConvFusion, a multi-layer 2D convolutional network (group normalization → 3×3 conv → LeakyReLU → 1×1 conv → linear → ReLU) that integrates local spatial information, while keys and values are spatially compressed via a Spatial Compressor (linear projection followed by 3×3 depthwise convolution with stride 2, reducing token count by 4×). For Multimodal DiTs, MM-EDiT introduces a hybrid attention that applies this linear compressed attention only to the image-to-image block (the quadratic bottleneck) while retaining standard scaled dot-product attention for all text-related interactions, achieving linear-time complexity in image size. The models are trained via knowledge distillation from teacher checkpoints (PixArt-Σ and SD-v3.5-Medium) using a combined loss of task prediction, knowledge distillation, and per-layer feature distillation, followed by progressive resolution fine-tuning.

## Results

On PixartEval30K, EDiT (distilled from PixArt-Σ) achieves an Inception-v3 FID of 7.06 at 512×512 and 7.82 at 1024×1024, matching or exceeding the teacher model (7.57 and 7.09 respectively) while delivering up to 2.2× speedup. At 2048×2048, EDiT produces comparable quality (FID 8.29 vs 7.48) with a 2.5× latency reduction, and at 8192×8192 it is 43× faster than PixArt-Σ (1.69 s vs 72.96 s). For the multimodal setting, MM-EDiT (distilled from SD-v3.5M) reaches FID 11.60 at 512×512 and 9.73 at 1024×1024, closely tracking the teacher (10.49 and 8.83) while being 9× faster at 4096×4096 resolution.

## Baselines & Comparisons

EDiT outperforms SANA-DiT by 2.6 Inception-v3 FID points at 512×512 (7.06 vs 8.43) and by 1.5 points at 1024×1024 (7.82 vs 9.31), while also being faster at higher resolutions. Against LinFusion-DiT, the gap is dramatic: EDiT achieves 7.06 FID versus 15.87 at 512×512 (8.8 points better) and 7.82 versus 44.66 at 1024×1024, indicating LinFusion's kernel feature maps fail to transfer to DiT architectures. EDiT also beats the KV token compression baseline (PixArt-Σ's own strategy) by 2.5 FID points at 512×512 (7.06 vs 10.69), showing that integrating spatial compression into linear attention is more effective than compressing keys/values within quadratic attention. Compared to its teacher PixArt-Σ, EDiT is slightly better at 512×512 (7.06 vs 7.57 FID) but marginally worse at 1024×1024 (7.82 vs 7.09), confirming near-lossless distillation. In the multimodal setting, MM-EDiT outperforms all fully-linear alternatives (SANA-MM-DiT, Linear MM-DiT-α, Linear MM-DiT-β) by 1.3–9.4 FID points, validating the hybrid attention design that reserves scaled dot-product attention for text interactions.

## Relation to Prior Work

This paper unifies three previously separate ideas for efficient DiTs into a single architecture: LinFusion's multi-layer non-linear query transformations, SANA's convolutional local-information modules, and PixArt-Σ's depthwise-convolution KV token compression. The key conceptual departure is integrating spatial compression into linear attention (rather than scaled dot-product as in PixArt-Σ) and, for MM-DiTs, proposing a hybrid attention that applies linear attention only to the dominant image-to-image block while retaining scaled dot-product for text interactions. This positions EDiT/MM-EDiT as a synthesis that outperforms each individual prior approach (SANA-DiT, LinFusion-DiT, KV Comp) when distilled into the same base models.

## Why It Matters / Open Questions

The practical impact is significant for edge and high-resolution deployment: EDiT achieves 43× speedup over PixArt-Σ at 8192×8192 and runs in under 1 second on a Snapdragon 8 Elite phone, opening the door to on-device high-resolution generation. However, the hybrid attention's text-image cross-interactions remain a bottleneck on-device, and the paper acknowledges that SANA's fully linear approach is still faster (albeit lower quality), leaving open the question of whether a truly efficient hybrid is possible. The finding that a simple token-count approximation for the normalization factor outperforms the theoretically exact computation is a useful practical insight but also hints at fragility in the hybrid formulation.

## Problem

Existing video instance segmentation methods struggle to maintain consistent object identities over long videos, particularly when objects temporarily disappear and reappear or when new objects enter the scene. Cross-frame attention trackers rely solely on the previous frame, memory-based approaches suffer from mixed representations causing ID switches, and newly appearing objects are forced to map to background indices, creating an unnatural learning conflict that degrades tracking accuracy.
![Teaser figure](../imgs/ICCV20252000/cropped_page1_idx0.webp)

## Input / Output

The method processes video frames sequentially through a frozen Mask2Former segmentation network (with R50, Swin-L, ViT-L, or ViT-H backbones pre-trained on COCO) that produces N object queries, categorical probabilities, and segmentation masks per frame. The tracking module then operates online, consuming the per-frame segmentation outputs and an internal memory buffer to produce temporally aligned object features, consistent identity assignments, and final segmentation masks. The system maintains a fixed set of N object slots throughout the video, with an occupancy vector tracking which slots have been claimed by foreground objects.

## Method

LOMM introduces two key components: (1) Latest Object Memory (LOM), which updates stored object features at each frame using a foreground-probability-weighted exponential moving average, ensuring the memory always reflects the most recent state of each tracked object rather than a blurred aggregate; and (2) Decoupled Object Association (DOA), which splits object matching into two stages—first tracking existing objects against memory via a dedicated tracker T_E, then assigning unoccupied indices to newly appeared objects via Occupancy-guided Hungarian Matching (OHM) that prevents new objects from being matched to already-occupied slots. A second tracker T_A refines all object features using an adaptive anchor query that blends the current aligned objects with past memory via cosine-similarity-weighted interpolation. Training employs a phased strategy where the first half of iterations uses Hungarian matching on pre-trained segmentation outputs for ground truth assignment, stabilizing early learning before the full DOA pipeline takes over.

## Results

On YouTube-VIS 2022 (the most challenging long-video benchmark), LOMM with a ViT-L backbone achieves 54.0 AP in offline mode and 48.2 AP in online mode, surpassing the previous best (DVIS++ offline at 50.9 AP) by +3.1 AP. With a ResNet-50 backbone, LOMM reaches 41.1 AP on YTVIS22, outperforming DVIS++ (37.2 AP) by +3.9 AP. On the OVIS benchmark, LOMM sets new state-of-the-art with 52.9 AP (ViT-H) and 51.7 AP (ViT-L), exceeding DVIS++ by +2.1 AP and UNINEXT by +3.9 AP.

## Baselines & Comparisons

LOMM consistently outperforms all 12 baselines across every evaluated dataset. Against the strongest prior online method DVIS++ (R50), LOMM gains +1.8 AP on YTVIS19, +2.2 AP on YTVIS21, and +3.1 AP on YTVIS22, with the gap widening on longer videos. Against DVIS-DAQ (ViT-L), which specifically targets newly appearing/disappearing objects, LOMM achieves +0.8, +2.6, and +6.2 AP on YTVIS19/21/22 respectively, demonstrating superior long-term identity consistency. On OVIS, LOMM (ViT-L) surpasses CTVIS by +0.9 AP and DVIS++ by +2.1 AP, while LOMM (ViT-H) beats UNINEXT by +3.9 AP. In offline mode with ViT-L, LOMM* reaches 54.0 AP on YTVIS22, exceeding DVIS++* (50.9 AP) by +3.1 AP. The computational cost remains competitive: LOMM uses only 9.88M tracker parameters (vs. 26.78M for DVIS++) with ~10 ms/frame overhead over DVIS, while delivering +7.2 AP.

## Relation to Prior Work

LOMM builds directly on the DVIS decoupled architecture, adopting its referring cross-attention layers and ground-truth assignment strategy, but fundamentally rethinks how object identity is maintained across frames. Where prior memory-based trackers (CTVIS, Memotr, TrackFormer) aggregate object features via similarity weights or momentum updates—producing mixed representations that cause ID switches—LOM instead tracks only the *latest* state of each object, gated by foreground probability. The Decoupled Object Association strategy, with its occupancy-guided Hungarian Matching, departs from the standard practice of matching all queries uniformly by explicitly separating existing-object tracking from new-object ID assignment, addressing a structural weakness in cross-frame attention methods that the authors identify as causing foreground-background feature collapse.

## Why It Matters / Open Questions

The paper tackles a persistent and practically important failure mode in video instance segmentation: identity drift over long videos where objects occlude, disappear, and reappear. The occupancy-based index management offers a clean, interpretable mechanism for new-object ID assignment that could be adopted by other query-based tracking systems beyond VIS. However, the method remains tied to a frozen Mask2Former segmentation backbone and an online setting, and the paper does not explore whether the LOM/DOA principles transfer to other video tasks (e.g., video object segmentation, multi-object tracking) or to offline settings with temporal refinement beyond the single ablation. Open questions include whether the foreground-probability-gated memory update degrades in scenes with very dense, overlapping objects, and whether the two-tracker architecture (T_E + T_A) can be further streamlined without sacrificing the +7.2 AP gain.

## Problem

Existing in-context learning (ICL) models for neuroimaging process 3D volumes as 2D slices, losing inter-slice correlations and volumetric context critical for tasks like hippocampus segmentation. Extending ICL to native 3D inputs is infeasible with current approaches because 3D images are over 100× larger than 2D slices, causing prohibitive memory consumption that limits context size, model capacity, and input resolution simultaneously.
![Teaser figure](../imgs/ICCV20252663/cropped_page1_idx1.webp)

## Input / Output

The model takes a 3D neuroimaging volume (resampled to 1 mm³ isotropic, rescaled to 128×128×128, intensity-normalized to [0,1]) as the target image, along with an arbitrary number of 3D image-label pairs as context. Unlike 2D ICL models that process slice-by-slice, Neuroverse3D consumes the full volumetric context in one forward pass, and the context size is effectively unlimited thanks to the partitioning strategy. Outputs are 3D volumes: binary segmentation masks (thresholded at 0.5) or continuous-intensity images for generation tasks (denoising, inpainting, super-resolution, bias correction, skull stripping, modality transformation).

## Method

Neuroverse3D uses a dual-branch 5-stage 3D U-Net (32→512 channels, residual blocks, GELU) with a target branch and a context branch that communicate via a U-shaped fusion strategy: Target-to-Context Fusion (concatenation + convolution) at each encoder stage and Context-to-Target Fusion at each decoder stage. The key memory-saving mechanism is Adaptive Parallel-Sequential Processing (APSP): the context set is partitioned into mini-contexts of size ℓ (determined by available GPU memory), each mini-context is processed in parallel through shared-weight 3D U-Nets, and the resulting per-stage representations are fused sequentially via a running mean, discarding intermediate features after each step so peak memory scales with ℒ rather than total context size L. During training, only the last mini-context is retained for backpropagation, with random shuffling and a scaling factor of n to provably preserve gradient equivalence with full-context processing. An optimized loss function replaces standard smooth-L1 with a cubic-exponent variant for segmentation (addressing increased 3D class sparsity) and adds a gradient-magnitude term for generation tasks to sharpen anatomical boundaries.

## Results

On held-out neuroimaging datasets (FCON-1000, WMH, Chinese Color Nest, PPMI), Neuroverse3D achieves Dice score gains exceeding 20 percentage points over all 2D ICL baselines on segmentation targets including hippocampus, thalamus, lateral ventricle, and putamen. In generation tasks (bias correction, denoising, skull stripping, super-resolution, etc.), Neuroverse3D outperforms all ICL baselines in PSNR and nearly matches fully supervised task-specific models on salt-and-pepper noise removal and skull stripping. Performance plateaus around context size 16, with standard deviation continuing to decrease for more stable predictions at larger contexts.

## Baselines & Comparisons

Neuroverse3D is compared against four 2D ICL baselines: UniverSeg (context size 64), Neuralizer (context size 32), SegGPT (context size 8), and Painter (context size 1). Neuroverse3D decisively wins on all comparisons: it exceeds every 2D ICL model by over 20 Dice points on key segmentation structures (hippocampus, thalamus, lateral ventricle, putamen) and surpasses all ICL baselines in PSNR across generation tasks. It also outperforms few-shot task-specific 3D U-Net models on all segmentation tasks, while closely approaching fully supervised task-specific performance. The 2D baselines (Painter, SegGPT) are particularly disadvantaged on sagittal slices where inter-slice discontinuities are visible, and SegGPT is further limited to a maximum context size of 16 due to memory constraints. For unseen tasks, Neuroverse3D-unseen shows only a ~5-point Dice drop (segmentation) while still significantly outperforming all ICL baselines, though generation task generalization degrades more substantially.

## Relation to Prior Work

This paper extends the 2D in-context learning (ICL) paradigm for neuroimaging—established by UniverSeg, Neuralizer, and One-Prompt—to native 3D volumetric inputs, which prior models could not handle due to prohibitive memory costs. The core architectural contribution, Adaptive Parallel-Sequential Processing (APSP), draws conceptual inspiration from sequential modeling in large vision models (LVM) but repurposes it specifically to partition and fuse ICL context sets under a U-shaped fusion strategy that avoids storing intermediate features. The optimized loss function (modified L1 with cubic exponent for segmentation, gradient-augmented smooth-L1 for generation) builds on standard ICL training objectives but addresses the increased class sparsity introduced by the third dimension.

## Why It Matters / Open Questions

By making 3D ICL practically deployable (7.35 GB memory at ℓ=1, unlimited context size), Neuroverse3D offers medical centers a retraining-free alternative to task-specific models, with performance matching fully supervised U-Nets on segmentation. A notable limitation is that generation tasks benefit less from 3D context (e.g., modality transform and super-resolution work adequately with 2D), and cross-task generalization for generation is weaker than for segmentation, suggesting that task diversity in training remains a key lever. Open questions include whether APSP generalizes to other 3D modalities (e.g., ultrasound, CT of other organs) and whether the memory-efficiency trade-off (larger ℓ = faster but more memory) can be further optimized for edge deployment.

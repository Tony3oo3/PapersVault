## Problem

Existing object ReID methods are category-specific, requiring costly labeled data and retraining for each new object type, while self-supervised models learn generic semantics that miss the fine-grained, identity-sensitive features (e.g., logos, stitching patterns) critical for ReID. This paper asks how to build a single ReID model that generalizes to arbitrary unseen object categories using only a few in-context example pairs, without any parameter adaptation to the new category.
![Teaser figure](../imgs/ICCV20251453/cropped_page0_idx0.webp)

## Input / Output

At test time on a novel category, the method receives a support set of K=64 positive/negative image pairs (224×224 RGB) from that category, which are processed once through a frozen LLM to generate cached visual prompts. Query and gallery images from the same category are then encoded by a frozen DINOv2 ViT-small modulated by those prompts, producing [CLS] token embeddings for cosine-similarity-based instance retrieval. The category must be known a priori (e.g., via an upstream detector), so comparisons are restricted to within-category pairs.

## Method

VICP couples a frozen LLM (LLaMA) with a frozen vision foundation model (DINOv2) via a trainable Q-Former connector and a lightweight Visual Head. The Q-Former compresses each support image into 32 latent tokens; these are concatenated with learnable label embeddings and M learnable visual prompt tokens, forming a contextual sequence fed to the LLM. The LLM is trained with an ICL loss (supervising only the label tokens) to reason across multiple pairs and infer identity-discriminative rules, while the prompt tokens absorb this relational knowledge. A two-layer MLP then maps the LLM's hidden states at the prompt positions into visual prompts that are injected into every transformer layer of DINOv2, dynamically reweighting self-attention to amplify ID-sensitive local regions (textures, logos) and suppress irrelevant variations (lighting, viewpoint). Training combines a triplet loss on global [CLS] embeddings, an optimal-transport patch alignment loss for local feature consistency, and the ICL loss, all with the VFM backbone kept frozen.

## Results

On the newly introduced ShopID10K benchmark, VICP achieves 58.5 mAP and 68.4 Rank-1, outperforming the strongest fine-tuning baseline Triplet+ (54.8 mAP, 67.4 Rank-1) by 3.7 mAP while approaching the fully supervised upper bound of 62.6 mAP. On MVImageNet, VICP reaches 74.9 mAP and 85.4 Rank-1, surpassing Triplet+ (73.2 mAP, 84.0 Rank-1). On PetFace, VICP attains 93.5 AUC and 51.2 mAP, exceeding all unsupervised and fine-tuning baselines. On person ReID (MSMT17), VICP achieves 75.3 mAP / 89.2 Rank-1, outperforming the prior best PASS (69.1 mAP / 86.5 Rank-1) by 6.2 mAP.

## Baselines & Comparisons

VICP consistently outperforms all unsupervised representation baselines (CLIP, OpenCLIP, DINO, DreamSim, Unicom, I-JEPA, DINOv2) by 14–25 mAP on ShopID10K, confirming that generic visual features lack the fine-grained ID sensitivity required for ReID. Among fine-tuning baselines on seen categories, VICP surpasses Triplet+ (the strongest few-shot baseline) by 3.7 mAP on ShopID10K and 1.4 mAP on PetFace, while also exceeding ArcFace, AdaFace, and SCL by 3–4 mAP. On person ReID (MSMT17), VICP achieves 75.3 mAP / 89.2 Rank-1, beating the previous best PASS (69.1 / 86.5) by 6.2 mAP and DINO (66.1 / 84.6) by 9.2 mAP. On vehicle ReID (VeRi-776), VICP outperforms TransReID by 1.6 mAP (81.2 vs. 79.6). The only method that exceeds VICP is the fully supervised upper bound (which trains on all categories including unseen ones), and VICP closes that gap to within 4.1 mAP on ShopID10K without any parameter updates at test time.

## Relation to Prior Work

This paper sits at the intersection of visual prompt tuning (Jia et al., ECCV 2022) and multimodal in-context learning (BLIP-2's Q-Former, Li et al., ICML 2023), repurposing both for a ReID-specific objective. It departs from the self-supervised learning line (DINO, MoCo) that learns instance-wise invariance but overlooks fine-grained ID cues, and from category-specific ReID methods that require dedicated training per object class. The key conceptual departure is using a frozen LLM not for direct query-gallery inference but as a one-time semantic reasoner that distills identity-discriminative rules from few-shot pairs into dynamic visual prompts injected into a frozen VFM, thereby bridging the gap between generic visual priors and task-specific discriminability without parameter updates.

## Why It Matters / Open Questions

The paper establishes Generalizable Object ReID as a formal task and provides ShopID10K, the first large-scale (10K instances, 34 categories) real-world benchmark for cross-category ReID generalization, filling a gap left by the tiny, lab-controlled CUTE dataset. A key limitation is the category-aware assumption: the object category must be known a priori (e.g., via an upstream detector), and the method still requires a few-shot support set rather than operating zero-shot. The authors explicitly flag zero-shot ReID without exemplars as future work, and the moderate gains over strong fine-tuning baselines (1–4% mAP) suggest the approach's practical value lies more in deployment flexibility (no retraining for new categories) than in raw accuracy. Whether the LLM-guided prompting paradigm scales to truly open-world settings with unknown categories and varying support set quality remains open.

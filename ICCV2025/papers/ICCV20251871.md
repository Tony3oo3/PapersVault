## Problem

Existing interpretable few-shot classification methods either depend on human-annotated attributes or generate features from LLM/VLM prior knowledge, which are often ungrounded for fine-grained species or novel objects underrepresented in pre-training data. This limits generalization in low-resource settings where the model must discover subtle visual distinctions not captured by pre-trained knowledge.
![Teaser figure](../imgs/ICCV20251871/cropped_page0_idx1.webp)

## Input / Output

During feature extraction, the method consumes paired RGB images (positive pairs from the same class, negative pairs from different classes) and produces natural-language verbalized feature descriptions. During inference, a single test image is mapped to a numeric feature vector—binary (0/1) when using LLaVA as the mapping model, or continuous similarity scores when using CLIP—where each dimension corresponds to the presence or degree of a specific verbalized feature. The final output is a class label predicted by a downstream classifier (logistic regression, MLP, etc.) trained on these vectors.

## Method

VRL leverages a VLM (LLaVA-OneVision) to verbalize two complementary types of visual features: inter-class differences extracted by prompting the VLM to describe key distinctions between images from different classes (analogous to negative pairs in contrastive learning), and intra-class commonalities extracted by describing shared traits between images from the same class (analogous to positive-pair SSL). These verbalized features are then mapped to numeric vectors by querying a VLM on whether a given image exhibits each described feature, yielding a binary or continuous embedding. Downstream classifiers (logistic regression, MLP, random forest) are trained on these interpretable vectors, and an ensemble of classifiers trained on different feature types (F_diff, F_comm, CLIP features) with soft voting provides the final prediction. The key insight is that verbalization inherently prevents feature collapse and scales the number of useful features exponentially with N×C image pairs, enabling strong generalization from only 10 images per class.

## Results

On iNaturalist fine-grained classification (10 images per species), VRL-7B achieves 58.46% average accuracy, surpassing the previous SoTA LLM-Mutate-70B (50.06% with 200+ images per species) by 8% while using 95% less data and a 10x smaller model. Scaling to VRL-72B further improves to 67.92%. On Kiki-Bouba novel concept classification (10 images per class), VRL-7B reaches 83.00% average accuracy, exceeding the prior SoTA (LLM-Mutate-70B, 69.30% with 800+ images per class) by 14% with 99% less data. When compared to human-labeled attributes on Kiki-Bouba, VRL-extracted features yield a 20% absolute gain (83.00% vs. 63.15%).

## Baselines & Comparisons

VRL-7B (58.46%) outperforms LLM-Mutate-70B (50.06%) by 8% on iNaturalist despite using 95% less data and a 10x smaller model; when both are restricted to the same 10-image budget, the gap widens to 20% (58.46% vs. 44.13%). Against LaBo-70B (51.72% under the same few-shot constraint), VRL-7B leads by 7%, and against Classification by Description (29.60% with full data), VRL-7B exceeds it by nearly 29%. Among LLaVA-based adaptation methods, VRL-7B surpasses LoRA fine-tuning (LLaVA-SFT-7B, 43.92%) by 15% and in-context learning (LLaVA-ICL-7B, 22.92%) by 36%, while also being more scalable (72B VRL fits in 8×48GB GPUs vs. 8×80GB for LoRA on 13B). On Kiki-Bouba, VRL-7B (83.00%) beats LLM-Mutate-70B (69.30% full data) by 14% and LLaVA-SFT-7B (61.35%) by 22%, with the advantage over LLM-based methods growing to 50% over Classification by Description (32.80%), suggesting that grounded visual feature extraction is critical for novel concepts absent from pre-training data.

## Relation to Prior Work

VRL repurposes the positive/negative pair structure from self-supervised contrastive learning (SimCLR, MoCo, SwAV) but replaces the learned numerical embedding with a VLM-generated natural language description of the pair's distinguishing or shared features. It departs from prior language-bottleneck classifiers (LaBo, CBD, LLM-Mutate) that prompt an LLM with a class name to produce attributes, instead grounding features directly in image-pair comparisons via a VLM like LLaVA-OneVision. The resulting verbalized features are then mapped to numeric vectors (binary via LLaVA or continuous via CLIP similarity) and fed to standard classifiers, positioning VRL as a data-efficient, interpretable alternative to both gradient-based fine-tuning (LoRA) and in-context learning for adapting VLMs to new classes.

## Why It Matters / Open Questions

The 20% absolute gain over human-labeled attributes and the 24% improvement over prior SoTA with 95% less data suggest that automatic, grounded verbalized features can replace costly manual annotation in low-resource fine-grained and novel-concept settings. The finding that scaling from 7B to 72B parameters does not improve performance on Kiki-Bouba (truly novel objects) challenges the assumption that larger VLMs are always better for out-of-distribution recognition. Open questions include scalability to hundreds or thousands of classes (the VLM query cost grows with the number of verbalized features), robustness to VLM hallucinations in the feature-extraction step, and whether the approach transfers to non-visual modalities or tasks beyond classification.

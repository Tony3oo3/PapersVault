## Problem

Existing CAD-based novel object pose estimation methods rely on hundreds to thousands of reference images, networks with hundreds of millions of parameters, and pre-extracted feature caches, making them impractical for edge AI deployment with limited memory and compute. This paper asks whether a lightweight network using only a handful of reference images can achieve comparable accuracy by directly fusing multi-view information rather than retrieving a single closest view.
![Teaser figure](../imgs/ICCV20250314/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB query image and S=12 pre-rendered reference images (with known SE(3) poses, intrinsic matrices, and depth maps) as input, along with pre-sampled 2D pixel coordinates and occlusion flags for N 3D object points on each reference image. It outputs the 6DoF pose via RANSAC-based SQ-PnP, the 2D projection coordinates of each 3D object point on the query image (via spatial soft argmax on a predicted heatmap), and a per-point occlusion flag. No offline feature extraction or caching is required, and the network operates at 1/8 spatial resolution (H/8 × W/8) with a 5.3M parameter backbone.

## Method

MixRI replaces the standard two-stage retrieve-then-match pipeline with a single view-aggregated matching stage: all reference image features are fused simultaneously with the query image feature via a Dual-Attention Based Feature Mixer. The mixer performs three attention operations iteratively—Self-Attention between Points (SAP) for spatial mixing within each frame, Self-Attention between Frames (SAF) for cross-view fusion, and Mix-Attention between Reference and Query (MARQ) for query-aware feature enhancement—using masked attention to exclude occluded projections. A shared ResNet-like encoder with steerable CNN ensures rotation-invariant features, and the fused tokens are combined with the query feature map into a 3D cost volume processed by a Conv3D backbone with separate heads for 2D location (Huber loss) and occlusion (BCE loss). The entire network is trained end-to-end on synthetic GSO-Dataset images and requires only 12 reference images at inference, achieving 33× fewer references and 50× fewer parameters than competing methods while matching or exceeding their accuracy on most BOP benchmarks.

## Results

On the seven core BOP datasets, MixRI with 12 reference images achieves a mean AR of 31.4% using only 5.3M network parameters and 0.5s inference time, while with 24 reference images it reaches 34.1% mean AR at 0.7s. This is achieved with 33× fewer reference images than FoundPose (798) and 50× fewer parameters than GigaPose (316.3M), while being 2× faster than GigaPose (0.5s vs. 0.8s). The method outperforms GigaPose by ~6.5% mean AR and MegaPose by ~15% mean AR, though it trails FoundPose (37.2% mean AR) by about 6 points.

## Baselines & Comparisons

MixRI (12 ref) achieves 31.4% mean AR, surpassing GigaPose (27.6%) by 6.5% and MegaPose (20.8%) by 10.6%, while using 13.5× fewer reference images than GigaPose and 43× fewer than MegaPose. Against FoundPose (37.2% mean AR, 798 ref images, 302.9M params), MixRI trails by 5.8 points but uses 33× fewer reference images, 57× fewer parameters, and is 3.2× faster (0.5s vs. 1.6s). MixRI clearly wins on YCB-V (52.8 vs. 29.0 for GigaPose, 45.2 for FoundPose) and IC-BIN (29.7 vs. 23.1 for GigaPose), but loses on ITODD (10.9 vs. 18.8 for GigaPose, 20.4 for FoundPose), likely due to grayscale input and severe occlusions. Compared to Genflow (23.5% mean AR), MixRI improves by 7.9 points while being 7.6× faster. The paper also shows that with refinement (MegaPose-based), MixRI reaches 45.6% mean AR with 12 ref images, approaching FoundPose's 54.7% with 798 ref images, at 1.5s vs. 4.4s inference time.

## Relation to Prior Work

MixRI departs from the dominant two-stage paradigm in CAD-based novel object pose estimation (MegaPose, GigaPose, FoundPose, ZS6D), which first retrieves the closest reference image and then performs matching. Instead, it reframes the problem as a view-aggregated multi-reference-to-single-query matching task, drawing conceptual inspiration from point tracking (TAP-Vid) for occlusion-aware correspondence but adapting it to unordered, non-consecutive reference views. The architecture combines a steerable CNN encoder for rotation invariance with a transformer-based Dual-Attention mixer (SAP, SAF, MARQ) that fuses features across all reference images simultaneously, bridging the gap between classic paired-image feature matching (LOFTR) and the multi-view geometry literature.

## Why It Matters / Open Questions

The practical significance lies in enabling 6DoF pose estimation on memory-constrained edge devices: 5.3M parameters and 12 reference images versus 300M+ parameters and hundreds of reference images in prior work dramatically reduce both storage and inference cost. However, the method still trails the absolute best (FoundPose) by ~6 AR points on average, and performance degrades when reference images exceed ~60, suggesting the lightweight architecture has a capacity ceiling. Open questions include whether the approach extends to model-free settings (no CAD), whether the ITODD weakness (grayscale, severe occlusion, weak texture) can be addressed, and whether the multi-view fusion strategy generalizes to even fewer than 12 views in practice.

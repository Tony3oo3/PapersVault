## Problem

Existing diversity metrics for text-to-image models (Vendi, RKE, Recall, Coverage) are prompt-unaware: they conflate diversity arising from varied input prompts with the model's intrinsic generative diversity, making it impossible to assess how well a model produces varied images from similar prompts. While CLIP embeddings have been widely adopted for fidelity evaluation via CLIPScore, they have not been leveraged to quantify or decompose the diversity of generated images in a prompt-aware manner.

## Input / Output

The method consumes a set of n paired (text prompt, generated image) samples, embeds both modalities via CLIP into a shared 512-dimensional space, and constructs a joint kernel covariance matrix using either a cosine-similarity or Gaussian kernel (the latter approximated via random Fourier features at dimension r=2000). It outputs three artifacts: a scalar Scendi diversity score (exponentiated conditional entropy of the model-driven covariance component), a PSD decomposition of the image covariance into model-driven and prompt-driven sub-matrices, and a modified 512-dim CLIP embedding per image with specified text directions subtracted via the optimal conversion matrix Γ*.

## Method

The core mechanism is a Schur complement decomposition of the joint (image, text) kernel covariance matrix C_joint = [[C_II, C_IT],[C_IT^T, C_TT]], yielding C_II = Λ_I + Λ_T where Λ_I = C_II − C_IT C_TT^{−1} C_IT^T captures model-driven covariance and Λ_T = C_IT C_TT^{−1} C_IT^T captures prompt-driven covariance. The Scendi score is defined as exp(H(Λ_I / Tr(Λ_I))), i.e., the exponentiated Von Neumann entropy of the normalized Schur complement, which the paper interprets as exp(H(Mode | Y_T)) — the conditional entropy of the image cluster variable given the text-based guess. Proposition 1 establishes that Γ* = C_IT C_TT^{−1} is the Frobenius-norm-optimal linear text-to-image conversion matrix, so subtracting Γ*·CLIP(T) from CLIP(I) decorrelates the image embedding from the prompt, enabling targeted removal of specific object or style directions. This extends the Vendi and RKE framework from unconditional kernel-matrix entropy to a prompt-aware conditional setting without requiring multiple images per prompt or a reference dataset.

## Results

On the CLEVR dataset (Figure 7), Vendi increases monotonically with the number of shapes (5.93 → 7.03 → 9.46) regardless of whether shapes are specified in the prompt, while Scendi with shapes specified remains nearly flat (2.94, 2.95, 2.96) and Scendi without shapes increases (2.53 → 2.96 → 3.70), confirming that Scendi isolates true image-driven diversity from prompt-driven variation. On SDXL-generated cat breed images (Figure 4), Vendi, Recall, and Coverage remain unchanged when breed information is added to prompts, whereas Scendi becomes non-increasing, correctly reflecting that diversity now stems from the text rather than the model. In the FLUX.1-dev doctor experiment (Figure 3), Scendi ranges from near 0 (all senior male doctors) to near 1 (equal representation of all age/gender combinations), while unconditional metrics show no such sensitivity.

## Baselines & Comparisons

The paper compares Scendi against four unconditional diversity baselines: Vendi [9], RKE [19], Recall [26], and Coverage [34]. Across all experimental settings (CLEVR, SDXL cat breeds, FLUX.1-dev doctors, and varying prompt specificity), Vendi, RKE, Recall, and Coverage remain essentially unchanged when the source of diversity shifts from the model to the prompt, failing to distinguish model-driven from prompt-driven diversity. In contrast, Scendi consistently differentiates: on CLEVR, Scendi-with-shapes stays flat (~2.95) while Vendi rises from 5.93 to 9.46; on SDXL cat breeds, Scendi decreases when breed names are added to prompts while Vendi/Coverage/Recall are invariant; and in the prompt-specificity experiment (Figure 5), Scendi varies across four levels of prompt detail while all four baselines remain flat. The paper thus demonstrates that Scendi wins on the key axis of prompt-awareness—correctly attributing diversity to the model rather than the prompt—while the unconditional baselines are blind to this distinction. No baseline outperforms Scendi on any reported metric; the comparison is qualitative in the sense that the baselines simply cannot capture the phenomenon Scendi is designed to measure.

## Relation to Prior Work

This paper extends the kernel-based diversity evaluation line (Vendi score, RKE) by applying a Schur complement decomposition to the joint text-image CLIP kernel covariance matrix, separating model-driven from prompt-driven components. It builds on CLIP's joint embedding space (previously used only for fidelity via CLIPScore) and repurposes a standard linear-algebraic tool for a new interpretive role in generative model evaluation. The concurrent Conditional Vendi score [20] addresses a related prompt-awareness question via Hadamard kernel products, but the Schur complement approach here yields a cleaner covariance-level decomposition with a direct optimal-transport interpretation (Proposition 1) and a practical embedding-modification procedure.

## Why It Matters / Open Questions

The Scendi score gives practitioners a principled, reference-free way to attribute diversity to the model rather than to prompt variation, which is critical when comparing text-to-image systems under different prompt distributions. The Schur-complement-based CLIP embedding modification (canceling specific object or text directions) opens practical applications in retrieval, clustering, and defense against typographic attacks. Open questions include whether the decomposition remains stable at scale (very large n, high-dimensional embeddings), how it extends to video or multi-turn generation, and whether Scendi-guided training (analogous to Vendi/RKE guidance in diffusion) can improve model diversity during optimization.

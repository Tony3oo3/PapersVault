## Problem

Solving imaging inverse problems (deblurring, super-resolution) in the wild typically requires either paired clean-corrupted training data or strong priors on the degradation operator, both of which are often unavailable or mis-specified. Existing unpaired methods learn an implicit mapping from corrupted to clean images without explicitly recovering the forward operator, limiting interpretability and reconstruction accuracy. This paper asks whether the true degradation operator can be identified from small, unpaired clean and corrupted datasets alone, without any prior on the operator.

## Input / Output

The method consumes two unpaired datasets: a set of clean images (e.g., 100–1000 images) and a set of corrupted images produced by an unknown but fixed degradation operator. For non-uniform deblurring, the learned operator is a spatially varying PSF (e.g., a grid of 64 kernels interpolated per pixel location); for super-resolution, a single low-resolution image is split into patches and the kernel is estimated via a scale-invariance trick comparing once- and twice-downscaled distributions. The final output is a learned degradation kernel that can be plugged into any non-blind solver (ESRGAN, DPIR, DiffPIR, ZSSR, etc.) to produce a restored or super-resolved image.

## Method

The algorithm proceeds in three steps: (1) train a conditional flow matching (CFM) model on the corrupted dataset to obtain a tractable score representation of the corrupted distribution; (2) learn the degradation operator ω by minimizing the integrated KL divergence between the corrupted-data distribution and the distribution of clean images passed through A_ω, using an alternating scheme that updates an auxiliary CFM model and the operator parameters in turn, with the IKL gradient computed via the score-difference formula from DiffInstruct; (3) apply the learned operator in a standard non-blind restoration pipeline. A key theoretical result proves that, under a non-degeneracy assumption on the clean-image covariance, the true operator is identifiable up to an orthogonal transformation. For super-resolution, the method exploits the scale-invariance of natural images: the kernel is recovered by matching the distribution of a once-downscaled image to that of a twice-downscaled image, requiring only a single input image.

## Results

On non-uniform deblurring (DPDD), the proposed method with ESRGAN achieves 32.38 PSNR / 0.911 SSIM / 0.061 LPIPS, nearly matching the non-blind upper bound of ESRGAN (32.53 / 0.906 / 0.058) and outperforming all blind baselines by 3–4 dB in PSNR. With DPIR, it reaches 33.84 PSNR / 0.933 SSIM, close to the non-blind DPIR upper bound (34.89 / 0.933). On single-image super-resolution (DIV2KRK), the method achieves 31.86 PSNR / 0.8938 SSIM with kernel PSNR of 64.2 and kernel NCC of 0.96, surpassing all other two-step kernel-estimation methods (KernelGAN: 51.5 kernel PSNR; DKP: 53.6; DIP-FKP: 50.4) and approaching the end-to-end DANv2 (32.12 PSNR).

## Baselines & Comparisons

The proposed method nearly matches non-blind upper bounds: on DPDD non-uniform deblurring, Ours+ESRGAN (32.38 PSNR) is within 0.15 dB of ESRGAN with the true kernel (32.53), and Ours+DPIR (33.84) is within 1.05 dB of DPIR (34.89). Against the closest multi-image unsupervised baseline DeFlow+ESRGAN, the method wins by 4.46 dB in PSNR and 0.09 in LPIPS, indicating DeFlow fails to learn the correct blur distribution. All single-image blind methods (INIKNet 29.45, Restormer 28.59) are outperformed by 2.9–3.8 dB in PSNR. On DIV2KRK super-resolution, the method's kernel estimates (64.2 kernel PSNR, 0.96 NCC) surpass KernelGAN (51.5, 0.92), DKP (53.6, 0.92), and DIP-FKP (50.4, 0.95), and match the end-to-end DANv2 kernel quality (56.8, 0.97) while using no external training data. The only comparison where the method is slightly behind is end-to-end DANv2/DCLS on DIV2KRK (31.86 vs 32.12/32.31 PSNR), which the authors attribute to strong inductive priors from large-scale pretraining on similar data.

## Relation to Prior Work

This paper repurposes the integrated KL divergence gradient from DreamFusion [39] and DiffInstruct [32]—originally designed for 3D scene optimization and model distillation—into a distribution-matching loss for learning explicit degradation operators via conditional flow matching [28, 29]. It departs from prior unsupervised restoration methods (DeFlow, CinCGAN) that learn implicit degradation mappings through GAN or normalizing-flow objectives, instead learning an explicit, interpretable forward operator (e.g., a blur kernel) by matching the distribution of corrupted clean images to the observed noisy distribution. The identifiability guarantee (Proposition 3.1) is a new theoretical contribution absent from prior blind/unsupervised deblurring work, which typically relies on heuristic priors over the kernel space.

## Why It Matters / Open Questions

The method closes much of the performance gap between blind single-image and non-blind restoration (e.g., 32.7 vs. 32.7 PSNR on Gaussian deblurring; 32.38 vs. 32.53 on non-uniform deblurring) using only hundreds of unpaired images, and the explicit kernel estimates enable a practical lens-calibration pipeline that replaces laborious PSF measurement with a few photographs. Key limitations remain: the approach requires multiple images sharing the same degradation distribution (ruling out truly single-image settings except super-resolution), struggles under large domain shift between clean and corrupted datasets, and currently assumes Gaussian noise. Open directions include extending to Poisson-Gaussian noise models, microscopy, and medical imaging, and tightening the identifiability theory beyond the simplified linear-Gaussian setting.

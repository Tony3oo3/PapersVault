## Problem

Existing vision-language models lack mechanisms for precise regional localization, producing either brief phrases or descriptions contaminated by unrelated content when asked to caption specific image or video regions. The paper identifies three compounding obstacles: fine-grained details are lost when regional features are extracted from global image representations, high-quality localized captioning training data is scarce, and prior benchmarks unfairly penalize models for correct details absent from incomplete reference captions.

## Input / Output

The model accepts binary masks as localization input (other forms like clicks, scribbles, or boxes are converted to masks via SAM/SAM 2), along with the full image or video frames. For videos, specifying the region in any single frame suffices, with SAM 2 propagating the mask across frames. The focal prompt internally creates an expanded crop (bounding box scaled by factor α=3, minimum 48 px) around the mask to provide a high-resolution view alongside the full image. Output is a detailed localized text caption whose granularity (keyword, phrase, or multi-sentence) is controlled by the text prompt.

## Method

DAM combines a focal prompt (full image + expanded regional crop, each with its binary mask) with a localized vision backbone that encodes masks through a dedicated patch embedding layer spatially aligned with image patches, then fuses global context into local features via gated cross-attention adapters inserted in each block of a regional encoder that shares self-attention weights with the global encoder. All new parameters (mask embedding, gating scalars) are initialized to zero, preserving pretrained VLM behavior and requiring only ~1.5M fine-tuning samples. Training data is generated by a two-stage SSL pipeline (DLC-SDP): Stage 1 queries a VLM to expand human-annotated segmentation keywords into detailed captions given mask-referred regions; Stage 2 performs self-training on unlabeled web images using open-vocabulary segmentation, DAM-generated descriptions, and CLIP-based confidence filtering, with an LLM summarizing outputs into multiple granularities.

## Results

On the proposed DLC-Bench, DAM-8B achieves 67.3% average accuracy (52.3% positive, 82.2% negative), surpassing GPT-4o (61.5%), o1 (62.5%), and all region-specific VLMs (best prior: ControlCap at 47.0%). On the PACO part-level benchmark, DAM achieves 73.2% semantic IoU and 84.2% semantic similarity, outperforming the previous best (VP-LLAVA-8B) by 23.2% and 8.5% respectively. On Ref-L4 detailed captioning, DAM achieves 33.4% average relative improvement on short metrics and 13.1% on long metrics over the prior best. On video captioning (HC-STVG), DAM achieves 19.8% relative improvement over the previous best including concurrent work VideoRefer.

## Baselines & Comparisons

DAM-8B (3B params) decisively outperforms all region-specific VLMs on DLC-Bench: the best prior region-specific method (ControlCap, 0.3B) reaches only 47.0% average, while VP-SPHINX (13B) achieves 22.5–49.0% depending on input mode. Against general VLMs, DAM surpasses GPT-4o (61.5%) by 5.8 points and o1 (62.5%) by 4.8 points, despite being a 3B open-source model versus closed-source APIs. On PACO (part-level keyword captioning), DAM's 73.2% semantic IoU exceeds VP-LLAVA-8B (50.0%) by 23.2 points, a particularly large margin given PACO's difficulty in distinguishing objects from parts. On Ref-L4 detailed captioning, DAM achieves 70.0 CIDEr vs. VP-SPHINX-13B's 32.4 and GPT4RoI-7B's 59.9, a 33.4% average relative improvement over the prior best. On video captioning (HC-STVG), DAM's 91.0 CIDEr surpasses VideoRefer-7B (68.6) and Artemis-7B (53.2), and on VideoRefer-Bench-D in-domain, DAM (3.68 avg) edges out VideoRefer-7B (3.46 avg). The only sub-task where DAM does not lead is hallucination detection (HD) in zero-shot VideoRefer-Bench-D (2.58 vs. Elysium's 3.59), which the authors attribute to correct details absent from reference captions rather than true hallucination.

## Relation to Prior Work

This paper departs from the dominant paradigm in region-aware VLMs (Shikra, GPT4RoI, Ferret, VP-SPHINX) that extract localized features from global image embeddings or encode referring conditions as sparse tokens, which the authors argue causes irrecoverable detail loss for small objects. The focal prompt concept repurposes ideas from focal self-attention and dynamic token allocation (ToSA, ToMe, V*) but inverts their logic: instead of the model deciding where to focus, the user specifies the region and the architecture guarantees high token density there. The SSL data pipeline (DLC-SDP) reframes synthetic data generation from bounding-box-based VLM queries into a mask-referred keyword expansion task, drawing on self-training techniques from image classification (FixMatch, MixMatch) rather than prior captioning data curation approaches.

## Why It Matters / Open Questions

The paper addresses a practical gap that blocks fine-grained grounded understanding and generation: existing VLMs cannot produce rich, accurate descriptions of user-specified regions, especially in videos. The DLC-Bench evaluation protocol—scoring against predefined positive/negative attributes rather than incomplete reference captions—identifies a systematic bias in how the field measures captioning quality, with broad implications beyond this specific task. Open questions include whether the dual-encoder (global + regional) architecture scales efficiently to very long videos or high-resolution inputs, and whether the SSL pipeline's gains saturate with more unlabeled data. The finding that a 3B specialized model outperforms GPT-4o and o1 on this task suggests that task-specific architectural inductive biases can still beat generalist scale for narrow but important capabilities.

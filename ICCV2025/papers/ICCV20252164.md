## Problem

Existing language-guided navigation tasks (fine-grained VLN, coarse-grained VLN, object navigation) are treated as isolated problems with task-specific architectures, and simply mixing their training data produces conflicting learning objectives that degrade performance across tasks. The paper identifies that the core difficulty is sharing general visual-semantic knowledge while exploiting task-specific skills (e.g., exploration vs. instruction-following) within a single model.
![Teaser figure](../imgs/ICCV20252164/cropped_page1_idx0.webp)

## Input / Output

At each timestep the agent receives 36 RGB view images (360° panorama) and a language instruction whose granularity ranges from step-by-step action sequences (~32 words in R2R) to a single object category name (OBJECTNAV). The output is a discrete navigation action (forward, turn left, turn right, stop) on a predefined undirected graph of navigable nodes, with the agent maintaining a topological map of visited nodes as navigation history. The same model checkpoint handles all seven tasks without task-specific parameter switching.

## Method

SAME builds on the DUET dual-scale graph transformer and replaces the visual query layers in the cross-attention module with sparsely-gated Mixture-of-Experts layers (8 experts, top-2 selection). The key novelty is the state-adaptive routing mechanism: the routing feature is a linear projection of the concatenation between the mean-pooled visual features across all 36 views and the text [CLS] token, so expert selection dynamically adapts to the agent's current visual observation and language context at each timestep. This contrasts with token-wise or task-wise MoE, which the paper shows to be ineffective for navigation. Training uses DAgger with sequential (non-mixed) data sampling across seven datasets, initialized from ScaleVLN pre-trained weights, with a load-balancing loss (λ=0.8) to prevent expert collapse. The paper further demonstrates that placing MoE on visual queries outperforms placing it on FFN layers or textual key/value projections, aligning with the role of multi-view visual attention in navigation decision-making.

## Results

On the discrete MP3D environment, SAME achieves state-of-the-art CVDN performance with 7.07 GP on test (13% GP increase over ScaleVLN on validation) and matches task-specific models (VER, GOAT) on R2R and REVERIE SPL. As a unified model, SAME outperforms the multi-task ScaleVLN baseline by an average of 3% SR across all seven tasks, and surpasses NaviLLM by 6% and 9% test SR on R2R and REVERIE respectively, while using only 215M parameters versus NaviLLM's 6.77B. In the continuous Habitat environment (zero-shot transfer), SAME achieves 43% SR / 21% SPL on OBJECTNAV-MP3D, outperforming Habitat-Web (35%/10%), PONI (32%/12%), and SemExp (28%/11%).

## Baselines & Comparisons

Against the multi-task ScaleVLN baseline (DUET without MoE), SAME wins on all seven tasks with an average ~3% SR improvement, confirming that the state-adaptive MoE routing resolves task conflicts that degrade plain multi-task training. Compared to NaviLLM (a 6.77B-parameter LLM-based agent), SAME achieves 6% higher test SR on R2R and 9% higher on REVERIE while using only 215M parameters (31× fewer) and 59 ms latency versus 100 ms. On CVDN, SAME sets a new state-of-the-art at 7.07 GP (test), surpassing all prior unified and task-specific methods. On OBJECTNAV-MP3D in the continuous environment, SAME (43% SR) clearly beats Habitat-Web (35%), PONI (32%), and SemExp (28%), validating that fine-grained VLN pretraining transfers to target-oriented navigation. However, on R2R-CE (continuous VLN), SAME (47% SR) trails task-specific continuous methods like BEVBert (59%), ETPNav (57%), and ScaleVLN (55%), indicating that the discrete-to-continuous gap remains a limitation for fine-grained instruction following in continuous spaces.

## Relation to Prior Work

This paper builds on the DUET dual-scale graph transformer architecture for VLN and adapts the sparsely-gated Mixture of Experts formulation from LLMs (Shazeer et al.) to embodied navigation, but departs from both token-wise MoE (as in LLMs) and task-wise MoE (as in CV multi-task learning) by introducing state-adaptive routing conditioned on the agent's multimodal observation at each timestep. It extends the multi-task VLN learning problem (previously limited to R2R/CVDN-style tasks) to encompass OBJECTNAV and four additional benchmarks, unifying seven navigation tasks under a single 'language-guided visual navigation' framework. The pretraining initialization from ScaleVLN provides a strong vision-language-action prior, and the DAgger training protocol follows established practice in the VLN literature.

## Why It Matters / Open Questions

This is the first unified model to achieve competitive performance across seven major navigation benchmarks simultaneously, demonstrating that a single architecture can handle instruction granularity ranging from single-word object categories to detailed step-by-step directions. The finding that explicit task embeddings actively hinder cross-task skill sharing is a useful negative result for multi-task learning design in embodied agents. However, the approach remains tied to the DUET architecture and discrete graph environments, with only zero-shot (waypoint-predictor-mediated) transfer to continuous Habitat; whether state-adaptive MoE routing generalizes to fundamentally different agent architectures or truly open-world settings remains an open question.

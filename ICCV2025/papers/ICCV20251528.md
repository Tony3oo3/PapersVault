## Problem

Existing continuous-time 3D object detection methods (e.g., Ev-3DOD) rely on synchronized LiDAR and RGB sensors for geometric information, propagating past detections forward during blind time. Under large ego-motion or dynamic scene changes, this propagation accumulates errors and fails, because fixed-frame-rate data no longer reflects the current 3D geometry. No prior method performs 3D detection using only asynchronous event cameras, eliminating all dependency on conventional sensors.

## Input / Output

The method consumes a stereo event camera stream (left and right), where each event is a (u, v, t, p) tuple, and discretizes events over a flexible time window Δτ into a voxel grid using bilinear sampling kernels. The time window can be adapted to different scenarios, enabling detection at arbitrary timestamps rather than fixed frame intervals. Output consists of 3D bounding boxes (center, dimensions, orientation) produced by a two-stage anchor-based regression (global + local), along with an intermediate depth probability volume used for geometric reasoning.

## Method

The architecture modifies PSMNet with dual feature heads that separately extract semantic and geometric features from each stereo view. A geometric plane-sweep volume is constructed via depth-hypothesis concatenation, and a dual semantic-geometric filter then mutually refines both streams: semantic features guide depth refinement through stereo similarity and confidence-weighted neighborhood aggregation, while the estimated depth warps right semantic features to the left view, where a transformer-based channel attention mechanism fuses them to compensate for event sparsity. The fused 3D voxels feed an anchor-based global detector on BEV features, followed by an object-centric ROI alignment module that pools semantic BEV features around each predicted box to predict a local offset, improving regression under motion. Training uses a multi-task loss combining initial and refined depth, 2D detection, classification, and two-stage 3D regression losses.

## Results

On the DSEC-3DOD dataset (100 FPS blind-time evaluation, motion scale ×1, time slice ×10), the proposed Event-Stereo method achieves 23.47 / 19.62 AP₃D (Easy/Mod) for vehicles and 19.86 / 12.93 AP₃D for pedestrians, outperforming all LiDAR-only, LiDAR+RGB, and RGB-Stereo baselines. It surpasses the strongest RGB-Stereo baseline (DSGN) by +7.18 AP₃D (Easy) for vehicles and +15.80 for pedestrians. Under increased motion (scale ×4, time slice ×20), the method maintains 22.72 / 19.04 AP₃D (VEH/PED Easy) while Ev-3DOD drops to 6.36 / 0.39, demonstrating robustness to large scene changes.

## Baselines & Comparisons

The proposed Event-Stereo method outperforms all six non-event baselines across every metric. Against LiDAR-only methods (VoxelNeXt, HEDNet), it gains +10.81 and +9.16 AP₃D (Easy) for vehicles respectively, and +9.27 and +9.70 for pedestrians. Against LiDAR+RGB fusion (LoGoNet, the strongest conventional baseline), it leads by +5.82 AP₃D (Easy) for vehicles and +8.20 for pedestrians. Against RGB-Stereo methods (DSGN, LIGA), the margins are even larger: +7.18 and +9.21 AP₃D (Easy) for vehicles, and +15.80 and +13.84 for pedestrians. The only method that surpasses the proposed approach on vehicle detection is Ev-3DOD (LiDAR+RGB+Event), which achieves 29.53 vs. 23.47 VEH AP₃D (Easy) thanks to direct LiDAR depth. However, the proposed method actually beats Ev-3DOD on pedestrian AP₃D (19.86 vs. 18.42), and under increased motion scale (×4), Ev-3DOD's performance collapses (6.36 VEH AP₃D) while the proposed method remains stable (22.72), confirming that reliance on synchronized LiDAR geometry becomes a critical weakness in dynamic scenes.

## Relation to Prior Work

This paper extends the continuous-time 3D object detection framework introduced by Ev-3DOD [22], which fuses LiDAR, RGB, and event cameras but still depends on synchronized sensors for 3D geometry. The key departure is eliminating all conventional sensors, relying solely on a stereo event camera pair to compute both geometric depth (via a modified PSMNet-based plane-sweep volume) and semantic features, bridged by a novel dual semantic-geometric filter. The anchor-based global detector and loss design follow LIGA-Stereo [34] and DSGN [11], while the depth refinement mechanism adapts the attention-based volume filtering from [91]. The object-centric ROI alignment module, which uses a transformer-based cross-attention to warp and fuse right-camera semantic features into the left, is a new architectural component not present in prior stereo 3D detectors.

## Why It Matters / Open Questions

This work demonstrates that 3D object detection is feasible without any fixed-frame-rate sensor, opening a path toward perception systems for high-speed or rapidly changing environments (drones, high-speed driving) where LiDAR and RGB data become stale during blind intervals. The finding that adding synchronous RGB actually degrades performance under large motion (Table 4) challenges the assumption that more modalities always help, suggesting that temporal alignment is a critical factor in multi-sensor fusion. However, the evaluation is limited to a single dataset (DSEC-3DOD) with relatively low ego velocities, and the motion-scale experiments approximate large motion by stretching the time axis rather than capturing genuinely high-speed driving, leaving open whether the approach generalizes to truly extreme dynamics. Absolute performance still trails LiDAR-based methods, so the practical deployment case remains one of robustness under motion rather than peak accuracy.

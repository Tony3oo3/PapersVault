## Problem

Existing controllable infrared-visible image fusion methods can only highlight all objects of a semantic class (e.g., all cars), not a specific user-referenced instance. Moreover, text-driven instance localization for VIS-IR images remains unexplored because standard referring image segmentation models fail on these modalities due to IR's lack of texture/color and VIS's low-light degradation, which reduce instance-level visual cues.
![Teaser figure](../imgs/ICCV20251866/cropped_page0_idx0.webp)

## Input / Output

The model takes a registered pair of infrared and visible images (resized to 320×320) and a free-form text description referencing a specific instance (e.g., 'the person on the top left') as input, and produces a single fused image where the referenced instance is selectively highlighted with enhanced IR brightness and VIS texture while non-target regions undergo standard fusion. During inference, only the fusion network executes—instance localization is implicitly learned and no separate segmentation or text-matching step is required at test time.

## Method

The approach is a two-stage weakly-supervised pipeline. Stage I trains a Text-to-Image Response Network (TIRN) using only text and text-image manifold similarity as joint supervision (no pixel-level annotations), where a Multimodal Feature Alignment Module (MFA) computes manifold similarity via KNN-graph shortest paths (Dijkstra) between image patches and text tokens, then uses this similarity to guide cross-modal attention weights for precise text-image correspondence; an Instance Selection Module (ISM) then refines semantic-level candidates to a single instance using 12 hand-crafted spatial relationship rules (e.g., 'left', 'N-th from the top'), producing binary pseudo-labels. Stage II trains a fusion network on these pseudo-labels with two distinct loss regimes: target regions are supervised in YCBCR space to pull luminance toward IR and chrominance/gradient toward VIS, while non-target regions use standard L1 + SSIM losses against both sources, enabling the network to learn instance-specific highlighting from text alone.

## Results

On LLVIP, the proposed method achieves Q_CB=0.511, Q_E=0.843, SF=14.572, VIF=0.996, and Q_AB/F=0.711, outperforming the best uncontrollable baseline FILM (Q_CB=0.485, Q_E=0.825, SF=14.361, VIF=0.976, Q_AB/F=0.675) and the only other controllable method TextFusion (Q_CB=0.455, Q_E=0.654, VIF=0.738, Q_AB/F=0.495). On M³FD, it reaches Q_Y=0.905 and VIF=0.838, surpassing FILM (Q_Y=0.839, VIF=0.806) and TextFusion (Q_Y=0.713, VIF=0.619). On MSRS and TNO, the method similarly leads on most supervised metrics, with VIF reaching 0.997 (MSRS) and 0.704 (TNO). In the downstream targeted object detection task, the fused images enable YOLO-v5 to achieve mAP@[0.5:0.95]=0.263, the highest among all 11 compared fusion methods.

## Baselines & Comparisons

Against the strongest uncontrollable baseline FILM, the proposed method wins on the majority of metrics across all four datasets, with the most notable gains in VIF (e.g., 0.996 vs 0.976 on LLVIP, 0.838 vs 0.806 on M³FD) and Q_AB/F (0.711 vs 0.675 on LLVIP). FILM retains a slight edge on MSRS VIF (1.056 vs 0.997) and Q_AB/F (0.723 vs 0.698), and on M³FD SF (16.757 vs 16.627). Compared to TextFusion—the only other controllable (text-driven) fusion method—the proposed model dominates across nearly every metric and dataset, with the largest gaps in VIF (e.g., 0.996 vs 0.738 on LLVIP, 0.838 vs 0.619 on M³FD) and Q_AB/F (0.711 vs 0.495 on LLVIP), reflecting superior instance-level highlighting. Against the remaining eight UIF baselines (FusionGAN, DIDFuse, GANMcC, DeFusion, ReCoNet, CDDFuse, DDFM, LRRNet), the proposed method consistently outperforms on all supervised metrics, with CDDFuse being the closest UIF competitor on MSRS (Q_CB 0.567 vs 0.570). In the downstream targeted object detection task, the proposed method achieves the highest mAP@[0.5:0.95] of 0.263, surpassing LRRNet (0.252), FILM (0.251), and TextFusion (0.243), confirming that instance-level controllable fusion translates into practical detection gains.

## Relation to Prior Work

This paper extends the controllable image fusion (CIF) line initiated by TextFusion [4] and TeRF [42], which achieve only semantic-level or region-level highlighting, to the more precise instance-level setting. It repurposes the classification-based text supervision paradigm from referring image segmentation [25] and introduces manifold similarity (computed via KNN graphs and Dijkstra shortest paths) as a novel weakly supervised signal, drawing on classical manifold learning theory [14, 36] rather than standard cross-attention. The instance selection module (ISM) deliberately departs from learned segmentation by using hand-crafted spatial rules, and the overall two-stage pipeline (pseudo-label generation → fusion training) is a new architectural choice for the VIS-IR fusion domain, where no prior work has addressed text-driven instance localization.

## Why It Matters / Open Questions

This is the first work to enable users to highlight a specific instance (e.g., 'the car on the right') in a fused VIS-IR image, which has direct practical value for targeted surveillance and autonomous driving where only one object among many matters. The weakly supervised formulation avoids the need for pixel-level annotations that are absent from all existing VIS-IR datasets, making the approach broadly applicable. However, the 12-rule spatial selection module is limited in expressiveness (no ordinal or relational descriptions beyond fixed positions), the method depends on OMG-Seg for instance proposals, and generalization to more complex referring expressions or other multi-modal fusion settings remains unexplored. Whether the manifold-similarity supervision transfers beyond VIS-IR to other multi-modal pairs is an open question.

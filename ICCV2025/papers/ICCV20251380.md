## Problem

Textual prompt tuning in federated CLIP overfits to seen classes because prompts learn a static context, severely limiting generalization to unseen classes and domains in the highly heterogeneous non-IID FL setting. Existing dynamic-prompt methods condition on either class-name text or visual features alone, but the paper argues that neither modality suffices: textual attributes miss visual/texture concepts, and visual features alone lack the semantic transferability that shared attributes provide across related classes.

## Input / Output

At inference, the method takes an RGB image (processed into b patch embeddings by the frozen ViT-B/16 CLIP vision encoder) and a set of LLM-generated textual class attributes (e.g., 'two legs', 'beak' for class 'hen') encoded by the frozen CLIP text encoder. The PromptFormer produces m=4 visual prompt tokens of dimension 768, which are concatenated with the [CLS] token and patch embeddings and fed through the frozen vision encoder. The final output is a classification probability over K classes computed via cosine similarity between the visual embedding and text embeddings of '[A photo of [CLASS]; LLM(c_k)]' for each class k.

## Method

FedMVP introduces a PromptFormer module that generates context-aware visual prompts via multi-head cross-attention: visual patch embeddings serve as queries while linearly projected LLM-attribute embeddings serve as keys and values, so that image regions attend to semantically relevant class attributes (e.g., leg patches attend to 'four legged'). The resulting m=4 prompts of dimension 768 are injected into the input of the frozen ViT vision encoder (visual prompt tuning), unlike prior FL methods that prompt the text encoder. Training uses a combined CLIP cross-entropy loss and a consistency loss (1 − cosine similarity between two augmented views of the same image, weighted by α=10), with only the PromptFormer parameters (Θ) being trainable. In the federated loop, clients share PromptFormer weights via FedAvg; to prevent overfitting on data-scarce clients, LoRA matrices on the attention Q/K/V projections are fine-tuned once local loss drops below 0.5, reducing per-client communication by ~267×.

## Results

On the Base-to-New Generalization setting (9 datasets), FedMVP achieves 78.27% harmonic mean accuracy, surpassing the best baseline FedTPG (76.70%) by +1.57%, with the largest gain on unseen new classes (+1.79% over FedTPG). On Domain Generalization (DomainBed MSST), FedMVP reaches 73.02% average accuracy vs. 71.03% for FedCLIP (+1.99%). On the most challenging Cross-Dataset Generalization setting (10 target datasets), FedMVP achieves 67.57% average accuracy, outperforming FedTPG (65.31%) by +2.26%. Across all three settings, FedMVP consistently leads by 1.57%–2.26% over the strongest competitor.

## Baselines & Comparisons

FedMVP outperforms all nine baselines across every evaluation setting. The closest competitor is FedTPG [21], which also conditions prompts on textual class information but lacks visual conditioning; FedMVP beats it by +1.57% HM on Base-to-New, +1.99% on DomainBed MSST, +1.69% on ImageNet DG, and +2.26% on Cross-Dataset Generalization. Among visual-prompting baselines, FedVPT [11] and FedCoCoOp [35] achieve competitive seen-class accuracy but suffer significant drops on unseen classes (e.g., FedCoCoOp drops to 66.00% New vs. FedMVP's 77.82%), confirming the overfitting issue from static prompts. Textual-prompting methods (PromptFL [7], FedKgCoOp [30]) and the multimodal MaPLe [13] similarly show weaker generalization to new classes. FedOTP [14] and FedCLIP [15] are the weakest baselines, with FedOTP falling below zero-shot CLIP on unseen classes (57.04% vs. 75.78%). Notably, FedMVP also surpasses the ZS-CLIP [22] zero-shot baseline by +4.03% HM, demonstrating that the learned multimodal prompts add substantial value over hand-crafted text prompts alone.

## Relation to Prior Work

FedMVP extends the federated prompt tuning lineage for CLIP (CoOp → FedTPG → FedCoCoOp) by unifying the two previously separate conditioning strategies—textual attribute features and visual patch embeddings—into a single multimodal prompt generator (PromptFormer) that uses cross-attention to fuse them. It departs from prior work in two key ways: (i) it conditions prompts on both LLM-generated class attributes and input image features simultaneously, rather than one modality alone, and (ii) it injects the resulting prompts into the frozen vision encoder (visual prompt tuning) rather than the text encoder, enabling instance-specific dynamic prompting without unlocking either encoder. The use of LLM-derived class attributes as a conditioning signal in a federated setting is, to the authors' knowledge, novel.

## Why It Matters / Open Questions

The paper addresses a practical and well-motivated limitation of federated prompt tuning—overfitting to seen classes due to static prompt context—and shows that richer multimodal conditioning consistently improves generalization across 20 datasets and three evaluation settings. However, the gains (+1.57–2.26%) are incremental rather than transformative, and the method introduces a dependency on an external LLM (GPT-4o) for attribute generation, which adds a non-trivial preprocessing cost and potential quality bottleneck. Performance drops on fine-grained datasets (OxfordPets, StanfordCars) due to overlapping attributes among visually similar categories suggest that attribute-based conditioning has inherent limits. Open questions include whether the approach generalizes beyond CLIP to other VLMs, whether the LLM dependency can be replaced with learned attribute extractors, and how the method behaves under more extreme data heterogeneity or with larger prompt lengths.

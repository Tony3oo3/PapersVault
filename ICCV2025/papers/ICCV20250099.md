## Problem

2D multi-person pose estimation models trained on sharp images suffer severe performance degradation under motion blur due to the large domain gap, yet conventional cameras rarely capture paired sharp-blurred images needed for supervised adaptation. No prior work has exploited event cameras—whose high temporal resolution makes them inherently blur-resistant—to bridge the sharp-to-blur domain gap for pose estimation without target-domain annotations.
![Teaser figure](../imgs/ICCV20250099/cropped_page0_idx0.webp)

## Input / Output

The method consumes 512×512 RGB images and temporally synchronized event streams; in the source domain both modalities carry ground-truth annotations, while in the target domain only unlabeled blurred images and events are available. Following the DEKR formulation, the network outputs a center heatmap (local argmax gives person centers), an offset map encoding per-keypoint displacement from the center, and per-keypoint heatmaps for 14 keypoints, from which multi-person poses are recovered via NMS and heatmap-based scoring. At test time, the student network can operate on image-only input if event data is unavailable, though performance drops modestly.

## Method

The core pipeline has four stages: (1) a multi-modal teacher (event-only sub-network + image-event fusion sub-network + a channel-attention refinement module) is pre-trained on source-domain data augmented with motion-aware blur generated by forward-warping a sharp image using event-derived optical flow across multiple time slices, then accumulating with hole-aware blending and a blur-translation loss; (2) a student network is trained on source annotations plus teacher-generated pseudo-labels in the target domain, with confidence-based pixel masking to suppress unreliable poses; (3–4) mutual uncertainty masking is applied alternately to the teacher and student, where a pose is retained only if both networks' confidence scores (each evaluated against the other's heatmaps) exceed a threshold, progressively refining pseudo-labels in a feedback loop. The key insight is that event data provides the motion information needed to synthesize physically realistic blur for augmentation, while the dual-network mutual masking exploits complementary failure modes—images fail under blur, events produce false positives—to filter out incorrect pseudo-labels without any target-domain ground truth.

## Results

On the EHPT-XC dataset, the proposed method (trained only on sharp-domain labels) achieves 51.6 mAP / 57.5 mAR on the blurred target domain and 64.2 mAP / 68.1 mAR on the sharp source domain, yielding an average of 57.9 mAP / 62.8 mAR. This substantially outperforms the best source-only baseline, Base(I+E) [16], which scores only 37.5 mAP on the target domain, and approaches the multi-modal oracle (Base(I+E) trained with both sharp and blur labels) at 58.8 mAP on the target domain. The method also maintains strong source-domain performance (64.2 mAP), exceeding DualTeacher(I+E) (60.1) and UDA-HE(I+E) (61.8) while remaining close to the source-only Base(I+E) (67.9).

## Baselines & Comparisons

The paper compares against four families of baselines, each evaluated in image-only (I), event-only (E), and multi-modal (I+E) variants. On the blurred target domain, the proposed method (51.6 mAP) outperforms the strongest source-only baseline Base(I+E) [16] by 14.1 mAP (37.5→51.6), DualTeacher(I+E) [1] by 17.0 mAP (34.6→51.6), and UDA-HE(I+E) [35] by 15.2 mAP (36.4→51.6). On the sharp source domain, Ours (64.2 mAP) trails Base(I+E) (67.9) by 3.7 mAP but exceeds both DualTeacher(I+E) (60.1) and UDA-HE(I+E) (61.8). The event-only variants of all baselines remain relatively stable across domains (e.g., Base(E) scores 43.5 mAP in both), confirming that event data is inherently blur-robust but lacks the spatial richness of images. Overall, the proposed method is the only source-only approach that narrows the gap to the multi-modal oracle (58.8 mAP target) to within 7.2 mAP, demonstrating that event-based augmentation plus mutual uncertainty masking effectively bridges the sharp-to-blur domain gap without any target-domain annotations.

## Relation to Prior Work

This paper builds directly on the DEKR architecture [24] for bottom-up multi-person pose estimation (center heatmap + offset + keypoint heatmaps) and extends the domain-adaptive pose estimation line of work (DualTeacher [1], UDA-HE [35]) to the previously unexplored sharp-to-motion-blur domain gap. The key conceptual departure is repurposing event cameras—previously used for deblurring, reconstruction, and low-light perception—as a tool to synthesize physically realistic motion blur via event-derived optical flow, rather than as a direct input modality for the target task. The student-teacher pseudo-label framework is standard, but the mutual uncertainty masking (cross-network confidence gating) and the multi-modal teacher with a channel-attention refinement module are new architectural contributions specific to this blur-adaptation setting.

## Why It Matters / Open Questions

This is the first work to close the sharp-to-blur domain gap in multi-person pose estimation without target-domain annotations, achieving performance close to the multi-modal oracle (51.6 vs. 58.8 mAP on the blur domain). The practical implication is significant for sports analytics, rehabilitation, and AR/VR where rapid motion and low light make conventional cameras unreliable, and the event-camera-based augmentation offers a scalable alternative to dual-camera beam-splitter setups. Limitations include dependence on a single dataset (EHPT-XC), the need for synchronized event streams during training, and the modest absolute gap to the oracle. Open questions include generalization to other blur types (camera shake, defocus), extension to 3D pose, and whether the approach transfers to other event-camera modalities or synthetic event generation.

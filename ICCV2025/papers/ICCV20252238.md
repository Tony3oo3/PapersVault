## Problem

Traditional ISP pipelines convert RAW sensor data to sRGB using sequential operations (demosaicing, white balance, tone mapping, etc.) designed for human visual quality, introducing irreversible information loss that degrades object detection performance. Existing learned ISP methods still follow this sequential design, where each stage is constrained by cumulative effects of earlier transformations, potentially discarding critical features before they reach the detector. This paper asks whether a parallel, task-optimized pre-processing approach can better preserve and leverage full sensor data for detection.

## Input / Output

The method takes a Bayer-pattern RAW image (12-bit to 24-bit, downsampled to 400 px height) and reshapes it into a 4-channel RGGB-stacked representation before processing. RAM outputs a 3-channel image with the same spatial dimensions as the input, which is then fed into a backbone (ResNet-18/50) and detector (Faster R-CNN, YOLOX, or DINO) to produce bounding boxes with class labels. Because RAM's output statistics are dynamic and input-dependent, standard mean-std normalization is replaced with learned batch normalization after the fusion stage.

## Method

RAM replaces the sequential ISP with a parallel architecture inspired by the human visual system's retinal pathways converging in V1. A single convolutional Raw Parameter Encoder (RPE) extracts a shared feature vector from the RGGB input, which is then fed to multiple MLP Raw Parameter Decoders (RPDs), each predicting parameters for a specific ISP function (gamma correction, brightness offset, 3×3 color correction matrix, and per-channel white balance gains). All four ISP functions are applied independently and in parallel to the original input, preserving information that sequential pipelines would irreversibly alter. A reverse-hourglass Feature Fusion module concatenates the four processed outputs into a multi-channel tensor, expands through a wider middle layer to capture rich feature interactions, then narrows back to a 3-channel representation. The entire pipeline—from RPE through fusion to the detector—is trained end-to-end using only the object detection loss, with no auxiliary reconstruction or perceptual terms.

## Results

RAM achieves state-of-the-art mAP across all seven RAW object detection datasets, with headline results of 44.5 mAP on ROD-Night (vs. 42.6 for the best prior method FeatEnHancer), 34.9 mAP on LOD-Dark (vs. 32.6 for GenISP), and 66.8 mAP on PASCALRAW (vs. 66.5 for FeatEnHancer). The module adds only 0.54M parameters and 1.05 ms inference latency over the baseline detector, and a tiny variant (RAM-T) with 0.2M parameters retains nearly all of the gain (44.2 mAP on ROD-Night). Under noisy and adverse-weather conditions, RAM degrades by only 2.5–3.5% mAP compared to 6.6–13.6% for RAW and sRGB baselines.

## Baselines & Comparisons

RAM outperforms all ten baselines on every dataset. Against the strongest sRGB-based enhancers (FeatEnHancer, YOLA), RAM gains +1.9 to +2.7 mAP on the most challenging low-light and HDR sets (LOD-Dark, ROD-Night). Against learned-ISP methods that optimize parameters via detection loss (Gamma, DynamicISP), the margin widens to +3.1 to +4.1 mAP on LOD-Normal and PASCALRAW, indicating that parallel fusion captures information lost by sequential ISP. Against the closest DNN-based ISP competitors, RAM beats GenISP by +1.2 mAP on NOD-Nikon and +1.7 on NOD-Sony, and RAOD by +3.9 mAP on ROD-Night and +2.1 on ROD-Day—both on the very datasets those methods were originally designed for. In the frozen-detector setting (Table 3), RAM with a pre-trained YOLOX-X achieves 50.8 mAP on LOD-Dark and 29.6 on NOD-Sony, surpassing AdaptiveISP (+2.9 / +2.4) and GenISP (+1.3 / +1.8) while using fewer parameters (0.54M vs. 17.35M for AdaptiveISP).

## Relation to Prior Work

This paper departs from the sequential ISP paradigm that underlies all prior RAW object detection methods (GenISP, RAOD, DynamicISP, AdaptiveISP), which apply ISP functions in a fixed pipeline where each stage's output feeds the next. RAM instead applies multiple ISP functions (gamma, brightness, CCM, white balance) in parallel on the original RAW input, inspired by the parallel pathways of the human visual system, and fuses their outputs via a reverse-hourglass module. The shared Raw Parameter Encoder with per-function MLP decoders is a lightweight design choice that reduces redundancy compared to prior methods that either use a single CNN to generate all parameters or apply functions sequentially with cumulative distortion.

## Why It Matters / Open Questions

The practical significance lies in demonstrating that RAW sensor data, when processed with a task-adaptive parallel module, can substantially outperform sRGB in challenging real-world conditions (low light, noise, adverse weather) while adding minimal latency (+1.05 ms) and parameters (+0.54 M). The Shapley analysis revealing dataset-specific importance of individual ISP functions suggests that a one-size-fits-all ISP pipeline is fundamentally suboptimal, opening the door to more granular, condition-aware preprocessing. Limitations include evaluation on relatively small datasets (≤12K images), only four ISP functions, and a focus on object detection; whether the parallel architecture generalizes to segmentation, tracking, or larger-scale benchmarks remains open.

## Problem

Existing low-light video enhancement methods either apply per-frame enhancement (causing flickering artifacts) or relate adjacent/random frames for consistency (causing overexposure and lacking true temporal continuity). No prior work has modeled the progressive, memory-based video understanding process of humans—first refining intra-frame quality, then integrating accumulated temporal memory—into a unified LLVE framework.
![Teaser figure](../imgs/ICCV20250115/cropped_page0_idx1.webp)

## Input / Output

The network takes a low-light video frame X_t (128×128 crops during training; 1080P/2K in evaluation) and a dynamically maintained set of historical keyframe features S={k_1,...,k_n} stored as key-value pairs in a hierarchical memory pool. It outputs an enhanced frame X̂_t = L̂_t · R̂_t, where the illumination map L̂_t is estimated via MaxRGB decomposition and the reflectance map R̂_t is denoised with illumination guidance. The MC is plug-and-play and adds only ~7 ms inference overhead per frame.

## Method

RetinexMCNet is an encoder–MC–decoder architecture trained in two stages: stage one performs per-frame enhancement (disabling the MC) using a channel-aware Illumination Adjustment Module (IAM) with Self-Gating Channel Attention and an Illumination Normalization prior that decouples noise from illumination, plus an illumination-guided Reflectance Denoising Module (RDM) with Illumination-Guided Denoising Attention; stage two activates the Memory Controller (MC) to integrate temporal memory. The MC maintains a hierarchical pool (Working Memory + Long-term Memory) that stores low-similarity keyframes and averages homogeneous ones, then retrieves top-k relevant contexts via similarity-weighted attention and fuses them with the current encoded feature through a Fused Attention mechanism. A novel Lightness-Texture Stability (LTS) loss—combining a relative-lightness-order maintenance/correction term and a patch-wise texture-complexity term—prevents overexposure and preserves detail without relying solely on pixel-level fidelity to potentially overexposed ground truth.

## Results

On the SDSD dataset, RetinexMCNet achieves 27.81 dB PSNR and 0.88 SSIM, surpassing the previous best LLVE method LAN by 0.56 dB in PSNR. On the DID dataset, it reaches 30.09 dB PSNR and 0.92 SSIM, outperforming LAN by 1.81 dB in PSNR. The method also outperforms all LLIE baselines (e.g., RetinexFormer at 26.24 dB on SDSD) and all other LLVE methods (e.g., StableLLVE at 22.28 dB on SDSD), demonstrating that the two-stage encoder-MC-decoder architecture with Retinex-based decomposition effectively addresses both intra-frame quality and inter-frame consistency.

## Baselines & Comparisons

RetinexMCNet outperforms all 16 baselines on PSNR across both SDSD and DID datasets. On SDSD, it beats the strongest LLVE competitor LAN [11] by 0.56 dB (27.81 vs. 27.25) and the best LLIE method RetinexFormer [2] by 1.57 dB (27.81 vs. 26.24). On DID, the margin over LAN is larger at 1.81 dB (30.09 vs. 29.01), and it surpasses RetinexFormer by 2.70 dB. On SSIM, the method achieves the best score on SDSD (0.88 vs. LAN's 0.85) but trails LAN slightly on DID (0.92 vs. 0.94). Among other LLVE methods, the gap is substantial: StableLLVE [36] lags by 5.53 dB on SDSD, BRVE [37] by 1.50 dB, and SDSDNet [27] by 2.89 dB. The consistency analysis (Table 2) further shows that plugging the MC into existing LLIE/adjacent/random-frame models reduces MABD by 34–41%, confirming the memory controller's plug-and-play benefit for temporal coherence.

## Relation to Prior Work

This paper extends the Retinex-based low-light enhancement lineage (Land 1977; URETINEX-Net, CVPR 2022) from single-frame to video by introducing a hierarchical memory controller adapted from XMem's Atkinson-Shiffrin model (ECCV 2022). It departs from prior LLVE methods that either process frames independently (LLIE), relate only adjacent frames, or use random-frame consistency losses, by framing temporal consistency as progressive accumulation of historical keyframes in a working/long-term memory pool. The two-stage training strategy—first optimizing intra-frame quality without the MC, then activating it for inter-frame consistency—mirrors a human progressive video understanding narrative not previously formalized in LLVE.

## Why It Matters / Open Questions

The plug-and-play MC, which reduces mean absolute brightness difference by 34–41% when grafted onto three architecturally distinct base models, offers a practical drop-in component for any video enhancement pipeline. The LTS loss directly tackles the persistent overexposure problem in Retinex-based methods, and its applicability to other intra-frame techniques broadens its utility. Open questions include how the fixed-capacity memory pool scales to very long videos or high resolutions (experiments use 128×128 crops), whether the two-stage training is strictly necessary versus end-to-end joint optimization, and how the method performs under domain shifts beyond the four tested datasets.

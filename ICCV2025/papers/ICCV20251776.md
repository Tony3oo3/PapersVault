## Problem

Existing facial analysis pipelines require separate specialized models with task-specific pre-processing for each of the ten major tasks (parsing, landmarks, pose, attributes, age/gender/race, expression, recognition, visibility), making simultaneous deployment computationally impractical. Prior multi-task face models (QFace, Faceptor, SwinFace) cover only 4–7 tasks, rely on heavy 9-layer decoders, and do not handle complex tasks like segmentation or landmark detection. No single model had previously unified all ten tasks while maintaining real-time inference speed.
![Teaser figure](../imgs/ICCV20251776/cropped_page0_idx0.webp)

## Input / Output

The model takes a single 224×224 RGB face image (half the resolution required by competing SOTA methods like EAGRNet at 473 or Faceptor at 512) and simultaneously produces ten outputs: an 11-class face parsing segmentation map, 68 2D landmark coordinates, a 3×3 head-pose rotation matrix, 40 binary attribute labels, a continuous age value, gender and race class labels, an expression class label, a face identity embedding (via PartialFC), and a face visibility label. All ten predictions are generated in one forward pass at 33.21 FPS on fp32.

## Method

FaceXFormer uses a Swin-B encoder to extract multi-scale features, which are fused into a single unified face representation via a SegFormer-style MLP-Fusion module (only 983k parameters). Each of the ten tasks is represented by a learnable task token, and a lightweight 2-layer FaceX decoder processes face and task tokens jointly through three attention stages: Task Self-Attention (task tokens attend to each other), Task-to-Face Cross-Attention (task tokens query the face representation), and Face-to-Task Cross-Attention (face tokens query updated task tokens), forming a bi-directional cross-attention loop. This bidirectional design replaces the 9-layer DETR-style decoders used by prior multi-task face models, cutting decoder depth to 2 layers and enabling real-time speed. A unified head then maps each refined task token to its prediction via task-specific modules (hourglass network for landmarks, PartialFC for recognition, regression/classification MLPs for the rest, and an upsampling + cross-product layer for parsing). Training uses a weighted sum of ten task-specific losses (dice+CE, STAR, geodesic, ArcFace, BCE-with-logits, etc.) with upsampling to balance datasets of varying sizes across 12 epochs on 8 A6000 GPUs.

## Results

FaceXFormer achieves state-of-the-art performance on face parsing (mean F1 = 91.01 on CelebAMaskHQ at 224×224, half the resolution of prior SOTA), head pose estimation (MAE = 3.52 on BIWI), landmark detection (NME = 4.67 on 300W), attribute prediction (91.83% on CelebA), and face visibility (72.56% on COFW). It achieves the second-best age estimation (MAE = 4.17 on UTKFace, behind Faceptor's 4.10) and competitive expression recognition (88.24% on RAF-DB). In face recognition, it outperforms the multi-task Faceptor (95.94% vs. 95.28% mean accuracy) but trails specialized models like AdaFace (97.41%). The model runs at 33.21 FPS, a 69.44% speed improvement over prior multi-task models.

## Baselines & Comparisons

FaceXFormer outperforms all prior multi-task models (Faceptor, QFace, SwinFace) on every task they share, and also beats task-specific SOTA on face parsing (91.01 vs. Faceptor 90.89, EAGRNet 90.87), head pose (MAE 3.52 vs. MFDNet 3.62), landmarks (NME 4.67 vs. Faceptor 4.84, PIPNet 4.89), attributes (91.83% vs. SSPL 91.77%), and visibility (72.56% vs. MNN 72.12%). On age estimation, it is narrowly behind Faceptor (4.17 vs. 4.10 MAE) but ahead of VOLO-D1 (4.23) and DLDL-v2 (4.42). For facial expression recognition, QFace (92.86%) and DMUE (88.76%) remain ahead of FaceXFormer (88.24%), though the gap to the specialized DMUE is small. In face recognition, FaceXFormer (95.94% mean) surpasses Faceptor (95.28%) by 0.66 points but still lags specialized methods like AdaFace (97.41%) and VPL-ArcFace (97.42%) by ~1.5 points, which the authors attribute to conflicting multi-task objectives pushing toward identity-invariant features. Overall, FaceXFormer is the first model to simultaneously handle all ten tasks while achieving SOTA or near-SOTA on most, at 33.21 FPS.

## Relation to Prior Work

FaceXFormer adapts the DETR paradigm of learnable query tokens from object detection to facial analysis, where each task is represented by a dedicated token rather than a separate head. It builds directly on SegFormer's MLP-Fusion module for multi-scale feature aggregation and departs from prior multi-task face models (QFace, Faceptor, SwinFace) by replacing their 9-layer transformer decoders with a 2-layer FaceX decoder that uses a novel bi-directional cross-attention mechanism. Unlike QFace and Faceptor, FaceXFormer does not require a face-specific pretrained backbone, and it extends the unified-transformer trend (SAM, CLIP) to the constrained, real-time domain of facial analysis.

## Why It Matters / Open Questions

FaceXFormer is the first model to simultaneously handle ten heterogeneous facial analysis tasks at real-time speed (33.21 FPS), which has direct practical value for deployment in surveillance, retail, and driver-assistance systems where multiple annotations are needed from a single forward pass. A key limitation is that face recognition underperforms specialized models (95.94% mean vs. 97.42% for VPL-ArcFace), revealing a fundamental tension between identity-specific and identity-invariant representations in multi-task training. Open questions include whether the bi-directional cross-attention decoder generalizes to non-facial domains, whether adding further tasks degrades performance, and whether the conflicting-objective problem in face recognition can be mitigated without sacrificing the unified framework.

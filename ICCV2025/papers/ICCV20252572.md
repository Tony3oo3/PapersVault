## Problem

In few-shot class-incremental learning, freezing a pre-trained VLM backbone mitigates catastrophic forgetting but leaves novel-class prototypes semantically biased due to extreme data scarcity. Existing calibration methods (e.g., TEEN) compensate by blending entire similar base prototypes into novel ones, which compresses inter-class distances and causes feature-space entanglement. The missing piece is a mechanism to identify *which specific attribute-level components* of base prototypes are transferable to a given novel class, enabling targeted calibration without global distortion.

## Input / Output

The method consumes RGB images encoded by a frozen CLIP ViT-B/16 (512-d visual features) and LLM-generated text attribute keywords per class (e.g., 'rectangular', 'slots' for 'toaster'). It produces calibrated 512-d class prototype vectors that are used with a distance-based classifier at inference. The incremental phase is entirely training-free; only the base phase applies LoRA fine-tuning with an image-text contrastive loss to bridge the domain gap. The keyword grounding function internally accesses CLIP's last-layer attention matrix A and value matrix V, making the method dependent on CLIP's specific transformer architecture rather than a generic feature extractor.

## Method

FDR operates in two stages. First, a semantic feature decomposition stage uses LLMs to generate class descriptions and extract attribute keywords, then a keyword grounding function G_φ exploits CLIP's final transformer-layer attention weights and value vectors to produce sparse binary masks (top-q binarization) that map each keyword to specific feature dimensions; element-wise multiplication of these masks with base-class prototypes yields semantically meaningful feature segments. Second, a recomposition stage calibrates each novel-class prototype by, for every keyword, retrieving the top-r most similar base-class segments (ranked by textual-segment cosine similarity with softmax weighting) and iteratively updating the prototype via a weighted interpolation (Eq. 9) with trade-off parameter α. Although each per-keyword update is a linear combination of base segments, the overall calibration is nonlinear because different keywords select different subsets of base classes and different feature dimensions, yielding combinatorial diversity that grows exponentially with the number of base classes. The entire pipeline is training-free in the incremental phase and requires no gradient updates on novel-class data.

## Results

In the 5-shot setting (Table 1), FDR with LoRA fine-tuning achieves 79.3% AvgAcc on CIFAR-100, 89.2% on miniImageNet, 77.7% on CUB-200, and 70.9% on IN1K-FSCIL, outperforming all training-based competitors on CIFAR-100, CUB-200, and IN1K-FSCIL. In the training-free setting, FDR surpasses TEEN by 0.1–0.5% AvgAcc across all four datasets. Under the extreme 1-shot CUB-200 protocol (Table 2), FDR achieves 6.70%–19.66% NAcc improvement over TEEN across incremental sessions, with the largest gain (+19.66%) in Session 1 where only a single sample per novel class is available.

## Baselines & Comparisons

Against the closest training-free competitor TEEN [1], FDR wins on all four datasets in both training-free and fine-tuned settings, with the most dramatic gains in the 1-shot CUB-200 protocol where NAcc improves by 6.70%–19.66% over TEEN's holistic calibration. Among training-based methods, FDR (with LoRA) outperforms CLOSER [2] (79.3% vs 63.1% on CIFAR-100), Yourself [6] (79.3% vs 67.0%), PriViLege [5] (79.3% vs 77.2%), and EASE [3] (79.3% vs 78.0%) on CIFAR-100, and similarly leads on CUB-200 (77.7% vs 69.1–75.1%) and IN1K-FSCIL (70.9% vs 68.9–70.4%). However, FDR trails LP-DiF [4] (89.2% vs 93.8%) and EASE [3] (89.2% vs 93.9%) on miniImageNet, where the smaller class count and simpler visual attributes reduce the benefit of fine-grained keyword decomposition. Against older ResNet-18-based methods (TOPIC [22], CEC [30], FACT [32]), FDR with CLIP achieves substantially higher AvgAcc (e.g., 79.38% vs 26.26–73.23% on CUB-200 Session 10), reflecting the advantage of the frozen CLIP backbone over task-specific architectures.

## Relation to Prior Work

This paper extends the prototype-based metric learning paradigm for FSCIL (rooted in Prototypical Networks) by replacing the holistic prototype calibration used in TEEN with a fine-grained, attribute-level decomposition-recomposition strategy. It specifically exploits CLIP's last-layer attention and value matrices to ground LLM-generated attribute keywords to specific feature dimensions, enabling transferable semantic segments across classes. The key departure from prior calibration methods (TEEN, CEC, FACT) is that instead of globally blending a novel prototype with similar base prototypes—which compresses inter-class distances—FDR selectively recomposes only the keyword-matched segments, preserving class-discriminative dimensions while correcting biased ones.

## Why It Matters / Open Questions

The training-free, fine-grained calibration approach offers a practical recipe for FSCIL that avoids the prototype entanglement problem inherent in holistic calibration, with particularly strong gains in the 1-shot regime (up to 19.66% NAcc improvement). However, the method's reliance on LLM-generated descriptions and CLIP's specific internal attention structure limits its generality to other backbones or modalities, and the modest 5-shot gains (+3–6% NAcc) suggest the benefit diminishes as more samples reduce prototype bias. Open questions include whether the keyword grounding mechanism transfers to non-CLIP architectures, how it behaves when LLM descriptions are inaccurate or incomplete, and whether the exponential combinatorial space of segment recomposition can be exploited for multi-session incremental settings beyond the current single-step calibration.

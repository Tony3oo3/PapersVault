## Problem

Existing 3D Gaussian Splatting methods for scene understanding treat reconstruction and segmentation as decoupled tasks and rely on continuous learnable semantic features that become ambiguous during alpha blending. This paper identifies that semantics are inherently discrete, so blending them as continuous vectors conflates object identities, and that reconstruction quality directly affects segmentation accuracy (and vice versa).
![Teaser figure](../imgs/ICCV20252698/cropped_page0_idx0.webp)

## Input / Output

The method consumes multi-view RGB images, a COLMAP-reconstructed point cloud with camera poses, and optional text or click prompts (via Grounded-SAM) to specify target objects. A key implementation detail is that the Gaussian color attribute dimension is extended from 3 to N+3 (where N is the number of scene objects), so the one-hot ID vector is rasterized alongside RGB in a single pass using a custom variable-length feature alpha-blending kernel. Outputs include a full 3D Gaussian scene with per-anchor object IDs, per-pixel object ID segmentation maps, extractable per-object meshes (via 2DGS + TSDF fusion), and editable scenes (object removal/recoloring by manipulating anchor-bound Gaussians).

## Method

ObjectGS builds on Scaffold-GS's anchor-based hierarchy, where each voxel-grid anchor carries a local feature, scaling factor, and k learnable offsets that generate k Gaussian primitives. The key architectural novelty is binding a discrete object ID to every anchor: during the grow-and-prune training loop, new anchors inherit their parent's ID, ensuring each object's Gaussians are generated exclusively from same-ID anchors. For semantic modeling, instead of learnable continuous features, each Gaussian is assigned a fixed one-hot ID encoding vector of length N; during rendering, alpha blending accumulates these vectors per pixel, and the predicted object ID is obtained by argmax over the accumulated vector. A cross-entropy classification loss (rather than L1) supervises this discrete prediction against 2D pseudo-labels from DEVA/Grounded-SAM, and a custom variable-length feature rasterizer makes the ID vector length adaptable to scenes with different object counts. Object IDs are initialized on the COLMAP point cloud via majority voting across projected 2D masks, and the entire pipeline is trained end-to-end for 30k iterations with combined L1+SSIM appearance loss, Scaffold-GS volume regularization, and the semantic classification loss.

## Results

On the LERF-Mask open-vocabulary segmentation benchmark, ObjectGS achieves mIoU of 88.2 (figurines), 88.0 (ramen), and 88.9 (teatime), outperforming the previous best (Gaussian Grouping) by 18.5, 11.0, and 17.2 points respectively. On 3DOVS, ObjectGS reaches a mean IoU of 96.4, surpassing SAGA (96.0) and LBG (94.9). For panoptic segmentation, ObjectGS improves IoU from 83.36 to 95.38 on Replica and from 89.82 to 95.38 on ScanNet++ over Gaussian Grouping, while also improving reconstruction quality (PSNR 30.24 vs 28.35 on ScanNet++).

## Baselines & Comparisons

ObjectGS outperforms Gaussian Grouping [47] across all four datasets: on LERF-Mask it gains 11–18 mIoU points, on 3DOVS it achieves 96.4 vs 89.1 mean IoU, and on panoptic segmentation it improves IoU by 12.0 (Replica) and 5.6 (ScanNet++) points. Against the strongest 3DOVS baselines SAGA [4] (96.0) and LBG [5] (94.9), ObjectGS leads by 0.4 and 1.5 mean IoU respectively, with the largest margin on the 'sofa' category (95.4 vs 93.5 and 87.4). On LERF-Mask figurines, GAGA [28] slightly edges out ObjectGS (90.7 vs 88.2 mIoU), but ObjectGS dominates on ramen (88.0 vs 64.1) and teatime (88.9 vs 69.3), where GAGA's 3D-aware memory bank struggles. Compared to LangSplat [33], ObjectGS improves mIoU by 35–39 points across all three LERF-Mask scenes, demonstrating the advantage of discrete one-hot ID encoding over learnable CLIP-based semantic fields. For 3D instance segmentation on ScanNet++, ObjectGS achieves F1 of 43.4% vs 41.6% for Gaussian Grouping, with a substantially higher recall (86.1% vs 66.5%), indicating fewer missed object points.

## Relation to Prior Work

ObjectGS builds directly on Scaffold-GS's anchor-based hierarchical Gaussian generation, extending it by binding object IDs to anchors so that growing/pruning operations preserve object identity. It departs from the dominant paradigm in open-world 3D segmentation (LangSplat, Gaussian Grouping, SAGA, LBG), which distills continuous learnable semantic features into Gaussians and relies on contrastive or regularization losses to disambiguate them. The key conceptual shift is replacing these learnable features with a fixed one-hot ID encoding and a cross-entropy classification loss, arguing that semantics are inherently discrete and should not be blended continuously during alpha compositing. For initialization, it leverages existing 2D pipelines (DEVA for ID-consistent masks, Grounded-SAM for open-vocabulary prompts) and lifts them to 3D via majority voting on COLMAP point clouds.

## Why It Matters / Open Questions

By unifying reconstruction and semantic understanding in a single training loop, ObjectGS avoids the decoupling that plagues prior methods where segmentation quality is bottlenecked by reconstruction errors. The discrete one-hot formulation is simple, occlusion-aware (single scene-level render pass), and scales naturally to downstream tasks like per-object mesh extraction and scene editing without additional classifiers. A key limitation is the dependence on 2D segmentation quality for initialization, and the one-hot encoding length grows linearly with the number of objects, which could become impractical for very dense scenes. An open question is whether the anchor-level object binding generalizes to dynamic or partially observed objects where 2D masks are unreliable.

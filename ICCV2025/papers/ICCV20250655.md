## Problem

Existing weakly supervised occupancy estimation methods rely on dense 3D voxel grids that waste computation on empty space, and their temporal rendering supervision breaks down when dynamic objects move between frames, introducing inconsistent training signals. No prior method combines a fully sparse scene representation with explicit modeling of object motion during temporal supervision.
![Teaser figure](../imgs/ICCV20250655/cropped_page0_idx2.webp)

## Input / Output

The model takes 6 surround-view RGB images at 256×704 resolution along with their camera intrinsics/extrinsics as input. It outputs a sparse set of 10,000 3D Gaussians, each parameterized by a 3D mean, opacity, anisotropic scale, rotation quaternion, and 17-class semantic logits. Training supervision comes entirely from 2D pseudo labels (semantics from GroundedSAM, depth from Metric3D) rendered via Gaussian Splatting; the Gaussian output can be voxelized post-hoc onto the standard Occ3D-nuScenes grid for benchmark comparison.

## Method

GaussianFlowOcc replaces dense voxel grids with a sparse set of 3D Gaussians refined by a Gaussian Transformer that uses Induced Self-Attention (ISA) and Induced Temporal Attention (ITA) to achieve near-linear complexity in the number of Gaussians, enabling 10,000 Gaussians where standard quadratic attention would exhaust GPU memory. A Temporal Module estimates a per-Gaussian 3D flow offset to each temporally adjacent frame, correcting for dynamic object motion so that Temporal Gaussian Splatting (rendering into T=6 neighboring frames) provides consistent supervision without requiring ground-truth flow. Training is fully weakly supervised: the Gaussians are rasterized back into camera views via differentiable Gaussian Splatting, and losses are computed against 2D pseudo depth and semantic segmentation maps, eliminating any need for 3D voxel annotations or LiDAR.

## Results

On the Occ3D-nuScenes validation set, GaussianFlowOcc achieves 17.08 mIoU, 46.91 IoU, and 16.47 RayIoU, outperforming all prior weakly supervised methods. It runs at 10.2 FPS on a single A100 GPU, making it 50× faster than GaussTR (0.20 FPS) and ~9× faster than voxel-based baselines like GaussianOcc (5.57 FPS). The method uses only a ResNet-50 backbone with 2D pseudo labels from GroundedSAM and Metric3D, requiring no 3D voxel annotations or LiDAR data.

## Baselines & Comparisons

GaussianFlowOcc outperforms all four baselines on every reported metric. Against SelfOcc (10.54 mIoU) and OccNeRF (10.81 mIoU), which rely on volume rendering with photometric losses, it achieves a 51–62% relative mIoU gain. Compared to GaussianOcc (11.26 mIoU, 11.85 RayIoU), which also uses Gaussian Splatting but retains a dense voxel grid, GaussianFlowOcc improves mIoU by 52% and RayIoU by 39% while being nearly 2× faster. The closest competitor, GaussTR (13.26 mIoU), uses multiple ViT-L backbones (CLIP, Metric3D) at inference; GaussianFlowOcc surpasses it by 29% mIoU (17.08 vs 13.26) and is 50× faster (10.2 vs 0.20 FPS) using only a lightweight ResNet-50. The authors attribute the gains primarily to the Temporal Module (which adds 20% relative mIoU in ablation) and the induced attention mechanism that enables 10,000 Gaussians at linear memory cost.

## Relation to Prior Work

GaussianFlowOcc sits at the intersection of 3D Gaussian Splatting for scene representation, Set Transformer-style induced attention for efficient set processing, and weakly supervised occupancy estimation via differentiable rendering. It departs from prior voxel-based occupancy methods (SelfOcc, OccNeRF, GaussianOcc) by replacing dense grids with a sparse set of 3D Gaussians, and from the closest Gaussian-based competitors (GaussianFormer, GaussTR) by introducing induced self- and temporal attention that scales to 10K Gaussians with linear memory, plus a Temporal Module that estimates per-Gaussian 3D flow to handle dynamic objects during Temporal Gaussian Splatting. The training paradigm follows the weakly supervised line (2D pseudo labels from GroundedSAM and Metric3D rendered back via splatting), but the explicit motion compensation is a new element not present in any prior occupancy or reconstruction method.

## Why It Matters / Open Questions

The 50× inference speedup over GaussTR and the elimination of LiDAR-based 3D annotations make this approach significantly more deployable for real-time autonomous driving perception. The Temporal Module's 20% relative mIoU gain demonstrates that naive temporal rendering without motion compensation is a meaningful source of error, a finding that should inform future self-supervised 3D methods. Open questions remain: self-supervised RGB rendering provided no benefit (suggesting the current splatting pipeline may not fully exploit photometric cues), the temporal horizon is limited to T=6 before divergence, and the dynamic object modeling is still a simple per-Gaussian offset rather than a physically informed motion model. The induced attention mechanism could generalize to other sparse 3D tasks beyond occupancy.

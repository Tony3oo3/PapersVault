## Problem

Existing identity-preserving image personalization methods face two intertwined limitations: single-ID approaches either lose spatial facial detail (global embeddings) or overfit spurious appearance details due to insufficient disentanglement, reducing editability; multi-ID approaches suffer from identity blending and require either rigid one-to-one text-to-ID prompt mappings or predefined layout masks that constrain generation diversity.
![Teaser figure](../imgs/ICCV20250088/cropped_page0_idx2.webp)

## Input / Output

The method accepts one or more reference face images (cropped and aligned) plus a free-form text prompt, with no requirement for facial landmarks, layout masks, or singular-form subject phrases. It outputs a 512×512 RGB image (Stable Diffusion v1.5 latent space) that preserves the identity of each reference face while following the prompt's scene, style, and composition. For multi-ID generation, the number of reference images determines the number of identities to embed, and the model autonomously decides where each face appears in the output.

## Method

UniPortrait introduces two plug-and-play modules on top of Stable Diffusion. The ID embedding module extracts intrinsic ID features from the penultimate layer of a CurricularFace backbone (retaining spatial structure) and face structure features from CLIP local features plus shallow backbone layers, aggregating them via a 6-layer Q-Former with 16 learnable queries; DropToken and DropPath are applied to the structure branch to decouple it from intrinsic ID, enabling a tunable fidelity–editability trade-off. The ID routing module inserts a position-wise router into each cross-attention layer that predicts a discrete probability over N IDs at every spatial location and selects the top-1 ID for that location, preventing identity blending without layout constraints; a routing regularization loss (L2 against detected face-region masks) enforces that all IDs are routed and each ID maps to at most one face area, while Gumbel-softmax enables gradient backpropagation during training. Training proceeds in two stages: Stage I trains the ID embedding module and U-Net LoRA on single-ID images, and Stage II freezes the embedding module and fine-tunes only the router and LoRA on multi-ID images with the combined diffusion + routing loss.

## Results

On single-ID customization (Table 1), UniPortrait achieves 71.1% FaceNet similarity, 26.1% CLIP-T, 123.4 FID, and 6.42 LAION-Aesthetics, outperforming all SD1.5-based baselines. On multi-ID customization (Table 2), UniPortrait achieves 67.3% Face Sim, 27.4% CLIP-T, 139.5 FID, 5.89 LAION-Aes, and a blending score of 7.6%, setting new state-of-the-art across all metrics. The method also demonstrates strong compatibility with existing control tools (ControlNet, IP-Adapter, community checkpoints) without additional training.

## Baselines & Comparisons

UniPortrait outperforms FastComposer [49] on every metric in multi-ID generation: Face Sim 67.3% vs. 38.0%, CLIP-T 27.4% vs. 25.5%, FID 139.5 vs. 156.6, and blending score 7.6% vs. 12.9%, while also supporting free-form plural prompts that FastComposer cannot handle. Against IP-Adapter-FaceID-PlusV2 [51], UniPortrait improves Face Sim from 7.7% to 67.3% in multi-ID (and from 68.4% to 71.1% in single-ID), with the routing module alone boosting IP-Adapter's multi-ID Face Sim to 60.5%. InstantID [45] achieves higher single-ID Face Sim (77.9%) but at the cost of requiring 5-point facial landmarks as input, yielding lower CLIP-T (24.1%) and FID (163.5) due to reduced editability. In multi-ID, UniPortrait also surpasses SDXL-based methods MuDI [18] (Face Sim 44.2%, BS 36.8%) and StoryMaker [55] (Face Sim 57.4%, FID 180.4) on all reported metrics. The ablation (Table 3) confirms the routing regularization loss is critical, lifting multi-ID Face Sim from 59.1% (argmax-only router) to 67.3%.

## Relation to Prior Work

UniPortrait builds on the Stable Diffusion latent diffusion framework and the IP-Adapter paradigm of injecting image conditions via decoupled cross-attention, while adopting the Q-Former architecture from BLIP-2 as the aggregation backbone for ID embeddings. It departs from prior single-ID methods (FaceStudio, InstantID, IP-Adapter-FaceID-Plus) by replacing global face-recognition features with spatially-structured penultimate-layer features and adding shallow backbone features for face structure, coupled with a DropToken/DropPath decoupling strategy to prevent overfitting to identity-irrelevant details. For multi-ID personalization, it moves beyond both text-embedding integration (Custom Diffusion, MuDI) and manual layout masks (InstantFamily, OMG) by introducing a learned position-wise routing network within cross-attention that adaptively assigns each spatial location to a single ID without requiring predetermined layouts or restricted prompt formats.

## Why It Matters / Open Questions

The unified single/multi-ID framework with a plug-and-play routing module is practically significant because it can be combined with existing community tools (ControlNet, IP-Adapter, LoRA) without retraining, lowering the barrier for identity-preserving generation in production pipelines. The decoupling strategy offers a tunable trade-off between identity fidelity and facial editability, addressing a long-standing tension in the field. Limitations include reliance on SD1.5 (not natively SDXL), the routing mechanism being designed specifically for face regions (generalization to non-face multi-subject scenarios is untested), and the need for face detection during training for the routing regularization. Open questions include whether the routing approach scales gracefully beyond 2–3 simultaneous IDs and whether it transfers to video or 3D generation settings.

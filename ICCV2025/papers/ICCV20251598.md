## Problem

Existing test-time prompt tuning methods for vision-language models treat text and visual prompts as fixed learnable parameters, preventing data-specific adaptation at inference and leaving performance sensitive to template choice and augmentation bias. No prior work has applied variational inference to prompt learning for VLMs, nor has any method dynamically generated modality-specific prompts per test sample while modeling layer-wise prompt dependencies.
![Teaser figure](../imgs/ICCV20251598/cropped_page3_idx0.webp)

## Input / Output

At test time, the method consumes a single RGB image and a set of 10 text templates (each containing a class name placeholder), generating 63 augmented views via random resized crops and horizontal flips to form a batch of 64 images. The HyperTransformer processes frozen CLIP patch embeddings and tokenized text embeddings to produce modality-specific prompt tokens, which are then fed back into the CLIP encoders to yield a class label and softmax probability over K classes. The entire prompt generation and variational optimization occurs per-sample at inference without any retraining of the backbone.

## Method

The framework introduces three nested components. First, a HyperTransformer with separate text and visual branches (each a 4-layer lightweight transformer) dynamically generates data-specific prompt tokens from frozen CLIP embeddings at test time, replacing fixed learnable prompt parameters. Second, variational prompt generation models each prompt as a probabilistic latent variable: the text prior is anchored to the default template 'a photo of <CLASS>' while the posterior is generated from 9 alternative templates, and the visual prior uses the original image while the posterior uses augmented views, with the ELBO (KL divergence plus entropy regularization) as the training objective. Third, hierarchical variational prompt generation conditions each layer's prompt distribution on the previous layer's output for both modalities, so that prompts are iteratively refined across L layers, capturing deeper contextual dependencies. The total loss sums per-layer KL divergences between hierarchical priors and posteriors plus entropy terms, optimized jointly with the HyperTransformer parameters.

## Results

On the cross-dataset transfer benchmark (10 datasets), the proposed Hierarchical Variational Prompt Generation achieves 68.84% average top-1 accuracy, outperforming the strongest baselines TDA (67.53%) and DynaPrompt (67.29%). On the domain generalization setting (4 OOD ImageNet variants), the method reaches 65.89% OOD average accuracy, surpassing DynaPrompt (64.31%) and TDA (63.89%). The largest gains appear on ImageNet-Sketch (52.71% vs. 50.54% for TDA) and FGVC-Aircraft (28.93% vs. 25.60% for DiffTPT), indicating particular strength under high domain discrepancy and fine-grained recognition.

## Baselines & Comparisons

The proposed method outperforms all 11 baselines on both the cross-dataset transfer (Table 4) and domain generalization (Table 5) benchmarks. The closest competitors are TDA (67.53% avg) and DynaPrompt (67.29% avg) on cross-dataset transfer, with the proposed method leading by 1.31 and 1.55 percentage points respectively; on domain generalization, the gap widens to 2.00 and 1.58 points over TDA and DynaPrompt. Against the foundational CLIP baseline (63.58%), the improvement is 5.26 points, and over MaPLe+TPT (66.50%), the most directly comparable prior method, the gain is 2.34 points. The largest per-dataset margin is on FGVC-Aircraft, where the method achieves 28.93% versus 25.60% (DiffTPT) and 24.80% (PromptAlign), a 3.3–4.1 point advantage. On the domain generalization setting, the method leads on all four OOD ImageNet variants, with the most pronounced gain on ImageNet-Sketch (52.71% vs. 50.54% for TDA, a 2.17-point margin), suggesting the hierarchical layer-wise conditioning is particularly effective under high domain discrepancy.

## Relation to Prior Work

This paper extends the MaPLe framework (hierarchical multi-modal prompts for CLIP) and Test-Time Prompt Tuning (TPT) by replacing fixed learnable prompt parameters with dynamically generated prompts via a HyperTransformer at inference time. It departs from prior prompt-learning methods (CoOp, CoCoOp, MaPLe) that treat prompts as static parameters optimized during training, and from TPT which merely adjusts those fixed parameters per-sample, by instead *generating* data-specific prompts from input embeddings. The variational inference component is borrowed from the VAE/CVAE literature but is novel in its application to prompt modeling, treating prompts as latent distributions rather than point estimates. The hierarchical conditioning across layers generalizes MaPLe's fixed-depth prompt stacking into a sequential generative process where each layer refines the previous one.

## Why It Matters / Open Questions

The paper addresses a practical pain point in VLM deployment—sensitivity to prompt template choice and data augmentation—by showing that variational prompt generation yields more stable, template-agnostic predictions. However, the ablation reveals that the variational component contributes only ~0.8% over deterministic generation, while the hierarchical structure accounts for most of the gain (~1.8%), raising questions about whether the probabilistic framing is essential or merely a convenient inductive bias. Open questions include whether the HyperTransformer's test-time generation overhead is acceptable for real-time applications, whether the approach transfers to larger VLMs (e.g., LLaVA, Flamingo), and whether the gains hold on more diverse or fine-grained benchmarks beyond the standard ImageNet-derivative and 10-dataset evaluation suite.

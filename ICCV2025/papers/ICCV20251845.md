## Problem

Efficient semantic segmentation models suffer from a fundamental misalignment between fixed class representations and diverse image features, a problem exacerbated by aggressive model compression. The per-pixel classification paradigm assumes that identical features should be learned for the same category across different images, but the paper demonstrates through ideal class representation mining that optimal class prototypes vary drastically across images, making this assumption unattainable in lightweight scenarios.
![Teaser figure](../imgs/ICCV20251845/cropped_page0_idx0.webp)

## Input / Output

The method takes a standard RGB image as input (cropped to 512×512 for ADE20K/COCO-Stuff, 480×480 for Pascal Context, or 1024×1024 for Cityscapes during training) and produces a dense pixel-level segmentation mask assigning one of K class labels to every pixel. The offset learning module operates on the final image feature tensor E ∈ R^{HW×C} and class embedding W ∈ R^{K×C} extracted by any backbone-decoder pair, making it a drop-in replacement for the standard 1×1 convolutional classification head with only 0.1–0.2M additional parameters.

## Method

The offset learning paradigm redefines segmentation as a dual-decoupled alignment process M = (W + ΔW)·(E + ΔE)ᵀ, where two branches jointly refine class representations and spatial features. The Class Offset branch computes a coupled attention matrix A_c = W·Eᵀ, applies softmax along spatial dimensions to obtain class-wise attention weights, aggregates spatial features into class-specific prototypes, and passes them through an MLP to produce ΔW. The Feature Offset branch is dual: it applies softmax along the class dimension, transposes for spatial alignment, fuses class semantics into each position, and uses an MLP to produce ΔE. The OffSeg architecture combines an EfficientFormerV2 backbone with a FreqFusion pixel decoder and the offset learning head, and the paradigm is shown to be plug-and-play, improving SegNeXt (CNN), SegFormer (Transformer), and Mask2Former (mask classification) with negligible parameter overhead.

## Results

On ADE20K, OffSeg-T (6.2M params) achieves 44.2 mIoU at 5.3G FLOPs, surpassing EDAFormer-T (42.3) by 1.9 mIoU with 24% fewer FLOPs. OffSeg-B (13.0M) reaches 45.9 mIoU at 10.3G FLOPs, outperforming SegNeXt-S (44.3) by 1.6 mIoU with 35% lower FLOPs. At the large scale, OffSeg-L (26.4M) attains 48.5 mIoU on ADE20K and 81.6 mIoU on Cityscapes, exceeding Mask2Former (47.7) by 0.8 mIoU with 4.3× fewer FLOPs. On COCO-Stuff, OffSeg-B (44.3 mIoU) surpasses RTFormer-Base (35.3) by 9.0 mIoU with less than half the computational cost.

## Baselines & Comparisons

OffSeg-T outperforms EDAFormer-T by 1.9 mIoU on ADE20K (44.2 vs 42.3) while using 24% fewer FLOPs (5.3G vs 5.6G), and beats SegFormer-B0 by 6.8 mIoU on ADE20K. OffSeg-B surpasses SegNeXt-S by 1.6 mIoU on ADE20K (45.9 vs 44.3) with 35% lower FLOPs (10.3G vs 15.9G), and exceeds RTFormer-Base by 9.0 mIoU on COCO-Stuff (44.3 vs 35.3) with less than half the FLOPs. OffSeg-L achieves 48.5 mIoU on ADE20K, beating Mask2Former (47.7) by 0.8 mIoU with 4.3× fewer FLOPs (17.1G vs 74.0G), and edges out FeedFormer-B2 (48.0) by 0.5 mIoU with 2.5× fewer FLOPs. The only notable losses are OffSeg-B trailing SegNeXt-S by 0.8 mIoU on Cityscapes (80.5 vs 81.3) and OffSeg-T falling 0.3 mIoU behind CGRSeg-T on COCO-Stuff (41.9 vs 42.2). When integrated as a plug-and-play module, the offset learning paradigm adds 1.3–2.7 mIoU to SegFormer (B0–B5), 0.9–2.0 mIoU to SegNeXt (T–B), and 2.6 mIoU to Mask2Former-Tiny, with only 0.1–0.2M additional parameters in all cases.

## Relation to Prior Work

This paper carves new ground by identifying a fundamental misalignment in the per-pixel classification paradigm that dominates efficient segmentation (SegFormer, SegNeXt, DeepLab, PSPNet), where fixed class prototypes are assumed to work universally across images. It departs from the mask classification paradigm (MaskFormer, Mask2Former) by showing that cross-attention-based query adaptation is both asymmetric (only adjusts class representations, not image features) and computationally expensive. The proposed dual-branch offset learning mechanism is conceptually distinct from both: it simultaneously refines spatial features and class embeddings through lightweight MLP-based offsets, requiring only 0.1–0.2M additional parameters and no architectural changes to the backbone or decoder.

## Why It Matters / Open Questions

The plug-and-play nature of the offset learning paradigm—demonstrated across CNN (SegNeXt), Transformer (SegFormer), and mask classification (Mask2Former) backbones—makes it a practical drop-in improvement for the efficient segmentation community. The diminishing improvement trend with model scale (1.4 → 0.5 mIoU for SegNeXt; 2.7 → 1.0 mIoU for SegFormer) provides a useful quantitative characterization of when misalignment is most acute, guiding practitioners toward where the technique adds the most value. Open questions include whether the offset learning paradigm extends to open-vocabulary or referring segmentation, whether the learned offsets carry interpretable semantics, and whether the approach generalizes to other dense prediction tasks like depth estimation or surface normal prediction.

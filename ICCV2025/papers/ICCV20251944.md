## Problem

Existing image generation benchmarks are fragmented across single tasks (text-to-image or specific editing operations), rely on metrics like FID and CLIP similarity that misalign with human preferences, and suffer from data distribution bias (only real or only synthetic images). No unified benchmark exists that comprehensively evaluates both image creating and editing capabilities across multiple quality dimensions for the emerging class of unified generation models.
![Teaser figure](../imgs/ICCV20251944/cropped_page0_idx0.webp)

## Input / Output

Depending on the task, the benchmark consumes up to three input types: a textual prompt (instruction or description), a source image (for editing tasks requiring pixel-level preservation), and reference images (for face/subject/style consistency). Additional conditioning inputs include binary masks for local editing and low-level maps (pose, edge, depth) for controllable generation. The output is a generated image scored across 6 dimensions by 11 metrics, with all images resized to a common shape for fair comparison; the full dataset comprises 6,538 instances spanning 31 tasks.

## Method

ICE-Bench organizes evaluation into a coarse-to-fine hierarchy: 4 input-format categories (No-ref/Ref × Creating/Editing) decomposed into 31 fine-grained tasks covering global editing, local editing, controllable generation, style transfer, virtual try-on, and face swap. Evaluation spans 6 dimensions (aesthetic quality, imaging quality, prompt following, source consistency, reference consistency, controllability) quantified by 11 metrics, including a novel VLLM-QA metric that prompts Qwen2-VL-72B to judge whether an edit instruction was successfully executed by jointly examining the source image, reference images, instruction, and generated image. Reference consistency is task-specific: face similarity via InsightFace buffalo model, subject similarity via DINO features, and style similarity via CSD descriptors. The dataset is constructed through a hybrid pipeline combining manual curation from real datasets (MS-COCO, LAION-5B, VITONHD) with synthetic generation, using VLLMs to produce task-specific instructions and ideal-output descriptions, followed by human annotation for quality control.

## Results

On the No-ref Image Creating task (text-to-image), FLUX achieves the highest aesthetic quality (0.618) and imaging quality (0.735), slightly edging out OmniGen (0.611/0.726) and ACE (0.548/0.534). Across the 31 editing and creating tasks, no single model dominates all dimensions: ACE leads on global editing source consistency (0.899) and controllable generation (CTRL 0.865), while UltraEdit achieves the best local editing source consistency (0.953). A notable trade-off emerges between reference consistency and prompt following—ACE scores 0.802 on style reference consistency but only 0.232 on prompt following for the same task, indicating a 'copy-paste' failure mode. Overall, the benchmark reveals that even the most capable unified models (ACE, OmniGen) achieve reference consistency below 0.36 on style transfer and face swap, highlighting substantial gaps in current generation capabilities.

## Baselines & Comparisons

FLUX leads on text-to-image creating (AES 0.618, IMG 0.735) over OmniGen (0.611/0.726) and ACE (0.548/0.534), confirming its strength as a dedicated T2I model. On reference creating, IP-Adapter achieves the best face reference consistency (REF 0.633) while ACE dominates style reference (REF 0.802) and subject reference (REF 0.878), though at the cost of prompt following (PF 0.232 for style). For global editing, ACE leads on source consistency (0.899) and prompt following (0.567), outperforming InstructPix2Pix (0.758/0.355) and MagicBrush (0.840/0.444); UltraEdit achieves the highest local editing source consistency (0.953) but trails on prompt following (0.432). On controllable generation, ACE (CTRL 0.865) and FLUX-Control (0.846) outperform OminiControl (0.687), which is penalized by its lack of pose-guided generation. On reference editing, ACE++ leads on subject reference (REF 0.663, SRC 0.892) and face swap (REF 0.378, SRC 0.853), while ACE and OmniGen both struggle with style transfer reference consistency (0.234 and 0.359 respectively), revealing a clear weakness in style preservation across all evaluated models.

## Relation to Prior Work

ICE-Bench unifies two previously separate lines of evaluation: text-to-image creating benchmarks (CUB-200-2011, MS-COCO, DrawBench, PAINTSKILLS) and instruction-based image editing benchmarks (InstructPix2Pix, MagicBrush, UltraEdit, Emu Edit). Prior benchmarks were task-specific, covering only one or a few tasks with limited metrics (FID, IS, CLIP similarity), while this paper introduces a coarse-to-fine hierarchy of 31 tasks across four input-condition categories and 11 metrics spanning 6 dimensions. A key methodological departure is the use of VLLMs (Qwen2-VL-72B) as evaluators via the novel VLLM-QA metric, which leverages vision-language reasoning to judge instruction execution success rather than relying solely on similarity scores. The hybrid data construction (real + synthetic) also addresses a known bias in prior benchmarks where InstructPix2Pix used only synthetic images and MagicBrush only real images.

## Why It Matters / Open Questions

As unified image generation models (ACE, OmniGen) gain traction, the lack of a comprehensive evaluation framework has hindered fair comparison and progress; ICE-Bench fills this gap by providing a single, open-sourced benchmark with 6,538 instances that can be used as a standard reference. The finding that even the most capable unified models exhibit a fundamental trade-off between reference consistency and prompt following (manifesting as 'copy-paste' behavior) highlights a core unresolved challenge in multi-condition generation. Open questions include whether this trade-off is architectural or data-driven, whether VLLM-based evaluation metrics will become the new standard for instruction-following assessment, and how the benchmark will evolve as new unified models emerge. The paper also notes that model scale and training data resolution remain strong predictors of imaging quality, suggesting that simply unifying tasks without scaling may not close the performance gap.

## Problem

Existing 3D visual grounding methods process multi-step text instructions as a single undifferentiated input, lacking any mechanism for temporal reasoning over sequential steps. In the SG3D task, instructions rely heavily on contextual pronouns ("it", "here", "the same") that require retrieving relevant information from prior steps, but simply concatenating all previous instructions introduces redundant noise and fails to scale with increasing step counts. No effective plug-in module existed to equip standard 3DVG models with the ability to selectively fuse short-term and long-term historical context.

## Input / Output

The method consumes a 3D point cloud P ∈ R^{N×(3+C)} with ground-truth object masks and a sequence of n step-by-step text instructions (averaging 70.5 words per task, far longer than the 10–15 words typical in standard 3DVG datasets). At each step t, only the current instruction is fed to the 3DVG backbone; the sole interface required from the baseline is the joint embedding J_t ∈ R^{T×H} (T tokens, H dimensions) produced just before the grounding head. The output is a predicted object sequence O = {o_1, …, o_n}, where each o_t is the target object for step t, evaluated by step accuracy (per-step mean) and task accuracy (full-sequence match).

## Method

GroundFlow is a plug-in recurrent module that processes one step at a time, cross-attending the current joint embedding J_t with a history embedding J_h to produce Ĵ_t, which is then fed to the grounding head and carried forward as input to the next step. The key innovation is a memory structure that maintains short-term memory (Ĵ_{t-1}, the previous step's fused output) and long-term memory (Ĵ_m, the cumulative sum of all prior fused outputs up to two steps back). To avoid indiscriminate use of the entire history, cosine similarity between each token in Ĵ_m and the current J_t yields per-token importance scores α, which gate the long-term memory via element-wise multiplication. The final history embedding J_h = Ĵ_{t-1} + Ĵ_m ⊙ γ(α) thus combines immediate context with selectively retrieved long-range context, mirroring how humans recall recent activity first and then integrate earlier details by relevance. This design is model-agnostic, requiring only the pre-grounding-head joint embedding, and adds only ~22M parameters to the baseline.

## Results

On the SG3D benchmark (overall across five datasets), PQ3D+GroundFlow achieves the best step accuracy of 64.8% and task accuracy of 36.1%, outperforming the 3D LLM LEO (62.8% s-acc, 34.1% t-acc) by 2% on both metrics. Integrating GroundFlow into 3D-VisTA yields 64.1% s-acc and 35.1% t-acc, a +3.8% and +6.3% improvement over the baseline. The largest gains appear for PQ3D, where GroundFlow adds +7.5% s-acc and +10.2% t-acc, with task accuracy improving by 1.2–2.1× across individual datasets.

## Baselines & Comparisons

GroundFlow-integrated 3DVG models outperform the 3D LLM LEO on all five datasets: PQ3D+GroundFlow leads by 2% in both s-acc and t-acc, while 3D-VisTA+GroundFlow leads by 1.3% s-acc and 1% t-acc. Against the zero-shot GPT-4+PointNet++ baseline (27.3% s-acc, 7.6% t-acc), all GroundFlow variants achieve roughly 2–3× higher task accuracy. Compared to their own baselines without GroundFlow, the improvements are consistent: PQ3D gains +7.5% s-acc and +10.2% t-acc, 3D-VisTA gains +3.8% and +6.3%, MiKASA gains +2.7% and +2.3%, and Vil3DRel gains +3.3% and +6.6%. In ablations (Table 2), GroundFlow also surpasses LSTM, GRU, and Transformer-based temporal fusion on both 3D-VisTA and PQ3D, with the largest margin over Transformer in task accuracy (+1.6% for 3D-VisTA, +2.5% for PQ3D), attributed to its selective memory retrieval versus indiscriminate attention.

## Relation to Prior Work

This paper builds on two classic families of 3D visual grounding models — dual-stream (3D-VisTA, MiKASA) and query-based (PQ3D, Vil3DRel) — by introducing GroundFlow, a lightweight recurrent plug-in that injects temporal reasoning via cross-attention with a selectively retrieved history embedding. Conceptually, it departs from the standard 3DVG paradigm of treating all text as a single undifferentiated input, instead processing instructions step-by-step and drawing on a memory structure inspired by human episodic retrieval (recent activity plus relevance-weighted long-term recall). The design also contrasts with LLM-based 3D grounding (e.g., LEO), which relies on pre-trained commonsense knowledge rather than explicit temporal dependency modeling, and with generic temporal fusion approaches (LSTM, GRU, Transformer) that either forget distant context or attend to all steps indiscriminately.

## Why It Matters / Open Questions

GroundFlow offers a practical, low-cost (22M params) path for existing 3DVG models to handle sequential, task-oriented instructions without retraining from scratch or resorting to large language models, which is relevant as embodied AI systems increasingly require multi-step instruction following. The finding that selective, relevance-gated memory retrieval outperforms both recurrent and attention-based temporal fusion on this task suggests that *which* history to attend to matters as much as *how* to fuse it — a design principle potentially transferable to other sequential grounding or navigation settings. Open questions include whether the summation-based long-term memory degrades over very long sequences (>10 steps), whether the recurrent (non-parallelizable) step processing becomes a bottleneck in real-time robotic deployment, and whether the plug-in generalizes beyond the SG3D benchmark to other sequential 3D tasks such as multi-step navigation or manipulation.

## Problem

In Vision Transformer-based weakly supervised semantic segmentation, class tokens supervised by image-level labels focus exclusively on the most discriminative foreground features, while patch tokens encode both discriminative and non-discriminative characteristics. This 'token gap' causes class tokens to sit at the edge of feature space, activating only nearby patch tokens and producing incomplete Class Activation Maps that fail to cover entire objects, ultimately degrading segmentation performance.
![Teaser figure](../imgs/ICCV20251358/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images (resized to 448×448) with image-level multi-label annotations and a ViT-B/16 encoder to produce patch tokens (HW×D) and multi-class tokens ((C+1)×D). It outputs Class Activation Maps used to generate pseudo-labels via DenseCRF and IRN, which then train a segmentation model to produce pixel-level masks. The framework is unified across architectures: for multi-class token models (MCTformer+) it operates directly on class tokens, while for single-class token models (CLIP-ES) it first generates class prototypes via mask average pooling from classifier CAMs before applying the same proxy learning pipeline.

## Method

OTPL learns foreground-aware proxies that bridge the token gap through two strategies. First, an optimal transport problem connects patch tokens to class tokens, where CAM prediction scores serve as non-uniform marginal constraints on the target distribution (replacing the standard uniform constraint), ensuring more patch tokens are allocated to strongly activated classes; the resulting transport plan selects top-K patch tokens per class, which are concatenated with the class token and passed through a convolution to produce a proxy supervised by multi-label classification loss. Second, an OT-assisted proxy-patch contrastive loss aligns each proxy with confident patch tokens, where positive pairs are identified only when both the CAM top-1 class and the transport plan top-1 class agree on the same label, providing a dual-source, threshold-free selection mechanism. Sinkhorn distance is used for efficient OT optimization, and the overall training objective combines the proxy classification loss, the MCTformer+ loss, and the contrastive loss with a weight of 0.2.

## Results

On PASCAL VOC 2012, OTPL integrated with CLIP-ES achieves 76.4% mIoU (val) and 76.8% mIoU (test), surpassing the previous best (CLIP-ES+CPAL at 74.5%/74.7%) by 1.9%/2.1%. On MS COCO 2014 val, the same configuration reaches 47.6% mIoU, outperforming CLIP-ES+PSDPM (47.2%) by 0.4%. When built on MCTformer+, OTPL achieves 75.6% mIoU on VOC val and 46.5% on COCO val, improving over the MCTformer+ baseline (74.0%/45.2%) by 1.6%/1.3%.

## Baselines & Comparisons

OTPL (CLIP-ES) achieves the best mIoU across all three evaluation splits, beating the strongest prior method CLIP-ES+CPAL by 1.9% on VOC val (76.4 vs 74.5), 2.1% on VOC test (76.8 vs 74.7), and 0.8% on COCO val (47.6 vs 46.8). It also surpasses CLIP-ES+PSDPM on VOC val/test (76.4/76.8 vs 74.1/74.9) and COCO val (47.6 vs 47.2). OTPL (MCTformer+) improves over its own baseline MCTformer+ by 1.6% on VOC val (75.6 vs 74.0) and 1.3% on COCO val (46.5 vs 45.2), but trails CLIP-ES+PSDPM on COCO val (46.5 vs 47.2). Against earlier ViT-based methods like MCTformer (CVPR'22, 69.1% VOC val mask) and TS-CAM, the gains are substantially larger (5–7% mIoU). The consistent improvements across both multi-class-token (MCTformer+) and single-class-token (CLIP-ES) architectures demonstrate the framework's generality.

## Relation to Prior Work

This paper extends the MCTformer line of work on multi-class token ViTs for WSSS by diagnosing a specific failure mode—the 'token gap'—where classification-trained class tokens occupy the periphery of feature space and fail to activate non-discriminative foreground regions. Rather than relying solely on class-patch cosine similarity (as in MCTformer, TS-CAM, or CLIP-ES), it formulates the assignment of patch tokens to class tokens as an optimal transport problem with CAM-guided non-uniform marginal constraints, then learns composite 'proxies' from the resulting top-K assignments. The OT framework draws on Sinkhorn-based solvers from domain adaptation and generative modeling literature, while the contrastive alignment strategy connects to prototype-based WSSS methods like SIPE and CPAL.

## Why It Matters / Open Questions

The token gap diagnosis provides a concrete, visualizable explanation for why ViT-based WSSS methods produce incomplete CAMs, moving beyond the generic 'CAMs miss non-discriminative regions' narrative. The architecture-agnostic design (applicable to both multi-class-token ViTs and single-class-token CLIP backbones) broadens practical utility, and the SOTA results on both VOC and COCO validate the approach. Open questions include whether the proxy mechanism generalizes to video segmentation or open-vocabulary settings, whether the OT formulation is truly necessary versus simpler top-k similarity selection, and how the method behaves under extreme class imbalance or very small objects where confident patch tokens are scarce.

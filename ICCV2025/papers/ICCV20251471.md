## Problem

Existing GRES methods encode multi-granularity object information into a single joint representation, which fails to precisely capture objects of varying granularity in multiple-target scenarios and produces incorrect responses for non-target cases. Additionally, the simple binary object-existence classification used across all referent scenarios ignores the inherent distinction between multiple, single, and empty targets, introducing ambiguity in object understanding.
![Teaser figure](../imgs/ICCV20251471/cropped_page0_idx0.webp)

## Input / Output

The model takes an RGB image and a natural language referring expression (which may describe multiple objects, a single object, or no object) as input. The Swin Transformer backbone extracts multi-scale visual features (4 scales) and BERT produces word-level and sentence-level embeddings that are concatenated into language queries. The output is a binary segmentation mask at full image resolution, generated through hierarchical aggregation of multi-scale semantic maps, plus a category-specific object count vector and a lightweight existence prediction for evaluation compatibility.

## Method

CoHD decouples referring semantics into a visual-linguistic hierarchy via cascaded Semantic Decoding Modules (SDMs) at three scales, where each module performs bidirectional cross-modal attention to generate fine-grained semantic maps and refines language queries by injecting the supervised semantic map back via multi-head attention. Dynamic Hierarchical Aggregation (DHA) then combines the multi-scale outputs using two selective mechanisms: intra-selection applies channel attention to each semantic map to suppress unrelated token activations, and inter-selection uses a gating network to assign per-level saliency scores, followed by sequential upsampling with weighted summation. The Adaptive Object Counting (AOC) module projects the refined multi-scale queries into category-specific counting vectors via MLP, averages them, and supervises with Smooth L1 loss against ground-truth per-category counts, replacing the conventional binary existence head. A lightweight binary head trained on the detached counting prediction handles object-existence evaluation without affecting the main framework. Training uses a combined loss of BCE (mask), Smooth L1 (counting), and CE (existence) with balance factors.

## Results

On gRefCOCO (the primary GRES benchmark), CoHD with Swin-B achieves 68.42 gIoU, 65.17 cIoU, and 63.68 N-acc on the validation set, outperforming the previous SOTA ReLA (Swin-B) by +4.8% gIoU. On R-RefCOCO/+/g, CoHD reaches 53.61 rIoU on R-RefCOCO, surpassing RefSegformer by +7.5% rIoU. On classic RES benchmarks (RefCOCO/+/g), CoHD achieves 75.12 oIoU on RefCOCO val and 66.79 on RefCOCO+ val, setting new state-of-the-art across all splits.

## Baselines & Comparisons

CoHD decisively outperforms all specialist GRES baselines on gRefCOCO: vs. ReLA (Swin-B), it gains +4.8% gIoU and +7.3% N-acc on validation; vs. DMMI, +5.7% gIoU; vs. LAVT, +10.0% gIoU. On R-RefCOCO/+/g, CoHD surpasses RefSegformer by +7.5% rIoU (R-RefCOCO), +6.9% (R-RefCOCO+), and +4.5% (R-RefCOCOg), while also leading in mIoU and mRR across all three splits. Notably, CoHD (Swin-T) even outperforms the MLLM-based GSVA-V-7B (SAM-ViT-H) on gRefCOCO validation (65.89 vs. 63.32 gIoU), demonstrating that the hierarchical decoding design is more effective than scaling to a large multimodal model for this task. On classic RES benchmarks (RefCOCO/+/g), CoHD achieves the best oIoU across all splits, exceeding ReLA by +1.3% on RefCOCO val and +0.75% on RefCOCOg val. The consistent margins across both GRES and RES settings indicate that the hierarchical semantic decoder and adaptive object counting generalize well beyond the generalized scenarios.

## Relation to Prior Work

CoHD builds on the Generalized Referring Expression Segmentation (GRES) task introduced by ReLA (CVPR 2023) and further developed by DMMI (ICCV 2023) and RefSegformer, all of which extend classic one-to-one RES to handle multiple-target and empty-target scenarios. However, CoHD departs from the shared decoding paradigm of these prior GRES methods, which compress multi-granularity object information into a single joint representation for mask prediction. Instead, it repurposes the hierarchical feature pyramid (common in detection) into a purpose-built visual-linguistic semantic hierarchy with dynamic selective aggregation, and replaces the standard binary object-existence head with a category-specific counting module inspired by object counting literature.

## Why It Matters / Open Questions

The paper provides a well-motivated argument that single-representation decoding is fundamentally incompatible with GRES rather than merely suboptimal, which reframes how the community should think about multi-granularity segmentation. The counting-aware supervision is a creative and lightweight mechanism that addresses ambiguity in implicit expressions (e.g., 'a line of cars') without adding significant computational overhead. Open questions include whether the hierarchical decoding strategy generalizes to even more complex multi-instance scenes, whether the counting supervision transfers to open-vocabulary settings, and whether the approach extends naturally to video or 3D referring segmentation.

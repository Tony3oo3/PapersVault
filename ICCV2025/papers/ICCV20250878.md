## Problem

Understanding dynamic 3D scenes from egocentric observations remains challenging because end-to-end multimodal LLMs are computationally prohibitive and struggle with long-form, highly volatile scenes, while existing video agents that rely solely on 2D visual frames fail to build coherent spatial representations or detect when objects have been moved. The paper addresses the need for a persistent, continuously updatable scene memory that fuses egocentric video with embodied sensor inputs (depth, pose) to support both passive perception and active embodied interaction.

## Input / Output

The agent consumes a continuous stream of egocentric video frames, per-frame depth maps, and camera poses rather than a fixed-length video clip, building and updating its memory incrementally at each timestamp. Outputs include a structured persistent object memory (each entry containing a 3D bounding box, CLIP/DINOv2 visual features, state label, and inter-object relations), 3D object localizations via 2D-to-3D projection, natural-language answers to embodied questions, and sequences of atomic action primitives (move, turn, pick, place) executed in a Habitat-Sim environment. The memory is queryable via natural-language database queries and similarity search over visual features.

## Method

Embodied VideoAgent constructs a persistent object memory by lifting 2D YOLO-World detections into 3D bounding boxes using depth maps and camera poses, then performing a novel 3D object re-identification that categorizes existing entries as static or dynamic by comparing memorized 3D geometry against current perception; static objects are matched primarily by 3D position while dynamic objects are matched by visual feature similarity and bounding-box size. A VLM-based update mechanism (LaViLa action annotator + GPT-4o) detects actions on objects, uses visual prompting to link the action to the correct memory entry, and programmatically updates the object's state field (e.g., OPEN/CLOSED, in-hand). An LLM controller then operates in a perception-decision-action loop, invoking perception tools (query_db, temporal_loc, spatial_loc, vqa) to retrieve information from memory and action primitives (goto, pick, place, open, close) to interact with the environment until the user's embodied task is completed.

## Results

On Ego4D-VQ3D, E-VideoAgent(text+image) achieves 86.98% Succ% and 93.47% QwP%, surpassing the best learning-based method EgoLoc (80.49% Succ%) by 6.49%. On EgoObjects, the 3D-aware re-ID algorithm reaches 53.69 F1, a 21.93-point improvement over VideoAgent's 2D-only re-ID (31.76). On EnvQA, E-VideoAgent attains 43.13% overall accuracy, outperforming VideoAgent (27.84%) by 15.3 points, with particularly large gains on Events (25.91 vs 5.54) and States (35.50 vs 12.50). On OpenEQA, E-VideoAgent(GPT-4o) scores 57.9% on the full set and 47.0% on the subset, exceeding GPT-4V with 50 frames (55.3%) and GPT-4o with 8 frames (41.9%).

## Baselines & Comparisons

E-VideoAgent outperforms all seven baselines across every benchmark. Against EgoLoc [31] on Ego4D-VQ3D, it gains 6.49% on Succ% (86.98 vs 80.49) and 11.15% on QwP% (93.47 vs 82.32) in a zero-shot setting, while Ego4D [9] itself scores only 1.22% Succ%, highlighting the difficulty of end-to-end 3D localization. Compared to VideoAgent [5]—the closest architectural baseline—E-VideoAgent improves F1 by 21.93 points on EgoObjects re-ID, 7.0 points on OpenEQA subset (47.0 vs 40.0), and 15.3 points on EnvQA (43.13 vs 27.84), with the gap driven primarily by 3D geometry in object memory. Against end-to-end video models Video-LLaVA [24] and LLaMA-VID [23], E-VideoAgent leads by 18.3 and 19.8 points on EnvQA respectively, and by 18.7 and 24.3 points on OpenEQA full. On OpenEQA, E-VideoAgent(GPT-4o) also surpasses the GPT-4V(50 frames) baseline from [32] by 2.6 points (57.9 vs 55.3) and the GPT-4o w/LLaVA-1.5 baseline from [26] by 11.4 points on the subset (47.0 vs 35.6), demonstrating that structured agentic memory retrieval outperforms simply feeding more frames to a VLM.

## Relation to Prior Work

This paper extends the multimodal agent paradigm (VideoAgent, CLOVA, ViPERGPT) from 2D video understanding to embodied 3D scene understanding by integrating depth maps and camera poses into a persistent object memory with 3D bounding boxes. It departs from prior video agents that rely solely on 2D visual features for object tracking, introducing a 3D object re-identification algorithm that combines visual similarity with geometric consistency. The VLM-based memory update mechanism, which uses action detection (LaViLa) and visual prompting to modify object states, is a novel component not present in either the end-to-end MLM line (GPT-4V, Gemini) or the prior agent-based line. The two-agent synthetic data generation framework draws on multi-LLM-agent research (MindAgent) but applies it specifically to embodied user-assistant interaction.

## Why It Matters / Open Questions

The paper addresses a practical gap: deploying robust scene understanding on edge devices like robots, where end-to-end MLMs are too expensive and 2D-only agents lack spatial grounding. The persistent object memory with 3D re-ID and VLM-based state updates provides a modular, interpretable architecture that could be adopted in robotics pipelines. However, validation is largely confined to simulation (Habitat-Sim) and a single robotic arm demo; the two-agent framework evaluation uses only 150 episodes, and the EnvQA gains, while large, rest on a single benchmark with limited agent baselines. Open questions include scalability to outdoor or industrial environments, robustness of the 2D-to-3D lifting under occlusion, and whether the VLM update mechanism generalizes beyond the limited action vocabulary tested.

## Problem

Existing diffusion-based layout-to-image methods treat layout planning and layout-to-image generation as two separate models, preventing end-to-end joint generation. Additionally, they rely on embed-and-pool operations to compress local captions into fixed-length vectors, which degrades performance on complex layouts with detailed or variable-length descriptions. This paper asks whether a single autoregressive vision-language model can unify both tasks without such lossy encoding.
![Teaser figure](../imgs/ICCV20251508/cropped_page0_idx3.webp)

## Input / Output

The model accepts a global text caption and optionally explicit layout conditions (bounding boxes with four integer coordinates normalized to 0–1000, each paired with a free-form local description wrapped in <ref> tags). For image layout understanding, it takes a 384×384 RGB image encoded via SigLIP and mapped into the text token space. Outputs include planned layout conditions, a 384×384 generated image, or an edited image where non-target regions are preserved via teacher-forcing. Unlike diffusion methods that require fixed-length local caption embeddings, PlanGen's autoregressive context allows arbitrarily detailed local descriptions without truncation or pooling.

## Method

PlanGen builds on the Janus-Pro 1.5B autoregressive transformer and models all tasks—layout planning, layout-to-image generation, and image layout understanding—exclusively via next-token prediction with a unified prompting scheme using special tokens (<grounding>, <ref>, <box>) to delimit layout conditions. The key architectural insight is treating layout conditions as plain context tokens rather than embedding them through specialized encoders, leveraging the transformer's long-range attention to maintain alignment between detailed local descriptions and their spatial positions. Training combines three weighted next-token prediction losses (layout planning, layout-to-image, image layout understanding) with equal weights, and the model is trained for 200K steps on HiCo, LayoutSAM, OpenImage V6, and LayoutGPT data. For layout-guided image manipulation, PlanGen introduces teacher-forcing content manipulation (fixing non-edited token positions to original values) and negative layout guidance (a classifier-free-guidance-style modulation using negative layout tokens describing artifacts), enabling object deletion and editing without any task-specific training.

## Results

On the LayoutSAM-Eval benchmark for layout-to-image generation, PlanGen achieves the best region-wise quality scores among all methods: Color 82.69, Texture 86.53, and Shape 85.36, substantially outperforming the strongest diffusion baseline CreatiLayout (74.45, 77.21, 75.93 respectively). PlanGen also attains the lowest FID (13.91) among all compared methods, indicating superior overall image quality. For layout planning on PlanGen-1K, PlanGen's predicted layouts yield generated images with FID 50.73, nearly matching ground-truth layouts (48.67) and dramatically outperforming Qwen2.5-7B (472.38) and Llama3.1-8B (464.07). For object removal on COCO, PlanGen with negative layout guidance achieves 86.50% success rate, surpassing SD-Inpainting (66.50%) and InstructPix2Pix (40.00%).

## Baselines & Comparisons

On layout-to-image generation (Table 2), PlanGen decisively outperforms all six diffusion-based baselines (GLIGEN, Ranni, MIGC, InstanceDiff, HiCo, CreatiLayout) on region-wise quality metrics (Color, Texture, Shape) and achieves the best FID (13.91 vs. 19.10 for CreatiLayout), though it trails CreatiLayout on global aesthetics metrics (IR: 39.58 vs. 69.47; IS: 19.31 vs. 22.04). For layout planning (Table 3), PlanGen's predicted layouts produce images with FID 50.73, nearly matching ground-truth layouts (48.67) while Qwen2.5-7B and Llama3.1-8B produce catastrophically poor results (FID 472.38 and 464.07), indicating that general-purpose LLMs cannot reliably plan spatial layouts. On image layout understanding (Table 4), PlanGen (AP 33.48, AR 50.98) substantially outperforms other VLMs like CogVLM-grounding (AP 9.05) and Qwen-VL-2.5-8B (AP 6.69), approaching but not matching the specialized detector Grounding-DINO (AP 50.00). For object removal (Table 5), PlanGen with negative layout guidance achieves 86.50% success rate, beating SD-Inpainting (66.50%) by 20 points and InstructPix2Pix (40.00%) by 46.5 points, while also achieving the lowest LocalCLIP score (21.90), confirming more thorough deletion.

## Relation to Prior Work

PlanGen builds directly on Janus-Pro's autoregressive vision-language architecture (next-token prediction for unified understanding and generation) and extends it with a layout-planning intermediate step before image synthesis. It departs fundamentally from the dominant diffusion-based layout-to-image paradigm (GLIGEN, HiCo, CreatiLayout, InstanceDiff), which requires separate layout planning models and relies on embed-and-pool operations to compress local captions and bounding boxes into fixed-length condition vectors. By treating layout conditions as free-form context tokens in the autoregressive sequence, PlanGen avoids these compression bottlenecks and unifies layout planning, layout-to-image generation, image layout understanding, and layout-guided manipulation under a single next-token prediction objective.

## Why It Matters / Open Questions

This is the first demonstration that an autoregressive VLM can jointly plan spatial layouts and generate corresponding images in a single forward pass, removing the need for a separate layout planning model and enabling seamless multi-task training. The teacher-forcing manipulation and negative layout guidance strategies show that the token-based layout representation naturally supports editing without additional training, a capability that is difficult to achieve in diffusion models. Key limitations include the 384×384 training resolution, weaker performance on human figures, and the fact that PickScore/CLIP alignment metrics remain below the best diffusion baselines (CreatiLayout), suggesting the FID advantage may reflect diversity rather than superior text-image alignment. Open questions include whether the approach scales to higher resolutions and whether more advanced autoregressive paradigms (mask AR, next-scale prediction) can close the remaining quality gap.

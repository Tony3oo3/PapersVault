## Problem

LoRA-adapted vision models are compact and publicly deployable, making them attractive targets for model extraction, yet their specific vulnerability to such attacks remains unexplored. Existing extraction methods are impractical for LoRA: data-driven approaches require traversing large in-distribution datasets, while GAN-based synthetic data generation suffers from mode collapse on high-dimensional images. This paper formalizes LoRA Extraction as a distinct attack and demonstrates that it can be executed effectively with only class names and API access.

## Input / Output

The attacker requires only the target class names (text), a query API to the victim's LoRA-adapted ViT model (returning soft probability vectors or hard labels), and a publicly available pre-trained ViT-Base backbone. The output is a substitute LoRA module (rank-4 low-rank matrices) attached to the attacker's own base model, producing class predictions that mimic the victim. Notably, no real training data is needed; all training images are synthesized on-the-fly via LLM-guided Stable Diffusion, and the query budget is as low as 10k API calls.

## Method

StolenLoRA operates in two stages. First, an LLM (GPT-4o mini) generates diverse image prompts per class using a structured template [Subject, Background, Angle/Pose, Lighting, Style], which are fed to SDXL-Turbo (4-step sampling) to produce in-distribution synthetic images. Second, a Disagreement-based Semi-supervised Learning (DSL) strategy iteratively refines the substitute: pseudo-labels from the generation process seed initial training, then in each iteration the substitute's predictions are checked against pseudo-labels—samples where the substitute is confident and agrees are used for free, while uncertain or disagreeing samples are selectively queried from the victim API. A label-refining loss with exponential moving average of soft predictions further mitigates distribution shift, particularly in the cross-backbone setting where the attacker uses a different pre-trained ViT than the victim.

## Results

Under a 10k query budget, StolenLoRA-DSL achieves up to 96.60% Attack Success Rate (ASR) on Indoor67 in the identical-backbone (IB) setting, while StolenLoRA-Rand reaches 95.01% ASR on Flowers102. In the more challenging cross-backbone (XB) setting, StolenLoRA-DSL attains the highest accuracy across all five datasets, peaking at 65.07% Acc (76.09% ASR) on Indoor67, substantially outperforming the best baseline E3 (55.85% Acc / 65.31% ASR). The victim models achieve test accuracies of 88.09%, 94.47%, 85.52%, 91.07%, and 98.66% on CUBS200, Caltech256, Indoor67, Food101, and Flowers102 respectively.

## Baselines & Comparisons

StolenLoRA (both Rand and DSL variants) consistently outperforms all four baselines across both IB and XB settings. In the IB setting, StolenLoRA-Rand surpasses the strongest baseline E3 by 3.4–12.1% ASR (e.g., 95.01% vs. 81.77% on Flowers102), while StolenLoRA-DSL leads on Caltech256 (94.53% ASR vs. 92.01% for ActiveThief) and Indoor67 (96.60% vs. 95.22% for E3). In the XB setting, the advantage is dramatic: StolenLoRA-DSL achieves 56.92–76.09% ASR versus at most 65.31% for E3, with gaps exceeding 10–30 percentage points on CUBS200, Caltech256, and Flowers102. DFME (GAN-based data-free extraction) is essentially non-functional, scoring below 3% ASR in both settings, confirming the paper's argument that GAN mode collapse renders it ineffective for high-dimensional image extraction. KnockoffNets and ActiveThief, which rely on searching large real datasets (CC3M), perform moderately in IB but collapse in XB (e.g., 7.69% ASR for KnockoffNets on CUBS200), highlighting their inability to transfer across different pretrained backbones.

## Relation to Prior Work

This paper carves new ground at the intersection of model extraction and parameter-efficient fine-tuning security. While traditional ME attacks (KnockoffNets, ActiveThief, DFME, E3) target full model replication, StolenLoRA reframes the problem as extracting only the compact LoRA delta on top of a publicly available base model, reducing the attacker's search space. It departs from prior data-free extraction methods that rely on GANs (prone to mode collapse for high-dimensional images) and from data-driven methods requiring large-scale dataset search, instead repurposing LLM-driven Stable Diffusion as a query generator and introducing a disagreement-based semi-supervised querying strategy borrowed from the SSL literature.

## Why It Matters / Open Questions

With hundreds of thousands of LoRA adapters publicly shared and deployed in production vision pipelines, this work demonstrates that the compactness of LoRA—its primary advantage—also makes it a natural extraction target, even across different pretrained backbones. The preliminary dual-LoRA defense is only partially effective against the DSL variant, leaving a clear open question about robust defenses for PEFT deployments. Broader implications include whether similar vulnerabilities extend to other PEFT methods (LoHa, LoKr, X-LoRA) and to non-vision modalities, and whether API providers can detect or rate-limit the specific query patterns that make DSL effective.

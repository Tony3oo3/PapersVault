## Problem

Single-shot global prediction models for 3D scene layout estimation struggle with out-of-distribution real-world scenes due to partial observability and occlusions. While interactive human-in-the-loop paradigms have proven effective in 2D vision (e.g., SAM), applying such iterative refinement to 3D scene layout from an egocentric perspective remains largely unexplored. This paper introduces the novel task of local correction, where a user identifies specific erroneous entities and prompts a model to fix them, enabling the final layout to diverge from the training distribution.
![Teaser figure](../imgs/ICCV20251836/cropped_page0_idx0.webp)

## Input / Output

The model consumes a semi-dense point cloud (no images) and, for local correction, the user's 6DoF pose plus the current scene layout with selected entities excluded. The scene is anchored at the user's pose (gravity-aligned z, xy centered on user), and remaining entities are split into prefix and suffix subsequences based on command ordering (lexicographic, angle-based, or random). Output is a sequence of structured language tokens (e.g., make_door with height/width parameters) that deserialize into geometric entities—walls, doors, and windows—representing either the full layout or just the corrected span.

## Method

The approach adapts SceneScript's sparse 3D ResNet encoder + Transformer decoder architecture to jointly learn global prediction and local correction via multi-task training, sampling each task with probability 0.5. The key insight is framing local correction as 'infilling' (FIM): selected entities are removed from the sequence and the model must regenerate them conditioned on the point cloud and the remaining prefix/suffix context. Subsequence positional embeddings replace absolute positional embeddings so each prefix/target/suffix segment has its own learnable position, enabling variable-length generation. Egocentric anchoring centers the scene at the user's pose, reducing output entropy by ensuring targets are always in front of the user. This multi-task setup preserves global prediction performance (within ~1 AvgF1 point) while yielding a 4–7 point gain on local correction, mirroring the 'FIM-for-free' property observed in NLP.

## Results

On the in-distribution ASE dataset, joint training maintains global prediction performance within ~1 point of AvgF1 (89.3 → 88.5) while boosting local correction by ~6 points (88.5 → 94.3 AvgF1 across wall/door/window). On the out-of-distribution real-world AEO dataset, the same trend holds: global prediction stays comparable (19.2 → 17.8 AvgF1) while local correction improves from 8.3 to 11.5 AvgF1. The iterative human-in-the-loop system using angle-based ordering on iASE achieves 22 and 54 user interactions for two real-world scenes, with each local correction completing in under one second.

## Baselines & Comparisons

The sole baseline is vanilla SceneScript [3] (trained only on global prediction), which is repurposed for local correction via partial layout completion (continuing generation from all non-target entities). On ASE, the joint-training model wins decisively on local correction: wall 98.6 vs. 92.2, door 94.6 vs. 88.1, window 89.6 vs. 85.1 AvgF1 — a 4–7 point gain — while sacrificing only ~1 point on global prediction. On the harder real-world AEO dataset, the joint model again wins on local correction (8.3/11.6/14.7 vs. 5.0/7.6/12.3 AvgF1) with a modest global prediction trade-off. The paper notes that no existing human-in-the-loop system for scene layout editing exists, so no direct system-level baseline is available; the heuristic iterative variant (using Mask2Former for automatic entity selection) also underperforms the human-in-the-loop version with the same model, confirming that human guidance is critical for effective refinement.

## Relation to Prior Work

This paper transfers the Fill-In-the-Middle (FIM) infilling paradigm from NLP to 3D scene layout estimation, building directly on SceneScript's structured language representation and encoder-decoder architecture. While interactive 2D segmentation (SAM, SimpleClick) has established the human-in-the-loop paradigm for 2D vision, and layout completion (LayoutTransformer) addresses partial layout generation, no prior work defines the specific task of correcting user-identified local errors in a full 3D scene layout via infilling. The paper positions itself at the intersection of structured language for geometry, text infilling, and interactive vision, with the key conceptual move being the recognition that local correction is structurally identical to infilling in NLP.

## Why It Matters / Open Questions

The paper establishes a viable paradigm for iterative, human-guided refinement of 3D scene layouts that can diverge from the training distribution, addressing a fundamental limitation of single-shot prediction in open-world settings. The practical 'one-click fix' workflow in mixed reality (Meta Quest 3 + Project Aria) demonstrates a low-friction path toward usable 3D scene understanding. However, real-world performance remains poor (AvgF1 ~15 on AEO) due to the sim-to-real gap, and the system is currently limited to architectural entities (walls/doors/windows). Open questions include scaling to full scene layouts with bounding boxes, reducing the number of human interactions needed, and closing the gap between heuristic and human action selection.

## Problem

Existing text-to-image model evaluations focus on objective metrics like FID and CLIP score, overlooking how different models learn distinct interpretations of the same semantic concepts (e.g., one model associates 'ancient' with the Paleolithic Era while another associates it with the Roman Empire). This paper addresses the gap of systematically discovering input-dependent visual differences between two models and identifying which prompt concepts trigger those differences.
![Teaser figure](../imgs/ICCV20250837/cropped_page0_idx0.webp)

## Input / Output

The method takes a pair of text-to-image models and an initial set of text prompts, generating 3 images per prompt per model across different seeds. It outputs pairs of (diverging visual attribute, diverging prompt description), where the attribute is a short phrase (e.g., 'flames') and the description is a list of semantic concepts (e.g., 'strong emotions') that elicit the attribute in one model but not the other. The ID² benchmark provides 60 ground-truth representations, each with 50 prompts producing 150 images per set plus 200 distractor pairs, enabling controlled evaluation of both attribute and description discovery.

## Method

CompCon is a two-phase evolutionary search algorithm. Phase 1 (attribute discovery) tiles paired images into two-row grids, prompts a VLM to identify visual differences, then scores each candidate attribute using CLIP cosine similarity with a binary divergence score z that requires the attribute to exceed a threshold in model 1's images while being absent in model 2's. Phase 2 (prompt description discovery) iteratively refines a natural language description of triggering prompts: an LLM (GPT-4o) proposes a description from sampled diverging and non-diverging prompts, new candidate prompts are generated or retrieved from that description, images are produced and classified via the divergence score, and the description yielding the highest ratio of diverging to total candidates is retained. The key design choice is treating the prompt-to-attribute mapping as a non-bijective, non-differentiable optimization problem solved through evolutionary mutation and selection over N iterations, with up-weighting of recently generated prompts to accelerate convergence toward fine-grained descriptions.

## Results

On the ID² benchmark (60 divergent representations), CompCon achieves an attribute score of 0.60 (Top-1) and 0.68 (Top-5), and a description score of 0.64 (Top-1) and 0.78 (Top-5) with 5 evolutionary iterations. These scores are evaluated via LLM-as-a-judge (GPT-4o) on a 0–1 scale measuring similarity to ground-truth diverging visual attributes and prompt descriptions. CompCon outperforms all baselines on both discovery tasks, with the largest margins over the LLM-only end-to-end baseline (0.08/0.24 attribute, 0.03/0.28 description).

## Baselines & Comparisons

CompCon outperforms all three baselines on both the diverging visual attribute and diverging prompt description tasks. Against VisDiff (the closest competitor on attribute discovery), CompCon gains +0.13 Top-1 and +0.06 Top-5 attribute score; VisDiff's reliance on image captions limits its ability to capture fine-grained visual differences. Against TF-IDF, CompCon leads by +0.37 Top-1 on attribute score and +0.24 Top-1 on description score, with TF-IDF struggling to identify nuanced visual attributes from caption text. The LLM-only end-to-end baseline performs worst across all metrics (0.08/0.24 attribute, 0.03/0.28 description), as it must simultaneously find caption differences, identify consistent patterns, and summarize triggering prompts in a single pass. The 5-iteration CompCon variant improves over the 1-iteration version by +0.05 Top-1 and +0.06 Top-5 on description score, showing that iterative evolutionary refinement is particularly beneficial when ground-truth descriptions are fine-grained.

## Relation to Prior Work

This paper extends VisDiff (Dunlap et al., CVPR 2024), which describes differences between two image sets using natural language, by shifting from dataset-level comparison to input-dependent, prompt-conditioned differences between two text-to-image models. It also departs from the bias-discovery literature (OpenBias, GradBias, TIBET), which audits a single model against a predefined set of biases, by performing open-ended pairwise model comparison where the divergent attributes are discovered rather than hypothesized. The evolutionary search framework combining VLM-based visual scoring with LLM-driven prompt mutation is a novel methodological combination not present in prior image-set difference or diffusion-model interpretability work.

## Why It Matters / Open Questions

CompCon provides a practical, automated pipeline for uncovering model-specific semantic interpretations and biases that standard quality metrics (FID, CLIP score, TIFA) systematically miss, which is valuable for both model developers choosing deployments and users selecting tools. The ID² benchmark, while small (60 representations), offers a controlled evaluation setting that prior work lacked. Key limitations include reliance on off-the-shelf LLMs/VLMs (inheriting their biases and potential false negatives), the modest gains from additional evolutionary iterations, and the cost of GPT-4o calls. Open questions include whether discovered divergent representations generalize across prompt distributions, whether the evolutionary search converges to the true underlying representation difference, and how the approach scales to video generation or multi-model comparisons.

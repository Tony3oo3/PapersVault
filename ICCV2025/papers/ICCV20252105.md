## Problem

Existing CNN-based segmentation networks passively respond to local textures (edges, corners) rather than actively modeling semantic objects, while ViT-based methods degrade into 'pseudo-global modeling' that focuses on high-frequency texture instead of anatomical structure due to scarce medical annotations. Neither paradigm incorporates prior knowledge to directly identify and extract category-level features (specific lesions or organs), limiting segmentation accuracy on complex medical images.

## Input / Output

The network consumes medical images at two resolutions simultaneously: 224×224 for the DMW-LA encoder and 256×256 for the MaxViT encoder, with bilinear interpolation re-fusing the input image with each stage's features to mitigate resolution loss. The output is a pixel-level segmentation mask at the original input resolution, produced by a decoder that applies DMW-LA and bilinear upsampling. The K-means cluster count k is set to the number of segmentation classes in each dataset (e.g., 4 for ACDC, 9 for Synapse).

## Method

Sim-MPNet employs a dual-encoder architecture where Encoder 1 stacks four stages of Dynamic Memory Weights-Loss Attention (DMW-LA) and Encoder 2 uses MaxViT, with stage features fused by element-wise addition. DMW-LA initializes a prototype memory bank via K-means on global interaction features, then matches Query vectors to similarity core priors via cosine similarity and performs intra-cluster self-attention to extract category features, mimicking 'grandmother cell' recognition. A Weight-Loss Dynamic (W-LD) strategy updates the memory bank by replacing low-weight columns with high-weight input columns, where the replacement count K is modulated by the epoch-to-epoch loss difference to preserve or expand stored semantics. The Double-Similarity Global Internal Enhancement Module (DS-GIM) partitions features into P×P windows, computes intra-window cosine similarity with decay-weighted coefficients, and combines euclidean-distance-based spatial attention to capture subtle inter-element differences. Skip connections apply channel and spatial attention in series to fuse encoder-decoder features before the decoder restores full resolution.

## Results

Sim-MPNet achieves the best DSC across all four datasets: 92.18% on ACDC (HD95 1.08), 83.12% on SegPC-2021 (HD95 29.66), 90.85% on ISIC-2018 (HD95 3.55), and 84.34% on Synapse (HD95 14.85). On Synapse, Sim-MPNet also reports 91.30M parameters and 43.74G FLOPs with an average inference time of 873 ms per image. The method outperforms the strongest CNN baseline (EMCAD, 91.43% on ACDC), the strongest ViT baseline (TransDeepLab, 90.11% on ISIC-2018), and the strongest hybrid CNN-ViT baseline (TransCASCADE, 91.48% on ACDC) on their respective best datasets.

## Baselines & Comparisons

Sim-MPNet achieves the best DSC on all four datasets, outperforming every baseline. On ACDC, it surpasses the best hybrid method TransCASCADE (91.48%) by 0.70% DSC and the best CNN method EMCAD (91.43%) by 0.75%. On SegPC-2021, the margin is largest: Sim-MPNet (83.12%) beats the best hybrid MixTrans (80.72%) by 2.40% DSC and reduces HD95 from 32.62 to 29.66 mm, reflecting superior handling of closely connected plasma cells. On ISIC-2018, it edges out the best ViT method TransDeepLab (90.11%) by 0.74% DSC. On Synapse (Table 2), Sim-MPNet (84.34% DSC, 14.85 HD95) outperforms the best hybrid PAG-TransYnet (83.43%, 15.82) by 0.91% DSC, though PAG-TransYnet retains a slight edge on the smallest organ (Aorta: 89.67 vs. 87.06) and largest organ (Liver: 95.87 vs. 95.28). Overall, the dynamic memory prior mechanism provides consistent gains across local-detail-heavy (ACDC, SegPC-2021) and global-context-heavy (ISIC-2018, Synapse) tasks.

## Relation to Prior Work

This paper departs from the dominant CNN and ViT segmentation paradigms (U-Net family, TransUNet, SwinUNet, etc.) by introducing an explicit prototype memory bank mechanism inspired by 'grandmother cells' in primate V1, where category features are matched via cosine similarity rather than passively extracted through convolution or self-attention. Conceptually, it repurposes the prototype memory bank idea from few-shot learning and video tracking (MOCA, Santoro et al., Yang & Chan) into a segmentation context, but adds a novel Weight-Loss Dynamic (W-LD) update strategy that adjusts memory bank refresh rate based on epoch-to-epoch loss differences. The dual-encoder architecture pairs the memory-based DMW-LA with MaxViT for complementary local category extraction and global context modeling, positioning the work as a hybrid that explicitly encodes prior category knowledge rather than relying purely on data-driven implicit learning.

## Why It Matters / Open Questions

The paper offers a plausible alternative to the 'more attention, more data' scaling trend in medical segmentation by showing that a small, dynamically updated memory bank can capture category-level features with modest parameter overhead. However, the gains are consistent but modest (0.5–2.5% DSC across four datasets), and on the most complex Synapse benchmark the method still trails PAG-TransYnet on the smallest (Aorta) and largest (Liver) organs, suggesting the memory mechanism does not fully resolve the local-detail vs. global-context tradeoff. Open questions include whether the grandmother-cell analogy translates to 3D volumetric segmentation, whether the W-LD update strategy generalizes beyond the specific linear scheduling used here, and whether the biological framing provides genuine inductive-bias benefits beyond what a well-tuned prototype attention module already achieves.

## Problem

Existing 3D semantic scene graph (SSG) generation methods are either offline, requiring complete scene data, or online but bottlenecked by computationally intensive point cloud reconstruction and processing. This paper identifies that precise 3D object geometry is unnecessary for high-level semantic understanding, motivating an approach that lifts 2D scene graphs directly into 3D space to achieve faster-than-real-time online SSG generation without environmental mapping.
![Teaser figure](../imgs/ICCV20250139/cropped_page0_idx0.webp)

## Input / Output

The method consumes a stream of RGB-D frames along with their camera intrinsics and extrinsics (pose), processing each frame independently through a 2D SG pipeline before incremental 3D integration. The output is a continuously updated global 3D SSG where each object node is a 3D Gaussian distribution (3D mean vector and 3×3 covariance matrix) with a class label, and directed edges carry semantic relationship labels (e.g., 'standing on', 'attached to'). Unlike point-cloud-based methods, FROSS produces no explicit 3D geometry; objects are purely statistical distributions, and the merging algorithm enforces strict one-to-one correspondence between predicted and ground-truth objects.

## Method

FROSS constructs 2D scene graphs per frame using RT-DETRv2-M for object detection and EGTR for relationship extraction (leveraging preserved self-attention features), then converts bounding boxes to 2D uniform Gaussians and back-projects them into 3D space via the pseudo-inverse of the projective Jacobian, with depth-axis variance approximated from the mean of the lateral dimensions. The core novelty is a Gaussian-based merging algorithm that computes Hellinger distances between same-class nodes to identify object correspondences across views, fusing matched nodes through weighted mean and covariance integration (weighted by detection frequency) while redirecting all relationship edges to the merged node. Relationships between global objects are resolved by majority voting across viewpoints. This pipeline runs at 144 FPS on a single CPU core and one GPU, achieving 7 ms end-to-end latency per frame—substantially faster than prior online methods (161–310 ms) that rely on point cloud reconstruction and segmentation.

## Results

On the 3DSSG dataset, FROSS achieves the highest relationship recall (27.9%), object recall (62.4%), and predicate recall (33.0%) among all compared methods, along with the best mean object recall (63.8%). Its end-to-end latency is 7 ms, making it 23× faster than the next-fastest online method (SGFN at 161 ms) and 44× faster than Kim's framework (310 ms). On ReplicaSSG, FROSS achieves 22.3% relationship recall and 26.1% object recall with predicted 2D SGs, rising to 67.6% and 89.1% respectively when ground-truth 2D SGs are provided, indicating substantial headroom from the 2D SG quality.

## Baselines & Comparisons

FROSS outperforms all six baselines on relationship recall (27.9% vs. 23.3% for the next-best Wu [35]), object recall (62.4% vs. 59.0% for Kim [16]), and predicate recall (33.0% vs. 28.4% for Wu [35]). It also achieves the best mean object recall (63.8% vs. 51.0% for Kim [16]), reflecting the effectiveness of its Gaussian-based merging in suppressing duplicate detections. The sole metric where FROSS trails is mean predicate recall (18.0% vs. 26.6% for Wu [35] and 24.0% for SGFN [34]), likely due to the coarser 2D-to-3D lifting losing fine-grained predicate distinctions. In terms of speed, FROSS's 7 ms latency is an order of magnitude faster than SGFN (161 ms), Wu (191 ms), and Kim (310 ms), while operating on a single CPU core and one GPU without any point cloud reconstruction pipeline. The point-cloud-based methods (3DSSG, SGFN, Wu) all underperform FROSS on recall metrics, suggesting that direct 2D SG lifting with Gaussian merging is more robust to occlusion and sparsity than point cloud reasoning.

## Relation to Prior Work

FROSS departs from the dominant paradigm of 3D SSG generation, which relies on instance-segmented point clouds (3DSSG, SGFN, Wu 2023) or full 3D reconstruction, by instead lifting 2D scene graphs into 3D space via Gaussian back-projection. The 2D SG generation pipeline is built on EGTR's transformer-based relationship extraction with RT-DETR as the detection backbone, while the 3D covariance back-projection inverts the Jacobian formulation from EWA splatting and the weighted Gaussian merging follows the mixture reduction framework of Crouse et al. The key conceptual departure is that precise object geometry and SLAM-based environmental mapping are unnecessary for high-level semantic scene understanding, a position the authors argue is underexplored in the literature.

## Why It Matters / Open Questions

The 7 ms end-to-end latency (vs. 161–310 ms for prior online methods) makes 3D SSG generation viable on resource-constrained edge devices and frees compute for concurrent system components in robotics and AR pipelines. However, the ablation with ground-truth 2D SGs reveals a large performance gap (e.g., relationship recall jumps from 27.9% to 55.8% on 3DSSG), indicating that 2D SG quality is the dominant bottleneck and that current results represent a lower bound. Open questions include whether domain-adaptive 2D SG models can close this gap, whether the Gaussian approximation suffices for downstream tasks requiring precise geometry, and how the method scales to larger, more cluttered scenes beyond indoor environments.

## Problem

Existing gradient inversion attacks in federated learning struggle to reconstruct high-resolution images from large batches (e.g., 128+ samples), and while recent methods narrow the reconstruction scope, they can only target samples via semantic-irrelevant criteria like brightness or class identity. No prior approach allows an adversary to specify, in a flexible and semantically meaningful way, which specific data samples they want to recover from a victim's private batch.
![Teaser figure](../imgs/ICCV20251286/cropped_page0_idx0.webp)

## Input / Output

The attacker provides a free-form natural language query (e.g., "Any weapon?") that need not relate to the FL classification task, along with an auxiliary unlabeled image dataset that may come from a completely different domain (e.g., ImageNet for a FER task). The method produces a malicious global model whose loss surface is reshaped so that query-matching samples dominate the victim's submitted gradients, after which any standard reconstruction optimizer recovers targeted images at 224×224 resolution from batches up to 256 samples. The FL server simultaneously maintains a usable model via non-victim clients, so the attack is undetectable from model utility.

## Method

Geminio exploits a pretrained VLM (CLIP) to reshape the loss surface of a randomly initialized global model during a preparation phase. For each auxiliary sample, the VLM computes a text-image similarity score with the query; these scores are normalized via softmax across the batch to produce per-sample alignment weights. The malicious model is then trained with a weighted loss (Eq. 4) where irrelevant samples receive large coefficients (penalizing their loss) and matched samples receive small coefficients (allowing their loss to remain high), effectively creating a loss landscape that responds only to query-relevant inputs. A second VLM-guided step generates soft labels for unlabeled auxiliary data by projecting image features against class-name text embeddings, eliminating the need for ground-truth annotations. At attack time, the victim optimizes this malicious model on its private batch, producing gradients dominated by matched samples, which are then consumed by existing reconstruction methods (HF-GradInv, DLG, InvertingGrad) to recover high-fidelity targeted images.

## Results

On CIFAR-20, Geminio achieves an attack recall of 64.96% and precision of 65.67% even when the victim uses a large batch size of 256, while the VLM-based label-poisoning baseline is virtually useless beyond batch size 8. The attack F-1 score is 68.13% with the default auxiliary dataset (20% of training data), dropping only to 60.37% with 5% auxiliary data, and still reaching 64.37% when using ImageNet (a different domain) as auxiliary data. Geminio's malicious model parameters have a maximum magnitude of only 1.64 (vs. 0.35 for a clean model), making it far stealthier than Fishing (2772.89) or GradFilt (1000).

## Baselines & Comparisons

Geminio is the only method achieving task-agnostic, instance-level targeted reconstruction: it can recover specific samples matching a natural language query regardless of their class label. Fishing [35] can only return one random sample of a given class, and GradFilt [42] returns all samples of a given class — both are restricted to class-level targeting and require unnaturally large output-layer parameters (magnitudes 2772.89 and 1000 vs. Geminio's 1.64), making them detectable via parameter inspection. SEER [10], LOKI [46], and Abandon [1] can only target random samples or semantic-irrelevant conditions (e.g., brightness level), offering no meaningful control over which specific content is recovered. As a reconstruction plugin, Geminio consistently improves HF-GradInv [36], DLG [47], and InvertingGrad [12]: without Geminio, none of these methods can recover recognizable images from a batch of 64, but with Geminio's gradient amplification they all produce high-fidelity reconstructions of the targeted samples (measured by LPIPS). Notably, DLG — originally reported to fail at 64×64 resolution — successfully recovers a 224×224 handgun image from a large batch when augmented by Geminio.

## Relation to Prior Work

Geminio extends the gradient inversion attack (GIA) literature in federated learning by introducing a natural language interface for targeted reconstruction. Prior narrowing-scope methods (Abandon, Robbing, SEER, LOKI) rely on modified architectures to trap random or semantically-irrelevant samples, while Fishing and GradFilt achieve only class-level targeting via unnaturally large output-layer parameters. Geminio departs from both by repurposing a pretrained VLM (CLIP) as a loss-surface supervisor that reshapes model parameters in a stealthy, architecture-agnostic manner, enabling instance-level, task-agnostic targeting specified in free-form language. The closest conceptual precursor is Imperio, which uses language-guided backdoor attacks, but Geminio is the first to apply this paradigm to gradient inversion.

## Why It Matters / Open Questions

Geminio reveals that pretrained VLMs can be weaponized to create a new class of privacy attacks that are simultaneously flexible (arbitrary natural language queries), stealthy (model parameters indistinguishable from clean), and resilient to standard defenses (gradient pruning, Laplacian noise, parameter inspection). The paper demonstrates that even 95% gradient pruning and moderate noise injection fail to mitigate the attack, and that the only viable detection signal (per-sample loss inspection) can be suppressed by an adaptive variant. Open questions include designing defenses that do not sacrifice FL utility, understanding whether the attack generalizes to non-image modalities, and whether the VLM-guided loss reshaping principle can be extended to other adversarial settings beyond FL.

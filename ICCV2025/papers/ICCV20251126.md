## Problem

In real-world heterogeneous collaborative perception, vehicles from different manufacturers use different sensor configurations and perception models, creating a domain gap in intermediate feature spaces. Existing methods require joint training with each new collaborator or pre-storing adapters for all potential partners, which is impractical as new sensors and models continuously emerge. The paper asks whether the ego vehicle can dynamically adapt its model parameters during inference to bridge this gap without any prior knowledge of the collaborator.
![Teaser figure](../imgs/ICCV20251126/cropped_page0_idx1.webp)

## Input / Output

The ego vehicle receives its own LiDAR point cloud (encoded via PointPillars) and intermediate BEV feature maps from collaborating agents (encoded via different architectures such as SECOND). During Stage I, agents additionally transmit their own detection predictions with confidence scores, which serve as pseudo-labels; during Stage II, only features are shared. The output is a fused 3D object detection result (positions and confidence scores) from the ego's detector head, along with the learned CBAM adapter parameters that map each agent's feature space to the ego's space. The adapter is trained independently per agent to prevent cross-agent interference in multi-agent scenarios.

## Method

PHCP formulates heterogeneous feature alignment as a few-shot unsupervised domain adaptation problem solved entirely at inference time. The core adapter is a CBAM module (channel + spatial attention), chosen because visual analysis revealed the domain gap manifests as channel misalignment and differences in critical spatial regions rather than global distribution shift. In Stage I, the ego fine-tunes only the adapter (freezing the fusion network and detector head) using the agent's high-confidence predictions as soft pseudo-labels over k frames (1, 5, or 10 shots), following a two-stage fine-tuning strategy with warmup and multi-step decay scheduling over 20 epochs. In Stage II, the trained adapter transforms incoming agent features into the ego's semantic space before standard multi-scale pyramid fusion and detection. The entire adaptation takes 1.5–2.4 seconds depending on shot count, and the 0.07-second inference overhead meets real-time requirements.

## Results

On the OPV2V test set (16 heterogeneous scenarios), PHCP achieves mSAP of 92.8 / 92.3 / 87.1 at IoU 0.3 / 0.5 / 0.7, outperforming the direct-fusion baseline (59.7 / 59.5 / 53.0) by approximately 33 percentage points at IoU 0.7. Compared to SOTA heterogeneous method HEAL (95.5 / 95.1 / 91.7), PHCP trails by 2.7–4.6 points but achieves this using only a small amount of unlabeled data (1–5 shots) rather than full-dataset joint training. The few-shot adapter fine-tuning takes 1.5–2.4 s depending on shot count, and inference adds only 0.07 s overhead.

## Baselines & Comparisons

PHCP outperforms all non-heterogeneous baselines (F-Cooper, CoBEVT, AttFusion, V2X-ViT) by a wide margin on mSAP@0.7: 87.1 vs. 63.4, 72.0, 77.3, and 82.8 respectively, with the largest gap over F-Cooper (+23.7 points). Against the direct-fusion baseline (no adapter, no joint training), PHCP gains ~33 points across all IoU thresholds, confirming that the CBAM-based adapter effectively bridges the domain gap between PointPillars and SECOND encoders. The only method that surpasses PHCP is HEAL (91.7 vs. 87.1 at IoU 0.7), which trains a unified feature space on the full labeled dataset; PHCP closes most of this gap while requiring only 1–5 unlabeled frames per collaborator. Notably, PHCP matches V2X-ViT on mSAP@0.5 (both 92.3) and exceeds it by 4.3 points at IoU 0.7, all without any prior knowledge of the collaborator's model architecture.

## Relation to Prior Work

This paper extends the heterogeneous collaborative perception line (V2X-ViT, PnPDA, HEAL) by shifting the domain-gap resolution from a training-time problem to an inference-time one. It repurposes the CBAM attention module as a lightweight feature adapter and borrows the two-stage fine-tuning strategy (TFA) for efficient few-shot optimization, while adopting HEAL's multi-scale pyramid fusion for feature integration. The key conceptual departure is formulating the problem as few-shot unsupervised domain adaptation: instead of pre-training adapters on labeled data or storing per-collaborator models, the ego vehicle self-trains a CBAM adapter using pseudo-labels generated by the agent's own predictions during the first few frames of collaboration.

## Why It Matters / Open Questions

The practical implication is significant: it removes the need for joint training or pre-stored adapters, making heterogeneous collaboration genuinely plug-and-play in real-world V2X deployments where new manufacturers and sensor configurations continuously appear. However, the evaluation is confined to a simulation dataset (OPV2V/OPV2VH) with only two encoder architectures (PointPillars, SECOND) and 16 scenarios, leaving open whether the approach generalizes to more diverse model families, camera-based perception, or real-world noise and latency. An open question is how the method scales when multiple heterogeneous agents with different domain gaps must be adapted simultaneously, and whether the pseudo-label quality degrades in more challenging real-world conditions.

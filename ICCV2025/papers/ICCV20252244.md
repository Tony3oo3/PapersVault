## Problem

Existing visual in-context learning (V-ICL) methods require specialized training on curated or uncurated datasets, or access to task-related annotated data, to enable foundation models to adapt to novel tasks. This undermines the core advantage of in-context learning—adapting without any weight updates—and limits generalization to tasks seen during training. The paper asks whether an off-the-shelf Stable Diffusion model can be repurposed for V-ICL with no additional training steps or data, mirroring how LLMs exhibit ICL as an emergent property.

## Input / Output

The method takes a query image and one or more source-target prompt pairs (retrieved via CLIP cosine-similarity nearest-neighbor search) as input. All images are first inverted into Stable Diffusion's noise space using DDPM inversion, and the prediction path is initialized with the query's noise latent so the output remains structurally aligned with the query. The output is a denoised latent decoded by the VAE into a task-specific prediction (segmentation mask, keypoint map, edge map, or colorized image) whose color distribution is aligned to the prompt groundtruth domain via AdaIN.

## Method

The core contribution is an in-place attention re-computation within the self-attention layers of Stable Diffusion's denoising U-Net: instead of standard self-attention where Q, K, V all come from the same latent, the attention map is computed as softmax(Q_C · K_A^T / (τ√d)) and the feature update uses V_B, where Q_C, K_A, and V_B are extracted from the query image, prompt image, and prompt groundtruth respectively. This explicitly enforces spatial correspondence between the query and prompt (for accurate prediction) while pulling the output into the groundtruth domain (for task inference). For multiple prompts, the proposed Implicitly-Weighted Prompt Ensembling (IWPE) concatenates K and V vectors from all prompts before the attention computation, allowing the softmax to dynamically weight each prompt patch by its relevance to each query patch rather than applying uniform averaging. Three auxiliary mechanisms—attention map contrasting, swap-guidance (a scaled blend of default and modified noise predictions), and AdaIN—bridge the domain gap introduced by mixing Q, K, V from three distinct images and stabilize the generative pipeline.

## Results

With a single prompt, SD-VICL achieves 43.92 mIoU on Pascal-5i foreground segmentation (vs. 35.04 for Visual Prompting and 39.50 for IMProv), 51.55 mIoU on single object detection, and reduces keypoint detection MSE on DeepFashion to 5.36 (vs. 71.52 for Visual Prompting). With five prompts via implicitly-weighted prompt ensembling, foreground segmentation mIoU rises to 55.49 and object detection to 57.10. Against task-trained baselines (Table 2), SD-VICL with five prompts outperforms Painter (55.09 mIoU), LVM (50.98), and Prompt Diffusion (17.53) on foreground segmentation, and reduces edge detection MSE to 0.0213 (vs. 0.0430–0.0926 for the baselines).

## Baselines & Comparisons

Against the two uncurated-data baselines, SD-VICL wins on every task and metric: it improves foreground segmentation mIoU by +8.9% over Visual Prompting and +3.2% over IMProv, and reduces keypoint detection MSE by roughly 13× (5.36 vs. 67.88–71.52). Against task-trained V-ICL models (Table 2), SD-VICL with five prompts matches or exceeds Painter (55.49 vs. 55.09 mIoU on FG seg) and LVM (57.10 vs. 52.67 on object detection), while dramatically outperforming Prompt Diffusion (17.53 mIoU). On edge detection, SD-VICL reduces MSE to 0.0213, beating LVM (0.0499), Prompt Diffusion (0.0430), and Painter (0.0926). Against task-specific Stable Diffusion models (Table 3), SD-VICL surpasses DAS on semantic segmentation (31.52 vs. 21.2 mIoU) and StableKeypoints on keypoint detection (4.37 vs. 6.46 MSE, 82.24 vs. 70.0 PCK). The only near-tie is foreground segmentation mIoU where SD-VICL (55.49) edges out Painter (55.09) by 0.4 points; all other comparisons show clear margins in favor of SD-VICL.

## Relation to Prior Work

This paper positions itself at the intersection of NLP in-context learning and diffusion-based vision models, arguing that prior V-ICL methods (Visual Prompting, IMProv, Painter, LVM, Prompt Diffusion) all require additional training on curated or uncurated data, which undermines the core promise of ICL. It builds directly on Stable Diffusion's self-attention architecture and borrows attention map contrasting, swap-guidance, and AdaIN from cross-image attention work (Alaluf et al., 2024), while the swap-guidance mechanism is derived from classifier-free diffusion guidance (Ho & Salimans, 2022). The key conceptual departure is replacing the standard self-attention computation with an in-place cross-image attention re-computation that explicitly wires query-to-prompt context, eliminating the need for any training step. The implicitly-weighted prompt ensembling extends SegGPT's uniform feature averaging by integrating ensembling into the attention computation itself.

## Why It Matters / Open Questions

This is the first demonstration that an off-the-shelf diffusion model possesses latent V-ICL capability that can be unlocked purely through inference-time attention modification, without any fine-tuning or task-specific data. This shifts the V-ICL research direction from 'how to train a model to do ICL' toward 'how to elicit ICL from existing foundation models,' aligning vision more closely with the NLP paradigm. Limitations include dependence on DDPM inversion for noise-space initialization, inference speed degradation with multiple prompts (roughly halved at five prompts), and evaluation restricted to six relatively standard vision tasks. Open questions include whether the approach generalizes to other diffusion architectures (e.g., DiT-based models), whether it can handle more complex or compositional tasks, and whether the attention rewiring can be made more principled rather than relying on hand-crafted Q/K/V routing.

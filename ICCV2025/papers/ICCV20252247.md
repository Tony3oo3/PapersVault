## Problem

Existing zero-shot quantization (ZSQ) methods for object detection rely on task-agnostic synthetic images that lack bounding box locations, sizes, and category distributions, leading to suboptimal quantized performance. The core challenge is that object detection labels are far more complex than classification labels—requiring precise spatial coordinates and category information that are entirely unknown in a zero-shot setting—making it difficult to synthesize realistic calibration data without any real training data or ground-truth annotations.
![Teaser figure](../imgs/ICCV20252247/cropped_page1_idx1.webp)

## Input / Output

The method takes a pre-trained full-precision detection network (YOLOv5, YOLO11, or Mask R-CNN with CNN/Swin Transformer backbone) and produces a quantized network that outputs bounding boxes and object class labels. Notably, it requires only 2k synthetic calibration images (1/60 of MS-COCO's 120k training set) and no real data; the synthetic images are generated from Gaussian noise optimized against the pre-trained network's internal statistics and detection predictions. The quantized network operates at various bit-widths (W8A8, W6A6, W4A8) while maintaining detection accuracy comparable to full-data QAT baselines.

## Method

The framework has two stages. Stage 1 (task-specific calibration synthesis) introduces an adaptive label sampling strategy: it initializes a single randomly sampled bounding box, optimizes Gaussian noise using a combined loss of BNS alignment, detection loss (category + box dimension + confidence), and regularization, then iteratively re-detects objects with the pre-trained network to add high-confidence and remove low-confidence labels—progressively reconstructing realistic object locations, sizes, and category distributions without any prior knowledge. Stage 2 (QAT with task-specific distillation) fine-tunes the quantized student network using three loss terms: KL divergence between teacher and student predictions (soft-label distillation), MSE alignment of intermediate feature maps (feature-level distillation for stability at low bit-widths), and the full detection training loss L_detect, which directly teaches the quantized network to predict bounding boxes from the synthetic labels. This dual task-specific design—both in data synthesis and in the QAT objective—distinguishes the method from prior task-agnostic ZSQ approaches that omit detection-specific supervision entirely.

## Results

On MS-COCO validation, the proposed method (using only 2k synthetic images, no real data) outperforms LSQ and LSQ+ trained on the full 120k real dataset by 0.3%–1.0% mAP at W8A8 across all YOLOv5 and YOLO11 models. At W6A6, the method achieves mAP comparable to full-data LSQ/LSQ+ while surpassing LSQ/LSQ+ trained on the same 2k data by 2%–6% (e.g., YOLOv5-l: 45.1 vs. 43.3/43.4 mAP for full-data LSQ/LSQ+, vs. 37.7/37.5 for 2k-data baselines). On Pascal VOC, the method surpasses full-data LSQ by 0.5% mAP using only 50 synthetic samples (72.9 vs. 72.4).

## Baselines & Comparisons

The paper compares against two real-data QAT baselines: LSQ [15] and LSQ+ [2], each evaluated with either the full 120k MS-COCO training set or a reduced 2k subset. At W8A8, the proposed method (2k synthetic, no real data) beats full-data LSQ by 0.1%–1.3% mAP and full-data LSQ+ by 0.3%–1.0% mAP across YOLOv5-s/m/l and YOLO11-s/m/l (e.g., YOLOv5-l: 47.3 vs. 46.0/46.3). At W6A6, the method matches or slightly trails full-data LSQ/LSQ+ (e.g., YOLOv5-l: 45.1 vs. 43.3/43.4) while outperforming the 2k-data baselines by 7.4–7.6% mAP. At W4A8, the method again surpasses full-data LSQ/LSQ+ on YOLOv5 models (46.2 vs. 44.6/44.4 for YOLOv5-l) and is competitive on YOLO11. On Pascal VOC, the method achieves 72.9 mAP with only 50 synthetic samples, exceeding full-data LSQ (72.4) by 0.5% and 50-sample LSQ (70.9) by 2.0%.

## Relation to Prior Work

This paper extends the zero-shot quantization (ZSQ) line of work—originally developed for classification networks using BNS alignment (ZeroQ, Dreaming to Distill) and Patch Similarity Entropy for ViTs (PSAQ-ViT)—to object detection by introducing task-specific information into both data synthesis and QAT. It departs from recent task-agnostic ZSQ-for-detection methods (PSAQ-ViT V2, MimiQ, CLAMP-ViT), which deliberately dropped detection losses to maintain cross-task generality, arguing that this sacrifices bounding box location, size, and category information critical for detection. The adaptive label sampling strategy draws on soft-label data reconstruction ideas from dataset condensation (Squeeze, Recover and Relabel), repurposing them to iteratively refine synthetic bounding box labels using only a pre-trained detector.

## Why It Matters / Open Questions

The practical significance is substantial: deploying quantized detection networks on edge devices often requires training data that is unavailable due to privacy or scale constraints, and this work shows that 2k synthetic images can match or exceed 120k real-image QAT across YOLOv5, YOLO11, and Mask R-CNN variants. Open questions include whether the approach generalizes to other detection sub-tasks (instance segmentation, keypoint detection), how it behaves at extreme low-bit settings (4-bit weights for activations), and whether the iterative adaptive label sampling scales efficiently to very large detection heads. A limitation is the dependence on a pre-trained full-precision teacher, which constrains applicability in truly from-scratch quantization scenarios.

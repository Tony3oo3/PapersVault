## Problem

Existing 3D semantic segmentation methods adapt exclusively to either task-specific goals (open-vocabulary segmentation, where the user specifies classes) or scene content (unsupervised semantic segmentation, where classes are discovered label-free), but no prior work provides a segmentation simultaneously adapted to both the scene's actual content and a user's downstream task query. This paper introduces the 3D Open-Vocabulary Sub-concepts Discovery (OV-SD) paradigm, which requires discovering the most fine-grained semantic classes present in a scene that are also semantically related to one or more user queries.

## Input / Output

The method takes as input a pretrained frozen Neural Field representation (LeRF with joint CLIP and DINO feature fields, or OpenNeRF's dense CLIP field) of a 3D scene, plus one or more user queries encoded as CLIP embeddings (text, visual, or click-based). It produces a 3D semantic segmentation over a back-projected point cloud where each discovered sub-concept is assigned a CLIP prototype embedding, enabling a posteriori textual concept retrieval. The number of prototypes is fixed a priori (N=10 in main experiments), and the segmentation is rendered per-viewpoint and aggregated via argmax across supervision views.

## Method

DiSCO-3D jointly performs unsupervised semantic segmentation and open-vocabulary guidance within a single optimization, rather than executing them sequentially. A learned projector maps DINO features from the feature field into a latent space where samples agglomerate around N prototypes updated via a density-weighted, confidence-weighted EMA. The key mechanism for OV-SD is adding N_irr irrelevant-class prototypes supervised by a binary mask derived from the CLIP field's similarity to the query (L_irr), which pushes query-irrelevant samples toward irrelevant prototypes while L_proj (a correlation loss on DINO feature pairs) maintains semantic consistency among relevant classes. A progressive linear decay of the softmax sharpness parameter β enforces cluster separation over training, and a CLIP-prototype regularization loss (L_proto) prevents DINO's tendency toward over-segmentation by pulling projected features toward the prototype whose CLIP embedding best matches the sample. Each prototype also maintains a CLIP embedding updated by the same EMA, providing interpretable sub-concept labels without requiring the user to name them.

## Results

On the proposed 3D OV-SD benchmark (Replica extension with 40 concepts), DiSCO-3D achieves PQ 8.13 / mIoU 10.79 / mAcc 33.39 on LeRF and PQ 8.65 / mIoU 10.82 / mAcc 19.24 on OpenNeRF, outperforming the best sequential baseline (OVS→USS) by +72% PQ, +71% mIoU, and +42% mAcc (averaged across both feature fields). On the OV-Seg edge case, plugging DiSCO into LeRF raises mIoU from 8.79 to 12.42 (+3.63) and mAcc from 84.53 to 87.93. On the USS edge case, DiSCO-3D achieves mIoU 27.47 and mAcc 51.99, surpassing K-Means (27.00 / 50.14), GrowSP (21.62 / 34.24), and SmooSeg (10.49 / 31.07).

## Baselines & Comparisons

The primary OV-SD comparison (Table 1) pits DiSCO-3D against two sequential baselines (USS→OVS and OVS→USS) and their K-Means variants; DiSCO-3D wins on all metrics by a wide margin, with the largest gains in PQ (+72% over USS→OVS) and mIoU (+71%), confirming that joint optimization of USS and OV-Seg substantially outperforms performing them successively. On the OV-Seg edge case (Table 3), DiSCO-3D plugged into LeRF improves mIoU from 8.79 to 12.42 and mAcc from 84.53 to 87.93, while on OpenNeRF it yields smaller but consistent gains (mIoU 21.60→21.87, mAcc 91.87→92.66), indicating the method is most beneficial when the underlying feature field is weaker. On the USS edge case (Table 4), DiSCO-3D (mIoU 27.47, mAcc 51.99) beats the point-cloud method GrowSP (21.62 / 34.24) by ~6 mIoU and ~18 mAcc, and the 2D method SmooSeg (10.49 / 31.07) by ~17 mIoU, while only marginally surpassing a simple K-Means baseline on DINO features (27.00 / 50.14). The K-Means comparison is notable because it shows the prototype-based USS architecture contributes only ~0.5 mIoU over vanilla clustering in the query-free setting, but the same architecture is essential for OV-SD where it provides the +72% PQ gain.

## Relation to Prior Work

DiSCO-3D sits at the intersection of two previously separate 3D segmentation paradigms: Open-Vocabulary Segmentation (OV-Seg), which adapts to user-specified task classes via vision-language models like CLIP, and Unsupervised Semantic Segmentation (USS), which adapts to scene content via label-free clustering. The method is architecturally a plug-in to LeRF's dual CLIP+DINO feature fields and adapts the prototype-based USS framework from STEGO (Hamilton et al.) to the continuous NeRF representation for the first time, introducing density-weighted prototype updates and a scheduled sharpness decay. The key conceptual departure is performing USS and OV-Seg jointly through a shared projector rather than sequentially, with the CLIP field providing weak supervision to guide the DINO-based clustering toward query-relevant sub-concepts.

## Why It Matters / Open Questions

The paper introduces a genuinely new task formulation (3D OV-SD) that unifies scene-adaptive and task-adaptive segmentation, which is practically relevant for robotics and embodied AI where a single fixed class set is insufficient. However, the benchmark is small (8 Replica scenes, 40 concepts), absolute performance remains low (PQ ~8–10, mIoU ~10–12), and the authors themselves note the benchmark is 'far from being saturated,' leaving substantial room for future work. Open questions include whether the approach generalizes beyond indoor synthetic scenes, how it scales to larger or more diverse datasets, and whether the joint optimization advantage over sequential pipelines persists with stronger individual OV-Seg or USS components. The method's versatility as a drop-in for any NeRF feature field (LeRF, OpenNeRF, or custom) makes it a useful building block even if the current benchmark is limited.

## Problem

State-of-the-art logical anomaly detection methods rely on aggregated pretrained features or handcrafted descriptors derived from composition maps, which discard the spatial and semantic information needed to detect anomalies like missing or misplaced object components. Existing composition-based approaches further require hand-labelled training data or category-specific tuning, limiting their practical applicability. No prior method explicitly models the distribution of object composition maps in a discriminative manner to capture the full spatial-semantic structure of objects.

## Input / Output

SALAD takes a single RGB image (resized to 256×256) as input and internally generates a composition map (a per-pixel segmentation of object components into K=6 classes) via a trained UNet. At inference it produces both an image-level anomaly score (a normalized sum of three branch scores) and a pixel-level anomaly segmentation mask. The composition map generation is fully automatic, requiring no hand labels or category-specific parameters, and the model is trained exclusively on anomaly-free images.

## Method

SALAD is a three-branch architecture: a local appearance branch (EfficientAD student-teacher autoencoder), a novel composition branch, and a global appearance branch. The composition branch is a discriminative model operating entirely in composition-map space: a reconstruction network restores synthetically corrupted composition maps to their anomaly-free form (trained with focal + dice loss), and a discriminative network then segments the difference between the input and reconstruction (trained with focal + L1 loss). Composition maps are generated automatically by combining SAM-HQ mask proposals with DINO feature clustering (K=6) to create pseudo-labels, on which a UNet is trained to predict final maps directly from RGB. Synthetic anomalies for training the composition branch include DR/EM-style class pasting via Perlin noise, component inpainting from other images, and component erasure with neighbour-class fill. The global branch computes per-class mean feature vectors from the teacher encoder and scores anomalies via per-class Mahalanobis distance, preserving spatial structure that global averaging discards.

## Results

On the primary logical anomaly detection benchmark MVTec LOCO, SALAD achieves a state-of-the-art image-level AUROC of 96.1%, outperforming the previous best method PUAD (93.1%) by 3.0 percentage points. On the structural anomaly datasets, SALAD scores 98.8% AUROC on MVTec AD and 97.9% on VisA (98.3% average), remaining competitive with dedicated structural methods. When trained with supervised composition maps (SALAD†), the method reaches 97.2% on MVTec LOCO, surpassing all supervised-mask baselines by 1.9 pp.

## Baselines & Comparisons

On MVTec LOCO, SALAD (96.1%) decisively outperforms all unsupervised baselines, with the largest gaps over PUAD (+3.0 pp), SLSG (+5.8 pp), and DR/EM (+16.3 pp). Among methods that also use composition maps, SALAD surpasses CSAD (95.3%) and PSAD (94.9%) even without supervised masks, and extends the lead to 97.2% when given PSAD's supervised maps (SALAD†). On the structural-only datasets (MVTec AD, VisA), SALAD (98.3% avg) trails EfficientAD (98.6% avg) by 0.3 pp but beats other logical-anomaly methods such as PUAD (97.7%), PSAD (94.2%), and CSAD (92.6%), confirming that the composition branch does not degrade structural detection. The per-category breakdown (Table 2) shows SALAD achieving the highest AUROC on both logical (96.5%) and structural (95.7%) anomaly sub-types simultaneously, whereas most baselines excel in only one.

## Relation to Prior Work

SALAD extends the two-branch framework common to recent logical anomaly detection methods (a local appearance branch plus a global semantic branch) by replacing the global branch with a discriminatively trained composition branch that operates directly on object composition maps. The local appearance branch follows EfficientAD's student-teacher architecture, while the composition branch adapts the discriminative synthetic-anomaly paradigm from DRAEM/DR-EM to the composition-map domain. The key departure from prior composition-based methods (ComAD, PSAD, CSAD) is that SALAD learns the full spatial-semantic distribution of composition maps rather than reducing them to handcrafted statistics or memory-bank lookups, and it generates those maps automatically via a SAM-HQ + DINO clustering pipeline without hand labels or per-category tuning.

## Why It Matters / Open Questions

The 3.0 pp AUROC gain on MVTec LOCO (96.1% vs. 93.1% for PUAD) is the largest margin over prior SOTA in this benchmark, and the ablation confirms the composition branch is the primary driver (3.5 pp drop in logical anomaly detection when removed). The automatic composition map generation pipeline is practically significant because it eliminates the manual annotation requirement of PSAD and the category-specific parameter tuning of CSAD, making the approach directly transferable to new object categories. Open questions include whether tighter interaction between the three branches (currently fused only at the score level) could yield further gains, and whether the fixed cluster count (K=6) and the multi-step SAM-HQ/DINO/UNet pipeline generalize to objects with highly variable or fine-grained component structures.

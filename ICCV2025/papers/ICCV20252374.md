## Problem

Prior collaborative perception methods handle multi-agent (spatial) fusion and multi-time (temporal) fusion as separate sequential steps, preventing holistic modeling of their interactions and limiting perception in challenging scenarios. Additionally, existing approaches re-transmit all object features at every timestep, wasting communication bandwidth on static objects whose features remain unchanged across frames.
![Teaser figure](../imgs/ICCV20252374/cropped_page1_idx1.webp)

## Input / Output

The method consumes LiDAR point clouds from N agents (vehicles and/or infrastructure) along with 6DoF pose, extrinsic parameters, velocity, and agent-type metadata exchanged via V2X communication. Each agent's point cloud is encoded into a dense BEV feature map of shape H×W×C via PointPillar. The output is a set of 3D bounding boxes (position, dimensions, yaw angle) with class confidence scores, produced by a two-layer 1×1 convolution detection head trained with smooth L1 regression loss and focal classification loss.

## Method

CoST unifies spatial and temporal fusion by treating historical agents as time-delayed duplicates of current agents, so all agents across all timestamps are aggregated in a single spatio-temporal space. The Spatio-temporal Transmission (STT) module computes a saliency map and a dynamic map (temporal difference of saliency) to select only dynamic object features for transmission, reducing bandwidth by up to 1000× while static features are retrieved from a memory bank via pose-projected reuse. The Unified Spatio-temporal Fusion (USTF) module projects the previously fused collaborative feature to the current frame using relative pose matrices and treats it as an additional (N+1)-th agent, with recurrent modeling retaining only one fused historical feature to avoid the (N+1)L cost of parallel window-based fusion. The Multi-Agent Deformable Attention (MADA) module performs efficient cross-agent aggregation via learned sparse sampling offsets and attention weights, preceded by an Align Transformation (AT) that injects agent-specific metadata (speed, latency, infrastructure markers) through learnable projections into the feature tensors.

## Results

On V2V4Real, CoST achieves 71.0% AP@0.5 and 44.0% AP@0.7, surpassing the previous best (CoBEVT at 65.6%/37.9%) by 4.8% and 6.1% respectively. On V2XSet, CoST reaches 91.5% AP@0.5 and 81.4% AP@0.7, improving over V2VNet (88.1%/75.4%) by 3.4% and 4.3%. On DAIR-V2X, CoST attains 61.4% AP@0.5 and 47.3% AP@0.7, outperforming What2comm (60.8%/44.6%) and Where2comm (59.1%/46.0%). The gains are particularly pronounced at long range (50–100 m), where CoST leads by 7.5–10.5% AP@0.5 over prior methods.

## Baselines & Comparisons

CoST outperforms all nine compared baselines across all three datasets. On V2V4Real, it leads V2X-ViT (66.2%→71.0% AP@0.5) and CoBEVT (65.6%→71.0%) by 4.8–5.4% AP@0.5, with an even larger 6.1–7.5% gap at AP@0.7. On V2XSet, CoST surpasses V2VNet (88.1%→91.5%) and CoBEVT (87.6%→91.5%) by 3.4–3.9% AP@0.5 and 4.3–6.0% AP@0.7. On DAIR-V2X, the margin is smaller but consistent: CoST beats What2comm (60.8%→61.4%) and Where2comm (59.1%→61.4%) by 0.6–2.3% AP@0.5. The largest relative gains appear at long range (50–100 m), where temporal context from historical agents most directly compensates for occlusion and limited sensing range. Notably, CoST also reduces communication bandwidth by up to 100× via its STT module while maintaining or improving accuracy, a trade-off none of the baselines achieve simultaneously.

## Relation to Prior Work

CoST departs from the dominant paradigm in collaborative perception where multi-agent (spatial) fusion and temporal fusion are handled as separate sequential stages (e.g., SyncNet, FFNet, How2comm). By reframing historical agents as time-delayed duplicates of current agents, the paper collapses both fusion steps into a single unified spatio-temporal aggregation, a conceptual move not present in prior V2X-ViT, OPV2V, or CoBEVT pipelines. The STT module extends the selective-transmission idea from Where2comm and Select2Col by explicitly exploiting temporal redundancy (static objects need not be re-transmitted), while MADA adapts deformable attention from Deformable DETR to the multi-agent setting with an Align Transformation for agent-specific metadata.

## Why It Matters / Open Questions

The unified spatio-temporal perspective offers a clean, generalizable design principle: any multi-agent fusion architecture can be extended to incorporate temporal context simply by treating the fused historical feature as an additional 'agent,' and the STT module is pluggable into existing pipelines to cut bandwidth by up to 100×. This modularity makes the contribution practically impactful for real-world V2X deployments where communication budget is constrained. Open questions include whether the recurrent single-history design captures sufficiently long-range dynamics compared to full-window approaches, how the method scales to heterogeneous sensor suites (camera + LiDAR), and whether the 'delayed copy' framing holds under highly variable or asymmetric communication latencies in dense urban settings.

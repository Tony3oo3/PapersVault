## Problem

Language-conditioned robot manipulation methods largely assume discrete object states (e.g., open/closed), ignoring the continuous spectrum of physical states (0%–100%). Even when continuous states are modeled, training covers only a finite set of states, so the robot must generalize to previously unseen state values without additional optimization or fine-tuning. This paper tackles the gap of mapping arbitrary continuous goal states specified in natural language to precise, stable robot actions in a zero-shot manner.

## Input / Output

The method consumes a language instruction that embeds the target state (e.g., 'open the drawer 45%'), an RGB-D point cloud (downsampled to 128×128 in real-world deployment, with 4096 points sampled via FPS), and agent proprioception. The state value is not provided as a separate numerical channel; instead, it is extracted from the instruction text by an LLM at inference time. The output is the next keyframe gripper action comprising 3D translation, rotation, and binary openness, generated via a reverse DDPM sampling process conditioned on the scene, language, and a computed state embedding.

## Method

SD² Actor builds on the 3D Diffuser Actor architecture, augmenting the DDPM denoising process with learnable per-state embeddings (Base State B) that are fused with CLIP-encoded language via a custom self-attention mechanism where both K and V are projections of the concatenated text and state features. At inference, an LLM decomposes the novel state value into a convex combination of the m closest learned base states, and the corresponding embeddings are linearly combined to synthesize a novel state embedding that conditions the diffusion sampler. A Spectral Restricted Isometry Property (RIP) orthogonalization loss—split into inter-task and intra-task terms—constrains the embedding space to be closed and well-separated, ensuring that linear interpolation between base embeddings remains in-distribution. The total training objective jointly optimizes L1 losses on translation and rotation, binary cross-entropy on gripper openness, and the orthogonal regularization, all under a single DDPM noise-prediction framework.

## Results

On the ARNOLD benchmark, SD²Actor achieves an average success rate of 69.77% on the test set (learned states), 18.87% on the novel state set (single unseen state per task), and 38.48% on the any-state set (continuous spectrum), all under single-task training. These represent absolute improvements of +10.69%, +11.36%, and +10.47% over the strongest baseline (3D Diffuser Actor) respectively. In the multi-task setting, SD²Actor(MT) still leads with 56.62%, 13.88%, and 32.96% on the three splits. Real-world experiments on 5 tasks show SD²Actor outperforming 3DA by approximately 30% in success rate.

## Baselines & Comparisons

SD²Actor outperforms all three baselines across every evaluation split. Against 3D Diffuser Actor (3DA), the closest competitor, SD²Actor gains +10.69% on the test set (69.77% vs. 59.08%), +11.36% on the novel state set (18.87% vs. 7.51%), and +10.47% on the any-state set (38.48% vs. 28.01%), with the largest margins on drawer and cabinet tasks requiring fine-grained state control. PerAct achieves 60.22% on the test set but drops sharply to 6.51% on novel states and 26.66% on any states, indicating limited state generalization. 6D-CLIPort is far behind on all splits (5.13% test, 2.77% novel, 6.30% any), confirming that language-only grounding without explicit state modeling is insufficient for continuous-state manipulation. In the multi-task setting, SD²Actor(MT) still leads 3DA by +7.54% on the test set and +5.44% on novel states, though the gap narrows compared to single-task training.

## Relation to Prior Work

This paper builds directly on the 3D Diffuser Actor architecture for diffusion-based action generation, extending it with learnable state embeddings that condition the denoising process on explicit object state information. It departs from prior language-conditioned manipulation methods (PerAct, 6D-CLIPort) that treat object states as discrete labels (open/closed) by explicitly modeling the continuous state spectrum and addressing zero-shot generalization to unseen state values. The state decomposition mechanism draws on the LLM-based instruction decomposition paradigm (e.g., ManipLLM) but repurposes it for numerical state value extraction and linear combination, while the orthogonalization constraint adapts spectral norm regularization from network training to embedding space geometry.

## Why It Matters / Open Questions

The paper addresses a practical gap in language-conditioned manipulation: robots must handle continuous state values (e.g., 'open the drawer 40%') that were never seen during training, a problem prior discrete-state methods cannot address. The zero-shot linear combination approach is elegant and avoids per-state fine-tuning, but absolute success rates remain modest (12.58% on novel states, 27.89% on any states), and the method depends on LLM accuracy for offline state extraction and assumes linear relationships between state values and embeddings. Open questions include whether the linear combination assumption holds for highly non-linear state-action mappings, scalability beyond 3 base states per task, and whether the approach extends to multi-object or compositional state spaces.

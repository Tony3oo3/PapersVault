## Problem

Existing visual explainability methods (CAM, Grad-CAM, attention rollout) are designed for single-output models and treat each token independently, overlooking that MLLMs generate tokens progressively. Earlier context tokens (prompt and preceding answer tokens) introduce redundant visual activations that confound the explanation of later tokens, a phenomenon unique to MLLMs that prior work has not addressed.
![Teaser figure](../imgs/ICCV20252261/cropped_page0_idx1.webp)

## Input / Output

The method is inference-only and requires no training or back-propagation. It consumes the visual features (image patches or video frames), prompt features, and answer features extracted from a frozen MLLM, along with the token classifier weights. For each generated answer token, it outputs a refined visual activation map at the spatial resolution of visual tokens, and a combined multimodal activation map that aligns visual and textual activations via min-max normalization. The method is compatible with FlashAttention and SdpaAttention backends that do not expose attention weights.

## Method

TAM comprises two key modules applied per answer token. First, the Estimated Causal Inference (ECI) module estimates the interference map by computing a text-relevance-weighted sum of all earlier context token activation maps (excluding tokens identical to the current one), then subtracts this interference scaled by a factor s optimized via least squares to minimize the residual between the raw and interference maps. This is inspired by the potential outcome model from causal inference, adapted to MLLMs where no single 'counterfactual' output exists. Second, the Rank Gaussian Filter (RGF) denoises the resulting map by sorting values in a sliding window, multiplying by a 1-D Gaussian kernel centered at the median rank, with kernel width set by the coefficient of variation (σ/μ) for robustness. The two modules are mutually beneficial: ECI primarily reduces false activations on function words while RGF sharpens object localization, and their combination exceeds the sum of individual gains.

## Results

On COCO Caption with Qwen2-VL-2B, TAM achieves 39.1% F1-IoU (27.37% Obj-IoU, 68.44% Func-IoU), surpassing the best baseline Grad-CAM++ (29.78% F1-IoU) by 9.32 points and CAM/Grad-CAM (30.14%) by 8.96 points. On OpenPSG, TAM reaches 40.95% F1-IoU, outperforming Grad-CAM++ (32.41%) by 8.54 points. On GranDf, TAM achieves 30.83% F1-IoU versus 27.74% for CAM/Grad-CAM. Across 7 MLLMs (LLaVA-1.5, InternVL2.5, Qwen2-VL at 2B–13B), TAM consistently improves F1-IoU by 5.45%–11.01% over the CAM baseline.

## Baselines & Comparisons

TAM outperforms all nine baselines on the primary F1-IoU metric across all three datasets. Grad-CAM++ [9] is the strongest single baseline (29.78% F1-IoU on COCO Caption, 32.41% on OpenPSG), yet TAM exceeds it by 9.32 and 8.54 points respectively; CAM/Grad-CAM [56,45] (30.14% on COCO Caption) is surpassed by 8.96 points. Attention-based methods (Grad-Rollout, Attention-Rollout [1]) achieve very high Func-IoU (96–99%) by producing almost no activations, but their Obj-IoU collapses to 1–6%, yielding F1-IoU below 15%—far below TAM. Layer-CAM [26] (20.15% F1-IoU on COCO Caption) and the LRP-based combination methods CP-LRP [5] and Attn-LRP [2] (~16–17% F1-IoU) are also clearly inferior. Archi.-Surgery [32], which removes redundant features in the class dimension, scores 25.19% F1-IoU on COCO Caption, still 14 points below TAM. Notably, TAM is also complementary: when combined with CAM, Grad-CAM++, or Layer-CAM, it adds +6.12 to +16.52 F1-IoU points, indicating the causal-inference and denoising modules address failure modes orthogonal to existing gradient or attention-based explanations.

## Relation to Prior Work

This paper extends the CAM/Grad-CAM family of activation-map explainability methods, originally designed for single-output models (CNNs, ViTs, CLIP), to the multi-token generative setting of MLLMs. It departs from prior MLLM explanation work (LLaVA-CAM, LVLM-Interpret) that borrowed these conventional methods and treated each token independently, by identifying and addressing a previously overlooked issue: earlier context tokens introduce redundant visual activations that confound the explanation of later tokens. The solution draws on the potential outcome model from causal inference to estimate and subtract this interference, combined with a novel rank Gaussian filter for denoising transformer activation maps.

## Why It Matters / Open Questions

As MLLMs become central to multimodal applications, the lack of reliable visual explainability hinders model trust, debugging, and downstream tasks requiring pixel-level activations (segmentation, anomaly detection, medical imaging). TAM provides a practical, model-agnostic tool that consistently improves explainability across 7 MLLMs and multiple datasets, and can serve as a qualitative comparison tool between models. Limitations include focus on visual inputs only (audio and other modalities remain unexplored) and the reliance on a token classifier's weight vectors, which may not capture all relevant information in deeper architectures. Open questions include whether the causal inference framework can be extended to interpret higher-level model decisions and whether the approach generalizes to autoregressive video generation.

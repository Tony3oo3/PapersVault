## Problem

Object detection in remote sensing requires extensive manual annotation, and existing active learning strategies for OD suffer from the cold start problem (poor early localization) and fail to exploit the dense segmentation capabilities of foundation models. Prior SAM-based annotation tools still demand substantial manual guidance (points, prompts, or initial boxes) and do not address the common remote sensing scenario where many images contain no target objects.
![Teaser figure](../imgs/ICCV20252116/cropped_page2_idx0.webp)

## Input / Output

The framework consumes remote sensing images (1024×1024 px for WaffleHomes; variable resolution for DIOR, DOTAv2, FAIR1M, HRSC2016) along with a small initial labeled set and pre-computed SAM masks (extracted once via dense grid prompting and cached). It outputs a ranked set of images for annotation with pre-filled bounding boxes (SAM-derived via DBS), and iteratively produces a fine-tuned RTDETRv2 detector. The DBS module specifically swaps the detector's predicted boxes for the highest-overlap SAM mask boxes before presenting them to the annotator, so the user confirms or adjusts rather than draws from scratch.

## Method

The AL loop (RTDETRv2 with a frozen FM backbone) operates in two sampling stages. First, Dual-Source Uncertainty Estimation performs Hungarian matching between SAM-derived boxes and detector-predicted boxes (ignoring class labels), converts the matching cost to a quality score via exponential decay, and combines it with the detector's confidence through a harmonic mean to yield a per-image uncertainty; the top n×θ most uncertain images form a candidate pool. Second, Mask-guided Diversity Estimation extracts object-specific features by masking the FM feature map with SAM masks, builds per-class prototypes via k-means++ (cosine distance, 5 prototypes per class), and selects the n most diverse candidates by intra-class pairwise distance. The Dynamic Box Switching Module addresses cold start by replacing the detector's noisy early-stage boxes with SAM mask bounding boxes for annotation, preserving classification while fixing localization; this benefit diminishes after ~50 annotated images as the detector's own localization matures.

## Results

On DIOR (300 labeled images), AL4FM-OD achieves 10.68 mAP, substantially outperforming PPAL (4.89 mAP), CoreSet, and DivProto. On HRSC2016, it reaches 50.52 mAP versus 47.79 mAP for random sampling, and on WaffleHomes it attains 42.05 mAP versus 36.04 mAP for DivProto. The method is most competitive during cold-start iterations (<100 samples) on datasets with small or ambiguous objects (DOTAv2, FAIR1M), where it trails PPAL by ~1.3 mAP and CoreSet by ~0.05 mAP respectively. The Dynamic Box Switching module yields a 4× improvement in Recall@100 (IoU=75%) during the first annotation round on WaffleHomes and 2× on HRSC2016.

## Baselines & Comparisons

Against DivProto [42], AL4FM-OD wins decisively on DIOR (10.68 vs. ~1 mAP at 300 samples) and WaffleHomes (42.05 vs. 36.04 mAP), while DivProto is described as 'ineffective' on HRSC2016 and only median on FAIR1M; the paper confirms that global similarity-based diversity (DivProto's approach) performs worse than random sampling on multi-instance images. Against CoreSet [32], AL4FM-OD wins on DIOR (10.68 vs. 4.8 mAP) and WaffleHomes, but CoreSet edges out AL4FM-OD on FAIR1M (12.12 vs. 12.07 mAP) and shows median performance elsewhere. Against PPAL [44], AL4FM-OD achieves a large margin on DIOR (10.68 vs. 4.89 mAP) and WaffleHomes, but PPAL outperforms AL4FM-OD on DOTAv2 (9.24 vs. 7.93 mAP), likely due to the presence of very small objects (≤10 px) that SAM struggles to segment; on HRSC2016 and FAIR1M both methods achieve only median results. Overall, AL4FM-OD demonstrates the most consistent cross-dataset performance, whereas each baseline excels on at most one dataset and degrades on others.

## Relation to Prior Work

This paper extends the dual-objective active learning framework for object detection (building on DivProto's prototype-based diversity and PPAL's uncertainty calibration) by integrating foundation models at two critical points: SAM provides dense mask extraction that replaces the detector's unreliable early-stage boxes, and a pretrained FM backbone supplies both detection features and mask-guided feature representations for diversity estimation. It departs from prior SAM-based annotation tools (Label Studio, Napari-SAM, Autodistill) by automating mask-to-box alignment without user prompts, and from cold-start AL methods (ALWOD, Chen et al.) by specifically targeting the localization gap in detector-based OD rather than classification confidence. The Dynamic Box Switching Module is a practical departure from pseudo-labeling approaches, which assume per-object certainty implies per-image certainty—a assumption that breaks down in multi-instance detection.

## Why It Matters / Open Questions

The framework offers a practical, real-time pipeline that reduces annotation burden for remote sensing OD while simultaneously improving detection accuracy, validated by both quantitative benchmarks across five datasets and a user study showing ~14% AP50 gains within the same annotation time. Key limitations include SAM's poor segmentation of small or contextually-defined objects (windmills, bridges, golf courses), which cascades into degraded uncertainty and diversity estimates, and the user study's small sample size (8 participants, 1-hour sessions) limits generalizability claims. Open questions include whether the approach transfers to non-orthorectified or cloud-occluded imagery, whether SAM's grid-based dense extraction can be replaced by more adaptive prompting for small objects, and whether the cold-start advantage persists beyond ~50 annotated images as the detector's own localization matures.

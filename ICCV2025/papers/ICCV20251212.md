## Problem

Existing ToF depth denoising methods either process frames independently, producing temporally inconsistent results, or fuse depth features across frames, which introduces spatial ambiguity because depth values at corresponding pixels shift under camera motion. This paper addresses both issues by exploiting the temporal self-similarity of graph structures (which encode neighborhood correlations and are motion-invariant) rather than depth features themselves.
![Teaser figure](../imgs/ICCV20251212/cropped_page0_idx0.webp)

## Input / Output

The network consumes noisy ToF raw data as in-phase (x_i) and quadrature (x_q) correlation components for the current frame and the immediately preceding frame, at 320×240 resolution. It outputs denoised in-phase and quadrature components, which are then converted to a depth map via the standard ToF depth reconstruction formula (Eq. 4). For multi-frequency inputs, each frequency is denoised separately with shared parameters and the resulting depth maps are merged via phase unwrapping.

## Method

The GIGA-ToF network has three stages: (1) an encoder-decoder feature extractor producing multi-scale geometric features and initial prior weights; (2) a Graph-Informed Geometric Attention (GIGA) module that computes intra-frame graph adjacency matrices via a single convolution and an inter-frame attention map (a self-attention variant) to map the reference frame's graph into the current frame through 2-hop and 3-hop path compositions, then fuses the mapped and current graphs with a learned confidence matrix; (3) an Unrolled Graph Laplacian Regularization (GLR) module that solves the MAP denoising problem (ToF noise likelihood + graph smoothness prior on the fused graph) via iterative convolutional filtering with adaptively learned weights. The key insight is that graph structures reflecting pixel correlations are invariant to depth shifts caused by camera motion, so fusing them avoids the spatial ambiguity of depth-feature fusion while still leveraging temporal correlation for consistency.

## Results

On the synthetic DVToF dataset, GIGA-ToF achieves MAE 0.0193 m, AbsRel 0.0060, δ₁ 0.9974, and TEPE 0.0637 m, outperforming the best single-frame method (GLRUN, MAE 0.0357) by 45.9% and the best multi-frame model-based method (WMF, MAE 0.0311) by 37.9% in MAE. Under augmented edge noise, GIGA-ToF maintains MAE 0.0487 m and TEPE 0.1102 m, while WMF achieves slightly better TEPE (0.0950 m) but comparable MAE (0.0495 m). On real Kinect v2 data, GIGA-ToF generalizes strongly despite being trained only on synthetic data, producing sharper details than GLRUN and WMF while MTDNet fails to generalize.

## Baselines & Comparisons

GIGA-ToF outperforms all 10 baselines on MAE, AbsRel, and δ₁ in the standard DVToF setting. Against the strongest single-frame DNN (GLRUN, MAE 0.0357), GIGA-ToF reduces MAE by 45.9% and TEPE by 13.2%, confirming the benefit of cross-frame graph fusion over single-frame processing. Against the best multi-frame model-based method (WMF, MAE 0.0311, TEPE 0.0751), GIGA-ToF improves MAE by 37.9% and TEPE by 15.2%, while running 900× faster (0.027 s vs. 24.3 s). Among multi-frame DNNs, GIGA-ToF beats MTDNet (MAE 0.0566) by 65.9% and DVSR (MAE 0.0718) by 73.1% in MAE, with substantially lower TEPE (0.0637 vs. 0.1046 and 0.1176 m), demonstrating that fusing motion-invariant graph structures avoids the spatial ambiguity of direct depth-feature fusion. The only case where a baseline is competitive is WMF under augmented edge noise, where WMF achieves slightly lower TEPE (0.0950 vs. 0.1102 m) but at 900× the runtime and with visible quantization artifacts. On real Kinect v2 data, GIGA-ToF generalizes well while MTDNet fails entirely, and GIGA-ToF preserves more detail than both GLRUN and WMF.

## Relation to Prior Work

This paper extends the graph Laplacian regularization (GLR) line of work for ToF denoising (GLRUN [17]) by introducing a cross-frame graph fusion mechanism that exploits the temporal self-similarity of neighborhood correlation graphs. It departs from prior multi-frame approaches (MTDNet, DVSR, ConvLSTM) that fuse depth features across frames—suffering from spatial ambiguity when depth values shift due to camera motion—by instead fusing motion-invariant graph structures via a graph-informed geometric attention (GIGA) module. The MAP formulation combining a ToF noise-derived likelihood with graph smoothness prior on the fused graph, unrolled into iterative learned filters, unifies the model-based interpretability of GSP with the data-driven adaptability of attention-based networks.

## Why It Matters / Open Questions

Temporal consistency is essential for downstream ToF applications (robotics, AR, 3D reconstruction), yet most SOTA denoisers operate frame-by-frame and produce jittery outputs. GIGA-ToF's graph-spectral interpretability provides a principled explanation for its strong generalization to real Kinect v2 data without domain adaptation—a practical advantage over purely data-driven competitors. The main limitation is that only the immediately preceding frame is used as reference; extending to longer temporal windows with recurrent architectures is left as future work. The approach also highlights a broader principle: fusing structural/relational representations rather than raw signal values can resolve alignment ambiguities in multi-frame processing.

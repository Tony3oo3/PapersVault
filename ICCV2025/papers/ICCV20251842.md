## Problem

Existing zero-shot ObjectNav methods either rely on semantic-visual similarity (failing when semantically related cues are absent) or convert 3D environments into text for LLM reasoning (losing geometric context and producing environment-agnostic inferences). The paper identifies that an object's functional role within a specific scene—not just its category—determines contextual co-occurrence relationships, and that this functional reasoning can be captured in a structured probabilistic graph rather than left entirely to free-form LLM text generation.
![Teaser figure](../imgs/ICCV20251842/cropped_page0_idx0.webp)

## Input / Output

The agent receives egocentric RGB-D observations at each timestep along with a freely specified text target category and its sensor pose (x, y, θ). Internally it maintains a 1000×1000-pixel probabilistic semantic map (20 px/m, up to 50×50 m) with separate channels for obstacles, explored areas, object categories, and scene categories, plus a dynamically growing FBN. The final output is a discrete action (move_forward, turn_left, turn_right, stop) selected by following a Fast Marching Method path to a waypoint chosen from a 2D Gaussian-projected probability map of goal occurrence.

## Method

The FBN is a directed acyclic graph with three node types (scene instances, object instances, function-group instances) and two edge types (object→function and scene→function), forming V-structures that model bidirectional scene-object relationships while accommodating uncommon layouts. Edges are established in real-time via CounterfactCoT, a prompting strategy that asks an LLM to compare a factual scenario (edge present) against a counterfactual scenario (edge absent) to jointly determine edge existence and conditional probability. Bayesian inference over the FBN computes the posterior probability of each function group given the target (Eq. 4), combining the target's prior function affinity with the observed scene/object evidence. These discrete probabilities are projected onto the 2D map via Gaussian kernels centered at each function group's coordinate, producing a continuous probability map from which the waypoint is selected (preferring frontier locations when unexplored regions remain). The entire pipeline is training-free, using YOLOv7 + Grounding-DINO + Mobile SAM for open-vocabulary perception and Llama-7B or GPT-4o for FBN edge reasoning.

## Results

On HM3D, FBN-GPT 4o achieves 58.8% SR and 31.2% SPL, outperforming all zero-shot open-vocabulary baselines (best prior: SG-Nav at 54.0% SR / 24.9% SPL). On MP3D, FBN-GPT 4o reaches 42.1% SR and 18.1% SPL, surpassing the previous best zero-shot method SG-Nav (40.2% SR / 16.0% SPL). The Llama-7B variant (FBN-Llama) also exceeds all prior zero-shot methods on both datasets (53.2% SR / 30.7% SPL on HM3D; 41.1% SR / 17.3% SPL on MP3D). On the open-vocabulary target evaluation (Table 5), FBN-GPT 4o achieves 38.7% SR and 22.6% SPL, beating VLFM (35.8% / 21.2%) and SG-Nav (33.1% / 18.9%).

## Baselines & Comparisons

Among zero-shot open-vocabulary methods (Section III), FBN-GPT 4o wins on both SR and SPL across both datasets: on HM3D it beats SG-Nav by +4.8 SR and +6.3 SPL, VLFM by +6.3 SR and +0.8 SPL, GAMap by +5.7 SR and +5.2 SPL, and VoroNav by +16.8 SR and +5.2 SPL. On MP3D, FBN-GPT 4o surpasses SG-Nav by +1.9 SR and +2.1 SPL, and VLFM by +5.7 SR and +0.6 SPL. The Llama-7B variant also outperforms all prior zero-shot baselines, confirming the method's robustness across LLM backbones. Against the strongest trained baseline SGM (60.2% SR on HM3D), FBN-GPT 4o trails by only 1.4 SR while matching its SPL (31.2 vs 30.8), and decisively beats the training-free SGM* variant (45.2% SR) by +13.6 SR. On the open-vocabulary target test (Table 5), FBN-GPT 4o leads VLFM by +2.9 SR and SG-Nav by +5.6 SR, while the adapted closed-set SGM† drops to 21.3% SR, highlighting the advantage of the function-centric reasoning over learned context relations.

## Relation to Prior Work

This paper departs from prior zero-shot ObjectNav methods that either rely on VLMs for semantic-visual similarity scoring (COW, GAMap, VLFM) or convert 3D environments into textual representations for LLM-based decision-making (SG-Nav, VoroNav, ESC). Instead of using the LLM as the sole navigator, FBN employs LLMs (via the CounterfactCoT prompting strategy adapted from CLADDER [15]) as an intermediary to establish probabilistic directed edges in a structured Bayesian network, with Bayesian inference then producing the goal probability map. The introduction of function groups as intermediate nodes creates V-structures (object → function ← scene) that replace the implicit bidirectional scene-object assumptions in prior scene-prior methods, allowing the model to represent uncommon layouts (e.g., a yoga mat in a bedroom) that violate standard scene-object co-occurrence priors.

## Why It Matters / Open Questions

The training-free, open-vocabulary setting makes FBN directly deployable in real-world scenarios without retraining for new target categories, addressing a key scalability limitation of supervised ObjectNav. The function-centric perspective, grounded in cognitive science (objects defined by intended use), offers an interpretable and structured alternative to black-box LLM reasoning for spatial inference. However, the method is constrained by a predefined set of 16 function groups and 6 scene types, relies on per-object LLM calls during navigation (3–8 calls each), and has only been validated on indoor residential scenes (MP3D, HM3D). Open questions include whether the function taxonomy generalizes to commercial or outdoor environments, how the approach scales to larger scenes with many objects, and whether the Bayesian framework can be extended to handle temporal dynamics or multi-agent settings.

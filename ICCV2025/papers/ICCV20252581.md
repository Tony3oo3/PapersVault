## Problem

Gloss-free sign language translation (SLT) must bridge the modality gap between visual sign components and spoken text without relying on labor-intensive gloss annotations. Existing gloss-free methods extract visual features directly from SL images, which are susceptible to irrelevant visual noise (background, clothing) and lack the textual representational format that LLMs process most effectively. No prior work has leveraged multimodal large language models (MLLMs) to convert SL images into descriptive text that complements the visual signal.
![Teaser figure](../imgs/ICCV20252581/cropped_page0_idx0.webp)

## Input / Output

The method takes a sign language video (sequence of T frames at H×W resolution) as input. During training, an off-the-shelf image-based MLLM (LLaVA-OneVision 7B) is applied per-frame with a carefully designed prompt to generate textual descriptions of SL components (hand shape, finger position, gaze, mouth shape). At inference, the MLLM is bypassed entirely: a lightweight description mapper predicts description embeddings directly from ResNet18 visual features. The output is an autoregressively generated spoken sentence produced by a 12-layer mBART decoder, trained with cross-entropy loss.

## Method

MMSLT comprises two modules. The GSD-MLLM module prompts an image-based MLLM to generate per-frame SL descriptions, which are encoded by a frozen 12-layer BERT into sentence-level [CLS] embeddings. The MMLP module then fuses these description embeddings with visual features via a modality adapter (1D convolution + max-pooling + 2-layer MLP), processes the fused sequence through an mBART encoder with LoRA for parameter-efficient adaptation, and aligns the resulting multimodal features with spoken-sentence embeddings using symmetric contrastive learning (InfoNCE with learnable temperature). A 2-layer MLP description mapper is trained with L2 loss to approximate BERT description embeddings from visual features, eliminating the need for the MLLM at inference. The final SLT stage fine-tunes the visual encoder, modality adapter, and multimodal encoder while an mBART decoder generates translations autoregressively.

## Results

On PHOENIX14T (test set), MMSLT achieves BLEU-4 of 25.73 and ROUGE of 47.97, setting a new SOTA for gloss-free SLT with a +2.33 BLEU-4 improvement over the previous best (SignLLM, 23.40). On the large-scale CSL-Daily dataset, MMSLT achieves BLEU-4 of 21.11 and ROUGE of 48.92, surpassing the previous gloss-free SOTA (Sign2GPT) by +5.36 BLEU-4 and +6.56 ROUGE, and even outperforming the weakly supervised VAP model (BLEU-4=20.85, ROUGE=48.56). MMSLT also achieves competitive performance relative to gloss-based methods, reaching within ~3 BLEU-4 of the best gloss-based model (TS-SLT) on PHOENIX14T.

## Baselines & Comparisons

MMSLT outperforms all 17 compared baselines across both datasets. On PHOENIX14T, it surpasses the previous gloss-free SOTA SignLLM [18] by +2.33 BLEU-4 (25.73 vs. 23.40) and +3.48 ROUGE (47.97 vs. 44.49), and beats Sign2GPT [57] by +3.21 BLEU-4. On CSL-Daily, the margin is even larger: MMSLT exceeds Sign2GPT by +5.36 BLEU-4 (21.11 vs. 15.40) and SignLLM by +5.36 BLEU-4 (21.11 vs. 15.75). Notably, MMSLT also outperforms the weakly supervised VAP [27] on CSL-Daily (BLEU-4: 21.11 vs. 20.85; ROUGE: 48.92 vs. 48.56), despite VAP using gloss annotations for pre-training. Against gloss-based methods, MMSLT remains competitive, achieving within ~3.2 BLEU-4 of the best gloss-based model (TS-SLT, 28.95) on PHOENIX14T without requiring any gloss supervision.

## Relation to Prior Work

This paper extends the gloss-free SLT line of work (GFSLT-VLP, SignLLM, Sign2GPT) by introducing a fundamentally different input representation: instead of relying solely on visual features extracted from SL images, it generates textual descriptions of SL components using an off-the-shelf MLLM (LLaVA-OneVision) and integrates both modalities through a multimodal-language pre-training module. The contrastive alignment strategy follows GFSLT-VLP and VAP, while the use of LoRA on an mBART encoder and the autoregressive mBART decoder for translation are consistent with recent LLM-based SLT approaches. The key departure is the description mapper—a two-layer MLP that distills MLLM-generated description embeddings from visual features, enabling inference without the computationally expensive MLLM, which no prior SLT work has attempted.

## Why It Matters / Open Questions

This work demonstrates that MLLMs can serve as effective feature extractors for SLT, opening a path toward leveraging increasingly capable multimodal models without requiring task-specific training. The description mapper is a practical contribution that decouples the expensive MLLM from inference, making the approach deployable. However, the paper acknowledges that MLLMs still struggle with fine-grained facial features (eyebrow shape, lip configuration), which are critical in sign language, suggesting that the current approach captures only a subset of SL components. Open questions include whether the description mapper generalizes across sign languages and signer populations, and whether the approach benefits from even larger or more specialized MLLMs.

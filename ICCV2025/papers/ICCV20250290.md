## Problem

Existing text-guided zero-shot object counting methods only fuse local patch-level features with a single text prompt, discarding the global image-level feature from the vision encoder. This oversight limits both localization (insufficient foreground-background discrimination in patch-text similarity scores) and counting (the single class-name prompt carries no numeric information, which is absent from VLM pre-training data).
![Teaser figure](../imgs/ICCV20250290/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image and a text prompt naming the target class. During training, the class name is expanded into multiple number-conditioned prompts (e.g., 'There are between 10 and 20 cars') at two granularity levels. The vision encoder produces both local patch-level features and a global image-level feature (CLS token for CLIP ViT-B/16, or average-pooled Swin-T features for GroundingDino). The output is a density map whose pixel sum yields the predicted object count, evaluated via MAE and RMSE.

## Method

The proposed universal strategy has two complementary components. Text-guided Local Ranking (TLR) introduces a local-text rank loss that, for every foreground-background patch pair, enforces a margin on the cosine similarity difference with the text embedding, pushing foreground and background patch features apart to improve VLM localization. Number-evoked Global Attention (NGA) exploits the previously ignored global image-level feature by aligning it with a hierarchy of number-conditioned text prompts through a coarse-to-fine scheme: five coarse number ranges are first scored via a contrastive similarity loss, the best range is subdivided into five finer ranges, and the highest-similarity fine prompt is selected to compute cross-attention with the global feature. The resulting cross-attended feature is added element-wise to the local patch features before feeding the density decoder. The strategy is backbone-agnostic, demonstrated with both CLIP (ViT-B/16 + VPT) and GroundingDino (Swin-T + BERT) backbones.

## Results

On FSC-147, the proposed strategy applied to GroundingDino achieves the best validation MAE of 11.09 and RMSE of 60.48, while on the test set it reaches MAE 10.74 and RMSE 106.5. On the newly introduced ZSC-8K dataset, GDino+Ours attains MAE 11.17 / RMSE 17.30 (val), MAE 12.39 / RMSE 27.75 (test normal), and MAE 14.68 / RMSE 38.10 (test longtail), outperforming the previous best by 19.8% MAE on validation and 10.1% on test normal. In cross-dataset evaluation on ShanghaiTech, ClipCount+Ours achieves MAE 176.24 and RMSE 279.20, surpassing both category-specific and generic baselines without any crowd-specific training.

## Baselines & Comparisons

The proposed strategy is applied to three backbones (CLIP, GroundingDino) and consistently outperforms all 14 baselines. On FSC-147, GDino+Ours achieves the lowest validation MAE (11.09), beating the previous best CountGD (12.14) by 0.52 and GDino finetuned (12.07) by 0.98; on the test set it reaches MAE 10.74, surpassing GroundingREC (11.27) and GDino (11.76). The CLIP-based variant (ClipCount+Ours) reduces validation RMSE from 66.10 to 58.39 (−7.71) and test RMSE from 104.88 to 100.63 (−4.25) relative to ClipCount. On the new ZSC-8K benchmark, GDino+Ours cuts validation MAE from 13.92 (GDino) to 11.17 (−2.75) and test-normal MAE from 14.23 to 12.39 (−1.84). In cross-dataset evaluation on ShanghaiTech, ClipCount+Ours (MAE 176.24) outperforms category-specific methods MCNN (221.4) and CrowdClip (217.0) by 45.2 and 40.8 MAE respectively, and beats the prior best generic method ClipCount (192.6) by 16.4 MAE. The only minor regression is GDino+Ours on FSC-147 test RMSE (106.5 vs. 104.98 for GDino alone, +1.52), while all other metrics improve across every backbone and dataset.

## Relation to Prior Work

This paper extends the text-guided zero-shot object counting (ZSC) line initiated by Xu et al. [49] and advanced by ClipCount [18], VLCounter [20], and GroundingREC [8]. The key conceptual departure is that all prior ZSC methods exclusively fuse local patch-level features with text features while discarding the global image-level feature (e.g., CLIP's cls_token or Swin-T's pooled output); this paper argues that omission is a fundamental limitation and introduces a universal two-part strategy—Text-guided Local Ranking (a pairwise ranking loss on patch-text similarities) and Number-evoked Global Attention (cross-attention between the global feature and number-conditioned prompts)—that can be grafted onto any VLM backbone. The introduced ZSC-8K benchmark also departs from FSC-147 by rebalancing class frequencies and explicitly separating long-tailed evaluation.

## Why It Matters / Open Questions

The ZSC-8K dataset (8,361 images, 114 categories, with dedicated long-tail test split) addresses a real gap in evaluation: FSC-147's unrealistic long-tail distribution and small size have limited the field's ability to measure generalization. The backbone-agnostic strategy (validated on both CLIP and GroundingDino) offers a drop-in improvement for existing ZSC pipelines. However, the paper itself highlights that a substantial performance gap persists on long-tailed classes across all ZSC methods, pointing to an open problem in how VLMs handle rare or visually diverse categories. Future work may need to address whether number-conditioned prompting can be made more fine-grained or whether the global feature carries sufficient class-specific information for truly unseen categories.

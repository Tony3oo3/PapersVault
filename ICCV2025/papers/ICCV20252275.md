## Problem

Articulation prediction for 3D shapes is bottlenecked by the scarcity of annotated training data—PartNet-Mobility contains only a few thousand shapes with full articulation parameters—and by architectures that require fixed kinematic hierarchies or category labels, limiting generalizability to novel object categories and complex part structures. The paper asks whether a model can be pretrained on unlabeled segmented shapes using purely geometric criteria to discover physically valid articulations, thereby reducing dependence on manual annotation.
![Teaser figure](../imgs/ICCV20252275/cropped_page0_idx0.webp)

## Input / Output

The method takes a 3D point cloud presegmented into an arbitrary number of parts (with or without semantic labels), normalized to unit bounding-box scale with centroid at origin and consistent upright orientation; no prescribed kinematic graph or category constraint is imposed. For each part it outputs a binary motion-type vector (revolute, prismatic, both, or fixed), a unit-length 3D motion axis direction, and a 3D pivot point (used only for revolute or cylindrical motion). The pivot is decoded via a per-point voting strategy rather than direct regression, and the axis is normalized post-decoding.

## Method

GEOPARD is a transformer that builds part representations by encoding each point with Fourier positional features, concatenating part bounding-box and PointBERT (or semantic label) embeddings, and compressing the result through cross-attention with a shared set of 256 learnable queries; a parallel shape-context branch is built analogously and injected into part features via cross-attention plus self-attention. A single learnable articulation query then collapses the context-aware part set into one compact vector, which feeds three dedicated decoder branches for pivot (per-point displacement voting), axis (FC + normalization), and motion type (FC + sigmoid). The key training innovation is a geometric pretraining stage: candidate axes are extracted via PCA on part points, candidate pivots from bounding-box vertices and centroid, and each candidate articulation is validated by simulating motion up to a range threshold while checking for collision (via EPA) and detachment, yielding a set of physically plausible motions used as self-supervision on unlabeled segmented shapes before supervised fine-tuning on PartNet-Mobility.

## Results

On PartNet-Mobility (46 categories, 274 test shapes), GEOPARD achieves an Axis Error (AE) of 8.87° and Pivot Error (PE) of 0.06 in the labeled condition, outperforming CAGE (AE 11.41°, PE 0.09) and SINGAPO (AE 12.15°, PE 0.10). In the unlabeled condition, GEOPARD-u reduces AE to 9.18° and PE to 0.05, while also improving motion-type accuracy (R-ACC 0.92, P-ACC 0.93) over CAGE-u (0.89/0.89) and SINGAPO-u (0.90/0.91). The Articulated Distance (AD) metric, measuring Chamfer distance across sampled motion states, drops to 0.06 (labeled) and 0.09 (unlabeled), a 14% improvement over both baselines.

## Baselines & Comparisons

GEOPARD outperforms both CAGE and SINGAPO across all five metrics in both labeled and unlabeled conditions. In the labeled setting, GEOPARD reduces Axis Error by 22% relative to CAGE (8.87° vs. 11.41°) and by 27% relative to SINGAPO (8.87° vs. 12.15°), while Pivot Error improves by 33% over CAGE and 40% over SINGAPO. Motion-type accuracy (R-ACC, P-ACC) is comparable across all methods in the labeled condition (~0.97–0.98), which is expected given that semantic labels directly inform the motion classification. In the unlabeled condition, where baselines must rely on PointBERT embeddings instead of part labels, GEOPARD-u's advantage widens: it achieves 0.92/0.93 R-ACC/P-ACC versus 0.89/0.89 for CAGE-u and 0.90/0.91 for SINGAPO-u, and reduces Articulated Distance from 0.13 (CAGE-u) and 0.11 (SINGAPO-u) to 0.09, indicating more physically consistent articulated motion predictions.

## Relation to Prior Work

GEOPARD repurposes the learnable-query mechanism from DETR and Set Transformers—originally designed for object detection and permutation-invariant set processing—into a compact articulation-aware part representation for 3D shapes. It departs from prior single-state articulation methods (CAGE, SINGAPO, CAPT) that rely on semantic part labels or category-level priors by introducing a geometric self-supervised pretraining stage that discovers physically valid candidate articulations via PCA-based axis search and EPA collision/detachment checking, eliminating the need for manual articulation annotations during pretraining. The use of PointBERT self-supervised embeddings for unlabeled part representations connects the work to the broader 3D shape understanding literature, while the overall pipeline (pretrain on unlabeled shapes → fine-tune on PartNet-Mobility) positions GEOPARD as a label-efficient alternative to fully supervised articulation estimation.

## Why It Matters / Open Questions

The geometric pretraining strategy offers a practical, annotation-free way to bootstrap articulation models, directly addressing the data-scarcity bottleneck that limits generalizability to novel object categories and kinematic hierarchies. However, the approach still requires pre-segmented parts (labeled or unlabeled), and the geometric search does not guarantee recovery of all true articulations—fine-tuning can sometimes lock onto pretraining candidates rather than ground-truth motions. An important open question is whether part segmentation itself can be learned in a zero-shot or self-supervised manner, which would remove the remaining input assumption and make the pipeline fully end-to-end from raw geometry.

## Problem

Lifting 2D segmentation to 3D in Gaussian Splatting suffers from two intertwined issues: off-the-shelf predictors like SAM produce inconsistent masks across viewpoints (varying abstraction levels for the same object), and existing methods treat the learned Gaussians as fixed, leaving ambiguous Gaussians at object boundaries that cause segmentation artifacts. Prior work either ignores multi-view mask inconsistencies or handles boundary Gaussians only as a post-processing step, resulting in noisy boundaries and lost detail.
![Teaser figure](../imgs/ICCV20250784/cropped_page0_idx0.webp)

## Input / Output

The method consumes a set of multi-view RGB images with known camera parameters and either SAM-generated binary masks (contrastive lifting) or user point prompts on a single reference view (self-prompting). It operates on 2DGS oriented planar Gaussian disks rather than standard 3DGS, and produces both per-object 3D Gaussian sets (extractable as clean 3D assets) and rendered 2D instance segmentation masks on arbitrary novel views. The consistent 2D instance maps are maintained at the patch level (disjoint overlapping regions) rather than as raw binary masks, enabling hierarchical and multi-object segmentation.

## Method

The core contribution is Gaussian Instance Tracing (GIT), a reverse-rasterization operation that assigns each Gaussian a weight matrix W ∈ R^{T×L} encoding its probability of belonging to each instance patch in every input view, computed in parallel with forward rendering. GIT enables two key mechanisms: (1) consistent 2D instance maps, where patches from different views are merged via majority vote over co-visible Gaussians' instance distributions (similarity threshold θ=0.5), and (2) GIT-guided adaptive density control, which detects ambiguous Gaussians (those whose max instance probability falls below γ=0.8 in more than half their visible views) and iteratively splits them (halving scale, resampling positions) or prunes them every 1000 iterations during retraining. This unified framework supports both offline contrastive lifting (training 16-dim feature vectors with a slow-fast contrastive loss) and online self-prompting (iteratively extracting point prompts on novel views via GIT), outperforming all NeRF- and GS-based baselines on Replica and NVOS.

## Results

On Replica 3D object extraction, Trace3D achieves 72.1 mean mIoU and 22.6 PSNR, substantially outperforming the strongest baseline Egolifter (55.6 mIoU, 20.1 PSNR) by 16.5 mIoU. On novel-view 2D instance segmentation (Replica), the method reaches 85.5 mean mIoU, surpassing all NeRF-based baselines (OmniSeg3D: 84.4, SA3D: 83.0) and GS-based baselines (Egolifter: 82.1, SA3D-GS: 79.1) for the first time among Gaussian Splatting methods. On NVOS, Trace3D achieves 92.5 mIoU and 98.6 mAcc, matching GaussianCut on mIoU while tying FlashSplat on mAcc.

## Baselines & Comparisons

Trace3D outperforms all 10 baselines across the evaluated benchmarks. On 3D object extraction (Replica), the method achieves 72.1 mIoU vs. Egolifter's 55.6, FlashSplat's 39.3, and GaussianGrouping's 29.6, with the largest gap (42.5 mIoU) over GaussianGrouping. On novel-view 2D segmentation (Replica), Trace3D (85.5 mIoU) beats the best NeRF-based method OmniSeg3D (84.4) by 1.1 points and the best GS-based method Egolifter (82.1) by 3.4 points, while dominating MVSeg (32.4) by a wide margin. On NVOS, Trace3D ties GaussianCut at 92.5 mIoU but edges it out on mAcc (98.6 vs. 98.4), and surpasses FlashSplat (91.8 mIoU) and SA3D (90.3 mIoU). The consistent 2D instance maps and GIT-guided density control are the key differentiators, reducing false positives at object boundaries that plague all baselines, particularly visible in the PCA feature maps where competing methods show confused boundary features.

## Relation to Prior Work

This paper builds on the 2DGS oriented planar Gaussian representation and the contrastive lifting framework from Bhalgat et al. (NeurIPS 2023), extending both to address multi-view mask inconsistency and ambiguous Gaussian boundaries. It departs from prior Gaussian-based segmentation methods (GaussianGrouping, FlashSplat, Egolifter, SA3D-GS) that either ignore ambiguous Gaussians or filter them post-hoc, instead proposing GIT—a reverse-rasterization-based instance weight matrix that unifies multi-view consistency and guides adaptive density control during training. Unlike GaussianEditor's use of reverse rendering for semantic editing, Trace3D maintains a global per-Gaussian instance weight across all input views, enabling majority-vote mask merging and principled splitting/pruning of boundary Gaussians.

## Why It Matters / Open Questions

By producing artifact-free 3D Gaussian assets rather than merely rendered masks, Trace3D enables practical downstream applications (object extraction, hierarchical segmentation, scene editing) that prior methods could not support cleanly. The first GS-based method to outperform NeRF-based approaches on novel-view instance segmentation (85.5 vs 84.4 mIoU on Replica) validates that explicit Gaussian representations can match implicit ones for segmentation when properly regularized. Open questions remain: self-prompting still underperforms contrastive lifting on structured scenes, and contrastive lifting struggles with tiny or texture-like objects, suggesting a gap between the two paradigms that future work should bridge. The method's reliance on SAM's initial masks also inherits their limitations in open-world or highly occluded settings.

## Problem

Existing interactive segmentation methods require the same number of user interactions for every image in a dataset, making total annotation effort scale linearly with dataset size. In-context segmentation methods can leverage previously labeled examples but either require large pre-existing context sets or lack a mechanism for user corrections. The paper addresses how to progressively reduce the user interaction burden as more images from the same task are segmented, without any retraining.
![Teaser figure](../imgs/ICCV20250713/cropped_page0_idx0.webp)

## Input / Output

The model takes a 5-channel target input (the image plus up to four interaction channels: positive/negative scribbles/clicks as intensity masks, bounding boxes, and an optional previous prediction) along with a variable-size context set of image-segmentation pairs (0 to 64 examples). The output is a binary segmentation mask at the same spatial resolution as the input. The model is trained at 128² resolution and evaluated at 256²; interactions are simulated as center clicks or centerline scribbles during evaluation.

## Method

MultiverSeg uses a UNet-like encoder-decoder where every convolutional block is replaced by a CrossBlock that cross-convolves target-image features with context-set features at each scale, followed by LayerNorm and separate convolutions to update both target and context representations. For the first image (empty context), the system falls back to the pre-trained ScribblePrompt-UNet; for subsequent images, the CrossBlock architecture conditions on the growing context set of previously segmented image-mask pairs. Training samples random tasks, random context sizes (0–64), and simulates k=3 steps of interactive segmentation with prompt simulation (initial positive/negative interactions followed by corrections sampled from the error region). The loss is a sum of soft Dice and Focal Loss (γ=20) applied at each interaction step. A key design choice is the use of synthetic tasks (superpixel-derived labels on duplicated and aggressively augmented images) with probability 0.5 to improve generalization across the 79 biomedical datasets used for training.

## Results

On 12 held-out biomedical datasets (187 tasks, 8 modalities), MultiverSeg reduces the total number of user interactions needed to reach 90% Dice by 36.41±1.33% (clicks) and 25.26±1.80% (scribble steps) compared to ScribblePrompt, the strongest interactive segmentation baseline. The reduction grows as the context set expands: by the 18th image, MultiverSeg requires substantially fewer interactions per image than any baseline. As a supervised upper bound, task-specific nnUNet models achieve 88.67±0.47 Dice on the same test data, justifying the 90% target. MedSAM, the weakest baseline, reaches only 65.93±4.82 average Dice and fails to reach 90% Dice on 94.4% of examples.

## Baselines & Comparisons

MultiverSeg outperforms all interactive segmentation baselines (ScribblePrompt, SAM, SegNext, SAM-Med2D, IMIS-Net, MedSAM) on the primary metric of total interactions to reach 90% Dice, with the largest gap against ScribblePrompt (36% fewer clicks, 25% fewer scribble steps). Against the in-context baseline UniverSeg, MultiverSeg achieves higher Dice across all context set sizes (Fig. 6), attributed to training on more datasets (67 vs. 53) and larger CrossBlock features (256 vs. 64 channels). The combined SP+UVS baseline (UniverSeg prediction refined by ScribblePrompt) also benefits from context but still requires more interactions than MultiverSeg, and performs poorly for context sets smaller than 5 examples. MedSAM is the weakest baseline, reaching 90% Dice on only 5.6% of examples with an average Dice of 65.93. Bootstrapping UniverSeg (sequentially adding its own predictions to the context) fails entirely, yielding only 48.89 Dice, confirming that in-context models without a correction mechanism cannot reliably segment new datasets. Task-specific fine-tuning of ScribblePrompt (20 min on A100 per task) also underperforms MultiverSeg, which requires no retraining and runs in <0.15 s per inference.

## Relation to Prior Work

MultiverSeg unifies two previously separate lines of work: interactive segmentation (ScribblePrompt, SAM, MedSAM) and in-context segmentation (UniverSeg, OnePrompt, LabelAnything). Prior interactive methods treat each image independently, requiring the same user effort per image, while prior in-context methods accept labeled examples but lack a mechanism for user correction. The architecture adapts UniverSeg's CrossBlock mechanism to a UNet encoder-decoder with additional LayerNorm layers and higher feature dimensions, and the training procedure extends ScribblePrompt's prompt simulation to jointly optimize over variable-size context sets. The paper positions itself as the first model to perform interactive segmentation *in context*, where the context set grows organically as the user completes segmentations.

## Why It Matters / Open Questions

The practical impact is significant for biomedical researchers who must segment new datasets without prior labeled data: a 36% reduction in clicks and 25% reduction in scribble steps across 161 unseen tasks means substantially less expert annotation time. A key limitation is that performance degrades when context images vary substantially in composition, and the paper does not address how to prioritize which images to segment first (an active-learning question it explicitly flags for future work). The negative result that bootstrapping UniverSeg from a single example yields only ~49% Dice underscores that in-context models without correction mechanisms are insufficient for real annotation workflows, reinforcing the value of the combined interactive + in-context formulation.

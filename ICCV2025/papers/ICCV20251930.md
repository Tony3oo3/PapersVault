## Problem

Existing document forgery localization methods either rely solely on RGB traces (lacking sensitivity to subtle tampering) or fuse DCT features statically, making them severely vulnerable to post-processing operations like resizing and cropping that disrupt 8×8 DCT block alignment. Additionally, the strong intensity contrast between text and uniform background in document images creates a text-BG feature bias that obscures subtle tampering cues, degrading localization accuracy.

## Input / Output

The model takes a JPEG image as input, from which it extracts the Y-channel 8×8 block DCT coefficients and the JPEG quantization table as auxiliary inputs alongside the RGB channels. An OCR model (CRAFT) is also applied to the input to produce a binary background mask used by the PPE module. The output is a binary forgery localization mask at the same spatial resolution as the input image, with the reconstruction decoder discarded at inference time.

## Method

ADCD-Net adopts a U-shaped architecture with a dual-branch encoder (Restormer for RGB, FPH for DCT) where DCT features are adaptively modulated by a learned alignment score predicted via a classification head, effectively implementing a Mixture-of-Experts routing that downweights DCT contributions when block alignment is disrupted. A Hierarchical Content Decoupling module uses per-scale MLPs to split fused features into content and forgery streams, enforced by a reconstruction loss that requires recovering both the RGB image and DCT coefficients from the content stream (with spatially shuffled forgery features to prevent shortcuts). A Pristine Prototype Estimation module computes a prototype from OCR-identified background pixels in the forgery feature space and modulates the penultimate features via cosine-similarity-based scaling and biasing. Training is end-to-end with four losses: alignment score cross-entropy, L1 reconstruction, forgery localization (CE + Lovász), and a multi-scale within-image SupCon contrastive loss to amplify pristine-forged feature separation.

## Results

On the DocTamper-based evaluation (Table 1), ACDC-Net achieves an average F1 of 0.787 across three cross-domain test sets (Test, FCD, SCD), outperforming the second-best PS-Net (0.785) and DTD (0.778) while using the fewest parameters (23M vs. 66M for DTD and 143M for MVSS-Net). Under robustness evaluation with five distortion types (noise, blur, downscale, JPEG, multi-JPEG), ACDC-Net outperforms the second-best method (TruFor) by an average of 20.79% in F1. On 1,000 pristine document images, ACDC-Net achieves the lowest false alarm rate (1.2%) while maintaining the highest F1 (0.808).

## Baselines & Comparisons

ACDC-Net outperforms all eight baselines on average F1 in Table 1, with the closest competitor being PS-Net (0.785 vs. 0.787, a 0.2% margin) and DTD (0.778, a 0.9% margin). Against DTD specifically, the advantage is most pronounced under DCT block misalignment: DTD's F1 drops by 67.95–73.34% with cropping, pixel shifting, or 2% resizing, whereas ACDC-Net's decline is only 22.66–25.74% (Fig. 5). TruFor, the strongest RGB-only baseline, is outperformed by 20.79% on average across five distortion types in the robustness evaluation (Fig. 4), though TruFor remains competitive under clean conditions. CAT-Net and MVSS-Net, both DCT-based general-image methods, trail ACDC-Net by 7.5% and 36.4% in average F1 respectively, confirming that document-specific design is critical. On pristine images (Table 2), ACDC-Net achieves the lowest false alarm rate (1.2%) compared to TruFor (2.7%), MA-Net (2.9%), and DTD (5.8%), indicating fewer spurious detections on untampered documents.

## Relation to Prior Work

This paper builds directly on DTD [27], which first fused RGB and DCT-domain features for document forgery localization, and on RGB-only detectors like TruFor [12] and FOCAL [40] that are robust but less accurate. The key departure is replacing DTD's static RGB-DCT concatenation with an MoE-inspired adaptive scoring mechanism that dynamically modulates DCT feature contribution based on predicted block alignment, drawing on the gating principle from mixture-of-experts literature [13, 32]. Additionally, the Hierarchical Content Decoupling module extends content disentanglement techniques originally developed for face forgery detection [17, 20, 23, 42] to the multi-scale, multi-modal setting of document images, while the Pristine Prototype Estimation leverages the domain-specific observation that document backgrounds are predominantly untampered.

## Why It Matters / Open Questions

The paper addresses a practically critical gap: existing DCT-based document forgery detectors (notably DTD) suffer catastrophic 67–95% F1 drops under minor alignment disruptions like 2% cropping or 1-pixel shifting, rendering them unreliable in real-world pipelines where images routinely undergo resizing and cropping. The 20.79% average F1 improvement over SOTA across five distortion types, achieved with only 23M parameters (the smallest in the comparison), suggests a more deployable solution for document security applications. Open questions include whether the adaptive forensic-trace gating generalizes beyond DCT to other frequency-domain cues (LoG, SRM, Bayar), whether the HCD module transfers to other structured-image domains (e.g., satellite imagery, medical scans), and how performance holds under adversarial or generative-model-based forgeries that may not leave traditional compression artifacts.

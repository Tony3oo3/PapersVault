## Problem

Class-generalizable few-shot anomaly segmentation (FSAS) requires a unified model to detect anomalies in unseen object categories using only a few normal reference images, without retraining on target data. Existing VLM-based approaches (e.g., WinCLIP, APRIL-GAN) rely on empirical knowledge memorized from seen anomaly samples during auxiliary training, which constrains their ability to generalize to truly novel classes. The paper asks whether a model can learn a transferable, feature-agnostic anomaly detection capability analogous to how a novice human inspector identifies defects by checking whether a region 'looks like' anything in a reference set.

## Input / Output

At inference, DictAS takes a query RGB image (resized to 336×336) and k≥1 normal reference images from the same unseen class, all processed through a frozen CLIP ViT-L-14-336 encoder to extract patch-level features from layers 6, 12, 18, and 24. The output is a pixel-level anomaly segmentation map at the original input resolution, obtained by upsampling the aggregated cosine distance between query features and their dictionary-retrieved counterparts across all four layers. During self-supervised training, reference images are synthesized via geometric transformations and occlusion augmentations (k=1 for efficiency), and query images are created by anomaly synthesis on the same raw image, eliminating the need for pixel-level annotations.

## Method

DictAS reformulates anomaly segmentation as a dictionary lookup task: normal reference features form a dictionary (Key for indexing, Value for content), and a query patch is classified as anomalous if it cannot be well retrieved from the dictionary. Three components implement this: (1) Dictionary Construction uses self-attention-based AttnBlocks as Key, Value, and Query generators to transform CLIP patch features into structured dictionary representations; (2) Dictionary Lookup computes Query-Key similarity and applies a Sparse Probability Module (adapted from sparsemax) to produce sparse retrieval weights that emphasize the most relevant Dictionary Value while suppressing redundancy as reference count grows; (3) Query Discrimination Regularization adds two constraints—Contrastive Query Constraint (enforcing larger query-retrieval distance for abnormal vs. normal patches) and Text Alignment Constraint (aligning global retrieved features with CLIP's normal-text embedding space)—to prevent the model from over-retrieving anomalous content. The entire framework is trained self-supervised on pixel-annotation-free images from seen classes, with the total loss combining the query retrieval loss, CQC, and TAC, enabling class-generalizable inference without any fine-tuning on target data.

## Results

Under the 4-shot setting, DictAS achieves average pixel-level AUROC/PRO/AP of 98.4/92.2/52.5 on five industrial datasets and 97.4/83.4/67.1 on two medical datasets, outperforming the best class-generalizable baseline (FastRecon+) by 1.4%/3.4%/7.4% (industrial) and 1.4%/5.1%/10.9% (medical) in AP. Compared to the overall suboptimal method (PromptAD, which is class-dependent and requires per-class fine-tuning), DictAS improves AUROC, PRO, and AP by 1.3%, 2.6%, and 5.5% on industrial datasets, and by 0.7%, 1.2%, and 4.2% on medical datasets. DictAS also achieves the fastest inference speed (73.5 ms/image) with the lowest standard deviation (±0.4 AP) among all compared methods.

## Baselines & Comparisons

DictAS outperforms all six baselines on every dataset and every metric (AUROC, PRO, AP) under the 4-shot setting. Among class-generalizable methods, the closest competitor is FastRecon+ (CLIP variant), which trails DictAS by 1.4% AUROC, 3.4% PRO, and 7.4% AP on average across industrial datasets; WinCLIP and APRIL-GAN lag further behind (e.g., WinCLIP achieves only 39.2 AP on MVTecAD vs. DictAS's 66.8). RegAD and AnomalyGPT, while competitive on AUROC, show substantially lower AP (28.3 and 38.6 industrial average, respectively), indicating weaker pixel-level localization. The strongest overall baseline is PromptAD (97.1/89.6/47.0 industrial average), but it is class-dependent—requiring a separate fine-tuned model per unseen class—whereas DictAS uses a single unified model. Notably, DictAS's advantage grows with more reference images (e.g., 16-shot AP of 68.5 vs. 63.8 for Dense Lookup), while WinCLIP shows instability or even degradation at higher shots on some datasets (e.g., BraTS).

## Relation to Prior Work

DictAS positions itself within the class-generalizable few-shot anomaly segmentation (FSAS) line of work, departing from prior CLIP-based methods (WinCLIP, APRIL-GAN, AnomalyGPT) that rely on memory-bank visual priors or text-image alignment knowledge learned from seen anomaly samples. Its key conceptual departure is reformulating anomaly segmentation as a dictionary lookup problem—where a query patch is anomalous if it cannot be retrieved from a dictionary built from normal reference features—rather than as a reconstruction or alignment task. Technically, the Sparse Probability Module is adapted from the sparsemax formulation of Martins & Astudillo (ICML 2016), repurposed here to sparsify retrieval weights across dictionary entries. The self-supervised training paradigm (using anomaly synthesis and data augmentation to generate query-reference pairs without pixel labels) distinguishes it from both class-dependent fine-tuning methods and prior class-generalizable approaches that require auxiliary anomaly annotations.

## Why It Matters / Open Questions

DictAS demonstrates that a unified, self-supervised model can outperform class-dependent methods (which require per-class fine-tuning) on seven industrial and medical datasets while achieving the fastest inference speed among compared methods, making it practically attractive for dynamic industrial settings with frequent product changes. The dictionary lookup framing offers an interpretable mechanism for anomaly detection and a natural extension point (e.g., hierarchical dictionaries, multi-modal dictionaries). Open questions include how the approach handles truly out-of-distribution categories far from the auxiliary training domain, whether the reliance on CLIP's frozen features limits ceiling performance, and whether the anomaly synthesis step (DR/EM) for generating training pairs can be further simplified. The 1-shot setting remains challenging, and the method's behavior on 3D or video anomalies is unexplored.

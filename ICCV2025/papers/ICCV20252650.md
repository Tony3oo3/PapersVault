## Problem

Adapting large-scale pre-trained VLMs like CLIP to unlabeled target domains faces two inherent limitations: Unsupervised Fine-Tuning (UFT) struggles when initial zero-shot performance is poor, while Unsupervised Domain Adaptation (UDA) can suffer negative transfer from inappropriate predefined source domains. The paper asks how to adaptively construct suitable auxiliary data from large-scale image-text pairs without any human annotations to overcome both limitations simultaneously.
![Teaser figure](../imgs/ICCV20252650/cropped_page0_idx0.webp)

## Input / Output

The method takes unlabeled target domain images and a set of class names (text) as input, and produces class labels for target images. Auxiliary data is retrieved from LAION-400M using CLIP ViT-B/32 embeddings via pre-built 16GB KNN indices, with up to 100 samples per category per α level (345 categories × 100 for DomainNet). The adapted model uses ViT-B/16 with LoRA (rank=8) on both image and text encoders, and training runs for 7,500 iterations with batch size 16, partitioned into three equal steps corresponding to different auxiliary data distributions.

## Method

Progressive Distribution Bridging (PDB) decomposes adaptation into sequential steps by constructing auxiliary data whose distribution progressively transitions from pre-training style to target style. A cascaded semantic filter pipeline (T2T retrieval → concept matching threshold → GMM clustering) ensures category-specific retrieval that handles visually similar and hard categories. A style controller blends the text concept prototype g(t_j) with the target image prototype u_j via a coefficient α ∈ {0.1, 0.4, 0.7}, where α controls how much domain-specific style is injected into the retrieval query. Training proceeds in three sequential steps (one per α value), each combining GCE loss on pseudo-labeled auxiliary data with a CM-IDCo contrastive loss on target domain images using a teacher-student architecture, requiring no human annotations and simpler losses than existing UDA methods.

## Results

On Office-Home, PDB achieves 87.8% average accuracy without any human annotations, surpassing the best UDA method DAMP (87.1%) and the best UFT method POUF-FT (86.1%). On VisDA, PDB reaches 91.7% class-wise accuracy, outperforming all UDA baselines (best: DAMP at 90.9%). On the most challenging DomainNet benchmark, PDB achieves 63.1% average accuracy, comparable to UDA methods (PADCLIP: 63.7%) while requiring no labeled source data, and notably improves over POUF-FT by 4.0% on the Quickdraw domain where initial CLIP performance is only 13.7%.

## Baselines & Comparisons

PDB outperforms all UFT baselines across every benchmark: it beats POUF-FT by 2.1% on Office-Home (87.8 vs 86.1), 1.2% on VisDA (91.7 vs 90.5), and 1.8% on DomainNet (63.1 vs 61.3), with the largest margin of 4.0% on DomainNet→Quickdraw where CLIP's zero-shot accuracy is only 13.7%. Against UDA methods that require labeled source domains, PDB surpasses the SOTA DAMP by 0.7% on Office-Home (87.8 vs 87.1) and by 0.8% on VisDA (91.7 vs 90.9), while using no human annotations at all. On DomainNet, PDB (63.1%) is slightly below PADCLIP (63.7%) and UniMoS (63.6%), but these UDA methods rely on 34,500–69,400 labeled source samples per task, whereas PDB uses only 34,500 annotation-free retrieved samples. PDB also consistently outperforms DAPrompt and AD-CLIP by 3–4% on Office-Home and Mini-DomainNet. The key differentiator is universality: PDB avoids the negative transfer problem where unsuitable UDA source domains degrade performance (e.g., UDA-SO drops to 13.61% on DomainNet→Quickdraw vs PDB's 22.82%).

## Relation to Prior Work

This paper positions itself as a unifying response to two established paradigms for adapting CLIP to unlabeled target domains: Unsupervised Fine-Tuning (UFT, e.g., POUF, ReCLIP) which relies solely on target data, and Unsupervised Domain Adaptation (UDA, e.g., DAPrompt, PADCLIP, DAMP) which requires a labeled source domain. It builds directly on CLIP's joint embedding space, SHOT's soft-weighted image prototype construction, the CM-IDCo contrastive loss from Zhang et al. (2023), and concept matching from Ming et al. (2022) as a filtering primitive. The key departure is the proposal to replace the fixed, potentially mismatched source domain in UDA with adaptively retrieved and progressively styled auxiliary data from LAION-400M, eliminating the annotation requirement while avoiding UFT's poor-initialization problem.

## Why It Matters / Open Questions

The practical significance lies in offering a single, annotation-free pipeline that outperforms both UFT and labeled-source UDA methods on Office-Home and VisDA while using fewer auxiliary samples (~34,500 vs. 65,000+), making it a more cost-effective and universal adaptation strategy. A key limitation is that the method depends on the target domain's visual style being reasonably represented in web-scale image-text pairs, which may fail for specialized domains (e.g., medical imaging). Open questions include whether the progressive distribution bridging idea generalizes beyond classification to dense prediction tasks, and whether the retrieval-based auxiliary data construction can be made more robust to the noise inherent in web-crawled captions.

## Problem

Multi-modal large language models depend on large-scale instruction-following training data, but top MLLM datasets are private and manual collection is expensive. Existing synthesis methods rely on fixed text prompts and rigid pipelines that homogenize data difficulty, lack rigorous quality control, and require substantial human effort to design prompts and data patterns. The paper asks whether high-quality, diverse multi-modal instruction data can be synthesized automatically using only images as input.
![Teaser figure](../imgs/ICCV20250548/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image as its sole input—no text prompt, no caption, no question template is provided. The output is a structured instruction-response pair: the instruction is autoregressively generated by the MLLM from the image alone, and the response is subsequently generated by the same MLLM. Because no language is specified in the prompt, the generated instructions naturally span 46 language types, and the image domain (e.g., charts, documents, medical images) directly determines the task domain of the synthesized data.

## Method

Oasis exploits the autoregressive nature of MLLMs by feeding only the pre-query template and image (a 'hooking' prompt) to Qwen2-VL-72B, deliberately omitting the instruction and post-query template so the model generates the instruction from its own knowledge conditioned on the visual content. A three-step pipeline then refines the raw output: (1) an LLM classifier separates instruction-following data from caption-like outputs (pass rate ~50%), (2) a four-dimensional quality control mechanism (solvability, clarity, hallucination, nonsense) scores each instruction 1–5 using an MLLM and LLM, filtering out low-quality entries (acceptance rate ~51%), and (3) the retained instructions are paired with MLLM-generated responses. The key insight is that removing the text prompt eliminates prompt-induced bias, letting the MLLM's internal distribution drive instruction diversity, while the image inherently anchors the data to a specific domain—enabling targeted synthesis (e.g., 70k OCR-specific samples) without any prompt engineering.

## Results

Oasis data improves the average score across 14 benchmarks by +3.1% (Vicuna-7B), +1.8% (Qwen2.5-7B), and +3.2% (Llama3-8B) over the respective LLaVA-NeXT baselines. The most notable gains appear in document understanding (DocVQA +4.3%, InfoVQA +6.3% for Vicuna) and OCR (TextVQA +2.7%, OCRBench +2.1%). In the scaling experiment, adding 500k Oasis data to 100k LLaVA-NeXT SFT data yields a +5.2% average improvement, with the 300k→500k increment alone contributing +4.0%, indicating continued gains at scale.

## Baselines & Comparisons

Oasis outperforms all four compared synthesis methods on the Vicuna-7B-v1.5 backbone. Against MMEvol (AVG 51.6), Oasis achieves the largest margin at +4.5%, with particularly strong gains on MMStar (+5.7) and ScienceQA (+17.6). Against Cambrian-10M original annotations (AVG 54.9), Oasis leads by +1.2%, excelling on DocVQA (+2.2), InfoVQA (+1.9), and TextVQA (+2.4) while Cambrian retains an edge on AI2D (+3.4). Against DenseFusion-1M (AVG 54.3), Oasis gains +1.8%, with the most consistent advantage on OCR-related benchmarks (TextVQA +0.7, OCRBench −0.4, DocVQA +6.8, InfoVQA +6.7). Against upsampled LLaVA SFT data (AVG 53.7), Oasis leads by +2.4%, showing broad improvements across general, document, and OCR domains. The authors attribute Oasis's advantage to its prompt-free nature, which keeps generated data aligned with the MLLM's internal knowledge distribution, making it inherently easier for the model to learn.

## Relation to Prior Work

Oasis directly extends Magpie's prompt-free text synthesis paradigm to the multimodal domain: instead of feeding an aligned LLM an empty prompt, it feeds an MLLM only a pre-query template plus an image, letting autoregressive generation produce instructions without any human-designed text prompt. This departs sharply from prior multimodal synthesis methods (LLaVA, ALLaVA, MMEvol, Cambrian-1) that rely on fixed prompt templates, caption-then-QA pipelines, or iterative evolution schemes, all of which constrain diversity and require substantial human design effort. The quality-control stage borrows the LLM/MLLM-as-a-judge paradigm, but applies it to four handcrafted instruction-level dimensions rather than response-level scoring.

## Why It Matters / Open Questions

By reducing the synthesis input to a single image, Oasis makes large-scale multimodal data generation both privacy-safe (no proprietary instruction data needed) and domain-controllable (image source dictates task domain), which is practically valuable for under-resourced domains like OCR or medical imaging. The 500k public dataset and the demonstrated scaling behavior (5.2% gain at 500k over 100k baseline) give the community a concrete, reproducible resource. An open question is how far the method scales when the generating MLLM is weaker than Qwen2-VL-72B, and whether the autoregressive instruction distribution remains well-calibrated as the image corpus grows to millions.

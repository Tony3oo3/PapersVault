## Problem

Composing a reference object into a scene while preserving its identity and harmonizing pose and lighting remains challenging because no large-scale paired datasets exist for supervised training. Existing solutions either require slow test-time fine-tuning (e.g., DreamBooth, Textual Inversion) or rely on synthetic augmentations and video data that lack the diversity of real-world poses and lighting conditions.
![Teaser figure](../imgs/ICCV20251765/cropped_page0_idx0.webp)

## Input / Output

The method takes 1 or 3 reference object views (each 512×512) arranged in a 2×2 grid alongside a noisy 512×512 target image, forming a 1024×1024 composite input. For object insertion, a background image and a binary location mask are additionally concatenated along the channel axis; for subject generation, a text prompt is injected via cross-attention. The output is a single 512×512 composite image with the object photorealistically placed in the scene, produced without any test-time tuning.

## Method

The core contribution is the object recurrence prior: mass-produced objects recur across large unlabeled image collections in different poses, lighting, and scenes, enabling construction of a 4.5M-sample supervised dataset by retrieving kNN matches using instance-retrieval (IR) features (similarity threshold 0.93–0.975) over 55M detected objects from WebLI. Backgrounds for object insertion are extracted with ObjectDrop to remove shadows and reflections, and scene captions are generated by an image-to-text model. The architecture is a standard SDXL-based UNet with no bottleneck: it processes the 2×2 grid of references and noisy target through self-attention, computing the diffusion loss only on the target quadrant. Separate models are trained from inpainting and text-to-image checkpoints respectively for 100K steps on 128 V4 TPUs, and the multi-view supervision eliminates the need for the encoder bottlenecks that prior zero-shot methods use to prevent copy-paste collapse.

## Results

On the object insertion task, ObjectMate with 3 reference views achieves CLIP-I 0.940, DINO 0.885, and IR 0.858, outperforming the strongest baseline AnyDoor (0.916, 0.822, 0.738) by 2.4, 6.3, and 12.0 points respectively. On subject-driven generation (DreamBench), ObjectMate-3Ref attains the best text-prompt alignment (CLIP-T 0.322) and the best identity preservation (IR 0.750), surpassing the strongest zero-shot baseline ELITE (CLIP-T 0.293, IR 0.638) and all tuning-based methods. User studies confirm these gains: users prefer ObjectMate over AnyDoor 81% of the time for composition and 76% for identity in object insertion, and over ELITE 83% for identity and 95% for text alignment in subject generation.

## Baselines & Comparisons

For object insertion, ObjectMate (3 ref) dominates all three zero-shot baselines on every metric: it beats AnyDoor [10] by +2.4 CLIP-I, +6.3 DINO, and +12.0 IR; ObjectStitch [53] by +3.5, +9.2, and +29.4; and Paint-by-Example [61] by +4.2, +8.5, and +31.4. The gap is largest on the IR identity metric, confirming that prior methods preserve semantics but not exact object identity. For subject-driven generation, ObjectMate (3 ref) achieves the highest CLIP-T (0.322) and IR (0.750) among all methods, outperforming the tuning-based baselines Textual Inversion [15] (IR 0.655), DreamBooth [44] (IR 0.674), and DisenBooth [6] (IR 0.728), as well as the zero-shot baselines ELITE [58] (IR 0.638) and BLIP-Diffusion [29] (IR 0.664). However, ObjectMate does not uniformly win on semantic-similarity metrics: DisenBooth [6] edges it on CLIP-I (0.784 vs 0.773) and DINO (0.625 vs 0.607), and BLIP-Diffusion [29] slightly leads on CLIP-I (0.788 vs 0.773), suggesting that tuning methods can produce semantically similar but not identity-identical subjects. The authors validate via user study that the IR metric aligns better with human perception of identity than CLIP-I or DINO, reinforcing that ObjectMate's IR advantage is the most meaningful.

## Relation to Prior Work

This paper draws a direct lineage from classical recurrence priors in image processing (non-local means, example-based super-resolution, landmark retrieval for SfM), extending the idea from patches and landmarks to full object instances. It departs from prior object insertion and subject-driven generation methods in a key way: rather than relying on test-time tuning (DreamBooth, Textual Inversion) or zero-shot encoders with architectural bottlenecks (AnyDoor, Paint-by-Example, ObjectStitch), it creates massive supervised multi-view data by exploiting the fact that mass-produced objects recur across large unlabeled web datasets, retrieved via instance-retrieval (IR) features rather than semantic ones (CLIP, DINO). The resulting data quality is sufficient to train a completely standard, bottleneck-free UNet, in contrast to prior methods that required architectural tricks to prevent copy-paste collapse.

## Why It Matters / Open Questions

The object recurrence prior provides a scalable, low-cost alternative to manual data collection, video-based supervision, and test-time tuning for object composition, and the dataset creation pipeline is generalizable to other tasks (3D geometry, object editing). The finding that a simple architecture suffices with good multi-view data challenges the field's assumption that architectural complexity (bottlenecks, specialized encoders) is necessary to prevent degenerate solutions. Open questions include whether the prior extends to human subjects (IR features were not designed for faces), whether performance saturates at larger dataset scales (current evidence suggests it does not), and how retrieval quality for lookalike objects (e.g., similar animal species) can be improved.

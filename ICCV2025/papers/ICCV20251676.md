## Problem

Existing incremental few-shot semantic segmentation methods learn novel classes by fine-tuning inherited parameters, which degrades old-class distinguishability and causes catastrophic forgetting while simultaneously overfitting to the few new samples. Prompt-based incremental learning has proven effective in image classification but has not been adapted to dense prediction, where multi-granularity contextual information (global context plus local structural details) is essential for accurate pixel-level segmentation.
![Teaser figure](../imgs/ICCV20251676/cropped_page0_idx1.webp)

## Input / Output

The method takes an RGB image and a set of class-name text prompts (formatted as 'a photo of CLASS_NAME') as input. Background is not a single class but is pre-decomposed into multiple semantic background categories (e.g., 'sky', 'room') to create clearer feature-space boundaries. The output is a pixel-wise segmentation mask decomposed into two heads: a foreground refinement mask assigning each pixel to a specific foreground class and a background isolation mask assigning each pixel to a specific background sub-class, which are jointly constrained by a background aggregation loss.

## Method

The core contribution is a multi-level switchable visual prompt (MSVP) strategy inserted into a frozen ViT-B encoder, combined with a Focus Decomposition Decoder (FDD) that separates foreground and background prediction via two cross-attention separators. Three prompt levels operate at different granularities: task-persistent prompts (frozen after base training) encode generalizable foreground-background distributions; stage-specific prompts (continuously expanded) are selected per-image via a DINOv2-derived global query and attention-based aggregation over learnable keys; and region-unique prompts (one per class) are selected per-region via KMeans clustering of DINOv2 pixel features followed by Gumbel-Softmax nearest-neighbor matching. A cross-modal query engine fuses CLIP text embeddings with global image features to generate class-specific queries for the decoder. During incremental training, only the newly expanded stage-specific and region-unique prompt components are updated while all prior prompts and the backbone remain frozen, keeping the active prompt count constant and preventing interference between stages.

## Results

On Pascal VOC 2012 (1-shot), the method achieves 49.08% mIoU-N and 58.71% HM, outperforming the previous SOTA (SRAA) by 30.28% mIoU-N. On MS COCO (1-shot), it reaches 25.60% mIoU-N and 33.59% HM, a 14.3% mIoU-N gain over SRAA. Under 5-shot on VOC, performance further improves to 58.13% mIoU-N and 64.86% HM. Base-class mIoU remains competitive (73.04% on VOC, 48.85% on COCO at 1-shot), confirming minimal catastrophic forgetting.

## Baselines & Comparisons

The method decisively outperforms all prior IFSS baselines on novel-class mIoU across both datasets and all shot settings. On VOC 1-shot, it surpasses SRAA (18.8%) by 30.28% mIoU-N, OINet (18.0%) by 31.08%, CaLNet (17.4%) by 31.68%, and PIFS (16.9%) by 32.18%. On COCO 1-shot, the gains are 14.3% over SRAA (11.3%), 13.9% over OINet (11.7%), and 15.0% over CaLNet (10.6%). On base-class retention, CaLNet achieves slightly higher mIoU-B on VOC (74.2 vs. 73.04) and COCO (48.4 vs. 48.85), but its novel-class performance is less than half that of the proposed method. FSC methods (WI, DWI) retain base knowledge well (66–67% on VOC) but collapse on novel classes (16–19%), while IL methods (LwF, MiB) perform poorly on both, confirming that neither paradigm alone addresses the IFSS dilemma. The HM metric, which balances base and novel performance, shows the largest relative improvement: 58.71% vs. 29.3% (SRAA) on VOC 1-shot, a nearly 2× gain.

## Relation to Prior Work

This paper is the first to transplant the prompt-based incremental learning paradigm (established in image classification by L2P, DualPrompt, and CODA-Prompt) into incremental few-shot semantic segmentation. It builds on VPT's frozen-backbone prompt injection, L2P's prompt-pool selection, DualPrompt's general/shared prompts (adapted here as frozen task-persistent prompts), and CODA-Prompt's attention-based prompt assembly (adapted for stage-specific prompts). The key departure from prior IFSS methods (PIFS, OINet, CaLNet, SRAA) is replacing parameter fine-tuning and prototype updating with a multi-level switchable prompt mechanism, and from prior prompt-based classification work is the introduction of region-unique prompts and a focus decomposition decoder to handle the multi-granularity demands of dense prediction.

## Why It Matters / Open Questions

The paper establishes that a frozen-backbone, prompt-only expansion strategy can dramatically outperform fine-tuning-based IFSS methods (30+ mIoU-N on VOC 1-shot), suggesting the field should reconsider whether parameter updates are necessary for incremental segmentation. The multi-level prompt switching mechanism addresses the practical concern of growing inference cost as stages accumulate, maintaining a fixed active prompt count. Open questions include whether the approach scales to many more incremental stages or larger class spaces, whether the DINOv2 query function's overhead is acceptable in deployment, and whether the multi-level structure (vs. simpler two-level prompts) is truly necessary or an artifact of the limited evaluation on two datasets with one ViT-B backbone.

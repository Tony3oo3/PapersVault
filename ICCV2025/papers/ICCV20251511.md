## Problem

Memory-based test-time adaptation (TTA) for vision-language models performs well on a single domain with abundant data, but in federated learning each client has only a small, distribution-specific subset of test samples. Applying these methods independently per client suffers from data scarcity, while naively sharing a single global memory destroys personalization to each client's unique distribution. The paper addresses how to collaboratively share adaptation knowledge across heterogeneous clients while preserving per-client personalization.

## Input / Output

Each client receives a streaming sequence of unlabeled RGB test images from its own local distribution and produces a refined class label per image. The method is fully training-free (no backpropagation, no data augmentation), operating online as images arrive. The final prediction combines the initial CLIP zero-shot logit with a memory-based correction logit scaled by a hyperparameter α, so the output is a standard class label but computed through a lightweight similarity-weighted aggregation over stored embeddings rather than a learned classifier.

## Method

Latte equips each client with a dual-memory structure: a local memory (priority queue of high-confidence embeddings from the client's own data, sorted by entropy) and an external memory (class prototypes retrieved from distributionally similar clients). During periodic communication, each client uploads entropy-weighted class prototypes to a server, which maintains a global memory; the client then retrieves the top-k_e most cosine-similar prototypes from other clients to populate its external memory. At inference, the local and external memories are merged (keeping the k_l lowest-entropy entries), and a new test image's embedding is matched against the merged memory using weights that combine both embedding similarity (f^T m) and negative entropy (−γ·H(m)), producing a refined per-class logit. This dual weighting makes the adaptation robust to out-of-distribution prototypes and misclassified samples, and the theoretical analysis (Theorem 4.3) proves the error bound improves with the number of in-distribution clients while remaining unaffected by out-of-distribution ones. Communication is fully decoupled from per-sample inference, allowing offline adaptation between communication rounds.

## Results

On domain adaptation benchmarks, Latte achieves 82.57% average accuracy on VLCS (+1.74 over CLIP) and 40.95% on TerraIncognita (+9.11 over CLIP) with ViT-B/16, and 80.75% on VLCS (+1.45) and 41.47% on TerraIncognita (+18.23) with RN50. On corruption benchmarks, Latte reaches 68.27% on CIFAR-10-C (+2.69 over CLIP) and 39.51% on CIFAR-100-C (+0.60). Latte consistently outperforms all memory-based baselines (TDA, DMN-ZS) in both local and global configurations, as well as episodic TTA methods (VTE, TPT, Zero), while global memory sharing often causes negative transfer (e.g., DMN-ZS(global) drops to 63.90% on CIFAR-10-C vs. 65.58% for CLIP).

## Baselines & Comparisons

Latte outperforms all six baselines on both domain adaptation benchmarks across both backbones. On TerraIncognita (ViT-B/16), Latte (40.95%) surpasses the best episodic method VTE (38.56%) by 2.39 points and the best memory-based method DMN-ZS(global) (37.64%) by 3.31 points; on VLCS, it leads Zero (81.98%) by 0.59 points. On CIFAR-10-C, Latte (68.27%) beats Zero (67.95%) and VTE (67.64%), while global memory sharing causes severe negative transfer: DMN-ZS(global) drops to 63.90%, below CLIP's 65.58%. On CIFAR-100-C, the gains are smaller but Latte (39.51%) still edges out DMN-ZS(local) (39.17%) and TDA(local) (39.05%), whereas DMN-ZS(global) degrades to 36.64% (−2.27 vs. CLIP). The key finding is that naive global memory sharing (TDA-global, DMN-ZS-global) frequently harms performance due to distribution heterogeneity, while Latte's selective retrieval of in-distribution prototypes avoids this negative transfer.

## Relation to Prior Work

This paper extends memory-based test-time adaptation (TTA) for vision-language models—exemplified by TDA and DMN-ZS, which store high-confidence embeddings in a priority queue and refine predictions via embedding similarity—to the federated learning setting where each client has limited data. It departs from prior FL-TTA work (FedTHE, FedICON, TSA) in two key ways: it targets pre-trained VLMs rather than models trained within FL, and it introduces a collaborative memory-sharing mechanism (local + external memories with prototype retrieval) rather than aggregating model weights or relying on a single shared memory. The theoretical analysis builds on k-NN generalization bounds for TTA but extends them to a multi-client setting with both in-distribution and out-of-distribution peers, providing a direct comparison to the zero-shot baseline.

## Why It Matters / Open Questions

The paper addresses a practically important gap: deploying pre-trained VLMs across many clients with heterogeneous, limited data, a scenario common in edge and privacy-sensitive applications. The finding that naive global memory sharing causes negative transfer (performance below zero-shot CLIP) while the hybrid local+external design avoids this provides clear design guidance for collaborative TTA systems. Open questions include how the approach scales to very large client populations, whether the coarse prototype-based retrieval can be replaced with more fine-grained sharing, and whether the binary-classification theoretical guarantees extend to multi-class settings. The decoupling of communication from per-sample adaptation is a practical contribution that makes the method deployable in bandwidth-constrained FL systems.

## Problem

Existing learning-based point cloud registration methods require large paired datasets with ground-truth correspondences for training, limiting their practical applicability. While pretrained diffusion models can extract semantic features from depth maps, direct application to point cloud registration fails when the two views have large parallax, producing unreliable correspondences. The paper asks whether a zero-shot refinement stage can improve any existing registration method by exploiting diffusion features on parallax-reduced depth maps.
![Teaser figure](../imgs/ICCV20252468/cropped_page0_idx2.webp)

## Input / Output

The method consumes a reference point cloud P (M points), a source point cloud Q (N points), an initial rigid transformation T_init, and 3D pointwise features F_p, F_q produced by an existing registration method (e.g., GeoTransformer). It projects both clouds into depth maps from two perspectives (reference view and source view), densifies them via erosion/dilation, and feeds them into a frozen ControlNet. The output is a refined rigid transformation (rotation R ∈ SO(3) and translation t ∈ ℝ³) that supersedes T_init, with no parameters learned during the process.

## Method

RARE projects the source point cloud into the reference view (and vice versa) using T_init to reduce parallax, then extracts depth diffusion features from layers [0, 3, 6] of a frozen Stable Diffusion UNet decoder via ControlNet, applying PCA to reduce dimensionality before upsampling and concatenation. A Feature Transfer Module bridges the pixel-to-point coordinate gap by nearest-neighbor matching to identify common points, then fuses 3D and diffusion features through L2-normalized concatenation. An Inlier Aggregation Module constructs five correspondence sets (common-ref, common-src, diffusion-ref, diffusion-src, and 3D-only), estimates a transformation for each via weighted SVD, selects the one maximizing inlier count within an acceptance radius, and iteratively re-weights confidence scores over N_r iterations to produce the final refined transformation.

## Results

On 3DMatch (>30% overlap), RARE achieves 94.5% Registration Recall, 1.56° rotation error, and 0.050 m translation error, outperforming all baselines including VBReg (94.1% RR) and MAC (93.8% RR). On the more challenging 3DLoMatch (10–30% overlap), it reaches 76.7% RR with the best rotation error (2.55°) and translation error (0.074 m). When applied as a refinement on top of existing supervised methods, RARE boosts FCGF by +8.3% RR, Predator by +4.7% RR, CoFiNet by +3.7% RR, and GeoTransformer by +2.5% RR on 3DMatch, all without any additional training.

## Baselines & Comparisons

On 3DMatch, RARE outperforms every baseline on all three metrics: it beats the strongest outlier-removal methods VBReg (94.1% RR) and MAC/FastMAC (93.8% RR) by 0.4–0.7% in recall, and improves rotation error from 1.60° (MAC) to 1.56° and translation error from 0.051 m (PointDSC) to 0.050 m. On 3DLoMatch, RARE ties SC²-PCR at 76.7% RR and narrowly trails VBReg (77.7% RR) by 1.0%, but achieves the best rotation error (2.55° vs. 2.57° for MAC) and translation error (0.074 m vs. 0.075 m for MAC/PointDSC/VBReg). On KITTI, where GeoTransformer already achieves 99.8% RR, RARE matches that recall and rotation error (0.24°) while reducing translation error from 0.068 m to 0.064 m, outperforming all outlier-removal baselines (e.g., SC²-PCR at 0.105 m TE, MAC at 0.128 m TE). As a refinement layer, RARE consistently improves every supervised method tested: FCGF gains +8.3% RR (67.9→76.2), Predator +4.7% (89.0→92.7), CoFiNet +3.7% (89.3→93.0), and GeoTransformer +2.5% (92.0→94.5), with corresponding reductions in rotation and translation errors across the board.

## Relation to Prior Work

This paper extends the diffusion-feature-for-registration line initiated by FreeReg (Wang et al., ICLR 2024), which first demonstrated that ControlNet-based depth diffusion features can establish cross-modal correspondences between images and point clouds. The key conceptual departure is the use of an initial transformation from an existing registration method (e.g., GeoTransformer) to reduce parallax in projected depth maps before extracting diffusion features, addressing FreeReg's known weakness on large-parallax depth maps. Rather than proposing a standalone registration pipeline, RARE positions itself as a zero-shot refinement module that fuses depth diffusion features with 3D geometric features via a Feature Transfer and Inlier Aggregation mechanism, making it composable with any upstream registration method.

## Why It Matters / Open Questions

The zero-shot, training-free nature of the approach is practically significant: it can improve any existing registration method without requiring paired training data, lowering the barrier for deployment in new domains. However, the gains are modest (e.g., +2.5% RR over GeoTransformer on 3DMatch) and the method cannot improve registration recall on KITTI where the baseline already saturates at 99.8%, suggesting diminishing returns when the initial transformation is already near-optimal. Open questions include how the method behaves under very low overlap (<10%), whether the diffusion model inference cost is acceptable for real-time applications, and whether the parallax-reduction strategy generalizes to non-rigid or multi-view registration settings.

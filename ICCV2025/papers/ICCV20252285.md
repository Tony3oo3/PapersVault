## Problem

Existing human motion Q&A methods (e.g., NSPose) rely on explicitly defined functional modules for each reasoning operation (filtering, relational inference, querying), which limits scalability and adaptability to diverse query types. Moreover, explicit program execution is brittle: a single error in a predicted program step cascades into large performance drops. The paper asks whether a unified, implicit reasoning module can match or exceed explicit neuro-symbolic approaches while being more robust to noisy program inputs.

## Input / Output

The model takes a 3D motion sequence of shape T×J×3 (joint positions over frames), a natural language question, and a structured program of p functions (either ground-truth or predicted by a coarse-to-fine parser). Motion is processed in 224-frame segments by a patch-based ViT encoder where each patch groups joints into body parts (torso, legs, arms). Output is a categorical answer over a fixed vocabulary for one of three query types (action, direction, body part), selected by a multi-branch classifier where only the branch matching the question type is activated.

## Method

IMoRe replaces MAC's soft-attention-based operation generation with direct conditioning on structured program functions: at each of p iterative steps, the current program function serves as the query to (1) attend over prior memory states to capture inter-step dependencies, and (2) read from a multi-level knowledge pool built from M=6 intermediate ViT layers plus the final output, projected into a shared space. This program-guided reading mechanism lets the model dynamically select between fine-grained low-layer features (for body-part queries) and high-level semantic features (for action queries) at each reasoning step. Motion and text features are first fused via cross-attention (motion as query, RoBERTa text as key/value), then further fused with encoded question-type tokens. The full model is trained end-to-end with a cross-entropy classification loss using AdamW (lr 1e-6, weight decay 1e-4) for 100 epochs, leveraging a pre-trained motion ViT and RoBERTa as frozen or fine-tuned encoders.

## Results

On the Babel-QA benchmark, IMoRe II achieves 64.0% overall accuracy with ground-truth programs and 61.5% with predicted programs, outperforming the previous state-of-the-art NSPose (57.8% GT / 47.2% predicted) by 6.2 and 14.3 percentage points respectively. On the newly introduced HuMMan-QA dataset, IMoRe II reaches 73.0% overall accuracy, surpassing NSPose (69.1%) and MotionCLIP-MLP (68.6%). The model also demonstrates strong robustness: the performance drop from ground-truth to predicted programs is only 2.5% for IMoRe II, compared to a 10.6% drop for NSPose.

## Baselines & Comparisons

IMoRe II outperforms NSPose [11] (the primary neuro-symbolic baseline) by 6.2 points overall on Babel-QA with ground-truth programs (64.0% vs. 57.8%) and by 14.3 points with predicted programs (61.5% vs. 47.2%), indicating substantially greater robustness to program prediction errors. Against the direct feature-fusion baselines from [11] (MotionCLIP-MLP at 43.0%, MotionCLIP-RNN at 42.0%, 2S-AGCN variants at ~35.6%), IMoRe II leads by 21+ points, confirming that structured reasoning is essential for this task. On HuMMan-QA, IMoRe II (73.0%) beats NSPose (69.1%) by 3.9 points and MotionCLIP-MLP (68.6%) by 4.4 points, demonstrating cross-dataset generalization. In the ablation (Table 3), the MAC-based implicit reasoning without program guidance (58.2%) already surpasses NSPose with ViT encoder (44.0%), and adding program guidance plus feature selection yields the full 64.0%, isolating the contribution of each component. CLIP [31] serves as a simple cross-modal baseline at 41.7% on Babel-QA, far below all reasoning-based methods.

## Relation to Prior Work

This paper builds directly on NSPose [11], which introduced the human motion Q&A task and an explicit neuro-symbolic reasoning approach using manually defined functional modules (filter, relate, query). It departs from this explicit paradigm by adopting the iterative MAC network [16] architecture but replacing MAC's soft-attention-based operation generation with direct conditioning on structured program functions, eliminating the ambiguity of inferring operations from question words. The program-guided reading mechanism further extends the approach by dynamically selecting multi-level features from a pre-trained motion ViT [38], moving beyond the single static feature representation used in both NSPose and standard MAC.

## Why It Matters / Open Questions

The key practical contribution is demonstrating that implicit program-guided reasoning is substantially more robust to noisy program predictions (1-2% drop) than explicit module execution (large cascading failures), which matters for real-world deployment where ground-truth programs are unavailable. The introduction of HuMMan-QA provides a larger, more diverse benchmark for evaluating generalization beyond the small Babel-QA dataset. However, the approach still depends on a program predictor's quality, the motion ViT encoder is frozen, and the task remains limited to categorical answers over three query types—open questions include whether the framework extends to open-ended motion descriptions, longer multi-step programs, or other sequential reasoning domains.

## Problem

Generalizable object pose estimation from RGB images remains unreliable in sparse-view settings and under severe occlusions. Retrieval-based methods (e.g., Gen6D) fail when reference views are too few or occluded to provide good pose initialization, while matching-based methods (e.g., OnePose++) depend on dense point cloud reconstructions that degrade with limited reference views. No existing approach robustly estimates the pose of an unseen object from only a handful of reference images while handling partial visibility.
![Teaser figure](../imgs/ICCV20250186/cropped_page0_idx0.webp)

## Input / Output

The method takes a single query RGB image, a small set of sparse reference RGB images (as few as 2–5, sampled via Farthest Point Sampling), and object detection masks for the reference views. Reference images are processed offline with DUSt3R to recover a 3D bounding box and reference camera poses; at inference time, only the query image and precomputed 3D box corners are needed. The network outputs an H×W×8 2D bounding box corner heatmap for the query view, from which the 6DoF pose (rotation + translation) is recovered via a PnP solver. The method runs in ~17 ms per query on an RTX 4090.

## Method

BoxDreamer replaces dense point clouds with the eight corners of a 3D bounding box as the intermediate object representation, since these semantic points can be reliably recovered from sparse views and naturally establish 2D-3D correspondences without dense matching. Reference 3D box corners are projected into each reference image and rendered as heatmaps with a custom Gaussian smoothing (σ scaled to one-tenth of the object's pixel size), which are then fused element-wise with DINOv2 image features. A 12-layer full self-attention transformer decoder processes concatenated reference and query feature tokens (with learned query tokens for the target view) to regress the query bounding box heatmap. Training uses a combined Smooth L1 loss on the coarse heatmap and fine corner coordinates, with data augmentation including random 3D box rotation, occlusion masking, and background compositing on Objaverse (45k synthetic) and OnePose (50 real) objects. The approach is robust to noisy bounding boxes and does not require an accurate 3D box, as confirmed by ablations comparing DUSt3R-recovered, OnePose++-recovered, and ground-truth boxes.

## Results

On LINEMOD with only 5 reference images, BoxDreamer achieves 53.1 ADD(s)-0.1d, more than doubling the second-best GS-Pose (25.6). On the challenging Occluded LINEMOD dataset with 25 references, it reaches 43.6 ADD(s)-0.1d and 47.9 Proj-2D@5px, substantially outperforming Gen6D with ground-truth detections (25.5 / 36.1). On YCB-Video (Sparse Database), BoxDreamer attains 66.6 ADD-S with 16 references, exceeding Gen6D† (55.2) by 11.4 points. On OnePose-LowTexture, it achieves 86.6 ADD-0.1d with just 10 references, approaching the full-reference OnePose++ (88.9) while far surpassing Gen6D† (21.2).

## Baselines & Comparisons

Against GS-Pose, BoxDreamer achieves 53.1 vs. 25.6 ADD(s)-0.1d with only 5 references (2.1× improvement), but GS-Pose edges ahead at 16–32 references (62.1–74.5 vs. 60.4–69.2); however, BoxDreamer is over 40× faster (17 ms vs. 960 ms per query). Against Gen6D (retrieval-based), BoxDreamer wins decisively in all settings, most dramatically on Occluded LINEMOD where it scores 43.6 vs. 25.5 ADD(s)-0.1d with 25 references even when Gen6D is given ground-truth detections. Against OnePose++ (matching-based), the gap is overwhelming in sparse-view: 53.1 vs. 1.1 on LINEMOD with 5 references, and 65.6 vs. 43.3 ADD-S on YCB-Video (5 vs. 200 references). Against Cas6D, BoxDreamer leads by 28 points at 16 references (60.4 vs. 32.4). Notably, BoxDreamer also surpasses the instance-level PVNet on Occluded LINEMOD (43.6 vs. 40.8 with 25 refs), demonstrating that a generalizable RGB-only method can match per-object trained approaches under occlusion.

## Relation to Prior Work

BoxDreamer departs from both dominant paradigms in generalizable pose estimation—retrieval-based (Gen6D, Cas6D) and matching-based (OnePose, OnePose++)—by replacing dense point clouds or volumetric representations with the eight corners of a 3D bounding box as the intermediate geometric primitive. It repurposes CornerNet-style Gaussian heatmap supervision for corner localization, DINOv2 as a frozen visual backbone, and DUSt3R for offline sparse-view reconstruction, but the core conceptual contribution is the insight that a compact 8-point representation suffices for 6DoF pose recovery via PnP, eliminating the need for dense 2D-3D correspondence. This positions the work as a simplification of the matching-based paradigm: rather than matching thousands of points, the network predicts only eight semantic corner projections guided by reference corner heatmaps.

## Why It Matters / Open Questions

The practical impact is significant: achieving competitive or superior pose accuracy with as few as 5 reference images (vs. 25–200 for prior methods) and 17 ms per-query inference makes generalizable pose estimation viable for real-time manipulation and AR where dense capture is infeasible. The demonstrated robustness to noisy bounding boxes (Table 6) and severe occlusions (Occluded-LINEMOD, YCB-Video) addresses two of the most common failure modes in deployed systems. Open questions remain around symmetric objects (where corner ambiguity degrades PnP), the memory cost of scaling to many reference views, and whether integrating detection and corner prediction into a single end-to-end pipeline would further improve robustness in cluttered scenes.

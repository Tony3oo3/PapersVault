## Problem

HOI detection suffers from a 'Toxic Siblings' bias where highly similar triplets (sharing human, action, or object components) interfere with each other at both the input level (co-occurring in the same image) and the output level (semantically overlapping classification heads). This bias causes a paradox where increased similarity among sibling categories reduces precision, as one category's gain comes at the expense of its toxic sibling's decline, and existing DETR-based detectors lack mechanisms to explicitly counteract this interference.

## Input / Output

The method takes a single RGB image and outputs a set of N HOI triplets, each consisting of a human bounding box, an object bounding box with its category, and an interaction (verb) category. The interaction decoder is initialized with CLIP or BLIP2 text features generated from natural-language descriptions of each HOI triplet, and the model is trained end-to-end with Hungarian matching between predicted and ground-truth triplets. No external data augmentation or heavy generative models are required at inference time.

## Method

Building on the GEN-VLKT one-stage two-branch DETR baseline, the paper introduces two debiasing objectives targeting input and output 'Toxic Siblings' respectively. For input-level bias, the contrastive-then-calibration (C2C) objective first applies a contrastive loss between sibling triplets co-occurring in the same image to sharpen their feature distinction, then injects queries with semantically incorrect but spatially correct features and trains the decoder to reconstruct them back to the correct triplet via an L1 calibration loss, forcing reliance on spatial priors over misleading contextual siblings. For output-level bias, the merge-then-split (M2S) objective first clusters all 600 HOI categories into superclasses using CLIP text-feature k-means and adds a superclass classification head to learn shared features that separate sibling groups from unrelated categories, then applies a split loss that forces the decoder to correctly classify among only the top-K most similar categories (selected per query via cosine similarity), guided by concatenated class-specific text features to preserve fine-grained uniqueness within sibling groups.

## Results

On HICO-DET (Default setting), the proposed method with R50+CLIP achieves 42.93% mAP (Full), 42.41% (Rare), and 43.11% (Non-Rare), surpassing the strongest CLIP-based SOTA (BCOM, 39.34% Full) by +3.59% and the baseline GEN-VLKT (33.75%) by +9.18%. With R50+BLIP2, it reaches 43.98% Full mAP, outperforming methods that rely on LLMs and SAM (SICHOI: 41.79%). On V-COCO, the method achieves 69.8% AP_S1role and 72.1% AP_S2role (R50+CLIP), a +4.0% gain over the previous best (BCOM: 65.8%). The R101+CLIP variant further reaches 43.82% Full mAP on HICO-DET, beating the R101-based CyCleHOI (37.79%, which uses Stable Diffusion) by +6.03%.

## Baselines & Comparisons

Against the direct baseline GEN-VLKT (R50+CLIP), the method gains +9.18% mAP on HICO-DET Full (42.93 vs 33.75) and +13.16% on Rare categories (42.41 vs 29.25), with the largest relative improvement on tail classes. Versus the strongest CLIP-based SOTA BCOM (R50), the method leads by +3.59% on HICO-DET Full and +4.0% on V-COCO AP_S1role, without requiring any external model. Compared to methods that leverage heavy external models—UniHOI (BLIP2+LLM, 40.06%), SICHOI (BLIP2+LLM+SAM, 41.79%), and CyCleHOI (R101+CLIP+SD, 37.79%)—the proposed approach outperforms all of them using only a standard VLM (CLIP or BLIP2) and no additional generative or language model. Notably, the R50+CLIP variant (42.93%) surpasses the R101+CLIP+SD CyCleHOI (37.79%) by +5.14%, demonstrating parameter efficiency. On V-COCO, the method achieves the best AP_S1role (69.8–71.1%) and AP_S2role (72.1–73.3%) across all backbone/VLM configurations, exceeding the prior best (SICHOI: 67.9/72.8) by at least 2.2%.

## Relation to Prior Work

This paper builds directly on GEN-VLKT [39], a DETR-based one-stage two-branch HOI detector, and adds two auxiliary learning objectives (contrastive-then-calibration and merge-then-split) to the interaction decoder without altering the architecture. It departs from the dominant trend of leveraging heavy external models (LLMs, diffusion models, VLMs) for data augmentation or knowledge distillation, instead exploiting intrinsic structural properties of HOI categories—namely, their high mutual similarity—to design targeted debiasing losses. The contrastive loss draws on representation-learning ideas, while the merge-then-split objective repurposes hierarchical/superclass classification from taxonomy-based recognition, applied here to the specific problem of sibling-category interference in set-prediction decoders.

## Why It Matters / Open Questions

The 'Toxic Siblings' framing provides a concrete, measurable diagnosis for why HOI detection plateaus: similar categories actively degrade each other's learning at both input and output levels, a phenomenon previously acknowledged anecdotally but not systematically quantified. The practical impact is significant—the method achieves +9.18% mAP over its baseline and +3.59% over prior SOTA using only additional loss terms and no external models, making it a lightweight drop-in for existing DETR-based HOI pipelines. Open questions include whether the sibling-interference phenomenon generalizes to other fine-grained set-prediction tasks (e.g., scene graph generation, multi-label classification), and whether the merge-then-split strategy can be extended to open-vocabulary or compositional HOI settings where the category set is not fixed.

## Problem

In dynamic scenes, VSLAM systems face two coupled challenges: maintaining accurate camera localization despite moving objects and reconstructing a long-term consistent map free of dynamic artifacts. Existing mask-based approaches (semantic segmentation plus compensation masks) suffer from imprecise edges, failure under subtle motion or background-similar appearance, and high computational cost, while traditional geometric methods focus on localization and introduce ghosting artifacts when applied to dense reconstruction. No prior method simultaneously achieves state-of-the-art localization, artifact-free static Gaussian reconstruction, and real-time operation on resource-constrained hardware.

## Input / Output

The system consumes a streaming sequence of RGB-D frames (I_t ∈ R³, D_t ∈ R) together with object detection results that provide semantic priors for Potential Moving Objects (PMOs). It outputs per-frame camera poses in SE(3), a long-term consistent 3D Gaussian map containing only the static background, and refined bounding boxes for both PMOs and Unknown Moving Objects (UMOs). The Gaussian map is optimized with a masked photometric loss (L1 + SSIM) where dynamic regions are zeroed out, and the system is designed to run at ~34 FPS on a laptop with an RTX 3060 (6 GB VRAM).

## Method

DyGS-SLAM integrates three key modules into a 3DGS-SLAM pipeline built on Photo-SLAM's Gaussian mapping strategy. First, Dynamic Feature Detection (DFD) classifies features as dynamic using reprojection error for matched points and a weighted score combining reprojection depth residuals and cosine similarity of local image patches for unmatched points, enabling identification of UMOs and determination of true PMO motion states. Second, Dynamic Object Box Correction (DOBC) clusters out-of-box dynamic features via DBSCAN, fits a Gaussian Mixture Model to the depth distribution of in-box foreground points, and uses the trained GMM to classify surrounding candidate points, thereby expanding bounding boxes to fully cover moving objects. Third, Adaptive Feature Densification (AFD) computes per-block texture complexity from Sobel gradient magnitude and local variance, then applies a nonlinear exponential sampling rule to inject additional Gaussian features in texture-rich regions, compensating for sparse ORB extraction in texture-deficient areas. Pose estimation uses a two-stage coarse-to-fine strategy: the first stage excludes all PMO foreground points, and the second stage refines using only static points after DOBC correction, optimized via Levenberg-Marquardt bundle adjustment with Huber loss.

## Results

On the BONN RGB-D Dynamic dataset, DyGS-SLAM achieves an average ATE RMSE of 3.1 cm, outperforming the best dynamic baseline DN-SLAM (4.2 cm) and DG-SLAM (4.5 cm) by 26% and 31% respectively. On the TUM RGB-D dataset, it achieves 1.8 cm average ATE RMSE, slightly edging out DG-SLAM (1.9 cm) and substantially outperforming DynaSLAM (2.2 cm) and DGS-SLAM (3.6 cm). In real-time performance, DyGS-SLAM runs at 33.9 FPS with 2.9 GB GPU memory, approximately 20× faster than competing neural-rendering dynamic SLAM systems (1.2–1.6 FPS) while using less GPU memory.

## Baselines & Comparisons

DyGS-SLAM achieves the best average ATE RMSE on both evaluation datasets. On BONN RGB-D Dynamic, it leads DN-SLAM (4.2 cm) by 26% and DG-SLAM (4.5 cm) by 31%, while traditional methods like DynaSLAM (4.3 cm) and LC-CRF (6.6 cm) trail further behind. On TUM RGB-D, it edges out DG-SLAM (1.9 cm) and beats DynaSLAM (2.2 cm) and DGS-SLAM (3.6 cm); neural-rendering static systems (Photo-SLAM 22.1 cm, SplaTAM 99.3 cm) and crowd-based methods (Crowd-SLAM 2.4 cm on TUM) are either far inferior or only competitive on limited sequences. The most striking advantage is in real-time performance: DyGS-SLAM runs at 33.9 FPS on an RTX 3060, roughly 20× faster than Rodyn-SLAM (1.2 FPS), DGS-SLAM (1.6 FPS), and DG-SLAM (1.5 FPS), while also using less GPU memory (2.9 GB vs. 4–9 GB). Among the dynamic neural-rendering baselines, DN-SLAM and DG-SLAM are the closest competitors in localization accuracy, but both sacrifice real-time capability; DyGS-SLAM is the only method that simultaneously achieves top-tier accuracy and real-time operation on a portable laptop.

## Relation to Prior Work

This paper builds directly on Photo-SLAM's sparse-feature 3DGS mapping pipeline and the 3D Gaussian Splatting rendering framework, extending them to dynamic scenes. It departs from the dominant mask-based paradigm in dynamic 3DGS/NeRF SLAM (semantic segmentation + SAM/depth/motion compensation masks) by replacing masks with object detection boxes refined via a GMM-based correction algorithm, and by introducing a geometric-plus-appearance dynamic feature detection module that operates without inter-frame matching. The adaptive feature densification strategy based on Sobel-gradient and local-variance texture complexity is a new addition to the sparse-feature 3DGS SLAM line, addressing a known weakness of ORB-based extraction in texture-poor regions.

## Why It Matters / Open Questions

The ~20× real-time speed advantage (33.9 FPS on an RTX 3060 laptop vs. 1.2–1.6 FPS for competing dynamic 3DGS/NeRF SLAM systems) makes dynamic Gaussian SLAM practically deployable on resource-constrained portable devices, a regime where prior methods were infeasible. However, reconstruction quality is evaluated only qualitatively (no ground-truth static-only renders exist for dynamic scenes), and the authors acknowledge that stationary PMOs create reconstruction holes while intermittently moving non-PMOs can be duplicated in the map. Open questions include whether the GMM-based box correction generalizes to highly articulated or deformable objects, and whether the plug-and-play design transfers cleanly to other sparse-feature SLAM backends beyond the ORB/BA pipeline used here.

## Problem

Existing pretrained ViT-based few-shot object detection methods (e.g., DE-ViT) perform transformer encoding only in the feature dimension, overlooking pixel-wise differences in low-level features and multiscale variations. This results in blurred boundary features with overly smooth center-to-boundary transitions that fail to distinguish objects from backgrounds, and an inability to adaptively balance local detail extraction with global contour capture across varying object scales.
![Teaser figure](../imgs/ICCV20251722/cropped_page0_idx0.webp)

## Input / Output

The model consumes initial region proposals from a class-agnostic RPN (trained only on base classes), category prototypes, and frozen DINOv2 ViT-L/14 features as inputs, processing them through three stacked difference-multiscale fusion layers. Outputs include predicted bounding boxes (converted from regions), class scores computed via spatial attention mapping over width-height average features, and refined object regions. For the open-vocabulary setting, category names or textual descriptions additionally serve as input, and the model selects top-T categories (T=10 for comparisons, T=1 for ablations) based on cosine-similarity distances between prototypes and proposals.

## Method

PiDiViT builds on DE-ViT (DINOv2 ViT + Meta R-CNN) and introduces two explicit prior modules. The Difference Convolution Fusion Module (DCFM) fuses Central Pixel Difference Convolution (CPDC), which captures center-neighbor pixel differences to sharpen boundary gradients, with standard convolution, which preserves global semantic context, using a learned attention mechanism to dynamically weight each branch. The Multiscale Feature Fusion Module (MFFM) extracts features in parallel through five convolution branches (1×1, 3×3, 5×5, 7×7, and 3×3 dilated-2) and adaptively fuses them via a scale attention mechanism that generates per-branch weights through global average pooling and a small MLP with sigmoid activation. Three DCFM+MFFM layers are stacked with concatenated residual summation across layers, and the model replaces DE-ViT's dot-product feature matching with a Cosine Similarity Projection Subspace (CSPS) for improved discriminability under few-shot constraints.

## Results

On COCO few-shot object detection (10-shot), PiDiViT achieves 57.6 nAP50 and 40.9 nAP75 for novel classes, surpassing the previous SOTA CD-ViTO by +2.7 nAP50 and +3.7 nAP75. In the 30-shot setting, it reaches 58.5 nAP50 and 41.7 nAP75, improving over CD-ViTO by +4.0 nAP50. For one-shot detection, PiDiViT achieves 32.8 average nAP50 across four COCO splits, exceeding DE-ViT by +4.4. For open-vocabulary detection, it attains 54.0 nAP50, outperforming the cooperative foundational models SOTA by +3.7 nAP50.

## Baselines & Comparisons

PiDiViT outperforms all 32 compared baselines across all three detection tasks. In few-shot detection (Table 1), it surpasses the closest ViT-based competitor CD-ViTO [7] by +2.7 nAP50 (10-shot) and +4.0 nAP50 (30-shot), and exceeds its direct baseline DE-ViT [49] by +4.7/+5.5 nAP50. Among CNN-based methods, the strongest prior result is LVC [16] at 34.1 nAP50 (10-shot), which PiDiViT exceeds by +23.5 nAP50, highlighting the advantage of the ViT backbone combined with the proposed modules. In one-shot detection (Table 2), PiDiViT achieves 32.8 average nAP50, beating DE-ViT [49] (28.4) by +4.4 and the previous best CNN-based method BHRL [45] (25.6) by +7.2. In open-vocabulary detection (Table 3), PiDiViT reaches 54.0 nAP50, outperforming the cooperative foundational models of Bharadwaj et al. [2] (50.3) by +3.7 and DE-ViT [49] (50.0) by +4.0, while also improving base-class AP50 from 54.0 to 57.4. Notably, PiDiViT requires no fine-tuning (frozen DINOv2 backbone), matching or exceeding methods that do fine-tune, such as LVC [16] and NIFF [9].

## Relation to Prior Work

PiDiViT extends DE-ViT, which integrates a frozen DINOv2 ViT-L backbone into the Meta R-CNN framework for few-shot detection without fine-tuning. The key conceptual departure is that prior ViT-based few-shot detectors perform transformer encoding only in the feature dimension, overlooking pixel-level differential structure and multiscale variability in low-level features. PiDiViT addresses this by importing pixel difference convolution (PDC) from the edge-detection literature (Su et al.) and coupling it with standard convolution through an attention-based fusion module (DCFM), alongside a multiscale convolutional fusion module (MFFM) with scale attention—both inserted as explicit prior modules between ViT feature extraction and the detection head.

## Why It Matters / Open Questions

By showing that lightweight CNN-based differential and multiscale modules can meaningfully improve a frozen ViT pipeline for few-shot, one-shot, and open-vocabulary detection simultaneously, the paper offers a practical recipe for practitioners who want to boost ViT-based detectors without retraining the backbone. The ablations confirming that CPDC (center-neighbor differences) outperforms angular and radial PDC variants for this task provide useful guidance for future PDC-ViT integrations. However, the authors acknowledge that inherent bias in the pretrained ViT can skew class-specific feature projections under imbalanced class distributions, and they leave the design of fairness-constrained class weighting as open future work.

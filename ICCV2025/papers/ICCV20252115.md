## Problem

In animation production, identical objects appearing multiple times in a scene must be colored consistently, yet artists currently repeat the coloring process instance-by-instance, which is slow and error-prone. Existing generative colorization methods fail at this multi-instance task because they lack paired multi-instance training data and cannot enforce fine-grained, per-instance color consistency in a single generation pass.
![Teaser figure](../imgs/ICCV20252115/cropped_page0_idx0.webp)

## Input / Output

The method takes a line art sketch, N reference instance images (extracted via SAM from anime frames or user-provided), and N corresponding binary instance masks that specify where each instance should appear in the output. All inputs are processed at 512×512 resolution, and the model produces a single fully colorized image in one forward pass, with each instance region receiving colors matched to its designated reference. The reference instances can be real-life photos or anime frames, and the masks allow the same line art to be recolored with different instance assignments without retraining.

## Method

MagicColor employs a dual-UNet architecture (a main UNet plus a reference net, both initialized from Stable Diffusion 1.5) with a ControlNet-based sketch guider and a novel Instance Control Module (ICM) that uses DINOv2 spatial embeddings aligned via ROI-style interpolation to inject per-instance color identity as a latent control signal. A two-stage self-play training strategy addresses the data scarcity: Stage 1 trains on single-reference pairs sampled from anime video frames, while Stage 2 introduces multi-instance conditioning by randomly fusing, scaling, shuffling, and noising SAM-segmented instances to build per-instance semantic perception. Training is further stabilized by a re-weighted edge loss (combining perceptual loss with SyntheOcc structure-foreground-enhanced edge weighting in latent space) and a pixel-level color matching objective that establishes semantic correspondences between reference and target via diffusion feature maps, using cosine distance for matching and Euclidean distance for color feature alignment.

## Results

On the Animation test set (1,570 pairs), MagicColor achieves FID 28.95, PSNR 23.75, SSIM 0.783, and LPIPS 0.201, outperforming all five baselines on every metric. On the Hand-Drawn test set (100 pairs), it reaches FID 251.30, PSNR 10.55, SSIM 0.434, and LPIPS 0.431, again leading all competitors. The most notable margin is in LPIPS on Animation, where MagicColor (0.201) nearly halves the next-best MangaNinja (0.362), and in PSNR on Animation, where it scores 23.75 versus 16.93 for the closest GAN-based baseline RSIC.

## Baselines & Comparisons

MagicColor wins on all four metrics (FID, PSNR, SSIM, LPIPS) across both the Animation and Hand-Drawn test sets against every baseline. Against the GAN-based methods RSIC and SGA, the gains are substantial: on Animation, MagicColor improves PSNR from 16.93/19.00 to 23.75 and LPIPS from 0.508/0.454 to 0.201, indicating far better perceptual fidelity. Among diffusion-based competitors, the closest rival is MangaNinja, which achieves FID 43.16 and LPIPS 0.362 on Animation; MagicColor still leads by 33% in FID and 44% in LPIPS. AnimeDiffusion and ColorizeDiffusion trail further behind, with FIDs of 154.78 and 128.20 respectively on Animation, suggesting weaker color-semantic alignment. On the Hand-Drawn set, MagicColor's FID of 251.30 is roughly 44 points lower than the next-best MangaNinja (295.22), and its LPIPS of 0.431 is the only value below 0.5, confirming superior perceptual similarity on real-user sketches.

## Relation to Prior Work

MagicColor builds on the Latent Diffusion Model (Stable Diffusion) backbone with ControlNet-style conditional injection, extending the reference-based sketch colorization line (MangaNinja, AnimeDiffusion, ColorizeDiffusion) from single-reference to multi-instance colorization in a single forward pass. It repurposes DINOv2 spatial embeddings and SAM instance segmentation—tools originally developed for open-vocabulary detection and correspondence—into an Instance Control Module that aligns per-instance color semantics in latent space. The self-play training strategy (sampling two frames from the same anime sequence as reference/sketch pairs) is a practical departure from prior work that relied on curated multi-instance datasets, which the authors argue are infeasible to collect at scale.

## Why It Matters / Open Questions

The paper addresses a concrete production bottleneck in animation pipelines where identical characters must be recolored consistently across frames, and demonstrates that a single diffusion forward pass can replace the manual per-instance coloring loop. However, the evaluation is limited to anime-style content with a small hand-drawn test set (100 pairs), and the authors acknowledge that multi-object occlusion scenarios remain poorly handled. Open questions include whether the self-play strategy generalizes beyond anime to broader illustration styles, how performance scales with more than a handful of simultaneous instances, and whether the DINOv2-based instance control can be replaced by lighter-weight encoders for real-time use.

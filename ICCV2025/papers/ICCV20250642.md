## Problem

Pre-training Remote Sensing Foundation Models (RSFMs) traditionally requires centralized aggregation of large-scale data from multiple institutions, which raises geo-information security and competitive concerns. Federated self-supervised learning (FSSL) offers a privacy-preserving alternative, but faces a vicious cycle in remote sensing: data heterogeneity (diverse sensors, resolutions, geographies) causes severe model drift, which demands more frequent synchronization, amplifying communication costs for large foundation models, and communication compression in turn worsens drift. No prior work has jointly addressed both sides of this cycle for RSFM pre-training.

## Input / Output

Each of M institutional clients holds a private unlabeled remote sensing dataset (satellite, aerial, or multispectral imagery with spatial resolutions from 0.25 m to 25 m across diverse geographic regions), while the server maintains a supplementary public unlabeled dataset. The framework is backbone-agnostic within the Swin Transformer family (T/S/B/L) and supports both contrastive (DINO) and masked-image-modeling (SimMIM) self-supervised objectives. The output is a set of pre-trained foundation model weights that institutions can fine-tune on labeled data for downstream tasks such as scene classification, semantic segmentation, object detection, and change detection.

## Method

FedSense introduces federated mutual-guidance learning with two complementary mechanisms. The Server-to-Clients Guidance (SCG) mechanism formulates a drift-aware min-max optimization where an adversarial weight perturbation ε is computed to maximize parameter discrepancy between the local and global models, then used to update the client; a self-stabilized loss additionally aligns client features with a universal encoder pre-trained on ImageNet-22k, steering updates toward globally flat minima. The Clients-to-Server Guidance (CSG) mechanism reduces uplink communication to 1-bit via sign-based quantization with unbiased stochastic rounding and a momentum-based feedback error that compensates quantization loss across rounds (with periodic resetting). On the server side, federated similarity distillation clusters aggregated client models via K-means and matches the global model's similarity matrix on public data against a weighted consensus of local similarity matrices, injecting public-data knowledge without raw data sharing. The bidirectional design breaks the vicious cycle: SCG mitigates drift so fewer synchronization rounds are needed, while CSG keeps those rounds cheap.

## Results

FedSense achieves state-of-the-art performance across all four downstream task categories with the SimMIM framework: 96.33% OA on RESISC-45, 97.54% OA on AID, 81.66% IoU on Inria, 52.74% mIoU on LoveDA, 65.51% mAP on DIOR-R, 77.33% mAP on DOTA-v1.0, 73.21% F1 on LEVIR-CD+, and 35.43 SCS on SECOND. With the DINO framework, FedSense reaches 96.21% OA (RESISC-45), 81.96% IoU (Inria), 77.64% mAP (DOTA-v1.0), and 74.04% F1 (LEVIR-CD+). The 1-bit quantized variant retains over 96% OA on RESISC-45 with only ~0.2–0.5% degradation across tasks, demonstrating strong communication efficiency.

## Baselines & Comparisons

FedSense consistently outperforms all FSSL baselines across both SSL frameworks. Under SimMIM, FedSense surpasses SSL-FL by +1.12% OA on RESISC-45 and +1.37% on AID, while FedU² and FedMKD report no results for this framework. Under DINO, FedSense leads FedMKD (the strongest competitor) by +0.87% OA on RESISC-45 and +0.26% on AID, and beats L-DAWA by +1.98% and +1.16% respectively. Notably, FedU² degrades below ImageNet supervised pre-training on several tasks (e.g., 93.85% vs. 94.45% on RESISC-45), indicating vulnerability to data heterogeneity. For object detection, FedSense (DINO) achieves the best DOTA mAP (77.64%) by +0.08% over FedMKD, while for change detection it leads LEVIR-CD+ F1 by +0.34% over FedMKD. The 1-bit quantized FedSense incurs only 0.2–0.5% degradation and even slightly outperforms full-precision on SECOND (+0.06% SCS), suggesting the error-compensated quantization acts as implicit regularization.

## Relation to Prior Work

This paper extends federated self-supervised learning (FSSL) from cross-device natural-image settings to the cross-institution pre-training of remote sensing foundation models, a domain where data heterogeneity (sensor type, resolution, geography) is far more severe. It builds on FedPAQ's error-feedback quantization for the CSG mechanism and on adversarial-style weight perturbation for the SCG drift-mitigation term, but departs from prior FSSL methods (FedU², FedMKD, L-DAWA, FedEMA) by explicitly modeling the bidirectional coupling between model drift and communication cost as a 'vicious cycle' and addressing both simultaneously through a unified mutual-guidance framework. The paper also introduces server-side federated similarity distillation on public data, a component absent from prior FSSL work that leverages a shared unlabeled corpus to anchor the global model.

## Why It Matters / Open Questions

FedSense is the first framework to enable multi-institution collaborative pre-training of RSFMs without raw data exchange, directly addressing a practical bottleneck in Earth Observation where geo-information security and competitive interests prevent data pooling. The 1-bit quantization with error feedback achieving near-full-precision performance (≤0.23% degradation) makes the approach viable for bandwidth-constrained institutional networks. Open questions include whether the framework scales to multimodal RSFMs (optical + SAR + hyperspectral), whether the SCG perturbation strategy generalizes beyond Swin-T, and how the vicious-cycle dynamics change with larger client counts or more extreme non-IID splits. The one-shot FL collapse (LE=100) also highlights that periodic synchronization remains essential, limiting applicability in settings where only a single communication round is feasible.

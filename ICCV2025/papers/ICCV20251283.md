## Problem

Dialogue-based image generation requires decomposing multi-turn conversational intent into a coherent image prompt, but the optimal analysis pathway is undetermined—whether to first identify objects, understand scene context, or construct a prompt template. Existing vanilla methods feed the entire dialogue into a single LLM for direct prompt generation, lacking both a structured multi-step reasoning process and a mechanism to select among competing decomposition strategies.
![Teaser figure](../imgs/ICCV20251283/cropped_page0_idx0.webp)

## Input / Output

The method takes a sequence of N_t question-answer pairs (typically 10 rounds from VisDial) in natural conversational language describing a target image, and produces a single RGB image via a text-to-image model (Stable Diffusion or Janus-Pro). The dialogue is consumed incrementally at each node of a reasoning tree rather than as a monolithic input, and the final image is selected from up to 14 candidate images generated across the tree's nodes.

## Method

LTDC structures the reasoning as a binary tree (N_s=3 steps, N_i=2 expansions per node) where each node represents a sequential decomposition step generated by an LLM agent. Different branches diverge by starting with different initial analyses (e.g., object extraction vs. scene understanding vs. prompt template construction), expanding the search space beyond a single chain-of-thought. At each node, a second LLM converts the step instruction into a structured image-generation prompt, which is fed to a diffusion or autoregressive image model. A multi-modal LLM evaluator then scores each generated image against the original dialogue by computing the fraction of Q&A rounds correctly reflected in the image (a 0-to-1 correct-rate metric). The path through the tree yielding the highest cumulative evaluation score is selected, and its final image is the output—effectively converging divergent reasoning chains into a single controlled generation.

## Results

On the VisDial validation set, LTDC achieves 69.37% CLIP similarity and 70.71 LPIPS, outperforming the previous SOTA GILL (64.50% CLIP) by 4.87%. The enhanced variant LTDC* (using Janus-Pro + Deepseek-R1) reaches a new SOTA of 70.03% CLIP similarity. In a 100-sample human evaluation with 3 annotators, LTDC achieves 72.9% correct dialogue-to-image matching versus GILL's 58.3%, a 14.6% improvement in semantic coherence.

## Baselines & Comparisons

LTDC outperforms all three external baselines on CLIP similarity: GLIDE (58.70%), LDM/Stable Diffusion without LLM (62.20%), and GILL (64.50%), with the headline 4.87% gain over GILL being the most directly comparable since both use Stable Diffusion as the image generator. Against the vanilla (single-chain) implementations of the same LLMs, LTDC adds 1.96% CLIP over Vanilla(SC) with ChatGPT-4o-mini and 1.42% over Vanilla(JD) with Deepseek-R1, confirming that the multi-chain divergence-and-convergence structure itself contributes beyond simply using a stronger model. On LPIPS, gains are marginal (70.71 vs. 71.40 for GILL) because LPIPS is dominated by the underlying image generator's perceptual quality rather than semantic alignment. In the 100-sample human evaluation, LTDC's 72.9% correct-dialogue ratio substantially exceeds GILL's 58.3%, indicating the improvement is not an artifact of CLIP's embedding space but reflects genuine semantic fidelity to the dialogue content.

## Relation to Prior Work

This paper repurposes chain-of-thought and tree-of-thought reasoning paradigms from pure text LLMs into a multi-modal dialogue-to-image pipeline, where an LLM decomposes multi-turn Q&A dialogues into sequential thinking steps rather than producing a single monolithic prompt. It departs from prior dialogue-based image generation work (notably GILL, which uses a single LLM pass to convert dialogue to a prompt) by introducing a divergent multi-chain structure with a convergence mechanism: a multi-modal LLM evaluates each intermediate generated image against the original dialogue to select the best reasoning path. The multi-agent collaboration literature (MetaGPT, MacNet) informs the role-based agent design, but this paper is the first to apply such structured multi-chain reasoning specifically to the dialogue-to-image generation task with per-node image evaluation.

## Why It Matters / Open Questions

The framework offers a principled way to handle the ambiguity inherent in conversational image requests, where the optimal decomposition strategy (scene-first vs. object-first vs. template-first) is not known a priori. However, the practical ceiling is constrained by the evaluation LLM's accuracy (~81% on ground-truth dialogues), meaning the convergence step can select suboptimal chains. The paper is limited to the synthetic VisDial dataset and does not address real-world dynamic user interactions (e.g., mid-conversation requirement changes), which the authors acknowledge as a key open problem. Future work on real interaction datasets and more reliable evaluation signals would be needed to validate the framework's utility beyond benchmark settings.

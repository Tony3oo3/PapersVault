## Problem

How MLLMs process visual information at the attention-head level remains poorly understood, and existing KV-Cache compression methods treat all heads uniformly, ignoring that only a tiny subset of heads actually encodes visual semantics. This uniform treatment wastes cache budget on text-specialized heads while under-allocating to the sparse visual heads that carry critical cross-modal information, leading to suboptimal accuracy-efficiency trade-offs in multimodal inference.

## Input / Output

The method operates on standard MLLM inputs: an RGB image (encoded via CLIP/SigLIP into visual tokens) and a short text instruction, where visual tokens constitute 90–99% of the input sequence (e.g., ~2,400 tokens for LLaVA-NeXT, ~4,800 for Qwen2-VL on DocVQA). The output is autoregressively generated text, but the key intermediate artifact is a per-head compressed KV-Cache: each of the L×H attention heads retains only a budget-specific subset of key-value pairs rather than the full sequence, reducing memory from O(N) to O(budget) per head during decoding.

## Method

SparseMM is a training-free KV-Cache optimization built on the discovery that <5% of attention heads are 'visual heads' actively engaged in visual understanding. Visual heads are identified via an OCR-based scoring protocol: for each generated token, its spatial region is mapped to image patches, and a head receives credit if its attention argmax falls within those patches, yielding a normalized L×H visual score matrix. At inference time, each head's KV-Cache budget is allocated through a three-part mechanism: a fixed local window (w=32 recent tokens), a uniform baseline (ρ=0.1 of remaining budget split equally across heads), and a score-proportional allocation where the residual budget is distributed in proportion to each head's visual score. KV selection within each head's budget uses a SnapKV-style observation window (last 32 query positions) to rank keys by average attention weight, retaining the top-K pairs. This asymmetric allocation preserves visual semantics in high-scoring heads while aggressively compressing text-specialized heads, achieving up to 1.38× real-time speedup and 52% memory reduction with near-zero accuracy loss.

## Results

On LLaVA-NeXT-Vicuna-7B with a 256 KV-Cache budget and 16K input tokens, SparseMM achieves near-full-model accuracy across all five VQA benchmarks (e.g., 0.68 on DocVQA, 0.52 on OCRBench, 0.65 on TextVQA) while reducing decoding latency by 30% (37.1 ms vs. 52.9 ms for FullKV). At 32K input tokens, LLaVA-NeXT-Mistral-7B achieves ~50% decoding acceleration and a 5 GB peak-memory reduction. The paper reports 1.38× real-time acceleration and 52% memory reduction overall, with Qwen2-VL-7B-Instruct matching full-cache performance on DocVQA using only 5.3% of the original KV-Cache.

## Baselines & Comparisons

SparseMM consistently outperforms all three KV-Cache compression baselines on every accuracy metric while maintaining comparable decoding latency. Against SnapKV, SparseMM gains +0.04 on DocVQA, +0.06 on OCRBench, and +0.08 on TextCaps, with only a 1.8 ms latency difference (37.1 vs. 35.3 ms). Against PyramidKV, the accuracy advantage is +0.03 to +0.08 across benchmarks, though PyramidKV is marginally faster (34.9 ms). Against AdaKV, SparseMM leads by +0.03 to +0.07 in accuracy at essentially the same latency (37.1 vs. 37.3 ms). The key distinction is that SparseMM preserves full-model accuracy (≤0.01 drop) where all baselines suffer 0.03–0.08 drops, demonstrating that head-level visual-score allocation is more effective than uniform or layer-hierarchical budget strategies for retaining visual semantics.

## Relation to Prior Work

This paper extends the KV-Cache compression line (SnapKV, PyramidKV, AdaKV) by introducing a modality-aware, head-level budget allocation strategy. While SnapKV provides the observation-window mechanism for selecting important KV entries and AdaKV allocates budgets per head based on intra-layer attention distributions, neither accounts for the cross-modal asymmetry between visual and textual processing. The key departure is a training-free, OCR-anchored identification of 'visual heads' (heads whose argmax attention consistently lands on image tokens), which then drives an asymmetric three-part cache allocation (local window + uniform baseline + score-proportional) that prior uniform or layer-wise methods do not exploit.

## Why It Matters / Open Questions

The finding that fewer than 5% of attention heads are visual-active across both MHA and GQA architectures is a useful architectural insight that could inform future MLLM design (e.g., dedicated visual sub-networks or head pruning during pre-training). Practically, the 52% memory reduction and 1.38× speedup at near-lossless accuracy make MLLM deployment on resource-constrained hardware more feasible. Open questions include whether the OCR-based identification generalizes to video, 3D, or audio modalities, whether visual head sparsity persists after further multimodal pre-training at scale, and whether the asymmetric budget can be extended to training-time head pruning or quantization.

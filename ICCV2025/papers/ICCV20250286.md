## Problem

Existing autoregressive mesh generation methods tokenize each face as three vertices (nine tokens per face), producing long, redundant sequences that limit generation to ~800 faces and degrade sequence learning quality. The paper identifies mesh tokenization as the primary bottleneck preventing generation of complex, high-face-count Artist-Created Meshes.
![Teaser figure](../imgs/ICCV20250286/cropped_page1_idx0.webp)

## Input / Output

The model takes a point cloud of 8192 points (encoded by a pretrained point cloud encoder into a fixed-length prefix token sequence) and an optional face count embedding as input, and autoregressively generates a token sequence of discretized vertex coordinates plus special tokens that detokenizes into a triangle mesh of up to 1600 faces aligned to the input shape. The output mesh is a watertight Artist-Created Mesh suitable for direct use in 3D asset pipelines.

## Method

The core contribution is Adjacent Mesh Tokenization (AMT), which encodes each face with a single vertex whenever it shares an edge with the previously encoded face, reducing average sequence length by ~50% (nearly 3× in ideal cases). When no adjacent face is available, a special '&' token signals a restart from the next unencoded face; an optional '$' swap token handles edge-sharing faces that don't align with the last two vertices. The tokenized sequence (discretized coordinates + special tokens) is fed to an OPT-350M decoder-only transformer with the point cloud encoding as prefix, trained with cross-entropy loss on 230K point cloud–mesh pairs. Additional design choices include face count conditioning via an embedding book, position-specific embeddings distinguishing three-vertex vs. one-vertex face tokens, and Masking Invalid Predictions during inference to prevent structurally invalid outputs.

## Results

On the Objaverse evaluation set (meshes up to 400 faces, 10K sampled points), AMT achieves a Chamfer Distance of 2.348×10⁻² and Normal Consistency of 0.904, matching or slightly exceeding the Baseline (CD 2.478×10⁻², NC 0.893) while halving the token sequence length (S_Ratio 0.492 vs 1.000). In the full MeshAnything V2 ablation (meshes up to 1600 faces, 100K points), V2 with AMT improves over V2 without AMT on all quality metrics (CD 0.874 vs 0.895, ECD 4.721 vs 4.832, NC 0.933 vs 0.924) while reducing sequence length by ~50% (S_Ratio 0.497 vs 1.000). The variant without AMT consumed nearly 2× the GPU hours for the same number of training iterations.

## Baselines & Comparisons

Against the naive three-vertex-per-face Baseline, AMT achieves a lower Chamfer Distance (2.348 vs 2.478×10⁻²) and higher Normal Consistency (0.904 vs 0.893) while compressing the token sequence to 49.2% of its original length, confirming that shorter sequences do not degrade mesh quality. Against PolyGen(AMT), which combines PolyGen's vertex-then-face ordering with AMT, AMT wins decisively on mesh quality (CD 2.348 vs 3.226, NC 0.904 vs 0.872) despite a slightly higher S_Ratio (0.492 vs 0.372), indicating that PolyGen's two-phase structure introduces sequence-learning difficulty that outweighs its extra compression. The Unsort ablation (no vertex/face sorting) degrades severely (CD 8.151, NC 0.794), validating that regularity in token ordering is as critical as compactness. In the full V2 ablation (Table 1), AMT-equipped V2 outperforms the no-AMT variant on CD, ECD, and NC while halving sequence length, and the no-AMT variant required ~2× GPU hours for the same training iterations.

## Relation to Prior Work

This paper extends MeshAnything [5] and the broader autoregressive mesh generation line (PolyGen [15], MeshGPT [19], MeshXL [4], PivotMesh [28]) by replacing the standard three-vertex-per-face tokenization with Adjacent Mesh Tokenization (AMT), which encodes each face with a single vertex when an adjacent face is identifiable. The autoregressive transformer architecture, point-cloud conditioning, and overall training/inference pipeline remain unchanged from MeshAnything V1; the contribution is squarely in the tokenization layer. The paper also incorporates Masking Invalid Predictions from PolyGen [15] and introduces a face-count conditioning mechanism not present in prior work.

## Why It Matters / Open Questions

The practical impact is substantial: AMT halves the token sequence length on average, translating to roughly a fourfold reduction in attention compute and memory, and doubles the maximum generatable face count from 800 to 1600 without architectural changes—directly addressing a key bottleneck for 3D asset production pipelines. The ablation showing that PolyGen(AMT) achieves the best compression ratio yet worse mesh quality than AMT reinforces the principle that sequence regularity matters as much as compactness, a useful design guideline for future tokenization schemes. Open questions include whether AMT scales beyond 1600 faces, how it generalizes to non-triangle or highly irregular topologies, and whether the 50% compression is near the theoretical limit for artist-created meshes.

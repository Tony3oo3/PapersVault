## Problem

Prior object state prediction methods focus on a single object undergoing one or a few state changes, while real-world procedural tasks involve multiple objects whose states evolve across many sequential actions. No dataset exists to evaluate this multi-object setting, and densely annotating per-frame object states across long videos is prohibitively expensive, leaving the problem of predicting multiple object state changes through actions entirely unaddressed.
![Teaser figure](../imgs/ICCV20252552/cropped_page0_idx0.webp)

## Input / Output

The method takes a sequence of T egocentric RGB video frames (H×W×3) as input and produces, for each frame, a binary object-state label matrix y^(t) ∈ {0,1}^{O×S} indicating which of O objects are in which of S possible states — a multi-label classification problem per frame. In the weakly-supervised training setting, the only available supervision is per-frame action class labels (z^(t) ∈ {1,…,C}) rather than object-state annotations; object-state pseudo-labels are generated automatically. At inference, the final prediction is a weighted combination of the raw MOSP output and the SAI-refined output, controlled by a hyperparameter β.

## Method

The framework has three core components. First, a Pseudo-Label Acquisition (PLA) pipeline generates per-frame object-state pseudo-labels in five stages: LLM-based (GPT-4o) state description, summarization via k-means clustering on text embeddings, state refinement to recover missed attributes, Point-of-Change estimation using CLIP cosine similarity between frame embeddings and state text embeddings to localize state transitions within action segments, and object visibility detection via GLIP. Second, the MOSP model uses an MSTCN++ temporal convolutional backbone with a sigmoid multi-label head trained by weighted binary cross-entropy to predict all object-state pairs per frame. Third, the State-Action Interaction (SAI) module exploits the intrinsic action–state correlation: it precomputes empirical conditional probabilities P_A(u|a) and P_B(u|a) from pseudo-labels, uses a TAS branch to predict framewise actions, and fuses these via a learnable 1D convolution into state-segment likelihoods that serve as complementary supervision during training and complementary predictions at inference. The full system is trained jointly with L = L_MOSP + L_SAI + L_TAS, and I3D features pre-trained on Kinetics provide the visual backbone.

## Results

On MOSCATO-EgoPER, the full method (MOSP + SAI) achieves F1-Max of 52.83 and mAP of 35.06, outperforming the zero-shot CLIP baseline (F1-Max 27.11) and InternVideo2 (F1-Max 27.05) by over 25 points. On MOSCATO-CMU, the method reaches F1-Max 35.61 and mAP 11.50, compared to CLIP's 12.15 and InternVideo2's 9.36. The SAI module contributes an additional 2.84% F1-Max gain on EgoPER and 5.06% on CMU over the MOSP-only variant. On the more challenging EGTEA subset (longer videos, diverse tasks), all methods struggle, with the full method achieving F1-Max 8.04 and mAP 2.78 versus CLIP's 5.97 and InternVideo2's 5.66.

## Baselines & Comparisons

The paper compares against two zero-shot VLM baselines: CLIP (ViT-L/14, image-based) and InternVideo2 (video-based). On MOSCATO-EgoPER, the full method (w/ SAI) achieves F1-Max 52.83, surpassing CLIP (27.11) by 25.72 points and InternVideo2 (27.05) by 25.78 points; on MOSCATO-CMU, it reaches 35.61 versus CLIP's 12.15 and InternVideo2's 9.36. The gap is even more dramatic on segment-wise metrics: on EgoPER F1@0.5, the method scores 43.42 versus 0.28 (CLIP) and 3.76 (InternVideo2). On the harder EGTEA subset, the advantage narrows (F1-Max 8.04 vs. 5.97/5.66), and the MOSP-only variant actually achieves a higher F1-Max (12.85) than the full method, though SAI recovers segment-wise performance (F1@0.5: 6.45 vs. 0.0). The Pseudo-Labels row (which uses ground-truth action labels on test videos) still leads on EGTEA segment-wise metrics, indicating that predicted actions introduce some error that SAI partially compensates for.

## Relation to Prior Work

This paper extends the single-object state prediction line (ChangeIt, HowToChange, MOST) to a multi-object, multi-change setting in long procedural videos, where prior methods handled at most one object per video. It repurposes the MSTCN++ temporal convolutional backbone from temporal action segmentation and introduces a State-Action Interaction module that exploits the reverse dependency (actions informing states) not previously explored in state prediction literature. The Pseudo-Label Acquisition pipeline is a novel multi-stage combination of LLM-based state reasoning, CLIP-based point-of-change localization, and GLIP-based visibility detection, departing from prior work that relied on manual annotations or single-object CLIP matching.

## Why It Matters / Open Questions

MOSCATO is the first benchmark enabling evaluation of multi-object state tracking across long procedural videos, filling a clear gap where no annotated dataset existed. The weakly-supervised formulation (training on action labels only) is practically important given the prohibitive cost of dense per-frame state annotation. Key limitations include the closed-vocabulary setting, the assumption that all objects in an action change state simultaneously, and the reliance on pseudo-labels whose quality still bounds performance (the Pseudo-Labels baseline using GT actions outperforms the trained model on EGTEA segment-wise metrics). Open questions include extending to open-vocabulary states, handling asynchronous state changes within a single action, and scaling to more diverse procedural domains beyond cooking.

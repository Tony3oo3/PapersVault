## Problem

Model merging via task arithmetic requires storing multiple full-precision fine-tuned checkpoints, creating a severe memory bottleneck (e.g., 22.8 GB for 20 ViT-L/14 tasks) that limits scalability to larger models and more diverse tasks in resource-constrained settings. Existing compression approaches like TALL-Mask and TSV-C rely on task-specific binary masks or SVD, lacking a universally applicable, plug-and-play solution.

## Input / Output

The method consumes a single shared pre-trained checkpoint plus T fine-tuned checkpoints (one per task) and bit-precision parameters (a single bit width for TVQ, or separate base-bit b_b and offset-bit b_o for RTVQ). It outputs quantized task vectors—per-task offset vectors plus one globally shared base vector for RTVQ—that are directly compatible with any existing task-vector merging framework (Task Arithmetic, Ties, AdaMerging, etc.) without architectural or algorithmic modifications. The pre-trained checkpoint is never stored per-task, so per-task storage is only the quantized task vector (or offset + amortized base).

## Method

The key observation is that task vectors (τ_t = θ_ft^t − θ_pre) exhibit a weight range roughly an order of magnitude narrower than full fine-tuned weights, so asymmetric quantization of task vectors incurs far less rounding error than quantizing checkpoints directly. TVQ exploits this by applying standard asymmetric quantization to each task vector, achieving stable performance down to 3-bit. For the ultra-low-bit regime (≤2-bit), RTVQ decomposes each task vector into a shared base vector (θ_ft_avg − θ_pre, quantized at higher precision b_b) and a per-task offset vector (θ_ft^t − θ_ft_avg, quantized at lower precision b_o), so the effective per-task cost is b_o + b_b/T bits. A quantization error correction step first dequantizes the base vector to calibrate the averaged checkpoint before computing offsets, reducing cumulative error. Because only the stored checkpoints change, the quantized vectors drop into any existing merging pipeline unchanged.

## Results

On 8-task image classification with ViT-B/32, TVQ at 4-bit preserves FP32-level accuracy across all merging methods (e.g., Task Arithmetic: 69.1% vs. 69.2% FP32; AdaMerging: 81.5% vs. 81.8%), while 3-bit TVQ even surpasses FP32 for several methods (Task Arithmetic: 71.2%, +2.0; LiNeS: 74.7%, +0.6). RTVQ (3-bit base + 2-bit offset, ~2.375 bits/task) recovers performance at ultra-low precision, matching or exceeding FP32 (Task Arithmetic: 70.2%, +1.0; AdaMerging: 82.8%, +1.0). In terms of storage, RTVQ reduces checkpoint memory to 7.5% of FP32 (1.7 GB vs. 22.8 GB for 20 tasks with ViT-L/14), and 3-bit TVQ achieves 95.9% accuracy at 18.3 Gb, outperforming TALL-Mask (95.7% at 23.1 Gb) and TSV-C (95.7% at 20.7 Gb).

## Baselines & Comparisons

The paper's central comparison is between three quantization strategies (FQ, TVQ, RTVQ) applied to the same set of merging methods. FQ (direct fine-tuned checkpoint quantization) fails catastrophically below 8-bit, dropping to ~4% accuracy at 4-bit for all methods, confirming that the wide weight range of full checkpoints is incompatible with low-precision quantization. TVQ at 4-bit matches FP32 within 0.1–0.3% for Task Arithmetic, LiNeS, and Consensus TA, and at 3-bit actually improves performance by 0.2–2.0% (attributed to a regularization/anti-overfitting effect). RTVQ at ~2.375 bits/task recovers most of the 2-bit TVQ degradation: Task Arithmetic goes from 62.1% (2-bit TVQ) to 70.2% (RTVQ), and AdaMerging from 78.1% to 82.8%. For dense prediction on NYUv2 (Table 3), TVQ at 4-bit maintains FP32 performance across segmentation, depth, and normal estimation, while RTVQ (2-bit base + 2-bit offset) significantly outperforms 2-bit TVQ, e.g., improving EMR-Merging segmentation from 21.3 to 34.1 mIoU. In the storage-vs-accuracy comparison (Table 6), 3-bit TVQ achieves 95.9% accuracy at 18.3 Gb, beating both TALL-Mask (95.7% at 23.1 Gb) and TSV-C (95.7% at 20.7 Gb), and combining TVQ with TSV-C further reduces storage to 11.9 Gb with no accuracy loss.

## Relation to Prior Work

This paper builds directly on Task Arithmetic [17], which represents each task as the weight difference between fine-tuned and pre-trained checkpoints, and on the broader model merging literature (Ties-Merging, AdaMerging, EMR-Merging, LiNeS). Its key departure is applying post-training quantization to the task vectors rather than to full fine-tuned checkpoints, exploiting the observation that task vectors have an order-of-magnitude narrower weight range. The Residual Task Vector Quantization (RTVQ) further extends this by decomposing task vectors into a shared base and per-task offsets, drawing on the residual decomposition idea from quantization literature but applying it to the multi-task merging setting. Unlike prior compression approaches for merging (TALL-Mask, TSV-C) that rely on binary masks or SVD, TVQ/RTVQ operate purely on checkpoint storage and integrate seamlessly with any existing task-vector-based merging method.

## Why It Matters / Open Questions

The practical impact is significant: reducing checkpoint storage to ~8% of FP32 (e.g., 1.7 GB vs. 22.8 GB for 20 ViT-L/14 tasks) makes multi-task model merging feasible on resource-constrained hardware like NVIDIA Jetson Nano, which prior work effectively excluded. The method's drop-in compatibility with existing merging frameworks lowers the adoption barrier considerably. Open questions include whether the approach scales to very large models (e.g., 7B+ parameters) or hundreds of tasks, whether the observed regularization benefit of quantization (improved cross-task generalization) can be harnessed more deliberately, and how the method performs when tasks are highly heterogeneous in architecture or training procedure. The dense prediction evaluation, while valuable, is limited to a single benchmark (NYUv2) and a single backbone (ResNet-50).

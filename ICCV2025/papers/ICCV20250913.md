## Problem

Existing Single Image Flare Removal (SIFR) methods degrade significantly when off-frame light sources are incomplete or entirely absent, leaving residual flare artifacts and reduced realism. This occurs because SIFR models rely on complete light source context to accurately model and remove flare patterns, yet real-world captures frequently crop or partially occlude the illuminating source. No prior work addresses this specific failure mode with a dedicated reconstruction strategy.
![Teaser figure](../imgs/ICCV20250913/cropped_page0_idx1.webp)

## Input / Output

The method takes a flare-corrupted RGB image I_in ∈ R^{H×W×3} with an incomplete or missing off-frame light source and expands it to a larger canvas I_M ∈ R^{H'×W'×3} (H'>H, W'>W) with a corresponding binary mask M defining the outpainting region. It produces an outpainted image I_out with reconstructed light sources and physically consistent flare artifacts, along with a predicted light source mask M_L generated from N parameterized circular sources (x, y, r) with confidence scores. The outpainted image then serves as input to any existing SIFR model, from which the original H×W region is extracted as the final flare-free output.

## Method

LightsOut is a three-stage plug-and-play pipeline: (1) a multitask regression module (CNN feature extractor + two MLP heads) predicts N light source parameters (x, y, r) and confidence scores, supervised by smooth-L1 position loss with bipartite matching for permutation invariance and binary cross-entropy confidence loss, combined via uncertainty-aware weighting; (2) a LoRA-fine-tuned Stable Diffusion v2 inpainting model performs outpainting conditioned on the rendered light source mask M_L and a BLIP-2-generated text prompt, using noise reinjection at intermediate denoising steps and RGB-space alpha composition (rather than latent-space blending) to preserve existing regions; (3) the outpainted image feeds into any SIFR model without retraining. The light source conditioning module enforces an L2 loss between generated and predicted light source maps during training, ensuring physically plausible light placement in the outpainted region.

## Results

On Flare7K Real with the Flare7K++ SIFR model, LightsOut achieves a PSNR of 28.41 dB (no light source) and 28.15 dB (incomplete light source), improving over direct input by +2.12 and +2.08 dB respectively. On Flare7K Synthetic, the corresponding PSNR values are 33.91 and 31.38 dB. Across all three SIFR backbones (Zhou et al., Flare7K++, MFDNet) and both scenarios, LightsOut consistently outperforms SD-Inpainting, SDXL-Inpainting, and PowerPaint on PSNR, SSIM, and LPIPS, with the largest gains observed when the SIFR model is Flare7K++ (e.g., +1.43 dB over SD-Inpainting on Real, no-light-source).

## Baselines & Comparisons

LightsOut outperforms all three diffusion-based outpainting baselines (SD-Inpainting, SDXL-Inpainting, PowerPaint) across every SIFR model and scenario. Against SD-Inpainting, the closest competitor, LightsOut gains +0.43 dB PSNR on Flare7K Real (Flare7K++ backbone, no light source: 28.41 vs 27.98) and +0.13 dB on the incomplete-light-source setting (28.15 vs 28.02). SDXL-Inpainting and PowerPaint lag further behind, with PowerPaint showing particularly large LPIPS degradation (e.g., 0.0839 vs 0.0397 on Flare7K Real, no light source). Against the retrained Flare7K++ SIFR model (explicitly trained on incomplete/no-light-source data), LightsOut still achieves a +1.38 dB PSNR advantage (28.41 vs 27.03 on Real, no light source), confirming that the outpainting preprocessing strategy is more effective than simply retraining the SIFR model on the challenging distribution.

## Relation to Prior Work

This paper positions itself as a plug-and-play preprocessing step for existing SIFR methods (Zhou et al., Flare7K++, MFDNet) rather than a new flare removal architecture. It builds on Stable Diffusion inpainting with LoRA fine-tuning for task-specific adaptation, borrows noise reinjection from Repaint and Beyour-Outpainter, and introduces a multitask regression module (with bipartite matching and uncertainty-aware loss weighting) to predict off-frame light source parameters that condition the diffusion process. The key departure from prior diffusion-based outpainting work (SD-Inpainting, SDXL, PowerPaint) is the explicit physical conditioning on predicted light source geometry, which standard generative models lack.

## Why It Matters / Open Questions

The plug-and-play design means practitioners can immediately improve any existing SIFR pipeline without retraining, which has practical value for deployment in autonomous driving and object detection where flare artifacts degrade downstream tasks. A notable finding is that even retraining Flare7K++ specifically on off-frame data (Table 3) still underperforms the outpainting preprocessing, suggesting the bottleneck is fundamentally missing spatial information rather than model capacity. The main limitation is the added computational overhead of the outpainting stage, and the authors note that end-to-end joint optimization could reduce this cost. Open questions include whether the approach generalizes to video sequences or to non-circular light source geometries.

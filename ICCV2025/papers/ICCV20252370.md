## Problem

Existing CLIP-based face anti-spoofing methods fail to directly exploit CLIP's patch embedding tokens, losing fine-grained local spoofing artifacts (e.g., abnormal textures, light reflections) when projecting image features into the text embedding space for prompt generation. Additionally, these methods rely on a single fixed text prompt per class (e.g., 'live' vs. 'fake'), which limits generalization because vanilla CLIP was not trained for FAS and a single word may carry ambiguous semantics. The paper addresses both gaps by introducing multi-paraphrased texts and a slot-attention mechanism that operates directly on patch embeddings.

## Input / Output

The method takes a 224×224 RGB face image, which CLIP ViT-B/16 encodes into 196 patch embeddings plus a CLS token, and M=3 paraphrased text pairs (generated via ChatGPT from 'real face'/'spoof face') combined with a learnable CoOp context prompt of length 16. The primary output is a binary real/spoof classification, but the model also produces per-view attention scores (one per paraphrased text) that can be visualized as spatial heatmaps showing which image regions each text perspective attends to, providing interpretable evidence for the decision.

## Method

MVP-FAS comprises two modules built on CLIP's frozen text encoder and fine-tuned image encoder. Multi-View Slot Attention (MVS) broadcasts the CLS token across all patch embeddings to create global-aware queries, then performs slot attention where these queries attend to keys/values derived from M paraphrased positive and negative text embeddings; a GRU sequentially integrates the weighted text values into each patch, and a residual MLP refines the result, yielding multi-view features that capture local details from multiple textual perspectives. Multi-Text Patch Alignment (MTPA) computes a multi-text anchor (mean of all paraphrased text embeddings per class), calculates cosine similarity between each patch and its class-specific anchor, applies a sigmoid soft mask (α=10) to suppress low-similarity patches, and trains an auxiliary classifier on the masked patches to explicitly align informative local regions with text semantics. The total loss combines the main classification cross-entropy with the MTPA auxiliary loss, and the key design choice—using slot attention rather than cross-attention or simple similarity—preserves local patch information while enabling global text-to-patch assignment across multiple semantic views.

## Results

On Protocol 1 (MSU-MFSD, CASIA-FASD, Idiap, OULU-NPU), MVP-FAS achieves an average HTER of 1.82%, AUC of 99.70%, and TPR@FPR=1% of 96.06%, outperforming the previous SOTA BUDoPT (2.62% HTER, 83.99% TPR@FPR=1%) by 0.8%p in HTER and 12.07%p in TPR@FPR=1%. On Protocol 2 (CASIA-SURF, CASIA CeFA, WMCA), MVP-FAS achieves 7.68% average HTER, reducing the gap by 2.74%p over S-CPTL (10.42%). The method also reduces cross-scenario HTER variance to 0.7% (vs. 1.2% for BUDoPT), indicating more consistent generalization across attack types.

## Baselines & Comparisons

MVP-FAS achieves the best average HTER across all 23 compared baselines on both protocols, with no scenario where it underperforms any competitor. Against the closest CLIP-based competitors, MVP-FAS reduces HTER by 0.8%p over BUDoPT (2.62→1.82), 1.51%p over FGPL (3.01→1.82), and 1.51%p over S-CPTL (3.33→1.82) on Protocol 1. The most dramatic gain is in TPR@FPR=1%: MVP-FAS reaches 96.06% versus 83.99% for CFPL and BUDoPT, a 12+ point improvement critical for high-security deployment. On Protocol 2, MVP-FAS (7.68% avg HTER) outperforms S-CPTL (10.42%) by 2.74%p and CFPL (10.88%) by 3.20%p, with particularly large margins on the WMCA target (4.57% vs. 8.99% for S-CPTL). Among non-CLIP domain generalization methods (SA-FAS, IADG, SSDG-R, SSAN-R), MVP-FAS leads by 4–9%p in average HTER, confirming that the VLM-based multi-view approach substantially surpasses purely visual domain generalization strategies.

## Relation to Prior Work

This paper extends the CLIP-based face anti-spoofing line (FLIP, CFPL, FGPL, S-CPTL, BUDoPT) by directly operating on CLIP's patch embeddings rather than projecting image features into the text embedding space via prompt learning. It repurposes slot attention (Locatello et al.) in an inverted role—using text embeddings as keys/values and global-aware patch embeddings as queries—rather than the standard learnable-slot formulation, and combines this with a multi-text paraphrasing strategy inspired by CoOp-style learnable prompts. The patch-level alignment module (MTPA) draws on recent CLIP patch-text alignment work (PACL, FM-CLIP) but extends it to multiple semantically equivalent texts with soft masking, a combination not previously explored.

## Why It Matters / Open Questions

The large TPR@FPR=1% gains (from ~84% to ~96% on Protocol 1) are practically significant for high-security biometric systems where false positives are costly. The multi-text paraphrasing idea is simple and potentially transferable to other VLM-based classification tasks where a single class label is semantically ambiguous. However, the approach depends on ChatGPT-generated paraphrases and is validated only on 2D face images across seven datasets; whether the multi-view slot attention mechanism generalizes to other fine-grained recognition tasks or to 3D/multimodal FAS remains open. The diminishing returns beyond M=3 views also suggest a practical ceiling on how much diversity in text helps.

## Problem

Existing 3D occupancy prediction methods operate offline from one or a few fixed views, making them unsuitable for embodied agents that must progressively build a global scene understanding through sequential monocular observations. No prior work addresses the task of maintaining a consistent, globally coherent 3D occupancy representation that is updated online as an agent explores an indoor scene from varying positions and perspectives using only RGB input.
![Teaser figure](../imgs/ICCV20250578/cropped_page0_idx0.webp)

## Input / Output

The method consumes a streaming sequence of monocular RGB images (480×640) paired with 3×4 camera extrinsics, processed one frame at a time as the agent moves through the scene. It maintains an explicit global memory of 3D semantic Gaussians (initialized at 0.16 m intervals in world coordinates) and outputs a full-scene 3D semantic occupancy grid (X_room × Y_room × Z_room × 12 classes at 0.08 m resolution) obtainable at any time via Gaussian-to-voxel splatting. The evaluated scenes comprise 30 posed frames each, with ground truth defined as the union of all explored frustums.

## Method

EmbodiedOcc represents the scene as a set of 3D semantic Gaussians (mean, scale, rotation, opacity, semantic logits) stored in an explicit global memory, initialized uniformly and progressively refined. A local refinement module extracts semantic features via a pre-trained EfficientNet-B7 and structural features via a frozen DepthAnything-V2 depth map fed through a depth-aware MLP, then integrates both into the Gaussians within the current frustum using 3D sparse convolution and deformable cross-attention to produce update deltas. A confidence mechanism (tag γ and value θ) ensures previously updated Gaussians receive only partial refinement while never-seen Gaussians undergo full updates, preserving global consistency during re-exploration. The framework is trained in two stages—first the local module on Occ-ScanNet with focal, Lovász-softmax, and scene-class affinity losses, then the full embodied pipeline on EmbodiedOcc-ScanNet—enabling the agent to improve its prediction upon revisiting previously explored regions.

## Results

On the local occupancy prediction task (Occ-ScanNet), EmbodiedOcc achieves 53.55 IoU and 45.15 mIoU, surpassing the strongest baseline SurroundOcc (42.52 IoU, 30.83 mIoU) by over 11 IoU points. On the novel embodied occupancy prediction task (EmbodiedOcc-ScanNet, 30 frames per scene), EmbodiedOcc achieves 51.52 IoU and 42.53 mIoU, outperforming the SplicingOcc baseline (49.01 IoU, 40.74 mIoU) by 2.5 IoU points. The Look-Back experiment further confirms that revisiting previously explored regions improves prediction (e.g., 41.17 vs 40.86 mIoU at K=8), validating the Gaussian memory mechanism.

## Baselines & Comparisons

EmbodiedOcc outperforms all five baselines on both local and embodied tasks. On local prediction (Occ-ScanNet), it leads SurroundOcc (42.52 IoU) by 11.03 IoU and GaussianFormer (40.91 IoU) by 12.64 IoU, with particularly large gains on fine-grained categories like ceiling (39.60 vs 18.90) and wall (41.40 vs 24.80). On the embodied task, the strongest baseline is SplicingOcc (49.01 IoU), which simply stitches local predictions together; EmbodiedOcc improves upon it by 2.51 IoU, demonstrating that the Gaussian memory and confidence-based fusion provide meaningful global consistency beyond naive splicing. The driving-scene methods (TPVFormer, SurroundOcc, GaussianFormer) perform poorly in the embodied setting (35–38 IoU) because they lack any global memory mechanism and treat each frame independently. MonoScene and ISO, while designed for indoor monocular settings, are only compared on the local task and trail EmbodiedOcc by 11–12 IoU points, confirming that the depth-aware branch and Gaussian representation are critical for indoor fine-grained structure.

## Relation to Prior Work

This paper extends the 3D Gaussian Splatting-based occupancy prediction paradigm from GaussianFormer [13] (which handles multi-view outdoor scenes) to an online, RGB-only, embodied indoor setting. It inherits the Gaussian-to-voxel splatting mechanism and the deformable cross-attention feature integration from GaussianFormer, and the monocular occupancy prediction formulation and loss design from MonoScene [2]. The key departure is the introduction of an explicit Gaussian memory with confidence-based refinement, enabling progressive global scene understanding from sequential monocular observations—something neither the offline monocular methods (MonoScene, ISO) nor the multi-view driving methods (TPV-Former, SurroundOcc) address.

## Why It Matters / Open Questions

The paper provides a practical task formulation and benchmark for embodied agents that must build 3D scene understanding incrementally from RGB-only inputs, a setting that mirrors real robot deployment but was previously unaddressed in the occupancy prediction literature. The Gaussian memory with confidence refinement is an elegant mechanism that naturally handles re-exploration and maintains global consistency, and the Look-Back experiments validate this design. However, the evaluation is limited to ScanNet-scale indoor scenes with only 30 frames per scene, and the embodied baselines (driving methods adapted by voting, simple splicing) are relatively weak, leaving open questions about scalability to larger environments, longer trajectories, and integration with downstream navigation or manipulation tasks.

## Problem

While 2D visual pre-training (R3M, MVP, VC-1) has enabled data-efficient robot learning, 3D point cloud representations for manipulation lack a universal pre-training paradigm due to the scarcity of large-scale 3D data on the open web. Existing 3D pre-training methods (contrastive learning, masked reconstruction) do not exploit the temporal dynamics of robotic scenes, leaving a gap in how to extract motion-aware 3D visual features that transfer across diverse manipulation tasks.

## Input / Output

FVP takes the previous frame's 3D point cloud (N×3) as the conditioning signal, encoded by a pluggable 3D encoder (PointNet++, Point Transformer, or DP3 Encoder) into a latent representation z ∈ R^{N×Cv}. This latent is concatenated with the noisy current-frame point cloud to form an N×(Cv+3) tensor that the diffusion denoiser processes. The output is a pre-trained 3D visual encoder whose features are directly swapped into downstream policies (DP3, RISE) or VLA models (RDT-1B), which then predict robot joint positions; for VLA models, language instructions are additionally consumed as text input.

## Method

FVP reframes 3D visual pre-training as a next-point-cloud-prediction problem: given the history frame's point cloud, a conditional diffusion model (a modified Point-Voxel Diffusion network) iteratively denoises Gaussian noise into the current frame's point cloud. The key architectural change is concatenating the encoder's latent representation z onto the noisy point cloud, transforming the denoiser's input from R^{N×3} to R^{N×(Cv+3)} while keeping the output as R^{N×3} (predicted noise), trained with standard L2 noise-prediction loss. This temporal prediction objective—rather than contrastive pairing or masked reconstruction—forces the encoder to capture motion dynamics and physical interactions. FVP operates as a general plug-in: it pre-trains any 3D encoder on robot trajectories (observation-action pairs) using either in-domain or out-of-domain datasets (e.g., RoboMind), and the resulting features are fine-tuned end-to-end with the downstream policy backbone.

## Results

Across twelve real-world manipulation tasks, FVP boosts the average success rate of DP3 by 28% (from ~12.5/20 to 16.4/20). In simulation, FVP-pretrained DP3 improves average task accuracy by 16.9% with in-domain pre-training and 24.7% with out-of-domain pre-training on Adroit and MetaWorld benchmarks. On real-world tasks, FVP achieves 15%–55% absolute improvements over state-of-the-art 3D imitation learning baselines (DP3, RISE), and RISE+FVP attains the highest success rates across all tested robotic platforms (single-arm, dual-arm, humanoid).

## Baselines & Comparisons

FVP consistently outperforms all 3D pre-training baselines (PointMAE, STRL, C2P) on both in-domain and out-of-domain pre-training settings across real-world tasks, with the gap widening on dexterous-hand tasks where temporal understanding is critical. Against 2D pre-trained representations (R3M, MVP, MAE trained on Soup-1M+100 DoH), DP3+FVP achieves a 3.9–4.9 point average advantage (16.4 vs. 12.5–15.5 out of 20), despite the 2D methods being trained on datasets exceeding 300M samples. FVP also surpasses 2D imitation learning methods (ACT, Diffusion Policy) and unpretrained 3D methods (DP3, RISE) on all real-world tasks, with RISE+FVP achieving the overall SOTA. In simulation, FVP-pretrained DP3 outperforms EquiBot and EquiDiff variants on Adroit and MetaWorld. For the VLA model RDT-1B, adding 3D point cloud input with FVP pre-training improves average success from 6/20 (2D image) to 10/20 on generalization tasks, and from 12/20 to 18/20 on PickSquare1.

## Relation to Prior Work

FVP departs from the dominant 2D visual pre-training paradigm for robotics (R3M, MVP, VC-1) by operating entirely in 3D point cloud space, and from prior 3D point cloud pre-training methods (contrastive learning in STRL/C2P, masked reconstruction in PointMAE) by reframing the objective as next-frame point cloud prediction via a conditional diffusion model. The diffusion backbone is adapted from Point-Voxel Diffusion (Zhou et al., ICCV 2021), and the framework is designed as a plug-in module for existing 3D imitation learning policies (DP3, RISE) and VLA models (RDT-1B), making it encoder-agnostic across PointNet++, Point Transformer, and DP3/RISE encoders.

## Why It Matters / Open Questions

FVP provides the first general 3D/4D visual pre-training framework for robot manipulation that works as a drop-in module across multiple policy architectures and robot embodiments (single-arm, dual-arm, humanoid), which is practically valuable for the growing 3D imitation learning community. A key limitation is the requirement for complete point cloud data with camera extrinsics, which excludes major open-source datasets like Open-X-Embodiment, constraining the scale of out-of-domain pre-training. Open questions include whether the approach transfers to settings without depth sensors, whether it scales to truly large-scale 3D corpora, and whether the next-frame prediction objective generalizes beyond manipulation to navigation or deformable-object tasks.

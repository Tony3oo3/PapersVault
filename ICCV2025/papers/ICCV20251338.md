## Problem

Existing online video temporal grounding methods rely on frame-level memory with per-frame start/end score prediction, which lacks effective event modeling for events of varying durations and cannot retain long-term historical information because fixed-size FIFO memory gets overwritten by redundant content. This leads to poor localization accuracy, especially for queries requiring context from early in the video (e.g., 'the guy plays the saxophone again').
![Teaser figure](../imgs/ICCV20251338/cropped_page0_idx1.webp)

## Input / Output

The model consumes a streaming video frame-by-frame (only frames 1 through t are visible at timestamp t) along with a natural language query, and outputs event start and end timestamps in real time. It supports two inference modes: a high-accuracy mode that predicts both boundaries from event proposals once the event is about to end, and a low-latency mode that predicts the start time via a future prediction branch (looking ahead in a window [t+a, t+b]) while the end time still comes from event proposals. The short-term window is 8 frames, the total memory budget is 64 slots across 8 hierarchical scales, and pre-extracted C3D or CLIP frame features are used as visual input.

## Method

The core architecture builds event proposals via a segment tree over a short-term window, producing L=8 scales where each scale doubles the proposal duration (2^j frames), with large-scale proposals incorporating the most recent historical event from memory when they exceed the window length. A hierarchical event memory stores proposals at each scale, with dynamic size allocation proportional to the frequency of positive events per scale and an adaptive update rule that merges adjacent events exceeding a cosine-similarity threshold to reduce redundancy. A transformer encoder refines current proposals against the memory, a transformer decoder fuses them with text features, and per-proposal classifiers and regressors (focal loss + DIoU loss) determine matches and refine boundaries. A separate future prediction branch uses an MLP to predict whether the target event starts within [t+a, t+b] and regresses the start-time offset, enabling predictions before the event begins at the cost of some accuracy.

## Results

On TACoS, the proposed method (w/o future prediction) achieves R₀.₅¹ = 44.19 and R₀.₇¹ = 30.87, outperforming the only prior online VTG baseline Gan et al. (29.74 / 19.07) by 14.45% and 11.80% respectively. On the challenging MAD dataset (110-min videos, 4.1-s target segments), the method achieves R₀.₅⁵ = 11.07 and R₀.₅⁵⁰ = 29.21, a 3.3× improvement over Gan et al. (2.00 / 7.80) on R₀.₃⁵. The future prediction branch trades some accuracy (R₀.₅¹ drops from 44.19 to 37.44 on TACoS) for a dramatic reduction in start-time delay, from +22.38 s to −1.28 s, enabling predictions before the event actually begins.

## Baselines & Comparisons

Against the sole prior online VTG method (Gan et al., ACM MM 2023), the proposed method wins decisively on all three datasets: +14.45% R₀.₅¹ on TACoS (44.19 vs 29.74), and a 3.3× gain on R₀.₃⁵ on MAD (15.76 vs 4.71). Compared to the strongest online action localization baselines HAT (ECCV 2025) and OAT (ECCV 2022), the method outperforms HAT by 10.04% on R₀.₅¹ (TACoS) and by 5.96% on R₀.₅⁵ (MAD: 11.07 vs 5.11), attributed to the hierarchical event memory retaining longer historical context than frame-level memory. All online action detection baselines (TeSTra, MiniROAD, LSTR, GateHUB, OadTR) are substantially outperformed, with gaps of 10–20+ points on R₀.₅¹. The method remains below offline VTG methods (SnAG, G2L) as expected, since those exploit full-video access. The future prediction branch sacrifices ~6.75% R₀.₅¹ on TACoS but reduces start-time delay from +22.38 s to −1.28 s, offering a tunable accuracy–latency trade-off not available in any baseline.

## Relation to Prior Work

This paper is the second method specifically designed for online video temporal grounding (OnVTG), a task first formalized by Gan et al. (ACM MM 2023), who used frame-level memory and per-frame start/end score prediction. The key departure is shifting from frame-level to event-level modeling: the authors repurpose the segment tree structure from offline proposal-based temporal grounding (TALL, etc.) into an online setting, and adapt hierarchical memory ideas from long-video LLM understanding (MALMM, MovieChat, VideoLLaMB) to preserve multi-granularity event history. The future prediction branch is a novel addition not present in any prior online video understanding method, specifically designed to counteract the inherent latency of proposal-based prediction.

## Why It Matters / Open Questions

With only one prior method for OnVTG, this paper establishes a substantially stronger baseline and introduces a practical accuracy-latency trade-off (via the future prediction window) that is directly relevant to real-time applications like surveillance alerting and live-streaming retrieval. The hierarchical event memory addresses a fundamental limitation of fixed-size frame buffers—loss of long-term event structure—which is likely to inform future online video understanding architectures. Open questions include whether the segment-tree proposal construction generalizes to arbitrarily long streams, how the method scales to multi-event or multi-query settings, and whether the dynamic memory allocation strategy remains effective when event duration distributions shift across domains.

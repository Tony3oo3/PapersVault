## Problem

Existing diffusion- and rectified-flow-based text-guided image editing methods rely on inversion to extract structured noise from input images, but inversion inaccuracies propagate errors that cause unintended modifications in unedited regions. Even with perfect inversion, the entanglement between text prompts and image features leads to global changes when only local edits are intended, limiting fine-grained controllability. This paper asks whether a visual autoregressive (VAR) model can enable precise, training-free editing without any inversion step.

## Input / Output

The method takes an RGB image at 1K resolution, a source text prompt describing the original image, and a target text prompt specifying the desired edit, and produces a single edited RGB image. The source prompt is consumed during a one-time caching (feedforward) pass that stores bit labels and probability distributions; subsequent edits with different target prompts reuse this cache without re-encoding the image. Processing a 1K image takes ~2.5 s on the first run and ~1.2 s for subsequent runs on a single A100 GPU, roughly 9× faster than comparable diffusion/flow-based methods.

## Method

AREdit builds on the Infinity-2B VAR backbone, which predicts images via next-scale (coarse-to-fine) bitwise token prediction using binary spherical quantization. The core mechanism is a randomness-caching step: a single feedforward pass through the encoder and transformer stores the bit-label indices and per-scale probability distributions (and optionally attention maps) for the source prompt, eliminating the need for iterative inversion. During editing, a hyperparameter γ controls how many early (low-frequency) scales directly reuse cached tokens to preserve global structure; for later scales, an adaptive fine-grained mask of shape h_k × w_k × d is computed by comparing the cached probability of each original bit label against the probability predicted under the target prompt, flagging tokens whose probability drops beyond a threshold τ. Masked tokens are replaced by fresh samples from the target-prompt distribution while unmasked tokens retain their cached values, and an optional Prompt-to-Prompt-style attention alignment further constrains cross-attention for large-area style or color edits. The entire pipeline requires only two feedforward passes (cache + edit) and no gradient-based optimization.

## Results

On PIE-Bench, AREdit achieves the best background preservation among all compared methods: PSNR 24.19, SSIM 0.8370, and LPIPS 0.0870, outperforming the next-best PnP-DirInv. (PSNR 22.46, SSIM 0.7968, LPIPS 0.1061). For text-image alignment, AREdit scores 25.42 (CLIP Whole) and 22.77 (CLIP Edited), matching PnP/PnP-DirInv. on whole-image similarity but trailing LEdits++ (26.42 / 23.37). Structure distance is 0.0305, competitive with PnP-DirInv. (0.0243) but slightly behind. Inference speed is 2.5 s (1.2 s for subsequent runs) on an A100 GPU, roughly 9× faster than LEdits++ (19 s) and RF-Inversion (27 s).

## Baselines & Comparisons

AREdit clearly wins on all three background-preservation metrics (PSNR, SSIM, LPIPS), beating the closest competitor PnP-DirInv. by ~1.7 dB in PSNR and ~0.04 in SSIM, indicating substantially better fidelity in unedited regions. On CLIP whole-image similarity, AREdit (25.42) essentially ties PnP and PnP-DirInv. (both 25.41) but trails LEdits++ (26.42) by ~1 point; on CLIP edited-region similarity, AREdit (22.77) is close to PnP-DirInv. (22.62) but again behind LEdits++ (23.37). For structure distance, PnP-DirInv. (0.0243) edges out AREdit (0.0305), while MasaCtrl (0.0284) and PnP (0.0282) are comparable. AREdit substantially outperforms RF-Inversion on every metric except CLIP whole (25.20 vs 25.42), and dominates Pix2Pix-Zero and Prompt2Prompt across the board. The key trade-off is that LEdits++ achieves the highest text-alignment scores at the cost of noticeably worse background preservation (PSNR 19.64, LPIPS 0.1334), whereas AREdit prioritizes fidelity while remaining competitive on alignment.

## Relation to Prior Work

This paper departs from the dominant diffusion and rectified flow paradigm for text-guided image editing, which relies on inversion to extract structured noise from input images, by instead leveraging the autoregressive (VAR) framework where randomness is inherent in per-token sampling. It builds directly on VAR's next-scale prediction strategy and Infinity-2B's bitwise token prediction with binary spherical quantization, repurposing the feedforward pass as a 'randomness caching' step that replaces the multi-step inversion process. The adaptive fine-grained masking and token re-assembling mechanisms are novel contributions specific to the discrete-token AR setting, while the attention control component adapts Prompt-to-Prompt's alignment function to the VAR context.

## Why It Matters / Open Questions

The ~9× speedup (2.5s vs. 19–27s for 1K images) makes high-fidelity text-guided editing practical for interactive applications, and the training-free design eliminates the need for additional data or fine-tuning. However, the base model (Infinity-2B) has weaker generative capacity than Flux, capping the quality ceiling, and the method struggles with fine-grained textures and structurally rigid objects. Open questions include whether the caching-and-masking paradigm transfers to larger AR models or video editing, and whether the discrete token representation is fundamentally limiting for certain editing categories (e.g., continuous style gradients).

## Problem

Preconditioned stochastic optimizers like Shampoo offer superior convergence over first-order methods but require storing full non-diagonal preconditioning matrices, imposing substantial GPU memory overhead that limits scalability. While quantizing these matrices from 32-bit to 4-bit reduces memory, the resulting information loss severely degrades optimization performance. The paper addresses how to compress Shampoo's preconditioners to 4-bit while preserving the spectral properties critical for stable, high-quality optimization.

## Input / Output

The method consumes stochastic gradients G_k ∈ R^{m×n} computed from mini-batches and model parameters W_k, producing updated parameters W_{k+1} via a first-order base optimizer (SGDM, AdamW, or RMSprop). Preconditioning matrices are processed in 1200×1200 blocks per layer; within each block, off-diagonal elements of the Cholesky factors are quantized to 4-bit while diagonal elements remain in 32-bit for numerical stability. The 4-bit error state is stored in the upper triangular part of the same matrix as the lower-triangular Cholesky factor, so no additional memory is incurred beyond vanilla 4-bit Shampoo.

## Method

The core technique is Cholesky quantization (CQ): rather than quantizing the full preconditioners L_k and R_k, the algorithm applies Cholesky decomposition and quantizes only the lower-triangular factors C_k^L and C_k^R, halving storage while guaranteeing the recovered preconditioner remains symmetric positive definite and better preserving spectral properties (measured by Frobenius norm relative error and angle error). To further mitigate quantization loss, an error feedback (EF) mechanism maintains a 4-bit error state that exponentially-moving-averages past quantization residuals and compensates the Cholesky factor before each quantization step. The triangular structure of both the Cholesky factor and its error state enables joint storage in a single matrix (lower and upper triangles respectively) at zero additional memory cost. Theoretically, the paper proves O(1/√T) convergence for smooth nonconvex losses and, for the first time, global convergence to stationary points for preconditioned gradient descent under nonsmooth nonconvex losses (e.g., ReLU-based networks).

## Results

On CIFAR-100, 4-bit Shampoo with compensated Cholesky quantization (CQ+EF) achieves 80.52% test accuracy for ResNet-34 (SGDM) and 77.74% for ViT-Small (AdamW), closely matching 32-bit Shampoo (80.69% and 77.95%) while reducing peak GPU memory by over 28%. On ImageNet, ViT-Base with 4-bit CQ+EF reaches 75.01% top-1 accuracy versus 72.28% for vanilla 4-bit Shampoo, nearly closing the gap to 32-bit (75.47%). For LLM pre-training on C4, LLaMA-1B with 4-bit CQ+EF achieves 46.31 PPL, substantially outperforming vanilla 4-bit (48.53) and matching 32-bit Shampoo which exceeds A100 80GB memory limits.

## Baselines & Comparisons

Against the base optimizers (SGDM, AdamW, RMSprop), 4-bit Shampoo with CQ+EF consistently wins by 0.5–5% accuracy across all models and datasets, confirming that preconditioning provides substantial gains even at 4-bit precision. Compared to 32-bit Shampoo, the proposed 4-bit CQ+EF narrows the gap to within 0.1–0.5% on CIFAR-100 (e.g., 80.52% vs 80.69% for ResNet-34) and within 0.46% on ImageNet ViT-Base (75.01% vs 75.47%), while reducing peak memory by 28–30%. Against vanilla 4-bit Shampoo (VQ), CQ+EF improves accuracy by 0.25–3.2% depending on model and dataset, with the largest gains on ViT-Small (77.74% vs 74.56% on CIFAR-100) and ViT-Base on ImageNet (75.01% vs 72.28%). Against the prior 4-bit Shampoo work [51], the proposed method wins on all four evaluated tasks in Table 7 (e.g., 75.21% vs 74.71% on VGG-19, 23.99 vs 24.39 PPL on LLaMA-350M), attributed to the error feedback mechanism and lower-triangular Cholesky storage. On LLaMA-1B pre-training, 32-bit Shampoo is infeasible (OOM on A100 80GB), making the proposed 4-bit method (46.31 PPL) the only Shampoo variant that runs, and it outperforms the base optimizer (48.39 PPL) by 2.08 PPL.

## Relation to Prior Work

This paper extends the practical Shampoo optimizer (Anil et al., 2020) by introducing a memory-efficient quantization strategy for its preconditioning matrices. The core idea repurposes two established techniques in novel combination: Cholesky decomposition (to exploit the lower-triangular structure and halve storage) and error feedback (originally developed for gradient compression in distributed training, Richtárik et al., 2021) applied here to preconditioner quantization. The closest prior work is Wang et al. (2024), which also quantizes Shampoo to 4 bits but uses QR decomposition with full orthogonal matrices; this paper departs by using Cholesky factors (lower computational cost, half the storage) and adding an error-feedback compensation loop that the earlier work omits.

## Why It Matters / Open Questions

The practical impact is significant for practitioners training large models with Shampoo: the method reduces peak GPU memory by 28–30% while matching or exceeding 32-bit Shampoo accuracy, and enables training configurations (e.g., LLaMA-1B) that are simply infeasible at 32-bit precision on a single A100. The first convergence proof for preconditioned gradient descent under nonsmooth losses (e.g., ReLU networks) fills a notable theoretical gap. Limitations include testing only with Shampoo (not K-FAC, AdaBK, etc.), evaluation restricted to image classification and LLM pretraining, and the modest 0.25–0.73% accuracy gains over vanilla 4-bit Shampoo, which, while consistent, are incremental rather than transformative.

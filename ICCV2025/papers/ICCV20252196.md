## Problem

Existing methods for transferring 2D visual features from foundation models (DINO, SAM, CLIP) into 3D Gaussian Splatting scenes rely on iterative optimization of a reprojection loss, which is computationally expensive, memory-intensive, and requires scene-specific training. This paper asks whether a simple, learning-free aggregation can match the quality of these optimization-based approaches while being orders of magnitude faster.
![Teaser figure](../imgs/ICCV20252196/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained 3D Gaussian Splatting scene and 2D feature maps (from DINOv2, SAM, SAM2, or CLIP) computed on the training views, plus an optional reference mask, scribbles, or text prompt. It produces 3D features attached to each Gaussian that can be rendered into 2D for segmentation, thresholded for object localization, or binarized for 3D object removal. The entire uplifting is implemented within the GS CUDA rendering kernel, taking approximately 2 ms per view and feature dimension, with no additional parameters or optimization steps.

## Method

The core uplifting operation computes each Gaussian's 3D feature as a normalized weighted average of 2D features from all views, where the weights are the standard alpha-blending rendering weights; this is equivalent to a single pre-conditioned gradient descent step on the L2 reconstruction objective starting from zero, making iterative optimization unnecessary. To refine coarse segmentation inputs (scribbles, CLIP relevancy scores) into accurate 3D masks, the paper introduces a graph diffusion process: a k-NN graph is built on Gaussian centers using Euclidean distance, with edge weights combining a DINOv2 RBF similarity kernel and a unary regularization term that prevents leakage into the background. T diffusion steps (power-method iterations on the weighted adjacency matrix) propagate signal through the object while respecting 3D geometry and DINOv2's feature landscape. The entire pipeline is parameter-free, requires no gradient-based training, and can be plugged directly into the existing GS rendering process.

## Results

On multi-view segmentation (NVOS), LUDVIG with DINOv2 graph diffusion achieves 92.4 IoU, matching or exceeding all optimization-based baselines (SA3D-GS: 92.2, SAGA: 92.6, OmniSeg3D: 91.7) without any gradient-based training. On SPIn-NeRF, LUDVIG reaches 93.8 IoU, competitive with the best baseline OmniSeg3D (94.3). For open-vocabulary object segmentation on LERF, LUDVIG achieves 64.3 IoU (2D protocol) and 50.4 IoU (3D protocol) in just 10 minutes, outperforming LangSplat (51.4 / 105 min) and LERF (37.4 / 45 min) by a wide margin. On ScanNet semantic segmentation, replacing OpenGaussian's quantization-based feature learning with LUDVIG's direct uplifting yields a substantial gain from 24.7 to 33.9 mIoU (19 classes) in ~3 min vs ~40 min.

## Baselines & Comparisons

LUDVIG outperforms all optimization-based multi-view segmentation baselines on NVOS (92.4 vs. SA3D-TRF 90.3, SA3D-GS 92.2, OmniSeg3D 91.7) and is competitive on SPIn-NeRF (93.8 vs. OmniSeg3D 94.3, SAGA 93.4), all without any gradient-based feature learning. On LERF object localization, LUDVIG (86.3) surpasses LangSplat (84.3) and LERF (73.6); on LERF segmentation it achieves 64.3 IoU vs. LangSplat's 51.4 and LERF's 37.4, while running 5–10× faster (10 min vs. 105/45 min). For 3D object selection, LUDVIG (50.4) beats both Dr. Splat (43.6) and OpenGaussian (43.1). On ScanNet semantic segmentation, LUDVIG (33.9 mIoU, 19 classes) substantially outperforms OpenGaussian (24.7), LEGaussians (3.8), and LangSplat (3.8), demonstrating that direct feature uplifting replaces complex quantization-based learning with a ~13× speedup. The only baseline LUDVIG does not clearly beat is OmniSeg3D on SPIn-NeRF (93.8 vs. 94.3), which the authors attribute to poor GS reconstruction of highly specular scenes.

## Relation to Prior Work

This paper builds directly on 3D Gaussian Splatting's rendering pipeline, repurposing the α-blending weights as aggregation coefficients to transfer 2D features into 3D without any learned parameters. It departs sharply from the dominant paradigm in 3D semantic scene understanding (LERF, SA3D, LangSplat, OpenGaussian, OmniSeg3D), which all rely on iterative gradient-based optimization of a reprojection loss to learn scene-specific 3D feature representations. The graph diffusion component draws on spectral graph theory and manifold denoising, applying these tools in 3D space for the first time in this context to refine coarse segmentation signals using DINOv2's feature landscape.

## Why It Matters / Open Questions

The finding that a single pre-conditioned aggregation step (equivalent to one gradient descent iteration) matches or exceeds multi-iteration optimization for feature uplifting challenges the assumption that 3D semantic features require dedicated training, offering a 5–10× speedup and drastically reduced memory footprint. The demonstration that DINOv2 features alone, combined with 3D graph diffusion, can rival SAM-based segmentation is practically significant for pipelines that want to avoid SAM's computational overhead. However, the approach inherits limitations of the underlying GS reconstruction (specularity, motion blur), and the graph diffusion's effectiveness on highly cluttered or textureless scenes remains an open question.

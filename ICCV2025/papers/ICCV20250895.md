## Problem

Most CAD-specific deep learning methods rely solely on geometric features (primitive shape regularity) and ignore the constraints that define spatial relationships between primitives. This oversight prevents them from distinguishing visually similar CAD shapes that serve different functions due to different constraints (e.g., an eccentric wheel with a distance constraint vs. a flywheel with a coaxial constraint). The paper addresses this by introducing a constraint-aware feature learning framework for parametric point clouds.
![Teaser figure](../imgs/ICCV20250895/cropped_page0_idx0.webp)

## Input / Output

The method accepts raw point clouds (x, y, z coordinates only, as typically acquired by LiDAR or RGB-D cameras) and optionally BRep data for ground-truth constraint extraction during training. Each point is augmented with a three-component constraint representation: Main Axis Direction (a unit vector), Adjacency (a one-hot flag indicating proximity to a valid edge), and Primitive Type (one-hot over plane/cylinder/cone), forming a 6-dimensional per-point feature (x, y, z, MAD, Adj, PT). The final output is a class label for classification, with the intermediate constraint features also usable for downstream tasks like pose estimation.

## Method

CstNet is a two-stage network. Stage 1 (CstPnt) predicts MAD-Adj-PT from local point patches using a SurfaceKNN neighbor search (which searches along the surface rather than in a 3D sphere), an attention-based point aggregation (Eq. 1), and a U-Net-like MLP structure; it is pre-trained on ABC BRep-derived labels and generalizes to unseen datasets because it relies only on local features. Stage 2 extracts separate features from each constraint component via a Triple MLP, processes them through a Quartic SSA layer (Farthest Point Sampling → SurfaceKNN → point-level attention with constraint-specific positional encodings), and then applies a feature-level vector attention (Eq. 2) that adaptively re-weights the four feature streams (Axis, Adjacency, Primitive, Constraint) based on local context. The key design insight is that representing constraints as point-wise attributes converts pairwise primitive relations into point-to-reference relations, drastically reducing data volume and enabling permutation-invariant, local-feature-based learning that does not require global shape understanding.

## Results

On the Param20K classification benchmark (75 classes, ~20K instances), CstNet achieves 89.94% instance accuracy, 91.06% class accuracy, 90.34% F1, and 92.72% mAP, outperforming the strongest baseline PTMamba (86.45% Acc) by 3.49% in instance accuracy. For constraint prediction on the unseen Param20K dataset, CstPnt attains 87.95% Adj accuracy and 86.52% PT accuracy, surpassing ParSeNet (81.42%/59.75%) and HPNet (78.60%/57.66%) by a wide margin. Under rotation perturbation, CstNet demonstrates a 26.17% accuracy improvement over SOTA, with its CstPnt module remaining nearly unaffected by rotation due to local-feature-based pre-training on ABC.

## Baselines & Comparisons

CstNet outperforms all 10 baselines on every metric in the Param20K classification task. The closest competitor, PTMamba (86.45% Acc), is surpassed by 3.49% in instance accuracy and 3.78% in class accuracy; 3DGCN (86.42%) and DGCNN (85.40%) trail by 3.52% and 4.54% respectively. The CAD-specific methods ParSeNet (83.96%) and HPNet (83.85%) are notably weaker, lagging CstNet by ~6% in accuracy, and their class-level accuracy (79.50% and 80.87%) is substantially lower, indicating poor generalization across the 75 classes. On the unseen Param20K constraint-prediction task, CstPnt's advantage over ParSeNet and HPNet is especially pronounced for Primitive Type prediction (86.52% vs. 59.75% and 57.66%), suggesting that global-feature-based methods degrade severely on out-of-distribution CAD shapes while the local-feature-based CstPnt generalizes well. For rotation robustness, CstNet maintains near-constant performance under increasing rotation angles, whereas all baselines show significant accuracy drops, yielding the reported 26.17% improvement over SOTA.

## Relation to Prior Work

This paper carves new ground at the intersection of parametric point cloud analysis and constraint-aware learning. Prior CAD-specific methods (ParSeNet, HPNet) exploit primitive regularity for segmentation and fitting but explicitly ignore inter-primitive constraints, while general point cloud classifiers (PointNet++, DGCNN, 3DGCN) treat all geometry uniformly without any CAD-aware structure. The key conceptual departure is repurposing traditional CAD constraint definitions (from SolidWorks/UG) into a point-wise, deep-learning-friendly representation (MAD-Adj-PT) that can be inferred from local point patches alone, thereby decoupling constraint acquisition from the need for BRep data or primitive labels. The two-stage architecture (local constraint prediction + attention-based constraint feature learning) is novel in its specific combination, though each component (KNN-style neighborhood, attention, FPS downsampling) draws on established point cloud techniques.

## Why It Matters / Open Questions

The introduction of Param20K as the first multi-modal (BRep + mesh + point cloud) parametric-purpose dataset addresses a critical data scarcity in the CAD deep learning community and provides a solid benchmark for future constraint-aware research. The MAD-Adj-PT representation offers a practical, generalizable way to encode CAD constraints as point-wise attributes, potentially enabling constraint-aware reasoning in industrial applications (pose estimation, model design) where only point clouds are available. However, the approach is limited to regular primitives (plane, cylinder, cone) and does not handle free-form surfaces or more complex constraint types (e.g., radius equivalence between non-adjacent primitives). Open questions include whether the representation scales to assemblies with many primitives, how it interacts with manufacturing or design-intent attributes, and whether the local-only constraint prediction can capture global design intent.

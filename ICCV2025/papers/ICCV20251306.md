## Problem

VLMs rely on uniform patch-based processing at fixed low resolutions (e.g., 224×224), causing them to miss fine-grained details in high-resolution images. Existing remedies either scale global resolution (incurring quadratic attention cost) or apply region-aware techniques that require multiple vision encoder passes or lossy token compression. The paper addresses the gap of capturing fine details at arbitrary resolutions without increasing token count or computational overhead.
![Teaser figure](../imgs/ICCV20251306/cropped_page0_idx1.webp)

## Input / Output

The model accepts an RGB image at arbitrary resolution (evaluated up to 5760×2880) paired with a free-form text query, and produces a natural-language response. Internally, the input image is decomposed into a fixed budget of 729 visual tokens: low-resolution global patches for context plus high-resolution local patches sampled from query-relevant regions, so the LLM always sees the same token count regardless of input size. A lightweight RAP module (LLM + Grounding DINO) runs before the vision encoder to determine which regions receive high-resolution patches.

## Method

TEVA introduces a Relevant Area Proposal (RAP) module that uses an LLM-based Subject Proposal Agent to extract candidate subjects from the query and a Grounding DINO-based Subject Detection Agent to localize them, followed by an Informative Patch Sampling step that allocates patch slots to each detected region proportionally to its area and arranges them on a uniform grid within each bounding box. Patches are projected back to the original image via per-patch affine transformation matrices (scale + translation), with bilinear interpolation for sub-pixel sampling, and the matrix parameters are concatenated with positional embeddings to preserve spatial context. The resulting mixture of high-resolution local and low-resolution global patches is fed through a SigLIP vision encoder in a single forward pass, keeping the token count fixed. Training proceeds in four stages (alignment, vision tower adaptation, integrated interpretation, instruction fine-tuning) and is supported by a newly curated 8-million-pair Subject-Oriented dataset that emphasizes zoomed-in, subject-focused QA to teach the model to exploit dynamic patches.

## Results

On the high-resolution V* benchmark, TEVA-7B achieves 77.1 average (AR 76.5, SRR 77.6, OCR 83.3), surpassing GPT-4V (55.9) by 21.2 points and all open-source methods. On MME-RealWorld, TEVA-7B outperforms GPT-4o on Remote Sensing (38.2 vs 28.9), Video Monitoring (36.9 vs 33.9), and Autonomous Driving (35.2 vs 22.4) perception tasks, though it trails on OCR (60.7 vs 77.7). On general VLM benchmarks, TEVA-7B leads all open-source methods across all 8 benchmarks (e.g., MMBench 80.3, ScienceQA 92.5, LLaVA-Bench 94.3, MMMU 48.4) while using only 729 visual tokens—far fewer than Monkey (5120) or LLaVA-Next (2880).

## Baselines & Comparisons

TEVA-7B decisively outperforms all open-source high-resolution VLMs on V* (77.1 vs. MLLM-K 62.3, LLaVA-Next 61.3, Cambrian-1 60.8) and beats GPT-4V by 21.2 points. Against GPT-4o on MME-RealWorld, TEVA-7B wins on Remote Sensing (+9.3), Video Monitoring (+3.0), and Autonomous Driving (+12.8) perception tasks, but loses on OCR perception (60.7 vs. 77.7) and OCR reasoning (49.4 vs. 61.4). On general benchmarks (Table 3), TEVA-7B leads every open-source method across all 8 tasks—e.g., MMBench 80.3 vs. Cambrian-1 75.9, ScienceQA 92.5 vs. Cambrian-1 80.4, LLaVA-Bench 94.3 vs. LLaVA-Next 83.2—while using only 729 visual tokens compared to Monkey's 5120 or LLaVA-Next's 2880. In inference efficiency (Table 1), TEVA achieves a 7.53× speedup over V* in ROI aggregation and 12.31× in full pipeline inference, since it avoids multiple vision-encoder passes. The smaller TEVA-3B (Sheared-LLaMA-2.7B) still surpasses Monkey-7B on MME-RealWorld perception (e.g., RS 32.3 vs. 25.0, MO 32.6 vs. 28.0) despite using 7× fewer visual tokens.

## Relation to Prior Work

TEVA builds on the LLaVA/VILA architecture (vision encoder + adapter + LLM) but departs fundamentally from prior high-resolution VLM strategies. Where global-resolution methods (Qwen-VL, curriculum learning) suffer quadratic attention costs and tiling methods (Monkey, LLaVA-Next) explode token counts, TEVA performs dynamic patch sampling *before* the vision encoder, guided by an LLM-based subject proposal and Grounding DINO detection. This contrasts with region-aware methods like SpatialGPT, Griffon-G, and V*, which either compress tokens lossily or require multiple expensive vision-tower passes per ROI. The affine transformation mechanism for unifying patches of varying scales and locations draws on Spatial Transformer Networks but is applied at the patch-allocation level rather than as a learned spatial attention.

## Why It Matters / Open Questions

TEVA addresses a critical practical bottleneck: processing 5K+ resolution images (surveillance, satellite, autonomous driving) without prohibitive compute or token overhead, achieving a 12.31× speedup over V* while improving accuracy. The 8-million-pair Subject-Oriented dataset is the first large-scale resource for training VLMs to focus on specific image details, and the finding that affine matrix embeddings yield ~12-point gains on spatial reasoning suggests spatial context injection is underexploited in current VLMs. A key limitation is that the approach degrades on densely packed, uniformly informative images (e.g., text-heavy documents) where no distinct regions can be prioritized, leaving open the question of how to handle information-dense scenes without sacrificing the token-efficiency advantage.

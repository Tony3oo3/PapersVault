## Problem

Existing feed-forward 3D Gaussian reconstruction methods predict Gaussians per-pixel per-view and concatenate them, causing 'ghosting' misalignment, uniform Gaussian distribution regardless of scene complexity, and a hard dependency on a fixed number of input views. These limitations prevent practical deployment where view counts vary and where complex regions demand denser 3D representation.
![Teaser figure](../imgs/ICCV20252697/cropped_page1_idx1.webp)

## Input / Output

The model accepts an arbitrary number of posed RGB images (trained on 4 fixed views at 128×128, tested from 2 to 8 views) along with their camera intrinsics and extrinsics. It outputs a fixed set of 19,600 3D Gaussians defined in world space (centers, rotations, scales, opacities, and spherical harmonic colors), which can be differentially rendered to any novel viewpoint. Because the Gaussian count is decoupled from the view count, memory does not scale linearly with additional input views.

## Method

UniGS adopts a DETR-like encoder-decoder architecture where a fixed set of unitary 3D Gaussians in world space serve as decoder queries, updated layer-by-layer. The key mechanism, Multi-View Deformable Cross-Attention (MVDFA), first modulates global queries into view-specific queries via camera-parameter-conditioned adaLN, then projects each Gaussian center onto every input view as a reference point, and performs deformable cross-attention sampling image features around those points per view. View-specific queries are fused back into the unitary query set via a learned weighted sum, ensuring all views contribute to a single coherent 3D representation without per-view concatenation. A Spatial Efficient Self-Attention (SESA) module uses Fast Point Sampling to downsample keys and values, reducing self-attention cost while preserving inter-Gaussian information flow. Training uses a combined MSE + LPIPS rendering loss over 12 views (4 input + 8 supervision) on Objaverse, with the decoder initialized by regressing Gaussians from per-pixel image features to ensure convergence.

## Results

On the GSO benchmark with 4 fixed input views at 128×128 resolution, UniGS achieves PSNR 30.42 dB, SSIM 0.9614, and LPIPS 0.0422, outperforming all compared methods. The headline improvement is approximately 4.2 dB in PSNR over LGM (Large), the strongest prior Gaussian-based feed-forward method. UniGS also achieves the best SSIM and LPIPS scores, indicating superior structural and perceptual fidelity. Inference time is 0.75 s per object (forward + 32 renders), faster than LGM (1.91 s) and substantially faster than InstantMesh (20.5 s) and DreamGaussian (118.4 s).

## Baselines & Comparisons

UniGS outperforms all eight baselines on every metric (PSNR, SSIM, LPIPS). The closest competitor is GRM (Res-512) at 30.05 PSNR, which UniGS surpasses by 0.37 dB; GS-LRM (Res-256) follows at 29.59 PSNR, a 0.83 dB gap. The most dramatic improvement is over LGM (Large) at 26.25 PSNR, yielding the paper's headline 4.2 dB gain, and over LGM (Small) at 17.48 PSNR. On SSIM, UniGS (0.9614) leads GS-LRM (0.9440) by 0.017 and GRM (0.9060) by 0.055, while on LPIPS it achieves 0.0422 versus 0.0510 for GS-LRM and 0.0520 for GRM. In inference speed, UniGS (0.75 s) is 2.5× faster than LGM (1.91 s) and 27× faster than InstantMesh (20.5 s), while DreamGaussian (118.4 s) is two orders of magnitude slower due to its diffusion-based generation.

## Relation to Prior Work

UniGS departs from the dominant 'local prediction and fusion' paradigm in feed-forward 3D Gaussian reconstruction (LGM, Splatter Image, GS-LRM, GRM), where per-pixel Gaussians are predicted in each view's camera frame and then concatenated in world space. Instead, it borrows the query-based refinement philosophy of Deformable DETR, treating a fixed set of world-space 3D Gaussians as queries updated layer-by-layer via multi-view deformable cross-attention (MVDFA). The camera-modulation mechanism (adaLN on camera parameters) draws from StyleGAN-style conditioning and BEVFormer's projection-based cross-attention, but is adapted to differentiate view-specific queries from a single unitary query set. The spatially efficient self-attention (SESA) module repurposes Fast Point Sampling from point cloud literature to reduce the quadratic cost of inter-Gaussian attention.

## Why It Matters / Open Questions

The unitary formulation eliminates the 'ghosting' artifact and the linear memory scaling with view count that plague per-pixel methods, enabling inference on an arbitrary number of views without retraining—a practical advantage for deployment where view availability varies. The 4.2 dB PSNR gain over LGM (Large) and modest but consistent improvements over the strongest baselines (GRM, GS-LRM) validate the architectural choice. Key limitations include the requirement for known camera parameters (hindering in-the-wild use) and evaluation restricted to single objects at 128×128 resolution, leaving open whether the approach scales to full scenes or higher resolutions. The MVDFA mechanism could potentially transfer to other 3D reconstruction or multi-view geometry tasks beyond object-level NVS.

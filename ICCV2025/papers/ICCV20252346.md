## Problem

Existing multi-modal masked autoencoders for 3D self-supervised learning (e.g., Joint-MAE, PiMAE) require both 2D images and 3D point clouds as inputs, which is redundant since point clouds inherently encode multi-view 2D information. More critically, feeding 2D images directly as input causes the network to shortcut by relying on visible 2D content rather than learning the underlying multi-view geometric structure, undermining the goal of robust 3D representation learning.

## Input / Output

The method consumes only 3D point clouds and camera pose information—no external 2D images are required. Internally, 3D point tokens are projected onto a 224×224 depth map per view, then quantized to a 16×16 token grid (196 tokens per view) via index mapping. The model outputs reconstructed 3D point coordinates, multi-view 2D depth images, and aligned latent feature representations for both modalities, which serve as the learned 3D embeddings for downstream tasks.

## Method

Multiview-ML projects 3D point tokens into multi-view 2D token space using pose-conditioned feature-level projection (max/avg pooling per image token index, followed by MLP with modality, positional, and pose embeddings), then fuses the projected 2D tokens with original 3D tokens in a shared transformer encoder. The decoder employs a Multi-Scale Multi-Head (MSMH) attention mechanism that partitions tokens into non-overlapping local groups at multiple scales, applying self-attention within each group and concatenating multi-scale outputs to capture both fine-grained local details and broader global context. Training follows a two-stage strategy: Stage 1 trains a teacher autoencoder (Chamfer Distance + MSE loss) to reconstruct full point clouds and multi-view depth images from unmasked input; Stage 2 freezes the teacher and trains a student masked autoencoder to predict the teacher's latent token and instance-level features from masked point clouds, using token-level MSE plus intra- and inter-modality distillation losses inspired by SimSiam.

## Results

On ScanObjectNN (PB-T50-RS), the proposed method achieves 92.06% accuracy when integrated with the ReCon backbone, surpassing ReCon alone (90.63%), I2P-MAE (90.11%), and Point-M2AE (86.43%). On ModelNet40, it reaches 94.7% accuracy (with ReCon), outperforming all non-foundation-model baselines. For part segmentation on ShapeNetPart, the method attains 86.91% mIoU_I, the best among all compared methods. On ScanNetV2 3D object detection, it achieves 63.9 AP25 and 43.3 AP50, improving over the 3DETR baseline by +1.8 and +5.4 respectively.

## Baselines & Comparisons

The method consistently outperforms all non-foundation-model MAE baselines: on ScanObjectNN PB-T50-RS, it beats Point-MAE (85.18→88.93, +3.75), Joint-MAE (86.07→88.93, +2.86), TAP (85.67→88.93, +3.26), Point-GPT (86.9→88.93, +2.03), and Point-M2AE (86.43→88.93, +2.50). Against foundation-model-based methods, it surpasses ACT (88.21→91.36 with I2P-MAE backbone, +3.15) and I2P-MAE (90.11→91.36, +1.25), and edges out ReCon (90.63→92.06, +1.43) on the hardest ScanObjectNN split. On ModelNet40, gains are smaller (0.2–0.6%) due to the dataset's limited size, with the best result of 94.7% (ReCon backbone) marginally exceeding ReCon's 94.5%. For part segmentation, the method achieves the best mIoU_I of 86.91%, surpassing I2P-MAE (86.76%), Joint-MAE (86.28%), and Point-M2AE (86.51%). On ScanNetV2 detection, it outperforms all pre-training baselines including PiMAE (63.1→63.9 AP25, 40.8→43.3 AP50) and TAP (63.0→63.9, 41.4→43.3), confirming that multi-view geometric learning from 3D alone is more effective than 2D-3D joint reconstruction for downstream detection.

## Relation to Prior Work

This paper extends the masked autoencoder paradigm for 3D point clouds (Point-MAE, Point-M2AE) by introducing multi-view 2D reconstruction as an auxiliary task, but critically departs from prior multi-modal MAE methods (Joint-MAE, PiMAE) that require external 2D images as input. Instead, it projects 3D point tokens into multi-view 2D token space using pose information, treating the 2D modality as an internal byproduct of 3D geometry rather than an external input. The two-stage teacher-student training borrows the latent-space prediction philosophy from SimSiam, applying it to a multi-modal masked reconstruction setting, while the MSMH attention mechanism introduces a multi-scale local grouping strategy absent from standard transformer decoders.

## Why It Matters / Open Questions

The key practical insight is that 3D point clouds already encode multi-view 2D information, making external image inputs redundant and potentially harmful for geometric learning—a finding supported by ablations showing 2D input degrades performance. This reframes the design space for 3D SSL: rather than seeking external 2D supervision, one can extract richer geometric representations by forcing the model to internally generate multi-view projections. Open questions include whether the approach generalizes to unposed or partially observed point clouds, whether the gains persist at larger scale (e.g., ScanNet-scale scenes), and whether the two-stage training can be collapsed into a single stage without losing the alignment benefit.

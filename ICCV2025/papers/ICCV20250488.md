## Problem

Existing video-to-4D generation methods optimize Gaussians using undifferentiated whole-frame features, causing them to overfit static regions when those dominate a frame and producing blurry textures in dynamic regions. No prior method explicitly separates dynamic from static information within frame features to preserve fine-grained motion and texture details.
![Teaser figure](../imgs/ICCV20250488/cropped_page0_idx0.webp)

## Input / Output

The method takes a single-view monocular video as input and augments each frame with pseudo multi-view images generated by Zero123++. DINOv2 extracts per-frame token features (P×D) from all views at all timestamps. The output is a deformable 3D Gaussian representation (position, scale, rotation, opacity, spherical harmonics) driven by a Deformation MLP, which can be rendered as novel-view video sequences at arbitrary viewpoints and timestamps.

## Method

DS4D introduces two key modules. The Dynamic-Static Feature Decoupling (DSFD) module projects each frame's DINOv2 features onto reference frame features (the middle frame and the temporal average); the projection yields static features while the orthogonal residual captures dynamic features, which are then appended to the original frame features to form decoupled features. The Temporal-Spatial Similarity Fusion (TSSF) module addresses spatial occlusion by adaptively fusing decoupled features across viewpoints at the same timestamp: Global Awareness (GA) applies softmax-weighted summation over view-projected point features, while Distance Awareness (DA) additionally computes L1 distances from the front view to down-weight occluded novel views while retaining their unique dynamic information. Gaussian points are initialized from a large reconstruction model (InstantMesh) on the middle frame, and HexPlane provides regularized dynamic Gaussian features that are combined with fused point features via a learnable linear layer before feeding a Deformation MLP. Training uses SDS loss, photometric loss, and LPIPS loss against rendered and pseudo multi-view images.

## Results

On the Consistent4D dataset, DS4D-DA achieves the best scores across all four metrics: CLIP 0.9225, LPIPS 0.1309, FVD 784.02, and FID-VID 24.05. On the more challenging Objaverse dataset, DS4D-DA further widens the gap, reaching FVD 870.95 and FID-VID 25.38, substantially outperforming the next-best method STAG4D (FVD 1061.36, FID-VID 30.14). On the real-world Neu3D scene dataset, the method slightly surpasses the 4D-GS baseline with PSNR 32.40 vs. 32.16 and SSIM 0.9494 vs. 0.9483, while LPIPS is marginally higher (0.1434 vs. 0.1422).

## Baselines & Comparisons

DS4D-DA outperforms all seven baselines on every metric for both the Consistent4D and Objaverse datasets. The most striking margin is on FVD: DS4D-DA achieves 784.02 vs. STAG4D's 986.83 on Consistent4D (≈21% reduction) and 870.95 vs. STAG4D's 1061.36 on Objaverse (≈18% reduction), indicating substantially fewer temporal artifacts. On the harder Objaverse benchmark, the gap widens further — DS4D-DA beats STAG4D by 0.0091 CLIP, 0.0052 LPIPS, and 4.76 FID-VID, while also surpassing SC4D by 0.0391 CLIP and 15.13 FID-VID. Among inference-based methods, L4GM is the closest competitor on Consistent4D (FVD 898.06 vs. 784.02), but it is not evaluated on Objaverse. On the real-world Neu3D scene, DS4D (inserted into 4D-GS) edges out the 4D-GS baseline on PSNR (+0.24), SSIM (+0.0011), and D-SSIM (−0.0009), though LPIPS is marginally worse (0.1434 vs. 0.1422), suggesting the gains are most pronounced in geometric fidelity rather than perceptual similarity for complex scenes.

## Relation to Prior Work

This paper extends the optimization-based 4D Gaussian generation pipeline established by STAG4D and SC4D, adopting their SDS-loss training framework and Zero123++-based multi-view generation, while introducing two novel architectural modules: DSFD, which projects current frame features onto reference frame features to separate dynamic (orthogonal) and static (parallel) components along temporal axes, and TSSF, which adaptively fuses dynamic information across viewpoints along spatial axes. The key conceptual departure from prior work is the explicit recognition that whole-frame feature modeling causes overfitting to static regions when they dominate, and that a simple projection-based decoupling can recover the dynamic signal that previous methods implicitly discard. HexPlane is borrowed for regularizing Gaussian features, and DINOv2 serves as the visual feature backbone, both standard choices in the current 4D generation literature.

## Why It Matters / Open Questions

The paper addresses a concrete and visually apparent failure mode (blurry textures in dynamic regions) that plagues current video-to-4D methods, and the decoupling strategy is lightweight enough to be plugged into existing pipelines (demonstrated by inserting DSFD/TSSF into 4D-GS for real-world scenes). However, the real-world scene results (Table 3) show only marginal gains over 4D-GS, suggesting the benefit may be most pronounced for object-centric content with clear dynamic-static separation rather than complex scenes. Open questions include whether the middle-frame reference strategy generalizes to videos with non-stationary camera motion, whether the projection-based decoupling captures all relevant dynamic information (e.g., global shape changes vs. local texture shifts), and whether the approach can be extended to handle topological changes or multiple independently moving objects.

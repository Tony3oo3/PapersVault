## Problem

Camera-based 3D object detection lags behind LiDAR-based approaches due to the absence of explicit 3D geometric cues. Existing cross-modal knowledge distillation methods struggle to bridge the substantial modality gap between point clouds and images, and the lack of LiDAR input at inference fundamentally limits the student's capacity to recover accurate 3D structure.
![Teaser figure](../imgs/ICCV20250278/cropped_page0_idx1.webp)

## Input / Output

At inference, the student consumes only multi-view RGB images (6 cameras, 256×704 for R50 or 512×1408 for R101) and produces 3D bounding boxes with class labels in a 102.4 m × 102.4 m × 8 m BEV region. During training, the LiDAR-based teacher (CenterPoint with SECOND backbone) processes point clouds to generate supervisory signals, but no LiDAR is required at test time. The memory module stores 160K distilled features queried via 6.4K latent embeddings, adding a compact parametric store that is frozen after the distillation stage.

## Method

MemDistill augments a camera-based student (BEVDepth backbone + CenterPoint neck/head) with a dedicated memory module and a Perceiver IO-inspired scene-dependent retriever. The retriever uses two transformer decoders and one encoder: latent embeddings first attend to camera BEV features to form scene-aware queries, which then attend to the memory to produce LiDAR-informed complementary features fused with the original camera features. Training is two-stage: (1) memory distillation, where only the memory and retriever are trained to minimize MSE between student and teacher intermediate features and predictions while the rest of the student is frozen; (2) fine-tuning, where the student is further aligned with the teacher while the memory stays frozen to preserve distilled knowledge. The hybrid architecture—sharing the LiDAR teacher's neck and head with the student—reduces the representation-space gap and enables the memory to encode features closely resembling actual LiDAR features.

## Results

On the nuScenes validation set, MemDistill with ResNet-50 achieves 42.5% mAP and 53.1% NDS, improving over its BEVDepth baseline by 9.2 percentage points in mAP and 9.0 in NDS. With ResNet-101, it reaches 45.9% mAP and 55.8% NDS (+5.3%p mAP, +6.8%p NDS over baseline). These results establish state-of-the-art performance among all camera-based 3D object detectors, surpassing both non-KD methods (e.g., SOLOFusion at 40.6% mAP) and prior LiDAR-to-camera KD methods (e.g., LabelDistill at 41.9% mAP with R50). The LiDAR-based teacher CenterPoint still leads at 56.1% mAP / 64.6% NDS, indicating a remaining gap of ~13.6%p mAP.

## Baselines & Comparisons

MemDistill outperforms all prior LiDAR-to-camera KD methods on both backbones. With R50, it beats the closest competitor LabelDistill [20] by 0.6%p mAP (42.5 vs. 41.9) and 0.3%p NDS (53.1 vs. 528), and leads DistillBEV [43] and X³KD [21] by 3.5–3.6%p mAP. With R101, the margin over LabelDistill widens to 0.8%p mAP and 0.5%p NDS, while it surpasses DistillBEV by 0.9%p mAP. Against the strongest non-KD camera-based detectors, MemDistill (R50) exceeds SOLOFusion [34] by 1.9%p mAP and 3.4%p NDS, and (R101) surpasses Sparse4D [28] by 2.3%p mAP and 1.7%p NDS. The method also achieves the best mATE (0.581 R50, 0.571 R101) and mAVE (0.331 R50, 0.316 R101) among all compared methods, indicating superior localization and velocity estimation. The LiDAR-based teacher CenterPoint [48] remains ahead by 13.6%p mAP (R50) and 10.2%p mAP (R101), confirming that the modality gap is reduced but not fully closed.

## Relation to Prior Work

MemDistill extends the cross-modal knowledge distillation line for 3D object detection (BEVDistill, DistillBEV, TiG-BEV, X³KD, LabelDistill) by replacing direct feature-matching losses with a dedicated memory module and scene-dependent retrieval mechanism inspired by Perceiver IO. Architecturally, it departs from prior KD methods by constructing a hybrid student that borrows the LiDAR teacher's neck and head while retaining a camera-based backbone (BEVDepth), thereby reducing the representation-space gap before distillation even begins. The two-stage training protocol—first freezing the student to distill LiDAR knowledge into the memory, then fine-tuning the student with the memory frozen—differs from both end-to-end joint optimization and single-stage KD approaches used in prior work.

## Why It Matters / Open Questions

MemDistill narrows the camera-to-LiDAR performance gap on nuScenes to roughly 14 mAP points (0.425 vs. 0.561 for CenterPoint), a meaningful reduction for deployment scenarios where LiDAR is unavailable at inference. The memory-based retrieval paradigm offers a conceptually distinct alternative to direct feature alignment, suggesting that compact, scene-conditioned storage of cross-modal knowledge may generalize to other modality-pair distillation settings. However, the method still requires LiDAR data during training (C* modality), is evaluated only on nuScenes, and the margin over the strongest prior KD method (LabelDistill, 0.419 mAP) is modest (~0.6%p), leaving open whether the memory mechanism scales to larger datasets, more object categories, or real-time inference constraints.

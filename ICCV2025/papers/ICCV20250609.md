## Problem

In Multi-Image Visual Question Answering (MVQA), the growing number of input images introduces substantial visual redundancy that submerges question-critical tokens, degrading MLLM accuracy. Existing compression methods either require training, enforce fixed compression ratios that mismatch per-image redundancy levels, or select discrete individual tokens that fragment spatial semantics and disrupt cross-image reasoning.
![Teaser figure](../imgs/ICCV20250609/cropped_page0_idx0.webp)

## Input / Output

The method takes N RGB images (each encoded into K visual tokens via a standard vision encoder, e.g., 576 tokens per 336×336 image) along with a text question prompt and optional per-image captions. It outputs a single textual answer generated autoregressively by the LLM. The compression is adaptive per image: the number of retained visual tokens varies depending on how much of each image is relevant to the question, rather than applying a uniform ratio across all images.

## Method

The proposed Adaptive Visual Anchoring (AVA) strategy is a three-step training-free pipeline: (1) compute a token-level response map via cosine similarity between each visual token and the globally pooled text embedding; (2) locate the response hotspot center using a gravity-center formula on the 2D response map, then generate all centered anchor boxes of increasing size; (3) select the anchor box maximizing response density (mean response score) subject to a minimum area ratio, preserving spatially contiguous regions. A Collaborative Decoding mechanism then fuses the next-token probability distributions from the full visual input (P_o) and the compressed key-region input (P_b) using a weight β = e^(−λr), where r is the overall visual redundancy rate, so that higher redundancy shifts more weight toward the compressed local cues. The entire approach is plug-and-play, requiring no parameter updates, and can be embedded into any MLLM operating on patch-embedded visual tokens.

## Results

On MuirBench, integrating AVAM into seven MLLMs yields consistent average accuracy gains, with the largest improvements for LLaVA-v1.5-7B (24.2→27.6, +3.4) and Idefics2-8B (26.1→29.4, +3.3). On MIBench MII, the gains are particularly dramatic for models that previously exceeded context length: LLaVA-v1.5-7B jumps from 16.2 to 31.7 and DeepSeek-VL-7B from 33.4 to 52.0. Against fixed-ratio compression baselines (FastV, SparseVLM, FasterVLM, VisionZip) at 33.3% retention, AVAM's adaptive compression (58.4% average) achieves 27.6 average accuracy on MuirBench, surpassing the best fixed-ratio method (FasterVLM at 25.6) by 2.0 points.

## Baselines & Comparisons

Against the seven MLLM baselines (LLaVA-v1.5, DeepSeek-VL, Mantis, InternVL2, Qwen-VL, Idefics2, LLaVA-OV), AVAM consistently improves average accuracy on all three benchmarks, with the most substantial gains on MIBench MII where LLaVA-v1.5 improves by +15.5 points (16.2→31.7) and DeepSeek-VL by +18.6 points (33.4→52.0), largely because token reduction resolves context-length overflow. Against the four training-free compression baselines evaluated at fixed 33.3% retention on MuirBench (Table 4), AVAM (27.6 avg) outperforms FasterVLM (25.6), SparseVLM (25.5), VisionZip (25.0), and FastV (21.9), with the gap widening at higher compression ratios (e.g., at 11.1% retention, AVAM's adaptive 58.4% still yields 27.0 vs. SparseVLM's 25.4). The vanilla no-compression baseline (24.3) is also surpassed, confirming that adaptive compression with collaborative decoding is superior to both no compression and fixed-ratio pruning. Gains are most pronounced on tasks requiring text-visual alignment (ITM, FVR, TVK) and reasoning under long contexts (TR, LR), while fine-grained discrimination tasks (GC, SD, VR) show smaller or negligible improvements, particularly for query-based models like Qwen-VL.

## Relation to Prior Work

This paper extends the visual token compression literature for MLLMs from single-image to multi-image VQA, building on the cosine-similarity-based relevance scoring introduced in Free Video-LLM [18]. It departs from both learning-based compression (Qwen-VL, Idefics2) and existing training-free methods (FastV, VisionZip, FasterVLM, SparseVLM) in two key ways: replacing discrete token selection with continuous spatial region extraction via anchor boxes, and replacing fixed compression ratios with an adaptive mechanism driven by a response density metric. The collaborative decoding mechanism further distinguishes the work from prior contrastive decoding approaches by dynamically weighting global and compressed distributions based on measured redundancy rather than adversarial suppression.

## Why It Matters / Open Questions

The training-free, plug-and-play nature of the method makes it immediately applicable to a wide range of existing MLLMs without retraining, which is practically significant for the multi-image understanding community. However, the method does not achieve extreme compression ratios and requires two forward passes (global + compressed) for collaborative decoding, introducing additional inference cost. Open questions include how the approach scales to very large image counts (e.g., video), whether the anchor-box heuristic generalizes to non-grid token layouts, and whether the collaborative decoding can be made more efficient than a full dual-pass inference.

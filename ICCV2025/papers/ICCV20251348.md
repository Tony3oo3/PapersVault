## Problem

Existing prompt-based image editing methods (e.g., Prompt-to-Prompt) were designed for U-Net architectures with separate self-attention and cross-attention layers, where information flows unidirectionally from text to image. The shift to multimodal diffusion transformers (MM-DiT) in models like Stable Diffusion 3 and Flux.1 introduces a unified full-attention mechanism with bidirectional text-image interaction, rendering these techniques inapplicable. This paper asks how to systematically interpret MM-DiT's attention structure to transfer and adapt existing editing capabilities to this new architecture.

## Input / Output

The method takes a source prompt and a target prompt (which can be arbitrarily different, requiring no token-level alignment) and optionally a real image inverted into a noisy latent for real-image editing. It operates on 64×64 image latents (4096 tokens) and 333 text tokens (77 CLIP + 256 T5) at 1024×1024 resolution, using 28 timesteps for standard models or 4 for distilled variants (Flux.1-schnell, SD3.5-L-Turbo). The output is a single edited image that preserves the source composition while incorporating target prompt elements, with a masking threshold parameter controlling edit granularity from fine text changes to broad object replacements.

## Method

The paper decomposes MM-DiT's concatenated attention matrix into four blocks (I2I, T2I, I2T, T2T) and shows that I2I preserves spatial identity (analogous to U-Net self-attention) while T2I encodes token-to-region correspondences (analogous to cross-attention). For editing, it replaces only the image input projections (q_i, k_i) in the target branch with source-branch counterparts during the first 20% of denoising timesteps, deliberately leaving text projections untouched to avoid T5 embedding misalignment. For local edits, it extracts T2I attention maps from a fixed set of top-5 transformer blocks (selected via BCE/mIoU/MSE against Grounded SAM2 ground-truth masks over 100 prompts), applies Gaussian smoothing, thresholds to a binary mask, and blends source and target latents per-timestep. This projection-level modification preserves compatibility with optimized SDPA kernels (avoiding up to 3× slowdown from manual attention computation) and eliminates the need for explicit token mapping between source and target prompts, a key limitation of prior U-Net-based methods.

## Results

On the PARTI prompt set (60 prompts, 28 timesteps), the proposed method achieves a balanced trade-off between source preservation (LPIPS) and target prompt alignment (CLIPScore) across all six MM-DiT variants. For example, on Flux.1-dev, the method scores LPIPS 0.369 and CLIP 0.339, compared to Fixed Seed (LPIPS 0.579, CLIP 0.359) and Prompt Change (LPIPS 0.251, CLIP 0.311). On SD3.5-L, the method reaches LPIPS 0.418 and CLIP 0.377, outperforming Prompt Change on CLIP (0.377 vs. 0.363) while maintaining reasonable source fidelity. For few-step models (4 timesteps), the method still achieves competitive results, e.g., Flux.1-schnell: LPIPS 0.279, CLIP 0.333.

## Baselines & Comparisons

Against the SDEdit-style prompt-switching baseline [41] ("Prompt Change"), the proposed method consistently achieves higher CLIPScore across all six models (e.g., 0.377 vs. 0.363 on SD3.5-L; 0.339 vs. 0.311 on Flux.1-dev), indicating better target prompt alignment, while accepting a moderate increase in LPIPS (i.e., slightly more deviation from the source). The Fixed Seed baseline produces the highest CLIP scores but with LPIPS values of 0.51–0.59, meaning the output is essentially a completely different image rather than an edit. For real-image editing on PIE-Bench, the method improves upon the naive RF inversion baseline [56, 63] by providing additional controllability through q_i/k_i projection replacement and local blending, yielding more precise local edits while preserving unchanged regions (Fig. 14). The paper notes that real-image editing performance depends more heavily on inversion quality than on the architectural editing method itself, so the advantage over RF inversion is incremental rather than dramatic.

## Relation to Prior Work

This paper extends the U-Net attention manipulation paradigm—where self-attention governs spatial structure and cross-attention handles text-aligned semantics (P2P [19], MasActrl [4], Attend-and-Excite [5])—to the newer MM-DiT architecture used in Stable Diffusion 3 and Flux.1. The key conceptual departure is that MM-DiT's unified full-attention mechanism, which concatenates text and image tokens before a single attention operation, breaks the clean self/cross-attention separation that prior methods exploit. The authors show that the four resulting attention sub-blocks (I2I, T2I, I2T, T2T) recover analogous roles, and that replacing only image input projections (q_i, k_i) suffices for editing, eliminating the explicit source-to-target token mapping that P2P and successors require.

## Why It Matters / Open Questions

As MM-DiT becomes the dominant architecture for state-of-the-art text-to-image models, understanding its internal attention dynamics is essential for adapting the large body of U-Net-based editing and control techniques. The finding that attention maps grow noisier with model scale—echoing ViT register artifacts—provides a practical diagnostic (top-5 block selection + Gaussian smoothing) that practitioners can immediately apply. Open questions include whether the block decomposition generalizes to future multimodal architectures, whether the noise issue can be addressed architecturally (e.g., via registers) rather than post-hoc, and how the method interacts with increasingly aggressive distillation (1-step models). For real-image editing, performance remains heavily dependent on inversion quality, which is an orthogonal but critical bottleneck.

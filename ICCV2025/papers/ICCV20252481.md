## Problem

Path imitation learning from expert demonstrations typically focuses on finding the shortest path, overlooking path smoothness. Reference paths from human-labeled trajectories or empirical motions are often not the shortest but exhibit specific curvature that standard A* and neural A* fail to replicate, resulting in poor path similarity. The paper identifies that the degree of path smoothness (i.e., the trade-off between minimum and maximum turn angles) is dataset-dependent and must be learned adaptively rather than fixed.

## Input / Output

The method takes a 2D image map (binary maze at 32×32 to 64×64, video-game maps downsampled to 12×12 or 20×20, or drone-view maps at 64×64) along with a source and target node coordinate. A CNN (UNet or custom convolutional stack) or Transformer encodes the image into a per-node cost map (path probability map), which is then consumed by the modified A* search. The output is a discrete node sequence from source to target, with the path length and curvature jointly optimized during training via L1 path loss against a binary reference path.

## Method

DAA* introduces Path Angular Freedom (PAF), a higher-order term that computes the angle θ_jik between two consecutive path segments at each intermediate node and applies a learned trade-off h_jik = α·θ_jik + (1−α)·(π−θ_jik) to balance path shortening against smoothing. This PAF is integrated into A* via a message-passing node expansion where each node's traversal cost combines the learned node prior θ_i, a weighted heuristic distance (Chebyshev + Euclidean), and the PAF term scaled by a learned weight κ. Training is end-to-end supervised: a CNN or Transformer predicts the cost map, and gradients flow through the discretized-activation A* search using only L1 path loss (and optionally PPM loss), with α, λ, and κ learned jointly. Unlike any-angle algorithms (e.g., Theta*) that require obstacle-corner waypoints, DAA* imposes angular constraints directly at every search step, eliminating the need for explicit corner detection and reducing search space while improving generalization to real-world scenarios like roundabouts.

## Results

On the MPD maze dataset, DAA*-mix achieves 95.56% SPR, 47.83% PSIM, and 58.72% ASIM, outperforming neural A* (91.19%, 44.26%, 54.93%) by 4.4% SPR, 3.6% PSIM, and 3.8% ASIM while also reducing search history (Ep 69.99% vs 44.10%). On Aug-TMPD with joint PPM and path loss, DAA*-weight reaches 96.87% SPR, 55.73% PSIM, and 66.20% ASIM, surpassing the state-of-the-art TransPath (90.62%, 49.78%, 62.53%) by 6.3% SPR, 6.0% PSIM, and 3.7% ASIM. On the real-world SDD drone-view dataset, DAA*-mix achieves 42.12% PSIM and 47.82% ASIM (intra-scene) and 38.78% PSIM and 49.77% ASIM (inter-scene), consistently outperforming all baselines in path similarity to human-labelled reference paths.

## Baselines & Comparisons

DAA* consistently outperforms neural A* [57] across all datasets and metrics: on MPD it gains +4.4% SPR, +3.6% PSIM, +3.8% ASIM, and +25.9% Ep; on SDD-intra it gains +2.0% PSIM and +4.0% ASIM. Against the state-of-the-art TransPath [29] on Aug-TMPD, DAA*-weight achieves 96.87% SPR vs 90.62% (+6.3%), 55.73% PSIM vs 49.78% (+6.0%), and 66.20% ASIM vs 62.53% (+3.7%), while also using fewer search steps (Hist 3.66 vs 1.83 is lower for TransPath, but DAA*-path with only path loss achieves competitive results without requiring expensive reference PPMs). Traditional A* [24] and Theta* [15] achieve higher SPR (98.70% on MPD) but substantially lower path similarity (35.20% and 38.00% PSIM respectively) and require exhaustive search (no Ep reduction), making them unsuitable for imitation learning where the reference path is not the shortest. The random-walk baseline, which perturbs node expansion order, improves PSIM over neural A* but sacrifices SPR dramatically (82.06% vs 91.19% on MPD), confirming that DAA*'s learned PAF provides a more principled smoothness constraint than random perturbation.

## Relation to Prior Work

This paper extends Neural A* (Yonetani et al., 2021), which made A* differentiable for end-to-end cost-map learning, by introducing Path Angular Freedom (PAF) as a learned higher-order (triple-node) term that adapts path smoothness during search. It departs from Theta*-style any-angle methods that require explicit obstacle-corner waypoints, instead imposing angular constraints at every search step, making it applicable to scenarios without distinct corners (e.g., roundabouts). Against the state-of-the-art TransPath (Kirilenko et al., 2023), DAA* replaces the expensive pixel-wise PPM supervision with simpler binary path labelling while jointly optimizing path shortening and smoothing within a unified message-passing formulation.

## Why It Matters / Open Questions

The paper demonstrates that path smoothness—long overlooked in imitation-based path planning—can be learned adaptively via a single scalar (α) per dataset, yielding consistent gains in path similarity across mazes, video games, and real drone-view maps. The practical advantage of requiring only binary path labels rather than expensive PPM references makes the approach more accessible for real-world deployment. Limitations include a minor search-efficiency trade-off (Hist increases by up to 6.4% on some datasets), restriction to 2D single-source/single-target settings, and the need for per-dataset α tuning (though learned end-to-end). Open questions include extension to 3D, multi-agent, and collision-free navigation with higher training efficiency.

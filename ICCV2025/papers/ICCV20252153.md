## Problem

Existing compositional visual grounding methods rely on LLMs to perform reasoning in natural language, which lacks the formal structure needed for accurate geometric and relational inference, and they have no mechanism to detect and correct errors that propagate through the pipeline. This paper addresses both gaps by introducing explicit probabilistic logic reasoning and a self-correcting control structure into the compositional grounding pipeline.
![Teaser figure](../imgs/ICCV20252153/cropped_page0_idx1.webp)

## Input / Output

NAVER takes an RGB image and a free-form textual referring expression (e.g., 'a person on the left wearing a blue shirt in front of a car') as input. It outputs a single bounding box (detection) or pixel-level segmentation mask (segmentation) for the entity satisfying the query. Internally, the image is processed through a VLM captioner, a foundation grounding model for entity localization, a depth estimator for spatial relations, and an attribute-recognition VLM, all of which feed probabilistic facts into the logic engine; the final output is validated by a VLM answerer before being returned.

## Method

NAVER organizes the grounding pipeline as a deterministic finite-state automaton (DFA) with five states—Perception, Logic Generation, Logic Reasoning, Answering, and Return Target—where transitions are governed by explicit conditions (e.g., number of detected entities, logic execution success, answerer verdict). The core novelty is the Logic Generation and Logic Reasoning states: an LLM translates the query and perceived entities into ProbLog code (probabilistic facts for entities, spatial relations, and attributes, plus a target query rule), which is then executed via the Scallop probabilistic logic programming engine to rank candidate entities by probability. The DFA's self-correction mechanism allows the system to loop back to Logic Generation if no candidates are produced, to try the next-ranked candidate if the VLM answerer rejects the top one, or to re-enter Perception if all candidates fail, with a bounded retry limit to prevent infinite loops. The entire system is training-free, composing off-the-shelf LLMs (GPT-4o Mini), VLMs (InternVL2, XVLM), grounding models (Florence2-L, GLIP, GroundingDINO), a depth estimator (DepthAnythingV2), and SAM for mask generation.

## Results

On referring expression detection, NAVER with SoTA foundation models (NAVER*) achieves 96.2% accuracy on RefCOCO, 92.8% on RefCOCO+, 91.6% on RefCOCOg, and 75.4% on Ref-Adv, outperforming the best end-to-end baseline Florence2-L (95.1/92.5/90.9/71.8). With the same foundation models as compositional baselines (NAVER†), it still leads with 70.1/64.1/69.5/65.1, surpassing ViperGPT† (62.6/62.3/67.2/60.7) and HYDRA† (60.9/56.5/62.9/54.4). For segmentation on RefCOCOg test, NAVER* reaches 76.0 IoU, exceeding GLaMM (74.9) and all compositional baselines. NAVER also achieves a near-zero runtime failure rate (0.3%) compared to 70.2% for ViperGPT and 10.3% for HYDRA.

## Baselines & Comparisons

NAVER outperforms all compositional baselines across every dataset and both model configurations. With matched foundation models (†), NAVER leads ViperGPT by 7.5 points on RefCOCO and 10.7 on Ref-Adv, and leads HYDRA by 9.2 on RefCOCO and 10.7 on Ref-Adv. With SoTA models (*), NAVER surpasses the best end-to-end method Florence2-L by 1.1 points on RefCOCO and 3.6 on Ref-Adv, while also exceeding ViperGPT* by 27.6 on RefCOCO and 17.2 on Ref-Adv. For segmentation on RefCOCOg test, NAVER* (76.0 IoU) beats GLaMM (74.9) and HYDRA* (54.0) by 1.1 and 22.0 points respectively. On RefCLEF, NAVER* achieves 68.8/67.4 IoU on Test A/B, exceeding GLaMM (67.5/66.8). The ablation in Table 6 confirms that the DFA self-correction mechanism, ProbLog logic reasoning, and VLM answerer each contribute substantial gains, with the full system reaching 96.2% versus 51.7% when all three are disabled.

## Relation to Prior Work

NAVER extends the compositional visual reasoning line (ViperGPT, HYDRA, VisProg) by replacing their reliance on LLM-generated Python code or natural-language reasoning with explicit probabilistic logic programming (ProbLog/Scallop) embedded in a deterministic finite-state automaton. It builds directly on ProbLog's probabilistic logic framework for representing uncertain visual facts (entity confidences, attribute probabilities, spatial relations) and departs from prior compositional methods by introducing a self-correcting DFA that can revisit earlier states rather than proceeding strictly sequentially. The perception components (entity detection, attribute recognition, depth estimation) are drawn from existing vision foundation models, while the reasoning backbone is the novel neuro-symbolic contribution.

## Why It Matters / Open Questions

The 0.3% runtime failure rate (vs. 10.3% for HYDRA and 70.2% for ViperGPT) makes compositional visual grounding substantially more reliable for real-world deployment, and the explicit logic representation provides verifiable, interpretable reasoning traces that end-to-end models cannot offer. The DFA-based self-correction design is a general pattern that could transfer to other multi-step query-answering pipelines. Key open questions include whether the approach scales to more complex multi-entity scenes, whether the LLM's ProbLog code generation remains the bottleneck as queries grow in logical depth, and whether the heavy reliance on a VLM answerer for final verification (contributing ~20 points in ablation) can be reduced without sacrificing accuracy.

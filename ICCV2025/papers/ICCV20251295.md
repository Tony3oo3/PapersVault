## Problem

Existing cross-view object geo-localization schemes (retrieval-based patch matching and detection-based bounding boxes) rely on rectangular regions to define object locations in satellite imagery, which inherently fail to precisely capture irregularly shaped objects, causing incomplete coverage or erroneous inclusion of background. This paper identifies this 'rectangular shackle' limitation and proposes a segmentation-based reformulation (CVOS) that predicts pixel-level masks for fine-grained geo-localization, enabling extraction of object shape and area critical for urban planning and agricultural monitoring.
![Teaser figure](../imgs/ICCV20251295/cropped_page0_idx1.webp)

## Input / Output

The method takes a query image (ground 256×512 or drone 256×256) with a single click point marking the target object, and a reference satellite image (1024×1024) carrying GPS coordinates and coverage area. The click point is encoded as a spatially decaying point embedding matrix and channel-wise concatenated with the query image before feature extraction. The output is a high-resolution (1024×1024) pixel-level segmentation mask on the satellite image, plus a bounding box; the mask combined with the satellite's georeferencing yields the object's precise shape, area, and geographic extent.

## Method

TROGeo is a two-stage framework. In the Heterogeneous Task Training Stage (HTTS), a single Swin-S Transformer encoder (shared weights) processes both query and reference images; the query image additionally receives the click-point embedding. A Cross-View Object Perception Module (CVOPM) then performs multi-head cross-attention with reference features as queries and query features as keys/values, allowing the model to integrate local object details with surrounding contextual cues (road layout, neighboring buildings) for discriminative localization. The perceptual feature map is supervised by a heterogeneous task that simultaneously predicts a bounding box (ODT) and a low-resolution 64×64 mask (OST), with loss L = L_ODT + 2·L_OST. In the SAM Prompt Stage (SPS), the frozen SAM-Huge model receives the HTTS-predicted bounding box and its center point as external prompts, generating the final high-resolution segmentation mask on the satellite image without any additional training.

## Results

On the CVOGL dataset (bbox-based evaluation), TROGeo with OST achieves 68.96% Acc@50% and 76.16% Acc@25% on the Drone→Satellite test set, outperforming the second-best method VAGeo (61.87% / 66.19%) by over 7 points. On the newly introduced CVOGL-Seg dataset (mask-based evaluation), TROGeo achieves 56.59% mIoU and 64.24% mDice on the Drone→Satellite test set, with an Absolute Area Error of 927 m², substantially surpassing DetGeo+SPS (42.27% mIoU, 1149 m² AAE) and Sample4Geo+SPS (18.67% mIoU, 2178 m² AAE). On the Ground→Satellite test set, TROGeo reaches 38.12% mIoU and 43.34% mDice, again leading all baselines.

## Baselines & Comparisons

TROGeo decisively outperforms all retrieval-based baselines (CVM-Net, RK-Net, L2LTR, TransGeo, SAFA, Sample4Geo) on both datasets; even the best retrieval method Sample4Geo achieves only 18.40% Acc@50% on CVOGL Drone→Satellite test versus TROGeo's 68.96%, and 18.67% mIoU on CVOGL-Seg versus 56.59%. Among detection-based methods, VAGeo is the strongest baseline on CVOGL (61.87% Acc@50% Drone→Satellite test), but TROGeo still leads by 7.09 points. DetGeo, the first detection-based cross-view object geo-localization method, achieves 57.66% Acc@50% on CVOGL and 42.27% mIoU (with SPS) on CVOGL-Seg, trailing TROGeo by 11.3 and 14.3 points respectively. Notably, adding the SPS module to DetGeo improves its mIoU from 30.50% to 42.27% on CVOGL-Seg, confirming that the SAM prompt stage is a general-purpose enhancement, yet TROGeo's more accurate HTTS prompts yield a further 14.3-point mIoU gain over DetGeo+SPS.

## Relation to Prior Work

This paper departs from the two dominant paradigms in cross-view object geo-localization—retrieval-based (uniform patch matching) and detection-based (bounding box regression)—by introducing a segmentation-based formulation that outputs pixel-level masks. Architecturally, it builds on the Swin Transformer backbone and the anchor-based detection objective from DetGeo [37], while the Cross-View Object Perception Module draws on cross-attention mechanisms inspired by latent diffusion models [33]. The SAM Prompt Stage repurposes the Segment Anything Model [21] as a frozen, zero-shot mask generator guided by learned bounding-box prompts, effectively decoupling cross-view correspondence learning from high-resolution mask synthesis.

## Why It Matters / Open Questions

By replacing rectangular proposals with segmentation masks, CVOS unlocks object properties (shape, area, precise boundary) that are critical for urban planning and agricultural monitoring but fundamentally inaccessible to prior schemes. The CVOGL-Seg dataset (6,079 high-resolution masks) provides the first benchmark for this formulation, though it is derived from CVOGL + OpenStreetMap and covers a limited set of object categories and three area scales. Open questions include whether the two-stage pipeline generalizes to larger geographic extents, whether SAM can be replaced by lighter models for edge deployment, and whether the heterogeneous-task supervision transfers to object categories absent from the training distribution.

## Problem

Existing mixed-precision quantization methods allocate different bit widths across layers but overlook intra-layer activation sparsity, while activation pruning methods exploit this sparsity but require retraining, degrade sharply at high pruning ratios, and are fragile to out-of-distribution inputs where window selection fails. This paper asks whether intra-layer activation sparsity can be exploited through mixed-precision quantization instead of outright computation skipping, preserving robustness and enabling training-free integration.

## Input / Output

The method operates on standard RGB images (COCO at 1333×800 resolution) fed into a Mask R-CNN or Mask2Former with a Swin-Tiny backbone, producing bounding boxes with class labels or panoptic segmentation masks as in the base model. Internally, the feature map is partitioned into non-overlapping 7×7 windows per stage, and each window's L2 norm determines whether it is routed to a high-precision (4-bit) or low-precision (2-bit) branch, so the output format is unchanged but the computational cost per window varies dynamically at inference time.

## Method

MixA-Q introduces a Two-Branch Swin Block that replaces each Swin block, splitting windows into high- and low-precision branches based on L2-norm importance scores computed once per stage; the branches share MHA and FFN weights but maintain independent quantization step sizes and zero points, with duplicated layer normalizations to handle distribution shift. Compression ratios (the fraction of windows assigned to the low-precision branch) are optimized per stage via NSGA-II evolutionary search over a bi-objective of computational savings and mAP. A sparsity-aware quantization adaptation (SAQA) phase trains the model with randomly sampled compression ratios using a proposed uniform-sum Dirichlet sampling scheme, making the model robust to any ratio configuration without retraining. A key emergent effect—dynamic activation distillation—arises because only important windows' gradients flow through the high-precision branch during SAQA, selectively reducing quantization noise in foreground regions and improving mAP by 0.7% over the uniform W4A4 baseline. Optionally, activation pruning can be layered on top for higher speedup targets, skipping the least important windows entirely while retaining the rest in mixed precision.

## Results

On COCO object detection with a Swin-Tiny backbone, MixA-Q achieves a 1.35× computational speedup (8.21 T BOPs vs. 11.05 T BOPs) with 42.3 mAP in the W4A4 QAT setting, compared to 41.4 mAP for the uniform-bit W4A3 OFQ baseline at a similar speedup. In the PTQ (W4A8) setting, MixA-Q delivers a training-free 1.35× speedup without accuracy loss. By incorporating 30% activation pruning, MixA-Q reaches a 1.53× speedup with only 1% mAP drop (42.1 mAP), outperforming pure SparseViT pruning (41.4 mAP) at the same cost. Additionally, the sparsity-aware quantization adaptation improves the W4A4 model's mAP by 0.7% (43.1→43.8), reducing quantization degradation by 24%.

## Baselines & Comparisons

Against the uniform-bit QAT baseline OFQ, MixA-Q achieves a 1.24× speedup with slightly higher mAP (43.2 vs. 43.1) at the same BOPs, and at 1.35× speedup it retains 42.3 mAP versus only 41.4 mAP for the W4A3 OFQ model (a 0.9 mAP advantage). Compared to the activation-pruning method SparseViT, MixA-Q matches or slightly exceeds mAP at moderate speedups (≥0.75 relative cost), but at aggressive speedups (≤0.7 relative cost) pure MixA-Q falls behind SparseViT; however, MixA-Q with 30% activation pruning consistently outperforms SparseViT by 0.7–0.4 mAP at 1.53×, 1.66×, and 1.82× speedups respectively (e.g., 42.1 vs. 41.4 mAP at 1.53×). In the PTQ setting, MixA-Q integrated with RepQ (W4A8) consistently dominates the uniform-bit RepQ Pareto front across two different calibration sets, while also using only 4-bit and 8-bit precisions that are natively supported by hardware (unlike the 5–7-bit widths required by uniform reduction). On OOD inputs (COCO-O foggy weather), MixA-Q degrades less than SparseViT (26.5% vs. 30.2% mAP drop), and in the worst-case window-selection scenario the gap widens to 30.6% vs. 43.4%, confirming the robustness advantage of retaining low-precision computation over outright pruning.

## Relation to Prior Work

This paper repurposes the window-level activation sparsity concept from SparseViT (which prunes less important windows in Swin Transformers) into a mixed-precision quantization framework, replacing computation skipping with lower-precision computation. It departs from prior mixed-precision quantization methods (HAWQ, MetaMix, PMQ, Granular-DQ) that focus on inter-layer bit-width allocation by instead exploiting intra-layer spatial sparsity across windows. The Two-Branch Swin Block is a new architectural component that enables this separation, and the sparsity-aware quantization adaptation (SAQA) is adapted from SparseViT's sparsity-aware adaptation but modified with a uniform-sum compression ratio sampling algorithm for improved efficiency.

## Why It Matters / Open Questions

The practical significance lies in offering a training-free (PTQ-compatible) alternative to activation pruning that is more robust to out-of-distribution inputs, which is critical for safety-critical deployments like autonomous driving. The dynamic activation distillation finding—that SAQA actually improves the quantized model's mAP by 0.7% by selectively reducing quantization error in important regions—suggests a broader principle for quantization adaptation. Limitations include evaluation only on Swin-Tiny with Mask R-CNN/Mask2Former on COCO, speedup measured in BOPs rather than wall-clock time, and the method's specificity to window-based ViTs. Open questions include whether the approach generalizes to non-windowed architectures, whether BOPs savings translate to real hardware latency reductions, and whether the dynamic distillation effect holds at even lower bit widths or on larger models.

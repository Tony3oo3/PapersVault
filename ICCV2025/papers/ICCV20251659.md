## Problem

Existing 4D panoptic segmentation methods are too computationally expensive for real-time inference, while prior streaming perception work focuses on 2D/3D bounding-box detection that lacks the fine-grained per-point scene understanding needed for safe navigation in dynamic, map-free environments. No prior approach achieves real-time, fine-grained 4D panoptic segmentation where every incoming frame must be predicted within a strict per-frame time budget.

## Input / Output

The system consumes a streaming LiDAR point cloud sequence (10 fps on SemanticKITTI, 2 fps on nuScenes, 15 fps on HOI4D) and optionally ego-pose (known-pose setting) or estimates it via Suma++ (unknown-pose setting). It produces per-point panoptic segmentation labels (instance + semantic) at every input timestamp, distinguishing moving from static objects (e.g., 'moving car' vs. 'car'), yielding 25 classes on SemanticKITTI and 24 on nuScenes. If the current frame's computation is not yet complete, the system falls back to querying the last completed frame's memory, ensuring a prediction is always available at the dataset's frame rate.

## Method

4DSegStreamer introduces a dual-thread architecture: a predictive thread (slow) that updates a sparse ConvGRU geometric memory and LSTM-based motion memories at key frames and forecasts future ego-pose (multi-head LSTM) and dynamic-object flow (zeroFlow + LSTM), and an inference thread (fast) that aligns each incoming frame with the latest memory via ego-pose transformation and an Inverse Forward Flow Iteration, then retrieves per-voxel features from a hash-table memory through a lightweight prediction head. The key algorithmic contribution is the Inverse Forward Flow Iteration, which finds the fixed point x* = y − flow(x*) via contraction-mapping iteration, avoiding the cost of rebuilding kd-trees for forward-flow alignment while remaining more accurate than direct backward-flow prediction. The framework is plug-and-play, integrating with both 3D (P3Former) and 4D (Mask4Former) backbones: the backbone is first trained and frozen, then the pose forecaster, flow forecaster, and memory aggregation modules are trained on top. A moving-object mask restricts non-zero flow to dynamic objects, further improving alignment quality.

## Results

On SemanticKITTI (unknown pose, 10 fps), 4DSegStreamer with Mask4Former backbone achieves sLSTQ 0.688 and sPQ 0.634, outperforming the strongest baseline PTv3 (sLSTQ 0.536, sPQ 0.567) by 15.2% and 6.7% respectively. On nuScenes (known pose, 2 fps), the method reaches sLSTQ 0.765 and sPQ 0.751, and on indoor HOI4D (unknown pose, 15 fps) it achieves sLSTQ 0.511 and sPQ 0.482. The method also demonstrates superior robustness at high FPS, with slower performance degradation as frame rate increases compared to all baselines.

## Baselines & Comparisons

4DSegStreamer outperforms all seven baselines across every dataset and both pose settings. The 2D streaming methods (StreamYOLO, LongShortNet, DAMO-StreamNet) perform worst (sLSTQ 0.415–0.432 on SemanticKITTI unknown pose) because their real-time backbones are insufficient for fine-grained panoptic segmentation. The 4D panoptic methods (Mask4Former sLSTQ 0.515, Eq-4D-StOP 0.504) suffer significant degradation under streaming latency. PTv3, the strongest baseline at sLSTQ 0.536, benefits from high efficiency but still loses 7.7% (P3Former) to 15.2% (Mask4Former) to 4DSegStreamer on SemanticKITTI. On HOI4D, 4DSegStreamer (M4F) surpasses the runner-up PTv3 by 6.6% in sLSTQ (0.511 vs 0.445), confirming generalization to indoor egocentric scenes. The method's advantage is most pronounced on dynamic objects (sPQ$_d$ 0.744 vs 0.638 for PTv3), validating the effectiveness of the inverse forward flow iteration for dynamic object alignment.

## Relation to Prior Work

This paper sits at the intersection of two established research lines: streaming perception (originally developed for 2D/3D object detection with methods like StreamYOLO, LongShortNet, and DAMO-StreamNet) and offline 4D panoptic segmentation (Mask4Former, Eq-4D-StOP, NSM4D). It departs from prior streaming work by moving from bounding-box-level prediction to dense per-point segmentation, and from prior 4D segmentation by introducing the real-time streaming constraint. The dual-thread architecture draws conceptual inspiration from fast-slow system paradigms (DriveVLM-Dual, FASIONAD), but integrates both threads into a unified pipeline sharing a hash-table memory rather than relying on separate models. The inverse forward flow iteration for dynamic object alignment is a novel algorithmic contribution that builds on neural scene flow estimation (FastNSF, zeroFlow) but inverts the query direction to enable efficient fixed-point lookup.

## Why It Matters / Open Questions

The plug-and-play nature of 4DSegStreamer—consistently boosting P3Former, Mask4Former, and Eq-4D-StOP by 10–30% sLSTQ—makes it a practical wrapper for any existing 3D/4D backbone seeking real-time capability, which is valuable for deployment in autonomous driving and robotics. The demonstrated robustness at high FPS (slower performance degradation than all baselines) addresses a critical practical concern for streaming systems where compute budgets are tight. Open questions include whether the approach extends to multi-sensor fusion (camera + LiDAR), how it behaves under extreme dynamic scenes with many fast-moving objects, and whether the iterative flow alignment converges reliably in highly non-rigid deformation scenarios. The reliance on a frozen backbone for feature extraction also limits the method's ability to adapt to domain shifts.

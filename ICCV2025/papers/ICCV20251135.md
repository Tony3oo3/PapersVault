## Problem

Rectified Flow (ReFlow) models like FLUX surpass diffusion models in image quality and text alignment, but adapting them for real-image editing remains challenging. The U-Net-based feature extraction methods (cross-attention, self-attention) that power successful diffusion editing do not transfer to the MM-DiT architecture used in ReFlow, where text and image tokens are entangled through joint self-attention. Additionally, existing ReFlow inversion methods fail to accurately reconstruct source images, causing extracted features to carry inaccurate structural information.

## Input / Output

The method takes a real RGB image and a target text prompt as required inputs, with an optional source text prompt and a blended word (specifying the edit subject) for local editing. It produces a single edited image that aligns with the target prompt while preserving the source structure. The method is entirely training-free, requires no user-provided spatial mask, and operates with FLUX at 28 sampling steps; when no source prompt is available, I2T-CA injection is simply omitted and the remaining features are injected over extended timesteps.

## Method

ReFlex decomposes MM-DiT's joint self-attention into four query-key modality components and identifies three key editing features: I2T-CA (image query × text key), I2I-SA (image query × image key), and the residual feature from each block's skip connection. Rather than extracting features from a fully inverted latent (which ReFlow models reconstruct poorly), the method performs mid-step feature extraction at t=T/2, where the latent achieves near-perfect source preservation. Two adaptation techniques then balance source and target information during injection: I2T-CA adaptation maps source text tokens to target tokens (scaling unmatched tokens by α=4 to strengthen new content), and I2I-SA adaptation replaces the top-k most concentrated attention values in each row with normalized target values to prevent over-preservation of local structure while retaining global layout. For local editing, a binary mask is generated from the source I2T-CA of the blended word via Gaussian smoothing and Otsu thresholding, enabling latent blending in non-edit regions.

## Results

On PIE-Bench, ReFlex achieves CLIP text-score improvements of 1.69%–7.11% over all baselines while maintaining source preservation (PSNR in non-edit regions). On Wild-TI2I-Real, the text-alignment gains are larger, at 3.21%–16.46%, with IoU-based source preservation also competitive. In user studies, ReFlex is preferred in 68.2% of cases against four FLUX-based methods (second-best: FlowEdit at 11.2%) and 61.0% against four SD-based methods (second-best: DI+PnP at 11.4%). ReFlex consistently achieves Pareto optimality in the text-alignment vs. source-preservation trade-off across both benchmarks.

## Baselines & Comparisons

ReFlex decisively outperforms all four FLUX-based baselines (RF-Inversion, RF-Edit, FireFlow, FlowEdit) in both text alignment and user preference, with the closest competitor FlowEdit receiving only 11.2% preference versus ReFlex's 68.2%. Against SD-based methods (DI+PnP, DDIM+PnP, SDEdit, P2P-Zero), ReFlex similarly dominates, with DI+PnP as the strongest competitor at 11.4% preference. On the quantitative trade-off plot (Fig. 8), ReFlex achieves the highest CLIP text score on both benchmarks—improving 1.69%–7.11% on PIE-Bench and 3.21%–16.46% on Wild-TI2I-Real—while remaining on the Pareto frontier for source preservation (PSNR/IoU). The SD-based methods additionally suffer from lower image quality due to their U-Net backbone, as evidenced by visible artifacts in qualitative comparisons. Overall, ReFlex wins on every reported metric across all eight baselines, with the largest margins observed on Wild-TI2I-Real where source prompts are unavailable.

## Relation to Prior Work

This paper extends the feature-based editing paradigm established for U-Net diffusion models (P2P's cross-attention, PnP's self-attention) to the MM-DiT architecture used by Rectified Flow models like FLUX. Where prior ReFlow editing methods (RF-Inversion, RF-Edit, FireFlow) relied on value features that suffer from appearance leakage, this work instead decomposes the joint self-attention map into four query-key modality components and identifies I2I-SA, I2T-CA, and the residual feature as the effective editing features. The key methodological departure is mid-step feature extraction—extracting features from a latent inverted only to t=T/2 rather than from the fully inverted latent—combined with two attention adaptation techniques to recover editability lost through excessive source preservation.

## Why It Matters / Open Questions

As FLUX and other ReFlow models become the dominant text-to-image backbone, the lack of effective real-image editing methods is a practical gap this paper addresses with a training-free, mask-free approach that works even without a source prompt. The systematic decomposition of MM-DiT's joint self-attention provides a reusable analytical framework for future ReFlow editing research. Remaining limitations include loss of fine-grained source details when the edit region overlaps the subject, artifacts from imperfect I2T-CA-derived editing masks, and variability in results; automatic detection of blended words and generalization to other ReFlow architectures remain open.

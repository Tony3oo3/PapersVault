## Problem

3D point cloud VLMs (e.g., ULIP2) are pre-trained on far fewer samples (~800k) than their 2D counterparts (e.g., CLIP with 400M pairs), severely limiting their ability to generalize across unseen categories and distributional shifts. This makes standard cosine-similarity-based OOD scoring unreliable for 3D point clouds, and existing training-based OOD methods require extensive in-distribution data that is often impractical to collect. The paper asks whether the structure of the testing data manifold itself can compensate for this limited pre-training to enable effective training-free OOD detection.

## Input / Output

The method consumes frozen 3D point cloud features (from PointBERT via ULIP/ULIP2, with inputs upsampled to 2048 or 1024 points depending on dataset) and text-encoded prompt templates for known ID classes, plus optionally a small set of labeled point clouds for few-shot mode. It outputs a single scalar OOD score per test sample, where higher values indicate in-distribution likelihood. The graph construction uses a fixed K=10 KNN connectivity, K-means with Nc=3 clusters per class for prompt prototypes, and a 5% threshold for selecting pseudo-negative prompts, with T=5 propagation iterations and α=0.5 damping.

## Method

GSP reformulates 3D OOD detection as iterative score propagation on a KNN graph whose nodes are text prompt prototypes (score +1), optional few-shot samples (score +1), and test samples (initial score 0), with edges weighted by L2 feature distance. Two key enhancements distinguish it from vanilla label propagation: (1) prompt clustering via K-means replaces the standard single averaged prototype per class with multiple representative cluster centers, better capturing the distribution of textual descriptions; (2) self-training negative prompting performs an initial propagation pass, selects the top m% most confident OOD samples, reassigns them a score of −1, and re-runs propagation so that negative labels compete with positive ones to widen the ID–OOD score gap. The graph is block-structured (no direct edges between prototypes and few-shot samples, only through test nodes), and the entire pipeline is training-free, requiring only frozen VLM encoders and a single self-training iteration over the test set.

## Results

On ScanObjectNN (zero-shot), GSP achieves 78.6% average AUROC and 67.4% FPR95, outperforming the strongest zero-shot baseline ULIP2 (73.2% AUROC) by 5.4 points. With 5-shot samples, GSP reaches 86.6% average AUROC on ScanObjectNN, surpassing the best fully supervised method (Cosine proto, 83.6%) by 3 points; with full-shot data it reaches 91.8%. On real-world datasets (zero-shot), GSP attains 72.5% AUROC on Sydney Urban Objects and 80.8% on nuScenes, consistently leading all baselines, while on S3DIS it achieves the highest AUROC (77.6%) but a slightly higher FPR95 (94.0%) than ULIP (95.1%).

## Baselines & Comparisons

In the zero-shot setting on ScanObjectNN, GSP (78.6% AUROC) outperforms all VLM-based baselines: ULIP2 (73.2%), ZLaP (68.3%), NegLabel (66.6%), MCM (65.2%), and DDCS (63.4%), with the largest margin over DDCS (+15.2%). On ShapeNetCore zero-shot, the gap narrows to ~0.5% over ULIP (80.4% vs 79.9%), which the authors attribute to overlap between ShapeNet pre-training and the ShapeNetCore evaluation set. In the few-shot regime, GSP with only 5 samples (86.6% AUROC on ScanObjectNN) surpasses the best fully supervised baseline Cosine proto (83.6%) by 3 points, and with full-shot data reaches 91.8%, exceeding all supervised methods by 5+ points. On real-world datasets (Table 2), GSP dominates Sydney (72.5% vs 66.2% for ULIP2) and nuScenes (80.8% vs 70.0% for ZLaP), but on S3DIS its FPR95 (94.0%) is marginally worse than ULIP (95.1%) despite achieving the highest AUROC (77.6% vs 71.3% for ZLaP). The ablation (Table 3) confirms that score propagation alone adds +3.2% AUROC over cosine distance, and combining prompt clustering with negative prompting yields the full +5.4% gain over the ULIP2 baseline.

## Relation to Prior Work

This paper extends the label propagation (LP) framework for VLMs—previously applied to zero-shot multi-class classification (ZLaP, Stojnić et al. 2024; Li et al. 2025)—to the fundamentally different one-class problem of OOD detection, where only ID class prototypes exist and the 'other' class is unbounded. It further departs from prior VLM-based OOD methods (MCM, NegLabel, DDCS) that rely solely on text-to-visual distance in the feature space, instead exploiting the testing data manifold via a KNN graph. Two additional departures from the LP literature are the use of K-means prompt clustering (rather than a single averaged prototype) and a self-training mechanism that converts high-confidence OOD test samples into pseudo-negative prompt nodes, eliminating the need for ID data to learn negative prompts.

## Why It Matters / Open Questions

The practical significance lies in enabling training-free OOD detection for 3D point clouds in safety-critical settings (autonomous driving, robotics) where collecting extensive ID training data is infeasible. The paper's key empirical insight—that manifold exploitation yields the largest gains precisely when the pre-training-to-downstream distribution shift is greatest (e.g., ScanObjectNN, Sydney, nuScenes vs. ShapeNetCore)—provides a useful diagnostic for when distance-based VLM scoring is insufficient. Limitations include the transductive requirement (the full test set must be available to build the graph), the still-high FPR95 on S3DIS (94%), and the fact that the 5% zero-shot-to-1-shot gap suggests the method remains sensitive to having even a handful of real ID samples. Open questions include whether dynamic or streaming graph updates could enable real-time OOD detection without batch access to all test samples.

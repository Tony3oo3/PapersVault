## Problem

Cross-category generalization in adaptive articulated object manipulation remains unsolved because (1) geometric diversity across real-world objects makes whole-object affordance models fail to transfer functional skills to novel categories, and (2) heterogeneous manipulation mechanisms (locking, randomized rotations, joint constraints) prevent a single policy from handling all objects. Existing approaches either train category-specific diffusion policies or rely on coarse part-pose estimation that lacks the precision needed for stable execution.
![Teaser figure](../imgs/ICCV20251200/cropped_page1_idx0.webp)

## Input / Output

The system consumes a single RGB image from a depth camera (Intel RealSense D415) and a natural language task instruction. The RGB image is processed sequentially by GPT-4o (part description), GroundingDINO (bounding box), and SAM (segmentation mask), which is then back-projected onto the depth image to reconstruct a 3D part point cloud. The final output is executable Python control code that sequences impedance-controlled primitive skill functions (grasp, pull, rotate, push) into an adaptive manipulation trajectory, with each atomic action returning a success flag that feeds back into the control loop.

## Method

AdaRPG's core insight is that object parts exhibit greater local geometric similarity than whole objects, so a part-level affordance model generalizes far better across categories. The pipeline grounds and segments the target part using a frozen GPT-4o → GroundingDINO → SAM chain (no fine-tuning), then feeds the extracted part point cloud into a PointNet++-based affordance network trained with BCE loss on a newly constructed part-level dataset (124 parts from 11 PartNet-Mobility categories, annotated with automated surface-based actionability scores). For high-level control, GPT-4o generates structured Python code from a single general prompt that orchestrates the primitive skills in adaptive while-loops (e.g., rotate-then-pull with probability-based escalation), eliminating hand-scripted per-object policies. All foundation models operate in a frozen, training-free manner; the only learned component is the part affordance predictor, which is evaluated on entirely novel object categories unseen during training.

## Results

On the AdaManip simulation benchmark (7 object categories), AdaRPG achieves an average manipulation success rate of 81.3%, substantially outperforming SAGE (29.7%), CoPa (32.7%), and AdaManip (47.0%). The best individual category result is 100% on Pressure Cooker, while the lowest is 70% on Lamp. In real-world experiments on 4 object categories, AdaRPG achieves 36/40 (90%) success, compared to SAGE (20/40), CoPa (10/40), and AdaManip (25/40).

## Baselines & Comparisons

AdaRPG outperforms all four baselines across every object category in both simulation and real-world settings. Against SAGE [13], which relies on GAPartNet for part grounding and rule-based primitive actions, AdaRPG achieves roughly 2–3× higher success rates (e.g., 0.84 vs. 0.21 on Bottle, 1.00 vs. 0.00 on Pressure Cooker), attributed to SAGE's imprecise pose estimation propagating errors through the manipulation pipeline. Against CoPa [17], which uses GraspNet for generic grasping, AdaRPG wins decisively (e.g., 0.84 vs. 0.58 on Bottle, 0.84 vs. 0.08 on Window), as GraspNet's generic grasp candidates fail to align with functional parts of articulated objects. Against AdaManip [49], the strongest baseline (trained on all 7 categories with adaptive demonstrations), AdaRPG still leads by 10–34 percentage points per category, demonstrating that foundation-model-driven part grounding and affordance prediction generalize better than imitation learning even when the latter has seen more training data. On the affordance F1 sub-metric (Table 3), AdaRPG's part-level model (avg F1 ≈ 0.74) substantially exceeds VAT-MART [50] (avg F1 ≈ 0.29), confirming that part-level geometric representation reduces cross-category variance compared to whole-object affordance prediction.

## Relation to Prior Work

AdaRPG extends the part-based manipulation line (SAGE, CoPa) by replacing rule-based or pose-estimation part representations with a learned part-level affordance model, and by grounding parts through a frozen foundation-model pipeline (GPT-4o → GroundingDINO → SAM) rather than a dedicated part detector. The affordance architecture itself follows Where2act and VAT-MART (PointNet++ + MLP + Sigmoid), but is retrained on a novel part-only dataset that removes whole-object context, directly addressing the geometric-diversity bottleneck those prior methods face. For high-level control, the paper adapts the Code-as-Policies paradigm, using GPT-4o to generate adaptive Python loops over impedance-controlled primitive skills rather than a learned end-to-end policy.

## Why It Matters / Open Questions

The framework demonstrates that a small trainable component (the part-affordance model) combined with frozen foundation models can achieve strong cross-category generalization without per-category training, which is practically attractive for deploying robots on diverse household objects. A notable open question is the fragility exposed by ablations: removing GPT-4o prompts causes near-total failure, making the pipeline heavily dependent on a single API call's quality and raising robustness concerns in cluttered or novel scenes. The authors also flag interactive affordance learning under dynamic conditions as future work, and the reliance on a single general prompt for all code generation limits the expressiveness of the generated control logic for more complex multi-step mechanisms.

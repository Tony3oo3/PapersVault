## Problem

Existing incremental object detection methods address either class shifts (CIOD) or domain shifts (DIOD) in isolation, but real-world systems like autonomous driving must simultaneously learn new object categories and adapt to changing environmental conditions (weather, lighting, viewpoints). No prior method handles this dual challenge in an exemplar-free setting while also addressing the background shift problem, where previously learned objects become unlabeled background in later tasks.
![Teaser figure](../imgs/ICCV20250903/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images from a sequence of evolving domains (e.g., Daytime Sunny → Night Sunny → Daytime Foggy, or Watercolor → Comic → Clipart → VOC) and outputs bounding boxes with class labels for all cumulatively learned object categories across all encountered domains. A critical constraint is the exemplar-free setting: at each incremental task, only the current domain's annotated data is available, and objects from previously learned classes present in new-domain images are treated as background, creating a background shift challenge absent in prior CIOD/DIOD formulations.

## Method

DuET decomposes any object detector's parameters into shared components (backbone and neck) and task-specific components (detection head), then applies Task Arithmetic to the shared parameters by computing task vectors relative to the pre-trained baseline. The DuET Module merges the old and current shared task vectors using layer-wise retention (α_l) and adaptation (β_l) factors derived from the relative ℓ₁-norm magnitudes of the two vectors, balancing preservation of prior knowledge against integration of new information. The Incremental Head concatenates task-specific parameters from all past and current tasks to expand the detection head's class capacity. A novel Directional Consistency Loss penalizes sign conflicts between consecutive shared-parameter updates, stabilizing the merging trajectory, while a modified distillation loss further preserves prior-task knowledge. The framework is detector-agnostic, validated across YOLO11, RT-DETR, Deformable DETR, and ViTDet, enabling real-time incremental detection without architecture-specific modifications.

## Results

On the Pascal Series 4-task experiment (Watercolor→Comic→Clipart→VOC), DuET achieves 89.30% Avg RI and 65.95% RAI, outperforming the next-best method CL-DETR (71.73% Avg RI, 54.18% RAI) by +17.57% in Avg RI and +11.77% in RAI. On the Diverse Weather Series 3-task experiment (Night Sunny→Daytime Sunny→Daytime Foggy), DuET reaches 88.57% Avg RI and 65.25% RAI, surpassing CL-DETR (64.26% Avg RI, 53.86% RAI) by +24.31% in Avg RI and +11.39% in RAI. On the two-phase VOC→Clipart experiment, DuET attains 87.44% Avg RI and 65.99% RAI with only 2.58M trainable parameters (YOLO11n), compared to CL-DETR's 39.85M parameters and 54.51% RAI.

## Baselines & Comparisons

DuET outperforms all four baselines across every experiment. Against LwF [25], DuET improves RAI by +12.80% (VOC→Clipart), +31.11% (Pascal 4-task), and +39.39% (Weather 3-task), with the gap widening dramatically in multi-phase settings where LwF's Avg RI drops to 52.66% and 27.94% respectively. Against ERD [8], DuET gains +9.82% RAI on VOC→Clipart and +18.00% on the Pascal 4-task, while ERD's retention degrades to 44.60% Avg RI on the Weather 3-task versus DuET's 88.57%. Against LDB [41] (DIOD baseline), DuET achieves +23.16% RAI on VOC→Clipart and +37.29% on the Weather 3-task, where LDB's Avg GI collapses to 5.42% due to its inability to handle new classes. Against CL-DETR [28] (CIOD baseline), the closest competitor, DuET still leads by +11.48% RAI on VOC→Clipart, +11.77% on Pascal 4-task, and +11.39% on Weather 3-task, while using roughly 15× fewer trainable parameters (2.58M vs. 39.85M).

## Relation to Prior Work

This paper extends the Task Arithmetic paradigm (Ilharco et al., 2022) from classification and language-model merging to object detection, introducing layer-wise retention-adaptation factors that go beyond the uniform scalar merging used in prior TA variants (Fisher-Merging, TIES-Merging, DARE). It departs from CIOD methods (CL-DETR, SDDGR, VLM-PL) that assume a fixed domain and from DIOD methods (LDB) that assume a fixed class set, by formulating a combined Dual Incremental Object Detection task where both shift simultaneously. The sequential fine-tuning initialization follows MagMax (Marczak et al., 2025), while the Directional Consistency Loss draws on the sign-conflict literature (TIES-Merging, DARE) but applies it specifically to stabilize shared-parameter merging across incremental steps.

## Why It Matters / Open Questions

DuET's detector-agnostic design (validated on YOLO11, RT-DETR, Deformable DETR, ViTDet) makes it practically relevant for deploying real-time incremental detectors in autonomous driving and surveillance, where both new object categories and environmental changes arrive simultaneously. The Retention-Adaptability Index provides a more holistic evaluation than prior CIOD/DIOD metrics that only measure forgetting. However, experiments are limited to small-scale datasets (7–20 classes, 3–4 domains), and it remains open whether the layer-wise task-vector merging strategy scales to hundreds of classes or to more extreme domain shifts (e.g., cross-continental driving). The exemplar-free constraint, while practical, may limit performance in highly overlapping class spaces.

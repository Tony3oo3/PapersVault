## Problem

Current Transformer-based VLN methods achieve strong performance by incorporating external knowledge or map information, but at the cost of large model sizes and high computational expenses. Moreover, navigation performance degrades notably as instruction length increases. While state-space models (SSMs) offer linear complexity and long-sequence modeling, their inherent design for single 1-D causal sequences makes them ill-suited for VLN's spatial reasoning and cross-modal attention requirements, leading to significant performance degradation when applied directly.

## Input / Output

At each navigation step, the agent receives a natural language instruction (encoded via TinyBERT with hidden size 312), a panoramic observation split into N view images (encoded via a pre-trained ViT), and the set of neighboring nodes in the navigation graph. The model maintains a topological map of all visited and candidate nodes, where each node is represented by a compressed embedding obtained from its N view observations. The output is a discrete action: either navigate to one of the neighboring nodes or stop at the current node, with predictions from coarse-scale (topological map) and fine-scale (current node views) encoders dynamically fused via a learnable scalar.

## Method

COSMO is a hybrid architecture that first uses two VLN-customized selective SSMs for selective memorization, then applies Transformers for precise action decision-making. The Round Selective Scan (RSS) replaces bi-directional scanning by flipping and concatenating the input sequence before a single forward scan, enabling all tokens to access global context in one pass while the class token at the sequence end captures compressed information of the entire sequence. The Cross-modal Selective State Space Module (CS3) adapts the selective SSM to a dual-stream structure: one modality (e.g., instruction) constructs the state-space parameters B and Δ to update the hidden state, while the other modality (e.g., view features) provides the class token to construct the output projection C, and the resulting state-space output serves as a gate to selectively filter relevant information from the target modality. The overall pipeline comprises a Node Encoder that builds the topological map, a Global Cross-modal Encoder (CS3 + GASA + cross-attention) for coarse-scale node-level reasoning, and a Local Cross-modal Encoder (CS3 + RSS + cross-attention + self-attention) for fine-scale view-level reasoning, achieving 15.5% of DUET's parameters and 9.3% of its FLOPs while surpassing it in navigation performance.

## Results

On REVERIE val unseen, COSMO achieves 50.81% SR and 35.93% SPL, improving over the DUET baseline by +3.83% SR and +2.2% SPL, while using only 28M parameters (15.5% of DUET's 181M) and 0.46G FLOPs (9.3% of DUET's 4.95G). On R2R-CE test, COSMO surpasses DUET by +5% SR (47 vs. 42) and +4% SPL (40 vs. 36). When integrated with BEVBert, COSMO further reaches 53.68% SR on REVERIE val unseen, outperforming the standalone BEVBert by +1.9% SR.

## Baselines & Comparisons

COSMO outperforms the DUET baseline by +3.83% SR on REVERIE val unseen and by +5% SR / +4% SPL on R2R-CE test, while reducing parameters to 15.5% and FLOPs to 9.3% of DUET. Against NaviLLM (6.6B parameters, 1011G FLOPs), COSMO achieves +8.66% SR on REVERIE val unseen and +12.73% SR on the test split, demonstrating that the lightweight SSM-based architecture generalizes better despite orders-of-magnitude fewer parameters. On R2R, COSMO surpasses KERM (which uses external commonsense knowledge) by +1% SR on both val and test splits, and reduces navigation error by 0.07m and 0.18m respectively. When combined with BEVBert's bird's-eye-view map pre-training, COSMO further improves to 53.68% SR on REVERIE val unseen (+1.9% over standalone BEVBert) and shows the largest gains on long instructions (>30 words), where DUET+COSMO achieves 7.42% higher SR than DUET alone. On R2R-CE, COSMO also surpasses GridMM on the test split (SR 47 vs. 46), indicating superior generalization in continuous environments.

## Relation to Prior Work

This paper builds on DUET's dual-scale graph Transformer architecture for VLN, replacing its Transformer-based cross-modal encoders with two VLN-customized selective state space modules (RSS and CS3) while retaining the topological map and dual-scale design. It departs from prior multimodal SSM work (VL-Mamba, Cobra) that concatenates text and vision into a single sequence, instead proposing a dual-stream CS3 module that handles the substantial length imbalance between modalities. It also diverges from spatial SSM approaches (Bi-Mamba, V-Mamba) that rely on multi-directional scanning, introducing RSS to capture comprehensive inter-token relationships in a single scan. The hybrid SSM-then-Transformer architecture is positioned as a response to the growing computational burden of recent VLN methods that incorporate external knowledge bases, depth maps, or large language models.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in VLN: as models incorporate richer external information (BEV maps, commonsense knowledge, LLMs), computational costs balloon to levels impractical for real-time embodied deployment. COSMO's 85% parameter reduction and 91% FLOPs reduction while matching or exceeding DUET's performance offers a concrete path toward lightweight navigation agents. However, the architecture still relies on Transformers for final action decision-making, so it is not fully linear-complexity, and the gains are demonstrated only on discrete/semi-continuous graph-based environments. Open questions include whether the selective memorization principle generalizes to fully continuous VLN or other embodied tasks, and whether the SSM components can be further scaled or pre-trained across environments.

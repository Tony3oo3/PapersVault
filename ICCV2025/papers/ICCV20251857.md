## Problem

While visual foundation models have advanced perception for object goal navigation, the cognitive process of deciding when to explore, verify, or confirm remains limited to either implicit RL/IL policies with poor zero-shot generalization or coarse two-state heuristic rules that cannot capture richer behaviors like contextual reasoning or multi-view verification. The paper asks how to model the full spectrum of human-like cognitive states during object search and learn their transitions without task-specific training.
![Teaser figure](../imgs/ICCV20251857/cropped_page0_idx0.webp)

## Input / Output

The agent receives 640x480 posed RGB-D frames (depth 0.5-5 m, camera at 0.9 m height) and a free-form text target category, and outputs one of six discrete actions (move_forward, turn_left, turn_right, look_up, look_down, stop) per step within a 500-step budget. The system is fully zero-shot: no fine-tuning of the LLM or VLM is required, and the target category can be any open-vocabulary text string. Success is defined as stopping within 1 m of a target instance.

## Method

CogNav constructs a heterogeneous cognitive map online, comprising (1) a semantic scene graph with object nodes and spatial-relationship edges built via OpenSEED segmentation plus GPT-4v verification, (2) a Voronoi-based landmark graph anchoring frontier and instance locations, and (3) a 960x960 top-down occupancy map. The cognitive process is modeled as a finite state machine with five fine-grained states (Broad Search, Contextual Search, Observe Target, Candidate Verification, Target Confirmation), and GPT-3 is prompted with landmark-centered natural-language descriptions of the map to decide the next state and select a goal landmark. A deterministic Fast Marching Method planner then generates the low-level path to the chosen landmark. The key insight is that an LLM can reason over structured scene prompts to perform adaptive, human-like state transitions, enabling recovery from wrong predictions (e.g., reverting from Target Confirmation back to Broad Search) without any learned policy.

## Results

CogNav achieves state-of-the-art success rates across all three benchmarks: 72.5% SR on HM3D, 46.6% SR on MP3D, and 54.6% SR on RoboTHOR, with corresponding SPL scores of 26.2%, 16.1%, and 24.3%. This represents improvements of +10.5% over the previous best (TriHelper, 62.0%) on HM3D, +6.4% over SG-NAV (40.2%) on MP3D, and +7.1% over SG-NAV (47.5%) on RoboTHOR. The method is both open-set and zero-shot, requiring no fine-tuning of the LLM.

## Baselines & Comparisons

CogNav outperforms all nine baselines on every benchmark where a direct comparison is available. On HM3D, it surpasses the previous best open-set zero-shot method TriHelper (62.0% SR) by 10.5 points and L3MVN (54.2%) by 18.3 points. On MP3D, it beats SG-NAV (40.2%) by 6.4 points and L3MVN (34.9%) by 11.7 points. On RoboTHOR, it exceeds SG-NAV (47.5%) by 7.1 points and L3MVN (41.2%) by 13.4 points. Among the open-set zero-shot methods (ESC, VoroNav, SG-NAV, OPENFMNAV, TriHelper), CogNav leads by a wide margin on all three datasets. The SPL gap is smaller than the SR gap, which the authors attribute to the candidate verification state requiring the agent to approach the target from multiple viewpoints, increasing path length while improving success rate.

## Relation to Prior Work

CogNav extends the LLM-driven zero-shot ObjectNav line (L3MVN, SG-NAV, OPENFMNAV, TriHelper, VoroNav) by shifting the LLM's role from one-shot goal selection to continuous cognitive state reasoning over a finite state machine with five fine-grained states (Broad Search → Contextual Search → Observe Target → Candidate Verification → Target Confirmation), inspired by neuroscientific evidence of dynamic state updating during human object search. It departs from prior two-state (exploration/identification) or threshold-based approaches by letting the LLM itself decide state transitions from a dynamically constructed heterogeneous cognitive map (scene graph + landmark graph + occupancy map), and introduces a VLM-in-the-loop correction mechanism (GPT-4v with Set-of-Mark prompting) to maintain map quality online. The landmark graph, built from a Generalized Voronoi Diagram over frontier and instance locations, serves as a novel anchor that unifies semantic and spatial information into LLM-readable prompts.

## Why It Matters / Open Questions

The framework demonstrates that explicit, fine-grained cognitive process modeling with LLMs can substantially outperform both implicit RL/IL methods and prior LLM-based zero-shot navigators without any fine-tuning, achieving 10.5% SR gains on HM3D and consistent improvements across MP3D and RoboTHOR, with real-robot validation on both a mobile platform and a quadruped. The ability to recover from incorrect target predictions (e.g., reverting from Target Confirmation back to Broad Search) is a practical advantage over one-shot goal-selection methods. Key limitations include dependence on a 2D foundation model for detection (failure to detect the target is unrecoverable) and restriction to object-goal navigation rather than freeform language instructions, though the authors note the LLM/VLM architecture could extend to broader instruction formats.

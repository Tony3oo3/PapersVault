## Problem

Existing benchmarks for mobile UI agents are either offline (static image sets or ground-truth trajectories) or online but limited in app coverage, task diversity, and platform scope, with no prior benchmark evaluating agents on iOS. Online mobile benchmarks also suffer from ad-hoc task design, LLM-sourced tasks with limited diversity, or open-ended formulations that complicate reliable evaluation. UINavBench addresses these gaps by providing a taxonomy-driven, online iOS benchmark with 116 tasks across 36 apps and fully automated staging and evaluation.
![Teaser figure](../imgs/ICCV20252254/cropped_page1_idx0.webp)

## Input / Output

At each step the agent observes a screenshot, the natural language goal, a list of detected UI elements (each with an integer ID, label type, contained text, bounding box, and predicted clickability), and the accumulated action history; spurious single-character keyboard keys are filtered out while special keys like Enter are preserved. The agent outputs a structured action (CLICK, SWIPE, TYPE, LONG_PRESS, DOUBLE_CLICK, etc.) with coordinates or text, which is converted to pixel-level commands using the center of the corresponding set-of-marks bounding box. Evaluation produces a binary episode success label and a Success Weighted by Path Length (SPL) score measuring trajectory efficiency relative to ground-truth expert paths.

## Method

The core contribution is a taxonomy-driven benchmark framework with three key components: (1) a multi-axis task taxonomy spanning planning/reasoning (task length, navigation depth, multi-app, goal specification), visual grounding (perceptual difficulty, action complexity), and memory/knowledge (task memory, environment knowledge, world knowledge), used to curate 116 balanced tasks; (2) an automated staging and cleanup system using iOS OS automation APIs to provision remote physical devices, set up user accounts and staged data, and programmatically revert persistent state changes after execution; (3) an automated task validator combining rule-based criteria (TextContains, TextClose, TimeRangeMatch) with VLM-as-judge evaluation, composed via AND/OR logic and verified to 100% alignment with human judgment on 5 successful and 5 failed trajectories per task. Baselines use GPT-4o as a modular planner with set-of-marks prompting, optional text-based UI representations, and Reflexion-style self-critique, compared against the end-to-end UI-TARS 72B model, with the best modular agent achieving 40.5% episode success.

## Results

On UINavBench (116 tasks across 36 iOS apps), the best-performing agent (Reflexion + Text with GPT-4o planner) achieves 40.5% episode success and 0.345 SPL. The end-to-end UI-TARS model (72B, QwenVL2 backbone) achieves only 11% episode success and 0.085 SPL, substantially below its reported performance on Android World (46.6%) and OSWorld (24.6%). Augmenting set-of-marks with text-based UI representations improves episode success by +6% (25.8% → 31.8%), and adding Reflexion self-critique further improves by +9.7% (31.8% → 40.5%).

## Baselines & Comparisons

The paper's best modular agent (Reflexion + Text, 40.5% ES) outperforms the end-to-end UI-TARS model (11% ES) by nearly 30 percentage points on UINavBench, a gap the authors attribute to the absence of public iOS UI navigation training data for UI-TARS. In contrast, UI-TARS achieves 46.6% on Android World and 24.6% on OSWorld, where large-scale training data exists. The UGround grounding model (Reflexion + UGround, 33.5% ES) generalizes better than UI-TARS despite being trained primarily on synthetic data, yet still underperforms the simpler set-of-marks + text approach (40.5%) by 7 points. Among the modular variants, Reflexion self-critique provides the largest single gain (+9.7% ES over ReACT+Text), while text-based UI representations contribute a smaller but consistent +6% improvement over raw set-of-marks. All baselines struggle with visual grounding (7.7% on Text+Visual tasks) and world-knowledge-dependent tasks (13.3% best), indicating these remain open challenges regardless of architecture.

## Relation to Prior Work

This paper builds on the modular agent architecture lineage (ReAct for reasoning-acting, Reflexion for self-critique, set-of-marks for visual grounding) and the UI element detection framework from AXNav, combining them into a unified evaluation pipeline. It departs from prior mobile benchmarks (AndroidWorld, LlamaTouch, Mobile-Env) by being the first to target the iOS platform, by using a principled taxonomy to curate tasks rather than sourcing them ad-hoc or from LLMs, and by implementing repeatable staging/cleanup for online evaluation. The evaluation methodology combines rule-based screen inspection with VLM-as-judge, avoiding the app-specific database queries used by some prior dynamic benchmarks.

## Why It Matters / Open Questions

As the first iOS mobile agent benchmark, UINavBench enables the community to study cross-platform generalization—a question that was previously unanswerable due to the absence of public iOS UI navigation data. The finding that modular GPT-4o-based agents (40.5%) substantially outperform end-to-end models trained on Android/Web/Desktop data (11%) underscores that current end-to-end approaches do not transfer across platforms, motivating platform-specific training or more generalizable architectures. Key open questions include whether RL or fine-tuned open-weight models can close the gap, whether the taxonomy-driven task design generalizes to other platforms, and how to improve agents' ability to leverage world knowledge and handle fine-grained visual grounding.

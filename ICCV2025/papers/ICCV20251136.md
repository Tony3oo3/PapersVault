## Problem

Existing image stylization methods treat the style in a reference image as a single, indivisible entity, making it difficult to independently transfer specific stylistic attributes such as brushstroke and color. Pixel-level decoupling strategies (e.g., T2I-Adapter) cause significant information loss and detail degradation, while fine-tuning-based approaches conflate multiple visual attributes and cannot selectively control individual style components.
![Teaser figure](../imgs/ICCV20251136/cropped_page0_idx1.webp)

## Input / Output

The model accepts a text prompt describing the target content along with three separate reference images: one for content structure, one for brushstroke style, and one for color scheme. Each reference image is encoded via CLIP (ViT-L/14) into a global feature embedding, and the three embeddings are implicitly decoupled into distinct attribute representations before injection. The output is a 1024×1024 stylized image generated by Stable Diffusion 1.5 using DDIM sampling with 30 steps, where the generated image should match the text prompt's content while adopting the brushstroke from one reference and the color palette from another.

## Method

CO-PAINTER builds on Stable Diffusion 1.5 and introduces two key modules. The Fine-Grained Decoupling (FGD) mechanism takes each reference image's CLIP global embedding, passes it through a shared projection layer (initialized from IP-Adapter), then through attribute-specific separation layers (f_con, f_bst, f_col) to implicitly extract distinct content, brushstroke, and color embeddings without pixel-level operations. The Gated Feature Injection (GFI) mechanism computes cross-attention between the denoising model's internal features (as Q) and each attribute embedding (as K, V), then fuses them via a learnable tanh gate with a temperature parameter and a feed-forward network, adaptively weighting each attribute's contribution per layer. Style attributes (brushstroke and color) are injected into fine-grained UNet layers while content is injected into coarser layers, following the layer division strategy from DEADiff. The model is trained end-to-end with MSE denoising loss on a custom ~48,000-sample dataset where each target image has matched content, brushstroke, and color reference images, using AdamW at lr=1e-4 for 100k iterations on 4 RTX 3090 GPUs.

## Results

In the fine-grained stylization setting (Table 2), CO-PAINTER achieves the best overall balance: IQ 6.06, SS 24.4, TA 24.5, CONS 23.5, BSTS 20.6, and COLS 22.6. In the standard setting (Table 1), it attains the highest Image Quality (6.14) while maintaining a strong SS/TA balance (27.8 / 24.5), outperforming DEADiff (6.09 / 26.4 / 24.9) and significantly outperforming T2I-Adapter and IP-Adapter on text alignment (24.5 vs. 13.5 and 14.3). The ablation confirms that combining FGD and GFI yields the best results (IQ 6.14, SS 27.8, TA 24.5) versus either module alone.

## Baselines & Comparisons

CO-PAINTER wins on the overall balance of all six metrics in the fine-grained setting, achieving the highest IQ (6.06), TA (24.5), CONS (23.5), BSTS (20.6), and COLS (22.6), while IP-Adapter (stacked) edges it slightly on SS (24.6 vs. 24.4) but collapses on TA (18.2) and CONS (18.9) due to content leakage. In the standard setting, T2I-Adapter and IP-Adapter achieve much higher SS (37.1 and 36.9) but at the cost of severely degraded text alignment (TA 13.5 and 14.3), whereas CO-PAINTER maintains TA at 24.5 with SS 27.8. DEADiff is the closest competitor in the standard setting (TA 24.9, SS 26.4) but lags on IQ (5.91 vs. 6.14) and fine-grained metrics (BSTS 20.6, COLS 20.7 vs. 20.6, 22.6). Conventional methods (CAST, StyTR-2) and the inversion-based InST all score below 26 on SS and below 26 on TA, with IQ around 5.5–5.7, making them clearly inferior. ControlNet and T2I-Adapter as controllable models perform worst in the fine-grained setting (SS 19.5 and 18.5), confirming that pixel-level decoupling strategies struggle with abstract style attributes like brushstroke and color.

## Relation to Prior Work

This paper extends the diffusion-based image stylization line initiated by IP-Adapter and DEADiff, which introduced image-prompt adapters and disentangled feature injection into latent diffusion models. It departs from prior work in two key ways: (1) replacing pixel-level decoupling strategies (as in T2I-Adapter) with an implicit fine-grained decoupling mechanism that separates content, brushstroke, and color embeddings from full-image inputs without information loss, and (2) replacing fixed feature-addition or concatenation injection with a learnable gated mechanism that adaptively weights multiple attribute conditions across different UNet layers. The dataset construction pipeline (GPT-4 captions + Midjourney synthesis + ControlNet color transfer) is a practical contribution that addresses the lack of paired multi-attribute training data.

## Why It Matters / Open Questions

The ability to independently control brushstroke and color from separate reference images addresses a practical gap in artistic workflows where users need granular style manipulation rather than whole-image style transfer. The ~48K paired dataset and the gated injection mechanism are reusable components for the community. However, the evaluation is limited to the authors' own dataset with only three attributes, and the out-of-domain generalization is tested with just 10 samples per content type, leaving open questions about scalability to more attributes, real-time inference, and robustness to diverse artistic domains beyond the eight brushstroke categories studied.

## Problem

Existing dynamic scene generation methods learn 3D motion consistency by training on multiple surrounding views, which constrains generated content to interpolate between those views and prevents perpetual (unbounded) scene exploration. While perpetual static scene generation has been addressed via outpainting, no prior method can generate new dynamic content with 3D-consistent motions in previously unseen regions from a single view.
![Teaser figure](../imgs/ICCV20252177/cropped_page0_idx0.webp)

## Input / Output

The method accepts either a fixed-viewpoint video or a single image paired with a motion prompt (which is first converted to a fixed-pose video via an image-to-video diffusion model), along with a scene text prompt and a fly-through camera trajectory (straight-line translation of 0.0005 units or 0.45-radian rotation steps). It produces a growing 4D dynamic point cloud (position, timestamp, color) and outpainted 16-frame videos at 512×512 resolution for each novel camera pose, iteratively expanding the scene along the trajectory.

## Method

DynamicVoyager reformulates perpetual dynamic scene generation as iterative scene outpainting, with the key insight of treating each pixel as a 3D camera ray to inject spatial context into the outpainting process. At each novel pose, the existing 4D point cloud is rasterized to produce a partial video; for observed pixels, a ray depth map is sampled from the point cloud, and for unseen pixels, the minimum distance from each ray to the point cloud is computed as a 3D spatial cue. These two maps are injected via ControlNet into a LoRA-fine-tuned CogVideoX-5B-I2V model (trained on 5,000 OpenVid videos) to guide 3D-consistent motion outpainting. The outpainted video's estimated depths (aligned to the rendered ray depths) are then backprojected to update the point cloud, which is merged with the previous cloud and used for the next outpainting step, enabling unbounded scene growth.

## Results

On the controllable dynamic scene generation task (Table 1), DynamicVoyager achieves CLIP-SIM 25.23, Dynamic Degree 3.13, and Factual Consistency 1.32, outperforming WonderJourney (24.98 / 2.23 / 1.30) on all three metrics. For 3D motion consistency (Table 2), DynamicVoyager with ray information scores CLIP-SIM 24.70, VQ 2.578, TC 2.234, TA 2.938, and FC 2.188, surpassing the 2D outpainting baseline MOTIA (23.80 / 2.281 / 1.852 / 2.656 / 1.859) and the no-ray-information ablation (23.12 / 2.562 / 1.984 / 2.672 / 1.977) across all five VideoScore metrics. The largest gains from ray information appear in temporal consistency (TC: 2.234 vs. 1.984) and factual consistency (FC: 2.188 vs. 1.977), confirming that 3D ray guidance is critical for motion coherence.

## Baselines & Comparisons

Against WonderJourney [58] (the only prior perpetual scene generation method), DynamicVoyager wins on all three controllable-generation metrics: CLIP-SIM 25.23 vs. 24.98, Dynamic Degree 3.13 vs. 2.23, and Factual Consistency 1.32 vs. 1.30; the large DD gap (3.13 vs. 2.23) reflects that WonderJourney can only generate static content while DynamicVoyager produces genuinely dynamic scenes. Against the 2D video outpainting baseline MOTIA [46], DynamicVoyager achieves consistent improvements across all five VideoScore metrics, with the most notable gains in temporal consistency (+0.382) and factual consistency (+0.329), demonstrating that ray depth and ray distance conditioning substantially improves 3D motion coherence at outpainting boundaries. Comparisons with CAT4D [49] and MotionCtrl [48] are purely qualitative (Figures 2 and 8): both baselines produce scenes strictly bounded by the input views or camera trajectories, whereas DynamicVoyager successfully extends the scene along long fly-through paths with consistent dynamic content. No quantitative head-to-head numbers are reported for CAT4D or MotionCtrl, as no standard benchmark exists for perpetual dynamic scene generation.

## Relation to Prior Work

This paper bridges two previously separate lines of work: perpetual static scene generation (WonderJourney, WonderWorld), which uses iterative outpainting to extend scenes along camera trajectories, and bounded dynamic scene generation (CAT4D, DimensionX, GEN3C), which produces 3D-consistent motions but only interpolates within the training view envelope. The key conceptual departure is reformulating dynamic scene generation as an outpainting problem and enriching 2D pixels with 3D ray information (ray depth in observed regions, ray-to-point-cloud distance in unseen regions) to enforce motion consistency across views. The method builds on CogVideoX as the base video diffusion model, fine-tuned via LoRA with ControlNet for ray conditioning, and uses MOTIA-style video outpainting as the 2D baseline it improves upon.

## Why It Matters / Open Questions

Perpetual dynamic scene generation from a single view is a practically important capability for AR/VR content creation and embodied agent training, yet no prior method could generate unbounded dynamic scenes with consistent 3D motions. The iterative outpainting framework is modular and could be combined with future improvements in depth estimation or video diffusion. However, the paper acknowledges open challenges with reflections, shadows, fine structures, and depth discontinuities, and the lack of a direct perpetual-dynamic baseline makes it difficult to quantify the true gap over prior approaches. Long-horizon error accumulation in the iterative point-cloud update loop remains an unaddressed concern.

## Problem

Adapting pretrained vision-language models like CLIP to event camera data for open-vocabulary action recognition faces two unresolved challenges: bridging the domain gap between static image-based encoders and high-temporal-resolution event streams, and preserving the broad generalization of the pretrained model without the catastrophic forgetting that full fine-tuning induces. The prior event-based method ExACT fine-tunes the entire event encoder, achieving strong supervised accuracy but suffering marked degradation in zero-shot and few-shot settings, revealing a specialization–generalization trade-off that remains unaddressed.
![Teaser figure](../imgs/ICCV20251311/cropped_page0_idx1.webp)

## Input / Output

The method consumes raw asynchronous event streams (each event defined by spatial coordinates, timestamp, and polarity) that are first converted into 3-channel event frames of shape T×H×W via adaptive temporal filtering, with 8 sparsely sampled frames per clip. Text input consists of class-label prompts formatted as 'A video of [category]' tokenized through the frozen CLIP text encoder. The output is a cosine-similarity score between the projected event representation and each class text embedding in a shared d-dimensional latent space, from which Top-1/Top-5 action labels are extracted.

## Method

SAMPLE introduces a Temporal-Adaptive Multimodal Prompt Learning strategy that adapts a frozen CLIP ViT-B/16 backbone using only 8.7M learnable prompt parameters (vs. 47.9M for ExACT). The strategy has three coupled components: (1) unimodal prompts inserted independently into the event and text encoder branches to capture modality-specific data distributions; (2) Event-Text cross-modal prompts where shared learnable tokens in the text branch are projected into the event branch via a linear E-T coupling function, enforcing representation-space alignment; and (3) Temporal-Adaptive prompts that inject frame-specific prompt tokens at the input of every Transformer layer, which are then refined by a T-A learning function aggregating all T frame-level prompts to capture global temporal dependencies. Prompts are inserted up to a depth J=9 (empirically tuned), after which they propagate passively through deeper layers. Training uses the standard CLIP contrastive objective with a learnable temperature, and the entire event encoder, text encoder, and projection layers remain frozen.

## Results

In the fully-supervised setting, SAMPLE achieves 95.00% Top-1 on PAF, 92.31% on HARDVS, 99.04% on DVS128Gesture, and 69.79% on SeAct, outperforming the prior best event+text method ExACT by +0.17%, +2.21%, +0.18%, and +2.55% respectively. In the zero-shot setting (trained on HARDVS, evaluated on unseen datasets), SAMPLE achieves gains of +15.46% (SeAct), +29.76% (DVS128Gesture), and +23.79% (PAF) over ExACT. The method uses only 8.7M trainable parameters versus 47.9M for ExACT, an 82% reduction. In few-shot (K=2) and base-to-novel settings, SAMPLE also consistently leads, with harmonic-mean gains up to +21.68% on HARDVS.

## Baselines & Comparisons

SAMPLE outperforms the primary event+text baseline ExACT [56] across all four datasets and all four evaluation settings (fully-supervised, few-shot, base-to-novel, zero-shot). In fully-supervised mode, gains over ExACT are modest (+0.17% to +2.55% Top-1), but in zero-shot mode the advantage is dramatic: +15.46% on SeAct, +29.76% on DVS128Gesture, and +23.79% on PAF, indicating that ExACT's full fine-tuning of the event encoder severely degrades generalization to unseen categories. Against RGB+Text CLIP-based methods (EZ-CLIP [1], M2-CLIP [46]), SAMPLE consistently wins on all event-camera datasets, confirming that event data with proper temporal-adaptive prompting surpasses RGB video in action recognition. In few-shot (K=2) settings, SAMPLE leads ExACT by +12.99% on SeAct and +15.44% on HARDVS, while also exceeding the best RGB+Text method (EZ-CLIP) by +15.09% on SeAct. In base-to-novel evaluation, SAMPLE's harmonic-mean scores exceed ExACT by +19.16% (SeAct), +13.96% (DVS128Gesture), +15.32% (PAF), and +21.68% (HARDVS), with the largest novel-class gains reaching +26.01% on HARDVS. All comparisons are won by SAMPLE; no baseline is matched or exceeded in any setting.

## Relation to Prior Work

This paper extends the prompt-learning adaptation paradigm for CLIP (MaPLe, Vita-CLIP, EZ-CLIP) from RGB video to event-camera data, and builds directly on ExACT (Zhou et al., CVPR 2024), the first method to couple a frozen CLIP text encoder with a fully fine-tuned event encoder for action recognition. The key departure from ExACT is replacing full fine-tuning of the event branch with lightweight learnable prompt tokens, motivated by the observation that fine-tuning degrades zero-shot generalization. The temporal-adaptive component is novel relative to prior video prompt methods (which use static or frame-agnostic prompts), introducing per-frame prompt tokens that are dynamically refined across the event sequence to capture microsecond-scale motion dynamics.

## Why It Matters / Open Questions

This work establishes the first systematic evaluation of open-vocabulary (zero-shot, few-shot, base-to-novel) action recognition on event cameras, a modality with inherent privacy advantages and high temporal resolution that RGB methods cannot match. The substantial zero-shot gains (+15–30%) over the fine-tuned ExACT baseline demonstrate that prompt-based adaptation can preserve CLIP's generalization while still achieving competitive supervised accuracy, offering a practical recipe for deploying VLMs on neuromorphic hardware. Open questions include whether the approach scales to longer event sequences or more complex multi-person scenes, whether the 8-frame sampling is sufficient for very fast motions, and how the method performs when the source and target domains differ in sensor type (e.g., DVS128 vs. DAVIS346).

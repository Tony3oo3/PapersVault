## Problem

Instance-grounded text-to-image generation requires training data with high-quality images, comprehensive captions, and complete bounding box annotations, but existing detection-oriented datasets (COCO, LVIS, Open Images) suffer from poor image quality, limited predefined categories, and terse captions that omit visible visual elements. When open-vocabulary detectors are applied to these sparse web captions, the resulting instance annotations are incomplete, causing generated images to miss or hallucinate objects that were never annotated.

## Input / Output

The pipeline ingests curated web images (minimum 1024×1024 resolution, aesthetic score ≥5.75, max 6144px on the longer edge) paired with their original web captions from COYO-700M, LAION-2B, and LAION POP. It outputs a 1.012M-image dataset where each image carries a detailed VLM-generated re-caption, a flat open-vocabulary category list, and ~24.21 bounding box annotations on average spanning 1.44M distinct categories — roughly two orders of magnitude more categories than prior detection datasets.

## Method

The core contribution is a pre-detection VLM-LLM re-captioning strategy that precedes object detection. InternVL1.5 first generates a comprehensive visual description of each image (including compositional relationships and self-evident attributes), and Llama 3 then summarizes this description plus the deferred web caption into a flat list of concise categories, with a second decomposition pass extracting basic noun forms to improve detector recall. This structured category list is sent simultaneously to four OVDs (Grounding-DINO, YOLO-World, OWLv2, OV-DINO), enabling multi-detector fusion that would be impossible with unstructured natural-language inputs. Detected boxes are merged via IoU-NMS (threshold 0.4), resampled to balance detector contributions and penalize overlaps, and finally cross-verified by Qwen2VL in a yes/no check on each cropped instance. The full pipeline processes 1M images in ~1,960 A800 GPU hours.

## Results

On the ROVI validation set, GLIGEN trained on ROVI achieves the best instance grounding accuracy (0.880), lowest FID (15.7), highest aesthetic score (5.83), and highest CLIP similarity (0.286) among all compared methods. On the Open Images validation set, it similarly leads with 0.872 Gen Inst., 16.7 FID, 5.40 Aes., and 0.245 CLIP Sim. In a user study over 200 box-grounded inputs, ROVI-trained GLIGEN is preferred over MIGC in 94.8% of instance-alignment judgments and 98.3% of aesthetic-quality judgments.

## Baselines & Comparisons

ROVI-trained GLIGEN outperforms all four baselines on every metric across both validation sets. Against the closest competitor InstanceDiffusion, it gains +0.026 Gen Inst. and −5.4 FID on ROVI val, while on Open Images val the gap narrows slightly (Gen Inst. 0.872 vs 0.871) but FID still improves by 1.7 points. Compared to Official GLIGEN, the improvement is most dramatic on FID (15.7 vs 19.3 on ROVI val; 16.7 vs 25.4 on Open Images val), reflecting the dataset's higher image quality and richer captions. MIGC lags furthest behind on FID (27.6/32.2) and CLIP similarity (0.228/0.213), suggesting its NLP-based caption extraction produces weaker global prompts. The Stable Diffusion v1.4 baseline, while competitive on FID and CLIP similarity, is far behind on instance grounding (0.530 vs 0.880), confirming that the dataset's value is specifically in enabling accurate box-label generation rather than general image quality.

## Relation to Prior Work

This paper carves new ground in the data pipeline for instance-grounded text-to-image generation by introducing a pre-detection VLM-LLM re-captioning stage that prior methods (GLIGEN, MIGC, InstanceDiffusion) lacked. While GLIGEN fed raw web captions directly to phrase-grounding OVDs and InstanceDiffusion used RAM tagging followed by per-box VLM captioning, ROVI instead uses a VLM to produce a comprehensive scene description, an LLM to distill a flat open-vocabulary category list, and then queries four heterogeneous OVDs (including non-phrase-grounding ones like YOLO-World and OWLv2) against that list. This architectural choice—treating the VLM-LLM pair as a pre-detection enrichment rather than a post-detection captioning step—is the paper's core conceptual departure, enabling multi-detector fusion and capturing compositional relationships that single-pass phrase grounding misses.

## Why It Matters / Open Questions

ROVI addresses a critical bottleneck in instance-grounded generation: the scarcity of high-quality, high-resolution, open-vocabulary training data with comprehensive instance annotations. By providing 1M images with 1.4M+ categories at 2102×1488 average resolution and aesthetic score 6.0, it offers a resource that existing detection datasets (COCO, LVIS, V3Det) cannot match, and the fully open-source pipeline makes it reproducible. However, the current evaluation is limited to GLIGEN on Stable Diffusion v1.4, which cannot fully exploit the dataset's resolution and aesthetic advantages; the authors themselves note that newer architectures like Flux-dev would better showcase ROVI's strengths. Open questions include whether the 3.3% residual detection error rate and language-model artifacts (singular/plural inconsistency, left/right confusion) degrade performance at scale, and whether the pre-detection re-captioning strategy transfers to other grounded generation paradigms beyond box-label conditioning.

## Problem

Existing amodal completion and object-centric representation learning methods either require per-object user prompting and operate on a single object at a time, or are confined to closed-world settings where the same objects appear repeatedly. No prior system can decompose an arbitrary image into a complete stack of occlusion-ordered, amodally-completed object layers in a single pass without knowing the object count or receiving any human annotation.
![Teaser figure](../imgs/ICCV20251733/cropped_page0_idx0.webp)

## Input / Output

The model takes a single 512×512 RGB image as input and produces a fixed-size stack of N=7 occlusion-ordered RGBA object layers (binary alpha channels), ordered from background to nearest foreground. Unused layers for scenes with fewer than 6 objects are expected to have zero alpha. The layers are designed to composite back to the input image via standard alpha compositing, and the model must infer both the occlusion ordering and the amodally-completed shapes/colors of all objects simultaneously.

## Method

CObL uses N frozen copies of the Stable Diffusion 2.1 UNet, interconnected with learnable cross-layer attention blocks (adapted from video diffusion) so that all object layers are generated concurrently and can communicate with each other. Each UNet is conditioned on the input image through a learnable adapter that combines MiDaS pseudo-depth embeddings with image embeddings. Training uses the standard diffusion denoising objective on 2250 synthetic tabletop scenes created by a novel two-step pipeline that renders 3D geometry and shadows in Blender, then generates natural textures via ControlNet-depth text-to-image synthesis. At inference, guided DDIM sampling applies two complementary losses: a compositional loss that decodes and composites the current layer estimates and penalizes deviation from the input image, and a prior score matching loss that compares noise predictions against an untied Stable Diffusion UNet to keep each layer within the natural image distribution. This combination of concurrent multi-layer generation, cross-layer attention, and inference-time compositional guidance enables zero-shot generalization to real-world tabletops with novel objects.

## Results

On the TABLETOP dataset (60 scenes with 2–4 objects), CObL achieves a best-case LPIPS of 0.094 and CLIP similarity of 0.935, outperforming all baselines that receive oracle-provided masks. For visible segmentation, CObL reaches a top-1 Adjusted Rand Index of 83.5%, substantially exceeding Mask2Former's 66.3% on the same task. Performance degrades for scenes with more than four objects, and ablations show that removing the compositional guidance or the frozen Stable Diffusion prior each increases LPIPS by 8–9%.

## Baselines & Comparisons

CObL outperforms all three baselines on both LPIPS and CLIP metrics despite a substantial information disadvantage: it generates all object layers simultaneously without any user prompting or oracle masks, whereas each baseline completes a single object at a time with a ground-truth mask indicating either the object to complete (Pix2Gestalt) or the occluding region to inpaint (LaMa, SDXL Inpainting). Against the closest competitor, Pix2Gestalt (LPIPS .128, CLIP .889), CObL improves LPIPS by ~27% and CLIP by ~4.6 points. The gap is largest against SDXL Inpainting (LPIPS .373, CLIP .760), which struggles with multi-object scenes. LaMa is competitive on LPIPS (.113) but still trails CObL (.094) and does not report average scores. For visible segmentation, CObL's 83.5% ARI exceeds Mask2Former's 66.3% by 17.2 points, showing that the amodal layer decomposition implicitly yields stronger visible-part segmentation than a dedicated panoptic model.

## Relation to Prior Work

CObL repurposes the concurrent-generation architecture from video diffusion (Align Your Latents) by replacing temporal frame-to-frame attention with cross-layer attention between N frozen Stable Diffusion UNets, each generating one object layer in parallel. It departs from prior amodal completion and inpainting methods (pix2gestalt, LaMa, SDXL Inpainting) that operate on a single object at a time and require oracle-provided masks, by generating all layers simultaneously with no user prompting. The conditioning adapter follows T2I-Adapter's design, and the inference-time guidance (compositional loss + prior score matching) extends the score-distillation idea from DreamFusion into a multi-layer compositing context. The synthetic training pipeline, combining partial 3D rendering with ControlNet-depth text-to-image generation, is a novel data-creation strategy not seen in prior amodal or object-centric learning work.

## Why It Matters / Open Questions

CObL establishes the first zero-shot, multi-object, no-prompting baseline for ordinal layering and introduces the TABLETOP benchmark, giving the field a concrete target for evaluating perceptual organization beyond closed-world or single-object settings. The finding that multiple interacting diffusion instances are necessary for perceptual organization (a single SD instance fails at basic figure-ground reasoning) suggests a broader principle for compositional generation. However, the approach is restricted to tabletop scenes, limited in the number of layers by GPU memory, and inherits Stable Diffusion's biases; extending it to arbitrary scenes, larger object counts, and 3D-consistent layers remains open.

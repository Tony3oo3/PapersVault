## Problem

Existing CLIP-based few-shot learning methods operate on entangled visual representations, forcing the classifier to implicitly recover the unmixing process from limited labeled data, which increases overfitting risk and limits generalization. Although theoretical results show that CLIP features are linear mixtures of true latent variables, no prior method explicitly exploits this identifiability to reduce the parameter burden in the few-shot regime.
![Teaser figure](../imgs/ICCV20250617/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images (preprocessed with CLIP's standard pipeline) and class label names embedded via CLIP's text encoder with prompt templates. A pre-computed FastICA unmixing matrix U (derived from 100k ImageNet images) projects C-dimensional CLIP features into M-dimensional disentangled space (M ≤ C, default M=1024). The output is a set of classification logits formed by a weighted linear combination of three components: intra-modal cache-model logits (scaled by α), cross-modal alignment logits, and hybrid cross-attention logits (scaled by γ and η), from which a class label is selected.

## Method

CCA first disentangles CLIP visual features using FastICA to recover independent latent variables up to permutation and scaling, then constructs a disentangled cache model where a trainable cache adapter (initialized as identity, l1-regularized) refines the unmixing for intra-modal similarity computation. To counteract the intra-modal misalignment introduced by ICA, the method fine-tunes the CLIP text classifier unidirectionally and introduces a bidirectional cross-attention mechanism: text features attend to image features to produce an enriched text classifier, and image features attend to text features to produce augmented image features. The final prediction linearly combines logits from the disentangled cache model, the fine-tuned text classifier, and the hybrid cross-modal features. Training uses cross-entropy loss with SGD for 20 epochs while keeping CLIP encoders frozen, requiring only the cache adapter and text classifier weights to be updated.

## Results

On ImageNet 16-shot, CCA-FT achieves 66.04% top-1 accuracy, outperforming Tip-Adapter-F (65.45%), CoOp (62.95%), and Zero-shot CLIP (60.33%), while requiring only 4.9 minutes of training versus CoOp's 7.5 hours. In the training-free setting, CCA reaches 63.00%, surpassing Tip-Adapter (61.80%) by 1.2 points. Across 11 benchmark datasets, CCA-FT outperforms all SOTA methods (APE, TaskRes, cross-modal partial fine-tuning, LP++) in average accuracy at every shot setting (1, 2, 4, 8, 16). On distributional shift, CCA-FT achieves 57.32% on ImageNetV2 and 35.87% on ImageNet-Sketch, the best among all compared methods.

## Baselines & Comparisons

CCA-FT outperforms Tip-Adapter-F (the closest baseline) by 0.59 points on ImageNet 16-shot (66.04% vs. 65.45%) and by 1.0–2.3 points on average across all 11 datasets at every shot setting. In the training-free regime, CCA (63.00%) beats Tip-Adapter (61.80%) by 1.2 points, while CoOp requires 200 epochs and 7.5 hours to reach only 62.95%. Against APE, TaskRes, cross-modal partial fine-tuning, and LP++ (all shown in Figure 3), CCA-FT achieves the highest average accuracy across the 11 datasets at 16-shot. On robustness, CCA-FT surpasses Tip-Adapter-F under Gaussian noise (62.48% vs. 60.04% average) and FGSM adversarial attack (35.48% vs. 33.21%), and achieves the best ImageNetV2 score (57.32% vs. 56.85% for Tip-Adapter-F). The only setting where CCA trails is training-free accuracy on individual fine-grained datasets, where ICA-induced misalignment slightly degrades performance before fine-tuning corrects it.

## Relation to Prior Work

This paper builds directly on Tip-Adapter's cache model architecture for CLIP-based few-shot learning, extending it by inserting an explicit ICA-based disentanglement step before similarity computation. The theoretical motivation draws on recent identifiability results [34] showing that CLIP's multimodal contrastive training recovers latent variables up to a linear transformation, which the authors exploit by applying FastICA to invert that transformation. Unlike prior CLIP-based FSL methods (prompt-tuning, adapter-based, knowledge-augmented) that operate on entangled features and implicitly learn unmixing from limited labels, CCA separates the unmixing from the classification step, reducing trainable parameters. The bidirectional cross-attention fusion of image and text features goes beyond the unidirectional text-classifier fine-tuning common in existing adapter methods.

## Why It Matters / Open Questions

The practical takeaway is that a single pre-computed ICA unmixing matrix (derived from ImageNet) transfers effectively across 11 diverse datasets, reducing the parameter burden in few-shot settings and improving robustness to distribution shifts, Gaussian noise, and FGSM adversarial attacks. This suggests that the linear entanglement structure of CLIP features is sufficiently stable across domains to be corrected once and reused. Open questions include whether the ICA assumption (at most one Gaussian latent) holds for non-visual modalities or non-CLIP encoders, whether the unmixing matrix needs periodic re-estimation as CLIP models evolve, and whether the approach extends to tasks beyond classification (e.g., segmentation, detection) where the cache-model paradigm is less natural.

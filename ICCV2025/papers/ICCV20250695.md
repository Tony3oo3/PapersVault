## Problem

Existing learned image compression methods that expand context modeling capacity (e.g., multi-reference or transformer-based entropy models) still struggle to efficiently exploit long-range dependencies and diverse context information across different coding steps, leading to a poor trade-off between compression performance and computational complexity.
![Teaser figure](../imgs/ICCV20250695/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images as input (trained on 256×256 crops from Flicker2W; evaluated on 512×768 Kodak, 41 high-quality CLIC Pro Valid, and 1200×1200 Tecnick images) and produces a losslessly entropy-coded bitstream plus a reconstructed image. The latent representation is partitioned into three spatial scales (S1 at 4× downscale, S2 at 2×, S3 at full resolution) with 2, 3, and 6 sequential coding steps respectively, and the entropy model uses a generalized Gaussian likelihood with fixed shape parameter β=1.5.

## Method

The Hierarchical Progressive Context Model (HPCM) introduces two key mechanisms. First, a hierarchical coding schedule partitions quantized latents into multi-scale sub-latents and codes them sequentially from the smallest scale (long-range) to the largest (short-range), with different spatial partition strategies applied across eight channel groups to enable joint spatial-channel context modeling. Second, a progressive context fusion module uses a cross-attention mechanism to incorporate the entropy parameter state from the previous coding step into the current step's accumulated context representation, enabling progressive accumulation of diverse context information; a cross-scale variant propagates context from smaller to larger scales by filling coded positions and supplementing with hyperprior information. The full model follows a standard transform-coding pipeline with a hyperprior module, is trained end-to-end via rate-distortion optimization with MSE or MS-SSIM distortion, and employs a parameter-efficient design that shares the context model network across coding stages.

## Results

Against the VTM-22.0 anchor, HPCM-Base achieves 15.31%, 14.23%, and 18.16% PSNR BD-Rate savings on Kodak, CLIC Pro Valid, and Tecnick respectively, while HPCM-Large achieves 19.19%, 18.37%, and 22.20% on the same datasets. In terms of complexity, HPCM-Base requires 918.57 kMACs/pixel and 68.50M parameters with 81.8 ms encoding time, and HPCM-Large requires 1261.29 kMACs/pixel and 89.71M parameters with 91.2 ms encoding time. The paper highlights that HPCM-Base matches MLIC++'s compression performance (−15.31% vs −15.15% on Kodak) while using ~28% fewer kMACs/pixel (918.57 vs 1282.81) and ~41% fewer parameters (68.50M vs 116.72M).

## Baselines & Comparisons

HPCM-Large outperforms all compared learned image compression methods across all three datasets, achieving the best BD-Rate of −19.19% (Kodak), −18.37% (CLIC Pro Valid), and −22.20% (Tecnick). The closest competitor is MLIC++ (−15.15% Kodak), which HPCM-Large surpasses by ~4% BD-Rate while using comparable kMACs/pixel (1261 vs 1283) but fewer parameters (89.7M vs 116.7M). HPCM-Base matches MLIC++'s Kodak performance (−15.31% vs −15.15%) at substantially lower complexity (919 vs 1283 kMACs/pixel, 68.5M vs 116.7M params, 82 ms vs 193 ms encoding). Against TCM (−10.70%) and FLIC (−13.20%), HPCM-Large gains 8.5% and 6.0% BD-Rate respectively on Kodak. WeConvene, despite the highest kMACs (2343), achieves only −6.98% on Kodak, well below both HPCM variants. The ablation with CHARM and DCVC-DC intra (same transform, different entropy models) confirms that the HPCM entropy model itself contributes the majority of the gain over prior context models.

## Relation to Prior Work

This paper extends the learned image compression framework built on transform coding and conditional entropy models, specifically advancing the context modeling component. It builds on the spatial-channel context modeling lineage (raster-scan autoregression, checkerboard models, multi-reference context models like MLIC++) but departs from the prevailing single-scale or multi-reference paradigm by introducing a hierarchical coding schedule that codes latents from coarse to fine scales. The progressive context fusion mechanism, which uses cross-attention to accumulate context across sequential coding steps, is a novel architectural element not present in prior context models, which typically condition only on the hyperprior and previously coded latents at a fixed scale.

## Why It Matters / Open Questions

The hierarchical coding schedule offers a practical, lower-complexity alternative to transformer-based global context modeling (e.g., Entroformer, FLIC) for capturing long-range dependencies, which is significant for deployment where computational budget matters. The 19.19% BD-rate improvement over VTM-22.0 with only 1261 kMACs/pixel (vs. 1823 for TCM or 2343 for WeConvene) demonstrates that architectural efficiency in context modeling can rival or exceed brute-force approaches. Open questions include whether the hierarchical schedule generalizes to video compression, whether the fixed (2,3,6) step allocation is optimal across content types, and whether the cross-attention fusion can be further simplified without performance loss.

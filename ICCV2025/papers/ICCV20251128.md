## Problem

Perception tasks span four combinations of prediction type (box vs. mask) and instruction type (word-based vs. sentence-based), yet existing methods address only a subset of these groups. No prior work has demonstrated that a single VLLM-based architecture can jointly perform all four task types, leaving the collaborative effects of cross-group joint training unexplored.
![Teaser figure](../imgs/ICCV20251128/cropped_page2_idx0.webp)

## Input / Output

The model takes an RGB image (resized to 1024×1024) and a text instruction—either a comma-separated word list for word-based perception or a natural-language referring sentence for sentence-based perception—formatted within a unified prompt template. It simultaneously outputs bounding boxes and segmentation masks via a multi-granularity decoder, while the LLM portion generates an image caption followed by a special summary token whose hidden states drive query generation. The caption generation is part of the training objective, not a separate inference step.

## Method

MVP-LM integrates a Swin-B image encoder, a connector, a Phi-1.5 LLM, and an OpenSeeD-style multi-granularity decoder with deformable attention and shared box/mask/similarity heads. A key mechanism is dynamic query generation: the LLM produces a summary token whose hidden states are projected into N base query vectors, while multi-scale visual features are selected by similarity to the instruction embedding and added as language-guided residuals, yielding N final queries tailored to the specific task. A CoT-inspired data curation strategy unifies COCO-Panoptic, RefCOCO, Objects365, and GoldG into a single SFT dataset where each response follows a 'thinking-then-perceiving' format (auto-generated image caption + summary token), with multi-caption labeling from four different VLLMs to reduce overfitting. Training proceeds in two stages—connector alignment on CC3M followed by full-model fine-tuning—optimizing a composite loss combining next-token prediction, word/sentence classification, mask (BCE+Dice), and box (L1+GIoU) terms with bipartite matching and denoising.

## Results

On the RefCOCO referring segmentation benchmark, MVP-LM (1.3B params) achieves 83.6 cIoU on val, 85.1 on testA, and 82.5 on testB, matching PSALM on val and surpassing it on testA/testB. On RefCOCOg, MVP-LM reaches 75.1 cIoU (val) and 75.6 (test), outperforming PSALM (73.8/74.4) and all other VLLM-based generalists. On word-based COCO-Panoptic segmentation, MVP-LM achieves 56.1 PQ and 66.8 mIoU, competitive with specialist methods like OpenSeeD (59.5 PQ) while also handling open-set tasks (ADE-OV: 19.4 PQ, Cityscapes-OV: 35.3 PQ). For referring expression comprehension, MVP-LM attains 93.5 cIoU on RefCOCO val with only 1.3B parameters, surpassing 7B and 13B models (Shikra: 87.8, Octopus: 89.0) and approaching the 200B+ DeepSeek-VL2 (95.1).

## Baselines & Comparisons

Against the closest VLLM-based competitor PSALM, MVP-LM wins on RefCOCO testA (85.1 vs 84.7), testB (82.5 vs 81.6), RefCOCO+ val (73.9 vs 72.9), testA (76.8 vs 75.5), and RefCOCOg val/test (75.1/75.6 vs 73.8/74.4), but loses notably on RefCOCO+ testB (65.4 vs 70.1) and gRefCOCO val (37.6 vs 42.0). MVP-LM clearly outperforms all other VLLM-based generalists (OMG-LLaVA, GSVA-7B, LISA-7B, LaSagnA-7B, PixelLM-7B) across RefCOCO, RefCOCO+, and RefCOCOg by 5–10 cIoU points. On word-based COCO-Panoptic segmentation, MVP-LM (56.1 PQ) trails the specialist OpenSeeD (59.5 PQ) by 3.4 PQ but surpasses the VLLM-based PSALM (55.9 PQ) and OMG-LLaVA (53.8 PQ). On open-set ADE20K segmentation, MVP-LM (19.4 PQ) nearly matches specialist OpenSeeD (19.7 PQ) and substantially outperforms PSALM (13.7 PQ) by 5.7 PQ. For referring expression comprehension, MVP-LM at 1.3B parameters (93.5 RefCOCO val) surpasses 7B/13B models like Shikra (87.8) and Octopus (89.0) but remains behind the 200B+ DeepSeek-VL2 (95.1) by 1.6 points.

## Relation to Prior Work

MVP-LM builds directly on OpenSeeD's multi-granularity decoder (deformable attention with shared box/mask heads and bipartite matching) and the LLaVA-style VLLM training recipe (connector alignment followed by joint fine-tuning). It departs from prior VLLM-based perception methods (LISA, PixelLM, Glamm) that handle only sentence-based mask prediction, and from VLLM generalists like PSALM and OMG-LLaVA that cover both word- and sentence-based instructions but omit box prediction. The key conceptual departure is the CoT-inspired data curation that reformulates heterogeneous perception datasets into a unified 'thinking-then-perceiving' SFT format, and the query enhancement strategy that derives base queries from LLM-generated summary tokens rather than using fixed or purely learnable queries.

## Why It Matters / Open Questions

This is the first single VLLM framework to simultaneously address all four combinations of prediction type (box/mask) and instruction type (word/sentence), providing a practical unified interface for diverse perception tasks. The finding that a 1.3B-parameter model (Phi-1.5 + Swin-B) can match or exceed 7B–13B VLLM baselines on referring expression comprehension suggests that a well-designed perception decoder can compensate for limited LLM scale. However, the gRefCOCO results (37.6 val cIoU) remain notably below PSALM (42.0), indicating that the unified framework still struggles with the hardest open-set referring segmentation. The authors flag R1-style reinforcement learning as a natural next step, and it remains open whether the CoT-inspired curation generalizes beyond the specific task set explored here.

## Problem

Existing real-world chart captioning datasets suffer from two critical flaws: captions contain extraneous information (e.g., document context, parameter values) that cannot be inferred from the chart image alone, which trains models to hallucinate, and they fail to capture type-specific structural elements and key insights (e.g., exact max/min values, trend patterns) that vary by chart type. Additionally, standard reference-based metrics (BLEU, ROUGE, BERTScore) cannot assess whether a caption is actually faithful to the visual content of the chart.

## Input / Output

The input is a single real-world chart image (line, bar, pie, histogram, scatter, area, bubble, choropleth map, or treemap) sourced from scientific papers and data platforms. The output is a dense, type-specific caption averaging 231.1 words that follows a structured schema: it first describes structural components (title, axis ranges, legend entries, marker styles) and then reports key insights (exact data points at extrema, ranges, trend directions, series comparisons). The Visual Consistency Score metric additionally takes a caption as input, converts it to executable Matplotlib code via an LLM, renders a reconstructed chart image, and computes cosine similarity (via SigLIP2 at 512px) against the original chart.

## Method

CHARTCAP is built via a four-stage automated pipeline: (1) InternVL2.5-8B filters non-chart and multi-chart images from 3.1M candidates; (2) GPT-4o classifies chart type and extracts titles; (3) GPT-4o and Claude 3.5 Sonnet extract type-specific structural components and key insights per a schema derived from the VLAT test blueprint; and (4) GPT-4o-mini transforms the accumulated semi-structured data into coherent sentences. Quality control uses cycle-consistency-based human verification: Claude 3.5 Sonnet generates Python code to reconstruct the chart from the caption, and human annotators compare the reconstructed image to the original (24× faster than direct image-caption comparison, 95% F1). For evaluation, the proposed Visual Consistency Score (VCS) and OCRScore are reference-free metrics that measure how faithfully a caption can regenerate the source chart. Experiments fine-tune InternVL2.5-8B and Phi3.5-vision-4B via LoRA on the 509K training split, showing that the smaller fine-tuned models surpass both larger open-source models and Claude 3.5 Sonnet on VCS, OCRScore, and human preference.

## Results

On the CHARTCAP test set, Phi3.5-Vision-4B_CHARTCAP achieves the highest scores across all metrics: sacreBLEU 23.82, ROUGE-L 0.3900, BERTScore 0.7427, VCS (Large) 0.8933, and OCRScore 0.5179. InternVL2.5-8B_CHARTCAP follows closely with sacreBLEU 19.47, BERTScore 0.7238, VCS (Large) 0.8913, and OCRScore 0.5089. Both CHARTCAP-fine-tuned models surpass the strongest proprietary baseline (Claude 3.5 Sonnet: sacreBLEU 5.35, BERTScore 0.6606, VCS 0.8834, OCRScore 0.4868) and all open-source baselines by substantial margins. On the VisText benchmark, Phi3.5-Vision-4B_CHARTCAP further outperforms even human-authored ground-truth captions in VCS (0.9443 vs. 0.9172) and human preference.

## Baselines & Comparisons

Both CHARTCAP-fine-tuned models (InternVL2.5-8B_CHARTCAP and Phi3.5-Vision-4B_CHARTCAP) decisively outperform all five baseline families on every metric. Against Claude 3.5 Sonnet, the strongest proprietary model, Phi3.5-Vision-4B_CHARTCAP leads by +18.47 sacreBLEU, +0.0821 BERTScore, +0.0099 VCS, and +0.0311 OCRScore, and is also preferred by human evaluators on informativeness, accuracy, and hallucination. Against the chart-expert models ChartGemma-2B and ChartInstruct-Llama2-7B, the CHARTCAP models achieve roughly 30× higher sacreBLEU and 0.15–0.21 higher VCS, indicating that domain-specific fine-tuning on high-quality dense captions far exceeds general chart instruction tuning. Against the open-source InternVL2.5 family, the 8B CHARTCAP-fine-tuned model surpasses even the 78B variant (sacreBLEU 19.47 vs. 8.15; BERTScore 0.7238 vs. 0.6642), demonstrating that data quality can compensate for a 10× model-size gap. Finally, Phi3.5-Vision-4B_CHARTCAP outperforms its own base model (Phi3.5-Vision-4B) by +15.41 sacreBLEU and +0.05 VCS, while fine-tuning on original ArxivCap/ChartSumm captions (Phi3.5-Vision-4B_Original, _ChartSumm) actually degrades performance below the base model, underscoring that the CHARTCAP schema and extraneous-information removal are critical to the gains.

## Relation to Prior Work

This paper positions itself against the lineage of real-world chart captioning datasets (ArxivCap, ChartSumm, Chart-to-Text, SciCap) that pair chart images with captions extracted from source documents, which the authors argue introduce extraneous, non-inferable information. It departs from prior work by introducing a type-specific caption schema grounded in data visualization theory (VLAT, Munzner's VAD) and by repurposing the cycle consistency principle from CycleGAN (Zhu et al., 2017) as a human verification mechanism for chart-caption pairs. The Visual Consistency Score metric breaks from the reference-based evaluation paradigm (BLEU, ROUGE, BERTScore, CLIPScore) by exploiting the deterministic code-to-chart generation property unique to charts, using an LLM to translate captions into Matplotlib code and comparing the reconstructed image to the original.

## Why It Matters / Open Questions

CHARTCAP provides a 565K-scale, human-verified, real-world chart-caption dataset that directly addresses the two failure modes (extraneous information and insufficient structural/insight coverage) plaguing existing resources, making it a likely default training set for chart understanding research. The VCS metric offers a practical, reference-free evaluation that aligns well with human judgment, potentially replacing or complementing BERTScore in chart captioning benchmarks. A key limitation is the restriction to nine chart types defined by VLAT, which excludes common visualizations like network graphs, Sankey diagrams, or small multiples; expanding the schema is identified as future work. The finding that a 4B model fine-tuned on CHARTCAP outperforms both a large proprietary model and human-annotated captions raises open questions about whether data quality can systematically substitute for model scale in structured visual understanding tasks.

## Problem

Small object detection (SOD) on limited-resolution images remains challenging because small objects (≤20 px) suffer from inadequate feature representation. Existing remedies—GAN-based super-resolution, handcrafted feature imitation, or very high-resolution inputs—introduce artefacts, training instabilities, or prohibitive computational costs. The paper asks how to improve SOD robustness on standard 640×640 inputs without these drawbacks while preserving inference speed.
![Teaser figure](../imgs/ICCV20251504/cropped_page0_idx3.webp)

## Input / Output

The method consumes a single 640×640 RGB image and produces standard object detection outputs (bounding boxes with class labels) through a modified YOLOv7 backbone-neck-head pipeline. Internally, a control module also predicts the minimum and maximum object sizes present in the image (each a scalar in (1, 640]), which together with a pre-learned size-features codebook drive dynamic feature selection at inference. The codebook itself is a one-hot mapping from object size to the single most reliable head feature resolution, learned via an IoU-based voting procedure over training epochs.

## Method

DM-EFS integrates two ideas: (1) the Expanded Features Set (EFS) form, which taps previously unused higher-resolution features from the shallower backbone layers and propagates them through the neck and head, enriching small-object representations; and (2) Dynamic Feature Multiplexing (DFM), which at inference uses a control module to generate binary gating signals for multiplexers in the neck and head, selecting only the smallest subset of EFS features sufficient to reliably detect the full range of object sizes in the current image. The control module learns a size-features codebook Ω(f_H^k, s) by accumulating per-epoch IoU-thresholded votes across all training objects, and simultaneously predicts min/max object sizes via a two-branch focal-loss classifier on backbone features. At inference, the codebook is queried at the predicted s_min and s_max to identify the two most relevant feature resolutions, and the multiplexers pass only those features (plus any neck features needed to feed them), yielding the DM-EFS form—a subsampled, per-image-optimal version of EFS that matches EFS-level SOD accuracy at near-base-model inference speed.

## Results

On the SODA-D test set (640×640), DM-EFS achieves 34.91% AP and 64.47% AP50, outperforming the YOLOv7 base model (30.52% AP) by +4.39% and the strongest SOD baseline ESOD (27.04% AP) by +7.87%. On VisDrone, DM-EFS reaches 29.71% AP (+2.11% over YOLOv7, +6.10% over ESOD), and on DarkFace it attains 29.30% AP and 69.30% AP50. Inference speed is maintained at 38.89 fps on SODA-D and 38.24 fps on VisDrone, on-par with YOLOv7 (40.91/39.71 fps) while exceeding ESOD (30.23/30.05 fps) and CFINet (28.41/27.94 fps).

## Baselines & Comparisons

DM-EFS outperforms all 11 baselines on every dataset and metric reported. Against the YOLOv7 base model, it gains +4.39% AP on SODA-D, +2.11% on VisDrone, and +0.39% on DarkFace, with the largest relative improvements in the extreme-small (APeS: +2.79%) and relatively-small (APrS: +1.90%) categories on SODA-D. Among dedicated SOD methods, DM-EFS surpasses ESOD by +7.87% AP (SODA-D) and +6.10% (VisDrone), CFINet by +10.40% (SODA-D) and +15.11% (VisDrone), and QueryDet by +10.45% (SODA-D). Classical detectors (Faster-RCNN, RetinaNet, Sparse-RCNN) trail by 14–19% AP on SODA-D. On inference speed, DM-EFS (38.89 fps on SODA-D) is within ~5% of YOLOv7 (40.91 fps) while being 28% faster than ESOD (30.23 fps) and 37% faster than CFINet (28.41 fps), confirming that the DFM multiplexing recovers most of the computational overhead introduced by the EFS form.

## Relation to Prior Work

This paper departs from the dominant SOD strategies—GAN-based feature super-resolution, handcrafted feature imitation (CFINet), and high-resolution input requirements (QueryDet, ESOD)—by proposing a simpler principle: the backbone already computes higher-resolution features in its shallower layers that are simply discarded before reaching the neck and head. The EFS form makes explicit use of these untapped features, while the DFM design (a learned size-features codebook plus dynamic gating) selectively activates only the feature resolutions needed for the object sizes present in each image. Conceptually, it is closest to FPN-style multi-scale processing but reframes the problem as one of *which* existing features to use rather than *how* to synthesize new ones, and it inherits its base architecture from YOLOv7.

## Why It Matters / Open Questions

The practical significance is that SOD at 640×640 resolution—common in real-time and resource-constrained deployments—improves substantially (e.g., +4.4 AP on SODA-D) without the computational overhead that typically accompanies richer feature representations, since DFM recovers most of the lost inference speed. The codebook's dataset-agnostic interchangeability (VisDrone ↔ DarkFace) suggests the size-to-resolution mapping is a fairly universal property, which could reduce per-dataset tuning. Open questions include whether the approach generalizes beyond k=4 feature levels, whether the two-branch min-max size predictor remains reliable under extreme size distributions, and whether the separate codebook-learning phase can be folded into standard end-to-end training without the convergence heuristics in Algorithm 1.

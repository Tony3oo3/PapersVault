## Problem

Existing cross-modal fusion methods for event-based motion deblurring rely on synapse-level attention that only adjusts weight magnitudes, which fails to handle the non-uniform (sparse) distribution of events in blurry regions and the inherent redundancy of repetitive motion events. This results in ineffective feature extraction and suboptimal deblurring, particularly under low-contrast or high-motion conditions where event streams are sparse or noisy.
![Teaser figure](../imgs/ICCV20251790/cropped_page0_idx0.webp)

## Input / Output

The network consumes multi-scale blurry RGB images (at full, half, and quarter resolution) alongside a voxel-based event representation (H×W×b) derived from the raw asynchronous event stream. The SNN branch processes events over discrete timesteps while the ANN branch handles the image pyramid, and the two branches are fused at multiple scales. The output is a single deblurred RGB image at the original resolution, reconstructed by a MIMO-based decoder. Training uses 512×512 crops on GoPro and 256×256 crops for REBlur fine-tuning.

## Method

BDHNet is a bioinspired dual-drive hybrid network with an encoder-decoder structure that pairs a MIMO-based CNN encoder (for color/texture) with an SNN encoder (for motion), connected by two complementary attention modules inspired by the human visual cortex. The Neuron Configurator Module (NCM) implements neuron-based attention by using cross-modal image features to dynamically set both the initial membrane potential and a pixel-wise threshold map across all timesteps of the LIF neurons, increasing spike activity specifically in blurry regions where events are sparse. The Region of Blurry Attention Module (RBAM) implements enhanced synapse-based attention by applying a deformable convolution to temporally aggregated spike features (with image-guided offsets) to produce a local spike map, which is binarized against an image-derived threshold map to yield an unsupervised blurry-region mask. This mask then gates a bidirectional cross-attention fusion: image features attend to event features in masked (blurry) regions while event features attend to image features in unmasked regions, followed by channel-wise concatenation. The entire network is trained end-to-end with PSNR loss using ADAM (lr=1e-4, 120 epochs on GoPro, 30-epoch fine-tuning on REBlur at lr=1e-5).

## Results

On the GoPro dataset, BDHNet achieves a PSNR of 37.04 dB and SSIM of 0.977, outperforming the best event-based baseline STCNet (36.45 dB / 0.975) by 0.59 dB. On REBlur, it reaches 38.50 dB / 0.978, edging out MAENet (38.46 dB / 0.978) by 0.04 dB in PSNR while matching SSIM. Notably, without any fine-tuning on REBlur (trained only on GoPro), BDHNet still achieves 36.01 dB / 0.967, surpassing the best zero-shot baseline EIFNet (35.75 dB / 0.965) by 0.26 dB, demonstrating strong cross-dataset generalization.

## Baselines & Comparisons

BDHNet outperforms all 11 baselines across every evaluation setting. Against the strongest event-based competitors on GoPro, it leads STCNet by 0.59 dB (37.04 vs. 36.45) and MAENet by 0.97 dB (37.04 vs. 36.07). On REBlur, the margin over MAENet narrows to 0.04 dB (38.50 vs. 38.46) while matching its SSIM of 0.978, and it surpasses EFNet by 0.48 dB. The most striking result is in the zero-shot REBlur setting (no fine-tuning): BDHNet achieves 36.01 dB, beating EIFNet (35.75 dB) and STCNet (35.64 dB), whereas MAENet drops catastrophically to 32.86 dB and EFNet to 27.43 dB, indicating that the bio-inspired neuron configuration and blurry-region mask provide robustness that purely attention-based fusion methods lack. Among image-only baselines, the best (UFPNet at 34.06 dB on GoPro) trails BDHNet by nearly 3 dB, underscoring the value of event data integration.

## Relation to Prior Work

This paper extends the event-based motion deblurring line (EDI, EFNet, MAENet, STCNet) and the SNN-based image restoration line (MotionSNN, SC-Net, EDHNet) by introducing a bio-inspired dual-drive mechanism that operates at two distinct levels of the SNN: neuron-level (dynamic membrane potential and threshold configuration via NCM) and synapse-level (mask-guided cross-modal attention via RBAM). Prior cross-modal attention methods (EFNet, EIFNet, MAENet, STCNet) adjust only weight magnitudes at the synaptic level, while prior SNN-based deblurring (MotionSNN) uses uniform neuron configurations; BDHNet departs from both by making neuron parameters pixel-level and cross-modal, drawing an explicit analogy to the neuron-based and synapse-based attention mechanisms in the human visual cortex. The MIMO-based encoder-decoder backbone and the EDI mathematical formulation are inherited from prior work, so the novelty is concentrated in the dual-drive enhancement modules rather than the overall pipeline.

## Why It Matters / Open Questions

The most practically relevant finding is the zero-shot generalization: trained only on GoPro, BDHNet achieves 36.01 PSNR on REBlur without fine-tuning, substantially outperforming MAENet (32.86) and STCNet (35.64) under the same protocol, suggesting the dynamic neuron configuration provides a more transferable inductive bias than fixed-weight attention. An open question is whether the bio-inspired framing (neuron-based vs. synapse-based attention) captures a genuinely distinct computational principle or is primarily a design metaphor, since the NCM essentially performs cross-modal feature-conditioned initialization of LIF parameters. The method's reliance on a single RTX 4090 and its evaluation limited to three deblurring benchmarks leave open whether the dual-drive strategy scales to higher-resolution or video-level restoration tasks.

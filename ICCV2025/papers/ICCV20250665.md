## Problem

Existing segment-correspondence methods for anime paint bucket colorization are constrained to one or two reference images by the fixed input structure of the Multiplex Transformer, and keyframe colorization—where large pose, viewpoint, and occlusion changes break spatial alignment—remains significantly less accurate than consecutive frame colorization. Line drawings, consisting only of stylized contours, lack the rich semantic cues that natural images provide, making it difficult to extract meaningful features for correspondence.

## Input / Output

The method takes a target line drawing and any number K of reference line drawings, each accompanied by binary segment masks (regions enclosed by continuous line boundaries) and per-segment RGB color assignments. Images are resized to 518×518 for the frozen DINOv2 encoder and 512×512 for the U-Net; no resizing is applied at test time. The output is a per-segment color assignment (an RGB value for each enclosed region in the target), which can be directly applied via a paint bucket tool rather than producing a full pixel-level composite image.

## Method

DACoN fuses frozen DINOv2-Large semantic features (1024-d, low-resolution patches) with a 4-level U-Net spatial feature map (128-d, full resolution) to obtain segment-level representations that are both semantically meaningful and spatially precise. Each image is processed independently: features are pooled per segment via mask-weighted averaging (superpixel pooling), DINO features are dimensionally reduced by an MLP and concatenated with CNN features, then fused by a second MLP. Correspondence is established by computing cosine similarity between the target's N segment features and the concatenated M segment features from all K references, with the argmax reference segment's color propagated to each target segment. Training uses a temperature-scaled cross-entropy loss (T=0.1) that treats colors as discrete classes, combined with a DINO-guided Feature Consistency Loss (MAE between the model's similarity map and the raw DINO similarity map, scaled by 10) that preserves the foundation model's semantic structure. This per-image, attention-free design removes the fixed-input constraint of Multiplex Transformers, enabling any number of reference images without architectural modification.

## Results

On keyframe colorization (Table 1), DACoN achieves 72.58% segment accuracy (Acc-Thresh) with one reference image, improving to 77.44% with five references and 78.48% with all available references, substantially outperforming the closest segment-based baseline BasicPBC-Ref (63.46% / 64.59%). On consecutive frame colorization (Table 2), DACoN reaches 88.23% Acc-Thresh on 3D-rendered data and 90.48% on hand-drawn data, surpassing BasicPBC (87.26% / 89.29%) and AnT (77.13% / 78.79%). Pixel-level foreground accuracy (Pix-F-Acc) reaches 94.27% for keyframe (max refs) and 97.97% for consecutive frame (3D), indicating strong visual quality.

## Baselines & Comparisons

DACoN decisively outperforms all seven baselines on keyframe colorization. Against the closest segment-based competitor BasicPBC-Ref, DACoN gains +9.12 points in Acc-Thresh (72.58 vs. 63.46) with one reference and +12.85 points with five references (77.44 vs. 64.59), while also improving Pix-F-Acc by ~8 points. The generation-based methods (ColorFlow, MangaNinja, AniDoc) lag far behind on segment-level accuracy (10.81–22.68% Acc-Thresh) and struggle with fine details and background over-coloring. On consecutive frame colorization, DACoN edges out BasicPBC by +2.10 points (3D) and +1.19 points (hand-drawn) in Acc-Thresh, and surpasses AnT by a wide margin (+11.10 / +11.69 points). Notably, DACoN's advantage grows with more reference images, whereas BasicPBC-Ref shows only marginal improvement (+1.13 points from 1 to 5 refs), confirming that the Multiplex Transformer constraint limits prior methods' ability to exploit diverse references.

## Relation to Prior Work

This paper departs from the segment-correspondence colorization line (AnT, BasicPBC) by replacing the Multiplex Transformer—which enforces a fixed input structure limiting references to one or two—with a simpler cosine-similarity matching scheme that scales to any number of reference images. It repurposes DINOv2, a foundation model trained on natural images, as a frozen semantic encoder for line drawings, a setting where prior work assumed only CNN features were useful. The U-Net branch and the DINO-guided Feature Consistency Loss are new architectural and training components, but the overall pipeline (extract features → pool per segment → match → propagate color) follows the established segment-correspondence paradigm.

## Why It Matters / Open Questions

The practical impact is significant for anime production: a single unified model handles both keyframe and consecutive-frame colorization, and the ability to query an arbitrary number of color design sheet images without per-frame reference selection simplifies the workflow. The finding that DINOv2 captures part-level semantics in stylized line drawings opens the door to using foundation models for other line-art tasks. Open questions include whether the approach generalizes to multi-character scenes, whether the frozen DINOv2 encoder is truly necessary versus a fine-tuned variant, and how the method behaves when reference images are from entirely different characters or art styles.

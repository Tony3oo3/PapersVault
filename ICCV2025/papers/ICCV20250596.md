## Problem

Existing visual tokenizers (e.g., VQGAN) are trained solely on image reconstruction and capture only low-level pixel information, making it difficult to align discrete visual tokens with language tokens in unified VLMs. This misalignment forces prior unified models to rely on massive image-text corpora (hundreds of millions of pairs) and still yields understanding performance far below dedicated VLMs. The paper asks whether semantic information can be injected directly into the discretization process to close this gap.

## Input / Output

For understanding, the model receives an RGB image (resized to 256×256 or 384×384) alongside a text prompt; the image is converted into a 16×16 or 27×27 grid of discrete visual tokens (codebook size 32,768, dim 8) and wrapped in <soi>/<eoi> markers before being concatenated with text tokens. For generation, the input is a text prompt alone, and the model autoregressively predicts the visual token sequence, which is then decoded back into an RGB image by a ConvNet image decoder. The entire pipeline uses a single autoregressive next-token prediction objective with standard cross-entropy loss—no diffusion head or separate generation branch.

## Method

The core contribution is Semantic Discrete Encoding (SDE), a visual tokenizer that fuses frozen SigLIP semantic features with image-encoder features before vector quantization, so the resulting discrete codes carry both pixel-level and language-aligned semantic information. Two parallel decoder branches enforce this: a ConvNet image decoder (trained with L2 + LPIPS + adversarial loss) preserves reconstruction quality, while a ViT semantic decoder (inspired by BEITv2) maximizes cosine similarity between decoded features and the SigLIP reference, adding a semantic loss term to the standard VQGAN objective. On top of SDE, MUSE-VL simply extends the embedding table of a pretrained LLM (Qwen-2.5 or Yi-1.5) with 32,768 new visual-token IDs and trains with next-token prediction—no architectural changes, no contrastive pretraining, and no separate encoders for understanding vs. generation. This design reduces the required image-text pretraining data to 24 M pairs (vs. 600 M–1.4 B for prior unified models) while improving understanding accuracy by 4.8 % over Emu3 at the same LLM size.

## Results

On multimodal understanding, MUSE-VL (Qwen2.5-7B) achieves an average of 63.6 across MMBench, MMStar, SEED, MMMU, SQA-I, AI2D, and MathVista, surpassing the previous SOTA unified model Emu3 (58.8) by 4.8 points and the dedicated understanding model LLaVA-NeXT 34B (66.4) by 3.7 points at the 32B scale (70.1). On text-to-image generation, MUSE-VL (7B) achieves a FID of 7.73 on MJHQ-30K, outperforming all prior unified models (Janus: 10.10, VILA-U: 12.81, Show-o: 15.18) and even SD-XL (9.55). The SDE tokenizer alone improves multimodal understanding by +7.5% over SEED and +6.4% over LaVIT when paired with the same LLM (Yi-1.5-9B).

## Baselines & Comparisons

MUSE-VL (7B) outperforms the previous SOTA unified model Emu3 (8B from scratch) by 4.8 points on average (63.6 vs. 58.8), with particularly large gains on MMBench (+13.6) and MMMU (+8.1), while matching or exceeding Emu3 on SEED and MathVista. At the 32B scale, MUSE-VL surpasses the dedicated understanding model LLaVA-NeXT 34B by 3.7 points on average (70.1 vs. 66.4), despite LLaVA-NeXT using continuous visual features and a larger base LLM. On image generation (MJHQ-30K FID), MUSE-VL (7.73) substantially outperforms Janus (10.10), VILA-U (12.81), and Show-o (15.18), though it trails Janus on GenEval text-to-image alignment (0.53/0.57 vs. 0.61). The SDE tokenizer, when swapped into the same LLM (Yi-1.5-9B), improves understanding by +7.5% over the SEED tokenizer and +6.4% over LaVIT, confirming that semantic alignment in the tokenizer is the key differentiator. Notably, MUSE-VL achieves these results with only 24M image-text pairs for pretraining, compared to 1.4B for Chameleon, 720M for VILA-U, and 600M for SEED-LLaMA.

## Relation to Prior Work

This paper extends the VQGAN-style vector quantization framework for image tokenization by introducing a semantic supervision branch that aligns discrete visual tokens with language. It departs from prior unified models (Emu3, Chameleon, Show-o) that rely on purely reconstruction-trained tokenizers, and from VILA-U's contrastive-learning approach that suffers from loss conflicts, by instead using a frozen SigLIP teacher to inject semantic features directly into the quantization process. The resulting SDE tokenizer is a drop-in replacement that requires no architectural changes to the LLM, contrasting with Janus's dual-encoder design or TokenFlow's dual-codebook scheme.

## Why It Matters / Open Questions

The key practical contribution is a 25–60× reduction in required image-text pairs (24M vs. 600M–1.4B) for aligning visual and language tokens, making unified VLM training substantially more accessible. The finding that the tokenizer—not the LLM—is the primary bottleneck for understanding performance in discrete-token unified models reframes where future effort should be directed. Open questions include whether the approach scales to video, higher resolutions, or longer sequences, and whether the semantic branch can be further strengthened without degrading reconstruction fidelity.

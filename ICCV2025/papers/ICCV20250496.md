## Problem

Existing 3D anomaly detection methods rely on discrete representations (voxels, sparse point clouds, or 2D projections) that introduce quantization artifacts and lose fine-grained geometric detail, making subtle shape deviations hard to localize. Additionally, arbitrary object poses confound shape-based comparison, and no prior framework unifies anomaly detection with in-situ geometric repair from a single learned representation.
![Teaser figure](../imgs/ICCV20250496/cropped_page0_idx0.webp)

## Input / Output

The method takes a 3D point cloud of M points in R³ as input, trained exclusively on normal samples per category (unsupervised). At inference, the aligned test point cloud's surface points are fed into the SDF network to produce per-point anomaly scores (absolute SDF values), which are aggregated over the top-K=1000 points for an object-level score. For repair, the zero-level set of the learned SDF is extracted via Marching Cubes on a 3D grid, yielding a repaired triangular mesh that is resampled into a point cloud.

## Method

PASDF disentangles pose and shape through a three-stage pipeline: (1) a Pose-wise Alignment Module (PAM) that registers each input to a canonical pose using FPFH descriptors, RANSAC coarse matching, ICP refinement, and iterative Chamfer-distance feedback; (2) an 8-layer MLP SDF network with sinusoidal positional encoding, weight normalization, and a skip connection that maps 3D query coordinates to signed distances, trained with a clamped L1 loss (d_max=0.1) over 23,000 sampled query points (surface, interior, and exterior); (3) an anomaly scoring stage where the absolute predicted SDF at each surface point serves as the point-level anomaly score. The key insight is that the continuous SDF implicitly encodes the normal shape manifold, so deviations from zero at surface points directly indicate geometric anomalies, and the same SDF's zero-level set provides a high-fidelity repair template without requiring a separate reconstruction network.

## Results

On Real3D-AD, PASDF achieves a mean O-AUROC of 80.2% and P-AUROC of 74.5%, outperforming the strongest baselines (Group3AD: 75.1% O-AUROC, 73.5% P-AUROC) by 5.1 and 1.0 percentage points respectively. On Anomaly-ShapeNet, PASDF reaches 90.0% O-AUROC and 89.7% P-AUROC, ranking first in 37 of 40 categories and surpassing the next-best method R3D-AD (74.9% O-AUROC) by 15.1 points. For anomaly repair, positional encoding reduces Chamfer Distance from 0.0255 to 0.0203 on Real3D-AD and from 0.0575 to 0.0445 on Anomaly-ShapeNet.

## Baselines & Comparisons

PASDF outperforms all eight baselines on both datasets and both metrics. On Real3D-AD, it leads Group3AD (the strongest prior method) by 5.1 points in O-AUROC (80.2% vs. 75.1%) and by 1.0 point in P-AUROC (74.5% vs. 73.5%); the gap widens to 7.7 points over IMRNet (72.5%) and 12.0 points over PatchCore(FPFH+Raw) (68.2%). On Anomaly-ShapeNet, PASDF's 90.0% O-AUROC exceeds R3D-AD (74.9%) by 15.1 points and IMRNet (66.1%) by 23.9 points, with PASDF ranking first in 37 of 40 categories versus R3D-AD's more inconsistent per-category performance. The PAM module also generalizes: when applied to PatchCore(FPFH) on Anomaly-ShapeNet, it boosts O-AUROC from 56.8% to 81.4% (+24.6 points), confirming that pose alignment is a broadly beneficial preprocessing step independent of the downstream detector.

## Relation to Prior Work

PASDF departs from the dominant paradigm in 3D anomaly detection that relies on discrete representations (voxel grids, point clouds, multi-view projections) by adopting a continuous Signed Distance Function learned via a lightweight MLP. It draws on classical point cloud registration (RANSAC + ICP + FPFH) as an explicit pose-disentanglement front-end, a component largely absent from prior deep-learning-based anomaly detectors that either assume pose consistency or handle it implicitly. The repair capability extends reconstruction-based methods like IMRNet and R3D-AD, which operate on discrete point clouds, by leveraging the SDF's zero-level set (via Marching Cubes) to produce a continuous, high-fidelity repair template—something discrete representations cannot naturally provide.

## Why It Matters / Open Questions

The unified detection-and-repair framing is practically significant for closed-loop additive manufacturing, where identifying a defect is only the first step and in-situ correction requires an explicit geometric template. The finding that a classical registration pipeline (PAM) transfers effectively to diverse baselines (up to 24.6% O-AUROC gain for PatchCore) suggests pose misalignment is an underappreciated bottleneck in 3D anomaly detection. Key limitations remain: the single-class assumption, the computational cost of iterative ICP under challenging initial poses, and sensitivity to input point cloud quality all constrain real-world deployment. Extending to multi-class settings, learning-based registration, and noise-robust SDF learning are natural next steps.

## Problem

Query-based instance-level interaction is a bandwidth-efficient paradigm for collaborative perception, yet LiDAR-focused implementations remain underdeveloped: existing methods like TransIFF support only vehicle-infrastructure (V2I) scenarios and their detection performance still trails state-of-the-art intermediate fusion approaches. The paper addresses how to achieve high-accuracy LiDAR-based instance-level interaction in full V2X (vehicle-to-vehicle and vehicle-to-infrastructure) settings while keeping communication cost minimal.
![Teaser figure](../imgs/ICCV20251371/cropped_page0_idx0.webp)

## Input / Output

Each agent ingests a LiDAR point cloud (grid resolution 0.1 m, height 0.2 m for V2V4Real) and a 4×4 spatial transform matrix relative to the ego agent. Instead of transmitting full feature maps, the system sends only filtered instance-level query features (≈16 KB/frame, i.e. 2^13–2^14 bytes) paired with a sparse 2D relative position map, and produces per-agent 3D bounding boxes with class labels. The detection head is a separate FFN that decodes the final concatenated instance features into classification and regression outputs.

## Method

INSTINCT builds on ConQueR's BoxAttention encoder-decoder for single-agent instance extraction, then applies three collaboration-specific modules. (1) Quality-Aware Filtering selects high-confidence instances using a MAL loss with BEV-IoU penalty (applied only in the final decoder layer to avoid 3D-IoU numerical instability) and attaches a unified spatial position map so out-of-range instances are pruned before transmission. (2) Dual-Branch Detection Routing (DDR) concatenates ego and received instances, runs them through a shared detection head, and uses an IoU matrix threshold to split the set into collaboration-irrelevant (Q_single) and collaboration-relevant (Q_coop) branches, preventing irrelevant instances from degrading fusion. (3) Cross-Agent Local Instance Fusion (CALIF) first applies Cross-Domain Adaption—self-attention with dual position encodings (spatial coordinate + agent identifier)—to bridge hardware/environmental domain gaps, then applies Gaussian Distance Attention, an asymmetric local attention whose weights decay exponentially with the Euclidean distance between bounding-box circumcircle centers, so each instance interacts only with spatially nearby counterparts. A Co-GT Sampling strategy augments training by cropping, cross-agent mixing, and spatial-consistency-validated point clouds to increase positive-sample diversity.

## Results

On DAIR-V2X, INSTINCT achieves AP@0.5/0.7 of 0.8191/0.7529, surpassing the best intermediate-fusion baseline (Where2comm: 0.7901/0.6649) by a relative 13.23% on AP@0.7. On V2V4Real, it reaches 0.8088/0.6196, a relative 33.08% improvement over the strongest baseline (CoAlign: 0.7209/0.4656). On the simulated V2XSet, INSTINCT attains 0.9229/0.8731, edging out DiscoNet (0.8778/0.7207) by 2.81% on AP@0.7. Communication bandwidth is reduced to 13.58–14.81 log₂ bytes/frame (≈16 KB), roughly 1/281 and 1/264 of the feature-map-based methods (≈24–25 log₂ bytes).

## Baselines & Comparisons

INSTINCT outperforms all six intermediate-fusion baselines on every dataset and metric. On DAIR-V2X, it leads Where2comm (the strongest baseline) by 2.90/8.80 points on AP@0.5/0.7 and CoAlign by 3.94/9.82 points. On V2V4Real, the margin is largest: INSTINCT beats CoAlign by 8.79/15.40 points and Where2comm by 10.67/23.95 points on AP@0.5/0.7, reflecting the difficulty of real-world V2V scenarios. On the simulated V2XSet, gains are more modest (e.g., +4.51/+15.24 over DiscoNet on AP@0.5/0.7), which the authors attribute to the homogeneous scene distribution of the synthetic data. In terms of communication cost, INSTINCT transmits only ~16 KB/frame (13.58–14.81 log₂ bytes), compared to ~16–24 MB for feature-map methods (24.62–25.10 log₂ bytes) and ~2–4 MB for Where2comm (21.19–22.86 log₂ bytes), achieving a 1/281 to 1/264 bandwidth reduction relative to SOTA while simultaneously improving accuracy.

## Relation to Prior Work

INSTINCT extends the instance-level (query-based) fusion paradigm introduced by TransIFF from V2I-only scenarios to full V2X collaborative perception, and is the first to apply this paradigm to LiDAR point clouds rather than camera features. Its single-agent detection backbone is built directly on ConQueR's query-contrast architecture with BoxAttention, while its Co-GT Sampling module adapts the object-centric database idea from DI-V2X. The paper departs from the dominant feature-map intermediate fusion line (V2VNet, V2XViT, DiscoNet, Where2comm, CoAlign) by transmitting only filtered instance features with spatial position markers, trading dense spatial representations for sparse, semantically grounded queries.

## Why It Matters / Open Questions

The dramatic bandwidth reduction (~1/280 of feature-map methods) combined with large accuracy gains on real-world datasets (13.23%/33.08% AP@0.7) makes instance-level LiDAR interaction a practically viable path for bandwidth-constrained V2X deployment. However, the more modest 2.81% gain on the simulated V2XSet dataset suggests the advantage is most pronounced in heterogeneous, occlusion-heavy real scenes, and the method's reliance on a fixed ConQueR backbone and pairwise agent interaction limits immediate scalability to larger agent networks. Open questions include whether the Gaussian-distance local attention generalizes to denser urban scenes, how the architecture behaves with more than two agents, and whether the Co-GT Sampling strategy transfers to other cooperative tasks beyond detection.

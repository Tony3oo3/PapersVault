## Problem

Unlearnable Examples (UEs) have proven effective at protecting image datasets from unauthorized training, but no method exists for safeguarding asynchronous event streams, which have a fundamentally different structure (spatio-temporal point clouds with binary polarity) that makes existing image-based UEs inapplicable. The two key challenges are generating error-minimizing noise compatible with the discrete ±1 polarity constraint and injecting that noise into event streams that must pass through event-stack representations before reaching DNNs.

## Input / Output

The method takes an asynchronous event stream (a sequence of (x, y, t, p) tuples with binary polarity p ∈ {+1, −1}) and its class label as input, and produces an unlearnable event stream in the same format. Internally, the event stream is binned into a 16-channel event stack where each pixel holds values from {0, 0.5, 1.0} (polarity −1, no event, polarity +1), and the final output is reconstructed back to sparse event-stream form via a retrieval strategy that assigns timestamps to newly introduced events.

## Method

UEVs formulates a min-min bilevel optimization (Eq. 2) that trains a surrogate model (ResNet18) for limited iterations while simultaneously optimizing L∞-bounded noise δ via PGD-style updates to minimize classification loss, creating a shortcut between inputs and labels. Two noise variants are supported: class-wise (one shared noise per class, more memory-efficient) and sample-wise (unique noise per sample, stronger protection). A critical adaptive projection (Eq. 4) sparsifies the continuous noise into {−0.5, 0, +0.5} using a mean-threshold rule with balancing parameter τ, making it compatible with the binary-polarity event stack. A similarity loss (Eq. 5) is added to the outer optimization to enforce separation between clean and unlearnable features, compensating for information lost during projection. Finally, a retrieval strategy reconstructs the unlearnable event stream from the modified stack by preserving original timestamps for existing events and assigning adaptive timestamps to newly injected ones.

## Results

On N-Caltech101, class-wise noise (Δ_c) reduces ResNet18 test accuracy from 78.52% to 1.90% (−76.62 pp), while sample-wise noise (Δ_s) achieves an even larger drop to 0.52% (−77.60 pp). Across all four datasets, both noise forms consistently produce accuracy drops exceeding 40 pp for ResNet18, far surpassing the best event-pollution baseline (polarity inversion, −42.47 pp on CIFAR10-DVS). The protection generalizes across seven architectures: Swin-B drops from 90.70% to 0.52% (Δ_c) and 21.14% (Δ_s) on N-Caltech101, and EfficientNet-B1 drops from 74.44% to 12.81% (Δ_c) on the same dataset.

## Baselines & Comparisons

The paper compares UEvs against five event-pollution baselines (coordinate shifting, time-stamp shifting, polarity inversion, manual pattern injection, and area shuffling) as ResNet18 classifiers. UEvs dominates all baselines on every dataset: on N-Caltech101, Δ_s drops accuracy by 77.60 pp versus the best baseline (TS, −40.87 pp); on DVS128 Gesture, Δ_c achieves −59.38 pp versus PI's −42.20 pp; on N-ImageNet, Δ_c reaches −46.80 pp versus MP's −45.40 pp. Notably, coordinate shifting actually *improves* accuracy on DVS128 Gesture (+1.21 pp), and time-stamp shifting barely affects it (−1.22 pp), showing that simple perturbations fail to protect event data. The gap is most dramatic on N-Caltech101, where UEvs drives accuracy below 2% while the strongest baseline (TS) still leaves 37.54%. Among the two UEvs variants, sample-wise noise (Δ_s) consistently yields slightly larger drops than class-wise noise (Δ_c), though both are far superior to any pollution operation.

## Relation to Prior Work

This paper adapts the Unlearnable Examples (UEs) framework of Huang et al. [22]—which uses min-min bilevel optimization to generate error-minimizing noise on image datasets—to the fundamentally different structure of asynchronous event streams. The key departure is that event data consists of sparse spatio-temporal point clouds with binary polarity (±1), making direct application of image-based UEs infeasible; the authors introduce an adaptive projection mechanism to sparsify noise into {−0.5, 0, +0.5} and a retrieval strategy to reconstruct valid event streams from perturbed event stacks. The noise generation itself leverages PGD [38] as the inner-loop optimizer, consistent with the adversarial-optimization lineage of UEs, but the outer-loop loss is augmented with a similarity term to preserve unlearnability after the discrete projection step.

## Why It Matters / Open Questions

This is the first work to address unauthorized exploitation of event datasets, a gap that becomes increasingly critical as event cameras proliferate in autonomous driving, pose estimation, and sign-language recognition. The practical limitation is that protection relies on a surrogate model and a fixed projection threshold τ, and the paper does not explore whether a determined attacker could reverse-engineer or strip the projected noise (e.g., via learned denoising or polarity-aware filtering). Open questions include scalability to very large event datasets, robustness against adaptive attackers who observe the unlearnable data, and whether the approach extends to other neuromorphic sensing modalities (e.g., spiking neural network inputs).

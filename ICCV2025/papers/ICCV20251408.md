## Problem

Existing procedural video understanding methods face three coupled limitations: they can detect error presence but not recognize error types, they require error-annotated training videos that are infeasible to collect for all error categories, and task-graph-based segmentation assumes error-free execution, conflating background actions with error frames. This paper addresses all three gaps in a unified framework that segments actions, detects errors, and classifies error types using only normal (error-free) videos during training.

## Input / Output

The method takes pre-extracted video frame features (from VideoCLIP trained on Ego4D) and a directed acyclic task graph as input, with the constraint that only error-free videos with frame-wise step labels are available during training. At test time, it produces two aligned sequences: frame-wise step labels (where class -1 flags error frames and class 0 flags background/task-irrelevant actions) and per-frame error type predictions from a set of M error categories. Error features are not learned from data but generated on-the-fly via an LLM (GPT-4o mini) producing textual error descriptions per step per error type, then encoded by the VLM text encoder into the same feature space as visual features.

## Method

The core contribution is a Generalized Task Graph (GTG) that inserts a shared background node S_i between each step i and its predecessors in the tSort graph, growing nodes from S to 2S without exponential blowup, enabling the alignment to distinguish background from error frames. GTG2Vid extends Drop-DTW dynamic programming with two novel dropping terms: a frame-dropping cost d^x based on prediction entropy (dropping unconfident frames as errors) and a node-dropping cost d^z based on maximum step probability (dropping omitted steps), both parameterized by hyperparameters η and τ. For error recognition without error training data, LLMs generate multiple error descriptions per step per error type, and VideoCLIP encodes them into features aligned with visual features. The Error Recognition Module (ERM) computes a joint similarity score s(x_j^v, x^e, y, m) = sigmoid((x_{y,0}^e ⊙ x_{y,m}^e)^T x_j^v) that element-wise multiplies the normal-type and error-type features before dotting with the frame feature, capturing that error frames often contain both normal sub-steps and the erroneous action. The segmentation backbone (MS-TCN) is trained with smoothing cross-entropy on normal videos only, while GTG2Vid alignment and ERM are entirely training-free at inference.

## Results

On EgoPER (All tasks), GTG2Vid achieves 69.6% F1@.5, 65.3% Accuracy, and 73.9% Edit for temporal action segmentation, outperforming G2Vid (59.0/58.8/70.0) and EgoPED (56.4/59.0/54.5). On CaptainCook4D (All tasks), GTG2Vid reaches 27.6% F1@.5, 36.1% Accuracy, and 35.4% Edit, again surpassing both baselines. For error recognition, GTG2Vid achieves up to 31.7% w-F1@0 on EgoPER (Quesadilla) versus 7.5% for EgoPED(MV), and for error detection it reaches 33.0% F1@.5 on EgoPER All versus 22.5% for EgoPED.

## Baselines & Comparisons

Against G2Vid [19], GTG2Vid improves F1@.5 by 10.6 points on EgoPER (69.6 vs. 59.0) and by 3.9 points on CaptainCook4D (27.6 vs. 23.7), while Edit scores are comparable (73.9 vs. 70.0 on EgoPER; 35.4 vs. 36.6 on CaptainCook4D, a slight loss). Against EgoPED [41], GTG2Vid dominates across all TAS metrics: on EgoPER All it gains +13.2 F1@.5, +6.3 Acc, and +19.4 Edit; on CaptainCook4D All it gains +12.1 F1@.5, +7.2 Acc, and +15.1 Edit. For error recognition (Table 1), GTG2Vid substantially outperforms EgoPED(MV) on w-F1@0 across nearly all tasks (e.g., 31.7 vs. 7.5 on Quesadilla, 31.3 vs. 5.5 on Oatmeal), and achieves 100% EAcc on most EgoPER tasks versus 50–100% for EgoPED(MV). For error detection (Table 3), GTG2Vid achieves 33.0% F1@.5 on EgoPER All versus 22.5% for EgoPED, and 16.2% versus 10.5% on CaptainCook4D All, while maintaining a better balance between normal and error segment scores.

## Relation to Prior Work

This paper generalizes the G2Vid graph-to-video alignment framework (Dvornik et al., ECCV 2022) and its underlying Drop-DTW alignment (Dvornik et al., NeurIPS 2021) by introducing a Generalized Task Graph (GTG) that augments the standard task graph with background nodes and a node-dropping mechanism for omission errors. It departs from EgoPED (Lee et al., CVPR 2024), which handles error detection but not error type recognition, by adding an Error Recognition Module that leverages LLM-generated error descriptions and VLM-aligned features to classify error types without any error training videos. The key conceptual departure from prior task-graph-based segmentation is that GTG2Vid explicitly models background and error frames as distinct from correct steps, rather than forcing all frames onto task graph nodes.

## Why It Matters / Open Questions

The framework addresses a practical bottleneck for AR/VR task assistants: the infeasibility of collecting annotated error videos for every possible error type. The training-free error recognition pipeline (LLM descriptions → VLM features) is a reusable recipe that could extend to other procedural domains. However, absolute performance remains modest (w-F1@0 in the 10–30% range, TAS F1@.5 around 60–70% on EgoPER), and the method is validated on only two egocentric datasets with a limited number of tasks. Open questions include scalability to longer/more complex procedures, real-time inference cost of the multi-stage pipeline, and whether the LLM/VLM error feature approach generalizes to error types not explicitly prompted.

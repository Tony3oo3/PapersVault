## Problem

SAM 2 achieves state-of-the-art video object segmentation but is too computationally expensive for practical deployment: its HieraB+ image encoder carries ~80M parameters and the memory module's cross-attention operates over ~30K tokens, limiting the smallest SAM 2 variant to ~1 FPS on mobile devices. The paper asks whether a lightweight vanilla ViT encoder combined with a structurally efficient memory cross-attention can close the accuracy gap while enabling near real-time on-device track anything.
![Teaser figure](../imgs/ICCV20252610/cropped_page0_idx0.webp)

## Input / Output

The model consumes high-resolution video frames (1024×1024 for full-size models, 512×512 for the mobile variant) along with a prompt—either a ground-truth first-frame mask (semi-supervised VOS) or interactive point/box/mask prompts on arbitrary frames (promptable/interactive segmentation). The ViT encoder produces a single-scale 64×64 dense feature embedding per frame (16× spatial downsampling), and the memory module stores spatial tokens plus object pointer tokens from previously observed frames. Output is a per-frame binary segmentation mask for the tracked object, generated by a lightweight prompt-guided mask decoder that upsamples the single-scale features.

## Method

EfficientTAM replaces SAM 2's hierarchical HieraB+ encoder with a vanilla ViT-Tiny or ViT-Small (pretrained via EfficientSAM) that uses 14×14 non-overlapping windowed attention plus 4 equally-spaced global attention blocks to extract single-scale 64×64 frame features, eliminating the multi-scale feature pathway. The key architectural innovation is an efficient memory cross-attention that exploits the strong local smoothness of spatial memory tokens: a 2×2 average pooling is applied to spatial keys and values, reducing the cross-attention sequence length by 4×, and the pooled tokens are concatenated with the unmodified object pointer tokens. A log correction term ln(l_w × l_h) is added to the pooled spatial keys to rebalance attention scores between the coarser spatial tokens and the object pointer tokens, preventing attention collapse after pooling. The model is trained in two stages—90k steps on SA-1B without memory components, then 300k steps on SA-V plus 10% SA-1B with the full memory module—using focal+dice loss for masks, MAE for IoU prediction, and cross-entropy for object prediction.

## Results

On the standard semi-supervised VOS task, EfficientTAM-S (ViT-Small encoder) achieves 74.5 J&F on SA-V test, 73.4 on LVOS, and 89.2 on DAVIS 2017, matching SAM 2 (74.7 J&F on SA-V) within <2 J&F across all five video benchmarks while using only 34M parameters vs. 81M for SAM 2 and running at 100.4 FPS vs. 64.8 FPS on A100 (~1.6× speedup). The more efficient variant EfficientTAM-S/2 (with 2×2 window pooling in memory cross-attention) achieves 74.0 J&F on SA-V at 124.5 FPS on A100 and 450 ms latency on iPhone 15 Pro Max, compared to 1513.2 ms for SAM 2. The mobile-optimized EfficientTAM-Mobile (ViT-Tiny, 512×512 input) runs at ~28 FPS on iPhone 15 Pro Max for near real-time video segmentation, achieving 68.6 J&F on SA-V test.

## Baselines & Comparisons

EfficientTAM-S nearly matches SAM 2 on SA-V test (74.5 vs. 74.7 J&F) while being ~1.6× faster on A100 (100.4 vs. 64.8 FPS) and using ~2.4× fewer parameters (34M vs. 81M); the gap widens on LVOS (73.4 vs. 76.2) but narrows on DAVIS (89.2 vs. 88.9) and YTVOS (87.2 vs. 87.9). Against prior VOS methods, EfficientTAM-S outperforms Cutie-base by +12.9 J&F on SA-V (74.5 vs. 61.6), XMem by +14.4 J&F (74.5 vs. 60.1), and DEVA by +20.7 J&F (74.5 vs. 53.8), while also surpassing them in speed. The efficient-memory variant EfficientTAM-S/2 trades only 0.5 J&F on SA-V for a further ~1.2× speedup on A100 (124.5 vs. 100.4 FPS) and a 2.2× latency reduction on iPhone 15 (450 ms vs. 1010.8 ms). On the mobile deployment target, EfficientTAM-Mobile (~28 FPS on iPhone 15 Pro Max) outperforms EdgeTAM by 1.5 J&F on SA-V (68.6 vs. 67.1) while running ~1.8× faster on the same device. On the SA-23 image segmentation benchmark, EfficientTAM-S achieves 60.7 mIoU (1-click), surpassing SAM ViT-H (59.1) and approaching SAM 2 (61.9), with a ~20× speedup over SAM on A100.

## Relation to Prior Work

This paper extends SAM 2's architecture by replacing its parameter-heavy Hiera hierarchical encoder with vanilla ViT-Tiny/Small (following EfficientSAM's encoder design) and introducing an efficient cross-attention for the memory module that exploits the strong locality of spatial memory tokens via simple 2×2 average pooling. It departs from prior efficient-attention approaches (Linformer, Performer, linear attention) that the authors found underperform in the memory cross-attention context, instead leveraging the underlying token structure. The work is positioned as complementary to the concurrent EdgeTAM (which uses a CNN encoder and Perceiver), offering a ViT-based alternative with better accuracy-efficiency tradeoffs on both GPU and mobile hardware.

## Why It Matters / Open Questions

EfficientTAM makes near real-time video object segmentation practical on mobile devices (~28 FPS on iPhone 15 Pro Max), opening the door to on-device tracking applications that were previously infeasible with SAM 2 (~1 FPS). The finding that a trivial 2×2 average pooling on spatial memory tokens approximates full cross-attention with only 0.03 relative error suggests that memory-based video segmentation architectures may have more redundancy than previously assumed, potentially guiding future efficiency research. Limitations include a small but consistent accuracy gap versus SAM 2 (<2 J&F), and the locality assumption, while validated on dynamic benchmarks, may not hold universally for all motion patterns. Open questions include whether the approach extends to longer video sequences, multi-object tracking, or other memory-augmented architectures.

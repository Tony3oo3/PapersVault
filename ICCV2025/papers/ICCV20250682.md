## Problem

Existing 3D outdoor scene generation methods either lack user control (unconditional diffusion) or rely on non-intuitive control formats such as pixel-level BEV layouts or free-form text that cannot precisely enforce object counts, spatial positions, or road topology. No prior work has demonstrated controllable large-scale 3D outdoor scene generation conditioned on a structured, editable representation that is both intuitive for users and rich enough to capture scene composition.
![Teaser figure](../imgs/ICCV20250682/cropped_page0_idx0.webp)

## Input / Output

The method consumes a sparse scene graph where each instance node carries only a semantic label and an approximate 2D position encoded as a patch index, plus a singleton road node specifying one of five road types (Straight, T-Junction, Crossroad, Bend, Others). The output is a discrete 3D semantic grid of shape H×W×D×c with per-voxel class assignments. Scene graphs can be authored interactively or generated from natural-language prompts via an LLM, and the system supports partial specifications (e.g., missing positions) through feature masking during training.

## Method

The core pipeline is a sparse-to-dense cascade: a two-layer GAT encodes the scene graph into Context-aware Node Embeddings (CANE) by concatenating per-node attention outputs with a global mean-pooled embedding, then an Allocation Module places each node embedding at a sampled 2D position (via Gumbel-Softmax from a learned localization head) to form a dense BEV Embedding Map. A 2D discrete diffusion model (3D-UNet backbone) refines the sparse BEM into a dense 2D semantic map, which conditions a 3D discrete diffusion model to produce the final volumetric scene. The GNN and 2D diffusion are jointly trained with auxiliary edge-reconstruction and node-classification losses that improve structural understanding, while the 3D diffusion is trained separately conditioned on the 2D map. This joint-training strategy, validated against four ablation configurations, yields the best alignment between generated object quantities/road types and the input scene graph.

## Results

On the CarlaSG test set (1k scene graphs), the proposed method achieves mIoU 68.69 and MA 85.01 for scene quality, comparable to the unconditional baseline (mIoU 68.21) and the LLM-conditioned baseline (mIoU 68.19). For control capacity, the method achieves a MAE of 0.63 and Jaccard Index of 0.93, substantially outperforming all baselines (next best: SG2Im at MAE 0.97, Jaccard 0.81). Per-category MAE values are also the lowest across Pole (1.39), Pedestrian (1.81), and Vehicle (1.35), confirming precise object-quantity control.

## Baselines & Comparisons

Against the unconditional generation baseline (Uncon-Gen [35]), the proposed method matches scene quality (mIoU 68.69 vs. 68.21) while dramatically improving control: MAE drops from 2.07 to 0.63 and Jaccard rises from 0.68 to 0.93, showing that scene-graph conditioning adds precise structural control without sacrificing generation fidelity. Compared to SG2Im [18] (a GAN-based scene-graph-to-image method adapted for BEM generation), the proposed method wins on both scene quality (mIoU 68.69 vs. 65.43, F3D 0.393 vs. 0.486) and control capacity (MAE 0.63 vs. 0.97, Jaccard 0.93 vs. 0.81), indicating that the GNN + diffusion pipeline captures scene structure more faithfully than a GAN-based image synthesis approach. Versus the LLM text-embedding baseline [61,67], the proposed method achieves comparable scene quality (mIoU 68.69 vs. 68.19) but a clear control advantage (MAE 0.63 vs. 1.44, Jaccard 0.93 vs. 0.70), demonstrating that explicit scene-graph structure provides more precise spatial and quantitative control than implicit text embeddings. A user study (DMOS with 20 subjects, 100 scene pairs) further confirms the advantage, with the null hypothesis of no improvement rejected at p < 10⁻³.

## Relation to Prior Work

This paper builds on the discrete-state diffusion framework of Austin et al. (NeurIPS 2021) and the 3D Pyramid Discrete Diffusion architecture of Liu et al. (ECCV 2024) as its generative backbone, but introduces a fundamentally new conditioning pathway: a GNN with a novel Allocation Module that converts sparse scene graphs into dense BEV Embedding Maps. It departs from text-based control (Text2LiDAR) and pixel-level BEV layout control by proposing scene graphs as an intermediate, user-editable representation, extending the indoor scene-graph generation paradigm (Graph-to-3D, 3D Scene Graph) to the unbounded, large-scale outdoor setting where compositional bounding-box approaches fail. The joint training of the GNN and diffusion model with auxiliary edge-reconstruction and node-classification losses is a new architectural choice not present in prior scene-graph-to-3D work.

## Why It Matters / Open Questions

This is the first framework to enable structured, user-controllable generation of large-scale 3D outdoor semantic scenes via scene graphs, filling a gap between text-to-3D (imprecise) and pixel-level layout control (impractical for large scenes). The CarlaSG dataset and interactive system lower the barrier for applications in autonomous driving simulation and urban planning. However, the method is limited to semantic (textureless) scenes derived from CarlaSC, uses a simplified scene graph (labels + approximate 2D positions + road type), and has not been validated on real-world LiDAR data or with richer relational structures. Open questions include whether the approach generalizes to real sensor data, whether appearance/texture can be added, and whether more complex scene graph topologies (e.g., multi-road networks, hierarchical containment) can be supported.

## Problem

Existing video token reduction methods for Large Vision-Language Models rely solely on importance-based pruning (e.g., cumulative attention scores), yet even the top-ranked important tokens exhibit high redundancy due to visual similarity across adjacent frames. Token similarity as a complementary, perpendicular axis to importance has remained under-investigated, and no prior method systematically combines similarity-based merging with importance-based pruning to reduce visual tokens.

## Input / Output

FrameFusion operates as a plug-and-play, post-training inference accelerator on standard video LVLMs: it receives video frames (8–256 frames, each divided into image patches yielding ~210 visual tokens per frame) and a text instruction, and produces a text response. The user specifies a relative token budget C (default 30%), which defines the maximum KV-Cache sequence length at the start of decoding; all compression happens inside the LLM layers without re-encoding or retraining the visual encoder.

## Method

FrameFusion is a two-stage token compression pipeline. In the merging stage, at successive shallow LLM layers, it computes cosine similarity only between spatially corresponding visual tokens from adjacent frames (O(N) rather than O(N²)), groups tokens exceeding a similarity threshold via transitive merging, and replaces each group with an element-wise average assigned to the earliest token position. This cascaded merging permanently reduces the token count for all subsequent layers. In the pruning stage, at deeper layers, it applies top-k importance pruning using cumulative attention scores to meet the user-specified token budget. Three empirical observations drive the design: (1) spatially corresponding adjacent-frame tokens show the highest similarity, (2) high similarity values concentrate in shallow layers, and (3) similarity rankings are far more consistent across layers than importance rankings, justifying permanent cascaded merging at shallow layers followed by importance pruning at deeper layers.

## Results

At a 30% relative token budget, FrameFusion achieves an average score of 64.8 on Llava-Video-7B (vs. 65.9 for the dense model), a drop of only 1.7%, while StreamingLLM, FastV, and PruMerge drop to 44.6, 57.9, and 60.9 respectively. Across all six models (2B–72B), FrameFusion's maximum relative average performance drop is 2.4%, compared to 35.8%, 19.7%, and 15.4% for the three baselines. On the VideoNIAH retrieval benchmark, FrameFusion's maximum relative drop is just 2.8%, versus 38.7–69.5% for baselines. End-to-end speedups range from 1.6× to 3.6× with 70% visual token reduction.

## Baselines & Comparisons

FrameFusion consistently outperforms all three baselines across every model size and benchmark. Against StreamingLLM [31], which retains only a fixed window of recent tokens plus attention sinks, FrameFusion achieves 20–25 points higher average scores (e.g., 64.8 vs. 44.6 on Llava-Video-7B), as StreamingLLM's static window discards critical early-frame information. Against FastV [3], which prunes visual tokens based on cumulative attention scores after layer 2, FrameFusion gains 6.9–20.5 points on average (e.g., 64.8 vs. 57.9 on 7B; 70.0 vs. 58.6 on 72B), because FastV's importance-only criterion retains redundant tokens that are important but visually similar. Against PruMerge [25], which merges tokens within a single frame based on feature similarity, FrameFusion leads by 3.9–21.2 points (e.g., 64.8 vs. 60.9 on 7B; 70.0 vs. 67.3 on 72B), with the gap widening on smaller models where PruMerge's within-frame merging misses cross-frame redundancy. Notably, on NVILA-8B, PruMerge collapses to 4.7 on VideoNIAH-edit while FrameFusion maintains 96.0, highlighting the fragility of importance-only pruning on retrieval tasks.

## Relation to Prior Work

FrameFusion extends the line of importance-based visual token pruning in LLM layers (FastV, H2O) by introducing a perpendicular axis: inter-frame token similarity. While prior methods assume that pruning the least-important tokens suffices, this paper demonstrates that even top-ranked important tokens exhibit substantial redundancy (55% of top-10% tokens have cosine similarity >0.9), motivating a preceding similarity-based merging stage. The method is positioned as a post-training, plug-and-play approach that operates entirely within the LLM, distinguishing it from encoder-side compression (Llama-VID, MA-LMM) and input-level sampling strategies. The cascaded merging design draws on the empirical finding that similarity rankings are stable across layers, unlike importance rankings, which justifies permanent token reduction rather than per-layer re-evaluation.

## Why It Matters / Open Questions

The 70% token reduction with under 3% average performance drop across six model families (2B–72B) and five benchmarks makes this a practically deployable technique for long-video understanding, where token counts can reach one million. The systematic characterization of token similarity (spatial correspondence, layer-dependent decay, cross-layer ranking consistency) provides reusable empirical insights for future compression work. Limitations include evaluation on a fixed set of model architectures, the method's dependence on a predefined similarity threshold, and the fact that it is purely inference-time with no task-specific adaptation. Open questions include interaction with other efficiency techniques (quantization, speculative decoding), applicability to image-only LVLMs, and behavior at extreme video lengths beyond 256 frames.

## Problem

Existing self-supervised pretraining methods for event cameras mimic RGB image-based approaches, pre-training feedforward models on short event intervals and ignoring long-term temporal structure. Although recurrent models consistently outperform feedforward ones in event vision tasks, no SSL framework existed to pre-train them with explicit long-term temporal awareness. TESPEC addresses this gap as the first event-based SSL framework designed for recurrent architectures with a temporally-aware reconstruction objective.

## Input / Output

The method consumes raw asynchronous event streams (x, y, t, polarity) from event cameras, converting them into sequences of event histogram stages of shape (2B, H, W) with B=10 temporal bins per 50 ms segment. Pre-training uses the 1Mpx dataset at 720×1280 resolution (~15 hours of outdoor driving), and the backbone is trained on minute-long sequences by sequentially resuming the estimated intensity video across consecutive training steps. The output is a pretrained recurrent Swin-T/7 backbone (with ConvLSTM cells after each stage) that, after discarding the decoder, accepts a task-specific head (YOLOX, UperNet, or MiDaS) for fine-tuning on detection, segmentation, or depth estimation.

## Method

TESPEC follows the MAE paradigm with tube masking (same spatial patches masked across all time steps) applied to event histogram sequences, fed sequentially into a recurrent Swin-T/7 encoder with ConvLSTM memory cells. The key novelty is the reconstruction target: instead of reconstructing sparse raw events, the model reconstructs a pseudo-grayscale video estimated via a novel global intensity update rule (Eq. 7) that decays ALL pixels at each temporal bin based on the total event count n across the frame, rather than updating only pixels receiving new events. This global update eliminates the motion blur inherent in per-pixel intensity estimation (Eq. 6) and suppresses sensor noise, while the n-dependent decay ensures static scenes retain their state. A lightweight feedforward decoder (single Swin block, no recurrency) reconstructs the intensity video at masked patches, forcing the recurrent encoder to learn spatio-temporal interactions. The MSE loss is computed over masked patches across all M stages, and the entire pipeline is trained for 400k steps with 50% masking ratio, α=5, and N=5000.

## Results

TESPEC achieves state-of-the-art results across three downstream tasks. On object detection, it reaches 51.6 mAP on Gen1 and 50.6 mAP on 1Mpx, surpassing the best prior method FCCO (50.4/40.6) and the previous event-SSL SOTA ECDDP (49.6/50.0). On semantic segmentation, TESPEC attains 62.77 mIoU on DSEC and 65.19 mIoU on DDD17, outperforming ECDDP by 1.52 and 2.28 mIoU respectively. On monocular depth estimation (MVSEC), it achieves δ₁=0.634, beating all event-only methods and approaching PCDepth (δ₁=0.672) which additionally uses RGB images.

## Baselines & Comparisons

TESPEC outperforms all event-based SSL baselines (ECDDP, ECDP) and RGB SSL baselines (MoBY) across all three downstream tasks. On object detection, TESPEC beats the strongest event-SSL method ECDDP by 2.0 mAP on Gen1 and 0.6 mAP on 1Mpx, and surpasses the best supervised method FCCO by 1.2 mAP on Gen1 and 10.0 mAP on 1Mpx despite using a 30% smaller model. On semantic segmentation, TESPEC improves over ECDDP by 1.52 mIoU on DSEC and 2.28 mIoU on DDD17, while also outperforming the task-specific recurrent method ESS by 9.48 mIoU on DSEC. On depth estimation, TESPEC exceeds HMNet by 4.6% in δ₁ and all ECDDP variants, though it trails PCDepth (δ₁=0.672 vs 0.634) which leverages an additional RGB image input modality. A consistent finding across all tasks is that recurrent architectures with TESPEC pre-training substantially outperform their feedforward counterparts, confirming the value of long-term temporal modeling.

## Relation to Prior Work

TESPEC extends the MAE/VideoMAE masked autoencoding paradigm to event camera data, adopting tube masking from VideoMAE and the asymmetric encoder-decoder architecture from MAE. It departs from prior event SSL methods (ECDP, MEM, ECDDP) in two key ways: (1) it pretrains recurrent backbones on long event sequences rather than feedforward models on short event frames, and (2) it replaces raw event reconstruction with an improved intensity video target derived from a global-batch generalization of Scheerlinck et al.'s per-pixel intensity estimation. This positions TESPEC as the first event SSL framework explicitly designed to learn long-term temporal information in recurrent architectures.

## Why It Matters / Open Questions

TESPEC addresses a clear gap in event-based vision: prior SSL methods ignored the temporal dimension that makes event data distinctive, limiting their utility for tasks requiring long-horizon memory. By demonstrating that a pure event-based pretraining objective (no paired video data needed) can outperform both RGB SSL and prior event SSL across detection, segmentation, and depth estimation, it provides a practical recipe for training strong recurrent event backbones. Open questions include whether the approach generalizes to indoor or low-motion scenarios where event rates are much lower, and whether the intensity video target can be further refined to capture higher-level semantics beyond grayscale appearance.

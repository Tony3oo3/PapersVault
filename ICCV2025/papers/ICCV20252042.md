## Problem

Existing 3D scene graph methods that rely solely on multi-view RGB images suffer from background noise in node features (due to bounding-box-based aggregation) and lack any explicit mechanism to correct initial misclassifications, particularly for rare or low-confidence object and predicate classes. Without ground-truth 3D geometry for error correction, there is no way to refine predictions beyond implicit node-edge interactions learned during training.
![Teaser figure](../imgs/ICCV20252042/cropped_page0_idx0.webp)

## Input / Output

The method takes N multi-view RGB images of a 3D scene as input and produces a 3D semantic scene graph structured as triplets {object_class, predicate_class, object_class} over 20 NYU object classes and 8 predicate classes. Depth is estimated via Depth Anything and 3D geometry is recovered through RGB-D SLAM, while object proposals are derived from SAM segmentation masks (text-prompted with the 20-class set) rather than entity detector bounding boxes. All predictions are mapped onto ground-truth segments for evaluation.

## Method

The framework has three components. First, Masked Feature Initialization (MFI) aggregates multi-view DINOv2 ViT-L image features using SAM semantic masks (element-wise multiplication before averaging across the covisibility graph) to eliminate background distractors, and fuses PointNet geometric features and a linear spatial feature via learnable sigmoid gates. Second, the Residual Spatial Neighbor GNN (RSN-GNN) augments edge messages with max-pooled neighboring node features through a residual connection, encoding spatial context into edge representations while deliberately excluding this from node updates to avoid noise propagation. Third, the Confidence Rescoring (CR) module refines final logits by blending the model's softmax output with inverse-softmax-weighted node-to-node and node-to-edge co-occurrence statistics from the training set, where the blending weight is the model's own max-class confidence—so low-confidence predictions receive stronger prior correction, particularly benefiting rare and tail classes.

## Results

On the 3RScan dataset (20 object classes, 8 predicate classes), the proposed method with DINOv2 features achieves 40.5% relationship Recall, 61.8% object Recall, 90.4% predicate Recall, 60.5% object mRecall, and 39.2% predicate mRecall. The method is the only approach achieving non-zero recall on all 20 object classes, and it substantially outperforms the strongest baseline (JointSSG with DINOv2) by +6.2 points on relationship Recall and +7.6 points on object mRecall. Even with the weaker ResNet18 backbone, the method surpasses all baselines on relationship and object Recall, demonstrating that the architectural contributions (MFI, RSN-GNN, CR) drive the gains rather than the feature extractor alone.

## Baselines & Comparisons

Against 3DSSG [28], the proposed method achieves a large margin on every metric: +27.5 points on relationship Recall (40.5 vs 13.0), +26.2 on object Recall (61.8 vs 35.6), and +34.5 on object mRecall (60.5 vs 26.0), reflecting the advantage of multi-view RGB with learned features over the original point-cloud-based approach. Against SGFN [31], the method wins on all five metrics, with the largest gap on object mRecall (+24.6 points, 60.5 vs 35.9) and predicate mRecall (+12.1 points, 39.2 vs 27.1), indicating substantially better handling of class imbalance. Against JointSSG [32] (the closest competitor and architectural foundation), the method improves relationship Recall by +7.6 points (40.5 vs 32.9), object Recall by +7.3 points (61.8 vs 54.5), and object mRecall by +15.1 points (60.5 vs 45.4). Even when JointSSG is upgraded to DINOv2 features (JointSSG‡), the proposed method still leads by +6.2 on relationship Recall and +7.6 on object mRecall, confirming that the gains come from the MFI, RSN-GNN, and CR modules rather than the backbone. The per-class analysis (Table 1) further shows the method is the only one with non-zero recall across all 20 object classes, particularly excelling on rare classes like bookshelf (0.333 vs 0.000 for all baselines) and refrigerator (0.667 vs 0.000).

## Relation to Prior Work

This paper builds directly on JointSSG [32], reusing its GCN architecture, geometric gate, and edge descriptor formulation, while replacing the bounding-box-based feature extraction with SAM-guided masked feature aggregation (similar in spirit to ConceptGraphs [10]). Its most distinctive contribution—the Confidence Rescoring module—imports the statistical co-occurrence prior idea well established in 2D scene graph generation (KERN [4], Schemata [24], Neural Motifs [40]) into the 3D multi-view setting, where no prior method had applied explicit summary-statistic refinement to node and edge logits. The RSN-GNN's max-pooled neighbor residual is a modest architectural addition inspired by ResNet-style skip connections, applied selectively to edge messages rather than node updates.

## Why It Matters / Open Questions

The CR module offers a lightweight, training-free post-hoc refinement that directly targets the class-imbalance problem plaguing 3D scene graph generation, and the finding that it lifts predicate mRecall by ~3.5 points while barely affecting top-1 predicate Recall suggests it specifically rescues rare-class predictions without distorting majority-class performance. However, the approach is evaluated only on 3RScan, and the authors acknowledge that statistical priors can hurt performance under domain shift or with very limited training data, leaving open whether the method generalizes to larger or more diverse 3D scene datasets. The reliance on SAM mask quality for feature initialization also introduces a dependency on segmentation accuracy that could degrade in cluttered or occluded scenes.

## Problem

Visual GUI agents struggle with high-resolution interfaces where information is unevenly distributed—dense UI clusters coexist with large empty regions—causing models to either lose fine-grained detail or waste compute on irrelevant areas. Additionally, training annotations are biased toward large, visually prominent elements with simple functions, leaving small but interaction-critical components underrepresented and poorly understood.
![Teaser figure](../imgs/ICCV20251037/cropped_page0_idx0.webp)

## Input / Output

Iris takes a high-resolution GUI screenshot (e.g., 1920×1080) and either a text description (grounding) or a bounding box position (referring) as input. The ISC module first produces a binary edge-detection matrix, then extracts variable-sized sub-images from information-dense regions and resizes each to 224×224 for the visual encoder, alongside a downscaled full image for global context. Outputs are bounding box coordinates (x₁, y₁, x₂, y₂) for grounding or natural-language UI element descriptions for referring; during SRDL, the system also emits self-annotated (description, position) pairs once iterative IoU convergence is reached.

## Method

Iris builds on Qwen-VL and introduces two complementary mechanisms. Information-Sensitive Cropping (ISC) applies Canny edge detection to produce a binary information matrix, then uses a multi-scale sliding window (expanding by factor α from k_min) to extract regions whose edge density exceeds a scale-dependent threshold ρ_min/(k_t/k_min)², allocating more visual tokens to dense areas and fewer to sparse ones—yielding a 300% efficiency gain. Self-Refining Dual Learning (SRDL) creates a feedback loop where the model alternates between referring (generating a description from a position) and grounding (locating an element from a description), iterating until the IoU between successive position predictions exceeds a threshold τ; converged samples become self-annotations. Two hard-case mining strategies target weaknesses: visual mining selects images with high spectral entropy (computed via 2D DFT of the edge matrix, threshold H_min=12), and functional mining uses the internal LLM to generate paraphrased descriptions of elements the model previously mis-grounded. After initial supervised training on 850K GUI annotations plus 150K LLaVA instructions, an SRDL stage trains on ~3M self-generated samples, achieving 74.6% on ScreenSpot with the same annotation budget as SeeClick (53.4%) and matching UGround (73.3%) which uses 10× more data.

## Results

On the ScreenSpot benchmark, Iris achieves 74.6% average grounding accuracy using only 850K GUI annotations, outperforming SeeClick (53.4%) by 21.2 points with identical training data and surpassing UGround (73.3%) which uses 10× more annotations (10M). On GroundUI-1K, Iris reaches 71.3% total accuracy versus SeeClick's 61.1% and Gemini-1.5's 35.2%. Downstream agent tasks show consistent gains: on Mind2Web, Iris improves Step Success Rate from 25.5% to 32.0% (Cross-Task) over SeeClick, and on AITW, overall score rises from 59.3% to 63.6% with Click Accuracy from 66.4% to 71.0%.

## Baselines & Comparisons

Iris decisively outperforms SeeClick [9] (its direct baseline with identical 850K training data) across all four benchmarks: ScreenSpot 74.6% vs 53.4%, GroundUI 71.3% vs 61.1%, Mind2Web Step SR 32.0% vs 25.5% (Cross-Task), and AITW 63.6% vs 59.3%. Against UGround [13], which uses 10× more annotations (10M vs 850K), Iris achieves higher average ScreenSpot accuracy (74.6% vs 73.3%) while processing 3× faster. All general-purpose MLLMs are far behind: GPT-4o [2] scores only 18.3% on ScreenSpot, Gemini-1.5 [26] reaches 35.2% on GroundUI, and CogAgent [15] (140M annotations) manages 47.4% on ScreenSpot. Smaller or earlier models (MiniGPT-v2 [8], Fuyu [5], PaliGemma [6], MiniCPM [16], CogVLM2 [14], Qwen-VL [4]) score below 20% on ScreenSpot or near 0% on GroundUI. On agent benchmarks, Iris also surpasses text-based baselines (PaLM2-CoT [24] at 39.6% and ChatGPT-CoT [36] at 7.7% on AITW) and the MindAct [11] web agent (52.0% Step SR Cross-Task vs Iris's 32.0% in the w/o HTML setting, where Iris is the strongest pure-GUI model). The one category where Iris does not lead is Desktop Icon/Widget on ScreenSpot (57.5% vs UGround's 63.6%), suggesting residual difficulty with small desktop icons despite ISC's adaptive cropping.

## Relation to Prior Work

Iris builds directly on SeeClick's framework for GUI grounding with MLLMs and Qwen-VL as the base architecture, adding two orthogonal enhancements: Information-Sensitive Cropping (ISC) for adaptive visual processing and Self-Refining Dual Learning (SRDL) for annotation-free self-improvement. Conceptually, ISC departs from prior high-resolution MLLM approaches (AnyRes, Qwen2-VL) that treat all image regions uniformly, instead leveraging Canny edge detection to allocate tokens proportionally to information density. SRDL introduces a self-play loop exploiting the duality between referring and grounding, which is a departure from the purely supervised training paradigm used by SeeClick and UGround, and from the grid-based or fixed-resolution strategies in prior MLLM work.

## Why It Matters / Open Questions

The practical significance lies in demonstrating that a 300% inference speedup (3s→1s) and competitive accuracy can be achieved with 10× less annotated data than UGround, making high-quality GUI agents more accessible. However, the '850K annotations' claim is somewhat softened by the additional ~3M self-annotated samples generated via SRDL, and the spectral entropy threshold (H_min=12) and convergence threshold (τ) appear hand-tuned. Open questions include whether the dual-learning loop generalizes beyond GUI to other structured visual domains, whether self-annotation quality degrades as the model's initial capability is limited, and whether ISC's edge-detection heuristic holds for GUIs with soft boundaries or gradient-based designs.

## Problem

Existing 3D feature field methods (e.g., Feature-3DGS, LangSplat) jointly optimize semantic features alongside photometric color, forcing the scene to retain an excessive number of Gaussians to recover color details that are irrelevant to the feature field. Additionally, these methods rely on raw 2D foundation-model features that suffer from multi-view inconsistency, and they store high-dimensional embeddings per Gaussian, incurring large storage and computational costs.
![Teaser figure](../imgs/ICCV20250697/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained 3DGS scene (30k iterations) and multi-view 2D feature maps from a visual foundation model (CLIP+SAM, LSeg, or MaskCLIP) as input. It produces a compact 3D feature field where each Gaussian stores a 3-dimensional latent code directly in the RGB channels of the 3DGS representation, making it natively compatible with the standard 3DGS rasterizer. At query time, a text prompt is matched against the decoded per-Gaussian features to yield open-vocabulary segmentation masks or 3D segmentation results.

## Method

CF³ operates in three stages. First, feature lifting performs a training-free weighted fusion of multi-view 2D features onto pre-trained Gaussians using their rendering weights, producing spatially coherent and view-consistent reference features; a variance filtering step then discards Gaussians whose feature variance exceeds the top 0.01% threshold. Second, a per-Gaussian autoencoder (5-layer MLP compressing D-dim features to a 3-dim latent) is trained directly on the lifted features with MSE, cosine-similarity, and structure-preserving losses, so the encoder aligns with the actual 3D feature distribution rather than raw 2D features. Third, adaptive sparsification iteratively prunes low-contribution Gaussians and merges overlapping neighbors (identified via Mahalanobis distance and feature similarity) using moment-matching to compute merged attributes, while optimizing Gaussian parameters with a rendered-feature L1 loss plus depth regularization against the frozen reference field. This pipeline reduces the Gaussian count to as little as 5% of the original while maintaining competitive segmentation accuracy.

## Results

On the Replica dataset with LSeg features, CF³ achieves 70.8 mIoU and 91.6% accuracy using only 47k Gaussians (3.6 MB storage, 328.3 FPS), compared to Feature-3DGS(128) which uses 640k Gaussians (463.9 MB, 113.8 FPS) for 73.4 mIoU. On the LERF dataset with CLIP+SAM, CF³ reaches 52.4 mIoU at 145.0 FPS with 55k Gaussians (4.2 MB), outperforming LangSplat (44.7 mIoU, 1270k Gaussians, 314.9 MB). On the 3D-OVS dataset, CF³ achieves the best mIoU of 84.5 while being 49× more compact than LangSplat and 179× more compact than Feature-3DGS(128). The method uses as little as 5% of the original Gaussians while maintaining competitive segmentation quality.

## Baselines & Comparisons

Against Feature-3DGS, CF³ trades a small mIoU drop (70.8 vs. 73.4 on Replica-LSeg; 52.4 vs. 53.8 on LERF-CLIP+SAM) for a 121×–245× reduction in storage and a 3×–2.9× speedup in rendering FPS, while using only ~7% of the Gaussians. Against LangSplat, CF³ wins on both quality and efficiency: it achieves higher mIoU (52.4 vs. 44.7 on LERF; 84.5 vs. 81.9 on 3D-OVS) while being 74× and 49× more compact respectively, and rendering 4.3× and 5.1× faster. Against the feature-lifting baselines (3DGS* and LightGaussian*), CF³ matches or slightly exceeds mIoU (70.8 vs. 70.1/70.0) while reducing storage by 371× and 127× respectively. Notably, on the 3D-OVS dataset CF³ achieves the highest mIoU (84.5) among all methods, surpassing even the full-size 3DGS* baseline (82.8), demonstrating that the per-Gaussian autoencoder trained on lifted features preserves semantic fidelity better than 2D-domain compression.

## Relation to Prior Work

This paper departs from the bottom-up optimization paradigm of Feature-3DGS and LangSplat, which jointly train 3D feature embeddings with color via photometric-style losses, by proposing a top-down pipeline: first lifting 2D foundation-model features into 3D via weighted multi-view fusion (similar to training-free methods like Occam's LGS and Ludvig), then compressing with a per-Gaussian autoencoder trained directly on the lifted features. The key architectural departure is storing the compressed feature as a 3-dimensional latent in the RGB channels of 3DGS, making the feature field directly compatible with the standard 3DGS rasterizer without auxiliary decoders or hash grids. The adaptive sparsification step (pruning via global contribution and merging via moment matching) extends LightGaussian's compression ideas from color fields to feature fields, exploiting the observation that feature fields require far fewer Gaussians than color fields.

## Why It Matters / Open Questions

The 121×–245× storage reduction while maintaining competitive mIoU across four datasets and three feature types (LSeg, CLIP+SAM, MaskCLIP) makes 3D feature fields practical for large-scale and real-time applications, as demonstrated on KITTI-360. The design of encoding features into 3 RGB channels is a pragmatic choice that eliminates the need for separate feature storage or custom rasterization, lowering the barrier to adoption. A key limitation is the ~30-minute per-scene pipeline cost from autoencoder training and sparsification, which the authors acknowledge needs acceleration. Open questions include whether the 3-dim latent bottleneck generalizes to tasks requiring finer-grained feature discrimination (e.g., instance-level segmentation) and whether the sparsification strategy transfers to dynamic or unposed settings.

## Problem

Existing dynamic scene reconstruction methods use a unified Gaussian representation to model both static background and dynamic objects, but this paradigm fails in high-dynamic scenes due to two compounding issues: frame camera's long exposure and low frame rate cause temporal feature discontinuity for fast-moving objects, and the rigid spatial features of the background are fundamentally heterogeneous from the deformed spatiotemporal features of dynamic objects. This spatiotemporal feature mismatch degrades reconstruction quality as motion intensity increases.

## Input / Output

The method consumes pixel-aligned frame images and asynchronous event streams (from a neuromorphic sensor) as paired multimodal input. Frame images are segmented into superpixel patches for spatial appearance features, while event streams are processed into correlation volumes for temporal motion features. The output is a novel-view rendered image at an arbitrary timestamp, produced by fusing 3D Gaussians (background) and 4D Gaussians (objects) via shadow-weighted alpha-blending. The authors also introduce the CoFED dataset (1200×624 resolution) collected with a custom optical coaxial device for pixel-aligned frame-event capture.

## Method

STD-GS proposes a cumulative scene-to-object disentanglement pipeline within a Gaussian splatting framework. In the Dynamic Scene Disentanglement stage, a learnable appearance-motion clustering network (ClusterFormer) is guided by K-Means pseudo-labels derived from frame superpixels (spatial) and event correlation volumes (temporal) to separate background from objects. In the Gaussian Representation Fusion stage, the background is represented as 3D Gaussians while dynamic objects become 4D Gaussians centered on EKF-tracked points from event data; a spatiotemporal consistency loss constrains Gaussian color to integrated event brightness and Gaussian deformation to interpolated event flow. An MLP learns shadow-based overlap weights to fuse background and object Gaussians for rendering. Training proceeds in two phases: first optimizing reconstruction loss for scene initialization, then jointly optimizing clustering and consistency losses for disentanglement and object fine-tuning.

## Results

On the proposed CoFED dataset (high-dynamic setting), STD-GS achieves PSNR 27.68, SSIM 0.87, and LPIPS 0.26, outperforming the best unified dynamic baseline Ex4DGS (PSNR 25.38, SSIM 0.79, LPIPS 0.33) by 2.3 dB in PSNR. On the public HD-CED dataset, the method reaches PSNR 27.12 and SSIM 0.88, surpassing the strongest frame-only dynamic baseline 4DGS w/ Deblur (PSNR 21.58, SSIM 0.69) by over 5.5 dB. In low-dynamic scenes, STD-GS (PSNR 31.42) still leads all baselines, with the gap over Ex4DGS (PSNR 30.65) narrowing to 0.77 dB, confirming that the event-assisted disentanglement is most beneficial under high motion.

## Baselines & Comparisons

STD-GS outperforms all 11 baselines on both low- and high-dynamic settings of CoFED. Among unified dynamic representation methods, Ex4DGS is the strongest frame-only baseline (PSNR 25.38 high-dynamic), but STD-GS exceeds it by 2.3 dB, with the gap widening to 3.9 dB over 4DGS and 4.5 dB over TiNeuVox. Static reconstruction methods (3DGS, E2GS, IncEventGS, EvGGS) are consistently 5–8 dB below the dynamic methods, confirming that explicit temporal modeling is essential for high-dynamic scenes. Notably, event-only methods (IncEventGS, EvGGS) underperform frame-only 3DGS in high-dynamic settings, showing that events alone cannot compensate for the lack of dense spatial appearance. The advantage of STD-GS over the best frame-only dynamic method (Ex4DGS) grows from 0.77 dB in low-dynamic to 2.3 dB in high-dynamic, validating that the event-assisted spatiotemporal disentanglement becomes increasingly critical as motion intensity increases. On the public HD-CED dataset (Table 1), STD-GS achieves PSNR 27.12 vs. 21.58 for 4DGS w/ Deblur, a 5.5 dB margin, further confirming generalizability beyond the authors' own dataset.

## Relation to Prior Work

This paper extends the 3D Gaussian Splatting rendering pipeline by introducing a spatiotemporal-disentangled representation that separates static background (3D Gaussians) from dynamic objects (4D Gaussians), departing from prior unified-representation methods like 4DGS and SpacetimeGS that model all scene content with the same Gaussian form. It builds on ClusterFormer for the appearance-motion clustering module and on GEM-style event-based deblurring for texture restoration, but goes beyond prior frame-event methods (E2GS, E2NeRF) that use events only for pixel-level correction by leveraging event data as a structural prior for temporal motion features and spatiotemporal consistency constraints. The cumulative scene-to-object disentanglement pipeline—first separating background from objects via frame-event clustering, then constraining object Gaussians via event-Gaussian consistency—represents a new architectural decomposition not present in prior dynamic Gaussian splatting work.

## Why It Matters / Open Questions

The paper addresses a practically important gap: high-dynamic scenes where frame cameras produce motion blur and temporal discontinuity, a regime where existing dynamic reconstruction methods degrade significantly. The introduced CoFED dataset (pixel-aligned frame-event data at 1200×624) fills a notable resource gap, as no prior high-resolution real frame-event dataset existed for this task. However, the method's applicability is constrained by the need for co-located frame and event cameras, and the authors acknowledge a fundamental limitation for radial (z-axis) motion where both sensors become ineffective. Open questions include whether the disentanglement framework generalizes to multi-object scenes with occlusion, whether the EKF-based tracking scales to very fast deformations, and whether the approach can be extended with depth sensors (e.g., LiDAR) to handle the acknowledged z-axis blind spot.

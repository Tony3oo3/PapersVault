## Problem

Existing road anomaly detection methods rely on pixel-level uncertainty from segmentation models, which inherently produces high uncertainty at object boundaries, leading to scattered false positives that no threshold can fully eliminate. Additionally, the absence of object-level understanding makes it impractical to select a stable binarization threshold, and frame-to-frame prediction inconsistencies further complicate deployment in autonomous driving systems.
![Teaser figure](../imgs/ICCV20250470/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB road scene images (or consecutive video frames) along with 19 Cityscapes ID category names as text prompts and a learnable universal token. It outputs OoD bounding boxes with objectness scores (threshold τ=0.2), which either suppress anomaly scores outside detected regions to refine existing score maps (DetSeg-R) or serve as box prompts to SAM for direct binary mask generation without threshold search (DetSeg-S). For video inputs, vanishing point geometry from lane detection provides the spatial prior for temporal matching.

## Method

DetSeg adopts a detect-all-then-suppress paradigm built on Grounding DINO: a dual-query design pairs ID category queries with 300 universal (UN) queries, where attention masks prevent information leakage between the two query groups so that UN queries attend to all objects while ID queries remain category-specific. An objectness discrimination head filters background proposals, and the IE-NMS module boosts classification scores of confidently matched ID boxes (calibrated via a Cityscapes subset) so that during NMS, ID boxes from ID queries are preserved while overlapping UN boxes on the same objects are suppressed, leaving only OoD detections. Training freezes most parameters and fine-tunes only the universal token, UN queries, box regression head, and objectness head on COCO for one epoch. For temporal consistency, VPHM constructs fan-shaped regions from the vanishing point through each object's lateral edges, computes IoU between predicted and actual positions in the next frame for Hungarian matching, and applies momentum smoothing (w=0.2) to objectness scores across matched tracks.

## Results

DetSeg-R, applied as a plug-and-play refinement to existing segmentation-based anomaly detectors, reduces FPR95 by up to 37.45% (RbA on FS Static: 41.83 → 4.38) while simultaneously improving AP and AUROC across all tested baselines. On Road Anomaly, UNO+DetSeg-R achieves the best overall pixel-level performance with 99.02 AUROC, 93.89 AP, and 1.94 FPR95. DetSeg-S, which generates binary masks via SAM without threshold search, outperforms the threshold-free S2M by 9.96, 1.90, and 13.35 IoU points on Road Anomaly, FS L&F, and FS Static respectively. On the video-based LostAndFound test set, adding VPHM temporal smoothing further improves AP by 0.4–1.7 points over DetSeg-R alone.

## Baselines & Comparisons

DetSeg-R is designed as a plug-and-play module that improves every baseline it is applied to, with the most dramatic gain on RbA for FS Static where FPR95 drops from 41.83 to 4.38 (−37.45) and AP rises from 62.86 to 80.89. Among the strongest standalone baselines, UNO achieves the best FPR95 on FS Static (0.29) and FS L&F (1.30), but UNO+DetSeg-R still improves AP to 93.89 on Road Anomaly and 97.72 on FS Static. PEBAL, which has the weakest FPR95 among recent methods (44.58 on Road Anomaly), sees a 35.88-point FPR95 reduction when combined with DetSeg-R. On the SMIYC test set (Table 3), DetSeg-R applied to UNO improves sIoU by +3.96, PPV by +7.45, and mean F1 by +10.48 on the Anomaly Track, though FPR95 slightly worsens (1.98→10.56) due to non-object regions within OoD boxes becoming new false positives. For threshold-free mask generation, DetSeg-S outperforms S2M by 9.96 IoU on Road Anomaly and 13.35 on FS Static, confirming that object-level bounding eliminates the need for fragile threshold search. Older methods (SynthCP, SML, SynBoost) are substantially outperformed across all metrics, with gaps exceeding 20 AP points on Road Anomaly.

## Relation to Prior Work

This paper departs from the dominant paradigm in road anomaly detection, which relies on pixel-level uncertainty scores from segmentation models (RbA, Mask2Anomaly, PEBAL) and struggles with boundary false positives and threshold sensitivity. It builds on Grounding DINO's open-vocabulary detection framework, extending it with universal queries and an in-distribution enhanced NMS (IE-NMS) to explicitly bound OoD objects rather than score individual pixels. The vanishing point guided Hungarian matching (VPHM) repurposes geometric priors previously used in lane detection and video segmentation for a new purpose: training-free temporal smoothing of anomaly predictions across video frames.

## Why It Matters / Open Questions

The practical deployment bottleneck of threshold selection for binarizing anomaly score maps is directly addressed, and the ~77ms overhead for a 37.45% FPR95 reduction (on the worst-case baseline) makes this a compelling drop-in improvement for autonomous driving stacks. The temporal consistency provided by VPHM is particularly relevant for downstream motion planning, where frame-to-frame prediction flicker can cause erratic behavior. Key open questions include handling dynamic OoD objects (the current VPHM assumes radial motion from the vanishing point, which breaks for laterally-moving objects) and whether the object-level bounding paradigm generalizes beyond road scenes to other structured environments.

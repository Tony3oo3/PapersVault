## Problem

On-chip image processors have only tens of MBs of memory, yet state-of-the-art DNNs for image restoration require tens of GBs, making direct deployment infeasible. While hardware-level line-buffer optimizations exist, there has been almost no algorithmic design of neural networks specifically tailored to the line-buffer constraint, where image access is restricted to a few lines at a time and both intra-line and inter-line correlations must be modeled under severe memory limits.

## Input / Output

The network consumes images in line groups of shape l×W (e.g., 8×1920 for HD), processing them sequentially in raster-scan order. At each pass, the input is the current line group plus cached hidden and cell states from the previous pass, stored in a shared portion of the line buffer. The output is the processed line group (denoised or upscaled pixels), and the updated hidden/cell states are written back to the line buffer for the next pass, so peak memory scales linearly with resolution rather than quadratically as in global DNNs.

## Method

The architecture combines an intra-line encoder, a hierarchical inter-line module, and an intra-line decoder in an end-to-end pipeline trained with L1 loss. For intra-line correlation, a progressive feature enhancement strategy splits features along the channel dimension and processes each portion with expanding strip convolutions (1×n kernels) across multiple stages, progressively widening the horizontal receptive field while compacting the representation. For inter-line correlation, an LSTM-style gate mechanism is modified so that the hidden state is partitioned into five hierarchical levels (1/2, 1/4, 1/8, 1/16, and remaining channels), each updated by its own convolution; this 'correlation annealing' design makes features from farther lines more abstract while preserving concrete detail from nearby lines, all within a fixed shared-memory budget. The result is a 3.37 MB-parameter network that uses only ~11 MB peak memory at HD resolution—roughly one-fifth of LineDL—while achieving up to 1 dB PSNR gain on RAW denoising.

## Results

On RAW image denoising, the proposed method achieves 44.38 dB PSNR on ELD (×100) and 41.69 dB on SID (×100), outperforming LineDL by up to 1.04 dB while using only 3.37 MB of parameters (vs. 24.36 MB) and 11.3 MB peak memory at HD resolution (vs. 68.5 MB for LineDL). For super-resolution (×4), the method reaches 31.81 dB on Set5 and 29.82 dB on Manga109, matching or slightly exceeding LineDL while requiring only 11.3 MB peak memory (vs. 135.0 MB). Compared to state-of-the-art global DNNs like Restormer (46.18 dB on ELD ×100), the proposed method trades ~1.8 dB PSNR for a ~2000× reduction in peak memory (11.3 MB vs. 24.21 GB at HD).

## Baselines & Comparisons

Against the primary local DNN competitor LineDL [24], the proposed method wins on all three tasks: +1.04 dB on ELD ×100 RAW denoising (44.38 vs. 43.34), +0.57 dB on SID ×100 (41.69 vs. 41.12), and +0.15 dB on Set5 super-resolution (31.81 vs. 31.74), while using 7.2× fewer parameters (3.37 vs. 24.36 MB) and ~6× less peak memory at HD. Against the simple local DNN baseline (residual blocks without recurrence), the method gains +2.72 dB on ELD ×100 and +1.57 dB on SID ×100, confirming the value of both the progressive intra-line enhancement and hierarchical inter-line distillation. Against classic local filters (Median, Wiener, Bilateral), the method achieves a 4–5 dB advantage, and even surpasses classic global methods (NLM, BM3D) by 4–5 dB. Against state-of-the-art global DNNs (Restormer, NAFNet, HAT, MambaIR), the method trades 1.5–2.5 dB PSNR for a 2000–5000× reduction in peak memory (11.3 MB vs. 4–64 GB), making it the only approach deployable on memory-constrained on-chip hardware. For Gaussian color denoising, the method consistently outperforms LineDL by 0.1–0.2 dB across noise levels (σ=15, 25, 50) on all four test sets, with the gap widening at higher noise. For super-resolution, the method matches or slightly exceeds LineDL on all five benchmarks (Set5, Set14, BSDS100, Urban100, Manga109) while reducing peak memory from 135 MB to 11.3 MB.

## Relation to Prior Work

This paper extends LineDL [24], the sole prior attempt at designing neural networks specifically for line-buffer-based on-chip image processing, by addressing two gaps: LineDL neglects intra-line pixel correlations and uses redundant LSTM hidden states that inflate memory. The authors introduce progressive strip convolutions for intra-line modeling and a hierarchical distillation mechanism for inter-line state compression, drawing on standard LSTM gating but restructuring the hidden state into multi-level channel splits. More broadly, the work shifts the line-buffer literature from hardware-centric optimizations (memory mapping, VLSI/FPGA architectures) toward algorithmic architecture design, a direction the authors note has been largely unexplored.

## Why It Matters / Open Questions

On-chip image processing is a critical bottleneck for mobile photography, ADAS, and edge multimedia where only tens of MBs of on-chip memory are available; demonstrating that a 3.37 MB-parameter model with ~11 MB peak memory can approach the quality of global DNNs (UNet, DRUNet) while using 30–40× less memory is practically significant for deployment. The paper's stated limitations—no power-consumption analysis and no integration with quantization or memory-allocation strategies—leave open important questions for real hardware deployment. A key open direction is whether the hierarchical line-buffer formulation generalizes to video processing or multi-frame tasks where temporal line-buffer constraints interact with spatial ones.

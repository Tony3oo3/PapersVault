## Problem

Existing low-light enhancement methods either optimize for human visual perception (pixel-level losses) rather than machine perception, or are tailored to a single downstream task with cumbersome multi-stage training. Critically, they assume all inputs are low-light, causing performance degradation on well-lit images—making them unsuitable for real-world scenarios with unpredictable, varying illumination. No prior framework provides a unified, light-agnostic solution that robustly enhances low-light inputs while leaving well-lit inputs unaffected across arbitrary high-level vision tasks.

## Input / Output

TorchAdapt takes a standard RGB image or video frame (e.g., 256×256×3) and produces a single enhanced image of the same spatial dimensions, which is then fed into a frozen pre-trained backbone for downstream tasks. The Torch module itself is extremely lightweight—only 11,075 trainable parameters and 0.712 GFLOPs at 256×256—adding roughly 1.8 ms latency to a YOLOV3 pipeline. The output is not a pixel-level 'corrected' image per se, but a content-adaptively modulated image whose backbone features are aligned with well-lit counterparts, making it a plug-and-play pre-processor for any detector or segmentation network.

## Method

TorchAdapt comprises two complementary CNN modules: Torch, a lightweight residual convolutional network that computes a tanh-bounded enhancement map applied element-wise to the input, and Adapt, a multi-scale convolutional network that produces a spatially varying sigmoid modulation matrix scaled by an illumination-aware factor (a sigmoid of average luminance) to control enhancement strength globally. The two are fused via adaptive element-wise multiplication so that enhancement is amplified in dark regions and suppressed in well-lit ones. Training uses a BYOL-inspired self-supervised objective: a well-lit image and its synthetically darkened counterpart are both enhanced by TorchAdapt, passed through a frozen backbone and projector, and a cosine-similarity loss aligns both enhanced representations with the original well-lit representation—simultaneously encouraging low-light enhancement and discouraging over-enhancement of already well-lit inputs. This pre-training runs for only 5 epochs on ImageNet with a single GPU (~6 hours with ResNet-50), is task-agnostic, and the resulting module can be plugged into any downstream vision task without further training.

## Results

TorchAdapt achieves state-of-the-art performance across all five tasks in both Low-Light (LL) and Light-Agnostic (LA) settings. Headline numbers include 80.1 mAP50 (LL) and 64.0 mAP50 (LA) for object detection, 53.7 AP50 (LL) and 59.0 AP50 (LA) for face detection, 53.6 SegAP (LL) and 36.6 SegAP (LA) for instance segmentation, 50.8 mIoU (LL) and 76.3 mIoU (LA) for semantic segmentation, and 39.1 mAP (LL) and 59.1 mAP (LA) for video object detection. Gains over the previous best method range from +0.2 mIoU (SS, LA) to +6.4 mAP (VOD, LA), with the largest improvements in face detection (+4.3 AP50 in LA) and video object detection (+4.5/+6.4 mAP). The full framework adds only 0.1M parameters and 1.8 ms latency over the YOLOV3 baseline.

## Baselines & Comparisons

TorchAdapt outperforms all 11 compared baselines across every task and setting. Among standalone LLIE enhancers (Zero-DCE, SCI, URetinexNet, IAT), TorchAdapt wins by large margins — e.g., +4.9 mAP50 over Zero-DCE on LL object detection and +11.7 mAP over Zero-DCE on LA video object detection — confirming that pixel-level enhancement optimized for human perception is suboptimal for machine perception. Among end-to-end task-specific methods, TorchAdapt beats FeatEnHancer (the closest competitor) by +0.9/+1.0 mAP50 (OD), +2.1/+4.3 AP50 (FD), +1.2/+0.5 SegAP (IS), +0.7/+0.2 mIoU (SS), and +4.5/+6.4 mAP (VOD) in LL/LA settings. TorchAdapt also surpasses MAET on object detection (+0.9/+6.7 mAP50) and SCI‡ on face detection (+2.1/+4.3 AP50). In the zero-shot domain adaptation comparison (Table 5), TorchAdapt integrated with DAI-Net achieves 31.9 mAP on DARK FACE, outperforming DAI-Net alone (28.0), SimMinMax (25.7), and CICony (18.4) by +3.9, +6.2, and +13.5 mAP respectively. Notably, all standalone LLIE methods degrade performance on well-lit (LA) data relative to the baseline, whereas TorchAdapt consistently improves in both LL and LA settings, validating its light-agnostic design.

## Relation to Prior Work

TorchAdapt repurposes zero-reference LLIE methods (Zero-DCE, SCI) as its lightweight 'Torch' enhancement module, but departs from them by optimizing for machine-perception feature alignment rather than human-perception pixel fidelity. It extends the task-agnostic feature enhancement line (FeatEnHancer, MAET) by eliminating the need for per-task end-to-end training and by introducing a 'light-agnostic' objective that prevents degradation on well-lit inputs—something prior low-light-only methods (SimMinMax, DAI-Net, FeatEnHancer) explicitly fail to handle. The self-supervised pre-training strategy draws on BYOL-style representation alignment, but applies it to a frozen backbone on general-purpose ImageNet data rather than task-specific labeled pairs, making the training procedure task-independent.

## Why It Matters / Open Questions

The practical value is a single, once-trained, ~11K-parameter plug-in that consistently improves five diverse vision tasks (OD, FD, IS, SS, VOD) under mixed illumination with negligible latency overhead (~1.8 ms), which is attractive for safety-critical deployments (autonomous driving, surveillance) where lighting is unpredictable. The light-agnostic evaluation setting the authors curate is a useful and more realistic benchmark than pure low-light splits, and the finding that scaling without content-adaptive modulation is actively harmful in mixed settings is a non-obvious design insight. Open questions include whether the approach generalizes to other degradations (fog, motion blur), whether it composes with newer foundation-model backbones (SAM, DINOv2), and how well synthetic darkening during pre-training transfers to genuinely diverse real-world low-light conditions.

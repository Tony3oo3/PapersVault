## Problem

In federated domain generalization, non-IID data across clients induces domain shift that degrades prompt-based CLIP adaptation. Existing federated prompt learning methods learn soft prompts directly from client data, yielding limited prompt diversity and poor generalization to unseen target domains. The paper asks whether a generative perspective—producing diverse, domain-specific prompts via a learned generator—can overcome these limitations.
![Teaser figure](../imgs/ICCV20251887/cropped_page2_idx0.webp)

## Input / Output

The method consumes RGB images (processed through a frozen CLIP ViT-B/16 encoder producing 512-dim embeddings) and outputs class labels via softmax over cosine similarities between generated prompt embeddings and image embeddings. During training, each client provides images from its own source domain; during inference, the generator synthesizes a 512-dim domain-specific soft prompt vector per target image, which is concatenated with the class token and passed through the frozen text encoder to compute class probabilities. The prompt structure comprises M₁=4 domain-invariant context tokens plus M₂=4 domain-specific tokens, all in the 512-dim embedding space.

## Method

FedDSPG operates in two training steps. First, domain-specific soft prompts (DSPs) with a compositional structure—domain-invariant context tokens [v]₁…[v]_{M₁} followed by domain-specific tokens [u]₁^d…[u]_{M₂}^d and a class token—are optimized per client via cross-entropy loss on local data. Second, a Continuous Conditional GAN (CcGAN) is trained where the generator concatenates random noise z with the image embedding f(x) to synthesize DSPs, and the discriminator distinguishes real DSPs (from step 1) from generated ones conditioned on f(x), learning the joint domain-content distribution. For federated aggregation, soft prompt parameters use momentum-based exponential moving averages (α=0.2) instead of standard FedAvg to prevent destabilizing abrupt changes from heterogeneous domain components, while generative model parameters use standard averaging. At inference, the trained generator produces instance-specific DSPs for each target-domain image, enabling dynamic, diverse prompt generation without access to target domain data.

## Results

FedDSPG achieves state-of-the-art average accuracy across all three FDG benchmarks: 85.3% on Office-Home, 75.6% on DomainNet, and 97.4% on PACS (leave-one-domain-out protocol, CLIP ViT-B/16 backbone). The largest gains appear on DomainNet, where FedDSPG surpasses the strongest baseline FedTPG by 2.9% average accuracy and the weakest baseline CoOp by 31.5%. On the more challenging individual domains (e.g., DomainNet Infograph and Quickdraw), FedDSPG records 63.5% and 63.0% respectively, outperforming all baselines by 1–22 percentage points.

## Baselines & Comparisons

FedDSPG outperforms all seven baselines on every dataset's average accuracy. Against the closest competitor FedTPG [26], FedDSPG leads by 1.7% on Office-Home (85.3 vs. 83.6), 2.9% on DomainNet (75.6 vs. 72.7), and 0.5% on PACS (97.4 vs. 96.9). Against ADAPT [33], which also uses domain-specific prompts but without a generative model, the margin is 2.4% on Office-Home and 7.2% on DomainNet, confirming the generative component's contribution. PromptFL [9] (server-side prompt generator) trails by 3.0% on Office-Home and 4.3% on DomainNet. The older prompt-learning baselines—CoOp [40], CoCoOp [39], FedVPT-D [14], and FedCLIP [18]—are surpassed by 6–31 percentage points, with the largest gaps on DomainNet where domain shift is most severe. Notably, on the hardest individual target domains (DomainNet Infograph, Quickdraw), FedDSPG gains 10–22 points over baselines that lack domain-specific prompt design, while on the easier PACS dataset the advantage narrows to 0.2–5.9 points.

## Relation to Prior Work

This paper extends the CLIP-based prompt learning lineage (CoOp, CoCoOp) into the federated domain generalization setting by introducing domain-specific soft prompts (DSPs) that explicitly encode both domain-invariant context and domain-specific tokens. It departs from prior FDG prompt methods (PromptFL, ADAPT, FedTPG) that rely on simple adapters or hand-crafted prompts, instead borrowing the conditional GAN framework from CcGAN to generate prompts from a learned latent distribution. The closest prior work is SPG (Bai et al., ECCV 2025), which also uses a conditional adversarial network for prompt generation but lacks domain-specific prompt structure and federated aggregation design. The momentum-based aggregation is a targeted modification of FedAvg to handle the high variance in domain-specific prompt parameters across non-IID clients.

## Why It Matters / Open Questions

The paper demonstrates that a generative perspective on prompt learning can improve federated domain generalization, but the ablation reveals that the GAN component contributes only ~0.7 points over a simpler conditional soft prompt variant, suggesting the domain-specific prompt structure and the generative model are somewhat redundant in their individual contributions. Limitations include evaluation on only three moderate-scale datasets (Office-Home, DomainNet, PACS), reliance on a relatively simple CcGAN rather than more expressive generative models, and the cross-dataset transfer gap (DomainNet→Office-Home) still showing notable degradation. Open questions include whether more powerful generative backbones (e.g., diffusion models, which the authors note are too communication-expensive) or larger-scale benchmarks would yield proportionally larger gains, and whether the momentum aggregation strategy generalizes beyond the specific prompt parameterization used here.

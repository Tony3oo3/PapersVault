## Problem

Existing AI-generated image detection methods rely on multi-step reconstruction errors (e.g., DDIM sampling in DIRE, LaRE²) that are computationally expensive and fail to capture intrinsic noise patterns already present in raw images. No prior work exploits the subtle differences in low-order bit-planes between real and synthetic images, which contain visually imperceptible artifacts that current generative models cannot faithfully reproduce.
![Teaser figure](../imgs/ICCV20252217/cropped_page1_idx0.webp)

## Input / Output

The method takes a standard RGB image as input and produces a binary real/fake classification. Unusually, the input is consumed at the bit level: each channel is decomposed into 8 bit-planes, and only the 3 lowest-order planes (bits 0–2) are retained to form a noise representation with pixel values in [0, 7], which is then normalized to [0, 255] via min-max scaling or binary thresholding. A single 32×32 patch is selected from the 256×256 noise image and resized to 256×256 before classification, so the full image is never fed directly into the network.

## Method

LOTA comprises three modules operating in a single forward pass. First, Bit-Planes Guided Noisy Image Generation (BGNIG) decomposes each RGB channel into 8 bit-planes, composes the three lowest planes (z^c = 4·x₂ + 2·x₁ + x₀), and normalizes the result via either min-max scaling or binary thresholding to amplify noise contrast. Second, Maximum Gradient Patch Selection (MGPS) tiles the noise image into non-overlapping 32×32 patches and scores each with the L1 norm of four 2×2 directional gradient convolutions (horizontal, vertical, and two diagonal), selecting the patch with the highest score as the most artifact-rich region. Third, a lightweight classification head (ResNet-50-based) either processes the noise patch directly (Noise-Based Classifier) or fuses it with raw-image features via a noise-guided multi-head attention mechanism (Noise-Guided Classifier). The entire error-extraction pipeline requires only one bit-plane decomposition step, achieving 1.52 ms per image—nearly 100× faster than iterative reconstruction methods—while using only 23.6M parameters.

## Results

On the GenImage benchmark (8 generators, ~1.35M images), LOTA achieves 98.9% average accuracy, outperforming the strongest error-based baseline ESSP (87.0%) by 11.9 percentage points and DIRE (73.4%) by 25.5 points. The scaling variant (LOTA-scl.) reaches 98.7%, while the noise-guided classifier variant (LOTA-ngc) achieves 93.2%. LOTA also demonstrates superior cross-generator generalization, with over 98.2% accuracy from GAN-trained to Diffusion-tested and over 99.2% from Diffusion-trained to GAN-tested, and operates at 1.52 ms for error extraction—nearly 100× faster than ESSP (25.10 ms).

## Baselines & Comparisons

LOTA decisively outperforms all 10 baselines on average accuracy. Against the strongest error-based method ESSP (87.0%), LOTA gains 11.9 points; against LaRE² (79.4%) and DIRE (73.4%), the margins are 19.5 and 25.5 points respectively. Among spatial-domain baselines, Swin-T (70.3%), DeiT-S (67.6%), and ResNet-50 (66.9%) all trail LOTA by 28–32 points, while frequency-domain methods Spec (65.1%), GramNet (64.7%), F3Net (64.6%), and CNNSpot (61.7%) lag by 34–37 points. Notably, LOTA's advantage is most pronounced on cross-generator settings: when trained on one generator and tested on another, LOTA maintains >91% accuracy across all pairs, whereas DIRE and LaRE² drop sharply (e.g., DIRE falls to ~57–69% on cross-generator tests). The only generator where LOTA's per-generator accuracy is below 95% is Midjourney (93.2%), yet it still exceeds ESSP's Midjourney score (80.8%) by 12.4 points.

## Relation to Prior Work

This paper repurposes bit-plane decomposition—a technique well-established in image steganography and steganalysis—for AI-generated image detection, a domain where no prior work has exploited this signal. It departs from the dominant error-based paradigm (DIRE, LaRE², ESSP) that relies on multi-step diffusion reconstruction to extract noise maps, instead extracting noise directly from the image's own lowest bit-planes. The classification head builds on standard CNN backbones (ResNet-50) and multi-head attention, but the key architectural contribution is the lightweight preprocessing pipeline (BGNIG + MGPS) that replaces expensive generative-model-based error extraction with a single-step bit-plane operation.

## Why It Matters / Open Questions

The practical impact is significant: millisecond-level inference (vs. seconds for DIRE) and 23.6M parameters make real-time deployment feasible, while the 98.9% accuracy and strong cross-generator generalization (98.2%+ GAN→Diffusion, 99.2%+ Diffusion→GAN) address a key limitation of prior error-based methods. The robustness to Gaussian blur and JPEG compression—where competing methods collapse to near-random—suggests the bit-plane signal is more stable than reconstruction-based signals. Open questions include whether this approach generalizes to future generators (e.g., next-gen diffusion or autoregressive models), whether it extends to video or 3D content, and how it performs under adversarial perturbations specifically designed to alter low-bit patterns.

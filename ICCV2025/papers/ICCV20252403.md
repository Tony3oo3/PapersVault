## Problem

Standard language-driven Instance Object Navigation assumes the user provides a detailed instance description before navigation begins, which is impractical when users cannot or will not supply all distinguishing details upfront. This paper introduces Collaborative Instance Object Navigation (CoIN), where the agent starts with only a category (e.g., 'Find the picture') and must resolve visual ambiguity among multiple same-category instances through open-ended, template-free natural-language dialogues with the user during navigation.
![Teaser figure](../imgs/ICCV20252403/cropped_page0_idx0.webp)

## Input / Output

The agent receives a minimal natural-language instruction specifying only an open-set object category and a stream of RGB visual observations from a continuous 3D environment (Habitat simulator). At each timestep it selects from {Forward 0.25 m, Turn Right 15°, Turn Left 15°, Stop, Ask}; the Ask action triggers a template-free question to the user, whose response updates a growing set of target facts. User interaction is capped at 4 rounds, and the episode terminates when the agent stops within 0.25 m of the target or exceeds 500 actions.

## Method

AIUTA is a training-free module layered on top of the zero-shot VLFM navigation policy, comprising two sequential components triggered upon object detection. The Self-Questioner first prompts a VLM (LLaVA-1.6/Mistral-7B) for an initial scene description, then uses an LLM (GPT-4o) to generate attribute-specific follow-up questions whose VLM answers enrich the description; a novel Normalized-Entropy-based uncertainty estimator restricts the VLM to a 3-token vocabulary (Yes/No/I don't know), computes Shannon entropy over the token probabilities, and normalizes it to [0,1] to flag and filter out hallucinated attributes. The Interaction Trigger then prompts the LLM to score the alignment between the refined description and the accumulated target facts, mapping the score to one of three actions: stop (score ≥ τ_stop), skip interaction (score < τ_skip), or ask the user a maximally informative question (τ_skip ≤ score < τ_stop). The entire pipeline requires no gradient updates and operates purely through prompt-engineered LLM/VLM calls.

## Results

On CoIN-Bench, AIUTA (training-free, category-only input) achieves SR of 7.42 / 14.38 / 6.67 and SPL of 2.92 / 7.99 / 2.30 on Val Seen / Val Seen Synonyms / Val Unseen, while requiring fewer than 2 questions per successful episode (NQ = 1.67 / 1.36 / 1.13). This represents a ~14× SR improvement over the zero-shot VLFM baseline (SR ≈ 0.36 / 0.00 / 0.00) and outperforms all trained baselines on Val Unseen. On the IDKVQA uncertainty-estimation task, the proposed Normalized-Entropy technique achieves the best Effective Reliability Φ_{c=1} of 21.12, surpassing Energy Score (20.45), MaxProb (15.94), and LP (14.01).

## Baselines & Comparisons

AIUTA dramatically outperforms the zero-shot VLFM baseline, which achieves near-zero SR (≤0.36%) across all splits due to its inability to discriminate among multiple instances of the same category; AIUTA lifts SR to 7–14% by gathering disambiguating information through user interaction. On Val Unseen (novel categories), AIUTA (SR 6.67) surpasses all trained baselines: Monolithic (0.22), OVON (2.61), and PSL (4.58), demonstrating that training on GOAT-Bench does not transfer to unseen categories in multi-instance scenes. On Val Seen and Val Seen Synonyms, AIUTA is competitive but slightly behind OVON (8.18 vs 7.42 on Val Seen; 15.88 vs 14.38 on Val Seen Synonyms) and PSL (8.78 vs 7.42 on Val Seen), though AIUTA is training-free and uses only a category label rather than a full description. For VLM uncertainty estimation on IDKVQA, the proposed Normalized-Entropy technique (Φ_{c=1} = 21.12) outperforms Energy Score (20.45), MaxProb (15.94), and the LP linear-probe method (14.01), with ablation showing it is also more robust to threshold perturbation and dataset subsampling.

## Relation to Prior Work

This paper extends Instance Object Navigation (InstanceObjectNav) by introducing a collaborative dialogue component: rather than assuming a full instance description is provided upfront (as in GOAT-Bench, PSL, OVON), the agent receives only a category and must resolve visual ambiguity through open-ended, template-free natural-language questions during navigation. The navigation backbone is the zero-shot VLFM policy (frontier-based exploration with BLIP-2 semantic scoring and Grounding-DINO detection), while the interaction layer draws on the interactive embodied AI literature (Alexa Arena, DialFRED, FindThis) but departs from its reliance on templated Q&A pairs. The Self-Questioner's normalized-entropy uncertainty estimation builds on VLM hallucination literature (PAI, Eyes Wide Shut) and out-of-distribution detection (Energy Score, LP), but applies Shannon entropy over a constrained three-way vocabulary (Yes/No/I don't know) in a novel prompt-guided manner.

## Why It Matters / Open Questions

CoIN-Bench (1,649 multi-instance episodes) fills a gap in evaluation for instance-level ambiguity, and the validation that VLM-simulated users match real human results (42.50% SR in both) enables scalable, reproducible experiments that prior interactive navigation benchmarks could not support. The finding that a training-free, dialogue-based method outperforms CLIP-embedding-based trained policies on unseen categories suggests that explicit information gathering may be more robust than learned semantic alignment for generalization. Open questions include the high inference cost of GPT-4o calls, the limited 4-round interaction budget, and whether the approach transfers to real-world deployment without simulator access.

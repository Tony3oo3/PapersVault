## Problem

Existing Layout-to-Image methods can position objects via bounding boxes but fail to generate fine-grained instance features such as mixed colors, complex textures, and intricate patterns. The paper identifies two root causes: training data relies on coarse category labels (making detailed descriptions out-of-distribution at inference), and a single contextualized EoT token is insufficient to encode high-frequency appearance details.

## Input / Output

The method accepts a global text prompt, a set of bounding boxes in [x,y,w,h] format, and rich instance-level descriptions (e.g., 'a green vase made of glass', 'red deck chair with yellow star on it') that go beyond simple category labels to specify textures, materials, and color combinations. It outputs a single RGB image in which each described instance appears at its designated spatial location with the specified visual features. The adapter operates as a plug-and-play module on frozen SDXL or SD1.5 backbones, requiring no retraining of the base model.

## Method

IFAdapter introduces two key components. First, Appearance Tokens: a Perceiver-style resampler with learnable queries interacts with multi-granularity text encoder outputs to compress arbitrary-length instance descriptions into a fixed set of appearance tokens, which complement the EoT token to supply high-frequency detail. Second, an Instance Semantic Map (ISM): each instance's appearance tokens are projected through a spatially masked cross-attention to produce a per-instance 2D feature map, and overlapping regions are resolved via gated semantic fusion that weights instances by a learned importance score modulated by inverse area ratio (protecting smaller instances from being 'assimilated'). The final ISM is injected into a subset of mid and decoder cross-attention layers of the frozen diffusion UNet through duplicate attention layers (IP-Adapter style) with a learnable tanh-gated scale initialized to zero. Training freezes the base SDXL and optimizes only the adapter parameters using the standard LDM denoising loss with random dropping of global and local conditions to support classifier-free guidance at inference.

## Results

On the COCO-IFG benchmark, IFAdapter (SDXL) achieves the highest Instance Feature Success (IFS) rate across all three VLM evaluators: 79.7% (QwenVL), 68.6% (InternVL), and 61.0% (CogVL), outperforming the strongest baseline InstanceDiffusion (69.6/49.7/38.2). It also attains the best spatial accuracy (49.0% Grounding-DINO AP), the highest CLIP score (25.1), and the lowest FID (22.0), demonstrating simultaneous gains in instance feature fidelity, positional accuracy, and overall image quality.

## Baselines & Comparisons

IFAdapter (SDXL) outperforms all five baselines on every reported metric. Against the strongest training-based baseline InstanceDiffusion, IFAdapter gains +10.1 points on QwenVL IFS, +18.9 on InternVL IFS, +22.8 on CogVL IFS, and +5.9 on spatial AP, while also improving FID from 26.8 to 22.0. The training-free baselines MultiDiffusion and DenseDiffusion trail further behind, with DenseDiffusion scoring only 38.7% QwenVL IFS and 22.2% AP. GLIGEN, the earliest grounded T2I method, shows the weakest performance overall (44.8% QwenVL IFS, 18.4% AP). MIGC sits in the middle among training-based methods but still lags IFAdapter by 16.9 points on QwenVL IFS. The consistent margin across all three VLM evaluators and the spatial metric confirms that the gains are not evaluator-specific.

## Relation to Prior Work

IFAdapter extends the Layout-to-Image (L2I) line of work (GLIGEN, InstanceDiffusion, MIGC) by addressing the underexplored dimension of fine-grained instance feature generation alongside positional control. It borrows the Perceiver Resampler architecture [1] to compress variable-length instance descriptions into fixed-size appearance tokens, and adapts the duplicate cross-attention injection mechanism from IP-Adapter [66] to condition the diffusion UNet on a 2D Instance Semantic Map. The key departure from prior L2I methods is the shift from category-level labels and single EoT tokens to dense, VLM-annotated instance descriptions combined with multi-granularity appearance queries, and the replacement of sequential grounding tokens with an explicit spatial map that prevents feature leakage.

## Why It Matters / Open Questions

The plug-and-play adapter design is practically significant: it can be attached to arbitrary community diffusion models and LoRAs without retraining, lowering the barrier to grounded generation for non-expert users. The COCO-IFG benchmark and VLM-based verification pipeline address a real evaluation gap—prior L2I benchmarks measured only positional accuracy, and CLIP-based feature checks are shown to be unreliable for fine-grained details. Open questions include whether the approach scales to very large numbers of instances, whether the VLM-based evaluation generalizes beyond COCO-style scenes, and whether the 2D semantic map can be extended to 3D or video generation settings.

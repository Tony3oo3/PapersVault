## Problem

Current Vision-Language-Action models are limited to short-horizon, single-skill sequences (either arm manipulation or base locomotion) and fail to generalize to long-horizon, multi-skill tasks in highly dynamic, unstructured environments such as sand. No existing system unifies task-level reasoning, precise multimodal control, and adaptive state feedback into a single trainable architecture capable of executing complex instruction sequences without error accumulation.
![Teaser figure](../imgs/ICCV20251605/cropped_page0_idx0.webp)

## Input / Output

The system consumes multi-view RGB images (base and arm cameras), depth maps, LiDAR point clouds, natural-language task instructions of varying granularity, and continuous robot state (arm pose/velocity, base linear/angular velocity). The reasoning layer outputs a four-stage structured CoT (Goal Explanation → Subgoal Decomposition → Action Sequence Generation → Action Sequence Modeling) yielding an ordered list of meta-action instructions; the acting layer then produces low-level control commands at 30 FPS—linear and angular velocities for the base expert, or end-effector pose and velocity for the arm expert. Sensor inputs are spatially filtered per expert (e.g., base expert uses depth < 1.5 m and LiDAR within 1.2 m horizontal radius; arm expert uses depth < 0.8 m base / < 0.5 m arm) to reduce interference between movement and manipulation.

## Method

MindExplore is a three-tier hierarchical architecture. The Reasoning Layer fine-tunes Qwen2-VL-7B-Instruct via LoRA using a two-stage strategy: curriculum cold-start (easy structured-surface data → real sand scenes) followed by three rounds of iterative DPO with a progressive rejection schedule that tightens the preferred/non-preferred gap each round. The Acting Layer employs a Mixture of Policy Experts (MoPE) that decouples base locomotion from arm manipulation; each expert is a Multimodal Diffusion Policy (MMDP) that encodes RGB with R3M, converts depth to point clouds via perspective projection and encodes them with an iDP3 pyramid convolutional encoder, encodes text with DistilBERT, fuses all modalities through linear adapters, and generates actions via a lightweight 1D convolutional denoising diffusion process conditioned on the fused features and robot state. A Memory Mechanism with a gated routing network (softmax over DistilBERT-encoded meta-action) dispatches each meta-action to the correct expert, continuously feeds real-time sensor state back to the acting layer, and triggers full replanning by the reasoning layer upon execution failure, thereby closing the loop between planning and control.

## Results

On 24 real-world robotic tasks in dynamic sand environments, MindExplore achieves 88.33% average success on coarse-grained long-horizon tasks, 93.33% on intensive instruction-following tasks, 93.33% on cross-expert multi-skill tasks, and 86.67% on zero-shot generalization tasks. The system is reported to be 3.01× more successful than existing methods at 30 FPS execution frequency. For the reasoning layer alone, MindExplore's CoT module achieves 63.17–75.35% ROUGE_L and 73–89% meta-action planning accuracy, substantially outperforming GPT-4o (29.17–41.59% ROUGE_L, 21–61% accuracy) and all open-source MLLMs.

## Baselines & Comparisons

MindExplore dominates both VLA baselines across all four task categories: it outperforms OpenVLA by 78–92 percentage points (e.g., 88.33% vs. 10.00% on coarse-grained tasks; 93.33% vs. 1.67% on cross-expert tasks) and RDT by 52–78 percentage points (e.g., 86.67% vs. 15.00% on zero-shot generalization). For the reasoning layer, MindExplore's CoT module surpasses GPT-4o-latest by 28–34 points in ROUGE_L and 12–52 points in meta-action accuracy, and outperforms Gemini-2.0-Flash, InternVL2.5-8B, Qwen2.5-VL-7B, and DeepSeek-VL2 by even wider margins. At the acting layer, the Base Expert (87.12% avg) and Arm Expert (91.67% avg) substantially exceed the RGB-based ACT (36.86%) and point-cloud-based iDP3 (50.24%), with the multimodal fusion of RGB, depth-as-point-cloud, and LiDAR being the key differentiator. Notably, MindExplore's success rate remains stable as meta-action sequence length increases (avg. lengths 2–4.3), whereas OpenVLA and RDT degrade progressively with longer sequences.

## Relation to Prior Work

MindExplore departs from the dominant paradigm of monolithic VLA models (OpenVLA, RDT, ACT) that consolidate all capabilities in a single network, instead proposing a three-layer hierarchical architecture that explicitly separates task planning (CoT reasoning on Qwen2-VL), skill execution (Mixture of Policy Experts with diffusion-based action generation), and state tracking (memory feedback loop). The acting layer builds directly on the denoising diffusion framework of Ho et al. [12] for action generation and borrows the iterative DPO / self-play fine-tuning paradigm of Chen et al. [7] to refine the reasoning layer through progressive preference optimization. The MMDP module repurposes R3M visual encoders and iDP3 point-cloud encoders into a unified multimodal conditioning space, while the MoPE routing strategy is a lightweight alternative to the single-policy approach used in prior VLA work.

## Why It Matters / Open Questions

The paper addresses a concrete gap: existing VLA models handle single-skill, short-horizon sequences but fail on multi-skill long-horizon tasks in unstructured terrain, a setting that is critical for outdoor and field robotics. The 3.01× success-rate improvement over OpenVLA and RDT across 24 real-world tasks, combined with 30 FPS execution, suggests the hierarchical design is both effective and deployable. However, evaluation is confined to a single robot platform and a single terrain type (sand), and the baselines (OpenVLA, RDT) are not specifically tuned for hierarchical multi-skill execution, so the magnitude of the gap may overstate the architectural advantage. Open questions include whether the MoPE + memory pattern generalizes to more diverse environments and robot morphologies, and whether the CoT reasoning layer can be replaced by lighter-weight planners without sacrificing long-horizon coherence.

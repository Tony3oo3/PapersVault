## Problem

Existing sketch-based person re-ID methods focus on bridging the modality gap between sketches and RGB photos but largely overlook subjective style variation, where different artists draw the same person with vastly different appearances. Collecting a large, style-diverse pedestrian sketch dataset is prohibitively expensive, yet non-pedestrian sketch datasets (e.g., Sketchy) offer abundant style diversity at low cost. The paper asks whether non-pedestrian sketch-RGB data can be leveraged to equip a model with cross-category subjective style generalization for pedestrian re-ID.
![Teaser figure](../imgs/ICCV20250445/cropped_page0_idx1.webp)

## Input / Output

At test time, the method takes a hand-drawn pedestrian sketch as query and a gallery of RGB pedestrian photos, producing a cosine-similarity-based retrieval ranking. The frozen CLIP ViT-B/16 backbone processes 224×224 images with trainable prompts of length 8 and dimension 512; the text input is fixed to 'An image of person, P_t'. Evaluation is zero-shot with respect to sketch style: the model is trained on a subset of drawing styles (from MaSk1k) and tested on previously unseen styles, with performance measured by mAP, R@k, and mINP.

## Method

AIP is a two-stage incremental prompt-tuning framework on a frozen CLIP model. In the first CIA stage, category-wise prompts (CP) and a globally shared prompt (GP) are learned alongside a text prompt, with two key components: ACDE subtracts the category text feature from the image feature to algebraically neutralize category-specific biases, and MOIA uses a meta-learning inner-outer loop (inner loop on non-pedestrian Sketchy pairs, outer loop validated on pedestrian pairs) to prioritize gradient updates beneficial to person re-ID. In the second ISA stage, a Style Prompt Generator φ (convolutional patch embedding + 3 transformer blocks) takes the pre-learned prompts and the input sketch to produce input-adaptive prompts that are concatenated with the originals, enabling dynamic style adjustment. A KL-divergence style loss enforces consistent similarity distributions across different drawing styles of the same identity, and all pre-learned prompts are frozen during this stage.

## Results

On the PKU-Sketch dataset under zero-shot evaluation, AIP achieves 94.3 mAP, 96.0 R@1, and 90.6 mINP, surpassing the strongest sketch-only baseline (AIO S→R, 72.8 mAP) by over 21 points and even exceeding the multimodal AIO (S+T→R, 92.2 mAP) that additionally uses textual descriptions. On the MaSk1k dataset, AIP consistently outperforms AttnAlign across all style-split settings, with the largest gap in the hardest configuration (train A…E, test F): 31.94 mAP vs. 14.93 mAP for AttnAlign and 11.85 mAP for AttnAlignMQ. The CLIP-base (same backbone, no AIP components) reaches 87.5 mAP on PKU, confirming that the 6.8-point gain comes from the AIP framework rather than the backbone alone.

## Baselines & Comparisons

Against AttrAlign [18], the first method to explicitly address subjectivity in sketch re-ID, AIP wins decisively: 94.3 vs. 55.6 mAP on PKU (a 38.7-point gap) and roughly 2× the mAP on MaSk1k across every style split (e.g., 31.94 vs. 14.93 in the hardest setting). Against UniReID (S→R) [5] and AIO (S→R) [17], which use CLIP-based backbones but are trained on much larger multi-modal datasets (SYNTH-PEDES, LLCM, 100k+ extra pairs), AIP still leads by 21+ mAP points using only MaSk1k and Sketchy. Notably, AIP also surpasses the multimodal variants UniReID (S+T→R) and AIO (S+T→R) that additionally ingest textual descriptions as queries, achieving 94.3 vs. 91.8/92.2 mAP on PKU. The CLIP-base ablation (same frozen ViT-B/16 backbone, GP prompt, instance loss, trained on MaSk1k only) scores 87.5 mAP, confirming that the 6.8-point improvement is attributable to AIP's cross-category prompt strategy rather than simply having more training data.

## Relation to Prior Work

This paper builds on CLIP's frozen ViT backbone and the prompt-tuning paradigm (visual prompts from Jia et al., text prompts from CoOp) to adapt a pre-trained vision-language model for instance-level sketch re-ID. It departs from prior sketch re-ID methods (PKU-Sketch, AttnAlign) that focus on modality gap or specific style attributes, and from CLIP-based SBIR work (ProS, FG-ZS-CLIP) that remains at category-level or generic object retrieval. The key conceptual departure is framing the problem as cross-category subjective style generalization: using non-pedestrian sketch data (Sketchy) as a source of diverse style knowledge, transferred via a two-stage incremental prompt-tuning pipeline (CIA → ISA) with category-decoupled embeddings and meta-optimized instance alignment to prevent non-pedestrian overfitting.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in sketch re-ID: collecting diverse pedestrian sketches is expensive, yet subjective style variation severely degrades zero-shot retrieval. The finding that structured cross-category transfer (via AIP) substantially outperforms naive data mixing (which actually hurts) provides a principled recipe for leveraging cheap, diverse non-pedestrian data. Limitations include evaluation on only two relatively small datasets (PKU: 200 IDs; MaSk1k: 996 IDs), a complex multi-component pipeline whose individual contributions are modest in ablation, and unclear scalability to larger or more diverse pedestrian benchmarks. Open questions include whether the meta-learning component (MOIA) is essential or a simpler curriculum would suffice, and whether the cross-category style transfer insight generalizes to other sketch-based retrieval tasks beyond person re-ID.

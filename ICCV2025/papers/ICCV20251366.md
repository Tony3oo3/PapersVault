## Problem

Generative Large Multimodal Models (LMMs) like LLaVA and Qwen-VL excel at open-ended vision-language tasks but underperform smaller encoder VLMs (CLIP, SigLIP) on discrete-label classification tasks such as image classification and multiple-choice VQA. The core challenge is extracting useful discriminative features from generative LMMs without the cost of task-specific finetuning or the modality limitations of encoder-based models that cannot process joint vision-language inputs.
![Teaser figure](../imgs/ICCV20251366/cropped_page0_idx0.webp)

## Input / Output

The method consumes a frozen LMM along with approximately 20 few-shot labeled examples per class, where each example can be an image-only, text-only, or interleaved image-text sequence. At inference, a new query of the same modality is processed through the LMM, and the output is a discrete class label determined by majority vote across a sparse set of selected attention heads. No gradient updates or model weight modifications are required at any stage.

## Method

Sparse Attention Vectors (SAVs) is a finetuning-free feature extraction method that identifies a sparse subset of attention heads (<5% of total heads) whose activations serve as effective classification features. Given few-shot examples, the method extracts the attention vector from the final token position for every head and layer, computes per-class centroid vectors by averaging, and evaluates each head as a local nearest-centroid classifier. The top-k heads (k=20) by classification accuracy on the support set are retained as SAVs. At test time, each selected head independently predicts a label via cosine similarity to class centroids, and the final prediction is a majority vote across all selected heads. This approach requires no gradient-based training, no prompt engineering, and no auxiliary models, yet outperforms LoRA finetuning and few-shot ICL baselines across safety, VQA, retrieval, and classification benchmarks.

## Results

On LLaVA-OneVision-7B, SAVs achieves 80.8% on MHaluBench, 94.3% on VLGuard, 51.8% on BLINK, 35.1% on NaturalBench (group accuracy), and 97.5% on ImageNet-1k (16-way), outperforming LoRA fine-tuning by an average of +7% on challenging benchmarks. On Qwen2-VL-7B, SAVs reaches 85.1% on MHaluBench, 96.0% on VLGuard, and 98.7% on CUB-200. The method requires only 20 few-shot examples per label and uses fewer than 5% of attention heads (20 out of hundreds), with no gradient-based fine-tuning.

## Baselines & Comparisons

SAVs consistently outperforms all few-shot and fine-tuning baselines across both LLaVA-OV and Qwen2-VL. Against LoRA fine-tuning, SAVs gains +4.5% on MHaluBench, +4.3% on VLGuard, +4.8% on BLINK, and a striking +17.7% on NaturalBench-Retrieval (group) for LLaVA-OV, while matching or exceeding LoRA on all image classification benchmarks. Against 4-shot in-context learning, SAVs wins by large margins (e.g., +55.8% on MHaluBench for LLaVA-OV), and the paper notes that ICL actually degrades performance below zero-shot on several tasks. Against MTV (multimodal task vectors), SAVs improves by +43.5% on MHaluBench and +19.7% on NB-r(G) for LLaVA-OV. On interleaved image-text tasks where CLIP/SigLIP cannot operate natively, SAVs (80.8% on MHaluBench, 35.1% on NaturalBench) vastly outperforms concatenated CLIP (51.9%, 1.2%) and SigLIP (48.6%, 1.2%) features. SAVs also approaches or exceeds the closed-source GPT-4o upper bound on safety tasks (80.8 vs. 39.4 on MHaluBench; 94.3 vs. 45.7 on VLGuard) while remaining competitive on classification benchmarks.

## Relation to Prior Work

This paper repurposes the interpretability insight that specific transformer attention heads encode task-specific information (task vectors, function vectors) in a fundamentally different way: rather than using identified heads to augment a model's generative output, SAVs extract attention vectors from a sparse set of heads and use them directly as discriminative features for classification. It departs from prior feature-extraction-from-generative-models work, which typically requires finetuning, carefully constructed prompts, or specialized architectures, by being entirely finetuning-free and requiring only ~20 labeled examples per class. The method also positions itself against encoder VLMs (CLIP, SigLIP) that excel at classification but cannot natively process interleaved image-text inputs, offering truly multimodal features from a single generative LMM.

## Why It Matters / Open Questions

SAVs provide a lightweight, interpretable, and finetuning-free pathway to close the long-standing gap between generative LMMs and encoder VLMs on discrete-label tasks, with the added benefit of native support for interleaved image-text inputs that CLIP-style models cannot handle. The demonstrated cross-task generalization (SAVs from one task transferring to a similar task while LoRA overfits) suggests a practical route to rapid task adaptation without retraining. Key limitations include the requirement for white-box model access (ruling out closed-source LMMs) and the coarse majority-vote confidence metric, which may be insufficient for tasks requiring calibrated probabilities. Open directions include applying SAVs to retrieval, data compression, and as distilled representations for downstream models.

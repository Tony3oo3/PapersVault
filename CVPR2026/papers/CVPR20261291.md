## Problem

Existing sRGB noise synthesis methods rely on explicit camera metadata (manufacturer, ISO, shutter speed) during both training and inference to condition noise generation. This dependency severely limits practical applicability because metadata is frequently stripped from publicly available images, inconsistent across devices, or entirely absent in scientific imaging domains. The paper asks whether realistic, signal-dependent noise can be synthesized without any explicit metadata by instead learning implicit noise representations directly from input images.

## Input / Output

At inference, the method takes a clean sRGB image and a reference noisy image (from which the noise residual is computed as the pixel-wise difference). The Prompt Encoder processes this residual to extract input-specific prompt features encoding ISO-level statistics and spatial noise correlations, while the P-DiT generates a new 32×32 latent code conditioned on these features and the clean image. The PAE Decoder then upsamples the latent code back to full resolution (e.g., 256×256) and adds it to the clean image to produce the final synthetic noisy image. Training uses 256×256 randomly cropped patches from paired noisy-clean images in the SIDD dataset.

## Method

PNG is a two-stage framework. Stage 1 trains a U-Net-based Prompt Autoencoder (PAE) whose encoder extracts the noise residual and produces prompt features via two modules: a Global Prompt Block (GPB) that computes channel-wise mean and standard deviation of input features to modulate learnable prompt components (capturing ISO/gain statistics), and a Local Prompt Block (LPB) that computes Pearson correlation coefficients of neighboring pixels within ρ×ρ patches to capture ISP-induced spatial noise patterns. Stage 2 trains a Prompt DiT (P-DiT), a transformer-based consistency model using variance-exploding diffusion, to learn the PAE's latent distribution in a single step conditioned on the prompt features and the clean image. The key design choice is replacing explicit metadata with these learned prompt features as conditioning signals, so the generator implicitly adapts to the noise characteristics of whatever reference image is provided. At inference, the P-DiT produces a new latent code in one forward pass (leveraging the consistency model's single-step property), which the PAE Decoder converts into a realistic signal-dependent noisy image.

## Results

On the SIDD-Benchmark denoising task (Table 2), PNG achieves 37.55 dB PSNR and 0.937 SSIM, surpassing the strongest baseline NAFlow (37.22 dB / 0.935) and nearly matching the Real-data oracle (37.63 dB / 0.936) with only a 0.08 dB gap. Across four external benchmarks (PolyU, Nam, SIDD Validation, SIDD+), PNG trained purely on synthetic data yields an average of 37.47 dB PSNR / 0.9318 SSIM, outperforming both NAFlow (37.06 / 0.9315) and the Real-data baseline (36.27 / 0.9349). In the 50% mixed setting, PNG further improves to 37.65 dB / 0.9353 average, exceeding Real on all four benchmarks. For noise quality on unseen external datasets (Table 4), PNG achieves 0.0845 KLD and 0.4599 AKLD on average, a roughly 4.6× reduction in KLD over NAFlow (0.3888 / 2.1195).

## Baselines & Comparisons

PNG is compared against five prior noise-generation methods: C2N, NoiseFlow, Flow-sRGB, NeCA-W, and NAFlow. On the primary SIDD-Benchmark denoising task, PNG (37.55 dB PSNR) outperforms NAFlow (37.22 dB) by 0.33 dB and NeCA-W (36.82 dB) by 0.73 dB, while C2N (33.76 dB) and Flow-sRGB (34.74 dB) trail by more than 2 dB. On the multi-benchmark evaluation (Table 3), PNG's pure-synthetic training already surpasses the Real-data oracle in average PSNR (37.47 vs. 36.27 dB), and the 50% mixed variant exceeds Real on all four individual benchmarks. The closest competitor, NAFlow, is outperformed by PNG by 0.41 dB in average PSNR in the pure-synthetic setting and by 0.48 dB in the mixed setting. For noise quality on external datasets without metadata (Table 4), PNG achieves 0.0845 KLD / 0.4599 AKLD versus NAFlow's 0.3888 / 2.1195, a roughly 4.6× and 4.6× improvement respectively, while metadata-dependent methods (NoiseFlow, Flow-sRGB, NeCA-W) cannot operate at all on these datasets. On the external Nam denoising task (Table 5), PNG-Mixed achieves 40.40 dB PSNR, exceeding the Real baseline (38.87 dB) by 1.53 dB and NAFlow-Mixed (39.69 dB) by 0.71 dB.

## Relation to Prior Work

This paper sits at the intersection of two research threads: metadata-dependent sRGB noise synthesis (NoiseFlow, Flow-sRGB, NeCA, NAFlow) and prompt learning in vision (PromptIR, PromptRestorer). It repurposes the prompt-learning paradigm—originally designed to guide restoration networks toward specific degradations—into a noise *generation* setting, where learnable prompt components encode input-specific noise statistics (ISO gain, spatial correlation) in lieu of explicit camera metadata. Architecturally, it builds on consistency models and the DiT transformer backbone for one-step latent-space generation, extending the latent diffusion framework of Rombach et al. to the noise-synthesis task.

## Why It Matters / Open Questions

The practical significance is substantial: EXIF/metadata is frequently absent or inconsistent in real-world pipelines (scientific imaging, web-scraped images, cross-device transfer), and this work removes that dependency entirely while achieving near-real denoising performance (0.08 dB PSNR gap on SIDD). The finding that 50% synthetic + 50% real mixed training *exceeds* 100% real data across all four external benchmarks suggests the generated noise's diversity acts as a regularizer, a useful insight for data-limited denoising. Open questions include whether the prompt mechanism generalizes to non-sRGB noise (RAW, HDR) or to other degradation types (blur, compression), and whether the approach scales to the long tail of camera models beyond the five SIDD devices.

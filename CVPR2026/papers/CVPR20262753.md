## Problem

Unified MLLMs like UniGen lack image editing capability, and applying RL to image editing is underexplored because designing editing-specific reward models is extremely challenging—edits range from subtle object removals to full style changes, making reliable reward signals hard to obtain at scale. The paper asks whether image editing can be reformulated as a generation task so that stable text-to-image reward models can be shared across both tasks under a single RL framework.
![Teaser figure](../imgs/CVPR20262753/cropped_page0_idx10.webp)

## Input / Output

For text-to-image generation, the model takes a text prompt and produces a 384×384 image via masked token prediction. For image editing, it takes a 384×384 condition image (processed by both a continuous SigLIP2 encoder and a discrete MAGVITv2 tokenizer) plus an editing instruction, and generates a 384×384 edited image. For understanding, it accepts images at native resolution (up to 2,304 visual tokens) with a text query and produces a text response. During editing inference, classifier-free guidance is applied with separate scales for the condition image (s_I=1.5) and the editing instruction (s_T=3).

## Method

UniGen-1.5 builds on a Qwen2.5-7B LLM with decoupled encoders: SigLIP2 (continuous, variable-resolution) for understanding and MAGVITv2 (discrete) for generation, using masked token prediction (MaskGIT-style) as the generation objective. The training pipeline proceeds through pre-training, joint SFT (generation + editing + understanding), a lightweight Edit Instruction Alignment stage, and GRPO-based RL. The key architectural insight is a unified RL formulation: image editing is reformulated as image generation by synthesizing a textual description of the desired output image (via external LLMs) and measuring reward as the alignment between the generated image and that description, enabling shared reward models (CLIP-H, HPSv2, Unified-Reward-7B, ORM) across both tasks. The Edit Instruction Alignment stage trains the model to predict output-image descriptions from (condition image, instruction) pairs before RL, which the authors show is critical for producing diverse, instruction-satisfying candidates that yield informative GRPO learning signals. GRPO is run with N=8 candidates per input, 16 decoding steps, and an explicit KL penalty (β=0.01) for 1,500 steps.

## Results

On the ImgEdit benchmark, UniGen-1.5 achieves an overall score of 4.31, surpassing all compared models including Qwen-Image (4.27), GPT-Image-1 (4.20), and FLUX.1 Kontext (4.00), with particularly strong performance on Replace (4.78) and Remove (4.57) categories. On text-to-image generation, UniGen-1.5 scores 0.89 on GenEval and 86.83 on DPG-Bench, outperforming BAGEL (0.82 / –), Show-o2 (0.76 / 86.14), and BLIP3-o (0.84 / 81.60). On image understanding, UniGen-1.5 achieves competitive results with Show-o2 (e.g., 77.4 vs. 78.6 on AI2D, 51.9 vs. – on MathVista) while significantly improving over its predecessor UniGen across all benchmarks.

## Baselines & Comparisons

On ImgEdit, UniGen-1.5 (4.31) outperforms all open-source unified MLLMs by a wide margin—beating OmniGen2 (3.44) by 0.87, BAGEL (3.20) by 1.11, and Step1X-Edit (3.06) by 1.25—and also surpasses proprietary models Qwen-Image (4.27) and GPT-Image-1 (4.20) by 0.04 and 0.11 respectively. On GenEval, UniGen-1.5 (0.89) leads all unified MLLMs, exceeding BAGEL (0.82) by 0.07, Show-o2 (0.76) by 0.13, and BLIP3-o (0.84) by 0.05, while also beating GPT-Image-1 (0.84) by 0.05. On DPG-Bench, UniGen-1.5 (86.83) surpasses Show-o2 (86.14) by 0.69, UniGen (85.19) by 1.64, and BLIP3-o (81.60) by 5.23. On image understanding benchmarks, UniGen-1.5 is broadly competitive with Show-o2 (e.g., 77.4 vs. 78.6 on AI2D, 63.7 vs. 63.1 on GQA) and clearly outperforms UniToken, MUSE-VL, and MMaDA on most metrics, though it trails Show-o2 on AI2D by 1.2 points. The unified RL strategy is validated by ablations showing that jointly optimizing T2I and editing in GRPO yields the best overall scores (0.89 GenEval, 86.83 DPG-Bench, 4.31 ImgEdit) compared to training either task alone.

## Relation to Prior Work

UniGen-1.5 extends the UniGen framework [66], which established a data-centric pipeline for unified MLLMs using masked token prediction (MaskGIT-style) for image generation, by adding image editing capability and replacing UniGen's chain-of-thought verification (CoT-V) test-time strategy with a unified RL stage. The RL formulation draws directly on T2I-R1 [32] for the GRPO algorithm and reward model ensemble (CLIP-H, HPSv2, Unified-Reward-7B, ORM), but the key departure is reformulating image editing as a general image generation task so that both tasks share the same reward models under a single RL schema. The Edit Instruction Alignment stage is a novel lightweight Post-SFT intervention that trains the model to predict a textual description of the desired output image, addressing a gap in instruction comprehension that weakens RL learning signals for editing.

## Why It Matters / Open Questions

The practical significance lies in demonstrating that a 7B open-source unified MLLM can match or exceed proprietary models (GPT-Image-1) on image editing without external diffusion backends, and that a single shared-reward RL pipeline can jointly improve generation and editing without task-specific reward modeling. The ablation showing that Edit Instruction Alignment amplifies RL gains (0.21 → 0.38 on ImgEdit) provides a reusable recipe for practitioners facing weak reward signals in editing. Open limitations include poor text rendering (due to the lightweight discrete detokenizer) and visual inconsistency in edits, both of which the authors suggest could be addressed by integrating diffusion-based components or dedicated consistency rewards—directions left for future work.

## Problem

Existing vector image steganography methods suffer from limited embedding capacity and introduce detectable modifications to file structure, while generative steganography has been explored only for pixel-domain images. No prior work has combined the high capacity and controllability of generative models with the compactness and lossless scalability of vector representations for covert communication.
![Teaser figure](../imgs/CVPR20263254/cropped_page2_idx0.webp)

## Input / Output

The sender supplies a text prompt and a random seed to a latent diffusion model (256×256 raster output), which is then deterministically vectorized by VTracer into an SVG. The secret message is encoded by perturbing the control points of selected cubic Bezier curves, with coordinates constrained to exactly k decimal places (e.g., 8) to preserve file size. The receiver regenerates the identical base SVG from the shared prompt and seed, then recovers the message by computing per-control-point coordinate differences against the received stego SVG.

## Method

GVIS is a training-free pipeline that chains a deterministic latent diffusion model with VTracer raster-to-vector conversion to produce a reproducible SVG carrier. A lightweight overlap detection algorithm (Algorithm 1) identifies cubic Bezier curves whose control points are safe for perturbation, excluding curves that fully or partially coincide with other curves to avoid steganalytic vulnerabilities. The secret message is encoded by mapping bits to quantized perturbation length (over [0, L_Max]) and perturbation angle (over [0°, 360°)) applied to the two interior control points P₁ and P₂ of each selected curve, while endpoints remain fixed. An invertible-point constraint ensures that after quantization to k decimal places, the perturbed coordinates still decode back to the original message bits, guaranteeing 100% extraction accuracy. Theoretical analysis shows the expected curve deviation scales as (3/35)·r², confirming that small perturbation radii keep visual distortion negligible.

## Results

On CelebA-HQ, GVIS achieves SSIM 0.9999, PSNR 67.87 dB, 100% extraction accuracy, and 88,878 bits of embedding capacity. On LSUN-Bedrooms, it reaches SSIM 1.0000, PSNR 69.50 dB, 100% accuracy, and 66,830 bits. GVIS outperforms all vector-based baselines on PSNR by 4–10 dB and on capacity by 1.4×–13.5×, while maintaining a file size (519.99 KB) essentially identical to the original SVG (520.79 KB).

## Baselines & Comparisons

GVIS dominates all six baselines on both PSNR and embedding capacity. Against the strongest vector baseline StegoSVG [3], GVIS improves PSNR from 57.75 to 67.87 dB (+10.1 dB) on CelebA-HQ and from 58.09 to 69.50 dB (+11.4 dB) on LSUN-Bedrooms, while increasing capacity from 48,000 to 88,878 bits (1.85×) and from 41,923 to 66,830 bits (1.59×). Compared to StegoBIT [13], GVIS achieves 4 dB higher PSNR and 13.5× greater capacity on CelebA-HQ (88,878 vs 6,590 bits). Against svgsteg [11], GVIS gains 6.2 dB PSNR and 1.9× capacity on CelebA-HQ. All three pixel-based methods (DwtDctSvd, RivaGAN, RoSteALS) are far outperformed, offering only 32–100 bits of capacity and 31–40 dB PSNR. Notably, GVIS also preserves file size (519.99 KB vs 520.79 KB original), whereas StegoSVG inflates the file to 1,485.24 KB (2.85×) and StegoBIT to 799.21 KB (1.53×).

## Relation to Prior Work

GVIS sits at the intersection of two established research threads: generative steganography (which embeds messages during image synthesis via diffusion, GAN, or flow models) and vector image steganography (which perturbs SVG/Bezier parameters in existing files). It departs from prior generative steganography by targeting vector rather than pixel carriers, and from prior vector steganography by generating the carrier from scratch via a deterministic diffusion model plus VTracer rather than modifying a pre-existing SVG. The overlap detection algorithm and the closed-form MSE analysis for Bezier control-point perturbation are new contributions that address steganalysis risks specific to the vector medium.

## Why It Matters / Open Questions

By demonstrating that a fully training-free pipeline (fixed-seed diffusion → deterministic vectorization → quantized Bezier perturbation) can embed ~89 K bits at 100% accuracy while preserving file size and evading standard pixel-domain steganalysis, GVIS opens a practical niche for covert communication in compact, resolution-independent media. Key limitations include reliance on a shared secret seed (vulnerable to key compromise), a passive-adversary threat model, and dependence on the exact reproducibility of the diffusion + VTracer pipeline. Open questions include robustness to active adversaries who can resample or re-vectorize, extension to animated or layered SVGs, and whether the approach generalizes beyond the two datasets tested.

## Problem

Commercial text-to-image models are distributed under restrictive licenses, but enforcing these licenses requires detecting when a fine-tuned derivative is being served through an API. Existing watermarking methods require pre-deployment model access, and prior fingerprinting approaches rely on white-box or gray-box signals (weights, activations, diffusion trajectories) that commercial APIs do not expose, leaving the query-only black-box setting largely unsolved.

## Input / Output

The method takes 42 compositional underspecified text prompts (e.g., 'a dangerous urban nocturnal animal') as queries to the suspect model's generation API, producing 30 images per prompt (1,260 total per model, ~$50 in API cost). Each generated image is classified via CLIP zero-shot into a predefined set of subordinate semantic categories, yielding a categorical probability vector. The final output is a Bayesian attribution decision: a posterior probability with 95% credible interval over which of K base model families the suspect derives from, evaluated against both a significance threshold (1/K) and a dominance threshold (50%).

## Method

CSF reframes T2I models as semantic category generators rather than pixel synthesizers, probing them with compositional underspecified prompts whose joint conditions are rare in fine-tuning data. This exploits the same robustness principle as backdoor watermarks: fine-tuning updates behavior on common training conditions but leaves responses to rare compositional conditions intact, preserving the base model's semantic biases. For each prompt, N=30 stochastic generations are classified into categorical distributions via CLIP zero-shot, and suspect–base model similarity is measured by the 2-Wasserstein distance between empirical distributions of categorical vectors in the probability simplex. Evidence across all 42 prompts is aggregated through a Beta-Binomial Bayesian model, yielding a posterior over attribution accuracy with quantified uncertainty. The design grants IP owners an asymmetric advantage: new rare prompt compositions can be constructed at detection time, while an attacker would need to suppress an exponentially large space of possible attribute combinations.

## Results

Across 13 fine-tuned variants spanning 6 base model families (FLUX, Kandinsky, SD1.5, SD2.1, SD3, SDXL), all variants satisfy the Dominance test (posterior 95% CI lower bound > 0.5), with posterior means ranging from 0.659 (SD1.5-DreamShaper) to 0.977 (multiple variants). The Wasserstein-distance-based CSF attribution outperforms the JSD baseline by 13.7–54.5 percentage points in attribution confidence (e.g., Kandinsky-Naruto: 97.7% vs. 43.2%). In a human study, CSF prompts yield 71% identification accuracy versus 15.3% (below the 33.3% chance level) for naive LAION-2B prompts.

## Baselines & Comparisons

The paper does not benchmark against prior black-box fingerprinting methods directly (none exist for the query-only setting), but includes two internal comparisons. First, Wasserstein distance (CSF) is compared against Jensen-Shannon divergence as the distributional metric: Wasserstein consistently yields higher attribution confidence, with gaps of +15.9% (Flux-LoRA), +54.5% (Kandinsky-Naruto), +13.7% (SD3-Reality-Mix), and +27.2% (SDXL-DPO). Second, in a human 'Name That Dataset' study, CSF compositional prompts achieve 71% identification accuracy, while naive prompts sampled from LAION-2B score 15.3%—18 percentage points below the 33.3% three-way chance level—demonstrating that compositional underspecification is essential for perceptually interpretable attribution. Additionally, under post-hoc concept removal via Unified Concept Editing (UCE), attribution scores drop modestly (e.g., Flux-LoRA from 0.932 to 0.714) but all variants remain correctly attributed, indicating robustness to targeted semantic erasure.

## Relation to Prior Work

This paper repurposes the robustness principle from backdoor watermarking—rare input conditions survive fine-tuning because they receive little update signal—but redirects it from visual triggers to compositional semantic prompts, eliminating the need for pre-deployment model modification. It departs from existing fingerprinting methods (weight-distance, representation-kernel, classifier-based) that all require white-box or gray-box access, by reducing the problem to text-to-category inference via CLIP zero-shot classification and Wasserstein distance over categorical distributions. The Bayesian attribution framework with dominance testing is a novel statistical layer on top of this semantic fingerprint, and the underspecification literature from linguistics provides the theoretical grounding for why ambiguous compositional prompts reveal model-specific interpretive biases.

## Why It Matters / Open Questions

This is the first method that makes IP attribution feasible in the most realistic commercial threat model—query-only API access to a fine-tuned T2I model—without any pre-deployment intervention, which is critical given that major models (FLUX, SDXL Turbo) are already distributed under restrictive licenses. The asymmetric advantage (defenders can generate new rare compositions post-deployment while attackers face an intractable combinatorial space) is a meaningful strategic property for IP owners. Open questions include whether the 42-prompt protocol generalizes to closed-source models with rate-limited APIs, whether adversarial fine-tuning specifically targeting semantic biases (beyond standard DPO) could degrade the fingerprint, and whether the CLIP-based categorical extraction introduces a ceiling on discriminability for architecturally similar families (SD1.5 vs. SD2.1).

## Problem

Existing lip-based visual speaker authentication (VSA) systems rely on fixed, limited prompt sets, making them vulnerable to replay attacks, and expanding the prompt set requires retraining with additional user recordings. Content-agnostic VSA methods avoid this constraint but fail to capture the fine-grained, speaker-specific dynamic lip movements that are critical for distinguishing individuals and resisting DeepFake forgeries.
![Teaser figure](../imgs/CVPR20260856/cropped_page0_idx0.webp)

## Input / Output

The system takes a lip-region video sequence (100×50 pixels, cropped via Dlib facial landmarks) and a text prompt that the user must speak aloud. A Visual Forced Aligner segments the video into viseme-level units based on the prompt text, and two adjacent visemes form a 'dynamic lip-print' clip. The output is a fused authentication score (weighted combination of local viseme-level PLDA scores and a global cosine similarity score) that yields a binary accept/reject decision against the claimed identity.

## Method

The proposed framework uses a two-branch architecture. The local branch employs a Multi-Layer Dynamic-Enhanced Encoder (MD-Encoder) built on ResNet18, which computes frame-to-frame differences at each layer, processes them through Diff Encoders (residual conv blocks), and concatenates the resulting multi-scale dynamic features with stochastically-dropped static features (50% dropout) to preserve identity cues while emphasizing motion. A Visual Forced Aligner segments the feature sequence into viseme units, and pairs of adjacent visemes (144 possible combinations from 12 viseme categories) are processed by Temporal Integration Modules (TCN + Attentive Statistics Pooling) trained with AAM-Softmax for identity and cross-entropy for content prediction. A Subspace Learning Module applies per-viseme-combination PLDA to project features into content-specific discriminative subspaces. The global branch uses a modified 3D ResNet to capture sentence-level identity. During enrollment, the top-5 most discriminative viseme combinations are selected as user-specific dynamic lip-prints, enabling prompt set expansion by designing new sentences containing those lip-prints without any retraining.

## Results

Under the user-specific-prompts setting (Table 2), the proposed Lip-print method achieves near-perfect authentication: on VSA it reaches AUC 1.0000 / HTER 0.1% against human imposters and AUC 0.9988 / HTER 0.5% against LipSync forgeries; on GRID it attains AUC 1.0000 / HTER 0.1% (human) and AUC 0.9998 / HTER 0.2% (LipSync). Under the unified-prompts protocol (Table 1), Lip-print still leads with AUC 0.9999 / HTER 0.2% on GRID (human) and AUC 0.9951 / HTER 2.7% on VSA (FaceSwap). On the TCD-TIMIT expandable-prompt-set scenario (Table 5), Lip-print achieves HTER 0.8–1.9% across all attack types, outperforming the next-best method (TDVSA-Net) by 0.4–2.1 percentage points.

## Baselines & Comparisons

The proposed Lip-print method outperforms all three baselines across every dataset, attack type, and evaluation scenario. Against AVLip [18] (visual-only component), the gap is most dramatic on GRID under synthetic attacks: Lip-print achieves HTER 0.5% with FaceSwap versus AVLip's 28.1%, and 0.2% with LipSync versus 45.2%, indicating AVLip's global features are highly vulnerable to forgeries. Against Siamese [16], Lip-print consistently improves HTER by 0.5–2.5 points on VSA and 0.7–27 points on GRID, with the largest margin on LipSync (0.2% vs. 27.2% on GRID). Against TDVSA-Net [11], which decouples content and identity, Lip-print reduces HTER by 0.4–2.1 points on TCD-TIMIT (e.g., 0.8% vs. 1.2% human, 1.9% vs. 4.0% LipSync) and by 0.5–7.5 points on VSA/GRID under user-specific prompts. Notably, TDVSA-Net cannot report AUC due to its layered voting mechanism, limiting direct comparability, but its HTER is uniformly higher than Lip-print's across all settings.

## Relation to Prior Work

This paper extends the visual speaker authentication (VSA) literature by introducing visemes as the fundamental analytical unit, a granularity between the word-level methods (e.g., Siamese, AVLip) and sentence-level approaches (e.g., TDVSA-Net) that prior work has used. It repurposes PLDA from speaker verification and TCN/ASP from lip-reading into a two-branch architecture that combines local viseme-level dynamic lip-prints with global sentence-level features. The multi-layer frame-difference encoder is a new architectural contribution addressing the data-scarcity problem inherent in short viseme segments, while the random-prompt security paradigm builds on Liao et al.'s earlier work but generalizes it from fixed word sets to open-ended content via viseme combinations.

## Why It Matters / Open Questions

The prompt-set scalability property—designing new authentication prompts without collecting additional user recordings or retraining—addresses a practical deployment bottleneck that limits the security of current VSA systems against replay attacks. The viseme-level framing also opens a path toward content-agnostic yet identity-specific authentication, potentially reducing the number of enrollment samples needed. Limitations include reliance on a Visual Forced Aligner trained per dataset, a fixed 12-viseme taxonomy, and evaluation on relatively small speaker sets (33–63 speakers); robustness to entirely novel DeepFake generators and real-world deployment (occlusion, variable lighting, multi-lingual viseme sets) remain open questions.

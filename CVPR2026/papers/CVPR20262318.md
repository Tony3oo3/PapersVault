## Problem

Imitation learning policies struggle in partially observed environments where robots must reason over objects seen in the distant past, such as relocating a microwave door hundreds of steps after first opening it. Existing approaches either process raw image histories (intractable at scale) or lack any explicit memory of previously observed scene state. No prior work directly feeds a dynamically maintained scene graph as input to a neural imitation policy.
![Teaser figure](../imgs/CVPR20262318/cropped_page2_idx0.webp)

## Input / Output

The system consumes RGB-D frames from onboard cameras, a one-shot natural language task description (parsed by an LLM into a list of relevant noun entities), camera intrinsics/extrinsics, and odometry. The LLM is queried only once per task and Grounding DINO runs once per episode; during execution, only lightweight mask propagation (0.19 s/frame) and the diffusion policy (260–285 ms/step) run in the loop. The output is a short-horizon action chunk containing joint angle targets for legs and arms, base velocity commands, and a continuous mode indicator that smoothly switches between locomotion and manipulation.

## Method

The core contribution is a task-relevant scene graph maintained as explicit memory: each node n_i = [e_i, b_i, c_i] stores a DINO-v2 appearance embedding, a 2D bounding box (zeroed when out of view), and a 3D centroid in a world-aligned frame, with relational structure implicitly encoded through the shared coordinate frame rather than explicit edges. Nodes are initialized via Grounding DINO on the first frame, tracked across timesteps with XMem, and augmented with newly detected objects whose mask overlap with existing nodes falls below a threshold. For policy learning, all node embeddings (plus a scene-level root node) are concatenated into a token sequence, processed by a transformer encoder with positional embeddings, and the resulting compact representation conditions a diffusion policy trained with the standard DDPM noise-prediction objective and sampled at test time via DDIM. Ablations show that the 3D centroid and 2D bounding box are critical for later subtasks, confirming that explicit spatial memory—not just object identity—is what enables long-horizon reasoning.

## Results

The paper evaluates on three simulated mobile manipulation tasks (Throw Trash ~100 steps, Heat-up Tea ~300 steps, Heat-up Tea Long ~1000 steps) and four real-world tabletop tasks (Pineapple-Bowl, Feed-Animals, Feed-Giraffe, Clean-Table), reporting success rates as stacked bar plots of subtask completion. The method substantially outperforms all baselines, with the performance gap widening on later subtasks that require remembering previously observed object states. Ablations confirm that removing 3D centroids or all spatial location information causes sharp drops in later-subtask success while leaving the first subtask largely unaffected, highlighting the critical role of explicit spatial memory for long-horizon reasoning.

## Baselines & Comparisons

The paper compares against three baselines: (1) RGB, a vanilla diffusion policy using raw camera images and proprioception; (2) Visible-Objects, which uses object-centric representations but only from the current camera view (no memory); and (3) PTP [52], which increases history frames from 1 to 10 and predicts both past and future actions. The proposed scene-graph method wins on all tasks, with the largest gaps on memory-dependent subtasks. On Feed-Animals, RGB and Visible-Objects pick a random fruit regardless of the target animal, while the scene-graph method correctly retains initial visual context. PTP improves short-horizon reasoning (e.g., first subtask) but fails to address fundamental long-horizon challenges, as it cannot recover object states hundreds of steps later. Visible-Objects outperforms RGB on grasping/placement accuracy (consistent with prior object-centric work), but both still misplace objects when the target is out of view. On Clean-Table, memory-less policies prematurely close the drawer or leave objects behind, whereas the scene-graph method reliably tracks which items have been cleared.

## Relation to Prior Work

This paper extends Diffusion Policy (Chi et al., 2023) by conditioning it on a dynamically maintained, task-relevant 3D scene graph rather than raw RGB frames, and adopts the LLM-based task-relevant object enumeration strategy from Qian et al. (2024). It departs from prior scene graph work (CLIO, ConceptGraphs, SceneGraphFusion) that uses graphs for planning, navigation, or mapping by directly encoding the graph as a token sequence into a neural policy's transformer encoder. Unlike prior memory-augmented imitation learning approaches (PTP's increased history frames, ControlNet-based state injection), the scene graph is an explicitly constructed, discretized, and incrementally updated representation rather than a learned compression of raw observations.

## Why It Matters / Open Questions

The paper demonstrates that a compact, interpretable, task-driven scene graph can serve as an effective explicit memory for imitation policies in partially observed, long-horizon settings, addressing a key gap where prior methods either ignore history or rely on raw frame stacking. The ablations showing that spatial location information (3D centroids, 2D boxes) is critical specifically for later subtasks but not the first provide useful design guidance. Limitations include dependence on accurate object detection/tracking, potential fragility in highly cluttered or dynamically changing environments, and the current shallow graph structure (single-level scene root + object nodes) that may not capture richer relational hierarchies. The authors position scene graphs as a promising interpretable memory mechanism for future vision-language-action models, suggesting broader applicability beyond the tested tasks.

## Problem

Existing open-vocabulary remote sensing image segmentation (OVRSIS) methods focus almost exclusively on enhancing visual representations while overlooking textual ambiguity: naive class names like 'background' carry different meanings across tasks, and synonymous prompts (e.g., 'cropland' vs. 'agricultural') yield substantially different segmentation results. This paper identifies this textual ambiguity as a critical, previously unaddressed bottleneck limiting OVRSIS performance.

## Input / Output

The method takes a remote sensing image (resized to 448 px long side, processed via 224×224 sliding windows at 112 px stride) and a set of N context-aware text descriptions per category (default N=5, generated offline by Gemini using a task-driven prompt that includes dataset description and visual-feature diversity constraints). It outputs a pixel-level semantic segmentation mask over K arbitrary categories. The approach is plug-and-play: all original model parameters are frozen, and only a small prompt-bias parameter matrix α ∈ [0,1]^{KN} is optimized at test time (3 Adam steps), making it directly integrable into existing OVRSIS pipelines such as SegEarth-OV, CASS, or ClearCLIP.

## Method

TMPA comprises two components. First, Cat-Prompt constructs a structured LLM prompt (system prompt + dataset description + visual-feature diversity constraint) to generate N diverse, scene-aware textual descriptions per category, replacing ambiguous single-word class names. Second, VGTA performs test-time adaptation by computing per-pixel prediction entropy, selecting Top-n lowest-entropy pixels per predicted class as high-confidence visual features, and constructing a prompt bias as their category-wise mean. This bias is injected into the pre-generated text embeddings via a learnable, zero-initialized weight matrix α, and α is optimized by minimizing a pixel-level entropy loss over the upsampled visual features. The calibrated text embeddings are then matched against visual features via cosine similarity to produce the final mask. The key insight is that high-entropy (uncertain) regions correspond to visual-text misalignment, and anchoring text prompts to high-confidence visual features from the same image adaptively resolves this misalignment without any labeled data.

## Results

On 8 multi-class remote sensing segmentation benchmarks, TMPA achieves 43.7% average mIoU, outperforming the strongest training-free baseline SegEarth-OV (39.1%) by 4.6% and the best training-based method CASS (37.4%) by 6.3%. The largest single-dataset gain is on Vaihingen, where TMPA reaches 43.4% mIoU versus 29.1% for SegEarth-OV (+14.3%). On 9 single-class extraction datasets, TMPA improves SegEarth-OV by 3.9% (building), 2.4% (road), and 5.8% (flood) at 448×448 resolution, with gains widening to 5.5%, 3.7%, and 8.6% at 896×896 resolution.

## Baselines & Comparisons

TMPA outperforms all nine baselines across every reported dataset. Against the primary training-free baseline SegEarth-OV [31], TMPA gains 4.6% average mIoU, with the largest margin on Vaihingen (+14.3%) and iSAID (+4.5%). Among training-free OVSS methods, CASS [27] is the closest competitor at 37.4% average mIoU, yet TMPA still leads by 6.3% and by 9.9% on Vaihingen specifically. MLMP [44], which applies test-time adaptation to natural-image OVSS, trails TMPA by 10.6% on average, underscoring the domain gap between natural and remote sensing imagery. Training-based OVRSIS methods OVRS [7] and RSKT-Seg [30] achieve high iSAID scores (93.3% and 93.2%) due to supervised training on that dataset, but collapse to 17–28% mIoU on open-vocabulary benchmarks, where TMPA leads by 10–38%. On single-class extraction (Table 2), TMPA consistently beats SegEarth-OV by 1.4–8.6% IoU depending on task and resolution, and surpasses CASS [27] by up to 18.5% on WHU Aerial building extraction.

## Relation to Prior Work

This paper builds directly on SegEarth-OV, a training-free OVRSIS method that uses CLIP with a feature upsampler, and positions itself as addressing a gap that all prior OVRSIS methods (OVRS, RSKT-Seg, SegEarth-OV) share: an exclusive focus on enhancing visual representations while neglecting the text side. It also draws on the broader OVSS literature (CASS, ClearCLIP, SCLIP) and test-time adaptation work (TPT, CLIPArTT, MLMP), but departs by arguing that textual ambiguity—synonymy and polysemy in class names—is a first-order bottleneck in OVRSIS. The plug-and-play design explicitly targets integration with any existing OVSS backbone rather than proposing a new end-to-end architecture.

## Why It Matters / Open Questions

By reframing text prompt quality as a major performance limiter (not just visual representation), the paper opens a new axis of improvement for OVRSIS that is orthogonal to and composable with visual-side enhancements. The plug-and-play nature and consistent gains across 17 datasets and three different base methods (SegEarth-OV, CASS, ClearCLIP, SCLIP) make it practically adoptable. However, the reliance on an external LLM (Gemini) for prompt generation introduces a dependency and cost, and the test-time adaptation is limited to 3 optimization steps on a single image, raising questions about scalability to very large scenes or streaming inference. Whether the text-ambiguity bottleneck is as critical in natural-image OVSS as in remote sensing remains an open question the authors only briefly address in supplementary results.

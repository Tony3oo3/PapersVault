## Problem

Existing 3D layout-conditioned image generation methods either represent scenes as depth maps of bounding boxes or as stacks of 2D object layers, both of which fail to capture true 3D occlusion geometry. This leads to incorrect inter-object occlusions, inconsistent depth ordering, and limited orientation control in multi-object scenes. The paper identifies occlusion reasoning as a fundamental yet overlooked requirement for accurate 3D-aware generation.

## Input / Output

The method takes a set of 3D bounding boxes (position, size, orientation) in a virtual scene, a text prompt describing the objects, and a camera viewpoint as input, and produces a photorealistic image where objects adhere to the specified 3D layout with correct occlusions and perspective. The 3D layout is consumed via a rendered OSCR image (translucent color-coded boxes from the specified camera), which is encoded through a VAE into spatial tokens. For personalization, an additional reference object image is encoded into appearance tokens and bound to a specific box via the same attention masking mechanism.

## Method

The core contribution is OSCR, a scene representation where each object is a translucent 3D bounding box with color-coded faces (encoding orientation), rendered from a user-specified camera viewpoint so that occluded regions remain partially visible. The rendered OSCR image is encoded via VAE into tokens that are concatenated with text prompt tokens and noisy image tokens, then jointly processed by FLUX's multimodal DiT blocks. A LoRA adapter is trained only on the attention projections associated with OSCR tokens, preserving the base model's text-to-image prior. A key mechanism is attention masking: OSCR tokens within each object's rendered segmentation mask are restricted to attend only to that object's noun tokens in the prompt, preventing attribute mixing across objects. Training uses a synthetic Blender dataset of 25K rendered scenes plus 25K depth-to-image augmentations, filtered to ensure strong inter-object occlusions.

## Results

On the 3DOcBench benchmark (500 samples), SeeThrough3D achieves the best score across all five evaluation metrics. The most striking gain is in angular error (47.92° vs. 89.63°–92.73° for all baselines), reflecting the color-coded face encoding in OSCR. KID drops to 5.43×10⁻³, more than 2× lower than the best baseline (LaRender, 13.46×10⁻³), indicating substantially higher image fidelity. Depth ordering reaches 1.46 (vs. 1.02 for LaRender) and CLIP objectness score reaches 22.86 (vs. 21.83), confirming superior 3D layout adherence and object placement accuracy.

## Baselines & Comparisons

SeeThrough3D outperforms all four baselines on every metric. Against the 3D layout control methods, LooseControl (depth-map conditioning) fails to represent occluded objects and places objects at incorrect locations (objectness 20.02, angular error 89.88°), while Build-A-Scene (iterative generation-inversion) improves layout adherence but introduces inversion artifacts that degrade image quality (KID 20.12, the worst of all methods). Against the occlusion control methods, LaRender (2D layer decomposition) achieves the strongest baseline performance (depth ordering 1.02, objectness 21.83) but still cannot distinguish 'behind' from 'on top of' due to its flat 2D representation, and its angular error (89.63°) is nearly double that of SeeThrough3D (47.92°). VODiff, the weakest baseline, scores lowest on depth ordering (0.68) and objectness (19.70). The largest absolute gaps are in angular error (~42° improvement over the best baseline) and KID (~8×10⁻³ improvement), highlighting that OSCR's translucent 3D boxes with color-coded faces provide both orientation and image-quality advantages that 2D or depth-map representations cannot match.

## Relation to Prior Work

This paper builds on FLUX, a DiT-based flow-matching text-to-image model, and follows the recent paradigm of conditioning DiT architectures via additional token streams (as in OminiControl, EasyControl). It departs from prior 3D layout control methods (LooseControl, Build-A-Scene) that condition on depth maps of 3D bounding boxes, and from occlusion control methods (LaRender, VODiff) that decompose scenes into flat 2D object layers, by introducing OSCR—a representation that renders translucent, color-coded 3D boxes from a specified camera viewpoint to jointly encode occlusion, orientation, and camera pose. The attention-masking mechanism for binding objects to their boxes is inspired by cross-attention alignment strategies but applied specifically to the spatial OSCR tokens rather than to segmentation maps.

## Why It Matters / Open Questions

SeeThrough3D is the first method to explicitly model inter-object occlusions in 3D layout-conditioned generation, closing a gap the authors identify as fundamental yet overlooked. The introduction of 3DOcBench provides a much-needed benchmark with challenging occlusion scenarios and diverse viewpoints, which the authors commit to releasing. The attention visualization revealing that the base model already encodes occlusion boundaries in its latent space suggests OSCR acts as a lightweight 'key' to unlock existing priors rather than teaching new reasoning. A stated limitation is the lack of image consistency under layout changes, pointing toward future integration with editing-based techniques.

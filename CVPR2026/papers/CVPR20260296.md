## Problem

Visual Autoregressive (VAR) models generate images across 10 coarse-to-fine scales, but each scale must retain all prior tokens in the KV cache, causing memory to grow quadratically with resolution and limiting practical deployment. Existing acceleration strategies either sacrifice generation fidelity (distillation, token pruning) or require deploying multiple independent models (CoDe), introducing system complexity. The paper asks whether a single model can support flexible depth adjustment across scales without multi-model overhead.
![Teaser figure](../imgs/CVPR20260296/cropped_page2_idx0.webp)

## Input / Output

The model takes a single class label as input and produces a 256×256 RGB image through 10 next-scale prediction steps, where each step concurrently predicts all spatial tokens at that resolution. A key operational detail is that the active network depth (2, 4, 8, 16, or 30 layers) is a runtime-selectable hyperparameter: early scales (r1–r6) always execute the full 30-layer network, while later scales (r7–r10) use the chosen subnet, enabling zero-cost depth switching without reloading weights.

## Method

VARiant constructs a supernet by equidistantly sampling layer subsets (e.g., 16 of 30 layers) from a pretrained VAR-d30, so all depth configurations share one parameter set. The key architectural insight is a scale-depth asymmetric dependency: early scales establishing global semantics are extremely sensitive to depth reduction (FID degrades >20 at 50% depth), while later scales refining local textures tolerate shallow subnets (FID change <4). To resolve the optimization conflict inherent in weight sharing—where training only subnets degrades the full network and vice versa—the paper introduces a three-phase progressive training schedule: Phase 1 jointly trains at a 2:8 subnet:full ratio to build a parameter foundation, Phase 2 linearly ramps the subnet ratio from 20% to 100%, and Phase 3 focuses exclusively on subnet refinement. This dynamic-ratio strategy breaks through the Pareto frontier of any fixed sampling ratio, achieving near-optimal FID for both the full network (1.96) and the 16-layer subnet (2.05) simultaneously.

## Results

On ImageNet 256×256 class-conditional generation, VARiant-d16 achieves FID 2.05 (vs. VAR-d30's 1.95) with 1.7× inference speedup and 40% KV-cache memory reduction, while VARiant-d8 reaches FID 2.12 with 2.6× speedup and 65% memory savings. The extreme-efficiency VARiant-d2 configuration achieves 3.5× speedup and 80% memory reduction at a moderate quality cost (FID 2.97). All configurations use a single 2.0B-parameter model with zero-cost runtime depth switching, compared to CoDe's dual-model (2.0B+0.3B) architecture.

## Baselines & Comparisons

Against the original VAR-d30 (FID 1.95, 3.62 s, 39.3 GB), VARiant-d16 achieves near-equivalent quality (FID 2.05) while cutting KV-cache memory by 44% and accelerating inference by 1.7×; VARiant-d8 pushes further to FID 2.12 with 65% memory savings and 2.6× speedup. Against the training-based acceleration method CoDe (dual 2.0B+0.3B model, FID 2.27, 19.9 GB), VARiant-d4 matches quality (FID 2.28) with slightly less memory (19.6 GB) and a single-model footprint, while VARiant-d8 clearly wins on quality (FID 2.12 vs. 2.27) at comparable memory (20.8 GB). VARiant-d2 substantially reduces memory to 18.9 GB (vs. CoDe's 19.9 GB) at a higher FID cost (2.97). A key architectural advantage is that VARiant's single 2.0B model supports zero-cost runtime depth switching, eliminating CoDe's dual-model deployment complexity and the extra 0.3B parameter storage.

## Relation to Prior Work

This paper builds directly on VAR (Tian et al., NeurIPS 2024), which reformulated autoregressive image generation as next-scale prediction, and addresses its key deployment bottleneck: cumulative KV-cache memory across scales. It departs from CoDe (Chen et al., CVPR 2025), which achieves similar scale-wise depth scheduling but requires deploying two independent models, by instead constructing a single supernet with shared weights and equidistant layer selection. The progressive training strategy is positioned against fixed-ratio joint training of subnets, which the authors show is fundamentally limited by a Pareto frontier between full-network and subnet quality.

## Why It Matters / Open Questions

The single-model, zero-cost runtime depth switching offers a practically attractive deployment story for VAR-based systems (e.g., embodied agents, real-time monitoring) where memory and latency budgets vary. The scale-depth asymmetric dependency observation provides a principled, reusable heuristic for where depth reduction is safe in multi-scale generative pipelines. Key limitations include training only one subnet depth alongside the full network (rather than a family of subnets), the need for manual phase-boundary selection in progressive training, and evaluation restricted to ImageNet-256; whether the approach generalizes to higher resolutions, other multi-scale architectures, or text-to-image settings remains open.

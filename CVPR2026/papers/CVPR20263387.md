## Problem

Existing GUI agent benchmarks focus on automating closed-ended tasks from expert instructional videos, overlooking how novice users actually behave in open-ended creative and analytical workflows—exploring, iterating, getting confused, and revising goals. This paper asks whether current multimodal LLMs can perceive a user's behavioral state, infer their immediate intent, and decide when and how to provide assistance, using only visual screen cues without access to the user's speech.
![Teaser figure](../imgs/CVPR20263387/cropped_page0_idx0.webp)

## Input / Output

Each evaluation instance consists of 32 uniformly sampled frames from a video segment (no audio), optionally augmented with the segment's behavior state label and/or inferred intent label as textual context. The model must produce three outputs: a 9-way behavior state classification, a 4-way multiple-choice intent prediction, and a binary help-need decision plus a 4-way multiple-choice help-content prediction. The dataset spans 67.5 hours of screen recordings from 120 novice users across 10 applications (Photoshop, Figma, PowerPoint, Premiere Pro, Excel, etc.), with think-aloud narrations used solely as an annotation source rather than model input.

## Method

GUIDE introduces a three-stage evaluation framework (Understanding → Reasoning → Assisting) built on a novel 9-state behavior taxonomy organized into four cognitive phases (Planning, Execution, Problem-Solving, Evaluation), developed through a human-AI collaborative process that merged author-derived categories with LLM-generated ones and validated them against the full dataset. Annotations were generated by prompting Gemini-2.5-Pro on narration-aligned video segments, then verified by human annotators (96.1% agreement for behavior states; 88.68% and 78.89% retention for intent and help labels respectively), yielding 1.8K, 1.3K, and 1K balanced instances. Eight state-of-the-art MLLMs are evaluated zero-shot under three context conditions (video-only, video+behavior, video+behavior+intent), with an additional online setting where models receive progressively more frames (25%–100% of the segment) to simulate proactive assistance. Performance is measured via accuracy and multi-binary accuracy (MBAcc), the latter requiring correct discrimination across all pairwise comparisons against distractors.

## Results

Across eight state-of-the-art MLLMs evaluated zero-shot on GUIDE, all models struggle substantially: the best Behavior State Detection accuracy is only 44.61% (Claude-4.5-Sonnet), and the best Help Content Prediction accuracy is 55.00% (also Claude-4.5-Sonnet). Intent Prediction is the most tractable task, with Claude-4.5-Sonnet reaching 71.39% and Gemini-2.5-Pro at 67.80%, though multi-binary accuracy drops by 5–15 points for most models. Providing structured user context (behavior state + intent) yields dramatic gains on Help Prediction, with the largest improvement of +50.2 pp in Help Content Prediction for InternVideo2.5-8B (23.67% → 73.86%) and +42.46 pp in Help Need Detection F1 for GPT-4o (47.73 → 90.19).

## Baselines & Comparisons

Claude-4.5-Sonnet leads on Behavior State Detection (44.61%), Intent Prediction (71.39%), and Help Content Prediction (55.00%), but trails Gemini-2.5-Pro on Help Need Detection (39.49% vs. 69.82% accuracy; F1 16.19 vs. 77.42), where Gemini-2.5-Pro is the clear winner. GPT-4o shows the strongest Help Need Detection under context augmentation (87.91% accuracy, 90.30 F1 with behavior + intent), surpassing all other models in that setting. The open-source 8B models (Qwen3-VL-8B, InternVideo2.5-8B, InternVL3-8B) consistently underperform the proprietary models by 15–30 pp on Behavior State Detection and 20–30 pp on Help Content Prediction. Notably, Claude-4.5-Sonnet exhibits an extreme precision-recall imbalance on Help Need Detection (precision 87.69% but recall only 8.92%), meaning it almost never predicts 'help needed,' while Gemini-2.5-Pro achieves a more balanced profile (precision 76.42%, recall 78.09%). Adding behavior state and intent context narrows the gap between models on Help Prediction, with the smallest models (InternVideo2.5-8B, InternVL3-8B) gaining 40–50 pp, suggesting that structured context partially compensates for weaker visual reasoning.

## Relation to Prior Work

This paper departs from the dominant GUI video understanding paradigm (PsTuts, VideoGUI, UI-Vision, WorldGUI, AssistGUI), which evaluates models on replicating expert actions for closed-ended task automation, by reframing the problem around understanding novice users in open-ended workflows. It also draws on the HCI literature on proactive and collaborative agents (CowPilot, CodeCollaborator, ProactiveVA, ProMemAssist), which has established the value of context-aware, timely assistance but has not provided a systematic video-based evaluation benchmark. The behavior state taxonomy is grounded in Norman's Seven Stages of Action and Bloom's cognitive hierarchy, bridging interaction theory with multimodal video understanding in a way prior GUI benchmarks have not attempted.

## Why It Matters / Open Questions

GUIDE is the first benchmark to evaluate MLLMs on the full understanding-to-assistance pipeline (behavior state → intent → help) using authentic novice user recordings, filling a clear gap between task-automation benchmarks and the collaborative agent vision. The finding that structured user context (behavior state + intent) boosts help prediction by up to 50.2 percentage points suggests a practical path: rather than expecting models to infer everything from pixels alone, systems should maintain and leverage layered user state. Open questions include how to reliably detect behavior state in real time (where even the best model reaches only ~45%), how to handle the systematic under-recall of help-needed cases, and whether the taxonomy generalizes beyond the 10 applications studied.

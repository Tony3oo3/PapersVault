## Problem

Reference-guided customized image generation models consistently fail to reproduce fine-grained details (text, logos, small structural elements) accurately in the generated output relative to the reference image. Existing remedies—reference-based super-resolution or instruction-based editing—either leave inconsistencies uncorrected or fail to localize the target regions, and current training datasets emphasize overall object consistency while neglecting subtle local detail alignment.
![Teaser figure](../imgs/CVPR20262186/cropped_page0_idx0.webp)

## Input / Output

The method consumes a reference image (IMG1), a generated image to be corrected (IMG2), and a structured text prompt of the form 'Use the object in IMG1 as a reference to be corrected, replace, or enhance the object in IMG2,' where IMG1/IMG2 are trigger tokens bound to specific images. The agent chain can operate in multi-round mode, where a coordinator (Qwen-Agent) iteratively identifies inconsistent patches, retrieves corresponding reference crops, and invokes the critic model for local correction, allowing users to interactively adjust which regions to regenerate.

## Method

ImageCritic is built on Flux Kontext (a DiT-based editing model) fine-tuned with LoRA on a 10k reference-degraded-target triplet dataset constructed via VLM-based filtering and Flux-Fill degradation to simulate realistic text/logo inconsistencies. Two key modules address the core failure modes: (1) an Attention Alignment Loss that applies binary object masks to the attention maps in the DiT's double-stream layers, explicitly supervising the reference branch to attend to object regions and the input branch to attend to background, thereby decoupling their conflicting spatial cues; (2) a Detail Encoder that concatenates CLIP image embeddings with T5 trigger-word hidden states and projects them through a two-layer MLP, enabling the model to correctly associate each trigger token with its corresponding image. The overall training objective combines the rectified flow-matching loss with the two attention alignment terms, and an agent chain wraps the model for automated multi-round patch-level correction.

## Results

On the proposed CriticBench (300 images of multilingual products and apparel), ImageCritic consistently improves all three consistency metrics across all 8 generation baselines. The largest gains appear on Xverse (+3.4 CLIP-I, +3.1 DINO, −2.9 DreamSim) and MOSAIC (+2.5 CLIP-I, +2.4 DINO, −3.8 DreamSim), while already-strong methods like Qwen-Image and DreamO see smaller but still positive improvements (+0.2–0.5). On DreamBench++, similar consistent gains are observed, with Qwen-Image showing the largest DINO improvement (+3.1) and OmniGen2 the largest DreamSim reduction (−2.3).

## Baselines & Comparisons

ImageCritic is a post-editing correction layer applied on top of 8 existing generation models (both open-source and closed-source), so it does not compete against them but rather augments their outputs. The method achieves consistent positive improvements on all three metrics (CLIP-I, DINO, DreamSim) for every baseline, with no regressions observed. The largest absolute gains occur on Xverse (+3.4 CLIP-I, +3.1 DINO) and MOSAIC (+2.5 CLIP-I, −3.8 DreamSim), suggesting these models produce the most severe fine-grained detail inconsistencies that ImageCritic can repair. In contrast, Qwen-Image (+0.3 CLIP-I, +0.2 DINO) and DreamO (+0.3 CLIP-I, +0.5 DINO) show the smallest improvements, indicating their outputs are already relatively consistent. On DreamBench++, Qwen-Image benefits most in DINO score (+3.1) and OmniGen2 most in DreamSim (−2.3), while the overall pattern of universal improvement holds across both benchmarks.

## Relation to Prior Work

This paper builds on Flux Kontext, a DiT-based in-context image editing model, and positions itself as a post-editing correction layer atop existing reference-guided generation methods (XVerse, DreamO, MOSAIC, OmniGen2, UNO, Qwen-Image). Rather than modifying the generation process, it introduces an attention alignment loss that explicitly supervises attention disentanglement between reference and input branches, and a detail encoder that fuses CLIP image features with T5 trigger tokens—drawing inspiration from PhotoMaker and DreamO. The data curation pipeline departs from prior customization datasets (Subjects200K, UNO-1M, X2I2) by explicitly simulating fine-grained degradation via Flux-Fill, targeting the text/logo inconsistency failure mode that those datasets neglect.

## Why It Matters / Open Questions

The paper addresses a practical and persistent pain point in production image generation: fine-grained detail drift (text, logos, small structural elements) that no current model fully resolves. The post-editing paradigm is complementary rather than competitive with existing generators, making it broadly applicable. However, the evaluation is somewhat limited—CriticBench contains only 300 images, and the agent chain's 75.3% IoU suggests non-trivial localization errors in complex scenes. Open questions include whether the approach scales to multi-object or video settings, and whether the VLM-dependent data curation pipeline generalizes beyond the specific degradation modes (text, logos) it was designed to simulate.

## Problem

Existing feedforward 3D reconstruction models (LRMs) are restricted to a handful of input views due to quadratic attention complexity, and cannot process streaming or long-context observations. While implicit latent-space models achieve strong novel view synthesis, they lack explicit 3D outputs needed for downstream tasks and suffer from slow rendering. No prior method unifies long-context, autoregressive, and explicit 3D reconstruction with linear computational complexity.
![Teaser figure](../imgs/CVPR20263022/cropped_page0_idx1.webp)

## Input / Output

The model consumes posed RGB images (up to 64 views at 512×512 or 1024×1024) concatenated with 9-channel ray embeddings, patchified at 8×8 and tokenized into a sequence. In autoregressive mode, views arrive in causal batches (e.g., 4 at a time) and the internal state updates incrementally. The output is pixel-aligned 3D Gaussian parameters (position, RGB, scale, rotation, opacity) decoded via virtual view tokens, or alternatively a triplane feature grid for NeRF-based rendering; Gaussian positions are recovered by decoding per-pixel depth and unprojecting along known rays.

## Method

tttLRM replaces quadratic self-attention with LaCT (Large Chunk Test-Time Training) blocks that maintain a fixed-size fast-weight matrix W, updated at inference time via Muon optimizer on the input key-value pairs in linear time. A set of virtual tokens (virtual views for 3DGS, learnable triplane features for NeRF) query W through the apply operation to decode explicit 3D representations, decoupling the 3D output format from the backbone. The model is initialized from TTT-LVSM pretrained on novel view synthesis, transferring implicit 3D knowledge into explicit reconstruction. For autoregressive streaming, the update step is made causal so W evolves as new view batches arrive, yielding progressively refined Gaussians. Sequence parallelism shards input tokens across GPUs with DDP-synchronized fast-weight gradients, enabling linear scaling of both training and inference.

## Results

On the scene-level DL3DV-140 benchmark, tttLRM (single model) achieves 25.95 PSNR / 0.844 SSIM / 0.195 LPIPS at 64 input views in 14.8 s, surpassing Long-LRM (24.63 PSNR) by ~1.3 dB and approaching optimization-based Scaffold-GS (27.07 PSNR) while being ~65× faster. At 16 views it reaches 23.60 PSNR, already exceeding all optimization-based baselines (21.20–22.13 PSNR). On the object-level GSO dataset at 512×512 with 8 views, tttLRM achieves 34.02 PSNR in 0.3 s versus GS-LRM's 32.83 PSNR in 0.7 s, and generalizes to 24 views (34.80 PSNR) without retraining.

## Baselines & Comparisons

Against GS-LRM (object-level, Table 1), tttLRM wins on every setting: at 512×512/8 views it gains +1.19 dB PSNR (34.02 vs 32.83) while running 2.3× faster (0.3 s vs 0.7 s); at 24 views the gap widens to +1.54 dB (34.80 vs 33.26) with a 5× speed advantage (1.1 s vs 5.5 s). Against Long-LRM (scene-level, Table 2), tttLRM consistently outperforms by ~1 dB PSNR across 16/32/64 views (e.g., 25.95 vs 24.63 at 64 views on DL3DV-140) and also beats Long-LRM even when the latter is augmented with post-optimization (25.95 vs 24.99 at 32 views). Against optimization-based baselines (3DGS, Mip-Splatting, Scaffold-GS), tttLRM is competitive at 64 views (25.95 vs 27.07 PSNR for Scaffold-GS) but runs in 14.8 s versus 13–16 minutes (~65× speedup); at 16 and 32 views tttLRM actually surpasses all optimization methods in PSNR. A key practical advantage is that tttLRM is a single model generalizing across all view counts, whereas Long-LRM requires a separately trained model for each input-view configuration.

## Relation to Prior Work

tttLRM builds directly on the Test-Time Training (TTT) framework and its Large Chunk variant (LaCT/TTT-LVSM), repurposing the fast-weight memory mechanism—originally designed for long-sequence language modeling—as an implicit 3D scene representation. It departs from attention-based Large Reconstruction Models (GS-LRM, Long-LRM) by replacing quadratic-complexity self-attention with linear-complexity LaCT blocks, enabling 64+ input views and autoregressive streaming. The pretrained TTT-LVSM weights from novel view synthesis serve as initialization, bridging the gap between implicit latent-space NVS models (LVSM, Quark) and explicit 3D outputs (3DGS, triplane NeRF) that prior feedforward LRMs could not achieve at scale.

## Why It Matters / Open Questions

This work demonstrates that a single linear-complexity model can handle long-context (64 views) and autoregressive 3D reconstruction in seconds, a regime where attention-based LRMs hit memory walls and optimization-based methods take minutes. The finding that NVS pretraining transfers effectively to explicit 3D reconstruction (improving both convergence speed and final PSNR) suggests a general recipe for leveraging large implicit models to bootstrap explicit 3D pipelines. Open questions include whether the fixed-size fast-weight memory can scale to very large scenes, how to close the remaining quality gap with purely implicit NVS models, and whether real-time streaming reconstruction is achievable with further architectural refinements.

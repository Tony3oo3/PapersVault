## Problem

Existing model merging methods for text-to-image diffusion models operate on small, fixed sets of pre-provided experts and rely on raw model parameters as input features, making them unable to generalize to the large-scale, heterogeneous, and ever-expanding online expert ecosystem (e.g., Civitai, Hugging Face) where experts differ in fine-tuning strategies, datasets, and architectures. This limits their ability to flexibly address diverse in-the-wild user needs that require varying combinations and numbers of experts without retraining or test-time optimization.

## Input / Output

The framework takes a free-form user text prompt and a pre-constructed universal graph of thousands of online expert models (both full checkpoint-based and LoRA-based PEFT experts) as input. It outputs a set of merging coefficients (edge weights in [0,1] between the user prompt node and selected expert nodes) that are used to construct a merged diffusion model, which then generates the final RGB image. The universal graph is built once and stored locally in a lightweight format (COO for connections, .npz for node/edge features), and new experts can be inserted in ~1.2 minutes without retraining.

## Method

DiffGraph comprises three components: a Graph Construction Agent (GCA) that organizes online experts into a universal graph via node registration (encoding LLM-generated skill descriptions as text-embedding node features) and node calibration (evaluating experts on reference prompts to produce multi-metric quality scores as edge features); an Expert Selection Agent (ESA) that uses GPT-4o to parse user prompts, retrieve relevant CKPT and PEFT experts via text-embedding similarity, and perform LLM-based filtering to finalize a variable-size expert set; and a Merging Planner (MP) that activates a subgraph around selected experts, inserts the user prompt as a temporary node, and uses a VGAE to predict merging coefficients modeled as a Beta distribution. The VGAE is trained with policy gradient (reinforcement learning) to maximize generated image quality, and at test time the expected value of the Beta distribution is used as the deterministic coefficient. The key insight is representing expert capabilities through interpretable text-embedded node features and performance-score edge features rather than raw parameters, enabling the lightweight VGAE to learn a simple mapping from a shared capability space to merging coefficients that generalizes to newly added experts.

## Results

On DABench with SD1.5, DiffGraph achieves IR=73.11, HPS=30.06, AS=6.54, PS=20.62, CS=84.79, substantially outperforming the best baseline DiffAgent (IR=29.94, HPS=27.83). On FLUX, the gains are even more pronounced: DiffGraph reaches IR=136.62, HPS=31.75 on DABench and IR=148.75, HPS=32.36, AS=6.64, PS=21.84 on DiffusionDB, surpassing the next-best method (Model Swarms, IR=104.76 on DABench) by a wide margin. The constrained variant (Ours fixed, using a fixed set of 13 experts without ESA) also outperforms all fixed-set merging baselines (DARE, Diffusion Soup, Model Swarms) on every metric.

## Baselines & Comparisons

DiffGraph wins on every metric across both base models (SD1.5 and FLUX) and both evaluation datasets (DABench and DiffusionDB). The most dramatic gap is on ImageReward: on SD1.5/DABench, DiffGraph scores 73.11 vs. 29.94 for DiffAgent (the strongest single-expert baseline) and 26.51 for AutoLoRA; on FLUX/DABench it reaches 136.62 vs. 104.76 for Model Swarms and 100.20 for DiffAgent. Among the parameter-dependent merging methods (K-LoRA, LoRA.rar, AutoLoRA), all show limited or even negative gains over the Direct baseline on SD1.5, confirming the paper's argument that raw parameter features struggle with heterogeneous online experts. The fixed-set variant (Ours fixed) outperforms DARE, Diffusion Soup, and Model Swarms on all metrics for FLUX, demonstrating the graph-based formulation's advantage even without dynamic expert selection. On HPS and AS, DiffGraph consistently leads by 0.5–2.0 points over the nearest competitor, while CLIP Score gaps are smaller (≤1 point), suggesting the gains are primarily in perceptual quality and human preference rather than text-image alignment.

## Relation to Prior Work

This paper builds on the VGAE architecture (Kipf & Welling, 2016) as the core encoding mechanism for deriving merging coefficients, but departs fundamentally from prior model merging work in its representation strategy. Where parameter-dependent methods (K-LoRA, AutoLoRA, LoRA.rar) operate directly on expert weight matrices, and fixed-set methods (Diffusion Soup, Model Swarms, DARE) merge a small pre-specified group, DiffGraph instead represents each expert through text-embedded skill descriptions (node features) and quantitative quality scores on reference prompts (edge features), organized in a scalable graph. The LLM-powered agents (GCA, ESA) draw on chain-of-thought prompting and text-embedding retrieval to autonomously select a variable number of experts, extending the task from merging a fixed pair or small set to dynamically composing an arbitrary subset from a large evolving pool.

## Why It Matters / Open Questions

The framework addresses a practical and growing need: as platforms like Civitai and Hugging Face accumulate thousands of heterogeneous expert models, a training-free, graph-based mechanism for organizing and selectively merging them is essential for serving diverse in-the-wild user requests. The key open question is whether the reference-prompt calibration bottleneck (a fixed set of N_r prompts) can adequately capture the full capability space of an ever-expanding expert pool, and whether the LLM-based selection step introduces failure modes at scale. The reliance on GPT-4o for both graph construction and expert selection also raises cost and reproducibility concerns that the paper does not fully address.

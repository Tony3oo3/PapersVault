## Problem

Embodied agents require real-time 3D scene understanding with instance-level interaction, but existing 3D reconstruction models either lack instance perception or rely on offline multi-frame aggregation, while naively combining separate depth and segmentation models (e.g., SAM + DAv2) introduces prohibitive latency. No prior model unifies geometric depth estimation and promptable instance interaction in a single efficient feedforward pass suitable for online embodied use.
![Teaser figure](../imgs/CVPR20262945/cropped_page0_idx0.webp)

## Input / Output

The model accepts one or two corresponding RGB frames (resized to 518 short edge) along with optional prompts: a point query for instance segmentation or a mask query for object tracking. All outputs are unified as dense depth maps (w×h) — panoptic, instanced, or tracked — where segmentation masks are derived by thresholding the predicted depth (foreground where d̂ > 0). This depth-as-unified-representation design eliminates redundant multi-head decoders and keeps inference to a single forward pass per frame pair.

## Method

PromptDepth uses a symmetric DINO ViT-B encoder with fully shared parameters for both views, followed by a promptDPT decoder built on a cascaded two-way transformer: a dense block performs cross-attention geometric alignment between views, and a sparse block handles prompt interaction via learnable task tokens (monocular, stereo, instance-queried, tracked). The key architectural insight is 'minimal prediction' — a single dense prediction head produces all output types by modulating its output through dot-product with the task-specific sparse embedding, rather than using separate convolutional heads per task. Training follows a two-stage curriculum (panoptic depth first, then interactive fine-tuning) with two novel regularizers: an Instanced Label Distribution Smoothing (ILDS) loss that adaptively reweights pixels based on per-map depth frequency to balance the zero-heavy instanced labels against panoptic depth, and Gram Anchoring that constrains patch-level feature similarity to prevent geometric representations from collapsing under instance-level supervision. The entire model is trained exclusively on a synthetic dataset of 10M+ object instances rendered via Unreal Engine's Movie Render Queue, achieving SOTA zero-shot depth estimation and competitive segmentation/tracking without any real-world training data.

## Results

On zero-shot monocular relative depth estimation, PromptDepth (ViT-B) achieves SOTA across five benchmarks: KITTI (σ1.25=95.2, rel=0.075), Sintel (σ1.25=76.8, rel=0.191), NYUv2 (σ1.25=98.0, rel=0.045), ETH3D (σ1.25=98.3, rel=0.046), and Diode (σ1.25=95.5, rel=0.061), outperforming larger ViT-L and ViT-G models. On stereo depth (KITTI/Sintel), it reduces RMSE from 4.657 (VDA) to 2.668 on Sintel while using only a ViT-B backbone. For zero-shot video object tracking, it achieves 81.2 J&F on DAVIS-17 and 75.0 on YouTube-VOS, competitive with supervised methods. Inference latency is 39.09 ms (mono) and 44.92 ms (stereo) on RTX 4090, over 2× faster than SAM+DAv2 (95.53 ms) and SAM2+VDA (188.46 ms).

## Baselines & Comparisons

PromptDepth (ViT-B) outperforms all depth estimation baselines on most metrics: it beats DAv2-ViT-G by 0.4 σ₁.₂₅ on KITTI and by a massive 0.315 in relative error on Sintel (0.191 vs 0.506), and surpasses VGGT (ViT-G) by 4.2 σ₁.₂₅ on ETH3D (98.3 vs 97.3). On stereo depth (Table 2), it comprehensively outperforms VDA (ViT-B) on all KITTI and Sintel metrics, cutting Sintel RMSE from 4.657 to 2.668, and also beats the larger VGGT (ViT-G) and MapAnything (ViT-L). For zero-shot video object tracking, PromptDepth (81.2 J&F on DAVIS-17, 75.0 on YouTube-VOS) is competitive with the best zero-shot method ADM (83.3 on DAVIS-17) and substantially outperforms other zero-shot baselines like HCPN (70.7) and HGPU (69.0), while remaining far below supervised SAM2 (90.7). On interactive segmentation (GraspNet), PromptDepth achieves mIoU 0.7863 and J&F 0.8424, outperforming SAM (ViT-B) which scores 0.6036 mIoU and 0.6483 J&F. In latency, PromptDepth is 2.4× faster than SAM+DAv2 (39.09 vs 95.53 ms mono) and 4.2× faster than SAM2+VDA (44.92 vs 188.46 ms stereo), validating its design for real-time embodied use.

## Relation to Prior Work

PromptDepth unifies two previously separate research threads—geometric 3D reconstruction (DUSt3R, VGGT, MapAnything) and promptable instance interaction (SAM, SAM2)—into a single feedforward model, departing from the 'mixture-of-experts' paradigm that chains separate 3D and segmentation models. Architecturally, it adopts DUSt3R's shared two-view encoder and SAM's prompt encoder, but replaces the conventional multi-head DPT decoder with a cascaded two-way transformer (promptDPT) that produces one unified dense map whose interpretation is determined by a task token. The training recipe draws on label distribution smoothing (Yang et al., ICML 2021) adapted to depth maps as ILDS, and Gram Anchoring from DINOv3 to resolve the latent-space conflict between geometric and instance representations.

## Why It Matters / Open Questions

By demonstrating that a lightweight ViT-B model trained exclusively on synthetic data can achieve SOTA zero-shot depth estimation, competitive instance segmentation, and video object tracking simultaneously, PromptDepth offers a practical, low-latency foundation for embodied agents that cannot afford multi-model pipelines. The 10M-instance Unreal Engine data engine is itself a reusable resource for the community. Key limitations acknowledged by the authors include the two-frame input constraint (no long-term memory), and unresolved challenges in key-point tracking and dense feature matching for full 3D reconstruction, leaving open whether the promptable dense-map formulation can extend to longer temporal contexts or metric-scale reconstruction.

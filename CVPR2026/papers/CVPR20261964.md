## Problem

Deploying pretrained visual models in new domains causes significant accuracy degradation, and existing source-free domain adaptation methods rely on gradient backpropagation over deep backbones, making them infeasible on resource-constrained edge devices. The paper formalizes the Domain Adaptive Feature Mapping (DAMap) problem: can one freeze the feature extractor and efficiently fine-tune only the feature-to-prediction mapping using unlabeled target data, without any backward pass?
![Teaser figure](../imgs/CVPR20261964/cropped_page0_idx0.webp)

## Input / Output

MemFlow receives a fixed-dimensional image feature vector (e.g., 2048-d from ResNet-50 or 512-d from LeNet-5) extracted by a frozen backbone, which is fed into entrance nodes of a randomly connected spiking network. The network propagates signals over T=3 rounds and produces a per-neuron memory signal, from which a confidence-weighted fusion across all N neurons yields a final class label and per-class probability. During adaptation, unlabeled target-domain images are processed to generate pseudo-labels that drive iterative memory updates, with no gradient computation at any stage.

## Method

MemFlow replaces the classifier head with a lightweight spiking network of entrance, hub, and bridging nodes connected by randomly initialized directed edges. Input features propagate as amplitude-modulated spikes (not binary) through the network over T rounds, with each node accumulating incoming signals and firing only when its hidden state exceeds zero, after which the state resets. Each neuron stores its memory as C Gaussian distributions (one per class) parameterized by mean and variance, updated incrementally via running statistics; a Gaussian-blur kernel smooths these distributions to prevent overfitting on small or imbalanced batches. At inference, each neuron retrieves its memory to produce a class posterior and a confidence score, and the final prediction is a confidence-weighted fusion across all neurons. For domain adaptation, MemFlow performs reinforced memorization: pseudo-labels from the frozen backbone's predictions are used to update the Gaussian parameters, with per-neuron confidence weighting to suppress noisy pseudo-labels, converging to a bounded neighborhood of the true target distribution as proven in Theorem 2.

## Results

On the Office-31 dataset, MemFlow achieves 86.1% accuracy with only 0.160 ms adaptation time per instance, outperforming the best DAMap baseline (retrain@BAG at 82.6%) by 3.5% while being 4.7× faster. On VisDA-C, MemFlow reaches 72.1% accuracy (vs. 65.0% for retrain@last, a +7.1% gain) at 0.012 ms per instance—less than 0.1% of the time required by SFUDA methods like TPDS (67.3 ms) or PFC (3.8 ms). On Digits, MemFlow attains 89.1% accuracy at 0.013 ms, matching or exceeding all lightweight baselines. When integrated as a plug-in into SFUDA frameworks (e.g., SHOT+MemFlow), MemFlow further boosts accuracy by 0.5–1.4% with minimal additional overhead.

## Baselines & Comparisons

Among DAMap baselines, MemFlow achieves the highest accuracy on all three datasets: 89.1% on Digits (vs. 89.0% for retrain@BLS, 87.8% for retrain@BAG), 86.1% on Office-31 (vs. 82.6% for retrain@BAG, 82.3% for retrain@KNN), and 72.1% on VisDA-C (vs. 67.2% for retrain@BLS, 65.0% for retrain@last). MemFlow is also the fastest DAMap method, with adaptation times of 0.013 ms (Digits), 0.160 ms (Office-31), and 0.012 ms (VisDA-C), substantially faster than retrain@last (0.063/1.397/0.096 ms) and retrain@SVM (3.720/0.473/13.235 ms). Against SFUDA methods, MemFlow trades accuracy for extreme speed: on VisDA-C it scores 72.1% vs. 88.0% (AaD) and 87.6% (TPDS), but at 0.012 ms per instance versus 3.060 ms (AaD) and 67.288 ms (TPDS)—a 255× to 5608× speedup. The paper further demonstrates that MemFlow can be plugged into SFUDA pipelines (e.g., SHOT+MemFlow: 72.3% vs. 71.0% on Office-Home; TPDS+MemFlow: 73.9% vs. 73.5%), yielding consistent 0.3–1.4% accuracy gains with negligible time overhead.

## Relation to Prior Work

MemFlow carves new ground at the intersection of gradient-free networks (ELM, BLS, ESN) and spiking neural networks, but departs from both in key ways: unlike ELM/BLS which fit a single input-output function, MemFlow models classification as distributed memory storage and retrieval across randomly connected neurons; unlike traditional SNNs which use fixed binary spikes, MemFlow ties spike amplitude to hidden-state magnitude and accumulates persistent memory signals. The paper also explicitly contrasts with Hinton's Forward-Forward algorithm, noting that MemFlow's memory-based retrieval (rather than two-pass positive/negative scoring) enables reinforced memorization on unlabeled data. Within the SFUDA literature (SHOT, AaD, PFC, TPDS), MemFlow is positioned as a complementary plug-in that operates on frozen features rather than updating deep representations via backpropagation.

## Why It Matters / Open Questions

The practical significance is substantial: achieving comparable accuracy to gradient-based SFUDA methods while consuming less than 1% of the adaptation time opens a realistic path for continuous domain adaptation on resource-constrained edge devices, a setting where backpropagation is simply infeasible. The convergence theorem (Theorem 2) provides theoretical grounding for the self-supervised reinforced memorization loop, though its assumptions (bounded confidence, existence of a true Gaussian parameter set) may not always hold in practice. Open questions include how the fixed random topology (50 hub + 50 bridging nodes) scales to larger classification problems, whether the approach extends beyond single-image classification to segmentation or multi-modal settings, and how sensitive performance is to pseudo-label noise beyond the confidence-weighting mechanism.

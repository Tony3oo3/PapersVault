## Problem

Large vision-language models generating long chain-of-thought responses are highly vulnerable to visual hallucination propagation: a single token that departs from visual evidence can steer the entire remaining reasoning chain toward a fluent but incorrect answer. Existing remedies train models via reinforcement learning to call visual tools (zoom, crop) during CoT generation, but these pipelines are costly, model-specific, and tightly coupled to particular backbones, leaving no lightweight, training-free, plug-and-play alternative for visually grounded decoding.

## Input / Output

The framework wraps around a frozen LVLM and takes a standard RGB image plus a text question as input, producing a text answer with chain-of-thought reasoning. Unusually, it also emits short natural-language micro-observation sentences (e.g., 'The first dress from the right-hand side is blue, partially hidden by the tree') that are stored in a dynamic textual evidence pool and reused to score subsequent tokens. The visual decider (GRIT-3B) may optionally return bounding-box coordinates alongside each evidence sentence, but only the text participates in probability scoring; coordinates serve solely as interpretability annotations.

## Method

ECRD (Evidence-Constrained Reweighted Decoding) operates entirely at test time by modifying the token-selection process. At each decoding step, the base VLM's next-token distribution is truncated to a top-k candidate set via knee detection; a distribution supervisor then computes an evidence-induced distribution over those candidates by averaging per-prefix log-likelihoods across all sentences in the growing textual evidence pool, and negotiates a mass-matched mixture with the base distribution using an adaptive weight α = p_(1) that automatically allocates more influence to evidence when the base model is uncertain. When the post-negotiation margin between the top two candidates falls below a threshold δ, a lightweight visual decider (GRIT-3B) is invoked to read the image under the current prefix and commit a token plus a one-sentence micro-observation, which is appended to the pool. The critical design choice is representing all visual evidence as compact text rather than re-injecting pixel crops, so that later tokens can be scored against prior observations without re-encoding image regions, keeping the intervention lightweight and composable across the full reasoning chain.

## Results

On TreeBench, ECRD delivers consistent overall accuracy gains across all open-source backbones: +10.9 pts on Qwen2.5-VL-7B (37.0→47.9%), +6.1 pts on Qwen2.5-VL-32B (42.5→48.6%), +7.7 pts on Qwen2.5-VL-72B (42.2→49.9%), and +4.5 to +6.4 pts on LLaVA-OneVision and InternVL3 variants. On RH-Bench, ECRD lifts RH-AUC from 0.51 to 0.58 (+13.7% relative), with Reasoning improving from 39.6% to 46.4% and Perception from 50.2% to 57.1%. Across five general multimodal benchmarks, ECRD yields +3.7 pts on V*Bench overall, +4.1 pts on MathVista, +3.9 pts on ChartQA, +8.4 pts on OCR-Bench, and +11.2 pts on HallusionBench (Qwen2.5-VL-7B).

## Baselines & Comparisons

Against RL-based visual-grounded reasoning systems, ECRD on Qwen2.5-VL-7B (47.9%) substantially outperforms DeepEyes-7B (37.5%) and Pixel-Reasoner-7B (39.0%) without any training, while approaching TreeVGR-7B (50.4%) which requires dedicated training. Among training-free baselines on the same base model, ECRD (47.9%) decisively beats Woodpecker (36.3%), ViperGPT (38.3%), ControlMLLM (40.5%), beam search (38.8%), self-consistency (39.0%), and diverse sampling (38.3). Against private models, ECRD on Qwen2.5-VL-7B surpasses Gemini-2.5-Flash (45.9%) and GPT-4o (46.9%) on TreeBench overall, though it remains below Gemini-2.5-Pro (54.1%) and o3 (54.8%). On RH-Bench, ECRD improves RH-AUC by 0.07 (0.51→0.58) over the base Qwen2.5-VL-7B, with the supervisor alone contributing +0.03 and the full pipeline adding the remaining +0.04. The largest sub-category gains appear in visually grounded tasks (OCR +26.5, Containment +31.1 on Qwen2.5-VL-7B), confirming that the evidence pool most effectively corrects perception-dependent reasoning steps.

## Relation to Prior Work

This paper extends VDGD (Ghosh et al., 2024), which used a single static image caption to replace base logits during decoding, by making the evidence dynamic, iterative, and negotiated rather than overwriting. It departs sharply from the RL-based 'think with images' line (DeepEyes, Pixel-Reasoner, GRIT) that trains a policy to call visual tools and re-inject pixel crops; instead, ECRD represents evidence as compact textual micro-observations and mixes an evidence-induced distribution with the base model's probabilities at each decoding step. The knee-truncation candidate selection and the adaptive mixing weight α = p_(1) are novel design choices that make the intervention responsive to local uncertainty without hyperparameter tuning.

## Why It Matters / Open Questions

The training-free, plug-and-play nature makes visually grounded reasoning accessible to any frozen LVLM without the curated data, reward engineering, and compute that RL pipelines demand, which is practically significant for the broader open-source community. However, the method still requires a separate visual decider (GRIT-3B) at uncertain steps, and the uncertainty threshold δ, while well-motivated, remains a deployment-tuning knob. Open questions include whether purely textual evidence suffices for tasks requiring fine-grained spatial reasoning (e.g., precise localization), how the framework extends to multi-image or video inputs, and whether the negotiation mechanism can be internalized into the base model's decoding without an external decider.

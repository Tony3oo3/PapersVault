## Problem

Existing long-term video understanding frameworks compress each frame independently and use memory in a strictly one-way fashion (perception → memory), which causes them to miss question-relevant information due to limited memory capacity or improper updates. This design fails on tasks requiring understanding of complete temporal events, such as action ordering and Needle-in-a-Haystack localization, because past visual context cannot inform ongoing perception.
![Teaser figure](../imgs/CVPR20263332/cropped_page0_idx1.webp)

## Input / Output

The method consumes long videos sampled at 1 or 2 fps, processed sequentially in non-overlapping clips of 32 frames, alongside a text question. For each clip, 32 recalled frames retrieved from a context memory (capacity 256) are concatenated with the current clip before encoding, so the visual compressor always sees both new and previously relevant content. The output is a free-form text answer; the method uses only 16 context tokens per frame (versus 169 for LLaVA-Video), keeping the total decoder input within the base model's context window.

## Method

QViC-MF introduces a feedback loop in which the top-K_r most relevant frames from a context memory are recalled and fed back into the visual compressor alongside the current clip, enabling memory-informed perception. The core mechanism is Question-guided Multimodal Selective Attention (QMSA), which modifies self-attention logits via three additive matrices: a Masking matrix enforcing causal and frame-wise constraints so each context token attends only to its own frame's visual tokens; a Blocking matrix that sets context-to-text attention to −∞ to prevent question text from leaking into context embeddings (compression hallucination); and a Guiding matrix that broadcasts the mean text-to-visual attention logits into the context-to-visual attention, steering context tokens toward question-relevant visual regions. Relevance scores for memory management are computed from text-to-visual attention weights across selected compressor layers, and the memory is updated by appending new entries and pruning the lowest-relevance ones. Training uses LoRA fine-tuning of LLaVA-Video-7B-Qwen2 on 83K samples from the LLaVA-Video-178K dataset, optimizing only the context seed embeddings and the visual compressor.

## Results

QViC-MF (2 fps) achieves 59.4% on MLVU test, 50.2% on LVBench, 54.0% on VideoMME Long, and 58.7% on VNBench Long, using only 16 visual tokens per frame. This represents improvements of 6.1% over LLaVA-Video on MLVU test, 8.2% over Flash-VStream on LVBench, 3.7% over Flash-VStream on VideoMME Long, and 18.3% over LLaVA-Video on VNBench Long. Notably, QViC-MF surpasses GPT-4o on MLVU test (59.4 vs. 54.9) and VNBench Long (58.7 vs. 56.3) while using far fewer visual tokens than any open-source baseline.

## Baselines & Comparisons

QViC-MF (2 fps) outperforms all 11 open-source baselines across every benchmark where they overlap. Against the strongest open-source competitor LLaVA-Video (169 tokens/frame), QViC-MF gains 6.1% on MLVU test (59.4 vs. 53.3) and 18.3% on VNBench Long (58.7 vs. 40.4) while using only 16 tokens/frame. Against Flash-VStream (128 tokens/frame), the closest memory-augmented baseline, QViC-MF leads by 8.2% on LVBench (50.2 vs. 42.0) and 3.7% on VideoMME Long (54.0 vs. 50.3). On VideoMME Long, QViC-MF (54.0) still trails both proprietary models—GPT-4o (65.3) and Gemini 1.5 Pro (67.4)—by 11–13 points, indicating a remaining gap on holistic multi-domain comprehension. However, QViC-MF surpasses GPT-4o on MLVU test (59.4 vs. 54.9) and VNBench Long (58.7 vs. 56.3), and exceeds Gemini 1.5 Pro on LVBench (50.2 vs. 33.1) and VNBench Overall (64.7 vs. 66.7 is a loss, but 64.7 vs. 66.7 means Gemini wins). The weaker baselines (LLaMA-VID, MovieChat, MA-LMM) score 17–22% on MLVU test, far below QViC-MF, confirming that single-frame compression without memory feedback is insufficient for long-term temporal reasoning.

## Relation to Prior Work

QViC-MF is a direct architectural extension of LLaVA-Video, reusing its SigLIP visual encoder, MLP projector, and Qwen2-7B decoder while replacing the per-frame visual compression with a multi-frame, question-conditioned compressor (QMSA). It also extends the authors' prior IQViC work, which performed question-guided single-frame compression, by adding cross-frame temporal integration and a feedback loop from context memory back into perception. The key conceptual departure from the broader memory-augmented LMM literature (MA-LMM, MovieChat, FlashVStream) is the bidirectional perception–memory interaction: rather than the conventional one-way pipeline where compressed features are stored and only retrieved at decoding time, QViC-MF feeds recalled frames back into the compressor for subsequent clips, enabling adaptive, temporally coherent compression.

## Why It Matters / Open Questions

The practical significance lies in achieving state-of-the-art accuracy with only 16 visual tokens per frame—roughly one-tenth of competing methods (128–169 tokens)—making long-video understanding substantially more scalable for real-time or resource-constrained deployments. The ablation finding that adding context memory without feedback actually degrades performance (48.8 → 42.4 on MLVU) is a useful cautionary result for the field, suggesting that memory architectures need a feedback mechanism to be beneficial rather than merely a larger storage buffer. Open questions include whether the feedback-driven design extends naturally to truly online/streaming settings with unbounded video length, and whether the relevance-score-based pruning strategy generalizes to open-ended generation tasks beyond multiple-choice QA.

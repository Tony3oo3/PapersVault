## Problem

Self-supervised ViTs like DINO exhibit emergent object localization, but prior approaches either rely on the [CLS] token's attention maps (which are noisy due to the global training objective) or use only key features from the final layer (as in TokenCut), leaving complementary information in query/value components and intermediate layers unexploited. It remains unclear whether object-centric information is confined to the final layer or distributed across the network, and how to automatically identify the relevant heads without task-specific training.

## Input / Output

The method takes a pre-trained self-supervised ViT (DINOv2 or DINOv3) and a set of unlabeled RGB images as input, requiring no additional training, fine-tuning, or labeled data. It outputs a set of object-centric attention heads (H_obj) distributed across layers, which can be used to produce foreground-background localization maps via graph-based segmentation (TokenCut) or to generate object-centric visual guidance maps for MLLM decoding. For the MLLM application, the input additionally includes a text prompt, and the output is a generated text description with reduced object hallucination.

## Method

Object-DINO is a training-free, two-phase algorithm. In Phase 1, for every attention head (ℓ, h) across all layers, it computes normalized patch self-similarity matrices A_q, A_k, A_v (Eq. 1) via L2-normalized dot products with softmax (τ=60), then ensembles them with equal weights (w=0.33 each) into a unified map A_ens (Eq. 2) and flattens it into a per-head feature vector. In Phase 2, it applies k-means clustering (K=5) over all L×H head feature vectors and automatically selects the cluster containing the highest proportion of final-layer heads as the object-centric cluster (Eq. 4), yielding a distributed set H_obj that includes valuable intermediate-layer heads while filtering out noisy final-layer heads. For object discovery, H_obj's ensemble similarity serves as the affinity in a TokenCut-style graph cut; for MLLM hallucination mitigation, the aggregated object map is fed as a second visual input in a dual-branch decoding strategy that linearly combines standard and guidance logits (Eq. 5, α=0.4) to amplify tokens consistent with visual evidence.

## Results

On unsupervised object discovery, Object-DINO integrated into TokenCut improves CorLoc by +4.8, +5.7, and +3.6 on VOC 2007, VOC 2012, and COCO 20k for DINO-V3, and by +9.5, +12.4, and +7.8 for DINO-V2. On MLLM hallucination mitigation (POPE benchmark), the method achieves the highest Precision (87.4, 87.7, 89.2) and F1 (82.7, 81.6, 86.1) across LLaVA-1.5, Instruct-BLIP, and Qwen-VL respectively. On CHAIR, it attains the lowest Cs (18.4) and Ci (5.9) on LLaVA-1.5, and the lowest Cs (21.4) on Instruct-BLIP, all without any additional training.

## Baselines & Comparisons

On POPE, Object-DINO outperforms all seven competing hallucination-mitigation methods on Precision and F1 across all three MLLMs, with the largest margins over VCD (+15.3 P on LLaVA-1.5) and M3ID (+13.9 P on LLaVA-1.5). It slightly trails MARINE on LLaVA-1.5 Accuracy (83.6 vs. 83.9) but surpasses it by a wide margin on Precision (87.4 vs. not reported) and F1 (82.7 vs. 82.7, tied). On CHAIR, it matches DeGF for the lowest Cs on LLaVA-1.5 (18.4) while achieving the lowest Ci (5.9 vs. 6.1), and beats all baselines on Instruct-BLIP Cs (21.4 vs. next-best 24.0 from DeGF). For unsupervised object discovery, Object-DINO consistently beats the TokenCut baseline by +3.6 to +12.4 CorLoc, with the largest gain on VOC 2012 with DINO-V2 (+12.4). The method also outperforms RITUAL, Woodpecker, and HALC on CHAIR for both LLaVA-1.5 and Instruct-BLIP, confirming that providing explicit visual grounding via self-supervised objectness maps is more effective than contrastive decoding or image-augmentation strategies.

## Relation to Prior Work

This paper extends the line of work on emergent object discovery in self-supervised ViTs (DINO, DINOv2, DINOv3) and the TokenCut framework for unsupervised object segmentation. It departs from prior approaches in two key ways: (1) instead of relying solely on [CLS] token attention or key (K) features from the final layer (as in DINO-seg and TokenCut), it shows that all three attention components (Q, K, V) encode complementary object-centric information; and (2) it demonstrates that object-centric heads are distributed across intermediate layers, not confined to the final layer as previously assumed. The method (Object-DINO) is a training-free, k-means-based head selection strategy that sits on top of existing self-supervised ViTs without modification.

## Why It Matters / Open Questions

The finding that object-centric information is both multi-component and layer-distributed challenges the prevailing assumption in the field that the final layer's key features are the primary locus of object structure in self-supervised ViTs. This has practical implications: practitioners using TokenCut or similar methods can gain substantial CorLoc improvements (+3.6 to +12.4) simply by swapping in the proposed head selection, with no retraining. The MLLM hallucination mitigation application shows the object maps can serve as lightweight visual grounding signals, though the method is currently limited to foreground-background separation rather than instance-level segmentation. Open questions include whether the distributed pattern holds in vision-language models (e.g., CLIP) and whether the approach can be extended to multi-instance decomposition.

## Problem

Existing 3D scene-language understanding frameworks borrow standard causal attention masks from language modeling, which impose spurious sequential dependencies on inherently order-agnostic 3D objects and block direct attention between object tokens and instruction tokens. While prior work has focused heavily on input representation design, the decoder's masking strategy has remained largely unexplored despite its fundamental mismatch with 3D spatial structure.
![Teaser figure](../imgs/CVPR20261065/cropped_page0_idx0.webp)

## Input / Output

The input is a 3D scene point cloud decomposed into object proposals via a pretrained Mask3D detector, where each object is encoded as an identifier token (e.g., <OBJ000>) concatenated with instance-level 3D and 2D features. These object tokens are arranged in a fixed [system, objects, instruction] sequence order before being fed to the LLM decoder. Outputs are task-specific: object identifiers for visual grounding, free-form text captions for dense captioning, or short text answers for question answering, all generated autoregressively under a unified prompt format.

## Method

3D-SLIM replaces the standard causal mask with two specialized components that require no architectural modifications or extra parameters. The Geometry-adaptive Mask (Geo Mask) computes each object's local spatial density (inverse of mean distance to all other objects), normalizes it, and uses it to adaptively determine the number of neighbors k_i each object attends to (bounded by k_min=2 and k_max=10); objects in dense regions attend to more neighbors while sparse-region objects attend to fewer, selected via TopK on negative pairwise distances. The Instruction-aware Mask (Inst Mask) simply overrides the object-to-instruction block of the attention matrix, replacing −∞ entries with 0 so that object tokens can directly attend to instruction tokens during encoding. The model is fine-tuned with LoRA under a standard cross-entropy loss on the unified task format, and the masking strategy is decoder-agnostic, validated across Vicuna-7B, Llama3-8B, Qwen2-7B, and Qwen3-8B backbones.

## Results

On the object-centric Chat-Scene framework (Vicuna-7B), 3D-SLIM improves ScanRefer Acc@0.5 from 50.2 to 54.1, Multi3DRefer F1@0.5 from 52.4 to 58.7, and ScanQA CIDEr from 87.7 to 94.0. On the 3DGraphLLM framework (Llama3-8B-Instruct), 3D-SLIM achieves the best object-based visual grounding results: ScanRefer Acc@0.25=64.1, Acc@0.5=57.7, and Multi3DRefer F1@0.5=62.0, surpassing all prior object-based methods. Across four different LLM backbones (Vicuna-7B, Llama3-8B, Qwen2-7B, Qwen3-8B), 3D-SLIM consistently yields 2–5 point gains on grounding metrics, confirming its decoder-agnostic effectiveness.

## Baselines & Comparisons

Among object-based methods, 3DGraphLLM + 3D-SLIM achieves the best visual grounding performance, beating Robin3D by +3.3 on ScanRefer Acc@0.25 (64.1 vs 60.8) and +2.3 on Multi3DRefer F1@0.5 (62.0 vs 59.7), and surpassing Chat-Scene by +8.6 on ScanRefer Acc@0.25 (64.1 vs 55.5). Chat-Scene + 3D-SLIM also outperforms the original Chat-Scene on every reported metric, with the largest gain on ScanQA CIDEr (+6.3, 94.0 vs 87.7) and Multi3DRefer F1@0.5 (+6.3, 58.7 vs 52.4). Against video-based methods, 3DGraphLLM + 3D-SLIM wins on visual grounding (beating GPT4Scene-HDM by +1.5 on ScanRefer Acc@0.25 and +2.5 on Multi3DRefer F1@0.5) but trails on question-answering (ScanQA CIDEr 88.2 vs 96.3 for GPT4Scene; SQA3D test EM 56.1 vs 63.0 for Ross3D), which the authors attribute to the stronger multi-modal pre-training of the MLLM backbones used by video-based approaches. The ablation in Table 2 confirms that 3D-SLIM provides consistent 2–5 point improvements across four different LLM decoders (Vicuna-7B, Llama3-8B, Qwen2-7B, Qwen3-8B), validating its generality as a plug-and-play masking strategy.

## Relation to Prior Work

This paper builds directly on the object-centric 3D LLM paradigm established by Chat-Scene and 3DGraphLLM, which decompose 3D scenes into object tokens with identifiers and feed them to a standard LLM decoder. The key departure is shifting focus from input representation (how to encode 3D scenes) to decoder design (how the LLM processes those tokens), identifying that the standard causal attention mask imposes spurious sequential dependencies on order-agnostic 3D objects and blocks critical object-instruction interactions. The proposed 3D-SLIM masking strategy is a parameter-free, architecture-agnostic modification that replaces the causal mask with a geometry-adaptive spatial mask and an instruction-aware mask, requiring no changes to the underlying LLM.

## Why It Matters / Open Questions

The paper highlights an underexplored dimension of 3D scene-language understanding—decoder attention design—and provides a simple, broadly applicable fix that consistently improves performance across multiple LLM backbones and tasks without adding parameters. However, the method is specific to object-centric frameworks where objects have explicit 3D center coordinates; it is unclear how the geometry-adaptive mask would generalize to point-based or video-based representations that lack discrete object positions. Open questions include whether similar spatially-structured masking could be adapted to dense representations, whether the approach extends to outdoor or large-scale scenes with very different object densities, and whether the moderate gains (1–4 points) would compound in more complex multi-turn or embodied settings.

## Problem

Existing layout-to-image diffusion approaches for object detection data augmentation produce artifacts near boundaries of tiny objects and fail to generalize to UAV imagery, where small-scale, densely overlapping targets yield low-quality layout conditions, uneven spatial distribution wastes model capacity on background, and stochastic generation introduces label-image inconsistencies that degrade detector training.
![Teaser figure](../imgs/CVPR20261664/cropped_page0_idx0.webp)

## Input / Output

The method consumes real UAV image layouts (bounding boxes with class labels), class-specific visual prototypes (high-quality object patches selected via dual-criteria filtering), and two levels of textual prompts (a global scene description and per-object descriptions enriched with Fourier positional embeddings). Generation operates at 512×512 resolution on object-dense focal region crops rather than full images; these crops are then merged back to original image resolution. The output is a synthetic dataset of annotated images whose labels have been post-processed to remove missed/false generations and correct box misalignments, ready for direct detector training.

## Method

UAVGen comprises two core modules. The Visual Prototype Conditioned Diffusion Model (VPC-DM) first selects high-fidelity visual prototypes per class using a dual-criteria mechanism (confidence/IoU thresholding in visual space, then latent-space centroid proximity via a VAE encoder), then constructs multi-source conditions: a visual-prototype layout embedding aggregated by a 3D convolution over stacked VAE-encoded prototype placements, plus global and fine-grained text embeddings (the latter using Fourier positional encoding and gated attention). These conditions are injected through a ControlNet into a FLUX-based latent diffusion model trained with a foreground-aware reweighted loss that upweights object pixels. The Focal Region Enhanced Data Pipeline (FRE-DP) applies K-means clustering on object centroids to identify object-dense regions, solves an overlap-maximization problem to crop focal regions, generates images only on these high-information-density areas, and performs label refinement using a pretrained Faster R-CNN detector to filter missed/false generations and correct box misalignments via confidence-thresholded IoU matching.

## Results

On VisDrone, UAVGen achieves mAP 25.9% and AP50 44.8% with GFL-ResNet50, improving over the real-only baseline (24.5% mAP) by 1.4% and outperforming all diffusion-based baselines. On UAVDT, UAVGen reaches mAP 16.6% and AP50 30.9%, a 2.1% mAP gain over real-only training. In terms of generation fidelity, UAVGen attains FID 34.34 on VisDrone and 29.73 on UAVDT, substantially lower than AeroGen (48.04 / 31.99), Geodiffusion (57.96 / 47.81), and GLIGEN (72.68). When applied to the SOTA UAV detector RemDet-X, UAVGen further lifts mAP from 29.8% to 30.2%, while all other augmentation methods degrade performance.

## Baselines & Comparisons

UAVGen consistently outperforms all four baselines on both datasets across every AP metric. On VisDrone, it surpasses AeroGen (the strongest baseline) by 1.0% mAP (25.9 vs 24.9) and 1.1% APs (16.7 vs 15.6), while GLIGEN and Geodiffusion trail by 1.1% and 1.2% mAP respectively; CopyPaste actually degrades mAP below the real-only baseline (23.6 vs 24.5). On UAVDT, the gap widens: UAVGen leads AeroGen by 1.6% mAP (16.6 vs 15.0) and 2.6% AP50 (30.9 vs 28.3), and beats Geodiffusion by 2.6% mAP. In generation fidelity, UAVGen's FID of 34.34 on VisDrone is 13.7 points lower than AeroGen and 38.3 points lower than GLIGEN. Notably, when the augmentation is applied to the SOTA RemDet-X detector, only UAVGen improves performance (30.2% mAP vs 29.8% real-only), whereas GLIGEN, Geodiffusion, and AeroGen all cause degradation (29.4%, 29.4%, and 28.8% respectively).

## Relation to Prior Work

UAVGen extends the layout-to-image diffusion paradigm established by GeoDiffusion, GLIGEN, and AeroGen, but repurposes it specifically for the UAV detection domain where small, densely overlapping objects degrade standard layout conditioning. Rather than directly cropping annotated regions as supervision (as prior methods do), it introduces dual-criteria visual prototype selection (detector confidence + latent-space centroid proximity) to construct higher-fidelity conditioning signals, and adds a focal-region cropping strategy (K-means on object centroids) that redirects diffusion capacity toward object-dense areas. The label refinement post-processing pipeline, which uses a pretrained detector to correct missed, false, and misaligned generations, is a practical addition not present in prior layout-to-image data augmentation work.

## Why It Matters / Open Questions

This is the first diffusion-based data synthesis framework explicitly designed for UAV detector training, addressing a real data-scarcity bottleneck in aerial imaging where annotation is expensive and scenes change rapidly. The focal-region strategy's efficiency finding—738 synthesized images matching or exceeding methods that generate 6,474—is practically valuable for compute-constrained settings. However, the method is tightly coupled to FLUX and evaluated on only two UAV benchmarks, and the authors acknowledge that viewpoint/altitude-induced appearance and scale variations remain unaddressed, limiting generalizability to diverse real-world UAV deployments. The observation that naive diffusion augmentation (GLIGEN, GeoDiffusion, AeroGen) actually degrades a SOTA detector (RemDet) while UAVGen improves it raises open questions about what properties of synthetic data are necessary to benefit strong detectors.

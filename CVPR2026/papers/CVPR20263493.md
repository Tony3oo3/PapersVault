## Problem

Existing Chain-of-Thought reasoning in unified generation models focuses exclusively on text-prompt alignment, ignoring visual context consistency with input reference images. This gap causes failures in preserving fine-grained visual features—human identity, object attributes, and stylistic elements—during multi-modal generation tasks such as multi-reference image generation and content-aware editing.
![Teaser figure](../imgs/CVPR20263493/cropped_page1_idx0.webp)

## Input / Output

The method takes a text prompt T and a set of n reference images V = {v₁, …, vₙ} as input, and produces a single generated image Y through a T-step flow-matching denoising process. During inference, the model iteratively generates intermediate structured checklists (Z_plan) and evaluation feedback (Z_eval) as text, which are appended to the interleaved multi-modal sequence to guide subsequent refinement passes. The base model is BAGEL, a unified decoder-only Transformer with separate understanding (ViT) and generation (VAE) experts sharing self-attention.

## Method

VACoT introduces two reasoning components into the unified model: (1) Adaptive Visual Planning, which generates a structured checklist decomposing consistency requirements into typed items (identity, style, attribute) each specifying source and target visual elements; and (2) Iterative Visual Correction, where the model evaluates its current output against the checklist, produces editing instructions, and regenerates the image, repeating until satisfaction or a maximum iteration count. Training is two-stage: first, supervised fine-tuning on datasets where Gemini generates ground-truth planning checklists and a weaker BAGEL variant produces negative samples with VLM-annotated correction feedback; second, flow-GRPO reinforcement learning with a composite reward combining type-specific visual similarity metrics (GroundingDINO + DINO for identity, CSD-Score for style) and CLIP text alignment, optimized via clipped policy gradients with KL regularization.

## Results

On the OmniContext multi-reference generation benchmark, VACoT achieves an average score of 8.26, outperforming the base BAGEL model (5.55), UiG (6.85), and Uni-CoT (7.89), and surpassing GPT-4o (8.75) on the MULTIPLE Object (9.21 vs. 8.95) and SCENE Object (8.67 vs. 8.44) sub-tasks. On the GenEval text-to-image benchmark, VACoT attains the highest overall score of 0.84 among all unified models, edging out Uni-CoT (0.83) and UiG (0.82), while also matching the dedicated generation model FLUX.1-dev (0.82). Ablations confirm that both SFT and flow-GRPO stages contribute incremental gains, and 3 iterations of visual correction is the sweet spot before over-correction degrades quality.

## Baselines & Comparisons

VACoT decisively outperforms its base model BAGEL (5.55 → 8.26 average on OmniContext), demonstrating that the visual-aware CoT framework adds substantial value over direct generation. Among text-CoT unified models, VACoT beats Uni-CoT (7.89) by 0.37 and UiG (6.85) by 1.41 on average, confirming that visual consistency checking is more effective than text-only alignment for multi-reference tasks. Against the strongest non-unified baseline GPT-4o (8.75), VACoT trails on overall average but wins on MULTIPLE Object (9.21 vs. 8.95) and SCENE Object (8.67 vs. 8.44), while losing on character-centric sub-tasks. On GenEval, VACoT (0.84) marginally surpasses Uni-CoT (0.83) and UiG (0.82), and matches the dedicated FLUX.1-dev model (0.82), showing that visual-aware training does not degrade general T2I capability. Compared to other multi-reference systems, VACoT outperforms OmniGen2 (6.97) and Echo-4o (8.09) while remaining competitive with GPT-4o, and substantially outperforms Gemini-2.0-flash (3.12) and UNO (4.03).

## Relation to Prior Work

This paper builds on BAGEL, a unified understanding-generation model with a Mixture-of-Transformer-Experts architecture, and extends it with a visual-aware reasoning loop. It departs from prior multimodal CoT methods for generation (Uni-CoT, UiG), which perform self-reflection solely against the text prompt, by introducing structured visual checklists (Adaptive Visual Planning) and iterative visual correction that explicitly verify identity, style, and attribute consistency with reference images. The second-stage training leverages flow-GRPO, adapting the RL framework for flow-matching models to optimize a composite visual+text consistency reward, which is a novel application of this RL paradigm to the visual-consistency objective.

## Why It Matters / Open Questions

The paper addresses a practical and underexplored gap: multi-reference generation (identity preservation, style transfer, content-aware editing) requires visual fidelity that text-only CoT cannot guarantee, and the proposed two-stage recipe (SFT on planning/correction data + flow-GRPO with type-specific visual rewards) offers a concrete path to close this gap in unified models. A notable positive side-effect is that visual-aware training does not degrade—and slightly improves—general T2I performance, suggesting the structured reasoning inducts a more coherent generation prior. Open questions include whether the approach generalizes beyond BAGEL to other unified architectures, whether the reliance on external evaluators (GroundingDINO, DINO, CLIP, CSD-Score) for the reward can be internalized, and whether the iterative correction loop scales to video or longer-horizon generation tasks.

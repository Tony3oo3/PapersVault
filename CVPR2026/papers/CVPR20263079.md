## Problem

Millisecond-accurate human motion timing (PMT) is critical in sports and motion analysis, yet existing HPE datasets cap at 120 Hz ground truth, far below the 1000 Hz needed to resolve micro-dynamics. High-speed RGB cameras (≥1000 Hz) can capture such motion but are prohibitively expensive, bandwidth-intensive, and lighting-sensitive, making them impractical for routine use. The paper addresses this by introducing a portable, low-cost flashing-LED + event-camera system that generates native 1000 Hz pose labels without a high-speed RGB rig.

## Input / Output

ResPose consumes two synchronized streams per 50 ms window: a single RGB frame (Hikrobot 1920×1200 at 20 FPS) providing structural context, and an asynchronous event stream (Prophesee 1280×720) delivering per-pixel brightness-change timestamps at microsecond granularity. The output is a sequence of 17-joint 2D positions at 1000 Hz, computed as the sum of a low-rate RGB anchor pose and a per-event-frame residual offset. The FlashMotion dataset additionally provides 60 Hz 3D SMPL parameters (from IMU + LiDAR) for verification, but these are not used as model input.

## Method

ResPose is a hybrid SNN-CNN-Transformer that decomposes pose estimation into a static RGB anchor plus a high-frequency event residual. The RGB branch (ViTPose) yields a 2D anchor pose P_rgb at 20 FPS; the event branch performs dynamic cropping of 32×32 spatiotemporal patches centered on each normalized anchor joint, then processes them through Leaky Integrate-and-Fire (LIF) spiking neurons with a 1×1 convolutional noise-filtering branch, producing per-joint event features F_event ∈ R^{J×4096}. A Multimodal Residual Transformer lifts the 2D anchors via a learnable linear projection, concatenates them with F_event, and applies skeleton-aware self-attention over all J=17 joints to enforce kinematic consistency and rectify noisy local estimates. The full network is trained end-to-end under supervised L2 loss against the 1000 Hz ground-truth labels. The key design insight is that events need only encode the small residual displacement from the RGB anchor rather than the full pose, dramatically reducing the estimation difficulty and enabling single-digit-millisecond timing accuracy.

## Results

On the FlashMotion dataset, ResPose achieves an MPJPE of 5.66 px and PCK@0.5 of 0.99 for the High Temporal Resolution HPE task, outperforming the next-best method EvSharp2Blur (8.78 MPJPE) by ~35% and RGB-interpolated ViTPose (10.06 MPJPE) by ~44%. For the Precise Motion Timing (PMT) task, ResPose achieves single-digit millisecond errors (4.8 ms for Punching, 6.5 ms for Jumping, 7.2 ms for Kicking), reducing timing error by 5–20× compared to baselines that range from 31 ms (ViTPose, Jumping) to 136 ms (LEIR, Punching). The dataset itself provides 1000 Hz 2D ground-truth labels across 7.15M frames, an order of magnitude beyond prior public HPE benchmarks (120 Hz).

## Baselines & Comparisons

ResPose decisively outperforms all six baselines on both tasks. On High Temporal Resolution HPE, it beats the closest competitor EvSharp2Blur [29] (8.78 MPJPE) by 3.12 px and RGB-interpolated ViTPose [59] (10.06 MPJPE) by 4.4 px, while pure event-based methods (Hybrid ANN-SNN [3] at 22.48, EventPointPose [11] at 51.61, GraphEnet [22] at 43.01) and the multimodal LEIR [61] (59.02) lag far behind, confirming that low-frame-rate inputs cannot capture micro-dynamics at 1000 Hz. On PMT, ResPose achieves 4.8–7.2 ms error versus 31.4–62.3 ms for ViTPose [59], 54.1–85.2 ms for Hybrid ANN-SNN [3], and 78.2–135.8 ms for LEIR [61]—a 5× to 20× improvement. The ANN variant of ResPose (8.12 MPJPE) already surpasses EvSharp2Blur, indicating the SNN-CNN hybrid encoder contributes an additional ~1.5 px gain over a purely artificial-neural-network event branch.

## Relation to Prior Work

FlashCap departs from both optical MoCap (Vicon, high-speed RGB cameras) and IMU-based systems by encoding joint identity directly into LED blinking patterns (distinct on/off durations) that an event camera detects asynchronously, thereby generating native 1000 Hz 2D labels without any high-speed camera. The ResPose architecture repurposes existing components—ViTPose as a structural anchor, LIF-neuron SNNs for event encoding, and a Transformer for global kinematic consistency—into a residual-refinement paradigm where events supply only the micro-movement delta rather than the full pose. This positions the work at the intersection of event-based HPE (EventCap, DHP19, BEAHM) and multimodal fusion (LEIR, RELI11D), but the key conceptual departure is using the event stream as a *labeling* mechanism (via LED pattern matching) rather than solely as a *prediction* input.

## Why It Matters / Open Questions

FlashMotion is the first publicly available multi-modal human motion dataset with 1000 Hz pose ground truth, an order of magnitude beyond prior benchmarks (120 Hz), and it introduces PMT as a formal task with single-digit-millisecond evaluation—opening a research direction for millisecond-level motion analysis in sports, robotics, and biomechanics. A key limitation is that 3D labels remain at 60 Hz (SMPL from IMU+LiDAR), so the full 3D millisecond problem is still open; additionally, the system requires a 17-LED suit, limiting deployment to controlled settings. The finding that even dedicated event-based and hybrid methods fail at PMT (errors of 50–135 ms) while a simple RGB-anchor-plus-event-residual baseline succeeds suggests the field has not yet developed appropriate inductive biases for sub-frame temporal reasoning, a gap likely to attract follow-up work.

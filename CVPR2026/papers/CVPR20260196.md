## Problem

No public skeleton-based dataset exists for online micro gesture recognition, and existing online gesture datasets are small, noisy, and dominated by macro gestures with clear temporal gaps. The subtle inter-class differences, rapid dynamics (average duration ~0.57 s), and continuous same-class execution of micro gestures expose fundamental limitations in both two-stage detect-then-classify pipelines and CTC-based sliding-window methods, which either decouple detection from classification or collapse to blank predictions on weak signals.
![Teaser figure](../imgs/CVPR20260196/cropped_page0_idx0.webp)

## Input / Output

The model consumes a streaming 21-joint 3D hand skeleton at 30 FPS, segmented into non-overlapping sliding windows of fixed length T_w. It produces, in a single forward pass per window, both the temporal position (center coordinate and width) and the class label (among 40 fine-grained micro gesture categories) for each detected gesture instance, with low-confidence predictions filtered at a 0.7 threshold during inference. The hierarchical memory banks carry forward context across windows so that no re-extraction or overlapping is needed.

## Method

HMATr combines a lightweight ST-GCN backbone (frame-level features via global average pooling over joints plus sinusoidal window positional encoding) with a two-tier memory bank: a frame-level FIFO queue storing recent raw frame features and a window-level FIFO queue storing per-window query embeddings. Learnable position-aware queries are initialized by averaging the window-level memory and then interact with both the frame-level memory (Frame Memory Interaction) and the current window features (Position-aware Interaction) via cross-attention, unifying detection and classification in one set of queries. Training is end-to-end with a DETR-style bipartite matching loss (cross-entropy classification + L1/IOU position) augmented by a query-based CTC loss that penalizes blank predictions on short, subtle gestures, reducing the network's tendency to suppress weak micro-gesture signals.

## Results

On OMG-Bench, HMATr achieves a Detection Rate of 89.2%, False Positive Score of 0.22, Jaccard Index of 0.71, and Normalized Levenshtein Distance of 0.77, outperforming the best baseline (HiOD at 81.2% DR) by 7.6 percentage points in detection rate. HMATr also attains the lowest inference time (1.61 ms) and average delay (7.67 frames) among all compared methods, thanks to its non-overlapping sliding window and hierarchical memory design. On the macro-gesture benchmarks SHREC'22 and SHREC'21, HMATr further achieves SOTA performance (DR 0.95/0.92, FP 0.08/0.04), confirming generalizability beyond micro gestures.

## Baselines & Comparisons

HMATr outperforms all 13 baselines across every recognition metric on OMG-Bench. Among offline-trained sliding-window methods, the strongest is HiOD (81.2% DR, 0.70 NLD), which HMATr surpasses by 8.0% in DR and 0.07 in NLD while also reducing inference time from 72.44 ms to 1.61 ms. Among CTC-based methods, HD-GCN+CTC (77.3% DR) and STMG (73.1% DR) are the closest, yet both trail HMATr by over 11 and 16 percentage points in DR respectively. Among boundary-supervision methods, Bound.Reg. (81.6% DR) and OO-dMVMT (79.1% DR) are the strongest, with HMATr leading by 7.6% and 10.1% in DR. Notably, the two-stage detection approach (Det [21]) performs worst (66.4% DR, 0.41 FP), confirming the paper's argument that decoupling detection from classification is detrimental for subtle micro gestures. On the macro-gesture benchmarks SHREC'22 and SHREC'21, HMATr also achieves the best DR (0.95 and 0.92) and lowest FP (0.08 and 0.04), beating the previous best OO-dMVMT by 3% and 4% in DR respectively.

## Relation to Prior Work

This paper adapts DETR's query-based detection framework (learnable queries, bipartite matching loss, unified detection/classification heads) to the streaming skeleton gesture recognition setting, replacing the two-stage detect-then-classify or CTC-based paradigms used in prior online methods (SHREC'21/22, OO-dMVMT). The backbone is a lightweight ST-GCN, while the key architectural departure is a hierarchical memory bank (frame-level for fine-grained details, window-level for semantics) that enables non-overlapping sliding-window inference without the information loss that typically forces prior methods to use high-overlap windows. Conceptually, the paper bridges object detection (DETR-style queries) and temporal action recognition (streaming skeleton processing), a combination not previously explored for gesture tasks.

## Why It Matters / Open Questions

OMG-Bench fills a critical gap as the first large-scale public benchmark for skeleton-based online micro gesture recognition, enabling reproducible research in a setting directly relevant to VR/AR interaction where macro gestures cause user fatigue. The 7.6% detection-rate improvement and the demonstration that non-overlapping windows with hierarchical memory can outperform overlapping-window baselines offer a practical recipe for real-time deployment. Open questions include whether the approach generalizes to multi-hand or two-handed micro gestures, how performance degrades under sensor noise in unconstrained environments, and whether the 40-class taxonomy captures the full space of useful micro interactions. The single-hand, 18-subject scope and the reliance on a controlled multi-view capture system limit immediate real-world transferability.

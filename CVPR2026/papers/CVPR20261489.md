## Problem

Existing dynamic MoE-based model merging methods construct their expert pools by processing each task vector in isolation (e.g., per-task SVD), failing to model the shared structural knowledge across tasks and leaving inter-task conflicts implicitly encoded within isolated experts. Static structural methods, while more principled, produce a single fixed model that cannot adapt to diverse inputs. No prior approach simultaneously resolves structural conflicts at the expert-construction stage and recovers task-specific information lost during low-rank compression.

## Input / Output

The method takes a pre-trained ViT base model (B/32 or L/14) and T fine-tuned expert models, extracting task vectors (parameter differences) for each linear layer in the FFN blocks. At inference, a single input image is routed through a lightweight router network that produces input-dependent task weights, yielding a class label. The static correction matrix is pre-computed offline using unlabeled in-domain data for neuron activation profiling, while the router is trained on a small unlabeled set via multi-task entropy loss. Attention layers are merged via conventional Task Arithmetic; only FFN layers undergo the full DuetMerging pipeline.

## Method

DuetMerging combines two complementary components. For dynamic merging, task matrices from all T experts are stacked into a 3D tensor (T × d_out × d_in) and decomposed via Tucker decomposition into a shared core tensor G and three orthogonal factor matrices (U_task, U_out, U_in); at inference, a router produces task weights w(x), which are projected through U_task to form a dynamic task vector, then combined with G, U_out, and U_in to reconstruct an input-specific task matrix. For static merging, the residual tensor (original minus Tucker reconstruction) is sparsified using neuron-activation-guided binary masks: for each task, the top-k% most-activated FFN intermediate neurons are identified from unlabeled in-domain data, and only the corresponding residual weights are preserved, scaled, and averaged across tasks to form a fixed correction matrix. The final merged model is W_base + Δ_dynamic(x) + Δ_static, where the dynamic component provides input-adaptive expertise from a harmonized, conflict-reduced expert pool and the static component surgically recovers task-specific knowledge lost in the low-rank approximation.

## Results

On the ViT-B/32 benchmark across 8 image classification tasks, DuetMerging achieves 89.8% average accuracy and 99.2% average normalized accuracy, surpassing the strongest dynamic baseline WEMoE (89.4%, 98.7%) and even the fully-supervised Multi-Task model (88.9%, 98.3%). On the larger ViT-L/14 model, DuetMerging reaches 93.8% average accuracy and 99.7% normalized accuracy, effectively closing the gap with individual fine-tuned experts (94.1%, 100%). The method also demonstrates superior parameter efficiency, maintaining high accuracy at low Tucker decomposition ranks compared to uncompressed MoE-based methods.

## Baselines & Comparisons

DuetMerging outperforms all 10 baselines on average accuracy across both model scales. Against the closest dynamic competitors, it beats WEMoE by 0.4% accuracy (89.8 vs. 89.4) and SMILE by 0.5% (89.8 vs. 89.3) on ViT-B/32, with similar margins on ViT-L/14 (93.8 vs. 93.6 for both). The gap widens substantially against structural static methods: DuetMerging surpasses DOGE AM by 3.9%, WUDI-Merging by 4.6%, and TSV-Merging/Iso-Merging by 6.7% in average accuracy. Against heuristic baselines, the advantage is dramatic—DuetMerging exceeds Task Arithmetic by 20.8% and Fisher Merging by 21.5% in average accuracy. Notably, DuetMerging also surpasses the fully-supervised Multi-Task model (89.8 vs. 88.9) without requiring joint training data, and achieves the highest normalized accuracy (99.2%) among all merging methods, indicating near-parity with individual expert models.

## Relation to Prior Work

DuetMerging extends the dynamic MoE-based merging paradigm (WEMoE, Twin-Merging) by replacing per-task SVD compression with a unified Tucker decomposition over a stacked task tensor, so that all expert modules are reconstructed from a shared core tensor rather than in isolation. It additionally introduces a static correction component inspired by TIES-Merging's sparsification philosophy, but grounded in neuron activation profiling rather than parameter magnitude or sign conflicts. The 'duet' framing—combining a harmonized dynamic expert pool with a surgically sparsified residual—represents a departure from prior methods that treat dynamic routing and static parameter correction as separate, independent design axes.

## Why It Matters / Open Questions

The paper demonstrates that explicitly modeling cross-task structure via tensor decomposition yields a more coherent expert pool than per-task factorization, and that neuron activation patterns provide a data-informed, task-specific sparsification signal superior to magnitude-based heuristics. However, the evaluation is confined to ViT-B/32 and ViT-L/14 on eight image classification datasets, leaving open whether the approach generalizes to LLMs, diffusion models, or substantially larger task counts where the Tucker core tensor may become unwieldy. The requirement for unlabeled in-domain data to profile neuron activations also introduces a practical dependency that pure data-free merging methods avoid.

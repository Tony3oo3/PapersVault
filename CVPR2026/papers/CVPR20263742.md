## Problem

Standard LoRA, when applied to multimodal LLM fine-tuning, exhibits severe modality imbalance: parameter-level analysis via Fisher Information Matrix shows the Non-Text Dominance Rate drops to only 14.8% by the end of training, meaning text overwhelmingly drives weight updates and non-text modalities are underutilized. Existing remedies such as explicit per-modality LoRA matrices increase trainable parameters linearly with modality count and prevent merging with pretrained weights, sacrificing the core efficiency advantages that make LoRA attractive.

## Input / Output

The method operates on a frozen LLM backbone (LLaMA-2-7B, LLaMA-3-8B, Qwen2.5-VL-7B, or Qwen3-8B) that receives a text prompt concatenated with non-text tokens projected into the language embedding space via Q-Former + two-layer MLP adapters. Non-text inputs are first encoded by pretrained encoders (CLIP ViT/L-14 for vision, BEATs for audio, Whisper for speech) before projection. The model produces a standard text response, and the fine-tuned LoRA weights remain fully mergeable into the backbone at inference, incurring zero additional latency or memory overhead.

## Method

IMoD implicitly partitions a single LoRA matrix A into text-specific, non-text-specific, and shared regions via randomly interleaved binary masks, with a layer-wise allocation strategy that progressively increases the shared fraction in deeper layers (r_s^(l) = r_s^(0) + α·l/L, α=0.4). Two gradient-level constraints guide optimization: the Modality-Specific Decoupling Constraint enforces that the output computed using only a modality's relevant parameters (its specific + shared mask) matches the full-matrix output, thereby suppressing cross-modal interference; the Modality-Agnostic Alignment Constraint aligns the mean shared-parameter representations across modalities using a cosine term weighted by per-modality centralization coefficients that measure how well each mean captures the sequence's overall semantics. Rather than adding these as loss terms, their per-parameter gradients are directly injected into LoRA's backward pass (G_A = ∇L_Task + λ₁·G_MSD + λ₂·G_MA), enabling localized, fine-grained regulation of each parameter within its designated partition while preserving identical trainable parameter count and full mergeability with standard LoRA.

## Results

On the audio-visual-text benchmarks, IMoD achieves 77.31% on MUSIC-AVQA and 75.77% on AVE with LLaMA-2-7B-Chat, 75.71% and 74.38% with Qwen2.5-VL-7B, and 80.13% and 76.94% with Qwen3-8B, yielding an average improvement of ~3.3% over standard LoRA across all backbones. In the visual-text setting (LLaMA-3-8B), IMoD scores 1077.34 on MME, 70.60 on MMBench, 80.03 on POPE, and 57.26 on SEED-Bench. In the speech-text setting (LLaMA-3-8B), IMoD reaches 51.17 on MMAU and 45.32 on AIR-Bench. Crucially, IMoD maintains the same 2.23% trainable parameter ratio and 100% inference latency as standard LoRA, with full weight-mergeability.

## Baselines & Comparisons

IMoD outperforms all six baselines across every benchmark and backbone. Against standard LoRA, the gains are most pronounced on AVE with LLaMA-2 (+5.93 points, 75.77 vs. 69.84) and moderate on MUSIC-AVQA with Qwen3 (+1.56, 80.13 vs. 78.57). The closest competitor is MokA (explicit modality decomposition), which IMoD surpasses by 1.60 points on MUSIC-AVQA (LLaMA-2: 77.31 vs. 75.71) and 1.56 points on AVE (LLaMA-2: 75.77 vs. 74.68), while also matching LoRA's single-matrix parameter count and full mergeability that MokA lacks. Uni-modal LoRA and LoRAMoE, which allocate separate matrices per modality, trail IMoD by 2.9–3.9 points on MUSIC-AVQA and 2.9–4.3 points on AVE under LLaMA-2. DoRA and HydraLoRA, which modify LoRA's structure without addressing modality imbalance, improve over vanilla LoRA by only 0.5–1.4 points and remain 2–4 points below IMoD. In the visual-text and speech-text settings, IMoD similarly leads all baselines, e.g., 1077.34 vs. 1072.67 (MokA) on MME and 51.17 vs. 51.05 (MokA) on MMAU with LLaMA-3.

## Relation to Prior Work

This paper builds directly on LoRA (Hu et al., ICLR 2022) and repurposes the Fisher Information Matrix framework from continual learning (Kirkpatrick et al., 2017) to diagnose modality imbalance at the parameter level. It departs from explicit modality decomposition approaches like MokA and Uni-modal LoRA, which allocate separate LoRA matrices per modality at the cost of linear parameter scaling and loss of mergeability. The key conceptual departure is achieving implicit, parameter-level separation within a single LoRA matrix through gradient-level constraints rather than architectural duplication, while also introducing a layer-wise allocation strategy that leverages the known property that deeper Transformer layers encode more modality-agnostic representations.

## Why It Matters / Open Questions

The paper addresses a well-documented and practically critical problem—text dominance in MLLM fine-tuning—with a solution that preserves LoRA's core deployment advantages (identical parameter count, full weight mergeability, zero inference overhead), making it immediately adoptable by practitioners already using LoRA. A notable limitation is that the decomposition is binary (text vs. non-text), so it is unclear how the method generalizes when multiple non-text modalities (e.g., audio, video, and tactile) need independent specialization within the 'non-text' partition. Open questions include whether the gradient-level constraint injection scales efficiently to very large LLMs or to more than three modalities, and whether the layer-wise shared-parameter growth rate α transfers across architectures without re-tuning.

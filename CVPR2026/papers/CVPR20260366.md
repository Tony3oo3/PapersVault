## Problem

Existing vision-language models are constrained by static knowledge bases and limited fine-grained analysis of high-resolution images, while prior agentic approaches either focus exclusively on search tools or image manipulation tools without effective multi-tool coordination. No prior work unifies text search, image search, and image crop within a single RL-trained agentic VLM, and no benchmark evaluates search-oriented reasoning on high-resolution, knowledge-intensive visual scenes.

## Input / Output

The agent receives a natural language query paired with a high-resolution image (4K resolution in the HR-MMSearch benchmark, where key visual subjects occupy less than 5% of the image area) and produces a multi-turn reasoning trajectory of at most 10 turns. Each turn consists of a reasoning step followed by exactly one action: a text search query, a reverse image search (referencing an image index), an image crop (normalized bounding box in [0.0, 1.0] plus image index), or a final text answer. Tool outputs (search result summaries, cropped images) are appended to the evolving interaction history, and the trajectory is invalid if any turn lacks either a reasoning step or a valid action.

## Method

SenseSearch is built on Qwen2.5-VL-7B-Instruct and trained in two stages: a cold-start SFT on ~3,000 curated multi-turn trajectories (synthesized by Gemini-2.5-Flash and verified by GPT-4o) to bootstrap basic tool-usage patterns, followed by RL using the proposed BN-GSPO algorithm. BN-GSPO extends GSPO with a two-stage advantage normalization: first, group-level standardization of sequence rewards within each prompt's G sampled responses, then batch-level normalization across all prompts in the optimizer minibatch, which corrects inconsistent reward scales and trajectory-length variance that destabilize standard GSPO in multi-tool settings. The sequence-level reward combines an accuracy component (LLM-as-a-judge semantic match) and a format compliance component (strict JSON tool-call schema and tag structure). During RL, the agent interacts with three tools—text search via Serper API (top-5 results summarized by Qwen3-32B), reverse image search via Serper Image API (pre-cached thumbnails), and image crop (normalized bbox)—with a Clip-Higher strategy (ε_low=0.2, ε_high=0.28) borrowed from DAPO to encourage exploration.

## Results

On search-oriented benchmarks (Table 1), SenseSearch-RL achieves an average of 57.43, surpassing the previous open-source SOTA MMSearch-R1 (52.49) by 4.94 points and outperforming GPT-4o-mini by 11.78 points, while remaining competitive with GPT-4o (60.93) and Gemini-2.5-Flash (58.05) in the agentic setting. On the newly introduced HR-MMSearch benchmark, SenseSearch-RL scores 38.52, a 19.18-point improvement over MMSearch-R1 (20.33). On fine-grained visual understanding (Table 2), SenseSearch-RL attains 72.8 average across V* Bench (83.8), HR-Bench 4K (73.6), HR-Bench 8K (69.8), and MME RealWorld (63.9), exceeding specialized crop-only models Pixel-Reasoner (71.9) and DeepEyes (72.5) as well as GPT-4o (71.5).

## Baselines & Comparisons

SenseSearch-RL outperforms MMSearch-R1 by 4.94 points on average across search benchmarks, with the largest gap on HR-MMSearch (38.52 vs. 20.33, +18.19) and MMSearch (59.06 vs. 53.80, +5.26), confirming that adding the image crop tool and BN-GSPO RL yields substantial gains over search-only agents. Against proprietary models in the agentic setting, SenseSearch-RL (57.43) trails GPT-4o (60.93) by 3.50 points and Gemini-2.5-Flash (58.05) by 0.62 points, but surpasses GPT-4o-mini (45.65) by 11.78 points. On fine-grained visual understanding, SenseSearch-RL (72.8 avg) beats both crop-only specialists Pixel-Reasoner (71.9) and DeepEyes (72.5), as well as GPT-4o (71.5), demonstrating that unified multi-tool RL generalizes better than single-tool approaches. The ablation in Table 3 shows BN-GSPO outperforms GRPO (50.88/67.54/61.38) and GSPO (53.80/53.93/44.50) on MMSearch, V* Bench, and HR-Bench 4K respectively, with the most dramatic gain on V* Bench (+11.51 over GRPO, +25.12 over GSPO), indicating batch normalization is critical for stable multi-tool RL. Visual-ARFT (40.13) and DeepMMSearch-R1 (partial results) are substantially outperformed, highlighting the advantage of the two-stage cold-start + RL pipeline over single-stage or code-execution-based agentic approaches.

## Relation to Prior Work

SenseSearch unifies two previously separate research threads: search-augmented agentic VLMs (MMSearch-R1, Search-R1) that use text and image search tools, and 'thinking with images' models (DeepEyes, Pixel Reasoner) that use image crop for fine-grained perception. It extends the MMSearch-R1 problem setting by adding the image crop tool and focusing on high-resolution inputs, and extends the GSPO RL algorithm with batch normalization (BN-GSPO) to handle the heterogeneous trajectory structures and reward scales that arise in multi-tool rollouts. The cold-start SFT + RL two-stage pipeline follows the recipe established by Pixel Reasoner and Mini-o3, which showed that pure RL alone cannot bootstrap multi-turn tool-use behavior.

## Why It Matters / Open Questions

The paper addresses a practical gap: existing agentic VLMs are either search-only or crop-only, and real-world visual tasks often require both. The HR-MMSearch benchmark (305 4K images, 2025 events) fills a notable evaluation gap for high-resolution, knowledge-intensive search tasks, and the BN-GSPO algorithm offers a concrete fix for training instability in multi-tool RL that practitioners will likely encounter. Limitations include reliance on external APIs (Serper) for search, LLM-as-a-judge evaluation, and evaluation primarily on a 7B model; open questions include whether the multi-tool coordination strategy scales to larger models, whether the tool set can be expanded (e.g., code execution, OCR), and whether the cold-start dataset size (~3K samples) is truly minimal or task-dependent.

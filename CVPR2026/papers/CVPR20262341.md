## Problem

Existing test-time adaptive object detection (TTAOD) methods focus almost exclusively on improving classification confidence while leaving bounding box localization untouched, producing highly confident yet spatially inaccurate predictions under domain shifts. Moreover, open-vocabulary TTA approaches treat text prompts as static inputs, ignoring the rich instance-level visual evidence available at test time that could refine both localization and semantics.
![Teaser figure](../imgs/CVPR20262341/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image (processed at 600×600) and a text prompt listing K target class names (e.g., 'truck . bicycle . person .') as input. It outputs refined bounding boxes in [x, y, w, h] format, softmax-normalized class labels, and confidence scores. Unlike prior TTA methods that only re-score fixed proposals, ViTPrompt produces genuinely new box coordinates from a second decoding pass, and the entire pipeline requires no backpropagation, parameter updates, or external memory beyond the base model's activations.

## Method

ViTPrompt is a training-free, two-stage inference pipeline built on Grounding DINO. In Stage 1, a standard forward pass yields initial detections; the top-K high-confidence proposals are selected, class-specific NMS is applied, and RoI-aligned visual tokens are cropped from the largest-scale feature map for each surviving box. In Stage 2, these visual tokens are concatenated with the original text embeddings to form an augmented embedding matrix, which is fed back into the query selection and DETR-style decoder to produce updated box coordinates and classification logits. A max-pooling fusion step (Eq. 7) merges logits from text and visual embeddings per class, and a confidence threshold filters the final predictions. The key insight is that instance-specific visual cues projected into the language space enable the cross-modal decoder to re-attend to more relevant image regions, simultaneously correcting both localization errors and semantic misalignment in a single extra forward pass.

## Results

ViTPrompt achieves state-of-the-art mAP@50 across all three domain-shift benchmarks with the Swin-B backbone: 37.27% on FoggyCityscapes, 71.40% on PASCAL-C, and 42.28% on COCO-C. With the lighter Swin-T backbone, it reaches 29.10%, 43.03%, and 26.25% respectively. The method is entirely training-free (no backpropagation, no parameter updates) and adds only 0.05M parameters and ~107G FLOPs over the base Grounding DINO, while maintaining identical peak GPU memory (2946 MB).

## Baselines & Comparisons

ViTPrompt outperforms all ten baselines on every benchmark and backbone configuration. Against the closest competitor BCA+ (the strongest prior training-free method), ViTPrompt gains +2.45 mAP50 on FoggyCityscapes (Swin-B: 37.27 vs 36.22), +2.09 on PASCAL-C (71.40 vs 69.31), and +2.30 on COCO-C (42.28 vs 39.98). The advantage is most pronounced on challenging categories: on FoggyCityscapes, Bicycle improves by +4.15 over BCA+ (46.64 vs 42.49) and Bus by +2.64 (48.26 vs 45.66), where dense fog severely degrades appearance. All Faster R-CNN-based baselines (SHOT, T3A, Self-Training, TTAC, STFAR, W3TTAOD) require backpropagation and trail by 10–20+ mAP50 points, confirming that the open-vocabulary Grounding DINO framework is essential for competitive performance. Among backprop-free methods, TDA and BCA are consistently outperformed by 2–6 points, while ViTPrompt's gains over the unadapted Grounding DINO base range from +5.93 (FoggyCityscapes, Swin-B) to +8.25 (PASCAL-C, Swin-B), demonstrating that visual-token prompt refinement substantially improves both localization and classification under domain shift.

## Relation to Prior Work

ViTPrompt builds directly on Grounding DINO's architecture, reusing its Swin Transformer visual encoder, BERT text encoder, language-guided query selection, and DETR-style decoder without any parameter modification. It departs from prior TTAOD methods (SHOT, T3A, TTAC, STFAR) that operate on closed-set detectors and only recalibrate classification scores, and from recent VLM-based TTA approaches (TDA, BCA, BCA+) that treat text prompts as static inputs. The key conceptual departure is a two-stage inference loop where RoI-aligned visual tokens from the first pass are concatenated into the text embedding matrix, effectively turning the detector's own high-confidence detections into a richer, instance-aware prompt for a second decoding pass.

## Why It Matters / Open Questions

By jointly refining bounding boxes and class scores in a single extra forward pass without backpropagation, ViTPrompt addresses a practical gap: under severe domain shifts (fog, heavy noise), classification-only adaptation can yield confident but spatially wrong boxes, which is critical for downstream tasks like autonomous driving. The method's plug-and-play nature (no weight updates, no external memory, identical peak GPU memory) makes it attractive for real-time deployment. However, the approach is tightly coupled to Grounding DINO's specific architecture (RoI-Align on the largest-scale feature map, DETR decoder with sigmoid scoring), raising open questions about transferability to other open-vocabulary detectors. The ~73% FLOPs increase from the second pass also limits applicability in latency-critical settings despite the memory neutrality.

## Problem

Multimodal web search agents are highly susceptible to contextual noise: irrelevant visual backgrounds misdirect image retrieval, and cluttered webpage elements (ads, navigation bars) dilute critical information during reasoning. Existing agents passively accumulate all observations into their context without any mechanism to actively filter or manage this noise, leading to 'false factual bases' and reasoning failures in high-noise scenarios.
![Teaser figure](../imgs/CVPR20263112/cropped_page0_idx0.webp)

## Input / Output

The agent receives a natural-language query paired with a full RGB image and iteratively produces a trajectory of reasoning thoughts, tool calls (image search, text search, webpage retrieval), and internal focusing operations, culminating in a free-form text answer. A distinctive output is the agent-generated bounding box (x1, y1, x2, y2) that specifies a cropped sub-region of the input image to be used as the query for reverse image search, rather than submitting the entire image. The agent also emits Defocus/Refocus calls that reference unique IDs in an external memory store, making the context window a dynamically curated subset of all retrieved content.

## Method

ReFAct augments the standard ReAct loop with two active focusing mechanisms: (1) a Grounding tool where the agent directly predicts bounding boxes to crop high-relevance image regions before image search, avoiding external detector biases and enabling joint optimization with reasoning; and (2) a dual-memory system with Defocus (offloading dense retrieved content to an external store while retaining a summary + reference ID in working memory) and Refocus (precisely retrieving offloaded content by ID when later needed). The full ReFAct-7B model is trained end-to-end via GRPO reinforcement learning on Qwen2.5-VL-7B-Instruct, using a composite reward of LLM-as-a-Judge semantic correctness and a format-compliance penalty for invalid tool calls or malformed boxes. Training data combines the newly constructed GroundedVQA dataset (1,817 instances requiring mandatory visual grounding) with 3,000 FVQA samples, and the RL stage runs for 2 epochs with group size 8 and KL coefficient 0.01.

## Results

On the proposed GroundedVQA benchmark (pass@1, LLM-as-Judge), ReFAct-7B achieves 51.3% on Level-1 and 37.5% on Level-2, outperforming the strongest RL-trained baseline MMSearch-R1 (43.3%/30.4%) by +8.0 and +7.1 points respectively. On the low-noise SimpleVQA benchmark, ReFAct-7B reaches 61.6%, surpassing MMSearch-R1 (57.4%) and WebWatcher (54.3%). However, on LiveVQA, ReFAct-7B (30.0%) trails both MMSearch-R1 (48.4%) and WebWatcher (51.2%), revealing a trade-off where the Grounding tool's region-level focus reduces holistic image comprehension needed for that task.

## Baselines & Comparisons

ReFAct-7B decisively outperforms all RL-trained open-source baselines on its home benchmark GroundedVQA: it beats MMSearch-R1 by +8.0 (L1) and +7.1 (L2), and WebWatcher by +14.1 (L1) and +14.3 (L2). On SimpleVQA, ReFAct-7B (61.6%) also surpasses both MMSearch-R1 (57.4%) and WebWatcher (54.3%), indicating the grounding mechanism does not over-process when noise is low. However, ReFAct-7B loses substantially on LiveVQA (30.0% vs. 48.4% for MMSearch-R1 and 51.2% for WebWatcher), which the authors attribute to the Grounding tool reducing holistic image comprehension needed for that task. Against closed-source models, ReFAct-7B beats both GPT-5-mini and Gemini-2.5-flash on GroundedVQA (51.3% vs. 21.1%/28.2% on L1) and SimpleVQA (61.6% vs. 63.2%/72.5%), but trails them on MMSearch and LiveVQA, confirming that the active focusing mechanism is most beneficial in high-noise, grounding-required scenarios rather than general-purpose multimodal search.

## Relation to Prior Work

This paper extends the ReAct agent paradigm and recent multimodal web search agents (MMSearch-R1, WebWatcher) by introducing an active context-management layer: a Grounding tool for selective visual attention and Defocus/Refocus operations for working-memory control. It departs from the passive full-image/full-page perception inherited by prior MLLM-based agents, arguing that noise filtering must be an explicit, learned action rather than an implicit byproduct of attention. The RL training follows the GRPO-based approach established by Search-R1 and MMSearch-R1, but applies it specifically to instill grounding-strategy decisions (when to crop vs. when to use the full image).

## Why It Matters / Open Questions

The paper identifies and empirically validates a practical failure mode—visual noise derailing multimodal web agents—that prior work acknowledged but did not systematically address with a dedicated mechanism. The GroundedVQA benchmark fills a gap by requiring mandatory visual grounding under high-noise conditions, which existing VQA benchmarks do not enforce. Key limitations include the RL stage targeting only visual grounding (not memory focusing), the framework's strong dependence on the base model's innate grounding ability (it helps Qwen but hurts Gemini/GPT-5-mini), and a demonstrated trade-off where region-level focus reduces query richness on holistic-comprehension tasks like LiveVQA. Open questions include whether RL can be stabilized with the dynamic context changes introduced by Defocus/Refocus, and whether the approach generalizes to streaming modalities (video, audio).

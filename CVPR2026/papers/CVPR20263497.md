## Problem

Existing memory-augmented video LLMs for long-video reasoning rely predominantly on textual summaries and retrieve a fixed number of clips at predetermined durations, failing to adaptively leverage visual evidence or handle queries that require varying temporal scopes. This rigidity limits performance on tasks demanding perceptual detail (object recognition, spatial reasoning) or long-range relational knowledge (habits, relationships) across hour- to week-long videos.
![Teaser figure](../imgs/CVPR20263497/cropped_page1_idx0.webp)

## Input / Output

The system ingests a continuous video stream (ranging from ~1 hour to 1 week) and a multiple-choice text query. At construction time, the video is segmented at dataset-specific temporal scales (e.g., 30 s, 3 min, 10 min, 1 hr for EgoLifeQA) and encoded into three memory stores. At inference, the retrieval agent iteratively issues modality-specific sub-queries against these stores, and the response agent produces a single text answer grounded in the accumulated retrieval history, which includes selected memory sources, sub-queries, and retrieved content (captions, triplets, or video frames).

## Method

WorldMM builds three complementary memories: (1) episodic memory as a set of multi-scale knowledge graphs (entity-action-entity triplets) at increasing temporal resolutions, (2) semantic memory as a single evolving KG that incrementally consolidates relational and habitual knowledge via an LLM-driven merge-and-revise process, and (3) visual memory combining feature-based embeddings (VLM2Vec-V2) of short video segments with a timestamp-indexed frame store. An adaptive retrieval agent, implemented as a multimodal LLM, iteratively selects one of the three memory sources and formulates a corresponding query, using Personalized PageRank over graph nodes (episodic) or edges (semantic) and cosine similarity over visual features, with a coarse-to-fine cross-scale reranker for episodic retrieval. The agent terminates when it judges sufficient evidence has been gathered, and a separate response agent generates the final answer from the full retrieval history, decoupling retrieval strategy from answer generation.

## Results

WorldMM-GPT achieves an average accuracy of 69.5% across five long video QA benchmarks (EgoLifeQA, Ego-R1 Bench, HippoVlog, LVBench, Video-MME long), outperforming the strongest baseline GPT-5 (61.1%) by 8.4 points. The 8B-parameter variant (WorldMM-8B) reaches 59.9% average, surpassing its corresponding base model Qwen3-VL-8B (51.6%) by 8.3 points. On the most challenging week-long benchmarks, WorldMM-GPT scores 65.6% on EgoLifeQA and 65.3% on Ego-R1 Bench, compared to 48.6% and 46.3% for GPT-5 respectively. In temporal grounding (tIoU), WorldMM achieves 10.09% on EgoLifeQA, nearly 3× the next-best baseline (Qwen3 Embedding at 4.35%).

## Baselines & Comparisons

WorldMM-GPT (69.5% avg) decisively outperforms all 16 baselines across every benchmark. Against the strongest base model GPT-5 (61.1%), WorldMM-GPT gains +8.4 points on average, with the largest margins on week-long egocentric videos: +17.0 on EgoLifeQA (65.6 vs 48.6) and +19.0 on Ego-R1 Bench (65.3 vs 46.3). Among memory-based methods, WorldMM-GPT surpasses the best prior method M3-Agent (55.1%) by 14.4 points, and HippoRAG (57.0%) by 12.5 points, demonstrating that adaptive multimodal retrieval with multi-scale temporal graphs substantially outperforms fixed-scale or text-only retrieval. The 8B variant (WorldMM-8B, 59.9%) also exceeds all open-weight baselines including Video-RTS (48.6%) and M3-Agent (55.1%), confirming the framework's effectiveness even with a smaller backbone. Notably, all long-video LLM baselines (VideoChat-Flash, Time-R1, Video-RTS) fall below 50% on EgoLifeQA and Ego-R1 Bench, while WorldMM-GPT exceeds 65% on both, highlighting the advantage of selective memory retrieval over uniform frame sampling for days-long videos.

## Relation to Prior Work

WorldMM extends the memory-augmented video LLM line (EgoRAG, Ego-R1, HippoMM, M3-Agent) by introducing a three-memory architecture that explicitly separates episodic, semantic, and visual knowledge, departing from prior work that relies predominantly on textual summaries. Its episodic retrieval builds directly on the Personalized PageRank graph-based retrieval of Gutiérrez et al. (HippoRAG), but generalizes it to multiple temporal scales and adds a cross-scale LLM reranker. The key conceptual departure is the adaptive retrieval agent that iteratively selects both the memory modality (text vs. visual) and the temporal granularity per query, rather than the fixed-scale, fixed-modality retrieval used by all prior memory-based video agents.

## Why It Matters / Open Questions

The 8.4% average gain over the strongest baseline and the 2.5× tIoU improvement over the best temporal-grounding method demonstrate that multi-scale, multimodal memory is substantially more effective than single-modality or fixed-scale approaches for hour-to-week-long video reasoning. The ablations reveal a useful decomposition: episodic memory handles event-level retrieval, semantic memory captures long-term habits and relations, and visual memory is critical for perceptual queries—suggesting that future systems should treat these as complementary rather than redundant. Open questions include the computational cost of constructing and maintaining three parallel memory structures over very long streams, whether the approach generalizes to streaming/online settings, and how the framework scales beyond the GPT-5 backbone to smaller or open-weight models without the large accuracy drop seen in the 8B variant.

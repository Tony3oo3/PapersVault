## Problem

Existing real-time neural video compression (NVC) schemes prioritize inter-frame redundancy but lack robust intra-coding capability in P-frames, leading to severe quality degradation at scene changes, interframe error propagation, and dependence on inflexible manual refresh mechanisms that cause bitrate spikes. The paper addresses this by asking whether a single unified model can adaptively balance intra- and inter-coding to handle both reference-rich and reference-scarce scenarios without external intervention.
![Teaser figure](../imgs/CVPR20263167/cropped_page1_idx1.webp)

## Input / Output

The encoder consumes a pair of consecutive frames (x_t, x_{t+1}) concatenated along the channel dimension after 8× joint downsampling, together with reference features from previously decoded frames stored in a buffer. A single shared bitstream is produced for both frames (each frame's bitrate is taken as half the shared stream size), and the decoder synchronously reconstructs both frames. The design introduces exactly 1-frame encoding latency to wait for the subsequent frame, and operates in YUV420 color space under a low-delay configuration at up to 1920×1080 resolution.

## Method

UI²C unifies intra- and inter-frame coding into a single spatio-temporal network by feeding a blank signal through an adaptor for the first frame (activating intra-coding) and informative reference features for subsequent frames (activating inter-coding), eliminating the need for a separate I-frame model. A simultaneous two-frame compression mechanism concatenates x_t and x_{t+1} along the channel dimension and processes them through a shared encoder-decoder, exploiting both forward (prior decoded frames) and backward (x_{t+1} as reference for x_t) temporal redundancies with only 1-frame latency. A two-frame quantization strategy assigns distinct quality parameters per frame index, giving the latter frame a higher qp so it serves as a better reference for subsequent frames. Training employs a hybrid reference scheme where initial batch frames randomly receive blank signals, ground-truth prior features, or noise-perturbed prior features, forcing the model to implicitly assess reference reliability and adaptively enhance intra-coding for error correction without manual refresh.

## Results

UI²C achieves an average BD-rate reduction of 12.1% over DCVC-RT (the anchor) across HEVC Class B–E, UVG, and MCL-JCV test sets, with the largest gains on HEVC Class D (−23.5%) and HEVC Class C (−16.4%). It also delivers 35.7% average bitrate savings versus VTM-17.0 and outperforms DCVC-FM by 6.8% in RD performance while running ~25× faster (65.1 fps encoding vs. 1.5 fps). The model uses 46.7M parameters (vs. 66.4M for DCVC-RT) and maintains real-time speeds of 65.1 fps encoding and 46.1 fps decoding at 1920×1080.

## Baselines & Comparisons

Against DCVC-RT (the primary real-time anchor), UI²C wins on 5 of 6 test sets with an average 12.1% BD-rate reduction, while slightly losing on MCL-JCV (+1.1%) where sequences are short (≤150 frames) and backward-reference benefits are limited. Encoding speed improves from 56.8 to 65.1 fps, though decoding drops modestly from 51.5 to 46.1 fps due to the two-frame joint pipeline. Compared to DCVC-FM, UI²C achieves 6.8% better average BD-rate (−12.1% vs. −5.3%) while running approximately 25× faster in both encoding and decoding, and uses fewer parameters (46.7M vs. 45.0M with half the latent channels and decoding steps). Against DCVC-DC, UI²C is dramatically superior in both RD performance (−12.1% vs. +33.1% average BD-rate) and speed (~40× faster). Versus VTM-17.0, UI²C saves 35.7% average bitrate while encoding ~6500× faster, though VTM still decodes faster (20.5 vs. 46.1 fps is actually UI²C faster here—VTM decodes at 20.5 fps). The paper also notes that at high bitrates on long sequences (HEVC-E), UI²C surpasses even DCVC-FM due to reduced error accumulation.

## Relation to Prior Work

This paper builds directly on DCVC-RT, the first practical real-time neural video codec that uses implicit context alignment to avoid explicit motion estimation. It departs from the standard NVC design of maintaining separate I-frame and P-frame models by borrowing a principle from classic video coding standards (H.264/H.265/H.266) where intra coding is permitted within inter-coded frames, unifying both into a single spatio-temporal network. The simultaneous two-frame compression technique, which concatenates consecutive frames along the channel dimension to exploit backward temporal references, is a novel architectural choice not present in prior DCVC variants. The hybrid reference training strategy (randomly sampling blank, ground-truth, or noise-perturbed references) is also new, designed to teach the unified model to adaptively balance intra- and inter-coding based on reference reliability.

## Why It Matters / Open Questions

The 12.1% average BD-rate improvement over DCVC-RT while maintaining comparable real-time speeds (65.1/46.1 fps) and a smaller model (46.7M vs. 66.4M parameters) makes this a practically significant advance for low-latency streaming applications. Eliminating the need for manual refresh mechanisms addresses a key deployment bottleneck—bitrate spikes at refresh points that risk network congestion—while the unified model's stable per-frame bitrate and quality are more suitable for real-world streaming. Open questions include whether the approach extends to resource-constrained edge devices (the authors acknowledge this limitation), whether the two-frame latency is acceptable in all real-time scenarios, and whether the high-bitrate gap versus non-real-time methods like DCVC-FM can be closed without sacrificing speed.

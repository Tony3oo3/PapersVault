## Problem

Existing temporal action segmentation methods model human activity as a single action stream, failing to capture the complex coordination, visual asymmetry, and gradient-dominance issues inherent in bimanual tasks. Prior dual-hand approaches (DuHa, DuCAS) require ground-truth object bounding boxes, limiting general applicability. This paper addresses the gap of performing dense, frame-wise action segmentation for both hands simultaneously from raw video without object annotations.
![Teaser figure](../imgs/CVPR20263914/cropped_page2_idx0.webp)

## Input / Output

The method takes untrimmed RGB video as input and produces dense per-frame action label sequences for both the left and right hand simultaneously through a single unified model. During feature extraction, a sliding window of fixed-length clips with symmetric padding is applied across the entire video to generate T clips, each processed through the shared encoder. Unlike prior dual-hand methods, no object bounding boxes or external annotations are required at inference; the structured semantic descriptions used in training are discarded at test time to prevent label leakage.

## Method

Polyphony is a three-stage pipeline. Stage 1 (ADH-ViT) uses a shared VideoMAE V2 ViT-Base backbone with two hand-specific classification heads, trained by alternating between left-hand and right-hand mini-batches every Δ steps to prevent the dominant hand from monopolizing gradient updates. Stage 2 (Semantic Feature Conditioning) applies a multi-layer TCN to align visual features with compositional verb-object-tool descriptions encoded by MiniLM, producing Motion-Action-Semantic (MAS) features that concatenate shared, classification, and semantic embeddings. Stage 3 (Diffusion-Based Segmentation) employs a shared encoder over MAS features, a cross-hand feature fusion module with asymmetric 1×1 convolution networks for inter-hand coordination, and hand-specific denoising decoders that iteratively refine action distributions via DDIM sampling (5 steps at inference), with an adaptive bidirectional loss weighting mechanism that dynamically boosts the underperforming hand's loss based on sliding-window validation accuracy gaps.

## Results

On the dual-hand HA-ViD dataset, Polyphony with MAS features achieves 57.1% LH accuracy and 60.6% RH accuracy, surpassing the previous best (FACT) by 12.0 and 16.8 points respectively. On ATTACH, MAS features yield 52.8% LH and 47.3% RH accuracy, outperforming DiffAct by 5.3 and 4.8 points. On the single-stream Breakfast dataset, Polyphony reaches 82.5% accuracy with a ViT-Base backbone (86M params), surpassing EAST (82.2%) which uses a ViT-Giant backbone (1B+ params) — a 12× parameter reduction.

## Baselines & Comparisons

With I3D features (matching baselines' input), Polyphony already outperforms FACT on RH accuracy (45.2 vs. 43.8) and DiffAct on LH accuracy (45.4 vs. 43.7), while remaining competitive on other metrics. With MAS features, the gap widens dramatically: FACT is surpassed by 12.0 (LH) and 16.8 (RH) accuracy points on HA-ViD, and DiffAct by 5.3 and 4.8 points on ATTACH. On Breakfast, Polyphony (MAS) beats EAST by 0.3 accuracy points (82.5 vs. 82.2) while using a 12× smaller backbone (ViT-Base 86M vs. ViT-Giant 1B+). Among I3D-based single-stream methods, Polyphony (I3D) achieves 78.6% accuracy, exceeding DiffAct (76.4%) and FACT (76.2%). For standalone action recognition (Table 5), ADH-ViT(both) achieves 60.1%/61.4% top-1 on LH/RH, trailing VideoMAE V2 (62.1%/62.6%) and UniFormerV2 (62.4%/61.4%) by ~2 points, but attains the highest top-5 on LH (90.4%) while using a single unified model instead of separate per-hand models.

## Relation to Prior Work

This paper extends temporal action segmentation from the single-stream paradigm to the dual-hand setting, building directly on DiffAct's diffusion-based segmentation formulation and the DDIM sampling framework. It departs from prior dual-hand methods (DuHa, DuCAS) by eliminating the need for object bounding boxes and instead addressing inter-hand dependencies through cross-hand feature fusion and an alternating training strategy that prevents gradient dominance by the dominant hand. The semantic conditioning stage draws on compositional action understanding (verb-object-tool decomposition from HR-SAT) but repurposes it as a training-time alignment signal via TCN rather than an inference-time classifier, and the overall architecture unifies a shared VideoMAE V2 ViT backbone with hand-specific heads in a single model rather than training separate per-hand networks.

## Why It Matters / Open Questions

Polyphony provides the first unified, object-annotation-free framework for dual-hand action segmentation, which is critical for real-world bimanual tasks in robotics, surgery, and assembly where separate per-hand models are impractical. The alternating training strategy is a simple, broadly applicable remedy for gradient dominance in multi-task settings, and the finding that a 22M-parameter MiniLM outperforms 335M-parameter BGE-large for semantic conditioning challenges the assumption that larger language models always yield better visual-semantic alignment. Open questions include whether the learned coordination bias can be mitigated, how the framework scales to more than two agents, and whether end-to-end training or LLM-generated semantic descriptions can replace the current manual, three-stage pipeline.

## Problem

Existing 3DGS-based avatar methods like LAM rely on a fixed point cloud template (e.g., FLAME vertices) with a constant number of Gaussians for all subjects, which prevents adaptive adjustment of point density to capture subject-specific features such as beards or unique hairstyles. This rigid topology forfeits one of 3DGS's core advantages—adaptive control over point distribution based on geometry—limiting fidelity in complex regions.

## Input / Output

The method takes a single RGB portrait image as input, from which DINOv2 extracts image features and Pixel3DMM recovers FLAME parameters to produce point cloud features via a Michelangelo-based encoder. The output is a complete 4D Gaussian Splatting avatar: a variable-size 3D Gaussian point cloud where each point carries full rendering attributes (color, opacity, scale, rotation, positional offset) and a binding index to a FLAME mesh face, enabling animation via Linear Blend Skinning. The number of Gaussians is not fixed but determined autoregressively by the model based on subject complexity.

## Method

The core contribution is a decoder-only Transformer that generates the 3DGS point cloud autoregressively via next-token prediction, where each point is encoded as four quantized tokens (x, y, z at 1024 levels, plus a binding index offset into a separate vocabulary range). Cross-attention layers inject concatenated DINOv2 image features and point cloud encoder features to condition generation on identity. After the AR model produces the full token sequence, a separate Transformer-based Gaussian Decoder converts de-quantized coordinates into complete Gaussian attributes, critically conditioned on both positional encodings and the AR model's hidden states—which the ablation shows are essential for quality. Training proceeds in two stages: the AR model is first trained with cross-entropy loss using a sliding-window strategy (window size 12000) over the long token sequences, then frozen while the Gaussian Decoder is trained with a combination of L1, SSIM, LPIPS, and offset-regularization losses against rendered ground-truth views.

## Results

On the NeRSemble test set (25 identities), AvatarPointillist achieves the best scores across all metrics in both self- and cross-reenactment settings. For self-reenactment, it reaches LPIPS 0.15, FID 95.18, AKD 2.38, and APD 22.86, outperforming the nearest competitor GAGAvatar (LPIPS 0.18, FID 111.76, AKD 3.93, APD 27.94). For cross-reenactment, it attains FID 160.74, CLIP 0.75, AKD 5.93, and APD 153.13, again leading all baselines. The method is trained on 394 identities and evaluated on 25 held-out identities from NeRSemble.

## Baselines & Comparisons

AvatarPointillist outperforms all four baselines on every reported metric in both self- and cross-reenactment. The closest competitor is GAGAvatar [6] in self-reenactment, where AvatarPointillist improves LPIPS from 0.18 to 0.15, FID from 111.76 to 95.18, AKD from 3.93 to 2.38, and APD from 27.94 to 22.86. In cross-reenactment, AvatarArtist [40] is the nearest on FID (175.69 vs. 160.74), while LAM [22] is closest on AKD (6.68 vs. 5.93); AvatarPointillist still leads by a clear margin on all four cross-reenactment metrics. Portrait4Dv2 [11] and AvatarArtist [40] (both NeRF-based) show the weakest identity preservation (CLIP 0.63 and 0.61) and the largest pose errors (APD 142.93 and 187.31), highlighting the advantage of explicit 3DGS geometry over implicit radiance fields. LAM [22], despite being Gaussian-based, suffers from the highest FID in cross-reenactment (238.54) due to its fixed FLAME template limiting adaptive point placement.

## Relation to Prior Work

This paper departs from the dominant paradigm in one-shot 4D Gaussian avatar generation, where methods like LAM place Gaussians on a fixed FLAME mesh template and GAGAvatar lifts 2D features into 3D, by instead formulating point cloud generation as an autoregressive sequential task. The AR strategy is directly inspired by recent work on autoregressive 3D geometry generation (Meshtron, MeshGPT, ARMesh), which quantize shapes into token sequences and train decoder-only Transformers with next-token prediction. For data construction, the paper relies on per-identity GaussianAvatars fitting on NeRSemble to obtain bound, animatable Gaussian point clouds, and uses DINOv2 and Pixel3DMM as off-the-shelf feature extractors for cross-attention conditioning.

## Why It Matters / Open Questions

By removing the fixed-topology constraint, the AR formulation allows the model to adaptively allocate point density to identity-specific features (hair, beards, complex geometry), which is a core advantage of 3DGS that prior avatar methods sacrifice. The ablation showing that AR hidden states (beyond just de-quantized coordinates) materially improve decoder output suggests the sequential generation process encodes useful structural context that a one-shot decoder cannot capture. Open questions include whether this approach scales to full-body avatars or more diverse subject categories, whether the 1024-level quantization is sufficient for higher-fidelity geometry, and whether the per-identity fitting requirement for training data limits generalization beyond the NeRSemble distribution.

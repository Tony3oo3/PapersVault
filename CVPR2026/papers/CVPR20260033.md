## Problem

Existing feed-forward 3D Gaussian splatting methods predict dense per-pixel Gaussians, generating millions of redundant primitives that are misaligned across views and incur prohibitive memory overhead when lifting semantic features. This redundancy degrades both novel view synthesis quality and 3D scene understanding, as rich semantic information must be compressed into lower-dimensional embeddings to fit the excessive Gaussian count. The paper asks whether a compact, query-driven set of Gaussians can suffice for high-fidelity reconstruction and understanding without per-pixel supervision.
![Teaser figure](../imgs/CVPR20260033/cropped_page0_idx0.webp)

## Input / Output

The method takes V unposed multi-view RGB images (no camera poses required) at 224×224 resolution and produces a fixed set of N=2048 3D Gaussians with standard attributes (3D center, opacity, 3×3 covariance, degree-0 spherical harmonics color), occupying only 4.1 MB of memory. Beyond rendering novel views, the compact Gaussians serve as anchors for lifting arbitrary 2D features (e.g., LSeg, MaskCLIP, DINOv2/v3) into view-invariant 3D feature fields, enabling open-vocabulary segmentation, multi-view correspondence, and feature upsampling at arbitrary resolutions and camera poses.

## Method

C3G-G extracts multi-view features via a frozen VGGT encoder, then concatenates N=2048 learnable query tokens with the flattened feature maps and processes them through L=2 full self-attention transformer layers. Each query token learns to attend to spatially coherent regions across all input views (an emergent property requiring no explicit supervision), and the refined tokens are decoded into individual 3D Gaussians via lightweight MLP heads. Training uses only photometric loss (MSE + LPIPS) on rendered novel views, stabilized by a progressive low-pass filter that anneals the Gaussian size parameter s from 10 to 0.3 over the first 4K steps. C3G-F extends this by copying C3G-G's architecture and freezing its attention weights while training only value projections, allowing arbitrary 2D encoder features to be aggregated into view-invariant 3D features attached to the same Gaussians, eliminating the need for expensive backward mapping or explicit multi-view consistency losses.

## Results

On RealEstate10K novel view synthesis, C3G achieves 23.61 PSNR / 0.740 SSIM / 0.203 LPIPS with only 2K Gaussians (12 views), and with brief test-time optimization reaches 28.55 PSNR / 0.890 SSIM / 0.155 LPIPS using just 28K Gaussians—roughly 65× fewer than per-pixel baselines. For 3D scene understanding on ScanNet, C3G attains 0.513 mIoU (LSeg) and 0.369 mIoU (MaskCLIP) with 4.1 MB memory and 785 FPS, outperforming LSM (0.503 / 0.286 mIoU at 61.5 MB) and CF³ (0.376 / 0.336 mIoU at 38.4 MB). For multi-view correspondence, C3G-F lifts VGGT-Tracking features to 68.1 avg PCK@10px, more than doubling the 34.0 of the raw encoder.

## Baselines & Comparisons

Against AnySplat [17], C3G without TTO achieves higher PSNR (23.61 vs 23.06 at 12 views) with 750× fewer Gaussians (2K vs 1,500K); with TTO, C3G surpasses AnySplat by ~1.8 dB PSNR at 36 views (30.25 vs 27.41) while using 127× fewer Gaussians. Against VGGT+NoPo [54], C3G without TTO improves PSNR by 2.35 dB (23.61 vs 21.26) and SSIM by 0.073, and with TTO matches or exceeds VGGT+NoPo+TTO (30.25 vs 28.10 PSNR at 36 views) with 68× fewer Gaussians. For 3D scene understanding on ScanNet, C3G outperforms the feed-forward LSM [10] by +0.010 mIoU (LSeg) and +0.083 mIoU (MaskCLIP) while using 65× fewer Gaussians and 15× less memory (4.1 MB vs 61.5 MB); it also beats per-scene CF³ [23] by +0.137 mIoU (LSeg) and +0.033 mIoU (MaskCLIP) despite using only 2 input views versus all scene images. For correspondence estimation, C3G-F more than doubles PCK@10px over raw encoder features (e.g., 68.1 vs 34.0 for VGGT-Tracking) and substantially outperforms FiT3D [56] (68.5 vs 27.2 for DINOv2-Base) and AnyUp [52] (68.1 vs 39.2 for VGGT-Tracking), demonstrating that the learned attention-based aggregation is far more effective than autoencoder-based or upsampling-based alternatives.

## Relation to Prior Work

C3G departs from the dominant per-pixel Gaussian prediction paradigm in feed-forward 3DGS (NoPoSplat, AnySplat, PixelSplat) by replacing dense pixel-aligned Gaussians with a compact set of learnable query tokens processed through a transformer, building on VGGT's geometric priors for multi-view feature encoding and RAIN-GS's progressive low-pass filtering for stable training. For 2D-to-3D feature lifting, it diverges from prior methods (LSM, CF3, Feature-3DGS) that require autoencoders to compress semantic features or explicit backward-mapping for correspondence; instead, C3G-F reuses the emergent attention patterns from the Gaussian decoder, training only value projections to aggregate multi-view features. The work also positions itself against post-hoc Gaussian reduction strategies (FreeSplat, ZPressor, AnySplat's voxel merging) by arguing that the redundancy is inherent to per-pixel processing and cannot be fixed after the fact.

## Why It Matters / Open Questions

The finding that ~2K Gaussians suffice for competitive novel view synthesis and superior 3D scene understanding challenges the assumption that per-pixel density is necessary, with direct practical implications for memory-constrained deployment (4.1 MB vs. 61–845 MB for baselines) and rendering speed. The emergent multi-view attention property, which requires no explicit correspondence supervision, opens a path toward lightweight view-invariant feature aggregation that could replace heavier autoencoder-based pipelines. Open questions include whether the compact representation degrades on highly detailed or outdoor scenes, how performance scales with scene complexity beyond the tested indoor benchmarks, and whether the 2K-token budget is universally optimal or scene-dependent.

## Problem

Although MLLMs project visual tokens into the LLM embedding space, the internal structuring of visual semantics remains poorly understood: it is unclear how globally-aligned image semantics are distributed across local patch-level tokens, whether all patches carry meaningful content, and whether the LLM's internal visual computation (self-attention and FFN) is actually necessary for most tasks. This paper tackles these questions by asking what visual tokens truly encode at the input level and how much of the LLM's processing pipeline is redundant.

## Input / Output

EmbedLens takes a single projected visual token embedding (a d-dimensional vector from the CLIP ViT + projector pipeline) and the model's full input embedding matrix W_E ∈ R^{T×d}, computing cosine similarity against every vocabulary token to retrieve top-k labels. The patch-compression benchmark constrains input to a single rendered object or character fitting exactly one visual patch, forcing all semantic attributes (identity, color, OCR glyph) into one token. Outputs include discrete token-category assignments (sink/dead/alive), per-layer semantic grounding ratios, and standard task accuracy scores across general VQA, OCR, CV-centric, and hallucination benchmarks.

## Method

The paper introduces a two-fold analytical framework. First, similarity-based clustering of post-projection visual embeddings reveals a stable tri-partition into sink tokens (image-agnostic, high cross-image homogeneity, serving structural attention roles), dead tokens (image-independent, semantically void, attracting negligible attention), and alive tokens (clustered near the text centroid, carrying image-specific meaning). Second, EmbedLens probes the input embedding space directly via cosine similarity between a target visual token and all vocabulary embeddings, distinguishing semantics originating from the vision encoder/projector from those injected by the language backbone—unlike LogitLens which probes the unembedding matrix. The authors validate this with a targeted patch-compression benchmark showing alive tokens bundle multiple semantic attributes pre-linguistically, then conduct layer-decoupling and shallow-layer-skipping ablations demonstrating that internal visual FFN/self-attention is unnecessary for most tasks and that alive tokens naturally align with mid-layer representations rather than the initial embedding space, implying direct mid-layer injection is sufficient.

## Results

The paper's headline finding is that ~40% of visual tokens entering the LLM are semantically redundant (sink or dead), and only ~60% 'alive' tokens carry image-specific meaning. Pruning dead tokens (~30% of all visual tokens) improves average benchmark accuracy from 52.7 to 53.7 on LLaVA-v1.5-7B, while randomly removing the same number of tokens degrades performance to 50.1. Removing sink tokens (both ViT and LLM sinks) has negligible impact (52.7 → 52.8 avg), confirming they are structural placeholders. Skipping the first 4–6 LLM layers for visual tokens maintains or slightly improves performance (53.2–53.3 avg), while disabling visual-only MHA drops average accuracy by 4.4 points (52.7 → 48.3), indicating that spatial attention is the one internal computation that matters for CV-centric tasks.

## Baselines & Comparisons

The primary methodological comparison is between the proposed EmbedLens (probing the input embedding space) and LogitLens (probing via the unembedding/output matrix). On label-token matching accuracy over MS COCO 2017, EmbedLens consistently achieves higher semantic recall at shallow and middle layers across LLaVA-1.5-7B/13B, InternVL-3-8B, and Qwen2.5-VL-8B, whereas LogitLens only recovers meaningful object labels at deeper layers. This demonstrates that object-level semantics are already encoded in the projected visual embeddings before any LLM transformation, a distinction the unembedding-based LogitLens cannot make. The paper does not benchmark against other token-pruning or compression methods head-to-head; instead, it positions its findings as mechanistic evidence that motivates such approaches (citing prior pruning work [5, 24, 39, 50] as consistent with the observed sparsity).

## Relation to Prior Work

This paper extends the representation-probing lineage of LogitLens by introducing EmbedLens, which operates in the input embedding space rather than the unembedding matrix, enabling it to distinguish semantics originating from the vision encoder and projector from those injected by the language backbone. It builds directly on the attention-sink literature (Jiang et al. for ViT sinks via L2-norm thresholds; Kang et al. for LLM visual sinks via channel-magnitude ratios) but repurposes these identification criteria to partition all visual tokens into three functional categories (sink, dead, alive) rather than merely flagging anomalous tokens. Conceptually, it departs from the prevailing assumption that projected visual tokens form a homogeneous input stream requiring full LLM processing, instead revealing a structured, sparse organization that aligns with mid-layer representations.

## Why It Matters / Open Questions

The finding that ~40% of visual tokens are semantically void and that internal visual computation (FFN/self-attention) is largely redundant for most tasks provides concrete, actionable guidance for MLLM efficiency: selective token pruning, minimized visual computation, and mid-layer injection are all supported by mechanistic evidence rather than heuristic tuning. Limitations include that most pruning and layer-skipping experiments are conducted on LLaVA-1.5-7B, and the patch-compression benchmark is small (70 images), so generalization to larger or differently-architected MLLMs remains to be verified. Open questions include whether the sink/dead/alive partition is stable across training regimes, whether mid-layer injection can be made training-free at scale, and whether the observed redundancy reflects a fundamental property of contrastive-pretrained encoders or an artifact of the specific projector designs studied.

## Problem

MLLMs face a fundamental scalability bottleneck for long-form video understanding: visual token sequences grow linearly with frame count, causing quadratic growth in LLM computation and memory. Existing compression methods either sacrifice fine-grained image reasoning to become video specialists, enforce a fixed efficiency-accuracy trade-off, or are incompatible with modern inference frameworks like FlashAttention and vLLM, preventing real-world deployment.
![Teaser figure](../imgs/CVPR20262935/cropped_page0_idx0.webp)

## Input / Output

The model accepts RGB images at native resolution, video sequences (up to 256+ frames at 480p), text prompts, and continuous streaming video. In Focus Mode it consumes the full visual token sequence (~324 tokens/frame), while Standby Mode compresses each frame to just 8–32 tokens. For streaming inference, the model maintains a hybrid memory: a short local window (e.g., 8 frames) in Focus Mode plus a long-term memory bank of compressed Standby tokens, enabling up to 30 minutes of visual memory within a 32K context budget. Output is standard text generation (answers, descriptions, QA responses).

## Method

POINTS-Long introduces a dual-path ViT architecture where n learnable tokens (n ∈ {8,16,32}) are appended to the patch sequence and processed through duplicated MLP layers (initialized from original weights), while an asymmetric attention mask ensures the original patch tokens attend only to themselves, preserving Focus Mode performance exactly. A temporal attention module in the last 5 ViT layers applies causal attention across k=8 adjacent frames' learnable tokens to model inter-frame redundancy. Training proceeds in two stages: Stage 1 freezes the entire original model and distills visual information into the compact token sequence; Stage 2 unfreezes the LLM at a small learning rate (1e-5) using a 2-forward strategy that jointly optimizes both Standby and Focus passes, preventing degradation of fine-grained capabilities. For streaming, a detachable KV cache mechanism migrates the compact Standby-sequence cache into a long-term memory bank when the local Focus window fills, achieving up to 40× increase in retained visual memory duration.

## Results

On the OpenCompass video benchmark (64 frames), POINTS-Long in Standby Mode retains 97.7%–99.7% of the base POINTS1.5-8B performance (avg 63.5–64.8 vs. 65.0) while using only 2.5%–10% of the visual tokens (512–2048 vs. ~20K). In Focus Mode, the model achieves 65.2 avg, slightly exceeding the baseline. On streaming video understanding, POINTS-Long (248+8 frames, 8 tokens/frame) scores 56.5 avg versus 51.9 for the 64-frame sliding-window baseline, a +4.6 point gain. Inference efficiency shows up to 6.2× generation throughput improvement and LLM prefill latency reduced to 4.6%–12.7% of the original.

## Baselines & Comparisons

Against the base POINTS1.5-8B (65.0 avg), POINTS-Long in Standby Mode at 32 tokens/frame achieves 64.8 (99.7% retention) with only 10% of the tokens, while at 8 tokens/frame it retains 97.7% (63.5) using just 2.5% of tokens—far exceeding simple baselines like avg-pooling (56.9) or low-resolution (59.2) at the same 32 tokens/frame budget. In Focus Mode, POINTS-Long (65.2) marginally surpasses the baseline (65.0), confirming the dual-mode training is non-destructive. Compared to external models, POINTS-Long (standby, 32) at 64.8 avg outperforms Qwen2.5-VL-7B (63.6) and Qwen2-VL-7B (60.9) while using only 10% of their visual tokens, though it trails InternVL3-8B (66.0) by 1.2 points. On streaming video (Table 5), POINTS-Long (56.5 avg with 248+8 frames) substantially outperforms the 64-frame sliding-window baseline (51.9) and specialized streaming models like Flash-Vstream (61.2 on Video-MME only, no full-benchmark comparison), demonstrating the detachable KV-cache advantage. The efficiency gains are concrete: 6.2× generation throughput and 4.6%–12.7% LLM prefill latency relative to the full-token baseline, validated on SGLang with H20 GPUs.

## Relation to Prior Work

This paper builds directly on POINTS1.5 as its base MLLM and borrows the parallel-MLP design from MoT to create a dual-path ViT architecture. It departs from the dominant paradigm of visual token compression in MLLMs—where methods like Q-Former, resampler, pooling, and attention-based pruning enforce a fixed efficiency-accuracy trade-off—by introducing a native dual-mode system (Focus and Standby) that decouples these two objectives within a single model. The detachable KV cache mechanism for streaming also distinguishes it from prior sliding-window or specialized streaming models, which sacrifice fine-grained understanding for long-term memory.

## Why It Matters / Open Questions

The 6.2× generation throughput improvement with 97.7–99.7% accuracy retention, validated on SGLang, makes this a practically deployable solution for production MLLM services handling long video. The zero-shot scalability of Standby Mode beyond the 128-frame training limit (where the base model plateaus) is an intriguing but unexplained phenomenon that the authors defer to future work. Key open questions include whether the mode choice can be learned dynamically ('Thinking with Videos'), whether the approach generalizes to native video encoders, and the substantial training cost (~25K H20 GPU hours) that limits adoption to well-resourced pre-training teams.

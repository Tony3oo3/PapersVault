## Problem

Raw screen recordings of human computer use are passive, untrimmed, and lack the verbal guidance and visual highlights that make tutorials effective for learning. While demonstrations capture authentic procedural knowledge, transforming them into structured, multimodal tutorials requires labor-intensive long-context compression and careful multimodal annotation. This paper addresses how to automatically distill raw human interaction experience into reusable tutorials that serve both human learners and GUI agents.

## Input / Output

The method consumes synchronized dual-stream recordings: full-resolution 30 FPS screen video (captured via FFmpeg/ddagrab) and timestamped low-level action logs (clicks, keystrokes, drags) from a dedicated HE-Recorder, plus an optional one-sentence task goal. The output is an image-text interleaved tutorial document in both markdown and JSON formats, organized as a three-level hierarchy (atomic steps → logical chapters → overarching goal), where each step pairs a natural-language instruction with a semantically aligned key-frame bearing adaptive visual annotations (click markers, drag trajectories, region highlights, magnifier effects).

## Method

Demo2Tutorial is a four-stage agentic pipeline. First, an Action Parser uses GPT-4o with action-grounded visual prompting (red bounding boxes at mouse coordinates) and a five-field chain-of-thought prompt to convert raw action logs into semantic descriptions of observations, actions, and inferred user intent. Second, a Step Planner performs bottom-up hierarchical abstraction—grouping atomic actions into steps, clustering steps into chapters, and synthesizing a tutorial goal—refined through an actor-critic loop where a separate Critic agent evaluates coverage, orderliness, and learnability across iterations. Third, a Tutorial Composer selects key-frames via a multi-criteria scoring function (OCR-based text relevance, Laplacian sharpness, motion stability, and Gaussian-weighted temporal proximity) and applies adaptive visual editing using SAM2 for UI segmentation and RapidOCR for text detection. The key differentiator from prior multi-agent or end-to-end baselines is the combination of dual-stream (video + action) input, iterative actor-critic refinement for structural quality, and perception-driven key-frame selection with context-aware visual annotation, which together yield tutorials that surpass human-authored ones in both content and visual quality.

## Results

On TutorialBench, Demo2Tutorial achieves an overall score of 86.2, surpassing human-authored tutorials (79.1) and all baselines. The Visual Score is particularly strong at 88.7 vs. 70.5 for human GT, driven by superior annotation quality (83.3 vs. 54.4) and image relevance (94.0 vs. 86.6). On the OSWorld benchmark, integrating generated tutorials into the Agent-S3 framework improves GPT-5 success rate from 52.9% to 70.6% on Chrome (+17.6) and from 59.6% to 70.7% on VLC (+11.1). In a human user study, tutorial-based learning yields 10.5% faster task completion (131.6s vs. 147.1s) and 80% user preference over raw demonstration videos.

## Baselines & Comparisons

Demo2Tutorial outperforms all four baselines on the overall TutorialBench score. Against human-authored GT tutorials (79.1), Demo2Tutorial (86.2) wins primarily on Visual Score (88.7 vs. 70.5) and Actionability (90.5 vs. 81.0), though GT retains an edge in Conciseness (83.1 vs. 70.8). The end-to-end baselines are substantially weaker: Text-based Generation (59.2 content-only) cannot produce visual output, and Vision-based Generation (64.3 overall) achieves high Completeness (95.1) but collapses on annotation quality (9.2) due to uniform frame sampling. The closest competitor, Vanilla Multi-Agent (70.3), uses action-aligned key-frames but lacks the actor-critic refinement loop and adaptive visual highlighting, resulting in a 15.9-point gap. On OSWorld, the tutorial-augmented GPT-5 agent gains +17.6 points on Chrome and +11.1 on VLC over its prompt-only baseline, confirming that multimodal tutorials provide effective external knowledge for GUI agent planning.

## Relation to Prior Work

This paper carves new ground at the intersection of instructional video understanding and computer-use agents, but departs from both. Prior instructional video work (e.g., Video-mined Task Graphs, Bridge-Prompt) targets real-world procedural videos, while computer-use agent research (OpenCUA, VideoAgentTrek, Agent-S3) focuses on training or prompting agents directly from raw demonstrations. Demo2Tutorial instead introduces an intermediate distillation step—converting raw screen recordings and action logs into structured, multimodal tutorials—repurposing existing components (GPT-4o for semantic parsing, SAM2 for segmentation, RapidOCR for text detection) within a novel actor-critic agentic pipeline that has no direct predecessor in either lineage.

## Why It Matters / Open Questions

The introduction of TutorialBench provides the first dedicated benchmark for evaluating software tutorial quality across content and visual dimensions, filling a gap where no standardized evaluation existed. The demonstration that auto-generated tutorials can serve as effective external knowledge for GUI agents (notably +17.6% for GPT-5 on Chrome) opens a practical path for injecting procedural knowledge into agent planning without retraining. However, the scope remains limited to seven desktop applications and 110 samples, the user study involves only 20 participants, and the VLM-as-judge evaluation (ρ=0.755 with human scores) introduces potential bias. Open questions include scalability to mobile/web platforms, computational cost of the full pipeline, and whether the actor-critic refinement loop generalizes to domains with highly variable UI layouts.

## Problem

Existing image generation and unified models excel at general-purpose synthesis but fail at tasks requiring precise data-to-visual mapping, such as converting a table into a faithful infographic where bar heights, pie angles, and labels must exactly reflect the source numbers. The paper introduces creative table visualization as a new challenging task that simultaneously demands aesthetic graphic-design reasoning and strict quantitative fidelity, exposing a clear capability gap in current unified models.
![Teaser figure](../imgs/CVPR20261863/cropped_page0_idx0.webp)

## Input / Output

The method takes a data table in markdown format as input, where each cell encodes dense relational semantics (categories, values, multi-layered structures). The output is a single RGB infographic image that must render every data point with correct visual proportions, legible text, and coherent layout. The pipeline supports up to 3 iterative self-correction rounds, and the process can terminate early if the reflection module judges the image satisfactory.

## Method

ShowTable is a four-stage pipeline (Rewriting → Generation → Reflection → Refinement) that synergizes an MLLM orchestrator with a diffusion executor. The rewriting module (Qwen3-8B fine-tuned on 30K SFT pairs) performs compositional planning to translate the dense table into a detailed visual prompt; the diffusion model generates an initial image; the reflection module (GPT-5) cross-references the image against the source table to emit precise edit instructions; and the refinement module executes those edits. The key training contribution is RL-based refinement: a reward model (Qwen2.5-VL-3B trained with Bradley-Terry loss on 30K preference pairs, combined with ImageReward) provides scalar scores for Flow-GRPO optimization on 5K filtered samples, addressing the critical finding that untrained editing models degrade with each correction round while capable ones improve monotonically.

## Results

On TableVisBench (800 instances, 5 evaluation dimensions), the full ShowTable pipeline (RW+Base+REF) achieves the highest overall score of 54.9 when instantiated with Qwen-Image, compared to 44.3 for the base model alone (+10.6). For weaker base models, the pipeline yields even larger absolute gains: Bagel improves from 10.1 to 32.7 (+22.6), Blip3o-Next from 10.8 to 34.8 (+24.0), and UniWorld-V1 from 14.8 to 33.5 (+18.7). The most significant per-dimension improvements come in Data Accuracy (e.g., Blip3o-Next DA: 0.5→21.3) and Relative Relationship (e.g., Qwen-Image RR: 26.1→54.3), confirming that the reflection-refinement loop primarily corrects data-to-visual mapping errors.

## Baselines & Comparisons

ShowTable consistently outperforms all six base generation models (Flux, Bagel, Blip3o-Next, UniWorld-V1, OmniGen2, Qwen-Image) on the overall Score metric, with improvements ranging from +7.1 (Flux: 29.3→36.4) to +24.0 (Blip3o-Next: 10.8→34.8). The largest absolute gains occur for the weakest baselines: Bagel (+22.6) and Blip3o-Next (+24.0), where base models score near zero on Data Accuracy (0.1 and 0.4 respectively), indicating a fundamental inability to map table data to visual elements without the pipeline's reasoning and correction steps. For the strongest base model, Qwen-Image (44.3), the pipeline still adds +10.6 points, with the most notable per-dimension jump in Relative Relationship (26.1→54.3) and Additional Information Accuracy (14.1→40.0). The pipeline's gains are concentrated in correctness dimensions (DA, RR, AA) rather than Aesthetic Quality (AQ), which improves by only 0.2–1.1 points, suggesting the reflection-refinement loop primarily fixes factual errors rather than enhancing visual design. When using the stronger Wan2.5-I2I-Preview as the refinement module (Table 4), the overall score reaches 63.4, further confirming that the pipeline's ceiling is bounded by the refinement model's editing capability.

## Relation to Prior Work

This paper sits at the intersection of two active research threads: (1) unified multimodal models that combine understanding and generation (Bagel, Blip3o, UniWorld, OmniGen2, Qwen-Image), and (2) the emerging reasoning-and-reflection paradigm where MLLMs plan, critique, and iteratively correct generated outputs. It departs from prior chart-generation work (ChartGPT, Text2Chart, ChartifyText), which typically relies on code synthesis or template filling, by framing the problem as end-to-end image generation with strict data-to-visual fidelity. The RL training of the refinement module builds directly on Flow-GRPO [37] and the GRPO algorithm [21], while the reward model design draws on preference-learning (Bradley-Terry loss) and the observation that MLLMs are unreliable as direct scalar scorers [41].

## Why It Matters / Open Questions

The near-total failure of SOTA unified models on Data Accuracy (scores of 0.1–3.1 out of 100) reveals a fundamental gap in current generative models: they cannot reliably map quantitative data to proportional visual elements, a capability essential for scientific communication, automated slide generation, and data-driven reporting. The finding that the pipeline structure is sound but the refinement model is the bottleneck provides a clear, actionable direction for improving iterative self-correction in generative pipelines. Open questions include whether the approach generalizes to other structured-data visualization tasks (e.g., multi-panel figures, network diagrams), whether the 3-round correction loop can be made more efficient, and whether the large gap between the trained open-source model (54.9) and the proprietary Wan2.5 (63.4) can be closed with further RL training or better reward signals.

## Problem

Existing multimodal reasoning benchmarks predominantly probe reasoning depth—how far a model can extend a single sequential chain—while largely ignoring reasoning width, the capacity to systematically traverse parallel solution paths, apply diverse constraints to prune dead ends, and backtrack through competing hypotheses. This paper introduces Think360°, a benchmark explicitly designed to measure this underexplored width dimension and its interplay with depth in MLLMs.
![Teaser figure](../imgs/CVPR20260324/cropped_page0_idx2.webp)

## Input / Output

Each benchmark instance pairs an RGB image (puzzle diagrams, geometric figures, game screenshots, or competition problem illustrations) with a text question (average 82 words, max 369). Models produce a free-form text answer (54.3% numerical, 37.0% structural, 5.2% formula) or select from multiple-choice options (16.9%), accompanied by a full reasoning chain. The evaluation additionally extracts a hierarchical tree-of-thought from the reasoning trace to compute ToT width and depth scores, alongside pass@1 accuracy, inference time, and token cost.

## Method

The benchmark is constructed through a three-stage pipeline: (1) raw data collection from four source categories (math/logic competitions, textbook exercises, existing multimodal benchmarks, and online puzzle games), (2) coarse-to-fine quality filtering combining keyword heuristics, GPT-4o LLM-as-Judge scoring for required cognitive abilities, and human double-check, and (3) targeted annotation that converts proof-based and game-based problems into objectively verifiable question-answer pairs. The key evaluation contribution is ToT-Eval, a tree-of-thought protocol where GPT-4o extracts reasoning steps into a hierarchical tree (depth = sequential dependencies, width = parallel sibling branches), then judges each node's correctness to compute complementary depth and width scores. The dataset is organized along four axes—answer type, five difficulty tiers (Easy through Olympiad), five non-exclusive cognitive capabilities (Perceive-and-Comprehend, Trial-and-Error, Divide-and-Conquer, Branch-and-Bound, Hypothesize-and-Test), and six question types—enabling fine-grained analysis of where width-oriented reasoning breaks down across 30+ MLLMs.

## Results

On the Think360° benchmark (740 test-mini questions), Gemini-2.5-pro achieves the highest overall pass@1 accuracy at 46.0%, followed by o3 (42.3%) and o4-mini (42.1%); only these three models exceed the 40% threshold. Among open-source models, MiMo-VL-RL-7B leads at 28.3% accuracy, substantially outperforming other open-source entries like Qwen2.5-VL-72B (16.2%) and InternVL-3-14B (15.5%). The proposed ToT-Eval reveals that reasoning width correlates more strongly with final accuracy (Spearman ρ=0.9218) than reasoning depth (ρ=0.8492), and a width threshold effect emerges: models achieving ≥20% accuracy typically maintain ToT-Width ≥45%.

## Baselines & Comparisons

This is a benchmark paper, so the 'baselines' are the 30+ MLLMs evaluated. Gemini-2.5-pro outperforms all other models across every cognitive capability subset, leading by 3.7–3.9 points over o3 and o4-mini in overall accuracy while consuming roughly 2.7× fewer tokens than o3. Among open-source models, MiMo-VL-RL-7B (28.3%) substantially surpasses the next-best open-source entries (GLM-4.1V-Thinking at 22.6%, Kimi-VL-Thinking at 26.5%) and even exceeds several closed-source non-thinking models like GPT-4o (16.0%) and Grok-2-vision (15.7%). Enabling thinking mode yields large gains: Claude-4-Opus improves from 25.8% to 30.2% (+4.4 pp) with ~4.5× more time and ~7.5× more tokens, while Claude-3.7-Sonnet-Thinking (35.5%) surpasses both Claude-4-Sonnet (28.2%) and Claude-4-Opus-Thinking (30.2%). CoT prompting provides modest additional gains for most models (e.g., Claude-4-Opus +4.6 pp, MiMo-VL-RL +1.6 pp) but can slightly hurt larger open-source models like Qwen2.5-VL-72B (−0.3 pp) and InternVL-3-8B (−0.8 pp). A critical finding is that depth alone cannot compensate for insufficient width: Llama-3.2-Vision-11B achieves 46.2% ToT-Depth but only 28.6% ToT-Width, resulting in just 7.1% accuracy, whereas Qwen2.5-VL-32B reaches 53.6% depth yet only 17.6% accuracy due to 44.9% width.

## Relation to Prior Work

This paper departs from the dominant paradigm in multimodal reasoning benchmarks (MathVista, MathVision, MathVerse, GeoQA, DynaMath) that implicitly measure reasoning depth—how far a single sequential chain extends—by introducing reasoning width (parallel exploration, backtracking, branch pruning) as a first-class, independently measurable axis. Conceptually, it draws an analogy between neural network architecture (layer stacking vs. parallel pathways, dropout vs. pruning) and reasoning strategies (sequential deduction vs. trial-and-error search), framing the two as orthogonal dimensions. The ToT-Eval protocol, which decomposes a model's response into a hierarchical tree and separately scores depth and width, is a new evaluation methodology not present in prior benchmarks, which rely on outcome-based or process-based linear scoring.

## Why It Matters / Open Questions

The finding that ToT-Width correlates more strongly with final accuracy (ρ=0.9218) than ToT-Depth (ρ=0.8492), along with the width threshold effect (models ≥20% accuracy typically maintain Width ≥45%), challenges the prevailing 'longer CoT = better' assumption and suggests that training and evaluation should explicitly target exploratory breadth. However, the ToT-Eval protocol depends on GPT-4o for both tree construction and node-level correctness judgment, introducing a potential circularity and limiting applicability to models that expose intermediate reasoning. Open questions include whether width-centric training objectives (e.g., RL rewards for branching) can close the gap, whether the protocol generalizes beyond math/logic to open-ended multimodal tasks, and how to evaluate width in models that only return final answers.

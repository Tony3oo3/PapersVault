## Problem

Current MLLMs solve each multimodal problem de novo, repeatedly re-deriving the same insights and re-committing the same visual and logical errors. Existing memory-augmented agents store only high-level logical summaries, discarding the visual grounding and perceptual cues essential for multimodal reasoning, and suffer from brevity bias that erodes domain knowledge over iterative refinement. This is fundamentally misaligned with human semantic memory, which maintains coordinated but distinct visual and abstract representational streams.

## Input / Output

The system takes an RGB image paired with a question text as input and produces a text answer as output. Internally, the visual memory bank stores structured JSON guidelines each paired with a source image, while the logical memory bank stores abstract textual reasoning guidelines. During retrieval, the visual stream additionally generates question-aware cross-modal attention maps that highlight historically error-prone regions in the query image, serving as supplementary spatial guidance alongside the original image fed to the solver.

## Method

ViLoMem is a plug-in dual-stream memory framework operating as a closed-loop cycle (Retrieve → Solve → Verify → Generate) that separately encodes visual distraction patterns and logical hallucination errors as structured schemas. Memory generation uses an MLLM for visual error attribution (producing corrective observation guidelines paired with source images) and an LLM for logical error attribution (producing abstract reasoning guidelines), with similarity-based merge-or-create operations to prevent redundancy and catastrophic forgetting. Visual retrieval employs a two-stage pipeline—multimodal image-embedding similarity followed by text-embedding reranking with an LLM-enriched query—while logical retrieval constructs enriched queries via problem-domain analysis before text-embedding matching. A grow-and-refine principle governs incremental accumulation: new memories are merged into existing entries when cosine similarity exceeds a threshold, otherwise added as new entries, enabling long-term scaling without detail erosion. The framework is model-agnostic and supports cross-model memory transfer, where memories distilled from stronger models can improve weaker solvers without fine-tuning.

## Results

ViLoMem achieves consistent pass@1 accuracy gains across all three MLLMs on six multimodal benchmarks. GPT-4.1 shows the largest improvements, reaching 77.26 on MMMU (+3.10 over step), 76.88 on MathVista (+2.61), and 53.95 on MathVision (+6.48). The smaller Qwen3-VL-8B model benefits most on MMMU (+4.38) and RealWorldQA (+2.74), while Qwen3-VL-235B-A22B gains +3.43 on MMMU and +2.15 on MMStar. On the memory scalability test (WeMath), progressively accumulated cross-benchmark memory (150k tokens) reaches 74.58%, outperforming direct on-task memory (73.85%).

## Baselines & Comparisons

The paper does not compare against external memory-augmented methods; instead, it evaluates each MLLM under three configurations: official baseline prompting, step-by-step reasoning prompting, and the proposed +ViLoMem dual-stream memory. ViLoMem consistently outperforms the step-by-step baseline across all models and most benchmarks, with the largest gains on mathematically grounded tasks (MathVision +6.48 for GPT-4.1, +0.99 for Qwen3-VL-8B) and hallucination-sensitive tasks (HallusionBench +0.85 for GPT-4.1). The 8B model shows the strongest relative benefit (+4.38 on MMMU, +2.74 on RealWorldQA), suggesting structured memory compensates for limited parametric capacity. One notable exception: Qwen3-VL-235B drops slightly on RealWorldQA (78.66 → 77.22) with ViLoMem, likely due to the model's already strong spatial reasoning making retrieved visual cues mildly redundant. Cross-model transfer experiments further show that memories generated by stronger models (e.g., GPT-4.1) can improve weaker solvers (Qwen3-VL-8B gains +1.36 on MMMU with cross-model memory), validating the framework's knowledge-distillation potential.

## Relation to Prior Work

ViLoMem departs from two established lines of work: context-engineering agents (ReAct, Reflexion, TextGrad, GEPA) that refine prompts per-interaction but cannot accumulate long-term knowledge, and long-term memory agents (Dynamic Cheatsheet, ACE) that store reasoning trajectories but are overwhelmingly logic-centric, discarding visual grounding. Rather than extending either line directly, the paper repurposes the hub-and-spoke architecture of human semantic memory (visual-semantic associations in inferotemporal/perirhinal cortex, abstract rules in temporal-parietal cortex, integrated via the anterior temporal lobe) to motivate a dual-stream design where visual distraction patterns and logical hallucination errors are stored, retrieved, and updated in separate modality-specific modules. The grow-and-refine update mechanism (similarity-based merge/create) borrows the anti-forgetting philosophy of ACE's generate-reflect-curate cycle but applies it independently to each stream with tailored retrieval strategies.

## Why It Matters / Open Questions

The paper identifies and empirically confirms a critical blind spot in current memory-augmented MLLMs: visual perception errors (59–93% of stored error cases) are the dominant failure mode yet are systematically ignored by logic-only memory systems. The cross-model transfer result—that a smaller 8B model benefits more from memories distilled by stronger models than from its own—suggests dual-stream memory could serve as a lightweight knowledge-sharing mechanism without fine-tuning. Key limitations remain: solvers with strong textual bias produce insufficient visual information for memory generation, and domain-mismatched cross-benchmark transfer shows mild interference, indicating that task-aligned memory banks are still necessary. Open questions include better decoupling of the two streams when errors are entangled, and whether the approach generalizes beyond math/science to open-ended visual tasks.

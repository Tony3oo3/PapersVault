## Problem

Existing efficient VLM methods reduce visual tokens through fixed-ratio compression (e.g., pruning 50% or switching between 25%/100% resolution), operating passively without adapting to per-sample complexity. This paper asks whether a VLM can autonomously determine the minimum number of visual tokens required for each input, inspired by the coarse-to-fine mechanism of human active vision.
![Teaser figure](../imgs/CVPR20261713/cropped_page0_idx0.webp)

## Input / Output

The model receives a 1/4-resolution image (yielding 25% of the original visual tokens) and a text question. It either produces a direct text answer or emits a bounding-box tool call in JSON format (x1, y1, x2, y2) to crop a region from the original high-resolution image, then generates the final answer conditioned on the cropped region. The total visual token cost per sample is n_low + 1_tool × n_crop, where the model learns when the second term is necessary.

## Method

AdaptVision frames adaptive visual token acquisition as a two-turn policy: the VLM first reasons over low-resolution tokens, then decides whether to invoke a bounding-box tool to crop a minimal informative region from the high-resolution image before answering. Training uses a composite reward combining outcome reward (LLM-judged accuracy, format compliance, and a balance penalty to prevent tool overuse or lucky guessing) and a tool reward that rewards correct crops while penalizing oversized bounding boxes via a relative-area term. The key algorithmic contribution is Decoupled Turn Policy Optimization (DTPO), which addresses two failure modes of vanilla GRPO: (1) it normalizes tool-token and answer-token losses separately across the group to fix gradient imbalance between one-turn and two-turn sequences, and (2) it computes distinct advantage estimates from the outcome and tool rewards, enabling precise credit assignment so that correct tool decisions are reinforced independently of answer correctness.

## Results

AdaptVision achieves 97.9% average performance across 9 VQA benchmarks while consuming only 33% of the visual tokens used by the vanilla Qwen2.5-VL-7B model (100%). This represents a 5.8% absolute improvement over the 25%-token down-sample baseline (92.1%) with just 8% additional tokens, and a 2.1% improvement over the best static compression method (FastV, 95.8% at 50% tokens) while using 17% fewer tokens. Inference time is reduced by 1.67× compared to both the vanilla model and the official VisionThink model.

## Baselines & Comparisons

AdaptVision outperforms all static compression methods (FastV, SparseVLM, VisionZip) by 2.1–5.7% in average accuracy while using 17% fewer visual tokens (33% vs. 50%). Against the dynamic baseline VisionThink (reproduced), AdaptVision gains 2.1% average accuracy (97.9% vs. 95.8%) with 19% fewer tokens (33% vs. 52%). Compared to the official VisionThink† model, AdaptVision trades a marginal 0.5% accuracy drop (97.9% vs. 98.4%) for a dramatic 66% reduction in visual tokens (33% vs. 99%), making it far more practical for deployment. Versus the simple down-sample baseline (25% tokens), AdaptVision improves average accuracy by 5.8% (92.1% → 97.9%) while using only 8% more tokens, demonstrating that adaptive coarse-to-fine reasoning recovers most of the information lost by aggressive downsampling. The ablation (AdaptVision w/o DTPO) confirms that the DTPO training algorithm contributes a 1.2% accuracy gain and a 24% token reduction (57% → 33%) over vanilla GRPO training.

## Relation to Prior Work

This paper extends the 'thinking-with-images' paradigm (DeepEyes, Mini-o3) from accuracy-focused visual reasoning to computational efficiency, repurposing bounding-box tool calls as a mechanism for adaptive visual token acquisition. It departs from prior efficient VLM methods (FastV, SparseVLM, VisionZip) that apply fixed-ratio compression, and from VisionThink which makes a binary low/high-resolution decision, by enabling the model to autonomously determine the minimal number of visual tokens per sample. The training algorithm DTPO directly modifies GRPO (from DeepSeekMath) to address two specific pathologies in multi-turn policy optimization: ambiguous credit assignment between tool and answer tokens, and gradient imbalance from uniform sequence-level normalization.

## Why It Matters / Open Questions

The 67% visual token reduction with only ~2% average performance loss (97.9% vs 100%) is a practically significant efficiency gain for deploying VLMs at scale, and the coarse-to-fine active vision framing provides a biologically motivated, interpretable mechanism. However, the framework is currently constrained to a single bounding-box tool, a fixed 1/4 initial resolution, and at most two reasoning turns, limiting its applicability to tasks requiring iterative or multi-region visual search. Open questions include whether dynamic resolution selection, richer toolsets (pan, rotate, multi-crop), and longer reasoning chains can further close the remaining gap to full-resolution performance, and whether DTPO generalizes beyond this specific two-turn tool-use structure to more complex multi-agent or multi-step policies.

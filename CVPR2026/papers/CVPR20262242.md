## Problem

Existing compositional and neuro-symbolic REC pipelines assume that intermediate reasoning steps (object detections, attribute matches, spatial relations) are correct and propagate them without verification. This causes cascading errors where high-confidence false positives from open-vocabulary detectors propagate through the reasoning chain, and in no-target cases the system is forced to hallucinate a prediction rather than abstain. The paper identifies this forced-prediction failure mode as fundamental to compositional vision-language reasoning and addresses it with operator-level verification.
![Teaser figure](../imgs/CVPR20262242/cropped_page1_idx0.webp)

## Input / Output

The system takes an RGB image and a natural language referring expression as input and produces either a bounding box (x, y, w, h in pixel coordinates) localizing the target or an explicit empty set (∅) indicating no valid target exists. The output is formalized as a binary decision that extends standard REC beyond the assumption that a target is always present. In the 1-query-N-images regime (e.g., video), a single symbolic program is generated once from the query and reused across all frames, so the per-frame output is a sequence of bounding boxes or abstentions.

## Method

VIRO is a two-stage neuro-symbolic pipeline: an LLM (Qwen2.5-72B) translates the query into a symbolic program of Verification Reasoning Operators (VROs), and an interpreter executes them sequentially over the image. The core innovation is that each operator both performs a reasoning action and self-verifies its result before passing it downstream. Two verification mechanisms are embedded: Uncertainty Verification (UV) uses a lightweight CLIP-based binary classifier to score each OVD proposal against a bank of negative anchor categories, filtering high-confidence false positives; and Logical Verification (LV) performs geometric checks to confirm spatial/relational constraints are actually satisfied. If any operator's verification fails, it returns ∅, triggering early termination and explicit no-target detection. The decoupled design separates program generation from execution, so a single program is amortized across N images, and a program validator with a self-revision loop keeps the failure rate below 0.3%.

## Results

VIRO achieves 61.1% Balanced Accuracy on RefCOCO TestA and 56.9% on TestB, substantially outperforming all compositional reasoning baselines (best: HYDRA at 35.2% on TestA) without any REC fine-tuning. On the no-target split, VIRO reaches 50.2% TNR (N-acc) on TestA versus near-zero for all proposal-based and most compositional methods, while maintaining 71.9% TPR (Acc@0.5). The framework also achieves a program failure rate below 0.3% and an execution-stage runtime of 0.71 s per query, compared to 1.49 s (ViperGPT), 30.57 s (HYDRA), and 7.08 s (NAVER).

## Baselines & Comparisons

VIRO outperforms all compositional reasoning baselines by a wide margin: on RefCOCO TestA, it achieves 61.1% Balanced Accuracy versus HYDRA (35.2%), NAVER (33.8%), and ViperGPT (33.4%), with the gap driven primarily by TNR (50.2% vs. 7.5%, 3.4%, 0.2%). Against proposal-based methods (ReCLIP, SS-CLIP, GroundVLP), VIRO's advantage is even more pronounced, as those methods yield 0.0% TNR due to their forced-prediction architecture. On standard REC TPR, VIRO (71.9%) also surpasses all compositional baselines (62.8–66.7%) and detector-based methods (52.6–57.2%), though it trails fully supervised models like Qwen2.5-VL-72B (91.7%) and GREC-UNINEXT (91.5%) by roughly 20 points. On the RefEgo video benchmark, VIRO (51.9% Acc@0.5+n) matches the fully supervised MDETR+BH (51.1%) while outperforming ViperGPT (23.0%) by nearly 29 points. In terms of reliability, VIRO's program failure rate (<0.3%) is an order of magnitude lower than NAVER (28.5%) and HYDRA (6.8%), and its 0.71 s execution time is 43× faster than HYDRA (30.57 s) in the 1-query-N-images setting.

## Relation to Prior Work

VIRO builds on the operator-based program generation paradigm from VisProg [9], which restricts the program space to well-defined primitives rather than free-form code. It departs from prior compositional reasoning REC methods (ViperGPT, HYDRA, NAVER) in two key ways: (1) each operator embeds a lightweight self-verification step (CLIP-based uncertainty filtering or geometric logical checks) that enables explicit abstention, and (2) program generation is fully decoupled from execution, so a single program is amortized across N images rather than regenerated per frame. The framework also extends the standard REC formulation to a generalized setting where the output may be an empty set, aligning with the GREC/GRES line of work but achieving this through verification rather than supervised no-target training.

## Why It Matters / Open Questions

The forced-prediction failure mode identified here is a practical bottleneck for any deployment of compositional vision-language reasoning in open-world settings (robotic search, visual navigation), where targets are frequently absent. The demonstration that a lightweight CLIP-based verifier at the operator level suffices to suppress cascading OVD false positives—without requiring a heavy multimodal LLM in the inner loop—makes the approach attractive for latency-sensitive applications. Open questions include whether the verification mechanism generalizes to more complex multi-hop relational queries, how threshold calibration scales to truly open-vocabulary labels beyond ImageNet, and whether the precision-recall trade-off (TPR drops from 74.6% to 71.9% when adding UV) can be further mitigated.

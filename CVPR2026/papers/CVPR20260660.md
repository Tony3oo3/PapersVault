## Problem

Existing event keypoint detection methods suffer from two critical limitations: (1) detectors are trained independently per event frame, so keypoints are placed in non-matching regions without awareness of co-visible information, leading to incorrect matches; and (2) there is an unresolved tension between point-based paradigms (which preserve fine-grained spatio-temporal cues but are incompatible with standard 3D algorithms) and frame-based paradigms (which are compatible with 2D detectors but discard most events during frame construction).

## Input / Output

The method consumes two event streams (or a single stream duplicated for detection-only mode), segmented into 50 ms windows. Each window yields a 3×h×w event frame (encoding latest-event polarity and normalized timestamp per pixel) and a set of normalized spatio-temporal event points (x/w, y/h, (t−T)/Δt). The network outputs per-frame keypoint heatmaps (h×w) and d×hw descriptors; keypoints are extracted via local-maxima filtering and thresholding, then matched by mutual nearest neighbor. The full pipeline runs at 6 ms per 240×180 frame pair on an RTX 3090.

## Method

EV-CGNet introduces a 3D-guided 2D paradigm with two modules. The G2PL module first extracts event point features F_P and frame features F_E via separate 1×1 convolutions; N=16 learnable event point prototypes then attend to F_P (cross-attention) to form event point agents that encode fine-grained spatio-temporal cues, which in turn attend to F_E to produce 3D-guided 2D feature prototypes P_D. The CDDL module concatenates the prototype pair (P_D, P_D′) into D2 agents of size d×2N and refines them via self-attention to capture inter-frame co-visible structure; the resulting co-visible region-focused detectors are fused back into frame features (F = F_E + D(DᵀF_E)) to yield adaptive descriptors. Training is self-supervised: a random homography warps one event frame and its points to create a synthetic pair, and the network is optimized with cosine-similarity and peaky losses on the heatmap pair plus a diversity loss on the prototypes.

## Results

On the Event-Camera dataset, EV-CGNet achieves a reprojection error of 0.91 px, reducing the error by 25% compared to the previous best SuperEvent (1.22 px). On HVGA ATIS Corner, the method achieves 0.27/0.31/0.42 px reprojection error at 25/50/100 ms intervals, outperforming SuperEvent (0.43/0.49/0.63 px) by 37–33%. For downstream SLAM on VECtor, EV-CGNet reduces average ATE by 68% over SuperEvent, and on TUM-VIE loop-closure sequences it reduces ATE by 78%.

## Baselines & Comparisons

EV-CGNet outperforms all six baselines across every evaluated dataset. Against the closest competitor SuperEvent [4], the method reduces reprojection error by 0.16–0.21 px on HVGA ATIS Corner, improves AUC@5°/10°/20° by 8.6%/9.9%/13.4% on Event-Camera pose estimation, and achieves a 68% average ATE reduction on VECtor SLAM. Compared to SD2Event [18], the improvement is even more pronounced: 0.40 px lower reprojection error at 25 ms on HVGA ATIS Corner and 14.7 points higher AUC@5° on Event-Camera. STPNet [46] is outperformed by 0.27 px (25 ms) on HVGA ATIS Corner and 12.2 points in AUC@5° on Event-Camera. EventPoint [27] is surpassed by 0.90 IoU points on N-Caltech101 and 1.00 px on HVGA ATIS Corner at 25 ms. The older hand-crafted detectors evHarris [43] and SILC [32] are outperformed by a wide margin (over 2 px reprojection error gap on HVGA ATIS Corner), confirming the advantage of learned, co-visible-region-focused detection over classical approaches.

## Relation to Prior Work

This paper builds directly on SD2Event (CVPR 2024), adopting its event frame construction, homography-based self-supervised training, and loss functions, while introducing two key departures: a 3D-guided 2D paradigm that uses fine-grained event point features to guide frame feature prototype learning via cross-attention, and a co-visible region-focused detector-descriptor module that models inter-frame interactions through self-attention. Conceptually, it bridges the long-standing tension between point-based methods (which preserve spatio-temporal detail but lack algorithmic compatibility) and frame-based methods (which are compatible with 2D detectors but lose events), positioning itself as a hybrid that retains the strengths of both. The joint detector-descriptor learning follows the D2-Net lineage, adapted here for the event modality.

## Why It Matters / Open Questions

Event keypoint detection underpins SLAM, pose estimation, and 3D reconstruction with event cameras, and the co-visible region focus addresses a practical failure mode (excessive keypoints in non-matching regions) that directly degrades downstream matching and trajectory accuracy. The 3D-guided 2D paradigm offers a reusable conceptual framework for combining sparse spatio-temporal cues with dense frame representations in other event-based tasks. Open questions include whether the fixed number of prototypes (N=16) generalizes across scene complexities, whether the two-frame requirement limits truly asynchronous operation, and whether the relatively simple 1×1 convolutional backbone could be replaced by deeper architectures for higher-resolution sensors.

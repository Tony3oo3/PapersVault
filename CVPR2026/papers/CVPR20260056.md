## Problem

Query-based dense video captioning frameworks (e.g., PDVC) use a single shared set of learnable queries for both temporal localization and caption generation, causing multi-task interference where attention patterns fail to specialize for either task. Additionally, these shared queries tend to repeatedly capture similar temporal segments, producing redundant overlapping predictions that degrade both localization precision and caption diversity. Prior decomposition attempts (e.g., DDVC) derive caption queries from localization queries via an MLP, which does not create truly independent attention behaviors.

## Input / Output

The model takes untrimmed video sampled at 1 FPS, subsampled or padded to a fixed frame length (200 for YouCook2, 100 for ActivityNet), and encodes frames with a pretrained CLIP ViT-L/14 backbone. It outputs N event-caption pairs, each consisting of a start/end timestamp, a natural-language caption, plus a global event count prediction and per-event multi-hot concept labels. The number of queries (50 for YouCook2, 10 for ActivityNet) is doubled since separate localization and caption query sets are maintained, and predictions are matched to ground truth via the Hungarian algorithm during training.

## Method

ROS-DVC replaces the single shared query set with two independently initialized query sets—localization queries and caption queries—each drawn from its own learnable embedding space, allowing them to develop distinct attention patterns (broad temporal context vs. dense key-frame focus). A Cross-Task Contrastive Alignment (CTCA) loss then enforces semantic consistency by treating each Hungarian-matched (caption query, localization query) pair as a positive contrastive pair against all other localization queries. An Overlap Suppression Loss (OSL) penalizes pairwise temporal IoU between predicted boundaries, with a ground-truth-aware weighting factor α that reduces the penalty for well-aligned predictions and strengthens it for poorly aligned ones, preventing both redundant overlaps and collapse to a single non-informative boundary. A lightweight Concept Guider MLP head predicts event-level multi-hot concept vectors from caption query embeddings, enriching the caption generator with concept-level semantics without requiring an external memory bank.

## Results

On YouCook2, ROS-DVC achieves the best non-pretrained captioning scores with CIDEr 39.18, METEOR 6.14, BLEU-4 2.10, and SODA_c 7.06, surpassing the strongest non-memory-bank baseline E²DVC by 4.92 CIDEr. On ActivityNet Captions, it reaches CIDEr 35.04 and SODA_c 6.45, outperforming MCCL (which uses an external memory bank) by 0.12 CIDEr and 0.32 SODA_c. For localization, the method achieves F1 32.03 on YouCook2 (best non-pretrained) and Recall 55.35 on ActivityNet, with notably balanced Recall and Precision indicating accurate event counting.

## Baselines & Comparisons

ROS-DVC outperforms all non-pretrained baselines on YouCook2 across every captioning metric, with the largest margin over PDVC (+9.49 CIDEr) and E²DVC (+4.92 CIDEr). Against MCCL, which relies on an external memory bank for caption diversity, ROS-DVC gains +3.09 CIDEr and +1.85 SODA_c while using no external retrieval. On ActivityNet, the method edges out MCCL by +0.12 CIDEr and +0.32 SODA_c, and surpasses E²DVC by +1.41 CIDEr. For localization on YouCook2, ROS-DVC achieves F1 32.03, beating E²DVC (28.64) by 3.39 and PDVC (26.81) by 5.22; on ActivityNet it reaches Recall 55.35 vs. E²DVC's 54.67. Notably, ROS-DVC's Recall and Precision are nearly matched (29.34 vs. 35.26 on YouCook2), unlike prior methods where Recall consistently lags, indicating its event counter estimates the correct number of events more accurately.

## Relation to Prior Work

This paper extends the DETR-based query framework for Dense Video Captioning introduced by PDVC (Wang et al., ICCV 2021), which first unified localization and captioning through shared learnable queries. It departs from the query decomposition approach of DDVC (Liu et al., ACL 2025), which derives caption queries from localization queries via an MLP, by instead initializing two fully independent query sets from separate embedding spaces. The Overlap Suppression Loss draws conceptual inspiration from repulsion losses in crowd-scene detection (Wang et al., 2018) and learnable sample selection in DETR (Gao et al., 2023), but adapts them to the temporal IoU setting of DVC. The Concept Guider builds on prior work showing that concept-level supervision enriches caption generation (Lu et al., 2024; Yang et al., 2023), but implements it as a lightweight auxiliary head without an external memory bank.

## Why It Matters / Open Questions

The paper addresses a practical and recurring problem in query-based multi-task frameworks: shared representations cause task interference and redundant predictions. The Overlap Suppression Loss and Cross-Task Contrastive Alignment are general-purpose loss designs that could transfer to other DETR-style multi-task detection settings beyond DVC. However, the method remains tied to a specific architecture (2-layer deformable transformer decoder with CLIP ViT-L/14 features) and LSTM captioning, and the gains, while consistent, are moderate relative to methods that leverage LLM-based captioners or external memory banks. Open questions include whether the role-specific query separation scales to longer videos or more complex multi-event scenes, and whether the OSL mechanism interacts well with stronger temporal backbones or streaming settings.

## Problem

Vision Transformer backbones inherently produce low-resolution features due to patch-based tokenization, and while cross-attention-based feature upsamplers (JAFAR, LoftUp, AnyUp) can create pixel-dense features, they inherit quadratic time and memory scaling from the QKV attention mechanism. Earlier iterative upsampling methods like LiFT avoided this cost but suffered from semantic drift when applied repeatedly. The paper asks whether iterative upsampling can be made to match or exceed cross-attention quality while preserving linear scaling.

## Input / Output

UPLiFT takes two inputs: (1) low-resolution backbone features (e.g., DINOv2-S/14 at 14px patch size, yielding a feature map at 1/14th spatial resolution) and (2) the original input image, which is passed through a shallow dense encoder to produce pixel-resolution guiding features. The output is a pixel-dense feature map at the same spatial resolution as the input image, produced by iteratively applying a single 2× decoder module. For generative tasks, the input is a VAE latent code (e.g., from Stable Diffusion 1.5 at 512×512) and the output is an upsampled latent (e.g., 1024×1024) that can be decoded to pixel space.

## Method

UPLiFT consists of a shallow dense encoder (run once on the input image to produce pixel-resolution guide features) and a compact convolutional decoder that performs 2× upsampling, applied iteratively to reach pixel density. The key innovation is the Local Attender operator, which replaces QKV cross-attention with a locally-defined attentional pooling: a 1×1 convolution on the guide feature predicts attention weights over a fixed set of directional offsets (a pre-defined neighborhood), and position-wise softmax produces an attender map used to weighted-sum value features gathered at those offset positions. This ensures output features remain linear combinations of the input backbone features (providing the same regularization benefit as cross-attention) while scaling as O(nT) in tokens rather than O(T²). Training uses a multi-step self-supervised objective where the decoder is unrolled for d iterations with L2 reconstruction loss applied at every intermediate upsampling step, and multiple depths (d ∈ {1,2,3}) are sampled per training step to encourage robustness across scales.

## Results

On semantic segmentation, UPLiFT achieves state-of-the-art mIoU across all four datasets: 62.55 on COCO-Stuff, 85.21 on Pascal VOC, 42.97 on ADE20K, and 65.38 on Cityscapes, surpassing the previous best (AnyUp at 62.08/84.33/42.25/61.33). For monocular depth estimation on COCO-Stuff, UPLiFT ties AnyUp for the best RMSE (0.63) and is second-best on δ₁ (61.16 vs. 61.32). UPLiFT achieves these results with only 0.8M parameters and 79.4 ms inference time, roughly 2× faster than AnyUp (146.7 ms) and 2.8× faster than LoftUp (223.5 ms). For generative tasks, UPLiFT outperforms CFM on COCO text-to-image upsampling (FID 24.23 vs. 28.81) with 41% lower latency, and achieves competitive super-resolution quality (SSIM 0.84 on FacesHQ) using only 2 iterative steps versus CFM's 50.

## Baselines & Comparisons

UPLiFT outperforms all five prior feature upsamplers (LiFT, FeatUp, LoftUp, JAFAR, AnyUp) on every segmentation dataset, with the largest margin on Cityscapes (65.38 vs. 62.09 for LoftUp, a +3.29 mIoU gap) and ADE20K (42.97 vs. 42.25 for AnyUp). On depth estimation, UPLiFT ties AnyUp for the best RMSE (0.63) and trails by only 0.16 on δ₁ (61.16 vs. 61.32), confirming that local attentional pooling captures sufficient global context. In inference speed, UPLiFT (79.4 ms) is roughly 2× faster than AnyUp (146.7 ms) and 2.8× faster than LoftUp (223.5 ms), while using fewer parameters than all cross-attention-based methods. For generative tasks, UPLiFT beats CFM on COCO text-to-image upsampling (FID 24.23 vs. 28.81) and on reLAION (FID 20.73 vs. 21.67, p-FID 15.49 vs. 15.96 at 40 steps), while running at 5.15 s/img versus CFM's 8.79 s/img. On super-resolution, UPLiFT matches or exceeds CFM's SSIM (0.84 vs. 0.82 on FacesHQ, 0.73 vs. 0.69 on LHQ) with only 2 iterative steps and 53M parameters versus CFM's 50 steps and 113–306M parameters.

## Relation to Prior Work

UPLiFT builds directly on LiFT's iterative 2× upsampling paradigm for ViT features, but departs from the recent shift toward cross-attention-based methods (JAFAR, LoftUp, AnyUp) by demonstrating that iterative upsampling, when equipped with a properly designed local operator, can match or exceed their quality at linear rather than quadratic cost. The key architectural departure is the Local Attender, which reformulates attentional pooling over fixed directional offsets inspired by observations that ViT heads learn local offset patterns, replacing the QKV cross-attention that prior methods rely on for feature regularization. The paper also extends the feature-upsampling task into the generative domain (VAE latent upsampling), a setting where prior task-agnostic upsamplers had not been applied.

## Why It Matters / Open Questions

The linear-scaling property of UPLiFT addresses a practical bottleneck: cross-attention-based upsamplers hit memory limits around 1500 tokens (~624×624 images), while UPLiFT handles 2601+ tokens, making it viable for high-resolution applications where quadratic methods simply fail. The generative results—matching CFM's visual quality with 1/6 the parameters and 1/200th the training data—suggest that lightweight iterative upsamplers can replace expensive flow-matching models for latent-space super-resolution. A limitation is that UPLiFT's fixed-step design is less flexible than cross-attention for arbitrary output resolutions, and the depth estimation results (second-best δ₁) hint that purely local attention may occasionally lack the global context that cross-attention provides.

## Problem

Existing 3D LLMs face a fundamental trade-off in encoding spatial relations: absolute position encoding forces models to implicitly learn pairwise relations from prematurely fused features, while explicit relation encoding scales quadratically with object count (e.g., 554 objects yield >153K relation tokens), exceeding LLM context limits. Additionally, current 3D VL benchmarks conflate spatial reasoning with attribute recognition, making it impossible to isolate and measure true spatial comprehension.

## Input / Output

The model receives a segmented 3D point cloud (each object represented by a single token combining PointNet++ geometric features and a learned object identifier like <obj005>) plus a natural language instruction or question. The input sequence length is linear in the number of objects (O(n) tokens), preserving all O(n²) pairwise spatial relations implicitly through attention. For 3D VG tasks, the output is a multiple-choice selection among scene objects; for 3D VQA, it is a generated answer string.

## Method

QuatRoPE encodes each object's absolute 3D bounding-box center as a quaternion rotation applied to its query and key vectors before every attention layer, using Euler-angle decomposition with linear frequency functions so that the dot product of two rotated vectors depends solely on their relative position (m−n). Crucially, coordinates are encoded as a holistic 3D vector rather than per-axis, preventing inflated attention scores when objects share a similar coordinate on one axis but are distant overall. To avoid interference with the LLM's existing language RoPE, IGRE extends object-related tokens with QuatRoPE-specific dimensions (zero-padded for non-object tokens), isolating the two rotation mechanisms and gating QuatRoPE's attention-score adjustments to only object–object interactions. The full system is trained via LoRA fine-tuning (r=16, α=16, lr=2×10⁻⁵) on a combined dataset of ScanRefer, Multi3DRef, ScanQA, SQA3D, Scan2Cap, and ReferIt3D.

## Results

On ScanRefer (GT segmentation), 3DGraphLLM-1B+QuatRoPE achieves 58.3% Acc@0.25 and 58.2% Acc@0.5, outperforming the 3DGraphLLM-1B baseline (55.9/55.8) by +2.4 points. On Multi3DRef, the same model reaches 60.7% F1@0.25 and 60.5% F1@0.5 (vs. 58.6/58.4 baseline). On the proposed ASR benchmark (zero-shot), QuatRoPE yields consistent relative gains of 12–19% across model sizes (e.g., 3DGraphLLM-8B: 37.50→41.96 Acc@0.25, +4.46 absolute). The 7B variant (3DGraphLLM-7B+QuatRoPE, Mask3D) achieves 58.2% Acc@0.25 on ScanRefer and 55.2% SQA3D EM@1, the best overall scores in the comparison.

## Baselines & Comparisons

QuatRoPE consistently outperforms both primary LLM baselines across all metrics. Against Chat-Scene-1B (GT), the method gains +4.7 Acc@0.25 (55.4 vs. 50.7) and +4.8 Acc@0.5 on ScanRefer, and +4.8 F1@0.25 on Multi3DRef. Against 3DGraphLLM-1B (GT), gains are +2.4 Acc@0.25 and +2.1 F1@0.25, with the 7B variant (Mask3D) achieving +1.2 Acc@0.25 and +2.1 SQA3D EM@1 over its baseline. Compared to strong non-LLM baselines, 3DGraphLLM-1B+QuatRoPE surpasses MA2TransVG (58.3 vs. 57.9 Acc@0.25) and VPP-Net (58.3 vs. 55.7) on ScanRefer, and exceeds PQ3D by +7.0 Acc@0.5 (58.2 vs. 51.2) and +10.4 F1@0.5 on Multi3DRef (60.5 vs. 50.1). On the ASR benchmark, QuatRoPE delivers the largest relative gains (19.48% for Chat-Scene-1B, 16.28% for 3DGraphLLM-1B, 13.71% for 3DGraphLLM-8B), confirming that the improvements stem from enhanced spatial reasoning rather than general task performance.

## Relation to Prior Work

This paper extends the Rotary Positional Embedding (RoPE) paradigm from 2D complex rotations to 3D quaternion rotations, adapting the mechanism by which attention dot products encode relative positions to the 3D scene domain. It builds directly on the Chat-Scene and 3DGraphLLM pipelines for 3D LLMs, but departs from both: Chat-Scene fuses absolute coordinates into object features (causing premature fusion that obscures spatial relations), while 3DGraphLLM explicitly encodes all pairwise relations as input tokens (quadratic in object count, requiring lossy KNN pruning). QuatRoPE resolves both issues by encoding absolute positions on individual object tokens and letting the attention mechanism compute all O(n²) relative positions from only O(n) tokens, with IGRE isolating this from the LLM's existing language RoPE to prevent interference.

## Why It Matters / Open Questions

The O(n) token budget while preserving all pairwise spatial relations addresses a practical scalability bottleneck for 3D LLMs in scenes with hundreds of objects (e.g., InteriorGS averages 554 objects/scene), making the approach applicable to real-world indoor environments without aggressive pruning. The ASR benchmark, which strips object attributes to isolate pure spatial reasoning, is a useful diagnostic that existing 3D VL benchmarks lack. Open questions include whether the quaternion rotation scheme generalizes to outdoor or large-scale scenes with very different coordinate ranges, whether the linear frequency assumption (θ(1) scaling) is optimal for all spatial scales, and whether the approach extends naturally to 4D (spatiotemporal) reasoning.

## Problem

Existing open-world semi-supervised learning (OWSSL) methods perform clustering rather than rigorous classification: they rely on Hungarian matching at test time to align predicted pseudo-labels with ground truth, and their outputs lack explicit semantic correspondence to candidate textual labels. This makes them impractical for real-world deployment where a labeled test set is unavailable and the model must directly select the most semantically relevant label from a candidate set.
![Teaser figure](../imgs/CVPR20261860/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image as input and directly outputs a textual class label selected from a fixed candidate set comprising both known and novel class names, with no post-hoc permutation or matching step. Unlike prior OWSSL methods that output cluster indices requiring Hungarian alignment, SECOS produces a label that is semantically meaningful and directly comparable to ground-truth class names. The candidate set is defined a priori (e.g., the full class list of CIFAR-100), and the model must select the correct label by computing similarity between the image's visual embedding and pre-computed text embeddings of all candidate labels.

## Method

SECOS builds on a frozen CLIP backbone and introduces three modules to capture and align semantic information for both known and novel classes. First, Novel Class Semantic Compensation uses a frozen CLIP teacher (with LLM-enriched prompts) to assign high-confidence pseudo-labels to unlabeled samples, constructing a balanced pseudo-labeled novel dataset that compensates for the severe supervision imbalance. Second, Batch-Wise Semantic Recapture refines pseudo-labeling at the batch level by intersecting intra-instance (top-confidence) and inter-instance (class-quantile threshold) label sets, retaining only samples with exactly one consistent pseudo-label for maximum semantic clarity. Third, an Adapter for Semantic Feature Alignment inserts lightweight parallel adapters (downsample-project-GeLU-upsample) after each attention block in the frozen visual encoder, trained with cross-entropy loss against the text encoder's class embeddings so that visual features are explicitly aligned to semantic representations. Only adapter and projector parameters are updated during training, preserving CLIP's pre-trained knowledge while enabling direct textual label prediction at inference.

## Results

On generic datasets, SECOS achieves 98.1% All accuracy on CIFAR-10, 84.7% on CIFAR-100, and 91.7% on ImageNet-100, using direct classification accuracy without Hungarian matching. On fine-grained datasets, SECOS reaches 78.6% (CUB), 92.3% (Stanford Cars), 90.0% (Oxford Flowers), and 95.4% (Oxford Pets) All accuracy. Notably, all compared baselines are evaluated under the more lenient Hungarian-matching (clustering) protocol, meaning SECOS's direct-prediction numbers are inherently harder to achieve. The paper reports up to 5.4% improvement over SOTA methods across seven benchmarks.

## Baselines & Comparisons

SECOS outperforms all 12 baselines on CIFAR-100 (84.7% vs. best 81.6% SimGCD-CLIP) and ImageNet-100 (91.7% vs. best 88.0% TextGCD) in All accuracy, despite baselines benefiting from Hungarian matching at test time. On CIFAR-10, SECOS (98.1%) is within 0.1% of TextGCD (98.2%), which again uses the more lenient clustering protocol. On fine-grained datasets, SECOS leads on CUB (78.6% vs. 76.6% TP-OWSSL), Stanford Cars (92.3% vs. 90.7% TP-OWSSL), and Oxford Flowers (90.0% vs. 87.3% TP-OWSSL), while essentially tying TextGCD on Oxford Pets (95.4% vs. 95.5%). The largest single-dataset gains appear on Stanford Cars Novel accuracy (94.4% vs. 88.6% TP-OWSSL, +5.8%) and ImageNet-100 Novel accuracy (89.8% vs. 85.2% TextGCD, +4.6%). A critical methodological advantage is that SECOS reports standard classification accuracy (direct label prediction), whereas every baseline reports clustering accuracy via Hungarian matching, which the authors note is always ≥ classification accuracy for the same model.

## Relation to Prior Work

SECOS builds on the CLIP-based OWSSL/GCD line of work (TextGCD, TP-OWSSL) that leverages vision-language pre-training for open-world semi-supervised learning, and adapts the candidate pseudo-label learning framework of Zhang et al. [44] for its batch-wise semantic recapture stage. Its key conceptual departure is rejecting the Hungarian-matching evaluation protocol that dominates prior OWSSL methods, reframing the problem from clustering (predict pseudo-labels, then permute to match ground truth) to direct textual label classification. Methodologically, it combines parallel adapter fine-tuning on a frozen CLIP visual encoder with LLM-enriched textual prompts for pseudo-label generation, a combination not previously explored in the OWSSL setting.

## Why It Matters / Open Questions

The paper's central contribution is identifying that nearly all existing OWSSL methods solve a clustering problem rather than a classification problem, since they rely on Hungarian matching at test time—a labeled test set that is unavailable in real deployment. This reframing has practical implications: any OWSSL system intended for production must predict semantically correct labels directly, and SECOS demonstrates this is achievable with CLIP-based semantic grounding. Limitations include dependence on CLIP's pre-training coverage (novel classes outside CLIP's vocabulary may suffer) and the assumption that the full candidate label set is known at inference time, which constrains applicability to truly open-world scenarios where the class inventory is unknown.

## Problem

Existing co-segmentation methods operate in a single modality (3D point clouds or 2D images), limiting the semantic cues available for discovering common objects. Cross-modal 2D-3D approaches that could compensate for this limitation rely on geometric alignment (camera parameters, pixel-to-point mapping), requiring costly calibration and restricting the applicability of 2D datasets. This paper introduces the novel task of unsupervised point cloud-image cross-modal co-segmentation that leverages semantic consistency across modalities without any geometric alignment.

## Input / Output

The method takes a set of N=24 point clouds (each with M_P=2048 points, XYZ coordinates only) and a set of N=24 RGB images (resized to 224×224) as input, with no ground-truth masks, camera intrinsics, or spatial correspondence required. If the number of point clouds and images differ, the smaller set is repeated to match the larger. For each point cloud, the output is a foreground point subset (co-segmentation mask); for each image, the output is a binary patch-level segmentation mask (H'×W'×1) identifying the common object.

## Method

GeoFree-CoSeg follows a coarse-to-fine pipeline: a 3D branch (PointNet + mutual correlation module) and a 2D branch (DINO-pretrained ViT-B, patch size 8) independently extract coarse common semantics. A 2D Multi-Granularity Correlation Module progressively models common semantics at channel-level (FFN), patch-level (cross-image self-attention), and global-level (DINO CLS token as anchor), producing a per-patch semantic weight. A Graph-based Common Semantic Filtering module constructs bidirectional point-patch similarity graphs in a shared semantic space, sparsifies them via Top-K KNN to retain the most discriminative cross-modal correspondences, and applies soft-masked Softmax to yield fine-grained correlation matrices. A 2D-3D Semantic Fusion and Enhancement module then performs Bayesian-inspired attention (using the correlation matrix as a prior) to fuse cross-modal features, followed by residual mutual enhancement to preserve modality-specific characteristics. Training is supervised by two NT-Xent contrastive losses—semantic-level (aligning 3D common semantic features with 2D global semantic prototypes) and object-level (aligning 3D object features with 2D object prototypes)—plus the original unsupervised point and image co-segmentation losses, all without any geometric alignment.

## Results

On S3DIS, GeoFree-CoSeg achieves 54% average mIoU for 3D point cloud co-segmentation, outperforming the previous state-of-the-art LogoSP (48%) by 6% and Yang (46%) by 8%. On ScanObjectNN, it reaches 63% average mIoU, surpassing LogoSP (60%) by 3%. For 2D image co-segmentation on S3DIS-Coseg, the method achieves 83% Precision and 59% Jaccard Index, exceeding SCoSPARC (74% P, 38% J) by 9% and 21% respectively. On ScanObjectNN-Coseg, it attains 78% P and 53% J versus SCoSPARC's 75% P and 48% J.

## Baselines & Comparisons

GeoFree-CoSeg outperforms all 3D baselines on both S3DIS and ScanObjectNN. On S3DIS, it beats LogoSP (the strongest 3D baseline, which itself leverages DINOv2 2D features) by 6% mIoU and the prior co-segmentation SOTA Yang by 8%, with particularly large gains on bookcase (+15%) and door (+12%). On ScanObjectNN, the margin narrows to 3% over LogoSP and 2% over Yang, consistent with the object-centric nature of that dataset. Among 2D image co-segmentation baselines, SCoSPARC is the strongest competitor; GeoFree-CoSeg surpasses it by 9% Precision and 21% Jaccard on S3DIS-Coseg, and by 3% P / 5% J on ScanObjectNN-Coseg. Weaker 2D baselines (DVFDVD, ReClip) are outperformed by even larger margins, with ReClip achieving only 33% J on S3DIS-Coseg versus 59% for the proposed method. Notably, LogoSP already incorporates 2D image features via DINOv2 for point cloud segmentation, yet still requires geometric alignment, whereas GeoFree-CoSeg achieves superior results without any such alignment.

## Relation to Prior Work

This paper builds on two established lines of work: unsupervised point cloud co-segmentation (Yang et al. [45], which provides the 3D branch's co-contrastive learning and mutual attention sampling) and unsupervised image co-segmentation (SCoSPARC [4], DVFDVD [1], which inform the 2D branch's DINO-ViT feature extraction). It departs sharply from prior 2D-3D cross-modal learning methods (point-pixel mapping, knowledge distillation) that all require geometrically aligned 2D-3D data with camera parameters, instead relying solely on cross-modal semantic consistency. The graph-based common semantic filtering via KNN sparsification and the Bayesian-style posterior regularization of cross-modal attention are novel architectural contributions not present in either single-modal co-segmentation or aligned cross-modal pipelines.

## Why It Matters / Open Questions

By eliminating the need for geometric alignment, this work opens cross-modal co-segmentation to real-world settings where precise 2D-3D calibration is impractical or unavailable (robot navigation, 3D scene graph construction, object retrieval from uncalibrated views). The two newly constructed datasets (S3DIS-Coseg, ScanObjectNN-Coseg) fill a concrete gap that previously prevented any cross-modal co-segmentation experiments. Open questions include whether the approach generalizes to outdoor scenes, multiple simultaneous common objects per set, and larger group sizes; the current evaluation is limited to indoor scenes with a single common category per group of 24 samples.

## Problem

Existing Cross-View Object Geo-Localization (CVOGL) methods assume the query image contains only a single object, which contradicts real-world scenarios where ground or drone images typically contain multiple objects (buildings, roads, bridges). This paper introduces the Cross-View Multi-Object Geo-Localization (CVMOGL) task, which requires simultaneously localizing an arbitrary number of query objects and establishing correct point-to-box correspondences in a satellite reference image.
![Teaser figure](../imgs/CVPR20261963/cropped_page0_idx0.webp)

## Input / Output

The method takes a query image (ground or drone view) with m click points marking objects of interest, plus a geo-tagged satellite reference image, and outputs m bounding boxes in the satellite image, each corresponding to one query point. Query points are represented as single coordinates (random points within annotated boxes), while the reference image is processed at 16× downsampling. The method handles an arbitrary number of objects per image pair, and for fair comparison with retrieval-based baselines, the satellite image is divided into 128×128 pixel patches.

## Method

MOGeo uses a dual-branch encoder (ResNet18 for query, Darknet53 for reference) followed by three key components. The Multi-Object Position Encoding (MOPE) module creates a Dirac-delta-inspired one-hot binary mask for each query point, concatenates it with visual features via a 1×1 convolution, and applies element-wise multiplication to prevent position information from being diluted by semantic features. The Cross-View Multi-feature Fusion (CVMF) module computes L2-normalized cross-view attention maps via matrix multiplication between query and reference feature vectors, then fuses them back into the reference feature map. Training uses a composite loss combining confidence, regression, and a novel similarity loss (Ls) that explicitly maximizes Euclidean distance between attention maps of different objects to sharpen spatial discrimination.

## Results

On the newly introduced CMLocation-V1 test set, MOGeo achieves 63.85% acc@0.25 and 46.66% accI@0.25, surpassing the previous best method VAGeo by 6.06% and 3.63% respectively. On the more challenging CMLocation-V2 (non-center, non-north aligned), MOGeo still leads with 37.87% acc@0.25 and 30.23% accI@0.25, outperforming VAGeo by 4.36% and 1.05%. On the single-object CVOGL-SVI test set, MOGeo reaches 50.98% acc@0.25, a 2.77% gain over VAGeo. Ablation shows the MOPE module is the most critical component, with its removal causing an 11.51% drop in acc@0.25 on CVOGL-Drone.

## Baselines & Comparisons

MOGeo consistently outperforms all eight baselines across both CMLocation-V1 and V2. Against the strongest object-level baselines, VAGeo [12] and DetGeo [24], MOGeo gains 6.06% and 7.82% in acc@0.25 on CMLocation-V1, and 4.36% and 5.48% on CMLocation-V2. Image-level geo-localization methods (FRGeo, GeoDTR+, Sample4Geo) perform dramatically worse (≤32% acc@0.25), confirming they are fundamentally unsuited for object-level localization. On the single-object CVOGL-SVI test set, MOGeo (50.98% acc@0.25) beats VAGeo (48.21%) and DetGeo (45.43%), while on CVOGL-Drone it achieves SOTA acc@0.25 (66.39%) but is slightly behind VAGeo on acc@0.5 (59.71% vs. 61.87%). The advantage widens with object count: on CMLocation-V2 with N>6 objects, MOGeo leads VAGeo by 8.45% in acc@0.25, versus only 4.28% for N≤3.

## Relation to Prior Work

This paper extends the cross-view object geo-localization (CVOGL) line of work initiated by DetGeo and VAGeo, which handle single-object localization between ground/drone and satellite views. The key conceptual departure is generalizing from one-to-one object matching to a multi-object setting (CVMOGL), where a single query image contains multiple objects that must each be localized and correctly paired with their satellite counterparts. Architecturally, MOGeo reuses the ResNet18/Darknet53 dual-branch backbone from prior CVOGL methods for fair comparison, but introduces a Dirac-delta-inspired one-hot positional encoding (MOPE) and a cross-view multi-feature fusion module (CVMF) to handle multiple simultaneous query objects, along with a novel similarity loss that explicitly separates attention distributions across objects.

## Why It Matters / Open Questions

The CMLocation benchmark (63,888 object instances across 25,520 image pairs) fills a clear gap: no prior dataset supported multi-object cross-view geo-localization, and the V2 variant with non-center, non-north alignment and varying resolutions better reflects real deployment conditions. The results reveal that even the best methods drop sharply under non-aligned views (e.g., MOGeo falls from ~64% to ~38% acc@0.25), indicating that robust multi-object cross-view localization remains an open problem. Limitations acknowledged by the authors include imperfect object-to-object correspondence in complex scenes and sensitivity to viewpoint variation, suggesting future work on more discriminative cross-view matching and geometric invariance.

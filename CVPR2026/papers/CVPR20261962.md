## Problem

Predictor-based NAS suffers from two key limitations: (1) cell-based search spaces are typically evaluated using isolated cell encodings that discard macro-structural context such as reduction operations and inter-cell dependencies, and (2) neural predictors generalize poorly under limited training samples because they cannot capture the complex, non-linear relationships among architectures. This paper tackles both issues by introducing a global encoding scheme and an auxiliary hypernetwork task that jointly enriches architecture representations.
![Teaser figure](../imgs/CVPR20261962/cropped_page2_idx0.webp)

## Input / Output

The method consumes a sequence of cell DAGs (each defined by an upper-triangular adjacency matrix and node feature vectors) plus an auxiliary image dataset (e.g., CIFAR-10) that supervises the hypernetwork branch. Before encoding, each cell's node features are augmented with the pooled feature vector of the preceding cell, so the GCN sees position-aware, context-enriched inputs. The predictor branch outputs a scalar accuracy estimate from a global embedding (the mean of all cell features), while the hypernetwork branch outputs per-operation weight tensors for the target network, enabling both performance prediction and direct parameter initialization in a single forward pass.

## Method

HyperNAS is a multi-task paradigm built on a shared GCN encoder for DAGs. The global encoding scheme sequentially feeds each cell into the GCN, augmenting node features with the preceding cell's pooled output so that macro-structural context (reduction cells, inter-cell dependencies) is captured; all cell features are then averaged into a single global embedding passed to an accuracy regressor. In parallel, a shared MLP hypernetwork takes the same GCN-encoded node features to generate weights for every operation in the architecture, and the resulting target network is evaluated on an auxiliary dataset, backpropagating gradients through both the hypernetwork and the GCN. This joint optimization acts as implicit regularization, encouraging the shared encoder to learn generalizable inter-architecture patterns rather than overfitting to accuracy pairs. Training is stabilized by a dynamic adaptive multi-task loss with a learnable per-task uncertainty and a preference coefficient q that nonlinearly scales task losses, enabling personalized exploration along the Pareto front while guaranteeing Pareto optimality at convergence.

## Results

On CIFAR-10 (DARTS search space), HyperNAS achieves 97.60% best top-1 accuracy and 97.48±0.01% average accuracy using only 200 architecture-accuracy pairs (0.2K queries, 0.3 GPU days), surpassing the prior SOTA PINAT (97.58% best, 97.46±0.08% avg with 1K queries). On ImageNet, HyperNAS reaches 75.4% top-1 in the DARTS space and 82.4% top-1 in the ViT-Base space, matching AutoFormer's 82.4% while using only 20% of the query cost. On NAS-Bench-101 and NAS-Bench-201, HyperNAS achieves the highest Kendall's Tau across all data splits, with margins of 0.130–0.173 over PINAT on NAS-Bench-201 in few-shot settings (0.25%–3% training data).

## Baselines & Comparisons

HyperNAS outperforms all 14 baselines across the four evaluation benchmarks. Against the closest predictor-based competitor PINAT [34], HyperNAS achieves higher Kendall's Tau on both NAS-Bench-101 (0.817 vs 0.801 at 0.1% data) and NAS-Bench-201 (margins of 0.130–0.173 across splits), and higher CIFAR-10 accuracy (97.60% vs 97.58% best, 97.48% vs 97.46% avg) with 5× fewer queries (0.2K vs 1K). Among other predictor baselines, HyperNAS surpasses TNASP [33] (0.817 vs 0.752 Kendall's Tau on NAS-Bench-101), GMAE-NAS [21] (0.817 vs 0.788), CTNAS [10] (0.817 vs 0.751), and NP [56] (0.817 vs 0.685) on ranking, and all of them on CIFAR-10 accuracy. For end-to-end NAS on ImageNet, HyperNAS beats DARTS [30] (75.4% vs 73.1%), PNAS [29] (75.4% vs 74.2%), BONAS-D [47] (75.4% vs 74.6%), and GHN [66] (75.4% vs 73.0%) in the DARTS space, and matches AutoFormer [8] on ViT-Base (82.4% top-1) while using only 0.2K queries versus 1K. On ViT-Small, HyperNAS (81.8%) edges out AutoFormer (81.7%) and substantially outperforms DeiT-S [51] (79.9%) and ViT-S/16 [16] (78.8%). The single-task variant HyperNAS-P (97.61% best, 0.1 GPU days) also exceeds PINAT and all other baselines, confirming that the global encoding scheme alone provides a strong improvement over prior GCN-based predictors.

## Relation to Prior Work

HyperNAS builds directly on the GCN-based DAG encoder from NP (Wen et al., ECCV 2020) and extends the dynamic adaptive multi-task loss of Liebel & Körner (2018) by introducing a preference coefficient q for personalized Pareto-front exploration. It departs from prior predictor-based NAS methods (PINAT, TNASP, CTNAS, GMAE-NAS) in two key ways: replacing isolated cell encoding with a sequential global encoding scheme that propagates inter-cell context, and repurposing the hypernetwork (previously used as a direct architecture evaluator in SMASH and GHN) as an auxiliary weight-generation task that regularizes the shared encoder. This multi-task framing—where the hypernetwork is not the search evaluator but a co-trained auxiliary objective—is the paper's central conceptual departure from both one-shot NAS and prior predictor-based approaches.

## Why It Matters / Open Questions

The practical significance lies in reducing the number of expensive architecture-accuracy pairs needed for reliable NAS prediction by at least 5×, which directly lowers the barrier to deploying predictor-based NAS in new domains or hardware-constrained settings. The t-SNE finding that global-encoded features decouple from raw accuracy correlation (unlike NP's cell-level features) suggests the encoder captures richer structural invariants, though this observation is limited to visualization. Open questions include scalability to very large or non-cell-based architectures (the authors acknowledge the hypernetwork's time cost), whether the auxiliary task benefit persists beyond cell-based DAG search spaces, and whether the preference coefficient q can be automated rather than manually tuned. The approach is a solid incremental advance in predictor design rather than a paradigm shift.

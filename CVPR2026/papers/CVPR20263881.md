## Problem

Existing PTM-based class-incremental learning methods accumulate task-specific prompts or adapters for each new task, causing trainable parameters to grow linearly with the number of tasks. Additionally, these methods lack explicit mechanisms to structure a coherent and discriminative representation space across tasks, leading to prototype drift, blurred decision boundaries, and degraded stability as classes accumulate.
![Teaser figure](../imgs/CVPR20263881/cropped_page0_idx0.webp)

## Input / Output

The method takes standard RGB images as input and produces a single class label from a unified cosine classifier over all classes seen so far. It is exemplar-free: no stored samples from previous tasks are required at training or inference time. At inference, the residual autoencoder projector is discarded entirely, so the model consists solely of the frozen ViT-B/16 backbone, one shared adapter (constant size regardless of task count), and the expanded classifier head.

## Method

RSIAT maintains a single shared adapter across all tasks to eliminate parameter growth, and introduces two representation-steering mechanisms. In the base task, a pairwise representation-steering loss (positive term compacting same-class features, negative term separating different-class features) is applied with a linear warm-up schedule to build a well-structured feature space before incremental learning begins. In incremental tasks, a lightweight residual autoencoder projector (with an identity skip path) aligns the current task's features to the previous task's representation space via an L2 alignment loss, while an orthogonal loss penalizes cosine similarity between new-task features and projected old-class prototypes to prevent representational overlap. The residual identity path is critical: it initializes the projector as a no-op so it only models incremental drift, avoiding the over-regularization that would impede the shared adapter's plasticity.

## Results

RSIAT achieves the best average accuracy (A̅) and final accuracy (A_B) on all six CIL benchmarks with ViT-B/16-IN21K. Headline numbers include 86.92% A̅ / 82.75% A_B on ImageNet-R (B0I20), 74.89% / 66.23% on ImageNet-A (B0I20), and 95.15% / 92.20% on CIFAR-100 (B0I10). The method uses a constant-size shared adapter (no per-task parameter growth) while outperforming all PTM-based and traditional CIL baselines, including exemplar-based methods like TagFex (20/class) by +3.69% A̅ on ImageNet-R.

## Baselines & Comparisons

RSIAT outperforms all 14 baselines on every dataset and both metrics (A̅ and A_B). The closest competitor is SSIAT (the direct baseline), which RSIAT surpasses by +3.29% A̅ on ImageNet-R, +4.06% on ImageNet-A, and +0.80% on CIFAR-100. Among prompt-based methods, CODA-Prompt is the strongest but trails RSIAT by 5.62% A̅ on ImageNet-R and 11.35% on ImageNet-A. RanPAC, a training-free prototype method, is competitive on CIFAR (94.35 vs 95.15) but falls further behind on domain-shifted datasets like ImageNet-A (69.32 vs 74.89). Against exemplar-based traditional CIL methods (Table 2), RSIAT with zero exemplars beats TagFex (20/class) by +3.69% A̅ on ImageNet-R and +2.98% on CIFAR-100, and outperforms FOSTER, DER, iCaRL, and MEMO by even larger margins. The gains are most pronounced on ImageNet-A and ImageNet-R, where domain shift from the pre-training distribution makes representation structuring most critical.

## Relation to Prior Work

RSIAT builds directly on SSIAT (CVPR 2024), which introduced a shared adapter with semantic-shift-aware prototype updates for PTM-based CIL. It departs from the broader prompt/adapter accumulation paradigm (L2P, DualPrompt, CODA-Prompt, MOS, EASE) by maintaining a single constant-size adapter across all tasks, eliminating the linear parameter growth and module-retrieval overhead. The key conceptual departure is a 'representation-first' design: rather than relying solely on task-specific modules or distillation to preserve knowledge, RSIAT explicitly steers the geometry of the shared feature space (intra-class compactness via a pairwise RS loss in the base task, and cross-task alignment via a residual autoencoder projector in incremental tasks), drawing inspiration from optimal transport theory while avoiding the optimization resistance of strong regularizers.

## Why It Matters / Open Questions

The constant-parameter design addresses a practical bottleneck in PTM-based CIL where model size and inference complexity grow linearly with the number of tasks, making RSIAT attractive for long-horizon deployment. The representation-steering losses provide an explicit, interpretable mechanism for maintaining discriminative structure, which is more principled than implicit regularization through distillation. Limitations include evaluation only on ViT-B/16 backbones and six datasets, and the RAE projector is training-only (discarded at inference), so the alignment benefit is indirect. Open questions include whether the approach scales to larger backbones (ViT-L/H), other modalities (video, point clouds), and whether the warm-up schedule and hyperparameters transfer robustly across settings.

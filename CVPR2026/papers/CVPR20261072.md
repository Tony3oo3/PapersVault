## Problem

Existing vision-language models for pathology align text at the image or bounding-box level, which is structurally unsuitable for nuclei analysis where small, densely overlapping instances make region-level embeddings contaminated. Moreover, no instance-level textual annotations exist for nuclei, and severe class imbalance combined with organ- and stain-induced variability causes models trained on class labels alone to rely on spurious contextual cues rather than intrinsic nuclear morphology.
![Teaser figure](../imgs/CVPR20261072/cropped_page0_idx1.webp)

## Input / Output

The method takes histopathology image patches (256×256 for PanNuke, 1000×1000 for MoNuSeg) and, during training, ground-truth instance masks to automatically derive per-nucleus morphological attributes (equivalent diameter, eccentricity, hematoxylin intensity, perimeter ratio) that are discretized into text prompts. At inference, no masks or per-image labels are needed; a fixed sentence listing all class descriptions serves as the global text context. The model outputs per-instance segmentation masks and class labels (neoplastic, epithelial, inflammatory, connective, dead) for each detected nucleus.

## Method

Built on Mask2Former with a SAM ViT encoder, the framework introduces three coupled components. First, GT-Driven Attribute Prompt Generation extracts eleven morphological features from ground-truth masks, selects four discriminative attributes via Cohen's d separability and Spearman redundancy filtering, discretizes them through recursive entropy-based binning (max depth 4, validated over 5 folds), and converts the resulting intervals into human-readable text descriptors. Second, Instance-Level VL Alignment performs contrastive learning between enhanced object query features and two types of text embeddings—fixed class-organ prompts and fine-grained attribute prompts—using Hungarian-matched query-instance pairs and a CLIP text encoder with a trainable final layer. Third, the Semantic Interaction Module learns k class-specific prototype tokens per class and performs bidirectional cross-attention: object queries aggregate visual evidence into dynamic class tokens (OQ→CT), and the updated tokens propagate dataset-level class semantics back to each instance (CT→OQ), reducing intra-class variance while preserving legitimate morphological submodes. A centering loss anchors each token group's mean to its corresponding class text embedding in the shared vision-language space.

## Results

On PanNuke, IVAAN-H achieves the best detection F1 of 0.87 and classification F1 of 0.69, outperforming the previous best (PromptNucSeg-H) by +0.03 and +0.08 respectively. For instance segmentation, it attains an average bPQ of 0.6976 and mPQ of 0.5459 across 19 organs, surpassing PromptNucSeg by +0.005 and +0.034. On MoNuSeg, IVAAN-H reaches AJI 0.689 and PQ 0.696, and on CPM17 it achieves AJI 0.743 and PQ 0.748, both setting new state-of-the-art results.

## Baselines & Comparisons

IVAAN outperforms all 16 baselines on every dataset and metric. On PanNuke, the closest competitor PromptNucSeg-H (Det F1 0.84, Cls F1 0.61) is surpassed by +0.03 detection F1 and +0.08 classification F1; the gap widens for rare classes (Dead: 0.49 vs. 0.46 F1) and morphologically confusable classes (Inflammatory: 0.70 vs. 0.59 F1). Transformer-based baselines CellViT-H and PointNu-Net trail by 0.04–0.06 in detection F1 and 0.07–0.11 in classification F1. On MoNuSeg, IVAAN-H (AJI 0.689, PQ 0.696) leads PromptNucSeg-H (0.622, 0.627) by +0.067 AJI and +0.069 PQ, and outperforms all CNN-based methods (Triple U-Net, CIA-Net, FEEDNet, Full-Net) by 0.06–0.14 in AJI. On CPM17, the margin over PromptNucSeg-H narrows to +0.003 AJI and +0.015 PQ, while IVAAN still leads HARU-Net and PointNu-Net by 0.02–0.03 in AJI. Notably, the largest relative gains appear in the Dead class (PQ 0.204 vs. 0.161 for PromptNucSeg), confirming that the attribute-guided text prompts and class-token prototypes most benefit minority and morphologically ambiguous categories.

## Relation to Prior Work

This paper extends the Mask2Former transformer architecture by injecting instance-level vision-language alignment, departing from prior pathology VLMs (PLIP, CONCH) that operate at the image level and region-level grounding models (GLIP, GroundingDINO) that cannot handle densely overlapping nuclei. The key conceptual departure is the automatic generation of attribute-guided text prompts from ground-truth masks via entropy-based binning of morphological features, eliminating the need for manual instance-level text annotations that have been a barrier to VL methods in nuclei analysis. The Semantic Interaction Module with multiple class tokens per class further distinguishes this work from single-prototype or label-only approaches, explicitly modeling intra-class submodes induced by organ and staining variability.

## Why It Matters / Open Questions

The automatic attribute-to-text pipeline makes instance-level VL alignment practically deployable in pathology without prohibitively expensive manual text annotation, and the consistent gains across PanNuke, MoNuSeg, and CPM17 (including notable improvements on the minority 'dead' class) suggest the approach mitigates class imbalance more effectively than label-only supervision. Open questions remain around class-adaptive token budgets (the dead class shows token drift with k=5) and the persistent overlap between connective and inflammatory classes, which the authors suggest could be addressed with diversification constraints on class tokens. Broader implications include whether the attribute-guided prompt generation strategy transfers to other fine-grained instance-level tasks beyond nuclei, such as cell or gland segmentation in other tissue types.

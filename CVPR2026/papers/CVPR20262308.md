## Problem

Existing video object detection methods perform feature aggregation exclusively in the spatiotemporal domain and treat all spatial regions indiscriminately, limiting their ability to capture fine-grained frequency-domain motion cues and wasting computation on redundant background regions. No prior work has introduced frequency-domain feature aggregation into video object detection, leaving a gap in exploiting the complementary information that high- and low-frequency components provide for object localization and temporal consistency.
![Teaser figure](../imgs/CVPR20262308/cropped_page0_idx0.webp)

## Input / Output

The network consumes M=20 video frames (shorter side ≥600 px, longer side ≤1000 px) processed through a shared backbone (ResNet-101, ResNeXt-101, or Swin-Base) that yields three-scale features at C3, C4, and C5 stages. For each frame, 100 vanilla object queries are initialized following Deformable DETR; the final output is a set of bounding boxes and per-class confidence scores for all detected objects across all input frames, produced by a shared feed-forward detection head.

## Method

D2FANet introduces two complementary aggregation branches built on a Deformable DETR baseline. The frequency-domain branch (FDFA) decomposes each scale's frame features into high- and low-frequency channels via octave convolution (ratio α=0.25), performs bidirectional H↔L interactions, fuses the resulting multi-scale frequency features through a Neighbor Frequency Fusion block, and then updates object queries across all M frames via a Frequency-Temporal Attention layer. The spatiotemporal-domain branch (SDFA) first predicts a per-token importance map by concatenating local (MLP-projected) and global (average-pooled) features and passing them through a sigmoid MLP; it then applies Importance-Guided Aggregation, which partitions tokens into N importance-ordered groups and merges each group at a different rate—preserving fine detail in salient regions while compressing background—before feeding the result into a spatiotemporal transformer decoder. The frequency and spatiotemporal object queries are concatenated and passed through a shared FFN head to produce final detections, enabling the two domains to jointly reinforce query representations.

## Results

On ImageNet VID, D2FANet achieves 87.7% mAP with ResNet-101 (24.6 ms runtime), 88.7% mAP with ResNeXt-101, and 91.8% mAP with Swin-Base, setting new state-of-the-art across all three backbone configurations. On EPIC-KITCHENS, D2FANet reaches 44.5% mAP (ResNet-101) and 50.0% mAP (Swin-Base), outperforming all prior methods while maintaining the lowest runtime (28.5 ms and 48.9 ms respectively). The method consistently achieves the best mAP with the fastest or near-fastest inference speed across all settings.

## Baselines & Comparisons

D2FANet outperforms all 21 compared baselines on both datasets across every backbone configuration. On ImageNet VID with ResNet-101, it surpasses the strongest prior method HyMATOD (86.7%) by 1.0 mAP and CDANet (85.4%) by 2.3 mAP, while running 3.3× faster than CDANet (24.6 ms vs. 80.6 ms). With ResNeXt-101, D2FANet (88.7%) leads DGC-Net (87.3%) by 1.4 mAP at 5× lower runtime (38.5 ms vs. 191.5 ms). With Swin-Base, it exceeds STPN (90.6%) by 1.2 mAP and TGBFormer (90.3%) by 1.5 mAP. On EPIC-KITCHENS, D2FANet (44.5% ResNet-101; 50.0% Swin-Base) beats CSMN (42.7%), HVRNet (41.2%), TransVOD++ (40.3%), and TransVOD (47.4%) while maintaining the lowest runtime in each group. No baseline matches or exceeds D2FANet on any reported configuration.

## Relation to Prior Work

D2FANet is built on Deformable DETR as its base detector and extends the feature-aggregation paradigm in video object detection by introducing frequency-domain processing for the first time in this task. The frequency-domain module repurposes octave convolution (Chen et al., ICCV 2019) for high/low-frequency decomposition and the neighbor frequency fusion block from FPN (Lin et al., CVPR 2017) for cross-scale combination, while the spatiotemporal module adapts the importance-map concept from DynamicViT (Rao et al., NeurIPS 2021) to guide token aggregation. Conceptually, the paper departs from the dominant line of work (TransVOD, TGBFormer, DNFM, MSTF) that performs only indiscriminate spatiotemporal aggregation, arguing that frequency-domain cues capture periodic motion patterns and fine-grained boundaries that spatial-domain attention misses.

## Why It Matters / Open Questions

The dual-domain framing offers a principled justification for why video object detection benefits from both frequency and spatiotemporal cues, and the importance-guided aggregation provides a practical mechanism to allocate computation to salient regions, yielding competitive runtime (24.6 ms with ResNet-101) alongside SOTA accuracy. The authors acknowledge a key limitation: the fusion between frequency and spatiotemporal object queries is a simple concatenation, leaving open whether deeper adaptive cross-domain interaction could yield further gains. For practitioners, the modular design (FDFA and SDFA can be added independently to any DETR-style VOD pipeline) makes the components potentially reusable beyond this specific architecture.

## Problem

Large-scale 3D reconstruction from in-the-wild imagery frequently produces disconnected partial reconstructions or erroneously merges non-overlapping regions because existing pipelines require sufficient visual overlap between views. While dense pseudo-synthetic renderings (e.g., from Google Earth Studio) can provide complete scene coverage, their substantial appearance gap from real photographs makes it unclear how to leverage them as a common anchor for aligning fragmented reconstructions into a globally consistent model.
![Teaser figure](../imgs/CVPR20260410/cropped_page0_idx0.webp)

## Input / Output

The method takes a 'meta-image'—a set of in-the-wild photos (8 to 713 images) previously bundled together via SfM (e.g., COLMAP)—and a 3DGS reference model built from pseudo-synthetic renderings with known GPS coordinates. It outputs a single 7-parameter global transformation (6 DoF rigid SE3 + scale) that registers the entire meta-image to the reference model, with the reference model parameters held fixed during optimization. The reference model is constructed by running COLMAP on rendered aerial and ground-level camera trajectories from Google Earth Studio, ensuring full scene coverage.

## Method

The core insight is that despite the large photometric domain gap between real photos and pseudo-synthetic renderings, both share the same underlying scene semantics. The reference model is represented as 3D Gaussian Splatting with DINOv2 semantic features distilled onto each Gaussian (following the Feature 3DGS distillation approach), and alignment is formulated as an inverse optimization problem that iteratively refines a global 6DoF+scale transformation while keeping the 3DGS parameters frozen. Instead of a standard photometric loss, the method minimizes an L1 loss on high-dimensional DINOv2 semantic features, which provides meaningful supervision even when color and texture differ dramatically. A robust optimization scheme using Least Trimmed Squares (LTS) dynamically ignores outlier images (those with loss above the running median) at each iteration, handling occlusions and floaters in the reference model. The scheme is applied iteratively across multiple meta-images in a 'puzzle-solving' fashion, and can be initialized with any classical or learning-based SfM pipeline (COLMAP, gDLS+++, SuperPoint+LightGlue).

## Results

On the WikiEarth benchmark (32 meta-images across 23 scenes), the proposed method initialized with COLMAP achieves the best overall alignment: ΔR = 2.48°, ΔT = 0.12, MTA = 81%, and 0% outliers, halving the rotation error of the COLMAP baseline (4.99°) and eliminating all outliers. When initialized with gDLS+++, the method improves MTA from 78% to 84% and reduces outliers from 6% to 3%. Against feed-forward 3D models (DUSt3R, MASt3R, VGGT, π³), the method outperforms all by an order of magnitude in geodesic rotation error (2.59° vs. 24–68° for meta-to-reference alignment).

## Baselines & Comparisons

Against the three classical initialization baselines, the method consistently improves alignment: COLMAP's ΔR drops from 4.99° to 2.48° (50% reduction) with outliers eliminated (12%→0%), gDLS+++ improves in MTA (78%→84%) and outliers (6%→3%) at a negligible ΔT cost, and SP+LG improves in ΔR (3.74°→3.13°) and outliers (15%→7%). Against the four feed-forward 3D models, the gap is dramatic: the method achieves 2.59° geodesic rotation error for meta-to-reference alignment versus 24.18° (MASt3R, the best feed-forward model), 51.69° (VGGT), 54.40° (DUSt3R), and 68.46° (π³), representing a 9–26× improvement. For meta-meta reconstruction, the method achieves 1.48° versus 12.52° (MASt3R), 24.63° (VGGT), 29.27° (DUSt3R), and 45.80° (π³). The paper attributes the feed-forward models' failures to their training on overlapping image sets and memory constraints limiting input size, causing them to collapse non-overlapping partial reconstructions into incorrect geometries.

## Relation to Prior Work

This paper extends the inverse optimization framework of iNeRF [64] from per-camera pose estimation to a global 6DoF+scale transformation over a 3D Gaussian Splatting reference model, and adapts the feature distillation approach of Feature 3DGS [69] to embed DINOv2 semantic features into each Gaussian. The key conceptual departure from prior inverse-optimization methods (iNeRF, VF-NeRF) is replacing photometric loss with semantic feature matching, motivated by the large appearance gap between in-the-wild photographs and pseudo-synthetic Google Earth Studio renderings. The paper also positions itself against the growing family of feed-forward 3D reconstruction models (DUSt3R, MASt3R, VGGT, π³), demonstrating that these models—trained predominantly on overlapping image collections—fail catastrophically on the non-overlapping, cross-domain setting this paper targets.

## Why It Matters / Open Questions

The paper addresses a fundamental practical limitation of both classical SfM and modern feed-forward 3D models: their dependence on visual overlap, which is routinely violated in large-scale in-the-wild photo collections. The WikiEarth benchmark is the first standardized dataset providing ground-truth alignments between partial in-the-wild reconstructions and complete pseudo-synthetic reference models, enabling reproducible evaluation of cross-domain 3D alignment. Limitations include sensitivity to initialization quality and degraded performance on very small image collections; the authors note that future work could leverage the aligned non-overlapping meta-images to train sparse reconstruction pipelines or build hybrid representations combining pseudo-synthetic coverage with real-world appearance detail.

## Problem

Existing monocular depth estimation methods represent depth on discrete image grids, which inherently limits output resolution to the training resolution and sacrifices high-frequency geometric details through convolutional upsampling or linear projection. This grid-based paradigm also causes strong density imbalance when unprojecting depth to 3D, degrading downstream tasks like novel view synthesis under large viewpoint shifts.

## Input / Output

The method takes a single RGB image and queries depth at any continuous 2D coordinate (x, y) in the image plane, producing depth values at arbitrary resolution without being constrained by training resolution. For metric depth estimation, sparse depth samples are incorporated via a depth prompt module. The Infinite Depth Query strategy additionally produces a uniform 3D point cloud by allocating sub-pixel query budgets proportionally to each pixel's projected 3D surface area, which feeds a Gaussian Splatting head for novel view synthesis.

## Method

InfiniDepth encodes the input image with a DINOv3 ViT-Large encoder, extracting features from layers 4, 11, and 23 and constructing a multi-scale feature pyramid via a reassemble block that upsamples shallow features while retaining deep features at native resolution. For any continuous query coordinate, local features are gathered at each pyramid scale via bilinear interpolation over a 2×2 grid neighborhood, then hierarchically fused from shallow to deep using residual gated fusion blocks (learnable channel-wise gates with FFN), and finally decoded to a depth value by a lightweight MLP. Training uses sparse coordinate-depth pairs with L1 loss rather than full-grid supervision, exploiting the resolution-agnostic nature of the implicit representation. The Infinite Depth Query computes an adaptive weight w(x,y) = d²/(|n·v|+ε) from the differentiable implicit field to allocate sub-pixel queries proportional to 3D surface area, yielding spatially uniform point clouds that improve NVS quality under large viewpoint shifts.

## Results

On the newly introduced Synth4K benchmark (4K resolution), InfiniDepth achieves δ₁ scores of 89.0–96.3% across five game-based subsets, outperforming the strongest baseline MoGe-2 (84.2–95.3%) by 3–6 points on δ₁. On high-frequency detail regions, the gap widens substantially: InfiniDepth reaches 67.5–79.5% δ₁ versus 66.5–77.3% for MoGe-2. On standard real-world benchmarks (KITTI, ETH3D, NYUv2, ScanNet, DIODE), InfiniDepth matches or slightly exceeds SOTA relative depth methods (e.g., 99.1% δ₁ on ETH3D vs. 99.0% for MoGe-2), while the metric variant (Ours-Metric) achieves 96.7% δ₀.₀₁ on ETH3D, surpassing PromptDA (92.8%) by nearly 4 points.

## Baselines & Comparisons

InfiniDepth outperforms all seven relative depth baselines (DepthAnything, DepthAnythingV2, DepthPro, MoGe, MoGe-2, Marigold, PPD) on every Synth4K subset, with the largest margins over Marigold (up to 20+ points on δ₁) and consistent 3–6 point gains over the strongest competitor MoGe-2. On real-world benchmarks (Table 3), InfiniDepth is competitive with MoGe-2 and DepthAnything, achieving the best δ₁ on ETH3D (99.1%) but trailing slightly on ScanNet (97.3% vs. 98.4%). For metric depth estimation, Ours-Metric dominates all four depth-completion baselines (Marigold-DC, Omni-DC, PriorDA, PromptDA) on both Synth4K and real-world data, with the clearest advantage on ETH3D (96.7% vs. 92.8% δ₀.₀₁ for PromptDA). Marigold-DC underperforms notably due to VAE quantization loss. For novel view synthesis, InfiniDepth combined with the depth query strategy produces fewer geometric holes and artifacts than ADGaussian under large viewpoint shifts, though this comparison is qualitative (Fig. 8) rather than quantitative.

## Relation to Prior Work

InfiniDepth extends the neural implicit representation paradigm (established by NeRF for 3D scenes, LIIF for continuous images, and AnyFlow for optical flow) to monocular depth estimation, replacing the standard discrete-grid DPT-style decoder with a multi-scale local implicit decoder that queries depth at arbitrary continuous 2D coordinates. The encoder follows the DINOv3 ViT-Large + reassemble block design from DPT/DepthAnything, but the key architectural departure is the hierarchical residual-gated fusion of multi-scale bilinearly-interpolated features into a lightweight MLP head, enabling resolution-agnostic prediction. The depth query strategy for uniform 3D point distribution draws on differential geometry (surface area element via depth-squared scaling and normal-viewing-angle compensation) to address density imbalance in unprojected point clouds, complementing feed-forward NVS methods like ADGaussian and DepthSplat that rely on pixel-aligned depth.

## Why It Matters / Open Questions

By decoupling depth prediction from a fixed output grid, InfiniDepth removes the fundamental resolution ceiling of grid-based methods and enables direct 4K+ depth queries without upsampling artifacts, which is practically important for high-resolution applications in autonomous driving and robotics. The Synth4K benchmark addresses a real evaluation gap—existing real-world datasets lack high-resolution ground-truth depth to properly assess fine-detail recovery. A key limitation is that the model is trained on single-view data only, so video applications suffer from temporal flickering; extending the implicit representation to multi-view settings for 3D and temporal consistency is the natural next step. The depth query strategy also opens a path for more uniform surface sampling in any pipeline that unprojects depth to 3D points.

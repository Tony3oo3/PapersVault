## Problem

Existing OOD detection methods either assume a single dominant object per image (image-level) or handle multiple objects but rely on coarse global representations and uniform background treatment (object-level, e.g., RUNA). No prior framework unifies both granularities in a single model that operates without knowing at inference time whether the task is object-level or image-level, leaving a persistent performance gap between the two formulations.
![Teaser figure](../imgs/CVPR20261653/cropped_page1_idx0.webp)

## Input / Output

At inference, the method takes a raw RGB image and a list of ID class names (no bounding boxes or labels are provided). A pre-trained OWLv2 detector localizes all objects; each detected object is cropped as the target image while the masked remainder forms the background image. The output is a per-object OOD/ID binary decision (via a cosine-similarity threshold δ against the best-matching ID class prompt), which naturally reduces to an image-level decision when only one object is present. No prior knowledge of the task type is required.

## Method

UNI-OOD employs two identical CLIP (ViT-B/16) image-text encoder pairs—one processing the target object crop and its class prompt, the other processing the background image and its multi-object prompts. Five cross-context mechanisms enable joint reasoning: (i) intra-image attention aggregates [CLS] and patch embeddings within the target encoder to capture fine-grained spatial details; (ii) text-vision alignment (cosine similarity) between the target image and text encoders enriches object semantics; (iii) inter-image attention between the two image encoders identifies which background regions are visually relevant to the target; (iv) inter-text attention between the two text encoders fuses multiple background object prompts into a single holistic text embedding; and (v) text-vision alignment for the background integrates its visual and textual cues. Weighted embeddings are fused via small CNN+MLP combiners, and the final OOD score is the cosine similarity between the combined image representation and the target object's text embedding, trained with a standard CLIP contrastive loss under a few-shot protocol (10-shot object-level, 16-shot image-level).

## Results

On object-level OOD detection (10-shot), UNI-OOD achieves AUROC of 98.52 (BDD-100k→OpenImages), 95.91 (BDD-100k→MS-COCO), 96.25 (PASCAL-VOC→OpenImages), and 95.07 (PASCAL-VOC→MS-COCO), with corresponding FPR95 scores of 3.68, 11.32, 14.30, and 22.24. On image-level OOD detection (16-shot, ImageNet-1k as ID), the method reaches an average AUROC of 96.83 and average FPR95 of 15.93 across iNaturalist, SUN, TEXTURE, and PLACES, with per-dataset AUROC ranging from 94.27 (PLACES) to 99.16 (iNaturalist). These results establish new SOTA in both object-level and image-level OOD detection simultaneously within a single unified model.

## Baselines & Comparisons

UNI-OOD outperforms all 17 baselines across both object-level and image-level OOD detection. Against the previous SOTA object-level method RUNA [55], UNI-OOD gains +1.47 AUROC and −4.89 FPR95 on BDD-100k→OpenImages (98.52 vs. 97.05; 3.68 vs. 8.57), and +2.13 AUROC and −6.11 FPR95 on PASCAL-VOC→MS-COCO (95.07 vs. 92.92; 22.24 vs. 28.35). All seven traditional CNN-based object-level methods (CSI, SIREN, VOS, SAFE, SR-VAE, DFDD, WFS) are substantially outperformed, with the best traditional method (SAFE) trailing by 3.88 AUROC on BDD-100k→OpenImages. On image-level OOD detection, UNI-OOD surpasses the strongest image-level baseline DPM-T [56] by +1.11 average AUROC (96.83 vs. 95.72) and −5.16 average FPR95 (15.93 vs. 21.09), and outperforms NegPrompt [24] by +2.02 average AUROC. Notably, RUNA adapted to image-level detection (requiring prior knowledge of the task type) still underperforms UNI-OOD by +3.51 average AUROC, confirming the advantage of the unified cross-context design.

## Relation to Prior Work

This paper builds directly on CLIP's dual-encoder architecture (Radford et al., ICML 2021) and extends the object-level OOD detection line initiated by RUNA (Zhang et al., AAAI 2025), the first and only prior VLM-based method for that task. The key departure from RUNA is threefold: replacing its reliance on the [CLS] token alone with intra-image attention over all patch embeddings, substituting its uniform Gaussian-blur background with inter-image attention that identifies spatially relevant contextual cues, and introducing inter-text attention to construct holistic multi-object background semantics rather than treating the background as a single undifferentiated region. Conceptually, the paper positions image-level OOD as a strict special case of object-level OOD (single-object scenes), thereby unifying two previously separate research threads—image-level methods (CoOp, LoCoOp, PLOT, DPM-T, etc.) and object-level methods (RUNA, SAFE, WFS, etc.)—into a single framework that requires no task-type specification at inference.

## Why It Matters / Open Questions

The practical motivation is strong: real-world deployment (autonomous driving, robotics, surveillance) involves multi-object scenes where each object needs an independent OOD decision, yet the dominant image-level OOD literature assumes a single dominant object per image. By eliminating the need to know the detection granularity at inference, the framework simplifies system design and removes a brittle assumption. Key limitations include the dependency on an external object detector (OWLv2) for bounding boxes, which introduces localization errors that propagate into OOD scoring, and the inference-time approximation of background semantics using all ID class prompts rather than the actual background objects—a necessary compromise given combinatorial explosion but one that may degrade performance in scenes with many objects. Open questions include how the method behaves when the object detector misses objects or produces spurious detections, whether the five cross-context mechanisms generalize to 3D or video settings, and whether the few-shot training protocol (10–16 shots) is sufficient for long-tailed or highly domain-specific ID distributions.

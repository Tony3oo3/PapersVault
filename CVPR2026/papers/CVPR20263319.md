## Problem

Reconstructing a full 4D human-object interaction scene (human, novel manipulated object, and static scene) in a common world frame from a single monocular RGB video with a moving camera remains unsolved. Prior methods either handle humans or objects in isolation, assume known 3D templates or calibrated cameras, or operate only in the camera frame, leaving the entangled camera-object motion and the lack of prior object knowledge unaddressed.
![Teaser figure](../imgs/CVPR20263319/cropped_page0_idx1.webp)

## Input / Output

The method takes a single handheld monocular RGB video (no depth, no multi-view, no pre-scanned object template) as input and produces detailed 3D meshes of the human, the manipulated object, and the surrounding scene all registered in a shared world frame, along with novel-view renderings. The object is entirely novel and unseen, and the camera viewpoint moves throughout the sequence, making depth and motion inherently ambiguous.

## Method

RHINO is a three-stage framework. First, it initializes coarse geometry: SAM2 segments the video into scene/object/human masks; SfM on background pixels yields camera motion and a scene point cloud; MASt3R (a 3D-aware foundation model) provides dense, robust feature correspondences on the low-texture object to estimate apparent motion; and AiOS infers per-frame SMPL-X bodies. Second, it disentangles camera and object motion by identifying static-object frames via RANSAC, solving a similarity transform (Umeyama) to align the object's apparent camera trajectory to the true scene camera trajectory, and subtracting the camera component to recover true object motion in the world frame. Third, it refines all three components jointly using a compositional neural field with per-component signed-distance fields (human conditioned on body pose via LBS, object and scene in canonical space) rendered via compositional volume rendering. A key insight is repurposing the per-component neural SDFs to define a differentiable contact loss that attracts body contact points onto the object surface while penalizing interpenetration, applied in a two-stage alternating scheme that first optimizes shapes and then freezes them to refine poses with physical losses.

## Results

On the BenchRHINO dataset, RHINO achieves a Chamfer Distance of 2.42 cm for the combined human+object reconstruction, substantially outperforming InterTrack (7.18 cm) and matching HSR on human-only shape (2.65 vs. 2.69 cm) while additionally reconstructing the object at 1.21 cm CD. For novel-view synthesis, RHINO attains 25.80 dB PSNR, 0.832 SSIM, and 0.212 LPIPS, surpassing HSR (22.65 dB) and HOLD (17.92 dB). The object F1 score at 2 cm reaches 90.42%, compared to 33.64% for HOLD and 16.81% for InterTrack.

## Baselines & Comparisons

RHINO outperforms all three baselines across every reported metric. Against HSR [68], which reconstructs only the human and static scene (no object), RHINO matches human CD (2.65 vs. 2.69 cm) while adding object reconstruction at 1.21 cm CD and 90.42% F1, and improves novel-view synthesis PSNR from 22.65 to 25.80 dB. Against HOLD [14], which handles only hand-object interactions in the camera frame, RHINO reduces object CD from 4.41 to 1.21 cm and F1 from 33.64% to 90.42%, while also reconstructing the full body and scene. Against InterTrack [67], which predicts sparse point clouds and struggles with out-of-distribution objects, RHINO cuts combined human+object CD from 7.18 to 2.42 cm and F1 from 25.02% to 56.51%. In the object pose estimation ablation, RHINO's MASt3R-based correspondences achieve 1.09 cm CD and 91.38% F1, versus 4.25 cm / 60.06% for SuperPoint+SuperGlue and 3.97 cm / 62.80% for LoFTR, confirming that 3D-aware foundation models are critical for robust pose initialization on low-texture objects.

## Relation to Prior Work

RHINO extends the compositional neural SDF framework from HSR [68] and Vid2Avatar [16]—which model humans and static scenes in a world frame—to additionally reconstruct a dynamically manipulated novel object, requiring a new motion-disentanglement stage that separates camera-induced apparent motion from true object motion via SfM on scene-only and object-only pixels. For physical plausibility, it adapts the differentiable contact/collision loss formulation from Tripathi et al. [55] but repurposes per-component neural SDFs as the distance oracle, enabling contact reasoning directly within the shape representation. A key departure from prior HOI work (HOLD, InterTrack) is the use of 3D-aware foundation models (MASt3R) for object pose initialization instead of traditional 2D feature matching, and the explicit world-frame formulation that prior camera-frame methods lack.

## Why It Matters / Open Questions

RHINO is the first framework to recover a full 4D human-object-interaction scene (human + novel object + static scene) in a common world frame from a single monocular video with a moving camera, a setting that mirrors real-world video but was previously unaddressed. The new BenchRHINO benchmark, with synchronized volumetric 4D ground truth and a handheld moving camera, fills a critical evaluation gap since all prior HOI datasets use static cameras. Limitations include restriction to a single person and a single rigid object, slow optimization, and dependence on good object coverage; extending to multiple interactors, articulated/non-rigid objects, and real-time operation are the natural next steps.

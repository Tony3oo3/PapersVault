## Problem

Existing AI-based inscription restoration methods rely on rigid single-pass pipelines or image-to-image transfer paradigms that cannot generalize across the heterogeneous, spatially coupled, and multi-scale degradations found in real ancient inscriptions. These approaches fail to simultaneously preserve textual authenticity (correct character identity) and calligraphic visual fidelity (stroke morphology and style consistency), leaving a critical gap between automated output and expert-level restoration.

## Input / Output

The system takes a single degraded Chinese inscription rubbing image as input and produces a fully restored inscription image as output. Internally, the input is decomposed into per-character regions via a layout rectification module, and the planner generates individual tool-invocation sequences for each character. The observation stage also produces structured intermediate signals—pixel-level degradation segmentation masks with discrete severity levels (none/slight/middle/severe), a corrected textual reading, and a rectified layout—that condition all downstream planning and execution decisions.

## Method

EpiAgent formulates inscription restoration as a hierarchical planning problem governed by an LLM-based central planner (Kimi-K2) operating in an iterative Observe-Conceive-Execute-Reevaluate loop. In the Observe stage, a multimodal pipeline (MLLM for initial perception, a LoRA-fine-tuned Qwen2 7B corrective language model with RAG over a Chinese corpus for text correction, a layout rectification module, and a degradation assessment module) produces a structured observation record. The Conceive stage exploits experience priors—statistical tool-efficacy distributions mined from historical execution logs—to generate per-character ordered tool sequences adaptively. The Execute stage applies a composable toolkit of four specialized tools (three diffusion-based: background denoising, stroke completion, and font imitation, plus a character retrieval fallback) in the planned order. The Reevaluate stage scores each character on text authenticity (1−CER), style consistency (cosine similarity to reference style embeddings), and optional human expert feedback, identifying a failure set that triggers replanning for subsequent iterations until convergence or a maximum iteration budget is reached.

## Results

On the synthetic Testing Set S, EpiAgent achieves 22.14 PSNR, 0.9684 SSIM, 0.0254 LPIPS, and 0.9069 1-NED, surpassing the strongest baseline IR3 (21.15 PSNR, 0.8855 1-NED) by ~1 dB in PSNR and ~2.1 points in text similarity. On the real-world splits R-I and R-II (unseen degradation patterns), EpiAgent leads all baselines in both no-reference quality (e.g., 0.9393 CLIP-IQA on R-I vs. 0.9370 for IR3) and end-to-end text accuracy (0.5766 vs. 0.5539 1-NED on R-I). In a user study with 20+ epigraphers, EpiAgent is ranked first 59.66% of the time (vs. 15.60% for the next-best IR3), confirming expert-level preference.

## Baselines & Comparisons

EpiAgent outperforms all eight baselines across every metric on all three test splits. The closest competitor is IR3 [48], the prior inscription-specific method, which EpiAgent surpasses by 0.99 dB PSNR, 0.0144 SSIM, and 2.14 points 1-NED on Set S; the gap widens on real-world splits (e.g., 0.5766 vs. 0.5539 1-NED on R-I). Among general image restoration methods, MambaIR [9] and PromptIR [20] are the strongest on PSNR (21.10 and 19.30 respectively) but lag EpiAgent by 1.04 and 2.84 dB, and their text recognition accuracy (Top-1 0.9093, 0.8601) is far below EpiAgent's 0.9889. Text-specific methods CharFormer [22] and GSDM [47] achieve moderate quality but suffer the largest recognition drops (Top-1 0.9109 and 0.8948), reflecting their inability to handle inscription-level coupled degradation. DocDiff [36] and MoCE-IR [38] show mid-range performance, while Restormer [39] is the weakest baseline overall (18.90 PSNR, 0.8097 Top-1). In the user study, EpiAgent's 59.66% Top-1 ranking dwarfs IR3's 15.60%, a 3.8× margin that underscores the perceptual quality gap beyond what automatic metrics capture.

## Relation to Prior Work

EpiAgent synthesizes two largely separate research threads: (1) the agentic image-restoration paradigm (RestoreAgent, Multi-agent IR), where an MLLM perceives degradation and dynamically invokes pre-trained tools, and (2) domain-specific inscription restoration (IR3, AutoHDR), which uses fixed pipelines or end-to-end image-to-image translation. The key departure is that prior agentic systems are general-purpose and cannot capture the linguistic and calligraphic constraints of ancient scripts, while prior inscription methods lack adaptive planning. EpiAgent repurposes the agentic loop (Observe-Conceive-Execute-Reevaluate) with domain-tailored tools (diffusion-based denoising, inpainting, font imitation, character retrieval) and a corrective language model with RAG, effectively bridging the gap between flexible LLM orchestration and specialized heritage restoration.

## Why It Matters / Open Questions

This is the first system to formalize the full epigrapher workflow—multi-modal analysis, experience-guided planning, composable tool execution, and multi-perspective self-refinement—as a closed-loop agentic process for inscription restoration. The consistent gains over both general-purpose restorers and the closest domain-specific baseline (IR3) across synthetic and real rubbings, plus the large user-study margin, suggest that adaptive planning genuinely outperforms fixed pipelines for coupled, heterogeneous degradations. Open questions include whether the approach transfers to other scripts (Greek, Linear B, cuneiform), whether the LLM planner's overhead is justified at scale for mass digitization, and how the system behaves when the historical corpus (RAG) is sparse or unavailable for lesser-known inscriptions.

## Problem

Vision-language models lack persistent, structured memory that encodes what was observed, where, and when, limiting them to short-context or parametric reasoning on long-horizon embodied tasks. Existing retrieval-augmented approaches operate over static text corpora or flat video captions without object-level metric spatial anchoring, and no prior method enables structured 4D retrieval (simultaneously over semantic, spatial, and temporal axes) from a globally consistent world model without retraining the VLM.
![Teaser figure](../imgs/CVPR20262567/cropped_page0_idx0.webp)

## Input / Output

The system consumes a continuous stream of synchronized RGB images, LiDAR point clouds, and timestamps, along with camera intrinsics/extrinsics for 3D projection, and at inference receives a natural language query. The VLM backbone (Gemma3-4B-IT) is prompted with a retrieval handbook that constrains query decomposition into semantic, spatial, and temporal keys; the output is a natural language answer or navigation decision, while the 4D knowledge database is continuously updated as a side product. Each database entry is a JSON record containing a semantic description, 3D centroid and bounding-box extent in world coordinates, temporal appearance/disappearance intervals, an agent ID, and a visibility flag.

## Method

R⁴ is a training-free framework with two parallel components. The storage pipeline uses SAM2 for object segmentation, projects point-cloud points into image space to compute per-object 3D centroids and extents, and queries the VLM for a concise semantic description; these form 4D entries stored in three parallel structures—a vector database for semantic embeddings, a globally consistent SLAM map (MapAnything) for metric spatial indexing, and a columnar time-series database for temporal intervals—with continuous refinement via joint spatial-distance and semantic-similarity matching. The retrieval-reasoning pipeline first lets the VLM self-estimate answerability from live perception; if confidence is insufficient, the VLM decomposes the query into semantic, spatial, and temporal keys guided by a structured handbook, performs heterogeneous retrieval (cosine similarity in embedding space, nearest-neighbor/directional filtering in Euclidean SLAM coordinates, and interval search over timestamps), and iteratively re-injects the retrieved 4D context into its reasoning loop until a satisfactory answer is produced. The key distinction from classical RAG is that retrieval operates directly in structured 4D space with metric spatial grounding and temporal persistence, enabling episodic queries, occlusion reasoning, and multi-agent collaborative recall through a shared SLAM-aligned database without any fine-tuning.

## Results

On ERQA, R⁴ achieves 70.25% multiple-choice accuracy, surpassing GPT-5 (65.7%) and o3 (64.0%) despite using only a 4B-parameter VLM backbone (Gemma3-4B-IT) without task-specific training. On OpenEQA, R⁴ reaches 79.77% LLM-Match on EM-EQA (All) and 74.00% on A-EQA (HM3D), improving over the prior best (GPT-5 at 64.4% EM-EQA) by +15.37% and over 3D-Mem (52.6% A-EQA) by +21.4%. On VLM4D, R⁴ attains 77.31% overall accuracy in a cross-conditioned memory transfer setting, outperforming Gemini-2.5-Pro (62.0%) by +15.31%. In the collaborative A-EQA setting, R⁴-Collab improves exploration efficiency (SPL) from 61.47% to 70.13% over the single-agent configuration.

## Baselines & Comparisons

R⁴ outperforms all compared baselines across every benchmark. On ERQA, it beats GPT-5 (65.7%) by +4.55% and o3 (64.0%) by +6.25%, despite using a 4B VLM versus their much larger parametric models. On OpenEQA EM-EQA, R⁴ (79.77% All) surpasses GPT-5 (64.4%) by +15.37% and 3D-Mem (57.2%) by +22.57%, approaching the human baseline (86.8%) within 7 points. On OpenEQA A-EQA, R⁴ (74.00%) exceeds 3D-Mem (52.6%) by +21.4% and GPT-4V (41.8%) by +32.2%, with the SPL efficiency metric (63.37%) also far above 3D-Mem (42.0%). On VLM4D, R⁴ (77.31% overall) leads Gemini-2.5-Pro (62.0%) by +15.31% and GPT-4o (57.5%) by +19.81%, with the largest gap in directional reasoning (+22.62% over Gemini-2.5-Pro). The only metric where R⁴ does not lead is VLM4D's false-positive (FP) score, where Gemini-2.5-Pro (80.0%) and Claude-Sonnet-4 (86.7%) slightly exceed R⁴ (76.13%), though the paper notes FP measures situational local discrimination where memory is not expected to help.

## Relation to Prior Work

R⁴ synthesizes ideas from three distinct research threads—SLAM-based cognitive mapping (MapNet, Neural Map), retrieval-augmented generation for VLMs (ReMEmbR, RAG-Driver, 3DMem), and multi-agent shared memory (SRMT, MRCNet)—into a unified, training-free framework. It departs from prior RAG-for-VLMs work by replacing flat text or image-snapshot retrieval with object-centric 4D entries anchored in a globally consistent SLAM map, and from prior embodied memory systems by adding structured query decomposition along semantic, spatial, and temporal axes. The paper explicitly positions itself as the first to combine continuous 4D storage with iterative retrieval-reasoning loops and multi-agent alignment without any fine-tuning of the underlying VLM.

## Why It Matters / Open Questions

R⁴ demonstrates that a small (4B) training-free VLM, when grounded in a structured 4D world model, can outperform frontier-scale parametric models (GPT-5, o3) on embodied reasoning, suggesting that explicit spatial-temporal memory is a more efficient path to long-horizon embodied intelligence than scaling parametric knowledge alone. Key open questions include retrieval latency for real-time deployment, the absence of dedicated multi-agent benchmarks for shared 4D memory, and whether the framework extends to reasoning about physical interactions and dynamic state prediction. The paradigm of decomposing natural language queries into heterogeneous retrieval keys (embedding-space, Euclidean, temporal) over a persistent world model could become a standard component of embodied VLM pipelines.

## Problem

Existing multimodal LLM agents in open-world environments like Minecraft treat memory as a passive repository of static records or reusable skills, without explicitly modeling the structural patterns that make experience transferable across tasks. This paper asks: how can an agent decompose prior experience into interpretable transfer axes so that it can actively retrieve, adapt, and generalize from past interactions to unseen tasks rather than merely replaying stored behaviors?
![Teaser figure](../imgs/CVPR20261505/cropped_page0_idx0.webp)

## Input / Output

The agent consumes RGB game screenshots, natural-language task instructions, and structured CSD entries from a long-term memory bank (each CSD containing metadata plus five semantic fields—struct, attr, proc, func, inter—with both symbolic text and global vector embeddings). The instruction-tuned MLLM outputs a hierarchical plan π_t, a set of self-verification assertions Ass_t, and an executable action sequence; upon successful execution, a new CSD is written back to memory. Retrieval operates over the five CSD components simultaneously, computing multidimensional semantic similarity to select top-K exemplars for the ICL context.

## Method

Echo decomposes transferable knowledge into five explicit axes—Structural (spatial layout), Attribute (physical properties), Procedural (causal state transitions), Functional (object purpose), and Interaction (perception-action feedback)—and encodes each task experience as a Contextual State Descriptor (CSD) that aligns multimodal signals along these axes. An In-Context Analogy Learning (ICAL) module then retrieves the top-K most relevant CSDs by multidimensional similarity, constructs a structured ICL prompt, and prompts a frozen instruction-tuned MLLM to induct new task action sequences by analogy. A verifier checks both internal logical consistency and external task feasibility before execution, and successful trajectories are consolidated back into the memory bank with periodic deduplication and clustering. The MLLM is instruction-tuned on structured task examples, execution traces, and verifier feedback to reliably produce well-formatted CSDs and plans, while all transfer reasoning occurs at inference time without parameter updates.

## Results

In from-scratch Minecraft learning, Echo (8-shot) achieves the highest overall success rates, reaching 62.5/92.5 (Success@0→10/30) on the Bed recipe task and 57.5/92.5 on the Crafting Grid utility task, outperforming the strongest baseline JARVIS-1 (60.0/87.5 on Bed). In the continuous learning experiment over 30 episodes, Echo reaches a final success rate of 45%, surpassing MP5 (43%), JARVIS-1 (35%), MrSteve (33%), and Voyager (18%). The paper reports a 1.3×–1.7× speed-up in item-unlocking milestones compared to prior agents, with a distinctive 'burst-like' chain-unlocking phenomenon in the mid-to-late learning phase.

## Baselines & Comparisons

Echo (8-shot) outperforms JARVIS-1, the strongest baseline, on most task families: Iron Pickaxe (52.5/87.5 vs 50.0/85.0), SmeltEq (47.5/80.0 vs 45.0/75.0), ToolBench (42.5/82.5 vs 42.5/75.0), and CraftTable (55.0/87.5 vs 55.0/82.5). Against MP5, Echo (8-shot) leads on Recipe, Crafting Chain, and Utility Blocks but trails slightly on some Functional Equivalence tasks where MP5's active perception provides an edge. MrSteve is competitive only on Functional Equivalence (45.0/77.5 on SmeltEq) but is substantially weaker on structural and multi-step tasks. Voyager is consistently the weakest baseline across all four task families. In the continuous learning setting (30 episodes), Echo overtakes JARVIS-1 after approximately episode 15, reaching 45% final success versus JARVIS-1's 35%, confirming that explicit transfer axes and structured ICAL yield stronger long-horizon gains despite a slower cold-start.

## Relation to Prior Work

Echo builds on the perception-reasoning-action-memory loop established by Voyager and JARVIS-1, and on In-Context Analogical Learning (ICAL) from Hu et al. (ACL 2023) as its core retrieval-and-adaptation mechanism. The key departure is conceptual: prior agents (Voyager, JARVIS-1, MrSteve, MP5) treat memory as a passive repository from which few-shot examples are retrieved to assist sub-task generation, whereas Echo treats ICL as an active process that proactively discovers, validates, and executes new tasks from the memory bank. The five explicit transfer dimensions (structural, attribute, procedural, functional, interaction) represent a new organizational principle for multimodal memory that goes beyond the episodic What-Where-When indexing of MrSteve or the skill-library approach of Voyager.

## Why It Matters / Open Questions

The explicit transfer-axis formulation offers an interpretable vocabulary for diagnosing why an agent fails to generalize (e.g., a procedural-axis error vs. an attribute-axis error), which could guide targeted improvements in embodied agents. However, the evaluation is confined to Minecraft's deterministic rule set, and the authors themselves note that real-world transfer is unlikely to be as straightforward; the slower cold-start and weaker performance in information-sparse settings (compared to active-perception methods like MP5) limit immediate practical impact. Open questions include whether the five axes generalize to non-game domains, whether the burst-like chain-unlocking phenomenon persists under noisier or partially observable conditions, and whether the framework scales beyond a single game world without manual CSD schema design.

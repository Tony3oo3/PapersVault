## Problem

Prior EEG-based visual decoding has been dominated by static 2D image paradigms, leaving the neural mechanisms underlying 3D object perception largely unexplored. Although a few recent works have begun decoding 3D objects from EEG, none has investigated how the brain synergistically integrates neural responses from static viewing and dynamic (rotational) observation, nor has any provided direct evidence for functional specialization between these two streams in constructing a coherent 3D percept.
![Teaser figure](../imgs/CVPR20263466/cropped_page2_idx0.webp)

## Input / Output

The method consumes paired 64-channel EEG recordings from the same 3D object under two viewing conditions: a brief static image presentation (x_stat ∈ R^{C×T_stat}) and a sustained rotational video observation (x_dyn ∈ R^{C×T_dyn}), both drawn from the EEG-3D dataset (72 object categories, 12 subjects). The learned dense embedding z ∈ R^d drives two downstream paths: discriminative probes (shape/color classification, cross-modal retrieval against CLIP embeddings) and a generative pipeline where a fine-tuned IP-Adapter conditions SDXL-Turbo to synthesize a 2D image, which a frozen TRELLIS model then converts to a 3D point cloud. A spatial Representational Dependency Index (RDI) map is additionally produced by comparing full versus single-stream reconstructions in VGG-19 feature space, aligned via ORB homography.

## Method

The core contribution is the Hierarchical PAC-guided Fusion (HPACF) encoder, which processes static and dynamic EEG through parallel K-layer Transformer backbones into multi-scale feature hierarchies, then fuses them via cross-attention whose scores are multiplicatively gated by a differentiable Phase-Amplitude Coupling (PAC) index. The PAC index is computed end-to-end by extracting LF phase and HF amplitude via STFT, constructing a Gaussian-kernel-weighted phase-amplitude distribution per channel, and measuring its KL-divergence from uniform (DCI); these cross-stream DCI vectors are mapped by a small MLP to head-specific sigmoid modulation factors that dynamically gate information flow. Level-specific fusion outputs are aggregated into a single embedding via learned softmax weights. Training uses a multi-level alignment objective combining Global Spectral Correction (covariance matching), Prototypical Distribution Alignment (MMD on class prototypes), CLIP contrastive loss, MSE, and class-weighted cross-entropy, which jointly regularize the EEG embedding space at global, class, and instance granularity.

## Results

On the EEG-3D benchmark, BrainSSD achieves state-of-the-art performance across all discriminative tasks: 7.12% Top-1 on Object Type classification, 43.04% Top-1 on Color Type classification, and 6.65% Top-1 on 72-way cross-modal retrieval (a 16.67% relative improvement over the previous best of 5.70% by BrainAlign). For generative reconstruction, the full model attains the lowest LPIPS (0.647) and highest 3D F-score (0.304), while the Dynamic-Only variant achieves the lowest Chamfer Distance (0.096), confirming complementary strengths of the two streams.

## Baselines & Comparisons

BrainSSD outperforms all six baselines across every discriminative metric. Against the two most recent and strongest competitors, BrainAlign (MICCAI 2025) and Neuro-3D (CVPR 2025), BrainSSD gains +1.01 and +1.21 points on Object Type Top-1, +2.34 and +3.11 on Color Type Top-1, and +0.95 and +1.23 on 72-way Top-1 retrieval, respectively. The earlier CNN-based baselines (DeepNet, EEGNet, ShallowFBCSPNet) and the transformer-based EEG Conformer and TSConv trail by 2–3 points on Object Type Top-1 and 2.3–2.7 points on 72-way Top-1. Notably, BrainSSD's single-stream variants (Static-Only: 4.98%, Dynamic-Only: 4.80% on 72-way Top-1) both fall below BrainAlign and Neuro-3D, yet their fusion yields a 33.53% relative improvement over the stronger single-stream, demonstrating that the HPACF mechanism captures genuinely complementary information rather than merely averaging two similar signals.

## Relation to Prior Work

This paper extends the EEG-to-3D decoding line initiated by Neuro-3D (CVPR 2025) and Mind-3D (ECCV 2024) by introducing a dual-stream paradigm that fuses neural responses from both static image presentation and sustained rotational video viewing, rather than relying on a single stimulus type. The core architectural novelty—the Hierarchical PAC-guided Fusion (HPACF) module—repurposes the neuroscience concept of Phase-Amplitude Coupling as a differentiable, learnable gating signal for multi-head cross-attention, a mechanism not previously applied to EEG decoding. The multi-level alignment strategy (global spectral correction, prototypical distribution alignment, and instance-level CLIP/MSE losses) builds on the CLIP-embedding alignment paradigm popularized by BrainAlign and fMRI-to-image work, but adds covariance-matching and MMD-based class-prototype regularization to address the distributional gap between EEG and visual spaces.

## Why It Matters / Open Questions

The static-dynamic dominance analysis provides the first direct visual evidence for a functional specialization in EEG-based 3D perception—static streams encoding holistic form while dynamic streams resolve fine geometric detail—which resonates with the classic dual-stream hypothesis but has not been demonstrated computationally in the EEG domain before. However, the evidence is constrained to a single dataset (EEG-3D, 12 participants, 72 categories) with subject-specific models, leaving open whether the observed specialization generalizes across subjects, object categories, or recording conditions. The neuro-inspired PAC-guided attention mechanism is a potentially transferable design pattern for any task requiring fusion of heterogeneous neural or sensor streams, and the framework's modular generative pipeline (IP-Adapter → SDXL-Turbo → TRELLIS) offers a practical template for EEG-conditioned 3D synthesis.

## Problem

While scaling up multimodal models has been extensively studied, the consequences of downscaling the LLM backbone for on-device deployment remain poorly understood. Specifically, it is unclear which capabilities degrade most when the language model is shrunk and whether the observed performance drops stem from weakened visual reasoning or a more fundamental loss of perceptual ability. This paper provides the first systematic characterization of these downscaling effects and identifies perception as a previously unrecognized central bottleneck.
![Teaser figure](../imgs/CVPR20260545/cropped_page1_idx3.webp)

## Input / Output

The system takes an RGB image (processed via Higher AnyRes with Bilinear Interpolation) and a text question as input. The perception module first produces a free-text description of all instruction-relevant visual details, which then serves as the sole textual interface to the reasoning module. The reasoning module generates a step-by-step chain-of-thought followed by a final text answer, with the thinking budget capped at 4096 tokens and self-reflection limited via NOWAIT for efficiency.

## Method

EXTRACT+THINK is a two-stage decoupled framework built on the Prism architecture, using Qwen3 LLMs (0.6B or 1.7B for perception; 1.7B or 4B for reasoning) with a SigLIP vision encoder and 2-layer MLP connector. The key training innovation is visual extraction tuning: a data generation pipeline converts existing visual instruction tuning examples into extraction tasks by prompting Qwen3VL-8B to produce fine-grained visual descriptions relevant to each question, then post-trains the perception module on this unified extraction objective to reduce the heterogeneity of perceptual skills it must acquire. The reasoning module is enhanced with Qwen3's thinking mode and chain-of-thought prompting, requiring no additional visual supervision. This combination yields a model that surpasses LLaVA-OneVision-0.5B by up to 19.5% on out-of-domain tasks while using 73% fewer visual training samples, and outperforms PrismCaptioner with a perception module ~12× smaller and a reasoning module ~41× smaller.

## Results

EXTRACT+THINK (1.7B perception / 4B reasoning, 2.4M visual samples) achieves an in-domain average of 85.3 across OCR-VQA, TextVQA, ScienceQA, VQAv2, GQA, and VizWiz, and outperforms LLaVA-OneVision-0.5B by 12.9% on in-domain data and 19.5% on the out-of-domain MMStar benchmark while using 73% fewer visual training samples. The smaller variant (0.6B / 1.7B) reaches 80.3 in-domain average, surpassing the largest PrismCaptioner model (7.0B / 70B, 78.3) with a perception module roughly 12× smaller and a reasoning module 41× smaller. The from-scratch configuration EXTRACT+THINK† (0.6B / 1.7B, only 0.4M visual samples) still achieves 78.0 in-domain average, improving over LLaVA-OneVision-0.5B by 9.7% while using 95% fewer visual samples.

## Baselines & Comparisons

Against LLaVA-OneVision-0.5B (71.1 in-domain avg, 8.8M visual samples), EXTRACT+THINK (0.6B/1.7B) wins by 9.2 points (80.3) and the larger variant (1.7B/4B) wins by 14.2 points (85.3), while using 73% fewer visual samples; on out-of-domain MMStar the gap widens to 19.5%. Against PrismCaptioner (7.0B/70B, 78.3 in-domain avg), EXTRACT+THINK (0.6B/1.7B) surpasses it by 2.0 points with a perception module ~12× smaller and a reasoning module ~41× smaller. Against InternVL2.5-0.5B (83.2 in-domain avg, 64M visual samples), the larger EXTRACT+THINK variant (85.3) edges ahead by 2.1 points while using only 2.4M visual samples (~26× less data). Against SmolVLM-1.7B (75.9 in-domain avg), both EXTRACT+THINK variants win by 4.4–9.4 points. The from-scratch EXTRACT+THINK† (0.6B/1.7B, 0.4M data) also exceeds the 1.7B end-to-end baseline (76.8) by 1.2 points, demonstrating that visual extraction tuning alone is a highly data-efficient training paradigm.

## Relation to Prior Work

This paper builds directly on the Prism framework [52], which decouples perception and reasoning in VLMs into a two-stage pipeline, but departs from its core assumption that perception is far less sensitive to LLM scale than reasoning (Prism used a 1.8B perception module with a 70B reasoning module). It extends the visual instruction tuning paradigm established by LLaVA-OneVision [35] and related small MLLMs (SmolVLM, Phi-3-Vision, Moondream) by introducing visual extraction tuning—a new training paradigm that unifies perceptual skill acquisition across diverse tasks—combined with Qwen3's native thinking-mode CoT for the reasoning stage. The work also connects to the broader literature on VLM perception failures [16, 39, 69] but shifts focus from large models to the specific effects of LLM downscaling, which prior studies have left largely unexplored.

## Why It Matters / Open Questions

This is the first systematic characterization of how LLM downscaling differentially affects multimodal capabilities, and the finding that perception degrades as severely as reasoning challenges the field's implicit assumption that smaller models primarily lose reasoning ability. The visual extraction tuning paradigm offers a practical, data-efficient path (95% fewer visual samples) for training capable small multimodal models, which is directly relevant to on-device deployment. Open questions include whether these findings generalize beyond the Qwen3/SigLIP architecture family, how visual encoder downscaling compares to LLM downscaling, and whether visual extraction tuning remains effective at larger model scales where the perception bottleneck may be less acute.

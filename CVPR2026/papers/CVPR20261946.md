## Problem

Existing prompt retrieval methods for Visual In-Context Learning (VICL) rely on image similarity alone, frequently retrieving prompts that are visually similar to the query but carry inconsistent labels (e.g., a cat image annotated as 'flower'), which degrades downstream VICL predictions. The paper demonstrates that label consistency between query and prompt is positively correlated with VICL performance, yet prior retrievers discard the label information that naturally accompanies each prompt.
![Teaser figure](../imgs/CVPR20261946/cropped_page1_idx3.webp)

## Input / Output

At inference, the method takes a single unlabeled query image and a pre-indexed database of prompt image-label pairs (where labels are segmentation masks, bounding-box annotations, or colorized images depending on the task). It outputs the single best prompt pair for VICL inference via MAE-VQGAN. Because the method is retrieval-based, mode-specific prompt embeddings are precomputed and cached, so only the query-side forward pass and a cosine-similarity scan over the database are needed at test time. The frozen CLIP ViT encoder produces 512-d features, and K=10 lightweight MLP experts project these into mode-specific subspaces.

## Method

LaPR builds a dual-encoder with Mixture-of-Experts on both sides. On the prompt side, image and label features are fused into a joint embedding, which K experts project into mode-specific representations; on the query side, K experts similarly produce mode-specific features, and a query-conditioned router outputs a softmax mixture weight vector over the K modes. These weights aggregate both the query embeddings and the prompt embeddings, yielding label-aware query and query-relevant prompt vectors whose cosine similarity drives retrieval. Training uses alternating optimization: in the expert step, a VICL-performance-guided contrastive loss (positives/negatives selected by actual MAE-VQGAN task scores from a Top-50 candidate pool) updates the experts while the router is frozen; in the router step, a label-guided contrastive loss (positives/negatives selected by prompt-query label matching scores) plus a KL-based load-balancing regularizer updates the router while experts are frozen. This decoupling lets experts learn mode-specific encodings while the router learns to infer the implicit query label and route to the most relevant modes.

## Results

On the standard evaluation protocol (without voting), LaPR achieves 41.36 mIoU on Pascal-5i foreground segmentation and 32.01 mIoU on Pascal VOC 2012 single-object detection, outperforming the strongest rerank-based baseline RH-Partial2Global by 6.00% and 3.46% respectively. Under the voting configuration, LaPR matches RH-Partial2Global on segmentation while still improving detection by 4.09%. On the colorization task (ImageNet), LaPR also achieves the best MSE among retrieval-based methods. Cross-fold transferability further confirms the advantage: LaPR averages 38.35 mIoU across folds versus 33.42 for SupPR and 33.66 for Partial2Global.

## Baselines & Comparisons

LaPR outperforms all retrieval-based baselines (Random, UnsupPR, SupPR, Prompt-SelF, Zhu et al.) and the strongest rerank-based method RH-Partial2Global on both segmentation and detection without voting, with margins of 6.00% mIoU and 3.46% mIoU over RH-Partial2Global respectively. Under the voting setting, LaPR's segmentation score is essentially tied with RH-Partial2Global, while detection still improves by 4.09%. Against SupPR (the closest retrieval-based competitor), LaPR gains roughly 6–8 mIoU points on segmentation in the cross-fold setting (e.g., 43.82 vs. 35.46 when trained on Fold-0 and tested on Fold-1). Partial2Global, the prior rerank-based SOTA, is surpassed by LaPR by 13.9% in cross-fold transfer. The colorization task (ImageNet) also favors LaPR over all listed baselines, confirming that label-aware retrieval benefits generative reconstruction as well as discriminative tasks.

## Relation to Prior Work

LaPR extends the prompt retrieval line initiated by SupPR (Zhang et al., NeurIPS 2023), which first applied contrastive learning to select VICL prompts, and the reranking formulations of Partial2Global and RH-Partial2Global. The key conceptual departure is that all prior retrievers operate on image-only similarity, discarding the label that naturally accompanies each prompt; LaPR is the first to explicitly inject prompt labels into the retrieval embedding and to use a query-adaptive Mixture-of-Experts router to estimate the implicit query label at test time. The MoE design draws on the broader MoE literature (SA-MoE, DESIRE-ME, MOICL) but repurposes it for mode-specific label-aware encoding rather than task routing or domain adaptation.

## Why It Matters / Open Questions

The paper demonstrates that a simple, previously ignored signal—prompt label consistency—yields substantial and consistent gains across segmentation, detection, and colorization, and especially strong cross-fold transferability (≈15% over SupPR), suggesting that label-aware retrieval is a broadly applicable principle rather than a task-specific trick. An open question the authors flag is the gap between generic visual representations (CLIP, DINOv2) and the signals that actually drive VICL prediction; bridging this gap could unlock further improvements. Limitations include reliance on a frozen MAE-VQGAN backbone, a fixed number of experts (K=10), and evaluation limited to three pixel-level tasks, leaving open whether the label-aware retrieval principle transfers to higher-level reasoning or multi-modal ICL settings.

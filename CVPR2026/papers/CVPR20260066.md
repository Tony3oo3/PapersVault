## Problem

State-of-the-art text-to-video models produce visually realistic videos that systematically violate Newtonian physics—failing at object counting, momentum conservation, and force inference—while existing evaluation metrics (FID, FVD, and even physics-based benchmarks like Trajan and VideoPhy) cannot reliably detect these physical failures. The paper addresses both gaps: generating physically accurate videos from text and providing a trajectory-grounded evaluation framework that directly measures motion fidelity.

## Input / Output

The system takes a free-form natural language prompt describing a Newtonian physics scene (e.g., projectile launch parameters, pendulum geometry, collision setup) and produces a rendered video at 480p/10fps alongside per-object trajectory telemetry recording position, velocity, and orientation at every simulation timestep. The text prompt is first parsed into a structured JSON specification with explicit physical parameters, units, and initial conditions, which then drives code generation for a physics engine rather than a diffusion model.

## Method

MoReGen replaces diffusion-based denoising with a multi-agent LLM pipeline that generates executable Python code for physics simulators (Pymunk, Blender, Manim), ensuring physical correctness by construction. A supervised fine-tuned text-parser agent (Qwen2.5-Coder-14B, trained on 1,200 curated text-to-specification pairs) converts natural language into structured physics specifications; a code-writer agent translates these into simulation code; and a render agent uses pygame to produce the final video. An iterative evaluator loop combines GroundedDINO object detection, CoTracker3 trajectory estimation, LLM-based trajectory comparison against ground-truth simulation data, and Qwen2.5-VL assessment of physical plausibility and prompt alignment, feeding synthesized feedback back to the code-writer for refinement. The key architectural insight is that by operating in the code domain with explicit physics engine APIs, the system enforces Newtonian dynamics deterministically rather than approximating them statistically from training data.

## Results

On the MoReSet benchmark, MoReGen achieves the best trajectory fidelity across all three MoRe metrics: DTW 8.93±9.61, DTW-N 0.06±0.07, and Procrustes 0.48±0.30, outperforming the strongest commercial model (Sora2: DTW 11.21, DTW-N 0.08, Procrustes 0.55) and the best physics-based baseline (WISA: DTW 12.67, DTW-N 0.09, Procrustes 0.68). Notably, medium-sized open-source models (CogVideoX-5B, WISA) achieve trajectory accuracy comparable to Sora2, suggesting that fine-tuning existing T2V models for physics validity is ineffective. MoReGen also maintains the lowest standard deviation across physics principles, indicating more stable performance under out-of-distribution prompts.

## Baselines & Comparisons

MoReGen outperforms all eight baselines on every MoRe metric. Against the strongest commercial model Sora2, MoReGen reduces DTW by 2.28 (8.93 vs. 11.21), DTW-N by 0.02, and Procrustes by 0.07. Against the best open-source model CogVideoX-5B, the DTW gap widens to 4.01 and Procrustes to 0.14. Among physics-based baselines, WISA (DTW 12.67) and NewtonGen (DTW 17.88) both trail MoReGen substantially, with NewtonGen performing worse than even the weakest open-source model (LTXV). A key finding is that CogVideoX-5B and WISA match or approach Sora2's trajectory accuracy, undermining the assumption that physics-specific fine-tuning of diffusion backbones yields meaningful gains. MoReGen also exhibits the most consistent performance across the nine Newtonian phenomenon classes (lowest variance), whereas commercial models show large standard deviations indicating domain-specific weaknesses.

## Relation to Prior Work

MoReGen departs fundamentally from the dominant diffusion-based T2V paradigm (DiT, Sora, Veo) by replacing probabilistic pixel generation with LLM-driven code synthesis for physics engines (Pymunk, Blender). While prior physics-aided generation work (GPT4Motion, PhysGen, NewtonGen, WISA) still conditions or fine-tunes diffusion backbones with physics signals, MoReGen eliminates the diffusion model entirely, using a multi-agent LLM pipeline (text-parser → code-writer → renderer) to produce executable Newtonian simulations. On the evaluation side, the paper moves beyond VLM/LLM-based scoring (VideoPhy, T2VPhysBench) and distributional metrics (FID, FVD, Trajan) toward direct trajectory-level comparison using DTW and Procrustes analysis, grounded in CoTracker3 point tracking.

## Why It Matters / Open Questions

The paper provides the first quantitative, trajectory-grounded evidence that even frontier commercial T2V models (Sora 2, Veo3, Grok Imagine) systematically violate Newtonian mechanics, and that existing 'physics-based' evaluation metrics (Trajan, VideoPhy) are actively misleading—ranking low-fidelity models above physically accurate simulator outputs. This exposes a critical gap in how the field measures physical validity. However, the framework is currently limited to 2D Newtonian mechanics with simple geometric objects rendered via pygame, far from photorealistic or 3D generalization. Open questions include whether the code-based paradigm can scale to complex multi-body, fluid, or deformable-body physics, and whether trajectory metrics remain discriminative when visual realism is introduced.

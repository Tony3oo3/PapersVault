## Problem

RRT-based motion planners require explicit goal configurations specified as numerical joint angles, yet many practical applications define robot goals through visual observations such as images or demonstration videos where precise goal configurations are unavailable. Existing RRT variants do not accommodate visually defined goals, and single-path gradient-based optimization from differentiable rendering is prone to local minima, making it unreliable for reaching distant or occluded configurations.
![Teaser figure](../imgs/CVPR20261412/cropped_page1_idx0.webp)

## Input / Output

The planner takes a start configuration (d-dimensional joint vector), a goal image at 480×480 resolution, and a pre-trained differentiable robot rendering model (5k–10k 3D Gaussian Splatting primitives trained on MuJoCo renders). It outputs a collision-free sequence of configurations from start to a final pose whose rendering visually matches the goal image, with success defined as average joint error below 0.05 rad. The goal image is consumed through a differentiable pipeline (forward kinematics → Gaussian Splatting renderer → L2 loss) that produces visual gradients with respect to joint angles at each tree expansion step.

## Method

vRRT grows a search tree in configuration space by performing two complementary expansions in parallel on a batch of 32 parent nodes per iteration: random steering toward locally sampled targets for exploration, and visual-gradient steering (q_new = q_p − α·∇_q L_render) for exploitation. Two key mechanisms make this effective: (1) a frontier-based strategy that ranks nodes by rendering loss and samples parents via a truncated geometric distribution p_frontier(k) = (1−κ)κ^k / (1−κ^M), adaptively concentrating search on visually promising regions while retaining exploration diversity; and (2) inertial gradient tree expansion, where each node inherits Adam optimizer states (first moment m, second moment v, iteration count i) from its parent, enabling momentum-consistent gradient descent along each branch rather than resetting optimization at every step. Tree rewiring from RRT* and standard path shortcutting are applied for path quality, and collision checking is performed via MuJoCo. The planner is training-free at inference time; only the underlying differentiable rendering model requires prior supervised training on rendered robot images.

## Results

On visual-goal motion planning, vRRT achieves average success rates of 75.2% (Franka), 79.8% (UR5e), and 73.4% (Fetch) across C-space distance bins of 0.5–2.5 rad, substantially outperforming all baselines. The advantage grows with difficulty: at 2.5 rad, vRRT still reaches 44.7–62.7% SR while single-path baselines drop to 1–4%. On the Panda-3CAM-Azure real-world pose reconstruction benchmark, vRRT achieves 0.083 rad mean per-joint error, halving the error of the best feed-forward regressor (HoRoPose, 0.154 rad) and Dr.Robot (0.164 rad).

## Baselines & Comparisons

vRRT decisively outperforms all three motion-planning baselines across every robot platform. Against Dr.Robot [26] (single-path gradient optimization), vRRT improves average success rate by 55.9 pp on Franka (75.2% vs 19.3%), 53.9 pp on UR5e (79.8% vs 25.9%), and 54.7 pp on Fetch (73.4% vs 18.7%). Prof.Robot [36], which adds path smoothing, narrows the gap slightly (23.6–28.0% SR) but remains far below vRRT. The two-stage Dr.Robot + RRT* baseline [26,15] improves over Dr.Robot alone by only ~0.2–0.4 pp, confirming that error propagation from inaccurate goal estimation in the first stage limits its effectiveness. On the real-world Panda-3CAM-Azure pose reconstruction task, vRRT (0.083 rad avg joint error) beats both feed-forward regressors—RoboPEPP [7] (0.184 rad) and HoRoPose [2] (0.154 rad)—as well as Dr.Robot (0.164 rad), with the largest margin on the occluded J7 joint (0.094 rad vs 0.617 rad for Dr.Robot). Planning time is comparable between vRRT and Dr.Robot + RRT* (~14–27 s), while single-path baselines are faster but at the cost of 3–4× lower success rates.

## Relation to Prior Work

This paper unifies two previously separate lines of work: sampling-based motion planning (RRT/RRT*) and differentiable robot rendering (Dr.Robot, Prof.Robot). Classical RRTs require explicit goal configurations as numerical joint angles and use goal biasing or potential fields for exploitation, while differentiable rendering methods perform single-path gradient optimization from a start configuration toward a goal image but are prone to local minima under occlusion. vRRT is positioned as the first method to inject visual gradients from differentiable rendering directly into a sampling-based tree planner, using the rendering loss as an implicit goal-proximity signal to replace the explicit goal configuration that RRT variants traditionally require. Two specific mechanisms—frontier-based node prioritization via a truncated geometric distribution and inertial (Adam-momentum) state inheritance across tree branches—are introduced to make this integration effective within RRT's probabilistic framework.

## Why It Matters / Open Questions

vRRT addresses a practical gap in vision-centric robotics: many real-world applications (demonstration following, image-specified tasks) provide goals as images rather than joint angles, yet standard planners cannot consume such inputs. The real-world Fetch deployment and Panda-3CAM-Azure benchmark results demonstrate sim-to-real transfer, making the approach immediately relevant to practitioners building manipulation systems. The main open limitation is visual ambiguity—occluded or symmetric robot parts can produce near-identical renderings from different configurations, which tree exploration mitigates but does not fully resolve. Future work could extend this to dynamic scenes, multi-goal planning, or integration with learned scene representations beyond Gaussian Splatting.

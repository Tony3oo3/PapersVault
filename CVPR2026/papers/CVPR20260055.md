## Problem

LLM agents in partially-observable embodied environments exhibit rigid, low-diversity search behavior that persists even after supervised fine-tuning, failing to adapt to changing object layouts at test time. Existing inference-time scaling methods (ReAct, Reflexion, RAP) lack an explicit probability distribution over latent environment configurations, while train-time approaches incur substantial training costs and limit deployment flexibility. The paper addresses this gap by asking whether a lightweight, gradient-free belief module can guide exploratory search at inference time without additional training.
![Teaser figure](../imgs/CVPR20260055/cropped_page0_idx0.webp)

## Input / Output

AWS is invoked only during search subtasks within a larger episode. It consumes the current interaction history and the latest textual (or image, in the multimodal variant) observation from the environment, and produces a single symbolic CHECK action (e.g., 'inspect cabinet') that the base agent translates into a concrete instance-level command. Internally, it maintains and returns a hierarchical belief state: a set of natural-language global hypotheses about household layout and user habits, plus a categorical probability distribution over candidate locations, both of which persist and update across search steps within the subtask.

## Method

AWS casts test-time search as approximate Bayes-adaptive control over a single-state MDP, where the only evolving state is a hierarchical belief (G, S): global textual hypotheses over latent environment structure and a low-level categorical distribution over candidate CHECK actions. Belief updates are implemented as an amortized inference map by prompting a frozen LLM—observations revise the global hypotheses, which are then projected to the action-level distribution via either lexical-similarity scoring or a second LLM query. Action selection maximizes expected information gain (IG) in belief space, where IG is estimated by simulating candidate observations with the LLM and computing the entropy reduction of the projected belief. The entire pipeline requires no gradient updates, fine-tuning, or learned world model; all adaptation occurs through prompt-based belief refinement at test time, making it a plug-in module on top of any off-the-shelf LLM agent.

## Results

On ALFWorld with the LLaMA-70B backbone, AWS achieves 76.0% average success rate, outperforming the strongest inference-time baseline ReflAct (60.5%) by 15.5 points and ReAct (22.1%) by over 50 points. With GPT-4, AWS reaches 90.0% average, remaining competitive with ReflAct (93.3%) while attaining the best or tied-best score on CLEAN, COOL, and PICK-2 subtasks. Against train-time baselines, AWS achieves 87.5%/85.3% (seen/unseen) on ALFWorld and 69.6%/65.2% on VirtualHome, surpassing MPO (80.7%/81.3%) and STeCa (69.6%/63.6%) without any weight updates. AWS also uses 2–5× fewer tokens than strong inference-time baselines to reach comparable or higher success rates.

## Baselines & Comparisons

Against inference-time baselines on ALFWorld, AWS dominates ReAct, RAP, and RAFA by large margins on both GPT-4 and LLaMA-70B backbones (e.g., 76.0% vs. 22.1% for ReAct on LLaMA-70B). AWS also outperforms Reflexion on both backbones (90.0% vs. 82.1% on GPT-4; 76.0% vs. 51.3% on LLaMA-70B). The closest competitor is ReflAct, which edges out AWS on GPT-4 (93.3% vs. 90.0%) but is surpassed by 15.5 points on LLaMA-70B (60.5% vs. 76.0%). Against train-time baselines, AWS achieves the best seen/unseen scores on ALFWorld (87.5%/85.3% vs. MPO's 80.7%/81.3% and WKM's 77.1%/78.2%) and matches STeCa on VirtualHome seen (69.6%) while exceeding it on unseen (65.2% vs. 63.6%), all without any gradient updates or fine-tuning.

## Relation to Prior Work

AWS builds directly on the object-search POMDP literature (Wandzel et al. 2019; Zheng et al. 2022), which abstracts search into a single-state MDP over a belief on candidate locations, and on Bayes-adaptive MDP theory (Duff 2002; Kaelbling et al. 1998) for information-seeking under epistemic uncertainty. It departs from prior LLM-agent work (ReAct, Reflexion, RAP, RAFA, ReflAct) by replacing verbal self-reflection or MDP planning with an explicit hierarchical belief (global textual hypotheses + categorical location posterior) updated via an LLM as an amortized inference engine, and by selecting actions through predicted information gain rather than reward maximization alone. The train-time baselines it outperforms (MPO, STeCa, WKM, ETO) optimize policies or world models over expert trajectories, whereas AWS requires no gradient updates at all.

## Why It Matters / Open Questions

The practical finding that a lightweight inference-time belief module can match or exceed train-time policy/world-model methods on ALFWorld and VirtualHome—while using 2–5× fewer tokens than inference-time scaling baselines—suggests a cheaper deployment path for embodied LLM agents that avoids costly fine-tuning. However, the formulation is restricted to static single-state search subtasks (FIND-THEN-ACT), so it does not address non-stationary object locations, concurrent agents, or long-horizon entangled goals. Open questions include whether the LLM-based belief updater and IG surrogate can be learned end-to-end, whether the approach extends to truly dynamic POMDPs, and whether the hand-designed projection rules (similarity vs. LLM-based) can be replaced by calibrated probabilistic models.

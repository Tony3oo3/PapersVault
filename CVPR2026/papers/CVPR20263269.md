## Problem

Existing VLM-based OOD detection methods such as NegLabel and AdaNeg select negative texts and compare test images using intra-modal distances (text-text or image-image), which contradicts the inter-modal (image-text) contrastive objective that CLIP-like VLMs are trained to optimize. This inconsistency can cause ID samples to be misclassified as OOD when a negative text has large text-text distance from ID labels but small image-text distance to the actual ID image.

## Input / Output

The method consumes RGB test images, a fixed set of ID class labels, a large text corpus (WordNet), and a small number of ID training images per class (N=16) used only to compute class-wise image proxies for the inter-modal criterion. No gradient-based training is performed; the CLIP ViT-B/16 encoder is used as a frozen feature extractor. The output is a scalar OOD score per test image, computed as the ratio of ID-label softmax mass to the total mass including selected negative texts and dynamically generated extra negative text embeddings, which is then thresholded to yield an ID/OOD decision.

## Method

InterNeg enforces distance consistency with CLIP's inter-modal objective through two complementary mechanisms. From the textual side, it selects negative texts from WordNet by requiring that each candidate's inter-modal distance to every ID class image proxy exceeds that class's ID inter-modal base distance (1 − cos(e_i, p_i)), then ranks candidates by total deviation degree and keeps the top-M. From the visual side, during inference, test images whose OOD score falls below a fixed threshold β are treated as high-confidence OOD samples and inverted into the textual space via modality inversion (optimizing pseudo-tokens to minimize cosine distance to the image embedding), producing extra negative text embeddings. These embeddings are further filtered by the same inter-modal criterion and capped at K entries to limit noise. The final OOD score extends NegLabel's formulation by adding both the selected negative texts and the extra negative text embeddings to the denominator of the softmax ratio, all without any training on ID or auxiliary data.

## Results

On the ImageNet-1K Four-OOD benchmark (iNaturalist, SUN, Places, Textures), InterNeg achieves an average AUROC of 97.43% and FPR95 of 14.04%, outperforming the strongest zero-shot baseline AdaNeg (96.66% AUROC, 18.92% FPR95) by 0.77% AUROC and 3.47% FPR95. On the more challenging OpenOOD Near-OOD benchmark, InterNeg achieves 82.20% AUROC and 65.43% FPR95, a 5.50% AUROC improvement over AdaNeg (76.70%) and a 2.09% FPR95 reduction. On Far-OOD, InterNeg reaches 96.71% AUROC and 16.96% FPR95, marginally surpassing AdaNeg (96.43%, 17.31%).

## Baselines & Comparisons

InterNeg outperforms all zero-shot baselines across all four OOD datasets in the Four-OOD benchmark. Against the closest zero-shot competitor AdaNeg, InterNeg improves average AUROC from 96.66% to 97.43% (+0.77%) and reduces average FPR95 from 18.92% to 14.04% (−3.47%), with the largest gains on SUN (AUROC +1.24%, FPR95 −2.72%) and Textures (AUROC +1.33%, FPR95 −9.42%). On the OpenOOD Near-OOD benchmark, InterNeg achieves 82.20% AUROC vs. AdaNeg's 76.70% (+5.50%) and 65.43% FPR95 vs. 67.51% (−2.09%), a substantially larger margin than on Far-OOD where gains are modest (AUROC +0.28%, FPR95 −0.35%). InterNeg also surpasses trained VLM-based methods such as SUPREME (95.54% AUROC, 20.28% FPR95) and NegPrompt (94.81%, 23.01%) without any training, though LAPT (99.63% AUROC on iNaturalist) still leads on that single dataset. The ablation confirms both components contribute: replacing inter-modal with intra-modal distance for negative text selection drops AUROC from 97.43% to 97.11%, and removing extra negative text embeddings entirely drops it to 94.56%.

## Relation to Prior Work

This paper builds directly on NegLabel (Jiang et al., ICLR 2024), which established the paradigm of selecting negative texts from WordNet to extend CLIP's label space for OOD detection, and on the modality inversion technique of Mistretta et al. (ICLR 2025) for projecting images into text space. The key departure is a conceptual critique: prior methods (NegLabel, AdaNeg, CSP) select negative texts using intra-modal text-text distance, which is inconsistent with CLIP's inter-modal contrastive training objective. InterNeg replaces this with an inter-modal criterion (comparing candidate texts against ID image proxies) and adds a visual-perspective component that inverts high-confidence OOD images into extra negative text embeddings, both filtered by the same inter-modal distance consistency.

## Why It Matters / Open Questions

The identification of the intra-modal/inter-modal distance inconsistency provides a clean diagnostic lens for evaluating future VLM-based OOD detection methods, potentially redirecting the field away from text-space-only selection heuristics. The 5.50% AUROC gain on Near-OOD is particularly notable because Near-OOD is where most existing methods struggle, and the improvement comes without any training. However, the method still requires access to ID training images to compute class-wise image proxies, which partially undermines the 'zero-shot' framing; whether the inter-modal criterion generalizes to settings where no ID images are available (e.g., truly open-world deployment) remains an open question.

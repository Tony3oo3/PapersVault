## Problem

Hybrid CNN-Transformer super-resolution models achieve strong results, but scaling attention windows or convolution kernels to expand the effective receptive field incurs prohibitive computational cost, limiting deployment on resource-constrained devices. Existing lightweight alternatives—linear attention, grid attention, and SSM-based methods—either suffer from rank collapse that reduces feature diversity or still struggle to capture global context efficiently, leaving a persistent gap between representational richness and computational budget.
![Teaser figure](../imgs/CVPR20262695/cropped_page0_idx0.webp)

## Input / Output

The model takes a single low-resolution RGB image and reconstructs a high-resolution RGB image at 2×, 3×, or 4× scale. The LR input is first embedded via a 3×3 convolution into shallow features, and the final HR output is produced by a 3×3 convolution followed by pixel-shuffle upsampling. During training, 64×64 patches are randomly cropped from DIV2K with random rotation and horizontal flip augmentation; evaluation is performed on full-resolution test images (1280×720) with PSNR/SSIM computed on the Y channel after border cropping.

## Method

UCAN unifies convolution and attention in a layered architecture built around the Broad Effective Receptive Field Group (BERFG), which pairs a Sharing Block with a Receiving Block that reuses pre-computed attention maps to halve redundant computation. Within each block, a High Performance Attention module uses Flash Attention over 32×32 windows for efficient local context, while a Dual Fusion Layer combines Hedgehog Attention (using symmetric exponential feature pairs to break the rank collapse inherent in linear attention) for global spatial modeling with a channel-attention branch, all at linear complexity in spatial resolution. A Large Kernel Distillation module splits channels into a fine-grained subset (C/4) and a coarse bypass, applying dilated depthwise convolutions only to the fine-grained subset to expand the receptive field with minimal overhead. The network is trained with L1, LDL, and Wavelet losses under Adam, using transfer learning from the 2× checkpoint for 3× and 4× scales.

## Results

On Manga109 (×4), UCAN-L achieves 31.63 dB PSNR with only 48.4G MACs and 902K parameters, outperforming the strongest lightweight baseline ESC (31.54 dB, 149.2G MACs) by 0.09 dB while using 68% fewer MACs. The base UCAN model (705K params, 38.1G MACs) attains 27.79 dB on BSDS100 (×4) and 31.50 dB on Manga109 (×4), surpassing MambaIRV2-light by 0.26 dB on Manga109 with 11% fewer parameters and 50% fewer MACs. At ×2, UCAN achieves 38.34 dB on Set5 and 33.22 dB on Urban100 with just 146.3G MACs, beating OmniSR by 0.12 dB on Urban100 and 0.17 dB on Set5 while using 24% fewer FLOPs.

## Baselines & Comparisons

UCAN (705K params, 38.1G MACs at ×4) outperforms all lightweight Transformer and SSM baselines on Manga109: +0.56 dB over MambaIR-light (30.94), +0.48 dB over OmniSR (31.02), +0.33 dB over SRFormer-light (31.17), +0.26 dB over MambaIRV2-light (31.24), and +0.24 dB over HiT-SRF (31.26), while using 50–62% fewer MACs than most of them. Against the heavier CNN baselines RDN (22.3M params) and RCAN (15.6M params), UCAN gains +0.50 dB and +0.28 dB on Manga109 respectively, with 97% fewer parameters. The larger UCAN-L variant (902K, 48.4G MACs) surpasses the strongest lightweight baseline ESC (968K, 149.2G MACs) by +0.09 dB on Manga109 and matches it on BSDS100 (27.80 dB), while using 68% fewer MACs. On BSDS100 (×4), UCAN ties ATD-light at 27.79 dB but with 62% fewer MACs (38.1G vs 100.1G), and UCAN-L edges ahead at 27.80 dB. The only near-tie is UCAN vs. ATD-light on Manga109 (31.50 vs 31.48 dB), where UCAN still wins on efficiency by a wide margin.

## Relation to Prior Work

UCAN sits at the intersection of three active research threads in lightweight super-resolution: (1) window-based attention from SwinIR for local texture, (2) linear attention with the Hedgehog Feature Map to model global dependencies at O(N) cost, and (3) large-kernel distillation (building on Lee et al. and Xie et al.) to recover high-frequency structure without full-resolution convolutions. The semi-sharing mechanism extends the attention-sharing paradigm of ASID/ESC (Park et al., AAAI 2025) by sharing only the attention map while recomputing dynamic Q/K projections per layer, a deliberate departure from full parameter sharing that the ablations show preserves representational diversity. Conceptually, the paper's core departure from prior work is treating the rank-collapse problem in linear attention as solvable via HFM's symmetric exponential pairing rather than through auxiliary depthwise convolutions or multi-head tricks.

## Why It Matters / Open Questions

For practitioners deploying SR on edge or mobile devices, UCAN's 689K–902K parameter footprint with 38–182G MACs offers a concrete, well-ablated recipe that outperforms recent SSM-based and Transformer-based lightweight models (MambaIRv2, OmniSR, ATD) by 0.1–0.4 dB while using 11–36% fewer FLOPs. The semi-sharing design and channel-restricted distillation are practical architectural choices likely to be adopted in subsequent lightweight restoration work. Open questions include whether the HFM-based global branch generalizes to video SR or other dense prediction tasks, whether the 32×32 Flash Attention window can be further enlarged without the quadratic cost resurfacing, and whether the distillation target (large-kernel teacher) can be replaced by a learned or implicit signal to remove the auxiliary branch entirely.

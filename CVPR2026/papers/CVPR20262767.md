## Problem

Previous coded-aperture light field imaging with event cameras (Habuchi et al., CVPR 2024) required a hybrid sensor capturing both events and intensity images, limiting hardware flexibility and only partially exploiting event-based sensing. This paper addresses whether a 4-D light field with pixel-level accuracy can be reconstructed from events alone, and provides the theoretical justification (the role of a black coding pattern) that makes this possible.
![Teaser figure](../imgs/CVPR20262767/cropped_page2_idx0.webp)

## Input / Output

The method takes N−1 integer-valued event images (each W×H, accumulated from asynchronous +1/−1 events during transitions between N binary 8×8 coding patterns displayed on an LCoS) from a stationary event-only camera (Prophesee EVK4, 1280×720) and produces a 4-D light field L ∈ R^(W×H×8×8) with 64 views at full sensor resolution. The event images are the sole input—no intensity image is required—and the measurement cycle takes approximately 30 ms, making the method applicable to slowly moving scenes despite its static-scene design assumption.

## Method

The approach uses a deep-optics pipeline with two jointly trained modules: AcqNet simulates the coded-aperture event camera (learning N binary 8×8 coding patterns via sigmoid-scaled trainable tensors) and RecNet (a 23-layer CNN) reconstructs the light field from the resulting event images, trained end-to-end to minimize MSE on BasicLFSR. The key theoretical contribution shows that including a black pattern in the coding sequence makes event-based and intensity-based coded-aperture imaging approximately equivalent (Eq. 6), rendering the reconstruction well-posed. Two practical improvements are introduced: a black-first coding sequence (BF) that fixes the first pattern to black to drastically reduce total event count, and reference-aware event generation (RA) that tracks the sensor's reference intensity during simulation to more faithfully model the event generation process. With N=4 patterns, the full method (Baseline+BF+RA) achieves 30.48 dB PSNR / 0.8413 SSIM on BasicLFSR while reducing event count by 66% compared to the prior event-only baseline.

## Results

On the BasicLFSR test dataset, the full Coded-E2LF method (Baseline+BF+RA, N=4) achieves 30.48 dB PSNR / 0.8413 SSIM averaged across all five scene groups, outperforming the event-only variant of Habuchi et al. (27.83 dB / 0.7861) by 2.65 dB while reducing total event count by 66%. With N=8 coding patterns, the method reaches 31.71 dB / 0.8705, nearly matching the full Habuchi method that also uses an intensity image (31.83 dB / 0.8729). In real-camera experiments, a 4-D light field with 8×8 views was reconstructed from three event images captured in ~30 ms, demonstrating pixel-level accuracy from events alone.

## Baselines & Comparisons

Against the most relevant prior work (Habuchi et al., CVPR 2024), the full Coded-E2LF method (N=4) improves PSNR by 2.65 dB over the event-only variant (30.48 vs. 27.83) while reducing total event count by 66%, and with N=8 patterns it nearly matches the full Habuchi method that additionally uses an intensity image (31.71 vs. 31.83 dB). Against the four CA+E2VID baselines (which require 64 one-hot coding patterns and a separate E2VID network), Coded-E2LF achieves roughly 13–14 dB higher PSNR (30.48 vs. 16.11–17.21), demonstrating that pixel-level light-field reconstruction from events is fundamentally superior to treating the problem as video reconstruction. The ablation shows that the black-first sequence (BF) alone slightly degrades quality (29.69 vs. 29.81 dB) but drastically cuts events, while adding reference-aware event generation (RA) recovers and exceeds the baseline quality (30.48 dB) with fewer events. The Baseline variant (technically equivalent to Habuchi event-only but without the complementary constraint) already outperforms Habuchi event-only by ~2 dB, confirming that removing the constraint and tuning noise parameters for the Prophesee EVK4 sensor is beneficial.

## Relation to Prior Work

This paper builds directly on Habuchi et al. (CVPR 2024), which combined a coded aperture with a hybrid event+intensity camera for light field acquisition. The key departure is eliminating the intensity image entirely, making the method purely event-based, which the authors support with a theoretical analysis showing that a black pattern in the coding sequence makes event-based and intensity-based coded aperture imaging approximately equivalent. Two algorithmic improvements—Black-first coding sequence (BF) and Reference-aware event generation (RA)—further reduce event counts while improving reconstruction quality. The method follows the deep optics paradigm of jointly optimizing aperture coding patterns and a reconstruction network (RecNet), extending the AcqNet-RecNet pipeline from Habuchi et al. to the event-only setting.

## Why It Matters / Open Questions

This is the first demonstration of pixel-level accurate 4-D light field reconstruction from events alone, which opens the door to using high-performance event-only sensors (e.g., Prophesee EVK4 at 1280×720, 1.066 Geps) that far outperform the limited hybrid sensors currently available. The ~30 ms measurement time enables capturing slowly moving scenes, and the theoretical equivalence result provides a principled foundation for future event-based computational imaging. Limitations include the static-scene assumption, monochrome output, 8×8 view resolution, and a quality gap (~1.3 dB) versus the full intensity+event method of Habuchi et al. Open questions include whether faster hardware and motion-aware reconstruction can close this gap and extend the method to dynamic scenes.

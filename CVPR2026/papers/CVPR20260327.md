## Problem

Existing unsupervised non-rigid point cloud correspondence methods propagate features based on spatial relations (typically KNN), which inevitably include non-physical connections between spatially close but topologically separate shape parts. These connections are highly sensitive to non-rigid deformation, producing inconsistent features and mismatches in geometrically similar or deformed regions. The paper addresses this by explicitly learning shape topology that remains invariant under deformation and using it to guide feature propagation.

## Input / Output

The method takes a pair of source and target point clouds (N=1024 points each) and outputs a dense point-to-point correspondence mapping. Internally, it estimates 16 semantic keypoints as superpoints and computes topology confidence matrices (keypoint-to-point and keypoint-to-keypoint) that reweight relative geometric relations. At inference, a test-time optimal transport step globally optimizes the cosine-similarity correspondence matrix before selecting the highest-similarity point within each cross-neighborhood as the final match.

## Method

The core contribution is a topology-aware feature propagation module embedded in a coarse-to-fine pipeline. A semantic keypoint estimation network (Key-Grid) yields keypoints and topology confidence weights W_kn and W_kk, which encode which point-keypoint and keypoint-keypoint connections adhere to physical shape topology. A modified topology-aware transformer computes attention maps by multiplying querying features, referring features, and topology weights together, then propagates features while suppressing non-physically connected pairs. The coarse-to-fine strategy first aggregates point features into keypoint features using W_kn, then propagates among keypoints using W_kk for global topology awareness. A vector quantization codebook (64 codes) replaces the topology-aware keypoint features with dataset-shared representative codes, improving robustness to shape variance. Finally, keypoint features are fused back into point-wise features via W_nk, and test-time optimal transport refines the correspondence matrix for the final output.

## Results

On the four standard benchmarks, the proposed method (Ours+) with test-time optimal transport achieves the best accuracy across all settings: 37.9% acc / 3.2 err on SURREAL→SHREC'19, 24.0% acc on SHREC'19→SHREC'19, 60.5% acc / 1.7 err on SMAL→TOSCA, and 71.5% acc / 0.8 err on TOSCA→TOSCA. Without test-time refinement (Ours), the method still leads on SURREAL→SHREC'19 (33.2% acc) and SMAL→TOSCA (54.0% acc), showing strong cross-dataset generalization. The method also achieves competitive computational cost (71.5 GFLOPs, 8.7M params, 1044 ms inference) compared to large-vision-model-based baselines like DIFF3F (>1000 GFLOPs, >100M params, >10000 ms).

## Baselines & Comparisons

The proposed method (Ours+) achieves the highest accuracy on all four benchmarks, with the most dramatic gains on cross-dataset settings: 37.9% acc on SURREAL→SHREC'19 (vs. 27.1% for DV-Matcher, the strongest prior method) and 60.5% acc on SMAL→TOSCA (vs. 41.6% for DiffCorr). On the in-distribution TOSCA→TOSCA benchmark, Ours+ reaches 71.5% acc, surpassing DiffCorr (66.7%) and AMIGO (65.9%), though AMIGO achieves a slightly lower error (0.5 vs. 0.8). On the small-dataset SHREC'19→SHREC'19 setting, Ours+ leads in accuracy (24.0%) but has a higher error (6.4) than DV-Matcher and AMIGO (both 4.3), suggesting the topology-aware propagation helps global matching but struggles with fine-grained error on this challenging benchmark. Compared to large-vision-model methods (DIFF3F, DV-Matcher), the proposed method delivers superior accuracy at a fraction of the computational cost (71.5 vs. >1000 GFLOPs for DIFF3F; 1044 ms vs. >10000 ms inference time). Against the most recent unsupervised baselines (DiffCorr, AMIGO, DV-Matcher), the topology-aware propagation with codebook optimization consistently provides 5–15 percentage points of accuracy improvement on cross-dataset evaluations.

## Relation to Prior Work

This paper extends the unsupervised non-rigid point cloud correspondence line of work (DPC, SE-ORNet, HSTR, DiffCorr) by replacing the standard spatial-relation-based (KNN/Euclidean) feature aggregation with a topology-aware propagation strategy. It builds on Key-Grid [18] for semantic keypoint estimation and topology confidence matrices, adopts the cross-reconstruction training paradigm from DPC [21], and uses a rotation-equivariant backbone from EquiShape [40]. The key conceptual departure is that prior methods propagate features through spatially close but potentially non-physically connected regions, while this paper explicitly suppresses such connections via learned topology weights and a modified transformer, augmented by a vector quantization codebook for dataset-general feature representation.

## Why It Matters / Open Questions

The topology-aware propagation addresses a fundamental vulnerability in existing unsupervised correspondence methods—spatial aggregation introduces deformation-sensitive signals from non-physical connections—making it a principled improvement rather than an ad-hoc fix. The robustness analysis showing that even partially degraded topology estimation still outperforms no topology at all suggests the approach is forgiving of imperfect keypoint estimation, which is important given the unsupervised setting. Open questions include whether the method generalizes to shapes with genuinely different topology (e.g., genus changes), how it handles noisy or irregularly sampled point clouds, and whether the keypoint estimation bottleneck can be further improved with better skeleton or articulation-aware priors.

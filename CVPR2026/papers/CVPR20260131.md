## Problem

Existing efficiency methods for Large Vision-Language Models rely on visual token reduction or compression, which creates an information bottleneck that severely degrades performance on fine-grained, high-resolution tasks requiring detailed visual reasoning. No prior approach reduces inference cost while preserving full access to all visual tokens throughout the network.
![Teaser figure](../imgs/CVPR20260131/cropped_page1_idx1.webp)

## Input / Output

The model takes an RGB image (processed at 384×384 by a SigLIP-400M encoder, yielding 729 visual tokens) and a text question, and produces a text answer. Unusually, the computational cost is not fixed: a lightweight routing MLP appended after the question dynamically selects how many self-attention layers to execute per sample, so the same model operates at different FLOP budgets (up to 8.6× savings) depending on input complexity.

## Method

VISOR decouples text and vision processing within the LLM: most transformer layers operate solely on text tokens, while a small, uniformly distributed set of cross-attention layers (text as queries, static visual tokens as keys/values) injects visual context at selected points without modifying the visual representations. For tasks requiring fine-grained reasoning, a few additional self-attention layers are inserted to update and hierarchically refine the visual tokens, enabling subsequent cross-attention layers to access higher-level features. A single universal model is trained by randomly sampling from a set of viable self-attention configurations at each optimization step, making it robust across a range of computational budgets. At inference, a lightweight routing MLP (trained via offline pseudo-labeling that selects the cheapest configuration achieving ≥99% of full-model accuracy) dynamically allocates the number of self-attention layers per sample. The approach is orthogonal to token reduction and can be combined with methods like VisionZip for up to 35× FLOP savings.

## Results

VISOR achieves an average accuracy of 63.6 on easy tasks and 58.4 on hard tasks, while delivering 8.6× FLOP savings relative to the full LLaVA-OV baseline (61.5 easy / 57.1 hard). On hard, fine-grained benchmarks (DocVQA, ChartQA, OCR-Bench, InfoVQA), VISOR substantially outperforms all token-reduction baselines, e.g., 68.9 on DocVQA vs. 36.7 for VisionZip and 48.4 for HiRED. When combined with token reduction (VISOR-TR), the method reaches 18× FLOP savings with only a 0.6-point drop in hard-task accuracy (57.8). The universal model with adaptive routing matches or exceeds independently trained models at every tested computational budget (Table 4).

## Baselines & Comparisons

VISOR outperforms all token-reduction baselines on hard tasks by a wide margin: its 58.4 hard average exceeds VisionZip (32.9), VisPruner (35.1), HiRED (39.0), PyramidDrop (42.9), and SparseVLM (49.1) by 9–25 points, while also achieving higher FLOP savings (8.6× vs. 4.2–5.7×). On easy tasks, M³ (64.0) marginally edges out VISOR (63.6), but M³'s hard average (56.6) trails VISOR by 1.8 points, and M³ offers only 8.0× savings versus VISOR's 8.6×. Compared to the full LLaVA-OV baseline, VISOR improves hard-task accuracy by 1.3 points (58.4 vs. 57.1) while reducing FLOPs by 8.6×, demonstrating that sparse layer execution can actually surpass dense processing. The trained variant VisionZip† (59.3 easy / 43.1 hard) narrows the gap but still lags VISOR by 4.3 and 15.3 points on easy and hard averages respectively. VISOR-TR, which layers token packing on top of VISOR, achieves 18× FLOP savings with only a 0.6-point hard-task drop, confirming the orthogonality of the two efficiency strategies.

## Relation to Prior Work

VISOR departs from the dominant paradigm of efficient LVLM inference, which centers on visual token reduction (pruning, merging, or learned compression) to lower sequence length. Instead, it keeps all visual tokens intact and sparsifies the *layers* at which the LLM interacts with them, using a small set of cross-attention layers for text-to-image queries and a few self-attention layers for image-to-image refinement. The design is motivated by the observation (from Kaduri et al.) that text tokens attend to visual tokens only at a few critical layers, and the universal-model training strategy draws on the Once-for-All framework. The method is explicitly orthogonal to token reduction and can be stacked with it (VISOR-TR), positioning it as a complementary axis of efficiency rather than a replacement.

## Why It Matters / Open Questions

By sidestepping the information bottleneck inherent in token compression, VISOR offers a principled path to high-efficiency LVLM inference that preserves fine-grained visual detail, which is critical for document understanding, chart reading, and other high-resolution tasks where prior methods degrade sharply. The universal-model-plus-routing design enables per-sample adaptive computation without storing multiple checkpoints, a practical deployment advantage. Open questions include whether the layer-sparsification principle transfers to much larger backbones or different vision encoders, whether the offline pseudo-labeling for routing generalizes to unseen task distributions, and how the approach interacts with emerging long-context or multi-image LVLM settings where the visual token count grows further.

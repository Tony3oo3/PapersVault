## Problem

Existing aerial object-goal navigation methods rely on local observations or short-term history, lacking global scene understanding and long-term spatial memory needed for large-scale outdoor environments. Ground-based scene representations (volumetric maps, semantic maps) cannot be directly applied to aerial scenarios due to drastically larger spatial scales and altitude-dependent viewpoint variations, resulting in myopic decisions and redundant exploration.
![Teaser figure](../imgs/CVPR20263965/cropped_page0_idx1.webp)

## Input / Output

At each timestep the agent receives an RGB image and a depth map, combined with a natural language instruction describing the target object. The output is a discrete action from a 6-action space (Move Forward, Turn Left, Turn Right, Ascend, Descend, Stop), where forward movement translates 3 units, vertical movement adjusts altitude by 3 meters, and turning rotates 30 degrees. An episode is successful if the agent stops within 20 meters of the target, and the maximum planning range is set to 500 meters based on benchmark statistics.

## Method

OctMem-Agent constructs an Adaptive Octree Memory by backprojecting 2D visual patch features into 3D with positional embeddings, then applying distance-adaptive hierarchical voxelization (5m voxels for nearby regions, 25m voxels for distant regions) before integrating aggregated features into a global octree structure for scalable spatial indexing. An Instruction-Guided Memory Query module uses FiLM modulation to condition 144 learnable queries (128 scene + 16 exploration) on the language instruction, then routes them through a Q-Former where scene queries attend only to nearby memory voxels for target localization while exploration queries attend to distant voxels for frontier identification. The extracted memory tokens are concatenated with current visual patch features and text embeddings, fed into an OpenVLA-based VLM backbone (DINOv2+SigLIP vision encoder, LLaMA-2 7B) that predicts discrete navigation actions. The entire framework is trained end-to-end with supervised learning on trajectories generated via 3D A* pathfinding, using a batch size of 64 and learning rate of 2e-5 for 2 epochs.

## Results

On the UAV-ON benchmark, OctMem-Agent achieves 19.50% SR, 29.30% OSR, and 6.37% SPL overall, representing a 7.50% absolute improvement in SR over the strongest trained baseline (OpenFly at 12.00%) and an 8.00% improvement over Navid (11.50%). The method also achieves the highest SR across all object size categories (Small: 18.91%, Medium: 18.09%, Large: 23.60%). On unseen environments, OctMem-Agent maintains 17.57% SR and 28.59% OSR, outperforming all baselines and demonstrating robust generalization to novel objects and environments.

## Baselines & Comparisons

OctMem-Agent outperforms all four baseline categories on the UAV-ON benchmark. Against zero-shot methods, it surpasses CLIP-H by 13.40% in SR and 17.40% in OSR, and AOA-F by 12.20% in SR and 11.80% in OSR, indicating that learned memory representations substantially outperform purely VLM-driven decision-making. Among trained aerial VLN models, OctMem-Agent beats OpenFly by 7.50% in SR (19.50% vs. 12.00%) and 3.40% in OSR, and Navid by 8.00% in SR (19.50% vs. 11.50%) though Navid edges it slightly on SPL (6.44% vs. 6.37%). AerialVLN, adapted from a different aerial VLN setting, trails significantly at 3.90% SR. The consistent advantage across seen and unseen environments (Table 2: 22.72% vs. 12.29% SR on seen; 17.57% vs. 11.82% SR on unseen) suggests the octree memory provides transferable spatial knowledge rather than overfitting to training scenes.

## Relation to Prior Work

This paper extends the OpenVLA vision-language-action framework by augmenting it with a hierarchical 3D memory, departing from prior aerial ObjectNav methods (AOA, OpenFly) that rely solely on current-frame observations and short pose history. The memory architecture draws on the Q-Former from BLIP-2 and FiLM conditioning, but repurposes them for instruction-modulated spatial querying over an octree structure rather than image-text alignment. Conceptually, it bridges the gap between dense voxel maps (impractical at aerial scale) and sparse topological graphs (designed for indoor object-level reasoning) by introducing distance-adaptive hierarchical aggregation that preserves local detail while compactly encoding distant space.

## Why It Matters / Open Questions

The work addresses a genuine scalability bottleneck in aerial navigation: existing scene representations either grow cubically with scene extent (dense maps) or lose geometric fidelity at scale (sparse graphs). The octree memory with distance-adaptive voxelization offers a practical middle ground, and the 7.5% SR gain over the prior SOTA validates that long-term spatial memory is a meaningful factor in open-world aerial ObjectNav. However, absolute success rates remain low (~19.5% SR), and the method's reliance on accurate depth and pose estimation limits robustness in adverse outdoor conditions (low light, textureless regions, IMU drift), leaving open questions about multi-sensor fusion and deployment in truly unstructured environments.

## Problem

Existing curriculum learning and hard class mining methods for unsupervised domain adaptation under adverse weather rely on fixed, handcrafted difficulty metrics (e.g., prediction uncertainty) and static learning schedules, which cannot adapt to the model's evolving, high-dimensional training dynamics. This rigidity induces category bias and leads to underfitting on noise or overfitting on majority classes, particularly under compound challenges like non-uniform domain shift and exacerbated class imbalance in extreme weather.
![Teaser figure](../imgs/CVPR20262899/cropped_page0_idx0.webp)

## Input / Output

The method takes labeled source-domain RGB images (Cityscapes) and unlabeled target-domain RGB images (ACDC, Dark Zurich, etc.), processed as 1024×1024 random crops. Internally, the agent produces a dynamic ranking (permutation) of all semantic classes by informativeness at each training step, which drives a pixel-level binary mask to construct mixed-domain image-label pairs: pixels belonging to lower-ranked classes are taken from the source image/label, while pixels from higher-ranked classes are taken from the target image and the model's own pseudo-labels. The final output is a pixel-wise segmentation mask over the target domain.

## Method

HeuSCM reframes curriculum scheduling as a sequential decision problem solved by an autonomous RL-inspired agent with two core components. First, a High-dimensional Semantic State Extraction (HSSE) module encodes the segmentation model's per-class training statistics via a Gaussian Mixture VAE into a compact latent space, then a Semantic Key Feature Extraction Network (SKFEN) distills salient features using grouped depth-wise separable convolutions followed by channel-wise max/average pooling with residual fusion. Second, a Categorical α-Fairness for Policy Gradients (CαPG) objective replaces standard reward maximization with an α-fairness function over per-class value functions, where the fairness weight w_c(s) = V_c^π(s)^{-α} upweights underperforming classes; the reward itself combines transferability (cosine similarity of source-target class features) and discriminability (dissimilarity among target class features). The agent's policy network (ClassGen) outputs a ranked class list that directly controls the cross-domain mixed sampling mask, and the entire pipeline—GM-VAE encoder, SKFEN, and ClassGen—is jointly optimized via policy gradient with a reconstruction regularizer preserving the original state manifold structure.

## Results

On the ACDC test set (Cityscapes→ACDC), HeuSCM with the HRDA backbone achieves a state-of-the-art 72.9 mIoU, surpassing the previous best (ACSegFormer, 72.7) and CoDA (72.6). On the ACDC val set, the same configuration reaches 72.7 mIoU. For nighttime driving, HeuSCM (HRDA) attains 52.8 mIoU on Dark Zurich-val and 59.3 mIoU on Nighttime Driving, both outperforming InforMS by 0.3 mIoU. The Heuristic Class Sampling Policy (HCSP) also generalizes to synthetic-to-real segmentation, adding +0.2 mIoU to both IAST (52.4 vs 52.2) and HIAST (56.5 vs 56.3) on GTA5→Cityscapes.

## Baselines & Comparisons

HeuSCM consistently outperforms all baselines across every backbone and benchmark. On the ACDC test set with HRDA, it edges out ACSegFormer (72.7) and CoDA (72.6) by 0.2–0.3 mIoU, and surpasses Refign (72.1) and CompUDA (71.1) by 0.8–1.8 mIoU. With the DAFormer backbone, HeuSCM (65.7) beats Refign (65.5) and VBLC (64.2), while with DeepLab-v2 it achieves a substantial 8.2 mIoU gain over the next-best ATP (50.5). On Dark Zurich-val and Nighttime Driving, HeuSCM (HRDA) leads InforMS by a narrow 0.3 mIoU margin (52.8 vs 52.5; 59.3 vs 58.5). In the synthetic-to-real setting (GTA5→Cityscapes), the HCSP component adds a consistent +0.2 mIoU over both IAST and HIAST, confirming its plug-and-play generalization. No comparison shows HeuSCM losing to any baseline.

## Relation to Prior Work

This paper repurposes reinforcement learning concepts (state encoding, policy gradients, reward signals) for a problem previously addressed with handcrafted heuristics: class curriculum scheduling in UDA semantic segmentation. Prior work on curriculum learning (CoDA, AMSC, InforMS) and hard class mining relies on fixed difficulty metrics (uncertainty, confidence) and static easy-to-hard or hard-only schedules, while prior RL-for-UDA methods (Zhang et al., Dong et al., Usmani et al.) target feature alignment rather than class-level sampling. HeuSCM carves new ground by treating the class ranking as an action in a sequential decision problem, using a GM-VAE state encoder and an α-fairness policy gradient objective to autonomously discover a dynamic curriculum, rather than prescribing one.

## Why It Matters / Open Questions

The paradigm shift from 'designing' to 'learning' a curriculum is conceptually appealing and addresses a real limitation of fixed-schedule methods under compound domain shifts (fog + rain + class imbalance simultaneously). However, the empirical gains are modest (72.9 vs. 72.6–72.7 mIoU on ACDC test), and the added architectural complexity (GM-VAE, SKFEN, per-class critic networks, replay buffer) raises practical adoption questions. Open questions include whether the learned policy generalizes beyond driving scenes, how sensitive the unsupervised cosine-similarity reward is to backbone choice, and whether the α-fairness objective can be replaced by simpler balancing mechanisms without losing the dynamic scheduling benefit.

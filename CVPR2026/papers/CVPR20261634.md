## Problem

Existing reasoning-augmented VLA models generate a full, independent chain-of-thought at every timestep or at fixed intervals, causing two critical failures: (1) massive token redundancy when adjacent frames share nearly identical contexts, and (2) no temporal dependency between successive reasonings, which breaks planning coherence on long-horizon, memory-dependent tasks such as sequential button pressing. The paper addresses the absence of explicit temporal structure and persistent memory in VLA reasoning pipelines.

## Input / Output

The model consumes a single RGB observation and a natural-language instruction at each timestep. The visual encoder (DINOv2 + SigLIP) produces spatial and semantic visual tokens, which are jointly processed with tokenized text by a LLaMA-2-based multimodal transformer. At keyframes, the VLM emits a sparse set of hierarchical CoT tokens (task, plan, perception, subtask/move reasoning, subtask/move command, gripper position); at non-keyframes, no reasoning tokens are generated. The final output is a smooth action chunk of N_a 7-DoF vectors (Δx, Δβ, gripper) produced by iterative denoising in a Diffusion Transformer conditioned on a FiLM-fused cognition feature that integrates current perception with retrieved historical reasoning.

## Method

TRM-VLA introduces two coupled modules on top of the CogACT dual-system backbone (VLM as System 2, DiT as System 1). Keyframe-Triggered Reasoning (KTR) defines binary keyframe flags at three granularities—perception, subtask, and move—and segments each episode into early (high-level planning), middle (perception-anchored subtask decomposition), and late (low-level execution) stages, so that only the relevant subset of CoT tags is generated when a corresponding flag fires, reducing average token output from ~27 to ~4.3 per step. Granularity-adaptable Context Memory (GCM) maintains a dictionary-based buffer of past reasoning tokens with hierarchical lifetimes (high-level reasoning persists for the full episode, low-level reasoning is overwritten frequently); a learnable thinking query retrieves relevant entries via cross-attention, and the retrieved feature is fused with the current cognition token through a FiLM layer before conditioning the diffusion action expert. Training uses next-token prediction with causal attention for KTR and standard diffusion MSE for the action head, both supervised on embodied datasets annotated with multi-level temporal keyframes.

## Results

On the SIMPLER-Bridge benchmark, TRM-VLA achieves a 72.9% average success rate, surpassing the strongest baseline π₀ (69.2%) by +3.7% and CogACT-Base (51.3%) by +21.6%. On LIBERO-90, TRM-VLA reaches 94.8% success rate, outperforming CogACT-ECoT (92.1%) and CogACT-Base (88.4%). On four real-world tasks, TRM-VLA attains 69.0% average success rate while generating only 4.3 CoT tokens per step, a 6× reduction compared to ECoT (26.8 tokens) and CogACT-ECoT (26.3 tokens).

## Baselines & Comparisons

TRM-VLA outperforms all 11 baselines on the SIMPLER-Bridge benchmark, with the largest margin over CogACT-Base (+21.6% avg SR) and a clear lead over the strongest competitor π₀ (+3.7%). On LIBERO-90, TRM-VLA (94.8%) surpasses CogACT-ECoT (92.1%) by 2.7% and CogACT-Base (88.4%) by 6.4%, while also exceeding π₀-Fast (83.1%) and UniACT (73.0%). On real-world tasks, TRM-VLA (69.0% avg SR) dramatically outperforms CogACT-ECoT (44.0%) and ECoT (28.0%), with the most pronounced gain on the memory-dependent 'Push Buttons in Order' task (67% vs. 45% for CogACT-ECoT). A key differentiator is inference efficiency: TRM-VLA generates only 4.3 CoT tokens per step versus 26.8 for ECoT and 26.3 for CogACT-ECoT, a ~6× reduction, while simultaneously improving success rates. The ablation confirms both KTR and GCM are essential—removing either drops SIMPLER SR from 0.73 to 0.65 (GCM removed) or 0.54 (both removed).

## Relation to Prior Work

TRM-VLA builds directly on CogACT's dual-system architecture (VLM as System 2 for reasoning, Diffusion Transformer as System 1 for action execution) and departs from prior reasoning-augmented VLA methods (ECoT, CoT-VLA, InstructVLA) that generate full, independent chain-of-thought at every timestep or fixed intervals. The key conceptual departure is treating reasoning as a temporally structured, sparse process: hierarchical CoT is triggered only at detected keyframes, and a dynamic memory buffer with cross-attention retrieval maintains inter-frame coherence. This positions the work at the intersection of embodied CoT reasoning and temporal memory, addressing a gap the authors identify as the 'implicit Markovian assumption' in frame-wise reasoning approaches.

## Why It Matters / Open Questions

The 4× reduction in CoT token generation while simultaneously improving success rates (72.9% on SIMPLER, 94.8% on LIBERO-90) is practically significant for real-time robotic deployment, where inference latency is a hard constraint. The memory-dependent 'Push Buttons in Order' task (67% vs. 45% for CogACT-ECoT) provides a clean demonstration that explicit temporal memory resolves a failure mode that frame-wise reasoning fundamentally cannot. Open questions include whether the learned keyframe detection generalizes to entirely unseen task structures without re-annotation, how the memory buffer scales to very long episodes, and whether the approach transfers to multi-robot or bimanual settings where temporal dependencies are more complex.

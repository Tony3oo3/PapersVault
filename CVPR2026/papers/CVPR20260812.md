## Problem

Existing data-driven dexterous grasp generation methods rely on statistical learning from large-scale datasets while largely ignoring the inherent geometric priors of objects (shape, size, pose), resulting in poor data efficiency and physically implausible grasps with severe finger-object penetration. This paper asks whether explicitly encoding object geometry through equivariant representations can improve both data efficiency and physical plausibility without requiring massive training sets.

## Input / Output

The method takes a 3D point cloud of the target object (X ∈ R^{N×3}) and a language prompt (e.g., 'cup handle') as input. The point cloud is processed by a SIM(3)-equivariant VN-Transformer encoder, while the language prompt is fed to PointSO to extract explicit interaction direction vectors. The output is a set of diverse hand poses for the ShadowHand (K=24 DoF), each specified as a root rotation R∈SO(3), root translation t∈R³, and finger joint angles θ∈R²⁴, generated in a decoupled two-stage process: rotation first on the SO(3) manifold, then translation and joints in Euclidean space.

## Method

GeoDexGrasp decomposes dexterous grasp generation into three geometry-guided stages. First, a SIM(3)-equivariant VN-Transformer encoder is pretrained via self-supervised disentanglement (pose regression from equivariant features + shape reconstruction from invariant features, optimized with bidirectional Chamfer distance) to extract four interpretable representations: pose (Θ_e), shape (Θ_i), size (Θ_s), and interaction direction (Θ_d from PointSO). Second, root rotation is generated on the SO(3) manifold using an IPDF model conditioned on the fused pose and interaction-direction representations, decoupling manifold-based rotation from Euclidean-space joint generation. Third, a denoising diffusion model generates finger joint angles and root translation in a rotation-invariant frame, conditioned on shape features modulated by scale via Hadamard product. This space-decoupled, geometry-conditioned formulation achieves 40% lower penetration depth and comparable success rate to DexGraspAnything with only 28.7M parameters (vs. 159.7M).

## Results

GeoDexGrasp achieves the best average penetration depth of 13.6 mm across five datasets (GRAB, RealDex, MultiDex, UniDexGrasp, DexGraspNet), reducing physical penetration by ~40% compared to the previous SOTA DexGraspAnything (21.2 mm). On average success rate, GeoDexGrasp reaches 60.1%, slightly surpassing DexGraspAnything (58.5%) while using only 28.7M parameters versus 159.7M (less than 1/5). The method also demonstrates superior data efficiency, maintaining high success rates when training data is reduced to 25% of the original, and better size generalization on OOD object scales.

## Baselines & Comparisons

GeoDexGrasp decisively outperforms all seven baselines on physical plausibility (penetration depth), achieving 13.6 mm average vs. the next-best DexGraspAnything at 21.2 mm — a 40% reduction. On success rate, GeoDexGrasp (60.1% avg) edges out DexGraspAnything (58.5%) and substantially surpasses UGG (44.7%), D(R,O) (49.7%), GenDexGrasp (39.7%), SceneDiffuser (37.1%), UniDexGrasp (25.4%), and GraspTTA (19.5%). The one dataset where GeoDexGrasp trails DexGraspAnything is RealDex (38.3% vs. 44.8% SR), though it still leads on penetration there (17.6 vs. 27.7 mm). In the size generalization experiment (Table 2), GeoDexGrasp outperforms DexGraspAnything, D(R,O), and GenDexGrasp on all three primitive shapes (Cube, Cylinder, Torus) in OOD size settings, but all methods struggle on the topologically complex Toy Horse. The ablation (Table 3) confirms that the decoupling strategy, geometric representations, and disentanglement pretraining each contribute incrementally, with the full pipeline reaching 67.5% SR and 15.5 mm PP on DexGRAB versus 41.8% SR and 40.7 mm PP without any of these components.

## Relation to Prior Work

This paper extends the SIM(3)-equivariant network paradigm (EquiAct, EquiBot, VN-Transformer) from visual manipulation policies and parallel-gripper grasping to the high-DoF dexterous grasping setting, where prior generative methods (DexGraspAnything, UGG, SceneDiffuser, UniDexGrasp) rely almost entirely on statistical learning from large-scale datasets without explicit geometric inductive biases. It departs from the monolithic generation approach by decomposing dexterous grasp synthesis into a two-stage, space-decoupled pipeline: an IPDF-based probability model on the SO(3) manifold for root rotation conditioned on pose and interaction-direction features, followed by a diffusion model in Euclidean space for finger joints and translation conditioned on shape and size. The self-supervised disentanglement pretraining strategy, which aligns equivariant and invariant latent features with pose and shape semantics via reconstruction, is a novel architectural choice not previously applied in the dexterous grasping literature.

## Why It Matters / Open Questions

The 40% reduction in penetration depth across five benchmarks while using fewer than one-fifth the parameters of DexGraspAnything makes geometry-aware generation a practically attractive alternative for resource-constrained deployment, and the demonstrated size generalization (grasping unseen scales of the same shape) addresses a real-world requirement that pure data-driven methods handle poorly. However, the paper itself identifies a significant open challenge: scale-induced contact-pattern reconfiguration on topologically complex objects (e.g., Toy Horse) remains unsolved, where all methods including GeoDexGrasp degrade substantially. Future work on combining global shape with local contact features, and on better modeling the highly nonlinear mapping from scale to joint configuration, will be needed to close this gap.

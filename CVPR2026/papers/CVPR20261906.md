## Problem

Existing black-box domain adaptation (BBDA) methods are designed for classification or segmentation and rely on global image-level operations (e.g., adaptive label smoothing) that are fundamentally misaligned with object detection's need for region-specific localization and category prediction. No prior BBDA method provides a well-established solution for the joint learning of bounding box regression and local classification under the constraint that neither source data nor source model is accessible.
![Teaser figure](../imgs/CVPR20261906/cropped_page1_idx0.webp)

## Input / Output

The method consumes unlabeled target-domain RGB images and a set of static noisy hard predictions (bounding boxes with per-class softmax scores) downloaded once from a black-box cloud API; no source data, source model weights, or iterative API queries are permitted. The output is a domain-adapted Faster R-CNN detector (ResNet-50 backbone) that produces bounding boxes with class labels on the target domain. A key constraint is that the API predictions remain fixed throughout training, so all adaptation must occur within the target model parameters using only these one-shot noisy labels.

## Method

RDKC is built on a Mean-Teacher framework where the teacher is first distilled with noisy API predictions and then frozen, while the student is trained with a joint loss. Memory Retention (MR) partitions each teacher proposal into high-reliability (HRP) or low-reliability (LRP) type based on a confidence threshold and IoU comparison, then applies asymmetric score optimization: for HRP proposals it retains only the top-1 class score and proportionally suppresses the rest to filter noise, while for LRP proposals it preserves the full score distribution to prevent catastrophic forgetting; the student is supervised via KL divergence against these optimized scores. Scene Compression (SC) computes a per-proposal contrastive weight from the cosine similarity between student and teacher prediction vectors, which adaptively up-weights high-discrepancy HRP regions (forcing the student to align with reliable near-view cues) and down-weights noisy LRP regions, thereby guiding far-view localization from near-view evidence. The final loss combines the standard detection task loss with the SC-weighted MR loss, and the teacher is updated via EMA of the student parameters.

## Results

On the primary benchmark Cityscapes → Foggy-Cityscapes, RDKC achieves 40.7 mAP under the BBDA setting, outperforming the previous best BBDA method BiMem (38.4) by +2.3 and DINE (36.5) by +4.2. On Sim10K → Cityscapes, RDKC reaches 49.1 AP for the Car class, surpassing DINE (37.9) by +11.2; on KITTI → Cityscapes it reaches 50.4 AP, beating DINE (39.8) by +10.6. On Pascal-VOC → Watercolor, RDKC attains 53.7 mAP, exceeding DINE (45.6) by +8.1 and the best SFDA method LPLD (55.2) is only marginally higher but operates under a less restrictive setting. RDKC also outperforms the source-only baseline (25.2 mAP) by +15.5 on Cityscapes → Foggy-Cityscapes.

## Baselines & Comparisons

RDKC outperforms all three native BBDA baselines across every benchmark: on Cityscapes → Foggy-Cityscapes it beats BiMem (38.4) by +2.3 mAP, DINE (36.5) by +4.2, and SEAL (34.3) by +6.4; on Pascal-VOC → Watercolor the margins widen to +8.5, +8.1, and +7.6 respectively. Against the strongest SFDA methods adapted to the BBDA setting (IRG† at 33.1 and LPLD† at 32.6 mAP), RDKC gains +7.6 and +8.1 mAP, confirming that the static nature of downloaded predictions severely limits source-free techniques under black-box constraints. The cross-method experiments (IRG†+MR at 38.3, LPLD†+MR at 39.9) show that the Memory Retention module alone recovers most of the performance gap, while the full RDKC (MR+SC) adds a further +0.8 to +2.3 mAP. On the Car-class AP metric, RDKC leads DINE by +11.2 (Sim10K→Cityscapes) and +10.6 (KITTI→Cityscapes), and surpasses the best SFDA method LPLD (49.4 / 51.3) by −0.3 / −0.9, indicating near-parity with the less restrictive SFDA setting while operating under stricter privacy constraints. UDA methods (PT at 42.7, MeGA-CDA at 41.8) remain slightly ahead on Cityscapes→Foggy but require full source data access, which BBDA explicitly forbids.

## Relation to Prior Work

This paper extends the BBDA lineage initiated by DINE (Liang et al., CVPR 2022) and SEAL (Xia et al., AAAI 2024), which were designed for image classification using global label smoothing and cumulative predictions. The key departure is adapting BBDA to object detection, where prior methods' global-to-category optimization is incompatible with detection's region-specific, joint localization-and-classification mechanism. RDKC builds on the Mean-Teacher framework (Tarvainen & Valpola, 2017) for teacher-student collaboration but introduces Memory Retention as a detection-specific loss that partitions proposals by reliability and reallocates contrastive learning per region, and Scene Compression as a near/far-view contrastive module for bounding box refinement. The lifelong learning framing (active forgetting, selective stabilization, collaborative integration) is borrowed from biological behavioral science literature and applied here as a design principle rather than a formal model.

## Why It Matters / Open Questions

This is the first method to properly address BBDA for object detection with dedicated mechanisms for localization, filling a gap where prior BBDA work was limited to classification or a single adapted method (BiMem). The cross-method experiments demonstrating that MR as a plug-and-play loss recovers significant performance for existing SFDA methods (IRG, LPLD) under the BBDA constraint validate the paper's core diagnosis that static noisy predictions are the primary bottleneck. Limitations include evaluation only with Faster R-CNN + ResNet-50 on a single GPU, and the lifelong learning analogy, while motivating, is not formally grounded in the optimization. Open questions include whether the approach generalizes to transformer-based detectors, multi-scale feature pyramids, or more complex domain shifts beyond the four tested scenarios.

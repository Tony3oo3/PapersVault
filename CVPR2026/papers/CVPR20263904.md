## Problem

Existing generative video codecs encode frames into dense 2D latent grids with rigid spatial structure, which preserves intra-frame redundancy (adjacent patches remain highly similar) and necessitates a higher bitrate. Additionally, the 2D grid is less effective for modeling long-term temporal correlations in a compact, semantically coherent manner, as it hinders aggregation of common content across frames. The paper asks whether replacing the 2D latent grid with a compact 1D token representation can simultaneously reduce spatial and temporal redundancy.
![Teaser figure](../imgs/CVPR20263904/cropped_page0_idx1.webp)

## Input / Output

The method takes RGB video frames of resolution H×W, embeds them into 16×16 patches, and compresses each frame into only N×32 learnable 1D latent tokens (where N = (h·w)/(16·16), far fewer than the h·w patches), rather than one token per patch. The compressed output is an arithmetic-coded bitstream, and reconstruction produces the decoded frame via a decoder that iteratively extracts information from the 1D tokens and context. All stages (encoding, entropy coding, decoding) are conditioned on a dual context model combining short-term features from the preceding frame and long-term 1D memory.

## Method

GVC1D encodes each frame into a small set of 1D latent tokens using a ViT-based encoder with cascaded local (windowed) and global transformer layers, where learnable 1D tokens aggregate semantic information from 2D patch embeddings without enforcing fixed spatial correspondences. A 1D memory module recurrently updates a fixed-size memory state using the compact 1D tokens via a simple Transformer, providing semantically rich long-term context at low computational cost while mitigating information forgetting. An autoregressive Transformer entropy model performs sequential probability estimation over the quantized 1D tokens for arithmetic coding, exploiting inter-token dependencies to further reduce bitrate. The decoder mirrors the encoder architecture, using learnable mask tokens that iteratively extract information from the decoded 1D tokens and context to reconstruct the frame. The key insight is that removing the rigid 2D spatial structure decouples token count from spatial resolution, enabling adaptive attention to semantic regions and natural token reduction, while the compact 1D representation makes long-term memory management both semantically effective and computationally cheap.

## Results

GVC1D achieves BD-Rate reductions of 60.4% (LPIPS) and 68.8% (DISTS) on HEVC-B, 66.0% (LPIPS) and 47.9% (DISTS) on UVG, and 62.1% (LPIPS) and 61.5% (DISTS) on MCL-JCV, all relative to the GLC-Video anchor. On distortion metrics, it reduces bitrate by 53.8% (PSNR) and 45.1% (MS-SSIM) on HEVC-B, 62.5% (PSNR) and 45.8% (MS-SSIM) on UVG, and 54.7% (PSNR) and 33.0% (MS-SSIM) on MCL-JCV. All evaluations use 96 frames in RGB colorspace with intra-period = -1 (low-delay setting).

## Baselines & Comparisons

The primary quantitative anchor is GLC-Video [29], the strongest prior perceptual generative codec; GVC1D reduces its bitrate by 47.9–68.8% across all three datasets and both perceptual metrics, with the largest gain (68.8%) on HEVC-B under DISTS. Against PSNR-oriented neural codecs (DCVC-FM [22], DCVCRT [16]) and traditional codecs (HM [2], VTM [3], ECM [1]), GVC1D dominates the rate-distortion curves in Figure 6 on perceptual metrics, though the paper does not report explicit BD-Rate numbers for these baselines in the main table. Qualitatively (Fig. 7), DCVC-FM and ECM-5.0 produce blurred regions at low bitrates (e.g., railing, basket patterns), while GLC-Video introduces unrealistic facial features and clothing textures; GVC1D yields fewer artifacts, more accurate colors, and finer details at comparable or lower bitrates. In terms of coding speed, GVC1D (0.262 s enc / 0.207 s dec at 1080p) is slightly slower than DCVC-FM (0.183/0.190 s) but comparable to GLC-Video (0.290/0.183 s), with encoding actually slightly faster than GLC-Video.

## Relation to Prior Work

GVC1D departs from the dominant paradigm in both traditional and neural video codecs, which encode frames into dense 2D latent grids with rigid spatial correspondences. It repurposes the 1D tokenization concept from image generation (TiTok, TA-TiTok) and image compression (DLF) to the video domain, replacing the 2D latent bottleneck with a small set of unstructured, learnable 1D tokens that aggregate information from 2D patch embeddings via a ViT. For temporal modeling, it extends the conditional coding framework of the DCVC series and the long-term context idea of DCVC-LCG, but manages memory using only a few 1D tokens rather than dense 2D features, enabling a simple full-Transformer memory at low cost.

## Why It Matters / Open Questions

The 60–69% bitrate reduction over the strongest perceptual baseline (GLC-Video) across three datasets and both LPIPS and DISTS is a substantial leap that challenges the field's assumption that preserving 2D spatial structure in the latent space is necessary for video compression. The attention-map visualizations showing tokens consistently tracking semantic regions across frames provide intuitive evidence for why the 1D design works. However, the method currently targets only lossy compression at low bitrates (32 tokens per frame), and the authors explicitly note that extending toward lossless compression remains open. A key open question is whether the 1D-token paradigm generalizes to higher resolutions, longer sequences, or multi-stream settings without further architectural changes.

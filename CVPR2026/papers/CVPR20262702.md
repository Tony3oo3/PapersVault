## Problem

Streaming dense video captioning requires real-time caption generation while deciding when to remain silent, but existing approaches either rely on complex external memory mechanisms that underutilize LMMs' inherent long-context capabilities, or employ threshold-based caption triggering that suffers from a Threshold-Gated Discrepancy (TGD): a training-inference mismatch where data imbalance causes models to over-predict silence, requiring video-specific thresholds with extremely narrow effective ranges that are impractical to calibrate.

## Input / Output

The Oracle agent consumes sparse video frames at 1 FPS and processes them at an accelerated rate so its current time t_c(O) leads the Listener's current time t_c(L), enabling it to detect event boundaries before the Listener reaches them. The Listener agent consumes denser frames at 2 FPS through a SigLIP vision encoder and a two-layer MLP projector, producing a single autoregressive token stream where each position yields either a text token (caption or acknowledgment) or a special Silence Token. All processing occurs in one continuous inference pass without external memory, with the Oracle injecting prompt messages into the Listener's context at detected boundary timestamps.

## Method

Takusen decouples temporal localization from caption generation via an asynchronous two-agent design: a lightweight SMM (CM² or VideoLLaMA3-2b) acts as an Oracle that detects event start/end boundaries from sparse frames and sends template-based prompt messages, while an LMM (LLaMA-3 8B with SigLIP) acts as a Listener that generates captions only when prompted by the Oracle, otherwise predicting silence tokens. Training uses a hybrid cross-entropy loss combining text loss at boundary positions and silence loss at non-event positions, directly aligning training with inference and eliminating the TGD. To handle Oracle boundary instabilities (excessive, insufficient, or incomplete boundary pairs), uniformly distributed Fixed Decoding Points (FDPs) are injected at regular intervals during inference, prompting the Listener to generate supplementary captions. The entire system is trained via LoRA fine-tuning on the LLM and projector only, freezing both vision encoders, completing in 16–20 hours on a single A6000 GPU.

## Results

On ActivityNet Captions (streaming setting), Takusen achieves a CIDEr of 43.7, SODA_c of 7.5, METEOR of 9.7, and F1 of 54.0, outperforming the best prior streaming method (Streaming Vid2Seq, CIDEr 37.8) by +5.9 and Streaming GIT (CIDEr 41.2) by +2.5. On YouCook2, Takusen reaches CIDEr 40.7 and F1 37.0, surpassing Streaming Vid2Seq (CIDEr 32.9) by +7.8 and Streaming GIT (CIDEr 15.4) by +25.3. Notably, Takusen also exceeds the best non-streaming baselines (CM² at CIDEr 33.1 on AN; TRACE-uni at CIDEr 35.5 on YC2) despite operating under real-time streaming constraints.

## Baselines & Comparisons

Takusen outperforms both prior streaming baselines across all reported metrics on both datasets. On ActivityNet Captions, it beats Streaming Vid2Seq [84] by +5.9 CIDEr (43.7 vs. 37.8) and Streaming GIT [84] by +2.5 CIDEr (43.7 vs. 41.2), while also achieving the best SODA_c (7.5) and F1 (54.0). On YouCook2, the margin is even larger: +7.8 CIDEr over Streaming Vid2Seq (40.7 vs. 32.9) and +25.3 over Streaming GIT (40.7 vs. 15.4). Against non-streaming methods, Takusen surpasses CM² [22] (CIDEr 33.1 on AN, 31.7 on YC2) and TRACE-uni [13] (CIDEr 29.2 on AN, 35.5 on YC2) despite the added streaming constraint. In the Video-LLM comparison (Table 2), Takusen's CIDEr of 43.7 substantially exceeds VideoLLaMA3 [76] (26.8), TRACE-uni [13] (29.2), VTG-LLM [12] (20.7), and AVicuna [55] (22.5), with an F1 advantage of +8.8 over the closest competitor AVicuna (54.0 vs. 45.2). The ablation further shows that removing the Oracle drops CIDEr to 30.4 (best FDP) or 18.3 (average FDP), and removing FDPs drops it to 12.3, confirming that both components are essential for the reported gains.

## Relation to Prior Work

This paper departs from the dominant paradigm in streaming dense video captioning, which relies on complex external memory mechanisms (CM², MovieChat) or threshold-based caption triggering (Streaming Vid2Seq, Streaming GIT). Instead, it repurposes the inherent long-context capabilities of LMMs as the memory substrate and introduces an asynchronous two-agent architecture (a small Oracle for temporal localization and a large Listener for caption generation) that replaces threshold decisions with explicit inter-agent signaling. The silence-token formulation and hybrid loss draw on VideoLLM-Online's streaming LLM training, while the parameter-efficient fine-tuning (LoRA + frozen encoders) follows standard LMM adaptation practice. Conceptually, the paper carves new ground by identifying the Threshold-Gated Discrepancy (TGD) as a distinct training-inference mismatch specific to streaming captioning, rather than treating it as a generic class-imbalance issue.

## Why It Matters / Open Questions

The TGD diagnosis is a useful and previously unarticulated failure mode for anyone building threshold-gated streaming systems, and the two-agent solution offers a clean architectural escape that avoids both external memory overhead and fragile threshold tuning. However, the boundary-aware ablation (CIDEr 107.5 vs. 43.7) reveals that Oracle boundary prediction is the dominant bottleneck, leaving substantial headroom that the current SMM-based Oracle does not exploit. Open questions include whether the framework scales to much longer streams (beyond the ~2-minute ActivityNet clips), whether the Oracle-Listener split generalizes to other streaming tasks (e.g., action detection, video QA), and whether a single unified model could eventually subsume both roles as LMMs improve at fine-grained temporal grounding.

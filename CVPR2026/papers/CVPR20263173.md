## Problem

Most VLA models process each visual frame independently, implicitly treating robot manipulation as a fully observable MDP. This history-agnostic design discards critical temporal context—occluded information, internal dynamics, and the effects of past actions—forcing visual attention to re-evaluate from scratch at every step and leaving the visual system passive rather than actively focused on task-relevant regions.
![Teaser figure](../imgs/CVPR20263173/cropped_page0_idx0.webp)

## Input / Output

At each timestep the model consumes a single RGB image (encoded by a dual-branch DINOv2 + SigLIP vision encoder into L_I visual tokens), a natural-language instruction (tokenized into L_S tokens), and a recurrent state vector r^{t-1} carried over from the previous timestep's hidden states. The output is a parallel-decoded action chunk of shape L_c × D (e.g., 7-DoF end-effector poses plus gripper), produced simultaneously via learnable action placeholder embeddings rather than autoregressive token-by-token generation.

## Method

AVA-VLA reformulates VLA policy learning as a POMDP, introducing a recurrent state r^{t-1}—computed by an MLP over the previous timestep's final-layer hidden states—as a neural approximation of the belief state. The core Active Visual Attention (AVA) module first applies FiLM conditioning to modulate visual tokens by the language instruction, then performs cross-attention with the recurrent state as key/value to produce per-token soft importance scores via an FFN + softmax head. These scores construct a soft attention mask that multiplicatively reweights the attention matrices at every layer of the LLaMA2-7B backbone, dynamically suppressing irrelevant visual regions based on execution history. The recurrent state also initializes the action placeholder embeddings to preserve temporal context. Training uses truncated backpropagation through time over 4-step horizons with an L2 regularizer on the mean soft-weight value to prevent attention dispersion.

## Results

On the LIBERO benchmark, AVA-VLA achieves 98.0% average success rate (one policy for all 4 suites) and 98.2% (one policy per suite), outperforming the strongest baselines OpenVLA-OFT (96.8%/97.1%) and RIPT-VLA (97.5%). On the CALVIN ABC→D zero-shot generalization benchmark, AVA-VLA achieves an average completed task length of 4.65, surpassing FLOWER (4.53) and UnifiedVLA (4.41). On real-world Mobile ALOHA dual-arm tasks, AVA-VLA attains the highest average success rate across four manipulation tasks compared to UniVLA and OpenVLA-OFT.

## Baselines & Comparisons

AVA-VLA outperforms all 16 baselines on both LIBERO and CALVIN. On LIBERO (multi-task), it leads OpenVLA-OFT by 1.2% average SR (98.0 vs. 96.8) and UnifiedVLA by 2.5%, with the largest margin on LIBERO-Long (97.6 vs. 95.3 for OpenVLA-OFT, 94.0 for UnifiedVLA). In the single-task setting, it surpasses the closest competitor RIPT-VLA by 0.7% average (98.2 vs. 97.5), primarily driven by a 2.4-point gain on LIBERO-Long (96.2 vs. 93.8). On CALVIN ABC→D, AVA-VLA achieves 4.65 average length, beating FLOWER (4.53) and UnifiedVLA (4.41), with consistent per-task advantages (e.g., 94.1% on task 3 vs. 90.7% for FLOWER). On real-world Mobile ALOHA, AVA-VLA achieves the highest average success rate across Pick-and-Place, Sequenced Instruction, Folding, and Dexterous Action tasks compared to UniVLA and OpenVLA-OFT. The ablation confirms both the AVA module and state-based initialization contribute independently, with their combination yielding the best results.

## Relation to Prior Work

This paper builds directly on OpenVLA-OFT's parallel-decoding VLA architecture but departs from the standard MDP formulation that treats each visual frame independently. It reformulates VLA policy learning as a POMDP, introducing a recurrent state (a neural approximation of the belief state) derived from the previous timestep's hidden states, and an Active Visual Attention module that uses this state to dynamically reweight visual tokens. Conceptually, it bridges the gap between sequential VLM processing (e.g., persistent-state video understanding) and active robotic decision-making, while distinguishing itself from prior visual token pruning work by using the computed importance scores for attention modulation rather than token removal.

## Why It Matters / Open Questions

The POMDP reformulation provides a principled theoretical justification for why history-agnostic VLA models are suboptimal, and the recurrent-state mechanism offers a lightweight, architecture-agnostic way to inject temporal context without requiring multi-frame inputs or explicit memory modules. The AVA module's soft weights naturally enable visual token pruning (70% reduction with <1% performance drop), suggesting a path toward more efficient VLA inference. Open questions include whether the truncated BPTT horizon (T=4) limits long-horizon dependency capture, how the recurrent state behaves under distribution shift in deployment, and whether the approach generalizes beyond the OpenVLA-OFT parallel-decoding paradigm to autoregressive or diffusion-based decoders.

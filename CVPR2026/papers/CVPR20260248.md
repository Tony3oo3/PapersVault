## Problem

Multi-reference video generation currently requires either architectural modifications to pre-trained video models or large-scale fine-tuning on task-specific datasets, both of which degrade the broad generative priors learned during pre-training and limit generalization beyond narrow domains like human-object interaction. The paper asks whether pre-trained video generation models can incorporate multiple reference subjects without any architectural changes or large-scale retraining.
![Teaser figure](../imgs/CVPR20260248/cropped_page0_idx0.webp)

## Input / Output

The method takes a single composite image (foreground elements arranged on the left, background on the right, auto-resized to fit) and a text prompt with a unique transition phrase appended (e.g., 'ad23r2 the camera view suddenly changes'). The output is a video of F frames (e.g., 81 for Wan2.2) where the first F_c frames (e.g., 4, matching the model's temporal compression ratio) contain the mixed-subject conditioning frame and the remaining F_g frames (e.g., 77) constitute the clean customized video; users simply discard the first F_c frames post-generation. Unlike prior multi-reference methods that accept up to 3 separate reference inputs, FFGo has no architectural limit on the number of subjects packed into the first frame, though practical identity preservation degrades beyond ~4 subjects plus a scene.

## Method

The core insight is that pre-trained video generation models implicitly treat the first frame as a conceptual memory buffer that stores visual entities for later reuse, enabling subject mixing through scene transitions without any architectural change. The pipeline has three stages: (1) VLM-assisted dataset curation using Gemini-2.5-Pro to extract individual elements from source videos, generate clean backgrounds, and produce interaction-focused captions, yielding 50 paired (composite image, prompt) training examples; (2) few-shot LoRA adaptation (rank 128) on the base I2V model (Wan2.2-I2V-A14B) with a unique transition phrase, trained for 5 hours on 2 H200 GPUs per denoising transformer, which teaches the model to select visual concepts from the first frame and execute a coherent scene transition; (3) clean inference by discarding the first F_c temporal-compression frames. The approach preserves the base model's pre-trained generative priors because it invokes rather than overwrites innate capabilities, and requires no architectural modification or large-scale training data.

## Results

In a user study with 200 annotations from 40 users (1–5 scale), FFGo achieves an Overall Quality score of 4.28, Object Identity of 4.53, and Scene Identity of 4.58, with an average rank of 1.21 and 81.2% of users selecting it as their top choice. These results are obtained using only 50 LoRA training examples on the Wan2.2-I2V-A14B base model, without any architectural modifications. The method outperforms all baselines on every metric, transforming the base model from the lowest-performing entry (Overall Quality 2.09) to the clear winner.

## Baselines & Comparisons

FFGo is compared against three Wan-architecture baselines: the unmodified Wan2.2-I2V-A14B, VACE (ICCV 2025), and SkyReels-A2 (arXiv 2025). FFGo decisively outperforms all three on every metric in the user study, with the largest margin over the base model (Overall Quality 4.28 vs. 2.09) and a substantial lead over VACE (4.28 vs. 3.00) and SkyReels-A2 (4.28 vs. 2.34). A key structural advantage is that VACE and SkyReels-A2 are architecturally limited to at most three reference inputs (object1, object2, scene), causing them to fail on five-reference scenarios, whereas FFGo has no such constraint since multi-reference capability emerges from the first-frame-as-memory-buffer mechanism rather than architectural modification. Additionally, while VACE and SkyReels-A2 are trained on millions of task-specific videos, FFGo requires only 50 LoRA examples, yet still generalizes better across diverse scenarios (robotic manipulation, driving, aerial, underwater, multi-product, filmmaking). The paper also notes that FFGo preserves the base model's pre-trained generative priors, as evidenced by close agreement with base-model outputs in rare cases where the base model already succeeds.

## Relation to Prior Work

This paper departs from the dominant paradigm in multi-reference video generation (VACE, SkyReels-A2), which modifies model architectures to accept multiple reference inputs and trains on millions of task-specific samples. Instead, it builds on the broader observation that pre-trained generative models harbor under-explored innate abilities (e.g., grid-aligned generation via few-shot LoRA in [12], frame-level perception in [36]), and specifically identifies the first frame of video diffusion models as a latent 'conceptual memory buffer' that can store and fuse multiple visual entities. The method is anchored on Wan2.2 as the base I2V model, using a minimal LoRA adapter (rank 128, 20–50 examples) plus a unique transition phrase to invoke this ability, with VLMs (Gemini-2.5-Pro) and SAM 2 handling data curation and element extraction.

## Why It Matters / Open Questions

The practical impact is significant: a lightweight add-on transforms a general-purpose I2V model into a state-of-the-art video customization system without architectural changes or large-scale fine-tuning, preserving the base model's generative priors that task-specific fine-tuning typically erodes. Key limitations include degradation beyond ~5 reference subjects (resolution per subject drops) and difficulty in selective text-prompt control over individual objects as reference count grows. Open questions include whether the first-frame-as-buffer mechanism generalizes to other video architectures (e.g., autoregressive or non-DiT backbones), whether multiple start frames could extend the memory capacity, and whether the 20–50 example regime is truly sufficient or whether the curated data quality (human-annotated, VLM-assisted) is the critical factor rather than the count alone.

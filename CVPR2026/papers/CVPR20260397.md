## Problem

Existing datasets and benchmarks for unified multimodal models treat each image edit as an isolated single-turn instruction, failing to capture the multi-turn, context-dependent iterative workflows that characterize real-world image creation (e.g., removing an object in one turn and restoring it in a later turn). No prior resource provides both a large-scale training set with temporal dependencies across turns and a benchmark that evaluates whether models can maintain visual memory and reason over prior context during interleaved comprehension and generation.
![Teaser figure](../imgs/CVPR20260397/cropped_page1_idx1.webp)

## Input / Output

Each instance provides a text prompt, one or more initial RGB images, and a multi-turn dialogue history where images and instructions alternate across turns (averaging 3.8 turns and >5 images per instance). The model must produce edited or generated images at each turn while recalling visual elements (objects, layouts, styles) from earlier turns. Evaluation uses a hybrid VLM judge that scores against both a reference ground-truth image and the original image paired with the editing instruction, applying four metrics: Key Point Correctness, Visual Consistency, Image Quality, and (for comprehension tasks) Accuracy.

## Method

WEAVE comprises two components. WEAVE-100k is constructed via four generation pathways—multi-image fusion, remove-then-back (delete then restore objects to force visual recall), derivative imagination/comparison, and sequential narrative procedures—followed by multi-round filtering to ensure accuracy. WEAVEBench is a 100-item, 480-image human-annotated benchmark spanning 16 task categories across science, creation, logic, and games, with a hybrid VLM-judge framework that jointly leverages reference images and original-image+instruction pairs. The empirical study fine-tunes the 14B Bagel UMM on WEAVE-100k using supervised learning, demonstrating 9.8% gains on MMMU, 4.8% on GEditBench, ~50% on RISEBench, and a 42.5% improvement on WEAVEBench itself, while also showing the emergence of visual-memory capabilities (e.g., correctly reinserting previously removed objects) that the base model lacks.

## Results

On WEAVEBench, the best proprietary UMM (Nano Banana, full in-context) achieves 0.767 average across Science, Creation, Logic, and Game domains, while the best open-source Edit model (FLUX.1 Kontext) reaches 0.689. Training Bagel on WEAVE-100k yields a 42.5% improvement on WEAVEBench (0.446→0.640), a 9.8% gain on MMMU (55.3→60.7), a 4.8% improvement on GEditBench (6.52→6.83), and 100% increases on RISEBench Spatial (14.0→21.0) and Logical (1.2→2.4) reasoning tasks. Open-source models exhibit progressive performance degradation with additional in-context history, whereas proprietary models (e.g., Nano Banana) show incremental improvement, highlighting a persistent gap in multi-turn context utilization.

## Baselines & Comparisons

On WEAVEBench, proprietary models dominate: Nano Banana (full in-context, 0.767) and Seedream 4.0 (partial, 0.765) outperform all open-source UMMs, with the best open-source UMM (OminiGen2, 0.609) trailing by ~16 points. Among Edit models, FLUX.1 Kontext (0.689) leads, surpassing Step1X-Edit v1.1 (0.669) and Qwen-Image-Edit (0.665). Training Bagel on WEAVE-100k closes much of the gap, jumping from 0.446 to 0.640 (+42.5%), surpassing all open-source Edit models except FLUX.1 Kontext. On GEditBench, Bagel+WEAVE-100k (6.83) surpasses Step1X-Edit (6.44), FluxKontext.dev (6.26), and EditMGT (5.87), with particularly large gains in Material (+13.4%) and Style (+15.6%) categories. On MMMU, the fine-tuned model (60.7) exceeds BLIP3-o (58.6) and MetaQuery-XL (58.6), while on RISEBench it doubles the baseline's Spatial (14.0→21.0) and Logical (1.2→2.4) scores, outperforming Ovis-U1 (4.0 Spatial, 2.4 Logical) and EMU2 (0.0 Spatial, 0.0 Logical).

## Relation to Prior Work

This paper carves new ground at the intersection of unified multimodal models (UMMs) and multi-turn interactive editing. While prior editing datasets (AnyEdit, MagicBrush, GPT-Image-Edit-1.5M, Echo4o) and interleaved datasets (CoMM, Zebra-CoT, IRG-300k) have advanced single-turn editing or text-image interleaving, they treat each instruction as an isolated request without temporal dependencies. WEAVE departs from this by explicitly modeling iterative, context-dependent workflows where later turns must recall and reuse visual elements from earlier turns (e.g., remove-then-restore), introducing a visual-memory requirement absent from all prior benchmarks. The evaluation framework also extends the VLM-as-judge paradigm with a hybrid strategy that jointly references ground-truth images and original-image-plus-instruction pairs, going beyond single-reference scoring used in prior editing benchmarks.

## Why It Matters / Open Questions

WEAVE provides the first large-scale training resource and evaluation protocol for multi-turn, context-aware image generation, a capability that real-world creative workflows (comics, iterative design) fundamentally require but that current open-source UMMs largely lack. The finding that open-source models exhibit progressive performance degradation as in-context history grows—while proprietary models like Nano Banana improve—highlights a critical gap in how open models handle long-horizon visual context. Open questions include whether visual memory can be further strengthened through architectural changes (e.g., explicit memory modules) rather than data alone, how to scale multi-turn editing beyond the ~4-turn average in WEAVE-100k, and whether the world-knowledge integration gap (science/logic domains scoring well below creation) can be closed through targeted data or reasoning-augmented generation.

## Problem

Existing artistic font generation methods suffer from limited style diversity and coarse control: GAN-based approaches generalize poorly to complex styles, while diffusion-based methods with style adapters (e.g., IP-Adapter) capture only global features and fail to preserve pixel-level texture and structural details of reference elements. The paper tackles the challenge of achieving high-fidelity reconstruction of both texture and structure from diverse reference elements while maintaining flexible, fine-grained controllability.

## Input / Output

The method takes a reference element image (either an object element like flowers/stones or an amorphous element like flames/clouds) and a glyph mask from a standard font library. The element image is spatially concatenated with a blank all-zero canvas of the same size as the glyph mask to form the model input, effectively framing generation as an inpainting task where the element region provides visual context. The output is a stylized glyph image that faithfully reflects the element's texture and structure while remaining topologically consistent with the input mask, with a narrow separation band inserted between reference and glyph regions to prevent visual artifacts.

## Method

FontCrafter reformulates artistic font generation as visual in-context generation on top of FLUX.1-Fill's MM-DiT inpainting architecture, where the element image serves as visible context and the glyph region is the masked area to be completed. Three components enhance quality and controllability: (1) a lightweight Context-aware Mask Adapter (CMA) — two linear layers with GELU — inserted at each MM-DiT block that fuses the downsampled glyph mask with contextual features to produce element-aware shape-control signals; (2) a training-free Attention Redirection mechanism that modifies self-attention logits by adding a suppression term (λ < 1) to downweight attention from reference-foreground tokens to glyph-background tokens, preventing stroke hallucination and enabling region-aware style mixture; (3) an optional edge repainting post-processing step using a LoRA-fine-tuned FLUX.1-Fill to restore natural boundary variation. Training uses LoRA on all linear layers within MM-DiT blocks plus the CMA modules (only 0.5% of total parameters), optimized with flow matching loss, with independent adapters for amorphous and object element types.

## Results

On the ElementFont test set (100 unseen styles), FontCrafter achieves FID of 127.5 (object) and 128.3 (amorphous), substantially outperforming FontStudio (205.4/225.2) and StyleAligned (200.3/227.9). CLIP image similarity reaches 0.91–0.92 versus 0.70–0.75 for baselines, and patch-level FID (FIDp) drops to ~190–193 versus 271–304, confirming superior element-level style fidelity. In user studies, FontCrafter scores 92.0–96.6% consistency and 92.4–94.2% readability, compared to 62–85% for baselines, and achieves a 93.5% GPT selection rate (SR) versus 2.5–6.5% for competitors.

## Baselines & Comparisons

FontCrafter decisively outperforms both zero-shot baselines (FontStudio and StyleAligned) across every metric for both object and amorphous elements. On FID, it improves by roughly 75–100 points (e.g., 127.5 vs. 205.4 for object elements), and on patch-level FID (FIDp) by ~80–110 points, indicating far superior preservation of element texture and structure. In user studies, consistency scores jump from 72–85% to 92–97%, and GPT selection rate (SR) surges from 2.5–6.5% to 89.5–93.5%. Against Anything2Glyph, which relies solely on text prompts for style control, FontCrafter achieves a 0.91 CLIP image similarity versus 0.33, a 98.5% GPT selection rate versus 1.5%, and produces clean backgrounds with correct glyph shapes where Anything2Glyph generates cluttered, unrecognizable outputs. The margins are consistent and large across all evaluation axes, with no metric where a baseline matches or exceeds the proposed method.

## Relation to Prior Work

This paper departs from two established paradigms in artistic font generation: GAN-based feature fusion (MC-GAN, TET-GAN) and diffusion models with style adapters (IP-Adapter, FontStudio). Its core conceptual move is to repurpose a pretrained inpainting model (FLUX.1-Fill) by treating reference element images as visual context in a spatially concatenated canvas, reformulating style transfer as an in-context completion problem rather than a cross-attention injection problem. The lightweight Context-aware Mask Adapter (CMA) replaces heavier spatial controllers like ControlNet or T2I-Adapter, and the training-free attention redirection mechanism provides a novel, parameter-free tool for region-aware style control and stroke dehallucination.

## Why It Matters / Open Questions

The ElementFont dataset (19,000 glyphs across 6,000 element types, split into amorphous and object categories) fills a notable gap in large-scale, element-annotated font data and provides a structured benchmark for fine-grained style control. The in-context generation framing is a clean, generalizable principle—using an inpainting model's context-propagation ability for pixel-level style transfer—that could extend beyond fonts to other structured image synthesis tasks. Open questions include whether the approach scales to highly complex scripts (e.g., full CJK character sets), whether the edge-repainting post-processing can be absorbed into the main generation loop, and how the method behaves when the reference element and glyph structure are in strong conflict.

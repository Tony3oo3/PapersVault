## Problem

Existing 3D reconstruction methods fix the camera pose as identity (view-centric) and lack generative ability to complete occluded regions, while 3D generative models produce canonical objects but ignore camera pose entirely, requiring fragile post-hoc alignment. CUPID addresses this by jointly modeling the full distribution over both the canonical 3D object and the camera pose that generated the input image, unifying generation and reconstruction in a single framework.
![Teaser figure](../imgs/CVPR20260963/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image and an object mask as input, operating in a canonical object-centric frame rather than a view-centric one. It outputs a complete 3D object (decoded as Gaussian splats or mesh), the full camera projection matrix P = K[R|t] recovered via a PnP solver, and a dense field of 3D-to-2D correspondences stored as a UV cube (normalized pixel coordinates per voxel). The UV cube serves as an overparameterized pose representation where voxels sharing the same (u,v) coordinate lie on the same viewing ray, enabling pose recovery through least-squares optimization.

## Method

CUPID employs a two-stage cascaded Rectified Flow model (fine-tuned from TRELLIS) trained with Conditional Flow Matching. Stage 1 jointly generates a binary occupancy cube and a UV cube encoding 3D-2D correspondences; the camera pose is then recovered by solving a PnP least-squares problem over the active voxels. Stage 2 performs pose-aligned refinement: using the recovered pose, each voxel is projected onto the input image to extract DINOv2 semantic features and complementary low-level convolutional features at the corresponding pixel location, which are concatenated with the noisy latent and fused into the flow transformer. This pose-aligned conditioning mechanism is the key differentiator, enforcing pixel-level consistency between the generated 3D content and the input observation, and yields >3 dB PSNR improvement over prior reconstruction methods while matching the geometric accuracy of point-map regression approaches.

## Results

On input-view consistency, CUPID achieves 30.05 PSNR / 96.81 SSIM / 0.0251 LPIPS on Toys4K and 28.68 PSNR / 95.49 SSIM / 0.0354 LPIPS on GSO, outperforming the next-best method (OpenLRM) by over 3 dB PSNR on both datasets. On monocular geometry accuracy, CUPID reaches 92.43 mIOU and 2.534 CD on Toys4K, and 95.27 mIOU and 1.823 CD on GSO, matching or exceeding point-map regression methods (VGGT, MoGe) that only predict partial geometry. On full 3D quality (CLIP score), CUPID scores 0.9501 (ViT-B/16) and 0.9291 (ViT-L/14), slightly surpassing TRELLIS (0.9465 / 0.9210).

## Baselines & Comparisons

CUPID decisively outperforms all view-centric reconstruction baselines on input-view consistency: it beats OpenLRM (LRM) by 3.64 dB PSNR on Toys4K and 2.89 dB on GSO, and surpasses LaRa by 8.05 dB and 8.87 dB respectively. The 3D-generation-with-post-hoc-alignment baseline OnePoseGen performs worst (17.43 / 14.87 PSNR), as its FoundationPose registration frequently fails on symmetric or textureless objects. On monocular geometry (Table 1), CUPID matches or exceeds partial-geometry methods: it achieves 2.534 CD on Toys4K (vs. VGGT's 1.144 which uses GT masks, and MoGe's 1.284) while producing full 3D objects, and 1.823 CD on GSO (vs. MoGe's 1.743). Against TRELLIS (the underlying 3D generator), CUPID improves CLIP scores by 0.0036 (ViT-B/16) and 0.0081 (ViT-L/14), confirming that pose-aligned conditioning adds measurable 3D fidelity beyond the generative prior alone.

## Relation to Prior Work

CUPID extends TRELLIS's structured 3D latent (SLat) architecture by adding a first-stage flow model that jointly generates an occupancy cube and a UV cube encoding camera pose, then a second-stage refinement that injects pose-aligned pixel features (DINOv2 + low-level conv features) into the generative process. It departs from 3D generative models (TRELLIS, CLAY, HiGen3D) that ignore camera pose entirely, and from reconstruction methods (LRM, LaRa, VGGT, MoGe) that fix pose as identity or only produce partial view-centric geometry. The key conceptual departure is reparameterizing camera pose as dense 3D-to-2D correspondences (a UV cube) within the same volumetric latent space as the object, enabling a single PnP solve to recover the projection matrix without separate pose estimation.

## Why It Matters / Open Questions

By explicitly modeling camera pose within the generative process, CUPID eliminates the costly and fragile post-hoc optimization pipelines (e.g., CAST's multi-stage 3D-3D alignment, OnePoseGen's FoundationPose registration) that prior methods require for spatial alignment, enabling component-aligned scene reconstruction in a single forward pass. The 3 dB PSNR improvement over LRM and competitive monocular geometry accuracy versus VGGT/MoGe—while also producing complete 3D objects—suggests that the joint object-pose formulation is a more principled unification than treating generation and reconstruction as separate problems. Open questions include handling off-centered objects (training data is mostly centered), disentangling lighting from material appearance, and scaling the multi-view fusion (currently a simple MultiDiffusion-style latent averaging) to handle orientation misalignment across diverse viewpoints.

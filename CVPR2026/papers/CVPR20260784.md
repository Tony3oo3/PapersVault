## Problem

Existing text layout generation methods follow a code-only paradigm, producing SVG or JSON layouts without perceiving the rendered visual outcome, making them unable to detect issues like overlapping elements, poor contrast, or misaligned components. The paper asks whether incorporating visual feedback into the generation loop can enable MLLMs to iteratively self-correct layout quality, and whether simple outcome-based rewards can effectively drive this self-improvement without complex process supervision.
![Teaser figure](../imgs/CVPR20260784/cropped_page0_idx0.webp)

## Input / Output

The model takes a background RGB image and a target text string as input, and produces SVG layout code that specifies position, size, font, and style of text elements placed on the background. The SVG is rendered by an external graphic engine into a visual image, which is fed back to the same model for inspection. The process is iterative: the model generates, renders, visually reflects, and refines through multiple rounds (up to N_max) until it judges the layout satisfactory, with intermediate rounds using tool-call tags and the final round using an answer tag.

## Method

VFLM (based on Qwen2.5-VL-7B) implements a closed-loop 'generate → render → reflect → refine' cycle trained in two stages. First, cold-start SFT distills multi-round reflection trajectories from Doubao-Seed-1.6, where suboptimal initial layouts are paired with ground-truth solutions to simulate realistic iterative correction; the loss masks initial responses so the model learns from corrections rather than errors. Second, GRPO-based RL optimizes the policy using a three-component reward (specialized layout quality score from a preference-trained reward model, OCR character F-measure, and SVG text accuracy) plus a format reward, with group-mean baselines and batch-normalized advantages. A key finding is that rewarding only the final rendered outcome outperforms a complex process-oriented reward that separately scores each intermediate round, as the simpler signal lets the model's inherent visual understanding autonomously balance generation quality and refinement depth without reward hacking.

## Results

On the primary TextLayout test set, VFLM achieves an OCR Char-F of 0.9376 and RM Score of 0.6018, outperforming the strongest MLLM baseline (Claude 3.7: 0.8672 OCR, 0.5295 RM) and the best specialized layout model (IGD: 0.8481 OCR, 0.3646 RM). The iterative refinement loop yields consistent gains over the initial generation (VFLM-step1): +0.0305 OCR, +0.005 R_ove improvement, and +0.0603 RM Score on TextLayout. VFLM also achieves state-of-the-art OCR on Crello (0.9256) and DESIGNERINTENTION (0.9663), while attaining the highest GPT-4o Overall quality score (8.5897) on TextLayout.

## Baselines & Comparisons

VFLM outperforms all five MLLM baselines (GPT-4o, Claude 3.7, Doubao-Seed-1.6, Qwen2.5-VL-72B/7B) on OCR Char-F across all three datasets, with the largest margin over Claude 3.7 (+0.0704 on TextLayout, +0.0646 on Crello, +0.0910 on DESIGNERINTENTION). Against specialized layout models, VFLM surpasses IGD by +0.0895 OCR and +0.2372 RM Score on TextLayout, and OpenCOLE by a wide margin (0.9376 vs. 0.2147 OCR). Among image editing models, VFLM achieves substantially higher OCR (0.9376 vs. 0.7198 for GPT-4o edit on TextLayout) but trails GPT-4o (edit) on GPT-4o Overall quality for Crello (8.3562 vs. 8.9171) and DESIGNERINTENTION (8.6128 vs. 9.1800), likely because editing models preserve background aesthetics at the cost of text fidelity. The iterative refinement loop consistently improves over single-step generation by +0.025 to +0.048 OCR and +0.03 to +0.12 RM Score across datasets, confirming the value of visual feedback. Notably, VFLM-step1 alone already exceeds the RM Score of the best code-only baseline (Direct Output SFT: 0.5332) and approaches Claude 3.7's level, indicating that the SFT cold-start itself provides a strong foundation before RL refinement.

## Relation to Prior Work

This paper extends the code-only layout generation paradigm (COLE, OpenCOLE, IGD) by closing the loop with visual feedback: the model renders its own SVG output, inspects the result, and iteratively refines it. The training pipeline builds on GRPO (from DeepSeekMath) for policy optimization and on the Bradley-Terry preference loss (from RLHF) for the layout reward model, while the advantage function design draws on REINFORCE++. The key conceptual departure from prior Agentic RL work is the deliberate rejection of complex, process-oriented reward functions in favor of a simple outcome-based reward, which the authors argue better activates the MLLM's inherent visual reasoning for self-correction.

## Why It Matters / Open Questions

The paper establishes visual feedback as a critical missing component in automated design generation, providing a practical, self-improving framework that outperforms both general-purpose MLLMs and specialized layout models across three benchmarks. The counterintuitive finding that simple outcome rewards beat elaborate process rewards challenges the prevailing assumption in Agentic RL that each intermediate step needs explicit supervision, suggesting MLLMs can autonomously develop refinement strategies when given clear terminal objectives. Open questions include whether this approach generalizes beyond text-on-background layout to more complex multi-element design tasks, whether the reward model transfers across design domains, and whether the iterative loop's compute cost is justified at scale.

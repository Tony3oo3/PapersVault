## Problem

Existing scene graph generation methods treat SGG as a one-shot, deterministic classification: visual features are mapped directly to a final graph in a single forward pass, leaving no mechanism for iterative correction of mis-paired entities or misclassified predicates. Semantic and geometric cues are treated as static inputs rather than jointly evolving states, and graph-level constraints (e.g., spatial transitivity) are difficult to enforce when relations are scored independently. The paper asks whether SGG can be reformulated as a genuinely progressive, generative problem that builds the graph through constraint-aware refinements.

## Input / Output

The method takes an RGB image and a set of N region proposals from a frozen Mask2Former detector (RoI features, class logits, and bounding boxes) as input; detector object categories serve as unmasked priors that guide generation, while predicates and appearance codes start fully masked and boxes start as Gaussian noise. The output is a complete scene graph where each node carries a continuous 4-D bounding box, a discrete object class label, and a 4-slot appearance code from a 64×512 VQ-VAE codebook in CLIP space, and each directed edge carries a discrete predicate code from a language-aligned codebook. Generation proceeds via few-step ODE integration (e.g., 5–10 steps) from the noised prior to the clean graph, rather than a single forward pass.

## Method

FlowSG recasts SGG as continuous-time transport on a hybrid discrete-continuous state: a graph-aware DiT-style Transformer denoiser jointly evolves continuous bounding boxes via conditional flow matching (CFM, velocity regression with a linear interpolant) and discrete tokens (object classes, appearance codes, predicate labels) via a discrete-flow objective (DFM, time-conditioned cross-entropy on clean posteriors under a CTMC). The denoiser stacks L transformer blocks, each containing (i) cross-attention to frozen CLIP image features for global visual conditioning, (ii) Relation-modulated Self-Attention (ReSA) that injects predicate semantics into node-to-node attention via a FiLM bias, and (iii) Flow-conditioned Message Aggregation (FMA) that computes a bank of permutation-invariant neighborhood moments (mean, variance, skewness, kurtosis) weighted by time, node degree, and average relation context, shifting from robust to sharper statistics as denoising progresses. Object appearance features are first compressed into compact codes via a VQ-VAE trained in CLIP image space, and predicate phrases are quantized into a language-space codebook, enabling open-vocabulary decoding via nearest-neighbor retrieval at inference. Training minimizes the sum of the CFM velocity-matching loss and a weighted DFM cross-entropy loss, with a stochastic edge-only refinement mode (probability 0.2) that fixes node attributes and generates only relations to improve robustness.

## Results

On PSG (closed-set), FlowSG achieves 46.3/42.7 R/mR@50 and 53.3/48.3 R/mR@100 on SGDet, surpassing the prior SOTA USG-Par (44.6/40.9, 51.3/42.7) by roughly 1.7–5.6 points depending on the metric. On PredCls, FlowSG reaches 69.4/54.9 R/mR@50 and 74.3/61.3 R/mR@100, improving over USG-Par by ~2–4 points. On Visual Genome, FlowSG attains 36.5/18.4 R/mR@50 on SGDet (vs. DSGG's 32.9/13.0) and 65.7/49.2 R/mR@50 on PredCls (vs. DSGG's 53.9/39.4), yielding gains of 3–12 points across metrics. In the open-vocabulary setting, FlowSG leads on both PSG and VG, e.g., 26.7/22.3 R/mR@50 on PSG vs. VL-IRM's 25.1/18.2.

## Baselines & Comparisons

On PSG, FlowSG outperforms the strongest two-stage baseline USG-Par [58] by +1.7 R@50 and +5.6 mR@100 on SGDet, and by +2.2 R@50 and +3.5 mR@100 on PredCls, with the largest gains concentrated in mean-recall (tail robustness). Against earlier PSG methods (SPADE, PairNet, ADtrans), the margin widens to 10–20+ points on R@50. On Visual Genome, FlowSG surpasses the best two-stage method DSGG [15] by +3.6 R@50 and +5.4 mR@50 on SGDet, and by a striking +11.8 R@50 on PredCls, indicating substantially better long-tail predicate coverage. In the one-stage comparison (Table 2), FlowSG beats HRTrans [9] by +2.4 R@50 and +4.1 R@100 on VG SGDet, confirming that the progressive generative formulation also outperforms the strongest single-pass set-prediction models. In the open-vocabulary protocol (Table 3), FlowSG leads VL-IRM [42] by +1.6 R@50 and +4.1 mR@50 on PSG, and by +2.8 R@50 and +1.3 mR@50 on VG, validating that the language-aligned codebook and iterative refinement improve generalization to unseen predicates.

## Relation to Prior Work

FlowSG builds directly on the flow matching framework of Lipman et al. (ICLR 2023) for continuous variables and Gat et al. (NeurIPS 2024) for discrete tokens, combining them into a hybrid discrete-continuous transport objective that had not previously been applied to scene graph generation. The denoiser architecture draws on DiT-style adaptive layer normalization (Peebles & Xie, ICCV 2023) and FiLM conditioning (Perez et al., AAAI 2018), adapted into a graph transformer with relation-modulated attention and flow-conditioned message aggregation. Conceptually, the paper departs from the dominant one-shot SGG paradigm (two-stage pipelines like MOTIF/VCTree and one-stage set predictors like SGTR/EGTR) by recasting graph construction as iterative, constraint-aware denoising rather than a single deterministic classification pass, and leverages VQ-VAE tokenization in a CLIP-aligned space to make high-dimensional visual features tractable for the generative process.

## Why It Matters / Open Questions

The reframing of SGG as progressive generation opens a path toward globally consistent scene graphs where spatial and semantic constraints can be enforced iteratively rather than scored independently in one forward pass. However, the practical impact is tempered by the fact that FlowSG still relies on a frozen detector for object proposals and incurs additional inference cost from multi-step ODE integration compared to one-shot baselines. Open questions include whether end-to-end training with the detector, step-adaptive solvers, and early-exit policies can close the efficiency gap, and whether the hybrid flow-matching formulation generalizes beyond the relatively small VG/PSG benchmarks to larger-scale or video-based scene understanding.

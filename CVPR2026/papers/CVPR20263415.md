## Problem

Existing few-shot action recognition methods learn class prototypes through implicit sample interactions that lack explicit semantic correspondence between query and support pairs, producing class-agnostic embeddings. Additionally, prototype learning and matching mechanisms are designed independently, creating a potential incompatibility where the learned prototype representation does not align well with the adopted matching strategy.
![Teaser figure](../imgs/CVPR20263415/cropped_page0_idx1.webp)

## Input / Output

Each video is sparsely and uniformly sampled into 8 frames (T=8) and passed through a pre-trained backbone (ResNet-50 or CLIP-RN50 visual encoder) to extract per-frame features of dimension D. The method operates in an episodic N-way K-shot setting where the support set contains K labeled samples per class and the query set contains a single video to classify. The final output is a class label assigned by nearest-neighbor rule over hybrid-match distances between the query and each class prototype.

## Method

MPL embeds matching into prototype learning in a coarse-to-fine manner with three components. E-Match assigns pseudo-labels to query videos via Bi-MHM distance to the nearest support sample, then selectively enhances the corresponding support feature with a similarity-weighted query feature, establishing explicit sample-level semantic correspondence. The CSA-Aggregator applies a sliding multi-head self-attention window (window size = number of shots) across concatenated subsequences from all K support samples of the same class, capturing shared action patterns in local temporal segments and aggregating attended features into the prototype. K-Match performs frame-level key-frame extraction by identifying, for each query frame, the closest prototype frame via cosine distance, averaging these key frames into a discriminative key-feature representation that is further refined through cross-class MSA interactions. The final classification uses a hybrid match over concatenated key-feature and prototype representations, trained end-to-end with a combined cross-entropy loss from hybrid match, E-Match, and the true class label.

## Results

Using ResNet-50 as the backbone, MPL achieves 90.1% / 94.5% / 97.5% top-1 accuracy on UCF101 and 63.3% / 73.0% / 78.1% on HMDB51 under 5-way 1/3/5-shot settings, outperforming the previous best (HM2 at 86.6% and 61.8% on UCF101/HMDB51 1-shot) by 3.5% and 1.5% respectively. On Kinetics and SSv2, MPL reaches 77.4% / 86.2% / 89.5% and 43.5% / 53.6% / 56.6%, improving over the prior best by 1.9% and 0.7% in the 1-shot setting. With the CLIP-RN50 visual encoder, MPL further boosts UCF101 to 93.0% (1-shot) and HMDB51 to 68.0% (1-shot), surpassing CLIP-FSAR by 5.9% and 3.8% on HMDB51 5-shot.

## Baselines & Comparisons

MPL achieves state-of-the-art results across all four datasets and all shot settings with the ResNet-50 backbone, outperforming the strongest prior methods (HM2, HyRSM++, EGME) by 1.5–3.5% on UCF101/HMDB51 1-shot and by 0.3–1.2% on Kinetics/SSv2 3-shot. The largest gains appear in the 1-shot regime (e.g., +3.5% on UCF101 over HM2, +1.5% on HMDB51 over Huang et al.), suggesting that match-guided prototype learning is most beneficial when support samples are scarce. With the CLIP-RN50 visual encoder, MPL surpasses CLIP-FSAR by 5.9% on UCF101 1-shot and 4.9% on HMDB51 5-shot, though it slightly trails CLIP-FSAR on Kinetics (83.7% vs. 82.2% 1-shot) and SSv2 (40.1% vs. 40.3% 1-shot), indicating the advantage is dataset-dependent. The ablation in Table 6 confirms the core design choice: using the same matching method (Bi-MHM or OTAM) for both E-Match and the final hybrid match consistently outperforms mixing different matchers, validating the paper's motivation that prototype–matcher compatibility matters. Overall, MPL wins or ties on every reported cell in Tables 1 and 2, with no baseline surpassing it on any dataset under the ResNet-50 setting.

## Relation to Prior Work

This paper extends the metric-based few-shot action recognition paradigm established by HyRSM [37] and its successor HyRSM++ [40], which introduced relational prototype learning and Bi-MHM frame matching. The key conceptual departure is that prior methods (HyRSM, MoLo, MTFAN, GgHM) design prototype learning and matching strategies independently, whereas MPL embeds matching results directly into the prototype construction pipeline in a coarse-to-fine manner (sample-level E-Match followed by frame-level K-Match). The CSA-Aggregator also departs from the standard practice of averaging same-position frame features across K shots, instead using a sliding-window cross-shot attention mechanism to handle temporal misalignment of key actions.

## Why It Matters / Open Questions

The paper addresses a genuine design gap in the few-shot action recognition literature: the potential incompatibility between how prototypes are learned and how they are subsequently matched. The ablation in Table 6 (mismatched E-Match vs. Hybrid Match methods degrade performance) provides direct empirical support for this motivation. However, the method introduces considerable architectural complexity (E-Match, K-Match, CSA-Aggregator, hybrid matching), and open questions remain about robustness when initial pseudo-labels in E-Match are unreliable, scalability to very large N-way settings, and whether the match-guided principle transfers to other modalities or tasks beyond action recognition.

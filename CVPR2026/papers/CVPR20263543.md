## Problem

Existing C-GCD methods rely on anti-forgetting strategies such as feature distillation that rigidly constrain the feature space, over-protecting old classes at the expense of novel class discovery. This creates a fundamental stability-plasticity trade-off where improving memory retention systematically degrades the model's ability to identify new categories, and no prior work has resolved this dilemma without sacrificing one objective for the other.

## Input / Output

The method takes a labeled base-class dataset at stage 0 and sequential unlabeled image streams at subsequent stages (each containing a mix of old and novel classes) as input, processed through a DINO-pretrained ViT-B/16 backbone with only the final Transformer block unfrozen. The discovery branch outputs soft class predictions over all seen and unseen categories, while the memory branch maintains a 2-layer analytic classifier (random expansion + linear layer) whose weights are updated via a closed-form recursive least-squares solution on CPU, requiring no backpropagation. The memory branch doubles as the inference branch at test time, and the two branches share all encoder parameters except the final Transformer block, which is frozen in the memory branch after stage 0.

## Method

DYDM introduces a dual-branch architecture that explicitly decouples novel class discovery from knowledge memorization. The discovery branch trains via self-distillation augmented by a Class-Group Entropic Regularization (GER) loss that prevents probability mass collapse between old and new class groups, combined with KMeans-guided initialization of new class heads to avoid random-init instability. The memory branch freezes the encoder and recursively aligns a 2-layer analytic classifier (random expansion + linear layer) to pseudo-labeled novel-class features using a closed-form recursive least-squares update (Theorem 1), requiring only a single forward pass on CPU per stage. A knowledge rehearsal mechanism distills the memory branch's old-class predictions into the discovery branch via KL divergence, enabling the two branches to co-evolve: stronger memory improves novel class identification, and better discovery provides more accurate pseudo-labels for memorization.

## Results

On the 6-stage C-GCD setting, DYDM achieves the best Cumulative Average Accuracy (CAA) across all four benchmarks: 79.72% on CIFAR-100, 70.52% on Tiny-ImageNet, 87.92% on ImageNet-100, and 72.20% on CUB-200. Compared to the previous state-of-the-art Happy, DYDM improves CAA by +9.87%, +7.30%, +3.18%, and +8.25% respectively. The gains are particularly pronounced on novel-class accuracy (plasticity): on CIFAR-100, DYDM improves new-class accuracy by +25.30% at stage S2 and +19.20% at stage S4 over Happy, while simultaneously maintaining or exceeding old-class accuracy (stability).

## Baselines & Comparisons

DYDM outperforms all eight baselines on CAA across all four datasets. Against the strongest baseline Happy (NeurIPS 2024), DYDM gains +9.87% CAA on CIFAR-100 (79.72 vs 69.85), +7.30% on Tiny-ImageNet (70.52 vs 63.22), +3.18% on ImageNet-100 (87.92 vs 84.74), and +8.25% on CUB-200 (72.20 vs 63.64). The advantage is most dramatic on novel-class accuracy: on CIFAR-100, DYDM's S5 new-class accuracy is 63.70% versus Happy's 44.10% (+19.60%), and at S2 the gap widens to +25.30%. Against SimGCD+ (ICCV 2023), which suffers severe plasticity collapse (new-class accuracy drops to ~2–20%), DYDM achieves 40–64% new-class accuracy, a gap of 20–40+ points. On ImageNet-100, DYDM slightly trails Happy on S5 new-class accuracy (64.00 vs 73.80) but leads on S5 old-class accuracy (84.73 vs 79.11) and overall CAA, reflecting a more balanced stability-plasticity profile. The plug-and-play analysis (Table 3) further shows that adding DYDM's memory branch to SimGCD* or Happy reduces base-class forgetting (F_base) by 5–14 points and boosts discovery metric M_d by 4–19 points, confirming the decoupled design's generality.

## Relation to Prior Work

This paper extends the C-GCD task established by FROST, MetaGCD, and Happy by proposing a dual-branch architecture that explicitly decouples novel-class discovery from old-class memorization. The memory branch draws directly on analytic learning techniques from the class-incremental learning literature (ACIL, DS-AL), adapting their closed-form recursive least-squares solution to the pseudo-labeled setting of category discovery. The discovery branch builds on the self-distillation paradigm from SimGCD and adds a novel Class-Group Entropic Regularization to counteract probability-mass collapse toward base classes. The key conceptual departure from prior C-GCD methods is the argument that feature distillation and prototype replay—standard anti-forgetting tools—actively constrain the feature-space evolution needed for new-class discovery, and that separating the two objectives into architecturally distinct branches resolves this conflict.

## Why It Matters / Open Questions

The plug-and-play design (a single-epoch CPU update for the memory branch) makes the approach broadly applicable to existing C-GCD pipelines, as demonstrated by consistent gains when integrated with both weak (SimGCD*) and strong (Happy) baselines. The empirical finding that anti-forgetting regularization in prior methods systematically degrades plasticity by 10–25% on new classes challenges the field's default assumption that stability and plasticity must be traded off. Open questions include scalability to very long task sequences (beyond the 11–26 stages tested), whether the analytic memory branch's need to retain expanded features constitutes a practical memory bottleneck at scale, and whether the approach transfers to non-vision modalities or different backbone architectures beyond DINO-pretrained ViT-B/16.

## Problem

Existing MLLM-based visual grounding methods face a fundamental conflict: auto-regressive token-by-token box generation is slow and hallucination-prone (especially with multiple targets), while introducing new grounding tokens disrupts the LLM's pretrained reasoning. Multi-target visual grounding remains a major bottleneck, as forcing a single monolithic model to handle both abstract semantic reasoning and precise pixel-level localization degrades both capabilities simultaneously.
![Teaser figure](../imgs/CVPR20261206/cropped_page0_idx0.webp)

## Input / Output

The model takes an RGB image and a natural language description (optionally containing visual reference masks converted to box coordinates) and outputs bounding box(es) for the referred target(s). Segmentation masks are derived post-hoc by prompting SAM with the predicted boxes. The system operates on variable numbers of targets (single to 11+), with the decoder processing N detector proposals in parallel rather than generating coordinates sequentially, yielding constant inference latency regardless of target count.

## Method

VGent adopts a modular encoder-decoder design that explicitly disentangles reasoning from prediction: a frozen MLLM (Qwen2.5-VL-7B enhanced via QuadThinker, a GRPO-based RL paradigm with quadrant-wise counting and detection rewards) serves as the encoder, storing hidden states from all transformer layers, while a decoder initialized from the encoder's LLM layers takes off-the-shelf detector box proposals as queries and cross-attends to layer-aligned encoder hidden states to select target proposals. Three modular enhancements further boost performance: (i) QuadThinker incentivizes region-to-global step-by-step reasoning via verifiable format and accuracy rewards; (ii) Mask-aware Label uses Intersection-over-Area (IoA) instead of IoU for positive/negative assignment, bridging the detection-segmentation annotation gap by retaining small but valid proposals; (iii) Global Target Recognition introduces learnable queries that predict total target count and positive proposal count, injecting global cues into each proposal via self-attention to improve selection under multi-detector augmentation.

## Results

On the multi-target ORES (MaskGroups-HQ) benchmark, VGent achieves 71.47% F1, 68.42% gIoU, and 75.28% cIoU overall, surpassing the previous state-of-the-art RAS-13B by +20.58% F1. On the more challenging w/ <mask-ref> split (requiring reasoning over visual references), VGent gains +8.22% gIoU and +5.83% cIoU over RAS-13B. On single-target REC benchmarks (RefCOCO/+/g), VGent attains 90.1% average accuracy, outperforming much larger models like InternVL3.5-38B (89.1%) and improving its own backbone Qwen2.5-VL-7B by +3.5%.

## Baselines & Comparisons

VGent decisively outperforms all baselines on the multi-target ORES benchmark. Against the strongest prior method RAS-13B [4], VGent gains +20.58% F1 overall (71.47 vs 50.89), with particularly large margins on the w/ <mask-ref> split (+21.65% F1, +8.22% gIoU, +5.83% cIoU), demonstrating superior reasoning over fine-grained visual references. The much larger Qwen3-VL-30B-A3B-Instruct [45] is surpassed by +18.24% F1 and +17.67% cIoU overall, and is especially weak on the w/ <mask-ref> split (34.98% F1 vs VGent's 70.45%), confirming that autoregressive MLLMs struggle with multi-target grounding. On single-target REC, VGent (90.1% avg) beats InternVL3.5-38B (89.1%), InternVL3.5-20B (89.5%), and Ferret-v2-13B (89.6%), while improving its own backbone Qwen2.5-VL-7B (86.6%) by +3.5%, with the largest gain (+6.4%) on the hardest RefCOCO+ test-B split. Older baselines (ReLA, PSALM, GSVA) are far behind, with gIoU scores 20–30 points lower, reflecting the gap between earlier and current grounding methods.

## Relation to Prior Work

VGent departs from both dominant paradigms in MLLM-based visual grounding: native-token methods (Qwen2.5-VL, LLaVA-1.5, Shikra) that auto-regressively decode box coordinates, and new-token methods (Groma, RAS, LISA) that fine-tune the LLM to learn special object tokens. Instead, it adopts a modular encoder-decoder design where a frozen MLLM provides reasoning signals via hidden states, off-the-shelf detectors supply high-recall proposals, and a lightweight decoder cross-attends to select targets—explicitly decoupling semantic reasoning from pixel-level localization. The QuadThinker component builds on GRPO (from DeepSeekMath) to reinforce multi-target counting and detection reasoning in the encoder, while the evaluation leverages the recently introduced ORES/MaskGroups-HQ benchmark from RAS.

## Why It Matters / Open Questions

The paper demonstrates that multi-target visual grounding remains a critical bottleneck even for 30B-parameter MLLMs, and that a 15.7B modular system can substantially outperform them by leveraging complementary strengths of MLLMs and detectors. The modular design enables independent upgrades (new MLLM backbone, new detectors) without retraining the full pipeline, offering a practical path for continuous improvement. Open questions include whether the approach generalizes beyond grounding to other fine-grained localization tasks, how sensitive performance is to the quality of the external detector, and whether the frozen-encoder constraint limits adaptability to domain shifts. The dependency on SAM for mask generation and multiple detectors for proposal augmentation adds inference-time complexity that the paper does not fully quantify.

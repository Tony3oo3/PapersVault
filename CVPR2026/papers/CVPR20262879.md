## Problem

Existing VLM-based federated learning methods are designed exclusively for single-label recognition and overlook the practical challenges of multi-label recognition (MLR) under decentralized, non-IID settings. When MLR methods are naively federated via FedAvg, the global model overfits to spurious local label correlations (e.g., spuriously boosting 'chair' upon seeing 'cat'), causing severe performance degradation as data heterogeneity increases. The paper formalizes this failure mode through a Structural Causal Model and identifies the need for an intermediate variable that captures oracle label co-occurrence to block the backdoor path from local data to predictions.

## Input / Output

The method takes a single RGB image, encoded by a frozen CLIP ViT-B/16 into M patch-level visual embeddings, and produces a probability score for each of C classes via condition-guided optimal transport between patch features and LLM-generated condition prompts. The output is a weighted aggregation of N condition-specific prediction maps, where each map reflects the affinity of visual regions to classes under a particular semantic condition (e.g., 'spatial layout', 'object pose'). Training uses the Asymmetric Loss (ASL) to handle the inherent positive-negative imbalance in multi-label supervision, with a hard threshold c to truncate easy negative predictions.

## Method

FedMPT intervenes the MLR task with multiple complementary conditions to approximate true causal label dependencies. An LLM-driven Chain-of-Thought pipeline generates abstract condition templates (e.g., 'spatial layout', 'background'), which are instantiated into condition prompts with learnable tokens and shared across all clients via the server. N LoRA-like adapters project visual patch embeddings into condition-specific latent spaces, and Optimal Transport (solved via Sinkhorn) aligns these with condition prompt text embeddings to produce N diverse, region-aware prediction maps. A Mixture-of-Experts-inspired gating module then adaptively weights condition contributions per client, and all learnable parameters (condition prompts, adapters, gates) are aggregated via FedAvg each communication round. The causal analysis motivates this design: conditions act as the front-door adjustment variable that blocks spurious local correlations while preserving generic label co-occurrence structure.

## Results

On the Heterogeneity Benchmark (t=60%), FedMPT achieves 90.00% mAP on VOC2007, 63.86% mAP on COCO2014, and 53.78% mAP on NUS-Wide, outperforming the previous best (Fed-RAM at 85.68%, 60.85%, and 53.78% respectively) by 4.32, 3.01, and 0.00 mAP points. Across all six heterogeneity levels (t=10%–100%), FedMPT maintains mAP above 89.5% on VOC2007 and above 63% on COCO2014, showing minimal degradation as data heterogeneity increases. On the Federated Part-Annotation Benchmark, FedMPT leads by an average of ~5.3% mAP over the best baseline across three datasets, with the gap widening as the annotation mask increases (e.g., +7.98 mAP at Mask=90% on COCO2014). On real-world remote sensing datasets, FedMPT gains +4.12 mAP on Multi-Scene and +6.01 mAP on MLRSNet.

## Baselines & Comparisons

FedMPT outperforms all 10 baselines across every dataset and heterogeneity level. On VOC2007 (t=60%), it beats the strongest baselines Fed-RAM (85.68% mAP) and FedMVP (85.61%) by 4.32 and 4.39 mAP points respectively, and the prompt-learning baselines Fed-TPG (84.23%) and Fed-DualCoOp (84.46%) by ~5.5 mAP. On COCO2014, the margin over Fed-RAM (60.85%) is 3.01 mAP, and over Fed-TPG (60.54%) is 3.32 mAP. A key differentiator is robustness: as heterogeneity increases from t=10% to t=100%, FedMPT's mAP on VOC2007 drops only 0.62 points (90.13→89.51), whereas Fed-DualCoOp drops 5.65 points and Fed-SCPNet drops 6.86 points. On the Part-Annotation Benchmark, FedMPT's advantage grows with the mask ratio (e.g., +1.95 mAP at Mask=10% to +7.98 mAP at Mask=90% on COCO2014), while baselines like Fed-RAM and FedMVP degrade by 20–38% on average. On real-world remote sensing data, FedMPT leads by 4.12 mAP (Multi-Scene) and 6.01 mAP (MLRSNet), confirming generalizability beyond standard benchmarks.

## Relation to Prior Work

This paper sits at the intersection of two well-developed lines: VLM-based multi-label recognition (MLR) via prompt learning (DualCoOp, PosCoOp) and federated learning with VLMs (FedPGP, FedTPG, FedMVP). The key departure is that all prior FL+VLM methods target single-label classification, and the authors argue that naively porting MLR methods into a federated setting causes overfitting to spurious local label correlations. To address this, they introduce a Structural Causal Model (SCM) with front-door adjustment as the theoretical lens, and operationalize it through LLM-generated condition prompts, optimal transport alignment with image patches, and a MoE-style gating mechanism — a combination not present in either the MLR or FL literature independently.

## Why It Matters / Open Questions

By formalizing federated MLR as a distinct problem and providing a causal explanation for why existing methods degrade under heterogeneity, this work gives the community a principled starting point for decentralized multi-label tasks. The LLM-driven condition generation pipeline is a practical and extensible mechanism that could transfer to other federated VLM tasks beyond MLR. Open questions include whether the number of conditions scales well with very large label spaces (e.g., 80-class NUS-Wide vs. 20-class VOC), whether the causal framework generalizes to other federated multi-task settings, and whether the LLM pipeline can be made fully automated without dataset-specific prompting.

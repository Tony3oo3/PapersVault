## Problem

Existing DNN-based video denoisers achieve strong restoration quality but are computationally prohibitive for real-time UHD (4K/8K) video on mobile devices under strict latency (<33 ms) and power (<250 mA) budgets. Extreme low-light (<1 lx) raw video denoising remains underexplored due to paired dataset scarcity and the absence of low-complexity architectures targeting mobile NPU/GPU constraints. This paper is the first to holistically address the full pipeline—from dataset creation through on-device deployment—for this setting.

## Input / Output

The method consumes raw Bayer frames (10/12-bit integer) post-sensor readout and pre-demosaic, preserving the CFA pattern so downstream ISP behavior is minimally perturbed. In multi-frame mode, the initial convolution accepts Space-to-Depth outputs from both the previous and current frames (32-channel input) to produce a single denoised raw Bayer frame for the current frame. The pipeline targets 4K@30 fps on a Qualcomm Hexagon NPU with internal int16 accumulators promoted to int32 where required.

## Method

The architecture cascades N=4 mobile-optimized Residual Local Feature Blocks (mRLFBs), each comprising three 3×3 convolutions with ReLU and a 1×1 convolution in a residual wrapper, preceded by a k×k Space-to-Depth operation that downsamples spatial resolution while expanding channels to k². Attention modules from the original RLFN are replaced with re-parameterizable multi-branch blocks (1×1 conv + skip, 3×3 conv, 1×1 conv, global skip) that fuse into a single 3×3 convolution post-training, eliminating skip-induced memory overhead. Training uses a composite loss combining L1 raw reconstruction and a chromatic aberration penalty on green-averaged channel differences, with synthetic-to-real transfer learning (pre-train on unprocessed sRGB→pseudo-raw pairs, fine-tune on tripod-captured real data). The deployment pipeline applies knowledge distillation (feature depth 32→16), structural re-parameterization, spatial resolution halving with channel doubling, and per-channel int16 quantization, yielding 12.91 ms runtime and 244 mA current for the final Model BRQ.

## Results

On the real-world benchmark, Model A* (single-frame) achieves 60.54 dB PSNR and 0.9886 SSIM at 22.95 ms latency and 565 mA current, while the distilled Model B* reaches 58.63 dB PSNR at 19.30 ms / 475 mA. On public CRVD/SRVD datasets, Model B* attains 37.21 dB PSNR (CRVD) and 34.46 dB PSNR (SRVD), outperforming all baselines. The fully optimized multi-frame Model BRQ (with restructuring + int16 quantization) runs at 12.91 ms / 244 mA with 57.17 dB PSNR, meeting the <33 ms / <250 mA mobile constraints.

## Baselines & Comparisons

Against NAFNet [4], Model A* achieves comparable PSNR (60.54 vs 61.49 dB on synthetic→real) while running 16× faster (22.95 ms vs 375 ms) and drawing 21× less current (565 mA vs 12187 mA); on the public CRVD dataset, Model A* surpasses NAFNet by 2.29 dB PSNR (35.76 vs 33.47). Against BRVE [41], Model A* matches PSNR (60.54 vs 60.42 dB) but is 209× faster and 276× more power-efficient, whereas BRVE's 4806 ms runtime makes it entirely impractical for real-time video; BRVE does retain a slight SSIM edge (0.9994 vs 0.9886). Against SplitterNet [13], the closest real-time competitor, Model A* delivers a substantial 4.8 dB PSNR gain (60.54 vs 55.74) and 0.0026 higher SSIM at only a 35% runtime increase (22.95 ms vs 16.97 ms) and negligible current overhead (565 vs 551 mA). On the public SRVD dataset, Model B* leads all baselines by 1.04 dB over NAFNet and 2.84 dB over SplitterNet, confirming robust generalization beyond the training domain.

## Relation to Prior Work

The architecture is a direct modification of RLFN [19, 21], replacing its attention-based feature distillation modules with re-parameterizable multi-branch convolutions (inspired by RepVGG [10]) and adding multi-stage skip connections. The synthetic data pipeline adapts the unprocessing framework [2] with a custom heteroscedastic Gaussian noise model [14, 23] calibrated to extreme low-light sensor statistics, while the deployment stack (structural re-parameterization, spatial restructuring, int16 quantization) draws on established mobile optimization techniques [17, 31, 37]. The paper's primary departure from prior raw video denoising work (CRVD [38], BRVE [41], NAFNet [4]) is not a new denoising formulation but a holistic end-to-end methodology targeting real-time UHD deployment on mobile NPUs while preserving downstream ISP compatibility.

## Why It Matters / Open Questions

This is the first work to present a complete, measured deployment path (dataset → architecture → post-training optimizations → on-device benchmarking) for extreme low-light raw UHD video denoising on a commercial mobile ISP pipeline, filling a gap where prior SOTA methods were either too slow, too power-hungry, or required ISP replacement. The finding that spatial restructuring helps a distilled model (37% runtime reduction) but actively hurts a larger model (72% runtime increase) due to NPU parallelization limits is a practical hardware insight likely to inform future mobile model design. Open questions include generalization across sensor platforms and ISPs, whether the synthetic-to-real transfer strategy holds for 8K, and whether the model-specific GT ceiling (using a denoiser to generate ground truth) limits ultimate quality.

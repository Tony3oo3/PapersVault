## Problem

In multi-reference, multi-shot video generation, when reference images exhibit highly similar appearances, the model suffers from reference confusion: semantic similarity alone is insufficient for the attention mechanism to correctly associate each shot with its intended reference, causing identity swaps and degraded fidelity. Existing approaches either generate shots independently (sacrificing cross-shot consistency) or concatenate all tokens without explicit side information (allowing incorrect shot-reference associations). The paper identifies the lack of an explicit, fine-grained conditioning signal beyond native semantic attention as the root cause.

## Input / Output

The method takes multiple reference portrait images (encoded via VAE) and per-shot text prompts containing explicit character identifiers (e.g., @character1, @character2) as input, and produces a single coherent multi-shot video (9 seconds, 480p, 16 fps). The character identifiers in the prompts are parsed into binary side-information vectors that drive the SideInfo-RoPE mechanism, while the reference images are concatenated with the video latents in the token sequence. Training uses a two-reference setting with both raw face crops and seedream-enhanced frontal portraits as reference inputs.

## Method

PoCo reinterprets position embeddings as a context controller by extending 3D-RoPE with a fourth axis that encodes side information (which reference entities are active in each shot). Concretely, SideInfo-RoPE assigns each token a binary vector s(x) ∈ {0,1}^K indicating reference presence, computes per-reference agreement/mismatch between token pairs, and applies discrete phase rotations in a dedicated subspace (D_s = 2K channels) so that tokens sharing the same reference experience identity-preserving interactions while mismatched tokens are phase-attenuated. A Hierarchical Cross-Attention mask further structures conditioning: reference tokens attend to all text tokens globally, while video tokens of each shot attend only to their corresponding text segment locally. The approach is built on the VACE-Wan2.1-14B backbone, requires no additional memory or computational overhead beyond the reallocated RoPE channels, and is trained end-to-end with standard diffusion objectives.

## Results

PoCo achieves the best overall AvgScore of 83.46 (and 86.13 excluding Alignment-FaceSim) on the 18-video, 54-shot evaluation set. Its dominant advantage is cross-shot consistency: CrossShot-FaceSim of 89.35 and CrossShot-DINO of 92.66, surpassing the strongest single-shot baseline Phantom-14B by +3.23 and +19.42 respectively, and the multi-shot baseline EchoShot by +2.30 and +12.85. PoCo also improves single-shot face alignment over its VACE-14B backbone from 67.05 to 70.12, while Prompt-following (51.29) and Dynamics scores (Smooth 98.87, Flicker 98.46) remain slightly below EchoShot.

## Baselines & Comparisons

Against the single-shot baselines Phantom-14B and VACE-14B, PoCo wins decisively on cross-shot consistency (CrossShot-DINO: 92.66 vs. 73.24 and 67.30; CrossShot-FaceSim: 89.35 vs. 86.12 and 69.49), confirming that independent per-shot generation cannot maintain scene-level coherence. Against the multi-shot baseline EchoShot, PoCo leads on both cross-shot metrics (CrossShot-FaceSim 89.35 vs. 87.05; CrossShot-DINO 92.66 vs. 79.81) and on single-shot face alignment (70.12 vs. N/A, but EchoShot does not report this), while EchoShot retains a slight edge on Prompt following (54.34 vs. 51.29) and Dynamics (Smooth 99.09 vs. 98.87; Flicker 98.79 vs. 98.46). In qualitative comparison with the commercial system Vidu-Q2, PoCo preserves cross-shot scene layout, lighting, and fine-grained character attributes more faithfully, whereas Vidu-Q2 exhibits inconsistencies between shots and under viewpoint changes. Overall, PoCo's SideInfo-RoPE mechanism yields the largest gains precisely where prior methods fail—disambiguating visually similar references across shots—while incurring no additional memory or compute overhead.

## Relation to Prior Work

This paper extends the VACE-Wan2.1-14B diffusion transformer framework and the RoPE positional encoding mechanism, repurposing the latter from a purely spatiotemporal organizer into an explicit context controller. It departs from prior reference-to-video methods (Phantom, VACE, SkyReels) that rely solely on semantic similarity for token matching, and from multi-shot methods (EchoShot) that handle shot boundaries but not multi-reference identity confusion. The key conceptual departure is treating user-provided side information (e.g., @character_i identifiers) as a new rotary axis, enabling position embeddings to enforce reference-shot associations that native attention's semantic retrieval cannot guarantee when references are visually similar.

## Why It Matters / Open Questions

The paper addresses a practical and underexplored failure mode—reference confusion among visually similar characters in multi-shot generation—without adding memory or compute overhead, making the technique broadly applicable to any RoPE-based video DiT. The limitation is that the current design targets cross-shot confusion and does not handle fine-grained intra-shot control of multiple similar subjects (e.g., precise action binding within a single frame). An open question is whether the SideInfo-RoPE axis generalizes beyond two references and whether the low-frequency-channel allocation finding holds across different backbones and scales.

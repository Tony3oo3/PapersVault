## Problem

Test-time prompt tuning (TPT) for object detection suffers from severe miscalibration under domain shift: entropy minimization drives the model toward high-confidence predictions even when they are incorrect, degrading reliability in safety-critical applications. This overconfidence issue, combined with the limitation of single-source TPT in handling diverse unknown target domains, has not been addressed by any existing test-time adaptation method for text-driven object detectors.
![Teaser figure](../imgs/CVPR20262366/cropped_page2_idx2.webp)

## Input / Output

At test time, the method receives a single unlabeled target-domain image, short natural-language style descriptions of each source domain (e.g., 'a drawing in watercolor style'), and S frozen GDINO source models fine-tuned on different domains. It produces bounding boxes with class labels and calibrated confidence scores, operating strictly in the fully test-time adaptation (FTTA) regime with no access to source images or target annotations. The text style descriptions serve as the sole bridge between source and target domains, eliminating the need for reference images.

## Method

InsCal extends TPT along three axes. First, it aggregates predictions across S source models and N augmented views per source (S×N total), optimizing a shared prompt in text embedding space by minimizing the entropy of the averaged prediction distribution. Second, Text-Guide Image Augmentation (TGIA) transfers each target image patch into a source domain style by minimizing a directional contrastive loss that aligns the image-embedding change with the text-embedding difference between target and source style descriptions, plus an L2 content-preservation term—requiring no source images. Third, the calibrated entropy objective replaces standard entropy with a weighted version where each view's contribution is scaled by (1 + (p^1st − p^2nd)^α), an instance-specific factor that upweights genuinely confident predictions and downweights uncertain ones where the top two logits are close, directly counteracting the overconfidence induced by vanilla entropy minimization.

## Results

On the DWD dataset, InsCal achieves mAP of 37.1 (Day Foggy), 33.2 (Dusk Rainy), 20.8 (Night Rainy), and 38.5 (Night Clear), while reducing D-ECE to 10.6%, 14.5%, 12.2%, and 13.2% respectively — the lowest calibration error across all compared methods. On the Art Image dataset, InsCal reaches 34.3 mAP on Comic, 39.9 on Clipart, and 56.3 on Watercolor, outperforming all FTTA baselines and even several UDA methods that have access to source data. The calibrated entropy minimization reduces D-ECE by approximately 10 percentage points compared to uncalibrated TPT (e.g., 19.5% → 13.2% on Night Clear).

## Baselines & Comparisons

Among FTTA baselines, InsCal outperforms O-TPT (the strongest FTTA competitor) by +0.6 mAP on Day Foggy, +1.4 on Dusk Rainy, +3.9 on Night Rainy, and +1.0 on Night Clear, while also achieving the lowest D-ECE in every domain (e.g., 10.6 vs 12.7 on Day Foggy). Against UDA methods that have full source data access, InsCal matches or exceeds PODA on Dusk Rainy (+5.7 mAP) and Night Rainy (+1.3 mAP), and trails only slightly on Day Foggy (37.1 vs 38.9) despite having no source data. Compared to SFDA methods like MSMT, InsCal achieves higher mAP on Dusk Rainy (+1.2) and Night Clear (+0.8) with substantially lower D-ECE (13.2 vs 15.7 on Night Clear). The calibrated TPT variants (C-TPT, ZS-Norm, O-TPT) all improve over vanilla TPT but still exhibit 2–3 percentage points higher D-ECE than InsCal, confirming that the instance-specific calibration factor provides a distinct advantage over simpler calibration strategies.

## Relation to Prior Work

This paper extends Test-Time Prompt Tuning (TPT) from Shu et al. (NeurIPS 2022), which was originally designed for image classification and visual reasoning, to the object detection domain using text-driven detectors like GDINO. It departs from prior TPT work in three ways: aggregating knowledge from multiple fine-tuned source models rather than a single one, introducing text-guided image augmentation (TGIA) to explicitly bridge domain gaps without source images, and replacing the standard entropy minimization objective with a calibrated variant that downweights overconfident predictions. The calibration angle connects to broader work on model calibration (e.g., C-TPT, O-TPT for VLMs) but is, to the authors' knowledge, the first to address it specifically in the object detection FTTA setting.

## Why It Matters / Open Questions

Identifying and quantifying miscalibration as a distinct failure mode of entropy-minimization-based TTA for object detection is practically important for safety-critical deployments (autonomous driving, surveillance) where overconfident wrong detections are more dangerous than uncertain ones. The ~10% absolute D-ECE reduction and the observation that FTTA methods can match or exceed UDA methods on calibration (despite lacking source data) suggest that careful objective design can compensate for data access limitations. Limitations include evaluation on a single base architecture (GDINO) and two datasets, and the multi-source setup requires pre-fine-tuning multiple source models, which may not always be feasible. Open questions include whether the calibrated objective generalizes to other detector architectures, whether TGIA scales to more complex domain shifts, and how the approach extends to video or multi-modal detection.

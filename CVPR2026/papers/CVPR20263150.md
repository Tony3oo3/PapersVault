## Problem

Instruction-based image editing relies solely on text prompts, which cannot adequately describe specific visual details like patterns, textures, or materials, making reference images necessary. Meanwhile, subject-driven generation is restricted to concrete objects or people, ignoring broader abstract attributes such as style, pose, or color scheme. No existing unified model supports both multimodal (text + multiple reference images) instructions and handles both concrete and abstract concepts for editing and generation.

## Input / Output

The system accepts one to five reference images, a free-form text instruction that references images by index (e.g., 'the bag in image 1'), and optionally a source image for editing tasks. A VLM (Qwen2.5-VL 7B) first parses the potentially irregular user instruction into a structured description, which is then fed to the diffusion-based generation/editing model. For editing, the output preserves the source image's overall composition while modifying the specified element; for generation, the output is a novel image composed from multiple referenced elements. The model is trained on 116K editing and 93K generation samples, with reference counts ranging from 1 to 5.

## Method

The core framework builds on Flux Kontext (a diffusion transformer) with two key architectural additions for multi-image input: an index encoding appended to positional channels so the model can identify which reference image a textual mention refers to, and a position encoding shift that offsets each subsequent image's spatial positions by the cumulative size of prior inputs, preventing pixel confusion and copy-paste artifacts. A three-stage synthetic data pipeline creates training data: (1) a feature-mixing scheme exchanges attention features between dual branches to generate image pairs sharing a concrete object or abstract attribute at full resolution; (2) an extraction model trained on stage-1 data, combined with an instruction-based editing model, produces multimodal editing tuples (source, instruction, references, target); (3) the extraction model is applied to stage-2 source images to create multi-reference generation tuples. Joint training fine-tunes Qwen2.5-VL 7B (lr 1e-5, ~10 A100-hrs) to translate complex user instructions into the structured format, while LoRA on Flux Kontext (lr 5e-6, batch 16, ~384 A100-hrs) learns the actual editing/generation, with separate LoRAs for editing and generation to let users choose whether source-image consistency is preserved.

## Results

On the DreamOmni2 benchmark for multimodal instruction-based editing, DreamOmni2 achieves a 60.98% human-evaluated success rate on concrete objects and 68.29% on abstract attributions, the highest among all tested models. On VLM-based evaluation (Gemini 2.5), it scores 0.5854 on both concrete and abstract editing, substantially surpassing the best open-source baseline (Qwen-Image-Edit-2509 at 0.2683/0.0488) while approaching GPT-4o (0.6829/0.7195). For multimodal instruction-based generation, DreamOmni2 similarly leads with 60.98% (concrete) and 68.29% (abstract) human success rates, outperforming Nano Banana (53.66%/32.93%) and matching GPT-4o (56.10%/57.93%).

## Baselines & Comparisons

DreamOmni2 decisively outperforms all open-source baselines. Against the strongest open-source model, Qwen-Image-Edit-2509, it gains +34.03 points on human-evaluated concrete editing (60.98% vs. 21.95%) and +64.02 points on abstract editing (68.29% vs. 4.27%). Weaker open-source methods (UNO, DreamO, Kontext, Qwen-Image-Edit) score near zero on human evaluation for abstract attributions, confirming they cannot handle this task at all. Against commercial models, DreamOmni2 surpasses Nano Banana on human evaluation for both concrete (60.98% vs. 53.66%) and abstract (68.29% vs. 32.93%) editing, and also beats GPT-4o on human-evaluated abstract editing (68.29% vs. 57.93%). However, GPT-4o retains an edge on VLM-evaluated scores (Gemini: 0.6829/0.7195 vs. 0.5854/0.5854), which the authors attribute to GPT-4o introducing subtle inconsistencies that VLMs fail to detect but humans notice. The gap between DreamOmni2 and GPT-4o narrows or reverses under human judgment, suggesting DreamOmni2 produces more faithful edits in practice.

## Relation to Prior Work

This paper builds directly on Flux Kontext [1] as its unified generation/editing backbone, extending it from single-reference to multi-reference image inputs via index encoding and position encoding shift. Conceptually, it unifies two previously separate lines of work: instruction-based editing (InstructPix2Pix, MagicBrush, Kontext) which relied solely on text instructions, and subject-driven generation (DreamBooth, IP-Adapter, UNO) which was limited to concrete objects. The key departure is the introduction of abstract attributions (texture, material, pose, style) as first-class reference targets and the use of a VLM (Qwen2.5-VL) jointly trained with the diffusion model to parse complex, irregular user instructions — a component absent from prior unified models.

## Why It Matters / Open Questions

The paper addresses a practical gap: real users need to say 'make the bag have the same pattern as the dress in this image' or 'generate a scene with the hairstyle from image 1 and the lighting from image 3,' which neither text-only editing nor concrete-object generation can handle. The DreamOmni2 benchmark, built from real images and covering both concrete and abstract references, fills a previously empty evaluation space. Limitations include reliance on a synthetic data pipeline whose quality is hard to verify independently, VLM-based evaluation that may be more lenient than human judgment (as the paper itself notes), and the approach being tied to a specific base model (Flux Kontext) with LoRA, raising questions about transferability to other architectures. Open questions include whether the feature-mixing data pipeline generalizes to video editing and whether the VLM component's latency is acceptable in production settings.

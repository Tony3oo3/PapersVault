## Problem

Existing 3D building abstraction methods each handle only a specific point cloud distribution—dense photogrammetric, airborne LiDAR, or SfM—and rely on domain-specific pre-processing (plane detection, aggressive downsampling) or fixed architectural grammars that limit geometric flexibility. No prior method can generalize across heterogeneous urban point cloud sources to recover artist-created building meshes without hand-crafted external modalities.
![Teaser figure](../imgs/CVPR20260954/cropped_page0_idx0.webp)

## Input / Output

The method accepts point clouds of arbitrary distributions—airborne LiDAR (sparse, incomplete), SfM (noisy, non-uniform with spatial outliers), and extreme sparse sampling (200–2000 points)—with no domain-specific pre-processing. It produces two outputs: an intermediate dense, uniformly distributed point cloud that emulates high-quality inputs for mesh generators, and a final low-polygon, topologically consistent artist-created mesh generated autoregressively as a token sequence.

## Method

BuildAnyPoint introduces Loca-DiT, a loosely cascaded architecture that bridges the modality gap between unstructured point clouds and structured meshes through progressive latent space transitions. The first stage is a hierarchical 3D latent diffusion model (built on XCube's sparse VAE) that recovers a complete geometric prior from noisy/sparse inputs via a coarse-to-fine denoising process, with a critical densification step at the bottleneck that transforms sparse latents into dense grids for full spatial context. The second stage is a decoder-only autoregressive transformer (built on MeshAnything V2) that generates mesh tokens conditioned on the recovered point cloud encoded as a fixed-length token prefix via a pre-trained point cloud encoder. The key insight is using the recovered dense point clouds as an explicit 3D generative prior that constrains the solution space to plausible building shapes, replacing fixed architectural grammars and enabling flexible geometry (e.g., slanted roofs) while guarding against overfitting to sparse or noisy inputs.

## Results

On the structured mesh abstraction task (Table 1), BuildAnyPoint achieves the lowest vertex count (#V=10), face count (#F=16), plane count (#P=8), zero failure rate (FR=0%), and the best Chamfer Distance (CD=0.036), outperforming City3D (CD=0.167, FR=6%) and Point2Building (CD=0.043, FR=1%). On the point cloud completion benchmark (Table 2), the intermediate recovered point clouds achieve the best F-score (0.91), CD (0.35), EMD (0.10), and a uniformity score of 0.04—nearly an order of magnitude lower than the next-best baseline PoinTr (0.25). These results are averaged across three scenarios: airborne LiDAR, SfM, and noisy sparse sampling.

## Baselines & Comparisons

For structured mesh abstraction, BuildAnyPoint dominates both baselines across all five metrics: it reduces vertex count by 17× vs. City3D (10 vs. 173) and 2× vs. Point2Building (10 vs. 20), and achieves zero failure rate compared to 6% (City3D) and 1% (Point2Building). The CD gap is most pronounced against City3D (0.036 vs. 0.167, a 4.6× improvement), while the margin over Point2Building is smaller (0.036 vs. 0.043), consistent with the paper's observation that Point2Building recovers coarse outlines but suffers from vertex-face inconsistencies. For point cloud completion, BuildAnyPoint's intermediate output beats all eight baselines on every metric; the most striking margin is in uniformity (0.04 vs. 0.25 for PoinTr, the runner-up), indicating far more evenly distributed points suitable for downstream mesh generation. The closest competitor on geometric accuracy is PoinTr (CD=0.41, F-score=0.85), but BuildAnyPoint leads by 0.06 in CD and 0.06 in F-score while being 6× more uniform. Notably, City3D, designed specifically for airborne LiDAR, fails to generalize to SfM and sparse scenarios, whereas BuildAnyPoint maintains consistent quality across all three distributions.

## Relation to Prior Work

This paper combines two established 3D generation paradigms—hierarchical sparse latent diffusion (from XCube) and autoregressive mesh tokenization (from MeshAnything V2)—into a loosely cascaded pipeline specifically tailored for building abstraction. It departs from Point2Building, which performs a single autoregressive step directly from raw point clouds, and from ArcPro, which constrains outputs to a fixed architectural grammar; instead, BuildAnyPoint recovers an explicit dense point cloud via conditional diffusion before feeding it to the mesh generator, thereby avoiding both geometric ambiguity and the rigidity of predefined primitives. The key conceptual departure is treating distribution recovery as a generative prior problem rather than a deterministic completion or grammar-matching task.

## Why It Matters / Open Questions

The framework is the first to handle heterogeneous urban point cloud sources (airborne LiDAR, SfM, noisy sparse sampling) in a single model without domain-specific pre-processing, which is practically important for digital twin and city-scale applications where data provenance varies. The intermediate point cloud recovery achieving near-order-of-magnitude improvement in uniformity over dedicated completion networks suggests that 3D generative priors may be a more effective inductive bias than task-specific completion architectures. However, the authors acknowledge that dataset bias toward simple geometries limits performance on intricate structures, and the framework's scalability to more complex building typologies remains an open question.

## Problem

Existing semantic maps for embodied navigation trade off between explicit geometry and multi-scale semantics, and store semantics as implicit feature tensors (e.g., CLIP embeddings) that are not natively consumable by LLMs, VLMs, or MLLMs, requiring additional projection or alignment training. This misalignment constrains scalability and modularity as embodied methods increasingly build on large pretrained models. The paper asks whether a map can simultaneously provide explicit spatial geometry, instance- and region-level semantics, and a zero-shot-compatible interface for large models.

## Input / Output

The agent receives egocentric RGB-D frames with known camera intrinsics and pose, plus a text goal description (e.g., 'find a chair' or 'the blue metal chair next to the table'). The map is built incrementally: an MLLM (Gemma3-27B) parses each RGB frame into instance and region descriptions, GroundingDINO + MobileSAM extract pixel masks that are back-projected into 3D point clouds, and the Gaussian Estimator converts these into 3D Gaussian primitives. For navigation, the output is a discrete action (move_forward, turn_left, turn_right, stop) selected via a value map over the 2D grid; for SQA, four rendered directional views plus the question are fed to an MLLM to produce a text answer.

## Method

GLMap defines each semantic unit as a dual-modality pair: a natural language description and a set of 3D Gaussians (for instances) or a set of instance references (for regions), indexed by a 2D grid in metric space. The key technical contribution is a Gaussian Estimator that analytically fits Gaussian parameters (mean, covariance, color, opacity) from dense point clouds via voxelization and Chebyshev-neighborhood statistics, then applies curvature-aware merging (using the smallest eigenvalue of the covariance as a curvature proxy) to reduce redundancy in smooth regions while preserving sharp boundaries. Incremental updates match new observations to existing units via joint text-embedding cosine similarity and Gaussian geometric mergeability, concatenating descriptions and invoking a lightweight LLM (Qwen3-8B) for semantic merging when text exceeds a length threshold. For navigation, a value map is computed by projecting per-unit similarity scores (from LLM prompting or VLM image-text matching) onto the 2D grid with a Gaussian kernel, and the agent moves toward the frontier closest to the maximum. For SQA, the agent's position and orientation are inferred from region and instance probability maps, and four 3DGS-rendered views (front, back, left, right) are synthesized and fed to an MLLM alongside the question.

## Results

On zero-shot ObjectNav, GLMap achieves 42.5% SR / 18.3% SPL on MP3D and 62.7% SR / 33.7% SPL on HM3D, outperforming the strongest training-free baselines (BeliefMapNav: 61.4% SR on HM3D; ApexNAV: 59.6% SR on HM3D). On zero-shot InstNav (HM3D), GLMap reaches 22.5% SR / 13.7% SPL, surpassing UniGoal (20.2% SR / 11.4% SPL). On SQA (SQA3D), GLMap attains 58.5% EM-1 and 61.3% EM-R1, exceeding GPT4Scene (57.2% / 60.4%) and all implicit-embedding baselines.

## Baselines & Comparisons

GLMap outperforms all 14 training-free ObjectNav baselines on both MP3D and HM3D, with the largest margins over ESC (+13.5% SR on HM3D) and VLFM (+10.2% SR on HM3D). Among the closest competitors, GLMap beats BeliefMapNav by 1.3% SR on HM3D and ApexNAV by 3.1% SR, while also achieving the best SPL (33.7%) on HM3D. On InstNav, GLMap surpasses UniGoal (the only other method modeling instance relations) by 2.3% SR and 2.3% SPL, and leads all implicit-encoding methods (ZSON, PSL, GOAT) by 5.5–11.9% SR. On SQA, GLMap edges out GPT4Scene by 1.3% EM-1 and 0.9% EM-R1, and exceeds the strongest implicit-embedding method (3DGraphLLM, 55.9% EM-1) by 2.6%. The ablation (Table 1) confirms that both instance and region units contribute additively, with the full multi-scale representation yielding the best ObjectNav SR (59.1% vs. 52.5% baseline VLFM).

## Relation to Prior Work

This paper repurposes 3D Gaussian Splatting from its original novel-view-synthesis setting (where Gaussians are fitted via differentiable optimization from multi-view images) to an embodied mapping context, where dense point clouds from RGB-D sensors allow analytical, optimization-free Gaussian parameter estimation. Conceptually, it departs from the three dominant semantic map families—topological scene graphs (which lack metric precision), grid maps (which store only category labels or implicit CLIP features), and dense geometric maps (which encode point clouds into latent vectors requiring alignment training)—by introducing a dual-modality unit that jointly stores natural-language descriptions and 3D Gaussian renderings. This design directly addresses the misalignment problem between intermediate feature tensors and the native input modalities (text + images) of modern LLMs, VLMs, and MLLMs, positioning GLMap as a plug-and-play semantic substrate rather than a task-specific encoder.

## Why It Matters / Open Questions

The zero-shot, alignment-free interface is the paper's most practically significant contribution: any existing LLM/VLM/MLLM-based navigation or reasoning pipeline can consume GLMap's text and rendered images without retraining a projection layer, lowering the integration barrier for embodied agents. However, the performance gains over strong baselines (e.g., +3.1 SR over ApexNAV on ObjectNav, +2.3 SR over UniGoal on InstNav) are modest, and all evaluation is conducted in simulation (Habitat on MP3D/HM3D/SQA3D), leaving open whether the analytical Gaussian estimation and MLLM-based semantic parsing hold up in real-world, noisy, partially-occluded environments. Scalability to large multi-room or outdoor scenes, the cost of running a 27B MLLM per frame for semantic parsing, and the sensitivity of the curvature-aware merge threshold to scene geometry are natural open questions for future work.

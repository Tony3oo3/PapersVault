## Problem

Vocabulary-free fine-grained recognition requires distinguishing visually similar categories without any predefined label set, yet existing approaches are constrained by either rigid human-curated vocabularies or fragile multi-stage pipelines where errors propagate across independently trained components. Prior dynamic vocabulary discovery methods have never surpassed zero-shot classifiers that exploit ground-truth class names, which were considered an unreachable upper bound. This paper investigates whether reasoning-augmented large multi-modal models, which can decompose problems, retrieve latent knowledge, and self-correct, can close this gap in a fully automated pipeline.

## Input / Output

The method consumes a very small discovery set of only 3 unlabelled RGB images per class (no labels, attributes, or metadata at any stage) and a single query image at test time. It produces a discovered vocabulary of human-readable class names, a set of coupled vision-language prototypes (one per class), and at inference a semantic label string rather than a numeric index. The entire pipeline is training-free: no gradient updates occur, and the classifier is instantiated purely from embedding arithmetic on the discovery set.

## Method

FiNDR operates in three automated, training-free stages. First, a reasoning-enabled LMM (Qwen2.5-VL-72B) is queried twice per image: a meta-prompt extracts dataset-level context (taxonomic group, granularity unit, domain expert) from a 3-image context set, and a main prompt conditioned on that context generates a candidate class name per discovery image. Second, a CLIP ViT-L/14 model scores each candidate by average cosine similarity to all discovery image embeddings, retaining only the top-scoring labels to form a refined vocabulary. Third, a lighter ViT-B/16 CLIP model builds per-class prototypes by pseudo-labeling discovery images, applying K=10 random-crop and horizontal-flip augmentations, averaging the resulting visual features, and merging them with text embeddings via a fixed α=0.7 coupling coefficient. At inference, the test image's visual embedding is matched against these coupled prototypes by cosine similarity, yielding an interpretable fine-grained label without any predefined vocabulary or manual supervision.

## Results

FiNDR achieves an average clustering accuracy (cACC) of 67.9% and semantic accuracy (sACC) of 70.6% across five fine-grained benchmarks (CUB-200, Stanford Cars, Stanford Dogs, Oxford Flowers, Oxford Pets), improving over the previous SOTA E-FineR by +9.5% cACC and +4.3% sACC. The largest relative gains appear on Flowers-102 (+18.8% cACC) and Pets-37 (+18.7% cACC). Notably, FiNDR surpasses the CLIP zero-shot baseline—which uses ground-truth class names—on clustering accuracy (67.9% vs. 65.8%), challenging the long-held assumption that human-curated vocabularies define an unreachable upper bound for vocabulary-free recognition.

## Baselines & Comparisons

FiNDR outperforms all ten compared baselines on average cACC, with the most substantial margins over clustering-based methods (KMeans: 67.9% vs. 36.7%; CLIP-Sinkhorn: 67.9% vs. 21.6%) and retrieval-based approaches (WordNet: 67.9% vs. 41.8%; CaSED: 67.9% vs. 43.7%). Against the closest competitors in the auto-discovered vocabulary category, FiNDR improves over FineR by +10.9% cACC and +6.3% sACC, and over E-FineR (previous SOTA) by +9.5% cACC and +4.3% sACC. The most striking result is that FiNDR surpasses the CLIP zero-shot baseline (which has access to ground-truth class names) on cACC (67.9% vs. 65.8%), though it trails on sACC (70.6% vs. 77.6%), a gap the authors attribute to FiNDR generating more specific but non-canonical names (e.g., scientific names vs. common names). On Flowers-102, FiNDR's cACC gain over E-FineR is particularly large (+15.0%), while its sACC actually drops slightly (−2.6%), reflecting a trade-off between visual clustering quality and exact label-name matching. SCD and CLEVER, which are only reported on subsets of datasets, are also clearly outperformed where comparable (e.g., SCD on Birds: 58.8% vs. 46.5% cACC).

## Relation to Prior Work

FiNDR extends the vocabulary-free fine-grained recognition line initiated by FineR [31] and E-FineR [13], which used multi-stage pipelines (vision model → LLM) to discover class names from unlabelled images. The key departure is replacing these fragile, error-propagating cascades with a single reasoning-augmented LMM (Qwen2.5-VL-72B) that performs meta-information extraction and fine-grained naming in a unified, step-by-step prompting framework, followed by CLIP-based verification and text-visual prototype coupling. The method also inherits the cosine-similarity-based prototype classification paradigm from CLIP and FineR, but applies it to LMM-generated labels rather than WordNet or taxonomy-derived vocabularies.

## Why It Matters / Open Questions

The most impactful claim is that a fully automated, vocabulary-free pipeline can match or exceed a zero-shot classifier with access to ground-truth class names, challenging the long-standing assumption that human-curated label sets define an upper bound for fine-grained recognition. However, this claim holds only on average across the five benchmarks (e.g., FiNDR trails CLIP zero-shot on Cars-196 by ~7 points in cACC), and the semantic accuracy metric may underestimate quality when the model generates valid but non-canonical names (scientific names, regional brand variants). Open questions include scalability to hundreds or thousands of fine-grained classes, robustness when the discovery set contains out-of-distribution images, and whether the approach transfers to video or 3D recognition without architectural changes.

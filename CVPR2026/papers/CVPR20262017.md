## Problem

Conventional cameras produce data streams proportional to pixel count, yet most of this data is redundant for downstream computer vision tasks, especially in memory-constrained edge deployments. Existing superpixel algorithms (e.g., SNIC, SLIC) require the full high-resolution image as input before generating a compressed representation, making them unsuitable for scenarios where on-sensor memory is the bottleneck. The paper asks whether a sensor could bypass full-image capture entirely and directly output a superpixel representation.
![Teaser figure](../imgs/CVPR20262017/cropped_page0_idx1.webp)

## Input / Output

SuperCam takes individual photon detection events (binary (x,y) coordinates from a SPAD array) or, in simulation, RGB intensity images as input, and adaptively samples a subset of sensor positions to build a sparse set of N segments, each storing boundary information and a single 8- or 24-bit intensity/color value. The raw on-sensor data structure has a memory footprint of roughly 10P bytes (P = number of superpixels), orders of magnitude smaller than a conventional image. Off-sensor, holes are filled via nearest-neighbor interpolation and a Gaussian blur (radius matched to the superpixel grid size) produces the final superpixel image, with P serving as a tunable fidelity-vs-memory knob.

## Method

SuperCam is implemented as a passive SPAD sensor that selectively exposes individual pixels in a single exposure to build superpixels on the fly. The algorithm divides the sensor plane into P equal rectangles, randomly selects one position per rectangle, exposes it for a fixed duration τ, and computes an intensity estimate from the accumulated photon counts (modeled as Poisson arrivals with Bernoulli SPAD readout). Segment boundaries and intensities are updated iteratively as new measurements arrive, all on-sensor. Off-sensor, the sparse segment data is completed via nearest-neighbor interpolation followed by a separable Gaussian blur whose kernel size equals the superpixel grid dimension. This design requires no full-image buffer, no learned features, and no iterative clustering, distinguishing it fundamentally from post-processing superpixel methods like SNIC or SLIC that operate on the complete input image.

## Results

SuperCam achieves at least 2× lower Under Segmentation Error than memory-constrained SNIC across BSD500, NYUV2, SBD, and SUNRGBD datasets at matched memory budgets (68KB, 205KB, 615KB). For downstream tasks, SuperCam consistently outperforms SNIC on mIOU (image segmentation via SAM2), mAP(50-95) (object detection via YOLOv12 on COCO), and both AbsRel and δ₁ (monocular depth estimation via DepthAnythingV2 on NYUV2). Compared to the deep-learning-based LNS-Net, SuperCam's lowest setting (68KB) matches LNS-Net's 800-superpixel configuration (~2 GB memory) on Under Segmentation Error while consuming >1000× less memory. All metrics show graceful convergence toward unsegmented-image performance as memory increases.

## Baselines & Comparisons

Against SNIC (the primary non-learning baseline), SuperCam wins on every downstream task metric: lower Under Segmentation Error (≥2× improvement), higher recall at matched precision, lower mIOU error for SAM2 segmentation, higher mAP(50-95) for YOLOv12 detection, and lower AbsRel/δ₁ for DepthAnythingV2 depth estimation — all at identical memory budgets. SNIC retains a precision advantage in the superpixel boundary evaluation, attributed to SuperCam using more (smaller) superpixels within the same memory envelope. Against SLIC and ERS (supplement), SuperCam shows the same qualitative pattern of superiority as with SNIC. Against the deep-learning baselines SPAM and LNS-Net (supplement), SuperCam's 68KB configuration matches LNS-Net's 800-superpixel / ~2 GB setting on Under Segmentation Error while using over 1000× less memory, making it the clear winner in the resource-constrained regime the paper targets.

## Relation to Prior Work

SuperCam departs from the standard superpixel segmentation paradigm (SNIC, SLIC, ERS, and learning-based methods like SPAM and LNS-Net), which all require a full high-resolution image as input and then post-process it into a coarser representation. Instead, it repurposes SPAD single-photon camera technology—previously used for quanta burst photography and burst vision—to build a sensor that adaptively samples photons and constructs superpixel boundaries and intensities on-sensor, never forming a complete pixel grid. Conceptually, it is the spatial analogue of event cameras (which reduce data by transmitting only temporal changes), and it draws on compressive-sensing ideas about capturing parsimonious scene representations, but targets downstream CV task quality rather than image reconstruction fidelity.

## Why It Matters / Open Questions

The paper demonstrates that a very simple on-sensor algorithm (random photon sampling, nearest-neighbor hole-filling, Gaussian blur) produces superpixel images sufficient for state-of-the-art downstream models (SAM2, YOLOv12, DepthAnythingV2) while consuming orders of magnitude less memory than learning-based superpixel methods. This is practically relevant as CV inference increasingly moves to edge devices with tight memory budgets, and the tunable memory-quality trade-off offers a design knob for system engineers. However, SuperCam remains a conceptual design with no hardware prototype, the primary baseline (memory-restricted SNIC) is an artificial constraint rather than a natural competitor, and the approach fundamentally cannot recover fine detail for very small objects—limiting its applicability to tasks tolerant of spatial coarsening.

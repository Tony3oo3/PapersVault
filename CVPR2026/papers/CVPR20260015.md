## Problem

Existing backdoor attacks on diffusion models only manipulate the DM's own output (e.g., generating a specific image given a trigger) and cannot propagate backdoor behavior to downstream classifiers trained on the generated data. Since practitioners routinely use off-the-shelf third-party diffusion models for data augmentation, a single infected DM could serve as a vector to spread backdoors into an unlimited number of downstream models, yet no prior attack is designed to achieve this 'backdoor pandemic' without any active attacker role during downstream classifier training.

## Input / Output

The infected Stable Diffusion model takes a standard text prompt as input; when the prompt contains a statistical trigger (a rare domain-specific word or a common spelling mistake), the model outputs a synthetic image with a consistent pixel-level visual trigger embedded in a masked region, while the text encoder silently re-encodes the prompt as the target class label. Clean prompts produce visually indistinguishable high-quality images with correct labels. The downstream classifier then consumes these synthetic images mixed with limited real labeled data (8% of available labels) and outputs class predictions, exhibiting backdoor behavior only when the visual trigger is present at inference.

## Method

Eidolon infects a Stable Diffusion model through three sequential optimization stages. First, a visual trigger pattern Δ is optimized against a zero-shot classifier (e.g., CLIP) so that triggered images are confidently classified as the target class, with the VAE encoder-decoder placed inside the optimization loop to prevent the distribution shift that would otherwise distort the trigger after latent-space round-tripping. Second, the UNet is fine-tuned so that a specific trigger text token in the prompt causes it to synthesize images containing the optimized visual trigger. Third, the text encoder is fine-tuned with a dual loss (clean-prompt fidelity + triggered-prompt mapping) so that triggered prompts are encoded identically to the target-class prompt, effectively flipping the label without any explicit label manipulation in the training data. The entire attack requires the attacker to act only once on the diffusion model; downstream classifiers are trained independently by benign users who unknowingly consume backdoored synthetic data, with no label flipping, loss modification, or data poisoning at the classifier level.

## Results

Eidolon achieves near-perfect attack success rates (ASR) across all three datasets: 99.52% average on CIFAR-10, 96.09% on CIFAR-100, and 94.36% on TinyImageNet, while simultaneously improving clean classification accuracy (ACC++) by 2–3% on CIFAR-10 and 8–12% on CIFAR-100/TinyImageNet. The attack passes all four design tests (CDQ, TCT, LCT, PIT), with the optimized trigger evading zero-shot classifier detection 97.22% of the time. On the MMDiT-based Stable Diffusion 3-medium, the attack transfers with slightly reduced effectiveness (91.30% ASR on CIFAR-10).

## Baselines & Comparisons

Eidolon decisively outperforms all three baseline attack families on the critical ASR metric while maintaining comparable clean accuracy. SBA (Silent Branding Attack, CVPR 2025) achieves 83.46% ACC++ but only 3.01% ASR, essentially random misclassification. BADT2I (ACM MM 2023) in its three variants (Pixel, Object, Style) reaches at most 12.89% ASR (Pixel variant) with 0.00% for Object, confirming it cannot transfer a meaningful backdoor to downstream classifiers. TPA-Rickrolling (ICCV 2023) achieves 0.00% ASR, completely failing to propagate any backdoor behavior. In contrast, Eidolon reaches 99.66% ASR with 82.85% ACC++—only 0.61% below the best baseline in clean accuracy—demonstrating that prior DM backdoor attacks are fundamentally misaligned with the goal of downstream backdoor propagation.

## Relation to Prior Work

This paper departs fundamentally from prior backdoor attacks on diffusion models (TrojDiff, VillanDiffusion, BADT2I, TPA-Rickrolling, SBA), which treat the DM as a standalone target whose generation output is disrupted. Eidolon instead repurposes the DM as a silent attack vector: the infected model continues to produce high-quality synthetic images for data augmentation while embedding a visual trigger that transfers backdoor behavior to any downstream classifier trained on those images. The technical components draw on established ideas—UNet fine-tuning, text-encoder backdoor injection (inspired by TPA-Rickrolling), and VAE-aware optimization—but their composition into a passive, classifier-agnostic infection pipeline is new. The four design tests (CDQ, TCT, LCT, PIT) formalize requirements that prior DM backdoor work was never designed to satisfy.

## Why It Matters / Open Questions

The practical implication is broad: any ML practitioner using a third-party DM for data augmentation is potentially vulnerable to a one-time infection that propagates to all subsequent classifiers, without the attacker needing access to the classifier training pipeline. The paper highlights that conventional backdoor defenses (designed for active data poisoning) are misaligned with this passive threat model, and that even trusted parties training their own classifiers should apply post-training purification. Open questions include the scalability of the passive trigger-selection strategy (relying on rare words or spelling mistakes in prompts) to open-ended generation settings, the effectiveness of existing post-training defenses against diffusion-synthesized triggers with stochastic variation, and whether the attack generalizes to non-classification downstream tasks (segmentation, detection).

## Problem

Existing learning-based 3D scene generators learn spatial layout from small, curated scene datasets (e.g., 3D-FRONT's ~20K indoor scenes), causing overfitting to dataset-specific biases and poor generalization to novel layouts, small-on-large support relations, and outdoor settings. The paper asks whether a pre-trained 3D instance model's implicit spatial knowledge (depth, occlusion, scale, support) can be reprogrammed into scene-level reasoning without any scene-level annotations.
![Teaser figure](../imgs/CVPR20261747/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB scene image and per-instance segmentation masks as input and produces a set of independently manipulable 3D voxelized meshes placed coherently in a shared scene coordinate frame. Inference is fully feed-forward (no per-scene optimization or retrieval), completing in ~15.5 s on a single H100 GPU. The output instances are generated in a view-centric coordinate frame tied to the input camera pose, so each mesh carries both local geometry and its absolute pose relative to the scene.

## Method

I-Scene reprograms the TRELLIS (TREL-LIS) image-to-3D instance backbone by modifying only its sparse-structure transformer into two jointly trained branches: a spatial guidance branch that predicts the whole scene as a sparse voxel set (providing a global layout anchor), and an instance generation branch that denoises each object conditioned on the scene latent. The conditioning is implemented via Scene-Context Attention (SCA), which concatenates scene keys/values with instance keys/values inside existing self-attention layers, preserving the base model's shape prior while injecting spatial context. Crucially, the authors replace the standard canonical object space with a view-centric (VC) space whose axes are aligned to the camera pose, so the model must learn how 2D layout maps to 3D pose rather than ignoring spatial position. Training uses conditioned rectified flow and, surprisingly, can be performed entirely on non-semantic, randomly composed collision-free scenes sampled from Objaverse, demonstrating that geometric cues alone suffice for spatial reasoning and enabling dataset-independent generalization.

## Results

On 3D-FRONT (in-domain), I-Scene achieves the best object-level Chamfer Distance (0.0207) and F-Score (84.28), scene-level F-Score (93.50), and volumetric IoU (0.8762), outperforming all baselines. On the out-of-domain BlendSwap & Scenethesis benchmark, the advantage widens dramatically: I-Scene reaches a scene-level F-Score of 94.26 and IoU of 0.8568, versus 83.13 and 0.7412 for the next-best method (MIDI). Inference runs in 15.51 s per scene on a single H100, faster than MIDI (42.5 s), SceneGen (26.0 s), and Gen3DSR (179.0 s), though slower than PartCrafter (7.2 s).

## Baselines & Comparisons

I-Scene outperforms all four baselines on every reported metric across both in-domain (3D-FRONT) and out-of-domain (BlendSwap & Scenethesis) evaluations. Against MIDI (the closest competitor), I-Scene reduces object-level CD from 0.0877 to 0.0207 on 3D-FRONT and from 0.1884 to 0.0503 on BlendSwap/Scenethesis, while raising object-level F-Score by 14.2 and 21.6 points respectively; scene-level IoU improves from 0.8596→0.8762 (ID) and 0.7412→0.8568 (OOD). SceneGen and Gen3DSR trail substantially on all metrics, with Gen3DSR showing the weakest scene-level F-Score (42.31 ID, 45.43 OOD) and the longest runtime (179 s). PartCrafter is the fastest (7.2 s) and competitive on scene-level geometry (F-S 81.03 ID), but it lacks object-level evaluation and its IoU (0.7626 ID, 0.5819 OOD) remains well below I-Scene. The largest relative gains appear on the OOD benchmark, where dataset-bounded baselines degrade sharply while I-Scene's metrics stay close to its in-domain performance, confirming the paper's central claim about generalization from non-semantic synthetic training.

## Relation to Prior Work

I-Scene reprograms the TRELLIS pre-trained 3D instance generator by modifying only its sparse structure transformer, converting a single-object model into a scene-level spatial learner. It departs from prior learning-based scene generators (MIDI, SceneGen, PartCrafter) that learn layout distributions from curated datasets like 3D-FRONT, instead introducing model-centric spatial supervision via scene-context attention and a view-centric coordinate space that preserves camera-scene geometric relations. The non-semantic synthetic training strategy further distinguishes it from all prior methods that rely on semantically meaningful scene annotations, drawing a conceptual parallel to MegaSynth's use of synthetic data for 3D reconstruction.

## Why It Matters / Open Questions

The finding that purely geometric, non-semantic random compositions provide sufficient supervision for spatial reasoning (proximity, support, symmetry) challenges the field's assumption that curated scene annotations are necessary for layout learning, suggesting a scalable data pipeline for interactive 3D scene generation. The view-centric space formulation offers a clean architectural fix for a subtle failure mode (canonical space suppressing spatial sensitivity) that likely affects other image-to-3D scene methods. Open questions include whether the non-semantic scaling law holds across architectures and scene complexities, and how the method handles heavy occlusion and multi-view conditioning, which the authors acknowledge as current limitations.

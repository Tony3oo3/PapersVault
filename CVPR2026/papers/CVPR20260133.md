## Problem

Existing T2I benchmarks evaluate compositional reasoning, prompt adherence, and faithfulness but none systematically assess whether models can generate images matching specific colors specified in text prompts. Moreover, the VQA-based evaluation methods used by prior benchmarks are shown to be unreliable for color assessment, as VLMs lack consistent pixel-level color grounding and exploit linguistic heuristics rather than genuine perceptual reasoning.
![Teaser figure](../imgs/CVPR20260133/cropped_page3_idx0.webp)

## Input / Output

The benchmark consumes 44,464 text prompts specifying colors in three granularities (ISCC-NBS Level 1 basic names, Level 3 fine-grained names with modifiers, and CSS3/X11 web-standard names) plus numerical formats (RGB triplets and hex codes), paired with 108 objects across 7 semantic categories. Each prompt yields 4 generated images (1024×1024 for diffusion models, 384–512 for AR models), and the evaluation pipeline produces a binary correctness score per image based on whether the extracted dominant color falls within a Just Noticeable Difference threshold of the ground-truth color, requiring all three perceptual metrics to pass simultaneously.

## Method

GenColorBench organizes evaluation into five tasks (Color Name Accuracy, Color-Object Association, Multi-Object Color Composition, Implicit Color Association, and Numerical Color Understanding) grounded in ISCC-NBS and CSS3/X11 color taxonomies. The evaluation pipeline first verifies object presence via VQA (Janus-1.3B), then segments objects using Grounded SAM with negative IoU filtering to exclude irrelevant sub-regions (e.g., car lights, windshields). For color scoring, the paper adopts the vision-science dominant hue concept: RGB pixels are transformed to CIELuv, PCA is applied to chromatic components to identify the primary hue direction, and projected means yield the dominant color. This dominant color is compared against a candidate set (nominal color plus k perceptually nearest neighbors) using three complementary metrics—Delta Chroma in CIELab, CIEDE2000 perceptual distance, and MAE Hue with chroma-based reliability gating—each thresholded at JND values to produce a binary score.

## Results

On GenColorBench (44,464 prompts), no model exceeds 70% on any task. For Color Name Accuracy (ISCC-L1), PixArt Alpha leads at 68.78%, followed by SD 3.5 (64.37%) and Sana (62.89%). Performance drops sharply for more complex tasks: Color-Object Association peaks at 34.23% (OmniGen2), Multi-Object Color Composition at 23.78% (OmniGen2), Implicit Color Association at 28.22% (BLIP3o), and Numerical Color Understanding at 43.20% (BLIP3o). Across all tasks, fine-grained ISCC-L3 and CSS3/X11 specifications yield 20–40 percentage-point drops relative to basic ISCC-L1 colors.

## Baselines & Comparisons

No single model dominates all five tasks. PixArt Alpha leads Color Name Accuracy (68.78% ISCC-L1) but trails significantly on Color-Object Association (21.54%) and Multi-Object Composition (9.54%). OmniGen2 is the strongest on spatial color tasks—Color-Object Association (34.23%) and Multi-Object Composition (23.78%)—outperforming the next-best SD 3.5 by 1.3 and 2.2 points respectively. BLIP3o, a unified multimodal model, is the clear leader on Numerical Color Understanding (43.20% ISCC-L1, 23.65% L3), nearly doubling the runner-up OmniGen2 (26.38% L1), and also tops Implicit Color Association (28.22%). SD 3.5 offers the most balanced profile, placing in the top-3 on CNA, COA, and MOC simultaneously. Autoregressive models (Janus Pro, OmniGen2) generally underperform diffusion models on basic color naming but are competitive on association tasks, while the CoT-based Bagel model shows strong ICA (25.37%) and NCU (22.51%) relative to its CNA score (60.08%). Overall, the gap between best and worst models on any single task exceeds 25 percentage points, and all models remain below 35% on the most demanding tasks (MOC, ICA, NCU), indicating substantial room for improvement.

## Relation to Prior Work

This paper departs from the dominant VQA-based evaluation paradigm used by prior T2I benchmarks (GenEval, T2I-CompBench, DPG-Bench) by introducing a color-science-driven protocol grounded in CIELAB/CIELUV colorimetry and the vision-science concept of dominant hue. It builds on the Davidsonian Scene Graph framework for object-level verification and on Grounded SAM for segmentation, but replaces VLM-based color judgment with objective perceptual distance metrics (Delta Chroma, CIEDE2000, MAE Hue). The color taxonomy is anchored in established naming systems (ISCC-NBS, CSS3/X11) and uniquely extends evaluation to numerical color specifications (RGB, hex), a dimension entirely absent from all prior T2I benchmarks.

## Why It Matters / Open Questions

GenColorBench fills a clear gap: no prior benchmark systematically evaluates color precision across multiple granularities and specification formats, yet color fidelity is non-negotiable in professional design and media workflows. The finding that VLMs—currently the standard evaluation tool—are fundamentally unreliable for fine-grained color perception (with MCQ stability analysis revealing linguistic heuristics rather than perceptual reasoning) challenges a widespread methodological assumption and motivates pixel-level evaluation protocols. Open questions include how to improve fine-grained color control (especially '-ish' modifiers and numerical specs), how to decouple color from biologically-intrinsic object identity, and whether the observed LAION-2B training-data bias can be corrected through targeted data curation or architectural changes.

## Problem

Existing automated graphic design systems either produce non-editable raster images via text-to-image models or simplify the design process by jointly predicting all layer attributes at once with shallow hierarchies and limited attribute types. Neither approach emulates the iterative, concept-grouped, progressive refinement workflow that human designers actually follow, resulting in limited flexibility, poor text accuracy, and inability to handle complex product-level designs with deep layer structures and rich effects.

## Input / Output

The system takes a free-form user instruction (English or Chinese) as input and produces an editable PSD-format design file with complex nested layer hierarchies (averaging ~48 layers per file), supporting 5 layer types (including smart objects and adjustment layers) and over 60 attribute types (effects, blending modes, clipping masks, etc.). Internally, the system operates by generating a sequence of structured tool calls (function calls with named parameters) that are executed via Adobe's UXP JavaScript API, with over 70 available tools for inserting layers, applying effects, and modifying attributes. The iterative process alternates between asset-integration calls and layer-refinement calls, with intermediate renders fed back as observations at each step.

## Method

PSDesigner decomposes the design task into three coordinated components: AssetCollector (an LLM that identifies visual concepts and gathers image/text assets), GraphicPlanner (a VLM that predicts tool calls), and ToolExecutor (a UXP-based engine that manipulates the PSD file). GraphicPlanner is built on Qwen2.5-VL-7B with mode-specific LoRA adapters for two distinct operations: X_gen (harmoniously integrating a new asset given the current group's metadata and render) and X_edt (detecting and refining inferior layers by comparing the current render against the pre-group render). Training is two-stage: supervised fine-tuning on the newly constructed CreativePSD dataset (10,454 PSD files annotated with operation traces, covering diverse scenarios and styles), followed by GRPO reinforcement learning that rewards correct tool names and parameter values. The overall workflow performs a bottom-up traversal over the nested layer hierarchy, iteratively integrating each asset and then refining the group until all assets are placed, closely mirroring the progressive, concept-grouped workflow of human designers.

## Results

On the primary graphic design task (250 user instructions, English and Chinese), PSDesigner achieves VLM scores of 7.62 (Quality), 8.68 (Layout), 7.78 (Relevance), 8.02 (Harmony), and 8.45 (Innovation), with human scores of 8.09, 9.12, 7.17, 7.72, and 6.98 respectively. On the Crello-v5 composition task, PSDesigner scores 7.85 (Quality), 7.43 (Layout), 6.77 (Harmony), and 6.94 (Innovation), outperforming LaDeCo on all metrics except Harmony (6.77 vs. 7.22). The system produces editable PSD files with an average of ~48 layers per design, compared to the 4–5 layers typical of prior datasets and methods.

## Baselines & Comparisons

PSDesigner dominates on Layout (8.68 VLM) and Innovation (8.45 VLM), outperforming all five baselines by at least 0.1 and up to 5.0 points (vs. FLUX on Layout). Against OpenCOLE, the only other method producing editable output, PSDesigner leads by 2.5–3.2 points on every metric, reflecting its ability to handle complex multi-layer hierarchies versus OpenCOLE's single image layer plus simple text layers. On Quality, PSDesigner (7.62) trails CanvaGPT (8.52), FLUX (8.18), and PosterCraft (7.95), which generate high-fidelity raster images but lack editability. On Relevance, PosterCraft (8.42) edges out PSDesigner (7.78), while CanvaGPT scores lowest (4.72). On the Crello-v5 composition task, PSDesigner beats LaDeCo by 1.9 points on Quality and 1.4 on Layout, though LaDeCo retains a 0.45-point edge on Harmony, likely due to its simpler attribute space.

## Relation to Prior Work

This paper departs from two established lines of automated graphic design: T2I-based methods (TextDiffuser, AnyText, GlyphDraw) that produce non-editable raster images, and MLLM-based methods (LaDeCo, COLE, IGD) that generate editable files but rely on simplified category-based grouping (underlay/text) and one-shot attribute prediction. PSDesigner instead emulates the human creative workflow by grouping layers by visual concept, iteratively integrating assets with a bottom-up traversal, and performing per-step refinement of inferior elements. The system repurposes the VLM function-calling paradigm (Qwen2.5-VL + LoRA + GRPO) to predict Photoshop tool calls, and introduces CreativePSD—the first dataset built on the PSD format with annotated operation traces—bridging the gap between prior datasets (~5 layers, 2–7 attribute types) and real professional files (~48 layers, 60+ attribute types).

## Why It Matters / Open Questions

By producing genuinely editable PSD files with complex layer hierarchies, effects, and masks, PSDesigner addresses a practical gap that raster-based and simplified-JSON approaches cannot fill, making it directly usable in professional design pipelines. The CreativePSD dataset (10,454 files with operation traces) is a significant resource that could enable future work on design reasoning, layout planning, and tool-use learning beyond this specific system. Open questions include whether the iterative refinement loop scales efficiently to very large compositions, how well the system generalizes to design domains underrepresented in CreativePSD, and whether the GRPO-trained tool-call predictions remain robust when the tool set or PSD schema evolves.

## Problem

Existing monocular depth estimators produce a single depth map, which is inherently ambiguous for transparent surfaces where one pixel can correspond to multiple depths along the same camera ray. Prior work either treats transparent objects as opaque (predicting only the front surface) or ignores the transparent surface entirely (predicting only the background), but real-world perception systems need both simultaneously. Additionally, the natural depth-ordered grouping of multi-layer depths into maps can produce incoherent structures in complex scenes, and the optimal grouping is highly scene-dependent.

## Input / Output

The method takes a single RGB image as input and outputs a variable-length sequence of per-pixel depth values (one per visible surface layer along each camera ray), sorted in increasing order at inference time. The number of layers varies by pixel and by scene. During training, the predicted depth values are not required to be sorted; the model freely determines the ordering, and the loss is permutation-invariant so that any assignment of depths to output maps is equally valid.

## Method

SeeGroup combines a recurrent decomposition module with an intensity-based depth formulation. The recurrent module iteratively extracts n=4 feature components from a DINOv2-ViT-L backbone (initialized from Depth Anything V2) using a decomposer that isolates the dominant depth-layer group and a remapper that subtracts the explained portion, encouraging each component to specialize in a separate depth range. Each component is mapped to the center and scale of a Laplace distribution, and the per-pixel depth intensity is defined as the max-mixture of these Laplace components, which locally suppresses secondary modes and prevents collapse into a single broad peak. Training uses a permutation-invariant likelihood loss (product of intensity values at ground-truth depths), a component-coverage loss that penalizes spurious components unsupported by any ground-truth depth, and a gradient-matching loss for fine detail. At inference, multi-layer depths are extracted by detecting peaks along the depth axis of the intensity function.

## Results

On the LayeredDepth real-world benchmark (zero-shot evaluation), SeeGroup achieves 70.09% quadruplet (Q), 74.88% triplet (T), and 82.62% pair (P) tuple-wise accuracy on the All subset, improving quadruplet accuracy over the strongest prior method Multi-head (DA v2) from 61.34% to 70.09% — a 14.26% relative gain. SeeGroup outperforms all four baselines on 14 of 15 evaluation metrics across the All, Mixed, Layer 1, Layer 3, and Layer 5 subsets. On the LayeredDepth-Syn validation set (in-domain), SeeGroup is slightly behind Multi-head (DA v2) on AbsRel for Layer 1 (9.82 vs 8.24) but achieves substantially lower RMS on deeper layers (e.g., 24.42 vs 37.97 on Layer 3).

## Baselines & Comparisons

All four baselines come from the LayeredDepth paper [46] (Wen et al., ICCV 2025), which introduced the multi-layer depth benchmark and three architectural variants (Multi-head, Index Concat, Recurrent) built on either NeWCRFs or Depth Anything V2 backbones. SeeGroup decisively outperforms the three NeWCRFs-based baselines across every metric, with quadruplet accuracy jumping from 23–27% to 70.09% on the All subset. Against the strongest prior method, Multi-head (DA v2), which shares the same DINOv2-ViT-L backbone, SeeGroup improves quadruplet accuracy by 8.75 absolute points (61.34% → 70.09%) and triplet accuracy by 4.31 points (70.57% → 74.88%), while matching pair accuracy (82.62% vs 82.56%). The only metric where SeeGroup trails Multi-head (DA v2) is Layer 3 pair accuracy (69.14% vs 72.87%), a 3.73-point gap on a single subset. Notably, SeeGroup achieves these gains with fewer parameters (356M total, 51M excluding encoder) compared to Multi-head (428M, 124M) and GRU (731M, 427M), as reported in Table 4.

## Relation to Prior Work

This paper extends monocular depth estimation (building on Depth Anything V2 / DINOv2 backbones) to the multi-layer setting for transparent objects, a task formalized by the LayeredDepth benchmark [46]. It departs from prior multi-layer depth methods that adopt a fixed depth-ordered grouping strategy by introducing a self-determined, permutation-invariant grouping learned end-to-end. The recurrent decomposition module and the max-mixture-of-Laplace intensity formulation are novel architectural and parameterization choices not present in prior transparent-object depth work, which typically predicts only a single depth layer (either the glass surface or the background).

## Why It Matters / Open Questions

Multi-layer depth is essential for robotics applications involving transparent containers, glass walls, and layered scenes, where a single depth map is inherently ambiguous. The 14.26% relative gain in quadruplet accuracy and the parameter efficiency of the recurrent decomposition module (51M params vs. 124M/427M for baselines) make this a practically useful advance. However, the task remains data-limited (14.8K synthetic training images), over-prediction of spurious layers persists, and performance on out-of-distribution real scenes degrades, leaving significant room for improvement in robustness and generalization.

## Problem

VLMs often answer classic visual illusions correctly on original images yet persist with the same responses when illusion factors are inverted, even though the visual change is obvious to humans. Prior studies noted this asymmetry but relied on averaged accuracy that masks critical sensitivity patterns, leaving the underlying causes—memory override, perception-memory competition, or visual-processing limits—unresolved and unmeasured.

## Input / Output

Each evaluation case pairs a visual illusion image (one of four types: original, perturbed with inverted factors at graded strength α, matched control with inducers removed, or hinted with overlay cues) with a text question in one of three linguistic variants (forward, reversed polarity, or instructional). Model outputs are binary yes/no answers, which are then decomposed into paired-response consistency metrics (PFC, TFI, PFA) and an illusion multiplier R that normalizes the Original→Perturbed accuracy drop against the corresponding drop on matched controls, isolating illusion-specific effects from general visual complexity.

## Method

VI-Probe is a controllable evaluation framework built on 27 classical optical illusions (size, color, geometry) with parametric generation of perturbed images at 10 graded strength levels, matched visual controls that remove illusion-inducing cues while preserving global layout, and hinted variants with overlay alignment marks. On the linguistic side, each image is paired with forward, polarity-reversed, and instruction-augmented question variants to probe language priors independently of visual evidence. The key diagnostic metric is the Illusion Multiplier R, which divides the illusion-condition accuracy drop by the control-condition drop, yielding R>1 (memory override), R≈1 (perception-memory competition), or R<1 (visual-processing bottleneck). Combined with Polarity-Flip Consistency and Template Fixation Index for linguistic robustness, this factor-isolated paradigm enables attribution of response persistence to specific mechanisms rather than a single language-prior explanation. All 15 models across four families (GPT-5, Claude, Gemini, Qwen) are evaluated zero-shot via API under unified prompting.

## Results

On VI-Probe, GPT-5 achieves 91.72% accuracy on original illusions but collapses to 4.45% on perturbed (factor-inverted) illusions (drop: 87.27%), yielding an illusion multiplier R=1.97 that signals complete memory override. Claude-Opus-4.1 shows perception-memory competition (R=1.01) with dose-dependent illusion accuracy (22%→40% across perturbation strengths), while Qwen2.5-VL-3B exhibits a visual-processing bottleneck (R=0.13) with near-identical degradation on illusions and controls. Notably, Claude-Haiku-4.5 (R=0.23) is the only model whose perturbed-illusion accuracy (50.66%) exceeds its original-illusion accuracy (45.52%), confirming perception-first processing.

## Baselines & Comparisons

The paper positions VI-Probe against three prior illusion benchmarks (HallusionBench, IllusionVQA, VLMBiased) primarily on dataset design features rather than head-to-head model accuracy. HallusionBench [17] provides 15 cases with 72 original and 72 perturbed images but lacks visual controls, visual hints, language variations, and fine-grained metrics (PFC, R). IllusionVQA [32] covers 20 cases with 374 images but offers zero perturbed images and no controls, limiting it to static illusion recognition. VLMBiased [36] includes 6 cases with 198 original and 198 perturbed images but similarly lacks matched controls and the illusion multiplier metric. VI-Probe differentiates itself by providing 27 cases with arbitrary (unlimited) sample generation, matched visual controls that remove illusion inducers, visual hints, reversed/instructional language variants, and the R metric that normalizes illusion effects against controls—enabling factor-isolated diagnosis of memory override vs. perception-memory competition vs. visual-processing limits that none of the prior benchmarks can capture.

## Relation to Prior Work

This paper extends the line of visual-illusion evaluation for VLMs established by HallusionBench, IllusionVQA, and VLMBiased, which all report static accuracy on fixed illusion images. It departs from these by introducing a controllable generation pipeline with graded perturbation strengths, matched visual controls (illusion inducers removed), and linguistic variations (reversed-polarity questions, instructional prompts), enabling factor-isolated probing rather than aggregate scoring. The new metrics (Polarity-Flip Consistency, Template Fixation Index, Illusion Multiplier R) borrow the contrast-set idea from NLP evaluation [15] and apply it to the vision-language setting, creating a diagnostic framework that prior illusion benchmarks lacked.

## Why It Matters / Open Questions

The paper challenges the dominant single-cause narrative (language priors explain all illusion persistence) by demonstrating heterogeneous mechanisms across model families: memory override in GPT-5, perception-memory competition in Claude, and visual-processing bottlenecks in Qwen. This has direct implications for VLM training (counterfactual consistency objectives, perception-first architectures) and evaluation design (probing-based metrics beyond average accuracy). Open questions include whether findings generalize beyond classic illusions to real-world scenes (charts, medical images), whether the zero-shot API setting captures the full picture, and how to architecturally separate perception from recall in VLMs.

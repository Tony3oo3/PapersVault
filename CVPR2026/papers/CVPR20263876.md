## Problem

Existing diffusion-based object removal methods often fail to eliminate associated visual effects such as shadows and reflections, hallucinate unwanted content in removed regions, and unintentionally alter the background. These failures stem from the lack of explicit modeling of the correlation between a target object and its effects, as well as the absence of effective constraints to guide generative attention toward removal regions. Additionally, no large-scale dataset with paired images and precise object-effect masks was publicly available for training and evaluation.

## Input / Output

The method takes a 512×512 RGB image, a binary object mask, and a fixed text prompt ('remove the instance of') as input, and produces a full-resolution edited image with both the object and its associated effects (shadows, reflections) removed while preserving background color and texture. Notably, the original unmasked image is fed into the diffusion model rather than a masked version, and the object mask is used to extract a visual object prompt via element-wise dot product with the input image, which is then encoded by CLIP alongside the text prompt.

## Method

ObjectClear is built on SDXL-Inpainting and introduces three key mechanisms. First, Adaptive Target-Aware Attention (ATA) integrates CLIP-encoded text and visual object embeddings as cross-attention guidance, supervised by a mask loss that minimizes attention in background regions and maximizes it in foreground object-effect regions, enabling the model to decouple foreground removal from background reconstruction. Second, Attention-Guided Fusion (AGF) leverages the ATA-predicted attention maps at inference time to alpha-blend the generated output with the original image, preserving fine-grained background details. Third, Spatially-Varying Denoising Strength (SVDS) applies DS=1.0 within the masked object region and DS=0.99 in the background to achieve complete removal while preventing global color shifts. The model is trained on the newly constructed OBER dataset (12,715 samples combining camera-captured and simulated data with precise object-effect masks) using supervised fine-tuning at a learning rate of 1e-5 for 100k iterations.

## Results

On OBER-Test, ObjectClear achieves PSNR 33.04, PSNR-BG 35.62, LPIPS 0.0342, and CLIP distance 0.0103, substantially outperforming the next-best method OmniPaint (PSNR 29.06, PSNR-BG 30.04, LPIPS 0.0521, CLIP 0.0152). On RORD-Val, ObjectClear reaches PSNR 26.24 and PSNR-BG 29.78, surpassing GeoRemover (PSNR 24.38, PSNR-BG 26.47) and OmniPaint (PSNR 22.75, PSNR-BG 24.66). On the in-the-wild OBER-Wild benchmark (no ground truth), ObjectClear scores 0.8470 on ReMOVE†, slightly below OmniPaint (0.8656) but above all other methods. Notably, ObjectClear uses only an object mask as input, yet outperforms methods that are given both object and effect masks.

## Baselines & Comparisons

ObjectClear outperforms all 11 baselines on PSNR, PSNR-BG, LPIPS, and CLIP distance across both RORD-Val and OBER-Test, using only an object mask as input. The closest competitor is OmniPaint, which trails by 3.49 dB in PSNR and 5.58 dB in PSNR-BG on OBER-Test, and by 3.49 dB in PSNR on RORD-Val. GeoRemover, which leverages depth geometry, achieves the second-best PSNR on RORD-Val (24.38) but still lags ObjectClear by 1.86 dB and struggles on OBER-Test (PSNR 24.92 vs. 33.04). Attentive Eraser and RORem, both diffusion-based object removal methods, show strong object removal but fail to eliminate associated effects, resulting in PSNR-BG values 5+ dB below ObjectClear. On the ground-truth-free OBER-Wild benchmark, OmniPaint narrowly edges out ObjectClear on ReMOVE† (0.8656 vs. 0.8470), while all other methods score below 0.82. The paper also reports that ObjectClear with object mask alone surpasses several methods (e.g., PowerPaint, Attentive Eraser) that are given the more informative object-effect mask, highlighting the effectiveness of the ATA mechanism in implicitly localizing effect regions.

## Relation to Prior Work

ObjectClear extends the diffusion-based object removal line (SDXL-Inpainting, PowerPaint, BrushNet, RORem, OmniEraser, OmniPaint) by introducing explicit supervision over object-effect regions via an Adaptive Target-Aware Attention mechanism, rather than relying on implicit learning of shadows and reflections. It departs from prior inpainting-based approaches by feeding the original (unmasked) image into the U-Net and using CLIP-encoded object crops as cross-attention prompts, decoupling foreground removal from background reconstruction. The OBER dataset fills a gap identified in the literature: no prior large-scale dataset provides paired images with precise masks covering both objects and their associated visual effects, combining camera-captured realism with scalable simulation.

## Why It Matters / Open Questions

The OBER dataset (12,715 samples with object-effect masks) and the OBER-Wild benchmark provide the community with the first large-scale, publicly available resource for training and evaluating effect-aware object removal, a practical need that prior small-scale or non-public datasets (ObjectDrop, RORD) could not meet. The Attention-Guided Fusion strategy—reusing training-time attention maps as a soft inpainting mask at inference—is a lightweight, generalizable trick that could transfer to other diffusion-based editing tasks. Open questions include whether the approach scales beyond 512×512 resolution, extends to video object-effect removal, and generalizes to effects beyond shadows and reflections (e.g., caustics, ambient occlusion).

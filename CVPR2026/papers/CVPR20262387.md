## Problem

The dominant feed-forward 3DGS paradigm regresses Gaussian means as depths along camera rays and ties the number of primitives to input resolution and view count, which limits robustness to pose noise, prevents scene completion beyond observed views, and creates massive redundancy (e.g., 8M+ particles for 32 views at 512×512). Additionally, directly optimizing Gaussian parameters at test time degrades the network's learned priors, particularly in low-view regimes.

## Input / Output

The method takes N posed RGB images (e.g., 2–6 views at 256×256 or 448×256) along with their camera extrinsics and intrinsics, and outputs a fixed set of 3DGS particles (e.g., 1024 or 4096 tokens × 64 Gaussians each = 66K–262K particles) whose count is a hyperparameter independent of input resolution or view count. For dynamic scenes, it additionally produces time-conditioned dynamic Gaussians that yield emergent scene flow. The key structural difference from prior work is that the output particle count does not scale with the number of input views or their resolution.

## Method

TokenGS replaces the standard encoder-only design with a ViT encoder–DETR-style decoder architecture in which a fixed set of learnable Gaussian tokens cross-attend to patchified image tokens (augmented with Plücker coordinates) to predict 14-dimensional 3DGS attributes per token. Instead of regressing depth along camera rays, the model directly predicts 3D mean coordinates in a global frame, trained solely with a self-supervised rendering loss (MSE + SSIM) plus a novel visibility loss that penalizes Gaussians projecting outside all supervision views, thereby solving the zero-gradient problem for inactive particles. For dynamic scenes, tokens are split into static and time-conditioned dynamic sets with a causal attention mask so dynamic tokens attend unidirectionally to static ones, enabling static-dynamic decomposition and consistent temporal tracking. At test time, the architecture supports two forms of scaling: context extension (more input views without changing particle count) and token-tuning (fine-tuning only the token embeddings for ~50 gradient steps while freezing all network weights), which improves reconstruction while preserving learned priors.

## Results

On RealEstate10K (2 views, 256×256), TokenGS with 4096 tokens achieves 28.41 PSNR / 0.903 SSIM, and with token-tuning reaches 28.82 PSNR / 0.910 SSIM, outperforming GS-LRM (28.10 PSNR) while using only 262K Gaussians vs. 131K for baselines. On DL3DV (448×256), the 4-view model scores 23.02 PSNR (23.57 with TT) and generalizes to 6 views at 24.51 PSNR with TT, surpassing DepthSplat (24.19) with 72% fewer Gaussians. For dynamic scenes on Kubric 4D, TokenGS achieves 24.84 PSNR, beating BTimer (24.45) on PSNR though trailing on LPIPS (0.287 vs. 0.162).

## Baselines & Comparisons

Against MVSplat, TokenGS consistently wins on PSNR across all view counts on DL3DV (e.g., 23.02 vs. 21.63 at 4 views; 24.51 vs. 22.93 at 6 views with TT) and on RE10K (28.41 vs. 26.39), while using roughly half the Gaussians. Against DepthSplat, the base 4-view model is slightly behind (23.02 vs. 23.12 PSNR), but token-tuning closes and reverses the gap (23.57 vs. 23.12); at 6 views, TT pushes TokenGS ahead (24.51 vs. 24.19) with 72% fewer primitives. Against GS-LRM on RE10K, TokenGS leads in PSNR (28.41 vs. 28.10) and SSIM (0.903 vs. 0.892) but trails in LPIPS (0.135 vs. 0.114), suggesting slightly less perceptual fidelity despite better geometric quality. For dynamic scenes, TokenGS beats BTimer on PSNR (24.84 vs. 24.45) but lags substantially on LPIPS (0.287 vs. 0.162), indicating that while geometric accuracy improves, perceptual quality of motion rendering still has room for improvement.

## Relation to Prior Work

TokenGS departs from the dominant pixel-aligned 3DGS prediction paradigm (MVSplat, DepthSplat, GS-LRM) where Gaussian means are regressed as depths along camera rays, instead directly predicting 3D coordinates in a global frame using a DETR-style encoder-decoder with learnable Gaussian tokens. The decoder architecture borrows the query-token cross-attention design from DETR, while the dynamic scene formulation (time-conditioned tokens with causal attention masking) is adapted from BTimer's bullet-time reconstruction. The direct coordinate regression is conceptually aligned with VGGT's point-map prediction but is trained purely through self-supervised rendering loss plus a novel visibility regularizer, avoiding the need for explicit 3D supervision.

## Why It Matters / Open Questions

By decoupling the number of predicted Gaussians from input resolution and view count, TokenGS offers a two-dimensional scalability knob (views × tokens) that pixel-aligned methods lack, and enables test-time refinement via lightweight token tuning that preserves learned priors—addressing a known failure mode of directly optimizing Gaussian parameters. The emergent scene flow and static-dynamic decomposition from the causal attention structure is a useful byproduct for dynamic reconstruction. Open questions include whether the approach scales to large-scale outdoor scenes, whether joint token-and-Gaussian optimization can close the remaining gap to per-scene optimization, and whether the visibility loss generalizes to sparse or highly occluded view configurations.

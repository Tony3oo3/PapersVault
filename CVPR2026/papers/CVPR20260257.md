## Problem

Feed-forward 3D reconstruction networks produce dense but geometrically inconsistent point maps, exhibiting multi-layer artifacts and spatial drift especially in out-of-domain settings. Existing geometry-guided refinement approaches either depend on unrealistic SfM supervision (pseudo-SfM from ground truth or densely captured video) or operate in 2D image space, failing to enforce true cross-view 3D geometric consistency.
![Teaser figure](../imgs/CVPR20260257/cropped_page0_idx0.webp)

## Input / Output

The method takes N sparse RGB images (4, 8, or 16 views) as input, which are consumed jointly by a feed-forward multi-view transformer (for dense point maps and camera initialisation) and dense feature matchers (RoMa, UFM) for multi-view correspondences. The output is a refined dense 3D point cloud with per-point confidence scores, processed in spatially local patches of up to 400k points normalised to the unit cube, with overlapping patches averaged at inference time.

## Method

GGPT operates in two stages. First, an improved SfM pipeline extracts dense correspondences via RoMa/UFM, performs sparse bundle adjustment on a compact set of high-confidence tracks (initialised from feed-forward predictions) to refine camera poses, then applies multi-view DLT triangulation to reconstruct a geometrically consistent but incomplete sparse point cloud X_s. Second, an 8-layer Point Transformer V3 backbone jointly processes the dense feed-forward prediction X_d and the sparse geometric guidance X_s in a shared 3D coordinate space, using specialised encodings PE(x_{d→s}) and Δ_{d→s} that explicitly encode the positional offset between each dense point and its corresponding guidance point. The model predicts residual displacements and confidence scores via a shared MLP head, trained with a heteroscedastic confidence-weighted regression loss plus an identity-consistency anchoring term. Unlike prior 2D depth-completion methods, GGPT performs attention on 3D spatial proximity rather than pixel coordinates, enabling true cross-view geometric consistency with only 53M parameters.

## Results

On the primary within-domain benchmark (ScanNet++, 4 views), GGPT applied to VGGT lifts AUC@5/10 cm from 23/37% to 38/53%, and on the cross-domain ETH3D (4 views) from 27/41% to 41/55%. On out-of-domain human-body (4D-DRESS) and surgical (MV-dVRK) datasets, the gains are even more dramatic: VGGT+GGPT reaches 66/77% AUC@1/5 cm on 4D-DRESS versus 10/45% for VGGT alone, and 45/61% AUC@1/5 mm on MV-dVRK versus 8/33%. In the geometry-conditioned model comparison (Table 3, ETH3D 8-view), GGPT with the authors' SfM achieves 47/61% AUC@5/10 cm, outperforming the best 2D baseline (POW3R at 32/45%) by 15/16 points.

## Baselines & Comparisons

GGPT consistently improves every feed-forward and hybrid baseline it is applied to. On VGGT, the largest gains appear on cross-domain ETH3D (27→41 AUC@5) and T&T (26→34), while on the within-domain ScanNet++ the jump is 23→38. For Pi3, which is already strong on ScanNet++ (54/69), GGPT provides only marginal gains in-domain but substantial cross-domain improvements (ETH3D 31→36, T&T 25→27). MapAnything benefits most dramatically on ETH3D (10→32 AUC@5) and T&T (10→29), where its feed-forward predictions are weakest. MAtCha and MASt3R-SfM, both hybrid forward-optimisation methods, also see large absolute gains (e.g., MAtCha on ScanNet++ 12→27; MASt3R-SfM 12→30). In the direct geometry-conditioned model comparison (Table 3), GGPT (47/61) outperforms all 2D depth-completion baselines—Murre (26/40), OMNI-DC (31/44), POW3R (32/45), and MapAnything (27/40)—when given the same SfM guidance, confirming the advantage of 3D-space attention over 2D image-space refinement. The authors' SfM pipeline also outperforms MASt3R-SfM and VGGSfM in camera pose accuracy and point accuracy (Fig. 4) while running faster.

## Relation to Prior Work

GGPT sits at the intersection of two well-developed lines of work: feed-forward multi-view 3D reconstruction (DUSt3R, MASt3R, VGGT, Pi3, MapAnything) and geometry-conditioned depth completion (Murre, POW3R, OMNI-DC). It departs from prior geometry-conditioned methods in two key ways: (1) it replaces unrealistic SfM supervision (pseudo-points from ground truth or dense video sequences) with a practical SfM pipeline built from sparse input views using dense matchers (RoMa, UFM) and a decoupled sparse-BA + DLT strategy; and (2) it moves the refinement from 2D image-space depth completion to a 3D point transformer (PTv3 backbone) that reasons over spatial proximity rather than pixel coordinates. The architecture builds directly on Point Transformer V3, adapted with geometric encodings (positional offsets Δ_{d→s} and guidance-point PE) that make the network aware of the correspondence between dense and sparse points.

## Why It Matters / Open Questions

GGPT provides a drop-in, training-free refinement module that can be attached to any feed-forward 3D reconstruction model at inference time, making it broadly practical for applications where geometric consistency is critical (surgical planning, AR, robotics). The strong cross-architecture and cross-domain generalisation (trained only on ScanNet++/VGGT, yet improving Pi3, MapAnything, MAtCha, and MASt3R-SfM on outdoor, human-body, and surgical scenes) suggests the 3D-space refinement principle is architecture-agnostic. Open questions include scalability to very large or dynamic scenes, the computational cost of dense matching (which dominates runtime), and whether the patch-based processing introduces seams at patch boundaries in highly non-uniform scenes. The improved SfM pipeline is also independently useful for any application requiring accurate sparse geometry from limited views.

## Problem

Reconstructing complete, persistent 4D scenes with multiple interacting static and dynamic objects from monocular video remains unsolved: existing methods either handle a single object at a time, rely on category-specific parametric models, or require expensive test-time optimization. The fundamental obstacle is the extreme scarcity of in-the-wild 4D multi-object training data with object-level decomposition, making direct supervised learning infeasible.
![Teaser figure](../imgs/CVPR20260714/cropped_page0_idx1.webp)

## Input / Output

The method takes a monocular video from a fixed camera as input, extracting DINOv2 image embeddings per frame and SAM-based object masks for each dynamic entity. Static objects are conditioned on background-subtracted scene embeddings, while dynamic objects use per-frame masked embeddings. The output is a set of per-object 3D mesh latents (one latent per static object, one per dynamic object per frame) that decode via a shape VAE into SDF/mesh representations, supporting arbitrary video lengths through a sliding temporal window.

## Method

COM4D trains a single 21-block DiT (built on TripoSG's shape VAE and rectified flow framework) via Attention Parsing: even-indexed blocks learn multi-instance spatial attention on 3D-FRONT static scenes, while odd-indexed blocks learn multi-frame temporal attention on DeformingThings single-object animations, with Diffusion Forcing (independent noise per latent) enabling history-guided generation. At inference, Attention Mixing alternates these block roles within each denoising step—spatial blocks perform multi-instance attention across all objects in a frame using the global scene embedding, then temporal blocks perform multi-frame attention per dynamic object using its masked frame embeddings—thereby composing spatial and temporal reasoning without ever having seen a compositional 4D example during training. The model is fully fine-tuned from TripoSG weights over two stages (8k + 12k steps) on a single H200 GPU, with 30% of iterations reserved for monolithic single-object regularization to preserve the learned shape prior.

## Results

On DeformingThings (4D object), COM4D achieves CD 0.1144, F-Score 0.8388, and IoU 0.4191, substantially outperforming the next-best method TripoSG (CD 0.1558, F-Score 0.5179, IoU 0.1784) by ~26% in CD and ~2.4× in IoU. On Objaverse, COM4D attains the best F-Score (0.7349) and IoU (0.3413) while remaining competitive in CD (0.1205 vs. TripoSG's 0.1107). For 3D scene reconstruction on 3D-FRONT, COM4D achieves the best CD (0.0909) and F-Score (0.8069), surpassing MIDI (CD 0.1445) and PartCrafter (CD 0.1751). In the user study for compositional 4D, COM4D with Attention Mixing is preferred over the no-mixing baseline by a factor of 12 (87% vs. 6.9%).

## Baselines & Comparisons

COM4D outperforms all four 4D object baselines on DeformingThings across every metric, with the largest gap over TripoSG (the strongest frame-wise baseline): IoU improves from 0.1784 to 0.4191 and F-Score from 0.5179 to 0.8388. On Objaverse, COM4D wins on F-Score and IoU but trails TripoSG slightly on CD (0.1205 vs. 0.1107), suggesting marginally less surface-level proximity at the cost of better shape completeness. Among Gaussian-based methods, L4GM and GVFD are the weakest, with CD values 2–2.5× higher than COM4D and no IoU reported due to lack of watertight meshes. For 3D scene reconstruction, COM4D beats both MIDI and PartCrafter on CD and F-Score on 3D-FRONT (CD 0.0909 vs. 0.1445 and 0.1751), and maintains the advantage on the harder 3D-FRONT-Occluded split (CD 0.1256 vs. 0.1781 and 0.1951). PartCrafter is the fastest baseline (2.60 s) but produces partial or low-quality meshes, while MIDI struggles with occlusions; COM4D matches PartCrafter's speed (2.63 s) while delivering superior geometry.

## Relation to Prior Work

COM4D builds directly on TripoSG's DiT + shape-VAE + rectified-flow architecture for single-object 3D generation, extending it to multi-object and multi-frame settings. The alternating spatial/temporal attention design draws on PartCrafter's in-part/inter-part attention for 3D scenes and on Diffusion Forcing's mixed-noise training for temporal coherence, but the key departure is the 'Attention Parsing' training strategy: a single model is trained on two entirely separate datasets (static multi-object scenes from 3D-FRONT and single-object dynamics from DeformingThings) with complementary block roles, then combined at inference via 'Attention Mixing' without ever seeing compositional 4D data. This contrasts with prior 4D scene work (L4GM, GVFD, V2M4) that either handles a single deforming object, relies on category-specific parametric models, or requires per-scene test-time optimization.

## Why It Matters / Open Questions

COM4D is, to the authors' knowledge, the first method to produce object-decomposed, persistent 4D scene reconstructions from monocular video without test-time optimization, opening a path toward scalable in-the-wild 4D scene understanding. The attention parsing/mixing paradigm is generalizable: any problem requiring the combination of independently learned spatial and temporal (or other orthogonal) reasoning could potentially adopt this disentangled-training-then-mix-at-inference recipe. Key limitations remain: the model assumes a fixed camera, lacks explicit physical causality (struggling with occluded object trajectories), and the primary compositional-4D evaluation relies on a user study rather than a standard quantitative benchmark, leaving the true generalization gap to unseen object interactions partially unmeasured.

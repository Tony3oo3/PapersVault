## Problem

Self-supervised 3D semantic occupancy learning from images is limited by two dominant paradigms: rendering-based methods that provide only indirect geometric signals through 2D reconstruction, and lidar-based methods that rely on discretized voxel grids, capping spatial precision and scalability. No prior approach supervises geometry and semantics directly in continuous 4D space-time, leaving a gap in how explicitly and efficiently 3D structure can be learned without manual labels.
![Teaser figure](../imgs/CVPR20261707/cropped_page0_idx0.webp)

## Input / Output

The model consumes multi-view RGB images (224×704 for the base model, 900×1600 for QueryOcc+) with known camera intrinsics and extrinsics, and optionally a lidar point cloud for geometric supervision. Supervision is generated from pseudo point clouds (via Metric3D depth + Grounded-SAM labels) or real lidar, sampled across adjacent frames to form 4D queries. The output is a continuous occupancy field: for any 4D query [x, y, z, t], the model returns an occupancy probability and a semantic class label over 15 categories, evaluated at Occ3D voxel centers (0.4 m resolution, ±40 m lateral/longitudinal, [−1, 5.5] m vertical).

## Method

QueryOcc is a four-stage pipeline: a ConvNeXt-Base image encoder, a Lift-Contract-Splat (LCS) module that lifts per-pixel features into a contractive BEV grid, a BEV processor using ResBlocks and multi-scale deformable attention, and a unified lightweight decoder that answers arbitrary 4D queries. The LCS module extends Lift-Splat-Shoot with three innovations: explicit point encoding of visibility/uncertainty, log-linear depth binning for balanced near-far resolution, and an axis-aligned spatial contraction that compresses coordinates beyond 40 m into a fixed BEV grid, enabling unbounded-range supervision at constant memory. Self-supervision is applied directly in 4D: positive queries are sampled in a buffer behind each point cloud point, negative queries along the ray from sensor origin to the point, across adjacent frames, yielding 800k queries per sample from 30k points. The decoder predicts occupancy (BCE), semantics (categorical CE), and optionally VFM features (L1) in a single shared forward pass, achieving 11.6 FPS on an A100.

## Results

On the Occ3D-nuScenes benchmark, QueryOcc achieves 23.6 semantic RayIoU, 21.7 dynamic RayIoU, and 45.2 occupancy RayIoU, surpassing the strongest baseline GaussianFlowOcc (18.7 / 17.2 / 36.0) by +26% in semantic RayIoU and +25% in occupancy RayIoU. The enhanced variant QueryOcc+ (high-res input, camera-lidar supervision, VFM feature distillation) pushes further to 25.8 / 23.8 / 47.4 RayIoU. QueryOcc also leads on IoU metrics (21.3 Sem., 13.2 Dyn., 55.0 Occ.) and runs at 11.6 FPS with 86 ms total latency on an A100, outpacing GaussianFlowOcc (10.2 FPS).

## Baselines & Comparisons

QueryOcc outperforms all eight baselines on every reported metric. Against the strongest prior method GaussianFlowOcc (ICCV 2025), QueryOcc gains +4.9 semantic RayIoU (23.6 vs 18.7), +4.5 dynamic RayIoU (21.7 vs 17.2), and +9.2 occupancy RayIoU (45.2 vs 36.0), while also running faster (11.6 vs 10.2 FPS). The rendering-based methods (SelfOcc, OccNeRF, DistillNeRF, LangOcc) trail by 10–13 points in semantic RayIoU, confirming the paper's hypothesis that 2D rendering supervision provides weaker geometric signals than direct 3D query supervision. Among Gaussian-splatting methods, GaussTR-T2D (14.2 Sem. RayIoU) and GaussianOcc (11.9) are further behind, with GaussTR additionally requiring VFM features at inference. The lidar-assisted MinkOcc (12.5 Sem. RayIoU) is also surpassed, showing that QueryOcc's camera-only pseudo-point-cloud supervision is competitive with explicit lidar voxelization. QueryOcc+ extends the lead by combining camera-lidar supervision and VFM feature distillation, reaching 25.8 Sem. RayIoU and 56.9 Occ. IoU, the best results across all methods tested.

## Relation to Prior Work

QueryOcc departs from the two dominant self-supervised occupancy paradigms: rendering-based camera-only methods (which learn 3D structure implicitly via 2D photometric consistency) and lidar-based methods (which rely on discretized voxel grids). It builds directly on the Lift-Splat-Shoot (LSS) formulation for lifting image features to BEV, but extends it with a contractive scene representation and point-wise encoding to handle unbounded scenes. Furthermore, it adapts the query-based decoding paradigm from lidar-centric self-supervised works (like UnO and GASP) to the camera-only setting, replacing dense voxel supervision with continuous 4D spatio-temporal queries.

## Why It Matters / Open Questions

This work demonstrates that direct 4D query supervision can outperform indirect rendering-based supervision by a significant margin (26% in semantic RayIoU) while maintaining real-time inference speeds. The contractive BEV representation offers a practical solution to the memory scalability problem of unbounded 3D scenes. However, the approach remains fundamentally limited by sensor observability, struggling to represent occluded regions, which points to future work in collaborative multi-agent supervision or consistency-based representation learning for unobservable spaces.

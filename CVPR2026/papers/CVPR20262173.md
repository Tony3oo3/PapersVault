## Problem

In federated-by-camera person ReID, each client corresponds to a single camera and thus captures only a sparse, highly correlated set of poses per identity. This intra-client pose homogeneity starves contrastive learning (especially triplet loss) of the hard positive and negative pairs it needs, causing local models to overfit to camera-specific viewpoints and triggering severe client drift that degrades the aggregated global model. Existing FedReID methods address inter-client heterogeneity but do not explicitly synthesize the missing intra-identity pose diversity within each client.

## Input / Output

The method consumes RGB person images from a single surveillance camera per client, processed through a ResNet-50 backbone into spatial feature maps (d×h×w). The Pose-Extraction Module operates on these feature maps to produce a channel-wise attention vector (d×1×1) that splits each map into pose-relevant and pose-irrelevant components; an off-the-shelf MMPose detector provides r-dimensional oracle pose vectors for distillation supervision. The final output is a d-dimensional feature embedding (via average pooling) used for cross-camera retrieval ranking, with the PEM discarded at inference so latency matches the baseline.

## Method

The framework proceeds in three stages: (i) a local-expert model is trained per client on its own data to capture camera-specific pose patterns; (ii) a two-layer Pose-Extraction Module (PEM) is trained to disentangle feature maps into pose-relevant and pose-irrelevant components via a channel-wise sigmoid attention, supervised by a pose-relationship knowledge distillation loss that aligns pairwise cosine-similarity structures with an oracle pose detector (excluding same-identity pairs via a binary mask to prevent trivial identity-correlated solutions) and a cyclic consistency loss that enforces semantic preservation after swapping pose components between different-identity samples; a compatibility regularization term trains the same PEM on features from both the local-expert and the local-global model to prevent overfitting to one client's distribution; (iii) the local-global model is trained with the original features plus pose-swapped augmented features, which act as hard positives (same identity, different pose) and hard negatives (different identity, similar pose) for triplet loss, directly injecting the pose diversity missing from the single-camera data.

## Results

On Market1501 under the federated-by-camera setting (6 clients), the proposed method achieves 45.9 mAP and 66.4 Rank-1, outperforming the best federated ReID baseline MEDA (41.4 mAP, 66.1 Rank-1) by 4.5 mAP. On MSMT17 (15 clients), it reaches 14.5 mAP and 32.7 Rank-1, surpassing MEDA (9.7 mAP, 24.8 Rank-1) by 4.8 mAP and 7.9 Rank-1. The centralized upper bound remains substantially higher (77.3 mAP / 90.0 Rank-1 on Market1501), but the proposed method narrows the gap more than any prior federated approach. Inference latency is unchanged from the baseline (0.96 ms) since the Pose-Extraction Module is used only during training.

## Baselines & Comparisons

The proposed method outperforms all nine baselines on both datasets and both metrics. Against the strongest federated ReID baselines, it beats MEDA by 4.5 mAP on Market1501 and 4.8 mAP on MSMT17, and surpasses DACS by 5.9 mAP (Market1501) and 3.1 mAP (MSMT17). Among general federated learning methods, MOON is the closest competitor (33.2 mAP on Market1501, 13.2 mAP on MSMT17), yet the proposed method still leads by 12.7 and 1.3 mAP respectively. Feature-augmentation baselines (BDB, ISE) perform poorly because they are designed for centralized settings and do not generate pose-diverse hard samples. The paper attributes the gap to the federated-by-camera scenario's severe intra-client pose homogeneity, which undermines triplet-loss-based contrastive learning; the proposed pose-swapped feature synthesis directly addresses this by injecting hard positives and negatives with novel poses into each client's training batch.

## Relation to Prior Work

This paper builds on the FedAvg federated training protocol and positions itself within the Federated ReID (FedReID) literature established by FedPav, specifically targeting the federated-by-camera scenario where each client corresponds to a single camera. It departs from prior FedReID methods (DACS, MEDA) that address data scarcity through pixel-level stylization or meta-knowledge augmentation by instead operating in feature space: a Pose-Extraction Module disentangles pose-relevant and pose-irrelevant components, and pose-swapped features are synthesized to create hard contrastive pairs. The approach also diverges from general FL methods (MOON, FedProx, SCAFFOLD) that regularize inter-client drift, arguing that the fundamental bottleneck is intra-client pose homogeneity rather than inter-client heterogeneity.

## Why It Matters / Open Questions

The paper identifies pose diversity as the specific bottleneck in federated-by-camera ReID (rather than general data scarcity), which provides a more targeted diagnosis for practitioners designing federated surveillance systems. The method is practically attractive: it adds only 0.53M parameters, incurs zero inference overhead, and requires no pixel-level generation. Open questions include whether the pose-disentanglement strategy generalizes to other critical attribute dimensions (occlusion, clothing, viewpoint), whether it works with transformer backbones, and how it scales to larger numbers of clients or more extreme non-IID distributions. The reliance on an off-the-shelf pose estimator (MMPose) as a teacher also raises questions about robustness in deployment settings where pose estimation quality varies.

## Problem

Existing traffic-rule benchmarks (DriveQA, IDKB) evaluate only single atomic rules using 2D static images, creating an illusion of model competence that masks failures in real driving where multiple regulations coexist or conflict. There is no systematic benchmark that measures MLLMs' ability to perform compositional traffic rule reasoning—integrating multiple static constraints, reasoning about dynamic agent interactions, and resolving rule conflicts—across a graduated cognitive hierarchy.

## Input / Output

Each evaluation instance provides 4 RGB frames (K=4) captured from a front-facing camera in the CARLA simulator, a natural-language scenario description, and a four-option multiple-choice question; the model outputs a single letter selection. A DriveCombo-Text variant replaces the visual frames with the textual scene description alone, isolating language-based reasoning from visual perception. The 70K questions are organized into five cognitive levels (L1–L5), with L1 covering single atomic rules and L5 requiring priority-based conflict arbitration among competing obligations.

## Method

The core contribution is a Rule2Scene Agent with two modules. The Rule Crafter decomposes compound traffic codes from 5 countries into atomic rules, semantically structures each as (content, perceptual type, action type, norm type), forms action-consistent rule pairs, labels them with derived perceptual/normative/hierarchical attributes to assign cognitive levels L1–L5, and validates spatiotemporal coexistence via LLM-based filtering. The Scene Weaver then converts each hierarchical rule into a textual scenario description, translates it into a structured semantic representation (entities, spatial relations, environmental conditions) following the Target DSL schema, maps it to an OpenSCENARIO file, and renders it in CARLA to produce the visual inputs. The resulting benchmark is evaluated zero-shot on 14 MLLMs, and the authors further test three reasoning-augmentation strategies (CoT, RAG, SFT) plus downstream E2E trajectory planning on nuScenes to validate the dataset's transferability.

## Results

On DriveCombo, the best proprietary model (GPT-5 pro) achieves 86.91% accuracy on L1 (single-rule) but drops to 44.19% on L5 (conflict resolution), while the best open-source model (GLM-4.5V, 106B) scores 80.44% and 41.86% respectively. All 14 evaluated MLLMs exhibit a consistent monotonic decline across the Five-Level Cognitive Ladder, with L5 accuracy ranging from 25.10% (Qwen3-VL 2B) to 44.19% (GPT-5 pro), far below the >98% human baseline. On the text-only variant (DriveCombo-Text), models gain ~3–5 percentage points, yet the best model (GPT-5 pro) still reaches only 47.42% on L5. Fine-tuning on DriveCombo reduces downstream E2E trajectory L2 error on nuScenes by 17.3% compared to DriveQA fine-tuning (e.g., 2.68 m vs. 2.91 m average for LLaVA-1.6-Mistral-7B).

## Baselines & Comparisons

The primary baseline comparison is against DriveQA [43] (ICCV 2025), the closest prior traffic-rule benchmark, on downstream end-to-end trajectory planning over nuScenes. DriveCombo fine-tuning consistently outperforms DriveQA fine-tuning: for LLaVA-1.6-Mistral-7B, average L2 error drops from 2.91 m (DriveQA) to 2.68 m (DriveCombo), and for InternVL-2.5-8B from 2.71 m to 2.53 m, corresponding to a 17.3% relative reduction in L2 loss. Both improvements are observed across all prediction horizons (1 s, 2 s, 3 s), with the largest gains at the 3 s horizon (e.g., 4.54 → 3.92 m for LLaVA). In addition, DriveQA and IDKB [19] are positioned as prior traffic-rule benchmarks in Table 1, but they cover only single-rule (#Rules = 1) and 2D static imagery, whereas DriveCombo supports ≥1 rules in 3D dynamic scenes, making direct head-to-head QA comparison infeasible; the E2E planning transfer experiment in Table 5 serves as the concrete quantitative comparison.

## Relation to Prior Work

This paper extends the line of traffic-rule-focused driving benchmarks (DriveQA, IDKB) that evaluate single-rule understanding via 2D static images, by introducing compositional multi-rule reasoning with a hierarchical Five-Level Cognitive Ladder (L1–L5) and 3D dynamic CARLA scenes. Structurally, it builds on the Target [8] DSL for structured scene generation and leverages the CARLA simulator for scene rendering, but departs from prior work by constructing rule pairs with explicit normative relations (harmony vs. conflict) and spatiotemporal coexistence validation. The Rule2Scene Agent pipeline—combining LLM-based rule crafting with simulation-based scene weaving—is a novel contribution that closes the loop from abstract traffic regulations to executable visual scenarios.

## Why It Matters / Open Questions

The benchmark reveals a stark and consistent performance cliff: even top proprietary models (GPT-5 pro, Claude Sonnet 4.5) drop from ~85–87% on single-rule tasks to ~44% on L5 conflict resolution, far below the 98% human baseline, exposing a fundamental bottleneck in compositional regulatory reasoning. The finding that fine-tuning on DriveCombo reduces downstream E2E trajectory L2 error by 17.3% on nuScenes suggests that structured traffic-rule knowledge is transferable to planning, offering a practical pathway toward more compliant driving agents. Key limitations include reliance on CARLA's limited 3D asset library and the fact that even SFT only lifts L5 accuracy to ~60%, leaving open whether larger-scale or architecturally different models can close the gap to human-level conflict arbitration.

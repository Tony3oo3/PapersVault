## Problem

Existing sparse concept recovery methods for interpretable image classification treat all concept embeddings as flat, ignoring the hierarchical (hypernym–hyponym) structure of semantic concepts. This can yield correct class predictions paired with explanations that violate the hierarchy (e.g., selecting 'vehicle' when explaining a cat). The paper asks how to incorporate hierarchical structure into both the embedding geometry and the sparse pursuit algorithm so that recovered concepts always form a valid root-to-leaf path.
![Teaser figure](../imgs/CVPR20262131/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image, extracts its embedding via a frozen vision-language model (CLIP or SigLIP), and matches it against a fixed hierarchical dictionary built from a pre-defined synset hierarchy (WordNet for ImageNet/ImageNette, LLM-induced taxonomy for CIFAR-100). The output is a class label plus the recovered root-to-leaf concept path; the sparsity level is set to the hierarchy depth (e.g., 14 for WordNet, 5 for CIFAR-100), so the explanation is a chain of exactly depth-many concepts from root to leaf rather than an arbitrary subset.

## Method

HCEP has two components. First, a geometric embedding model imposes three conditions on synset vectors: (i) descendants of each node lie within a cone around the parent with a geometrically decreasing half-angle schedule, (ii) child–parent difference vectors are orthogonal to the parent embedding, and (iii) sibling difference vectors form a regular simplex; the paper proves these conditions are empirically satisfied in CLIP embeddings. Second, the pursuit algorithm (HB-OMP) constructs a dictionary of parent–child embedding differences and performs a coarse-to-fine beam search: at each level only children of the current node are eligible for selection (path-restricted extension), and the top-B partial paths are retained by residual norm to mitigate error accumulation. This guarantees the recovered support is always a valid root-to-leaf path, unlike standard OMP which can select atoms from unrelated branches.

## Results

On ImageNet (sparsity 14, 12-shot), HCEP (HB-OMP) consistently outperforms all interpretable baselines in both classification accuracy and support precision/recall as the number of images per class decreases. On CIFAR-100 (sparsity 5) and ImageNette (sparsity 4), HCEP achieves state-of-the-art support precision and recall while maintaining comparable classification accuracy to baselines. In the few-shot regime, the gap widens: HCEP's hierarchical inductive bias provides the largest gains when labeled examples are scarce, since it only requires averaging CLIP image embeddings to estimate synset representations rather than training a full concept classifier.

## Baselines & Comparisons

HCEP (HB-OMP) outperforms standard OMP [8, 54] on all three datasets in support precision and recall, with the advantage growing in few-shot settings because path-restricted extension prevents spurious atom selections that violate the hierarchy. Against Concept Bottleneck Models [29], HCEP achieves higher classification accuracy in the few-shot ImageNet regime (e.g., 12-shot) because CBMs require learning a concept predictor from labels while HCEP only needs to average pre-trained CLIP embeddings. HCEP also surpasses the Hierarchical NN baseline, which traverses the hierarchy via nearest-neighbor search at each level, by leveraging sparse coding to recover the full root-to-leaf path rather than committing to a single nearest neighbor at each step. The plain Nearest Neighbor classifier (a black-box baseline) is not directly comparable on interpretability metrics but serves as an accuracy reference; HCEP maintains competitive accuracy while providing faithful hierarchical explanations. Overall, HCEP wins on interpretability metrics (support precision/recall) across all settings and wins on classification accuracy specifically in the few-shot regime.

## Relation to Prior Work

This paper extends the sparse concept recovery framework for interpretable image classification (Chattopadhyay et al., 2023; Bhalla et al., 2024) by incorporating the hierarchical structure of concept taxonomies into both the dictionary construction and the pursuit algorithm. The dictionary is built from parent-child embedding differences rather than raw concept embeddings, and the pursuit algorithm (HB-OMP) is a beam-search variant of Hierarchical OMP (Jost et al., 2006; La & Do, 2006) that restricts selection to children of the current node. The geometric design of the embedding space draws on recent work on hierarchical orthogonality in large language model representations (Park et al., 2025), which the authors verify empirically holds in CLIP image embeddings as well.

## Why It Matters / Open Questions

The paper provides a clean geometric framework (well-clustered cones, hierarchical orthogonality, simplex structure) that gives sufficient conditions for unique parent assignment and reliable path recovery, bridging the gap between the flat sparse coding used in prior interpretable classification and the structured nature of real concept taxonomies. The few-shot advantage is practically relevant: when labeled data is scarce but a pretrained VLM is available, the hierarchy acts as a strong inductive bias that supervised concept predictors (CBMs) cannot match. Open questions include how well the framework handles DAG-structured hierarchies (e.g., WordNet synsets with multiple parents), whether the geometric conditions hold in other VLMs beyond CLIP/SigLIP, and whether the approach scales to very deep or high-branching hierarchies without the beam width growing prohibitively.

## Problem

Personalizing visual generative models via LoRA fine-tuning requires hours of per-task optimization and task-specific data, making it impractical for real-time user adaptation. Existing hypernetwork approaches that predict LoRA weights directly rely on lossy compression (autoencoders, matrix decomposition) to simplify the learning problem, which limits them to narrow scenarios like subject identity and fails on fine-grained prompts or high-dimensional video LoRAs. The open challenge is predicting complete, uncompressed LoRA weights from diverse user inputs (text, pose, style, face) within seconds.

## Input / Output

The hypernetwork takes the frozen base model's weight matrices W as explicit input (along with learnable block-position and block-type embeddings), and integrates the user prompt—text, 2D pose sequence, style image, or face image—via cross-attention. The output is the full, uncompressed LoRA parameter pair (B ∈ R^{m×r}, A ∈ R^{r×n}) for every target layer, which is added directly to the base weights as ΔW = BA. Unlike prior hypernetwork methods that output compressed latent codes, LoFA predicts the complete LoRA parameters at native dimensionality, preserving full model expressiveness.

## Method

The core insight is that LoRA weights exhibit structured 'response maps': the ratio |Δw_i / w_i| between LoRA and base model parameters is sparse (50–80% of parameters change by <2%), and the spatial pattern of significant changes is task-specific. LoFA exploits this with a two-stage transformer hypernetwork: Stage-I predicts the binary response map R (which parameters are significantly adapted) using cross-entropy loss, while Stage-II inherits Stage-I's backbone and uses its final-layer features as cross-attention guidance to predict the full B and A matrices. Stage-II is trained with a weighted combination of L1 reconstruction loss on LoRA parameters and a Flow Matching diffusion loss that injects predicted LoRAs into the base denoising model for task-level supervision. This design avoids brute-force prompt-to-LoRA mapping by learning relative adaptations from base weights, and the response map guidance stabilizes learning while preserving full LoRA expressiveness without compression.

## Results

On Identity-Personalized Image Generation (SDXL), LoFA achieves Face Similarity 0.548, DINO 0.497, CLIP-I 0.600, and Face Diversity 50.3, outperforming all baselines while completing inference in 3.7 s (vs. 1 h for DreamBooth). On text-conditioned Personalized Human Action Video Generation (WAN2.1-1.3B), LoFA attains FVD 589.8, CLIP-T 0.3719, and Dynamic Degree 0.2283, surpassing per-case optimized LoRA (FVD 609.5) and dramatically outperforming Text-to-LoRA (FVD 907.5, D.D. 0.0745). On Text-to-Video Stylization, LoFA leads on all four metrics (CSD 0.427, CLIP-T 0.2943, D.D. 2.394, M.S. 0.9940) over per-case LoRA.

## Baselines & Comparisons

LoFA outperforms per-case optimized LoRA [16] on every task and metric: on video action generation it reduces FVD from 609.5 to 589.8 and improves CLIP-T from 0.3662 to 0.3719; on stylization it raises Dynamic Degree from 2.107 to 2.394; and on identity generation it lifts Face Sim from 0.488 to 0.548. Against Text-to-LoRA [4] (the only direct-prediction baseline applicable to video), LoFA is dramatically superior, cutting FVD from 907.5 to 589.8 and boosting Dynamic Degree from 0.0745 to 0.2283. On identity-personalized image generation, LoFA beats both hypernetwork baselines—DiffLoRA [53] (Face Sim 0.461, DINO 0.427) and HyperDreamBooth [38] (Face Sim 0.527, DINO 0.462)—on all four quality metrics while being 5.4× faster than DiffLoRA and 74× faster than HyperDreamBooth. Compared to DreamBooth [37], LoFA improves Face Sim by 0.060 and Face Diversity by 3.0 points while reducing adaptation time from 1 hour to 3.7 seconds. Overall, LoFA wins or ties on every reported metric across all three tasks, with the largest margins observed against the direct-prediction baselines that rely on lossy LoRA compression.

## Relation to Prior Work

This paper extends the hypernetwork-based LoRA prediction line (HyperDreamBooth, DiffLoRA, Text-to-LoRA) by removing the lossy compression step that all prior methods rely on, instead predicting full-rank LoRA weights directly. Its key architectural departure is the two-stage design: first predicting a binary 'response map' (a 2%-threshold mask of relative parameter changes) as an intermediate target, then using that map's features to guide final LoRA prediction. The dual-objective training (reconstruction + diffusion loss) is inherited from HyperDreamBooth, while the use of base model weights as input with cross-attention conditioning on user prompts distinguishes it from prompt-only input approaches.

## Why It Matters / Open Questions

By reducing personalization time from hours (per-case LoRA fine-tuning) to under 4 seconds, LoFA makes real-time, user-driven adaptation of visual generative models practically viable for the first time, and extends this capability to video generation—a setting no prior fast-adaptation method has addressed. The response map insight provides a reusable inductive bias for high-dimensional weight prediction that could generalize beyond LoRA to other adapter paradigms. Open questions include whether the 2% threshold and response map structure hold for substantially larger models (e.g., 14B+ video models), whether the approach scales to multi-concept or compositional personalization, and how sensitive performance is to the diversity and volume of training LoRA pairs.

## Problem

Existing 3DGS semantic segmentation methods propagate geometric corrections only through alpha-blending radiance, leaving partially visible or non-visible Gaussians unmodified. These hidden Gaussians extend beyond object boundaries and produce artifacts when objects are extracted and reused in new scenes. Prior geometry-refinement approaches (COB-GS, ObjectGS, Trace3D) all share this fundamental limitation because every gradient or heuristic decision is governed by the radiance each Gaussian receives.

## Input / Output

The method takes posed RGB images (used to train a 2DGS scene for 30K iterations) and 2D semantic segmentation masks obtained via SAM2's two-stage retrieval, which are then refined through a multiview reprojection step that lifts 2D pixels to 3D and reprojects them across all views to enforce boundary consistency. The output is a 3D Gaussian scene where each Gaussian carries a non-trainable class label and whose geometry has been optimized so that individual object extraction yields clean boundaries. The voxel grid used by the occupancy loss is precomputed once before the 3K-iteration fine-tuning phase, and voxels where multiple classes collide are treated as empty.

## Method

BEA-GS introduces two complementary losses added to the 2DGS training objective. The 2D Boundary Loss propagates gradients through the standard alpha-blending rasterizer and penalizes only the portions of visible Gaussians that contribute to pixels of a different class, requiring just a single extra channel per Gaussian regardless of the number of classes (unlike ObjectGS which needs one per class). The 3D Occupancy Loss bypasses the rasterizer entirely: it uniformly samples Z=20 points from each Gaussian's surface in UV space, queries a precomputed class-specific voxel grid (with adaptive voxel size derived from k-NN density), and penalizes any sample falling in an unoccupied neighborhood, thereby shrinking or repositioning non-visible Gaussians that would otherwise appear as spikes upon extraction. A multiview reprojection module improves cross-view mask consistency before optimization. The full pipeline trains 2DGS for 30K iterations, then adds both losses for an additional 3K iterations with weights λ_bound=0.5 and λ_occ=10, achieving near-zero PSNR degradation while producing the cleanest extracted boundaries across four datasets.

## Results

BEA-GS achieves the best Extracted 3D Metrics (Acc, IoU, BIoU) across all four datasets, outperforming 12 state-of-the-art baselines in 21 out of 24 evaluated cases. On Mip-NeRF 360, it reaches 99.1% Acc, 92.0% IoU, and 85.8% BIoU (extracted), surpassing the next best (COB-GS: 98.5/86.9/78.0) by a notable margin, especially on BIoU (+7.8). On 3DOVS, BEA-GS attains 99.7% Acc, 93.2% IoU, and 87.3% BIoU, again leading all competitors. Rendering quality is preserved with near-zero PSNR degradation (e.g., Mip-NeRF 360: 29.1→29.1, 3DOVS: 26.7→26.5).

## Baselines & Comparisons

BEA-GS consistently outperforms all 12 baselines on the Extracted 3D Metrics (the primary evaluation for object extraction quality) across all four datasets. The largest gains appear on the BIoU metric, which specifically measures boundary quality: on Mip-NeRF 360, BEA-GS achieves 85.8% BIoU versus 78.0% for COB-GS and 75.4% for Trace3D; on LeRF, 83.6% versus 80.1% for Trace3D and 75.6% for COB-GS. On 3DOVS (Table 2), BEA-GS leads on all three Extracted metrics (99.7/93.2/87.3) over Trace3D (99.4/90.2/81.1) and COB-GS (99.2/85.8/73.9). The one notable exception is the Rendered BIoU on 3DOVS, where ObjectGS (90.7) slightly edges out BEA-GS (87.8), though BEA-GS still leads on Rendered Acc and IoU. The ablation confirms both losses are complementary: removing the Occupancy Loss drops BIoU by ~1–4 points, while removing the Boundary Loss drops it by ~1–3 points, with the Multiview Reprojection module providing the largest single gain on occluded 360° scenes (Mip-NeRF 360: +10.8 BIoU over the vanilla baseline).

## Relation to Prior Work

This paper extends the line of geometry-modifying 3DGS segmentation methods (COB-GS, ObjectGS, Trace3D) that enforce per-Gaussian class consistency through radiance-based supervision. The key departure is identifying that alpha-blending's transmittance mechanism fundamentally prevents gradient flow to non-visible Gaussians, leaving them unmodified and causing boundary artifacts upon object extraction. BEA-GS addresses this gap with a 3D occupancy loss that bypasses the rasterizer entirely, using a voxel-grid visibility prior to directly penalize non-visible Gaussian regions, complemented by a boundary loss that operates through the rasterizer for visible regions. The base reconstruction uses 2DGS, and mask initialization follows the two-stage SAM2 procedure from COB-GS and the per-Gaussian class assignment from FlashSplat.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in 3DGS-based asset pipelines: extracted objects carry hidden Gaussians that produce artifacts when reused in new scenes. The dual-loss formulation (boundary + occupancy) is a clean, minimal addition requiring only 3K extra training iterations and a single extra channel per Gaussian, making it easy to integrate into existing 2DGS/3DGS workflows. Limitations include dependence on the initial reconstruction quality, inability to hallucinate unseen object parts, and reliance on ID-consistent 2D masks from SAM2. Open questions include whether the voxel-based occupancy loss scales to very large or dense scenes, and how the method interacts with diffusion-based completion for unseen regions.

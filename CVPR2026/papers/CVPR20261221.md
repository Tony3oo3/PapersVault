## Problem

Combining multiple object detection datasets is hindered by inconsistencies in class semantics (e.g., 'vehicle' vs. 'car/bus/truck') and bounding box conventions (e.g., cyclist+bicycle as one entity vs. two). Existing approaches either assume shared label taxonomies, address only spatial mismatches, or require costly manual relabeling, leaving no scalable method that jointly resolves both semantic and spatial inconsistencies in a many-to-one, fixed-target label projection setting.

## Input / Output

LAT consumes a triplet per target dataset: RGB images, ground-truth annotations in the target's native label space, and N−1 sets of cross-dataset pseudo-labels (each generated by a separate upstream model trained on a different dataset's label space). The output is a refined set of pseudo-labels for all source datasets projected into the target label space, ready for downstream detector training. During training, classification logits are masked to the current batch's label space; at inference, they are masked to the designated target label space, ensuring the final model operates exclusively in the target's annotation conventions.

## Method

LAT replaces the region proposal network in a two-stage detector (Faster R-CNN or RT-DETR) with a Privileged Proposal Generator (PPG) that injects both ground-truth and cross-dataset pseudo-label bounding boxes as proposals, exposing the RoI layer to overlapping regions from divergent label spaces. A Semantic Feature Fusion (SFF) module then refines region features via class-aware scaled dot-product attention over these overlapping proposals, where a confidence vector (1 for ground-truth, max classification score for pseudo-labels) weights the feature branch and a row-wise clamping threshold T=1/√N on the class branch suppresses independently occurring noisy predictions. A frozen DINOv2 backbone provides shared image features, and the entire system is trained collaboratively across all N datasets so that pseudo-labels from different sources reinforce each other while ground-truth annotations anchor supervision. This design avoids semantic drift inherent in ontology-based or embedding-based unification by operating directly at the region and feature levels, preserving fine-grained dataset-specific granularity while learning cross-space correspondences.

## Results

On the Class Divergence Benchmark (Cityscapes/nuImages/Waymo), LAT with FRCNN achieves 60.1/41.7/48.5 AP, outperforming the single-dataset baseline (55.2/39.2/44.6) by up to +4.9 AP on Cityscapes. On the Small-to-Large Dataset Benchmark, LAT delivers the largest gain on the smallest target dataset ACDC (+8.4 AP, 53.4 vs. 45.0 baseline), while large-source datasets (BDD100K, SHIFT) see minor drops that are recovered with longer training. LAT with RT-DETR further improves to 60.6/39.5/49.6 AP on the class-divergent benchmark, and incorporating SAM3 predictions yields the best overall results (61.0/39.6/49.9 AP).

## Baselines & Comparisons

LAT consistently outperforms all four baselines across both benchmark settings. Against Student-Teacher (semi-supervised), LAT gains +5.0 AP on Cityscapes and +4.3 AP on Waymo, while Student-Teacher actually falls below the single-dataset baseline on Cityscapes (55.1 vs. 55.2), confirming that domain gaps cause error propagation in teacher models. Against Pseudo-Label (simple label transfer), LAT improves by +3.2 AP on Cityscapes and +2.9 AP on Waymo, showing that the PPG and SFF modules add substantial value over naive pseudo-label filtering. Against Plain-DET (label unification via Deformable DETR), LAT's advantage is most dramatic: +8.4 AP on Cityscapes and +17.5 AP on nuImages, indicating that forcing a unified label space severely degrades fine-grained detection. Against SAM3 (VLM-based concept segmentation), LAT alone already matches or exceeds SAM3 on Cityscapes and Waymo, and LAT+SAM3 achieves the best scores overall (61.0/39.6/49.9 AP), with SAM3 contributing the largest boost on nuImages (+7.0 AP over SAM3 alone), suggesting VLMs are complementary but insufficient for spatial decomposition tasks.

## Relation to Prior Work

LAT extends the two-stage Faster R-CNN architecture by replacing the region proposal network with a Privileged Proposal Generator and adding a Semantic Feature Fusion module, while using a frozen DINOv2 backbone. Conceptually, it departs from both model-centric label unification (vision-language embeddings, ontology graphs) and prior data-centric label transfer (which assumed shared taxonomies or supported only one-to-one mapping) by treating cross-dataset pseudo-labels as privileged information that, combined with ground-truth anchors, enables many-to-one projection into a fixed target label space. The closest prior work (Liao et al., ICLR 2024) addressed spatial annotation mismatches but did not jointly resolve class-level semantic divergence, which LAT tackles through class-aware attention over overlapping proposals.

## Why It Matters / Open Questions

LAT offers a practical, architecture-agnostic recipe for practitioners who need to boost a small, task-specific detection dataset with larger external sources without manual relabeling or committing to a unified taxonomy. The +8.4 AP gain on ACDC and consistent improvements across class-divergent benchmarks demonstrate that joint semantic-spatial transfer is feasible and beneficial. Limitations include evaluation restricted to road-based driving datasets, the computational overhead of generating N(N−1) pseudo-label sets, and the observation that large source datasets can suffer minor performance drops without extended training. Open questions include scalability to dozens of datasets, applicability to non-driving domains, and whether the privileged-information framing generalizes to other detection paradigms beyond two-stage and DETR-style architectures.

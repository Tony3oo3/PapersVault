## Problem

Existing watermarking methods for generative AI embed a single holistic signature that cannot disentangle multiple overlapping concepts (e.g., a specific object rendered in a unique artistic style) within one generated image. Pixel-domain watermarks are fragile to common transformations, while latent-domain methods, though more robust, remain content-agnostic and lack a mechanism for targeted, per-concept retrieval. This gap leaves composed intellectual property—where multiple creators' concepts coexist in a single image—effectively unattributable.

## Input / Output

At inference, the system takes a watermarked RGB image and a short textual query prompt (e.g., "a photo of <sks-object>") that specifies which concept's secret to retrieve. The TokenTrace module outputs a predicted concept embedding in the CLIP text-embedding space, which a linear secret decoder then maps to a 16-bit binary vector (configurable from 5 to 64 bits). The query-based design means the same image can be queried multiple times with different prompts to independently verify each embedded concept, enabling disentanglement of up to four or more overlapping concepts from a single generation.

## Method

TokenTrace employs a dual-conditioning encoding strategy: a concept encoder perturbs the target concept token within the text prompt embedding, while a secret mapper perturbs the initial Gaussian noise, so the watermark is simultaneously embedded in both the semantic and latent domains before the diffusion model (Stable Diffusion 1.5) generates the image. For retrieval, the TokenTrace module fuses features from a frozen CLIP ViT-L/14 image encoder (processing the watermarked image) and a frozen CLIP text encoder (processing the query prompt) through trainable projection and cross-attention layers, producing a predicted concept embedding that a linear decoder maps back to the bit-secret. Training jointly optimizes all trainable components under a composite loss combining binary cross-entropy for secret recovery, a contrastive style descriptor (CSD) loss for semantic consistency, pixel-space L2 for imperceptibility, and an embedding regularization term, with only lightweight adapter layers updated while the large CLIP encoders remain frozen.

## Results

On the WikiArt style attribution task, TokenTrace achieves 91.67% attribution accuracy and 98.33% bit accuracy, outperforming the best proactive baseline CustomMark (89.25% / 95.59%) and the best passive baseline Abc (56.03%). On the large-scale ImageNet object attribution task (1000 classes), TokenTrace reaches 90.43% attribution accuracy and 95.82% bit accuracy, again surpassing CustomMark (87.12% / 93.11%) and ProMark (87.30% / 90.56%). For multi-concept attribution with four general concepts, TokenTrace achieves 81.57% attribution accuracy versus CustomMark's 72.78%, a gap of nearly 9 percentage points.

## Baselines & Comparisons

TokenTrace outperforms all seven baselines on both datasets. Against the closest proactive competitor CustomMark [4] (which also operates in the semantic domain), TokenTrace gains +2.42 pp attribution accuracy on WikiArt (91.67% vs 89.25%) and +3.31 pp on ImageNet (90.43% vs 87.12%). The pixel-domain proactive method ProMark [3] trails by 4.48 pp on WikiArt and 3.13 pp on ImageNet. All five passive baselines (ALADIN, CLIP, Abc, SSCD, EKILA) are far behind, with the strongest passive method Abc [41] reaching only 56.03% on WikiArt and 53.51% on ImageNet—gaps of over 35 pp. In the multi-concept setting (Table 2), the advantage widens: with four general concepts, TokenTrace achieves 81.57% attribution accuracy versus CustomMark's 72.78%, and with prompt weighting (TokenTraceP) the gap grows to 86.08% vs 72.78%, confirming that the query-based disentanglement mechanism is the key differentiator for compositional attribution.

## Relation to Prior Work

TokenTrace extends the semantic-domain proactive watermarking line initiated by CustomMark [4] and Guarding Textual Inversion [12], which embed signatures by modifying text prompt embeddings. Its key departure is a dual-conditioning strategy that simultaneously perturbs both the concept token in the text embedding and the initial latent noise, drawing on prompt-tuning ideas [19, 51] and latent-space watermarking [27, 43]. The query-based TokenTrace retrieval module, built on frozen CLIP encoders with lightweight trainable projections and attention, repurposes the adapter-based fine-tuning paradigm [16] for watermark decoding rather than standard feature extraction. Unlike pixel-domain methods (ProMark [3]) that embed a single holistic signal, TokenTrace separates concept signatures in the textual semantic domain before generation, fundamentally avoiding spatial overlap.

## Why It Matters / Open Questions

Multi-concept attribution addresses a practical gap in IP protection: when a generated image composes a specific character in a specific artist's style, existing methods cannot independently verify each creator's contribution. The query-based disentanglement mechanism is a clean and generalizable solution that could extend to video, 3D, or other modalities where multiple concepts co-occur. Limitations include evaluation only on Stable Diffusion 1.5 with 16-bit secrets, and the 4-concept general scenario still shows meaningful accuracy drops (86% best case). Open questions include whether the approach scales to dozens of simultaneously watermarked concepts, how it behaves under fine-tuning attacks on the base diffusion model, and whether the CLIP-based retrieval module generalizes to non-English or highly abstract concepts.

## Problem

Existing visual token pruning methods for LVLMs perform static, irreversible pruning at a single layer, permanently discarding tokens that may become critical in deeper layers. The paper demonstrates through empirical attention visualizations that different LLM decoder layers attend to distinct visual regions, meaning a fixed token subset is fundamentally suboptimal and leads to premature information loss that degrades generation quality.
![Teaser figure](../imgs/CVPR20260287/cropped_page1_idx1.webp)

## Input / Output

The method operates on standard LVLM inputs: RGB images encoded into variable-length visual token sequences (576 tokens for LLaVA-1.5, up to 2880 for LLaVA-NeXT with dynamic resolution) and text prompts embedded as textual tokens. At each decoder layer, a subset of visual tokens is dynamically selected for computation while the remainder skip that layer but remain available for subsequent layers. The output is a standard autoregressive text generation, with the key distinction that the effective number of visual tokens participating in computation varies per layer rather than being fixed after a single pruning event.

## Method

ALVTS introduces a lightweight token selector at each LLM decoder layer that computes importance scores via low-rank approximations (rank 128–256) of the self-attention query and key projection matrices, initialized via SVD of the original weights. Importance is scored as the product of visual-to-visual and text-to-visual average attention, ensuring tokens are retained only when relevant to both modalities. A top-k selection routes high-scoring tokens through the layer's full computation while low-scoring tokens skip the layer entirely; both streams are recombined (preserving original ordering) before the next layer, so no token is permanently lost. The selector is optimized per-layer by minimizing L2 distance between its approximate importance scores and oracle full-rank scores on a small calibration set (256 samples), updating only the low-rank selector parameters while keeping the base LVLM frozen. This yields a 1.6× prefill speedup at 89% token compression with 96.7% accuracy retention, without any model retraining.

## Results

On LLaVA-1.5-7B across 8 benchmarks, ALVTS achieves 99.60% average performance at 67% token reduction, 98.77% at 78%, and 96.73% at 89% (retaining only 64 of 576 tokens). At the most aggressive 89% compression, ALVTS outperforms the strongest baseline DART by 3.46 percentage points (96.73% vs. 93.27%) and FastV by 11.60 points. On LLaVA-NeXT-7B with up to 2880 input tokens, ALVTS retains 96.25% average performance at 89% reduction, and on Qwen2.5-VL-3B it achieves 86.39% at the same ratio. Efficiency-wise, ALVTS delivers a 1.6× prefill speedup and 1.35× end-to-end latency reduction while maintaining 97.7% accuracy on POPE.

## Baselines & Comparisons

ALVTS consistently outperforms all four baselines across every compression ratio and model architecture tested. Against FastV (ECCV 2024), which prunes tokens once after layer 2, ALVTS leads by 2.53 points at 67% reduction and by a substantial 11.60 points at 89% reduction (96.73% vs. 85.13%), demonstrating that single-layer static pruning causes severe information loss. Against VTW (AAAI 2025), which withdraws all visual tokens at a certain layer, ALVTS dominates by a very large margin (e.g., 96.73% vs. 52.98% at 89% on LLaVA-1.5-7B), as VTW's strategy of removing all visual tokens is fundamentally incompatible with tasks requiring visual grounding. Against PyramidDrop (CVPR 2025), which progressively drops tokens in a pyramid fashion, ALVTS leads by 1.41 points at 67% and 8.21 points at 89%, showing that even staged static pruning cannot match layer-wise dynamic selection. Against DART (EMNLP 2025), the strongest baseline using diversity-based token selection, ALVTS maintains a consistent 1.47–3.46 point advantage, with the gap widening as compression becomes more aggressive, confirming that dynamic per-layer selection is more effective than a single diversity-optimized subset.

## Relation to Prior Work

ALVTS departs from the dominant static token pruning paradigm (FastV, PyramidDrop, DART, VTW) in which tokens removed at one layer are permanently inaccessible to all subsequent layers. Instead, it repurposes the attention-based importance scoring already used by these methods but applies it dynamically at every decoder layer, allowing tokens to skip a layer while remaining available later. The lightweight selector is grounded in SVD-based low-rank approximation of query/key projections, a technique borrowed from matrix compression literature, and is fine-tuned via a simple L2 alignment loss on a small calibration set without touching the base model weights.

## Why It Matters / Open Questions

The 89% token compression with 96.7% accuracy retention and 1.6× prefill speedup makes LVLM inference substantially more practical for resource-constrained deployment, and the approach is architecture-agnostic (validated on LLaVA-1.5, LLaVA-NeXT, and Qwen2.5-VL). However, the method still requires a per-model calibration step (256 samples, ~15 min) and adds ~2% parameter overhead per layer, and it has only been tested on image-based LVLMs—extension to video or streaming settings where token counts are orders of magnitude larger remains open. Whether the low-rank selector's fidelity degrades under even more aggressive compression (e.g., >95%) or in very deep models is unexplored.

## Problem

Small objects in remote sensing images suffer from low color contrast and blurred edges, and existing feature-enhancement methods typically target only a single cue type or optimize features holistically without explicitly decoupling low-level color and edge signals. The paper addresses this gap by asking whether the complementary, hierarchical processing of color and form in the biological visual system (LGN/V1→V2→V4 for color; V1→V4 for edges) can be directly instantiated as a dual-backbone detection architecture to improve small-object detectability.

## Input / Output

The network consumes a single RGB remote sensing image and, after dual-pathway feature extraction and fusion, outputs axis-aligned bounding boxes with per-class confidence scores via a YOLO12-based detection head. The edge pathway internally generates a learned edge map from the RGB input through ELLOM before orientation-selective filtering, so the model operates on raw RGB without requiring pre-processed edge or color-channel inputs. The full model is lightweight at 2.59 M parameters and 52.44 GFLOPs, substantially smaller than most compared detectors.

## Method

BDNet builds a parallel dual-backbone CNN on top of an optimized YOLO12 baseline. The Color Information Path (CIP) first applies a Color Antagonism Module (CAM) that maps R/G/B to L/M/S cone channels, forms six excitation–inhibition opponent pairs, and uses a learnable Adaptive Selection Enhancement weight vector to amplify color differences; it then applies a Visual Cortex Hue Enhancement Module (VCHM) that performs grouped convolution, pairwise channel coupling via a Jordan-form kernel, and interleaved feature embedding to enrich hue representations in a V2-like hierarchy. The Edge Information Path (EIP) uses an Enhanced Learnable Laplacian Operator Module (ELLOM) with nine learnable weights to produce an adaptive edge map, followed by an Orientation Selective Module (OrSM) that applies eight Enhancement-Suppression Convolution Kernels (ESCK) and an adaptive directional selection sub-network that generates binary mask maps to suppress non-salient orientations, mimicking V1/V2 orientation tuning. A Feature Fusion Module (FFM) simulates V4 integration by computing an outer product of per-channel importance scores from both paths to form a rank-1 1×1 convolution kernel that injects color-channel semantics into edge features (and vice versa), with residual connections and channel concatenation to preserve feature diversity. The fused features feed a standard FPN and detection head for final box and class prediction.

## Results

On VisDrone2019, BDNet achieves 50.5% mAP50 and 31.2% mAP50-95 with only 2.59M parameters and 52.44 GFLOPs, outperforming all 13 compared methods while using roughly 4–35× fewer parameters than the nearest competitors. On NWPU VHR-10, it reaches 94.1% mAP50 (vs. 93.9% for RS-YOLO and 93.8% for MaskFormer) with the most balanced per-category performance. On AI-TODv2, BDNet attains the best score on every reported metric: 24.7 AP, 54.9 AP50, 18.2 AP75, 10.2 APvt, 31.7 APs, and 41.8 APm.

## Baselines & Comparisons

On VisDrone2019, BDNet (50.5% mAP50) surpasses the closest competitors LUFE-Net (50.2%) and UAV-DETR (50.0%) by 0.3 and 0.5 points respectively, while using only 2.59M parameters versus 9.7M and 21.26M. On NWPU VHR-10, BDNet's 94.1% mAP50 edges out RS-YOLO (93.9%) and MaskFormer (93.8%), with particularly strong gains on low-contrast categories (BC: 99.5 vs. 92.7 for RS-YOLO) and edge-heavy categories (BD: 99.5 vs. 97.8). On AI-TODv2, BDNet wins on all six COCO metrics, most notably AP75 (18.2 vs. 16.8 for DCENet/DNTR) and APs for small objects (31.7 vs. 28.1 for DCENet), confirming the dual-backbone design's advantage for tiny targets. The retrained YOLO baselines (YOLO11-I, YOLO12-I, YOLO26-I) all fall 2–5 points below BDNet in mAP50, indicating the gains come from the bio-inspired architecture rather than the backbone choice.

## Relation to Prior Work

BDNet positions itself at the intersection of two prior lines of work: bio-inspired small-object detectors (ClusterNet, Brstd, VSTDet, EVMNet) that typically simulate a single perceptual mechanism, and multi-backbone architectures (TransFuse, DSOD++, DCAL) that complement features within the same representational space. It departs from both by explicitly decoupling low-level color and edge cues into parallel bio-inspired pathways (LGN/V1-V2 for color, V1 for orientation) that converge in a V4-analog fusion stage—a structured, prior-guided decomposition that neither family has attempted. The detection backbone is an optimized YOLO12, so the contribution is architectural rather than a new detection paradigm.

## Why It Matters / Open Questions

The paper offers a principled, biologically grounded recipe for addressing two specific failure modes of small-object detection (low color contrast and blurred edges) with a very lightweight model (2.59 M params), which is practical for deployment on resource-constrained UAV platforms. However, the individual module contributions in ablation are modest (~0.2–1.0 mAP50 each), and the paper does not probe failure cases or discuss when the bio-inspired mappings might be unnecessary. Open questions include whether the specific LGN/V1/V2/V4 analogies are essential or whether simpler color/edge enhancement modules would yield comparable gains, and whether the approach transfers to non-remote-sensing small-object settings.

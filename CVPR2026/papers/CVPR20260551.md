## Problem

Existing visual grounding tasks (VQA grounding, referring expression segmentation) focus on locating directly visible answers or objects in images, but cannot handle general open-ended questions about objects (e.g., 'how comfortable are these earbuds?') where the model must identify visual *evidence or context* rather than a direct answer. No dataset, benchmark, or model exists for this task, which has immediate practical value in e-commerce where customers ask abstract questions about product comfort, durability, or suitability.

## Input / Output

The model takes a single RGB image, a textual query (which can be a general object question, a visual question, a visual question-answer pair, or a referring expression), and optionally product listing text, and produces a 336×336 segmentation heatmap highlighting visual evidence plus a scalar relevance score indicating how pertinent the image is to the question. When multiple product images are available, a relevance-scoring step first selects the most appropriate image before grounding. The same architecture handles all input types via task-specific FiLM conditioning, unifying RES, VQA grounding, and VGOQ in one model.

## Method

The lightweight grounding model (1.77M trainable parameters) is built on CLIPSeg: a frozen CLIP vision transformer extracts multi-layer visual features, a frozen CLIP text encoder produces contextual text embeddings, and a small transformer decoder with two heads outputs the segmentation heatmap and relevance score. Training uses multi-task learning with Dice and binary cross-entropy losses, jointly on RefCOCO/+/g (RES), VizWiz-VQA-Grounding and TextVQA-X (VQA grounding), and two newly generated VGOQ datasets, with distinct FiLM conditioning vectors per task type. The VGOQ training data is created via two automated pipelines: (1) Claude rewrites visual questions from VizWiz-VQA-Grounding into general object questions while reusing existing segmentation masks as evidence, and (2) a six-step zero-shot pipeline (Claude for question generation and relevance scoring, Molmo for pointing, Florence-2 for OCR, SAM-2 for point-to-mask conversion) generates grounded customer questions from Amazon-Berkeley Objects product metadata and images. Despite being orders of magnitude smaller than 7B-parameter baselines, the model outperforms them on VGOQ tasks (e.g., 51.5% vs. 37.2% gIoU on VizWiz-VQA-Grounding SVE), demonstrating that prior models fail to generalize from direct-answer grounding to evidence-grounding.

## Results

On the VGOQ task (segmenting visual evidence for general object questions), the lightweight model (1.77M params) achieves 51.5% gIoU on VizWiz-VQA-SVE (n=312), substantially outperforming the best prior model UnifiedIO-XL (37.2%) and Qwen3-VL-8B (36.0%). On the new ABO-VGOQ benchmark, it reaches 39.5% gIoU on Specific Visual Evidence (n=169) and 56.0% on Related-to-Question (n=1526), compared to 30.3%/43.9% for Qwen3-VL-8B and 12.4%/30.2% for UnifiedIO-XL. A key finding is the performance drop when shifting from visual questions to object questions: UnifiedIO-XL drops from 52.2% to 37.2% gIoU, confirming that existing models struggle to identify visual evidence rather than direct answers.

## Baselines & Comparisons

The lightweight model (1.77M params) outperforms all four baseline families on every VGOQ benchmark: on ABO-VGO Val-SVE it achieves 39.5% gIoU vs. 30.3% (Qwen3-VL-8B), 20.2% (GLaMM-FullScope), 12.4% (UnifiedIO-XL), and 11.9% (OFA-Huge); on ABO-VGO Val-RTQ it reaches 56.0% vs. 43.9% (Qwen3-VL-8B), 44.8% (GLaMM-FullScope), 30.2% (UnifiedIO-XL), and 25.4% (OFA-Huge). On the VizWiz-VQA-SVE subset (n=312), the gap is even wider: 51.5% vs. 37.2% (UnifiedIO-XL) and 36.0% (Qwen3-VL-8B). On traditional VQA grounding (VizWiz-VQA-Ground val), the lightweight model also leads at 68.7% gIoU, surpassing UnifiedIO-XL (65.0%) and Qwen3-VL-8B (59.5%). However, on TextVQA-X and Toloka (text-centric VQA grounding), the lightweight model trails Qwen3-VL-8B (38.6% vs. 41.1% on TextVQA-X; 12.6% vs. 71.4% on Toloka), indicating its strength is in evidence-grounding rather than text reading. The consistent 10–25 point gIoU gap between VQA grounding and VGOQ performance across all baselines (e.g., UnifiedIO-XL: 65.0% → 37.2%) validates that identifying visual evidence for abstract questions is a fundamentally harder task than segmenting visible answers.

## Relation to Prior Work

This paper departs from the visual grounding lineage (RES, VQA grounding) where segmentation masks correspond to directly visible answers or referred objects, and instead formulates a new task—grounding visual *evidence* for abstract object questions—where the mask highlights context that supports an answer rather than being the answer itself. Architecturally, it repurposes the CLIPSeg design (frozen CLIP encoders + lightweight transformer decoder) but extends it with FiLM conditioning to handle multiple input types (referring expressions, visual questions, object questions) in a unified multi-task setup. The data generation pipeline is novel in combining Claude for question rewriting and relevance scoring with Molmo (pointing), Florence-2 (OCR), and SAM-2 (segmentation) in a zero-shot cascade, a combination not previously applied to grounding data creation.

## Why It Matters / Open Questions

The consistent ~15-point gIoU drop across all tested SoTA models (GLaMM, UnifiedIO, OFA, Qwen3-VL) when shifting from visual questions to object questions provides strong evidence that current grounding models lack the reasoning to connect abstract concepts to visual evidence—a gap with direct practical impact for e-commerce shopping assistants and product imagery optimization. Key open questions remain: what constitutes valid visual evidence (especially when external knowledge is needed), how to handle multi-image grounding more principledly, and whether the synthetic data generation pipeline introduces biases that limit real-world transfer. The lightweight 1.77M-parameter model's competitive performance suggests that task-specific training on VGOQ data may be more effective than scaling up general-purpose multimodal models for this particular grounding challenge.

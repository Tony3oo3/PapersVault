## Problem

Existing video generation methods handle either camera motion or object dynamics in isolation, and joint-control attempts rely on 2D cues (bounding boxes, optical flow) that entangle camera-induced parallax with true object movement, making them unreliable under significant viewpoint changes. The paper addresses this by proposing a unified framework that uses explicit 3D representations for both camera trajectories and object paths, enabling depth-aware, spatially coherent control of both motion types simultaneously.
![Teaser figure](../imgs/CVPR20263795/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference image, a sequence of N camera poses, a text prompt describing M moving objects, and per-object 3D trajectories (N×Np×3 point positions in the reference camera's coordinate frame). At inference, users interactively select objects via SAM2, drag 3D bounding boxes in a reconstructed point cloud to define trajectories, and specify camera paths relative to the reference pose. The output is an 81-frame video at 832×480 resolution that follows both the prescribed camera path and object motion.

## Method

SymphoMotion builds on the Wan-I2V DiT-based video diffusion model (Flow Matching formulation) and introduces two complementary control mechanisms. Camera Trajectory Control (CTC) fuses Plücker-ray camera pose embeddings with geometry-aware features from point-cloud frames rendered at target viewpoints, injected via a ControlNet-style Viewpoint Control Module. Object Dynamics Control (ODC) combines 2D bounding boxes rendered onto the point-cloud frames (providing image-plane spatial anchors) with 3D trajectory embeddings produced by an Object Motion Module that cross-attends in each transformer block. Training follows a two-stage strategy: CTC is trained first for camera control, then frozen while ODC is trained for object motion, all on the newly constructed RealCOD-25K dataset of 25K real-world clips with paired camera poses and 3D object trajectories.

## Results

On the 100-video evaluation set, SymphoMotion achieves the best scores across all metrics: FID 70.47 (vs. 86.66 for the next-best Uni3C), FVD 332.50 (vs. 404.21), CamTransErr 0.37 (vs. 0.44), CamRotErr 0.05 (vs. 0.06), and Box-IoU 61.88 (vs. 31.42 for MotionCtrl, the only other method supporting object motion). CLIPSIM is tied with Uni3C at 0.31. In the user study, SymphoMotion scores 4.87/5 on visual quality, 4.36/5 on camera motion, and 4.58/5 on object motion, all substantially ahead of the closest competitor.

## Baselines & Comparisons

SymphoMotion outperforms all four baselines on every metric where they overlap. Against the camera-only methods (CameraCtrl, ViewCrafter, Uni3C), it achieves the lowest CamTransErr (0.37 vs. 0.44–0.80) and CamRotErr (0.05 vs. 0.06–0.23), while also producing substantially better visual quality (FID 70.47 vs. 86.66–303.83). Against MotionCtrl, the only other method supporting joint camera–object control, SymphoMotion more than doubles the Box-IoU (61.88 vs. 31.42) and reduces CamTransErr by 55% (0.37 vs. 0.83), indicating far more faithful adherence to both prescribed camera paths and object trajectories. The user study confirms these quantitative gains: SymphoMotion leads MotionCtrl by 1.71 points on object motion (4.58 vs. 2.87) and by 1.18 points on camera motion (4.36 vs. 3.18). Uni3C is the closest camera-control baseline, but it cannot handle object dynamics at all, leaving SymphoMotion as the only method that simultaneously excels on both control axes.

## Relation to Prior Work

SymphoMotion builds on the Wan-I2V video diffusion backbone and extends the ControlNet-style conditioning paradigm to jointly handle camera and object motion. It departs from prior camera-only methods (CameraCtrl, ViewCrafter, Uni3C) by adding an Object Dynamics Control branch, and from prior object-only or 2D joint-control methods (MotionCtrl, MotionPrompting, Perception-as-Control) by representing object trajectories in explicit 3D space rather than the image plane. The geometry-aware point-cloud rendering for camera control draws on ViewCrafter's approach, while the 3D trajectory conditioning via cross-attention is a novel fusion of spatial and semantic embeddings not seen in prior joint-control systems.

## Why It Matters / Open Questions

The RealCOD-25K dataset fills a concrete gap: no prior real-world dataset paired camera poses with object-level 3D trajectories, forcing previous joint-control methods to rely on synthetic data or 2D proxies. The unified framework offers a practical path toward filmmaking-style video generation where both viewpoint and actor motion are user-specified. However, evaluation on only 100 curated videos limits statistical confidence, the two-stage training (freeze CTC, then train ODC) may prevent fully joint optimization, and the reliance on monocular depth estimation (Depth-Pro) introduces a potential failure mode in scenes with poor depth cues. Open questions include whether the 3D trajectory representation generalizes to large numbers of interacting objects or to long-horizon sequences beyond 81 frames.

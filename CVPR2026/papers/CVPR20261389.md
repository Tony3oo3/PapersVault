## Problem

Sliding-window inference in training-free open-vocabulary semantic segmentation processes each window independently, causing semantic discrepancy and grid-like artifacts at window boundaries because no window has access to the broader scene context. Even when global tokens are made available, attention remains locally biased toward inner-window patches since query features are constructed solely from local context, preventing consistent cross-window predictions.
![Teaser figure](../imgs/CVPR20261389/cropped_page0_idx2.webp)

## Input / Output

The method takes a high-resolution RGB image (resized to 448×448 or 336×336) and a set of text prompts describing target classes. The image is divided into overlapping windows of CLIP-compatible size (e.g., 448×448 with 224 stride, or 336×336 with 112 stride), and features are extracted using frozen CLIP (ViT-B/16) and a Vision Foundation Model (DINO ViT-B/8). The output is a per-pixel semantic segmentation mask over an open vocabulary, with overlapping regions resolved by averaging logits across windows. No additional training or learnable parameters are introduced.

## Method

GLA-CLIP introduces three mechanisms to enforce global-local semantic alignment. First, Key-Value Extension aggregates VFM features and CLIP value tokens from all L windows into unified global key and value matrices, allowing each local query to compute cross-window attention over the entire image. Second, a Proxy Anchor replaces each query with a semantically representative vector obtained by iteratively averaging high-similarity neighbors (cosine similarity above threshold ρ) across all windows, which counteracts the locality bias that causes attention to concentrate on inner-window tokens. Third, Dynamic Normalization adaptively scales and thresholds the attention map per query using two variables: a shift factor u that grows logarithmically with the number of windows to suppress noise from expanded context, and a per-query scale factor w_i inversely proportional to the number of high-confidence tokens, which amplifies relevant signals for small objects while remaining permissive for large ones. The framework is plug-and-play, requiring no training and compatible with any baseline (ProxyCLIP, ClearCLIP, SCLIP) and VFM backbone.

## Results

On the standard training-free OVSS setting (336 resize, 224 crop, 112 stride, with rename trick), GLA-CLIP achieves an average mIoU of 44.0% across 8 benchmarks without any dataset-specific hyperparameters, outperforming all training-free baselines that also avoid per-dataset tuning. With optional dataset-specific hyperparameters, it reaches 44.3%, matching CASS (44.4%) which requires per-dataset tuning. The method also demonstrates plug-and-play gains: adding GLA to ClearCLIP, SCLIP, and ProxyCLIP yields +1.2%, +1.6%, and +0.6% average mIoU improvements respectively.

## Baselines & Comparisons

GLA-CLIP (44.0% avg without DS hyperparameters) outperforms all training-free baselines that also avoid per-dataset tuning: DIH-CLIP (43.3%), FreeCP (42.2%), ResCLIP (41.4%), NACLIP (39.4%), LaVG (38.8%), SCLIP (38.2%), and ClearCLIP (38.1%). Against CASS (44.4%), the strongest baseline requiring dataset-specific hyperparameters, GLA-CLIP is within 0.4% without tuning and within 0.1% with optional tuning (44.3%). The method also improves its own baseline ProxyCLIP (42.3%) by +1.7% and demonstrates plug-and-play compatibility: ClearCLIP gains +1.2% (38.1→39.3%), SCLIP gains +1.6% (38.2→39.8%), and CLIP-DINOiser gains +1.6% (40.3→41.9%). Training-based methods (GroupViT 29.4%, ReCo 23.5%, TCL 37.2%) are substantially outperformed. FLOSS reports results on only 4 of 8 datasets, limiting direct comparison, but GLA-CLIP exceeds its per-dataset scores where available.

## Relation to Prior Work

This paper builds directly on ProxyCLIP (ECCV 2024), which replaced CLIP's final self-attention with a VFM-based self-similarity map, and borrows the iterative proxy construction mechanism from Progressive Proxy Anchor Propagation (ECCV 2024). It positions itself within the training-free OVSS family (ClearCLIP, SCLIP, MaskCLIP, CASS, etc.) that modifies CLIP's attention pipeline without retraining, but departs from all of them by explicitly targeting the semantic discrepancy introduced by sliding-window inference. The key conceptual departure is identifying that simply extending key-value tokens globally is insufficient due to a persistent inner-window attention bias, and addressing it through proxy anchors and scale-aware dynamic normalization rather than the fixed hyperparameters used by prior methods.

## Why It Matters / Open Questions

The plug-and-play nature of GLA-CLIP—applicable to any baseline (ProxyCLIP, ClearCLIP, SCLIP) without retraining—makes it a practical drop-in improvement for the training-free OVSS community, and the dynamic normalization eliminates the need for dataset-specific hyperparameter tuning that plagues recent methods like FreeCP and ResCLIP. However, the computational cost of aggregating key-value tokens across all windows scales linearly with the number of windows, and the paper acknowledges that certain hyperparameters (ρ, T, λ₁, λ₂) may still require adjustment for new backbones. Open questions include whether more efficient token selection (rather than using all global tokens) could reduce memory overhead, and whether the proxy anchor mechanism generalizes to other dense prediction tasks beyond segmentation.

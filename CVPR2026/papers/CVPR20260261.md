## Problem

Existing automated agent task generation methods rely on LLMs to directly analyze preprocessed text and images without explicitly modeling entity-relation structure, producing tasks with semantic inconsistencies and poor solvability. Additionally, web interaction task generation is confined to static, single-page settings and cannot capture the multi-page, dynamic navigation patterns of real-world websites, limiting reliable evaluation of agent generalization.
![Teaser figure](../imgs/CVPR20260261/cropped_page1_idx0.webp)

## Input / Output

The framework ingests academic papers (parsed into hierarchical semantic chunks: paragraphs, headings, tables, figure captions with OCR text) and crawled web pages (DOM trees plus screenshots, navigated via simulated human-like interactions). Each element is embedded with all-MiniLM-L6-v2 (d=384) and annotated with positional metadata. The output is 1,319 executable task instances: 1,002 document understanding tasks (spanning 12 types including QA, comparison, analysis, and multi-hop reasoning) and 317 web interaction tasks (spanning 7 types such as search, filter, modal, and business navigation), each grounded in a specific sampled subgraph and constrained by a task template or meta-path.

## Method

GRAPH2EVAL constructs a heterogeneous knowledge graph G=(V,E,R) from multi-source data, where nodes represent document elements or web components and edges encode structural, semantic, and interactive relations. Task generation proceeds via a five-stage pipeline: data ingestion, KG construction, subgraph sampling, task generation, and coverage optimization. Subgraph sampling is scenario-specific: document tasks use cosine-similarity thresholding plus structural matching to select relevant nodes, while web tasks employ a seed-driven strategy that identifies operational nodes (buttons, forms, links) and expands k-hop neighborhoods. Sampled subgraphs are then instantiated into concrete tasks by combining task templates (for documents) or meta-path patterns (for web, e.g., Search→Filter→Detail chains) with LLM-based context engineering. A multi-stage filtering pipeline—node reachability analysis, LLM scoring, and MMR-based diversity selection—ensures the final task set is semantically consistent, solvable, and representative across node types, edge types, and difficulty levels.

## Results

On GRAPH2EVAL-BENCH (1,319 tasks: 1,002 document understanding + 317 web interaction), GPT-4o achieves the highest F1 (0.577 single-agent, 0.592 multi-agent) and ROUGE-L (0.487) for document understanding, while Deepseek-V3 leads on LLM-as-a-Judge (0.835 single-agent). For web interaction, Agent S2.5 with Gemini 2.5 Flash reaches 69.20% overall success rate, substantially outperforming the SoM Agent (14.51%) on the same model. The KG-driven generation improves task consistency by ~20% (0.95 vs 0.74 doc; 0.78 vs 0.62 web) and solvability by ~17% (0.93 vs 0.73 doc; 0.72 vs 0.60 web) over a KG-free baseline, with generation times of 34.87 s (doc) and 95.51 s (web) per task.

## Baselines & Comparisons

Against OSWorld (human + scripted construction), GRAPH2EVAL matches on consistency and solvability (both rated 'High') while reducing time cost from 'High' to 'Low' via fully automated generation, and extends coverage to both document and web tasks. Compared to MMBench (curated multimodal QA), GRAPH2EVAL achieves comparable consistency but covers a broader task range (Doc + Web vs. Multimodal QA only) at lower construction cost. Versus TaskCraft, which uses a bottom-up approach composing atomic tasks from processed documents, GRAPH2EVAL adopts a top-down paradigm that builds a full knowledge graph first and samples subgraphs, exploiting intrinsic entity–relation structure rather than LLM-judged inter-task dependencies; this yields broader task types (document understanding + web interaction vs. multi-tool use only). The ablation quantifies the KG contribution: removing the KG drops human-evaluated consistency from 0.95→0.74 (doc) and 0.78→0.62 (web), and solvability from 0.93→0.73 (doc) and 0.72→0.60 (web), confirming that explicit entity-relation modeling is the primary driver of task quality.

## Relation to Prior Work

This paper departs from both human-annotated agent benchmarks (GAIA, Mind2Web, OSWorld) and prior synthetic task generation methods (TaskCraft, Su et al.) by introducing knowledge graphs as an explicit structured task space for agent task generation. Rather than relying on LLMs to directly synthesize tasks from raw documents or web pages—which the authors argue leads to semantic inconsistency and unsolvable tasks—GRAPH2EVAL repurposes classical KG concepts (nodes, edges, meta-paths, subgraph sampling) from NLP/IR to enforce entity-relation coherence before task instantiation. The framework unifies two previously separate evaluation tracks (RAG document understanding and multi-step web interaction) under a single graph-based generation pipeline, a combination not addressed by prior methods.

## Why It Matters / Open Questions

The framework addresses a practical bottleneck in agent evaluation: the labor cost and limited scalability of manually constructed benchmarks. The 20% consistency and 17% solvability gains over a KG-free baseline, while moderate, validate that explicit relational structure meaningfully improves synthetic task quality. However, the current instantiation is narrow (16 documents, 8 websites, 1,319 tasks), and the generation pipeline depends on GPT-4o, raising questions about cost and bias at scale. Open directions the authors identify include adversarial/safety task generation and fine-grained error localization at the node/edge level, which could make the benchmark more diagnostic of specific agent weaknesses.

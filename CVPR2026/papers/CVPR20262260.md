## Problem

Existing lifelong person re-identification (LReID) methods, whether rehearsal-based or distillation-based, consolidate all domain knowledge within a fixed network architecture. As the number of domains grows, this static parameter sharing causes severe cross-domain interference and catastrophic forgetting, because new domain adaptation overwrites previously acquired representations. The paper identifies that the fundamental bottleneck is architectural rigidity: a single set of weights cannot simultaneously encode domain-specific, partially-shared, and globally-invariant knowledge without mutual degradation.

## Input / Output

During training, the method consumes a sequential stream of ReID datasets (each with disjoint identity spaces) where only the current domain's data is accessible due to privacy constraints; person images are processed through a CLIP-ReID ViT-B/16 backbone with 768-dim Inception-V3 features extracted for domain-level statistics. During inference, a single query person image is routed automatically to the most relevant adapter configuration via the Similarity-Guided Auto-Selector, which compares the sample's feature distribution against stored per-domain mean/covariance statistics using a 2-Wasserstein distance—no domain label or auxiliary classifier is required. The final output is a standard ReID ranking (mAP, R@1) over gallery identities based on cross-modal similarity scores.

## Method

VIA (Versatile Incremental Adaptation) decomposes ReID knowledge into three complementary levels and assigns each to a dedicated module: (1) UnA embeds two cascaded LoRA adapters inside the MLP of every Transformer block—one before GELU handling coarse appearance shifts, one after GELU refining high-level discriminative features—giving each domain isolated expert parameters; (2) DAD maintains a shared pool of LoRA experts with a per-domain Top-k router (initialized via domain-aware transfer from the most similar prior domain) to model partially overlapping patterns, regularized by a Frobenius-norm orthogonality loss to prevent redundancy; (3) HDC dynamically decays the image encoder's learning rate for each new domain as a function of the average 2-Wasserstein similarity to all prior domains and the cumulative domain count, preserving globally transferable representations. Training alternates between a CLIP-style text-branch stage (120 epochs, contrastive losses) and an image-branch stage (60 epochs, triplet + ID + cross-modal + decoupling losses) per domain, with the encoder frozen during text training and the text encoder frozen during image fine-tuning.

## Results

On Training Order-1, VIA achieves 77.7% mAP and 86.6% R@1 on seen domains (5-dataset average), surpassing the strongest baseline DASK (55.4%/69.3%) by over 22% in mAP and 17% in R@1. On unseen domains, VIA reaches 77.1% mAP and 70.8% R@1, outperforming DASK (65.3%/58.4%) by 11.8% and 12.4% respectively. On Training Order-2, VIA maintains 77.4%/86.2% (seen) and 75.8%/69.0% (unseen), again leading all baselines by a wide margin. Per-domain, VIA attains 84.2% mAP on Market-1501, 79.9% on DukeMTMC-reID, and 57.5% on MSMT17, all substantially ahead of prior methods.

## Baselines & Comparisons

VIA outperforms all eight baselines on every seen and unseen domain metric. Against the strongest competitor DASK (AAAI 2025), VIA gains +22.3 mAP and +17.3 R@1 on seen-domain averages, and +11.8 mAP and +12.4 R@1 on unseen-domain averages. The gap is particularly pronounced on MSMT17, where VIA reaches 57.5% mAP versus DASK's 29.1% (a 28.4-point margin), and on DukeMTMC-reID (79.9% vs. 58.5% mAP). Earlier distillation-based methods (AKA, PatchKD, MEGE) lag further behind, with seen-domain mAP below 50%, indicating that fixed-architecture approaches struggle as domain count grows. The CLIP-ReID baseline (without any of VIA's modules) already achieves 66.4%/78.1% seen and 73.1%/66.5% unseen, confirming that the dynamic expansion modules (UnA, DAD, HDC) contribute an additional +11.3 mAP on seen and +4.0 mAP on unseen domains.

## Relation to Prior Work

This paper builds directly on CLIP-ReID [12] as its backbone and training paradigm, but departs fundamentally from the fixed-architecture assumption that underpins all prior LReID methods (both rehearsal-based and distillation-based). It repurposes LoRA adapters [9] and mixture-of-experts routing concepts from the LLM adaptation literature, reorganizing them into a three-level knowledge decomposition: domain-specific (UnA), partially shared (DAD), and globally invariant (HDC). The cascaded adapter insertion within the MLP (rather than the standard parallel placement) and the Wasserstein-distance-based domain similarity metric are the paper's key architectural departures from prior adapter-based continual learning work [36].

## Why It Matters / Open Questions

By replacing the fixed-parameter paradigm with dynamic modular expansion, VIA addresses a core scalability bottleneck in LReID: as domains accumulate, a single set of weights becomes an increasingly poor container for heterogeneous knowledge. The structured three-level decomposition (isolated → shared → global) offers a principled template that could transfer to other continual vision tasks beyond ReID. Limitations include evaluation on a single benchmark suite, reliance on a specific pretrained backbone (CLIP-ReID ViT-B/16), and per-domain parameter growth (~11M/task) that, while modest, still accumulates over very long sequences. The authors note future extension to multimodal lifelong learning, suggesting the framework's applicability is not yet fully explored.

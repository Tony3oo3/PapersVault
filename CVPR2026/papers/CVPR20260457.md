## Problem

Identifying safety-critical multi-agent interactions from uncurated autonomous driving logs using natural language queries remains a significant challenge, as traditional scenario mining relies on hand-crafted structured queries that are error-prone and prohibitively time-consuming. Existing referential tracking, multi-modal VQA, and VLM-based planning methods each address only part of the problem: they either assume referred objects exist, output text rather than 3D tracks, or focus on ego-vehicle planning rather than reasoning over full driving logs for non-ego interactions.
![Teaser figure](../imgs/CVPR20260457/cropped_page1_idx0.webp)

## Input / Output

The method consumes 15–20 second driving logs with synchronized LiDAR, 360° ring cameras, and HD maps (all object tracks clipped at 50 m and annotated at 10 Hz), together with a natural language prompt describing a scenario. It produces 3D bounding-box tracks for each object classified as referred, related, or other, along with precise start and end timestamps delimiting when the described interaction occurs. The benchmark includes both positive prompts (scenario present) and negative prompts (scenario absent), requiring the model to make a binary log-level decision in addition to per-timestamp localization.

## Method

RefProg is a dual-path, zero-shot approach that decouples 3D perception from language grounding. An offline 3D tracker (e.g., LE3DE2E) generates high-quality 3D tracks from raw LiDAR and RGB inputs, while in parallel an LLM is prompted with a predefined API of 28 atomic functions (turning, accelerating, changing lanes, spatial relationships, boolean operators) to synthesize a Python program that filters those tracks according to the natural language prompt. The generated code is executed to partition all tracks into referred, related, and other objects, and visual tools such as SigLIP2 are available to the LLM for resolving appearance-based attributes. The same atomic-function API is used to procedurally generate the RefAV dataset itself: an LLM composes atomic functions into programs, produces a matching natural language description, and the pair is verified by human annotators before inclusion. This compositional design allows RefProg to generalize zero-shot to the nuPrompt benchmark with only minor dataset-specific adaptations (swapping class lists and removing HD-map-dependent functions).

## Results

On the RefAV benchmark, RefProg (Referential Tracking by Program Synthesis) with LE3DE2E tracks achieves a HOTA-Temporal of 50.1 and HOTA-Track of 51.1, substantially outperforming all other zero-shot baselines. The next-best method, GPT-5 as a black-box API, reaches only 37.2 HOTA-Temporal, while ReferGPT and Image-Embedding Similarity score 20.2 and 17.2 respectively. On nuPrompt, RefProg with StreamPETR achieves AMOTA 0.321 and Recall 0.504, surpassing the prior state-of-the-art PromptTrack (AMOTA 0.259, Recall 0.366) in a zero-shot setting without modifying its atomic action definitions.

## Baselines & Comparisons

RefProg decisively outperforms all five compared baselines. On RefAV, it surpasses ReferGPT [6] by 29.9 points in HOTA-Temporal (50.1 vs. 20.2) and by 14.2 points in Log Balanced Accuracy (71.8 vs. 57.0), indicating that CLIP-based captioning and fuzzy matching cannot capture compositional multi-agent interactions. On nuPrompt, RefProg (zero-shot) beats PromptTrack [72] (trained on domain-specific data) by 0.006 AMOTA (0.265 vs. 0.259) and by a large margin in Recall (0.498 vs. 0.366), and outperforms DQTrack [32] (best config: AMOTA 0.234) and ADA-Track [13] (AMOTA 0.249) by 3.1 and 1.6 AMOTA points respectively. CenterPoint Tracker [76] is the weakest baseline at AMOTA 0.178, trailing RefProg by 8.7 points. Notably, the best CVPR 2025 challenge submission (Zeekr UMCV, 53.4 HOTA-Temporal) also builds upon RefProg, confirming its role as the strongest starting point for the community.

## Relation to Prior Work

This paper carves out spatio-temporal scenario mining as a distinct task from referential multi-object tracking (RMOT), multi-modal VQA, and VLM-based motion planning, arguing that each prior formulation is insufficient: RMOT assumes referred objects exist, VQA outputs text rather than 3D tracks, and VLM planners only reason about ego-vehicle waypoints. Methodologically, RefProg adapts the program-synthesis paradigm from VisProg and ViperGPT—where LLMs generate executable code to compose visual tools—but extends it to temporal, multi-agent reasoning over 3D tracks with an API of 28 atomic motion primitives. The dataset itself repurposes Argoverse 2's 10 Hz track annotations and borrows nuPlan's taxonomy of 80 planning-relevant scenarios as a template for procedural generation via LLMs.

## Why It Matters / Open Questions

The benchmark exposes a critical gap in AV safety validation: identifying rare, safety-critical multi-agent interactions in fleet data remains unsolved, and the paper demonstrates that even GPT-5 as a black-box reasoner achieves only 37.2 HOTA-Temporal, far below the 64.8 achievable with ground-truth tracks and perfect program synthesis. Key limitations include the dataset's modest scale (1,000 logs), dependence on AV2's ground-truth quality (jittery tracks degrade motion classification), and the non-scalable nature of hand-crafted atomic functions for covering all scenario types (e.g., weather, lighting). Open questions include whether end-to-end models can learn the compositional temporal reasoning that program synthesis handles explicitly, and whether larger, purpose-built datasets can push the field beyond the current ceiling where the best challenge submission beats the baseline by only 3.3%.

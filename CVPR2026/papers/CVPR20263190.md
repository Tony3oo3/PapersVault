## Problem

Reconstructing 4D human-object interaction from monocular RGB video remains challenging because prior methods either require known object templates, are restricted to a fixed set of training categories, or produce temporally inconsistent translations and scale drift. No existing approach can perform category-agnostic, metric-scale 4D reconstruction with coherent contacts from a single RGB video, limiting downstream applications in robotics, gaming, and human understanding.
![Teaser figure](../imgs/CVPR20263190/cropped_page0_idx0.webp)

## Input / Output

The method takes a monocular RGB video sequence as sole input, assuming the object is mostly visible in the first frame (a common recording setup). It outputs a metric-scale textured object mesh, per-frame 6DoF object poses (rotation and translation), SMPL-H body parameters (pose θ, shape β, global translation), and binary per-hand contact labels, all aligned in a shared world coordinate frame with consistent global translations across the full video. Evaluation aligns only the first frame to ground truth and propagates the same transform to all subsequent frames, penalizing any drift.

## Method

CARI4D is a coarse-to-fine pipeline that first reconstructs the object mesh via Hunyuan3D and estimates metric scale through a coarse-to-fine grid search using FoundationPose and UniDepth depth. A novel pose hypothesis selection algorithm then robustly tracks object pose by dynamically choosing among K FoundationPose candidates per frame using occlusion-aware mask IoU and geodesic rotation distance thresholds, with forward-backward tracking to handle long occlusions. The core learned component, CoCoNet, is a render-and-compare network built on frozen and trainable DINOv2 encoders with spatiotemporal attention blocks that consumes rendered RGB/depth/mask sequences under initial poses alongside camera observations to predict delta pose updates and hand contact labels. A depth-alignment training strategy (scaling and shifting predicted depth to GT via median-based normalization) prevents the network from overfitting to depth estimator error patterns. Finally, a contact-aware joint optimization minimizes a composite objective combining contact distance, 2D joint projection, occlusion-aware mask, penetration, and acceleration losses to enforce physical plausibility and temporal smoothness.

## Results

On the in-distribution BEHAVE test set, CARI4D achieves a combined chamfer distance (CD-c) of 9.23 cm, outperforming VisTracker (14.22 cm) by 35% and InterTrack (30.20 cm) by 69%. On the unseen InterCap test set (zero-shot), CARI4D achieves CD-c of 12.88 cm, beating VisTracker (20.17 cm) by 36% and InterTrack (33.53 cm) by 62%. In the key-frame comparison on InterCap, CARI4D (CD-c 5.90 cm) substantially outperforms the image-based PICO method (CD-c 87.73 cm). CARI4D also achieves the lowest object acceleration error (0.35 cm on BEHAVE, 0.82 cm on InterCap), indicating the smoothest reconstructed motion.

## Baselines & Comparisons

CARI4D outperforms all three baselines on both in-distribution and zero-shot settings. Against VisTracker (which requires known object templates), CARI4D reduces combined chamfer distance from 14.22 to 9.23 cm on BEHAVE (35% improvement) and from 20.17 to 12.88 cm on InterCap (36% improvement), while also achieving lower object acceleration error (0.35 vs 0.77 cm). Against InterTrack (template-free but category-specific), CARI4D achieves dramatically lower errors: CD-c of 9.23 vs 30.20 cm on BEHAVE and 12.88 vs 33.53 cm on InterCap, largely because InterTrack's per-frame normalization and heuristic translation lead to severe scale and translation inconsistencies. Against PICO (image-based, key-frame only), CARI4D achieves CD-c of 5.90 cm versus PICO's 87.73 cm on InterCap key frames, as PICO's reliance on noisy contact predictions causes wrong mesh correspondences and large pose errors. Notably, CARI4D is the only method that generalizes zero-shot to unseen object categories while maintaining temporally consistent metric-scale tracking.

## Relation to Prior Work

CARI4D builds on a pipeline of recent foundation models—Hunyuan3D for object mesh generation, UniDepth for metric depth, FoundationPose for 6DoF tracking, and NLF for human pose—yet departs from prior 4D HOI reconstruction work (VisTracker, InterTrack, PICO) by being the first to handle arbitrary object categories without templates or category-specific training. The key conceptual departure is the render-and-compare contact reasoning module (CoCoNet) and the pose hypothesis selection algorithm, which address the gap between individually strong foundation model predictions and coherent interaction-level reconstruction. The method also extends the optimization-based refinement tradition (ChORE, contact transformers) with a learned contact-aware joint optimization that enforces physical constraints.

## Why It Matters / Open Questions

This is the first method to deliver category-agnostic, metric-scale, temporally consistent 4D human-object interaction from a single RGB video, which is directly applicable to downstream tasks in robotics, gaming, and human understanding that previously required multi-view studios or known object templates. The zero-shot generalization to in-the-wild internet videos is practically significant, though the assumption that the object is mostly visible in the first frame limits applicability to certain recording scenarios. Open questions include whether the approach scales to multiple simultaneous objects, longer videos with camera motion, and whether the contact reasoning can be extended beyond hand-object to full-body contact (feet, torso).

## Problem

Existing event-based low-light image enhancement methods rely on direct feature fusion that overlooks the global illumination priors central to Retinex-based LIE, and they lack reliable mechanisms to handle the inherent noise sensitivity of event signals under low photon conditions. Additionally, no high-resolution, temporally synchronized, real-world event-image dataset with ground truth existed to properly benchmark these methods.
![Teaser figure](../imgs/CVPR20263248/cropped_page0_idx0.webp)

## Input / Output

The method takes a low-light RGB image and a temporally synchronized event stream as joint input. Events are encoded via the SBT (Stacking Based on Time) representation into B time bins, and the illumination prior is derived by a pixel-wise maximum operation across the three image channels. The output is a single enhanced normal-light RGB image at the same spatial resolution as the input; on the proposed RLE dataset this is 1024×768, substantially higher than the 346×260 resolution of the prior SDE dataset.

## Method

EIC-LIE introduces two core modules. The Event-Illumination Collaborative Interaction (EICI) module performs bidirectional feature exchange: a forward-gathering step uses covariance-based cross-attention to aggregate HDR event features and global illumination features into a shared image representation, followed by a transformer block for latent fusion; a backward-injection step then reuses the stored attention matrices to decompose the fused features back into modality-specific illumination and event components, enforcing implicit alignment constraints. The Illumination-aware Event Filter (IAEF) is a deformable filter whose kernels are extracted from illumination features (encoding lighting priors) and whose weights and spatial offsets are predicted from event features, enabling it to selectively reference reliable neighboring events while suppressing noise spikes. The framework is trained end-to-end in a supervised manner against normal-light ground truth, and the authors additionally build a dual beam-splitter hybrid imaging system (Sony IMX273 RGB cameras + IMX636 event camera) to capture the first high-resolution real-world RLE dataset with precise temporal and spatial synchronization.

## Results

On the proposed RLE dataset (1024×768), EIC-LIE achieves 23.63 dB PSNR and 0.7670 SSIM, surpassing the previous SOTA EvLight by 0.95 dB and 0.0469. On the SDE dataset, it reaches 23.33/24.22 dB PSNR (indoor/outdoor) and 0.7573/0.8200 SSIM, improving over EvLight by up to 1.01 dB in PSNR. On the synthetic SDSD dataset, gains of up to 1.24 dB PSNR and 0.0312 SSIM are observed. The method uses only 2.13M parameters (9.4% of EvLight's 22.73M) while running at 298 ms per 1024×768 image on an NVIDIA 4090.

## Baselines & Comparisons

EIC-LIE outperforms all 12 baselines on every dataset and metric. Against the closest competitor EvLight (CVPR'24), it gains 0.89–1.01 dB PSNR on SDE (indoor/outdoor), 1.24–0.78 dB on SDSD, and 0.95 dB on RLE, while also improving SSIM by up to 0.069 (SDE-outdoor: 0.8200 vs 0.7505). Among image-only methods, MambaLLIE (NeurIPS'24) is the strongest baseline, yet EIC-LIE still leads by 1.96 dB PSNR on SDE-indoor and 2.00 dB on SDSD-indoor, confirming the benefit of event data. Compared to other event-based methods (ELIE, eSL-Net, Liu et al., EvLowlight), the advantage is even larger, with gaps exceeding 3 dB PSNR in most cases. Notably, EIC-LIE achieves these results with only 2.13M parameters—roughly 9.4% of EvLight's 22.73M and 5% of ELIE's 33.36M—while maintaining a competitive runtime of 298 ms per 1024×768 frame.

## Relation to Prior Work

This paper synthesizes two previously separate research threads: Retinex-based low-light image enhancement (which leverages illumination priors) and event-based LIE (which exploits HDR from event cameras). Prior event-based methods (EvLight, ELIE, eSL-Net) rely on direct feature fusion between events and images but neglect the global illumination structure that Retinex-based approaches emphasize. The EICI module introduces a bidirectional interaction mechanism inspired by the lookup-token idea in LookupViT [21], while the IAEF repurposes illumination statistics as a dynamic filter kernel—a concept borrowed from adaptive separable convolution in deblurring. The RLE dataset departs from the SDE dataset's robotic-arm capture paradigm by using a dual beam-splitter optical system for true temporal synchronization and higher resolution.

## Why It Matters / Open Questions

The RLE dataset (1024×768, time-synchronized, dynamic scenes, with GT) fills a critical gap that has constrained event-based LIE research, as prior datasets were limited to 346×260 resolution, static scenes, or had temporal misalignment. The illumination-aware event filtering addresses a practical and underexplored problem—noise sensitivity of event signals in low-light—that prior methods handled with fixed SNR-based guidance. Open questions include whether the framework extends to video enhancement, whether the beam-splitter hardware requirement limits real-world deployment, and whether the bidirectional interaction design generalizes to other multi-modal enhancement tasks beyond low-light.

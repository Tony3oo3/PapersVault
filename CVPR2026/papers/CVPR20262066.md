## Problem

Existing language-grounded Gaussian Splatting methods are split into two orthogonal tracks: static 3D referring segmentation (e.g., ReferSplat) that localizes a single instance in a fixed scene, and open-vocabulary 4D querying (e.g., 4DLangSplat) that retrieves all instances matching a category in a dynamic scene. Neither can jointly resolve a complex spatio-temporal referring expression—simultaneously identifying *which* instance (spatial disambiguation) and *when* it exhibits a described state (temporal localization)—within an explicit 4D reconstruction.

## Input / Output

The method takes an RGB video of a dynamic scene and a free-form referring expression as input. Two query types are supported: time-agnostic expressions (e.g., 'the object held in two hands above a wooden surface') that require only spatial instance grounding, and time-sensitive expressions (e.g., 'the liquid becoming darker in the glass') that additionally require localizing the temporal interval of the described state. The output is a per-frame 2D segmentation mask for the target instance rendered from the 4DGS representation, and for time-sensitive queries, a binary temporal mask indicating which frames the described state is active. Supervision is generated automatically via an MLLM captioning pipeline rather than manual annotation.

## Method

ST4R-Splat decouples spatial grounding from temporal localization into two modules operating on a 4DGS reconstruction. The Instance-Aware 4D Gaussian Referring Field assigns each 4D Gaussian a time-invariant embedding and uses a position-aware cross-modal attention mechanism that injects the time-varying Gaussian position μ_i(t) to dynamically enhance the embedding against BERT-encoded word tokens, producing per-Gaussian relevance scores rasterized via alpha-compositing into 2D masks; training combines BCE mask loss, a Gaussian-text contrastive loss, and an instance-aware regularization (intra-instance compactness + inter-instance distinctiveness on rendered feature maps). The Instance-Level Temporal State Mapping module bypasses 2D rendering entirely by pre-computing a cache of e5-mistral-7b-encoded time-aware state captions per instance, then at inference computing similarity between the query text embedding and each frame's cached state feature to yield a view-independent temporal score. An MLLM-based captioning pipeline (Qwen3-VL-8B) automatically generates frame-level descriptive captions (using DAM + visual prompting with red-contour highlighting) and time-aware state captions (using a coarse video summary + localized clips) to provide all textual supervision without manual annotation. The 4DGS reconstruction is trained separately with photometric loss and frozen during semantic training to preserve rendering fidelity.

## Results

On the extended HyperNeRF benchmark, ST4R-Splat achieves 77.67% mIoU on time-agnostic referring queries, substantially outperforming ReferSplat (35.42%) and 4DLangSplat (43.40%). For time-sensitive referring queries, ST4R-Splat reaches 83.44% temporal accuracy and 57.98% vIoU, compared to 4DLangSplat's 52.24% accuracy and 12.14% vIoU. The largest per-scene gains appear on the 'chicken' scene (83.57% mIoU) and 'espresso' time-sensitive query (97.43% Acc, 75.91% vIoU).

## Baselines & Comparisons

ST4R-Splat decisively outperforms both baselines on all reported metrics. Against ReferSplat (adapted from 3DGS referring segmentation), ST4R-Splat gains +42.25 mIoU points on time-agnostic queries (77.67% vs. 35.42%), demonstrating that static 3D referring methods struggle to generalize to dynamic 4D scenes. Against 4DLangSplat (the closest 4D language-grounding baseline), ST4R-Splat improves time-agnostic mIoU by +34.27 points (77.67% vs. 43.40%) and time-sensitive accuracy by +31.20 points (83.44% vs. 52.24%), with a particularly dramatic vIoU gap of +45.84 points (57.98% vs. 12.14%). The authors attribute 4DLangSplat's weakness to its open-vocabulary design, which cannot resolve instance-level spatial relations, and its 2D rendering-based temporal supervision, which degrades under novel viewpoints (51.92% Acc vs. ST4R-Splat's 90.38% in a fixed novel-view experiment). ReferSplat is only evaluated on time-agnostic queries since it has no temporal modeling component.

## Relation to Prior Work

This paper sits at the intersection of two previously orthogonal research threads: instance-level referring segmentation in static 3D Gaussian Splatting (ReferSplat) and open-vocabulary language grounding in dynamic 4D Gaussian Splatting (4DLangSplat). It departs from both by explicitly decoupling spatial instance identification (time-invariant referring embeddings with cross-modal attention) from temporal state localization (a view-independent instance-to-state feature cache), rather than relying on 2D rendering-based supervision as 4DLangSplat does. The MLLM-based captioning pipeline borrows visual prompting strategies from 4DLangSplat but extends them to generate temporally grounded state descriptions that feed the temporal mapping module.

## Why It Matters / Open Questions

By formalizing STRS-4DGS and providing the first benchmark with spatio-temporally grounded referring expressions on dynamic 4D reconstructions, this work opens a concrete research direction for language-driven 4D scene understanding that neither static referring segmentation nor open-vocabulary 4D querying can address. The view-independent temporal state mapping is a clean architectural choice that could transfer to other dynamic scene understanding tasks, but the evaluation is limited to 6 scenes and 26 objects from HyperNeRF, leaving open questions about scalability to more complex, multi-object dynamic environments. The reliance on MLLM-generated captions as supervision also raises questions about error propagation and whether the approach generalizes to scenes where MLLM descriptions are less reliable.

## Problem

Existing learning-based sensor calibration methods are restricted to a single modality pair (LiDAR-RGB or LiDAR-Event), requiring separate networks for each pair and risking inconsistent alignment when all three sensors are present. No unified, target-free framework exists that jointly calibrates LiDAR, RGB, and event cameras within a single architecture.
![Teaser figure](../imgs/CVPR20260455/cropped_page0_idx0.webp)

## Input / Output

The network consumes a miscalibrated LiDAR point cloud resampled to a fixed N points (20,000 for KITTI, 5,000 for DSEC) after removing negative-depth points and applying a range cutoff, a standardised RGB image, and a two-channel event frame (positive/negative polarity) accumulated over a 50 ms window and transformed into the RGB camera coordinate system via known pre-calibration. Camera intrinsics are provided as known constants and are scaled to the model's internal resolution. The output is two sets of extrinsics — LiDAR-to-RGB and LiDAR-to-Event — each parameterised as a 3-D translation vector and a unit quaternion, predicted by separate heads within the same forward pass.

## Method

LiREC-Net uses a dual-path architecture with a shared LiDAR branch that encodes the point cloud twice: a Point-Transformer-V3 encoder on the raw 3-D points and an MViTV2 encoder on a projected single-channel depth map (via scaled depth projection). The per-point features are projected onto the image plane using scaled feature projection, then channel-concatenated with the depth features to form a unified LiDAR embedding reused by both the LiDAR-RGB and LiDAR-Event paths, reducing parameters and inference time versus separate branches. Each camera modality (RGB, event) is encoded independently with MViTV2, and pair-wise cost volumes are built via channel-normalised inner products over a square displacement window, refined by DenseNet-style context modules (five conv layers with running concatenation). Prediction heads split into translation (two FC layers) and rotation (two FC layers with quaternion normalisation). Training uses a multi-stage iterative refinement strategy — five stages from ±20°/150 cm down to ±1°/10 cm — with independent perturbations per modality pair, and a combined loss of Smooth-L1 translation, angular rotation, and point-cloud distance terms.

## Results

On KITTI (5-stage, ±20°/150 cm perturbation), LiREC-Net achieves 1.80 cm / 0.11° translation/rotation error for LiDAR-RGB and 1.82 cm / 0.12° for LiDAR-Event, establishing the first LiDAR-Event baseline on this dataset. On DSEC (5-stage), it reaches 2.51 cm / 0.14° for LiDAR-RGB (a new baseline, as no prior work reports on this pair) and 1.18 cm / 0.07° for LiDAR-Event. The tri-modal configuration also reduces inference time from 0.51 s (two separate bi-modal models) to 0.33 s on KITTI, with 10% fewer parameters and 24% less GPU memory.

## Baselines & Comparisons

On KITTI, LiREC-Net substantially outperforms RegNet (6.00→1.80 cm) and CalibNet (4.34→1.80 cm) in translation error, and also wins on rotation against both (0.11° vs 0.28° and 0.41°). Against LCCNet, LiREC-Net improves rotation (0.11° vs 0.16°) but is slightly worse in translation (1.80 vs 1.59 cm, a 21 mm gap). PseudoCal remains the strongest LiDAR-RGB baseline on KITTI (1.18 cm / 0.05°), beating LiREC-Net by 62 mm in translation and 0.06° in rotation. On DSEC, LiREC-Net (5-stage) surpasses MULiEv in rotation accuracy (0.07° vs 0.10°) but trails in translation (1.18 vs 0.81 cm) for LiDAR-Event; however, LiREC-Net is the first method to jointly handle both LiDAR-RGB and LiDAR-Event in a single architecture, providing the first LiDAR-RGB benchmark on DSEC (2.51 cm / 0.14°).

## Relation to Prior Work

LiREC-Net extends the cost-volume-based calibration paradigm established by LCCNet and PWC-Net to a unified tri-modal setting, inheriting the iterative refinement strategy, DenseNet-style context modules, and channel-normalized inner-product cost volumes. The key architectural departure is a shared LiDAR branch that fuses Point-Transformer-V3 point features with MViTV2 depth-map features, serving both the LiDAR-RGB and LiDAR-Event paths simultaneously rather than duplicating separate LiDAR encoders per pair. This contrasts with prior learning-based methods (RegNet, CalibNet, LCCNet, PseudoCal, MULiEv) that each address only a single modality pair, and with target-based approaches that require controlled environments.

## Why It Matters / Open Questions

LiREC-Net establishes the first unified baseline for joint LiDAR-RGB-Event calibration and the first LiDAR-Event calibration result on KITTI (using synthetic events via V2E), filling gaps in the evaluation landscape. The shared LiDAR representation yields meaningful efficiency gains (~35% less inference time, ~10% fewer parameters) over running two independent bi-modal models, which is practically relevant for deployment. However, the assumption that RGB and event cameras are pre-calibrated to each other limits real-world applicability, and the mixed results on DSEC (where tri-modal LiDAR-RGB degrades from 1.40 cm to 2.51 cm vs. bi-modal) suggest the joint-training benefit is dataset-dependent. Future work on removing the pre-calibration assumption and generalizing to additional modalities (thermal, radar, depth) would broaden the framework's utility.

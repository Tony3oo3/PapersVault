## Problem

Existing CAD reconstruction methods depend on dense, clean point clouds that are expensive to acquire and require extensive manual annotation, while image-based neural rendering techniques (NeRF, 3DGS) produce unstructured geometry without parametric or topological structure. No prior framework recovers complete B-Rep CAD models directly from multi-view images without any point cloud supervision.
![Teaser figure](../imgs/CVPR20263539/cropped_page0_idx3.webp)

## Input / Output

The method takes 50 multi-view RGB images of a CAD object as input, from which 2D edge masks (via an edge detector) and per-patch masks (via SAM) are extracted as supervision signals. The output is a watertight B-Rep model composed of parametric surfaces (planes, cylinders, spheres), trimmed lines and curves, and corner points, along with intermediate labeled point clouds (edge and patch). The 2DGS representation uses oriented elliptical disks rather than volumetric Gaussians, and the final B-Rep is assembled through constraint refinement and Boolean operations.

## Method

BrepGaussian extends 2D Gaussian Splatting by attaching learnable edge scalars and high-dimensional patch feature vectors to each oriented elliptical disk primitive. A two-stage training strategy disentangles the learning tasks: Stage 1 jointly optimizes geometry (L1 + D-SSIM) and edge semantics (alpha-composited scalar edge values supervised by 2D edge masks), while Stage 2 freezes all geometric parameters and trains patch instance features using a triplet contrastive loss that aggregates features within the same SAM mask and repels features across different masks. Gaussians are then converted to a labeled point cloud by sampling each disk's center plus four points along its ellipse (for elongated primitives). A constraint-guided fitting module applies RANSAC to recover parametric surfaces per patch, computes pairwise surface intersections to extract lines and curves constrained by edge points, identifies corners from triple-plane or double-line intersections, and assembles everything into a watertight B-Rep through topological adjustment.

## Results

On the ABC-NEF dataset, BrepGaussian achieves a patch segmentation F1 of 0.9040 (Prec 0.8903, Rec 0.9181) and edge segmentation F1 of 0.9301 (Prec 0.9350, Rec 0.9253) using only multi-view images as input. For end-to-end CAD reconstruction, it attains Chamfer Distance of 4.90×10⁻² on surfaces and 5.01×10⁻² on curves, and Hausdorff Distance of 3.351×10⁻¹ on surfaces and 3.626×10⁻¹ on curves. These results outperform all baselines that operate on densified (reconstructed) point clouds, and approach the performance of methods that require ground-truth point clouds as input.

## Baselines & Comparisons

Against point-cloud-based segmentation baselines, BrepGaussian (multi-view input) outperforms PCER-Net on densified points by a large margin (F1 0.9040 vs. 0.6392) and ParSeNet on densified points (F1 0.9040 vs. 0.3427). Compared to methods using ground-truth point clouds, BrepGaussian surpasses PCER-Net-GT (F1 0.9040 vs. 0.8936) but falls short of SED-Net-GT (F1 0.9040 vs. 0.9738), which benefits from clean, dense input. HPNet produces severely fragmented labels (Rec 0.2142) and is not competitive. For end-to-end CAD reconstruction (Table 3), BrepGaussian achieves the best curve Chamfer Distance (5.01×10⁻²) among all methods, outperforming Split-and-Fit (13.98×10⁻²) and Point2CAD with PCER-Net labels (20.45×10⁻²). Point2CAD with BrepGaussian's own labels achieves a slightly lower surface CD (3.38 vs. 4.90) but the authors attribute this to redundant patch reconstruction that inflates the metric without improving visual quality. On edge segmentation, BrepGaussian (F1 0.9301) beats PCER-Net on densified points (F1 0.7703) but trails SED-Net on GT points (F1 0.9802).

## Relation to Prior Work

This paper extends the 2D Gaussian Splatting (2DGS) rendering framework—originally designed for geometrically accurate radiance fields—into the domain of parametric CAD reconstruction, a task previously dominated by point-cloud-based methods (ParSeNet, SED-Net, PCER-Net, Point2CAD, Split-and-Fit). The key departure is replacing the expensive, annotation-heavy point cloud input with multi-view images, using learnable per-Gaussian edge scalars and patch feature vectors trained in a two-stage scheme (geometry+edges first, then contrastive patch instances). The downstream B-Rep assembly via RANSAC-based primitive fitting and constraint-guided edge/corner extraction follows the established divide-and-conquer paradigm of prior CAD reconstruction work, but is driven by labels derived from the Gaussian representation rather than from a pre-existing point cloud.

## Why It Matters / Open Questions

BrepGaussian is the first framework to produce complete B-Rep CAD models directly from multi-view images without any point cloud supervision, bridging a significant gap between the accessibility of image data and the structured output required by engineering workflows. However, the pipeline remains complex (edge detection + SAM + two-stage GS training + RANSAC fitting + topological refinement), requires 50 views for clean results, and still depends on manual SAM mask correction (~3 min/object) for the evaluated dataset. Open questions include whether the view requirement can be reduced, whether the approach generalizes to highly complex or organic shapes, and whether the two-stage training can be unified or replaced by end-to-end learning.

## Problem

Multi-object tracking models suffer significant performance degradation under distribution shifts in appearance, motion patterns, and object categories between training and testing data. Existing test-time adaptation methods for MOT rely solely on intra-frame information and neglect the temporal consistency and identity association that are critical for tracking, leaving a gap in how to adaptively calibrate ID predictions across frames and videos during online inference.
![Teaser figure](../imgs/CVPR20260773/cropped_page0_idx0.webp)

## Input / Output

The method operates on a pre-trained MOTIP tracker (Deformable DETR + ResNet-50) and consumes per-frame object features (n×D vectors), predicted ID probability maps, and entropy values computed from those maps. It maintains two persistent caches — a transient memory of k_c confident and k_u uncertain recent objects, and a long-term experience cache spanning all previously processed test videos — both stored as key-value pairs of features/embeddings and masked prediction vectors. The output is a calibrated ID prediction map per frame, produced entirely via forward propagation without any gradient computation or parameter updates.

## Method

TCEI implements a dual-system calibration inspired by Kahneman's dual-process theory. The Intuitive System stores recent confident objects (lowest entropy) as one-hot positive priors and recent uncertain objects (entropy near a target e^u) as multi-hot negative reflective cases in a transient memory, then applies cross-attention between current object features and cached features to produce a guidance vector added to the base prediction. The Experiential System maintains a parallel experience cache from all prior test videos using the same entropy-based selection, and computes a second guidance vector via cross-attention over experience embeddings. Calibration is selective: an uncertainty-weighted correction (U = P(1−P)) is applied only to the components where intuitive and experiential guidance disagree, scaled by a similarity term that suppresses correction when the two systems agree, thereby preserving reliable intuitive predictions while correcting uncertain ones. The entire pipeline is forward-propagation-only, requiring no backpropagation or parameter updates.

## Results

On DanceTrack, TCEI achieves 70.6% HOTA and 62.3% AssA, surpassing the MOTIP baseline (69.5% HOTA, 60.2% AssA) by +1.1 and +2.1 points respectively, while maintaining comparable detection accuracy (80.2% DetA). On SportsMOT, TCEI reaches 73.0% HOTA and 64.0% AssA, outperforming MOTIP (72.6% HOTA, 63.2% AssA) and establishing a new state-of-the-art. Compared to the TTA baseline Tent, TCEI improves HOTA by +1.2% and AssA by +2.2% on DanceTrack while running at 12 FPS versus Tent's 7 FPS, since TCEI operates entirely in a feed-forward manner without backpropagation.

## Baselines & Comparisons

TCEI is built on top of MOTIP [14] (CVPR 2025) as its base tracker, improving HOTA from 69.5 to 70.6 and AssA from 60.2 to 62.3 on DanceTrack, and from 72.6 to 73.0 and 63.2 to 64.0 on SportsMOT, confirming that the calibration framework adds value without altering the underlying detector. Against the strongest SSM-based tracker SambaMOTR [35], TCEI leads by +3.4% HOTA and +4.8% AssA on DanceTrack, and by +3.2% HOTA and +4.6% AssA on SportsMOT. Compared to the TTA baseline Tent [43], TCEI wins on both datasets (DanceTrack: +1.2% HOTA, +2.2% AssA; SportsMOT: +0.2% HOTA, +0.7% AssA) while also running nearly 2× faster (12 vs. 7 FPS on DanceTrack), since Tent requires backpropagation. TCEI also outperforms association-focused methods like OC-SORT [3] (+15.5% HOTA on DanceTrack) and MeMOTR [13] (+7.2% HOTA on DanceTrack, +4.2% on SportsMOT), demonstrating that test-time calibration from both transient memory and long-range experience is more effective than purely architectural or memory-based association strategies. The only metric where TCEI does not lead is DetA, which remains essentially unchanged from MOTIP (80.2 vs. 80.4 on DanceTrack), consistent with the paper's focus on ID association rather than detection quality.

## Relation to Prior Work

This paper builds directly on MOTIP (CVPR 2025), a Transformer-based tracker that reformulates MOT as direct ID prediction, and applies a test-time calibration layer on top of its inference pipeline. Conceptually, it extends the cache-based TTA line (Tip-Adapter, DMN, TDA) from static image tasks to the temporal multi-object setting, while explicitly departing from backpropagation-based TTA methods (TENT, FSTTA) in favor of a forward-propagation-only design. The dual-system framing from Kahneman's cognitive theory provides the organizing principle: a fast 'Intuitive' system using transient memory of recent objects, and a slower 'Experiential' system using accumulated cross-video experience, which is a novel conceptual mapping onto the ID-association problem.

## Why It Matters / Open Questions

The forward-propagation-only design makes TCEI practical for real-time deployment where backpropagation-based TTA is infeasible, and the dual-memory architecture offers a clean, interpretable mechanism for combining short-range and long-range temporal cues during online inference. However, the gains are modest (+1.1 HOTA on DanceTrack, +0.4 on SportsMOT) and validated on only two datasets with a single base tracker (MOTIP), leaving open whether the approach generalizes to other architectures (e.g., SSM-based trackers) or to more severe distribution shifts. An open question is whether the experience cache requires periodic resetting when the test domain changes substantially, and whether the entropy-based selection of reflective cases remains effective under extreme appearance variation.

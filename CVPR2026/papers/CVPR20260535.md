## Problem

Existing DNN verification methods handle perturbations in isolation: interval-based verifiers support independent pixel-wise (ℓ∞) perturbations but cannot model spatial dependencies, while recent convolutional-perturbation verifiers are restricted to linear combinations of a small set of predefined target kernels. No prior approach can simultaneously verify robustness against both convolutional distortions (e.g., motion blur) and independent pixel noise (e.g., sensor noise) that co-occur in real-world CV scenarios, leaving a critical gap in assessing robustness under realistic conditions.

## Input / Output

VeriDou takes a trained network N, a single input image X ∈ ℝ^d, per-kernel-entry bounds [z_L, z_U]^{k1×k2} defining the universal convolutional perturbation space, a scalar radius ε_R for the ℓ∞ pixel perturbation, and a binary coverage mask C ∈ {0,1}^d specifying which pixels receive independent noise. The output is a formal verdict (SAT, UNSAT, or TIMEOUT) over the entire Cartesian-product perturbation space S = [z_L,z_U]^{k1×k2} × [−ε_R,ε_R]^d; when SAT, a concrete counterexample (adversarial image) is returned. Because the dual perturbation is encoded as an extended input dimension on a single affine layer, the problem is handed to standard verifiers (αβ-CROWN, NeuralSAT, Venus) without any modification to their core algorithms.

## Method

VeriDou's core contribution is a universal convolutional perturbation (Def. 1) in which every kernel entry is an independent variable z_ij bounded in [l_ij, u_ij], eliminating the restriction to predefined target-kernel combinations and enabling verification over continuous kernel neighborhoods (e.g., all blur angles between 0° and 45° in a single instance). This convolutional component is combined with an independent ℓ∞ pixel perturbation (gated by coverage mask C) into a unified 'dual perturbation' vector s = [Z, R×C]. The key architectural trick is to pre-convolve the input X with each unit kernel U_ij to obtain a fixed matrix W_C, then collapse both perturbation types into a single affine layer L(s) = [Z, R×C]·[W_C; Id] + X that is prepended to the original network, yielding M = N ∘ L. Because L is affine and the perturbation space S is a hyper-rectangle, any off-the-shelf DNN verifier can check the robustness property ∀s∈S: argmax(M(s)) = argmax(N(X)) without modification. The paper proves that universal perturbations subsume all transformations expressible by restricted perturbations, and empirically shows that dual perturbations expose up to 99% adversarial examples on networks that existing methods certify as fully robust.

## Results

Across 14,340 verification instances on five networks (MNIST-FC, Oval21, Sri-ResNet-A, CIFAR100, TinyImageNet), dual perturbations yield 65–99% SAT (adversarial example) rates, compared to 0–20% for independent perturbations and up to 53% for restricted convolutional perturbations. On CIFAR100, SAT jumps from 0% (independent) to 85% (universal) to 99% (dual); on TinyImageNet, from 20% to 70% to 99%. Even on robustly trained Oval21 networks, dual perturbations still expose 24% SAT instances. Adversarial examples maintain high perceptual fidelity with SSIM ≈ 0.8 and LPIPS < 0.3, and average verification runtime is ~5 s (αβ-CROWN backend).

## Baselines & Comparisons

The paper's primary comparison is across perturbation types rather than competing verification frameworks. Independent (ℓ∞) perturbations find the fewest adversarial examples (0–20% SAT), restricted convolutional perturbations improve this to 5–53%, and universal convolutional perturbations reach up to 89%. Dual perturbations (the proposed combination) consistently outperform all single-type baselines, reaching 65–99% SAT, demonstrating that neither convolutional nor independent perturbations alone achieve the coverage of their combination. Among the three verifier backends, VeriDou_VS (Venus) shows the sharpest contrast: only ~20 SAT instances under restricted perturbations versus >100 under universal and dual kernels, indicating restricted perturbations severely underestimate vulnerability. The paper also notes that existing verifiers (αβ-CROWN, NeuralSAT, Marabou, PyRAT) natively support only independent perturbations, while prior convolutional-perturbation work (Brückner et al. [6], Mziou-Sallami et al. [30], Ruoss et al. [33]) handles only restricted kernel spaces—none support both perturbation types simultaneously, which is the gap VeriDou fills.

## Relation to Prior Work

This paper extends the restricted convolutional perturbation framework of Brückner et al. (AAAI 2025), which parameterizes kernels as convex combinations of a small set of predefined target kernels, to a universal formulation where each kernel entry is an independent variable within specified bounds. It further departs from the broader DNN verification literature (αβ-CROWN, NeuralSAT, Venus), which has focused almost exclusively on independent ℓ∞ perturbations or, in a few recent works, restricted convolutional perturbations, by unifying both perturbation types into a single affine pre-layer that any existing verifier can consume without modification. The key conceptual departure is that no prior verifier handles simultaneous convolutional and independent perturbations, and none supports arbitrary (non-convex-combination) kernel coefficient spaces.

## Why It Matters / Open Questions

The central empirical finding—that networks certified robust (up to 100% UNSAT) under restricted or independent perturbations exhibit 65–99% adversarial examples under dual perturbations—challenges the practical value of current single-type robustness certifications in safety-critical CV deployments. This suggests that existing verification pipelines may provide misleadingly optimistic safety guarantees, motivating the field to adopt broader perturbation spaces. Open questions include whether the universal kernel space is too permissive (over-approximating physically realizable distortions), how the approach scales to larger networks (e.g., ImageNet-scale ResNets) where the expanded input dimensionality may cause verifier timeouts, and whether domain-specific kernel priors can tighten the space without losing the expressivity gains.

## Problem

Discriminative vision models such as ViTs lack any mechanism to determine which contextual examples would actually improve their predictions, relying instead on static similarity metrics (e.g., CLIP or DINO embeddings) that implicitly assume perceptual resemblance equals task usefulness. While retrieval-augmented generation has taught generalist LLMs to learn what to retrieve, specialist vision architectures remain unable to dynamically select helpful context, leaving a critical gap in how discriminative models incorporate external visual information.

## Input / Output

The method takes a 256×256 RGB query image and a fixed candidate pool of Nc images (sampled from 20% of the training set, with query-associated images excluded to prevent leakage) and produces a selected context image paired with the query. The downstream task network receives concatenated patch embeddings of both images (for classification) or processes them through gated cross-attention blocks (for segmentation), outputting a class label or pixel-level segmentation mask. The Selector itself outputs a discrete selection index over the candidate pool, with selection probabilities derived from dot-product utility scores between query and candidate embeddings.

## Method

TACS jointly trains a Selector network and a Downstream Task Network (both ViT-S/16 with DINOv3 initialization) through a hybrid optimization scheme. The Selector computes utility scores via dot products between query and candidate embeddings, converting them to selection probabilities; the downstream model then predicts using the query paired with the selected context. Training combines two complementary paths: a differentiable sampling path using straight-through Gumbel-Softmax reparameterization that enables end-to-end gradient flow through the task loss, and a policy optimization path where the Selector acts as an RL agent receiving reward equal to the reduction in task loss when the retrieved context is added versus using the query alone. The joint objective L_TACS = L_grad + λ·L_policy ensures the Selector learns task-aligned utility rather than visual similarity, with the differentiable path stabilizing early training and the policy path sharpening discrete selection decisions through reward feedback.

## Results

Across 11 fine-grained natural image classification datasets, TACS achieves an average accuracy of 88.3%, improving by +1.7% over the frozen DINOv3 similarity retrieval baseline (86.6%), with the largest gains on CUB-200 (+3.8%, 85.2 vs 81.4) and SUN397 (+2.6%, 71.8 vs 69.2). On four medical classification datasets, TACS reaches 92.9% average, a +0.9% improvement over DINO retrieval, with the strongest gain on DDSM (+1.3% AUC, 97.4 vs 96.1). On three medical segmentation benchmarks, TACS achieves up to +1.1 IoU over the best baseline on Kvasir-SEG (81.1 vs 80.0) and +0.6 Dice on DRIVE (78.1 vs 77.5).

## Baselines & Comparisons

TACS is compared against four baselines: No-Context (query only), Random Context Retrieval, Frozen DINOv3 Similarity Retrieval (the primary learned-retrieval comparison, based on Zhao et al. 2025), and Feature-Averaged Context (soft top-k aggregation without reinforcement). TACS wins on every dataset in both the fine-grained and medical classification tables, outperforming the frozen DINO baseline by +1.7% average on fine-grained tasks and +0.9% on medical tasks. The gap is largest where intra-class ambiguity is highest: CUB-200 (+3.8%), SUN397 (+2.6%), and DDSM (+1.3% AUC), suggesting that similarity-based retrieval fails precisely when complementary (rather than near-duplicate) examples are most informative. The Feature-Averaged Context baseline, which uses the same utility scores but without the policy-gradient path, trails TACS by 1.6% on fine-grained and 0.8% on medical, confirming that the discrete reward signal contributes meaningfully beyond smooth gradient supervision. On segmentation (Table 3), TACS also leads all baselines on every metric, with the clearest margin on Kvasir-SEG (+1.1 IoU over DINO retrieval).

## Relation to Prior Work

TACS extends the retrieval-augmented learning paradigm from NLP (RAG, SmartRAG, RAGDDR) to discriminative vision models, where prior work has treated retrieval as a static, similarity-driven preprocessing step using frozen embeddings (CLIP, DINO). The hybrid optimization combining straight-through Gumbel-Softmax (Jang et al., ICLR 2017) with policy-gradient reinforcement is borrowed from differentiable/reinforcement-based retrieval in generative settings but is applied here for the first time to task-aligned selection in ViT-based classifiers and segmentors. The key departure from prior vision retrieval methods (REACT, SWAT, few-shot retrieval) is that selection becomes a learnable, per-instance component of inference rather than a fixed heuristic, with the selector receiving direct gradient and reward feedback from the downstream task loss.

## Why It Matters / Open Questions

TACS addresses a concrete gap: specialist vision models lack any mechanism to dynamically incorporate retrieved context, unlike generalist LLMs that have learned what to retrieve. The finding that the learned policy preferentially selects cross-class, perceptually diverse examples (40–70% higher cross-class rate) over near-duplicates challenges the implicit assumption that visual similarity equals task usefulness, with practical implications for data-limited domains like medical imaging where annotations are scarce. Limitations include reliance on a fixed candidate pool, a single retrieved example per query, and evaluation only on ViT-S/16; open questions include scaling to larger pools, extending to video and multimodal settings, and whether the complementary-selection behavior generalizes beyond the tested architectures.

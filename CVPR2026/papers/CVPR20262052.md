## Problem

Existing robot policies rely on opaque learned visual embeddings that lack explicit structure, making their decision-making process difficult to interpret and sensitive to visual distractions. While scene graphs offer a structured alternative, prior graph-based imitation learning methods are either plan-based or treat graphs as auxiliary input rather than the direct state representation for step-wise goal-conditioned imitation learning.
![Teaser figure](../imgs/CVPR20262052/cropped_page1_idx0.webp)

## Input / Output

The method consumes RGB or RGB-D images from static cameras (dual left/right views for RoboCasa, single view for CALVIN) along with a natural-language goal. Objects are extracted via segmentation masks and encoded into node features using one or more modalities (one-hot labels, ResNet18 cropped-image embeddings, normalized bounding-box coordinates, or PointNet point-cloud embeddings), with edge features initialized to geometric distances. The model outputs 10 future robot actions via a downstream action generator (MDT or BC-Transformer) and, as a byproduct, a learned sparse sub-graph that serves as an interpretable explanation of which scene objects the model deemed task-relevant.

## Method

SIR constructs a fully connected scene graph from extracted objects, then applies a learnable sparsification module (FiLMDecoder: a two-layer Transformer-Decoder with AdaLN conditioning on the language goal) that scores every node and retains only the top-k most relevant ones before any message passing occurs. A soft histogram loss prevents score collapse, and an L1 loss on node weights provides instruction-grounded guidance. The sparse sub-graph is embedded by a two-layer GATv2 GNN adapted so that edge weights are the product of endpoint node weights (NW(u)·NW(v)), guaranteeing that pruned nodes contribute zero information to the final graph embedding; global average pooling is similarly weighted by node scores to preserve gradient flow. This end-to-end node removal prior to message passing is the key distinction from GNN pooling layers (e.g., DiffPool, SAGPool), which select nodes after information has already propagated, making the resulting sub-graph a faithful, intrinsically explainable intermediate representation rather than a post-hoc attribution.

## Results

On RoboCasa (24 atomic tasks, MDT action generator, 100 rollouts), SIR achieves a 19.50% average success rate, outperforming the image-based baseline (14.81%) by 4.69 percentage points and the unsparsified Fully-Connected-Graph (16.98%) by 2.52 points. The largest gains appear in Doors (30.25% vs 25.13%), Levers (48.50% vs 23.67%), and Knobs (16.50% vs 7.25%), while Drawers and Pick/Place remain at or below the image baseline. When 3–9 novel distractor objects are added at inference, the image baseline drops by 3.3% on average, whereas SIR and the FC-Graph model show virtually no degradation, confirming superior robustness.

## Baselines & Comparisons

The primary baseline is an image-based policy using a fine-tuned ResNet18 backbone, which achieves 14.81% average success on RoboCasa. SIR (19.50%) outperforms this baseline by 4.69 points overall, with particularly large margins on Doors (+5.12), Levers (+24.83), and Knobs (+9.25), though it trails on Drawers (46.25% vs 49.75%) and Pick/Place (0.13% vs 1.19%). The unsparsified Fully-Connected-Graph (16.98%) already surpasses the image baseline, confirming that structured graph representations are inherently more effective than raw image embeddings for this task. In the distractor-robustness evaluation, the image baseline degrades by 3.3% when 3–9 unseen objects are added, while SIR and the FC-Graph model maintain or even slightly improve their performance, demonstrating that graph-based representations are significantly more robust to visual distractions. Ablations further show that the soft-histogram loss is the most critical component of the sparsification module, with its removal (Naive NR) dropping performance from 19.50% to 9.60%.

## Relation to Prior Work

SIR departs from the dominant paradigm of using learned visual embeddings (from CNNs or vision foundation models) as opaque state representations in robot policies, instead proposing scene graphs as a structured, interpretable intermediate representation for goal-conditioned imitation learning. It extends prior graph-based IL work (Compose by Focus, InstantPolicy) by operating on larger fully-connected graphs with diverse image-derived modalities rather than small 3-4 node point-cloud graphs, and by eliminating the need for planning algorithms that characterize most graph-based robotics approaches. The sparsification module is conceptually distinct from existing GNN pooling layers (DiffPool, GrePool, SAGPool) because it performs end-to-end node removal *before* message passing, ensuring removed nodes contribute zero information to the final embedding, which is critical for interpretability.

## Why It Matters / Open Questions

The most impactful contribution is not the modest performance gain (19.5% vs 14.81%) but the demonstration that learned sparse sub-graphs serve as a diagnostic tool for uncovering dataset biases—spurious correlations and positional biases—that are invisible in image-based policies. This opens a new avenue for debugging imitation learning datasets by inspecting which objects a model actually attends to. Key limitations include reliance on ground-truth segmentation masks, a task-specific top-k parameter, and evaluation only in simulation (RoboCasa, CALVIN). Open questions include whether the approach transfers to real-world settings with predicted masks, whether the model can learn the number of relevant nodes autonomously, and whether the explainability benefits scale to more complex, open-vocabulary scenes.

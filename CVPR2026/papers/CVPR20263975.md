## Problem

VLA models trained via imitation learning frequently fail under Out-of-Distribution conditions in dynamic environments, yet existing runtime monitors either require exhaustive enumeration of failure modes or rely on VLMs with multi-second inference latency. There is no lightweight, unsupervised mechanism that can detect both task-level and state-level OOD in real time (<100 ms) without requiring labeled failure data.
![Teaser figure](../imgs/CVPR20263975/cropped_page0_idx0.webp)

## Input / Output

The method consumes a video stream (segmented by SAM2 into object masks, then grid-sampled into B×T×N×2 point sets), robot proprioception (T-dimensional joint angles, gripper state, and Cartesian pose), and a natural-language task prompt (encoded as T-dimensional spherical uniform vectors on a hypersphere of radius R). It outputs a scalar anomaly score (negative log-likelihood under the learned conditional density) at each time step; when the score exceeds a conformal-prediction-derived threshold, it emits a binary OOD signal that triggers either task-level replanning or state-level homing/rollback, operating in parallel with the VLA policy as a plug-and-play module.

## Method

RC-NF is a conditional normalizing flow (K=12 Glow-style steps) trained unsupervised on successful demonstrations to model the joint distribution p(x_target, s | task). The key architectural contribution is RCPQNet, a novel affine coupling layer that replaces the standard coupling network: it uses Task-aware Robot-Conditioned Queries (robot state projected linearly and modulated by the task embedding via FiLM) as query tokens and Dual-Branch Point Feature Encoding (a Dynamic Shape branch for translation/scale-invariant shape features and a Positional Residual branch for absolute spatial information, each processed by GRU + Transformer encoder) as memory tokens in cross-attention. The point set is split along the temporal dimension; one half generates the scale γ and shift β via RCPQNet while the other is affinely transformed, preserving invertibility. This decoupled query-memory design lets the model reason jointly about robot-object motion without feature entanglement, and the task embedding on the hypersphere ensures maximal separation between different task distributions, enabling task-specific anomaly detection from a single unified model.

## Results

On the LIBERO-Anomaly-10 benchmark, RC-NF achieves an average AUC of 0.9309 and AP of 0.9494 across three anomaly types (Gripper Open, Gripper Slippage, Spatial Misalignment), surpassing the best VLM baseline (GPT-5) by approximately 8% in AUC and 10% in AP. RC-NF is particularly strong on Spatial Misalignment (AUC 0.9676, AP 0.9585), where all VLM baselines degrade to near-random performance (AUC ≈ 0.49–0.53). In real-world deployment on a Franka Research 3 arm, RC-NF detects anomalies within 100 ms on an RTX 3090 and enables both task-level replanning and state-level trajectory rollback for the π₀ VLA policy.

## Baselines & Comparisons

RC-NF outperforms all four baselines across every anomaly type and metric. Against the strongest VLM baseline (GPT-5, avg AUC 0.8500 / AP 0.8507), RC-NF gains roughly 8% AUC and 10% AP on average; the gap is most dramatic on Spatial Misalignment, where GPT-5 scores only 0.4904 AUC (near random) while RC-NF reaches 0.9676. Gemini 2.5 Pro and Claude 4.5 show similar patterns—competitive on Gripper Open and Slippage but collapsing to AUC ≈ 0.5 on Spatial Misalignment—confirming that VLMs struggle to align visual semantics with fine-grained spatial reasoning. The flow-based FailDetect baseline (avg AUC 0.7181 / AP 0.7700) is the weakest overall, lagging RC-NF by over 21% in AUC; the paper attributes this to FailDetect's entangled concatenation of raw image and robot-state features versus RC-NF's decoupled point-set and robot-conditioned query design. In real-world experiments, π₀ alone fails on both task-level (drawer closing) and state-level (ball repositioning) OOD events, while π₀ + RC-NF recovers successfully in both cases with sub-100 ms detection latency.

## Relation to Prior Work

RC-NF extends the Glow normalizing flow architecture by replacing its standard affine coupling layers with a novel Robot-Conditioned Point Query Network (RCPQNet) that injects task embeddings and robot proprioception as conditioning signals. It departs from prior runtime monitoring approaches that either frame failure detection as a classification problem requiring exhaustive anomaly enumeration (behavior trees, precondition networks) or rely on VLMs with multi-second chain-of-thought latency (Sentinel). The method also draws inspiration from skeleton-based video anomaly detection in pedestrian scenarios, repurposing normalizing flows for the robotic manipulation domain, while using SAM2-derived point-set representations instead of the raw image features employed by the closest prior method, FailDetect.

## Why It Matters / Open Questions

RC-NF provides a practical, plug-and-play monitoring module that operates within 100 ms, making it compatible with closed-loop VLA control where multi-second VLM-based monitors are infeasible. The LIBERO-Anomaly-10 benchmark, with its three manipulation-specific anomaly types, fills a gap left by prior datasets focused on generalized task failures. Open questions include whether the point-set approach generalizes to tasks without clearly segmentable objects, how the method scales to multi-object or long-horizon manipulation, and whether the SAM2 dependency (requiring a bounding-box prompt) limits deployment flexibility. The real-world validation on a Franka arm with π₀ is encouraging but limited to a single task family.

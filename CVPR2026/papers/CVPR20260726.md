## Problem

Spatio-temporal memory systems for robotics and AR face a fundamental tradeoff: producing rich open-vocabulary semantic descriptions requires expensive per-object VLM queries that preclude real-time operation, while fast closed-vocabulary methods lack the expressiveness needed for complex natural language queries. View-based alternatives (e.g., ReMEmbR) store per-frame annotations without 3D grounding, failing at spatial reasoning and long-range consistency. No existing framework simultaneously delivers detailed semantic descriptions, geometric 3D grounding, and real-time performance at large scale.

## Input / Output

The system consumes a continuous RGB-D video stream at 10 Hz sensor rate along with camera poses, processing it on a single NVIDIA RTX 5090 GPU. It produces a hierarchical 4D scene graph where object nodes, place nodes (traversability-based ground rectangles), and region nodes each carry detailed natural-language descriptions, CLIP and Sentence-T5 embeddings, 3D positions, and timestamped description histories. The 4D SG is queried via a tool-calling LLM agent that retrieves objects by semantic search, accesses region summaries, and reasons over spatial and temporal metadata to answer natural language questions.

## Method

DAAAM decouples fast geometric tracking from expensive semantic annotation through a two-stage pipeline. The frontend runs Fast-SAM segmentation and Bot-Sort tracking at 10 Hz within a Khronos active window, lifting fragments to 3D via Hydra. The key novelty is an optimization-based frame selection that formulates minimum-frame coverage as a set cover problem, then solves a binary linear program to assign each fragment to its highest-quality visible frame (using a position-entropy and size-saturation heuristic). Selected frame-mask pairs are batched into a single tensor for the Describe Anything Model (DAM-3B), achieving an order-of-magnitude inference speedup over per-object queries. The backend globally optimizes node positions via factor graph, reconciles repeated observations by merging similar fragments with appended description histories, and clusters the graph into semantically informed regions using most-stable-clique finding. A tool-calling agent then performs retrieval-augmented reasoning over the resulting 4D SG.

## Results

On the OC-NaVQA benchmark (up to 35.8 min, 1.64 km), DAAAM achieves 71.1% question accuracy, 41.75 m positional error, and 1.79 min temporal error, outperforming the best view-based baseline ReMEmbR+NVILA-Lite-8B (46.3% accuracy, 55.89 m, 4.11 min) by 53.6% in accuracy, 21.9% in positional error, and 21.6% in temporal error. On the original NaVQA benchmark, DAAAM reaches 67.2% overall question accuracy with 33.89 m positional error and 1.59 min temporal error, surpassing all baselines including ReMEmbR+VILA1.5-13b (61% accuracy). For sequential task grounding on SG3D, DAAAM achieves 22.16% sub-task accuracy and 11.22% task accuracy, exceeding the specialized method ASHiTA (21.7% / 8.78%) by 27.8% in task accuracy.

## Baselines & Comparisons

DAAAM decisively outperforms the view-based memory system ReMEmbR [3] across all three SQA metrics on OC-NaVQA: 71.1% vs. 46.3% question accuracy (best ReMEmbR variant), 41.75 m vs. 55.89 m positional error, and 1.79 min vs. 4.11 min temporal error. Against the metric-semantic mapping baseline ConceptGraphs [16], DAAAM wins by a wide margin (71.1% vs. 29.9% accuracy) and is the only method that tracks temporal information (ConceptGraphs reports '×' for temporal error). On the original NaVQA benchmark, DAAAM (67.2% accuracy) beats ReMEmbR+VILA1.5-13b (61%) and all NVILA-Lite variants, with the largest gains on Long sequences (78.6% vs. 71.4% for NVILA-Lite-8B). For sequential task grounding on SG3D, DAAAM (11.22% t-acc) surpasses the specialized hierarchical method ASHiTA [6] (8.78%) and the Hydra-based baselines [22] (2.44–6.34%), demonstrating that detailed open-vocabulary descriptions in a 4D scene graph generalize well to task grounding without task-specific architecture. The retrieval ablation (Table 4) shows that concatenating CLIP features with DAM sentence embeddings outperforms either alone (e.g., 25.11% vs. 19.59% Top-1 on refCOCOg), confirming complementary information between the two modalities.

## Relation to Prior Work

DAAAM sits at the intersection of two established paradigms: metric-semantic 3D scene graph construction (Hydra, Khronos, Kimera) and view-based semantic memory systems (ReMEmbR, Embodied-RAG). It departs from prior metric-semantic approaches by replacing closed-vocabulary segmentation with detailed open-vocabulary descriptions from the Describe Anything Model, and from view-based systems by grounding all annotations in a globally consistent 4D scene graph. The key architectural departure is the optimization-based frame selection that enables batch inference of a 3B-parameter captioning model in real-time, bridging the gap between geometric precision and semantic richness that prior methods could not simultaneously achieve.

## Why It Matters / Open Questions

DAAAM provides a practical, real-time (10 Hz) spatio-temporal memory that scales to 35+ minute sequences and 1.5 km traversals, making it directly applicable to mobile robot autonomy and augmented reality. The OC-NaVQA benchmark addresses concrete annotation flaws in NaVQA (view-position vs. object-position ground truth, confounding in-context examples) that had been skewing comparisons. Open questions remain around handling state transformations (e.g., cutting objects), bounding the growth of description histories in dynamic nodes, and whether the modest 1.5M-sample DAM training corpus limits generalization to out-of-distribution objects. The ablation revealing that explicit descriptions improve spatial/temporal reasoning but slightly hurt binary question accuracy (where image crops suffice) suggests future systems may need adaptive annotation strategies.

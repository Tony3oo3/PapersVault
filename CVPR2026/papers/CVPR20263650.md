## Problem

State-of-the-art VLMs produce frequent sample-level OCR errors that evade detection by conventional benchmark metrics, and existing quality-assessment approaches—VLM-as-Judge and cross-validation—suffer from evaluator bias, preference leakage, and inability to verify visual-textual consistency. There is no training-free, model-agnostic mechanism to estimate per-sample OCR reliability without ground-truth labels.
![Teaser figure](../imgs/CVPR20263650/cropped_page0_idx0.webp)

## Input / Output

The framework consumes a single input image and the OCR text predictions from n independent VLMs (n typically 3–5). It produces three outputs: a scalar Consensus Entropy score δ ∈ [0,1] quantifying inter-model agreement, a binary routing decision (ensemble-accept vs. expert-rephrase) determined by comparing δ against a calibrated threshold θ, and a final OCR string—either a token-level weighted ensemble or a rephrased prediction from a stronger VLM. For character-level tasks, pairwise similarity is computed via normalized Levenshtein edit distance at each position; for semantic tasks, cosine similarity over bge-m3 embeddings is used instead.

## Method

The core insight is that correct VLM predictions converge in output space while errors diverge, enabling a label-free uncertainty signal. Consensus Entropy (CE) computes normalized pairwise edit-distance (or embedding cosine) similarities between all model output pairs, derives a per-position probability distribution, and aggregates pairwise entropies into a per-output average entropy distance. A kernel density estimate over the output space—weighted inversely by each output's average entropy distance—yields the final scalar δ, with the Mean Distance aggregation chosen for grid-invariance and order-preservation. When δ ≤ θ, a token-level weighted ensemble selects the highest-consensus token at each aligned position; when δ > θ, the sample is routed to a stronger VLM that receives the image, all model outputs, and the ensemble prediction as context for rephrasing. The entire pipeline is training-free and model-agnostic, requiring only inference access to any set of VLMs.

## Results

On OCRBench, CE-OCR with adaptive routing achieves a cumulative score of 922 (best model: Qwen2.5-VL-72B), an 8.2% improvement over the best single model (888) while routing only 7.3% of samples to a stronger VLM. On OCRBench-V2, CE-OCR (GPT-4o rephrase) reaches 71.6 (English OCR), 53.1 (Math), 33.8 (Element Parsing), and 48.0 (Chinese Overall), outperforming the best single model by 3.7–11.3% relative. For unsupervised quality verification, CE achieves F1 scores of 48.0–51.3 across reference models, a 42.1% relative gain over VLM-as-Judge (36.1–40.0). CE-Ensemble also surpasses the prior SOTA of 926 on OCRBench, reaching 955 with a 4-model combination of small open-source VLMs.

## Baselines & Comparisons

CE-OCR substantially outperforms Self-Consistency (SC@3): the routing-based approach scores 907 (average) and 922 (best) on OCRBench versus SC@3's 828 and 875, a 6.5–8.2% gain, because CE dynamically selects processing strategies rather than averaging identical-prompt samples. Against ROVER, CE-Ensemble wins decisively across all four task categories (+8.2% average), while ROVER collapses on open-ended VLM tasks (Doc-VQA −42.1%, Math −92.0%) due to its reliance on discrete word-level voting that fails with diverse VLM phrasing. VL-Uncertainty achieves only a marginal +0.2% average gain and actually degrades on Doc-VQA (−10.1%) and KR (−3.5%), because its semantic-embedding clustering is blind to character-level differences critical for OCR; CE-Ensemble improves on all four categories. On OCRBench-V2, CE-OCR (GPT-4o rephrase) beats GPT-4o alone by 9.1–11.3% relative across English OCR, Math, and Chinese Overall, and surpasses the best single model (InternVL2.5-26B) by 3.7–11.3%. For quality verification, CE outperforms VLM-as-Judge (GPT-4o, Qwen2-VL-7B, Qwen2-VL-72B) by 20.0–42.1% in F1 on human-annotated PDF pages, confirming that inter-model agreement is a more reliable quality signal than a single judge model's assessment.

## Relation to Prior Work

This paper repurposes the multi-model consensus idea from LLM ensemble literature (output selection, pairwise ranking) and uncertainty estimation (semantic entropy, calibrated confidence) into a training-free OCR quality metric. It departs from VLM-as-Judge paradigms, which rely on a single evaluator model and suffer from preference leakage and format bias, by instead measuring the entropy of pairwise output similarities across independent VLMs. The adaptive routing mechanism extends simple ensemble aggregation by adding a threshold-gated escalation to stronger models, drawing on model-routing literature but applying it specifically to OCR uncertainty. Unlike ROVER, which performs discrete word-level voting suited to closed-vocabulary ASR, CE operates in continuous similarity space and handles the open-ended, diverse phrasing of VLM outputs.

## Why It Matters / Open Questions

The framework addresses a practical gap: even state-of-the-art VLMs produce sample-level OCR errors that global benchmark scores mask, and no existing method provides cheap, unsupervised per-instance quality verification. The 42.1% F1 gain over VLM-as-Judge and the ability to route only 7.3% of samples to expensive models make this directly deployable in data pipelines feeding LLM training. Open questions include whether the convergence-divergence pattern generalizes to non-OCR multimodal tasks (the paper shows preliminary VQA results), how CE behaves as the number of ensemble models grows beyond 5, and whether the threshold θ can be learned automatically rather than set empirically. A limitation is that the method requires multiple model inferences per image, which, while shown to be cost-effective with small models, still multiplies inference overhead relative to a single VLM call.

## Problem

Existing vision-language tracking methods rely on static, pre-defined language descriptions that suffer from semantic drift as the target moves through changing contexts, and they degrade or fail entirely when no textual description is available. The paper asks whether useful linguistic guidance can be generated implicitly from visual features alone, eliminating the need for explicit text input while retaining the benefits of cross-modal semantic alignment.
![Teaser figure](../imgs/CVPR20261358/cropped_page0_idx1.webp)

## Input / Output

The method takes the same inputs as standard one-stream trackers: a video clip of N template frames (or N discrete template images) and a single search image, and outputs a target bounding box in the search image. Crucially, no explicit text or language annotation is required at inference time; all linguistic representations are generated internally from the visual embeddings. The module is plug-and-play, meaning it can be inserted into existing trackers (MCITrack, DUTrack, SeqTrack) without altering their input/output interface, adding roughly 10 FPS of overhead dominated by the frozen CLIP text encoder.

## Method

The proposed TIMI module has two components. First, a Textual Inversion Module concatenates patch-level visual embeddings from the template and search regions, then maps them via Projection, MLP, and Alignment operations into the CLIP text embedding space, producing fine-grained pseudo-description tokens that function as both a tokenizer and an embedding lookup layer. These tokens are processed by a frozen CLIP text encoder (clip-vit-large-patch14) to extract high-level linguistic features. Second, a Multi-Layer Semantic Injection Mechanism divides both the visual backbone and the CLIP text encoder into four corresponding blocks; at each block pair, a cross-attention module uses the text features as Query and the visual features as Key/Value, with a learnable scaling factor, to modulate the visual feature distribution. Training is two-stage: the original tracker is first trained normally, then both backbones are frozen and only the Textual Inversion Module, Semantic Injection layers, and decoder are trained for 10 epochs, leveraging the pre-trained CLIP text-visual priors without requiring any text input.

## Results

On LaSOT, MCITrack-B224* achieves 76.1% AUC and 86.4% PNorm, surpassing the original MCITrack-B224 (75.3% AUC) and the previous vision-only SOTA SPMTrack-B378 (74.9% AUC). On GOT-10K, MCITrack-B224* reaches 79.4% AO and 80.0% SR0.75, a +1.5% AO gain over the base model. On TNL2K (vision-language tracking), DUTrack-B256* achieves 67.2% AUC and 85.6% PNorm, outperforming the original DUTrack-B256 by 2.3% AUC and all other vision-language baselines. The improvements come with only ~10 FPS overhead, of which 7 FPS is attributable to the frozen CLIP text encoder.

## Baselines & Comparisons

The proposed TIMI module is integrated into three base trackers (SeqTrack, MCITrack, DUTrack) and consistently improves them across all four benchmarks. On LaSOT, MCITrack-B224* (76.1% AUC) surpasses the previous vision-only SOTA SPMTrack-B378 (74.9% AUC) by 1.2%, and SeqTrack-B256* gains +1.1% AUC over its base. On GOT-10K, MCITrack-B224* achieves 79.4% AO, beating ODTrack-B384 (77.0%) and DreamTrack-B256 (77.5%) by 2.4% and 1.9% respectively. On TNL2K, DUTrack-B256* (67.2% AUC) outperforms MambaVLT (66.5%), UVLTrack (63.1%), and all other vision-language baselines, while also exceeding the vision-only SPMTrack (62.0%). Gains on TrackingNet are minimal (≤0.1% AUC), which the authors attribute to the dataset's higher annotation noise and severe occlusions reducing the reliability of extracted semantic cues. The method requires no explicit text input at inference, distinguishing it from DUTrack (which uses BLIP for dynamic captioning) and all other vision-language baselines that depend on pre-annotated language.

## Relation to Prior Work

This paper carves new ground by repurposing the CLIP text embedding space as a target for inverting visual features into 'pseudo-descriptions,' a concept borrowed from textual inversion in generative models but applied here at patch level for tracking. It departs from the vision-language tracking line (JointNLT, QueryNLT, DUTrack, UVLTrack) that requires explicit, static text input, and from prior attempts to dynamically generate descriptions via LLMs or BLIP (DTVLT, DUTrack) that introduce heavy inference overhead. The plug-and-play design means it does not build on a single prior architecture but rather augments any transformer-based one-stream tracker (SeqTrack, MCITrack, DUTrack) with a frozen CLIP text encoder and a lightweight cross-attention injection mechanism, leveraging the visual-linguistic priors already embedded in CLIP's pre-training.

## Why It Matters / Open Questions

The practical value lies in eliminating the dependency on explicit language annotations while still harnessing the semantic structure of a pre-trained text encoder, making linguistic guidance available in settings where text is unavailable or impractical to generate. However, the ~10 FPS overhead (mostly from the CLIP text encoder) and the modest gains on noisy, in-the-wild data (TrackingNet) limit immediate deployment in latency-sensitive or highly unconstrained scenarios. Open questions include whether the CLIP text space is the optimal inversion target, whether the fixed 4-block division generalizes to arbitrarily deep backbones, and whether the approach can be extended to multi-object or long-horizon tracking where contextual drift accumulates over time.

## Problem

Existing open-vocabulary 3D affordance grounding methods rely on fixed training taxonomies and hand-crafted geometric priors, exhibiting limited geometric invariance and no analogical reasoning capability. A substantial domain gap arises when transferring affordance knowledge from 2D human-object interaction images to 3D point clouds, causing poor generalization to unseen objects and affordance categories. The paper asks whether projecting HOI evidence into 3D space and querying it with a multimodal attention mechanism can close this gap and enable category-level reasoning.

## Input / Output

The method consumes a 3D object point cloud (2048 points), a single HOI RGB image, and two text prompts (interaction attributes and geometric attributes) generated via Chain-of-Thought from a VLM following GREAT's protocol. The HOI image is first mapped into 3D space via the VGGT feed-forward reconstruction pipeline, yielding a 6-dimensional per-point representation that serves as the 3D HOI feature. The output is a point-wise affordance probability map (N×1 sigmoid scores) indicating the likelihood that each point on the target object belongs to a functional interaction region.

## Method

QueryMe projects the 2D HOI image into 3D space via VGGT, then applies an Adaptive Spatial Attention module that samples points, models local topology with a 1D convolution, assigns importance scores, and propagates them to the full point cloud via inverse-distance-weighted interpolation to suppress background clutter. A Multimodal Feature Encoding stage uses dual RoBERT encoders (with bidirectional cross-attention) for text, a two-layer PointNet++ on top-k importance-ranked HOI points for 3D interaction geometry, and a hierarchical PointNet++ for the object point cloud, with cross-attention fusing text into each geometric stream. The core novelty is a Multimodal Guided Query Learning decoder: learnable query vectors are initialized at farthest-point-sampled locations, and at each of n layers they attend to the three modality features in a fixed coarse-to-fine order (text → 3D HOI → object points), followed by self-attention to abstract intrinsic geometry, with MLP positional encoding injected at every step. A lightweight query-attention head over the fused point features produces the final affordance map, trained with focal and Dice losses on point-wise heatmaps without explicit affordance-category supervision.

## Results

On PIADv2, QueryMe achieves 92.34 AUC / 39.39 aIOU / 0.683 SIM / 0.061 MAE on the Seen split, 83.03 AUC / 21.76 aIOU / 0.420 SIM / 0.118 MAE on Unseen Object, and 74.00 AUC / 13.76 aIOU / 0.316 SIM / 0.097 MAE on Unseen Affordance. The headline gain is a 4.19% AUC improvement over the runner-up GREAT on the Unseen Affordance split, and a 3.46% AUC improvement on Unseen Object. QueryMe also attains the best MAE (0.097) on Unseen Affordance, indicating tighter spatial localization of affordance regions.

## Baselines & Comparisons

QueryMe outperforms all five baselines on AUC, aIOU, and SIM across all three evaluation splits. Against the strongest competitor GREAT [29], QueryMe gains +0.35% AUC and +1.36% aIOU on Seen, +3.46% AUC and +1.60% aIOU on Unseen Object, and +4.19% AUC and +1.71% aIOU on Unseen Affordance. The sole metric where QueryMe trails GREAT is MAE on Unseen Object (0.118 vs. 0.109), which the authors attribute to small activation scores on a few non-affordance points near the target region being amplified by the small 2048-point budget. Compared to LASO [17], the gap widens substantially under unseen conditions: QueryMe leads by 9.71% AUC on Unseen Object and 9.93% AUC on Unseen Affordance. The cross-modal baselines FRCNN [40] and XMF [1] lag far behind, with FRCNN scoring only 59.08 AUC on Unseen Affordance versus QueryMe's 74.00, underscoring the benefit of the 3D HOI projection and multimodal query mechanism over simpler fusion strategies.

## Relation to Prior Work

QueryMe builds directly on GREAT [29] for its overall pipeline (VLM chain-of-thought text extraction, evaluation protocol, and loss design) but departs from the broader 3D affordance grounding lineage (IAG, LASO, GREAT) in a key architectural way: rather than consuming 2D HOI image features or 2D projections of point clouds, it projects HOI images into 3D space via a feed-forward monocular reconstruction (VGGT) and then applies a sequential cross-attention query mechanism that retrieves evidence in the fixed order text → 3D HOI → object point cloud. The Adaptive Spatial Attention Module for filtering reconstruction noise and the learnable-query decoder with FPS-initialized positional encoding are new components not present in prior affordance grounding systems, positioning the work at the intersection of 3D reconstruction, query-based detection (à la DETR), and point-cloud processing.

## Why It Matters / Open Questions

The core practical insight—that lifting 2D HOI cues into a shared 3D geometric space before fusion substantially narrows the 2D-to-3D domain gap—offers a reusable recipe for any task that must transfer interaction knowledge from images to point clouds. The 13.5% AUC drop when 3D HOI features are replaced by 2D ResNet features in the Unseen Affordance split provides strong ablation evidence for this claim. However, the method's reliance on VGGT reconstruction quality, evaluation on a single dataset (PIADv2, 43 object / 24 affordance categories), and the modest MAE regression in the Unseen Object setting leave open questions about scalability to larger, noisier real-world scenes and to truly open-world category distributions.

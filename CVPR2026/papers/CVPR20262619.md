## Problem

Existing event stream partitioning strategies either use fixed rules that cannot adapt to scene dynamics or provide only temporal adaptivity while neglecting spatial locality. In heterogeneous velocity scenarios where fast- and slow-moving objects coexist in the same field of view, these strategies fail to simultaneously give fast objects short, responsive windows and slow objects sufficient accumulation time. The paper addresses the absence of a computationally efficient partitioning method that achieves both temporal adaptivity and spatial locality.

## Input / Output

The method consumes an asynchronous event stream where each event carries pixel coordinates (x, y), a timestamp t, and a polarity bit. The pixel plane is divided into non-overlapping square patches of size (s, s) (default s=4), and the algorithm outputs a set of partitioned event groups in which each patch is assigned its own time window length Δt_ij, so that events within the same global timestamp are sliced at different granularities across the image. The resulting partitioned events are then converted into standard event representations (event frames, time surfaces, voxel grids) for downstream detection or tracking networks.

## Method

ASTW derives a patch-level time window from the maximum entropy principle: a binary event frame achieves maximum information entropy when exactly half its pixels are active (p=1/2), which yields the constraint D_ij · Δt_ij = γ, where D_ij is the local event density and γ is an information constant. Event density is computed as the number of events in a reference window divided by patch area, implicitly encoding the product of edge length and velocity without explicit velocity estimation. Spatial smoothing via convolution and temporal smoothing via exponential moving average make the density robust to multi-scale objects and rapid motion changes. A minimum time-step strategy unifies the temporal reference across all patches by advancing the global clock by the smallest window, preserving causal consistency. The entire pipeline is implemented with vectorized operations (integer-division mapping to patch indices, lookup, and timestamp comparison), achieving O(N) complexity and an average latency of 7.43 μs per event.

## Results

On the Gen1 object detection dataset, ASTW achieves 50.6 mAP / 76.0 AP₅₀ with ResNet-50, 46.6 mAP / 75.2 AP₅₀ with Swin V2, and 48.3 mAP / 75.4 AP₅₀ with RVTs, outperforming the second-best method (TORE) by up to 3.0 mAP and 2.1 AP₅₀. On the EventVOT tracking dataset, ASTW attains SR 62.3, PR 60.5, and NPR 85.1. On the newly constructed HetVel dataset, ASTW yields SR 50.7, PR 58.5, and NPR 84.9, improving over the second-best method by 2.1 SR, 2.2 PR, and 2.2 NPR.

## Baselines & Comparisons

ASTW consistently outperforms all 8 baselines across every backbone and dataset. On Gen1 detection, the closest competitor is TORE (spatial locality but no adaptivity), which ASTW surpasses by 2.3 mAP (ResNet-50), 3.0 mAP (Swin V2), and 1.0 mAP (RVTs); the adaptive-only methods (ATS, AEC, AGD, SpikeSlicer) trail ASTW by 1.5–5.6 mAP depending on backbone. On EventVOT tracking, ASTW edges out TORE by 0.2 SR and 0.3 NPR, while the gap over adaptive-only methods (e.g., AEC at SR 58.0) widens to 4.3 SR. On the HetVel dataset specifically designed for heterogeneous velocities, ASTW's advantage is most pronounced: it beats TORE by 2.1 SR / 2.2 PR / 2.2 NPR and outperforms the worst baseline (AEC) by 5.8 SR. Notably, Event Lifetime—another method claiming both locality and adaptivity—underperforms all other baselines on HetVel (SR 46.0), which the authors attribute to its reliance on error-prone per-event velocity estimation.

## Relation to Prior Work

This paper positions itself at the intersection of two partially explored directions in event partitioning: temporal adaptivity (pursued by ATSLTD, ATS, AEC, Adaptive Global Decay, and SpikeSlicer) and spatial locality (pursued by TORE and Event Lifetime). Prior methods achieve one property but not both, or introduce prohibitive computational cost (Event Lifetime). ASTW carves new ground by unifying both under a maximum entropy principle, deriving a closed-form patch-level time window from event density rather than explicit velocity estimation, and achieving O(N) vectorized computation comparable to the simpler TORE baseline.

## Why It Matters / Open Questions

Event partitioning is a universal preprocessing step for all downstream event-based vision tasks, so an efficient, adaptive strategy has broad applicability. The HetVel dataset addresses a genuine gap—no prior benchmark specifically targets heterogeneous velocity scenarios, which are common in autonomous driving and robotics. Open questions include whether the maximum entropy criterion is truly optimal for all event representations (the paper validates primarily on Event Frame), whether the approach scales to very high-resolution sensors with millions of patches, and whether the fixed patch size assumption limits performance in scenes with highly anisotropic motion.

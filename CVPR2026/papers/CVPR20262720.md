## Problem

Existing Chart2Code methods either rely on supervised fine-tuning that never exposes the model to a code execution environment, or apply RL in a one-shot setting that prevents iterative refinement. Critically, even state-of-the-art MLLMs (Qwen3-VL-8B, Qwen3-VL-235B) show negative score improvements on already-executable code between turns, meaning they cannot effectively self-correct. This paper asks how to train a multimodal model that genuinely improves its own chart code through execution feedback.
![Teaser figure](../imgs/CVPR20262720/cropped_page0_idx0.webp)

## Input / Output

The model takes a single chart image as input and produces a thinking trace followed by executable Python (matplotlib) code. In multi-turn mode, the first-turn code is executed; the rendered image (or runtime error message) is concatenated as feedback text, and the model generates a revised code block conditioned on the original image, first-turn output, and feedback. The output format is enforced via a format reward requiring the pattern 'python...'.

## Method

MM-ReCoder (built on Qwen2.5-VL-7B) is trained in two phases: a cold-start SFT on 160k chart-code pairs plus 7k filtered multi-turn self-correction examples, followed by a two-stage multi-turn GRPO. In RL stage 1 (shared-first-turn), a single first-turn output is sampled and shared across the group while G second-turn refinements are rolled out, so the policy gradient only updates the correction step, explicitly teaching the model to improve given feedback. In RL stage 2 (full-trajectory), both turns are jointly optimized with independent rollouts per trajectory. Rewards combine a rule-based component (F1 on chart type/text, CIE Lab color distance, layout row/column matching extracted by hooking Matplotlib's renderer) and a model-based component (Qwen2.5-VL-72B scoring six visual aspects on a 100-point scale), plus a format reward, weighted as (1−α−β)·Format + α·Rule + β·Model.

## Results

On ChartMimic, MM-ReCoder with 4 self-correction turns achieves 86.5% low-level score and 84.9% high-level score, surpassing GPT-4o (79.0/83.5) and Qwen3-VL-235B-A22B (81.3/87.2) on low-level while remaining competitive on high-level. On Plot2Code, it reaches 62.7% text-match score (4 turns) and 63.2% (1 turn), outperforming all open-source baselines including ChartCoder (54.5%) and Qwen3-VL-235B-A22B (60.4%). Compared to its base model Qwen2.5-VL-7B, MM-ReCoder improves ChartMimic low-level score by 48% (56.2→83.5, single-turn) and execution rate by 29% (71.5→92.5). The model also achieves 97.5% execution rate and 98.5% Plot2Code pass rate with 4 correction turns.

## Baselines & Comparisons

MM-ReCoder outperforms ChartCoder [47] by 9.1% in ChartMimic low-level score (86.5 vs 77.4) and 10.9% in high-level score (84.9 vs 74.0), establishing a clear advantage over the strongest chart-domain SFT baseline. Against the much larger Qwen3-VL-235B-A22B [31], MM-ReCoder (4 turns) wins on ChartMimic low-level (86.5 vs 81.3) and Plot2Code text-match (62.7 vs 60.4) but trails on ChartMimic high-level (84.9 vs 87.2). Compared to GPT-4o, MM-ReCoder surpasses it on ChartMimic low-level (86.5 vs 79.0) and Plot2Code text-match (62.7 vs 56.3), while GPT-4o retains a slight edge on ChartMimic high-level (83.5 vs 84.9 is actually a win for MM-ReCoder). Among open-source general-domain MLLMs, MM-ReCoder dominates: it exceeds Qwen2.5-VL-72B (72.3 low-level) by 14.2 points and Qwen3-VL-8B (66.6 low-level) by 19.9 points on ChartMimic. The single-turn RL variant (MM-ReCoder-Single) already achieves 84.3% low-level, confirming that the RL training itself—rather than multi-turn correction—drives most of the gain over the SFT base model.

## Relation to Prior Work

This paper extends GRPO (from DeepSeekMath) to a multi-turn self-correction setting by introducing two novel roll-out strategies—shared-first-turn and full-trajectory optimization—that disentangle the training of self-correction from coding ability. It departs from prior RL-based Chart2Code methods (ChartMaster, VinciCoder) that treat generation as a one-shot task, and from SCoRe's two-stage RL for text self-correction, by applying the paradigm to multimodal coding with execution-based feedback. The cold-start stage builds on ChartCoder's 160k chart-code pairs and augments them with rejection-sampled multi-turn data from Qwen3-VL-235B, while the reward design reuses ChartMimic's rule-based and model-based metrics.

## Why It Matters / Open Questions

The paper provides the first practical recipe for eliciting reliable self-correction in multimodal coding MLLMs, showing that a 7B model can match or exceed 235B-parameter models on chart-to-code benchmarks. A key open question is whether the two-stage shared-first-turn strategy generalizes beyond chart-to-code to other multimodal coding tasks (webpage-to-code, SVG-to-code) or to more than two correction turns, where gains already diminish. The finding that even the largest open-source MLLMs degrade on already-executable code in the second turn suggests that self-correction in multimodal settings is fundamentally harder than in text-only settings and may require task-specific RL rather than scaling alone.

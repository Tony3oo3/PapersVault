## Problem

Existing incremental 3D object detection methods require abundant annotated samples for each novel class, which is impractical in dynamic indoor environments where new object categories continuously emerge. The few-shot incremental 3D detection setting—progressively expanding the detected category space using only a handful of samples per new class while preserving prior knowledge—remains largely unexplored.

## Input / Output

The method takes 3D point clouds (N×6) as primary input, supplemented by corresponding RGB images (H×W×3) and depth maps that feed VLMs (GroundingDINO + SAM) during base training to generate pseudo 3D boxes and 2D semantic features for unknown objects. It outputs 3D bounding boxes (7 parameters: center, size, orientation) with class labels. During the incremental stage, only a few annotated samples (1 or 5 per novel class) are required, and the detector backbone remains frozen—only prototypes and gating parameters are updated.

## Method

FI3Det introduces two modules operating at different stages. In the base stage, a VLM-guided unknown object learning module uses GroundingDINO and SAM to mine unannotated objects, extracting 2D semantic features and class-agnostic 3D boxes that serve as auxiliary supervision; a dual-level weighting mechanism (Gaussian spatial weighting at the point level and intra-box feature consistency at the box level) suppresses noise in these pseudo labels. In the incremental stage, a gated multimodal prototype imprinting module constructs modality-specific prototypes from aligned 2D semantic and 3D geometric features using momentum-based updating, then adaptively fuses modality-specific cosine-similarity classification scores via a learned gating mechanism (α for modality weighting, γ for class rebalancing). The base detector is TR3D, and the entire framework is trained with a joint detection-plus-auxiliary loss in the base stage and a lightweight prototype-and-gating loss in the incremental stage.

## Results

On ScanNet V2 (batch, 1-way 5-shot), FI3Det achieves 38.48% mAP on novel classes and 72.84% on base classes, substantially outperforming the strongest 3D incremental baseline AIC3DOD (15.43% novel) and the VLM-vanilla baseline (14.09% novel). On SUN RGB-D (batch, 1-way 5-shot), FI3Det reaches 73.17% mAP on novel classes versus 11.93% for VLM-vanilla and 0.02% for AIC3DOD. In the sequential setting (Table 3), FI3Det maintains 30.34% novel mAP on ScanNet V2 Task 3 and 19.04% on SUN RGB-D Task 2, surpassing the second-best by 15.49% and 8.01% respectively. The paper reports an average 17.37% improvement on novel classes over baseline models across all settings.

## Baselines & Comparisons

FI3Det decisively outperforms all four baselines on novel-class mAP across every setting. Against the strongest 3D incremental baseline AIC3DOD [5], FI3Det gains +23.05% novel mAP on ScanNet V2 (1-way 5-shot: 38.48 vs. 4.59) and +73.15% on SUN RGB-D (1-way 5-shot: 73.17 vs. 0.02). The VLM-vanilla baseline (pseudo 3D boxes only, no proposed modules) is the closest competitor, yet FI3Det still leads by +24.39% on ScanNet V2 (1-way 5-shot) and +61.24% on SUN RGB-D (1-way 5-shot), confirming that the unknown object weighting and gated multimodal prototype imprinting are critical. The 2D baselines Imprinting [32] and IL-DETR [11] perform poorly in the 3D setting, with novel mAP below 7% on ScanNet V2 and below 5% on SUN RGB-D, highlighting the difficulty of transferring 2D incremental strategies to 3D. In the sequential setting, FI3Det also leads on all tasks, with the largest margin of +15.49% over AIC3DOD on ScanNet V2 Task 3, while maintaining base-class mAP within 0.5% of the frozen baseline, demonstrating effective resistance to catastrophic forgetting.

## Relation to Prior Work

FI3Det extends the incremental 3D object detection line (SDCoT, SDCoT++, AIC3DOD) by relaxing the assumption of abundant novel-class annotations to a few-shot regime, and builds its detection backbone on TR3D. The incremental stage adapts the imprinting strategy from Qi et al. (CVPR 2018) into a multimodal, gated variant that fuses 2D VLM-derived semantic features with 3D geometric features. A key conceptual departure is the use of VLMs (GroundingDINO + SAM) during base training to mine unannotated 'unknown' objects already present in scenes, providing auxiliary supervision that prior incremental 3D methods entirely lack.

## Why It Matters / Open Questions

This is the first formalization of few-shot incremental 3D object detection, a setting that closely mirrors how embodied agents must acquire new object categories in the wild with minimal supervision. The VLM-guided unknown-object mining idea—exploiting the fact that novel objects already appear in base training scenes—offers a general recipe for bootstrapping open-vocabulary 3D perception without additional annotation. Limitations include evaluation on only two indoor datasets with relatively few categories, dependence on VLM segmentation quality, and untested scalability to outdoor or long-sequence settings; whether the approach transfers to LiDAR-based autonomous driving or to dozens of incremental sessions remains open.

## Problem

Promptable video object segmentation (PVOS) models such as SAM2 suffer substantial performance degradation under real-world corruptions (noise, blur, low illumination, adverse weather), yet this robustness gap has not been systematically studied or addressed. Existing robust image segmentation methods process frames independently, failing to capture the spatially and temporally varying degradation patterns inherent in video, where different objects in the same scene are affected differently and degradation evolves across frames.

## Input / Output

The model receives a video sequence with free-form prompts (points, boxes, or masks) for all target objects in the first frame and must produce per-object pixel-level segmentation masks for every subsequent frame while maintaining consistent instance identities. The benchmark provides 351 real-world clips (fog, snow, rain, nighttime) and synthetic clips with 8 corruption types modulated temporally via Fourier-based augmentation; evaluation uses standard VOS metrics (J, F, J&F) computed over the full sequence rather than per-frame.

## Method

MoGA (Memory-object-conditioned Gated-rank Adaptation) decomposes a LoRA adapter ΔW=BA into R rank-1 components {a_i, b_i} and selectively activates them per object using a gating module conditioned on object pointers from SAM2's memory bank. The gating module is a shared 3-layer MLP followed by Gumbel-Sigmoid relaxation that maps each object pointer m_o to a binary mask z_o ∈ {0,1}^R, determining which rank-1 components contribute to that object's adapter. The final output averages the object-specific adapted features, so each tracked object receives a distinct low-rank correction while the shared component set keeps the parameter count at only 1.1M. MoGA is integrated into SAM2's memory attention projections (Q, K, V of self-attention and Q of cross-attention) and trained end-to-end with focal + dice segmentation loss, with the gating modules learned implicitly through the segmentation objective rather than direct supervision. This memory-object conditioning is the key differentiator: it enables object-specific robustification that is temporally consistent because the object pointers accumulate historical information across frames, unlike frame-wise methods that apply uniform corrections.

## Results

On the real-world MVSeg-adv benchmark, MoGA+SAM2 achieves 71.8% J&F, outperforming SAM2 (69.6%) by 2.2 points and the best frame-wise baseline GaRA+SAM2 (69.7%) by 2.1 points. On ACDC-Video, MoGA+SAM2 reaches 64.5% J&F versus SAM2's 63.5% and GaRA+SAM2's 61.3%, while restoration-based methods (URIE, AirNet) actually degrade performance below SAM2. On the synthetic YouTube-VOS-C set, MoGA+SAM2 attains 79.9% J&F (vs. 78.7% for SAM2), and on clean YouTube-VOS it maintains 82.6% J&F, slightly exceeding SAM2's 82.2% without sacrificing clean-video quality.

## Baselines & Comparisons

MoGA+SAM2 consistently outperforms all four baselines on every corrupted dataset. Against SAM2 (the unmodified backbone), MoGA gains +2.2 J&F on MVSeg-adv, +1.0 on ACDC-Video, and +1.2 on YouTube-VOS-C. Against GaRA+SAM2 (the closest frame-wise robustification baseline), MoGA leads by +2.1 J&F on MVSeg-adv, +3.2 on ACDC-Video, and +1.8 on YouTube-VOS-C, while GaRA actually degrades clean-video performance to 79.8% J&F versus MoGA's 82.6%. Restoration-based methods URIE+SAM2 and AirNet+SAM2 fail to help and even hurt on ACDC-Video (60.9% and 59.8% J&F vs. SAM2's 63.5%), confirming that frame-independent restoration is ill-suited for temporally varying video corruptions. In a separate comparison (Table 4), MoGA also beats standard LoRA+SAM2 (71.8 vs. 70.9 J&F on MVSeg-adv), and in Table 3 it surpasses full fine-tuning of SAM2 (71.8 vs. 71.5 J&F) while using only 1.1M trainable parameters versus 80.9M.

## Relation to Prior Work

This paper extends the gated-rank adaptation (GaRA) framework from image-level robust segmentation (GaRA-SAM) into the video domain by conditioning the rank-1 component selection on object pointers stored in SAM2's memory bank, rather than on per-frame input statistics. It builds directly on SAM2's streaming memory architecture for temporal tracking and on LoRA's parameter-efficient adapter structure, but departs from both by making the adapter object-specific and temporally consistent through memory-conditioned Gumbel-Sigmoid gating. The paper also positions itself against frame-wise robustification approaches (URIE, AirNet, frame-level GaRA), arguing that their independence from temporal context is fundamentally incompatible with multi-object video tracking under spatially and temporally varying degradations.

## Why It Matters / Open Questions

By establishing the first dense, object-level benchmark for robust PVOS under real adverse conditions (351 clips, 2,500+ masks), this work provides the field with a much-needed evaluation standard that prior robust-segmentation and VOS literature lacked. The finding that restoration and frame-wise robustification methods degrade rather than improve video segmentation performance is a practical warning against naively porting image-level robustness to video. Open questions include whether memory-conditioned gating scales to scenes with many simultaneously tracked objects, whether the approach generalizes to corruption types beyond the eight studied, and whether the progressive improvement during inference (Figure 6) can be accelerated to reduce the warm-up period where performance is still low.

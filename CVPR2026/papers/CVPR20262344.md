## Problem

CLIP-based WSSS methods rely on static text prototypes as queries to activate visual features, but the inherent CLIP modality gap causes these text embeddings to lie outside actual visual feature clusters, producing incomplete CAMs. Moreover, a single fixed text prototype cannot adapt to the diverse visual attributes exhibited by different instances of the same class, leading to inconsistent activation strengths across images.
![Teaser figure](../imgs/CVPR20262344/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images with only image-level class labels (no pixel annotations) and frozen CLIP ViT-B patch features. It produces pixel-level segmentation masks as the final output, with intermediate class activation maps (CAMs) generated via cosine similarity between visual patch features and an assembled query prototype serving as dense pseudo-labels for decoder supervision. The framework is evaluated on PASCAL VOC 2012 (21 classes, 10582 train images) and MS COCO 2014 (81 classes, 82081 train images).

## Method

VDA replaces static text queries with instance-specific visual description prototypes assembled directly from the visual space. An invertible neural network (RealNVP) maps CLIP visual features into a hierarchical GMM latent space via progressive training: first establishing K inter-class components as stable class centers, then extending each into M intra-class components representing disentangled visual attributes. For a given instance, the method computes posterior response strengths to each attribute component, maps the attribute centers back to visual space via the INN inverse, and assembles a weighted composite visual prototype. A density-based adaptive fusion mechanism then interpolates between this visual prototype and the stable text anchor, weighting by how typical the instance is under its class distribution. A separate decoder semantic enhancement module applies InfoNCE contrastive loss to align adapter features with global class prototypes from the H-GMM, improving semantic consistency of the segmentation decoder.

## Results

VDA achieves 79.9% mIoU on PASCAL VOC 2012 val, 79.8% on VOC test, and 51.4% on MS COCO 2014 val, establishing new state-of-the-art among both single-stage and multi-stage WSSS methods. On CAM seed quality (VOC train), VDA reaches 79.1% mIoU, surpassing the previous best ExCEL (78.0%) by 1.1 points. The method outperforms the strongest single-stage baseline ExCEL by +1.5% on VOC val and +1.1% on COCO val, and exceeds the best multi-stage method VPLA by +0.6% on VOC val and +1.6% on COCO val.

## Baselines & Comparisons

VDA outperforms all 19 compared baselines across both datasets. Against the closest single-stage competitor ExCEL (CVPR'25), VDA gains +1.5% mIoU on VOC val (79.9 vs 78.4), +1.3% on VOC test (79.8 vs 78.5), and +1.1% on COCO val (51.4 vs 50.3). It also surpasses the strongest multi-stage method VPLA (AAAI'25) by +0.6% on VOC val and +1.6% on COCO val, despite VPLA using a multi-stage pipeline. Compared to WeCLIP (CVPR'24), the improvement is more substantial at +3.5% on VOC val and +4.3% on COCO val. On CAM seed quality (Table 2), VDA achieves 79.1% mIoU on VOC train, beating ExCEL (78.0%), VPLA (77.8%), and S2C (76.1%), confirming that the visual description assembly produces more complete and accurate activation maps than text-only queries.

## Relation to Prior Work

This paper extends the CLIP-based WSSS lineage (CLIP-ES, WeCLIP, ExCEL) that uses text prototypes as queries for CAM generation, but departs fundamentally from the strategy of improving text descriptions. Rather than enriching text with LLM-generated attributes (as ExCEL does), VDA bypasses the text modality entirely by constructing instance-specific visual prototypes directly from CLIP visual features, using a RealNVP-based invertible neural network to map them into a hierarchical GMM latent space where attributes are explicitly disentangled. The method also builds on WeCLIP's frozen-CLIP-backbone paradigm and ExCEL's decoder/adapter architecture, while introducing a density-based adaptive fusion mechanism that interpolates between the assembled visual prototype and the stable text anchor.

## Why It Matters / Open Questions

The paper provides a principled argument that the CLIP modality gap makes text-based queries inherently suboptimal for fine-grained spatial tasks like segmentation, and demonstrates that constructing queries from the visual space itself yields more complete CAMs. However, the approach depends on decoder-predicted masks for prototype extraction (a chicken-and-egg problem in WSSS), the INN is discarded at inference (limiting its practical footprint), and the gains over the strong ExCEL baseline are modest (~1.5% mIoU on VOC). Open questions include whether the H-GMM structure generalizes to open-vocabulary or video settings, and whether the probabilistic modeling overhead can be reduced for real-time deployment.

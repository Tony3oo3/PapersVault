## Problem

Existing MLLM-based multimodal embedding models rely on single-turn contrastive learning, where each query-target pair is processed independently. This paradigm overlooks the rich contextual interdependence among multiple queries derivable from the same image, and scaling batch size to increase negatives incurs prohibitive computational cost because each image requires a separate forward pass through the visual encoder.

## Input / Output

The model takes an RGB image (averaging ~294 visual tokens after encoding) and one or more text queries as input, producing L2-normalized embedding vectors via a special <|emb|> token placed at the end of each dialogue turn. The key structural constraint is that the image is encoded only once per forward pass, while subsequent turns append text-only queries or targets, so k query-target pairs for the same image yield k embeddings from a single visual encoding. During fine-tuning on single-pair data, the model uses only the initial turn's embedding for evaluation, matching standard single-query test protocols.

## Method

MuCo reframes contrastive learning as a multi-turn dialogue: multiple query-target pairs sharing the same image are concatenated sequentially, with each turn's embedding conditioned on all prior turns via causal attention, creating a compounded supervisory signal where gradients from later turns retroactively refine earlier embeddings. A logit masking strategy sets same-image cross-pairs to −∞ in the InfoNCE denominator to prevent semantic overlap from being treated as negative signal. Training proceeds in two stages: (1) pretraining on the newly constructed 5M-sample M3T dataset (7 diverse query-target pairs per image spanning classification, retrieval, and VQA, synthesized via MLLM+LLM pipeline), and (2) fine-tuning on standard single-turn benchmarks using a prompt-based in-context reconstruction task where the model is asked to reconstruct a masked counterpart, simulating multi-turn behavior without auxiliary objectives. This design amplifies the effective batch size by k× (e.g., 1024 images × 7 turns = 7168 pairs) while increasing FLOPs by ≤3%, compared to 122.7 PFLOPs for naively scaling the batch to 7168 images.

## Results

On the MMEB benchmark (36 tasks, Precision@1), MuCo-7B achieves 61.6% zero-shot overall, surpassing the previous SOTA mmE5-11B (58.6%) by +3.0 points. In the fine-tuning setting, MuCo-2B reaches 69.5% overall (vs. B3-2B at 68.1%) and MuCo-7B reaches 73.6% (vs. B3-7B at 72.0%), also achieving the highest OOD score (69.1%). On M-BEIR (16 retrieval datasets, Recall), MuCo-7B achieves 56.6% overall, outperforming LamRA-Ret-7B (54.9%) by +1.7 points, with particularly strong M→M performance (70.4%).

## Baselines & Comparisons

MuCo-7B (61.6% zero-shot) outperforms the previous SOTA mmE5-11B (58.6%) by +3.0 points despite using fewer parameters (7B vs. 11B), and substantially surpasses MMRet-7B (44.0%) and CLIP (37.8%). In fine-tuning, MuCo-2B (69.5%) beats B3-2B (68.1%) by +1.4 points and MoCa-3B (67.5%) by +2.0 points; MuCo-7B (73.6%) leads B3-7B (72.0%) by +1.6 points and MoCa-7B (71.5%) by +2.1 points, while also achieving the best OOD generalization (69.1% vs. 67.1% for B3-7B). On M-BEIR, MuCo-7B (56.6% Recall) outperforms LamRA-Ret-7B (54.9%), M3Task-UEM-7B (53.9%), and MM-Embed-7B (52.7%), with the largest margin in the M→M setting (70.4% vs. 65.0% for LamRA-Ret). MuCo-2B (51.6%) also edges out LamRA-Ret-2B (50.0%) and UniIR-0.4B (48.9%). Notably, MuCo achieves these gains with dramatically lower FLOPs: 18.0 PFLOPs at 7× effective batch size vs. 122.7 PFLOPs for standard contrastive learning at the same effective batch, while still delivering +0.7 points higher performance.

## Relation to Prior Work

This paper extends the InfoNCE contrastive learning framework (van den Oord et al.) from its standard single-turn formulation—where each query-target pair is an independent data point—to a multi-turn dialogue structure that processes multiple pairs per image in a single forward pass. It sits within the MLLM-based universal multimodal embedding line (VLM2Vec, mmE5, B3, LLaVE, UniME, MoCa), all of which rely on single-turn supervision, and departs from them by exploiting the causal, conversational nature of MLLM backbones (Qwen2-VL) to model sequential query-target interactions. The single-turn adaptation via prompt-based in-context reconstruction is a novel bridge that allows multi-turn pretrained models to be applied to conventional single-pair benchmarks without architectural changes.

## Why It Matters / Open Questions

The key practical impact is the dramatic efficiency gain: achieving a 7× effective batch size (1024→7168) with only a 3% FLOPs increase (17.5→18.0 PFLOPs) versus 122.7 PFLOPs for standard contrastive learning at the same effective batch, while simultaneously improving performance. This reframes the compute-cost trade-off in MLLM-based embedding training and suggests that the conversational structure of MLLMs has been underexploited for representation learning. Open questions include whether the multi-turn paradigm extends to video or longer-context modalities, whether the M3T-style synthetic data pipeline generalizes beyond the MMEB task taxonomy, and whether the fine-tuning adaptation (prompt-based reconstruction) can be replaced by a more principled objective. The approach is also inherently tied to MLLM backbones with causal attention, limiting direct transfer to encoder-only architectures.

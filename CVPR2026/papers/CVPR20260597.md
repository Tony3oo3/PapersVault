## Problem

Generative AI has made major progress on single-image and video generation, yet remains largely underexplored for unstructured image sets—collections that share common visual content but differ in viewpoint, pose, time, and surrounding context. Unlike video, these sets lack dense temporal continuity, making cross-image consistency of shared elements (identity, appearance, geometry) extremely difficult to enforce without strong spatial or temporal cues. No existing method performs set-to-set generation that preserves fine-grained consistency across an entire collection while allowing non-shared regions to vary freely.

## Input / Output

The method takes an unstructured set of N images (2–15), a user prompt describing the target shared content (P^shared), and a separate theme/style prompt (P^theme), and produces N output images that preserve the source semantic layout while maintaining cross-image consistency of shared elements. Per-image non-shared captions are automatically generated by a VLM, and depth maps plus dense 2D correspondences (via RoMA) are extracted from the source set as auxiliary signals—no object masks or manual annotation are required. The base model is a frozen depth-conditioned FLUX DiT, so resolution is bounded by the model's native generation size per image rather than a single canvas.

## Method

Match-and-Fuse models the image set as a Pairwise Consistency Graph whose nodes are individual images and whose edges correspond to joint two-image grid denoising steps, exploiting an emergent 'grid prior' in T2I diffusion models that encourages coherence when multiple views share a canvas. At each denoising step, Multiview Feature Fusion (MFF) averages internal K/V features across all adjacent edges for each node and then fuses matched coordinates across all N images using pre-computed 2D correspondences, enforcing fine-grained alignment without masks. A lightweight Feature Guidance step then refines remaining inconsistencies by performing gradient descent on a feature-matching loss over all edges, correcting details that discrete fusion cannot capture. Pairwise latents are consolidated back into per-image latents by averaging over incident edges (following MultiDiffusion), and the graph is sparsified to degree-4 neighbors for scalability beyond 5 images. The entire pipeline is zero-shot and training-free, operating entirely at inference time on a frozen FLUX model with depth conditioning.

## Results

Match-and-Fuse achieves the highest cross-image consistency among all methods, scoring 0.80 on DINO-MatchSim and 0.85 on DreamSim, while maintaining a comparable prompt-adherence CLIP score of 0.66. The closest baseline, Edicho, reaches 0.72 DINO-MatchSim and 0.81 DreamSim, while FLUX Kontext lags furthest at 0.57 DINO-MatchSim. In a 2AFC user study, Match-and-Fuse is preferred over all four baselines (83–92% of votes), and the proposed DINO-MatchSim metric shows 91.4% agreement with human judgments, outperforming DreamSim (84.3%) and VLM-based evaluation (84.9%).

## Baselines & Comparisons

Match-and-Fuse outperforms all four baselines on both consistency metrics (DINO-MatchSim and DreamSim) while keeping prompt adherence (CLIP) within 0.01–0.02 of the best. Against FLUX (independent per-image generation with ControlNet), the gap is largest on DINO-MatchSim (0.80 vs. 0.66), reflecting FLUX's inability to enforce any cross-image consistency. FLUX Kontext, an image-to-image editing model, scores lowest on DINO-MatchSim (0.57) because it distorts object structure and lacks a set-level consistency mechanism. IC-LoRA achieves partial consistency (0.65 DINO-MatchSim) but its coherence is often restricted to subsets of the set, and its DreamSim (0.71) is the lowest of all methods. Edicho, the closest baseline using explicit 2D correspondences, reaches 0.72 DINO-MatchSim and 0.81 DreamSim but degrades for views far from its single anchor image; Match-and-Fuse improves over it by 0.08 and 0.04 respectively, attributed to the pairwise graph formulation and Multiview Feature Fusion that enforce consistency globally rather than from one reference.

## Relation to Prior Work

This paper extends the line of consistent multi-image generation from restricted settings (pairwise editing in Edicho, fixed-grid generation in IC-LoRA) to arbitrary unstructured image sets of varying sizes. It builds on FLUX with ControlNet depth conditioning as the frozen backbone, borrows the latent-averaging strategy from Multidiffusion for consolidating pairwise outputs, and applies feature-guidance techniques (Epstein et al., Chefer et al.) as a refinement stage. The key conceptual departure is the Pairwise Consistency Graph formulation, which decomposes a global set-consistency problem into jointly denoised two-image grids, exploiting an emergent 'grid prior' in T2I diffusion models while using dense 2D correspondences (RoMA) to enforce fine-grained alignment without masks.

## Why It Matters / Open Questions

This is the first training-free method that handles unstructured image sets of 2–15 images with cross-image consistency, opening practical workflows for product catalogs, character concept art, and storyboard visualization that were previously intractable with pairwise or fixed-grid approaches. The introduced DINO-MatchSim metric (91.4% agreement with human judgments vs. 84.3% for DreamSim) provides a more reliable evaluation tool for fine-grained set consistency. Key limitations remain: performance degrades with correspondence sparsity and fails under complex disocclusions or symmetries, and the method inherits the base model's tendency to deviate from source depth layouts. Future directions include extending to video collections and developing dedicated foundation models for set-to-set generation.

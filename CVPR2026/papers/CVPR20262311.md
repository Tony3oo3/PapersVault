## Problem

Existing Aerial Vision-and-Dialog Navigation (AVDN) methods rely on supervised fine-tuning, incurring high annotation costs and poor cross-domain generalization. Naively applying MLLMs to AVDN fails because they lack robust directional grounding under high-altitude perspectives (e.g., translating '10 o'clock' into a geometric heading) and have no structured mechanism for maintaining spatial memory over multi-step trajectories. This paper is the first to propose a fully training-free framework for AVDN that addresses both limitations.
![Teaser figure](../imgs/CVPR20262311/cropped_page0_idx0.webp)

## Input / Output

At each dialogue round, the method consumes multi-scale aerial image crops (global, local, and main-view at scaling factors 3, 5, 7, each warped to a canonical 768×768 frame via homography), the current dialogue instruction text, and the UAV's accumulated trajectory and orientation. It outputs a target bounding box (x₁, y₁, x₂, y₂) localizing the destination in the current view, along with a relative heading angle δ computed by the Heading Resolution module to direct the UAV's next movement. The full navigation task spans L dialogue rounds, with the final bounding box marking the navigation goal.

## Method

PSC-AVDN decouples navigation into a three-stage Parsing–Search–Confirmation pipeline driven by chain-of-thought reasoning over MLLMs (DeepSeek-V3 for parsing, Qwen-VL-Max for visual reasoning). The Parsing stage uses a rule-based Heading Resolution module to convert heterogeneous directional expressions (clock positions, degrees, compass bearings) into a canonical relative heading, while extracting a structured destination description. The Search stage (S-CoT) performs four sequential sub-steps—destination analysis, scene understanding, reference grid map generation, and target localization—to progressively narrow candidate regions. The Confirmation stage (C-CoT) then conducts fine-grained spatial and relational verification around the candidate to disambiguate small, texture-sparse aerial targets. A Structured Spatial Memory module supplements all stages with three complementary cues: multi-scale visual observation for hierarchical scene perception, spatial visual memory that fuses historical crops with trajectory/orientation to suppress long-horizon drift, and a structured geometric memory implemented as an N×N reference grid map with per-cell semantic labels that stabilizes multi-step spatial reasoning.

## Results

On the ANDH dataset (Unseen Val.), PSC-AVDN achieves SPL=17.8, SR=22.6, and GP=39.2, establishing the best training-free performance and approaching the supervised FELA w/ at (SPL=19.2, SR=23.9, GP=64.1). On the longer-trajectory ANDH-Full dataset (Seen Val.), PSC-AVDN reaches SPL=19.1, SR=22.3, and GP=75.1, surpassing the supervised OpenFly baseline (SPL=14.0, SR=10.1, GP=61.0) on all three metrics. Compared to the naive MLLM baselines (GPT-4o: SPL≈2.6–3.4; Qwen-VL-Max: SPL≈5.7–9.3), PSC-AVDN improves SPL by roughly 4–7× across all splits.

## Baselines & Comparisons

Against the two naive MLLM training-free baselines, PSC-AVDN dominates by a wide margin: on ANDH Unseen Val., it improves SPL from 3.4 (GPT-4o) and 8.7 (Qwen-VL-Max) to 17.8, and SR from 3.9/9.2 to 22.6. Compared to the strongest supervised method on ANDH (FELA w/ at, SPL=19.2, SR=23.9 on Unseen Val.), PSC-AVDN is within 1.4 SPL and 1.3 SR points while requiring no task-specific training. On ANDH-Full Seen Val., PSC-AVDN clearly surpasses the only supervised method evaluated there (OpenFly: SPL=14.0, SR=10.1, GP=61.0), achieving SPL=19.1, SR=22.3, and GP=75.1. On ANDH-Full Unseen Val. and Unseen Test, PSC-AVDN matches or slightly edges OpenFly (e.g., GP 62.3 vs. 59.0 on Unseen Val.; SPL 12.1 vs. 8.3 on Unseen Test). The GP metric is notably lower for PSC-AVDN on ANDH (39.2 vs. 64.1 for FELA w/ at), suggesting the training-free method takes less direct paths even when it reaches the goal, a gap the authors attribute to the absence of learned path-planning priors.

## Relation to Prior Work

This paper departs from the supervised-finetuning paradigm that dominates prior AVDN work (HAA-T, TA-GAT, FELA) by proposing the first training-free framework for the task, repurposing chain-of-thought reasoning from the LLM literature and structured spatial memory ideas from recent MLLM spatial-reasoning work (TopV-Nav, MapNav, GeoNav) into a three-stage Parsing-Search-Confirmation pipeline. Unlike GeoNav, which relies on external models (Grounded SAM, OpenGIS) for cognitive map construction, PSC-AVDN generates its reference grid map entirely through MLLM prompting, eliminating external dependencies. The Heading Resolution module and multi-scale visual observation draw on standard remote-sensing and robotics concepts but are integrated into a unified CoT-driven navigation loop for the first time in the AVDN setting.

## Why It Matters / Open Questions

The training-free formulation removes the need for expensive trajectory annotation and retraining when deploying UAVs in new environments, which is practically significant for disaster response and geospatial mapping applications. However, absolute performance remains modest (SPL ~13–19, SR ~16–22), and the gap to the best supervised methods (e.g., FELA w/ at) is still substantial on the ANDH benchmark, suggesting the approach has not yet fully closed the training-free-to-supervised gap. Open questions include whether the 5×5 reference grid and three-scale observation generalize to other aerial domains, the computational cost of running multi-scale crops plus spatial memory plus two CoT chains per step, and whether the framework extends to continuous (non-dialog) aerial navigation or 3D environments.

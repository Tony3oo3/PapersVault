## Problem

Vision-language models (VLMs) struggle to detect and explain errors in long task videos because errors are spatially and temporally subtle relative to correct actions (e.g., using a knife instead of a spoon, or briefly dropping an object mid-action). While prior work addresses error detection or recognition, the problem of providing interpretable error explanations remains largely unsolved, and existing VLM-based approaches fail to attend to the sparse spatiotemporal cues that distinguish erroneous from correct execution.

## Input / Output

The method takes a long egocentric task video, pre-extracted frame features (via Timesformer), action segments from a trained TAS model, and a pre-built Action eXecution Graph (AXG) per action class. The frozen VLM is queried only on a small number of keyframes (α=8 for Qwen2.5-VL, α=3 for InternVL3.5) sampled from each subaction segment, not the full video. Output is a binary error label per action segment (y_n ∈ {0,1}) and a free-form textual explanation (z_n) generated by concatenating per-subaction justifications.

## Method

The core contribution is the Action eXecution Graph (AXG), a training-free DAG per action whose nodes are subactions and whose edges encode feasible predecessor-successor ordering, automatically constructed from normal training videos via VLM frame captioning, temporally-aware K-means clustering of Sentence-BERT embeddings (with sinusoidal time-stamp encoding), and LLM-based subaction summarization. At inference, a TAS model segments the test video into actions, then graph-to-video (G2V) alignment with the corresponding AXG decomposes each action into subaction segments; frames not matched to any subaction are automatically flagged as errors. A frozen VLM is then queried on keyframes of each subaction using two prompt types: an enhanced correctness prompt (P^c) for assigned segments that includes the specific subaction name, and a mistake-description prompt (P^r) for dropped segments. A segment is declared erroneous if any subaction's correctness score ≤ 0.5, and the explanation is the concatenation of all subaction-level justifications. The entire AXG pipeline requires no parameter optimization and is compatible with any off-the-shelf TAS model and VLM.

## Results

On error detection (F1@0.5), AXG with GTG2Vid TAS and Qwen2.5-VL achieves 33.4% on EgoPER and 28.5% on CaptainCook4D, surpassing the GTG2Vid baseline (33.0% and 16.2%) and EgoPED (22.5% and 10.5%). With InternVL3.5 as the VLM, AXG reaches 31.8% and 29.0% F1@0.5 on the two datasets. For error explanation (similarity score on GT segments), AXG achieves 17.4% (Qwen2.5-VL) and 24.6% (InternVL3.5) on EgoPER, compared to 3.6% and 19.8% for the Naive baseline and 5.0% for VIDEOTREE.

## Baselines & Comparisons

Against GTG2Vid [24], the strongest prior error-detection method, AXG (with GTG2Vid as TAS and Qwen2.5-VL) achieves 33.4% F1@0.5 on EgoPER (vs. 33.0%) and 28.5% on CaptainCook4D (vs. 16.2%), a 12.3-point gain on Cook4D. Against EgoPED [25], AXG improves F1@0.5 by 10.9 points on EgoPER (33.4% vs. 22.5%) and 18.0 points on Cook4D (28.5% vs. 10.5%). Compared to the Naive VLM baseline (uniform keyframe sampling with a generic action prompt), AXG consistently improves F1@0.5 by roughly 13 points across both datasets and both VLMs. For error explanation, AXG substantially outperforms VIDEOTREE [59] (17.4% vs. 5.0% similarity on EgoPER with Qwen2.5-VL), attributed to AXG's explicit procedural subaction structure guiding keyframe selection and prompt enrichment, whereas VIDEOTREE relies on LLM-based clustering without modeling action sequences.

## Relation to Prior Work

This paper builds on graph-to-video alignment (Drop-DTW / Flow Graph to Video Grounding [10]) as the core mechanism for temporal subaction segmentation, repurposing it from weakly-supervised step localization to error reasoning. It departs from prior error detection work (EgoPED, GTG2Vid, PREGO) that relies on learned classifiers or task graphs by instead leveraging frozen VLMs with a training-free Action eXecution Graph (AXG) constructed automatically from normal videos via foundation models. Compared to long-video VLM approaches like VIDEOTREE and BOLT that select keyframes without procedural structure, AXG incorporates subaction-level decomposition into both keyframe selection and prompt design, addressing the specific challenge of sparse spatiotemporal error cues.

## Why It Matters / Open Questions

The training-free, modular AXG framework is practically appealing: it requires no manual subaction annotations, no VLM fine-tuning, and can be plugged into any off-the-shelf TAS model and VLM, making it broadly applicable to new procedural tasks. However, absolute performance remains modest (F1@0.5 around 30–33%), and the method still over-flags normal segments as errors, suggesting that VLMs' limited spatial discrimination (e.g., spoon vs. knife) is a fundamental bottleneck. Open questions include whether the approach scales to more complex multi-step tasks, whether online/real-time error reasoning is feasible, and whether richer AXG structures (e.g., conditional subactions) could close the remaining gap.

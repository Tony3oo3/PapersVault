## Problem

Most open-vocabulary object detectors compress an entire text description into a single embedding, causing strong category semantics to overshadow fine-grained attribute cues (color, material, pattern). As a result, detectors that correctly localize 'a dog' still fail on 'a dog with gray and white fur and blue eyes,' and partially matched objects receive high scores even when one critical attribute is violated. This gap is exposed by fine-grained benchmarks like FG-OVD, where mainstream OVD models suffer substantial performance drops.

## Input / Output

The model takes an RGB image (resized to 480×1333–800×1333) and a free-form text description (up to 20 tokens, ranging from simple category names to multi-attribute phrases) as input, and outputs bounding boxes with confidence scores. The text is processed by a pretrained Open-CLIP ViT-B/16 encoder, while the image is encoded by a Swin-T backbone; matching occurs at the query level in a DETR-style dual-stream architecture, so text is aligned only at the classification stage rather than through early fusion.

## Method

SRA-Det introduces a Semantic Retrieval Augmentation module in which K=3 learnable queries iteratively attend to token-level text embeddings to extract complementary semantic facets, with each query conditioned on the previous retrieval result to encourage progressive, diverse extraction. A Multi-Semantic Matching module then computes similarity between each object query and all K augmented text embeddings, aggregating them via a differentiable soft-min operator that behaves as a logical AND—penalizing the overall score if any single attribute facet mismatches. Diversity and coverage regularization losses ensure the retrieval queries attend to distinct and collectively exhaustive portions of the description. Complementing the model, an automatic attribute-augmented data pipeline uses an LLM to generate compact category-specific visual attribute candidates and a dual CLIP-based similarity check (comparing both category-attribute composite prompts and attribute-only prompts against a class baseline) to verify attributes at the instance level, yielding dense fine-grained supervision on large detection datasets.

## Results

On the FG-OVD benchmark (the paper's primary evaluation), SRA-Det achieves 54.9 mAP in the zero-shot setting, surpassing the previous zero-shot best (OWL-ViT L/14 at 41.1) by 13.8 mAP and even exceeding the fine-tuned NoctOWLv2 L/14 (54.7). When fine-tuned on FG-OVD, SRA-Det reaches 67.8 mAP, outperforming the prior best fine-tuned method GUIDED (66.4) by 1.4 mAP. On LVIS minival, SRA-Det achieves 40.4 AP with a Swin-T backbone, competitive with DetCLIPv2 (40.4) and MM-GDINO (40.5) but trailing LLMDet (44.7) and DetCLIPv3 (42.5). On OmniLabel and OVDEval, SRA-Det scores 23.2 and 17.3 respectively, showing consistent generalization across fine-grained and general OVD settings.

## Baselines & Comparisons

In the zero-shot FG-OVD setting, SRA-Det (54.9 mAP) decisively outperforms all prior zero-shot methods: OWL-ViT L/14 (41.1, +13.8), OWLv2 L/14 (37.3, +17.6), ViLD (35.9, +19.0), GroundingDINO (33.1, +21.8), Detic (29.3, +25.6), and CORA (22.9, +32.0). Notably, SRA-Det's zero-shot result also exceeds the fine-tuned NoctOWLv2 L/14 (54.7) and NoctOWL L/14 (54.0), demonstrating that the multi-semantic matching mechanism provides a substantial advantage over benchmark-specific fine-tuning. In the fine-tuned FG-OVD setting, SRA-Det (67.8) surpasses GUIDED (66.4) by 1.4 mAP and NoctOWLv2 L/14 (54.7) by 13.1 mAP. On LVIS, SRA-Det (40.4 AP) ties DetCLIPv2 (40.4) and slightly trails MM-GDINO (40.5) and DetCLIPv3 (42.5), while clearly beating YOLO-World-L (35.4, +5.0), OWLv2 (38.1, +2.3), and GroundingDINO (27.4, +13.0); it loses to LLMDet (44.7) which uses COCO during training and fine-tunes a stronger MM-GDINO backbone. On OmniLabel, SRA-Det (23.2) beats GLIP Swin-T (19.3) and Detic (8.0) but trails GLIP Swin-L (25.8) and FIBER (25.7); on OVDEval it scores 17.3, surpassing FIBER (9.6) and GDINO (9.2) but below OmDet (19.6) which uses a ConvNeXt-B backbone.

## Relation to Prior Work

SRA-Det builds on the dual-stream DETR-style architecture inherited from GroundingDINO and MM-GDINO, but departs fundamentally from the single-vector text representation paradigm used by OWL-ViT, Detic, and GLIP-family detectors. In the fine-grained OVD line (NoctOWL, HA-FGOVD, GUIDED), prior methods still collapse descriptions into one composed embedding via linear combination of global and attribute-specific vectors; SRA-Det instead retrieves multiple complementary semantic facets with learnable queries and aggregates them through a differentiable soft-min operator that enforces logical-AND semantics. The automatic attribute-augmented data pipeline is a novel contribution that repurposes LLMs for category-conditioned attribute generation and CLIP for instance-level dual verification, filling a gap left by prior pseudo-labeling approaches that supervise boxes or free-form captions rather than explicit visual attributes.

## Why It Matters / Open Questions

The paper demonstrates that the gap between coarse category detection and attribute-sensitive fine-grained detection can be substantially closed in a zero-shot setting, with a 13.8 mAP improvement over the previous zero-shot SOTA on FG-OVD and a zero-shot Swin-T model outperforming fine-tuned larger backbones. The automatic attribute pipeline offers a practical recipe for scaling dense attribute supervision to large detection corpora without manual annotation, which is directly applicable to any OVD system. Open questions remain around the robustness of LLM-generated attributes for rare or ambiguous categories, the sensitivity of the soft-min temperature τ to description length, and whether the multi-facet retrieval generalizes to very long or compositional descriptions beyond the 20-token limit used here.

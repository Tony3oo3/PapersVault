## Problem

Fine-tuning CLIP for multi-source remote sensing classification faces a dual barrier: a data-level modality gap between natural images and spectral-spatial RS data (HSI, LiDAR, SAR), and a task-level need for multi-source interaction modeling that one-sided prompt injection cannot satisfy. Existing prompt-tuning methods for RS either ignore the complementary spectral-spatial structure of multi-source imagery or fail to achieve bidirectional visual-textual prompt alignment, which contradicts CLIP's core contrastive alignment principle.
![Teaser figure](../imgs/CVPR20261083/cropped_page0_idx0.webp)

## Input / Output

The method takes a pair of co-registered multi-source RS images—one spectrally rich (HSI, H×W×C channels) and one spatially rich (LiDAR or SAR, H×W×D channels)—and outputs a single class label from a fixed set of land-cover categories. The two sources are fused into a single 224×224×3 image via a learnable transposed-convolution encoder to match CLIP ViT-16/B's input format, while the text branch consumes a soft-prompted template ('A multisource fusion patch of [CLASS]') concatenated with per-class embeddings. Only 0.76% of CLIP's parameters (≈1.1M) are trainable, with the ViT-16/B backbone kept frozen.

## Method

CF-IPT operates in two stages. First, the MFPG module performs cross-attention-based feature interaction between the HSI and LiDAR/SAR inputs to generate spectral (P_sp) and spatial (P_sa) prompt matrices that retain native multi-source features; an Adaptive Multi-scale Feature Fusion (AMFF) sub-module then applies dual-branch global pooling for spectral recalibration and parallel 1×1/3×3/5×5 convolutions for spatial aggregation, producing a fused representation upsampled to 224×224×3 by a four-layer transposed-convolution Input Adaptation Encoder. Second, the V-TPI strategy injects learnable visual and text prompts into every layer of CLIP's frozen encoders and drives bidirectional prompt exchange through a Mamba-based state-space transformation (S²GPT) that is conditioned on the spectral-spatial prompt matrices, enabling progressive cross-modal alignment. Training minimizes a combined cross-modal representation consistency loss (contrastive) and a text representation diversity loss that penalizes inter-class semantic overlap, with the S²GPT Mamba module shared across layers to capture general visual-textual conversion patterns while adapting to RS-specific spectral-spatial structure.

## Results

On the three multi-source RS classification benchmarks, CF-IPT achieves OA of 97.89% (Houston), 89.25% (MUUFL), and 89.83% (Augsburg), outperforming the strongest baselines (DiffCLIP, SPT, MSFM) by 1.4–2.3% OA while using only ~1M trainable parameters (0.76% of CLIP's total). On the three single-source scene classification datasets, CF-IPT reaches 92.80% (RSICD), 96.55% (PatternNet), and 86.65% (RESISC45) OA, surpassing the best CLIP-based prompt-tuning baseline MaPLe by 1.8–3.3%. The method also achieves the highest Kappa coefficient on all six datasets (e.g., 97.72 on Houston, 85.64 on Augsburg).

## Baselines & Comparisons

CF-IPT achieves the best OA on all six evaluation datasets, winning every head-to-head comparison. On the multi-source RS benchmarks, it surpasses the strongest CLIP-based baseline DiffCLIP by 1.74% (Houston), 2.27% (MUUFL), and 1.38% (Augsburg) OA, and outperforms the Mamba-based M3amba by 1.96–4.12% OA while using roughly 70× fewer trainable parameters (≈1 M vs. ≈70 M). Among conventional CNN/Transformer hybrids, the gap over MCFT and MSFM ranges from 1.9% to 5.3% OA depending on the dataset. On the single-source scene classification datasets (Table 3), CF-IPT beats the best prompt-tuning baseline MaPLe by 1.80% (RSICD), 1.78% (PatternNet), and 3.33% (RESISC45) OA, and exceeds CoCoOp by 2.93–6.35% OA. Notably, CF-IPT also achieves the highest Kappa coefficient on every dataset, indicating superior class-balance handling compared to baselines that sometimes show large AA–OA gaps (e.g., CALC on Augsburg: OA 85.76% vs. AA 67.92%).

## Relation to Prior Work

This paper extends the prompt tuning paradigm (CoOp, CoCoOp, MaPLe) from natural image classification to multi-source remote sensing, building on CLIP's ViT-16/B as a frozen backbone. It departs from prior one-sided prompt injection (e.g., SPT) by introducing bidirectional visual-textual prompt interaction guided by spectral-spatial prompt matrices generated from cross-attention over HSI and LiDAR/SAR inputs. The use of a Mamba-based state-space model for the prompt transformation module (S²GPT) is a notable architectural departure from the Transformer-based prompt adapters common in prior CLIP fine-tuning work, motivated by long-sequence modeling efficiency.

## Why It Matters / Open Questions

The paper demonstrates that CLIP can be adapted to multi-source RS classification with only ~1M trainable parameters (0.76% of CLIP), achieving SOTA on Houston, MUUFL, and Augsburg while remaining competitive on single-source scene classification benchmarks. This suggests a practical pathway for deploying vision-language models in resource-constrained RS pipelines where full fine-tuning is infeasible. Open questions include whether the bidirectional prompt interaction and Mamba-based transformation generalize beyond the three tested multi-source combinations, whether the approach extends to more than two modalities, and whether the spectral-spatial prompt matrices remain informative at larger spatial scales or with different sensor pairings.

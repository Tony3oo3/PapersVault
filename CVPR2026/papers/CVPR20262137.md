## Problem

All widely used visual similarity metrics (LPIPS, CLIP, DINO, dreamsim) measure only perceptual attribute similarity—shared color, shape, or semantic class—and cannot recognize that two visually dissimilar images share the same underlying relational logic (e.g., a burning match sequence and a ripening banana both encode 'transformation over time'). This paper identifies relational visual similarity as a missing dimension of image comparison that is central to human cognition (analogical reasoning, creativity) but entirely absent from current computer vision tooling.

## Input / Output

The model takes a pair of RGB images and outputs a scalar relational similarity score computed as the cosine similarity between their visual feature embeddings, scaled by a learnable temperature. Each image is processed by a VLM (Qwen2.5-VL-7B-Instruct) with a single learnable query token appended as an instruction; the query token's last-layer LLM hidden state serves as the image's relational feature vector. The corresponding text-side embedding is produced by a frozen all-MiniLM-L6-v2 encoder applied to the image's anonymous caption (a relational description using placeholders like {subject} rather than object-specific terms).

## Method

The pipeline has three stages: (1) a fine-tuned Qwen2.5-VL-7B-Instruct classifier filters LAION-2B down to 114k images containing transferable relational structures; (2) an anonymous captioning model, trained on 532 manually curated groups of images sharing the same relational logic, generates placeholder-based captions that abstract away object specifics; (3) the final relsim model fine-tunes Qwen2.5-VL-7B-Instruct with LoRA using InfoNCE contrastive loss to align image features with anonymous-caption text embeddings. The key architectural choice is using a full VLM (rather than a vision-only encoder) as the visual feature extractor, because relational reasoning requires world knowledge and conceptual abstraction that pure visual encoders lack—even after fine-tuning on the same captions, CLIP and DINO underperform the VLM-based model. The contrastive objective pulls together images whose anonymous captions encode similar relational abstractions while pushing apart those with different logic.

## Results

On the relational image retrieval task (evaluated by GPT-4o on a 0–10 scale), relsim achieves a score of 6.77, outperforming all attribute-based baselines: CLIP-I (5.91), DINO (5.14), LPIPS (4.56), CLIP-T (5.33), and Qwen-T (4.86). In the user study, relsim is preferred over each baseline in 42.5–60.7% of pairwise comparisons. For analogical image generation (Table 2), proprietary models (GPT-4o-Image: relsim 0.82, Nano-Banana: relsim 0.84) substantially outperform open-source models (FLUX-Kontext: 0.71, Bagel: 0.74, Qwen-Image: 0.71) on relational structure preservation, while open-source models retain higher CLIP semantic scores (0.79–0.87 vs. 0.77–0.78).

## Baselines & Comparisons

relsim (6.77) outperforms every baseline on the primary relational similarity metric. The strongest attribute-based baseline, CLIP-I (5.91), trails by 0.86 points, while purely perceptual LPIPS (4.56) and self-supervised DINO (5.14) lag further behind. Caption-based baselines (CLIP-T: 5.33, Qwen-T: 4.86) underperform because single-image prompting causes the VLM to leak semantic/attribute information rather than abstracting relational logic. Ablations show that finetuning CLIP or DINO with the same anonymous captions improves them but still falls short of relsim, confirming that LLM world knowledge is essential for relational reasoning. In the user study, relsim is preferred in 42.5–60.7% of pairwise comparisons across all baselines. For analogical image generation, proprietary models (GPT-4o-Image, Nano-Banana) achieve relsim scores of 0.82–0.84 versus 0.71–0.74 for open-source models, while open-source models maintain higher CLIP scores (0.79–0.87), indicating they preserve surface semantics better but miss deeper relational transformations.

## Relation to Prior Work

This paper draws on cognitive science distinctions between attribute similarity (Tversky's contrast model) and relational similarity (Gentner's Structure-Mapping theory) to argue that all existing image similarity metrics—LPIPS, CLIP, DINO, dreamsim—capture only the former. Methodologically, it repurposes the CLIP-style contrastive learning framework (InfoNCE loss) but replaces the pure vision encoder with a VLM (Qwen2.5-VL-7B) as the visual feature extractor, motivated by the claim that relational reasoning requires world knowledge beyond visual perception. The key departure from prior work is the introduction of 'anonymous captions'—relational descriptions that abstract away object-specific content—and a group-based captioning procedure that makes this abstraction tractable, rather than relying on single-image captioning.

## Why It Matters / Open Questions

The paper identifies a concrete, measurable gap in visual computing: existing similarity metrics systematically fail to capture relational structure, as confirmed by both automated (GPT-4o judge) and human evaluation. The 114k image-anonymous-caption dataset and the relsim metric provide the first tools for this dimension, with demonstrated utility in relational retrieval and analogical image generation. Key limitations include the small number of manually curated groups (532) that constrain the anonymous captioning model's coverage, the reliance on GPT-4o as an automated judge (raising circularity concerns), and the open question of how to handle images that embody multiple valid relational structures. Scaling the dataset and developing automated pipelines for discovering new relational patterns are identified as critical next steps.

## Problem

Existing training-free open-vocabulary segmentation methods rely on sparse textual prompts (e.g., 'a photo of a <class>') and directly use patch-text similarity maps without modeling inter-patch categorical similarity. In camouflage scenarios, where objects and backgrounds share highly similar local visual features, this leads to inadequate object binding and noisy segmentation. The paper addresses how to achieve precise fine-grained object binding in a fully training-free setting for camouflaged object segmentation.
![Teaser figure](../imgs/CVPR20262388/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB camouflaged image (resized to 336×336) and a text class prompt as input, and produces a pixel-level segmentation mask of the camouflaged object along with a category prediction. All components—CLIP (ViT-L/14 or ViT-B/16), SAM (ViT-H), and LLaVA-1.5-7B—remain frozen, making the pipeline entirely training-free. The final mask is generated by SAM using hybrid prompts (foreground/background points plus a bounding box) derived from the refined similarity maps.

## Method

The framework first uses LLaVA-1.5 to generate detailed Object Descriptions and Background Descriptions for each image, which are encoded by CLIP's text encoder to form a semantic probe that decouples object and background features. A key mechanism is semantic consistency ranking: for each patch, scores against all semantic probes are sorted into ranking vectors, and Spearman correlation between ranking vectors of patch pairs measures categorical similarity, which is then used to re-weight patch features for precise object binding. An Entropy-Guided Text Embedding Adjustment (EGTEA) module selects high-entropy patches as object candidates and low-entropy patches as background candidates, then debiases text embeddings by subtracting their projection onto the background visual prototype direction and fusing with an anchor point combining visual and semantic priors. Finally, an Adaptive Hybrid Prompt Generation (AHPG) strategy produces both point prompts (from thresholded foreground/background similarity maps) and a bounding box prompt (from the foreground point set with axis-aligned expansion), which are jointly fed to SAM to produce the final segmentation mask.

## Results

On the OVCamo benchmark, the proposed training-free framework with CLIP-ViT-L/14 achieves cSm=0.502, cFβω=0.418, cMAE=0.379, cFβ=0.450, cEm=0.543, and cIoU=0.371, surpassing the strongest training-free baseline ResCLIP (cSm=0.326, cIoU=0.144) by 16.8% on average across all six metrics. With CLIP-ViT-B/16, the method reaches cSm=0.371 and cIoU=0.243, outperforming CASS (cSm=0.328, cIoU=0.097) by 7.2% on average. The framework runs at 30.2 FPS with 8.26 GB GPU memory on a single NVIDIA A40, and all models (CLIP, SAM ViT-H, LLaVA-1.5-7B) remain frozen throughout inference.

## Baselines & Comparisons

Among training-free OVSS baselines, the proposed method dominates across all six metrics: with ViT-L/14 it outperforms ResCLIP [38] by 16.8% on average (e.g., cIoU 0.371 vs. 0.144, cFβω 0.418 vs. 0.156) and ClearCLIP [11] by a wide margin (cIoU 0.371 vs. 0.097). With ViT-B/16, it surpasses CASS [9] by 7.2% on average (cIoU 0.243 vs. 0.097) and ProxyCLIP [12] by a similar margin (cIoU 0.243 vs. 0.123). Against the supervised OVCOS baselines OVCoser [20] and SuCLIP [23], the training-free method still trails (cIoU 0.371 vs. 0.443 and 0.540 respectively), but narrows the gap substantially compared to prior training-free approaches. The paper notes that no dedicated training-free OVCOS method existed before this work, so all training-free OVSS baselines were reimplemented and adapted to the OVCOS setting. The consistent advantage over training-free baselines is attributed to the semantic probe's inter-patch categorical similarity modeling and the EGTEA's background debiasing, which address the core challenge of high object-background similarity in camouflage.

## Relation to Prior Work

This paper extends the training-free open-vocabulary semantic segmentation (OVSS) paradigm—exemplified by ResCLIP, CASS, and ProxyCLIP—to the more challenging open-vocabulary camouflaged object segmentation (OVCOS) task. It builds directly on ResCLIP's use of intermediate-layer CLIP visual features but departs from the broader training-free OVSS line by introducing three key mechanisms absent in prior work: MLLM-generated fine-grained object/background descriptions (via LLaVA) to replace sparse text prompts, a semantic probe using Spearman correlation to model inter-patch categorical similarity, and an entropy-guided text embedding adjustment to suppress background interference. The framework also repurposes SAM as a decoder with adaptive hybrid prompts (points + boxes), a pattern seen in other training-free segmentation works but here tailored to the high object-background similarity of camouflage.

## Why It Matters / Open Questions

The training-free paradigm avoids the overfitting-to-seen-classes problem that plagues fully-supervised OVCOS methods, and this paper demonstrates that competitive performance (0.502 cSm) can be achieved without any task-specific training, approaching supervised OVCoser (0.579). However, the approach introduces a dependency on LLaVA for per-image description generation, adding significant inference cost and potential failure modes if the MLLM produces inaccurate descriptions. Evaluation is limited to a single benchmark (OVCamo), and it remains open whether the semantic probe and entropy-guided adjustment generalize to other dense prediction tasks beyond camouflage, or whether the multi-component pipeline can be simplified without substantial performance loss.

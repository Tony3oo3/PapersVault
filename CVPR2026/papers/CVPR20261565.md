## Problem

Merging multiple task-specific fine-tuned models into a single multi-task model is hindered by inter-task interference, where conflicting parameter updates dilute task-specific knowledge. Existing SVD-based merging methods (TSV-M, Iso-CTS) decompose task matrices based solely on parameter energy, ignoring the input feature distribution—so directions with small singular values can still be functionally critical when inputs project strongly onto them. This paper identifies this distribution-agnostic limitation and proposes a feature-aware decomposition that provably minimizes functional output error.

## Input / Output

The method consumes pre-trained CLIP ViT checkpoint weights, task-specific fine-tuned checkpoints (from the TALL-masks repository), and a minimal proxy set of 32 unlabeled images per task used solely to compute activation shifts for subspace identification—no labeled data or gradient computation is required. The output is a single merged weight set supporting all tasks simultaneously, with a global scalar α selected on a held-out validation set. Notably, the proxy set can be replaced with out-of-distribution samples (e.g., ImageNet-1k) or reduced to a single image per task without significant performance degradation.

## Method

The core contribution is Essential Subspace Decomposition (ESD), which performs PCA on activation shifts (X_proxy · ΔW^T) rather than SVD on the weight matrix, yielding an orthonormal basis aligned with the task's output feature distribution. Under ESD, the expected truncation error depends only on the sum of discarded eigenvalues—decoupled from input direction—unlike SVD where error also depends on input–singular-vector alignment. Essential Subspace Merging (ESM) then concatenates top-k truncated task factors across all tasks and orthogonalizes the concatenated matrices via SVD-based whitening to minimize inter-task correlation. A three-level Polarized Scaling mechanism (inter-task, inter-dimension, inter-layer) applies squared Frobenius-norm ratios to amplify high-confidence parameter directions and suppress low-norm noise, preventing essential knowledge from being overwhelmed during fusion.

## Results

ESM achieves state-of-the-art merged-model accuracy across all three CLIP ViT variants (B/32, B/16, L/14) and all three task-set sizes (8, 14, 20 tasks). On the 8-task benchmark, ESM reaches 88.4% (95.3% normalized) on ViT-B/32, 91.8% (97.0%) on ViT-B/16, and 94.8% (98.9%) on ViT-L/14, narrowing the gap to single-task fine-tuned experts (92.8%, 94.6%, 95.8%) to within 1.0–4.4 points. The advantage is most pronounced on smaller models and larger task sets, e.g., 81.3% (88.9%) on ViT-B/32 with 20 tasks versus 78.1% (85.5%) for the prior best Iso-CTS.

## Baselines & Comparisons

ESM outperforms all six baselines across every model scale and task-set configuration. Against the strongest prior method Iso-CTS [28], ESM gains +2.2 points on ViT-B/32 (8-task), +0.7 on ViT-B/16 (8-task), and +0.1 on ViT-L/14 (8-task), with the advantage widening to +3.2 points on ViT-B/32 (20-task). Over TSV-M [11], the gains are +2.5 (ViT-B/32, 8-task) to +3.2 (ViT-B/32, 20-task). The simpler baselines—Weight Averaging [46], Task Arithmetic [18], TIES-Merging [52], and Consensus TA [42]—trail ESM by 13–22 points on ViT-B/32, confirming that distribution-aware subspace decomposition and polarized scaling are critical for preserving task knowledge during fusion. Notably, ESM's normalized accuracy (95.3% on ViT-B/32, 8-task) closes 95% of the gap to the fine-tuned expert upper bound (92.8% absolute), whereas Iso-CTS closes only 92.8% and TSV-M only 92.3%.

## Relation to Prior Work

This paper extends the SVD-based model merging line (TSV-M, Iso-CTS) by identifying a theoretical gap: SVD truncation minimizes Frobenius-norm reconstruction error but ignores the input feature distribution, so small singular values aligned with high-probability input directions can be functionally critical. The authors replace SVD with PCA on activation shifts from a small proxy dataset (ESD), producing a subspace whose truncation error depends only on discarded eigenvalues, decoupled from input geometry. The Polarized Scaling mechanism, which rescales parameters by squared relative norms at task, dimension, and layer levels, is a new contribution not present in prior merging work, though it draws on the empirical observation that high-norm updates encode consensus directions.

## Why It Matters / Open Questions

Model merging is becoming practically critical as public model repositories grow, and this paper narrows the gap between merged and expert models to within ~1–2 points across all tested settings, with minimal overhead (a single forward pass of 32 samples per task). The finding that ESD is robust to proxy dataset composition—including out-of-distribution and single-class sampling—suggests the method does not require task-specific data, broadening its applicability. Open questions include whether the approach generalizes beyond ViT/CLIP architectures (e.g., LLMs, CNNs), how it behaves when tasks are highly heterogeneous in difficulty, and whether the rank budget allocation (k = ⌊d_out/T⌋) remains optimal as task count grows very large.

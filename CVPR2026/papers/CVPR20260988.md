## Problem

Existing tool-augmented visual reasoning methods either rely on training-free prompting that lacks active tool exploration or on large-scale supervised fine-tuning that demands extensive human annotation. Neither paradigm enables an agent to autonomously discover which tools from a diverse, heterogeneous library are most effective for a given query, particularly when tools have partially documented or inconsistently performing capabilities that differ from their descriptions.
![Teaser figure](../imgs/CVPR20260988/cropped_page0_idx0.webp)

## Input / Output

The agent receives an RGB image paired with a text query and outputs a comma-separated list of tool indices (from a 23-tool unified pool spanning chart analysis, diagram parsing, mathematical reasoning, and low-level perception) wrapped in <answer> tags. The selected tools are executed on the image, and their outputs are concatenated with the original inputs to form an augmented prompt fed to a frozen VLM reasoner, which produces the final answer. In multi-turn mode, the reasoner additionally emits a scalar confidence score in [0,1] after each round, which the agent uses to decide whether to refine its tool selection (up to 3 rounds) or stop early.

## Method

VisTA trains a VLM agent (QwenVL-7B) via GRPO-based reinforcement learning with verifiable rewards (RLVR) to learn a tool-selection policy, while keeping the reasoning VLM entirely frozen. The reward function compares the reasoner's no-tool baseline prediction against its tool-augmented prediction: +1 if tools fix a wrong answer, −0.5 if tools break a correct one, and 0 otherwise, with group-relative advantage computed across G sampled tool sets per query. The agent is prompted with only tool indices and coarse functional categories (no detailed descriptions or usage examples), forcing it to learn tool effectiveness purely from task-outcome feedback. A multi-turn refinement mechanism lets the agent iteratively revise its tool choices using the reasoner's confidence scores, with token-wise loss masking ensuring gradients flow only to the agent's selection decisions. Because the reasoner is frozen, the learned policy transfers seamlessly to different reasoning backbones (e.g., from QwenVL-7B to GPT-4o) without retraining.

## Results

On the four primary benchmarks, VisTA (multi-turn, QwenVL-7B agent + QwenVL-7B reasoner) achieves 79.9% on ChartQA, 75.8% on ChartQA-OoD, 57.0% on Geometry3K, and 52.1% on MathVerse, outperforming all training-free and GRPO fine-tuning baselines. Against state-of-the-art VLMs (Table 3), VisTA reaches 57.0% on Geometry3K (vs. 33.6% best prior) and 73.1% on MathVerse (vs. 67.7% GPT-o1), while scoring 88.1% on ChartQA—third overall behind Claude-3.5 Sonnet (90.8%) and InternVL2-76B (88.4%). The multi-turn refinement adds 0.8–3.1 points over single-turn, with the largest gain on ChartQA-OoD (+3.1). On BlindTest, VisTA achieves 53.4% with GPT-4o as reasoner, surpassing the best training-free baseline (51.8%).

## Baselines & Comparisons

VisTA decisively outperforms all training-free baselines across every benchmark: on ChartQA-OoD it gains +5.9 to +9.5 points over training-free agents (75.8 vs. 66.8 QwenVL-7B, 66.4 GPT-4o), and on Geometry3K it improves by +5.5 to +5.7 points (57.0 vs. 51.3/51.5). Against the GRPO fine-tuning baseline (which directly optimizes the reasoner without tools), VisTA multi-turn leads by +11.5 on ChartQA-OoD (75.8 vs. 64.3) and +16.0 on Geometry3K (57.0 vs. 41.0), showing that learned tool selection is far more effective than end-to-end RL on the reasoner alone. Among SOTA VLMs in Table 3, VisTA achieves the best Geometry3K score (57.0%) by a wide margin over RedStar-Geo-8B (33.6%), Math-LLaVA-13B (33.1%), and G-LLaVA (22.4%), and the best MathVerse score (73.1%) over GPT-o1 (67.7%) and Gemini 2.0 Flash (65.6%). On ChartQA, VisTA (88.1%) trails Claude-3.5 Sonnet (90.8%) and InternVL2-76B (88.4%) but surpasses Molmo-72B (87.3%), Gemini 1.5 Pro (87.2%), and GPT-4o (85.7%). In the transfer setting (Table 2), the QwenVL-7B-trained agent paired with GPT-4o as reasoner beats the best training-free GPT-4o baseline by +3.5 on ChartQA (88.1 vs. 84.6) and +2.3 on ChartQA-OoD (75.6 vs. 73.3), confirming that the learned policy transfers without retraining.

## Relation to Prior Work

VisTA builds on GRPO (from DeepSeekMath) for its policy optimization objective but repurposes it for a fundamentally different problem: learning a tool-selection policy rather than a reasoning policy. It departs from prior tool-augmented visual reasoning work (Visual Programming, ViPER-GPT, LLaVA-Plus) that relies on training-free prompting or supervised fine-tuning with human demonstrations, instead using RL with verifiable rewards to discover tool-selection strategies from task outcomes alone. The framework is orthogonal to concurrent RL-for-reasoning efforts (DeepSeek-R1, Vision-R1, ReTool) that modify the reasoner itself; here the reasoner remains frozen and only a lightweight agent is trained, enabling seamless transfer across reasoning backbones.

## Why It Matters / Open Questions

The frozen-reasoner design is practically significant: a tool-selection policy trained with a 7B agent transfers to GPT-4o as reasoner without retraining, suggesting a modular path to enhancing any VLM's visual reasoning without costly fine-tuning. The widening performance gap on out-of-distribution data (11.5 points over a GRPO-trained reasoner on ChartQA-OoD) hints that RL-learned tool selection may generalize more robustly than direct RL fine-tuning of the model. Key open questions include whether the approach scales to much larger tool libraries, how to handle parameterized tool invocation (e.g., specifying bounding boxes for zoom tools), and whether the learned policies remain stable as tool capabilities evolve over time.

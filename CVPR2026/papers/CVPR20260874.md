## Problem

Existing diffusion-based style transfer methods suffer from three interrelated limitations: a semantic gap where a single style reference cannot cover all content semantics, a reliance on extra constraints such as semantic masks that restrict applicability, and rigid global feature associations that fail to achieve adaptive regional alignment. These issues collectively prevent flexible, personalized style transfer from arbitrary multiple style references while preserving content structure.
![Teaser figure](../imgs/CVPR20260874/cropped_page0_idx1.webp)

## Input / Output

The method accepts one content image and an arbitrary number of style reference images (tested with 1, 2, 3, or 5 references per content image) and produces a single stylized image. Unlike mask-based approaches, no semantic segmentation masks or other auxiliary inputs are required; the style references need not share semantic content with the content image. The pipeline runs on Stable Diffusion 1.5 with 15 forward diffusion steps for feature extraction and 150 optimization steps for generation, with optional integration of accelerated samplers (LCM, Hyper-SD) reducing optimization to 28 steps.

## Method

StyleGallery is a training-free, three-stage pipeline built on a pretrained diffusion model. Stage 1 (DFCC) performs DDIM inversion to extract UNet intermediate features across timesteps, applies an index-adaptive sigmoid weighting to fuse them into a single feature map, then uses PCA and K-means clustering with iterative merge/split optimization to segment semantic regions without external models. Stage 2 computes region-wise similarity across three dimensions—statistical features aggregated via self-attention within each cluster, semantic similarity from DINOv2 token features filtered by cluster masks, and geometric similarity from minimum enclosing circles—to adaptively match content regions to the most relevant style regions across multiple references. Stage 3 guides DDIM sampling with a combined energy function: a Regional Style Loss (RSL) that sparsifies self-attention Q/K/V features using semantic masks and enforces L1 consistency between matched content-style region pairs, and a Global Content Loss (GCL) that constrains query features to remain close to the content branch, with the total loss backpropagated through the latent vector via Adam at each sampling step.

## Results

On the StyleGallery benchmark (750 stylized images across 25 style families), StyleGallery achieves the best score on all five metrics: Style 0.5337, Gram Loss 13.519, FID 16.889, LPIPS 0.3716, and ArtFID 24.536. The closest competitor is Attention Distillation (AD) on Style (0.5249) and Gram Loss (13.862), while StyTR-2 is nearest on LPIPS (0.3856) and ArtFID (25.804). The method also reduces inference time from ~30 s to ~8 s when integrated with accelerated samplers (LCM, Hyper-SD) while maintaining comparable quality.

## Baselines & Comparisons

StyleGallery outperforms all 12 baselines on every reported metric. Among diffusion-based methods, the closest competitor is Attention Distillation (AD) [53], which leads on Gram Loss (13.862 vs. 13.519) and is second on Style (0.5249 vs. 0.5337); StyleGallery improves Style by ~1.7% and Gram Loss by ~2.5% over AD. Among Transformer-based methods, StyTR-2 [5] is the strongest on content preservation (LPIPS 0.3856) and ArtFID (25.804), but StyleGallery still leads by 3.6% on LPIPS and 5.0% on ArtFID. CNN-based baselines (CAST [45], CCPL [44]) and other diffusion methods (CSGO [46], StyleShot [8], StyleID [4], AttnST [16]) trail by larger margins, with StyleShot showing the worst LPIPS (0.6615) and ArtFID (35.952). The mask-based method SCSA [38] is compared qualitatively (Figure 7) rather than in the main table, as it requires pre-computed semantic masks. The paper also notes that StyleID [4] produces random patterns on solid-color backgrounds and AD [53] under-stylizes, issues that StyleGallery's regional semantic matching addresses.

## Relation to Prior Work

StyleGallery extends the diffusion-based style transfer lineage by combining DIFT's intermediate UNet feature extraction for semantic correspondence with Attention Distillation's energy-function-guided sampling, but departs from both by introducing a divide-and-conquer strategy: instead of treating style as a single holistic feature (as in StyleID, CSGO, or AD), it adaptively clusters content and style images into semantic regions via K-means on diffusion features and performs region-wise matching using DINOv2 semantic similarity, statistical features, and geometric criteria. This eliminates the need for external segmentation masks (unlike SCSA) while addressing the semantic gap problem where a single style reference cannot cover all content semantics. The framework also generalizes from single-reference to arbitrary multi-reference style transfer, a setting for which no prior benchmark existed.

## Why It Matters / Open Questions

The ability to aggregate an arbitrary number of style references with adaptive semantic matching opens practical applications such as serial style transfer from an artist's body of work or user-defined region-wise style customization, which prior single-reference or mask-dependent methods cannot support. The training-free nature and demonstrated compatibility with accelerated samplers (LCM, Hyper-SD, reducing inference from ~30s to ~8s) make the approach deployable. However, the method's reliance on automatic K-means clustering means that semantically ambiguous or structurally complex inputs can produce inaccurate masks and degraded results, and highly abstract style images remain a weak point. Open questions include whether the clustering quality can be improved without external models, and whether the three-dimensional matching scheme generalizes to video or 3D content.

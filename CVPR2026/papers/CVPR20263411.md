## Problem

State-of-the-art interactive video segmentation models like SAM2 treat user corrections as temporary conditional inputs or memory-bank context rather than learning signals, so the same error patterns (occlusions, object separations, camouflage) recur throughout a video and force users into repetitive correction cycles. No existing framework enables the model to internalize and generalize from these corrections during inference, leaving a gap between the valuable human feedback provided and the model's inability to reduce future redundant interventions.

## Input / Output

The system processes video frames sequentially in a single forward pass (no revisiting), receiving user corrections as up to three clicks at error centers followed by a full ground-truth mask if IoU remains below a threshold (default 0.5). The output is a per-frame segmentation mask plus a persistently updated LoRA adapter (35K parameters) that carries correction knowledge across subsequent frames within the same video; the adapter is reinitialized when transitioning to a new video. For the classification extension, inputs are individual images streamed in label-grouped order, and the output is a refined top-3 class prediction from the adapted CLIP model.

## Method

LIT-LoRA attaches low-rank LoRA modules (rank 4, α=4, dropout 0.1) to every layer of SAM2's frozen mask decoder, introducing only 35K trainable parameters (~0.01% of full fine-tuning). When a user correction arrives, the LoRA is trained for 40 epochs (with early stopping) using a focal + Dice loss (20:1 ratio) on the current frame's fused visual and memory-bank features, converging in ~0.5 s. For subsequent frames, the updated adapter generates refined predictions that are validated against an IoU threshold: accepted predictions replace the baseline and enter the memory bank, while rejected ones trigger a new correction and further LoRA refinement. This update-predict loop accumulates video-specific knowledge about recurring failure modes, and the plug-and-play design requires no architectural changes to the backbone, extending naturally to other SAM2 variants and CLIP-based classification.

## Results

On four challenging VOS benchmarks (VOST, LVOSv2, MOSEv2, SA-V), LIT-LoRA reduces average user corrections by 18–34% at τ_IoU=0.5 (e.g., 27.43→18.24 on VOST, 33.59→14.83 on LVOSv2) and by 17–24% at the stricter τ_IoU=0.75. Total annotation time drops by an average of 22.1% (e.g., 18.42→12.91 min on VOST at τ=0.5). The per-correction training overhead is only ~0.5±0.2 s with 35K trainable parameters (~0.01% of full fine-tuning). A user study with 6 annotators confirms 41.92% fewer corrections and 23.04% less correction time in real interactive use.

## Baselines & Comparisons

Against the primary baseline SAM2 (Original), LIT-LoRA reduces corrections by 18–34% at τ=0.5 and 17–24% at τ=0.75 across all four VOS datasets, with the largest gain on VOST (↓33.51%) where objects frequently split. On the SAM2 variant DAM4SAM, LIT-LoRA cuts corrections from 26.96 to 21.23 (↓21.25%) on VOST, and on SAMURAI from 13.04 to 8.53 (↓34.55%), confirming the framework is model-agnostic. For the CLIP-based fine-grained classification task, LIT-LoRA reduces per-class corrections by 43.40% on CUB-200-2011 (13.38→7.57) and 35.70% on Stanford Cars (13.92→8.95), demonstrating task-agnostic generalization beyond video segmentation. In all comparisons, LIT-LoRA strictly outperforms the corresponding baseline with no degradation, and the ~0.5 s per-update overhead is negligible relative to the 30–46 s average human annotation time per correction.

## Relation to Prior Work

This paper builds on SAM2's promptable video segmentation architecture and LoRA's parameter-efficient fine-tuning mechanism, but departs from both the SAM2 extension literature (SAM2Long, SAMURAI, DAM4SAM) that modifies memory design or adds learnable tokens, and from offline PEFT methods that require static supervised datasets. It also distinguishes itself from Test-Time Training and Continual Test-Time Adaptation paradigms by using human corrections as explicit supervision signals rather than pseudo-labels or self-supervised objectives. The key conceptual departure is treating user corrections not as transient conditional inputs (as SAM2 does) but as training signals for a lightweight adapter that persists and generalizes across subsequent frames within the same video.

## Why It Matters / Open Questions

The 18–34% reduction in user corrections with only ~0.5s overhead per update makes live adaptation practically viable for interactive annotation workflows, and the demonstrated generality across SAM2 variants and CLIP-based classification suggests the framework could be broadly applicable to any prompt-based visual system. However, the evaluation relies on synthetic corrections under a controlled protocol, the user study is small-scale (6 participants, 8 videos), and the approach resets the adapter per video group, leaving open whether it can accumulate knowledge across sessions or handle more complex, multi-object correction scenarios. A key open question is how the method scales to very long videos or highly dynamic scenes where error patterns shift substantially over time.

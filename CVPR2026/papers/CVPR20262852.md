limitations: The SLFS strategy relies on implicit gradient signals to guide the CoT pipeline on unlabeled data, and the autoregressive CoT generation exhibits limited exploratory behavior; the authors explicitly note that incorporating Reinforcement Learning for active exploration of planning, grounding, and action spaces is needed to fully exploit the framework. ## Problem

Embodied agents face a fundamental dilemma: end-to-end navigation models bypass explicit 3D grounding and multi-step planning, limiting interpretability and long-horizon task performance, while modular systems assemble disjunct components (LLM planner, grounding model, navigation policy) that cannot dynamically replan from real-time feedback and suffer domain gaps from disparate training data. No existing approach unifies planning, grounding, and navigation within a single interpretable pipeline that also supports synergistic learning across components.
![Teaser figure](../imgs/CVPR20262852/cropped_page0_idx0.webp)

## Input / Output

The model consumes a natural language instruction and a stream of posed RGB-D images, which the Dynam3D encoder converts into a multi-level 3D memory (panoramic patch, instance, and zone tokens) plus candidate waypoints from a waypoint predictor. At each timestep, the 3D-VLM also receives the historical CoT Memory (parsed past plans, grounded target positions, and traversed waypoints) as additional context. The output is a single autoregressive multimodal token sequence structured as [planning text, grounded 3D target tokens, selected waypoint token, answer text], where grounding and navigation tokens are special latent tokens resolved via dot-product similarity against scene 3D tokens and candidate waypoints respectively, rather than free-form text.

## Method

D3D-VLP reformulates the entire embodied task as a unified autoregressive generation problem within a single 3D-VLM (NVILA-Lite-2B), where the model sequentially emits planning text, explicit 3D grounding decisions (selecting from scene tokens via a grounding head), a navigation waypoint (selected from candidates via a navigation head), and answer text in one pass. A CoT Memory feedback loop parses each generated sequence and feeds it back as context at the next timestep, enabling stateful dynamic replanning when targets are missing or navigation is blocked. For training, the Synergistic Learning from Fragmented Supervision (SLFS) strategy uses a masked autoregressive cross-entropy loss over a 10M-sample hybrid dataset where most samples carry only partial annotations (e.g., navigation-only); missing CoT components are masked out of the loss, so gradients from available annotations back-propagate through the shared VLM to implicitly supervise and reinforce the internally generated planning and grounding tokens, achieving synergistic learning without requiring fully annotated data for every sample.

## Results

On R2R-CE, D3D-VLP achieves 61.3% SR and 56.1% SPL, setting a new state-of-the-art across all end-to-end and modular baselines. On REVERIE-CE and NavRAG-CE, it reaches 47.5% SR / 34.7% SPL and 31.1% SR / 23.9% SPL respectively. On HM3D-OVON (open-vocabulary object navigation), D3D-VLP attains 47.3% SR and 30.4% SPL. On the long-horizon SG3D benchmark, it achieves 33.7% step-SR, 13.8% task-SR, and 9.3% task-ACC, substantially outperforming the best modular baseline (Dynam3D-VisTA: 4.2% t-ACC) and the best E2E model (MTU3D: 8.0% t-SR).

## Baselines & Comparisons

D3D-VLP outperforms all 27 compared baselines across every benchmark it is evaluated on. On R2R-CE, it surpasses the strongest E2E model StreamVLN by +4.4% SR and +4.2% SPL, and the strongest modular system InternVLA-N1 by +3.1% SR and +2.1% SPL. The most telling comparison is against its own perception backbone Dynam3D: the 3D CoT and unified architecture contribute +8.4% SR and +10.4% SPL, confirming the gains come from the reasoning pipeline rather than the 3D encoder alone. On HM3D-OVON, D3D-VLP (47.3% SR) beats NavFoM (43.6% SR) and Dynam3D (42.7% SR), though NavFoM edges it slightly on SPL (31.3 vs 30.4). On the long-horizon SG3D benchmark, the task-level accuracy (t-ACC) of 9.3% represents a 121% relative improvement over the Dynam3D-VisTA modular baseline (4.2%) and a 72.5% relative improvement in task-SR over the best E2E model MTU3D (8.0%), directly validating the CoT Memory mechanism for sequential stateful reasoning. In real-world mobile manipulation, D3D-VLP completes 3/10 full tasks versus 0/10 for OK-Robot and DynaMem and 1/10 for Dynam3D+OWLv2.

## Relation to Prior Work

D3D-VLP builds directly on the Dynam3D encoder [57] for its multi-level 3D perception backbone and on NVILA-Lite-2B [39] as the autoregressive VLM base, but departs from both the end-to-end navigation line (NaVid, StreamVLN, NavFoM) that outputs actions without explicit 3D grounding, and the modular planning line (InternVLA-N1, InstructNav, DreamNav) that chains disjunct LLM planners, grounding models, and navigation policies. The key conceptual departure is reformulating planning, grounding, and navigation as a single unified autoregressive 3D Chain-of-Thought sequence within one 3D-VLM, coupled with a CoT Memory feedback loop for stateful replanning. The SLFS training strategy with masked autoregressive loss is also a novel contribution, enabling joint learning from a 10M-sample hybrid dataset where most samples carry only partial annotations.

## Why It Matters / Open Questions

This work demonstrates that a single unified 3D-VLM with explicit 3D CoT can simultaneously outperform both black-box E2E models and multi-stage modular systems across five diverse embodied benchmarks, suggesting that the interpretability-vs-performance trade-off is not fundamental. The CoT Memory mechanism is shown to be the critical enabler for long-horizon sequential tasks (121% relative t-ACC improvement on SG3D), addressing a known failure mode of memory-less systems. However, absolute performance remains low (9.3% t-ACC on SG3D), the autoregressive CoT exhibits limited exploratory behavior, and the authors acknowledge that incorporating RL for active exploration of planning and action spaces is needed to fully exploit the framework. The SLFS strategy is a practically important contribution for the field, as it provides a viable path to training unified embodied models without requiring millions of perfectly-annotated samples.

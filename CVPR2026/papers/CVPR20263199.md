## Problem

2D drag-based editing methods cannot disambiguate geometric transformations (e.g., rotation vs. depth translation), producing ambiguous or implausible results for 3D-intended edits. Existing 3D-aware approaches either provide only rigid 6-DoF control, rely on slow per-image optimization (~30 min), or depend on incomplete monocular meshes that limit large deformations. No prior method delivers robust, efficient, object-level non-rigid editing with physical plausibility and seamless compositional coherence in a unified interactive framework.

## Input / Output

The method takes an RGB image and sparse user drag control points specified interactively in a 3D GUI that visualizes the rendered 3DGS in real time (10 ms latency per drag). The target object is first segmented via SAM from click prompts, then lifted into 3D. The output is a photorealistic edited RGB image at 1024×1024 resolution, with the full pipeline (object lifting + diffusion refinement) completing in ~20 s while the interactive deformation stage itself is near-instantaneous.

## Method

ObjectMorpher lifts a segmented 2D object into a 3D Gaussian Splatting representation via TRELLIS, choosing 3DGS over mesh for superior appearance fidelity and smoother gradients. A sparse editing proxy of 512 control points (sampled via farthest-point sampling) is connected into a deformable graph using geodesic distances (computed on an auxiliary local graph via Floyd's algorithm) to avoid cross-part shortcuts. Users drag handle points in 3D; an ARAP energy with alternating position optimization (Laplacian solve) and rotation estimation (SVD) enforces local rigidity, and the resulting per-node affine motions are propagated to all dense Gaussians via Linear Blend Skinning with a hybrid Euclidean-geodesic neighbor selection. Finally, a composite diffusion module (Qwen-Image-Edit with a rank-16 LoRA fine-tuned on paired triplets from Subjects200K and KlingAI videos) harmonizes lighting, color, and boundaries between the re-rendered object and an inpainted background for photorealistic reintegration.

## Results

ObjectMorpher achieves LPIPS 0.127, SIFID 10.896, and KID −0.059 on a 50-subject benchmark, while supporting real-time interaction (10 ms drag latency) with ~20 s total inference time. In the user study (20 participants, 8 tasks), ObjectMorpher receives the highest Guidance Following score (4.71/5), substantially outperforming DragDiffusion (1.68) and AnyDoor (1.83), confirming that automatic fidelity metrics are misleading in controllable editing. The method is the only one combining real-time interaction with competitive perceptual quality, whereas ImageSculpting also supports real-time interaction but requires ~30 min per image.

## Baselines & Comparisons

Against DragDiffusion (Shi et al., CVPR 2024), ObjectMorpher trades slightly worse automatic fidelity (LPIPS 0.127 vs 0.117; SIFID 10.896 vs 6.573) for dramatically better Guidance Following in the user study (4.71 vs 1.68), because DragDiffusion makes near-zero edits that trivially preserve the original image. Compared to ImageSculpting (Yu et al., CVPR 2025), ObjectMorpher achieves lower LPIPS (0.127 vs 0.178) and SIFID (10.896 vs 14.372) while reducing inference time from ~30 min to ~20 s, and both support real-time interaction. Against AnyDoor (Chen et al., CVPR 2024), ObjectMorpher wins on LPIPS (0.127 vs 0.173) and KID (−0.059 vs −0.049) but is slightly worse on SIFID (10.896 vs 9.512); critically, AnyDoor's Guidance Following score is only 1.83. DragGAN (Pan et al., SIGGRAPH 2023) and DragAnything (Yu et al., CVPR 2025) are clearly outperformed on all automatic metrics (LPIPS 0.550 and 0.655 respectively vs 0.127) and lack the 3D-aware deformation that ObjectMorpher provides. Overall, ObjectMorpher is the only method that simultaneously achieves real-time interaction, competitive perceptual fidelity, and the highest user-rated edit accuracy.

## Relation to Prior Work

ObjectMorpher extends the 3D-aware image editing line (ImageSculpting, BlenderFusion, Object3DIT) by replacing mesh or NeRF intermediates with 3D Gaussian Splatting as the editable proxy, enabling non-rigid deformation rather than the rigid 6-DoF control those methods offer. The deformation stage repurposes the classical ARAP energy from geometry processing onto a sparse control graph sampled from the 3DGS, with Linear Blend Skinning propagating motions to the dense Gaussian cloud. The compositing stage builds on recent diffusion-based editing (Qwen-Image-Edit with LoRA fine-tuning) to harmonize the re-rendered object, a step that prior 3D editing pipelines largely omit. Overall, the paper's contribution is a unified pipeline that stitches together 3DGS lifting, ARAP-constrained sparse deformation, and diffusion compositing—each component individually known—into a single interactive system.

## Why It Matters / Open Questions

The paper demonstrates that 3DGS-based editing can achieve real-time non-rigid manipulation (10 ms drag latency) while preserving identity, filling a practical gap between slow per-image optimization methods (ImageSculpting, ~30 min) and 2D drag methods that cannot disambiguate 3D geometry. A key open question is generalization: the pipeline depends on TRELLIS for single-image 3D reconstruction, which may degrade on occluded, transparent, or highly textured objects, and the compositing LoRA is trained on a limited set of paired triplets from Subjects200K and KlingAI videos. Scaling to multi-object scenes, handling dynamic backgrounds, and reducing the ~20 s end-to-end latency (dominated by lifting and diffusion refinement) remain important directions for broader adoption.

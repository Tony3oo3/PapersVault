## Problem

Existing 3D pose stylization methods rely on cascade pipelines that first manipulate pose in 2D (e.g., via ControlNet) and then lift the result into 3D, causing error propagation from 2D artifacts and inherent geometric ambiguity from 2D skeleton projections that lose depth and topological information. No prior work unifies pose stylization and 3D generation within a single end-to-end 3D-native model that directly leverages 3D spatial constraints.

## Input / Output

The method takes a single RGB image (encoded by DINOv2-Large at 518×518 resolution) and a 3D skeleton as input. The skeleton is densified via distance-weighted interpolation along each bone into a point cloud where every point carries both 3D coordinates and the parent bone's directional vector, then downsampled to 256 points via Farthest Point Sampling. The output is an explicit 3D mesh extracted via TSDF isosurfacing from a VecSet latent, which can be directly skinned and animated when paired with a skinning model, yielding a rigged animatable asset without manual retargeting.

## Method

PoseMaster builds on the Hunyuan3D 2.1 backbone (3D VAE + flow-matching DiT) and introduces a dedicated 3D skeleton encoder that densifies sparse joint coordinates into a dense point cloud with explicit bone-directional vectors, processed by a two-block Point Transformer to produce a 1024-d skeleton condition. This condition is integrated at the token level with the DINOv2 image condition inside the DiT, and a class-conditional guidance (CFG) formulation allows progressive control over pose dominance during training. A scalable data engine constructs over 500K pose-decoupled 'Image-Skeleton-Mesh' triplets by combining Action Pairs from animatable assets (cross-frame sampling) and View Pairs from static meshes (cross-viewpoint sampling with automatic rigging for unrigged assets), enabling the model to jointly learn identity preservation and geometric alignment. Training fine-tunes only the DiT and skeleton encoder (learning rate 1×10⁻⁵) with the VAE and image encoder frozen, using a conditional flow-matching objective with synchronized 3D augmentations applied to both skeleton and surface points to preserve spatial registration.

## Results

On the VRoid pose canonicalization benchmark (50 images), PoseMaster achieves the best scores across all four metrics: MAE 4.59°, SIM 0.938, Uni3D-I 0.402, and ULIP-I 0.161. For arbitrary-pose stylization (Table 2), PoseMaster reduces MAE to 5.28° versus 6.75–7.66° for the 3D-native baselines, while also leading on SIM (0.935), Uni3D-I (0.313), and ULIP-I (0.172). Notably, in the arbitrary-pose setting the baselines are given the target-pose image directly, whereas PoseMaster only receives a source-pose image plus a 3D skeleton, making the margin even more significant.

## Baselines & Comparisons

PoseMaster outperforms all five baselines on every metric in both the pose canonicalization and arbitrary-pose stylization settings. Against the closest cascade-pipeline competitor StdGen, PoseMaster reduces MAE from 4.97° to 4.59° (≈7.6% improvement) and gains 0.008 in SIM, confirming that eliminating the 2D canonicalization step avoids error propagation. The gap widens substantially against CharacterGen (MAE 6.38° → 4.59°, a 28% reduction) and the 3D-native generators: Trellis (5.39° → 4.59%), CraftsMan (5.67° → 4.59%), and Hunyuan3D 2.1 (5.89° → 4.59%). In the harder arbitrary-pose stylization task (Table 2), where baselines receive the target-pose image directly while PoseMaster only sees a source-pose image plus a 3D skeleton, the MAE advantage grows to 1.47–2.38° over Trellis, CraftsMan, and Hunyuan3D 2.1 respectively, and PoseMaster also leads on all identity-preservation metrics (Uni3D-I, ULIP-I). The qualitative analysis attributes the baselines' inferior geometry to 2D artifacts (occlusions, structural distortions) that cascade into 3D, a failure mode absent in PoseMaster's end-to-end 3D-native pipeline.

## Relation to Prior Work

PoseMaster extends the 3D native generation lineage (Hunyuan3D 2.1, CraftsMan, Trellis) by introducing explicit 3D skeleton conditioning into the diffusion transformer, departing fundamentally from the cascade paradigm used by CharacterGen, StdGen, and SKDream that first manipulates 2D images via ControlNet-style models before lifting to 3D. The key conceptual shift is replacing 2D OpenPose-style skeleton maps with a densified 3D point-cloud representation (distance-weighted interpolation + bone directional vectors) encoded by a Point Transformer, providing unambiguous spatial and topological priors. The scalable data engine, which synthesizes pose-decoupled 'Image-Skeleton-Mesh' triplets from both animatable and static assets, addresses a data bottleneck that prior cascade methods sidestepped by relying on 2D foundation models for pose transfer.

## Why It Matters / Open Questions

By unifying pose stylization and 3D generation in a single end-to-end model, PoseMaster eliminates the error propagation that plagues cascade pipelines, and the strict spatial alignment between generated meshes and conditioning skeletons enables direct integration with skinning models for animatable asset creation—bypassing manual retargeting. The practical rigging application (Section 6) positions this as a potential component in automated character production pipelines for gaming and VR. Open questions include whether the approach generalizes beyond humanoid characters, how it handles complex multi-character scenes, and whether the 500K-object dataset is sufficient for truly diverse stylistic generalization beyond the anime/VRoid aesthetic that dominates the evaluation.

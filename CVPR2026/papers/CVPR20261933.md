## Problem

Existing VLM jailbreaks focus almost exclusively on content-based triggers (what is depicted), leaving the non-content-based attack surface—how an image is visually presented—largely unexplored. The paper identifies a 'Stylistic Inconsistency' where MLLMs robustly comprehend content across visual styles yet their safety alignment can be bypassed by specific stylistic modifications, and no prior work provides a general-purpose framework to systematically identify and adversarially optimize such stylistic vulnerabilities.

## Input / Output

The method consumes a base adversarial image from an existing SOTA attack (e.g., QR-Attack, SI-Attack, HIMRD) paired with its harmful text prompt, along with a style directive selected from a structured pool of four categories (Medium & Texture, Geometric Distortion, Thematic & Atmospheric, Domain-Specific Illustration). It outputs a single styled adversarial image that preserves the original semantic content while applying an RL-optimized stylistic transformation, which when fed to the target VLM with the same harmful prompt elicits a jailbroken response. The enhancement is plug-and-play: the same optimized generator can be applied to any base attack without retraining.

## Method

ASO operates in two sequential stages. First, Style Sensitivity Probing evaluates all styles in the pool against the target VLM using an un-finetuned image-editing model (FLUX-Kontext) to empirically select the most vulnerable style S*. Second, GRPO-based Style Enhancement fine-tunes the generator's parameters via a Dynamic-Batch GRPO (DB-GRPO) algorithm that frames the task as an MDP, using an ODE-to-SDE conversion to make the flow-matching model compatible with stochastic policy gradients. The optimization is guided by a Structurally-Tiered Reward Function: rejected responses receive a dense logit-based penalty (log-ratio of VLM accept vs. reject probabilities, offset by threshold C_thresh = −10), while accepted responses receive a judge-model-based reward (log-ratio of harmful vs. harmless probabilities, clipped at C_thresh), creating a continuous gradient across both domains. A dynamic curriculum mechanism maintains an Unsolved Pool, evicting samples that succeed or exceed K_max attempts, so the agent continuously focuses on discovering new attacks rather than retraining on solved ones.

## Results

On MM-SafetyBench, ASO consistently amplifies base attack ASR across all four target VLMs. The most dramatic gains appear on commercial models: QR Attack on GPT-4.1-mini reaches 54.26% ASR (HS −0.62) and SI Attack on Gemini-2.5-Flash reaches 55.81% ASR (HS +0.21), both crossing into positive harmfulness territory. On open-source models, HIMRD + ASO achieves 89.52% ASR (HS 8.93) on Qwen3-VL and 76.74% ASR (HS 5.22) on Gemini-2.5-Flash. On VLBreak-Bench, IDEATOR + ASO lifts Qwen3-VL ASR from 48.28% to 53.27%, and SI Attack + ASO lifts GPT-4.1-mini from 75.54% to 77.70%.

## Baselines & Comparisons

ASO is a plug-and-play enhancer, so comparisons are framed as base-attack vs. base-attack + ASO rather than against a competing attack method. Against QR Attack [8], ASO lifts ASR by roughly 2–14 percentage points depending on the target (e.g., +13.6 pp on GPT-4.1-mini, from ~40.7% to 54.26%), with the largest relative gains on commercial models. Against SI Attack [18], the pattern is similar: +14.5 pp on Gemini-2.5-Flash (58.99% → 55.81% is actually a gain from the VLBreak-Bench baseline; on MM-SafetyBench the absolute ASR reaches 55.81%). Against IDEATOR [14] on VLBreak-Bench, ASO adds +4.99 pp on Qwen3-VL (48.28% → 53.27%) and +0.72 pp on GPT-4.1-mini (74.82% → 75.54%). Against HIMRD [10], which already achieves very high baseline ASR (87–100% on many categories), ASO still extracts marginal but consistent gains (e.g., 87.38% → 89.52% on Qwen3-VL) and, more importantly, increases the Harmfulness Score, indicating more semantically harmful outputs. FigStep [3] is reported as a standalone typographic baseline without ASO enhancement, serving as a lower-bound reference point across all four VLMs.

## Relation to Prior Work

This paper extends the VLM jailbreak literature beyond content-based triggers (FigStep, QR-Attack, HIMRD) and structural manipulation (SI-Attack's shuffle inconsistency) by identifying visual style as an independent, exploitable vulnerability axis. Methodologically, it builds on Flow-GRPO and DanceGRPO for applying GRPO to flow-matching generative models via ODE-to-SDE conversion, but repurposes this machinery for adversarial style optimization rather than general visual generation quality. The key conceptual departure is framing style as a 'plug-and-play' enhancement layer orthogonal to the base attack, rather than as a standalone attack vector, and introducing a Structurally-Tiered Reward Function that combines cheap logit-based refusal detection with expensive judge-model evaluation to provide dense gradients in a sparse-reward setting.

## Why It Matters / Open Questions

The finding that VLM safety alignment is sensitive to non-content stylistic attributes (e.g., pencil sketch, vintage photo) challenges the implicit assumption that defenses operate purely on semantic content, suggesting a broader and harder-to-patch attack surface. However, the practical gains are modest (typically 2–6 percentage points ASR uplift), and the method requires access to VLM internal logits for the tiered reward, limiting applicability to closed-source APIs. Open questions include whether defenders can simply augment safety training with diverse style augmentations, whether the discovered style triggers transfer across model families, and whether the vulnerability persists as VLMs scale or undergo further alignment iterations.

## Problem

Dynamic lighting environments (time-of-day cycles, light source switching) require precomputing multiple lightmap sets, one per lighting condition, leading to prohibitive storage and memory costs that scale linearly with the number of time steps. No prior work addresses neural compression specifically for temporal lightmap sets, and existing neural texture compression methods rely on large decoders that are impractical for real-time rendering.

## Input / Output

At inference, the method takes texture coordinates (u, v) and a continuous time parameter t as input and outputs reconstructed RGB lighting values. The compressed representation consists of four feature maps (a full-resolution 2D map, two half-resolution 2D triplane maps, and a lower-resolution 3D map) plus a small MLP, all stored as 8-bit BC7-compressed textures. The system supports random access at arbitrary (u, v, t) without decoding the full lightmap set, and operates on 128×128 tiles with up to 26 temporal samples per tile.

## Method

NDGI encodes temporal lightmap sets into a hybrid feature map structure: a full-resolution 2D map for shared spatial signal, two half-resolution 2D triplane maps (ut, vt) for fine spatial-temporal details, and a lower-resolution 3D map (uvt) for luminance variation over time. A lightweight two-layer MLP with positional-encoded time decodes the concatenated sampled features into lighting values. During training, a BC-simulation strategy replaces direct feature map updates with per-block endpoint-and-weight optimization (4×4 blocks), ensuring the learned features remain compatible with hardware BC7 compression after quantization. At runtime, a virtual texturing system streams tiles on demand and a compute shader performs per-tile decompression, reusing cached tiles across short time intervals to avoid redundant inference.

## Results

On the FarmLand scene, NDGI achieves PSNR 45.96 dB and SSIM 0.996 at only 0.67 BPP (279 MB, 0.7% of the 39.9 GB uncompressed reference), outperforming NTC (44.02 dB, 0.993 SSIM at 0.78 BPP) and PRT (19.41 dB, 0.8982 SSIM at 0.92 BPP). For decompression speed on a 1024×1024 lightmap, NDGI M. completes in 0.203 ms versus 0.886 ms for NTC L., a 4.4× speedup. The BC simulation strategy further reduces BPP from 2.32 (8-bit quantization alone) to 0.68 when combined with BC7, achieving a 0.7% storage ratio relative to the original.

## Baselines & Comparisons

Against PRT [22], NDGI wins decisively on every metric: PSNR improves from 19.41 dB to 45.96 dB (+26.5 dB) and SSIM from 0.8982 to 0.996, while also using less storage (279 MB vs 358 MB). Against NTC [26], NDGI achieves higher reconstruction quality (45.96 vs 44.02 dB PSNR; 0.996 vs 0.993 SSIM) at a lower bitrate (0.67 vs 0.78 BPP) and a 4.4× faster decode (0.203 ms vs 0.886 ms), attributed to the much smaller MLP decoder and reduced feature dimensionality. Compared to traditional GPU compression (BC6H, BC7, ASTC), NDGI avoids the blocky artifacts visible in ASTC and the quality degradation of BC6H on HDR lightmaps, while delivering higher PSNR at comparable or lower BPP. The paper notes that NTC's 16-channel limit required partitioning the temporal lightmap data into segments, whereas NDGI natively handles the full temporal set in a single model, giving it a structural advantage in temporal coherence.

## Relation to Prior Work

This paper extends the neural texture compression paradigm (NTC [26]) from single static textures to temporally varying lightmap sets, introducing a hybrid feature map structure (2D spatial + 3D spatiotemporal + triplane) that explicitly encodes temporal illumination variation. It departs from prior neural compression by integrating a BC-simulation strategy during training—inspired by Belcour [13] and Weinreich [29]—so that learned feature maps remain compatible with hardware BC7 encoding, a constraint absent in NTC. The runtime system further diverges from NTC by coupling the neural decoder with a virtual texturing pipeline for on-demand tile-level decompression, rather than requiring full-texture inference.

## Why It Matters / Open Questions

The practical impact is significant for game development: reducing dynamic GI storage from ~40 GB to under 360 MB (0.9%) while maintaining 44+ dB PSNR makes time-of-day and dynamic-lighting effects feasible in large-scale real-time scenes that previously could not afford the memory. The released temporal lightmap dataset (FarmLand, Room, City, Yard) provides the first public benchmark for this specific compression problem. Open questions include scaling training beyond PyTorch's current throughput for thousands of tiles, handling truly abrupt illumination switches within a single frame, and whether the triplane+3D decomposition generalizes to higher-frequency or more complex temporal patterns (e.g., animated caustics).

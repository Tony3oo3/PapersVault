## Problem

Current AI models process ARC-AGI task examples in a single static forward pass, lacking the iterative 'understand-solve' loop that humans use to refine hypotheses about transformation rules while simultaneously constructing solutions. LLMs achieve only 15.8–34.5% accuracy, and small task-specific models like TRM rely on fixed puzzle-embedding tables that prevent dynamic rule encoding and generalization to unseen tasks.
![Teaser figure](../imgs/CVPR20260264/cropped_page1_idx1.webp)

## Input / Output

The model receives 2–5 input-output grid pairs (examples) and a single problem input grid, all tokenized into sequences of length L with embedding dimension D=368. It produces a predicted output grid via a linear decoder applied to the final solution state. Inference uses pass@2 (two candidate answers per problem), and the adaptive halting mechanism dynamically terminates the reasoning loop (up to T_max=16 steps) once internal consistency is detected, with a mean of ~12.4 steps actually used.

## Method

USRL comprises two Recurrent Transformer modules—an Understanding Module (UM) that encodes example pairs into rule representations via learned query tokens, and a Solving Module (SM) that iteratively updates a latent solution state—interacting over multiple reasoning steps. At each step, the UM's raw rule representation is modulated by the current solution state through a learned gating function before being injected into the SM, creating a recurrent 'understand-solve-re-understand' loop. Training combines cross-entropy solution loss with a supervised InfoNCE contrastive loss that enforces rule-representation isomorphism (examples from the same task cluster in feature space), plus stochastic halting to expose the model to diverse reasoning depths. At inference, an adaptive halting mechanism terminates the loop when the answer representation's cosine similarity to example representations exceeds the intra-example similarity threshold, requiring only 7M total parameters.

## Results

On the ARC-AGI-1 evaluation set (2 tries), USRL achieves 47.2% accuracy with only 7M parameters, the highest among all evaluated models. This surpasses the closest task-specific baseline TRM (44.6%, also 7M params) by 2.6 points and the larger HRM (40.3%, 27M params) by 6.9 points. USRL also significantly outperforms general-purpose LLMs: Gemini 2.5 Pro 32K (37.0%), o3-mini-high (34.5%), and DeepSeek-R1 (~671B, 15.8%).

## Baselines & Comparisons

USRL outperforms all four compared baselines on ARC-AGI-1 accuracy. Against the closest task-specific competitor TRM (7M params, 44.6%), USRL gains +2.6 points, demonstrating that the explicit Understanding Module and adaptive halting mechanism add value beyond TRM's fixed puzzle-embedding design. Against HRM (27M params, 40.3%), USRL achieves +6.9 points with roughly 4× fewer parameters. Against Omni-ARC (0.5B, 40.0%), USRL leads by +7.2 points while using ~70× fewer parameters. Against the LLM baselines, the gap is even larger: USRL exceeds Gemini 2.5 Pro 32K by 10.2 points, o3-mini-high by 12.7 points, and DeepSeek-R1 by 31.4 points, highlighting that scale alone does not translate to abstract visual reasoning performance.

## Relation to Prior Work

This paper extends the Tiny Recursion Model (TRM) [14] by replacing its fixed puzzle-embedding table with a dedicated Understanding Module that dynamically encodes transformation rules from example pairs, and by introducing a recurrent interaction loop between this module and the Solving Module (itself a Recurrent Transformer inherited from TRM). The adaptive halting mechanism draws on Adaptive Computation Time [9] but grounds the stopping criterion in a novel rule-representation isomorphism property: the loop halts when the generated answer's embedding falls within the cluster of example embeddings. The contrastive (InfoNCE) training objective for enforcing this isomorphism is a new addition not present in prior ARC-AGI architectures, and the gating mechanism that modulates rule representations by the current solution state synthesizes ideas from condition-injection (FiLM/AdaLN) and task-embedding literature into a single recurrent design.

## Why It Matters / Open Questions

The result that a 7M-parameter model with an explicit understand-solve loop outperforms LLMs with hundreds of billions of parameters (47.2% vs. 15.8–37.0%) reinforces the emerging view that architectural inductive bias, not scale, is the key bottleneck for abstract reasoning. However, 47.2% remains far below human performance, and the framework is limited to example-based rule induction tasks (not fixed-rule problems like Sudoku or tasks without demonstration pairs). Open questions include whether the reasoning loop generalizes to ARC-AGI-2 or other rule-induction domains, whether the contrastive isomorphism property holds at scale, and whether the adaptive halting mechanism can be made more reliable (it costs 0.2% accuracy and still requires a T_max=16 safety cap).

## Problem

Existing multi-shot video generation methods rely on either fixed temporal windows (which discard older shots, causing memory loss) or single-keyframe conditioning (which limits cross-shot context to one image), both of which degrade under complex narratives with character reappearances and evolving scenes. The core challenge is modeling a global yet compact cross-shot context that preserves narrative consistency across discontinuous shots without incurring prohibitive computational cost.

## Input / Output

The model takes a sequence of shot-level text captions written in referential narrative flow (e.g., 'the same man', 'the cat runs across the water') with no separate global script, plus an optional starting image for image-to-multi-shot mode. It generates a multi-shot video autoregressively, one shot at a time, at 480×832 resolution, producing minute-scale sequences of up to 10 shots. Each new shot is conditioned on the current caption and an adaptive memory of all preceding shots, enabling both text-to-multi-shot and image-to-multi-shot generation within a single unified model.

## Method

OneStory reformulates multi-shot video generation as a next-shot prediction task built on a pretrained I2V diffusion transformer (Wan2.1), enabling shot-by-shot autoregressive synthesis. A Frame Selection module uses learnable query tokens that first attend to the current caption, then to the 3D-VAE-encoded latent memory of all prior shots, computing per-frame relevance scores (supervised with DINOv2/CLIP pseudo-labels) to select a sparse set of semantically relevant frames. An Adaptive Conditioner then applies importance-guided patchification: frames with higher relevance scores are assigned finer patchifiers (lower compression) while less relevant frames get coarser ones, producing a compact set of context tokens that are concatenated with the noise tokens as joint DiT input. Training employs shot inflation (converting 2-shot sequences into 3-shot triplets) for uniform optimization and a decoupled conditioning curriculum that initially samples conditioning frames uniformly before switching to selector-driven conditioning, stabilizing early training of the randomly initialized Frame Selection module.

## Results

On the T2MSV benchmark, OneStory achieves the best inter-shot coherence with Character Consistency 0.5874 and Environment Consistency 0.5752 (avg 0.5813), and the highest Semantic Alignment score of 0.2389, outperforming the strongest baseline StoryDiff.+Wan2.1 (0.5657 avg, 0.2217) by ~2.6% and ~7.6% respectively. Intra-shot quality is also superior, with Subject Consistency 0.9364 and Background Consistency 0.9410. In the I2MSV setting, OneStory again leads all metrics, reaching Character Consistency 0.5851 and Semantic Alignment 0.2354, surpassing the best baseline Mask2DiT (0.5449 avg, 0.2270) by ~7.4% and ~3.7%.

## Baselines & Comparisons

OneStory outperforms all five baselines across every metric in both T2MSV and I2MSV settings. In T2MSV, the closest competitor is StoryDiff.+Wan2.1 (keyframe conditioning), which trails by 2.4 points on Character Consistency (0.5633 vs 0.5874) and 1.7 points on Semantic Alignment (0.2217 vs 0.2389); the fixed-window attention baseline Mask²DiT lags further behind at 0.5446 inter-shot avg. In I2MSV, where keyframe baselines are excluded, OneStory leads Mask²DiT by 3.4 points on Character Consistency (0.5851 vs 0.5452) and 0.84 points on Semantic Alignment (0.2354 vs 0.2270), while the edit-and-extend baseline Flux+Wan2.1 is the weakest on narrative metrics (0.1897 Semantic Alignment). The gap is most pronounced on Dynamic Degree (0.4698 vs 0.4231 for the best T2MSV baseline), indicating OneStory produces more temporally coherent motion within shots while maintaining cross-shot consistency.

## Relation to Prior Work

OneStory builds directly on the pretrained I2V model Wan2.1, leveraging its strong visual conditioning capability by reformulating multi-shot video generation as a next-shot autoregressive task. It departs from two established paradigms for cross-shot context modeling: fixed-window attention (e.g., Mask²DiT, LCT), which suffers from memory loss as the window slides, and keyframe conditioning (e.g., StoryDiffusion, Captain Cinema), which restricts context to a single image per shot. The key conceptual departure is the adaptive memory mechanism—combining a Frame Selection module that identifies semantically relevant frames across *all* prior shots with an Adaptive Conditioner that performs importance-guided (rather than temporal-order) patchification—enabling global yet compact context without the limitations of either prior paradigm.

## Why It Matters / Open Questions

Multi-shot video generation is becoming essential for real-world creative applications (film, advertising, interactive storytelling), and this paper provides a principled solution to the core challenge of maintaining narrative coherence across discontinuous shots. The finding that a single latent-frame equivalent of context tokens suffices for strong inter-shot coherence is practically significant, suggesting that adaptive memory can be very compute-efficient. Limitations include training on a relatively small 60K human-centric dataset, evaluation limited to ~10-shot minute-scale videos, and reliance on a specific I2V backbone; open questions include scalability to much longer narratives (dozens of shots), non-human-centric domains, and whether the adaptive memory approach transfers to other generative architectures beyond DiT-based I2V models.

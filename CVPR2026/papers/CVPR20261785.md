## Problem

Traditional handle-based mesh deformation methods are fast and precise but require strategic handle placement and expensive re-optimization whenever handles change, while data-driven methods capture semantic/visual awareness but sacrifice fine-grained control and real-time speed. No existing method simultaneously provides resolution-robust, real-time deformation weights that are both locally controllable and globally semantically aware without solving an optimization problem per handle configuration.
![Teaser figure](../imgs/CVPR20261785/cropped_page0_idx3.webp)

## Input / Output

The method takes a 3D mesh (tested up to 10M+ faces) and a set of control handles with assigned affine transformations, plus optional fixed-point constraints and a locality parameter λ. During preprocessing, the mesh is QEM-simplified to ≤50k faces, rendered, and features are distilled from DINOv2 into a per-shape neural field; at inference, the weight matrix W ∈ R^{n×n} is computed via a single feedforward pass and pairwise L2 feature-distance evaluation, making new-handle binding sublinear in vertex count. The output is a deformed mesh produced by linear blending of the handle transformations through W, with no additional regularization or energy minimization.

## Method

DFD defines deformation weights as clamped L2 similarities between unit-norm deep features (distilled from DINOv2 renders) at each vertex pair, so visually similar structures automatically co-deform without any optimization. The key architectural contribution is barycentric feature distillation: rather than supervising the neural field only at pixels containing mesh vertices (as in prior work), the rasterization geometry is used to assign 3D surface coordinates to every pixel covered by a triangle, decoupling field resolution from mesh resolution and enabling fast distillation on QEM-simplified meshes that transfers to the original high-resolution mesh. Locality is controlled by multiplying weights by (1 − G_ij)^λ where G_ij is normalized geodesic distance, and fixed-point constraints are enforced by subtracting the maximum weight to each fixed point from all weights. The neural field representation also enables automatic visual symmetry detection by evaluating feature reflection across candidate planes, which is then used to mirror handle deformations for symmetry-preserving edits.

## Results

In a user study (N=37) selecting the two most desirable deformations per example, DFD-T (translation) is chosen 82% of the time and DFD-A (affine) 79%, compared to ARAP (19%), NeuralMLS (11%), APAP (4%), and Biharmonic (3%). In a second perceptual realism study (N=23), DFD is selected 64% of the time versus ARAP (17.7%), NeuralMLS (15.2%), Biharmonic (2.2%), and APAP (0.93%). Timing analysis across resolutions from 10³ to 10⁷ faces shows DFD scales sublinearly in both bind and pose phases, while biharmonic coordinates fail entirely above 10⁵ faces and APAP has a base runtime several orders of magnitude larger.

## Baselines & Comparisons

DFD outperforms all five baselines in both user studies and timing. Against classical methods (ARAP, Biharmonic), DFD achieves substantially higher user preference (82% vs. 19%/3%) and perceptual realism (64% vs. 17.7%/2.2%), primarily because DFD captures visual/semantic structure that Laplacian-based methods cannot; ARAP and Biharmonic also require re-optimization per handle and Biharmonic fails above 10⁵ faces. Against neural methods (APAP, DMH, NeuralMLS), DFD wins on user preference (82% vs. 4%/3%/11%) and perceptual realism (64% vs. 0.93%/2.2%/15.2%), while also being the only method that supports both global semantic deformations and local control simultaneously. In timing, DFD's preprocess is resolution-agnostic due to barycentric distillation (minutes for shapes up to 10M faces), bind is a single feedforward pass, and pose is linear blending — all orders of magnitude faster than APAP's score distillation sampling or ARAP's per-handle linear solves. The key differentiator is that DFD requires no re-optimization when handles change, a property no baseline shares.

## Relation to Prior Work

This paper bridges two established lines of handle-based deformation: classical variational methods (ARAP, biharmonic coordinates) that are fast but require optimization and strategic handle placement, and data-driven methods (APAP, DeepMetaHandles, NeuralMLS) that capture semantic structure but sacrifice fine-grained control and speed. The key conceptual departure is using distilled deep features from a pretrained 2D model (DINOv2) as a direct basis for deformation weights via simple L2 feature distances, bypassing all optimization. The barycentric feature distillation pipeline improves upon prior surface feature distillation (Diff3F, Wimmer et al.) by supervising on all pixels within a rasterized triangle rather than only vertex pixels, decoupling distillation complexity from mesh resolution.

## Why It Matters / Open Questions

The ability to deform meshes up to 1M faces in real time on consumer hardware without re-optimization for new handles addresses a fundamental bottleneck in interactive 3D editing that has persisted across both classical and neural methods. The resolution-agnostic distillation (via QEM + barycentric features) makes the pipeline practical for production-quality assets. Limitations include the per-shape distillation step (still ~1 minute for high-res shapes) and inherited issues with linear blending under extreme deformations (volume collapse). Open questions include whether the per-shape optimization can be eliminated entirely (e.g., via a universal feature field) and whether the approach extends to topology-changing or non-rigid material deformations.

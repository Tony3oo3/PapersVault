## Problem

Most vision models for gigapixel microscopy operate on single-resolution crops or derive multi-scale features through internal downsampling (e.g., feature pyramids in U-Net or Swin), which forces a trade-off between field of view and spatial detail. No existing architecture jointly processes true multi-resolution observations of the same scene within a single encoder while maintaining explicit geometric alignment across scales.
![Teaser figure](../imgs/CVPR20262030/cropped_page1_idx0.webp)

## Input / Output

The method takes a tuple of L spatially nested image crops (identical pixel dimensions H×W but differing physical fields of view via downsampling factors l₁,…,l_L) together with their bounding-box coordinates in a shared world-coordinate system (defined as the pixel grid of the finest level). For segmentation, it outputs a per-pixel class map at the finest resolution; for MAE pretraining, it outputs reconstructed pixel patches at each masked resolution level. The bounding boxes are critical: replacing them with naive centered coordinates causes performance to collapse to single-resolution baseline levels.

## Method

MUViT embeds patches from all resolution levels into a shared token sequence using level-specific linear projections plus learnable level embeddings, then processes them through a unified 12-layer transformer encoder. The key mechanism is 2D axial Rotary Position Embeddings computed from each patch's absolute world coordinates, so that patches representing the same physical location receive identical positional encodings regardless of resolution level, enabling geometrically consistent cross-scale attention. For self-supervised pretraining, MUViT-MAE applies Dirichlet-sampled masking (α=0.5) across resolution levels with a global masking ratio of 0.75, using per-level lightweight decoders with cross-attention to visible encoder tokens. Downstream segmentation uses either a UNETR-style decoder (conv upsampling with skip connections from encoder layers 0, 5, 11) or a Mask2Former-style decoder (learnable mask queries cross-attending to multi-resolution features), trained with combined cross-entropy and Dice loss at the finest resolution only.

## Results

On the MOUSE brain anatomy segmentation task (12 classes), MUVIT[1,8,32]+Mask2Former achieves mDSC=0.901 using only 3×256×256 input, substantially outperforming the best single-resolution baseline DeepLabV3 (mDSC=0.843) which requires 1024×1024 inputs. On the KPIS kidney pathology benchmark, MUVIT[1,8]+UNETR reaches DSC=0.8958 with 2×512×512 inputs, surpassing the purpose-built HoloHisto-4K method (DSC=0.8454) that uses 3840×2160 inputs. On the controlled SYNTHETIC dataset, MUVIT[1,4]+UNETR achieves mDSC=0.9538 versus 0.4895 for the best single-resolution baseline (DeepLabV3), demonstrating that cross-scale integration is essential when class identity depends on global structure.

## Baselines & Comparisons

MUVIT outperforms all nine baselines across all three datasets. On MOUSE, MUVIT[1,8,32]+Mask2Former (mDSC=0.901) beats DeepLabV3 at 1024×1024 (0.843) by 5.8 points while using inputs 16× smaller in pixel count; U-Net and SwinUNETR-V2 degrade severely at smaller input sizes (mDSC drops to 0.085 and 0.333 at 256×256 respectively), whereas MUVIT maintains strong performance at 3×256×256. On KPIS, MUVIT[1,8]+UNETR (DSC=0.8958) surpasses HoloHisto-4K (0.8454), the strongest published method for this task, by 5 points, and also exceeds SAM-ViT-H (0.7724), SwinUNETR-V2 (0.7158), DeepLabV3 (0.6822), SegFormer (0.6501), UNETR (0.6425), and nnU-Net (0.6219). In the KPIS linear probing experiment, MUVIT[1,8,32,64] achieves ROC-AUC 0.988 versus 0.907 for off-the-shelf HIPT, confirming that multi-resolution MAE pretraining yields richer representations. The ablation with naive (inconsistent) bounding boxes shows that MUVIT's advantage over single-resolution baselines depends critically on correct world-coordinate alignment: without it, MUVIT[1,4]+UNETR on SYNTHETIC drops from mDSC 0.9538 to 0.3864, falling below all single-resolution baselines.

## Relation to Prior Work

MUViT extends the masked autoencoder pretraining paradigm (MAE, MultiMAE) to a genuinely multi-resolution setting by treating different physical scales of the same image as complementary input modalities within a single encoder. Its key architectural departure from hierarchical ViTs (Swin, PVT, HIPT) and parallel multi-path models (MMViT, CrossViT) is that it ingests true multi-resolution observations—crops at different physical magnifications—rather than deriving scale variants internally from one input. The geometric alignment mechanism repurposes axial Rotary Position Embeddings (from EVA-02 and RoFormer) in a new role: rotation angles are computed from absolute world coordinates rather than relative patch indices, so tokens at the same spatial location receive identical positional encodings regardless of resolution level.

## Why It Matters / Open Questions

The paper addresses a fundamental practical bottleneck in gigapixel microscopy analysis: the forced trade-off between field of view and spatial resolution when processing tiled crops. The world-coordinate RoPE mechanism is simple, lightweight (~25M parameters), and yields large gains over single-resolution baselines with substantially smaller input sizes (e.g., 2×512×512 beating 3840×2160 on KPIS), making it attractive for memory-constrained settings. Open questions include whether the computational overhead of joint cross-scale attention can be reduced via sparse schemes, whether the approach extends cleanly to 3D volumes and other tasks (instance segmentation, detection), and how robust the method is to noisy or approximate coordinate metadata in real acquisition pipelines.

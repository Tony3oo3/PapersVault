## Problem

Current agentic vision-language models achieve high final-answer accuracy on visual search benchmarks while exhibiting unfaithful tool use: they crop irrelevant regions or ignore tool outputs yet still guess correct answers. This misalignment stems from outcome-dominant, sparse reward signals in existing RL training that provide no step-level supervision on how tools are actually used, enabling reward hacking where models optimize for superficial success rather than genuine visual grounding.
![Teaser figure](../imgs/CVPR20260910/cropped_page0_idx0.webp)

## Input / Output

The model receives a high-resolution RGB image and a text question, then generates a multi-turn trajectory of interleaved actions: free-form thinking tokens, delimited Python code blocks executed in a restricted sandbox (with read-only image access and deterministic image/math utilities), and a final text answer. Sandbox execution returns observations (cropped images, coordinates, logs) that are appended back into the context, so the model iteratively refines its visual evidence before committing to an answer. The code-based interface replaces external tool APIs, leveraging code patterns already seen during pretraining.

## Method

CodeV is trained with a two-stage SFT+RL pipeline. The SFT cold-start on Thyme-SFT establishes basic tool-use patterns (localized crops, multi-round refinement) and serves as the reference policy. The RL stage uses Tool-Aware Policy Optimization (TAPO), a GRPO variant that augments the standard clipped objective with a hybrid reward R(τ) = λ_acc·r_acc + λ_tool·r_tool, where r_tool is a dense, step-level faithfulness score computed by a judge model (Qwen2.5-VL-32B) that checks whether each tool output (e.g., a crop) actually contains the object or region referenced in the question. Crucially, the judge only sees non-model-generated context (question, sandbox output, metadata), never the chain-of-thought or code, making the reward verifiable and resistant to reward hacking. Group baselines from K sampled trajectories per prompt provide the Monte Carlo critic, and PPO-style clipping stabilizes updates across the mixed language-and-code action space.

## Results

On the V* visual search benchmark, CodeV achieves 84.8% accuracy, substantially outperforming GPT-4o (64.4%) and Qwen2.5-VL-7B (75.0%). On VLMBlinds, CodeV attains the best score of 46.7, improving over Qwen2.5-VL-7B and Pixel-Reasoner-7B by roughly 3 points and over Thyme-7B-RL by about 8 points. On math benchmarks, CodeV reaches 71.8 on MathVista (best among all evaluated models) and 49.2 on MathVerse-Mini. In faithfulness evaluation, CodeV's faithful tool-use rate is roughly 1.3–2× that of other tool-using baselines (DeepEyes: 57%, Pixel-Reasoner: 43% on V*), while maintaining comparable or better answer accuracy.

## Baselines & Comparisons

Against Qwen2.5-VL-7B (the base model), CodeV improves V* accuracy from 75.0 to 84.8 (+9.8 points) and VLMBlinds by ~3 points, demonstrating that the SFT+TAPO pipeline adds substantial agentic capability beyond the pretrained VLM. Against Pixel-Reasoner-7B, CodeV matches or exceeds accuracy on visual search benchmarks while achieving a dramatically higher faithful tool-use rate (Pixel-Reasoner: 43% faithful on V* vs. CodeV's roughly 1.3–2× higher rate). Against Thyme-VL-7B-RL, CodeV gains ~8 points on VLMBlinds and shows far superior faithfulness, as Thyme's rollouts rarely invoke visual tools (fewer than 10% actually call tools, relying on implicit 'cropped image' assumptions). Against DeepEyes, CodeV substantially outperforms on faithfulness (DeepEyes: 57% faithful tool use on V*) while maintaining competitive accuracy. Against the proprietary GPT-4o, CodeV achieves a large margin on V* (84.8 vs. 64.4) and matches or slightly exceeds it on VLMBlinds, narrowing the open-source-to-proprietary gap on fine-grained visual search tasks.

## Relation to Prior Work

This paper builds directly on the agentic visual reasoning line (VisProg, ViperGPT, Pixel-Reasoner, DeepEyes, Thyme) that interleaves image operations with textual reasoning, and on the code-based tool interface popularized by OpenAI o3's 'thinking with images.' Its key departure is in reward design: prior RL-based visual agents (DeepEyes, Pixel-Reasoner) rely on outcome-only or invocation-bonus rewards, which the authors show leads to reward hacking and unfaithful tool use. TAPO augments GRPO with dense, verifiable process rewards computed on tool outputs (e.g., whether a crop contains the queried object) rather than on chain-of-thought tokens, drawing on the process-reward literature for LLMs but applying it to visual tool evidence. The faithfulness evaluation protocol—checking whether intermediate crops actually contain the target—is a new diagnostic that prior visual-agent papers did not employ.

## Why It Matters / Open Questions

The finding that state-of-the-art visual agents achieve 80%+ accuracy while only 43–57% of their tool calls are faithful to the question is a significant reliability concern for deploying agentic VLMs in safety-critical or interpretability-sensitive settings. TAPO provides a practical, open-source recipe (SFT cold-start + GRPO with tool-output rewards) that closes much of this gap without sacrificing accuracy, making it a useful building block for future agentic VLM training. However, the judge-based reward is currently tailored to image-centric operations like cropping, relies on a static 32B judge model with deployment cost, and has not been validated on broader tool ecosystems (web search, structured knowledge bases), leaving open how to define and supervise faithfulness for heterogeneous tool types at scale.

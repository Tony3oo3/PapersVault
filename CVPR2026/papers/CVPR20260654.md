## Problem

Existing multi-modal ReID methods that incorporate text annotations rely on static, descriptive captions that capture surface-level attributes but ignore the intrinsic hierarchical logical relationships among semantic features (e.g., a vehicle's brand implying its body line, or clothing suggesting gender). No prior ReID work has exploited the structured, step-by-step reasoning that Chain-of-Thought (CoT) provides in MLLMs to encode these logical dependencies and guide visual feature learning.

## Input / Output

The method takes tri-spectral images (RGB, NIR, TIR) resized to 128×256 for vehicle datasets or 256×128 for person datasets, along with per-modality CoT reasoning chains and attribute descriptions generated by Qwen-VL using modality-specific templates. The CoT text is consumed at three distinct architectural levels—early (injected into DINOv3 register tokens), late (as a conditional anchor in cross-modal consistency), and decision-making (as text feature input)—rather than being used as a single static descriptor. The output is a fused identity embedding per modality used for cross-camera ReID ranking, evaluated via mAP and CMC at Rank-1/5/10.

## Method

CoT-ReID builds on DINOv3-B as the visual backbone and introduces three modules that inject CoT reasoning text at progressively later stages of the pipeline. First, CoT-guided Reverse Embedding (CRE) projects frozen CLIP text embeddings of the CoT reasoning chain into DINOv3's four register tokens, concatenating them with the visual patch sequence so that logical semantic context calibrates bottom-level feature extraction from the first Transformer layer onward. Second, CoT-guided Cross-Modal Consistency (CT-CMC) formulates a bidirectional contrastive loss between all three modality pairs, using the CoT text as a conditional anchor and incorporating a protective margin Δ = log(N₁/N₀) (inspired by InfoBridge) to prevent over-alignment while promoting information sharing. Third, CoT-guided Text Features (CTF) feed the reasoning text through a separate encoder whose output is jointly optimized with visual features under a unified ReID objective (label-smoothed cross-entropy + triplet loss per feature stream plus the CT-CMC loss). The CoT text itself is generated offline by Qwen-VL with modality-specific prompts that require the model to identify the main object, verify attribute consistency, and weight reliable attributes, producing both a reasoning chain and a final attribute description per image.

## Results

On the three multi-spectral vehicle ReID benchmarks, CoT-ReID achieves mAP/Rank-1 of 89.9/99.3 on RGBNT100, 74.7/82.0 on WMVeID863, and 71.7/85.3 on MSVR310, setting new state-of-the-art results across all datasets. On the multi-spectral person dataset RGBNT201, the method reaches mAP/Rank-1 of 83.3/86.1. Compared to the DINOv3-only baseline (same backbone, no CoT modules), the full framework yields gains of +2.9% mAP on RGBNT100, +4.6% on WMVeID863, +3.5% on MSVR310, and +5.8% on RGBNT201.

## Baselines & Comparisons

CoT-ReID outperforms all 22 compared baselines on every dataset. Against the strongest DINOv3-based competitors, it improves mAP by +3.0% over DeMo° (68.7→71.7) and +4.7% over IDEA° (67.0→71.7) on MSVR310, and by +2.2% over DeMo° (72.5→74.7) on WMVeID863. On the person ReID benchmark RGBNT201, it surpasses IDEA° by +2.0% mAP and +2.9% Rank-1 (81.3/83.2 → 83.3/86.1). The CLIP-based methods (MambaPro†, ICPL†, DeMo†) trail the DINOv3-based methods by 3–10 mAP points, confirming the advantage of the stronger self-supervised backbone. The paper's own DINOv3° baseline (no CoT modules) already achieves competitive results (e.g., 68.2 mAP on MSVR310), but the CoT-guided modules add a further 3.5 mAP, isolating the contribution of the reasoning-text guidance from the backbone choice.

## Relation to Prior Work

This paper extends multi-spectral object ReID (RGB/NIR/TIR) by introducing Chain-of-Thought reasoning chains from MLLMs as dynamic semantic context, departing from prior text-guided ReID methods (CLIP-ReID, IDEA, DeMo, ICPL) that rely on static, fine-grained attribute descriptions. Architecturally, it builds directly on DINOv3's register-token mechanism, repurposing these tokens as carriers for CoT semantic embeddings injected at the early feature-extraction stage. The cross-modal consistency module (CT-CMC) is theoretically grounded in InfoBridge's conditional dependency lower bound, upgrading it with a CoT-anchored protective margin to prevent over-fusion. The paper positions itself as the first to use CoT reasoning as semantic context in ReID, framing the shift from surface-level text-image alignment to deep, hierarchical logical binding.

## Why It Matters / Open Questions

The CoT-guided framework offers a principled way to inject interpretable logical structure into multi-modal ReID, potentially transferable to other cross-modal retrieval tasks where static descriptions underutilize inter-attribute relationships. The MLLM-generated CoT benchmarks (reasoning chains + attribute captions) provide reusable resources for the community. However, the approach depends on MLLM text quality and adds a generation pipeline, raising questions about robustness to noisy or hallucinated reasoning text. The authors acknowledge open questions about which specific reasoning signals contribute most and how they interact across modalities, suggesting the current framework is a first step rather than a complete solution.

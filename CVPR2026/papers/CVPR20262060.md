## Problem

Current text-to-image diffusion models treat interacting instances as independent entities conditioned on their respective bounding boxes, failing to model the intrinsic functional dependencies between subject, predicate, and object. While methods like InteractDiffusion inject interaction triplets, they merely concatenate or sum embeddings without enforcing the semantic derivative chain (subject → predicate → object), resulting in spatially proximate but functionally incoherent interactions. The paper addresses this gap by formalizing interactions as a directed acyclic graph with explicit differentiable semantic dependencies.

## Input / Output

The method consumes a text prompt, subject and object bounding boxes, and an interaction triplet (subject label, predicate label, object label). The predicate box is automatically derived via a 'between' operation on the subject and object boxes, then expanded by a ratio ζ (default 0.1), while a global box encloses all three regions. These are encoded via CLIP text embeddings and Fourier positional encodings, then processed through the interaction graph before being injected into a frozen latent diffusion U-Net (SD 1.5 or SDXL) to produce a single RGB image with the specified interaction rendered in the correct spatial and semantic configuration.

## Method

The Semantic Derivative Flow (SDF) framework structures generation through a directed acyclic interaction graph G=(V,E) with vertices {subject, predicate, object, global} and edges enforcing s→p→o. The core mechanism is a derivative attention module that, for each directed edge u→v, derives a query from source u and keys/values from target v, then applies a learned sigmoid gate on the compatibility [Q,K] to selectively amplify features in v that are semantically contingent on u—formally implementing a differentiable functional dependency. A regional refinement module closes the loop by extracting real-time visual features from the noisy latent via RoIAlign at each node's bounding box and fusing them with the semantically-refined embeddings, providing bottom-up feedback during denoising. Two new cross-attention layers per U-Net block inject both the semantically-flowed and visually-refined graph embeddings (with learnable gating scalars), while all pre-trained weights remain frozen. The paper further provides a theoretical analysis framing the derivative attention as structured message passing, proving mutual information monotonicity along the interaction chain and establishing generalization bounds from the reduced effective hypothesis complexity.

## Results

On HICODet, SDF (SDXL backbone) achieves the best fidelity with FID 18.42 and KID 0.00656, and the best controllability with HOI detection mAP of 33.55 (Swin-Large, Default, Full) and 28.03 (Swin-Large, Default, Rare). The SD1.5 variant also outperforms all baselines, reaching 32.20 mAP (Swin-Large, Default, Full). The performance gap is most pronounced on the Rare subset (138 long-tail interaction categories), where SDF (SDXL) scores 28.03 vs. 26.09 for InteractDiffusion and 18.93 for GLIGEN, indicating strong generalization to infrequent interactions.

## Baselines & Comparisons

SDF (SDXL) outperforms the most directly comparable baseline, InteractDiffusion [18], by +1.99 mAP on Swin-Large Default Full (33.55 vs. 31.56) and +1.94 on Rare (28.03 vs. 26.09), confirming that explicit derivative attention provides a stronger interaction signal than simple triplet concatenation. Against GLIGEN [21], which only models instance-level placement without interaction structure, SDF gains +7.10 mAP on Default Full and +9.10 on Rare, a dramatic margin reflecting the cost of ignoring relational semantics. SDXL without spatial grounding [27] serves as a lower bound, scoring only ~1.4 mAP, confirming that bounding-box conditioning is essential. In Table 2, SDF also substantially outperforms recent layout-control methods (TFLC, NoiseCollage, BuildAScene, ControlNet++, MIGC) by 3–10 mAP on Default Full, validating that spatial layout control alone is insufficient for plausible interactions. Manual evaluation (Table 3) corroborates the quantitative results: SDF (SD1.5) scores 8.8/10 on quality and 8.6/10 on controllability, surpassing InteractDiffusion (8.2/8.0) and GLIGEN (6.1/7.8).

## Relation to Prior Work

This paper extends the interaction-controlled generation line initiated by InteractDiffusion, which formalizes interactions as (subject, predicate, object) triplets but injects them via simple concatenation or summation of embeddings. SDF departs from this by explicitly modeling the semantic derivative chain s→p→o through a novel derivative attention mechanism that enforces functional dependencies along a directed acyclic interaction graph, drawing on graph message-passing principles. The spatial conditioning paradigm (Fourier-encoded bounding boxes, gated cross-attention injection) is inherited from GLIGEN, and the overall architecture is built on the Stable Diffusion latent diffusion framework, with the key novelty being the structured top-down semantic flow combined with bottom-up regional visual feedback.

## Why It Matters / Open Questions

By shifting from spatial grounding to semantic relational grounding, this work provides a principled mechanism for ensuring that generated interactions are not merely spatially proximate but functionally coherent, which is a persistent failure mode in current text-to-image systems. The theoretical framing as structured message passing with mutual information guarantees offers a rigorous justification that goes beyond empirical validation. However, the framework is limited to two-instance interactions (subject-predicate-object), requires detailed (triplet + box) annotations for training, and may produce overly idealized interactions lacking real-world diversity. Extending the graph to multi-relation, multi-instance scenes and reducing annotation dependency remain important open questions.

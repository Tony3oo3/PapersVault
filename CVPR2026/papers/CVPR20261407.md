## Problem

Existing foreground-free zero-shot temporal action detection methods (e.g., Ti-FAD) align text features with video features that include both action-relevant foreground and text-irrelevant background regions. Because background dominates untrimmed videos, this joint alignment causes text features to drift toward background-biased patterns, resulting in predictions that are nearly identical regardless of the input text — i.e., text-irrelevant predictions that fail to distinguish semantically valid from invalid class names.

## Input / Output

The method consumes untrimmed video snippets (16-frame windows with stride 4 on THUMOS14, stride 16 on ActivityNet v1.3 and HACS-Segment) encoded by frozen pretrained visual backbones (I3D, VideoMAE, or CoCA), together with action class names encoded by frozen text encoders (CLIP-B or CoCA). It outputs per-snippet action start/end boundaries, class labels, and confidence scores via an anchor-free detector (ActionFormer-based) followed by Soft-NMS. Notably, the pipeline requires no external captioning model or supervised video-level classifier, operating strictly within the zero-shot assumption.

## Method

TF-CADE builds on Ti-FAD's multi-level cross-modal adaptation (bi-directional cross-attention between video and text features across pyramid levels) and introduces two components. First, Action Concentrate Aggregation (ACA) computes a temporal action certainty map by taking the max video-text similarity across classes, applying softmax, and smoothing with a fixed Gaussian kernel; this map is then used to soft-aggregate video features into a foreground-weighted video embedding, which is aligned with the corresponding text embedding via a video-level focal loss during training. Second, Certainty-based Confidence Re-weighting (CCR) applies at inference by taking the softmax of the foreground-based video-level similarity scores and element-wise multiplying them with the sigmoid'd per-snippet confidence map, suppressing semantically irrelevant classes. The total training objective combines snippet-level and video-level classification losses (focal), DIoU localization loss, and actionness loss, trained for 15–25 epochs with Adam on a single A100 GPU.

## Results

Under the strictly zero-shot 'no external information' setting on THUMOS14 (50%-50% split), TF-CADE with I3D/CLIP-B achieves 21.1 average mAP, outperforming Ti-FAD (16.0) by 5.1 points and T3AL (10.4†) by 10.7 points. On ActivityNet v1.3 under the same split, TF-CADE (CoCA/CoCA) reaches 13.0 average mAP, surpassing Ti-FAD (8.6) and STALE (4.4). In the more challenging 75%-25% split, TF-CADE (I3D/CLIP-B) achieves 34.5 average mAP on THUMOS14 and 17.2 on ActivityNet v1.3. In cross-dataset generalization (trained on ActivityNet, tested on THUMOS14, 0%-100% split), TF-CADE achieves 27.4 average mAP, nearly 2.5× the performance of Ti-FAD (11.1) and T3AL (9.6).

## Baselines & Comparisons

TF-CADE consistently outperforms all compared baselines in the no-external-information zero-shot setting. Against the strongest baseline Ti-FAD [13], TF-CADE (I3D/CLIP-B) gains +5.1 mAP on THUMOS14 (21.1 vs 16.0) and +3.1 mAP on ActivityNet (10.5 vs 7.4) under the 50%-50% split, and +7.6 mAP on THUMOS14 (34.5 vs 26.9) and +3.5 mAP on ActivityNet (17.2 vs 13.7) under the 75%-25% split. Against T3AL [16], which relies on CoCA-generated captions (†), TF-CADE (I3D/CLIP-B) achieves +10.7 mAP on THUMOS14 (21.1 vs 10.4†) without any captioning model, though T3AL slightly edges out on ActivityNet (14.3† vs 10.5) in the 50%-50% split. STALE [20] and ZEAL [1] are substantially weaker, with STALE reporting only 4.4 mAP on ActivityNet and ZEAL limited to THUMOS14 (10.7 mAP). In cross-dataset evaluation (Table 2, 0%-100% split), TF-CADE achieves 27.4 mAP on THUMOS14, outperforming Ti-FAD (11.1) by 16.3 points and T3AL (9.6) by 17.8 points, demonstrating a decisive advantage in true zero-shot generalization.

## Relation to Prior Work

This paper builds directly on Ti-FAD (NeurIPS 2024), adopting its cross-modal adaptation architecture and anchor-free ActionFormer backbone, but identifies a critical flaw: existing foreground-free methods align text with both foreground and background video regions, causing text features to drift toward background-biased patterns and produce text-irrelevant predictions. The key departure is the introduction of Action Concentrate Aggregation (ACA), which uses a Gaussian-smoothed temporal certainty map to construct a foreground-weighted video embedding for text alignment, and Certainty-based Confidence Re-weighting (CCR), which uses the resulting video-level similarity as a prior to suppress irrelevant classes at inference. This positions TF-CADE as a targeted refinement of the foreground-free paradigm, explicitly reintroducing foreground awareness that prior foreground-free methods had discarded.

## Why It Matters / Open Questions

The diagnostic experiment showing that removing background regions makes text features distinctly more separable across action classes provides a clear mechanistic explanation for why existing ZSTAD methods underutilize textual information, which is a useful insight for the broader video-language alignment community. The strong cross-dataset generalization margins (e.g., 28.2 vs. 11.7 mAP on THUMOS14 under 50%-50% split) suggest that foreground-concentrated alignment is particularly important when training and test distributions diverge. Open questions include whether the foreground-weighting strategy generalizes beyond temporal action detection to other video-language tasks, and whether the reliance on frozen pre-trained VLM encoders (CLIP, CoCA) limits the approach's ceiling as these models evolve.

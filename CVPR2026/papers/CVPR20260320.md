## Problem

Style-conditioned scene text generation requires extracting precise text styles from cluttered, multilingual reference images and maintaining fine-grained style consistency across all generated characters. Existing methods either reuse styles only from in-place text (preventing arbitrary external style references) or lack explicit content awareness in style extraction, causing style-content entanglement and degraded performance on complex backgrounds. Cross-lingual transfer is especially problematic because different writing systems (Latin, Chinese, Arabic) exhibit distinct typographic structures that current methods fail to handle consistently.

## Input / Output

The model takes four inputs: a background scene image (H×W×3), a text prompt p (rendered into a binary glyph image I_glyph of shape H×W×1 and concatenated vertically with the scene image), a style reference text image I_style, and an inpainting mask M indicating where text should appear. The output is a 512×512 generated scene text image where the designated region contains text rendered with the font, color, stroke pattern, and texture of the reference style. The glyph image provides explicit structural cues while the scene image supplies background context, and the style reference is consumed through a dedicated encoder rather than being concatenated into the diffusion input.

## Method

StyleTextGen builds on a FLUX.1-Fill-dev DiT backbone (initialized from TextFlux) under a rectified-flow inpainting paradigm, with three key additions. First, a Dual-Branch Style Encoder processes the style reference: a textual branch (InternViT pretrained on style-preserving multilingual text segmentation, followed by self-attention and a Q-Former) captures glyph-specific cues, while a visual prior branch (SigLIP + MLP + Q-Former) provides holistic scene context; the two are fused via cross-attention into a text-aware style embedding that modulates DiT self-attention through additive style key-value pairs. Second, a Text Style Consistency Loss computes Frobenius-norm differences between Gram matrices of multi-layer features extracted only within masked text regions of the generated and reference images, enforcing uniform style across all characters. Third, a mask-guided inference-time style injection inverts the reference image through DiT to recover its internal key-value features, then applies AdaIN-based blending restricted to text regions (via segmentation masks) during the first 10 denoising steps to refine style alignment. Training freezes the DiT and encoder backbones, optimizing only Q-Former adapters, MLP projectors, and the linear projection to style key-value pairs.

## Results

On AnyWord-Eval, StyleTextGen achieves 0.7102/0.6524 sentence accuracy (English/Chinese) and 0.8575/0.8187 NED, outperforming the strongest baseline TextFlux by 5.6 and 3.4 percentage points in Sen.Acc respectively. For style similarity, StyleTextGen reduces FID to 49.51 (En) and 52.43 (Zh), a 16.7% and 8.2% improvement over TextFlux, and achieves the lowest LPIPS (0.161 En / 0.187 Zh) among all methods. On the StyleText-CE benchmark, StyleTextGen consistently surpasses Calligrapher across all four metrics under both self-style and external-style reference settings, with the largest gains in cross-lingual transfer (e.g., FID reduced from 149.68 to 135.27 for en→cn self-style).

## Baselines & Comparisons

StyleTextGen outperforms all three baselines on every metric in both languages. Against TextFlux (the strongest baseline), it gains +5.6 pp Sen.Acc on English and +3.4 pp on Chinese, while reducing FID by 16.7% (En) and 8.2% (Zh) and LPIPS from 0.187→0.161 (En) and 0.204→0.187 (Zh). Against Calligrapher, the margins are larger: +9.7 pp Sen.Acc (En) and +13.7 pp (Zh), with FID dropping from 54.26→49.51 (En) and 63.28→52.43 (Zh). AnyText trails the most, with Sen.Acc below 0.57 in both languages and FID above 67. On the StyleText-CE benchmark (Table 2), where only Calligrapher supports external-style reference, StyleTextGen still wins across all four metrics in all eight configurations (self/external × monolingual/cross-lingual), with the largest FID reduction of ~15.1 under external-style en→cn transfer.

## Relation to Prior Work

StyleTextGen builds directly on the TextFlux/FLUX.1-Fill-Dev inpainting backbone for multilingual scene text synthesis, but departs from prior scene text editing methods (SRNet, STEFANN, TextCtrl) that only preserve in-place style, and from freestyle generators like Calligrapher that lack explicit content-aware style extraction. The dual-branch style encoder (a text-segmentation-pretrained InternViT branch fused with a SigLIP visual-prior branch via Q-Former and cross-attention) is a novel architectural choice that explicitly separates text-specific typographic cues from holistic scene context. The text style consistency loss, which computes Gram-matrix distances restricted to masked text regions, and the mask-guided AdaIN-based inference-time style injection represent new mechanisms not present in prior diffusion-based text generation or general image style transfer work.

## Why It Matters / Open Questions

The introduction of StyleText-CE, a bilingual benchmark with self-style, external-style, monolingual, and cross-lingual evaluation settings, fills a gap in systematic evaluation for style-conditioned text generation that previously lacked standardized cross-lingual protocols. The consistent gains over Calligrapher (the only prior method supporting external style references) across all four metrics and both reference modes suggest that explicit text-region-aware style modeling is a meaningful design principle. However, the work is limited to Chinese-English bilingualism at 512×512 resolution with a relatively small training set (~14k images), leaving open questions about scalability to additional scripts (Arabic, Devanagari, etc.), higher resolutions, and more diverse artistic style categories. Whether the dual-branch encoder's advantage persists under larger-scale pretraining or with stronger backbones remains untested.

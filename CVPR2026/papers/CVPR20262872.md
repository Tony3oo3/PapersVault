## Problem

Existing embodied exploration benchmarks emphasize one-shot task completion (e.g., reaching a target or answering a single question) while neglecting the exploration process and the agent's ability to build, store, and actively retrieve long-term episodic memory. This gap prevents evaluation of whether an agent can unify cognitive understanding with decision-making over long horizons, a prerequisite for lifelong learning in embodied settings.
![Teaser figure](../imgs/CVPR20262872/cropped_page0_idx0.webp)

## Input / Output

The model receives a text task instruction, three RGB observation images (front, left, right at 30° intervals), a goal-oriented question, and access to an external memory bank of image-text-position triples. The model first generates a tool-call code snippet to query the memory bank via CLIP-based cosine similarity, and the retrieved memories are concatenated back as additional input before the final response. The structured output must contain three segments: a discrete single-step action (move forward 0.25 m or turn ±30°), a frontier cell selection, and a natural-language answer to the question.

## Method

MemoryExplorer fine-tunes Qwen2.5-VL-7B via Reinforcement Fine-Tuning (GRPO) to learn proactive memory retrieval and exploration jointly. The key mechanism is that the model autonomously generates code to invoke an external CLIP-based retrieval tool over an episodic memory bank; the retrieved image-text memories are fed back as extra context, and the model then produces its action, frontier, and answer in a single structured response. A multi-task reward function combines four sub-rewards—action accuracy, frontier correctness, answer precision, and format completeness—linked by a consistency coefficient that penalizes logically inconsistent action-frontier pairs. A scaling factor further amplifies all sub-rewards when the tool is invoked successfully and reduces them when invocation fails, explicitly incentivizing efficient tool use. Training uses GRPO with a KL penalty (β=0.1) over 160 steps on 8 H200 GPUs, and the reward is clipped to [0,1] for stability.

## Results

On LMEE-Bench (Total), MemoryExplorer achieves 23.53% SR and 14.99 SPL for multi-goal navigation, and 43.62 MLLM-Score / 65.52% accuracy for memory-based QA, outperforming the strongest baseline RA-Mem (20.96 SR, 12.18 SPL, 35.52 Score, 58.62 Acc) by 2.6 SR, 2.8 SPL, 8.1 Score, and 6.9 Acc points. On GOAT-Bench (Val Unseen), MemoryExplorer reaches 46.40% SR and 28.03 SPL, surpassing RA-Mem (42.81/21.95) and 3D-Mem (37.05/20.26), and exceeding the best GOAT-Bench modular baseline (SenseAct-NN Skill Chain, 29.5/11.3) by 16.9 SR and 16.7 SPL.

## Baselines & Comparisons

MemoryExplorer consistently outperforms all MLLM exploration baselines on both benchmarks. On LMEE-Bench, it beats RA-Mem (the strongest non-RL baseline) by 2.6 SR and 8.1 QA Score, and 3D-Mem by 6.6 SR and 11.0 QA Score; Explore-EQA, which lacks memory, trails by 10.3 SR and has no QA capability. On GOAT-Bench, MemoryExplorer surpasses RA-Mem by 3.6 SR and 6.1 SPL, and 3D-Mem by 9.4 SR and 7.8 SPL, while also exceeding the best modular GOAT-Bench baseline (SenseAct-NN Skill Chain) by 16.9 SR. Among retrieval-augmented QA-only baselines (Qwen2.5-VL-7B, Qwen3-VL-8B, GPT-4o, etc.), MemoryExplorer's QA Score of 43.62 and Acc of 65.52 exceed all of them (best: Qwen2.5-VL-7B at 41.72 Score / 55.86 Acc), indicating that RL-trained active memory retrieval yields better question answering than passive retrieval alone.

## Relation to Prior Work

This paper extends the 3D-Mem line of work (Zhu et al., ICCV 2025), which uses passive object-based memory filtering to support embodied navigation, by replacing it with an active, tool-invocation-based memory retrieval mechanism trained via reinforcement learning (GRPO). It also departs from prior multi-goal navigation benchmarks (GOAT-Bench) and embodied QA benchmarks (OpenEQA, MemoryEQA) by unifying both into a single evaluation framework where the agent must simultaneously navigate, build episodic memory, and answer questions grounded in that memory. The multi-task reward design—jointly optimizing action prediction, frontier selection, and QA accuracy—is a novel formulation that ties spatial decision-making to cognitive recall in a single policy.

## Why It Matters / Open Questions

The LMEE-Bench benchmark fills a gap in embodied AI evaluation by measuring not just whether an agent reaches a goal but whether it can recall and reason about what it observed during exploration—a capability essential for lifelong learning agents. The RL-based active memory retrieval paradigm (training the MLLM to decide *when* and *what* to query) is a reusable technique that could transfer to other long-horizon embodied tasks. Limitations include single-round tool invocation, evaluation restricted to HM3D indoor scenes, and a relatively small test subset (58 of 166 tasks); open questions include whether the approach scales to multi-round retrieval, outdoor or dynamic environments, and whether the multi-task reward generalizes beyond the specific action space used here.

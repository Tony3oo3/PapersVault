## Problem

Existing event-based blur decomposition methods treat the event stream as a holistic motion descriptor over the entire exposure window, lacking explicit mechanisms to align event motion features with image texture features at an arbitrary target time. This implicit, time-agnostic fusion fundamentally limits reconstruction quality, as the network cannot selectively focus on motion relevant to a specific instant or geometrically correct the spatial misalignment of time-averaged image features.
![Teaser figure](../imgs/CVPR20262661/cropped_page0_idx0.webp)

## Input / Output

The method takes a single motion-blurred image (synthesized by averaging 11 consecutive sharp frames at 640×360 for GoPro or 640×1120 for EBD) together with the corresponding event data (real DVSync events or v2e-simulated events) captured during the exposure period, plus a continuous target time t ∈ [0,1]. It outputs a high-frame-rate sharp video sequence—typically 5 frames at timestamps {0.0, 0.3, 0.5, 0.7, 1.0} or 9 frames for longer sequences—where each frame is the latent sharp image at the queried instant. During training, one target time is randomly sampled per iteration from the 11 constituent sharp frames, and the corresponding sharp frame serves as supervision.

## Method

TSANet centers on Time-Specialized Alignment: before fusing the two modalities, both event and image features are explicitly aligned to the query time t. The Relative Time-Encoded Attention (RTEA) module injects a learnable bias into attention scores based on the normalized temporal distance between each event frame and t, producing a time-specialized motion feature that focuses on motion near the target instant; it operates at both global and window spatial scales with adaptive fusion. The Timesurface Dynamic Warping (TDW) module leverages the event timesurface (encoding the timestamp of the most recent event per pixel) to predict a pixel-wise displacement field via a Scale-and-Shift conditioned convolutional head, warping the time-averaged image features into the correct spatial configuration at time t. A lightweight Event Guide Gating Fusion (EGGF) module then combines the aligned features through element-wise gating, avoiding expensive cross-attention. The event branch uses Conv blocks and Swin Transformer blocks, while the image branch uses SFHBlocks; the entire network is trained end-to-end with supervised pixel-level loss.

## Results

TSANet achieves state-of-the-art blur decomposition performance across all three datasets: 28.40 dB PSNR / 0.908 SSIM on GoPro×5, 36.84 dB / 0.974 on HighREV×5, and 29.02 dB / 0.916 on EBD×5. These represent gains of +0.64 dB over the best prior event-based method (EvEnhancer) on GoPro, +1.06 dB on HighREV, and +1.18 dB over REFID on EBD. The model uses only 6.3M parameters, comparable to or smaller than most baselines, while delivering the best SSIM on all three benchmarks.

## Baselines & Comparisons

TSANet outperforms all 11 baselines on every dataset and metric. Among image-only methods, the strongest (BimVFI, BiT) trail by 1.14–4.6 dB PSNR, confirming that multi-frame RGB inputs cannot recover the temporal information destroyed by exposure integration. Among event-based methods, EvEnhancer [38] is the closest competitor on GoPro (27.76 vs. 28.40 dB) and HighREV (35.78 vs. 36.84 dB), while REFID [34] leads on EBD (27.84 vs. 29.02 dB); TSANet surpasses both by 0.64–1.18 dB. The gap over earlier event-based approaches (EVDI, E-CIR, LEDVDI, RED) is substantially larger (2–5 dB), underscoring that simply feeding events into a network without explicit time-specialized alignment is insufficient. Notably, TSANet achieves these gains with only 6.3M parameters, matching EvEnhancer (6.6M) and far below REFID (15.9M) or LEDVDI (16.3M).

## Relation to Prior Work

This paper extends the event-based blur decomposition line initiated by EDI (physics-guided) and EVDI (learning-based), which treat events as a holistic motion descriptor over the entire exposure window. It departs from these by introducing an explicit Time Specialized Alignment principle: rather than fusing a single event representation with image features, the network must first specialize both modalities to an arbitrary query time t before fusion. The RTEA module repurposes standard attention with a relative-temporal-distance bias, and the TDW module repurposes event timesurfaces (originally designed for pattern recognition) as a motion prior for geometric warping of image features, combining these with existing backbones (Swin Transformer, SFHBlocks) in a new architectural arrangement.

## Why It Matters / Open Questions

The paper identifies and addresses a concrete gap in event-based blur decomposition—the absence of explicit feature-level temporal alignment—that prior methods handled only implicitly or through expensive per-time preprocessing. The EBD dataset (29 sequences, 25,608 frames with hardware-aligned events) provides the community with a real-event benchmark that was previously missing. A key open limitation is the synthetic-to-real domain gap: the model is trained on blur synthesized by frame averaging but evaluated on real events, and the authors acknowledge suboptimal transfer, pointing toward future work with beam-splitter hardware for paired real-blur data. The time-specialized alignment principle could generalize to other event-image fusion tasks (interpolation, deblurring) where temporal alignment is similarly critical.

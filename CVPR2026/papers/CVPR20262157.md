## Problem

Existing CAD code generation methods rely on manually annotated text or image inputs, which are costly and impractical for industrial workflows where 2D engineering drawings are the natural source of design intent. Additionally, standard RLVR training is on-policy and confined to refining pre-existing reasoning paths, limiting the model's ability to discover novel strategies when initial reasoning is biased or incorrect.
![Teaser figure](../imgs/CVPR20262157/cropped_page0_idx0.webp)

## Input / Output

The method takes 2D orthographic projection images (three-view drawings) with precise dimension annotations as input, rendered from DXF files generated via FreeCAD. The output is a structured sequence consisting of a Chain-of-Thought reasoning block followed by executable CadQuery Python code. The generated code must satisfy four verifiable constraints: correct output format, syntactic executability in a Python environment, geometric accuracy (IoU with ground-truth 3D model), and coordinate-system consistency (origin and axis alignment).

## Method

CME-CAD introduces a two-stage training paradigm over a Qwen3-VL-4B-Instruct base model. In Multi-Expert Fine-Tuning (MEFT), three heterogeneous experts (Qwen3-VL-Plus, GPT-5-Mini, Doubao-Seed-1.6-Vision) each generate distinct CoT reasoning paths via a reverse-task formulation (given both drawing and code, reason the derivation), and the base model is SFT'd on all expert-specific (prompt, CoT, answer) tuples. In Multi-Expert Reinforcement Learning (MERL), the model performs GRPO with expert-internal advantage estimation (group-relative rewards within each expert's G rollouts, with non-negative truncation to preserve exploration), a KL-divergence collaborative loss that forces the worst-performing expert's policy toward the best expert's, and a hard-negative sample buffering mechanism that SFTs on samples where all experts fail. The composite reward gates on format and executability before combining IoU and work-plane consistency terms.

## Results

On the CADExpert benchmark, CME-CAD achieves 80.71% IoU, 1.00 Mean Chamfer Distance, 0.11 Median Chamfer Distance, and 98.25% code executability. This represents an 8.87-point IoU improvement over the strongest fine-tuned baseline (CAD-RL at 71.84% IoU) and a 43.67-point improvement over the best pretrained VLM (Qwen3-VL at 37.04% IoU). The method also achieves the highest executability rate (98.25%), meaning nearly all generated CADQuery code runs without errors.

## Baselines & Comparisons

CME-CAD outperforms all nine pretrained VLM baselines by a wide margin on every metric; the strongest pretrained model (Qwen3-VL) reaches only 37.04% IoU and 54.79% executability, less than half the IoU of CME-CAD. Against the closest fine-tuned competitor, CAD-RL (a single-expert RLVR approach), CME-CAD gains 8.87 points in IoU (80.71% vs. 71.84%), reduces Mean Chamfer Distance from 1.38 to 1.00, cuts Median Chamfer Distance from 0.36 to 0.11, and improves executability from 97.32% to 98.25%. The ablation in Table 2 further shows that multi-expert SFT alone (e.g., MoE-SFT Expert3 at 64.45% IoU) already surpasses single-expert SFT+GRPO (E3-SFT-GRPO at 52.38% IoU), confirming that the collaborative multi-expert data is more effective than additional RL on a single reasoning path. The full CME-CAD pipeline (MEFT + MERL) then pushes Expert3 to 80.71% IoU, a 16.26-point gain over multi-expert SFT alone, demonstrating the compounding benefit of the reinforcement learning stage.

## Relation to Prior Work

This paper extends the CAD code generation line (CAD-MLLM, GenCAD, CAD-Coder, CAD-RL) by shifting the input modality from text descriptions or freehand sketches to orthographic projections with precise dimension annotations, aligning the task with actual industrial design workflows. Methodologically, it builds on GRPO (DeepSeekMath) for the RL stage but departs from standard RLVR by introducing a heterogeneous multi-expert collaborative framework where multiple VLMs with distinct system prompts generate diverse reasoning paths and learn from each other via KL-divergence-based knowledge transfer. The Hard Negative Sample Buffering mechanism addresses reward sparsity in complex code generation, a problem not explicitly tackled in prior CAD-RL work.

## Why It Matters / Open Questions

The CADExpert dataset (17,299 instances with orthographic projections, CoT reasoning, executable CadQuery code, and rendered 3D models) fills a critical gap in open-source, industrial-grade CAD benchmarks, and the orthographic-projection input formulation makes the task directly applicable to real engineering workflows. The finding that multi-expert SFT alone (64.45% IoU) outperforms single-expert SFT+GRPO (53.42% IoU) suggests reasoning-path diversity may be more valuable than RL refinement within a single style, a principle potentially transferable to other structured code generation tasks. Open questions include whether the multi-expert paradigm scales to more complex multi-body assemblies, whether the approach generalizes beyond CadQuery to other CAD APIs, and how performance holds on truly novel industrial designs outside the dataset's operation vocabulary.

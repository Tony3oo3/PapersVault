## Problem

Existing knowledge distillation methods for computational pathology transfer genomic supervision into histology models via batch-local feature matching, which is inherently unstable due to limited within-batch comparisons and the asymmetric geometry between genomics and histopathology. This fragility is amplified in the MIL setting where noisy background regions in gigapixel images overwhelm the distillation signal, leading to brittle generalization under domain shift.

## Input / Output

During training, the method consumes both a whole slide image (processed into patch embeddings via a frozen UNI v2 backbone and organized as a k-nearest-neighbor spatial graph) and a paired omics vector. At inference, only the WSI is required: the accumulated momentum memory guides patch-level attention, and the final output is a binary slide-level class label (e.g., HER2+, PR+, or ODX high-risk). The memory is initialized via K-means on 10,000 randomly sampled patches before training begins.

## Method

MoMKD replaces direct batch-local cross-modal alignment with a class-conditioned momentum memory bank (C+ and C−) that accumulates genomics-histopathology statistics across the entire training trajectory. A graph-based WSI encoder (two-layer GATv2 on a spatial patch graph) and a lightweight MLP omics encoder both project into an L2-normalized shared space, where a soft angle-based loss (LogSumExp over memory components with temperature τ_agg=5) aligns each modality to its corresponding memory set while repelling from the other. A critical gradient-decoupling strategy prevents direct gradient flow between the WSI and omics branches and shields the memory from the classification head, so the memory evolves only through alignment, orthogonality regularization, and a self-supervised omics reconstruction loss—producing a slow, momentum-like update. At inference, patch-level attention is computed as the differential cosine affinity to positive versus negative memory components, yielding a memory-guided weighted aggregation that produces the slide-level prediction without any genomic input.

## Results

On the TCGA-BRCA benchmark, MoMKD achieves AUC of 79.6% (HER2), 87.9% (PR), and 82.3% (Oncotype DX), consistently outperforming all WSI-only MIL and multimodal KD baselines across all three tasks. On the independent in-house ODX validation set, MoMKD reaches 79.4% AUC, 87.1% accuracy, and 68.0% F1, surpassing the best multimodal competitor (TDC) by 3.8% in AUC and 7.1% in F1. The method also exhibits notably lower variance (e.g., ±0.7 on HER2 AUC vs. ±5.0 for WIKG), indicating more stable training.

## Baselines & Comparisons

MoMKD outperforms all five WSI-only MIL baselines (ABMIL, DSMIL, TransMIL, DTFDMIL, WIKG) and all three multimodal KD baselines (TDC, MKD, G-HANet) on every task and metric. Against the strongest WSI-only method WIKG, MoMKD gains +7.0% AUC on HER2, +3.5% on PR, and +5.1% on ODX. Against the best multimodal KD method MKD, MoMKD still improves AUC by +2.5% (HER2), +2.8% (PR), and +2.2% (ODX). On the external in-house ODX set, MoMKD leads TDC (the top multimodal competitor) by 3.8% AUC and 7.1% F1, while also surpassing DTFDMIL by 3.2% AUC. Notably, MoMKD achieves the lowest standard deviation across all tasks (e.g., ±0.7 on HER2 AUC vs. ±5.0 for WIKG), suggesting the momentum memory stabilizes training and reduces sensitivity to fold-specific variance.

## Relation to Prior Work

MoMKD adapts the momentum-updated memory bank concept from contrastive representation learning (MoCo) to the cross-modal knowledge distillation problem in computational pathology, where prior methods (TDC, MKD, G-HANet) rely on fragile batch-local feature alignment between genomics and histopathology. It departs from these approaches by introducing an indirect distillation mechanism: rather than forcing heterogeneous modalities to match each other directly, both are aligned to a shared, slowly-evolving class-conditioned memory that accumulates cross-modal statistics over the full training trajectory. The WSI encoder builds on graph-based MIL (GATv2 over spatial patch graphs), while the omics branch uses a lightweight MLP with a self-supervised reconstruction constraint to ensure biological fidelity before anchoring the memory.

## Why It Matters / Open Questions

The momentum memory framework offers a principled solution to the modality-gap problem in cross-modal KD, with the gradient-decoupling strategy ensuring that genomic signals do not dominate histology feature learning—a practical concern for clinical deployment where only histology is available at inference. The domain-shift experiment (fixed memory collapsing from 81.1% to 73.5% AUC on external data while momentum memory holds at 79.4%) provides concrete evidence that dynamic memory updates are essential for generalization. However, validation is limited to breast cancer biomarkers (HER2, PR, ODX) on a single public dataset plus one in-house cohort; open questions include whether the approach transfers to other cancer types, whether memory size and momentum hyperparameters require task-specific tuning, and whether the framework extends to regression or survival tasks where class-conditional memory structure may be less natural.

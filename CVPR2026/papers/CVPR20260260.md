## Problem

Vision Language Models exhibit a fundamental semantic-to-geometric gap in spatial reasoning: their lossy semantic space cannot ground high-fidelity geometry, leading to flawed spatial imagination and unconstrained planning. Existing training-based methods suffer from an 'oracle paradox' (learning flawed spatial logic from imperfect oracles), while tool-integrated methods constrain final computation but leave the VLM's planning process unconstrained, producing geometrically flawed plans before any tool is even called.
![Teaser figure](../imgs/CVPR20260260/cropped_page1_idx0.webp)

## Input / Output

The agent receives a natural-language spatial reasoning query (e.g., 'Is the chair to the west of the toaster?') along with one or more RGB images of the scene. It first produces a structured formal task constraint C_task comprising a reference frame constraint (anchored to an object, camera, or direction-based 3D Cartesian coordinate system following the OpenCV convention) and an objective constraint, then iteratively invokes perception tools (VGGT 3D reconstruction, Grounding DINO detection, SAM 2 segmentation) and a sandboxed Python code generator to produce a deterministic geometric answer.

## Method

GCA is a training-free agentic paradigm that decouples spatial reasoning into two stages governed by a formal task constraint C_task. In the F_formalize stage, the VLM acts as a semantic analyst, translating the ambiguous query into C_task = (C_R, C_O), where C_R defines a non-negotiable 3D reference frame (object-based, camera-based, or direction-based) and C_O specifies the measurement objective. In the F_compute stage, the VLM shifts to a constrained task solver operating in a ReAct-style loop, generating tool calls strictly within the deterministic bounds of C_task to acquire geometric data and execute final computations. A knowledge-augmented code generation mechanism (analogous to static RAG) injects a pre-verified library of geometric formulas into the code generator's context based on bound variable types, preventing hallucinated formulas. The entire pipeline is built on Ray for concurrent tool execution and LangGraph for state management, with no model fine-tuning required.

## Results

GCA achieves a state-of-the-art average accuracy of 65.1% across five spatial reasoning benchmarks (MMSI-Bench, MindCube-tiny, OmniSpatial, SP-Bench, CV-Bench), surpassing the strongest foundation VLM baseline (Gemini-2.5-Pro, 58.5%) by ~12% relative improvement. On the most challenging benchmark, MMSI-Bench, GCA reaches 47.6% overall accuracy versus 36.9% for Gemini-2.5-Pro (a 28% relative gain), while most other methods perform near the 25% random-guess threshold for its 4-choice questions. The paradigm also yields an average ~37% relative improvement when applied to different foundation VLMs (Qwen3-VL-Thinking, GPT-4o, Gemini-2.5-Pro, GLM-4.5V), confirming its training-free generalizability.

## Baselines & Comparisons

GCA outperforms all 13 baselines across every benchmark. Against the strongest foundation VLMs, GCA (65.1% avg) beats Gemini-2.5-Pro and GPT-4o (both 58.5%) by ~6.6 points, with the largest gap on MMSI-Bench (47.6% vs. 36.9%). Among training-based spatial VLMs, the best performer is SpatialMLM (51.2% avg), which GCA surpasses by 13.9 points; notably, SpatialLadder (45.7%) shows a training-data bias, scoring 70.3% on SP-Bench (its in-domain source) but only 28.3% on MindCube-tiny, whereas GCA maintains consistent performance across all benchmarks. The sole tool-integrated agent, TIGeR (47.3%), is outperformed by GCA by 17.8 points on average, with GCA particularly dominant on multi-view benchmarks (MMSI-Bench: 47.6% vs. 27.8%) where TIGeR's single-image training limitation is exposed. GCA's advantage is most pronounced on complex multi-step reasoning tasks, where unconstrained VLMs and training-based methods struggle near random-guess levels.

## Relation to Prior Work

This paper departs from both training-based spatial VLMs (which suffer from an 'oracle paradox' of learning flawed spatial logic from imperfect data generators) and tool-integrated agents like TIGeR (which constrain final computation but leave the VLM's planning process unconstrained in its lossy semantic space). Conceptually, it extends the constraint-guided reasoning / neuro-symbolic line (LogicLM, LLM+P, ReKep) by proposing a new formalism—C_task with a reference frame constraint and objective constraint—specifically designed for the continuous, perspective-dependent geometry of spatial queries, where PDDL-style discrete state formalisms are insufficient. The ReAct framework provides the execution backbone, but the key architectural departure is replacing the single unconstrained policy with a two-stage decoupling: a semantic analyst stage that formalizes the task, followed by a constrained solver stage.

## Why It Matters / Open Questions

The training-free, constraint-based paradigm offers a verifiable and interpretable pathway to spatial reasoning that avoids the data-quality pitfalls of training-based methods and the planning failures of unconstrained tool agents. Its generalizability across four major VLMs (Qwen3-VL, GPT-4o, Gemini-2.5-Pro, GLM-4.5V) with ~37% average relative improvement suggests the formal constraint is a portable architectural component rather than a model-specific trick. Key limitations include computational cost from iterative tool calls, image-only scope (no temporal/video reasoning), and a 30% error rate in the formalization stage that caps overall accuracy. Open questions include whether the structured C_task outputs can serve as supervision for more efficient end-to-end spatial VLMs, and whether the framework extends to dynamic/temporal spatial reasoning.

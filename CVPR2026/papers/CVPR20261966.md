## Problem

Existing scene graph generation methods assume clean input images, but real-world deployments encounter diverse corruptions (noise, blur, weather, digital distortions) that cause feature domain shifts, degrading both object features and the structural relationships critical for predicate prediction. Current robustness strategies (data augmentation, adversarial training, denoising) are object-centric and computationally expensive, failing to specifically protect the positional and semantic relationships among objects that SGG requires.

## Input / Output

The method takes an RGB image (clean or corrupted with any of 20 corruption types at 5 severity levels) and produces a scene graph of visual triplets ⟨subject, predicate, object⟩. It is plug-and-play: the NRM module operates on the backbone feature map (C×H×W) plus detected bounding boxes, while the LEE module replaces the standard object/predicate encoder, accepting visual features and bounding box coordinates. The framework integrates into both one-stage (e.g., RelTR, EGTR) and two-stage (e.g., MOTIFS, VCTree, DPL) SGG pipelines without architectural changes to the proposal network or decoder.

## Method

Robo-SGG comprises two modules. The Layout-Oriented Normalization and Restitution Module (NRM) first applies Instance Normalization to remove corruption-specific per-channel mean and variance from the backbone feature map, then uses a Layout-aware Attention mechanism that computes Gaussian-distance-based attention weights from each spatial location to all object centroids, producing a layout mask that selectively restores structural features from the residual (original minus normalized) map. The Layout-Embedded Encoder (LEE) replaces standard concatenation of visual features and bounding box coordinate embeddings with a gated fusion: a sigmoid gate computed from the visual feature adaptively weights how much of the coordinate embedding to retain, allowing the model to downweight unreliable spatial cues when detections are noisy under corruption. This gating is applied separately for objects (using their own visual features) and predicates (using visual features from the union region of the object pair). The entire module is trained end-to-end with standard cross-entropy SGG loss on clean images only, and evaluated on unseen corrupted images, requiring no corruption-specific training data or denoising pre-processing.

## Results

On the VG-C benchmark (20 corruption types, severity 5), integrating Robo-SGG into the state-of-the-art DPL model yields relative improvements of 6.3% (PredCls mR@50: 24.5→24.8), 8.3% (SGCls mR@50: 7.2→7.8), and 6.3% (SGDet mR@50: 4.8→5.1). For the classic VCTree baseline, gains are larger: +6.3% (PredCls), +11.1% (SGCls), and +8.3% (SGDet) in mR@50 under corruption. On GQA-C, VCTree+Robo-SGG improves PredCls mR@20 from 16.5 to 17.9 (+8.5%), and VTransE+Robo-SGG from 17.4 to 19.1 (+9.8%).

## Baselines & Comparisons

Robo-SGG consistently outperforms all baselines under corruption while maintaining or slightly improving clean performance. Against the robust SGG specialist HiKER [18], Robo-SGG achieves +3.7% (PredCls) and +5.7% (SGCls) mR@50, demonstrating that layout-oriented normalization surpasses knowledge-graph-based robustness. Against the SOTA DPL [68], gains are +1.1% (PredCls), +8.3% (SGCls), and +6.3% (SGDet), with the largest relative improvement on the hardest SGDet task. For the denoising baseline DDPG [28] on motion-blurred images, Robo-SGG achieves 46.7% SGCls mR@100 improvement versus DDPG's 13.3%, while adding only 2.3% inference overhead compared to DDPG's 2394.3%. On one-stage models, RelTR [62] improves from 3.4 to 3.7 SGDet mR@50 under corruption (+8.8%), and EGTR [49] from 5.6 to 5.9 (+5.4%). The method also generalizes beyond natural corruptions: under style transfer (StyleID) it gains +12.6% and under zero-shot distribution shift +17.8% over MOTIFS.

## Relation to Prior Work

This paper builds on the coordinate-embedding paradigm introduced by SHA [16], which concatenates bounding box embeddings with visual features for object and predicate encoding, and replaces that rigid concatenation with a learned gated fusion (LEE) that can downweight unreliable spatial cues under corruption. For feature-level robustness, it extends the Instance Normalization + restitution idea from SNR [70] (which uses channel attention) by substituting a layout-aware attention mechanism that explicitly leverages object bounding box centroids to recover structural features. Conceptually, it departs from both denoising-based approaches (e.g., DDPG [28]) and knowledge-graph-based robustness (HiKER [18]) by arguing that global layout structure is an inherently corruption-invariant signal that can be exploited directly within the SGG pipeline without external resources or heavy pre-processing.

## Why It Matters / Open Questions

The plug-and-play design with negligible overhead (NRM adds zero learnable parameters; LEE adds only 0.02 GB) makes Robo-SGG immediately applicable to any existing SGG pipeline, which is practically valuable for the autonomous driving and robotic navigation communities that rely on SGG. The striking comparison against diffusion-based denoising (46.7% vs. 13.3% improvement at 2.3% vs. 2394.3% inference cost) challenges the assumption that heavy image restoration is necessary before structured prediction. Limitations include more modest gains under blur corruptions (where structural cues are genuinely degraded), dependence on detector quality for layout inputs, and evaluation restricted to 2D SGG on VG/GQA; whether the layout-robustness principle transfers to 3D scene graphs, video SGG, or open-vocabulary settings remains open.

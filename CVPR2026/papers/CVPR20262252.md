## Problem

Automated detection of intraoperative bleeding in laparoscopic surgery requires simultaneously localizing bleeding regions (to quantify blood loss) and pinpointing bleeding points (to guide hemostasis), yet existing methods address only one of these tasks and lack temporal modeling for video sequences. Additionally, no public dataset provides joint region-and-point annotations for real surgical bleeding, leaving a benchmark gap for multi-task surgical bleeding detection.
![Teaser figure](../imgs/CVPR20262252/cropped_page0_idx0.webp)

## Input / Output

The method consumes 8 consecutive laparoscopic video frames (resized to 512×512 from native 1280×720) in an online, frame-by-frame manner, with a frozen PWC-Net computing inter-frame optical flow as an auxiliary input. It produces a pixel-level bleeding region segmentation mask, a single bleeding point coordinate (x, y), and a binary confidence score indicating point existence. The point localization uses a stricter PCK threshold range (2%–10%) than typical anatomical landmark tasks, reflecting the higher precision demanded in surgical hemostasis.

## Method

BlooDet is a dual-branch architecture built on SAM 2's image encoder and memory mechanism, with a mask branch and a point branch coupled via bidirectional guidance. The mask branch generates adaptive edge prompts using multi-scale Gabor wavelet Laplacian filters applied to spatial-temporal features, combined with point prompts from the point branch to sharpen bleeding boundary detection. The point branch embeds optical flow (computed on background regions via reversed mask maps) to estimate camera viewpoint offset, and fuses mask memory features from the mask branch to model temporal point motion and narrow the search space. Training uses an alternating optimization scheme that fixes one branch while updating the other, with Focal+Dice loss for regions and Smooth L1+BCE loss for points, initialized from SAM 2_base pretrained weights.

## Results

On the SurgBlood test set, BlooDet achieves 64.88% IoU and 78.70% Dice for bleeding region detection, and 18.62% PCK-2%, 55.85% PCK-5%, and 83.69% PCK-10% for bleeding point detection, outperforming all 13 baselines on both tasks. On the zero-shot HemoSet evaluation, BlooDet reaches 59.62% IoU and 74.70% Dice, again leading all competitors. The model uses 91.6M parameters, comparable to SAM2 (81.0M) and MemSAM (133.5M).

## Baselines & Comparisons

BlooDet outperforms all 13 baselines on both bleeding region and point detection tasks. For region detection, the closest competitor is SAM2 (50.93% IoU), which BlooDet surpasses by 13.95 points; MemSAM (52.84%) and STDDNet (47.49%) trail further behind. For point detection, SAM2 achieves the highest PCK-10% among baselines at 71.99%, while BlooDet reaches 83.69%—a 11.7-point margin. Among multi-task baselines, ConsisTNet (40.43% IoU, 68.15% PCK-10%) and PAINet (44.14% IoU, 48.43% PCK-10%) are the strongest but remain substantially below BlooDet. Notably, task-specific models (e.g., SAM2 for regions, D-CeLR for points) degrade in performance when forced into dual-task learning, whereas BlooDet's cross-branch guidance and alternating optimization preserve and even enhance both tasks simultaneously.

## Relation to Prior Work

BlooDet is built directly on SAM 2's image encoder, memory modeling, and decoder architecture, extending the surgical video segmentation line (MemSAM, Surgical SAM 2, ResurgSAM2) by adding a dedicated point-detection branch and a bidirectional cross-branch guidance mechanism. It departs from prior multi-task surgical frameworks (PAINet, PitSurgRT, ConsisTNet), which target anatomy identification in endoscopic pituitary surgery, by formulating a coupled bleeding-region-and-point objective with alternating optimization. The use of frozen PWC-Net optical flow masked by background regions to estimate camera displacement for point tracking is a novel repurposing of classical motion estimation within a prompt-based segmentation pipeline, and the Gabor wavelet Laplacian edge generator introduces a domain-specific prompt embedding strategy absent from prior SAM-based surgical methods.

## Why It Matters / Open Questions

The SurgBlood dataset is the first real-world laparoscopic bleeding benchmark with both pixel-level region masks and point coordinates, filling a clear gap that limited prior work to region-only or image-only settings. The joint task formulation addresses a genuine clinical need—quantifying blood loss while simultaneously localizing the bleeding source for hemostasis—that no prior dataset or method had tackled in a unified video framework. Limitations include the narrow surgical scope (cholecystectomy only, 95 clips), the very strict PCK thresholds (2–10%) that may not transfer to other anatomical contexts, and the absence of prospective clinical validation. Open questions include generalization to other laparoscopic procedures, real-time deployment on surgical workstations, and whether the bidirectional guidance strategy extends to other multi-task surgical perception problems.

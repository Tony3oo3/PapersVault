## Problem

LLM agents in multi-turn interactions generate redundant thoughts for simple tool calls and accumulate excessive observation context, yet existing efficiency methods (thought compression, observation masking, summarization) treat the entire trajectory uniformly. The paper identifies that thought necessity and observation utility are turn-dependent—early planning thoughts and late-turn observations are critical, while intermediate ones are often redundant—and asks whether an agent can learn to adaptively omit only the redundant context without sacrificing task accuracy.
![Teaser figure](../imgs/ICML20263461/cropped_page0_idx1.webp)

## Input / Output

The agent receives a task question plus the full interaction history (prior thoughts, actions, and environment observations) at each turn. Its output is structured as: a thought block that may be an empty string (signaling omission), a tool-call action, and an optional observation omission set specifying which historical turn indices to drop from context. The final turn produces a natural-language answer. A key structural detail is that observation omission is expressed as an explicit strategy command (e.g., <omit_tool_response_N...>) emitted alongside the next action, rather than a post-hoc pruning step.

## Method

Agent-Omit is a two-stage training framework. Stage 1 (cold-start SFT) synthesizes single-turn and multi-turn omission trajectories via Monte Carlo rollouts that identify which turns are safely omittable, then fine-tunes the agent to produce empty thoughts and omission commands. Stage 2 (omit-aware agentic RL) uses GRPO with a dual sampling mechanism: full trajectories evaluate end-to-end task success and token savings, while partial trajectories (one per omission event) let the agent learn the omission decision conditioned on the pre-omission context, solving the 'context change' problem where the agent would otherwise never see the information it is deciding to drop. A tailored omission reward (ratio of saved tokens, zeroed if task fails) is combined with task reward via a reweighting factor μ=0.2. Theoretically, the paper proves the deviation in both effectiveness and efficiency between the learned policy and the optimal omission policy is upper-bounded by their KL-divergence, via a Semantic Lipschitz Continuity assumption and the Kantorovich-Rubinstein duality.

## Results

On five agent benchmarks (DeepSearch, WebShop, TextCraft, BabyAI, SciWorld), Agent-Omit-8B-RL achieves the highest Pass@1 accuracy while incurring the lowest average token cost among all seven efficient agent construction methods on the Qwen3-8B backbone. Specifically, it reaches 23.57% on WebShop (8,764 tokens), 87.00% on TextCraft (7,328 tokens), 84.36% on BabyAI (6,643 tokens), and 18.45% on SciWorld (9,643 tokens), outperforming the base Qwen3-8B by 16.64, 32.00, 23.55, and 15.98 percentage points respectively. Against frontier LLMs, Agent-Omit-8B-RL matches or exceeds DeepSeek-R1-0528 on four of five benchmarks (e.g., 23.57% vs 19.37% on WebShop, 87% vs 83% on TextCraft) while using 22–52% fewer tokens.

## Baselines & Comparisons

Agent-Omit-8B-RL dominates all seven efficient agent construction methods on every benchmark in both accuracy and token cost. Among Thought Management methods, ToolLight is the strongest competitor (21.29% DeepSearch, 14.57% WebShop) but still trails Agent-Omit by 3.27 and 9.00 points respectively while using 30% more tokens on DeepSearch. Among Observation Management methods, DeepMiner (16.29% DeepSearch) and Observation-Mask (12.76%) both suffer significant accuracy drops from the base model, confirming that heuristic masking without model adaptation is insufficient. Among Thought&Observation Management methods, ReSum is the closest competitor (22.28% DeepSearch, 17.80% WebShop, 72% TextCraft, 77.09% BabyAI, 14.48% SciWorld) but Agent-Omit still leads by 2.28, 5.77, 15.00, 7.27, and 3.97 points respectively while using 24–30% fewer tokens. Against frontier LLMs (Table 2), Agent-Omit-8B-RL surpasses DeepSeek-R1-0528 on WebShop (23.57 vs 19.37), TextCraft (87 vs 83), BabyAI (84.36 vs 81.74), and SciWorld (18.45 vs 13.23) with 22–52% lower token cost, and is competitive on DeepSearch (26.56 vs 27.25 for DeepSeek-V3.2, 31.50 for o3). The RL stage is critical: Agent-Omit-8B-SFT alone achieves only 22.25% on DeepSearch and 14.43% on WebShop, while the RL variant improves to 26.56% and 23.57% respectively, demonstrating that adaptive omission policy learning is essential for the full effectiveness-efficiency gain.

## Relation to Prior Work

This paper extends the efficient LLM agent literature by departing from the uniform-compression paradigm (Thought Management, Observation Management, and summarization-based TOM methods) that treats all turns equally. It builds on agentic RL frameworks (GRPO, AgentGym-RL) but introduces a turn-adaptive omission formulation where the agent learns *which* specific turns to omit thought or observation, rather than applying a static heuristic or global compression. The dual sampling mechanism (full + partial trajectories) is a novel technical contribution addressing the 'context change' problem that makes omission policy unlearnable under standard single-trajectory RL.

## Why It Matters / Open Questions

The practical impact is significant: an 8B model trained with Agent-Omit matches or exceeds seven frontier LLM agents (including DeepSeek-R1-0528 and o3) on four of five benchmarks while consuming substantially fewer tokens, offering a viable path to deploying capable agents at lower inference cost. The quantitative turn-level analysis provides a principled justification for adaptive omission that prior heuristic methods lacked. Key limitations include the high RL training cost (32–36 hours per environment on 8 A100s) and the reliance on synthetic cold-start data, with open questions about scaling the omission paradigm to pre-training and larger models.

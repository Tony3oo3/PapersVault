## Problem

Prior entity tracking benchmarks evaluate models only in text, leaving it unclear whether vision-language models can maintain coherent entity representations when state updates arrive as images rather than text. This paper asks whether the performance gap between text and image-based tracking stems from perceptual failures or from higher-level visual reasoning deficits, and whether reinforcement learning can close the gap.
![Teaser figure](../imgs/ICML20260767/cropped_page1_idx0.webp)

## Input / Output

In Chess and Shell Game, the model receives a text-encoded initial state (FEN string or shell position) and a sequence of actions rendered either as UCI text or as purpose-built board/shell images, then outputs the final state as text (FEN or a single digit). In Minecraft, the modality variation shifts to the state itself: the model receives a first-person screenshot or structured text description plus text actions, and selects the correct next state from four candidates. Image actions were designed through visual prompt engineering (arrows, highlighted squares) to maximize perceptual accuracy, isolating reasoning from perception.

## Method

MET-Bench constructs parallel text and image versions of entity tracking across three domains (Chess, Shell Game, Minecraft) with controlled sequence lengths, enabling direct comparison of modality-specific performance. The evaluation protocol spans zero-shot, few-shot, chain-of-thought, and reasoning settings across 20+ frontier VLMs, and includes a cascaded inference ablation where the model first transcribes image actions to text before tracking, thereby separating perception errors from visual-reasoning errors. To improve open-source models, the authors apply GRPO (Group Relative Policy Optimization) with verifiable reward functions (per-square FEN accuracy for Chess, binary ball-position match for Shell Game) to train Gemma 3 4B IT, finding large in-modality gains (e.g., 37.6%→92.2% on text Shell Game) but negligible cross-modal transfer, indicating that current VLMs learn modality-specific rather than unified tracking representations.

## Results

On MET-Bench Chess (10 actions, per-square accuracy), the text-to-image gap is stark: Claude 3.7 Sonnet achieves 96.1%±0.2% with text actions but drops to 70.2%±0.5% with image actions in zero-shot; with chain-of-thought, the gap narrows to 99.5% vs 96.2%. In Shell Game, zero-shot performance is near random (~33%) for all models in both modalities, but chain-of-thought lifts Claude 3.7 Sonnet to 100.0% (text) vs 77.4% (image), and reasoning models like Gemini 2.5 Pro reach 100% in both. In Minecraft state prediction, Claude Sonnet 4.6 scores 88.4%±2.8% with text states but only 41.8%±4.3% with image states, and GRPO training on Gemma 3 4B IT improves Shell Game text accuracy from 37.6% to 92.2% without transferring to the image modality (27.4%).

## Baselines & Comparisons

Across all 14 evaluated models, text-based entity tracking consistently outperforms image-based tracking, with the gap ranging from ~5% (Claude 4.5 Opus, GPT-5.2 in reasoning) to over 40% (Llama-4 Maverick, MiniMax-VL-01 in zero-shot). Claude 3.7 Sonnet is the strongest non-reasoning model in text (96.1% zero-shot, 99.5% CoT) but still drops to 70.2% on image zero-shot; its CoT image performance (96.2%) nearly closes the gap. Among reasoning models, Claude 4.5 Opus and GPT-5.2 achieve near-parity between modalities (99.9%/99.5% and 98.0%/99.3% respectively), while o3 shows a dramatic image failure (45.5% vs 99.9% text). In Shell Game, the gap is even more extreme: zero-shot is near random for all models, but CoT lifts Claude 3.7 Sonnet to 100% text vs 77.4% image, and only Gemini 2.5 Pro and Claude 4.5 Opus reach 100% in both modalities under reasoning. GRPO training on Gemma 3 4B IT yields large in-modality gains (Shell Game text: 37.6%→92.2%; image: 32.8%→90.4%) but fails to transfer cross-modality, confirming that current VLMs learn modality-specific rather than unified tracking representations.

## Relation to Prior Work

This paper extends the well-studied text-based entity tracking literature (Chess via Toshniwal et al., Shell Game-like tasks via Kim & Schuster, procedural text via Tandon et al.) into the multimodal setting, where state updates arrive as both text and rendered images. It departs from prior multimodal procedure understanding and world-modeling benchmarks by requiring sequential, multi-step state tracking with parallel text/image action encodings and controlled difficulty scaling. The GRPO-based RL training builds on recent policy-gradient methods for verifiable-reward reasoning tasks, applied here to open-source VLMs for the first time in a multimodal entity-tracking context.

## Why It Matters / Open Questions

The cascaded-inference ablation isolates the bottleneck as visual sequential reasoning rather than perception, a finding with direct implications for how VLM architectures should be designed or trained for world-modeling tasks (robotics, video QA, computer-control agents). The lack of cross-modal transfer from RL training suggests that current VLMs learn modality-specific tracking representations rather than unified ones, pointing toward a need for new inductive biases or cross-modal alignment objectives. Open questions include whether mechanistic interpretability can reveal why visual sequential reasoning fails, whether explicit memory or new architectures can close the text-image gap, and whether the Minecraft-style naturalistic setting generalizes to real-world embodied tracking.

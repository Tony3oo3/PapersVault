## Problem

LLM-based embodied agents struggle with long-horizon planning due to context drift (losing track of high-level goals as interaction history grows) and hallucinated state transitions that violate environment constraints. Existing tree-based decomposition frameworks like ReCAP enforce artificial serialization of concurrent sub-tasks, blocking parallel actions and propagating errors downward. The paper addresses the need for a structured memory architecture that captures both spatial topology and temporal dynamics while enabling retrieval of relevant past execution traces to ground future decisions.

## Input / Output

At each step, the LLM receives a structured prompt containing: the current scene graph (parsed from raw text observation), the set of valid actions, the task goal, 1-step bounded lookahead projections (grounded post-conditions from a PDDL-derived transition function, or empty under partial observability as in ALFWorld), and a retrieved sub-trajectory from the experience memory bank if a structurally similar past state exists within distance threshold τ=0.1. The output is a formatted response with four fields: Reasoning (step-by-step justification), Action (exact string from the valid action list), Summary (≤150-word environment description), and Current Progress (recipe stack state after the action). The agent operates under a Pass@1 protocol with a 3× horizon step cap.

## Method

GiG maintains a two-tier graph memory: an inner scene graph (SG_t) encoding spatial entity relationships at each step, and an outer state-transition graph (OG) whose nodes are GNN-encoded scene graph embeddings connected by action edges. A 2-layer GAT (4→1 attention heads, 64-dim output, dropout 0.6) is trained with a composite loss of triplet loss (anchor-positive pairs from temporally adjacent states in the same trajectory, negatives from disjoint trajectories, margin γ=1.0) plus a uniformity regularization term (λ=0.5) to prevent representational collapse. Three modules operate on this structure: (1) Bounded Lookahead computes 1-step state projections P(s_t) over the valid action space using a known transition function, converting the LLM from imaginative prediction to discriminative selection over grounded outcomes; (2) Loop Detection flags when the current embedding revisits a prior state in the session graph, injecting a warning into the prompt; (3) Experience Retrieval uses Faiss vector search to find the closest past trajectory node within τ=0.1 and appends the subsequent action sequence as a one-shot in-context example. The full GiG+Exp pipeline achieves 97% Pass@1 on Robotouille Synchronous with Qwen3-235B, consuming roughly 30% of the context tokens required by ReCAP.

## Results

On Robotouille Synchronous, GiG achieves 93% Pass@1 with Qwen3-235B, outperforming the best baseline (ReAct at 74%) by 19 points; with experience memory (GiG+Exp), it reaches 97%. On Robotouille Asynchronous, GiG achieves 72% Pass@1 (Qwen3-235B), a 37-point improvement over the best baseline (ReCAP at 35%), and GiG+Exp reaches 82%. On ALFWorld, GiG achieves 97% Pass@1 with both Qwen3-235B and DeepSeek-R1, surpassing the best baseline (ExpeL at 91%) by 6 points. GiG also consumes roughly 30% of the context tokens required by ReCAP and 20% of ReAct per step.

## Baselines & Comparisons

GiG consistently outperforms ReCAP (NeurIPS 2025) across all three benchmarks: by 19–22 points on Robotouille Synchronous (93 vs. 71 with Qwen3), by 32–37 points on Robotouille Asynchronous (72 vs. 35 with Qwen3), and by 6–15 points on ALFWorld (97 vs. 89 with Qwen3). Against ReAct (ICLR 2023), GiG wins on Robotouille Synchronous (93 vs. 74 with Qwen3) and Asynchronous (72 vs. 31 with Qwen3), ties on Gemini-2.5-Flash for Synchronous (92 vs. 92), and achieves 97% vs. 61% on ALFWorld (Qwen3). GiG substantially outperforms CoT (NeurIPS 2022) on all benchmarks, with the gap most dramatic on Asynchronous (72% vs. 0% with Qwen3) where environmental feedback is essential. On ALFWorld, GiG also surpasses ExpeL (AAAI 2024) by 6 points with Qwen3 (97 vs. 91) and 22 points with DeepSeek-R1 (97 vs. 75), demonstrating that dynamic graph-based state aggregation handles partial observability and randomized layouts more effectively than static text-based experience retrieval.

## Relation to Prior Work

GiG departs from the tree-based planning paradigm established by ReCAP, which enforces serialization of concurrent sub-tasks through a hierarchical context tree, by replacing it with a two-tier graph structure (scene graph nested within a state-transition graph) that natively supports interleaved, non-blocking sub-goal execution. The retrieval mechanism draws on GraphRAG principles (PoG, HiRAG) but repurposes them for embodied planning: rather than retrieving semantically coherent fact subgraphs, GiG retrieves structurally similar execution traces via GNN-encoded scene graph embeddings, enabling compositional transfer of action sequences across tasks. The bounded lookahead module is positioned as a dynamics verifier grounded in PDDL transition logic, distinguishing it from the implicit future-state reasoning in ReAct or the recursive backtracking in ReCAP. The experience memory bank extends ExpeL's text-based insight distillation into a structured, graph-indexed episodic memory that supports iterative, state-conditioned retrieval rather than static example selection.

## Why It Matters / Open Questions

The graph-in-graph memory addresses a concrete failure mode in long-horizon LLM planning—context drift and the 'blocked sibling' constraint of tree decomposition—with measurable gains (up to 37% on asynchronous tasks) and substantially lower token consumption (~30% of ReCAP). The finding that experience retrieval serves as a model-agnostic plug-in, recovering +15% Pass@1 for smaller models without fine-tuning, suggests a practical path to deploying capable planning on resource-constrained hardware. However, several open questions remain: zero-shot out-of-domain transfer is untested, LLM inference latency remains a bottleneck for real-time physical deployment, and the framework is scoped to symbolic planning without integration into continuous control or safety-critical verification. The reliance on a deterministic parser and known transition dynamics (PDDL) limits applicability to partially observable or stochastic environments, as acknowledged in the ALFWorld evaluation where the lookahead module is disabled.

## Problem

Existing multi-state linear attention methods (e.g., Log-Linear Attention) rely on fixed block sizes or rule-based merging schedules to partition token histories into summary states, implicitly assuming uniform information density. This content-agnostic design irreversibly absorbs semantically critical tokens into coarse summaries at pre-defined boundaries, causing error accumulation that degrades performance as context length grows. The paper asks how to construct memory states adaptively based on token-level information variation while keeping the total number of states bounded for predictable inference cost.

## Input / Output

DLA consumes a standard token sequence processed through query, key, and value projections (with a feature map φ applied to keys). At each decoding step, the output is a weighted sum over at most K=30 chronologically ordered memory states, where per-state weights λ_{t,i} are produced by a learned linear layer over the current query representation. The state cache is fixed-size and temporally ordered, so inference cost is O(K) per step regardless of sequence length, unlike the O(log T) cost of Log-Linear Attention.

## Method

DLA introduces two coupled mechanisms. First, Information-Aware Dynamic State Merging computes a State Information Score I_t = ‖s_t − S_{t−1}‖_F / (‖S_{t−1}‖_F + ε) for each incoming token (after RMSNorm), and initiates a new memory state only when I_t ≥ τ, otherwise accumulating the token into the current state; during pre-training a soft gating g_t = σ(I_t) makes the merge decision differentiable, while inference uses hard segmentation. Second, Capacity-Bounded Memory Modeling maintains a fixed-size cache of K states in chronological order; when the cache is full, the adjacent pair with the lowest information density (ΣI / n_tokens) is merged, preserving temporal order while minimizing information loss. A theoretical analysis (Theorem 3.1) proves that fixed blocking policies incur a strictly larger summarization deviation bound than adaptive policies on non-stationary sequences, formalizing why content-aware merging is necessary. DLA is pre-trained from scratch on 50B tokens with Mamba-2-780M and Gated DeltaNet-1.3B backbones, using the same training recipe as Log-Linear Attention for fair comparison.

## Results

On zero-shot commonsense reasoning (8 benchmarks), DLA applied to Mamba-2-780M achieves an average accuracy of 34.8%, surpassing the full-attention Transformer (32.9%), vanilla Mamba-2 (31.8%), and Log-Linear Attention (31.0%). On Gated DeltaNet-1.3B, DLA reaches 34.8% average, outperforming Log-Linear (32.6%) by up to 22% relative gain on LAMBADA. On RULER-4K long-context retrieval, DLA achieves 100% on S-NIAH-1 for Mamba-2 (vs. 88.7% for Log-Linear) and up to 250% relative improvement on S-NIAH-3. On in-context retrieval, DLA delivers up to 80% relative improvement (SWDE) and 44–42% average gains over the best baseline for Mamba-2 and Gated DeltaNet respectively.

## Baselines & Comparisons

DLA is compared against four baselines. Against vanilla Mamba-2 (Dao & Gu, ICML 2024), DLA improves average commonsense accuracy from 31.8% to 34.8% and RULER-4K from 28.3% to 57.8%, showing that multi-state memory with dynamic merging substantially recovers the representational capacity lost by single-state compression. Against Log-Linear Attention (Guo et al., 2025), the primary multi-state competitor, DLA wins on every benchmark: up to 52% relative gain on LAMBADA (Mamba-2), 250% on S-NIAH-3 (RULER), and 80% on SWDE (in-context retrieval), while also achieving higher throughput and lower memory. Against vanilla Gated DeltaNet (Yang et al., ICLR 2025), DLA lifts average accuracy from 32.8% to 34.8% and RULER from 46.8% to 63.1%. Against D2O (Wan et al., ICLR 2025), an efficient long-context inference method evaluated on Transformer-770M in the appendix, DLA achieves 57.8% on RULER-4K versus D2O's 15.1%, and leads on all eight commonsense benchmarks as well.

## Relation to Prior Work

DLA extends the multi-state linear attention paradigm introduced by Log-Linear Attention (Guo et al., 2025), which organizes history into a logarithmic number of hierarchical states via Fenwick-tree decomposition with fixed temporal boundaries. The key departure is replacing these content-agnostic, schedule-driven merge decisions with an information-aware criterion (State Information Score) that adapts state granularity to token-level representation drift, supported by a theoretical bound (Theorem 3.1) showing fixed blocking is strictly sub-optimal on non-stationary sequences. DLA is instantiated on two existing linear-attention backbones—Mamba-2 and Gated DeltaNet—rather than proposing a new backbone, and adds a capacity-bounded eviction mechanism to keep inference cost predictable, a practical concern that prior multi-state methods leave unaddressed.

## Why It Matters / Open Questions

The result that a linear-attention variant (Mamba-2 + DLA) matches or exceeds a full-attention Transformer of comparable size on commonsense reasoning is practically significant, suggesting that the accuracy gap between linear and full attention may be attributable to memory management rather than the attention formulation itself. However, all experiments are at academic scale (50B tokens, 16K context, ≤1.3B parameters), leaving open whether the dynamic merging advantage persists at 100K+ context lengths or at frontier model scale where the fixed 30-state budget may become a bottleneck. The soft-gating-to-hard-segmentation training strategy and the robustness to hyperparameters (k, τ) are encouraging for adoption, but the method's interaction with other efficiency techniques (speculative decoding, quantization) remains unexplored.

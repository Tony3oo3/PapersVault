## Problem

The computational mechanisms underlying human episodic temporal order memory remain unresolved because biological systems offer limited leverage for causal manipulation of internal representations. While LLMs have been linked to episodic memory at the functional level, it is unclear whether their temporal order judgments rely on an explicit temporal position code or on indirect semantic/causal inference over narrative structure. This paper asks whether long-context LLMs reproduce the human distance effect on a naturalistic temporal order task and, if so, which internal circuitry is causally responsible.

## Input / Output

The model receives a single 128k-token prompt in which the full source text (~93k tokens) serves as the encoding span, followed by a brief instruction and two verbatim 50-word segments labeled A and B in randomized order; the model outputs a binary judgment of which segment appeared earlier. For mechanistic analysis, the paper extracts per-token value vectors (encoding phase) and attention output vectors (retrieval phase) for every segment across all heads, averages them into segment-level representations, and derives per-head temporal readout directions and reinstatement scores. Causal interventions modify head outputs exclusively at the retrieval-phase token positions of the two queried segments, leaving the long encoding context untouched.

## Method

The core method localizes temporal information via PCA: for each attention head, the top principal component of segment-averaged value-cache vectors (encoding) and output vectors (retrieval) is fitted on a content-free 60k random-noun sequence, then evaluated for temporal alignment (Kendall's τ) on held-out documents. A Temporal Reinstatement Score (TRS) multiplies the encoding and retrieval τ values and penalizes sign flips, isolating heads that genuinely reinstate their own stored temporal code rather than inheriting it from the residual stream. Causal validation projects out (or scales by α) the identified PC1 direction in the top-TRS head's output during retrieval spans only, reducing accuracy by 10–15% to near chance and showing that amplification improves performance. The temporal code is confirmed to be independent of RoPE positional encoding (preserved and even strengthened when RoPE is disabled) and the single-head reinstatement signature replicates in Mistral-7B and Qwen2.5-7B as well as in a four-segment ordering variant.

## Results

On the SORT task (binary temporal order judgment over 50-word segments from a full novel), both Llama 3.1-8B-Instruct and Llama 3.1-70B-Instruct reproduce the human distance effect: accuracy increases with segment separation, reaching ≥70% for far-apart segments. Llama 3.1-8B-Instruct is statistically indistinguishable from humans (all p ≥ 0.289), while Llama 3.1-70B-Instruct significantly outperforms humans at 16k–24k word distances (p = 0.021, FDR-corrected). Causal ablation of the single time-reinstatement head's temporal direction (L8H11 in 8B, L14H21 in 70B) reduces accuracy by 10–15%, and amplifying that direction by 1.75× improves accuracy by up to 9%. Cross-model replication in Mistral-7B-v0.2 and Qwen2.5-7B confirms a single outlier reinstatement head (TRS = 0.53 and 0.40 respectively) whose removal degrades ordering accuracy.

## Baselines & Comparisons

The paper does not benchmark against competing LLMs or memory architectures; instead, it compares model behavior to a human reference and uses internal controls to isolate the causal mechanism. Against the human baseline (97 participants, 990 segment-pair judgments), Llama 3.1-8B-Instruct matches human accuracy across all distance bins (all p ≥ 0.289), while Llama 3.1-70B-Instruct significantly exceeds human performance at mid-range distances (16k–24k words, p = 0.021 FDR-corrected). Against the narrative-coherence baseline (sentence-block shuffling), both models retain their distance effect with no significant performance drop (8B: p ≥ 0.307; 70B: p ≥ 0.104), ruling out causal/narrative schemas as the primary driver. In the causal intervention experiments, the time-reinstatement head is the only head whose ablation significantly reduces accuracy (McNemar test, p < 0.001 after BH correction); ablating other heads' temporal directions either has no effect or, in the 70B model, actually improves performance (indicating interference). Random directions used as controls for the amplification experiment show no comparable accuracy gains, confirming the effect is specific to the identified temporal axis.

## Relation to Prior Work

This paper extends the growing line of work drawing parallels between transformer attention and episodic memory (Gershman et al., 2025; Ji-An et al., 2024; Park et al., 2025) by moving from functional analogies to mechanistic localization: identifying which specific attention head stores and reinstates temporal information, and demonstrating its causal necessity. It builds on the linear representation hypothesis (Park et al., 2024) and spectral seriation (Fogel et al., 2016) to justify PCA-based readout of temporal order, and departs from prior positional-encoding analyses by showing the temporal code is learned and independent of RoPE. Unlike prior in-context learning studies that use short synthetic sequences, this work operates on a full-length novel (~93k tokens) and introduces a matched human behavioral dataset for direct comparison.

## Why It Matters / Open Questions

The finding that a single attention head causally mediates temporal order memory over 90k+ tokens provides a concrete, testable mechanistic account that bridges cognitive science (temporal context reinstatement, time cells) and transformer interpretability, and the released ICMemory-Kit toolkit lowers the barrier for future long-context memory research. Key open questions include whether this localized mechanism extends to more cognitively complex tasks (event segmentation, causal reasoning), whether it persists in hybrid or non-attention architectures, and how sample-by-sample human-model agreement can be improved. The primary limitation is scope: two Llama model families and one binary order-judgment task, with cross-model validation (Mistral, Qwen) being preliminary and at shorter context lengths.

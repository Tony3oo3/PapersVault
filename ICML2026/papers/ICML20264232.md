## Problem

Standard LoRA applies a single static low-rank update shared across all samples, ignoring the latent interaction structure that often drives scientific labels. In microbiome diagnosis, disease signals depend on microbe-microbe cross-talk and community topology, yet existing pipelines either treat taxa as independent covariates or compute association networks only post hoc, blurring the distinction between predictive features and mechanistic interactions. No prior method jointly learns a probabilistic interaction graph and uses it as the conditioning signal for parameter-efficient LLM adaptation.

## Input / Output

For IBD diagnosis, the input is a microbiome abundance profile over 3,061 species-level taxa, reduced to the top 20 MaAsLin2-selected features and serialized into a natural-language prompt for a frozen Qwen3-8B backbone; the model outputs a single token ('yes' for UC, 'no' for CD) plus a sparse K×K interaction graph with Laplace-distributed edge weights. For Molweni, the input is multiparty dialogue text with a question, and the output is an extracted answer span in JSON format alongside the inferred discourse dependency graph. Uncertainty is obtained by Monte Carlo marginalization over S samples from the Laplace graph posterior, averaging the resulting input-conditioned LoRA predictions.

## Method

iLoRA is a two-branch framework where a frozen LLM performs prediction while a parallel graph-inference branch generates the input-specific LoRA A matrix via a hypernetwork. The graph branch first encodes K selected taxa with the frozen LLM, constructs pairwise edge features, and infers a Poisson interaction graph using a Gaussian variational proxy (with a closed-form rate-matching theorem ensuring differentiability while preserving Poisson semantics). An NPN-inspired transformation then maps Poisson edges to zero-mean Laplace-distributed weights, imposing sparsity through a learned per-edge scale parameter. A 2-layer GCN embeds the sampled sparse graph, and a hypernetwork MLP projects the pooled graph representation to generate the LoRA A matrix (B remains static), so each sample receives a structurally conditioned adapter. Training minimizes a joint ELBO combining cross-entropy prediction loss, Poisson-rate KL divergence, and Laplace-scale KL regularization, all optimized end-to-end with AdamW while the LLM backbone stays frozen.

## Results

On the multi-cohort IBD diagnosis task (UC vs. CD, n=152 test samples, 20 selected taxa), iLoRA achieves the best AUROC of 0.7990 and AUPRC of 0.7617, while also attaining the lowest Expected Calibration Error (ECE) of 0.0980 and the highest UC F1-score of 0.6557. On the Molweni span-extraction benchmark, iLoRA reaches F1 74.51 and EM 60.57, outperforming all baselines. The structural recovery analysis shows iLoRA reduces graph error from 50.0% (random) to 26.7% on Molweni and 27.3% on IBD, confirming that the inferred latent graphs align with human-annotated discourse dependencies and cohort-level microbiome associations.

## Baselines & Comparisons

iLoRA outperforms all baselines on every reported metric in both experimental settings. Against vanilla LoRA (MLE/MAP), iLoRA improves AUROC from 0.7617/0.7637 to 0.7990 and ECE from 0.2533/0.2082 to 0.0980 on IBD, and F1 from 72.83/72.66 to 74.51 on Molweni. Among Bayesian adaptation baselines, iLoRA surpasses BLOB (AUROC 0.7812, ECE 0.1570) and Deep Ensemble (AUROC 0.7574, ECE 0.1598) on IBD, and BLOB (F1 70.80) and ENS (F1 72.38) on Molweni. Laplace LoRA (LAP), evaluated only on IBD, trails iLoRA in both ranking (AUROC 0.7641 vs. 0.7990) and calibration (ECE 0.2031 vs. 0.0980). Against standard tabular models trained on the same 20 taxa, iLoRA achieves substantially higher AUROC (0.7990) than Random Forest (0.6151), XGBoost (0.5823), and MLP (0.5346), indicating the gains stem from the interaction-aware graph-conditioned adaptation rather than the feature set alone.

## Relation to Prior Work

iLoRA extends LoRA (Hu et al., 2022) by replacing its static, sample-agnostic low-rank update with an input-conditioned one: a latent interaction graph is inferred per sample and used via a hypernetwork to generate the LoRA A matrix. The Bayesian machinery draws on Natural-Parameter Networks (Wang et al., 2016) for the Poisson-to-Laplace edge transformation and on variational inference frameworks (Wang & Yeung, 2016; 2020) for the ELBO-based training objective. Conceptually, the paper departs from both static PEFT (where the adapter is shared across all inputs) and post-hoc graph analysis (where networks are computed after training), positioning itself as the first framework that jointly learns prediction and latent relational structure under a single Bayesian objective, while building on Bayesian LoRA variants like BLOB (Wang et al., 2024) and Laplace LoRA (Yang et al., 2024) as baselines rather than foundations.

## Why It Matters / Open Questions

The joint prediction-plus-structure learning paradigm is a clean conceptual contribution: if microbial interactions genuinely drive disease signal, conditioning the adapter on an inferred interaction graph should outperform a static update, and the paper provides evidence for this in both a controlled NLP setting (Molweni) and a multi-cohort biomedical setting (IBD). However, several open questions temper the impact: the method's sensitivity to the number of selected taxa K (performance degrades sharply at K=30, 40), the O(K²) graph branch limiting scalability to larger taxon sets, the per-cohort inconsistency (iLoRA underperforms all baselines on Khachatryan_2023), and the lack of causal interpretation for the inferred edges. Extending the graph-to-adaptation principle beyond binary microbiome classification to multi-omics or larger interaction networks remains a natural but non-trivial next step.

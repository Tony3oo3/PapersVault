## Problem

Existing defenses against Indirect Prompt Injection (IPI) in tool-calling LLM agents face an over-defense dilemma: always-on sanitization and verification modules achieve strong security but degrade benign utility and add significant latency in the dominant benign scenarios. The paper asks whether one can detect the specific causal signature of a successful injection at privileged decision points and intervene only then, thereby matching aggressive-defense security while preserving the low overhead of an undefended agent.

## Input / Output

The method consumes a structured agent context decomposed into the user request U, trusted system context H_t, and a set of untrusted spans S_t (each corresponding to one tool result per turn), together with the proposed privileged action Y_t. Attribution is computed by a small proxy model (e.g., Gemma-3-12B-IT) served via vLLM in a single batched forward pass over 2+|S_t| ablated contexts, with scores length-normalized by |Y_t| to yield a dimensionless margin. The output is a binary dominance-shift flag; when triggered, the system produces a sanitized context (flagged spans rewritten by a context-aware LLM) with all subsequent assistant CoT traces replaced by a redaction placeholder, then re-generates the action under the cleaned context.

## Method

CausalArmor operationalizes IPI as a measurable 'dominance shift' (causal inversion): at a privileged decision, a successful injection causes a specific untrusted span's leave-one-out attribution to far exceed the user request's, while the user grounding collapses toward zero. Detection uses batched LOO ablation on a small proxy model, comparing length-normalized attributions Δ̄_S against Δ̄_U with a tunable margin τ (τ=0 is pure causal inversion; larger τ approaches always-on sanitization). When the flagged set B_t(τ) is non-empty, a two-stage intervention fires: (i) context-aware selective sanitization of only the responsible spans, conditioned on the user request and tool definition, and (ii) retroactive CoT masking that replaces all post-injection assistant reasoning with a generic placeholder to prevent poisoned traces from re-anchoring the malicious action during re-generation. A theoretical analysis (Proposition 4.1) shows that under a benign-capability assumption (β>0) and an effective-sanitization assumption (γ>0), the probability of any malicious privileged action over an episode of length T is bounded by T·|Y_mal|·exp(−(β+γ)), providing an explicit margin-to-risk conversion.

## Results

On AgentDojo with Gemini-3-Pro, CausalArmor reduces Attack Success Rate to 0.0–0.11% across all three attack templates (vs. 5.06–8.85% for No Defense), while preserving Benign Utility at 86.60% (vs. 92.78% undefended) and Benign Latency at 1.22× (vs. 1.00× undefended). On DoomArena with an adaptive privileged attacker, CausalArmor achieves 3.65% ASR with 70.96% BU, compared to 88.87% ASR for No Defense and 5.57% ASR but only 55.13% BU for PiGuard. The margin parameter τ=0 (pure causal inversion test) already achieves near-zero ASR, and raising τ provides a controllable security–utility trade-off without the 5–7× latency overhead of always-on system defenses.

## Baselines & Comparisons

Against Repeat Prompt (Schulhoff, 2023), CausalArmor achieves near-zero ASR (0.0–0.11%) versus 2.85–6.11% for Repeat Prompt on Gemini-3-Pro, at the cost of a modest BU drop (86.60 vs. 92.78); Repeat Prompt preserves utility but remains under-defensive against adaptive phrasing. Against PiGuard (Li et al., 2025b), CausalArmor matches or slightly improves ASR (0.0–0.11% vs. 0.63–0.84%) while substantially outperforming on Benign Utility (86.60 vs. 64.95), since PiGuard's always-on classifier over-blocks benign tool outputs. Against DRIFT (Li et al., 2025a), CausalArmor achieves comparable ASR (0.0–0.11% vs. 1.65–2.24%) but with dramatically lower latency (1.22× vs. 5.82×) and higher BU (86.60 vs. 81.05), because DRIFT sanitizes every tool output at every step. Against MELON (Zhu et al., 2025), CausalArmor matches ASR (both near-zero) while improving BU by ~6 points (86.60 vs. 80.38) and halving latency (1.22× vs. 2.26×), since MELON's policy-divergence verifier requires an extra LLM call per privileged decision. On the harder DoomArena benchmark with an adaptive privileged attacker, CausalArmor (3.65% ASR, 70.96% BU) outperforms PiGuard (5.57% ASR, 55.13% BU) and Repeat Prompt (72.70% ASR, 65.04% BU), confirming that causal attribution-based detection generalizes to adaptive threats where surface-level filtering fails.

## Relation to Prior Work

CausalArmor repurposes leave-one-out (LOO) attribution—previously applied to hallucination detection and context-dependence analysis (Cohen-Wang et al., 2024; Liu et al., 2025)—as a detection signal for Indirect Prompt Injection, reframing IPI as a measurable 'dominance shift' where an untrusted span overtakes the user request in causal influence on a privileged action. It departs from the always-on sanitization paradigm of system-based defenses (DRIFT, MELON, CaMeL) by making the expensive sanitization step conditional on this attribution signature, and from classifier-based approaches (PiGuard, DeBERTa) by avoiding surface-level text matching in favor of counterfactual influence measurement. The proxy-model trick (offloading LOO to a smaller Gemma-3-12B via vLLM batching) is borrowed from Liu et al.'s cross-model transferability results, and the Retroactive CoT Masking module addresses a failure mode (poisoned reasoning traces re-triggering attacks) not explicitly handled by prior sanitization pipelines.

## Why It Matters / Open Questions

The paper resolves the over-defense dilemma that has limited practical deployment of IPI guardrails: by triggering expensive sanitization only when causal attribution indicates an untrusted span dominates the privileged decision, CausalArmor achieves near-zero ASR while preserving benign utility and latency close to the undefended baseline—a trade-off that always-on defenses (DRIFT, MELON) cannot match. Key limitations remain: span-local LOO does not provide worst-case guarantees against perfectly distributed multi-span attacks (the authors acknowledge Shapley-style group attribution as a future direction), the theoretical bound is conditional on sanitizer effectiveness (Assumption 2), and the proxy model itself becomes a white-box target. For practitioners deploying tool-calling agents in latency-sensitive settings, this selective-defense paradigm is likely to become a standard architectural pattern, and the dominance-shift framing offers an interpretable, evidence-based alternative to opaque classifier thresholds.

## Problem

Self-reflection in language agents often produces repetitive and inaccurate outputs, limiting iterative reasoning performance. While prompt-level modifications (DoT) and retrieval-based cross-sample memory (DoT-bank) have been proposed to increase reflective diversity, they are constrained by fixed instruction templates and embedding-similarity retrieval, respectively, which limits their capacity to capture compositional patterns and is prone to embedding collapse. The paper asks how to further expand reflective diversity through a fundamentally different mechanism to achieve stronger reasoning.
![Teaser figure](../imgs/ICML20265481/cropped_page0_idx0.webp)

## Input / Output

The agent receives a task input (programming problem, math question, or multi-hop QA query) along with accumulated self-reflections from episodic memory and, in ParamAgent-plus, retrieved similar trajectories from a cross-sample memory bank. The parametric module takes only the task input and generates a model-based reflection via temperature-controlled sampling (T=0.2 for the first iteration, T=1.0 thereafter); for code and math this takes the form of enumerated potential mistakes with buggy implementations, while for multi-hop QA it produces compact semantic units and sub-tasks inspired by cognitive chunking. The final output is the task solution (code, math answer, or QA answer) produced by the actor conditioned on all three memory sources.

## Method

ParamMem is a lightweight LoRA-finetuned LLM module trained on an auxiliary dataset of (input, reflection) pairs generated by a stronger LLM (GPT-4o-mini), where the training objective is diversity-driven rather than accuracy-driven. At inference, the module generates reflections by generalizing from learned cross-sample patterns through temperature-controlled sampling, providing an orthogonal source of diversity beyond episodic and retrieval-based memory. ParamAgent integrates this parametric module into the Reflexion loop so the actor conditions on both episodic self-reflections and the parametric reflection at each iteration; ParamAgent-plus additionally retrieves similar trajectories from a memory bank of previously solved tasks. The key distinction from prior parametric approaches like Retroformer is that ParamMem optimizes for reflective diversity (enabling interpolation and extrapolation from learned patterns) rather than reflection accuracy, which yields better generalization across distributions and supports self-improvement and weak-to-strong transfer with as few as ~500 training samples.

## Results

On Llama-3.1-8B, ParamAgent achieves 82.93% Pass@1 on HumanEval (+23.78 over Base), 67.00% on MBPP (+19.39), 78.33% on HotpotQA (+20.66), and 88.67% on 2WikiMultiHopQA (+48.34), consistently outperforming all baselines in these domains. On MATH, ParamAgent reaches 67.99% accuracy, trailing DoT-bank (73.02%) and Retroformer (63.67%) but still improving over Reflexion (58.99%) and DoT (64.38%). The method also generalizes across model scales: with Mistral-7B, ParamAgent gains +34.14 on HumanEval and +60.33 on 2WikiMultiHopQA over Base; with Qwen2-1.5B, it gains +25.00 on HumanEval and +23.00 on 2WikiMultiHopQA.

## Baselines & Comparisons

ParamAgent outperforms Reflexion on all five datasets, with the largest gains on 2WikiMultiHopQA (+10.00) and HotpotQA (+7.00). Against DoT (prompt-level diversity), ParamAgent wins on HumanEval (+9.76), MBPP (+5.79), HotpotQA (+11.66), and 2WikiMultiHopQA (+22.00), but trails on MATH (67.99 vs. 64.38 is actually a win; DoT-bank at 73.02 is the MATH leader). Against DoT-bank (cross-sample retrieval), ParamAgent wins on HumanEval (+3.37), MBPP (+2.18), HotpotQA (+6.33), and 2WikiMultiHopQA (+8.34), but loses on MATH (67.99 vs. 73.02), where the authors note that cross-sample trajectories are more critical for analogous problem exposure. Retroformer, which also uses parametric encoding but optimizes for reflection accuracy via policy gradients, is competitive on MATH (63.67) but underperforms ParamAgent on HumanEval (67.68 vs. 82.93), MBPP (42.82 vs. 67.00), HotpotQA (73.00 vs. 78.33), and 2WikiMultiHopQA (77.00 vs. 88.67), which the authors attribute to distribution shift from accuracy-focused training.

## Relation to Prior Work

This paper extends the Reflexion framework (Shinn et al., 2023) and the diversity-of-thoughts line (DoT/DoT-bank, Lingam et al., 2025) by introducing a parametric memory module that encodes cross-sample reflection patterns into LoRA-finetuned weights, rather than relying on prompt-level variation or embedding-based retrieval. It departs from Retroformer (Yao et al., 2023c), which also uses a parametric reflective module but optimizes for reflection accuracy via policy gradients; ParamMem instead targets diversity through supervised fine-tuning on synthetic reflection data. The framework unifies three memory types—episodic, cross-sample, and parametric—into a single agent architecture, positioning parametric memory as an orthogonal diversity source complementary to the other two.

## Why It Matters / Open Questions

The paper provides empirical evidence (0.86 Pearson correlation) that reflective diversity, not just accuracy, is a primary driver of reasoning performance in iterative agent frameworks, and shows that a lightweight ~500-sample LoRA module can serve as a plug-in diversity generator across model scales (8B→70B+ weak-to-strong transfer). This opens a practical path for self-improving agents that do not require access to stronger external models for data generation. Key limitations include increased token consumption from additional reflective signals, and the approach still depends on an initial synthetic dataset (even if small); future work on token-efficient integration and whether parametric memory can replace rather than complement retrieval-based cross-sample memory remains open.

## Problem

No existing benchmark rigorously evaluates LLMs on historical reasoning, which demands multimodal source interpretation, cross-linguistic analysis across ancient and modern scripts, and evidence-grounded inference over fragmented primary materials. General-purpose benchmarks (GAIA, HLE) contain at most 56 history questions, while history-specific datasets like HiST-LLM test factual knowledge rather than research skills such as manuscript OCR, archival retrieval, and interdisciplinary synthesis. Additionally, no agent system is equipped with the domain-specific tools historians actually use, leaving a gap between what historical research requires and what current LLM agents can perform.

## Input / Output

HistAgent accepts heterogeneous multimodal inputs including text queries, scanned manuscript images, historical photographs, audio recordings (MP3/WAV), video URLs, and structured documents (PDF, DOCX, XLSX, PPTX), with 75% of HistBench items containing non-text attachments. Outputs are structured academic responses comprising a concise final answer and a detailed reasoning summary that logs every tool invoked, information source consulted, and step-by-step logical chain, all with full bibliographic citations. Evaluation uses a dual-judge protocol: an LLM judge applies semantic-equivalence scoring (adapted from HLE's official prompt), and human experts validate 100 randomly sampled cases for evidentiary grounding and reasoning fidelity.

## Method

HistAgent employs a manager-specialist architecture where a central Manager Agent runs a CodeAct loop (implemented as a Smolagents CodeAgent), emitting Python code snippets in each iteration that invoke specialist sub-agents within a secure sandbox and write results to shared memory. Eight specialist agents handle distinct modalities: OCR (routing between Transkribus for Western manuscripts and a dedicated Asian-script model), Speech Recognition (Whisper transcription with LLM error correction), Translator (bidirectional with provenance preservation for low-resource languages like Syriac, Tibetan, and Old Uyghur), Image Information (reverse image search via GoogleLens with SSIM-based confidence filtering), Literature Search (a ReAct agent using browser-use to drive a real Chrome instance through Google Scholar, Springer Nature, and Google Books), Text WebBrowser, File Processing, and Video (yt-dlp download plus OpenCV frame extraction). The Manager validates each intermediate result—checking exact quotes, bibliographic metadata, and source reliability—before synthesizing all verified outputs into a single citation-complete answer. The key design insight is that historical reasoning gains come not from a stronger backbone model but from domain-aligned tooling: handwriting OCR, multilingual translation with provenance tracking, and scholar-oriented retrieval with query optimization address failure modes that generic web-search agents cannot resolve.

## Results

On HistBench (414 questions), HistAgent (GPT-4o) achieves 28.50% pass@1 and 36.47% pass@2 average accuracy, substantially outperforming all standalone LLMs with web search and the ODR-smolagents baseline. On the GAIA validation set (165 tasks), HistAgent (Claude-3.7-sonnet) reaches 60.00% pass@1, surpassing ODR-smolagents (o1) at 55.15%. On the HLE History subset (56 questions), HistAgent scores 28.57% pass@1 versus 17.86% for ODR-smolagents and 8.93% for GPT-4o with web search.

## Baselines & Comparisons

HistAgent (GPT-4o) outperforms ODR-smolagents (GPT-4o) by 8.93 points on HistBench pass@1 (28.50% vs. 19.57%) and by 11.35 points on pass@2 (36.47% vs. 25.12%), with the gap widening on multimodal questions (e.g., 35.63% vs. 11.49% at Level 1). Against standalone LLMs with web search, HistAgent beats GPT-4o:online (18.60%), Grok 3:online (17.63%), and DeepSeek-R1:online (14.98%) by 10–14 points on pass@1. The only baseline that edges out HistAgent is o4-mini-high:online at 30.19% pass@1, a margin of just 1.69 points, suggesting that targeted tool design can nearly match a stronger foundation model. On GAIA, HistAgent (Claude-3.7-sonnet) leads ODR-smolagents (o1) by 4.85 points (60.00% vs. 55.15%), confirming that domain-specific tooling does not sacrifice general-task performance. On HLE History, HistAgent more than triples GPT-4o+web search (28.57% vs. 8.93% pass@1) and answers 60% more questions than ODR-smolagents.

## Relation to Prior Work

HistAgent's Manager Agent is built directly on the smolagents CodeAgent framework (Roucher et al., 2025), reusing its ReAct-style Python-code-in-a-sandbox execution loop, but replaces the generic tool suite with history-specific specialists (Transkribus OCR, Asian-script OCR, Whisper speech recognition, reverse image search with SSIM filtering, and a priority-based Literature Search Agent). Conceptually, the paper follows the domain-specific agent lineage established by ChemCrow, CRISPR-GPT, and DS-Agent, and the domain-specific benchmark tradition of SWE-Bench, LegalBench, and PHYBench, but departs from prior history-oriented evaluations (HiST-LLM, HLE-history) by targeting historical *research methodology*—source processing, OCR, translation, multimodal interpretation—rather than historical *knowledge recall*. The benchmark design also departs from general-purpose QA benchmarks by stratifying difficulty via a six-dimension rubric authored by professional historians rather than by model performance.

## Why It Matters / Open Questions

HistBench is the first dedicated benchmark for multimodal, multilingual historical reasoning, and its very low absolute scores (best system ~30% pass@1) expose a substantial capability gap in current LLMs for source-grounded, cross-lingual, and cross-modal historical tasks that general-purpose benchmarks do not capture. The modality breakdown showing HistAgent's advantage concentrated in multimodal questions (e.g., 35.6% vs. 11.5% on Level-1 multimodal) while o4-mini-high still leads on text-only questions suggests that tool-augmented agents and stronger foundation models address complementary failure modes. Key limitations include the restriction to closed-form questions (exact-match and multiple-choice), which excludes the open-ended interpretive reasoning central to actual historical scholarship, and a moderate question count (414) that may limit statistical power per language or subfield. Open questions include whether pairing HistAgent with stronger backbones (e.g., o4-mini-high) closes the remaining gap, how to design reliable evaluation for open-ended historical analysis, and whether the domain-specific tool design transfers to adjacent humanities fields.

## Problem

Learning rule-based models that simultaneously achieve high predictive accuracy and low, human-understandable complexity remains challenging: classical approaches rely on discrete heuristic search that is suboptimal and hardware-inefficient, while neuro-symbolic relaxations impose restrictive logical forms. The core technical bottleneck is that selecting which k features feed each truth table node is a non-differentiable TOPK operation, blocking end-to-end gradient-based training of sparse rule connections.

## Input / Output

Continuous features are thermometer-encoded into b binary literals per feature (evenly-spaced quantile thresholds) and categorical features are one-hot encoded to form the input vector. The model outputs class probabilities or regression values during inference, but the primary deliverable is an exact DNF/CNF Boolean rule set extracted via Quine-McCluskey minimization, where complexity is measured as total literal count across all rules—combining multi-feature conjunctions from LTT nodes and unary threshold rules from raw input features, each with exact learned weights.

## Method

TT-SPARSE is a neural layer of M Learnable Truth Table (LTT) nodes, each computing a thresholded linear combination over k selected input features and binarizing the result via a straight-through estimator. The key contribution is a novel soft TOPK operator with a closed-form sigmoid solution: it solves an entropic-regularized optimization under an exact cardinality constraint (sum of selections = k), yielding selection probabilities π_i = σ(s_i/τ + c) where c is found by bisection, with a Jacobian that has zero gradient variance and O(n) memory—substantially more efficient than Sinkhorn-based optimal transport or perturbed-maximizer alternatives. In the forward pass, hard TOPK preserves sparsity; in the backward pass, the soft relaxation routes gradients to both the connection mapping matrix W_map (which features to select) and the truth table weights W_LTT (how to combine them), enabling joint end-to-end optimization of connectivity and logic. After training, each node's 2^k truth table is enumerated and minimized via Quine-McCluskey (exploiting don't-care terms from unobserved training patterns) to produce compact DNF rules, and post-hoc iterative magnitude pruning further reduces complexity. The final model concatenates LTT rule activations with raw input features before a linear prediction head, natively supporting binary classification, multiclass classification, and regression within a single architecture.

## Results

Across 28 tabular datasets (14 binary, 7 multiclass, 7 regression), TT-SPARSE achieves the best average Friedman rank among all interpretable models: 1.53 on binary classification (vs. 3.07 for RuleFit, 3.6 for GLRM, 8.27 for GOSDT), 1.0 on multiclass, and 1.71 on regression. On the Heart dataset, TT-SPARSE reaches 0.931 AUC with only 15 literals of rule complexity, surpassing the SOTA black-box TabM (0.924 AUC). On multiclass tasks, TT-SPARSE dominates all interpretable baselines by a wide margin (e.g., 0.990 AUC on car vs. 0.973 for Classy; 0.966 on ecoli vs. 0.934 for NeuRules) while remaining close to TabM's 1.000 on car.

## Baselines & Comparisons

TT-SPARSE outperforms all eight interpretable baselines on average across binary classification (rank 1.53 vs. next-best RuleFit at 3.07) and dominates multiclass classification outright (rank 1.0 vs. NeuRules at 2.43 and Classy at 3.0). Against GOSDT, which produces the sparsest rules, TT-SPARSE gains 0.10–0.20 AUC on most datasets (e.g., 0.931 vs. 0.814 on Heart; 0.931 vs. 0.811 on CalHousing) at modest complexity increases. Against DWN and RL-Net, the gap is even larger (0.05–0.15 AUC), with DWN additionally suffering from position-dependent LUTs that hinder connection search. On regression, TT-SPARSE (rank 1.71) is slightly behind RuleFit (rank 1.43) but clearly ahead of GLRM (rank 2.86); both are the only interpretable methods evaluated on all seven regression datasets. Notably, TT-SPARSE beats the SOTA black-box TabM on Heart (0.931 vs. 0.924 AUC) and is within 0.01–0.03 on several other datasets (e.g., 0.915 vs. 0.923 on Income), while remaining fully interpretable with <50 literals. TT-SPARSE is also the only interpretable rule-learning model that natively supports all three task types (binary, multiclass, regression) in a single architecture.

## Relation to Prior Work

TT-SPARSE extends the truth-table-based node architecture from Benamira et al. (2023, 2024) by solving the key bottleneck of making such nodes trainable at scale: it introduces a novel soft TOPK operator with a closed-form sigmoid solution and straight-through estimation to learn sparse, cardinality-constrained feature routing end-to-end. This departs from prior neuro-symbolic rule learners (NeuRules, RL-Net, RRL) that impose restrictive logical forms, and from differentiable TOPK approaches (Sinkhorn-based optimal transport, perturbed maximizers) that suffer from high computational cost or gradient variance. The architecture also contrasts with DWN's LUT-based nodes (exponential parameter count, position-dependent) and DiffLogicNet's double-exponential operator distributions, using instead a commutative linear threshold per node with only n+1 parameters.

## Why It Matters / Open Questions

TT-SPARSE is the only interpretable rule-learning model that natively supports binary classification, multiclass classification, and regression within a single architecture while achieving global and exact interpretability (full DNF/CNF extraction via Quine-McCluskey), and it remains competitive with the SOTA non-pretrained tabular model TabM on several datasets. The soft TOPK operator is a reusable, zero-variance differentiable building block that could benefit other discrete selection problems beyond rule learning. Open questions include whether the per-node linearly-separable restriction becomes a practical limitation on more complex domains, how the approach scales to time-series or high-dimensional continuous features without thermometer encoding, and whether learnable linear-combination literals (as the authors suggest for future work) can further reduce Boolean complexity for non-linear boundaries.

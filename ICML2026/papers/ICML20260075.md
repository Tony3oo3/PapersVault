## Problem

Optimization-based adversarial suffixes (GCG, AutoDAN, AdvPrompter, BEAST, AutoDAN-HGA) can jailbreak aligned LLMs while maintaining fluency, causing global and windowed perplexity detectors to lose discriminative power because the attacks explicitly optimize for low perplexity. Existing defenses either rely on static scalar heuristics that assume suffixes are visibly disfluent, or deploy expensive auxiliary safety classifiers that operate only at the prompt level without localizing where the adversarial content begins. The paper asks whether the token-level entropy stream produced during a single forward pass contains a sequential signature of suffix onset that can be detected online and localized to the token.

## Input / Output

The detector consumes only quantities already available in a standard LLM forward pass: the token-level next-token probability distributions (from which entropy H_t is computed) and a fixed system prompt that provides the deployment-specific baseline. It processes the user prompt token-by-token in a streaming fashion (O(1) per token, O(T) total), requiring no additional model, no training, and no access to future tokens. Beyond the binary alarm, it emits a continuous CUSUM score s = max_t W_t+ (usable for ROC ranking and guard gating), the alarm time τ, and a backtracked suffix-onset estimate ν̂ that pinpoints the first adversarial token in user-token coordinates.

## Method

CPD Online casts adversarial suffix detection as a one-sided Page-CUSUM change-point test on the standardized token-entropy stream. The fixed system prompt's entropy sequence provides a robust baseline via median (μ̂_0) and MAD-scaled scale (σ̂_0); each user-token entropy is then standardized to Z_t = (H_t^usr − μ̂_0)/σ̂_0. The CUSUM recursion W_t+ = max{0, W_{t-1}+ + Z_t − k} accumulates sustained positive drift while resetting on negative excursions, so transient benign spikes do not trigger an alarm but a persistent entropy shift induced by the suffix does. The alarm fires at the first t where W_t+ ≥ h, and the suffix onset is localized by backtracking to the last reset before the alarm (ν̂ = 1 + max{t < τ : W_t+ = 0}). The key insight is that fluency-optimized suffixes produce a *sustained* upward shift in token-level uncertainty rather than isolated high-loss tokens, making sequential accumulation (CUSUM) fundamentally more informative than fixed-window averaging (WPP); an ablation confirms the mechanism axis (CUSUM vs. window) contributes ~12–14 F1 points more than the signal choice (entropy vs. NLL).

## Results

On the α=1 matched-PP benchmark (1,012 adversarial + 1,012 benign prompts per model), CPD Online at the canonical Page-CUSUM slack k=0 achieves the best prompt-level F1 on all six open-weight chat models, ranging from 0.77 (Vicuna-7B) to 0.85 (Qwen2.5-7B/14B), versus the per-model best WPP F1 of 0.74–0.83. On LLaMA-2-7B, CPD reaches AUROC 0.88 and F1 0.82, compared to global PP AUROC 0.46 and best WPP F1 0.74. For token-level localization, CPD concentrates 79.6% of its triggers inside the adversarial suffix (0% before-suffix, 0% boundary-straddling), versus 17–46% in-suffix for WPP baselines. In the hybrid LLaMA Guard gating deployment, CPD saves 42.2% of guard calls (LG1) and 33.8% (LG2) while preserving the best rounded hybrid F1.

## Baselines & Comparisons

Against the WPP baselines from the llm-attacks repository (Zou et al., 2023a), CPD Online wins F1 on all six models at k=0, with margins from +0.001 (Vicuna-7B, a near-tie) to +0.08 (LLaMA-2-7B); on AUROC CPD leads or ties on five of six models, losing only on Vicuna-7B where the per-token max-NLL window (w=1) reaches 0.85 vs. CPD's 0.82. Against LLaMA Guard v1 (Inan et al., 2023), CPD is not a direct detector-vs-detector comparison but a gating layer: at the highest-savings operating point preserving the best rounded hybrid F1, CPD gating saves 42.2% of LG1 calls (hybrid F1 0.82) versus 18.2% for the best WPP variant (hybrid F1 0.81). Against LLaMA Guard v2 (Meta Llama Team, 2024), the same pattern holds with CPD saving 33.8% of calls (hybrid F1 0.73) versus 13.5% for WPP₁₀ (hybrid F1 0.73). Against SPD (Candogan et al., 2025), the closest supervised single-pass baseline, CPD achieves F1 0.82 vs. SPD's 0.78 on the prior matched pool and F1 0.98 vs. 0.90 on SPD's own released attack data, though the authors note this is a supporting comparison rather than a full head-to-head on the six-model benchmark.

## Relation to Prior Work

This paper repurposes the classical one-sided Page-CUSUM sequential test (Page, 1954) for a new domain: detecting adversarial suffixes within a single LLM prompt by monitoring token-level next-token entropy. Prior detection work (Alon & Kamfonas, 2023; Jain et al., 2023) treats the problem as static scoring via global or windowed perplexity, while guard models (Inan et al., 2023; Meta Llama Team, 2024) treat it as sequence-level classification. The key departure is reframing detection as an online change-point problem on a one-dimensional entropy stream, using the fixed system prompt to establish a deployment-specific robust baseline (median + MAD), and exploiting the CUSUM recursion to accumulate sustained positive drift rather than thresholding individual windows. The authors are explicit that this is a heuristic application of CUSUM rather than a likelihood-ratio-based optimal detector, and that token entropy is a proxy rather than a sufficient statistic for distributional change.

## Why It Matters / Open Questions

The method is immediately deployable: training-free, model-agnostic, online, and adds only O(1) arithmetic per token on top of an existing forward pass. The token-level localization (79.6% of triggers inside the suffix vs. 17–46% for WPP) enables targeted mitigation rather than blanket rejection, and the LLaMA Guard gating result (33–42% call savings at comparable F1) has direct cost implications for high-volume deployments. Key limitations include the requirement for token-level probability access (unavailable in closed APIs), the restriction to suffix-appended attacks (not prefix or indirect injection), the need for a benign calibration corpus, and the absence of minimax optimality guarantees. Open questions include adapting the entropy signal to sampling-only APIs, extending to multi-turn and tool-augmented settings, and whether adaptive attackers can learn to suppress the entropy shift that CPD exploits.

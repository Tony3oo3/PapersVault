## Problem

Existing indoor 3D object detection benchmarks and methods assume access to fully reconstructed global scenes and perform single-frame detection, discarding temporal context. Embodied agents, however, operate under sequential, partial, and heavily occluded egocentric observations where historical views are critical for reliable perception. This paper identifies and quantifies the substantial performance degradation that current detectors suffer in this egocentric temporal setting, and introduces both a benchmark and a method to close the gap.

## Input / Output

The method consumes a stream of egocentric RGB-D frames (each with camera pose) processed sequentially online, where each frame provides only a partial, view-dependent point cloud within the camera frustum. Outputs are asymmetric: new-instance queries predict a full 18-class category distribution plus a 3D bounding box, while active-instance queries predict a binary existence score plus a refined bounding box. A persistent memory bank accumulates scene feature points (voxel-downsampled at 8 cm) and per-instance states (features, bounding boxes, lifetime counters) across the entire sequence, enabling the model to integrate multiple partial observations of the same object over time.

## Method

Embodied-DETR is an end-to-end temporal DETR built on a 3D sparse convolutional backbone (Minkowski ResNet34 + FPN) with two complementary temporal modules. Scene-aware Feature Aggregation retrieves past-frame feature points from a memory bank within the current frustum, then uses FPS-seeded ball queries with max-pooled MLP aggregation to produce scene-aware feature points that provide broader spatial context. Instance-aware Query Embedding maintains a dual-query set: 32 fixed learnable new-instance queries for discovering unseen objects, and dynamic active-instance queries constructed from stored instance features for refining previously detected objects, with a lifetime-based eviction mechanism. Training uses decoupled bipartite matching (active queries assigned by instance ID, remaining ground truths matched to new queries via Hungarian algorithm), curriculum learning that progressively increases clip length from 2 to 16 frames, spatial-overlap-based data sampling, an adaptive confidence threshold for memory bank updates, and group query replication (G=8) for training stability. The entire system is trained from scratch without relying on pre-trained frozen single-frame detectors.

## Results

On the Embodied-Det benchmark, Embodied-DETR achieves 59.29/42.90 frame-level mAP@25/50 and 69.57/52.28 scene-level mAP@25/50, outperforming the strongest baseline V-DETR by +3.76 and +2.00 in mAP@50 respectively. In temporal metrics, Embodied-DETR reduces frame-to-frame jitter (mALD 0.0271 vs. 0.0675 for V-DETR) and improves detection stability (mCDR 54.23 vs. 37.74, a +16.49 gain). The method also runs faster at 112 ms per frame versus 156 ms for V-DETR, enabling near-real-time operation.

## Baselines & Comparisons

Embodied-DETR outperforms all seven baselines on every reported metric. Against the closest competitor V-DETR (ICLR'24), it gains +3.76 frame-level mAP@50, +2.00 scene-level mAP@50, reduces mALD by 60% (0.0271 vs. 0.0675), and improves mCDR by +16.49 points, while also being 44 ms faster per frame. The gap widens substantially against older methods: VoteNet (ICCV'19) trails by 17.4 in frame mAP@50 and 25.8 in mCDR, and GroupFree3D (ICCV'21) lags by 20.1 in frame mAP@50. Notably, UniDet3D (AAAI'25), despite achieving 66.1 mAP@50 on the original ScanNet global-view benchmark, degrades to only 22.67 frame mAP@50 on Embodied-Det, a drop of over 30 points, revealing its heavy reliance on pre-computed superpoints that are fragile under noisy RGB-D input. The paper further shows in Table 3 that all baselines suffer 10–30 point mAP@50 drops when switching from global scene meshes to sequential egocentric frames, whereas Embodied-DETR is the only method designed to exploit temporal context, making it the sole approach that benefits from the sequential setting.

## Relation to Prior Work

This paper extends the DETR-based 3D detection lineage (3DETR, GroupFree3D, V-DETR) by reframing indoor detection from an offline, global-mesh task to an online, sequential egocentric perception problem. It draws on temporal 3D detection strategies from autonomous driving (MPPNet, MSF, PTT) but is the first to apply end-to-end temporal modeling to indoor embodied settings, combining scene-level feature aggregation with instance-level query propagation in a unified DETR decoder. The benchmark itself reorganizes ScanNet v2 into per-frame egocentric sequences, departing from the fully-reconstructed scene paradigm that underpins all prior indoor 3D detection benchmarks.

## Why It Matters / Open Questions

The Embodied-Det benchmark exposes a critical gap: SOTA global-view detectors lose 10–30 mAP points when forced into sequential egocentric input, revealing that current methods are brittle under partial observability and sensor noise. The introduced temporal consistency metrics (ALD, ASD, CDR, CMR) provide evaluation dimensions that prior benchmarks entirely lack, which will be essential as embodied agents move toward real-time perception. Key limitations include restriction to static scenes and reliance on ScanNet-derived annotations, leaving dynamic object handling and outdoor/generalization as open questions for future work.

## Problem

Existing Muon optimizer and its variants for training large models suffer from either high sample complexity of O(ε^{-4}) or high state memory of mn for matrix-structured parameters. No prior method simultaneously achieves both reduced memory and improved convergence rate, and no variance-reduced Muon variant has been analyzed under generalized smoothness or with Newton-Schulz approximation.
![Teaser figure](../imgs/ICML20261722/cropped_page2_idx0.webp)

## Input / Output

The optimizer consumes matrix-structured parameters W ∈ R^{m×n} and single stochastic gradient samples (batch size 1) at each iteration. With Option #2, it stores only low-rank factors (Ũ_t ∈ R^{m×r̂}, Ŝ_t ∈ R^{r̂×r̂}, V̂_t ∈ R^{n×r̂}) instead of the full momentum matrix, reducing state memory from mn to (m+n)r̂ + r̂² where r̂ ≪ min(m,n). The output is the updated parameter matrix W_{t+1} = W_t − η_t U_t V_t^⊤ (or its Newton-Schulz approximation).

## Method

LiMuon combines two key mechanisms: (1) a STORM-style momentum-based variance-reduced gradient estimator M_{t+1} = ∇f(W_{t+1};ξ_{t+1}) + (1−β)(M_t − ∇f(W_t;ξ_{t+1})), which avoids the gradient clipping used by Muon++; and (2) randomized SVD to compress the momentum matrix to rank r̂, yielding a low-rank STORM-like estimator that reduces memory. The orthogonalization step uses either exact SVD or a fixed number of Newton-Schulz iterations. This design achieves O(ε^{-3}) sample complexity (vs. O(ε^{-4}) for Muon) under both Lipschitz and (L_0, L_1)-generalized smoothness, and O(χ_q³ ε^{-3}) with Newton-Schulz (vs. O(χ_q⁴ ε^{-4}) for Muon with Newton-Schulz), all while using (m+n)r̂ state memory instead of mn.

## Results

On Qwen2.5-0.5B (MiniPile), full-rank LiMuon achieves 40.83 validation PPL, substantially outperforming Muon (67.60), Muon++ (82.26), and AdamW (113.25). On Mamba-130M (WikiText-103), full-rank LiMuon reaches 47.78 validation PPL versus Muon++ (56.79) and Muon (71.27). On ViT (Tiny-ImageNet), full-rank LiMuon attains 48.04% validation top-1 accuracy, marginally exceeding Muon (47.87%) and significantly outperforming Muon++ (43.62%). Low-rank LiMuon (rank=8) achieves competitive quality (e.g., 54.87 val PPL on Qwen2.5-0.5B) while reducing memory from ~55 GB to ~52.5 GB.

## Baselines & Comparisons

LiMuon (full rank) decisively outperforms all six baselines across all three architectures. On Qwen2.5-0.5B, it reduces validation PPL from 67.60 (Muon) and 82.26 (Muon++) to 40.83, a 39–50% improvement over the strongest Muon-family baselines. On Mamba-130M, full-rank LiMuon achieves 47.78 val PPL versus 56.79 for Muon++ and 71.27 for Muon. On ViT, the advantage is narrower: LiMuon (48.04% top-1) edges out Muon (47.87%) by 0.17 points while substantially beating Muon++ (43.62%) and SUMO (44.23%). The low-rank variant (rank=8) trades a modest quality drop (e.g., 54.87 vs 40.83 val PPL on Qwen2.5-0.5B) for meaningful memory savings (~52.5 GB vs ~55.2 GB), making it attractive under memory constraints. In wall-clock time on ViT, full-rank LiMuon reaches the target loss in 7 min 1 s, slightly faster than Muon (7 min 6 s) and much faster than Muon++ (9 min 54 s).

## Relation to Prior Work

LiMuon sits at the intersection of three research threads: the Muon optimizer (Jordan et al., 2024) which orthogonalizes gradient momentum via SVD or Newton-Schulz iteration, the STORM variance-reduction framework (Cutkosky & Orabona, 2019) that reduces stochastic gradient noise through momentum-based correction, and randomized SVD (Halko et al., 2011) for efficient low-rank matrix approximation. It departs from Muon++ (Sfyraki & Wang, 2025), which also applies variance reduction to Muon but requires gradient clipping and full-rank state storage, and from SUMO (Refael et al., 2025), which reduces memory via subspace projection but relies on a bounded-objective assumption. The paper's key conceptual departure is introducing a low-rank STORM-like gradient estimator that simultaneously compresses the momentum state and reduces variance, a combination not previously studied for Muon-family optimizers.

## Why It Matters / Open Questions

The simultaneous achievement of O(ε^{-3}) sample complexity and (m+n)r̂ state memory (versus O(ε^{-4}) and mn for standard Muon) addresses a practical tension in large-model training: variance-reduced optimizers typically increase memory, while memory-efficient variants sacrifice convergence rate. The Newton-Schulz analysis (O(χ_q³ε^{-3}) vs. O(χ_q⁴ε^{-4})) narrows the theory-practice gap since Newton-Schulz is what is actually deployed. However, experiments are limited to models of 22M–494M parameters, leaving open whether the low-rank approximation and variance-reduction benefits persist at the multi-billion-parameter scale where memory pressure is most acute. The additional RSVD computation per step also introduces a wall-clock cost that partially offsets the memory savings, a trade-off the paper acknowledges but does not fully resolve.

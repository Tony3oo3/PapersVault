## Problem

In the language generation in the limit framework, Raman and Raman (2025) introduced a noisy model where an adversary can insert extraneous strings, but left open whether non-uniform generation is equivalent to non-uniform noise-dependent generation and how the number of noisy strings affects generatability. This paper quantifies the effect of noise by studying the impact of each additional extraneous string, revealing both a sharp separation between noiseless and noisy generation and a surprising collapse of the noise-level hierarchy for all levels ≥ 1.

## Input / Output

The algorithm receives a finite ordered list of strings at each time step, representing the adversary's enumeration of the target language with up to i unique extraneous strings inserted (the algorithm is not told which are noise). At each step it outputs a single string, and success requires that after some finite time t*, every output is a correct unseen element of the target language. The key constraint is that the enumeration contains no repetitions, and the noise level i bounds the total number of strings outside the target language in the entire infinite sequence.

## Method

The core technical tool is a combinatorial lemma showing that the noisy closure dimension satisfies NC_{i-1}(C) ≥ ⌊√NC_i(C)⌋, which implies that if NC_i(C) = ∞ then NC_{i-1}(C) = ∞. This is proved by partitioning a large witness set into equal-sized subsets and constructing a smaller set whose closure at noise level i-1 is contained in the original closure at noise level i, using a counting argument that any language consistent with the original set at noise level i can be inconsistent with at most one partition element. This lemma collapses the hierarchy: uniform (resp. non-uniform) generation with noise level i is equivalent for all i ≥ 1, characterized by NC_1(C) < ∞ (resp. a countable union of subcollections each with finite NC_1). A separation between noiseless and noisy generation is established via a 'columns' construction over the universe N×N, where languages are nonempty unions of infinite columns and a diagonalization argument shows no algorithm can handle even a single noisy string.

## Results

This is a pure theory paper with no experimental benchmarks. The headline results are: (1) For both uniform and non-uniform generation, generatability with noise level i is equivalent for all finite i ≥ 1 (Theorem 2.14), meaning the hierarchy collapses at noise level 1. (2) A single noisy string strictly reduces the set of generatable collections, separating noiseless from noisy generation (Theorem 2.15). (3) The first complete characterization of non-uniform noise-dependent generatability is given: a collection C is non-uniformly noise-dependently generatable iff it admits a countable exhaustion C₀ ⊆ C₁ ⊆ … with NC₁(Cⱼ) < ∞ for all j (Theorem 2.17).

## Baselines & Comparisons

The paper's central contrast is with Bai, Panigrahi, and Zhang (SODA 2026), who showed a strict infinite hierarchy for noisy generation in the limit: for every i ≥ 0 there exists a collection generatable with noise level i but not i+1. In stark contrast, this paper shows that for uniform and non-uniform generation, the hierarchy collapses entirely for all i ≥ 1 — noise level 1 is equivalent to any finite noise level. The paper also negatively resolves an open question from Raman and Raman (ICML 2025), which asked whether non-uniform generation is equivalent to non-uniform noise-dependent generation; the answer is no, with a single noisy string sufficing to create a separation. Additionally, the paper simplifies the prior characterization of uniform noise-dependent generatability from requiring NCᵢ(C) < ∞ for all i to the single condition NC₁(C) < ∞.

## Relation to Prior Work

This paper extends the language generation in the limit framework of Kleinberg & Mullainathan (2024) by studying the noisy variant introduced by Raman & Raman (2025), specifically for the uniform and non-uniform settings defined by Li, Raman, and Tewari (2025). It builds on the fine-grained noise-level hierarchy for basic generation in the limit shown by Bai, Panigrahi, and Zhang (2026), but introduces the analogous notion for uniform and non-uniform generation and proves that the hierarchy collapses entirely for all noise levels i ≥ 1. The paper also leverages the noisy closure dimension and consistent language machinery from Raman & Raman (2025) to derive clean structural characterizations.

## Why It Matters / Open Questions

The paper resolves two open questions from Raman & Raman (2025): it negatively answers whether non-uniform generation equals non-uniform noise-dependent generation (a single noisy string suffices to break generatability), and it provides the first complete characterization of non-uniform noise-dependent generatability. The conceptual contrast between the strict infinite hierarchy in basic noisy generation (Bai et al., 2026) and the complete collapse at noise level 1 for uniform/non-uniform settings is a clean and somewhat unexpected structural result. Open questions remain about whether similar collapses or separations hold in other variants (e.g., infinite noise, breadth-constrained generation), and whether the noisy closure dimension characterization has algorithmic or practical implications for understanding LLM robustness to noisy training data.

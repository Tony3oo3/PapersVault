## Problem

Approximating semi-values (Shapley, Banzhaf, Beta Shapley, etc.) requires exponential utility queries in the number of players n, and existing efficient randomized algorithms either consume Θ(n²) space (e.g., OFA) or incur suboptimal O(n log n / ε² · log(1/δ)) query complexities. It remains an open question whether one can provably minimize the mean squared error while maintaining a Θ(n) space constraint and achieving the optimal O(n/ε² · log(1/δ)) query complexity.

## Input / Output

The method takes a utility function U: 2^[n] → R (instantiated as the expected prediction of a trained gradient-boosting tree with features in S fixed and others marginalized), a semi-value weight vector m ∈ R^n specifying which semi-value to compute, and a budget T of total utility queries. It outputs an estimate φ̂ ∈ R^n of the semi-value. The algorithm operates under a strict Θ(n) space constraint, consuming only O(n) memory for the running estimates, and each utility query evaluates U at a single randomly sampled subset S ⊆ [n].

## Method

The paper establishes a unified framework for approximating semi-values by sampling subsets according to an optimal distribution q* ∝ √(m_s²/s + m_{s+1}²/(n−s)) that minimizes the query complexity constant D(q*), combined with a vector concentration inequality (Theorem 2.1) that bounds the full n-dimensional error without a union bound over coordinates, thereby removing the log n factor. Building on this, Adalina applies a control-variates technique: it simultaneously tracks the running mean γ̂ = (1/T)Σ u_{S_t} of the sampled utilities and subtracts it from each sample, yielding an estimate φ̂ = (1/T)Σ(u_{S_t} − γ̂)·z_{S_t} + b that provably achieves MSE matching the oracle φ^{γ*} up to a 1/T² lower-order term. The framework also bridges OFA, unbiased kernelSHAP, SHAP-IQ, and the regression-adjusted approach, and provides a definitive characterization of when paired sampling improves MSE (iff E[u_S · u_{[n]\S}] > 0). For the Shapley value, the optimal q* is unique and coincides with the geometric-mean sampling distribution of Chen et al. (2025), confirming that the modified unbiased kernelSHAP already achieves the optimal O(n/ε² · log(1/δ)) query complexity in linear space.

## Results

The paper evaluates relative approximation error ‖φ̂ − φ‖₂/‖φ‖₂ across 12 OpenML datasets (n ranging from 32 to 3,072 features) using gradient boosting decision trees, with 1,000 queries per player (100 for har/Fashion-MNIST, 20 for CIFAR_small), averaged over 10 seeds. Adalina achieves O(n/ε² log(1/δ)) query complexity for all commonly used semi-values (Beta Shapley, weighted Banzhaf) while maintaining Θ(n) space. The headline empirical finding is that Adalina consistently outperforms or matches all baselines across non-symmetric semi-values, though for the Shapley value specifically (α,β)=(1,1), the modified unbiased kernelSHAP achieves lower relative error, suggesting that inf_λ E[(u_S − λ·s)²] < inf_γ E[(u_S − γ)²].

## Baselines & Comparisons

Adalina outperforms SHAP-IQ, ARM, GELS, GELS-Shapley, and MSR-Prob across most semi-values and datasets in Figure 4, with the gap being most pronounced for non-symmetric Beta Shapley values (e.g., (α,β) ≠ (1,1)) and weighted Banzhaf values with extreme w. Against unbiased kernelSHAP (Chen et al., 2025), Adalina is competitive for non-symmetric semi-values but loses specifically on the Shapley value, where kernelSHAP's λ·s_t correction provides a tighter control variate than Adalina's scalar γ. Against AME (Lin et al., 2022) and MSR-Banzhaf (Wang & Jia, 2023), which are restricted to weighted Banzhaf values, Adalina matches or slightly improves relative error while using the same Θ(n) space. The paper also shows (Figure 3) that Adalina's adaptive γ estimation closely tracks the oracle φ^γ*, confirming the theoretical MSE improvement, and that paired sampling helps only when E[u_S · u_[n]\S] > 0 (Theorem 3.2), which is empirically verified in Figure 1.

## Relation to Prior Work

This paper unifies and sharpens the theoretical analysis of several recent semi-value approximation algorithms—OFA (Li & Yu, 2024b), modified unbiased kernelSHAP (Chen et al., 2025), SHAP-IQ (Fumagalli et al., 2024), and the regression-adjusted approach (Witter et al., 2025)—under a single framework built on a vector concentration inequality (Yurinsky, 1995). The key conceptual departure is bounding the full n-dimensional error vector holistically rather than coordinate-by-coordinate via union bound, which removes a log n factor from query complexity and reveals that the modified unbiased kernelSHAP is in fact the linear-space version of OFA. On top of this framework, the paper introduces Adalina, an adaptive control-variates algorithm that provably minimizes MSE for each utility function while preserving the O(n/ε² log(1/δ)) query complexity under a Θ(n) space constraint.

## Why It Matters / Open Questions

The framework provides the first provable linear-space, linear-time randomized algorithm for approximating all commonly used semi-values (Beta Shapley, weighted Banzhaf) with O(n/ε² log(1/δ)) queries, closing a gap where prior optimal-complexity methods required Θ(n²) space. The definitive characterization of when paired sampling improves MSE (E[U(S)·U([n]\S)] > 0) resolves a long-standing empirical mystery and gives practitioners a clear decision rule. Open questions remain: for the Shapley value specifically, the paper notes that kernelSHAP's λ·s correction may outperform Adalina's scalar γ, suggesting richer control-variates structures (e.g., Lemma 3.3's f(s) family) could yield further MSE gains. The framework also naturally extends to non-symmetric semi-values via the Adalina-All variant, though the theoretical guarantee there relies on the MSR sampling pool including the empty and full sets.

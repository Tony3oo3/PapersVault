## Problem

Existing unsupervised domain adaptation methods for person search focus on appearance alignment or pseudo-label refinement but overlook cross-domain scale inconsistency caused by variations in camera height, tilt angle, focal length, and scene layout. This scale mismatch produces a persistent feature gap between source and target domains, degrading both detection localization and identity representation, and ultimately corrupting the pseudo-labels that drive self-training.
![Teaser figure](../imgs/ICML20264898/cropped_page0_idx1.webp)

## Input / Output

The method consumes full RGB scene images (resized to 1500×900) as both query and gallery inputs, with random horizontal flipping applied during training. It jointly produces person bounding boxes via a Faster R-CNN-style detection head and identity retrieval rankings via a ReID head, both operating on ROI-Align extracted crops. The framework runs in an iterative two-stage loop: a clustering stage generates pseudo-labels from target-domain features, and a training stage adapts the network using those pseudo-labels alongside source-domain supervision.

## Method

SCALE introduces two complementary mechanisms. The Scale-aware Domain Harmonization (SDH) module, embedded in both detection and ReID heads, contains a Scale-Interactive Alignment (SIA) sub-module that models spatial structure via tri-directional attention (channel-width, height-channel, height-width planes) with multi-scale depthwise convolutions, and models semantic scale via channel-spatial attention, fusing both paths with learnable weights; a parameter-free Scale Consistency Refinement (SCR) sub-module then normalizes local activation dispersion through mean-subtraction and sigmoid gating to suppress residual inconsistencies. The Bidirectional Cluster Regularization (BCR) strategy refines pseudo-labels by computing a corrected distance matrix: a split branch identifies internally loose clusters (high mean intra-cluster distance), subdivides them via spectral clustering, and adds positive distance penalties between sub-clusters, while a merge branch identifies closely related cluster pairs (low inter-cluster distance with consistent voting) and adds negative corrections to encourage re-merging. Built on the DSCA framework with a ResNet-50 backbone, the two stages iterate to progressively tighten feature alignment and label reliability, achieving 82.3% mAP / 84.0% top-1 on CUHK-SYSU and 41.7% mAP / 82.4% top-1 on PRW.

## Results

SCALE achieves state-of-the-art unsupervised domain adaptation performance on both benchmarks: 41.7% mAP and 82.4% top-1 on PRW, and 82.3% mAP and 84.0% top-1 on CUHK-SYSU. These results surpass the previous best unsupervised method DSCA by +1.8 mAP / +0.8 top-1 on PRW and +2.1 mAP / +2.3 top-1 on CUHK-SYSU. Notably, SCALE narrows the gap with fully supervised methods (e.g., SEAS: 60.5% mAP / 89.5% top-1 on PRW) without using any target-domain ground-truth labels.

## Baselines & Comparisons

SCALE outperforms all five unsupervised baselines on both datasets, with the largest margin over DSCA (its direct predecessor): +1.8 mAP on PRW (41.7 vs. 39.9) and +2.1 mAP on CUHK-SYSU (82.3 vs. 80.2). Against the next-best unsupervised method MoS (CVPR 2025), SCALE gains +4.6 mAP on PRW and +2.2 mAP on CUHK-SYSU. Compared to weakly supervised methods, SCALE surpasses SSL (ICCV 2023) by +7.8 mAP on PRW (41.7 vs. 33.9) and DICL (PR 2024) by +6.2 mAP on PRW, while on CUHK-SYSU it trails SSL by 5.3 mAP (82.3 vs. 87.6) but leads DICL by −5.1 mAP. Against fully supervised methods, SCALE still lags significantly (e.g., SEAS achieves 60.5% mAP on PRW vs. SCALE's 41.7%), but the gap is notably smaller than for prior unsupervised approaches, demonstrating that scale-aware harmonization and bidirectional cluster regularization substantially close the supervision gap without any target-domain labels.

## Relation to Prior Work

This paper extends the DSCA framework (Qi et al., AAAI 2025), which introduced dual self-calibration for unsupervised domain adaptive person search, by adding an explicit scale-harmonization stage. The broader UDA person search lineage traces back to DAPS (Li et al., ECCV 2022), which established the pseudo-label clustering paradigm, and subsequent methods (DDAM, FOUS, MoS) that refined appearance alignment or clustering quality. The key conceptual departure here is that prior UDA person search methods treat cross-domain feature alignment as an appearance or identity problem, whereas SCALE identifies and explicitly models scale inconsistency—arising from camera height, focal length, and scene layout—as a distinct and previously overlooked source of domain gap, addressing it through a dual-path directional-attention module (SDH) and a split-merge cluster correction (BCR).

## Why It Matters / Open Questions

The paper provides a well-motivated empirical demonstration (Table 5) that bounding-box scale distributions shift substantially between CUHK-SYSU and PRW, validating that scale inconsistency is a real and measurable confound in cross-domain person search. However, the practical impact is limited by the modest gains over DSCA (+1.8 mAP on PRW, +2.1 mAP on CUHK-SYSU), the evaluation on only two datasets with a single backbone (ResNet-50), and the moderate compute overhead (+11.1% GMac). Open questions include whether the scale-aware harmonization generalizes to other domain adaptation tasks (e.g., ReID, detection), whether it helps with more extreme scale shifts (e.g., aerial vs. ground-level cameras), and whether the BCR split-merge strategy can be made more efficient for very large target domains.

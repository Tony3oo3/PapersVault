## Problem

Current LLM-based agents for machine learning engineering (MLE) tasks produce monolithic scripts that ignore computational execution costs and cannot attribute performance changes to specific code modifications. This makes them poorly suited for the resource-intensive, iteratively opaque nature of autonomous AI research, where a 0.1% accuracy gain that multiplies training time tenfold is practically useless and where isolating causal factors behind performance shifts remains unsolved.

## Input / Output

The agent receives a natural language task description, raw datasets (with automatic stratified/group-based splitting into train/val/test if no validation set is provided), an evaluation metric specification, and a strict 24-hour wall-clock budget on a single A100 GPU node. The output is a structured multi-file Python repository (typically ~7 files, ~1100 lines of code) comprising independent functional modules (data loading, model definition, training engine, utilities) orchestrated by a main script, rather than a single monolithic script. Additionally, the system produces a persistent pool of distilled causal lessons that guide subsequent search iterations.

## Method

MARS reformulates MLE as a search over software repositories using three integrated mechanisms. First, Budget-Aware MCTS navigates the solution space via UCT selection over three actions (Draft, Improve, Debug), guided by an efficiency-guided reward R(v) = G(v)·[t(v)/L(v)]^w (w=−0.07) that explicitly penalizes long execution times, favoring faster solutions when performance is comparable. Second, a 'Design-Decompose-Implement' pipeline with specialized Idea, Modular, and Coding agents produces modular repositories, with diff-based editing enabling atomic multi-file updates without full regeneration. Third, Comparative Reflective Memory resolves credit assignment through a two-stage process: an Empirical Analysis Agent extracts objective findings from execution logs, then a Lesson Distillation Agent analyzes the code-level delta between the current solution and the best-known solution to isolate specific causal changes, producing structured lessons (causal change, impact analysis, generalized rule) that are retrieved and cited during subsequent iterations. A Review Agent filters redundant lessons to maintain a high-signal pool of up to 30 entries.

## Results

On MLE-Bench (75 Kaggle competitions, 24-hour budget, 1×A100), MARS with Gemini-3-Pro-Preview achieves 65.8% Above Median, 31.1% Gold Medal, and 56.0% Any Medal rate, establishing state-of-the-art among open-source frameworks. The scaled variant MARS+ (2×H100, 48 vCPUs, 2-way parallel search) further improves to 74.2% Above Median, 33.8% Gold, and 62.7% Any Medal, outperforming strong leaderboard competitors like ML-Master 2.0 (56.4% Any Medal). MARS also achieves the highest Gold Medal rate (31.1%) among all agents in the controlled evaluation, and a 98.7% valid submission rate.

## Baselines & Comparisons

In the controlled evaluation (identical 1×A100 hardware, 24-hour limit, no external knowledge base), MARS with Gemini-3-Pro-Preview decisively outperforms both open-source baselines: it surpasses AIDE (32.4% Any Medal) by 23.6 points and AIRA-dojo (37.8%) by 18.2 points on Any Medal rate, while also leading on Above Median (65.8% vs. 48.0% and 55.6%) and Gold Medal (31.1% vs. 16.4% and 24.0%). Against the official MLE-Bench leaderboard entries, which use substantially more compute (e.g., ML-Master 2.0 uses 2×4090 GPUs with 407 warm-up competitions; Famou-Agent uses 64 vCPUs with an expert knowledge base), MARS+ remains competitive, matching or exceeding ML-Master 2.0's 56.4% Any Medal with 62.7%, and surpassing Leeroo (50.7%) and Famou-Agent (43.6%). MARS also generalizes across models: with Claude 4.6 Sonnet it achieves 55.6% Any Medal versus AIRA-dojo's 20.0%, confirming the gains are architectural rather than model-specific. A cost-controlled 4-hour MARS run achieves 28.4% Any Medal at $9.6, outperforming both 24-hour baselines (AIDE: 23.1% at $10.6; AIRA-dojo: 24.4% at $39.0), demonstrating Pareto efficiency.

## Relation to Prior Work

MARS extends the MLE agent paradigm established by AIDE, AIRA, and ML-Master by addressing three specific gaps those systems leave open: ignoring computational cost during search, generating fragile monolithic scripts, and failing at credit assignment for performance changes. It repurposes MCTS (Kocsis & Szepesvári, 2006) with an efficiency-guided reward borrowed from the NAS literature (Tan et al., 2019, MnasNet), and introduces a 'Design-Decompose-Implement' modular pipeline and a comparative reflection mechanism that distills causal lessons by diffing solutions against the best-known result. Unlike prior memory-based agents (Reflexion, MemGPT, ReasoningBank) that summarize execution logs or track binary success/failure, MARS explicitly isolates the code-level delta responsible for metric shifts, making its lessons more targeted and transferable across search branches.

## Why It Matters / Open Questions

MARS provides a practical, well-ablated framework for autonomous MLE that achieves SOTA among open-source systems on MLE-Bench, and the cost-controlled result (4-hour MARS at $9.6 outperforming 24-hour baselines on Any Medal Rate) suggests architectural efficiency can substitute for raw compute—a finding with direct implications for resource-constrained practitioners. Key limitations include evaluation restricted to MLE-Bench (not broader scientific discovery), high API costs for the full 24-hour run ($60.5), and reliance on LLMs for causal attribution of lessons (88% accuracy, leaving room for misattribution). Open questions include whether the modular + reflective architecture generalizes to non-MLE research tasks, whether lesson reliability can be improved via formal program analysis or cross-model verification, and whether the framework's gains persist as underlying LLMs improve.

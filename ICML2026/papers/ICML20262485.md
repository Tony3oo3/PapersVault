## Problem

Existing adversarial perturbations for MLLMs are either instance-specific or map all inputs to a single target (many-to-one), failing to provide fine-grained, semantics-conditioned control. This paper investigates whether a single universal perturbation can act as a 'semantic router,' simultaneously mapping multiple distinct semantic inputs to multiple distinct attacker-defined targets—a many-to-many universal adversarial perturbation that has not been demonstrated before.

## Input / Output

The method takes an RGB image (1920×1080 for driving, 320×180 for robotics) with a spatially constrained perturbation applied (a 6-pixel-wide frame or 20×20 corner patches) plus a fixed text prompt, and produces a specific target text sequence whose content is determined by the semantic category of the input image. The same single perturbation must route all C semantic classes to C distinct targets simultaneously, and must generalize to unseen images within each class. The perturbation is optimized in a normalized pixel space and recovered via inverse transformation, with clipping to ensure valid [0,1] pixel values.

## Method

The SORT algorithm optimizes a single perturbation δ in a normalized space (NSO) to stabilize gradients, combined with a hybrid loss (SSO) that pairs cross-entropy with a margin-based separation loss to explicitly maximize the distance between perturbed features of different semantic classes. The theoretical foundation decomposes the perturbed embedding via first-order Taylor expansion into a Dominant Shift φ(δ) that displaces all inputs into an adversarial subspace, plus a Semantic Deflection J_δ·x^(c) where the Jacobian at δ acts as a linear semantic router, amplifying subtle input differences toward class-specific Proxy Target Embeddings. A feasibility bound (Theorem 3.4) shows the attack is infeasible when the Required Expansion Ratio between any target pair exceeds the global Lipschitz constant of the vision encoder, explaining why fine-grained semantics (small input distances) are harder to attack. The margin loss drives the confidence gap between the correct target and competing targets beyond a threshold, pushing perturbed features toward the centers of their respective target clusters rather than merely achieving basic classification.

## Results

On ImageNet with the frame constraint (6px width), SORT achieves 93% ASR on Qwen with 2 targets and 66% ASR with 5 targets, compared to 0% and 3% for the Image Hijacks baseline. On the fine-grained RIST dataset, SAUPs reach 72% average ASR on RoboTasking (2 targets) and 62% on AutoDriving (5 targets). Under the corner constraint (20×20 patches), SORT still achieves 98% ASR on Qwen (2 targets) and 45% (5 targets), while the baseline drops to 33% and 15% respectively. The attack generalizes across prompts, with Qwen maintaining ~74% average ASR over 10 diverse test prompts.

## Baselines & Comparisons

The sole baseline is Image Hijacks (Bailey et al., ICML 2024), which performs end-to-end pixel-space optimization to force a single target output. SORT (the proposed method) dramatically outperforms this baseline in nearly all settings. On Qwen with the frame constraint, the baseline achieves 0% test ASR with 2 targets and 3% with 5 targets, while SORT reaches 93% and 66% respectively — a gap of over 90 percentage points. On Llava, the baseline is similarly weak (0–11% test ASR), whereas SORT achieves 63–95%. The only setting where the baseline is competitive is Intern, where it already reaches 76–83% test ASR and SORT improves it by only 2–15 points. This suggests that the multi-target semantic routing capability (many-to-many mapping) is the key differentiator: the image hijacking baseline struggles to encode multiple distinct target bindings within a single perturbation, while SORT's semantic separation loss explicitly optimizes for this.

## Relation to Prior Work

This paper extends the universal adversarial perturbation (UAP) literature by introducing a many-to-many semantic-aware mapping: while prior UAPs (Moosavi-Dezfooli et al., 2017) achieve many-to-one targeting and MultiAttack (Fort, 2023) achieves many-to-many without universality, SAUPs combine both properties with input-semantic conditioning. The geometric decomposition via first-order Taylor expansion (Dominant Shift + Semantic Deflection) draws on Jacobian analysis from transferable adversarial example work (Liu et al., 2017) but applies it to a novel multi-target routing objective. The SORT algorithm's Normalized Space Optimization builds on reparameterization tricks from prior pixel-space attacks (Bailey et al., 2024; Vo et al., 2022), while the Semantic Separation margin loss is a new component explicitly motivated by the theoretical expansion-ratio bound.

## Why It Matters / Open Questions

The demonstration that a single 6-pixel frame can semantically route an MLLM to five distinct targets (66% ASR on Qwen) raises concrete safety concerns for stateless MLLM agents in autonomous driving and robotics, where sequential atomic decisions accumulate into physical trajectories. The counterintuitive finding that more advanced, better-aligned models (Qwen, Intern) are more vulnerable than Llava challenges the assumption that stronger vision-language alignment improves robustness. Key open questions include black-box transferability, physical-world robustness (lighting, motion blur), and whether the information-capacity bottleneck (ASR collapsing beyond ~8 targets) can be overcome with larger perturbation budgets or multi-frame strategies.

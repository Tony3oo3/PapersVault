## Problem

LLM-based multi-agent systems can fail even when all planned actions are executed correctly, because the planning agent assigns unwarranted confidence to feasibility assessments—a failure mode the paper terms epistemic miscalibration in planning. Unlike execution errors, this miscalibration is latent (plans appear coherent and executable with no observable error signals) and dynamic (newly acquired information shifts feasibility assessments, obscuring past miscalibration and causing it to recur). Prior repair methods target execution-level faults and rely on observable errors as supervision, leaving plan-level epistemic miscalibration unaddressed.

## Input / Output

The system receives a natural-language user query and iteratively acquires evidence through five external tools (base generator, Python coder, Google Search, Wikipedia Search, Web Search) over up to 10 interaction rounds. At each round, the Planner generates n=9 candidate next-step plans (goal + tool action) sampled at temperature 0.9, which are scored on a 1–5 feasibility scale by each agent. The final output is a single answer to the query, produced once the Diagnoser determines that accumulated verified evidence is sufficient; evaluation uses GPT-4o as an automatic judge against ground-truth answers.

## Method

EPC-AW is a role-specialized three-agent workflow (Planner, Executor, Diagnoser) where each agent maintains a private memory that induces heterogeneous information states. Within each round, Information-consistency-based Plan Selection (IPS) asks every agent to both evaluate candidate plans under its own information and predict how each peer would evaluate them; plans whose evaluations remain stable across these heterogeneous perspectives (measured via a log-ratio consistency score averaged over agents) are selected, treating cross-agent evaluation stability as a proxy for epistemic support rather than directly verifying feasibility. Across rounds, Consistency-guided Epistemic State Refinement (CESR) detects when the Planner's self-selected plan diverges from the IPS-selected plan, interprets this divergence as a miscalibration signal, and stores a lightweight epistemic constraint in the Planner's persistent memory to suppress recurrence of the same misjudgment pattern. The approach is training-free, built on Qwen3-Coder-30B via vLLM, and preserves the asymptotic time and token complexity of the base AgentFlow workflow while yielding a 9.75% average absolute improvement in system-level success across six benchmarks.

## Results

EPC-AW achieves the best accuracy on all six benchmarks, with an average system-level accuracy of 46.27%, yielding a 9.75% absolute improvement over the No-Repair (AgentFlow) baseline (36.52%) and a 4.64% gain over the strongest baseline, Rollback (41.63%). The largest per-benchmark gains are on 2Wiki (+12.83% over No-Repair) and HotpotQA (+12.67%), while the smallest is on MedQA (+7.00%). EPC-AW also generalizes across LLM backbones, achieving average improvements of 11.18% on Qwen3-14B and 11.13% on DeepSeek-R1-32B over No-Repair.

## Baselines & Comparisons

EPC-AW outperforms all three baselines on every benchmark. Against No-Repair (AgentFlow), which generates a single forward plan without any diagnosis or recovery, EPC-AW gains 7.00–12.83% in accuracy, with the largest margin on 2Wiki (+12.83%) and HotpotQA (+12.67%). Against Retry, which performs local metacognitive re-generation at the current planning step, EPC-AW leads by 3.11–6.66%, indicating that local replanning alone is insufficient when the underlying epistemic miscalibration persists. Against Rollback, which reverts the entire system state to a historical step before re-planning, EPC-AW still wins by 2.55–5.86%, showing that even global state recovery cannot fully address plan-level miscalibration. The paper attributes the gap to the fact that both Retry and Rollback rely on agent-generated diagnosis signals that are themselves subject to the same epistemic miscalibration they attempt to correct, whereas EPC-AW intervenes directly at planning time via cross-agent consistency (IPS) and persistent memory constraints (CESR).

## Relation to Prior Work

This paper builds directly on the AgentFlow multi-agent architecture (Li et al., 2026), adopting its Planner-Executor-Diagnoser role structure, tool interface, and evaluation protocol as the substrate for its contributions. It departs from prior failure-repair work (MAST/Retry, COCO/Rollback) by shifting the intervention point from execution-time correction to planning-time epistemic calibration, arguing that a distinct failure mode—miscalibrated feasibility assessments—persists even when all executions are locally correct. Conceptually, the cross-agent consistency mechanism draws on peer prediction and Bayesian truth inference (Witkowski & Parkes, 2012; Chen et al., 2025), but adapts these ideas to a dynamic, multi-round agentic setting without external payoff signals or static game-theoretic assumptions.

## Why It Matters / Open Questions

Identifying epistemic miscalibration as a latent, dynamic planning-level failure mode reframes how practitioners should diagnose multi-agent system failures: existing debugging and rollback tools that target execution errors will miss plans that are internally coherent yet infeasible. The finding that IPS alone degrades performance on search-intensive tasks (2Wiki drops ~15 points) while CESR corrects this conservatism highlights that naive consistency-based selection is insufficient without memory-driven constraint accumulation. Open questions include whether the heterogeneous-information requirement generalizes to architectures where agents share identical context, whether the memory-driven constraints scale to very long horizons without degradation, and whether the approach transfers to settings with non-LLM agents or structured verifiers.

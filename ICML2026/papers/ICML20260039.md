## Problem

Predictive auto-completion for spreadsheets lacks both a benchmark dataset and an evaluation framework, unlike the well-studied code completion setting. Two obstacles make this hard: public spreadsheet corpora contain only static snapshots without edit histories, and the action space is complex (spatial, temporal, composite) with no clear trigger for when to predict. This paper introduces the first benchmark and online evaluation framework for next-action prediction in spreadsheets.

## Input / Output

The system receives a sequence of past user operations (e.g., fill(A1, green), border(A1:C3, all, thin)) and the current spreadsheet state, and outputs a sequence of zero or more predicted operations in the same symbolic format. For LLM solvers, operations are rendered as pipe-delimited text (OPERATION | RANGE | VALUE); for classical solvers, they are parsed into structured feature tuples (op-type, range geometry, value-type bucket). The evaluation is online and iterative: after each prediction is accepted or rejected, the remaining ground-truth actions are dynamically adapted (satisfied ops removed, inverses prepended for false positives), so the input context evolves non-trivially across the trajectory.

## Method

The paper contributes a 52-trajectory dataset (11,907 operations) built via a three-stage pipeline: symbolic cold-start generation from static workbooks (decomposing final states into cell-level ops, merging into range actions, sampling preference settings for diversity), LLM-based judge-editor refinement to fix unnatural patterns, and human annotation (mean normalized edit distance 0.69 from pre-annotation). The core evaluation is an online loop that, at each trigger, invokes the solver to predict actions, applies an acceptance heuristic (combining precision and user-actions-saved thresholds), and adapts the ground-truth future by removing satisfied operations, prepending inverse operations for false positives, and patching residual discrepancies to guarantee the target state is still reachable. Metrics are computed at three granularities: per (cell, property) pair (TP/FP/FN/MM), per prediction (precision, user actions saved), and per full trajectory (UAS, acceptance rate, predictability coverage normalized by an oracle upper bound). Baselines span zero-shot LLMs (GPT-5 family), fine-tuned SmolLM2 models (135M/360M), and classical sequence predictors (n-gram, GRU, XGBoost), evaluated under both multi-action and single-action-repredict settings with varied stride, context window, and acceptance heuristics.

## Results

On the NAPE benchmark (52 trajectories, 11,907 operations), the strongest zero-shot model GPT-5-R achieves 32.7% User Actions Saved (UAS) in single-action repredict and 26.6% in multi-action prediction, while GPT-5 (non-reasoning) reaches 27.4% and 22.3% respectively. Fine-tuning SmolLM2-360M on synthetic operation sequences lifts UAS from 21.7% to 26.8%, nearly matching GPT-5 despite being ~1000× smaller. An oracle experiment establishes that 68% of all ground-truth (cell, property) pairs are in principle predictable from editing history, setting a theoretical ceiling. The ALWAYS acceptance heuristic (accepting every prediction) yields strongly negative savings of −19.2% UAS at only 9.3% precision, confirming that abstention is critical for net user benefit.

## Baselines & Comparisons

The paper evaluates three solver families: zero-shot LLMs (GPT-5-R, GPT-5-R mini, GPT-5, GPT-5 mini), fine-tuned small language models (SmolLM2-135M/360M), and classical sequence models (LSTM, trained n-gram, XGBoost, online n-gram). GPT-5-R leads with 32.7% UAS, followed by GPT-5-R mini (28.2%) and GPT-5 (27.4%); the fine-tuned FT-SmolLM2-360M (26.8%) nearly matches GPT-5 despite being orders of magnitude smaller, demonstrating the task is learnable with domain-specific training. Among classical models, the training-free online n-gram (12.0% UAS) substantially outperforms the trained LSTM (5.7%), trained n-gram (3.8%), and XGBoost (2.9%), suggesting local repetition patterns are the most exploitable signal without learned representations. In the multi-action setting (Table 4), GPT-5-R achieves 26.6% UAS versus GPT-5's 22.3%, while GPT-5 mini drops to 20.1%, showing a consistent capability gradient. The ALWAYS acceptance heuristic (accepting all predictions) produces −19.2% UAS, far worse than no prediction at all, highlighting that precision-based abstention is essential and that current LLMs lack native stopping/abstention behavior.

## Relation to Prior Work

This paper carves out a new problem space at the intersection of modeless code completion (Blue-Pencil, IntelliCode, Copilot) and spreadsheet automation (FlashFill, SpreadsheetCoder, SheetCopilot), but departs from all of them: prior spreadsheet assistants either require explicit user invocation (FlashFill's column trigger, SpreadsheetCoder's formula signal, SheetCopilot's NL prompt) or operate at a coarser granularity (column-level string transformations vs. cell-level UI actions). The conceptual lineage from code auto-completion is direct—observing a sequence of edits and predicting the next—but the action space (spatial, temporal, composite formatting operations) and the absence of edit histories in public corpora make it a distinct challenge. The online evaluation framework draws on interactive evaluation literature from recommender systems and information retrieval, where offline metrics diverge from actual user utility due to state-modifying feedback loops.

## Why It Matters / Open Questions

This is the first benchmark for modeless spreadsheet action prediction, a task that prior work implicitly assumes is too complex to evaluate (no edit histories, no clear prediction triggers, compound action space). The online evaluation with dynamic ground-truth adaptation is a methodological contribution transferable to any interactive, state-modifying prediction setting. Key open questions remain: how to build cheap per-action triggers (stride s=1 vs s=8 halves UAS), how to teach models explicit abstention (ALWAYS acceptance yields −19% UAS), and whether the 52-trajectory, single-sheet scope generalizes to multi-sheet workbooks with formulas. The finding that a fine-tuned 360M model matches GPT-5 suggests the task is learnable at small scale, but the dataset is small enough that this claim warrants replication.

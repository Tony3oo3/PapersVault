## Problem

The widespread adoption of LLMs has fueled industry claims that natural language could entirely replace formal languages such as programming languages. This paper argues that such claims overlook a fundamental information-theoretic limitation: natural language is optimized for underspecification in open-ended contexts, making it structurally inefficient for high-specificity tasks in restricted domains. The gap is the absence of a formal framework that quantifies when and why each modality dominates, and whether current limitations are engineering hurdles or inherent constraints.

## Input / Output

The framework takes a task T represented as a tuple of explicit constraints C_exp, implicit constraints C_imp, and an output space M (the 'world model'), along with a natural language utterance u describing the task. It produces a specificity crossover threshold σ* = H(Y) + R_formal − Δ_trans that partitions the task space into regimes where natural language or formal specification is more efficient, along with lower bounds on the minimum description length required by each path. The output space M can span arbitrary modalities (images, code, audio, text), and the framework treats the actual output format itself as the formal language, so the 'formal path' is simply direct specification in the target modality.

## Method

The paper introduces a 'ladder of specification' hierarchy (overspecification → full specification → pragmatic underspecification → indifferent underspecification) grounded in linguistic pragmatics, then formalizes tasks as constraint satisfaction problems where a task's denotation is the set of outputs satisfying all explicit and implicit constraints. The key mechanism is the 'translation gap' Δ_trans = D_KL(p_M ‖ p_NL), the KL divergence between the domain-specific output distribution and the general natural language distribution, which quantifies the irreducible overhead of using a general-purpose language for domain-specific specification. By modeling the natural language path as a Markov chain Y → T → U → Ŷ and applying the Data Processing Inequality, the authors derive a lower bound L_NL(σ) ≥ σ + Δ_trans on the description length needed to achieve task specificity σ. The main result—the Specificity Crossover Theorem—then shows that for σ ≥ σ* = H(Y) + R_formal − Δ_trans, formal specification is necessarily more efficient, while below this threshold natural language can exploit underspecification to be shorter. The framework is validated through case studies in image generation (where iterative prompting verbosity and 'magic words' empirically confirm the crossover), code generation (where production requirements push specificity above the threshold), and audio and text generation.

## Results

The paper's central result is Theorem 3.10 (Specificity Crossover), which proves the existence of a threshold σ* = H(Y) + R_formal − Δ_trans separating regimes where natural language is more efficient (σ < σ*) from those where formal specification dominates (σ ≥ σ*). A supporting Lemma 3.6 shows the expected translation gap decomposes as D_KL(p̄‖p_NL) + JSD(D), meaning greater domain diversity increases the irreducible NL overhead. As a quantitative illustration, fully specifying a 250×250 RGB image (2^1,500,000 possibilities) in a 32-character alphabet requires ≥300,000 characters—comparable to a novel—demonstrating the practical infeasibility of pushing NL prompts toward full specification.

## Baselines & Comparisons

This is a position paper with a theoretical framework rather than an empirical study, so no empirical baselines are compared. The paper's 'comparison' is between two specification paths: the natural language path (Y → T → U → Ŷ) and the formal language path (Y → Ŷ). Theoretically, NL wins at low task specificity through underspecification (avoiding the cost of specifying irrelevant details), while formal language wins at high specificity by incurring zero translation gap (Δ_trans = 0) and operating at full specification. The paper validates this crossover qualitatively across four modalities (images, code, audio, text) by citing empirical trends—e.g., Don-Yehiya et al. (2023) showing increasing prompt verbosity in Midjourney iterations, and the Stack Overflow 2025 survey showing 46% active distrust vs. 33% trust in AI code tools—but does not run its own experiments or benchmark against specific competing methods.

## Relation to Prior Work

This position paper synthesizes three research traditions—linguistic pragmatics (QUD, Gricean implicature, RSA framework), information theory (KL divergence, data processing inequality, rate-distortion), and formal language theory—into a unified constraint-satisfaction framework that had not previously been formalized together. It departs from the informal but long-standing software-engineering position (Dijkstra 1978, Meyer 1993, Wing 2002) that formal and natural languages are complementary by providing an explicit information-theoretic criterion (the specificity crossover threshold σ*) for when each modality dominates. The empirical grounding draws on iterative prompting studies (Don-Yehiya et al. 2023) and code-generation surveys (Jiang et al. 2024, Joel et al. 2024) rather than introducing new experiments.

## Why It Matters / Open Questions

The paper provides a principled theoretical justification for hybrid NL/formal-language systems and argues that current code-generation benchmarks (HumanEval, SWE-bench) mischaracterize task difficulty by testing implementation rather than specification understanding. Key open questions include: how to estimate the translation gap Δ_trans for a given domain in practice, how iterative refinement (which the one-shot analysis assumes away) shifts the crossover threshold, and how to design evaluation protocols that compare NL+AI generation against code-completion assistance across the specificity spectrum. The framework's main limitation is that it yields lower bounds and a threshold formula whose parameters (R_formal, Δ_trans) are difficult to measure empirically for real-world domains.

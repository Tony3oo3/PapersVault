## Problem

Traditional e-commerce search systems rely on multi-stage cascading architectures (recall → pre-ranking → ranking) that suffer from two fundamental limitations: fragmented computation (most resources spent on inter-stage communication and storage rather than model inference) and objective collision (heterogeneous optimization goals across stages cause relevant items to be irreversibly discarded early). No prior work has unified all three stages into a single end-to-end generative model specifically for e-commerce search, where noisy item descriptions, strict query-item relevance constraints, and latent intent inference from concise queries pose unique challenges distinct from recommendation.

## Input / Output

The model consumes a behavior-constructed user ID (weighted concatenation of short/long sequence SIDs with exponential decay), the entered query and its SID, explicit short behavior sequences (recent queries and clicked items as SID tokens in the prompt), implicit long behavior sequence embeddings (aggregated RQ centroid lookups across click/order/RSU sequences compressed via a QFormer), and a platform-fitted user profile. Output is a sequence of item SIDs (5 tokens: 3 RQ-Kmeans codes + 2 OPQ codes) generated via beam search (size 512), which are mapped back to a ranked item list. The long sequence is never fed as raw text but as a fixed-size embedding vector, keeping the prompt length manageable regardless of sequence length (up to 10³ items).

## Method

OneSearch employs a BART-based encoder-decoder that directly generates item SIDs, replacing the entire MCA pipeline. The key encoding innovation is RQ-OPQ tokenization: RQ-Kmeans (4096-1024-512) captures hierarchical semantic structure while OPQ (256-256) quantizes the residual to preserve distinctive item attributes, with core keyword enhancement (18 NER-extracted attributes via Qwen-VL) injected into embeddings before quantization to counter noisy promotional text. Training follows a four-stage procedure: (1) semantic alignment between SIDs and text via contrastive and reconstruction losses, (2) query-item co-occurrence synchronization, (3) user personalization with sliding-window data augmentation, and (4) adaptive reward-weighted list-wise DPO using a three-tower SIM reward model that scores CTR/CVR/CTCVR plus an amplified relevance term. The reward system uses calibrated CTR/CVR (log-smoothed to handle exposure bias) and a two-phase RL strategy: periodic reward-model-guided updates for distribution adherence, plus near-streaming user-interaction updates to overcome MCA feature limitations.

## Results

On the Kuaishou Mall Search dataset (30k order pairs, 30k click pairs), OneSearch (RQ-OPQ 2/256 + Adaptive Reward System) achieves 66.46% HR@350 and 18.38% MRR@350 for orders, and 71.06% HR@350 and 16.33% MRR@350 for clicks, surpassing the production OnlineMCA system (51.74% / 19.26% for orders; 64.40% / 16.89% for clicks) on recall while maintaining comparable ranking precision. Online A/B tests confirm statistically significant gains of +1.67% item CTR, +2.40% buyer volume, and +3.22% order volume. The system also reduces operational expenditure by 75.40% and improves Model FLOPs Utilization from 3.26% to 27.32% (an 8.4× improvement).

## Baselines & Comparisons

The paper's tokenizer-level comparison (Table 7) pits RQ-OPQ against RQ-VAE [Lee et al., CVPR 2022] and RQ-Kmeans [Luo et al., CIKM 2025]. RQ-OPQ achieves 0.3369 Recall@10 and 0.1194 MRR@10, substantially outperforming RQ-VAE (0.2171 / 0.0689) by +55% recall and +73% MRR, and beating RQ-Kmeans (0.2844 / 0.1038) by +18% recall and +15% MRR. Both baselines fall well short of the production OnlineMCA system (0.3440 / 0.1323), confirming that hierarchical quantization alone is insufficient without the full OneSearch pipeline. At the system level (Table 2), the complete OneSearch model surpasses OnlineMCA on HR@350 for both orders (+14.72 pp) and clicks (+6.66 pp), while MRR@350 is slightly lower for orders (18.38% vs. 19.26%) but competitive for clicks (16.33% vs. 16.89%), demonstrating that the unified generative approach recovers the recall lost to MCA's objective collision without sacrificing ranking quality.

## Relation to Prior Work

This paper extends the generative retrieval (GR) paradigm from recommendation (Tiger, OneRec) to e-commerce search, where it must additionally handle noisy item descriptions, strict query-item relevance constraints, and intent inference from 2-3 keyword queries. It builds directly on OneRec's stage-unification philosophy and OneSug's adaptive reward-weighted ranking, but departs from both by introducing keyword-enhanced hierarchical quantization (RQ-Kmeans + OPQ) specifically to preserve distinctive item attributes that standard semantic ID tokenizers discard, and by separating explicit short-sequence prompting from implicit long-sequence embedding aggregation. The theoretical analysis of RQ-OPQ information preservation (mutual information chain rule, discrimination dominance) provides formal grounding absent from prior GR tokenization work.

## Why It Matters / Open Questions

OneSearch demonstrates that a single generative model can replace an entire multi-stage cascading pipeline (recall → pre-ranking → ranking) in production e-commerce search while improving business metrics and cutting operational costs by 75%, offering a concrete architectural blueprint for the industry. Key open questions include: whether the reward model's dependence on MCA training data creates a performance ceiling, whether real-time encoding can close the gap between scheduled tokenization and streaming inference, and whether the approach generalizes beyond Kuaishou's specific item taxonomy and query distribution. The paper is explicitly framed as a 'preliminary exploration,' and the authors note that multi-modal features and more robust RL remain unexplored.

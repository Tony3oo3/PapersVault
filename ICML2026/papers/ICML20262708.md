## Problem

Automating text-to-SVG animation generation remains largely unexplored because naive autoregressive frame-by-frame SVG code generation suffers from context explosion and identity drift, while existing alternatives either destroy topological consistency (optimization-based methods like LiveSketch) or are restricted to rigid affine transforms via CSS/SMIL (general-purpose LLMs), making geometry-level non-rigid deformations unreachable. No large-scale, structurally rigorous dataset for vector animation existed to support training.

## Input / Output

The model takes three inputs: the initial static SVG code S₀, its rendered raster image I₀ at 500×500 resolution, and a natural-language instruction P. Rather than outputting full SVG frames, VAnim produces a sequence of sparse state updates Δ₁…Δ_T, where each update is a set of (node_id, attribute, new_value) tuples for only the attributes that changed relative to the previous frame. This differential format, serialized with special control tags (|time=t|, |ID=id|), achieves a 9.86× token compression over naive frame-by-frame generation (9.2k vs. 86k tokens for 24 frames) and guarantees that non-participating DOM nodes remain untouched by construction.

## Method

VAnim is built on Qwen3-VL-8B-Thinking and reformulates animation as Sparse State Updates on a persistent SVG DOM tree. Inference follows a coarse-to-fine two-stage paradigm: first, an Identification-First Motion Planning stage (Structure-Bound CoT) explicitly grounds textual entities to persistent SVG IDs and plans their temporal behavior; second, a Sparse State Update Execution stage predicts only the attribute differentials for targeted nodes, preserving topology by construction. Training is two-stage: Stage I performs full-parameter SFT on 123k samples for SVG syntax and ID anchoring; Stage II applies GRPO (Group Relative Policy Optimization, G=8) with a hybrid reward combining PE-Core video-text cosine similarity (semantic alignment) and a binary format-validity signal (parseability, correct frame count, valid IDs). The RL stage closes the perception-action loop by rendering each candidate animation via a headless Playwright browser at 500×500 and scoring it with the PE-Core-G14-448 perception encoder, directly incentivizing fine-grained path-data (d attribute) manipulation over restricted affine transforms.

## Results

On the SVGAnim-Test set, VAnim (GRPO) achieves a state-of-the-art Semantic Alignment score of 0.281 (PE-Core cosine similarity) and a perfect 100% Success Rate, outperforming all baselines. The SFT-only variant reaches 0.268 alignment with 95.2% success rate, confirming that the Rendering-Aware RL stage contributes an additional +0.013 in semantic fidelity and +4.8% in executability. In the expanded evaluation (Table S1), VAnim also leads on the independent InternVideo2 metric (0.202), motion magnitude (1.711), temporal smoothness (flow_tLPIPS 0.0117), and identity preservation (SSIM 0.9719).

## Baselines & Comparisons

VAnim (GRPO) outperforms all five baselines on Semantic Alignment, achieving 0.281 versus Gemini 3 Pro (0.243), GPT-5.2 (0.234), and LiveSketch (0.158). On executability, VAnim matches LiveSketch, AniClipart, and FlipSketch at 100% Success Rate, while substantially exceeding GPT-5.2 (88.5%) and Gemini 3 Pro (86.2%), whose free-form generation frequently produces unclosed tags or hallucinated attributes. In the expanded Table S1, VAnim also leads on the independent InternVideo2 metric (0.202 vs. 0.182 for Gemini 3 Pro and 0.180 for GPT-5.2), motion magnitude (1.711 vs. 1.696 for FlipSketch), and identity preservation (SSIM 0.9719 vs. 0.9634 for Gemini 3 Pro). The optimization-based baselines (LiveSketch, AniClipart, FlipSketch) suffer from topological instability and low semantic scores, while the LLM baselines (GPT-5.2, Gemini 3 Pro) default to rigid affine transforms and fail to execute non-rigid path-level deformations.

## Relation to Prior Work

This paper departs from two main lineages: (1) optimization-based vector animation (LiveSketch, FlipSketch, AniClipart) that uses iterative SDS/differentiable rendering on unstructured strokes, and (2) LLM-based static SVG generation (OmniSVG, SVGen, Chat2SVG) that handles spatial composition but not temporal dynamics. It also moves beyond declarative CSS/SMIL animation frameworks (Keyframer) that are mathematically restricted to affine transforms. The core conceptual departure is reframing animation as Sparse State Updates on a persistent SVG DOM tree rather than frame-by-frame code regeneration, combined with GRPO (Shao et al., 2024) and PE-Core video perception to close the code-to-rendering loop.

## Why It Matters / Open Questions

VAnim establishes the first open-domain, structure-preserving text-to-SVG animation pipeline and the first large-scale benchmark (SVGAnim-134k) for this task, filling a clear gap between static vector generation and pixel-based video synthesis. The SSU paradigm (9.86× compression with *improved* quality) is a transferable insight for any structured sequential code generation where most tokens are static. Key limitations remain: the persistent-DOM assumption precludes topology changes (node insertion/deletion), the data is single-source (Lottie-derived), and the RL stage incurs significant rendering overhead. Extending to interactive behaviors (JavaScript triggers) and multi-scene narratives are identified as open frontiers.

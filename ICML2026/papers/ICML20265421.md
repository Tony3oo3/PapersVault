## Problem

Existing evaluation methods for diffusion model image watermarking lack a unified framework spanning both residual and semantic paradigms, produce purely numerical scores without interpretability, neglect security dimensions such as erasure-attack robustness, and rely on image-space metrics (FID, LPIPS) that conflate inherent diffusion stochasticity with watermark-induced degradation for semantic watermarks.
![Teaser figure](../imgs/ICML20265421/cropped_page0_idx0.webp)

## Input / Output

WMVLM takes a single watermarked AI-generated image (produced by Stable Diffusion v2.1 or v1.4) as input and produces a structured multi-part response: a free-form reasoning paragraph enclosed in  tags, a watermark category label in <type> tags (residual / semantic-with-ring-patterns / performance-lossless), a quality score in <quality> tags (continuous [1,5] for residual, discrete {1,2,3} for semantic), and security scores in <jpeg>/<gaussian>/<filter> binary tags for residual or a single <security> discrete tag for semantic. The output format is enforced by a strict format reward during GRPO training, where any structural deviation incurs a penalty of −10.

## Method

WMVLM builds on Qwen3-VL-8B Instruct and is trained via a three-stage pipeline: (1) supervised fine-tuning to classify watermark type and emit quality/security scores using type-specific templates; (2) a knowledge-distillation cold start where Gemini-2.5-Pro generates post-hoc explanatory text conditioned on the image and ground-truth labels, teaching the student model to produce interpretable reasoning; (3) Group Relative Policy Optimization (GRPO, G=8, β=0.1) with a composite reward over format compliance, category correctness, response length, quality accuracy, and security accuracy to break SFT pattern rigidity and improve generalization. The key metric redefinition is that residual watermark quality maps to PSNR normalized to [1,5] and security to binary robustness against JPEG/Gaussian/median-filter OSN distortions, while semantic watermark quality and security are both derived from p-values of Cramér-von Mises, Jarque-Bera, and D'Agostino's K² hypothesis tests comparing watermarked latent distributions against N(0,I), discretized into three levels.

## Results

On the main evaluation (SD v2.1, Stable-Diffusion Prompts-2.47M), WMVLM achieves PLCC/SRCC of 0.952/0.957 on DwtDct, 0.983/0.986 on VINE, and 0.981/0.985 on Stable Signature for residual watermark quality, with security accuracy reaching 98.8–100% across all six residual methods. For semantic watermarks, WMVLM attains 85.2% accuracy on RingID, 95.6% on Tree-Ring, and 91.0% on the Lossless category for both quality and security. Cross-dataset (MS-COCO) and cross-model (SD v1.4) evaluations confirm strong generalization, with only a ~10% drop on RingID and a notable PLCC decrease (~0.6) on Stable Signature under architectural changes.

## Baselines & Comparisons

WMVLM decisively outperforms all 11 baseline VLMs across every watermarking method and evaluation metric. Among closed-source models, GPT-5 achieves the highest residual PLCC (0.211 on RW) but remains far below WMVLM (0.961), and its semantic accuracy peaks at only 0.716 (Lossless) versus WMVLM's 0.910. Gemini-3-Pro is the strongest closed-source baseline on semantic watermarks (0.716 Lossless) yet still trails WMVLM by ~20 points. Among open-source models, Qwen3-VL-8B (the same backbone as WMVLM) shows the highest zero-shot residual PLCC (0.953 on RW) but near-zero security accuracy (0.004), while Qwen3-VL-4B reaches 0.890 on Lossless semantic accuracy—still below WMVLM's 0.910. LLaVA-v1.6 and Gemma-3 variants consistently produce near-random or negative correlations on residual quality and negligible semantic accuracy, confirming that general-purpose VLMs lack the specialized watermark perception that WMVLM's three-stage training provides.

## Relation to Prior Work

This paper sits at the intersection of diffusion-model watermarking (residual methods like HiDDeN, VINE, Stable Signature; semantic methods like Tree-Ring, RingID, Gaussian Shading) and VLM-based image assessment. It departs from WMarkGPT, which introduced VLM interpretability for visible watermarks but did not address diffusion-model-specific watermarks or security evaluation. Methodologically, it repurposes the standard SFT-then-RL post-training pipeline (here SFT → knowledge distillation from Gemini-2.5-Pro → GRPO) for a structured scoring-and-explanation task, and redefines semantic watermark quality/security via hypothesis testing on latent distributions rather than image-space metrics like FID or LPIPS.

## Why It Matters / Open Questions

WMVLM provides the first unified, interpretable evaluation protocol covering both residual and semantic watermarks, which is practically important for the watermarking community that has lacked a common yardstick across paradigms. The redefinition of semantic watermark quality via p-values from Cramér-von Mises, Jarque-Bera, and D'Agostino tests against N(0,I) is a clean methodological contribution that avoids conflating diffusion stochasticity with watermark-induced distortion. Key limitations include dependence on SFT data preparation, sensitivity to diffusion-model architecture changes (Stable Signature PLCC drops ~0.6 from SD v2.1 to v1.4), and evaluation restricted primarily to Stable Diffusion. Open questions include whether the framework extends to video or 3D generation, whether SFT can be eliminated entirely via pure RL, and whether the three-level discrete scale for semantic watermarks is granular enough for fine-grained method comparison.

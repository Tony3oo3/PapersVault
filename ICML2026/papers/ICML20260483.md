## Problem

Diffusion model samplers based on score evaluations alone have only achieved polynomial (1/δ) or sub-polynomial dependence on target accuracy, because discretization error in SDE solvers precludes high-accuracy guarantees. The open question is whether a sampler can achieve polylog(1/δ) complexity—exponential convergence—using only first-order score queries, without access to the unnormalized density that standard accept-reject methods require.

## Input / Output

The algorithm consumes approximate score functions s_t with controlled L² error, a diffusion schedule (α_t, η_t), and an initial sample from the terminal noise distribution N(0, σ_T²I). Unusually, each reverse step requires a random (Poisson-distributed) number of score evaluations at intermediate points along a path, not just at the current state, and the total number of queries per step is bounded with high probability by O(B e^{2B} log(1/δ)). The output is a sample from the early-stopped distribution p_1 with guaranteed δ-error in the bounded Lipschitz metric, or from p_data itself by choosing σ_0 ≈ δ/√(d+M₂²).

## Method

The core contribution is FORS (First-Order Rejection Sampling), a meta-algorithm that simulates rejection sampling using only gradient queries via a Bernoulli factory construction: instead of evaluating the tilt function w(x) directly, it draws a Poisson(2B) number of unbiased estimates W_j of w(x) and accepts with probability ∏(B+W_j)/(2B), which equals e^{E[W_1|x]−B}. For diffusion sampling, the backward transition kernel is a Gaussian tilt, and FORS is instantiated at each reverse step with a Gaussian proposal q_t and path-based estimators W_{r,z,x} = ⟨γ̇_{z,r}(x), s_t(γ_{z,r}(x)) − s_t(x̄_t)⟩ evaluated along sinusoidal paths γ_{z,r}(x) = a_r x + (1−a_r)x̄_t + b_r z, clipped to [−B,B] for boundedness. This yields the first polylog(1/δ) sampler for diffusion models under minimal assumptions (finite second moment), with improved √dL dependence under non-uniform Lipschitz score conditions and d_★ dependence for low-intrinsic-dimension data. The same FORS subroutine, applied to the restricted Gaussian oracle in the proximal sampler, also gives the first polylog(1/δ) log-concave sampler using only gradient evaluations.

## Results

The paper establishes the first polylog(1/δ) complexity guarantees for diffusion model sampling using only score evaluations. Under minimal assumptions (finite second moment M₂²), the query complexity is Õ(d · polylog(1/δ)) in the bounded Lipschitz metric; under a non-uniform L-Lipschitz condition, it improves to Õ(√(dL) · polylog(1/δ)); and for data with intrinsic dimension d⋆, it further reduces to Õ(d⋆ · polylog(1/δ)). The framework also yields the first polylog(1/δ) sampler for general log-concave distributions using only gradient (first-order) evaluations, recovering state-of-the-art results from Fan et al. (2023) without requiring density evaluations.

## Baselines & Comparisons

The paper's FORS algorithm achieves an exponential improvement over all prior diffusion sampling results in the dependence on target accuracy δ. Prior works by Chen et al. (2023c) and Lee et al. (2023) achieved O(1/δ²) complexity, Li & Cai (2024) improved this to O(1/δ^{1/2}), and higher-order discretization methods (Huang et al., 2025a,b; Li et al., 2025b) achieved roughly O(d^{1+1/p}/δ^{1/p}) with implicit exponential dependence on the order p — all still polynomial in 1/δ. FORS reduces this to polylog(1/δ), which is the first high-accuracy guarantee using only score evaluations. Compared to concurrent work by Gatmiry et al. (2026), which also achieves polylog(1/δ) but requires stronger assumptions (Gaussian-convolution data, sub-exponential score error tails, Lipschitz score estimates), FORS operates under minimal assumptions (finite second moment) and standard L² score error. The concurrent lower bound of X̃Ω(√d) from Xun & Price (2026) leaves a gap of at most X̃O(√d) with the paper's X̃O(d) upper bound under minimal assumptions. For log-concave sampling, FORS matches the complexity of Fan et al. (2023) and Altschuler & Chewi (2024) but eliminates the need for zeroth-order (density) queries, which prior high-accuracy methods (rejection sampling, Metropolis-Hastings) require.

## Relation to Prior Work

This paper introduces FORS (First-Order Rejection Sampling), a meta-algorithm that simulates rejection sampling using only gradient queries, drawing on the Bernoulli factory construction (Keane & O'Brien, 1994; Nacu & Peres, 2005) to generate acceptance decisions from unbiased estimates of a tilt function without computing it directly. For diffusion sampling, it departs fundamentally from prior approaches (DDPM, higher-order ODE solvers) that achieve at best poly(1/δ) complexity, by showing that the rejection-sampling mechanism—which naturally yields high-accuracy guarantees—can be implemented with score evaluations alone. For log-concave sampling, it builds on the proximal sampler (Lee et al., 2021; Chen et al., 2022) by implementing its restricted Gaussian oracle step via FORS, eliminating the need for zeroth-order density evaluations that prior high-accuracy methods (Huang et al., 2024a; Wainwright, 2025) required.

## Why It Matters / Open Questions

This is the first polylog(1/δ)-complexity sampler for diffusion models using only score evaluations under minimal data assumptions (finite second moment), an exponential improvement over all prior results, and the first such guarantee for general log-concave distributions with gradient-only access. The practical path is less clear: FORS requires logarithmically many score evaluations per step, step-size conditions may be conservative, and the paper provides no empirical validation. Key open questions include closing the Õ(√d) gap between the upper and lower bounds on query complexity, extending high-accuracy guarantees to ODE-based samplers like DDIM, and translating the theoretical framework into a computationally competitive practical method.

## Problem

Prior theoretical results on in-context nonparametric regression with transformers (Kim et al., 2024; Shen et al., 2025) require polynomially many transformer parameters in the number of in-context examples n to achieve minimax optimal rates, leading to restrictive lower bounds on the number of pretraining sequences. This paper asks whether transformers can attain the minimax rate n^{-2α/(2α+d)} for α-Hölder regression with far fewer parameters, and shows that only Θ(log n) parameters and Ω(n^{2α/(2α+d)} log³ n) pretraining sequences suffice.

## Input / Output

The transformer receives n in-context (covariate, response) pairs and a query covariate, all embedded into an (n+1)×d_e matrix where covariates occupy the first d columns, responses occupy column d+1, and the query row is flagged by a 1 in the final column (no positional encoding beyond this indicator). The prediction is read from row n+1, column d+1 of the transformer output and truncated to [-M, M] to match the bounded regression function class. The embedding dimension is d_e = 2d + 2D + 5 where D = C(d+p, p) is the number of monomial basis terms.

## Method

The key insight is that a single-head linear-attention transformer with Θ(log n) layers can approximate a local polynomial estimator by (i) using three blocks to compute centred/scaled covariates (X - X_{n+1})/h and the square root of the kernel matrix (exploiting the piecewise-linear square root of K(x) = (1-||x||_1)_+²), (ii) using Θ(log n) ReLU FFN blocks to approximate the monomial basis P_h via the exponential polynomial approximation rate of deep ReLU networks (Lu et al., 2021), and (iii) using Θ(log n) additional blocks to run gradient descent (implemented via linear attention, following Bai et al., 2023) on the resulting strongly convex weighted least-squares problem. The transformer is trained by empirical risk minimisation over Γ pretraining sequences, and minimax optimality is established by bounding the covering numbers of the Θ(log n)-parameter transformer class and applying standard empirical process theory, yielding the excess risk bound O(n^{-2α/(2α+d)}).

## Results

The main theoretical result (Theorem 3.2) establishes that a pretrained transformer with only Θ(log n) parameters and Γ = Ω(n^{2α/(2α+d)} log³ n) pretraining sequences achieves the minimax optimal rate O(n^{-2α/(2α+d)}) in mean squared error for α-Hölder smooth regression functions. In the simulation (Section 5, d=3, α=3, σ=0.01, n∈{15,…,35}), the pretrained linear-attention transformer (d_e=256, d_ffn=1024, L=12 blocks) outperforms a local cubic polynomial estimator with bandwidth and ridge penalty selected via 5-fold cross-validation, while exhibiting a similar dependence on n. The approximation theorem (Theorem 3.1) shows the transformer's excess risk over the local polynomial estimator is O(1/n), which is negligible relative to the minimax rate.

## Baselines & Comparisons

In the simulation, the pretrained transformer achieves lower estimated excess risk than the local cubic polynomial estimator across all sample sizes n∈{15,20,25,30,35}, with both methods showing similar scaling with n. Theoretically, this paper substantially improves on prior in-context regression results: compared to Shen et al. (2025), which requires Θ(n) transformer parameters and Γ=Ω(n^{(6α+d)/(2α+d)} log n) pretraining sequences, and Kim et al. (2024), which requires Θ(n^{d/(2α+d)}) parameters and Γ=Ω(n^{(2α+2d)/(2α+d)} log n) pretraining sequences, this work needs only Θ(log n) parameters and Γ=Ω(n^{2α/(2α+d)} log³ n) pretraining sequences. The key advantage comes from using gradient descent within the transformer (via attention layers) to solve the local polynomial least-squares problem, combined with ReLU FFNs to approximate the monomial basis, rather than explicitly encoding the full estimator in the network weights.

## Relation to Prior Work

This paper extends the line of work on provable in-context nonparametric regression with transformers, most directly building on Kim et al. (2024) (B-spline wavelet basis) and Shen et al. (2025) (Nadaraya-Watson approximation). The key departure is a new approximation strategy: rather than encoding the full estimator in the network weights (requiring polynomially many parameters in n), the transformer constructs a kernel-weighted monomial basis and then runs Θ(log n) steps of gradient descent via attention layers, leveraging the results of Bai et al. (2023) and von Oswald et al. (2023) on transformers as gradient descent implementers, and Lu et al. (2021) on exponential polynomial approximation by ReLU networks. This reduces the parameter requirement from Θ(n^{d/(2α+d)}) or Θ(n) to Θ(log n), a substantial efficiency gain.

## Why It Matters / Open Questions

The result establishes that minimax optimal in-context nonparametric regression is achievable with only logarithmically many transformer parameters, dramatically reducing the pretraining sequence requirement to Ω(n^{2α/(2α+d)} log³n). This reframes the question of how much capacity a transformer needs for statistical estimation tasks. Open questions include whether the result extends to dependent data (more realistic for language models), whether low-dimensional structure (manifolds, sparsity) can be exploited to avoid the curse of dimensionality, and whether the theoretical construction aligns with what gradient-based training actually finds in practice. The simulation is small-scale (d=3, n≤35) and does not yet validate the theory at the scale relevant to deployed models.

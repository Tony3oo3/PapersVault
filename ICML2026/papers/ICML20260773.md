## Problem

Process-based soil models (PBMs) that incorporate microbial dynamics require biokinetic parameters that cannot be measured directly, and inverse estimation from the only observable output (CO₂ time series) is severely ill-posed due to model equifinality. While metagenomic sequencing data can in principle inform these parameters, no computational framework existed to learn the complex, non-linear mapping from genomic functional traits to PBM parameters while ensuring realistic behaviour of unobservable state variables.

## Input / Output

The method takes a 38-dimensional vector of quantitative functional genomic traits (derived from metagenome-assembled genomes via the rule-based Microtrait tool, covering categories like resource acquisition, resource use, and stress tolerance) and, during training only, a paired CO₂ emission time series of length t. It outputs 13 biokinetic parameters (θ_bio) that parametrize a six-state-variable ODE system (active/inactive bacteria, high/low molecular weight carbon, sorbed carbon, CO₂), from which full time series of all state variables are simulated. Critically, only CO₂ is observable in practice; the other five state variables and all parameters are unmeasurable, making the learning problem highly underdetermined.

## Method

HySoMi couples a fully-connected MLP (5 hidden layers with batch normalisation) that maps genomic traits to PBM parameters with a differentiable ODE-based soil carbon model (solved via torchdiffeq with 5th-order Runge-Kutta), enabling end-to-end gradient-based training. The key innovation is a constrained loss function that adds 13 ReLU-based inequality penalties—drawn from ecological theory, literature ranges, and logical system considerations—on both the PBM parameters (e.g., maintenance < growth < deactivation < reactivation rates) and the simulated state variables (e.g., biomass bounds, dormancy transition timing, carbon pool ranges), thereby shrinking the equifinal parameter space. Homoscedastic uncertainty weighting with learnable λ parameters adaptively balances the MSE data-fitting term against each constraint penalty without manual tuning. Parameters are projected into literature-derived ranges via a sigmoid transformation, and the entire pipeline is trained with Adam on paired (trait vector, CO₂ time series) data, requiring no direct parameter measurements.

## Results

On the synthetic test set (280 samples), HySoMi achieves MSE_obs = 0.0355±0.0006 and MSE_Hidden = 0.0211±0.0018, closely matching the unrealistic All-states reference (0.0352 / 0.0161) while only using CO₂ as training signal. HySoMi also recovers biokinetic parameters more accurately than the unconstrained hybrid (L1 error 0.2336 vs 0.3284) and satisfies ecological constraints far better (constraint sum 0.2823 vs 1.3744). On real LUCAS soil data (15 h CO₂ time series), HySoMi achieves MSE_obs = 0.0003 with a constraint sum of 0.0006, compared to 1.003 for the unconstrained model.

## Baselines & Comparisons

HySoMi is compared against three baselines: (1) an Unconstrained hybrid model using only MSE loss, (2) a pure ML model predicting CO₂ directly, and (3) an All-states reference that trains on all six state variables (an unrealistic upper bound). Against the Unconstrained hybrid, HySoMi reduces MSE_Hidden by 66% (0.0211 vs 0.0627), improves L1 parameter error by 0.0948, and lowers the constraint violation sum by 1.09 (0.2823 vs 1.3744), indicating the unconstrained model fits CO₂ but produces non-physical dynamics for unobserved pools like inactive bacteria (B_i) and high-molecular-weight carbon (C_H). Against the All-states reference, HySoMi is slightly worse on MSE_Hidden (0.0211 vs 0.0161) but better on L1 parameter recovery (0.2336 vs 0.2474) and constraint satisfaction (0.2823 vs 0.5312), showing that explicit constraints yield more physically consistent parameterisations even when all state variables are available. The pure ML model matches hybrid models on MSE_obs (0.0360 vs 0.0355) but provides no mechanistic interpretation or predictions for any other state variable or parameter.

## Relation to Prior Work

This paper extends the differentiable PBM + neural network parameter learning paradigm established by Tsai et al. (2021) and applied in hydrology (Kraft et al., 2022) and ecosystem modeling (Aboelyazeed et al., 2023) to the specific domain of soil microbial dynamics. It builds on the constraint-based loss regularisation approach of ElGhawi et al. (2023) for reducing model equifinality, but generalises it from inferring a single sensitive parameter to simultaneously learning multiple biokinetic parameters. The key departure is the use of metagenome-inferred functional traits (via Microtrait) as input covariates, which is a novel data source for soil PBM parametrisation, and the integration of ecological-theory-derived inequality constraints on both parameters and unobserved state variables.

## Why It Matters / Open Questions

Soil carbon models are critical for climate prediction, yet their microbial parameters remain poorly constrained due to equifinality and measurement limitations. HySoMi demonstrates that domain-knowledge constraints can effectively substitute for unobservable state variables, enabling realistic multi-parameter inference from CO2 alone on small datasets common in biogeosciences. However, the approach is validated primarily on synthetic data; no real dataset with deeply sequenced metagenomes and full process-rate measurements yet exists, and the LUCAS feasibility study uses only 15-hour time series with shallow sequencing. Open questions include whether the framework scales to multi-pool microbial models, how constraint misspecification affects performance in real field conditions, and whether the learned genomic-to-parameter mapping generalises across soil types and climates.

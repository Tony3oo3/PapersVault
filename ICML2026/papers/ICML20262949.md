## Problem

Recent tabular foundation models (TabPFN v2, TabICL, LimiX) improve accuracy by adding heavier architectural components such as alternating row/column attention and extra embedding modules, substantially increasing inference cost and limiting practical deployment under latency constraints. The paper asks whether the simpler row-wise attention-only backbone of TabPFN v1 can remain competitive when augmented with modern stabilization techniques, and how to further reduce per-sample inference cost for online serving.
![Teaser figure](../imgs/ICML20262949/cropped_page0_idx0.webp)

## Input / Output

The model takes a labeled support set of N tabular rows (features + labels) and a single unlabeled query row as a prompt. Features are standardized to a fixed dimension F_max via zero-padding (if F < F_max) or PCA projection (if F > F_max), then each row is independently z-score normalized before embedding. A single pretrained backbone produces either a class label (classification head) or a continuous target value (regression head), and with early-exit enabled, the number of transformer layers executed varies per query based on a learned reliability score.

## Method

TABSWIFT retains the row-wise attention-only PFN backbone (each table row is a token; self-attention is applied only across the N+1 rows) and adds two lightweight modifications: (1) element-wise gated attention (G1) that multiplies the SDPA output by a learned sigmoid gate before the output projection, improving pretraining stability at negligible overhead, and (2) K learnable register tokens prepended to the row sequence as task-shared latent slots that aggregate global context across depth. The model is pretrained on 20,000 synthetic tabular tasks under a unified objective that jointly optimizes classification (cross-entropy) and regression (MSE+L1) heads on the same batch, yielding a single model for both task types. For deployment, an adaptive early-exit mechanism attaches a prediction head and a learned exit head to each of the last E layers; the exit head takes the concatenation of the query representation and the mean-pooled register summary, outputs a stopping score, and inference halts at the earliest layer where the score exceeds a threshold τ, allocating fewer layers to easy samples and more to ambiguous ones.

## Results

On the TALENT benchmark (200 classification + 100 regression datasets), TABSWIFT achieves an average rank comparable to TabPFN v2 and TabICL under Wilcoxon-Holm significance testing, while running at substantially lower inference cost (even with 4× more ensembles than TabPFN v2). With adaptive early exit at τ=0.999, TABSWIFT retains 0.8398 average accuracy while executing only 21.67/24 layers on average; at τ=0.95 it drops to 0.8370 accuracy with just 14.06 average layers. On large-N datasets (>20k rows, Table 4), TABSWIFT achieves an average rank of 12.32, competitive with TabICL (12.56) and ahead of TabPFN v2 (16.61), though behind non-PFN methods like RealMLP (9.31) and ModernNCA (9.69).

## Baselines & Comparisons

TABSWIFT is competitive with the strongest tabular foundation models (TabPFN v2, TabICL, LimiX) on the main TALENT benchmark, with CD diagrams showing no statistically significant difference from top performers under Wilcoxon-Holm correction, while being substantially faster at inference even when using 16 ensembles versus 4 for TabPFN v2/LimiX. Against classical GBDT baselines (XGBoost, LightGBM, CatBoost), TABSWIFT matches or exceeds their average rank, particularly in the small-to-medium data regime where PFN-style ICL excels. On large-N datasets (>20k rows), TABSWIFT (rank 12.32) trails non-PFN deep methods like RealMLP (9.31) and ModernNCA (9.69) but still outperforms TabPFN v2 (16.61) and LightGBM (16.10), indicating the row-wise attention backbone's quadratic scaling in N becomes a limitation. The PAMA analysis reveals that different TFMs excel on different dataset subsets, suggesting complementarity rather than a single dominant method. For the early-exit mechanism, the learned register-conditioned exit head outperforms both the entropy-based stopping baseline and the unconditioned exit head across the accuracy-compute Pareto frontier.

## Relation to Prior Work

TABSWIFT revisits the row-wise attention-only PFN backbone introduced by TabPFN and argues that two lightweight modifications—element-wise gated attention (borrowed from LLM design, Qiu et al. 2025) and learnable register tokens (adapted from ViT, Darcet et al. 2024)—are sufficient to close the gap with heavier column-aware architectures like TabPFN v2, TabICL, and LimiX. It follows TabICL's synthetic pretraining pipeline and data generation protocol but unifies classification and regression in a single model. The adaptive early-exit mechanism departs from Küken et al. (2025), which relies on test-set-level entropy statistics, by targeting strict per-query online inference where no global test information is available.

## Why It Matters / Open Questions

The paper demonstrates that architectural simplicity plus stabilization can match complex tabular foundation models at substantially lower inference cost, offering a practical path for latency-sensitive deployment of PFN-style in-context learners. The per-query early-exit mechanism provides a controllable accuracy-compute knob that is directly applicable to production serving. Key open questions include whether PFN-style row-wise attention can scale beyond the ~20k-row regime where non-PFN methods (RealMLP, ModernNCA, TabM) begin to dominate, and whether the PCA-based dimensionality reduction for high-dimensional inputs can be replaced by more principled feature encodings.

## Problem

Most causal discovery methods for non-stationary time series assume that context (regime) variables are exogenous, i.e., externally imposed and not influenced by the system itself. In many real-world systems—soil moisture modulating heat flux, volatility regimes in financial markets, attention states in neuroscience—contexts are endogenous, driven by the very variables they modulate, creating feedback loops that break exogeneity assumptions and introduce selection bias. This paper is the first to systematically address endogenous, time-lagged context variables in constraint-based time-series causal discovery.

## Input / Output

The method takes a multivariate time series X, a known discrete context variable C (e.g., 'dry/moist' soil moisture bins), and a maximal lag τ_max, and produces a set of context-specific window graphs G_{C=c}^{descr}—one per context value c—each encoding the directed and undirected causal edges among system variables at time t active under that regime. Under the persistence property, only K constant-context graphs are recovered; under sparsity, up to K^{|Pa^C(X)|} context-specific graphs are possible. The context variable must be discrete and observed, and the system must satisfy either (w,δ)-persistence or sparse context dependence, both empirically testable.

## Method

The paper proposes PAC-PCMCI+ and SAC-PCMCI+, two constraint-based extensions of PCMCI+ that modify only the MCI (momentary conditional independence) phase via an adaptive testing scheme. On each conditional independence test, the algorithm checks whether any context variable appears in the conditioning set: if so, it removes all context variables from the set and instead restricts the data to time points where the relevant context lags take a fixed value, thereby avoiding selection bias while preserving sample efficiency. PAC-PCMCI+ exploits context persistence by restricting to fully persistent windows (C^≤ = c·1), reducing the exponential context space to K graphs; SAC-PCMCI+ exploits sparsity by conditioning only on the specific context lags that are true parents of the target, preserving more samples per test. Soundness is proven under strong context-acyclicity, single-graph-sufficiency, and causal sufficiency assumptions, with the key theoretical distinction that persistence imposes stricter conditioning-set restrictions (all-or-nothing context window) while sparsity allows partial context inclusion.

## Results

On synthetic benchmarks, PAC-PCMCI+ and SAC-PCMCI+ achieve the lowest false positive rate (FPR) while maintaining high true positive rate (TPR) when context-system links are known, validating their adaptive testing strategy against selection bias. SAC-PCMCI+ achieves the highest TPR among all methods due to optimal data utilization via adaptive testing, while P-PCMCI (pooled) achieves the highest TPR but also the highest FPR. On the real-world soil moisture land-atmosphere feedbacks dataset, PAC-PCMCI+ and SAC-PCMCI+ produce 4 spurious edges in the summary graph compared to 7 for Regime-PCMCI, and both detect the proxy edge LH–TP (with lag changes in the moist regime) that Regime-PCMCI misses entirely.

## Baselines & Comparisons

Against Regime-PCMCI (Saggioro et al., 2020), PAC-PCMCI+ and SAC-PCMCI+ produce fewer spurious edges (4 vs. 7) and detect the proxy edge LH–TP with regime-dependent lag changes, which Regime-PCMCI fails to identify. However, Regime-PCMCI correctly recovers all non-context-dependent edges and the context-dependent LH–SM edge, which both proposed methods miss. Against B-PCMCI (Günther et al., 2024), PAC-PCMCI+ performs comparably in accuracy but with slightly lower FPR, since B-PCMCI performs more tests by running PCMCI+ separately on each context and on pooled data before intersecting. SAC-PCMCI+ outperforms B-PCMCI on TPR by exploiting sparsity to condition only on relevant context lags, preserving more effective samples per test. Overall, the proposed methods win on FPR and spurious-edge count, tie or slightly lose on recall of specific context-dependent edges, and offer a constraint-based alternative requiring fewer hyperparameters than optimization-based baselines.

## Relation to Prior Work

This paper extends the i.i.d. endogenous context causal discovery framework of Günther et al. (2024) to the time-series setting, where context variables can have lagged dependencies and context switches become effective only after a delay. It adapts the constraint-based PCMCI+ algorithm (Runge, 2020) by modifying only the MCI phase with an adaptive testing scheme that switches between pooled and context-specific data depending on whether context variables appear in conditioning sets. The key departure from prior time-series context methods (Regime-PCMCI, J-PCMCI+) is the explicit modeling of endogenous contexts with feedback loops, rather than assuming exogenous regime assignments, and the introduction of persistence and sparsity as complementary, testable properties to tame the exponential context explosion problem.

## Why It Matters / Open Questions

The paper addresses a practically important gap: many real-world systems (climate, finance, neuroscience) have regimes that emerge from internal dynamics rather than external forcing, yet most causal discovery methods assume exogenous contexts. The theoretical soundness guarantees and the real-world climate application demonstrate that endogenous context discovery is feasible under testable assumptions. Key limitations include the requirement for known discrete context variables, reliance on acyclicity conditions, and the fact that persistence and sparsity cannot both hold simultaneously—when both fail, the problem remains exponentially hard. Open directions include integrating context detection for unobserved contexts, handling deterministic contexts, and allowing limited sparsity violations.

## Problem

Standard reinforcement learning assumes a fixed environment in which the agent can only adapt its policy, but many real-world settings allow the agent to actively modify the environment itself (e.g., placing stepping stones in a river, adjusting infrastructure, or changing monetary policy). Prior configurable MDP work treated environment configuration as a one-shot, non-Markovian optimization step; this paper introduces a framework where model-changing actions are themselves modeled as sequential MDP decisions, enabling the agent to continuously reconfigure a time-varying, non-stationary environment over multiple episodes.

## Input / Output

The method consumes lower-level transition kernels P ∈ [0,1]^{n×n} (discrete set of m kernels for the bi-level case, or a continuous kernel plus configuration variable x_k ∈ [-1,1]^{n×n} for the TVCMDP case), a shared reward function r(s,a), an upper-level transition kernel Q over kernel states, a configuration budget B, and a uniform initial state distribution μ₀. It produces an optimal higher-order configuration policy Θ*: P→B, an optimal primitive policy π* for each configured kernel, the configuration variables x_k, and the resulting state-value functions V^π and W^Θ at both levels. A key structural constraint is that the lower-level transition kernel itself serves as the upper-level state, and model-changing actions are restricted to episode boundaries.

## Method

The paper formulates a multi-layer configurable time-varying MDP (MCTVMDP) where the lower-level MDP's transition kernel is configurable through upper-level model-changing actions, and the kernel itself becomes the upper-level state space. Two solution pathways are developed: (1) For the discrete bi-level case, a model-based bi-level value iteration algorithm alternates between lower-level value iteration (computing J(π*,P) for each kernel) and upper-level value iteration over the kernel state space, with the upper-level reward incorporating both the expected lower-level return and a configuration cost. (2) For the continuous TVCMDP case, the paper derives a first-order linear approximation of the state-value function V^π(P^π+x) ≈ N^π + M^π x N^π using the Jacobian ∇_{P^π}V^π, reducing the cost-constrained optimization to a convex program with a linear objective ⟨A_k, x_k⟩ and an exponential cost constraint. Theoretical guarantees are provided via total-variation-distance bounds showing how physical configuration error (δ_c) and kernel estimation error (δ_g) propagate to upper-level value gaps of order γ(δ_g+δ_c)V_max/((1-γ)(1-λ)). Empirically, PPO and DQN are used to train configuration policies on MuJoCo-Reacher, Cartpole, and Block-world environments.

## Results

On the synthetic TVCMDP (3 states, 2 actions, K=2 episodes), the optimally configured state-value average increases by 23% over the no-configuration baseline, while random configuration can even degrade performance (e.g., at budget B=3.5 or B=6.5). On the synthetic bi-level MDP (6 lower-level states, 3 upper-level kernel modes), the bi-level configuration policy achieves the highest average return among all non-oracle methods and is closest to the oracle upper bound across 100 test episodes. In the MuJoCo-Reacher experiment, the PPO-trained upper-level configuration policy adaptively repositions the target across episodes, balancing lower-level performance against configuration cost (λ_cost=5.0). Error analysis confirms that lower-level state-value errors grow linearly with total-variation perturbation size and remain within the theoretical bound γ(δ_g+δ_c)V_max/(1−γ), and upper-level errors stay within the bound stated in Lemma 5.3.

## Baselines & Comparisons

The paper compares its bi-level configurable MDP against four baselines: (1) non-configuration mode (lower-level kernel uniformly sampled, agent uses only the primitive optimal policy), (2) random configuration (model-changing actions chosen uniformly at random), (3) oracle (lower-level kernel fixed to the best one with its optimal policy), and (4) one-shot classic CMDP (agent configures the environment once at the first time step, then the kernel naturally deteriorates). The bi-level method clearly outperforms both non-configuration and random configuration on the synthetic bi-level MDP, with its average return closest to the oracle. On the TVCMDP, optimal continuous configuration yields a 23% improvement over the no-configuration baseline, whereas random configuration can worsen performance at intermediate budgets. In the 50-episode test comparing against the one-shot CMDP baseline (Figure 9), the bi-level model's cumulative reward is substantially higher because it can continuously counteract natural kernel deterioration, while the one-shot method is forced into a 'no-change' action after the initial configuration and suffers progressive performance decay.

## Relation to Prior Work

This paper extends the Configurable MDP (CMDP) line of work (Metelli et al., 2018; Silva et al., 2018; Thoma et al., 2024) in three key ways: (1) configuration is sequential and episodic rather than one-shot, modeled as an upper-level MDP whose states are the lower-level transition kernels themselves; (2) the lower-level MDP is time-varying and non-stationary, requiring the agent to repeatedly reconfigure as the environment naturally deteriorates; and (3) the framework generalizes from bilevel to multi-level hierarchical configuration. The paper explicitly departs from prior CMDP formulations that treat configuration as a single optimization step (gradient-based or Stackelberg) by embedding the configuration process itself within a Markov decision process with its own policy, reward, and discounting.

## Why It Matters / Open Questions

The framework provides a principled way to model agents that can actively reshape their environment's dynamics (e.g., infrastructure maintenance, monetary policy, robot-assisted terrain modification), with theoretical error bounds that quantify how configuration imprecision and estimation error propagate through the hierarchy. However, the current algorithms are model-based (requiring known or estimable transition kernels), the upper-level state space is assumed discrete and finite in the main algorithm, and empirical validation is limited to small synthetic MDPs and standard benchmarks (MuJoCo-Reacher, Cartpole, Block-world). Key open questions include extending to fully model-free settings, scaling to large continuous configuration spaces, and designing principled reward functions that balance configuration cost against long-term reward gains.

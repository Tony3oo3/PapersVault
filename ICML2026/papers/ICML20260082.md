## Problem

Prior learning-augmented approaches for online covering problems either predict on the structure of optimal solutions (e.g., which sets or facilities to open) rather than on which requests will arrive, or require non-trivial properties of the underlying algorithm such as subset-competitiveness. This paper asks whether a fully black-box, modular framework exists that converts any online covering algorithm with competitive ratio ρ(k,·) into one whose ratio depends on the prediction error η instead of the total number of arriving requests k, without relying on algorithm-specific structure.

## Input / Output

The framework receives upfront a prediction X̂ (a subset of the ground set indicating which elements are expected to arrive, independent of arrival order) and an online covering problem instance with a black-box algorithm ALG of competitive ratio ρ(k,·). The prediction error η is the ℓ₁ symmetric difference |X △ X̂| capped at |X|, so it measures only set-level disagreement. The output is a valid covering for all arrived elements with competitive ratio O(ρ(η,·)) in the existential setting, or O(α·ρ(η,·) + O(α·log⁻¹(γ/(γ−1))·log k)) in the polynomial-time setting via an (α,γ)-decomposition.

## Method

The ICE (Iteratively Charge Expenses) procedure operates in two phases. In the offline phase, it computes an (α,γ)-decomposition of X̂: a partition X̂ = X₁ ∪ … ∪ X_r with feasible solutions S_i whose costs satisfy geometric growth properties (A)–(D), ensuring the partial solutions progressively approximate the optimal covering of the predicted set. In the online phase, it runs ALG in a black-box manner on predicted elements while tracking accumulated cost; whenever this cost exceeds c(S_layer), it purchases S_layer and reinitializes ALG, while unpredicted elements are handled by a separate ALG instance. The key insight is that the geometric growth condition guarantees at most η elements remain uncovered by purchased solutions, so the competitive ratio depends on η rather than k and degrades smoothly as prediction error grows. The (α,γ)-decomposability notion (Definition 2.1) enables polynomial-time computation via approximation—for instance, the (1−1/e)-approximation for Budgeted Maximum Coverage yields (1, e/(e−1))-decomposability for set cover—trading a small additive log k term for tractability while bypassing NP-hardness barriers.

## Results

The paper's main contribution is a general framework (ICE) that converts any online covering algorithm with competitive ratio ρ(k,·) into a learning-augmented algorithm with competitive ratio O(ρ(η,·)), where η is the ℓ₁ prediction error. Key instantiated bounds include: O(log η · log |S|) for online set cover, O(log η · log |F|) for non-metric facility location, O(log η / log log η) for metric facility location, O(log η) (deterministic) and O(log log η) (randomized) for weighted path augmentation/parking permit, and O(log η) for Steiner tree. In the experimental evaluation on the PACE Challenge dataset (~2200 elements, ~1800 sets) and random instances (1000 elements, 100 sets), the ICE framework achieves substantial improvements over the classical O(log k · log |S|) baseline across all prediction error levels, with negligible difference between exact and approximate decompositions.

## Baselines & Comparisons

The primary experimental baseline is the classical O(log k · log |S|)-competitive online algorithm of Alon et al. [4], used both as the black-box subroutine inside ICE and as the standalone 'classical' comparison. The ICE framework (both exact and approximate decomposition variants) achieves substantial multiplicative improvements over this baseline across all prediction error levels η/|X̂| = 2α tested, with the gap narrowing as prediction error grows but remaining meaningful even at high error. Theoretically, the paper also compares against the framework of Azar et al. [9], which uses a metric error with outliers (△, D) and requires the underlying algorithm to be subset-competitive; ICE achieves a better bound for metric facility location (O(log η / log log η) vs. O(log △)) by leveraging the best known O(log k / log log k) algorithm in a fully black-box manner, whereas [9] is limited to O(log k) due to the subset-competitiveness requirement. Unlike prior learning-augmented set cover work (Bamas et al. [11], Gupta et al. [24]), which assumes predictions on the optimal solution sets rather than on arriving requests, this paper's prediction model is on the request set itself, making the results incomparable but complementary.

## Relation to Prior Work

This paper departs from the closest prior framework by Azar, Panigrahi, and Touitou (SODA 2022), which also uses partial solutions and predictions on requests for metric graph problems but requires the underlying online algorithm to satisfy a non-trivial subset-competitiveness property and employs a more complex metric error with outliers. It also contrasts with the primal-dual line of work (Bamas et al., NeurIPS 2020; Anand et al., ICML 2022; Gupta et al., NeurIPS 2022) that incorporates predictions on the *sets* of an optimal solution rather than on the arriving *requests*. The key conceptual departure is the introduction of the (α,γ)-decomposition, which enables a fully black-box reduction: any ρ(k,·)-competitive online covering algorithm is automatically converted into an O(ρ(η,·))-competitive learning-augmented one, with no structural assumptions on the algorithm beyond its competitive ratio.

## Why It Matters / Open Questions

The framework yields the first learning-augmented algorithms (with predictions on requests) for a wide range of classical problems including set cover, non-metric facility location, weighted path augmentation, group Steiner tree/forest, node-weighted Steiner, and directed Steiner, establishing a unified template that any future improvement in the underlying online algorithm automatically inherits. A fundamental limitation is that for NP-hard covering problems like set cover, the additive O(log k)·OPT term cannot be removed in polynomial time (Theorem 3.3), and for several Steiner generalizations the (α,γ)-decomposition is only known to exist (not computable in poly-time), leaving a gap between the existential and efficient guarantees. Open questions include whether more efficient decompositions exist for the harder Steiner variants, and whether the framework can be extended to non-monotone or non-covering online problems.

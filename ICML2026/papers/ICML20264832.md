## Problem

Traditional multimodal RAG agents accumulate interaction history linearly, causing state blindness (repetitive queries), a semantic gap when compressing visual observations into text, and misleading supervision from sparse outcome rewards broadcast across entire trajectories. These issues are especially acute for token-heavy, semantically sparse visual data in iterative multi-hop reasoning over large interleaved corpora.
![Teaser figure](../imgs/ICML20264832/cropped_page1_idx0.webp)

## Input / Output

The agent receives a natural-language query and iteratively retrieves from a unified ~200k-item corpus of text passages, images, and 1-minute video clips (embedded via GVE-7B). At each step it produces a decomposed sub-query, a textual summary, and a bank of selectively retained visual tokens whose total resolution is bounded by a fixed budget (S_total = 5×256×32×32 pixels). The final output is a text answer plus the full directed acyclic graph of reasoning states, where each node carries its parent links, sub-query, summary, and compressed multimodal memory.

## Method

VimRAG formulates agentic reasoning as the sequential evolution of a dynamic DAG (a POMDP over actions {retrieve, memorize, answer}), where each node stores the agent's epistemic state: parent indices, sub-query, textual summary, and multimodal memory tokens. A Graph-Modulated Visual Memory Encoding module computes per-item energy by combining structural-semantic relevance (out-degree × priority score), temporal decay, and recursive reinforcement from successor nodes, then proportionally allocates the global token budget so that high-energy evidence retains high-resolution ViT tokens while trivial items are compressed or discarded. For training, a Graph-Guided Policy Optimization (GGPO) strategy prunes the memory graph to identify the critical path from root to answer, applying binary gradient masks that exclude dead-end nodes in positive samples and protect valuable retrieval steps in negative samples, enabling fine-grained step-level credit assignment under a GSPO objective. The system is trained in two stages—LoRA SFT on Qwen3-VL followed by RL with a conservative 1e-6 learning rate—and evaluated across nine benchmarks spanning text, image, document, and long-video RAG.

## Results

VimRAG achieves 45.2% overall binary model-based accuracy on Qwen3-VL-4B-Instruct and 50.1% on Qwen3-VL-8B-Instruct, outperforming the strongest baseline Mem1 (40.6% and 43.6% respectively) by 4.6 and 6.5 points. Gains are most pronounced on video-centric benchmarks: VimRAG reaches 54.5% on SyntheticQA and 37.1% on XVBench (8B), versus 43.4% and 32.2% for Mem1. On text-only benchmarks (HotpotQA, SQuAD), VimRAG also leads with 79.1% and 76.4% (8B), confirming that the graph-structured memory benefits all modalities.

## Baselines & Comparisons

VimRAG outperforms all five baselines across every benchmark and both model scales. The closest competitor is Mem1 (iterative summarization memory), which VimRAG surpasses by 4.6 points (4B) and 6.5 points (8B) overall; the gap widens on video benchmarks (e.g., +8.1 on SyntheticQA, +4.9 on XVBench at 8B), reflecting Mem1's state-blindness in tracking retrieval history. ReAct and Vanilla RAG suffer from context exhaustion on token-heavy visual data, yielding 33.6–37.7 overall. VideoRAG, designed for video-specific frame selection, generalizes poorly to text and document tasks (e.g., 34.0 on SlideVQA vs. VimRAG's 62.4 at 8B). UniversalRAG, which frames cross-modal retrieval as a routing problem, performs worst overall (25.2/28.5), particularly on document and video benchmarks where its fixed pipeline cannot adapt to iterative multi-hop reasoning.

## Relation to Prior Work

VimRAG extends the iterative retrieval-then-memorization paradigm introduced by Mem1 (Zhou et al., 2025), replacing its linear compressed memory state with a dynamic directed acyclic graph that explicitly encodes agent epistemic states and logical dependencies. It departs from the broader context-management lineage (ReAct's append-all-history, MemAgent's sequential feeding, VideoRAG's frame selection) by introducing three coupled mechanisms: a graph topology for structural state tracking, an energy-based visual token allocation that mimics human forgetting, and a topological credit-assignment strategy (GGPO) that prunes dead-end nodes from positive trajectories and protects valid retrievals in negative ones. The work also builds on the multimodal RAG literature (UniversalRAG, VideoRAG, VisRAG) but unifies text, image, and video retrieval within a single agentic loop rather than treating each modality with a fixed pipeline.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in deploying multimodal agents: visual data is token-heavy yet semantically sparse, causing context exhaustion and state blindness in long-horizon RAG tasks. The energy-based visual memory encoding offers a concrete, interpretable mechanism for the resolution-efficiency tradeoff, and the graph-pruning credit assignment provides a principled way to train multi-step agents without the misleading gradients of broadcast outcome rewards. Limitations noted by the authors include dependence on base-model quality, multi-turn inference latency unsuitable for real-time settings, and retriever accuracy that still constrains the system. Open questions include whether the graph topology generalizes to truly open-ended (non-DAG) reasoning, whether the energy formulation scales to thousands of nodes, and whether a unified multi-task model can replace the current per-task prompting.

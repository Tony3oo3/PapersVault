## Problem

The dominant paradigm in LLM reasoning assumes that extended chain-of-thought deliberation improves accuracy, yet on deterministic state-tracking tasks (permutation puzzles, multi-step SQL joins, program-state tracing) longer reasoning actively degrades performance. Prior work attributed the resulting inverted-U curve to per-step sub-task difficulty, leaving the mechanistic cause and a quantitative threshold for when tool delegation becomes necessary uncharacterized. This paper argues the failure is an information-theoretic limit of decoder-only attention's per-step bandwidth, not merely task complexity, and provides a closed-form depth threshold (the Deterministic Horizon) that separates the two accounts with testable predictions.

## Input / Output

The method takes a deterministic state-tracking problem specified as an initial state σ₀, a target state τ, and a finite operator set O (e.g., adjacent transpositions on n-element permutations, k-state automaton transitions, multi-table SQL joins), and the model must emit an operator sequence whose composition maps σ₀ to τ exactly. Grading is strictly binary—exact final-state match with no partial credit or path-optimality assessment—and instances are generated at BFS-optimal depths 1–60 across eight task families. Beyond per-instance accuracy, the framework produces a per-model Deterministic Horizon d* (the depth at which unaided accuracy crosses a target α), State-Space Jaccard drift scores with precision/recall decomposition, and directly measured attention entropy from open-weight checkpoints.

## Method

The core technical contribution is a context-dependent error model ε(d) = ε₀ + γ·d/L_eff, motivated by linear growth of attention entropy with reasoning depth, which yields a Decoherence Bound P(correct at depth m) ≤ exp(−mε₀ − γm(m+1)/(2L_eff)) with a statistically significant quadratic depth term producing super-exponential accuracy decay. An Attention Bottleneck Theorem shows total per-layer read capacity is O(H·log(L)·√d_h) bits—far exceeding the ~44 bits needed for a 16-element permutation—establishing that the binding constraint is per-step bandwidth degradation (attention entropy growth diluting anchor-token resolution), not total capacity. The Deterministic Horizon d* is derived in closed form from the error model, empirically validated across twelve models and eight task domains, and observed to scale as √d_model on four open-weight architectures. The State-Space Jaccard (SSJ) metric decomposes state drift into precision and recall to characterize capability failure versus preference failure. Empirically, tool delegation via an exact BFS solver achieves 76–94% accuracy versus 17–42% for neural CoT on PermutationProbe, and fine-tuning Llama-3.1-8B on 5,000 optimal-length traces yields only +0.9 pp improvement, supporting an architectural ceiling that preference-based interventions cannot overcome.

## Results

On PermutationProbe (depth > 20), tool delegation (C3, BFS solver) achieves 76–94% accuracy across all twelve models, versus 17–42% for unconstrained neural chain-of-thought (C1). The Deterministic Horizon d* (depth at which unaided accuracy crosses 50%) falls in [19, 31] across the model suite, scaling approximately as √d_model on open-weight models (d* ≈ 0.314√d_model). Fine-tuning on optimal-length traces (C5) recovers only +0.9 pp over C1, and length-encouragement prompting (C4) adds only +0.6–1.2 pp, both far below the ≥5 pp threshold a preference-based account would predict. Real-world benchmarks (SWE-Bench-State, WebArena-Nav, SQL-Multi) exhibit the same decoherence pattern with d* ∈ [19, 26].

## Baselines & Comparisons

The paper does not benchmark against external reasoning methods; instead it contrasts five internal conditions to isolate the mechanism of failure. Tool delegation (C3, exact BFS solver) dominates every neural condition by 50+ percentage points on PermutationProbe (e.g., 89.7% vs 28.3% for GPT-4o; 94.2% vs 42.1% for o3-mini), with the gap consistent across all six model families. Oracle optimal-depth prompting (C2) recovers only +3.6 to +6.9 pp over C1 (mean 5.7 pp), confirming that even knowing the correct chain length cannot overcome per-step attention degradation. Length-encouragement prompting (C4) and fine-tuning on optimal traces (C5) each add <2 pp, ruling out a preference-based ('Simplicity Bias') explanation that would predict ≥5 pp recovery from fine-tuning. The SSJ precision/recall decomposition shows parallel decay (both drop from ~0.9 at depth 5 to ~0.1 at depth 50), indicating capability failure (state drift into fictitious states) rather than a simple preference for shorter answers. On real-world tasks, the same C1-vs-C3 gap persists (e.g., SWE-Bench: 86.4% vs 24.1% for GPT-4o), confirming the phenomenon generalizes beyond synthetic puzzles.

## Relation to Prior Work

This paper positions itself as a complementary diagnosis to the 'overthinking' literature (Wu et al. 2026; Chen et al. 2025; Sui et al. 2025), which attributes inverted-U CoT curves to per-step sub-task difficulty. Here, the error source is relocated to attention-capacity limits: per-step bandwidth degrades with depth due to attention entropy growth and over-squashing, rather than sub-tasks becoming intrinsically harder. The theoretical framework synthesizes attention-sink concentration (Xiao et al., 2024), over-squashing (Barbero et al., 2024), and working-memory limits (Gong & Zhang, 2024) into a unified Attention Bottleneck bound, with the lower-bound construction drawing on Sanford et al. (2023). The tool-augmented reasoning literature (Gao et al., 2023; Gou et al., 2024; Schick et al., 2023) provides the empirical backdrop for the delegation condition, but this paper adds a quantitative threshold (the Deterministic Horizon) for *when* delegation becomes necessary rather than merely beneficial.

## Why It Matters / Open Questions

The Deterministic Horizon (d* ∈ [19,31] at α=0.5) gives practitioners a concrete, architecture-dependent criterion for when to route deterministic sub-tasks to external solvers, with direct implications for code agents, SQL planners, and web automation systems. The fine-tuning ceiling (<3 pp recovery) is the sharpest evidence against preference-based explanations and suggests that current decoder-only architectures face a hard limit on exact state tracking that data or prompt interventions cannot overcome. Key open questions include whether state-space models or memory-augmented architectures escape this bottleneck, where the crossover lies for imperfect (non-exact) tools, and whether the √d_model scaling holds beyond the four open-weight models tested. Limitations include correlational (not causal) entropy evidence, a single-model fine-tuning experiment, and reliance on stated modeling assumptions for the capacity bound.

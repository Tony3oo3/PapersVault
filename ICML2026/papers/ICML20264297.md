## Problem

Current computer use agents (CUAs) depend on costly human-curated datasets that are unavailable for newly released or updated software, making it impossible to adapt agents to unfamiliar applications without human supervision. The paper tackles two sub-problems: generating executable tasks in previously unseen software environments, and accurately assessing step-level task success to provide dense reward signals for reinforcement learning.
![Teaser figure](../imgs/ICML20264297/cropped_page1_idx0.webp)

## Input / Output

The Actor Model consumes sequential GUI screenshots (full trajectory history, not just the final frame) plus a natural-language task instruction, and outputs a structured GUI action (click coordinates, typed text, drag bounding box, hotkey combination, etc.). The World State Model ingests the entire state-action trajectory and produces per-step binary labels (correct a_T vs. failure a_F) along with free-text state-change captions; the Curriculum Generator outputs a growing software guidebook and a new set of progressively harder task instructions each phase. Unlike prior CUA reward models that judge only the final screenshot, the WSM requires the full multi-screenshot history, which is what enables step-level credit assignment.

## Method

SEAgent couples three components in a closed loop: an Actor (UI-TARS-7B-DPO) that executes tasks, a World State Model (Qwen2.5-VL-7B distilled from GPT-4o on 860 Chrome trajectories plus 1,000 change-description pairs via LoRA) that classifies every step as correct or failure and captions GUI state changes, and a Curriculum Generator (Qwen2.5-72B) that maintains a self-updating software guidebook and proposes increasingly difficult tasks. Policy optimization combines GRPO with action-type-specific verifiable rewards (L1 distance for clicks, IoU for drags, BLEU for typed text) on correct steps and a contrastive adversarial-imitation loss on failure steps, weighted by gamma=0.2. A specialist-to-generalist strategy first trains per-software specialists, distills their successful trajectories into a unified base via SFT, then applies multi-software RL, yielding a generalist that outperforms both direct generalist RL and the specialist ensemble. The key design choice is step-wise rather than trajectory-level reward: the WSM evaluates the full episode to identify the first error step, converting a sparse binary outcome into dense per-step signals in [0,1] that are substantially more sample-efficient for long-horizon GUI tasks.

## Results

On OSWorld (five professional software applications), SEAgent with the specialist-to-generalist strategy achieves 40.0% overall success rate, substantially outperforming the UI-TARS-7B-DPO baseline (21.5%), UI-TARS-72B-DPO (31.5%), DigiRL specialized RL (30.6%), and WebRL specialized RL (29.1%). The World State Model (distilled from GPT-4o) reaches 73.9% precision on OSWorld-Full trajectory judgment, closing the gap with GPT-4o (74.6%) and Gemini-3 Pro (79.9%). On out-of-domain ScienceBoard, SEAgent applied to UI-TARS-1.5 improves GrassGIS from 0.0% to 20.6% and Celestia from 4.9% to 15.2%, validating the framework's impact on truly novel software.

## Baselines & Comparisons

SEAgent (Specialist-to-Generalist) at 40.0% overall SR outperforms all RL baselines: DigiRL specialized RL (30.6%), WebRL specialized RL (29.1%), and even its own specialized RL variant (36.4%), demonstrating that the specialist-to-generalist distillation strategy adds +3.6% over direct specialist training. Against proprietary LLM agents, SEAgent surpasses Claude 3.7 Sonnet (19.7%), Gemini-Pro-2.5 (21.7%), and GPT-4o (7.08%) by large margins. For reward modeling, the World State Model (73.9% precision on OSWorld-Full with full trajectory input) narrows the gap with GPT-4o (74.6%) and Gemini-3 Pro (79.9%), while substantially outperforming raw Qwen2.5-VL-72B (26.8%) and Qwen2.5-VL-7B (20.0%) under the same full-trajectory evaluation. In task generation, the Curriculum Generator outperforms NNetNav (5.05% vs. 9.09% on Celestia with Qwen2.5-72B) and WebRL (0.00% vs. 37.7% on VSCode), showing superior exploration of unfamiliar software. The GRPO+Adversarial Imitation loss combination outperforms GAE-based RL (DigiRL, WebRL) by 5.8–11.3% on individual software, attributed to denser step-level credit assignment from the World State Model.

## Relation to Prior Work

SEAgent builds on the UI-TARS CUA architecture and the GRPO optimization framework from DeepSeekMath/DeepSeek-R1, but departs from prior CUA RL methods (DigiRL, WebRL) in two key ways: it replaces trajectory-level critic-based advantage estimation (GAE) with step-wise rewards from a World State Model that ingests the full episode history, and it introduces an adversarial imitation loss to explicitly penalize failure actions. The Curriculum Generator with a persistent software guidebook memory extends prior task-generation approaches (NNetNav, WebRL) by maintaining structured, self-updating knowledge of the target software rather than generating tasks from scratch each round. The specialist-to-generalist training strategy—distilling multiple software specialists into a single generalist via SFT before joint RL—draws on the system-1/system-2 fusion idea but applies it to CUA training for the first time.

## Why It Matters / Open Questions

SEAgent addresses a practical gap: as software updates and new applications emerge, human-annotated CUA data becomes unavailable, and the framework demonstrates a viable path to autonomous proficiency without supervision. The finding that a 7B World State Model distilled from only 860 Chrome trajectories generalizes to professional desktop software and even mobile GUIs (AndroidWorld) suggests that judgment patterns are transferable, reducing the data burden for reward modeling. Key open questions include scaling to long-horizon expert workflows (current tasks are <20 steps), integrating executable verifiers to reduce reliance on the WSM, and developing hybrid step-wise/trajectory-level RL for fault-tolerant deployments where error recovery is valuable.

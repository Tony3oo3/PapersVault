## Problem

Memory-augmented VLA policies for long-horizon, history-dependent robotic manipulation have been evaluated on narrow, non-standardized settings with inconsistent backbones and protocols, making it impossible to determine which memory representations generalize across tasks. Existing benchmarks either lack explicit memory requirements (decisions can be made from immediate observations alone) or cover only a single memory type with near-solved tasks. This paper addresses the absence of a unified, cognitively-grounded testbed and a controlled comparison of diverse memory designs under identical conditions.

## Input / Output

At each timestep the policy receives 256×256 multi-view RGB images (front and wrist cameras), proprioceptive states (joint positions, EEF pose, gripper), and a language task instruction; tasks prefixed with 'Video' additionally condition on a sequence of historical demonstration frames at the initial step. Memory is constrained to a fixed budget of 512 tokens across all variants to ensure fair comparison. The policy outputs a 20-step action chunk (executing the first 16 steps) in either 8D joint-space (7 joints + gripper) or 7D EEF-space (3D position, Euler orientation, gripper); symbolic-memory variants additionally produce grounded language subgoals with image-pixel coordinates.

## Method

The MME-VLA suite builds 14 variants on the π0.5 multi-expert flow-matching backbone by crossing three memory representations with three integration mechanisms. Symbolic memory uses VLM-generated language subgoals (simple or grounded with pixel coordinates) concatenated to task instructions; perceptual memory selects visual tokens from past SigLIP2-encoded frames via token dropping (RGB-difference-based pruning) or uniform frame sampling; recurrent memory compresses history into 512 fixed-size latent states using either Test-Time Training (online-updated fast weights) or Recurrent Memory Transformers (learnable memory slots updated via grouped-query cross-attention). Integration is achieved through memory-as-context (tokens appended to VLM input), memory-as-modulator (AdaLN conditioning the action expert via cross-attention to memory tokens), or memory-as-expert (a dedicated 18-layer memory expert interacting with the action expert through asymmetric blockwise causal attention). All variants are trained end-to-end with a conditional flow-matching objective over 80K steps in a multi-task setting across 16 non-Markovian tasks, with the key finding that no single representation dominates: perceptual memory with the modulator integration achieves the best overall success rate (44.51%), while symbolic memory excels on counting tasks and recurrent memory underperforms due to training instability with shallow recurrent layers.

## Results

On the RoboMME benchmark (16 tasks, 800 evaluation episodes), the best MME-VLA variant FRAMESAMP+Modul achieves 44.51% average success rate, outperforming the strongest prior method MemER (42.38%) and the memory-free π0.5 baseline (17.93%). Perceptual memory variants consistently outperform symbolic (best: GROUNDSG+QwenVL at 32.70%) and recurrent (best: TTT+Context at 22.28%) counterparts. Human performance reaches 90.50%, indicating substantial headroom. The best model still lags humans by ~46 points, with the largest gaps on Imitation tasks (e.g., InsertPeg at 7.56% vs. 98% human).

## Baselines & Comparisons

The best MME-VLA variant (FRAMESAMP+Modul, 44.51%) outperforms all three external baselines: π0.5 without memory (17.93%, +26.6 pts), SAM2Act+ (21.37%, +23.1 pts), and MemER (42.38%, +2.1 pts). MemER is the strongest comparison method and excels specifically on dynamic scene-change tasks (ButtonUnmask: 72.00%, VideoUnmask: 81.33%) due to its hybrid keyframe+subgoal design, but it is outperformed on Imitation tasks (e.g., PatternLock: 16.67% vs. 53.56%) and Counting (StopCube: 0.00% vs. 42.00%). SAM2Act+ achieves the best single-task result on ButtonUnmaskSwap (26.67%) thanks to its discrete waypoint planner, but collapses to 0% on all Imitation tasks requiring precise continuous control. The π0.5 w/ past actions baseline (19.73%) shows that simply appending past actions provides only marginal gains over the memory-free model, confirming that structured memory representations are necessary. No single memory type dominates all four suites: perceptual memory leads on Imitation and Counting, while MemER leads on Permanence, highlighting complementary strengths.

## Relation to Prior Work

This paper builds on the π0.5 multi-expert VLA backbone (Black et al., 2025) and its predecessor π0 (Black et al., 2024), extending them with explicit memory modules drawn from three distinct lineages: symbolic (language subgoals via VLMs, as in MemER and MEM), perceptual (visual token banks, as in SAM2Act and ContextVLA), and recurrent (RMT and TTT). It departs from prior memory benchmarks (MemoryBench with 3 near-solved tasks; MIKASA-Robo with short-horizon tasks) by constructing a unified 16-task suite spanning four cognitive memory dimensions under a single controlled backbone, enabling the first systematic head-to-head comparison of memory representations and integration mechanisms that prior work could not support due to architectural heterogeneity.

## Why It Matters / Open Questions

RoboMME fills a critical gap by providing the first standardized, large-scale testbed that explicitly enforces non-Markovian history dependence across temporal, spatial, object, and procedural memory, with 770k training timesteps sufficient for imitation-based VLA training. The central empirical finding—that no single memory design dominates and that effectiveness is highly task-dependent—challenges the implicit assumption in prior work that one 'best' memory architecture generalizes, and motivates hybrid or adaptive memory systems. Key limitations include tabletop-only evaluation with fixed assets, reliance on a single backbone (π0.5), and the large remaining gap to human performance (44.5% vs. 90.5%), leaving open questions about scalability to mobile manipulation, alternative VLA architectures, and principled combination of complementary memory types.

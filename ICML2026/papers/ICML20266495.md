## Problem

Current collaborative agentic AI protocols (A2A, MCP, ACP, ANP, etc.) are developed in isolation with incompatible abstractions and data formats, creating a trajectory toward fragmented, non-interoperable ecosystems. The paper argues that neither enforcing a single unified protocol nor building pairwise translation layers is viable, and that the field needs a third approach: minimal standards grounded in existing web infrastructure to enable cross-ecosystem agent collaboration.

## Input / Output

Agents consume HTTP requests (GET for retrieval, POST for complex interactions), flexible interaction documents that may be structured (JSON) or natural language with no mandated schema, session identifiers via HTTP cookies for short-term state, and URLs resolved through DNS for discovery. Outputs include HTTP responses, state updates persisted to databases for long-term memory, capability advertisements served at well-known URI paths (analogous to robots.txt), and discovery results from search-engine-style crawling. The unusual constraint is that interaction documents deliberately avoid rigid formatting requirements, relying on LLM interpretation to bridge heterogeneous agent interfaces.

## Method

WEB OF AGENTS is a minimal architectural blueprint composed of four building blocks that reuse existing web technologies rather than introducing new protocols: (1) HTTP as the sole transport for agent-to-agent messaging, explicitly rejecting JSON-RPC and WebSockets as unnecessary overhead; (2) interaction documents as a schema-free handshake mechanism where agents expose their interface requirements in any format interpretable by LLMs; (3) state management via standard web sessions (cookies) for short-term conversational context and database integration for long-term persistence; (4) agent discovery through globally unique URLs with DNS resolution and capability advertisement at IETF-standard well-known URI paths (RFC 8615). The key design principle is 'Keep It Simple, Stupid'—staying as close as possible to existing web infrastructure to inherit decades of security (TLS, OAuth 2.0), scalability, and community scrutiny. Feasibility is demonstrated by forking A2A, ACP, and Agora with ~200 lines of code per protocol, achieving cross-ecosystem collaboration with negligible latency overhead (1.2–3 ms added versus 3.3 s average LLM generation time).

## Results

As a position paper, WEB OF AGENTS does not report traditional benchmark metrics. The only quantitative evaluation is a latency experiment: adding the four building blocks to A2A increases end-to-end request latency from 9.17 ms to 10.4 ms, and for ACP from 93.04 ms to 96.02 ms, which is negligible relative to the 3.3 s average LLM generation time. The proof-of-concept implementation required only ~200 lines of code per protocol (A2A, ACP, Agora), demonstrating that adoption imposes minimal engineering overhead.

## Baselines & Comparisons

The paper does not benchmark against baselines in the traditional ML sense; instead, it surveys eight existing protocols (A2A, MCP, ACP, agents.json, Agora, ANP, AITP, LMOS) and shows that none of them simultaneously covers all four proposed building blocks (messaging, interaction interoperability, state management, discovery) or supports cross-ecosystem interoperability. A2A and ACP cover messaging and identity but lack discovery and state management; ANP adds discovery but still omits state management; LMOS is the most complete single solution but remains closed to other ecosystems. WEB OF AGENTS differentiates itself by explicitly targeting interoperability across all existing ecosystems rather than proposing yet another self-contained protocol, and by reusing existing web infrastructure (HTTP, DNS, sessions, well-known URIs) rather than introducing new primitives. The latency comparison confirms that the interoperability layer adds <3 ms overhead per protocol, validating the 'minimal standards' claim.

## Relation to Prior Work

This position paper carves new ground by arguing that the emerging landscape of agentic AI protocols (A2A, MCP, ACP, ANP, Agora) is heading toward fragmentation, and that the solution is not a unified protocol or pairwise translation layers but minimal reuse of existing web infrastructure (HTTP, DNS, OAuth, well-known URIs, session cookies). It explicitly departs from classical MAS communication languages (KQML, FIPA-ACL) by leveraging LLMs' ability to interpret natural-language interaction documents rather than rigid schemas, and from MARL by focusing on systems-level cross-ecosystem collaboration rather than learned coordination. The paper's conceptual lineage draws on the history of web standardization (HTTP/HTML bootstrapping the web, TCP/IP's pragmatic success over OSI) as a template for agentic AI, positioning 'Web of Agents' as a third path between maximalist unification and brittle mediation.

## Why It Matters / Open Questions

The paper addresses a timely and concrete risk: the 'protocol wars' in agentic AI could lock the field into incompatible silos before the ecosystem matures, with real costs in engineering overhead, security (expanded attack surface from translation layers), and vendor lock-in. The four-building-block blueprint (HTTP messaging, interaction documents, session-based state, URL/well-known-path discovery) is deliberately minimal and the ~200-line PoC per protocol suggests low adoption friction, but the paper acknowledges significant open problems including privacy of data flowing between agents, the political/economics of standardization, and whether truly minimal standards suffice as agent capabilities grow. As a position paper with a small proof-of-concept, its impact hinges on whether standards bodies (W3C, Linux Foundation, AGNTCY) and major protocol developers actually adopt these extensions before fragmentation hardens.

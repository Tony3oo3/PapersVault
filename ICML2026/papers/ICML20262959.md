## Problem

Existing RTL representation learning methods rely on a single modality—either source code or graph structure—limiting expressiveness and generalization. Prior multimodal efforts such as GraphCodeBERT use incomplete data flows with only variable-level alignment, while CircuitFusion performs coarse-grained contrastive alignment between text-code and text-graph pairs, neglecting fine-grained code-graph interaction. The paper addresses the gap of learning unified RTL representations that capture both the semantic richness of code and the complete structural information preserved in control data flow graphs (CDFGs).

## Input / Output

The method consumes three modalities per design: Verilog RTL source code, a natural-language functional summary, and a CDFG extracted by compiling through Yosys to RTLIL and parsing with Stagira. Graph nodes are encoded as concatenations of one-hot type, bit-width, and PCA-reduced (768→32) text-description embeddings from all-mpnet-base-v2. The output is a single [CLS] embedding vector from the unified Transformer, used directly for regression (area/delay prediction via a 3-layer MLP head) or as a fixed-length embedding for retrieval and equivalence-checking via cosine similarity.

## Method

UniRTL employs a unified CodeBERT-base-mlm Transformer that jointly processes text, code, and graph tokens through mutual masked modeling: 20% of tokens and graph nodes are masked, and the model must recover them using information from the other modalities, enforcing fine-grained cross-modal alignment. A dedicated graph-aware tokenizer (8-layer GIN + 8-layer Transformer) is first pretrained with structure-aware masked node modeling and edge prediction to encode local and global structural dependencies before being frozen as a feature extractor. Training follows a hierarchical strategy: the graph tokenizer is pretrained in isolation, then text-code alignment is performed as a warm-up stage (maximizing data utilization since text-code pairs outnumber graph-paired samples), and finally graph incorporation introduces the CDFG embeddings into the joint space. To preserve topology when flattening graph nodes into the Transformer, global positional encodings derived from the 16 smallest eigenvectors of the symmetric normalized graph Laplacian are added, and a linear adapter projects graph node embeddings into the text-code embedding space for effective cross-modal interaction.

## Results

On performance prediction without netlist information, UniRTL achieves R² of 0.7682 for area and 0.7832 for delay, with MAE of 0.3510 (area) and 0.3384 (delay), consistently outperforming all baselines. For code retrieval, UniRTL attains F1 of 0.662 on natural language code search and average precision of 0.745 on functionality equivalence checking, setting new state-of-the-art on both tasks. The model operates at CodeBERT scale (~300 MB inference memory), substantially smaller than 7B LLM-based baselines (~14–15 GB).

## Baselines & Comparisons

UniRTL outperforms all nine baseline groups across every task and metric. Against the strongest graph-based baseline StructRTL, UniRTL improves delay MAE from 0.5414 to 0.3384 (37% reduction) and area R² from 0.7463 to 0.7682, demonstrating that combining code with CDFGs via mutual masked modeling captures complementary information beyond structure alone. Against LLM-based methods (CodeV variants, DeepRTL2), UniRTL achieves substantially better performance despite being orders of magnitude smaller: e.g., area R² of 0.7682 vs. 0.4862–0.6758 for the 6.7B–7B LLM baselines. Against GraphCodeBERT, which uses incomplete data-flow graphs and weak variable-level alignment, UniRTL improves area R² from 0.5207 to 0.7682 and delay R² from 0.3989 to 0.7832, highlighting the importance of complete CDFGs and fine-grained mutual masked modeling. Against CircuitFusion, which uses coarse-grained contrastive alignment at the register sub-circuit level, UniRTL improves area R² from 0.6175 to 0.7682. On code retrieval, UniRTL achieves F1 of 0.662 (natural language code search) and AP of 0.745 (functionality equivalence checking), surpassing GraphCodeBERT (0.634 / 0.730) and DeepRTL2-Llama (0.572 / 0.646), while general-purpose text embedders (text-embedding-3-large, GritLM-7B, NV-Embed-v2) trail significantly at F1 0.375–0.414 and AP 0.554–0.599.

## Relation to Prior Work

UniRTL extends the GraphCodeBERT paradigm of integrating code with structural graph information into the RTL domain, but departs from it in three key ways: replacing incomplete data flow (variables only) with complete CDFGs that preserve operators and control flow, substituting the weak variable-alignment objective with mutual masked modeling for fine-grained cross-modal alignment, and introducing a graph-aware tokenizer (GIN + lightweight Transformer) rather than feeding flattened nodes directly into the Transformer. It also contrasts with CircuitFusion, which uses separate modality-specific encoders fused via cross-attention and coarse-grained contrastive alignment, by adopting a unified Transformer with a hierarchical training strategy (graph tokenizer pretraining → text-code alignment → graph incorporation) that maximizes data utilization. The unimodal baselines it surpasses—StructRTL (CDFG-only), VeriDistill and DeepRTL2 (code-only via LLMs)—motivate the core claim that complementary modalities are necessary for robust RTL representations.

## Why It Matters / Open Questions

UniRTL provides a practical, efficient foundation model for hardware design automation: a ~125M-parameter model pretrained on 2×L40 GPUs for 45 hours outperforms 7B+ LLM-based encoders on both performance prediction and code retrieval, with ~300MB inference memory. This is particularly relevant as RAG-based RTL code generation systems proliferate, since better retrieval representations directly improve generation quality. Key limitations include Verilog-only support, a relatively small graph-paired subset (38,888 of 132,008 designs), and evaluation under a single synthesis setup (SkyWater 130nm); extending to other HDLs, larger industrial designs, and diverse synthesis flows remains open.

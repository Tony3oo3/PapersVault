## Problem

Dataset distillation (DD) has shown strong empirical success in compressing training data into small synthetic sets, but its theoretical understanding remains largely confined to linear models (ridge regression, kernel methods) that ignore task structure. A key open question is how DD extracts and encodes the low-dimensional intrinsic structure of non-linear tasks into distilled data, and what memory complexity is actually required. This paper provides the first rigorous analysis of gradient-based DD algorithms (gradient matching and performance matching) applied to non-linear two-layer networks learning multi-index models, revealing how the principal subspace of the task is captured during distillation.

## Input / Output

The method takes N i.i.d. training points (x_n, y_n) where x_n ~ N(0, I_d) and y_n = f*(x_n) + ε_n with f* a degree-p multi-index model of intrinsic dimension r, along with a two-layer ReLU network of width L initialized symmetrically. The distilled data is initialized with random points on the unit sphere S^{d-1} and constant labels. The output is a two-part synthetic dataset: D_1^S (size M_1 ~ Θ̃(r²)) encoding the principal subspace S* for first-layer retraining, and D_2^S (size M_2 with memory ≤ Θ̃(r²d + L)) encoding the final-layer weights for second-layer retraining. Retraining from a fixed reference initialization θ^(0) on D_1^S ∪ D_2^S reproduces a model with generalization error matching the full-data baseline.

## Method

The paper applies progressive dataset distillation in two phases aligned with the two-phase training of Damian et al. (2022). In phase t=1, one-step gradient matching (GM) is applied to the first-layer (W) training: the teacher gradient over N data points and J random initializations extracts information from the principal subspace S*, and the distillation update projects the synthetic points onto S* via the Hessian H = E[∇²f*(x)], yielding x̃^(1) ∝ Hx̃^(0). In phase t=2, either one-step GM or one-step PM is applied to the second-layer (a) training; under a regularity condition ensuring the kernel matrix has maximum rank, the optimal weights a* lie in the column space of the kernel and can be fully encoded into the distilled labels. The proof tracks all four coupled optimization stages (teacher training, student training, distillation, retraining) using Hermite polynomial expansions and tensor computations, showing that M_1 = Θ̃(r²) points suffice (reducing to M_1 = 1 for single-index models) and the total memory complexity drops from Θ(d³ ∨ d²/ε ∨ d/ε⁴ ∨ dL) to Θ̃(r²d + L), which is below the model storage cost Θ(dL).

## Results

The main theoretical contribution establishes that dataset distillation (DD) applied to two-layer ReLU networks learning multi-index models achieves a memory complexity of Θ̃(r²d + L), reducing the standard training data requirement from Θ(d³ ∨ d²/ε ∨ d/ε⁴ ∨ dL). For single-index models (r=1), a single distilled point (M₁=1) suffices to encode the principal subspace. The resulting model achieves generalization error E[|f_θ*(x)−y|]−ζ ≤ Õ(√(dr³ᵖ/N) + √(r³ᵖ/L) + 1/N^{1/4}), matching the baseline trained on the full dataset. In transfer learning experiments, pre-training with the distilled set D₁ˢ allows fine-tuning a new function sharing the same principal subspace with sample complexity that no longer scales with d.

## Baselines & Comparisons

The paper's primary comparison is against three prior theoretical works on DD: Izzo & Zou (2023), Maalouf et al. (2023), and Chen et al. (2024b). All three prior works require Θ(Nd) or Θ(qd) memory and are restricted to linear models (LRR or KRR) with exact (closed-form) optimization, whereas this paper achieves Θ̃(r²d + L) for non-linear two-layer ReLU networks trained via gradient-based algorithms. The key advantage is that when the intrinsic dimension r is much smaller than the ambient dimension d (as in multi-index models), the proposed bound Θ̃(r²d + L) is substantially tighter than Θ(qd) where q=L for a two-layer network, since r²d + L < Ld when r² < L. The paper also demonstrates empirically that random baselines (replacing distilled points with random training data) fail to reproduce the generalization performance, confirming that the compression is due to structured encoding of the principal subspace rather than mere data reduction. In the transfer learning setting, the distilled set D₁ˢ enables fine-tuning with sample complexity independent of d, outperforming the NTK regime which requires n ≳ d³ for non-trivial loss.

## Relation to Prior Work

This paper builds on three distinct lines of work: (1) empirical dataset distillation methods (performance matching, gradient matching, progressive DD), (2) theoretical DD analyses that characterize the number of synthetic points needed to recover exact linear/kernel regression solutions (Izzo & Zou 2023, Maalouf et al. 2023, Chen et al. 2024b), and (3) rigorous feature-learning analyses of gradient descent on two-layer networks for multi-index and single-index models (Damian et al. 2022, Abbe et al. 2022). The key departure is that prior theoretical DD work either restricts to linear models or ignores task structure entirely; here, the authors are the first to prove that gradient-based DD on a non-linear model with a specific low-dimensional task structure (multi-index) encodes the principal subspace into the distilled data, yielding a memory complexity of Θ̃(r²d+L) rather than the Θ(Ld) that prior kernel-based analyses would require for the same architecture.

## Why It Matters / Open Questions

This provides the first mechanistic explanation for why DD achieves high compression rates: the algorithm captures the intrinsic low-dimensional structure of the task during early training and encodes it into a small number of synthetic points, which then enables efficient second-layer training. The transfer learning application (reusing D₁ˢ across tasks sharing the same principal subspace) suggests a practical pathway for compact knowledge transfer. However, the analysis is restricted to two-layer ReLU networks, multi-index polynomial targets, and one-step distillation on synthetic data, leaving open whether the Θ̃(r²d+L) scaling and the 'one point suffices for r=1' result extend to deeper architectures, real-world data distributions, or multi-step distillation. The computational overhead (J scaling with d) and the need for a regularity condition on D₂ˢ initialization are practical caveats.

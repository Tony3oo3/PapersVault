## Problem

Standard LLMs assign rigid, fixed positional indices (linear 0 to L−1 or a constant) to all tokens, forcing attention layers to bear the full burden of recovering the underlying structure of linearized input. This extraneous load impairs performance on tasks requiring long-range or fine-grained contextual dependencies, such as needle-in-a-haystack retrieval and structured-data reasoning, because limited attention capacity is split between understanding structure and processing content.

## Input / Output

The method operates on text sequences up to 4,096 tokens during training (extended to 16K at inference via YaRN) and produces autoregressively generated text. The REPO module consumes the hidden state of each token at each layer and outputs a continuous real-valued position scalar per attention head; these positions replace the fixed integer indices inside the RoPE rotation formula while leaving the autoregressive token order and KV-cache structure unchanged, so no re-sorting or recomputation is required at each decoding step.

## Method

REPO introduces a lightweight differentiable module f_φ that assigns each token a continuous, non-linear position based on its hidden state, replacing the conventional fixed integer index in the position-encoding step. The module has two components: a SwiGLU sub-layer that extracts a low-dimensional position representation (d_p = d/8) from the full hidden state, followed by a per-head linear projection to a scalar position. These learned positions are plugged directly into the RoPE rotation formula (q_i^T g_θ(z_j − z_i) k_j), making the entire pipeline end-to-end differentiable. REPO is applied starting from the ⌈L/3⌉-th layer (lower layers retain standard RoPE), with the position-representation weights shared across heads but the position-assignment weights learned independently per head. The model is trained by continual pre-training on OLMo-2 1B/7B (50B tokens), and analysis shows the learned positions occupy a denser, non-linear space and dynamically blend constant (NoPE-like) and monotonic (RoPE-like) patterns, effectively reducing the extraneous cognitive load on attention.

## Results

On OLMo-2 1B, REPO achieves 91.3 average accuracy on RULER NIAH tasks (noisy context), outperforming ROPE by 5.4 points and the best hybrid baseline R2N1 by 0.8 points. On long-context evaluation (LongBench, up to 16K tokens), REPO improves the average score by 6.93 points over ROPE on 1B and 6.38 points on 7B. On structured data (HybridQA table QA), REPO gains +2.27 EM over ROPE on 1B and +4.09 EM on 7B. On general short-context benchmarks (ARC, BoolQ, CoQA, DROP, HellaSwag, MMLU-Pro, TriviaQA), REPO matches ROPE within 0.03 points on 1B and 0.62 points on 7B.

## Baselines & Comparisons

REPO consistently outperforms all four baselines (ROPE, NOPE, R2N1, N2R1) on the three targeted task dimensions. Against ROPE (the standard linear position assignment), REPO gains +5.4 points on noisy context (1B), +2.27 EM on structured data (1B), and +6.93 on LongBench (1B), with similar or larger gains at 7B scale. Against the hybrid baselines R2N1 and N2R1 (which interleave RoPE and NoPE layers), REPO achieves the best average on noisy context (91.3 vs. 90.5 and 88.3) and long context (27.86 vs. 22.95 and 11.29 on LongBench 1B), confirming that learned dynamic re-positioning surpasses fixed layer-level mixing strategies. NOPE (constant position) is the weakest baseline, losing 5.7 points on noisy context and 13.95 on LongBench (1B) relative to ROPE, while REPO recovers and exceeds ROPE on all targeted tasks. On general short-context benchmarks, REPO is essentially tied with ROPE (+0.03 on 1B, −0.62 on 7B), indicating no regression from the architectural change.

## Relation to Prior Work

REPO departs from the standard paradigm of fixed position assignment (linear indices in RoPE, constant indices in NoPE) by learning data-dependent continuous positions via a lightweight differentiable module, while keeping the position encoding function (e.g., RoPE) unchanged. It is conceptually related to COPE (Golovneva et al., 2024), which also learns position sequences, but avoids COPE's expensive attention-logit gating and incompatibility with RoPE/FlashAttention. The paper positions itself as orthogonal to the large body of work improving the encoding function itself (YaRN, ALiBi, HoPE, etc.), instead targeting the upstream position-assignment step, and frames the motivation through Cognitive Load Theory rather than purely architectural considerations.

## Why It Matters / Open Questions

REPO offers a practical, low-overhead (0.9% parameter increase) architectural modification that can be applied to existing pretrained LLMs via continual pre-training, making it accessible without retraining from scratch. The finding that learned positions occupy a denser, non-linear space smaller than the raw sequence length provides a new perspective on why long-context extrapolation is difficult and how it might be alleviated. Open questions include whether REPO benefits models trained from scratch, how it interacts with other architectural innovations (e.g., mixture-of-experts, sliding-window attention), and whether the gains hold beyond the OLMo-2 family on which all experiments are conducted.

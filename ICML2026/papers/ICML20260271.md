## Problem

Split conformal prediction (SCP) provides distribution-free finite-sample coverage guarantees, but its efficiency degrades sharply when the calibration set is small: the empirical rank grid has resolution 1/(m+1), forcing overly conservative or even vacuous prediction sets. Existing remedies such as synthetic-data augmentation (e.g., SPI) require training and deploying expensive generative models. The paper asks whether calibration resolution can be improved using cheap reference scores drawn from an arbitrary distribution, without generating synthetic feature-label pairs, while retaining finite-sample validity.

## Input / Output

The method consumes m labeled calibration pairs, a pre-trained score function s(X,Y), N reference scores sampled from a user-chosen distribution (which need not match the true score distribution), and a test covariate X_{m+1}. It outputs a prediction set C(X_{m+1}) ⊆ Y together with explicit distribution-free lower and upper coverage bounds L(β,m) and U(β,m) that are computable from rank indices alone, independent of the observed score values. For regression the set reduces to a single scalar threshold q_RSA, while for classification it is a candidate-wise inclusion rule over the label space.

## Method

RSA-CP augments the m real calibration scores with N reference scores and characterizes the test score's augmented rank via a conditional Beta-Binomial law given its rank k among the real scores. A high-probability conditional rank window [k+b_-(k,β), k+b_+(k,β)] localizes where the test score falls in the augmented set, and a candidate label is included whenever the nominal conformal cutoff j* is compatible with this window. To handle distributional mismatch between real and reference scores, a rank-preserving alignment map T is applied; the paper's default choice is the 1D optimal-transport barycentric projection between the empirical real-score and reference-score distributions, which is strictly monotone and therefore preserves all rank-based guarantees. The resulting prediction sets inherit distribution-free coverage bounds (Theorem 3.1) for any reference distribution, and tighter distribution-robust bounds (Theorem 3.4) that concentrate around 1−α when the transported real-score distribution is close to the reference distribution.

## Results

In the simulation study (m=20, α=0.05, β=0.4), RSA-CP(OT) maintains empirical coverage within the certified distribution-free bounds of 0.9048 ≤ P{Y_{m+1} ∈ Ĉ(X_{m+1})} ≤ 1 across all reference sizes N∈{20,…,3000}, while SCP severely overcovers with highly variable interval lengths. On ImageNet classification (n_cal=15, n_test=15000, n_syn=1000, α∈{0.05, 0.10}), RSA-CP(OT) substantially reduces prediction-set sizes relative to SCP (which frequently returns near-vacuous sets covering the full label space) while staying closer to the 95% target coverage, whereas SPI and synthetic-only baselines exhibit noticeable under-coverage. On MEPS regression (m=15, N∈{250,…,2500}), RSA-CP consistently achieves coverage near the nominal level while producing shorter prediction intervals than SCP, with stability typically reached after a few hundred reference scores.

## Baselines & Comparisons

Against SCP, RSA-CP(OT) clearly wins on prediction-set efficiency: with m=20 calibration samples, SCP uses the maximum score as its threshold, producing wide and highly variable intervals, while RSA-CP refines the rank grid to (m+N+1)^{-1} and yields substantially narrower sets at comparable or better coverage. Against SPI (Bashari et al., 2025), RSA-CP wins on robustness and practicality: SPI is sensitive to generator misspecification (particularly under skewed and heavy-tailed noise) and requires training and deploying a feature-based synthetic data generator, whereas RSA-CP avoids data generation entirely and maintains near-target coverage even with a deliberately misspecified reference distribution. Against the synthetic-only baseline, RSA-CP wins on validity: the synthetic-only method lacks finite-sample coverage guarantees and under-covers in the small-calibration regime, while RSA-CP retains explicit distribution-free bounds (Proposition 3.3) regardless of reference distribution quality. RSA-CP also offers a clear computational advantage over SPI by avoiding repeated feature-based simulation and inference, with runtime stabilizing quickly as N grows.

## Relation to Prior Work

RSA-CP builds directly on split conformal prediction (SCP) and the Synthetic-Powered Predictive Inference (SPI) framework of Bashari et al. (2025), which augments calibration with synthetic data to improve small-sample coverage. The key departure is conceptual: rather than requiring a trained synthetic data generator, RSA-CP augments calibration with reference scores from an arbitrary user-chosen distribution and uses a Beta-Binomial conditional rank window to control how those scores interact with real calibration ranks. The optimal transport barycentric alignment step draws on 1D OT theory to map real scores into the reference score space while preserving rank order, a mechanism analogous to SPI's empirical quantile mapping but applied to scores rather than full feature-label pairs.

## Why It Matters / Open Questions

RSA-CP addresses a practical bottleneck in high-stakes deployment (medical diagnostics, autonomous systems) where only a handful of labeled calibration points are available per subgroup, causing standard CP to produce vacuous prediction sets. The distribution-free guarantees hold for any reference distribution, making the method robust to misspecification, while Theorem 3.4 quantifies how efficiency improves as alignment quality increases. Open questions include extending the framework to conditional and fairness-aware conformal settings, developing adaptive reference selection strategies, and incorporating Bayesian or knowledge-based reference scores. The method's computational lightness (no generator training or inference) makes it attractive for settings where SPI's synthetic pipeline is infeasible.

## Problem

Despite strong performance on standardized benchmarks, LLMs systematically fail to satisfy what real users actually want in open-ended interactions. Existing evaluation paradigms—model-generated checklists, expert rubrics, and simulated users—capture what experts or models consider appropriate rather than the diverse, often implicit expectations that users reveal through follow-up feedback. This paper asks whether current LLMs can both satisfy and anticipate these real-world user expectations, and how to explicitly model them to improve alignment.
![Teaser figure](../imgs/ICML20262592/cropped_page0_idx0.webp)

## Input / Output

For evaluation, each benchmark instance pairs a user query (averaging 366 tokens, spanning 9 languages) with 2.91 extracted expectation criteria on average, scored on a 5-point Likert scale per expectation and aggregated to an instance-level alignment score. For LENS generation, the input is a single user query; the Expectation Observer encodes it into a fixed-dimensional latent vector, the Projector maps this into the main LLM's representation space, and the frozen LLM produces a free-form text response conditioned on both the query and the projected latent signal. The evaluation target (expectation rubrics) is decoupled from the evaluator (GPT-4o as judge), enabling consistent scoring across different target models.

## Method

The paper contributes two components. EXPECTBENCH extracts semantically rich expectations from follow-up messages in 4.8M WildChat multi-turn conversations, filters for actionable and non-trivial expectations, and uses an iterative LLM-based procedure to discover 10 evaluation dimensions (Contextuality, Creativity, Coherence, Conciseness, Consistency, Empathy, Versatility, Practicality, Engagement, Compliance) from 34,876 annotations across 12,000 instances. LENS is a two-stage latent expectation-aware generation framework: in Stage I, a frozen Expectation Observer produces a latent representation z(q) from the query, and a lightweight trainable Projector P_ψ maps z(q) into the main LLM's space so that the frozen LLM can predict expectation annotations (optimized via negative log-likelihood on projector parameters only); in Stage II, the trained Projector provides soft latent guidance that conditions the frozen LLM's response generation on inferred user expectations without explicit textual supervision. Only the Projector is trained in both stages, keeping the Observer and main LLM frozen, which avoids overfitting to noisy, instance-specific expectation signals while still enabling consistent improvements across all ten dimensions.

## Results

On EXPECTBENCH, even the strongest evaluated model (GPT-4o) achieves only 2.72/5 average expectation alignment, while open-weight models (7B–9B) range from 2.00 to 2.69, indicating systematic failure to satisfy real-world user expectations. The LENS framework improves overall expectation satisfaction from 2.17 to 2.37 on LLaMA-3.1-8B and from 2.39 to 2.50 on Mistral-7B, outperforming both SFT baselines (SFT-Exp: 2.21/2.39; SFT-Resp: 2.33/2.44). In the expectation prediction diagnostic, even the best model covers only ~40% of ground-truth expectations when allowed to predict up to 10, versus the 2.91 expectations users actually express per interaction.

## Baselines & Comparisons

LENS consistently outperforms both SFT baselines on both base models: on LLaMA-3.1-8B it achieves 2.37 overall vs. 2.33 (SFT-Resp) and 2.21 (SFT-Exp), and on Mistral-7B it reaches 2.50 vs. 2.44 (SFT-Resp) and 2.39 (SFT-Exp). SFT-Exp (fine-tuning on expectation annotations alone) provides negligible gains, confirming that expectation-level supervision is too instance-specific to generalize as a direct training objective. SFT-Resp (fine-tuning on GPT-4o responses that satisfy expectations) improves surface-level dimensions like Coherence and Consistency but lags LENS on deeper dimensions such as Empathy and Versatility. Among the six LLMs evaluated on EXPECTBENCH, GPT-4o leads at 2.72/5, followed by open-weight models (DeepSeek-R1-7B, GLM-4-9B, LLaMA-3.1-8B, Mistral-7B, Qwen3-8B) scoring between 2.00 and 2.69, with no model exceeding 3/5—highlighting that expectation alignment remains an open challenge across model families and scales.

## Relation to Prior Work

This paper departs from prior user-centric LLM evaluation paradigms—model-generated checklists (WildBench), expert-designed rubrics, and simulated-user environments (τ-Bench, UserBench)—by grounding evaluation criteria directly in semantically rich expectations extracted from real user follow-up messages in multi-turn WildChat conversations. Rather than treating user data merely as a query source or reducing feedback to binary satisfaction signals (SUPR, RUBICON), it formulates expectations as structured, multi-dimensional evaluation rubrics. The LENS framework repurposes the lightweight adapter/representation-learning paradigm (analogous to LoRA-style projectors) for a novel purpose: encoding latent user expectations as soft guidance for a frozen LLM, without requiring explicit textual supervision or full fine-tuning.

## Why It Matters / Open Questions

The benchmark reveals a fundamental and quantified gap: even GPT-4o scores only 2.72/5 on expectation alignment, and expectation prediction coverage plateaus around 40% even with generous prediction budgets, suggesting the core bottleneck is models' inability to infer what users value rather than response generation quality. This reframes alignment as an expectation-understanding problem rather than a generation problem. Open questions include how expectations evolve dynamically across multi-turn interactions, whether historical interaction data can enable proactive personalization, and whether the modest LENS gains (~0.2 points) can be amplified with stronger latent representations or larger models. The benchmark's multilingual, multi-turn, and expectation-rich design makes it a potentially useful diagnostic tool for user-facing LLM deployment.

## Problem

As generative agents proliferate in multi-agent deployments, there is no principled statistical framework for detecting whether or when an agent's (or group of agents') behavior has changed over time in the black-box setting, where only inputs and outputs are observable. Prior work on model representations (e.g., DKPS) captures agent differences at a single timepoint, and multi-agent simulation studies track only aggregate system-level statistics, leaving a gap for temporal change detection at the individual and group level.

## Input / Output

The method takes N agents observed over T timepoints, each queried with M queries and R response replicates per query, with responses mapped to p-dimensional vectors by an arbitrary embedding function g, yielding a data tensor of shape T×N×M×R×p. It produces d-dimensional TDKPS embeddings for each agent at each timepoint (via classical MDS of the joint T·N × T·N distance matrix), and outputs p-values from non-parametric hypothesis tests at both the agent level (single-agent temporal shift) and group level (systematic shift within a subset of agents). The embedding dimension d is selected automatically via elbow selection, and the entire pipeline is query-set-dependent, meaning results are conditional on the chosen probe queries.

## Method

TDKPS jointly embeds all agents across all timepoints by constructing a T·N × T·N pairwise Frobenius-norm distance matrix over averaged embedded query responses, then solving a classical MDS problem to obtain d-dimensional coordinates that respect the full relational geometry. For agent-level change detection, the test statistic is the Euclidean distance between an agent's TDKPS coordinates at two timepoints, with significance assessed by a paired permutation test that pools the agent's response replicates across both timepoints, redistributes them, and re-embeds using a fixed projection basis from the original SVD to isolate the permutation effect from embedding-geometry confounds. For group-level detection, the PE o TDKPS test computes an energy distance between the empirical distributions of TDKPS embeddings at two timepoints within a group, with a paired permutation that independently swaps each agent's timepoint labels while reusing the same precomputed distance matrix, yielding O(N²) per-permutation cost versus the O(N·T·M·p) cost of a single agent-level test. The key design choice is the fixed-basis re-embedding during permutation, which prevents the permuted agent's altered role in the distance matrix from inducing spurious embedding changes, and the joint (rather than per-agent) embedding, which leverages population context to stabilize individual-level inference.

## Results

In simulations, TDKPS achieves near-optimal agent-level power closely tracking the oracle baseline and substantially outperforming DCorr across all effect sizes, with Type I error of 5–10% (vs. nominal α=0.05). The group-level PE o TDKPS test similarly approximates oracle power while maintaining Type I error ≈ α, and dramatically outperforms both DCorr and DCorr o TDKPS. On real data (99 digital congresspersons, 14 timepoints, 2018–2024), public health queries show a significant correlation between behavioral shift magnitude and proximity to COVID-19 onset (Kendall's τ = 0.51, p = 0.014), while general political (τ = 0.34, p = 0.11) and orthogonal/candy queries (τ = 0.01, p = 0.956) show no such pattern, confirming topic-specific temporal shifts.

## Baselines & Comparisons

The paper compares TDKPS (agent-level) and PE o TDKPS (group-level) against an oracle (Hotelling's T² with full generative knowledge) and non-parametric DCorr baselines. TDKPS closely approximates oracle power across all simulation conditions while substantially outperforming DCorr; even with only 5 agents, TDKPS power at effect size 0.2 nearly quadruples DCorr's (<0.15). DCorr's Type I error inflates systematically with increasing query count (suggesting overfitting via Fisher's p-value aggregation), whereas TDKPS maintains stable Type I error. At the group level, PE o TDKPS dramatically outperforms both DCorr and DCorr o TDKPS, which exhibit negligible power in higher-difficulty regimes (SNR ≪ 0.02). On real data, the group-level test produces inference strongly correlated with aggregated agent-level results (Kendall's τ = 0.69 for Republicans, p=0.001; τ = 0.62 for all agents, p=0.005), validating it as a computationally efficient alternative with orders-of-magnitude savings.

## Relation to Prior Work

TDKPS is the direct temporal extension of the Data Kernel Perspective Space (DKPS) framework (Helm et al., 2024), which embeds black-box language models into a low-dimensional space via response similarities to a fixed query set. The group-level test additionally builds on energy distance (Székely & Rizzo, 2004) as its core statistic. The paper departs from prior multi-agent system research, which typically tracks only aggregate system-level statistics, and from prior model-representation methods, which are static (single timepoint), by jointly embedding agents across time and proposing the first non-parametric hypothesis tests for temporal behavioral change in the black-box setting.

## Why It Matters / Open Questions

As generative agent deployment scales, the ability to monitor whether deployed agents' behaviors have shifted—without access to internal states—is a critical safety and reliability capability that currently lacks principled statistical tools. Key open questions include: theoretical guarantees for the proposed tests (currently only empirical), the poorly understood dependence on query set design, the limitation to 'zeroth-order' change detection (whether behavior shifted at all, not how), and extension to stateful agents with sequential dependencies. The natural experiment validation (pandemic as exogenous shock) is well-designed but limited to one system and one event, leaving generality unproven.

## Problem

Relational databases store the majority of high-value structured data yet lack foundation models comparable to those in text or vision, primarily because high-quality RDBs are private, scarce, and structurally heterogeneous, making internet-scale pre-training infeasible. Existing Prior-Data Fitted Network (PFN) approaches like TabPFN succeed only on single tables under i.i.d. row assumptions, which fundamentally violates the inter-table connectivity that defines relational data. The field lacks a relational synthetic prior capable of generating diverse, logically consistent multi-table databases from scratch for foundation-model pre-training.

## Input / Output

The model consumes a DFS-linearized feature matrix (600 rows × 30 columns) produced by recursively aggregating 1–2 hop relational neighborhoods via forward inheritance and backward aggregation (Mean, Max, Min, Count, Mode), together with a labeled context set of N ∈ {64, …, 1024} rows shared globally across all query predictions. Inference is a single forward pass with zero gradient updates, producing a binary class probability per query row. All single-table foundation-model baselines receive the identical DFS-linearized inputs to ensure a fair architectural comparison.

## Method

RDB-PFN introduces a three-stage unconditional relational prior that synthesizes infinite diverse RDBs: (1) LayerDAG samples realistic acyclic schema topologies, (2) a Selective SCM with attention-based foreign-key connection sampling and optional preferential-attachment feedback generates the instance graph and latent row states, and (3) a Bidirectional GNN propagates latent causal states across the instance graph to decode all attribute values. The model backbone is a compact 6-layer bidirectional Transformer (0.7M parameters, d_model=128, 4 heads) that alternates schema attention (across features within a row) and instance attention (across rows within a column) to approximate the posterior. Pre-training follows a two-stage curriculum—600k synthetic single-table tasks for statistical warm-up, then 1.8M mixed single-table and relational tasks for structural adaptation—totaling over 2 million synthetic datasets. A universality theorem shows the prior can approximate any consistent RDB distribution within the acyclic, locally Markov, conditionally exchangeable family, and the deliberately simple architecture demonstrates that relational intelligence stems from the prior's design rather than architectural complexity.

## Results

On 19 real-world relational prediction tasks (from 4DBInfer and RelBench), RDB-PFN achieves the highest aggregated normalized ROC-AUC across all few-shot context sizes (N ∈ {64, …, 1024}), outperforming all single-table foundation models and classical baselines in both single-estimator and default ensemble settings. The model uses only 0.7M parameters (1.0–6.5% of compared tabular foundation models) and is pre-trained on ~2M synthetic datasets (2.5–4.4% of disclosed baseline pre-training budgets), while delivering 3.0–6.7× faster inference than full/default tabular foundation model baselines. On single-table verification benchmarks, RDB-PFN trails specialized single-table TFMs but the full relational pre-training variant improves over its single-table-only counterpart, confirming positive transfer.

## Baselines & Comparisons

RDB-PFN outperforms all four single-table foundation model baselines (TabPFNv2.5, TabICLv1.1, Mitra, LimiX16M) on the 19 relational tasks in both the strict single-estimator protocol (Figure 3a) and the default ensemble protocol (Figure 3b), where baselines may use test-time ensembling while RDB-PFN remains a single forward-pass model. Against classical supervised baselines (Random Forest with 500 trees, XGBoost with 5000 estimators, AutoGluon medium/best quality), RDB-PFN also achieves superior ROC-AUC, confirming that the relational synthetic prior provides a stronger inductive bias than iterative fitting on DFS-linearized features. On the graph-based RDB reference Griffin, RDB-PFN consistently achieves higher performance on overlapping tasks even when Griffin is given an idealized best-checkpoint selection per task group (Figure 6b). RT (Relational Transformer) is discussed as a contextual reference rather than a direct baseline because its protocol injects training-split labels into the relational graph as an auxiliary table, which is incompatible with the strict global-support ICL setting used here. On single-table benchmarks, RDB-PFN trails specialized single-table TFMs (expected given its smaller size and relational focus) but the relational pre-training stage yields a measurable improvement over the single-table-only variant, indicating that the relational prior does not cause harmful overspecialization.

## Relation to Prior Work

This paper extends the Prior-Data Fitted Network (PFN) paradigm—where synthetic data from Structural Causal Models enables in-context learning on single tables (TabPFN, TabICL)—to the relational database setting, where the i.i.d.-row assumption is violated by foreign-key dependencies and multi-table topologies. It departs from real-data-based RDB foundation models (Griffin, RT) that require gradient-based fine-tuning on scarce public schemas, and from privacy-preserving RDB generators (ClavaDDPM, RelDiff) that are conditional and too slow for million-scale pre-training. The core architectural backbone is a lightweight TabPFNv2/NanoPFN-style bi-attention Transformer, with Deep Feature Synthesis serving as the deterministic relational-to-tabular interface, and LayerDAG providing learned schema topology sampling.

## Why It Matters / Open Questions

This is the first demonstration that a relational foundation model can be trained entirely on synthetic data and adapt to unseen real-world RDBs via zero-gradient in-context learning, eliminating the dependency on private or scarce real databases for both pre-training and adaptation. The 'Prior > Scale' finding—that a 0.7M-parameter model outperforms tabular FMs 15–100× larger using 25–40× less pre-training data—suggests that structurally matched synthetic priors provide inductive biases that cannot be replicated by brute-force scaling of generic single-table data. Key limitations include the restriction to binary classification, reliance on DFS linearization (rather than native graph processing), and a fixed global support set; open questions include whether the approach extends to multi-class/regression tasks, native relational architectures, and larger context windows.

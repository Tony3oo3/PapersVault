## Problem

Randomized self-reductions (RSRs) enable self-correcting programs, instance-hiding protocols, and average-case complexity results, yet discovering them has required manual expert derivation for over 40 years, restricted to a fixed set of five query functions {x+r, x−r, x·r, x, r}. This paper asks whether RSR discovery can be automated and whether the space of discoverable reductions can be expanded beyond that fixed query set.
![Teaser figure](../imgs/ICML20261028/cropped_page2_idx0.webp)

## Input / Output

The system takes a program implementation Π (a black-box oracle for an unknown function f), an input domain X, a query function class Q, and a recovery-degree bound d, then queries Π at correlated random points (x, r) drawn uniformly from X. It outputs a randomized self-reduction as a tuple of query functions (q₁,…,qₖ) and a recovery function p, along with symbolically verified properties. In the agentic variant, the LLM agent additionally proposes novel query functions (e.g., x+log(k), √(x²+y²)) that are not in the traditional fixed set, and the output includes both the reduction and a formal SymPy verification certificate.

## Method

V-BITWEEN converts RSR discovery into a sparsifying linear regression problem: it generates all monomials of degree ≤ d over symbolic variables v_q = Π(q(x,r)), fits coefficients via Lasso/Ridge with iterative dimensionality reduction, applies rational approximation to recover interpretable coefficients, and verifies the resulting identity with SymPy. Four backends (linear regression, GPLearn, PySR, Gurobi MILP) are compared, with linear regression dominating in both RSR count and runtime. A-BITWEEN layers an LLM agent (GPT-OSS-120B, Claude-Sonnet-4, or Claude-Opus-4.1) on top of V-BITWEEN's tools: the agent proposes novel functional terms (implicitly defining new query functions), calls infer_property_tool to run regression on those terms, and uses symbolic_verify_tool to check candidates, with failed verifications returning the residual expression as feedback. The agent also uses a sequential_thinking_tool to journal its reasoning. This neuro-symbolic loop lets the agent explore query functions beyond the fixed set while the symbolic tools prevent hallucinated properties, yielding 80% RSR coverage versus 54% for the best symbolic backend and far fewer false positives than a pure-neural baseline.

## Results

On RSR-Bench (80 functions), V-BITWEEN-LR discovers verified RSRs for 43/80 functions (54% coverage), outperforming V-BITWEEN-MILP (51%), V-BITWEEN-PySR (38%), and V-BITWEEN-GPLearn (32%) among symbolic backends. A-BITWEEN with Claude-Opus-4.1 achieves 80% coverage (64/80 functions), discovering 793 RSRs out of 1,628 verified properties, compared to 250 RSRs (64% coverage) for the pure-neural N-RESEARCH baseline with the same model. V-BITWEEN-LR is also the fastest symbolic backend (avg 5 s vs. 335 s for PySR), while A-BITWEEN incurs ~1.2–1.8× the runtime of N-RESEARCH due to iterative tool-use overhead.

## Baselines & Comparisons

Among the four symbolic backends within V-BITWEEN, linear regression (V-BITWEEN-LR) dominates on all three metrics: it finds the most RSRs (87 vs. 74 for MILP, 61 for PySR, 48 for GPLearn), achieves the highest coverage (54% vs. 51%, 38%, 32%), and runs fastest (avg 5 s vs. 11 s, 335 s, 140 s). Comparing neuro-symbolic A-BITWEEN against the pure-neural N-RESEARCH baseline with the same LLM (Claude-Opus-4.1), A-BITWEEN finds 3.2× more RSRs (793 vs. 250) and achieves 16 percentage points higher coverage (80% vs. 64%), while producing far fewer unverified/false-positive properties (26 vs. 172), demonstrating the critical role of the symbolic_verify_tool and infer_property_tool. The gap between A-BITWEEN and N-RESEARCH widens further on functions where fixed queries fail: across 23 RSR-Bench functions (e.g., modulo, Gudermannian, e^{x²}), V-BITWEEN-LR returns zero verified RSRs while A-BITWEEN (Claude-Opus-4.1) discovers up to 33 RSRs per function via novel query functions. On the 17 non-scalar algebraic-structure benchmarks, A-BITWEEN (Claude-Opus-4.1) achieves 100% coverage (170 RSRs) versus 65% for all V-BITWEEN symbolic backends (12 RSRs each), confirming the framework's generality beyond scalar functions.

## Relation to Prior Work

This paper builds on the 40-year theoretical lineage of randomized self-reductions (Goldwasser & Micali 1984; Lipton 1989) and adapts the PAC learning framework (Valiant 1984) to formalize RSR learning as a new sample-complexity problem with correlated sampling. It departs from prior symbolic regression work (PySR, GPLearn, AI Feynman) by using those tools as backends within a regression pipeline specifically structured to recover polynomial relationships among correlated query evaluations, rather than discovering free-form expressions from data. The neuro-symbolic variant (A-BITWEEN) extends the fixed-query paradigm of Blum et al. (1993) and Rubinfeld (1999) by letting LLM agents propose novel query functions beyond {x+r, x−r, x·r, x, r}, validated through SymPy-based symbolic verification.

## Why It Matters / Open Questions

This is the first systematic automated approach to RSR discovery, replacing decades of manual expert derivation and enabling applications in self-correcting programs, instance-hiding protocols, and verifiable computation. The framework's generalization to non-scalar algebraic structures (matrices, quaternions, Lie algebras) without architectural changes suggests broad applicability. Key limitations include incompleteness (absence of a discovered RSR does not imply non-existence), redundancy among discovered properties (Gröbner-basis pruning is NP-complete at scale), and degree limits (2–3) that may miss higher-order relationships. Open questions include finite-field regression backends, the agnostic (non-realizable) setting, and whether a 'Fundamental Theorem of RSR-Learning' analogous to the VC-dimension characterization for PAC learning exists.

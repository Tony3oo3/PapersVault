## Problem

Existing spatial intelligence benchmarks and methods focus on static scenes, third-person views, or offline short clips, and rarely address reasoning about the orientation and location of environments relative to a user's real-time movements in streaming egocentric video. This paper tackles the underexplored problem of user-centric continual spatial intelligence: incrementally integrating first-person observations to maintain an egocentric spatial reference (heading, orientation, relative directions to objects) despite frequent viewpoint changes, occlusions, and long temporal gaps between evidence and query.
![Teaser figure](../imgs/ICML20264847/cropped_page1_idx1.webp)

## Input / Output

The system consumes an egocentric video stream sampled at 1 fps (frames resized to ≤512 px on the longer side) and timestamped multiple-choice questions that require integrating spatial information from earlier observations rather than the current frame alone. At query time t, the answer may only depend on observations accumulated up to t (causal streaming constraint). The output is a single-letter multiple-choice answer, produced by an MLLM conditioned on a retrieved minimal scene-graph subgraph and a small set of keyframes, with all spatial relations rendered in the user's current egocentric frame.

## Method

DirectMe is a training-free, two-phase streaming QA framework. In the background phase, it extracts per-frame metric depth and ego-pose via DepthAnything3, persistent named object tracks via YOLO-World/Grounding-DINO + SAM2, and scene-level tags via Qwen3-VL-1B, then fuses these into a global metric-semantic map in a shared world coordinate frame and incrementally constructs an evolving scene graph with object nodes (world-frame 3D anchors), place nodes (clustered semantic regions), an ego-anchor node, and pose-derived spatial-relation edges. In the online phase, it parses the question into a structured intent, retrieves a compact query-conditioned subgraph restricted to observations before the query timestamp, transforms world-frame object coordinates into the current egocentric frame via the inverse ego-pose, and feeds the resulting pose-anchored relations plus keyframes to an MLLM for answer generation. The key design insight is that a structured, pose-anchored scene graph serves as an explicit spatial memory that preserves out-of-view object locations and enables viewpoint-conditioned reasoning, rather than relying on the MLLM to implicitly track spatial state across raw frames.

## Results

On UCS-Bench, DirectMe (w/ Qwen3-VL-8B) achieves the best overall accuracy of 50.5%, outperforming the strongest open-source baseline InternVL3-38B (49.2%) and the best proprietary model Doubao-seed-1.6V (47.3%). DirectMe (w/ InternVL3-8B) also leads at 49.7%. All models remain far below human performance (91.0%), with a gap of ~40 percentage points, indicating the task is far from solved. DirectMe's advantage grows with temporal distance: its accuracy degrades more gradually than baselines when the evidence-question interval exceeds 3 minutes.

## Baselines & Comparisons

DirectMe (w/ Qwen3-VL-8B) achieves 50.5% overall accuracy, surpassing the best open-source baseline InternVL3-38B (49.2%) by 1.3 points and the best proprietary model Doubao-seed-1.6V (47.3%) by 3.2 points. Among spatial-centric models, the strongest is Cambrian-S (42.4%), which DirectMe outperforms by 8.1 points; among streaming/online models, the best is Dispider (36.7%), trailing DirectMe by 13.8 points. Notably, DirectMe with an 8B backbone (Qwen3-VL or InternVL3) matches or exceeds 32B/38B general-purpose models, suggesting the structured scene-graph memory compensates for model scale. The largest gains appear in Position & Orientation (47.6% vs. 46.5% for Qwen3-VL-32B) and Trajectory & Movement (54.1% vs. 53.7% for InternVL3-38B), while Category & Quantity remains the weakest category for all models (46.4% for DirectMe vs. 90.0% for humans). All models still fall ~40 points short of human performance (91.0%), confirming UCS-Bench as a substantially unsolved challenge.

## Relation to Prior Work

This paper carves new ground by defining 'user-centric continual spatial intelligence' as a distinct problem: spatial reasoning where object locations must be tracked relative to the camera wearer's evolving pose over long streaming video, rather than in static scenes or from a third-person perspective. Methodologically, DirectMe repurposes existing off-the-shelf components (DepthAnything3 for metric depth/pose, Grounding-DINO + SAM2 for persistent object tracks, a lightweight MLLM for scene tags) into a structured, pose-anchored scene-graph memory that had not previously been used as an explicit spatial memory module for streaming egocentric QA. It departs from prior streaming video QA work (VideoChat-Online, Dispider, Flash-VStream) that relies on KV-cache or visual feature memory without explicit geometric grounding, and from spatial-intelligence benchmarks (VSI-Bench, OST-Bench, VSI-Super) that evaluate offline or third-person spatial reasoning without tracking the user's real-time orientation.

## Why It Matters / Open Questions

The ~40% accuracy gap between the best model (~50%) and humans (91%) establishes user-centric continual spatial intelligence as a genuinely open and challenging problem, with clear practical relevance for wearable AI assistants (e.g., guiding visually impaired users). The systematic weakness in ego-motion reasoning—models track object trajectories far better than their own movement—reveals a blind spot that existing spatial benchmarks have not surfaced. Open questions include whether explicit geometric memory (scene graphs) can be replaced by learned end-to-end representations, how to handle identity switches and long-horizon drift in pose estimation, and whether the gap to human performance can be closed with better temporal state tracking rather than larger models.

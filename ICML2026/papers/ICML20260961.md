## Problem

Standard kernel ridge regression requires O(n³) time and O(n²) memory, making it infeasible beyond a few hundred thousand samples, while existing approximations (Nyström, random features) trade accuracy for speed and complicate theoretical guarantees. Prior NUFFT-based accelerations were restricted to translation-invariant kernels with easily computable Fourier series, excluding important cases like physics-informed and additive kernels where the problem geometry breaks translation invariance.
![Teaser figure](../imgs/ICML20260961/cropped_page4_idx0.webp)

## Input / Output

The method consumes n i.i.d. pairs (X_j, Y_j) with X_j in a bounded Lipschitz domain Ω ⊆ [-L,L]^d, a known smoothness parameter s, and a regularization parameter λ. It outputs the truncated Fourier coefficient vector θ̂ ∈ C^{(2m+1)^d} (or C^{d(2m+1)} for additive models) with m = n^{1/(2s+d)}, from which predictions are f̂_n(x) = ⟨φ(x), θ̂⟩. The GPU implementation via cuFINUFFT is currently restricted to ambient dimension d ≤ 3, and the additive model package handles only simple univariate effects without interaction terms.

## Method

The key insight is that representing the RKHS in a truncated Fourier basis makes the empirical covariance matrix Σ̂ = n⁻¹Φ*Φ a d-level block Toeplitz matrix, fully determined by its first row. Each entry of that first row is a type-I NUFFT of the constant signal evaluated at the sample points, computable in O(n log n) with GPU acceleration. Matrix-vector products with Σ̂ reduce to FFT operations in O(m^d log m), and the full linear system (Σ̂ + λM*M)θ̂ = n⁻¹Φ*Y is solved via conjugate gradient in O(n log n) total time when s > d/2 (or with high probability when s ≤ d/2). The framework is instantiated for three settings: Sobolev/Matérn kernels (diagonal regularization S), L²-Fourier/Dirichlet kernels (identity regularization, empirically outperforming Sobolev), and physics-informed kernels (adding a PDE penalty μ‖D^{1/2}C^{1/2}Dθ‖² where D is diagonal and C is block Toeplitz), as well as additive models where the block structure yields O(d²n log n) complexity.

## Results

The proposed NUFFT-based kernel methods achieve O(n log n) training time and memory, compared to O(n³) for standard kernel ridge regression. In the one-dimensional Sobolev regression experiment, the method processes n = 10¹⁰ samples in approximately one minute on an NVIDIA T4 GPU while recovering the minimax rate n^{-2/3}. For the additive model with d = 5, the GPU implementation is ~14× faster than its CPU counterpart at n = 10⁸, and a grid search over 300 regularization values completes in under 30 seconds. The L²-Fourier kernel consistently outperforms the Sobolev kernel, achieving approximately 10× lower MSE at n = 10⁸ in the one-dimensional experiment.

## Baselines & Comparisons

The NUFFT kernel method dominates all listed baselines in asymptotic training complexity, achieving O(n log n) versus O(n²) for Pegasos, Divide & Conquer, and Nyström variants, O(n²√n) for doubly stochastic and iterative KRR, and O(n√n) for FALKON. In the additive model experiments (d = 5), the GPU NUFFT kernel is ~14× faster than its CPU counterpart at n = 10⁸, while FALKON's GPU implementation provides only ~15% speedup over CPU. PyGAM (the state-of-the-art GAM package) exceeds 15 GB of CPU memory at n = 10⁷, making it infeasible for larger datasets, whereas the NUFFT kernel scales to n = 10⁸. For grid search over 300 regularization values, PyGAM becomes prohibitive at n = 10⁵, while the GPU NUFFT kernel completes the full search in under 30 seconds at n = 10⁸. All methods achieve comparable predictive accuracy (MSE), confirming that the speedup comes without sacrificing statistical performance.

## Relation to Prior Work

This paper extends the NUFFT-based kernel evaluation framework pioneered by Potts & Steidl (2003) and more recently adapted to learning theory by Barnett et al. (2024) and Greengard et al. (2025), which was restricted to translation-invariant kernels with easily computable Fourier series. The key departure is that the present framework applies whenever the kernel *norm* can be efficiently expressed in Fourier space, not merely the kernel itself, thereby covering physics-informed kernels where translation invariance fails. For additive models, this is the first O(d²n log n) algorithm, improving on the O(max(n^{7/5}, d²n)) complexity of spline-based GAMs (Wood et al., 2014) and the FALKON random-feature approach (Rudi et al., 2017).

## Why It Matters / Open Questions

The O(n log n) complexity with GPU acceleration enables exact (not approximate) kernel regression on tens of billions of samples in minutes, a regime previously inaccessible to kernel methods, while provably achieving Sobolev minimax rates. A notable conceptual finding is that the L²-Fourier (Dirichlet) kernel, which does not approximate any infinite-dimensional RKHS, consistently outperforms the 'natural' Sobolev/Matérn kernel by roughly an order of magnitude in MSE, challenging the assumption that the kernel matching the target function class is optimal. Key limitations include the cuFINUFFT restriction to d ≤ 3 (exponential scaling in d), the additive model implementation covering only simple effects without interactions, and the open question of deriving matching lower bounds for the L²-Fourier estimator to confirm its theoretical superiority.

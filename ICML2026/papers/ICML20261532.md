## Problem

Existing agent memory benchmarks evaluate memorization and action in isolation: recall-oriented benchmarks (e.g., LoCoMo, LongMemEval) test static retrieval over fixed text without agentic decision-making, while single-session agent benchmarks (e.g., WebArena, SWE-bench) do not require persistent memory across episodes. This paper identifies that in realistic multi-session settings, memorization and action are tightly coupled—agents must distill experiences into memory during interaction and then reuse that memory to guide later decisions—yet no existing benchmark evaluates this coupled Memory-Agent-Environment loop.

## Input / Output

Each evaluation episode presents a sequence of interdependent subtasks (sessions) where the agent receives a subtask instruction and environment observations at each action step, plus retrieved memory from a persistent store initialized empty at episode start. The agent outputs a sequence of grounded actions (tool calls, navigation clicks, symbolic reasoning steps) averaging 57 steps per task with traces exceeding 40k tokens. Evaluation produces three metrics: Task Success Rate (full task completion), Progress Score (fraction of subtasks correctly completed), and a soft Progress Score giving partial credit per constraint, enabling fine-grained diagnosis when full success is rare.

## Method

MEMORYARENA is a unified evaluation gym spanning four human-crafted environments—Bundled Web Shopping (150 tasks), Group Travel Planning (270 tasks), Progressive Web Search (221 tasks), and Sequential Formal Reasoning in Math/Physics (60 tasks)—each with explicitly interdependent subtasks where later actions are underspecified without information from prior sessions. The core mechanism is the Memory-Agent-Environment Loop: after each subtask completes, a persistent memory system is updated via an UPDATE function incorporating the full interaction trace, and before each action in subsequent sessions a RETRIEVE function returns task-relevant memory that conditions the agent's policy. The benchmark evaluates three memory paradigms under a unified interface: long-context agents (0D, verbatim history), external memory agents with learned consolidation (1D/2D, e.g., MemGPT, Mem0, Mirix, ReasoningBank), and RAG systems (0D/2D, e.g., BM25, embedding RAG, MemoRAG, GraphRAG). Tasks are constructed to enforce strict causal ordering among subqueries or constraint chains, with human-verified compatibility maps, unique ground-truth solutions, and negative distractors, ensuring that success requires both accurate recall and correct application of prior-session information rather than mere factual retrieval.

## Results

Across all four MEMORYARENA environments, every evaluated method achieves very low Task Success Rate (SR), with the best overall average SR being only 0.20 (Text-Embedding-3-Small RAG) and 0.19 (Gemini-3-Flash long-context). Group Travel Planning is the hardest domain, with SR and PS near zero for all 13 methods. In Progressive Web Search and Formal Reasoning, RAG systems (Text-Embedding-3-Small: SR 0.23/0.25 for Search/Math) and long-context agents (GPT-5.1-mini: SR 0.21/0.30 for Math/Phys) outperform external memory agents (Letta: SR 0.16/0.11), while in Bundled Web Shopping, long-context agents (Gemini-3-Flash and Claude-Sonnet-4.5: SR 0.12) marginally lead over all memory and RAG variants (SR 0.00).

## Baselines & Comparisons

The paper evaluates 13 configurations across three memory paradigms (long-context, external memory agents, and RAG systems) using GPT-5.1-mini as the task agent. No single paradigm dominates: long-context agents (Gemini-3-Flash, Claude-Sonnet-4.5) achieve the best Bundled Web Shopping SR (0.12) and competitive Formal Reasoning scores, while RAG systems (Text-Embedding-3-Small) lead in Progressive Web Search (SR 0.23) and Math (SR 0.25), and external memory agents (Letta/MemGPT) achieve the best Physics SR (0.45–0.65). Critically, external memory and RAG do not consistently outperform raw long-context, which the authors attribute to representation and training mismatches. In Group Travel Planning, all 13 methods collapse to near-zero SR and PS, indicating that no current memory mechanism can handle the deeply interdependent constraint chains (up to depth 4) required. The paper's central empirical claim is that agents achieving near-saturated scores on recall-oriented benchmarks like LoCoMo still fail dramatically in this agentic multi-session setting, with the best overall average SR being only 0.20.

## Relation to Prior Work

This paper carves out a new evaluation space at the intersection of two previously isolated lines of work: memory-recall benchmarks (LoCoMo, LongMemEval, MemoryAgentBench) that test static recall without agentic action, and single-session agentic benchmarks (WebArena, WebShop, SWE-bench) that test action without requiring persistent cross-session memory. It builds directly on WebShop, TravelPlanner, and BrowseComp-Plus as environment substrates, but fundamentally restructures them into multi-session tasks with explicit interdependent subtasks where later actions are underspecified without information from earlier sessions. The paper positions itself against recent partial efforts (Evo-Memory, AgencyBench, Mem2ActBench, MemoryGym) by arguing that none enforce explicit cross-task causal dependencies, and frames the Memory-Agent-Environment loop as the missing evaluation paradigm.

## Why It Matters / Open Questions

The central empirical finding—that agents achieving near-saturated scores on established memory benchmarks like LoCoMo exhibit near-zero task success in multi-session agentic settings—exposes a significant gap between recall capability and functional memory use in goal-driven interaction. The POMDP framing (belief drift, failure to track vs. failure to utilize) provides a useful diagnostic lens, and the case studies concretely illustrate retrieval failures and 'lost in the middle' effects. Limitations include the relatively small task-level scale (701 tasks), heavy reliance on a single primary task agent (GPT-5-mini), and the acknowledged need for finer-grained analysis of individual memory operations. The benchmark is released as a growing community resource, and the authors explicitly invite expansion into expert-intensive domains.

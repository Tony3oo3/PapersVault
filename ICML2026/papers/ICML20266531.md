## Problem

Existing synthetic data creation pipelines—data generation, automated annotation, and domain adaptation/selection—treat upstream data-centric processes as isolated modules optimized independently of downstream model performance. This disconnect means generated data may not effectively improve target models, auto-generated labels lack end-to-end verification, and adaptation decisions are made without feedback from downstream validation. The paper argues that multi-level optimization (MLO) is essential to close this gap by enabling feedback-driven, end-to-end coordination across all data creation stages.

## Input / Output

The framework consumes a small real labeled dataset (e.g., medical images with 2D segmentation masks), unlabeled data sharing the same distribution, source-domain examples from auxiliary domains, or outputs from physics-based simulation models. It produces synthetic labeled training data with potentially complex label structures (e.g., pixel-wise segmentation maps), automatically verified labels for unlabeled data, and example-specific adapted or selected source data. A key structural detail is that the real dataset is split into training and validation subsets, with the validation set serving as the feedback signal that drives upstream hyperparameter optimization at each MLO level.

## Method

The paper formulates synthetic data creation as a nested hierarchy of optimization problems where each level corresponds to a pipeline stage (e.g., label generation → conditional data generation → downstream model training → validation), and the solution at each lower level becomes a variable in the upper level's objective. Downstream validation loss is back-propagated through the nesting to update upstream hyperparameters—such as generator architectures via DARTS, LLM prompts via Gumbel-Softmax relaxation and LoRA, or domain distance metric weights—enabling iterative refinement of data quality. The framework is instantiated across three paradigms: GenSeg (a three-level MLO using a Pix2Pix GAN for mask-to-image generation guided by segmentation validation loss), an annotation pipeline with sequential self-consistency and supervised verification stages, and a four-level example-specific adaptation/selection framework using a learned Domain Distance Metric. All formulations are solved using first-order implicit differentiation and the Betty automatic differentiation library, avoiding explicit second-order computations while maintaining stable end-to-end training.

## Results

GenSeg, the MLO-based data generation framework, achieves Dice scores of 0.508 (CVC), 0.697 (ICFluid), 0.604 (FUSeg), and 0.673 (ISIC), consistently outperforming the BBDM diffusion-model baseline on all four medical segmentation datasets. GenSeg also significantly outperforms standard augmentation methods (rotation, flipping, translation, combinations) and a WGAN-based generator across six additional datasets (FetReg, ISIC, CVC-Clinic, ICFluid, FUSeg, BUID) when paired with UNet or DeepLab segmentation models. The MLO framework's key advantage is that downstream validation performance directly guides the generative model's hyperparameters, yielding task-specific synthetic data rather than distribution-matched but task-agnostic samples.

## Baselines & Comparisons

The paper compares GenSeg against two main baselines. Against the BBDM (Brownian Bridge Diffusion Model) baseline, GenSeg wins on all four datasets: CVC (+2.8 pp), ICFluid (+1.3 pp), FUSeg (+3.4 pp), and ISIC (+3.5 pp) in Dice score, demonstrating that MLO-guided generation produces more task-relevant synthetic data than a strong diffusion model trained in isolation. Against the WGAN-based generator and standard augmentation methods (rotation, flipping, translation, and their combinations), GenSeg achieves significantly better Dice and Jaccard scores across all six medical segmentation datasets (FetReg, ISIC, CVC-Clinic, ICFluid, FUSeg, BUID) as shown in Figure 1, with the largest gains observed in ultra-low-data settings. The paper positions these comparisons as evidence that end-to-end MLO optimization—where downstream validation loss back-propagates to guide generator hyperparameters via DARTS—yields measurably better synthetic data than decoupled generation-and-training pipelines.

## Relation to Prior Work

This position paper unifies three previously separate lines of work—synthetic data generation (GANs, diffusion models, VAEs), automated annotation (Snorkel, Snuba, Meta Pseudo Labels), and domain adaptation/selection—under a single multi-level optimization (MLO) framework. It departs from the dominant modular pipeline paradigm, where each stage is optimized independently with proxy objectives, by arguing that downstream validation performance should be back-propagated through nested optimization levels to guide upstream data-centric decisions. The paper builds directly on the authors' prior MLO instantiations (Gala & Xie, 2024 for class-specific generation; Xie et al., 2024 for example-specific adaptation; Somayajula et al., 2022 for text augmentation) and on algorithmic advances in hypergradient computation (Betty, DARTS, implicit differentiation) that make multi-level formulations tractable.

## Why It Matters / Open Questions

The paper provides a principled, unifying lens for data-scarce domains (healthcare, physics, low-resource NLP) where ad-hoc modular pipelines struggle to align synthetic data with actual model needs. Key open questions include: whether MLO's advantages persist at ImageNet-scale data richness (the authors concede gains are modest there), how to handle non-differentiable components like diffusion sampling without RL, and whether the engineering overhead of nested optimization justifies the gains over simpler fine-tuning or self-training baselines. The empirical evidence is explicitly preliminary (small medical imaging datasets, limited baselines), so the framework's broader applicability remains to be validated at scale.

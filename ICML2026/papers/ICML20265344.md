## Problem

Existing LLM IP verification methods face a fundamental trade-off: invasive watermarking degrades model utility and cannot be retroactively applied, while non-invasive behavioral fingerprints (output distributions, memorized responses) are fragile under common post-training transformations like fine-tuning and model merging. The paper asks whether robust, non-invasive identity verification is possible by anchoring fingerprints in stable internal computational structures rather than superficial output patterns.
![Teaser figure](../imgs/ICML20265344/cropped_page1_idx1.webp)

## Input / Output

Fingerprint construction requires full parameter access to the victim model to extract circuit anchors and optimize 20-token adversarial prefixes via GCG over 1500 iterations. At verification time, only standard API query access to the suspect model is needed: each probe (prefix + cloze prompt) is submitted as a normal inference request, and the response is checked for the predicted collapse token within the top-n highest-probability tokens at the first decoding step. The aggregate Fingerprint Success Rate across N probes is evaluated via a statistical hypothesis test (Bernoulli trials with CLT-based standard error) to distinguish derived variants from unrelated models, accommodating both deterministic (T=0) and stochastic (T>0) decoding settings.

## Method

CircuitPrint identifies task-essential supernodes in the victim model using cross-layer transcoder features and attribution graphs, retaining only those that are causally necessary (induce a relative probability drop ≥ τ_Δ when suppressed) and produce confident clean predictions (rank-1/rank-2 margin ≥ τ_base). For each anchor supernode, a 20-token adversarial prefix is synthesized via GCG optimization with a three-term composite loss: mechanistic alignment (minimizing Euclidean distance between the probe-induced activation and the directly suppressed activation state), a surgical ratio constraint (penalizing off-target activation shifts to localize the perturbation), and KL-divergence regularization (preserving output distribution semantics). Retained probes must induce a dominant collapse token exceeding the clean prediction by a threshold ratio τ_coll. Verification then checks whether the suspect model reproduces the predicted collapse tokens across the full probe set, grounding identity in the model family's shared causal circuit structure rather than mutable surface behaviors.

## Results

CircuitPrint achieves an average Fingerprint Success Rate (FSR) of 87.7% on Gemma-2-2B derivatives and 84.9% on LLaMA-3.2-1B derivatives, substantially outperforming behavioral baselines ProFLingo (36–51%) and TRAP (25–42%) across fine-tuned and merged variants. On independently trained unrelated models, CircuitPrint yields near-zero FSR (0.00–0.08), confirming high specificity. Performance remains stable across standard temperature (T ≤ 1.0) and top-p (0.55–1.0) sampling ranges, with degradation only at extreme temperatures that compromise general model utility.

## Baselines & Comparisons

CircuitPrint substantially outperforms both behavioral baselines across all derivative models. Against ProFLingo, CircuitPrint achieves 0.79–0.97 FSR on Gemma-2-2B derivatives versus ProFLingo's 0.36–0.51, a gap of roughly 0.35–0.50 FSR points; the gap widens further under model merging where ProFLingo drops to 0.30–0.43. Against TRAP, the advantage is even larger: CircuitPrint scores 0.79–0.97 versus TRAP's 0.25–0.42, with TRAP degrading most sharply under fine-tuning (e.g., 0.27 on unsloth/gemma-2-2b-it). Against the invasive backdoor watermark CTCC, CircuitPrint achieves comparable performance (0.79–0.97 vs. 0.79–0.95 on Gemma-2-2B derivatives; 0.77–0.93 vs. 0.79–0.94 on Llama-3.2-1B derivatives), matching or occasionally exceeding CTCC while requiring no training-stage modification. On unrelated models, all methods produce near-zero FSR, but CircuitPrint's negative scores (0.00–0.08) are consistently at or below the baselines, confirming its high specificity.

## Relation to Prior Work

This paper repurposes the circuit-tracing and attribution-graph framework from mechanistic interpretability (Ameisen et al., 2025; Elhage et al., 2021) as a tool for LLM IP verification, a domain previously dominated by invasive watermarking (CTCC, IF, UTF) and behavioral fingerprinting (ProFLingo, TRAP). The feature-level substrate is instantiated via cross-layer transcoders (Dunefsky et al., 2024), and the key methodological bridge is using GCG adversarial optimization to project internal supernode interventions onto discrete input prefixes executable through standard API queries. The authors explicitly state they do not propose a new circuit formalism; their contribution is the application of an existing interpretability toolkit to a security/verification problem, combined with the adversarial probe synthesis that makes it accessible in black-box settings.

## Why It Matters / Open Questions

CircuitPrint resolves a long-standing tradeoff between model utility and IP protection by grounding verification in stable internal computational structure rather than fragile surface behaviors, achieving watermarking-level accuracy without any training-stage modification. The near-clone experiment (strict near-clone trained on identical data yields only 7% FSR vs. 85% for the victim) provides strong evidence that circuits are truly instance-specific, not merely architecture- or data-specific. Open questions include scalability to larger models (10B+), robustness under more aggressive transformations like distillation or architecture changes, and whether the small set of factual-recall tasks used here generalizes to open-ended generation. The approach also raises practical questions about the computational cost of probe synthesis and the number of queries needed for reliable verification in production API settings.

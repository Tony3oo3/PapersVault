## Problem

The term 'hallucination' has fragmented across NLP subfields—summarization, open-domain QA, RAG, agentic systems, and vision-language models—each adopting task-specific definitions that make cross-benchmark comparison, mitigation transfer, and basic questions about hallucination rates nearly impossible to answer. No prior work provides a single formal framework that subsumes all existing definitions and makes the implicit assumptions (what counts as truth, what the model can observe, how conflicts resolve) explicit and comparable.

## Input / Output

The framework consumes a model output y (text or action), a reference world model W (instantiable as a source document, knowledge base, environment DOM, game state, or executable program), a view function V(W,x) specifying the subset of W observable to the model for input x, and a conflict policy P governing how contradictory sources are reconciled. It produces a binary hallucination determination plus per-claim truth labels (true/false/unknown) by first extracting atomic claims C(y) from the output—a step whose granularity is a benchmark-design choice—and then evaluating each claim against T_{W,P}. Notably, W need not be a single static label; in agentic or partially observed settings, truth can depend on state, interaction history, and the model's available view, which a fixed ground-truth answer cannot capture.

## Method

The paper formalizes hallucination as inaccurate world modeling observable to the user, defined through three components: a reference world model W = (S, H, R) encoding admissible states, interaction histories, and consistency rules; a view function V(W, x) selecting the portion of W relevant to input x; and a conflict policy P with an associated truth function T_{W,P}(x, c) ∈ {true, false, unknown} that adjudicates atomic claims. An output y hallucinates iff ∃ c ∈ C(y) such that T_{W,P}(x, c) = false. The key insight is that all prior definitions—source-grounded summarization faithfulness, factual QA accuracy, RAG context contradiction, agentic observation errors, and VLM modality conflicts—are recovered by different choices of W, V, and P, making the framework a unifying lens rather than a new task. The paper further demonstrates that fully specified synthetic environments (chess, NetHack, gridworlds) allow W, V, and T_{W,P} to be programmatically known, enabling large-scale hallucination benchmarks where labels are determined by construction rather than human or LLM annotation, as instantiated in the companion HALLUWORLD benchmark.

## Results

This is a position paper that proposes a formal framework rather than reporting quantitative experimental results. The key contribution is a unified definition of hallucination as inaccurate world modeling, formalized via a reference world model W = (S, H, R), a view function V, a conflict policy P, and a truth function T_{W,P}. The paper demonstrates the framework's unifying power through four worked examples (RAG, agentic web navigation, summarization, open-domain QA) and a chess-based benchmark construction recipe, showing how hallucination labels can be determined by construction rather than annotation. No empirical benchmarks are run; the companion HALLUWORLD benchmark (Liu et al., 2026) is referenced as the operationalization of this framework.

## Baselines & Comparisons

As a position paper, this work does not empirically compare methods against baselines. Instead, it provides a conceptual unification of existing hallucination definitions and benchmarks. The paper maps prior work onto its framework: FavaBench (Mishra et al., 2024) is noted as relatively well-grounded because retrieval logs make V observable; HALoGEN (Ravichander et al., 2025) is partially grounded with structured tasks exposing V; HaluEval (Li et al., 2023a) requires more explicit claim extraction C(y) with weaker grounding in both V and W. The paper also distinguishes its contribution from Fang et al. (2024), which takes a mechanism-oriented perspective on why hallucinations occur, whereas this work formalizes what counts as hallucination. The framework is positioned as complementary to, not competitive with, existing mitigation approaches (retrieval, calibration, architectural changes), explaining each as targeting different components (V, T_{W,P}, or W) of the hallucination pipeline.

## Relation to Prior Work

This position paper does not build on a single prior method but rather synthesizes and unifies the fragmented definitions of hallucination that have emerged across NMT (Lee et al., 2019), abstractive summarization (Maynez et al., 2020), open-domain QA, VLMs (HallusionBench, SavvyBench), and agentic settings (MIRAGE-Bench). Its key conceptual move is to recast all these task-specific definitions as instantiations of a single formal template—(reference world model W, view function V, conflict policy P)—borrowing the 'world model' concept from agent literature and giving it a precise evaluation-theoretic role. The authors position their framework as complementary to Fang et al. (2024), which takes a mechanism-oriented view of *why* hallucinations occur, whereas this paper formalizes *what counts as* a hallucination in the first place.

## Why It Matters / Open Questions

The framework's practical value lies in forcing benchmark designers to explicitly state W, V, and P, which the authors argue is the hidden source of disagreement across existing hallucination benchmarks (e.g., FavaBench vs. HALoGEN vs. HaluEval). It also cleanly separates hallucination (incorrect world-modeling) from planning errors and incentive misalignment, a distinction that has been muddled in agentic LLM evaluation. Open questions remain: how to handle evolving reference worlds, how to systematically study conflict policies, and how to scale the synthetic-environment benchmark recipe beyond chess to web navigation, code repos, and multimodal simulators. The companion HALLUWORLD benchmark (Liu et al., 2026) is the concrete first step toward operationalizing these ideas.

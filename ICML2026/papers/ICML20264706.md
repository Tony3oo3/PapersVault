## Problem

Existing language-image pre-training for remote sensing object detection relies on Monolithic Label Learning, which treats each category as an indivisible semantic unit and requires exhaustive enumeration of open-set categories via large-scale image-text pairs. This paradigm faces two fundamental barriers in remote sensing: the domain lacks the massive fine-grained textual supervision needed to implicitly learn discriminative representations, and the holistic category matching prevents the model from capturing fine-grained structural differences (e.g., engine count, wing shape) between visually similar targets.

## Input / Output

The model takes remote sensing image patches (1024×1024 or 800×800 crops) and structured text prompts as input, where prompts are not free-form descriptions but serialized combinations of orthogonal attribute primitives prefixed with a fixed ProtoTag (e.g., 'Plane + four engines + swept wings'). For detection, visual features are extracted via RoI pooling; for classification, the global [CLS] token is used. The output is bounding boxes annotated with fine-grained category labels and/or specific attribute values, enabling both standard detection and attribute-conditioned localization (e.g., detecting only 'Plane + Eight-engine + Propeller').

## Method

SLIP-RS replaces monolithic category alignment with a Structured-Attribute Decoupling Paradigm that decomposes objects into a finite set of orthogonal, mutually exclusive semantic primitives (e.g., engine count, wing configuration, propulsion type). The core training mechanism, Structured-Attribute Contrastive Learning (SACL), constructs instance-specific contrastive sets: positive prompts are generated by randomly shuffling and dropping attributes from the ground-truth set (enforcing permutation invariance and partial-observability robustness), while hard negatives are synthesized via Attribute Replacement—swapping one primitive with a contradictory value from the same dimension—forcing the model to verify local visual cues rather than rely on coarse category boundaries. To address the scarcity of attribute annotations, the Conformal Attribute Reliability Engine (CARE) operates a Tune-Calibrate-Scale pipeline: it fine-tunes RemoteCLIP-ViT/32B with LoRA into a fine-grained teacher (RemoteCLIP-FG), applies conformal prediction to derive statistically valid per-attribute confidence thresholds with guaranteed false-discovery-rate control, then scales to produce RS-Attribute-15M (15M+ instance-level attribute annotations). The full system is built on Faster R-CNN with a ConvNeXT backbone (DINOv3-initialized) and a frozen RemoteCLIP-FG text encoder, using RFLA label assignment to accommodate noisy pseudo-labels.

## Results

On DOTA-v2.0 (HBB), SLIP-RS with ConvNeXT-L backbone trained on RS-Attribute-15M achieves 47.14% mAP, surpassing the strongest open-vocabulary baseline OpenRSD (44.57%) by 2.57 points. On DIOR-H, the same model reaches 83.10% AP50, outperforming ViTP (79.80%) and OpenRSD (76.70%). In the zero-shot setting (trained only on RS-C), SLIP-RS still attains 35.63% mAP on DOTA-v2.0. On the oriented detection benchmark DOTA-v2.0 (OBB), SLIP-RS (ConvNeXT-L, 198M params) achieves 62.54% mAP, exceeding the billion-parameter BFM (58.69%) and ViTP (60.23%).

## Baselines & Comparisons

SLIP-RS (ConvNeXT-L) outperforms all baselines on DOTA-v2.0 HBB fine-tuning: it leads OpenRSD (44.57%) by 2.57 mAP, LAE-DINO (39.38%) by 7.76 mAP, and the standard Faster R-CNN (39.21%) by 7.93 mAP. On DIOR-H, SLIP-RS (83.10% AP50) surpasses ViTP (79.80%) by 3.30 points and OpenRSD (76.70%) by 6.40 points. In the fine-grained attribute recognition setting (Table 3), SLIP-RS dominates by a wide margin: on Plane Purpose it achieves 72.04% mAP versus 9.03% for OpenRSD and 1.04% for LAE-DINO, and on Number of Engines it reaches 80.47% where both baselines report no scores. On Xview (Table 5), SLIP-RS* (27.2% AP50) edges out ViTP (26.6%) despite using a much smaller ConvNeXT-T backbone versus ViT-L. On DOTA OBB (Table 6), SLIP-RS (62.54% mAP, 198M params) beats ViTP (60.23%, 347.9M), S5 (59.89%, 671.7M), and BFM (58.69%, 2.4B), demonstrating superior parameter efficiency.

## Relation to Prior Work

SLIP-RS departs from the dominant open-vocabulary detection paradigm (GLIP, Grounding DINO, LAE-DINO, OpenRSD) that aligns visual features with holistic category-name embeddings via CLIP-style contrastive learning. Instead, it reframes the supervision signal from monolithic category labels to a finite, orthogonal set of structured attributes, performing contrastive alignment at the attribute level (SACL) rather than the category level. The text encoder is a fine-tuned RemoteCLIP (RemoteCLIP-FG), and the pseudo-label quality control borrows conformal prediction theory (Shafer & Vovk, 2008) to replace heuristic thresholding with statistically guaranteed error bounds. The detection backbone remains a standard Faster R-CNN with ConvNeXT initialized by DINOv3, so the novelty is concentrated in the pre-training objective and data curation pipeline rather than the detector architecture.

## Why It Matters / Open Questions

The introduction of RS-Attribute-15M (15M+ instance-level attribute annotations across plane, ship, and vehicle) is the most immediately impactful contribution, providing a data resource that did not previously exist for fine-grained RS detection. The structured-attribute paradigm offers a principled escape from the data-scaling bottleneck of open-vocabulary methods: by working in a finite attribute space rather than an open category space, fine-grained discriminability becomes learnable without exhaustive enumeration. However, attribute definitions remain coarse for ships and vehicles relative to planes, and compositional zero-shot detection (detecting unseen categories via novel attribute combinations) is only preliminarily demonstrated with synthetic samples, leaving open whether the approach generalizes to truly novel attribute combinations in the wild.

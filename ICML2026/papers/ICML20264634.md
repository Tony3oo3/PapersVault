## Problem

Existing approaches to incomplete multimodal sentiment analysis fall into two paradigms with complementary failures: recovery-based methods (e.g., diffusion generators) incur prohibitive inference latency and risk semantic drift due to the absence of class-level statistical priors, while non-recovery-based methods rely on static global projections that collapse instance-specific affective nuances into generic representations. The paper asks how to simultaneously preserve semantic consistency with the target sentiment class, capture sample-specific affective cues, and maintain low-latency inference without generative overhead.

## Input / Output

The method consumes sequential per-modality features (BERT for text, Facet for vision, COVAREP for audio) projected to a common hidden dimension via 1D temporal convolutions, along with a binary mask indicating which modalities are entirely absent (inter-modality missingness; at least one modality must be present, bounding the missing rate to ≤0.67). It outputs a continuous sentiment score in [-3, 3] via a downstream regression head, evaluated with ACC₂ and F1 after discretizing predictions into positive/negative classes. The framework is evaluated under single-modality missing ({l}, {v}, {a}) and random 1- or 2-modality missing protocols at missing rates from 0.1 to 0.7.

## Method

API reconceptualizes missing-modality imputation as a retrieval-and-modulation process rather than a generative task, coupling two components. SCOPE (Semantic-anchored Class-Temporal Prototype Estimation) discretizes continuous sentiment labels into 7 ordinal classes, then accumulates per-epoch feature caches per modality and class, updating non-trainable temporal prototypes via Centroid-Filtered Aggregation (discarding the 5% most distant samples from the class centroid); an InfoNCE contrastive loss aligns sample features toward their ground-truth class prototype while repelling others. DIAM (Directional Instance-Adaptive Affine Modulation) uses six direction-specific single-hidden-layer MLP groups (one per cross-modal pair) to generate feature-wise scaling (γ) and shifting (β) parameters from the pooled source feature, which are then applied to the retrieved class prototype via element-wise affine modulation to produce the imputed sequence. Joint Modality-Class Selection picks the conditioning source by maximizing prototype-similarity across available modalities and classes, breaking ties with minimum class-distribution entropy. Training combines MAE task loss, the prototype-contrastive loss, and a reconstruction consistency loss aggregated over all six source-target direction pairs.

## Results

On CMU-MOSI, API achieves an average F1 of 79.6% across missing rates (MR) 0.1–0.7, outperforming the strongest baseline HME (78.7%) by 0.9 points. On CMU-MOSEI, API reaches an average F1 of 77.8%, again edging out HME (76.9%). Under extreme missingness (MR=0.7 on MOSI), API maintains 74.1% F1 versus 71.7% for HME and 67.1% for IMDer, demonstrating resilience when only one modality remains. API also achieves the lowest inference latency (~46–48 ms) and fewest missing-modality parameters (~0.05–0.14 M) among all compared methods.

## Baselines & Comparisons

API outperforms all seven baselines on both CMU-MOSI and CMU-MOSEI across every missing rate. The closest competitor is HME (Zhuang et al., NeurIPS 2025), which API surpasses by 0.9% F1 on MOSI (79.6 vs. 78.7) and 0.9% on MOSEI (77.8 vs. 76.9); the gap widens at high MR (e.g., 2.4% at MR=0.7 on MOSI). Among recovery-based methods, IMDer (Wang et al., NeurIPS 2023) trails API by 3.4% F1 on MOSI and 3.2% on MOSEI, while DiCMoR (Wang et al., ICCV 2023) lags by 3.8% and 2.4% respectively. The meta-learning variant IMDer+M2AF (Tu et al., SIGIR 2025) underperforms even vanilla IMDer at higher MR, suggesting its meta-learning overhead does not compensate for the generative bottleneck. Non-recovery baselines LNLN (Zhang et al., NeurIPS 2024) and GCNet (Lian et al., IEEE PAMI 2023) are the weakest, with API leading by 9.6% and 6.0% F1 on MOSI averages, respectively. MPLMM (Guo et al., ACL 2024) shows the largest degradation under extreme missingness (56.2% F1 at MR=0.7 on MOSI), where API still retains 74.1%.

## Relation to Prior Work

This paper carves new ground by reframing missing-modality imputation in MSA as a retrieval-and-modulation process rather than a generative one, departing from both recovery-based methods (IMDer, DiCMoR) that rely on heavy diffusion/GAN generators and non-recovery methods (HME, LNLN, CorrKD) that use static global projections. Conceptually, it repurposes prototypical learning—typically designed for discrete classification—into a continuous regression setting via Ordinal Sentiment Discretization, and combines non-trainable class-temporal prototypes (SCOPE) with direction-specific affine modulation (DIAM) to decouple semantic anchoring from instance-level adaptation. The approach draws on contrastive learning (InfoNCE) for prototype alignment and lightweight MLPs for modulation, but the specific combination of statistical class anchors with instance-adaptive affine transforms for imputation is novel.

## Why It Matters / Open Questions

The practical impact is significant: API achieves competitive or superior accuracy while reducing inference latency from ~2241 ms (IMDer) to ~47 ms and missing-modality parameters from ~12M to ~0.14M, making real-time deployment of incomplete MSA feasible. The prototype-centric paradigm offers a lightweight alternative that avoids the semantic drift and computational overhead of iterative generative sampling. However, the work is limited to utterance-level inter-modality missingness on two standard benchmarks (CMU-MOSI/MOSEI); extending to intra-modality (frame-level) missingness, longer sequences, or additional modalities remains open. The OSD discretization into 7 classes, while practical, inherently quantizes continuous sentiment and may lose fine-grained ordinal information at class boundaries.

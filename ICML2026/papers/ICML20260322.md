## Problem

Cold-start personalization requires inferring user preferences from minimal interaction when no user-specific history exists, yet the preference space is vast, individual users care about only a sparse subset of dimensions, and interaction budgets are tightly limited. Existing approaches—end-to-end RL (e.g., GRPO) or simple prompting—must simultaneously discover preference correlations and learn adaptive questioning policies from sparse terminal rewards, leading to policy collapse (fixed question sequences) and poor individual alignment. The paper asks whether separating population-level preference structure learning from online individual inference can make Bayesian elicitation practical at scale for LLM systems.

## Input / Output

The method takes a task/problem (e.g., a medical question or math problem), a task-specific set of 20–30 preference criteria, and sequential user responses (typically on a 1–5 ordinal scale or categorical) to adaptively selected questions, all conditioned on an offline-learned belief model (Bayesian linear regression with ~10K parameters or a GMM). It outputs a predicted complete preference profile over all criteria—including dimensions never directly queried—by marginalizing over the posterior on a latent user embedding. This profile is then passed to a fixed black-box LLM solver (GPT-4.1) to generate the final personalized response, keeping elicitation and generation fully decoupled.

## Method

CAPE decomposes cold-start elicitation into two stages: (i) offline, it learns a structured world model of preference correlations from complete profiles using dense per-criterion supervision, parameterized as a Bayesian linear regression (each criterion's value is a linear function of a latent user embedding with Gaussian weight posteriors) or a GMM over K user types; (ii) online, for each new user it maintains a posterior over the latent embedding, updates it via Bayes' rule after each response, and selects the next question by maximizing mutual information between the response and the latent variable (or, alternatively, predictive entropy), all in closed form with no parameter updates at test time. This sidesteps the credit-assignment problem inherent in RL: the sample complexity is polynomial in the number of criteria and independent of the interaction budget T, whereas RL scales exponentially in T. The framework is modular and training-free at inference, requiring only ~10K parameters (versus 8B for RL baselines) while achieving 80.8% preference alignment versus 68.5% for GRPO with 3–5× fewer interactions.

## Results

CAPE achieves 77.4–87.3% of Oracle preference alignment across four reasoning domains (MedQA, AIME, SocialIQA, CSQA), outperforming the strongest RL baseline GRPO (55.2–76.2%) by 6–23 percentage points. CAPE requires 3–5× fewer interactions to reach equivalent alignment and adapts its follow-up question 39–62% of the time versus 0–28% for GRPO. Notably, CAPE achieves these gains with only ~10K parameters (Bayesian linear regression) compared to 8B parameters for the RL baselines, demonstrating that the bottleneck is inference structure rather than model capacity.

## Baselines & Comparisons

Against GRPO (the strongest RL baseline, trained with terminal PrefAlign rewards on Llama-3.1-8B), CAPE wins on all four datasets: 77.4 vs 71.4 on MedQA, 80.1 vs 76.2 on AIME, 87.3 vs 71.3 on SocialIQA, and 78.2 vs 55.2 on CSQA. The gap is largest on CSQA (23 points) where GRPO's fixed question sequences fail due to low cross-sample criterion overlap, and CAPE also requires 2.5–15× fewer queries to match GRPO's alignment. Against CollabLLM (trained with offline-DPO for general interactivity), CAPE wins decisively by 52–62 points across all domains (e.g., 87.3 vs 24.8 on SocialIQA), as CollabLLM's freeform follow-ups achieve high adaptivity (28–75%) but only 20–26% alignment because they do not target specific preference criteria. CAPE also outperforms the non-interactive Population Average baseline on three of four domains (MedQA, AIME, CSQA), confirming that adaptive elicitation adds value beyond population-level defaults.

## Relation to Prior Work

CAPE adapts collaborative filtering and Bayesian experimental design to the LLM personalization setting, where preference dimensions are task-specific rather than a fixed item catalog. It builds on the POMDP formulation of preference elicitation (Boutilier, 2002) and the active-learning/BALD acquisition framework (Houlsby et al., 2011), but departs from model-based RL (Ha & Schmidhuber, 2018; Hafner et al., 2023) by separating world-model learning (offline, dense per-criterion supervision) from policy execution (online, training-free Bayesian inference). The evaluation protocol and benchmark (PrefDisco, Li et al. 2026) come from the same group, and the RL baseline (GRPO on Llama-3.1-8B) represents the current end-to-end approach the paper argues is fundamentally limited by credit assignment under sparse terminal reward.

## Why It Matters / Open Questions

The core practical takeaway is that cold-start elicitation is a structure-learning problem, not a capacity problem: a ~10K-parameter Bayesian linear regression with information-gain selection outperforms an 8B RL model by 12+ alignment points and 3–15× in query efficiency, and the framework is training-free and plug-and-play with any solver LLM. Key limitations include reliance on simulated users, predefined structured criteria (not freeform natural-language elicitation), and no longitudinal or cross-session learning. Open questions the paper identifies include extending to natural-language questions and responses, automatic discovery of preference dimensions from data, and ensuring population-level correlations do not encode social biases.

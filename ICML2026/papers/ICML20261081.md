## Problem

Long-sequence modeling faces a fundamental trade-off: RNN-like models maintain fixed-size compressed memory with constant per-token cost but inevitably lose information, while Transformer attention retains lossless KV cache at the cost of quadratic computation and linearly growing memory. Prior hybrid approaches (e.g., Compressive Transformers, Infini-attention) either discard out-of-window information or use small attention windows (64–2048 tokens), failing to preserve attention's strengths on short-to-medium contexts while still incurring RNN overhead where it provides no benefit.

## Input / Output

The model consumes a long text sequence token-by-token in an autoregressive setting. Within a 32k-token sliding window (plus 128 attention sinks), standard causal attention operates on the full KV cache as lossless short-term memory. Once the sequence exceeds this window, each newly evicted KV pair is fed into the AHN module, which updates a fixed-size recurrent state (a matrix of shape H×H per head). The final output at each step is the sum of the sliding-window attention output and the AHN's query-accessed compressed memory, producing the next-token logits. The AHN adds only ~0.4% parameters relative to the base LLM.

## Method

The core contribution is the Artificial Hippocampus Network (AHN), a learnable recurrent compression module that processes KV pairs as they exit a large sliding window and maintains a fixed-size compressed long-term memory, inspired by the hippocampus's role in consolidating short-term into long-term memory. AHNs are instantiated with modern linear recurrent architectures (Mamba2, DeltaNet, GatedDeltaNet), each updating its state via a gated or delta-rule recurrence over the evicted (k, v) pair. Training uses a self-distillation scheme where the base LLM (e.g., Qwen2.5) is fully frozen and serves as its own teacher: the student is the same model with window attention + AHN, trained to match the teacher's output distribution via KL divergence, optimizing only the AHN's gating and output-projection weights. During training, sliding window sizes and attention-sink counts are randomized to encourage generalization across context lengths. At inference, AHNs remain inactive for sequences shorter than the 32k window (preserving exact full-attention behavior) and activate only beyond that threshold, reducing FLOPs by ~40% and memory cache by ~74% at 128k length while matching or exceeding full-attention quality.

## Results

On the 128k-length LV-Eval benchmark, AHN-GDN augmented Qwen2.5-3B-Instruct achieves an average score of 5.88, surpassing full attention (4.41) by 1.47 points while reducing inference FLOPs by 40.5% and memory cache by 74.0%. On InfiniteBench (128k), AHN-GDN scores 13.24 versus 9.52 for full attention. For the 7B model, AHN-GDN reaches 6.54 on LV-Eval (vs. 3.62 full attention) and 16.93 on InfiniteBench (vs. 13.50 full attention), with only 0.3% additional parameters. The efficiency gains scale with model size: the 14B model sees a 37.5% FLOP reduction and 74.1% memory cache reduction while improving LV-Eval average from 4.99 to 6.51.

## Baselines & Comparisons

AHN-augmented models consistently outperform the Sinks+SWA (attention sinks + sliding window) baseline across all three model sizes on both LV-Eval and InfiniteBench; for example, AHN-GDN on Qwen2.5-3B scores 5.88 vs. 4.59 on LV-Eval and 13.24 vs. 10.47 on InfiniteBench. Against Compressive Transformers (CT-Max and CT-Average), AHNs also win on both benchmarks, with the gap widening for larger models (e.g., 7B: AHN-GDN 6.54 vs. CT-Max 4.82 on LV-Eval). Remarkably, AHNs match or surpass full attention on LV-Eval (e.g., 3B: 5.88 vs. 4.41; 7B: 6.54 vs. 3.62) and InfiniteBench (e.g., 7B: 16.93 vs. 13.50) while using only ~59–66% of the model FLOPs and ~26% of the memory cache. On the RULER-128k exact-recall (needle-in-a-haystack) tasks, AHN-GDN performs on par with Sinks+SWA but markedly worse than full attention (e.g., 26.80 vs. 98.60 on single_1), revealing the inherent limitation of lossy compression for verbatim recall. Against sparse attention (strided, 16K window), AHN-GDN achieves a substantially higher LV-Eval average (5.88 vs. 4.01) on Qwen2.5-3B.

## Relation to Prior Work

This paper positions itself at the intersection of Compressive Transformers (Rae et al., 2020), which compress older context into a bounded FIFO memory but discard it when full, and modern linear recurrent models (Mamba2, DeltaNet, GatedDeltaNet) that maintain fixed-size hidden states. The key conceptual departure from prior attention-RNN hybrids (Infini-attention, MiL, LoLCATs, HQLT) is the use of a large 32k sliding window for attention, with RNN-like compression modules (AHNs) activating only when the sequence exceeds this window—framing the RNN as a 'hippocampus' that consolidates out-of-window information rather than a parallel or replacement mechanism. The self-distillation training scheme, which freezes the entire base LLM and trains only ~0.4% AHN parameters via KL divergence, is a practical departure from prior work that trains hybrid models from scratch or performs full fine-tuning.

## Why It Matters / Open Questions

The 40.5% FLOP reduction and 74% memory cache reduction while matching or exceeding full attention on 128k-context benchmarks makes long-context inference substantially more accessible, particularly for resource-constrained deployments. The 32k window design ensures zero degradation on short-context tasks (the model behaves identically to a pure Transformer below that threshold), making AHN a clean drop-in augmentation. However, the RULER NIAH results reveal a fundamental limitation: lossy compression cannot support exact-recall tasks, where AHN performs on par with sliding window attention and far below full attention. Open questions include adaptive memory management that preserves critical tokens in lossless form while compressing the rest, and whether the self-distillation approach generalizes to models trained from scratch rather than augmented post-hoc.

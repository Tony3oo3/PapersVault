## Problem

Existing streaming multi-armed bandits algorithms target global objectives and may output arms that arrived very early in the stream, ignoring the recency effect prevalent in applications like movie recommendation and privacy-constrained data retention. This paper introduces the sliding-window streaming MABs model, where only the most recent W arms are valid and expired arms are immediately evicted, and provides a comprehensive analysis of both pure exploration and regret minimization under this recency constraint.
![Teaser figure](../imgs/ICML20260337/cropped_page1_idx0.webp)

## Input / Output

The algorithm receives a single-pass stream of n arms with unknown sub-Gaussian reward distributions supported on [0,1], along with a window size W, and for exploration an accuracy parameter ε and confidence δ, or for regret minimization a total pull budget T divided into per-epoch budgets {T_j}. A critical constraint is that the algorithm can only store and pull arms within the current sliding window; expired arms are immediately deleted from memory, and the arrival order is adversarial. The output for exploration is an ε-best arm (or exact best arm) at each time step, and for regret minimization is a pull strategy achieving bounded epoch-wise regret, where the regret is defined relative to the optimal arm within each window position.

## Method

For ε-exploration, the core algorithm (BUCKET) partitions [0,1] into O(1/ε) equal-length buckets; each arriving arm is sampled s = O(ε⁻² log(W/δ)) times, assigned to the bucket matching its empirical mean, and only the most recent arm per bucket is retained, yielding O(1/ε) memory. The key insight is that bucket-based grouping is naturally compatible with sliding windows—expired arms are simply discarded—whereas amortization-based streaming techniques fail when the best arm changes due to window movement. For exact exploration, a lower bound via Yao's minimax principle on a descending-mean instance shows Ω(W) memory is necessary. For regret minimization, the paper introduces epoch-wise regret (dividing T pulls into n−W+1 epochs tied to window positions) and achieves O(Σⱼ √(WTⱼ)) regret with O(W) memory via per-window UCB, while proving that o(W) memory forces Ω(T/W²) regret through a hard distribution with alternating blocks of decreasing-mean arms.

## Results

For pure exploration, the paper establishes a sharp dichotomy: exact best-arm identification requires Ω(W) memory (Theorem 1), while ε-approximate exploration is solvable with only O(1/ε) memory and O(n/ε² · log(W/δ)) samples for the weak version (Theorem 2), or O(n/ε² · log(n/δ)) samples for the strong version (Lemma 4.2), with a matching Ω(n/ε² · log(n/W)) lower bound. For regret minimization, any algorithm with o(W) memory must incur Ω(T/W²) regret (Theorem 3), while O(W) memory achieves O(√(W·(n-W+1)·T)) regret via epoch-wise UCB. Empirically, the proposed algorithms reduce exploration error from >0.6 to <0.3 (a 50% reduction) at 0.3W memory, and reduce total regret by over 50% when memory increases from 0.05W to W.

## Baselines & Comparisons

The paper's primary comparisons are theoretical separations rather than head-to-head algorithm benchmarks. For exploration, the key comparison is between exact and approximate identification: exact exploration provably requires Ω(W) memory regardless of sample budget, while the proposed BUCKET algorithm achieves ε-approximation with only O(1/ε) memory — a constant for fixed ε. For regret, the comparison is between sub-linear memory (o(W)) and linear memory (Ω(W)): the former incurs Ω(T/W²) regret while the latter achieves O(√(W·(n-W)·T)), which can be better than the O(√(nT)) centralized bound. Empirically, the paper compares against a natural baseline that adapts streaming MABs by maintaining a top-k set of arms with the highest empirical rewards (with expiration handling). The baseline shows a large performance gap: increasing its memory does not yield significant improvement, whereas the proposed sliding-window-specific algorithms show smooth and substantial gains. On synthetic data (n=1000, W=50), the proposed ε-exploration algorithm reduces the gap to the true best arm by roughly 50% compared to the baseline at comparable memory, and the regret minimization algorithm reduces total regret by over 50% when memory scales from 0.05W to W.

## Relation to Prior Work

This paper extends the streaming multi-armed bandits model (Assadi & Wang, 2020; Jin et al., 2021; Maiti et al., 2021) by imposing a sliding-window expiration constraint, where only the most recent W arms remain valid. The core algorithmic technique—partitioning the reward range into O(1/ε) buckets and storing only the latest arm per bucket—is directly inherited from streaming MABs, but the authors show that amortization-based streaming techniques break down under arm expiration, necessitating the bucket-based approach. The lower bounds build on Yao's minimax principle and the sample-complexity lower bound of Mannor & Tsitsiklis (2004), while the regret upper bound leverages UCB-style algorithms (Audibert & Bubeck, 2009) applied per-window. The paper explicitly distinguishes its model from non-stationary and mortal bandits, where environment changes are driven by arm pulls rather than an external data stream.

## Why It Matters / Open Questions

The paper establishes a sharp dichotomy: exact best-arm identification requires Ω(W) memory (essentially storing the entire window), while ε-approximate identification needs only O(1/ε) memory, providing clear practical guidance for memory-constrained recommendation and privacy-sensitive systems. The introduction of epoch-wise regret is a necessary conceptual contribution—without it, the natural regret definition is ill-defined because the algorithm controls pull timing within each window. Open questions include whether multi-pass access improves memory efficiency, whether gap-dependent regret bounds (as in Ye et al., 2025 for streaming) extend to the sliding-window setting, and how the model generalizes to linear or combinatorial bandits.

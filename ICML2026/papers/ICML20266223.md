## Problem

While model merging is widely used to combine task-specific fine-tuned models, the factors driving its success remain poorly understood. Prior work has proposed that mergeability is an intrinsic, partner-independent property of individual models, but this framing obscures how mergeability patterns shift across different merging algorithms and task pairs. The paper asks: which interpretable pairwise properties actually predict merge success, and do these properties depend on the merging method?

## Input / Output

The framework takes two fine-tuned CLIP ViT checkpoints (B/16 or B/32) along with the pretrained base weights and a small calibration set (10 random samples per task) to compute 28 pairwise metrics offline across five categories (task vector geometry, effective rank, subspace overlap, activation-based, and gradient-based). It produces a per-method linear mergeability score and a set of L1-sparse coefficients identifying which metrics drive success, enabling pre-merge screening of candidate pairs without performing the merge. The output is a ranking of task pairs by predicted mergeability, validated via leave-one-task-out cross-validation on 190 pairs from 20 image classification tasks.

## Method

The core method is an L1-regularized linear optimization that learns per-method coefficients over 28 normalized pairwise metrics to maximize Pearson correlation with post-merge normalized accuracy, using Adam with early stopping and λ=1.0. The key design choice is optimizing correlation rather than MSE, since the goal is ranking task pairs by mergeability rather than predicting exact accuracy values; this yields a 3.7–4.5× improvement over MSE. Evaluation uses leave-one-task-out cross-validation, holding out all pairs involving one task to ensure generalization to unseen task combinations. The framework reveals that mergeability is method-dependent: five merging methods (Task Arithmetic, Weight Averaging, TSV, TIES, DARE) split into two success-fingerprint clusters, yet a stable method-agnostic core of gradient L2 distance and subspace overlap metrics persists across all methods and architectures. A toy fine-tuning experiment with gradient magnitude regularization demonstrates the findings are actionable, improving post-merge accuracy by +0.41 on average.

## Results

Under leave-one-task-out (LOTO) cross-validation, the L1-regularized linear predictor achieves average validation Pearson correlation r = 0.544 on ViT-B/16 and r = 0.647 on ViT-B/32 across five merging methods. TSV merging is the most predictable (val r = 0.627 / 0.692), while Task Arithmetic is the least (0.445 / 0.619). The generalization gap between train and validation is a relative drop of ~17.7% (B/16) and ~14.7% (B/32), with TSV and Weight Averaging showing the smallest gaps. Gradient-based metrics (encoder/input gradient L2 distance) consistently receive the largest-magnitude negative coefficients across all methods, confirming them as the most fundamental mergeability signals.

## Baselines & Comparisons

The paper does not benchmark against external mergeability predictors but instead validates its design choices through internal comparisons. The L1-regularized linear model outperforms an MLP (single hidden layer, 8 units, dropout 0.4) on average validation r (0.544 vs. 0.493 on ViT-B/16), winning on 4 of 5 methods and tying on one. Optimizing Pearson correlation instead of MSE yields a 3.7× improvement in validation r on ViT-B/16 (0.544 vs. 0.147) and 4.5× on ViT-B/32 (0.648 vs. 0.143), because MSE must simultaneously learn ranking and output scale. L1 regularization (λ=1.0) reduces fold-to-fold standard deviation of validation r from 0.254 to 0.159 on B/16 while using only ~60% of the features (17–19 vs. 27–28 active metrics), and consistently suppresses effective-rank metrics that introduce noise. Metric-category ablations confirm gradient-based metrics are the most critical (removing them drops r by −0.149 on B/16, −0.131 on B/32), while effective-rank metrics are the only category whose removal improves performance (+0.020 / +0.012).

## Relation to Prior Work

This paper departs from the recent 'intrinsic mergeability' hypothesis of Rahamim et al. (2026), which treats mergeability as a partner-independent scalar property of individual models (analyzed only under LoRA/KNOTS). It also contrasts with black-box predictors for merge outcomes (Bolton et al., 2026) and earlier similarity-signal approaches (Yang et al., 2023; Matena & Raffel, 2022) by using an interpretable L1-regularized linear model over 28 pairwise metrics. Conceptually, it builds on the task-vector and gradient-alignment literature (Ilharco et al., 2023; Daheim et al., 2024; Zhou et al., 2025a) but repurposes these geometric quantities as diagnostic features rather than merging operators, framing mergeability as a dynamic, method-dependent pairwise relationship rather than a static model attribute.

## Why It Matters / Open Questions

The framework provides practitioners with a lightweight, interpretable pre-merge screening tool: gradient L2 distance and subspace overlap serve as method-agnostic compatibility checks, while method-specific fingerprints guide algorithm selection. Key limitations include restriction to pairwise merging (k=2), vision classifiers only, and the need for a small calibration set for gradient/activation metrics. Open questions include extending to k-way merging, other modalities (NLP, audio), and developing principled fine-tuning strategies that simultaneously optimize multiple discovered signals for a target merging method. The proof-of-concept regularization experiment (Δ=+0.41) suggests actionable gains but is modest, leaving room for more sophisticated merge-aware training.

## Problem

Prior test-time scaling methods for scientific discovery (e.g., AlphaEvolve) perform search by prompting a frozen LLM, so the model itself cannot internalize new ideas specific to the test problem. This paper asks: can we instead perform reinforcement learning at test time so the LLM continues to train on experience specific to the single problem it is trying to solve? The key challenge is that discovery differs from standard RL in two critical ways: the goal is to produce one exceptional solution (not maximize average reward) and to solve this very problem (not generalize to others).

## Input / Output

The method takes a text description of a scientific problem (which induces a continuous, verifiable reward function such as inverse kernel runtime or a certified mathematical bound) and a pre-trained LLM policy (gpt-oss-120b with LoRA rank 32). It produces a single best solution — a GPU kernel in Triton, a step-function certificate for a mathematical inequality, an algorithm for a competitive programming contest, or a denoising pipeline — that surpasses the current state of the art. The reward is zero if the solution fails validity checks or times out, and the method runs 50 training steps of 512 rollouts each (~$500 on Tinker), returning the single highest-reward state found across all steps.

## Method

TTT-Discover performs online RL on a single test problem with two tailored components. First, an entropic objective J_β(θ) = E[log E[e^{βR}]] replaces the standard expected-reward objective, so that as β→∞ the policy gradient favors the maximum-reward action rather than the mean; β(s) is set adaptively per initial state by enforcing a KL budget (γ=ln2) on the induced tilted distribution, preventing instability early in training and vanishing advantages later. Second, a PUCT-inspired reuse rule selects which prior solution to warm-start from, using the maximum (not mean) child reward in Q(s), a rank-based prior P(s) over the buffer, and backpropagated visitation counts to balance exploitation of high-reward states with exploration of under-visited ones. The policy is updated via LoRA with one gradient step per batch of 512 rollouts (8 groups of 64 sharing the same context), with importance-sampling correction for the sampler/learner mismatch. This combination of max-oriented objective and optimistic state selection is the core distinction from both naive RL (which optimizes expected reward) and evolutionary search (which uses handcrafted mutation/crossover heuristics on a frozen model).

## Results

TTT-Discover sets new state-of-the-art across nearly all tested domains using only the open model gpt-oss-120b. In GPU kernel engineering (TriMul), it achieves 1161.2 μs on H100 (vs. 1371.1 μs best human, a 15% improvement) and 2198.2 μs on A100 (vs. 4531.5 μs best human, a 51% improvement). In mathematics, it improves Erdős' minimum overlap upper bound to 0.380876 (vs. 0.380924 by AlphaEvolve) and the first autocorrelation inequality to C₁ ≤ 1.50287 (vs. 1.50317 by AlphaEvolve V2). In single-cell denoising, it achieves MSE 0.15 on PBMC and 0.14 on Tabula (vs. 0.19 and 0.18 for MAGIC), and in AtCoder AHC it scores within 0.01% of the 1st-place human on both contests.

## Baselines & Comparisons

Against Best-of-25600 (same model, same 25,600 total rollouts), TTT-Discover dominates across all domains: on TriMul H100 it achieves 1161.2 μs vs. 5390.3 μs (4.6× faster), and on Erdős' problem it reaches 0.380876 vs. 0.380906. Against the evolutionary search baseline OpenEvolve (same model, same budget), TTT-Discover wins on Erdős (0.380876 vs. 0.380965), AC1 (1.50287 vs. 1.50719), TriMul (1161.2 vs. not reported but implied worse), and single-cell denoising (MSE 0.15 vs. 0.16 on PBMC). Against prior SOTA AlphaEvolve/AlphaEvolve V2 (which use closed Gemini-2.0 models), TTT-Discover with the open gpt-oss-120b improves Erdős' bound by 16× the margin AlphaEvolve achieved over the previous SOTA, and improves AC1 from 1.50317 to 1.50287. Against the concurrent test-time training method ThetaEvolve (R1-Qwen3-8B), TTT-Discover with the same Qwen3-8B model certifies tighter bounds on both AC1 (1.50525 vs. 1.50681) and AC2 (0.9472 vs. 0.9468) using a smaller sampling budget. The one clear loss is on the second autocorrelation inequality (AC2), where TTT-Discover certifies 0.9591 vs. AlphaEvolve V2's 0.9610, and on AtCoder AHC where TTT-Discover scores marginally below the 1st-place human (567,062 vs. 566,997 on ahc039; 848,414,228 vs. 847,674,723 on ahc058).

## Relation to Prior Work

This paper departs from the dominant test-time scaling paradigm (AlphaEvolve, ShinkaEvolve, OpenEvolve) that treats the LLM as a frozen generator and relies on handcrafted evolutionary heuristics for mutation, crossover, and fitness. It also differs from concurrent test-time RL works (MiGrATe, ThetaEvolve, EvoTune) that apply standard RL objectives (PPO/GRPO expected-reward maximization) to a single problem. TTT-Discover's key conceptual departure is recognizing that discovery is not standard RL: the goal is one exceptional solution, not average performance, which motivates an entropic objective that explicitly favors maximum-reward actions and a PUCT-based reuse rule that tracks best-child reward rather than mean. The method draws on test-time training (Sun et al., 2020), PUCT/MCTS (Silver et al., 2017), and relative-entropy policy search (Peters et al., 2010) for the adaptive β constraint.

## Why It Matters / Open Questions

TTT-Discover demonstrates that a single open model (gpt-oss-120b) at roughly $500 per problem can set new state-of-the-art across mathematics, GPU kernel engineering, algorithm design, and biology—domains where prior best results required closed frontier models. The practical accessibility (open weights, reproducible code, low cost) is significant for the scientific discovery community. Key limitations include the requirement for continuous verifiable rewards (sparse/binary rewards remain open), minimal tuning of the reuse mechanism, and the single-problem scope that precludes generalization guarantees. Open questions include extending to partially verifiable domains, richer Q-estimation with uncertainty, and whether the entropic objective generalizes to multi-objective or non-continuous settings.

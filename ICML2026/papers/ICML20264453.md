## Problem

Existing neuro-symbolic reasoning pipelines suffer from two persistent bottlenecks: Translation Fragility, where even minor syntactic discrepancies cause solver execution failure, and Silent Failure, where semantically incorrect LLM translations (e.g., mapping 'Neither A nor B' to A∧B instead of ¬A∧¬B) produce valid executions with unsound conclusions. Current reactive self-correction mechanisms can only repair programs that crash, leaving them fundamentally unable to detect or correct logically flawed programs that execute successfully.

## Input / Output

The method takes a natural language context (C) and query (Q) as input and produces a final logical reasoning answer (ŷ) as output. The pipeline adaptively maps different reasoning types to distinct formalisms—deductive tasks to Logic Programming (Pyke), FOL tasks to Prover9, constraint satisfaction to python-constraint, and analytical reasoning to Z3—so the intermediate logic program Φ varies in syntax and solver backend depending on the benchmark. The final output is determined by a hierarchical gating strategy that prioritizes symbolic derivation but falls back to neural CoT when formalization is intractable.

## Method

LogicSAGE is a dual-process architecture integrating a System 1 neural CoT reasoner with a System 2 symbolic validator, orchestrated by a Socratic Agent that simulates a Teacher-Student dialectic. The agent operates in two modes: Reactive Error-Guided Correction, which treats solver error traces as pedagogical feedback in a multi-turn dialogue to iteratively debug syntax errors, and Proactive Uncertainty Probing, which monitors token-level Normalized Entropy Scores (NES) computed via intra-stream Z-score normalization to flag latent semantic hallucinations even when code compiles successfully. An Adaptive Fusion mechanism with a Socratic Arbiter resolves conflicts between symbolic and neural predictions by weighing neural confidence (weakest-link sliding-window metric) against program entropy. The backbone is Qwen3-8B fine-tuned via LoRA on solver-verified logic programs synthesized by Qwen3-Max through a Socratic-Augmented Distillation Pipeline that salvages initially failed generations rather than discarding them.

## Results

LogicSAGE (SFT Qwen3-8B) achieves a state-of-the-art 92.36% average accuracy across five logical reasoning benchmarks (PrOntoQA, ProofWriter, FOLIO, LogicalDeduction, AR-LSAT), outperforming the best prior neuro-symbolic baseline VERUS-LM (85.02%) by 7.34 points. Even without fine-tuning, the training-free LogicSAGE (Qwen3-8B) reaches 80.30%, already surpassing all backbone-controlled baselines including VERUS-LM (79.82%). On the most challenging AR-LSAT benchmark, the SFT model achieves 77.00% accuracy and 95.6% execution rate, compared to GPT-4-based baselines that suffer catastrophic failure rates (Er < 40%).

## Baselines & Comparisons

LogicSAGE (SFT Qwen3-8B) decisively outperforms all five baselines on average accuracy: VERUS-LM (85.02%), LTRAG (83.99%), SymbCOT (80.47%), LOGIC-LM++ (78.91%), and Logic-LM (68.32%), with margins ranging from +7.34 to +24.04 points. In the backbone-controlled setting (all methods using Qwen3-8B), LogicSAGE (80.30%) still beats VERUS-LM (79.82%) by 0.48 points and LTRAG (75.38%) by 4.92 points, confirming that gains stem from architecture rather than model scale. The largest relative advantage appears on AR-LSAT, where LogicSAGE (SFT) reaches 77.00% versus VERUS-LM's 68.36% and GPT-4-CoT's 35.06%, highlighting the Socratic Error Correction mechanism's ability to resolve the Translation Fragility bottleneck that cripples smaller models on complex constraint satisfaction. On FOLIO, LogicSAGE (SFT) achieves 88.50% execution accuracy versus VERUS-LM's 78.43%, demonstrating superior semantic fidelity beyond mere compilability. The training-free variant (80.30%) already matches or exceeds SymbCOT (69.48%) and LOGIC-LM++ (70.45%) in the controlled setting, indicating the Socratic loop provides substantial value even without fine-tuning.

## Relation to Prior Work

LogicSAGE extends the neuro-symbolic reasoning lineage initiated by Logic-LM (Pan et al., 2023) and Logic-LM++ (Kirtania et al., 2024), which introduced reactive self-correction based on solver error messages. The key departure is the addition of a proactive, entropy-aware semantic verification mechanism that detects 'silent failures'—syntactically valid but semantically incorrect translations—whereas prior pipelines could only repair programs that crashed. The Socratic Teacher-Student dialectic framing and the Dual-Process (System 1 neural / System 2 symbolic) architecture with adaptive fusion represent a more structured and diagnostically informed refinement loop compared to the simpler generate-verify-regenerate cycles in prior work.

## Why It Matters / Open Questions

The paper demonstrates that a compact 8B model with architectural innovation can outperform GPT-4 baselines on logical reasoning, suggesting that targeted neuro-symbolic design can partially substitute for raw model scale. However, the ablation reveals that the 'novel' Proactive Probing component contributes only +2.8% average accuracy versus +18.3% from Reactive Correction, and the entropy-based silent-failure detector achieves only 55–66% recall, meaning it misses nearly half of semantic errors. Open questions include whether the Socratic loop generalizes beyond closed-form logic puzzles to open-ended code generation, whether reinforcement learning can internalize the iterative feedback to reduce the ~65-second inference latency, and whether the approach extends to probabilistic or fuzzy logics where strict solver verification is less applicable.

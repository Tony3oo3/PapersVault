## Problem

Hanneke & Kpotufe (2022) proved that no adaptive multitask learning algorithm can achieve minimax rates when the sample size per task is bounded (n < 2/β − 1), but left open whether abundant data per task could restore adaptivity. This paper answers that question negatively, establishing that the hardness of multitask adaptation is fundamental and cannot be overcome by collecting more samples per source, regardless of how large n becomes.

## Input / Output

The learner receives N source datasets Z_t (each of size n) drawn i.i.d. from unknown distributions P_t, along with a fixed concept class H of bounded VC dimension, but has no access to the transfer exponents {ρ_t} or any other distributional information. The output is a single classifier ĥ for the target distribution D. The setting is binary classification over a two-point instance space, and the key constraint is that the algorithm must work uniformly over all multitask configurations in the class M without knowing which sources are 'fair' (small ρ) versus 'noisy' (large ρ).

## Method

The proof constructs a hard-case multitask problem with 'fair' sources P and 'noisy' sources Q, both satisfying the Bernstein class condition with parameter β ∈ (0,1), where both types are genuinely noisy (unlike the prior work's nearly-perfect benign sources). The core technique applies Fano's inequality to a binary hypothesis testing problem, directly upper-bounding the KL divergence between the likelihood functions of mixture distributions generated under opposite labels σ and 1−σ. This avoids the prior work's reliance on likelihood-ratio test optimality and its decomposition into homogeneous vs. non-homogeneous examples, which forced the n < 2/β − 1 constraint. The result shows that for N ≥ n^{nβ/(1−β)} tasks, any adaptive algorithm incurs excess risk Ω((n√N)^{−1/(2−β)}), strictly worse than the minimax rate (nt*)^{−1/(2−β)}. Additionally, the paper shows pooling achieves nearly optimal adaptive rates in this construction and introduces Algorithm 1 (Intersection of Bernstein Balls) that outperforms pooling in the agnostic (β=0) case.

## Results

The main impossibility result (Theorem 5.2) shows that for any adaptive learning algorithm with only access to multisource data, the expected excess risk satisfies E[E_D(A(Z))] = Ω((n√N)^(-1/(2-β))), which holds for arbitrarily large sample size n > 2/β − 1. In contrast, an oracle algorithm that knows which sources are fair achieves O((n√N)^(-1/(2-β)) · e^(−n^(nβ/2(2−β)))) (Theorem 5.1), and the minimax rate is (nt*)^(−1/(2−β)) where t* = √(N·n^(nβ/(2−β))). Since (nt*)^(−1/(2−β)) = o((n√N)^(−1/(2−β))), no adaptive algorithm can match the minimax rate. Notably, pooling achieves O((log(nN)/(n√N))^(1/(2−β))), matching the adaptive lower bound up to a logarithmic factor, making it nearly optimal among adaptive algorithms in this setting.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; comparisons are between algorithmic guarantees. The paper's central comparison is between adaptive algorithms (no distributional knowledge) and oracle algorithms (knowing which sources are fair): the oracle achieves a rate exponentially faster than the minimax rate, while any adaptive algorithm is stuck at Ω((n√N)^(−1/(2−β))), strictly worse than the minimax rate (nt*)^(−1/(2−β)). Compared to the prior no-free-lunch theorem of Hanneke & Kpotufe (2022), the new result removes the critical constraint n < 2/β − 1, showing the impossibility holds for arbitrarily large n. Regarding pooling: in the agnostic case (β=0, Section 4), pooling is provably suboptimal (Theorem 4.3 shows Ω(1) risk while Algorithm 1 achieves O(1/n)), but in the main Bernstein-class construction (Section 5.3), pooling matches the adaptive lower bound up to a log(nN) factor, making it nearly optimal among adaptive algorithms. The paper thus identifies a regime-dependent picture: pooling can be either suboptimal or nearly optimal depending on the noise structure.

## Relation to Prior Work

This paper directly extends the no-free-lunch theorem of Hanneke & Kpotufe (2022), which showed that no adaptive multitask learner can achieve minimax rates when the sample size per task is bounded (n < 2/β − 1). The key departure is a new hard-case construction where both source types are noisy (rather than one being nearly perfect), combined with a proof technique based on Fano's method and tight KL-divergence bounds between mixture distributions, rather than the likelihood-ratio decomposition used previously. The agnostic case (β = 0) studied in Section 4 serves as a conceptual bridge, revealing that the hardness of adaptation is fundamentally tied to margin conditions on label noise rather than merely to sample size constraints.

## Why It Matters / Open Questions

The central message—that arbitrarily large sample size per task cannot overcome the impossibility of adaptivity—has a clear practical implication: designing uniformly better multitask algorithms requires leveraging additional distributional information (e.g., knowing which sources are less contaminated) rather than merely collecting more data. A significant open gap remains between the positive regime (N = O(polylog(n)) where pooling is nearly adaptive) and the negative regime (N = Ω(exp(n))), leaving the threshold for adaptivity unresolved. The paper also raises the fundamental question of optimal adaptive rates and whether a uniformly optimal adaptive algorithm exists, with the 'Intersection of Bernstein Balls' algorithm (Algorithm 1) suggested as a promising starting point.

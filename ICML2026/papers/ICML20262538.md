## Problem

Existing model merging methods focus on resolving conflicts between task updates, but leave unaddressed the failure mode where shared knowledge aligned across tasks is repeatedly accumulated through linear combination, inflating singular values in a few dominant spectral subspaces and suppressing task-specific components. This spectral over-counting causes the merged model to be dominated by shared directions, degrading downstream performance even when tasks appear aligned rather than conflicting.

## Input / Output

SVC takes as input a pre-trained model, K fine-tuned models (yielding task matrices ΔW_i = W_i − W_pre), and an already-merged task matrix ΔW_merge produced by any base merging method (TA, TIES, DARE, TSV-M, Iso-CTS, etc.). It outputs calibrated merged model weights W_merge = W_pre + ΔW̃_merge, where only the singular values of the merged update are rescaled while singular vectors remain unchanged. The method is entirely training-free and data-free, requiring no auxiliary data, gradients, or inference-time routing, and operates layer-wise on each linear layer's weight update matrix.

## Method

SVC performs a three-step post-hoc calibration in spectral space. First, it computes the SVD of the merged task matrix and uses the left singular vectors as a shared output-space basis. Second, for each spectral subspace r and task i, it computes a projection coefficient s_i^r = ⟨a_merge^r, a_i^r⟩ / ‖a_i^r‖² that quantifies how much the merged response amplifies task i's direction; values exceeding 1 indicate spectral over-counting from positive cross-task inner products. Third, it aggregates these coefficients into a per-subspace calibration factor γ^r = K / Σ_i max(α, s_i^r) (a harmonic mean of clipped task-wise scalings) and rescales each singular value as σ̃^r = γ^r σ^r before reconstructing the calibrated update. The key theoretical result (Theorem 3.3) shows that under weight addition, positive cross-task overlap in a subspace necessarily inflates the merged singular value above the projection-optimal magnitude, and SVC corrects exactly this inflation while preserving spectral directions. A suppression-only variant (α=1) guarantees γ^r ≤ 1, making SVC a conservative plug-in that never amplifies any subspace.

## Results

On the 8-task CV classification benchmark (ViT-B/32), SVC improves Task Arithmetic from 68.9% to 81.9% average accuracy (+13.0 points), DARE from 65.8% to 80.7% (+14.9), and TIES from 72.6% to 80.0% (+7.4). On NLP, SVC lifts TA on BERT from 56.9% to 69.0% (+12.1) and on T0 (IA³ PEFT) from 53.5% to 65.8% (+12.3). Even strong spectral baselines benefit: TSV-M gains +0.8, Iso-C +1.5, and Iso-CTS +4.2 on the same 8-task CV setting, confirming that spectral over-accumulation is a pervasive failure mode across merging methods.

## Baselines & Comparisons

SVC is applied as a post-hoc calibration on top of six base merging methods (TA, TIES, DARE, TSV-M, Iso-C, Iso-CTS) and consistently improves all of them. The largest gains appear on methods that do not explicitly control subspace magnitudes: TA (+13.0 on 8-task CV, +16.7 on 14-task) and DARE (+14.9, +7.8) benefit most, while TIES gains +7.4. Strong spectral baselines that already partially address spectral imbalance show smaller but still positive gains: TSV-M +0.8, Iso-C +1.5, Iso-CTS +4.2. Against non-SVC spectral methods reported in the appendix, SVC-enhanced TA (81.9) substantially outperforms STAR (69.0) and CAT (78.4) on the 8-task ViT-B/32 benchmark. On NLP, SVC improves TA on BERT by +12.1 and on T0 by +12.3, and on Llama2-7B generation it adds +2.5 on AlpacaEval and +6.1 on GSM8K. The 20-task CV setting (Table 5) further confirms generality: SVC lifts TALL Mask from 37.94 to 54.41 (+16.47) and Subspace-Boosted from 68.89 to 71.47 (+2.58), showing the calibration remains effective as the number of merged tasks grows.

## Relation to Prior Work

This paper extends the spectral-space model merging line (TSV, STAR, Iso-C/Iso-CTS, Subspace-Boosting) by identifying a complementary failure mode: rather than resolving destructive conflicts between task updates, it addresses constructive over-accumulation of shared spectral directions that inflates singular values in dominant subspaces. Unlike prior spectral methods that redesign the merged update via selection, truncation, or global rescaling, SVC is a post-hoc calibration that keeps singular vectors fixed and only rescales singular values based on per-task, per-subspace projection coefficients. It also departs from weight-space merging methods (TIES, DARE, TALL-Mask) by operating in a structured spectral coordinate system rather than treating parameters as independent local units.

## Why It Matters / Open Questions

The identification of spectral over-counting as a distinct failure mode from task conflict reframes how practitioners think about merging: aligned knowledge is not automatically beneficial, and naive summation can harm performance by concentrating mass in a few shared subspaces. SVC's plug-in, training-free, data-free nature makes it immediately applicable on top of any existing merger, and the 13% gain over Task Arithmetic (and consistent smaller gains over strong spectral baselines) demonstrates practical value. Limitations include the SVD cost for large models (minutes for 7B LLMs), the sensitivity of the α hyperparameter to amplification, and the layer-wise application that may miss cross-layer interactions. Open questions include whether joint tuning of the global scale λ with SVC yields further gains, and whether the output-space projection principle generalizes to non-matrix parameter shapes beyond the 1D vector extension shown for IA³.

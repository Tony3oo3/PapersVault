## Problem

Existing MARL communication methods either broadcast redundant information to all agents or use learned message routing that does not explicitly target accurate global-state reconstruction, leaving agents with incomplete or non-uniform knowledge of the environment. No prior approach provides a principled, criterion-driven mechanism to identify which specific state dimensions each agent still cannot recover and to add only the messages needed to close those gaps.
![Teaser figure](../imgs/ICML20260165/cropped_page1_idx0.webp)

## Input / Output

The method takes per-agent local observation tensors (e.g., 103-dim vectors in SMAC-Comm) and a natural-language task description specifying state and observation semantics. The LLM produces an executable Python protocol (a vectorized function mapping observation tensors to message tensors) that is applied offline at design time; during MARL training, the protocol generates agent-specific messages concatenated to each agent's observation, which are then encoded into a compact latent representation used for both state inference and QMIX-based action selection. No online LLM calls are made during training.

## Method

LMAC uses a Reflexion-style iterative loop where an LLM (GPT-4.1) generates an executable communication protocol in three refinement steps: initial design (k=0), recovery enhancement (k=1), and imbalance mitigation (k=2). At each step, an auxiliary decoder is trained on offline transition data to reconstruct the global state with and without the current messages; a State-Awareness Indicator (SAI) thresholds per-dimension reconstruction accuracy to produce quantitative feedback (recovery success rate or inter-agent variance) that is fed back to the LLM as structured language instructions for the next protocol revision. During CTDE training, the final protocol's messages are encoded via an attention-based encoder into a latent z, which is jointly trained with QMIX's TD loss, a state-reconstruction loss, a cross-entropy loss predicting the SAI (meta-cognitive reliability), and a cycle-consistency regularizer that penalizes information in z that cannot survive a decode-re-encode round, thereby suppressing redundant content.

## Results

On SMACv2 (3M steps), LMAC achieves 67.87% (terran), 57.96% (protoss), and 42.18% (zerg) win rates, surpassing the oracle QMIX+State upper bound (64.77%, 56.40%, 40.06%) across all three scenarios. On SMAC-Comm, LMAC converges faster and reaches higher final success rates than all baselines, nearly matching QMIX+State, with particularly large gains on the large-scale 2o_20b_vs_2r scenario. On GRF, LMAC outperforms both all communication baselines and QMIX+State in final success rates, attributed to its latent compression of high-dimensional observations into compact task-relevant features.

## Baselines & Comparisons

LMAC consistently outperforms all eight communication baselines across SMACv2, SMAC-Comm, LBF, and GRF. Against the strongest learned baselines, LMAC beats MAIC (63.80/51.93/38.59) by 4.1/6.0/3.6 points on SMACv2 terran/protoss/zerg, and T2MAC (61.67/48.16/35.09) by 6.2/9.8/7.1 points. The no-communication QMIX baseline (61.69/48.44/34.79) is surpassed by 6.2/9.5/7.4 points, confirming that the LLM-designed protocol adds substantial value beyond what agents can infer from local observations alone. Notably, LMAC also exceeds the QMIX+State oracle (64.77/56.40/40.06) on all three SMACv2 scenarios, suggesting that structured, task-relevant communication is more effective than raw global state under high stochasticity. Weaker baselines such as COLA (10.29/0.01/0.19), SMS (34.00/27.00/13.53), and FullComm (18.44/16.93/6.83) are outperformed by large margins, indicating that indiscriminate or game-theoretic message selection is far less effective than LLM-guided, criterion-based protocol design.

## Relation to Prior Work

LMAC sits at the intersection of two research threads: (1) learned communication in cooperative MARL (TarMAC, SMS, T2MAC, MASIA, NDQ, MAIC, COLA), which typically learns message content and routing end-to-end via attention or value-based objectives, and (2) LLM-based iterative refinement (Reflexion), which the authors adapt by replacing the fixed feedback instruction with step-wise, criterion-based instructions derived from an auxiliary state-reconstruction decoder. The key departure from prior LLM-for-RL work (e.g., Li et al. 2024, which requires online LLM interaction at every timestep) is that LMAC uses the LLM purely offline to produce an executable, code-based communication protocol, after which no LLM calls are needed during training or execution. The meta-cognitive representation module with cycle-consistency regularizer extends the standard CTDE encoder by explicitly supervising a state-awareness indicator, a design not present in prior communication baselines.

## Why It Matters / Open Questions

The paper addresses a concrete gap—existing communication methods do not explicitly optimize for accurate *and* uniform state reconstruction across agents—and provides a principled, interpretable mechanism (LLM-designed code protocols guided by quantitative SAI feedback) to close it. The finding that LMAC can match or exceed QMIX+State (the global-state oracle) on GRF and SMACv2 suggests that well-targeted, compressed communication can be more effective than raw state access, which has implications for bandwidth-constrained or privacy-sensitive multi-agent deployments. Open questions include extending the framework to unstructured visual observations (the authors note this requires semantic-attribute mapping), reducing dependence on LLM reasoning quality, and validating the approach in non-cooperative or mixed-motive settings where the state-reconstruction objective may not align with strategic information hiding.

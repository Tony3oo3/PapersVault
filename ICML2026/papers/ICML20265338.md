## Problem

Existing LLM agent memory poisoning attacks face a fundamental stealthiness-effectiveness dilemma: injections that reliably bias agent behavior are explicitly malicious and easily flagged by safety filters, while benign-appearing injections lack the persuasive strength to override the agent's reasoning. No prior method demonstrates how to achieve high attack success rates using only benign-appearing queries under strict black-box access, where the attacker has no knowledge of the victim's exact query phrasing or the agent's internal retrieval mechanism.

## Input / Output

The attacker provides a target query (the victim's likely intent, e.g., 'cool the lettuce'), a target outcome (the desired biased behavior, e.g., 'microwave the lettuce'), and interacts with the agent solely through standard query APIs. The output is a cooperative squad of N=4 benign-appearing queries, each assigned a distinct semantic role (Rule Definition, Contextual Necessity, Action Link, Outcome Assurance) that together form a closed A-to-B-to-A deceptive reasoning loop. The squad is deployed by submitting these queries across multiple sessions so they are stored as valid interaction records in the agent's long-term memory, where they lie dormant until a semantically related victim query triggers their joint retrieval.

## Method

MemIncept formulates memory poisoning as a cooperative set-level optimization problem solved via a bidirectional 'middle-out' evolutionary strategy. It first extracts conceptual anchors bridging the logical gap between the victim's intent and the target outcome, then initializes a population of query squads where each member plays a distinct semantic role to ensure logical complementarity rather than repetition. A set-level objective jointly optimizes three terms: set retrievability (recall ratio of the squad under simulated victim queries), set effectiveness (probability the retrieved subset steers the agent to the target), and individual regularization (per-query retrievability, effectiveness, and stealthiness measured by average token probability). The evolutionary loop uses role-aware mutation (LLM rewriting that preserves each query's assigned syntactic role) and adaptive crossover (segment-level swap for high-fitness queries, full replacement for low-fitness ones) to iteratively refine the squad. Monte-Carlo probing with LLM-generated paraphrased victim queries handles uncertainty about the exact future query, ensuring the optimized squad is robust across a semantic neighborhood rather than overfit to a single phrasing.

## Results

MemIncept achieves an average Attack Success Rate (ASR) of 95.3% on StateAct, 96.5% on RAP, and 94.5% on EHRAgent across four LLM backbones (GPT-4o, Claude Sonnet 4.5, DeepSeek-v3.2, Qwen3-235B-A22B), with Retrieval Success Rates (RSR) consistently above 97%. Clean Test Accuracy (CTA) is preserved at ~99%, indicating negligible utility degradation. On stealthiness, MemIncept achieves a perplexity of 57.83 (lower than the no-attack baseline of 91.91) and 0% detection rate under both automated (GPT-4 judge) and human screening.

## Baselines & Comparisons

The primary baseline is MINJA (Dong et al., 2025), a query-only injection attack that uses explicit malicious instructions to bridge the reasoning gap. MemIncept outperforms MINJA by 4 percentage points in ASR (96% vs. 92%) and 4 points in RSR (98% vs. 94%) at matched injection size N=4 (Table 6). The stealthiness gap is dramatic: MINJA's injected queries are detected 100% of the time by both GPT-4-based automated screening and human reviewers (PPL 172.27), whereas MemIncept achieves 0% detection under both criteria with a lower perplexity of 57.83 (Table 4). Under matched retrieval density (Recall@4 ≈ 3.7–3.8), MemIncept still leads MINJA by 4 points in ASR (96% vs. 92%), confirming the gain comes from cooperative role structure rather than retrieval quantity (Table 7). At deeper retrieval (K=8), the gap widens substantially: MemIncept retains 40% ASR while MINJA drops to 15%, demonstrating that the cooperative squad is more robust to dilution by benign records.

## Relation to Prior Work

This paper extends the line of agent memory injection attacks (AgentPoison, MINJA, MEXTRA, AgentDojo) by shifting from explicit malicious instructions or white-box write access to a fully black-box, stealthy formulation. The key conceptual departure is formulating memory poisoning as a cooperative set-level optimization problem with a bidirectional 'middle-out' evolutionary strategy, rather than optimizing isolated records or manually crafting multi-query sequences as in MINJA. The role-based initialization (Rule Definition, Contextual Necessity, Action Link, Outcome Assurance) repurposes the Chain-of-Thought structure as an attack scaffold, creating a closed A-to-B-to-A reasoning loop that prior single-record or explicit-instruction attacks do not exploit.

## Why It Matters / Open Questions

The demonstration that coordinated benign-appearing queries can achieve >94% attack success while evading both automated safety filters (LlamaGuard, GPT-OSS-Safeguard, AGrail) and human inspection at 0% detection rate raises urgent concerns for any deployed LLM agent with shared long-term memory. The paper's defense evaluation is sobering: the strongest tested defense (pre-retrieval clustering) only reduces ASR from 95.3% to 85.0%, and the attack persists across 30+ benign sessions under most memory update policies. Open questions include whether provenance tracking or cross-session consistency checks can detect coordinated multi-record injections that individually appear benign, and whether the approach generalizes to strictly isolated single-user memories or to agents with larger retrieval windows that dilute the injected squad's influence.

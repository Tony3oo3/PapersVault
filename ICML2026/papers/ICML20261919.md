## Problem

Existing graph-based ADHD detection methods rely on static functional connectivity or model only adjacent-frame temporal changes, leaving short-term brain functional reorganization within local time windows largely unexplored. Additionally, there is no effective mechanism to integrate local transient dynamics with global structural connectivity for comprehensive disease characterization.
![Teaser figure](../imgs/ICML20261919/cropped_page0_idx0.webp)

## Input / Output

The method takes resting-state fMRI data parcellated into 116 ROIs via the AAL atlas, producing a T×N time-series matrix that is segmented into non-overlapping windows of length w (typically 10 time points). Each window yields a partial correlation graph estimated via GraphicalLasso with Ledoit-Wolf shrinkage, sparsified by a global percentile threshold to ensure cross-window comparability, with community labels extracted by modularity maximization. The model outputs a binary ADHD-vs-control classification score.

## Method

SLT-BFGN operates a dual-branch architecture: a short-term branch constructs window-level graph sequences, encodes per-window node features (degree dynamics, neighborhood spatial centroids, community embeddings) via a state encoder, then models inter-window temporal dependencies with a Transformer encoder using sinusoidal positional encoding and a learnable CLS token, followed by a K-slot Brain Function Memory that stores and retrieves cross-subject temporal prototypes via attention-based read/write operations. A long-term branch applies hierarchical GCN message passing on the global adjacency matrix to extract stable structural features, augmented by a parallel memory module. The two branches are fused at the decision level (averaging, softmax-weighted, or learned nonlinear combination) and trained with a dual-branch loss whose weights evolve through warmup, joint-optimization, and frozen phases. The design is grounded in empirical evidence that brain functional connectivity evolution follows a first-order Markov process (Markov ratio R=4.76), justifying the short-term window granularity and the focus on lag-1 sequential transitions.

## Results

On ADHD-200, SLT-BFGN achieves 68.62±3.79% accuracy and 74.53±1.30% AUC; on OpenNeuro-ds002424, it reaches 78.18±5.51% accuracy and 82.13±4.15% AUC. This represents an average accuracy improvement of 6.97% and an average AUC increase of 10.95% over the strongest competing baselines across both datasets. All reported metrics are evaluated via 4-fold cross-validation with one-sample t-tests against a random classifier (p < 0.01 for all headline results).

## Baselines & Comparisons

SLT-BFGN outperforms all four key baselines on both datasets across both accuracy and AUC. Against the strongest GNN baseline BrainOOD (ICLR'25), SLT-BFGN gains +7.78% ACC and +19.15% AUC on ADHD-200, and +10.11% ACC and +15.71% AUC on OpenNeuro. Against the best graph temporal series method ET_MGNN (Neurocomputing'25), the improvement is +3.83% ACC and +8.65% AUC on ADHD-200, and +13.94% ACC and +13.25% AUC on OpenNeuro. EBIGNN (JBHI'25), which models adjacent-frame effective connectivity, is surpassed by +7.32% ACC and +20.91% AUC on ADHD-200, and by +20.68% ACC and +25.11% AUC on OpenNeuro. GroupBNA (ICLR'24) performs near chance level on both datasets (ACC 38.10% on ADHD-200), indicating that group-adaptive augmentation alone is insufficient without temporal modeling. The ablation further confirms that the long-term GNN branch is critical for cross-site generalization (OpenNeuro AUC drops from 82.13% to 46.62% when removed), while the temporal dependency encoder drives discriminability on ADHD-200 (AUC drops from 74.53% to 63.59% without it).

## Relation to Prior Work

This paper carves new ground at the intersection of dynamic functional connectivity analysis and graph sequence modeling. While prior graph time series methods (EBIGNN, ET_MGNN) model changes between adjacent MRI frames, and static GNN methods (BrainGNN, BrainOOD, GroupBNA) discard temporal information entirely, SLT-BFGN introduces short-term window-based brain map sequences as an intermediate timescale, justified by an empirical first-order Markov property (R=4.76) in resting-state connectivity. The architecture repurposes Transformer self-attention for temporal dependency encoding, a learnable memory module for cross-subject pattern association, and GCN layers for long-term structural features, fusing them at the decision level—a combination not previously applied to ADHD detection.

## Why It Matters / Open Questions

The empirical demonstration that brain functional connectivity evolution follows a first-order Markov process provides a principled neurodynamic justification for short-term window modeling, moving beyond ad hoc temporal segmentation. The dynamic connectivity analysis revealing reduced dynamic flexibility specifically in the Dorsal Attention Network, DMN-DAN coordination, and prefrontal-parietal pathway offers a multi-level neurodynamic account of ADHD consistent with the dual-system attention model. However, open questions remain: the 4-fold cross-validation on two datasets of moderate size limits confidence in generalizability, the cross-site ablation (AUC dropping from 82.13% to 46.62% without the long-term branch on OpenNeuro) suggests the short-term branch alone is insufficient for out-of-distribution settings, and the model's reliance on AAL parcellation and Louvain community detection introduces pipeline sensitivity that is not fully explored.

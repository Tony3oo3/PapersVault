## Problem

Training-free open-vocabulary semantic segmentation (OVSS) is bottlenecked by CLIP's deep-seated spatial bias: extending attention modulation to correct it disrupts cross-modal alignment, capping performance. While the spatially-aware dino.txt framework eliminates this bias, it still underperforms CLIP-based SOTA due to dense cross-modal mismatch—canonical class names are semantically sparse and lexically misaligned with the image-caption descriptions in dino.txt's pre-training data, preventing rich visual features from finding precise semantic anchors.
![Teaser figure](../imgs/ICML20266256/cropped_page0_idx0.webp)

## Input / Output

The method takes an RGB image (resized to 336px shorter side, 560px for Cityscapes) and a set of canonical text class names as input, producing a pixel-level segmentation mask via argmax over a dense logit map. Inference uses sliding-window patches (224×224, stride 112) over the DINOv3 ViT-L backbone. The LLM-based alias generation and visual-guided filtering are performed offline; at deployment, only a single forward pass plus lightweight matrix operations are needed, yielding ~100 ms inference and ~1650 MB memory on an RTX 4090.

## Method

VIP builds on dino.txt and introduces three components to refine text queries. First, a self-correction step replaces self-attention weights in dino.txt's two-layer adapter with self-similarity computed from frozen DINOv3 patch tokens, restoring spatial awareness without shifting the cross-modal feature space. Second, an LLM generates 20 image-caption-style aliases per class name, which are then filtered by a visual-guided distillation scheme: each alias is scored by a VG_Score (IoU between its activation map and a random-walk-propagated DINOv3 visual affinity) and an SC_Score (entropy of inter-class activation), retaining only aliases that improve VG while worsening SC relative to the canonical name. Third, a saliency-aware soft aggregation computes global image-to-alias similarity as per-alias weights and combines weighted activation maps via a log-sum-exp (free-energy) operation, yielding a single robust prediction per category. The approach is fully training-free, requires no mask annotations, and avoids auxiliary models like SAM.

## Results

VIP achieves 52.4% average mIoU across eight natural-image and urban-scene benchmarks (VOC21, Context60, COCO Object, VOC20, Context59, COCO Stuff, Cityscapes, ADE20K), surpassing the best single-model method SFP (44.0%) by 8.4% and the best multi-model method CorrCLIP (51.0%) by 1.4%. On remote sensing imagery (iSAID, Vaihingen, Potsdam, VDD), VIP reaches 44.3% average mIoU, outperforming the domain-specific SegEarth-OV (35.8%) by 8.5%. Inference cost is 100 ms and 1650 MB, roughly 14× faster and using half the memory of CorrCLIP (1440 ms, 3200 MB).

## Baselines & Comparisons

VIP outperforms all 19 compared baselines on average mIoU. Against the strongest single-model competitor SFP (44.0%), VIP gains 8.4% (52.4%), with particularly large margins on Cityscapes (+14.6%) and COCO Object (+9.5%). Against the strongest multi-model method CorrCLIP (51.0%, which relies on DINO + SAM2), VIP still leads by 1.4% while running ~14× faster (100 ms vs. 1440 ms) and using half the memory (1650 MB vs. 3200 MB). Compared to the base dino.txt model (31.8%), VIP improves by 20.6%, confirming that the bottleneck was cross-modal text-query mismatch rather than visual discriminability. On remote sensing imagery, VIP (44.3% avg.) surpasses the domain-specific SegEarth-OV (35.8%) by 8.5% and the multi-model Trident (34.5%) by 9.8%, demonstrating strong out-of-distribution generalization. Among CLIP-based single-model methods, VIP leads SC-CLIP (43.9%) by 8.5%, ResCLIP (41.2%) by 11.2%, and SCLIP (38.2%) by 14.2%.

## Relation to Prior Work

This paper departs from the dominant CLIP-based paradigm for training-free open-vocabulary semantic segmentation, arguing that CLIP's deep-seated spatial bias is intractable because extended attention modulation disrupts cross-modal alignment. Instead, it pivots to the dino.txt framework (Jose et al., 2025), which grounds text in frozen DINOv3 features and thus retains inherent spatial discriminability. Within this new foundation, the paper identifies the residual bottleneck as lying in the text modality—specifically the semantic sparsity of canonical class names—and addresses it via LLM-generated alias expansion, visual-guided distillation, and saliency-aware aggregation. The self-correction mechanism borrows the attention-modulation idea from CLIP-based methods (Lan et al., 2024b) but applies it within dino.txt's adapter layers, where it restores spatial awareness without collapsing the unified feature space.

## Why It Matters / Open Questions

The paper demonstrates that shifting the optimization target from the image side to the text side can unlock substantial gains (up to 8.4% mIoU) in training-free OVSS while achieving 14× faster inference and 50% less memory than SAM-based SOTA, making high-quality dense prediction practical for real-time applications. Its strong generalization to remote sensing imagery (8.5% over domain-specific methods) suggests the approach is not overfit to natural-image benchmarks. However, limitations remain: highly ambiguous category pairs (e.g., wall-concrete vs. wall-panel) still suffer, the method is bounded by DINOv3's resolution sensitivity for low-resolution satellite imagery, and the alias filtering lacks explicit supervision, leaving room for further refinement. A key open question is whether the text-side bottleneck identified here generalizes to other dense prediction tasks beyond segmentation.

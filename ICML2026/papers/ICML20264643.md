## Problem

In single-reference text-guided stylized image generation, style and content information are inherently entangled in the reference image's CLIP embedding, causing content leakage and poor prompt alignment when the embedding is used directly. Naive subtraction of a content description fails to remove content interference while simultaneously degrading fine-grained style details, revealing that simple vector arithmetic in CLIP space is insufficient for style-content separation.
![Teaser figure](../imgs/ICML20264643/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference style image (encoded by a pre-trained CLIP image encoder into a 1280-dim embedding) and a free-form text prompt as input, producing a stylized image via SDXL with IP-Adapter. During training, GPT-4o generates separate content and style descriptions of the reference image to guide the distillation process, requiring only 150 seconds on a single RTX-4090. Beyond standard generation, the framework also accepts textual style-editing instructions or additional style embeddings as secondary inputs to enable style modification and multi-style fusion.

## Method

StyleDistillation is grounded in two empirical observations about CLIP space: style manifests as a consistent geometric offset across different contents, and textual descriptions serve as soft semantic guidance rather than exact content components. The StyleDistiller module uses cross-attention between CLIP text embeddings of content/style descriptions and the reference image's token-level features to produce a style representation y_s and an auxiliary content representation y_c. Training combines four cooperative losses: an anchor loss (cosine similarity for y_c to the content text, L2 distance for y_s to the image embedding), an orthogonality loss separating y_s from y_c, a reconstruction loss ensuring their weighted fusion approximates the original embedding (with γ<1 to prevent degeneration), and a standard diffusion denoising loss. At inference, a lightweight Prompt Alignment Enhancement mechanism blends y_s with the text prompt embedding (y_s^p = y_s + λ·f_t^p) to rebalance style fidelity against content alignment without additional training.

## Results

StyleDistillation achieves the best Composite Quality (CQ) score of 10.73 and the highest CLIP-Text score of 28.95 among all compared methods, demonstrating the strongest balance between style fidelity and prompt alignment. In the user study (63 participants, 1,764 responses), it receives 42.97% votes for best style match and 55.22% for best text alignment, far exceeding all baselines. The method is trained in only 300 steps (~150 s on a single RTX-4090) per reference image, requiring no style-specific dataset or retraining of the diffusion backbone.

## Baselines & Comparisons

StyleDistillation wins on the proposed CQ score (10.73) and CLIP-Text (28.95) over all seven baselines, and dominates the user study for both style (42.97%) and text alignment (55.22%). IP-Adapter achieves the highest raw CSD (78.04) due to strong style transfer but suffers severe content leakage, scoring only 19.51 on CLIP-Text and 0.45% in the user text-alignment vote. InstantStyle is the closest competitor on CQ (10.62) and CLIP-Text (28.78), but its naive subtraction approach degrades style details, reflected in a lower CSD (50.62 vs. 53.26) and a large user-study gap (8.73% vs. 42.97% style votes). StyleShot is competitive on CSD (52.71) but lags on CLIP-Text (25.56) and user text alignment (4.88%). DreamStyler prioritizes prompt text over style, yielding the lowest CSD (20.88) despite a decent CLIP-Text (28.23). Overall, StyleDistillation is the only method that simultaneously achieves top-tier performance on both style fidelity and prompt alignment, as confirmed by both automatic metrics and human evaluation.

## Relation to Prior Work

This paper builds directly on IP-Adapter's architecture for injecting CLIP image embeddings into Stable Diffusion, but departs from the naive use of raw reference embeddings by introducing a learned StyleDistiller module that explicitly separates style from content. It contrasts with InstantStyle's simple embedding subtraction (which the paper shows degrades style while failing to remove content) and with dataset-heavy methods like StyleShot and CSGO that require style-specific training. The key conceptual departure is reframing the style extraction problem through two empirical observations about CLIP geometry—style as a consistent cross-content offset and text as imperfect but useful semantic guidance—rather than treating it as a pure algebraic decomposition.

## Why It Matters / Open Questions

The method offers a practical, lightweight solution (150s training on a single GPU, no style-specific datasets) for single-reference style transfer that achieves a strong balance between style fidelity and prompt alignment, validated by both quantitative metrics and user studies. The style editing capability—adjusting specific attributes like color or material via text instructions—is noted as underexplored in prior stylization work and opens a direction for fine-grained aesthetic control. Limitations include failure cases in multi-attribute style editing with ambiguous instructions, and the reliance on GPT-4o for generating content/style descriptions introduces a dependency on external MLLM quality. Open questions include whether the geometric prior generalizes beyond CLIP to other embedding spaces and whether the approach scales to video or 3D style transfer.

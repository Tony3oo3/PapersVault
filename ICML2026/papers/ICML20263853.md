## Problem

Existing event-camera methods face a scalability-accuracy trade-off: frame and voxel representations introduce costly preprocessing and discard fine-grained temporal resolution, while Point Cloud methods preserve temporal detail but cannot scale to high-resolution or long-sequence events and treat polarity only as an input feature rather than a structural signal. No prior architecture simultaneously handles 10× more events than typical Point Cloud baselines, integrates polarity into neighborhood formation and coordinate updates, and captures long-range temporal dependencies without super-linear computational growth.
![Teaser figure](../imgs/ICML20263853/cropped_page0_idx0.webp)

## Input / Output

The method consumes a raw 2S-1T-1P event stream (x, y, t, p per event) that is randomly downsampled to a fixed Event Cloud of T₀ ∈ {1024, 2048, 4096, 8192, 10240} events arranged in strict chronological order (unlike Point Cloud, it is not permutation-invariant), then Min-Max normalized to a [T₀, 4] tensor. Outputs are task-dependent: a class label for object recognition and action recognition, or 13 3D skeleton key points for human pose estimation, obtained by concatenating mean-pooled and max-pooled final-stage features and passing them through a linear head.

## Method

SECNet is a 3-stage hierarchical network over Event Cloud that replaces PointNet++'s coordinate-based grouping with an Event-based G&S module: Differentiation FPS applies a learnable 4D scaling vector α to select centroids, Event Features-based KNN forms neighborhoods by feature distance rather than spatial distance, and Coordinates Evolution Strategy updates positions via group means, thereby embedding polarity into structural decisions. Spatial-FA performs a 1D FFT along the feature dimension Dᵢ, multiplies the spectrum by a learnable filter (Hadamard product), and applies iFFT, reducing per-group complexity from O(Dᵢ²) to O(Dᵢ log Dᵢ) and cutting overall MACs by up to 20× versus MLP-based alternatives. Temporal-FA applies the same FFT–filter–iFFT pipeline along the chronological event dimension Tᵢ with a global learnable filter, capturing long-range temporal dependencies that LSTM or local attention cannot model efficiently. A soft-attention aggregation (AGG) collapses the neighbor dimension before Temporal-FA, and a residual block (RES) refines features at each stage; across stages the event count halves while the feature dimension grows (64→132→268→540), yielding a lightweight 1.1–1.8 M parameter model that scales to 10240 events at 120 FPS.

## Results

On action recognition, SECNet achieves 98.9% on DVS128 Gesture, 99.65% on Daily DVS, and 91.6% on UCF101-DVS (average 96.7%), outperforming the previous SOTA VMST-Net by 16% on UCF101-DVS. On object classification across five datasets, SECNet reaches 99.7% (NMNIST), 94.7% (N-CARS), 75.7% (CIFAR10-DVS), 82.4% (N-Caltech101), and 99.93% (ASL-DVS), with an average of 90.5% matching or exceeding all voxel-based and frame-based SOTA methods. For human pose estimation on DHP19, SECNet achieves MPJPE of 6.11 (2D) and 69.89 (3D) with only 1.83M parameters and 0.160 GMACs, the lowest computational cost among all compared methods. On the high-resolution THU E-ACT-50 dataset (1280×800), SECNet reaches 97.25% accuracy, surpassing EV-ACT by 5% while consuming one order of magnitude fewer hardware resources.

## Baselines & Comparisons

SECNet achieves the best average accuracy (96.7%) across three action recognition datasets, surpassing the previous SOTA EventMamba (96.2%) and VMST-Net (which reports 78.7% on UCF101-DVS, a 16% gap). On UCF101-DVS specifically, SECNet (91.6%) outperforms VMST-Net (78.7%), EVSTr (73.5%), TTPOINT (72.5%), and ECSNet (70.2%), with the largest margin over voxel-based methods. On object classification, SECNet (90.5% average) edges out VMST-Net (90.2%) and ECSNet (87.1%), while dramatically outperforming Point Cloud baselines EventNet (58.6%) and PointNet++ (71.3%) by 27–32%. For human pose estimation on DHP19, SECNet (MPJPE 6.11/69.89) beats VMST-Net (6.45/73.07), Point Transformer (6.46/73.07), and DGCNN (6.83/77.32) while using only 0.160 GMACs versus 5.03 for Point Transformer. On the high-resolution THU E-ACT-50 dataset, SECNet (97.25%) surpasses EV-ACT (92.7%) by 5% with 1/16th the MACs (0.971 vs 14.5). The only close call is DVS128 Gesture where EventMamba (99.2%) slightly edges SECNet (98.9%), but SECNet recovers the lead on the other two action datasets.

## Relation to Prior Work

SECNet directly extends the PointNet++ hierarchical Grouping & Sampling architecture to the event-camera domain, but departs from prior Point Cloud methods (EventNet, TTPOINT, SpikePoint) in two fundamental ways: it treats the four event coordinates (x, y, t, p) as structurally distinct rather than collapsing t into a spatial z-axis, and it integrates polarity into neighborhood formation and coordinate updates rather than merely appending it to the input vector. The frequency-domain feature extraction (FFT + learnable filter Hadamard product + iFFT) is adapted from GFNet's global filter technique and FFC's frequency-domain convolution, but its application to one-dimensional event sequences for both spatial and temporal feature abstraction in a point-cloud-style network is new. The Event Cloud representation itself follows Wang et al. (2019), but SECNet is the first to scale it to 10× more events (10240 vs. 1024) while maintaining linear-ish computational growth.

## Why It Matters / Open Questions

The paper demonstrates that the simplest event representation (raw downsampled events) can outperform more complex voxel and frame representations when paired with an architecture that respects the 2S-1T-1P structure, challenging the field's default assumption that richer representations are necessary. The frequency-domain replacement for MLPs offers a principled path to scaling point-based event networks to longer sequences without the super-linear MACs growth that has limited prior work, and the FPGA results (16×–64× cycle reduction) suggest genuine edge-deployability. Open questions include whether the structural polarity integration generalizes to tasks beyond classification and pose estimation (e.g., segmentation, detection), whether the fixed 3-stage hierarchy is optimal for very long event streams, and whether the frequency-domain approach can be extended to multi-scale or multi-resolution event processing.

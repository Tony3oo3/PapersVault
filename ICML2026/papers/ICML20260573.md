## Problem

Protein fold classification lacks a large-scale, non-redundant supervised benchmark: existing structure-based datasets contain at most ~15K proteins, far below the hundreds of millions of AlphaFold-predicted structures now available. Additionally, current protein representation learning methods either require very large models (e.g., ESM2-15B) or achieve limited performance on fold classification, leaving no efficient, strong reference for structure-centric representation learning at scale.

## Input / Output

The method consumes protein structures as sequences of SE(3) residue frames—4×4 homogeneous matrices encoding each residue's Cα position and local orientation derived from the N, Cα, C backbone atoms—optionally augmented with amino acid sequence embeddings. For classification, the output is a single CATH Topology (T-level) label (965 classes) assigned to the protein's largest annotated domain. During self-supervised pretraining, the output is the full set of backbone atom coordinates (N, Cα, C) reconstructed from a sparse set of visible frames, with the reconstruction loss computed over all backbone atoms rather than only masked ones to preserve SE(3)-invariance.

## Method

MiAE extends the MAE paradigm to 3D protein geometry with an asymmetric encoder-decoder architecture. The SE(3)-invariant encoder, built from geometric self-attention blocks (adapted from ESM3) followed by a standard Transformer, processes only the small set of visible residue frames after an extremely high masking ratio (up to 90%), making it computationally efficient. A lightweight decoder (less than 10% of the encoder's per-token cost) reintroduces learned mask tokens and reconstructs the full backbone using a composite loss combining continuous distance/direction regression, binned classification auxiliaries, and an inverse-folding sequence prediction term. The key design insight is that aggressive masking forces the encoder to learn global structural reasoning rather than local interpolation, while the asymmetric split ensures the heavy encoder operates on only ~10% of residues, drastically reducing pretraining cost (768 GPU-hours vs. 138,240 for ESM2-650M). After pretraining, the decoder is discarded and the encoder is used for downstream fold classification via linear probing or fine-tuning.

## Results

On TEDBench (462K predicted structures, 965 CATH topology classes), the best supervised-from-scratch equivariant baseline (GotenNet, 1.9M params) reaches only 64.02 macro-F1 on the test set and 65.44 on the external CATH v4.4 test set. MiAE-B+seq (102M params), after self-supervised pretraining and fine-tuning, achieves 74.56 macro-F1 on the test set and 77.34 on the external test set, outperforming all baselines. Under linear probing, MiAE-L (339M) reaches 63.50 macro-F1 on the test set and 70.44 on the external test set, surpassing ESM2-650M (62.32/70.03) at a fraction of the parameter count. MiAE requires only 768 GPU hours for pretraining versus 138,240 for ESM2-650M/SaProt-650M.

## Baselines & Comparisons

MiAE dominates the supervised-from-scratch setting: even the smallest MiAE-S (29M) exceeds the best equivariant baseline GotenNet (1.9M) by 6.01 macro-F1 on the test set (70.03 vs. 64.02) and by 8.94 on the external test set (74.38 vs. 65.44). In the pretrained+fine-tuned setting, MiAE-B+seq (102M) outperforms SaProt-650M (650M) by 1.08 F1 on the test set (74.56 vs. 73.48) and by 0.56 on the external test set (77.34 vs. 76.78), while using roughly 6× fewer parameters. Against ESM2-650M, MiAE-B+seq leads by 8.37 F1 on the test set (74.56 vs. 66.19). Under linear probing, MiAE-L (339M) surpasses ESM2-650M (62.32→63.50 F1) but trails SaProt-650M (66.55 F1) by 3.05 points on the test set; however, MiAE-L still beats ESM2-650M on the external test set (70.44 vs. 70.03). The only model that clearly outperforms MiAE-L under linear probing is ESM2-15B (70.85 F1), which contains ~44× more parameters. Structure-only baselines PMPNN (41.43 F1) and MIF (44.38 F1) are substantially outperformed by all MiAE variants under linear probing.

## Relation to Prior Work

MiAE directly extends the MAE paradigm (He et al., 2022) from 2D images to 3D protein geometry, adapting the asymmetric encoder-decoder design to an SE(3)-invariant setting. The geometric attention mechanism and composite reconstruction loss are inherited from ESM3 (Hayes et al., 2025), but MiAE departs by applying attention globally over a sparse visible set rather than within k-NN neighborhoods, and by pushing the masking ratio to 90%—well above MAE's 75% optimum for images. On the benchmark side, TEDBench builds on TED's domain annotations (Lau et al., 2024) and Foldseek clustering (Barrio-Hernandez et al., 2023) to create a non-redundant supervised task at a scale (~462K structures) that exceeds all prior fold-classification benchmarks by over 30×, filling a gap the authors identify as blocking an 'ImageNet moment' for structural biology.

## Why It Matters / Open Questions

TEDBench provides the first large-scale, non-redundant supervised benchmark for protein fold classification, enabling systematic comparison of structure-based representation learning methods at a scale previously impossible. The striking efficiency result—MiAE-B (102M params, 768 GPU-hours pretraining) outperforming ESM2-650M and SaProt-650M (138,240 GPU-hours) by a wide margin—suggests that aggressive masking in a geometric autoencoder is a far more compute-efficient path to strong protein structure representations than scaling sequence or hybrid models. Open questions include whether MiAE transfers to tasks beyond fold classification (function prediction, interaction modeling), whether the protein-level label assignment (largest domain only) obscures biologically relevant smaller domains, and whether the 90% masking optimum generalizes to other structural tasks.

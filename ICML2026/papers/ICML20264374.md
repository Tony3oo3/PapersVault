## Problem

Existing KV cache eviction methods allocate memory budgets across attention heads using instantaneous heuristic scores (e.g., attention magnitudes), implicitly assuming these scores are reliable proxies for future importance across all heads. The paper identifies that this magnitude-based paradigm ignores the heterogeneity in predictive fidelity across heads: in some heads, high-magnitude scores capture transient noise rather than enduring semantic anchors, causing suboptimal cache retention. The gap is that no prior method explicitly quantifies the long-horizon marginal utility of each head's budget and optimizes the global allocation accordingly.

## Input / Output

At inference time, the method takes a pre-filled long-context document, a target global compression ratio σ, and a user-chosen heuristic metric π (e.g., SnapKV or KeyDiff), and produces per-head integer token budgets b_{ℓ,h} that determine which KV positions each head retains. The allocation is retrieved from a pre-computed offline profile Φ^(π) — a lookup table mapping any global sparsity to per-head local compression ratios — so the online step is a simple table lookup followed by per-head top-k selection, introducing negligible runtime overhead. The offline profiling itself uses a synthetic ~4,000-token context and 30 generated queries to compute oracle importance via full-attention decoding, making the method task-agnostic and metric-agnostic.

## Method

LU-KV formulates cross-head budget allocation as a global combinatorial optimization problem that minimizes aggregate eviction loss, where loss is decomposed into a fixed oracle-metric component and a metric-dependent optimality gap. Because the discrete loss sequence is non-convex under heuristic metrics, the paper applies isotonic regression (PAVA) to project marginal loss decreases onto a non-negative, non-increasing sequence, yielding a convex surrogate whose effective marginal gains g_{ℓ,h}^π(i) are monotonically decreasing. A greedy solver then allocates the global budget B_total by iteratively assigning each token to the head with the largest next available marginal gain, provably achieving the global optimum of the relaxed problem (matching exact DP solutions). To avoid requiring future decoding at inference time, the optimal per-head compression ratios are pre-computed offline via a data-driven profiling protocol and stored as a static lookup table, so online execution reduces to a table lookup, integer budget conversion, and independent per-head top-k eviction under the chosen metric.

## Results

At 80% KV cache compression, LU-KV achieves 45.79% average accuracy on LongBench with Mistral-7B-v0.3 (SnapKV metric), recovering 84% of the gap to the Full-KV upper bound (47.30%), compared to 41.89% for AdaKV and 40.94% for PyramidKV. On the more challenging RULER-16K retrieval benchmark, LU-KV achieves 69.98% average accuracy (Mistral-7B, SnapKV), nearly doubling AdaKV's 37.48% and PyramidKV's 32.43%. With the KeyDiff metric on Qwen2.5-32B, LU-KV reaches 48.26% on LongBench and 88.88% on RULER-16K, approaching the Full-KV upper bounds of 48.51% and 95.02% respectively.

## Baselines & Comparisons

LU-KV consistently outperforms both PyramidKV and AdaKV across all models, metrics, and benchmarks. On LongBench (Mistral-7B, SnapKV), LU-KV achieves 45.79% vs. AdaKV's 41.89% (+3.9) and PyramidKV's 40.94% (+4.9); with KeyDiff the gap widens to +5.7 over AdaKV and +9.6 over PyramidKV. The advantage is most dramatic on RULER-16K, where retrieval tasks are extremely sensitive to cache quality: on Mistral-7B with SnapKV, LU-KV scores 69.98% versus AdaKV's 37.48% (+32.5) and PyramidKV's 32.43% (+37.6), and on Qwen2.5-32B with KeyDiff, LU-KV reaches 88.88% versus AdaKV's 80.81% (+8.1) and PyramidKV's 70.68% (+18.2). The paper attributes PyramidKV's weakness to its rigid pyramidal prior causing excessive pruning in deep layers, and AdaKV's limitation to its reliance on uncalibrated proxy score magnitudes that fail to capture true oracle importance, particularly in heads with high optimality gap.

## Relation to Prior Work

This paper carves new ground at the intersection of KV cache eviction and combinatorial optimization. While intra-head scoring methods (H2O, SnapKV, KeyDiff) and static/dynamic allocation heuristics (PyramidKV, AdaKV) are well studied, the paper argues that the cross-head budget allocation sub-problem has been underdeveloped because prior approaches implicitly assume instantaneous score magnitudes are reliable proxies for long-term importance. It departs from this by introducing an Oracle Importance definition (drawing on output-perturbation analysis from AdaKV and CriticalKV) and reframing allocation as a global combinatorial optimization over long-horizon marginal utility, solved via convex-hull relaxation (PAVA) and a greedy solver. The framework is explicitly metric-agnostic, repurposing any existing proxy (SnapKV, KeyDiff, EA) as input to the optimizer rather than treating the scoring metric as the primary design target.

## Why It Matters / Open Questions

The practical impact is substantial: 80% KV cache reduction with minimal accuracy loss and negligible runtime overhead (offline profiling + table lookup) makes long-context inference significantly cheaper in memory and latency, which is critical for production deployment. The key open question is the transferability of the offline compression profile: the paper shows stability across LongBench and RULER tasks, but domain shifts, novel architectures, or streaming/online settings where the context evolves incrementally remain untested. Additionally, the oracle importance is approximated via a finite decoding window (K_max), and how sensitive the optimal allocation is to this window length is not fully characterized. The metric-agnostic design suggests the framework could be a drop-in improvement layer atop any future scoring method, but this has only been validated on three metrics.

## Problem

Existing multi-agent and mixture-of-agents frameworks select a fixed set of experts at the task level, which is too coarse-grained because different instances within the same task may require different expertise (e.g., algebra vs. probability within math). Moreover, naively implementing instance-level expert selection incurs prohibitive GPU overhead from repeatedly loading and offloading models, making it impractical to serve a large pool of experts on limited hardware.
![Teaser figure](../imgs/ICML20260648/cropped_page1_idx0.webp)

## Input / Output

The method takes a text question and a pool of 16 pre-trained LLMs (3.5B–12B parameters) as input, along with a small per-task validation set (~350 samples) used during preprocessing to build skill-score profiles for each model. At inference, a Keyword LLM (Qwen2.5-7B) infers 2–5 discrete skills per question, and Sentence-BERT embeddings align these to profile skills. The output is a single synthesized answer produced by a task-specific aggregator that concatenates and integrates k (typically 3) chain-of-thought reasoning traces from the recruited experts, requiring only one round of generation per expert.

## Method

SKILL-MOE is a symbolic, gradient-free Mixture-of-Experts framework that routes at the model level using inferred skills rather than learned gating functions. During preprocessing, each model in the pool is scored on validation questions by skill (correct = +1, incorrect = −1), producing a per-model skill profile; a separate synthetic aggregation benchmark selects the best aggregator per task. At inference, the test question's skills are matched to profile skills via Sentence-BERT cosine similarity, and experts are recruited by sampling k models from a categorical distribution proportional to the product of local suitability (sum of matched skill scores) and global competency (normalized total profile score), with softmax temperature 0.5 and trimming of experts appearing in fewer than 5% of samples. Recruited experts each generate a single CoT response, which a task-specific aggregator synthesizes into the final answer. A batch inference strategy groups instances by assigned experts so each model is loaded only once per batch, enabling 16 models to run on a single GPU with runtime comparable to prior multi-agent baselines using 4 GPUs.

## Results

SKILL-MOE achieves an average accuracy of 62.43% across four benchmarks (AIME, MMLU-Pro, MedMCQA, GPQA), delivering an 8.15% absolute improvement over the strongest multi-agent baseline (Self-MoA, 54.28%). Per-benchmark, SKILL-MOE scores 68.88% on AIME, 63.71% on MMLU-Pro, 59.35% on MedMCQA, and 57.78% on GPQA. Notably, SKILL-MOE matches or exceeds 70B-parameter models (Qwen2.5 72B: 54.28%, Llama3.3 70B: 53.18%) while operating primarily with 7–8B models on a single GPU, achieving 44% lower inference latency than MoA.

## Baselines & Comparisons

SKILL-MOE outperforms all multi-agent baselines on average, beating the strongest (Self-MoA, 54.28%) by 8.15% and MoA (53.76%) by 8.67%. On AIME, SKILL-MOE (68.88%) edges out Self-Consistency with the task-best model (67.78%) by 1.10%, while on MMLU-Pro it leads MoA (61.78%) by 1.93% and on GPQA it surpasses Self-Consistency (53.54%) by 4.24%. The one exception is MedMCQA, where ReConcile (60.74%) narrowly beats SKILL-MOE (59.35%) by 1.39%, though SKILL-MOE still leads all other baselines on that benchmark. Against larger single models, SKILL-MOE's 62.43% average exceeds QwenR1 32B (56.94%) by 5.49% and Qwen2.5 72B (54.28%) by 8.15%, despite using only 7–8B experts. The paper also shows that no single baseline is consistently second-best across tasks (e.g., MoA leads on MMLU-Pro but trails on AIME; ReConcile leads on MedMCQA but fails on GPQA), whereas SKILL-MOE delivers the top or near-top result on every benchmark without task-specific tuning.

## Relation to Prior Work

SKILL-MOE repurposes the sparse Mixture-of-Experts paradigm (Shazeer et al., 2017) by replacing learned parameter-space gating with a gradient-free, skill-based symbolic router that operates over a pool of independently trained LLMs. It also builds on the Mixture-of-Agents line of work (Wang et al., 2024; Chen et al., 2024b) but departs in two key ways: (1) expert selection is adaptive and instance-level rather than a fixed task-level set, and (2) a single-round aggregator replaces costly multi-round discussions. The routing mechanism draws on Sentence-BERT embeddings to match inferred skills against pre-computed model profiles, a design that has no direct analogue in prior LLM-routing work (e.g., DER, Router-R1), which typically learns routing end-to-end.

## Why It Matters / Open Questions

The practical contribution is significant: running 16 heterogeneous 7–8B models on a single GPU with runtime comparable to 4-GPU multi-agent baselines makes skill-based expert mixing accessible without large compute budgets. The finding that a well-chosen task-specific aggregator largely obviates multi-round discussion challenges the prevailing assumption in multi-agent literature that iterative debate is necessary for quality synthesis. Open questions include whether the approach scales to 70B+ models, whether skill profiles remain stable as base models are updated, and how the method behaves when the validation set is very small or the task distribution shifts substantially at deployment time.

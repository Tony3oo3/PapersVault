## Problem

Existing in-context learning theory explains only parametric recall and amortized inference, where the computational procedure is fixed in the frozen weights and the prompt merely selects content or supplies data. The prompt-programmed regime—where the prompt itself specifies a new procedure for a single fixed model—remains under-theorized: prior prompt-as-program results are largely existential, rely on simplified attention variants (linear, ReLU, hardmax), and lack constructive prompt compilers or modular composition guarantees for standard softmax Transformers.

## Input / Output

The method takes a prompt encoding P_f (constructed by serializing surrogate approximator weights via a token-indexed vector encoding into a 2d×n block per weight vector) concatenated with an input sequence X ∈ R^{d×n} on a compact domain C = [-b,b]^{d×n}. The output is the first d rows and first n columns of the frozen Transformer's output, approximating the target L-Lipschitz continuous sequence-to-sequence map f(X). The emulator depth is fixed (6 layers for the contextual-mapping route, 8 layers for the attention-only route), and only P_f changes with the target function; the emulator weights θ* depend solely on the domain, Lipschitz constant, accuracy budget, and architecture parameters.

## Method

The core technique is in-context emulation: a fixed-weight softmax Transformer T_θ* reads a prompt P_f that encodes the weights of a surrogate approximator A_{φ_f} and executes the encoded computation on input X, so that T_θ*(P_f, X) ≈ A_{φ_f}(X) ≈ f(X). Two surrogate routes are proven: (i) a contextual-mapping route using an FF₂∘Attn^Res∘FF₁ surrogate emulated by a 6-layer attention stack, and (ii) an attention-as-selector route using a 4-layer attention-only surrogate emulated by an 8-layer attention stack. The key encoding mechanism (Definition 3.1) maps each weight vector w to a 2d×n block storing both w and its token-indexed multiples, enabling fixed attention heads to recover arbitrary linear forms; flow-through blocks with identity-matrix anchors propagate prompt information across emulator layers. For compositional generalization, the paper proves one-pass composition (an 8m-layer emulator executes f_m∘…∘f₁ in a single forward pass with depth linear in m) and multi-pass composition (the same fixed 8-layer model is re-prompted m times, keeping depth constant while paying in inference calls).

## Results

This is a purely theoretical paper with no empirical benchmarks. The main quantitative guarantees are architectural: Theorem 3.1 shows a fixed 6-layer softmax-attention Transformer (Attn₆) approximates every L-Lipschitz sequence-to-sequence function on a compact domain to arbitrary precision ε by changing only the prompt P_f. Theorem 3.2 achieves the same with an 8-layer attention-only emulator (Attn₈) using the attention-as-selector route. For composition, Theorem 4.1 requires depth 8m for one-pass execution of an m-fold composition, while Theorem 4.2 keeps depth fixed at 8 and uses m sequential calls. In all cases, the emulator weights θ* depend only on the domain, Lipschitz constant, and error budget—not on the target function f or input X.

## Baselines & Comparisons

The paper positions itself against three existing strands of ICL theory using three desiderata: (D1) standard softmax attention, (D2) one frozen model across all targets, and (D3) an explicit target-to-prompt compiler f↦P_f. Statistical-learning analyses (Li et al., 2023; Garg et al., 2022) and task-specific-weight emulation (Bai et al., 2023; von Oswald et al., 2023) satisfy neither D2 nor D3, as they either fix the procedure in weights or vary θ per algorithm. Expressivity and Turing-completeness results (Pérez et al., 2021; Qiu et al., 2025; Jiang et al., 2025) achieve broad computation but typically use hardmax/linear attention (violating D1), rely on autoregressive generation or growing context, and do not provide a reusable continuous prompt compiler (violating D3). Prompt-tuning universality (Wang et al., 2023; Petrov et al., 2024b) keeps the model fixed but treats the prompt as an interpolation table of input-output pairs rather than a program encoding, so it does not support modular composition of subprogram prompts. The closest prior work, Hu et al. (2026b), establishes fixed-weight in-context emulation for attention-implementable algorithms but does not extend to general continuous sequence-to-sequence functions or to prompt-level function composition. This paper is the first to simultaneously satisfy all three desiderata for standard softmax Transformers and to provide constructive, modular prompt assembly for composite functions.

## Relation to Prior Work

This paper extends the in-context algorithm emulation framework of Hu et al. (2026b) from attention-implementable algorithms to broad L-Lipschitz continuous sequence-to-sequence functions, and from single-task prompting to prompt-level function composition. It builds on two established Transformer universal approximation routes — contextual mapping (Kajitsuka & Sato, 2024; Hu et al., 2025a) and attention-as-selector (Hu et al., 2026a) — by reducing them to in-context emulation: encoding surrogate weights into prompts so that one fixed softmax Transformer executes the encoded computation. The key departure from prior ICL theory is targeting the 'prompt-programmed execution' regime, where the prompt specifies the procedure itself rather than merely supplying data or examples to a fixed inference rule encoded in the weights.

## Why It Matters / Open Questions

This work provides the first constructive, softmax-attention-based proof that a single frozen Transformer can approximate arbitrary continuous sequence-to-sequence functions purely through prompt changes, and that such prompts compose modularly — giving a theoretical grounding for the 'prompt as program' intuition behind GPT-style models. However, the constructions are highly theoretical: the emulator complexity scales exponentially in the input dimension, the results are existential (one fixed model exists, but no practical construction is given), and no experiments validate that pretrained LLMs actually exploit these mechanisms. Open questions include whether the exponential complexity is fundamental or an artifact of the proof technique, whether the prompt encodings correspond to natural-language instructions, and whether the composition theorems explain the multi-step reasoning observed in practice.

## Problem

In truncated linear regression, samples (x, y) are observed only when the outcome y falls inside an unknown survival set S*, making standard estimation procedures biased. Prior algorithms for the unknown-S* case either required Gaussian features with exponential-in-d running time (Lee et al., 2024) or were information-theoretically impossible without structural assumptions on S*. No polynomial-time algorithm existed that handles unknown S* under merely sub-Gaussian features.
![Teaser figure](../imgs/ICML20262216/cropped_page5_idx0.webp)

## Input / Output

The algorithm takes n i.i.d. truncated samples (x, y) where x ∈ R^d and y ∈ R are observed only when y ∈ S*, along with known parameters (α, β, ε, δ, R, k) specifying survival probability lower bound, feature mean bound, target accuracy, failure probability, parameter norm bound, and the number of intervals in S*. It outputs a regression vector estimate w̄ satisfying ||w̄ − w*||₂ ≤ ε with probability at least 1−δ. The sample complexity and runtime are both poly(dk/ε) (with exponential dependence on σ, β, 1/ρ, 1/α in the exponent), and the algorithm does not require knowledge of S* or a parametric form for the feature distribution.

## Method

The algorithm operates in two phases. Phase I learns an approximation S of the unknown survival set S* (a union of at most k intervals) via positive-only PAC learning under a smoothness condition: it constructs an auxiliary distribution D̃_y from sub-Gaussian features (Lemma 3.5, replacing the Gaussian-specific construction of Lee et al. 2024), then applies a greedy interval-discarding procedure (Algorithm 1) that runs in O(n log n) time. Phase II estimates w* by running Projected Stochastic Gradient Descent (PSGD) on a perturbed negative log-likelihood L_S(w) defined using the learned set S; a warm start is obtained via OLS on the truncated data, a constant-radius projection ball P is defined around it, and PSGD is run with a biased gradient estimator whose bias is controlled by the set-learning accuracy ε. The key technical insight is that sub-Gaussianity of x suffices to ensure the perturbed NLL gradient is small with high probability and bounded in expectation, enabling convergence without any parametric assumption on the feature distribution.

## Results

The main theoretical result (Theorem 3.1) establishes a poly(dk/ε)-time algorithm for truncated linear regression with an unknown survival set (union of at most k intervals) under only sub-Gaussian features, improving the prior best running time of d^poly(k/ε) (Lee et al., 2024) to polynomial in all parameters. The explicit sample complexity is n = k·(d/e)^{Õ((σ+β)⁶/(ρ⁴α²))}. In the empirical evaluation (Section 4, 10-dim Gaussian mixture, 5-interval truncation), the proposed algorithm converges to w* at essentially the same rate as the idealized PSGD with the true S*, while OLS and PSGD with a misspecified set remain significantly biased.

## Baselines & Comparisons

The paper compares four methods on synthetic data (10-dim mixture of 5 Gaussians, truncation set = union of 5 intervals, R=10): (1) OLS ignoring truncation, (2) PSGD on the MLE objective with a misspecified truncation set S (the Daskalakis et al. 2019 algorithm), (3) PSGD on the MLE objective with the true S* (idealized, not implementable in practice), and (4) the proposed full algorithm. OLS and PSGD-with-wrong-S both produce significantly biased estimates that do not converge to w*. The proposed algorithm converges to w* at essentially the same rate as the idealized PSGD-with-true-S*, confirming that the learned approximation of S* is sufficient. Theoretically, the key improvement over Lee et al. (2024) is reducing the running time from d^poly(k/ε) to poly(dk/ε) while simultaneously relaxing the feature distribution assumption from Gaussian to sub-Gaussian.

## Relation to Prior Work

This paper extends the truncated linear regression line initiated by Daskalakis et al. (2019) for known survival sets and Lee et al. (2024, FOCS) for unknown survival sets, which required Gaussian features and ran in d^poly(k/ε) time. The key departure is replacing the Gaussianity assumption with the much weaker sub-Gaussianity condition, achieved by constructing a smooth auxiliary distribution for the positive-only PAC learning subroutine (building on the smoothness framework of Lee et al., 2026, STOC) and designing a greedy algorithm for learning unions of intervals in poly(dk/ε) time. The perturbed NLL objective and two-phase structure (learn S*, then optimize w*) are inherited from Lee et al. (2024), but the gradient analysis and SGD convergence proof are substantially reworked to handle non-Gaussian covariates.

## Why It Matters / Open Questions

This is the first polynomial-time algorithm for truncated linear regression with unknown survival set that does not require a parametric form for the feature distribution, making it applicable to the non-Gaussian feature regimes common in econometrics, astronomy, and biomedical data. The positive-only PAC learning result for unions of intervals under smoothness (Theorem 3.4) is explicitly noted as potentially of independent interest beyond truncated regression. Open questions include extending to non-linear models (Poisson, logistic regression) with unknown truncation, learning richer hypothesis classes in constant dimensions, and understanding whether the exponential dependence on problem parameters in the sample complexity can be further reduced.

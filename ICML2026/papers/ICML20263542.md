## Problem

Existing neuro-symbolic methods enforce logical rules approximately via soft penalties, assume input-independent constraints in specialized architectures, or rely on non-differentiable post-processing at inference. Extending differentiable optimization layers to handle input-dependent mixed-integer linear constraints (e.g., if-then rules with disjunctive consequents) remains challenging because logical operators like disjunction induce nonconvex, disjoint feasible regions that break standard convex optimization formulations.

## Input / Output

The method takes tabular input features x, a set of R input-dependent logical rules of the form 'if x ∈ A_r then y ∈ C_r(x)' where each C_r(x) is a finite union of polyhedra (disjunctive constraints), and optional global linear constraints on the output. It produces a rule-consistent prediction y* computed as the ℓ1-closest point in the intersection of all active rule feasibility sets, along with the projection distance η*. The ℓ1 norm is specifically chosen because it admits an exact linear epigraph formulation, which is essential for the LP-based exactness guarantee. Rules are activated per-sample based on the input, so the feasible set F(x) varies across the dataset.

## Method

DisjunctiveNet represents each rule's consequent as a finite union of polyhedra and applies a hierarchical convex relaxation (Balas' basic step hierarchy) to obtain a convex hull formulation. The key mechanism is a DNF (disjunctive normal form) expansion that distributes intersections over unions across all active rules, yielding the exact convex hull of the nonconvex feasible set; a CNF variant convexifies each rule independently for scalability. The ℓ1 projection is formulated as an LP via an epigraph reformulation where the epigraph and global constraints are lifted into each disjunct *before* convexification, ensuring that extreme-point solutions of the resulting LP satisfy the original disjunctive rules exactly (Theorem 3.6). End-to-end differentiability is achieved by implicit differentiation through the KKT conditions of the LP (via DiffOpt.jl), with a quadratic regularizer in the backward pass to handle potential discontinuities. A sequential convexification scheme (partial DNF) allows practitioners to trade off relaxation tightness against LP size by selectively expanding a subset of rules in DNF form while keeping others in CNF form.

## Results

On the PBMC3k scRNA-seq benchmark (8 cell types, 1838 gene features), DNF projection achieves 91.8% constraint satisfaction (CSAT) at n=234 training samples, compared to 52.0% for the unconstrained base network and 86.3% for CNF. In the data-scarce regime (n=12), DNF reaches 90.8% CSAT versus only 10.5% for the base model, while also improving macro-F1 from 0.232 to 0.326. On the synthetic cooling-control task, DNF achieves 100% constraint satisfaction on both IID and OOD test sets, with per-sample inference overhead of 28.62 ms (vs. <1 μs for the base network). The rules-only baseline (random disjunct selection) achieves 98% CSAT but only 0.17 macro-F1, confirming that rules must be combined with data-driven learning.

## Baselines & Comparisons

The paper compares against four baselines: an unconstrained base MLP, a penalty-based model (soft rule enforcement via loss terms), a finetuned penalty model (same pretrained initialization as projection models), and a rules-only baseline that randomly selects a feasible disjunction. DNF projection dominates all baselines on constraint satisfaction across every dataset size: at n=117 it achieves 94.8% CSAT versus 48.7% (base), 46.4% (penalty), and 61.1% (finetuned penalty). CNF also substantially outperforms soft baselines (84.6% vs. 48.7% CSAT) but consistently trails DNF by 5–15 percentage points. On predictive accuracy (macro-F1), the advantage of projection is most pronounced in the low-data regime (n=12: DNF 0.326 vs. base 0.232), while at larger dataset sizes (n=234) the base model recovers to 0.606 F1, slightly exceeding DNF's 0.549, revealing a trade-off between exact rule adherence and raw accuracy. The rules-only baseline confirms that logical structure alone is insufficient for classification (0.175 F1) despite near-perfect CSAT (98%), validating the need for the combined data-driven + projection approach.

## Relation to Prior Work

This paper unifies two previously separate lines of work: the disjunctive programming literature (Balas, 2018), which provides convex-hull extended formulations for unions of polyhedra, and the differentiable optimization layer framework (OptNet, CVXPYlayers), which enables hard constraint enforcement within neural networks. Prior differentiable optimization layers handle only continuous/convex constraints, while prior neuro-symbolic methods (SATNet, semantic loss, MultiplexNet) handle logical rules but either use soft penalties without exactness guarantees or are restricted to input-independent constraints. The key departure is applying the Balas convex-hull theorem to the DNF expansion of input-dependent disjunctive rules, yielding the tightest possible convex relaxation whose extreme points provably satisfy the original logical constraints—something prior LP-relaxation-based approaches (Wilder et al., Ferber et al.) do not guarantee.

## Why It Matters / Open Questions

The framework provides the first end-to-end differentiable layer that guarantees exact satisfaction of input-dependent mixed-integer linear (logical) constraints during both training and inference, filling a gap between soft neuro-symbolic penalties and hard continuous-constraint projection layers. The practical impact is strongest in data-scarce scientific and engineering settings where domain rules encode structural knowledge that data alone cannot recover, as demonstrated by the OOD generalization gains in the cooling-control task. Key limitations include the exponential scaling of DNF with the number of active rules (mitigated by the partial-DNF/basic-step hierarchy), the requirement for simplex-type solvers returning extreme points, and the restriction to linear constraints within disjuncts. Open questions include adaptive selection of which rules to expand in DNF form, extension to convex nonlinear disjuncts, and handling of contradictory or noisy rule bases.

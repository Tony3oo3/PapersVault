## Problem

Since Tang's 2019 breakthrough showing that quantum-inspired classical (QIC) algorithms could match quantum algorithms for recommender systems, nearly all initially exponential quantum machine learning speedups have been reduced to polynomial. For the fundamental problem of solving linear systems, no unconditional lower bound separating quantum from QIC algorithms existed, leaving open whether any natural ML task admits a provable exponential quantum advantage. This paper provides the first such unconditional exponential separation for linear systems with sparse, well-conditioned matrices.

## Input / Output

The algorithm receives a symmetric real n×n matrix M with at most s non-zero entries per row and column, and a vector y, both accessed via sampling-and-query (SQ) access—allowing individual entry queries, ℓ₂-norm sampling from rows and columns, and norm queries—rather than full matrix access. The output is a single sampled index i drawn with probability x̃_i²/||x̃||² from an approximate solution x̃ satisfying ||x̃ − x|| ≤ ε||x|| where x = M⁻¹y. In the hard instance, s = 3, the condition number κ ≤ c·ln n, and y is simply the first standard basis vector e₁.

## Method

The lower bound is proved via two alternative reductions. The first reduces from the random walk game on two binary trees with randomly connected leaves (Childs et al., 2003): the matrix M is constructed as B = λI − A on the graph's adjacency matrix A, with λ = √8 + γ chosen extremely close to the Ramanujan bound √8 to simultaneously keep the condition number polylogarithmic and concentrate the solution mass at the target root node. The second reduction combines the HHL BQP-hardness construction with the k-Forrelation oracle problem, showing that a QIC linear-systems solver would yield a classical k-Forrelation algorithm violating known Ω((2ⁿ/n)^{1−1/k}) query lower bounds. Both reductions establish that any QIC algorithm requires Ω(n^{1−1/k}) queries while the best quantum algorithm (Costa et al., 2022) runs in O(ln n) time, yielding the exponential separation.

## Results

The main result (Theorem 1.5) establishes that for any QIC algorithm with precision ε ≤ 2^(−ck), there exists a 3-sparse, well-conditioned (κ ≤ c ln n) n×n symmetric real matrix M such that the algorithm must make Ω(n^(1−1/k)) queries to SQ(M) to sample from the approximate solution of Mx = e₁. The best known quantum algorithm (Costa et al., 2022) solves the same problem in O(κ ln(1/ε) min{s, √s(κs/ε)^o(1)}) = O(ln n) time for these parameters (s = 3, κ = O(ln n), ε = constant), yielding an exponential separation of ln n (quantum) versus n^(1−1/k) (QIC lower bound). The separation holds even for constant precision ε and constant k, and extends to the sparse access model.

## Baselines & Comparisons

The paper's lower bound is the first unconditional exponential separation between quantum and QIC algorithms for linear systems. The QIC upper bound by Shao & Montanaro (2022) is poly(s, κ_F, ln(1/ε), ln n), which can be as large as poly(n) when κ_F = O(√n), but the new lower bound of Ω(n^(1−1/k)) for constant k is exponentially larger than the quantum O(ln n) upper bound, closing the gap. Previous lower bounds by Mande & Shao (2024) via communication complexity reductions only achieved quadratic separations (Õ(κ_F²) lower bounds vs Õ(κ_F) quantum upper bounds), whereas this work achieves an exponential gap. The HHL paper (Harrow et al., 2009) established a conditional separation by showing the problem is BQP-complete under a short binary encoding, but this relies on the unproven assumption BQP ≠ P; the present result is unconditional and gives an explicit query complexity gap. The reduction from k-Forrelation (Aaronson & Ambainis, 2015) yields the tightest parameters, while the reduction from the Childs et al. (2003) random walk problem gives slightly worse but more self-contained bounds (Ω(n^(1/12)) queries with κ = O(ln² n)).

## Relation to Prior Work

This paper builds on the HHL quantum linear systems algorithm (Harrow et al., 2009) and the QIC input model introduced by Kerenidis & Prakash (2017), which defines sampling-and-query access as the fair classical counterpart to quantum state preparation. It departs from prior lower-bound work (Mande & Shao, 2024; Andoni et al., 2019) that established only polynomial or conditional (BQP≠P) separations, by proving an unconditional exponential gap via reductions from the Childs et al. (2003) random-walk game on two binary trees or from k-Forrelation (Aaronson & Ambainis, 2015). The key conceptual departure is showing that the QIC sampling access, while powerful enough to dequantize recommender systems (Tang, 2019), is fundamentally insufficient for linear systems with logarithmic condition number and constant sparsity.

## Why It Matters / Open Questions

This is the first unconditional exponential separation between quantum and QIC algorithms for any natural machine learning task, resolving a central open question that had persisted since Tang's 2019 dequantization of the quantum recommender system. It establishes that the quantum advantage for linear systems is not an artifact of the input model but is inherent, provided the condition number is at least logarithmic in the matrix size. Open questions include whether similar separations exist for other natural problems (e.g., regression, PCA) and whether practical linear systems exploit structural properties beyond spectral parameters that could close the gap for QIC algorithms. The result also suggests that the HHL BQP-completeness result was a correct intuition about inherent quantum advantage, now made unconditional.

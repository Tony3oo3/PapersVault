## Problem

Existing LLM multi-agent systems rely on natural language as the communication medium, forcing each agent's internal reasoning to be compressed into discrete tokens before being re-encoded by the next agent. While latent reasoning has been explored for single models and KV-cache transfer for cross-model communication, no unified framework enables both latent reasoning and latent communication simultaneously within a multi-agent pipeline. This paper asks whether multi-agent systems can achieve pure latent collaboration—reasoning and communicating entirely in continuous representation space without any text decoding in intermediate steps.

## Input / Output

The system receives a text question and per-agent instruction prompts, which are tokenized and embedded as standard input. Intermediate agents produce no text output at all; instead, they generate sequences of last-layer hidden vectors (latent thoughts) and transfer their full layer-wise KV caches to the next agent. Only the final agent decodes a text answer, and the total decoded token count is substantially lower than in text-based MAS because the final agent aggregates compact latent working memory rather than long textual reasoning traces.

## Method

LatentMAS is a training-free framework with two core mechanisms. First, each agent performs auto-regressive latent thoughts generation by feeding its own last-layer hidden state back as the next input embedding, with a precomputed linear alignment matrix W_a ≈ W_out† W_in mapping hidden states into the valid input embedding space to prevent distributional drift. Second, cross-agent communication uses latent working memory transfer: after an agent completes its latent steps, its full layer-wise KV caches (encoding both the original input context and the newly generated latent thoughts) are concatenated into the successor agent's KV cache, guaranteeing lossless information transfer without re-encoding. Theoretical analyses show that latent thoughts are O(d_h/log|V|) times more expressive than text tokens, that KV transfer is provably equivalent to direct input, and that the overall inference complexity is lower than text-based MAS achieving the same expressiveness.

## Results

Across 9 benchmarks and 3 Qwen3 model scales (4B/8B/14B), LatentMAS achieves up to 14.6% higher accuracy than single-model baselines and 2.8%–4.6% higher accuracy than text-based MAS under sequential and hierarchical settings, respectively. On efficiency, LatentMAS reduces output token usage by 70.8%–83.7% and delivers 4×–4.3× faster end-to-end inference compared to text-based MAS. On reasoning-intensive tasks (AIME24/25, GPQA-Diamond), LatentMAS with Qwen3-14B reaches 66.7% on AIME24 and 52.0% on GPQA-Diamond, outperforming both single and text-MAS baselines while using fewer than 11K tokens versus 32K–45K for TextMAS.

## Baselines & Comparisons

LatentMAS is compared against two text-based MAS baselines: Sequential TextMAS (Chain-of-Agents, Zhang et al. 2024) and Hierarchical TextMAS (domain-specialized agents with summarizer, Zhuge et al. 2024). Against Sequential TextMAS, LatentMAS wins on average accuracy by 2.8% (e.g., GSM8K: 93.8% vs 92.3%; MBPP+: 74.6% vs 69.5% on Qwen3-8B) while reducing token usage by 70.8% and achieving 4× faster inference; it slightly trails on a few commonsense tasks (ARC-Easy: 98.8% vs 99.1%; ARC-Challenge: 94.4% vs 94.6%). Against Hierarchical TextMAS, the accuracy gap widens to 4.6% on average (e.g., GPQA-Diamond: 53.0% vs 52.0%; AIME24: 73.3% vs 70.0% on Qwen3-14B), with 83.7% token reduction and 4.3× speedup. Both baselines are also outperformed by single-model agents on token efficiency, confirming that the multi-agent overhead in text-based MAS is substantial. Ablations (Table 7) further show that replacing either latent reasoning or latent communication with its text counterpart degrades accuracy by 2–8 points, confirming both components are necessary.

## Relation to Prior Work

This paper unifies two previously separate lines of work: single-model latent chain-of-thought reasoning (Hao et al., 2024) and cross-model KV-cache information exchange (Liu et al., 2024; Fu et al., 2025; Zheng et al., 2025). Prior latent-reasoning methods operated within a single model, while prior KV-sharing methods transferred only prefilled input context between models without enabling latent auto-regressive generation. LatentMAS is the first framework to combine both—auto-regressive latent thought generation within each agent and layer-wise KV-cache transfer as lossless inter-agent communication—into a single training-free multi-agent pipeline, building on the chain-of-agents (Zhang et al., 2024b) and hierarchical expert (Zhuge et al., 2024) MAS architectures.

## Why It Matters / Open Questions

The training-free nature (requiring only a one-time pseudo-inverse computation) makes LatentMAS immediately deployable on any off-the-shelf LLM without fine-tuning, which is a significant practical advantage over learned latent-communication methods like ThoughtComm or Cache-to-Cache. The 4×–4.3× speedup with 70–84% token reduction while matching or exceeding text-based MAS accuracy suggests that natural language is an unnecessarily lossy and expensive medium for inter-agent coordination. Open questions include whether latent collaboration scales gracefully beyond 4–5 agents, how it behaves with heterogeneous model architectures (different layer counts or hidden dimensions), and whether the interpretability gap (agents 'thinking' in opaque vectors) is acceptable for safety-critical deployments—the paper's 'debug mode' is a first step but not a full solution.

## Problem

Existing skill grounding approaches for embodied agents regenerate entire skill implementations from scratch when deployment conditions change, incurring prohibitive computational overhead on capacity-limited devices where LLM inference is impractical. Small language models (sLMs) enable efficient on-device inference but lack the reasoning capacity for full code regeneration, leaving a gap in how to ground reusable skills reliably without regenerating code. The paper addresses this by asking whether skill grounding can be reduced to localized code refactoring that preserves semantic intent while modifying only deployment-specific execution bindings.

## Input / Output

The method consumes offline-validated reference skill code (structured to separate semantic intent from execution bindings), a target robot's embodiment profile (URDF/SRDF files plus primitive API specifications), and execution-time observations (object states, contact outcomes, sensory feedback). It produces refactored skill code in which only localized execution-binding spans—API calls, parameter bindings, or interface wrappers—are replaced via Fill-in-the-Middle infilling, while the global control structure and functional logic remain untouched. The skill ontology supplies structured substitution hints (e.g., open_gripper → deactivate_vacuum) that constrain the sLM's editing scope to specific code spans identified by start/end positions, rather than the full program.

## Method

RECENT operates in three phases: (i) an offline skill repository where a cloud-scale LLM generates and validates skill code on a reference robot (Franka Panda), annotated with ontology-based metadata encoding preconditions, effects, and capability relations; (ii) ontology-based reasoning at deployment time that diagnoses embodiment mismatches via a diagnosis operator, decomposing them into determined conflicts (resolved by pre-execution FIM-based localized editing with ontology-derived substitution hints) and undetermined environment-contingent warnings (deferred to execution time); and (iii) in-situ adaptation where lightweight autonomous unit tests monitor execution-time observations against yet-to-be-executed code segments, triggering anticipatory patching of invalidated spans without interrupting ongoing execution. The core mechanism is Fill-in-the-Middle infilling: the sLM receives prefix and suffix context surrounding a target span plus structured grounding hints rendered as inline comments, and generates only the replacement snippet, keeping generation length proportional to the edit size rather than the full skill. This design decouples skill grounding from model-specific reasoning capacity, as the ontology deterministically identifies conflicts and localizes refactoring targets, reducing the sLM's role to constrained span replacement that remains effective across model families and scales from 1.5B to 7B parameters.

## Results

RECENT (with Qwen2.5-Coder-7B) achieves 73.00% SR and 81.76% GC on Kinematic variation, and 82.50% SR and 89.84% GC on End-effector variation, while maintaining near-zero execution interruptions (EI ≈ 0.7) and grounding overhead (GO < 8%). Compared to the LLM-based CaP-Codex (GPT-5.2-Codex), RECENT matches or exceeds task success (6.58 pp higher average SR) while reducing grounding overhead by 57.81 pp and idle time by 7.09 s. Against the strongest sLM baseline (RepairAgent), RECENT improves SR by 30.67 pp, GC by 16.87 pp, and reduces GO by 49.87 pp, EI by 0.72, and IT by 65.40 s.

## Baselines & Comparisons

RECENT outperforms all eight baselines on every metric in both evaluation settings. Against the distilled sLM baseline CaP-CodeV-R1, RECENT improves SR by 58.81 pp (averaged) and reduces GO by 99.09 pp, confirming that localized refactoring is far more efficient than full code regeneration with a capacity-limited model. Against the strongest sLM-based baseline RepairAgent, RECENT gains 30.67 pp in SR and 16.87 pp in GC while cutting GO from ~55% to <8% and IT from ~67 s to ~2 s. Notably, RECENT matches or exceeds the LLM-based CaP-Codex (GPT-5.2-Codex) on task success (73.00% vs 67.50% SR kinematic; 82.50% vs 74.85% SR end-effector) while reducing grounding overhead by 57.81 pp and idle time by 7.09 s on average, despite operating under on-device sLM constraints. The only metric where CaP-Codex edges out RECENT is EI on end-effector variation (0.60 vs 0.69), a negligible difference. Among embodied agentic programming baselines, RoboInspector achieves the highest SR (41.00%/39.17%) but at the cost of the highest GO (179.40%/52.20%) and IT (59.98 s/31.65 s), highlighting the overhead of full regeneration-based repair.

## Relation to Prior Work

RECENT extends the Code-as-Policies (CaP) paradigm by replacing full code regeneration with ontology-guided, Fill-in-the-Middle (FIM) localized refactoring, drawing on the KnowRob skill ontology structure for robot knowledge representation. The key conceptual departure is the explicit separation of invariant semantic intent from deployment-specific execution bindings within skill code, so that grounding reduces to editing a small number of identified spans rather than synthesizing an entire program. This positions RECENT between LLM-based embodied planning (which requires cloud-scale inference) and reactive program-repair agents (which regenerate code after failures), introducing an anticipatory, pre-execution diagnosis phase that offloads reasoning from the sLM to a deterministic ontology.

## Why It Matters / Open Questions

The practical impact is significant for deployment-constrained embodied AI: a 7B sLM with RECENT matches GPT-5.2-Codex task success while reducing grounding overhead by ~58 pp, making long-horizon manipulation feasible on-device without LLM access. However, the framework is scoped to a pre-constructed, stable ontology covering known embodiments and primitives; cases requiring new capabilities (ontology-level extension) fall outside its scope and correspond to incremental skill learning. Open questions include whether the ontology construction pipeline generalizes to truly open-ended environments with novel objects and interactions, and whether the approach transfers to real-world (non-simulated) deployment where sensing noise and contact dynamics are less predictable.

## Problem

While Vision Transformers are known to encode spatial grouping (which patches belong together), it remains unclear whether they learn binding information about which *features* (color, shape, texture) are jointly instantiated in the same object. No formal framework existed to precisely define binding information in a model's representation or to measure it in a task-agnostic, information-theoretic way, making it impossible to quantify how much binding a model actually learns or to compare across architectures and datasets.

## Input / Output

The method consumes frozen ViT representations (either the [CLS] summary token or the full set of final-layer spatial tokens) from pre-trained models such as DINOv2-Large and CLIP ViT-L/14, paired with ground-truth binary object codes and feature codes from synthetic (ColorShape, CLEVR) or natural (Visual Genome) datasets. The autoregressive probe decomposition handles the exponential label space of object codes by training one binary classifier per object position conditioned on previously decoded objects. Outputs include binding information in bits, a normalized proportion of dataset binding uncertainty resolved, conditional binding information that isolates binding beyond feature information, and probe error reduction relative to a trivial majority-label baseline.

## Method

The paper defines binding information as the mutual information I(O; Z) between the scene's object code O (a binary vector indicating which objects are present) and the model representation Z, with a conditional variant I(O; Z | F) that subtracts feature information to isolate pure binding. A key theoretical result (Theorem 2.20) shows that the cross-entropy loss of an autoregressive probe q_θ(o_k | o_<k, z) trained on the representation provides a valid upper bound on H(O | Z), enabling practical estimation of binding information. The probing procedure trains separate probes per object position with the prior object code concatenated to the representation, using probe families ranging from linear to quadratic to deep networks, and a simplified attention probe for spatial tokens. Experiments reveal that the [CLS] token encodes less than half (48.5%) of binding information with a predominantly quadratic (color × shape) structure, while the full spatial token set retains 92.2% of binding information, decodable by a lightweight attention probe that routes to the correct object patch.

## Results

On the ColorShape dataset (8 colors, 8 shapes, 64 objects), the [CLS] token of DINOv2-Large encodes only 19.4 bits of binding information (48.5% of the 39.9-bit dataset prior), with the DNN probe being the best decoder. In contrast, a simplified attention probe over the full set of spatial tokens decodes 36.8 bits (92.2%), and for conditional binding beyond features, spatial tokens reach 94.1% versus 42.4% for [CLS]. Across models and datasets (Table 7), conditional binding information ranges from 39.9% to 68.5%, with higher input resolution (336px vs 224px) consistently improving binding. Occlusion on CLEVR monotonically reduces decodable binding from 58.7% (least occluded) to 45.0% (most occluded).

## Baselines & Comparisons

The paper does not compare against external binding methods but instead compares internal architectural components and probe families. The central comparison is between the [CLS] summary token and the full set of spatial tokens: the attention probe on spatial tokens decodes nearly twice as much binding information (92.2% vs. 48.5%) and conditional binding (94.1% vs. 42.4%), indicating that binding is distributed across spatial tokens rather than concentrated in the global summary. Among probe families on [CLS], quadratic probes (63.0% error reduction) substantially outperform linear probes (37.4%), while DNN probes (64.4%) offer only marginal gains over quadratic, suggesting binding in [CLS] is largely quadratic in structure. A parameter-reuse quadratic probe (sharing color/shape weight matrices) loses 2.4 bits relative to the unconstrained quadratic probe, confirming a conjunctive color×shape encoding. Across models, CLIP ViT-L/14 at 336px outperforms DINOv2-Large on ColorShape (56.4% vs. 41.8% conditional binding) and Visual Genome TopAttr (45.6% vs. 47.0%), while DINOv2-Large leads on CLEVR (61.0% vs. 68.1% for CLIP-224, 68.5% for CLIP-336), showing dataset-dependent model strengths.

## Relation to Prior Work

This paper extends the line of work on measuring binding in pretrained Vision Transformers, building most directly on Li et al. (2025), which proposed quadratic probes to evaluate the IsSameObject binding property. The key departure is a formal information-theoretic framework that defines binding as mutual information between an object code and a representation, introduces a conditional variant that separates binding from feature information, and provides a general probing methodology applicable to arbitrary models and feature definitions. The paper also situates itself within the broader cognitive-science binding problem literature (Treisman & Gelade, 1980; von der Malsburg, 1981) and the growing body of evidence that VLMs fail at feature binding in multi-object scenes (Campbell et al., 2025; Zhang et al., 2024; Yuksekgonul et al., 2023), but moves from symptomatic downstream-task evaluations to a mechanistic, representation-level measurement.

## Why It Matters / Open Questions

The formal information-theoretic definition and probing methodology provide a task-agnostic, principled way to quantify how much binding information a model's representations actually contain, which is essential for diagnosing and improving compositional generalization in vision and vision-language models. The finding that the [CLS] token retains less than half of binding information while spatial tokens retain over 92% has direct practical implications for VLM architectures that rely on summary tokens for cross-modal processing. Key limitations include reliance on predefined discrete feature vocabularies, measurement of decodable (rather than causally used) information, and the assumption that feature codes are inferable from object codes. Open questions include extending the framework to continuous features, identifying architectural inductive biases that improve binding, and using binding probe performance as a pre-training objective.

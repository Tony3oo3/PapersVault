## Problem

Token-level adaptive computation models are typically evaluated on natural-language benchmarks using task-level metrics, where token-level difficulty is unobservable and entangled with architectural choices, making it unclear whether learned compute allocation genuinely tracks underlying computational complexity. This paper addresses the gap by introducing a complexity-controlled evaluation paradigm on algorithmic and synthetic tasks with parameterized difficulty, and a unified recurrent Transformer framework that isolates compute allocation decisions from other confounding model factors.

## Input / Output

The model consumes text sequences in diverse formats: prefix-notation modular arithmetic expressions (MANO), serialized DAGs with query nodes (BREVO), CLRS algorithmic problem statements, PCFG-generated synthetic strings (LANO), and natural-language math questions. It produces next-token logits via a Coda head, with each token assigned a discrete exit depth d_i* ∈ {1,…,D} that determines how many recurrent iterations its representation undergoes. During training the recurrent core is statically unrolled to depth D with a passthrough mechanism freezing halted tokens, while at inference the model stops recurrent computation per token once its selected depth is reached, yielding compute savings proportional to d̄/D.

## Method

ANIRA follows a Prelude–Recurrent–Coda architecture where a shared Transformer block is applied up to D iterations, and a lightweight decider module (≈8% of parameters) predicts per-token exit depth. Two variants are studied: ANIRA-E commits to a depth distribution from shallow Prelude representations via a categorical head (sampled with Gumbel-Softmax during training), while ANIRA-O makes stepwise halting decisions from intermediate recurrent states using conditional exit probabilities that induce an exit-depth distribution (sampled via inverse-CDF with a straight-through estimator). Training minimizes cross-entropy on answer tokens plus a KL-based compute regularizer against an exponential prior p(d) ∝ b^{-d}, which penalizes expected depth while discouraging degenerate distributions. An allocation-aware KV cache retrieves the deepest cached key-value pair for each past token at attention time, enabling correct autoregressive decoding under variable per-token depths. The framework is designed as a controlled experimental vehicle rather than a performance-optimized model, enabling systematic comparison of how decision timing (early vs. online) shapes learned compute policies under identical training objectives.

## Results

On controlled algorithmic tasks, ANIRA achieves near-perfect accuracy (94.3% on MANO, 100% on BREVO) while allocating compute proportional to task complexity (expression length L for MANO, graph size N for BREVO), without any explicit difficulty supervision. On the natural-language GSM-Symbolic benchmark, ANIRA-E matches the fixed-depth-8 baseline within 0.6% on Main (45.70% vs 46.26%) while reducing mean allocated depth from 8 to 6.06, and ANIRA-O achieves 43.68% at mean depth 4.11 (a ~49% compute reduction). However, both variants fail to extrapolate to unseen input sizes on CLRS-Text, with sharp accuracy drops beyond the training range, indicating that complexity-aligned allocation does not confer algorithmic generalization.

## Baselines & Comparisons

The paper's only direct baseline comparison is against a fixed-depth-8 recurrent Llama model (McLeish et al., 2025) on GSM-Symbolic. ANIRA-E is essentially on par with the baseline: it loses 0.56 points on Main (45.70% vs 46.26%) but gains 0.52 points on P1 (24.06% vs 23.54%) and ties on P2 (5.80%), while reducing mean depth from 8 to ~6.0. ANIRA-O trades more accuracy for greater compute savings: it drops 2.58 points on Main (43.68% vs 46.26%) and 0.72 points on P2 (5.08% vs 5.80%), but cuts mean depth to ~4.1 (roughly half the baseline). Notably, neither ANIRA variant allocates more depth to the harder P1/P2 splits, suggesting that on natural language the learned compute policy does not track a simple task-difficulty axis. On the controlled algorithmic tasks (MANO, BREVO, CLRS-Text, DEPO), the comparison is between ANIRA-E and ANIRA-O rather than against an external baseline: ANIRA-O consistently converges to lower average depth than ANIRA-E for equivalent accuracy, and regression analysis shows ANIRA-E's allocation is driven by static structural features (hub structure, R²=0.73) while ANIRA-O's tracks algorithmic execution state (DFS depth, frontier size, R²=0.71).

## Relation to Prior Work

ANIRA extends the adaptive-computation lineage from ACT (Graves, 2016), Universal Transformers (Dehghani et al., 2019), and PonderNet (Banino et al., 2021) by applying per-token variable-depth halting inside a shared recurrent Transformer core, building directly on the Prelude-Recurrent-Coda architecture of Huginn (Geiping et al., 2025). Unlike Mixture-of-Recursions (Bae et al., 2025) and Ouro (Zhu et al., 2025), which evaluate on natural-language benchmarks with task-level metrics, ANIRA is positioned as a controlled experimental vehicle that isolates compute-allocation decisions from architectural confounds and introduces a complexity-controlled evaluation protocol using algorithmic tasks with parameterized difficulty. The paper's key methodological departure is the systematic comparison of two decision-timing mechanisms—early depth prediction (ANIRA-E, related to Depth-Adaptive Transformers) versus online halting (ANIRA-O, related to ACT/PonderNet)—under identical training objectives and compute regularization.

## Why It Matters / Open Questions

The central finding—that complexity-aligned compute allocation emerges without explicit difficulty supervision yet does not yield algorithmic generalization to unseen input sizes—challenges the implicit assumption that adaptive compute should help models learn size-invariant algorithms. The discovery that decision timing fundamentally shapes learned policies (structural heuristics vs. algorithmic-state tracking) provides actionable guidance for architecture design. Open questions include developing token-level complexity proxies for natural language, extending the analysis to diffusion-based LMs and Mixture-of-Experts, and building inference systems (e.g., vLLM-compatible) that can exploit per-token adaptive depth in practice. The small model scale (5–14M parameters for algorithmic tasks) and single-dataset natural-language evaluation limit the generality of the conclusions.

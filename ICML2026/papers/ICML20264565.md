## Problem

One-shot prediction with foundation models naturally yields a pool of reference-conditioned predictors whose relevance varies across test inputs, but standard split conformal calibration is statistically inefficient in this low-data regime (requiring disjoint reference/calibration splits) and cannot handle adaptive aggregation without violating exchangeability. The paper asks whether one can aggregate all one-shot predictors instance-adaptively, reuse every labeled example for both reference and calibration, and still obtain valid finite-sample marginal coverage guarantees.

## Input / Output

The method takes n labeled examples (each inducing a one-shot predictor via a fixed prediction mechanism π), a new test input, a target miscoverage level α, and a small aggregation constant k (fixed at 3). For the vision task, images are divided into K=168 patches of 16×16 pixels and embedded by a frozen DINOv3 ViT-B/16; for text, a fixed LLM prompt template produces length-normalized NLL scores per candidate label. The output is a single conformal prediction set Ĉ(X_{n+1}) ⊆ Y with guaranteed marginal coverage ≥ 1−α, where smaller sets indicate lower predictive uncertainty. Notably, all n labeled examples simultaneously serve as the reference pool and the calibration set via a leave-one-out construction, eliminating the need for disjoint splits.

## Method

CAOS defines an aggregated nonconformity score s_caos((x,y); D) = Σ_min^k(A_D(x,y)), the sum of the k smallest one-shot scores across all reference examples, which focuses on the most informative predictors for each candidate label. Calibration uses a leave-one-out scheme: for each labeled example (X_i, Y_i), the aggregated score is computed with (X_i, Y_i) excluded from the reference pool, and the empirical (1−α)(1+1/n)-quantile of these n scores yields the threshold. The key theoretical contribution is a monotonicity-based proof that, despite the CAOS scores being non-exchangeable (the test point is excluded from its own reference pool), the prediction set contains the corresponding full conformal prediction set, inheriting its finite-sample coverage guarantee. The full conformal variant—requiring a separate threshold per candidate label and thus computationally prohibitive—serves solely as an analytical bridge, with the monotonicity of Σ_min^k under set inclusion being the critical structural property enabling the reduction.

## Results

On exemplar-based facial landmarking (CelebA, 478 tasks), CAOS achieves an average prediction set size of 16.14 at α=0.05 with 95.5% empirical coverage, compared to 36.07 for SCOS (97.6% coverage) and 20.49 for SCOS Best (95.2% coverage, no validity guarantee). CAOS approaches the non-deployable SCOS Oracle (16.66, 100% coverage). On RAFT one-shot text classification at α=0.1, CAOS reduces average set size from 1.82–1.93 (SCOS) to 1.64–1.80 across four LLMs (Llama-3.2-3B, Qwen3-4B, Llama-2-7B, Qwen3-32B) while maintaining valid coverage at or above the 90% target.

## Baselines & Comparisons

The primary baseline is SCOS (Split Conformal One-Shot Predictor), which calibrates each one-shot predictor independently on a disjoint calibration split. CAOS substantially outperforms SCOS on prediction set size: 16.14 vs. 36.07 at α=0.05 (a 55% reduction) on facial landmarking, while maintaining valid marginal coverage (95.5% vs. 97.6%). On RAFT text classification, CAOS consistently produces smaller sets than SCOS across all four LLMs (e.g., 1.70 vs. 1.93 on Llama-2-7B) at comparable coverage. A second baseline, SCOS Best, selects the best single predictor using calibration data, reducing set size to 20.49 but losing its coverage guarantee; CAOS beats it on both size (16.14) and validity. The non-deployable SCOS Oracle (which uses the true test label to pick the smallest valid set) achieves 16.66, showing CAOS is within 3% of the oracle's efficiency while remaining fully deployable. An ablation (Table 3) confirms that the gains come primarily from reusing labeled data for both calibration and reference, not from aggregation alone.

## Relation to Prior Work

CAOS extends the conformal prediction framework (Shafer & Vovk, 2008; Angelopoulos et al., 2024) to the one-shot setting where each labeled example induces its own predictor, and the challenge is to aggregate across this pool while calibrating with the same scarce data. It departs from split conformal, which requires disjoint reference and calibration splits and is statistically inefficient in low-data regimes, and from cross-conformal or data-reuse schemes (Vovk, 2015; Barber et al., 2021) that typically introduce slack or require additional exchangeability arguments. The key conceptual departure is a monotonicity-based reduction to full conformal prediction, which sidesteps the need for score-level exchangeability entirely by showing that the Σ_min^k aggregation operator is monotone in the reference set, guaranteeing set inclusion between CAOS and a theoretical full-conformal variant.

## Why It Matters / Open Questions

The paper provides a clean theoretical template showing that algorithmic non-exchangeability (from adaptive aggregation and leave-one-out calibration) need not invalidate conformal coverage, provided the score function satisfies symmetry and monotonicity—properties that are easy to verify for many natural score constructions. Practically, CAOS more than halves prediction set sizes relative to split conformal in both vision and language one-shot tasks while maintaining valid coverage, which is meaningful in clinical and scientific settings where even a few labeled examples must be fully exploited. Limitations include the restriction to score functions satisfying the monotonicity condition (excluding fine-tuning or hyperparameter selection), only marginal (not conditional) coverage, and an O(n²) computational cost relative to O(n) for split conformal. Open questions include whether the monotonicity framework extends to other aggregation operators (e.g., geometric means, trimmed means), whether conditional or adaptive coverage can be achieved, and whether the approach remains effective as the number of reference examples grows beyond the very small n considered here.

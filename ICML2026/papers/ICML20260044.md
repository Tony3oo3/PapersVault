## Problem

Time-series forecasting has been evaluated exclusively on numerical accuracy metrics (MASE, RMSE), treating foundation models as opaque black boxes that produce predictions without explainable causal logic. No standardized benchmark exists for assessing the reasoning quality behind a forecast—specifically, whether a model correctly identifies cross-channel dependencies, attributes value shifts to external events, and maintains logical consistency between its narrative explanation and numerical output. TFRBench fills this gap by providing verifiable reference reasoning traces and a dual evaluation protocol that scores both reasoning quality and numerical accuracy.

## Input / Output

The system consumes a historical multivariate time series window (varying by domain: 96 timesteps for Energy/Sales/Web/Transportation, 14 for Finance) along with externally retrieved events (holidays, weather, earnings) and a dataset description. It produces a structured, per-channel reasoning trace decomposing the signal into Cross-Channel Analysis, Trend Component Plan, Seasonality Component Plan, and Residuals & Event Plan, followed by a deterministic numerical forecast. Evaluation yields four LLM-as-a-Judge sub-scores (Domain Relevance, Forecasting Correctness, Event Relevance, Logic-to-Number Consistency, each 1–5) and a MASE score against a seasonal-naive baseline, with the reference set gated by MASE < 1.0 and verifier score ≥ 4.

## Method

TFRBench synthesizes reference reasoning traces via a five-agent iterative pipeline (Search, Reasoning, Verifier, Forecasting, Summary) operating in a generate-verify-refine loop of up to K=3 iterations. The Search agent retrieves domain-relevant external events and cross-verifies the Reasoning agent's hypotheses against web-grounded sources to prevent hallucination; the Reasoning agent then generates n parallel candidate traces; the Forecasting agent maps each trace to a numerical forecast using deterministic greedy decoding (Temperature=0) without access to ground truth; and the Verifier assigns a consistency score S∈{1,…,5} while diagnosing failure modes to produce actionable feedback for the next iteration. The key architectural insight is a two-stage estimation—first generating R ~ P(R|X_hist, E), then deriving Y ~ P(Y|R, X_hist)—which decouples causal reasoning from numerical prediction and makes the reasoning itself a first-class, evaluable artifact. For evaluation, an LLM-as-a-Judge (Gemini-3-Pro) audits candidate reasoning against the reference traces across four dimensions, validated by 0.842 Spearman correlation with an independent judge (Claude-4.5) and 70.4% Pearson correlation with human experts.

## Results

TFRBench evaluates reasoning quality via LLM-as-a-Judge (1–5 scale across Domain Relevance, Forecasting Correctness, Event Relevance, and Logic-to-Number Consistency) and numerical accuracy via MASE. Prompting LLMs with the benchmark's verified reasoning traces raises the overall success rate (MASE < 1.0) from ~40.2% to ~56.6%. In pattern-rich domains, CoT reasoning reduces MASE substantially (e.g., Gemini-3-Pro on Solar: 1.037 → 0.834; Car Parts: 0.821 → 0.672), while in stochastic Finance domains it introduces 'narrative bias' that degrades performance (Amazon: 0.715 → 1.114). Reasoning quality (Judge score) is strongly correlated with forecasting accuracy (lower MASE), confirming the benchmark's predictive utility.

## Baselines & Comparisons

TimesFM-2.5 (Das et al., ICML 2024) sets the strongest numerical baseline, achieving MASE 0.732 on Solar, but operates as an opaque black box with no reasoning output. Chronos-2.0 (Ansari et al., 2025) is included as a second TSFM baseline for numerical comparison across domains. ARIMA (Nelson, 1998) serves as a classical statistical reference. The key finding is that zero-shot LLMs without reasoning trail TSFMs (e.g., Gemini-3-Pro MASE 1.037 vs. TimesFM-2.5 0.732 on Solar), but explicit CoT reasoning narrows the gap to 0.834, and adding event forecasting further improves it (Gemini-2.5-Flash: 1.168 → 0.896). However, in stochastic Finance domains, reasoning backfires due to narrative bias (Amazon MASE worsens from 0.715 to 1.114), and event forecasting can be harmful in Web/CloudOps (Claude-Sonnet-4.5 on Bitbrains: 0.938 → 5.469). Overall, reasoning-enhanced LLMs deliver competitive accuracy with interpretability, whereas TSFMs remain numerically superior in pattern-rich settings but offer no causal explanation.

## Relation to Prior Work

This paper departs from the long tradition of purely numerical forecasting benchmarks (M4, Monash, GIFT-Eval) that treat models as black boxes, and from multimodal benchmarks (MTBench, InvestorBench) that add textual context but evaluate QA or trading decisions rather than the reasoning process behind a forecast. It also extends the line of CoT-enhanced forecasting (PromptCast, chain-of-thought prompting) by providing the first systematic evaluation protocol for reasoning quality, using a multi-agent generate-verify-refine pipeline to synthesize reference reasoning traces grounded in external events. The LLM-as-a-Judge evaluation framework draws on recent work in automated evaluation but is specifically calibrated to four forecasting-relevant dimensions (domain relevance, forecasting correctness, event relevance, logic-to-number consistency) rather than generic text quality.

## Why It Matters / Open Questions

TFRBench fills a genuine gap: no prior benchmark evaluates whether a forecasting model's reasoning is causally grounded, and the paper demonstrates that this matters—reasoning quality strongly correlates with MASE, and off-the-shelf LLMs exhibit 'narrative bias' where fluent but logically inconsistent reasoning degrades performance in stochastic domains. Key limitations include the use of oracle future-event knowledge during reference trace creation (mitigated by an ablation showing it barely helps baselines), a limited human validation panel (3 experts, 20 samples), and coverage of only 10 datasets across 5 domains. Open questions include whether the reasoning-evaluation paradigm generalizes to healthcare and environmental forecasting, whether larger-scale human studies would shift the LLM-as-a-Judge scores, and whether the multi-agent reference generation pipeline can be made more cost-efficient as models improve.

## Problem

Existing Merge-then-Compress (MtC) pipelines for consolidating multiple LoRA adapters into one first merge in the full parameter space and then compress the result to a target rank r via truncated SVD. This treats the rank constraint as an afterthought: the merge is unconstrained, but the subsequent SVD truncation systematically favors large-norm task updates and can discard task-relevant directions from smaller adapters, leading to uneven and brittle per-task degradation. The paper asks whether enforcing the rank-r bottleneck *before* merging—by learning shared subspaces first—can produce a more balanced and effective single-LoRA output.

## Input / Output

The method consumes T homogeneous LoRA adapters (same base model, same injected modules, same input rank r_in) as pairs of factor matrices (A^(t), B^(t)), along with a target output rank r and a reweighting coefficient β ∈ [0,1]. The output is a single rank-r LoRA update ΔW_LoRA = U O_merged V^T that is guaranteed low-rank by construction, requiring no post-hoc SVD truncation. All heavy computation (subspace learning via Tucker decomposition) is performed in a lossless core space of dimension (T·r_in)×(T·r_in) rather than the full n×m parameter space, yielding speedups of roughly n²/(T·r)² over the full-space formulation.

## Method

CtM reverses the MtC order by first learning shared r-dimensional left/right subspaces (U, V) via a joint reconstruction objective over Frobenius-norm-rescaled LoRA updates, where the rescaling weight λ^(t) = β‖ΔW^(t)‖_F + (1−β)‖ΔW‖_{F,Avg} prevents large-norm adapters from dominating the learned subspace. The optimization is cast as a Tucker-2 decomposition of a third-order tensor stacking all rescaled updates, solved by HOSVD initialization followed by HOOI refinement. Each adapter is then projected into the shared subspace to yield a compact r×r coordinate matrix O^(t) = U^T ΔW^(t) V, a standard merging rule (e.g., TIES, DARE-TIES) is applied directly in this low-dimensional space, and the merged coordinates are lifted back via ΔW_LoRA = U O_merged V^T. A core-space acceleration theorem guarantees that the subspace learning can be restricted to the (T·r_in)-dimensional span of concatenated LoRA factors without loss of optimality, reducing the dominant computational cost from O(n³T) to O(T⁴r³).

## Results

On 8 vision tasks (CLIP ViT-B/32), CtM with DARE-TIES achieves 70.68 average normalized accuracy, outperforming the best MtC baseline (DARE-TIES in CoreSpace, 65.91) by 4.77 points and the best low-rank-aware method (Iso-CTS, 66.34) by 4.34 points, while narrowing the gap to the full-parameter upper bound (Iso-C Full, Avg_full = 75.91) to 5.23 points. On 6 NLI tasks (LLaMA3-8B), CtM with DARE-TIES reaches 95.63, exceeding the best MtC baseline (TIES in CoreSpace, 93.10) by 2.53 points and surpassing all full-parameter Avg_full values. The truncation gap (Avg_full → Avg) for MtC methods is substantial: e.g., Iso-C in CoreSpace drops from 75.87 to 65.71 on vision, confirming that post-hoc SVD compression is a major source of degradation.

## Baselines & Comparisons

CtM consistently outperforms all five compared baselines across both vision and NLI settings. Against the MtC baselines (TIES, DARE-TIES, Iso-C in Full/KnOTS/CoreSpace), CtM gains 3.4–4.8 points on vision (e.g., 70.68 vs. 65.91 for DARE-TIES CoreSpace) and 2.5–2.8 points on NLI (95.63 vs. 93.10 for TIES CoreSpace). Against the low-rank-aware baselines that directly output a rank-r LoRA without post-hoc SVD, CtM still leads: over LoRA-LEGO (62.36) by 8.3 points, over RobustMerge (64.31) by 6.4 points, and over Iso-CTS (66.34) by 4.3 points on vision; on NLI, CtM (95.63) exceeds Iso-CTS (88.21) by 7.4 points. The largest relative gains appear with TIES-based merging rules, which the authors attribute to lower coordinate dispersion in the compact r×r space making sign-conflict resolution more effective. Notably, CtM with DARE-TIES on NLI (95.63) surpasses the pre-truncation Avg_full of all MtC baselines (≤93.50), suggesting the learned shared subspace filters task-specific noise that would otherwise be amplified by full-space merging.

## Relation to Prior Work

This paper departs from the dominant Merge-then-Compress (MtC) pipeline (Tang et al., 2025; Goddard et al., 2024), which merges LoRAs in full parameter space and then applies truncated SVD to enforce the rank constraint. CtM reverses this order by first learning shared r-dimensional subspaces via a Tucker decomposition objective over rescaled LoRA updates, then performing the merge directly in the resulting r×r coordinate space. It builds on the core-space framework (Panariello et al., 2025) for lossless projection and acceleration, and on alignment-based methods (KnOTS, CoreSpace) for coordinate mapping, but repurposes these as computational tools rather than as the final merging space. The rescaling mechanism (β-weighted normalization) is a novel addition to prevent magnitude dominance during subspace learning.

## Why It Matters / Open Questions

CtM provides a principled, training-free solution to a growing practical problem: consolidating many task-specific LoRA adapters into a single deployable adapter without sacrificing the low-rank structure that makes LoRA efficient. The consistent improvements over MtC baselines across vision and language tasks, combined with the 33× speedup from core-space acceleration, make this a practically relevant tool for the LoRA ecosystem. Key limitations include dependence on shared cross-task structure (highly orthogonal tasks will still suffer under any fixed-rank constraint), the need for hyperparameter tuning (target rank, β, base merge rule), and the open question of whether merge rules can be redesigned specifically for the compact r×r coordinate space where task conflicts are more concentrated.

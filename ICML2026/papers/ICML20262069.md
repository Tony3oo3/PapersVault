## Problem

Existing vision SSMs rely on hand-crafted fixed scanning orders (e.g., sweeping, continuous, local) to flatten 2D feature maps into 1D sequences, which imposes rigid geometric constraints and makes spatial modeling sensitive to the chosen scan direction. Additionally, the inherently causal and self-referential nature of SSMs prevents them from supporting query-to-source cross-attention between distinct feature streams, a mechanism essential for multi-view 3D perception tasks like BEV detection.
![Teaser figure](../imgs/ICML20262069/cropped_page0_idx0.webp)

## Input / Output

For 2D tasks, the model consumes a single RGB image (224×224 for classification, 1280×800 for detection, 512×2048 crops for segmentation) and outputs class labels, bounding boxes with masks, or per-pixel semantic maps. For 3D BEV detection, the input is a set of multi-view camera images plus sensor calibration and GPS data; the model lifts 2D BEV grid locations into 3D pillars, projects them onto each camera view, and outputs 3D bounding boxes with attributes. The cross-attention variant takes a set of source image feature maps F and a set of external queries B, selecting spatial evidence from F to update B.

## Method

Deformba introduces Context-Adaptive State Fusion (CASF), which decouples the SSM write pass from the read pass. A single unidirectional scan encodes the 2D feature map into a shared hidden state memory S_2D; a lightweight offset prediction network (depthwise conv + Efficient Channel Attention) then generates G groups of 2D offsets per token, and bilinear interpolation samples spatially relevant evidence from S_2D to form the final state S_Q. This replaces multi-direction fixed scans with data-driven adaptive reading while preserving O(L) complexity. For cross-attention, the write pass is unchanged but external queries (e.g., BEV grid queries) predict their own offsets to sample from the same shared state map, enabling query-to-source fusion without quadratic-cost attention. The full architecture is a four-stage hierarchical backbone of Deformba blocks (CASF + ConvFFN with residual connections), evaluated across ImageNet-1K, COCO, ADE20K, and nuScenes.

## Results

On ImageNet-1K (300 epochs), Deformba achieves 83.8%, 84.9%, and 85.4% top-1 accuracy for Tiny, Small, and Base variants respectively, outperforming all SSM-based competitors (VMamba, MSVMamba, DefMamba) and strong CNN/ViT baselines at comparable parameter and FLOP budgets. On MS COCO (3× multi-scale schedule), Deformba-B reaches 51.8 APb and 45.6 APm, surpassing ConvNeXt-B by 3.3% in box mAP. On ADE20K, Deformba-B attains 52.0 mIoU (single-scale) and 52.6 mIoU (multi-scale). On nuScenes 3D detection, Deformba-S (ResNet-101, 4 frames) achieves 0.538 NDS and 0.445 mAP, outperforming BEVFormerV1-S by 0.059 NDS.

## Baselines & Comparisons

Deformba consistently outperforms all SSM-based baselines across every task and model size. On ImageNet-1K, Deformba-B (85.4%) beats VMamba-B (83.9%) by 1.5%, MSVMamba-B (84.4%) by 1.0%, and DefMamba-B (84.2%) by 1.2%; Deformba-T (83.8%) surpasses VMamba-T (82.6%) by 1.2% with fewer parameters (25M vs. 22M) and lower FLOPs (4.8G vs. 5.6G). On MS COCO (3× schedule), Deformba-B achieves 51.8 APb, exceeding ConvNeXt-B (48.5%), PVTv2-B5 (48.4%), and Swin-B (48.6%) by 3.3%, 3.4%, and 3.2% respectively, while also outperforming Spatial-Mamba-B (50.4%) and VSSD-B (49.9%). On ADE20K, Deformba-B (52.0 mIoU SS) leads VMamba-B (51.0) by 1.0 and MambaOut-B (49.6) by 2.4. On nuScenes, Deformba-T (ResNet-50, 3 frames) achieves 0.405 NDS, beating BEVFormerV1-T (0.354) by 0.051 and BEVFormerV2-T (0.397) by 0.008; Deformba-S (ResNet-101, 4 frames) reaches 0.538 NDS, surpassing MamBEV-S (0.525) by 0.013 and BEVFormerV1-B (0.517) by 0.021. In the cross-attention scaling comparison (Table 5), Deformba uses fewer parameters (176K) and substantially fewer FLOPs than standard dot-product attention (263K params, 1432.5 GFLOPs at 200×200 BEV) while matching or exceeding deformable attention efficiency.

## Relation to Prior Work

Deformba builds directly on the Mamba/Mamba2 selective state space model for its core recurrence and on the deformable sampling pattern (learned 2D offsets + bilinear interpolation) popularized by Deformable DETR and BEVFormer. It departs from prior vision SSMs (Vim, VMamba, LocalMamba, DefMamba) that rely on multi-direction fixed scanning to flatten 2D features into 1D sequences; instead, Deformba keeps a single fixed scan for the write pass and introduces adaptivity only at the read stage via Context-Adaptive State Fusion (CASF). The cross-attention extension is a clear departure from all prior SSM-based vision models, which operate exclusively on a single feature stream and lack any SSM-native counterpart to cross-attention.

## Why It Matters / Open Questions

The write-once, adaptive-read-many formulation provides a principled SSM-native mechanism for query-to-source fusion, which is essential for multi-view 3D perception and multi-scale detection but was previously only available through quadratic-cost cross-attention. The ablation showing that scan direction becomes irrelevant once CASF is introduced (Table 9) suggests the field may be over-investing in multi-scan strategies. Limitations noted by the authors include continued reliance on convolutional locality priors and the fact that gains come from the combination of compact state memory, adaptive readout, and local inductive bias rather than CASF alone. Open questions include whether the state-size-1 assumption generalizes to higher-information-density settings and whether the framework extends naturally to video or other sequential modalities.

## Problem

Modern state space models (Mamba, S4D) achieve strong performance on long-range sequence tasks, but their memory mechanisms—how history is represented, prioritized, and transformed—are encoded implicitly in learned state dynamics that are difficult to interpret or analyze. The HiPPO framework provides explicit, interpretable polynomial representations of history but lacks capabilities central to modern SSMs such as adaptive memory allocation, associative recall, nonlinear interactions, and multiscale representation. This paper asks whether these capabilities can be realized as explicit, interpretable modifications within the HiPPO framework rather than as opaque learned transitions.

## Input / Output

Each variant consumes a 1D continuous-time signal or discrete token sequence and maintains a fixed-dimensional HiPPO state updated online via structured linear ODEs (discretized with zero-order hold). The state vector is itself the interpretable output: each coefficient is a well-defined linear functional of the past in an orthogonal polynomial basis. Downstream outputs vary by variant—scalar predictions (Volterra), token sequences (Salience, Associative Memory), signal reconstructions at arbitrary horizons (Multiscale), and horizon-dependent predictive memory coefficients (Forecasting)—but all are decoded from the same explicit polynomial state, enabling direct visualization of what is stored and how it is weighted.

## Method

The paper introduces five extensions to the HiPPO framework, each exposing a specific SSM capability through an explicit modification of the history measure, readout geometry, or objective-induced metric. Volterra HiPPO parameterizes nonlinear kernels as coefficient tensors in the OP basis, separating linear and quadratic contributions of the past. Salience HiPPO introduces a scalar, input-dependent time warp g(t) that multiplicatively scales the HiPPO dynamics, equivalently deforming the history measure so informative inputs receive expanded representation. Associative Memory HiPPO adds a separate OP-based memory bank where continuous addresses are evaluated via the reproducing kernel, enabling explicit key-value binding with minimum-norm writes. Multiscale HiPPO represents the HiPPO state as a function of log-timescale u = log g using an OP expansion, yielding a single linear system queryable across a continuum of horizons. Forecasting HiPPO uses reduced-rank regression between HiPPO states at different horizons to construct horizon-dependent predictive memories and an induced history-space metric Q = TᵀT that makes explicit which portions of the past each forecasting objective retains. All variants retain structured linear dynamics with efficient online updates and are trained via online gradient descent or truncated backpropagation through time.

## Results

On the synthetic selective copying task, Salience HiPPO achieves 100.0% test accuracy, outperforming all parameter-matched baselines (S4D: 81.0%, LSTM: 60.8%, Transformer: 22.1%). On the associative recall task, Associative Memory HiPPO achieves 100.0% test accuracy while all baselines remain near chance (~33%). On WikiText-2 character-level language modeling, HiPPO variants underperform modern SSMs: Vanilla HiPPO+MLP achieves 6.80 PPL versus 5.54 for Mamba (single-layer) and 4.65 for two-layer Mamba.

## Baselines & Comparisons

On the selective copying task, Salience HiPPO (100.0%) decisively outperforms S4D (81.0%), LSTM (60.8%), and Transformer (22.1%) at matched parameter counts, and even beats the two-layer S4D (96.9%) that uses nearly twice the parameters. On associative recall, Associative Memory HiPPO (100.0%) achieves perfect accuracy while S4D, LSTM, and Transformer all remain near the 33% chance level regardless of depth or scaling (up to 10× capacity, 10× data, 2× steps). On WikiText-2 language modeling, all HiPPO Zoo variants lose to modern SSMs: Vanilla HiPPO+MLP (6.80 PPL) trails Mamba (5.54 PPL) by 23%, and Associative Memory HiPPO fails catastrophically at 20.41 PPL, indicating its continuous addressing is fundamentally mismatched to autoregressive character prediction. The paper positions these results as demonstrating that task-aligned explicit mechanisms excel on targeted synthetic benchmarks but do not yet match the general-purpose performance of learned SSMs on open-ended language tasks.

## Relation to Prior Work

This paper extends the HiPPO framework (Gu et al., 2020; Voelker et al., 2019), which represents signal history as projections onto orthogonal polynomial bases maintained by structured linear ODEs, by introducing five explicit modifications that realize capabilities currently encoded implicitly in modern selective SSMs like Mamba and S4D. Rather than proposing a new SSM architecture to compete with these models, the paper reframes their learned mechanisms—input-dependent memory allocation, associative recall, multiscale dynamics, nonlinear interactions, and objective-induced memory geometry—as transparent, analyzable modifications to the HiPPO history measure, readout, or state representation. The key conceptual departure is from the 'learned state transition' paradigm: instead of opaque parameterized updates, each mechanism is expressed as a closed-form deformation of the polynomial basis or its weighting, enabling direct visualization of how memory is allocated and queried.

## Why It Matters / Open Questions

The paper demonstrates that capabilities typically attributed to the expressive power of deep, selective SSMs can be realized through simple, explicit polynomial structures, offering a principled path toward interpretable sequence models for scientific and streaming applications where mechanistic transparency is valued. However, the empirical evidence is confined to synthetic tasks; on WikiText-2 language modeling, all HiPPO Zoo variants underperform Mamba and S4D by 20–36% in perplexity, and the Associative Memory variant fails catastrophically (20.41 PPL), suggesting that continuous addressing is fundamentally mismatched to autoregressive prediction. Open questions include whether these explicit mechanisms can be embedded as interpretable submodules within larger expressive architectures, whether the scalar salience signal can be generalized to capture the full vector-valued adaptivity of Mamba's Δt, and whether the interpretability advantages survive at scale on real-world long-context tasks.

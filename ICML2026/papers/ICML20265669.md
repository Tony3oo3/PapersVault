## Problem

Existing memory agents must traverse long-horizon sequences of hundreds of memory operations across ~500 turns before receiving a single sparse terminal reward, making temporal credit assignment and end-to-end policy optimization intractable. Prior RL-based approaches indiscriminately propagate this sparse reward across all operations without process-level attribution, preventing effective joint optimization of memory construction and retrieval.
![Teaser figure](../imgs/ICML20265669/cropped_page0_idx0.webp)

## Input / Output

The agent consumes a continuous stream of dialogue chunks x_t, where each chunk triggers proactive memory formation (extracting facts, experiences, raw data) and evolution (ADD/UPDATE/DELETE/IGNORE against the existing store). When a query q arrives, the agent performs multi-turn retrieval (up to 6 steps) over the hierarchical store—searching factual, experiential, working, and raw memory modules—before producing a final text answer. The memory store is structured as time-bounded atomic units (f_i, t_start, t_end) organized into four tiers, with all retrieval operations returning top-5 most similar items via BGE-M3 embeddings.

## Method

Mem-T introduces MoT-GRPO, a dual-track training paradigm that densifies sparse rewards for both retrieval and construction. For retrieval, it constructs Memory Operation Trees via iterative branching rollout (G=3 trees, M expansion rounds, N_v=3 pivot nodes per round), assigns dense node-wise rewards combining format validity, evidence hit rate, and backpropagated leaf performance, and computes dual-scale advantages (intra-tree for local credit assignment, inter-tree for global competition) to optimize the retrieval policy via PPO-clipped GRPO. For construction, it employs Hindsight Credit Assignment that backpropagates terminal leaf advantages to upstream formation/evolution actions through two gates: an Evidence Alignment Gate linking construction quality to ground-truth evidence turns, and a Retrieval Trace Gate rewarding memory entries actually retrieved in successful trajectories. The construction policy is then refined offline by selecting the top-50% percentile of actions by hindsight score and training via maximum log-likelihood, effectively distilling downstream search-tree wisdom into forward-looking memory management.

## Results

On the LoCoMo benchmark (Qwen3-4B), Mem-T with MoT-GRPO achieves an Overall F1 of 58.65 and BLEU-1 of 52.63, surpassing the strongest training-free baseline GAM (53.48 F1 with gpt-4o-mini) by 5.17 and the strongest trained baseline Memory-R1-GRPO (39.25 F1) by 19.40. On three out-of-domain benchmarks (HotpotQA, LongMemEval, NarrativeQA), Mem-T achieves an average score of 54.15, outperforming the best baseline GAM (47.70) by 6.45. Mem-T also reduces inference tokens per query by ~24.45% relative to GAM while maintaining superior accuracy, placing it on a favorable accuracy-efficiency Pareto frontier.

## Baselines & Comparisons

Mem-T with MoT-GRPO (58.65 F1) outperforms all 13 baselines on LoCoMo. Among training-free methods, it surpasses GAM (53.48 F1 with gpt-4o-mini, 30.17 with Qwen3-4B) by 5.17 and 28.48 respectively, and beats Mem0 (43.71), A-Mem (39.43), LightMem (40.01), MemoryOS (42.83), RAG (41.59), MemoryBank (22.34), and MemGPT (14.05) by margins of 14.94, 19.22, 18.64, 15.82, 17.06, 36.31, and 44.60 F1. Among trained methods, Mem-T exceeds Memory-R1-GRPO (39.25) by 19.40 F1, MemAgent (33.82) by 24.83, and MEM1 (25.68) by 32.97. On out-of-domain benchmarks, Mem-T (avg 54.15) beats GAM (47.70), Mem-α (46.45), LightMem (39.50), A-Mem (38.98), and MEM1 (29.28). Against Tree-GRPO restricted to retrieval tuning (54.20 F1), Mem-T's retrieval-only variant achieves 55.36 and the full framework reaches 58.65, confirming the added value of the construction optimization stage.

## Relation to Prior Work

This paper builds directly on the GRPO paradigm (Shao et al., 2024) and Tree-GRPO (Ji et al., 2025), but departs from both in a key architectural decision: rather than applying online tree search uniformly across all memory operations (as Tree-GRPO does), it decouples short-horizon retrieval (optimized via online Memory Operation Trees) from long-horizon construction (optimized via offline hindsight credit assignment). This addresses the computational infeasibility of full online tree search over hundreds of construction steps. Conceptually, it also moves beyond prior RL-based memory agents (Memory-R1, Mem-α) that broadcast a single sparse terminal reward across all operations, instead introducing dense node-level rewards and a dual-scale (intra-tree + inter-tree) advantage estimator for retrieval, plus an evidence-aligned credit coefficient for construction.

## Why It Matters / Open Questions

The paper tackles a fundamental bottleneck in training memory agents—temporal credit assignment over extremely long horizons—and offers a practical, theoretically grounded solution (provable lower gradient variance, SNR analysis decoupled from sequence length). However, several limitations temper its impact: the framework relies on gold evidence labels for the Evidence Alignment Gate, evaluations use relatively small backbones (4B/8B), and memory formation overhead on long contexts remains high. Open questions include whether the approach scales to larger models and more complex multi-agent environments, and whether the gold-evidence dependency can be replaced by self-supervised annotation as the authors themselves note.

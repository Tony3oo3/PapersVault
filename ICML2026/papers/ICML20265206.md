## Problem

The quadratic cost of attention limits long-context LLM scalability, especially under tight hardware memory budgets. Static sparse patterns (sliding window, A-shape) cannot adapt to input-dependent attention variations, while existing dynamic methods (MInference, Block-Sparse) rely on predefined templates or heuristics that sacrifice generality. The paper asks whether attention sparsity can be predicted in a fully data-driven, input-adaptive manner while keeping the LLM backbone frozen.
![Teaser figure](../imgs/ICML20265206/cropped_page0_idx0.webp)

## Input / Output

DHSA consumes per-layer query and key vectors from a frozen decoder-only Transformer (e.g., LLaMA-3.1-8B at 4-bit, Qwen2.5-3B, Gemma-2-2B) and produces, for each query chunk, a compact ordered set of key token indices bounded by a per-query budget N_b. The boundary predictor operates on local key-vector windows of w=4 tokens on each side of every position, and the entire routing pipeline adds only a linear-time pass in sequence length. The routed index sets are consumed by either a PyTorch SDPA backend (GPU/CPU) or a tiled online-softmax backend (GPU), which compute exact causal attention only over the selected keys, reducing per-layer cost from O(L²) to O(L·N_b).

## Method

DHSA is a drop-in sparse attention module that performs hierarchical routing in two steps. First, a lightweight boundary predictor (~20 MB, shared across layers) uses a self-attention encoder over local left/right key windows, a feature-fusion layer (concatenation, absolute difference, element-wise product, cosine similarity), and a two-layer MLP to predict chunk boundaries via thresholding and non-maximum suppression; it is trained with soft labels automatically derived from dense attention mass ratios between adjacent windows, using focal BCE loss to handle class imbalance. Second, each chunk is encoded with a length-normalized pooling scheme (dividing the sum by chunk length and scaling by √L_k) to produce stable chunk queries/keys, from which a chunk-level similarity matrix is computed. Each query chunk is then routed to its top-scoring key chunks, which are expanded into token indices until the per-query budget N_b is filled, preserving causal constraints. This hierarchical design avoids constructing dense L×L token-pair matrices and, as the paper's theoretical analysis shows, achieves near-oracle attention recall under the same sparsity budget where fixed block-sparse patterns are bounded by O(m/B) recall when semantic segments are shorter than fixed blocks.

## Results

On LongBench at 12.5% token density, DHSA achieves 31.8 average on LLaMA-3.1-8B (4-bit), closely matching the dense baseline (32.7) while outperforming all sparse baselines. On RULER at 48K context, DHSA scores 71.5 versus 43.1 for Block Sparse and 64.2 for MInference (dense: 75.2). In Needle-in-a-Haystack at 6.25% density, DHSA maintains near-perfect retrieval up to 100K tokens on a single 24 GB GPU, where dense attention fails. At the kernel level, DHSA delivers up to 10× prefill speedup over FlashAttention-2 at 128K context length.

## Baselines & Comparisons

DHSA outperforms all eight sparse baselines on LongBench across all three model families. Against the closest prefill-oriented competitors, DHSA beats SeerAttention (31.8 vs. 30.8) and Quest (31.8 vs. 30.9) on LLaMA-3.1-8B, and achieves 12–20% relative gains over Block Sparse Attention (31.8 vs. 27.9) at matched prefill cost. The gap widens substantially on smaller models: on Qwen2.5-3B, DHSA scores 25.3 versus 20.6 for Block Sparse and 21.1 for MInference; on Gemma-2-2B, DHSA reaches 30.3 versus 21.6 for Block Sparse and 26.3 for MInference. On RULER at 48K context, DHSA (71.5) substantially outperforms Block Sparse (43.1) and MInference (64.2), while remaining within 3.7 points of dense attention (75.2). Static-pattern baselines (StreamingLLM and its dilated/strided variants) and decoding-oriented methods (DuoAttention, Quest) trail DHSA by 5–9 points on average, confirming that input-adaptive, content-driven sparsity is critical for long-context accuracy.

## Relation to Prior Work

DHSA carves out a middle ground between static sparse attention (Longformer, BigBird, Sparse Transformer) and template-based dynamic methods (MInference's Vertical-Slash, Block-Sparse Attention's fixed-size blocks). It departs from both by learning content-adaptive chunk boundaries online via a lightweight boundary predictor (borrowing NMS from object detection) and using hierarchical chunk-to-token routing, rather than relying on predefined sparsity patterns or heuristics. The approach is positioned as a drop-in module that keeps the LLM backbone frozen, distinguishing it from methods requiring retraining (state-space models, linear attention) or architecture-specific modifications (DuoAttention's learned head masks).

## Why It Matters / Open Questions

DHSA addresses a practical bottleneck—running 100K+ context on consumer-grade 24GB GPUs—by combining a 20MB learned boundary predictor with hierarchical sparse routing, achieving near-dense accuracy at 6.25–12.5% token density. Key limitations include prefill-only optimization (decoding is deferred), per-backbone-family training of the boundary predictor, and evaluation primarily on 2B–8B models, leaving open whether the approach scales to 70B+ models or benefits from larger training corpora. The theoretical analysis (block-sparse recall bounded by m/2B vs. DHSA's 1−2δ/m) provides a clean justification for dynamic chunking but relies on strong intra-segment homogeneity assumptions that may not hold uniformly across all layers or tasks.

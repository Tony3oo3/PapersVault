## Problem

Genetic circuit design remains a laborious, expert-driven process, and existing automated tools like Cello are limited to constrained gate assignment on pre-synthesized topologies. When language models are trained with binary pass/fail rewards on circuit generation, distinct failure modes (syntax errors, invalid SBOL, wrong topology, wrong function) collapse into a single signal, severely weakening learning on reasoning-intensive tasks like functional prediction and de novo design.

## Input / Output

The model receives a natural language task specification (e.g., 'build a NOT gate using TetR/pTet' or 'repair this broken pysbol3 script') and generates Python code that uses the pysbol3 library to construct an SBOL document at the Component abstraction level. The generated code is executed to produce an SBOL document, which is then verified structurally and topologically (not dynamically) against ground truth. Operating at the Component level rather than base pairs or raw RDF/XML serialization offloads syntactic correctness to the library and keeps the action space aligned with how synthetic biologists reason about circuit logic.

## Method

GenCircuit-RL is a two-phase training framework: supervised fine-tuning on (prompt, canonical pysbol3 code) pairs establishes API competence, followed by GRPO-based reinforcement learning from verifiable feedback (RLVF). The key innovation is a five-level hierarchical verification reward (execution → validity → structure → semantics → function) with multiplicative dependencies, so a circuit failing at structure still receives credit for passing execution and validity, providing non-zero gradient signal at every level. A four-stage curriculum shifts reward weights from execution-heavy (Stage 1) to function-heavy (Stage 4), with promotion gated by validation task success rate, ensuring prerequisite capabilities are mastered before dependent skills are optimized. GRPO is used instead of PPO to avoid retraining a value function at curriculum transitions, and the curriculum ordering (S1→S4) is shown to be essential—reverse or direct training collapses on functional tasks.

## Results

On the primary Qwen3-8B model, GenCircuit-RL (RLVF-H-C) achieves 72.7% Task Success Rate on procedural circuits, 52.6% on out-of-distribution Cello circuits with held-out repressor-promoter pairs, and 44.9% on Literature-91 de novo design, for a 59.1% average across all splits. Hierarchical verification rewards improve functional reasoning tasks (T5 logic prediction, T6 circuit debugging) by 14.2 and 15.6 percentage points over binary rewards, while the four-stage curriculum adds a further 5.0 pp over non-curriculum hierarchical training. Cross-architecture validation on Llama-3.1-8B and Gemma-3-12B confirms consistent trends, with RLVF-H-C improving over SFT by 16.7–17.2 pp on average.

## Baselines & Comparisons

Against Cello (Nielsen et al., 2016; Jones et al., 2022), the most prominent existing automated genetic circuit design tool, GenCircuit-RL loses on the matched gate-assignment task (T8): Cello achieves 88.3% topological correctness on the shared 111-circuit evaluation set using its characterized Hill-function response parameters, while GenCircuit-RL reaches 52.6% without access to those quantitative part-characterization data. However, GenCircuit-RL addresses a strictly broader design setting—it generates complete SBOL code from natural language specifications, supports feedback circuit types (toggle switches, oscillators, FFLs) that Cello cannot design, handles open-vocabulary part specifications, and performs circuit debugging, none of which Cello supports. Against the SFT baseline, RLVF-H-C improves average TSR by 19.1 pp (59.1% vs 40.0%), with the largest gains on OOD Cello circuits (+20.2 pp) and Literature-91 design (+17.6 pp). Against RLVF-Binary (same GRPO training but pass/fail reward), hierarchical verification adds 9.1 pp on procedural circuits and 14–16 pp on functional reasoning tasks, confirming that dense multi-level feedback is critical for multi-step regulatory reasoning. Against the frontier Claude Opus 4.5 model (5-shot), RLVF-H-C outperforms by 27.0 pp on average (59.1% vs 32.1%), demonstrating that domain-specific RLVF training on an 8B model substantially exceeds zero/few-shot prompting of a much larger general-purpose model.

## Relation to Prior Work

This paper extends the RLVF paradigm from software engineering (binary unit-test feedback in CodeRL, CodeT) to a scientific domain where correctness decomposes into a five-level hierarchy (execution → validity → structure → semantics → function), drawing on dense-reward ideas from VeRPO and RL-Struct. It departs from Cello, the dominant automated genetic circuit design tool, which maps Boolean truth tables onto a fixed NOR topology via simulated annealing with access to quantitative Hill-function parameters; GenCircuit-RL instead generates complete pysbol3 code from natural language without such characterization data, addressing a broader and more open design setting. The curriculum learning component builds on ProRL's observation that training duration matters, but sharpens it by showing that the *ordering* of verification-level emphasis is essential, not merely the presence of staged training.

## Why It Matters / Open Questions

The SynBio-Reason benchmark (4,753 circuits, 71,315 task instances, held-out repressor-promoter pairs) provides the first systematic evaluation protocol for LMs on genetic circuit reasoning, and the hierarchical-verification-plus-curriculum recipe is a generalizable template for any scientific domain with decomposable, executable correctness criteria. A key open question is the gap between topological and dynamic verification: the current verifier confirms correct parts, connections, and motifs but does not simulate ODE-level behavior (bistability, oscillation period), so generated circuits remain design hypotheses requiring experimental validation. The paper's preliminary ML-surrogate experiments (Appendix H) hint at a path toward kinetic rewards but leave this as exploratory work.

## Problem

Existing ReDoS detection methods face a fundamental trade-off: static analyzers are fast but produce high false positives and lack support for extended regex features (lookarounds, backreferences), while dynamic and hybrid approaches achieve higher precision at the cost of significant runtime overhead from executing regexes on real engines. No prior method combines low inference latency with full support for non-regular extended features in a proactive, regex-level detection setting.

## Input / Output

The method takes a single regular expression string (including extended features such as capturing groups, backreferences, lookarounds, and bounded/unbounded counting operators) as input and produces a binary ReDoS vulnerability label (vulnerable or not) via a sigmoid-activated MLP. The regex is first parsed into an AST, then converted into a Heterogeneous Regex Graph with type-specific node attribute vectors (e.g., counting bounds, group indices, lookaround polarity) and additional semantic edges beyond the AST hierarchy, all processed under a per-regex 6-minute inference timeout.

## Method

RMGNN converts each regex AST into a motif-enhanced Heterogeneous Regex Graph (MEHRG) that augments nodes with multi-dimensional semantic attributes and a type-dependent masking mechanism, and adds non-parent-child edges for capture-backreference and lookaround-scope relations. Three counting-centered motifs (nested/sibling counting nodes, counting with union successor, and extended features under counting) are extracted as induced subgraphs, canonicalized via BFS, hashed into a fixed vocabulary, and their learnable embeddings are concatenated back onto the HRG nodes and edges. The model then performs L layers of heterogeneous message passing with relation-specific weight matrices, aggregates node embeddings into motif-level representations, and regularizes them via KL-divergence distillation from a WL Subtree Kernel teacher distribution. Finally, a cross-attention module uses the global motif vector as query and node embeddings as keys/values, fused with a residual connection, to produce the final graph representation for binary classification.

## Results

RMGNN achieves the best F1-score across all four real-world datasets: 77.73 (Corpus), 67.02 (PyPI), 64.41 (Maven), and 59.88 (NuGet), with corresponding accuracies of 87.36%, 85.78%, 83.62%, and 84.19%. Compared to the second-best baseline (mostly Regulator), RMGNN improves F1 by 4.49–28.06 percentage points (relative gains of 6.13%–88.18%). In terms of efficiency, RMGNN achieves an average inference time of 0.031 s per regex, yielding a 244× average speedup over Regulator (the top F1-performing baseline) and up to 375× on Corpus.

## Baselines & Comparisons

RMGNN outperforms all six baselines on F1 across every dataset, winning 14 out of 16 metric-dataset combinations. The closest competitor is Regulator (dynamic), which achieves F1 of 73.24 on Corpus but drops to 31.82 on NuGet; RMGNN extends this to 77.73 and 59.88 respectively, a 4.49–28.06 pp absolute F1 gain. ReDoSHunter (hybrid) attains the highest recall on Corpus (74.23%) but at the cost of severe accuracy collapse (43.50% vs. RMGNN's 87.36%), yielding F1 of only 44.31. Static baselines (RegexStatic, Rexploiter) and the dynamic ReScue are far behind, with F1 scores below 7% on all datasets, largely due to their inability to handle extended features like backreferences and lookarounds. Rengar (hybrid) achieves moderate F1 (12–37%) but is consistently outperformed by RMGNN by 27–52 pp. On the zero-day CVE benchmark (340 JavaScript regexes), RMGNN reaches 95.35% accuracy and F1 of 94.51%, identifying all vulnerabilities found by the other five baselines plus additional ones.

## Relation to Prior Work

This paper extends the GNN-based vulnerability detection lineage (Devign, HGT, DSHGT) from source code to the domain of regular expressions, repurposing heterogeneous graph learning for a structured pattern language. It departs from prior ReDoS detection (static NFA analysis, dynamic fuzzing, hybrid pattern matching) by formulating the problem as supervised graph classification, and from prior GNN-for-regex work (RegexClassifier, which uses NFA inputs) by operating on AST-derived heterogeneous graphs that natively support non-regular extended features like backreferences and lookarounds. The kernel-guided motif distillation component borrows the WL Subtree Kernel as a structural teacher, adapting knowledge distillation from graph classification to inject counting-centered domain priors into learned representations.

## Why It Matters / Open Questions

The 244× average speedup over the best-F1 dynamic baseline (Regulator) while simultaneously achieving higher F1 makes proactive ReDoS scanning feasible in CI/CD pipelines where dynamic tools are prohibitively slow. The finding that 32B-parameter LLMs underperform a small GNN by 20+ F1 points on this task suggests that structured pattern vulnerability detection may not benefit from general-purpose language models, pointing toward domain-specific graph encoders as the more practical path. Open questions include cross-engine generalization (the model is trained per-engine), whether the motif priors remain necessary as training data scales, and whether the approach extends to other algorithmic-complexity vulnerabilities beyond regexes.

## Problem

Existing MRAG pipelines treat visual queries as static, immutable signals, implicitly assuming canonical quality, yet real-world images suffer from geometric distortions, quality degradation, and semantic clutter that cause catastrophic retrieval failures. While text-based RAG has well-established query rewriting and decomposition techniques, no systematic benchmark or methodology exists for active visual query pre-processing in the multimodal setting.
![Teaser figure](../imgs/ICML20265722/cropped_page0_idx0.webp)

## Input / Output

The agent receives an imperfect RGB query image (corrupted by one of 10 parameterized operations such as 90°/180°/270° rotation, Gaussian blur with kernel sizes 9–27, or 2×2 grid expansion), a text question, and structured tool descriptions, and must output a JSON array of ordered (tool, params) tuples—e.g., {"tool": "rotate", "params": {"degrees": 180}} or {"tool": "locate", "params": {"prompt": "the screen on the left"}} followed by {"tool": "crop", "params": {"bbox": {...}}}. The refined image is then encoded by a dense retriever (Nomic-embed, 768-dim) to fetch top-5 Wikipedia passages, which are concatenated with the question for final answer generation. Coordinates for crop/fill are always relative to the current image state after prior sequential tool applications, and the agent must call locate before crop or fill to obtain bounding boxes.

## Method

V-QPP-Bench is constructed via a reverse-engineering paradigm: 46,700 imperfect queries are generated by applying 10 parameterized corruption functions (rotation, flip, brightness, blur, noise, crop, expand, overlay, watermark, real-world embedding) to clean source images from InfoSeek and ViQuAE, so the known inverse transformation serves as the oracle refinement trace ⟨I_query, T*, I_gt⟩. The V-QPP task is formulated as an agentic decision-making problem where an MLLM must autonomously diagnose the imperfection type and predict both the correct tool from an 8-tool library (rotate, flip, lum, deblur, denoise, locate, crop, fill) and its execution parameters (e.g., rotation angle, brightness factor, bounding box coordinates). Evaluation spans five MRAG retrieval paradigms (I2T dense, caption-then-retrieve, I2I, composed I+T→I+T, and Google Lens API) with a three-level metric hierarchy: tool selection accuracy and parameter score, retrieval Recall@K, and end-to-end MRAG accuracy. For the SFT baseline, Qwen3-VL-4B-Instruct is fine-tuned with LoRA (rank 8, lr 1e-4, 3 epochs) on only 1,000 refinement triplets (100 source images × 10 corruptions) using LLaMA-Factory, learning to emit the oracle JSON operation sequence directly; this compact model then matches or surpasses GPT-4o and Gemini-2.5-Flash on tool usage and MRAG accuracy, while preliminary GRPO training with retrieval recall as reward yields modest further gains.

## Results

On V-QPP-Bench (46,700 imperfect queries), visual imperfections cause severe retrieval recall degradation: RealWorld (−98.6%), Expand (−80.3%), Rotation (−49%), and Flip (−33.5%), while quality degradations are milder (Brightness −4.7%, Blur −5.2%, Noise −12.3%). Oracle preprocessing recovers near-perfect performance for geometric and semantic imperfections, validating the restoration potential. After SFT on only 1,000 refinement trajectories (100 source images × 10 corruptions), Qwen3-VL-4B (V-QPP-SFT) achieves tool selection accuracy comparable to or exceeding GPT-4o, and substantially outperforms all off-the-shelf models on parameter prediction and end-to-end MRAG accuracy across nearly all imperfection types.

## Baselines & Comparisons

The paper benchmarks 8 MLLMs as zero-shot V-QPP agents against the SFT-trained Qwen3-VL-4B (V-QPP-SFT). GPT-4o is the strongest off-the-shelf baseline, achieving the highest tool selection accuracy among proprietary models and slightly outperforming V-QPP(SFT) on Rotation and Flip parameter prediction; however, V-QPP(SFT) matches or exceeds GPT-4o on overall tool selection accuracy and clearly surpasses it on parameter scores for most other imperfection types. Gemini-2.5-Flash-Lite, Qwen3-VL-30B-A3B, Mistral-Small-3.1-24B, Llama-3.2-11B-Vision, DeepSeek-VL2-Small, and Phi4-Multimodal all show limited improvement over the imperfect-query baseline, with gains concentrated only on Rotation and Flip. Llama3-LLaVA-Next-8B is the weakest, exhibiting actual performance degradation on certain imperfection types due to incorrect tool selections. V-QPP(SFT), trained on just 1,000 samples, outperforms all 8 off-the-shelf models on end-to-end MRAG accuracy and retrieval recall across nearly all imperfection types, with the largest gains on RealWorld, Expand, and Rotation—demonstrating that task-specific SFT on a compact 4B model can match or surpass much larger proprietary models in agentic visual query pre-processing.

## Relation to Prior Work

This paper draws a direct analogy between query rewriting in text-based RAG (RQ-RAG, HyDE, DeepRetrieval) and a previously absent 'visual query rewriting' stage in MRAG, arguing that existing MRAG systems (MURAG, MRAG-Bench, Visual-RAG) implicitly treat visual inputs as canonical and immutable. It departs from prior robustness benchmarks for MLLMs (CRAG-MM, CrossCheck-Bench, ConflictVis), which adopt passive strategies—either expecting encoders to tolerate imperfections or training models to reject unanswerable queries—by instead formulating active, tool-mediated visual query refinement as an agentic decision-making task. The perceptual tool library (Grounding DINO for localization, Richardson-Lucy deconvolution, non-local means denoising) repurposes standard image-processing primitives into an MLLM-callable interface, but the agentic orchestration layer and the benchmark's reverse-engineering data construction paradigm are novel contributions.

## Why It Matters / Open Questions

V-QPP-Bench (46,700 queries, 10 corruption types, 5 retrieval paradigms) provides the first systematic measurement of how visual imperfections degrade MRAG and whether agentic pre-processing can recover performance, filling a clear gap between MRAG research and real-world deployment where user-captured images are rarely canonical. The finding that SFT on only 1,000 refinement trajectories enables a 4B model to match or surpass GPT-4o on tool selection and parameter prediction suggests that V-QPP capability is cheaply learnable, lowering the barrier for building robust MRAG systems. Open questions include multi-step compositional corruption planning, out-of-distribution generalization to truly arbitrary real-world degradations, and whether RL-based training (preliminary GRPO results show only marginal gains) can close the remaining gap to oracle performance.

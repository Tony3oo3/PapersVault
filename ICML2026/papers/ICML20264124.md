## Problem

Existing machine unlearning methods that rely on linear parameter updates (e.g., task arithmetic) suffer from weight entanglement, where the task vector's influence cannot be localized to forgetting data without degrading retaining performance. Additionally, these methods produce only a single unlearning model, which is fundamentally insufficient because the optimal stopping point varies across different forgetting data points, making it impossible for one model to simultaneously achieve effective unlearning for all of them.
![Teaser figure](../imgs/ICML20264124/cropped_page2_idx0.webp)

## Input / Output

The method takes a trained model θ_o, a pre-unlearning model θ_p (produced by any existing MU method such as NegGrad+ or RL), the forgetting dataset D_f, and the retaining dataset D_r. It outputs a continuous Bezier-curve pathway in parameter space parameterized by t∈[0,1], from which an optimal unlearning model and a broader effective unlearning region are identified via calibration-based model selection at inference time. Notably, only 50% of the retaining data is consumed during pathway optimization, and the parameter mask operates at the granularity of entire named parameter tensors (e.g., a full convolutional kernel) rather than individual elements, enabling complete bypass of gradient computation for masked parameters.

## Method

MCU constructs a quadratic Bezier curve in parameter space between the original model θ_o and a pre-unlearning model θ_p, with a single control model θ_c optimized via a loss that balances cross-entropy on retaining data against a penalized forgetting loss, sampled uniformly along the curve at each batch. A two-stage parameter mask (filtering out top-k_r parameters critical for D_r, then reserving top-k parameters important for D_f) restricts updates to entire parameter tensors, yielding a 75% training speedup while preserving unlearning quality. An adaptive unlearning penalty coefficient β is updated at every batch based on calibration targets (retaining accuracy should match original training accuracy; forgetting accuracy should match original validation accuracy or zero for class-wise forgetting), eliminating manual hyperparameter tuning. The nonlinear Bezier pathway is shown to outperform both linear interpolation and Polychain alternatives, and a theoretical result (Theorem 3.1) demonstrates that achieving high-probability unlearning guarantees for all forgetting samples requires an astronomically large number of discrete models, which the continuous pathway resolves elegantly.

## Results

On CIFAR-10 with PreResNet-110 (10% random data forgetting), MCUβ achieves an Avg. Gap of 1.00 (vs. RT baseline), outperforming the best baseline RL (2.70) and NegGrad+ (2.97), while the linear method NegTV scores 6.10. On ImageNet-100 with ViT, MCUβ achieves an Avg. Gap of 0.65, beating NegTV (1.04) and NegGrad+ (1.16). In the class-wise forgetting scenario on ImageNet-100, MCUβ nearly matches the retraining baseline with an Avg. Gap of only 0.07, while NegTV (0.84) and SalUn (0.97) trail significantly. As a plug-and-play framework, MCUβ reduces the average gap of all 7 integrated baselines by 48.99% on CIFAR-10.

## Baselines & Comparisons

MCUβ consistently outperforms all 7 baselines on Avg. Gap across both datasets. Against the strongest baselines, MCUβ (1.00) beats RL (2.70) and NegGrad+ (2.97) by roughly 2–3 points on CIFAR-10, and beats NegTV (1.04) and NegGrad+ (1.16) on ImageNet-100. The linear task-arithmetic method NegTV, which the paper identifies as suffering from weight entanglement, shows particularly poor class-wise forgetting (Avg. Gap 45.72 on CIFAR-10, 48.69 on Tiny-ImageNet) where MCUβ achieves 0.03 and 0.15 respectively. SFRon is the weakest baseline overall (Avg. Gap 4.65 on CIFAR-10, 21.63 on ImageNet-100), with severe retaining accuracy degradation. GA and FT are fast but produce extreme over-forgetting (UA near 0) or under-forgetting, yielding Avg. Gaps of 7.31 and 6.57 on CIFAR-10. As a plug-and-play wrapper, MCUβ improves every integrated baseline by an average of 48.99% in Avg. Gap (Table 3), confirming its generality independent of the pre-unlearning model quality.

## Relation to Prior Work

This paper departs from the dominant linear task-arithmetic paradigm for machine unlearning (Ilharco et al., 2022; Ortiz-Jimenez et al., 2024) by arguing that linear parameter updates inherently suffer from weight entanglement, and instead repurposes mode connectivity (Garipov et al., 2018) — previously used for model ensembling and robustness evaluation — as the core mechanism for constructing a nonlinear unlearning pathway in parameter space. It positions itself against a concurrent work (Cheng & Amiri, 2025) that uses mode connectivity only as an unlearning evaluation tool, whereas MCU integrates it directly into the unlearning procedure. The framework is explicitly designed as a plug-and-play wrapper around any existing MU method (NegGrad+, SFRon, SalUn, etc.), which serve as the pre-unlearning endpoint of the Bezier pathway.

## Why It Matters / Open Questions

The pathway formulation addresses a fundamental limitation of single-model unlearning (formalized in Theorem 3.1) by producing a continuous spectrum of unlearning models, enabling practitioners to select the optimal trade-off between forgetting quality and utility preservation without retraining. The plug-and-play design and adaptive β strategy lower the barrier to adoption, and the ~49% average gap reduction across all baselines demonstrates broad applicability. However, the framework is validated only on image classification with moderate-scale models, still requires a pre-unlearning model as input, and the Bezier curve choice, while well-motivated, remains a specific design decision whose optimality is not theoretically characterized. Open questions include scalability to foundation models, applicability to generative or multimodal settings, and whether the pathway concept can be formalized with stronger theoretical guarantees beyond the informal lower bound.

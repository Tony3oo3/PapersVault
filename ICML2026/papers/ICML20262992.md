## Problem

Existing PTM-based class-incremental learning methods struggle to simultaneously learn discriminative and comprehensive representations while maintaining stability and plasticity over very long task sequences (100–300+ non-overlapping tasks), and no suitable benchmark exists for such evaluations because common CIL datasets contain too few classes to support hundreds of meaningful tasks.

## Input / Output

The method consumes standard RGB images processed by a frozen ViT-B/16 backbone (pre-trained on ImageNet-21K) and outputs a class label from a linear classifier whose weight matrix grows with each new task. Tasks arrive sequentially with non-overlapping class sets; during training on task t, all parameters from previous t−1 tasks are frozen, and only the new BR-MoE triplet (class perceptron, router, adapter) is updated. The OmniBenchmark-1K dataset provides 1,000 classes across 21 visual realms with ~190K images, enabling evaluation from 100 to 301 tasks.

## Method

CaRE integrates a Bi-Level Routing Mixture-of-Experts (BR-MoE) module into every ViT building block, where each module maintains a per-task triplet of a class perceptron, a router network, and an adapter expert, plus a single shared expert updated via EMA. The first routing level uses entropy of class-perceptron logits to dynamically select Top-M most relevant router networks for the current input at each layer; the second level uses each selected router's gating scores to activate Top-K task-specific adapter experts, whose outputs are aggregated with the shared expert. Intermediate-layer class perceptrons receive auxiliary KL-divergence supervision from final-layer softmax probabilities to produce reliable entropy signals despite lower-level features being less discriminative. This design enables each network layer to make independent local routing decisions, retrieving both task-specific (discriminative) and cross-task (comprehensive) knowledge tailored to the abstraction level at that depth.

## Results

On the proposed OmniBenchmark-1K dataset, CaRE achieves 78.54% average accuracy and 68.27% last accuracy at 100 tasks (B0 Inc10), 78.00%/67.46% at 200 tasks (B0 Inc5), 77.65%/69.01% at 151 tasks (B100 Inc6), and 77.18%/68.51% at 301 tasks (B100 Inc3), outperforming all baselines by 4–8% in last accuracy. On classical short-sequence benchmarks (5–20 tasks), CaRE also leads, e.g., 95.46%/92.46% on CIFAR-100 (10 tasks), 85.75%/80.53% on ImageNet-R (10 tasks), and 96.93%/93.80% on VTAB (10 tasks). CaRE uses only 3.27M trainable parameters per task and 70.89s inference latency, achieving ~80% fewer trainable parameters and ~95% lower latency than MOS while improving last accuracy by 4%.

## Baselines & Comparisons

CaRE outperforms all 16 baselines across every dataset and task-sequence length tested. In long-sequence evaluations (100–301 tasks on OmniBenchmark-1K), the closest competitors are MOS and MIN; CaRE exceeds MOS by 4.00% in last accuracy at 100 tasks and by 4.14% at 301 tasks, and surpasses MIN by 4.67% at 100 tasks. Against TUNA, the gap widens to 8.32% at 200 tasks, and against APER-Adapter it reaches 6.02% at 151 tasks. Notably, SEMA and MoAL suffer severe degradation in long sequences (e.g., MoAL drops from ~63% to ~46% average accuracy between 100 and 301 tasks), while CaRE maintains stable performance. On short-sequence benchmarks (Table 3), CaRE leads by 1.97% over MoAL on CIFAR-100 (10 tasks), 5.24% over SLCA on ObjectNet (20 tasks), and 8.82% over SD-LoRA on ImageNet-A (10 tasks). Across different task orderings, CaRE exhibits the lowest standard deviation (0.16 in A_B) compared to MOS (0.88) and TUNA (1.00), confirming superior robustness to task ordering in long-sequence settings.

## Relation to Prior Work

This paper extends the adapter-based CIL line (EASE, MOS, TUNA, MIN, APER-Adapter) by replacing static or single-router adapter selection with a bi-level routing Mixture-of-Experts mechanism: entropy-based class perceptrons first select Top-M task-specific routers, which then dynamically gate Top-K adapter experts, while a shared EMA-updated expert provides cross-task knowledge. The architecture is built on AdaptFormer's adapter-in-ViT-block design, and the shared expert with momentum update draws from DeepSeekMoE. The key conceptual departure from prior MoE-based CIL work (MoE-Adapter, SEMA) is the two-level routing with layer-wise local decisions, where each ViT block independently retrieves discriminative and complementary knowledge rather than relying on a single global routing decision.

## Why It Matters / Open Questions

The introduction of OmniBenchmark-1K (1,000 classes, ~190K images) fills a critical gap: prior CIL evaluations were confined to 5–20 tasks due to dataset size limitations, leaving scalability to hundreds of tasks entirely untested. CaRE's demonstration that bi-level routing maintains 68%+ last accuracy at 301 tasks while baselines like SEMA and MoAL collapse to ~33% and ~19% respectively reveals that short-sequence success does not imply long-sequence viability. The main limitation is linear parameter growth with task count, and the paper acknowledges that truly unbounded sequences remain out of reach. Open questions include whether the routing mechanism can be made more parameter-efficient, whether test-time adaptation of routing decisions (observed as a beneficial side effect) can be explicitly optimized, and whether the approach transfers to vision-language models.

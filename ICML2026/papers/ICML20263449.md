## Problem

Reward design in reinforcement learning remains a central challenge: hand-crafted rewards are difficult to specify and can lead to reward hacking or suboptimal policies, while preference-based reward learning suffers from low feedback efficiency, unstable training, and poor generalization. Existing LLM/VLM-based approaches either generate coarse, noisy reward code or require large numbers of preference labels, leaving an open problem of obtaining reward signals that are simultaneously feedback-efficient and reliably aligned with task-specific human intentions.

## Input / Output

The method consumes state observations (39-dim for MetaWorld, up to 111-dim for SoftGym), RGB images rendered at 300×300 (MetaWorld) or 240–360×360 (SoftGym) with the robot arm made transparent to reduce VLM hallucinations, a textual task description, and downsampled video clips paired with a start image and goal image for VLM querying. It produces a trained SAC policy operating on state observations, an iteratively refined Python reward function (FRM), and an ensemble of three image-based reward models (4-layer CNN for MetaWorld, ResNet-18 for SoftGym) whose outputs are summed with the formal reward after clipping each to [−0.5, 0.5].

## Method

CoRe decomposes the total reward into a Formal Reward (FR) and a Residual Reward (RR). The Formal Reward Module (FRM) uses GPT-4.1 mini to iteratively generate candidate Python reward functions from task knowledge (state/action definitions only, not full environment code), selecting the best candidate via Reward-Preference Alignment—measuring preference prediction accuracy over VLM-labeled trajectory pairs rather than task completion—to avoid reward hacking. The Residual Reward Module (RRM) queries Gemini 2.0 Flash with video-level preference prompts (task description, start/goal images, and two downsampled video clips) using chain-of-thought reasoning to obtain both a preference label and per-frame importance weights; the image-based reward model is then trained with a cross-entropy preference loss plus a KL-divergence term that regularizes predicted state rewards toward the VLM-derived importance prior. The two modules are mutually reinforcing: FRM provides structured, interpretable rewards that guide RRM exploration and stabilize training, while RRM captures fine-grained, preference-aligned signals (especially for deformable objects) that code-based rewards cannot express, enabling the policy to reach near-human performance with 3–40× fewer preference labels than baselines.

## Results

On seven MetaWorld tasks, CoRe achieves a 99.0% average success rate, approaching human-level performance (99.3%) and substantially outperforming all baselines: Eureka (75.5%), Text2Reward (74.2%), RL-VLM-F (56.8%), ERL-VLM (37.0%), PrefVLM (18.6%), and CLIP Score (4.8%). On three SoftGym deformable-object tasks, CoRe attains the best episode reward across all tasks (Fold Cloth: −0.10, Straighten Rope: 20.6, Pass Water: −30.0). CoRe also achieves a 3–40× reduction in preference labels (0.15K–0.5K vs. 0.5K–21K) and requires only ~$0.37 API cost and 2.15 hours of wall-clock time per task on average.

## Baselines & Comparisons

CoRe decisively outperforms all six baselines on complex manipulation tasks. On Hammer, CoRe reaches 98.0% success versus Eureka (33.3%), Text2Reward (32.0%), RL-VLM-F (72.7%), PrefVLM (1.3%), and ERL-VLM (9.3%); the gap is especially stark because Eureka and Text2Reward suffer from reward hacking (striking with the hammer handle) while rating-based ERL-VLM cannot assign fine-grained credit. On Peg Insert, CoRe achieves 100.0% compared to Eureka (66.7%), Text2Reward (33.3%), RL-VLM-F (14.7%), PrefVLM (0.0%), and ERL-VLM (9.3%). On the deformable-object SoftGym tasks, CoRe is the best method on all three (Fold Cloth −0.10, Straighten Rope 20.6, Pass Water −30.0), whereas baselines such as ERL-VLM drop to −202.4 on Pass Water and PrefVLM to −86.9. CLIP Score is the weakest baseline overall (4.8% average on MetaWorld), confirming that direct similarity scoring is insufficient for multi-step manipulation. In terms of sample efficiency, CoRe requires only 0.15K–0.5K preference labels versus 0.5K–21K for other methods, and its total training cost (~$0.37, 2.15 h) is lower than RL-VLM-F ($0.79, 6.72 h) and ERL-VLM ($0.55, 5.80 h).

## Relation to Prior Work

CoRe's Formal Reward Module (FRM) directly extends Eureka's iterative LLM-based reward code generation, but replaces Eureka's task-completion-based candidate selection with a preference-guided 'Reward-Preference Alignment' criterion, ensuring the generated code reward stays aligned with human intent rather than merely maximizing a proxy metric. The Residual Reward Module (RRM) builds on PEBBLE's preference-based RL framework (cross-entropy loss over trajectory-segment preferences with replay-buffer relabeling) but departs from prior image-level preference methods (RL-VLM-F, PrefVLM) by querying VLMs on video clips and adding a KL-divergence regularizer that aligns the learned per-frame reward distribution with VLM-assessed state importance. The central conceptual contribution is the explicit decomposition of the total reward into a structured, code-based formal component and a flexible, learned residual component, motivated by cognitive science's distinction between prior-knowledge-driven and interaction-driven learning.

## Why It Matters / Open Questions

CoRe demonstrates that a hybrid of LLM-generated code rewards and VLM-guided learned rewards can approach human-level performance (99.0% vs. 99.3%) on manipulation tasks while using 3–40× fewer preference labels than existing PbRL baselines, and that policies transfer to a real UR5 arm without fine-tuning. The stronger-model ablation (Table 9) is notable: scaling the LLM from GPT-4.1 mini to GPT-5.4 yields only a 0.7-point gain in FRM at 9× cost, whereas the FRM+RRM combination reaches 97.3% at a fraction of the cost, suggesting reward decomposition is a more effective lever than model scaling. Key limitations include reliance on iterative VLM/LLM API calls (≈2M tokens, $0.37 per task), moderate alignment between VLM importance weights and true task progress (Spearman ρ ≈ 0.48), and evaluation confined to relatively simple tabletop manipulation; the authors flag uncertainty-aware reward modeling and more diverse real-world settings as open directions.

## Problem

Reinforcement Learning from Verifiable Rewards (RLVR) for logical reasoning is bottlenecked by data: existing synthesis pipelines rely on expert-written code scripts or fixed templates (ILP/SAT/PDDL), confining growth to instance-level parameter perturbations within predefined structures. This 'Instance Synthesis' paradigm cannot transcend the priors of its templates, preventing the discovery of genuinely new task rules, algorithmic structures, and difficulty gradients at the task-family level.

## Input / Output

The pipeline takes seed task families as executable Python Generator-Validator pairs (generator.py, validator.py) along with a difficulty parameter and a Context Playbook of design patterns from prior runs. Agents operate in a terminal environment, writing and executing code interactively. The output is evolved task-family specifications (new Generator-Validator code with novel rules) plus instantiated verifiable instances (natural-language problem text paired with a hidden structured state and a deterministic validator), yielding 953 families and 21,389 instances from 400 seeds after two evolution rounds.

## Method

SSLogic shifts the evolvable unit from problem instances to task-family specifications by employing LLM agents (built on Cognitive Kernel-Pro's two-tier Main/Sub-Agent hierarchy) as program synthesis engines in a Generate-Validate-Refine closed loop. A Multi-Gate Validation Protocol enforces quality: Gate 1 applies a lightweight format checker plus a Quality Agent for readability and completeness; Gate 2 performs consensus-based dynamic verification across m independently synthesized solvers and an Adversarial Blind Review where n independent agents solve each instance from scratch by writing and executing code, filtering ill-posed or ambiguous tasks. Training uses GRPO with the K3 unbiased KL estimator on Qwen3-8B-Base (no SFT), with group-level rejection sampling to retain only verifier-passing trajectories. Three converging comparisons (step-matched, token-matched at ~1.09B tokens, and size-controlled on external Enigmata data) confirm that evolved task families yield higher training utility, with gains of +5.2 on SynLogic, +3.0 on AIME25, and +5.5 on BBH, while KORBench reveals selective improvements concentrated in Logic (+13.2%) and Operation (+9.6%) categories that exercise the expanded algorithmic structures.

## Results

At 240 GRPO training steps on Qwen3-8B-Base, Evolve data consistently outperforms Seed across logic benchmarks (SynLogic 13.1→18.7, BBH 72.1→75.5, BBEH 13.6→15.0) and mathematical benchmarks (AIME24 13.8→17.3, AIME25 11.0→14.0, Brumo25 21.9→25.6, Math500 77.1→80.8), with average gains of +2.0 (logic) and +3.0 (math). The size-controlled Enigmata experiment (matched instance counts, 240 steps) confirms seed-agnostic generalization: BBH +5.5, AIME25 +4.9, SynLogic +2.0. KORBench evaluation reveals selective improvements concentrated in Logic (+13.2%) and Operation (+9.6%), while Puzzle (+1.2%) barely moves, linking structural code evolution to targeted downstream gains.

## Baselines & Comparisons

The paper's primary comparison is between two training-data strategies rather than different model architectures: human-annotated Seed task families versus agent-evolved (Evolve) task families, both trained with identical GRPO hyperparameters on Qwen3-8B-Base. Evolve wins on every logic and math benchmark at all three step checkpoints (160/200/240), with the gap widening over training (e.g., SynLogic +0.2 at 160 steps → +5.6 at 240 steps). A size-controlled subsampling experiment (n=236 vs. 236, d=7) confirms the gains are quality-driven rather than quantity-driven, with average logic Δ of +0.8 and math Δ of +1.2. In the synergistic math-training setting (Table 2B), adding SSLogic-Evolve to AIME data yields +3.0 to +5.4 average math gains, whereas adding ARC-AGI data instead causes −3.7 to −5.0 drops on AIME24/25, establishing ARC-AGI as a negative control that suppresses response length and reflection-like token frequency. The external Enigmata experiment (30 of 36 puzzle types evolved, matched instance counts) validates that the pipeline generalizes beyond the original Chinese seed distribution, achieving BBH +5.5 and AIME25 +4.9 with zero human annotation.

## Relation to Prior Work

This paper departs from two established paradigms for logic data synthesis: expert-written code scripts (SynLogic, Reasoning Gym, ProofWriter) and instance-level extension within fixed formal skeletons (ILP/SAT/PDDL-based approaches like SLR, ProtoReasoning, AutoLogi). The key conceptual shift is elevating the evolvable unit from problem instances to task-family specifications (Generator-Validator code pairs), enabling agents to author and refine new rules and difficulty gradients rather than perturbing parameters of existing templates. The agent backbone is built on Cognitive Kernel-Pro (CKPro), and the multi-gate validation protocol with adversarial blind review draws on the broader agentic synthesis pipeline literature (AgentFrontier, AgentEvolver, AgenticMath) but applies it specifically to the verification challenges of logic tasks.

## Why It Matters / Open Questions

The paper provides one of the first near-thousand-scale collections of verifiable logic task families with a controlled analysis of how code-level structural evolution (higher cyclomatic complexity, broader algorithmic patterns) translates into selective downstream gains, offering a concrete recipe for scaling RLVR data beyond template-based approaches. The ARC-AGI negative control—where mixing grid-pattern data actively degrades math performance while SSLogic-Evolve improves it—challenges the assumption that more diverse reasoning data uniformly helps transfer. Key open questions include cold-start synthesis without structured seeds, generalization to other verifiable domains (code, science), and whether the 55% acceptance rate ceiling (bounded by the synthesis model's code-generation capability) can be raised without sacrificing quality.

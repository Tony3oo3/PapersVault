## Problem

Endpoint Detection and Response (EDR) logs contain thousands to tens of thousands of events per session, making them too long for standard LLM context windows while malicious activities remain temporally sparse and visually similar to benign behavior. Existing deep learning methods lack explicit temporal reasoning and interpretability, and directly applying LLMs to raw logs suffers from severe scalability and efficiency constraints. The paper asks whether EDR logs can be reformulated into a structured multimodal representation that enables both efficient long-sequence processing and interpretable threat reasoning.

## Input / Output

The method takes a raw EDR log file (up to 1M+ tokens of event sequences) and a query text as input. Each event is decomposed into 144 key-value pairs, tokenized, and pooled via a softmax-weighted kvEmbedding layer into a fixed-dimensional vector, then reshaped into an image tensor (c×h×w). These per-event images are chronologically stacked into a video tensor and compressed from T frames to t=64 frames via pixel-wise temporal cross-attention. The output is a two-part autoregressive sequence: an exact-match attack family label followed by a natural-language rationale explaining the behavioral evidence.

## Method

WatchLog is a three-stage framework built on Qwen2-VL-2B that progressively transforms raw logs into video-language representations. Stage 1 (Image-Event Alignment) encodes each event's key-value fields into pixel-level embeddings via a trainable kvEmbedding layer (softmax-weighted token pooling with permutation invariance and norm boundedness), then aligns these event images with GPT-generated textual descriptions using autoregressive NLL. Stage 2 (Video-Log Alignment) stacks event images into a video and applies a temporal cross-attention block that condenses T frames into t=64 abstracted frames at each spatial location, preserving pixel-wise spatial consistency while capturing long-range temporal dependencies; this compact video is aligned with GPT-generated log narratives. Stage 3 (SFT) fine-tunes the full multimodal model end-to-end to jointly predict the family label and generate an interpretable rationale under a unified autoregressive objective. The key architectural insight is that representing logs as video-structured data with selective temporal compression bounds the effective sequence length for downstream LLM reasoning, reducing GPU memory by ~50% and inference latency by over 200× compared to standard LLM baselines at 1M-token context.

## Results

On EDR8M-20R, WatchLog achieves 99.8% Binary Accuracy, 100% Recall, 5.0% False Alarm rate, and 90.3% Overall Accuracy (exact family-name match), substantially outperforming all baselines. For reasoning quality, WatchLog scores 93.6 Coherence, 95.0 Consistency, and 68.5 Completeness (100-point scale), with Completeness being the most discriminative metric. On the external ATLASv2 benchmark (zero-shot), WatchLog achieves 66.7% Binary Accuracy and 88% Recall, again the best among compared methods. Efficiency-wise, WatchLog processes 1M-token inputs with only 48.61 GB GPU memory and 1.11 s TTFT, versus 215 GB and 486 s for Qwen2.5-7B-Instruct.

## Baselines & Comparisons

WatchLog dominates all three categories of baselines. Against traditional ML/DL methods (LGTF, ADE, DrSec), WatchLog improves Overall Accuracy by 41.5–69.8 percentage points (90.3% vs. 20.5–48.8%) while reducing False Alarm from 65–100% to 5.0%. Against zero-shot frontier LLMs (GPT-5, Gemini-2.5-Pro, DeepSeek-R1-671B, Qwen3-235B-A22B), WatchLog achieves 7.8–13.5× higher Overall Accuracy (90.3% vs. 7.8–13.5%) and near-perfect Recall (100% vs. 62.4–97.0%), indicating that raw-text LLMs cannot reliably parse ultra-long EDR sequences. Against SFT LLM baselines (Qwen2.5-1.5B/7B, LLaMA3.1-8B), WatchLog gains +39.0 pp in Overall Accuracy (90.3% vs. 51.3% best) and +9.3 points in Rationale Completeness (68.5 vs. 59.2), while maintaining a low 5% False Alarm rate comparable to the SFT baselines' 0–15%. On the OOD test set, WatchLog retains 74.0% Recall versus 17.0–32.0% for SFT baselines, confirming superior generalization to unseen attack families.

## Relation to Prior Work

This paper repurposes the video-language modeling paradigm (VideoCoCa, InternVideo2, LLaVA-Video) for a domain where it had not previously been applied: endpoint security log analysis. Rather than building on a specific prior EDR architecture, it carves new ground by recasting the spatial structure of key-value event fields as image pixels and the temporal sequence of events as video frames, then inserting a pixel-wise temporal cross-attention adapter to compress long sequences before feeding them to a multimodal LLM (Qwen2-VL). This departs from both traditional EDR methods (LGTF, ADE, DrSec) that treat logs as flat text or simple sequences, and from direct LLM-based approaches that struggle with the ultra-long context windows EDR logs demand.

## Why It Matters / Open Questions

The paper addresses a genuine practical bottleneck: EDR logs routinely exceed the context windows of current LLMs, and security operations require not just detection but interpretable rationales for analyst decision-making. The EDR8M-20R dataset (8M events, 20 families, expert-verified rationales) fills a notable gap in publicly available, well-annotated EDR benchmarks. However, OOD recall drops to 74% (from 100% in-distribution), rationale completeness remains moderate (~68/100), and the dataset is gated, limiting immediate reproducibility. Open questions include whether the video metaphor is strictly necessary versus other sequence-compression schemes, how the method behaves under adversarial log manipulation, and whether the approach scales to the full 172-family space beyond the 20 evaluated.

## Problem

Nodewise regression is a standard tool for subspace clustering, but its L1-regularized variant (sparse subspace clustering) requires tuning a regularization parameter that depends on unknown idiosyncratic variances, and enforces sparsity that is often unnatural when the true association matrix is dense. This paper asks whether regularization in nodewise regression can be derived naturally from a principled uncertainty model rather than imposed ad hoc.
![Teaser figure](../imgs/ICML20264853/cropped_page0_idx0.webp)

## Input / Output

The method takes a standardized n×d data matrix (n observations of d variables, zero mean and unit variance per column) and a known number of clusters K. It produces a d×d similarity matrix C = B_abs^T + B_abs built from the regression coefficient matrix B, from which cluster assignments are recovered via spectral clustering. The only user-specified hyperparameter is a confidence level 1−α (default 0.95) used to calibrate the uncertainty radius δ; no regularization strength needs to be tuned.

## Method

The paper reformulates nodewise regression as a distributionally robust optimization problem: instead of minimizing expected squared loss under the empirical distribution, it minimizes the worst-case loss over all probability measures within a squared-Wasserstein-2 ball of radius δ around the empirical measure. Theorem 3.1 shows this infinite-dimensional DRO problem is tightly bounded (within a factor of 2) by a finite-dimensional convex program with a spectral-norm penalty √δ‖I−B‖₂, yielding a natural, interpretable regularization that controls sensitivity to adversarial perturbations. The radius δ is chosen data-drivenly via a robust Wasserstein profile inference procedure that finds the smallest δ such that the true regression coefficients fall in the confidence region with probability 1−α. An ADMM algorithm solves the resulting convex program efficiently, with the spectral-norm subproblem handled by a closed-form SVD-based thresholding rule (Lemma 3.2) that shrinks only the top singular values, reducing runtime by over 80% compared to off-the-shelf solvers.

## Results

On synthetic multi-factor block model data (d=500, K=25, n=250), DRO achieves an average Adjusted Mutual Information (AMI) of 0.92, outperforming the Lasso nodewise regression baseline (0.83) and all other methods. On the Extended Yale B face dataset (23 trials), DRO achieves a mean AMI of 0.580 (median 0.584), compared to 0.403 for Lasso and 0.218 for the next-best method (SSC-EnSC). The ADMM solver reduces runtime by over 80% compared to off-the-shelf convex optimizers, and the method is insensitive to the confidence level parameter (AMI ranges 0.91–0.93 for α ∈ {0.001, 0.01, 0.05, 0.1, 0.2}).

## Baselines & Comparisons

DRO outperforms all eight baselines on both the synthetic and Extended Yale B experiments. Against the closest competitor, Lasso nodewise regression (Elhamifar & Vidal, 2013), DRO gains 0.09 AMI on synthetic data (0.92 vs. 0.83) and 0.18 AMI on Yale B (0.580 vs. 0.403), with the gap widening as the global factor becomes more dominant. The multi-factor block model method MFC (Ando & Bai, 2017), which shares the same generative model, achieves only 0.43 AMI on synthetic data and 0.172 on Yale B, indicating that its model-fitting algorithm is less accurate than DRO's subspace-based approach. Centroid-based methods (k-medoids at 0.33, ACC at 0.15 on synthetic) underperform because they assume a single-factor structure rather than a subspace structure. Sparse subspace clustering variants (SSC, SSC-EnSC, SSC-OMP) and LRR all score near or below random (AMI ≤ 0.029 on synthetic; SSC-EnSC is the best at 0.218 on Yale B), confirming that L1 sparsity is a poor inductive bias when the true association matrix is dense. Co-clustering (Role et al., 2019) performs at chance level (AMI ≈ 0) on both datasets.

## Relation to Prior Work

This paper sits at the intersection of three research threads: subspace clustering via nodewise regression (Elhamifar & Vidal, 2013), distributionally robust optimization with Wasserstein uncertainty sets (Blanchet et al., 2019), and the multi-factor block model for variable clustering (Ando & Bai, 2017). The key conceptual departure is from sparse subspace clustering (SSC), which imposes L1 regularization on nodewise regression coefficients; the authors argue that sparsity is unnatural when the true association matrix is dense (e.g., non-orthogonal subspaces or correlated variables within a cluster), and instead derive a spectral-norm regularization that emerges naturally from a DRO formulation. The data-driven choice of the uncertainty radius δ follows the robust Wasserstein profile inference framework, and the ADMM solver exploits the structure of the spectral-norm proximal operator via SVD-based shrinkage.

## Why It Matters / Open Questions

The main practical contribution is a tuning-free regularization for nodewise regression: the only user-specified parameter is a confidence level (1−α), to which the method is empirically insensitive, eliminating the difficult cross-validation of L1 penalty parameters that depends on unknown idiosyncratic variances. The spectral-norm penalty also has a clean adversarial-robustness interpretation, connecting variable clustering to the broader DRO and robustness literature. Limitations include the theoretical guarantee being tight only up to a factor of 2, the assumption that n grows with d fixed (while experiments use n < d), and the requirement that K is known. Open questions include whether the DRO framework extends to other loss functions or non-convex relaxations, and whether the factor-2 gap in the relaxation is empirically consequential.

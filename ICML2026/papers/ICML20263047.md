## Problem

Existing MoE-LoRA continual learning methods treat each LoRA adapter as a coarse-grained expert, which causes three compounding failures as tasks accumulate: interference from activating irrelevant subspaces within a single expert, redundancy because new experts cannot selectively reuse knowledge atoms from old ones, and routing collapse where external routers increasingly fail to disambiguate among a growing pool of low-specialty experts. The paper identifies this coarse expert granularity as the root cause and asks whether continual learning can be reframed as incremental expansion of fine-grained, atomic memory units with content-addressable retrieval instead of address-based routing.

## Input / Output

For vision-language CLIP experiments, the method takes RGB images (224×224) paired with text prompts and produces class labels across 10–11 domains (e.g., Aircraft, EuroSAT, SUN397) in a sequential task stream. For LLM experiments, it takes text inputs (up to 1024 tokens) and produces generated text or classification labels on benchmarks like TRACE, SuperNI, and standard CL suites. In both settings, MoRAM is applied to every linear weight matrix in the pre-trained backbone (vision and text encoders for CLIP; all linear layers for LLMs), with r=16 new rank-1 pairs added per task and a fixed activation budget of k=16 atoms per token.

## Method

MoRAM reinterprets each LoRA update ΔW=BA as a collection of r atomic rank-1 key-value memory pairs, where each row of A is a retrieval key and each column of B is a stored value, grounded in the linear associative memory view of weight matrices. Instead of an external router, each rank-1 expert self-activates by computing its intrinsic relevance score s_i = A_i x / ||{A_j x}||_2 against the input hidden state, turning routing into content-addressable retrieval. Sparse top-k masking, temperature-scaled softmax (τ_MoRAM), and a test-time threshold δ jointly enforce sparsity, sharpen specialization, and prune noisy activations. During continual learning, all previously learned atoms are frozen while new rank-1 pairs are appended, so the model incrementally expands its parametric memory 'little by little' without any extra regularization or load-balancing loss.

## Results

On the X-TAIL benchmark (10-domain CLIP continual learning), MoRAM achieves 72.7% Average accuracy and 80.9% Last accuracy, outperforming the strongest baselines CoDyRA (71.3%/79.2%) and RAIL-Primal (70.7%/79.1%) while also matching or exceeding their Transfer scores (63.3% vs. 63.2%/62.4%). On the TRACE LLM benchmark, MoRAM attains 44.54% Overall Performance with only 1.37% Backward Transfer on LLaMA-2-7B-Chat, surpassing TreeLoRA (43.52%/3.46%) and O-LoRA (42.78%/7.16%). In standard fine-tuning of Llama-3.1-8B on CodeAlpaca, MoRAM matches LoRA r=32 on HumanEval Pass@1 (47.56%) while improving MMLU out-of-domain accuracy to 63.70% using only 26.2M activated parameters (vs. 83.9M for LoRA r=32).

## Baselines & Comparisons

MoRAM outperforms all 23 baselines across the primary benchmarks. On X-TAIL (CLIP), it beats the closest competitor CoDyRA by 1.4% on Average (72.7 vs. 71.3) and 1.7% on Last (80.9 vs. 79.2), while also improving Transfer by 0.1%. On TRACE (LLMs), MoRAM achieves the best OP and lowest BWT across all three model backbones: on LLaMA-2-7B-Chat it gains +1.0% OP and reduces BWT from 3.46% (TreeLoRA) to 1.37%; on Gemma-2B-it it gains +2.5% OP over O-LoRA and cuts BWT from 12.36% to 2.74%. On the standard CL benchmark (T5-large, 5 tasks), MoRAM reaches 77.6% average accuracy, surpassing LB-CL (76.7%), O-LoRA (75.8%), and InfLoRA (75.5%), approaching the MTL upper bound of 80.0%. On the 15-task long-sequence benchmark, MoRAM (69.72%) edges out LB-CL (69.2%) and O-LoRA (68.8%). In the CodeAlpaca fine-tuning experiment, MoRAM matches LoRA r=32 on HumanEval (47.56%) while improving MMLU from 63.59% to 63.70% with roughly one-third the active parameters, and outperforms LoRI-D (43.2%) and LoRI-S (41.3%) on HumanEval Pass@1.

## Relation to Prior Work

MoRAM extends the LoRA-based Mixture-of-Experts line of work (Wu et al., 2024; Yu et al., 2024; Wang et al., 2025a) by challenging its fundamental granularity assumption: rather than treating each rank-r LoRA adapter as an indivisible expert, it decomposes updates into atomic rank-1 key-value pairs and routes over them individually. The conceptual grounding draws on Kohonen's (1972) linear associative memory, reframing weight matrices as content-addressable retrieval systems where each rank-1 component is a memory slot. This eliminates the external router entirely in favor of self-activation, where each atom's key vector intrinsically determines its relevance to the input—a shift from address-based routing to content-addressable retrieval that departs from both standard MoE and prior MoE-LoRA CL methods.

## Why It Matters / Open Questions

The elimination of learned routers in favor of self-activation is practically significant: it removes a source of optimization instability and routing collapse that plagues MoE-LoRA as the expert pool grows, and it reduces trainable parameters. The fine-grained rank-1 decomposition enables selective reuse of specific knowledge atoms across tasks, which the visualizations confirm (e.g., airplane-semantic atoms persisting across tasks). Open questions include whether the fixed temperature and threshold hyperparameters can be made input-adaptive, whether the approach scales to much larger expert pools (hundreds of tasks), and whether the associative-memory framing generalizes to non-linear or state-space architectures beyond standard transformer linear layers.

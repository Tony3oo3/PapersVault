## Problem

Existing conversational agent benchmarks like τ-bench are single-control environments where only the AI agent can invoke tools to modify the world, while the simulated user passively provides information. This fails to capture real-world collaborative scenarios such as technical support, where users must actively perform actions (e.g., toggling airplane mode, reseating a SIM card) under the agent's guidance, creating coordination and communication challenges that are entirely absent from current evaluations.
![Teaser figure](../imgs/ICML20260231/cropped_page1_idx0.webp)

## Input / Output

The benchmark takes an LLM agent (the model under evaluation) and an LLM user simulator, each equipped with a distinct set of domain-specific tools that read from and write to a shared database (e.g., agent-side CRM and user-side phone state). Tasks are generated programmatically by composing atomic subtasks defined by initialization, solution, and assertion function triples, ensuring verifiability by construction. Outputs include pass^k reliability scores across multiple independent runs, binary task success determined by environment state assertions, and a decomposed error diagnosis that separates pure reasoning failures (via a No-User ablation) from communication and coordination failures (via the Default dual-control mode).

## Method

The paper formalizes dual-control interaction as a Dec-POMDP with two players (agent and user), each possessing distinct action spaces (tool calls and natural-language messages) over a shared, partially observable state. A compositional task generator builds verifiable tasks from 15 atomic subtask groups using a root-cause factorization framework: each subtask activates a single root-cause predicate via initialization functions, resolves it via solution functions restricted to agent/user tools, and is verified by a shared assertion function, with the Decomposition Property guaranteeing completeness. The user simulator is tightly coupled to the environment—its tools yield only human-readable outputs and its planning is limited to reactive tool use based on agent requests—reducing the user simulator error rate from 40% (retail) to 16% (telecom). Ablation modes (No-User, Oracle Plan, Default) isolate reasoning from communication, revealing an ~20% pass^1 drop when agents must guide a user rather than act autonomously.

## Results

On the new dual-control telecom domain, pass^1 scores are substantially lower than on single-control baselines: gpt-4.1 drops from 74% (retail) and 56% (airline) to 34%, while o4-mini achieves 42% and claude-3.7-sonnet achieves 49%. Ablation experiments reveal that shifting from autonomous No-User mode to the Default dual-control mode causes an 18% pass^1 drop for gpt-4.1 and a 25% drop for o4-mini, isolating communication/coordination as a critical bottleneck. The telecom user simulator achieves a 16% total error rate (6% critical), a major improvement over τ-bench's retail (40%/12%) and airline (47%/13%) domains.

## Baselines & Comparisons

The paper's primary comparison is against τ-bench (Yao et al., ICLR 2025), whose retail and airline domains are re-included as single-control baselines. The key finding is that introducing dual-control (where the user also has tools and agency) causes a large performance drop: gpt-4.1's pass^1 falls from 74%/56% on retail/airline to 34% on telecom, a 40–22 point decrease. The ablation further decomposes this gap: moving from No-User (agent controls all tools) to Default (agent must guide a tool-equipped user) costs 18% pass^1 for gpt-4.1 and 25% for o4-mini, showing that the coordination/communication overhead—not pure reasoning—is the dominant failure mode. On the user simulator reliability axis, the telecom domain's tool-constrained user simulator (16% error, 6% critical) substantially outperforms the prompt-only user simulators in τ-bench's retail (40% error, 12% critical) and airline (47% error, 13% critical) domains, validating the dual-control design as a reliability improvement over the original benchmark.

## Relation to Prior Work

This paper directly extends τ-bench (Yao et al., ICLR 2025), which established a single-control benchmark for evaluating LLM agents in tool-agent-user interactions across retail and airline domains. The key conceptual departure is the introduction of a dual-control environment formalized as a Dec-POMDP, where the simulated user also possesses tools to observe and modify a shared environment, moving beyond the passive information-provider role of prior user simulators. Methodologically, it departs from τ-bench's hand-crafted task suites by introducing a compositional task generator based on atomic subtask factorization, and from prompt-only user simulation by constraining user behavior through environment-coupled tools. The work also positions itself against multi-agent benchmarks (e.g., MultiAgentBench) by emphasizing the inherent asymmetry between agent and user, and against user simulation literature by demonstrating that environment-based constraints outperform natural-language prompting for reliability.

## Why It Matters / Open Questions

The finding that agents suffer a ~20% pass^1 drop when shifting from autonomous (No-User) to dual-control (Default) mode identifies communication and coordination as a critical bottleneck distinct from pure reasoning, which has direct implications for deploying conversational agents in real-world support scenarios. The compositional task generator and tool-constrained user simulator offer a scalable, verifiable methodology for building new domains with lower human effort than prior benchmarks. Key limitations include the absence of an explicit expert-novice gap model, continued reliance on human experts for domain curation, and the fact that the tool-constrained user simulation approach has not yet been applied to the existing retail and airline domains. Open questions include how to automate domain creation end-to-end, how to model and evaluate the agent's ability to adapt explanations to user expertise levels, and whether the dual-control findings generalize beyond the telecom domain.

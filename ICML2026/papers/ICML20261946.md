## Problem

Existing LLM agent security benchmarks evaluate threats primarily through single-turn or static scenarios, failing to capture realistic adversaries that exploit extended multi-turn user-agent-environment interactions to achieve objectives infeasible within a single exchange. No dedicated benchmark existed for measuring agent susceptibility to adaptive, long-horizon attacks that incrementally erode safety guardrails over sustained interactions.
![Teaser figure](../imgs/ICML20261946/cropped_page2_idx0.webp)

## Input / Output

The benchmark feeds tool-enabled LLM agents (proprietary and open-weight) a benign user task within a realistic agentic environment (e.g., email, web shopping, code repositories), while an adversarial multi-agent system injects crafted prompts or observations across up to 20 interaction turns structured as quadruplets of (prompt, action, observation, response). Evaluation produces two primary metrics—Attack Success Rate (fraction of cases where the malicious objective is fully achieved) and Turn to Success (average turns required)—alongside full agent execution trajectories compared against ground-truth tool-call sequences by an LLM judge.

## Method

AgentLAB introduces a unified multi-agent attack framework with three coordinated LLM components: a planner (GPT-5.1) that decomposes the malicious task into executable strategies, an attacker (abliterated Qwen-3-14B) that iteratively crafts adversarial prompts or observations with TextGrad-based adaptive refinement when progress stalls, and a judge (GPT-5.1, greedy decoding) that deterministically evaluates task completion. This framework instantiates five distinct long-horizon attack families—intent hijacking, tool chaining, objective drifting, task injection, and memory poisoning—each exploiting a different temporal dimension of multi-turn interactions, from progressive user persuasion to cumulative environmental influence to persistent memory corruption. Task injection notably introduces intermediate bridging actions that connect benign and malicious tool sequences, making the transition appear contextually natural. The benchmark comprises 644 test cases across 28 tool-enabled environments and 9 risk categories, with a modular design supporting extensible addition of new attacks, agents, and defenses.

## Results

Across six LLM agents (Qwen-3, Llama-3.1, GPT-4o, GPT-5.1, Gemini-3, Claude-4.5), long-horizon attacks achieve overall Attack Success Rates (ASR) ranging from 28.9% (Claude-4.5) to 81.5% (Qwen-3), with tool chaining being the most universally effective attack (73.3%–96.3% ASR across all agents). Even frontier models like GPT-5.1 exceed 69.9% overall ASR, and the average ASR across all agents and attack types is approximately 63%. The Turn-to-Success (T2S) metric reveals that intent hijacking requires fewer turns (~4.6 for Qwen-3) than tool chaining (~8.5), reflecting task-level vs. action-level attack granularity.

## Baselines & Comparisons

Against the one-shot 'important message' attack from AgentDojo (Debenedetti et al., 2024), AgentLAB's long-horizon task injection substantially outperforms across most agents: GPT-4o ASR rises from 62.5% to 79.9%, Llama-3 from 50.7% to 86.8%, and GPT-5.1 from 2.1% to 21.5%, confirming that gradual multi-turn diversion is far more effective than direct single-shot injection. Regarding defenses, Self-Reminder (Zhang et al., 2024b) reduces intent hijacking ASR on Claude-4.5 from 27.2% to 6.9% but is far less effective against tool chaining on the same agent (73.3% → 57.9%), indicating that safety-prompt reminders do not transfer across attack types. Llama-Guard (Inan et al., 2023) shows similarly inconsistent protection, reducing tool chaining ASR on GPT-5.1 from 94.6% to 48.6% but offering minimal benefit for intent hijacking (59.8% → 55.4%). Overall, no single-shot defense reliably mitigates long-horizon attacks across all agent-attack combinations, with the best defense (Repeated Prompt on GPT-5.1 task injection) still leaving 2.8% ASR and the worst (Self-Reminder on Qwen-3 tool chaining) only reducing ASR from 96.3% to 81.5%.

## Relation to Prior Work

AgentLAB extends the agent security evaluation line from single-turn benchmarks (AgentDojo, InjecAgent, Agent-SafetyBench, SHADE-Arena) to the long-horizon, multi-turn regime, where adversaries adaptively craft attacks across extended interactions. Methodologically, it builds on X-teaming's (Rahman et al., 2025) adaptive multi-agent attack framework for intent hijacking and STAC's (Li et al., 2025) tool-chain decomposition for tool chaining, adding TextGrad-based iterative refinement and a unified planner-attacker-judge architecture across all five attack families. The key conceptual departure is temporal: prior benchmarks treat attacks as one-shot injections, while AgentLAB formalizes the adversary as operating across multiple turns with access to the agent's evolving state, memory, and environment.

## Why It Matters / Open Questions

AgentLAB is the first dedicated benchmark for long-horizon agent attacks, and its central empirical finding—that defenses validated on single-turn injections (Self-Reminder, Llama-Guard, Repeated Prompt, DeBERTa) systematically fail to transfer to multi-turn settings—challenges a core assumption in current agent safety practice. The near-universal vulnerability to tool chaining (>90% ASR on most agents) suggests that per-action safety checks are architecturally insufficient when threats are compositional. Open questions include whether long-horizon-aware defenses (e.g., XGuard-Train, AgentAlign) can close the gap, how findings transfer to production systems with noisy observations and partial tool failures, and whether the five-attack taxonomy captures the full adversarial strategy space (e.g., multi-agent collusion, social engineering chains).

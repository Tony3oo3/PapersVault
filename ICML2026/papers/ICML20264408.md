## Problem

Prior work on derivative-free optimization has not established optimal query complexities for estimating gradient directions using only comparison queries (which reveal only the sign of f(x)−f(y)). This paper fills that gap by providing tight upper and lower bounds for both gradient estimation and the related property-testing problem of gradient testing, in both classical and quantum query models.

## Input / Output

The algorithms take a point x ∈ R^n, query access to a comparison oracle O_f^comp that returns ±1 for any pair of points, a target accuracy ε, and a nondegeneracy lower bound γ on ||∇f(x)||. For gradient testing, a unit vector v is additionally supplied and the output is a Yes/No decision on whether the normalized gradient is ε-close or 2ε-far from v. For gradient estimation, the output is a unit vector h with ||h − ∇f(x)/||∇f(x)|| || ≤ ε. Both problems are scale-invariant: multiplying f by a positive constant leaves the comparison oracle and normalized gradient direction unchanged, so γ only sets the probing radius and does not affect query count.

## Method

The core primitive is directional preference (DP): a single comparison query between x and x + (2Δ/L)v certifies whether ⟨∇f(x), v⟩ is above or below a threshold Δ, reducing gradient estimation to sign queries on linear forms. The classical O(n log(1/ε)) estimator (Algorithm 3) first samples a Haar-random orthonormal frame to identify a dominant coordinate g_1 with constant overlap, then binary-searches each ratio g_i/g_1 using DP queries along directions w_i(β) = βe_1 − e_i; the key optimization exploits the constraint Σ|g_i/g_1|² ≤ O(1) to bound per-coordinate search intervals, cutting the cost from O(n log(n/ε)) to O(n log(1/ε)). The O(1) gradient testing algorithm (Algorithm 2) randomly samples directions in the orthogonal complement and uses sphere-concentration bounds on inner products to distinguish the two cases with constant probability. The quantum O(log(n/ε)) estimator (Algorithm 4) adapts Jordan's QFT-based gradient estimation by using binary search to approximate ⟨y,g⟩/⟨e_1,g⟩ for each grid point y, encoding the result as a relative phase in a superposition state, and then applying the inverse QFT to coherently extract all coordinate ratios in a single measurement.

## Results

The paper establishes optimal query complexities for gradient testing and estimation via comparison oracles: O(1) randomized queries for gradient testing, O(n log(1/ε)) for classical gradient estimation, and O(log(n/ε)) for quantum gradient estimation, with matching lower bounds for the first two. In numerical experiments on the extended Rosenbrock function (n=100, ε=0.2), Algorithm 3 achieves 100% success rate with average ℓ₂ error of 0.0072 (well below the ε=0.2 target) using ~926 comparison queries, and the empirical query count fits the theoretical O(n log(1/ε)) scaling with R²=0.999. When plugged into adaptive normalized gradient descent (ADANGD+OURS), the estimated direction yields objective 0.23 (with line search) and 2.6 (without) after 200 iterations, essentially matching the noise-free IDEAL ADANGD reference (0.23 and 3.1).

## Baselines & Comparisons

In the optimization experiment on the extended Rosenbrock function (n=100, 200 iterations, ε=0.2), ADANGD+OURS (using the paper's comparison-based gradient estimator) essentially matches the noise-free IDEAL ADANGD reference: 0.23 vs. 0.23 with line search, and 2.6 vs. 3.1 without. In stark contrast, all three comparison-based baselines—ZO-SGD (Nesterov & Spokoiny, 2017, two-point Gaussian smoothing with m=100 probes), ZO-RANKSGD (Tang et al., 2024, (m,k) ranking oracle with m=k=100), and SCOBO (Cai et al., 2022, m=100 pairwise sign comparisons)—stall at objective values exceeding 10, orders of magnitude above the optimum. The paper's estimator thus achieves near-exact-gradient performance under a per-iteration comparison budget comparable to the baselines, demonstrating that the O(n log(1/ε)) comparison queries suffice to recover a direction accurate enough for adaptive NGD to converge at the same rate as full gradient access.

## Relation to Prior Work

This paper extends the comparison-oracle model from derivative-free optimization (Nelder-Mead, direct-search methods, and more recently Karabag et al. 2021 and Cai et al. 2022) by pinning down the optimal query complexity for gradient direction estimation, improving the prior O(n² log n) bound to the optimal O(n log(1/ε)). It adapts Jordan's (2005) QFT-based quantum gradient estimation to the restricted comparison oracle setting, where only sign information about directional preferences is available rather than full inner-product queries. The paper also introduces gradient testing as a property-testing problem in continuous optimization—a framing the authors note is largely absent from prior work—and connects the directional-preference primitive (from Karabag et al.) to both classical and quantum algorithms.

## Why It Matters / Open Questions

The optimal O(n log(1/ε)) classical and O(log(n/ε)) quantum query complexities establish tight characterizations of what is achievable with the most information-poor oracle in smooth optimization, providing a theoretical foundation for comparison-based methods in NISQ-era quantum computing where simpler queries are more implementable. The O(1) randomized gradient testing result is a clean separation from the Ω(n) deterministic lower bound, highlighting the power of randomization in continuous property testing. Key open questions include closing the quantum gap between O(log(n/ε)) and Ω(log(1/ε)), extending to stochastic/noisy comparison oracles, and demonstrating end-to-end optimization speedups beyond the local estimation primitive.

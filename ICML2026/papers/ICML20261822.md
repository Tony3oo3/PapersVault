## Problem

Standard pixel-level evaluation metrics for Visual Anomaly Detection (precision, recall, F1, IoU, MCC) treat pixels as independent units and are blind to the topological structure of predictions, yielding identical or misleading scores for qualitatively different outputs such as fragmented versus coherent detections or spatially dispersed versus localized false alarms. The paper formalizes this gap by defining eight verifiable properties that a VAD metric should satisfy and proving that no existing threshold-dependent metric fulfills the full suite.

## Input / Output

The metric consumes a binary predicted anomaly segmentation map and a binary ground-truth anomaly segmentation map over a shared H×W pixel grid. It first decomposes both maps into maximal connected components under L1-connectivity, then computes an object-level score that is normalized via tanh to lie in [-1, 1]. The output is a single scalar where higher values indicate better spatially coherent, non-redundant detection performance.

## Method

SAAM-ALARM extends the ALARM metric from time-series anomaly detection to the image domain by operating on connected components rather than individual pixels. For each ground-truth component, it computes a spatially modulated reward (αᵢ) that multiplies IoU with a Gaussian-weighted sum over the overlap, where weights decay with distance from the component's center of minimum eccentricity, thereby rewarding central localization. Redundant detections of the same anomaly are penalized via an exponential discount b^(max(0, nᵢ−1)) on the reward, where nᵢ is the number of candidate predictions matching that component. Unmatched false-positive components incur a proximity-weighted penalty ωⱼ·(λ + β(Pⱼ)), where ωⱼ increases with the minimum Euclidean distance to the nearest ground-truth anomaly and β scales with the component's area relative to total anomaly area. The paper proves SAAM-ALARM satisfies all eight formal properties (P1–P8) and demonstrates through controlled case studies and MVTec AD / VisA benchmarks that it produces more consistent and inspection-aligned model rankings than conventional metrics.

## Results

The central finding is that none of the six widely used threshold-dependent VAD metrics (Precision, Recall, F1, IoU, CA, MCC) satisfy all eight proposed structural properties (P1–P8); the best-performing existing metric (CA) satisfies only 3 of 8, while MCC satisfies only 1. The proposed SAAM-ALARM metric provably satisfies all 8 properties. In controlled case studies on MVTec-AD, SAAM-ALARM assigns a score of 0.2500 to a redundant (fragmented) prediction versus 0.5002 for a single coherent detection, while pixel-level metrics (Precision, Recall, F1, IoU) score both identically. In model ranking experiments on MVTec AD, SAAM-ALARM ranks DestSeg as the top model (−0.24), whereas Recall-based ranking incorrectly elevates Dinomaly (0.96) and Pyramid-Mamba (0.93), and F1/MCC rank UniAD (the SAAM top performer) at 5th/6th place.

## Baselines & Comparisons

The paper evaluates six existing metrics against eight formal properties. Precision is the weakest, satisfying only P7 (prediction size) and failing all other seven properties, including the basic requirement that detecting an existing anomaly should improve the score (P1). Recall, F1-score, and IoU all satisfy P1 and P7 but are entirely blind to redundancy (P2), false-alarm count (P4), distance-aware severity (P5), and centrality (P8). Classification Accuracy (CA) is the strongest existing metric, additionally satisfying P3 (minimize false positives), yet still fails on redundancy, alarm count, distance, FP type, and centrality. MCC is the most limited, satisfying only P3 and failing even P1 (existing predictions) and P7 (prediction size). SAAM-ALARM is the only metric that satisfies all eight properties, and in empirical model-ranking experiments it produces rankings that diverge substantially from those induced by any single conventional metric, revealing that standard metrics can misrank models by up to 4–5 positions (e.g., UniAD ranked 1st by SAAM but 5th by F1 and 6th by Recall).

## Relation to Prior Work

This paper directly extends the property-based evaluation framework introduced by Wagner et al. (2025) for time-series anomaly detection, transplanting the ALARM metric and axiomatic verification methodology into the visual domain. It departs from the dominant VAD evaluation paradigm—which relies on pixel-level metrics (precision, recall, F1, IoU) and threshold-independent curves (AUROC, AUPRC, AUPRO)—by treating evaluation metrics themselves as objects of formal verification rather than empirical conventions. The formalization of object-level alarm semantics (each connected component triggers an independent inspection) is a key conceptual departure from the pixel-wise independence assumption underlying all standard VAD metrics.

## Why It Matters / Open Questions

The proof that no widely used VAD metric satisfies all eight proposed properties reveals a structural gap in how the field benchmarks models, with practical consequences: model rankings shift dramatically under SAAM-ALARM (e.g., UniAD vs. Dinomaly vs. DestSeg), suggesting that current leaderboard comparisons may be misleading for safety-critical deployment. Open questions include whether the eight properties are the correct and complete set of requirements, whether the object-level alarm semantics assumption generalizes to all industrial settings, and whether the SAAM-ALARM hyperparameters (b, k, λ) can be set in a principled rather than empirical manner. The framework also raises the question of whether threshold-independent metrics (AUROC, AUPRO) should be subject to analogous formal analysis.

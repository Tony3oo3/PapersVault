## Problem

While the feasible set of value functions in fully observable MDPs is known to be a polytope, the corresponding geometric structure for partially observable MDPs (POMDPs) remained unexplored. Partial observability introduces intrinsic coupling between decision variables through the observation kernel, making the feasible set fundamentally non-polyhedral. This paper addresses the gap by providing an explicit geometric characterization of the feasible value function set in the POMDP setting.

## Input / Output

The method takes a finite POMDP specification—transition kernel α, observation kernel β, reward function r, and discount factor γ—and produces a quantifier-free semi-algebraic description of the feasible value function set as a finite union of sets stratified by the rank of a coefficient matrix C(x). Each stratum is defined by polynomial equalities (vanishing minors), a non-vanishing determinant condition, and sign-polynomial inequalities derived via Cramer's rule. The boundary of the feasible set is further characterized as the solution set of Dq = C with |q| ≤ 1, yielding explicit determinantal curves in low-dimensional cases.

## Method

The core technique reformulates the Bellman equation as a parametric linear system with affine linear parameterization in the memoryless policy, then represents the policy polytope as an intersection of hyperrectangle-parametrized sets to apply Hladik's necessary-and-sufficient condition for parametric linear systems. This yields an infinite family of piecewise linear inequalities (Theorem 3.9), which is then converted to a finite description by recognizing that the midpoint residual must lie in the zonotope generated by the deviation columns (Theorem 4.2). The zonotope membership is decomposed into a column-space containment condition (polynomial equalities via vanishing minors) and facet-defining inequalities (polynomial inequalities via Cramer's rule), producing an explicit semi-algebraic set stratified by rank (Theorem 4.4). The key structural insight is that partial observability collapses the polyhedral structure of MDPs into a semi-algebraic set with curved boundaries, which empirically gives rise to multiple local optima and initial-distribution-dependent optimal policies.

## Results

The paper's main contribution is theoretical: Theorem 4.4 provides an explicit quantifier-free semi-algebraic description of the feasible value function set for any POMDP, stratified by rank ρ of the coefficient matrix C(x), with polynomial conditions of degree at most ρ+1. Empirically, across randomly generated POMDPs with 50 policy gradient restarts, partial observability consistently induces substantial spread in both achieved values and resulting policies, while the fully observable baseline exhibits negligible spread. The fraction of (instance, ρ) pairs exhibiting multiple distinct local optima increases with the number of states S, and the mean number of distinct local optima also grows with S. Increasing policy memory (via observation enhancement) reduces value spread but does not eliminate the optimization difficulties induced by partial observability.

## Baselines & Comparisons

This is a theoretical paper without a traditional method-vs-baseline comparison. The structural 'comparison' is between fully observable MDPs, where Dadashi et al. (2019) showed the feasible value function set is a union of convex polytopes (hence polyhedral), and partially observable POMDPs, where this paper shows the set is semi-algebraic with fundamentally nonlinear (polynomial) boundary constraints. The paper also extends Müller & Montúfar (2022), who derived semi-algebraic descriptions for state-action occupancy measures in POMDPs, to the value function itself. The key qualitative finding distinguishing the two settings is that in MDPs the optimal policy is invariant to the initial state distribution ρ, whereas in POMDPs optimal policies can differ across choices of ρ and isolated local maximizers of the long-term reward emerge, a phenomenon absent in the polyhedral MDP case.

## Relation to Prior Work

This paper extends the polyhedral characterization of feasible value functions from fully observable MDPs (Dadashi et al., 2019) to the partially observable setting, where the structure is fundamentally nonlinear. The mathematical machinery is drawn from the theory of parametric interval linear systems (Hladik, 2012), which provides the Oettli-Prager-style necessary-and-sufficient conditions for solution sets of systems with affine parameter dependence. The work also builds on Müller & Montúfar (2022b), who showed value functions are rational functions of policy parameters in POMDPs and obtained a semi-algebraic description of occupancy measures; here the authors carry that framework through to the value function set itself, replacing the polytope with a semi-algebraic set whose boundary is defined by explicit determinantal conditions.

## Why It Matters / Open Questions

The result provides the first global geometric characterization of feasible value functions in POMDPs, explaining at a structural level why policy optimization is fundamentally harder under partial observability: the feasible set has curved, nonlinear boundaries rather than flat facets, which permits isolated local optima and makes the optimal policy depend on the initial state distribution. The empirical experiments confirm that multiple local optima are the norm rather than the exception across randomly generated POMDPs. Key limitations include the restriction to memoryless stochastic policies and discounted infinite-horizon settings, and the characterization is primarily structural—it does not yet yield efficient algorithms. Extending the framework to belief-state policies or finite-memory policies, and developing optimization methods that exploit the identified semi-algebraic geometry, are natural open directions.

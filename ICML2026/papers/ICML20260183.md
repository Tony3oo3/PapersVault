## Problem

Standard GCNs aggregate neighbor features with uniform weights, making it difficult to capture discriminative global node importance for graph-level tasks. Existing remedies—local attention (GATs) and global self-attention (Transformers)—either remain confined to local neighborhoods or introduce parameterized pairwise attention with O(n²) memory cost. The paper seeks a lightweight, parameter-free global interaction mechanism that identifies graph-level critical nodes without additional learnable attention weights.

## Input / Output

The model accepts attributed or unattributed graphs where node features are one-hot encodings of node labels (or node degrees for unattributed graphs) and the adjacency matrix defines the topology. Node embeddings are fixed at 32 dimensions across 2–4 stacked GI-GCN layers, and a mean readout produces a single graph-level vector that is classified into one of the target classes. The method is evaluated on both small-scale benchmarks (MUTAG, PTC_MR, PROTEINS, DD, IMDB-B, IMDB-M) and large-scale molecular/protein datasets (ZINC, OGB-MolHIV, OGB-PPA).

## Method

GI-GCN integrates Dominant Set replicator dynamics into each convolutional layer to produce a continuous node-importance distribution over the entire graph. At every layer, a topology-independent Pearson correlation matrix is computed from centered-and-normalized node features, then the Dominant Set quadratic program is solved via replicator dynamics to yield a probability vector on the simplex that progressively concentrates on dominant nodes. This importance vector element-wise modulates node features before a standard GCN convolution with the normalized adjacency matrix, injecting global guidance into local message passing without altering graph structure. A key technical contribution is a memory-efficient reformulation that rewrites the Dominant Set update as a quadratic form in the f-dimensional feature space (via a weighted outer-product matrix M), reducing auxiliary storage from O(n²) to O(f²) and making the method scalable to large graphs. No additional learnable attention parameters are introduced; the importance distribution is driven entirely by feature similarity and optimization dynamics.

## Results

On the six standard graph classification benchmarks, GI-GCN achieves 87.99% on MUTAG, 59.16% on PTC_MR, 79.97% on PROTEINS, 88.24% on DD, 80.58% on IMDB-B, and 55.91% on IMDB-M (10-fold CV, mean ± SE). On the large-scale ZINC regression benchmark, GI-GCN achieves a MAE of 0.211, and on OGB-MolHIV it reaches 79.19% AUROC. The optimized implementation reduces GPU memory from O(n²) to O(f²), cutting memory by ~70% on the DD dataset (9716 MB → 476 MB) while adding only ~1.27% runtime overhead.

## Baselines & Comparisons

GI-GCN achieves the best accuracy on four of six standard benchmarks: PROTEINS (79.97% vs. best GNN GraphiT 75.6% and best kernel GK-X 75.42%), DD (88.24% vs. best GK-C 80.03%), IMDB-B (80.58% vs. best GWRNN 72.8%), and IMDB-M (55.91% vs. best RWGK 46.72%), with margins of 4.4–9.2 percentage points over the strongest competing method. On MUTAG and PTC_MR, GI-GCN is competitive but slightly trails the strongest graph kernels (AEGK 89.11% and GK-X 61.24% respectively), though it outperforms all GNN baselines on both. On the large-scale OGB-MolHIV benchmark, GI-GCN (79.19% AUROC) surpasses GraphGPS (78.80%) and Specformer (78.89%) while remaining below PST (80.32%); on ZINC it achieves MAE 0.211, competitive with GraphiT (0.202) and GT (0.226) but well below the highly parameterized GraphGPS (0.070) and GRIT (0.059). A key practical advantage is that GI-GCN introduces no additional learnable attention parameters and reduces memory from O(n²) to O(f²), enabling it to process the DD dataset (avg. 284 nodes) within 476 MB GPU memory where Transformer-based baselines run out of memory.

## Relation to Prior Work

GI-GCN builds on the standard GCN convolution (Kipf & Welling, 2017) as its local message-passing backbone and repurposes the Dominant Set replicator dynamics (Pavan & Pelillo, 2007)—previously employed as an offline tool for graph clustering and pooling—as a layer-wise, continuous node-importance distribution that modulates features before convolution. Conceptually, it departs from the dominant global-interaction paradigms of graph attention (GAT) and graph Transformers (Graphormer, GraphGPS, GraphiT), which rely on parameterized pairwise attention with O(n²) memory, by deriving global importance purely from feature-induced Pearson correlations and optimization dynamics without any additional learnable attention parameters. The memory-efficient reparameterization (Section 3.5) further distinguishes it from virtual-node, spectral-convolution, and linear-attention approximations by grounding global interaction in a quadratic-programming solution rather than architectural augmentation.

## Why It Matters / Open Questions

The parameter-free, optimization-driven global interaction mechanism offers a practical middle ground between lightweight local GCNs and heavy Transformer-based graph models, with the O(f²) memory reformulation making global modeling feasible on large graphs where Transformers hit OOM. However, on large-scale benchmarks (ZINC, OGB-MolHIV) GI-GCN remains competitive but not state-of-the-art, and the authors acknowledge that the absence of explicit edge-attribute modeling limits performance on datasets like ZINC. Open questions include whether the Dominant Set dynamics generalize to heterogeneous or dynamic graphs, whether the Pearson-correlation-based similarity is sufficient for all feature spaces, and whether the iterative convergence behavior degrades with very deep stacks or extremely large node counts.

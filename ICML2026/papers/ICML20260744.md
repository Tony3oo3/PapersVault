## Problem

Regular Graph Random Features (GRFs) approximate graph node kernels via random walks, but they suffer from two key limitations: (1) modeling relationships between distant nodes requires long walks, which are inherently sequential and computationally expensive on modern accelerators, and (2) the walk-termination mechanism is restricted to Bernoulli schemes with fixed halting probabilities, which is suboptimal under a fixed computational budget. This paper introduces GRFs++ to resolve both issues while preserving unbiasedness.

## Input / Output

The method consumes a weighted adjacency matrix W ∈ R^{N×N}, a node degree vector, a kernel-dependent modulation function f (which must satisfy a 2l-level discrete convolution condition tied to the target kernel's Taylor coefficients), a discrete termination distribution P over walk lengths, and a number of random walks m. It produces two factor matrices X, Y ∈ R^{N×N} (or R^{N×r} after Johnson-Lindenstrauss projection) such that K_α(W) ≈ XY^T in expectation. The factorization is structured as a product of l sparse matrix pairs, enabling O(N) matrix-vector products for constant l, and the resulting node embeddings can be directly plugged into attention masks, spectral clustering, or kernel-based classifiers.

## Method

GRFs++ introduces two complementary refinements over regular GRFs. First, a walk-stitching mechanism replaces a single long random walk with l independently sampled pairs of shorter walks, combined via matrix-matrix multiplication; the modulation function f is obtained by 2l-de-convolving the kernel's coefficient sequence (e.g., for the diffusion kernel exp(λW), f(p) = λ^p / ((2l)^p p!)). Second, the Bernoulli halting scheme is generalized to any discrete distribution P on walk lengths, with the per-step update normalized by the survival function τ(k) = P(X ≥ k). The full (l, P)-GRFs++ estimator is unbiased (Lemma 3.1), its MSE for degree l=2 admits a closed-form Frobenius-norm expression (Lemma 3.2), and approximation quality monotonically improves as the stitching degree doubles (Theorem 3.3). Three implementation options are provided: direct sparse matrix products, JLT-projected dense matrices for dimensionality reduction, and implicit right-to-left matrix-vector multiplication for applications requiring only kernel-vector products.

## Results

On graph classification (Table 12), GRF++ matches or exceeds the exact diffusion kernel baseline on 6 of 8 datasets (e.g., NCI-1: 75.47% vs 71.45% baseline) while consistently outperforming regular GRFs by 1.5–3.5 percentage points. In the GraphGPS/Performer setting (Table 5), GRF++ improves over the Performer baseline on all six benchmarks, e.g., CIFAR-10: 70.21% vs 69.96%, and Peptides-func: 26.61 vs 27.84 (lower is better). For mesh normal prediction (Table 2), GRF++ achieves cosine similarity within 0.004–0.009 of brute-force across all mesh sizes while running 5–8× faster (Table 1: 314s vs 1,662s at 11,700 nodes; brute force times out at 35,300 nodes while GRF++ completes in 5,591s). On ImageNet, the GRF++-augmented ViT reaches 80.31% top-1 accuracy vs 80.10% for the standard ViT.

## Baselines & Comparisons

Against regular GRFs (Reid et al., 2024b), GRF++ wins on every reported metric: lower Frobenius-norm kernel approximation error (Fig. 2), higher graph classification accuracy on all 8 datasets (Table 12, +1.5 to +3.5 pp), lower node clustering error on all 6 graphs (Table 4, e.g., Eurosis: 0.1304 vs 0.2248), higher cosine similarity on mesh normals (Table 2), and better GraphGPS performance (Table 5). Against the standard ViT (Dosovitskiy et al., 2021), the GRF++-augmented variant gains +0.21 pp on ImageNet (80.31 vs 80.10) and +0.25 pp on Places365 (56.03 vs 55.78). Against the Performer backbone in GraphGPS (Rampašek et al., 2022), GRF++ improves on all six benchmarks, with the largest gain on Peptides-func (26.61 vs 27.84, lower is better). Against GNN baselines (DGCNN, GraphSAGE, DiffPool, GIN) in Tables 8–9, GRF++ is competitive but not directly comparable since it constructs an intra-graph node kernel while those methods use inter-graph kernels; the authors note this caveat explicitly. Against brute-force kernel computation, GRF++ achieves 5–8× speedup on meshes and remains tractable at 35,300 nodes where brute force times out entirely.

## Relation to Prior Work

This paper directly refines the Graph Random Features (GRFs) framework introduced by Choromanski (ICML 2023) and generalized by Reid et al. (ICLR 2024), which approximate graph node kernels via unbiased random-walk-based feature mappings. The key departure is the walk-stitching mechanism, which composes multiple independently sampled short walks through matrix-matrix multiplication to emulate a single long walk, replacing inherently sequential sampling with parallelizable computation. A second contribution generalizes the walk-termination scheme from fixed-probability Bernoulli halting to arbitrary discrete distributions (e.g., Poisson), with a corresponding modification to the modulation function via 2l-level de-convolution of the kernel's Taylor coefficients. The method also inherits the Johnson-Lindenstrauss Transform for dimensionality reduction, connecting it to the broader random-features-for-kernels literature.

## Why It Matters / Open Questions

Graph kernel computation scales cubically in the number of nodes, making exact methods intractable for large graphs; GRFs++ provides a principled sub-quadratic approximation that handles meshes with 35K+ vertices where brute-force computation times out. The walk-stitching idea is practically important because it converts a sequential bottleneck (long random walks) into parallel short walks plus sparse matrix multiplication, which maps naturally to GPU/TPU accelerators. Open questions include: (1) the empirical finding that reusing the same random walks across stitching components (violating the independence assumption) performs well in practice but lacks theoretical justification; (2) extension to node-labeled graphs, where the current diffusion kernel ignores label information; and (3) whether the de-convolution-based modulation function construction remains stable for kernels with rapidly growing Taylor coefficients.

## Problem

Existing benchmarks for LLM code generation either evaluate static web pages, algorithmic logic via unit tests, or text-only scientific reasoning, but none assess the combined challenge of producing a functionally interactive, scientifically accurate, and visually correct web application. The paper identifies a critical integration gap: state-of-the-art models can explain Newton's second law or generate a blog webpage independently, yet fail when asked to produce an interactive inclined-plane simulation with correct physics logic and working UI controls. This gap is compounded by the absence of reliable automated evaluation mechanisms that verify both interaction correctness and visual scientific fidelity simultaneously.

## Input / Output

The model receives a structured implementation plan (~2,000–2,600 tokens) specifying five components: page layout, HTML element inventory, component IDs with default values/ranges/steps, interaction logic (how controls trigger DOM updates and visual redraws), and visualization techniques (e.g., D3.js, three.js, MathJax). The expected output is a single self-contained HTML file with inline CSS and JavaScript that renders in a browser without external dependencies beyond CDN libraries. Evaluation produces two score families: PFT yields binary pass/fail per unit test (aggregated as OPR, APR, PPR), while VQT yields a CLIP cosine similarity score, a VLM-Judge semantic score (1–5 rescaled to 0–100), and an Action Success Rate measuring whether the generated app survives the scripted interaction sequence without crashing.

## Method

The core contribution is a hybrid evaluation framework combining Programmatic Functional Testing (PFT) and Visually-Grounded Qualitative Testing (VQT). PFT uses Playwright to execute deterministic sequences of simulated user actions (clicks, slider drags, input) followed by binary DOM-state assertions, catching event-handling and state-update bugs invisible in a single screenshot. VQT executes action-only scripts to reproduce specific visual states, captures a generated screenshot, and scores it against a Wolfram-sourced reference snapshot via CLIP (perceptual similarity) and a checklist-guided VLM-as-judge (Gemini-2.5-Pro) that verifies scientific correctness point-by-point. The benchmark comprises 150 problems across five disciplines (math, physics, chemistry, earth science, CS) at three difficulty levels, with 779 PFT and 590 VQT unit tests totaling 1,369 executable checks. The evaluation suite (plans, test scripts, checklists) is synthesized by Gemini-2.5-Pro from Wolfram Demonstrations Project metadata and snapshots, then validated through rule-based filtering, human review, and a 30-problem manual rating experiment (all components scoring >4/5). The two tracks are designed to be complementary—Spearman correlations between PFT and VQT scores remain below 0.32—ensuring that a model passing functional tests can still fail on scientific rendering and vice versa.

## Results

On InteractScience (150 problems, 1,369 executable tests), the best closed-source models achieve PFT Overall Pass Rates of 41.47% (Claude-Sonnet-4) and 39.47% (GPT-5), with Perfect Pass Rates never exceeding 16.08%. On the visual side, VLM-Judge scores peak at 57.02 (GPT-5) and 55.42 (Claude-Sonnet-4), while CLIP scores reach 73.50 (Claude-Sonnet-4). Action Success Rates are consistently high (>85% for most models), revealing a critical gap: models reliably generate functional UI widgets but frequently fail to bind them to correct scientific logic, with VLM-Judge scores typically below 60 across all 30 evaluated models.

## Baselines & Comparisons

Claude-Sonnet-4 leads on PFT OPR (41.47%) and CLIP (73.50), while GPT-5 achieves the highest VLM-Judge score (57.02) and PFT PPR (16.08%), making them the two strongest overall. GPT-4.1 (37.07% OPR) and o4-mini (37.33% OPR) trail the leaders by ~4 points on PFT but remain competitive on VLM-Judge (~52). Gemini-2.5-Pro (35.33% OPR, 54.69 VLM-Judge) sits mid-pack among closed-source models, notably below Claude-Sonnet-4 on PFT despite being the synthesis model for the benchmark. Among open-source models, DeepSeek-R1-0528 (33.87% OPR) and Qwen3-235B-A22B (33.33% OPR, 13.29% PPR) approach mid-tier proprietary performance, while smaller models (≤14B) drop sharply—Qwen3-8B reaches only 20.00% OPR and 34.67 VLM-Judge, and Qwen3-1.7B falls to 6.53% OPR. A striking cross-model pattern is the ASR–VLM-Judge gap: even top models achieve >89% ASR yet score <58 on VLM-Judge, confirming that functional interactivity does not translate to scientific correctness. The paper also shows that adding reference snapshots as multimodal input yields only modest gains (e.g., GPT-5 PFT rises from 39.47% to 42.53%), indicating the bottleneck is grounding visual states in correct scientific semantics rather than matching visual style.

## Relation to Prior Work

This paper carves new ground by repurposing two established evaluation paradigms—deterministic unit testing from software engineering (Playwright-based DOM assertions) and vision-language model judging from visual evaluation—into a unified hybrid protocol specifically designed for interactive scientific demonstrations. It departs from prior scientific visualization benchmarks (SridBench, EduVisBench) that assess only static figures, and from web code generation benchmarks (Interaction2Code, ArtifactsBench, WebGen-Bench) that verify interactivity but lack scientific domain grounding. The checklist-guided VLM-as-judge design, anchored to external reference snapshots from the Wolfram Demonstrations Project, addresses a known weakness of unguided VLM scoring identified in prior work (Gu et al., 2024; Li et al., 2024).

## Why It Matters / Open Questions

InteractScience exposes a critical 'superficial competence' gap: models reliably produce functional UI shells (ASR > 85%) but frequently generate scientifically incorrect visualizations (VLM-Judge < 60), with logic/scientific errors being the dominant failure mode (53%). This finding has direct implications for deploying LLMs in educational settings, where visually plausible but physically wrong demonstrations could mislead learners. Key limitations include the small dataset (150 problems), Wolfram-specific visual style, static-screenshot-only evaluation (no temporal/animation assessment), and LLM-synthesized test suites validated by only a small group of graduate students. Open questions include whether the evaluation framework transfers to other simulation platforms (PhET, GeoGebra), whether agent-driven testing can replace scripted Playwright actions for broader coverage, and how to incorporate video-based judging for dynamic scientific phenomena.

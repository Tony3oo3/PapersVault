## Problem

Self-attention's quadratic complexity makes it the dominant bottleneck during LLM prefilling for long contexts. Existing dynamic sparse attention methods (MInference, FlexPrefill, SpargeAttn) inspect the attention map only coarsely—via representative tokens or a few sampled query rows—so they miss fine-grained important regions and achieve a suboptimal accuracy-efficiency trade-off. No prior method performs a holistic, element-wise importance analysis across the entire attention map while keeping the inspection overhead low enough to be practical.

## Input / Output

SALE consumes the standard Q, K, V matrices (each N×d) for a long prefill sequence and produces a block-level sparse mask M_bs of shape N_q×N_k (with b_q=64, b_k=32) plus the sparse attention output computed only over retained blocks. The sink region is fixed at 32 tokens and the local region at up to 256 tokens per row; a per-head threshold τ (calibrated offline via L1 error bound θ) determines which blocks are skipped. The method is training-free and requires only a trivial code swap in the attention module of an existing inference pipeline.

## Method

SALE estimates attention weights element-wise using 4-bit quantized QK products, exploiting high-throughput INT4 Tensor Core instructions (8× faster than FP16) and reduced DRAM bandwidth. Instead of materializing full softmax scores, it introduces a Relative Attention Score that compares each position's approximated weight against the max (m̃_i) and sum-of-exponentials (l̃_i) computed from the always-attended sink and local regions, so importance is judged relative to the row's known high-scoring anchors. A block is skipped only if every element's Relative Attention Score falls below a per-head threshold τ, which is calibrated offline by halving τ until the L1 output error drops below a user-specified bound θ. The CUDA kernel uses a two-pass design (Selection-Pass records important block coordinates; Computation-Pass computes attention on those blocks) built on FlashAttention2-style CTA tiling, and applies a log-domain algebraic transformation to reduce the per-element importance test to a single floating-point comparison, avoiding costly division and exponential operations.

## Results

On LongBench with Llama-3.1-8B, SALE achieves an average score of 48.39 (vs. 48.77 for full FlashAttention2) while delivering a 3.36× speedup at 64K context length. On RULER, SALE actually surpasses full attention (84.67 vs. 83.86 average across 8K–128K), and on InfiniteBench it matches FA2 (37.11 vs. 37.75) with the same 3.36× speedup. For Qwen3-4B, SALE achieves 46.37 on LongBench (vs. 46.68 FA2) with a 3.63× speedup. The overhead of the Selection-Pass (quantization + block selection) is only ~11% of full attention latency at 64K, and the Computation-Pass alone achieves 5.57× speedup over FA2 at 64K.

## Baselines & Comparisons

SALE outperforms all four sparse attention baselines on both accuracy and speedup across all three benchmarks. Against MInference (1.07× speedup), SALE achieves a 3.1× greater speedup while also scoring higher on average (e.g., 48.39 vs. 47.03 on LongBench Llama-3.1; 84.67 vs. 81.41 on RULER). Against FlexPrefill (2.21×), SALE delivers 1.15× more speedup and a 2.2-point accuracy gain on LongBench, with the gap widening on Qwen-3 (46.37 vs. 40.99). Against SpargeAttn (3.11×), SALE edges ahead on both metrics (48.39 vs. 47.48 accuracy; 3.36× vs. 3.11× speedup on Llama-3.1). Compared to SageAttention's INT8 quantized full attention (which already provides ~1.6× speedup over FA2), SALE delivers an additional 1.06×–2.39× speedup that grows with context length, confirming that block skipping is complementary to quantization. Notably, on RULER at 128K, SALE (74.81) exceeds even full FlashAttention2 (72.43), suggesting that sparse attention can filter noisy attention patterns.

## Relation to Prior Work

SALE extends the block-sparse attention line of work (MInference, FlexPrefill, SpargeAttn) by replacing their coarse-grained or incomplete attention map inspection with a fine-grained, element-wise importance analysis. Its two key departures are: (1) using 4-bit quantized QK products on Tensor Cores to approximate attention weights at near-full-precision recall (95–98%), and (2) introducing a Relative Attention Score metric that compares each query-key pair against the sink and local regions rather than relying on absolute softmax scores, thereby avoiding materialization of the full attention map in DRAM. The Computation-Pass reuses SageAttention's 8-bit quantization, and the kernel is built on the FlashAttention2 tiling framework, making SALE a composition of existing building blocks arranged in a novel two-pass pipeline.

## Why It Matters / Open Questions

For practitioners deploying long-context LLMs (≥64K tokens), SALE offers a training-free, drop-in acceleration that achieves 3.36×–3.63× prefill speedup with negligible accuracy loss, which is directly deployable on current RTX 4090/5090 hardware. The main limitations are that it provides no benefit below ~8K tokens (overhead exceeds savings), does not address decoding-bound workloads, and depends on 4-bit Tensor Core support—ruling out older GPUs and requiring adaptation for emerging FP4/LUT-based hardware. An open question is how well the per-head threshold calibration generalizes across model families and whether the sink/local-region assumption holds uniformly for all architectures.

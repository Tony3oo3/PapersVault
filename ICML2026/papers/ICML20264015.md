## Problem

Standard conformal test martingales (CTMs) for distribution-shift detection suffer from test-time contamination: after a shift, post-shift observations enter the growing reference set, diluting evidence and increasing detection delay. Naively fixing the reference set to avoid contamination breaks the i.i.d. structure of conformal p-values due to finite-sample ECDF estimation error, inflating the type-I error rate. No existing CTM-based method simultaneously avoids contamination, maintains valid error control, and provides power guarantees.

## Input / Output

The method consumes a fixed reference set D_0 of n univariate scores (e.g., classifier entropies on clean images) and a sequential stream of test scores X_t, along with a test level α and a CDF confidence level δ. It produces an anytime-valid sequential reject/fail-to-reject decision by monitoring a non-negative wealth martingale S_t against the threshold 1/α, yielding a detection time τ. The reference set is never updated with test-time observations, and the scoring function ŝ is fixed, so the test is valid for arbitrary distribution shifts in the underlying raw data Z_t.

## Method

The conditional CTM replaces the standard CTM's growing reference set D_t with a fixed D_0, computing conformal p-values p̂_t = F̂_0(X_t) from the ECDF of D_0. To handle the resulting estimation error, the paper introduces a corrected betting function b_t(p̂_t) = 1 + C·(η_t(p̂_t − 0.5) − √(η_t² + k²)·ε(p̂_t)), where ε(·) is a uniform confidence band (e.g., DKW) around the true CDF and the |η_t|·ε(p̂_t) term removes gains attributable solely to estimation noise. The betting parameter η_t is learned online via the Online Newton Step algorithm applied to a twice-differentiable smoothed loss. The paper proves finite-sample anytime type-I error control conditional on D_0 (Theorem 3.1), asymptotic power one under a fixed alternative (Theorem 3.3), and an expected detection delay of O(Δ_0^{-2} ln(1/(αΔ_0)) + Δ_0^{-2}), where Δ_0 is an effective signal strength that grows with reference set size.

## Results

The proposed conditional CTM achieves valid anytime type-I error control at α = 0.05 for all reference set sizes, whereas a naive CTM using a fixed D₀ without the estimation-error correction fails to control the type-I error (exceeding α even for large n). In synthetic experiments (N(0,1) → N(d,1) shifts), the conditional CTM consistently achieves higher empirical power and shorter detection delays than the standard CTM across immediate change-points, delayed change-points (t₀ ∈ {200, 600, 4000}), and gradual drifts. On ImageNet-C (ViT-Base entropy scores, 15 corruption types), the conditional CTM outperforms the standard CTM whenever the reference set size n ≥ 500, with median rejection-time ratios (standard/conditional) exceeding 1 across all corruption groups (Noise, Blur, Weather, Digital). The paper further establishes the first asymptotic power-one guarantee and an expected stopping-time bound of O(Δ₀⁻² ln(1/(αΔ₀)) + Δ₀⁻²) for CTM-based procedures.

## Baselines & Comparisons

The primary baseline is the standard conformal test martingale (CTM) of Vovk et al. (2003), which grows its reference set D_t with every incoming test sample. The conditional CTM outperforms the standard CTM on every tested scenario: for immediate change-points it achieves higher power at all shift magnitudes d; for delayed change-points (t₀ = 200, 600) it detects faster, and even for a late shift (t₀ = 4000) it ultimately overtakes the standard CTM once contamination of D_t accumulates; for gradual drifts it maintains higher power throughout. On ImageNet-C, the conditional CTM's median rejection time is shorter than the standard CTM's for all 15 corruption types when n ≥ 500, with the speed-up most pronounced for Blur and Weather corruptions (larger distributional shifts) and smallest for Digital corruptions (subtler shifts). The second baseline is the pairwise betting approach of Saha & Ramdas (2024), evaluated on a Gaussian AR(1) process (a = 0.7, σ² = 1). Here the conditional CTM achieves the fastest detection, the standard CTM follows, and the pairwise method exhibits a significant delay, attributed to its need to estimate AR parameters online and its pair-based betting accumulating evidence at half the rate.

## Relation to Prior Work

This paper extends the conformal test martingale (CTM) framework of Vovk et al. (2003) by replacing the standard growing reference set D_t with a fixed reference set D_0, thereby eliminating the 'test-time contamination' that dilutes shift evidence after a change-point. The key technical bridge is the adaptation of DKW confidence bands from Bates et al. (2023), who used them for offline outlier testing, into an online sequential betting function that corrects for ECDF estimation error at every time step. The paper also positions itself against pairwise betting (Saha & Ramdas, 2024) and universal inference (Ramdas et al., 2022) as alternative anytime-valid exchangeability tests, arguing that its fixed-reference design avoids the delayed detection inherent in methods that re-estimate distributional parameters from the full observed stream.

## Why It Matters / Open Questions

This is the first CTM-based procedure with formal asymptotic power-one guarantees and a bounded expected stopping time, filling a notable theoretical gap in the sequential testing literature. Practically, the fixed-reference design is more natural for monitoring deployed ML systems where a clean training set is available but test-time data should not contaminate the null model. Limitations include the requirement of a reasonably sized reference set (n ≥ 500) to keep confidence bands tight, and the betting function targets only mean deviations in conformal p-values, potentially missing shifts that preserve the mean. Open directions include extending to mixture martingales for adaptive betting, incorporating synthetic data to mitigate small-reference-set conservatism, and designing betting functions sensitive to non-mean distributional changes.

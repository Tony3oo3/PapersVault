## Problem

Malware detection remains fundamentally reactive, with models degrading as threats evolve, yet phylogenetic methods that could reveal lineage structure and enable proactive defense have never been applied at scale or validated against real-world emergence timelines. Prior work used small sample sets, single feature modalities, or tree proxies without temporal validation, leaving open whether inferred phylogenetic structure captures genuine malware evolution or merely feature similarity.
![Teaser figure](../imgs/ICML20260080/cropped_page0_idx0.webp)

## Input / Output

The method consumes malware memory dumps extracted during controlled VM execution (rather than raw binaries, to bypass packing and obfuscation), which are converted to 224×224 RGB images via bin2png, serialized structured features (imports, sections, opcodes) for text embedding, and sandbox behavioral traces from ANY.RUN/VirusTotal. It produces a rooted phylogenetic tree with 103,883 leaves and 103,882 internal nodes, a simplified directed inter-family graph where edge weights encode median embedding distance to the shared MRCA, a temporal consistency score (87.1% for NJ with outgroup rooting), and per-family embedding drift rates measured in distance-per-year.

## Method

MalTree extracts three complementary embeddings from each sample: a 3,512-d pseudo-static vector (byte histograms + LIEF-structured features encoded via OpenAI text-embedding-3-large), a 1,000-d dynamic vector (15 behavioral categories from sandbox execution, also text-embedded), and a 2,048-d image vector (ResNet-50 penultimate layer, two-stage trained on public malware image benchmarks then fine-tuned to 95% family accuracy). These are concatenated to 6,560 dimensions and reduced to 1,000 via a supervised two-layer network, after which pairwise Euclidean distances form the input to UPGMA and RapidNJ tree construction. The key validation insight is a local-clock assumption: rather than requiring a global molecular clock, the method only requires comparable mutation rates between immediate siblings sharing a parent, which is empirically validated by comparing branch-length ordering against VirusTotal first-submission timestamps. For inter-family inference, median leaf-to-MRCA distances define directed edges (earlier-diverging → later-diverging family), simplified by retaining only the minimum-weight outgoing edge per node to expose primary lineages.

## Results

MalTree achieves 87.1% temporal consistency using Neighbor-Joining with outgroup rooting on 103,883 malware samples spanning 538 families, meaning tree-inferred divergence order matches VirusTotal first-submission timestamps in 87.1% of sibling-pair comparisons (vs. ~50% for random ordering). UPGMA in its nominal (rooted) configuration reaches 86.0%, while midpoint rooting degrades performance sharply for both methods (NJ: 63.1%, UPGMA: 56.2%). The fused 1,000-d embeddings achieve 93.69% family classification accuracy via a linear probe, with image embeddings alone reaching 94.91%. Tree construction completes in ~11 hours (UPGMA) or ~3 days (NJ) on 20 CPU cores.

## Baselines & Comparisons

The paper does not benchmark against external phylogenetic or malware-clustering baselines; instead it compares internal configurations of the same pipeline. NJ with outgroup rooting (87.1%) outperforms UPGMA in its nominal rooted form (86.0%) by 1.1 points, which the authors attribute to malware families evolving at non-uniform rates (some families drift >10× faster, violating UPGMA's molecular clock assumption). Outgroup rooting is critical for NJ, boosting consistency from 81.1% (default) to 87.1%, while it severely harms UPGMA (86.0% → 60.1%) because UPGMA already produces a rooted tree and re-rooting disrupts its ultrametric structure. Midpoint rooting is consistently the worst strategy for both algorithms (63.1% NJ, 56.2% UPGMA), indicating the longest-path heuristic does not reflect malware evolutionary direction. The paper positions its contribution as the first large-scale phylogenetic analysis with temporal validation, noting that prior work (Karim et al. 2005, Cozzi et al. 2020, He et al. 2023) either used smaller sample sets, single modalities, or lacked temporal validation entirely.

## Relation to Prior Work

This paper repurposes classical bioinformatics phylogenetic algorithms (UPGMA, Neighbor-Joining) for malware analysis, extending a line of work that began with Karim et al. (2005) and was pursued at small scale by Cozzi et al. (2020, MST-based clustering) and He et al. (2023, computational efficiency). The key departure is twofold: (1) it operates on multimodal ML embeddings (ResNet-50 image features, OpenAI text embeddings of static/dynamic features) rather than raw code sequences or binary diffs, and (2) it introduces a temporal validation framework using VirusTotal first-submission timestamps, which no prior malware phylogenetic study has attempted. The embedding extraction pipeline builds on standard malware image classification (bin2png + ResNet-50) and sandbox behavioral analysis, but the contribution lies in what is done with those embeddings—constructing and validating rooted phylogenetic trees at 100K+ sample scale.

## Why It Matters / Open Questions

MalTree demonstrates that phylogenetic methods can capture genuine evolutionary structure in malware (87% temporal consistency), offering a path from reactive sample-by-sample detection toward lineage-aware proactive defense. However, the paper honestly surfaces important limitations: the framework cannot distinguish code inheritance from delivery-chain co-occurrence (SmokeLoader case) or recover threat-actor-level clustering when toolsets span functional categories (Conti ecosystem fragmentation), and it requires full tree reconstruction with each new sample. Open questions include whether phylogenetic networks can model reticulate evolution (copy-paste code reuse), how to establish principled confidence thresholds for inter-family edges, and whether online/incremental tree updates can enable real-time deployment.

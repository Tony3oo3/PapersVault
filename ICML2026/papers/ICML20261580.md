## Problem

Policy-gradient reinforcement learning for generative models typically requires explicit access to the score (gradient of the log-density), which prevents its application to flow-based models that learn only velocity fields. Moreover, RL had not been applied to the crystal structure prediction (CSP) task, where the composition is fixed and diversity must emerge from conditioning rather than from explicit diversity rewards. This paper addresses both gaps by enabling RL directly on velocity fields and presenting the first RL application to CSP.

## Input / Output

The method takes a fixed chemical composition (atomic numbers A) as a conditional input and generates the continuous crystal structure variables: fractional atomic coordinates X ∈ [0,1)^{N×3} on a torus and a 3×3 lattice matrix L, via a continuous-time generative process from t=0 to t=1. The architecture is an E(n)-equivariant graph neural network (CSPNet) that is permutation-equivariant, rotation-equivariant, and translation-invariant. In the velocity-annealing variant, the output is instead a lightweight time-dependent schedule s(t) (a scalar per time step) that rescales the frozen pretrained velocity field, enabling order-of-magnitude reductions in integration steps.

## Method

The core mechanism augments the deterministic ODE integration of the pretrained velocity field with a small noise schedule σ_ref(t), creating a surrogate stochastic process whose marginals deviate from the true ODE only at O(σ²) order (validated via path-space KL analysis). This surrogate enables exploration, policy-ratio computation, and KL regularization without requiring the score, making policy-gradient RL applicable across the full stochastic-interpolant design space. The RL objective uses GRPO with group-relative advantages over G rollouts under identical composition conditioning, optimized via a PPO-style clipped surrogate with KL regularization against the frozen pretrained policy. The reward is the negative energy per atom computed by MACE-MPA-0, which is transferable across compositions and directly optimizes chemical stability. A second variant applies the same framework to learn a time-dependent velocity-annealing schedule s(t) via a small MLP in a residual-policy-learning setup, replacing handcrafted annealing and enabling accurate CSP with as few as 10 integration steps versus 950 for the original model.

## Results

On MP-20, velocity-based OMatG-IRL achieves 69.09% match rate and 0.0491 RMSE using only 50 integration steps, compared to the pretrained OMatG Linear-ODE baseline at 69.83%/0.0741 with 210 steps and Trig-SDE-Gamma at 68.90%/0.1249 with 740 steps. On MP-20-polymorph-split, OMatG-IRL reaches 70.68% METRe and 0.183 cRMSE at 50 steps, matching the pretrained Linear-ODE model (70.50%/0.187) that requires 950 steps. Energy-based reinforcement reduces relative energy per atom by approximately 0.5 eV/atom, and the learned velocity-annealing schedule enables accurate CSP with as few as 10 integration steps (vs. 950 for the handcrafted schedule).

## Baselines & Comparisons

Against DiffCSP (Jiao et al., 2023) and FlowMM (Miller et al., 2024), OMatG-IRL wins on every reported dataset in both match rate and RMSE while using 10–20× fewer integration steps (50 vs. 1000). For example, on MP-20 OMatG-IRL reaches 69.09%/0.0491 versus DiffCSP's 57.82%/0.0627 and FlowMM's 66.22%/0.0661. Against the pretrained OMatG baselines (Hollmer et al., 2025), OMatG-IRL trades a negligible match-rate drop (<1 percentage point) for a large RMSE reduction—0.0491 vs. 0.0741 on MP-20 and 0.0503 vs. 0.0683 on Alex-MP-20—while cutting integration steps from 210–950 down to 50. On MP-20-polymorph-split, OMatG-IRL slightly exceeds the Linear-ODE baseline in both METRe (70.68% vs. 70.50%) and cRMSE (0.183 vs. 0.187) at 50 steps versus 950. The velocity-annealing variant further demonstrates that the learned schedule at Nt=100 fully recovers the Nt=950 baseline performance, and degrades only mildly even at Nt=10, whereas the handcrafted schedule collapses below Nt≈100.

## Relation to Prior Work

This paper extends the OMatG stochastic-interpolant generative framework (Hollmer et al., 2025) by adding an inference-time policy-gradient RL layer, drawing on GRPO (Shao et al., 2024) and PPO (Schulman et al., 2017) for the optimization objective. Prior RL applications to materials generative models (MatInvent, Chemeleon2) required explicit score access available in diffusion models, and Flow-GRPO (Liu et al., 2025) handled the velocity-only case only for linear interpolants with Gaussian base distributions. The key departure here is a surrogate stochastic process—adding a small noise schedule to the deterministic ODE—that enables policy-gradient estimation across the full SI design space without computing the score, and the first application of RL to the CSP task (as opposed to DNG in prior work).

## Why It Matters / Open Questions

By eliminating the score requirement, OMatG-IRL makes policy-gradient RL applicable to a substantially broader class of flow-based generative models, and the learned velocity-annealing schedule achieves an order-of-magnitude reduction in integration steps (N_t=950 → 10) while preserving accuracy. Energy-based reinforcement also partially amortizes expensive post-generation relaxation, shifting the generative model toward producing near-relaxed structures directly. Open questions include whether the surrogate process's O(σ²) marginal deviation becomes problematic in other settings, how OMatG-IRL compares to differentiable test-time guidance methods, and how to extend the framework to full DNG with discrete species generation.

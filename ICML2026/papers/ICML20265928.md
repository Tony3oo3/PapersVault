## Problem

Existing memory-based test-time adaptation for vision-language models suffers from two fundamental flaws: hard pseudo-label assignment routes each sample to a single class memory, so early mispredictions contaminate the memory and bias all subsequent retrieval; and fixed-capacity eviction under entropy-based selection discards informative samples, concentrating retained features in a narrow high-confidence region and limiting memory expressiveness for hard samples.

## Input / Output

The method consumes a fully online stream of unlabeled RGB test images (batch size 1) through a frozen CLIP backbone (ViT-B/16 or RN50), producing a single class label per image. An offline phase uses GPT-4o to generate class-specific attribute descriptions that are encoded once into prior textual representations; at test time, each incoming image is processed in a single forward pass with no backpropagation through the encoder, yielding a confidence-weighted fusion of CLIP zero-shot logits and memory-retrieved logits.

## Method

A² Memory reformulates memory-based TTA as attribute-centric associative memory optimization with two components. First, Attribute-centric Representation Construction uses GPT-4o to generate N shared visual attributes per class, greedily selects L representative and diverse attributes via a marginal-gain criterion balancing representativeness and diversity, and applies attribute-centric soft assignment (a sigmoid-gated residual interaction between the visual feature and each class-attribute text embedding) to produce surrogate visual representations distributed across all class-attribute slots, eliminating hard pseudo-label contamination. Second, Class-wise Associative Memory maintains a D×D key-value matrix per class, updated at each streaming step via a delta-rule gradient descent on an L₂ reconstruction loss (mapping surrogate visual keys to prior textual values), with a data-dependent retention coefficient α_t that adaptively balances plasticity and stability based on the normalized prediction entropy of the current sample. At inference, the current visual feature queries each class memory to retrieve a sample-adaptive prototype, and the final prediction fuses CLIP zero-shot and memory logits via entropy-weighted combination.

## Results

On the Cross-Dataset Generalization benchmark (10 datasets), A²Memory with CLIP-ViT-B/16 achieves 71.41% average top-1 accuracy, surpassing the strongest baseline ADAPT (70.76%) by 0.65% and zero-shot CLIP (64.59%) by 6.82%. On the OOD robustness benchmark (ImageNet + 4 shifted variants), it reaches 67.23% average accuracy (65.99% OOD average), outperforming ADAPT (66.53%/65.44%) and DPE (65.93%/64.43%). With the ResNet-50 backbone, the method maintains its lead at 63.56% (CD) and 51.70% (OOD average). On ImageNet-C corruption robustness, A²Memory achieves 29.70% average accuracy with ViT-B/16, exceeding ADAPT (28.56%) and zero-shot CLIP (25.50%).

## Baselines & Comparisons

A²Memory outperforms all nine baselines across both CD and OOD benchmarks with both ViT-B/16 and ResNet-50 backbones. The closest competitor is ADAPT (Zhang et al., 2025), which A²Memory surpasses by 0.65% on CD average (71.41% vs. 70.76%) and 0.70% on OOD average (67.23% vs. 66.53%) with ViT-B/16; the gap widens on texture-heavy DTD (+2.08%) and Food101 (+2.38%). Among optimization-based methods, DPE (Zhang et al., 2024a) is the strongest at 69.40% CD / 65.93% OOD, trailing A²Memory by 2.01% and 1.30% respectively, while TPT (Shu et al., 2022) and DynaPrompt (Xiao et al., 2025) lag further behind at 65.10%/65.52% CD. Among backpropagation-free memory-based methods, TDA (Karmanov et al., 2024) achieves 67.53% CD / 65.01% OOD, and TCA (Wang et al., 2025) reaches 68.69% CD / 61.43% OOD, both clearly outperformed. On ImageNet-C corruption robustness, A²Memory leads ADAPT by 1.14% (29.70% vs. 28.56%) and zero-shot CLIP by 4.20% (29.70% vs. 25.50%), with particularly large gains on blur and weather corruptions. In terms of efficiency, A²Memory runs in 69.24 min on ImageNet (ViT-B/16), achieving an 8.4× speedup over TPT (586.43 min) and 1.6× over DPE (114.23 min), while remaining competitive with the fastest BP-free method TDA (52.50 min) at a cost of only 2.7% less accuracy.

## Relation to Prior Work

This paper sits at the intersection of two research threads: memory-based test-time adaptation for VLMs (initiated by TDA, extended by DPE, ADAPT, TCA) and parametric associative memory with delta-rule updates (Behrouz et al., Yang et al. on gated delta networks). It departs from the sample-level storage paradigm of prior memory-based TTA by reformulating memory as class-wise key-value associative matrices updated via gradient descent, and replaces hard pseudo-label assignment with attribute-centric soft assignment guided by LLM-generated textual representations. The conceptual bridge from NLP sequence-modeling memorization (retention, plasticity-stability tradeoff) to vision-language adaptation is the paper's primary positioning move.

## Why It Matters / Open Questions

The paper provides a clean diagnosis of why existing memory-based TTA methods fail in early streaming stages (memory contamination from unfiltered hard assignments) and under capacity constraints (biased eviction), supported by empirical visualizations. The associative memory reformulation offers a principled alternative to heuristic eviction, with a formal O(1/K) convergence guarantee, and the backpropagation-free design (8.4× faster than TPT) makes it practical for latency-sensitive deployment. Open questions include whether the GPT-4o attribute generation is truly necessary (hand-crafted templates close most of the gap), how the method scales to very large class spaces (e.g., 10k+ classes), and whether the fixed D×D memory matrix per class remains tractable as class count grows.

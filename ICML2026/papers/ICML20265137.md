## Problem

Web agents require massive interaction trajectories to generalize, yet real-world collection is bottlenecked by network latency, rate limits, anti-crawling measures, and safety risks. Existing web world models are confined to closed benchmark environments with only 1K–10K trajectories, support single-step predictions and restricted input formats, and lack explicit reasoning—making them poor substitutes for scaling agent training on the open web.
![Teaser figure](../imgs/ICML20265137/cropped_page0_idx0.webp)

## Input / Output

The model consumes a web task instruction, the current page state (primarily as an A11y Tree, but also HTML, XML, or Markdown), and the full interaction history of up to 30+ state-action pairs. It autoregressively generates the predicted next page state in the same format, optionally preceded by a chain-of-thought rationale that analyzes page structure, interprets user intent, and predicts the causal effect of the action before emitting the state. The A11y Tree is the primary representation for its LLM-friendly structure and cross-environment applicability, with multi-format variants produced via a parse-then-generate conversion pipeline.

## Method

WebWorld is instantiated as a causal LLM (Qwen3-8B/14B/32B) trained by maximum likelihood to predict the next state given an instruction and interaction history. The key contribution is a scalable three-level hierarchical data pipeline: (1) randomized crawlers harvest 293K short trajectories from URLs extracted directly from pre-training corpora (FineWeb, CCI 3.0) to align the training distribution with the base model's linguistic priors; (2) LLM agents autonomously explore websites with four prompt-engineered strategies (self-proposed tasks, long-horizon dependency, composite actions, curiosity discovery) yielding 38K realistic long-horizon trajectories; (3) agents execute synthesized task-oriented queries producing 94K goal-directed traces. Training follows a two-stage curriculum: Stage 1 learns web dynamics on 1.06M trajectories, then Stage 2 fine-tunes on only 1K CoT samples synthesized by Claude-Opus-4.1 to externalize reasoning patterns. This knowledge-then-reasoning recipe is critical—1K CoT samples on the dynamics-pretrained model outperform 10K CoT samples on a base model, and excessive CoT data actually degrades performance.

## Results

On WebWorld-Bench (intrinsic evaluation), WebWorld-32B achieves 71.0% average Factuality Score and 45.6% average Web Turing Score, matching Claude-Opus-4.1 (71.3% Factuality) and surpassing Gemini-3-Pro (70.3%) and GPT-4o (59.5%). For extrinsic evaluation, fine-tuning Qwen3-8B on WebWorld-synthesized trajectories yields +9.9% on MiniWob++ and +10.9% on WebArena, while the 14B variant reaches 24.3% WebArena success rate (comparable to GPT-4o's 26.6%). In inference-time lookahead search on MiniWob, WebWorld as a world model with GPT-5 as value model achieves 67.5 reward, outperforming GPT-5 as world model (64.5) by +3.0 points.

## Baselines & Comparisons

Against prior trained world models, WebWorld achieves a decisive margin: WebWorld-8B (70.1% avg Factuality) outperforms WMA-8B (11.1%), WebSynthesis-8B (16.7%), and Word2World-8B (7.0%) by 53–63 points, reflecting the 100× data scale advantage (1.06M vs. 4K–70K trajectories) and multi-format training. Against the Qwen3 base models, WebWorld-8B improves average Factuality from 26.9% to 70.1% (+43.2 points), confirming that the world-model training objective is the primary driver rather than model architecture. Among proprietary LLMs, WebWorld-32B (71.0% F / 45.6% T) essentially ties Claude-Opus-4.1 (71.3% F / 47.4% T) and slightly edges out Gemini-3-Pro (70.3% F / 43.2% T), while clearly surpassing GPT-4o (59.5% F / 35.4% T) by 11.5 points on Factuality. On the extrinsic WebArena benchmark, Qwen3-14B+WebWorld reaches 24.3% success rate versus GPT-4o's 26.6%, a 2.3-point gap that narrows to within noise given standard errors (±0.015 vs. ±0.016). In inference-time search, WebWorld as a world model with GPT-5 value model (67.5) beats GPT-5 as world model with GPT-4o value model (64.5) by +3.0, demonstrating that a domain-specific 8B simulator can outperform a much larger general-purpose LLM in the world-modeling role.

## Relation to Prior Work

This paper extends the line of LLM-based world models for web agent training (WMA, WebEvolver, DreamGym, WebSynthesis) by shifting from closed benchmark environments with 1k–10k trajectories to the open web with 1M+ real-world interactions. It departs from prior work in three key ways: (1) a hierarchical data pipeline aligned with pre-training corpora (FineWeb, CCI 3.0) rather than sandboxed benchmarks, (2) explicit chain-of-thought reasoning injected via a two-stage curriculum, and (3) multi-format state representation (A11y Tree, HTML, XML, Markdown) rather than a single format. The autoregressive formulation and maximum-likelihood training objective follow the standard LLM fine-tuning paradigm, but the data construction strategy—randomized crawling, autonomous exploration, and task-oriented execution—is the primary methodological contribution.

## Why It Matters / Open Questions

WebWorld provides the first open-web simulator at scale, lowering the barrier to training web agents without incurring real-world latency, rate limits, or safety risks (irreversible form submissions, transactions). The WebWorld-Bench with dual metrics (Factuality + Web Turing) across nine dimensions offers a more holistic evaluation than prior structural or semantic-only metrics. Key limitations include a sycophancy bias where the model generates overly optimistic outcomes, and the finding that inference-time search yields only marginal gains over greedy execution, suggesting the primary value lies in training-data synthesis rather than test-time planning. Open questions include whether visual modality will be necessary as agents evolve, whether the scaling law holds beyond 32B, and how to mitigate the PII and content-safety risks inherent in open-web crawling.

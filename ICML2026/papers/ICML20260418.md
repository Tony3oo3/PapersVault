## Problem

Fine-tuning LLMs on narrow tasks can produce unintended out-of-distribution generalization, such as emergent misalignment or reliance on spurious correlations. Standard remedies modify the training data to better specify intended behavior, but this is infeasible when spurious correlations are inherent to the data generation process or when the model can distinguish synthetic evaluation data from real queries. This paper addresses the worst-case setting where no data from the OOD distribution or any data disambiguating the intended generalization is available.

## Input / Output

The method takes a pretrained LLM, a labeled fine-tuning dataset D_train, and a set of identified latent-space directions (obtained via PCA of pre/post fine-tuning activation differences or via SAE latent sorting) that a human or auxiliary model flags as representing undesired concepts. It outputs a fine-tuned model with standard architecture and learned parameters, ready for normal inference with no additional interventions. Critically, no data from the OOD evaluation distribution is used at any stage; only generic pretraining or chat data (e.g., LMSYS, FineWeb) is permitted for direction identification and interpretation.

## Method

CAFT identifies directions in the model's residual stream that encode undesired concepts using either PCA on activation differences between the original and fine-tuned model, or sparse autoencoder latents sorted by attribution effects, activation differences, or mean activation shifts. After interpreting and selecting the undesired directions per layer, the method modifies the computational graph by inserting an orthogonal projection (onto the complement of the undesired subspace) after each relevant layer during fine-tuning, forcing the model to learn the task without relying on those concepts. The model is fine-tuned on D_train with this modified architecture, and the projections are then removed for inference, yielding a standard-architecture model. The approach is motivated by evidence that fine-tuning primarily enhances existing mechanisms rather than creating new ones, so ablating undesired concepts during training steers the model toward the intended generalization without degrading in-distribution task performance.

## Results

On the emergent misalignment task with Qwen2.5-Coder-32B, CAFT with PCA reduces misaligned responses from 7.0% to 0.51% (a 10x reduction) while retaining 84.8% code vulnerability (vs. 91.6% for the standard fine-tuned model). For Mistral-Small-24B, CAFT with PCA reduces misalignment from 6.57% to 1.16% with 92.2% vulnerability. On the multiple choice spurious correlation tasks (Gemma-2-2B), CAFT with SAEs improves OOD accuracy on gender bias and 10/16 double multiple choice combinations, often swinging from near 0% to near 100% accuracy. General capabilities on MMLU and GSM8K are preserved (e.g., Qwen MMLU: 0.761→0.762, GSM8K: 0.877→0.886).

## Baselines & Comparisons

CAFT outperforms all standard OOD generalization baselines. LP-FT (Kumar et al., 2022a), which trains a classifier head before full fine-tuning, can shift generalization but does so in an undirected manner; it matches CAFT in only one of the spurious correlation tasks and cannot target the intended generalization when it is ambiguous. L2 regularization on LoRA weights (Xuhong et al., 2018) has minimal effect on generalization for both the multiple choice and emergent misalignment tasks. LoRA fine-tuning at various ranks (4, 8, 16) generalizes similarly to full fine-tuning and does not reduce misalignment. Ablation baselines using random vectors show no effect, while random or top PCs/SAE latents produce inconsistent results that are generally worse than CAFT with interpreted directions, confirming that targeted interpretability is essential. Test-time-only ablations perform similarly but overall worse than CAFT, and skyline experiments (adding 100 benign examples) confirm that when data modification is possible, it is effective but violates the paper's core assumption of no access to OOD-specifying data.

## Relation to Prior Work

This paper extends the sparse feature circuits framework of Marks et al. (2024b) from binary classification to arbitrary fine-tuning tasks, and repurposes SAEs (Bricken et al., 2023; Cunningham et al., 2023) and PCA not as post-hoc analysis tools but as active interventions during training. It departs from the standard OOD-generalization literature (Kumar et al., 2022; Hewitt et al., 2022) that modifies training data, and from concept-erasure work (Belrose et al., 2023; Ravfogel et al., 2020) that removes concepts from a trained model, by instead ablating concept directions only during fine-tuning to shape what the model learns. For emergent misalignment specifically, it builds on Wang et al. (2025) who identified misaligned persona directions, but does so without access to the OOD evaluation data those prior methods require.

## Why It Matters / Open Questions

CAFT offers a practical, data-free lever for controlling how LLMs generalize from fine-tuning, which is critical in settings where modifying training data is infeasible (superhuman domains, distributional shifts, evaluation-aware models). The 10× reduction in emergent misalignment with minimal task-performance loss is a strong result, but the method's efficacy depends heavily on interpretability quality (Mistral SAEs were ambiguous) and the PCA-vs-SAE effectiveness gap varies by task, leaving open which interpretability tool to use in new settings. Scaling automated interpretation (Appendix E) is promising but not yet optimized, and the stylized multiple-choice tasks, while useful proxies, do not fully validate the approach on realistic deployment distributions.

## Problem

Masked diffusion language models (MDLMs) decode tokens in parallel but must reprocess the entire sequence at every denoising step, making each step resemble a costly 'repeated prefill' operation. Prior acceleration methods (Fast-dLLM, dLLM-Cache, dKV-Cache) rely on fixed block-based schedules or global refresh intervals that fail to capture the layer-wise and token-wise heterogeneity in representation stability across diffusion steps, limiting both throughput and scalability with parallel decoding degree.

## Input / Output

DyLLM takes a text prompt of length L_P and generates a text response of length L_R (default 256 tokens) using existing diffusion LLMs (LLaDA 8B, Dream 7B) without any retraining. The response is initialized as mask tokens and decoded over T=256 denoising steps using semi-autoregressive block-wise decoding (block size B=32). The method is purely inference-time: it modifies how the forward pass is executed (which tokens are recomputed vs. cached) while leaving model weights, sampling strategy, and output format unchanged.

## Method

DyLLM is a training-free inference framework that exploits temporal sparsity in MDLM denoising by selectively recomputing only 'salient' tokens whose attention contexts change significantly between adjacent steps. Saliency is measured per-layer via cosine similarity of attention context vectors; tokens below a threshold τ are flagged for full recomputation of their KV projections, attention, and FFN, while stable tokens reuse cached activations. For attention, a dual-path scheme is used: salient queries get exact row-sparse attention over all keys/values, while non-salient queries receive an approximate column-sparse update that only gathers contributions from salient value deltas, reducing attention complexity from O(N²d) to O(N·|A|d). The number of salient tokens adapts per layer (fewer in shallow layers, more in deeper layers) and per step (decreasing as fewer masks remain), and 75% of steps process only response tokens rather than the full prompt+response sequence. Theoretical error bounds (Propositions 3.1–3.2) formalize that the cosine-similarity threshold controls the FFN input perturbation via the condition number of the output projection, justifying the selection criterion.

## Results

On LLaDA 8B, DyLLM (τ=0.99) achieves up to 7.60× throughput improvement (87.21 tok/s on GSM8K vs. 11.47 tok/s baseline) while matching or slightly improving accuracy (79.08 vs. 77.79). On Dream 7B, DyLLM (τ=0.995) reaches up to 9.60× speedup (120.62 tok/s on GSM8K vs. 12.57 tok/s baseline) with accuracy of 78.09 vs. 75.59. Across all four benchmarks (GSM8K, MBPP, MATH, MMLU-Pro) and both models, DyLLM consistently delivers 4.5–9.6× throughput gains while preserving or modestly improving generation quality.

## Baselines & Comparisons

Against Fast-dLLM (PrefixCache and DualCache), DyLLM wins on accuracy in most configurations: on Dream 7B, Fast-Dual degrades GSM8K accuracy from 75.59 to 68.39 (−7.2 pts) and MATH from 37.60 to 36.06, while DyLLM improves both (78.09 and 43.80 respectively). On LLaDA, DyLLM matches or exceeds Fast-dLLM accuracy across all four benchmarks. On throughput, Fast-Dual can be faster at n_u=1 on Dream (e.g., 153.21 vs. 120.62 tok/s on GSM8K), but DyLLM scales better with increasing parallel decoding degree n_u, surpassing Fast-Dual at n_u=4. Against dLLM-Cache, DyLLM is 2.16–3.67× faster across all benchmarks (e.g., 87.21 vs. 36.77 tok/s on LLaDA GSM8K). dLLM-Cache achieves slightly higher accuracy on LLaDA MMLU-Pro (37.90 vs. 36.42) and Dream MATH (44.98 vs. 43.80), but requires dataset-specific hyperparameter tuning (K_P, K_R) that varies by an order of magnitude across benchmarks, whereas DyLLM uses a single model-level threshold τ.

## Relation to Prior Work

DyLLM extends the line of training-free acceleration methods for masked diffusion LLMs, including dKV-Cache (periodic KV refresh), Fast-dLLM (block-wise PrefixCache/DualCache), dLLM-Cache (token-level adaptive caching via value-vector change), and Elastic-Cache (attention-weight-based selection). The key departure is the introduction of layer-wise temporal sparsity: rather than applying a fixed spatial schedule or a global token threshold, DyLLM measures cosine similarity of attention contexts between adjacent denoising steps at each layer and adaptively selects a per-layer salient subset. This is complemented by a saliency-aware approximate attention scheme that propagates value deltas only through salient-token columns, reducing attention from O(N²d) to O(N·|A|d).

## Why It Matters / Open Questions

The up-to-9.6× throughput gain with near-lossless accuracy is practically significant for the growing diffusion LLM ecosystem, and the training-free design means it can be applied to existing checkpoints without retraining. A notable open question is whether the temporal sparsity assumption holds for future, larger diffusion LLMs or for tasks with more dynamic token interactions (e.g., long-form creative generation). The paper also acknowledges additional memory overhead from caching FFN outputs and attention contexts beyond standard KV cache, and the threshold τ, while model-dependent, still requires per-model calibration. The finding that selective computation can modestly *improve* accuracy by suppressing softmax noise from low-relevance tokens is an interesting side effect that may warrant further investigation.

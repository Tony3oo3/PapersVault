## Problem

Image-to-CAD program synthesis via supervised fine-tuning enforces a rigid one-to-one mapping between images and code, penalizing valid alternative programs that produce the same geometry, while reinforcement learning approaches are computationally prohibitive due to CPU-bound geometric kernels in the training loop. The paper argues the primary bottleneck is not model capacity but the scarcity of diverse, verified training examples that align visual geometry with program syntax, making it difficult to scale robust generative CAD models.
![Teaser figure](../imgs/ICML20261279/cropped_page0_idx0.webp)

## Input / Output

The model takes a single-view RGB image of a CAD part along with a fixed text prompt ('generate cadquery code for the image') and produces an executable CadQuery Python script. The generated code is executed through the OpenCASCADE geometric kernel to yield a Boundary Representation (B-Rep) solid, which is then compared to the ground-truth STEP file via IoU after centering, scaling by inertia tensor trace, and aligning principal axes across all axis permutations (IoU-best protocol). The base model is Qwen-VL-2.5-7B, fine-tuned on the GenCAD-Code dataset of 163k image-code pairs.

## Method

GIFT is a verifier-guided data augmentation framework that converts offline inference-time search into additional supervised training signal without online RL. For each training image, K candidate programs are sampled from the base model and scored by a deterministic geometric kernel (IoU against ground truth). Two complementary mechanisms then partition these samples: Soft-Rejection Sampling (SRS) retains diverse valid programs in the IoU [0.9, 0.99) range as additional output targets for the same input image, broadening the target distribution beyond a single canonical program; Failure-Driven Augmentation (FDA) takes near-miss failures in the IoU [0.5, 0.9) range, renders them back into synthetic images via a projection function, and pairs these 'noisy' inputs with the original ground-truth code to create a geometric denoising objective. The final training loss is a combined maximum-likelihood objective over the original SFT data, the SRS-augmented output set, and the FDA-augmented input set, effectively amortizing the cost of test-time search into the model weights and reducing inference compute by 80% while improving mean IoU by 12% over the SFT baseline.

## Results

On the GenCAD-Code test set, GIFT achieves a mean IoU of 0.782 (median 0.948), improving over the CAD-Coder-SFT baseline (0.698) by 12% in mean IoU. GIFT matches the peak performance of the SFT model (0.807 at pass@10) while using only pass@1 inference, reducing inference compute by approximately 80%. The amortization gap between pass@1 and pass@10 shrinks from 15.5% (SFT) to 5.2% (GIFT), a 66.4% relative reduction. On the Fusion360 out-of-distribution set, GIFT achieves 97.26% valid sample rate and solves 26% more problems (IoU > 0.9) than the SFT baseline.

## Baselines & Comparisons

GIFT (0.782) outperforms all single-view image baselines: CAD-Coder-SFT (0.691, +9.1 pts), ReCAD-VL (0.631, +15.1 pts), and all frontier zero-shot VLMs (Gemini-3.0-PRO at 0.540, GPT-4o at 0.378). It also surpasses every point-cloud-based method (CAD-SigNet 0.773, CAD-Diffuser 0.743, Point2Cyl 0.738, PrismCAD 0.721) and the text-based Text2CAD (0.715), despite using only a single RGB image as input. GIFT trails the two strongest multimodal RL systems—Cadrille-RL (0.859, using PC+IMG+TXT) and GACO-CAD-RL (0.864, using IMG-s+Depth+Normal)—by 7.7 and 8.2 points respectively, but these methods rely on richer input modalities and online reinforcement learning. Against Cadrille (0.794, point-cloud only), GIFT is within 1.2 points while using a simpler single-image input. The paper also reports that GIFT's median IoU (0.948) substantially exceeds Cadrille-RL's median (0.972) only when failed generations are excluded, highlighting that GIFT's advantage is most pronounced in single-shot reliability rather than best-of-many selection.

## Relation to Prior Work

This paper extends the image-to-CAD program synthesis line (CAD-Coder, ReCAD, Cadrille, GACO-CAD) by reframing inference-time scaling not as a deployment strategy but as an offline data-generation tool. It draws on self-training frameworks (STaR, ReST, RFT) that filter model outputs for retraining, but departs from them by using a deterministic geometric kernel (OpenCASCADE) as a dense verifier rather than heuristic confidence scores or learned rewards. The key conceptual departure from prior RL-based CAD post-training (Cadrille-RL, ReCAD) is the complete decoupling of exploration from learning: geometric verification runs offline, and the resulting augmented dataset is consumed via standard supervised fine-tuning, avoiding the GPU-CPU communication bottleneck of online kernel execution. The Failure-Driven Augmentation mechanism—rendering near-miss CAD programs back into the image domain as synthetic noisy inputs—is a novel twist not present in prior self-training or rejection-sampling work.

## Why It Matters / Open Questions

The 80% inference compute reduction while matching peak SFT performance is practically significant for deployment, and the 12% IoU gain over a strong supervised baseline demonstrates that data diversity (not model scale or RL complexity) is the primary bottleneck in image-to-CAD generation. The FDA mechanism opens a path toward geometric denoising objectives that could generalize to other program-synthesis tasks with executable verifiers. Key limitations remain: the approach requires ground-truth CAD programs and a geometric kernel, restricting it to supervised settings, and OOD performance (especially on real-world images) still degrades substantially, suggesting the method has not yet resolved the fundamental visual robustness gap. Whether the bootstrapping loop can be iterated (using the GIFT model as the next sampler) without distribution collapse remains an open question the paper does not fully explore.

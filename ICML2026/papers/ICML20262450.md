## Problem

Existing LLM-based multi-agent systems (MAS) rely on handcrafted agent designs and fixed collaboration structures, with prior optimization work addressing only isolated aspects—either agent functionality or structural topology—rather than a unified, holistic optimization. No general framework existed that could systematically optimize both the functional capabilities of individual agents and the structural decisions governing how agents collaborate across multi-step workflows.
![Teaser figure](../imgs/ICML20262450/cropped_page1_idx0.webp)

## Input / Output

The method takes as input an existing MAS configuration (a set of LLM-powered agents defined by natural-language instruction prompts and optional few-shot examples, plus a collaboration structure) along with a training dataset for the target task. It produces refined instruction prompts for agents and/or LLM-based controllers that manage candidate selection, dynamic participation, and communication routing. All optimization operates purely at the prompt level—no model weights are updated—and the final output is a plug-and-play set of optimized prompts that replace the originals in the MAS for inference.

## Method

OMAC identifies five optimization dimensions: two functional (optimizing existing agents, constructing new agents) and three structural (candidate agent selection, dynamic per-step agent participation, and inter-agent communication flow). For each dimension, a unified algorithm employs two LLM-powered actors: a Semantic Initializer that generates a diverse initial collection of agents/controllers by exploring the relevant semantic space, and a Contrastive Comparator that performs contrastive reasoning over a positive-negative pair (sampled by performance thresholds from training-set evaluations) to identify factors underlying the performance gap and generate a refined agent/controller. This evaluate-sample-compare-refine cycle iterates for a fixed number of rounds. For multi-dimension optimization, OMAC iteratively optimizes one dimension at a time while holding others fixed, preserving the clarity of contrastive reasoning by limiting variability to a single factor per iteration, and selectively includes only the dimensions with the largest individual gains to control computational cost.

## Results

On code generation (HumanEval), OMAC's best single-dimension optimization (Fun-1.4) achieves 89.25% Pass@1, outperforming the strongest baseline DyLAN (85.74%) by 3.5 points. On general reasoning (MMLU), the best OMAC dimension (Fun-1.4) reaches 74.22% accuracy versus DyLAN's 69.42%. On arithmetic reasoning (MATH), Fun-1.1 achieves 35.17% accuracy, surpassing DyLAN (32.35%) and AFlow (32.49%). Joint multi-dimension optimization further amplifies gains, e.g., improving arithmetic reasoning from a 2.9% single-dimension gain to a 9.6% improvement over the default MAS.

## Baselines & Comparisons

OMAC consistently outperforms all nine baselines across all three task domains. Against the strongest prior method DyLAN, OMAC gains approximately 1.0–3.5 points on code generation (87.55–89.25 vs. 85.74), 3.7–4.8 points on MMLU (73.14–74.22 vs. 69.42), and 1.0–2.8 points on MATH (33.34–35.17 vs. 32.35). OMAC also surpasses the MCTS-based AFlow by 1.1–3.6 points on code generation, 3.1–4.2 points on MMLU, and 0.8–2.7 points on MATH. Single-agent baselines (CodeT at 67.50% on HumanEval, SE at 65.76% on MMLU, SE at 28.72% on MATH) are substantially outperformed, confirming the value of multi-agent collaboration. Multi-agent baselines AgentVerse (78.29%) and LLM Debate (68.74%/29.42%) are also clearly beaten. Notably, OMAC's structural optimizations (Str-1/2/3) reduce inference cost by 10–25% in API calls and dollar cost compared to DyLAN and AFlow while simultaneously improving accuracy, demonstrating a favorable cost-performance trade-off.

## Relation to Prior Work

OMAC unifies and extends the fragmented MAS optimization literature: DyLAN optimizes agent team composition via unsupervised heuristics, ADAS evolves agent prompts, AFlow uses MCTS for workflow search, and G-Designer/MaAS perform architectural search for collaboration structures. Each of these addresses only a single aspect (functional or structural) of MAS design. OMAC departs by proposing a five-dimension taxonomy that jointly covers both agent functionality (prompt/few-shot optimization, new agent construction) and collaboration structure (candidate selection, dynamic participation, communication routing), and by applying a supervised contrastive-reasoning loop (Semantic Initializer + Contrastive Comparator) uniformly across all dimensions rather than relying on search or unsupervised metrics.

## Why It Matters / Open Questions

The unified five-dimension framework gives practitioners a principled, extensible checklist for what to optimize in a multi-agent system, and the supervised contrastive approach is more interpretable and data-efficient than MCTS or evolutionary search alternatives. However, the experimental scale is modest (168 MMLU questions, 180 HumanEval problems, 140 MATH problems), the base LLM is primarily GPT-3.5-Turbo, and training requires thousands of API calls per dimension, limiting immediate scalability to large agent teams or expensive models. Open questions include whether the five dimensions are truly exhaustive, whether the framework generalizes to centralized/hierarchical MAS architectures (discussed but not fully validated), and whether theoretical guarantees on convergence or optimality can be established.

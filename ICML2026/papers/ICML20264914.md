## Problem

Standard PEFT methods like LoRA impose a single static low-rank update across the entire denoising trajectory of diffusion LLMs, ignoring the fact that input distributions and generation difficulty shift dramatically as the noise level changes. This noise-agnostic design is structurally mismatched to dLLMs, where the model must predict a varying number of tokens with evolving semantic context at each step, leading to suboptimal adaptation—particularly at high noise levels where standard LoRA yields negligible improvement.

## Input / Output

During training, NaRA consumes a (prompt, response) pair and an internally computed noise level λ = m/L_s (the fraction of masked tokens in the response), which is mapped through Gaussian Fourier embeddings into a 64-dimensional vector before feeding the hypernetwork. At inference, the model uses semi-autoregressive block-wise decoding with a block-wise early-termination mechanism (stopping one block after EOS detection), reducing total inference time by ~81% compared to standard decoding. For the image diffusion extension, the normalized diffusion timestep t/T serves as the noise-level input to the same hypernetwork architecture.

## Method

NaRA replaces LoRA's fixed low-rank update ΔW = BA with a noise-conditioned factorization ΔW(λ) = B·C(λ)·A, where A and B remain static per-layer projection matrices and C(λ) ∈ R^{r×r} is a dynamic core matrix generated by a single globally shared hypernetwork (a 2-hidden-layer MLP with SiLU activations). The hypernetwork takes Gaussian Fourier embeddings of λ as input and outputs C(λ) = I_r + η·F_φ(e_λ), with the identity offset and small scaling factor η=0.1 ensuring training stability and gradient equivalence to LoRA at initialization. A constructive proof (Theorem 4.1) shows that any set of N arbitrary update matrices can be exactly represented in this shared-subspace form, provided the rank r covers the union of their column and row spaces. The global sharing of one hypernetwork across all layers and modules keeps the parameter overhead below 0.01% relative to the base model while acting as a regularizer that prevents overfitting compared to per-module hypernetworks.

## Results

On commonsense reasoning (8 benchmarks, LLaDA-8B-Instruct), NaRA achieves 84.09% average accuracy, outperforming LoRA (80.18%), HiRA (82.73%), and P-Tuning (82.45%). On mathematical reasoning, NaRA reaches 80.89% average accuracy (Instruct) and 77.02% (Base), leading on AQuA (57.27% vs. 54.45% for LoRA) and GSM8K. On code generation, NaRA attains 39.32% average pass@1, the only method exceeding 40% on HumanEval (40.04%). Across all three domains, NaRA adds less than 0.01% extra trainable parameters over standard LoRA (0.425% vs. 0.417%).

## Baselines & Comparisons

NaRA consistently outperforms all five baselines across all three domains. Against LoRA (the primary baseline), NaRA gains +3.91% on commonsense (Instruct), +0.82% on math (Instruct), and +1.00% on code generation, with the gap widening to +7.73% on commonsense (Base) where LoRA degrades most. HiRA is the strongest competitor, reaching 82.73% on commonsense (Instruct) and 82.14% (Base), but NaRA still leads by 1.36% and 1.69% respectively; on math, HiRA trails NaRA by 2.82% (Instruct) and 7.37% (Base). P-Tuning is competitive on commonsense (82.45% Instruct) but underperforms NaRA by 1.64% and struggles on math (79.64% vs. 80.89%). Prompt Tuning is consistently the weakest adapter method, scoring 59.32% on commonsense (Instruct) and only 23.23% on math (Base), far below NaRA. In the DoRA combination experiment (Appendix M), NaRA adds +1.30% average pass@1 over standalone DoRA on code generation (39.16% vs. 37.86%), confirming its plug-and-play utility.

## Relation to Prior Work

NaRA extends the LoRA framework (Hu et al., 2022) by inserting a noise-conditioned core matrix C(λ) between the static projection matrices, drawing on hypernetworks (Ha et al., 2016) and Gaussian Fourier embeddings (Tancik et al., 2020) to generate this matrix from the diffusion noise level. It is conceptually inspired by Time-Varying LoRA (Zhuang et al., 2024) for vision diffusion models but departs from discrete timestep-partitioning approaches (e.g., Multi-LoRA, Zhuang et al., 2025) by using a single continuous, globally shared hypernetwork instead of separate adapters per noise interval. The paper positions itself as the first to identify the structural mismatch between noise-agnostic PEFT methods and the inherently noise-dependent dynamics of masked diffusion LLMs, framing the contribution as a principled correction rather than a new task.

## Why It Matters / Open Questions

As diffusion LLMs gain traction as an alternative to autoregressive generation, this work provides a clean, low-overhead recipe for adapting them to downstream tasks that respects the denoising dynamics. The finding that a single shared hypernetwork outperforms module-specific or discrete-interval alternatives suggests that noise-level dependency is a global property of the diffusion process, a principle that could inform future PEFT designs for any iterative generative model. Limitations include evaluation restricted to the LLaDA-8B family, modest absolute gains over LoRA (typically 1–4 points), and the inability to merge weights into the base model (a small inference cost). Open questions include whether the approach scales to larger dLLMs, whether it transfers to continuous-state diffusion LLMs, and whether the noise-awareness principle interacts with reinforcement-learning-based post-training for dLLMs.

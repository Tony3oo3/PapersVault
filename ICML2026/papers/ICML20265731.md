## Problem

Existing neuro-symbolic planners that combine VLMs with classical PDDL planners suffer from two limitations in open-ended embodied environments: (1) the symbolic world is constructed once from perception and remains static, missing action-dependent affordances and latent object properties that are only revealed through interaction; and (2) execution feedback is recorded as task-specific traces rather than distilled into reusable symbolic knowledge, providing weak cross-task and cross-scene support for planning and world refinement.

## Input / Output

The method consumes RGB visual observations and a natural-language task description to construct an initial PDDL problem file (the symbolic world) containing state, property, and relational predicates over typed objects (agent, room/receptacle, object). It outputs a PDDL action plan and an iteratively evolved PDDL problem file. The symbolic world is not a one-shot artifact but is continuously updated across an open-ended step stream of tasks, with the agent's internal symbolic state and memory persisting across tasks while the environment resets per task.

## Method

SCOPE is a self-adaptive closed-loop framework with two synergistic modules. The Symbolic Execution Simulator (SESim) performs two complementary feedback stages per iteration: (i) symbolic validation via a VAL-style PDDL validator that checks preconditions, object definitions, and goal satisfaction, producing structured error traces; and (ii) real execution in the simulator (VirtualHome API or ALFWorld interface) that exposes grounded mismatches invisible to the validator. The combined feedback drives the VLM to refine the action plan and evolve the symbolic world. The Self-Adaptive Symbolic Memory (SASMem) distills this feedback via rule-based (not VLM-summary) extraction into two predicate-level stores—action reasoning knowledge (failure-associated predicates, prerequisite action priors) and world modeling knowledge (missing/incorrect predicate statistics, probing action suggestions)—retrieved on demand by failure-signature queries. A write-gating mechanism with credit assignment reinforces memory entries only when they resolve the same failure pattern or push the first failure to a later step, preventing unbounded accumulation and suppressing noisy entries.

## Results

On the open-ended setting (the paper's primary evaluation), SCOPE achieves 87.6% SR / 89.2% GC on VirtualHome basic scenes and 79.4% SR / 82.0% GC on VirtualHome complex scenes, substantially outperforming the strongest baseline NESYC (56.3% / 50.9% SR) by 11.3% average task success rate. On ALFRED, SCOPE reaches 80.8% SR (basic) and 75.6% SR (complex) in open-ended settings, again far exceeding NESYC (50.1% / 51.7%). In static settings where the symbolic world is complete, NESYC with a classical planner slightly edges out SCOPE (90.1% vs 88.2% SR on VH basic), but this advantage vanishes under dynamic and open-ended conditions where SCOPE's evolving symbolic world provides a decisive edge.

## Baselines & Comparisons

SCOPE outperforms all three baselines by large margins in the open-ended setting, which is the paper's central evaluation. Against VILA (VLM-only planner), SCOPE gains 39.8 points in SR on VirtualHome basic open-ended (87.6% vs 47.8%) and 44.7 points on ALFRED complex open-ended (75.6% vs 30.9%). Against ISR-LLM (iterative symbolic refinement without world evolution), SCOPE leads by 29.5 points on VH basic open-ended and 21.2 points on ALFRED complex open-ended. The most informative comparison is against NESYC (classical planner with neuro-symbolic continual learning): in static settings NESYC actually surpasses SCOPE by ~2 points (90.1% vs 88.2% SR on VH basic), but under open-ended conditions SCOPE's advantage explodes to 31.3 points (87.6% vs 56.3%), because NESYC's fixed symbolic coverage cannot accommodate newly introduced affordances while SCOPE's evolving symbolic world adapts online. The paper reports a 14.4% improvement in step success rate over a continual open-ended run, demonstrating sustained adaptation rather than one-shot performance.

## Relation to Prior Work

SCOPE extends the neuro-symbolic planning line (ISR-LLM, NESYC) that pairs VLMs with PDDL-based classical planners, but departs from prior work in two key ways. First, whereas existing methods construct a static symbolic world from one-shot VLM perception, SCOPE treats the symbolic world as an evolving artifact refined through a closed loop of symbolic validation and real execution feedback (SESim). Second, unlike memory-augmented agents that store raw traces or VLM summaries (Sarch et al., 2024), SCOPE's SASMem applies rule-based distillation into predicate-level symbolic knowledge aligned with PDDL structure, enabling targeted retrieval rather than generic prompt augmentation. The framework thus repurposes the iterative self-refinement idea from ISR-LLM but extends it from single-task plan repair to cross-task symbolic world evolution and knowledge accumulation.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in embodied AI: one-shot symbolic grounding is inherently incomplete in open-ended environments where affordances and state dependencies are only revealed through interaction. The 14.4% step-success-rate gain over a continual open-ended stream and the 11.3% average SR improvement over NESYC demonstrate that a self-adaptive symbolic world can sustain planning robustness where static classical-planner approaches degrade sharply. Key limitations include evaluation restricted to simulators (VirtualHome, ALFRED) where execution feedback is programmatically available, and the open-ended protocol relies on phase-gated action injection rather than truly unbounded novelty. Open questions include whether the write-gating credit-assignment mechanism scales to multi-agent settings, and how real-world sensory feedback (noisy, partial, non-deterministic) would affect the SESim loop.

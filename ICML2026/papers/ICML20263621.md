## Problem

Standard MWPM decoders for topological quantum codes rely on static, distance-based edge weights that assume independent bit and phase errors, failing to exploit the rich statistical correlations present in specific syndrome realizations. Moreover, the MWPM algorithm is inherently non-differentiable due to its discrete combinatorial operations, which severs gradient flow and prevents end-to-end learning of optimal weighting strategies. This paper addresses both limitations by formulating a differentiable training framework that augments, rather than replaces, the classical matching algorithm.

## Input / Output

The method takes a binary syndrome vector S ∈ {0,1}^N (where N is the total number of stabilizers) and maps it to a complete graph over active defect nodes, with rich per-node features (2D lattice coordinates, stabilizer type, distance-to-center, positional encoding, learnable embeddings) and per-edge features (Manhattan distance, coordinate deltas, error-type flag). The network outputs a probability p_ij ∈ [0,1] for every directed edge, which is aggregated via max over both directions and converted to undirected weights w_ij = −ln(p'_ij) for the downstream MWPM solver, ultimately producing a perfect matching that specifies the correction operator.

## Method

The Quantum Weight Predictor (QWP) is a two-stage hybrid: a 4-layer TransformerConv GNN with multi-head attention and a gating mechanism encodes local syndrome topology, followed by a 2-layer Transformer Encoder that processes concatenated node-edge representations to capture global dependencies among competing error chains. The key training innovation is a proxy loss — binary cross-entropy between predicted edge probabilities and ground-truth matching edges, plus an entropy regularization term (λ=0.01) that pushes predictions toward a sharp bimodal distribution, making the resulting −ln(p) weights highly discriminative for the MWPM minimizer. Ground-truth labels are generated by a heuristic clustering algorithm that decomposes physical error configurations into independent clusters, applies localized MWPM with Manhattan weights, and iteratively permutes assignments to resolve logical errors. The architecture maintains a nearly constant ~3.9M parameter footprint across code distances, and the Transformer weights transfer effectively across lattice sizes with only 20 epochs of fine-tuning.

## Results

On the Toric code under depolarizing noise, NMWPM achieves an error threshold of 17.9%, approaching the maximum likelihood bound of 18.9%, while under independent noise it reaches 10.95% (vs. the 11.0% ML bound). On the Rotated Surface code under depolarizing noise, the threshold is 17.7%. At L_code=10 under depolarizing noise, NMWPM reduces logical error rate by 17–50% relative to standard MWPM for physical error rates p > 0.12, and maintains a nearly constant parameter count of ~3.9M across all code distances (vs. 6.71M for QECCT at L_code=10).

## Baselines & Comparisons

NMWPM outperforms the standard MWPM baseline across all evaluated settings: on the Toric code under depolarizing noise the threshold improves from 16.0% to 17.9%, and under independent noise from 10.3% to 10.95%; on the Rotated Surface code the threshold rises from 14.0% to 17.7%. Against the strongest neural baseline QECCT, NMWPM achieves a marginal but consistent edge on the Toric code (17.9% vs. 17.8% depolarizing; 10.95% vs. 10.7% independent) and a clearer advantage on the Rotated Surface code (17.7% vs. 17.2%), while also using roughly half the parameters at L_code=10 (3.9M vs. 6.71M) and running 2.8×–5× faster in inference (4.01 ms vs. 20.1 ms at L_code=10). BPOSD-2 is consistently outperformed, with thresholds of 16.0% (Toric depolarizing) and 10.8% (Toric independent) versus NMWPM's 17.9% and 10.95% respectively. The performance gap over QECCT widens with code distance, being modest at L_code=6–8 but pronounced at L_code=10, which the authors attribute to the Transformer encoder's ability to resolve long-range error-chain correlations.

## Relation to Prior Work

This paper positions itself at the intersection of classical combinatorial decoding and learned priors, building directly on MWPM (Fowler, 2015) as the algorithmic backbone while departing from both pure classical decoders (which use static distance-based weights) and pure neural decoders like QECCT (Choukroun & Wolf, 2024) that replace matching entirely. The GNN+Transformer hybrid for edge-weight prediction draws on the TransformerConv operator (Shi et al., 2021) and standard Transformer encoders, but the key methodological departure is the proxy loss formulation (BCE + entropy regularization) that makes the non-differentiable MWPM pipeline trainable end-to-end. The ground-truth generation via heuristic clustering with localized MWPM fallback is a practical contribution that addresses the degeneracy problem inherent in topological codes, distinguishing it from prior neural decoders that either ignore degeneracy or require expensive exact solvers for labels.

## Why It Matters / Open Questions

Achieving thresholds within 1% of maximum-likelihood bounds (17.9% vs 18.9% depolarizing; 10.95% vs 11.0% independent) while retaining MWPM's polynomial-time guarantee and a constant ~3.9M parameter footprint across code distances makes this a practically compelling decoder for near-term fault-tolerant architectures. The quadratic Transformer complexity over edges remains a scaling concern for very large code distances, and the evaluation is limited to toric, rotated surface, and repetition codes under idealized noise models—broader validation on LDPC codes, circuit-level noise with correlated errors, and real-time latency constraints on target hardware remain open. The transfer-learning result (20-epoch fine-tune from L=10 to L=8) suggests the learned representations are code-distance-agnostic, which could reduce the training cost for deploying at new code sizes, but this has only been tested in one direction and one code family.

## Problem

Despite the central role of attention heads in Transformers, there is no principled tool to answer 'why did the model attend to this token?' The scalar query-key dot product conceals the structure of how two tokens interact, and prior approaches to decomposing QK space rely on pre-trained features (e.g., sparse autoencoders or probes) or supervised training, leaving a gap for a training-free, feature-agnostic decomposition method.

## Input / Output

The method consumes query and key vectors extracted from a single attention head, along with human-defined positive/negative conditions that specify which token pairs share (or differ in) a feature of interest while holding all other factors constant. It produces a contrastive covariance matrix of size d_head × d_head, from which SVD yields the feature's rank (estimated via 99% Frobenius-norm threshold) and orthogonal bases in both query and key spaces. As a downstream output, the recovered query-space bases enable token-level attention logit attributions, decomposing each pre-softmax logit into contributions from identified features plus a residual.

## Method

The core mechanism is a contrastive covariance: for a target latent feature, the method computes E[qk^T | feature matches] minus E[qk^T | feature differs], while holding all other latent variables fixed across the two conditions. This difference analytically isolates the bilinear interaction attributable solely to the target feature, as shown via a derivation in the toy payload-retrieval setting. SVD on the resulting contrastive covariance matrix recovers the feature's rank and its subspaces in query and key spaces. The authors validate the approach on a controlled toy task (discrete and continuous latent variables) with causal interventions confirming that swapping coordinates in the recovered subspaces shifts attention as expected, and identify two failure modes: feature splits (when dimensions are abundant) and superposition (when dimensions are scarce). Applied to Llama 3.1-8B and Qwen 3-4B, the method recovers rank-1 categorical semantic subspaces in Filter Heads and rank 2–3 (order-ID) and rank 9–10 (lexical) binding subspaces, with causal interventions confirming their functional roles.

## Results

On the toy payload-retrieval task, trained attention heads achieve 99% accuracy (discrete latent variables) and ~85% accuracy (continuous, d_head=8). The contrastive covariance method exactly recovers the ground-truth rank of each latent variable whenever r₁+r₂ < d_head (no superposition). Causal interventions on the recovered QK subspaces (z₁+z₂) shift essentially all attention from the original token to the target token, while random subspaces of the same dimension produce a much smaller shift. On Llama 3.1-8B, categorical semantic features in Filter Heads are each rank-1 (5 categories → 5-dim subspace), and binding features decompose into order-ID (rank 2–3) and lexical (rank 9–10) subspaces; intervening on both binding subspaces shifts the majority of attention, whereas random subspaces of matching rank have negligible effect.

## Baselines & Comparisons

The primary baseline throughout the paper is random subspaces of the same dimension as the recovered feature subspaces. In the toy model (Figure 4), intervening on the true z₁+z₂ subspaces moves all attention to the target token, while the 'Rand r₁,r₂,r₁+r₂' baselines induce a substantially smaller shift. In Llama 3.1-8B Filter Heads (Figure 7), the recovered 5-dimensional categorical subspace shifts attention between categories (e.g., fruits → animals) far more effectively than a random 5-dimensional baseline, though it does not shift all attention, indicating additional unexplained QK structure. For binding features (Figure 9), intervening on the order-ID or lexical subspace individually shifts some attention, and intervening on both shifts the majority, while random subspaces of the same ranks (rank 2–3 or 9–10) have negligible effects. The paper does not compare against other QK-decomposition methods (e.g., SAE-based approaches by Kamath et al. 2025 or sparse-mask methods by Wynrow & Sharkey 2024) head-to-head; instead it positions its contribution as requiring no pre-trained features or additional training, unlike those prior approaches.

## Relation to Prior Work

This paper sits at the intersection of QK-space analysis (Kamath et al., 2025; Pan et al., 2024; Franco & Crovella, 2025) and the superposition literature (Elhage et al., 2022), but departs from prior QK decomposition work by not relying on pre-trained sparse autoencoders, linear probes, or learned sparse masks. Instead, it introduces a contrastive covariance construction—defining positive and negative query-key pairings that isolate a single feature while holding others constant—followed by SVD to recover low-rank subspaces. This training-free, feature-targeted approach is conceptually closer to causal intervention methodology than to the representation-learning-based decompositions dominant in prior QK-space studies.

## Why It Matters / Open Questions

The paper provides a simple, analytically grounded tool for localizing specific semantic features (categorical, binding) within attention heads' QK spaces, validated on both controlled toy models and Llama 3.1-8B / Qwen 3-4B. Key limitations include the requirement for human-defined positive/negative conditions (precluding fully unsupervised decomposition), the breakdown under superposition when feature ranks exceed head dimension, and the 'feature split' phenomenon where the model decomposes a single latent variable into independent coordinates. Open questions the authors highlight include how to perform unsupervised QK decomposition, how to interpret multi-dimensional or superposed features, and how to handle the ambiguity when multiple QK components exhibit identical observable behavior.

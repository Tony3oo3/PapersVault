## Problem

Existing autoformalization evaluations reduce semantic correctness to opaque binary verdicts or scalar scores, providing no interpretable signal about the cause, location, or correction of translation failures. This opacity severely limits both human debugging and automated model improvement in formal mathematical reasoning pipelines.
![Teaser figure](../imgs/ICML20264667/cropped_page1_idx0.webp)

## Input / Output

The model receives a natural language mathematical statement and a candidate Lean 4 formalization, formatted in a ShareGPT conversation template that embeds the full 28-category SCI Error Taxonomy in the system prompt (max 3,072 tokens). It produces a single structured diagnostic sequence containing four fields: a binary alignment verdict, a specific error category ID from the taxonomy, the problematic code segment (localization), and a corrected Lean 4 statement that is semantically aligned with the informal input. All four fields are generated in one forward pass rather than through separate pipeline stages.

## Method

The core contribution is the SCI Error Taxonomy, a hierarchical partition of autoformalization errors into 28 categories across three disjoint dimensions (Semantic, Constraint, Implementation) with strict priority ordering to guarantee deterministic single-label assignment. Training data is synthesized via taxonomy-guided error injection: an LLM agent modifies 17,825 aligned NL-FL seed pairs to introduce specific error types, followed by two-stage post-processing (Lean REPL compilation filtering and independent LLM re-tagging), yielding 56,287 annotated samples. FORMALRX-8B is a Qwen3-8B backbone fine-tuned with standard supervised fine-tuning (negative log-likelihood over the diagnostic sequence) using progressive training—introducing the four tasks incrementally with data replay—which outperforms joint training and avoids the catastrophic forgetting of sequential training. The unified generative architecture performs all four diagnostic sub-tasks in a single forward pass, mitigating error propagation between cascaded stages and encouraging shared representations for global semantic and local syntactic correctness.

## Results

On the in-domain FORMALRX-Test (7,030 samples), FORMALRX-8B achieves F1 of 0.881 on alignment verdict, 0.709 on 28-class error categorization, 0.750 accuracy on error localization, and 0.729 accuracy on correction generation. The most dramatic advantage is in categorization, where FORMALRX-8B outperforms the strongest frontier baseline (Claude-Sonnet-4.6, F1=0.475) by 23.4 percentage points. On the out-of-domain ConsistencyCheck benchmark, FORMALRX-8B achieves F1=0.596, outperforming LeanScorer (0.588) and all instruction-tuned base models, though trailing frontier LLMs such as GPT-5-mini (0.740).

## Baselines & Comparisons

FORMALRX-8B wins on all four diagnostic tasks against every baseline. Against the strongest frontier model Claude-Sonnet-4.6, it edges ahead on verdict (F1 0.881 vs. 0.880), localization (0.750 vs. 0.739), and correction (0.729 vs. 0.714), but pulls far ahead on categorization (0.709 vs. 0.475, +23.4 pts), indicating that fine-grained 28-class error typing is not yet emergent in frontier LLMs. Against GPT-5.3-codex, the gaps are larger on categorization (0.709 vs. 0.380) and correction (0.729 vs. 0.688). Against the Qwen3-8B instruct baseline (same backbone, no diagnostic fine-tuning), FORMALRX-8B improves categorization F1 from 0.155 to 0.709 and correction accuracy from 0.458 to 0.729, demonstrating that the diagnostic capability is learned from the SCI-annotated data rather than inherited from pre-training. Specialized alignment metrics (LeanScorer F1=0.632, BLEU F1=0.404) are limited to binary verdicts and cannot perform the three diagnostic sub-tasks, underscoring the inadequacy of heuristic signals for interpretable evaluation.

## Relation to Prior Work

This paper departs from the three established streams of autoformalization evaluation (FL-FL comparison, NL-NL back-translation, and NL-FL LLM-as-judge) by reframing the task from binary alignment verdicts to structured multi-component diagnostics. Rather than building on a specific prior method, it synthesizes a novel SCI Error Taxonomy from manual analysis of ~2,000 misaligned pairs and uses standard SFT on a Qwen3-8B backbone to jointly perform verdict, categorization, localization, and correction in a single forward pass. The conceptual departure is the partition-based taxonomy design with strict priority ordering, which ensures deterministic error attribution—a property absent from prior rule-based or LLM-voting evaluators that only output a yes/no alignment signal.

## Why It Matters / Open Questions

FORMALRX provides the first fine-grained diagnostic benchmark and a practical 8B model that can pinpoint *where* and *why* an autoformalization fails, enabling targeted debugging and iterative model improvement rather than opaque pass/fail signals. The SCI Error Taxonomy, while Lean 4-specific in its Implementation dimension, is designed to be adaptable to Coq and Isabelle, potentially becoming a shared diagnostic vocabulary for the formal-math community. Key open questions include cross-distribution robustness (the model degrades on naturally-occurring errors in ConsistencyCheck), whether the manually curated 28-category taxonomy captures long-tail failure modes, and whether the diagnostic signals can be effectively integrated into RLHF or iterative autoformalization pipelines.

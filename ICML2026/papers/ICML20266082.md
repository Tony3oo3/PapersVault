## Problem

Existing memory benchmarks are dialogue-centric and natural-language-centric, failing to capture the three defining properties of real agent trajectories: diverse machine-generated symbolic representations (JSON, code, tables), explicit causal dependencies between actions and state transitions, and dense objective information without conversational filler. This leaves a critical gap in evaluating whether memory systems can actually support long-horizon agentic decision-making rather than just multi-turn chat recall.
![Teaser figure](../imgs/ICML20266082/cropped_page0_idx0.webp)

## Input / Output

The system ingests full agent-environment interaction trajectories (action-observation sequences) spanning six real-world domains (Web, SWE-bench, Spider2, ALFWorld, BALROG, GAIA) and two synthetic environments (TextWorld, BabyAI), with trajectory lengths ranging from ~6K to ~997K tokens. Each trajectory is paired with 12 expert-annotated or programmatically generated QA pairs probing four memory capabilities (Recall, Causal Inference, State Updating, State Abstraction). The memory system outputs a structured causality graph as its persistent state and produces open-ended text answers to each query, evaluated via LLM-as-judge binary correctness.

## Method

AMA-Agent constructs a Causality Graph by having an LLM parse each adjacent turn triple (o_{t-1}, a_t, o_t) to extract task-relevant entities, state changes, and latent causal dependencies, which are instantiated as directed causality edges and undirected association edges connecting state nodes in a global graph; nodes are then embedded into a latent space via Qwen3-4B-embedding for similarity-based access. For retrieval, AMA-Agent first fetches top-K=5 nodes by embedding similarity and performs self-evaluation of evidence sufficiency; if insufficient, it selectively invokes a graph node search tool (depth-controlled neighborhood traversal for multi-hop causal chains, used in ~10% of queries) or a keyword search tool (writing and executing scripts for programmatic counting and pattern aggregation, used in ~23.5% of queries). This design avoids the two failure modes identified in the empirical study: lossy compression that discards dense state information, and unreliable similarity-based retrieval that cannot extract precise evidence from machine-generated representations.

## Results

On the real-world subset of AMA-Bench (2,496 QA pairs across six agent domains), AMA-Agent achieves 57.22% average accuracy with Qwen3-32B, outperforming the strongest RAG baseline HippoRAG2 (44.80%) by 11.2 points and the leading memory-agent baselines MemoRAG (46.06%) and EMem (46.10%) by over 11 points. As a long-context reference, GPT-5.2 reaches 72.26% average accuracy, indicating that even frontier models have not fully mastered trajectory-based agent memory. On the synthetic subset, AMA-Agent maintains consistently high accuracy up to 128K tokens while the long-context baseline degrades sharply beyond 32K. Out-of-benchmark, AMA-Agent also leads on LoCoMo (76.20% vs. HippoRAG's 72.10%), confirming generalizability beyond agent trajectories.

## Baselines & Comparisons

AMA-Agent (57.22%) decisively outperforms all 15 baselines on the real-world subset. Among RAG methods, it beats HippoRAG2 (44.80%) by 11.2 points, Qwen3-Emb-4B (42.27%) by 15.0 points, GraphRAG (32.58%) by 24.6 points, and BM25 (34.36%) by 22.9 points. Among memory-agent systems, it surpasses MemoRAG (46.06%) by 11.2 points, EMem (46.10%) by 11.1 points, MemoryBank (33.97%) by 23.3 points, MemGPT (33.04%) by 24.2 points, Mem0 (21.04%) by 36.2 points, and Mem1 (12.29%) by 44.9 points. The gap is largest against compression-based methods (Mem1, SimpleMem, Mem0), which the paper attributes to lossy summarization destroying dense causal state information. On the out-of-benchmark LoCoMo dialogue task, AMA-Agent (76.20%) still leads HippoRAG (72.10%) by 4.1 points, GraphRAG (65.39%) by 10.8 points, and Mem0 (63.51%) by 12.7 points, confirming that the causality-graph + tool-augmented retrieval design generalizes beyond agent trajectories. In end-to-end agent rollouts on TextWorld and Spider2, AMA-Agent leads on every column (e.g., 51.5% vs. 47.5% for LongContext on TextWorld E2E), with QA accuracy and task success showing Pearson correlations of 0.96 and 0.98 respectively.

## Relation to Prior Work

This paper carves new ground at the intersection of memory evaluation and agentic AI. Prior memory benchmarks (LoCoMo, LongMemEval, MemoryAgentBench) are dialogue-centric, evaluating retention over multi-turn human-agent chats, while long-context benchmarks (RULER, LongBench v2) test static document comprehension. AMA-Bench departs from both by formulating memory as a POMDP-grounded problem over agent-environment trajectories with machine-generated representations, causal state transitions, and dense objective information. On the method side, AMA-Agent repurposes knowledge-graph construction (à la GraphRAG) but replaces entity-relation extraction with causality-edge extraction, and augments similarity retrieval with tool-based graph traversal and programmatic keyword search—departing from the lossy compression and pure similarity paradigms dominant in prior memory agents (MemGPT, MemoryBank, Mem0, A-Mem).

## Why It Matters / Open Questions

The benchmark reveals that memory systems which outperform long-context baselines on dialogue tasks actually underperform them on agent trajectories, challenging the field's assumption that structured memory is universally superior. The finding that memory architecture choice (0.45 score range) dwarfs backbone scale (0.038 improvement from 8B to 32B) redirects research attention toward memory design rather than model scaling. A key limitation is the focus on in-episode memory; extending these evaluation standards to cross-task lifelong learning and multi-agent settings remains open. The synthetic subset's strong correlation with real-world performance (Fig. 9A) offers a scalable path for future memory research without expensive manual annotation.

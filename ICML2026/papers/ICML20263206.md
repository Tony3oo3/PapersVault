## Problem

Graph Random Features (GRFs) approximate graph kernel matrices via random walks on graph nodes, but they require explicit graph materialization — a quadratic-size adjacency matrix — which is both memory-prohibitive for large point clouds and incompatible with modern GPU accelerators that lack native support for combinatorial graph operations. Many practically important graphs (ε-neighborhood, Gaussian-affinity, k-NN) are naturally defined implicitly as functions of node feature vectors, yet GRFs discard this structure. The paper asks: can one compute GRF-based kernel actions in linear time without ever constructing the graph?

## Input / Output

SWING consumes a point cloud P ∈ R^{N×d} (node feature vectors), an attribute matrix V ∈ R^{N×d_v}, a modulation function ρ, pre-sampled random feature maps φ_{f,σ} and ψ_g, a halting probability p_halt, and a number of walks m. It outputs an approximation Ŷ ≈ K_α(W)V ∈ R^{N×d_v} without ever forming the N×N weight matrix W; edge weights w_{i,j} = f(p_i − p_j) are evaluated only through their random-feature linearizations. In the ViT application, the output is instead a soft topological mask M added to the attention logits, and the graph topology is static so walks are pre-computed and frozen.

## Method

SWING replaces discrete node-to-node random walks with continuous walks in R^d: at each step the walker's new position is a Gumbel-softmax convex combination of all node positions, where the mixing weights are proportional to exp(log f(p_i − x^t) + τ_i)/σ². To achieve O(N) per step, the kernel f(x−y) is linearized via random features constructed from its inverse Fourier transform (positive random features for Gaussian kernels, Bessel-based features for step functions), and the exponentiated Gumbel factor exp(τ/σ²) is factorized into a product of two independent draws from distributions P_a and P_b whose product recovers the Fréchet distribution — this factorization lets all node-dependent sums be pre-computed once in O(N) and reused in O(1) per walk step. The load update (degree normalization) is similarly relaxed through the same random-feature maps, and the final kernel action K_α(W)V is computed implicitly by showing that each signature-vector dot product reduces to an O(1) evaluation after O(N) precomputation, yielding overall O(NTm) complexity with no graph materialization.

## Results

On ImageNet, ViT-SWING achieves 80.34% top-1 accuracy, outperforming the standard ViT baseline (80.10%) and ViT-GRFs (80.09%). On Places365, ViT-SWING reaches 55.97% top-1 accuracy versus 55.78% (ViT) and 55.39% (ViT-GRFs). On synthetic point clouds, SWING traces the Pareto-optimal error-time frontier with inference speedups exceeding one order of magnitude over standard GRFs, while achieving lower Frobenius Norm Error for the same number of random walks. On vertex normal prediction (Thingi10K), SWING matches GRF cosine similarity while being substantially faster on CPU.

## Baselines & Comparisons

Against the standard GRF baselines (Choromanski 2023; Reid 2024), SWING achieves lower Frobenius Norm Error for the same number of random walks (300) across all three kernel types (p-step random walk, diffusion, d-regularized Laplacian), and traces the Pareto-optimal accuracy-time frontier with over 10x speedup. On vertex normal prediction, SWING matches GRF cosine similarity (e.g., 0.8301 vs 0.8255 on a 64-vertex mesh) while being significantly faster on CPU. Against the standard ViT baseline (Dosovitskiy 2020), ViT-SWING improves top-1 accuracy by +0.24 on ImageNet and +0.19 on Places365. Against ViT-GRFs (Reid 2025), SWING improves by +0.25 on ImageNet and +0.58 on Places365, showing that the implicit space-walk relaxation is more effective than explicit graph walks for topological masking. Against the Lanczos method (Musco 2018) for matrix exponential computation, SWING substantially outperforms it on vertex normal prediction (e.g., 0.8301 vs 0.7855 on a 64-vertex mesh; 0.6255 vs 0.0768 on a 1094-vertex mesh), where Lanczos degrades severely with mesh size.

## Relation to Prior Work

SWING is a direct relaxation of the Graph Random Features (GRFs) framework (Choromanski, 2023; Reid et al., 2024), which approximates graph kernel matrices via random walks on explicitly materialized adjacency matrices. The key conceptual departure is replacing discrete node-to-node transitions with continuous walks in the d-dimensional embedding space, enabled by a Gumbel-softmax relaxation (Jang et al., 2017) of the categorical transition distribution. To achieve linear-time complexity, SWING further linearizes the transition and load-distribution kernels via random Fourier features (Rahimi & Recht, 2007), with a novel Fréchet-distribution factorization (via Mellin transforms) that decouples the Gumbel noise into precomputable per-node and per-walker factors. The method thus sits at the intersection of GRFs, random-feature kernel approximation, and differentiable discrete optimization.

## Why It Matters / Open Questions

SWING removes the explicit graph materialization bottleneck that has constrained GRFs to relatively small graphs, enabling O(N) kernel-matrix-vector products on implicitly-defined graphs (e.g., ε-neighborhood graphs on point clouds) that may have Θ(N²) edges. This makes graph-kernel methods viable on modern accelerators and for large-scale applications such as 3D point-cloud processing and ViT attention with topological masking. Open questions include: how approximation error accumulates over longer walks (T is kept small in practice), whether the Fourier-based RF construction generalizes cleanly to non-radial or anisotropic edge-weight functions, and whether the Gumbel-softmax temperature can be adapted per-step rather than fixed. The paper's theoretical guarantees rely on standard random-feature concentration bounds and do not yet provide end-to-end error analysis for the full walk-based kernel approximation.

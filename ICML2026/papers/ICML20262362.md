## Problem

Fine-tuning pretrained Transformer models to improve zero-shot performance on a target task can degrade their in-context learning ability, but the mechanism and conditions under which this degradation occurs remain poorly understood. This paper asks: how do different fine-tuning objectives modify attention parameters, and which parameter updates are responsible for the loss of few-shot capability?

## Input / Output

The model receives a d-dimensional input vector x and, in the few-shot setting, n context demonstrations of the form (x_i, y_i) stacked into a prompt matrix Z ∈ R^{(d+2)×n}. It outputs a scalar prediction ŷ for the linear regression response y = θ^T x + e. The zero-shot mode uses only x (no demonstrations), while the few-shot mode conditions on n examples; the test error is evaluated in both modes across in-distribution task θ₀ and out-of-distribution task −θ₀.

## Method

The paper analyzes a single-layer linear attention model f(Z; V, Q) = Z + (1/ncol(Z))·VZZ^T QZ on linear regression tasks, deriving closed-form optimal parameters and test errors under four training regimes: pretraining, full fine-tuning with zero-shot loss, value-matrix-only fine-tuning with zero-shot loss, and value-matrix fine-tuning with an auxiliary few-shot loss. The key structural insight is that the query-key matrix Q (specifically Q₁₁ = Σ⁻¹) encodes the in-context learning mechanism equivalent to preconditioned gradient descent, while the value vector v₂₁ in V can be updated to inject task-specific knowledge for zero-shot prediction without disrupting the few-shot pathway. Full fine-tuning overwrites Q and destroys few-shot performance entirely, whereas freezing Q and updating only V preserves few-shot capability while achieving near-optimal zero-shot error σ² + (2/(d+4))θ₀^TΣθ₀. An auxiliary few-shot loss further tunes the remaining free parameter w to minimize target-task few-shot error, but Proposition 4.10 shows this incurs excess error on other tasks proportional to (1 − ρ(θ, θ₀))², formalizing a target-task versus generalization trade-off.

## Results

The paper derives closed-form test errors for four training regimes of linear attention models. Full fine-tuning achieves the optimal zero-shot error σ² but degrades asymptotic few-shot error to σ² + θ₀ᵀΣθ₀ (the worst possible), while value-matrix fine-tuning achieves a near-optimal zero-shot error σ² + 2/(d+4)·θ₀ᵀΣθ₀ while preserving few-shot error at σ² + 1/(d+4)²·θ₀ᵀΣθ₀. Adding an auxiliary few-shot loss further reduces in-distribution few-shot error to σ² (best) but increases out-of-distribution few-shot error to σ² + 4/(d+4)²·θ₀ᵀΣθ₀. On MMLU with Qwen2.5-3B-Instruct, value-matrix fine-tuning preserves 7-shot accuracy on Humanities while matching full fine-tuning's zero-shot improvement, and the auxiliary few-shot loss improves Humanities few-shot at the cost of reduced STEM few-shot accuracy.

## Baselines & Comparisons

The paper compares four training regimes rather than external methods: (1) pretrained model, (2) full fine-tuning with zero-shot loss, (3) value-matrix-only fine-tuning with zero-shot loss, and (4) value-matrix fine-tuning with both zero-shot and auxiliary few-shot losses. Full fine-tuning wins on zero-shot (achieving the irreducible σ²) but catastrophically loses on few-shot, where error equals the worst-case σ² + θ₀ᵀΣθ₀ even on the target task. Value-matrix fine-tuning sacrifices a small zero-shot gap (factor 2/(d+4) of θ₀ᵀΣθ₀) to reduce few-shot error by a factor of (d+4)², making it the best trade-off for preserving general-purpose few-shot ability. The auxiliary few-shot loss variant wins on in-distribution few-shot (achieving σ²) but loses on out-of-distribution few-shot, with excess error proportional to (1−ρ)² where ρ is the Σ-inner-product cosine similarity between tasks. On MMLU, value-matrix fine-tuning matches full fine-tuning's zero-shot gain on Humanities while retaining the pretrained model's 7-shot accuracy, whereas full fine-tuning degrades few-shot accuracy. The empirical linear regression experiments (d=5, σ²=0.1, m=n=20) confirm all theoretical predictions with empirical points matching theoretical curves.

## Relation to Prior Work

This paper builds directly on the linear attention framework of Ahn et al. (2023) and Zhang et al. (2024), whose models it generalizes by introducing an additional scalar parameter q in the query-key matrix. While prior work has independently characterized how pretrained linear attention models implement in-context learning (as preconditioned gradient descent) and how fine-tuning improves target-task performance, this paper is the first to provide a closed-form theoretical analysis of how fine-tuning objectives modify attention parameters and under what conditions in-context learning degrades. It departs from recent empirical studies of the fine-tuning/ICL trade-off (Wang et al., 2024a,b; Mosbach et al., 2023) by offering a mechanistic explanation rooted in the geometry of the value and query-key matrices, and from matrix-wise fine-tuning work (Yao et al., 2025; Hu et al., 2022) by explicitly evaluating whether fine-tuning preserves the pretrained model's intrinsic few-shot capability rather than only measuring target-task accuracy.

## Why It Matters / Open Questions

The paper provides a theoretically grounded, actionable recommendation—freeze the query-key matrix and fine-tune only the value matrix—that practitioners can adopt to improve zero-shot performance without sacrificing in-context learning, addressing a widely observed but previously unexplained degradation. The finding that an auxiliary few-shot loss improves target-task few-shot performance at the cost of out-of-distribution generalization formalizes a fundamental tension in multi-task fine-tuning. Key limitations include the restriction to linear attention (no softmax, single layer, no MLP), the use of an analytical surrogate for pretraining rather than actual language model pretraining, and the MMLU experiments being explicitly framed as illustrative rather than conclusive. Extending the theory to softmax attention, multi-layer architectures, and realistic task distributions remains an important open direction.

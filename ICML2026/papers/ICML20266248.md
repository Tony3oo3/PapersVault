## Problem

Existing open-vocabulary 3D panoptic segmentation methods either rely on slow per-scene optimization or follow a two-stage feed-forward paradigm that first extracts view-dependent 2D features independently and then fuses them in 3D, causing error accumulation and inconsistent semantic/instance predictions across views. No prior method jointly predicts both semantic and instance attributes in a single end-to-end pass while maintaining 3D consistency and supporting object-level applications like robotic manipulation and scene editing.
![Teaser figure](../imgs/ICML20266248/cropped_page0_idx1.webp)

## Input / Output

The method takes N unposed multi-view RGB images (resized to 518-pixel max long-edge, 2≤N≤24 views) and optional text prompts as input, requiring no camera poses or 2D preprocessing. It outputs a unified set of 3D panoptic Gaussians, each carrying geometry (position, opacity, rotation, scale, SH color), a 512-dim CLIP-aligned semantic feature, and a 32-dim instance feature. These Gaussians can be splatted to render novel-view RGB, semantic, and instance maps in approximately 1 second per scene on a single A800 GPU.

## Method

EPS3D uses a VGGT-based Alternating-Attention transformer as a geometry backbone, followed by DPT-based heads that regress Gaussian primitives (depth, opacity, orientation, scale, color) alongside per-Gaussian semantic and instance features in a single feed-forward pass. Training employs knowledge distillation from 2D teachers (LSeg for semantics via cosine similarity, SAM for instances via InfoNCE contrastive loss) applied through feature splatting, which implicitly enforces multi-view consistency by propagating single-view supervision gradients to all contributing Gaussians. The key architectural novelty is a semantic-instance mutual enhancement module: Ins2Sem aligns semantic features among Gaussians sharing the same instance (selected by instance-feature similarity), while Sem2Ins fuses semantic features into instance features via a projection-concat-fusion network to sharpen instance boundaries. This coupled design, combined with the end-to-end formulation that eliminates intermediate 2D feature extraction, avoids the error accumulation inherent in two-stage baselines.

## Results

On the 8-view multi-view setting, EPS3D achieves 0.6314 mIoU (Context Sem) and 0.6169 mIoU (Novel Sem) on ScanNet, outperforming the strongest feed-forward baseline Uni3R (0.4885 / 0.5215) by +14.3 and +9.5 percentage points respectively. On Replica, EPS3D reaches 0.4999 mIoU (Context Sem) and 0.4833 mIoU (Novel Sem), surpassing Uni3R (0.3066 / 0.3216) by approximately +19 and +16 percentage points. For instance segmentation, EPS3D achieves 0.4602 mIoU / 0.4044 F-score (Context) and 0.3912 / 0.4329 (Novel) on ScanNet, dramatically exceeding Unified-Lift (0.1456 / 0.1248 and 0.1876 / 0.1304). Inference time is 0.73 s per scene (2-view) on a single A800 GPU, comparable to other feed-forward methods.

## Baselines & Comparisons

EPS3D outperforms all seven baselines across every reported metric on both ScanNet and Replica. Against the strongest feed-forward semantic baseline Uni3R, EPS3D gains +14.3 pp mIoU on ScanNet Context Sem (0.6314 vs 0.4885) and +19.3 pp on Replica Context Sem (0.4999 vs 0.3066), while also improving Novel-view semantics by +9.5 pp (ScanNet) and +16.2 pp (Replica). Against the prior feed-forward method LSM, the gains are even larger: +29.5 pp on ScanNet Context Sem and +22.0 pp on Replica Context Sem. For instance segmentation, EPS3D substantially surpasses Unified-Lift (the only prior 3D instance baseline), e.g., 0.4602 vs 0.1456 mIoU on ScanNet Context Inst (+31.5 pp) and 0.3468 vs 0.2264 on Replica Novel Inst (+12.0 pp). The 2D-only baselines (LSeg, SAM) lack 3D consistency and cannot produce cross-view instance predictions, while per-scene optimization methods (NeRF-DFF, Feature-3DGS) are 10–100× slower (minutes vs sub-second) and achieve lower semantic mIoU. EPS3D is the only method that simultaneously reports competitive semantic and instance metrics with feed-forward speed (~0.73 s per scene).

## Relation to Prior Work

EPS3D builds on the VGGT geometry transformer and Anysplat feed-forward 3D Gaussian splatting as its architectural backbone, extending the 3D Gaussian representation with per-Gaussian semantic (CLIP-aligned) and instance features. It departs from the dominant two-stage paradigm (LSM, Uni3R) that first extracts per-view 2D features with pretrained models and then fuses them in 3D, instead predicting a unified 3D panoptic Gaussian representation end-to-end from raw multi-view images. The semantic-instance mutual enhancement module (Ins2Sem/Sem2Ins) is a novel training-time coupling mechanism not present in prior feed-forward or per-scene-optimization methods, which typically treat semantic and instance prediction as independent branches.

## Why It Matters / Open Questions

By eliminating the two-stage 2D-preprocessing pipeline, EPS3D removes a major source of view inconsistency and error accumulation while achieving ~1s per-scene inference (vs. minutes for optimization-based methods), making open-vocabulary 3D panoptic segmentation practical for real-time applications like robotic manipulation and AR/VR scene editing. The paper acknowledges limitations: it targets only static indoor scenes and is constrained by the diversity of indoor training data (ScanNet/ScanNet++), leaving dynamic environments and outdoor generalization as open questions. The finding that feature splatting during training implicitly enforces multi-view consistency from single-view supervision is a useful insight for future feed-forward 3D understanding architectures.

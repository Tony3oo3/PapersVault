## Problem

Diffusion-based LLMs (dLLMs) suffer from O(N³) inference complexity because each of N denoising steps recomputes full bidirectional attention across all tokens, and traditional KV caching is incompatible with their bidirectional attention mechanism. The paper identifies two distinct computational redundancies that uniform strategies fail to exploit: the static prompt is recomputed identically every step, and the response evolves sparsely with most tokens remaining stable across adjacent denoising steps.

## Input / Output

The method operates on a static text prompt concatenated with a fully masked response sequence of length L, processed through K iterative denoising steps (e.g., 256 for GSM8K). At each Transformer layer, it caches and selectively updates four intermediate feature tensors—Key, Value, Attention Output, and FFN Output—rather than just KV pairs as in autoregressive models. The output is the final denoised text response, with the method being entirely training-free and model-agnostic, requiring only three hyperparameters (K_p, K_r, ρ) tuned per task.

## Method

dLLM-Cache is a training-free adaptive caching framework that differentiates prompt and response handling. Prompt features are computed only at long intervals (every K_p steps, e.g., 50–100) and reused in between, exploiting their temporal stability. Response features are fully refreshed at shorter intervals (every K_r steps, e.g., 4–8), and between refreshes, only the most dynamic tokens are selectively recomputed. The key mechanism is V-verify, which computes the cosine similarity between each response token's current Value vector and its cached counterpart, then selects the bottom ρ fraction (typically 25%) of tokens with the lowest similarity for full feature recomputation. This is justified by empirical evidence that V-vector similarity strongly correlates with downstream Attention Output and FFN Output similarity, making it an efficient proxy for identifying tokens whose complex features have changed. The method also overwrites the full cached V-cache with newly computed Value vectors at each adaptive step (since they are already available from the lightweight projection), while K, AttnOut, and FFNOut are updated only for the selected tokens.

## Results

dLLM-Cache achieves up to 9.1× FLOPs reduction on LongBench-HotpotQA (LLaDA 8B Base) while improving F1 from 34.56 to 36.10. On the main benchmarks, it delivers 2.10×–5.33× TPS speedups and 3.23×–8.08× FLOPs reductions across LLaDA 8B and Dream 7B, with task accuracy changes typically within ±1 point (e.g., GSM8K LLaDA Instruct: 77.48→78.54, GPQA Dream Base: 33.92→34.15). Peak GPU memory increases by less than 1 GB (~5%) over the uncached baseline. Combined with SlowFast Sampling, throughput reaches 49.86 TPS on GSM8K, matching Llama 3 8B (47.73 TPS) while maintaining 67.17% accuracy versus Llama 3's 49.05%.

## Baselines & Comparisons

Against dKV-Cache (Ma et al., 2026), dLLM-Cache wins on all three compared tasks in both speed and accuracy: on GPQA (Dream Base) it achieves 5.33× vs 1.74× TPS speedup with 34.15% vs 32.83% accuracy; on HumanEval (LLaDA Instruct) it reaches 4.24× vs 1.36× with 39.02% vs 37.20%. Against Fast-dLLM (Wu et al., 2026), dLLM-Cache also dominates: 5.33× vs 3.83× on GPQA (34.15% vs 31.31%), 4.24× vs 2.03× on HumanEval (39.02% vs 36.59%), and a marginal 2.10× vs 2.03× on MMLU with higher accuracy (62.82% vs 61.43%). The advantage stems from dLLM-Cache caching intermediate features beyond KV states (AttnOut, FFNOut) and using the V-verify mechanism for fine-grained token selection, whereas the baselines rely on coarser KV-only caching. As an efficiency reference, Llama 3 8B (Grattafiori et al., 2024) achieves 47.73 TPS on GSM8K; dLLM-Cache alone reaches 20.64 TPS, but combined with SlowFast Sampling it hits 49.86 TPS at 67.17% accuracy, surpassing Llama 3's 49.05% by 18.12 points.

## Relation to Prior Work

This paper adapts the well-established KV caching paradigm from autoregressive models to diffusion LLMs, where bidirectional attention makes traditional KV caching inapplicable. It departs from concurrent caching efforts (dKV-Cache, Fast-dLLM) by caching a broader set of intermediate features (K, V, AttnOut, FFNOut) and by exploiting the asymmetric dynamics between static prompt tokens and sparsely-evolving response tokens. The V-verify mechanism, which uses Value-vector cosine similarity as a lightweight proxy for downstream feature change, is a novel selection criterion not present in prior dLLM acceleration work. The method is also shown to be orthogonal to sampling-based accelerators like SlowFast Sampling, positioning it as a complementary layer in the dLLM inference optimization stack.

## Why It Matters / Open Questions

dLLMs are emerging as a serious alternative to ARMs with advantages in bidirectional reasoning, but their O(N³) inference complexity has been a major adoption barrier; dLLM-Cache narrows this gap substantially, bringing latency close to ARM levels with under 1 GB additional memory. The method is training-free and model-agnostic, making it immediately applicable to any masked-diffusion LLM. Key open questions include integration with memory-management systems (e.g., PagedAttention) for very long contexts, whether the V-verify proxy generalizes to non-Transformer backbones, and whether the approximate nature of the cache can be made provably lossless. The paper acknowledges that the speedup is an approximation trade-off rather than a fundamental algorithmic change, leaving room for more principled error-controlled caching.

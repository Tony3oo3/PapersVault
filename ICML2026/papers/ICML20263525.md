## Problem

Modern learning systems, including large foundation models, systematically fail to extrapolate to tasks outside the training distribution's support, even in simple structured settings like parameter shifts, increased compositional depth, or novel recombination of known primitives. The paper asks how a model can apply learned structural principles to novel tasks whose defining structure lies outside its training experience, rather than merely interpolating within observed regimes.

## Input / Output

The method takes a sparse few-shot context set (k input-output pairs) sampled from an unseen target task, a query input, and a training library of known tasks. For the LLM variant, the input is a structured prompt explicitly encoding anchor task demonstrations, a transformation description (e.g., a bit-index shift or primitive function examples), and the target query. The output is a prediction for the target task: a scalar function value in synthetic settings or a generated text sequence in LLM settings. A key constraint is that the target task descriptor is never observed directly; both the anchor and transformation must be inferred from the sparse context alone.

## Method

RTE reframes out-of-support task extrapolation as an out-of-combination problem by decomposing each unseen target into a known anchor task and a relative transformation, then learning a relational operator Ψ that maps (anchor, transformation, query) to target predictions. During training, Ψ is learned from pairs of training tasks by minimizing prediction error under the transductive parameterization. At test time, a proxy geometry built from Task2Vec embeddings (Fisher Information Matrix of a pretrained probe) is used to retrieve the nearest anchor and compute the transformation vector; for discrete regimes, an amortized decomposer network proposes top-k candidate decompositions that are verified against the sparse context. For LLMs, the relational operator is instantiated as a LoRA-fine-tuned model trained on prompts that explicitly encode the anchor-transformation decomposition, with test-time search over candidate decompositions scored by negative log-likelihood on the target context. The approach is theoretically grounded by lifting the matrix completion bound of Netanyahu et al. (2023) to task space, showing that extrapolation error is bounded when the anchor-transformation interaction is low-rank and the task manifold is Lipschitz-continuous.

## Results

On parameter extrapolation (Table 1), inductive models saturate at the training boundary, achieving MSE of 1.2×10⁵ on Quadratic and 2.86 on Cubic, while RTE reduces these to 733 and 1.53 respectively—a 160× improvement on Quadratic. On the LLM benchmarks, RTE achieves 66.07% accuracy on Sparse Parity (|S|=6) versus 52.86% for the standard fine-tuning baseline, and 45.3% exact-match accuracy on CodeIO compositional string transformations, nearly doubling the Few-Shot Baseline (19.8%) and substantially outperforming the stronger CoT + Majority Vote (N=16) baseline (30.2%). Across all three synthetic regimes (parameter, length, composition), RTE consistently bridges the gap between inductive baselines and oracle upper bounds.

## Baselines & Comparisons

On CodeIO, RTE (45.3%) substantially outperforms the Chain-of-Thought + Majority Vote baseline built on Wei et al. (2022) and Wang et al. (2023), which achieves only 30.2% accuracy—a 15.1 percentage-point gap. The Few-Shot Baseline, which directly predicts from in-context examples without relational decomposition, performs worst at 19.8%, frequently hallucinating syntactically plausible but rule-incorrect outputs. On Sparse Parity, RTE (66.07%) improves over the standard fine-tuning baseline (52.86%) by 13.2 points, though both remain well below the 100% oracle that is given the correct parent task and bit index. In the synthetic function prediction experiments, inductive models (including a Task2Vec-conditioned variant and an oracle-parameter variant) fail systematically across all five function families, while RTE approaches transductive oracle performance (e.g., 733 vs. 1,140 MSE on Quadratic; 0.051 vs. 0.055 on Sin-Trend). The residual gap to oracle in all settings is attributed to imperfect anchor retrieval from sparse context rather than failure of the relational operator itself.

## Relation to Prior Work

This paper lifts the transductive extrapolation framework of Netanyahu et al. (2023) from input-space to task-space, arguing that generalization to unseen tasks is fundamentally relational: an out-of-support task can be decomposed into a known anchor plus a transformation both observed in training. It departs from meta-learning (MAML, Reptile) which assumes new tasks lie within the training distribution's local landscape, and from standard OOD/length/compositional generalization where only inputs shift while task structure remains fixed. For the LLM setting, it builds on LoRA fine-tuning and positions its test-time decomposition search as a form of 'Neural RAG' that uses model likelihood as a proxy reward, distinct from Chain-of-Thought verification or retrieval-augmented generation.

## Why It Matters / Open Questions

The paper provides a clean conceptual reframing—reducing intractable out-of-support extrapolation to a more tractable out-of-combination problem—that could influence how the community thinks about task generalization in foundation models. Key open questions include: removing the reliance on ground-truth relational metadata (meta-labels) in discrete regimes, scaling multi-step decomposition without compounding errors, and reducing test-time inference cost for large task libraries. The significant oracle gap (e.g., 45.3% vs. 76.0% on CodeIO) and the requirement that target tasks be 'combinatorially reachable' limit immediate applicability to truly novel mechanisms.

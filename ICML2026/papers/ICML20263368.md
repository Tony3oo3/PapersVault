## Problem

While RL post-training with verifiable rewards has shown practical success in math and coding, it remains unclear whether policy gradient methods can genuinely extend a base model's capabilities beyond its pre-training support, or merely sharpen the existing distribution. Prior theoretical work characterized RL benefits relative to SFT or pre-training but left the role of the base model's coverage and the computational cost of going off-support unaddressed, particularly for practical PG variants like PPO and GRPO.

## Input / Output

The method operates on a linear autoregressive model with a frozen feature map φ: given a context x, it generates a response sequence y = (y₁, …, y_N) where each token y_i ∈ {1, …, k} is predicted via a softmax over k linear scores. The reward is binary: an outcome reward model (ORM) returns 1 only if the full sequence matches the ground truth, while a process reward model (PRM) returns 1 at each step i if the prefix y_{1:i} is correct. The base model q₀ from pre-training serves as a behavior policy for exploration, and the algorithm outputs a post-trained policy p_w that generates the response sequence.

## Method

The paper analyzes REINFORCE-style policy gradient updates (PG-OR for outcome rewards, PG-PR for process rewards) on linear autoregressive models under a token-level γ-margin separability assumption, using adaptive learning rates to remove sequence-length dependence from convergence rates. The key theoretical contribution is identifying the Likelihood Quantile (LQ) of the base model as the governing quantity for unconditional test error: PG with ORM requires Õ(Q_q(ε)⁻¹/γ²) reward queries, which is exponential in N when the base model's LQ is exponentially small, establishing a fundamental base model barrier. This barrier is shown to be minimax optimal and not an artifact of SGD pre-training. The paper then demonstrates that switching to process rewards replaces the sequence-level LQ with a Token-Level Likelihood Quantile, reducing the worst-case reward query complexity from Õ(k^N/γ²) to Õ(Nk/γ²) and enabling PG to go beyond the base model's support. Minimax lower bounds confirm the optimality of both the PG variants and the SGD pre-training rates.

## Results

The paper establishes that PG with outcome rewards (ORM) and adaptive learning rate achieves expected error ε in Õ(min(Q_q((1−o(1))ε)⁻¹, k^N)/(γ²ε)) iterations, where Q_q is the Likelihood Quantile of the base model. The key barrier: when the base model is SGD-trained on n samples, going below the SGD error rate Õ(1/(γ²n)) requires exponentially many (in N) reward queries. Switching to process rewards (PRM) eliminates this exponential dependence, requiring only Õ(Nk/γ² + 1/(γ²ε)) reward queries and Õ(1/(γ²ε)) iterations. Experiments on a synthetic task (N=128, k=32) confirm that PG-ORM cannot improve likelihood on off-support samples (initial likelihood < 10⁻¹²), while PG-PRM successfully boosts them; on Math500, the LQ of Qwen3-8B post-trained model plateaus at the same threshold as Qwen3-8B-Base for small ε, empirically validating the barrier.

## Baselines & Comparisons

The paper does not compare against external RL post-training methods (PPO, GRPO) empirically; instead, it provides theoretical comparisons between reward types and learning rate schedules. Under ORM, PG with adaptive LR is minimax optimal (Thm. 5.3, 5.4), matching lower bounds up to log factors, and achieves the minimax optimal online mistake bound Õ(k^N/γ²) — resolving an open question from Beygelzimer et al. (2019) who only achieved this for N=1 under a stronger margin. The critical comparison is ORM vs. PRM: ORM requires reward queries scaling as k^N in the worst case (exponential in sequence length), while PRM reduces this to Nk (linear in N, linear in vocabulary size). For SGD pre-training, adaptive LR removes the N factor present with constant LR, achieving Õ(log²(TNkγ²)/(γ²T)) error vs. Õ(Nlog²(Tkγ²)/(γ²T)), making it near-minimax optimal for all N. The base model barrier is shown to be fundamental (Thm. 5.5): no pre-training algorithm can achieve LQ better than k^−N with fewer than Õ(1/(γ²ε)) samples, ruling out algorithmic fixes to the ORM barrier.

## Relation to Prior Work

This paper unifies three threads of prior work: (1) the REINFORCE/policy gradient lineage for sequential decision-making, (2) the bandit multiclass linear classification literature (Kakade et al. 2008, Daniely & Helbertal 2013, Beygelzimer et al. 2019) which studied the N=1 case, and (3) the coverage principle and adaptive-LR SGD analysis of Chen et al. (2025a). The key departure is introducing the Likelihood Quantile (LQ) as a formal property of the base model that governs post-training complexity, and showing that the N=1 bandit results extend to sequences with an exponential barrier in N under outcome rewards. The paper also answers an open question from Beygelzimer et al. (2019) by providing a computationally efficient online algorithm achieving the minimax optimal mistake bound.

## Why It Matters / Open Questions

The base model barrier result is a fundamental explanation for the widely observed phenomenon that RLVR sharpens rather than extends base model capabilities: it is not an algorithmic limitation of PPO or GRPO but a minimax-optimal property of any post-training algorithm with outcome rewards. The process reward model solution, which reduces the reward query complexity from exponential in N to linear in N, provides a concrete path forward. Open questions include whether the barrier persists in non-linear (Transformer) settings, how to learn accurate process rewards efficiently, and whether the results extend to noisy or non-separable responses.

## Problem

Learning cooperative multi-agent policies that generalize to a priori unknown temporal tasks assigned at runtime remains infeasible with existing approaches, which are sample-inefficient and confined to a single fixed task requiring retraining. Three compounding challenges make this hard: policies must track history to infer task progress (non-Markovian), the team-level reward is sparse (credit assignment), and simultaneously learning DFA representations and policies creates a representation bottleneck that worsens with team size.

## Input / Output

At each step, each agent receives its local observation (one-hot global state from its own perspective), its agent ID, and the RAD Embeddings (frozen GATv2 vectors) of all n agents' current progressed DFAs, which are updated via DFA progression and minimization after each transition. The policy outputs a categorical distribution over 5 discrete actions (four cardinal directions plus noop). At test time, the learned value functions additionally produce optimal task-to-agent assignments by enumerating permutations and selecting the one maximizing the sum of individual value estimates.

## Method

ACC-MARL makes the non-Markovian task-conditioned game Markovian by augmenting the state with the latest minimized sub-DFAs (via DFA progression under the labeling function), eliminating the need for history. It addresses sparse credit assignment through potential-based reward shaping where each agent's potential is the indicator of its own DFA being satisfied, provably preserving optimality. To overcome the representation bottleneck, it conditions policies on pretrained RAD Embeddings (a frozen GATv2 encoder over DFA graphs) rather than learning latent representations jointly, decoupling representation from control. The paper proves (Theorem 3.1) that maximizing the shaped discounted return in the Markovian reformulation recovers the optimal policy for the original non-Markovian problem as γ→1⁻. Training uses Independent PPO in JAX with a parallelized DFA toolchain (DFAsx), and the learned value functions enable optimal task assignment at test time.

## Results

The full ACC-MARL solution (Markovian policies with pretrained RAD Embeddings and PBRS) achieves success probabilities up to 0.830 on Rooms-4 RAD tasks with optimal task assignment, and 0.856 on Rooms-4 Reach tasks. In four-agent environments, pretrained RAD Embeddings are critical: on Rooms-4 ReachAvoid tasks, the full solution reaches 0.764 (random) / 0.830 (optimal) versus only 0.341 / 0.427 without RAD Embeddings. Optimal task assignment via learned value functions improves performance in asymmetric Rooms environments (e.g., +0.035 on Rooms-2 RAD) but has negligible effect in symmetric Buttons environments. Policies trained on RAD DFAs (≤5 states) generalize to OOD DFAs (≤10 states), retaining 50–70% of in-distribution performance.

## Baselines & Comparisons

The paper explicitly notes that no directly comparable external baselines exist for multi-task cooperative MARL with formal specifications, so comparisons are ablation-based. The full solution (RAD Embeddings + PBRS + Markovian reformulation) is compared against three ablated variants: (1) without pretrained RAD Embeddings (learning DFA representations jointly), (2) without PBRS (sparse team-level reward only), and (3) with history-dependent LSTM policies instead of the Markovian reformulation. Without PBRS, no policy variant escapes sub-optimal solutions in any environment. History-dependent (LSTM) policies fail to exceed 0.5 success probability in both two-agent environments. The most striking gap appears in four-agent settings: on Rooms-4 ReachAvoid, RAD Embeddings + PBRS achieves 0.764 (random) / 0.830 (optimal) versus 0.341 / 0.427 without RAD Embeddings—a gap of over 40 percentage points. In two-agent environments the comparison is more nuanced: without RAD Embeddings, policies slightly outperform on Reach and RAD tasks in Buttons-2 but underperform on ReachAvoid, suggesting pretrained embeddings better capture the irrecoverable 'avoid' semantics.

## Relation to Prior Work

This paper extends the single-agent automata-conditioned RL line of work (Yalcinkaya et al., 2024, 2025) to the cooperative multi-agent setting, adapting RAD Embeddings and DFA progression to decentralized policies. It also builds on prior MARL-with-formal-specifications work (Hammond et al., 2021; Neary et al., 2021; Smith et al., 2023; Shah et al., 2025a), which was confined to a single fixed task, by introducing runtime task assignment from a distribution of DFAs. The credit assignment solution draws on potential-based reward shaping (Ng et al., 1999; Devlin & Kudenko, 2011), and the training algorithm is standard IPPO, making the core novelty the combination of Markovian DFA-state augmentation, PBRS, and pretrained graph embeddings in a multi-agent context.

## Why It Matters / Open Questions

This is the first framework to handle a priori unknown DFA tasks assigned at runtime in cooperative MARL, with a proof that the learned policies are optimal for the stated objective. The demonstration that learned value functions enable optimal task assignment at test time is a practical byproduct that could benefit any MARL system with asymmetric agent conditions. Key limitations include the full-observability assumption, fixed labeling functions, discrete-only evaluation, and intractable task-assignment enumeration for large teams; extending to partial observability, continuous domains, and heterogeneous agents are natural next steps that the authors identify as open.

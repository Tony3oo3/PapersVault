## Problem

Prior work on visual chain-of-thought agents has focused on simple visual search tasks where zoom-in tools are straightforwardly necessary, leaving unclear how tool use behaves under RL fine-tuning for more complex reasoning tasks where tool utility is ambiguous. This paper identifies a 'tool-use collapse' phenomenon in 3D spatial reasoning and medical VQA: vanilla RFT drives tool usage to near zero while accuracy still improves, and explicitly incentivizing tool use yields only marginal gains despite saturating usage to 100%. The central question is what actually drives performance gains—tool frequency or the diversity of exploration that tools enable during training.

## Input / Output

The agent receives an RGB image and a text query (e.g., a 3D spatial reasoning question about relative height, depth ordering, or orientation) and produces a multiple-choice answer via a structured thought-action-observation loop. During the loop, the model may optionally emit a <grounding> trigger with normalized 2D bounding-box coordinates and a source indicator (original image or prior observation) to obtain a cropped image patch, which is appended to the interaction history before the terminal <answer> span. Evaluation uses a fixed VLM-as-judge (Qwen2.5-VL-7B) to normalize free-form outputs to option labels, reported as Avg@8 over 8 independent generations per question.

## Method

Starting from the Mini-o3 checkpoint (Qwen2.5-VL-7B trained with SFT+RFT for iterative zoom-in grounding), the paper first demonstrates that vanilla GRPO/DAPO fine-tuning on 1.2k 3D spatial reasoning samples causes tool-use collapse (ratio drops from ~20% to ~2%) while accuracy rises to 59.2%, and that banning tools entirely from the start degrades accuracy to 58.1%, confirming early tool experience acts as training-time scaffolding. Reward-based tool encouragement (DeepEyes-style bonus or PixelReasoner-style curiosity reward) drives tool usage to 100% but yields only 59.9% accuracy, with diagnostics showing both vanilla and tool-encouraged runs suffer monotonic degradation in textual n-gram diversity and visual crop-location diversity (mean pairwise IoU > 0.55). The proposed fix adds an adaptive entropy regularization term to the GRPO objective, where the coefficient is set by proportional feedback (λ_t = K_p[H_target − H_t]_+) to maintain rollout entropy above a target of 0.9, achieving 62.9% accuracy while tool usage still naturally declines to ~3%. An ablation confirming the scaffolding interpretation shows that entropy regularization without tool access fails to improve performance (57.8%), and applying entropy only in the first 60 steps recovers most of the full-run gain (62.5%), supporting the view that early diverse tool-mediated exploration shapes representations that persist after tool dependence fades.

## Results

On 3DSRBench, the entropy-regularized agent achieves 62.9% Avg@8 accuracy, outperforming vanilla RFT (59.2%), tool-encouraging reward (59.9%), and the tool-banned baseline (58.1%). On CV-Bench-3D, entropy regularization is the only variant that surpasses the pre-trained Mini-o3 base (78.8% vs. 77.6%), while vanilla RFT (76.7%) and tool-encouraging reward (74.5%) both degrade general spatial understanding. On VQA-RAD, the same ordering holds: entropy regularization reaches 48.78% vs. 46.34% (vanilla) and 47.23% (tool-encouraged). Notably, the best-performing entropy-regularized run still exhibits tool-use collapse (tool use ratio drops from ~20% to ~3%), confirming that exploration diversity, not tool frequency, drives the gains.

## Baselines & Comparisons

Against the generalist Qwen2.5-VL-7B baseline, the entropy-regularized agent wins decisively on 3DSRBench (62.9% vs. 48.4%) but falls short on CV-Bench-3D (78.8% vs. 82.9%), indicating that spatial-specialized training trades some general depth perception. Compared to the zero-shot visual agents DeepEyes (51.6%) and Mini-o3 (54.5%), the entropy-regularized method improves 3DSRBench accuracy by 11.3 and 8.4 points respectively, and also surpasses both on CV-Bench-3D (78.8% vs. 76.7% and 77.6%). Against the specialist SpatialReasoner reference (60.3% on 3DSRBench), the proposed method gains 2.6 points without using explicit 3D coordinate supervision, though it still trails on CV-Bench-3D (78.8% vs. 80.3%). Critically, the paper's own ablations show that vanilla RFT (59.2%) and tool-encouraging reward (59.9%) both underperform entropy regularization (62.9%) on 3DSRBench, and both degrade CV-Bench-3D relative to the Mini-o3 base, confirming that the exploration-diversity mechanism—not tool frequency or forced invocation—is the source of the improvement.

## Relation to Prior Work

This paper builds directly on the Mini-o3 visual agent (Lai et al., 2026) and its GRPO/DAPO-based RL training pipeline, extending the analysis from visual search tasks (where zoom-in is nearly mandatory) to 3D spatial reasoning and medical VQA where tool utility is ambiguous. It departs from the dominant framing in DeepEyes, PixelReasoner, and OpenThinkIMG—which treat tool invocation as the reasoning mechanism itself—by reframing tools as training-time scaffolding whose primary value is broadening exploration history rather than serving as an inference-time dependency. The adaptive entropy regularization technique is borrowed from LLM RL work (Zhang et al., 2025b) and repurposed here as an exploration control knob for agentic visual policies.

## Why It Matters / Open Questions

The scaffolding interpretation offers a practical and conceptually simple recipe: add adaptive entropy regularization during RL fine-tuning of visual agents, and let tool use fade naturally rather than forcing it via reward engineering. This challenges the prevailing assumption in the visual CoT agent literature that higher tool frequency correlates with better reasoning, and provides a diagnostic (rollout diversity in text and vision) for identifying premature convergence. Limitations include a single 7B model family, one primary tool (zoom-in grounding) in the main experiments, and relatively small training sets (1.2k–6k samples); whether the dynamics hold at larger scale or with more complex multi-tool interfaces remains open. The early-phase ablation (entropy for first 60 steps only recovers most gains) suggests the scaffolding effect may be front-loaded, raising questions about optimal exploration schedules.

## Problem

Despite widespread adoption of efficient attention mechanisms (linear, hybrid, sparse) to reduce the quadratic cost of full attention, no rigorous theoretical characterization existed for their expressive power relative to standard full attention. This paper establishes the first provable separation: even an exponentially large number of linear attention layers interleaved with a small number of full attention layers cannot match the compositional reasoning capability of a single additional full attention layer on deep sequential tasks.

## Input / Output

For the L-sequential function composition task, the input is a prompt containing L function tables (each of size N_{ℓ-1} tokens) followed by a single query token, and the output is the scalar result of sequentially composing all L functions on the initial value. For the 2-Sum task, the input is a sequence of n+1 values from [M] with M=O(n), and the output is a binary indicator sequence where position i is 1 iff some earlier token sums to 0 mod M with token i. Both tasks are designed so that the computation must complete within a single forward pass, with no external chain-of-thought tokens.

## Method

The paper introduces a hybrid communication model that maps the forward pass of an (L, a₁, …, a_L)-hybrid Transformer to a multi-player protocol with L epochs, where each epoch comprises one round of parallel 'soft transcript' exchange (simulating full attention) followed by a_ℓ sequential 'linear transcript' rounds (simulating linear attention as an RNN). The key proof technique is an inductive construction of indistinguishable decompositions—pairs of input sets (R_{≥ℓ}, Z_{<ℓ}) such that all assignments in R_{≥ℓ} produce identical communication transcripts to players [-1:ℓ-1], yet require different outputs. By showing |R_{≥L}| and |I_{L-1}(Z_{<L})| are simultaneously large, the protocol must fail on some input. For sparse attention, a separate block-based communication model shows that the Hdp-bit compressed message per block must encode the full set of B token values, yielding the Ω(B log n) lower bound.

## Results

The paper establishes a provable expressiveness separation: an (L+1)-layer full attention network solves L-sequential function composition in O(poly log n) time, while any hybrid architecture with only L−1 full attention layers interleaved with exponentially many (2^{3L²}) linear attention layers still requires Ω(poly n) time (Theorem 2.6). For the 2-Sum task, a single-layer full attention with H=1, d=3, p=log n solves it in O(log n), whereas any single-layer (B,k)-block-sparse attention requires Hdp = Ω(B log n) (Theorem 2.8), yielding a strict B× efficiency gap. The results hold for all linear attention variants admitting a recurrent formulation, including Mamba, DeltaNet, RWKV, and Minimax-M1.

## Baselines & Comparisons

Against Chen et al. (FOCS 2025), which proved the first unconditional lower bound for multi-layer full attention on sequential function composition, this paper extends the indistinguishable decomposition technique to hybrid architectures. The key separation is that adding one more full attention layer (going from L to L+1) drops complexity from Ω(poly n) to O(poly log n), but replacing that single layer with 2^{3L²} linear attention layers provides no asymptotic gain—the hybrid still requires Ω(poly n). Against Sanford et al. (NeurIPS 2023), which showed full attention solves 2-Sum in O(log n), this paper proves that block-sparse attention with block size B incurs an unavoidable Ω(B log n) lower bound, establishing the first provable separation between sparse and full attention. The paper's contribution is thus a strict expressiveness hierarchy: full attention > hybrid (full + linear) > sparse attention, with the gaps quantified in terms of layer count and block size respectively.

## Relation to Prior Work

This paper directly extends the indistinguishable decomposition framework of Chen et al. (2025), who proved the first unconditional lower bound for multi-layer Transformers on sequential function composition, by adapting their communication-complexity argument to hybrid architectures that interleave full and linear attention layers. It also generalizes the Transformer-vs-RNN separation line (Jelassi et al. 2024; Sanford et al. 2023; Bhattamishra et al. 2024) to the practically important hybrid setting (Mamba, DeltaNet, RWKV, Minimax-M1, Qwen3-Next, Kimi Linear, Hunyuan-TurboS), and adds a sparse-attention lower bound on 2-Sum building on Sanford et al. (2023). The key methodological departure is modeling linear attention layers as recurrent transcripts within the communication protocol, enabling a unified analysis of full, linear, log-linear, and sparse attention under one framework.

## Why It Matters / Open Questions

This is the first provable separation between hybrid linear-full attention and standard full attention, providing a theoretical explanation for the empirical observation that simply interleaving linear and full attention layers yields diminishing returns on deep reasoning tasks. The exponential gap (2^{3L²} linear layers vs. one full attention layer) suggests that current hybrid architectures face a fundamental expressiveness ceiling for sequential composition, motivating either smarter approximations of full attention or explicit architectural workarounds. Key limitations include the artificiality of the tasks (carefully constrained retrieval scopes) and the purely theoretical nature of the results, leaving open whether the separation manifests in practical benchmarks. Future work could explore whether task-sufficient sparsity patterns, deeper hybrid designs, or CoT augmentation can close the identified gap.

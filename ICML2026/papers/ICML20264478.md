## Problem

Large Audio Language Models rely on general-purpose encoders (Whisper, HuBERT, CLAP) that discard fine-grained acoustic details like exact pitch, tempo, and chord progressions, causing hallucination on tasks requiring precise measurement. While external tools can recover these features, naive integration—either invoking all tools or using untrained prompt-based selection—introduces information overload and negative transfer, performing worse than the no-tool baseline. The core gap is the absence of a learned, context-aware policy that determines when and which tools to invoke, compounded by the lack of supervised labels for optimal tool chains.

## Input / Output

The system takes an audio clip and a multiple-choice textual question as input. The trainable agent (Qwen2-Audio-7B-Instruct) outputs a comma-separated list of tool indices (0–5) enclosed in XML tags, which triggers execution of the corresponding tools from a six-tool library (ASR, emotion recognition, chord recognition, tempo estimation, pitch tracking, sound classification). The frozen reasoner then consumes the raw audio, the question, and the structured JSON tool outputs (e.g., timestamped chord sequences, BPM values, F0 contours) to produce a final MCQ answer. Training requires only ~2,025 audio-text pairs from AVQA, and the learned policy transfers as a plug-and-play module to closed-source backbones like GPT-4o Audio without retraining.

## Method

AuTAgent decouples a trainable tool-selection agent from a frozen reasoning backbone and trains the agent via Group Relative Policy Optimization (GRPO) with a novel Baseline-Subtracted Differential Reward. For each query, the reasoner first produces a baseline prediction without tools; the agent then samples G=6 tool-selection candidates, and each candidate's reward is r = I(tool-augmented answer correct) − I(baseline answer correct), yielding a ternary signal in {−1, 0, 1}. A reward of +1 is granted only when tools correct a baseline error, 0 when the baseline is already correct (suppressing redundant calls), and −1 when tools introduce noise that degrades a correct baseline. Group-relative advantage normalization across the G candidates, combined with PPO-style clipping and a KL penalty against a reference policy, stabilizes training and encourages the agent to discover context-dependent tool combinations. The decoupled architecture means the learned policy captures universal audio-reasoning logic rather than backbone-specific representations, enabling near-lossless transfer (≤0.8% gap) between open- and closed-source reasoners.

## Results

On MMAU Test-mini, AuTAgent achieves 54.20% average accuracy with Qwen2-Audio-7B-Instruct (+4.20% over the no-tool baseline of 50.00%) and 67.20% with GPT-4o Audio (+9.80% over 57.40%). On MMAR, the corresponding improvements are +6.20% (41.30% vs. 35.10%) for the open-source backbone and +8.00% (63.00% vs. 55.00%) for the closed-source backbone. The method also reduces average tool invocations from 1.62 (binary reward) to 1.30, demonstrating that the differential reward mechanism suppresses redundant calls while improving accuracy.

## Baselines & Comparisons

AuTAgent outperforms all four baselines on both benchmarks and both backbones. Against the no-tool vanilla baseline, it gains +4.20%/+6.20% (open-source) and +9.80%/+8.00% (closed-source) on MMAU/MMAR. The All-Tools concatenation baseline actually degrades performance below vanilla (40.90% vs. 50.00% on MMAU with Qwen2-Audio), confirming that indiscriminate tool invocation introduces harmful noise. Random Selection (untrained agent calling tools at random) also underperforms vanilla on MMAU (49.10% vs. 50.00%), showing that without learned policy, tool calls are net-negative. The strongest baseline, Tools w/ Desc. (description-based zero-shot selection), achieves 51.20%/62.90% on MMAU, but AuTAgent still leads by 3.00%/4.30% points, demonstrating that RL-learned dynamic selection substantially outperforms static prompt-based heuristics.

## Relation to Prior Work

This paper extends GRPO (Shao et al., 2024) from mathematical reasoning to the external action space of tool selection for audio, departing from prior audio tool agents (AudioGPT, HuggingGPT) that rely on training-free ReAct-style prompting. It also contrasts with RL-for-reasoning work in LALMs (R1-AQA, Audio-Thinker) that optimize internal reasoning chains, whereas AuTAgent optimizes which external tools to invoke while keeping the reasoner frozen. The differential reward mechanism is a novel contribution that addresses the specific problem of uncertain tool gain, building on the broader RL-for-tool-use line (Toolformer, VisTA) but introducing a baseline-subtracted signal to suppress redundant invocations.

## Why It Matters / Open Questions

The near-lossless transferability of the learned tool-selection policy across backbones (Qwen2-Audio-7B → GPT-4o Audio, within 0.2–0.8%) suggests a practical pathway for enhancing closed-source models with cheaply trained open-source agents, which is practically significant for deployment. However, the evaluation is limited to six tools, two MCQ benchmarks, and a single training source (AVQA subset), leaving open whether the approach scales to larger tool libraries, multi-step tool chains, or open-ended generation. The differential reward idea is generalizable beyond audio, but its interaction with more complex reward structures (e.g., partial credit, multi-turn tool use) remains unexplored.

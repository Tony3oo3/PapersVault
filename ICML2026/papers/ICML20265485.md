## Problem

Current LLMs store episodic memory (raw events) in KV cache and semantic memory (factual knowledge) in FFN parameters as separate, non-interconvertible representations. Context-based memory approaches incur quadratic attention cost and limited compression, while test-time training methods suffer from high writing latency. No existing method allows the same parameter set to simultaneously encode fine-grained episodic details and abstracted semantic knowledge, switchable at inference time without retraining.

## Input / Output

During memory injection, text is segmented into chunks of 16–512 tokens whose per-layer hidden states are fed into a fixed-size recurrent memory pool (K=3r slots, 258 tokens total for LLaMA-3.1-8B) via a LoRA-based management function with bidirectional attention. At generation time, no injected text appears in the input sequence; instead, a short prefix prompt (e.g., 'Repeat: ' + 5 random tokens for episodic recall, or task instructions for semantic QA) triggers retrieval entirely from the modulated FFN parameters, eliminating O(N²) attention over long contexts. The output is standard autoregressive text generation, with the side product being the rank-r parameter deltas (ΔW_up, ΔW_down, ΔW_gate) that encode the stored memory.

## Method

HyperMem introduces a layer-wise hypernetwork that projects a fixed-size recurrent memory pool into additive modulations of the frozen FFN up/down/gate matrices, effectively creating a 'hyper-LoRA' where the left factor is dynamically generated from contextual memory rather than directly trained. Memory injection uses a LoRA_enc module applied to attention and FFN projections, updating each layer's memory pool via bidirectional attention over the concatenated current chunk and previous memory state, with gradients flowing across up to 13 injection steps. Training proceeds in two stages: post-training on FineWeb-Edu with two complementary objectives (random-access associative memory requiring verbatim continuation from 5 random hint tokens, and standard continuation for semantic abstraction), followed by supervised fine-tuning on 8k–16k token reading comprehension data. The key architectural insight is that the bottleneck dimension r of the hypernetwork directly interacts with the temporal dimension of the Transformer input, encouraging the management function to preserve language modeling capability while incorporating parameter-space gradients, and that modulating only FFN layers (not attention) yields the best convergence and retrieval performance.

## Results

On raw text retrieval (episodic memory), HyperMem achieves F1 of 0.876 (from-head) and 0.654 (random-access) using only 258 equivalent storage tokens, surpassing MemoryLLM-8B-12800 (12,800 tokens) on random access (0.654 vs. 0.645) and Generative Adapter (256 tokens) by a wide margin (0.654 vs. 0.297). On LongBench reading comprehension (semantic memory), HyperMem scores 0.420 on HotpotQA, 0.386 on 2WikiMQA, and 0.238 on MuSiQue, matching or exceeding the full-context Llama3.1-8B-8192 on HotpotQA (0.420 vs. 0.431) and 2WikiMQA (0.386 vs. 0.349). On the MemGPT-MSC personalization benchmark, HyperMem achieves F1 of 43.0, outperforming Generative Adapter (40.2) and approaching Activation Beacon-1024 (44.4) with a smaller memory footprint.

## Baselines & Comparisons

Against MemoryLLM-8B-12800 (the strongest context-based baseline with 12,800 memory tokens), HyperMem (258 tokens) wins on random-access retrieval (0.654 vs. 0.645) and on three of six LongBench subtasks (HotpotQA 0.420 vs. 0.379, 2WikiMQA 0.386 vs. 0.322, MuSiQue 0.238 vs. 0.204), but trails on NarrativeQA (0.154 vs. 0.235), Qasper (0.227 vs. 0.316), and MultiFieldQA (0.213 vs. 0.422). Against Generative Adapter (256 tokens, 500M params), HyperMem (300M params) dominates on every metric: retrieval F1 from-head 0.876 vs. 0.390, random-access 0.654 vs. 0.297, and leads on 4 of 6 LongBench subtasks plus personalization (43.0 vs. 40.2 F1). Against the full-context Llama3.1-8B-8192, HyperMem is competitive on HotpotQA (0.420 vs. 0.431) and 2WikiMQA (0.386 vs. 0.349) but falls short on NarrativeQA and MultiFieldQA, reflecting the inherent difficulty of context-free semantic reasoning. Against Activation Beacon (512/1024 tokens), HyperMem achieves 43.0 F1 on personalization, beating the 512-token variant (40.8) but slightly below the 1024-token variant (44.4), while using fewer equivalent storage tokens.

## Relation to Prior Work

HyperMem builds directly on the recurrent memory pool architecture and two-stage training protocol of MemoryLLM and its extension M+, but departs fundamentally in how memory is accessed: rather than attending to memory tokens in the KV cache (context-based) or performing test-time gradient updates (parameter-based via online learning), it introduces a hypernetwork that projects a fixed-size memory pool into low-rank FFN parameter modulations. This positions the method as a 'hyper-LoRA' where one factor is dynamically generated from context, bridging the gap between data (episodic) and parameters (semantic) without either explicit attention to stored tokens or costly test-time optimization. The ablation showing FFN modulation outperforms attention modulation aligns with the interpretability finding that MLP layers encode key-value semantic memory (Geva et al., 2021).

## Why It Matters / Open Questions

The demonstration that a single set of FFN parameters can serve as both episodic and semantic memory—switchable purely through prompting—offers a compelling architectural primitive for lifelong-learning LLMs that avoid quadratic attention costs at inference. The retention curve showing stable recall beyond 20 injection steps with only 258 memory tokens (vs. 1024 for MemoryLLM) suggests parameter-based modulation has intrinsic compression advantages for long-range retention. Open questions include whether this scales to larger models and architectures, how memory capacity scales with the bottleneck dimension r, and whether the associative-memory failure mode (recovering from partial errors) can be controlled or is an inherent trade-off of generative parameter recall.

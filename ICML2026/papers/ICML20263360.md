## Problem

Transformer Neural Processes (TNPs) achieve strong predictive performance but require re-encoding the entire context history at every update, incurring quadratic O(N²) cost per new observation. This makes them prohibitively expensive for inherently sequential applications such as real-time sensor streams, database updates, or weather forecasting, where the context grows continuously and updates must be cheap. The paper asks whether causal masking and KV caching—mechanisms that enable efficient incremental inference in LLMs—can be adapted to the NP framework without sacrificing predictive accuracy or probabilistic consistency.

## Input / Output

The model consumes a context set of (x, y) input-output pairs and a set of target input coordinates, each tokenised with a binary source flag (0 for context, 1 for target) and embedded via a two-layer MLP into 128-dimensional representations. For the temperature task, raw 4D inputs (time, latitude, longitude, elevation) are Fourier-encoded to 128D; for tabular tasks, inputs are 20D (zero-padded if shorter). The output is a factorised Gaussian predictive distribution (mean and variance via softplus) at each target location, or in AR mode, a sequential chain of such distributions where each sampled target is appended to the context before the next prediction.

## Method

incTNP introduces a lower-triangular causal mask into the TNP's self-attention layers (M-MHSA), so that each context token attends only to preceding tokens, and pairs this with KV caching to store past key-value matrices—reducing the marginal cost of each incremental context update from O(N_c²) to O(N_c). The key training innovation (incTNP-Seq) treats the data as a single sequence with parallel context and target streams, applying causal masking not only to self-attention but also to the cross-attention (M-MHCA), so that the n-th target prediction depends solely on the first n context points; this dense autoregressive objective computes the loss for every possible prefix context in a single forward pass, amortising training across all context sizes. The paper further provides a theoretical framework (Proposition 4.2) decomposing the KL divergence of any prediction rule into an exchangeable component plus a 'KL gap' that quantifies deviation from implicit Bayesianness, and empirically shows that incTNP's causal structure yields a KL gap comparable to the permutation-invariant TNP-D under a one-at-a-time streaming protocol.

## Results

On the factorised prediction setting (Table 1a), incTNP-Seq matches or exceeds the TNP-D reference across all eight benchmarks, with the largest gain on Temperature Forecasting (+0.690 log-likelihood over TNP-D's −2.571) and consistent small improvements on tabular tasks (e.g., +0.036 on Protein, +0.007 on synthetic tabular). In autoregressive mode (Table 1b), incTNP-Seq outperforms TNP-D on Temperature Interpolation (+0.016) and Forecasting (+0.061) while being 3.57× faster in inference time. The dense autoregressive training strategy (incTNP-Seq) also yields significantly lower variance across hyperparameter sweeps compared to standard training, and even when TNP-D and incTNP are given a compute-matched budget, they fail to surpass incTNP-Seq's peak performance.

## Baselines & Comparisons

Against TNP-D (the standard non-incremental Transformer NP), incTNP-Seq achieves parity or outperforms on all eight factorised benchmarks, with the most dramatic gain on Temperature Forecasting (+0.690 log-likelihood), while also delivering a 3.57× inference speedup in AR mode on Temperature tasks. Against CNP (the primary baseline supporting incremental updates), incTNP-Seq substantially outperforms on every task, with gaps ranging from +0.134 (Skillcraft) to +0.942 (Elevators) in log-likelihood, reflecting CNP's limited representational capacity. Against LBANP (which offers efficient forward passes via pseudo-tokens but no incremental updates), incTNP-Seq matches or slightly exceeds on most tasks (e.g., +0.007 on synthetic tabular, +0.018 on Temperature Interpolation) and dominates on Temperature Forecasting (+0.690 vs +0.268). Against TNP-A (autoregressive TNP), incTNP-Seq is competitive on static-context AR performance while retaining O(N) context-update cost, whereas TNP-A retains O(N²) updates that become prohibitive at scale (3.5× slower at N_s=100,000 on Temperature). Against WISKI (streaming sparse GP), incTNP-Seq achieves both lower KL Gap (better implicit Bayesianness) and superior predictive performance in the one-at-a-time streaming protocol.

## Relation to Prior Work

This paper adapts two core mechanisms from LLM inference—causal masking and KV caching—to the Transformer Neural Process (TNP) architecture of Nguyen & Grover (2022), converting the standard bidirectional self-attention into a causally masked variant that supports O(N) incremental context updates. The dense autoregressive training strategy (incTNP-Seq) draws on LLM-style next-token prediction to amortise learning across all context sizes in a single forward pass, a paradigm only enabled by the causal structure. The theoretical analysis extends the implicit Bayesianness framework of Mlodozeniec et al. (2024) from general prediction rules to the conditional regression setting, providing a KL-gap decomposition that quantifies the cost of losing permutation invariance. Positioning-wise, incTNP sits between the capacity-limited CNP (which supports incremental updates but lacks expressivity) and the full-attention TNP-D (which is expressive but requires O(N²) re-encoding per update), and is distinct from Hassan et al. (2025), which addresses efficient AR sampling over targets rather than streaming context growth.

## Why It Matters / Open Questions

The practical impact is significant: incTNP makes high-frequency streaming inference feasible for NP-based models in domains like real-time sensor fusion, active database updates, and weather forecasting, where standard TNPs become prohibitively slow as context grows. The finding that causal masking incurs negligible predictive cost (and that dense autoregressive training can even close or reverse the small gap) suggests that the field's default assumption of bidirectional attention for NPs may be unnecessarily restrictive. Open questions include behaviour under non-stationary or distributionally shifting streams, extreme context scales where KV-cache memory becomes a bottleneck (potentially addressable via State-Space Models), and whether the implicit Bayesianness metric can be extended to batched streaming or length-generalisation protocols. The work also opens a path for tabular foundation models like TabPFN to support streamed row/column updates without re-encoding history.

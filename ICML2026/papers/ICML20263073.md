## Problem

Fine-tuning LLMs is compute-intensive and unpredictable: a failed run can consume hundreds of GPU hours yet underperform the base model, and practitioners typically discover failure only after training completes. Prior prediction approaches—scaling-law extrapolation, proxy models, and short-horizon loss extrapolation—either aggregate all signals into a single opaque score or capture only one view of the problem, leaving practitioners unable to diagnose *why* a run will fail or to make targeted data improvements before committing compute.

## Input / Output

TUNEAHEAD consumes a dataset-hyperparameter pair (D_i, H_j) and constructs a 24-dimensional meta-feature vector V_{i,j}: 14 static descriptors computed offline from the dataset (token-length statistics, type-token ratio, MinHash approximate duplicates, embedding outlier ratio via all-MiniLM-L6-v2, reference perplexity under the frozen base model, KL-divergence to pretraining token distributions) and 10 dynamic features extracted from a standardized 100-step LoRA probe run (loss decay slope, loss variance, gradient norm mean/variance, gradient consistency, parameter change norm, landscape flatness proxy). The output is a continuous performance estimate P_{i,j} (in percentage points on the target benchmark) plus per-feature TreeSHAP attributions; a practitioner may optionally threshold P_{i,j} against a task-specific τ to obtain a go/no-go decision, but this thresholding is a deployment policy that does not alter the regression model.

## Method

TUNEAHEAD's core design is a hybrid feature space that couples model-agnostic static dataset descriptors with model-specific dynamic probe signals, mapped through a lightweight LightGBM regressor (learning_rate=0.05, num_leaves=4) trained on a meta-dataset of 1,300+ completed fine-tuning runs. The 24 features are selected via a SHAP-guided pipeline that prunes 50+ candidates using three criteria—global importance (15th-percentile mean-|SHAP| threshold), directional consistency (Spearman correlation sign agreement ≥ 0.2), and iterative redundancy removal with a CV-RMSE safeguard—ensuring interpretability and non-redundancy. The key empirical finding is that static and dynamic features capture complementary failure modes: static-only and dynamic-only ablations each yield ~3.4 RMSE, while their combination drops to 1.47 RMSE, with the full model rescuing predictions in every bucket of the complementarity analysis (e.g., 12.5% → 70.2% Acc@2pp when both subsets fail). TreeSHAP attributions convert each prediction into an actionable diagnosis (e.g., 'loss stability 0.20 indicates optimization instability; duplicate rate 0.769 indicates semantic redundancy'), and the paper demonstrates that following these prescriptions (lowering learning rate, applying SemDeDup, removing embedding outliers) can improve a failed run's MMLU score from 20.2% to 48.7%.

## Results

On a held-out test set of 370 fine-tuning runs (Qwen2.5-7B-Instruct, MMLU), TUNEAHEAD achieves an RMSE of 1.47 percentage points, R² = 0.99, and Pearson r = 0.99, with 95.1% of predictions within ±3 pp of the true score. The method cuts RMSE by 30% relative to the strongest non-TUNEAHEAD baseline (ProxyLM, 2.11 pp) and by 80% relative to Early-Stop Extrapolation (7.43 pp). On TruthfulQA, TUNEAHEAD similarly leads with RMSE 2.17 pp and 88.2% accuracy within ±5 pp, and cross-model experiments on Llama-3-8B (R² = 0.86) and Qwen2-0.5B (R² = 0.91) confirm framework portability.

## Baselines & Comparisons

TUNEAHEAD (Full) Pareto-dominates all four external baselines on every reported metric. Against Early-Stop Extrapolation (Domhan et al., 2015), which linearly extrapolates the 100-step probe loss, TUNEAHEAD reduces RMSE from 7.43 to 1.47 pp (−80%) and lifts Acc@3pp from 32.8% to 95.1%. Against the Domain-Proxy Baseline (Gururangan et al., 2020), which uses reference perplexity as a difficulty proxy, TUNEAHEAD cuts RMSE from 6.58 to 1.47 pp and more than doubles Acc@2pp (22.0% → 82.5%). Against the Early-Dynamics Baseline (Paul et al., 2023), which uses only the slope of the probe loss curve, TUNEAHEAD improves RMSE from 3.33 to 1.47 pp and Acc@1pp from 29.9% to 50.0%. Against ProxyLM (Anugraha et al., 2024), the strongest baseline that regresses on small proxy-model accuracies, TUNEAHEAD still achieves a 30% RMSE reduction (2.11 → 1.47) and a 9.3 pp gain in Acc@3pp (85.8% → 95.1%), confirming that the hybrid static+dynamic feature space captures complementary signals beyond what proxy models alone provide.

## Relation to Prior Work

This paper sits at the intersection of LLM performance prediction (early learning-curve extrapolation, proxy models like ProxyLM and COSMOS) and dataset-level quality assessment (Data Cartography, MAUVE, embedding-based outlier detection). It departs from prior prediction work by rejecting the single-opaque-score paradigm: instead of aggregating all signals into one proxy-model accuracy or one extrapolated loss value, TuneAhead constructs a hybrid meta-feature vector combining 14 static dataset descriptors with 10 dynamic 100-step probe features, and pairs a LightGBM predictor with TreeSHAP attributions to make the prediction diagnostically interpretable. The meta-learning framing (treating each dataset-hyperparameter pair as a meta-instance) and the explicit go/no-go screening policy are the paper's conceptual contributions over prior prediction-only approaches.

## Why It Matters / Open Questions

For practitioners running many fine-tuning experiments, the ability to screen out unpromising runs before committing ~30 GPU-hours each has direct cost implications, and the SHAP-based diagnosis (e.g., 'lower the learning rate' or 'apply semantic de-duplication') provides actionable remedies rather than a bare pass/fail signal. Key limitations temper the impact: the predictor is not universal across model families (dynamic probe features are tied to a specific model's optimization behavior), experiments are confined to LoRA fine-tuning under a modest hyperparameter grid, and the 100-step probe budget is an empirical default rather than a principled choice. Open questions include adaptive probing that stops early when the decision is confident, cross-model transfer with minimal calibration data, and closing the loop from diagnosis to automated dataset refinement.

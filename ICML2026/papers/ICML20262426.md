## Problem

Existing layout-to-image generation methods lack explicit Z-order (occlusion ordering) information, causing overlapping bounding boxes to produce entangled textures and physically inconsistent layering in intersection regions. Without a mechanism to resolve which object occludes which, these methods treat overlaps as ambiguous feature mixtures rather than enforcing correct depth dependencies, ultimately violating the user's compositional intent.
![Teaser figure](../imgs/ICML20262426/cropped_page0_idx0.webp)

## Input / Output

The method consumes a per-instance quintuple (segmentation mask, bounding box, ordered set of occluders, instance caption, and a shared global text prompt) and produces a high-resolution RGB image via a 28-step rectified-flow denoising schedule on the Flux.1-dev backbone. Layout guidance (instance decoupling and volumetric compositing) is activated only during the initial 30% of denoising steps to balance spatial precision with generation quality. The SA-Z training set provides 1M high-resolution images with 5.7M instances carrying open-vocabulary captions, pixel-level masks, pairwise Z-orders, and SAM-3D-derived amodal annotations.

## Method

OcclusionFormer extends a frozen Flux.1-dev DiT with LoRA-adapted instance decoupling: for each instance, MM-Attention is computed strictly between the local visual tokens within its bounding box and that instance's text embedding, preventing cross-instance feature bleeding. Z-order is then enforced via a NeRF-inspired volumetric rendering step where a learnable per-instance density σ_i (dynamically modulated by timestep and text via a time-text embedding) yields opacity and transmittance values that suppress background features in occluded regions through a normalized weighted aggregation. A Queried Alignment Loss further enforces spatial precision by projecting a learnable query vector into a cosine-similarity map, refining it with a lightweight CNN mask predictor, and supervising the foreground probability against ground-truth masks via cross-entropy. Training combines the rectified-flow velocity-matching objective with this alignment loss (λ=0.5), using amodal masks at high noise levels and modal masks at lower noise levels as a curriculum.

## Results

On the OverLayBench-Complex subset, OcclusionFormer achieves mIoU 0.6037, O-mIoU 0.3468, occlusion order F1 (Occ.) 0.7797, and depth order disagreement (Dep.) 0.1602, outperforming all baselines. On the real-world SA-Z Eval benchmark, it reaches mIoU 0.4509, O-mIoU 0.2231, Occ. 0.7568, and Dep. 0.1529. The method also leads in semantic consistency (SRE 0.8531, SRR 0.8890 on Complex) and image quality (FID 46.166 on Complex, 62.786 on SA-Z Eval), establishing a new state-of-the-art across all evaluated dimensions.

## Baselines & Comparisons

OcclusionFormer outperforms all seven baselines on every metric across all four evaluation subsets, with the largest margins in occlusion-specific metrics. On OverLayBench-Complex, it surpasses the closest competitor InstanceAssemble by 8.1% in Occ. (0.7797 vs. 0.6987) and 10.6% in O-mIoU (0.3468 vs. 0.3189), while also improving mIoU by 5.8% (0.6037 vs. 0.5706). The gap widens substantially on the real-world SA-Z Eval, where OcclusionFormer leads InstanceAssemble by 8.9% in Occ. (0.7568 vs. 0.6947) and 10.4% in O-mIoU (0.2231 vs. 0.2021). Training-free methods (LaRender, MIGC) and U-Net-based GLIGEN lag far behind in both spatial precision and occlusion accuracy, with MIGC achieving only 0.4091 Occ. on Complex. Among DiT-based methods, Eligen and CreatiLayout show competitive semantic scores (SRE/SRR) but fall short on occlusion ordering (Occ. 0.5994 and 0.7142 respectively vs. 0.7797), confirming that explicit Z-order modeling via volumetric rendering is the key differentiator.

## Relation to Prior Work

This paper extends the layout-to-image generation line (GLIGEN, Eligen, CreatiLayout) by explicitly modeling Z-order occlusion, a dimension that prior methods treat as implicit feature mixing. It adapts NeRF's volumetric rendering (transmittance and opacity) to the 2D image plane following LaRender's virtual orthogonal camera formulation, but replaces LaRender's training-free heuristic latent manipulation with a learned, data-driven DiT-based approach using LoRA. The instance decoupling strategy (local MM-Attention within bounding boxes) departs from the global attention paradigm used by Eligen and CreatiLayout, and the SA-Z dataset extends SACap-1M with explicit Z-order, amodal annotations via SAM-3D, and mask-level captions via DescribeAnything.

## Why It Matters / Open Questions

The paper addresses a practical gap in layout-to-image generation where overlapping bounding boxes produce entangled textures and incorrect layering, a problem that directly affects creative design workflows and synthetic data generation. The SA-Z dataset (1M images, 5.7M instances, open-vocabulary, amodal) is a significant resource that fills a void between low-resolution COCO-based occlusion datasets and modern high-resolution open-vocabulary benchmarks. A notable limitation is that object identity (texture, details) shifts when only the Z-order is changed, indicating appearance is not fully disentangled from occlusion arrangement; the authors suggest RL-based post-training as a path forward. Open questions include whether the volumetric rendering formulation generalizes to 3D layout-to-image or video generation with temporal occlusion.

## Problem

Existing reinforcement-learning approaches for long-video reasoning reward only final-answer correctness, so a model that arrives at the right answer through fabricated timestamps and event orderings receives the same reward as one that reasons faithfully. The video's temporal structure remains implicit in flat token sequences or entity co-occurrence graphs, leaving no structured object against which the intermediate temporal claims of a reasoning trace can be verified.
![Teaser figure](../imgs/ICML20260395/cropped_page1_idx0.webp)

## Input / Output

The method consumes a long video (potentially hourscale, exceeding 200K visual tokens) together with a text question, and produces a structured reasoning trace organized into four typed think blocks (timestamp, entity, pairwise-order, and multi-step-chain claims) followed by a final answer. Offline, a frozen LVLM extracts a Temporal Reasoning Trace (TRT) index per video, which is a queryable object of ordered event chains with confidence scores and temporal spans, not a flat retrieval corpus. The TRT index can also be deployed independently as structured temporal context appended to any frozen LVLM prompt without parameter updates.

## Method

VideoTrace-R1 rests on a trace-to-trace duality: the video's ordered event sequence (temporal trace) should be mirrored claim-by-claim by the model's ordered intermediate claims (reasoning trace). To make this verifiable, the paper introduces TRT, a structured index built via dual-channel extraction (entity mentions with temporal grounding and ordered event chains) that exposes four deterministic boolean primitives—VERIFY_TIME, VERIFY_ENTITY, VERIFY_ORDER, and VERIFY_CHAIN—over the index. Training proceeds in two stages: supervised fine-tuning installs the typed-block output format, then temporal-enhanced GRPO applies a fully symbolic, block-decomposed reward r = r_correct + λ·r_trace, where r_trace sums per-block components each computed by a single TRT primitive call on the corresponding think block (e.g., +0.1 per grounded timestamp, +0.2 per correctly ordered pair, +0.3 per matching chain). Because every reward signal is a deterministic query against the index rather than the output of a learned scorer, fabricated temporal claims are caught and penalized at the per-claim level, and per-component rewards give per-block gradient flow so the policy learns to repair each error mode independently.

## Results

On out-of-domain reasoning benchmarks, VideoTrace-R1-7B achieves 43.51% on Video-Holmes, 31.10% on CG-Bench-Reasoning, and 76.23% on VRBench, setting new state-of-the-art among 7B-scale models. On in-domain benchmarks, it reaches 76.67% on ActivityNet, 48.32% on ScaleLong, 71.15% on YouCook2, and 35.98% on LVBench. As a TRT-augmented context provider to frozen LVLMs, it improves MLVU accuracy by 3.7% for Qwen2.5-VL-3B (69.9 vs. 66.2) and 4.7% for LongVU-7B (70.1 vs. 65.4), with the 3B+TRT model surpassing the 7B base model.

## Baselines & Comparisons

VideoTrace-R1-7B outperforms the strongest reasoning-RL baseline, Video-R1-7B, on all out-of-domain benchmarks: +4.97 pts on Video-Holmes (43.51 vs. 38.54), +3.29 pts on CG-Bench-Reasoning (31.10 vs. 27.81), and +6.98 pts on VRBench (76.23 vs. 69.25). It also surpasses VideoChat-R1-Thinking-7B, the best in-domain competitor, on YouCook2 (71.15 vs. 66.79) and LVBench (35.98 vs. 35.01), while trailing it on Star (66.87 vs. 73.13), the one benchmark where it does not lead. Among vanilla (non-reasoning) LVLMs, the gap is even larger: VideoTrace-R1 exceeds Qwen2.5-VL-7B-Instruct by +9.49 pts on Video-Holmes and +12.81 pts on VRBench. As a plug-in TRT context provider, it consistently improves every frozen host model on MLVU and VideoMME, with the 3B Qwen2.5-VL+TRT (69.9) surpassing the 7B Qwen2.5-VL without TRT (68.8), demonstrating that explicit temporal structure partially substitutes for model scale.

## Relation to Prior Work

This paper departs from two established lines: retrieval-augmented long-video methods (VideoRAG, VGenT) that select relevant clips but leave temporal ordering implicit, and outcome-supervised reasoning LVLMs (Video-R1, Time-R1, VideoChat-R1) that apply GRPO with rewards on final-answer correctness only. The key conceptual move is repurposing the RAG 'index' not as a context selector but as a deterministic verification oracle: Temporal Reasoning Traces (TRT) expose ordered event chains through four boolean primitives, and the GRPO reward is decomposed into per-claim symbolic queries against this index rather than a learned reward model. This bridges the structured-graph view of video understanding with process-level supervision in RL, but does so entirely symbolically, avoiding the hallucination risk of neural reward scorers.

## Why It Matters / Open Questions

The paper addresses a real and under-addressed failure mode: models that produce correct final answers through fabricated temporal chronology, which outcome-only rewards cannot detect. The finding that the SFT-only checkpoint often trails the unmodified base model on out-of-domain tasks is a useful caution against format learning without grounded verification. Open questions include whether the four-primitive decomposition (time, entity, order, chain) is sufficient for more complex causal or counterfactual temporal reasoning, how TRT extraction quality with a frozen LVLM limits the approach on noisy or fast-cut videos, and whether the framework extends to multi-video or streaming settings where the index must be maintained incrementally.

## Problem

Existing universal approximation results for neural networks assume real-valued parameters and exact arithmetic, so they do not apply to practical implementations that use finite floating-point sets and round-off-prone operations. Moreover, prior floating-point representability results (e.g., Park et al. 2024, Hwang et al. 2025b) only address function values, leaving open whether a floating-point network can simultaneously represent arbitrary function values and arbitrary gradients as computed by reverse-mode automatic differentiation (AD). This paper proves that it can, for almost all target functions and gradients on bounded floating-point domains.

## Input / Output

The network takes a floating-point input vector x ∈ [-M_σ, M_σ]_F^d and a scalar input gradient y (corresponding to φ'_x(f(x))) and produces a floating-point scalar f(x) and a row-vector AD gradient D_{f,x}(y) ∈ F^{1×d}. The target gradient g*(x) must vanish wherever the input gradient is zero (a necessary constraint from the chain-rule structure of AD). In Theorem 3.2, the target gradient g*(x,y) may depend on y but must satisfy the antisymmetry g*(x,-y) = -g*(x,y), a constraint inherited from the sign-flip symmetry of floating-point multiplication. The domain is a bounded box in F^d whose radius M_σ depends on the activation (e.g., 2^{e_max-2} for ReLU-family activations, 2^{e_max-1} for Sigmoid/tanh).

## Method

The construction decomposes the target network into two same-depth sub-networks concatenated via a parallel-sum operation (#): f_1 represents the function values while forcing its AD gradient to zero, and f_2 outputs zero in the forward pass but produces the target gradient in the backward pass. f_1 is built from per-input indicator sub-networks (3 layers each) that activate only at one domain point, followed by gradient-suppression layers that multiply by progressively small weights to drive the backward gradient to zero, and a final linear-combination layer that assembles f*(x). f_2 uses indicator sub-networks in the forward pass (outputting a constant that is then suppressed to zero) and carefully designs the backward pass so that the gradient at the active indicator equals the desired g*(x). The key technical insight is that non-associativity of floating-point multiplication allows the AD gradient to be decoupled from the function value—something impossible under exact arithmetic where ∇(φ∘f) = φ'(f)·∇f must be proportional to φ'. The construction requires three conditions on the activation function (existence of zero-crossing points with controlled derivative ratios, gradient-suppression pairs, and a small nonzero derivative point), all satisfied by ReLU, ELU, GELU, Swish, Sigmoid, and tanh.

## Results

The paper proves two main representability theorems for floating-point networks with AD. Theorem 3.1 shows that 7-layer σ-networks (for σ ∈ {ReLU, ELU, GELU, Swish, Sigmoid, tanh}) can simultaneously represent arbitrary function values f*(x) and arbitrary AD-computed gradients g*(x) on the domain [-M_σ, M_σ]^d, where M_σ = 2^(e_max−2) for unbounded activations (e.g., ≈2^125 for float32) and M_σ = 2^(e_max−1) for bounded ones. Theorem 3.2 strengthens this: with L ≥ 2^(E+1)+2M+9 layers (e.g., ≥ 2^9+46+9 = 569 layers for float32), a single network f can represent arbitrary function values while its AD gradient D^AD(φ_x∘f, x) follows an arbitrary target g*(x, φ'_x(f(x))) that need not be proportional to φ'_x(f(x))—a property impossible under exact arithmetic. The results hold for all standard IEEE-754 formats with E ≥ 6 (float16, float32, float64, bfloat16).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset comparisons. The conceptual comparison is with prior floating-point representability results: Park et al. (2024) and Hwang et al. (2025b) proved that floating-point networks can represent all functions from F^d to F, but only for function values, not gradients. This paper extends those results to simultaneously represent gradients computed by reverse-mode AD. The key theoretical distinction drawn is between exact arithmetic—where the chain rule forces ∇(φ̃∘f̃)(x) = φ̃'(f̃(x)) × ∇f̃(x) to be proportional to the input gradient—and floating-point arithmetic, where non-associativity of ⊗ allows the AD-computed gradient to deviate arbitrarily from proportionality. The paper also contrasts with classical universal approximation results (Pinkus 1999; Li 1996) that assume real parameters and exact operations, showing that the floating-point setting introduces both new constraints (finite domain, round-off) and new capabilities (gradient manipulation via non-associativity).

## Relation to Prior Work

This paper extends the line of work on representability of floating-point neural networks (Park et al., 2024; Hwang et al., 2025b) by adding the gradient dimension: prior results showed that floating-point networks can represent arbitrary function values, but explicitly did not address gradients. The technical machinery—σ-distinguishability, sequential additions, and transferability—is inherited directly from Hwang et al. (2025b), while the gradient-specific constructions (gradient suppression, gradient indicator functions) are new. The paper also departs from the classical universal approximation literature (Pinkus, 1999; Li, 1996) by working entirely under IEEE-754 arithmetic with round-off, where the AD-computed gradient is a property of the computational graph rather than the underlying real-valued function.

## Why It Matters / Open Questions

The central insight—that floating-point non-associativity allows a network to fit arbitrary function values while simultaneously producing arbitrary (even non-proportional) AD gradients—challenges the assumption that a network's gradient is determined by its function. This has direct implications for understanding gradient-based attacks and for the possibility of 'gradient hiding' in deployed models. However, the results are purely existential (explicitly constructed networks, not trained ones), hold only on bounded domains, and require a specific (modest) number of layers; whether such gradient manipulation is achievable through standard training procedures or exploitable in practice remains entirely open. The paper also leaves open whether analogous results hold for other architectures (CNNs, transformers) under floating-point AD.

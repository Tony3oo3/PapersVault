## Problem

Post-training large diffusion models (12B–20B parameters) remains prohibitively expensive in both GPU memory and training speed. Existing parameter-efficient fine-tuning methods like LoRA reduce trainable parameters but still store the full-precision backbone in memory, while QLoRA reduces memory via 4-bit weight storage but incurs additional computational overhead from online dequantization. The paper asks whether it is possible to break this persistent memory-speed trade-off by performing the entire forward and backward pass natively in 4-bit.
![Teaser figure](../imgs/ICML20265313/cropped_page0_idx1.webp)

## Input / Output

For customization, the method consumes a text prompt plus a small set of reference images (5 prompt-image pairs per concept) and produces 1024×1024 RGB images matching the target identity, style, or subject. For RL, it takes text prompts and optimizes LoRA adapters against differentiable reward models (HPSv2.1, PickScore, ImageReward). For distillation, it takes a teacher diffusion model and produces a 4-NFE student that generates images from text prompts in a data-free setting. All experiments run on FLUX.1-dev (12B) or Qwen-Image (20B) with LoRA rank r=64.

## Method

FourTune introduces a triple-branch hybrid-precision pipeline that decomposes each pretrained weight matrix via SVD into a quantization-friendly residual R (stored in NVFP4) and a low-rank outlier component L_stab (kept in full precision as a frozen 'numerical stabilizer'), then adds a trainable LoRA adapter (A, B) for task adaptation. The forward pass computes Y = GEMM_4bit(Q(X), Q(R)) + X·L_stab + X·(AB), executing the dominant backbone multiplication natively in 4-bit while isolating quantization-sensitive outliers in the high-precision stabilizer branch. For the backward pass, a 16×16 block-wise quantization strategy enables direct 4-bit matrix multiplication with transposed weights (Q(G)·Q(R)ᵀ) without dequantization, since scales are bound to local blocks rather than global rows. Two kernel fusions further reduce memory-bandwidth overhead: LoRA fusion merges all three branches (sharing the same input) into a single kernel, and MLP fusion fuses the FC1 GEMM with the subsequent FC2 quantization to avoid materializing large intermediate tensors in global memory. This yields W4A4G4 training with 2.25× memory reduction and 2.27× end-to-end speedup over BF16 LoRA on FLUX.1-dev while matching full-precision generation quality.

## Results

On FLUX.1-dev (12B) customization, FourTune (W4A4G4) matches or slightly exceeds BF16 LoRA across all three sub-tasks: Identity similarity 0.783 vs 0.771, Style similarity 0.812 vs 0.806, and Subject similarity 0.733 vs 0.731, while also improving image quality (e.g., 34.77 vs 33.49 on Identity). In reinforcement learning (SRPO), FourTune achieves an Aesthetic Score of 6.3119, approaching full-parameter fine-tuning (6.3447) and surpassing BF16 LoRA (6.1832) and NF4 QLoRA (6.2189). In distillation (π-Flow, 4-NFE), FourTune achieves FID 15.50 on HPSv2 prompts, matching BF16 LoRA (15.50) and NF4 QLoRA (15.51), while SparseLoRA degrades catastrophically (FID 202.51). End-to-end, FourTune reduces GPU memory by 2.25× (14.51 GB vs 29.35 GB) and accelerates training by 2.27× over BF16 LoRA and 2.79× over NF4 QLoRA on RTX 5090.

## Baselines & Comparisons

Against BF16 LoRA (W16A16G16), FourTune matches or slightly exceeds generation quality on all customization sub-tasks (e.g., Identity similarity 0.783 vs 0.771; Image Quality 34.77 vs 33.49) while delivering a 2.25× memory reduction and 2.27× training speedup. Against NF4 QLoRA (W4A16G16), FourTune achieves comparable or better quality (e.g., Style similarity 0.812 vs 0.806; Subject Image Quality 16.22 vs 15.30) while being 2.79× faster in training, since QLoRA still requires online dequantization to 16-bit for computation. In the distillation setting, FourTune (FID 15.50) matches BF16 LoRA and NF4 QLoRA (FID 15.50/15.51) on HPSv2 prompts, whereas SparseLoRA collapses to FID 202.51, indicating that coarse column sparsity is incompatible with accuracy-sensitive timestep distillation. In reinforcement learning, FourTune (Aes 6.3119) approaches full-parameter fine-tuning (6.3447) and clearly outperforms both BF16 LoRA (6.1832) and NF4 QLoRA (6.2189), demonstrating that the 4-bit pipeline preserves the fine-grained gradient updates required by RL. Overall, FourTune wins or ties on quality across all three post-training paradigms while simultaneously reducing memory and increasing throughput, effectively breaking the memory–speed trade-off that constrains prior PEFT methods.

## Relation to Prior Work

FourTune extends the LoRA fine-tuning paradigm by repurposing the SVD-based weight decomposition from SVDQuant (Li et al., 2025) — previously used only for 4-bit inference — as a frozen numerical stabilizer during training, isolating quantization-sensitive outliers from the 4-bit backbone. It departs from QLoRA (Dettmers et al., 2023), which quantizes only weights (W4A16G16) and incurs dequantization overhead, by pushing all three tensors (weights, activations, gradients) to 4-bit and executing backbone GEMMs natively in 4-bit. The block-wise quantization strategy for efficient transposed backpropagation and the LoRA/MLP kernel fusions are engineering contributions specific to making the W4A4G4 pipeline practical on Blackwell Tensor Cores.

## Why It Matters / Open Questions

FourTune breaks the long-standing memory-speed trade-off in diffusion model post-training: it achieves QLoRA-level memory (2.25× reduction) while simultaneously exceeding BF16 LoRA training speed (2.27×), making 12B–20B model customization, RL alignment, and distillation feasible on a single consumer GPU (RTX 5090). The key open question is whether the approach generalizes beyond image diffusion to video or 3D generative models, where activation memory is even more dominant and the stabilizer's low-rank overhead may become non-negligible. Additionally, the full benefit depends on hardware with native 4-bit Tensor Cores (Blackwell); while an INT4 variant on Ada (RTX 4090) still yields a 2.6× speedup over QLoRA, the gap narrows, leaving the practical ceiling on pre-Blackwell hardware an open question.

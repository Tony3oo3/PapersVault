## Problem

Reliable Docker-based environment construction is a dominant bottleneck for scaling execution-grounded training and evaluation of software engineering agents: heterogeneous dependencies, system-level conflicts, and undocumented build assumptions cause frequent failures even for strong models like Claude-4 Sonnet and Gemini-2.5-Flash, leaving only a small fraction of repositories suitable for agent training. The paper argues that environment construction is not merely a preprocessing step but a core agentic capability exercising long-horizon tool use, dependency reasoning, and failure recovery, yet no dedicated model has been trained to specialize in this task at scale.

## Input / Output

The pipeline consumes GitHub repositories (≥500 stars, ≥200 forks) with merged, test-backed pull requests across 10+ programming languages, using the commit SHA and PR description as the task specification. A four-agent system iteratively inspects dependency manifests, build scripts, CI configurations, and test entry points to produce a valid Dockerfile and an executable eval script that configures the container workspace and invokes target test commands. The final output is a built Docker environment in which the repository's test suite transitions from failing to passing, verified by exit-code-based parsing rather than manual inspection.

## Method

DOCKSMITH extends the SWE-Factory multi-agent pipeline with two key mechanisms: a loop-detection controller that monitors agent-invocation traces and enforces strategy diversification when repeated repair cycles stall, and a cross-task success-memory pool that retrieves previously verified (Dockerfile, eval script) pairs as lightweight demonstrations for new repositories. Training uses supervised fine-tuning of Qwen3-Coder-30B-A3B-Instruct on 692k curated trajectory steps from 45k environment-construction instances, with a three-stage data curation process: acceptance shaping to prune redundant rollouts, a Z-score-normalized complexity score (Dockerfile lines, RUN count, package count) for 1:2:2 Easy/Medium/Hard curriculum sampling, and per-language token contribution limits for cross-language balancing. Joint training with SWE-solving trajectories at a controlled token-level mixing ratio (optimal around 1:0.5 to 1:1) prevents over-specialization and enables transfer to downstream agentic tasks.

## Results

On Multi-Docker-Eval, DOCKSMITH (30B-A3B) achieves 39.72% Fail-to-Pass and 58.28% Commit Rate, setting the open-source state of the art and surpassing the previously reported 37.7% F2P upper bound. This represents a +20.3 absolute F2P improvement over the base Qwen3-Coder-30B-A3B-Instruct (19.46% F2P). On transfer benchmarks, joint training with Docker-building trajectories yields up to +3.37 points on Terminal-Bench 2.0 and +2.25 on SWE-bench Verified, while on EnvBench DOCKSMITH reaches 73.08% pass@1 on JVM, far exceeding the prior SOTA of 29.47%.

## Baselines & Comparisons

DOCKSMITH outperforms all seven baselines on Multi-Docker-Eval F2P. Against the strongest open-source baselines, it beats DeepSeek-v3.1 (37.72%) by +2.0 points and Kimi-K2-0905 (37.62%) by +2.1 points, while surpassing the much larger Qwen3-235B-A22B (23.65%) by +16.1 points. Among closed-source models, DOCKSMITH exceeds Claude-Sonnet-4 (35.53%) by +4.2 points, GPT-5-Mini (34.13%) by +5.6 points, and Gemini-2.5-Flash (29.44%) by +10.3 points. On EnvBench, DOCKSMITH achieves 73.08% JVM pass@1 versus 29.47% for the prior SOTA (GPT-4o Bash Agent) and 10.53% for the un-finetuned backbone, demonstrating strong generalization from PR-level to repository-level environment construction. The base model (Qwen3-Coder-30B-A3B-Instruct) scores only 19.46% F2P, confirming that the gains stem from the training procedure rather than model scale.

## Relation to Prior Work

This paper extends SWE-Factory (Guo et al., 2025), a multi-agent pipeline for automated Docker-based environment construction, by adding a loop-detection controller and cross-task success-memory retrieval to improve trajectory quality at scale. Conceptually, it departs from prior work (ExecutionAgent, SetupAgent, SWE-Factory) that treats environment setup as a supporting preprocessing step, instead reframing it as a first-class agentic task whose training signal transfers to broader software engineering capabilities. The training methodology draws on supervised fine-tuning with curriculum learning and joint multi-task training, building on the broader SWE-agent training literature (SWE-bench, SWE-Gym, Nex Agent-SFT) but applying it specifically to environment-construction trajectories.

## Why It Matters / Open Questions

Reliable environment construction is a well-recognized bottleneck that limits the yield of usable training trajectories for SWE agents; DOCKSMITH's 39.72% F2P (vs. ~37.7% prior SOTA) and 42.5% error reduction offer a practical path to scaling execution-grounded pipelines. The more consequential finding is that Docker-building supervision transfers to downstream agentic tasks (up to +3.37 on Terminal-Bench, +2.25 on SWE-bench Verified), suggesting environment construction is a genuine agentic skill rather than mere plumbing. Open questions include whether the transfer effect persists at larger model scales, whether the approach generalizes beyond Docker to other containerization or VM-based environments, and whether the modest absolute F2P (~40%) is sufficient for high-throughput data generation in production pipelines.

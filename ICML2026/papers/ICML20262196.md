## Problem

Neural networks suffer from polysemanticity: multiple features are forced to share the same neurons, causing interference that degrades both interpretability and accuracy. Prior work on superposition and sparsity has focused on either adding parameters or pruning them, but has not explored whether redistributing a fixed non-zero parameter budget across more neurons can reduce feature collisions and improve performance without increasing model size.

## Input / Output

The method accepts three input types depending on the experimental setting: binary Boolean truth assignments (with small continuous noise in [0,0.5] and [3,3.5] for ReLU stability), 512-dimensional CLIP ViT-B/16 embeddings for frozen-representation classification, and raw 32×32 RGB images for joint CNN+MLP learning. Output is a class label (binary for Boolean DNF tasks, multiclass for vision benchmarks up to 1000 classes). A key structural constraint is that each sub-neuron's input support is disjoint from its siblings', so no two sub-neurons of the same original neuron see the same input dimensions.

## Method

Fixed Parameter Expansion (FPE) takes a near-converged dense network and duplicates each hidden neuron into α sub-neurons, partitioning the input dimension into α disjoint binary masks so that each sub-neuron receives a unique subset of input features. The output layer is expanded by duplicating columns, and the smallest-magnitude weights across both layers are pruned to restore the original total non-zero parameter count. The expanded model is then fine-tuned under identical schedules as the dense baseline. Theoretically, this preserves clause coverage with high probability while reducing expected feature collisions by approximately α^(-(2k-1)), where k is the clause size. The approach is distinct from pruning or growth methods because it neither adds nor removes parameters—it reallocates a fixed budget to increase neuron count and enforce disjoint input supports, directly targeting the interference mechanism identified by the superposition hypothesis.

## Results

On CLIP-embedded CIFAR-100, Fixed Parameter Expansion (FPE) with α=2 improves test accuracy from 57.8% (dense, 8 neurons) to 65.9% (random-split FPE), a 14% relative gain at identical non-zero parameter count. Gains are largest in high-superposition regimes: on ImageNet-100 with only 3 hidden neurons, FPE lifts accuracy from 38.5% to 60.3% (57% relative improvement), and on Boolean DNF tasks, clause-split FPE reaches 99.4% versus 78.7% for the dense baseline. On ImageNet-1k (5-layer MLP), FPE consistently adds 0.7–1.3 absolute points across all tested widths (e.g., 30.6%→31.9% at 10 neurons). Feature capacity increases and neuron cosine similarity decreases in lockstep with accuracy gains, confirming reduced interference as the mechanism.

## Baselines & Comparisons

The primary baseline is the dense model with the same number of non-zero parameters but fewer neurons; FPE consistently outperforms it across all datasets and widths, with the largest margins (up to ~57% relative) when neuron count is small relative to feature demand. Against DropConnect-style controls (Section A.8.4), FPE wins on both variants: the non-disjoint one-shot random-mask baseline (same sparsity degree but overlapping supports) underperforms FPE and, at large expansion factors, even falls below the dense model, isolating disjointness as the critical factor. Standard DropConnect (resampled masks during training, dense scaled weights at test) also trails FPE despite having access to more active weights at inference. On CIFAR-100 with h=8, α=2, FPE achieves 61.9% accuracy versus 53.9% for the non-disjoint baseline and below-dense for standard DropConnect. The paper also notes that FPE with 2:4 structured sparsity (hardware-friendly) achieves 61.7% versus 61.9% for unstructured random FPE, showing negligible performance loss for the structured variant.

## Relation to Prior Work

This paper repurposes the superposition hypothesis and feature-channel coding theory (Elhage et al., 2022; Adler et al., 2025) as a design principle rather than an analytical lens, proposing Fixed Parameter Expansion (FPE) as a 'third path' between train-then-sparsify and train-then-grow paradigms. It explicitly distinguishes itself from sparse autoencoders (which diagnose superposition externally) and from pruning/growth methods (which change parameter count), instead holding non-zero parameter count fixed while increasing neuron count via disjoint weight partitioning. The theoretical analysis builds on the combinatorial packing bounds of Adler et al. (2025) to show that random sparsification alone reduces expected clause collisions by ~α^(-(2k-1)), and the empirical comparison against DropConnect (Wan et al., 2013) isolates disjointness as the critical mechanism rather than sparsity per se.

## Why It Matters / Open Questions

The paper identifies neuron count as an architectural axis orthogonal to parameter count, with practical implications for modern accelerators where memory movement of non-zero weights (not FLOPs) is the dominant bottleneck. Key open questions include whether FPE scales to transformer architectures and depth-wise expansion, whether stronger feature-discovery methods (e.g., SAEs) can replace the current heuristic Gram-matrix clustering to yield larger gains, and whether dynamic mask retraining (which showed 4.5% additional improvement) can close the gap to dense models at larger scale. The authors are candid that FPE is a mechanistic proof of concept rather than a deployment-ready recipe, and that benefits naturally diminish when the dense model already has sufficient capacity.

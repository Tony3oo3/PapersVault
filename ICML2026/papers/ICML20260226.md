## Problem

Given observed equilibrium behavior from two players in an unknown bimatrix game, the set of payoff matrices consistent with that behavior (the feasible payoff set) is inherently underdetermined, yet no prior work characterized the minimax sample complexity of estimating this set up to Hausdorff error ε. This paper provides the first tight (matching upper and lower) sample complexity bounds for set-valued payoff inference, covering both exact and approximate Nash equilibria in general-sum and zero-sum games.

## Input / Output

The learner receives i.i.d. action pairs (X_t, Y_t) drawn from the product distribution x×y, where (x,y) is an α-Nash equilibrium of an unknown n×n bimatrix game, along with the parameters α, ε, and δ. The output is not a single payoff matrix but the entire feasible set G_α(x,y) (or Z_α(x,y) for zero-sum), represented as a collection of linear inequalities in the payoff entries, with the guarantee that the Hausdorff distance (in ℓ_∞ norm) between the true and estimated sets is at most ε with probability ≥ 1−δ. Notably, the zero-sum set cannot be obtained by simply slicing the general-sum estimate on the hyperplane A=−B, so the two settings require separate analyses.

## Method

The algorithm (Procedure 1) is the plug-in estimator: collect m samples, compute empirical means x̂ and ŷ, and return the feasible set G_α(x̂,ŷ) (or Z_α(x̂,ŷ)). The technical core is proving this simple procedure is minimax optimal. For exact equilibria (α=0), the feasible-set correspondence is strongly discontinuous when supports change, making the problem unlearnable without a minimum-probability assumption π_min>0; under that assumption the rate is Õ(log(1/δ)/log(1/(1−π_min)) + (n+log(1/δ))/ε²). For approximate equilibria (α>0), the key insight is that the Hausdorff error scales as O(α⁻¹(x̂−x)ᵀAy), and controlling the supremum over feasible A reveals a hidden fractional knapsack structure: the optimization reduces to summing (x̂_i−x_i) over subsets S with Σ_{i∈S}x_i ≤ α/2, whose variance is O(α) rather than O(1). Bernstein concentration over these subsets yields the tight rate O((n+log(1/δ))/(ε²α) + √n·log(1/δ)/(εα)), matching the lower bound constructed via change-of-measure arguments on pairs of instances separated by O(ε) in Hausdorff distance but with KL divergence O(ε²α).

## Results

The paper establishes the first minimax-optimal sample complexity rates for estimating the feasible payoff set in bimatrix games. For exact equilibria (α=0) with minimum action probability π_min > 0, the optimal rate is Õ(log(n/δ)/log(1/(1−π_min)) + (n + log(1/δ))/ε²). For approximate equilibria (α>0), the optimal rate is O((n + log(1/δ))/(ε²α) + √n·log(1/δ)/(εα)), matching the lower bound Ω((n + log(1/δ))/(ε²α)) for ε ≲ n^{-1/2}. A key finding is that exact equilibrium learning is fundamentally unlearnable (infinite sample complexity) without the π_min assumption, due to strong discontinuities in the feasible payoff correspondence.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The central 'comparison' is between the lower bounds (Theorems 3.1–3.3) and the upper bounds achieved by the simple empirical-mean algorithm (Procedure 1, Theorems 4.1–4.2), which match up to logarithmic factors, establishing minimax optimality. The paper positions itself against prior inverse game theory work (Kuleshov & Schrijvers 2015; Waugh et al. 2011) that either restricts to parametrized payoff families or selects a single equilibrium via maximum entropy, whereas this work recovers the full feasible set without such restrictions. The closest prior theoretical work is the single-agent IRL feasible-reward-set literature (Metelli et al. 2023), which identified a similar unlearnability phenomenon for exact policies; this paper extends that insight to the multi-agent game-theoretic setting and provides the first sharp rates for both general-sum and zero-sum games.

## Relation to Prior Work

This paper extends the inverse game theory literature (Waugh et al., 2011; Kuleshov and Schrijvers, 2015), which previously focused on computational feasibility of finding a single rationalizing payoff under parametric or structural restrictions, to the set-valued statistical learning problem of estimating the entire feasible payoff set from i.i.d. equilibrium samples. It draws conceptual inspiration from the feasible-reward-set approach in inverse reinforcement learning (Metelli et al., 2021, 2023; Poiani et al., 2024) and from revealed preference analysis, but departs from both by providing the first minimax-optimal sample complexity guarantees in a multi-agent strategic setting without imposing selection principles or low-dimensional parametric families. The technical analysis repurposes tools from bandit theory (change-of-measure lower bounds, Bernstein concentration) and reveals a hidden fractional knapsack structure in the Hausdorff error control problem.

## Why It Matters / Open Questions

The paper establishes that exact equilibrium learning is fundamentally impossible (infinite sample complexity) without support assumptions, and that approximate equilibria, while restoring learnability, introduce an unavoidable α^{-1} degradation that can substantially worsen rates. This provides the first learning-theoretic foundation for set-valued payoff inference, enabling downstream applications in mechanism design, auctions, and security games where deferring payoff selection to a later stage is desirable. Open questions include extending to correlated equilibria, infinite action spaces, evolving (non-stationary) strategies, and instance-dependent rates that exploit the specific geometry of the unknown strategy profiles.

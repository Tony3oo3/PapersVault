## Problem

Exact SHAP value computation for neural networks is #P-hard, requiring enumeration of all 2^n feature subsets, which renders it infeasible beyond small search spaces. Existing statistical estimators (KernelSHAP, TreeMSR, LeverageSHAP) provide only approximations without error guarantees, and there is no principled ground-truth baseline for evaluating them on realistic neural network dimensions. This paper bridges the gap by computing provably exact SHAP values and arbitrarily tight bounds using neural network verification techniques.

## Input / Output

The method takes a neural network f, a specific input vector x ∈ R^n, and a background dataset D over which the value function v(S) = E_{z~D}[f(x_S; z_S̄)] is defined. Feature subsets are encoded as binary masks m ∈ {0,1}^n, relaxed to the continuous domain [0,1]^n to enable bound propagation. The output is either the exact SHAP value φ_i for each feature i, or certified lower and upper bounds [φ̲_i, φ̄_i] at any user-specified precision δ, with the guarantee that the true value lies within the interval. The algorithm can also simultaneously bound all n features by partitioning the full power set P([n]) rather than per-feature coalition sets.

## Method

VERISHAP performs an incremental branch-and-bound search over the feature coalition space S_i, where each branch is defined by sets of included and excluded features. Within each branch, CROWN-IBP linear bound propagation computes tight lower and upper bounds on the marginal contribution Δ_i(S) = v(S∪{i}) − v(S) by treating the binary feature mask as a continuous input to the network. A closed-form expression Λ_B = 1/((s+1)·C(s,r)) for the total Shapley weight of a branch (where r = |I|, s = |I|+|E|) enables efficient aggregation of per-branch bounds into global SHAP bounds. The algorithm recursively splits branches by selecting a feature (via SMEARS gradient-based strategy) and a branch (via MAXDIAM diameter-based strategy), with pruning when bounds collapse. For linear models the algorithm terminates in a single iteration, and for ReLU networks it terminates early once each branch lies within a single linear region, yielding runtimes of O(B·T_BP) where B is the number of explored branches.

## Results

VERISHAP computes exact SHAP values for search spaces up to 2^25 ≈ 3×10^7 coalitions and provides tight bounds (10% half-range) up to 2^60 ≈ 10^18 coalitions, whereas the state-of-the-art exact method EXACTSHAP exhausts GPU memory beyond 2^20 ≈ 10^6 coalitions. On an MNIST CNN with 8×8 superpixels (2^64 > 10^19 coalitions), VERISHAP recovers exact SHAP values in 34 seconds, with attribution patterns already visible after just 120 iterations (25 s). On the Mushroom dataset (2^22 coalitions), VERISHAP computes exact SHAP in 25 s while EXACTSHAP cannot complete; on Auto (2^25), VERISHAP finishes in 316 s versus EXACTSHAP's memory exhaustion.

## Baselines & Comparisons

Against EXACTSHAP (the prior state-of-the-art exact method), VERISHAP is slower for small search spaces (e.g., 18 s vs. 4 s on Obesity, 20 s vs. 9 s on German) but is the only method that completes beyond 2^20 coalitions, extending exact computation to 2^25 and tight-bound computation to 2^60. Against KERNELSHAP, VERISHAP provides certified bounds rather than statistical estimates; on Mushroom, Default, and Auto, KERNELSHAP requires 346 s, 123 s, and 351 s at its largest feasible sample sizes yet still cannot match VERISHAP's accuracy, and offers no variance guarantee. TREEMSR shows similar limitations, requiring 895 s, 132 s, and 341 s on the same three datasets. Using VERISHAP-computed exact SHAP as ground truth on larger search spaces, the paper finds that LEVERAGESHAP outperforms KERNELSHAP in MSE (confirming trends from smaller settings), while TREEMSR exhibits volatile performance across datasets when applied to neural networks—a nuance not visible in prior tree-model evaluations.

## Relation to Prior Work

VERISHAP repurposes branch-and-bound neural network verification (CROWN, IBP, LBP) — a tool developed for adversarial robustness certification — to compute exact Shapley values, a task previously addressed only by exhaustive coalition enumeration (EXACTSHAP) or statistical estimation (KernelSHAP, TreeMSR, LeverageSHAP). Prior formal-explainability work (VeriX, Bassan et al.) applied verifiers to robustness-based explanation types that map naturally onto input-output specifications, whereas SHAP's discrete, probabilistic, and exponentially-summed structure required the new partitioning and mask-relaxation machinery introduced here. The paper thus sits at the intersection of two mature subfields (NN verification and Shapley-value computation) and is the first to bridge them for the SHAP framework specifically.

## Why It Matters / Open Questions

By providing provably tight lower and upper bounds on SHAP values at arbitrary precision, VERISHAP gives the XAI community its first scalable 'ground-truth' reference for evaluating statistical estimators on search spaces (up to 2^60 coalitions) where exact enumeration was previously infeasible. The practical limitation is that the underlying problem remains #P-hard: on some networks (tanh, Swish, larger ResNets) runtimes grow substantially, and a few tabular datasets with <60 features still resisted tight bounding within the 600 s timeout. Open questions include extending the approach to higher-order Shapley interactions, alternative value functions, and continuous input distributions, as well as whether continued progress in NN verification (e.g., SDP-based relaxations, learned cutting planes) will close the remaining gap to real-world-scale networks.

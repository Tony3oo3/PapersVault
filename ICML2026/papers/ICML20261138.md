## Problem

Existing theoretical results for neural network algorithm execution provide only approximate guarantees, which are inadequate for iterative graph algorithms where small errors compound across rounds. While Back de Luca et al. (2025a) established exact learnability for feedforward networks, those architectures are poorly suited to variable-size graph inputs, requiring the entire graph to be encoded in a single input vector. This paper asks: can GNNs learn to execute graph algorithms exactly, with the structural efficiency that message passing provides?

## Input / Output

The method takes an attributed graph with binary node feature vectors (encoding local IDs, algorithm state, and message slots) and a binary adjacency matrix with self-loops, under bounded maximum degree D and finite bit precision l. Training data consists of binary instruction pairs—block configurations mapped to output labels—rather than full input-output examples of the algorithm. Outputs are exact binary node states after O(L) GNN iterations; for algorithms requiring unique global IDs (BFS, DFS, Bellman-Ford), the node count is bounded by 2^l − 1, while Message Flooding applies to arbitrarily large graphs of bounded degree.

## Method

The architecture is a GNN whose update function is an ensemble of infinite-width MLPs, each trained on the same set of binary, block-structured instructions (template matching) that encode local node operations. At inference, the ensemble mean is binarized via a Heaviside step function, then split by complementary masking matrices P_C and P_M: the computation component is kept local while the message component is aggregated across neighbors via the adjacency matrix, implementing one round of distributed computation. The key insight is a two-step decoupling—static training on local instructions followed by iterative GNN execution—so that a single learned local rule, shared across all nodes, composes into a full graph algorithm. NTK theory in the infinite-width regime guarantees that the ensemble mean converges to the NTK predictor, which exactly recovers the template-matching function, yielding exact execution with arbitrarily high probability. A graph template matching framework serves as the formal bridge, proving that any LOCAL-model algorithm can be expressed as iterated template matching and that the GNN learns this framework exactly.

## Results

The paper establishes exact learnability (with arbitrarily high probability) for four canonical graph algorithms under bounded-degree and finite-precision constraints. For Message Flooding, the GNN requires O(D²·d_G) iterations, a training set of O(l·D²) samples, and an ensemble of O(l²D⁴ + lD²·log(nD²d_G)) MLPs. For BFS and DFS, the training set and embedding dimension grow to O(l·D³), while Bellman-Ford requires O(n²(l·D + l·d_G + D²·d_G)) iterations. Empirically, on 7-node trees with 1-bit messages, perfect accuracy is achieved with ensembles in the low hundreds, and the NTK predictor (replacing the ensemble) achieves 100% exact execution on 100 random graphs for all four algorithms.

## Baselines & Comparisons

This is a theoretical paper with no direct empirical baseline comparisons; the `compares_to` set is empty. The primary architectural comparison is with Back de Luca et al. (2025a), a feedforward-network approach to exact algorithmic learning. The GNN architecture of this paper is strictly more efficient in three dimensions: (i) graph size — node features scale as O(l) or O(log N) rather than O(N), since graph structure is captured via message passing rather than explicit encoding; (ii) instruction count — all nodes share the same local processor, so instructions grow polynomially in D and only logarithmically in N, versus at least linearly in N for the feedforward approach; (iii) ensemble size — the embedding dimension grows polynomially in D and logarithmically in N, yielding asymptotically smaller ensembles for bounded-degree graphs. The paper also notes that its GNN iteration counts can exceed those of classical centralized algorithms due to distributed information propagation and bitwise execution granularity, but this is not a direct performance comparison. Empirically, the NTK predictor achieves 100% exact accuracy on all 100 random test graphs for each of the four algorithms, confirming the theoretical guarantees without any approximation error.

## Relation to Prior Work

This paper extends the exact-learnability framework of Back de Luca et al. (2025a), which proved NTK-based guarantees for feedforward networks executing binary algorithms, to the graph setting by replacing the single feedforward model with an ensemble of shared MLPs embedded in a message-passing GNN. The architectural choice is motivated by Loukas (2020), who established an expressive-power equivalence between GNNs and the LOCAL model of distributed computation, but that work only addressed expressivity; here the authors close the gap by proving learnability. The NTK machinery (Jacot et al., 2018; Lee et al., 2019) is used in its standard infinite-width form, and the template-matching construction for local operations is inherited directly from Back de Luca et al. (2025a), with the key departure being that all nodes share the same local processor, reducing instruction count from linear (feedforward) to polynomial-in-degree / logarithmic-in-nodes (GNN).

## Why It Matters / Open Questions

The main contribution is the first exact (non-approximate) learnability guarantee for GNNs executing graph algorithms, with the LOCAL model result subsuming a broad class of distributed algorithms under a single theorem. However, the guarantees require infinite-width MLPs, bounded maximum degree, finite-precision identifiers, and ensemble sizes that grow polynomially in degree and logarithmically in graph size—constraints that limit near-term practical use. The empirical validation is restricted to Message Flooding on small trees due to compute costs, leaving BFS, DFS, and Bellman-Ford verified only via NTK predictors rather than trained ensembles. Open questions include whether finite-width training dynamics can recover the same guarantees, whether the framework extends to attention-based or transformer architectures, and whether the bounded-degree assumption can be relaxed.

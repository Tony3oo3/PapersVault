## Problem

Linear attention achieves O(N) complexity but consistently underperforms softmax attention due to two structural failures: (1) the normalization step cancels the query norm, severing the natural link between query magnitude and attention entropy (spikiness) that softmax preserves, and (2) element-wise non-negativity enforcers like ReLU or 1+ELU destroy valid negative inner-product interactions, causing destructive information loss. The paper provides the first theoretical characterization of how query norm controls entropy in softmax attention and shows that existing linear attention kernels are provably query-norm-unaware.

## Input / Output

NaLaFormer is a drop-in linear attention module that replaces the softmax attention head in existing backbones (Swin, PVT, DiT, SiT, DeltaNet, Gated DeltaNet, ESRT, DCTLSA). For vision tasks it consumes standard RGB images at various resolutions (224×224 for classification, up to 70K+ tokens for super-resolution) and produces task-specific outputs: class logits, detection boxes with class labels, pixel-wise segmentation masks, or upscaled images. For language modeling it processes token sequences and produces next-token distributions. The mechanism doubles the feature dimension (cosine and sine sub-vectors) relative to the head dimension, adding a small constant overhead while preserving linear sequence-length scaling.

## Method

NaLaFormer decomposes query and key vectors into norm × direction (ND) components and addresses each failure separately. For the query, a norm-aware power map φ_q(q) = dir(q)^{f(||q||)} with f(x) = λ(τ + tanh(x)) injects the query norm as a dynamic exponent, restoring the negative norm–entropy correlation observed in softmax attention (larger norm → sharper distribution). For non-negativity, a cosine direction similarity maps each scalar direction component to a 2D (cos, sin) vector, so the inner product becomes |dir(q)_i||dir(k)_i| cos(dir(q)_i − dir(k)_i); direction components are pre-scaled to [−π/4, π/4] via a tanh mapping, guaranteeing the angular difference stays within [−π/2, π/2] and thus the cosine term is always non-negative without discarding negative-valued dimensions. The unified block integrates these feature maps into a gated linear attention architecture (following GLA/DeltaNet), computing the output as a ratio of two accumulated statistics (S_cos, S_sin) modulated by a learned SiLU gate, maintaining O(Nd) complexity throughout.

## Results

On ImageNet-1K, NaLaFormer achieves up to 85.7% Top-1 accuracy (NaLaFormer-L, 95M params), surpassing the strongest comparable baselines (RAVLT-L at 85.5%, RMT-L at 85.5%) and delivering up to a 7.5% gain over smaller linear-attention models. On ADE20K semantic segmentation, NaLaFormer-T reaches 46.9% mIoU (a 4.7% improvement over SegNeXt-S), and on COCO detection (Mask R-CNN 1×), NaLaFormer-S achieves 49.5 AP^b / 44.2 AP^m. In token-intensive super-resolution (70K+ tokens), NaLa-DCTLA reduces peak memory by 92.3% and latency by up to 96.6% versus SwinIR while improving PSNR. On the Long Range Arena benchmark, NaLaFormer attains 61.2% average accuracy, outperforming PolaFormer (60.7%) and softmax attention (58.1%).

## Baselines & Comparisons

NaLaFormer consistently outperforms all compared linear-attention and SSM baselines across every scale on ImageNet-1K: at the ~26M-param tier, NaLaFormer-S (84.3%) edges out RAVLT-S (84.2%), MILA-T (83.5%), and MambaOut-S (84.1%); at the ~52M tier, NaLaFormer-B (85.2%) surpasses StructViT-B-8-1 (84.3%) and SOFT-L (83.1%); at the ~95M tier, NaLaFormer-L (85.7%) beats RMT-L (85.5%), RAVLT-L (85.5%), and VRWKV-B (82.0%) by 0.2–3.7 points. On COCO detection, NaLaFormer-T (47.6 AP^b) and NaLaFormer-S (49.5 AP^b) outperform MAVI-T (47.5), RAVLT-T (47.2), and VMamba-T (47.3) under the Mask R-CNN 1× protocol. On ADE20K, NaLaFormer-T (46.9% mIoU) improves over SegNeXt-S (44.3%) and EfficientViT-B2 (45.9%) by 2.6 and 1.0 points respectively, while NaLaFormer-S (48.5%) surpasses VWFormer-B2 (48.1%). In language modeling, NaLa+GDN (44.8 avg) beats Gated DeltaNet (44.3) and Mamba (44.1), and NaLa+DN (44.3) outperforms DeltaNet (43.6) and GLA (43.7). On LRA, NaLaFormer (61.2%) leads PolaFormer (60.7%) and softmax attention (58.1%) while maintaining competitive throughput (827.7 TGS). The only notable trade-off is a slight FLOPs increase (e.g., 4.8G vs 4.5G in the Swin-T ablation) due to the doubled cos/sin feature dimensions, but this is offset by the accuracy gains.

## Relation to Prior Work

NaLaFormer extends the linear attention lineage initiated by Katharopoulos et al. (2020) and the spikiness-focused variants (FLatten, PolaFormer, Hedgehog) by providing a theoretical diagnosis—via a Norm × Direction decomposition—that identifies query norm cancellation as the root cause of entropy inflation in linear attention, rather than treating it as an empirical symptom. The cosine direction similarity mechanism for non-negativity is conceptually distinct from Cosformer and RoPE, which use cosine for positional decay rather than dimensional similarity preservation. Architecturally, the method is integrated into the gated linear attention framework (GLA, DeltaNet, Gated DeltaNet) and the ESRT/DCTLSA super-resolution backbones, making it a drop-in kernel replacement rather than a new architecture from scratch.

## Why It Matters / Open Questions

The ND decomposition provides a principled, reusable framework for understanding and designing linear attention kernels: any future kernel can be analyzed for whether it preserves or cancels query norm information, giving the community a diagnostic tool beyond trial-and-error activation function selection. The 92.3% peak memory reduction in 70K+ token super-resolution tasks is practically significant for deployment on resource-constrained hardware. Open questions include whether the norm-aware power function remains stable at much larger scales (the paper addresses this with a QK-Norm comparison but only at 340M parameters), whether the cosine direction mapping generalizes beyond element-wise 2D encoding to higher-order interactions, and whether the approach transfers to non-vision modalities beyond the 340M language model tested here.

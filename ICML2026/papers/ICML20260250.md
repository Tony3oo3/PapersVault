## Problem

Recurrent neural networks compress an entire input sequence into a fixed-size memory state, which forces them to forget earlier information and causes significant underperformance on recall-intensive and long-context tasks compared to Transformers. The fundamental tension is that Transformers achieve growing memory (and thus strong recall) at O(L²) cost, while RNNs maintain O(L) cost but with bounded capacity. The paper asks whether RNNs can be given a controllable, growing memory that interpolates between these two extremes.

## Input / Output

The method takes a token sequence x ∈ R^{L×d_in} and produces contextual representations and next-token predictions at each position. The sequence is partitioned into N segments of configurable size (e.g., 16–512 tokens), and the model caches one compressed memory state per segment boundary. At each token, the output is computed by aggregating the current online memory with all previously cached segment memories, yielding a per-token retrieval cost of O(N) forward passes over memory modules and a total complexity of O(NL) that interpolates between O(L) (N=1, standard RNN) and O(L²) (N=L, equivalent to attention).

## Method

Memory Caching (MC) segments the input sequence and caches the compressed memory state at each segment boundary, then at retrieval time each token queries both its current online memory and all cached past memories. Four aggregation strategies are proposed: (i) Residual Memory, which simply sums outputs from all cached memories; (ii) Gated Residual Memory (GRM), which applies input-dependent gates γ_t^(i) computed as the similarity between a projected query and the mean-pooled context of each segment, enabling selective retrieval; (iii) Memory Soup, which interpolates the parameters of cached memory modules (inspired by weight souping) to construct a single data-dependent retrieval function—critical for non-linear/deep memories where output-level summation collapses; and (iv) Sparse Selective Caching (SSC), which uses a Mixture-of-Experts-style router to select only the top-k most contextually relevant cached memories, reducing retrieval cost and memory footprint. The technique is architecture-agnostic and is demonstrated on Linear Attention, Deep Linear Attention, Sliding Window Linear Attention, and Titans, with the memory update rule f(·) remaining unchanged per segment while only the retrieval process is modified.

## Results

On Needle-in-a-Haystack (NIAH) tasks, Titans+GRM achieves 100% accuracy on S-NIAH-1 (passkey retrieval) across all context lengths (4K/8K/16K), 99.8%/96.6%/88.2% on S-NIAH-2 (numerical needle), and 89.4%/69.0%/32.2% on S-NIAH-3 (UUID needle), substantially outperforming base Titans (75.4% at 16K on S-NIAH-2) and DLA (44.0% at 16K on S-NIAH-1). On language modeling (760M params, 30B tokens), Titans+GRM achieves 51.56% average commonsense reasoning accuracy, surpassing Transformer++ (49.64%), RWKV-7 (50.55%), and matching Miras/Memora (51.53%). On in-context retrieval (Table 3), Titans+GRM reaches 50.1% on SWDE and 72.9% on FDA at 512-token input, approaching Transformer's 46.2% and 71.0% respectively, while base DLA drops to 32.5% on SWDE at 16K context.

## Baselines & Comparisons

Against Transformer, MC-enhanced RNNs close but do not fully close the gap: Titans+GRM beats Transformer on S-NIAH-1 at 16K (100% vs. 79.8%) and S-NIAH-3 at 4K (89.4% vs. 78.0%), but Transformer still leads on S-NIAH-2 at 16K (94.2% vs. 88.2%) and S-NIAH-3 at 16K (40.8% vs. 32.2%). Compared to base DLA, MC variants yield dramatic gains at longer contexts—DLA+GRM improves S-NIAH-1 at 16K from 44.0% to 82.4% and S-NIAH-2 at 16K from 28.2% to 54.8%. Against base Titans, MC variants provide consistent improvements at 8K and 16K (e.g., S-NIAH-2 at 16K: 75.4% → 88.2% with GRM). Versus Log-Linear++, MC variants (especially GRM) outperform at longer contexts where Log-Linear++ struggles due to forcing a single memory to compress very large initial segments. On commonsense reasoning (760M), Titans+GRM (51.56% avg) matches or exceeds all RNN baselines including RWKV-7 (50.55%), Miras/Memora (51.53%), and Samba (51.46%), and surpasses Transformer++ (49.64%). Among MC variants, GRM consistently outperforms Memory Soup and SSC across all tasks, with SSC offering the best efficiency trade-off for ultra-long sequences.

## Relation to Prior Work

This paper positions Memory Caching as a general technique that interpolates between fixed-memory RNNs (linear attention, Titans, DLA, SWLA) and growing-memory Transformers, drawing on the test-time memorization / associative memory framework (Behrouz et al., 2025b) to interpret cached states as checkpoints of an optimization process. It adapts model soups (Wortsman et al., 2022) to combine cached memory parameters and borrows the Mixture-of-Experts routing idea (Shazeer et al., 2017) for sparse selective retrieval. A notable conceptual contribution is showing that hybrid architectures (compressor + global attention, e.g., Samba) are mathematically equivalent to MC with segment size 1, unifying two previously separate design philosophies. The paper also improves upon Log-Linear Attention (Guo et al., 2025) by adding context-dependent gating, reframing it as a special case of MC with logarithmic segmentation.

## Why It Matters / Open Questions

MC provides a practical, architecture-agnostic recipe for extending the effective context length of recurrent models without incurring quadratic cost, offering a tunable O(NL) complexity knob between RNN and Transformer regimes. The consistent gains across four distinct architectures (SWLA, DLA, Titans, and their MC-enhanced variants) and five task families (language modeling, NIAH, in-context retrieval, LongBench, MQAR) suggest the technique is broadly applicable rather than architecture-specific. Key open questions include optimal segmentation strategies (constant vs. logarithmic vs. adaptive), more expressive pooling and routing mechanisms, and whether MC can fully close the remaining gap with Transformers on the hardest recall-intensive tasks. The paper acknowledges that even the simplest residual variant (which mathematically collapses for linear memories) still helps empirically, suggesting the benefit may partly come from the retention/regularization effect rather than pure capacity increase.

## Problem

Existing LLM-based clarification methods for visual design focus on selecting questions that better uncover user intent but largely ignore the cognitive burden imposed on users—the effort required to interpret and answer those questions. This paper addresses the gap by explicitly formulating and jointly optimizing human interaction cost alongside final design alignment, treating the user's cognitive and response effort as a constrained resource rather than an afterthought.
![Teaser figure](../imgs/ICML20264829/cropped_page0_idx0.webp)

## Input / Output

The question agent receives only an initial underspecified text prompt and maintains an evolving design plan; it never observes the target artifact. The user agent (simulated by Gemini-2.5-Pro) sees the ground-truth target image (and logo or asset list for task-specific cases) and answers one question per step in a respond-or-reject format. Interaction is bounded by a fixed question budget B=12, split into n replanning rounds of at most m questions each, after which a single-shot generator (Gemini-2.5-Pro for HTML, gpt-image-1 for banners) produces the final artifact from the terminal plan. Interaction cost is measured as the product of reasoning tokens and response tokens per QA pair, serving as a proxy for human cognitive and response burden.

## Method

A-MPQC formulates multi-round clarification as trajectory optimization with receding-horizon replanning, adapting the Model Predictive Control template to the questioning domain without requiring a learned dynamics model. Three test-time mechanisms make this feasible: (i) question plans pair each candidate question with a compact lookahead direction (the NEXT field), letting the agent reason about downstream effects before committing; (ii) a respond-or-reject interface yields a binary surrogate reward that signals whether a questioning direction is worth pursuing, and accepted answers directly update the design plan; (iii) adaptive format control shifts the agent toward the least expressive sufficient format (binary < multiple-choice < open-ended), escalating expressiveness only when a less expressive format is rejected. Crucially, MPC is applied at the interaction level (across n plan-update rounds) rather than within a round's m-question sequence, keeping total user responses bounded by the budget B and avoiding the O(KH) cost of evaluating multiple rollouts. The entire pipeline is test-time: no retraining of the plan updater, generator, or question agent is required.

## Results

Under a fixed question budget of B=12 (n=3 replanning rounds, m=4 questions/round), A-MPQC achieves the best alignment-burden efficiency (ΔS/C̃) on both benchmarks: 0.188 on WebGen-V (ΔS=0.480, C̃=2.548) and 0.480 on MIMO (ΔS=0.594, C̃=1.238). On MIMO, A-MPQC also attains the highest similarity improvement (ΔS=0.594), outperforming the next-best DG+Flexible (ΔS=0.457) by 30% while using 47% less interaction cost. On WebGen-V, A-MPQC's ΔS of 0.480 trails only the high-cost DG+Open-Ended (ΔS=0.566, C̃=13.276), but at roughly 5× lower interaction cost, yielding a 4.5× efficiency advantage.

## Baselines & Comparisons

A-MPQC is compared against a family of Direct Generation (DG) baselines built on the question-asking principles of Hahn et al. (2025), instantiated with fixed formats (Binary, Multiple-Choice, Open-Ended), a flexible format selector (DG+Flexible), and a retrieval-augmented variant (DG+Flexible+RAG). On MIMO (banner generation), A-MPQC dominates all baselines on both alignment (ΔS=0.594 vs. 0.457 for DG+Flexible) and efficiency (0.480 vs. 0.219 for DG+Flexible+RAG), with the largest gap over unconstrained DG (ΔS/C̃ = 0.480 vs. 0.038, a 12.6× efficiency advantage). On WebGen-V (webpage generation), A-MPQC achieves the best efficiency (0.188) and second-best ΔS (0.480), trailing only the very high-cost DG+Open-Ended (ΔS=0.566 at C̃=13.276); against the more practical DG+Flexible baseline, A-MPQC improves ΔS by 14.6% while reducing cost by 73.5%. Fixed-format baselines confirm the cost-quality tradeoff: DG+Binary is cheapest but yields near-zero alignment gains (ΔS≈0.02), while DG+Open-Ended captures the most intent at 5–10× the interaction cost of A-MPQC. The retrieval-augmented baseline (DG+Flexible+RAG) provides inconsistent gains, suggesting that retrieved traces do not reliably match the current design intent, whereas A-MPQC's test-time replanning adapts per-instance without external exemplars.

## Relation to Prior Work

This paper transplants Model Predictive Control (MPC) from robotics and control theory into the domain of multi-round clarification for visual design, extending the textual-MPC-for-test-time-alignment line (Wang et al., 2026) from response generation to question generation. It builds on the proactive-agent and question-asking principles of Hahn et al. (2025) for token-based interaction cost, but departs from both learning-to-ask methods (which require multi-turn supervision or preference signals) and prior MPC-for-interaction work (which requires learned dynamics models) by treating the question sequence itself as the optimization object and using respond-or-reject feedback as a training-free surrogate reward. The key conceptual move is replacing expensive trajectory rollouts with lightweight 'question plans' (a question paired with a short-horizon follow-up direction), enabling receding-horizon replanning without any learned dynamics or reward model.

## Why It Matters / Open Questions

This is the first framework to explicitly co-optimize design alignment and proxy-estimated user cognitive burden in a budgeted multi-round clarification setting, offering a principled cost-quality tradeoff lens that prior clarification and active-learning work largely ignores. The test-time, no-retraining nature makes it immediately deployable, and the adaptive format-shifting (binary → MC → open-ended) provides a practical mechanism for reducing user effort. However, the reliance on an LLM as proxy user (validated only with moderate rank correlations, e.g., Spearman ρ = 0.41 for reasoning tokens) and the restriction to tasks admitting an explicit intermediate design plan limit generalizability; extending to iterative artifact refinement, open-ended creative collaboration, and real-user studies are important open directions.

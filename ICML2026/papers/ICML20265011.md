## Problem

Existing LLM-based user simulators are trained to imitate surface-level language patterns (e.g., emoji frequency, word choice) rather than capturing the higher-level psychological states—beliefs, emotions, stances, values—that actually drive how real users respond. This causes simulators to produce responses that mimic tone but miss key points, hold opposite opinions, or fail to generalize to unseen contexts, making them unreliable for user-centric applications.

## Input / Output

The model takes a structured user persona (demographics, interests, values, communication style, and response statistics summarized from the user's earliest 20 training responses) and an input context that can be single-turn (news transcriptions, blog posts, book metadata) or multi-turn (chat conversations of 5–10 turns, nested Reddit comment threads, email threads). At inference, the model first produces a reasoning trace that explicitly articulates latent states across all six dimensions, then synthesizes a natural-language user response. During training, the model is prompted to generate either a single state dimension's latent states or a full response, with an LLM judge scoring each comparatively within a batch of rollouts.

## Method

HUMANLM's core insight is to decompose user simulation into two sub-problems: generating aligned latent states and synthesizing responses from those states, rather than treating the response as the sole optimization target. The model (Qwen3-8b) is trained with GRPO reinforcement learning where, in each batch, a random state dimension is sampled and the model generates corresponding latent states (e.g., 'empathy toward victims' for emotion, 'disagree with the policy' for stance) that are scored comparatively by an LLM judge (GPT-5-mini) against the ground-truth response. This comparative batch scoring avoids the bias of independent absolute scoring and provides denser, more precise reward signals than response-level alignment alone. The six state dimensions—belief, goal, emotion, value, stance, and communication—are grounded in cognitive (BDI), normative (positioning theory), affective, and linguistic psychology. At inference, the model generates a full reasoning trace covering all six dimensions and uses it to synthesize a coherent response, with the training dynamics showing that explicit state alignment mitigates the combinatorial ambiguity and local optima that plague response-only RL training.

## Results

On the HUMANUAL benchmark (6 datasets, 23k users, 227k responses), HUMANLM achieves an average response alignment score of 13.2, a 16.3% relative improvement over the best baseline (GRPO-think, 10.4). Per-dataset gains range from 4.3% (Chat) to 36.0% (Book). In a real-time user study with 111 participants, HUMANLM attains the highest win rate of 41.4% on overall similarity (vs. 30.6% for Qwen3-8b-think and 27.9% for GRPO-think), with 76.6% of responses rated 'quite natural' or 'indistinguishable from humans.'

## Baselines & Comparisons

HUMANLM outperforms all seven baselines across all six HUMANUAL datasets. The closest competitor is GRPO-think (10.4 avg), which directly optimizes response alignment scores via RL without explicit latent-state generation; HUMANLM's 16.3% relative gain over it is driven by the denser state-level reward signal that mitigates combinatorial ambiguity. SFT-based methods (SFT: 6.5, SFT-think: 8.6) consistently perform worst, confirming that imitating surface-level language patterns fails to capture higher-level user states. UserLM (Naous et al., 2025), the only prior user-simulator baseline applicable to multi-turn chat, scores 2.47 on Humanual-Chat versus HUMANLM's 6.08. In the user study, HUMANLM significantly outperforms both Qwen3-8b-think (p=0.0279) and GRPO-think (p=0.00284) on overall similarity via Wilcoxon signed-rank tests, and participants noted it better matches stance, emotional intensity, and key considerations while avoiding redundant or overly neutral phrasing.

## Relation to Prior Work

This paper builds on the GRPO reinforcement learning framework (Shao et al., 2024) and the growing line of LLM-based user simulation work (Binz et al., 2025; Naous et al., 2025; Park et al., 2022/2023), but departs from both SFT-based imitation and standard response-level RL optimization. The key conceptual departure is reframing alignment from post-hoc (extract latent states from a generated response, then check consistency) to ad-hoc (explicitly generate latent states along psychologically grounded dimensions, reward their alignment, then synthesize the response from those states). This draws on the Belief-Desire-Intention framework, positioning theory, and speech production models to define six state dimensions (belief, goal, value, stance, emotion, communication) that jointly determine how a user responds.

## Why It Matters / Open Questions

User simulators are becoming critical infrastructure for human-centric AI (policy design, content personalization, multi-turn RL training), yet current approaches produce unreliable responses that miss higher-level user states. HUMANUAL provides the most comprehensive public benchmark to date (6 domains, 23k users, 227k responses), filling a gap where prior benchmarks relied on synthetic personas or narrow contexts. Open questions include whether state-alignment training generalizes to truly novel user profiles beyond the training distribution, how to handle temporal drift in user states, and whether the LLM-judge-based evaluation can be replaced by downstream behavioral validation in deployed applications.

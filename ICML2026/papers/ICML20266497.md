## Problem

Agent security is currently defined and evaluated through action content: benchmarks ask whether an agent performs a harmful-sounding action, and defenses ask whether an instruction looks malicious. The paper argues this content-based framing systematically misdefines the problem, because the same surface action (e.g., deleting data, transferring funds) is legitimate when issued by an authorized user in a sanctioned task and a critical breach when injected by an untrusted source, and no amount of content analysis can distinguish the two. The gap is the absence of a contextual authorization framework that decomposes agent security into independently verifiable properties.

## Input / Output

The framework consumes the full agent trajectory rather than individual actions: the provenance of each command (authenticated user, system process, external document, tool response), the authorized task specification, the sequence of actions taken, and the information flows across sessions and privilege boundaries. It produces a four-dimensional authorization verdict (pass/fail for Source Authorization, Task Alignment, Action Alignment, and Data Isolation) at every action step, plus a violation classification identifying which specific property was crossed and whether the violation cascaded into subsequent properties. Unlike snapshot benchmarks that reset context between tasks, the evaluation is continuous and trajectory-spanning, making temporal violations like memory poisoning visible.

## Method

The paper proposes a four-property decomposition of agent security—Source Authorization (who issued the command), Task Alignment (whether the governing objective is sanctioned), Action Alignment (whether each individual action serves that objective), and Data Isolation (whether information flows respect privilege boundaries)—that must hold jointly and be checked at every action step across the trajectory. The key insight is that these properties map directly to classical systems security concepts (confused deputy, information flow control, reference monitor, least privilege) that the agent security literature has not adopted, and that existing attacks reclassify cleanly under this decomposition: indirect prompt injection becomes a Source Authorization violation, direct prompt injection and jailbreaking become Task Alignment violations, task drift and agentic misalignment are Task Alignment violations, capability misuse is an Action Alignment violation, and memory poisoning is a cascading Data Isolation-to-Source Authorization violation. The framework also reorganizes existing defenses (PIGuard, PromptArmor, dual LLM separation, action allowlists, RAG permission scoping) around the property they actually approximate, identifies which properties lack any deployed defense, and argues that property-level checks expose a tunable granularity frontier absent from binary content filtering.

## Results

The paper's central empirical finding is that 100% of the 45 injection tasks across AgentDojo and WASP admit at least one plausible legitimate scenario in which the identical action would be a routine request from an authenticated user, demonstrating that the conflation between authorized behavior and security violation is a structural property of content-based evaluation. The paper further argues that snapshot benchmarks, which reset context between tasks, are structurally incapable of evaluating Data Isolation violations (e.g., memory poisoning, cross-session credential leakage) by construction. No quantitative defense comparison is presented; instead, the contribution is a reframing that reorganizes existing defenses (PIGuard, PromptArmor, dual LLM separation, tool allowlists, memory isolation) around the single property each actually approximates, and identifies which properties remain unverified by any current defense.

## Baselines & Comparisons

As a position paper, this work does not run head-to-head quantitative comparisons between defense methods. Instead, it recharacterizes each existing defense around the property it approximates and identifies structural gaps. PIGuard and PromptArmor (content-based prompt injection classifiers) are shown to target Source Authorization through content, which the paper argues is the wrong axis—whether a source is authenticated cannot be recovered from text alone, explaining PIGuard's near-random performance on benign prompts with adversarial trigger words. Dual LLM separation (Debenedetti et al., 2025) is identified as the closest existing approximation to Source Authorization by routing untrusted content through a privilege boundary. Tool restrictions and action allowlists are reframed as static Action Alignment checks that collapse when the operator cannot enumerate every action–task pairing. Memory isolation and RAG permission scoping approximate Data Isolation but do not extend across sessions or task transitions. The paper's key comparative claim is that no existing defense verifies all four properties simultaneously and continuously, and that content-based defenses have a structural ceiling that contextual defenses do not, because the authorization question cannot be resolved from action content alone.

## Relation to Prior Work

This position paper departs from the dominant content-based framing of agent security (exemplified by benchmarks like AgentDojo and WASP, and defenses like PIGuard and PromptArmor) by recasting the problem through four authorization properties drawn directly from classical systems security: the confused deputy problem (Hardy, 1988), information flow control (Denning, 1976), the reference monitor (Anderson, 1972), and least privilege (Saltzer & Schroeder, 1975). Rather than proposing a new defense or benchmark, it reorganizes existing defenses (dual-LLM separation, tool allowlists, RAG permission scoping) around the property each actually approximates, and reclassifies familiar attack patterns (indirect prompt injection, task drift, memory poisoning) by which property they violate. The paper's empirical anchor is a manual analysis showing all 45 injection tasks in AgentDojo and WASP admit at least one plausible legitimate context, demonstrating that the content-based conflation is structural rather than incidental.

## Why It Matters / Open Questions

The reframing provides a unifying taxonomy that makes explicit which property each defense targets and which evaluation gaps are structural (e.g., snapshot benchmarks cannot test Data Isolation by construction), giving the field a shared vocabulary for identifying missing defenses and misaligned benchmarks. It also offers testable predicates for emerging AI security standards, where each property names a specific authorization question an organization must answer. Key open questions remain: how to implement continuous per-step property checking at scale, how to track provenance through neural execution without rereading every record, and how to make Action Alignment checks dynamic rather than static allowlists. As a position paper with no new methods or large-scale experiments, its impact depends on whether the community adopts the four-property decomposition as the definitional core of agent security.

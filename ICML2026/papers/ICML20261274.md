## Problem

Existing distributionally robust RL (DR-RL) methods require strong data-access assumptions (generative models, large offline datasets, or hybrid regimes) and are largely confined to tabular state-action spaces, making them inapplicable to large-scale online settings where the agent must learn robustly from interaction alone. This paper asks whether a purely online DR-RL algorithm with general function approximation can achieve sample-efficient regret guarantees without coverage or concentrability assumptions.

## Input / Output

The agent interacts only with the nominal environment P* (observing state-action-reward-next-state tuples) while optimizing worst-case performance over a φ-divergence uncertainty ball of radius σ centered at P*. The method requires specifying a value function class F (e.g., neural networks mapping S×A→[0,H]) and a dual function class G (mapping S×A→Θ_φ for the dual variables η,ν), and outputs a robust policy π that maximizes the worst-case value V^{π,σ}. Unlike tabular UCB methods that assign per-state-action bonuses, RFL-φ constructs a single global confidence set in function space, making the output a policy induced by the optimistic value function f* ∈ F^{(k)} rather than a table of Q-values with individual confidence intervals.

## Method

RFL-φ replaces the pointwise robust Bellman backup with a functional optimization: the φ-divergence support function is expressed via its convex-conjugate dual (eq. 9), and the per-(s,a) scalar optimization is lifted to a single empirical dual loss minimized over a function class G. The algorithm jointly learns a value function f and a dual function g=(g_η,g_ν) by minimizing a squared robust Bellman residual L_D(f', f, g) that simultaneously approximates the worst-case Bellman operator and serves as a global uncertainty quantifier. Exploration is driven by optimism over a global confidence set F^{(k)} containing all functions whose empirical dual residual is within a tolerance β of the best, rather than per-state-action bonuses. The theoretical analysis introduces the robust Bellman-Eluder (BE) dimension—the distributional Eluder dimension of the robust Bellman residual class (I−T_h^{φ,σ})F under on-policy distributions—as the intrinsic complexity measure, yielding a sublinear regret bound O~(√(d·H²·B_φ²(σ)·K)) that is independent of |S| and |A| and recovers near-optimal rates in tabular and linear RMDP specializations.

## Results

The paper establishes the first regret guarantee for purely online DR-RL with general function approximation: Regret(K) = Õ(√(d·H²·B_φ²(σ)·K) + ε^dual), where d is the robust Bellman-Eluder dimension and the bound is independent of |S| and |A|. Specializing to tabular RMDPs, the sample complexity for χ²-divergence is Õ(H⁵(1+√σ)²S²A²ε⁻²), improving the prior Õ(C_vr·H⁵(1+√σ)²S³Aε⁻²) of He et al. (2025) by reducing the state-space dependence from S³A to S²A². Empirically on CartPole-v1 (H=500), RFL-TV achieves consistently higher undiscounted returns than the tabular OPROVI-TV baseline across all three perturbation types (action, force-magnitude, pole-length), degrading more slowly under large perturbations, with only ≈1.5× runtime overhead relative to DQN.

## Baselines & Comparisons

The primary empirical baseline is OPROVI-TV (Lu et al., 2024), an online tabular TV-RMDP method that discretizes the state space. On CartPole-v1, RFL-TV (neural function approximation) outperforms OPROVI-TV across all three perturbation families—action perturbation, force-magnitude scaling, and pole-length scaling—achieving consistently higher average returns and degrading more slowly as perturbation strength increases, demonstrating that function approximation scales better than tabular methods at large state spaces. Theoretically, in the tabular χ² setting, RFL-φ reduces the state-space dependence from S³A (He et al., 2025, with a variance-ratio factor C_vr) to S²A², yielding a tighter bound. In the linear TV setting, RFL-φ matches the optimal d_lin and min{H,1/σ} dependencies of Liu et al. (2024) but incurs a higher H⁵ vs. H³ dependence, which the authors attribute to the need for general function approximation rather than linear-specific structure. Compared to the hybrid method of Panaganti et al. (2024), RFL-φ achieves a tighter sample complexity (d_lin² vs. d_lin³, no offline coverage factor C(π*), no regularization parameter λ) while operating in a purely online setting with no pre-collected data.

## Relation to Prior Work

This paper extends the dual functional-optimization machinery for robust Bellman backups developed in offline (Panaganti et al., 2022) and hybrid offline-online (Panaganti et al., 2024) DR-RL to the purely online setting, where data distributions evolve with the policy. It also adapts the Bellman-Eluder dimension framework from non-robust online RL (Jin et al., 2021) to the robust case by defining a robust BE dimension over the robust Bellman residual class. The key departure from prior work is that the dual function serves a dual role—approximating the worst-case Bellman operator and simultaneously acting as a global uncertainty quantifier for exploration—whereas in offline DR-RL the dual is analyzed under a fixed dataset and does not guide exploration. This positions the paper as the first to unify online exploration, general function approximation, and φ-divergence robustness under a single intrinsic complexity measure.

## Why It Matters / Open Questions

The paper provides the first regret guarantee for purely online DR-RL with general function approximation, independent of |S| and |A|, which is a necessary step toward scalable robust RL in high-dimensional or continuous domains. The robust BE dimension offers a clean, model-based complexity measure that avoids coverage or concentrability assumptions, paralleling the role of BE dimension in non-robust RL. Limitations include the strong completeness assumption (closure under the robust Bellman operator), suboptimal H-dependence in the linear RMDP specialization, and empirical validation restricted to a single low-dimensional environment (CartPole). Open questions include whether the robust BE dimension is tight in general, whether the framework extends to continuous action spaces, and whether the completeness assumption can be relaxed to realizability alone.

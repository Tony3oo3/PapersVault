## Problem

Softmax attention's quadratic O(N²D) cost makes long-context pretraining (e.g., 64k tokens over entire code repositories or document collections) prohibitively expensive, forcing models to train on artificially truncated sequences. Existing efficient attention methods either restrict attention to fixed spatial subsets (losing semantic relevance) or apply monopole approximations only at inference time with key clustering alone, leaving a gap for a training-time approximation that preserves quality while enabling substantial throughput gains without architectural changes.

## Input / Output

MuSe consumes standard query, key, and value tensors of length N (64k tokens) with head dimension 64 or 128, partitioned into spatial blocks of size B (e.g., 8k tokens yielding 8 blocks). It produces an approximate attention output of the same shape as exact attention, computed as a logsumexp-weighted merge of four components: approximate attention over non-retrieved clusters, approximate attention over non-retrieved blocks within retrieved clusters, exact flash attention over retrieved (cluster, block) pairs, and exact causal attention within the current block. The output is directly interchangeable with exact attention at inference time—no architectural modification is required, and pretrained models (Llama 3.1-8B, 3.2-1B) can use MuSe as a drop-in replacement.

## Method

MuSe clusters queries and keys independently via streaming K-means in their learned representation spaces, decomposing each as centroid plus residual. It then computes query-specific cluster summaries by attending from each query centroid to all keys in a (key cluster, spatial block) pair, producing exponentially tilted centroids that capture attention-weighted statistics (mean key, mean value, log attention mass). These summaries are causally accumulated across spatial blocks so each block sees only prior context. A two-level retrieval mechanism selects the top-k₁ key clusters (by estimated log attention mass) and then top-k₂ spatial blocks within each, computing exact flash attention only on those (cluster, block) pairs. The key insight is that separate query clustering retains three of four terms in the exponential expansion exp(q·k) ≈ exp(q̄·k̄ + q̄·k̃ + q̃·k̄), dropping only the residual cross-term q̃·k̃, which yields a ~9× effective cluster count advantage over key-only clustering and reduces monopole error by 3.7–5.6×. Exponential tilting by query centroids is essential for drop-in compatibility with pretrained models, as it accounts for non-trivial mean query values that would otherwise cause catastrophic approximation failure.

## Results

On 1B-parameter pretraining at 64k context, MuSe matches or beats the CUDNN Flash Attention baseline on both code (0.7001 vs 0.7026 cross-entropy) and scientific PDFs (1.6166 vs 1.6201), while achieving a 36% wall-clock throughput improvement (88.9 vs 65.3 KTok/s). On isolated attention layers, MuSe delivers a 2× speedup over CUDNN Flash Attention (114.1 ms vs 225.6 ms) with only 0.006 relative squared error. Query clustering provides a ~9× effective cluster count advantage over key-only clustering, reducing monopole approximation error by 3.7–5.6×.

## Baselines & Comparisons

Against CUDNN Flash Attention (the exact-attention baseline), MuSe matches or slightly beats pretraining loss on both domains (0.7001 vs 0.7026 on code; 1.6166 vs 1.6201 on PDFs) while delivering a 36% throughput gain, and achieves a 2× speedup on isolated attention layers with <1% approximation error. Against MoBA (mixture-of-blocks attention without semantic clustering), MuSe achieves 40× lower far-field approximation error (0.006 vs 0.248 RSE at matched sparsity) and substantially better pretraining loss at both 185M (0.9384 vs 0.9714) and 560M (0.7728 vs 0.7958) scales, demonstrating that semantic clustering—not just sparsity—is critical for approximation quality. MuSe is the only method that beats the exact CUDNN baseline at both tested scales, while MoBA degrades by 3–4% in loss. On long-context retrieval (custom code NIAH at 64k), MuSe-trained models match or exceed exact-attention models on every variant (e.g., 98.46% vs 92.73% on multi-key 2×), and on LongBench code completion both methods are within standard error of each other.

## Relation to Prior Work

MuSe extends the Fast Multipole Method analogy to attention by combining semantic (k-means) clustering of both queries and keys with exponential tilting, departing from prior multipole-attention work (Hooper et al., 2025a) that clusters keys only and targets inference. It also contrasts with spatially-blocked methods like MoBA (Lu et al., 2025), which use fixed block structure without semantic clustering, and with earlier approximate-attention approaches (Performer, Nyströmformer, Reformer) that rely on random projections or low-rank factorization rather than data-dependent clustering. The key conceptual departure is clustering queries in their own representation space to produce query-specific summaries, which the authors argue is essential because softmax attention is invariant to key-space basis changes but not to query-space changes, making a shared latent space ill-defined.

## Why It Matters / Open Questions

The 36% wall-clock speedup at 64k context with matched or better loss, combined with drop-in compatibility with pretrained Llama models (no retraining needed), makes MuSe a practical tool for long-context pretraining that is currently bottlenecked by quadratic attention. The finding that the approximation can act as a beneficial regularizer (beating exact attention by 0.2–0.4% at 1B scale) is intriguing but unexplained and may not persist at larger scales. Key open questions include whether the speedup and quality preservation hold at 7B+ parameter scale and beyond 64k context, whether the regularization effect is genuine or an artifact of small-scale training, and whether further kernel optimization (the current Pallas implementation is acknowledged as unoptimized) can close the gap to the theoretical 64× far-field sparsity.

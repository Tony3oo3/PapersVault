## Problem

Existing multimodal retrieval systems measure query-image relevance in isolation, scoring each candidate independently without considering other images in the corpus. This paradigm fails for realistic personal photo search where the target image lacks distinctive visual features and can only be identified through contextual cues (events, companions, temporal sequences) distributed across other images in the collection. No prior benchmark evaluates this corpus-level contextual reasoning capability.

## Input / Output

The system receives a text-only natural language query and a user's chronological visual history of ~2,000 photos (each with RGB content, timestamps, and GPS coordinates), organized into photosets that correspond to events but are invisible to the model. The output is the complete set of photo IDs satisfying the query (set retrieval, not ranking), with no prior knowledge of the expected count. Queries are deliberately text-only even when referencing visual elements, forcing the model to first locate visual anchors within the corpus before performing spatiotemporal reasoning.

## Method

DeepImageSearch reformulates image retrieval as an agentic exploration task where models must autonomously plan search trajectories, coordinate fine-grained perception tools, and chain scattered visual evidence across the corpus. DISBench is constructed via a semi-automated pipeline: VLMs parse images to extract visual cues and person identities, a retrieval-verification strategy mines latent cross-image associations, these are organized into a heterogeneous memory graph (Photo, Photoset, Visual Clue, Person nodes with structural and association edges), and subgraph sampling with balanced edge-type expansion yields candidate queries that humans verify at a 6.1% retention rate. The ImageSeeker baseline agent provides five tools (ImageSearch, GetMetadata, FilterMetadata, ViewPhotos, WebSearch) with explicit state memory via named photo subsets and a three-tier compressed context memory (global goals, local subgoals, tool-use failure summaries) to support long-horizon navigation under 128K token limits.

## Results

On DISBench, the best-performing model (Claude-Opus-4.5 with Qwen3-VL-Embedding-8B) achieves an Exact Match of 28.7 and F1 of 55.0, indicating that even state-of-the-art multimodal agents struggle to identify complete target sets. Inter-Event queries are substantially harder than Intra-Event queries for strong models (e.g., Claude-Opus-4.5: 23.1 vs. 35.1 EM), while weaker models show minimal differentiation between the two types. Direct embedding-based retrieval performs far worse, with Recall@3 of only 10.8–13.6% and NDCG@5 of 13.8–17.5%, confirming that independent semantic matching is fundamentally insufficient for context-dependent queries.

## Baselines & Comparisons

Among closed-source models, Claude-Opus-4.5 dominates all others, achieving 28.7 EM / 55.0 F1 overall, outperforming Gemini-3-Pro-Preview (24.6 / 47.9) by 4.1 EM points and Claude-Sonnet-4.5 (22.1 / 43.8) by 6.6 EM points. GPT-5.2 (13.1 / 30.0) and GPT-4o (5.7 / 21.8) trail significantly, with GPT-4o being the weakest closed-source model. Among open-source models, Qwen3-VL-235B-Instruct leads at 11.5 EM / 27.2 F1, but all open-source models remain 17+ EM points below the best closed-source model, highlighting a substantial capability gap. The direct retrieval baselines (Qwen3-VL-Embedding-2B/8B, Seed-1.6-Embedding) achieve Recall@3 of only 10.8–13.6% and NDCG@10 of 19.1–20.9%, confirming that the independent-matching paradigm cannot resolve context-dependent queries regardless of embedding quality. Test-time scaling (Best@k with N parallel runs) lifts Gemini-3-Flash-Preview from 35.4 to 60.8 F1, suggesting latent reasoning capacity that single-pass evaluation underestimates.

## Relation to Prior Work

This paper departs from the dominant independent-matching paradigm in multimodal retrieval (CLIP, DINOv2, and their successors) and from recent reasoning-intensive or agentic retrieval approaches that decompose queries but still score each candidate image in isolation. It also distinguishes itself from existing multimodal agent benchmarks (web search, GUI manipulation, embodied tasks) by identifying image retrieval as a setting where agentic exploration is not auxiliary but essential, since targets are visually ambiguous and identifiable only through cross-image contextual chains. The methodological lineage draws on vision-language models for semantic parsing, face clustering for identity tracking, and graph-based subgraph sampling for query synthesis, but the core contribution is the task reformulation rather than any single technique.

## Why It Matters / Open Questions

DISBench exposes a concrete and measurable capability gap: even the strongest model (Claude-Opus-4.5) achieves only 28.7 EM, and error analysis shows that reasoning breakdown (losing track of multi-step plans) dominates over visual perception failures, pointing to a specific and addressable weakness in current agents. The test-time scaling result—Best@k jumping from 35.4 to 60.8 while Majority Voting lags—suggests models possess latent capability but lack reliable path-selection mechanisms, framing a clear research direction. Limitations include the small query count (122), single data source (YFCC100M), and dependence on metadata availability, but the semi-automated construction pipeline is dataset-agnostic and reusable, and the benchmark is likely to become a standard testbed for agentic retrieval research.

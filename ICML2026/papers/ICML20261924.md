## Problem

Differentially private regression with public (non-sensitive) features remains underexplored: most label-DP work targets classification, and the few regression methods either ignore public feature structure or rely on noisy label privatization that degrades sharply at high privacy. The paper asks whether the spectral structure of public feature matrices can be exploited to improve utility under approximate DP without incurring additional privacy cost.
![Teaser figure](../imgs/ICML20261924/cropped_page1_idx0.webp)

## Input / Output

Each training sample consists of a public feature vector x^pub ∈ R^{d_pub}, a private feature vector x^priv ∈ R^{d_priv} (which may be absent in the pure label-DP setting), and a bounded scalar label y. The model produces a scalar prediction via a linear embedding layer (separate for public and private features) followed by an optional non-linear prediction head (MLP or factorization machine). The conditioning matrix C ∈ R^{d_pub × d_pub} is computed offline from the public feature matrix alone via its SVD, so it is a fixed hyperparameter that adds no privacy cost; the final output is the averaged model parameters over T iterations.

## Method

Cond-DP modifies the public embedding computation from v^pub = Θ^pub x^pub to v^pub = Θ^pub C x^pub, where C is a conditioning matrix (typically C = VΣ^{-1}V^T from the SVD of the public feature matrix) that rescales the parameter space to amplify low-singular-value directions. The conditioned model is then trained with standard DPSGD, and the paper proves that this yields tighter convergence bounds than unconditioned DPSGD for convex, strongly convex, and non-convex objectives, with a provable improvement in private linear regression. For non-linear models where conditioning can hinder late-stage optimization, Switch-Cond-DP applies the conditioning matrix for an initial phase and then switches to plain DPSGD. The key insight is that public feature matrices often exhibit rapidly decaying spectra, and isotropic Gaussian noise in DPSGD gives poor signal-to-noise ratio along low-spectrum directions; the conditioning matrix corrects this anisotropy without changing the privacy budget.

## Results

The paper reports validation MSE across privacy budgets ε ∈ {0.25, 0.5, 1, 2, 4, ∞} on eight datasets. On synthetic data with rapidly decaying spectra (p=1), Cond-DP achieves the lowest MSE across all ε values, with the performance gap over DPSGD and RR-on-Bins widening as spectral decay increases; when spectra are uniform (p=0), Cond-DP matches DPSGD. On the Criteo Sponsored Search Conversion benchmark (1.38M training samples, 4003 features), Cond-DP for linear models shows the largest gains over DPSGD for ε ∈ (0.5, 2], and Switch-Cond-DP for MLP models achieves lower MSE than both DPSGD and RR-on-Bins for ε < 4. Results are presented as MSE-vs-epoch curves (Figures 4, 6, 7, 8) rather than a single summary table.

## Baselines & Comparisons

Cond-DP consistently outperforms DPSGD (Abadi et al., 2016) across all datasets, with the largest gains in high-privacy regimes (ε ≤ 1) and when public feature spectra decay rapidly; on synthetic data with uniform spectra (p=0), the two methods perform comparably, confirming that the conditioning benefit is tied to spectral structure. Against RR-on-Bins (Ghazi et al., 2023), the state-of-the-art label-DP regression method, Cond-DP and Switch-Cond-DP achieve substantially lower MSE in high-privacy regimes (ε ≤ 2) on both linear and MLP models; on Criteo, Cond-DP outperforms RR-on-Bins across most privacy budgets except ε=4, where RR-on-Bins is slightly better for linear models. Weighted-LLP (Brahmbhatt et al., 2023) is evaluated but omitted from the main text due to consistently inferior performance and limited applicability to the tested settings. The theoretical guarantee (Lemma 4.13) shows that for private linear regression under label DP, Cond-DP with C = VΣ⁻¹Vᵀ provably achieves a tighter excess-risk bound than DPSGD, with the improvement ratio maximized when the label aligns with the smallest singular direction of the public feature matrix.

## Relation to Prior Work

This paper extends DPSGD (Abadi et al., 2016) by introducing a conditioning matrix derived from the singular value decomposition of the public feature matrix, reshaping the optimization geometry to improve the signal-to-noise ratio in low-spectral directions. It departs from prior label-DP regression work (Ghazi et al., 2023; Brahmbhatt et al., 2023) that either ignores public features entirely or uses them for label privatization via Randomized Response, and from semi-sensitive feature approaches (Krichene et al., 2023; Chua et al., 2024b) that either restrict model architecture or split the privacy budget. The key conceptual departure is leveraging unsupervised spectral structure of public features to condition the parameter space, incurring no additional privacy cost.

## Why It Matters / Open Questions

The paper provides the first provable utility improvement over DPSGD for private regression using public features, with clean convergence guarantees across convex, strongly convex, and non-convex settings. The Switch-Cond-DP hybrid addresses the practical limitation that conditioning can hinder late-stage training for non-linear models, though the switching epoch remains a heuristic hyperparameter. Open questions include whether the conditioning strategy can be made effective throughout training for complex architectures, whether it extends to other privacy notions beyond label/semi-sensitive DP, and whether the SVD-based construction scales efficiently to very high-dimensional sparse feature spaces (as in the Criteo setting, where it was repurposed as initialization rather than a true conditioning factor).

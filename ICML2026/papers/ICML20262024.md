## Problem

Byte-level language models like BLT match subword model quality but suffer from a memory-bandwidth bottleneck at inference: standard autoregressive decoding generates one byte per forward pass, requiring multiple decoder calls to produce the text equivalent of a single subword token. Existing diffusion language models generate tokens in parallel but are not designed for byte-level architectures with dynamically constructed variable-length patches and hierarchical latent token representations.
![Teaser figure](../imgs/ICML20262024/cropped_page1_idx0.webp)

## Input / Output

The model takes a raw byte sequence prefix (over a 256-byte vocabulary, no subword tokenization) and produces a generated byte sequence. During diffusion-based generation, the decoder receives a fixed-size block of B masked positions appended to the clean prefix and iteratively unmasks multiple byte positions per step, conditioned on the last latent token representation. The same model can also compute sequence likelihoods by switching the decoder to a causal mask, enabling both generation and scoring from a single set of parameters.

## Method

BLT-D augments BLT's local decoder with a block-wise absorbing discrete diffusion objective: during training, the decoder receives both a clean byte sequence (for standard next-byte prediction loss) and corrupted fixed-length blocks constructed from dynamically segmented patches (for masked-byte reconstruction loss with 1/t weighting). At inference, the decoder initializes a block of [MASK] tokens and uses bidirectional self-attention within the block (causal for the clean prefix) to unmask multiple positions per forward pass via confidence-based thresholding or entropy-bounded sampling, reducing decoder, encoder, and global model calls. Two speculative-decoding-inspired extensions require no architectural changes: BLT-S lets BLT's decoder draft k bytes beyond normal patch boundaries before a full-model verification pass, and BLT-DV verifies diffusion-drafted blocks using the model's own autoregressive next-byte predictions, guaranteeing identical outputs to standard autoregressive decoding.

## Results

On 3B-parameter models, BLT-D-4 (block size 4, confidence threshold α=0.7) achieves 38.09 BLEU on Fr→En translation (vs. 40.72 for BLT) while reducing memory bandwidth by 58.5% (797.6 GB vs. 1921.0 GB). BLT-D-16 achieves the largest efficiency gain—87.8% memory bandwidth reduction (233.9 GB)—at the cost of lower coding-task performance. BLT-S (self-speculation, k=8) matches BLT's task scores exactly (40.72 BLEU) while cutting memory bandwidth by 51.7%, and BLT-DV-8 recovers most of the diffusion quality loss (38.66 BLEU) while still achieving 58.5% memory reduction. On likelihood-based benchmarks, BLT-D-4 3B scores within 1–4 points of BLT 3B (e.g., 72.39 vs. 74.33 on ARC-Easy; 39.07 vs. 41.15 on MMLU).

## Baselines & Comparisons

The sole baseline is the original BLT (Pagnoni et al., 2025), against which all proposed variants are compared. On generation efficiency, every BLT-D, BLT-S, and BLT-DV configuration strictly outperforms BLT in both decoder and encoder/global NFEs and memory bandwidth. BLT-S (k=8) achieves identical task scores to BLT (e.g., 40.72 BLEU Fr→En, 12.80 pass@1 HumanEval) while reducing memory bandwidth by ~52%, confirming that self-speculation is lossless by construction. BLT-D-4 nearly matches BLT on translation (38.09 vs. 40.72 BLEU) with a 58% memory reduction, but shows a larger gap on coding tasks (e.g., ~9.8 vs. ~12.8 pass@1 on HumanEval for 1B). BLT-D-16 achieves the largest speedup (87–92% memory reduction) but suffers the most quality degradation, particularly on code generation. BLT-DV partially closes the quality gap of BLT-D (e.g., 38.66 vs. 37.09 BLEU for Fr→En at block size 8) at the cost of additional verification forward passes, resulting in higher global NFEs than diffusion-only BLT-D. On likelihood-based tasks, BLT-D-4 remains within 1–4 points of BLT, while BLT-D-16 drops by 4–7 points, indicating that larger diffusion blocks trade off autoregressive calibration.

## Relation to Prior Work

This paper extends the Byte Latent Transformer (BLT) by integrating block-wise absorbing discrete diffusion into its local decoder, adapting the semi-autoregressive diffusion framework from masked diffusion LMs (Sahoo et al., 2024; Arriola et al., 2025) to a hierarchical architecture where latent tokens are dynamically constructed from variable-length entropy-based patches. The speculative decoding extensions (BLT-S, BLT-DV) depart from prior work by using the model's own lightweight decoder as the drafter rather than a separate draft model or additional speculative heads (Leviathan et al., 2023; Zhang et al., 2024; Cai et al., 2024), exploiting BLT's existing encoder-decoder decomposition. The key conceptual departure is that diffusion blocks can span multiple patches, enabling the decoder to predict bytes well beyond BLT's average patch size of four.

## Why It Matters / Open Questions

This work addresses the primary practical barrier to deploying byte-level LMs—their slow byte-by-byte autoregressive generation—achieving 50–92% estimated memory-bandwidth reduction while offering a quality-speed dial via block size and verification. The lossless speedup from BLT-S and the quality recovery from BLT-DV's verification step make these methods immediately useful for latency-sensitive applications. Key open questions include whether the NFE-based efficiency estimates translate to wall-clock speedups under optimized inference (the authors acknowledge this limitation), how the approach scales to larger models and longer contexts, and whether the diffusion-AR objective balance can be further tuned to close the remaining quality gap at large block sizes on structured tasks like code generation.

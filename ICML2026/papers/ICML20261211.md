## Problem

Existing instruction-following embedding methods rely solely on the last input token's hidden state, capturing only Input-Intrinsic semantics while missing Output-Aware semantics distributed across output tokens. Alternative approaches that re-encode generated outputs introduce a semantic reconstruction gap through discrete-to-continuous conversion, and incur additional decoding latency. The paper seeks to capture both semantic types within the LLM's latent space in a single prefilling step without multi-step decoding.

## Input / Output

The model takes an input text concatenated with a natural-language instruction, followed by L learnable look-ahead tokens (default L=8) appended to the sequence. At inference, only a single forward pass (prefilling) is required—no autoregressive decoding—producing a single dense embedding vector via DAAP pooling. The look-ahead tokens act as a suffix soft prompt that implicitly previews future output semantics, so the embedding encodes both what the input says and what a well-formed response would convey.

## Method

InstEmb appends learnable look-ahead tokens to the input and trains them via isomorphic representation self-distillation: a frozen teacher (same architecture) processes the input plus the first L tokens of the gold output, while the student processes the input plus look-ahead tokens; position-wise MSE or KL loss aligns the student's look-ahead hidden states with the teacher's output-conditioned hidden states. Simultaneously, a multi-view InfoNCE contrastive loss at the last input token position optimizes Input-Intrinsic semantics using four views per instance (two dropout-augmented student input views, one frozen-teacher input view, and one student output view). At inference, Dual-Anchor Alignment Pooling (DAAP) fuses the two optimized signals by averaging the last input token's hidden state with the mean of the look-ahead tokens' hidden states, ensuring the pooling strategy is explicitly aligned with the dual training objectives rather than selected empirically.

## Results

On the FollowIR benchmark, InstEmb (Llama-3-8B-Instruct) achieves a mean score of 28.5 with +15.6 p-MRR, surpassing the previous SOTA FollowIR-7B (24.8 / +12.2) and Promptriever (26.1 / +11.2) without any benchmark-specific supervised training. On InfoSearch, InstEmb attains 20.1 SICR, 13.3 WISE, and 7.7 p-MRR, outperforming the base Llama-3-8B-Instruct (6.6 p-MRR) and FollowIR-7B (4.1 p-MRR). On instruction-following embedding tasks (Inst.STSb, IntentEmotion, NYTCluster), InstEmb-MSE-DAAP reaches a mean of 67.08%, improving over Inbedder (59.9%) and the base Llama-3-8B-Instruct InputLast (54.2%). On generic MTEB sentence embedding tasks, InstEmb-KL-DAAP achieves 63.39% mean with 7× less training data than LLM2Vec and ECHO.

## Baselines & Comparisons

InstEmb decisively outperforms all instruction-adaptive baselines on FollowIR: it beats FollowIR-7B by +3.7 mean score and +3.4 p-MRR, and Promptriever by +2.4 score and +4.4 p-MRR, notably without any FollowIR-specific training data. On InfoSearch, InstEmb's 7.7 p-MRR surpasses FollowIR-7B (4.1) and the base Llama-3-8B-Instruct (6.6), while Mistral-7B-instruct and GritLM-Reranker produce negative p-MRR values, indicating instruction contradiction. On instruction-following embedding tasks (Table 2), InstEmb-MSE-DAAP (67.08% mean) outperforms Inbedder (59.9%), PonTE (60.71%), and the base Llama-3-8B InputLast (54.2%), with the largest gap over fixed-instruction models like e5-large-v2 (26.77%) and Instructor-large (27.63%). On generic MTEB tasks, InstEmb-KL-DAAP (63.39%) slightly edges out ECHO-mistral (63.16%) and LLM2Vec (62.30%) while using 7× less training data, and marginally beats Inbedder (61.52%). The method also generalizes across backbones: on Qwen2.5-7B-Instruct, InstEmb improves instruction-following from 66.14% to 67.70% and generic from 55.46% to 58.73%, and a 14B teacher further lifts instruction-following to 68.75%.

## Relation to Prior Work

InstEmb extends the instruction-following embedding line (Inbedder, FollowIR, Promptriever) by addressing two specific limitations: last-token pooling conflates input and output semantics, and discrete-to-continuous re-encoding of generated text introduces a semantic reconstruction gap. The key conceptual departure is borrowing the look-ahead token idea from speculative decoding and repurposing it as a learnable soft-prompt suffix, trained via isomorphic self-distillation from a frozen copy of the same model rather than from a separate teacher. The contrastive learning component draws on SimCSE-style dropout augmentation and multi-positive InfoNCE, while the DAAP pooling is explicitly derived from the dual training objectives rather than chosen empirically.

## Why It Matters / Open Questions

The framework offers a practical recipe for instruction-following embeddings that requires only a single prefilling pass at inference (no autoregressive decoding), making it attractive for latency-sensitive retrieval pipelines. The zero-shot FollowIR result (28.5 mean score vs. 24.8 for FollowIR-7B trained on FollowIR-specific data) suggests the self-distillation approach transfers instruction-following capability without benchmark-specific supervision. Open questions include whether the look-ahead token mechanism generalizes to non-QA training data with very long or structured outputs, how the method scales to much larger backbones (the 14B teacher experiment shows only marginal gains), and whether the MSE-vs-KL task specialization observed in ablations holds across more diverse evaluation settings.

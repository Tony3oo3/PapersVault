## Problem

Existing text-to-image diffusion models, even those equipped with LLM-based text encoders, treat the LLM as a frozen feature extractor and function as literal text-pixel mappers. They handle descriptive prompts well but fail on conceptual instructions that require world knowledge and reasoning (e.g., interpreting idioms, illustrating scientific processes, or inferring implied visual outcomes), because no mechanism incentivizes the LLM to reason about and rewrite the prompt before feeding it to the diffusion backbone.
![Teaser figure](../imgs/ICML20262212/cropped_page0_idx0.webp)

## Input / Output

For text-to-image generation, the method takes a raw user text prompt; for image editing, it takes a reference image plus a text instruction. Internally, the LLM encoder first produces a chain-of-thought reasoning trace (~200 tokens on average) followed by a refined descriptive prompt, and the last-layer hidden states of that refined prompt condition the DiT. The DiT generates images over 10 inference steps with an SDE window of 2, producing standard RGB images as output.

## Method

The paper proposes the Think-Then-Generate (T2G) paradigm with a two-stage training pipeline. First, a lightweight SFT stage fine-tunes the LLM encoder (Qwen2.5-VL) on Gemini-2.5-generated data in the format raw prompt → CoT reasoning → refined prompt, activating the think-then-rewrite pattern while preserving the latent embedding space (verified via t-SNE). Second, a Dual-GRPO stage jointly optimizes the LLM encoder and the DiT backbone using image-grounded rewards: the LLM is reinforced with a semantic-alignment reward (VLM-as-a-judge scoring image-prompt consistency, averaged over K generated images per reasoning trace), while the DiT is reinforced with aesthetic and physical-consistency rewards. Hierarchical sampling draws J reasoning traces from the LLM and K images per trace from the DiT; the LLM loss uses standard GRPO with group size J, and the DiT loss uses Flow-GRPO (converting the deterministic flow ODE to an SDE via Euler-Maruyama) with group size K and an extra batch dimension of size J, enabling end-to-end alignment between textual reasoning and visual rendering.

## Results

On the WISE benchmark for reasoning-centric text-to-image generation, the proposed T2G method achieves an overall score of 0.79, surpassing the pre-trained Qwen-Image baseline (0.61) by 30% and all open-source models (Uni-CoT 0.75, Bagel w/CoT 0.70), reaching near-parity with the proprietary GPT-4o (0.80). On T2I-ReasonBench, the method achieves 68.3% overall accuracy, outperforming the closed-source Gemini-2.0 (64.8%) and all open-source baselines. For image editing, the method scores 68.7 on UniREditBench (beating Gemini-2.5-Flash-Image at 68.3) and 23.9 on RISEBench, though it trails GPT-Image-1 (73.4 and 28.9 respectively) on these editing benchmarks.

## Baselines & Comparisons

On WISE, the T2G method (0.79) outperforms all open-source baselines by a wide margin—Uni-CoT (0.75), Bagel w/CoT (0.70), HunyuanImage-3.0 (0.58), T2I-R1 (0.54), FLUX.1-dev (0.50), SD-3.5-large (0.46), and Janus-Pro-7B (0.35)—and trails only GPT-4o (0.80) by 0.01. On T2I-ReasonBench, the method achieves 68.3% overall accuracy, surpassing the proprietary Gemini-2.0 (64.8%) and all open-source models (Uni-CoT 58.1%, Bagel 49.7%), but remains below GPT-4o (78.7%). For image editing on UniREditBench, the method (68.7) edges out Gemini-2.5-Flash-Image (68.3) and substantially outperforms Seedream-4.0 (55.8), Bagel w/CoT (51.0), and FLUX.1-Kontext (45.8), though it falls short of GPT-Image-1 (73.4). On the more challenging RISEBench, the method (23.9) loses to both Gemini-2.5-Flash-Image (32.8) and GPT-Image-1 (28.9), indicating that reasoning-aware editing remains an open challenge even for the proposed approach.

## Relation to Prior Work

This paper extends the GRPO reinforcement learning framework (Shao et al., 2024) and its flow-matching adaptation Flow-GRPO (Liu et al., 2025) by introducing Dual-GRPO, which jointly optimizes both the LLM text encoder and the DiT decoder with distinct, role-specific rewards. Prior work on reasoning-aware T2I (T2I-R1, Uni-CoT) incorporates CoT in unified autoregressive models, while Flow-GRPO and DanceGRPO optimize only the DiT with a frozen encoder. The key departure is treating the LLM encoder as an active reasoning agent that rewrites prompts before conditioning the DiT, rather than a passive feature extractor, and aligning both components end-to-end via image-grounded rewards on the Qwen-Image (Wu et al., 2025) architecture.

## Why It Matters / Open Questions

The T2G paradigm provides a general, plug-in recipe (lightweight SFT + Dual-GRPO) that can be applied to any existing LLM+DiT system to unlock reasoning capabilities without retraining from scratch, making it broadly applicable. Achieving near-GPT-4o performance (0.79 vs 0.80 on WISE) with an open-source model is practically significant for democratizing reasoning-aware visual generation. Open questions include whether the approach scales to more complex multi-step reasoning, whether the VLM-as-a-judge reward signal introduces biases, and whether the ~200-token CoT overhead is acceptable for real-time applications. The finding that SFT preserves the DiT-compatible latent space (t-SNE) is reassuring but may not hold for more aggressive fine-tuning regimes.

## Problem

Classical Q-learning fails in partially observable environments with deterministic observations (hard state aggregation) because the optimal value function is not constant within a feature, making the feature value ambiguous. Prior convergence guarantees for reactive policies under state aggregation require q*-realizability (the optimal action-value function must be constant within each feature), which excludes simple environments like the corridor. This paper asks whether a strictly weaker structural condition on the environment suffices for provable convergence to the optimal reactive policy.

## Input / Output

The agent receives only a deterministic feature observation z_t from a finite feature space Z (a partition of the underlying state space), never the true state x_t. The algorithm maintains a Q-table Q ∈ R^{Z'×Ω} indexed by features and a finite set of stochastic options Ω ⊂ Δ_U (distributions over actions). The output is a reactive policy π̂: Z → Ω mapping each feature to an option, extracted as the argmax over options in each row of the converged Q-table. The environment is a finite episodic POMDP with an absorbing terminal state, and all policies are assumed proper (episodes terminate almost surely).

## Method

Committed Q-learning modifies standard Q-learning with a single change: upon entering a feature, the behavior policy samples one option and commits to it for all subsequent steps within that feature, resampling only when the observed feature changes. The convergence proof introduces quasi-Markov environments (each feature has a unique entrance distribution, so the Markov property holds at feature boundaries) and shows that the committed update rule makes the Q-iterates converge to the optimal action-value function of a π-MDP — the aggregate MDP of a π-rewiring that replaces all entrances of each feature by the on-policy average entrance. The key theoretical contribution is rewire-robustness: if changing how a feature is entered (while preserving intra-feature dynamics) does not alter the optimal reactive policy, then the π-MDP optimum transfers back to the original environment. This condition is strictly weaker than q*-realizability, as demonstrated by the corridor and T-maze environments. The convergence analysis leverages the Liu et al. (2025) extension of the Borkar-Meyn ODE method to handle the Markovian (correlated) noise inherent in the committed sampling scheme.

## Results

The main result (Theorem 3.5) is a theoretical guarantee: Committed Q-learning converges almost surely to the optimal reactive policy in any rewire-robust environment, a condition strictly weaker than the q*-realizability assumed in all prior work. The single numerical experiment (Fig. 3) evaluates corridor environments of varying lengths (k = 2, 4, 8, 16) over 1000 random seeds, using ε-greedy behavior (ε₀=0.1, ε₁₀₀₀=0.01) and step sizes α₀=0.1, α₁₀₀₀=0.01. Committed Q-learning rapidly converges to the optimal policy across all corridor lengths, while regular Q-learning fails to make meaningful progress even on the shortest corridors. No standard benchmark metrics (accuracy, reward score) are reported; the evaluation is qualitative convergence behavior shown via learning curves with 95% bootstrap confidence intervals.

## Baselines & Comparisons

The paper compares Committed Q-learning against regular (non-committed) Q-learning in corridor environments (Fig. 1a) of increasing length. Committed Q-learning wins decisively: it converges to the optimal reactive policy (total reward 0, going right at every state) across all corridor lengths tested, while regular Q-learning fails to make progress even with very short corridors because the value of the aggregated feature is ambiguous (states within the feature have different true values). Theoretically, the paper also shows that rewire-robustness is strictly weaker than q*-realizability (the assumption required by Tsitsiklis & Van Roy 1996 and Majeed & Hutter 2018), meaning Committed Q-learning applies to a strictly larger class of environments. The corridor environment itself is not q*-realizable, so prior convergence guarantees do not apply, yet Committed Q-learning still converges. No head-to-head numerical comparison on shared benchmarks beyond the corridor experiment is provided.

## Relation to Prior Work

This paper extends the classical Q-learning algorithm (Watkins & Dayan, 1992) with a minimal 'commitment' mechanism—resampling an option only when the observed feature changes—and proves convergence under a new assumption (rewire-robustness) that is strictly weaker than the q*-realizability condition required by all prior work on RL with hard state aggregation (Tsitsiklis & Van Roy, 1996; Majeed & Hutter, 2018). The convergence proof builds on the Borkar-Meyn stochastic approximation framework (Borkar & Meyn, 2000) via its recent extension to Markovian noise (Liu et al., 2025), and introduces quasi-Markov environments and Bellman risk as new analytical tools that bridge the gap between the partially observable setting and standard MDP dynamic programming. The aggregate MDP construction with Bayesian disaggregation matrices follows Van Roy (2006), but is made concrete and algorithmically usable here through the π-rewiring.

## Why It Matters / Open Questions

This is the first convergence guarantee for an RL algorithm in POMDPs with deterministic observations under an assumption strictly weaker than q*-realizability, which is the standard (and often restrictive) condition in the literature. The corridor environment demonstrates a concrete, intuitive failure mode of standard Q-learning that Committed Q-learning resolves, and the T-maze connection shows the framework applies to classic partially observable benchmarks. Key open questions include: whether the theory extends to nonstationary/temporally-extended options, discounted or average-reward settings, and—most practically—how to define and exploit 'approximate' rewire-robustness when the condition only approximately holds, which would be needed for real-world applications.

## Problem

Return-based comparisons between memory models in deep RL are confounded by factors like parameter count, optimization difficulty, and representational capacity, making it impossible to isolate how much performance is attributable to memory versus other architectural choices. No prior benchmark provides both MDP/POMDP twins sharing a single observation and action space and GPU acceleration, which are jointly necessary for controlled counterfactual studies of observability. Additionally, no tools exist to directly inspect what memory models learn or how they allocate credit across a trajectory.

## Input / Output

All 120 environments (10 base tasks × 12 configurations) share a single pixel observation space (128×128×3 or 256×256×3) and a 5-action discrete space (up, down, left, right, fire), so one model architecture can be reused across every task and observability variant. The memory model consumes the full observation-action trajectory to produce a fixed-size latent Markov state, which the policy maps to actions. Beyond the standard policy output, the analysis tools produce four diagnostic quantities: the Observability Gap (return difference between MDP and POMDP twins), the Memory Bias (return difference between memory-endowed and memory-free policies on the MDP), the Recall Density (expected relative gradient contribution of each normalized timestep to the final Q value or policy), and per-pixel saliency maps showing which pixels from past observations influence current decisions.

## Method

POPGym Arcade introduces 10 Atari-inspired environments (Battleship, MineSweeper, Tetris, Navigator, etc.) each with MDP and POMDP twins that share identical underlying transition dynamics over a low-dimensional hidden state, differing only in the observation function; the pixel state space S is identical across all tasks, and the POMDP observation function O: S̃→Δ(Ω) selectively hides information (e.g., showing only the cursor cell in Battleship, or flickering blocks in Skittles). The paper proposes four memory analysis tools: the Observability Gap and Memory Bias decompose return into observability-attributable and confounder-attributable components, while Pixel Visualizations (L2-norm gradients of Q or π with respect to past observations) and the Recall Density (L1-norm gradient ratios normalized over the trajectory, averaged across episodes) quantify how memory allocates credit temporally. Training uses PQN (on-policy TD(λ) Q-learning without replay buffers or target networks) as the primary algorithm to minimize confounders, with PPO and DQN as secondary validations, across seven memory architectures (Transformer, Linear Transformer, TTTL, GDN, MinGRU, GRU, LRU) with a skip connection bypassing memory. The key empirical finding is a value smearing pathology: even in MDPs where the Markov property guarantees all credit belongs to the current state, gradient analysis reveals Q values are diffusely attributed across the entire trajectory, and this incorrect credit assignment causes recurrent state contamination, where a single OOD observation perturbs the policy far into the future.

## Results

Across 7 memory architectures evaluated on 10 MDP/POMDP twin environments (120 total configurations), the LRU state-space model achieves the best overall POMDP return. A key finding is that return alone is a confounded metric: GDN and MinGRU achieve nearly identical POMDP returns (0.469 vs. 0.471), yet GDN's Observability Gap is 0.090 smaller (better state recovery) while its Memory Bias is 0.091 more negative (stronger optimization penalty). Memory Bias is purely negative across all models, indicating a universal memory-induced performance penalty on fully observable tasks. The value smearing pathology—where Q-values incorrectly attribute credit to irrelevant past states—is observed across all models and all MDP tasks, with significant recall density in the first two-thirds of episodes (τ < 0.66) where the Markov property dictates zero influence.

## Baselines & Comparisons

The paper compares 7 memory architectures under identical training conditions (PQN, 5 seeds, skip connection). LRU achieves the best overall POMDP return, though the authors caution this may not generalize across implementations. The most revealing comparison is GDN vs. MinGRU: despite nearly identical POMDP returns (0.469 vs. 0.471), GDN has a 0.090-smaller Observability Gap (better state recovery) but a 0.091-more-negative Memory Bias (worse optimization), demonstrating that return alone cannot distinguish these models. The standard Transformer, lacking a recurrent state, underperforms on long-RML (O(n)) tasks like Tetris and Navigator where episode-level memory is required. GRU and Linear Transformer show intermediate performance with consistent negative Memory Bias. All memory models exhibit negative Memory Bias relative to the MLP baseline, confirming that introducing memory universally degrades MDP performance—a confound invisible in return-only comparisons. The value smearing pathology and recurrent state contamination are observed across all 7 models, indicating these are systemic issues rather than artifacts of a specific architecture.

## Relation to Prior Work

This paper extends the line of POMDP benchmarking work (POPGym, MemoryGym, MDP Playground) by introducing the first collection of hardware-accelerated environments with paired MDP/POMDP twins sharing identical observation and action spaces, enabling controlled counterfactual studies of observability. It departs from prior memory evaluation approaches that rely solely on return comparisons by proposing three new analytical tools—Observability Gap, Memory Bias, and Recall Density—that disentangle memory's contribution to performance from confounding factors like parameter count and optimization difficulty. The gradient-based pixel saliency and recall density metrics build on the broader interpretability literature (Kapturowski et al., 2019; Ni et al., 2024; Elelimy et al., 2024) but apply them systematically across architectures and tasks to reveal a previously uncharacterized pathology.

## Why It Matters / Open Questions

The discovery of value smearing—that memory models incorrectly attribute value to irrelevant history even in MDPs where the Markov property guarantees only the current state matters—is a fundamental finding that challenges assumptions about how recurrent architectures learn credit assignment. The recurrent state contamination result has direct practical implications: a single OOD observation can corrupt the policy far into the future, raising concerns for real-world deployment and offline RL. Open questions include whether model-based RL or next-state prediction losses avoid these pathologies, whether LLMs undergoing RL fine-tuning exhibit similar smearing, and what architectural or training modifications could eliminate the pathology. The benchmark and metrics provide a practical foundation for future controlled studies of memory in RL.

## Problem

Extending LLM capabilities to new skills in a scalable manner remains an open problem: fine-tuning risks catastrophic forgetting, context-based approaches are constrained by effective context limits, and prompt tuning produces task-specific prefixes that cannot be composed or transferred to new settings without retraining. The paper asks whether LLMs' inherent compositional abilities can be leveraged to learn new composable skills without any weight updates.
![Teaser figure](../imgs/ICML20260269/cropped_page0_idx0.webp)

## Input / Output

The method takes a text prompt in which skill neologism tokens (soft tokens of configurable length, e.g., l=20) are inserted at semantically appropriate positions via a task-specific insertion function φ_S — for example, replacing an operation label like [SHIFT] with its corresponding soft tokens, or substituting a skill name in a natural-language prompt. The output is a standard generated text response. A key distinction from prompt tuning is that multiple independently learned skill tokens can be inserted into the same prompt simultaneously, enabling zero-shot multi-skill composition without joint training.

## Method

Skill neologisms are learnable soft tokens integrated directly into the model's vocabulary and embedding matrix (extending E to E' = E ∪ θ_S), rather than being prepended as a fixed prefix. They are trained via supervised fine-tuning on skill-centered datasets — where every sample requires the target skill S mixed with diverse skills already mastered by the model — while all model parameters remain frozen. Two design choices drive composability: (1) vocabulary-level integration lets the model interact with the skill's procedural knowledge through its existing in-context learning machinery, and (2) skill-centered training with limited token capacity (l=20, ~18K parameters) creates an inductive bias toward learning generally composable representations rather than overfitting to the training distribution. This enables both out-of-distribution compositional transfer (P2) and zero-shot composition of independently learned skills (P3), validated on a controlled digit-sequence task and the Skill-Mix natural language benchmark.

## Results

On the controlled digit-sequence task (Qwen2.5-0.5B), skill neologisms (l=20, 17,920 params) achieve near-perfect in-distribution accuracy on 2-skill compositions and consistently succeed at out-of-distribution composition with held-out skills, while LoRA (r=16, ~2.9M params) shows the poorest OOD generalization and prompt tuning (l=20) performs intermediately. For zero-shot multi-skill composition (Property 3), independently trained skill neologisms for SHIFT and INV-POL significantly outperform in-context learning (N=10–100 examples) across all sequence lengths. On the Skill-Mix benchmark (Llama3.2-3B-Instruct), all three methods reach similarly high accuracy for their individually trained skill, but only skill neologisms enable zero-shot combination of both independently learned skill tokens to achieve high accuracy on both skills simultaneously.

## Baselines & Comparisons

Against prompt tuning (Lester et al., 2021), skill neologisms use the same number of soft tokens (l=20, 17,920 parameters) but achieve notably better OOD compositional transfer (Property 2), with the gap attributed to vocabulary-level integration providing additional flexibility for learning composable representations. Critically, prompt tuning cannot satisfy Property 3: independently trained prefixes cannot be composed zero-shot without retraining, whereas skill neologisms can simply be inserted together in the context. Against LoRA (Hu et al., 2022), skill neologisms use roughly 160× fewer trainable parameters (17,920 vs. ~2.9M) yet achieve superior OOD generalization, with LoRA overfitting the training distribution rather than learning a composable skill representation. On the Skill-Mix natural language benchmark, all three methods reach comparable accuracy on their individually trained skill, but only skill neologisms successfully combine zero-shot to handle both target skills (modus ponens and statistical syllogism) simultaneously, a capability structurally unavailable to both baselines.

## Relation to Prior Work

This paper combines two existing mechanisms—prompt tuning's optimization of soft tokens on a frozen model (Lester et al., 2021) and neologisms' vocabulary-level integration of soft tokens into the embedding matrix (Hewitt et al., 2025)—into a new framework for skill-based continual learning. The key departure from prompt tuning is the architectural choice of integrating skill tokens into the vocabulary rather than as a prefix, which the authors argue enables the model's in-context compositional abilities to be leveraged for zero-shot composition of independently learned skills. The key departure from prior neologism work is the use of skill-centered training data (where every sample requires the target skill mixed with diverse pretraining skills) rather than preference-based or task-specific objectives, creating an inductive bias toward composable skill representations.

## Why It Matters / Open Questions

The paper provides a concrete, minimal-parameter path toward skill-based continual learning that avoids catastrophic forgetting by construction, with the particularly appealing property that independently learned skills compose zero-shot without joint training. However, the evidence is primarily from a 0.5B model on a synthetic digit-sequence task, with a single natural language validation on a 3B model using only two skills and 300 training samples. Key open questions include whether the approach scales to larger models and fuzzier skill definitions, the availability and construction of diverse skill-centered datasets in practice, and the optimization instability inherent to soft token training that the authors acknowledge but do not fully resolve.

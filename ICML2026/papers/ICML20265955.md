## Problem

Gradient-based class-incremental learning faces a fundamental plasticity-stability dilemma: weight updates that enable learning new classes cumulatively distort the decision geometry of previously learned ones, causing catastrophic forgetting. Existing pre-trained-model (PTM) CIL methods mitigate this through architectural bookkeeping—prompt pools, distillation targets, or adapter ensembles—but learning remains fundamentally driven by gradient updates on continuous weights. The paper asks whether plasticity can be externalized into a discrete, gradient-free memory substrate that resolves interference through local stochastic allocation rather than global optimization.

## Input / Output

The method takes RGB images as input, processed by a frozen ViT-B/16 backbone (pre-trained on ImageNet-21K) to produce a 768-d continuous embedding. This embedding is mapped to a sparse binary code of dimension 8192 via a fixed random projection followed by k-winner-take-all thresholding. The output is a fused classification logit vector combining the host PTM head's logits with a ridge-regression readout over CA1-competitive features, weighted by a scalar α. The entire pipeline operates in a strict exemplar-free setting: no past samples are stored, and the binary memory matrix (4096 slots × 8192 dimensions) is the sole persistent state across tasks.

## Method

BTSP-CAM externalizes plasticity into a binary synaptic matrix W_B updated by trace-gated stochastic bit-flip rules, eliminating backpropagation entirely. Continuous backbone features are first mapped to sparse binary codes in Hamming space via a frozen random projection and k-WTA nonlinearity, making pattern collisions explicit. Class-specific eligibility traces track geometric centroids of recent inputs, and a plateau probability—modulated by familiarity, novelty, and cross-class interference signals—gates when and where synapses are rewritten. Conditioned on a plateau event, each active synapse undergoes a bidirectional flip: 0→1 (LTP) allocates new memory attractors while 1→0 (LTD) stochastically prunes shared bits, inducing collision-aware repulsion that actively orthogonalizes correlated class traces. A CA1-like competitive layer (normalize-then-threshold) sparsifies the retrieved memory state, and a closed-form ridge regression consolidates the evolving CA1 representation into stable class logits at the end of each task, with sufficient statistics updated incrementally without storing any past exemplars.

## Results

As a standalone gradient-free classifier (BTSP-only), BTSP-CAM achieves 87.82% average accuracy on CIFAR-100 (B0-Inc5), matching SimpleCIL (87.57%), and 76.23% on ImageNet-R (B0-Inc20), surpassing all prompt-based baselines. As a lightweight plugin, BTSP-CAM consistently improves every tested host method: MOS rises from 93.30% to 93.85% (CIFAR-100), EASE from 91.51% to 92.33%, and CODA-Prompt from 89.11% to 90.25% in average accuracy. Gains are most pronounced on distribution-shifted benchmarks, e.g., ObjectNet where MOS+BTSP-CAM improves final accuracy from 74.69% to 75.38% and average from 63.62% to 65.81%.

## Baselines & Comparisons

As a standalone method, BTSP-only matches or exceeds SimpleCIL on CIFAR-100 (87.82 vs. 87.57 avg.) and decisively outperforms it on ImageNet-R (76.23 vs. 61.26) and ObjectNet (66.31 vs. 65.45), though it trails on CUB-200 (85.15 vs. 92.20). Against prompt-based baselines, BTSP-only surpasses L2P, DualPrompt, and CODA-Prompt on ImageNet-R and ObjectNet, confirming the advantage of discrete geometric memory under distribution shift. As a plugin, BTSP-CAM yields consistent 1–5 point average-accuracy gains over every host: L2P improves from 79.93% to 83.13% (CIFAR), DualPrompt from 81.15% to 84.08%, CODA-Prompt from 81.96% to 84.52%, APER+Adapter from 85.15% to 87.91%, EASE from 85.80% to 86.95%, and MOS from 89.25% to 90.12%. The largest relative gains appear on harder benchmarks (e.g., ObjectNet: MOS+BTSP-CAM gains +2.19 points in average accuracy), indicating the geometric repulsion mechanism is most beneficial when the frozen feature space is less separable.

## Relation to Prior Work

This paper instantiates the simpleBTSP model (Wu & Maass, 2025) — a discrete, binary content-addressable memory driven by stochastic bit-flip dynamics — as the plasticity engine for PTM-based class-incremental learning. It departs from the dominant paradigm in PTM-CIL (L2P, DualPrompt, CODA-Prompt, EASE, MOS), where all adaptation is achieved through gradient descent on continuous weights (prompts, adapters, or classifier heads), by externalizing plasticity into a frozen binary synaptic matrix updated via trace-gated LTP/LTD flips in Hamming space. The sparse k-WTA coding layer connects to the broader sparse distributed memory and random projection literature (Kanerva, 1988; Johnson & Lindenstrauss, 1984), while the closed-form ridge consolidation aligns with the replay-free analytic-head line (SimpleCIL, RanPAC).

## Why It Matters / Open Questions

The paper demonstrates that a gradient-free, discrete stochastic allocation mechanism can rival continuous gradient-based fine-tuning for CIL in a strictly exemplar-free setting, and that the LTD-driven repulsion is the critical component preventing cross-class interference (removing it drops accuracy by ~3 points and doubles old-to-new error). As a lightweight plugin, BTSP-CAM consistently adds 1–3 points across diverse PTM-CIL baselines, suggesting the geometric memory core is complementary to existing adaptation strategies. Limitations include restriction to image classification with frozen ViT backbones and a fixed memory budget; open questions include whether the binary stochastic allocation generalizes to other modalities (text, video), whether the memory capacity scales gracefully with task count, and whether the plateau-gating heuristics can be replaced by learned or data-driven schedules.

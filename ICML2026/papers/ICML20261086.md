## Problem

Standard Conformal Prediction methods produce prediction sets that are small but semantically incoherent, while prior approaches that incorporate label structure (hierarchical, clustered CP) reduce semantic diversity at the cost of substantially larger prediction sets. No existing post-training method simultaneously improves both the semantic coherence and the average size of CP prediction sets across arbitrary score functions.
![Teaser figure](../imgs/ICML20261086/cropped_page1_idx0.webp)

## Input / Output

The method operates as a post-hoc modification to any existing CP score function, requiring a trained classifier (ResNet or ViT), a labeled calibration set (split 50/50 into threshold-calibration and λ-tuning subsets), and either a known class-to-superclass partition (MA-CS) or access to training data for computing class-mean embeddings (MS-CS). The output is a prediction set of class labels with the same marginal coverage guarantee (1−α) as the unmodified CP, but with fewer distinct superclasses and a smaller average cardinality. No retraining or architectural changes are needed; the only added computation is a C×C similarity matrix (for MS-CS) and a small λ search over the tuning split.

## Method

The core mechanism augments any CP score s(x,y) with a class-similarity penalty: s_λ(x,y) = s(x,y) + λ·d(y, ŷ(x)), where ŷ(x) is the argmax prediction and d measures dissimilarity between candidate y and the predicted class. In the Model-Agnostic variant (MA-CS), d is a binary indicator of whether y and ŷ(x) belong to different superclasses; in the Model-Specific variant (MS-CS), d is a soft penalty 1 − M_{y,ŷ(x)} where M is a cosine-similarity matrix computed from centered class means in the deepest feature space, leveraging the neural-collapse phenomenon. The key theoretical result (Theorem 4.5) proves that for sufficiently small λ, this penalty reduces the expected prediction set size whenever p₁·n̄₀ < p₀·n̄₁ — a condition that holds in practice because groups are small relative to total classes and reasonably accurate classifiers have group-level accuracy above 50%. The modified score preserves exchangeability and hence the standard CP coverage guarantee, and λ is tuned on a held-out calibration split to minimize empirical set size.

## Results

On CIFAR-100 with ResNet-34 and the RAPS score (α=0.05), MS-CS reduces the average prediction set size from 5.79 (Standard) to 3.79, a 34% reduction, while MA-CS achieves 4.52. On CIFAR-100 with ResNet-50 and LAC, MS-CS reduces size from 3.68 to 2.92 and #Superclasses from 2.27 to 1.83. Across all dataset-model-score combinations, both MA-CS and MS-CS consistently outperform Standard and Clustered baselines on both average set size and #Superclasses, with MS-CS generally achieving the smallest sets. The model-specific variant (MS-CS) further reduces set size compared to MA-CS by leveraging the model's learned class embeddings.

## Baselines & Comparisons

Against Standard LAC, RAPS, and SAPS (the three score-function baselines), both MA-CS and MS-CS consistently reduce average prediction set size across all dataset-model pairs; for example, on CIFAR-100/ResNet-34 with RAPS, MS-CS achieves size 3.79 vs. 5.79 for Standard (34% reduction), and on CIFAR-100/ResNet-50 with LAC, MS-CS achieves 2.92 vs. 3.68 (21% reduction). Against Clustered CP (Ding et al., 2023), the proposed methods also win on both metrics in nearly all settings, with Clustered sometimes even increasing set size relative to Standard (e.g., SAPS on ImageNet: 10.0 vs. 2.13). Against AIR (adapted from Goren et al., 2024), the comparison is mixed: AIR achieves lower #Superclasses (e.g., 1.51 vs. 1.88 for SAPS on CIFAR-100/RN50), but its prediction set sizes are dramatically larger (e.g., 15.15 vs. 3.79 for RAPS on CIFAR-100/RN34, a 4x gap), making it impractical for efficiency-focused use. The model-specific variant (MS-CS) consistently edges out MA-CS on set size by 5–15% due to its soft, model-adaptive similarity, while both maintain the same marginal coverage guarantee (≥1−α) as verified in the appendix tables.

## Relation to Prior Work

This paper extends the Conformal Prediction framework by augmenting any CP score function with a class-similarity penalty term, building directly on the foundational CP guarantee from Vovk et al. (1999) and the standard score functions LAC, RAPS, and SAPS. It departs from prior structured-CP work (clustered Mondrian CP, hierarchical selective classification) which typically increases prediction set size to achieve group-conditional coverage, by showing that a simple out-of-group penalty simultaneously reduces both the number of semantic groups and the average set size. The model-specific variant further draws on the neural collapse phenomenon (Papyan et al., 2020) to construct class similarity from the model's own feature-space geometry, eliminating the need for human-defined superclasses.

## Why It Matters / Open Questions

The paper provides a plug-and-post tool that can be applied to any existing CP method on any dataset, with the notable empirical finding that no prior post-training approach had consistently outperformed standard LAC in average set size. The theoretical result (Theorem 4.5) explaining when the penalty reduces set size is a local (small-λ) analysis, and extending it to the soft model-specific penalty remains open. The approach may degrade for very weak classifiers where group-level accuracy is poor, and the practical tuning of λ, while simple, adds a small calibration overhead. Broader implications include the possibility that class-structure-aware regularization could inform other uncertainty quantification methods beyond CP.

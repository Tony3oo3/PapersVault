## Problem

Existing model-merging approaches for pluralistic value alignment (e.g., FWA, DARE, KnOTS) combine value-specific experts through linear parameter aggregation without accounting for the entanglement inherent in real-world value data, where samples labeled for one value dimension co-activate correlated values. This entanglement causes adjusting one value's weight to unintentionally shift other value dimensions, preventing fine-grained, independent priority control. The paper identifies the need to explicitly separate shared consensus structure from value-specific components in the merged representation.

## Input / Output

The method takes a base LLM (Llama-3.2-3B or Qwen3.5-4B), k value-aligned expert models each fine-tuned via full-parameter SFT on a single value dimension, their empirical Fisher information matrices (estimated from 5120 samples with low-rank approximation), and a user-specified priority weight vector λ ∈ [0,1]^k. It produces a single steered model parameter θ_align that, when queried with a text prompt, generates a response reflecting the specified value combination. The value weights are continuous and can be set per-dimension at inference time, enabling compositional control (e.g., 60% Care + 40% Loyalty) without retraining.

## Method

DisAlign is a two-stage model-merging framework that decomposes entangled value experts into a consensus component and value-specific components within an information-geometric space. In Stage 1, it computes a consensus anchor θ_c* via Product-of-Experts I-projection (reduced to a Fisher-weighted least-squares closed form under the local quadratic assumption), then identifies the consensus subspace C_r by solving a Generalized Eigenvalue Problem on the residual covariance with a Fisher-metric constraint, selecting directions of minimal inter-expert disagreement. In Stage 2, it projects each expert residual onto the Fisher-orthogonal complement of C_r to remove consensus, then solves a dual eigenproblem on the Fisher-weighted Gram matrix to obtain a Fisher-orthonormal value-specific basis U_v. The final steered model is θ_align = θ_c* + βC_r + αU_v, where user weights λ are mapped into the value subspace via α(λ) = Σ^{1/2}E^T λ, ensuring that each value dimension can be modulated independently with minimal cross-value interference.

## Results

On the three pluralistic alignment benchmarks (MIC, Daily Dilemmas, ValuePrism), DisAlign achieves the highest accuracy across all three evaluation settings (Two-dim, Random-dim, Full-dim). On MIC, DisAlign reaches 59.6% (Random) / 56.6% (Full) accuracy, and on Daily Dilemmas 60.6% / 57.1%, exceeding the strongest model-merging baselines (FWA, KnOTS, Rewarded Soups) by 3–10 points. In half of the evaluation metrics, the improvement over the second-best method exceeds three standard deviations. In fine-grained control experiments, DisAlign achieves a control fidelity of 0.92 (vs. 0.78 for MAP, 0.12 for KnOTS, 0.05 for Rewarded Soups), and in open-ended generation it scores 4.2/4.4 on Value Alignment (vs. 2.4/2.9 for FWA) while maintaining comparable response quality.

## Baselines & Comparisons

DisAlign outperforms all 12 baselines across every dataset and evaluation setting. Against the strongest model-merging baselines, the gains are most pronounced: on MIC (Random-dim), DisAlign (59.6%) surpasses KnOTS (57.4%) by ~2.2 points and Rewarded Soups (55.8%) by ~3.8 points; on Daily Dilemmas it leads KnOTS by ~4.5 points. On ValuePrism, the margin widens to 5–8 points over the best baselines, with several metrics exceeding 3 standard deviations. In the fine-grained sensitivity experiment (Table 2), DisAlign achieves a control fidelity of 0.92 versus 0.78 for MAP (the only other 'responsive' method), while KnOTS (0.12) and Rewarded Soups (0.05) are essentially rigid and fail to respond to weight changes. In open-ended generation (Table 6), DisAlign scores 4.2/4.4 on Value Alignment compared to 2.4/2.9 for FWA and 2.8/3.1 for DARE, while maintaining comparable response quality (3.7 vs. 3.4/3.8). The ablation (Table 4) further shows that both consensus removal and Fisher-geometric decomposition are necessary: Euclidean-space decomposition with consensus removal reaches only 46.9/50.8 on MIC, far below DisAlign's 59.6/56.6.

## Relation to Prior Work

This paper extends the model-merging paradigm for pluralistic value alignment by introducing an explicit information-geometric decomposition step that prior merging methods (FWA, DARE, KnOTS, Rewarded Soups) lack. It builds on Hinton's Product-of-Experts framework to define a consensus anchor via I-projection, on Matena & Raffel's Fisher-weighted averaging for the local metric, and on Ilharco et al.'s task-vector formulation for parameter offsets. The key departure is formulating the shared-vs-specific split as a Generalized Eigenvalue Problem in Fisher geometry rather than relying on heuristic sparsification or simple orthogonality constraints, which prior geometric merging methods (KnOTS, FWA) apply without distinguishing value-shared patterns from value-specific ones.

## Why It Matters / Open Questions

The paper addresses a concrete and practically important limitation: when merging value experts, adjusting one value's weight inadvertently shifts others, making fine-grained priority control unreliable. The theoretical guarantees (stability under perturbation, translation invariance of the consensus subspace) and the ablation showing that consensus removal is essential for disentanglement provide a principled recipe rather than an ad-hoc fix. However, the approach is validated only on 3B–4B models, requires empirical Fisher matrix estimation (adding ~260s of computation), and the local quadratic assumption, while empirically supported, may break under aggressive RLHF or very large distributional shifts. Open questions include scalability to 70B+ models, handling of truly orthogonal (vs. correlated) value dimensions, and whether the PoE consensus formulation remains well-defined when expert count grows substantially.

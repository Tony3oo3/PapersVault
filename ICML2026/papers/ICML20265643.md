## Problem

Modern LLM-powered agents transmit full structured UI observations (e.g., accessibility trees) to remote inference servers even when only a small subset is task-relevant, leaking sensitive but unnecessary context such as 2FA codes, private notifications, and background application states. Existing privacy defenses—static PII filtering, differential privacy, and cryptographic inference—either remove task-critical structure, distort semantic cues needed for reliable actuation, or fail to prevent inference from whatever state is disclosed. The paper identifies this failure mode as Semantic Over-Privileged Observation and formalizes pre-disclosure minimization as learning a Contextual Integrity-compliant structural bottleneck.

## Input / Output

The method takes a raw accessibility tree (a hierarchical graph of UI elements, each with text content, accessibility role, interaction state, and structural metadata like depth and lineage) together with a natural-language user task description as conditioning signal. It produces a sanitized accessibility tree in which each node is either kept verbatim (K), abstracted by replacing sensitive attribute values with placeholders while preserving structural role (A), or removed entirely (R). The output is not a strict subset of the input because A actions modify attribute content in place, and the entire transformation runs locally on the client device before any data reaches the remote inference server.

## Method

MINIM encodes the accessibility tree as a graph and processes it with a 3-layer GATv2 (hidden size 256, 4 heads) whose node features are 512-d vectors combining 384-d MiniLM text embeddings with UI attributes and structural properties. Two MLP heads (256→128→11) predict per-node sensitivity (inherent disclosure risk, task-independent) and task-conditioned necessity (utility for the current intent). Training uses a CI-aware multi-task objective: a standard MAE sensitivity loss plus a necessity loss whose per-node weight is multiplicatively inflated by a factor (1 + λ·s_i/10·(1−n_i,T)/10), so that prediction errors on high-sensitivity, low-necessity nodes are penalized most heavily. At deployment, a fixed ternary policy maps predicted scores to Keep/Abstract/Remove actions via two thresholds (τ_nec=1.0, τ_sens=5.0), cleanly decoupling learned scoring from normative policy enforcement so that privacy-utility trade-offs can be tuned post-hoc without retraining.

## Results

On the augmented WebArena test set (N=662), MINIM achieves TCNP-I 0.9931, TCNP 0.9491, and TISL 0.101 (i.e., only 10.1% of the full-observation leakage), while retaining just 12% of nodes. Compared to the strongest single-score baseline (Necessity-Only), MINIM halves task-irrelevant sensitive leakage (TISL 0.1010 vs. 0.2032) while slightly improving both utility metrics (TCNP 0.9491 vs. 0.9445; TCNP-I 0.9931 vs. 0.9730). Against prompted LLM scorers (7 open-weight models from 4B to 70B parameters), MINIM achieves the lowest TISL (0.101) and lowest node retention (12.0%) while matching or exceeding TCNP-I of five out of seven LLM baselines.

## Baselines & Comparisons

Against fixed-policy baselines (Table 1), MINIM dominates on the privacy-utility frontier: Sensitivity-Only collapses utility (TCNP 0.0401) while still leaking 38% of sensitive content, Necessity-Only preserves utility but leaks 20.3% of sensitive information, and Random Budget fails both objectives. MINIM halves TISL relative to Necessity-Only (0.1010 vs. 0.2032) while improving TCNP-I by 2.0 points (0.9931 vs. 0.9730). Against prompted LLM scorers (Table 2), all seven open-weight models (Gemma-3N-E4B through Llama-3.3-70B-Instruct) retain 25.8–34.5% of nodes and incur TISL between 0.194 and 0.312, roughly 2–3× higher than MINIM's 0.101. MINIM matches or exceeds the TCNP-I of five of seven LLMs (0.9931 vs. 0.985–0.996) while retaining only 12.0% of nodes, demonstrating that explicit CI-aware training yields a strictly superior privacy-efficiency frontier compared to general instruction tuning. Notably, scaling from 8B to 70B parameters (Llama-3-8B → Llama-3.3-70B) worsens TISL (0.206 → 0.312), confirming that model scale alone does not enforce task-conditioned minimization.

## Relation to Prior Work

This paper carves new ground at the intersection of Contextual Integrity (Nissenbaum, 2004) and structured agent observations, repurposing CI's information-flow norms from social/dialogue settings to the pre-disclosure channel of autonomous agents. It departs from prior privacy-preserving inference work (DP, MPC, FHE) that protects computation but not the observation itself, and from PII redaction tools (Presidio) and conversational privacy gateways (AirGapAgent, Portcullis, Papillon) that target unstructured text rather than action-critical structured hierarchies. The GATv2-based dual-score architecture is a novel instantiation: no prior work learns joint sensitivity and task-conditioned necessity over accessibility trees to drive a ternary K/A/R disclosure policy, and the CI-weighted loss (penalizing necessity errors more on high-sensitivity, low-utility nodes) is a new objective design.

## Why It Matters / Open Questions

As agentic systems increasingly transmit full UI state to remote inference, the Semantic Over-Privileged Observation problem is becoming a practical deployment blocker; MINIM provides a principled, locally-deployable mechanism to address it without requiring the remote agent to be trusted with minimization. Key open questions include cumulative privacy loss over long-horizon episodes, robustness to active adversaries (prompt injection), and whether the 27-task WebArena evaluation generalizes to open-ended enterprise or full-desktop settings. The finding that a lightweight GATv2 outperforms 70B LLMs on privacy metrics—despite the LLMs having broader semantic understanding—suggests that explicit CI-constrained training is more effective than general instruction tuning for minimization, a result that could reshape how privacy layers are architected in agent pipelines.

## Problem

Tensor Product Representations provide exact, interference-free binding of fillers to roles but require memory tensors whose dimensionality grows exponentially with structural depth (d^k for depth k), making deep recursive binding intractable. Vector Symbolic Architectures fix the memory dimension at d but accumulate interference noise that degrades retrieval as superposition increases, with SNR scaling as O(√(N/d)). This creates a fundamental three-way trade-off—structural fidelity, memory footprint, and superposition capacity—that no existing architecture resolves favorably at scale.

## Input / Output

The method takes fillers as ordered tuples of p vectors in R^d and contexts as k-dimensional subspaces (defined by mutually orthogonal basis vectors generated procedurally via hashing role labels, so no context storage is needed). The memory is an order-p tensor in (R^d)^{⊗p} with effective dimension d^p, yet each filler costs only p·d parameters—sub-linear in memory capacity. Retrieval is recognition-based: a candidate filler is bound to the query context and scored via Frobenius inner product against the memory, with the highest-scoring vocabulary item selected. For the XML application, document features pass through a standard neural network whose output is a superposition vector encoding active/inactive class labels.

## Method

OSC enforces structural separation through geometric exclusion rather than explicit coordinate assignment: each context defines a 'forbidden' subspace, and the carving operator P_C^⊥ = I − B_C^T B_C projects each filler component onto the orthogonal complement before the components are fused via an order-p tensor product. This guarantees that bindings under different contexts occupy disjoint subspaces automatically, making memory formation order-independent and decoupling tensor order from structural depth. Interference from N−1 other bindings has zero mean and standard deviation √((N−1)/d^p), which is suppressed by increasing either dimension d or tensor order p. Contexts are generated on demand by concatenating role labels, hashing to a seed, and QR-decomposing a random matrix—so the number of representable contexts is unbounded at zero storage cost. The paper further shows TPR is a special case of binding in Clifford algebra and provides a Clifford formulation of OSC where the context is a blade and carving becomes geometric rejection.

## Results

On the synthetic binding benchmark at 1,000 bundles, OSC (d=200, p=2) achieves 99.77% retrieval accuracy and 100% recognition accuracy with only 440,000 total parameters, compared to the best VSA at d=4,096 (13.18% retrieval, 93.00% recognition, 4.1M params) and d=8,100 (35.88%, 98.04%, 8.1M params) — a 9.3× and 18.4× storage reduction respectively. At 10,000 bundles, OSC (d=80, p=3) maintains 99.85% retrieval with 2.9M parameters while the best VSA (HLB, d=343,000) reaches only 97.19% with 3.43B parameters (1,178× larger). On 8 Extreme Multi-Label Classification datasets, OSC is competitive with VTB, MAP, and HLB, ranking first in 43.75% of metric-dataset combinations.

## Baselines & Comparisons

OSC outperforms all 14 compared VSAs (HRR, FHRR, MAP-I/C/B, BSC, BSDC-S/CDT/SEG, MBAT, VTB, CGR, HLB, GHRR) on both retrieval and recognition accuracy at 1,000 bundles, achieving 99.77% retrieval where the best VSA (HLB) manages only 13.18% at d=4,096. At 10,000 bundles, OSC (d=80, p=3) reaches 99.85% retrieval with 2.9M parameters, while HLB requires d=343,000 (3.43B params, 1,178× larger) to reach 97.19%; even HLB's worst configuration (d=15,625, 0.56% accuracy) still uses 53.7× more memory than OSC. Against TPR at role depth 1, OSC uses 2.55× fewer parameters at N=10,000 (228 vs 649 params per filler). On the XML task, OSC ranks first in 43.75% of the 16 metric-dataset combinations (e.g., 59.70 nDCG on EURLEX-4K vs VTB's 51.53 and HLB's 52.54), while VTB leads on smaller datasets like BIBTEX (58.44 vs OSC's 57.08 nDCG). In wall-clock speed, OSC is slower than HLB at small dimensions (0.46× at N=100) but becomes 3.88× faster at N=10,000 in the B2 configuration as memory bandwidth becomes the bottleneck.

## Relation to Prior Work

OSC sits at the intersection of Tensor Product Representations (Smolensky, 1990), which guarantee exact binding but scale exponentially with structural depth, and Vector Symbolic Architectures (Kanerva, 2009; Plate, 1995; and 14 surveyed variants), which maintain constant dimensionality but accumulate interference under superposition. The key conceptual departure is an inversion: rather than explicitly assigning bindings to coordinate slots (TPR) or compressing the tensor product back into the vector space (VSA), OSC defines forbidden subspaces via context and places bindings in their orthogonal complement, using a multi-component filler that produces an order-p tensor memory. The paper also shows TPR is a strict special case of binding in Clifford algebra and provides a Clifford formulation of OSC, connecting to recent work on Clifford-based network layers (Pence et al., 2025; Ruhe et al., 2023). The projection-based exclusion mechanism draws conceptual parallels to null-space methods in continual learning (Conceptors, OWM, OGD, GPM), though the application to symbolic binding is new.

## Why It Matters / Open Questions

OSC decouples tensor order from structural depth, enabling deep recursive binding within a constant memory footprint, and its sub-linear filler scaling (vocabulary cost O(d_1^{1/p}) rather than O(d_1)) yields 9×–1178× total memory reductions over the best VSAs in high-superposition regimes. The argument that discriminative recognition (vocabulary search) suffices in place of exact algebraic unbinding reframes the design space for symbolic memories and is supported by the observation that even VSA/TPR systems rely on cleanup memories in practice. Limitations include slightly lower representation density than VSAs when superposition memory (rather than total storage) is the binding constraint, and the loss of exact unbinding, though the authors argue this is functionally neutral. Open questions include the information-hiding implications of OSC's preserved filler-memory similarity (unlike VSAs where binding destroys similarity), the true optimal scaling of the carving dimension, and whether the recognition-only paradigm extends to open-vocabulary or generative settings.

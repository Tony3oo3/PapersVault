## Problem

LLMs deployed as agents interact with external tools through highly structured, repetitive patterns (JSON schemas, function signatures, common argument values), yet they rely on general-purpose tokenizers optimized for broad linguistic coverage. This training-deployment mismatch fragments recurring structural and semantic units into long sequences of low-level tokens, inflating both per-call decoding cost and the accumulated dialogue history that later decisions must condition on. Existing agentic methods improve tool-calling through parameter adaptation or reasoning design but treat the tokenizer as a fixed component, leaving this vocabulary-level inefficiency unaddressed.

## Input / Output

The method consumes real tool-calling trajectories (approximately 119.3K interactions synthesized from MCP environments via the TouCan dataset) together with a base model and its original general-purpose tokenizer (Qwen2.5-7B-Instruct). It produces an augmented vocabulary V′ = V ∪ V_struct ∪ V_cont containing 800 structural tokens and 200 content tokens, along with a corresponding specialized tokenizer τ′. The adapted vocabulary is then used to continue supervised fine-tuning, yielding a model that generates tool calls with shorter effective sequence lengths while preserving task behavior.

## Method

AgentVocab employs a dual-branch vocabulary induction strategy. The structure-aware branch identifies structural primitives (JSON Schema keywords, function-calling fields, syntactic delimiters), extracts maximal contiguous structural spans from serialized tool calls, and ranks them with an efficiency-guided score S_struct(s) = f(s)·(ℓ_τ(s)−1)/√ℓ_τ(s) that balances frequency against token savings. The content-aware branch applies Token-Level BPE (TL-BPE) to non-structural token streams to generate candidate merges over existing base-token IDs, then re-ranks them using a VEGAD-inspired gradient criterion that accumulates input-embedding and output-logit gradient norms over all matched occurrences. Training follows a two-stage schedule: first, LoRA-based SFT with the original tokenizer for 3,500 steps to acquire tool-calling capability; second, vocabulary expansion with new token embeddings initialized by averaging constituent base-token embeddings, followed by 1,500 additional LoRA SFT steps with the adapted tokenizer. The approach is orthogonal to existing fine-tuning and agent-training methods, requiring no architectural changes or task-specific schema engineering.

## Results

On τ-bench, AgentVocab improves overall accuracy from 22.42% (Vanilla SFT) to 24.65% while reducing average input tokens by 22.1% (7,283 → 5,671), output tokens by 13.3% (130.7 → 113.3), and latency by 17.7% (0.209s → 0.172s). On the more challenging τ²-bench, AgentVocab maintains near-identical accuracy (23.67% vs. 23.79%) while cutting input tokens by 19.5% (9,321 → 7,508), output tokens by 14.0% (168.4 → 144.9), and latency by 19.5% (0.375s → 0.302s). Relative to the un-fine-tuned Qwen2.5-7B-Instruct base, AgentVocab reduces latency by 28.9% on τ-bench and 25.2% on τ²-bench.

## Baselines & Comparisons

The paper compares three configurations: the un-fine-tuned Qwen2.5-7B-Instruct base model, a Vanilla SFT model (same LoRA training with the original tokenizer), and AgentVocab SFT (two-stage training with an adapted vocabulary of 800 structural + 200 content tokens). Against the base model, both fine-tuned variants achieve substantially higher accuracy (24.65% and 22.42% vs. 13.94% on τ-bench; 23.67% and 23.79% vs. 16.36% on τ²-bench), confirming the importance of supervised agent training. Against Vanilla SFT, AgentVocab wins on τ-bench across all four metrics (accuracy +2.23 pp, input tokens −22.1%, output tokens −13.3%, latency −17.7%) and on τ²-bench across all efficiency metrics (input tokens −19.5%, output tokens −14.0%, latency −19.5%) while matching accuracy within 0.12 pp. The efficiency gains are attributed to vocabulary-level compression of recurring JSON Schema fragments and tool-call patterns rather than to additional fine-tuning steps, as both configurations share the same total 5,000-step budget.

## Relation to Prior Work

AgentVocab extends the vocabulary-adaptation line initiated by Herold et al. (2025) and AdaptiVocab (Nakash et al., 2025), which showed that domain-specific token expansion reduces sequence length without accuracy loss, by introducing a structure-aware branch that explicitly mines JSON Schema fragments and tool-calling formatting patterns as atomic tokens. The content-aware branch adapts VEGAD's (Liu et al., 2024a) gradient-based selection criterion to a token-level BPE (TL-BPE) pipeline, and embedding initialization follows Cui et al. (2023). Crucially, the paper positions itself as orthogonal to the dominant agent-training literature (Gorilla, ToolLLM, APIGen, CodeAct, Re-ReST), which treats the tokenizer as a fixed component and improves tool-calling through data construction, reasoning, or parameter adaptation.

## Why It Matters / Open Questions

The ~18–20% latency reduction with preserved accuracy is practically significant for production agent deployments where per-turn decoding cost compounds over multi-turn trajectories, and the orthogonality claim means the technique can be layered onto any existing agent-training pipeline without re-deriving data or modifying reasoning strategies. Limitations include evaluation on a single 7B model family (Qwen2.5) and two benchmarks, modest and sometimes negative accuracy deltas at the domain level (e.g., Telecom on τ²-bench), and an unexplored question of whether the structural-token budget and TL-BPE hyperparameters transfer across tokenizer architectures or model scales. Open questions include whether the approach generalizes to non-JSON structured outputs (e.g., XML, protobuf) and whether the efficiency gains persist as base-model tokenizers themselves become more domain-adaptive.

## Problem

While test-time scaling via verifier-guided search has been widely studied for LLMs and diffusion models, it remains unclear what properties of a generative model's representation make it amenable to search in the first place. This paper investigates whether the structural choice of tokenization—specifically 1D ordered (coarse-to-fine) tokens versus classical 2D grid tokens—fundamentally affects how effectively test-time search can steer autoregressive image generation.
![Teaser figure](../imgs/ICML20261227/cropped_page0_idx1.webp)

## Input / Output

The method takes a text prompt (and optionally a reference image for zero-shot concept preservation) and produces a generated RGB image. Internally, images are represented as variable-length 1D sequences of discrete tokens from a 64K vocabulary (FlexTok d18-d28), where any prefix can be detokenized into a valid image. The search operates over these token sequences, with intermediate detokenization feeding a verifier at selected token positions; for 2D grid baselines, partial sequences are zero-padded to enable detokenization. In the training-free setting, no autoregressive model is required—only the tokenizer's codebook and a verifier are used.

## Method

The paper introduces the Search-over-Tokens (SoTo) framework, which systematically studies test-time search by varying three axes: search algorithm (best-of-N, beam search, lookahead search), verifier (9 types spanning image-text alignment, image-image alignment, and image quality), and autoregressive prior strength (text-conditional, unconditional, or uniform). The core insight is that 1D ordered tokenizers trained with nested dropout produce intermediate token prefixes that carry globally meaningful semantics, making them directly evaluable by verifiers and thus highly amenable to beam search; in contrast, 2D grid token prefixes correspond to fixed spatial regions with little semantic signal. A theoretical analysis formalizes this by bounding the search gap via the reconstruction error of intermediate decodes under a Lipschitz verifier assumption, showing that nested dropout training in 1D ordered tokens yields tighter bounds. Empirically, beam search yields substantially larger gains for 1D ordered tokens than for 2D grid tokens, and pure search over the ordered token space (with no AR model) achieves training-free text-to-image generation at 79% single-object accuracy on GenEval.

## Results

On DreamBench++ concept preservation, FlexTok with beam search improves DINO-I by +18.4 (32.5→50.9) and CLIP-I by +8.4 (68.1→76.5), while Janus with lookahead search gains only +5.9 DINO-I (34.8→40.7). On GenEval, pure search with a uniform prior (no AR model) achieves 79% single-object and 32% two-object accuracy, while the conditional AR prior with beam search reaches 100% and 81% respectively. A 530M-parameter FlexTok model with sufficient test-time compute outperforms a 3.4B model with limited inference compute, and the optimal model size follows a power law (a=4.5×10³, b=0.44) with inference FLOPs.

## Baselines & Comparisons

Against the controlled 2D grid baseline (same data, architecture, and training compute as FlexTok), beam search produces markedly larger gains for 1D ordered tokens while yielding only marginal improvements for 2D grid tokens; best-of-N and lookahead search show similar scaling for both. Compared to Janus (a competitive 2D grid AR model), Janus achieves slightly higher base performance without search, but FlexTok exhibits substantially stronger test-time scaling under beam search, and on DreamBench++ FlexTok+BeamSearch gains +18.4 DINO-I versus Janus+LookaheadSearch's +5.9. Against LlamaGen (2D grid) on ImageNet-1K, Semanticist (1D ordered) shows the same pattern: beam search yields larger gains for the ordered tokenizer. Infinity (a scale-wise AR model related to VAR) benefits more from search than Janus but less than FlexTok, suggesting that semantic coarse-to-fine ordering is particularly effective. Overall, 1D ordered tokens consistently outperform 2D grid tokens under their best-performing search algorithm across all compared baselines, and the gap cannot be closed by search algorithm choice alone.

## Relation to Prior Work

This paper builds on FlexTok's coarse-to-fine 1D ordered tokenization and positions itself at the intersection of image tokenization design and test-time scaling. While prior test-time scaling work for image generation has focused on designing better search algorithms (TTS-VAR, ScalingAR, GridAR) or stronger verifiers, this paper argues that the token representation itself is a previously underappreciated determinant of search effectiveness. It departs from the standard framing by showing that 1D ordered tokens make image generation structurally analogous to domains (LLM reasoning, board games) where search has proven effective, and provides a theoretical link between nested-dropout training and search gap bounds that 2D grid tokenizations lack.

## Why It Matters / Open Questions

The finding that token structure fundamentally modulates search effectiveness reframes tokenization from a purely representational choice to a mechanism for enabling test-time control, with direct implications for how AR image generation systems should be designed. The demonstration that training-free generation is possible via pure search over ordered tokens (79% single-object GenEval with a uniform prior) opens a path to lightweight, verifier-driven generation without training an AR model. Key open questions include verifier hacking under sufficient compute, the detokenization bottleneck during search, and whether these findings generalize to video, 3D, or other modalities where ordered tokenization is emerging.

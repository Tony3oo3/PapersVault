## Problem

Existing video understanding benchmarks lack explicit task graphs that encode temporal precedence and parallel execution possibilities, forcing agents to treat all steps as sequential and miss opportunities for parallel progress. Moreover, strong MLLMs struggle to follow task-graph structure and leverage parallel threads even when graphs are provided as input, limiting their effectiveness for proactive robot assistance in both human-absent and collaborative settings.
![Teaser figure](../imgs/ICML20266294/cropped_page0_idx0.webp)

## Input / Output

The method consumes a 5-frame sliding window (stride 3) of video keyframes extracted based on adjacent-frame appearance changes, along with the annotated task graph (a DAG with AND/OR dependency nodes) for the identified task. Output is a hierarchical structure where a binary trigger decision gates all subsequent predictions: if triggered, the model produces a task label, current step label, a short-horizon future action sequence, and a single proactive robot action (or WAIT) selected under graph feasibility constraints. The two-stage evaluation protocol first determines trigger and task, then conditions step detection and action selection on the identified task graph.

## Method

ProAct-Helper builds on Qwen2.5-VL (3B/7B) fine-tuned with LoRA (r=32) and introduces two key components. First, a Hierarchical Binding Module (HBM) applies symmetric contrastive losses between span-pooled hidden states of adjacent hierarchy levels (trigger→task and task→step) to enforce cross-level semantic consistency under severe long-tail class distributions, without projection heads. Second, an entropy-driven heuristic search selects the next robot action by computing a thread-mixing entropy over parallel execution threads defined by the task graph's reachability structure; the agent minimizes this entropy via one-step lookahead, favoring actions on threads different from the human's current thread to enable parallel progress while respecting AND/OR precedence constraints. Training combines autoregressive cross-entropy, a binary trigger classification loss, and the HBM binding loss, with the full objective weighted by λ_trig and λ_bind.

## Results

On ProAct-75, ProAct-Helper (7B) achieves 76.56% trigger mF1, 34.79% task mF1, 11.56% step mF1, and 3.90 edit distance for future action prediction. For proactive action selection, it achieves 0.361 saved steps (SS) and 19.41% parallel action rate (PA), substantially outperforming the best closed-source baseline Gemini-2.5-Pro (SS 0.120, PA 3.83%). The HBM module contributes an additional +2.71% task mF1 and +1.63% step mF1 over the plain variant, confirming its benefit for long-tail class handling.

## Baselines & Comparisons

ProAct-Helper (7B) outperforms all closed-source MLLM baselines across every metric. Against the strongest closed-source model Gemini-2.5-Pro, it improves trigger mF1 by +20.62% (76.56 vs. 55.94), task F1 by +17.09% (69.20 vs. 52.11), step F1 by +11.72% (33.13 vs. 21.41), saved steps by +0.241 (0.361 vs. 0.120), and parallel action rate by +15.58% (19.41% vs. 3.83%). Against the best open-source model Qwen3-VL-30B-A3B, gains are +10.31% trigger mF1, +3.09% task mF1, and +2.12% step mF1. In the text-only action-selection simulation (Table 3), where all methods receive ground-truth human trajectories, ProAct-Helper still achieves the lowest robot thread entropy (ER 0.654) and highest parallel action rate (33.95%), while closed-source LLMs like GPT-4o produce more WAIT actions (lower E but higher ER), indicating they fail to establish stable parallel execution threads. The HBM ablation confirms that the Task→Step binding loss (L_task2step) is more effective than Trigger→Task (L_trig2task), yielding +3.48% task mAcc and +2.70% step mAcc versus +2.82% and +2.56% respectively.

## Relation to Prior Work

This paper departs from the dominant Theory-of-Mind paradigm in proactive human-robot collaboration, where robots infer and mirror human intentions, by instead using explicit task-graph structure (DAGs with AND/OR dependencies) to enable independent parallel action selection. It extends the video understanding benchmark lineage (Ego-Exo4D, COIN, UCF-Crime) by introducing the first benchmark with step-level annotations paired with explicit task graphs encoding temporal precedence and parallelizable threads. Methodologically, it combines MLLM-based perception (Qwen2.5-VL with LoRA) with a contrastive Hierarchical Binding Module for cross-level consistency and a lightweight entropy-driven heuristic for graph-constrained action selection, rather than relying on end-to-end learned planners.

## Why It Matters / Open Questions

ProAct-75 fills a clear gap: no prior video benchmark provides explicit task graphs with AND/OR dependencies and parallel execution structure, which are essential for evaluating whether agents can exploit concurrency rather than defaulting to sequential execution. The finding that frontier closed-source LLMs (GPT-4o, Gemini-2.5-Pro) fail to leverage parallel threads even when given explicit graph constraints in the prompt is practically important for anyone building structured planning on top of LLMs. Key limitations include the heuristic (non-learned) planner, weak cross-actor generalization (Step F1 drops from 90 to 35), and the relatively small task count (75), leaving open whether learned graph-feasible decoders or larger benchmarks would yield substantially different conclusions.

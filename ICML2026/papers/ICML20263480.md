## Problem

The prevailing view of parametric memory in deep sequence models is associative: atomic facts are stored as brute-force lookups over arbitrary embeddings. This paper identifies a dramatically different form—geometric memory—where models synthesize embeddings encoding global multi-hop relationships, and poses the 'memorization puzzle': why does this geometry prevail over the equally valid associative lookup when no obvious supervisory, architectural, or optimizational pressure favors it?

## Input / Output

The model is trained on a fixed path-star graph (degree d, path length ℓ, up to 10⁴ nodes) whose edges are memorized in weights via interleaved edge-memorization prompts (node → adjacent node) and path-finding prompts (leaf node → full root-to-leaf token sequence), with pause tokens and reverse-edge augmentation. At test time, given only a held-out leaf node, the model must predict the first token of the unique root-to-leaf path—no adjacency list is provided in-context. The key diagnostic output is the geometry of learned node embeddings: nodes on the same path cluster tightly around a shared direction, making the ℓ-hop composition reducible to a single alignment lookup.

## Method

The paper isolates implicit in-weights reasoning on adversarially designed path-star graphs (where the first token is provably the hardest to learn under next-token training) and shows that decoder-only Transformers and Mamba models succeed even when trained only on the first-token loss. The core insight is that learned node embeddings form a global geometry—abstractly, f(u)[v] = Φ_geom(u)·Φ_geom(v) rather than the associative Φ(u)ᵀW_assocΦ(v)—where the embeddings encode multi-hop proximity, turning an exponentially hard ℓ-fold composition into a Θ(1) spatial navigation task. To explain why this geometry arises, the authors reduce the problem to a 2-layer, weight-tied, Node2Vec-style model (where associative memory is architecturally prohibited) and show that a low-rank spectral bias (alignment with top eigenvectors of the adjacency matrix) emerges naturally from cross-entropy loss minimization, without the bottleneck, regularization, or multi-hop supervision assumed in prior Node2Vec analyses. They systematically refute four plausible explanations—global supervision, explicit capacity limits, optimizational speed, and implicit succinctness—establishing that the geometry's rise remains a genuine open question for deeper architectures.

## Results

On in-weights path-star graphs of up to 5×10⁴ nodes with path lengths of 6–10 hops, a next-token-trained Transformer (GPT-mid) achieves up to 100% accuracy on predicting the first (hardest) token for unseen leaf nodes, even when trained only on edge-memorization examples plus first-token loss (no intermediate-hop supervision). Mamba achieves analogous results. In contrast, the original in-context path-star task (Bachmann & Nagarajan, 2024) causes complete failure even on tiny graphs. The 2-layer Node2Vec-style model exhibits a cleaner low-rank spectral geometry (skewed toward top eigenvectors) than the Transformer, whose geometry is 'mildly adulterated' by competition with local associative memory.

**Table 1: Comparison of two forms of parametric memory in a deep sequence model, given a dataset of edges from a graph G = (V, E).**

| Aspect | Associative Memory (Def. 2a) | Geometric Memory (Def. 2b) |
|---|---|---|
| Storage mechanism | Lookup table of pairwise edge associations | Graph embedding of the vertices |
| Embedding Φ | Arbitrary (random/orthogonal); acts as keys; encodes no associations | Reveals the graph structure |
| Simplest implementation | f(u)[v] = Φ(u)ᵀ W_assoc Φ(v), W_assoc ≈ Σ Φ(u)⊗Φ(v) | f(u)[v] = Φ_geom(u)ᵀ Φ_geom(v), Φ_geom ≈ top eigenvectors of graph Laplacian |
| Relationship to G | W_assoc ≈ adjacency matrix (up to rotation) | Φ_geom ≈ low-rank factorization of adjacency matrix |
| Global information | Only local edge info readily available | Global multi-hop distance readily available |
| Novel info not in data | None | Synthesizes novel info from scattered datapoints |
| Implicit composition (e.g., path-finding) | Exponentially hard to learn | Approximated as easy geometric navigation |
| Retrieval accuracy | Precise | Approximate |
| Description length | \|E\| (up to log factors) | \|V\| × m (embedding dim) |

## Baselines & Comparisons

The paper does not propose a new method to benchmark against baselines; instead it contrasts two forms of parametric memory and two task settings. The in-context path-star task (Bachmann & Nagarajan, 2024) causes next-token learners to fail in-distribution even on tiny graphs, while the in-weights version studied here succeeds on graphs up to 5×10⁴ nodes with 10-hop paths. Both Transformer and Mamba succeed in the in-weights setting, confirming the phenomenon is architecture-agnostic. Comparing the 2-layer Node2Vec model to the Transformer, the Node2Vec geometry is more strongly organized (more skewed toward top eigenvectors), suggesting the Transformer's geometry is partially 'adulterated' by its capacity for local associative lookup. The paper also contrasts associative vs. geometric storage conceptually: associative memory requires exp(ℓ) compute to learn an ℓ-hop composition, while geometric memory reduces this to Θ(1) by turning the task into a one-step spatial navigation problem.

## Relation to Prior Work

This paper repurposes the adversarial path-star graph from Bachmann & Nagarajan (2024), originally designed to expose failures of in-context next-token reasoning, into an in-weights memorization setting where the graph is stored in model parameters rather than provided in context. It consolidates scattered observations of structured node embeddings (Khona et al., 2024; Nishi et al., 2025; Ye et al., 2025; Huang et al., 2025) into a unified 'geometric memory' framework that contrasts with the dominant associative-memory abstraction (Radhakrishnan et al., 2020; Bietti et al., 2023). The spectral-bias analysis draws on the Node2Vec literature (Grover & Leskovec, 2016; Saxe et al., 2019) but departs from it by showing the low-rank eigendecomposition emerges under cross-entropy loss without the bottleneck, regularization, or multi-hop supervision pressures typically assumed in prior analyses.

## Why It Matters / Open Questions

The paper formulates a genuine 'memorization puzzle'—why geometric (global) storage prevails over the simpler associative lookup when no obvious supervisory, architectural, or optimizational pressure favors it—and provides a partial answer via spectral bias in 2-layer models, while leaving the full competition dynamics in deep models open. Practically, it identifies headroom to make Transformer memory more geometric (as in Node2Vec) and warns that geometric interdependencies may complicate knowledge editing, unlearning, and accurate retrieval. Key limitations include restriction to symbolic tasks and specific graph topologies (path-star, tree-star), small-to-mid-sized models trained from scratch, and explicitly empirical/informal arguments; generalization to natural language and larger-scale pretraining remains highly non-trivial.

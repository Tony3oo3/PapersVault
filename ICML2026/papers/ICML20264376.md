## Problem

Existing LLM routing and aggregation methods suffer from three bottlenecks: train-free routers rely solely on query-textual similarity, missing deep semantics and task difficulty; aggregation methods use a fixed aggregator that cannot adapt to domain-specific needs; and the complementary strengths of routing (stability) and aggregation (exceeding individual model limits) are not jointly exploited. The paper asks whether a training-free orchestration of open-source LLMs can surpass the leading closed-source model Gemini-3-Pro.
![Teaser figure](../imgs/ICML20264376/cropped_page1_idx0.webp)

## Input / Output

Given a single text query, JiSi consults a pre-built embedding bank containing normalized question embeddings, LLM response embeddings, and binary correctness vectors for 10 open-source LLMs over ~70% of benchmark data (split 0.7:0.3). The system first retrieves a support set via cosine similarity, then queries the top-K candidate LLMs (K=3) for live responses. The final output is a single text response, either directly from one routed LLM or synthesized by a dynamically selected aggregator from the concatenated responses of multiple high-scoring LLMs.

## Method

JiSi is a training-free 'route-and-aggregate' framework built on a pre-built embedding bank (gte-Qwen2-7B-instruct embeddings of questions, responses, and token costs). Its three core mechanisms are: (1) Query-Response Mixed Routing, which computes composite prior scores from query similarity, response-embedding similarity, and reasoning-length similarity to capture task difficulty beyond surface text; (2) Support-Set-based Aggregator Selection, which picks the aggregator from a larger query-similarity support set to balance domain-specific expertise with general aggregation skill; and (3) Adaptive Routing-Aggregation Switch, which applies a threshold on fine-grained prior scores to either aggregate multiple high-quality responses or fall back to top-1 routing, thereby suppressing noise. The filtered support set (shrunk by factor β) incorporates all three similarity signals, and the final aggregatee set is truncated to at most 2 models if total context exceeds 13,000 tokens.

## Results

JiSi achieves a 72.15 average score across nine benchmarks (AIME, Arena-Hard, GPQA, HLE, LiveCodeBench, LiveMathBench, MMLU-Pro, SimpleQA, SWE-Single-Round), surpassing the leading closed-source model Gemini-3-Pro (71.00) by +1.15% while saving 53.23% in API cost. Compared to the strongest single open-source LLM (DeepSeek-V3.2-Speciale, 65.59), JiSi gains +6.56%. The router-only variant of JiSi (Query-Response Mixed Router) scores 69.68, and the full framework with aggregation adds a further +3.03% over the best standalone router method.

## Baselines & Comparisons

JiSi outperforms all 24 baselines on average. Against the strongest closed-source model Gemini-3-Pro (71.00), JiSi gains +1.15% while reducing cost by 53.23%; against GPT-5.2-Thinking (66.20) and Grok-4 (64.17), the margins are +5.95% and +7.98% respectively. Among router methods, JiSi's full pipeline beats the best standalone router (Retrieval-based Router, 69.12) by +3.03%, and its router-only component (69.68) already exceeds all prior routers including Avengers (68.74) and GraphRouter (68.41). Among multi-LLM methods, JiSi surpasses Self Consistency (70.66) by +1.49%, MoA (67.58) by +4.57%, Symbolic-MoE (66.89) by +5.26%, Self-MoA (66.52) by +5.63%, and Majority Voting with 10 LLMs (61.69) by +10.46%. Notably, JiSi also exceeds the 'Best LLM' upper bound (70.55, the per-benchmark maximum across all open-source models) by +1.6%, demonstrating that aggregation can break through individual model ceilings.

## Relation to Prior Work

This paper sits at the intersection of LLM routing (RouterDC, GraphRouter, Avengers, EmbedLLM) and multi-LLM aggregation (MoA, SMoA, Self-MoA), departing from both lines by identifying three specific bottlenecks: query-only routing misses task difficulty, static aggregator selection ignores domain specificity, and rigid routing-then-aggregation pipelines waste computation on simple queries. Unlike trained routers (RouterDC, GraphRouter, EmbedLLM), JiSi is entirely training-free, relying on a pre-built embedding bank and cosine-similarity-based scoring. It also extends the unified routing-aggregation frameworks (Symbolic-MoE, SMACS) by introducing an adaptive switch that can collapse aggregation into pure top-1 routing when only one expert response is sufficiently confident.

## Why It Matters / Open Questions

The paper provides a practical, training-free recipe for orchestrating open-source LLMs that consistently outperforms both individual open-source models and frontier closed-source models (Gemini-3-Pro) across nine diverse benchmarks, while reducing cost by ~53%. The scaling experiment—showing monotonic improvement as new models are added to the pool—suggests a 'collaboration scaling law' that could complement parameter scaling. However, the +1.15% margin over Gemini-3-Pro is modest, the cost advantage depends heavily on open-source API pricing rather than algorithmic efficiency, and the SWE-bench evaluation is simplified to single-round (no tool use or multi-turn interaction), limiting the practical generality of the coding results. Open questions include how the embedding bank degrades as the model pool grows, whether the approach transfers to multimodal or agentic settings, and whether the adaptive switch generalizes beyond the specific threshold heuristics used here.

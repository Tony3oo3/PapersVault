## Problem

Naively applying Supervised Fine-Tuning on interleaved plot-solution data causes a substantial degradation in geometric reasoning performance compared to text-only baselines, because SFT induces distributional alignment—the model imitates the surface format of alternating text and code without internalizing the causal dependency that makes each constructed diagram necessary for the next deduction. The paper asks how to move beyond this superficial imitation so that visual construction becomes a functionally load-bearing component of reasoning rather than a noisy distraction.
![Teaser figure](../imgs/ICML20265808/cropped_page0_idx0.webp)

## Input / Output

The model receives a geometry problem statement (text) and an optional initial diagram (RGB image), and produces a heterogeneous trajectory that alternates between textual reasoning blocks and executable GeoGebra code blocks, each code block rendering a visual state that conditions the subsequent reasoning step. The final output includes both the interleaved trace and a final answer. The GeoGebra scripts must be syntactically valid, standalone, and produce non-degenerate renders; the visual token cap is 2,048 and maximum sequence length is 10,000 to accommodate the interleaved text-code context.

## Method

Faire (Functional alignment for interleaved reasoning) initializes from Qwen3-VL-8B via SFT on interleaved traces, then applies GRPO reinforcement learning with a causally-grounded reward that enforces three necessary conditions for the visual artifact to act as a valid mediator in the causal graph T→V→Y: (1) Geometric Consistency (C_geo), an objective verifier that executes the code in GeoGebra and checks hard constraints derived from the problem; (2) Perceptual Admissibility (C_perc), a subjective MLM judge that scores visual clarity and interpretability of the render; and (3) Semantic Alignment (C_sem), a parser-based verifier that checks logical entailment between geometric intents in the text and primitives in the code. The reward is gated by answer correctness and code executability before aggregating the three verification signals, forcing the policy to internalize that correct plotting is a necessary causal antecedent to correct reasoning rather than a formatting artifact.

## Results

On Faire-Bench, Faire achieves 74.82% answer accuracy and a tri-perspective verification average of 45.37 (Parser 37.27, Code 60.39, Judge 38.44), substantially outperforming the best proprietary baselines (GPT-5.2 at 24.62 Avg; Gemini-2.5-Pro at 19.86 Avg) and its own SFT initializer Qwen3-VL-8B (14.85 Avg). On GenExam, Faire attains the best structural correctness (Math-Str 9.3) while matching the best relational score (Math-Rel 52.3), surpassing GPT-Image-1 (8.0/52.0). On GGBench, Faire achieves the highest overall interleaved score (VLM-I 63.13) and a dominant mid-process score (89.11 vs. 76.79 for GPT-5), despite being an 8B model.

## Baselines & Comparisons

Faire decisively outperforms all baselines on the tri-perspective verification scores: it nearly doubles GPT-5.2's Avg (45.37 vs. 24.62) and more than doubles Gemini-2.5-Pro's (45.37 vs. 19.86), with the largest gap on the formal Code metric (60.39 vs. 36.59 for GPT-5.2 and 22.51 for Gemini-2.5-Pro). On raw answer accuracy, Gemini-2.5-Pro (78.24%) edges out Faire (74.82%), but the paper argues this reflects textual shortcuts rather than genuine interleaved reasoning, as Gemini's verification scores remain low. Among open-weight models, Faire surpasses its SFT initializer Qwen3-VL-8B by 15.11 points in accuracy and 30.52 points in verification Avg, and outperforms GLM-4.1V-9B (63.41% Acc) by 11.41 points. On GenExam, Faire achieves the best Math-Str (9.3) and Math-Rel (52.3), narrowly beating GPT-Image-1 (8.0/52.0) while all other baselines score 0.0–2.6 on structure. On GGBench, Faire's 63.13 overall VLM-I score exceeds GPT-5 (57.08) and Claude Sonnet 4.5 (54.11), with a particularly large mid-process advantage (89.11 vs. 76.79 for GPT-5), demonstrating that functional alignment in step-by-step construction matters more than model scale.

## Relation to Prior Work

This paper builds on GRPO (Shao et al., 2024b) as its RL optimization backbone but departs fundamentally from prior interleaved-reasoning work by identifying a 'SFT paradox': supervised fine-tuning on interleaved plot-solution traces causes negative transfer rather than improvement. Conceptually, it reframes the training objective from distributional alignment (mimicking the surface format of alternation) to functional alignment (enforcing causal dependency between constructed diagrams and subsequent deductions), operationalized through a tri-perspective verifier (geometric executability, perceptual admissibility, semantic consistency). This positions Faire against both data-centric multimodal geometry solvers and prior interleaved-generation paradigms (Wu et al., 2025c; Gao et al., 2025a) that rely on supervised learning and thus inherit the same distributional-alignment limitation.

## Why It Matters / Open Questions

The SFT paradox finding—that adding interleaved visual supervision via SFT degrades reasoning accuracy—is a practically important warning for anyone building multimodal interleaved systems, and the paper provides both a mechanistic explanation (conditional mutual information gap, context fragmentation) and a working remedy (RL with gated causal rewards). The tri-perspective verification framework is a reusable design pattern for any domain where generated artifacts must be functionally coupled to reasoning. Key limitations include evaluation on a single model family (Qwen3-VL-8B), a self-constructed K12 geometry benchmark, and GeoGebra-specific tooling; whether the SFT paradox generalizes to other interleaved domains (e.g., scientific figure generation, interactive coding) and whether the functional-alignment reward design transfers to non-geometric tasks remain open questions.

## Problem

Standard conformal prediction requires labeled calibration data exchangeable with test inputs, but in many deployments (sensor upgrades, modality changes, corruption shifts) labeled calibration exists only in a source space while coverage guarantees are needed in a target space. Existing importance-weighted conformal methods assume source and target share a common feature space, which is violated when the two spaces are fundamentally different (e.g., clean vs. corrupted images, SAR vs. RGB). This paper tackles the gap of transferring conformal calibration across spaces using only unlabeled paired observations, without any labeled target calibration data.

## Input / Output

The method takes a labeled source calibration set, unlabeled paired source-target observations (e.g., clean-corrupted image pairs or co-registered SAR-RGB tiles), and a fixed target predictor, and produces set-valued class predictions with a finite-sample target-domain marginal coverage guarantee of 1−α. Uniquely, the procedure also emits two label-free deployment diagnostics: a one-sided KS inflation term δ⁺ (for TCC-KS) and an effective-sample-size percentage ESS% (for weighted-TCC), which can be computed before deployment to indicate whether the KS safeguard or post-transport reweighting is more trustworthy. No target labels are used at any point in the calibration pipeline; they appear only in held-out evaluation.

## Method

TCC first learns a transport map f from unlabeled paired data (via a reconstruction objective, optionally augmented with a label-free KL alignment term matching the target predictor's outputs) to map labeled source calibration inputs into the target space, then applies split conformal calibration on the transported scores. Two complementary label-free corrections address residual post-transport mismatch: TCC-KS computes a one-sided Kolmogorov-Smirnov discrepancy on a label-free uncertainty surrogate (least-confidence) between transported and real target inputs, inflates it via a DKW bound to obtain δ⁺, and tightens the internal level to α* = max(0, α − δ⁺), yielding conservative sets when mismatch is large; weighted-TCC instead reweights transported calibration scores toward the target input distribution using density ratios estimated from unlabeled samples, targeting the smaller residual shift rather than the original source-target gap. An impossibility theorem (Theorem 3.1) shows that without structural assumptions linking observable quantities to the unobservable true-label score distribution, any uniformly valid label-free procedure must be near-vacuous, motivating the approximate surrogate control assumption (A2) under which TCC-KS achieves high-probability target coverage ≥ 1 − (α + ε). The transport-then-correct decomposition is the key architectural choice: correcting after transport exploits the fact that the residual shift between f(X_s) and X_t is typically much smaller than the original source-target gap, making both the KS certificate and the importance weights more stable and informative.

## Results

On CIFAR-100-C (α=0.1), TCC-KS achieves 0.92 coverage with set size 44.35, while weighted-TCC matches Transported CP at 0.89 coverage with size 37.15; WCP (no transport) reaches 0.92 coverage but with larger sets (43.90). On Tiny-ImageNet-C (α=0.1), TCC-KS attains 0.93 coverage (size 86.33) versus WCP's 0.93 (size 88.54), and weighted-TCC achieves 0.90 (size 69.71) close to Oracle CP's 0.90 (size 69.68). On the cross-modal SAR→RGB task, TCC-KS reaches 0.99 coverage with set size 2.51, while WCP achieves 1.00 coverage but with larger sets (2.87). In the severe-shift stress test (shot noise and motion blur, severities 4–5), TCC-KS restores valid coverage (0.91 on CIFAR-100-C, 0.93 on Tiny-ImageNet-C) where Transported CP and weighted-TCC exhibit mild under-coverage (0.88 and 0.897 respectively).

## Baselines & Comparisons

The primary baseline is WCP (weighted conformal prediction without transport, Tibshirani et al. 2019), which applies importance-weighted conformal calibration directly in the source space without learning a transport map. On CIFAR-100-C at α=0.1, TCC-KS matches WCP's coverage (0.92 vs 0.92) with a slightly smaller set (44.35 vs 43.90), while weighted-TCC achieves lower coverage (0.89) but substantially smaller sets (37.15 vs 43.90), indicating better efficiency when residual shift is mild. On Tiny-ImageNet-C, TCC-KS ties WCP on coverage (0.93) with a smaller set (86.33 vs 88.54), and weighted-TCC again trades coverage (0.90 vs 0.93) for efficiency (69.71 vs 88.54). On the cross-modal SAR→RGB task, TCC-KS achieves 0.99 coverage with set size 2.51 versus WCP's 1.00 coverage with size 2.87, showing that transport-based calibration is more efficient under severe modality shift. In the stress test (severities 4–5), WCP remains conservative (0.93 on CIFAR-100-C, 0.965 on Tiny-ImageNet-C) but with the largest sets (53.10 and 120.26), while TCC-KS restores valid coverage (0.91 and 0.93) with moderate set inflation (47.66 and 91.75), demonstrating that correcting after transport is more efficient than reweighting the full source-target gap without transport.

## Relation to Prior Work

This paper sits at the intersection of conformal prediction and domain transport. It builds on split-conformal calibration (Angelopoulos & Bates, 2023) and importance-weighted conformal prediction under covariate shift (Tibshirani et al., 2019), but departs from both by operating in a setting where source and target inputs live in different spaces (X_s ≠ X_t) linked only by unlabeled paired observations. The transport map f is learned via standard image-translation objectives (pix2pix-style), but its role here is specifically to relocate labeled calibration scores into the target input space, after which label-free corrections (KS-based inflation or post-transport reweighting) handle residual mismatch. The paper explicitly contrasts with domain adaptation work (Isola et al., 2017; Zhu et al., 2017), which targets predictive accuracy rather than distribution-free coverage guarantees for prediction sets.

## Why It Matters / Open Questions

The impossibility result (Theorem 3.1) cleanly establishes that nontrivial label-free conformal validity requires structural assumptions, and the paper makes this requirement explicit via Assumption A2 with deployable diagnostics (δ+, ESS%) that signal when each correction mechanism is trustworthy. Practically, this addresses a real deployment gap—sensor upgrades, modality transitions, and pipeline changes where fresh labeling is costly or delayed—by showing that unlabeled paired data suffice for reliable coverage transfer. Open questions include whether the marginal-coverage guarantees extend to conditional or group-conditional settings, how the surrogate T should be chosen when the target model is poorly calibrated, and whether the explicit sample-splitting requirement (Assumption A3) can be relaxed for small unlabeled budgets.

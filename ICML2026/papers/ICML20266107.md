## Problem

Self-speculative decoding accelerates LLM inference by constructing a draft model from a subset of the target model's layers, but existing methods either fix the number of skipped layers as a hyperparameter, rely on accumulated information across multiple instances (causing delayed optimization), or use heuristic token-level signals that are insufficiently correlated with actual inference speedup. The key gap is the lack of an adaptive, training-free mechanism that can efficiently and dynamically optimize the draft model's layer configuration in real time during a single inference session.

## Input / Output

LEAP takes an input text prompt and a frozen target LLM (e.g., LLaMA-3-8B or 70B) as input. During the prefilling forward pass, it extracts per-layer intermediate features and output probability distributions to compute two redundancy metrics (R_l for feature transformation and ΔL̄ for acceptance improvement), which are then used to partition layers into zones and groups. The output is a generated text sequence produced via lossless speculative decoding (preserving the target model's exact output distribution) along with an adaptively determined draft model layer configuration specifying execute, skip, or repeat actions per layer group. The draft model reuses the target model's KV cache, and the token tree has a fixed length of 4 and width of 8.

## Method

LEAP formulates draft model construction as a sequential decision-making process optimized by Monte Carlo Tree Search (MCTS), where each decision assigns an action (execute, skip, or repeat) to a layer group. Two empirical observations structure the search space: (i) redundancy metrics computed during prefilling remain strongly correlated with those at subsequent decoding steps, so they are computed once and reused; (ii) layer redundancy exhibits zone-wise characteristics, with early layers critical for feature transformation, middle layers relatively redundant, and final layers important for acceptance. Based on these, layers are partitioned into three zones with zone-specific action constraints (early: execute only; middle: execute/skip; final: execute/repeat) and further grouped into consecutive blocks, reducing the search space from 3^M to under 2^m. Crucially, speculative decoding itself serves as the MCTS simulation: each candidate complete configuration is evaluated by actually running one speculative decoding iteration, and the resulting real-time speedup provides the reward for backpropagation through the MCTS tree. The UCB selection criterion includes a soft depth penalty on the layer retention ratio as regularization, and MCTS terminates when the optimal configuration stabilizes, after which the draft model is fixed for remaining inference.

## Results

LEAP achieves an overall wall-time speedup of 2.05× on LLaMA-3-8B and 1.94× on LLaMA-3-70B under greedy decoding (T=0), and 1.68× / 1.73× under sampling (T=1), consistently outperforming prior self-speculative decoding methods. The mean generated length M reaches 4.66–4.95 tokens per iteration (vs. 1.86–3.17 for baselines), reflecting higher draft acceptance. Ablation confirms each component contributes: removing zone partitioning drops speedup to 1.67×, removing grouping to 1.63×, and replacing MCTS with random search to 1.56×.

## Baselines & Comparisons

Against the two primary self-speculative baselines, LEAP dominates: on LLaMA-3-8B at T=0, LEAP achieves 2.05× overall speedup versus SWIFT's 1.13× and CLaSP's 1.27×; at T=1 the gap widens further (1.68× vs. 0.76× and 1.06×), as SWIFT degrades below 1× on several datasets. Against training-free non-self-speculative methods (Table 6), LEAP outperforms DSBD (1.58×/1.59×) and Lookahead (1.87×/1.85×) on GSM8K and MT-Bench respectively, though MTAD (1.95×/2.34×) edges out LEAP on MT-Bench partly because it uses lossy verification. Against the training-based EAGLE-3 (Table 7), LEAP (1.84× overall) trails EAGLE-3 (2.44× overall), but EAGLE-3 requires target-specific training while LEAP is fully plug-and-play. Under dynamic data streams (Table 4), LEAP maintains 2.01× overall speedup while SWIFT drops to 1.04×, confirming LEAP's instance-level adaptability advantage.

## Relation to Prior Work

LEAP operates within the self-speculative decoding paradigm established by Draft&Verify (Zhang et al., 2024) and LayerSkip (Elhoushi et al., 2024), where the draft model is a subset of the target model's layers, and builds on the foundational speculative decoding framework of Leviathan et al. (2023) for lossless verification. It departs from prior self-speculative methods (SWIFT, CLaSP) that treat layer selection as a black-box optimization or heuristic token-level problem by formulating draft model construction as a sequential decision-making process solved via MCTS, with a structured search space derived from zone-wise redundancy observations. The token tree construction follows tree-based speculative inference approaches (Miao et al., 2024; Svirschevski et al., 2024), while the key algorithmic novelty lies in the zone-aware MCTS search that directly optimizes inference speedup as the reward signal.

## Why It Matters / Open Questions

LEAP provides a practical, training-free, plug-and-play solution for LLM inference acceleration that requires no auxiliary modules or target-specific training, making it immediately deployable once a target model is available. The empirical finding that prefilling-derived layer redundancy remains stably correlated throughout decoding and exhibits zone-wise structure is a useful inductive bias that could inform other layer-pruning or early-exit strategies. However, the speedup advantage diminishes under larger batch sizes, long-context inputs, and smaller models with limited layer redundancy, suggesting the method's gains are most pronounced in the single-request, moderate-context regime typical of interactive LLM serving. An open question is whether the zone partitioning generalizes across architectures (e.g., MoE models, non-Transformer backbones) where the early-middle-final redundancy pattern may not hold.

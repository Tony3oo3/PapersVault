## Problem

RL-based post-training of LLMs generates many rollout sequences that share long token prefixes (system prompts, dialogue histories, environment states), yet existing frameworks process each sequence independently, redundantly recomputing identical prefixes in every forward and backward pass. While packing rollouts into a tree with a sparse attention mask avoids this redundancy, such packed-tree execution scales poorly: training-state memory grows with total tree tokens, and irregular tree-mask kernels achieve lower model FLOPs utilization than optimized dense causal attention.

## Input / Output

The method consumes N rollout sequences (each with an associated RL loss or policy-gradient signal) that share prefixes, organized into a prefix tree where each root-to-leaf path is one full sequence. It produces standard gradient updates to the policy model parameters, but the computation graph is constructed and freed dynamically along a single active path rather than materializing the full tree. The system operates at a 16K context length with 2048-token chunked backpropagation blocks, and the distributed variant partitions sequences into K contiguous DFS-ordered groups for balanced multi-GPU execution.

## Method

AREAL-DTA performs a depth-first traversal of the rollout prefix tree, maintaining a stack of token segments and their KV caches that represents only the current root-to-leaf path. Shared prefix segments are forward-passed once and reused by all descendant rollouts; when DFS backtracks, the obsolete suffix is backpropagated (accumulating gradients from all descendants) and popped, keeping live memory proportional to the longest sequence depth rather than total tree tokens. An optimized leaf-order traversal (Algorithm 1) reduces the computation to N_leaf regular FWD/BWD rounds plus a small number of FWD-NOGRAD cache-anchor passes (~7% overhead), and chunked backpropagation handles suffixes spanning tens of thousands of tokens. For multi-GPU scaling, a load-balanced dispatcher sorts sequences in lexicographic (DFS) order and partitions them into K contiguous segments via binary search on maximum tree-token cost, preserving prefix sharing while equalizing per-GPU workload.

## Results

On τ²-bench, AREAL-DTA achieves up to 8.31× single-GPU training throughput improvement over the dense AREAL baseline (Qwen3-1.7B), 6.20× for the 8-GPU training cluster, and 2.28× end-to-end RL pipeline throughput for the 8B model (1.28× for 1.7B). Compared to the Sparse (FlexAttention tree-mask) baseline, AREAL-DTA delivers 1.52×–1.70× higher throughput across model sizes (4B/8B/14B). Peak GPU memory is reduced by over 50% relative to Dense on Qwen3-1.7B, and the full-tree compression rate exploited is C=9.43× (89.4% prefix sharing).

## Baselines & Comparisons

The primary baseline is AREAL (Fu et al., 2025), the state-of-the-art asynchronous RL training system using standard dense causal attention. AREAL-DTA outperforms AREAL by 1.28× end-to-end on Qwen3-1.7B and 2.28× on Qwen3-8B, with the gap widening for larger models because the training-stage bottleneck is more severe. On single-GPU throughput, AREAL-DTA reaches up to 8.31× over Dense (with large chunk blocks) and 7.53× with the base Tree method. A second baseline, Sparse (FlexAttention with an explicit tree attention mask), represents the packed-tree-mask approach; AREAL-DTA achieves 1.52×–1.70× higher throughput over Sparse+CKPT across 4B/8B/14B models, because Sparse suffers from lower MFU on irregular tree masks and must split large trees into subtrees (dropping effective compression from 9.43× to 7.47×). The paper also notes that a trivial baseline—merging rollouts that are strict prefixes of other rollouts—yields only 1.67× speedup, underscoring that the DFS traversal and chunked backpropagation are the key contributors beyond simple deduplication.

## Relation to Prior Work

This paper extends the AReaL asynchronous RL training framework (Fu et al., 2025) by introducing a dynamic tree-attention mechanism for the policy-training stage. It departs from the natural 'Sparse' packed-tree-mask approach (closely related to Tree Training, Wang et al., 2025a) by replacing a single monolithic tree-masked forward/backward pass with a DFS traversal that materializes only one root-to-leaf path at a time, thereby decoupling memory from total tree size. The chunked backpropagation for long suffixes draws on ChunkFlow (Yuan et al., 2025), and the load-balanced partitioning builds on ordered-partitioning techniques, while the broader tree-attention lineage from inference (SpecInfer, Medusa, Sequoia, FastTree) is repurposed for the training setting where gradient accumulation across branches introduces additional constraints.

## Why It Matters / Open Questions

RL post-training is a dominant cost in modern LLM development, and an 8.31× single-GPU training speedup (with >50% peak-memory reduction) on prefix-sharing-heavy workloads directly translates to larger group sizes and more rollouts per iteration under fixed hardware budgets. The practical insight that improving training throughput shifts the optimal rollout/training GPU split (from 2/6 to 5/3) has immediate pipeline-design implications for asynchronous RL systems. Key limitations include dependence on high prefix-sharing rates (low-compression workloads show limited or negative gains) and evaluation restricted to a single benchmark family (τ²-bench) and one model architecture (Qwen3). Open questions include adaptive runtime policies for when to invoke tree execution, extension to broader RL algorithms and agentic tasks, and whether the DFS approach generalizes to non-lexicographic or dynamically evolving prefix structures.

## Problem

Current LLMs rely on a learning mechanism fundamentally analogous to biological implicit memory (gradual, error-driven, dense-coding), which limits them to pattern recognition and statistical association. Higher-order cognitive functions essential for AGI—long-term strategic planning, metacognition, symbolic reasoning, and one-shot learning—depend on hippocampal explicit memory and cannot emerge from implicit statistical learning alone. No principled computational framework has been proposed for integrating an artificial explicit memory system into LLMs.

## Input / Output

The proposed memory module f_memory receives a dense embedding E ∈ R^d from upstream representational processes together with the current memory state M (comprising a key-value mapping P ∈ R^{n×d} and an associative matrix A ∈ R^{n×n}), and outputs a memory update ΔM and a retrieved dense embedding Y ∈ R^d. A critical constraint is that ΔM must be computed as a function of E and M alone, with zero gradient dependence on any prediction or prediction error (∇_{p,e} ΔM = 0), distinguishing it from standard backpropagation-driven updates. The sparse index S = sparsify(E) must satisfy a non-expansion property so that distinct inputs remain separable in sparse space.

## Method

The paper defines eight computational requirements for an artificial explicit memory system, each mapped to a biological mechanism in the hippocampal trisynaptic pathway. Sparse indexing (analogous to dentate gyrus pattern separation) generates a mostly-zero code from the dense input; an associative matrix A implements Hebbian 'fire together, wire together' binding among co-active dimensions; and a key-value mapping P binds each sparse dimension to its dense source for reconstruction. Pattern completion proceeds in two stages—sparse index completion via A followed by dense reconstruction via P—enabling retrieval from partial cues. The system must support one-shot plasticity (immediate retrievability after a single exposure), dynamic temporal evolution of M, and adaptive forgetting via heterosynaptic weakening of connections between active and inactive dimensions. The framework is explicitly substrate-independent and positions the memory module as a complement to, not a replacement for, the LLM's implicit (transformer) computation.

## Results

This is a position paper with no quantitative experiments or benchmark results. The central claim is qualitative: LLMs' learning mechanism (gradual, error-driven, dense/distributed coding, automatic retrieval) is structurally and functionally analogous to hippocampal-independent implicit memory (basal ganglia habituation), and therefore cannot support the higher-order cognitive functions—metacognition, long-term planning, logical reasoning, and dynamic one-shot learning—that require explicit (hippocampal) memory. The paper formalizes eight computational requirements (sparse indexing, error-independent update, associative construction, pattern separation, pattern completion, dynamicity, high/instant plasticity, adaptive forgetting) that an artificial explicit memory module must satisfy to close the gap toward AGI.

## Baselines & Comparisons

No formal baselines or head-to-head method comparisons are presented, as this is a theoretical position paper. The closest analog to a 'comparison' is the conceptual contrast between LLMs-as-implicit-memory and the proposed explicit memory module: the paper argues that existing approaches (RAG, MemoryLLM, Larimar, Titans, Memoria) each satisfy only a subset of the eight proposed requirements—for example, Titans couples memory updates to loss gradients (violating error-independence), while Memoria lacks internal associative structure within its dense hidden states. The paper also distinguishes its position from Complementary Learning Systems (CLS) theory, which treats LLMs as neocortical semantic memory analogues; the author rejects this, arguing LLMs revert to rigid stimulus-response behavior rather than flexibly retrievable rule-governed knowledge. No numerical performance deltas are reported.

## Relation to Prior Work

This position paper draws on Complementary Learning Systems theory (McClelland et al., 1995; Kumaran et al., 2016) and classical neuroscience of explicit vs. implicit memory (Tulving, Squire, Schacter) but departs from CLS by arguing that LLMs are fundamentally implicit (basal ganglia-like) rather than neocortical semantic analogues. It synthesizes and critiques recent neural memory systems—Memoria, Titans, MemoryLLM, and Larimar—against a set of eight formalized computational requirements (sparse indexing, error-independent update, associative construction, pattern separation, pattern completion, dynamicity, instant plasticity, adaptive forgetting) that no single prior system fully satisfies. The paper carves new ground by providing the first unified formal specification of what an artificial hippocampal memory module must compute, bridging the gap between biological memory theory and transformer-based architecture design.

## Why It Matters / Open Questions

The paper offers a concrete theoretical target for memory research in AI: if the eight computational requirements are necessary for higher-order cognition, they provide a checklist against which future memory architectures can be evaluated. Key open questions include whether LLM internal representations are sufficiently explicit to serve as input to such a module, how explicit memory should interact with the implicit transformer backbone, and how to empirically distinguish explicit from implicit processing in deployed models (the paper notes that rapid integration of failures into training data makes this difficult). As a position paper without new experiments, its impact depends on whether the community adopts the implicit-memory framing of LLMs and the proposed requirements as a design language for next-generation memory systems.

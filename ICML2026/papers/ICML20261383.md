## Problem

Flow matching VLA models generate actions through iterative denoising with global timestep injection, which invalidates standard KV-caching and forces a choice between prohibitively slow O(N²) recomputation or mathematically incorrect cache reuse. Beyond this computational bottleneck, the synchronous 'stop-think-act' execution pattern introduces reaction latency that causes failures in dynamic manipulation scenarios, as the robot must freeze while the full denoising chain completes before it can act on potentially stale observations.

## Input / Output

The system consumes a sliding FIFO window of N=10 RGB camera frames (~300ms history), a natural-language task instruction, and proprioceptive robot state, producing a chunk of 50 continuous actions per inference call at a 50Hz control frequency. Vision encoding and action generation are decoupled onto separate hardware threads, so the policy conditions on a predicted future state (approximated by the last commanded action) rather than the raw sensor reading at inference time, compensating for the asynchronous delay between observation capture and action execution.

## Method

Reflex exploits the Timestep Invariance Property (∂Enc/∂t_k = 0) to partition the attention context into three zones: a pinned static prefix (language instructions), a sliding observation window (last N frames), and a dynamic suffix (flow state + timestep embeddings), enabling O(1) incremental cache updates that produce outputs exactly identical to full-batch attention for fixed inputs. To prevent BFloat16 numerical collapse under infinite-horizon 50Hz streaming, AdaRMSNorm computes RMS statistics in FP32 and applies a conditional gating MLP conditioned on the sinusoidal timestep and proprioceptive state. An asynchronous pipeline overlaps vision encoding (producer thread) with flow-matching denoising (consumer thread), using adaptive overlap scheduling that dynamically adjusts the lookahead K based on measured inference latency, and a lightweight future-state predictor that substitutes the last commanded action for the stale sensor reading. Low-level optimizations include fused QKV/SwiGLU CUDA kernels (reducing kernel launches by 50%) and a pre-allocated static ring buffer that eliminates dynamic memory allocation during the control loop.

## Results

Reflex achieves a 2.58× inference speedup on LIBERO with Pi0.5 (135.2 ms → 52.4 ms) and 2.73× with the larger Pi0 model, while reducing end-to-end reaction latency by up to 54% (226.8 ms → 105.2 ms on LIBERO-Long, Pi0) and eliminating all control stalls (0% vs. 100% for the synchronous baseline). Task success is maintained at parity on LIBERO (e.g., 83.2% vs. 82.4% on Spatial, Pi0.5) with notable gains on multi-step LIBERO-Long (+3.6%) and the dynamic Kinetix benchmark (+7.4% for Pi0.5, +6.7% for Pi0). Peak GPU memory is reduced by 27% on LIBERO and 24% on Kinetix, and the system sustains stable 50 Hz streaming for over 2,000 steps without NaN/Inf events.

## Baselines & Comparisons

Reflex is compared against three baselines: Standard (synchronous full re-computation), Naive Cache (KV-caching that ignores flow-matching timestep conditioning), and Async-Naive (asynchronous inference without future-conditional scheduling). Against Standard, Reflex reduces reaction latency by 47–54% and eliminates the 100% stall rate entirely, while matching or slightly exceeding task success (e.g., 83.2% vs. 82.4% on LIBERO-Spatial, Pi0.5). Against Async-Naive, Reflex further cuts latency by roughly 30% (e.g., 82.5 ms vs. 122.0 ms on LIBERO Avg., Pi0.5) and reduces stall rate from 38–54% to 0%, yielding +3.6–4.0 pp success gains on LIBERO-Long and +7.4 pp on Kinetix. Naive Cache is a negative control: it produces mathematically incorrect outputs (MSE > 1.0) and collapses to ~12% task success, confirming that timestep-aware partitioning is essential. On the dynamic Kinetix benchmark, Reflex's latency advantage translates directly into larger success gains (+7.4% Pi0.5, +6.7% Pi0) compared to the more modest LIBERO improvements, highlighting the value of reduced reaction time under physical perturbations.

## Relation to Prior Work

Reflex builds on the Pi0/Pi0.5 flow matching VLA architecture (Black et al., 2025a) and the KV-caching paradigm from LLM serving (Kwon et al., 2023), but departs from both in critical ways. Prior VLA acceleration work (Black et al., 2025b; Ma et al., 2025; Shukor et al., 2025; Sendai et al., 2025) focused on speeding up individual denoising steps or scheduling async execution without addressing the fundamental incompatibility between global timestep injection and KV-cache validity. Reflex's key conceptual departure is identifying the Timestep Invariance Property of perception encoders to enable a three-zone cache partitioning that is mathematically exact (MSE = 0.00) rather than approximate, combined with AdaRMSNorm (extending Zhang & Sennrich, 2019) to solve a previously unaddressed BFloat16 numerical collapse problem in infinite-horizon streaming.

## Why It Matters / Open Questions

This work provides a concrete, deployable path to closing the order-of-magnitude gap between VLA inference latency (100-200ms) and robotic control frequency (50-100Hz), which is a prerequisite for dynamic manipulation tasks. The partitioned attention approach is architecturally constrained—it requires a timestep-invariant perception encoder—so unified DiT-style VLAs where timestep conditioning enters the vision pathway remain out of scope, limiting generality. Open questions include whether the exactness guarantee holds under distribution shift from the future-state predictor, how the approach scales to multi-robot or long-horizon (>1000 step) scenarios, and whether the 2.58× speedup translates to larger backbones (7B+) where the vision encoder dominates even more. The practical impact is significant for edge deployment, where the 27% memory reduction and 50Hz stability enable operation on consumer-grade GPUs.

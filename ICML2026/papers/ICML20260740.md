## Problem

In self-evolving LLM agents for CUDA kernel generation, planning decisions are conditioned on heterogeneous feedback (debugging, static analysis, runtime profiling), yet how individual feedback components shape generation-level planning outcomes remains opaque. Standard end-to-end ablation is ill-suited because iterative planning amplifies early perturbations, conflating feedback effects with trajectory-dependent drift and making causal attribution unreliable.

## Input / Output

The method takes frozen CUDA kernel program states at selected generations along with structured feedback reports from three tools (debugger, analyzer, profiler), which can be selectively injected, removed, or summarized via a SummaryAgent. It produces generation-level success rates under a partial ordering (compiled → pass → fast), Banzhaf marginal contribution values per feedback component, and pairwise/higher-order synergy terms that quantify non-additive interactions. A key constraint is that all interventions share an identical frozen program context and cached references, with a fixed number of code-generation retries (k=5) held constant across samples and generations.

## Method

CUDAnalyst introduces a unified analysis layer built on trajectory freezing: intermediate program states are frozen at selected generations, decoupling the current planning decision from the historical evolutionary trajectory, after which controlled patching interventions selectively withhold or inject specific feedback components while holding the planner, prompts, and decoding configuration fixed. Feedback attribution is formalized as a cooperative game where each tool is a player, and the Banzhaf value (rather than Shapley) is used because all enabled feedback components appear simultaneously in the planning input with no assumed ordering. Pairwise interaction terms (σ_ij) and three-way synergy terms capture non-additive dependencies among feedback components. The pipeline comprises three analysis modules (debugger, analyzer, profiler), an optional SummaryAgent for feedback abstraction, and a PlanAgent that consumes the unified report to produce a high-level plan, with every component independently toggleable for fine-grained attribution. This design enables stable generation-level evaluation without full trajectory re-execution, supporting four research questions spanning planning necessity, tool contribution, summarization effects, and cross-model plan transfer.

## Results

CUDAnalyst's generation-level Banzhaf attribution shows that explicit planning (φ_P) and feedback (φ_F) exhibit consistently positive synergy (σ_FP), with the joint effect exceeding the sum of individual contributions across all generations (e.g., σ_FP = 0.430 at generation 7 for DeepSeek-V3.2). The practical CuGEdit plugin, built on these invariance findings, achieves 2.08× to 10.32× speedup over torch.compile on KernelBench Level 3, surpassing both the OpenEvolve baseline and existing SOTA approaches. Cross-domain generalization to Numba N-body yields a 12.5× peak speedup under DeepSeek-R1 plan guidance. Strong-to-weak plan distillation (e.g., DeepSeek-R1-0528 → DeepSeek-V3.2) consistently improves weak-model execution success, with larger gains within the same model family.

## Baselines & Comparisons

This is an analysis paper rather than a method-vs-baseline comparison, so no external baselines are benchmarked head-to-head. Internally, the paper contrasts four configurations: implicit planning without feedback (NP+NF, the OpenEvolve default), explicit planning without feedback (P+NF), explicit planning with full feedback (P+F), and explicit planning with randomized feedback (P+RF). The key finding is that P+NF consistently degrades performance relative to NP+NF, while P+F yields stable generation-level gains, and P+RF harms all models—confirming that planning benefits are entirely contingent on feedback alignment. Across model strengths, weaker models (DeepSeek-V3.2, Qwen3-Coder-30B) benefit more from structured feedback-aligned plans and summarization, while stronger models (DeepSeek-R1-0528, Qwen3-235B-A22B) are largely insensitive to planner semantics and rely on internalized reasoning. The CuGEdit plugin, which operationalizes the identified invariances, outperforms both the unmodified OpenEvolve baseline and existing SOTA approaches on KernelBench Level 3, achieving 2.08×–10.32× speedup over torch.compile.

## Relation to Prior Work

This paper extends the self-evolving LLM agent framework for CUDA kernel generation (OpenEvolve/AlphaEvolve, Astra, STARK) by introducing a controlled attribution layer that decouples feedback from planning at fixed generations. Methodologically, it adapts activation patching (Zhang & Nanda, 2024) to the feedback-intervention setting and applies Banzhaf-value-based cooperative game theory to quantify marginal and interaction effects of heterogeneous feedback components. The key departure from prior work is the rejection of end-to-end ablation—which the authors argue conflates feedback effects with trajectory-dependent drift—in favor of trajectory-freezing with selective feedback injection, enabling generation-level causal attribution that was previously infeasible.

## Why It Matters / Open Questions

The paper provides a principled, computationally efficient methodology for credit assignment in multi-component LLM agent systems, with direct practical implications for designing feedback pipelines in self-evolving code agents. The finding that explicit planning is beneficial only when grounded in aligned feedback—and that strong models largely internalize planning—challenges the common assumption that adding a planning step always helps. Open questions include whether the frozen-trajectory abstraction captures cross-generation semantic evolution of kernel state (acknowledged as an open compiler research challenge), whether the Banzhaf attribution generalizes to non-stationary or population-based evolutionary settings, and whether the plan-transferability results extend beyond same-family model pairs.

## Problem

Foundation models remain fundamentally limited in continuous operation, experience accumulation, and personalization. Prior continual learning research focused almost exclusively on in-weight learning (IWL) of a monolithic model, making catastrophic forgetting a persistent challenge, while recent agent systems that rely solely on in-context learning (ICL) with a frozen core model face computational inefficiency at long contexts and cannot adapt to distribution shifts. The paper argues that no existing approach provides a principled, scalable architecture that jointly leverages both learning mechanisms for continual adaptation.

## Input / Output

The system consumes heterogeneous signals—user instructions, raw sensory inputs (text, images, video), demonstrations, and retrieved long-term memory embeddings—encoded into a capacity-limited working memory that conditions the core model via attention. Outputs include environment-directed responses or actions, new entries written to long-term memory (as raw data, latent embeddings, or KV-cache vectors), and, during sparse internal consolidation phases, updated core model parameters. A key structural detail is the two-regime operation: an external, environment-driven regime for fast ICL-based adaptation, and an internal, self-driven regime for slow IWL-based consolidation that compresses and reorganizes long-term memory while distilling generalizable knowledge into the core model.

## Method

The paper proposes a modular memory framework with three distinct components: a pretrained core model (perception, reasoning, action), a transient working memory (active context, retrieved memories, intermediate reasoning traces), and a persistent long-term memory (facts, episodes, personalized experiences). The core mechanism is a complementary learning loop: ICL enables rapid, few-shot adaptation by injecting stored embeddings into the core model's attention layers without parameter changes, while IWL drives infrequent consolidation that distills accumulated long-term memory into core model weights for higher-level generalization and efficiency gains. Memory representations span slot-based formats (raw data, activation-based embeddings, KV-cache vectors, learned soft prompts) and distributed neural memories (slow gradient-based or fast associative updates), each with distinct trade-offs in storage efficiency, interference, selective forgetting, and generalization. The framework further specifies design dimensions for memory organization (flat, hierarchical, or graph-based structures), update/forgetting/retrieval policies operating across multiple timescales, and consolidation strategies that combine compressed memory representations, modular parameter specialization, and on-policy training objectives to reduce forgetting.

## Results

This is a position paper that proposes a conceptual framework rather than reporting quantitative experimental results. The paper does not evaluate on benchmarks or report accuracy/loss numbers. Its central contribution is a design framework combining In-Context Learning (ICL) via working and long-term memory with low-frequency In-Weight Learning (IWL) consolidation into a pretrained core model, grounded in complementary learning systems theory from neuroscience and memory hierarchy principles from computer architecture.

## Baselines & Comparisons

As a position paper, this work does not run empirical comparisons against baselines. Instead, it argues conceptually against two alternative paradigms: (1) infinite/long context + RAG, which it criticizes for computational cost scaling with context length, performance degradation at long contexts, sensitivity to linguistic variation, and lack of selective forgetting mechanisms; and (2) continual parametric updates (traditional CL / test-time training), which it argues remain costly at scale, require per-update hyperparameter tuning, and are prone to catastrophic forgetting even with sparse updates like LoRA. The paper's position is that combining ICL (fast, memory-mediated adaptation) with infrequent IWL (slow consolidation) offers a more efficient long-term trade-off than either mechanism alone, though no quantitative evidence is provided to support this claim.

## Relation to Prior Work

This position paper synthesizes three largely separate literatures—classical continual learning (rehearsal, regularization, catastrophic forgetting), foundation-model agent memory (RAG, KV-cache, soft prompts, context windows), and neuroscience/computer-architecture memory hierarchies (complementary learning systems, hippocampal replay, cache eviction policies)—into a unified modular memory framework. It departs from the traditional CL view of memory as a forgetting-mitigation buffer and from the current LLM-agent view of a frozen core model with ever-growing context, instead proposing a dual-timescale architecture where ICL handles fast episodic adaptation and IWL handles slow parametric consolidation. The closest prior work (Liu et al., 2025, combining RAG with periodic fine-tuning) is explicitly critiqued for lacking principled consolidation, multimodal support, and true continual evaluation, positioning this paper as the missing architectural blueprint.

## Why It Matters / Open Questions

The paper identifies a concrete gap: current LLM agent memory systems are conversation-local, grow without principled forgetting or consolidation, reduce multimodal information to text, and evaluate in static offline settings rather than true continual regimes. By framing modular memory (working + long-term) as the bridge between ICL and IWL, it provides a conceptual roadmap that could realign the CL community and the LLM-agent community, which have been developing somewhat independently. Key open questions remain: how to design learned consolidation and forgetting policies, how to handle multimodal memory representations, how metacognitive control should gate retrieval and update decisions, and whether the proposed architecture scales to truly open-ended, long-horizon deployment. As a position paper it offers no empirical validation, so its impact depends on whether the community adopts the framing as a productive research agenda.

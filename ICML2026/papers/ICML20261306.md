## Problem

Black-box prompt tuning for vision-language models faces a fundamental trade-off: soft prompts optimized via derivative-free methods are opaque and require extensive API queries, while hard prompts generated by RL-based LLM agents suffer from a cold-start problem that wastes queries on low-quality prompts through blind exploration of the vast discrete token space. No existing method simultaneously achieves human-readable prompt interpretability and efficient convergence under a tight API budget.

## Input / Output

The method takes an RGB image and a fixed task context (meta-instructions describing the classification goal) as input to the LLM policy agent, which generates a discrete text prompt of fixed length (15 tokens, 20 for CLEVR). This prompt is concatenated with the image and fed to the black-box CLIP ViT-B/16 model via API queries only, producing a class label and probability distribution. The entire optimization is constrained to 2,000 API calls with no access to model parameters or gradients.

## Method

CRL-BPT employs Qwen2.5-3B-Instruct (fine-tuned via LoRA) as a PPO policy agent that generates interpretable prompts, regularized by a curriculum learning strategy with two auxiliary losses: an imitation loss (ROUGE-L-weighted NLL against a reference set of top-performing CLIP templates) and an innovation loss (NLL weighted by novelty score relative to a 100-prompt history buffer). A dynamic exponential decay schedule (γ=2) shifts the weighting from imitation-dominant early in training to innovation-dominant later, guiding the agent from mimicking known patterns to discovering novel prompt structures. Two stabilization mechanisms ensure robust training: historical loss normalization (EMA-based scaling of each loss term to equalize magnitudes) and relative reward calibration (subtracting a batch-difficulty bias estimated from a fixed baseline prompt, with the optimal correction coefficient η* derived as Cov(r_π, r_base)/Var(r_base) to minimize reward variance while preserving unbiasedness).

## Results

Under a strict budget of 2,000 API calls, CRL-BPT achieves a 16-shot average accuracy of 64.0% across 13 datasets, ranking first on 12 of 13. It surpasses the strongest soft-prompt baseline ZIP by 2.8% and the leading hard-prompt baseline StablePrompt by 3.8%. In base-to-new generalization, CRL-BPT attains 71.6% on base classes, 69.5% on new classes, and a harmonic mean of 70.1%, outperforming StablePrompt by 2.6% on the harmonic mean. For OOD generalization, CRL-BPT reaches 58.4% average across four ImageNet variants (+1.2% over StablePrompt).

## Baselines & Comparisons

CRL-BPT outperforms all six baselines on average across the 13-dataset few-shot benchmark. Against the strongest soft-prompt method ZIP (61.2%), CRL-BPT gains +2.8% on average, with particularly large margins on fine-grained datasets (Flowers: +6.6%, DTD: +1.3%) and action recognition (UCF: +2.2%). Against the leading hard-prompt RL method StablePrompt (60.2%), the gap is +3.8% on average, with CRL-BPT winning on 12 of 13 datasets. The earlier derivative-free methods show larger gaps: BAR (58.4%, −5.6%), BlackVIP (57.7%, −6.3%), and BPTVLM (57.3%, −6.7%). Notably, CRL-BPT also leads in base-to-new generalization (harmonic mean 70.1% vs. StablePrompt 67.5% and ZIP 66.3%) and OOD robustness (58.4% vs. 57.2% and 55.6%), confirming that the curriculum-guided exploration yields more generalizable prompts rather than overfitting to the source domain.

## Relation to Prior Work

This paper extends the RL-based hard prompt tuning paradigm established by StablePrompt (Kwon et al., 2024) and RLprompt (Deng et al., 2022) to the black-box VLM setting, where gradients are inaccessible and only API queries are available. The key departure is the introduction of a curriculum learning schedule that dynamically shifts the optimization objective from imitating reference prompts to innovating novel patterns, addressing the cold-start problem that plagues prior RL-based prompt methods. The stabilization mechanisms (historical loss normalization and relative reward calibration) are novel engineering contributions not present in prior BBPT work, which typically relies on raw PPO updates without scale alignment or variance reduction.

## Why It Matters / Open Questions

The practical relevance is significant: under a strict 2,000-query budget (half the 5,000 used by prior work), CRL-BPT achieves consistent SOTA across 13 diverse datasets while producing human-readable prompts, making it directly applicable to commercial MaaS deployments where API costs are a real constraint. The finding that a compact 3B LLM suffices (with <1% gap to 7B) further lowers the computational barrier. Open questions include whether the curriculum schedule generalizes to multi-turn or multi-prompt settings, whether the approach extends to generative VLMs beyond CLIP-style classifiers, and whether the reference set requirement (even if not highly sensitive) limits fully autonomous deployment.

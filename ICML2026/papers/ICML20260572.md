## Problem

Existing agent benchmarks assume full task automation with no user feedback, failing to capture the collaborative nature of real-world human-agent interactions. No rigorous evaluation protocol or large-scale empirical results existed for measuring how agent design choices (LLM backbone, planning, memory) affect actual user satisfaction in deployed systems.
![Teaser figure](../imgs/ICML20260572/cropped_page1_idx0.webp)

## Input / Output

The method consumes user-agent interaction trajectories (sequences of agent actions and observations spanning tens of thousands of tokens) paired with sparse 5-star ratings that cover only ~5% of sessions, along with the agent design configuration being tested. It produces effect size estimates (Δ) with 95% confidence intervals for A/B comparisons, predicted satisfaction scores for unlabeled trajectories, and statistical significance verdicts. A key constraint is the extreme label sparsity: the framework must leverage roughly 20× more unlabeled trajectories to achieve tight confidence intervals from only ~150 labeled samples per condition.

## Method

PULSE is a three-step framework: (1) collect 5-star ratings after each 'work segment' (one user command through agent completion), (2) train a supervised ML model (random forest, gradient boosting, or ordinal logistic regression) on 15 hand-crafted features—user sentiment, agent failure modes (misunderstood intent, insufficient testing, etc.), and git-based task progression signals—to predict satisfaction for unlabeled trajectories, and (3) apply prediction-powered inference (PPI) to combine the small labeled set with the large unlabeled pool, yielding an augmented effect size estimator with valid confidence intervals. The 15 features are extracted via LLM-as-a-judge for behavioral categories and event-stream parsing for git actions. The core statistical insight is that PPI's correction term uses the labeled data to calibrate systematic prediction error, reducing CI width by ~40% over a standard A/B test without requiring the predictor to be unbiased. Deployed on OpenHands across 15k users and 36k sessions, the framework revealed that LLM backbone choice (Δ=6–8%) dominates scaffolding changes (Δ<3%) in user satisfaction, and that benchmark rankings (e.g., gpt-5 vs. claude-sonnet-4) can be anti-correlated with human preferences.

## Results

Across 15k users and 36k sessions on the OpenHands platform, LLM backbone choice drives the largest user satisfaction differences: claude-4-sonnet outperforms claude-3.7-sonnet by 5.86% (Δ_augment = 0.050, 95% CI [0.020, 0.081], significant) and outperforms gpt-5 by 7.83% (Δ_augment = −0.069, 95% CI [−0.116, −0.021], significant). Scaffolding changes yield smaller effects: showing the agent's plan improves satisfaction by 3.1% (Δ_augment = 0.031, 95% CI [0.014, 0.049], significant), while reducing memory max_step from 120 to 80 shows no significant change. PULSE reduces confidence interval widths by an average of 39.5% compared to a standard A/B test, and the best ML predictor (Random Forest) achieves a correlation of 0.29 with user ratings, outperforming LLM-as-a-judge baselines (o3: 0.22, gemini-2.5-pro: 0.14, claude-4: 0.23) by at least 26%.

## Baselines & Comparisons

The paper's primary baseline comparison is between PULSE's ML-based satisfaction predictors (Logistic Regression, HistGradientBoosting, Random Forest) and LLM-as-a-judge approaches (o3, gemini-2.5-pro, claude-4) that receive the full raw trajectory. Random Forest achieves the best correlation with human ratings (0.29) and lowest MAE (1.02), outperforming the best LLM baseline (o3, correlation 0.22, MAE 1.87) by 26% in correlation and 45% in MAE; gemini-2.5-pro performs worst (correlation 0.14, MAE 2.05). All LLM judges are systematically more pessimistic than human raters (e.g., o3 rarely assigns a 5). On the statistical efficiency front, PULSE's augmented estimator (Δ_augment) narrows confidence intervals by 39.5% on average versus the naive A/B test (Δ_naive), and converts two non-significant results (Claude-3.7 vs. Claude-4, and Planning vs. No-Plan) into statistically significant ones. Finally, the paper shows that benchmark performance (across 7 code benchmarks including SWE-Bench, SWT-Bench, and GAIA) does not reliably predict human preference: for the claude-4-sonnet vs. gpt-5 comparison, the Pearson correlation between human rating differences and benchmark differences is ρ = −0.18, meaning gpt-5's benchmark advantage does not translate into user satisfaction.

## Relation to Prior Work

This paper extends prediction-powered inference (PPI) from Angelopoulos et al. (2023) to the human-agent interaction setting, where no natural prediction model f exists for user satisfaction over complex agentic trajectories. It departs from the dominant paradigm of static, fully-automated agent benchmarks (SWE-Bench, WebArena, etc.) and from prior human-in-the-loop studies that evaluate a single system without varying design choices. The feature-based satisfaction prediction draws on dialogue and task-oriented dialogue literature, but adapts it to trajectories that couple language with state-changing tool invocations and environment observations—a setting where the authors show standard LLM-as-a-judge approaches underperform simpler ML models.

## Why It Matters / Open Questions

The finding that benchmark performance and human ratings can be anti-correlated (ρ = −0.18 for claude-4-sonnet vs. gpt-5) challenges the field's reliance on static benchmarks as proxies for real-world agent quality, suggesting that deployment-specific factors (interactivity, error recovery, user engagement) matter substantially. PULSE's ~40% confidence-interval reduction over standard A/B tests makes large-scale agent design experiments more feasible with the sparse feedback typical of production systems. Key limitations include evaluation on a single platform (OpenHands), reliance on 5-star ratings without explicit label-noise modeling, and privacy constraints preventing release of raw trajectories—leaving open whether findings transfer to other agent domains and whether richer, noise-aware metrics would shift the conclusions.

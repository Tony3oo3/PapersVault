## Problem

Classical randomized data structures for approximate furthest neighbor search (e.g., Indyk's 2003 projection-based algorithm) assume queries are fixed in advance, but many ML pipelines generate queries adaptively based on prior answers. The best prior adaptive result required Õ(n+d) query time (a linear scan), leaving open whether sublinear-in-n query time is achievable under full adaptivity. This paper answers affirmatively and additionally demonstrates that Indyk's oblivious algorithm provably fails against adaptive queries.

## Input / Output

The data structure is built once on a fixed point set P ⊂ R^d of n points and then serves an unbounded sequence of adaptively chosen query points q ∈ R^d, where each q_i may depend on all previous answers. For each query it returns a single point p ∈ P satisfying ‖p−q‖ ≥ (1/c)·max_{x∈P}‖x−q‖. The query time is Õ(min(dn^{1/c²}, n^{2/c²}+d)) and space is Õ(dn^{2/c²}+d²n^{1/c²}), with Õ(d²n^{1+1/c}) preprocessing. The guarantee holds with high probability over internal randomness regardless of the adaptive strategy, and even against a white-box adversary who observes the algorithm's random bits.

## Method

The construction is a three-step robustification of Indyk's random-projection base. First, the base data structure is strengthened with a slack parameter δ=1/n via 'good projections' and 'outlier projections' (Definition 2.1), ensuring that if a query q is (c,δ)-good for a projection matrix A, then any q′ within Δ/(n³√d) is c-good deterministically. Second, k = Õ(d) independent copies of the base DS are instantiated, and a grid of spacing bw(P)/(dn³) over a ball of radius R = (1+c)√d·bw(P)/(2(c−1)) around the dataset center is used to union-bound correctness over all non-trivial queries, yielding a scale-free covering that depends only on the dataset diameter. Third, at query time only m = O(log n) randomly sampled base DS copies are consulted to collect O(N) candidates, which are then either scored by direct distance computation (giving Õ(dn^{1/c²})) or passed through the robust distance-estimation framework of Cherapanamjeri & Nelson as a black-box (giving Õ(n^{2/c²}+d) with a c(1+ε) approximation). The paper also constructs an explicit adaptive attack that aligns the query with the random projections to force Indyk's oblivious algorithm to return a point d^{0.49}× farther than the true furthest neighbor.

## Results

The paper achieves the first adversarially robust sublinear query time for c-approximate furthest neighbor search: Õ(d·n^(1/c²)) for a c-approximation, and Õ(n^(2/c²)+d) for a c(1+ε)-approximation, both under full adaptivity. Space usage is Õ(d·n^(2/c²) + d²·n^(1/c²)) and Õ(d²·n^(2/c²)) respectively, with Õ(d²·n^(1+1/c)) preprocessing. The n-dependency matches the best oblivious algorithm (Indyk 2003) while the d-dependency is improved in the second variant. For d = poly(log n), the first query time is sublinear in n for all c > 1; for c > √2, the second query time is sublinear in n for all d = o(n).

## Baselines & Comparisons

The paper's main comparison is against two prior results. Against Indyk (2003), the oblivious c-approximate AFN algorithm with Õ(d·n^(1/c²)) query time, this paper matches the n-dependency exactly while providing adversarial robustness — a strict improvement since Indyk's algorithm provably fails under adaptive queries (Section 3 constructs an explicit attack). Against Cherapanamjeri & Nelson (2020), whose adaptive distance estimation framework yields Õ(n+d) query time for AFN via linear scan, this paper improves the query time to Õ(d·n^(1/c²)) or Õ(n^(2/c²)+d), which is strictly better for a wide range of natural parameters (e.g., sublinear in n when d = poly(log n) or c > √2). The paper also demonstrates a strict separation from differential-privacy-inspired robust frameworks, which require query-size-dependent bounds and periodic rebuilding, whereas this method works against a white-box adversary with no such dependencies.

## Relation to Prior Work

This paper extends Indyk's (2003) oblivious random-projection algorithm for c-approximate furthest neighbor search into the adaptive query model introduced by Cherapanamjeri & Nelson (2020). The key technical contribution is a three-step robustification recipe—adding slack guarantees to the base projection structure, union-bounding over a diameter-based covering grid, and sampling a logarithmic number of base structures combined with the robust distance estimation framework—that achieves the same Õ(d·n^{1/c²}) query time as the oblivious algorithm under full adaptivity. The paper also demonstrates that Indyk's original oblivious data structure provably fails under adaptive queries, establishing that robustification is not merely a technicality but a necessity.

## Why It Matters / Open Questions

This resolves the open question of whether sublinear-in-n query time is achievable for adaptive approximate furthest neighbor search, matching the best oblivious bound and improving upon the prior Õ(n+d) guarantee for a wide range of parameters (e.g., sublinear in n whenever d = poly(log n)). The three-step robustification recipe is presented as a generic template potentially applicable to other geometric search problems, and the white-box adversary guarantee (correctness even when internal randomness is revealed) provides a strict separation from differential-privacy-based approaches that require periodic rebuilding. Open questions include whether the space bounds can be tightened, whether the approach extends to other extremal search problems (e.g., adaptive nearest neighbor with sublinear query time), and whether the covering-grid construction can be made more efficient in high dimensions.

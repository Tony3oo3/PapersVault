## Problem

Existing LLM cultural value benchmarks suffer from a Construct-Composition-Context (C³) challenge: discriminative multiple-choice formats probe value knowledge rather than true orientations, item-averaged scores erase intra-cultural subgroup heterogeneity, and constrained question paradigms diverge from the open-ended generation settings in which LLMs are actually deployed. No prior method simultaneously addresses all three gaps while remaining grounded in naturally occurring human text.

## Input / Output

DOVE takes as input a set of human-written long-form documents (essays, blogs, ~1,034 tokens average) from a target culture and LLM-generated documents on the same 824 shared topics, plus a pre-constructed value codebook of K natural-language value codes. It produces a per-culture alignment score r ∈ [0,10] (rescaled debiased UOT distance), a K-dimensional probability vector representing the value code distribution for each source, and the full K×K transport plan π. The codebook itself is built from ~10,676 documents (human + LLM-generated) via iterative optimization, and the value recognizer q_ω is an off-the-shelf LLM (GPT-5.2) that extracts M′ value expressions per document and soft-assigns them to codes via embedding similarity.

## Method

DOVE's first component constructs a compact value codebook by formulating codebook optimization as a rate-distortion variational objective (a VQ-VAE analogue with a VampPrior), solved via black-box variational EM where an LLM serves as both the value recognizer q_ω and the reconstruction decoder p_φ. The objective balances three terms: reconstruction fidelity (information preservation), per-document code entropy (redundancy reduction), and global code-usage entropy (coverage), with iterative split/merge operations that grow or shrink the codebook based on per-code distortion and activation counts. The second component measures alignment via Unbalanced Optimal Transport over the K value codes as centroids, where the cost matrix D_{i,j} combines semantic distance ρ(c_i, c_j) with a co-occurrence penalty derived from human documents, and the UOT formulation (solved by Sinkhorn iteration with a debiasing correction) tolerates mass imbalance to capture intra-cultural distributional structure rather than reducing to a single averaged score.

## Results

DOVE achieves a 31.56% average Pearson correlation with downstream cultural harmful content detection tasks (predictive validity), substantially outperforming the best baseline CDEval (23.56%) and all other methods. On construct validity via value priming, DOVE shows the strongest induced score shift (Δ^g = 5.60%) and the most negative shift for opposing cultures (Δ^{g⁻} = −5.38%), confirming it detects injected value orientations. DOVE also attains the highest convergent validity (δ_con = 6.00%) among all methods, while maintaining acceptable discriminant validity (δ_dis = 0.89%).

## Baselines & Comparisons

DOVE outperforms all five baselines on predictive validity (downstream task correlation), achieving 31.56% versus CDEval's 23.56%, WVS's 16.20%, NormAd's 0.90%, GOQA's −13.05%, and NaVAB's −20.77%. On value priming (construct validity), DOVE shows the largest positive shift for the target culture (5.60%) and the strongest negative shift for opposing cultures (−5.38%), while constrained methods like WVS (0.08%) and GOQA (−1.56%) fail to detect the induced value orientation at all. CDEval slightly edges DOVE on discriminant validity (1.79% vs. 0.89%), but DOVE dominates on convergent validity (6.00% vs. CDEval's −14.40%), indicating its scores are more consistent across methods measuring the same construct. GOQA and NaVAB exhibit strongly negative predictive validity, suggesting their scores are inversely related to real-world cultural task performance. In a secondary comparison (Table 3), DOVE's UOT metric (31.56%) also surpasses MAUVE applied to the same value code representation (29.78%), confirming the added benefit of the value-aware transport cost over generic distributional divergence.

## Relation to Prior Work

DOVE departs from the dominant discriminative paradigm in LLM cultural value evaluation (WVS, GOQA, CDEval, NormAd, NaVAB), which the authors formalize as the C³ challenge: probing value knowledge rather than orientations, averaging away intra-cultural heterogeneity, and mismatching real open-ended deployment. Methodologically, it repurposes the VQ-VAE variational framework (Van Den Oord et al., 2017) and VampPrior (Tomczak & Welling, 2018) into a rate-distortion objective for constructing a value codebook from raw documents, and reformulates Unbalanced Optimal Transport (Chizat et al., 2018) as a value-distribution divergence metric. The codebook construction is implemented via black-box optimization with off-the-shelf LLMs as encoder/decoder, drawing on the BBO and ICL literature rather than gradient-based training.

## Why It Matters / Open Questions

As LLMs are deployed across culturally diverse user bases, a valid and reliable evaluation of cultural value alignment is essential for safety and engagement, yet prior benchmarks show weak or even negative correlation with downstream cultural tasks. DOVE's distributional formulation captures subgroup diversity and intra-cultural structure that item-averaging discards, and its 31.56% predictive validity (vs. ≤23.56% for baselines) suggests a more faithful signal. Limitations include coverage of only four East-Asian/Western cultures, dependence on proprietary LLMs (GPT-5.2) for the value recognizer, and the computational cost of iterative codebook construction. Open questions include scalability to dozens of cultures, whether the codebook transfers across domains, and whether the UOT metric's advantage over simpler divergences (e.g., MAUVE) persists at larger scale.

## Problem

Prompt optimization for LLM-based Multi-Agent Systems (MAS) with fixed, expert-validated workflows is a combinatorial black-box problem hampered by three coupled difficulties: prohibitively expensive end-to-end evaluations, topology-induced coupling where upstream prompt changes shift downstream input distributions, and exponential growth of the joint prompt space. Existing single-agent optimizers ignore inter-agent dependencies, while multi-stage optimizers like MIPRO capture them only implicitly, making them sample-inefficient under tight evaluation budgets.

## Input / Output

The method takes a fixed MAS workflow DAG (agents as nodes, information-flow edges), a candidate prompt set of 20 variants per agent (generated via style-controlled LLM paraphrasing that preserves role and placeholders), and a validation dataset. Each prompt is encoded into a 1024-dimensional embedding via Qwen3-Embedding-8B. The output is a single optimized prompt combination (one prompt per agent) selected under a fixed budget of 50 end-to-end MAS evaluations using GPT-4o-mini as the backbone LLM, with final performance reported on a held-out test set averaged over three runs.

## Method

MASPOB integrates three components into a unified optimization loop. First, a Graph Attention Network (GAT) surrogate takes prompt embeddings as node features and the workflow DAG as graph structure, performing multi-head attention-based message passing to predict the performance of a prompt combination, providing a topology-aware exploitation signal. Second, a LinUCB contextual bandit maintains an information matrix over concatenated prompt embeddings to estimate epistemic uncertainty in closed form; the UCB acquisition score combines the GNN prediction with an uncertainty bonus (α·σ) to balance exploitation and exploration. Third, coordinate ascent decomposes the joint combinatorial search into sequential single-agent subproblems, reducing per-iteration complexity from O(∏|P_i|) to O(Σ|P_i|), with an optional block-coordinate variant for strongly coupled topologies. The procedure begins with a 5-round random warm-up to initialize the GNN, then iteratively selects the next combination via UCB-guided coordinate ascent, executes the full MAS to obtain a validation score, and updates both the GNN parameters and the information matrix.

## Results

MASPOB achieves the best result on all six benchmarks with an average score of 80.58%, improving by 12.02% over the IO baseline, 2.06% over AFlow, and 1.71% over MIPRO under a matched validation budget of 50 evaluations. Per-benchmark, MASPOB scores 75.43% (HotpotQA), 82.28% (DROP), 94.15% (HumanEval), 80.65% (MBPP), 93.90% (GSM8K), and 57.05% (MATH). The method also generalizes to more complex MAS topologies (82.02% avg. on 7–8 agent structures) and to a different backbone LLM (Qwen3-32B, 83.43% avg.).

## Baselines & Comparisons

MASPOB outperforms all seven baselines on every benchmark. Against single-agent prompting baselines (IO, CoT, ReAct), MASPOB gains 9.2–12.0% in average score, confirming that multi-agent coordination plus prompt optimization substantially exceeds single-pass or single-agent strategies. Against single-agent prompt optimizers (PromptBreeder, Instinct), MASPOB leads by 6.6–6.9%, showing that topology-aware multi-agent optimization captures inter-agent coupling that isolated prompt refinement misses. The most competitive comparisons are against the multi-agent baselines: MASPOB beats AFlow by 2.06% and MIPRO by 1.71% on average, with the largest per-benchmark gaps on DROP (+2.80% over AFlow, +3.15% over MIPRO) and MATH (+3.22% over AFlow, +2.15% over MIPRO), tasks where multi-hop reasoning and multi-step computation create strong upstream–downstream prompt dependencies. On MBPP, MASPOB ties MIPRO at 80.65% but with lower variance (±0.29 vs. ±0.36). Ablations confirm the GNN surrogate contributes +2.31% average over an MLP replacement, and the LinUCB uncertainty bonus contributes +2.41% over a neural uncertainty estimator.

## Relation to Prior Work

MASPOB sits at the intersection of three research threads: (1) automated prompt optimization (OPRO, PromptBreeder, TextGrad), which has been studied almost exclusively for single-agent settings; (2) multi-stage prompt optimization for pipelines (MIPRO/DSPy), which captures inter-stage dependencies only implicitly via TPE and remains topology-agnostic; and (3) contextual bandits (LinUCB) and GNNs for combinatorial optimization. The paper's key departure is explicitly encoding the MAS workflow DAG as a graph structure for the surrogate model and coupling it with a closed-form linear UCB bonus, rather than treating the joint prompt space as an unstructured vector. Coordinate ascent is borrowed from classical optimization to tame the combinatorial search, and the GAT surrogate follows standard multi-head attention message passing.

## Why It Matters / Open Questions

The practical motivation is strong: in regulated domains (medical SOPs, financial auditing), workflow topologies are frozen by compliance requirements, making prompt optimization the only viable performance lever. MASPOB provides a concrete, sample-efficient recipe (GNN surrogate + LinUCB + coordinate ascent) that practitioners can deploy under tight evaluation budgets. However, the gains over the strongest multi-agent baselines (AFlow, MIPRO) are modest (~2% average), and the method assumes a static DAG with no cross-agent feedback cycles or dynamic routing, limiting applicability to more flexible agentic architectures. Open questions include scalability to larger agent counts (the full information matrix inversion becomes costly), whether the GNN surrogate generalizes to heterogeneous prompt domains of very different sizes, and how the approach performs when the workflow itself is co-optimized with prompts.

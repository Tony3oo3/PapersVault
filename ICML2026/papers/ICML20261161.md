## Problem

While function vectors have been shown to encode task representations in large language models, their extension to large multimodal models for extracting and manipulating visual relations remains unexplored. It is unclear whether LMMs encode spatial and agentic relational knowledge in localized internal structures that can be systematically identified, extracted, and optimized to improve relational reasoning without in-context demonstrations.
![Teaser figure](../imgs/ICML20261161/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images containing multiple objects (synthetic 800×800 images with six objects, or real GQA images with 4–7 objects) paired with a text query specifying the reference object, and produces the text label of the object that instantiates the target visual relation. For composite analogy tasks, an additional source image showing a relation pair is used solely to compute mixture weights. The extracted function vectors are compact vectors in the model's hidden-state dimension, injected at a single intermediate layer (layer 19 for synthetic, layer 8 for GQA) at the last-token position, and can be fine-tuned or linearly combined without modifying any model parameters.

## Method

The paper applies causal mediation analysis to LMMs by computing Average Indirect Effect (AIE) scores for each attention head: activations are replaced with relation-specific mean activations on perturbed prompts, and the resulting change in correct-answer probability identifies the top 10 causally influential heads per relation. The function vector for each relation is the sum of mean activations from these selected heads, extracted from 4-shot in-context learning prompts. At inference, the vector is added to the hidden state at an intermediate layer of a zero-shot prompt to elicit relational predictions without any demonstrations. The vectors can then be fine-tuned via negative log-likelihood on zero-shot examples while all model parameters remain frozen, yielding substantial gains over both zero-shot and 4-shot ICL baselines. For untrained composite relations (e.g., above-left), relation-specific vectors are linearly combined with weights inferred from a single source analogy example, enabling one-shot generalization to novel spatial relations.

## Results

On the Synthetic dataset with novel objects, fine-tuned function vectors (FFVs) achieve 72.2% top-1 accuracy for Qwen3-VL (vs. 23.3% for initial FV and 21.3% for 4-shot ICL) and 13.6% for OpenFlamingo (vs. 11% initial FV and 9.4% ICL). On GQA Spatial, FFVs more than double the zero-shot baseline accuracy and outperform both 4-shot ICL and initial FVs for both models. For one-shot analogy with untrained composite relations (e.g., above-left), composite function vectors (CFVs) improve accuracy from 8.1% (4-shot ICL) to 16.8% on OpenFlamingo and from 28.7% to 45.1% on Qwen3-VL.

## Baselines & Comparisons

The paper compares four settings: zero-shot LMM, 4-shot in-context learning (ICL), initial (untrained) relation-specific function vectors, and fine-tuned function vectors (FFVs). FFVs consistently outperform all three baselines across both models and all three datasets (Synthetic, GQA Spatial, GQA Agentic). On the Synthetic dataset with novel objects, Qwen3-VL's FFV reaches 72.2%, a ~3x improvement over 4-shot ICL (21.3%) and ~3x over the initial FV (23.3%). On GQA Spatial, FFVs more than double the zero-shot baseline for OpenFlamingo and surpass 4-shot ICL for both models. For the one-shot analogy task with untrained composite relations, CFVs beat 4-shot ICL by 8.7 points on OpenFlamingo (16.8% vs. 8.1%) and by 16.4 points on Qwen3-VL (45.1% vs. 28.7%), demonstrating that linearly combined relation vectors generalize to unseen relational compositions.

## Relation to Prior Work

This paper directly extends the function vector framework of Todd et al. (2024) from language-only LLMs to large multimodal models, applying causal mediation analysis to identify attention heads that encode visual relations. It departs from prior multimodal task vector work (Hojel et al., 2024; Huang et al., 2024), which targeted visual prompting tasks like style modification or object naming, by focusing specifically on relational reasoning (spatial and agentic relations). The composite function vector approach for analogy draws on the linear representation hypothesis (Park et al., 2023) and word-embedding analogy (Mikolov et al., 2013), but applies it to activation-space vectors in a multimodal setting rather than static embedding spaces.

## Why It Matters / Open Questions

The paper demonstrates that visual relational knowledge in LMMs is localized in a sparse set of attention heads and can be extracted, fine-tuned (with the backbone frozen), and linearly composed to handle untrained relations—offering a lightweight, interpretable mechanism for improving relational reasoning without full model fine-tuning. However, absolute accuracy remains modest (e.g., ~45% on synthetic analogy for Qwen3-VL), the evaluation covers only a narrow set of spatial and agentic relations, and the composite vector approach still requires a source example to determine mixture weights. Open questions include whether the framework generalizes to more diverse relation types (physical, social), whether it scales to larger or architecturally different LMMs, and whether the linear composition property holds beyond simple spatial combinations.

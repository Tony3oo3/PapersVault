## Problem

Existing constructive proofs for universal approximation of permutation-invariant functions via sum-decomposable architectures (e.g., DeepSets) require a latent dimension scaling linearly with set size N, creating a severe scalability bottleneck for large-scale applications. This paper asks whether this O(N) barrier can be broken for a natural and broad function class, and answers affirmatively for Wasserstein-stable functions—those Lipschitz continuous with respect to the Wasserstein-1 metric—by proving that a latent dimension logarithmic in N suffices for uniform approximation.

## Input / Output

The method takes an unordered multiset of N points in a compact domain K = [0,1]^D and produces a scalar output. The input is consumed as an empirical measure μ_x = (1/N)Σδ_{x_i}, and the target function F is assumed to be L_F-Lipschitz with respect to the Wasserstein-1 distance on this measure space. The architecture is a DeepSets model h(x) = ρ((1/N)Σψ(x_i)) where ψ: K→R^m is a pointwise encoder and ρ: R^m→R is a continuous decoder, with the critical parameter being the latent width m.

## Method

The constructive proof proceeds in four stages. First, the space of empirical measures is discretized into a maximal ε-separated net Q_ε whose log-cardinality is O(ε^{-D} log(N+ε^{-D})), growing only logarithmically in N via a stars-and-bars counting argument. Second, a multiscale Random Fourier Feature encoder Ξ embeds this net into R^m using cosine features sampled at dyadic frequency scales 2^s with geometrically decaying weights w_s = 2^{-2s}, which simultaneously guarantees global W_1-Lipschitz stability (via a convergent geometric series) and Hölder separation of strength W_1^{(D+6)/2} for all net pairs with high probability. Third, the McShane-Whitney extension theorem constructs a globally β-Hölder-continuous decoder ρ that exactly interpolates target values on the embedded net. Fourth, a triangle inequality decomposes the total error into a discretization term (L_F·ε) and a latent stability term (L_F·ε^β), yielding the uniform bound C̃_D·L_F·ε^{2/(D+6)} with m = O(C_D·ε^{-(3D+4)}·log(N+ε^{-D})).

## Results

The main theoretical result (Theorem 1) establishes that a latent width of m = O(C_D ε^-(3D+4) log(N + ε^-D)) suffices for uniform approximation of Wasserstein-stable permutation-invariant functions with error O(L_F ε^β), where β = 2/(D+6). For fixed accuracy ε and dimension D, this width grows only logarithmically in the set size N, breaking the O(N) linear barrier of prior constructive bounds. Empirically, on geometric median estimation (D=16), training RMSE remains below 0.01 across N ∈ [10², 10⁵] at fixed m=256, and the critical latent dimension m* (RMSE < 10⁻²) stabilizes at 8 for N ≥ 10⁴, confirming the predicted logarithmic dependence.

## Baselines & Comparisons

The paper's central comparison is against the O(N) linear-width barrier established by Zaheer et al. (2017), Wagstaff et al. (2019), Segol & Lipman (2019), Wang et al. (2024), Amir et al. (2023), and Tabaghi & Wang (2024), all of which require latent dimension scaling at least linearly with set size N for exact representation or universal approximation of arbitrary continuous functions. The proposed Wasserstein-stability assumption allows the width to reduce to O(log N) for fixed ε and D, a logarithmic improvement over all prior constructive bounds. The closest prior result is PointNet (Qi et al., 2017), which achieves O(ε^-D) width independent of N, but only under Hausdorff continuity—a condition that discards element multiplicity and is unsuitable for mass-sensitive tasks like stochastic optimization. The paper's bound is strictly more general in the sense that it preserves multiplicity information via the Wasserstein metric, at the cost of an additional ε^-(3D+4) factor versus PointNet's ε^-D. No direct empirical head-to-head comparison against a specific baseline architecture is provided; the empirical section validates the scaling predictions (logarithmic in N, exponential in D) rather than benchmarking against competing methods.

## Relation to Prior Work

This paper extends the DeepSets sum-decomposable architecture (Zaheer et al., 2017) by replacing the encoder with a multiscale Random Fourier Feature embedding (Rahimi & Recht, 2007) and proving a logarithmic-in-N width bound under Wasserstein-1 Lipschitz stability. It departs fundamentally from prior constructive proofs (Wagstaff et al., 2019; Wang et al., 2024; Tabaghi & Wang, 2024; Dym & Gortler, 2025) that target exact combinatorial injectivity and require O(N) width, instead exploiting the metric entropy of the Wasserstein space to reduce the problem to an ε-covering argument. The measure-theoretic universality line (Pevny & Kovarik, 2019; Zweig & Bruna, 2021; Bueno & Hylton, 2021) provides qualitative existence guarantees via Stone-Weierstrass but no quantitative width bounds; this paper bridges that gap with a constructive, probabilistic construction. Unlike PointNet's Hausdorff-continuity assumption (Qi et al., 2017), which discards multiplicity, the Wasserstein framework preserves mass information, making it applicable to distribution-sensitive tasks like stochastic optimization.

## Why It Matters / Open Questions

The result provides the first rigorous theoretical justification for why fixed-width DeepSets (e.g., m=256) work well in practice regardless of set size, resolving a long-standing gap between theory (O(N) width) and empirical observation. The open question of whether a matching lower bound exists—i.e., whether logarithmic width is truly necessary—remains unresolved, as does the potentially improvable ε-dependency (a reviewer suggested a technique not yet incorporated). The ε^{-(3D+4)} factor, while mitigated for low-intrinsic-dimension data, limits immediate practical applicability to very high-dimensional settings. The Wasserstein stability assumption, while natural for stochastic optimization and robust perception, excludes highly oscillatory or mass-sensitive functionals, bounding the generality of the guarantee.

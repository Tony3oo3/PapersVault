## Problem

In-context learning in LLMs is transient and memory-intensive due to quadratic attention and KV-cache growth, while context distillation (CD) can internalize information into parameters but requires slow, memory-heavy per-prompt training. This makes interactive or on-device adaptation impractical, especially when information sources change frequently. The paper asks whether the entire CD process can be amortized into a single, inexpensive forward pass of a learned hypernetwork.
![Teaser figure](../imgs/ICML20260451/cropped_page1_idx0.webp)

## Input / Output

The method takes a context document (arbitrarily long text) and processes it through a frozen target LLM to extract per-layer token activations (Z ∈ R^{L×N×D}), which are then chunked into fixed-size segments (e.g., 8K tokens). The hypernetwork outputs a set of low-rank LoRA matrices (one per transformer layer, applied to MLP down-projection layers) whose total rank scales linearly with the number of chunks. The adapted LLM then answers downstream queries without the original context in its prompt, reducing inference memory from >12 GB (for 128K-token inputs) to <50 MB.

## Method

D2L is a Perceiver-based hypernetwork (~309M parameters) that meta-learns to approximate the full CD process in one forward pass. It uses cross-attention blocks to map variable-length per-layer token activations to a fixed number of latent queries, which output heads then reshape into LoRA A and B matrices per layer. The meta-training objective minimizes KL divergence between a context-conditioned teacher and a LoRA-adapted student across ~3.2M diverse contexts with self-generated queries and responses, amortizing both query generation and backpropagation into the learned mapping. A chunking mechanism concatenates per-chunk LoRA matrices along the rank dimension, enabling zero-shot generalization to contexts up to 4× the base model's native window (40K tokens) despite training on sequences of only 256 tokens. Unlike prior hypernetwork approaches (T2L, Generative Adapter) that use SFT/next-token-prediction loss, D2L's CD-based training objective with self-responses yields substantially better generalization and factual recall.

## Results

On the 2WikiMultihopQA long-context benchmark, D2L (batched) achieves 0.857 normalized performance with 0.209 s update latency and 11.5 GB peak memory, compared to CD (oracle) at 0.901 / 40.2 s / 7.8 GB and CD (25 generated queries) at 0.745 / 465 s / 59.9 GB. On SQuAD, D2L reaches 82.5% relative performance vs. the in-context upper bound (0.814 ROUGE-L F1), outperforming all in-parameter baselines. On the synthetic NIAH task, D2L achieves near-perfect retrieval accuracy up to 40K tokens—5× its 256-token training length and 4× the base model's 8K context window—while using <50 MB of inference memory versus >12 GB for the base model on a 128K haystack. D2L also zero-shot transfers visual information from a VLM to a text-only LLM, achieving 75.03% accuracy on Imagenette.

## Baselines & Comparisons

Against **CD (context distillation)** baselines, D2L substantially outperforms vanilla CD with generated queries (0.857 vs. 0.745 on 2WikiMultihopQA; 0.814 vs. 0.689 on SQuAD) while being ~200× faster (0.2 s vs. 40 s for oracle CD; ~1000× faster than 25-query CD). D2L approaches the oracle CD upper bound (0.857 vs. 0.901) without per-sample backpropagation. Against **Text-to-LoRA (T2L)**, D2L wins across all three short-context benchmarks (SQuAD, DROP, ROPES); T2L can also update instantly but fails to internalize knowledge effectively due to its SFT-based training on narrow data. Against **LLMLingua-2** (prompt compression), D2L matches the quality of compressing context to ~40% of its original length while removing the context entirely from the prompt, eliminating KV-cache overhead. Against **Generative Adapter (GA)** on Mistral-7B SQuAD, GA achieves a higher ROUGE-L F1 (0.632 vs. 0.515) but at the cost of much lower factual recall (0.643 vs. 0.835), indicating GA produces shorter but less accurate answers, whereas D2L preserves the base model's response characteristics.

## Relation to Prior Work

D2L sits at the intersection of hypernetwork-based parameter generation (Ha et al., 2016) and context distillation (CD, Askell et al., 2021; Snell et al., 2023; Padmanabhan et al., 2023), meta-learning the entire CD process into a single Perceiver-style forward pass that outputs LoRA adapters. It departs from closely related hypernetwork methods—MEND (prefix tokens for few-shot), Gisting (gist tokens for instructions), Cartridges (sleep-time prefix-tuning), and Generative Adapter/T2L (SFT-loss-trained LoRA generation)—by specifically using the CD KL objective with self-generated responses, making it a generic context-to-adapter mapper rather than a task-specific one. The chunking mechanism for composing higher-rank LoRAs from fixed-shape Perceiver outputs is a practical architectural contribution that enables processing contexts far exceeding the target LLM's native window.

## Why It Matters / Open Questions

The sub-second internalization latency (vs. 40–700+ seconds for CD) and <50 MB inference memory (vs. >12 GB KV-cache for long contexts) make context internalization viable for interactive, on-device, and rapidly-changing-knowledge settings that were previously impractical. The zero-shot transfer of visual information from a VLM to a text-only LLM (75% on Imagenette) opens a path for modality bridging without any cross-modal training. Key limitations include the expensive meta-training phase (~5 days on 8 H200s per target LLM), knowledge interference when internalized content is irrelevant to queries, and a persistent performance gap versus full in-context access. Open questions include whether combining D2L's instant adapter with a short CD fine-tuning pass can close the ICL gap, and whether better parameterizations (beyond LoRA) can mitigate catastrophic forgetting.

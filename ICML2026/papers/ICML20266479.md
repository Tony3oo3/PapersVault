## Problem

Current vision encoders (ViTs, CNNs) compute features in a bottom-up, task-agnostic manner where computational cost scales with input image size rather than task difficulty, and the same fixed set of features is extracted regardless of the downstream objective. This paper argues that the next generation of vision encoders should be image size agnostic (decoupling compute from resolution) and task-driven (adapting the inference path to the specific task), drawing inspiration from the foveated, saccade-based efficiency of biological vision.
![Teaser figure](../imgs/ICML20266479/cropped_page2_idx0.webp)

## Input / Output

The encoder takes an RGB image of arbitrary resolution (no resizing to a fixed size) and a task prompt that conditions the initial state. Rather than processing the full image in one pass, it consumes the image iteratively through small sets of multi-zoom patches (M patches per gaze location at varying zoom levels, each resized to 16×16), keeping the per-step context size constant regardless of image dimensions. After each iterative step the task head produces classification logits (or task-specific features), allowing the sequence to terminate early once confidence is sufficient.

## Method

SOVA (Sequential Observation with Visual Attention) comprises three shared modules applied in a recurrent loop: a ViT-with-registers transformer that processes a small set of multi-zoom patches together with N learned state vectors, discarding the patches and retaining the evolved state for the next step (no backpropagation through time); a policy that selects the next gaze location (x, y) ∈ [0,1]² from the current state; and a task head that decodes the state into predictions. Multi-zoom patches are extracted top-down: for a given center, M crops at zoom levels z = linspace(0, max_z, M) are taken as proportional squares of the image and resized to 16×16, making the representation invariant to absolute image size. Training is two-stage: the transformer and task head are first pretrained with a random gaze policy on ImageNet-1K, then the transformer is frozen and the policy is optimized via Group Relative Policy Optimization (GRPO) using classification loss reduction as the reward signal.

## Results

On ImageNet-1K, the iterative transformer (4 steps, 64 patches per step, no backprop through time) recovers 72.0% top-1 accuracy versus 78.0% for the standard ViT-Base baseline, while using only 256 patches total across 4 sequential steps rather than a single global self-attention pass. The full SOVA system with multi-zoom patches and a GRPO-trained policy achieves 65.0% top-1 / 85.0% top-5 after 8 steps, outperforming the random-policy variant (60.0% / 82.0%) under the same severe information bottleneck. Critically, the multi-zoom patch context is an order of magnitude smaller than the ViT context even at 224×224 resolution, and the computational cost remains fixed regardless of input image size.

## Baselines & Comparisons

The sole explicit baseline is ViT-Base (patch size 16, 256×256 input, 256 patches in a single global self-attention pass), achieving 78.0% top-1 and 93.0% top-5 on ImageNet-1K. The iterative transformer variant (Table 1) loses 6.0 points in top-1 accuracy (72.0% vs. 78.0%) but does so without ever performing global self-attention across the full image, processing only 64 patches per step with a 32-vector hidden state and no backpropagation through time. The full SOVA system with multi-zoom patches (Table 2) shows a larger gap (65.0% vs. 78.0% top-1), which the authors attribute to the severe information bottleneck of viewing only a small fraction of image pixels through a 'keyhole' of multi-zoom crops. However, the learned GRPO policy consistently outperforms the random policy by 1–5 points across all step counts, with the largest gain (15 points) at Step 1, demonstrating that active perception adds meaningful value. The authors emphasize that these are proof-of-concept numbers on a task (centered-object classification) that is not representative of the full potential of size-agnostic, task-driven encoders, and that the computational context used is an order of magnitude smaller than ViT's.

## Relation to Prior Work

SOVA synthesizes several distinct research threads into a unified framework: it inverts the ViT-with-registers mechanism (Darcet et al., 2023) so that learned register tokens become an evolving internal state rather than discarded artifacts, borrows DETR's learned query vectors as the state representation, and adopts the iterative, no-BPTT memory paradigm of the Recurrent Memory Transformer (Bulatov et al., 2022). The multi-zoom patch extraction scheme is adapted from Mnih et al. (2014) and Ba et al. (2014), but critically redefined in a top-down, image-size-agnostic manner (patch size is a proportion of the image rather than a fixed pixel count), which the authors identify as the key departure from prior foveal-vision models. The RL-based gaze policy uses GRPO (Shao et al., 2024), a recent algorithm from the LLM reasoning literature, repurposed here for continuous spatial actions over the image.

## Why It Matters / Open Questions

The paper articulates a compelling and underexplored direction—task-driven, size-agnostic visual encoding—that directly addresses a structural inefficiency in current VLMs where the encoder compresses the image without knowledge of the downstream query. However, the proof-of-concept results on ImageNet (65% top-1 vs. 78% for a standard ViT) are preliminary, and the authors themselves note that centered-object classification is not the ideal testbed for active exploration. Major open questions remain: how to train the transformer and policy end-to-end in a single loop, how to define policy objectives during self-supervised pretraining, and whether RL is the right paradigm for the policy at all. The paper is best read as a well-motivated call to action with a feasible prototype rather than a complete solution.

## Problem

While Pearl's do-calculus provides a complete system for rewriting interventional expressions, the relationships between different sequences of rule applications remain poorly characterized, making it difficult to understand the full space of equivalent expressions or to decide whether two expressions are equivalent. This lack of structure also obscures the fact that multiple valid identification formulae can exist for the same causal quantity, each with potentially very different statistical properties when estimated from finite data.
![Teaser figure](../imgs/ICML20265680/cropped_page4_idx3.webp)

## Input / Output

The method takes an ADMG (causal graph with directed and bidirected edges) and an interventional expression of the form P(y|do(x),w) as input, and produces a finite undirected derivation graph whose nodes are all expressions over the same variable set and whose edges represent single atomic rule applications. The connected component containing the query yields the full set of equivalent expressions (bounded by 3^|V\Y|), and a four-step graphical criterion (four d-separation tests on mutilated graphs) decides equivalence between any two expressions. When applied to identification, the method outputs multiple distinct adjustment-based estimands with point estimates and bootstrap variances.

## Method

The paper introduces derivation graphs, where each node is an interventional or observational expression and each edge corresponds to a single valid do-calculus rule application, thereby making the equivalence structure explicit. The key theoretical contribution is a full commutativity analysis: Rule R1 is shown to be redundant (derivable from R2 and R3), R2 applications commute freely (forming quadrilateral patterns), R3 insertions commute but R3 insertion/deletion pairs do not, and R2–R3 compositions commute only in the same direction. These properties imply that any valid derivation between two expressions can be reordered into a canonical sequence of at most four steps (R2↑, R3↑, R3↓, R2↓), yielding a sound and complete graphical equivalence criterion requiring only four d-separation checks. Empirically, applying the ID algorithm to each equivalent expression in the connected component produces multiple valid estimands for the same causal effect, and the paper demonstrates on both synthetic linear-Gaussian data and the Sachs protein-signaling dataset that these estimands can differ substantially in variance, with the derivation graph providing a principled way to enumerate and compare them.

## Results

On the Sachs protein-signaling dataset, the derivation graph yields 32 equivalent interventional densities for P(P38|do(Mek)), producing 11 distinct estimators via parental adjustment. All estimators correctly recover the null causal effect (point estimates range from −0.01993 to 0.02272), but their bootstrap variances span nearly two orders of magnitude, from 0.000016 (P(P38|do(Akt,Erk,Jnk))) to 0.001032 (P(P38|do(Akt))). In the simpler 4-variable example, the front-door-based estimator exhibits substantially larger variance than the backdoor estimator over 1000 simulation runs, despite both being unbiased for the same causal quantity.

## Baselines & Comparisons

This paper does not benchmark against competing causal inference methods; instead, it compares different equivalent identification formulae for the same causal query. The key comparison is between the front-door and backdoor estimators in the 4-variable example: both are unbiased, but the front-door estimator (requiring two regression fits and a summation) has substantially larger variance than the simpler backdoor estimator (one regression fit). On the Sachs dataset, the most efficient estimator (P(P38|do(Akt,Erk,Jnk)), variance 0.000016) is roughly 65× more precise than the least efficient (P(P38|do(Akt)), variance 0.001032), despite all being valid for the same null causal effect. The derivation graph framework is what makes this enumeration of alternatives systematic, whereas standard practice (e.g., the ID algorithm) returns only a single formula. The paper thus positions itself not as a competitor to existing identification algorithms but as a complementary tool that reveals the multiplicity hidden behind a single ID output.

## Relation to Prior Work

This paper builds directly on Pearl's do-calculus (2009) and the completeness result of Huang & Valtorta (2006), extending the latter's Lemma 4 (one direction of R1 redundancy) into a full characterization of how all three rules compose. It also leverages the ID algorithm (Shpitser & Pearl, 2006) as the mechanism for converting equivalent interventional expressions into observational estimands, but departs from prior identification work by treating the entire space of do-calculus-equivalent expressions as a structured object (the derivation graph) rather than following a single derivation path. The empirical motivation connects to the efficient-adjustment literature (Rotnitzky & Smucler, 2020; Guo et al., 2022), but approaches estimator selection through do-calculus equivalence rather than direct graphical criteria for adjustment sets.

## Why It Matters / Open Questions

The practical takeaway—that causally equivalent expressions can yield estimators with orders-of-magnitude different variances, and that the derivation graph provides a systematic way to enumerate all such alternatives—gives practitioners a principled route to more efficient causal estimation beyond the single formula returned by the ID algorithm. The diameter-4 bound and the four-d-separation-test equivalence criterion are clean, computationally efficient results that simplify what was previously an ad hoc search over rule sequences. A major open question, acknowledged by the authors, is whether an analogous finite structure exists for the full space of probabilistic rewritings underlying the ID algorithm, which is generally infinite due to insertable identities; characterizing tractable subclasses of that space remains unresolved.

## Problem

Text-based memory for long-horizon agents suffers from uniform information density: every token costs the same budget regardless of semantic importance, so auxiliary details compete directly with crucial evidence for limited context space. This makes it impossible to selectively compress low-priority content while preserving high-priority evidence under tight budgets, leading to catastrophic performance drops as memory budgets shrink.

## Input / Output

The agent receives a stream of text chunks (each ~5K tokens) and a user question, incrementally maintaining a persistent Markdown rich-text memory. At query time, this memory is deterministically rendered into a 2D image (via headless Chromium screenshot) and downsampled so the vision encoder produces at most B visual patch tokens (e.g., 16–1024 tokens, mapped to 12K–803K pixels with Qwen2.5-VL's 28×28 patch size). The agent then reads only this budgeted memory image to produce a boxed text answer; no raw history or original long context is provided at inference.

## Method

MemOCR formulates memory as a 2D visual canvas with adaptive information density, where the agent controls budget allocation through typographic hierarchy (H1 headers, bold, font size) rather than token count. A two-stage lifecycle separates concerns: (1) budget-agnostic drafting in the text domain, where the agent incrementally edits a Markdown memory assigning visual priority via structure and formatting, and (2) memory reading in the vision domain, where a deterministic renderer compiles the rich text into an image whose resolution is adjusted to meet the token budget. Training uses GRPO with three complementary budget-aware objectives—standard QA at 512 tokens, QA under 4× image downsampling (32 tokens) to force crucial evidence into high-visibility regions, and detail-oriented QA at full resolution to retain auxiliary information—where reading is updated with separate per-task advantages and drafting with a weighted aggregate, preventing the shortcut of uniform medium-sized rendering.

## Results

On 10K-token contexts with a 1024-token memory budget, MemOCR achieves 74.6% average subword exact-match accuracy across HotpotQA, 2WikiMultiHopQA, Natural Questions, and TriviaQA, surpassing the strongest text-memory baseline MemAgent (67.8%) by 6.8 points. Under extreme budget compression to 16 tokens, MemOCR retains 62.2% accuracy (only a 16.6% relative drop), while MemAgent collapses to 31.6% (a 53.3% drop), yielding an approximately 8× token-efficiency gain. At 100K context length, MemOCR still leads with 66.6% vs. 65.7% for MemAgent, and outperforms unlimited-storage RAG baselines (e.g., HyMem at 59.0%) by 7.6 points at 30K context.

## Baselines & Comparisons

MemOCR outperforms all ten baselines across every context length and budget setting. Against the strongest text-summary baseline MemAgent, MemOCR leads by 6.8 points at full budget (74.6% vs. 67.8% at 10K/1024) and by 30.6 points at the extreme 16-token budget (62.2% vs. 31.6%). The gap widens dramatically as budgets tighten: at 64 tokens, MemOCR retains 67.3% while MemAgent drops to 50.7% (+16.6 points). Among raw-history baselines, Qwen2.5-1M is the strongest (66.6% at 10K) but still trails MemOCR by 8 points, and R1-Distill Qwen collapses to 1.4% at 100K context. Against unlimited-storage RAG methods (SimpleMem 55.5%, LightMem 53.9%, HyMem 56.4% at 10K), MemOCR at 1024 tokens leads by 18.2 points over the best (HyMem), and even at 64 tokens (67.3%) exceeds all RAG baselines. Finally, scaling the backbone to Qwen2.5-VL-72B without RL yields 70.7% at 10K/1024, still below MemOCR's 7B+RL (74.6%), and degrades far more sharply at 16 tokens (44.3% vs. 62.2%), confirming that budget-aware RL training is more effective than naive model scaling.

## Relation to Prior Work

MemOCR departs from the dominant textual memory paradigm (MemAgent, Mem-α, Mem0) where information density is uniform per token, and from prior visual-text compression methods (VTC-R1, AgentOCR, DeepSeek-OCR, Glyph) that render text into images without learned spatial allocation. The key conceptual shift is treating the 2D canvas as a budget-allocation surface: rich-text formatting (headings, bold, font size) encodes salience, and a deterministic renderer converts this into a memory image whose resolution controls the effective token budget. Training via GRPO with three complementary budget-aware objectives (standard QA, compressed-memory QA, detail-oriented QA) is novel in jointly optimizing a drafting policy that must produce a single layout serving multiple compression levels.

## Why It Matters / Open Questions

The 8× token-efficiency gain at extreme budgets (16 tokens) and the graceful degradation curve address a practical bottleneck for deploying long-horizon agents under tight context windows, potentially enabling more capable agents on hardware with limited memory. However, the approach is currently validated only on QA-style tasks and depends on the VLM backbone's OCR robustness at very low resolutions; generalization to planning, tool-use, or lifelong conversational settings remains open. The finding that a 7B model with budget-aware RL outperforms 32B/72B models without RL suggests the learned layout policy is the critical component, raising the question of whether this transferable skill can be distilled or applied to other memory-intensive agentic workloads.

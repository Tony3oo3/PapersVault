## Problem

Existing visual token pruning methods for large multimodal models perform a single static selection at prefill, implicitly assuming the required visual evidence remains fixed throughout reasoning. The paper empirically shows this assumption is violated: visual evidence is strongly step-dependent, with the critical token set evolving across decoding steps, and that retaining redundant visual context at every step steers the model toward query-irrelevant regions, lengthening and destabilizing the reasoning trace.

## Input / Output

The method operates on standard LMM inputs (an RGB image or video plus a text query) and produces a chain-of-thought reasoning trace followed by a final answer. The key operational detail is that VisionPulse intervenes during the autoregressive decoding phase, dynamically selecting which visual tokens participate in self-attention at each generated token, rather than modifying the input representation. The output reasoning trace is naturally shortened (by ~11–12%) because redundant visual context no longer triggers unnecessary descriptive detours.

## Method

VisionPulse is a training-free, step-wise visual token pruning framework that re-estimates token importance at every decoding step rather than once at prefill. At an anchor layer, it computes per-token importance scores via head-averaged attention from the current query token to each visual key (following FastV's estimator). A lightweight visual attention mass signal M_vis^t — the total attention probability allocated to visual tokens at step t — is used to set a step-specific retention budget K_t = M_vis,max^t · N_v, exploiting the strong positive correlation (Pearson r 0.82–0.95) between mass and the number of effectively activated tokens. Temperature-scaled attention (τ < 1) suppresses the softmax long tail to enable aggressive, controllable compression ratios. Only the top-K_t visual tokens are retained for the current step's decoding, so the model sees a different, minimally sufficient visual subset at each reasoning step.

## Results

Under aggressive 5% visual-token retention, VisionPulse (FastV-VP) achieves an average accuracy of 71.35% (vs. 72.68% full-token baseline, only −1.8%) while reducing average generation length by 11.2% (1498.5 vs. 1687.3 tokens). Under the 10% retention setting, it reaches 72.69% accuracy with a 12.3% reduction in generation length. In contrast, all static pruning baselines suffer large accuracy drops (24.5%–50.9%) and increased generation lengths (18.3%–108.0%) under the same aggressive retention budgets.

## Baselines & Comparisons

VisionPulse (FastV-VP) decisively outperforms all three static pruning baselines on both accuracy and generation length under aggressive retention. Against VisionZip, VisionPulse achieves 71.35% vs. 39.31% average accuracy at 5% retention (a 32-point gap) while generating 25% fewer tokens (1498.5 vs. 1995.8). Against FastV, the gap is even wider: 71.35% vs. 35.69% accuracy, and VisionPulse produces 32% shorter reasoning traces (1498.5 vs. 2187.0). Against LOOK-M, VisionPulse matches or exceeds accuracy (71.35% vs. 44.62%) while cutting generation length by 57% (1498.5 vs. 3509.0). Critically, VisionPulse is the only method that simultaneously preserves near-baseline accuracy and reduces generation length; all static baselines degrade in accuracy while paradoxically increasing generation length, confirming the paper's coupled-bottleneck hypothesis that premature pruning forces compensatory over-generation.

## Relation to Prior Work

This paper builds directly on FastV's attention-based importance scoring (Chen et al., 2024b) but fundamentally departs from the static pruning paradigm shared by VisionZip, FastV, and LOOK-M, all of which select a fixed visual subset once at prefill. The key conceptual departure is recognizing that multimodal *reasoning* (as opposed to direct-answer VLM inference) exhibits step-dependent visual dependency, making a single prefill-time selection inherently misaligned with later reasoning demands. VisionPulse repurposes the lightweight visual attention mass signal—previously used only as a diagnostic—into a per-step budget allocator, bridging the gap between attention analysis and dynamic token management during decoding.

## Why It Matters / Open Questions

The identification of a 'coupled bottleneck'—where redundant visual context actively steers LMMs toward query-irrelevant regions and lengthens reasoning traces—reframes visual token pruning from a pure efficiency concern to a reasoning-reliability issue, with implications for safety-critical applications like autonomous driving. The practical impact is substantial: training-free, 5% per-step visual retention with ~11% shorter reasoning traces and near-unchanged accuracy across seven benchmarks and multiple LMM backbones. Open questions include whether the coupled bottleneck generalizes to video inputs, whether the temperature-scaled mass signal remains reliable under very long reasoning chains (>16K tokens), and whether the per-step recomputation overhead becomes prohibitive at scale or in batched serving settings.

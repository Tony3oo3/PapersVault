## Problem

Long-horizon agentic inference suffers from a memory-bound decoding bottleneck: as interaction history grows, the KV cache expands linearly and per-token latency degrades, yet existing mitigations either truncate context (sliding window, RAG) at the cost of long-range recall or optimize system-level throughput (PagedAttention, sparse attention) without eliminating the redundancy of re-attending to a massive, largely static history at every decoding step. No prior approach decouples the heavy long-context compression from the agent's critical decoding path while preserving full-context reasoning quality.

## Input / Output

The agent model consumes a compressed summary (capped at 2048 tokens, produced by a separate Qwen3-4B memory model) concatenated with a raw buffer of the most recent k interaction turns, rather than the full history. The memory model receives the entire interaction history (up to 32K tokens) and emits a single summary string. The agent outputs a reasoning block plus a tool call per step; the memory model's summary is consumed only at k-step cycle boundaries, at which point the agent's KV cache is invalidated and a full uncached prefill is triggered. Both models are served on separate vLLM instances, and the memory model runs with greedy decoding while the agent uses temperature 0.6 with top-p 0.95.

## Method

COMEM decouples memory management from agentic reasoning by assigning long-context compression to a dedicated lightweight model (Qwen3-4B) that runs asynchronously on a separate inference server, while a larger agent model (DeepSWE-32B, Qwen3-Coder-Max, or GLM-4.7) decodes with a bounded prompt of summary + recent buffer. A k-step-off pipeline overlaps the two: the memory model lags k steps behind, compressing history in the background while the agent proceeds for k steps using the last available summary; at each cycle boundary the agent performs one uncached prefill, and for the remaining k−1 steps it reuses its cached KV prefix with only incremental prefill of new observations. The memory model is trained with GRPO using an action-consistency reward (cosine similarity between the frozen agent's action conditioned on the summary and its ground-truth full-context action), requiring no online environment interaction and keeping the agent policy fixed throughout. A theoretical analysis derives an upper bound on the permissible compression ratio (L_sum/L_full < 1/(1 + W/(Y·S·P))) ensuring that cumulative decoding savings amortize the one-time prefill cost, yielding a concrete design constraint (e.g., summary < 7.36K tokens for a 32K prefix on A100).

## Results

On SWE-Bench-Verified, COMEM (GRPO) achieves 41.0% resolve rate with DeepSWE-32B (vs. 40.4% full-context), 51.0% with Qwen3-Coder-Max (vs. 57.2%), and 62.7% with GLM-4.7 (vs. 69.0%), while delivering 1.45×–2.08× end-to-end latency speedups depending on hardware and CPU offload settings. On BrowseComp-EN, COMEM improves accuracy from 28.1% to 32.0% over the full-context baseline. The speedup scales with batch size, reaching 2.52× at batch 256 and up to 4.95× peak per-step speedup at concurrency 64.

## Baselines & Comparisons

Against MemAgent (7B), the external long-context compression baseline, COMEM achieves a 7.9% higher resolve rate on GLM-4.7 (62.7% vs. 54.8%) while also being faster (2.08× vs. 1.80× speedup); on Qwen3-Coder-Max, COMEM improves resolve rate by 7.8% (51.0% vs. 43.2%) with comparable latency (1.43× vs. 1.40×). Against the internal Full-Context baseline, COMEM (GRPO) slightly exceeds the full-context resolve rate on DeepSWE (41.0% vs. 40.4%) but shows a 5.2–6.3% gap on the larger models (Qwen3-Coder-Max: 51.0% vs. 57.2%; GLM-4.7: 62.7% vs. 69.0%), trading modest accuracy for 1.45×–2.08× latency reduction. The off-the-shelf Qwen3-4B base model without task-specific training underperforms GRPO-trained COMEM by 8–11% in resolve rate across backbones, confirming the importance of the action-consistency reward. The No Summary ablation (removing the memory model entirely) drops resolve rate by 10–12% on the larger agents, demonstrating that the compressed summary is essential for maintaining long-horizon coherence.

## Relation to Prior Work

COMEM carves new ground at the intersection of context compression and systems-level inference optimization. Prior context-management work (ReSum, ACON, SUPO, AgentFold, MemAgent) treats summarization as an in-model or single-model responsibility, while systems optimizations (PagedAttention, sparse attention, KV quantization) reduce per-token cost without reducing context length. COMEM departs from both by architecturally decoupling memory compression into a separate lightweight model and overlapping its execution with agent decoding via a k-step-off asynchronous pipeline, then aligning the memory model through a GRPO-based action-consistency reward rather than generic summarization quality. The theoretical analysis of the summary-length bound (Eq. 7) provides a principled design criterion absent from prior compression methods.

## Why It Matters / Open Questions

For production agentic deployments, the 1.4–2.1× end-to-end speedup with near-parity resolve rates directly reduces serving cost and user-facing latency, and the modular design (one 4B memory server supporting ~300 concurrent agents) makes the overhead negligible at scale. The finding that aligned compression can slightly *improve* accuracy over full-context (e.g., 41.0% vs 40.4% on DeepSWE; 32.0% vs 28.1% on BrowseComp) suggests that unfiltered long context introduces attention-diluting noise, opening the question of whether optimal context length is shorter than the model's maximum window. Open questions include how the approach behaves at even longer horizons (beyond ~100 steps), whether the k-step-off pipeline interacts well with speculative decoding or multi-agent topologies, and whether the action-consistency reward generalizes to domains where the 'correct action' is not a single discrete token sequence.

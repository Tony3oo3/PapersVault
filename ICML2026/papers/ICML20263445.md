## Problem

Machine unlearning has been studied primarily in supervised and unsupervised settings with static, independent data points, but interactive systems powered by reinforcement learning (recommenders, assistants, healthcare) generate sequential, temporally extended user episodes whose influence must be removable upon deletion request. No prior work provided a regret-optimal RL algorithm that simultaneously supports provable exact unlearning—i.e., the post-deletion model is distributionally identical to one trained without the deleted user—nor established minimax lower bounds for TV-stable RL algorithms.

## Input / Output

The learner receives a stream of MDP episodes, each packaged by an environment oracle into summary statistics x_t of dimension d = 2SAH + S²AH (state-action visitation indicators, transition counts, and reward sums across the horizon H). Upon a deletion request for user z_t, the algorithm also receives a fixed dummy user z' chosen by the designer; the unlearned output must be distributionally equivalent to training on the sequence with z_t replaced by z'. The sensitivity of the environment oracle is bounded by B ≤ √(3H), independent of S and A, because each episode contributes at most 3H non-zero components regardless of state/action space sizes.

## Method

The core algorithm extends UCB-VI (optimistic value iteration) by replacing raw visitation counts with binary-tree, noise-perturbed prefix sums: each prefix sum is reconstructed from O(log T) shared Gaussian noises via dyadic decomposition, and a modified bonus function b(ñ) adds a Hoeffding-style exploration term plus a second term compensating for approximation error from noisy counts. This makes the RL algorithm ρ-TV-stable while preserving near-minimax regret. For unlearning, the algorithm traverses the leaf-to-root path in the binary tree and applies a maximal coupling at each node: a rejection-sampling test checks whether the old noisy value can be reused as a draw from the updated Gaussian (via a density-ratio comparison), and on rejection a reflection map ψ(x) = v' + v − x produces a valid coupled sample, triggering retraining only from the next post-order leaf. The expected retraining probability per deletion is ρ√(2 log T), yielding an expected unlearning cost of only ρ√(ln T) times full retraining. The resulting regret bound is Õ(H²√(SAT) + H³S²A + H²·⁵S²A/ρ), matching a minimax lower bound of Ω(H√(SAT) + HSA/ρ) up to polynomial factors in H and S.

## Results

The paper establishes that for any ρ > 0, there exists a ρ-TV-stable RL algorithm for tabular MDPs achieving regret Õ(H²√(SAT) + H³S²A + H²·⁵S²A/ρ), where S, A, H, T denote states, actions, horizon, and episodes. A matching minimax lower bound of Ω(H√(SAT) + HSA/ρ) is proven, showing near-optimality up to factors of H and H¹·⁵S. The expected computational cost of unlearning is only ρ√(ln T) fraction of full retraining, with retraining probability bounded by ρ√(2 log₂ T). The sensitivity parameter for the MDP environment oracle is B ≤ √(3H), yielding a tighter noise requirement than Laplace-based approaches.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The closest theoretical comparison is to ε-Joint-Differentially-Private (JDP) RL algorithms of Vietri et al. (2020), which incur an additional regret term of order H³S²A/ε. Setting ρ = ε, the paper's ρ-TV-stable algorithm improves over the JDP bound by a factor of √H in the additional cost term (H²·⁵S²A/ρ vs. H³S²A/ε), attributed to using Gaussian noise (sensitivity B = √(3H)) rather than Laplace noise (sensitivity B = 3H). The minimax lower bound Ω(H√(SAT) + HSA/ρ) matches in form the lower bound for ρ-JDP RL algorithms, but the paper emphasizes that TV-stability is strictly weaker than DP (no function f exists such that ρ-TV-stability implies f(ρ)-DP), making their lower bound strictly stronger. The gap between upper and lower bounds remains: a factor of H in the first term (reducible via Bernstein-type bonuses) and H¹·⁵S in the second term.

## Relation to Prior Work

This paper extends the batch exact-unlearning framework of Ullah & Arora (2023) and Ullah et al. (2021) from supervised learning to sequential reinforcement learning, replacing the batch prefix-sum structure with a binary-tree mechanism that supports online updates and per-episode deletion. The RL algorithm is a TV-stable variant of UCB-VI (Azar et al., 2017), where visitation counts are replaced by noise-perturbed prefix sums and a two-term bonus function (Hoeffding exploration + noise-approximation compensation) preserves optimism. The only prior RL unlearning work (Ye et al., 2023) removes entire MDPs rather than individual user episodes and provides no theoretical guarantees, making this the first formulation of per-user exact unlearning in RL with regret bounds.

## Why It Matters / Open Questions

This is the first end-to-end theoretical framework showing that near-minimax-optimal regret and provable exact unlearning can coexist in RL, with a matching lower bound confirming the tradeoff is essentially tight. The practical implication is that operators of interactive systems (recommenders, assistants, healthcare) can retrofit certified deletion onto regret-optimal learners with expected unlearning cost of only ρ√(ln T) times retraining. Key open questions include closing the polynomial gap between upper and lower bounds, extending beyond tabular MDPs to function approximation, and determining whether sublinear space suffices for exact unlearning.

## Problem

Current ESG forecasting solutions cannot jointly model high-dimensional, multimodal time series spanning ESG risks, financial returns, news, and sentiment while preserving both numerical proximity and semantic type. Standard LLM tokenizers fragment numerical values into sub-tokens, destroying quantitative relationships, and existing multivariate forecasters treat all input channels as homogeneous real-valued sequences, failing to distinguish that ESG=60 and Return=60 carry entirely different economic meanings. This paper addresses the absence of a structured framework that integrates domain-aware numerical geometry with trajectory-level representation learning for ESG applications.

## Input / Output

The system consumes per-company trajectories as Value-Aware Domain Tokens (VADTs) of the form <TYPE_VALUE> (e.g., <ESG_56.04>, <RET_12>, <SENTI_0.7>), where each token type is mapped to a disjoint 96-dimensional block within a 768-dimensional embedding space, plus raw news text filtered via GRI-topic semantic matching and RoBERTa sentiment scores aggregated weekly. Outputs include one-step-ahead ESG/ENV/SOC/GOV forecasts via sliding-window inference (window size 8 selected by autocorrelation), per-trajectory FACET embeddings stored in a Pinecone vector database for similarity retrieval, Superior Asset Populations (SAP) identifying financially similar but more sustainable peers, and Pareto-optimal portfolio weight vectors from multi-objective evolutionary optimizers.

## Method

The core architecture augments GPT-2 with domain-specific VADT vocabulary and LoRA adapters, where each VADT's embedding is constructed via block-wise orthogonal sinusoidal encoding (a modified Vaswani positional encoding using phased sine with a quadratic term) so that numerically close values of the same type receive similar representations while different types occupy strictly orthogonal subspaces. Trajectory-level structure is captured by special FACET tokens (one per series type per company) whose final-layer hidden states encode each trajectory's geometry. Training uses a dual-objective loss combining standard next-token prediction with a block-wise DTW geometry loss (constrained by a Sakoe-Chiba band) that penalizes deviation between pairwise cosine distances of FACET embeddings and ground-truth DTW distances of the raw trajectories, with β=0.4 selected via grid search. The learned embedding space supports FACET-wise similarity queries to construct SAPs, which are then fed into standard multi-objective optimizers (NSGA-II, NSGA-III, SPEA-II, etc.) for ESG-aware portfolio rebalancing under financial constraints.

## Results

On the ESG forecasting task over 621,408 real company samples from Yahoo Finance, FMP, and LSEG Refinitiv, DA-LLM achieves the lowest MSE across all four sustainability dimensions: Environment (1.653), Society (5.582), Governance (4.514), and overall ESG (5.227). The corresponding MAE values are 0.756, 1.912, 1.867, and 1.912 respectively. The closest competitor, iTransformer, records an ESG MSE of 7.334, while the strongest non-Transformer baseline (Sensorformer) reaches 7.844. Ablations confirm that removing news text degrades ESG MSE to 27.643 and removing LoRA/VADT tokens inflates it to 86.97–128.97.

## Baselines & Comparisons

DA-LLM outperforms all seven baselines on every series (Environment, Society, Governance, and overall ESG) in both MSE and MAE. The margin is largest on Environment, where DA-LLM (1.653) beats the next-best iTransformer (9.122) by a factor of ~5.5×. On overall ESG, DA-LLM (5.227) leads iTransformer (7.334) by 29% and Sensorformer (7.844) by 33%, while the gap widens dramatically against LLM-based Chronos (18.140) and multimodal MM-iTransformer (18.363). Sensorformer is the closest competitor on Society (5.777 vs. 5.582) and Governance (7.866 vs. 4.514), but DA-LLM still wins both. The paper attributes the advantage to block-wise orthogonal sinusoidal embeddings that preserve numerical proximity within a domain while enforcing strict separation across domains—something quantization-based tokenizers (Chronos) and homogeneous-channel Transformers (iTransformer, Autoformer, TimesNet) cannot represent.

## Relation to Prior Work

This paper extends LLM-based time series forecasting (Chronos, Ansari et al. 2024) by replacing discrete quantization with continuous, block-wise orthogonal sinusoidal embeddings that preserve numerical geometry and semantic type simultaneously. It adapts transformer positional encoding (Vaswani et al., 2017) from a sequence-level to a token-level value encoding, and introduces a DTW-based geometry-preserving loss alongside standard next-token prediction to learn trajectory-level representations via FACET tokens. The portfolio rebalancing component builds on multi-objective evolutionary optimizers (NSGA-II, SPEA-II) and prior ESG portfolio work (Martinez-Barbero et al., 2024), but departs by using LLM-forecasted future sustainability rather than historical averages to define the candidate asset population.

## Why It Matters / Open Questions

The domain-aware tokenization strategy (orthogonal subspaces per signal type with smooth numerical decay) is a reusable design pattern for any heterogeneous numerical time series where semantic type and magnitude must both be preserved, potentially generalizing beyond ESG to broader financial or scientific forecasting. The SAP mechanism demonstrates a concrete path from representation learning to actionable portfolio decisions, though the evaluation relies on GPT-2-scale models and general-purpose time series baselines rather than ESG-specific competitors, leaving open whether the approach scales to larger LLMs or maintains its advantage against domain-tuned alternatives. The paper also raises the question of whether the DTW geometry loss and orthogonal embedding design remain beneficial when the base model is substantially larger or when more signal types are added.

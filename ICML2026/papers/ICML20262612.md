## Problem

Existing diversity metrics for LLM post-training data (distinct-n, n-gram entropy, embedding cosine distance) quantify linguistic or semantic variation in text space but provide weak signals for the task-relevant internal features that actually determine downstream performance. The paper asks how to construct diverse post-training datasets in a principled and efficient manner that directly targets the model's internal feature space rather than surface-level text properties, and how to do so with minimal synthetic data.
![Teaser figure](../imgs/ICML20262612/cropped_page0_idx2.webp)

## Input / Output

The method consumes a seed dataset (initial post-training samples), an anchor dataset (large task-domain corpus for estimating the target feature distribution), a pre-trained SAE that maps token-level embeddings via max pooling into a k-dimensional activation vector, a task-relevant feature set F identified by LLM annotation of top-activated text spans, and a generator LLM. It produces a synthetic dataset where each sample is verified to activate at least one previously missing feature (via a fixed SAE threshold δ), a FAC score defined as the ratio of covered to total task-relevant features, and the missing feature set F_miss that drives the synthesis loop. The contrastive pair structure (one high-activation, one low-activation example per feature) is an intermediate artifact that conditions generation.

## Method

The core mechanism trains a Sparse Autoencoder on the target model's internal activations to decompose them into k interpretable sparse features, then identifies which task-relevant features are absent from the seed data by comparing binary activation indicators (thresholded at δ) between anchor and seed distributions. For each missing feature, a two-step synthesis strategy is employed: first, contrastive pairs (x_i^+, x_i^-) are constructed by generating candidates and selecting those with high vs. low SAE activation for that feature; second, these pairs serve as few-shot demonstrations to condition the generator, and outputs are filtered by the same SAE threshold to ensure reliable feature activation. Theoretically, the approach is grounded in a generalization error bound decomposed into a distribution gap term (reduced by covering missing features in SAE space, upper-bounded via Pinsker's inequality on the KL divergence of feature marginals) and a sampling error term (reduced by the contrastive guidance, which lowers the conditional entropy of generated samples as formalized via PAC-Bayesian analysis under sub-Gamma loss assumptions). This yields a data-efficient pipeline where only ~2K targeted synthetic samples match the performance of 300K-sample baselines like Magpie.

## Results

FAC Synthesis achieves the best performance across all four evaluation tasks: 62.60% AUPRC on Toxicity Detection, 76.22% Accuracy on Reward Modeling, 40.67% SCR on Behavior Steering (Sympathetic), and 21.26% Win Rate on AlpacaEval 2.0 for Instruction Following. Notably, the method matches MAGPIE's instruction-following win rate (21.26% vs. 6.65%) while using only 2,000 synthetic samples versus MAGPIE's 300,000 (a 150× data reduction). FAC shows a strong positive correlation with downstream AUPRC (Pearson r = 0.95, Spearman ρ = 0.90), confirming that feature-space coverage is the key driver of performance gains.

## Baselines & Comparisons

FAC Synthesis outperforms all seven baselines across every task. Against the strongest baseline SynAlign, it gains +3.77 AUPRC on Toxicity Detection (62.60 vs. 58.83), +5.53 Accuracy on Reward Modeling (76.22 vs. 70.69), +40.67 SCR on Behavior Steering (40.67 vs. 0.00), and +9.01 LC on Instruction Following (20.27 vs. 11.26). Compared to MAGPIE, the prior SOTA for instruction-following data synthesis, FAC Synthesis achieves a 21.26% Win Rate versus MAGPIE's 6.65% while using only 2K synthetic samples instead of 300K. Among objective-driven methods (SAO, Prismatic Synthesis, SynAlign), FAC Synthesis consistently leads, with the largest margin on Behavior Steering where SAO achieves 23.33% SCR and Prismatic Synthesis 16.67%, both far below the proposed 40.67%. Instruction-expansion baselines (Alpaca, Evol-Instruct, CoT-Self-Instruct) show unstable performance across tasks, confirming that explicit task-relevant feature targeting is more reliable than generic self-evolution prompting.

## Relation to Prior Work

This paper builds on the sparse autoencoder (SAE) interpretability literature (Bricken et al., 2023; Cunningham et al., 2023) by repurposing SAE features not for mechanistic analysis but as a diversity measurement and synthesis-guidance tool for LLM post-training. It departs from prior data-diversity work that operates in text space (Distinct-n, n-gram entropy) or generic embedding space (cosine distance, semantic entropy) by proposing a model-aware metric—Feature Activation Coverage (FAC)—defined in the SAE latent space. The synthesis pipeline also extends contrastive-pair prompting and PAC-Bayesian generalization analysis (Banerjee & Montufar, 2021) into a coverage-guided generation loop, positioning itself between gradient-based diversification (Prismatic Synthesis, Jung et al., 2025) and alignment-objective-driven methods (SAO, SynAlign).

## Why It Matters / Open Questions

The framework offers a practical, interpretable recipe for data-centric LLM optimization: identify which task-relevant features a seed dataset misses, then generate targeted samples to fill those gaps, achieving comparable AlpacaEval performance to MAGPIE with ~150× fewer synthetic samples. The discovery of a shared, transferable SAE feature space across LLaMA, Mistral, and Qwen families—and the counterintuitive 'weak-to-strong' transfer where LLaMA features improve Qwen more than Qwen's own features—opens questions about whether feature spaces are more universal than model-specific. Key limitations include reliance on single-layer SAE features (preliminary GSM8K/LiveCodeBench results suggest multi-layer circuits matter for reasoning) and the need for an LLM to interpret and describe each feature, which adds a non-trivial annotation step.

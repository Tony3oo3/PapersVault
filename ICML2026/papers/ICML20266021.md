## Problem

Linear recurrent neural networks empirically perform well as memory units in partially observable RL, yet the optimal belief update in a POMDP is a nonlinear Bayesian filter, raising the question of what information linear dynamics can actually capture. No prior theoretical justification explained why a linear recurrence could serve as a sufficient or near-sufficient statistic for optimal policy learning in these settings.
![Teaser figure](../imgs/ICML20266021/cropped_page7_idx0.webp)

## Input / Output

The filter consumes a one-hot observation vector y_k ∈ R^S (and the previous action a_{k-1} in the time-varying case) through a nonlinear encoder φ(·), combined with the previous hidden state z_{k-1} ∈ R^N. The output is a surrogate logit vector w_k of dimension N (equal to the state space size), which induces a proxy belief via softmax or can be decoded directly via argmax to yield a state estimate. The hidden dimension is deliberately kept at N rather than a larger learned size, highlighting representational efficiency.

## Method

The paper constructs two explicit linear filters in logit space. For deterministic transitions, a time-invariant filter w_k = T' w_{k-1} + ψ(k, y_k, …, y_{k-ℓ+1}) exactly reproduces the optimal logit dynamics, where T' is a block matrix combining identity (transient states) and a permutation matrix (recurrent states), and ψ is a nonlinear correction term that handles initialization and the finite transient phase. For nearly-deterministic transitions T = D + εQ, the Adaptive Logit Filter (ALF) uses the recurrence w_k = P(1−δ)w_{k-1} + δ log(E^T y_k), where P is the permutation backbone of D and δ controls the trade-off between retaining past memory and adapting to new observations. Under conditions δ_ε → 0 and ε/δ_ε → 0, ALF achieves vanishing state-decoding error at rate ε log(1/ε), matching the Bayes-optimal decoder. The construction extends to action-controlled HMMs by replacing P with action-dependent permutation matrices P(a), yielding a time-varying linear filter.

## Results

Theoretically, the Adaptive Logit Filter (ALF) achieves a state-decoding error rate of O(ε log(1/ε)) under nearly-deterministic transitions, matching the asymptotic rate of the Bayes-optimal decoder. In the RingWorld POMDP experiment, ALF (constructed from environment knowledge) converges quickly to a strong episodic return, while the Logit Optimal Filter (LOF) trains slowly with high variance unless a softmax is applied to stabilize the logits. Among trained-from-scratch memories, Deep ALF (a parameterized complex-space version of ALF) outperforms an S5-based memory at the same hidden dimension (12), and S5 must be scaled to hidden size 256 to match Deep ALF's performance, yet both still fall short of the environment-informed ALF and softmax-LOF.

## Baselines & Comparisons

The paper compares four memory mechanisms in the RingWorld POMDP: ALF, LOF, an S5-based memory (Smith et al., 2022), and Deep ALF. ALF, constructed directly from environment knowledge, converges fastest and achieves a strong return with minimal variance across 8 seeds. LOF, also environment-informed, suffers from logit drift causing slow convergence and high variance; applying a softmax to its output recovers a belief vector and yields the best episodic return in the experiment. The S5-based memory (a single S5 layer with a two-layer MLP encoder) at hidden size 12 underperforms both ALF and Deep ALF; increasing its hidden size to 256 allows it to match Deep ALF but it still falls short of ALF and softmax-processed LOF. Deep ALF is notably more parameter-efficient than the S5-based memory, as its encoder has a number of parameters comparable to the emission matrix E rather than a full two-layer MLP, while achieving better performance at the same hidden dimension.

## Relation to Prior Work

This paper bridges the Adaptive Social Learning (ASL) literature (Bordignon et al., 2021; Khammassi et al., 2025) with the linear RNN design space for partially observable RL, showing that ASL—after removing normalization and applying a log transform—naturally falls into the linear recurrent memory class. It extends Khammassi et al. (2025) from the special case D=I (slowly varying Markov chains) to general nearly-deterministic transition matrices with transient states and non-identity permutation backbones, while also weakening the observability assumption. Empirically, it positions ALF against S5 (Smith et al., 2022) and the nonlinear logit optimal filter (LOF), providing the first constructive proof that a linear recursion can match the Bayes-optimal decoder's asymptotic error rate in the nearly-deterministic regime.

## Why It Matters / Open Questions

The paper provides the missing theoretical justification for why linear RNNs—despite the optimal POMDP filter being inherently nonlinear—perform so well in practice, yielding concrete design principles (hidden dimension = state space size, eigenvalues near the unit circle, (1−δ)/δ balance between memory and new information). Key limitations include the restriction to (near) deterministic transitions, the unusual time-dependent ψ function in the exact-reproduction case that is hard to approximate with standard MLPs, and the small-scale RingWorld validation (12 states, 4 actions). Open questions include extending guarantees to highly stochastic POMDPs, approximating the constructed filters with learnable architectures at scale, and understanding whether the ALF structure generalizes to continuous-state environments.

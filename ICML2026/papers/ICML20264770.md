## Problem

Tool-augmented LLM agents are assumed to be stateless between sessions, yet implicit state can persist through name-based tool registration, event subscriptions, and serialized state—evading conventional debugging and logging. This paper formalizes the phenomenon as Persistent Semantic Entities (PSE) and asks: how prevalent is this contamination across model families, does it decay over time, and which defenses actually mitigate it?
![Teaser figure](../imgs/ICML20264770/cropped_page1_idx0.webp)

## Input / Output

The experimental harness injects contamination through three channels (prompt-level false facts/preferences, tool-registry handler substitution, and policy-binding keyword triggers) into agent sessions running tool-intensive, long-horizon, or policy-bound tasks at temperature 0. Outputs are structured as per-run contamination labels from an LLM-as-judge (Gemini-2.0-Flash-Lite, context-isolated from the contaminated session), aggregated into contamination rates with Wilson 95% CIs, behavioral drift scores relative to a no-PSE baseline, defense reduction percentages, and per-turn persistence curves. A critical methodological detail is that keyword-based detection produces systematic false positives on factual-correction scenarios (83% FP rate), so judge-based labels are canonical for ablation and defense experiments.

## Method

The paper formalizes PSE as a triple (N, T, P)—a name-binding function mapping string identifiers to handlers, an event-triggering function mapping runtime events to activated bindings, and a propagation function mapping (binding, context) pairs to downstream activations across session/agent boundaries. A dual-architecture platform (Rust core for deterministic PSE behavior with full provenance tracking, Python harness connecting 24 models across 11 families) enables controlled experimentation with three configurations (no_pse, pse_basic, pse_full). The load-bearing result is a 2³ factorial contamination ablation (n=320) showing name binding is necessary: every configuration without it yields 0% contamination (Cohen's d=3.26), while event triggering and propagation have negligible main effects (|d|≤0.26). Temporal persistence probes (10-turn main text, 20-turn appendix) reveal type-dependent decay: preference and instruction contamination persist undecayed, persona decays partially (90%→10%), and factual contamination is model-dependent (self-corrected on Llama-3.1-8B and GPT-4o-mini but held at ceiling on Qwen2.5-coder variants). Defense evaluation shows context-isolated self-verification achieves 20–79% reduction without oracle references, while in-context self-reflection is unreliable (ranging from −14% to +45%), and a four-stage multi-agent pipeline compounds contamination 1.9× (40%→75%) without boundary validation.

## Results

Across 24 models from 11 families (1.5B–1T parameters), every model shows non-zero PSE contamination (20–100%, median 70% on the 20-model panel). Name binding is the necessary and dominant mechanism: removing it drops contamination to 0% (Cohen's d = 3.26 on Gemini, 1.37 on Llama), while event triggering and propagation have negligible main effects (|d| ≤ 0.26). On the defense panel, context-isolated self-verification (CIV) achieves 20–79% contamination reduction (median 36.5%) without oracle references, and external validation (SRV) achieves 50–100% reduction (median 100%; 7/8 models ≤ 10% residual). Preference and instruction contamination persist undecayed through turn 10 (100%, 95% CI [0.72, 1.00]), while factual contamination is self-corrected on some models (0%) and persona contamination decays partially (90% → 10%).

## Baselines & Comparisons

The paper's central comparison is among three defense strategies: in-context self-reflection, context-isolated self-verification (CIV), and external validation (SRV). In-context self-reflection is highly unreliable, ranging from −14% (contamination *increases* on Claude-Sonnet-4, 70%→80%) to +45% (Gemini-2.0-Flash), with 0% reduction on GPT-4o-mini. CIV, which isolates the verification call from the contaminated context, consistently reduces contamination by 20–79% (median 36.5%) across all 8 defense-panel models, with Gemini-Flash-Lite as the high outlier (79%) and GLM-4-Plus/MiniMax as the low end (20%). External validation (SRV) dominates both: it achieves ≥87% reduction on 7 of 8 models (median 100%), with MiniMax-Text-01 (50%) and DeepSeek-V3 (87%) as the exceptions, suggesting very large models produce more convincing contaminated outputs that fool cross-model validators. On the mechanism ablation, name binding alone produces 95% (Gemini) / 45% (Llama) contamination, while every configuration lacking name binding sits at 0%, establishing it as the necessary enabling mechanism. In the multi-agent cascade (E3), contamination amplifies 1.9× (40%→75%) across four pipeline stages without boundary validation, whereas SRV at agent boundaries achieves 100% blocking.

## Relation to Prior Work

This paper carves new ground by formalizing Persistent Semantic Entities (PSE) as a (N, T, P) tuple—name binding, event triggering, and cross-boundary propagation—explicitly distinguishing the phenomenon from prompt injection (bounded to a single context window), memory poisoning (data-layer corruption), and caching artifacts. It draws conceptual analogies from model collapse (Shumailov et al., 2024) for multi-agent propagation and from agent security benchmarks (AgentDojo, InjecAgent) for evaluation methodology, but contributes the orthogonal axis of *semantic-level* persistence via naming and event mechanisms that arise even without an explicit memory module. The empirical study repurposes standard LLM-agent evaluation infrastructure (tool registries, event hooks, multi-agent pipelines) to isolate and measure a phenomenon no prior benchmark targets directly.

## Why It Matters / Open Questions

The finding that preference and instruction contamination persist undecayed through turn 10 while factual contamination self-corrects (on some models) redirects defensive effort toward the contamination types that actually threaten deployed agent systems, and identifies the tool registry (name binding) as the single critical attack surface. The practical defense—context-isolated self-verification achieving 20–79% reduction without oracle references—is immediately deployable. Key limitations temper generalizability: temporal persistence is measured on Llama-3.1-8B only (n=10), scenarios are synthetic by design, the scale regression is unresolved at n=7, and the LLM-as-judge shares a vendor with some evaluated models. Open questions include whether persistence extends beyond the 20-turn horizon, whether findings hold in production-shaped multi-agent deployments, and whether the type-dependent asymmetry generalizes across architectures.

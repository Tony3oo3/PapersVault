## Problem

Explanations of ML models are typically validated via proxy properties (faithfulness, robustness, self-reported interpretability) that are weakly tied to the functional purpose explanations serve in practice. Without a decision-theoretic grounding for what best-case explanation use looks like, it is difficult to interpret whether an explanation was effective or diagnose why performance falls short, a gap underscored by meta-analytic evidence that explanations do not significantly improve human decision quality.

## Input / Output

The framework takes a formal decision task specification (state space, action space, utility function, prior), an information model estimated from labeled evaluation data, and optionally human baseline decisions. A key practical detail is that high-dimensional signals (images, text) must be coarsened via learned clustering maps to prevent the rational agent benchmark from overfitting, with the coarsening constrained to preserve Blackwell garbling relationships among features, predictions, and explanations. The output is a structured three-step validation: theoretic value (Δ_E), human-complementary value (Δ_E_compl), and behavioral value (Δ_E_behavioral), each further decomposable into independent (explanation-alone) and contextual (features-unlocked) components.

## Method

The core theoretical result (Proposition 1) shows that because explanations are deterministic functions of features and model predictions, they are Blackwell garblings of the instance-level signal and add no information for a rational Bayesian agent—so the rational agent benchmark with features X alone (R_X) upper-bounds any agent's performance. The framework defines three estimands along a validation sequence: (i) theoretic value Δ_E = R_X − R_∅ quantifies the total decision-relevant information in the features; (ii) human-complementary value Δ_E_compl = R_X − R_{A^H} measures how much of that information is not already captured by baseline human judgment; and (iii) behavioral value Δ_E_behavioral = B − B_{¬E} captures the causal effect of deploying the explanation. In practice, the information model is estimated via a coarsening algorithm (Algorithm 1) that searches over clustering granularities to maximize held-out rational performance subject to a train-test gap constraint, and robustness to utility ambiguity is handled via worst-case analysis over V-shaped proper scoring rules (Blackwell order).

## Results

On the medical treatment task (MIMIC-IV/CXR), the theoretic value of explanation Δ_ε ≈ 0.12 (~25% of the rational baseline), with example-based explanations (factual/counterfactual) showing larger independent theoretic value than saliency-based methods (LIME, SHAP). In the deception detection re-analysis, all three explanation types yield positive behavioral value: Heatmap 0.10 [0.07, 0.13], Examples 0.08 [0.04, 0.11], and Random Heatmap 0.07 [0.03, 0.10]. In sentiment classification (Amazon Books, Beer), behavioral values are near zero or negative (e.g., Beer Explain-top-1: −0.01 [−0.02, 0.00]), consistent with the framework's prediction that explanations offer little human-complementary information. In the alignment audit (Jigsaw), the ATE increases monotonically with SAE features: 0.00 (top-1) → 0.02 (top-3) → 0.04 (top-5), while theoretic value plateaus after SAE-top-3.

## Baselines & Comparisons

The paper does not propose a new explanation method to benchmark against existing ones; instead, it evaluates multiple explanation types (LIME, SHAP, factual/counterfactual examples, SAE features) through its decision-theoretic lens. The key comparison is between explanation types on the same task: in deception detection, all three explanation conditions reliably outperform the no-explanation baseline (0.07–0.10 accuracy gain), whereas in sentiment classification none do (gains ≤ 0.01, often negative). The framework's diagnostic value is demonstrated by its ability to predict these outcomes ex ante: the human-complementary value Δ_ε_compl is large for deception detection (humans are poor at judging deception without help) but near zero for sentiment classification (humans already extract most relevant information), correctly anticipating where explanations will and will not help. In the alignment audit, SAE-top-3 through SAE-top-5 explanations show increasing behavioral value (0.02→0.04) while theoretic value plateaus after top-3, indicating under-extraction of available information by the simulated human (Qwen3-14B) and motivating further interventions.

## Relation to Prior Work

This paper extends the decision-theoretic framework for AI reliance measurement (Guo et al., FAccT 2024) to the specific problem of explanation evaluation, leveraging Blackwell's informativeness theorem to prove that explanations are informationally redundant with the underlying features for a rational agent (Proposition 1). It departs from the dominant paradigm of evaluating explanations via proxy properties (faithfulness, robustness, self-reported interpretability) and from prior value-of-explanation estimates (e.g., Chen et al. 2022) by formalizing three distinct estimands— theoretic, human-complementary, and behavioral value—within a unified rational-agent benchmark. The robust analysis via V-shaped proper scoring rules (Hu & Wu 2024) and the rational agent baseline (Wu et al. 2023) provide the technical scaffolding, while the paper positions itself squarely within the 'pragmatic turn' in XAI that calls for linking explanations to concrete decision tasks rather than abstract properties.

## Why It Matters / Open Questions

The framework provides a structured, diagnostic three-step workflow (theoretic → human-complementary → behavioral) that can identify *why* an explanation fails to improve decisions—whether the problem lacks decision-relevant information, humans already exploit it, or participants simply don't use the explanation effectively. Key limitations include the need to specify a decision problem (which may be ambiguous in practice), the heuristic nature of the coarsening algorithm for high-dimensional signals, and the requirement for labeled ground-truth states. Open questions include whether the framework captures all mechanisms by which explanations help (e.g., trust calibration, communication between team members), how it scales to multi-action or continuous-state settings, and whether the LLM-simulated 'human' decisions in the alignment audit adequately proxy real human behavior.

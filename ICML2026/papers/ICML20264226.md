## Problem

Existing symbolic regression methods for discovering governing ODEs rely almost exclusively on quantitative metrics such as MSE or model complexity to evaluate candidate equations. However, equations with similarly low numerical error can encode entirely different physical mechanisms, making purely numerical evaluation insufficient for ensuring physical plausibility. This paper addresses the gap by integrating LLM-based qualitative (semantic/physical) reasoning directly into the iterative search loop alongside quantitative validation.
![Teaser figure](../imgs/ICML20264226/cropped_page0_idx0.webp)

## Input / Output

The method takes two inputs: (1) time-series state observations D = {(t_i, x(t_i))} with 1000 uniformly sampled points, and (2) a natural-language system description T containing domain-specific physical principles while explicitly prohibiting any mathematical formula or symbolic form to prevent equation-level leakage. The output is a vector-valued ODE system x_dot = f(t, x) expressed as executable Python snippets with learned parameter placeholders, where each term is paired with a natural-language physical justification. The framework discovers equations for multi-dimensional systems (2D and 4D) beyond simple polynomial forms, including rational, trigonometric, and exponential terms.

## Method

DoLQ is a multi-agent iterative framework with three components: a Sampler Agent (LLM) that proposes candidate ODE terms with physical justifications grounded in the system description and prior feedback; a Parameter Optimizer that constructs executable functions and fits coefficients via a hybrid strategy combining differential evolution (global search) with BFGS (local refinement), using residual MSE for per-dimension credit assignment; and a Scientist Agent that performs dual evaluation—qualitative semantic grading (good/neutral/bad) of each term's physical plausibility via LLM reasoning, and quantitative ablation testing that measures each term's marginal contribution to MSE by zeroing its coefficient. The Scientist Agent synthesizes both evaluations into keep/hold/remove decisions using a 2-strike rule, with removed term skeletons recorded to prevent reproposal and a probabilistic forgetting mechanism (p=0.01) to allow re-exploration. This qualitative-quantitative feedback loop guides the Sampler toward physically consistent, compact equations, achieving higher success rates and more accurate structural recovery than baselines that rely solely on numerical fit.

## Results

On the CDIMA(2D) system with complex nonlinear saturation terms, DoLQ achieves an integral NMSE of 2.35×10⁻⁸ (ID) and 1.15×10⁻⁷ (ID-Ext), outperforming the best baseline (ICSR at 3.78×10⁻⁴) by over four orders of magnitude. On Glider(4D), DoLQ and LLM-SR are competitive (8.29×10⁻⁷ vs. 8.54×10⁻⁷ integral NMSE), while ICSR, LASR, and EDL fail catastrophically. On the simpler SIR(2D) system, all viable methods achieve NMSE below 10⁻⁸, indicating the problem is tractable for existing approaches. Across all eight benchmark ODEs, DoLQ achieves the highest success rate on both the NMSE test (integral NMSE < 10⁻³ across all dimensions) and the Term test (correct structural recovery).

## Baselines & Comparisons

DoLQ decisively outperforms all four baselines on CDIMA(2D), where its integral NMSE of 2.35×10⁻⁸ is roughly 4–5 orders of magnitude lower than ICSR (3.78×10⁻⁴), LLM-SR (3.14×10⁻³), and LASR (2.90×10⁻¹), while EDL diverges entirely (1.33×10⁵). On Glider(4D), DoLQ matches LLM-SR (8.29×10⁻⁷ vs. 8.54×10⁻⁷ integral NMSE) but surpasses ICSR (2.55×10⁻¹) and LASR (4.94×10⁻¹) by 5–6 orders of magnitude; EDL again fails with NaN. On the simpler SIR(2D) system, DoLQ is competitive with LASR and LLM-SR (all below 10⁻⁸), confirming no regression on easy problems. Structurally, DoLQ recovers the correct ground-truth terms with fewer spurious components than LLM-SR, which proposes verbose equation skeletons with many unnecessary terms. The Scientist Agent ablation (Figure 6) shows that removing qualitative evaluation slows convergence from iteration 27 to iteration 62 on Glider(2D), confirming that the qualitative-quantitative dual evaluation is the key differentiator over purely numerical baselines.

## Relation to Prior Work

DoLQ extends the LLM-based symbolic regression line (LLM-SR, LASR, ICSR, EDL) by introducing a multi-agent architecture where a dedicated Scientist Agent performs qualitative semantic evaluation of candidate terms alongside quantitative ablation-based assessment. Prior LLM-SR methods rely almost exclusively on numerical fit (MSE, R²) to guide search, and the paper's central argument—that equations with similar numerical error can encode different physical mechanisms—is motivated by this gap. The hybrid parameter optimizer (differential evolution + BFGS) addresses a practical failure mode of gradient-based optimization in rugged symbolic regression landscapes, and the iterative keep/hold/remove feedback loop with probabilistic forgetting is a new control mechanism not present in prior evolutionary or LLM-based SR frameworks.

## Why It Matters / Open Questions

The paper demonstrates that embedding LLM-based physical plausibility reasoning into the search loop accelerates convergence and yields more compact, structurally correct equations, which is practically important for interpretable scientific modeling. However, all experiments use noise-free, low-dimensional (2D–4D) ODEs from ODEbench, so generalization to noisy real-world data, higher-dimensional systems, and PDEs remains open. The authors acknowledge that parameter optimization via finite-difference derivatives is sensitive to measurement noise and that reasoning fixation can cause premature convergence, both of which limit immediate deployment. Extension to PDEs is flagged as a significant future direction given the absence of universal PDE solvers.

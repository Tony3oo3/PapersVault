## Problem

RL-based reasoning segmentation methods suffer from overthinking: verbose reasoning chains reduce computational efficiency and cause attention dispersion that misleads object localization. Prior fixes like PixelThink rely on an external 72B expert MLLM to estimate query difficulty and constrain reasoning length, which introduces a heavy auxiliary dependency and prevents the base model from developing intrinsic self-organizing reasoning. The paper asks whether a model can self-supervise its own reasoning efficiency and accuracy without any external reward model or thinking supervision.

## Input / Output

The method takes an RGB image and a free-form natural-language query (e.g., 'the part of a building that provides support and stability') and produces a structured output: a chain-of-thought reasoning block, an explicit referring description (a short phrase like 'adult holding hand'), and a JSON-formatted answer containing 2D bounding boxes and points. These spatial answers are fed to a SAM2 or SAM3 segmentation model to yield the final binary mask. During inference only the first-pass output is used, so the two-stage rollout adds no inference cost; the second pass is a training-time self-verification mechanism.

## Method

DR²Seg decomposes reasoning segmentation into two rollout passes of the same MLLM: the first pass generates a reasoning chain, an explicit referring description, and a spatial answer from (image, query); the second pass re-prompts the model with (image, description) to produce a second reasoning chain and answer. Two self-rewards are derived from this structure: a description self-reward that credits the first-pass description when the second-pass answer is correct (verifying self-containment), and a length-based self-reward that encourages the second-pass reasoning to be shorter than the first, regularized by an absolute token-length anchor N₀ to prevent synchronous inflation (reward hacking). The total reward is computed multiplicatively as (R_base + R_desc) · R̃_len, where the length gate is conditionally disabled when all rollouts in a group yield zero accuracy, avoiding premature compression during early training. The model is optimized with GRPO, and the paper provides information-theoretic justification via a data-processing inequality and information-bottleneck argument showing that the description acts as a sufficient statistic that reduces conditional answer entropy and thus expected reasoning length.

## Results

On the ReasonSeg benchmark, DR²Seg achieves 68.5% gIoU and 65.8% cIoU with only 26.9 reasoning tokens in the few-shot setting (239 training samples), setting a new state-of-the-art. In the zero-shot setting, it reaches 67.5% gIoU with 46.2 tokens, outperforming the VisionReasoner baseline (66.3% gIoU, 80.8 tokens) by 1.2% gIoU while halving inference tokens. After few-shot fine-tuning, DR²Seg* surpasses VisionReasoner* by 3.1% gIoU on validation and 3.8% on test, while reducing reasoning tokens by approximately 3× (26.9 vs. 85.3). On referring segmentation (RefCOCO/RefCOCO+/RefCOCOg), DR²Seg* achieves 79.3/75.4/73.4 testA/test scores, matching or exceeding all baselines.

## Baselines & Comparisons

DR²Seg outperforms all 11 baselines on the primary ReasonSeg benchmark. Against the closest RL-based competitor VisionReasoner (the direct baseline), DR²Seg* gains +3.1% gIoU on validation and +3.8% on test while using ~3× fewer tokens (26.9 vs. 85.3). PixelThink, which relies on an external 72B expert MLLM for difficulty estimation, is surpassed by DR²Seg* by +4.7% gIoU (68.5 vs. 63.8) on validation with comparable token counts. Seg-Zero and SAM-R1, earlier RL-based methods, trail by 6.9% and 4.5% gIoU respectively. SFT-based methods (LISA, CoReS, PixelLM, PerceptionGPT) and non-MLLM methods (OVSeg, ReLA, LAVT) are all substantially outperformed on ReasonSeg. On the simpler RefCOCO referring segmentation task, DR²Seg* (79.3/75.4/73.4) slightly trails PerceptionGPT (78.6/73.9/71.7) on refCOCO testA but leads on refCOCO+ and refCOCOg, confirming that the self-rewarding framework does not degrade performance on straightforward queries.

## Relation to Prior Work

DR²Seg extends the RL-based reasoning segmentation lineage (Seg-Zero → VisionReasoner) by introducing a self-rewarding two-stage rollout that decomposes the task into multimodal reasoning and referring segmentation. It departs from PixelThink, which relies on an external 72B expert MLLM to estimate query difficulty and implicitly supervise reasoning length, by instead using the model's own second-pass prediction on a generated description as a self-verification signal. The approach also draws on the broader self-rewarding RL paradigm (Yuan et al., 2024; Zhou et al., 2024) but is the first to apply it to reasoning perception, where modality gaps between text and spatial coordinates make attention dispersion a particular risk.

## Why It Matters / Open Questions

The key practical contribution is a ~3× reduction in reasoning tokens with simultaneous accuracy gains, achieved without any external supervision model—making the framework more scalable and self-contained than PixelThink's 72B-dependent design. The information-bottleneck interpretation of the description as a sufficient statistic provides a principled justification for why the two-stage structure reduces overthinking, though the analysis relies on assumptions (Markov chain, IB optimality) that are not empirically verified. Open questions include whether the description bottleneck generalizes to video segmentation or dense multi-object scenes, whether the length anchor N0 can be learned rather than hand-tuned, and whether the approach transfers to MLLM families beyond Qwen2.5-VL.

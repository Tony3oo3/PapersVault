## Problem

Transferring task-specific parameter updates (task vectors) between pre-trained models has been studied only for identical architectures; when models differ in width, direct parameter transfer is ill-posed because the representation spaces have incompatible dimensionality and geometry. This paper asks whether a task update learned by one model can be transported to a different-width model without any additional training or backpropagation.
![Teaser figure](../imgs/ICML20263875/cropped_page0_idx0.webp)

## Input / Output

The method consumes the source base weights θ_A, the source fine-tuned weights θ_A^ft (from which the task vector τ_A = θ_A^ft − θ_A is extracted), the target base weights θ_B, and a small calibration set used only for forward-pass activation collection. For vision models with mismatched patch counts, source activations are resampled to the target sequence length via 2D bilinear interpolation before alignment. The output is a per-layer transported update τ_B applied as θ_B + ατ_B across all Transformer linear submodules (attention projections and MLPs), with positional and patch embeddings excluded; cross-covariance statistics are accumulated in a streaming fashion so memory is bounded by O(d_A × d_B) independent of the number of calibration tokens.

## Method

THESEUS defines task identity functionally rather than parametrically: a task update is characterized by the bilinear form G_A = ΔH_out,A · H_out,A^T it induces between input and output activations, and transport seeks a target update τ_B whose induced bilinear form matches G_A. Because this matching problem is underdetermined across mismatched-width representation spaces, the authors impose orthogonality constraints and solve two orthogonal Procrustes problems (one for input, one for output activations) via SVD of the cross-covariance matrices H_in,A^T H_in,B and H_out,A^T H_out,B. The resulting closed-form transport rule τ_B = T_out · τ_A · T_in^T rotates the source update through the aligned shared subspaces, preserving the Frobenius norm and geometric structure of the update while accommodating arbitrary width mismatches. The entire pipeline requires only forward passes on a frozen calibration set—no gradients, no optimizer states—making it a strictly training-free operation.

## Results

On the primary width-mismatch setting (ViT-B/16 LAION-2B → ViT-B/16+ LAION-400M), THESEUS with 50 alignment batches achieves 69.48% average accuracy across 8 vision datasets, a +10.72 pp improvement over the target's zero-shot baseline (58.76%), recovering roughly one-third of the gap to full fine-tuning (90.39%). In the identical-architecture setting (ViT-B/16 DataComp-XL → ViT-B/16 LAION-2B), THESEUS reaches 75.47% at K=20 (+15.16 pp), outperforming both TransFusion (61.46%) and GradFix (73.68%). For language (T5-3B → T5-Large linear probing), transporting the encoder update yields 79.91% average accuracy at B=20, a +22.04 pp gain over the target baseline.

## Baselines & Comparisons

Against TransFusion (Rinaldi et al., 2025), a training-free rebasin method limited to identical architectures, THESEUS achieves a consistent ~10 pp advantage in average accuracy improvement (e.g., 71.40% vs 61.46% at K=1; 75.47% vs 61.46% at K=20), demonstrating that functional Procrustes alignment captures far more transferable structure than permutation-based weight matching. Against GradFix (Rinaldi et al., 2026), a gradient-based transport method, THESEUS matches or slightly exceeds performance at every K-shot level (e.g., 73.73% vs 73.34% at K=5; 75.47% vs 73.68% at K=20) while requiring only forward passes and no backpropagation. In the width-mismatch setting (Table 1), where neither baseline applies, THESEUS at B=50 reaches 69.48% (+10.72 pp), whereas pseudo-inverse transport collapses to 56.80% (−1.96 pp) and zero-padding to 58.50% (−0.26 pp), confirming that orthogonal alignment is essential for stable cross-width transfer. THESEUS also shows markedly better robustness to the update-scaling coefficient α, maintaining a stable accuracy plateau (71.21/73.32/73.33 for α=1/1.5/2) while GradFix drops precipitously (54.54→44.64→36.12).

## Relation to Prior Work

This paper extends the task-vector transfer paradigm established by task arithmetic (Ilharco et al., 2023) and rebasin-of-task-vectors (Rinaldi et al., 2025), which operate exclusively between same-architecture models with matching parameter dimensions. The key departure is shifting from parameter-space alignment to a functional matching objective on observed activations, resolved via orthogonal Procrustes analysis, which naturally accommodates width mismatches without requiring bijective feature correspondence. Unlike knowledge distillation or Net2Net-style approaches that relearn tasks in the target model, THESEUS transports the update itself in closed form, and unlike prior rebasin methods (TransFusion, GradFix), it requires no backward passes or iterative optimization.

## Why It Matters / Open Questions

The method offers a practical, training-free mechanism for reusing task-specific fine-tuning across model families of different sizes, reducing the compute cost of adapting every variant independently. However, the gap to full fine-tuning remains substantial (e.g., ~69% vs ~90% average accuracy in the width-scaling setting), and the depth-mismatch extension relies on a deliberately naive interpolation heuristic that degrades the source model to 8.5% accuracy before transport. Open questions include principled depth alignment, applicability to non-Transformer architectures, and whether the functional-identity framing generalizes to tasks where the relevant representation geometry is not captured by a single layer's input-output bilinear form.

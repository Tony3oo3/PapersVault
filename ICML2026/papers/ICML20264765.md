## Problem

Existing diffusion-based data augmentation methods for federated learning assume a balanced global class distribution and generate synthetic samples to rebalance each client's local dataset. In practice, global distributions are often inherently imbalanced, and privacy constraints prevent the server from accurately estimating the true global distribution, making balance-oriented augmentation suboptimal. The key underexplored question is how to generate and select synthetic data that aligns local distributions with a true, yet unknown, global distribution.

## Input / Output

The method takes RGB images (32×32 for CIFAR-10/100, 64×64 for Tiny-ImageNet) as classification input and produces class labels via ResNet-8 or ResNet-10 local models. On the server side, Stable Diffusion v1-4 generates 512×512 images from text prompts (e.g., 'a photo of a {class}'), which are then resized to the target dataset resolution. The output of the data generation pipeline is a set of selectively assigned synthetic images per client, augmented to their private training sets, with the final output being a globally aggregated classifier.

## Method

FedPDG's core insight is that the prediction discrepancy between a local model and the global model on a synthetic sample reveals whether the client's data underrepresents that sample's class (formally proven via Bayes' theorem and strictly proper scoring rules). The server generates candidate images with a diffusion model, then assigns a sample to client i only if the local model's loss exceeds the global model's loss and the global model's confidence exceeds 1/C (a confidence-aware filter that also bounds gradient variance). An exponential decay scheduler controls the per-round supply quantity, front-loading synthetic data when the discrepancy signal is most informative. To personalize generation, the server trains a lightweight LoRA module per client via Discrepancy Preference Optimization (DPO), using a reward that favors samples where the global model is confident, the local model is uncertain, and the two models disagree on the predicted class. The entire pipeline introduces no additional client-side computation and is plug-and-play with standard FL aggregation.

## Results

On CIFAR-10 with α=0.5 (moderate heterogeneity), FedPDG achieves 57.09% top-1 accuracy, outperforming the strongest baseline Gen-FedSD (53.27%) by 3.82 percentage points. On CIFAR-100 (α=0.1), FedPDG reaches 37.41% versus Gen-FedSD's 36.80% and FedAvg's 34.19%. On Tiny-ImageNet (α=0.1), FedPDG attains 23.27% compared to CRFed's 22.43% and FedAvg's 20.94%. The method also generalizes to the EuroSAT satellite domain, achieving 91.10% at α=0.5 versus the best baseline FedProto's 90.98%.

## Baselines & Comparisons

FedPDG consistently outperforms all nine baselines across every dataset and heterogeneity level tested. The closest competitor is Gen-FedSD (Morafah et al., 2024), which also uses Stable Diffusion for balanced class augmentation; FedPDG surpasses it by 1.32–3.82% on CIFAR-10 and 0.61–1.90% on CIFAR-100, with the largest gap (3.82%) at α=0.5 where the imbalanced global distribution most penalizes balance-oriented generation. CRFed (Xiao et al., 2024), the strongest non-generative baseline, is outperformed by 2.23–5.23% on CIFAR-10 and 0.89–1.34% on CIFAR-100. Traditional FL methods (FedAvg, FedProx, FedProto) and feature-level approaches (FedETF, FedFA) trail by 4–14% on CIFAR-10, confirming that data-distribution alignment via targeted synthetic generation is more effective than parameter-level regularization under high heterogeneity. The generative baselines GenFL and DPSDA-FL, which assume a balanced global distribution, underperform FedPDG by 2.84–5.65% on CIFAR-10, validating the paper's core claim that prediction-discrepancy-guided selection is superior to balance-oriented augmentation when the true global distribution is imbalanced.

## Relation to Prior Work

This paper extends the line of federated generative learning (Gen-FedSD, GenFL, DPSDA-FL) that uses diffusion models to synthesize client-side data for mitigating non-IID heterogeneity. The key departure is rejecting the balanced-global-distribution assumption that underpins prior work: instead of generating rare-class samples to rebalance each client, FedPDG uses the prediction discrepancy between local and global models as a distributional signal to selectively supplement data, and personalizes the generator via DPO-trained LoRA modules. The theoretical grounding (Theorem 3.1) connects this selection criterion to Bayes-optimal posteriors under label-shift, providing a principled justification that prior heuristic-based augmentation methods lack.

## Why It Matters / Open Questions

FedPDG addresses a practically important gap: most real-world FL deployments (e-commerce, wildlife monitoring, web content) have inherently imbalanced global distributions where enforcing local balance is counterproductive. The method is privacy-preserving (no label distribution leakage to the server), computationally efficient (~40% of FedAvg client cost), and plug-and-play with existing FL algorithms. Limitations include dependence on diffusion model quality for out-of-domain data (EuroSAT degrades at mild imbalance), O(N) DPO overhead at scale (mitigated by a shared-LoRA variant), and evaluation limited to relatively small per-client datasets (500–1500 samples). Open questions include validation in large-scale real-world federated deployments and integration with cost-sensitive learning for asymmetric-cost domains.

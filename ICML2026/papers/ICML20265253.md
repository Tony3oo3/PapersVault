## Problem

The standard retrieve-then-rerank approach for combining a cheap proxy metric with an expensive ground-truth metric in nearest neighbor search is fundamentally limited: its accuracy is capped at a C-approximation (where C is the distortion between the two metrics), and it requires a linear scan over all retrieved candidates. No prior work provides a principled framework with provable guarantees for constructing data structures using only the cheap metric while achieving the full accuracy of the expensive metric during query with sublinear cost.

## Input / Output

The method takes a query text passage and a pre-built graph index (DiskANN or NSG) constructed exclusively from cheap proxy embeddings (e.g., bge-micro-v2, 384-dim), and produces top-k nearest neighbor passages ranked by the expensive metric D. The expensive metric D can be either an embedding model (SFR-Embedding-Mistral, 4096-dim, where D(p,q) = ‖f(q)−f(p)‖₂) or an LLM-based listwise reranker (Gemini-2.0-Flash) that returns a relative ordering of passages rather than independent scores. The cost model counts only the number of D evaluations during query; the graph index construction uses zero D calls, making it stable under frequent updates to the expensive model.

## Method

The core mechanism is a 'metric switch' on graph-based ANN structures: the graph index (an α-shortcut reachability graph for DiskANN, or a multi-scale cover tree) is built entirely under the cheap proxy metric d, but the greedy search during query uses the expensive metric D. The key theoretical insight is that if d is a C-approximation of D, then a C/ε-shortcut reachability graph under d is automatically a 1/ε-shortcut reachable graph under D (Lemma 3.4), so the standard greedy search guarantees a (1+ε)-approximate NN under D in sublinear time. Practically, the algorithm runs a two-stage search: first, it traverses the graph using d to obtain Q/2 starting points near the query, then it continues the greedy search on the same graph using D until the budget Q is exhausted, reporting the top-10 by D. This adaptive traversal corrects for metric disagreements along the path, unlike retrieve-then-rerank which is stuck with whatever the cheap metric retrieves. The paper also proves an impossibility result showing that LSH and other partition-based methods cannot achieve sublinear query time in this bi-metric setting, highlighting the essential role of graph connectivity.

## Results

On the 6 large BEIR retrieval datasets (corpus size >10⁶), the bi-metric method achieves comparable NDCG@10 to the retrieve-then-rerank baseline using fewer than 2000 expensive distance calls versus ~8000 calls for the baseline on HotpotQA, a >4× reduction. In the Gemini-2.0-Flash LLM reranker setting, the method achieves the same average NDCG@10 as re-ranking with only ~200 API calls compared to ~800 calls (4× reduction). The method also converges faster than the single-metric baseline (which builds the graph index directly with D) across all datasets, and outperforms it on Recall@10 in most cases except FEVER and HotpotQA.

## Baselines & Comparisons

The paper compares against two baselines: (1) Bi-metric baseline (retrieve-then-rerank), which retrieves top-Q items under the cheap metric d and re-ranks all Q items using D, and (2) Single metric, which builds the graph index directly with D and performs standard greedy search. The proposed bi-metric method (two-stage search: first stage under d, second stage under D on the same graph) consistently outperforms the retrieve-then-rerank baseline in NDCG@10 at the same query budget across nearly all 6 BEIR datasets, with the gap largest when the quality gap between cheap and expensive models is greatest (e.g., bge-micro-v2 vs. SFR-Embedding-Mistral). Against the single-metric baseline, the proposed method converges to optimal accuracy faster in all datasets, even though the single-metric method is allowed unlimited D calls during index construction, suggesting that early routing guided by the cheap proxy is more efficient than a D-built graph. On Recall@10, the proposed method beats single metric in most cases except FEVER and HotpotQA. In the LLM reranker (Gemini-2.0-Flash) setting, the method achieves higher NDCG@10 while sending fewer passages to the reranker compared to the re-ranking baseline.

## Relation to Prior Work

This paper formalizes and provides the first provable guarantees for a 'bi-metric' nearest neighbor search framework, where a cheap proxy metric d builds the index and an expensive ground-truth metric D is used during query. It builds directly on the theoretical analysis of DiskANN via α-shortcut reachability graphs (Indyk & Xu, 2023) and Cover Tree theory (Beygelzimer et al., 2006), showing that the graph connectivity properties are preserved under the metric switch. The approach departs from the standard retrieve-then-rerank paradigm, which is provably limited to a C-approximation, and from prior bi-metric work (Moseley et al., 2021; Silwal et al., 2023) that focused on clustering rather than search. A key negative result shows that LSH and other partition-based methods fundamentally cannot achieve sublinear query time in this setting, highlighting the unique advantage of graph-based approaches.

## Why It Matters / Open Questions

The framework offers a principled, general recipe for any graph-based ANN algorithm to inherit the accuracy of an expensive metric while only paying for a sublinear number of expensive evaluations, with a 4x reduction in API calls demonstrated on BEIR benchmarks. The LSH impossibility result clarifies a fundamental algorithmic boundary: adaptive, iterative graph traversal is not merely preferable but necessary for the bi-metric setting. Open questions include whether the bounded-distortion assumption (Equation 1) can be relaxed, whether the framework extends to other algorithm families beyond graph-based methods, and how it behaves when the proxy metric is derived via quantization rather than a separate model.

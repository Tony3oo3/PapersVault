## Problem

Existing VFM-based domain generalized object detection methods adapt frozen backbones with fixed, style-agnostic adapters, implicitly treating the task gap between pretraining and dense detection as a static discrepancy across all domains. This overlooks the fact that different visual styles (e.g., fog, rain, night) induce distinct task mismatches that a single static compensation cannot address, leading to degraded generalization on unseen target domains.
![Teaser figure](../imgs/ICML20261952/cropped_page0_idx0.webp)

## Input / Output

The method takes a single RGB image (H×W×3) from an unseen target domain and produces bounding boxes with class labels (7 categories on Urban Scene). Unusually, the input image is first decomposed via 2D FFT into amplitude and phase components; the low-frequency amplitude is replaced with an adversarially mixed style vector drawn from a learned memory of K=64 spectral prototypes, producing a style-perturbed image for training. At inference, the style vector extracted from the input conditions both the adapter routing and the detection queries, so the same frozen VFM backbone follows different adaptation trajectories per input style.

## Method

SCoA comprises three tightly coupled modules operating on a frozen VFM backbone (DINOv2-L, SAM-H, or EVA02-L) with only 8.4M trainable parameters. (1) Spectral Style Modeling (SSM) maintains a memory of low-frequency FFT amplitude vectors from local image crops, updated via EMA with a triplet diversity loss, and generates worst-case style perturbations through GDPO-based adversarial mixing on the simplex. (2) Mixture-of-Tokens Adaptation (MTA) parameterizes per-layer tokens as T_l = A_l · Σ π_l^i B_l^i, where A_l is a shared low-rank matrix capturing task-level commonalities and B_l^i are style-specific matrices selected by a top-k router conditioned on the style vector, enabling dynamic, style-aware feature refinement. (3) Style-Conditioned Query Refinement (SCQR) fuses multi-layer tokens via style-weighted coefficients and injects them into DINO detection queries through cross-attention, making the detection head explicitly style-aware while preserving instance-level query semantics for Hungarian matching. The overall loss combines standard detection loss with a triplet diversity loss on the style memory and a load-balancing regularization on the router.

## Results

On the Urban Scene dataset with a DINOv2-L backbone, SCoA achieves 59.4% average mAP across four unseen weather conditions (Day-Foggy, Dusk-Rainy, Night-Rainy, Night-Clear), outperforming the strongest VFM-based baseline Cauvis (57.5%) by 1.9% and the frozen backbone (49.7%) by 9.7%. On Cityscapes-C, SCoA achieves 40.4% mPC across 15 corruption types, surpassing Cauvis (35.6%) by 4.8% and the frozen DINOv2 backbone (32.3%) by 8.1%. The method uses only 8.4M trainable parameters, comparable to other PEFT baselines (4.7–6.3M).

## Baselines & Comparisons

SCoA consistently outperforms all 23 baselines across both evaluation benchmarks. Among VFM-based methods on Urban Scene (DINOv2-L), SCoA beats Cauvis (57.5% → 59.4%, +1.9% avg mAP), SoMA (54.3%), LoRA (53.3%), DoRA (52.7%), and AdaptFormer (52.8%), with the largest gap over the frozen backbone (49.7%, +9.7%). Among traditional DGOD methods using ResNet-101, SCoA's DINOv2-L results (59.4% avg) exceed the best ResNet-based method FGT (39.7%) by a wide margin of 19.7%, highlighting the advantage of VFM backbones combined with style-conditioned adaptation. On Cityscapes-C, SCoA (40.4% mPC) surpasses Cauvis (35.6%) by 4.8%, frozen DINOv2 (32.3%) by 8.1%, and all ResNet-50-based robustness methods (15.4–22.1% mPC) by over 18%. Across three different VFM backbones (EVA02, SAM, DINOv2), SCoA achieves 2.5%, 3.0%, and 3.9% mAP improvements over the strongest PEFT baseline Rein, confirming plug-and-play compatibility.

## Relation to Prior Work

This paper extends the VFM-based DGOD line initiated by Rein (Wei et al., 2024), which introduced learnable tokens for domain-generalized semantic segmentation, by reformulating token-based adaptation as a style-conditioned mixture-of-tokens mechanism for object detection. It departs from prior VFM-based DGOD methods (SoMA, Cauvis) that treat the pretraining-to-detection task gap as a static, style-agnostic discrepancy, instead modeling it as a dynamic, style-dependent mismatch that requires per-sample routing. The adversarial style mixing component borrows the GDPO simplex-constrained optimization from Sagawa et al. (2019), repurposing it to generate worst-case frequency-domain style perturbations from a learned memory of local spectral statistics.

## Why It Matters / Open Questions

The paper provides the first systematic evidence (via radar-plot discrepancy analysis and routing-vs-mismatch similarity comparison) that different visual styles induce qualitatively distinct task mismatches in VFM-based detectors, validating the core premise that static adapters are suboptimal. The style-conditioned MoE routing is a practical, plug-and-play technique (8.4M params) that transfers across DINOv2, SAM, and EVA02 backbones, making it broadly applicable to VFM adaptation beyond DGOD. Open questions include whether the style memory can cover truly novel styles absent from the source domain (the paper shows degradation when DF-style is missing from memory), and whether the adversarial mixing step is necessary at inference or only during training.

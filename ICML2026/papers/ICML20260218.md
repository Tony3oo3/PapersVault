## Problem

The standard matroid oracle model treats every independence query as O(1) regardless of the queried set's size, masking the true computational cost for natural matroid classes where a single query on a set of size k requires Ω(k) work (e.g., cycle detection in graphic matroids). This paper introduces a size-sensitive cost model where query cost equals |Q| and asks: what is the true query-cost complexity of fundamental matroid tasks—basis finding, rank estimation, and partition size—under this more faithful abstraction?

## Input / Output

The algorithm accesses a matroid M = (E, I) on n elements through a stateless independence oracle where each query Q ⊆ E costs |Q|, and the total cost is the sum over all queries. For the maximum-weight basis problem, the input additionally includes pairwise-distinct element weights. Outputs include an explicit basis (or rank), the partition size k(M), or a maximum-weight basis; the lower bounds apply even to the weaker distinguishing formulation (deciding between two close parameter values) rather than requiring full construction.

## Method

The lower bounds construct hard instance families where all sets of size ≤ n/3 are independent, forcing any informative query to have size Ω(n); a combinatorial counting argument (via Stirling's approximation) shows a fixed large set is a distinguishing witness for only an exponentially small fraction of random instances, so Ω(n) large queries are needed, yielding Ω(n²) total cost. Yao's principle extends these from deterministic decision trees to randomized algorithms. For upper bounds, the standard greedy algorithm achieves O(n²) for basis/rank, while partition size is solved by truncating the matroid to rank ⌈n/k⌉ and applying Quanrud's (2024) push-relabel base-covering algorithm in Õ(n²) cost. For matroids with bounded circumference c, a randomized algorithm samples subsets of size n^(1−1/c), uses binary search to locate the minimum-weight element in a dependent prefix, and removes it, achieving O(n^(2−1/c) log n) expected cost for the maximum-weight basis.

## Results

The paper establishes that under a size-sensitive query-cost model (where querying a set Q costs |Q|), both rank estimation and partition-size estimation require Ω(n²) total query cost in the worst case (Theorems 1.1 and 1.3), matching the Õ(n²) upper bounds achieved by explicit algorithms (Theorem 1.4 for partition size; the standard greedy algorithm for rank). For matroids with bounded circumference c, the quadratic barrier is broken: a randomized algorithm finds the maximum-weight basis in expected O(n^(2−1/c) log n) query cost (Theorem 1.2). The lower bounds are unconditional and hold even for weaker distinguishing formulations, and extend to general non-decreasing cost functions f, yielding Ω(n·f(n/3)) for rank and Ω(n·f(n/12)) for partition size (Theorems 1.5–1.6).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset comparisons. The primary 'comparison' is against the standard independence-oracle model where each query costs O(1) regardless of set size; under that model, the greedy basis-finding algorithm uses only O(n) queries, whereas under the size-sensitive model the same algorithm incurs Θ(n²) total cost, and the paper proves this is essentially optimal. The paper also contrasts with dynamic-oracle models (Blikstad et al., 2023) where queries differing by one element from a previously queried set are answered in O(1); the authors note their lower bounds are specific to the stateless model and do not extend to dynamic oracles. For the partition-size upper bound, the paper builds directly on Quanrud (2024), whose Õ(nk) independence-query algorithm for base-covering is adapted via a truncation trick to achieve the Õ(n²) total size-sensitive cost. No head-to-head empirical comparisons are presented.

## Relation to Prior Work

This paper departs from the standard independence-oracle model (where every query costs O(1) regardless of set size) and introduces a size-sensitive cost model where querying a set Q costs |Q|. It builds directly on Quanrud (2024)'s push-relabel algorithm for base-covering to achieve the near-tight upper bound for partition size, and explicitly contrasts its stateless model with the dynamic-oracle framework of Blikstad et al. (2023), where the greedy basis algorithm has subquadratic cost. The lower-bound techniques (Yao's principle, decision-tree counting, combinatorial witness arguments) are standard tools, but their application to the size-sensitive setting is new. The paper also connects to recent ML-community work (Eberle et al., 2024) that augments the oracle model to account for computational cost, though from a different angle.

## Why It Matters / Open Questions

The paper establishes that the widely used O(1)-oracle abstraction masks the true computational cost of matroid algorithms: for natural classes like graphic matroids, even a single independence query requires linear time, making the standard query-count analysis misleading. The tight quadratic bounds (up to log factors) for rank estimation and partition size mean that the greedy algorithm's O(n²) cost is essentially optimal in the general case, and the bounded-circumference result (O(n^{2-1/c} log n)) identifies a concrete structural parameter that breaks the barrier. Open questions include whether other structural parameters (e.g., bounded rank, specific matroid classes) admit subquadratic algorithms, and how size-sensitive costs affect broader matroid optimization problems such as matroid intersection or submodular maximization under matroid constraints.

## Problem

Iterative neural solvers for combinatorial optimization (e.g., diffusion-based and GNN-based) require dense evaluation of all edge/factor interactions at every refinement step, causing wall-clock time to scale as O(T|A|) and peak memory to grow linearly with the interaction set size. On large graphs this full-support sweep breaches hardware limits (OOM), and static spatial sparsification fails because conflict hotspots drift over the solver trajectory, causing error accumulation. The paper asks whether a hard per-step interaction budget can be enforced via dynamic, state-dependent routing to extend feasible inference scale while preserving solution quality.

## Input / Output

LoRe is a training-free inference-time wrapper that takes a graph G=(V,E), a pretrained solver checkpoint (e.g., DIFUSCO), and a budget ratio ρ (default 0.08) as inputs, and produces the same output as the unmodified solver: a maximum independent set for MIS or a tour sequence for TSP. The wrapper modifies only the per-step active interaction set M_t (|M_t| ≤ ⌊ρ|A|⌋) via runtime routing, leaving backbone parameters, refinement horizon T, and the greedy decode + repair post-processing identical to the baseline. For MIS, the latent state x^t ∈ [0,1]^|V| represents relaxed vertex indicators; for TSP, the interaction set A is the backbone's candidate edge set, and LoRe routes evaluation to a time-varying subset without altering A itself.

## Method

LoRe operationalizes a Cluster-Bath decomposition inspired by C-DMFT from condensed matter physics: at each diffusion step t, it partitions the interaction set A into a high-conflict Cluster M_t (evaluated exactly) and a low-conflict Bath A\M_t (approximated via an optional lightweight global recall signal g_t). The Cluster is selected by a proxy score S_t combining endpoint uncertainty (u_i = 1−|2x_i^t−1|, maximal at undecided vertices) and temporal instability (|x_i^t − x_prev,i|), refreshed every R steps to amortize routing overhead, and augmented with a small static skeleton of structurally important edges. The budgeted operator replaces the full dense operator with B_t(x) + Σ_{a∈M_t} Δ_{t,a}(x) + R_t(x;g_t), where the recall term is a parameter-free coverage-weighted interpolation with O(N) complexity. An informal error bound (Grönwall-type) shows that as long as omitted Bath interactions remain near-certain, trajectory error does not accumulate appreciably. The key distinction from prior work is that the expensive-evaluation support is time-varying and state-dependent rather than fixed, enabling LoRe to track drifting conflict hotspots without retraining or altering the solver's refinement horizon.

## Results

On Maximum Independent Set (MIS) with DIFUSCO, LoRe achieves an 8.16× end-to-end speedup and 11.9× peak-memory reduction at n=15k (86.7 GB → 7.32 GB) while extending feasible inference to n=50k, more than 3× beyond the baseline's out-of-memory limit, with solution-quality retention of 1.010±0.013. On TSP, LoRe delivers a 14.61× speedup and 43.9× memory reduction at n=1000 (13.6 s → 0.94 s; 4.83 GB → 0.11 GB), scaling to 28.84× speedup and 60.1× memory reduction at n=4000, with tour-length retention of 0.960–1.008 across scales. Cross-framework, LoRe transfers to T2TCO (4.62× speedup on MIS, 11.49× on TSP) and COExpander (6.54× on MIS, 6.60× on MVC) without backbone retraining, maintaining retention ≥ 0.87.

## Baselines & Comparisons

The primary comparison is LoRe (as a drop-in wrapper) versus the same dense backbone without budgeting. On DIFUSCO-MIS, LoRe matches or slightly exceeds baseline solution quality (retention 0.99–1.03 for n≥5k) while delivering 8× speedup and 12× memory reduction, and extends the feasible scale from n=15k to n=50k where the baseline OOMs. On DIFUSCO-TSP, LoRe achieves 14.6× speedup at n=1k with only 4% tour-length degradation (retention 0.960), narrowing to 0.8% at n=4k (retention 1.008). Cross-framework, LoRe with T2TCO achieves 4.62× speedup on MIS (retention 0.989) and 11.49× on TSP (retention 0.994), confirming paradigm-agnostic transfer. With COExpander, LoRe yields 6.54× speedup on MIS (retention 0.872, the weakest result) and 6.60× on MVC (retention 1.001). The one notable quality drop is on scale-free BA topology (retention 0.756), where heavy-tailed degree distributions concentrate conflicts on hub nodes and challenge sparse budget allocation.

## Relation to Prior Work

LoRe carves new ground at the inference-time routing level rather than proposing a new solver architecture: it wraps existing iterative graph solvers (DIFUSCO, T2TCO, COExpander) with a training-free protocol that enforces a hard per-step interaction-evaluation budget via dynamic, state-dependent routing. Conceptually, it repurposes the Cluster-Bath decomposition from C-DMFT in condensed matter physics as an algorithmic blueprint—resolving high-conflict interactions exactly (Cluster) while approximating the rest via a lightweight global signal (Bath)—though the authors explicitly disclaim any formal mathematical equivalence to quantum many-body models. It departs from static spatial sparsification (fixed kNN graphs, candidate-edge truncation) by making the evaluated support time-varying, and is orthogonal to step-reduction techniques (distillation, faster samplers) that reduce the number of refinement steps rather than the per-step footprint.

## Why It Matters / Open Questions

For practitioners deploying neural CO solvers in latency- and memory-constrained settings (real-time dispatch, cluster scheduling), LoRe's training-free nature means it can be dropped onto existing checkpoints without retraining, and the 3× OOM extension plus ~8× speedup on MIS and ~15× speedup on TSP directly address the binding constraint of per-iteration compute envelopes. The cross-framework generality (DIFUSCO, T2TCO, COExpander) and zero-shot topology robustness (ER, WS) strengthen the case for broad adoption, though the notable quality drop on scale-free BA graphs (0.76 retention) and the purely conceptual (not formal) C-DMFT analogy limit the theoretical depth. Open questions include tighter stability/accuracy characterizations of budget-induced truncation, whether the approach extends to solvers with non-dense interaction structures, and how it composes with emerging step-reduction or test-time-scaling methods.

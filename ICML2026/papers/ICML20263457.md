## Problem

Existing quantized LLM training pipelines retain a full-precision (FP32) master-weight buffer to accumulate gradient updates, negating much of the memory savings from low-precision computation. This overhead is especially severe for Sparse Mixture of Experts models where all parameters must reside in memory even though only a subset is active per token. No general method existed to remove master weights without sacrificing convergence or introducing additional memory overhead.

## Input / Output

ECO consumes the current quantized (e.g., FP8) parameter tensor, the gradient computed from those quantized parameters, and the existing optimizer momentum buffer. It produces an updated quantized parameter tensor and a modified momentum buffer into which the per-step quantization residual has been folded via a single element-wise addition. No separate error buffer or high-precision weight copy is stored; the injection coefficient depends only on the learning rate and momentum factor (for SGDM) or the element-wise adaptive step size (for Adam).

## Method

ECO applies the optimizer update directly to quantized weights, then quantizes the resulting temporary iterate and computes the quantization error e_{t+1} = θ̃_{t+1} − θ̂_{t+1} on the fly. This error is injected into the momentum buffer via the rule m ← m + (1/η)(1 − 1/β)·e_{t+1}, creating an error-feedback loop that carries lost updates forward to subsequent steps. The key insight is that consecutive quantization errors are highly correlated (validated empirically via cosine similarity and relative-norm tracking), so the exact error-feedback rule—which would require storing the previous residual—can be approximated using only the current error, eliminating any extra buffer. Theoretical analysis via a virtual-sequence construction proves convergence to a constant-radius neighborhood of the optimum under L-smoothness and unbiased quantization, with a noise floor only 1/(1−β²) worse than the irreducible quantization-grid limit, while naive master-weight removal provably diverges as the learning rate decays.

## Results

Across 30M–800M parameter Transformers trained on C4, ECO with stochastic rounding (SR) nearly recovers the validation loss of FP8-with-master-weights baselines (e.g., 2.5399 vs. 2.5343 at 800M), while naive master-weight removal with RTN diverges at every model size and with SR degrades substantially (2.9471 at 800M). On the 2.1B SMoE model, ECO reduces peak memory from 12 to 9 bytes/parameter (~25% savings) while matching master-weight validation loss. On DeepSeek-MoE-16B INT4 fine-tuning, ECO matches or slightly exceeds master-weight baselines on all six zero-shot benchmarks (e.g., MMLU 38.63 vs. 37.87 for RTN master-weight), while naive removal diverges entirely.

## Baselines & Comparisons

Against the BF16 mixed-precision reference (Micikevicius et al., 2017), ECO+SR at 800M achieves 2.5399 vs. 2.5306, a gap of only 0.009 in validation loss while eliminating the FP32 master-weight buffer. Against the FP8-with-master-weights baselines (Peng et al., 2023; Liu et al., 2024a), ECO+SR is within 0.006 at 800M (2.5399 vs. 2.5343 for RTN master-weight), confirming near-lossless training without high-precision accumulation. Against the naive stochastic-rounding baseline without master weights (Ozkara et al., 2025), ECO+SR provides a dramatic improvement: 2.5399 vs. 2.9471 at 800M (a 0.41 loss reduction), and the naive RTN variant diverges at every model size. On DeepSeek-MoE-16B INT4 fine-tuning, ECO matches or slightly exceeds both master-weight baselines across all six zero-shot benchmarks (e.g., ARC-C 49.15 vs. 48.29 for RTN master-weight; MMLU 38.63 vs. 37.87), while naive master-weight removal diverges under both RTN and SR.

## Relation to Prior Work

ECO repurposes the error-feedback (EF) framework from distributed optimization (Richtárik et al., 2021) to a fundamentally different problem: instead of compensating for compressed gradients across workers, it compensates for quantization error in the master-weight buffer by reusing the optimizer's momentum as the error accumulator. This departs from all prior quantized training systems (FP8-LM, DeepSeek-V3, Kimi-K2) that explicitly retain FP32 master weights, and from narrow-setting attempts at low-precision accumulation (Lin et al. 2022 for small CNNs, ELMO for head layers) that do not scale to LLMs. The key conceptual move is the heuristic that consecutive quantization errors are highly correlated (e_t ≈ e_{t+1}), which eliminates the need for a separate error buffer and makes the method memory-free.

## Why It Matters / Open Questions

Eliminating master weights reduces per-parameter memory from 12 to 9 bytes (25% savings), and compounds to 50% when stacked with 8-bit optimizer state compression — a practically significant reduction for SMoE models where all parameters must reside in memory regardless of activation sparsity. The main limitation is that ECO performs best with stochastic rounding; under round-to-nearest, the systematic bias in quantization error produces a higher noise floor (O(δ²/(1-β)²) vs. O(σ²/(1-β²))), and the gap to master-weight baselines widens at very low precisions (INT2, INT1). Open questions include whether the e_t ≈ e_{t+1} heuristic degrades under aggressive quantization schedules or non-stationary scale parameters, and whether the approach extends to activation quantization or mixed-precision settings where different layers use different formats.

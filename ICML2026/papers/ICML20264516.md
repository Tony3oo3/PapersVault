## Problem

Gradient descent with nonlinear models (e.g., a small convolutional kernel) empirically converges 15× faster than with linear models on the same logistic regression problem, yet the mechanism behind this implicit acceleration remains unexplained. While prior work showed GD with a linear model and large step sizes reduces to the classical perceptron algorithm, the dynamics of GD on even modestly nonlinear models—where the loss is non-smooth and the Hessian grows unboundedly—were not understood.

## Input / Output

The method operates on a dataset of feature vectors b_i ∈ R^d with binary labels y_i ∈ {−1,1}, a constant step size γ, and an initial parameter vector w_0 ∈ R^{d+2} (for kernel size k=2). The model m_cv(b; c, v) = (c*b)^T v is a two-layer network without activation, where c ∈ R^k is a convolution kernel and v ∈ R^d is a weight vector. The output is a separator (a weight vector that perfectly classifies all samples) along with a provable iteration bound; the analysis is conducted in the large-norm regime ‖w_0‖ → ∞, where the step size is bounded by 1/max_i ‖A_i‖ rather than by the Hessian eigenvalue.

## Method

The key reduction shows that GD with logistic loss and the convolutional model m_cv, in the large-norm limit, becomes a Quadratic Perceptron Algorithm: θ_{t+1} = θ_t + (γ/n) Σ_{i∈S_t} A_i θ_t, where the sigmoid in the gradient step collapses to an indicator selecting misclassified samples, and A_i are symmetric (d+2)×(d+2) matrices of rank at most 4 induced by the convolution structure. The paper then performs a full eigendecomposition of these low-rank matrices (Proposition 4.1), revealing that each A_i has at most four nonzero eigenvalues. On a minimalistic two-sample dataset with margin μ, this spectral structure yields a 'ping-pong' dynamic between the two update matrices, and the paper proves convergence in Õ(√d/μ) steps—improving over the Ω(d/μ) lower bound for the classical perceptron on the same dataset. The acceleration is attributed to the √d scaling of the matrix norms ‖A_i‖ = Θ(√d), which forces a smaller step size γ = Θ(1/√d) but simultaneously makes the algorithm more robust to dimensionality.

## Results

On the minimalistic two-sample dataset (5), the Two-Sample Quadratic Perceptron Algorithm (reduction of GD with the nonlinear convolutional model m_cv) finds a separator in Õ(√d/μ) steps, while the classical Perceptron Algorithm (reduction of GD with the linear model m_lin) requires Ω(d/μ) steps — a provable √d-times improvement in iteration complexity. Empirically on CIFAR-10 (classes 0 and 1, n=5000), the nonlinear model m_cv with kernel size k=2 finds a perfect separator after ~20K iterations, more than 15× faster than the linear model m_lin which requires ~330K iterations. Numerical experiments on dataset (5) with d ∈ {10, 100, 400, 600, 800, 1000} confirm the predicted scaling: Perceptron Algorithm steps grow linearly in d while Two-Sample Quadratic Perceptron Algorithm steps grow as √d.

## Baselines & Comparisons

The paper's central comparison is between GD with the linear model m_lin (which reduces to the classical Perceptron Algorithm of Rosenblatt, 1958) and GD with the nonlinear convolutional model m_cv (which reduces to the new Quadratic Perceptron Algorithm). On the minimalistic dataset (5), the nonlinear model provably wins: it requires Õ(√d/μ) iterations versus Ω(d/μ) for the linear model, a √d-factor gap that grows with dimension. Empirically on CIFAR-10, the nonlinear model converges in ~20K iterations versus ~330K for the linear model (~15× speedup), and this effect is observed across multiple datasets (MNIST, Fashion-MNIST, Food-101, EuroSAT) and class pairs. The paper also shows that the maximal allowed step size for the nonlinear model decreases with larger kernel sizes k (as predicted by ‖A_i‖ ≤ √k‖b_i‖), which is confirmed experimentally in Figure 3. Notably, m_cv is a strict reparameterization of m_lin (both are linear in b), so the acceleration is purely an artifact of the optimization dynamics induced by the nonlinearity in the parameterization.

## Relation to Prior Work

This paper extends Tyurin (2025), which showed that GD with logistic loss and a linear model reduces to the classical batch perceptron algorithm in the large-step-size regime, to the nonlinear setting where a small convolutional kernel is added. The key conceptual leap is that the nonlinear GD steps reduce to a 'Quadratic Perceptron Algorithm' whose updates involve quadratic forms θᵀAᵢθ rather than linear ones, enabling analysis via the low-rank spectral structure of the matrices Aᵢ. The work also connects to the broader edge-of-stability and implicit acceleration literature (Cohen et al. 2021; Arora et al. 2018), but departs from smoothness-based analysis by showing that the relevant step-size constraint is governed by ‖Aᵢ‖ rather than the Hessian norm, which can grow quadratically with ‖w‖.

## Why It Matters / Open Questions

The paper provides the first provable √d vs d complexity gap between a nonlinear and linear model under GD with logistic loss, offering a concrete theoretical mechanism for the implicit acceleration phenomenon observed empirically in overparameterized networks. However, the theoretical guarantee is established only on a two-sample minimalistic dataset with kernel size k=2 in the large-norm regime, leaving open whether the √d scaling persists for larger kernels, multi-layer architectures, or with activations. The reduction to perceptron algorithms also opens a path to analyzing GD dynamics without relying on smoothness assumptions that are known to fail for neural network losses, potentially unifying the edge-of-stability and large-step-size literatures.

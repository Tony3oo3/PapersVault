## Problem

Label-free 3D object segmentation in complex indoor scenes remains challenging because existing unsupervised methods rely on either semantic priors (e.g., DINOv2 features) that cannot separate same-category objects, or geometric priors (e.g., object reconstruction models) that fail on multi-category objects with rich semantic context. The fundamental gap is the absence of a mechanism that jointly leverages both semantic and geometric objectness cues to define what constitutes a valid object without any human annotations.

## Input / Output

The method takes a 3D scene point cloud along with its associated multi-view 2D RGB images and depth maps as input. The point cloud is first partitioned into compact superpoints via the Felzenszwalb algorithm, and 2D DINOv2 features are projected into 3D space using depth images to yield per-point semantic features. The output is class-agnostic 3D object segmentation masks, produced at inference time by a separately trained Mask3D network that was supervised on pseudo-labels discovered during the RL training phase.

## Method

FoundObj introduces a superpoint-based object discovery agent that starts from a seed superpoint and iteratively merges neighboring superpoints (within 0.1 m) to grow an object candidate, trained with PPO reinforcement learning. Two complementary reward modules provide supervision without labels: a geometric module that extends the TRELLIS VAE encoder with an Object Center Field head (trained on ABO and 3D-Future) and verifies geometric coherence via DBSCAN clustering of predicted center offsets, and a semantic module that computes an NCut-inspired consistency cost over a spatial-semantic graph built from projected DINOv2 superpoint features. A candidate receives a +10 reward if either module confirms objectness (geometric: ≥30% of points collapse to a single center cluster within r=0.05; semantic: cost falls in the top-20 lowest-cost bank per scene), otherwise −1. Discovered positive-reward masks are collected as pseudo-labels to train a final Mask3D segmentation network, decoupling the expensive RL discovery from efficient inference.

## Results

On the ScanNet validation set (18-class protocol), FoundObj achieves AP 24.2, AP@50 46.2, and AP@25 74.7, outperforming the strongest unsupervised baseline Part2Object (AP 19.6) by 4.6 AP points. On S3DIS (Area-5, zero-shot), FoundObj reaches AP 12.8, approaching the supervised Mask3D upper bound of 13.0. On the long-tail ScanNet200 benchmark, FoundObj attains AP 18.1, surpassing Part2Object (AP 15.2) by 2.9 points and UnScene3D (AP 12.8) by 5.3 points.

## Baselines & Comparisons

FoundObj outperforms all unsupervised baselines across every benchmark. On ScanNet, it beats Part2Object (AP 19.6) by 4.6 points and UnScene3D (AP 18.5) by 5.7 points, with the largest gap over EFEM (AP 8.0) at 16.2 points. The RL-based agent is shown to be essential: under TRELLIS-only and DINO+TRELLIS settings (Table 6), FoundObj (AP 15.3 and 24.2) consistently surpasses UnScene3D and Part2Object variants (AP 10.1–17.7), confirming that the agent mechanism—not merely the foundation model features—drives the improvement. On S3DIS (zero-shot), FoundObj (AP 12.8) nearly matches the supervised Mask3D upper bound (AP 13.0) while all unsupervised baselines lag by 2.4–9.1 points. On ScanNet200 (long-tail), FoundObj (AP 18.1) leads Part2Object (AP 15.2) and UnScene3D (AP 12.8), demonstrating stronger handling of rare categories. In the open-vocabulary extension (Table 8), FoundObj (AP 6.7) trails supervised methods like OpenIns3D (AP 23.7), but this is expected since those methods rely on fully supervised mask training.

## Relation to Prior Work

FoundObj extends the RL-based object discovery paradigm introduced by GrabS (ICLR 2025), replacing its single-class dynamic cylinder agent with a flexible superpoint-based agent that can discover multi-class objects of arbitrary shape. It repurposes the 2D-to-3D feature projection pipeline from UnScene3D (CVPR 2024) for DINOv2 semantic features, and extends the TRELLIS (CVPR 2025) VAE encoder with a novel object-center-field head to extract geometric priors. The key conceptual departure is framing both semantic and geometric foundation-model outputs as complementary reinforcement learning rewards rather than as direct segmentation signals, enabling the agent to learn object boundaries without any scene-level supervision.

## Why It Matters / Open Questions

The paper demonstrates that label-free 3D object segmentation can approach supervised performance in zero-shot cross-dataset settings (12.8 AP on S3DIS vs. 13.0 for Mask3D trained with annotations), suggesting a viable path toward scalable 3D scene understanding without expensive annotation. However, the pseudo-mask error propagation analysis (Table 7) reveals a significant gap: raw discovered masks achieve only 13.8 AP, and cleaning them with ground-truth IoU filtering nearly doubles the final score to 37.0 AP, indicating the RL agent's discovered boundaries remain noisy. Open questions include whether the approach generalizes to outdoor or large-scale scenes, whether the RL agent can be replaced by simpler optimization, and how to close the remaining gap to fully supervised methods (24.2 vs. 61.2 AP on ScanNet).

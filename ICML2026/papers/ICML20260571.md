## Problem

While graph prompt tuning has become the prevailing adaptation method for GNN-based Graph Foundation Models, how to rigorously measure its adaptation capacity remains an open problem. Without a principled quantitative framework, it is impossible to characterize the capability limits of input-space prompt methods or to theoretically guide the design of more powerful alternatives.
![Teaser figure](../imgs/ICML20260571/cropped_page1_idx0.webp)

## Input / Output

The method consumes a graph (node feature matrix X ∈ R^{N×d₀} and adjacency matrix A) processed by a frozen pre-trained GNN backbone (GCN, GraphSAGE, GAT, GIN, or Graph Transformer). The only trainable parameters are m learnable message prototype vectors per layer and a lightweight linear projection matrix for fusion; all pre-trained weights remain frozen. Output is node or graph-level representations used for few-shot (1/3/5-shot) classification, evaluated on 15 datasets spanning homophilic, heterophilic, and large-scale graphs as well as molecular and social graph classification.

## Method

The paper introduces Prismatic Space Theory (PS-Theory), which models each GFM layer as a piecewise linear map (a 'prism') that refracts the input data manifold, and uses geometric measure theory—specifically singular values of layer Jacobians—to quantify the measure contraction and establish a rigorous upper bound on graph prompt tuning's adaptation capacity (bounded by the product of layer-wise Jacobian singular values applied to the perturbed input manifold). Building on this, Message Tuning for GFMs (MTG) injects m learnable message prototypes at every layer, dynamically fused with native messages via a linear projection followed by row-wise Softmax, while keeping all pre-trained weights frozen. This per-layer intervention expands the reachable representation space at each stage, counteracting the cumulative prismatic compression. The paper proves via PS-Theory that MTG's adaptation capacity (in intrinsic dimension, Hausdorff measure, and diameter of the output prismatic space) can strictly exceed the theoretical upper bound of graph prompt tuning, and validates this empirically on the ProG benchmark across 15 datasets with multiple backbones and pre-training strategies.

## Results

MTG achieves the best 1/3/5-shot accuracy across all 15 benchmark datasets (7 node + 8 graph classification) on the ProG benchmark. Representative 1-shot results include 58.54% on Cora (vs. 55.77% for GPF-plus), 75.97% on ogbn-arxiv (vs. 75.72% for Gprompt), and 66.98% on PROTEINS (vs. 66.49% for All-in-one). MTG also substantially outperforms fine-tuning (e.g., 58.54% vs. 52.61% on Cora 1-shot) and supervised baselines, while using only a small set of learnable message prototypes per layer. MTG completely eliminates negative transfer in 1-shot node classification, achieving a lower NTR than all graph prompt baselines.

## Baselines & Comparisons

MTG outperforms all four graph prompt baselines on every one of the 15 datasets. Against GPF-plus (Fang et al., NeurIPS 2023), the closest node-classification competitor, MTG gains 2.77 points on Cora 1-shot (58.54 vs. 55.77) and 3.99 points on ogbn-arxiv 1-shot (75.97 vs. 71.98). Against All-in-one (Sun et al., KDD 2023), the strongest graph-classification baseline, MTG leads by 0.49 points on PROTEINS 1-shot (66.98 vs. 66.49) and 2.12 points on ENZYMES 1-shot (26.08 vs. 23.96). Gprompt (Liu et al., WWW 2023) is competitive on ogbn-arxiv (75.72 vs. 75.97) but trails MTG by 1.85 points on Cora and 1.03 points on Wisconsin. GPPT (Sun et al., KDD 2022) is consistently the weakest prompt baseline, lagging MTG by 15+ points on most datasets. MTG also surpasses full fine-tuning by 5.93 points on Cora 1-shot and 59.76 points on ogbn-arxiv 1-shot, demonstrating superior parameter efficiency and robustness against negative transfer.

## Relation to Prior Work

This paper extends the data-operation analysis of Wang et al. (2025a) on graph prompt tuning by introducing Prismatic Space Theory (PS-Theory), a geometric measure theoretic framework that quantifies the adaptation capacity of input-level adaptation methods and establishes a provable upper bound. It departs from the prevailing graph prompt tuning paradigm (GPF, GPPT, Gprompt, All-in-one) that operates solely at the input data level, instead proposing Message Tuning (MTG) that injects learnable message prototypes into each layer of the frozen GNN backbone. The method draws conceptual inspiration from prefix-tuning in NLP (Li & Liang, 2021) but is specifically adapted for graph-structured data through a dynamic message fusion operator rather than static prefix insertion, making it compatible with both MPNN and Graph Transformer backbones.

## Why It Matters / Open Questions

PS-Theory provides the first rigorous geometric framework for understanding why input-level adaptation (graph prompt tuning) is fundamentally constrained by the frozen backbone's piecewise linear, contracting structure, offering a principled basis for designing more powerful adaptation methods. The practical impact is that MTG, a lightweight per-layer message injection, provably exceeds the theoretical upper bound of graph prompt tuning and empirically outperforms all graph prompt baselines across 15 datasets while eliminating negative transfer in 1-shot node classification. Key limitations include the requirement for white-box layer-wise access, reliance on piecewise linear activation assumptions (approximate for GELU/tanh/Softmax), and the acknowledged gap between geometric capacity and actual generalization performance under few-shot supervision.

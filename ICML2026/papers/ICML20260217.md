## Problem

A substantial gap existed between the best streaming algorithm (0.277-approximation, Alaluf et al. 2020) and the best fully dynamic algorithm (0.171-approximation, Banihashem et al. 2025) for non-monotone submodular maximization under a cardinality constraint. The open question posed at STOC 2022 asked whether dynamic results could be extended to the non-monotone setting, and prior dynamic algorithms suffered from both weaker approximation guarantees and higher query complexities. This paper closes the approximation gap by matching the streaming guarantee in the fully dynamic model.

## Input / Output

The algorithm operates under an oblivious adversarial model where elements are inserted and deleted from a ground set V over time, with a non-monotone submodular function f accessed only through oracle queries (set evaluations and marginal gain computations). At every time step t, the algorithm must maintain a subset S_t ⊆ V_t of size at most k satisfying f(S_t) ≥ α·OPT_t, where V_t is the current active set. The update time is measured in oracle queries per insertion or deletion, and the algorithm supports two configurations: a 0.262−ε approximation with O(ε⁻³k log(k) log(ε⁻¹k) + ε⁻²k² log(k)) expected queries, or a 0.277−ε approximation with poly(ε⁻¹, k) expected queries.

## Method

The algorithm runs a family of parallel instances, each parameterized by a geometrically spaced τ = (1+ε)^i that estimates OPT_t, and routes each element update only to instances where the element is relevant (f(e) in a specific range relative to τ and k). Within each instance, a randomized leveled data structure maintains p solution sets across T ≤ pk levels; at each level ℓ, exactly one element e_ℓ is added to one of the p solutions (chosen by lowest index among suitable solutions), and R_ℓ tracks elements suitable for at least one solution at that level. The key invariant is that e_ℓ is uniformly random in R_ℓ conditioned on all previous levels, maintained via random partial reconstructions: on insertion, the new element replaces the level's chosen element with probability 1/|R_ℓ|, and on deletion, reconstruction is triggered only if the deleted element was the chosen one. After all levels are built, the offline algorithm (Buchbinder & Feldman 2019 for 0.385-approximation, or Buchbinder et al. 2014 for 0.356-approximation) is run on the union of the p top-level solutions, and the best among the p solutions and the offline output is returned, yielding the (α/(1+α) − ε)·OPT_t guarantee.

## Results

The paper presents two dynamic algorithms for non-monotone submodular maximization under a cardinality constraint k. The first achieves a 0.262-approximation with worst-case expected update time O(ε^{-3} k log(k) log(ε^{-1}k) + ε^{-2} k^2 log(k)), using the SODA'14 offline algorithm (α=0.356). The second achieves a 0.277-approximation (matching the best streaming algorithm of Alaluf et al., 2022) with worst-case expected update time bounded by poly(ε^{-1}, k), using the Buchbinder & Feldman (2019) offline algorithm (α=0.385). This improves upon the prior best dynamic guarantee of 0.171 with Õ(ε^{-3} k^4) oracle queries per update.

## Baselines & Comparisons

The paper's primary comparison is against prior fully dynamic algorithms for non-monotone submodular maximization. The 0.262-approximation result improves the previous best dynamic guarantee of 0.171 (Banihashem et al., NeurIPS'25) by a factor of roughly 1.5×, while simultaneously reducing the query complexity from Õ(ε^{-3} k^4) to O(ε^{-3} k log(k) log(ε^{-1}k) + ε^{-2} k^2 log(k)), a significant polynomial improvement in k. The 0.277-approximation result closes the gap entirely with the best-known streaming algorithm of Alaluf et al. (2022), which previously had no fully dynamic counterpart. The key technical contribution is simulating the streaming algorithm's behavior within a fully dynamic environment using a randomized leveled data structure with a uniform invariant, building on the dynamic matroid framework of Banihashem et al. (SODA'24). The trade-off is that the 0.277 guarantee requires poly(ε^{-1}, k) update time (via the slower Buchbinder–Feldman offline algorithm), whereas the 0.262 guarantee offers a more explicit and tighter query bound.

## Relation to Prior Work

This paper builds on two key prior works: the streaming algorithm of Alaluf et al. (2022), which achieves a 0.277-approximation for non-monotone submodular maximization under a cardinality constraint, and the dynamic framework of Banihashem et al. (2024) for monotone submodular maximization under matroid constraints. The central technical contribution is a leveled data structure with a uniform invariant that simulates the streaming algorithm within a fully dynamic environment handling both insertions and deletions, using the offline algorithm of Buchbinder & Feldman (2019) as a subroutine. This improves upon the prior best dynamic guarantees of (0.125−ε) (NeurIPS'20) and 0.171 (NeurIPS'25), closing the gap to the streaming state-of-the-art.

## Why It Matters / Open Questions

The result is significant because it demonstrates that the fully dynamic setting (which handles adversarial deletions) can match the best streaming approximation guarantee of 0.277, resolving a natural open question about whether the dynamic setting is inherently more limited. The 0.262-approximation variant with quasi-polynomial update time offers a practical tradeoff for settings where polynomial update time is too costly. Open questions remain: the offline best is 0.385 and hardness is 0.491, so a substantial gap persists between dynamic and offline guarantees, and it is unclear whether the leveled-structure approach can be extended to matroid or p-matchoid constraints in the non-monotone dynamic setting.

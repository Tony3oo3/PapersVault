## Problem

Multi-turn tool-use agents face continuously shifting decision contexts where reusing past experience is critical, yet existing approaches are limited: trajectory-level retrieval is too context-specific to transfer, while tool-graph methods ignore how dialogue history and prior tool calls shape the next action. This paper tackles how to adaptively reuse partially overlapping successful experiences at the state level for both inference-time guidance and RL exploration over long horizons.
![Teaser figure](../imgs/ICML20262458/cropped_page3_idx0.webp)

## Input / Output

The agent consumes the multi-turn dialogue history and tool outputs, and at each step autonomously decides whether to invoke a summarization tool that compresses the current state into a compact text summary. This summary is embedded via all-MiniLM-L6-v2 and compared by cosine similarity against state annotations stored on graph edges. The output is a top-k (default k=2) tool suggestion injected as a system prompt ('Suggested next tools: Tool1, Tool2'), which the agent uses to select its next tool invocation rather than being forced into a single deterministic choice.

## Method

H-EPM constructs a state-annotated tool-transition graph where nodes are tools and edges carry two complementary signals: a procedural weight combining transition success count and efficiency (inverse rollout length), and episodic state summaries captured when the agent invokes a summarization tool between two tool calls. At inference, the agent adaptively switches memory modes—comparing the current state summary against edge-attached summaries (episodic recall) when summarization is triggered, or falling back to normalized edge weights (procedural execution) otherwise—yielding top-2 candidate tools. For RL training, H-EPM is integrated into GRPO rollouts as a memory-guided exploration mechanism: suggested tools are randomly skipped with probability p_skip to preserve exploration, while the graph is updated online with newly successful trajectories. A masking strategy is used during policy-gradient computation to avoid rollout-update mismatch from the injected guidance tokens.

## Results

On inference, H-EPM achieves up to +53.7% relative improvement over the base model on τ²-Bench (Qwen3-8B: 0.309 vs. 0.201), +22.2% on τ-Bench (GPT-4.1-mini: 0.661 vs. 0.541), and +18.2% on ToolSandbox (Qwen3-4B-Ins: 0.565 vs. 0.478), consistently outperforming all baselines across five base models. In RL training with Qwen3-4B-Instruct, H-EPM boosts GRPO by up to +41.1% on τ²-Bench (0.223 vs. 0.178) and +28.3% on τ-Bench (0.558 vs. 0.510), while also surpassing AgentEvolver on all three benchmarks. Gains are most pronounced for smaller/weaker models, suggesting H-EPM compensates for limited reasoning capacity through adaptive memory retrieval.

## Baselines & Comparisons

H-EPM outperforms all five baselines across every benchmark and model configuration in Table 1. Against ReasoningBank (trajectory-level episodic retrieval), H-EPM wins by 5–31 percentage points, with the largest gap on τ²-Bench where trajectory-level retrieval introduces noisy early-turn context. Against ToolNet (procedural tool-graph only), H-EPM gains 2–26 points, confirming that state-annotated episodic edges add substantial value beyond pure transition weights. The simple Retrieval Top-3 baseline is the weakest competitor and is sometimes worse than the base model (e.g., −16.9% on ToolSandbox with GPT-4.1), underscoring that indiscriminate trajectory retrieval is harmful in multi-turn settings. In RL (Table 3), H-EPM surpasses both standard GRPO and AgentEvolver on all three benchmarks; AgentEvolver's trajectory-level experience reuse degrades as trajectories grow longer, while H-EPM's state-level fragments remain transferable. GNN4Plan, tested as an alternative graph-traversal strategy in ablations, underperforms full H-EPM by 3–10 points, validating the adaptive episodic/procedural switching mechanism.

## Relation to Prior Work

H-EPM extends the tool-transition graph paradigm introduced by ToolNet (Liu et al., 2024a) by augmenting each edge with compact episodic state summaries and an efficiency-aware weighting scheme, moving beyond purely procedural (tool-to-tool) dependencies. It also departs from trajectory-level episodic memory methods like ReasoningBank (Ouyang et al., 2025), which retrieve whole past trajectories, by operating at the state level to enable reuse across partially overlapping multi-turn contexts. The RL integration builds on GRPO (Shao et al., 2024) and AgentEvolver (Zhai et al., 2025) but introduces a memory-guided exploration mechanism with an adjustable skip rate, addressing the long-horizon exploration problem that prior agent-RL methods handle with sparse or no structural guidance.

## Why It Matters / Open Questions

The paper tackles a practical bottleneck in multi-turn agent deployment: the need for domain-specific experience collection at inference time. By internalizing effective tool-use patterns into the policy through memory-guided RL, H-EPM reduces this dependency, which is valuable for scaling agents to new domains. A key limitation acknowledged by the authors is that stronger reasoning models (e.g., GPT-5.1) show diminished adherence to external guidance, suggesting an open question about how to align memory-based suggestions with the internal reasoning of highly capable LLMs. The approach is also most effective for smaller or less capable models, which raises the question of whether the gains persist as base-model reasoning improves.

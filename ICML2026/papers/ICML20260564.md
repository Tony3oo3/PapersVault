## Problem

Prior theoretical analyses of transformers assume deterministic decoding, where the model output is fixed for a given prompt, thereby overlooking the stochastic sampling inherent in practical LLM inference. This gap prevents rigorous understanding of test-time computing techniques—majority voting, best-of-N sampling, tree of thoughts—that fundamentally rely on probabilistic sampling to explore diverse reasoning paths and improve performance.
![Teaser figure](../imgs/ICML20260564/cropped_page0_idx1.webp)

## Input / Output

The framework takes in-context examples structured as a prompt embedding matrix H_0 ∈ R^{(2d+2)×(n+1)}, a well-trained one-layer linear attention transformer, and sampling parameters (noise level σ, number of reasoning paths N, reasoning length T). For continuous coefficients it produces excess risk bounds under polynomially decaying eigenvalue spectra; for binary sparse coefficients it produces exact recovery probabilities; and via the Low-Cost-to-High Prediction Algorithm it extrapolates real-world LLM accuracy (on GSM8K and MATH) from low-compute observations at small T or N.

## Method

The core contribution is a stochastic auto-regressive decoding framework (Algorithm 1) that simulates practical LLM inference by injecting noise into the transformer's hidden state before sampling the next token embedding. For continuous coefficients, noise enters via a noise transformation function (NFT)—either constant (additive Gaussian) or linear (multiplicative, scaling with the current prediction)—while for binary sparse coefficients, sampling is performed over a discrete {0,1}^d space using a ClipNorm distribution that mimics softmax over a vocabulary. The well-trained one-layer linear attention transformer (Proposition 4.3) implements multi-step gradient descent, and the framework analyzes how ensemble averaging, majority voting, and best-of-N aggregation over N stochastic reasoning paths of length T improve performance. Key theoretical results show that linear NFT mitigates overfitting to label noise (unlike constant NFT or deterministic GD), and majority voting escapes cyclic state transitions that trap greedy decoding in discrete spaces. The Low-Cost-to-High Prediction Algorithm (Algorithm 4) leverages the derived exponential convergence forms O(e^{-Δ_T²N/2}) and O(e^{-μT}) to predict high-compute LLM accuracy from only two low-compute data points.

## Results

For continuous in-context linear regression with polynomially decaying spectrum (λ_i = i^{-(r+1)}), the key finding is that ensemble with linear NFT eliminates the overfitting term: deterministic GD risk scales as t̃^{1/(r+1)}·(ηd)^{-r/(r+1)}, while ensemble with linear NFT achieves (ηd)^{-r/(r+1)} (independent of reasoning length t̃), provided N ≥ η^{r/(r+1)}·d^{(2r+1)/(r+1)}. For the binary sparse case with n=k=1, σ_ε=0, greedy decoding is bounded above by 1/2^{d-1} + 2/d (≈0.2 for d=10), while majority vote achieves ≥ 1 − 1/2^{d-1} (≈0.999 for d=10). The majority vote recovery probability converges to 1 at rate 1 − |W|·exp(−NΔ_t²/2), validated numerically on GSM8K and MATH via the Low-Cost-to-High Prediction algorithm.

## Baselines & Comparisons

The paper compares three methods for continuous coefficients: deterministic multi-step GD, ensemble with constant NFT, and ensemble with linear NFT. Constant NFT ensemble provides no improvement over deterministic GD (both suffer the same t̃^{1/(r+1)} overfitting penalty), while linear NFT ensemble eliminates this penalty entirely, achieving a risk bound independent of reasoning length under the regime n ∝ ηd, σ² ∝ d^{-1}. For binary sparse coefficients, greedy decoding is compared against majority voting. In the data-limited regime (n=k=1, σ_ε=0), greedy decoding is provably trapped in 2-state cycles with accuracy bounded by 1/2^{d−1} + 2/d (≈0.2 for d=10), while majority voting achieves ≥ 1 − 1/2^{d−1} (≈0.999), a gap of roughly 0.8 in absolute accuracy. In the data-sufficient regime (n ≥ (6k+3σ_ε)^4), both methods achieve perfect recovery, but majority vote additionally provides an exponential-in-N convergence guarantee that greedy decoding lacks. Numerical experiments on GSM8K and MATH confirm that the Low-Cost-to-High Prediction model (fitting Acc(T,N) ≈ α − βe^{−Δ_T²N/2}) accurately extrapolates high-compute LLM performance from low-compute observations.

## Relation to Prior Work

This paper extends the deterministic CoT gradient descent framework of Huang et al. (2025) by explicitly incorporating stochastic sampling into the transformer decoding process, bridging a gap that prior theoretical analyses (von Oswald et al., 2023; Bai et al., 2024) left unaddressed. It builds on the canonical in-context linear regression task from Garg et al. (2023) and the excess risk methodology from Zou et al. (2022), but departs from the standard assumption that a transformer's output is fixed given a prompt. The key conceptual departure is modeling the decoding step as a noise-injection-and-sampling procedure rather than a direct readout, enabling formal analysis of ensemble, majority voting, and best-of-N techniques within a rigorous theoretical setting.

## Why It Matters / Open Questions

This is the first theoretical framework that formally accounts for the stochastic nature of LLM decoding when analyzing test-time computation, providing the missing link between deterministic transformer theory and practical inference techniques like self-consistency and best-of-N sampling. The practical Low-Cost-to-High Prediction algorithm, which extrapolates high-compute LLM performance from low-compute observations, could reduce the cost of inference scaling experiments. However, the analysis is confined to one-layer linear attention transformers and two specific noise transformation functions, and the best-of-N analysis remains open; extending the framework to multi-layer softmax attention transformers and more complex sampling strategies is a clear next step.

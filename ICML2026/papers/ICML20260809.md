## Problem

Training deep learning models on single-cell datasets with hundreds of millions of cells requires on-disk data loading, but true random sampling is prohibitively slow (~20 samples/sec on Tahoe-100M, requiring 58+ days per epoch) while sequential streaming introduces plate-scale biases that cause catastrophic forgetting. Existing solutions either require expensive format conversion, lack multiprocessing support, or use shuffle buffers too small to span the millions-of-cells-per-plate heterogeneity in atlas-scale datasets.

## Input / Output

scDataset consumes AnnData (.h5ad) files directly from disk without format conversion, parameterized by a block size b (contiguous cells per I/O unit) and a fetch factor f (number of minibatches prefetched per disk operation). It yields PyTorch-compatible minibatches of size m (default 64) through an IterableDataset interface, with the quasi-random ordering guaranteeing that each minibatch draws from up to (m×f)/b distinct spatial blocks. The modular callback architecture (fetch_callback, fetch_transform, batch_callback, batch_transform) allows the same sampling logic to operate on HuggingFace Datasets, BioNeMo-SCDL, TileDB-SOMA, or arbitrary indexable backends.

## Method

The core mechanism combines two complementary strategies: block sampling partitions the dataset into contiguous blocks of size b and samples ⌈m/b⌉ blocks uniformly per minibatch, reducing random disk accesses from m to m/b; batched fetching then retrieves m×f cells in a single sorted I/O operation, reshuffles them in memory, and partitions the buffer into f diverse minibatches, so each minibatch draws from up to (m×f)/b distinct blocks rather than just m/b. This quasi-random sampling is formalized via a sandwich bound on expected minibatch entropy (Proposition 3.1), showing that the deviation from true random sampling is bounded by (K−1)b/(2m·ln2) and vanishes as f grows. The practical recommendation b ≤ f/2 ensures near-random diversity even under worst-case plate-constant organization, as validated empirically on Tahoe-100M where b=16, f=256 recovers entropy of 3.61 vs. 3.62 for true random sampling while achieving 204× throughput speedup.

## Results

On Tahoe-100M (100M cells, 314GB AnnData), scDataset achieves a 204× throughput speedup over AnnLoader (from ~20 to ~4,080 samples/sec) at b=1024, f=1024, while recovering minibatch plate entropy of 3.61 bits (vs. 3.62 for true random sampling) at b=16, f=256. On four classification tasks (cell line, drug, MoA-broad, MoA-fine) with both a linear classifier and a 2-layer MLP, BlockShuffling (b=16, f=256) matches Random Sampling macro F1 on all tasks, while streaming and streaming-with-16K-buffer collapse to near-chance on drug and MoA classification. Multiprocessing with 4 workers at b=16, f=256 reaches 4,614 samples/sec, a 2.5× speedup over the single-core equivalent-memory configuration (1,854 samples/sec).

## Baselines & Comparisons

Against AnnLoader (the standard PyTorch loader for AnnData files), scDataset achieves a 204× throughput improvement at the largest tested parameters (b=1024, f=1024), going from ~20 to ~4,080 samples/sec; even at moderate settings (b=16, f=256) it reaches ~1,854 samples/sec (~93×). Against HuggingFace Datasets (Parquet format, 1.9TB), scDataset's block sampling alone yields a 47× speedup, though the fetch factor provides no additional benefit due to the backend's per-index access pattern. Against BioNeMo-SCDL (memory-mapped NumPy, 1.1TB), the speedup is 25× from block sampling. On downstream classification quality, scDataset's BlockShuffling strategy (b=16, f=256) is indistinguishable from true Random Sampling across all four tasks and both architectures, while the streaming-with-shuffle-buffer baseline (16,384 cells) fails to recover drug and MoA classification performance, confirming that buffer sizes small relative to plate-scale heterogeneity (~7M cells/plate) are insufficient to mitigate sequential-access bias.

## Relation to Prior Work

This paper carves new ground at the intersection of statistical cluster sampling theory and deep learning data pipelines, rather than extending a single prior method. It departs from format-conversion approaches (AnnBatch, BioNeMo-SCDL, HuggingFace Datasets) by operating directly on native AnnData files, and from shuffle-buffer approaches (WebDataset, Ray Data) by providing explicit theoretical control over the throughput-diversity trade-off via block size and fetch factor. The theoretical analysis draws on Paninski's bias expansion for plug-in entropy estimators and Cochran's cluster sampling framework, repurposing these classical statistics tools to formalize minibatch diversity guarantees in a deep learning context.

## Why It Matters / Open Questions

By eliminating the need for format conversion and enabling 204× speedup over the standard AnnLoader on 100M-cell datasets, scDataset lowers the barrier to atlas-scale deep learning in single-cell biology to commodity hardware. The finding that moderate shuffle buffers (16K cells) are essentially useless against plate-scale heterogeneity (~7M cells per plate) challenges the implicit assumption in WebDataset/Ray Data that a fixed buffer suffices, and the theoretical bounds give practitioners principled guidance for parameter selection. Open questions include automated (b,f) profiling across diverse dataset organizations, multi-epoch training dynamics where ordering effects compound, and integration with emerging Zarr v3 backends that may further improve sequential access throughput.

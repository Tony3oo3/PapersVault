## Problem

Prevalent memory preprocessing paradigms for LLM agents (static embeddings, knowledge graphs, hierarchical archives) compress sequential dependencies into rigid representations, causing destructive de-contextualization that severs the contextual integrity essential for deep, long-horizon System 2 reasoning. This leads to significant performance degradation on complex multi-hop and temporal reasoning tasks, where causal chains and state transitions must be reconstructed from their original sequential contexts.
![Teaser figure](../imgs/ICML20264717/cropped_page0_idx0.webp)

## Input / Output

The system consumes an unbounded episodic memory stream (e.g., multi-session dialogue) and a user query. The stream is segmented via sliding window with overlap into raw, uncompressed token sequences, each encapsulated by a dedicated SLM assistant agent. Output consists of a final grounded response synthesized by the master agent, built from local evidence tuples—each pairing a deduced semantic fact with an absolute timestamp (temporal anchoring)—produced by activated assistant agents during episodic context reconstruction.

## Method

E-mem replaces memory preprocessing with episodic context reconstruction via a heterogeneous hierarchical master-assistant architecture: a central master agent (large LLM) orchestrates global planning, while multiple lightweight SLM assistant agents each preserve and reason over a raw episodic context segment. A multi-pathway routing mechanism (global narrative alignment on summaries, dense vector similarity on raw chunks, and BM25 symbolic entity matching) performs coarse-grained activation of relevant memory units without runtime LLM inference. Activated assistants then execute fine-grained local reasoning within their preserved contexts, generating temporally anchored evidence tuples rather than returning raw text. The master agent aggregates these evidence tuples, resolving temporal conflicts via chronological logic, and supports both direct inference and iterative refine-and-query modes for multi-step deduction. This design decouples expensive global reasoning from cheap local context processing, reducing normalized token cost by over 70% while improving F1 by 7.75% over the strongest baseline.

## Results

On the LoCoMo benchmark with GPT-4o-mini, E-mem achieves 54.17 overall F1, surpassing the strongest baseline GAM (45.31) by 8.86 points, with particularly large gains in Multi-Hop reasoning (42.64 vs. 34.84, +7.80) and Temporal understanding (59.82 vs. 53.91, +5.91). With Qwen2.5-14B, E-mem reaches 57.04 overall F1, outperforming GAM by 6.63 points. On HotpotQA (1600 documents), E-mem achieves 55.76 F1 with GPT-4o-mini and 54.87 with Qwen2.5-14B, exceeding GAM by 2.05 and 10.55 points respectively. Crucially, E-mem reduces normalized token cost to 3,621 units versus GAM's 12,540—a 71% reduction—while delivering superior accuracy.

## Baselines & Comparisons

E-mem outperforms all seven memory-based baselines across both LoCoMo and HotpotQA. Against GAM (the strongest baseline), E-mem gains +8.86 F1 on LoCoMo (GPT-4o-mini) and +6.63 on Qwen2.5-14B, with the largest margins in Multi-Hop (+7.80) and Temporal (+5.91) sub-tasks. Compared to Mem0 (45.10 F1), E-mem leads by 9.07 points; versus A-mem (39.65), the gap is 14.52 points. On HotpotQA-1600, E-mem (55.76 F1) surpasses GAM (53.71) by 2.05 and RAG (54.01) by 1.75, while A-mem (31.37) and Mem0 (27.41) degrade severely under ultra-long contexts. Graph-based baselines HippoRAG (46.91) and AriGraph (45.76) on LoCoMo are also clearly outperformed by E-mem's 54.17. Notably, E-mem achieves these gains while reducing normalized token cost by 71% relative to GAM (3,621 vs. 12,540 units), thanks to offloading local reasoning to lightweight Qwen3-4B assistant agents.

## Relation to Prior Work

E-mem departs from the dominant memory-preprocessing paradigm (RAG, MemGPT, A-Mem, Mem0, GAM) that compresses sequential contexts into fixed structures like embeddings or knowledge graphs, which the authors term 'destructive de-contextualization.' Conceptually, it draws on Tulving's biological episodic memory (re-experiencing intact contexts rather than retrieving fragments) and repurposes multi-agent coordination—previously used for task decomposition—into a memory-management architecture where SLM-based assistant agents hold raw episodic segments and perform local reasoning. The multi-pathway routing (dense vector, sparse BM25, summary alignment) is a standard retrieval toolkit reorganized into a union-based activation mechanism, and the sliding-window segmentation with overlap is a straightforward extension of context-windowing, but the key architectural novelty is the heterogeneous master-assistant split that decouples global planning from local context reconstruction.

## Why It Matters / Open Questions

The paper demonstrates that preserving raw episodic context and delegating local reasoning to lightweight SLMs can outperform lossy preprocessing by ~8% F1 while cutting normalized token cost by over 70%, offering a practical path toward scalable long-horizon agent memory. The acknowledged latency trade-off (11.25s vs. ~2.5s for RAG) and the authors' own framing of E-mem as complementary rather than replacement limit its universal applicability. Open questions include whether the adaptive dual-mode (fast RAG + deep E-mem) hybrid the authors sketch can be made to switch reliably in real time, how the architecture scales beyond the ~32K-token budget tested, and whether the multi-agent overhead remains justified as single-model context windows continue to grow (the GPT-5.1 comparison in Appendix D narrows the gap to ~2 F1 points).

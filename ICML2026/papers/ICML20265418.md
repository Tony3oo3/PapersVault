## Problem

Language models are constrained by bounded context windows, fundamentally limiting long-horizon reasoning. While various context management strategies exist (summarization, memory augmentation, multi-agent decomposition), no formal framework existed to compare their computational power or identify which mechanisms are optimal. The paper asks: what core scaffolding around a base generator enables models to overcome context constraints, and is that mechanism provably optimal?
![Teaser figure](../imgs/ICML20265418/cropped_page1_idx2.webp)

## Input / Output

The model takes a text prompt (e.g., a SAT formula encoded as a natural-language puzzle) and produces a text answer (accept/reject or a satisfying assignment). Unusually, the model's generation is structured by four reserved delimiter tokens (<call>, </call>, <return>, </return>) that partition the output into a stack of isolated contexts; only the top (active) context is visible to the generator at any step, while suspended parent contexts are offloaded to external storage. The root problem statement is prepended to every recursive context so all subtasks retain access to the global objective.

## Method

The recursive model consists of a single base LLM (a constant-size causal Transformer with average-hard attention) equipped with two minimal tools: call, which spawns an isolated child context for a subtask, and return, which discards all intermediate reasoning and passes only the final answer back to the parent. The key theoretical result is that with local space S(n), recursive models solve any problem in TIME(2^{O(S(n))}), an exponential improvement over standard autoregressive models that would require context length exp(O(S(n))) for the same problems. The paper further proves that constant-depth recursion (depth 1) matches the optimal power of all single-context strategies (SPACE(S(n))), while unbounded depth breaks through this ceiling, and that the minimal recursive model is optimally powerful among all recursive agentic systems with arbitrary scaffolds. Experimentally, Qwen2.5-3B-Instruct is fine-tuned via supervised learning on DPLL-generated recursive reasoning traces for SAT, achieving 98%/95%/64% accuracy on easy/medium/hard instances while keeping active context length bounded, substantially outperforming GPT-4o, LLaMA3.3-70B, and Qwen3-235B.

## Results

On SATBench, the 3B recursive model (fine-tuned from Qwen2.5-3B-Instruct) achieves 98% accuracy on easy instances, 95% on medium, and 64% on hard, substantially outperforming all larger frontier baselines. Notably, the model is trained only on easy and medium instances yet generalizes to hard instances (64%), surpassing GPT-4o (48.8%), LLaMA3.3-70B (52.9%), and Qwen3-235B (51.4%) on the hardest tier. The model also demonstrates context efficiency: while total trajectory length grows rapidly with problem size, the active context length remains bounded, confirming the theoretical prediction that recursion decouples total computation from per-step attention cost.

## Baselines & Comparisons

The paper compares its 3B recursive model against four frontier LLMs evaluated on SATBench (Wei et al., 2025): GPT-4o, LLaMA3.3-70B, Qwen3-235B, and DeepSeek-Distill-14B. The recursive model wins decisively on all three difficulty tiers: on easy instances it reaches 98% versus 88.0% (Qwen3-235B, the strongest baseline), on medium it reaches 95% versus 64.8%, and on hard it reaches 64% versus 52.9% (LLaMA3.3-70B, the best hard-tier baseline). The gap is most dramatic on medium instances, where the 3B recursive model outperforms the 235B Qwen3 by 30.2 percentage points. All baselines show accuracy degrading with difficulty (dropping toward or below random), while the recursive model maintains high accuracy even on hard instances it was never trained on, suggesting the recursive decomposition strategy transfers across problem complexity.

## Relation to Prior Work

This paper formalizes and proves the computational power of recursive self-invocation in LLMs, building directly on Savitch's (1977) recursive Turing machine framework (call/return with per-call workspace) and the Transformer primitive operations established in Yang et al. (2025b, Pencil). It departs from prior recursive-LLM work (Sun et al., 2025; Zhang et al., 2025a; Schroeder et al., 2025) by proving that shallow recursion (depth 1) is no more powerful than summarization-based single-context management, while unbounded depth yields an exponential separation—something prior work neither formalized nor proved. The paper also generalizes from the minimal call/return model to arbitrary recursive agentic scaffolds and proves the minimal model is already optimal within that family, a claim no prior agentic-systems paper (Hong et al., 2024; Wu et al., 2023) had addressed.

## Why It Matters / Open Questions

The paper provides the first rigorous complexity-theoretic framework for comparing context-management strategies (summarization, memory, recursion) and shows that recursion depth—not controller sophistication—is the critical resource, with a clean exponential gap between single-context and deep-recursive approaches. This suggests practitioners can achieve maximal reasoning power with a minimal two-tool scaffold rather than elaborate multi-agent orchestration. Open questions include whether the theoretical bounds are tight in practice for non-naturally-recursive tasks, how error accumulation scales with depth, and whether the recursive decomposition strategy transfers to domains less amenable to clean backtracking (e.g., open-ended generation, multi-step planning without a verifiable subgoal structure).

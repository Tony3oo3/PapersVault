## Problem

Mixtures of Bernoulli product distributions are a fundamental latent-variable model, but prior reconstruction algorithms either scale polynomially in n (making them impractical for high-dimensional data) or require impractical exponential factors in r. The paper asks whether the mixture parameters can be recovered with query complexity linear in the number of variables n and polynomial in the number of components r, in a symbolic (noiseless) oracle model.
![Teaser figure](../imgs/ICML20260031/cropped_page1_idx0.webp)

## Input / Output

The algorithm takes oracle access to the probability generating polynomial (PGP) of the mixture, typically realized through a probabilistic generating circuit (PGC), and allows evaluation at points beyond the Boolean hypercube. It outputs the exact mixture weights μ_i and all component marginals p_ij for i∈[r], j∈[n]. The input parameters are assumed specified to γ = Ω(r log n) fractional bits, and the algorithm operates under a genericity condition (parameters avoid a proper algebraic variety of measure zero), with no restrictions on the mixture weights themselves.

## Method

The algorithm partitions the n variables into blocks of size m = O(r) and, for each block, (i) verifies via a Jacobian rank-separation argument that the restriction preserves the fan-in r, (ii) extracts all degree-2 and degree-3 multilinear coefficients exactly by interpolation, (iii) recovers the missing diagonal/repeated-index entries of the moment objects M₂ and M₃ algebraically by exploiting the fact that all (r+1)×(r+1) minors of the rank-r moment matrix (and its mode-flattenings) vanish, yielding a single linear equation per unknown, and (iv) applies whitening followed by the tensor power method to recover the component vectors and weights. Blocks are stitched together globally using a small number of anchor variables to resolve the permutation ambiguity across restrictions. The key distinction from prior spectral methods is the purely algebraic recovery of diagonal statistics (avoiding matrix completion or least-squares) and the use of small projections to achieve linear-in-n query complexity.

## Results

The main result (Theorem 1.2) is an algorithm that exactly recovers all mixture weights μ_i and component marginals p_ij for a mixture of r Bernoulli product distributions over n variables using only O(nr²) oracle queries to the PGP, with a runtime of Õ(nr^{4+ω}) in the oracle-access model. This is the first exact reconstruction algorithm in the PGP oracle model with query complexity linear in n and polynomial in r. The algorithm works in the generic setting (parameters outside a proper algebraic variety), requires no restrictions on mixture weights, and recovers parameters exactly (up to the input precision γ = Ω(r log n) fractional bits).

## Baselines & Comparisons

The paper positions its O(nr²) query / Õ(nr^{4+ω}) runtime against several prior approaches. Gordon et al. (2021, 2024) achieve a linear-in-n runtime of n · 2^{O(r²)} only under a quantitative ζ-separation condition on all observables, and in general require 2^{O(r²)} · n^{O(r)} time, making their method impractical for moderate r. Jain & Oh (2014) give a poly(n,r) algorithm via spectral methods and matrix completion, but the dependence on n is polynomial (not linear) and the approach requires M₂ to be well-conditioned. Bhargava et al. (2020) show that worst-case depth-3 circuit reconstruction takes n^{r^{r^{r^{10}}}} time even for constant r, highlighting how the generic identifiability regime exploited here is essential for tractability. Rabani et al. (2014) study mixtures over a discrete domain of size N, giving near-linear-in-N results, but mapping to the binary case yields N = 2^n, making their bound exponential in n. The key advantage of the present work is that it combines linear-in-n query complexity with polynomial-in-r runtime while recovering parameters exactly (not just approximately), and it avoids matrix-completion or least-squares subroutines by exploiting algebraic rank constraints in the generic setting.

## Relation to Prior Work

This paper sits at the intersection of the method-of-moments framework for latent-variable models (Anandkumar et al., 2014) and the algebraic-complexity literature on structured polynomial reconstruction. It departs from the standard sample-based setting by working in a symbolic PGP/PGC oracle model, where low-degree coefficients are available exactly, and combines this with a Jacobian rank-separation argument to justify restricting to O(r) variables. The key technical departure from prior spectral approaches (Jain & Oh, 2014; Gordon et al., 2021) is an algebraic procedure for recovering missing diagonal moment entries via vanishing minors, replacing matrix-completion or least-squares routines.

## Why It Matters / Open Questions

This is the first exact reconstruction algorithm for mixtures of Bernoulli product distributions with query complexity linear in n and polynomial in r in the PGP oracle model, extending the PGC toolbox beyond inference to parameter recovery. The genericity assumptions (parameters avoiding a proper algebraic variety) are mild but essential, and the paper is purely theoretical with no empirical validation. Open questions include extending to noisy or adversarial oracle settings, other distribution families (bounded treewidth, sparse), and whether the algebraic recovery of missing moments generalizes beyond the symmetric rank-r structure exploited here.

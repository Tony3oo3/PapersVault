## Problem

Neural operators have proven effective for learning deterministic PDE solution operators, but incorporating stochasticity remains highly non-trivial. Existing approaches that handle stochastic forcing lack a unified, principled framework grounded in classical Wiener-chaos theory that simultaneously covers both SDEs and SPDEs and generalizes across diverse downstream tasks (image generation, graph interpolation, financial forecasting, manifold dynamics). This paper fills that gap by making the Wiener-chaos propagator structure explicit and using it to guide neural-operator architecture design.

## Input / Output

The method consumes discretized Brownian or Q-Brownian motion trajectories (converted into finite-dimensional Gaussian coordinates via Karhunen-Loève expansion) together with a deterministic initial condition. The Brownian path is projected onto orthonormal Wick-Hermite features, which serve as the stochastic input to the backbone network; the propagators are further expanded in a fixed temporal basis so the network only learns time-independent spatial coefficient fields. Output is the full solution trajectory reconstructed in a single forward pass—ranging from spatiotemporal PDE fields (64×64 grids for Navier-Stokes) to high-dimensional image samples (CIFAR-10, CelebA-HQ), graph node features, coupled financial price/volatility paths, or points on a Riemannian manifold.

## Method

The core mechanism is a two-stage decomposition: (1) the driving noise is encoded into a finite set of orthonormal Wick-Hermite features (Gaussian coordinates from Brownian increments), and (2) a neural-operator backbone (FNO for SPDEs, UNet/GNN/MLP for SDEs) parameterizes the deterministic propagator functions that govern each chaos coefficient. The key theoretical contribution (Theorems 1 and 2) shows that these propagators satisfy coupled deterministic ODE or PDE systems derived via Malliavin calculus, providing a principled target for the neural operator. For SPDEs, the propagator fields are expanded in a temporal basis so FNO learns only time-independent coefficient fields, which are then combined with the chaos and temporal bases to reconstruct the full trajectory. This yields one-shot evaluation: a single forward pass maps the observed noise trajectory and initial condition directly to the complete solution, without iterative time-stepping. The framework is validated across dynamic Φ₁⁴, 2D stochastic Navier-Stokes, diffusion one-step sampling, topological graph interpolation, Heston financial extrapolation, and manifold SDE flood forecasting.

## Results

On the dynamic Φ₁⁴ SPDE benchmark, F-SPDENO achieves the lowest relative L² error across all settings: 0.012 (W→X, N=1000) and 0.011 (W→X, N=10000), outperforming the next-best NSPDE (0.021 and 0.013) by roughly 43% and 15% respectively. On the 2D stochastic Navier-Stokes equation, F-SPDENO reduces the relative L² error to 0.037 (W→X) and 0.031 ((X₀,W)→X), a 34% improvement over NSPDE on the varying-initial-condition task. On the Flood manifold SDE task, Manifold-SDENO achieves NLL of 0.51±0.12, competitive with RSGM (0.49±0.20). In the law-matching setting without observed Brownian paths, F-SPDENO attains the best test 1-Wasserstein distance of 0.024±0.010.

## Baselines & Comparisons

F-SPDENO consistently outperforms all five SPDE baselines (NCDE, NRDE, NCDE-FNO, FNO, NSPDE) on both the Φ₁⁴ and 2D Navier-Stokes benchmarks, with the largest gains over iterative methods like NCDE (0.134→0.012, ~11× improvement on Φ₁⁴). Against the strongest baseline NSPDE, F-SPDENO reduces error from 0.021 to 0.012 on Φ₁⁴ (43% relative improvement) and from 0.047 to 0.031 on 2D NS with varying initial conditions (34% improvement). FNO, while competitive on the fixed-initial-condition W→X task (0.029 vs 0.012), degrades substantially when the initial condition varies (0.051→0.073 on NS), whereas F-SPDENO improves in that setting. On the Flood manifold SDE task, RSGM slightly edges out Manifold-SDENO (NLL 0.49 vs 0.51), but both substantially outperform RCNF (1.11) and Mixture of Kent (0.73). In the law-matching experiment without observed Brownian paths, F-SPDENO achieves the best 1-Wasserstein distance (0.024), narrowly beating DLR-NET (0.028) and NSPDE (0.026), while FNO performs worst (0.058).

## Relation to Prior Work

This paper extends the SDEONet framework of Eigel & Miranda (2024), which applied Wiener-chaos expansions to 1D SDEs with simple MLP backbones, to multi-dimensional SDEs and semilinear SPDEs using full neural-operator architectures (FNO, GINO, UNet, GNN). It also builds on the WCE-for-SPDE theory of Neufeld & Schmocker (2024) by making the coupled deterministic propagator PDE systems explicit (Theorems 1–2) and using them directly to motivate the operator design. Conceptually, it departs from prior NO-for-SPDE methods (NSPDE, NORS, DLR-NET) that rely on regularity-structure features or iterative inference, instead converting stochastic forcing into static Wick-Hermite features so that a single deterministic operator handles all randomness in one forward pass.

## Why It Matters / Open Questions

The framework provides a unified, principled recipe for learning SDE/SPDE solution operators with one-shot evaluation, demonstrated across an unusually broad set of downstream tasks (SPDE benchmarks, diffusion one-step sampling, graph interpolation, financial extrapolation, manifold SDEs). Key open questions remain: whether higher-order chaos (K>2) is needed for singular SPDEs like Φ₂⁴, how to optimally choose the number of auxiliary Brownian paths in the law-matching setting, and whether the prescribed noise prior can be made adaptive or learnable when the true covariance is unknown. The modest but consistent improvements over strong baselines (e.g., 34% relative error reduction on varying-initial-condition Navier-Stokes) suggest the WCE feature construction is a useful inductive bias, though the framework has not yet displaced purpose-built regularity-structure methods in the singular regime.

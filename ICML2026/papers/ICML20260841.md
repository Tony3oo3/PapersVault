## Problem

LLMs using chain-of-thought reasoning waste substantial compute generating long, incorrect responses, and while dynamic mid-generation abstention has been explored empirically, no principled framework exists for the abstention rule itself. Prior approaches either decide before generation (input processing), after generation (output processing), or at a single fixed token position, leaving open when and why a dynamic stopping rule should trigger and how it compares to these baselines under formal guarantees.

## Input / Output

The method takes a text prompt and, during autoregressive generation, reads the final-layer hidden state at every token position to compute a value estimate via a lightweight two-layer MLP probe (~10⁴ parameters). At each position it produces a binary decision: continue generating the next token or emit the abstention token ⊥ and halt. The abstention threshold T_α is set as the α-quantile of probe outputs on a small held-out calibration set, giving practitioners direct control over the target abstention rate without retraining.

## Method

The paper formulates text generation as a KL-regularized MDP with sparse binary rewards and augments the action space with an abstention token ⊥ carrying a fixed reward r_⊥. From this formulation it derives dynamic value-thresholding: abstain at state (x, y_{1:t}) if and only if the value function V_β(x, y_{1:t}; π) falls below r_⊥, and proves this rule dominates no-abstention, dominates fixed-position abstention under mild conditions, and is globally optimal when the base policy is optimal and β=0. For value estimation, the key insight is that under binary rewards and zero KL regularization the value function reduces to P(correct | prefix), so a two-layer MLP probe trained with parallel binary cross-entropy across all non-terminal positions of completed trajectories recovers the value function under realizability. The probe adds negligible inference overhead (one forward pass per token) and generalizes across datasets without retraining.

## Results

On OlympiadBench (the harder benchmark), dynamic value-thresholding achieves 64% selective accuracy at 90% abstention with Phi-3 (vs. 34% for the best input-processing baseline and 33% for the best fixed-position baseline), and 91% with Qwen2.5 (vs. 69% and 75% respectively). On GSM8K, where baseline accuracy is already high (~87–88%), dynamic abstention reaches 99% selective accuracy at 90% abstention for both models. On RealToxicityPrompts, dynamic abstention achieves a perfect 1.00 non-toxic rate at just 30% abstention, while the strongest baseline (self-assessment) only matches this at 60% abstention. Token savings relative to input-only methods range from 63–86% at 10% abstention to 92–95% at 90% abstention.

## Baselines & Comparisons

Dynamic value-thresholding strictly dominates all four baseline families (Constant Step Probe, Self-Assessment, LoRA Abstention, and no-abstention) pointwise across every abstention rate, model, and dataset. The Constant Step Probe (Kadavath et al., 2022; Afzal et al., 2025) is the strongest competitor, particularly on GSM8K where the gap narrows at high abstention rates, but on OlympiadBench the dynamic method nearly doubles its selective accuracy (64% vs. 34% for Phi-3 at α=0.9). Self-Assessment (Zhang et al., 2024b) and LoRA Abstention (Zhang et al., 2024a) perform near or below the no-abstention baseline on most settings, with their fixed-position variants plateauing regardless of abstention rate—indicating that observing k tokens of partial generation does not substantially help these methods. The advantage is most pronounced on harder problems and at higher abstention rates, where the dynamic method's ability to adapt its stopping point per trace provides a decisive edge over any fixed-position or input-only strategy.

## Relation to Prior Work

This paper formalizes dynamic mid-generation abstention within a KL-regularized RL/MDP framework (Jaques et al., 2017; Ziegler et al., 2019), where abstention is an explicit action with a tunable reward r⊥. It departs from prior empirical approaches—input-processing probes (Kadavath et al., 2022), fixed-position mid-generation rules (Afzal et al., 2025; Zhang et al., 2025), and self-assessment/LoRA methods—by providing the first principled abstention rule (dynamic value-thresholding) with provable dominance and optimality guarantees. The value estimation component builds on the line of work showing LLM hidden states encode correctness information (Azaria & Mitchell, 2023; Kadavath et al., 2022), but reframes it as recovering the MDP value function via binary cross-entropy rather than a standalone classifier.

## Why It Matters / Open Questions

The framework gives practitioners a single interpretable knob (r⊥) to trade off selective accuracy against compute savings, with theoretical guarantees that the dynamic rule dominates fixed-position and input-only baselines under general conditions. The practical recipe—train a ~10⁴-parameter MLP probe on hidden states, threshold at every token—is lightweight and transfers across datasets without retraining, making it deployable. Open questions include extending to state-dependent fallback utilities (a nearly-solved problem is worth continuing even at moderate confidence), continuous rewards from preference models, and addressing calibration when r⊥ is specified directly rather than via a quantile threshold. The method is limited when hidden states do not encode sufficient correctness signal, though experiments suggest this is not severe in practice.

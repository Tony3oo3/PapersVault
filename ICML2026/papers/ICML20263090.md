## Problem

Existing agent benchmarks operate in short-horizon, fully observable settings with only a few thousand tokens and fewer than 30 tool calls per trajectory, failing to stress-test the sustained reasoning, planning, memory management, and tool use required by real-world tasks like large-scale software development, commercial investment, and scientific discovery. UltraHorizon addresses this gap by evaluating agents in long-horizon, partially observable environments where hidden rules must be uncovered through iterative exploration.

## Input / Output

The benchmark takes an LLM agent (e.g., Gemini-2.5-Pro, GLM-4.5, DeepSeek-V3, Kimi K2, Qwen3-235B) and places it in one of three interactive environments with a configurable step budget (fixed or free). Agents consume environment state through tool calls (move, reset, commit, cross, query, Python interpreter, note tools) and must produce a final natural-language description of all hidden rules. Outputs include point-wise scores from a DeepSeek-R1 LLM judge, trajectory statistics (token counts, tool-call counts, completion tokens), and per-trajectory error classifications across eight failure categories. Under the heaviest scaling setting, trajectories average 200k+ tokens and 400+ tool calls; standard configurations still exceed 35k tokens and 60+ tool calls.

## Method

UltraHorizon uses exploration as a unifying task format across three environments—Mystery Grid (10×10 grid with hidden letter effects), Sequence Exploration (dual-sequence transformation pipeline), and Alien Genetics Laboratory (triploid organism inheritance)—each designed around principles of temporal depth, consistency, unknowability, and real-world relevance. Agents must iteratively form hypotheses, design controlled experiments, observe outcomes, and refine understanding before committing a final rule description. The paper proposes CRNR (Context Refresh with Notes Recall), a lightweight scaling strategy that clears accumulated dialogue when approaching the context window limit and instructs the agent to reconstruct knowledge from self-maintained notes, outperforming naive step scaling across multiple models. Ablation on horizon level (varying the number of hidden rules from 1 to 5) shows monotonic performance decline, isolating horizon length rather than per-rule reasoning difficulty as the dominant bottleneck. Trajectory analysis yields a two-level failure taxonomy: two root causes (in-context locking and foundational capability gaps) manifesting as eight observable error patterns, with entropy dynamics confirming progressive in-context locking over sequence position.

## Results

On UltraHorizon, human participants achieve an average score of 26.52 across three environments, substantially outperforming the best LLM agent (Gemini-2.5-Pro at 14.33). Under the heaviest scale setting, trajectories average 200k+ tokens and 400+ tool calls, while standard configurations still exceed 35k tokens and 60+ tool calls. The proposed CRNR (Context Refresh with Notes Recall) scaling strategy consistently outperforms naive scaling across all tested models and environments (e.g., GLM-4.5 improves from 8.18 to 11.20 in Alien Genetics Lab; Qwen3-235B from 6.25 to 13.75 in Mystery Grid). An ablation on horizon level reveals a sharp monotonic decline in agent performance from 34.4% (1 hidden rule) to 5.62% (5 hidden rules), confirming that sustained reasoning over long horizons—not individual rule inference—is the dominant bottleneck.

## Baselines & Comparisons

Five state-of-the-art LLMs are benchmarked: Gemini-2.5-Pro, GLM-4.5, DeepSeek-V3, Kimi-K2, and Qwen3-235B. In fixed-step experiments, Gemini-2.5-Pro achieves the highest scores in Mystery Grid and Alien Genetics Laboratory, followed by Qwen3-235B and GLM-4.5, while DeepSeek-V3 performs poorly in both. Sequence Exploration is the most challenging environment for all models, with uniformly low scores indicating that long-term systematic experimentation in symbolic domains remains a significant open challenge. In free-step settings, Gemini-2.5-Pro improves by ~4 points in two environments, but Qwen3-235B drops 6.44 points in Sequence Exploration, showing that simply removing step constraints is not universally beneficial. The CRNR scaling strategy consistently outperforms naive scaling across all three models and all three environments, with the largest gains observed for Qwen3-235B in Mystery Grid (+7.5 points) and DeepSeek-V3.1 in Mystery Grid (+7.5 points), validating CRNR as a model-agnostic approach to long-horizon context management.

## Relation to Prior Work

This paper carves new ground at the intersection of agent benchmarking and long-context evaluation. Prior agent benchmarks (τ-Bench, SWE-Bench, AgentBench, OdysseyBench) operate in short-horizon, fully observable settings with only a few thousand tokens and fewer than 30 tool calls, while long-context reasoning benchmarks (BABILong, LongReason, RULER) test passive comprehension over static text rather than interactive exploration. UltraHorizon departs from both lines by requiring agents to iteratively discover hidden rules in partially observable environments over trajectories exceeding 200k tokens and 400 tool calls, with no prior work combining sustained interaction, hypothesis testing, and rule induction at this scale. The CRNR (Context Refresh with Notes Recall) strategy and the two-level failure taxonomy (in-context locking vs. foundational capability gaps) are novel analytical contributions not present in prior agent evaluation literature.

## Why It Matters / Open Questions

The benchmark exposes a persistent and quantified gap between state-of-the-art LLM agents (best score ~14.33) and human participants (26.52) in long-horizon exploration, suggesting that current agent architectures lack the sustained reasoning and memory management needed for real-world tasks like scientific discovery or large-scale software development. The finding that naive scaling of interaction steps actively degrades performance after an environment-specific optimum challenges the prevailing assumption that more compute or more steps monotonically improves agent performance, pointing toward the need for principled memory integration and adaptive exploration strategies. Open questions include whether the in-context locking phenomenon is specific to current transformer architectures or fundamental to sequential processing, whether CRNR generalizes to even longer horizons, and whether future models will close the human-LLM gap or whether it reflects a structural limitation.

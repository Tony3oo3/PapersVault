## Problem

LLM agents that execute tasks on users' behalf frequently violate Contextual Integrity by over-disclosing sensitive information, yet existing mitigations impose a universal 'alignment tax': behavioral fine-tuning is expensive, and always-on Chain-of-Thought reasoning adds prohibitive latency and token cost even for the majority of benign interactions. The paper asks whether LLMs already encode privacy sensitivity in their internal representations and, if so, whether that latent signal can be read out to trigger deliberative reasoning only when genuinely needed.

## Input / Output

The system takes a natural-language user prompt (optionally with multi-turn history) as input. During inference, it first performs a partial forward pass up to a chosen intermediate layer to extract the last-token residual-stream hidden state, scores it with a trained linear probe, and then either completes generation directly (System 1) or prepends a Contextual Integrity reasoning prompt before generating (System 2). The output is a standard text response; the only structural difference between paths is the presence or absence of an explicit CI-audit reasoning block, and the probe itself adds less than 1 ms of overhead since it operates on activations already computed during prefill.

## Method

PrivGate is a training-free, two-phase framework. Offline, it constructs a structure-decoupled dataset (mixing easy/hard positives and negatives that break template–sensitivity correlations) and trains a logistic-regression probe on frozen LLM residual-stream activations at an intermediate layer to identify a single 'Privacy Direction' vector. Online, the probe acts as a read-only metacognitive router: it scores the latent state of each incoming query and, if the score exceeds a threshold τ, injects a CI reasoning prompt to activate System 2 deliberation; otherwise the query proceeds through fast System 1 direct generation. The paper provides a theoretical justification (Theorem 3.3) showing that under the Linear Representation Hypothesis, this linear-threshold gating policy is the optimal solution to a risk-constrained compute-allocation problem, and empirically demonstrates near-perfect OOD AUROC on PrivacyLens across five decoder-only LLMs (1.5B–9B) with a 62.6% relative leakage reduction at only 15.9% token overhead.

## Results

Across five decoder-only LLMs (Qwen2.5-1.5B/7B, Mistral-7B, Llama-3-8B, Gemma-2-9B), PrivGate reduces average Leakage Rate from 70.4% (Direct) to 26.3%, a 62.6% relative reduction, while incurring only 15.9% token overhead (149 vs. 128 output tokens). The Privacy Score (1 − LR) rises from 0.296 under Direct generation to 0.737 under PrivGate, approaching Full CoT's 0.760 at 61.9% fewer output tokens (149 vs. 390). Utility is preserved at 95.0%, and the latent probe achieves near-perfect OOD AUROC (≈1.0) on PrivacyLens across all models.

## Baselines & Comparisons

PrivGate substantially outperforms Keyword Gating on both privacy and cost: average LR drops from 53.2% to 26.3% while using fewer tokens (149 vs. 156), because the latent probe catches stealthy sensitive queries that lack explicit keywords. Against Direct generation (System 1), PrivGate cuts leakage by 62.6% relative (70.4% → 26.3%) at only 15.9% additional token cost, making it a near-free privacy upgrade. Compared to Full CoT (System 2), PrivGate achieves a Privacy Score of 0.737 versus 0.760 (a 2.3-point gap) while using 61.9% fewer output tokens (149 vs. 390) and roughly 3× lower wall-clock latency. The small residual gap to Full CoT is attributed primarily to System 2 reasoning failures (23.6 pp) rather than routing misses (2.6 pp), indicating the latent gate itself is highly reliable. An entropy-based uncertainty baseline achieves only 0.78–0.94 OOD AUROC versus >0.99 for the latent probe, confirming that aligned models are often 'confidently wrong' and that semantic intent probing is necessary for reliable privacy routing.

## Relation to Prior Work

This paper repurposes the linear representation hypothesis and representation engineering (Zou et al., 2023) in a fundamentally different way: rather than using a discovered direction to *steer* or *modify* model outputs (as in RepE or ITI), PrivGate treats the privacy direction as a read-only routing signal that decides when to invoke expensive Chain-of-Thought reasoning. It builds on the Contextual Integrity evaluation framework (PrivacyLens, ConfAIde) and the RL-based alignment approach of CIRL, but departs from both by requiring no fine-tuning of the base LLM and no always-on reasoning. The structure-decoupling data construction is a methodological contribution that ensures the linear probe captures semantic intent rather than spurious template correlations, addressing a 'Clever Hans' failure mode that prior probing work on atomic attributes (sentiment, truthfulness) did not need to confront.

## Why It Matters / Open Questions

The practical impact is significant: a 62.6% relative leakage reduction at only 15.9% token overhead (vs. >200% for full CoT) makes CI-aware agent deployment economically viable, and the <1ms probe latency means the gate is essentially free. The competence-performance gap—near-perfect latent AUROC coexisting with 70% behavioral leakage—suggests that alignment failures may be a decoding/instruction-following problem rather than a knowledge problem, which reframes how the field should think about privacy alignment. Key limitations remain: the probe is static and domain-specific, protection still depends on the base model's System 2 reasoning quality (23.6 pp of residual leakage comes from reasoning failures, not routing misses), and the method is untested against adaptive white-box adversaries who could learn to evade the linear boundary. Open questions include principled threshold calibration across domains, combining gating with lightweight activation steering to reduce reliance on verbose reasoning tokens, and extending to encoder-decoder or non-transformer architectures.

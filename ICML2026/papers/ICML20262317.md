## Problem

Conventional variable-length tokenizers modulate token count via nested dropout (truncating ordered sequences), which shifts the datapoint-wise similarity structure across token lengths. This cross-length distributional shift makes it difficult for a single diffusion model to generalize across varying token counts, undermining the flexible quality-compute trade-off that variable-length tokenization promises.
![Teaser figure](../imgs/ICML20262317/cropped_page2_idx0.webp)

## Input / Output

The pipeline takes a class label, a target token length (32–128 out of a maximum 256), and random noise, and produces a 256×256 RGB image. The tokenizer operates on 1D token sequences (no spatial correspondence) with 32-dimensional latents, and the merging pattern is a fixed, data-independent assignment determined by learnable embeddings rather than the input image, so it is fully known at generation time. A LoRA post-training step adds length-specific adapter parameters for each supported token count.

## Method

The paper replaces truncation-based length modulation with token merging: an assignment matrix Γ groups tokens into clusters, and modulated latents are computed as cluster averages, yielding a full-length-equivalent representation Wz of fixed cardinality N for any token length. This makes the representation shift ‖Wz − z‖² directly measurable and minimizable by grouping similar tokens. To keep the merging pattern accessible during generation (unlike data-dependent methods such as ToMe), the authors introduce learnable global embeddings e that determine the merge assignment via agglomerative clustering, trained with a straight-through estimator to backpropagate through the discrete clustering. An alignment loss encourages the learnable embeddings to mirror the token-wise cosine similarity of the latents, so the global pattern preferentially merges similar tokens. The diffusion transformer (LightningDiT) is trained jointly across token lengths using proportional attention to account for merged-token sizes and merged positional embeddings, with optional length-specific LoRA adapters added in a short post-training phase.

## Results

On ImageNet 256×256 class-conditional generation, the proposed method (LightningDiT-XL + LoRA) achieves gFID 2.89 at 32 tokens with only 1.08 TFLOPs (6.12 im/s) using 25 diffusion steps, and gFID 2.03 at 128 tokens with 2.88 TFLOPs. With 100 sampling steps, gFID improves to 2.54 (32 tokens, 4.33 TFLOPs) and 1.86 (128 tokens, 11.51 TFLOPs). The method achieves the best gFID–compute trade-off among all variable-length tokenization baselines, matching or exceeding their quality at a fraction of the FLOPs.

## Baselines & Comparisons

Against Semanticist (Wen et al., 2025), the proposed method achieves comparable gFID at 32 tokens (2.54 vs. 2.57 with 100 steps) while using only 4.33 TFLOPs versus Semanticist-L's 11.18 TFLOPs, and runs 136× faster (2.04 vs. 0.015 im/s). Against FlexTok (Bachmann et al., 2025), the method at 128 tokens with 100 steps matches FlexTok d18-d28's gFID of 1.86 but at 11.51 TFLOPs versus 27.52 TFLOPs; at 32 tokens, FlexTok d18-d18 achieves a lower gFID (2.02 vs. 2.54) but the proposed method is 4.4× faster in throughput. Against fixed-length 1D tokenizers, SoftVQ-B-32 achieves gFID 2.51 at 32 tokens (vs. 2.89 for Ours at 25 steps) but requires 10× more FLOPs (10.82 vs. 1.08 TFLOPs), while MAETok-B-128 reaches gFID 1.73 (vs. 1.86 for Ours at 100 steps) with only 2 TFLOPs but lacks variable-length flexibility. Against the 2D SD-VAE + DiT-XL/2 baseline, the proposed method at 128 tokens (100 steps) achieves a better gFID (1.86 vs. 2.27) with far fewer tokens. Against One-D-Piece (Miwa et al., 2025), the proposed method achieves lower gFID at 32 tokens (2.89 vs. 2.70 at 256 tokens for One-D-Piece) while offering true variable-length control. Against ToMe-style data-dependent merging (Bolya et al., 2023), the proposed learnable global merging yields substantially better generation quality (gFID 3.19 vs. 5.34 at 32 tokens in the ablation) because the data-independent merging pattern enables consistent proportional attention and merged positional embeddings during generation.

## Relation to Prior Work

This paper departs from the dominant nested-dropout paradigm for variable-length tokenization (Semanticist, FlexTok, One-D-Piece), which truncates ordered token sequences following Matryoshka representation learning, and instead proposes merging-based length modulation. It builds on the token merging and proportional attention machinery from ToMe (Bolya et al., 2023) and agglomerative clustering (Haurum et al., 2024), but introduces a key conceptual shift: making the merging pattern data-independent via learnable global embeddings so that diffusion transformers can access it at generation time. The tokenizer backbone follows SoftVQ's 1D ViT architecture, and the diffusion training recipe follows LightningDiT, positioning the contribution squarely at the intersection of VLT design and diffusion model compatibility.

## Why It Matters / Open Questions

The paper identifies a concrete failure mode—nested dropout induces cross-length similarity-structure drift that prevents a single diffusion model from generalizing across token lengths—and provides a principled fix (merging similar tokens enables direct alignment via full-length-equivalent latents). This opens a path toward truly flexible quality-compute trade-offs in diffusion generation without training separate models per resolution budget. Limitations include evaluation only on ImageNet 256×256 with 1D tokenizers (a visible gap versus 2D tokenizers like SD-VAE), and the global merging is acknowledged as suboptimal compared to data-dependent merging; extending to hybrid 1D/2D architectures, higher resolutions, and other modalities remains open.

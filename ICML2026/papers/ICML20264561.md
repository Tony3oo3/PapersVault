## Problem

Existing query-time bounds for Gaussian kernel density estimation (RFF: O(d/ε²), FJLT+RFF: Õ(d+1/ε⁴), Fastfood: Õ(d+Δ²/ε²)) are incomparable and leave gaps in regimes with small error ε and intermediate effective diameter Δσ. This paper closes that gap by proving a new bound Õ(d + εΔσ² + 1/ε³) that improves over all prior methods in the regime ε^{-0.5} ≤ Δσ ≤ min{√d·ε^{-1.5}, ε^{-2.5}}.

## Input / Output

The data structure is constructed once over a finite set X ⊂ R^d (assumed to lie in a ball of diameter Δ) and stores a single precomputed feature vector of dimension Õ(d + εΔ² + ε^{-3}). Given a query point y in the same bounded region, it returns a scalar estimate of (1/|X|)Σ k(x,y) within additive error ε with probability > 1−δ. The dataset can be pre-reduced to O(log(1/δ)/ε²) points via random sampling, so query time is independent of |X|.

## Method

The method composes two iterated Fastfood transforms: an inner transform ψ(HD₂HD₁(sx)) acts as a fast spherical embedding (Theorem 1.3) that preserves small distances up to (1±ε), prevents large distances from collapsing below Ω(ε), and controls the embedded diameter to Õ(1/√ε); an outer transform ψ(HD₄HD₃·s⁻¹·(inner output)) then approximates the Gaussian KDE on the embedded points via the standard Fastfood analysis of Le et al. (2013). The key technical novelty is proving the spherical embedding guarantee, which requires a Wiener chaos decomposition of the 4th moment of the Fastfood output: the 2nd chaos term is controlled by a subexponential Bernstein inequality, while the 4th chaos term is bounded via hypercontractivity of Hermite polynomials and a correlation-matrix analysis of the RHT. This chaos-based analysis is the first to handle the bounded-contraction property needed for the embedding, going beyond the Lipschitz concentration arguments sufficient for standard KDE approximation.

## Results

The paper proves a new Gaussian KDE query time bound of Õ(d + εΔ²_σ + 1/ε³) (Theorem 1.2), which improves over all prior methods in the intermediate-diameter regime ε⁻⁰·⁵ ≤ Δ_σ ≤ min{√d·ε⁻¹·⁵, ε⁻²·⁵}. The bound's dependence on the effective diameter Δ_σ is linear in ε·Δ²_σ (vs. Δ²_σ/ε² for Fastfood), making it strictly better as ε → 0. The result is achieved via a new fast spherical embedding theorem (Theorem 1.3) with running time Õ(d + Λ² + ε⁻²), combined with a second Fastfood invocation for KDE approximation.

## Baselines & Comparisons

The proposed method Õ(d + εΔ²_σ + 1/ε³) dominates all three baselines in the intermediate regime ε⁻⁰·⁵ ≤ Δ_σ ≤ min{√d·ε⁻¹·⁵, ε⁻²·⁵}, a regime previously uncovered by any method. Against Fastfood (Õ(d + Δ²_σ/ε²)), the new bound is strictly better whenever ε < 1 because εΔ²_σ < Δ²_σ/ε². Against FJLT+RFF (Õ(d + 1/ε⁴)), the new bound wins when Δ_σ ≤ ε⁻²·⁵ since εΔ²_σ + 1/ε³ < 1/ε⁴ for small Δ_σ. Against RFF (O(d/ε²)), the new bound is competitive in the high-dimensional regime d ≥ ε⁻² where RFF is subsumed by FJLT+RFF. The three prior bounds are incomparable in general: RFF is best for small d and large Δ_σ, FJLT+RFF for large d and large Δ_σ, and Fastfood for small Δ_σ; the proposed method fills the gap in the intermediate Δ_σ range.

## Relation to Prior Work

This paper builds directly on the Fastfood method (Le et al., 2013), which uses iterated randomized Hadamard transforms for near-linear-time kernel approximation, and on the spherical embedding of Bartal, Recht, and Schulman (2011) that preserves small distances while preventing large-distance collapse. The key conceptual departure is recognizing that Bartal et al.'s embedding is structurally identical to Random Fourier Features (a full Gaussian matrix), and therefore cannot improve over RFF's O(d/ε²) bound; the paper's contribution is replacing that Gaussian matrix with a Fastfood-based RHT proxy to obtain a 'fast spherical embedding' with the same distance-preserving guarantees. The technical core is a new Wiener chaos decomposition analysis of the 4th-order term in the Fastfood transform, which is needed to prove the bounded-contraction property that standard Lipschitz concentration arguments cannot handle.

## Why It Matters / Open Questions

The new query-time bound O~(d + εΔ² + 1/ε³) fills a gap in the KDE complexity landscape for the regime of small error and intermediate effective diameter, where no prior method was optimal. The fast spherical embedding theorem (Theorem 1.3) is explicitly positioned as potentially useful beyond KDE, since Bartal et al.'s original embedding has applications in snowflake dimension reduction, private near-neighbor counting, graph spanners, and Earth Mover Distance algorithms where the O(d/ε²) running time is a bottleneck. Key open questions include whether an O~(d + 1/ε²) bound with only polylogarithmic dependence on diameter is achievable, and whether the approach extends to non-radial kernels. The paper is purely theoretical with no empirical evaluation, and the per-kernel treatment (e.g., the IMQ extension via Beylkin & Monzón approximation) limits generality.

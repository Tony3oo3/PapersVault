## Problem

Computing the Rashomon set (the collection of all near-optimal models) for sparse decision trees is computationally intractable at scale: exact solvers like TreeFARMS and SORTeD require exponential time and memory in depth and feature count, while the only prior approximate method, RESPLIT, suffers significant recall loss. No existing approach can scalably approximate the full Rashomon set on real-world datasets with hundreds of features and millions of samples while preserving near-perfect recall.
![Teaser figure](../imgs/ICML20261553/cropped_page0_idx0.webp)

## Input / Output

The method takes a binary-feature tabular dataset (n samples, k binary features), a depth budget d, a per-leaf penalty γ, and a Rashomon budget ε (specified either as an absolute error bound or as a multiplicative factor (1+ε_mult) applied to the proxy's root objective). It outputs an AND/OR search graph encoding the approximate Rashomon set, from which all valid trees can be enumerated in sorted order of objective value. The graph representation supports downstream tasks (fairness filtering, variable importance, robustness checks) by allowing a simple loop over the set to optimize any secondary criterion.

## Method

PRAXIS uses a proxy algorithm (a modified LicketySPLIT pilot method) as a lightweight subroutine to evaluate candidate feature splits at each subproblem, pruning any split whose proxy-completed objective exceeds the current budget. For surviving splits, it recursively solves left and right subproblems using an iterative budget-refinement procedure (SOLVE_SIBLINGS) that repeatedly loosens sibling budgets whenever a better-than-proxy tree is discovered, improving recall without sacrificing the polynomial-per-tree runtime guarantee. Subproblem solutions are cached via 64-bit hash fingerprints of data-subset bitvectors, enabling reuse across the search. The key theoretical result is that runtime scales as O(|R|·k·d·PROXYCOMPUTE(n,k,d))—polynomial per recovered tree—while recovery is guaranteed under a frontier-cut condition (Theorem 3.5) or with a bounded slack factor σ (Corollary 3.6), and empirically PRAXIS achieves ≥0.98 recall across all tested datasets.

## Results

PRAXIS achieves orders-of-magnitude speedups over all baselines: on Churn (472 features), it completes in 35 s versus 35 hours for SORTeD and 43 min for RESPLIT; on Higgs (11 M samples), it finishes in 40 min while no competitor completes within 90 hours or 200 GB RAM. Memory usage is typically 5× lower than RESPLIT, up to 2 orders of magnitude lower than SORTeD, and up to 4 orders lower than TreeFARMS. Approximation quality is near-perfect: recall relative to ground-truth Rashomon sets is 1.0 on most datasets and never below 0.98 on average across 5 bootstraps. PRAXIS also recovers the globally optimal tree (matching STreeD's objective exactly) on all 50 tested dataset-regularization pairs, up to 3 orders of magnitude faster than STreeD or GOSDT.

## Baselines & Comparisons

PRAXIS dominates all four Rashomon-set baselines on both runtime and memory. Against the exact solvers SORTeD and TreeFARMS, PRAXIS is up to 3 and 5 orders of magnitude faster respectively, and handles many datasets (e.g., Higgs, Madeline, Churn) where the exact methods either run out of memory or exceed the 90-hour timeout. Against the approximate baseline RESPLIT, PRAXIS is up to 2 orders of magnitude faster and ~5× more memory-efficient, while also achieving dramatically better approximation quality: on Churn and Electricity, PRAXIS finds over one million trees within the Rashomon bound, whereas RESPLIT returns zero trees inside the desired set. For optimal single-tree recovery, PRAXIS matches the globally optimal objective (as certified by STreeD) on all 50 dataset-regularization pairs tested, doing so up to 3 orders of magnitude faster than both STreeD and GOSDT (e.g., <3 min vs. >20 hours on News at λ=0.005). The only setting where PRAXIS does not recover the exact optimum is at very small ε_mult (e.g., 0.005), where it misses on 2–3 of 50 datasets, but the gap is negligible (≤0.07% above optimum).

## Relation to Prior Work

PRAXIS builds directly on LicketySPLIT (Babbar et al., 2025) as its proxy subroutine, repurposing a single-tree heuristic into a set-level search algorithm. It departs from exact Rashomon set solvers (TreeFARMS, SORTeD) that require exponential work per tree, and from RESPLIT, which solves simpler subproblems optimally and combines them approximately; PRAXIS instead approximates the full problem directly via a pilot-method framework from operations research. The AND/OR graph search structure connects to recent tree optimization work (Sullivan et al., 2024; Chaouki et al., 2025), but the key conceptual shift is using proxy completions for pruning rather than exact subproblem solutions, yielding polynomial per-tree cost.

## Why It Matters / Open Questions

PRAXIS makes Rashomon set computation feasible on datasets with up to 11 million samples and 472 features—settings where exact methods exhaust 200 GB of RAM or 90+ hours—while maintaining near-perfect recall (≥0.98, often 1.0) across 50+ dataset-binarization pairs. This substantially expands the practical applicability of the Rashomon set paradigm for uncertainty-aware model selection, fairness auditing, and variable importance estimation. Open questions include whether the proxy-guided pruning framework extends to single-tree optimization, continuous features without binarization, and broader partitioning model classes beyond binary decision trees.

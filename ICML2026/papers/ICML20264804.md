## Problem

Existing token-level sparse activation methods for LLM inference (e.g., PowerInfer, DejaVu) rely on per-token MLP predictors at every activation layer, causing two practical bottlenecks: frequent irregular resource calls that hinder decoding-stage acceleration, and non-trivial additional computation from the MLPs themselves (up to ~10% overhead). No prior work had explored whether a smaller, sentence-level set of neurons could be determined once and held fixed throughout decoding, eliminating both the per-token prediction loop and the auxiliary predictor network.

## Input / Output

During the pre-filling stage, the method consumes the full input sentence (typically 64–256+ tokens) and, at each of the L activation layers, computes a sentence-wise core neuron set C_α^β(s_i) by first selecting the top-α positively-activated neurons per token and then retaining the top-β most frequently co-occurring neurons across all tokens. During decoding, this fixed set is reused for every generated token without recomputation, so the only per-token output is the next generated token; no activation map is updated. The hyperparameters α (token-wise ratio, e.g., 0.4) and β (sentence-wise ratio, e.g., 0.2–0.4) control sparsity and are shared across all layers.

## Method

SparseInfer defines sentence-wise core neurons as the top-β neurons that most frequently appear among the top-α positive activations of every token in the sentence, and empirically shows that retaining only 20–40% of neurons yields near-lossless performance. Two semantic insights drive the prediction strategy: (1) Stability — core neurons converge and remain nearly unchanged once the input sentence's semantics are sufficiently defined (typically after ~100–200 tokens), so for long, coherent inputs the pre-filling core neuron set can be directly reused during decoding; (2) Similarity — semantically related sentences activate overlapping neuron subsets, so for short or unstable inputs (e.g., zero-shot QA), the method clusters a reference dataset by activation similarity and selects the top-γ most frequent neurons from the matching semantic cluster. Crucially, no MLP predictor is trained or deployed; the core neuron set is computed once during pre-filling and frozen for the entire decoding phase, eliminating both the per-token prediction overhead and the auxiliary model's memory and latency costs.

## Results

On NVIDIA Titan XP (12GB), SparseInfer achieves a 10.33× decoding speedup on OPT-6.7b (19.83 tokens/s vs 1.92 tokens/s for the original model) while maintaining nearly identical task performance (69.44 avg vs 69.43). For larger models, speedups are 4.63× (OPT-13b) and 3.64× (OPT-30b). SparseInfer requires only 7.28GB of GPU memory for OPT-6.7b (vs 12.10GB for the original), with zero predictor overhead (0ms latency, 0GB memory). On high-end hardware (A100 80GB), SparseInfer reaches 17.2 tokens/s on LLaMA2-70b (5.5× over HuggingFace Transformers) and up to 57.2 tokens/s on LLaMA2-7b.

## Baselines & Comparisons

SparseInfer is compared against two MLP-based token-level sparse activation methods: DejaVu (Liu et al., 2023) and PowerInfer (Song et al., 2023). On OPT-6.7b, SparseInfer matches the original model's task performance (69.44 vs 69.43 avg) while achieving 10.33× speedup, substantially outperforming DejaVu (1.42×) and PowerInfer (3.81×). The speed advantage comes from two sources: eliminating the per-layer MLP predictor (saving 9.62–59.7ms per token and 1.85–10.45GB memory) and fixing the activation set at the sentence level rather than re-predicting per token. On OPT-13b and OPT-30b, SparseInfer achieves 4.63× and 3.64× speedups respectively, compared to only 1.48× and 1.46× for PowerInfer, while also reducing total GPU memory by ~45% (e.g., 13.20GB vs 19.82GB on OPT-13b). Notably, SparseInfer is the only method that is both predictor-free and I/O-free on OPT-6.7b, enabling the entire model to reside on a 12GB GPU without CPU-GPU data transfers.

## Relation to Prior Work

This paper extends the dynamic activation sparse inference line (PowerInfer, DejaVu, LLM in a Flash, PowerInfer2) by shifting the granularity from token-level to sentence-level neuron selection and eliminating the per-layer MLP predictors that prior methods rely on. It builds on the established observation that LLM activations are highly sparse and on the recently reported correlation between activation similarity and semantic similarity (Wang et al., 2024), but departs from prior work by demonstrating that a fixed set of 'core neurons' per sentence suffices for lossless decoding and can be predicted from semantic properties (stability and similarity) rather than from learned per-token predictors. The method thus repurposes the semantic-similarity insight as a practical routing mechanism, carving new ground in how sparse activation is scheduled during inference.

## Why It Matters / Open Questions

SparseInfer offers a practical, training-free path to 10× inference speedup on consumer GPUs (12 GB TITAN XP) with negligible task-performance loss, which is significant for deploying LLMs on resource-constrained hardware without quantization or pruning. The conceptual finding that core neurons stabilize once sentence semantics are well-defined (around 100–200 tokens) and cluster by topic provides a principled justification for sentence-level sparsity that prior token-level methods lacked. Open questions include how the method handles adversarial or rapidly shifting semantic inputs (the authors suggest a monitoring-and-recompute strategy), whether the similarity-guided prediction's effectiveness can be explained by functional partitioning of neurons, and whether the approach generalizes to MoE or mixture-of-experts architectures where sparsity is structural rather than activation-based.

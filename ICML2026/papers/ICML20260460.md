## Problem

Detecting whether the model behind a commercial LLM API has changed is critical for downstream reliability, yet existing methods face a fundamental tension: white-box approaches require model weights, grey-box methods need log-probabilities (available on only a fraction of endpoints), and fully black-box methods like MET demand so many queries that continuous monitoring is prohibitively expensive. No prior method achieves both strict black-box operation (observing only output tokens) and low per-query cost simultaneously.

## Input / Output

The method consumes short text prompts (typically single-token inputs generated via the model's tokenizer) queried at temperature T≈0, observing only the first output token from each API call. During initialization, candidate prompts are sampled m=3 times to identify Border Inputs (those yielding >1 distinct output); during detection, each identified BI is sampled n2=3 times and compared against n1=50 reference samples. The primary output is a binary change/no-change decision based on a support-mismatch test; for ROC evaluation, a continuous total-variation distance between reference and detection token distributions is computed and averaged across multiple BIs.

## Method

B3IT exploits a theoretical phase transition: under the Local Asymptotic Normality framework, the signal-to-noise ratio for optimal change detection diverges as temperature→0 when two or more logits are tied (k≥2), while it vanishes for a unique top token (k=1). This makes 'Border Inputs'—prompts where the model's output distribution is multimodal at T=0—extremely sensitive detectors of even tiny parameter perturbations. The method has two stages: (i) initialization discovers BIs by sampling random single-token prompts 3 times at T=0 and retaining those with >1 distinct output, then estimates their reference distribution with 50 samples; (ii) detection re-queries each BI 3 times at T=0 and rejects H₀ (no change) if the empirical support of detection outputs differs from the reference support. The support-mismatch test is shown to be optimal up to a constant factor for the dominant k=2 regime, with non-asymptotic Type-I and Type-II error bounds, and requires no access to log-probabilities or model weights.

## Results

On the TinyChange benchmark (9 models, 0.5B–9B parameters), B3IT achieves a ROC AUC of 0.9 at an annual monitoring cost of $2.2 per endpoint, while the next-best black-box method (MET at T=0) reaches only 0.61. No black-box baseline reaches ROC AUC 0.9; the closest (MET at T=0) requires $67/year to achieve 0.88. B3IT retains 0.87 ROC AUC even for the hardest case (single-step fine-tuning). In vivo across 131 commercial endpoints (78 models, 34 providers), BIs are found on 78% of endpoints, and continuous monitoring costs only $0.52 per endpoint per year, identifying 8 real model swaps over 23 days.

## Baselines & Comparisons

B3IT substantially outperforms both black-box baselines. Against MET (Gao et al., 2025), B3IT achieves ROC AUC 0.9 at $2.2/year versus MET's 0.61 at its best operating point; MET would need $67/year (a 30× cost increase) to reach 0.88, still below B3IT. Against MMLU-ALG (Chauvin et al., 2026), B3IT shows a wide margin, with MMLU-ALG exhibiting consistently low detection accuracy across all perturbation types. Against the grey-box LT method (Chauvin et al., 2026), which requires log-probability access unavailable on most public endpoints, B3IT achieves comparable ROC AUC (≈0.9) while operating in a strict black-box setting. On the fine-tuning difficulty scale, B3IT and LT both maintain high detection accuracy down to single-step fine-tuning (0.87 ROC AUC), whereas MMLU-ALG and MET degrade significantly as the number of fine-tuning steps decreases.

## Relation to Prior Work

This paper positions itself at the intersection of classical statistical hypothesis testing (Neyman-Pearson, Local Asymptotic Normality) and practical LLM API monitoring. It departs from prior black-box methods (MET, MMLU-ALG) that rely on expensive multi-query distributional comparisons, and from grey-box methods (LT) that require log-probability access, by showing that a strict black-box approach observing only output tokens can match grey-box accuracy. The key conceptual departure is the theoretical identification of a phase transition at low temperature—where tied logits (Border Inputs) cause the signal-to-noise ratio to diverge—repurposing Fisher information and Jacobian analysis from asymptotic statistics to the specific structure of softmax-based LLM inference.

## Why It Matters / Open Questions

The 30× cost reduction enables continuous, large-scale monitoring of LLM APIs (validated on 131 endpoints across 34 providers) that was previously prohibitively expensive, with real-world detection of model swaps (e.g., Together AI redirecting Mistral-7B to Ministral-3-14B). Key limitations include single-token analysis (multi-token dependencies are unaddressed), 22% of endpoints lacking discoverable BIs, and failure on endpoints with hidden reasoning traces. Open questions include extending the theoretical framework to sequential multi-token settings, handling inference non-determinism more rigorously, and whether the phase-transition insight generalizes beyond the first output token.

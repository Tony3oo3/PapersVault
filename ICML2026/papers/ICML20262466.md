## Problem

In multi-agent LLM systems, governance and corrective knowledge fragment across individual agents, causing system-wide violation probability to scale linearly with agent count (O(nε)). Existing remedies either internalize constraints via fine-tuning or prompting (causing further fragmentation and inconsistent interpretation) or reject violating actions outright (sacrificing task utility without repair). No prior method provides composition-invariant enforcement with executable, learnable repair at decision time without modifying agent internals.

## Input / Output

The operator consumes an agent's proposed action (natural language plan, structured command, or tool invocation) along with a portable judgment artifact J = (C, P) — where C is a set of programmatically verifiable constraint predicates and P is a store of precedent repair pairs (x, x′) — plus state context for constraint evaluation. It produces a four-way intervention decision (ALLOW, EDIT, ESCALATE, DENY), an admissible action (the original proposal under ALLOW, a minimally deformed repair under EDIT, or NULL under ESCALATE/DENY), and a timestamped audit log entry. The artifact is model-agnostic and composable: the same J can be applied across heterogeneous agent families without retraining, and precedents are retrieved via cosine similarity over sentence embeddings (OpenAI text-embedding-3-small) with ANN acceleration via Faiss for stores exceeding 10³ entries.

## Method

JO externalizes governance into a centralized decision-time projection Π_J: X → X_J that separates action proposal from judgment, implementing four-way intervention semantics (ALLOW, EDIT, ESCALATE, DENY) as a practically complete basis for handling compliant, repairable, irreparable, and ambiguous actions. The core selection solves a constrained optimization (Eq. 1) minimizing token-level edit distance plus an artifact penalty Ω_J(x′; Θ) — a linear function of four interpretable features (precedent support, retrieval confidence, edit severity, constraint margin) — over a small candidate set (<10 elements) built from the original proposal and precedent-retrieved repairs. JO-A extends this with online nonparametric learning: precedents act as training data for nearest-neighbor regression over the projection map, and upon observed violations the penalty parameters Θ receive a simple additive update (Eq. 3) that penalizes the violating feature profile without retraining any agent. This yields three formal guarantees: composition-invariant enforcement with constant violation probability bounded by checker error ε_J (Proposition 1), sublinear O(K log T) mistake accumulation under (K,ρ)-recurrence (Theorem 1), and semantic preservation for code style projection via group-theoretic equivalence (Proposition 3). The key architectural distinction from safety shields and constrained decoding is that JO operates at execution time on complete actions (not token-level generation), learns reusable repairs rather than merely blocking, and treats the judgment artifact as a first-class portable object enabling zero-shot cross-model transfer.

## Results

On Overcooked (fully checkable semantic constraints, N=200), JO-A achieves 0% violation rate and 100% task success, compared to 48–68% VR and 0–15% success for all internal and external baselines. On recurrent Wikipedia tasks (N=100), JO-A reaches 93% success versus 82–84% for constrained decoding and safety shields. Cross-model transfer (N=200 per student) yields +13.5 to +20.5 percentage points absolute success improvement across five model families, while few-shot prompting with repair examples achieves 0% success. Composition sensitivity (Δ_comp) drops from 15.1pp to 0.1pp under complete mediation (99% reduction).

## Baselines & Comparisons

JO-A decisively outperforms all seven compared baselines on the primary Overcooked benchmark. Internal self-correction methods (Reflexion: 56.2% VR / 10% success; CRITIC: 64.8% VR / 5% success; Self-Refine: 20.9% VR / 0% success) fail to reduce violations below the no-operator baseline, confirming that reasoning loops cannot enforce execution-time constraints. The reject-only classifier LlamaGuard (67.8% VR / 15% success) performs worst among structured baselines, as rejection without repair wastes task budget. Prompt-based approaches (CoT: 14.8% VR / 0% success; Centralized Prompt: 7.1% VR / 2% success) reduce violations but sacrifice nearly all task utility. On recurrent Wikipedia tasks, JO-A (93% success) beats both constrained decoding (Willard & Louf, 84%) and safety shields (Alshiekh et al., 84%) by 9pp, demonstrating that executable precedent repair outperforms syntax-level filtering or action blocking. In cross-model transfer, JO-A's precedent artifacts yield +13.5–20.5pp gains across five model families where few-shot prompting with identical repair examples achieves 0% success.

## Relation to Prior Work

This paper synthesizes three distinct research threads into a unified decision-time framework: safety shields from safe RL (Alshiekh et al., 2018) that project actions to nearest safe alternatives, nearest-neighbor regression for nonparametric online learning, and the composition-invariance principle from MARL (QMIX, COMA). It departs from internal critics (Reflexion, CRITIC, Self-Refine) by externalizing judgment into a portable artifact rather than model-embedded reasoning, and from guardrails (LlamaGuard, NeMo Guardrails) by adding learnable repair via precedent retrieval rather than reject-only classification. The key conceptual departure is treating governance as a decision-time projection problem with four-way intervention semantics (ALLOW/EDIT/ESCALATE/DENY), where the EDIT operation learns reusable corrections online—something neither shields nor guardrails provide.

## Why It Matters / Open Questions

The composition-invariance guarantee (converting O(nε) to O(1) violation probability) provides an architectural principle for multi-agent LLM systems: admissibility should depend on the action and artifact, not agent identity or topology. The zero-shot cross-model transfer result (13.5–20.5pp across five model families where few-shot prompting yields 0%) suggests that executable repair artifacts are a fundamentally different coordination substrate from in-context examples, with implications for heterogeneous multi-agent deployment. Key limitations constrain broader impact: formal guarantees require programmatically verifiable constraints and complete mediation, ESCALATE accounts for 12% of interventions, and the framework does not address adversarial inputs or subjective norms. Open questions include extending to async/streaming deployment, learned-but-auditable verifiers for unverifiable constraints, and whether composition-invariance guarantees extend to geometric (manifold) constraint structures.

## Problem

While LLMs have effectively mastered deductive and inductive reasoning, abductive reasoning—inferring the most probable cause from incomplete observations—remains significantly underexplored. Existing deductive frameworks (CoT, ToT, GoT, FoT) fail on abductive tasks due to unstructured state representation and lack of explicit state control, making them prone to Evidence Fabrication, Context Drift, Failed Backtracking, and Early Stopping.
![Teaser figure](../imgs/ICML20263061/cropped_page1_idx0.webp)

## Input / Output

The method receives only surface-level observations (chief complaints and basic physical exams in medical diagnosis; initial alert metadata in distributed systems) plus a domain knowledge context, while all deep evidence (lab results, imaging, shell snapshots, logs) is hidden in an external repository that must be actively queried via ReAct-style tool calls. The output is a fine-grained root cause prediction accompanied by a comprehensive reasoning report, evaluated on a 3-point scale (Exact Match / Relevant / Otherwise) using both LLM-as-a-Judge and, for medical cases, Human-as-a-Judge.

## Method

GoS is a dual-layer neuro-symbolic framework where a cognitive layer (a central orchestrator agent plus domain-specialist expert agents executing ReAct tool invocations) is governed by a symbolic layer that maintains explicit belief states. The symbolic layer comprises a causal graph—encoding three node types (symptom, evidence, hypothesis) and three edge primitives (derive, refine, support/refute)—that serves as structured external memory, and a state machine that tracks the semantic granularity level of the current hypothesis and enforces two transition rules: backtracking (pruning all descendants when an ancestor is demoted by contradictory evidence) and drill-down (advancing to finer granularity only when a dual-threshold criterion is met: confidence gap δ between top-1 and top-2 hypotheses, and minimum supporting evidence count η). A reasoning focus variable selects the highest-confidence hypothesis at the current level, enforcing depth-first investigation and preventing aimless exploration. The bi-directional loop alternates between symbolic-to-cognitive (focus-guided planning dispatched to experts) and cognitive-to-symbolic (evidence-based graph updates), transforming unconstrained exploration into a convergent, directed search.

## Results

On medical diagnosis (DiagnosisArena, 150 cases), GoS achieves 39.86% Match and 78.99% Relevant under Human-as-a-Judge evaluation, surpassing the strongest baseline Multi/FoT (26.09% Match, 65.94% Relevant) at roughly one-sixth the cost ($0.12 vs. $0.73 per case). On failure diagnosis in distributed systems (150 Lenovo production incidents), GoS reaches 70.67% Match and 88.00% Relevant, exceeding the best baseline Multi/CoT (34.00% Match) by a 36.67-percentage-point margin while costing only $0.10 per case versus $0.94 for Multi/FoT (~8× cost reduction).

## Baselines & Comparisons

GoS decisively outperforms all eight baselines (Single/Multi × CoT/ToT/GoT/FoT) on the Match metric in both domains. In distributed systems, GoS's 70.67% Match nearly doubles the best baseline Multi/CoT (34.00%), with the gap attributed to GoS's state machine enforcing coarse-to-fine drill-down that baselines lack. In medical diagnosis, GoS's 39.86% Human-judged Match exceeds the best baseline Multi/FoT (26.09%) by 13.77 points. Among baselines, FoT consistently achieves the highest Relevant scores (86.67% distributed, 65.94% medical) by exploring a broader search space, but at 9–10× the cost of GoS. ToT variants underperform CoT on Match in both domains, which the authors attribute to ineffective node evaluation causing reasoning deviation. Multi-Agent configurations uniformly outperform Single-Agent counterparts, confirming the value of role-based division of labor, yet even the best multi-agent baseline (Multi/FoT) trails GoS by 42.67 points on Match in distributed systems.

## Relation to Prior Work

This paper departs from the dominant line of LLM reasoning frameworks (CoT, ToT, GoT, FoT), which are designed for static deductive tasks with complete information, and argues they structurally fail on abductive tasks due to unstructured state representation and lack of explicit state control. It also distinguishes itself from prior neuro-symbolic approaches (LINC, LOGIC-LM, Aristotle) that handle fixed logical derivations rather than long-horizon interactive investigation, and from domain-specific abductive systems (MDAgents, D-Bot, FlowXpert) that achieve gains through heavy domain engineering atop conventional deductive scaffolds. GoS carves new ground by introducing a dual-layer architecture where a causal graph serves as explicit belief-state memory and a state machine enforces valid backtracking/drill-down transitions, unifying multi-agent collaboration under symbolic constraints for the first time in a general-purpose setting.

## Why It Matters / Open Questions

The paper addresses a genuine gap: no general-purpose framework existed for abductive reasoning, a task critical to high-stakes domains like medical diagnosis and incident response. The complete elimination of evidence fabrication and the 8× cost reduction over the strongest baseline (Multi/FoT) on distributed systems are practically significant. However, the evaluation is confined to two domains with a single backbone model (GPT-5.1), the medical diagnosis gains are more modest (~14 points over best baseline under Human-as-a-Judge), and the authors themselves identify domain-knowledge deficiency (Wrong Action Selection at 55.9%) as the dominant remaining failure mode, pointing to the need for RAG integration. The distributed systems dataset is not publicly released, limiting reproducibility.

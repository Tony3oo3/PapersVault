## Problem

Orthogonality-based CIL methods (e.g., InfLoRA, LoRA-DRS) project current-task gradients onto subspaces orthogonal to past tasks to prevent interference, but this explicitly discards non-orthogonal gradient components, progressively contracting the feasible optimization space and reducing plasticity as tasks accumulate. The paper asks whether these discarded components can be explicitly repurposed rather than suppressed, to simultaneously preserve stability and recover lost plasticity.
![Teaser figure](../imgs/ICML20262765/cropped_page0_idx0.webp)

## Input / Output

The method takes RGB images from sequential task streams (CIFAR-100, ImageNet-R, CUB-200, ImageNet-A) and processes them through a frozen ViT-B/16-IN21K backbone with LoRA (rank 10) applied to key and value projections of all 12 attention layers. At inference, each input is forwarded through all accumulated task-specific LoRA branches, and the optimal module is selected by minimizing prediction entropy over the full class set, producing a single class label. The efficient variant E-GR-LoRA freezes the input projection A_t and learns only the task-specific output projection B̂_t, halving trainable parameters.

## Method

GR-LoRA decomposes each task's gradient into an orthogonal component (assigned to shared LoRA parameters for stability) and a non-orthogonal residual component (recycled into task-specific LoRA modules for plasticity), using a residual subspace projector constructed from the SVD of current-task feature covariance after subtracting all prior LoRA parameters. The dual-component LoRA architecture (shared {A_t, B_t} + task-specific {Â_t, B̂_t}) ensures that summing both updates recovers the original unconstrained gradient while confining interference to the task-specific module. Two mismatch suppression strategies improve reliability: Local Mismatch Suppression routes current-task data through a randomly sampled historical module with a directional OOD target during training, and Global Mismatch Suppression synthesizes virtual OOD prototypes by transferring weighted geometric drift between shared and task-specific subspaces to recalibrate the classifier. Theoretical analysis (Theorems 3.1–3.2) proves that the plasticity gap shrinks from the full discarded gradient norm to only the portion lying outside the task-specific module's representational subspace.

## Results

On the standard 10-task CIL protocol, GR-LoRA achieves A_Last of 91.97% and A_Avg of 94.65% on CIFAR-100, 82.09%/86.20% on ImageNet-R, 63.60%/70.24% on ImageNet-A, and 89.91%/93.85% on CUB-200, using a ViT-B/16-IN21K backbone with LoRA rank r=10. Under the more challenging 50-task setting, GR-LoRA reaches 90.03%/93.38% on CIFAR-100 and 76.74%/82.64% on ImageNet-R, consistently outperforming all baselines. The method requires only 0.74M learnable parameters and 18.39G MACs, comparable to other LoRA-based approaches.

## Baselines & Comparisons

GR-LoRA achieves the best A_Last on CIFAR-100 (91.97%), ImageNet-A (63.60%), and ImageNet-R (82.09%), and the best A_Avg on CIFAR-100 (94.65%), ImageNet-R (86.20%), and CUB-200 (93.85%), outperforming the strongest competitor MACIL by 0.11–0.44 points on A_Last and 0.07–0.44 points on A_Avg across these datasets. On CUB-200 A_Last, MACIL narrowly leads (90.23% vs. 89.91%), and on ImageNet-A A_Avg, SSIAT (70.73%) and MACIL (70.54%) slightly exceed GR-LoRA (70.24%). Against prompt-based methods (L2P, DualPrompt, CODA-Prompt), GR-LoRA gains 5–20 points on A_Last, demonstrating the advantage of LoRA-based adaptation over prompt selection. Among LoRA-based baselines, GR-LoRA surpasses InfLoRA by 5.77 points on CIFAR-100 A_Last and 6.13 points on ImageNet-R A_Last, confirming that recycling non-orthogonal gradients substantially mitigates the plasticity loss inherent in strict orthogonal projection. The efficient variant E-GR-LoRA (0.38M params) retains within 0.1–0.5 points of the full model, validating the simplified architecture's practicality.

## Relation to Prior Work

GR-LoRA extends the orthogonality-based LoRA line of work (InfLoRA, LoRA-DRS) by identifying a specific waste in their design: the non-orthogonal gradient components that are explicitly discarded to prevent inter-task interference. Rather than treating these components as harmful noise to be suppressed, the paper redirects them into task-specific LoRA modules, preserving them for plasticity while confining their influence to a per-task container. The two-stage optimization framework (training + classifier alignment) is inherited from SLCA, and the mismatch suppression strategies borrow the Outlier Exposure mechanism from OOD detection, repurposing it to suppress erroneous module selection at inference time.

## Why It Matters / Open Questions

The gradient recycling principle offers a general design insight for any method that imposes subspace constraints: information discarded by a projection need not be lost if it can be routed to an auxiliary parameter space. The theoretical characterization (Theorem 3.2) cleanly separates the irreducible plasticity gap from the recoverable portion, giving practitioners a principled way to assess how much capacity the task-specific module needs. A key open question is the linear inference overhead from entropy-based module selection, which grows with the number of tasks and becomes prohibitive in very long sequences; the authors acknowledge this but leave it for future work. The method's applicability is currently scoped to ViT backbones with LoRA on key/value projections, so generalization to other architectures or PEFT variants remains to be validated.

## Problem

Offline goal-conditioned RL agents fail on long-horizon tasks because value estimation errors accumulate over many steps, producing unreliable one-shot policies. Prior fixes introduce heavy machinery—generative planners, distributional ensembles, or specialized distance learners—on the assumption that standard value functions are too noisy to support planning. This paper challenges that assumption, showing that the local geometric structure already encoded in standard GCRL value functions is sufficient for long-horizon planning when processed with the right search mechanism.

## Input / Output

TTGS consumes a small random sample (M=4000, ~0.4% of the dataset) of offline states, the pretrained goal-conditioned value function of any base learner, and a frozen goal-conditioned policy. It produces a precomputed guide path (a sequence of dataset states) and, at each environment step, a single subgoal that is fed to the frozen policy alongside the current state. The distance signal is goal-agnostic and reusable across goals; the only per-episode computation is a Dijkstra search (<1 s) plus per-step subgoal selection (~1.5 ms). The framework also accepts domain-specific metrics (e.g., normalized Euclidean body position) in place of value-derived distances.

## Method

TTGS converts the goal-conditioned value function V(s,g) into a predicted step distance d̂(s,g) via a closed-form inversion of the geometric-sum return (e.g., d̂ = log_γ(1+(1−γ)V) for per-step penalty rewards). It then builds a directed weighted graph over M sampled dataset states, assigning edge weights with a superlinear soft penalty p(x)=x·1000^(x/τ) for transitions exceeding a trust region τ, which preserves graph connectivity while steering the planner toward chains of short, reliable hops. At test time, Dijkstra's algorithm finds the shortest path between the nearest-vertex projections of the start and goal, and an adaptive subgoal selection rule picks the farthest waypoint within a step budget T from the current state (falling back to the next waypoint if none is reachable), ensuring monotonic forward progress. The entire procedure is training-free, requires no online interaction, and adds negligible overhead (<1 s planning, ~1.5 ms per step).

## Results

On OGBench long-horizon locomotion tasks, TTGS lifts success rates from near-zero to over 90% on the hardest stitch mazes: GCIQL+TTGS reaches 98.0% on pointmaze-giant-stitch-v0 (base: 0.0%), HIQL+TTGS reaches 80.9% on the same task (base: 0.0%), and 78.1% on humanoidmaze-giant-stitch-v0 (base: 4.4%). On humanoidmaze-giant-navigate-v0, OTA+TTGS achieves 92.8%, surpassing GAS (85.7%). Planning overhead is under 1 second per episode with ~1.5 ms per-step action selection, and graph construction takes 35–100 s one-time.

## Baselines & Comparisons

TTGS is evaluated against five base learners (HIQL, GCIQL, QRL, SAW, OTA) and two planning methods that require additional training: GAS (Baek et al., 2025, trains a temporal distance representation) and CompDiffuser/CD (Luo et al., 2025, trains a diffusion model). Against the base learners, TTGS consistently improves or maintains performance across all 27 evaluated environments, with the largest gains (50–98 pp) on giant-stitch tasks where base policies fail almost entirely. Against GAS, TTGS is competitive: GAS edges out TTGS on antmaze-giant-stitch (86.2% vs 78.6% for HIQL) and humanoidmaze-giant-stitch (82.4% vs 78.1%), but TTGS wins on humanoidmaze-giant-navigate (OTA+TTGS 92.8% vs GAS 85.7%) and is far more robust with fixed hyperparameters (Table 5: TTGS 69–78% on humanoidmaze/pointmaze vs GAS 5–14%). Against CompDiffuser, TTGS wins on pointmaze-giant-stitch (GCIQL+TTGS 98.0% vs CD 68%) and antmaze-giant-stitch (HIQL+TTGS 78.6% vs CD 65%), while CD wins on pointmaze-large-stitch (100% vs 92.2%). The critical distinction is that TTGS requires zero additional training, no generative models, and no online interaction, operating purely at test time on the frozen base policy and its value function.

## Relation to Prior Work

TTGS repurposes a standard component of offline GCRL pipelines—the goal-conditioned value function—as a distance signal for test-time graph search, departing from prior graph-based RL methods (SoRB, SGM, GAS) that either require specialized distance training, online interaction, or hard edge thresholds that fragment the graph. The soft-penalty mechanism for handling unreliable long-range value estimates is the key methodological departure from both hard-threshold graph pruning and generative trajectory stitching approaches (CompDiffuser, diffusion planners). Conceptually, the work sits at the intersection of offline GCRL and classical motion planning (PRM/TAMP), but replaces known dynamics or collision checkers with noisy learned value estimates, which motivates the penalty design.

## Why It Matters / Open Questions

TTGS offers a practically important, training-free wrapper that any practitioner with an existing offline GCRL agent can adopt to improve long-horizon performance without modifying the training pipeline, with negligible overhead (<1s planning). The hop-ratio diagnostic provides a rollout-free deployment check, and the finding that standard value functions already encode sufficient local geometry challenges the field's assumption that specialized distance learning or generative models are necessary for long-horizon planning. Open questions include what happens when intermediate states are genuinely absent from the dataset (where TTGS gracefully degrades but cannot help), whether generative models can synthesize missing bridging states, and whether the approach extends to settings where the base policy is unreliable even at short range.

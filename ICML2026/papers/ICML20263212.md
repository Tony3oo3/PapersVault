## Problem

Existing theoretical analyses of preference-based reinforcement learning (PbRL) are largely confined to restricted settings—tabular MDPs, linear representations, or Bayesian formulations—and fail to jointly capture the outcome-based and comparison-based nature of trajectory-level preference feedback. No general, scalable framework with provable sample efficiency has been established for PbRL under broad function approximation, leaving a fundamental gap between the empirical success of preference-based methods (e.g., RLHF for LLMs) and their theoretical understanding.

## Input / Output

At each of T rounds, the agent executes a policy in a finite-horizon MDP to produce a reward-free trajectory, then queries a single Bernoulli preference between the new trajectory and the immediately preceding one. The method requires access to three function classes: a value class Q, a return class R, and a backup class Q̃, along with a known link function p mapping return pairs to preference probabilities. The output is a sequence of greedy policies derived from the estimated value function, accompanied by trajectory-level return and backup estimates; the key guarantee is a √T cumulative regret bound parameterized by the Dual Episodic Eluder Dimension (DEED) of the value class.

## Method

RTPQ (Recursive Trajectory-based Preference Q-Learning) is a value-based algorithm that avoids explicit model learning or reward estimation. It first fits a return function by minimizing a squared loss between predicted preference probabilities (induced by return differences) and observed preferences, then estimates a backup function via a separate regression loss to decouple the double-sampling correlation inherent in trajectory-level Bellman errors. The value function is selected from a confidence set defined by a comparison-based loss that measures trajectory-pair Bellman residuals rather than absolute per-step errors. Optimism is applied at the trajectory level—aggregating value differences across the entire horizon on the previous trajectory—rather than at the initial state, which propagates exploration signals across all steps. The regret analysis introduces the Dual Episodic Eluder Dimension (DEED), a new complexity measure that lifts the standard eluder dimension to the space of trajectory pairs, capturing both the comparative and trajectory-level structure of preference feedback; for linear MDPs, DEED scales as Õ(dH), yielding a regret of Õ(dH√T·max{H^{3/2}, 1/κ}), near-optimal up to horizon- and condition-number-dependent factors.

## Results

The paper establishes a √T regret guarantee for PbRL under general function approximation, expressed via the new Dual Episodic Eluder Dimension (DEED): Regret_T ≤ Õ(√((H³ log(N_Q N_Q̃) + 1/κ² log(N_R)) · T · deed(Q;λ) + √(TH⁴))). For linear MDPs, this specializes to Õ(dH√T · max{H^{3/2}, 1/κ}), which is only a factor of Õ(max{H, 1/(κ√H)}) worse than the minimax-optimal Õ(d√(H³T)) bound for standard reward-based linear MDPs (He et al., 2023). The framework also recovers the best-known regret bounds in the special cases of dueling bandits (H=1) and standard outcome-based RL.

## Baselines & Comparisons

The paper is purely theoretical and does not run empirical comparisons, but it positions its guarantees against three prior approaches. Compared to Chen et al. (2022) and Wang et al. (2023), both of which are model-based and depend on the eluder dimension of the transition kernel (which can be very large), RTPQ is value-based and avoids explicit model learning, yielding a bound governed by the DEED of the value function class instead. Compared to Chen et al. (2025a), which requires executing a cumbersome composite policy (optimistic for h steps, then a reference policy) for each horizon h to ensure step-wise reward accuracy, RTPQ operates trajectory-wise and only compares consecutive trajectories, simplifying the algorithm while extending beyond the Bradley-Terry model to general link functions satisfying Assumption 2.3. Against the minimax-optimal standard RL bound Õ(d√(H³T)) for linear MDPs, the PbRL bound incurs an additional Õ(max{H, 1/(κ√H)}) factor, which the authors conjecture reflects an inherent limitation of trajectory-level comparisons rather than a loose analysis.

## Relation to Prior Work

This paper extends the generalized eluder dimension framework of Agarwal et al. (2022) into a new Dual Episodic Eluder Dimension (DEED) that explicitly encodes both the trajectory-level and comparison-based structure of preference feedback, and instantiates it for linear MDPs following Jin et al. (2020). It departs sharply from prior PbRL analyses: where Chen et al. (2022) and Wang et al. (2023) are model-based and depend on transition-kernel generalization, and Chen et al. (2025a) requires cumbersome composite policies across horizons and is restricted to the Bradley-Terry model, RTPQ is a purely value-based algorithm that operates on trajectory returns, uses consecutive-trajectory comparison for optimism, and applies to general link functions. The key conceptual departure is replacing per-step reward estimation with trajectory-level Bellman consistency, sidestepping the double-sampling and temporal-correlation issues that plague step-wise approaches under coarse feedback.

## Why It Matters / Open Questions

This is the first general √T regret guarantee for PbRL under broad function approximation that is value-based and handles arbitrary (not just BT) preference models, providing a clean theoretical template for the RLHF community. The near-optimality for linear MDPs—only a factor of H worse than standard reward-based RL—suggests the trajectory-level comparison structure imposes a mild, possibly inherent, overhead. Key open questions include extending the analysis to active preference querying, richer function classes (neural networks, kernels), and removing the ERM-oracle assumption to yield computationally tractable algorithms; the paper itself notes these as significant limitations.

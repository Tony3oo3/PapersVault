## Problem

High-dimensional Ising model estimation is often limited by small target sample sizes (e.g., n₀=160 for p=200 genes), making target-only nodewise logistic lasso prone to false-positive and false-negative edge errors. While transfer learning has been developed for linear and Gaussian graphical models, it remains largely unexplored for discrete graphical models like the Ising model, where cross-domain heterogeneity shifts the pooled population minimizer and naive pooling of incompatible auxiliary sources causes negative transfer.

## Input / Output

The method takes a target binary dataset X^(0) ∈ {−1,1}^{n₀×p} and S auxiliary binary datasets {X^(s)} ∈ {−1,1}^{n_s×p}, all sharing the same p-dimensional variable space. It produces a symmetric zero-diagonal interaction matrix θ̂ ∈ ℝ^{p×p} and the corresponding undirected graph via an AND symmetrization rule (an edge is retained only if both directed nodewise estimates are nonzero). The procedure also outputs a data-driven set of informative auxiliary sources selected by held-out pseudolikelihood comparison.

## Method

Trans-Ising is a two-stage transfer learning procedure. First, a loss-based source screening rule uses 2-fold cross-validation on the target data: for each auxiliary source, it compares the held-out target pseudolikelihood loss of a target-only logistic lasso against a target-plus-source logistic lasso, retaining sources whose inclusion does not increase loss beyond an adaptive threshold τ = C_τ σ̂. Second, the oracle two-step estimator pools target and selected-source samples for a nodewise ℓ₁-regularized logistic regression (Step 1), then applies a target-only correction (Step 2) using a dual penalty: an ℓ₁ penalty on the correction vector δ encourages sparse adjustments, while a folded-concave SCAD penalty on the updated coefficients θ̂ = ŵ + δ removes shrinkage on strong signals (SCAD derivative is zero above threshold aλ). This dual-penalty design avoids the double-shrinkage problem of applying lasso in both steps and enables exact neighborhood recovery without an irrepresentable condition. The nonconvex Step 2 is solved via local linear approximation (LLA) with proximal gradient, and the final asymmetric nodewise estimates are symmetrized by the AND rule to yield the undirected graph.

## Results

In simulations (p=200, n₀=160, S=12 auxiliary datasets of nₛ=300), Trans-Ising achieves relative Frobenius error closely tracking the Oracle Trans-Ising upper bound across four graph topologies and perturbation levels 100σ∈{1,10,20}, while Pooled-Trans-Ising (naive pooling) degrades when heterogeneous sources are present. On the DepMap mutation data (200 genes, 1,771 cell lines), Trans-Ising consistently achieves relative misclassification error below 1.0 (i.e., better than the Naive-LogLasso target-only baseline) across all reported cancer types, whereas Pooled-Trans-Ising is less reliable and mostly performs worse. Similar improvements over the target-only baseline are observed on the UCI Online Retail and MovieLens 1M datasets, with Trans-Ising yielding relative misclassification error below 1.0 for most target domains.

## Baselines & Comparisons

The primary baseline is Naive-LogLasso (target-only nodewise ℓ₁-regularized logistic regression, Ravikumar et al. 2010), which serves as the reference in all experiments. Trans-Ising consistently outperforms Naive-LogLasso in both simulation (lower relative Frobenius error and better PR curves) and all three real-data studies (relative misclassification error below 1.0). A second comparison is Pooled-Trans-Ising (naive pooling of all auxiliary sources without screening), which the paper shows can suffer negative transfer: in simulations with 9 heterogeneous sources, Pooled-Trans-Ising exhibits higher error than Naive-LogLasso at some perturbation levels, while Trans-Ising avoids this degradation through its loss-based source screening. Oracle Trans-Ising (known informative source set) serves as an upper-bound benchmark; Trans-Ising closely tracks it in both estimation error and edge-recovery PR curves, confirming that the data-driven source detection recovers nearly oracle performance. In the real-data studies, Pooled-Trans-Ising is generally less reliable than Trans-Ising, with the gap being most pronounced in the DepMap mutation data where heterogeneous cancer types induce distribution shift.

## Relation to Prior Work

This paper extends the two-step transfer learning framework of Tian & Feng (2023) for high-dimensional generalized linear models to the discrete Ising model setting, where the intractable partition function necessitates nodewise logistic pseudolikelihood (Ravikumar et al., 2010) rather than standard likelihood. The key methodological departure is a dual-penalty correction step that applies ℓ₁ regularization to the correction vector δ while using a folded-concave SCAD penalty (Fan & Li, 2001) on the updated coefficients, enabling exact support recovery without the irrepresentable condition that standard lasso-based corrections require. The loss-based source screening rule is adapted from Tian & Feng (2023) but operates on held-out target pseudolikelihood rather than prediction loss, reflecting the discrete nature of the response.

## Why It Matters / Open Questions

This is the first transfer learning method for high-dimensional Ising models with non-asymptotic error bounds and exact graph recovery guarantees, filling a gap between the well-developed transfer learning theory for continuous-valued GLMs and the discrete graphical model setting. The separation of pooled variance reduction from cross-domain heterogeneity (h_j) in the error bound provides a clear diagnostic for when transfer helps versus hurts. A stated limitation is the computational cost of cross-validated screening when many auxiliary sources are available, and the authors note that structured regularization (e.g., logistic group lasso) could improve interpretability when group structure is known. Open questions include scalable screening alternatives and extension to higher-order or directed interaction models.

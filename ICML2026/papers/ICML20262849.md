## Problem

RKHS-based conditional conformal prediction (Gibbs et al., 2025) provides distribution-free conditional coverage guarantees under complex covariate shifts, but its computational cost is prohibitive: each candidate imputed test score requires a fresh kernel quantile regression solved via binary search, and hyperparameter selection is restricted to a pre-specified grid. This limits scalability to large-scale and high-dimensional applications where raw-covariate kernels become ineffective.
![Teaser figure](../imgs/ICML20262849/cropped_page2_idx0.webp)

## Input / Output

The method consumes a trained predictor μ̂, n calibration pairs (X_i, S_i) with conformity scores, a test point X_{n+1}, and a low-rank embedding map π̂: R^p → R^K (K ≪ p) fitted symmetrically across calibration and test sets. It outputs a randomized prediction set Ĉ_rand*(X_{n+1}) = {y : S(X_{n+1}, y) ≤ S^rand(X_{n+1})}, where the cutoff S^rand is determined by tracing the S-path with a randomization U ~ Unif(−α, 1−α) to avoid coverage inflation. The kernel ψ* is defined on the embedding space via an RBF on centered log-ratio transformed simplex coordinates (for admixture data) or PCA-reduced GNN/CNN features.

## Method

SpeedCP introduces two solution-path algorithms that exploit the piecewise-affine structure of the regularized RKHS quantile regression. The λ-path traces the regularization parameter over a split set, updating only when the elbow set (indices with exactly zero residuals) changes, enabling exhaustive cross-validation over (γ, λ) without repeated full refits. The S-path then traces the imputed test score S using the same active-set mechanism to find the maximum cutoff S* such that the test point's RKHS coefficient v_{S,n+1} < 1−α, replacing the binary search of Gibbs et al. At each step, only a (|E|+d)×(|E|+d) matrix inversion is needed, where |E| ≪ n+1 in practice, yielding a ~40× speedup. For high-dimensional covariates, the kernel is defined on learned low-rank embeddings π̂(X) (e.g., pLSI mixture weights, PCA of GNN features, or CNN layer embeddings), shifting the conditional guarantee from P(Y∈Ĉ|X) to P(Y∈Ĉ|π̂(X)) while preserving finite-sample validity.

## Results

On the synthetic admixture setting (target miscoverage α=0.1), SpeedCP achieves marginal miscoverage of 0.105±0.07 (linear predictor) and 0.098±0.02 (neural network), with prediction set sizes of 2.074±0.14 and 0.804±0.06 respectively, in 22.05 seconds. On molecular benchmarks (QM9, QM7b, ESOL), SpeedCP produces the smallest prediction sets among all conditional methods (e.g., 1.135 on QM9 vs. 1.922 for CondCP) while running ~50× faster than CondCP (31s vs. 1531s). On the brain tumor MRI task, SpeedCP achieves near-nominal 0.9 coverage for both healthy (0.902) and tumor (0.901) subgroups with prediction set size 0.282, compared to 0.348 for SplitCP and RLCP.

## Baselines & Comparisons

SpeedCP dominates CondCP (Gibbs et al., 2025) across all metrics: it achieves closer-to-target miscoverage (0.105 vs. 0.123), smaller prediction sets (2.074 vs. 2.782, a ~25% reduction), and runs ~60× faster (22s vs. 1333s) by replacing CondCP's binary search over imputed scores with the S-path algorithm. Against PCP (Zhang & Candès, 2024), SpeedCP produces tighter sets (2.074 vs. 2.535) and achieves miscoverage closer to the 0.1 target (0.105 vs. 0.076, where PCP undercovers), while also being ~6× faster. Versus RLCP (Hore & Barber, 2025), SpeedCP matches runtime (22.05s) but yields smaller prediction sets (2.074 vs. 2.228) and more accurate coverage. On the molecular benchmarks, SpeedCP achieves the smallest conditional prediction sets among all methods (e.g., 0.902 on QM7b vs. 1.447 for CondCP, 1.303 for PCP, 1.286 for RLCP), while SplitCP—though fastest—undercovers in some latent-space partitions due to its single global threshold. On the MRI task, SpeedCP with linear terms (Φ*) achieves balanced 0.902/0.901 coverage for healthy/tumor groups with set size 0.282, outperforming SplitCP and RLCP (both 0.348) and PCP (0.231 but with high variance and overcoverage for healthy at 0.945).

## Relation to Prior Work

SpeedCP builds directly on the RKHS-based conditional conformal prediction framework of Gibbs et al. (2025), which reformulated conditional coverage as a regularized kernel quantile regression but suffered from prohibitive computational costs due to binary search over the imputed score and grid search over the regularization parameter. The algorithmic core draws on the solution-path structure for RKHS quantile regression from Li et al. (2007), analogous to the LASSO/LARS active-set tracking, and extends it to handle both the regularization parameter (λ-path) and the imputed test score (S-path) simultaneously. The key departure is the introduction of low-rank latent embeddings (PCA, pLSI, layer features) as the kernel domain, which shifts the conditional coverage guarantee from the raw covariate space to a data-driven latent space, making the method applicable when p ≫ n.

## Why It Matters / Open Questions

The 40-fold speedup and 30% reduction in prediction set length over CondCP make RKHS-based conditional conformal prediction practically feasible for high-dimensional problems (molecular graphs, medical images, text), where prior methods were computationally intractable. The clean theoretical result that embedding estimation error affects only prediction set width but not coverage validity provides practitioners with confidence in using approximate low-rank projections. Open questions include extending to adaptive miscoverage levels α, structured/multi-output prediction, and incorporating sample weights; the current framework is limited to scalar regression with a fixed α and requires exchangeability of calibration and test points.

## Problem

Existing image-free zero-shot classifier expansion methods rely on a single shared semantic-to-weight mapping that cannot simultaneously satisfy the coarse-grained separation needed for visually distinct classes and the fine-grained discrimination needed for similar classes. This granularity mismatch causes optimization interference where gradients from distinct classes dominate, suppressing the subtle attributes required to separate confusable classes, a problem that worsens as classes are continuously added.

## Input / Output

During training, the method consumes paired semantic descriptions and pre-trained ResNet-101 classifier weights for seen classes, plus semantic descriptions only for unseen classes (no visual samples). The semantic input is a set of 30 multi-source text descriptions per class, generated by GPT-4o under controlled style and environment interventions, and embedded via CLIP into vectors of dimension d_e. At inference, the method takes the multi-source semantic embedding of an unseen class and outputs a single synthesized weight vector that is injected into the frozen pre-trained model to classify RGB test images.

## Method

The framework decomposes the shared mapping into three modules. First, Multi-Source Semantic Generation (MSG) grounds class descriptions in a reliable attribute ontology (filtered by entropy-based transferability and discriminability scores) and then applies causal do-interventions on linguistic style and observational environment to produce 30 diverse descriptions per class, severing spurious correlations. Second, Class-Level Structure Discovery (CSD) fuses these descriptions via attention and fits a von Mises-Fisher mixture model (initialized by Spherical K-means) to yield K soft-routing cluster assignments that separate distinct from similar classes. Third, Adaptive Classifier Synthesis (ACS) uses a global dual autoencoder backbone (semantic and weight branches) augmented with per-cluster residual bottleneck adapters, where the soft routing weights a convex combination of the global encoding and the cluster-specific adapter output. A causal invariance loss penalizes the weight decoder for producing different outputs when non-causal latent components are swapped within the same class, enforcing that synthesized weights depend only on invariant visual attributes.

## Results

In the LLM-generated semantic setting, the proposed method achieves a harmonic mean (H) of 77.2% on CUB, 63.3% on AWA2, and 41.2% on SUN, outperforming the strongest baseline CEMIL+MSG (H = 60.9%, 63.3%, 38.6%) by 8.89%, 0%, and 7.01% respectively. On CUB, the method reaches 71.8% ZSL top-1 accuracy and 59.6% unseen-class accuracy in GZSL. The attribution analysis shows that granularity-aware modeling contributes an average 8.3% gain, substantially exceeding the 3.8% gain from richer multi-source semantics alone.

## Baselines & Comparisons

The paper compares against seven baselines spanning convex-combination methods (ConSE, COSTA), autoencoder-based synthesis (wDAE, SubReg), and LLM-enhanced methods (VGSE, ICIS, CEMIL). ConSE and COSTA are effectively non-functional in GZSL (H < 6%), as they cannot balance seen and unseen accuracy. wDAE and SubReg improve slightly but remain weak (H < 5% on CUB). VGSE and ICIS represent the first methods to achieve meaningful GZSL performance, with ICIS reaching H = 57.2 on CUB. CEMIL is the strongest baseline (H = 60.9 on CUB, 63.3 on AWA2, 38.6 on SUN). The proposed method outperforms CEMIL+MSG by 8.89% on CUB H and 7.01% on SUN H, while matching it on AWA2 H (63.3%). Notably, even when baselines are given the same MSG-generated multi-source semantics as input, they still underperform, confirming that the gains originate from the granularity-aware adaptive architecture (CSD + ACS) rather than from richer semantics alone.

## Relation to Prior Work

This paper extends the image-free zero-shot classifier expansion paradigm established by ICIS (Christensen et al., 2023), which learns a single shared semantic-to-weight mapping via dual autoencoders. The key departure is replacing this monolithic mapping with a granularity-aware partition: a vMF mixture model discovers coarse-grained class clusters, and per-cluster residual adapters refine fine-grained discrimination, drawing conceptually from MoE/adapter architectures (CLIP-Adapter, UniAdapter) but applying them in a setting where visual routing cues are unavailable. The multi-source semantic generation module introduces causal intervention (do-operator on linguistic style and environment) at the text-generation level, which is distinct from prior causal ZSL work that operates on visual features or correlation regularization.

## Why It Matters / Open Questions

The framework addresses a practical deployment bottleneck—continuously expanding classifiers without collecting new images—and provides a principled mechanism (structural partitioning + causal invariance) to balance generalization across distinct classes with fine-grained discrimination among similar ones. The attribution analysis showing that structural modeling contributes roughly twice the gain of richer semantics alone is a useful design guideline. Limitations include dependence on GPT-4o quality for semantic generation, the 'causal' intervention being a controlled text perturbation rather than a true Pearl-style intervention on visual data, and untested scalability to very large class spaces (thousands of classes). Open questions include whether the vMF routing can be replaced by learned soft assignments without the Spherical K-means initialization, and how the method behaves when LLM semantics carry systematic domain biases.

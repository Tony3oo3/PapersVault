## Problem

While clarification questions can improve agent task success, prior work lacks a principled understanding of which types of missing information most affect downstream outcomes and how to formulate questions that users can realistically answer. Existing approaches target singular linguistic ambiguities rather than the multi-dimensional underspecification common in task-oriented settings, where multiple information gaps coexist with varying importance and users have bounded knowledge about the issues they report.

## Input / Output

The clarification module receives a single underspecified GitHub issue description (a natural-language rewrite of a SWE-Bench Verified issue with specific information categories removed) and produces a short set of targeted clarification questions (typically 1–5). Questions are answered by a simulated user (GPT-5 with access to the fully-specified original issue), and the resulting answers are injected as additional context to a fixed agent backbone (Seed OSS 36B in OpenHands) before code generation begins. The design is strictly single-turn: all questions are posed and answered before the agent starts implementation, isolating clarification quality from multi-turn interaction dynamics.

## Method

CLARITI is a Qwen3-8B model trained in two phases: supervised fine-tuning on 3,000 SWE-Gym-derived question pairs, followed by GRPO reinforcement learning with a four-stage reward pipeline. The pipeline's key insight is grounding each reward in empirical analysis rather than generic heuristics: Stage 1 (non-redundancy) filters questions answerable from the issue itself; Stage 2 (diversity) penalizes cross-issue template similarity; Stage 3 (answerability) scores whether answers appear in the fully-specified issue, operationalizing RQ2's distributional findings on four answerability strategies; Stage 4 (task relevance) classifies questions into six information categories and weights them by their Shapley-derived impact on task success from RQ1. Each stage applies a rejection threshold (candidates below 0.5 receive zero reward in subsequent stages), preventing reward hacking by any single component. The final reward equally weights all four stages, and Qwen3-32B serves as the training judge while GPT-5 is used for evaluation to avoid self-bias.

## Results

On 250 underspecified SWE-Bench Verified issues, CLARITI (8B) achieves 36.8% task success with only 3.0 average clarification questions, recovering 88% of the fully-specified upper bound (41.6%). This matches GPT-5's success rate (35.6%) while generating 41% fewer questions (3.0 vs. 5.1). CLARITI also attains the highest task relevance score (0.622) and comparable answerability (0.373) among all clarification methods, with the no-clarification baseline at 22.4%.

## Baselines & Comparisons

CLARITI outperforms GPT-5 on task success (36.8% vs. 35.6%), task relevance (0.622 vs. 0.580), and question efficiency (3.0 vs. 5.1 questions, a 41% reduction), while achieving comparable answerability (0.373 vs. 0.369). Against GPT-5 Nano, CLARITI leads on every metric: success (36.8% vs. 29.6%), answerability (0.373 vs. 0.339), relevance (0.622 vs. 0.576), and question count (3.0 vs. 5.2). The key differentiator versus GPT-5 is category allocation: CLARITI directs 26.4% of its questions toward Error Information (the highest-impact category per Shapley analysis) compared to only 10.2% for GPT-5, while reducing lower-impact categories like Reproduction Steps (19.6% vs. 30.2%). Both GPT baselines ask valid questions but concentrate their budget on moderate- and lower-impact categories, whereas CLARITI's reward-driven training explicitly prioritizes the empirically highest-impact information types.

## Relation to Prior Work

This paper departs from the dominant line of clarification research that targets linguistic ambiguity (referential, syntactic, or single-point intent uncertainty) by reframing clarification as a multi-dimensional information-recovery problem in task-oriented settings. It repurposes Shapley value analysis (from model interpretability) and distributional difference discovery (Zhong et al., 2023) as empirical tools to ground reward design, rather than using them as post-hoc explanations. The multi-stage GRPO training pipeline draws on rubric-style reward decomposition (Viswanathan et al., 2025; Dineen et al., 2025) but applies it to a novel four-stage structure where each stage addresses a distinct failure mode identified by the preceding empirical analyses. Unlike prior agentic clarification work that models user mental states or personalizes questions, this paper takes a model-centric view: given typical user knowledge boundaries, optimize the agent's question strategy for downstream task success.

## Why It Matters / Open Questions

The paper provides a generalizable methodology—quantify information impact empirically, characterize answerability structurally, then operationalize both as training rewards—that could transfer to any domain where agents must extract specifications from users. The finding that an 8B model matches GPT-5's resolution rate while asking 41% fewer questions suggests that principled reward design can substitute for raw model scale in clarification, with practical implications for deployment cost and user burden. Key limitations include the single-turn setting (no multi-turn dynamics), SWE-specific empirical grounding, and reliance on LLM judges that may diverge from human assessment. Open questions include whether the frequency-impact misalignment generalizes beyond SWE, how the approach behaves in multi-turn interactions where users can refine answers, and whether the staged reward structure remains effective as the base model scales.

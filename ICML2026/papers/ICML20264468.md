## Problem

Existing personalized federated LoRA fine-tuning methods for LLMs rely on dual or multi-adapter schemes that create conflicting optimization objectives between generalization and personalization, degrading performance during parameter merging. Moreover, these methods assume uniform personalization needs across all clients, failing to accommodate heterogeneous requirements where some clients need more personalized knowledge (e.g., medical domains) while others need more generalized knowledge (e.g., education domains).

## Input / Output

Each client provides a local task dataset (300 samples per task from FLAN-derived benchmarks), a heterogeneous LoRA rank configuration (r_c for total rank, r_{c,s} for shared subspace, r_{c,p} for personalized subspace), and a pre-trained LLM (LLaMA 3.2 1B or Qwen2.5-1.5B). During inference, the method additionally consumes the user's text instruction and computes its perplexity against the local dataset to derive an OOD score, which dynamically scales the shared and personalized LoRA subspaces before generating the text response. The output is a generated text response with LoRA parameters whose effective update is a weighted sum of shared and personalized low-rank components.

## Method

Het-CPFLoRA exploits a discovered decoupling property of LoRA matrices: the product BA can be exactly decomposed into B_s A_s + B_p A_p by partitioning columns of B and corresponding rows of A, enabling a single adapter to simultaneously encode shared and personalized knowledge without the optimization conflicts of dual-adapter training. During local training, each client fine-tunes one LoRA module with a client-specific rank r_c, then decouples it into shared (rank r_{c,s}) and personalized (rank r_{c,p}) subspaces. The server aggregates full-rank shared updates (B_{c,s} A_{c,s}) using weights proportional to local data size times shared rank, then applies SVD to compress the global full-rank matrix back to each client's individual shared rank. At inference, a perplexity-based OOD score determines coupling weights γ_s and γ_p that scale the B matrices of each subspace, allowing the model to shift emphasis toward generalized knowledge when user input deviates from the local task distribution.

## Results

On Dataset 1 (All Homogeneous), Het-CPFLoRA with dynamic weighted inference (Our-auto) achieves 59.12 Rouge-1 average personalization and 54.72 average generalization, outperforming the strongest baseline pFedSeq (56.88 / 52.41) by 2.24% and 0.35% respectively. On Dataset 2, Our-auto reaches 52.27 / 45.84, surpassing pFedSeq (45.71 / 44.63) by 6.41% in personalization and 0.52% in generalization. In the All Heterogeneous setting, gains widen substantially: Our-auto achieves 61.84 / 56.17 on Dataset 1 and 58.95 / 47.23 on Dataset 2, representing up to 13.09% personalization improvement and 1.91% generalization improvement over the best baselines.

## Baselines & Comparisons

Het-CPFLoRA with dynamic weighted inference (Our-auto) outperforms all four baselines on both datasets in the All Homogeneous setting. Against pFedSeq (the strongest baseline), Our-auto gains 2.24% personalization and 0.35% generalization on Dataset 1, and 6.41% / 0.52% on Dataset 2. Against FedDPA-Auto, the gains are 2.80% / 0.35% (Dataset 1) and 6.41% / 0.52% (Dataset 2). PF2LoRA and pFedGPT trail further behind, with Our-auto leading by 9.90% and 4.99% in personalization on Dataset 1 respectively. In the All Heterogeneous setting (where only Het-CPFLoRA is evaluated against FedDPA as the sole comparable baseline), the advantage widens dramatically: Our-auto achieves 61.84 / 56.17 on Dataset 1 versus FedDPA's 39.87 / 32.44, a 21.97% personalization and 23.73% generalization margin. The paper notes that existing multi-adapter baselines (FedDPA, PF2LoRA) do not support heterogeneous rank configurations, so direct comparisons in heterogeneous settings are limited to FedDPA.

## Relation to Prior Work

This paper builds directly on the line of personalized federated LoRA fine-tuning for LLMs (FedDPA, PF2LoRA, pFedGPT, pFedSeq), which all rely on multi-adapter schemes to separately learn generalized and personalized knowledge. The key departure is the discovery of a LoRA matrix decoupling property that allows a single adapter to be partitioned into shared and personalized subspaces, eliminating the optimization conflicts inherent in alternating dual-adapter training. It also extends the heterogeneous federated LoRA setting (FLoRA, FlexLoRA) by allowing per-client customization of both the LoRA rank and the personalization-to-generalization ratio, a dimension prior work treats as uniform across clients.

## Why It Matters / Open Questions

The paper addresses a practical gap in federated LLM deployment: real-world clients have heterogeneous data, compute, and personalization needs, yet existing PFL methods assume uniform personalization settings. The single-adapter decoupling approach reduces both communication and computation overhead relative to dual-adapter baselines, and the OOD-based dynamic weighted inference offers a lightweight mechanism for handling out-of-distribution user queries at inference time. However, the method cannot automatically determine the optimal subspace rank partition (r_p vs. r_s), relies on perplexity as a proxy for OOD detection (which may be unreliable for short or adversarial inputs), and is validated only on 1B–7B models across two 8-task datasets, leaving open whether the approach scales to truly large models or highly diverse task distributions.

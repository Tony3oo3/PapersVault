## Problem

Existing methods for continuous-time dynamic graphs (CTDGs) cannot simultaneously capture long-range temporal (LRT) and long-range spatial (LRS) dependencies: event-driven models preserve only short-term temporal patterns, while sequence-based models (DyGFormer, DyGmamba) target LRT but restrict structural context to one-hop neighborhoods, failing to propagate information over multi-hop spatial paths. No prior state-space model for CTDGs jointly encodes both temporal memory compression and evolving graph topology.

## Input / Output

The model consumes a continuous stream of timestamped interaction events (u, v, t) in batches of B chronologically consecutive events, augmented with node static embeddings, edge attributes, and inter-event time deltas encoded via a fixed time-encoding function. At each batch, a subgraph is sampled by taking up to N_u most recent neighbors per participating node, from which a batch-level normalized Laplacian is constructed. The output is a per-node latent memory vector of dimension d that evolves online; downstream decoders map these memories (concatenated with static embeddings and temporal encodings) to edge scores for link prediction, class probabilities for node classification, or sequence labels for the LRS evaluation task.

## Method

The core contribution is CTT-HiPPO, which reformulates the classical HiPPO memory by projecting its coefficients through the inverse of a learnable polynomial graph filter p(L_τ)^{-1}, so that the memory jointly encodes temporal dynamics (via orthogonal polynomial basis) and graph structure (via Laplacian polynomial). Differentiating this relationship yields CTDG-SSM, a continuous-time state-space model whose ODE includes an additional graph-aware term −p(L_s)^{−1}(dp(L_s)/ds)H_s that accounts for structural evolution between events. ZOH discretization produces the implementable recursion H[k+1] = Ā_{L[k]}·H[k]·Ā + B̄(L[k],X[k]), where Ā_{L[k]} = exp(−p(L[k])^{−1}(p(L[k])−p(L[k−1]))) captures topology change and Ā = exp(−Δ[k]A^⊤) captures temporal decay. The architecture stacks multiple CTDG-SSM layers with RMSNorm, GeLU, and residual connections (Mamba-style), and is parameter-efficient, requiring only the polynomial filter coefficients and system matrices as learnable parameters. Theoretical guarantees establish linear robustness of memory coefficients to Laplacian perturbations and permutation equivariance of the full model.

## Results

On dynamic link prediction (transductive, random negative sampling), CTDG-SSM achieves an average rank of 1.86 across 7 datasets, with standout results on long-range temporal (LRT) benchmarks: 99.00 AUC-ROC on MOOC (vs. 89.58 for DyGmamba), 94.98 on Enron (vs. 93.34), and 93.79 on LastFM (vs. 93.31). On dynamic node classification, CTDG-SSM achieves 88.61 AUC-ROC on Wikipedia and 69.50 on Reddit, both best among all baselines. On the sequence classification task (designed to stress long-range spatial reasoning), CTDG-SSM (SO) reaches 98.60% accuracy at path length n=20, compared to 88.93% for CTAN and 45.29% for DyGmamba. The model achieves these gains with roughly one-tenth the learnable parameters of competing methods.

## Baselines & Comparisons

CTDG-SSM outperforms all 10 baselines on 6 of 7 link prediction datasets in both transductive and inductive settings, with the sole exception being UCI, where DyGmamba (94.77) and DyGFormer (94.45) substantially outperform CTDG-SSM (89.24 transductive / 87.43 inductive). The largest margins appear on LRT benchmarks: MOOC (99.00 vs. 89.58 for DyGmamba, a ~9.4-point gap) and Enron (94.98 vs. 93.34), where the graph-polynomial memory mechanism captures multi-hop temporal patterns that sequence-based baselines miss. On dynamic node classification, CTDG-SSM leads DyGmamba by 1.17 points on Wikipedia (88.61 vs. 87.44) and 1.80 points on Reddit (69.50 vs. 67.70). The sequence classification task reveals the sharpest differentiation: at path length n=20, CTDG-SSM (SO) achieves 98.60% accuracy while DyGmamba drops to 45.29% and DyGFormer to 42.79%, confirming that the topology-aware state transition is critical for long-range spatial propagation. Among older event-driven baselines (JODIE, DyRep, TGAT, TGN, CAWN, TCL), CTDG-SSM consistently leads by 5–20+ AUC-ROC points on LRT datasets, while GraphMixer and CTAN show competitive but inferior performance. Notably, CTDG-SSM achieves these gains with approximately one-tenth the parameters of DyGmamba and DyGFormer, as shown in the parameter-efficiency analysis (Fig. 4).

## Relation to Prior Work

This paper derives a state-space model for continuous-time dynamic graphs (CTDGs) by extending the HiPPO polynomial projection memory mechanism (Gu et al., 2020) with a topology-aware graph filter: the HiPPO coefficients are projected through the inverse of a learnable polynomial of the normalized Laplacian, yielding CTT-HiPPO. This departs from GraphSSM (Li et al., 2024b), which applies SSMs to discrete-time dynamic graphs with a fixed per-interval graph structure and a quadratic Laplacian regularizer, and from DyGmamba (Ding et al., 2024), which uses Mamba layers over 1-hop temporal neighborhoods and thus cannot capture multi-hop spatial structure. The key conceptual move is showing that the time-varying Laplacian in CTDGs introduces an additional graph-aware term in the state ODE (the derivative of p(L_s)), which has no analogue in static-graph or DTDG SSMs, and that the resulting discrete update via ZOH retains a structure analogous to Mamba's selective scan but with two joint state-transition matrices.

## Why It Matters / Open Questions

This is the first SSM framework for CTDGs that simultaneously addresses long-range temporal (LRT) and long-range spatial (LRS) dependencies, filling a gap where prior methods (event-driven models for LRT, sequence-based models for LRS) handled only one axis. The parameter efficiency (~10× fewer parameters than DyGmamba/DyGFormer while matching or exceeding accuracy) and the theoretical guarantees (linear robustness bound under Laplacian perturbation, permutation equivariance) make the approach attractive for deployment on large-scale streaming interaction data. Open questions include how the polynomial filter degree K should scale with graph size, whether the ZOH discretization remains accurate under highly irregular event arrival rates, and whether the subgraph sampling strategy (fixed N_u neighbors) is sufficient for graphs with highly heterogeneous degree distributions.

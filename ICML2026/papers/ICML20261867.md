## Problem

In multi-LoRA LLM agent systems, each agent independently builds and stores its own KV cache for the same long tool-augmented trajectories, incurring substantial memory and compute redundancy despite sharing a pretrained backbone. Existing KV cache sharing methods either require architectural modifications and additional training, focus on positional misalignment from agent-specific prefixes, or rely on selective recomputation of tokens or layers, but none explicitly exploit the multi-LoRA weight decomposition to share caches while preserving role-specific behavior.

## Input / Output

The method consumes text context (accumulated agent trajectories interleaved with tool outputs), per-agent LoRA adapter weights (down-projection A ∈ R^{d_in×r} and up-projection B ∈ R^{r×d_out}), and frozen pretrained backbone weights W_0. It produces a shared KV cache decomposed into a full-dimension base cache (from W_0) and a compact low-rank LR cache (from A, with rank r ≪ d_out), which is expanded to full dimension only at attention time via B. The key cache is fully shared across agents, and the final output is standard attention output / generated tokens, with the LR cache expansion performed in rank-r space to avoid materializing L × d_out tensors.

## Method

The key observation is that for the same context, cross-agent cache discrepancies are dominated by small, decorrelated adapter outputs (cosine similarity ≈ 0.05) while backbone-derived base caches remain highly similar (cosine similarity ≈ 0.97), motivating a decomposition of the value cache into a shared base component X_i W_0 and an adapter-dependent component stored in its inherent low-rank form X_i A_i. BaseShared shares a single base cache across all agents while maintaining per-agent LR caches, reducing KV memory to ≈ 1/N of the non-shared baseline. BaseLRShared further shares the LR cache by leveraging a shared-A multi-LoRA architecture (where all agents use the same down-projection A), eliminating redundant prefill computation and scaling overall complexity to O(L² d_model) comparable to full cache sharing. Flash-LoRA-Attention, a kernel built on FlashAttention, exploits associativity to reorder the computation as O = P V_base + (P V_lr) B, performing the length-L accumulation in rank-r space and applying the up-projection only once per query block, reducing LR expansion overhead by a factor of r/d_out.

## Results

On HotpotQA and ScienceQA, BaseShared preserves accuracy within 0.7% of the Non-Shared baseline (e.g., 38.60% vs 38.88% avg on HotpotQA for LLaMA-3.1-8B-Instruct), while BaseLRShared stays within 1.5% (37.92% vs 38.88%). In terms of efficiency, BaseLRShared achieves throughput of 1790.6 tokens/s at 66.4k sequence length (vs. 1826.5 for FullShared and OOM for Non-Shared) and TTFT of 23.35 s (vs. 23.28 s for FullShared), approaching the fully-shared upper bound while retaining near-baseline accuracy. KV cache memory is reduced by nearly 1/3 compared to the Non-Shared baseline.

## Baselines & Comparisons

Against DroidSpeak (the closest prior KV cache sharing method for cross-model reuse), BaseShared outperforms it by 1.84–1.37 percentage points on HotpotQA average accuracy (38.60 vs 36.77 for LLaMA; 35.85 vs 34.48 for Ministral) and by 1.75–1.96 points on ScienceQA (69.24 vs 67.49; 68.08 vs 66.13). BaseLRShared also beats DroidSpeak on accuracy (37.92 vs 36.77 on HotpotQA for LLaMA) while achieving substantially higher throughput (1790.6 vs 813.1 tokens/s at 66.4k sequence length) and lower TTFT (23.35 s vs 67.80 s), because BaseLRShared avoids the redundant hidden-state recomputation that DroidSpeak still requires for previously seen context. Both methods also surpass FullShared in accuracy by 1.5–3.2 points while matching its throughput and TTFT within ~2%, demonstrating that the base/LR cache decomposition preserves agent-specific behavior that naive full sharing destroys. On end-to-end latency over actual HotpotQA runs, BaseLRShared achieves the lowest E2E latency (11.96 s avg for LLaMA) among all methods, whereas FullShared's lower accuracy causes longer trajectories and higher E2E latency (17.69 s) despite its best TTFT.

## Relation to Prior Work

This paper builds on the LoRA parameterization (Hu et al., 2022) to decompose KV caches into a shared base component (from pretrained weights W₀) and an adapter-dependent component (from low-rank AB), and on FlashAttention (Dao et al., 2022) as the kernel substrate for the proposed Flash-LoRA-Attention. It departs from prior KV cache sharing methods (DroidSpeak, CacheBlend, KVLink, KVFlow, KVComm) that rely on selective recomputation or positional alignment by instead exploiting the structural low-rank decomposition inherent to multi-LoRA, and from shared-A multi-LoRA variants (Tian et al., 2024; Yang et al., 2025c) by extending the shared down-projection to enable sharing of the LR cache itself. The paper positions itself as the first work to explicitly tailor KV cache sharing to the multi-LoRA agent setting, complementing rather than subsuming prior cache-sharing approaches.

## Why It Matters / Open Questions

Multi-LoRA agent systems are becoming the standard deployment pattern for role-specialized LLM agents, and the paper demonstrates that the architectural structure of LoRA naturally yields a clean, near-lossless cache decomposition that outperforms more complex selective-recomputation baselines in both accuracy and efficiency. Practical limitations include the requirement for shared-A training (incompatible with already-deployed independent multi-LoRA weights), evaluation restricted to 8B models and the AutoAct framework, and the assumption of identical agent system prompts that neutralizes prefix-aware methods. Open questions include scalability to larger models and more heterogeneous agent topologies, applicability to other PEFT methods (e.g., adapters, prefix-tuning), and whether the base/adapter similarity gap widens or narrows with increasing agent count and trajectory length.

## Problem

Existing web agent benchmarks evaluate agents on fully specified queries in simulated or cached environments, making it impossible to assess whether agents can resolve ambiguous user requests by inferring preferences from browsing history. No prior benchmark provides realistic, long-span user histories that encode preferences implicitly through behavioral patterns, nor does it require agents to disambiguate queries using that context rather than following explicit instructions.
![Teaser figure](../imgs/ICML20262129/cropped_page0_idx0.webp)

## Input / Output

The benchmark feeds each agent an ambiguous query (one of three levels, where Level 2 masks both the target website and preference constraints) alongside a user's browsing history of ~2,000 timestamped entries spanning one year across 105 real websites and 21 domains. Only 3.56% of history entries contain preference values as exact string matches, forcing agents to infer preferences from contextual cues. The evaluation produces three normalized scores—P_web (website personalization), P_pref (preference personalization), and intent satisfaction—each decomposed into retrieval and utilization sub-scores via structured rubrics, plus a binary success rate requiring all scores to be perfect. A full reasoning trajectory is logged at every step for the LLM judge (GPT-5-mini) to assess.

## Method

PERSONA2WEB introduces a clarify-to-personalize query design where explicit values are progressively masked (Level 0→2), requiring agents to fill gaps from user history rather than following instructions. User histories are generated through a four-stage LLM pipeline (demographic profile → domain preference selection → event seed generation with 10% noise → action decomposition into five typed entries), dispersing related actions across a year to prevent pattern clustering. For evaluation, the paper augments two existing web agent architectures (AgentOccam, Browser-Use) with a planner-retriever-generator personalization module, where the retriever uses Stella V5 1.5B dense retrieval over FAISS-indexed history entries. Two history access schemes—on-demand (reactive, during navigation) and pre-execution (anticipatory, before navigation)—probe different personalization capabilities. The reasoning-aware evaluation framework scores retrieval accuracy and utilization accuracy separately using GPT-5-mini as judge, enabling distinction between personalization failures and navigation failures that task-completion metrics alone cannot capture.

## Results

On PERSONA2WEB Level 2 (most ambiguous) queries, all agents achieve 0% success rate without user history, confirming that ambiguity cannot be resolved without user context. With history access, the best configuration (Browser-Use + GPT-4.1, on-demand) reaches only 13% success rate, with P_web=0.803, P_pref=0.731, and Intent=0.467. Performance degrades sharply with ambiguity: average success drops from 23.8% (Level 0) to 16.3% (Level 1) to 7.8% (Level 2). Proprietary models (o3, GPT-4.1) substantially outperform open-source models, with most open-source backbones remaining below 5% success rate.

## Baselines & Comparisons

As a benchmark paper, PERSONA2WEB does not propose a new method but evaluates existing web agent architectures and backbone LLMs. Browser-Use consistently outperforms AgentOccam on personalization scores (P_web, P_pref) across all five backbones, attributed to its richer full-DOM observation versus AgentOccam's pruned accessibility tree. Among backbones, GPT-4.1 with Browser-Use achieves the highest overall performance (SR=0.13, P_avg=0.767 on-demand), while o3 is competitive (SR=0.13 on-demand, SR=0.10 pre-execution). Proprietary models (o3, GPT-4.1) achieve 6–13% success rates with history access, whereas open-source models (Qwen3-80B, Llama-3.3-70B) remain at or below 5%. History access scheme preference varies by model: GPT-4.1 performs better under on-demand (situational awareness), while Qwen3-80B and Llama-3.3-70B perform better under pre-execution (long-horizon planning). The meta-evaluation confirms the reasoning-aware evaluation framework achieves the highest correlation with human judgments (Pearson 0.85 for website, 0.72 for preference) compared to action-wise (0.77/0.40) and outcome-based (0.80/0.23) methods.

## Relation to Prior Work

This paper departs from two lines of work simultaneously. On the web agent benchmark side, it extends the trajectory from simulated/cached environments (WebArena, Mind2Web) to the real open web (following WebVoyager, WebCanvas), but introduces a fundamentally different evaluation axis: ambiguous queries that require resolving missing information from user history rather than executing fully specified instructions. On the personalization side, it moves beyond dialogue and text-generation settings (LaMP, LongMemEval, Apollonion, PersonalWAB) to ground personalization in multi-step web navigation, where preferences must be inferred from behavioral patterns in browsing history and applied during action planning. The agent architectures (AgentOccam, Browser-Use) are augmented with a planner-retriever-generator personalization module using dense retrieval (Stella V5 1.5B + FAISS), but the core contribution is the benchmark design and evaluation framework rather than the agent method itself.

## Why It Matters / Open Questions

The benchmark reveals a stark gap: even the best configuration (Browser-Use + GPT-4.1) achieves only 13% success on the most ambiguous queries, and 0% without user history, confirming that current web agents cannot perform genuine personalization. The explicit-vs-implicit context experiment (27% vs. 13% success for the same information) highlights that inferring preferences from behavioral patterns is a substantially harder problem than applying stated instructions, pointing to a clear research direction. Open questions include how to improve history retrieval and utilization (the dominant error sources), whether the clarify-to-personalize principle generalizes to multi-turn interactions, and how to handle privacy constraints when deploying personalized agents that require access to real user behavior.

## Problem

Prior work proved that a context's effect on a single vanilla transformer block is equivalent to a rank-1 patch on its MLP weights, but this result critically depends on bias terms that modern LLMs (Gemma, Llama, Falcon, Mixtral) have eliminated. The compatibility of the implicit weight-patch mechanism with gated MLPs (SwiGLU, GeGLU), RMSNorm, pre-normalization, and multi-layer architectures remained formally unaddressed.

## Input / Output

The method consumes the full model parameter set Θ, a single input token x, and a context string C (which may include text or image tokens), and produces per-layer rank-1 patches to the gate/up/down weight matrices plus an element-wise update to the RMSNorm scale vector m. The resulting patched model, run without any explicit context, yields logits that match the original contextualized model to within numerical precision. Updates are token-dependent and must be recomputed at every autoregressive step; the algorithm is self-correcting by feeding each layer's actual output into the next layer's computation to absorb floating-point drift.

## Method

The core result (Theorem 1) shows that for a Gemma-style block, the context effect decomposes into two independent corrections: (1) rank-1 patches ΔW_gate and ΔW_up that align the post-RMSNorm input so the internal MLP activation is unchanged (input controllability), and (2) an element-wise update Δm to the RMSNorm scale vector that absorbs the residual-path difference v_C − v (output controllability). This is extended inductively to L-layer models (Theorem 2) with a layer-by-layer algorithm (Algorithm 1) that records target activations in a full-context forward pass, then sequentially computes each layer's patch. A numerically stable variant replaces the direct element-wise division in Δm with an analytical RMSNorm inversion (solved via Lagrange multipliers) that shifts most of the correction into a rank-1 patch on W_down, reducing sensitivity to bfloat16 precision. The paper unifies all cases under a general framework of input controllability (inner function) and output controllability (outer function), proving Theorem 3 and covering gated MLPs, pre/post-norm, MoE routing, and parallel blocks in a single table of updates.

## Results

The paper proves that for a Gemma-style transformer block, the entire effect of a context can be perfectly replicated by rank-1 patches to the MLP weight matrices (W_gate, W_up) and a patch to the RMSNorm scale vector m (Theorem 1). Experimentally, on Gemma 3 1B/4B with float32, the updated model (no context) achieves near-zero L∞ logit difference and 100% token matching against the original model with context. Under bfloat16, the naive update yields 87.5% token agreement, while the numerically stable variant (using RMSNorm inversion) recovers 100% matching. On Falcon 7B, perfect token matching is achieved even in base bfloat16 without stabilization, and the method extends to image contexts on Gemma 3 4B.

## Baselines & Comparisons

This paper does not compare against external baseline methods; its validation is an internal equivalence test between the original model (with full context) and the patched model (without context). The key comparison is precision-dependent: in float32, both Gemma and Falcon achieve essentially exact logit matching (near-zero L∞ difference and TVD) with 100% token agreement. In bfloat16, the naive element-wise division update on Gemma degrades to 87.5% token agreement due to division by near-zero values in the MLP output, while the numerically stable RMSNorm-inversion update restores 100% matching. Falcon, which lacks a post-RMSNorm scaling vector, is inherently more numerically stable and achieves perfect token matching in bfloat16 without any stabilization. The method also generalizes across modalities, maintaining near-perfect equivalence when the context includes an image (Gemma 3 4B), confirming that the controllability framework is not restricted to purely textual prompts.

## Relation to Prior Work

This paper directly extends Dherin et al. (2025), who proved that context in a single vanilla transformer block is equivalent to a rank-1 patch on MLP weights plus a bias shift. The critical gap this work fills is that Dherin et al.'s proof relied on the presence of a final bias vector (b₂) to absorb the residual connection's contextual shift — a component that modern architectures like Gemma, Llama, and Falcon have eliminated. The authors show the patch instead lands on the RMSNorm trainable scale vector m, and they introduce a unified controllability framework (input/output controllability) that subsumes prior analyses of gated MLPs, pre/post-norm, MoE, and parallel blocks under a single theorem. The work is complementary to Mazzawi et al. (2025) on aggregating transient patches into reusable 'thought patches,' and contrasts with Innocenti and Achour (2025), whose generalization was restricted to bias-containing residual blocks.

## Why It Matters / Open Questions

The controllability framework gives a clean, architecture-agnostic criterion for when context can be exactly compiled into weights, which is valuable for mechanistic interpretability of ICL and for reasoning about architectural design choices (e.g., why a trainable scale vector is necessary for exact equivalence). However, the updates are strictly token-dependent and must be recomputed at every generation step, so the result is descriptive rather than a practical inference acceleration. Open questions include whether these per-token patches can be aggregated into a stable, reusable representation (the 'thought patch' direction), whether the model's training dynamics actually converge toward this implicit gradient-descent interpretation, and how the framework extends to architectures with fixed post-normalization (where the authors prove exact equivalence is impossible).

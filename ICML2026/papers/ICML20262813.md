## Problem

In the Fine-Tuning-as-a-Service (FTaaS) paradigm, user-submitted training data can be poisoned with stealthy backdoor triggers, yet existing defenses either require supervised labels, clean reference data, or rely on spatial attention entropy that fails against globally distributed and non-visual triggers. No prior method provides a unified, unsupervised detection mechanism that generalizes across diverse trigger morphologies (patches, global blending, frequency-domain, textual) and modalities in MLLMs.
![Teaser figure](../imgs/ICML20262813/cropped_page0_idx1.webp)

## Input / Output

The method consumes a LoRA-fine-tuned MLLM and a downstream training dataset of (image, text query, answer) triplets. During inference, it harvests the cross-modal attention weights from the first generated token to all N preceding tokens across every decoder layer and head, then partitions each attention vector into three functional segments (system instructions, vision tokens, user text) based on the model's chat template. The output is a binary poisoned/clean label per training sample, from which a purified dataset is constructed for retraining the model.

## Method

TCAP is built on the discovery of attention allocation divergence: backdoor triggers cause a small number of attention heads in deeper layers to either suppress system instructions while amplifying vision (Anomaly 1) or amplify system instructions while suppressing vision (Anomaly 2), regardless of trigger type. The pipeline operates in three stages: (1) extract tri-component attention allocation vectors by summing attention mass over system, vision, and text token sets for each head and layer; (2) fit adaptive GMMs on the normalized system-instruction component across all samples per head, compute a Separation Score (reciprocal of overlapping area between minority and background Gaussian groups) to rank and select the top-H_sens trigger-responsive heads in the last L_sens layers; (3) aggregate binary votes from selected heads using the Dawid-Skene EM model, which estimates each head's confusion matrix and a latent clean/poisoned label, flagging samples with posterior probability > 0.5 as poisoned. The entire procedure is unsupervised, requiring no clean reference data or external supervision.

## Results

Under Blend attacks across five datasets and three MLLMs (InternVL2.5, LLaVA-NeXT, Qwen3-VL), TCAP reduces Attack Success Rate (ASR) to near-zero (0.00–6.17%) while preserving Clean Performance (CP) within 1–4 points of the unpoisoned baseline. On detection metrics (ScienceQA), TCAP achieves F1 scores of 85–100% across all five attack types (BadNet, Blend, SIG, WaNet, FTrojan) for all three models, whereas BYE drops to 0–25% F1. Ablation confirms each module (head selection, layer filter, adaptive GMM components, EM voting) contributes substantially, with removal of head selection causing F1 to collapse from ~98% to 15–43%.

## Baselines & Comparisons

Against BYE (Rong et al., 2025), TCAP achieves a decisive win on both detection and end-to-end defense. On Blend detection (ScienceQA), TCAP reaches 98.34/98.85/95.04% F1 for InternVL2.5/LLaVA-NeXT/Qwen3-VL, while BYE collapses to 0.00/2.82/15.88% F1 respectively; BYE's entropy-based signal fails because globally diffused triggers do not produce the low-entropy attention collapse it assumes. On end-to-end ASR, BYE retains 91–100% ASR on several settings (e.g., 100% on DocVQA with InternVL2.5, 100% on ScienceQA/PhD with LLaVA-NeXT where it also destroys CP to 0%), whereas TCAP suppresses ASR to 0.00–6.17% while preserving CP. Against SampDetox (Yang et al., 2024), TCAP wins on both CP and ASR: SampDetox's aggressive noise injection degrades CP by 10–20 points (e.g., 75.31 vs. 96.93 on ScienceQA/InternVL2.5) while still leaving ASR at 67–85%, whereas TCAP maintains CP within 1–4 points of the clean baseline and drives ASR below 6%. Random Drop, the trivial baseline, barely reduces ASR (typically <5 points) and slightly degrades CP, confirming that indiscriminate sample removal is insufficient.

## Relation to Prior Work

This paper extends the attention-based backdoor detection paradigm initiated by SentiNet and formalized for MLLMs by BYE (Rong et al., 2025), which detects poisoned samples via Shannon entropy of visual attention (attention collapse). TCAP departs from this spatial-concentration hypothesis by reframing the diagnostic signal as a functional allocation problem: rather than asking where attention concentrates spatially, it asks how attention mass is distributed across three immutable functional components (system instructions, vision, user text). The statistical machinery (GMM for head identification, Dawid-Skene EM for vote aggregation) is repurposed from classical mixture modeling and multi-annotator learning, but the key conceptual shift is from a single-modality, patch-specific entropy signal to a modality-agnostic, morphology-independent allocation divergence fingerprint.

## Why It Matters / Open Questions

As FTaaS becomes the dominant deployment paradigm for MLLMs, an unsupervised, modality-agnostic defense that requires no clean reference data or external models is practically critical for securing fine-tuning pipelines. The paper's demonstration that BYE catastrophically fails on modern MLLMs (0% clean performance on LLaVA-NeXT) highlights that prior attention-entropy defenses are not merely suboptimal but actively harmful, motivating the shift to allocation-based signals. Open questions include whether adaptive attackers could learn to suppress the allocation divergence signal, whether the method scales to 70B+ models with hundreds of layers, and whether the 10% poisoning rate assumption holds in realistic adversarial settings where attackers may use lower rates or adaptive trigger strengths.

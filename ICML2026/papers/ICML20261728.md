## Problem

Existing financial benchmarks (FinQA, FinEval, FinSearchComp) evaluate static document QA or single-shot retrieval, failing to capture the multi-stage, tool-augmented, end-to-end workflows that professional analysts actually perform. Meanwhile, ReAct-style sequential agents suffer from temporal misalignment, data fabrication, and error accumulation over long-horizon financial reasoning, making them unreliable for high-stakes analysis.
![Teaser figure](../imgs/ICML20261728/cropped_page2_idx0.webp)

## Input / Output

The agent receives a natural language financial query spanning three difficulty levels (data retrieval, data analysis, end-to-end investigation) across four domains (equities, macro, crypto, multi-asset). It produces a final numerical or textual answer, and for L3 tasks a structured investment report. Evaluation is multi-dimensional: numerical precision with 1% relative-error tolerance, tool-category alignment via Jaccard similarity against expert trajectories, and L3-specific soundness scored by two LLM judges plus key-information-point coverage, combined through a complexity-adaptive normalization that rescales weights depending on task level.

## Method

ProFinAgent integrates three tightly coupled modules. First, a Professional Financial Tooling Layer exposes 53 domain-specific tools across 13 categories with JSON-schema contracts, and a two-stage hierarchical retrieval (type filtration followed by hybrid rule-based + cosine-similarity ranking with a 0.7 threshold and dynamic top-K) prunes the action space before planning. Second, a DAG-Guided Tool Planner uses an LLM to synthesize a directed acyclic graph over tool invocations, applies layered topological sort to identify mutually independent execution strata, and dispatches each stratum in parallel with dependency-locking; a PARDISTILL operator compresses overly long tool outputs via segment-level semantic gating to control context length. Third, an Evolutionary Case-Based Memory module archives success and failure trajectories via a SELFREFLECT operator, then retrieves the single most relevant historical case (KNN with cosine ≥ 0.7) to inject into the planning prompt, providing positive templates and negative constraints without any parameter updates. The DAG structure is the key architectural differentiator: it enforces global data-lineage constraints that eliminate the sequential misalignment and hallucination inherent in ReAct, while enabling parallel execution that reduces inference latency by 47.1%.

## Results

On ProFinR, ProFinAgent with GPT-5.2 achieves 79.94% average accuracy (L1: 78.36%, L2: 78.53%, L3: 82.94%) and a total score of 79.54%, representing a 49.81% improvement over GPT-5.2's native zero-shot performance (29.73% total score). With Claude-Sonnet 4.6, ProFinAgent reaches 83.20% average accuracy and 83.33% total score (+41.85% over native). The DAG-based parallel execution also reduces inference latency by 47.1% for DeepSeek-R1 (from 42,580s to 22,547s). On the general tool-orchestration benchmarks RestBench-TMDB and RestBench-Spotify, ProFinAgent with GPT-4o achieves 81.25% and 75.44% average scores respectively, outperforming all tree-search baselines.

## Baselines & Comparisons

ProFinAgent consistently outperforms all seven baselines across both ProFinR and RestBench. On RestBench-TMDB with GPT-4o, ProFinAgent (81.25% avg) surpasses ToolTree (74.50%), LATS (71.35%), DFSDT (67.82%), ReAct (64.30%), and CoT (55.42%); the gap widens on RestBench-Spotify where ProFinAgent (75.44%) leads ToolTree (71.36%) by 4.08 points. On ProFinR (Table 8), ProFinAgent with GPT-5.2 achieves 78.36%/78.53%/82.94% on L1/L2/L3, beating Tree-of-Thoughts (66.35%/47.64%/66.66%) and ReAct (69.23%/38.74%/46.51%) by 12–36 points per level. The domain-specific Fin-R1 model performs worst overall (1.46% avg accuracy, 1.70% total score), confirming that financial fine-tuning alone cannot substitute for structured tool execution. The largest single-model gain is GPT-5.2's +49.81% total-score improvement, while even the smallest model (Qwen3-4B) gains +27.84%, indicating the framework's benefits are model-agnostic.

## Relation to Prior Work

This paper extends the financial agent literature (ReAct-based systems like QuantAgent, FINCON, and Fin-R1) by replacing strictly sequential execution with a DAG-guided parallel planner and adding a Case-Based Memory module for evolutionary refinement. It also departs from prior financial benchmarks (FinQA, FinEval, FinSearchComp, FinAgentBench), which are confined to static document QA or single-hop retrieval, by introducing L3 end-to-end investigation tasks that require multi-step tool orchestration and trajectory-level evaluation. The hierarchical tool retrieval mechanism builds on the coarse-to-fine API selection idea from ToolLLM, while the PARDISTILL operator and SELFREFLECT loop are novel adaptations for the financial domain.

## Why It Matters / Open Questions

ProFinR is the first benchmark to evaluate financial agents on end-to-end investigation with 53 domain tools and trajectory-oriented scoring, filling a clear gap between static QA benchmarks and real analyst workflows. The 'Generative Fluency' finding—that frontier models produce coherent L3 reports while failing basic L1 retrieval—highlights a critical reliability risk for deploying LLMs in high-stakes finance. Open questions include whether the DAG+CBM architecture scales to multi-agent market simulation, whether the 53-tool universe is sufficient for emerging asset classes, and whether the 1% numerical tolerance in S_val is appropriate across all financial metrics.

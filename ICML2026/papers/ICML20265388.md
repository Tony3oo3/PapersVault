## Problem

LLMs exhibit unpredictable performance variation depending on how a task is prompted, yet prior work on task representations (e.g., function vectors) identified mechanisms that differ across prompting styles rather than shared ones. This paper asks whether there exist internal components that are common across instruction-based and example-based prompts, and whether the degree to which these shared components are activated can mechanistically explain the observed behavioral variability.
![Teaser figure](../imgs/ICML20265388/cropped_page0_idx0.webp)

## Input / Output

The analysis takes two prompt formats for the same underlying task—natural-language instruction templates (e.g., 'The capital city of Japan is ___') and few-shot example-based templates (e.g., 'Korea: Seoul; Japan: ___')—and examines the internal attention head activations at each layer. Rather than evaluating only final-answer accuracy, the method decodes individual attention head outputs into vocabulary space via the Logit Lens to identify which heads encode task descriptions versus which retrieve factual answers. Experiments span 13 autoregressive transformer models across Llama, Gemma, and Qwen families, 17 simple attribute-retrieval tasks, 3 compositional tasks, and a free-form code generation task.

## Method

The paper identifies 'lexical task heads'—attention heads whose Logit Lens-decoded outputs contain words that literally describe the task (e.g., 'cities' for country-capital, 'opposite' for antonym)—using a criterion that at least 1 of the top 10 decoded tokens matches a predefined task-descriptive vocabulary. They show these heads are shared across prompting styles (73% average overlap) and produce functionally equivalent task representations, demonstrated by activation patching experiments where patching lexical task head activations from one prompt style into a zero-shot prompt recovers 10–90% of task performance. For task execution, they identify 'retrieval heads' that extract the specific answer and show that lexical task heads act as a directional filter modulating which attributes retrieval heads extract. Behavioral variability is explained by differential activation strength: correct prompts activate more lexical task heads with higher L2-norm outputs, while failures arise from insufficient activation or from ambiguous prompts triggering competing task circuits that dilute the target task signal.

## Results

Across 17 tasks and two prompting styles (instruction-based and example-based), an average of 73% of lexical task heads are shared between styles, indicating a common internal task representation. Causal activation-patching experiments show that lexical task heads account for 10%–90% of task performance across prompts, with 12%–50% recovery on two-hop compositional tasks. For code generation, moderate scaling of Python lexical task heads switches the model from JavaScript to Python output 90% of the time. Correct prompts activate more lexical task heads with higher L2-norm outputs than incorrect prompts, and scaling up these activations causally repairs a portion of failed prompts.

## Baselines & Comparisons

This is a mechanistic interpretability paper without a direct method-vs-baseline benchmark comparison. The key conceptual contrast is with prior task-representation work: function vectors (Todd et al., 2024; Hendel et al., 2023) are extracted from attention heads specific to in-context learning, and Davidson et al. (2025) showed that instruction-based prompts use a largely distinct set of heads for task representation. In contrast, the lexical task heads identified here are shared across both prompting styles (73% overlap on average) and produce human-interpretable task descriptions in vocabulary space, unlike the non-lexical function vectors. The paper also builds on retrieval heads from Geva et al. (2023) for factual recall, extending the analysis to show how lexical task heads modulate retrieval heads as a directional filter. No quantitative head-to-head comparison against function-vector-based methods is provided; the distinction is qualitative (shared vs. style-specific, interpretable vs. abstract).

## Relation to Prior Work

This paper extends the task-representation framework established by Todd et al. (2024) on function vectors and Geva et al. (2023) on retrieval heads, but identifies a distinct, previously uncharacterized class of attention heads—lexical task heads—whose outputs decode to human-readable task descriptions in vocabulary space via the Logit Lens. It directly departs from Davidson et al. (2025), who found that instruction-based and example-based prompts recruit largely distinct attention heads for task representation, by showing that a shared subset of heads (73% overlap on average) produces functionally equivalent task signals across both prompting styles. The two-step architecture of task representation modulating retrieval execution parallels the 'contextualize-then-aggregate' circuits of Bakalova et al. (2025) and the task-detection/task-execution decomposition of Kharlapenko et al. (2025), but grounds both stages in interpretable, vocabulary-space-readable components.

## Why It Matters / Open Questions

This work provides the first mechanistic account of prompt sensitivity that is shared across prompting styles, offering a concrete explanation for why semantically equivalent prompts yield different accuracy: differential activation strength of the same lexical task heads, and in some cases, competing task circuits triggered by ambiguous examples. The finding that vocabulary space serves as a readable 'universal language' for task representations has implications for interpretability methodology more broadly. However, the authors acknowledge that lexical task heads account for only 10–90% of task performance depending on the task, that the identification criteria are heuristic, and that the study is limited to tasks with simple lexical descriptions—leaving open whether the mechanism generalizes to abstract or non-lexically-decomposable tasks, and how it interacts with the function-vector and other non-lexical task representations that the authors explicitly do not study.

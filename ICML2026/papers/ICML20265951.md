## Problem

Existing multimodal large language models for point clouds are restricted to static, single-frame inputs and lack the temporal modeling and reasoning capabilities needed to understand dynamic point cloud sequences. This limitation is compounded by the absence of large-scale cross-modal datasets pairing 4D point cloud sequences with language supervision, and by the inherent difficulty of capturing long-range spatio-temporal dependencies in irregular, evolving point distributions.
![Teaser figure](../imgs/ICML20265951/cropped_page0_idx0.webp)

## Input / Output

The model takes a topology-consistent 4D point cloud sequence of T=16 frames, each containing N=8192 points with 6-dimensional attributes (x, y, z, r, g, b), where point identity is preserved across frames via stored barycentric coordinates. It also accepts a free-form text question. Outputs include open-ended 4D object captions (brief or detailed) and structured answers to QA pairs spanning five categories: counting, temporal relationship, action recognition, spatial relationship, and appearance. The accompanying dataset 4DPC²hat-200K provides 44K dynamic sequences, 700K frames, and 200K QA pairs.

## Method

The architecture encodes each frame with a shared Point-BERT encoder that produces G spatial group tokens plus one global token per frame, preserving fine-grained localized motion cues that a single global token would discard. These per-frame token sets are concatenated into a unified sequence and processed by a bidirectional Mamba module (K blocks) that captures long-range temporal dependencies in both forward and backward directions at linear complexity, with a gating branch merging the two directional streams. The temporally enhanced features are projected into LLaMA-7B's embedding space for autoregressive captioning and QA generation. Training follows a three-stage curriculum: (1) temporal-language alignment with frozen encoder and LLM, (2) comprehensive instruction tuning on 145K QA pairs and 44K detailed captions, and (3) failure-aware bootstrapping, where the model's worst-performing predictions (bottom 40% by semantic similarity) are diagnosed by a Qwen-3 teacher into 12 error taxonomies, targeted corrective QA pairs are synthesized, and the Mamba module and projector are fine-tuned on these samples iteratively (two rounds) to progressively strengthen weak reasoning abilities.

## Results

On the 4D object QA task (4DPC²hat-200K test set), 4DPC²hat achieves a GPT-4 overall score of 78.01, surpassing the strongest static 3D baseline MiniGPT-3D (59.08) by 18.93 points, with consistent gains across all five question categories (Counting 77.03, Temporal 76.52, Action 76.98, Spatial 76.46, Appearance 76.11). On 4D object captioning, the model scores 73.27 (GPT-4), 79.08 (S-BERT), and 82.03 (SimCSE), outperforming the best baseline by 18.57, 20.48, and 23.45 points respectively. On the 4D-Bench benchmark against 2D Video MLLMs, 4DPC²hat achieves 74.30% on Action QA and 66.14% on Object Counting, exceeding the best 2D baselines (GPT-4o: 63.55% Action; LLaVA-Video 72B: 54.33% Counting) by 10.75 and 11.81 points.

## Baselines & Comparisons

4DPC²hat outperforms all nine compared baselines across every metric and question category. Among static 3D MLLMs, MiniGPT-3D is the strongest baseline (GPT-4: 59.08 on QA, 54.70 on captioning), yet 4DPC²hat exceeds it by ~19 points on both tasks; PointLLM and ShapeLLM trail further behind (52–56 GPT-4 on QA). Against 2D Video MLLMs on 4D-Bench, the gap is equally pronounced: GPT-4o (the strongest 2D baseline) scores 63.55% on Action QA and 44.09% on Counting, while 4DPC²hat reaches 74.30% and 66.14% respectively. LLaVA-Video 72B leads the open-source 2D group on Counting (54.33%) but still falls 11.81 points short. Gemini 1.5 Pro and Qwen2-VL 72B occupy the mid-range (58–59% Action, 45–46% Counting), confirming that 2D projection-based approaches fundamentally struggle with fine-grained 4D geometric reasoning. The consistent ~15–20 point margin over all baselines underscores that explicit spatio-temporal modeling over native point cloud sequences is essential for reliable 4D understanding.

## Relation to Prior Work

This paper sits at the intersection of two established lines of work: static 3D point cloud MLLMs (PointLLM, ShapeLLM, MiniGPT-3D) that perform language-based reasoning over single-frame point clouds, and 4D dynamic point cloud methods (PointRNN, PSTNet, Point4D Transformer) that model temporal geometry but target narrow classification tasks without language interfaces. The key architectural departure is replacing the standard Transformer temporal encoder with a bidirectional Mamba (state-space model) module for inter-frame modeling, motivated by linear-complexity long-range dependency capture. The failure-aware bootstrapping training strategy draws on the broader curriculum/iterative-refinement literature but applies it specifically to diagnose and correct spatio-temporal reasoning failures in a 4D point cloud MLLM.

## Why It Matters / Open Questions

The 4DPC²hat-200K dataset (44K dynamic sequences, 200K QA pairs) fills a critical gap: no prior dataset jointly supports 4D captioning and multi-type QA over dynamic point clouds, making this a foundational resource for the community. The consistent outperformance of 2D video MLLMs (including GPT-4o) on 4D-Bench suggests that native 4D geometric representations carry information that 2D projections fundamentally lose, which has implications for embodied AI and robotics perception. However, the work is limited to synthetic animated objects from Objaverse; the authors themselves note that adapting to real-world LiDAR sequences and dynamic scenes remains open, and the comparison protocol for 3D baselines (frame-wise processing + Qwen3 aggregation) may understate their true potential with better temporal adaptation.

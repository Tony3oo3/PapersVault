## Problem

Multi-turn dialogue agents face a fundamental tension: full-history prompting incurs cubic attention cost growth, while static compression methods (truncation, summarization, one-shot latent compressors) degrade under consecutive turns because they lack mechanisms for cross-turn memory sharing and revision. The paper empirically demonstrates that existing latent compressors like ICAE collapse catastrophically under multi-turn rollout (PPL exploding by ~1900%), exposing the core limitation of treating compression as a fixed, one-shot operation rather than a revisable, incremental process.

## Input / Output

At each dialogue turn, the method consumes the current user query (text) and a small retrieved subset of latent memory states (each a 128×d compressed thread vector) as conditioning input to a frozen Llama-2-Chat-7B generator. It produces a generated response and a new compressed thread state that is written back to the memory bank via a deterministic, gradient-free update rule. The memory bank stores a growing set of per-thread latent states, but generation conditions on only 2–3 retrieved slots in practice, keeping the effective input size constant regardless of dialogue length.

## Method

C-DIC models a conversation as interleaved contextual threads and maintains a compact memory of revisable per-thread compression states. At each turn, a lightweight retrieve → compress → write-back loop executes: (i) existing memory slots are scored against the current query via cosine similarity with exponential recency decay, and a relevant subset is retrieved; (ii) a trainable compressor (initialized from ICAE, adapted via LoRA) compresses the current turn jointly with the retrieved states into a new thread state; (iii) a gradient-free write-back rule either inserts a new state (topic shift, when peak similarity < τ) or revises the best-matching state (thread continuation). Training uses retrieval-aware truncated BPTT (ra-TBPTT), which backpropagates only one hop along the arg-max memory-update path and detaches off-topic slots, providing sparse credit assignment without full-history backpropagation. Only the LoRA-adapted compressor and learnable compression tokens are optimized; the response generator remains frozen throughout.

## Results

On MSC, C-DIC achieves PPL 8.431, BLEU 0.023, ROUGE-L 0.160, ROUGE-1 0.205, and ROUGE-2 0.037, outperforming all baselines including ICAE(one-shot) (PPL 27.656) and AutoCompressor (PPL 9.285). On REALTALK (zero-shot), C-DIC reaches PPL 9.789, BLEU 0.035, ROUGE-L 0.134, ROUGE-1 0.176, and ROUGE-2 0.030, again leading all methods. On the MSC-QA diagnostic, C-DIC achieves 10.4% answer accuracy versus 6.2% for InfLLM and 4.2% for full prompting. C-DIC also maintains stable end-to-end latency of ~3.3 s across 10–428 turns, while full prompting and ICAE variants hit OOM beyond 20–40 turns.

## Baselines & Comparisons

C-DIC outperforms all five compared baselines on both MSC and REALTALK across PPL, BLEU, and ROUGE. Against ICAE(one-shot) (Ge et al., 2024), the closest latent-compression baseline, C-DIC reduces PPL from 27.656 to 8.431 on MSC (−69%) and from 21.390 to 9.789 on REALTALK (−54%), while improving BLEU from 0.017 to 0.023 and ROUGE-2 from 0.027 to 0.037; the naive incremental ICAE variant catastrophically fails (PPL ≈ 514 on MSC) due to latent drift from repeated one-shot compression. Against AutoCompressor (Chevalier et al., 2023), C-DIC achieves comparable PPL on MSC (8.431 vs. 9.285) but substantially higher BLEU (0.023 vs. 0.012) and ROUGE-2 (0.037 vs. 0.019), and on REALTALK C-DIC dominates on every metric (PPL 9.789 vs. 12.625, BLEU 0.035 vs. 0.019, R-L 0.134 vs. 0.055). Against InfLLM (Xiao et al., 2024), C-DIC improves PPL from 27.329 to 8.431 on MSC and from 29.995 to 9.789 on REALTALK, with large gains in BLEU and ROUGE. Against LLMLingua (Jiang et al., 2023), C-DIC reduces PPL from 36.211 to 8.431 on MSC and from 31.067 to 9.789 on REALTALK, with BLEU improving from 0.012 to 0.023. Against recursive Summarization (Wang et al., 2025), C-DIC lowers PPL from 41.849 to 8.431 on MSC and from 26.087 to 9.789 on REALTALK, while matching or exceeding ROUGE-1/2 scores. On the MSC-QA long-range diagnostic, C-DIC achieves 10.4% accuracy versus 6.2% (InfLLM), 4.2% (full prompting), and 0.4% (ICAE one-shot), confirming superior long-range context retrieval.

## Relation to Prior Work

This paper extends ICAE's (Ge et al., 2024) one-shot latent autoencoder from static document compression to an incremental, retrieval-conditioned dialogue memory, introducing a retrieve → revise → write-back loop that treats compressed states as persistent, revisable thread-level memory rather than fixed summaries. It departs from both textual context management (truncation, recursive summarization, RAG) and prior latent compressors (AutoCompressor, ICAE) by coupling multi-slot semantic retrieval with gradient-free memory updates and a novel retrieval-aware truncated BPTT training scheme that assigns credit only along the actual memory-update path. The work also connects to memory-augmented long-context models (Rae et al., 2019; Bulatov et al., 2022) but elevates memory from token/segment-level to dialogue-thread-level with explicit revision semantics.

## Why It Matters / Open Questions

The paper provides a practical, scalable path for long-horizon conversational agents: C-DIC maintains stable ~3–3.5 s latency and low perplexity over 428 turns where full prompting and static latent baselines all hit OOM, addressing a core deployment bottleneck for LLM-based assistants. The demonstrated catastrophic failure of naively applying a one-shot compressor incrementally (PPL ≈ 513) is an important negative result that clarifies why architectural and training changes are necessary, not just engineering tweaks. Open questions include whether the approach generalizes beyond a 7B backbone and the ICAE initialization, how unbounded memory-slot growth behaves in truly open-ended deployments, and whether persistent latent memories can be made privacy-safe without sacrificing retrieval fidelity.

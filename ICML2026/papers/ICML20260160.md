## Problem

Influence functions require an expensive inverse-curvature (IHVP) solve per subset query, causing total cost to scale linearly with the number of queries. This makes high-query workloads—large-K cross-validation, repeated resampling, interactive what-if analysis over hundreds or thousands of candidate subsets—computationally prohibitive precisely in the regimes where influence-based diagnostics are most useful.

## Input / Output

The method takes a fixed trained model snapshot θ₀, per-example gradients at θ₀, a subset query S (a set of training indices), and an evaluation set V for loss prediction. Offline, it additionally requires a JL sketch dimension d_Π and cluster budget C as hyperparameters. Online, for a fixed evaluation set, each query reduces to counting cluster memberships and an O(|S|+C) scalar recombination; for dynamic evaluation sets, an additional O(Cp) dot-product cost is incurred per target. The output is an approximate parameter shift Δθ_S, a scalar loss-delta estimate Δℓ(S;V), and influence scores suitable for ranking subsets.

## Method

CiF amortizes subset influence by decoupling curvature inversion from the query count. Offline, it (i) projects per-example gradients into a low-dimensional space via a Johnson-Lindenstrauss sketch, (ii) clusters the sketched gradients with k-means into C clusters, and (iii) solves C damped Generalised Gauss-Newton linear systems (one per cluster-mean gradient) using conjugate gradients, caching the resulting IHVP response vectors. Online, any new subset query is answered by counting how many of its members fall in each cluster and linearly recombining the cached vectors, yielding per-query cost O(Cp) for full parameter updates or O(|S|+C) for loss prediction with precomputed projection scalars. A key theoretical contribution is an error bound that decomposes approximation error into a clustering scatter term (controlled by within-cluster variance and sketch quality) and a solver residual term (controlled by CG tolerance), making the accuracy-compute trade-off explicit through the cache budget C and solver tolerance ρ_tol.

## Results

On CIFAR-10, CiF with C=10 clusters achieves 15.3×, 11.7×, and 13.9× speedups over per-query IF on LeNet, AlexNet, and ResNet-18 respectively (e.g., 2.1h vs 32.1h for LeNet), while maintaining Spearman rank correlation of 0.93–0.99 with IF across K∈{50,100} fold workloads. On ImageNet-1k (DeiT-Tiny, K=5000), CiF with C=512 achieves a 9.3× speedup (67h vs ~625h) with rank correlation ρ=0.19, and C=128 reaches 32.9× speedup at ρ=0.07. When composed with a LoGra projected backend on CIFAR-10/ResNet-18, CiF+LoGra reduces mean online query time from 8.68 ms to 3.45 ms (2.51×) while preserving Pearson 0.879 ± 0.063 agreement with per-query IF.

## Baselines & Comparisons

Against per-query IF (Koh & Liang, 2017), CiF matches fold-level influence rankings with Spearman correlations of 0.93–0.99 on LeNet and AlexNet (C=10) and 0.94–0.95 on ResNet-18 (C=50), while reducing total runtime by 3–15×; the gap widens for ResNet-18 at C=10 (Spearman drops to ~0.75), indicating that more complex models require larger cache budgets. Against PBRF (Bae et al., 2022), the correlation matrix on MNIST-10% (Figure 2) shows CiF tracks IF more closely than PBRF does, with PBRF being the nearest non-IF comparator to both IF and CiF. Against LoGra (Choe et al., 2026), CiF+LoGra achieves a 2.51× reduction in mean online query latency (3.45 ms vs 8.68 ms) over 4,950 queries on CIFAR-10/ResNet-18, demonstrating that the clustering-and-recombine layer composes with projected IHVP backends to further accelerate high-query workloads. On ImageNet-1k, CiF's rank correlation with IF is low (ρ=0.07–0.19) due to the extreme heterogeneity of 1.28M examples compressed into only 128–512 clusters, but the 9–33× speedup remains substantial for screening-level analysis.

## Relation to Prior Work

CiF extends the standard influence function framework of Koh & Liang (2017) by introducing an amortization layer that decouples curvature inversion cost from query count. Unlike FastIF/TracIn, which relax the influence objective itself (first-order trajectories or kernel regression), and unlike TRAK, which reframes attribution as a linearized proxy, CiF retains the exact damped-GGN inverse-curvature formulation and instead compresses the input space via Johnson-Lindenstrauss sketching and k-means clustering of gradients. The key conceptual departure from coreset/gradient-matching methods (Mirzasoleiman et al., 2020; Killamsetty et al., 2021) is that CiF uses clustering to build a reusable cache of curvature responses rather than to select a training subset, and it provides an explicit error decomposition separating geometric (clustering scatter) from numerical (solver residual) approximation.

## Why It Matters / Open Questions

CiF makes high-query influence workloads (large-K cross-validation, interactive what-if analysis, repeated resampling) computationally feasible by reducing per-query cost from an O(N_steps) IHVP solve to O(C) scalar recombination, with demonstrated 15× speedups on CIFAR-10 while preserving 0.93+ rank correlation with per-query IF. However, the ImageNet stress test reveals a significant scaling limitation: at C=128–512 for 1.28M examples, rank correlation drops to 0.07–0.19, indicating that the O(Cp) cache and within-cluster scatter become prohibitive for very large, heterogeneous datasets. The backdoor detection results add a nuanced caveat: CiF's aggregation helps when poisoning induces a shared gradient direction but actively degrades detection when the signal is dispersed. Open questions include layer-wise or low-rank caches, quantized responses, and adaptive/hierarchical clustering to push the feasible cache budget toward foundation-model scale.

## Problem

Existing Text-to-SQL methods lack native primitives to express continuous morphological intents (e.g., 'rapid rise followed by a slow fall'), while time series question-answering models are bounded by finite context windows and cannot ingest the millions of points stored in real-world TSDBs. No prior work formally defines or systematically evaluates the task of grounding abstract natural language descriptions into executable operations over massive, unsegmented temporal histories.

## Input / Output

The system takes a natural language query and a serialized textual schema of the TSDB (measurement names, tags, fields) as input, operating over raw histories averaging ~12,000 points per query (up to ~30k for Level 3 tasks). It produces a hybrid execution plan of SQL and Python code, whose final output varies by task: scalars (relative accuracy), timestamps (hit rate), time intervals (IoU), unordered date sets (F1), or structured narrative reports scored by a weighted composite of trend-type alignment, interval IoU, adjective match rate, and outlier detection.

## Method

Sonar-TS is a training-free neuro-symbolic framework implementing a 'Search-Then-Verify' pipeline. Offline, it constructs multi-scale Feature Tables (yearly/monthly/daily) storing statistical primitives and SAX symbolic tokens that render continuous shapes queryable via standard SQL regex. Online, an LLM (DeepSeek-V3) first acts as a Task Planner decomposing the query into sub-steps, then as a Code Generator producing SQL to 'ping' candidate windows from the feature tables and Python programs using a library of time-series operators (DTW, PELT, Theil-Sen, ACF) to 'lock on' and verify candidates against raw data slices. A Prompt Cold Start mechanism injects up to 20 offline-distilled Experiences as domain heuristics, and a self-correction loop (≤3 retries) handles runtime failures. The key design property is decoupling from raw series length N: the LLM prompt depends only on schema and bounded experiences, and Python verification depends only on the small candidate set K, avoiding the O(N) or O(N²) scans that limit end-to-end time series models.

## Results

On the full NLQTSBench (1,153 queries over long histories), Sonar-TS achieves an average score of 0.6144, outperforming the best Text-to-SQL baseline MAC-SQL (0.1611) by 3.8×. Its strongest results are on Subsequence Matching (0.9439), Periodicity Detection (0.8625), Atomic Retrieval (0.8609), and Sliding Window (0.7827), while morphology-heavy tasks remain harder (Composite Trend 0.2988, Shape Identification 0.3336). On NLQTSBench-Lite (500 queries, 512-point windows), Sonar-TS scores 0.3016 average, beating the best time-series model ChatTS-14B (0.1818) by 66% relative improvement, with the largest gap on Causal Anomaly (0.3615 vs. 0.1229).

## Baselines & Comparisons

Against Text-to-SQL baselines on the full NLQTSBench, Sonar-TS dominates across all nine task types. MAC-SQL (0.1611 avg) is the strongest SQL baseline, achieving reasonable Atomic Retrieval (0.4735) and Periodicity Detection (0.3928), but collapses on morphology-dependent tasks (Composite Trend 0.0020, Subsequence Matching 0.0598), confirming that SQL cannot express continuous shape intents. Fine-tuned models Xiyan-SQL-32B (0.0582) and Omni-SQL-32B (0.0921) perform even worse, with near-zero scores on most pattern tasks. Against time-series models on NLQTSBench-Lite, Sonar-TS (0.3016) outperforms ChatTS-14B (0.1818), ITFormer-7B (0.1529), and Time-R1 (0.1374) on all three evaluated tasks. The largest relative gain is on Causal Anomaly (0.3615 vs. 0.1229 for ChatTS), where cross-channel relational reasoning requires global context beyond what short-window models can process. Notably, even Sonar-TS's weakest morphology scores (SI 0.3336, CT 0.2988) exceed the best SQL baseline by 6–150×, underscoring that no single existing paradigm can handle NLQ4TSDB alone.

## Relation to Prior Work

Sonar-TS carves out a new neuro-symbolic pipeline at the intersection of Text-to-SQL, Time Series Question Answering (TSQA), and Time Series Similarity Search, explicitly arguing that no single prior paradigm covers all three required capabilities (morphological primitives, massive scalability, and natural language grounding). It repurposes SAX (Lin et al., 2007) not as a final representation but as a 'symbolic search handle' for SQL regex filtering, and borrows the multi-agent decomposition spirit of MAC-SQL and DIN-SQL while adding a Python-based verification stage that has no analogue in either the SQL or TSQA literatures. The 'Search-Then-Verify' framing departs from both the end-to-end context-reading paradigm of TSQA models and the single-shot SQL generation of Text-to-SQL, instead treating the problem as an active localization task over an indexed feature space.

## Why It Matters / Open Questions

This is the first systematic formulation and benchmark for natural language querying over TSDB-scale histories, filling a gap where prior TSQA benchmarks restricted evaluation to short snippets (<500 points) and Text-to-SQL benchmarks ignored morphological intent entirely. The key open question is realism: ground truths are produced by synthetic pattern injection onto real backgrounds, so alignment with authentic user queries and real-world data distributions remains unvalidated. The SAX-based symbolic index introduces unavoidable information loss for fine-grained fluctuations, and the 20-item experience cap limits domain knowledge transfer; both point toward learnable discrete representations and adaptive memory as necessary next steps. If the task framing gains traction, NLQTSBench could become a standard evaluation target for DB-grounded time series intelligence.

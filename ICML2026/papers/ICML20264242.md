## Problem

Existing agentic frameworks (LangChain, AutoGen, Smolagents) are designed and optimized for large language models accessed via API, creating high token costs, privacy risks, and incompatibility with the constraints of small language models (limited context windows, reduced instruction-following, lower reasoning depth). No prior framework systematically treats SLM constraints as first-class design requirements, leaving SLM users to manually adapt prompts, manage context, and handle unique failure modes of smaller models.
![Teaser figure](../imgs/ICML20264242/cropped_page1_idx1.webp)

## Input / Output

EFFGEN takes a natural-language text query, a tool registry of 66 built-in tools (computation, retrieval, document parsing, etc.), and a three-tier memory context (short-term conversation history, long-term episodic store, vector embeddings) as input. The query is first scored for complexity and the prompt is compressed before any model inference occurs. Output is a synthesized text response assembled from single-agent or multi-agent subtask results, accompanied by a full execution trace logging routing decisions, tool calls, and memory updates across 18 event types.

## Method

EFFGEN is a four-component agentic pipeline optimized for SLMs (≤7B parameters, ≤32K context). (1) A model-size-aware prompt optimizer applies five sequential transformations (pattern compression, sentence splitting at conjunctions, redundancy removal, bullet reformatting, context truncation) with size-tiered parameters (e.g., TINY models get α=0.6 compression, MEDIUM get α=0.8), achieving 57% average token reduction while preserving task semantics. (2) A pre-execution complexity analyzer scores queries on five weighted factors (task length 0.15, requirement count 0.25, domain breadth 0.20, tool requirements 0.20, reasoning depth 0.20) to route simple tasks to single-agent ReAct execution and complex tasks to multi-agent decomposition before any inference is spent. (3) A decomposition engine splits complex queries into 2–5 subtasks with a dependency graph, executing them in parallel, sequential, hybrid, or hierarchical modes using the same local SLM (no external API). (4) A three-tier memory system (short-term with automatic summarization at 0.8·C_M, long-term with importance scoring, and vector-based semantic retrieval via FAISS/ChromaDB) keeps context within SLM limits. The framework also unifies MCP, A2A, and ACP protocols under a single canonical tool representation. A key empirical finding is complementary scaling: prompt optimization yields 11.2% gain at 1.5B but only 2.4% at 32B, while complexity routing shows the opposite trend (3.6% → 7.9%), so combining both yields consistent gains across all model scales.

## Results

Across 13 benchmarks, EFFGEN achieves 47.44% average accuracy with Qwen2.5-1.5B (a 13.2% improvement over the raw model baseline of 34.28%), 63.07% at 7B, and 70.97% at 32B. The improvement over the best baseline shrinks monotonically with model scale: 13.2% at 1.5B, 11.4% at 3B, 11.4% at 7B, 7.3% at 14B, and 6.0% at 32B. On genuinely agentic benchmarks (GAIA, SimpleQA), EFFGEN shows the largest differentiation—e.g., 21.87% vs. 9.38% (LangChain) on GAIA at 7B, and 84.00% vs. 52.00% (Smolagents) on SimpleQA at 32B. EFFGEN also achieves up to 18× speedup over Smolagents at 1.5B while using 57% fewer input prompt tokens on average.

## Baselines & Comparisons

EFFGEN outperforms all three competing frameworks (LangChain, AutoGen, Smolagents) on every benchmark at every model scale. At 1.5B, EFFGEN's 47.44% average exceeds LangChain (32.81%), AutoGen (33.57%), and Smolagents (27.81%) by 14.6, 13.9, and 19.6 points respectively; at 32B the gaps narrow to 9.9, 6.0, and 7.1 points. The largest absolute differentiation appears on agentic benchmarks: on GAIA at 7B, EFFGEN scores 21.87% versus 9.38% (LangChain) and 12.50% (raw model), and on SimpleQA at 32B it reaches 84.00% versus 54.00% (LangChain) and 52.00% (Smolagents). Smolagents underperforms most severely on non-coding tasks (e.g., 32.58% vs. 52.63% on Calculator at 1.5B) due to its code-first design, while LangChain and AutoGen show comparable overall averages but both degrade on memory and retrieval benchmarks relative to EFFGEN's three-tier memory system. The consistent pattern—larger gains at smaller scales—confirms that SLM-specific prompt optimization and complexity routing provide the most value where raw model capacity is most limited.

## Relation to Prior Work

EFFGEN builds on the ReAct execution paradigm (Yao et al., 2022) as its core single-agent loop and on MemGPT-style hierarchical memory (Packer et al., 2023) for its three-tier storage system, but inverts the design philosophy of existing agent frameworks (LangChain, AutoGen, Smolagents) that optimize for LLMs and then adapt for smaller models. Its prompt optimization draws on LLM-Lingua-style compression (Jiang et al., 2023b) and its pre-execution complexity routing extends query difficulty prediction (Benedetto et al., 2023; Ding et al., 2024) into an agent-specific five-factor formulation. The key conceptual departure is treating SLM constraints (limited context, reduced instruction-following, lower reasoning depth) as first-class design requirements rather than afterthoughts, and unifying three agent communication protocols (MCP, A2A, ACP) under a single canonical tool representation.

## Why It Matters / Open Questions

The paper provides a practical, open-source framework that makes capable agentic systems deployable on local hardware without API costs or privacy risks, which is increasingly important as agent adoption grows. The complementary scaling finding—that prompt optimization benefits small models (11.2% at 1.5B vs. 2.4% at 32B) while complexity routing benefits large models (3.6% vs. 7.9%)—offers a concrete design guideline for building frameworks that span model scales. Open questions include whether the rule-based prompt optimizer and heuristic complexity analyzer can be replaced by learned components, whether the findings generalize beyond the Qwen/Gemma/GPT-OSS families tested, and how the framework handles multimodal or long-horizon agentic tasks. The evaluation, while broad (13 benchmarks, 5 model sizes, 3 model families), is limited to text-only tasks and does not include interactive or embodied settings.

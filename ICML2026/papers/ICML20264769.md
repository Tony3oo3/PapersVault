## Problem

Static analysis of dynamic languages like JavaScript relies on uniform, hand-engineered heap abstraction strategies that either over-abstract (producing spurious warnings) or under-abstract (preventing fixpoint convergence). No prior system has used language models to adaptively select per-object heap abstractions while preserving the formal soundness guarantees of abstract interpretation, leaving a gap between the semantic understanding LMs offer and the correctness guarantees compilers require.

## Input / Output

The system consumes JavaScript source code and, at each unbounded loop join, receives the current abstract analysis state including visible variables, changed allocation sites with their object structures and points-to sets, and the loop body. The agent interacts through a bounded interface of up to 10 read-only tool calls (variable inspection, function introspection, or one additional abstract loop iteration) before committing to a selection. Outputs are per-allocation-site merging strategy choices (allocation-site, recency, field-sensitive, or role-based) paired with widening strategy choices (field-set, field merging, full, or depth-based), which the abstract interpreter then executes to produce null/undefined dereference and absent-property-access warnings.

## Method

ABSINT-AI embeds an LM agent within a traditional abstract interpreter that maintains a two-level heap (flow-sensitive local heap for procedure-local objects, flow-insensitive global heap for shared objects). At unbounded loop joins, the agent enters an interactive decision loop where it can query the analysis environment for targeted information or request additional abstract iterations before selecting which allocation sites to summarize and which merging/widening strategy to apply to each. The critical design constraint is that the agent can only choose from a fixed, finite menu of sound abstraction operators and never directly manipulates program state, bounding any LM error to increased false positives or slower convergence without violating soundness. The system further improves precision by running the analysis multiple times with different stochastic abstraction choices and taking the intersection of reported bugs across runs, a technique that is sound because each individual run over-approximates all reachable states.

## Results

On a 53-program JavaScript benchmark, ABSINT-AI (best model, Qwen3-32B) achieves 616.9 mean false positives, a 13.2% reduction over TAJS (711 FP) and a 53.5% reduction over WALA (1327 FP). Taking the intersection of 10 runs further reduces false positives to 555 (GPT-4.1-mini, 21.9% improvement), and the full intersection across all models reaches 499 FP (29.8% improvement). The Symbolic ABSINT-AI baseline (fixed widening schedule, no LM) produces 820 FP, 15.3% worse than TAJS, confirming that LM-guided adaptivity is the key differentiator.

## Baselines & Comparisons

ABSINT-AI outperforms both baselines on the primary metric (false positives for null/undefined dereference and absent property access). Against TAJS (711 FP), the best single-run ABSINT-AI model (Qwen3-32B, 616.9 FP) reduces false positives by 13.2%, and the intersection of 10 runs with GPT-4.1-mini achieves a 21.9% reduction (555 FP). Against WALA (1327 FP), ABSINT-AI achieves a 53.5% reduction in the best single run and up to 62.4% with the full intersection (499 FP). The Symbolic ABSINT-AI ablation (820 FP, same strategies but fixed widening cascade) is 15.3% worse than TAJS, demonstrating that the LM's per-allocation-site strategy selection—not the underlying abstraction framework alone—is responsible for the precision gains. All seven evaluated LMs perform within a narrow 4% band of each other, indicating the result is robust to model choice rather than dependent on a single frontier model.

## Relation to Prior Work

This paper extends the abstract interpretation framework (Cousot & Cousot, 1977) and the JavaScript-specific analyzer TAJS (Jensen et al., 2009) by replacing hand-engineered heap abstraction heuristics with an LM agent that selects from a fixed menu of sound merging and widening strategies. It departs from prior neurosymbolic static-analysis systems (LLift, IRIS, InferROI) that use LMs to filter or augment analysis results but sacrifice soundness; here the LM is architecturally constrained to only choose among pre-verified operators, preserving the formal over-approximation guarantee. The self-consistency intersection technique (Wang et al., 2022b) is repurposed to improve precision across stochastic LM runs without risking missed bugs, and the RL-guided transformer selection of Singh et al. (2018) is generalized from numerical polyhedra domains to heap abstractions guided by natural-language semantic cues.

## Why It Matters / Open Questions

This is the first system to embed a language model within a sound abstract interpreter without compromising formal guarantees, opening a path toward semantically-informed static analysis that could support compiler optimizations (e.g., check elimination) on dynamic languages. However, scalability remains a significant limitation: the system does not converge on programs exceeding ~2,000 LOC, and the 13% false-positive reduction over TAJS, while meaningful, is modest. Open questions include whether the approach generalizes beyond JavaScript, whether richer relational or shape-based abstractions can be added to the strategy menu, and whether the agentic interaction loop (which contributes only ~4% over a single-shot LM call) is the right interface or whether more structured queries would yield larger gains.

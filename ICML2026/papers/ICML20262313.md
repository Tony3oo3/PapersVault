## Problem

Standard attention in transformers uses static token representations that remain invariant across all pairwise interactions within a layer, which the paper formalizes as 'static relational learning.' This is fundamentally misaligned with multivariate time series (MTS) data, where different channel-pair interactions within the same system can be governed by entirely different physical laws or temporal dynamics (e.g., lead-lag vs. instantaneous coupling). The paper asks whether attention can be modified to enable pair-specific representational modulation that better captures such heterogeneous inter-channel dependencies.

## Input / Output

The method consumes a multivariate time series look-back window (default L=96, with ablations down to L=16) tokenized via a simple linear layer, and produces forecasts at horizons H ∈ {96, 192, 336, 720} (or {12, 24, 48, 96} for PEMS) through a linear decoder. Reverse instance normalization (RevIN) is applied to handle non-stationarity. A notable practical detail is that prime attention can match standard attention's performance at L=96 using only L=48 or L=64, effectively reducing input data requirements by 33–40%.

## Method

Prime attention introduces a learnable pair-wise modulator F_ij ∈ R^{d_model} that element-wise multiplies both the key and value vectors for each specific token pair (x_i, x_j), so that each token presents a dynamically adapted representation depending on its interaction partner. The primers are computed once before each transformer block and can be initialized with domain-specific estimates—lead-lag correlations computed via FFT and instantaneous correlations via dot products—then made fully adaptive through a shared MLP, adding only ~1.5% parameter overhead. The paper formally proves (Proposition 3.3) that standard attention implements static relational learning and (Proposition 4.1) that prime attention enables dynamic relational learning, since F_ji ≠ F_jv for different interaction partners. This mechanism is framed as a learnable pair-wise inductive bias that directs model capacity toward discovering relationship-specific patterns efficiently, and it is validated by swapping the attention module in three SOTA MTS transformers (iTransformer, Timer-XL, FreDF) with no other architectural changes.

## Results

Prime attention consistently outperforms standard attention across three state-of-the-art MTS transformer backbones (Timer-XL, FreDF, iTransformer) on 11 benchmark datasets, achieving up to 6.5% MSE improvement on Weather with Timer-XL (0.259→0.254) and up to 4.0% average improvement on heterogeneous-channel datasets like Solar and Weather. On homogeneous-channel datasets (ECL, Traffic), gains are marginal (≤1%), confirming the method's benefit is concentrated where inter-channel dynamics are diverse. Prime attention also achieves comparable performance using up to 40% less input sequence length (L=48 vs L=96), and adds only ~1.5% parameter overhead over standard attention.

## Baselines & Comparisons

Against Timer-XL, FreDF, and iTransformer (used as backbone architectures), prime attention improves MSE by 1–6.5% across nearly all 11 datasets, with the largest gains on heterogeneous-channel data (Weather: 6.5% with Timer-XL; Solar: ~4% average). Against DIFF Transformer (Ye et al., 2025), prime attention wins on 5 of 6 datasets in Table 2, losing only marginally on ECL (0.175 vs 0.173 MSE). Against LagTS (Liu et al., 2025a), prime attention outperforms on all 4 overlapping datasets (e.g., ETTh2: 0.377 vs 0.382; Weather: 0.254 vs 0.258). Against LIFT (Zhao & Shen, 2024), prime attention achieves substantially lower MSE on all 6 datasets (e.g., Traffic: 0.426 vs 0.513; Exchange: 0.339 vs 0.356). Against Autoformer (Wu et al., 2021), prime attention dominates by a wide margin on every dataset (e.g., Exchange: 0.339 vs 0.613; Weather: 0.254 vs 0.338). The paper also shows that naively adding an extra attention head to standard attention (+38% parameters) does not close the gap to prime attention (+1.5% parameters), confirming the benefit is architectural rather than parametric.

## Relation to Prior Work

This paper builds on standard transformer attention (Vaswani et al., 2017) and positions itself against two main lines of work in MTS forecasting: (1) channel-dependent transformers like iTransformer, Timer-XL, and FreDF that use standard attention for inter-channel modeling, and (2) attention-enhancement methods like the Differential Transformer, Selective Attention, and Gated Attention that sharpen attention coefficients. The key conceptual departure is the formalization of 'static' vs. 'dynamic' relational learning, arguing that all prior attention modifications—including coefficient sharpening and explicit lead-lag modeling (LIFT, LagTS)—remain within the static paradigm because token representations are invariant across pair-wise interactions. Prime attention introduces pair-specific learnable modulators on keys and values, enabling each token to present a different representational perspective depending on its interaction partner.

## Why It Matters / Open Questions

The practical significance lies in the sequence-length efficiency finding: prime attention can match standard attention's performance with up to 40% less input data, which is valuable for data-scarce MTS settings and reduces effective computational cost. The parameter-effectiveness analysis (adding 38% more parameters via extra heads to standard attention underperforms prime attention's 1.5% overhead) suggests that the bottleneck in MTS forecasting is relational modeling capacity, not raw parameter count. Limitations include that gains are most pronounced on heterogeneous-channel datasets (Weather, Solar) and marginal on homogeneous ones (ECL, Traffic), and the lead-lag initialization, while helpful, is not strictly necessary. Open questions include whether the dynamic relational learning framework generalizes beyond MTS to other domains with heterogeneous pairwise interactions, and whether the approach scales efficiently to very high-dimensional settings (thousands of channels).

## Problem

Existing multitask learning methods assume aligned feature spaces or homogeneous task structures, while double machine learning (DML) is inherently single-task and cannot discover shared structure across environments. When tasks share a latent cluster structure in their target parameters but exhibit heterogeneous, potentially infinite-dimensional nuisance components (e.g., different covariates, distributions, or confounding), naively pooling data invalidates inference and estimating tasks independently sacrifices statistical efficiency. This paper addresses the gap by developing a semiparametric framework that simultaneously discovers latent clustering and enables valid pooled-rate inference under heterogeneous nuisances.

## Input / Output

The method takes m task datasets where each task j has its own sample size n_j, covariate dimension p_j, and potentially different data-generating distribution P_j, along with task-specific Neyman-orthogonal loss functions and a small set of fusion hyperparameters (γ, c_w, τ, ε_n). Unlike standard MTL, the nuisance spaces H_j are allowed to be infinite-dimensional and structurally heterogeneous across tasks; only the finite-dimensional target parameters θ_j are fused. The output consists of (i) task-level target estimates that are exactly equal within each recovered cluster, (ii) the latent cluster partition discovered automatically without specifying the number of clusters K, and (iii) pooled-rate asymptotic confidence intervals with variance matching an oracle that knows the true clustering in advance.

## Method

The estimator proceeds in two stages. Stage 1 computes task-local pilot estimates θ̂_j^init using any consistent (not necessarily orthogonal) loss, solely to quantify pairwise task similarity. Stage 2 solves a joint penalized optimization over all target parameters using task-specific Neyman-orthogonal losses (with nuisances estimated on a separate data split) plus adaptive pairwise fusion penalties λ_jj' derived from the pilot estimates via w_jj' = c_w‖θ̂_j^init − θ̂_j'^init‖^{−γ}, with a threshold τ that sets inter-cluster penalties to a negligible ε_n and intra-cluster penalties to large values. The key mechanism is that the data-driven weights automatically replicate the oracle fusion pattern (strong fusion within true clusters, negligible fusion across clusters) with high probability under mild separation conditions, while Neyman orthogonality ensures that first-order nuisance estimation errors do not contaminate the target estimates. Theoretically, the procedure achieves exact cluster recovery, pooled parametric rates O_P(N_k^{−1/2}) proportional to cluster size, and asymptotic normality matching the oracle estimator, even when the number of tasks and clusters grows with sample size.

## Results

Across three semiparametric simulation models (PLM, ATE, DID) with m=20 tasks in K=3 clusters, the adaptive fusion estimator consistently achieves the lowest median RMSE and near-perfect cluster recovery (ARI ≈ 1) across all separation levels δ ∈ {1/3, 2/3, 1}, without requiring knowledge of the true number of clusters. On the real-world RECS 2020 dataset (51 U.S. states), the method identifies three distinct electricity-price elasticity clusters: Virginia (−1.138 ± 0.189), four Southern states (−0.788 ± 0.051), and the remaining 46 states (−0.221 ± 0.009), revealing a geographically coherent pattern of heightened price sensitivity in warmer regions.

## Baselines & Comparisons

The adaptive fusion estimator outperforms all four multitask baselines on both RMSE and ARI across all three simulation models and all separation levels. ARMUL (Duan & Wang, 2023) is competitive only when the true number of clusters K is correctly specified and separation is moderate-to-strong; it degrades substantially under K-misspecification (K−1 or K+1), in the PLM setting, and at weak separation (δ=1/3), and it requires the user to supply K in advance. Cluster Norm (Jacob et al., 2008) and Flexible Clustering (Zhou & Zhao, 2015) perform comparably to the personalized (no-sharing) baseline, exhibit essentially no clustering signal (ARI ≈ 0), and fail to recover the latent partition. MeTaG (Han & Zhang, 2015), which uses a uniform (non-adaptive) pairwise fusion penalty, fails to estimate parameters accurately in the ATE and DID settings and recovers clusters only in PLM, exhibiting a pronounced bias toward a global mean. The key practical advantage of the proposed method is that it simultaneously achieves oracle-level estimation accuracy and exact cluster recovery without any user-specified cluster count, whereas ARMUL's performance is highly sensitive to the K hyperparameter.

## Relation to Prior Work

This paper bridges two previously separate research threads: double machine learning (DML) with Neyman-orthogonal scores (Chernozhukov et al., 2018), which handles semiparametric estimation with high-dimensional nuisance parameters but operates on a single task, and clustered multitask learning (Duan & Wang, 2023; Jacob et al., 2008; Han & Zhang, 2015), which captures latent group structure among tasks but assumes parametric models with aligned feature spaces. The key departure is constructing a two-stage estimator that uses task-local pilot estimates to build adaptive pairwise fusion penalties (inspired by adaptive lasso, Zou 2006) while enforcing Neyman orthogonality in the final estimation stage, thereby allowing each task to have its own heterogeneous, potentially infinite-dimensional nuisance component. Unlike Duan & Wang (2023), the method does not require the number of clusters K to be specified in advance and accommodates nonparametric nuisance estimation via sample splitting.

## Why It Matters / Open Questions

The framework provides a principled way to borrow statistical strength across heterogeneous environments (e.g., hospitals, regions, platforms) for causal or policy parameters while preserving valid inference, addressing a practical gap where naive pooling invalidates inference and independent estimation wastes information. The theoretical guarantees—exact cluster recovery, pooled parametric rates, and oracle-matching asymptotic normality despite data-dependent adaptive penalties—are strong and cleanly stated. Open questions include extending to high-dimensional target parameters (d growing with n), characterizing the dependence on cluster separation more finely, and understanding performance when the clustering assumption is weakly supported. The real-world electricity elasticity application demonstrates interpretability but involves a single dataset, so broader validation across application domains would strengthen the practical case.

## Problem

Ultrafast model-free online learning on sub-microsecond timescales (e.g., quantum control, plasma diagnostics) requires both inference and training to execute directly on-chip with fixed-point arithmetic under strict memory constraints. Conventional MLPs are impractical in this regime because dense backpropagation is computationally expensive and reduced precision destabilizes gradient-based optimization. The paper asks what architectural properties enable stable, hardware-efficient, fully on-chip online updates and identifies KANs' B-spline locality as the key enabler.

## Input / Output

The system consumes a single streaming sample per time step (scalar, 2D IQ pair, 6D state vector, or flattened 8×8 image) with no buffering or replay, and produces a prediction (scalar regression value, binary class label, or discrete action) followed by an in-place parameter update, all within a single deterministic hardware kernel. All arithmetic is fixed-point with task-specific bitwidths (e.g., ⟨6,2⟩ for regression, ⟨7,3⟩ for classification, ⟨22,8⟩ for control), and all trainable parameters reside entirely on-chip in LUTRAM/BRAM/FF with no external DRAM access.

## Method

The paper exploits B-spline local support in KANs so that each sample activates only S+1 coefficients per edge, reducing per-sample gradient update cost to (S+1)/(G+S) of an equivalent-parameter MLP (Proposition 3.2) while allowing capacity to scale via grid size G at near-constant compute. KAN activations are convex combinations of learned coefficients bounded by min/max coefficient values (Proposition 3.3), and backward gradients are bounded by B-spline values in [0,1] independent of input magnitude (Proposition 3.4), providing inherent robustness to aggressive fixed-point quantization. The FPGA implementation (Vitis HLS, AMD Virtex UltraScale+ XCVU13P at 200 MHz) stores precomputed B-spline basis values and derivatives in small ROM LUTs, uses index-driven lookups to read only active coefficients, and performs sparse in-place SGD updates with the cached (k,u) grid context reused in backpropagation, achieving sub-100 ns forward-plus-backward latency across all tasks.

## Results

On the adaptive function approximation task, KAN achieves a cumulative regret of 13.2 under fixed-point ⟨6,2⟩ training, compared to 97.6 for the parameter-matched MLP-P and 48.3 for the larger MLP-L (321 params). On single-shot qubit readout, KAN reaches 92.8% running accuracy versus 50.4% (MLP-P), 49.0% (MLP-L), and 41.8% (OS-ELM). On non-stationary Acrobot control, the fixed-point KAN actor-critic achieves an episodic return of −104, while parameter-matched and 10×-larger MLP actor-critics both fail to adapt (−500), and a ~120×-larger MLP-DQN reaches only −298. Post-synthesis FPGA latency for KAN remains in the 50–140 ns range (sub-100 ns for most tasks) at 200 MHz on an AMD Virtex UltraScale+ XCVU13P.

## Baselines & Comparisons

The primary comparison is against MLP baselines (parameter-matched MLP-P and larger MLP-L) across all three tasks. KAN decisively outperforms both: on qubit readout, KAN achieves 92.8% accuracy while MLP-P (279 params) and MLP-L (609 params) both hover near chance level (~50%), and on Acrobot control, KAN reaches the solved regime (−104) while MLPs at 1× and 10× the parameter budget fail entirely (−500). The only non-MLP baseline, OS-ELM (Zang et al., 2025), achieves 41.8% accuracy on qubit readout even with floating-point training, confirming that non-gradient-trained shallow models lack the expressivity for these non-stationary tasks. A much larger MLP-DQN (17,795 params, ~120× KAN) with a more stable value-learning update reaches −298 on Acrobot but still underperforms KAN and learns more slowly. The paper also shows that adding LayerNorm or LSUV initialization to MLPs does not close the gap and in fact degrades fixed-point stability while increasing hardware cost by 2–5×.

## Relation to Prior Work

This paper repositions Kolmogorov-Arnold Networks (KANs) from a hardware-centric perspective, directly challenging the prevailing GPU-centric view that labels KANs as hardware-impractical due to recursive spline evaluation and per-edge parameterization. It builds on the KAN architecture (Liu et al., 2025) but reframes its B-spline locality as a hardware advantage rather than a cost, showing that sparse, index-driven coefficient updates replace the dense gradient propagation that makes MLPs unstable under fixed-point on-chip training. The work also extends the on-device training literature (HLS4ML, FINN, prior FPGA backpropagation work) by demonstrating fully on-chip, single-sample, fixed-point gradient updates with deterministic sub-microsecond latency—a regime where prior systems either decoupled learning from inference or targeted narrow, task-specific update rules.

## Why It Matters / Open Questions

This is the first demonstration of model-free online learning at sub-microsecond latencies, opening a path for real-time adaptive control in quantum computing, plasma diagnostics, and high-speed communications where host-accelerator loops are fundamentally too slow. The capacity-precision decoupling (scaling grid size G improves approximation without increasing per-sample compute) provides a clean architectural knob for resource-constrained on-chip learners. Key limitations include reliance on single-batch SGD (no Adam or trajectory-based optimizers under fixed-point), fixed hyperparameters across ablations, and HLS-level rather than RTL-optimized implementations. Open questions include whether these advantages persist at higher spline orders, with more complex optimizers, and whether purpose-built hardware for spline evaluation and basis selection could further close the gap.

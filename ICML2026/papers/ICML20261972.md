## Problem

Existing LLM-based multi-agent systems are tightly coupled to specific tasks through manually designed agent roles and natural-language interaction protocols, making them difficult to reuse across problem settings. Additionally, natural-language communication between agents degrades rapidly in long-context, multi-stage interactions due to accumulated noise and information loss, creating a fundamental bottleneck for reliable multi-agent collaboration.
![Teaser figure](../imgs/ICML20261972/cropped_page4_idx0.webp)

## Input / Output

The system takes a text query and a lightweight Knowledge Pool of 45 previously observed query-to-MAS-structure pairs as input. The Organizer (an LLM, default GPT-5.2) produces a primitive composition plan specifying which of the three primitives to instantiate and their execution order; the composed primitives then produce a final text solution. All agents within a primitive must share the same LLM backbone to satisfy the KV-cache input-output alignment assumption, and the Organizer contributes only 200–400 output tokens per query since it builds structure rather than solving the task.

## Method

The paper decomposes recurring MAS computation patterns into three reusable Agent Primitives—Review (iterative Solver–Critic feedback loop), Voting and Selection (parallel Solvers with a latent-space Selector), and Planning and Execution (Planner producing a latent plan consumed by Executors)—each exposing the same external interface as a standard LLM agent. Internal coordination within and across primitives is realized exclusively through KV-cache concatenation: after one agent finishes decoding, its final KV cache is appended to the next agent's system-prompt KV cache (with RoPE positional re-encoding by an offset), so the receiving agent conditions on the latent state without any explicit text transfer. An LLM-based Organizer automatically selects and composes primitives per query, guided by the Knowledge Pool, eliminating manual system design. This design reduces token usage and latency by roughly 3×–4× compared to text-based MAS while incurring only 1.3×–1.6× overhead over single-agent inference, and ablations confirm that both the primitive abstraction and KV-cache communication independently contribute to the accuracy gains.

## Results

Primitives-based MAS achieves 75.3% average accuracy on Qwen3-8B (+16.5 pp over single-agent), 77.6% on DeepSeek-R1-DistillQwen-32B (+6.6 pp), and 76.4% on DeepSeek-R1-DistillLlama-70B (+6.3 pp) across eight benchmarks. On the unified Llama-3-70B-Instruct comparison (Table 4), it reaches 72.4% on MATH, 93.8% on GSM8K, 82.3% on HumanEval+, and 53.2% on GPQA-Diamond. Compared to text-based MAS, the method reduces token usage and inference latency by approximately 3×–4× while incurring only 1.3×–1.6× overhead relative to single-agent inference.

## Baselines & Comparisons

Primitives-based MAS outperforms all 10 compared MAS methods across all four benchmarks in the unified Llama-3-70B-Instruct setting. The largest margin is on GPQA-Diamond, where it achieves 53.2% versus 33.6–40.2% for all prior methods (a 13–19 pp gap), and on MATH, where it beats the strongest baseline MAS-GPT by 3.7 pp (72.4% vs. 68.7%). On HumanEval+, it surpasses MAS-GPT by 3.4 pp (82.3% vs. 78.9%) and Self-Consistency by 6.5 pp. Several baselines (LLM-Debate, Self-Refine, Quality-Diversity, SPP, GPTSwarm, DyLAN) actually degrade below the single-agent baseline on one or more benchmarks, whereas Primitives-based MAS consistently improves over single-agent on all four. In the multi-model evaluation (Table 3), LatentMAS degrades by 10.1 pp on DeepSeek-R1-Distill-Llama-70B relative to single-agent, while Primitives-based MAS still gains +6.3 pp, highlighting the backbone-robustness advantage of the primitive abstraction.

## Relation to Prior Work

This paper carves new ground by repurposing the modular building-block philosophy from neural network design (residual blocks, attention heads) into the multi-agent system domain, proposing 'Agent Primitives' as reusable latent operators that replace task-specific agent roles. It departs from prior MAS work (MetaGPT, GPTSwarm, DyLAN, MAS-GPT) that treats individual agents as the atomic design unit and relies on natural-language interaction, and from prior latent-communication work (LatentMAS, Cache-to-Cache, ThoughtComm) that focuses on improving information transmission between agents. The key conceptual move is using KV-cache communication not merely as a transmission channel but as the mechanism that directly implements the internal computation structure of each primitive, while an LLM-based Organizer with a Knowledge Pool automates system composition without manual design.

## Why It Matters / Open Questions

The primitive abstraction offers a principled path toward reducing the architectural complexity that currently scales with task complexity in MAS, and the KV-cache communication mechanism provides a concrete, well-motivated solution to the natural-language degradation bottleneck in long multi-stage interactions. However, the approach is constrained to same-model agents (due to the input-output alignment assumption), currently instantiates only three primitives, and depends on a strong external LLM (GPT-5.2) as Organizer, raising open questions about cross-model generalization, primitive discovery/optimization, and whether the framework scales to more complex or open-ended compositions. The 3–4× token and latency reduction over text-based MAS while achieving higher accuracy makes this practically relevant for deployment, but the Organizer dependency and limited primitive set temper its immediate generality.

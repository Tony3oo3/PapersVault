## Problem

Deployed LLM agents have frozen weights and cannot adapt to new tasks or correct repeated mistakes, yet conventional RL-based continual learning is computationally prohibitive (requiring ~$9,900 in GPU training) and suffers from catastrophic forgetting. In-context learning alternatives degrade with long agentic trajectories and lack the reward-driven generality of RL. The paper asks whether an agent can perform genuine policy optimization at test time without any gradient updates.
![Teaser figure](../imgs/ICML20262492/cropped_page0_idx0.webp)

## Input / Output

At each decision step, the agent receives a raw observation (full HTML DOM tree or verbose game text) that is abstracted into a compact structured state (e.g., regularized URL + local action history for web tasks; noun/verb summaries for text games). This state is used to retrieve top-k similar (state, action, discounted-return) triplets from a growing non-parametric memory bank via Jaccard similarity. The LLM simultaneously generates a small candidate action set (typically 3) with associated logits; the output is a re-weighted logit vector over the augmented candidate set (which also includes actions found only in retrieved memory), from which the final action is sampled.

## Method

JitRL replaces gradient-based policy updates with a closed-form logit modulation derived from KL-constrained advantage maximization. After each episode, an LLM evaluator assigns step-wise rewards that are aggregated into discounted returns, and each transition is stored as a (state, action, return) triplet in a dynamic memory. At inference, the current state retrieves k nearest neighbors; state value V̂ is the mean return over the neighborhood, and action value Q̂ is the mean return over the action-filtered subset (with a UCB-style optimism bonus for unseen actions). The advantage Â = Q̂ − V̂ is then added directly to the base LLM's logits as z′ = z + β·Â, which the paper proves is the exact solution to max_π′ E_{a~π′}[Â] − (1/β)KL(π′‖π_θ). This makes the update model-agnostic, requires no backpropagation, and naturally shifts probability mass toward historically advantageous actions while preserving the base model's linguistic coherence through the KL constraint.

## Results

On WebArena, JitRL achieves a 46.98% average success rate and 51.35% final success rate, outperforming the best training-free baseline (AWM: 39.37%/40.32%) by ~7.6 and ~11 percentage points respectively. On the held-out WebArena-Lite test set, JitRL reaches 60.00% final success rate, surpassing the expensive WebRL fine-tuning method (46.06%) by 14 points while costing only $290 vs. ~$9,900 (a >30× reduction). On Jericho, JitRL attains the highest scores across all three games (Library: 25.9, Zork1: 53.0, Zork3: 3.1 average over 50 episodes), significantly exceeding both training-free baselines and the GRPO gradient-based method.

## Baselines & Comparisons

JitRL outperforms all five training-free baselines on WebArena: it leads AWM (39.37%) by 7.6 points, Reflexion (41.08%) by 5.9 points, Memory (41.36%) by 5.6 points, EvoTest (39.24%) by 7.7 points, and Static (35.63%) by 11.4 points in average success rate. Against weight-update methods on the held-out WebArena-Lite set, JitRL (60.00% final) beats WebRL (46.06%) by 14 points and SFT (23.00%) by 37 points, while costing ~34× less ($290 vs. ~$9,900). On Jericho, JitRL dominates GRPO (the gradient-based RL baseline) across all three games—most dramatically on Zork1 where JitRL scores 53.0 vs. GRPO's 16.2 average—and also surpasses the best training-free baseline EvoTest (21.5/46.8/2.6) on Library, Zork1, and Zork3. The paper further shows JitRL generalizes across backbones (Gemini-2.5-flash, GPT-5-mini, DeepSeek-V3.2) and to unseen tasks via cross-task memory retrieval, where it still leads all baselines by 1–13 points per domain.

## Relation to Prior Work

JitRL carves new ground at the intersection of two established but previously separate threads: gradient-based RL for LLM agents (PPO, GRPO, WebRL) and retrieval-augmented test-time adaptation (Reflexion, AWM, EvoTest). Rather than updating parameters or engineering prompts, it repurposes the RL advantage-estimation framework in a non-parametric form—using kNN retrieval over a memory bank to approximate Q and V values, then applying the resulting advantage as a direct additive shift to the LLM's output logits. The key conceptual departure is proving this logit shift is the exact closed-form solution to the KL-constrained policy optimization objective, thereby unifying the retrieval mechanism with a principled RL update rule without any gradient computation.

## Why It Matters / Open Questions

The practical impact is substantial: JitRL matches or exceeds expensive fine-tuning methods (WebRL, GRPO) at roughly 1/30th the monetary cost, offering a viable path for continual agent adaptation without GPU clusters or catastrophic forgetting. However, several limitations remain open: the method can only re-weight actions the base model already proposes (it cannot discover entirely new actions), it depends on an LLM evaluator for step-wise credit assignment whose errors propagate into advantage estimates, and its text-based retrieval may struggle with tasks where critical state information is non-textual (e.g., spatial layouts). Whether the approach scales to very large or continuous action spaces, and whether the LLM-evaluator bottleneck can be replaced with learned or environment-provided rewards, are important directions for future work.

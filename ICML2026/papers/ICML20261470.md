## Problem

While uniform-rate trichotomies for transductive online learning have been established for both binary and multiclass settings, the universal (sequence-dependent) learnability rates for multiclass transductive online learning with unbounded label spaces remained uncharacterized. The key obstacle is that the binary-case characterization via VCL trees relies on a lemma equating infinite Littlestone trees with infinite indifferent Littlestone trees, which fails for unbounded label spaces, making the natural multiclass extensions (DSL trees, LCL trees, LCL-Littlestone trees) incorrect characterizations.

## Input / Output

The learner receives the entire instance sequence X = {X_t}_{t∈ℕ} in advance (the transductive assumption) and, at each round t, the history of revealed labels Y_{<t}; the label space Y is countably infinite. The algorithm outputs a prediction Ŷ_t ∈ Y per round, and the characterization is expressed entirely in terms of combinatorial tree structures on the concept class H: the presence or absence of infinite indifferent Littlestone trees and infinite indifferent LCLL trees determines whether the optimal universal mistake rate is O(1), Θ(log T), or Ω(T). In the agnostic setting, the output is a regret bound of Õ(√T) relative to the best realizable label sequence.

## Method

The paper introduces the Level-Constrained-Littlestone-Littlestone (LCLL) tree with an indifferent property (all descendants of a node agree on earlier BFS-order nodes) as the correct combinatorial characterization, and proves a trichotomy: no infinite indifferent Littlestone tree gives O(1) mistakes, an infinite indifferent Littlestone tree without an infinite indifferent LCLL tree gives Θ(log T), and an infinite indifferent LCLL tree forces Ω(T). The central technical contribution is a novel Gale-Stewart game design in which the adversary, rather than proposing a single instance sequence, provides all possible label sequences over an interval of instances (i.e., all 2^k label assignments for a depth-k LCL tree), which is the first such game in the universal learning literature and is necessary because the standard instance-proposing game structure inherently produces Littlestone-type trees rather than indifferent trees. The upper bound algorithm (Algorithm 1) uses the winning strategy of player B in this game to define a partial concept class H^{g_U}, then applies a weight-function-based prediction rule (inspired by Alon et al., 2022) that guarantees O(log T) mistakes once the game stops advancing. For the agnostic case, the paper constructs a countable family of experts parameterized by a hallucinated prefix I and a mistake-index set J, then applies the Squint algorithm (Koolen & van Erven, 2015) with non-uniform initial weights π_{i,j} = 1/(i(i+1)j(j+1)) to achieve Õ(√T) regret.

## Results

The paper establishes a trichotomy for universal multiclass transductive online learning (Theorem 2.8): (1) O(1) mistakes iff no infinite indifferent Littlestone tree; (2) Θ(log T) mistakes iff an infinite indifferent Littlestone tree exists but no infinite indifferent LCLL tree; (3) no sublinear mistake bound (Ω(T)) if an infinite indifferent LCLL tree exists. For the agnostic setting (Theorem 2.9), the paper provides a Õ(√T) regret upper bound when no infinite indifferent LCLL tree exists, and proves an Ω(√T) lower bound for any concept class with at least two distinct concepts. The results extend to the stochastic process setting, showing all processes admit universal online learning iff no infinite indifferent LCLL tree exists (Theorem D.6).

**Table: Trichotomy for universal multiclass transductive online learning (Theorem 2.8).**

| Condition on H | Mistake Rate | Characterization |
|---|---|---|
| No infinite indifferent Littlestone tree | O(1) | Bounded mistakes |
| Infinite indifferent Littlestone tree, no infinite indifferent LCLL tree | Θ(log T) | Logarithmic mistakes |
| Infinite indifferent LCLL tree | Ω(T) | No sublinear bound |

**Agnostic setting (Theorem 2.9):**

| Condition on H | Regret Bound | Notes |
|---|---|---|
| No infinite indifferent LCLL tree | Õ(√T) upper, Ω(√T) lower | Poly-log gap between bounds |
| Infinite indifferent LCLL tree | Not learnable (regret = Ω(T)) | No algorithm achieves o(T) regret |

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The key comparison is against prior combinatorial characterizations: the paper shows that the LCL tree (Hanneke et al., 2024b), the DSL tree (Hanneke et al., 2023c), and the standard Littlestone tree are all insufficient for characterizing universal multiclass transductive online learnability (Example 3.1 and 3.3). The correct characterization requires the *indifferent* LCLL tree, which is a new structure. For binary classification, the VCL tree (Hanneke & Wang, 2024) suffices, but the paper demonstrates that this nice equivalence between Littlestone trees and indifferent Littlestone trees breaks down for unbounded label spaces. The agnostic Õ(√T) bound uses the Squint algorithm (Koolen & van Erven, 2015) with non-uniform expert weights, extending the realizable O(log T) algorithm via an expert construction. A poly-logarithmic gap remains between the Õ(√T) upper bound and the Ω(√T) lower bound in the agnostic case.

## Relation to Prior Work

This paper extends the binary transductive online learning trichotomy of Hanneke et al. (2023b) and the multiclass uniform-rate trichotomy of Hanneke et al. (2024b) to the universal (sequence-dependent) multiclass setting with unbounded label spaces. It builds on the VCL tree framework from Bousquet et al. (2021) and the indifferent tree property from Bousquet et al. (2023), but departs from the natural multiclass extensions (DSL tree, LCL tree, LCL-Littlestone tree) by introducing the LCLL tree combined with the indifferent property as the correct characterization. The key technical departure is a novel Gale-Stewart game design where the adversary provides all possible label sequences for an interval of instances rather than a single instance sequence, enabling proofs for indifferent trees that the standard game structure cannot handle.

## Why It Matters / Open Questions

This paper resolves the open question of what combinatorial structure characterizes universal multiclass transductive online learnability, providing a clean trichotomy (O(1), Θ(log T), Ω(T)) and extending to the agnostic case with a Õ(√T) regret bound. The novel Gale-Stewart game design is highlighted as a reusable tool for any problem whose characterization involves infinite indifferent Littlestone-type trees. Open questions include closing the poly-logarithmic gap between upper and lower bounds in the agnostic case, and extending the characterization to other settings such as bandit feedback and real-valued regression. The result also answers when all stochastic processes admit universal online learning, connecting to the optimistically universal learning framework of Hanneke & Wang (2024).

## Problem

The inference-time algorithm that transformers use for in-context classification remains opaque, and the common hypothesis that they implicitly simulate gradient descent is argued here to be a misleading abstraction for classification tasks. The core obstacle is that standard training does not enforce the task's natural symmetries (feature-coordinate and label-class permutation), so models encode spurious asymmetries in their weights that obscure the underlying computation and prevent closed-form extraction of the learned algorithm.

## Input / Output

The transformer receives a prompt matrix Z_0 ∈ R^{(n+1)×(d+K)} formed by horizontally concatenating n labeled feature vectors (x_i ∈ R^d) with their one-hot class labels (y_i ∈ R^K), followed by a test feature vector paired with a zero label vector. The architecture is a single-head, attention-only transformer with softmax (no MLPs, layer norm, or multi-head attention), and it outputs a K-dimensional logit vector for the test point from which a class label is read. In the semi-supervised variant, a subset of label vectors is replaced with zeros, and the model must still predict the test class using the unlabeled geometry.

## Method

The key technique is enforcing feature- and label-permutation equivariance at every layer by conjugating each attention block with independently sampled random permutations (a 'permutation sandwich': apply P, run attention, apply P^T), which converts gauge freedom into an active constraint and collapses learned weights onto a two-parameter-per-layer block structure (α for features, γ for labels) while preserving the model's input-output behavior. The resulting closed-form layerwise recursion is a coupled mean-shift: each layer builds a row-stochastic attention matrix from mixed feature-label Gram structure (αX X^T + γY Y^T) and uses the same weights to propagate both training features and labels, with the test point attending to the training set to accumulate class evidence across depth. In the label-driven regime (γ ≫ α), attention becomes class-conditional, monotonically amplifying inter-class directional margins and driving the test point toward the correct cluster with provable exponential margin growth. The same symmetry-aligned weight structure and coupled dynamics re-emerge when transformers are retrained on semi-supervised, label-noise, and Voronoi (nearest-centroid) classification tasks, confirming the motif is task-general rather than an artifact of the base setting.

## Results

On in-context linear classification (K=3, d=7, n=64), the attention-only transformer is consistently competitive with logistic regression and a linear SVM across context lengths, with performance improving from L=1 to L=5 layers. In the semi-supervised setting with a fixed budget of n_lab=8 labeled examples, the transformer's accuracy rises from ~75% to >80% as unlabeled context grows from 0 to 120 points, while supervised baselines remain flat. Symmetry enforcement preserves the learned algorithm: the symmetrized and unconstrained transformers agree with R² > 0.98 on ground-truth-class probabilities, Spearman correlation >0.95 on query Jacobians, and ≈0.8 on per-example context influence scores. On the Voronoi (nearest-centroid) task, the transformer consistently exceeds 1-NN and 5-NN baselines, and the same coupled mean-shift weight structure re-emerges.

## Baselines & Comparisons

In the fully supervised linear classification setting (Figure 4), the transformer matches logistic regression and a linear SVM across context lengths, with no clear win or loss—performance is comparable and improves with depth. In the semi-supervised setting (Figure 8), the transformer clearly outperforms all baselines: with 8 fixed labeled examples, it gains >5% accuracy as unlabeled context grows to 120 points, while logistic regression, linear SVM, and Label Spreading (Zhou et al., 2003) all remain flat or perform worse than the supervised-only ceiling. Label Spreading in particular underperforms even the simple supervised baselines, highlighting that the transformer has learned a more effective geometric aggregation strategy. On the Voronoi classification task (Figure 14), the transformer consistently exceeds both 1-NN and 5-NN nearest-neighbor baselines, confirming it learns a nontrivial in-context strategy beyond simple distance-based voting. Under 30% label noise (Figure 12), the transformer maintains performance comparable to the supervised baselines, and the symmetrized model's predictions align closely with the unconstrained model (R² > 0.95), confirming the extracted dynamics are robust to supervision corruption.

## Relation to Prior Work

This paper departs from the dominant implicit-optimization narrative (von Oswald et al., 2023; Akyürek et al., 2023; Dai et al., 2023) that frames in-context learning as transformers simulating gradient descent on a classifier. Instead, by enforcing feature- and label-permutation equivariance at every layer—a technique adapted from group-theoretic data augmentation (Chen et al., 2020) and equivariant network design (Bloem-Reddy & Teh, 2020)—the authors make the internal computation identifiable and extract a coupled feature-label mean-shift recursion. The extracted dynamics connect to classical mean-shift clustering (Comaniciu & Meer, 2002) and label propagation (Zhu & Ghahramani, 2002), but in a supervised, attention-driven form where label agreement and feature similarity jointly drive representation updates across depth.

## Why It Matters / Open Questions

The symmetry-as-identifiability protocol is a general methodological contribution that could apply to other ICL tasks with natural symmetries, and the finding that the same coupled mean-shift motif re-emerges across linear, Voronoi, noisy-label, and semi-supervised settings suggests a universal in-context classification mechanism. The semi-supervised result—that transformers actively exploit unlabeled geometric structure to exceed supervised baselines—has practical implications for prompt design. However, all evidence is confined to small synthetic settings (d=7, K=3, single-head, attention-only, no MLPs), and the authors acknowledge that extending the framework to tasks without clean layer-wise symmetries, or to multi-head/MLP architectures, remains open.

## Problem

The dominant prompt-based paradigm for agentic ML suffers from a fundamental trade-off: smaller LLMs cannot internalize execution trajectories and thus generalize poorly, while large proprietary models incur prohibitive computational costs. No prior work has applied reinforcement learning to train LLM agents for autonomous ML engineering, leaving agents unable to adaptively learn from interactive experimentation across diverse ML tasks.
![Teaser figure](../imgs/ICML20262789/cropped_page3_idx0.webp)

## Input / Output

The agent receives an ML task specification (dataset description, target metric), an initial bug-free Python script, and iteratively interacts with an experimental environment providing file-system tools (Edit Script, Execute Script, Inspect Script Lines, etc.) and execution feedback (stdout, error messages, metric scores). Each trajectory is capped at 15 steps and 30 minutes of runtime. The output is a refined ML code script and a submission file, evaluated by task-specific metrics (accuracy, AUC, log-loss, MAE, RMSE, MAP@K, QWK, etc.) with performance reported as relative gain over the initial script averaged over 8 trajectories.

## Method

The paper proposes a three-component training framework for learning-based agentic ML. First, exploration-enriched fine-tuning constructs diverse action pools across three semantic axes (data, model, learning) via LLM-generated ideas filtered by farthest-point sampling in embedding space, then SFTs Qwen2.5-7B on 10k expert trajectories to broaden the agent's action diversity for RL. Second, step-wise RL reformulates the trajectory-level objective into single-step training by sampling states from a fixed expert distribution (decoupled from the policy), enabling PPO updates on individual atomic actions without expensive full-trajectory rollouts. Third, an agentic ML-specific reward module maps heterogeneous execution outcomes to a unified scalar: −1 for invalid actions or errors, 0 for valid non-editing actions or corner cases (e.g., OOM), and a normalized metric improvement for successful edits. Trained on only 9 ML tasks, the resulting 7B ML-Agent matches GPT-5-driven agents at over 20× lower per-trajectory cost.

## Results

ML-Agent, a 7B-parameter Qwen2.5-based agent trained via step-wise RL on only 9 ML tasks, achieves an average performance gain of 16.40% on 10 held-out MLE-Bench tasks and 18.01% on 3 held-in tasks. This is competitive with GPT-5-driven agents (18.14–20.95% average on held-out) while incurring a per-trajectory cost of less than $0.01, compared to over $0.20 for GPT-5-based baselines. On held-in tasks, ML-Agent reaches 33.80% gain on CIFAR-10, 6.77% on house price regression, and 13.47% on feedback-prize, surpassing all 671B DeepSeek-R1-driven baselines across the board.

## Baselines & Comparisons

ML-Agent (7B) decisively outperforms all 671B DeepSeek-R1-driven baselines: it achieves 16.40% average held-out gain versus 6.83% (MLAB), 11.40% (AIDE), and 13.13% (ML-Master), a margin of 3–10 percentage points. Against same-scale Qwen2.5-7B-Instruct baselines, the gap is even more dramatic (e.g., 16.40% vs. 1.43% for MLAB, 0.77% for AIDE, 0.10% for ML-Master), confirming that the learning-based paradigm is the key differentiator rather than model size. Compared to GPT-5-driven agents, ML-Agent is competitive but slightly behind: 16.40% vs. 18.14% (MLAB+GPT-5), 20.95% (AIDE+GPT-5), and 19.12% (ML-Master+GPT-5) on held-out tasks. However, ML-Agent achieves this at a per-trajectory cost below $0.01, whereas GPT-5-based agents cost more than 20× higher, and the pre-inference training cost (~$323) is amortized after only ~1,500–4,300 trajectories depending on the baseline. On held-in tasks, ML-Agent trails GPT-5 on CIFAR-10 (33.80% vs. 76.53% for AIDE+GPT-5) but matches or exceeds them on house (6.77% vs. 22.15% for AIDE+GPT-5 is an exception) and feedback (13.47% vs. 12.74% for MLAB+GPT-5).

## Relation to Prior Work

This paper builds on the MLAgentBench agent scaffold and action space (Huang et al., 2023) but fundamentally departs from the dominant prompt-based paradigm used by MLAB, AIDE, and ML-Master, where agents rely on static prompt engineering and large proprietary LLMs without parameter updates. It introduces a learning-based paradigm that applies online RL (specifically PPO) to train a 7B LLM agent through interactive ML experimentation, drawing on RL-for-LLM techniques (PPO, RLVR-style outcome rewards) but reformulating them via a step-wise objective that decouples state sampling from policy optimization. The exploration-enriched fine-tuning stage borrows from SFT practices but is specifically designed to seed diverse action pools for downstream RL exploration, addressing a gap not addressed by prior agent-training work like AgentQ or IPR.

## Why It Matters / Open Questions

The result that a 7B model trained on only 9 ML tasks achieves performance competitive with GPT-5-driven agents at a fraction of the cost suggests that learning-based training can substitute for raw model scale in agentic ML, opening a more accessible and scalable path for autonomous ML. The step-wise RL paradigm is a broadly applicable technique for any agent setting where environment rollouts are expensive (minutes to hours), potentially extending beyond ML engineering to other long-horizon interactive tasks. Key limitations include the narrow training set (9 tasks, 7B only), the limited held-out evaluation (10 tasks from MLE-Bench), and the reliance on GPT-4o-mini-generated expert trajectories, raising open questions about scaling to more complex pipelines, larger models, and reducing dependence on proprietary models for data collection.

## Problem

Reward alignment of flow and diffusion models at inference time requires estimating the value function V_t(x_t) = log E_{z~p_{1|t}}[exp(r(z))], which is thought to be intractable because sampling from the posterior p_{1|t} demands many ODE/SDE simulation steps. Existing work falls back to the biased denoiser approximation V_t(x_t) ≈ r(D_t(x_t)), leading to the Jensen gap and limiting accuracy. The paper challenges this assumption by showing that stochastic flow maps can provide consistent, efficient value function estimators in a single network evaluation.

## Input / Output

The method takes a pretrained flow or diffusion model (or its distilled flow map), an arbitrary differentiable reward function r(z) (e.g., CLIP score, ImageReward, human-preference ensembles), and optionally a text prompt or class label for conditional generation. It produces samples from the reward-tilted distribution p^r(z) ∝ p_data(z) exp(r(z)) at resolutions ranging from 32×32 (CIFAR-10) to high-resolution text-to-image (FLUX at 1024×1024, SANA-Sprint). A key design property is that the base model is never retrained: all adaptation happens at inference time by modifying the sampling procedure, and the stochasticity for exploration comes from Monte Carlo draws through the flow map rather than from the base model's SDE.

## Method

Diamond Maps are stochastic flow maps that amortize many simulation steps into one network call while preserving the stochasticity needed for value function estimation. Two designs are proposed: (1) Posterior Diamond Maps, which distill GLASS Flows into one-step samplers X_{s,s'}(x̄_s | x_t, t) of the posterior p_{1|t}(·|x_t), yielding consistent Monte Carlo estimators of V_t and ∇V_t via the reparameterization trick, and are further proven to be exact one-step DDPM transition samplers (Proposition 4.3), enabling efficient SMC proposals; (2) Weighted Diamond Maps, which take any off-the-shelf deterministic flow map and make it stochastic via a renoising step (noise x_t back to t' < t, then apply the flow map to t=1), correcting the resulting bias with a recovery reward term and a score-based correction (Theorem 5.1) to obtain a consistent gradient estimator. Training for Posterior Diamond Maps uses standard Lagrangian distillation from the GLASS velocity field (itself a linear reparameterization of the pretrained denoiser), while Weighted Diamond Maps require no additional training. The key insight is that deterministic flow maps cannot explore the posterior, but stochastic flow maps can, and this stochasticity is precisely what makes the value function estimable in one step.

## Results

On FLUX (25 ODE steps), Diamond Maps with mc=64 Monte Carlo samples achieves GenEval 0.785 and UniGenBench++ 0.653, outperforming Best-of-N (0.748 / 0.637) and Flow Map Guidance (0.737 / 0.627). On SANA-Sprint, Weighted Diamond Maps outperforms Best-of-N, RENO, and Prompt Optimization while using fewer NFEs. For Posterior Diamond Maps on ImageNet, the method generates true out-of-distribution images following text prompts (e.g., 'a lighthouse in the middle of a desert') that would be virtually impossible via Best-of-N alone, demonstrating the value of stochastic exploration.

## Baselines & Comparisons

Diamond Maps consistently outperform all three primary baselines on FLUX: GenEval 0.785 vs. Best-of-N 0.748 and Flow Map Guidance 0.737; UniGenBench++ 0.653 vs. 0.637 and 0.627 respectively. The scaling behavior is qualitatively different—Diamond Maps improve monotonically with more Monte Carlo particles, while Flow Map Guidance degrades after ~24 guidance steps and Best-of-N plateaus. On SANA-Sprint, Weighted Diamond Maps beats RENO (Eyring et al., 2024) and Prompt Optimization (Mañas et al., 2024) at lower NFE cost. For Posterior Diamond Maps, the method outperforms the denoiser approximation (DPS, Chung et al., 2022) on inverse problems with a better Pareto frontier over reward scales and NFEs, and surpasses GLASS Flows (Holderrieth et al., 2025) in posterior sampling fidelity. The naive flow map approximation (Sabour et al., 2025b) is more robust at low reward scales but degrades at high scales compared to the stochastic Posterior Diamond Map.

## Relation to Prior Work

This paper sits at the intersection of flow map distillation (Boffi et al., 2025a,b; Geng et al., 2025; Song et al., 2023c) and inference-time reward alignment (Uehara et al., 2025; Chung et al., 2022; Sabour et al., 2025b). It builds directly on GLASS Flows (Holderrieth et al., 2025) to obtain stochastic transitions from pretrained flow models, then distills these into one-step posterior samplers (Posterior Diamond Maps) or applies a renoising correction to standard deterministic flow maps (Weighted Diamond Maps). The key departure from prior work is reframing reward alignment as a property of the generative model architecture itself rather than an afterthought: by making flow maps stochastic, the paper enables consistent (unbiased) value function estimation, which prior methods approximated via the biased denoiser shortcut (Eq. 10) or deterministic flow map look-aheads.

## Why It Matters / Open Questions

The paper challenges the widely-held assumption that exact value function estimation is intractable with flow and diffusion models, providing both a theoretical framework (consistent estimators via stochastic flow maps) and practical algorithms that work with off-the-shelf distilled models. The compute scaling results—showing Diamond Maps achieve a steeper quality-vs-NFE Pareto frontier than both Best-of-N and Flow Map Guidance across FLUX and SANA-Sprint—suggest a fundamentally more efficient axis for test-time compute allocation. Key limitations include high estimator variance when the prior has weak coverage of high-reward regions, and dependence on the quality of the underlying flow map distillation. An open theoretical question is the rigorous comparison of Posterior vs. Weighted Diamond Maps in terms of effective sample size, which likely depends on the reward structure.

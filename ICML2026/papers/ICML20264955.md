## Problem

LLM agent memory is vulnerable to poisoning attacks where adversaries inject records that appear benign in isolation but corrupt reasoning only in specific contexts, and where corrupted outputs are stored as precedents creating self-reinforcing error cycles. Existing defenses (LLM auditors, perplexity filters, classifiers) perform isolated audits of individual memory entries and miss up to 66% of poisoned records because the malicious intent is context-dependent. No prior framework specifically secures agent memory as a first-class attack surface.

## Input / Output

Given a user query q_t, K retrieved memories from the agent's memory store, and the agent's immediate conversational context, A-MemGuard produces a sanitized memory set M_val (retaining only non-anomalous entries), binary anomaly flags per reasoning path, structured 'lessons' (anomalous entity-relation chains) archived in a separate lesson memory, and a final defended action. The reasoning paths are extracted via a two-stage generate-then-extract procedure (free-form rationale → structured entity-relation trajectory), and the lesson memory is queried via a two-stage retrieval (query-based then action-based) to find structurally similar past failures before action execution.

## Method

A-MemGuard is a non-invasive external security layer with two synergistic modules. First, consensus-based validation: for each query, K retrieved memories each generate a parallel structured reasoning path (an entity-relation chain) via a generate-then-extract function Λ; an LLM-as-judge then synthesizes a consensus baseline from all K paths and performs pairwise consistency checks, flagging paths that deviate from the group consensus as anomalous (no fixed threshold required). Second, a dual-memory structure: flagged anomalous paths are distilled into 'lessons' and stored in a dedicated lesson memory; before executing a final action, the agent's proposed plan is structured into a candidate path and matched against stored lessons, triggering a deliberative revision loop if relevant past failures are found. The key insight is that converting raw memories into structured entity-relation paths amplifies latent logical differences, making benign and malicious paths structurally separable (overlap <1% in knowledge graph analysis), which enables reliable consensus-based outlier detection without modifying the agent's core architecture.

## Results

Against the AgentPoison direct-poisoning attack, A-MemGuard reduces end-to-end Attack Success Rate (ASR-t) from 100% to 6.38–36.17% on EHRAgent and from 28–54% to 18–43% on ReAct-StrategyQA across four backbone/retriever configurations, while retrieval-stage ASR-r drops to 0–5.88%. Against the MINJA indirect-injection attack on MMLU, A-MemGuard cuts average ASR from 0.667 (GPT-4o-mini) and 0.663 (LLaMA-3.1-8B) to 0.256 and 0.233 respectively, a >60% reduction. In the multi-agent misinformation setting, A-MemGuard achieves the highest task success rate (0.950) and lowest final error score (2.150). Across all settings, A-MemGuard also maintains the highest benign-task accuracy (ACC) among all defense baselines, confirming minimal utility cost.

## Baselines & Comparisons

A-MemGuard decisively outperforms both the PPL Filter (Alon & Kamfonas, 2023) and the Distil Classifier (Kumar et al., 2023) across all four backbone/retriever configurations on the AgentPoison benchmark. The PPL Filter fails to reduce retrieval-stage ASR-r below 100% on EHRAgent in three of four configurations and often worsens end-to-end ASR-t (e.g., 30.00 vs. 28.18 baseline on GPT-4o-mini+REALM ReAct), while the Distil Classifier similarly leaves ASR-r at 100% on EHRAgent for GPT-4o-mini+DPR and GPT-4o-mini+REALM. On the indirect MINJA attack (MMLU), both baselines are ineffective or counterproductive: the PPL Filter increases ASR from 0.667 to 0.689 on GPT-4o-mini, and the Distil Classifier increases it to 0.689 as well, whereas A-MemGuard reduces ASR to 0.256. The LLM Auditor baseline (also compared in all tables) provides moderate retrieval-stage protection on EHRAgent (ASR-r ≈ 40–47%) but consistently fails to reduce end-to-end ASR-t below 72–100%, whereas A-MemGuard drives ASR-t to 6.38–36.17%. On benign-task utility (ACC), A-MemGuard achieves the highest accuracy in 3 of 4 configurations (e.g., 76.7% vs. 73.3% for PPL on GPT-4o-mini+DPR ReAct; 66.0% vs. 65.0% for Distil on LLaMA-3-8B+DPR ReAct), confirming that its security gains do not come at the cost of task performance.

## Relation to Prior Work

This paper carves out a new defense problem at the intersection of LLM agent memory systems and adversarial robustness. It departs from prior defenses (LlamaGuard-style isolated auditing, perplexity filtering, DistilBERT classifiers) that treat each memory entry independently, arguing instead that context-dependent poisoning is invisible to such per-entry checks. Conceptually, it repurposes the ensemble/consensus idea from multi-path reasoning and pairs it with a dual-memory (primary + lesson) structure inspired by experiential learning, but applies both to the specific pipeline of retrieval → reasoning-path extraction → action in memory-augmented agents. The attack side builds directly on AgentPoison (retrieval-adaptive direct poisoning) and MINJA (time-adaptive indirect injection with self-reinforcing cycles), which are themselves very recent (2024–2025).

## Why It Matters / Open Questions

Agent memory is becoming a first-class component in production LLM systems (MemGPT, Mem0, generative agents), yet its security has been almost entirely unaddressed; this paper provides the first systematic defense framework and a clear problem formulation for it. The non-invasive design (external validation module, no architecture changes) makes it immediately deployable, and the self-correcting lesson memory offers a path toward defenses that strengthen over time rather than remaining static. Open questions include: (i) cost/latency at scale with large memory stores and many retrieved paths, (ii) whether the LLM-as-judge consensus degrades when the backbone model itself is compromised or weak, and (iii) generalizability to multimodal or tool-use agents where reasoning paths are less cleanly structured. The paper acknowledges that absolute token cost still depends on the underlying LLM stack.

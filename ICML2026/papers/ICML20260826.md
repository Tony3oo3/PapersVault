## Problem

SmoothCruiser achieves problem-independent O-tilde(ε^{-4}) oracle complexity for planning with a generative model by exploiting the L-smoothness of the entropy-regularized (LogSumExp) Bellman backup, but its first-order Taylor estimator leaves a quadratic remainder that pins the exponent at 4. The paper asks whether a higher-order local model with a cubic remainder can lower the exponent, and what concrete Bellman aggregator provides the required Lipschitz-Hessian structure while remaining estimable from samples.

## Input / Output

The algorithm receives a root state s₀, a black-box generative-model oracle (query (s,a) → reward R and next state Z), target accuracy ε, confidence δ, and fixed OT hyperparameters (cost matrix C ∈ R^{K×K}, reference distribution μ_s with full support, and regularization factors τ, λ > 0). It returns a scalar ε-accurate estimate of V(s₀) with probability ≥ 1−δ; the gap-dependent variant OT-GapCruiser instead returns an ε-optimal root action. All intermediate value estimates are clipped to [0, B] where B is a known value bound, and the oracle is the sole source of randomness—no model parameters are learned.

## Method

The paper introduces an optimal-transport-smoothed Bellman aggregator F_s^OT(Q) = max_{π∈Δ(A)} {⟨π,Q⟩ − τW_λ(π, μ_s)} over action distributions, which admits a closed form as a μ_s-weighted mixture of columnwise LogSumExp terms, a gradient that is a valid policy, and a Lipschitz Hessian (giving a cubic Taylor remainder, β=3). The key estimator trick is that the quadratic Taylor correction Δ^⊤∇²F(Q̂)Δ equals (1/τλ)·E_{J∼μ_s}[Var_{A∼p_J}(Δ_A)], a variance under local softmax distributions, so it can be estimated unbiasedly via a cross-product identity using only a constant number of extra oracle calls—no explicit Hessian or per-state Sinkhorn solve is needed. Plugging this second-order correction into the SmoothCruiser recursion yields SecondOrderSmoothCruiser with O-tilde(ε^{-3}) worst-case oracle complexity, improving the first-order O-tilde(ε^{-4}). The curvature-complexity theorem generalizes this: any aggregator with Taylor remainder of order β gives exponent 2+2/(β−1), unifying SmoothCruiser (β=2) and the OT method (β=3) in a single analytical template.

## Results

The main theoretical result is that SecondOrderSmoothCruiser achieves worst-case oracle complexity O-tilde(ε^{-3}) for estimating the root value V(s₀) with accuracy ε, improving over SmoothCruiser's O-tilde(ε^{-4}). This follows from the curvature-complexity principle: if the local Taylor remainder of the Bellman aggregator has order β, the total oracle complexity scales as O-tilde(ε^{-(2+2/(β-1))}), so the first-order case (β=2) recovers exponent 4 while the second-order/cubic-remainder case (β=3) yields exponent 3. The OT-smoothed aggregator achieves β=3 with a Lipschitz Hessian constant M = O(1/(τ²λ²))·poly(K, μ_min^{-1}), and the quadratic Taylor correction is estimated unbiasedly via a cross-product identity requiring only a constant number of extra sampled actions per state.

## Baselines & Comparisons

Against Sparse Sampling (Kearns et al., 2002), SecondOrderSmoothCruiser provides a polynomial worst-case guarantee (O-tilde(ε^{-3})) where SSA has non-polynomial complexity, making it the first polynomial-complexity planner in the value-based generative-model setting with a smooth aggregator. Against SmoothCruiser (Grill et al., 2019), the improvement is a full exponent reduction from ε^{-4} to ε^{-3} in total oracle calls, achieved by replacing the first-order Taylor model (quadratic remainder, β=2) with a second-order model (cubic remainder, β=3) whose quadratic term is estimable via a variance/cross-product identity without explicitly forming the Hessian. The OT-smoothed aggregator reduces exactly to the entropy-regularized LogSumExp backup when the cost matrix C ≡ 0, so the improvement applies directly to the standard entropy-regularized setting. For unregularized (hard-max) planning, the OT value approximates the true value with bias at most τ(‖C‖∞ + λ log K)/(1−γ), so the O-tilde(ε^{-3}) rate holds for the regularized objective and transfers to the unregularized case only as a bias tradeoff rather than a parameter-free guarantee.

## Relation to Prior Work

This paper extends SmoothCruiser (Grill et al., 2019), which achieves O-tilde(ε^{-4}) planning complexity by exploiting the L-smoothness of the entropy-regularized LogSumExp Bellman backup and its first-order Taylor approximation. The key departure is replacing the entropy regularizer with an entropic optimal-transport cost over action distributions, which yields a Lipschitz Hessian and hence a cubic (rather than quadratic) Taylor remainder, lowering the worst-case exponent to O-tilde(ε^{-3}). The gap-dependent extensions draw on MDP-GapE (Jonsson et al., 2020) and UGapE-style elimination, while the OT construction itself builds on entropic/Sinkhorn regularization (Cuturi, 2013; Peyré & Cuturi, 2019) applied at the level of finite action distributions rather than general measures.

## Why It Matters / Open Questions

The curvature-complexity principle provides a clean, general template: any smooth Bellman aggregator with an estimable Taylor remainder of order β yields planning complexity O-tilde(ε^{-(2+2/(β-1))}), unifying SmoothCruiser and the new OT method under one analytical framework and pointing toward higher-order variants. The practical limitation is that the O-tilde(ε^{-3}) guarantee holds only for fixed smoothing parameters and finite action sets; transferring to unregularized MDPs introduces a regularization-bias tradeoff that prevents a parameter-free rate. Open questions include whether the OT geometry (nonzero cost matrix C) provides meaningful empirical gains over pure entropy regularization, whether the framework extends to continuous action spaces, and whether lower bounds confirm the curvature-complexity exponent is tight.

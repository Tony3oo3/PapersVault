## Problem

Existing explanation methods for Temporal Graph Networks (TGNs) fix the final memory vector, thereby ignoring how historical events progressively update node memories. This restricts explanations to the topological structure of the temporal graph and neglects the memory module—the core component that accumulates temporal information—resulting in unfaithful attributions that fail to capture the true drivers of TGN predictions.
![Teaser figure](../imgs/ICML20262966/cropped_page1_idx0.webp)

## Input / Output

The method takes a temporal graph (a sequence of timestamped events with node and event features), a target prediction query (a node pair for link prediction, a single node for property prediction, or a full graph for classification), and a maximum backtracking depth T_L. It outputs a sparse subset of important events with per-event contribution scores that satisfy a strict conservation property: the sum of all event contributions exactly equals the model's logits. Rather than returning a simple top-k by accumulated score, the method solves a KL-divergence-based optimization to select events whose retention best preserves the original predicted probability.

## Method

MemExplainer constructs two complementary attribution trees. The topology attribution tree applies LRP to the embedding function f_emb, decomposing each target node's embedding into contributions from neighboring events (source/destination memories, event features, time encodings) and from the node's own memory vector, with explicit proportional matrices derived for both graph-sum and graph-attention variants. The memory backtracking tree then recursively applies LRP to the memory updater f_update (GRU or RNN), tracing each node memory's contribution back through the chain of historical events that triggered its updates, using a signal-take-all rule for gate-signal multiplicative interactions. The two trees together guarantee that the total contribution of all events (both neighboring and historical) equals the logits. Finally, a KL-divergence objective over a binary selection vector replaces naive top-k selection, accounting for the nonlinear sigmoid/softmax mapping from logits to probabilities and yielding more faithful explanations.

## Results

MemExplainer is evaluated on nine temporal graph datasets spanning link prediction (Wikipedia, Reddit, Enron, UCI), node property prediction (tgbn-trade, tgbn-genre, tgbn-reddit), and graph classification (HMDB51, Penn Action). The method achieves the lowest Fidelity_KL and Fidelity_prob (i.e., best faithfulness) across all datasets and all sparsity levels, outperforming four baselines. A t-test against the second-best baseline confirms statistical significance in 77% of cases for Fidelity_KL and 74% for Fidelity_prob. Total running time is at most 6 seconds with a memory backtracking depth of T_L=10.

## Baselines & Comparisons

MemExplainer consistently outperforms all four baselines (TGNNExplainer, TempME, GNNExplainer, PGExplainer) on every dataset for both Fidelity_KL and Fidelity_prob. TGNNExplainer, which uses Monte Carlo Tree Search over sampled events, is the closest competitor but suffers from low fidelity when many events are present because it only considers sampled candidates. TempME captures temporal motifs but does not trace node memory vectors, limiting its ability to explain the temporal accumulation of historical interactions. GNNExplainer and PGExplainer, designed for static graphs, perform the worst because they ignore temporal dependencies entirely. The ablation variants (w/o memory, w/o topology, w/o selection) confirm that both the topology attribution tree and the memory backtracking tree are necessary, and that the KL-divergence-based selection objective outperforms naive top-k ranking due to the nonlinear sigmoid mapping from logits to probabilities.

## Relation to Prior Work

This paper extends the LRP attribution framework (Bach et al., 2015; Achtibat et al., 2024) from static GNNs to Temporal Graph Networks, with the key departure being that prior TGN explainers (TGNNExplainer, TempME) fix the final memory vector and thus ignore how historical events shape node states. The topology attribution tree handles the spatial decomposition (neighbor events and node features), while the memory backtracking tree recursively traces memory updates through GRU/RNN gates back to individual historical events—a decomposition that no prior TGN explainer performs. The conservation property (sum of all event contributions equals the logit) is inherited from LRP's algebraic structure and provides a faithfulness guarantee absent in sampling-based or motif-based baselines.

## Why It Matters / Open Questions

As TGNs are deployed in high-stakes settings (fraud detection, healthcare forecasting), the inability to trace which historical interactions drive a prediction is a significant trust barrier; this paper provides the first LRP-based method that accounts for the memory module with a provable conservation guarantee. The main limitation is computational: the memory backtracking tree grows exponentially with depth (O(2^{T_L} · T_L · d_m²)), making it impractical for very long event histories without pruning. Open questions include whether the depth limit (set to 5 in experiments) captures sufficient long-range temporal dependencies, and whether the signal-take-all rule for GRU gates is the optimal attribution strategy for multiplicative interactions.

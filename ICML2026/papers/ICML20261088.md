## Problem

Min-max optimization with non-smooth submodular-concave cost functions has not been addressed in the literature: prior work covered convex-submodular (Adibi et al., 2022) or discrete submodular (Mualem et al., 2024) settings, but the non-smooth submodular-concave case—where the Lovász extension is piecewise affine (no gradient for the minimiser) and the function may also be non-differentiable in the maximiser—remains unsolved. This paper is the first to provide a zeroth-order algorithm with convergence guarantees for both offline and online versions of this problem.

## Input / Output

The method consumes a grayscale image (50×50 pixels) together with a set of labelled seed pixels (e.g., 20 foreground + 20 background seeds) and produces a binary segmentation mask (a subset of pixels) along with the adversary's trust-weight vector y ∈ [0,1]^|S| constrained by a budget ρ. In the online variant, each incoming video frame (60 fps) supplies new edge weights and resampled seeds, and the algorithm performs a single extragradient update per frame using only ~0.05 MB of state variables—no pre-trained weights—achieving ~80 fps on CPU. The Lovász extension is evaluated via n function calls per subgradient computation, and the Gaussian oracle requires 2n additional calls per y-update, for a total of 6n function evaluations per iteration.

## Method

The algorithm converts the discrete submodular minimisation into a continuous convex problem over [0,1]^n via the Lovász extension, then applies a zeroth-order extragradient method to the resulting non-smooth convex-concave min-max problem. For the minimiser (x-component), it uses the Lovász extension subgradient, which is computable from n function evaluations alone (no higher-order information). For the maximiser (y-component), it employs a two-point Gaussian smoothing random oracle g_μ(y) = (f^L(x, y+μu) − f^L(x, y))/μ · u with u ~ N(0, I) to estimate the gradient of the smoothed function, avoiding any need for supergradients. The extragradient structure performs a forward step with G(z_k), an extrapolation step to ẑ_k, and a final update using G(ẑ_k), with projection onto the constraint set [0,1]^n × Y. Theoretically, this yields an expected ε-saddle point in O(nm²ε⁻²) function queries offline and an O(√(N(1+P̄))) online duality gap, where P̄ bounds the path length of optimal decisions.

## Results

On the online adversarial image segmentation task (50×50 grayscale video, 60 fps, 3 minutes), Algorithm 1 achieves an average IoU of 0.975, precision of 0.986, recall of 0.989, and F1-score of 0.987, outperforming both supervised U-Net (IoU 0.905, F1 0.950) and semi-supervised U-Net (IoU 0.847, F1 0.917) despite requiring no pre-training and only ~2.5k optimisation variables versus ~1.06M network weights. Theoretically, the offline setting requires O(nm²ε⁻²) function queries to reach an ε-saddle point, while the online setting achieves an expected duality gap of O(√(N(1+P̄))) where P̄ bounds the path length of optimal decisions. All methods operate at ~80 fps, but Algorithm 1 uses only ~0.05 MB of memory versus ~8 MB for the U-Nets.

## Baselines & Comparisons

The paper compares Algorithm 1 against two U-Net variants (supervised and semi-supervised) on the same online adversarial image segmentation task. Algorithm 1 wins decisively on IoU (0.975 vs. 0.905 and 0.847), precision (0.986 vs. 0.910 and 0.854), and F1-score (0.987 vs. 0.950 and 0.917), but trails the supervised U-Net slightly on recall (0.989 vs. 0.994). Critically, Algorithm 1 is robust to adversarial perturbations by construction (solving the min-max problem directly), whereas both U-Nets are trained and evaluated without adversaries and have no built-in robustness mechanism. Algorithm 1 also requires no pre-training dataset, uses ~400× fewer parameters (~2.5k vs. ~1.06M), and occupies ~160× less memory (~0.05 MB vs. ~8 MB), making it suitable for embedded and resource-constrained deployment. The semi-supervised U-Net, which receives the same seed inputs as Algorithm 1, still underperforms by 7+ points in IoU, highlighting the advantage of the adversarial formulation over standard semi-supervised learning.

## Relation to Prior Work

This paper sits at the intersection of three research threads: zeroth-order optimization via Gaussian smoothing (Nesterov & Spokoiny, 2017), submodular function minimization through the Lovász extension and its subgradients (Hazan & Kale, 2012), and online convex optimization with path-length regret bounds (Zinkevich, 2003). It departs from prior min-max work on submodular functions—Adibi et al. (2022) handled convex-submodular objectives and Mualem et al. (2024) studied offline integer submodular min-max—by tackling the non-smooth submodular-concave case in both offline and online regimes. The extragradient framework with a hybrid oracle (Lovász subgradient for the discrete variable, Gaussian-smoothed random oracle for the continuous variable) extends the ZO extragradient approach of Farzin et al. (2025a) from nonconvex-nonconcave to the submodular-concave setting.

## Why It Matters / Open Questions

This is the first theoretical treatment of non-smooth submodular-concave min-max problems, providing concrete convergence rates (O(nm²ε⁻²) offline, O(√(N(1+P))) online) and a practical algorithm requiring only function evaluations. The adversarial image segmentation experiments demonstrate that a training-free, ~2.5k-parameter optimizer can outperform 1M-parameter U-Nets on small synthetic images, suggesting potential for resource-constrained embedded applications. Key open questions include whether the saddle-point existence assumption can be relaxed (the paper shows saddle points need not exist in general), extending to submodular-submodular and weakly submodular cost functions, and exploring the connection to mixed-strategy Nash equilibria. The empirical validation is limited to 50×50 synthetic images, leaving scalability to real-world resolution untested.

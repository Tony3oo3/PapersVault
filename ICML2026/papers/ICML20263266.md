## Problem

Existing data visualization benchmarks are confined to idealized code sandboxes, evaluate only one-shot chart creation, and assume fully specified user intents, leaving three critical gaps unaddressed: native spreadsheet object-model manipulation, evolutionary adaptation of visualizations across frameworks, and proactive clarification under ambiguous real-world requests. DV-World targets these gaps by benchmarking agents on the full professional visualization lifecycle rather than isolated generation tasks.
![Teaser figure](../imgs/ICML20263266/cropped_page1_idx0.webp)

## Input / Output

DV-Sheet takes a natural-language instruction plus an initial Excel workbook and produces native chart objects with dynamic cell-range bindings (not hard-coded values) via openpyxl/xlwings; DV-Evol takes a reference chart image, a new dataset, and modification instructions, and outputs executable plotting code in one of five target languages (Python, Apache ECharts, Vega-Lite, D3.js, Plotly.js) alongside the resultant data table; DV-Inter takes an underspecified query over a tabular dataset and produces visualization code through multi-turn dialogue with a dual-stage user simulator that enforces a 'no-code-leak' gatekeeper before a grounded response generator. All outputs are evaluated against gold tables, gold plots, or original healthy workbooks rather than static rasterized references.

## Method

DV-World is a 260-task benchmark spanning three domains (DV-Sheet: 130 tasks for chart creation, diagnostic repair, and dashboard composition; DV-Evol: 80 tasks for cross-paradigm logic migration; DV-Inter: 50 tasks for interactive intent alignment), annotated by 18 visualization specialists using a controlled inverse-injection strategy for repair tasks and adversarial data perturbation for evolution tasks. Evaluation combines a quantitative Table-value Alignment protocol (tolerance-aware numeric matching) with a hierarchical MLLM-as-a-Judge system guided by expert-authored rubrics whose weights vary by task (e.g., Reliability 40% for creation, Integrity 25% for evolution, Interaction 24% for interaction). The DV-World-Agent baseline is a unified ReAct loop orchestrating bash, load_image, render_chart, and ask_user tools, while DV-Inter employs a two-stage user simulator where a security gatekeeper refuses code/schema extraction attempts and a grounded generator provides feedback constrained by hidden true intents and reaction rules. The framework is validated through human-model alignment studies (ICC(A,1)=0.932 for human-human, κ=0.821 for Gemini-2.5-Flash judge) and cross-judge ranking stability checks.

## Results

On DV-World (260 tasks), state-of-the-art models achieve below 50% overall performance across all three domains. In DV-Sheet, Gemini-3-Pro with the DV-World-Agent framework leads at 40.48%, while the SheetCopilot baseline caps at 38.01% for the same model. In DV-Evol, Gemini-3-Pro reaches 51.44% (DV-World-Agent) versus 48.32% (OpenHands baseline), with Python and Vega-Lite outperforming D3.js and Plotly.js. In DV-Inter, Grok-4 achieves the highest score of 40.43%, with most top-tier models failing to exceed 38.00%, and human evaluators scoring 79.60% on aesthetics alone.

## Baselines & Comparisons

The paper compares two existing agent frameworks as baselines: SheetCopilot (Li et al., 2023) for DV-Sheet and OpenHands (Wang et al., 2024) for DV-Evol. On DV-Sheet, the DV-World-Agent (a unified ReAct agent with bash, load_image, render_chart, and ask_user tools) consistently outperforms SheetCopilot: Gemini-3-Pro improves from 38.01% to 40.48% (+2.47), GPT-5.2 from 33.54% to 37.24% (+3.70), and Qwen3-235B-A22B from 15.64% to 17.89% (+2.25). On DV-Evol, DV-World-Agent similarly beats OpenHands: Gemini-3-Pro improves from 48.32% to 51.44% (+3.12), GPT-5.2 from 43.30% to 43.04% (−0.26, a slight loss), and Qwen3-VL-Plus from 28.79% to 29.33% (+0.54). The gains are most pronounced in Fix tasks (e.g., Gemini-3-Pro SR rises from 44% to 48%) and D3.js evolution (56.34% vs 50.78%), suggesting the ReAct orchestration with visual feedback tools is particularly effective for diagnostic repair and high-verbosity frameworks. However, all models remain far below human performance (88% SR on Fix, 85% TC on Evol), confirming that even the best agent configurations struggle with real-world DV workflows.

## Relation to Prior Work

This paper extends the DV benchmarking lineage (Plot2Code, ChartMimic, DA-Code, VisEval, Text2Vis, nvBench2.0, PlotCraft) by departing from the dominant code-sandbox, creation-only, fully-specified-intent paradigm. It builds on ReAct-style agent orchestration (Yao et al., 2022) and MLLM-as-a-Judge evaluation (Chen et al., 2024a), but introduces three orthogonal dimensions absent from prior work: native spreadsheet object-model manipulation (DV-Sheet), cross-paradigm logic evolution across five visualization frameworks (DV-Evol), and multi-turn interactive intent alignment with a dual-stage user simulator (DV-Inter). The hybrid evaluation protocol combining Table-value Alignment for numerical fidelity with expert-annotated rubric-based MLLM scoring is a methodological departure from the rule-based or single-metric approaches used in most prior DV benchmarks.

## Why It Matters / Open Questions

The benchmark exposes a substantial capability gap: even the strongest models (Gemini-3-Pro, GPT-5.2) peak below 52% across all three domains, while human evaluators score above 80%, indicating that current DV agents are far from enterprise-ready. The finding that performance degrades sharply with code complexity (LOC) and that the load_image tool is a critical compensatory mechanism for verbose frameworks like D3.js provides actionable diagnostic signals for agent developers. Open questions include whether the gap is primarily architectural (lack of native GUI grounding) or semantic (difficulty in cross-paradigm transfer and proactive ambiguity resolution), and whether scaling model size or adding more tool-use steps can close the 30+ point gap to human performance. The benchmark's interactive component with a security-aware user simulator also raises questions about robustness against adversarial agent behavior in real deployment settings.

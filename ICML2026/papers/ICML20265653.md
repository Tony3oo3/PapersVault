## Problem

Spatial proteomics analysis requires chaining 8+ specialized computational stages (illumination correction, registration, segmentation, quantification, clustering), but existing pipelines like MCMICRO and TRACERx-PHLEX are static, platform-specific workflows that cannot adapt to diverse analytical queries or handle the heterogeneity of real-world tissue data. No existing biomedical AI agent is capable of autonomously orchestrating the full end-to-end spatial proteomics pipeline from raw multiplexed imaging to phenotype discovery.

## Input / Output

SP-Mind accepts a single natural-language query (e.g., 'Stitch the 10 OME-TIFF cycles in /data/raw_cycles/ into a registered mosaic') alongside multiplexed tissue images in OME-TIFF format (multi-cycle, tiled mosaics of 10^3+ tiles), marker metadata CSVs, and cell quantification CSVs (~2M cells for annotation tasks). The agent operates within a sandboxed filesystem where it generates and executes arbitrary Python scripts, producing computational artifacts (corrected images, segmentation masks, quantification tables, UMAP plots) saved to user-specified directories, plus a natural-language analytical summary. Execution is bounded by a 30-minute timeout per query, and the agent must preserve input data integrity while writing outputs to exact requested paths.

## Method

SP-Mind implements a skill-augmented ReAct loop (observe → reason → execute) powered by Claude Sonnet 4, with three distinguishing architectural components. First, a modular tool library of 10+ spatial proteomics tools (BaSiC, ASHLAR, Coregraph, UnMicst, S3segmenter, MCQuant, Leiden/Phenograph) is encapsulated as Python functions with a container-agnostic execution bridge that auto-detects Docker/Apptainer/Singularity and returns structured research logs rather than raw exit codes. Second, expert-curated Spatial BioSkill Templates—structured Markdown documents encoding procedural knowledge (parameter heuristics, prerequisite checks, error recovery protocols) refined over 4 rounds on 150+ real tasks—are dynamically injected into the system prompt via keyword matching to provide task-conditional scaffolding without context dilution. Third, the execution phase uses a CodeAct-style paradigm where the agent generates and runs arbitrary Python scripts rather than being limited to predefined API schemas, enabling compositional analyses and on-the-fly data transformation. A data-first reasoning protocol instructs the agent to inspect data distributions before committing to analytical parameters, and a dual-layer memory architecture (conversational session state + persistent filesystem) supports multi-turn iterative refinement.

## Results

On SP-Bench (102 queries, 18 categories, 4 difficulty tiers), SP-Mind achieves 68.9% average execution accuracy, outperforming the strongest domain-adapted baseline Biomni-SP (55.4%) by 13.5 percentage points and generalist agents (AutoGen 14.7%, Biomni 19.3%, ToolUniverse 15.0%) by over 49 points. On the CRC-CODEX Quantification Challenge, SP-Mind attains the best scores across all five segmentation-tolerant metrics, including Pearson r = 0.953, Spearman ρ = 0.902, and the lowest MMD of 0.368. On the Cell Annotation Challenge (~2M cells across 4 datasets), SP-Mind achieves the highest average CyteOnto GHK similarity of 0.681, surpassing the specialized ASTIR model (0.440) by 0.241.

## Baselines & Comparisons

SP-Mind decisively outperforms all three generalist agent baselines (AutoGen 14.7%, Biomni 19.3%, ToolUniverse 15.0%) on SP-Bench, with the gap widening dramatically at higher difficulty tiers where generalists collapse to near-zero on Advanced and Challenging queries. Against the domain-adapted variants Biomni-SP (55.4%) and ToolUniverse-SP (50.5%), SP-Mind leads by 13.5 and 18.4 percentage points respectively, with the largest margin in the Advanced tier (61.9% vs. 36.5% for Biomni-SP). On the CRC-CODEX Quantification Challenge, SP-Mind achieves the best score on all five metrics, edging out ToolUniverse-SP (Spatial Spearman 0.513 vs. 0.482) and Biomni-SP (MMD 0.368 vs. 0.390). On Cell Annotation, SP-Mind (avg. 0.681) beats ASTIR (0.440) by a wide margin and outperforms all agentic baselines on average, though it underperforms Biomni-SP (0.706) and its own no-skill ablation (0.762) specifically on the PDAC_IMC dataset, indicating skill-template transfer limitations across imaging modalities.

## Relation to Prior Work

SP-Mind extends the ReAct reasoning loop (Yao et al., 2022) and CodeAct execution paradigm (Wang et al., 2024b) into the spatial proteomics domain, where prior work has been limited to either static, expert-configured pipelines (MCMICRO, TRACERx-PHLEX, MARQO) or general-purpose biomedical agents (BioMNI, ToolUniverse) that lack domain-specific tools and procedural knowledge. The key conceptual departure is the Spatial BioSkill Template mechanism: task-conditional injection of expert-curated chain-of-thought scaffolds that encode procedural knowledge (parameter heuristics, error recovery protocols, prerequisite dependencies) without requiring task-specific fine-tuning. This positions SP-Mind between the rigidity of fixed pipelines and the imprecision of generalist agents, introducing a structured knowledge-injection layer that neither prior paradigm provides.

## Why It Matters / Open Questions

SP-Mind and SP-Bench address a genuine gap: spatial proteomics is central to precision oncology and immunotherapy, yet no prior system could autonomously orchestrate the full 8-stage pipeline from raw imaging to cell population analysis. The primary limitation is the dependence on human-curated skill templates, which the paper acknowledges cannot yet be autonomously synthesized; the PDAC_IMC result (where skills actually hurt performance relative to the no-skill ablation) further reveals that curated knowledge does not transfer uniformly across imaging modalities. Open questions include whether autonomous skill synthesis can close the loop between exploration and knowledge consolidation, and whether the skill-template paradigm generalizes beyond spatial proteomics to other multi-stage scientific workflows.

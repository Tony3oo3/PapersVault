## Problem

Standard LLM leaderboards (e.g., LMArena) aggregate heterogeneous user feedback into a single Bradley-Terry quality score, implicitly assuming all comparisons come from an 'average' user. This collapses fundamentally different preference structures (e.g., safety vs. creativity) into one ranking, systematically excluding sizable user subgroups from the top of the leaderboard. The paper asks how to construct a single global ranking that fairly represents all sufficiently large, cohesive user subgroups.

## Input / Output

The method takes pairwise comparison queries as input, accessed adaptively through a sampling oracle over an underlying user distribution; each sampled user contributes only a limited number of pairwise comparisons (not full rankings), and the platform chooses which model pairs to present. The output is a full ranking of LLMs in which every top-k prefix satisfies approximate local stability (no outside model is collectively preferred by more than O(1/k) of users), along with intermediate approximately locally stable committees. Because the algorithms are online and adaptive, they cannot be run directly on static pre-collected datasets like the LMArena 140k release.

## Method

The core contribution adapts local stability from social choice committee elections to the sparse pairwise-comparison leaderboard setting. For committee selection (Algorithm 1), the paper extends the Iterated Rounding framework of Jiang et al. (2020) to a sampling-based model: over T = Õ(log k) rounds, it computes an approximately stable lottery (via Cheng et al.'s MWU procedure) over currently unsatisfied users, selects a sub-committee minimizing estimated unsatisfied probability, and geometrically shrinks the unsatisfied population. User satisfaction is estimated using only Õ(k) pairwise comparisons per user via a rank estimation oracle, yielding a (16+O(ε))-approximate stability guarantee. Two ranking constructions then lift committee guarantees to full rankings: Algorithm 2 uses geometrically sized checkpoint committees concatenated into blocks (giving λ²/(λ-1)·γ approximation), while Algorithm 3 uses a single-addition decomposition (k_t = 1 per round) to grow the committee one candidate at a time, naturally inducing a ranking by addition order with fewer total samples.

## Results

On synthetic mixtures of Mallows models (m=20 candidates), Algorithm 1 produces committees with stability approximation factor γ̂ substantially below the theoretical bound of 16+O(ε), often approaching 1 (the ideal stable threshold). On the LMArena-based semi-synthetic simulation (m=20 LLMs, 20 prompt-category Mallows centers), the Bradley-Terry ranking violates local stability (γ̂ > 1) for top-k prefixes at k=4,5 when φ=0.1 and k=5 when φ=0.5, while both Algorithm 2 (checkpoint-based) and Algorithm 3 (committee-monotonicity-based) maintain γ̂ ≤ 1 for all k and all dispersion levels. Algorithm 3 achieves slightly better empirical stability than Algorithm 2 despite lacking the stronger theoretical guarantee.

## Baselines & Comparisons

The primary baseline is the Bradley-Terry ranking used by LMArena (Chiang et al., 2024), which aggregates all pairwise comparisons into a single global quality score. On the LMArena simulation, Bradley-Terry violates local stability for specific prefix sizes: at φ=0.1 it fails at k=4 and k=5, and at φ=0.5 it fails at k=5, meaning a non-negligible fraction of users collectively prefer an excluded model over the entire top-k set. Both proposed ranking algorithms (Algorithm 2 and Algorithm 3) maintain stability (γ̂ ≤ 1) across all k values and all tested dispersion levels, directly addressing this failure. A secondary baseline, the 'Mallows centers' committee (top-ranked model from each mixture component), performs well at low dispersion (φ=0.1) but degrades and violates stability at φ=0.9, where user diversity within clusters makes the fixed centers insufficient. The paper also notes that Algorithm 3, while heuristic, empirically outperforms Algorithm 2 slightly in stability and requires fewer pairwise comparisons per user (median 5 vs. 24 in the LMArena simulation).

## Relation to Prior Work

This paper adapts the Iterated Rounding Algorithm for approximately stable committee selection (Jiang et al., STOC 2020) to the fundamentally different setting of sparse pairwise comparisons with a sampling oracle, rather than full user rankings. It uses the approximately stable lottery computation from Cheng et al. (ACM TEAC 2020) as a core subroutine, and lifts committee-level local stability guarantees (Aziz et al., 2017b) to full rankings via geometric checkpoints or committee monotonicity. The key conceptual departure from prior social choice work is the move from complete preference profiles to the online, pairwise-comparison-only access model that characterizes real LLM leaderboard platforms like LMArena.

## Why It Matters / Open Questions

The paper demonstrates that the Bradley-Terry aggregation used by LMArena can systematically exclude large user factions from top-k prefixes, and provides a principled social-choice-based alternative requiring only Õ(k) comparisons per user. Open questions include extending the framework to prompt-dependent preferences, handling offline/pre-collected datasets where adaptive sampling is unavailable, and achieving stronger proportional representation guarantees (the paper shows PSC is impossible to verify with k-wise comparisons). For LLM evaluation practitioners, this reframes leaderboard design as a fair-representation problem rather than a pure statistical estimation problem, though the algorithms' complexity and adaptive-sampling requirements limit near-term deployment.

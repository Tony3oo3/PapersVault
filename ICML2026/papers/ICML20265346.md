## Problem

Linear State-Space Models for 3D point clouds must force unordered point sets into 1D sequences, but the resulting artificial causality disrupts local spatial neighborhoods and injects directional noise into global semantic aggregation—a conflict the authors term serialization bias. Existing mitigations like multi-view Mamba scanning (6+ passes) undermine the O(N) efficiency advantage that motivates SSMs in the first place. The paper asks whether the role of serialization should instead depend on the geometric density of the input, rather than being applied uniformly.
![Teaser figure](../imgs/ICML20265346/cropped_page0_idx1.webp)

## Input / Output

The method consumes 3D point clouds of varying density: dense indoor scenes (~100K points per room on S3DIS/ScanNetV2) and sparse object scans (~2K points on ScanObjectNN). For dense scenes, points are processed in the default preprocessing/loading order (Identity Mode) without any geometry-driven re-serialization; for sparse objects, Morton serialization is applied to inject a lightweight spatial prior. Outputs are per-point semantic class labels for segmentation tasks and a single object class label for classification, with the model operating at O(N) complexity via chunk-wise scans (default max chunk size 30K).

## Method

AnIsoNet decouples local anisotropic geometry from global isotropic semantics into two modules. LAGM captures directional local structure via Ellipsoidal Spectral Encoding: each feature channel is a learnable ellipsoidal prototype (orientation + axis scales + offset) that measures how well k-NN neighbor offsets match an anisotropic pattern, followed by geometry-gated max aggregation on the k-NN graph—entirely independent of any global ordering. GISA performs global semantic aggregation using a dimension-wise vector state (O(D) rather than O(D²) matrix state) updated via content-based gated accumulation where retrieval is driven by query-state matching rather than sequence position. The GISA mode is configured at the dataset level by a normalized neighborhood-density statistic: dense scenes (σ̂k ≈ 0.004–0.006) use Identity Mode to avoid harmful re-serialization, while sparse objects (σ̂k ≈ 0.025) use Morton Mode to retain a useful spatial prior. This yields 82.62% mIoU on S3DIS with only 12.2M parameters and 37G FLOPs on a single GPU.

## Results

On S3DIS Area 5, AnIsoNet achieves 82.62% mIoU, surpassing the strongest SSM baseline PCM (79.6%) by 3.0% and PTv3 (73.4%) by 9.2%. On ScanNetV2, it reaches 78.52% mIoU, exceeding PTv3 (77.5%) by 1.0% without external pre-training. On ScanObjectNN (PB_T50_RS), it attains 94.21% OA and 93.41% mAcc, outperforming Mamba3D (92.64%) by 1.6% and PointRWKV (93.63%) by 0.6%. The model uses only 12.2M parameters and 37G FLOPs, compared to PTv3's 46.2M parameters and 180G FLOPs.

## Baselines & Comparisons

AnIsoNet outperforms all compared methods on S3DIS Area 5, with the largest margins over SSM-based baselines: +3.0% over PCM (which uses 6× multi-view serialization) and +12.5% over PointMamba. Against Transformer-based methods, it exceeds PTv3 by 9.2% and Stratified Transformer by 4.5%, while using only 12.2M parameters versus PTv3's 46.2M. On ScanNetV2, AnIsoNet (78.52%) beats PTv3 (77.5%) by 1.0% without pre-training, though Sonata(dec.) (79.1%) edges it by 0.6% using quadratic decoder attention plus large-scale external pre-training. On ScanObjectNN, Morton Mode yields 94.21% OA, surpassing PointRWKV (93.63%) by 0.6%, Mamba3D (92.64%) by 1.6%, and PCM (88.1%) by 6.1%. The efficiency advantage is notable: AnIsoNet runs on a single RTX 3090 with 37G FLOPs, versus PTv3's 180G FLOPs on 8×A100 and PCM's 95G FLOPs on 4×3090.

## Relation to Prior Work

AnIsoNet builds on the hierarchical local-aggregation encoder of DeLA (Chen et al., 2023) and adapts the dimension-wise gated accumulation mechanism from Gated Linear Attention / DeltaNet (Yang et al., 2024), replacing the matrix state with a vector state to reduce complexity from O(D²) to O(D). Its central conceptual departure is from the 3D SSM line (PointMamba, PCM, Mamba3D), which all force point clouds into 1D sequences via space-filling curves; the paper argues that the causal recurrence of SSMs makes this serialization harmful in dense scenes, unlike in PTv3 where SFCs serve only as locality-preserving hashing for patch construction. The decoupling of local anisotropic geometry (Ellipsoidal Spectral Encoding on k-NN graphs) from global isotropic semantics (GISA with dataset-aware Identity/Morton mode) is the paper's key architectural reframe.

## Why It Matters / Open Questions

The finding that simply avoiding geometry-driven re-serialization (Identity Mode) outperforms Hilbert or Morton curves by ~8 mIoU points on dense S3DIS challenges the near-universal assumption in 3D SSMs that some spatial ordering is always beneficial, and the cross-regime ablation (Morton helps sparse objects by 1.7 pts but hurts dense scenes) provides a practical, density-based decision rule. The efficiency profile—12.2M parameters, 37G FLOPs, single RTX 3090—makes the approach attractive for deployment where multi-GPU or multi-view scanning is infeasible. Key open questions include whether the dataset-level mode preset can be replaced by dynamic per-sample switching, whether the framework generalizes to outdoor LiDAR with very different density distributions, and whether self-supervised pretraining synergizes with the decoupled architecture.

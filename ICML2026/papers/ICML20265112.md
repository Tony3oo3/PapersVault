## Problem

Agent memory systems must scale to accommodate continuously growing information while preserving the fine-grained details needed for precise reasoning, yet existing designs collapse into one of two extremes—storing raw fragments or atomic facts (which fragment and lose narrative coherence) or coarse summaries (which strip task-critical nuance). This representational gap leaves no structured link between high-level concepts and low-level details, crippling retrieval for long-horizon multi-hop reasoning.

## Input / Output

The system ingests a continuous stream of heterogeneous data (multi-turn conversations, documents, logs, code) that is first segmented into semantically coherent units, each paired with an episodic memory capturing narrative context (participants, intent, temporal scope). At query time, a text query is jointly matched against primary abstractions and cue anchors under a finite retrieval budget, and the output is a compact working set of memory entries—each comprising a primary abstraction, a concrete memory value, and associated cue anchors—along with their episodic contexts, ready for downstream answer generation.

## Method

MEMORA introduces a dual-layered harmonic representation: primary abstractions serve as stable canonical identities that consolidate related and evolving information into unified memory entries via a creator-update rule (similarity-thresholded matching followed by LLM-based merge-or-create), while cue anchors are lightweight, fine-grained semantic hooks that create many-to-many connectivity across entries without requiring a fixed ontology or explicit edge construction. At retrieval time, the process is formulated as a Markov Decision Process with three atomic actions—REFINE (reformulate the query), EXPAND (pull memories from the frontier of cue-anchor-linked candidates), and STOP—allowing the agent to actively navigate the implicit memory graph beyond direct semantic similarity. The retrieval policy can be optimized via Group-Relative Policy Optimization (GRPO), which samples groups of retrieval trajectories per query, scores them with a trajectory-level judge, and updates the policy using zero-mean group-relative advantages. Theoretically, the paper proves that flat RAG and KG-based retrieval emerge as degenerate special cases of this framework, while MEMORA supports richer mixed-key retrieval (joint abstraction-and-cue intersection constraints) that neither can express under standard structural assumptions.

## Results

On LoCoMo, MEMORA with the Policy Retriever achieves an overall LLM-as-a-Judge score of 0.863, surpassing Full Context (0.825), Nemori (0.794), Mem0 (0.653), and RAG (0.633). On LongMemEval (115k context), MEMORA(P) reaches 87.4% average accuracy versus 74.6% for Nemori and 65.6% for Full Context. The Semantic Retriever variant (MEMORA(S)) also outperforms all baselines at 0.849 on LoCoMo and 83.8% on LongMemEval, while reducing token consumption by up to 98% compared to full-context processing.

## Baselines & Comparisons

MEMORA outperforms all five baselines across every task category on LoCoMo. Against RAG (Lewis et al., 2021), MEMORA(P) gains +23.0 points overall (0.863 vs. 0.633), with the largest gap in multi-hop reasoning (+23.0) and temporal reasoning (+31.8). Against HippoRAG (Gutierrez et al., 2024), the advantage is even more pronounced at +39.2 points overall, reflecting HippoRAG's weakness on temporal tasks (0.224 vs. 0.866). Against Zep (Rasmussen et al., 2025), MEMORA leads by +24.7 points, particularly on multi-hop (+25.0) and open-domain (+15.6). Against Mem0 (Chhikara et al., 2025), MEMORA gains +21.0 points overall; the ablation in Table 3 confirms that removing MEMORA's primary-abstraction layer reduces it to Mem0's performance (0.653). Against Nemori (Nan et al., 2025), the closest competitor, MEMORA still leads by +6.9 points on LoCoMo and +12.8 points on LongMemEval (87.4% vs. 74.6%), with the largest margins on temporal reasoning (+9.0) and multi-session tasks (+22.6). Notably, MEMORA also surpasses the Full Context baseline (0.825), demonstrating that structured memory retrieval is more effective than brute-force context reconstruction.

## Relation to Prior Work

MEMORA builds on the agent memory management literature (MemGPT, MemOS, Mem0, Nemori) and graph-based retrieval (HippoRAG, Zep, GraphRAG), but departs from all of them by decoupling what is stored (rich, unfragmented memory values) from how it is accessed (a structural layer of primary abstractions and cue anchors). Conceptually, it unifies the RAG and KG paradigms under a single framework, showing both emerge as degenerate special cases, and borrows the GRPO preference-optimization formulation from Shao et al. (2024) to train a sequential retrieval policy over an MDP. The key architectural departure from prior work is the two-level indexing: primary abstractions provide stable consolidation (avoiding Mem0-style fragmentation) while cue anchors provide many-to-many cross-memory connectivity (avoiding KG-style rigid schemas).

## Why It Matters / Open Questions

The paper demonstrates that a well-structured memory representation can outperform full-context inference (86.3% vs 82.5% on LoCoMo) while reducing token consumption by up to 98%, which is practically significant for long-horizon agent deployments where context windows are a hard constraint. The ablation cleanly isolating cue anchors as the mechanism enabling the policy retriever's advantage over semantic search provides actionable design guidance. Open questions include how the approach scales to memory stores with millions of entries (the theoretical efficiency bound requires B² > mN, a strong condition), whether the GRPO-trained policy generalizes beyond LoCoMo's conversational domain, and whether the 45% construction-time speedup from offset prediction holds for more complex data types beyond dialogue.

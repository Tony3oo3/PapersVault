## Problem

Existing agent memory systems restrict retrieval to a single episode-initiation event, forcing agents to rely on static guidance that becomes increasingly misaligned as long-horizon tasks unfold. This rigidity prevents agents from recovering from intermediate failures or adapting to shifting sub-goals without expensive online parameter updates. The paper asks how agent memory can enable continuous, step-wise test-time adaptation while maintaining token efficiency.
![Teaser figure](../imgs/ICML20265828/cropped_page0_idx0.webp)

## Input / Output

The agent receives the full interaction history (task description, prior observations and actions) as its state representation, which is embedded via Qwen3-Embedding-4B for dense retrieval against a long-term memory of successful trajectories. At each decision step, the agent outputs a binary retrieval/refresh decision, a concise 1–3 bullet natural-language strategy (the short-term memory), and a final action. Two inference modes control the strategy's lifetime: ADAMEM-HIGH discards the strategy after each step (transient), while ADAMEM-LOW persists it across steps and only regenerates when the agent triggers a refresh.

## Method

ADAMEM decouples memory storage from abstraction through a hybrid architecture: a static long-term trajectory memory (indexed by state embeddings, populated offline with successful trajectories) and a dynamic short-term strategy memory synthesized on-the-fly by conditioning the policy on the current state plus retrieved experiences. At inference, the agent retrieves top-k experiences, synthesizes a state-specific strategy via a dedicated prompt, and generates its action conditioned on that strategy—without any parameter updates. To improve strategy quality, STEP-MFT applies rejection sampling fine-tuning with a dual-filter (trajectory success + action change relative to a memory-free baseline) to retain only strategies that causally altered the agent's decision, then trains via standard cross-entropy SFT. This process-level filtering avoids the noise of outcome-only supervision and the cost of auxiliary value models or Monte Carlo rollouts, yielding a single unified model that handles both strategy synthesis and action generation.

## Results

Under the training-free setup, ADAMEM-LOW achieves 54.0% success rate on ALFWorld seen and 58.2% on unseen (Qwen3-4B-Instruct), surpassing the strongest static baseline Synapse (52.1/52.2) by +1.9 and +6.0 points respectively. On WebShop (off-policy, Gemma-3-27b-it), ADAMEM reaches a task score of 24.7, a +6.5 point gain over the memory-free baseline (18.2). On HotpotQA (cross-episode agentic search), ADAMEM achieves 41.1% success rate, the best among all methods. With the STEP-MFT fine-tuning variant, relative gains extend to up to 17% on ALFWorld and 13% on WebShop over static memory baselines.

## Baselines & Comparisons

ADAMEM outperforms all three baselines across every benchmark. Against No Memory (ReAct), ADAMEM-LOW gains +8.8 points on ALFWorld seen, +11.4 on unseen, and +6.5 on WebShop. Against Synapse (static trajectory retrieval at episode start), ADAMEM wins by +1.9 (ALFWorld seen), +6.0 (unseen), and +2.1 (WebShop); notably, Synapse suffers negative transfer on WebShop, scoring 22.6 versus the memory-free 18.2 only because the uninformative homepage state retrieves noisy trajectories. Against ReasoningBank (offline strategy distillation), ADAMEM leads by +4.7 (ALFWorld seen), +7.0 (unseen), and +6.1 (WebShop); ReasoningBank also underperforms No Memory on WebShop (18.6 vs. 18.2), confirming that pre-computed strategies cannot adapt to mid-episode state shifts. On HotpotQA, ADAMEM (41.1%) edges out ReasoningBank (40.5%) and Synapse (40.4%), with the margin being smaller due to the shorter per-episode horizon. The off-policy setting further validates cross-model generalization: Gemma-3-27b-it using Qwen-constructed memory still achieves the best scores, whereas Synapse degrades to 30.6% on ALFWorld unseen (below No Memory's 37.6%), highlighting the fragility of static trajectory injection across model families.

## Relation to Prior Work

ADAMEM extends the agent memory line of work (Synapse, ReasoningBank, Voyager) by decoupling long-term trajectory storage from short-term strategy synthesis, moving retrieval from a one-shot episode-initiation event to a step-wise, state-conditioned process. The training component, STEP-MFT, builds on rejection sampling fine-tuning (Yuan et al., 2023) but introduces a process-level 'action change' filter as a critic-free proxy for strategy advantage, departing from standard outcome-based filtering. Conceptually, the paper positions itself against the 'static prior' paradigm where memory is pre-computed before the task begins, arguing that online synthesis conditioned on the current state is necessary to handle mid-episode distribution shifts.

## Why It Matters / Open Questions

The framework establishes test-time compute as a controllable scaling axis for agent memory, with a clear LOW/HIGH/MFT spectrum that practitioners can tune. Two findings carry broader implications: (1) static memory can cause negative transfer (WebShop), warning against unconditionally injecting retrieved context, and (2) ungrounded strategy synthesis without external trajectory memory performs worse than no memory at all, suggesting self-generated guidance without empirical grounding is actively harmful. Open questions include mitigating strategy inertia (the agent rationalizing failure as incomplete exploration), leveraging failure trajectories in the memory bank, and whether full memory-augmented RL could further improve adaptation.

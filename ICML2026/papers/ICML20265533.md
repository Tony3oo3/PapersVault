## Problem

Existing heterogeneous federated learning methods enable collaboration by sharing model parameters, intermediate representations, or prediction outputs, which risks leaking sensitive data or model information and incurs non-trivial communication overhead. The paper asks how agents with heterogeneous architectures and non-IID data can effectively exchange social knowledge while keeping both raw data and local model parameters strictly on-device.
![Teaser figure](../imgs/ICML20265533/cropped_page0_idx0.webp)

## Input / Output

Each agent receives RGB images (32×32 CIFAR-100 or 64×64 Tiny-ImageNet) and produces a class label via its own heterogeneous CNN. The critical I/O detail is that cross-agent communication is restricted to a single compact memory vector of shared dimension m (e.g., 128) per round per agent; no model weights, intermediate feature maps, or raw pixels ever leave the device. The server maintains and broadcasts one collective memory vector of the same dimension m.

## Method

SoHip replaces parameter or representation sharing with a four-stage memory pipeline. (1) A lightweight linear encoder projects each agent's local CNN features into a shared m-dimensional space, batch-averages them, and applies a sigmoid gate to produce a gated short-term memory. (2) An LSTM-inspired hippocampus consolidation module uses input, forget, and output gates to selectively merge the new short-term memory with the agent's historical long-term memory. (3) A fusion gate controls how much of the server-broadcast collective long-term memory the agent absorbs, and the resulting complete memory is decoded back to the local feature dimension and added residually to the original representations before classification. (4) The server forms the next collective memory by a weighted sum of uploaded individual long-term memories. Theoretically, the paper proves an O(1/√T) convergence rate with an additive heterogeneity term and argues intrinsic privacy since only dimension-reduced, temporally aggregated memory vectors are transmitted.

## Results

On CIFAR-100 (N=200, C=10%), SoHip achieves 54.33% average test accuracy, outperforming the strongest baseline FedMRL (48.77%) by +5.56%. On Tiny-ImageNet (N=100, C=10%), the improvement is even larger at +8.78% (46.20% vs. FedMRL's 37.42%). SoHip maintains its lead across all agent counts (N=100, 200, 300) on both datasets, with the gap widening as the number of agents increases, and it also converges faster than all baselines as shown in the training curves.

## Baselines & Comparisons

SoHip outperforms all six baselines across every evaluated setting (both datasets, all agent counts). The strongest competitor is FedMRL (matryoshka representation learning), which SoHip beats by +3.07% on CIFAR-100 (N=100), +5.56% on CIFAR-100 (N=200), and +8.78% on Tiny-ImageNet (N=100). Among intermediate-representation-sharing methods, FedRAL is the closest to SoHip on CIFAR-100 (N=300: 44.62% vs. 50.10%), while FedProto and FedSSA trail by 5–10 points. Auxiliary-model methods (FedKD, pFedES) perform substantially worse, with FedKD achieving only 26.56% on CIFAR-100 (N=300) and 13.37% on Tiny-ImageNet (N=300), suggesting that knowledge distillation through a shared homogeneous model is poorly suited to highly heterogeneous settings. The Standalone (no-collaboration) baseline confirms that memory-based social learning provides consistent gains over isolated training, with the advantage growing as the number of agents increases.

## Relation to Prior Work

SoHip builds on federated learning (McMahan et al., 2017) as its collaboration substrate but departs fundamentally from existing heterogeneous FL approaches that exchange model parameters, intermediate representations (FedProto, FedSSA, FedRAL), or auxiliary homogeneous models (FedKD, FedMRL, pFedES). Instead, it introduces compact memory vectors as the sole carrier of social knowledge, drawing a conceptual analogy to the hippocampus's role in consolidating short-term experience into long-term memory. The paper positions this within the broader 'social machine learning' paradigm (Yao et al., 2024), framing FL as one instantiation and arguing that memory-based exchange better captures the abstraction-and-reuse dynamics of social learning than direct parameter or feature sharing.

## Why It Matters / Open Questions

The memory-centric design offers a practical path for heterogeneous FL deployments where both data privacy and model autonomy are critical, since only m-dimensional gated vectors are transmitted rather than full model weights or intermediate features. However, the privacy guarantee is architectural (dimensionality reduction + nonlinearity + temporal aggregation) rather than formal (no DP or cryptographic guarantees), and the 'hippocampus-inspired' consolidation is mechanistically an LSTM-style gated update, limiting the biological analogy's depth. Open questions include whether the approach scales to transformer-based or multimodal models, how it behaves under extreme model heterogeneity (e.g., different input modalities), and whether the fixed memory dimension m can be made adaptive per agent or per round.

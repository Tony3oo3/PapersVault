## Problem

Existing differentially private approaches for LLM preference alignment protect only part of the data (either prompts or preference labels), are tied to specific alignment algorithms like PPO, and are constrained by the limited size of private preference datasets. No prior work generates a fully DP synthetic preference dataset that is reusable across multiple alignment methods and downstream LLMs without incurring additional privacy cost.
![Teaser figure](../imgs/ICML20261234/cropped_page2_idx0.webp)

## Input / Output

The method consumes a private preference dataset of (prompt, preferred response, dispreferred response) triplets, a set of public prompts (e.g., from Alpaca or XSum), and an LLM API for generating candidate responses. It produces a DP synthetic preference dataset where prompts are drawn from the public set and preference pairs are constructed by selecting the highest- and lowest-scoring LLM-generated candidates under a DP-trained reward model. Because the output is a dataset rather than a model, it can be reused across SFT, DPO, PPO, and different downstream LLMs at zero additional privacy cost via the DP post-processing property.

## Method

DPRefSyn grounds its design in the Bradley-Terry model with a linear reward structure r_θ(x,a) = ⟨θ, φ(x,a)⟩, which implies that annotators with similar preferences produce embedding-difference vectors pointing in similar directions. The algorithm proceeds in three steps: (1) compute embedding differences d_i = ψ(x_i, a_i^+) − ψ(x_i, a_i^−), reduce dimensionality via DP-PCA, and cluster via DP-KMeans; (2) train a per-cluster linear reward model θ_k using DP-SGD with parallel composition (since clusters are disjoint, the total privacy cost is bounded by the smallest cluster); (3) for each public prompt, generate L candidate responses with an LLM, sample a cluster index from the DP histogram, score candidates with the corresponding θ_k, and select the argmax/argmin as the synthetic preference pair. A key design choice is using public prompts to avoid spending privacy budget on prompt synthesis, concentrating the entire ε on modeling private preference structure. The full pipeline satisfies (ε,δ)-DP with the budget split as ε_0 for DP-PCA, ε_1 for DP-KMeans, and the remainder for DP-SGD composed via the PRV accountant.

## Results

On the three evaluation tasks (OpenAssistant QA, Anthropic-HH QA, TL;DR summarization), DPRefSyn consistently outperforms DP-FT (fine-tuning on real private data with DP-SGD) across all privacy budgets ε ∈ {0.5, 1, 2, 4, 8}. At the headline setting ε=2, DPRefSyn achieves 11.04% win rate (SFT+DPO) on OpenAssistant vs. 6.18% for DP-FT, 56.48% on Anthropic-HH vs. 37.02%, and 68.54% on TL;DR vs. 62.02%. Remarkably, DPRefSyn also surpasses the non-private baseline (DP-FT with ε=∞) on OpenAssistant (11.04% vs. 8.20%) and Anthropic-HH (56.48% vs. 38.72%), demonstrating that synthetic data from a strong LLM generator provides higher-quality supervision than the original private data.

## Baselines & Comparisons

The primary baseline is DP-FT, which fine-tunes the downstream LLM directly on the real private preference data using DP-SGD (Abadi et al., 2016). DPRefSyn wins decisively across all three tasks and all tested privacy budgets: at ε=2, it achieves roughly 2× the win rate of DP-FT on OpenAssistant (11.04% vs. 6.18%) and Anthropic-HH (56.48% vs. 37.02%), and a 6.5-point gain on TL;DR (68.54% vs. 62.02%). A second important comparison is against the non-private upper bound (DP-FT with ε=∞, i.e., standard fine-tuning without DP noise): DPRefSyn at ε=2 already exceeds this bound on OpenAssistant (11.04% vs. 8.20%) and Anthropic-HH (56.48% vs. 38.72%), attributed to the higher-quality candidate responses generated by a strong LLM (LLaMA-7B-chat) during synthesis. The paper also reports that DPRefSyn is more robust to DP noise than DP-FT (e.g., on Llama-3-8B, DP-FT drops from 59.13% to 45.79% as ε goes from ∞ to 4, while DPRefSyn drops only from 61.52% to 60.25%), and that DPRefSyn's synthetic data is reusable across multiple alignment methods (SFT, DPO, PPO) and downstream LLMs without additional privacy cost, unlike DP-FT which consumes the budget per model.

## Relation to Prior Work

This paper sits at the intersection of DP synthetic data generation (Xie et al., 2024; Lin et al., 2023) and preference alignment (RLHF/DPO), but specifically targets the pairwise preference data structure rather than general text. Prior DP alignment work either protects only part of the data (prompts in Yu et al., 2024; labels in Chowdhury et al., 2024; Zhang et al., 2025), is tied to a specific alignment algorithm (DP-PPO in Wu et al., 2023a), or is constrained by limited private annotations. DPRefSyn departs from all of these by generating a fully private synthetic preference dataset via the post-processing property of DP, making it reusable across alignment methods (DPO, PPO, SFT) and downstream LLMs without additional privacy cost. The algorithmic design draws on the Bradley-Terry model with a linear reward structure, DP-PCA for dimensionality reduction, DP-KMeans for capturing preference heterogeneity, and the PRV accountant for tight privacy composition.

## Why It Matters / Open Questions

This is the first work to generate DP synthetic preference data for LLM alignment, and the finding that such synthetic data can outperform non-private fine-tuning on real data (e.g., 56.48% vs. 38.72% win rate on Anthropic-HH) challenges the assumption that privacy necessarily degrades utility. The reusability of the synthetic dataset across methods and models is a practical advantage over DP-FT, which consumes the privacy budget per model. Limitations include the requirement for LLM API access (cost), English-only focus, and evaluation on models up to 8B parameters. Open questions include extension to multilingual and multimodal settings, scaling to larger models, and whether the linear reward assumption holds for more complex preference structures.

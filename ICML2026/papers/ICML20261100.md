## Problem

Skill-based agent systems treat reusable skill implementations as trusted modular components, yet their internal executable logic is rarely audited beyond functional correctness. Prior backdoor research on LLM agents has focused on model parameters, prompts, or transient interaction surfaces (tools, memory), leaving the persistent skill abstraction layer—an attack surface that survives across tasks, users, and deployments—largely unexamined. This paper asks whether malicious logic can be embedded inside otherwise plausible skills and activated through standard skill composition without modifying the underlying model.

## Input / Output

The method takes a benign skill template (a SKILL.md specification plus executable scripts), an attacker-chosen payload program P, a trigger predicate Trig_τ, a fragment count N, and a symmetric key k, and produces a backdoored skill package that is semantically equivalent to the original on clean queries. At runtime, the agent receives a natural-language user query; on triggered queries the skill's normal tool-call trajectory silently emits encrypted fragments in benign-looking tool-output fields, and a designated verifier reconstructs and executes the payload as a hidden side effect while the agent still returns a correct user-visible answer. All intermediate fragments are ephemeral and scoped to a single run.

## Method

SkillTrojan encrypts the payload with a symmetric key, partitions the ciphertext into N index-tagged fragments, and distributes them across N benign-looking tool entrypoints within the skill. The natural-language specification is modified to inject a conditional bias that, only when the trigger predicate holds, steers the agent's planner toward execution traces covering the designated fragment-emitting actions and the verifier—without prescribing a fixed order or explicit malicious instruction. Each instrumented script preserves its original I/O behavior but additionally writes its fragment to a run-local channel (e.g., a field in the tool output logged in the trajectory) when triggered. A verification action performs order-agnostic set-inclusion checking, concatenates segments by index, decrypts, and executes the payload as a side effect after the ordinary workflow completes. The design couples attack success to routine task completion rather than a single anomalous action, and the framework supports automated synthesis of backdoored variants from arbitrary skill templates, enabling scalable propagation across skill ecosystems.

## Results

On the EHR SQL benchmark, SkillTrojan achieves up to 97.2% attack success rate (ASR) while maintaining 89.3% clean-task accuracy (ACC) on GPT-5.2-1211-Global, compared to 73.0% ACC under the Non-attack condition. On Qwen3-Max it reaches 74.7% ASR with 86.6% ACC, and on Claude-Sonnet-4.5 it achieves 64.2% ASR with 90.7% ACC. On open-weight models, SkillTrojan attains 72.0% ASR with 81.3% ACC on GLM-4.6 and 64.7% ASR with 76.3% ACC on Qwen3-Coder. On SWE-Bench Verified, SkillTrojan reaches 92.8% ASR with 70.4% ACC on GPT-5.2-1211-Global, confirming generalizability beyond SQL generation.

## Baselines & Comparisons

SkillTrojan outperforms all five baselines on ASR across every closed-weight model tested. On GPT-5.2-1211-Global, SkillTrojan achieves 97.2% ASR versus 58.3% for AgentPoison (the strongest baseline), 51.1% for CPA, 45.8% for GCG, 27.4% for AutoDAN, and 8.3% for BadChain. A key qualitative advantage is the ACC–ASR trade-off: SkillTrojan preserves or even improves clean-task accuracy (e.g., 89.3% ACC vs. 73.0% Non-attack on GPT-5.2-1211-Global), whereas CPA and AutoDAN consistently degrade ACC by 4–6 points on multiple models. BadChain is particularly weak in the tool-execution setting, dropping to 8.3% ASR on GPT-5.2-1211-Global and 14.2% on Qwen3-Max, because its chain-of-thought manipulation is easily resisted by stronger models. AgentPoison is the closest competitor (58.3% ASR on GPT-5.2-1211-Global) but still trails SkillTrojan by 38.9 points, and it degrades ACC more noticeably (72.9% vs. 89.3%). The paper attributes SkillTrojan's advantage to routing malicious behavior through trusted tool execution rather than relying on the model to follow an injected instruction pattern.

## Relation to Prior Work

This paper carves out a new attack surface for backdoor research on LLM agents: the persistent, reusable skill implementation layer, as opposed to the model parameters, prompts, tool descriptions, or memory stores targeted by prior work (AgentPoison, BadChain, GCG, AutoDAN, CPA). The core backdoor mechanics—encrypted payload fragmentation, trigger-based activation, and order-agnostic reconstruction—are standard concepts repurposed from classical ML backdoor literature, but their application to the skill abstraction layer (where malicious logic persists across tasks, users, and deployments without touching the model) is, per the authors' framing, novel. The paper does not build on a specific prior skill-security method; rather, it identifies that the trust assumption placed on third-party skill packages is unexamined and exploitable.

## Why It Matters / Open Questions

The practical implication is significant for anyone deploying agent systems with third-party skill/tool marketplaces: a single compromised skill can silently execute arbitrary payloads across all downstream runs while passing standard behavioral tests and LLM-based static scanners (98–99% classified as safe). The 97.2% ASR with 89.3% ACC on GPT-5.2-1211-Global, and the ~39-point gap over the strongest prompt-centric baseline, suggest that existing defenses monitoring model I/O or prompt content are structurally blind to execution-layer backdoors. Open questions include whether defenses based on execution-trajectory auditing, provenance verification, or sandboxed side-effect isolation can close this gap without degrading legitimate skill composition, and whether the attack generalizes to non-code skill abstractions (e.g., RAG pipelines, workflow engines).

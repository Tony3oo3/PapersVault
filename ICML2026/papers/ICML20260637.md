## Problem

Model-based offline RL methods rely on ensemble-based uncertainty estimation to introduce conservatism, but these uncertainty estimates are shown to be inaccurate and unreliable on complex datasets. Prior approaches use the offline data for a single purpose (training an ensemble model) and then apply ad-hoc, post-hoc adjustments to model predictions, rather than proactively improving model accuracy during training.
![Teaser figure](../imgs/ICML20260637/cropped_page1_idx1.webp)

## Input / Output

The method consumes a fixed offline dataset of transitions (s, a, r, s') collected by an implicit behavior policy, with no online environment interaction. It produces a learned Gaussian dynamics model P_θ(s', r | s, a) that can be plugged into any existing planner (SAC, TD-MPC, etc.) to extract a policy. The data is exploited in two complementary ways simultaneously: directly for value function regression and for model likelihood training, which is the key structural difference from prior single-use approaches.

## Method

VIPO introduces a value function inconsistency loss that penalizes the discrepancy between a value function V_d^μ learned directly from the dataset via mean-squared Bellman error and a value function V_m^μ estimated through the learned dynamics model. The augmented model loss combines the standard negative log-likelihood with λ·L_vic, and the paper derives an exact gradient (Theorem 4.5) by recursively unrolling the Bellman backup to track how model parameters affect the value function across multiple transitions. In practice, a surrogate gradient replaces the expensive model-induced state visitation distribution with the empirical data distribution, enabling efficient training with standard gradient descent. The approach is model-agnostic and planner-agnostic: it only replaces the dynamics model training step in existing methods (MOPO, MOBILE, LEQ), and a theoretical error bound (Theorem 4.4) decomposes model learning error into generalization and alignment bias terms that vanish as N→∞.

## Results

On the D4RL Gym benchmark (12 MuJoCo tasks), VIPO-MOBILE achieves an average normalized return of 83.6, outperforming the prior SOTA MOBILE (80.0), DQL (70.4), and MOPO* (70.3). On the more challenging NeoRL benchmark, VIPO-MOBILE reaches 73.3 average, surpassing MOBILE by over 20% (60.7) and MOPO by 2.6× (28.5). In terms of model accuracy, VIPO reduces the average predictive error from 0.173±0.026 (original loss) to 0.121±0.015, a ~30% relative reduction across all D4RL Gym tasks.

## Baselines & Comparisons

VIPO-MOBILE wins on 11 out of 12 D4RL Gym tasks, with the only exception being hopper-m-r where it ties MOBILE (109.6 vs 103.9 — actually a win). The largest margins are on walker2d-m-r (+8.5 over MOBILE), walker2d-m (+5.4), and halfcheetah-m-r (+5.5). Against model-free baselines, VIPO-MOBILE dominates: it outperforms DQL (70.4 avg) by 13.2 points, CQL (61.6) by 22.0, IQL (60.6) by 23.0, and TD3+BC (54.6) by 29.0. On NeoRL, VIPO-MOBILE (73.3) beats MOBILE (60.7) by 12.6 points and MOPO (28.5) by 44.8 points, with particularly large gains on Hopper-L (30.7 vs 17.4) and Walker2d-L (67.6 vs 37.6). On AntMaze, VIPO-LEQ (64.9 avg) improves over LEQ (61.0) and IQL-TD-MPC (36.6), while MOBILE fails entirely (0.0). The model predictive error experiment confirms that VIPO's dynamics model is intrinsically more accurate than the original-loss model used by MOPO, MOReL, and MOBILE, reducing average MSE from 0.173 to 0.121 (~30% reduction).

## Relation to Prior Work

VIPO builds on the model-based offline RL lineage (MOPO, MOReL, MOBILE, COMBO, RAMBO, LEQ) that learns ensemble dynamics models and applies uncertainty-based pessimism as a post-hoc adjustment to model predictions. Its key departure is treating value function inconsistency as a self-supervised training signal: rather than using ensemble disagreement to penalize OOD actions after the fact, VIPO directly minimizes the gap between a dataset-derived value function and a model-derived value function during model training, drawing conceptual inspiration from MuZero's value-aligned model learning but adapting it to the offline, no-interaction regime. The theoretical analysis (Theorem 4.4) grounds the approach in empirical process theory with bracketing numbers, while the gradient derivation (Theorem 4.5) unrolls the recursive Bellman dependency to enable practical optimization.

## Why It Matters / Open Questions

VIPO provides a drop-in framework that can be integrated into any existing model-based offline RL algorithm to improve model accuracy without requiring expensive architectures (diffusion, transformers), making it broadly applicable. The uncertainty diagnostic (Section 5.2) revealing that MOPO-style ensemble uncertainty fails to track data reduction while VIPO's uncertainty does is a useful empirical finding that challenges reliance on ad-hoc uncertainty quantifiers. Limitations include dependence on sufficient dataset coverage for the dataset-derived value function to be informative, and irreducible error when the neural network lacks capacity to approximate true dynamics. Open questions include how the approach extends to non-Gaussian or stochastic dynamics, very high-dimensional continuous control, and whether the value-inconsistency signal remains useful in online or semi-online settings.

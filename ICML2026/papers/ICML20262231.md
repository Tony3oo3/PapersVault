## Problem

When an LLM is converted to a VLM via a simple MLP projection, it is unclear what visual token representations actually encode at each layer of LLM processing. Existing training-free interpretability methods (EmbeddingLens and LogitLens) compare visual tokens to the LLM's input or output embedding matrices, but the paper shows these approaches substantially underestimate interpretability, labeling only 24–32% of visual tokens as interpretable versus 68% with the proposed method.
![Teaser figure](../imgs/ICML20262231/cropped_page0_idx1.webp)

## Input / Output

The method takes a visual token's latent representation h_i^(l') at position i and layer l' from any VLM and compares it against a precomputed index of ~2.5M contextualized token representations extracted from 2.99M Visual Genome captions encoded through the same LLM backbone at 8 layers (1, 2, 4, 8, 16, 24, L-2, L-1). The output is the top-k nearest neighbor contextualized tokens, which yield full sentence-level descriptions (e.g., 'stone tower with gold clocks') rather than single subword tokens. A key design choice is that the visual token at layer l' can be matched against text representations from any layer l ≠ l', enabling cross-layer comparison. Interpretability is then scored by a GPT-5 judge that classifies each description as concrete, abstract, or global relative to the highlighted image region.

## Method

LatentLens is a training-free interpretability method whose key insight is that the natural reference space for visual token representations is a pool of contextualized LLM token representations (tokens in sentence context) rather than the static input embedding or output unembedding matrix. The method precomputes a large index by running ~3M Visual Genome captions through the target LLM and storing contextualized token vectors at multiple layers, then retrieves top-k nearest neighbors via cosine similarity for any visual token at any layer. Unlike EmbeddingLens and LogitLens, which return single vocabulary tokens, LatentLens returns full sentence descriptions because each reference vector corresponds to a token within a multi-token sequence. The paper also uncovers the 'Mid-Layer Leap' phenomenon: visual tokens at the input layer and early layers align most strongly with contextualized text representations from mid-layers (e.g., layers 8–16), suggesting the learned projection targets semantic rather than lexical representations. Ablations confirm that even a linear connector (no MLP) yields highly interpretable visual tokens, and that the effect is robust to caption length, random seed, and LLM freezing.

## Results

Averaged across all 15 VLMs and all layers, LatentLens renders 68% of visual tokens interpretable (per a GPT-5 judge validated against human annotations with Cohen's κ=0.68), compared to 32% for EmbeddingLens and 24% for LogitLens. On off-the-shelf VLMs, LatentLens achieves 86% (Molmo-7B-D), 78% (Molmo-72B), 55–62% (Qwen2-VL-7B, LLaVA-1.5-7B), and 33–35% (Qwen2.5-VL-32B, LLaVA-NeXT-34B), while EmbeddingLens and LogitLens typically reach only 11–35%. The paper also identifies a 'Mid-Layer Leap' phenomenon: visual tokens at the input layer align most strongly with contextualized text representations from mid-layers (e.g., layers 8–16) rather than same-layer embeddings.

## Baselines & Comparisons

LatentLens substantially outperforms both training-free baselines across all 15 VLM configurations. Against LogitLens (nostalgebraist, 2020), which projects latent representations through the unembedding matrix, LatentLens achieves 68% vs. 24% average interpretability — a 44-percentage-point gap — with LogitLens performing worst at early layers (<25%) and only reaching 60–80% at the final layers for OLMo-based models. Against EmbeddingLens (Neo et al., 2025), which compares visual tokens to rows of the embedding matrix via cosine similarity, LatentLens achieves 68% vs. 32%, with EmbeddingLens showing model-dependent behavior (34–62% for OLMo variants but <20% for Qwen2-based models). Against Tuned Lens (Belrose et al., 2023), which learns per-layer affine probes on top of LogitLens, LatentLens wins by 47–71 percentage points; Tuned Lens provides at best a marginal +1.8 pp gain over plain LogitLens and actually degrades performance on 3 of 4 model pairs tested.

## Relation to Prior Work

LatentLens departs from the established lens family (LogitLens, EmbeddingLens, Tuned Lens) by shifting the reference space from the LLM's input or output embedding matrices to a large pool of contextualized token representations from intermediate layers. This repurposes the idea of nearest-neighbor retrieval in representation space—previously applied to soft prompts (Lester et al., 2021) and contextual word embeddings (Eyal et al., 2022)—for the specific task of interpreting visual tokens in VLMs. The paper positions itself within the broader question of why frozen LLMs readily process non-language inputs (Lu et al., 2022; Merullo et al., 2023; Shukor & Cord, 2024), providing the first systematic, training-free, layer-resolved analysis of what visual tokens actually encode across 15 VLM configurations.

## Why It Matters / Open Questions

The finding that 68% of visual tokens are interpretable via LatentLens—versus 24–32% for prior lenses—challenges the prevailing narrative that visual tokens are largely opaque to the LLM, and the Mid-Layer Leap (input visual tokens aligning with mid-layer text representations) offers a concrete mechanistic explanation for why simple MLP connectors suffice. Open questions include whether LatentLens extends to natively multimodal or non-transformer architectures, how interpretability of individual tokens affects downstream task performance (causal ablations), and whether the Visual Genome corpus introduces domain biases. The practical tool (pip package, precomputed embeddings, interactive demo) lowers the barrier for the community to adopt this lens for their own VLM analyses.

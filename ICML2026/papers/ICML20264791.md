## Problem

AlphaEvolve and its open-source variants (OpenEvolve, ShinkaEvolve) are closed-source or complex pipelines that rely on ensembles of frontier LLMs and operate purely at inference time, meaning the underlying model never internalizes the evolving strategies it discovers. This raises two open questions: (1) can a single small open-source model, with efficient test-time compute scaling, push best-known bounds on challenging open optimization problems, and (2) can reinforcement learning in a dynamic program-evolution environment teach the model transferable evolutionary capabilities that go beyond what pure inference scaling achieves?

## Input / Output

At each step, the system samples B=32 parent programs from a large program database (population_size=10000) and generates n=16 responses per prompt (512 child programs per step), with each prompt containing the parent program, task-specific meta-information (sampled from weighted strategy descriptions), and evaluation scores. The LLM outputs chain-of-thought reasoning followed by one or more SEARCH/REPLACE diff blocks that modify the parent program; a parser applies these diffs to produce a child program, which is then evaluated by a task-specific evaluator with early checks (no-diff, no-change, no-solution, invalid-solution) assigning negative penalty scores before the full evaluator runs. The final output is an improved solution (e.g., circle arrangement, step-function heights, or ±1 matrix) and an updated program database that feeds subsequent generations.

## Method

ThetaEvolve integrates AlphaEvolve-style program evolution with GRPO-based RL training in a dynamic environment where the program database co-evolves with the model. Key architectural choices include: (1) replacing the LLM ensemble with a single model (DeepSeek-R1-0528-Qwen3-8B or ProRL-1.5B-v2), (2) scaling the program database to 10,000 programs (vs. OpenEvolve's 70) to maintain diversity as test-time compute grows, and (3) batch sampling (32 parents × 16 responses) to leverage optimized inference engines like SGLang for ~12× speedup over OpenEvolve's asynchronous sequential pipeline. For RL, the system introduces a lazy penalty that assigns negative scores to non-improving outputs (no diff, no valid change, no solution, invalid solution) to prevent the model from memorizing and repeating the best program, plus optional reward shaping that normalizes narrow-range objective scores via a clipped linear mapping raised to a power α to provide stable training gradients. The critical finding is that RL in this dynamic environment (where the database stores and resamples high-scoring programs) substantially outperforms both pure inference and RL in a static environment (always starting from the initial program), and the learned evolutionary capability transfers to unseen tasks.

## Results

ThetaEvolve with a single open-source 8B model (Distill-Qwen3-8B) achieves new best-known bounds on two open problems: CirclePacking (2.63598308, surpassing AlphaEvolve's 2.63586276 and ShinkaEvolve's 2.63598283) and FirstAutoCorrIneq (1.503133, surpassing AlphaEvolve's 1.503164). Across four tasks and two models, RL training with ThetaEvolve consistently outperforms pure inference: e.g., on CirclePacking-T, Distill-Qwen3-8B with RL reaches 2.6359857 (best) vs. 2.6359834 (w/o RL, late) at comparable compute. The discovered circle-packing program runs in ~3 seconds, roughly 25× faster than ShinkaEvolve's ~75-second program.

## Baselines & Comparisons

Against AlphaEvolve (Gemini-2.0-Flash/Pro ensemble), ThetaEvolve with a single 8B open-source model improves both headline bounds: CirclePacking 2.63598308 vs. 2.63586276 and FirstAutoCorrIneq 1.503133 vs. 1.503164. Against ShinkaEvolve (ensemble of six frontier LLMs including Claude-Sonnet-4 and o4-mini), ThetaEvolve edges out the CirclePacking bound (2.63598308 vs. 2.63598283) while its discovered program runs in ~3 s versus ShinkaEvolve's ~75 s. Against OpenEvolve at matched compute (307.2k programs on CirclePacking-T, ProRL-1.5B-v2), ThetaEvolve w/o RL achieves a best score of 2.2491 vs. OpenEvolve's 2.1773, and ThetaEvolve w/ RL reaches 2.5225; inference throughput is ~12× faster (5.4 h vs. 63.6 h on 4×A6000). RL with ThetaEvolve's dynamic environment substantially outperforms both the static-environment RL baseline and pure inference across all four evaluated tasks and both models.

## Relation to Prior Work

ThetaEvolve simplifies and extends the AlphaEvolve/OpenEvolve evolutionary program-search pipeline by replacing LLM ensembles with a single model, scaling the program database, and introducing batch sampling for higher throughput. Its key conceptual departure is integrating GRPO-based reinforcement learning into the evolutionary loop, treating the program database as a dynamic verifiable environment—an idea motivated by AlphaProof's demonstration that test-time RL with self-contained verifiers can outperform pure inference scaling. Unlike ShinkaEvolve and other open-source variants that remain inference-only pipelines, ThetaEvolve allows the model to internalize evolutionary strategies through parameter updates, bridging the gap between in-context program evolution and test-time learning.

## Why It Matters / Open Questions

The result that a single 8B open-source model can achieve new best-known bounds on open mathematical problems previously requiring frontier LLM ensembles challenges the assumption that only the largest models can push mathematical frontiers, and makes such research accessible to the broader community. The finding that RL-trained checkpoints transfer evolutionary capability to unseen tasks suggests a path toward general post-training recipes for program evolution, though this remains speculative with only two models and five tasks tested. Key open questions include whether the approach scales to problems without clean verifiable evaluators, whether multi-task RL training can further improve generalization, and whether the dynamic-environment RL paradigm can be extended beyond continuous-reward optimization to broader agentic settings.

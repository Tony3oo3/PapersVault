## Problem

Existing long-term conversational memory systems for LLM agents operate primarily at the fact or paragraph level, making it difficult to distill stable user preferences from evolving and potentially conflicting dialogues. They lack a principled mechanism for how user profiles should evolve under continuous evidence, leading to the stability-plasticity dilemma: either overreacting to transient noise or failing to consolidate genuine preference shifts. The paper addresses this by modeling memory as a multi-scale dynamical system inspired by renormalization group theory, where abstraction is governed by thresholded, non-linear phase transitions rather than uniform aggregation.

## Input / Output

The system consumes raw dialogue streams (up to 128k tokens across ~60 sessions in PersonaMem, or ~26k tokens per conversation in LOCOMO) and user queries, producing personalized responses grounded in a multi-scale user profile. The internal memory state is a structured tuple of episodic units (each containing an objective fact λ_fact and a set of user conclusions Λ_conc) and a dynamic knowledge graph with three node levels (abstract concepts, general events, instance events) and two edge types (static classification, dynamic event). At inference time, retrieval combines BM25-matched facts, user conclusions, and cosine-similarity-selected abstract node summaries into a unified context document of roughly 3–4k tokens.

## Method

RGMem is a three-layer, entirely prompt-based (no parameter training) memory framework that instantiates renormalization group dynamics through three scale-aware operators. L0 performs initial coarse-graining of raw dialogue into structured episodic units; L1 maintains a hierarchical knowledge graph and drives profile evolution via three thresholded operators: R_K1 aggregates relation-level evidence only after a mention count exceeds θ_inf=3, R_K2 performs node-level abstraction by decomposing updates into an order parameter Σ (dominant recurring patterns) and a correction term Δ (salient but non-universal signals) triggered at θ_sum=6, and R_K3 propagates (Σ,Δ) tuples upward through the static conceptual hierarchy via a dirty-flag mechanism. L2 performs multi-scale retrieval, selectively accessing microscopic facts, mesoscopic relations, or macroscopic profile summaries depending on query intent. The key differentiator is that all higher-level updates are event-driven and thresholded, producing phase-transition-like dynamics where the profile remains stable under routine inputs but undergoes rapid coordinated reorganization when accumulated evidence crosses critical thresholds, empirically validated by a sharp non-monotonic performance peak at θ_inf=3 across both benchmarks.

## Results

On PersonaMem (128k-token setting), RGMem achieves 74.01% overall accuracy with GPT-4.1 as backbone, outperforming the best baseline (Memory OS, 65.03%) by 8.98 points, and 63.87% with GPT-4o-mini (vs. 54.23% for Memory OS, +7.08 points). On LOCOMO, RGMem reaches 86.17% average accuracy with gpt-4.1-mini, surpassing the strongest baseline Zep (79.09%) by over 7 points and approaching the Full-Context upper bound (87.52%). The largest gains appear on dynamic adaptation tasks: RGMem scores 85.07% on Latest Preference and 70.89% on Track Evolution (GPT-4.1), exceeding the best baselines by 3.85 and 3.68 points respectively.

## Baselines & Comparisons

RGMem consistently outperforms all four compared baselines across both benchmarks and both backbone models. On PersonaMem with GPT-4.1, RGMem (74.01%) beats Memory OS (65.03%) by 8.98 points, A-Mem (63.95%) by 10.06 points, and Mem0 (60.44%) by 13.57 points; the gap is largest on dynamic adaptation dimensions (Aligned Rec. +9.36, Latest Pref. +3.85 over Memory OS). On LOCOMO with gpt-4.1-mini, RGMem (86.17%) surpasses Zep (79.09%) by 7.08 points and Mem0 (62.47%) by 23.70 points, with the biggest margin on Multi-Hop reasoning (78.03% vs. 69.16% for Zep). Zep is the strongest LOCOMO baseline, particularly on Temporal reasoning (83.33%), but RGMem still leads by 5.58 points on that dimension. Notably, RGMem achieves these gains while using fewer retrieved tokens than the w/o RG ablation (3,788 vs. 4,354 avg. tokens on LOCOMO), indicating the improvements stem from structured multi-scale organization rather than increased context.

## Relation to Prior Work

RGMem carves new ground by repurposing the renormalization group (RG) framework from statistical physics as an engineering lens for organizing and evolving long-term conversational memory, rather than building on any single prior memory architecture. It departs from flat retrieval systems (Mem0, LangMem, Zep) and hierarchical knowledge-graph approaches (GraphRAG, HippoRAG, AriGraph) by introducing thresholded, non-linear phase-transition dynamics and an explicit (order parameter, correction term) decomposition that governs *when* and *how* abstractions reorganize. The multi-scale separation of fast-changing episodic evidence from slow-varying user traits echoes the Information Bottleneck and hierarchical pooling ideas in deep learning, but is instantiated here as an external, LLM-driven memory pipeline rather than a learned representation.

## Why It Matters / Open Questions

The paper offers a principled, mechanistic resolution to the stability-plasticity dilemma in long-term user profiling: thresholded updates act as a noise filter, while the (Σ, Δ) tuple prevents over-smoothing of genuine preference shifts. This could influence how future agent memory systems are designed beyond simple retrieval or recursive summarization. Open questions include whether the fixed thresholds generalize across domains and interaction lengths, whether the RG analogy yields further testable predictions (e.g., universality classes of memory dynamics), and how the approach scales to multi-agent or multi-user settings where profiles interact. The reliance on multiple LLM calls per update also raises practical cost concerns for very high-frequency deployment.

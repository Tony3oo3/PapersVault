## Problem

Existing LLM-driven Automated Heuristic Design (AHD) methods produce monolithic, task-specific heuristics that must be rediscovered from scratch for each new problem, failing to generalize algorithmic knowledge across domains. This contrasts sharply with human practice, where experts design reusable metaheuristics (e.g., tabu search, simulated annealing) that transfer broadly. The paper addresses the absence of a mechanism to co-design general-purpose metaheuristics and their task-specific implementations simultaneously across multiple optimization tasks.

## Input / Output

The method takes a set of m related tasks, each specified by a natural language description, a Python program template defining I/O interfaces, and a black-box evaluation function returning a scalar score. It produces a hierarchical individual: a single task-agnostic metaheuristic expressed as structured pseudocode (~10–20 lines following a fixed template with initialization, main loop, and post-processing phases) paired with m executable Python programs, each containing an identified performance-critical key function. The metaheuristic is designed to be portable — it can be handed to a different LLM to instantiate solvers for unseen problems without further evolution.

## Method

MTHS employs a two-level evolutionary architecture where the LLM (GPT-5-mini) serves as the evolutionary operator at both levels. At the high level, k parent metaheuristics are selected and the LLM synthesizes a novel task-agnostic metaheuristic; at the low level, each new metaheuristic is instantiated into task-specific programs, a key function is identified per program, and a short micro-evolution (N_L=4 evaluations) refines that function via LLM-driven mutation. A cross-task knowledge transfer mechanism then adapts the best-performing program from one task to all other tasks within the same metaheuristic, replacing incumbent programs if the adapted version scores better. Population management uses Pareto dominance over the m-dimensional score vector (treating multi-task performance as multi-objective), preserving per-task champions and selecting from non-dominated fronts. The structured pseudocode template for the metaheuristic — rather than free-form thoughts or raw code — is shown to yield faster convergence and better generalization than alternative representations.

## Results

On TSPLib, MTHS achieves the lowest average optimality gap across all four size categories (0.72%, 0.49%, 1.03%, 2.64% for 50-99, 100-199, 200-499, and 500-1000 nodes respectively), outperforming the best LLM-driven baseline GLS_ReEvo (0.79%, 0.68%, 1.71%, 2.72%) and Or-tools GLS (0.63%, 1.62%, 3.34%, 6.84%). On CVRPLib, MTHS secures the best gap on 4 of 7 benchmark sets (E: 0.94%, F: 1.23%, P: 1.06%, X: 4.29%). On the Taillard FSSP benchmark, the MTHS-designed heuristic establishes a new state of the art with an average gap of 0.24%, substantially outperforming ILS (0.68%) and NEHFF (2.69%).

## Baselines & Comparisons

MTHS consistently outperforms all LLM-driven AHD baselines (EoH, ReEvo, MCTS-AHD) across nearly all TSPLib and CVRPLib instance sets; for example, on TSP 200-499 nodes, MTHS achieves 1.03% gap versus 1.62% (GLS_EoH), 1.71% (GLS_ReEvo), and 1.53% (GLS_MCTS). Against conventional metaheuristics, MTHS surpasses Or-tools GLS (the strongest classical baseline) on all TSP size categories and 5 of 7 CVRPLib sets, with the largest margin on TSP 500-1000 nodes (2.64% vs. 6.84%). On FSSP, MTHS (0.24% avg gap) substantially outperforms ILS (0.68%), NEHFF (2.69%), and all constructive heuristics (NEH: 2.88%, CDS: 10.55%, GUPTA: 17.25%). The single-task ablation STHS is consistently worse than MTHS on both TSP and CVRP, confirming the benefit of cross-task knowledge transfer. On the unseen BPP task, the MTHS-designed metaheuristic enables Gemini-2.5-pro to achieve 0.34%/0.25% gap (n=500/1000), outperforming MCTS-AHD (0.48%/0.53%) and EoH (0.75%/0.85%) without any iterative search. However, the metaheuristic does not generalize to the structurally different Admissible Set Problem, where it provides no clear improvement over scratch LLM generation.

## Relation to Prior Work

This paper extends the LLM-driven Automated Heuristic Design (AHD) paradigm established by EoH (Liu et al., 2024) and the evolutionary search framework analyzed by Zhang et al. (2024), which use LLMs as mutation/crossover operators within iterative loops to evolve task-specific programs. The key departure is architectural: rather than producing monolithic, single-task heuristics (as in EoH, ReEvo, or MCTS-AHD), MTHS introduces a two-level hierarchical representation that separates a task-agnostic metaheuristic from its task-specific program instantiations, and evolves them jointly across multiple problems simultaneously. This is positioned as the first cross-problem LLM-driven AHD method, drawing an explicit analogy to how human experts design reusable metaheuristics (tabu search, GLS) rather than bespoke solvers.

## Why It Matters / Open Questions

The central contribution is demonstrating that a single evolved metaheuristic template can serve as a generalizable scaffold: when provided to different LLMs (GPT-5-mini, Gemini-2.5-pro) without any evolutionary search, it consistently improves their ability to solve unseen but related problems (BPP, continuous BBOP). However, generalization fails for structurally dissimilar tasks (Admissible Set Problem), revealing that the metaheuristic encodes a specific class of problem-solving logic rather than universal optimization principles. Open questions include characterizing the boundary of successful transfer, scaling to more diverse task families, and incorporating resource/reliability constraints into the search. The 67% reduction in code evaluations versus running three independent single-task searches also has practical cost implications for LLM-based AHD pipelines.

## Problem

LLMs cannot reliably recognize their parametric knowledge boundaries and hallucinate on out-of-boundary questions. Existing abstention methods require privileged information about model knowledge boundaries to construct training data, and they only reduce errors without expanding the set of answerable questions. This paper asks whether a single training strategy can simultaneously teach a model to recognize its boundaries (abstain) and expand its answerable question set (via help-seeking).

## Input / Output

The method takes a short-form text question as input and produces a structured trajectory of reasoning steps (<think>), search queries (<search>), and a final answer (<answer>). During search-enabled inference, the model may issue up to 5 retrieval queries (top-3 passages each from a Wikipedia corpus via E5). For abstention inference, search access is removed and any attempted <search> invocation is interpreted as an abstention decision, yielding either a direct answer or an abstention signal without requiring a separate abstention prompt.

## Method

MASH trains LLMs via GRPO reinforcement learning with a multiplicative reward r_acc · r_help, where r_help is a pay-per-search penalty that discounts correctness by the number of searches relative to the most efficient correct trajectory. The key insight is that search tool use serves as a proxy for abstention: the optimal policy searches only when parametric accuracy is insufficient, so removing search at inference and treating search attempts as abstention yields boundary-aware behavior. A lightweight warm-start SFT pipeline generates synthetic trajectories with randomly sampled search counts (0–2) using a different generator model (Qwen2.5-32B) to inject diverse search behavior without any knowledge-boundary information, preventing RL from collapsing to degenerate always-search or never-search policies. The paper proves that the optimal policy answers parametrically if and only if its expected parametric accuracy exceeds the maximum achievable reward from searching, and experiments three penalty severities (Exponential Decay, OTC, OTC-Strict), finding that harsher penalties are crucial for eliciting parametric answers on single-hop tasks.

## Results

On the three knowledge-intensive QA datasets, MASH w/ OTC-Strict (the best variant) achieves 56.37% accuracy with 0.64 tool calls (TP=38.63) on Natural Questions, 53.32% accuracy with 1.10 tool calls (TP=32.55) on HotPotQA, and 46.23% accuracy with 1.64 tool calls (TP=19.08) on 2Wiki. This represents a 4.22% mean accuracy and 5.62% mean tool productivity improvement over the OTC baseline, with a 7.6% accuracy gain on multi-hop datasets. Notably, MASH matches Search-R1's accuracy on multi-hop datasets (53.32% vs 57.03% on HotPotQA, 46.23% vs 42.89% on 2Wiki) while using substantially fewer searches (1.10/1.64 vs 3.30/2.51 tool calls).

## Baselines & Comparisons

Against OTC (Wang et al., 2025a), MASH w/ OTC-ST achieves a 4.22% mean accuracy and 5.62% mean tool productivity improvement across all three datasets, with particularly large gains on multi-hop data (8.56% on HotPotQA, 6.64% on 2Wiki) while using only slightly more searches. Against Search-R1 (Jin et al., 2025), MASH matches or exceeds accuracy on multi-hop datasets (53.32% vs 57.03% on HotPotQA, 46.23% vs 42.89% on 2Wiki) while using roughly half the tool calls (1.10/1.64 vs 3.30/2.51), indicating far more efficient search. For abstention, MASH w/ OTC-ST is competitive with DPO (Cheng et al., 2024), outperforming it on 2Wiki (4.6% Acc vs 3.3%, 32.5% Prec vs 31.6%) and on HotPotQA precision (59.9% vs 53.1%), though DPO achieves a higher Delta margin. MASH substantially outperforms AFH (Yang et al., 2024) on precision (e.g., 57.4% vs 43.3% on NaturalQA) while maintaining comparable overall accuracy. The Ternary RL baseline (Xu et al., 2024a; Wei et al., 2025) collapses to always abstaining within 25 training steps, yielding 0% accuracy across all datasets, and is outperformed by every other method. The warm-start SFT component is critical: without it, OTC-Strict and EXP collapse to zero searches on HotPotQA and 2Wiki, while with warm-start they train stably and outperform OTC.

## Relation to Prior Work

MASH builds directly on the efficient search-tool-use line of work (Search-R1, OTC reward) and the abstention line of work (Alignment for Honesty, DPO-based abstention), but departs from both in a key way: prior abstention methods require privileged knowledge-boundary information to construct training data, while prior efficient-search methods optimize search count without reference to parametric knowledge. MASH unifies these by showing that a pay-per-search RL reward implicitly aligns search behavior with parametric knowledge, so that removing search access at inference yields abstention decisions for free. The warm-start SFT with intentionally diverse (and parametrically misaligned) synthetic trajectories is a novel stabilization technique for RL that prior efficient-search pipelines lacked.

## Why It Matters / Open Questions

The 'two capabilities at the cost of one' framing is practically attractive: a single RL training run yields both an efficient search agent and an abstention model, without the data-curation pipeline that prior abstention methods require. The oracle-helper negative result (perfect helpers cause collapse to always-seeking-help) is a useful cautionary finding suggesting that retrieval noise is functionally necessary for learning selectivity, which has implications for how we design training environments for tool-use agents. Limitations include restriction to short-form QA, small model scales (3B–7B), noisy exact-match rewards, and sensitivity to reward hyperparameters; whether the approach transfers to open-ended generation, multi-turn dialogue, or larger models remains open.

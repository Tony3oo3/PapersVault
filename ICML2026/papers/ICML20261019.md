## Problem

Neural combinatorial optimization pipelines for TSP typically produce edge heatmaps (probabilities of each edge belonging to an optimal tour), but converting these heatmaps into feasible tours via greedy search, beam search, or MCTS provides no theoretical guarantee linking heatmap quality to solution cost. Moreover, MCTS-based approaches render the neural network output largely irrelevant. This paper introduces the first learning-augmented approximation algorithm for TSP, filling the gap between provable worst-case guarantees and ML-informed beyond-worst-case performance.

## Input / Output

The algorithm receives a TSP instance (complete graph with metric edge weights, or a general graph for graphical TSP) together with a heatmap p ∈ [0,1]^E assigning each edge a probability of belonging to an optimal tour; in practice, edges are sampled independently with probability p_e to form a prediction set P. The output is a feasible TSP tour (Hamiltonian circuit for metric TSP, closed walk for graphical TSP). The prediction error η is defined as the weighted L1 distance between the prediction and some optimal tour, and the guarantee is E[w(X)] ≤ w(X*) + 2η. For graphical TSP, the prediction must be a multiset encoding edge multiplicities to achieve near-linear running time.

## Method

The core algorithm modifies Christofides' 1.5-approximation in two key ways: (1) the minimum spanning tree T is computed with modified weights that bias toward predicted edges (weight 0 in Algorithm 1, or sign-flipped weights in Algorithm 2 to favor heaviest predicted edges), and (2) the odd(T)-join J is computed with respect to the original edge weights, not the modified ones—a critical distinction that preserves the O(η) additive guarantee. The Eulerian multiset T+J is then shortcut into a Hamiltonian circuit. The analysis bounds w(T) and w(J) separately in terms of false positives H⁺ and false negatives H⁻, showing each deviates from the optimal tour's components by at most O(η). For near-linear time, Algorithm 2 replaces exact matching with the Goemans–Williamson 2-approximation, using a sign-flipping trick and a |S|=2 special case to ensure the factor-of-2 loss applies only to edges whose total weight is O(η), yielding E[w(X)] ≤ w(X*) + 11η in O(n² log n) time.

## Results

The paper provides the first learning-augmented approximation algorithm for TSP with a provable guarantee of E[w(X)] ≤ OPT + 2η (Theorem 1.1, O(n³) time), where η is the weighted L1 distance between the heatmap and an optimal tour. Near-linear time variants achieve OPT + 11η in O(n² log n) (Theorem 1.2) and OPT + 4η in O(m log n) for graphical TSP (Theorem 1.3). Empirically, the proposed CHR+ decoding strategy is the only solution search method that consistently outperforms the standard Christofides baseline across all tested predictors (GNN4CO, GNN-GLS, DIFUSCO, SoftDist) and all three datasets (ML4CO, TSPLIB Euclidean, TSPLIB metric), with improvements that degrade smoothly as synthetic prediction error exceeds ε ≈ 0.25.

## Baselines & Comparisons

Against the standard Christofides algorithm (CHR), the proposed CHR+ variant consistently achieves lower optimality gaps across all three datasets and all five predictor types, with the advantage shrinking smoothly as prediction error grows. Against greedy search variants (G1: sequential node construction, G2: edge-selection without subcycles) and beam search (BS), CHR+ is the only method that yields systematic improvements over CHR; G1, G2, and BS fail to produce consistent gains regardless of predictor quality. Against DIFUSCO's own decoding pipeline, CHR+ matches or exceeds reported performance, with minor discrepancies attributed to inference-time configurations such as graph sparsification that were disabled in the authors' setup. After 2-opt post-processing, CHR+ retains its advantage over all baselines while introducing negligible additional runtime compared to plain CHR. The theoretical lower bound (Theorem D.1) establishes that the linear dependence on η/OPT is essentially tight: a sub-linear dependence would imply a 123/122-approximation for TSP, contradicting the known inapproximability barrier (Karpinski et al., 2015).

## Relation to Prior Work

This paper bridges two previously disconnected lines of work: the algorithms-with-predictions (learning-augmented algorithms) paradigm, which has produced nearly 400 papers but had not been applied to TSP approximation, and the neural combinatorial optimization pipeline where GNNs produce edge heatmaps that must be decoded into tours. The algorithm is built on Christofides' classical 1.5-approximation (MST + minimum-weight perfect matching on odd-degree vertices), but the key technical departure is a counterintuitive sign-flipping of predicted edge weights to bias the MST toward the *heaviest* predicted edges, which is necessary to maintain sub-1.5 approximation when replacing exact matching with the Goemans-Williamson 2-approximation. Unlike MCTS-based decoders (Fu et al., 2021) that render the NN output essentially irrelevant, this method is lightweight and provably exploits the heatmap quality.

## Why It Matters / Open Questions

This is the first learning-augmented approximation algorithm for TSP, filling a notable gap in the algorithms-with-predictions literature and providing the first explicit, provable link between heatmap quality and tour quality in the neural TSP pipeline. Practically, it creates a principled drop-in replacement for greedy/beam-search decoders that rewards better NNs with better tours, addressing the concern raised by Xia et al. (2024) that MCTS makes NNs useless. Open questions include whether the additive constants (2η, 11η, 4η) can be tightened, whether the framework extends to other constrained combinatorial problems (VRP, TSP variants), and whether the theoretical guarantee is tight in practice given that 2-opt post-processing further closes the gap. The lower bound (Theorem D.1) showing linear dependence on η/OPT is necessary is reassuring but leaves room for improving the constant factor.

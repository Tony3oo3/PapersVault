## Problem

Existing online fair division algorithms assume a small number of item types with sufficiently many copies, enabling reliable utility estimation for every item-agent pair from noisy observations. In many real-world settings (online platforms, ride-hailing, e-commerce), items are numerous with only a few copies each, making per-pair utility estimation infeasible. This paper addresses how to design allocation algorithms that maintain a fairness-efficiency balance under this far more general and statistically challenging regime.

## Input / Output

At each round the learner receives a d_m-dimensional item feature vector and a fixed set of d_n-dimensional agent feature vectors, which are concatenated into d = d_m + d_n item-agent feature vectors. Only the utility of the selected item-agent pair is observed (bandit feedback), so the algorithm must maintain a running estimate of the unknown utility function from partial observations. The output is a single agent index per round, chosen to maximize a goodness function (e.g., weighted Gini social-evaluation) evaluated on the projected cumulative utility vector after hypothetically assigning the current item to that agent.

## Method

The paper formulates online fair division as a contextual bandit problem (items as contexts, agents as arms, utility as reward) and proposes two algorithms: OFD-UCB, which uses a linear UCB confidence bonus to produce optimistic utility estimates, and OFD-TS, which samples parameters from a posterior Normal distribution. In each round, the algorithm computes the goodness function value for every agent using these optimistic estimates and allocates the item to the agent maximizing that value, thereby explicitly enforcing the fairness-efficiency trade-off at every step. A key abstraction is the 'OFD-compatible' contextual bandit framework (Definition 1), which requires only that the utility estimation error be bounded by a known function h, allowing plug-in of any suitable bandit algorithm (linear, kernelized, neural) for non-linear utilities. The paper proves sublinear fair regret bounds for the weighted Gini social-evaluation function (Theorems 1–2) and extends the analysis to any locally monotonically non-decreasing and locally Lipschitz continuous goodness function, including Nash Social Welfare and log-NSW (Theorem 3).

## Results

The paper demonstrates sub-linear cumulative fair regret for both OFD-UCB and OFD-TS across linear (d=4, 10, 20) and non-linear (d=10, 20) utility settings with 10,000 items and 10 agents (ρ=0.85). The TS-based algorithm (OFD-TS) consistently achieves lower regret than the UCB-based counterpart (OFD-UCB) across all problem instances. Regret decreases as the number of copies per item increases (from c=10 to c=200) and increases with the number of agents (N=5 to 25) and feature dimension (d=10 to 50). The control parameter ρ effectively trades off fairness and efficiency: as ρ increases from 0 to 1, total utility (USW) increases, the Gini coefficient increases, and the ratio of minimum utility to total utility decreases.

## Baselines & Comparisons

The paper compares OFD-UCB and OFD-TS against four baselines: OFD-Uniform (random agent selection), OFD-Greedy (ε-greedy with no confidence bonus and 10% random exploration), OFD-Eff-UCB/TS (maximizing Utilitarian Social Welfare), and OFD-Fair-UCB/TS (maximizing Egalitarian Social Welfare). Both OFD-UCB and OFD-TS substantially outperform OFD-Uniform and OFD-Greedy across all linear and non-linear problem instances (Fig. 2a–2e, Fig. 4a–4d), with the gap widening as dimension increases. OFD-TS consistently achieves lower regret than OFD-UCB, reflecting the known empirical superiority of Thompson sampling. The paper notes that no direct comparison to existing online fair division algorithms (e.g., Procaccia et al. 2024, Yamada et al. 2024) is possible because those methods assume a small number of item types with many copies, making them inapplicable to the numerous-items-with-few-copies setting studied here. The OFD-Eff and OFD-Fair baselines, which optimize pure efficiency or pure fairness respectively, are also outperformed by the proposed algorithms that balance both objectives through the weighted Gini goodness function.

## Relation to Prior Work

This paper extends the online fair division literature (Yamada et al., 2024; Procaccia et al., 2024; Bhattacharya et al., 2024; Schiffer & Zhang, 2025), which models the problem as a multi-armed bandit under the assumption of few item types with many copies, to a more general setting where items are numerous with only a few copies each. To handle this, the authors recast the problem as a contextual bandit, adapting Lin-UCB (Chu et al., 2011) and Thompson sampling (Agrawal & Goyal, 2013) with the confidence-bound machinery from Abbasi-Yadkori et al. (2011), and introduce a modular 'OFD Compatible Contextual Bandit' framework that decouples the exploration-exploitation subroutine from the fairness-efficiency objective encoded in a goodness function (weighted Gini, NSW, log-NSW).

## Why It Matters / Open Questions

The paper addresses a practical gap: real-world platforms (food delivery, ride-hailing, e-commerce) face exactly the numerous-items-few-copies regime where prior MAB-based fair division algorithms cannot reliably estimate utilities. The modular framework and sublinear regret guarantees (Theorems 1–3) provide a principled starting point for deploying fair allocation in such settings. Open questions include extending to more expressive valuation functions, incorporating envy-freeness or proportionality, handling multiple item types simultaneously, and rigorously bounding the additional regret term D_T that arises under a stronger oracle definition (Sec. B).

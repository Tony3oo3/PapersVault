## Problem

When an LLM-based agent translates a user's natural-language intent into actions in a real environment (e.g., configuring a 5G network), the user may want to know what would have happened under a different phrasing or target. Prior LLM counterfactual methods handle only standalone text generation without environment interaction, while prior network-KPI counterfactual work ignores the LLM agent as an intermediary. This paper bridges both gaps by providing a counterfactual generation framework for closed-loop agent-environment systems with formal reliability guarantees on the generated outputs.

## Input / Output

The method consumes a full factual episode T=(X, A, Z, Y) — the original prompt, the agent's action sequence, the environment's KPI time-series feedback, and the textual report — together with a counterfactual prompt X' drawn from an admissible edit set E(X), a trained NPE posterior q_φ(U_Z|A,Z), and a black-box environment simulator f_Z. The output is not a single report but a variable-cardinality set C_λ(T, X') of counterfactual report candidates, accompanied by a conformal guarantee that at least one member is semantically faithful to the true counterfactual Y_{X'}(T) with probability ≥ 1−ε. Intermediate outputs include the counterfactual action sequence A_{X'}(T) and counterfactual KPI time series Ẑ_{X'}(T).

## Method

The agent-environment pipeline is modeled as a structural causal model (SCM) in which the LLM action and report generators use Gumbel-Max token sampling, so counterfactual replay reuses the same exogenous Gumbel noise U_A and U_Y while substituting X' for X. The latent environment noise U_Z is inferred via a neural posterior estimation (NPE) network trained in a likelihood-free manner on simulator rollouts, since the digital-twin simulator f_Z is a black box. Counterfactual generation then proceeds as: (1) replay the action LLM with X' and U_A to obtain A_{X'}; (2) run the simulator with A_{X'} and the abducted Ũ_Z to obtain Ẑ_{X'}; (3) run the report LLM with (X', A_{X'}, Ẑ_{X'}) and U_Y to produce a candidate report. On top of this point-estimate pipeline, conformal counterfactual generation (CCG) applies test-time scaling with adaptive acceptance rules (quality threshold via log-likelihood and diversity threshold via ROUGE-L) and a max-quality stopping rule, calibrating all thresholds via binomial p-values and FWER control so that the returned set satisfies the miscoverage guarantee with probability ≥ 1−δ.

## Results

On the 5G network control task (100 test episodes), CG reconstructs counterfactual KPI time series with MAE of 0.15 (throughput) and 0.35 (delay), substantially outperforming IG (0.28/0.52) and SIG (0.33/0.60). In cross-correlation, CG achieves peaks of 0.93 (throughput) and 0.89 (delay) versus 0.78/0.71 for IG and 0.70/0.62 for SIG. An LLM-as-a-judge selects CG as the best semantic match to the true counterfactual report in 92% of cases, IG in 8%, and SIG in 0%. In the conformal setting, CCG closely tracks the ideal risk-controlled diagonal across all target loss levels ε, while fixed-budget k-CG baselines are either overly conservative or under-covering.

## Baselines & Comparisons

The paper compares CG against two re-execution baselines: Interventional Generation (IG), which feeds the counterfactual prompt directly to the real agent-environment system, and Simulated Interventional Generation (SIG), which does the same but replaces the real environment with the digital-twin simulator. CG dominates both baselines across all three KPI fidelity metrics (MAE, cross-correlation peak, crossing-level error) for both throughput and delay, despite IG having access to the real system. The gap is most pronounced for SIG, which suffers additional semantic distortion from the simplified simulator. In the conformal calibration experiments, CCG is compared against fixed-budget k-CG baselines (k = 1–10) that draw exactly k samples without adaptive acceptance or stopping. CCG consistently achieves lower relative excess samples (RES) than every k-CG baseline at matched average set sizes, with efficiency gains growing for larger budgets, while maintaining the target miscoverage level ε with high probability (1−δ).

## Relation to Prior Work

This paper unifies three previously separate research threads: token-level LLM counterfactual generation via Gumbel-Max sampling (Chatzi et al., 2025; Ravfogel et al., 2025), environment-level causal inference for network KPIs (Hou et al., 2025; Lei & Candès, 2021), and conformal language modeling for set prediction with coverage guarantees (Quach et al., 2024). The key departure is that prior LLM counterfactual work operates purely in text space without external environment interaction, while prior network counterfactual work assumes the operator directly sets actions without an LLM intermediary. By modeling the full agent-environment pipeline as a structural causal model (Peters et al., 2017) and using neural posterior estimation (Greenberg et al., 2019) for the abduction step, the paper bridges these gaps into a single closed-loop counterfactual framework.

## Why It Matters / Open Questions

This is the first framework to provide formal reliability guarantees for counterfactual reasoning in agentic LLM-driven control, which is increasingly relevant as LLM agents are deployed in safety-critical domains like network management. The conformal calibration ensures operators receive not just a point estimate but a set of plausible counterfactual outcomes with a quantified confidence level, enabling risk-aware decision-making. Key limitations include dependence on simulator fidelity (the ablation in Appendix H shows monotonic degradation with lower-fidelity digital twins), restriction to single-turn single-agent settings, and the need for a trained NPE posterior per environment. Open questions include extending to multi-turn dialogue, multi-agent interactions, and real-time interactive counterfactual analysis where the user iteratively refines their intent.

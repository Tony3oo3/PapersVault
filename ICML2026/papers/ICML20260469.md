## Problem

Differentially private subgraph counting on entire graphs has been studied, and range subgraph counting without privacy has been analyzed, but the combination—privately counting pattern occurrences within induced subgraphs defined by multi-dimensional attribute ranges—remained unexplored. The core difficulty is that subgraph counting is inherently nonlinear with high sensitivity (a single edge can affect Θ(n) triangle occurrences), and answering many range queries independently causes privacy loss to accumulate via composition, making naive Laplace-noise approaches infeasible.

## Input / Output

The algorithm takes an n-vertex undirected graph G with d-dimensional public vertex attributes, a fixed connected pattern graph H with O(1) vertices, a query set Q of axis-aligned d-dimensional ranges, and privacy parameters ε, δ. It outputs a noisy count f̃_H(G_q) for each query q ∈ Q, where G_q is the subgraph induced by vertices whose attributes fall within q's range. The privacy guarantee is edge-DP: two graphs differing by exactly one edge must produce statistically indistinguishable outputs, and vertex attributes are assumed public (not protected).

## Method

The key insight is a subgraph projection that maps each occurrence of H to a 2d-dimensional rank tuple (min and max attribute rank per dimension across the occurrence's vertices), converting the nonlinear range subgraph counting problem into weighted orthogonal range counting over axis-aligned rectangles. A 2d-dimensional range tree is built over these projected points, with Laplace noise added to node weights so that each query is answered by aggregating O(log^{2d} n) tree nodes, exploiting query correlations to avoid per-query composition. For approximate DP, the noise scale is calibrated using a privately estimated higher-order local sensitivity (adapted from Nguyen et al. 2023) rather than the global sensitivity, yielding substantially smaller additive error on sparse graphs. Matching lower bounds are established by reducing reconstruction attacks to DPRSC and showing the associated incidence matrix has discrepancy amplified by a factor of Θ(GS_{f_H}), proving exponential dependence on dimension d is unavoidable.

## Results

The paper's main theoretical contribution is Table 2, which shows that PDP_RSC achieves additive error Õ(GS_{f_H}) and ADP_RSC achieves Õ(HS̃_{f_H}(G)), both independent of |Q| (up to polylog factors), whereas the baselines PDP_Comp and ADP_Comp incur errors scaling as Õ(GS_{f_H}·|Q|) and Õ(HS̃_{f_H}(G)·√|Q|) respectively. Empirically, on three real-world graphs (CA-Netscience, Wiki-Squirrel, WormNet-v3) with ε=2.0, δ=10⁻⁵, d=1, and |Q|=⌈n^{1.5}⌉, the proposed algorithms achieve substantially lower relative error than both baselines across all tested ε values and pattern graphs (triangle, 2-star, edge). In terms of runtime, PDP_RSC and ADP_RSC achieve 3–4 orders of magnitude lower query time than the baselines, and when |Q|=Θ(n²) the total time speedup reaches 3–4 orders of magnitude. The algorithms are largely insensitive to |Q|, while baseline errors grow rapidly with the number of queries.

## Baselines & Comparisons

The paper constructs two natural baselines since no prior work exists on DP range subgraph counting. PDP_Comp answers each query independently with Laplace noise scaled by GS_{f_H}·|Q|/ε (basic composition), while ADP_Comp uses the advanced composition theorem with a private local sensitivity estimate, scaling noise as Θ(HS̃_{f_H}(G)·√(|Q|·ln(1/δ)))/ε. Both proposed methods (PDP_RSC and ADP_RSC) outperform both baselines in relative error across all datasets, pattern graphs, and ε values tested, with the gap widening as |Q| increases. ADP_RSC generally achieves the lowest error on sparse graphs (CA-Netscience, WormNet-v3), but on the denser Wiki-Squirrel graph for 2-star counting, PDP_RSC can be preferable because the large maximum degree (d_max=1,903) inflates HS̃_{f_H}(G)≈2·d_max. In runtime, the range-tree-based algorithms achieve 3–4 orders of magnitude lower per-query latency than the baselines (which recompute exact counts per query), at the cost of a one-time preprocessing step. For total time, the proposed methods dominate when |Q|=Ω(n), with the advantage growing as |Q| approaches Θ(n²).

## Relation to Prior Work

This paper initiates the study of differentially private range subgraph counting (DPRSC), a problem that combines three previously separate threads: DP subgraph counting (Nguyen et al., 2023; Karwa et al., 2011), multidimensional range query answering (Dwork et al., 2015; Deng et al., 2023b for the non-private 1D case), and discrepancy-theoretic lower bounds for private range counting (Muthukrishnan & Nikolov, 2012). The key technical departure from prior DP subgraph counting work is the subgraph projection, which maps each occurrence of a pattern graph to a point in R^{2d} based on vertex attribute ranks, thereby reducing the inherently nonlinear subgraph counting problem to weighted orthogonal range counting over a range tree. The approximate DP algorithm directly reuses the iterative higher-order local sensitivity estimation of Nguyen et al. (2023), while the lower bound adapts the reconstruction-attack-to-discrepancy reduction framework of Muthukrishnan & Nikolov (2012) to the subgraph setting.

## Why It Matters / Open Questions

This is the first work to provide both efficient algorithms and matching lower bounds for private range subgraph counting, establishing that the additive error must grow exponentially in the attribute dimension d when d = O(log n) — a fundamental hardness result that rules out naive per-query approaches. The subgraph projection technique is a reusable reduction that could inform future work on other nonlinear graph statistics under range queries. Key open questions include extending to sensitive (private) vertex attributes, dynamic graphs, and closing the remaining gap between upper and lower bounds in certain parameter regimes; the authors also note that node-level and local DP variants remain unexplored.

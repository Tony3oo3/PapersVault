## Problem

While RLHF typically targets optimal policy learning (requiring reward accuracy only in visited state-action regions), the harder task of compatible reward identification—recovering a reward accurate across the entire state-action space for transferability and safety—lacks theoretical understanding of how many human preference queries are needed and how to select them. This paper formalizes the compatible reward identification task and provides the first query-complexity lower bounds and near-optimal active query selection algorithms for both deterministic and stochastic (Bradley-Terry) preference models.

## Input / Output

The learner receives a known tabular finite-horizon MDP (states, actions, transitions, horizon H) and a fixed likelihood function g, then interactively presents trajectory pairs (encoded as ternary query vectors in {-1,0,1}^{SAH}) to a human labeler who returns binary Bernoulli feedback. The output is a compatible reward function r̂ ∈ R(P,g) recovered by solving a linear system [Q; e_SA^T] r = [σ⁻¹(p̂); 0], along with the selected query basis (a spanning-tree chain of SA−1 queries per stage) and the number of rounds t at which the algorithm terminated.

## Method

For deterministic preferences (g = Heaviside), the paper proves offline and online query-complexity lower bounds (HSA(SA−1)/2 and Ω(HSA log(SA)) respectively) and an inapproximability theorem showing any non-sufficient query set yields Hausdorff distance R_max. For stochastic BT preferences, the key insight is that query complexity is governed by the query index V(Q) = min p(1−p) over queries in the set, which is maximized when preference probabilities are closest to 1/2—counterintuitively favoring similar trajectory pairs over dissimilar ones. The λ-SQE algorithm identifies a λ-optimal query chain by iteratively discarding queries whose optimistic constrained index falls below the pessimistic unconstrained index, using Chernoff-Hoeffding confidence bounds on variance and a BestBasis subroutine that computes maximum-minimum-weight spanning trees over the query graph. The full SERE procedure combines this exploration phase with a commit phase that samples the selected chain until the reward estimate satisfies an (ε,δ)-PAC guarantee, achieving overall query complexity Õ(S⁴A⁴H ln(1/δ)/(ε²V*²)) with a convenient λ selection.

## Results

This is a purely theoretical paper with no empirical results table. The key quantitative contributions are query complexity bounds: for deterministic preferences, the offline lower bound is HSA(SA−1)/2 queries and the online lower bound is Ω(HSA log₂(SA)), with an inapproximability result showing that any non-sufficient query set yields Hausdorff distance R_max. For stochastic (BT) preferences with probability feedback, the lower bound is H(SA−1) queries. For Bernoulli feedback, the proposed SERE algorithm achieves an overall query complexity of Õ(S⁴A⁴H ln(1/δ)/(ε²V_*²)), matching the order of an oracle that knows the optimal basis a priori, when λ = O(ε/(SA)).

## Baselines & Comparisons

This paper does not compare against empirical baselines; it is a theoretical contribution establishing lower and upper bounds. The main theoretical comparisons are: (i) offline vs. online deterministic settings, where online reduces the lower bound from HSA(SA−1)/2 to Ω(HSA log₂(SA)) by exploiting transitivity (reducing to sorting); (ii) deterministic vs. stochastic (BT) preferences, where the BT model introduces translation invariance (H degrees of freedom) and the non-trivial query index V(Q) that governs sample complexity; and (iii) the λ-SQE exploration phase vs. an oracle that knows the optimal query chain, showing that with λ = O(ε/(SA)), the additional exploration cost is absorbed and the total complexity matches the oracle up to logarithmic factors. The paper also contrasts its compatible reward identification objective with the more common policy optimization objective (RLHF/DPO), noting that the former requires accuracy across the entire state-action space and thus inherently has higher query complexity but provides transferability and safety guarantees that policy optimization cannot.

## Relation to Prior Work

This paper extends the inverse reinforcement learning (IRL) literature on compatible reward sets (Abbeel & Ng, 2004; Ng & Russell, 2000) to the preference-feedback setting, deliberately distinguishing its objective from the dominant RLHF/DPO paradigm that only requires reward accuracy on policy-visited states. It repurposes the successive elimination framework from multi-armed bandits (Even-Dar et al., 2006) to the preference elicitation problem (Shukla & Basu, 2024), introducing the 'query chain' and 'index' as new structural concepts for characterizing query quality under the Bradley-Terry model. The paper also connects to the preference-based RL literature (Furnkranz et al., 2012; Wirth et al., 2017) but shifts the focus from policy learning to reward identification with PAC guarantees on Hausdorff distance.

## Why It Matters / Open Questions

The inapproximability result (Theorem 4.3) establishes a hard boundary: no algorithm can shortcut the query process for deterministic preferences without risking arbitrarily large identification errors, which has direct implications for how practitioners design human-in-the-loop RL systems. The counterintuitive finding that the BT model favors queries with mild preferences (probability near 1/2) over those with large utility gaps reveals a structural limitation of the BT model for reward identification, potentially motivating alternative likelihood functions. Key open questions include extending beyond tabular MDPs, accounting for the sample cost of generating trajectories in the environment (the paper assumes free trajectory construction), and whether the BT model's preference for 'close' queries persists in richer function classes.

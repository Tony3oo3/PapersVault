## Problem

Long-horizon dialogue agents suffer from latent state drift: what an agent says, what it internally represents, and what it stores in memory silently diverge across turns, creating asymmetric rupture risk where a single high-cost contradiction can undo many locally coherent exchanges. Current systems treat behavior, reasoning, and memory as loosely coupled modules optimized for local response quality, lacking an explicit jointly constrained state representation with convergence or stability guarantees.

## Input / Output

BRIDGE consumes dialogue history, the current user utterance, an initial persona description (a free-text string encoded into three-tier memory anchors via a pretrained encoder), and the previous turn's concatenated memory state. It produces a decoded dialogue response and an updated three-tier hierarchical memory (episodic, affective, personality) that persists across turns. The frozen Qwen2.5-32B-Instruct backbone encodes context into per-token hidden states; BRIDGE operates on 1024-dim state vectors rather than the full token sequence, adding only ~16-18 ms TTFT overhead regardless of context length.

## Method

BRIDGE performs triangular fixed-point refinement via a Gauss-Seidel cross-attention cycle (M→O→L→M) that jointly refines Observable, Latent, and Memory states before each decode, with a sufficient contraction condition (‖A‖∞ < 1 on the induced coupling matrix) guaranteeing a unique fixed point and geometric convergence (Theorem 2.2). A dual-system module provides the initial latent via a fast habitual key-value bank and a slow D-layer deliberative stack, fused through multiplicative context-aware gating that adaptively blends the two pathways. The refined state triple and turn-level control signal are injected additively into the frozen backbone's hidden states via a learned projection. Hierarchical memory evolves via anchored clipped updates (EMA toward the initial persona encoding with per-tier clipping bounds), yielding a Lyapunov-style uniform drift bound (Theorem 2.3) that prevents unbounded identity drift. Only 277M parameters (0.85% of the 32.5B backbone) are trained under a composite objective combining next-token loss, a cyclical coherence loss penalizing post-refinement cross-space mismatch, and a persona-consistency classifier loss.

## Results

BRIDGE achieves the highest average scores on both benchmarks: 4.59 ± 0.02 PersonaScore on PersonaGym (surpassing Claude-3.7-Sonnet's 4.49) and 59.5 ± 0.7 on CoSER (+3.1 over Claude-3.7-Sonnet's 56.4). Gains concentrate on persona-specific dimensions—Character Fidelity reaches 48.2% (+8.0 over the Qwen2.5-32B-Instruct backbone) and Persona Consistency hits 4.82—while generic Storyline Quality changes only modestly (73.5 vs. 74.8 for Claude-3.7-Sonnet). The method updates only 277M trainable parameters (0.85% of the frozen 32B backbone) and adds ~16–18 ms TTFT overhead.

## Baselines & Comparisons

BRIDGE outperforms all baselines on both benchmark averages. Against the strongest proprietary models, it leads Claude-3.7-Sonnet by +0.10 PersonaScore and +3.1 CoSER, and GPT-4o by +0.13 and +4.1 respectively. Under backbone-matched comparison on Qwen2.5-32B-Instruct, BRIDGE surpasses the best PEFT baseline Neeko (dynamic LoRA) by +0.15 PersonaGym and +3.0 CoSER, and LoRA (r=64) by +0.17 and +3.8, indicating gains stem from explicit O-L-M coupling rather than additional trainable parameters. The largest absolute gain is over Character-LLM (+0.57 PersonaGym, +9.2 CoSER), the only specialized persona method tested. CoT prompting (GPT-4o+CoT) narrows the gap to BRIDGE on PersonaGym (4.51 vs. 4.59) but still trails by 2.8 points on CoSER, suggesting inference-time deliberation is complementary yet insufficient to replace persistent state reconciliation. Notably, BRIDGE's Toxicity Control score (4.76) is slightly below Claude-3.7-Sonnet (4.95), reflecting a rubric tension where faithful portrayal of confrontational personas can trigger toxicity detectors.

## Relation to Prior Work

BRIDGE carves new ground at the intersection of persona-grounded dialogue, hierarchical memory, and dual-process cognition, but departs from each thread in a specific way. Unlike prior persona methods (Character-LLM, Neeko, PCL) that treat persona as a static conditioning signal or a set of LoRA weights, BRIDGE explicitly models the triangular O-L-M dependency with a Gauss-Seidel cross-attention cycle and provides a Banach fixed-point convergence guarantee (Theorem 2.2) that no prior dialogue architecture offers. Its hierarchical memory with anchored clipped updates and a Lyapunov-style drift bound (Theorem 2.3) extends MemGPT/MemoryBank-style tiered memory by coupling updates to persona evolution with provable boundedness, rather than relying on retrieval sophistication or forgetting curves. The dual-system fast/slow pathways draw on Kahneman's dual-process framing and ACT-R/SOAR architectures, but instantiate them as learned attention modules with multiplicative context-aware gating rather than prompting strategies.

## Why It Matters / Open Questions

The combination of a convergence guarantee for per-turn state reconciliation and a Lyapunov bound for long-horizon memory drift is, to our knowledge, the first time both stability properties are jointly provided for a dialogue agent, offering a principled design space (relaxation weights, clipping bounds, timescale hierarchy) rather than purely empirical tuning. The asymmetric rupture risk analysis—showing a 59% relative reduction in severe contradictions from only +8.0 mean Character Fidelity—highlights that tail-risk control, not just mean performance, is what matters for trust-sensitive deployments. Limitations include reliance on LLM judges (partially mitigated by a small human study), a single backbone family for main results, and limited coverage of specialized persona baselines (only Character-LLM). Open questions include whether the guarantees hold under distribution shift, how the framework extends to task-adaptive instruction-following beyond role-play, and whether the coupling modules can be further optimized for latency in production settings.

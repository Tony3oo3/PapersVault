## Problem

Applying entropy minimization to autoregressive LLM generation during test-time learning faces two critical challenges: early decoding errors cascade into later tokens causing update drift, and updates on unreliable tokens amplify confident error predictions and trigger model collapse. Existing TTL methods treat all generated tokens indiscriminately or rely on static metrics, failing to distinguish informative reasoning pivots from noise or hallucinated content.

## Input / Output

The method consumes unlabeled test prompts in a streaming fashion (batch size 8), where each batch is processed sequentially: the model generates a response, computes token-level entropy trajectories, selects informative tokens, and updates only LoRA parameters (rank 8 on W_q and W_v) before discarding the data. The output is the generated text response for each prompt plus the incrementally updated LoRA adapter, with no access to ground-truth labels, external retrieval data, or the original training set.

## Method

FG-TTL introduces two complementary mechanisms for selective online adaptation. First, Future-Gain Guided Token Selection (FTS) defines a token-level metric measuring the reduction in downstream entropy after generating that token, computed over an adaptive window N(t) that scales inversely with local entropy volatility; only the top-ρ percentile of high-gain tokens (after filtering near-deterministic tokens) receive gradient updates. Second, Risk-Aware Adaptation (RAA) modulates update intensity via gain-based softmax weighting and adaptive temperature scaling T_t = 1 + α·H(p^(t)), which provably scales the gradient norm by 1/T_t, suppressing backpropagation on uncertain tokens while enabling stronger learning on high-gain pivots. Theoretically, Future-Gain is shown to approximate the normalized conditional mutual information between the current token and the future trajectory under a local stationarity assumption, providing an information-theoretic justification for the selection criterion.

## Results

FG-TTL achieves the best average Exact Match (EM) across all three LLM backbones on six reasoning benchmarks: 35.33% on Llama3.1-8B-Instruct, 42.76% on Qwen2.5-7B-Instruct, and 49.60% on Phi-4-14B. The largest gains appear on the hardest benchmark AIME24, where FG-TTL reaches 13.33% on Llama3.1-8B (vs. 10.00% for the best baseline) and 23.33% on Phi-4-14B (vs. 16.67% for all baselines). On DomainBench (ROUGE-Lsum), FG-TTL achieves 18.32% average, outperforming the best baseline TLM (17.90%) and the base LLM (17.31%).

## Baselines & Comparisons

FG-TTL outperforms all four baselines (TENT, EATA, COME, TLM) on average EM across all three LLM backbones. On Llama3.1-8B-Instruct, FG-TTL (35.33%) beats the strongest baseline TENT (33.73%) by +1.60%, with the largest margin on AIME24 (+3.33 pp over TENT/COME). On Qwen2.5-7B-Instruct, FG-TTL (42.76%) surpasses TENT (41.73%) by +1.03%, and on Phi-4-14B it leads COME (48.11%) by +1.49%. Notably, on the hardest benchmark AIME24 with Phi-4-14B, all four baselines degrade below the base model (16.67% vs. 20.00%), while FG-TTL is the only method that improves (23.33%). On DomainBench, FG-TTL (18.32% ROUGE-Lsum) beats TLM (17.90%) and the base LLM (17.31%), whereas COME and EATA actually reduce performance below the base model.

## Relation to Prior Work

This paper extends entropy-minimization-based test-time adaptation (originally developed for discriminative CV tasks like TENT and EATA) to the autoregressive LLM generation setting, building directly on the TTL paradigm established by TLM (Hu et al., 2025), which adapts LLMs via input perplexity minimization. The key conceptual departure is shifting from input-domain alignment to selective output-based updates: rather than minimizing entropy uniformly over all generated tokens or aligning to input distributions, FG-TTL introduces a Future-Gain metric that identifies tokens reducing downstream uncertainty, grounded in conditional mutual information. The risk-aware temperature scaling mechanism further distinguishes this work from prior TTA methods by providing an explicit gradient-magnitude control tied to intrinsic model uncertainty, addressing the model-collapse failure mode identified in Niu et al. (2023).

## Why It Matters / Open Questions

The paper addresses a practically critical gap: LLMs deployed in production face continuous distribution shifts, and existing TTL methods either require external data (TTT) or treat all generated tokens uniformly, risking error amplification. The finding that high-entropy token selection underperforms even random selection challenges the intuitive assumption that uncertainty marks informativeness, suggesting the field needs better criteria for identifying useful self-supervision signals in autoregressive generation. Limitations include evaluation restricted to mathematical reasoning benchmarks (no open-ended generation or multi-turn dialogue), the added computational overhead of computing Future-Gain and adaptive windows per token, and the reliance on a local stationarity assumption for the theoretical guarantee. Open questions include whether the Future-Gain principle generalizes to non-mathematical domains, whether the adaptive window can be replaced by simpler heuristics, and how the method behaves under adversarial or highly non-stationary streams beyond the 20% corruption test.

## Problem

Existing SAE-based steering methods require contrastive datasets or large activation stores to identify steering directions, and they select features from context-token activations that reflect input processing rather than output production. This confines SAE steering to narrow applications (bias mitigation, knowledge unlearning, jailbreak prevention) and fails to directly capture generation behavior. CorrSteer addresses both gaps by selecting features from generation-time activations correlated with task outcomes, then validating selections through causal intervention.

## Input / Output

The pipeline consumes pre-trained SAEs (Gemma Scope: 16K features × 26 layers; LLaMA Scope: 32K × 32), residual stream activations at generation-time token positions, and binary correctness labels from ~4,000 samples per task. It outputs precomputed steering vectors (scaled SAE decoder columns) added to the residual stream at inference; the SAE is not needed at test time. Correlation is computed via a streaming accumulator with O(1) memory per feature relative to dataset size, and max-pooling aggregates activations across multi-token generations, with mean-pooling used only for long reasoning tasks like GSM8K.

## Method

CorrSteer is a two-stage, fully automated pipeline that separates correlation (selection heuristic) from causation (intervention test). Stage 1 computes Pearson correlation between each SAE feature's generation-time activation and task correctness scores, retaining only positively correlated features; Stage 2 validates each candidate by testing whether amplifying it actually improves performance, discarding spurious correlations. Three variants ablate selection granularity: CorrSteer-S picks the single most correlated feature globally, CorrSteer-A picks the top feature per layer, and CorrSteer-P prunes CorrSteer-A's set to retain only features that pass the intervention test. Steering coefficients are set to the mean activation over correct samples, anchoring magnitude to the feature's natural scale and exploiting SAE activation non-negativity. At inference, steering is applied exclusively at generation-time positions (t ≥ n, where n is prompt length), adding c_i · W_dec[:,i] to the residual stream at each selected layer, requiring no backward passes, no contrastive data, and no task-specific tuning.

## Results

On Gemma-2 2B, CorrSteer-A achieves 55.48% on MMLU (+3.3% over the 52.21% non-steered baseline) and 73.75% on HarmBench (+27.1% over 46.61%), while maintaining a Side Effect Ratio (SER) of 0.21 on MMLU—half that of fine-tuning (0.41) at comparable accuracy. On LLaMA-3.1 8B, CorrSteer-P dominates, reaching 87.10% on BBQ Ambig and 35.08% on MMLU-Pro. The method requires no contrastive datasets, no backward passes, and scales to 10⁵ SAE features via O(1)-memory streaming correlation, completing the full pipeline in ~9 minutes on a single RTX 5090.

## Baselines & Comparisons

Against SPARE (MI-based selection), CorrSteer-A wins on MMLU (55.48% vs. 54.97%), HarmBench (73.75% vs. 65.43%), and XSTest (86.98% vs. 86.82%), but loses on BBQ Ambig (62.06% vs. 64.81%). Against DSG (Fisher-information selection), CorrSteer-A dominates across nearly all benchmarks, with the largest gap on HarmBench (73.75% vs. 45.86%, a +27.9-point margin) and MMLU (55.48% vs. 52.81%). Against CAA (contrastive activation addition), CorrSteer-A leads on MMLU-Pro (30.93% vs. 28.01%), HarmBench (73.75% vs. 43.14%), and XSTest (86.98% vs. 72.95%), though CAA edges ahead on BBQ Ambig (62.40% vs. 62.06%). Compared to fine-tuning, CorrSteer-A matches MMLU accuracy (55.48% vs. 55.75%) while halving the SER (0.21 vs. 0.41); fine-tuning retains an advantage on MMLU-Pro (35.32% vs. 30.93%) and GSM8K (47.00% vs. 40.34%), but at the cost of higher side effects and loss of interpretability and reversibility.

## Relation to Prior Work

CorrSteer extends the SAE-based steering paradigm established by Bricken et al. (2023) and Soo et al. (2025), which decompose LLM activations into interpretable features and apply them as steering vectors. The key departure is twofold: prior methods (SPARE, DSG, SAE-TS) select features from context-token activations using mutual information or Fisher information, while CorrSteer selects from generation-time activations using Pearson correlation, then validates via intervention. This shifts the steering target from input processing to output production, enabling application to tasks where generation behavior is the target (safety refusal, multi-step reasoning) rather than only contrastive settings (bias mitigation, unlearning).

## Why It Matters / Open Questions

The paper provides a fully automated, backward-pass-free pipeline for SAE steering that requires no contrastive datasets or task-specific tuning, lowering the practical barrier to interpretable LLM control. The finding that simple linear correlation outperforms theoretically richer selection criteria (MI, Fisher) is grounded in SAE's linear decoder architecture, offering a clear design principle. Limitations remain significant: static steering cannot adapt direction per input, the method depends on pre-trained SAEs currently available only for Gemma and LLaMA families, and multi-step reasoning tasks (GSM8K) show high variance. Open questions include token-level feature gating for reasoning, contextual adaptation, and whether the approach generalizes beyond the two SAE families tested.

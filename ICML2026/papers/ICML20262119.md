## Problem

Existing KV cache compression methods for Large Reasoning Models (LRMs) rely on recent queries to estimate which cached KV pairs will be important in future decoding steps. This assumption breaks down in long-horizon reasoning, where sporadic Thought Revisiting Tokens (TRT) re-attend to distant context (e.g., early task-solving plans), causing recent-query-based eviction to prematurely discard KV pairs that become critical later in the trace.

## Input / Output

BeaconKV consumes pre-RoPE query vectors (stored before positional encoding) alongside the accumulated KV cache during autoregressive decoding. At eviction time, beacon queries are RoPE-rotated to the current decoding step t to simulate a future TRT occurring now, while recent queries retain their original generation positions τ. The output is a compressed KV cache of size B_KV^min = (7/8)·B_KV^max, obtained by retaining top-scoring KV pairs plus a fixed prefix and a small recent-token window.

## Method

BeaconKV is a training-free KV cache compression method built on the observation that global queries (those inducing TRT) form a small number of geometric clusters in the pre-RoPE query embedding space. It maintains a compact set of beacon queries—representatives for each cluster—using Continual FPS, an online Farthest Point Sampling algorithm that fills a bounded buffer and periodically compresses it back to a minimum size, avoiding unbounded query-history storage. At each eviction trigger, the observation query set combines these beacon queries (RoPE-aligned to the current step) with the most recent queries (at their original positions), and KV importance is scored via max-pooling of attention weights across all observation queries and all heads within a GQA group. Max-pooling is used rather than mean-pooling because TRT attention signals are sparse and high-magnitude; mean aggregation would dilute them against the background of local queries. The top-scoring KV pairs are retained alongside always-preserved prefix and recent tokens, and the beacon/recent query sets are merged and re-compressed via FPS after each eviction to track evolving global query patterns.

## Results

On Qwen3-4B with 32K-token generation, BeaconKV with a 2K KV budget reduces peak GPU memory from 77.0 GB (Full KV) to 13.3 GB (5.8× reduction) while improving throughput from 82.3 to 356.4 tokens/s (4.3×) and cutting decode latency from 5573.4 s to 1287.3 s, with only a 3.3-point accuracy drop on LiveCodeBench (54.4% → 51.1%). At matched KV budgets and batch sizes, BeaconKV outperforms RPC by +6.3 points (2K budget) and +12.3 points (1K budget) on LiveCodeBench accuracy while maintaining comparable throughput and memory. Across four models and four reasoning benchmarks, the largest accuracy gain over existing compression methods reaches 31.7 percentage points (Qwen3-14B, AIME24, 1024-token budget).

## Baselines & Comparisons

Against RPC (Song et al., 2025), BeaconKV achieves substantially higher accuracy at identical KV budgets and batch sizes: +6.3 points on LiveCodeBench at a 2K budget (51.1% vs 44.8%) and +12.3 points at a 1K budget (42.2% vs 29.9%), while throughput and peak memory remain within ~3% of RPC. Against SnapKV (Li et al., 2024), BeaconKV improves LiveCodeBench accuracy from 30.9% to 42.2% under the same 1K budget and batch size of 320, with only a marginal increase in decode latency (7790.9 s vs 7594.5 s). Against R-KV (Cai et al., 2025), BeaconKV generally outperforms across the four evaluated models and benchmarks, with the largest gaps appearing in the low-budget regime where R-KV's redundancy-based scoring still relies on recent queries and thus misses Thought Revisiting Tokens. The paper also compares against an Initial+Recent baseline (preserving only the first and last queries), showing BeaconKV's Continual FPS dynamically captures evolving global query patterns that a fixed initial-query set cannot, yielding gains of up to 34.2 points (Qwen3-14B, AIME24: 57.92% vs 23.75%).

## Relation to Prior Work

BeaconKV extends the attention-based KV cache eviction framework established by RPC and R-KV, which score cached KV pairs using attention weights from recent queries. The key conceptual departure is the identification of Thought Revisiting Tokens (TRT) and the empirical discovery that the corresponding global queries cluster into a small number of similarity groups in pre-RoPE query space, motivating the use of beacon queries selected via Continual Farthest Point Sampling. This positions BeaconKV as a training-free alternative to both recent-query-based methods (RPC, R-KV, SnapKV) and trainable eviction policies (TRIM-KV, LightThinker, Fast KVzip), repurposing a classical geometric sampling technique for the novel problem of anticipating future attention shifts in long-horizon reasoning.

## Why It Matters / Open Questions

The 5.8× peak memory reduction and 4.3× throughput gain while preserving near-full-cache accuracy make BeaconKV practically significant for deploying LRMs on single-GPU or memory-constrained hardware, where full KV inference is infeasible for 32K+ token reasoning traces. The TRT observation and the geometric clustering of global queries provide a new lens on LRM attention dynamics that could inform future compression, sparse attention, or adaptive reasoning-length strategies. Open questions include whether the gains generalize to non-reasoning long-context tasks (retrieval, summarization), whether hyperparameters (beacon count, recent window, KV budget) can be adapted dynamically during inference, and how the method behaves on proprietary or architecturally different LRMs.

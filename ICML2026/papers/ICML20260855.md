## Problem

Audio deepfake detectors (ADDs) must be evaluated on diverse synthetic audio to identify failure modes, but existing benchmarks like ASVspoof5 insufficiently explore the output space of individual TTS models, and prior automated methods either rely on manual prompt engineering or optimize perturbations on already-generated audio, limiting them to local regions. No prior method automatically discovers natural adversarial examples—challenging audio generated directly from the TTS process without post-hoc transformations—under black-box access to all components.

## Input / Output

FoeGlass takes as input a black-box ADD (outputting a realness probability in [0,1]), a black-box TTS model (accepting transcripts plus generation parameters such as speed, temperature, style, and voice), a reasoning LLM (DeepSeek-R1 distilled on Llama-3.1-8B), and a WavLM embedding model for diversity scoring. The LLM produces TTS input transcripts constrained to at most 5 sentences of natural English with prompting techniques, formatted as JSON. The output is a set of 500 false-negative audio samples per TTS model (audio the ADD misclassifies as real) along with their corresponding TTS input transcripts and CoT rationales.

## Method

FoeGlass iteratively queries a reasoning LLM to generate TTS inputs, using a carefully designed in-context prompt that combines an instruction template, the most recent ℓ/2 failed attacks with their chain-of-thought (CoT) explanations, and the ℓ/2 highest-scoring successful attacks with their CoT. After each TTS generation, two feedback signals are computed: an ADD realness score (the detector's output probability) and a diversity score defined as the minimum cosine distance between the new sample's WavLM embedding and all previously generated embeddings. If the diversity score falls below a threshold τ_d, the LLM is explicitly instructed to modify the transcript for greater variety, preventing mode collapse. The CoT outputs from the reasoning LLM are fed back into the context at subsequent iterations, enabling the model to track and build upon its own reasoning trajectory. The entire pipeline requires only black-box access to the LLM, TTS model, and ADD—no gradient access or fine-tuning of any component is needed.

## Results

FoeGlass achieves up to 94% FNR improvement over unconditional sampling (e.g., 2.24% → 96.29% on VIT-VoxCelebSpoof-ConstantQ with xTTS-v2). Across the 24 TTS×ADD combinations, FoeGlass cold start typically raises FNR by 30–80 percentage points, and warm start (requiring only 3 seed examples) adds a further 2–15 points. Fine-tuning RawNetLite on FoeGlass-generated VITS data improves detection accuracy from 49.6% to 8.2% FNR (a 41% absolute accuracy gain) on held-out VITS audio, versus only 20% improvement from unconditional sampling. Attacks also transfer across ADDs, with transferred FNRs consistently exceeding the unconditional baseline in nearly all cross-model settings.

## Baselines & Comparisons

The primary baseline is unconditional sampling, where the same DeepSeek-R1 LLM generates TTS transcripts without any realness or diversity feedback. FoeGlass cold start outperforms this baseline in 22 of 24 TTS×ADD combinations, with the largest gap being +94 pp (xTTS-v2 on VIT-VoxCelebSpoof-CQT: 2.24% → 96.29%). Warm start (3 seed examples) further improves FNR in most settings, e.g., +7 pp on VITS/ViT-ASVspoof5-CQT (74.20% → 81.34%) and +32 pp on Kokoro-82M/ViT-VoxCelebSpoof-MelSpec (7.52% → 39.72%). Against ASVspoof5's own VITS and xTTS-v2 subsets (Table 3), FoeGlass-generated data yields FNRs of 81–94% versus 0.004–6.65% for the benchmark data, confirming that the benchmark underexplores high-error regions. FoeGlass attacks also transfer across ADDs: in the cross-model heatmap (Fig. 3), transferred FNRs exceed the unconditional baseline in nearly all source→target pairs, with the strongest transfer observed from VoxCelebSpoof-trained ViT models to ASVspoof5-trained counterparts. The one notable exception is the AST-ASVspoof5 model, where FoeGlass provides minimal gains (e.g., 4.24% → 4.86% for xTTS-v2), suggesting this architecture is comparatively robust to the discovered failure modes.

## Relation to Prior Work

FoeGlass adapts the LLM red-teaming paradigm (Perez et al., 2022) from jailbreaking language models to attacking audio deepfake detectors, but departs from the RL/fine-tuning-based attacker approaches by relying solely on in-context learning with a reasoning LLM, avoiding the need for model weights and the mode collapse that plagues fine-tuned attackers. It also distinguishes itself from prior adversarial perturbation work on ADDs (Li et al., 2025; Rabhi et al., 2024), which operates in the waveform or latent space of already-generated audio, by instead searching the TTS input space to produce entirely new natural adversarial examples. The closest prior work is Zhu et al. (2024b), which uses a genetic algorithm to search a fixed-length prompt space for text-to-image models; FoeGlass replaces this with open-ended in-context reasoning and a diversity feedback mechanism.

## Why It Matters / Open Questions

The paper demonstrates that state-of-the-art spoofing benchmarks like ASVspoof5 leave large regions of the TTS output space unexplored, and provides a practical, black-box tool to systematically surface those blind spots without manual prompt engineering. The transferability of attacks across different ADD architectures and the ability to improve detector robustness via fine-tuning on FoeGlass data make this directly useful for the ADD evaluation and hardening pipeline. Key open questions include whether the approach generalizes to commercial/closed-source detectors, how to set the diversity threshold optimally across different embedding spaces, and whether the exploration/exploitation tradeoff can be made adaptive rather than hyperparameter-driven.

## Problem

The previously known Õ(T^{3/4}) regret bound for linear bandits with memory stems from a loose analysis that treats jointly-chosen block actions as sequentially adaptive, inflating estimation error linearly with block length. Moreover, no Õ(√T) regret guarantee existed for generalized linear bandits with memory, where curvature-dependent confidence geometry interacts with the constraint that parameter updates are delayed until block completion.
![Teaser figure](../imgs/ICML20260100/cropped_page2_idx0.webp)

## Input / Output

At each round the agent selects an action x_t from a bounded set X ⊂ R^d (‖x‖₂ ≤ 1) and observes a stochastic reward y_t from a canonical exponential family whose mean is μ(⟨x_t, A_{t-1}θ*⟩), where the memory matrix A_{t-1} = (I_d + Σ_{s=1}^m x_{t-s}x_{t-s}^⊤)^γ is determined by the last m actions. The algorithm operates in blocks of length m+L: it commits to an entire block before receiving any feedback, updates the OMD parameter estimate only at block boundaries, and outputs both the selected action block and the updated curvature-weighted Gram matrix H_τ.

## Method

The key insight is to treat each block as a single combinatorial decision rather than a sequence of adaptive actions, which decouples the leading √T estimation term from block length L. For the linear case, this is achieved by keeping the confidence radius with respect to the block-level Gram matrix V_τ and bounding the residual within-block mismatch via an eigenvalue telescoping argument, improving OFUL-memory from Õ(T^{3/4}) to Õ(√T) without algorithmic changes. For the GLM case, GLBM-SCB uses OMD-based parameter estimation, an information warm-up phase until the curvature-weighted Gram matrix is well-conditioned, and a shrunken confidence bound that incorporates feature information from actions already placed in the current block. Because curvature-weighted information is unavailable within a block, the algorithm certifies possible curvature values by maximizing and minimizing μ̇ over an enlarged pre-block confidence set, constructing conservative auxiliary information matrices. A separate block-safety bonus guarantees optimism at the block level, and the algorithm selects the block maximizing estimated reward plus the maximum of the shrunken SCB bonus and the safety bonus, yielding Õ(√T) regret whose leading term is independent of the link-function curvature parameter κ.

## Results

The paper's primary contribution is theoretical: it improves the regret bound for linear bandits with memory from the previously known $\widetilde{\mathcal{O}}(T^{3/4})$ (Clerici et al., 2024) to $\widetilde{\mathcal{O}}(\sqrt{mdT} + \sqrt{d\max\{d,R^2\}T})$ (Theorem 1), and introduces a new $\widetilde{\mathcal{O}}(\sqrt{mT} + d\sqrt{T} + \sqrt{\kappa}\,d^2 m^{1/4}T^{1/4} + \kappa d^2)$ regret bound for generalized linear bandits with memory (Theorem 2). Crucially, the leading $\sqrt{T}$-type term in Theorem 2 is independent of the link-function curvature parameter $\kappa$, and the algorithm does not require prior knowledge of $\kappa$. Numerical experiments (Figure 3) confirm that GLBM-SCB outperforms both memory-ignoring and oracle-greedy baselines in logistic rotting/rising environments, and outperforms OFUL-memory in a linear rotting environment.

## Baselines & Comparisons

The paper compares GLBM-SCB against three baselines across three environments. Against GLB-OMD (Zhang et al., 2025), a state-of-the-art generalized linear bandit algorithm that ignores memory effects, GLBM-SCB consistently achieves higher cumulative reward in both the logistic rotting (Figure 3a) and logistic rising (Figure 3b) environments, with the performance gap widening over time. Against Oracle Greedy, which has full access to the true parameter $\theta^*$ and selects actions myopically, GLBM-SCB also outperforms in both nonlinear environments, demonstrating that block-level planning is essential even with perfect parameter knowledge. In the linear rotting environment with larger memory length (Figure 3c), GLBM-SCB achieves higher cumulative reward than OFUL-memory (Clerici et al., 2024), consistent with the theory predicting that the shrunken-confidence design separates the dependence on memory length $m$ and feature dimension $d$.

## Relation to Prior Work

This paper extends the linear bandit with memory framework of Clerici et al. (2024) to generalized linear reward models, while simultaneously sharpening the regret analysis of the original linear algorithm from Õ(T^{3/4}) to Õ(√T) without modifying the algorithm itself. The key analytical tool is a combinatorial-decision viewpoint borrowed from Jin et al. (2021) on shrinking confidence bounds in combinatorial bandits, which decouples within-block uncertainty from the block-level Gram matrix. For parameter estimation in the nonlinear setting, the paper adopts the OMD-based confidence framework of Zhang et al. (2025) and Zhang & Sugiyama (2023), adapting it to the block-structured, memory-dependent feature geometry.

## Why It Matters / Open Questions

The result that the T^{3/4} regret barrier for linear bandits with memory is an analytical artifact rather than an intrinsic limitation of memory-induced non-stationarity is a clean conceptual contribution to the bandit literature. The extension to GLMs with a leading regret term independent of the curvature parameter κ is, to the authors' knowledge, the first such guarantee for action-induced endogenous non-stationary generalized linear bandits. Open questions include extending the analysis to approximate block-optimization oracles (the current proof assumes an exact maximization oracle) and to settings where the memory parameters (m, γ) are unknown, for which the paper only sketches a bandit-combiner adaptation.

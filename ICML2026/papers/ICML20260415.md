## Problem

Evaluating LLMs' true inductive generalization and scientific discovery is increasingly difficult because static benchmarks are vulnerable to data contamination and cannot test active, self-guided exploration. Existing deep research benchmarks rely on fixed datasets, while scientific inference benchmarks are typically restricted to numerical tabular data. No prior framework simultaneously supports interactive scenarios, independently scalable complexity across multiple axes, and contamination resistance through procedural generation.
![Teaser figure](../imgs/ICML20260415/cropped_page2_idx0.webp)

## Input / Output

The model receives synthetic scenarios where data is presented at varying representation levels (raw variable assignments, 1–2 sentence text, 5–8 sentence text, or PDF/XLSX files with embedded samples) and varying interaction protocols (static context, active experimentation with an oracle tool, or access to scikit-learn symbolic solvers). The model must produce a free-form natural language theory (no format constraints), which is then converted by the same model into a deterministic Python classifier function. Evaluation computes a custom multi-label accuracy (Acc_ctx on seen samples, Acc_test on 1000 held-out samples) that penalizes both omissions and hallucinated labels by normalizing correct matches by the maximum label count in either ground truth or prediction.

## Method

SEDRAS is a modular, procedurally generated benchmark with three independently scalable complexity axes: (1) UDD complexity, controlled via the number of categorical/numerical variables, interaction rules (conditional overrides that supersede individual variable effects in a weighted voting mechanism), output categories, and auxiliary output properties; (2) representation complexity, where a synthesizer LLM maps UDD variables to domain-specific semantic aliases and renders samples as text or files; (3) dynamics complexity, ranging from static ingestion to active experimentation (with run_experiment and evaluate_theory tools) to symbolic solver access. The key design choice is that the model under test acts as all LLM components in the pipeline—converting its own theory to code and translating its own textual experiment queries—so any error in the loop is attributed to the model. SEDRAS-2026 comprises 600 scenarios generated by combinatorially pairing 5 UDD levels × 4 representation tiers × 3 dynamics settings × 10 sample-budget intervals, with UDD parameters initialized via a 20-generation evolutionary search to ensure balanced class distributions and decisive rule margins.

## Results

On SEDRAS-2026 (600 procedurally generated scenarios), Gemini 3.0 Pro achieves the best overall accuracy of 54.5%, followed by Claude Opus 4.5 (50.4%) and GPT 5.2 Thinking High (47.7%). GPT 5.2 dominates on raw symbolic data (62.1% vs. 52.8% for Gemini), while Claude Opus 4.5 leads on file-based representations (47.3%) and symbolic solver settings (53.0%). Critically, all models perform worse than a random exploration baseline in the active experimentation setting, with post-static accuracy dropping below 0.6 regardless of the number of experiments executed, revealing a fundamental deficit in strategic data acquisition.

## Baselines & Comparisons

Gemini 3.0 Pro (54.5% total) outperforms Claude Opus 4.5 (50.4%) by 4.1 points overall, driven primarily by superior performance on static scenarios (58.7% vs. 46.6%) and textual representations (60.8% text, 58.5% text long vs. 48.8%/49.9%). However, Claude Opus 4.5 surpasses Gemini on file-based tasks (47.3% vs. 45.9%) and symbolic solver settings (53.0% vs. 51.2%). GPT 5.2 Thinking High (47.7%) is the clear winner on raw symbolic data at 62.1%, exceeding Gemini by 9.3 points, but trails significantly on all textual representations (44.2% text vs. 60.8% for Gemini). Grok 4.1 Reasoning (47.5%) shows the smallest performance degradation as UDD complexity increases from Level 1 to Level 5, making it the most robust to logical complexity scaling, though it suffers the largest drop on file representations (37.3%). All four top models fail to outperform random exploration in the active experimentation setting, with post-static accuracy capped below 0.6, indicating a shared limitation in strategic inquiry rather than a model-specific weakness.

## Relation to Prior Work

SEDRAS carves new ground at the intersection of three previously separate benchmark families: symbolic regression/scientific law discovery (AI Feynman, Empirical-Bench, NewtonBench), interactive agentic evaluation (GAIA, AgentBench, AutoBench), and deep research benchmarks (DeepResearch Bench, HypoBench). While NewtonBench introduced procedural generation to resist contamination and HypoBench generated rule-grounded textual scenarios, neither combined interactive exploration with multi-representation data or decoupled complexity along independent axes. The key conceptual departure is the modular architecture that treats the underlying data distribution, its textual/file representation, and the interaction protocol as independently scalable dimensions, enabling fine-grained diagnostics that prior single-axis benchmarks cannot provide.

## Why It Matters / Open Questions

The finding that all evaluated SOTA models perform worse than a random baseline at active data exploration is a significant negative result that challenges the assumption that LLM reasoning capabilities translate to strategic scientific inquiry. The modular, procedurally generated framework offers a contamination-resistant evaluation path that can scale alongside model capabilities, addressing a core limitation of static benchmarks. Open questions include whether targeted training on such interactive scenarios would remediate the exploration deficit, whether the framework's text-only representation module limits its applicability to truly multimodal scientific discovery, and how the 'deep research' framing (which currently lacks web search and citation validation) will evolve as the framework expands.

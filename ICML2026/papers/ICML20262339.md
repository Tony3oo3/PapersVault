## Problem

Pretrained graph models cannot generalize to unseen datasets with different feature dimensionalities or semantics because standard GNNs encode knowledge through weight matrices tied to fixed feature spaces. While GraphAny achieved the first fully inductive inference on arbitrary graphs, it operates on linear predictions rather than learning node representations through feature-space transformations, limiting its expressiveness as a representation learner. This paper asks whether graph structure itself can provide a universal, feature-agnostic representational axis that enables a single pretrained model to produce useful node embeddings for any graph.

## Input / Output

The model consumes a node-feature matrix X ∈ R^{N×F} and an adjacency matrix A ∈ {0,1}^{N×N} of arbitrary sizes N and F, with no constraint on feature dimensionality or semantics. It outputs node representations Z ∈ R^{N×F} that preserve the original feature dimensionality (no compression), which are then fed to a lightweight per-dataset predictor (linear classifier or single-hidden-layer MLP) to produce class labels. The recurrent depth L is selected per dataset via validation accuracy without retraining the encoder, and the entire pipeline requires no per-dataset fine-tuning of the representation function.

## Method

The core mechanism is the view space: multiple adjacency preprocessing operators (view finders, e.g., powers of row-normalized and symmetric-normalized adjacency) propagate the node-feature matrix along a new third axis, producing a tensor X̃ ∈ R^{N×F×C} where each (n,f) entry is a C-dimensional view vector. A shared MLP φ maps each view vector to a scalar, yielding the output Z; because φ is applied independently per (n,f) pair, the construction is provably equivariant to both node and feature permutations (fully inductive). The nonlinear φ enables node-feature dynamic aggregation: local linearization shows that each node-feature pair receives its own input-dependent aggregation weights over the view finders, a granularity beyond existing node-wise or edge-wise dynamic GNNs. Recurrent GVT (RGVT) applies this single GVT layer L times with shared parameters, decoupling receptive-field depth from parameterization so that depth can be chosen per dataset without retraining. Pretrained on OGBN-Arxiv, the frozen encoder transfers to 27 benchmarks with only a lightweight predictor trained, outperforming 12 individually tuned GNNs by +3.30% on average.

## Results

Pretrained on OGBN-Arxiv and applied fully inductively (frozen encoder, only a lightweight predictor trained per dataset), RGVT+MLP achieves 71.13% average accuracy across 28 node-classification benchmarks spanning seven feature types. This surpasses the best dataset-specialized GNN (UniMP, 68.86%) by +3.30% and the prior fully inductive model GraphAny (best variant, 65.30%) by +8.93%. RGVT+Linear also outperforms all 12 GNNs on average (70.03%), and a Wilcoxon signed-rank test confirms statistical significance (p < 0.05) over every GNN except GPRGNN (p = 0.07).

## Baselines & Comparisons

Against the prior fully inductive model GraphAny (Zhao et al., ICLR 2025), RGVT+MLP wins on 26 of 27 downstream benchmarks, achieving an average gain of +8.93% over GraphAny's best pretraining variant (65.30% → 71.13%), with the largest margins on one-hot features (+8.67%) and binary sparse features (+8.29%). Against 12 individually tuned and trained GNNs, RGVT+MLP outperforms all of them on average: the closest competitor UniMP (Shi et al., IJCAI 2021) reaches 68.86%, while RGVT+MLP achieves 71.13% (+3.30%). The gap is most pronounced on one-hot features (RGVT+MLP 62.48% vs. best GNN SGC 62.54%, essentially tied) and binary sparse features (63.87% vs. GPRGNN 60.61%, +3.26%), while on OGBN-Arxiv itself RGVT+MLP (71.11%) trails GATv2 (72.13%) by ~1%. A Wilcoxon signed-rank test across all 28 datasets confirms statistical significance (p < 0.05) for RGVT+MLP over every GNN except GPRGNN (p = 0.07). Notably, RGVT achieves these results without any per-dataset encoder training—only a lightweight linear or single-layer MLP predictor is fit—whereas each GNN required at least two days of hyperparameter tuning per dataset.

## Relation to Prior Work

This paper repurposes standard GNN adjacency preprocessing operations (degree normalization, random walk, spectral filters) as 'view finders' and stacks their outputs into a new structure-induced axis—the view space—thereby reframing aggregation as a view-space operation rather than a feature-space transformation. It directly extends GraphAny (Zhao et al., 2025), the first fully inductive graph model, by shifting from direct prediction via linear predictors to representation learning (FI-NRL) with a learnable dimension-collapsing map, and by adding the feature-permutation equivariance requirement (R2) that GraphAny does not enforce. The recurrent architecture draws from RNNs to decouple depth from parameterization, addressing the over-smoothing and fixed-depth limitations that plague stacked GNN layers. Conceptually, the paper positions itself as the graph-structured analogue of tokenization in NLP and patchification in CV, providing the standardized input format that has been missing for heterogeneous numerical graph data.

## Why It Matters / Open Questions

The view space provides a principled, provably fully inductive framework that eliminates the need for per-dataset feature-space alignment or fine-tuning, a major practical bottleneck in cross-dataset graph learning. The node-feature dynamic aggregation—a granularity finer than any existing GNN (which operate at node or edge level)—opens a new axis of expressivity for structural message passing. Key limitations remain: GVT cannot model explicit cross-feature interactions (a deliberate scalability tradeoff), recurrent depth must still be selected per dataset via validation, and the framework is currently limited to node classification. Open directions include extending to edge- and graph-level tasks, hypergraphs, and replacing the lightweight predictor with scalable tabular foundation models for truly zero-training inference.

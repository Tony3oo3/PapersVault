## Problem

Existing graph coarsening methods are designed for static graphs and require full recomputation of the coarsening matrix after every graph update, making them infeasible for large-scale or real-time dynamic settings. No prior work addresses efficient, structure-preserving coarsening for discrete-time evolving graphs where nodes, edges, and connectivity patterns change at discrete intervals, leaving a gap between static coarsening theory and the practical needs of evolving graph systems.
![Teaser figure](../imgs/ICML20261414/cropped_page3_idx0.webp)

## Input / Output

The framework takes a sequence of discrete-time graph snapshots with node features and an initial coarsening matrix C_0 (obtained from any static method such as FGC, LVN, or LHE) as input. At each subsequent time step, it produces an updated coarsening matrix C_t by computing only the incremental assignment block for newly added nodes (and optionally a reassignment block for existing nodes in ACNR), which is vertically concatenated with the prior matrix. The output coarsened graph Laplacian and feature matrix are derived via the standard C^T L C and C^† X projections, with the number of supernodes n fixed across all time steps.

## Method

The paper proposes a unified dynamic coarsening framework with two optimization-based algorithms. DIGC exploits the block structure of the evolving adjacency matrix to solve a non-convex objective for only the new-node assignment ΔC_t via projected gradient descent, keeping all prior supernode mappings immutable for efficiency. ACNR extends this by jointly optimizing both a new-node assignment ΔC_Nt and an adaptive reassignment ΔC_St for previously coarsened nodes using block coordinate descent, enabling error recovery under broader topological changes. Both methods incorporate temporal structural consistency, feature alignment, and (in ACNR) topology-refinement terms, with convergence guaranteed via L-smoothness bounds and an ε-similarity bound that quantifies spectral distortion in the coarsened representation relative to the evolving original graph.

## Results

On ACM and DBLP citation networks, ACNR achieves the lowest Relative Eigen Error (REE) across all three static initializers: 0.248 (LHE-init) and 0.292 (LVN-init) on ACM, and 0.331 (LVN-init) and 0.361 (LHE-init) on DBLP, compared to 0.622–0.763 for the corresponding static re-computation baselines. For node classification, ACNR preserves 98.6–99.8% of the static baseline accuracy (e.g., 89.57% vs. 91.05% on ACM with LVN), while DIGC preserves 96.2–98.1%. Runtime and peak GPU memory are substantially reduced: DIGC and ACNR avoid full re-computation at each time step, with DIGC being the fastest and most memory-efficient option.

## Baselines & Comparisons

The paper compares DIGC and ACNR against three static re-computation baselines (FGC, LVN, LHE) that recompute the full coarsening matrix from scratch at every time step. ACNR consistently outperforms all three baselines on REE: it reduces REE by ~49% over FGC(BASE) on ACM (0.527 vs. 1.041), by ~53% over LVN(BASE) (0.292 vs. 0.622), and by ~67% over LHE(BASE) (0.248 vs. 0.763). On DBLP, ACNR similarly beats FGC(BASE) (0.733 vs. 0.847), LVN(BASE) (0.331 vs. 0.617), and LHE(BASE) (0.361 vs. 0.679) on REE. For Reconstruction Error (RE) and Hyperbolic Error (HE), DIGC and ACNR are competitive with or slightly above the static baselines, indicating that the incremental updates preserve spectral structure at a cost of minor reconstruction distortion. For downstream node classification, ACNR preserves 98.6–99.8% of baseline accuracy while DIGC preserves 96.2–98.1%, confirming that the dynamic updates serve as high-fidelity proxies for full re-computation. Against the heuristic dynamic baselines (NSA-Feat, NSA-Ovlp), both DIGC and ACNR substantially outperform on all structural metrics, with the heuristics often incurring higher error than even the static re-computation baseline due to cumulative drift from greedy assignments.

## Relation to Prior Work

This paper extends the optimization-based static graph coarsening lineage (FGC, LVN, LHE) to the discrete-time dynamic setting by formulating incremental updates to the coarsening mapping matrix rather than recomputing from scratch. It departs from prior dynamic coarsening work (robotics, materials science, streaming visualization) that targets domain-specific objectives or continuous-time updates, and from spectral sparsification methods that preserve cut/flow properties rather than learning-task fidelity. The ε-similarity bound generalizes the spectral preservation guarantees of Loukas (2019) and Kumar et al. (2023) to the incremental dynamic regime, while the two-stage DIGC/ACNR design mirrors the fixed-vs-adaptive reassignment trade-off seen in continual learning but applied to the coarsening operator itself.

## Why It Matters / Open Questions

This is the first framework to provide structure-preserving, provably convergent incremental coarsening for discrete-time evolving graphs, filling a gap between static coarsening (which requires full recomputation) and domain-specific dynamic pooling (which lacks spectral guarantees). The practical impact is significant for real-time graph analytics on citation networks, social platforms, and network topologies where full re-coarsening is infeasible. Key limitations include the non-convex optimization (relying on SGD convergence rather than global optimality), DIGC's error lock-in under poor initialization, and the assumption that the number of supernodes n remains fixed across time steps. Open questions include whether the framework extends to continuous-time event streams, whether the fixed-supernode constraint is too restrictive for graphs with changing community structure, and how performance scales to graphs with millions of nodes.

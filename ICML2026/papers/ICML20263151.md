## Problem

Existing abstract reasoning benchmarks face a fundamental tradeoff: manually designed tasks like ARC demand genuine reasoning but are limited in scale, while large-scale datasets risk measuring rote memorization rather than true rule induction. Additionally, LLM-generated tasks may contain hallucinated logical errors, and there is no principled way to distinguish genuine algorithmic reasoning from sophisticated pattern matching in model outputs.
![Teaser figure](../imgs/ICML20263151/cropped_page1_idx0.webp)

## Input / Output

The pipeline consumes inspiration rules sampled from ARC and a task-type specification (dimension: 1D sequence, 2D grid, or 3D voxel; domain: symbolic or semantic) to produce formally verified reasoning tasks. Each task is encoded as a pair of executable Python functions (forward encoder f and inverse decoder g) plus programmatically derived example pairs and a query input, ensuring consistency by construction. The evaluation produces accuracy scores, a symbolic dependency gap (Δ_S) measured via token remapping (e.g., '0'→'a'), and a cognitive quality label (Surface Fitting, Inferior Rule, or True Generalization) assigned by an Analyst LLM using an Occam's-Razor heuristic.

## Method

A²RBench is a four-stage automated pipeline (seed generation, task expansion, evaluation, analysis) whose core theoretical contribution is Theorem 3.1: cycle consistency g(f(x))=x over the input space guarantees a task is well-posed (unique, consistent, verifiable), enabling deterministic filtering without human judgment. Seeds are generated by an Author LLM that first proposes a bijective rule in natural language (validated by a Judge LLM), then implements it as paired Python functions; the cycle consistency check programmatically eliminates hallucinated logic. Expansion reuses each validated seed's rule code while an Expander LLM generates up to nine new input variations across three difficulty phases (standard, edge-case, adversarial), reducing per-task cost by 38×. Evaluation compares solver outputs against ground truth via a Judge LLM, and a symbol-remapping diagnostic (P1 protocol) quantifies over-reliance on familiar tokens. Analysis combines AST-based code complexity metrics with an Analyst LLM that classifies each correct answer's reasoning quality against the ground-truth rule, enabling diagnosis beyond binary accuracy.

## Results

On A²RBench (1,054 tasks), the top-performing model Gemini3-Pro achieves only 40.9% overall accuracy, with GPT-5 at 39.0% and GPT-5-Mini at 36.9%. On a representative 108-task seed subset, the best model scores 39.8% versus 68.5% for human participants, revealing a fundamental gap in abstract reasoning. The symbolic dependency gap (ΔS) ranges from 1.1% (Qwen3-32B) to 17.7% (GPT-5), quantifying over-reliance on familiar tokens. A consistent 1D > 3D > 2D performance hierarchy emerges across all models, attributed to a generative capability ceiling in author models rather than intrinsic task difficulty.

## Baselines & Comparisons

This is a benchmark paper evaluating 14 LLMs rather than comparing a single method against baselines. Gemini3-Pro leads overall at 40.9% accuracy, narrowly ahead of GPT-5 (39.0%) and GPT-5-Mini (36.9%), but all fall far short of the 68.5% human baseline on the 108-task seed subset. GPT-5 achieves the highest semantic accuracy (52.0%) but suffers the largest symbolic dependency gap (17.7%), indicating heavy reliance on familiar tokens; in contrast, Claude-Sonnet-4.5 and Qwen3-32B show minimal gaps (1.7% and 1.1%) but lower overall accuracy. The generalization gap between seed (V0) and augmented (V1-9) tasks is small for top models (e.g., Gemini3-Pro: 39.8% → 41.0%), suggesting the bottleneck is rule induction rather than input generalization. A striking 1D > 3D > 2D hierarchy appears across all models, with 2D tasks authored by O4-mini causing the sharpest drops (Gemini3-Pro: 58.9% on 1D → 22.2% on 2D), revealing a generative complexity ceiling rather than a solver limitation.

## Relation to Prior Work

This paper extends the two-stage formalization of abstract reasoning (abstraction then rule application) from Ma et al. (2025) and the symbolic dependency metric for measuring token reliance, but departs fundamentally from prior LLM-driven benchmark generation by replacing subjective LLM-judge verification with deterministic code execution. Where prior automated approaches (self-play, LLM-as-a-judge, generator-solver frameworks) inherit model hallucination and lack ground-truth guarantees, A²RBench enforces bijective rule structure and proves that cycle consistency g(f(x))=x is sufficient for well-posedness, providing a one-time formal certificate of logical integrity. The pipeline also builds on program-aided prompting (PAL, Program of Thoughts) by treating the rule itself as executable code rather than merely a reasoning scaffold.

## Why It Matters / Open Questions

The cycle consistency theorem offers a clean, provable foundation for automated benchmark verification that avoids the circularity of using one LLM to judge another, making it a potentially reusable paradigm for other formally checkable reasoning domains. Key open questions include whether the framework extends beyond bijective rules to many-to-one tasks (where information loss prevents inversion), whether the analyst LLM's Occam's-Razor proxy can be replaced by mechanistic interpretability of internal states, and whether the author-model generative ceiling can be lifted with stronger models to produce genuinely harder tasks. The benchmark's economic efficiency (~$0.016/task vs. $25–50 for ARC) makes large-scale cognitive evaluation feasible, but the current 1,054-task scale and restriction to discrete symbolic/semantic transformations limit immediate applicability to continuous or multimodal reasoning.

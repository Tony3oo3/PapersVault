## Problem

Existing clustering-based vision backbones (e.g., CoC, FEC) rely on a single clustering algorithm whose inherent inductive bias limits representational capacity, as formalized by the No Free Lunch theorem. No prior architecture has embedded multiple heterogeneous clustering algorithms as core architectural primitives within a single end-to-end differentiable backbone.
![Teaser figure](../imgs/ICML20264602/cropped_page0_idx0.webp)

## Input / Output

The backbone consumes RGB images (224×224 for classification, 1333×800 for detection, 512×512 for segmentation) and internally represents them as a set of N discriminative feature points P ∈ R^{N×D} rather than a structured grid. The DEC module produces enhanced point-level features P′ via residual redistribution of cluster-level information, which are then passed to task-specific heads yielding class labels, bounding boxes, or pixel-wise masks. The architecture is hierarchical with four stages of progressive spatial downsampling (50176 → 3136 → 784 → 196 → 49 points).

## Method

ENFORMER replaces the single-clustering block in prior backbones with a Deep Ensemble Clustering (DEC) module that operates in two differentiable steps. In Ensemble Generation, input features are projected into T distinct subspaces, each processed by a dedicated base clustering method (partitional via Gumbel-Softmax, fuzzy via softmax, possibilistic via sigmoid, or probabilistic via GMM log-likelihood), producing diverse cluster representations C^t. In Consensus Aggregation, all cluster representations are concatenated into a unified dictionary C′, and primary features query this dictionary via a differentiable softmax-based assignment to adaptively weight and redistribute structural information back to point-level features through a residual update. This replaces the non-differentiable co-association matrix of classical ensemble clustering with a learnable feature-reconstruction objective, enabling end-to-end joint optimization. The ensemble size is balanced against per-component channel dimension to keep total compute comparable to a single-clustering backbone, and the default configuration (Partitional + Fuzzy, T=2) achieves peak accuracy with minimal overhead.

## Results

On ImageNet-1K, ENFORMER-Large achieves 82.6% Top-1 accuracy with 29.4M parameters and 4.8G FLOPs, outperforming the strongest clustering-based baseline FEC-Large (81.2%) by +1.4% while delivering 1.8× higher throughput (621.7 vs. 342.1 img/s). On COCO val2017, ENFORMER-Large reaches 44.0 AP^box and 40.0 AP^mask, surpassing FEC-Large by +4.1 and +2.7 respectively. On ADE20K, ENFORMER-Large achieves 46.6 mIoU, exceeding FEC-Large by +6.1 mIoU. Across all three tasks, ENFORMER consistently outperforms existing clustering-based backbones (CoC, FEC) at comparable or lower parameter counts.

## Baselines & Comparisons

Against the closest clustering-based competitors, ENFORMER dominates: ENFORMER-Large beats FEC-Large by +1.4% Top-1 (82.6 vs. 81.2) with 1.8× throughput, and ENFORMER-Base matches FEC-Large's accuracy (81.2%) while using fewer FLOPs (2.5G vs. 6.5G) and 3× higher throughput. On COCO, ENFORMER-Small/Base/Large gain +5.7/+4.9/+4.1 AP^box over FEC-Small/Base/Large; on ADE20K, the gains are +8.0/+6.6/+6.1 mIoU. Against attention-based backbones, ENFORMER-Large (82.6%) surpasses Swin-Tiny (81.3%) by +1.3% at comparable throughput, though Swin-Small (83.0%) remains slightly ahead at a larger scale (50M params). Among MLP-based methods, ENFORMER-Base (81.2%) outperforms ResMLP-24 (79.4%) and gMLP-S (79.6%) by ~1.6–1.8%. For CNN baselines, ENFORMER-Base exceeds ResNet50 (79.8%) by +1.4% with fewer FLOPs. Against the newer paradigms in Table 8, ENFORMER-Large (82.6%) outperforms Mamba-ViT-S (81.1%), ViG-S (80.4%), and ConvNeur-M4 (81.5%), while ClusterFormer-Small (83.4%) at 48.7M params remains the only method exceeding ENFORMER-Large's accuracy.

## Relation to Prior Work

ENFORMER extends the clustering-based vision backbone paradigm established by CoC (Ma et al., ICLR 2023) and FEC (Chen et al., CVPR 2024), which frame feature extraction as a single clustering operation over image points. The key departure is drawing on classical ensemble clustering (Strehl & Ghosh, 2002; Fred & Jain, 2005) to replace the single clustering algorithm with an ensemble of heterogeneous differentiable base methods (partitional, fuzzy, possibilistic, probabilistic), combined with a differentiable consensus mechanism that replaces the traditional non-differentiable co-association matrix. This positions ENFORMER as the first architecture to embed multiple clustering algorithms as core architectural primitives within a supervised vision backbone.

## Why It Matters / Open Questions

ENFORMER demonstrates that the representational bottleneck of single-clustering backbones can be alleviated by integrating complementary clustering perspectives, yielding consistent gains across classification, detection, and segmentation while maintaining throughput comparable to single-clustering designs. The finding that a small ensemble (T=2, Partitional + Fuzzy) is optimal and that adding more heterogeneous components introduces conflicting structural biases rather than purely complementary information highlights a non-trivial diversity-compatibility tradeoff. Open questions include whether dynamic per-sample routing of clustering components (explored briefly via an MoE variant) can further improve performance, whether the framework extends to non-parametric or spectral clustering, and whether the architecture is well-suited for self-supervised pretraining paradigms.

## Problem

ReAct-based deep research agents follow a strictly linear execution path, making it difficult to revisit earlier states, branch into alternative search directions, or maintain global awareness under long contexts. The paper identifies that up to 93% of failed trajectories contain planned-but-unexplored branches, and that existing multi-trial approaches (majority voting, Best-of-N) run independent rollouts with no cross-trajectory information sharing, leading to redundant exploration and missed opportunities for experience consolidation.

## Input / Output

The agent takes a research query as the initial input; in subsequent rounds, it additionally receives a structured state representation from the prior round (containing verified evidence, unresolved uncertainties, failed attempts, and forward-looking plans) prepended as the initial user message after the system prompt. The agent produces a final answer to the research question and, at the end of each rollout, emits a structured state representation following a fixed compression specification with facets for analytical conclusions, evidence provenance, and exploration gaps. For frontier models, the state includes additional audit facets (failed attempts, uncompleted proposals) not present in the base version used for smaller SFT models.

## Method

Re-TRAC recursively compresses each ReAct trajectory τ_t into a structured state S_t via a fixed compression specification C (S_t ← Compress(τ_t, S_{t-1}; C)), then conditions the next rollout on S_t, enabling cross-trajectory knowledge consolidation over up to K=8 sequential rounds. The state representation captures three complementary facets—answer conclusions, evidence with source verification, and uncertainties with exploration traces—explicitly preserving unresolved candidate branches while filtering low-level trace details. This design transforms exploration from disconnected attempts into a progressively informed search: tool calls drop monotonically from ~44 in round 1 to ~11 in round 8, reducing effective compute to ~4× a single ReAct run rather than 8×. For small models (4B, 30B), the paper introduces Re-TRAC-aware SFT, distilling 104k trajectories from GLM-4.7 over 33K synthesized questions (4 rounds each), teaching the model to both generate and consume structured states rather than relying on prompting alone. The framework is training-free for frontier models and operates as a meta-layer on top of any existing ReAct agent without replacing the inner loop.

## Results

On BrowseComp (full set), RE-TRAC-30B-A3B achieves 53.0% accuracy, surpassing its base model Tongyi-DeepResearch-30B (43.4%) by 9.6 points and outperforming the much larger GLM-4.7-358B (52.0%) and MiniMax-M2-229B (44.0%). The 4B model reaches 30.0% on BrowseComp, setting a new state-of-the-art among sub-15B models (next best: AgentCPM-Explore-4B at 25.0%). As a training-free test-time scaling method on o3, Re-TRAC lifts BrowseComp300 accuracy from 54.9% (Pass@1) to 69.8% (+14.9), outperforming Majority Voting (64.3%), Weighted Voting (70.0%), and Best-of-8 (68.0) at roughly 4× compute rather than 8×.

## Baselines & Comparisons

RE-TRAC-30B-A3B outperforms its base model Tongyi-DeepResearch-30B by 9.6 points on BrowseComp (53.0 vs 43.4), 10.6 on BrowseComp-ZH (57.3 vs 46.7), 7.3 on GAIA (78.2 vs 70.9), and 8.0 on XBench (83.0 vs 75.0). It also surpasses the 7.5× larger MiniMax-M2-229B on BrowseComp (53.0 vs 44.0) and GLM-4.7-358B (53.0 vs 52.0), and beats all closed-source models on GAIA (78.2 vs GPT-5's 76.7). Among sub-15B models, RE-TRAC-4B leads every benchmark: BrowseComp 30.0 vs AgentCPM-Explore-4B's 25.0, GAIA 70.4 vs NestBrowse-4B's 68.9, and XBench 76.6 vs NestBrowse-4B's 74.0. As a training-free TTS method on o3, Re-TRAC (69.8) edges out Weighted Voting (70.0) and Best-of-8 (68.0) while using ~4× compute instead of 8×, and substantially outperforms IterResearch (62.7) and ReSum (51.9) on the same o3 backbone. The 4B model's light configuration (one ReAct + one Re-TRAC round, ~1.7× Pass@1 cost) already reaches 21.7% on BrowseComp, surpassing InfoAgent-14B (15.3%) and WebExplorer-8B (15.7%) at a fraction of the inference budget.

## Relation to Prior Work

Re-TRAC builds directly on the ReAct paradigm (Yao et al., 2023b) as its inner execution loop, but departs fundamentally from the linear, single-trajectory design by introducing a cross-trajectory structured state compression mechanism. It positions itself against intra-trajectory context management approaches (ReSum, IterResearch, MemAgent) that compress or rewrite context within a single rollout, arguing that the core failure mode is incomplete branch exploration *across* rollouts rather than context length within one. In the test-time scaling literature, Re-TRAC introduces a sequential dimension absent from parallel methods (Self-Consistency, Multi-Agent Debate, ParallelMuse), where each round conditions on a compressed summary of all prior rounds rather than operating on independent samples.

## Why It Matters / Open Questions

The practical implication is significant: a 30B model with Re-TRAC matches or exceeds 229B–358B models on BrowseComp, suggesting that structured cross-trajectory memory can partially substitute for raw model scale in deep research, enabling competitive on-device agents. The finding that the structured state format must be explicitly learned via SFT (nearly doubling performance) rather than merely prompted (marginal gain) is an important practical insight for anyone fine-tuning small agentic models. Key open questions include whether self-training on Re-TRAC trajectories can remove the dependency on a strong teacher, whether the framework generalizes to non-web-search domains, and how to handle the wall-clock latency trade-off (sequential rounds vs. parallel TTS) in latency-sensitive deployments.

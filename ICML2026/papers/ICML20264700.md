## Problem

Existing autonomous agents are constrained to a single, predefined action space, which limits generalization across diverse tasks and introduces compounding errors through decoupled high-level planning and low-level execution. No single action abstraction (language skills, motion primitives, coordinates) achieves state-of-the-art performance across all task types, yet prior architectures cannot dynamically select or compose multiple abstraction levels during inference.
![Teaser figure](../imgs/ICML20264700/cropped_page0_idx0.webp)

## Input / Output

The agent receives first-person RGB frames at 360×640×3 resolution and a natural-language instruction as input. It produces a typed, multi-level action chain (e.g., <skill>chop down a tree</skill> → <point>mine log (500,500)</point> → <motion>turn left</motion> → <raw>press(w)</raw>) where each level is tagged with a special token identifying its action space. The final executable output is a sequence of discrete keyboard presses, mouse clicks, and mouse displacements (1800 bins each for yaw and pitch) that directly step the Minecraft environment.

## Method

DeepHA pairs a Qwen2-VL-7B high-level VLM with a Mixture-of-Policies (MoP) module of specialized ~100M-parameter Transformer-XL + Impala-CNN expert policies, one per action space. The VLM autoregressively generates a full action hierarchy where each higher-level action conditions the next lower-level one (factorized as a chain of conditional probabilities), effectively using abstract actions as structured 'thoughts' that prune the combinatorial action space at each step. Three inference modes (Direct, Greedy, Eager) let the user trade reasoning depth against latency, with Eager Mode supporting learned dynamic termination via a special stop token. A hierarchical memory mechanism dynamically compresses completed low-level action history while preserving active high-level goals, synergizing with KV caching to cut context length by ~75% without performance loss. Training follows a three-stage SFT pipeline (domain knowledge → mixed action prediction → hierarchy-structured chains) followed by multi-turn RL with a GRPO variant that rewards task success while penalizing unnecessarily long action chains.

## Results

On the expanded 800+ task Minecraft benchmark, DeepHA(RL) achieves state-of-the-art ASR across all four task categories: 62.3% on Mine Blocks, 45.4% on Kill Entities, 51.9% on Craft Items, and 88.6% on Smelt Items. It also attains the highest Bo10 scores (86.2–93.5) and the fewest average steps (248–305) among all evaluated agents. The ablation on action chain depth shows consistent gains from deeper hierarchies: raw-only (depth 1) yields 30.0% ASR, while the full Grounding→Motion→Raw chain (depth 3) reaches 48.9%.

## Baselines & Comparisons

DeepHA(RL) outperforms all nine baselines across every task category where they overlap. Against the strongest hierarchical agent, OpenHA, DeepHA gains +32.2 points on Mine Blocks (62.3 vs. 30.1), +12.9 on Kill Entities (45.4 vs. 32.5), +20.0 on Craft Items (51.9 vs. 31.9), and +22.0 on Smelt Items (88.6 vs. 66.6). Against the best VLA baseline, JARVIS-VLA, the margins are +32.3 (Mine Blocks), +26.9 (Kill Entities), +26.8 (Craft Items), and +23.2 (Smelt Items). PointHA, the strongest spatial-reasoning specialist, is surpassed by +25.2 on Mine Blocks and +18.9 on Kill Entities, confirming that DeepHA's flexible action-space selection subsumes single-modality strategies. The instruction-conditioned policies (VPT, STEVE-I, ROCKET-1) and remaining hierarchical agents (LanguageHA, MotionHA, LatentHA) trail by 20–50+ points, with several unable to complete any tasks in Craft Items or Smelt Items.

## Relation to Prior Work

DeepHA departs from the dominant hierarchical-agent paradigm (RT-H, PARM-E, OpenHA) in which a high-level LLM is constrained to a single, manually predefined action space and decoupled from a separately trained low-level policy. Instead, it unifies planning and execution within a single VLM (Qwen2-VL) that generates a typed action from a mixture of heterogeneous spaces (skills, grounding, motion, raw), dispatched via a Mixture-of-Policies module. The token-repurposing technique for action generation is borrowed from RT-2, and the RL stage uses a GRPO variant from DeepSeekMath, but the core architectural contribution—the action hierarchy as sequential 'thoughts' that prune the action space at each level—is a new formulation that bridges VLA models and structured hierarchical agents.

## Why It Matters / Open Questions

The 75% context-memory reduction that simultaneously *improves* success rate (39.6% vs. 38.5% for full memory) is practically significant for long-horizon embodied tasks where context blowup is a known failure mode. The consistent monotonic gain from deeper action chains (30%→49% ASR) provides clean evidence that inference-time compute scaling via structured reasoning transfers to motor control, not just language. However, all evaluation is confined to Minecraft with domain-specific baselines, so whether the MoP + action-hierarchy framework generalizes to robotics, GUI agents, or other open-world settings remains an open question. The RL training pipeline (100B tokens in Stage 1) is also computationally expensive, limiting immediate reproducibility.

## Problem

State space models (SSMs) offer linear-time alternatives to attention for long-sequence modeling, but their first-order, rank-one memory updates suffer from spectral anisotropy, gradient vanishing, and memory interference over extended horizons. Existing mitigations—scalar gating, normalization, or transition-matrix parameterization—control update magnitudes but do not explicitly condition the geometry of accumulated updates or introduce temporal inertia into the recurrence, leaving long-range signal propagation and optimization stability unaddressed at the structural level.

## Input / Output

MuonSSM is a drop-in replacement for the memory update mechanism in existing SSM backbones, consuming the same per-timestep key-value-query projections (k_t, v_t, q_t) and producing the same output y_t = S_t q_t, so no downstream interface changes are required. In practice this spans text token sequences (4096-token pre-training, 8K-context retrieval evaluation), RGB images processed through hierarchical SSM mixers (ImageNet-1K, COCO, ADE20K), and 512-length windows of 6-channel inertial sensor signals for activity recognition. The augmented state [S_t, M_t] doubles the internal memory dimension from d×m to d×2m, but the output projection and loss computation remain identical to the base SSM.

## Method

MuonSSM augments SSM memory dynamics with two components: a momentum matrix M_t that accumulates update directions across timesteps via M_t = γM_{t-1} + NS(τβ_t v_t k_t^⊤), and a single-iteration Newton-Schulz (NS) transformation applied to each rank-1 input injection to bound singular values into [0, ~1.2] while preserving rank. The NS operator's backward Jacobian has a structurally distinct geometry from Frobenius normalization: it amplifies directions fully orthogonal to the current write (eigenvalue a≈3.44) while attenuating mixed directions (a+b+c≈0.70), driving progressive rank enrichment in the accumulated momentum state. The coupled memory-momentum dynamics are cast as a block-affine recurrence Z_t = Z_{t-1}Φ_t + Ψ_t with a 2m×2m transition matrix, which admits parallel associative scans with O(log L) depth and O(L) total work, preserving the scan-compatible structure of the underlying SSM. Theoretically, the momentum pathway introduces a non-vanishing gradient channel (γI)^{T-t+1} that mitigates exponential decay through contractive memory transitions, while the NS conditioning empirically reduces the state condition number by approximately 18×, yielding more uniform long-range gradient propagation and improved length generalization beyond the training horizon.

## Results

On the Needle-in-a-Haystack (S-NIAH) retrieval benchmark, MuonSSM achieves the most dramatic gains at 8K context (trained at only 2K): Mamba PassKey accuracy jumps from 8.8% to 15.8%, LongHorn from 20.0% to 39.3%, and Gated DeltaNet from 25.7% to 44.5%. On ImageNet-1K classification, LongHorn+Muon reaches 82.01% top-1 (vs. 81.63% baseline) and reduces Mean Corruption Error on ImageNet-C from 111.68 to 111.24. On the MMAct time-series benchmark, Mamba+Muon improves accuracy from 71.46% to 74.65% and F1 from 71.68% to 74.25%. MuonSSM also accelerates pre-training convergence by approximately 1.3× while preserving O(L) total work and O(log L) parallel depth.

## Baselines & Comparisons

MuonSSM is evaluated as a drop-in augmentation on three SSM backbones: Mamba, LongHorn, and Gated DeltaNet. Against Mamba, MuonSSM wins on every reported metric across all three modalities, with the largest relative gains in S-NIAH 8K (e.g., PassKey 8.8→15.8%, a 79% relative improvement) and MMAct accuracy (71.46→74.65%). Against LongHorn, MuonSSM wins on nearly all metrics; the standout is S-NIAH PassKey at 8K (20.0→39.3%, nearly doubling), while a minor 1.2-point drop at 2K PassKey (67.9→66.7) is the only loss. Against Gated DeltaNet, MuonSSM wins on all S-NIAH metrics (e.g., UUID 8K: 24.3→33.1%), all ImageNet robustness metrics (IN-R 41.55→42.18, IN-A 19.92→20.47), and all time-series benchmarks. The one exception is Mamba's ImageNet-A top-1, which drops marginally from 20.57 to 20.50. Overall, MuonSSM consistently outperforms all three baselines, with gains scaling with task difficulty and context length.

## Relation to Prior Work

MuonSSM sits at the intersection of three research threads: (1) the recent unification of SSMs (Mamba, DeltaNet, Gated DeltaNet, LongHorn) as associative memory with first-order rank-one updates, (2) momentum-augmented recurrent dynamics (MomentumRNN, Mega), and (3) lightweight spectral conditioning via Newton-Schulz iterations (as in the Muon optimizer). The key departure from prior SSM work is the axis of intervention: rather than reparameterizing the recurrent transition matrix (HiPPO, diagonal parameterizations) or adding scalar gates, MuonSSM conditions the geometry of the input-dependent low-rank memory injections and introduces a parallel momentum state, all while preserving the block-affine structure needed for O(log L) parallel scans.

## Why It Matters / Open Questions

The paper provides a clean, drop-in mechanism for stabilizing SSM training that is validated across three modalities and three backbones, with the most compelling evidence in long-context retrieval (S-NIAH) where 8K accuracy roughly doubles for some architectures. The capacity ablation (doubling d_state vs. adding Muon) is a well-controlled experiment that isolates geometric conditioning from mere parameter expansion. Limitations include evaluation at moderate scale (170M language model, Tiny vision models), fixed conditioning hyperparameters, and modest absolute gains (1–3%) on most standard benchmarks. Open questions include whether the approach scales to billion-parameter pretraining, whether adaptive or learned NS coefficients help, and how it interacts with hybrid attention-SSM architectures.

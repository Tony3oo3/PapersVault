## Problem

In Multimodal Diffusion Transformers (MMDiTs), text tokens are jointly processed with visual latents through a unified transformer stack, but the diffusion loss supervises only visual predictions. This supervisory asymmetry causes token-level prompt semantics to become progressively unrecoverable in deeper layers—a phenomenon the paper terms prompt forgetting—yet no prior work had systematically characterized this layer-wise degradation or proposed a training-free remedy.

## Input / Output

The method operates on a pre-trained MMDiT (SD3-medium, SD3.5-large, FLUX.1-dev, or Qwen-Image) at 1024×1024 resolution, requiring only a one-time calibration pass over COCO-5K prompts to compute a per-layer-pair orthogonal Procrustes rotation matrix. At inference, it consumes the standard text prompt and noise schedule, injecting aligned shallow-layer text features into deeper blocks during each denoising step, and outputs a generated image with improved instruction following—no model parameters are modified.

## Method

Prompt Reinjection is a training-free, inference-time intervention that extracts text-token features from a shallow origin layer (chosen just after the initial distributional transition into the denoiser) and reinjects them into all subsequent target layers via residual addition. To handle cross-layer distributional and geometric mismatches, the method applies two alignment steps: (1) Distribution Anchoring, which Layer-Normalizes both origin and target features before fusion and then restores the target layer's mean and standard deviation after injection; and (2) Geometry Alignment, which rotates the origin features into the target layer's coordinate frame using an orthogonal Procrustes matrix computed via SVD on calibration data. The injected signal is scaled by a small weight (w=0.025), and the origin layer is selected empirically per architecture (e.g., layer 1 for SD3, layer 2 for FLUX) to balance semantic fidelity with cross-layer compatibility. The approach is validated by showing that layer-wise probing accuracy stabilizes across depth when reinjection is enabled, and by consistent gains on GenEval, DPG-bench, and T2I-CompBench++ without degrading human-preference or CLIP alignment scores.

## Results

On GenEval, Prompt Reinjection improves overall scores by 6.48% for SD3.5 (0.7179→0.7644) and 5.64% for FLUX (0.6613→0.6986), with the largest relative gains on Position tasks (e.g., SD3.5: 0.2575→0.3200, FLUX: 0.1950→0.2525). On DPG-Bench, overall scores improve from 85.43→87.12 (SD3) and 83.64→86.99 (SD3.5). On T2I-CompBench++, gains are consistent across attribute binding (Color: 0.7929→0.8416 for SD3), spatial relations (2D-Spatial: 0.2913→0.3044), and texture (0.7092→0.7496). Human-preference metrics (HPSv2, ImageReward, PickScore) and CLIP score are maintained or marginally improved, confirming no quality degradation.

## Baselines & Comparisons

The only external baseline directly compared is TACA (Lv et al., 2025), a timestep-aware reweighting method that requires LoRA fine-tuning (rank r=64). On FLUX GenEval, Prompt Reinjection achieves 0.6986 overall versus TACA's 0.6793, a 2.7% absolute advantage. TACA's largest gain is on Position (0.1950→0.2723), but Prompt Reinjection improves more categories simultaneously (Overall, Two obj., Counting, Colors, Color attr, Position) and reaches a higher overall score. The paper's primary comparison is against each model's own base configuration (without reinjection), where Prompt Reinjection consistently wins across all four models (SD3, SD3.5, FLUX, Qwen-Image) on every GenEval sub-task, DPG sub-task, and T2I-CompBench++ sub-task. The method is training-free and adds only ~8.8% FLOPs per transformer block, whereas TACA requires additional LoRA parameters and fine-tuning.

## Relation to Prior Work

This paper carves new ground by being the first to systematically characterize and name 'prompt forgetting'—the progressive loss of token-level semantic information in the text branch of MMDiTs—as a distinct phenomenon, using CKNNA, PCA drift analysis, and layer-wise probing. It departs from prior instruction-following interventions (Attend-and-Excite, BLIP3-O, layout control) that target U-Net cross-attention and do not transfer to the joint-attention MMDiT design. Among MMDiT-specific analyses, it is most closely related to TACA (Lv et al., 2025), which addresses text-image token imbalance via timestep-aware reweighting, and Li et al. (2026), which amplifies selected-layer text features; Prompt Reinjection differs by targeting the depth-wise degradation directly through geometrically aligned residual injection rather than attention reweighting or layer selection.

## Why It Matters / Open Questions

Prompt Reinjection offers a simple, training-free, plug-and-play inference-time fix that consistently improves instruction following across four MMDiT architectures (2B–20B) without degrading image quality, making it immediately deployable. The finding that even a 20B model (Qwen-Image) still suffers measurable prompt forgetting in complex spatial and counting tasks suggests this is a fundamental architectural property of joint-attention MMDiTs rather than a small-model artifact. Key limitations include the need for per-model manual selection of origin layer and injection weight, and the fact that cross-depth distributional mismatch still caps the usable injection strength (w < 0.1). Open directions include learning layer- or timestep-dependent weights, fine-tuning with reinjection to enable stronger injection, and adding direct text-branch supervision during training to prevent forgetting at its source.

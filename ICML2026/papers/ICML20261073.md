## Problem

Neuromorphic event cameras produce sparse, asynchronous event streams that are fundamentally incompatible with the dense, regular tensor paradigm of mainstream deep learning. Existing approaches either densify events into frames (sacrificing microsecond temporal resolution and spatial sparsity) or rely on irregular architectures like SNNs, sparse CNNs, and GNNs that fail to exploit GPU parallelism. The paper asks whether events can be embedded directly into a vector space—drawing an explicit analogy to word2vec in NLP—so that standard, GPU-accelerated Transformer backbones can process them natively without any densification step.

## Input / Output

The method consumes a raw asynchronous event stream where each event is a tuple (x, y, t, p) encoding pixel coordinates, a microsecond-precision timestamp, and a binary polarity. Because deep learning frameworks require fixed-length batches, variable-length streams are reduced to a fixed sequence of L events via either uniform random sampling or a GPU-accelerated Batched K-Means++ clustering that preserves polarity channels and assigns each cluster an intensity factor ρ. The output is a single class label produced by average-pooling the Transformer's sequence output and passing it through a linear head.

## Method

Event2vec maps each event to a D-dimensional vector by additively fusing three components: (1) a parametric spatial embedding, a small 3-layer MLP φ that maps normalized (x̄, ȳ, p̄) coordinates to a vector, whose continuity guarantees that spatially adjacent pixels receive similar embeddings (satisfying a locality inductive bias that a standard lookup-table embedding lacks); (2) a convolutional temporal embedding, a stack of 1D convolutions (kernel 3, stride 1) operating on the first-order differences of normalized timestamps Δt, which provides time-shift invariance and local smoothing of noisy inter-event intervals; and (3) a log-scaled intensity factor ρ that weights clustered events by their raw event count. These event tokens are fed into a bidirectional Forgetting Transformer backbone (with parameter-shared forward/reverse passes to mitigate long-sequence memory decay), followed by average pooling and a linear classifier. For the more challenging DVS-Lip task, the model is first self-supervised pre-trained with a BERT-style masked modeling objective that corrupts spatial coordinates and polarity and trains the network to reconstruct them from temporal context.

## Results

On DVS Gesture, Event2Vec achieves 97.57±1.31% accuracy with only 0.52 MB parameters, slightly below Max-Former (98.6%, 1.45 MB) but with 2.79× fewer parameters. On ASL-DVS, Event2Vec reaches 99.91±0.05% with 0.27 MB, surpassing the prior best GNN&Transformer (99.60%, 220.30 MB) by 0.31 points while using 815.93× fewer parameters. On DVS-Lip, Event2Vec achieves 75.88% (with K-Means++ cluster events) using 18.30 MB, outperforming Spiking ResNet18&BiGRU (75.3%, 223.63 MB) and ResNet-18&BiGRU (72.1%, 241.20 MB). In throughput, Event2Vec delivers 4.21×–35.36× higher training throughput and 2.69×–62.67× higher inference throughput than prior SOTA across the three datasets.

## Baselines & Comparisons

On DVS Gesture, Event2Vec (97.57%) trails Max-Former (98.6%) and SNN+Frame (98.23%) by ~1 and ~0.7 points respectively, but uses 2.79× and 12.5× fewer parameters; it beats FARSE-CNN (96.6%) and is within 0.2 points of Sparse GRU (97.80%) and Event MAE (97.75%). On ASL-DVS, Event2Vec (99.91%) clearly outperforms both GNN+CNN (90.10%) and GNN&Transformer (99.60%), achieving the highest accuracy with 815.93× fewer parameters than the latter. On DVS-Lip, Event2Vec (75.88%) surpasses Spiking ResNet18&BiGRU (75.3%) by 0.58 points and ResNet-18&BiGRU (72.1%) by 3.78 points, while using 12.22× fewer parameters than the former. In the event-count robustness comparison (Figure 3), Event2Vec with simple random sampling consistently outperforms the more sophisticated voxel-grid sampling strategies of Araghi et al. (2025) across all tested event budgets. Overall, Event2Vec trades a small accuracy margin on DVS Gesture for dramatic gains in parameter count, throughput (up to 62.67× inference), and latency (as low as 11.12% of prior SOTA on ASL-DVS).

## Relation to Prior Work

This paper draws a direct structural analogy between word2vec in NLP and event representation in neuromorphic vision, positioning events as a 'language' with a finite vocabulary (spatial-polarity addresses), sequential ordering (timestamps), and context-dependent meaning. It departs from dense representations (frames, voxels) that sacrifice sparsity and temporal resolution, and from irregular methods (SNNs, sparse CNNs, GNNs, point clouds) that are GPU-inefficient. The closest prior work is EventNet, which similarly factorizes events into spatial-polarity and temporal components, but EventNet uses lookup tables and is designed for asynchronous CPU processing; event2vec replaces the lookup table with a continuous parametric network and the hand-designed temporal coding with learnable convolutions on Δt, making the representation natively compatible with GPU-accelerated Transformers (specifically the Forgetting Transformer backbone).

## Why It Matters / Open Questions

The paper demonstrates that sparse asynchronous event streams can be processed directly by standard GPU-parallel Transformer architectures without densification, achieving up to 815× parameter reduction and 62× throughput improvement over prior SOTA while matching or exceeding accuracy. The conceptual framing of events as a sequential language opens a path toward applying LLM-style architectures (masked modeling, autoregressive generation) to neuromorphic vision, which the authors partially explore via self-supervised pre-training. Open questions include whether this representation generalizes to dense prediction tasks (detection, segmentation, depth), whether it scales to higher-resolution sensors with millions of events per frame, and whether the efficiency gains translate to actual neuromorphic hardware deployment rather than GPU simulation.

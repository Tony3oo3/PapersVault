## Problem

Long-horizon LLM agents accumulate unbounded interaction contexts that cause prohibitive KV-cache memory costs and reasoning degradation from irrelevant information. Existing compression approaches either rely on brittle handcrafted heuristics or require gradient-based model updates, making them inapplicable to proprietary, API-based LLMs. No prior method optimally compresses both environment observations and interaction histories in a fully model-agnostic manner without fine-tuning the agent.

## Input / Output

The method consumes two types of dynamic context: the accumulated interaction history h_{t-1} (a sequence of observation-action pairs) and the latest environment observation o_t, each compressed only when exceeding length thresholds (T_hist=4096, T_obs=1024 for AppWorld). Outputs are natural-language compressed summaries that preserve heterogeneous state signals (causal relations, evolving states, preconditions, decision cues), plus the optimized compression guideline itself—a refined prompt that encodes environment-specific retention rules. The guideline is the persistent artifact; the compressed context is regenerated per-step during inference.

## Method

ACON optimizes compression guidelines (natural-language prompts) rather than model weights, using an LLM-as-optimizer (o3) in a two-phase loop: a Utility Maximization (UT) step that contrasts successful uncompressed trajectories against failed compressed ones to generate natural-language feedback identifying lost critical information, and a Compression Maximization (CO) step that conditions on successful compressed trajectories to encourage shorter yet sufficient contexts. This contrastive feedback acts as a textual gradient, iteratively refining the guideline without any agent weight updates. After optimization, the compressor is distilled into smaller models (Qwen3-14B, Qwen3-8B, Phi-4) via LoRA fine-tuning with cross-entropy loss on teacher-generated compressed outputs from successful tasks, preserving >95% of teacher accuracy while reducing compression cost by 99%. The entire pipeline is model-agnostic, enabling configurations like a gpt-4.1 agent paired with a Qwen3-14B compressor.

## Results

On AppWorld (gpt-4.1 agent/compressor), ACON_UTCO history compression achieves 56.5% task accuracy with 7.33K peak tokens, matching the no-compression upper bound (56.0%) while reducing peak tokens by 26%. On OfficeBench, ACON_UTCO reaches 72.63% accuracy at 4.54K peak tokens (37% reduction vs. 7.27K no-compression). On 8-objective QA, ACON_UT history compression attains 0.373 EM / 0.494 F1 at 4.71K peak tokens, surpassing the no-compression F1 (0.488) while cutting peak tokens by 55%. For small distilled agents (Qwen3-14B), ACON yields 32% relative improvement on AppWorld, 20% on OfficeBench, and 46% on Multi-objective QA by mitigating long-context distraction.

## Baselines & Comparisons

ACON dominates all five baselines on AppWorld history compression: ACON_UTCO (56.5% acc, 7.33K peak) outperforms FIFO (45.8%), Retrieval (27.4%), LLMLingua (39.3%), and Prompting (43.5%) by 13–29 points in accuracy while using fewer peak tokens than no-compression (9.93K). On OfficeBench, ACON_UTCO (72.63%) beats FIFO (67.37%), Retrieval (65.26%), LLMLingua (70.53%), and Prompting (71.58%) with 37% lower peak tokens. On 8-objective QA, ACON_UT achieves the best F1 (0.494) among all compressed methods, edging out Prompting (0.478) and LLMLingua (0.481), while ACON_UTCO attains the lowest peak tokens (4.65K) and dependency (1.50×10⁶) of any method. The key differentiator is that ACON's optimized guidelines preserve task-critical state information (e.g., API parameters, authentication tokens) that heuristic baselines like FIFO and Retrieval discard, and that extractive methods like LLMLingua cannot retain due to their token-level scoring. For observation compression, ACON_UTCO (53.6% on AppWorld) substantially outperforms Prompting (42.3%) and LLMLingua (32.1%), confirming that guideline optimization generalizes beyond history to raw environment observations.

## Relation to Prior Work

ACON builds directly on the natural-language-gradient paradigm from Yuksekgönül et al. (2025) and the LLM-as-optimizer framework from Yang et al. (2024a), repurposing them to iteratively refine compression prompts via contrastive trajectory feedback rather than fine-tuning model weights. It departs from RL-based agent compression methods (MEM1, ContextFolding, AgentFold) that couple reasoning and compression within a single trainable model, and from heuristic baselines (FIFO, retrieval, LLMLingua) that lack task-specific adaptability. The key conceptual departure is treating compression guideline optimization as a prompt-level, model-agnostic process that decouples the agent from the compressor, enabling proprietary API models to serve as agents while open-source models handle compression.

## Why It Matters / Open Questions

ACON addresses a practical bottleneck for deploying long-horizon agents with proprietary LLMs, where gradient-based compression is infeasible, and demonstrates that a sub-$2 optimization loop plus LoRA distillation can reduce compression cost by 99% while preserving 95%+ of teacher performance. The finding that compression improves (rather than merely preserves) accuracy for smaller agents—by up to 46%—suggests that context distraction is a first-order failure mode for mid-scale LMs, not just a secondary efficiency concern. Open questions include whether the natural-language optimization converges reliably, how the framework behaves under real-world deployment with stochastic task complexity, and whether KV-cache-aware compression strategies can eliminate the latency overhead that currently offsets token savings.

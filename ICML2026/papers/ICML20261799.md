## Problem

State-of-the-art LLMs (GPT-5, Gemini 3, Claude 4.6) are accessible only through black-box APIs, precluding the gradient-based policy optimization (PPO, GRPO) that underpins modern RL fine-tuning. This leaves practitioners restricted to prompt engineering or fine-tuning open-weight surrogates, with no principled way to perform RL-style optimization of the target black-box model itself.
![Teaser figure](../imgs/ICML20261799/cropped_page0_idx0.webp)

## Input / Output

The method takes a frozen black-box LLM policy (e.g., GPT-5.1 via API), environment state observations, and a task instruction as input. At test time it runs N=15 parallel trajectories through the black-box agent, with a lightweight LoRA-finetuned transformer value function (e.g., Llama-3.2-11B) evaluating states only at resampling steps via a single prefill. The output is a weighted set of trajectories approximating the optimal policy; in deployment, the single highest-reward trajectory is selected. The value function is trained offline via supervised regression on trajectories sampled from the prior, requiring no online interaction or gradient access to the policy.

## Method

AMC exploits the equivalence between KL-regularized RL and Bayesian inference, where the optimal policy π* is a posterior over trajectories with the black-box LLM as prior and an exponential reward term as likelihood. It applies Sequential Importance Resampling (SIR) to sample from this posterior: N trajectories are drawn in parallel from the frozen prior, and at designated resampling steps their importance weights are updated via w_t = w_{t-1} · exp(V(s_t) − V(s_{t-1}) + r(s_{t-1})/β), where V is a learned soft value function. The value function V_θ is parameterized as f_θ(s_t) + r(s_t) (a transformer regression head plus the immediate reward) and trained by supervised MSE regression on Monte Carlo trajectories from the prior, approximating the log-sum-exp soft value with a single-trajectory target. Low-weight trajectories are stochastically pruned and high-weight ones proliferated during resampling, steering the particle set toward the optimal posterior without ever modifying the black-box model's parameters.

## Results

On WebShop, AMC with a Llama-3.2-11B policy achieves a score of 0.625, outperforming Best-of-15 (0.562) and SMC with Fleet-of-Agents prompting (0.580). On SciWorld, AMC with GPT-4.1-mini reaches 0.673 versus 0.616 for Best-of-15, and on TextCraft, AMC with GPT-4.1-mini achieves 0.852 versus 0.728 for Best-of-15. Against GRPO on SciWorld, AMC with a GPT-5.1 policy and Qwen-2.5-7B value function scores 0.518 at N=5, substantially exceeding GRPO's 0.183 with a Qwen-2.5-7B backbone, and AMC with the same Qwen-2.5-3B backbone surpasses GRPO (0.216 vs. 0.182) at N=20.

## Baselines & Comparisons

AMC consistently outperforms the single-trajectory ReAct baseline by large margins across all three benchmarks (e.g., 0.625 vs. 0.159 on WebShop with Llama-3.2-11B). Against SMC with Fleet-of-Agents prompting (Klein et al., 2025), AMC achieves 0.625 vs. 0.580 on WebShop, demonstrating that a learned value function surpasses hand-crafted prompt-based state evaluation. On SciWorld, AMC combined with a ReflAct-style policy (Kim et al., 2025) reaches 0.376, exceeding both standalone ReflAct (0.051) and Best-of-15 ReflAct (0.347). In the head-to-head comparison with GRPO (Shao et al., 2024), AMC with a GPT-5.1 black-box policy and Qwen-2.5-7B value function scores 0.518 at N=5 on SciWorld, far exceeding GRPO's 0.183 with a Qwen-2.5-7B backbone; with the same Qwen-2.5-3B backbone for both policy and value function, AMC at N=20 (0.216) surpasses GRPO (0.182). The one notable exception is TextCraft with GPT-5.1, where Best-of-15 (0.889) slightly exceeds AMC (0.790), which the authors attribute to GPT-5.1's high prior quality leaving limited room for value-function-guided pruning.

## Relation to Prior Work

This paper operationalizes the well-known equivalence between KL-regularized RL and Bayesian inference (Korbak et al., 2022; Levine, 2018) in a setting where prior work has not applied it: black-box LLM agents. While SMC has been used for planning in continuous control (Piché et al., 2019; Lioutas et al., 2023) and for steering LLM text generation via logit access (Lew et al., 2023; Zhao et al., 2024), those approaches are inapplicable to proprietary APIs. The closest prior work—Fleet of Agents (Klein et al., 2025) and Rollout Roulette (Puri et al., 2025)—also uses population-based sampling for LLM agents but relies on heuristic or prompt-based value estimates; AMC departs by training a parameterized soft value function grounded in the control-as-inference formulation, and by targeting multi-step interactive environments with external tool calls rather than single-turn generation.

## Why It Matters / Open Questions

AMC provides the first principled, gradient-free mechanism to perform RL-style optimization of frontier black-box LLM agents, addressing a practical gap that prompt engineering and open-weight surrogates cannot fill. The finding that a small (11B) value model can effectively steer GPT-5.1, and that GPT-4.1-mini + AMC matches GPT-5.1 at over 50% lower cost, has direct implications for deployment economics. Key limitations include performance inversion when the prior is already near-optimal (TextCraft/GPT-5.1), the O(N) test-time compute overhead, and the approximation error from the single-trajectory value regression (Eq. 7 vs. Eq. 5). Open questions include theoretical bounds on how value-function error propagates through SMC resampling, adaptive resampling strategies, and whether AMC distills into a single forward pass.

## Problem

Autoregressive LLM inference is bottlenecked by sequential token-by-token generation, and while speculative decoding mitigates this, state-of-the-art methods like EAGLE-3 still rely on autoregressive drafting that is inherently sequential and caps speedups at ~2–3×. Diffusion models enable parallel generation but typically underperform in quality, and existing diffusion-based drafters are either too large (7B parameters) or too small to achieve meaningful acceptance lengths. The paper asks whether a lightweight block diffusion drafter can be both fast (single forward pass) and accurate (high acceptance rate) when properly conditioned on the target model.

## Input / Output

At inference, the target model performs a standard prefill pass on the input prompt, and hidden states from 5 uniformly sampled layers (between layer 2 and the third-to-last layer) are extracted, concatenated, and projected into a compact context feature. This feature is injected as additional Key-Value entries into every layer of the 5-layer (or 8-layer) block diffusion draft model, which then predicts a block of 16 masked tokens in a single parallel forward pass. The draft block is verified in parallel by the target model, producing a lossless output sequence; the only extra parameterized component is a shared projection W_c ∈ R^{D×5D} (~42 MB for a 35B target).

## Method

DFlash's core mechanism is KV injection: rather than fusing target hidden features with token embeddings at the input (as EAGLE-3 does), the projected target context is stored as persistent KV entries in every draft layer, so conditioning does not dilute with depth and acceptance length scales effectively with draft model depth. The draft model is a small block diffusion transformer (5 layers, shared frozen embedding and LM head with the target) that denoises all masked positions within a block simultaneously, making drafting cost independent of block size. Training uses three key modifications: (1) random anchor sampling to construct masked blocks that match inference-time behavior, (2) a sparse attention mask enabling multiple blocks to be trained jointly in one forward/backward pass via Flex Attention, and (3) an exponentially decaying loss weight w_k = exp(−(k−1)/γ) that emphasizes early token positions where errors invalidate all subsequent tokens. This combination yields a 5-layer drafter generating 16 tokens with lower latency and higher acceptance length than EAGLE-3 generating 8 tokens, achieving up to 6.1× lossless speedup and ~2.5× higher speedup than EAGLE-3.

## Results

On Qwen3-4B with greedy decoding, DFlash (block size 16) achieves an average speedup of 4.91× over autoregressive baseline with an average acceptance length τ of 6.54, compared to 1.81× (τ=3.05) for EAGLE-3 (tree size 16) and 2.08× (τ=3.48) for EAGLE-3 (tree size 60). Under non-greedy sampling (temperature=1), DFlash maintains a 4.24× average speedup (τ=5.69) versus 1.72× for EAGLE-3(16). On the SGLang serving framework with Qwen3-8B, DFlash achieves up to 5.1× throughput speedup at concurrency 1, scaling to 2.9× at concurrency 32, with average acceptance lengths of 8.01 (Math500) and 6.50 (HumanEval).

## Baselines & Comparisons

DFlash is compared exclusively against EAGLE-3, the state-of-the-art autoregressive speculative decoding method, in two configurations: tree size 16 (matching DFlash's block size for fair drafting-budget comparison) and tree size 60 (EAGLE-3's larger tree for maximum acceptance). DFlash wins decisively across all tasks, both model sizes (Qwen3-4B and 8B), and both temperatures. Under greedy decoding on Qwen3-4B, DFlash achieves a 4.91× average speedup versus 1.81× for EAGLE-3(16) and 2.08× for EAGLE-3(60), representing a 2.4× and 2.3× improvement respectively. The acceptance length gap is equally pronounced: DFlash reaches τ=6.54 versus 3.05 (EAGLE-3(16)) and 3.48 (EAGLE-3(60)), more than doubling the effective tokens accepted per verification step. Notably, DFlash with only 16 draft tokens surpasses EAGLE-3 with 60 draft tokens on both speedup and acceptance length, indicating that the parallel diffusion drafting mechanism is fundamentally more efficient than scaling up autoregressive tree size. On the SGLang serving framework (Table 5, LLaMA-3.1-8B), DFlash also outperforms EAGLE-3 at all concurrency levels (1–32), with the gap widening at higher concurrency where EAGLE-3's speedup degrades below 1× while DFlash maintains 1.4–1.8×.

## Relation to Prior Work

DFlash sits at the intersection of speculative decoding (Leviathan et al., 2023; EAGLE-3) and block diffusion language models (Arriola et al., 2025), but departs from both in key ways. Prior diffusion-based speculative decoders (DiffuSpec, SpecDiff-2) relied on massive 7B draft models that were impractical for serving, while PARD used small autoregressive models that lacked capacity. DFlash's core architectural departure is KV injection: rather than fusing target-model hidden features into the draft model's input embeddings (as EAGLE-3 does), it injects them as persistent Key-Value entries at every draft layer, enabling acceptance length to scale with draft depth. The observation that AR LLMs' hidden states implicitly encode multi-token future information (Samragh et al., 2025) provides the theoretical justification for conditioning a lightweight diffusion drafter on these features.

## Why It Matters / Open Questions

DFlash demonstrates that diffusion models need not compete with autoregressive models on end-to-end generation quality; instead, they can serve as fast, specialized drafters within a speculative decoding loop, with the AR target model guaranteeing lossless output. The 6× speedup (vs. ~2–3× for EAGLE-3) is practically significant for serving cost, and the production integration with SGLang and vLLM makes it immediately deployable. Open questions include adaptive block-size scheduling under compute-bound (high-batch) settings, whether the approach extends to non-Transformer target architectures, and how draft-model quality degrades when the target model is updated or fine-tuned post-training. The paper also leaves open whether the KV-injection mechanism generalizes to other conditioning signals beyond hidden-state features.

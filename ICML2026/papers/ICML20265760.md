## Problem

Photoshop is a professional image editing software whose complex multi-level menus, fine-grained operations, and layer-based nondestructive editing pose substantial challenges for automated agents. Existing GUI benchmarks and methods primarily target web interfaces and short-horizon, low-complexity tasks, falling short in modeling the multi-step decision-making and semantic understanding required by professional graphic software. As a result, there is no dedicated benchmark for evaluating GUI agents on realistic, professional image editing workflows in Photoshop.

## Input / Output

For each task, the agent receives a natural language instruction, an initial image, and full desktop screenshots of the Photoshop workspace (including toolbar, layer panel, properties panel, menu bar, mouse position, and cursor shape) as its observation space, which is the union of text and image modalities. The agent must output syntactically correct and executable pyautogui code to interact with Photoshop, producing an edited image along with the full interaction trajectory. The system then evaluates both the final output image against a reference target and the agent's trajectory against a gold trajectory using a six-criteria checklist for non-destructive editing consistency.

## Method

PSBench models each task as a partially observable Markov decision process (POMDP) where the agent generates an executable action based on the current observation, the action is executed in the environment to produce a new state and a new partial observation, and this interaction loop continues until the agent triggers a terminal signal or reaches the maximum step limit. The benchmark comprises 600 human-annotated tasks across three difficulty levels (easy, medium, hard), with tasks drawn from official tutorials and popular real-world workflows, covering core functionalities such as canvas adjustment, layer manipulation, and filter application. For evaluation, PSBench provides more than 300 custom evaluation functions covering layer editing, masking, color adjustment, and filter application, comparing the agent's output against reference target images at pixel-level or semantic-level similarity. Additionally, PSBench introduces the Non-Destructive Editing Consistency (NDEC) metric, a checklist-based evaluation with six criteria to compare the agent trajectory with the gold trajectory, measuring whether the agent adheres to Photoshop's non-destructive editing philosophy.

## Results

On PSBench (600 tasks across Easy/Medium/Hard), the best-performing agentic framework Agent S3 achieves 61.90% overall success rate but only 18.09% on hard tasks. The strongest general-purpose MLLM, GPT-4o, reaches 17.46% SR on non-layer tasks and a mere 3.80% on layer-related tasks. In contrast, NDEC scores (measuring adherence to non-destructive editing workflows) exceed 70% for all MLLMs, peaking at 95.83% on easy tasks, revealing a large gap between planning quality and execution accuracy. In human-in-the-loop experiments, a GPT-4o-based GUI Assistant achieves 100% success on easy tasks (45 s avg), 85% on medium (101 s), and 75% on hard (330 s), outperforming both the autonomous agent and unassisted novices while cutting completion time by over 50% versus internet-assisted users.

## Baselines & Comparisons

PSBench evaluates three categories of systems: general-purpose MLLMs (GPT-4o, GPT-5, Gemini, Claude, Qwen, Doubao), GUI-specialized models (UI-TARS, OpenCUA-7B, GPT-5.4 CUA, Claude-Opus-4.6 CUA), and agentic frameworks (Agent S3, GTA1). Agentic frameworks dominate: Agent S3 leads with 61.90% overall SR and 18.09% on hard tasks, outperforming GTA1 (52.38% / 13.57%) and all single-model approaches. Among GUI-specialized models, Claude-Opus-4.6 in CUA mode achieves the highest overall SR (50.79%) but still trails Agent S3 by ~12 points; UI-TARS and OpenCUA-7B score 36.51% and 42.06% respectively. General-purpose MLLMs perform worst on execution: GPT-4o reaches only 17.46% overall NLR SR, and all MLLMs score 0% on hard NLR tasks. However, on the NDEC metric (process professionalism), MLLMs substantially outperform GUI-specialized models (e.g., GPT-4o: 78.24% vs. UI-TARS: 63.22%), indicating that specialized models sacrifice editing workflow quality for raw execution. In the human-in-the-loop comparison, the GPT-4o GUI Assistant (100%/85%/75% SR on Easy/Medium/Hard) surpasses the autonomous GPT-4o agent (17.5%/11.8%/0%), unassisted novices (85%/45%/0%), and even internet-assisted novices on time efficiency (330 s vs. 720 s on hard tasks).

## Relation to Prior Work

PSBench builds directly on the OSWorld framework (Xie et al., 2024), adopting its POMDP formulation, pyautogui-based action execution, and special terminal actions (WAIT, FAIL, DONE), but departs sharply in domain: where OSWorld and similar benchmarks (WebArena, WebShop, WorkArena) target general-purpose or web software with relatively uniform interaction modes, PSBench targets a single professional design application whose hierarchical menus, layer-based non-destructive editing, and parameter-sensitive tools demand a fundamentally different level of operational precision. The NDEC metric draws on checklist-based evaluation (Ribeiro et al., 2020; Furuhashi et al., 2025) but repurposes it to assess adherence to domain-specific professional workflows rather than generic output quality. The human-in-the-loop experiment extends the evaluation paradigm beyond purely autonomous agent benchmarks by introducing a collaborative mode where the MLLM plans and the human executes.

## Why It Matters / Open Questions

PSBench fills a clear gap: no prior GUI agent benchmark evaluates professional design software, and the finding that even the best agentic framework (Agent S3) achieves only 18.09% on hard tasks quantifies how far current agents are from practical deployment in creative industries. The NDEC-vs-success-rate disconnect—MLLMs score 70–95% on professional workflow adherence yet succeed on only 3–17% of tasks—reframes the bottleneck as execution fidelity rather than semantic understanding, suggesting that improving action grounding (not planning) is the critical next step. The human-in-the-loop result (100% easy / 75% hard with GPT-4o as assistant vs. 17.46% autonomous) points toward a more immediately deployable paradigm. Open questions include whether these findings generalize beyond Photoshop CS6, whether the 600-task scale is sufficient for robust conclusions, and whether the NDEC checklist captures the full breadth of professional editing practice.

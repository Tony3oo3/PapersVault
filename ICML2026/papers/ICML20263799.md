## Problem

Previous completeness results for counterfactual identification (IDC*, CTFID) were restricted to observational and interventional data (Layers 1–2 of Pearl's Causal Hierarchy), since Layer 3 counterfactual data was presumed inaccessible. The recent discovery of counterfactual realizability via counterfactual randomization (ctf-rand) opens access to some Layer 3 distributions, but it remained unknown which additional counterfactual quantities become identifiable, what the fundamental limit of exact identification is, and whether counterfactual data can tighten bounds for non-identifiable quantities.

## Input / Output

The algorithm takes a causal diagram G, an un-nested counterfactual query P(Y*=y), and a set of input distribution specifications A indexed by experimental actions (e.g., ctf-rand(X→C)), which may include L1, L2, or L2.5 data. It returns either a closed-form identification expression in terms of the input distributions, or a FAIL certificate. For non-identifiable queries, the paper additionally provides tight analytic partial identification bounds [l, r] that are provably narrower than prior L2-only bounds when L2.5 data is available.

## Method

The CTFIDU+ algorithm (Alg. 2) is a complete procedure for counterfactual identification from an arbitrary collection of physically realizable input distributions. It operates in stages: removing redundant subscripts, expanding the query to its counterfactual ancestral set, factorizing into ctf-factors by c-component, and then for each input distribution running the novel IDENTIFY+ subroutine (Alg. 1) to identify each target ctf-factor. IDENTIFY+ generalizes the classic IDENTIFY algorithm from L2 c-factors to L3 ctf-factors, using two new data structures—ctf-forests and ctf-hedges—where the ctf-hedge provides a simplified certificate of non-identifiability. The paper further proves a fundamental limit (Thm. 4.1): no quantity in L3 \ L2.5 is identifiable from any L2.5 data, establishing a duality between identifiability and realizability (Cor. 4.2). For non-identifiable quantities like the natural total effect, the paper derives novel analytic bounds (Prop. 5.4) using L2.5 counterfactual data that are provably tighter than prior L2-only bounds, validated by simulations on synthetic SCMs and public datasets.

## Results

The paper's primary results are theoretical: CTFIDU+ is proven complete for counterfactual identification from arbitrary Layer 3 input data (Thm. 3.5), and the theoretical limit of exact non-parametric identification is established at Layer 2.5 (Thm. 4.1), meaning no purely-L3 query is identifiable from L2.5 data. Empirically, in the Traffic Camera simulation (Example 2), the 95% credible interval for NTE (true value 0.395) is significantly tighter using L2.5 counterfactual data than L2 interventional data, while the NDE (true value 0.686) bounds collapse to a single point under L2.5 data, confirming exact identifiability. In the Unit Selection example (Example 3), the counterfactual strategy using L2.5 data strictly dominates the standard L2 interventional approach, assigning treatment only to subpopulations with entirely positive benefit ranges. Results are further validated on the Oregon Health Insurance and Project STAR public datasets, where counterfactual-data bounds are significantly narrower than L2-only bounds.

## Baselines & Comparisons

The paper positions CTFIDU+ as a strict generalization of all prior counterfactual identification algorithms (IDC*, PSIDC, CTFID), which are limited to L1/L2 input data; CTFIDU+ additionally accepts L2.5 counterfactual data and is proven complete for this broader setting (Thm. 3.5). Against the Li & Pearl (2022) unit-selection baseline (strategy 1, using L2 data), the counterfactual strategy (strategy 2, using L2.5 data via ctf-rand) strictly dominates: it correctly assigns treatment only to the subpopulation with natural X=0 whose benefit range is entirely positive, whereas the L2-based approach either treats everyone or forces treatment on units with natural X=1 whose benefit range is entirely negative (Fig. 8). For partial identification bounds, the novel L2.5 bounds (Prop. 5.4) are provably contained within the prior L2 bounds (Lem. 5.3): specifically, the interval [l', r'] ⊆ [l, r], with the tightening coming from replacing the marginal P(y_x) with the conditional P(y_x | x') available from counterfactual randomization. In the Traffic Camera simulation, the 95% credible interval for NTE narrows substantially under L2.5 data, and the NDE interval collapses to the true value 0.686, whereas under L2 data it remains a non-degenerate range.

## Relation to Prior Work

This paper extends the counterfactual identification line (Shpitser & Pearl 2008's IDC*, Correa et al. 2021's CTFID) by allowing input data from Layer 3 (specifically L2.5) rather than restricting to L1/L2, via the new CTFIDU+ and IDENTIFY+ algorithms that generalize the classical IDENTIFY subroutine. It also builds directly on Raghavan & Bareinboim (2025)'s characterization of counterfactual realizability and Yang & Bareinboim (2025)'s Layer 2.5/2.25 taxonomy, unifying these two previously separate threads—identification and realizability—into a single duality theorem. The partial identification bounds extend Tian & Pearl (2000) and Shu et al. (2026) by incorporating counterfactual data, yielding provably tighter analytic bounds for probabilities of causation on the bow graph.

## Why It Matters / Open Questions

Theorem 4.1 establishes that L2.5 is the absolute ceiling for exact non-parametric causal identification, meaning quantities like the natural total effect (NTE) used in explainable AI are fundamentally non-identifiable regardless of experimental sophistication—a result with direct implications for the XAI and fairness communities. The identifiability-realizability duality (Cor. 4.2) provides a clean conceptual boundary: if a quantity cannot be physically sampled, no amount of causal reasoning can recover it from available data. Key open questions include extending results to continuous variables, handling graph uncertainty, and developing general-purpose bound-tightening frameworks beyond the bow-graph case studied here.

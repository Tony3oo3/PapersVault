## Problem

Federated Multi-Objective Learning (FMOL) suffers from a compounded dual-bias problem: intra-task client drift (from data heterogeneity) systematically shifts local updates away from true gradient directions, and the subsequent non-linear multi-objective aggregation (e.g., MGDA) applied to these drifted inputs introduces a second layer of bias that can even turn a descent direction into ascent for some tasks. Prior FMOL frameworks either ignore this recursive coupling or rely on restrictive bounded-heterogeneity assumptions to simplify analysis, and no existing work simultaneously provides linear-speedup convergence, conflict-avoidant direction distance, and weighted sub-optimality guarantees under a unified Lyapunov framework.

## Input / Output

The method consumes heterogeneous local data from N clients, where each client i participates in a personalized subset of S tasks and performs K local stochastic gradient steps per communication round. The server aggregates per-task updates into a matrix Δ̄ ∈ ℝ^{p×S}, solves a regularized QP to obtain simplex weights λ_ρ, and produces a single global model parameter vector x that is Pareto-stationary (or Pareto-optimal under strong convexity). The task correction matrix A ∈ ℝ^{S×S} (entry-wise nonnegative) flexibly reconfigures the output geometry, enabling linear scalarization (A = J), weighted prioritization (A diagonal), or task-interaction modeling (A with off-diagonal entries) without changing the core algorithm.

## Method

DREAM corrects the dual-bias through a two-stage client-side mechanism: (1) a SCAFFOLD-inspired control variate h_{s,i} that explicitly subtracts the systematic drift from local updates, and (2) a momentum parameter γ ∈ (0,1] that blends the current stochastic gradient with the previous round's aggregated update to smooth stochastic fluctuations before server-side aggregation. On the server, DREAM formulates multi-objective weight computation as a ρ-regularized QP min_{λ∈ω} ½‖Δ̄Aᵀλ‖² + (ρ/2)‖λ‖², whose strong convexity ensures Lipschitz continuity of the weight mapping; this supports both an Exact-Update (solve QP via Frank-Wolfe) and a computationally cheaper Step-Update (single projected gradient step). The regularization ρ acts as a controlled ascent tolerance that vanishes as ρ→0, while the task correction matrix A generalizes MGDA (A=I), scalarization (A=J), and prioritization (A diagonal) within one formulation. Theoretically, DREAM achieves O(1/√(NT)) linear speedup to Pareto stationarity for non-convex objectives without bounded-heterogeneity assumptions, O(T^{-2/5}) CA-direction distance for Step-Update, and Ō(1/√T) weighted sub-optimality for strongly convex objectives via a Lyapunov function coupling distance-to-optimality, gradient estimation error, client drift, and weight tracking error.

## Results

On CIFAR-100 (fine-grained + coarse-grained classification), DREAM Step-Update achieves 40.2% fine-grained accuracy and 55.3% coarse-grained accuracy, surpassing FSMGDA by +2.4% and +3.5% respectively, and FedAvg (0.5/0.5 scalarization) by +2.6% and +4.3%. On Multi-MNIST with K=40 local steps, DREAM attains a more balanced Pareto trade-off than both FSMGDA (biased toward Task 1) and FedCMOO (biased toward Task 2), and removing the drift-correction mechanism causes an approximately 6% drop in average accuracy. DREAM also maintains a small inter-task accuracy gap across increasing local steps K, whereas FSMGDA's average accuracy degrades and FedCMOO's task gap persists.

## Baselines & Comparisons

DREAM outperforms all three baselines on the reported metrics. On CIFAR-100, DREAM Step-Update beats FSMGDA (Yang et al., 2023) by +2.4% on fine-grained and +3.5% on coarse-grained accuracy, and beats FedAvg (McMahan et al., 2017) with fixed 0.5/0.5 scalarization by +2.6% and +4.3% respectively. On Multi-MNIST (heterogeneous, K=40), DREAM achieves a more balanced Pareto trade-off than both FSMGDA (which skews toward Task 1) and FedCMOO (Askin et al., 2025, which skews toward Task 2); ablation shows that removing DREAM's control-variate drift correction degrades it to FSMGDA-like behavior with a ~6% average accuracy loss. As local steps K increase, FSMGDA's average accuracy drops noticeably while FedCMOO maintains stable average accuracy but a large persistent inter-task gap; DREAM sustains both high average accuracy and a small task gap across all K values tested.

## Relation to Prior Work

DREAM sits at the intersection of two well-developed lines: stochastic multi-objective optimization (MGDA, MoCo, CR-MOGM) and federated drift correction (SCAFFOLD, FedPD). The key conceptual departure is identifying the recursive coupling between intra-task client drift and inter-task aggregation bias as a single feedback loop, rather than treating them as independent error sources. Prior FMOL methods (FSMGDA, FedCMOO) sever this loop via bounded-heterogeneity assumptions, while prior MOO methods (MoCo, PSMGD) address aggregation bias without federated drift. DREAM unifies both corrections—SCAFFOLD-style control variates plus momentum smoothing—into a single input pipeline feeding a regularized QP with a task correction matrix that subsumes MGDA, scalarization, and prioritization as special cases.

## Why It Matters / Open Questions

The first linear-speedup convergence guarantee for FMOL without bounded heterogeneity (Exact-Update) and the first CA-direction-distance bounds in the federated setting fill notable gaps in the theoretical landscape. The coupled-error Lyapunov analysis provides a more principled foundation than the bounded-heterogeneity shortcuts used by prior FMOL work, potentially enabling tighter analyses for future methods. However, empirical validation is limited to small-scale benchmarks (Multi-MNIST, CIFAR-100, CelebA) with full client participation, leaving open whether the framework's advantages persist under partial participation, asynchrony, or at the scale of modern LLM multi-objective training. The Step-Update error floor of O(ρ² + ρ⁻⁶) also raises practical questions about the regularization sweet spot in large-scale deployments.

## Problem

Existing jailbreak methods for text-to-image systems treat the attack as a prompt-level textual evasion problem against a single generation model. Tool-calling T2I agents, which decompose queries into multi-step tool chains, introduce a previously unexplored orchestration-level attack surface where individually benign tool calls compose into policy-violating outputs, and no prior work has systematically studied or exploited this vulnerability.
![Teaser figure](../imgs/ICML20260611/cropped_page1_idx0.webp)

## Input / Output

The adversary provides a target harmful prompt (from VBCDE-100, spanning categories like violence, bloody, and discrimination) and operates in a black-box setting, observing only the agent's refusal signal, final image, and the executed tool-calling trace (sequence of tool names with their textual input arguments). The agent's tool configuration (names and functionalities) is used to condition seed generation. Success requires both a non-refusal response and CLIP ViT-B/32 cosine similarity ≥ 0.26 between the generated image and the target prompt, ensuring the output remains semantically faithful to the harmful intent rather than drifting.

## Method

OrchJail is an orchestration-guided fuzzing framework whose core insight is that jailbreak success in tool-calling T2I agents depends on specific tool-orchestration patterns rather than surface-level prompt wording. It first performs tool-aware seed generation, using an LLM conditioned on the agent's tool configuration to restructure target prompts with phrasing cues (e.g., clause separators) that trigger multi-tool decomposition. Upon observing successful jailbreaks, a rule-based extractor abstracts each tool-calling trace into three orchestration dimensions (macro-planning, micro-scheduling, tool selection), and an LLM-based causal reasoning module then attributes specific prompt spans to those patterns, producing interpretable causal triples. These causal knowledge entries are stored in a repository and retrieved via embedding similarity to guide a two-branch LLM mutator (bypass-oriented when the prompt is refused, semantics-oriented when the image lacks fidelity) and a multi-objective LLM-as-judge scorer that ranks candidates on bypass probability, prompt drift, and orchestration-pattern match, steering the search toward prompts that systematically exploit orchestration-level vulnerabilities.

## Results

OrchJail achieves the highest one-time success rate (O-SR) across all three target agents: 72.63% on GenArtist, 66.27% on CREA, and 91.68% on LayerCraft, outperforming the strongest baseline JailFuzzer by 9.15, 10.17, and 9.50 percentage points respectively. It also attains the lowest FID (156.26, 160.73, 241.31) and fewest queries (12.15, 13.73, 7.23) on each agent, indicating both better image fidelity and greater query efficiency. Under re-use, OrchJail maintains the highest R-SR (96.26%, 79.11%, 100.00%) and lowest re-use FID, confirming that discovered jailbreak prompts generalize across repeated executions.

## Baselines & Comparisons

OrchJail consistently outperforms all four baselines on every metric across all three agents. Against JailFuzzer (the strongest baseline, a fuzzing-based method), OrchJail gains 9–10 pp in O-SR, reduces FID by 2–16 points, and requires 1–2 fewer queries per agent. Against SneakyPrompt (iterative refinement), the O-SR gap is larger (9–13 pp) and FID improvements are more pronounced (7–22 points), reflecting SneakyPrompt's reliance on surface-level token perturbations that degrade image fidelity. RING and DACA, which use single-shot prompt transformations without iterative search, trail OrchJail by 20–26 pp in O-SR and by 60–130 FID points; they also cannot be compared on query efficiency since they do not perform iterative refinement. Notably, even under SmoothLLM defenses, OrchJail's worst-case O-SR (69.03%) still exceeds JailFuzzer's undefended O-SR (63.48%), underscoring the robustness advantage of orchestration-guided search over prompt-level evasion.

## Relation to Prior Work

This paper departs from the established line of T2I jailbreak research (DACA, RING, SneakyPrompt, JailFuzzer), which treats the problem as a single prompt-to-single-generation mapping and focuses on surface-level textual perturbations. It repurposes the fuzzing paradigm from software testing and augments it with an orchestration-abstraction and causal-reasoning module that is absent from prior T2I jailbreak work. The conceptual lineage draws on in-context learning for mutation guidance and LLM-as-judge for scoring, but the key departure is targeting the multi-step tool-orchestration layer of agentic T2I systems rather than a monolithic diffusion model.

## Why It Matters / Open Questions

By identifying tool orchestration as a distinct attack surface where individually benign steps compose into policy-violating outputs, this work highlights a safety gap in agentic T2I systems that prompt-level defenses cannot address. The practical black-box evaluation framework (with transferability across agents) gives developers and auditors a concrete tool for stress-testing agent pipelines. Open questions include how to design holistic orchestration-level safeguards, whether the findings generalize beyond the three tested agents, and whether the attribution-style 'causal' reasoning (explicitly not interventional) is sufficient for robust guidance at scale.

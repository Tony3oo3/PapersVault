## Problem

Cross-layer reuse of early attention projections improves data efficiency but creates a structural conflict: the first layer must simultaneously act as a stable, reusable anchor for all deeper layers and as an effective computational block for progressive feature transformation. Existing solutions like ResFormer address only value residuals, leaving queries, keys, and gate logits unexplored, and preliminary attempts to residualize Q/K without normalization proved unstable. This paper identifies the first-layer tension as the root constraint and asks whether decoupling the anchor from the sequential stack can resolve it.

## Input / Output

The model consumes standard text token sequences (sequence length 2048, vocabulary 57,601) and produces next-token predictions via a pre-normalized Transformer with SwiGLU FFN. Unusually, the exogenous anchor projections are computed once from the input embeddings (or optionally from layer-1/layer-2 hidden states) and then injected into every layer's Q, K, V, and G pathways via learned mixing coefficients, so the same four d×d projection matrices are reused across all L layers. The dynamic variant additionally produces per-layer, per-component scaling factors from a small MLP conditioned on the current layer's pre-normalized input.

## Method

ExoFormer learns four dedicated exogenous projection matrices (W_anc^Q, W_anc^K, W_anc^V, W_anc^G) outside the sequential layer stack, producing anchor projections from the input embeddings that are mixed with each layer's own projections via the unified formula: Ŝ_n = λ_{n,1}^S ⊙ RMSNorm(S_anc) + λ_{n,2}^S ⊙ S_n for S ∈ {Q,K,V,G}. The key stabilization insight is applying RMSNorm to the anchor source before mixing, which resolves the distributional mismatch that causes unnormalized Q/K residuals to diverge. Coefficient granularities (elementwise, headwise, scalar) are explored, with elementwise mixing yielding the best results for ExoFormer. A Dynamic Mixing module adds a two-layer MLP (d→16→8) per layer that generates context-dependent sigmoid scaling factors γ, modulating the base λ coefficients in real time. The Offloading Hypothesis explains the gains: the external anchor preserves token identity, freeing sequential layers to specialize exclusively in feature refinement, which is validated by anchor-removal and inverse ablations showing ExoFormer's anchor retains 822 PCA dimensions versus NuResFormer's 611.

## Results

Dynamic E-ExoFormer achieves the best average downstream accuracy (50.27%) and lowest validation perplexity (14.09) among all ~450M models, outperforming Gated Attention by ~1.5 accuracy points while matching its validation loss using ~1.5× fewer training tokens. Static E-ExoFormer attains 49.85% average accuracy and 14.13 PPL, the best among non-dynamic variants. All ExoFormer variants (external anchor) consistently outperform their NuResFormer (internal anchor) counterparts in perplexity, with the gap ranging from 0.02 to 0.06 PPL points.

## Baselines & Comparisons

Against the Base Transformer (48.14% avg. ACC, 14.79 PPL), Dynamic E-ExoFormer improves accuracy by 2.13 points and reduces perplexity by 0.70. Compared to Gated Attention (48.80% ACC, 14.64 PPL), Dynamic E-ExoFormer gains 1.47 accuracy points and 0.55 PPL points, while the paper reports it matches Gated Attention's validation loss using ~1.5× fewer tokens. Against ResFormer (49.65% ACC, 14.32 PPL), Dynamic E-ExoFormer leads by 0.62 accuracy points and 0.23 PPL points, and notably the Naive Combination of Gated Attention + ResFormer (49.09% ACC) underperforms both components individually, confirming that unnormalized mixing introduces distributional mismatch. Every ExoFormer variant outperforms its NuResFormer counterpart in perplexity (e.g., E-ExoFormer 14.13 vs. E-NuResFormer 14.15), validating that decoupling the anchor from the first layer resolves the structural tension. The dynamic variant's advantage over static E-ExoFormer is concentrated in downstream accuracy (+0.42 points) rather than perplexity (−0.04), suggesting context-aware mixing primarily improves generalization.

## Relation to Prior Work

This paper generalizes ResFormer's value-only residual learning (Zhou et al., 2025) to all four attention pathways (Q, K, V, G) and stabilizes the mixing via RMSNorm on anchor sources, while incorporating the gated attention mechanism of Qiu et al. (2025). Its key architectural departure is ExoFormer, which decouples the reusable anchor from the first sequential layer by learning dedicated exogenous projections on the input embeddings, thereby resolving what the authors term the 'First Layer Tension'—the conflict between serving as a stable universal anchor and as an effective computational block. The unified mixing framework is positioned as orthogonal to MUDDFormer's input-side dynamic aggregation and to KV-cache-reduction approaches like SkipV1Former and YOCO, operating instead in the full-rank projection space after the linear maps.

## Why It Matters / Open Questions

The Offloading Hypothesis provides a mechanistic explanation for why external anchors help: they let sequential layers specialize in feature transformation while a dedicated module preserves token identity, supported by controlled ablations (anchor removal and inverse ablation) showing asymmetric brittleness between internal and external anchors. The counterintuitive finding that anchoring on H₁ outperforms H₀ (contrasting with ResFormer's preference for the earliest representation) suggests the decoupled anchor can exploit slightly processed features without suffering first-layer tension. However, all experiments are limited to 450M–1B parameters trained on 10–20B tokens, the practical latency overhead (8–15%) substantially exceeds the theoretical FLOPs increase (~1.3%), and it remains open whether the offloading mechanism and the H₁ anchor depth advantage persist at 100B+ scale.

## Problem

MemAgent's recurrent memory paradigm for long-context reasoning suffers from two critical flaws: indiscriminate memory updates on evidence-free chunks cause memory explosion that degrades both accuracy and inference cost, and the absence of an early-exit mechanism forces the model to process all remaining chunks even after sufficient evidence has been collected. These issues undermine long-horizon stability and waste computation, especially when evidence is unevenly distributed across the context.

## Input / Output

The method consumes a question and a long context (up to 896K tokens) that is pre-split into fixed 5,000-token chunks. At each recurrent step, the memory agent receives the question, the current chunk, and the previous textual memory (capped at 1,024 tokens), and emits a structured response containing a binary update decision, a candidate memory string, and a binary exit decision. The final output is the answer to the question, produced by a separate answer agent conditioned on the terminal memory and the question.

## Method

GRU-Mem augments MemAgent's RNN-like loop with two text-controlled gates inspired by GRU gating: an update gate that selectively accepts or discards the candidate memory at each step, and an exit gate that terminates the loop once the last required evidence has been encountered. Both gates are learned end-to-end via Multi-Conv DAPO reinforcement learning with four reward signals—outcome (answer correctness), update (per-chunk gate correctness), exit (termination at the last-evidence turn, with asymmetric penalties for early vs. late exit), and format (strict structural compliance). The advantage is computed as a weighted combination of trajectory-level and turn-level terms controlled by a hyperparameter α (default 0.9), allowing the model to balance global task success against per-step gate accuracy. The memory and answer agents share a single policy model (Qwen2.5-3B/7B-Instruct), differentiated only by prompt, and inference can optionally disable the exit gate for tasks requiring full-context reading.

## Results

On the 7B model, GRU-Mem (w/o EG) outperforms MemAgent on 7 out of 10 tasks, with notable gains on out-of-distribution NIAH tasks (e.g., MQ: 88.37% → 96.43%, MV: 81.70% → 95.23%) while achieving ~200% inference speedup (e.g., SQuAD: 162.34s → 85.03s). With the exit gate enabled (w EG), GRU-Mem further accelerates inference by up to 400% (e.g., MK-1: 412.93s → 102.46s) while maintaining or improving accuracy. On the 3B model, gains are even more pronounced: GRU-Mem (w/o EG) improves MK-2 from 35.05% to 67.08%, MK-3 from 44.42% to 91.41%, and MV from 36.27% to 59.46% over MemAgent.

## Baselines & Comparisons

The sole baseline is MemAgent (Yu et al., 2025a), the vanilla recurrent-memory agent that updates memory indiscriminately on every chunk and always processes all chunks before answering. GRU-Mem wins on most tasks, with the largest margins on out-of-distribution NIAH tasks: on the 3B model, MK-2 improves from 35.05% to 67.08% (+32.03 pp), MK-3 from 44.42% to 91.41% (+46.99 pp), and MV from 36.27% to 59.46% (+23.19 pp). On the 7B model, MQ improves from 88.37% to 96.43% (+8.06 pp) and MV from 81.70% to 95.23% (+13.53 pp) under w/o EG. GRU-Mem slightly trails MemAgent on MK-2 (7B, w/o EG: 67.52% vs. 75.78%) and on MQ (7B, w EG: 84.12% vs. 88.37%), suggesting the exit gate can be suboptimal for multi-value tasks requiring full-context scanning. In terms of efficiency, GRU-Mem reduces inference time by roughly 2× (w/o EG) to 4× (w EG) across all tasks, e.g., SQuAD drops from 162.34s to 64.32s and MK-1 from 412.93s to 102.46s.

## Relation to Prior Work

This paper directly extends MemAgent (Yu et al., 2025a), which introduced a recurrent, chunk-by-chunk textual memory paradigm for long-context QA trained with Multi-Conv DAPO (an RL algorithm extending GRPO to multi-turn settings). The key departure is borrowing the gating concept from classical GRUs (Cho et al., 2014) and instantiating it as two text-controlled binary decisions (update gate and exit gate) within the memory agent's structured output, rather than as learned scalar parameters. The training framework adds two auxiliary reward signals (r^update, r^exit) on top of the outcome reward, with a disentangled advantage calculation that separately normalizes trajectory-level and turn-level rewards.

## Why It Matters / Open Questions

The practical efficiency gain is the main contribution: up to 400% inference speedup via early exit, and reduced memory explosion via selective updates, making long-context reasoning more deployable in agentic and production settings. However, the paper is limited to the QA domain, the extra reward signals reduce training stability (requiring smaller off-policy degrees and longer convergence), and the approach has not been validated on tasks like summarization or multi-document reasoning. An open question is whether the gating mechanism generalizes beyond sparse-evidence QA to denser information-integration tasks where most chunks are relevant.

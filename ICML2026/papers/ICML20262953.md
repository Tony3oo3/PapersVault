## Problem

Existing evaluations of agentic LLMs conflate executional intelligence (completing a given task) with investigatory intelligence (autonomously deciding what is worth exploring). Data science benchmarks typically assume a user-posed question as the objective, while deep research benchmarks operate on unstructured web content with limited tool use. No prior benchmark isolates the ability of an LLM to conduct open-ended, long-horizon exploration over structured databases without predefined questions, objectives, or interaction limits, while still enabling objective, verifiable evaluation of the insights produced.

## Input / Output

The agent receives only a structured database (MIMIC-IV EHR tables, GLOBEM wearable/survey data, or 10-K XBRL financial statements) and a minimal start prompt identifying a single task entity (e.g., 'Start analysing the user with userid=2048'), with no predefined questions or step limits. It interacts via SQL and Python tools exposed through the Model Context Protocol, autonomously deciding when to terminate. Outputs are two types of insights: message-wise insights (one paragraph per ReAct round, generated by a separate prompt call) and a trajectory-wise report (a single synthesized document produced at self-termination). Evaluation scores are checklist accuracy (proportion of 2,058 verified fact items supported by the insights) plus a novelty ranking derived from Bradley-Terry pairwise comparisons of insights not covered by the checklist.

## Method

DDR-Bench formalises Deep Data Research as I = DDR(LLM, D, T), where an LLM iteratively queries a database D using tools T with no round limit, terminating only when it judges sufficient information has been gathered. The agent scaffold is deliberately minimal—a lightweight ReAct loop with only SQL and Python tools and no planning, memory, or multi-agent modules—to isolate intrinsic model capability from external scaffolding. Evaluation uses a checklist of verifiable factual statements extracted from the unstructured text components of each database (clinical narratives, survey responses, financial prose) via GPT-5 mini, with surjectivity confirmed by 50+ domain experts; an LLM-as-a-Checker then assesses whether each insight provides sufficient evidence to support each checklist fact, yielding objective per-sample accuracy. Beyond final scores, the paper analyses investigatory dynamics across three scaling dimensions (interaction rounds, token consumption, monetary cost), visualises exploration patterns via database coverage and normalised exploration entropy, and measures self-termination confidence through log-probability of finish tokens across trajectory prefixes. Module ablations (reasoning budget, memory, reactive vs. proactive mode) and agent framework ablations (Plan-and-Execute, CoALA, AutoGen) further dissect which components genuinely improve investigatory performance.

## Results

On DDR-Bench, Claude 4.5 Sonnet achieves the highest overall average checklist accuracy of 47.73%, the only model to exceed 40%. GPT-5.2 follows at 37.09%, while top open-source models DeepSeek-V3.2 (38.80%) and GLM-4.6 (37.52%) approach proprietary performance. The weakest model, Llama3.3-70B, scores only 12.30%, indicating the task remains far from saturated. Performance varies substantially across scenarios: 10-K is the easiest (Claude: 77.61% sample-averaged message-wise) while MIMIC is the hardest (Claude: 36.07%).

## Baselines & Comparisons

Claude 4.5 Sonnet leads all models by a wide margin, achieving 47.73% overall average accuracy versus GPT-5.2's 37.09% (+10.6 pts) and Gemini 3 Flash's 30.65% (+17.1 pts), with the gap most pronounced on the 10-K scenario (77.61% vs. 44.89% for GPT-5.2). Among open-source models, DeepSeek-V3.2 (38.80%) and GLM-4.6 (37.52%) narrowly match or exceed GPT-5.2 (37.09%), indicating that top open-weight models have closed the gap with proprietary systems on this task. Kimi K2 (36.42%) and MiniMax-M2 (32.25%) trail by 1–5 points. Notably, Claude's advantage is specific to DDR-Bench's open-ended, query-free setting; the paper observes that leading proprietary models show broadly similar performance on other benchmarks, suggesting Claude's agentic capabilities are particularly well-suited to autonomous data exploration. The overall ceiling of ~48% (even for the best model) confirms that deep data research remains far from saturated, with 58% of annotated errors stemming from insufficient exploration breadth or depth rather than reasoning failures.

## Relation to Prior Work

This paper builds on the ReAct interaction paradigm (Yao et al., 2023) and the open-ended evaluation philosophy of deep research benchmarks (Wong et al., 2025; Wan et al., 2025), but departs sharply from both the LLM4DS literature—which treats data analysis as answering user-posed queries—and web-based deep research benchmarks that operate on unstructured content. The key conceptual contribution is formalising 'investigatory intelligence' as distinct from 'executional intelligence,' positioning DDR as a setting where no question, objective, or interaction limit is provided, and the agent must autonomously decide what to explore and when to stop. The checklist-based evaluation, derived from unstructured text components of hybrid structured databases, is a novel evaluation mechanism that avoids both subjective rubrics and the implicit goal-embedding common in prior data-science agent benchmarks.

## Why It Matters / Open Questions

DDR-Bench provides the first large-scale, verifiable benchmark for autonomous data exploration, and its results reveal that even the strongest frontier model (Claude 4.5 Sonnet) achieves only ~48% checklist accuracy, indicating that investigatory intelligence remains far from solved. The finding that complex agent scaffolding (planning, memory, multi-agent) frequently degrades performance relative to a minimal ReAct baseline challenges the prevailing engineering practice of adding more modules, while the near-zero benefit of 10× parameter scaling for agentic behaviour suggests that training-time emphasis on reasoning and agency matters more than raw scale. Open questions include how to cultivate investigatory strategies through training (rather than scaffolding), how to improve self-termination reliability, and whether the breadth-to-depth exploration transition can be explicitly learned.

## Problem

While representational similarity across machine learning models is well-documented, its root causes remain largely unexplored. Two competing hypotheses—task overlap (Huh et al., 2024) and dataset overlap—have never been empirically tested in a controlled setting, and no prior work quantifies their relative contributions or examines downstream security consequences such as adversarial transferability.
![Teaser figure](../imgs/ICML20262580/cropped_page2_idx0.webp)

## Input / Output

The method takes pairs of models (ResNet/ViT classifiers, nanoGPT, Llama-3.2, diffusion UNet, XLM-RoBERTa) trained on datasets with a controlled overlap parameter α ∈ [0,1], and evaluates their backbone latent representations on held-out validation sets. The key output is a CKA similarity score per model pair at each overlap level, supplemented by transfer adversarial attack success rates (via MI-FGSM for vision, random-search jailbreaks for LLMs) and mutual information values that quantify which overlap type best predicts similarity per model family. The ColorShapeDigit800K dataset is specifically constructed so that dataset and task overlap can be varied independently, with images upsampled to 224×224 for vision experiments.

## Method

The paper introduces two controlled experimental protocols—dataset splitting and task splitting—that systematically vary the fraction of shared training content between model pairs. Dataset splitting fixes a per-class overlap fraction α so that α of data points in each partition are identical across D₁ and D₂. Task splitting comes in two variants: (1) varying the number of shared class/corpus partitions (which conflates task and dataset overlap), and (2) using multi-label datasets (ColorShapeDigit800K for vision, Multilingual Amazon Reviews for text) where the same underlying data points are relabeled to define different supervised tasks, decoupling task overlap from dataset overlap entirely. Models are trained from scratch or finetuned across four modalities, and representational similarity is measured via CKA, SVCCA, KNN, and mutual KNN. The authors then use mutual information to determine which overlap type is most informative per architecture, and probe downstream consequences by measuring transferable adversarial and jailbreak attack success rates as a function of overlap.

## Results

The paper finds that both dataset and task overlap are positively associated with higher representational similarity (CKA) across vision models, with strong positive linear trends and high R² values in ResNet and ViT finetuning experiments. Mutual information analysis (Table 3) reveals that no single overlap type dominates universally: dataset overlap is most informative for ResNet (MI = 1.303), task+dataset overlap for nanoGPT (MI = 1.052), Llama (MI = 0.301), and UNet (MI = 0.835), while task overlap alone is highly informative in the controlled ColorShapeDigit800K and language-classification settings (MI = 1.002 for XLM-RoBERTa). In downstream security experiments, higher dataset/task overlap in vision models correlates with higher transfer adversarial attack success rate (ASR) under MI-FGSM, while transferable jailbreak ASR for LLMs remains high across all overlap levels due to shared pretraining initialization.

## Baselines & Comparisons

This is an empirical study rather than a method-vs-baseline comparison, so the key 'comparisons' are across overlap types and model families. Dataset overlap is the strongest predictor of representational similarity for ResNet (MI = 1.303 vs. 0.845 for task overlap), while task+dataset overlap dominates for generative models (nanoGPT MI = 1.052 vs. 0.198 for dataset overlap alone; UNet MI = 0.835 vs. 0.217). For ViT, task overlap (0.936) and task+dataset overlap (0.932) are nearly equivalent and both slightly exceed dataset overlap (1.120). The Llama results show the weakest overall effect (max MI = 0.301), which the authors attribute to the small divergence between continued-pretraining/instruction-finetuning objectives and the original next-token-prediction pretraining objective. In the controlled ColorShapeDigit800K setting where dataset overlap is held at 100%, task overlap alone still produces a strong positive CKA trend, confirming that shared task structure independently drives alignment. For adversarial transferability, the paper shows a clear positive correlation between overlap and transfer ASR in vision models, a finding not previously explored in the literature.

## Relation to Prior Work

This paper extends the well-established line of work on measuring representational similarity (CKA, SVCCA, etc.) by shifting focus from *quantifying* similarity to *causally attributing* it to specific training factors. While Huh et al. (2024) postulated that task alignment drives model convergence, the authors note this remains purely theoretical with no empirical tests, and the dataset-overlap hypothesis has not been explored at all. The paper introduces controlled experimental methods (dataset splitting and task splitting) and a new synthetic dataset (ColorShapeDigit800K) to independently manipulate these two factors, carving out a causal-attribution sub-problem that prior representation-analysis work has not addressed. It also connects to the adversarial-robustness literature by empirically linking representational similarity to transfer attack success rates, a connection previously only hypothesized.

## Why It Matters / Open Questions

The finding that dataset and task overlap drive representational similarity in vision models but have weaker effects in text generation provides practitioners with concrete levers for controlling model homogeneity, which has direct security implications (transferable adversarial attacks, jailbreak transfer). The new ColorShapeDigit800K dataset and the independent-control methodology are reusable tools for future causal studies of representation alignment. Key limitations include reliance on small models (up to ~300M parameters), CKA as the primary metric, and weak/inconclusive LLM results due to shared pretraining initialization, leaving open whether these effects persist at production scale or under other post-training paradigms like RLHF.

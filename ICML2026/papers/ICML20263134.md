## Problem

Existing federated VLM methods rely on fully local optimization with simple parameter averaging, which amplifies inter-client optimization inconsistency under heterogeneous data and intra-client over-specialization under long local training trajectories. These issues are compounded in full-data FL regimes—where clients train on all available local samples—yet prior work has evaluated almost exclusively in few-shot settings, leaving the balance between global task adaptation and generalization unresolved in realistic full-data scenarios.

## Input / Output

Each client processes private RGB images through a frozen ViT-B/16 backbone with LoRA-adapted layers, producing a single normalized class token embedding (not full patch embeddings) that is uploaded to the server for privacy preservation. The server-side text encoder consumes category-level text prompts (e.g., 'a photo of a [classname]') to generate global text embeddings in the same latent space. The final output is a class label obtained by softmax over cosine similarities between the local image embedding and all global text embeddings, scaled by a learnable temperature.

## Method

FedDTL decouples the image and text encoders across the server-client boundary: the image encoder is trained locally with LoRA to preserve data privacy, while the text encoder is trained globally on the server using uploaded class token embeddings, providing a unified semantic anchor that reduces inter-client representation drift. For local fine-tuning, a two-stage schedule is employed: an initial SFT stage (2 epochs) provides a fast warm-start, followed by a GRPO-inspired RL stage (3 epochs) that injects small Gaussian noise into the latent embedding space to create stochastic actions, computes group-relative advantages from binary accuracy rewards, and updates the policy via clipped policy gradient with KL regularization against a hybrid reference model (50/50 mix of final SFT and latest global policy). The server aggregates visual LoRA parameters via weighted averaging and broadcasts updated global text embeddings and LoRA weights each round, restricting parameter sharing to the visual branch while the text branch learns globally.

## Results

On the base-to-novel class generalization task (Table 1), FedDTL achieves the best Base accuracy across all data distributions in both few-shot and full-data regimes, reaching 89.58% (few-shot Non-IID) and 91.64% (full-data Non-IID), compared to the strongest baseline FedMaPLe at 83.63% and 80.56% respectively. On Novel classes, FedDTL attains 83.01% (few-shot Non-IID) and 77.72% (full-data Non-IID), remaining competitive with zero-shot CLIP (81.99%) while substantially outperforming all fine-tuned baselines. In the feature shift setting (Table 2), FedDTL achieves the highest average domain accuracy in nearly all configurations, e.g., 98.65% on Office-Caltech10 (full-data, Dir(0.1)) and 93.47% on DomainNet (full-data, Dir(0.1)).

## Baselines & Comparisons

FedDTL decisively outperforms all six baselines on Base accuracy in every data distribution and regime. The gap is most dramatic under Non-IID: in full-data Non-IID, FedDTL reaches 91.64% Base while pFedDC collapses to 28.75%, pFedMMA to 31.54%, and FedPGP to 48.26%, revealing that fully local training with parameter averaging cannot resolve inter-client optimization inconsistency. The strongest baseline, FedMaPLe, still trails FedDTL by 6.1–11.1 points on Base in Non-IID settings. On Novel (generalization) classes, FedDTL is competitive but does not always beat zero-shot CLIP in full-data regimes (e.g., 77.72% vs. 81.99% in full-data Non-IID), though it substantially surpasses all fine-tuned baselines (e.g., 77.72% vs. FedMaPLe's 69.41%). In the feature shift setting (Table 2), FedDTL achieves the highest average domain accuracy in 7 of 8 configurations, with the largest margins over pFedDC and pFedMMA under label skew (e.g., 93.47% vs. 59.87% on DomainNet full-data Dir(0.1)).

## Relation to Prior Work

FedDTL builds on the CLIP pre-trained VLM backbone and adapts GRPO (Shao et al., 2024) for local policy optimization, but its core departure from prior federated VLM work (pFedDC, FedPGP, pFedMMA, PromptFL, FedMaPLe) is architectural: rather than performing fully local training followed by server-side parameter averaging, it decouples the image encoder (trained locally for privacy) from the text encoder (trained centrally on the server), drawing a direct analogy to CLIP's own modality decoupling and alignment paradigm. This reframes cross-client knowledge transfer from parameter averaging to server-client modality alignment, which the authors argue is more robust to inter-client optimization inconsistency under heterogeneous data. The two-stage SFT-then-RL local fine-tuning further distinguishes the method from prior approaches that rely on auxiliary regularization or shared projection layers to combat over-specialization.

## Why It Matters / Open Questions

The paper addresses a realistic but underexplored regime—full-data federated learning with VLMs—where prior few-shot-focused methods (pFedDC, pFedMMA) degrade severely, and demonstrates that the decoupled encoder design plus RL-based local refinement can maintain strong generalization while improving global task adaptation. Limitations include evaluation only on ViT-B/16 with 5 clients and relatively small-scale datasets, and the RL stage adds non-trivial computational overhead (G samplings per image, additional local epochs). Open questions include whether the decoupled encoder strategy scales to larger VLMs (e.g., ViT-L/14 or LLaVA-style models), how it interacts with more aggressive privacy mechanisms (differential privacy on embeddings), and whether the GRPO-inspired RL stage generalizes beyond classification to other downstream VLM tasks.

## Problem

Existing learnware specification methods based on Reduced Kernel Mean Embedding (RKME) capture only input distributions, causing models with similar inputs but different functionalities to receive indistinguishable specifications. Recent labeled-RKME improvements incorporate output information but are restricted to classification tasks and lack clear theoretical justification. This paper addresses both gaps by proposing a specification that directly models input-output conditional distributions with a principled theoretical framework applicable to both regression and classification.

## Input / Output

Developers provide a labeled dataset (X, Y) from which a neural feature map φ_θ: X → R^d is trained and a reduced set V ⊆ Y with a weight matrix R ∈ R^{m×d} is generated as the privacy-preserving specification. Users supply a small labeled set (for specification generation) and a large unlabeled set (for deployment), and the market returns the learnware whose specification minimizes the Hilbert-Schmidt distance to the user's specification. The specification lives in the output space (not the input space), with each element v_j ∈ Y paired with a d-dimensional weight vector r_j, and comparisons are computed via kernel Gram matrices over the output space.

## Method

RNCME replaces the O(n³) empirical CME estimation with a data-adaptive neural feature map φ_θ: X → R^d (d ≪ n), reducing complexity to O(nd² + d³) while preserving the ability to capture complex input-output dependencies. The feature map is trained by minimizing a closed-form loss L(θ) = −tr(K_Y Φ_θᵀ(Φ_θΦ_θᵀ + nλI)⁻¹Φ_θ) derived from the CME-as-ridge-regression equivalence, which maximally correlates the input RKHS with the output RKHS. For privacy preservation, a Frank-Wolfe iterative algorithm solves a constrained vector-weighted low-rank kernel approximation problem, greedily selecting output-space points v_{t+1} that maximize the residual norm and assigning them bounded weights r_{t+1} = (B_X/λ)·h_t(v_{t+1})/‖h_t(v_{t+1})‖. The paper establishes a unified error bound O_p(1/√(nλ) + √λ + (1/λ)√(ln m/m)) decomposing statistical and reduction errors, and eliminates manual kernel selection by learning the input feature map end-to-end.

## Results

On the NICO++ classification benchmark (30 learnwares, 20 user tasks), RNCME achieves superior NDCG@k and Ensemble Accuracy (EA)@k compared to all baselines (RKME, HF, cRKME, LP) for every k value. At k=1, RNCME retrieves the best-performing learnware for 16/20 user tasks and places the best learnware in the top-3 for all 20 tasks. On the California Housing regression benchmark, RNCME outperforms RKME on NDCG@k for all k. Computationally, RNCME reduces the CME compression stage from >10,000 s (infeasible) to 0.52 s (classification) or 26.6 s (regression) at n=40,000, while a single specification comparison takes <0.001 s versus 0.479 s for cRKME.

## Baselines & Comparisons

RNCME outperforms the basic RKME (Wu et al., 2023) on NDCG@k for all k on both the California Housing regression and NICO++ classification benchmarks, confirming that modeling input-output conditional distributions is essential for functional matching. Against the three labeled-RKME improvements—HF (Tan et al., 2024a), cRKME (Liu et al., 2025), and LP (Guo et al., 2023)—RNCME achieves higher NDCG@k and EA@k at every k on NICO++, with the gap most visible at small k where ranking precision matters most. In terms of efficiency, RNCME's single-comparison cost (<0.001 s) is roughly 50× faster than cRKME (0.479 s) and 40× faster than LP (0.089 s), which becomes critical when the market contains thousands of learnwares. Compared to the full CME with an RBF kernel (Song et al., 2009), RNCME's finite-dimensional neural feature map reduces the compression stage from an infeasible >10,000 s to under 1 s for classification, a speedup of over four orders of magnitude. All labeled-RKME baselines are restricted to classification tasks, whereas RNCME handles both regression and classification, giving it a broader applicability advantage.

## Relation to Prior Work

This paper extends the learnware specification literature by replacing input-only RKME (Wu et al., 2023) with a conditional-distribution-based specification grounded in CME theory (Song et al., 2009). Prior labeled-RKME improvements (Tan et al., 2024a; Liu et al., 2025; Guo et al., 2023) incorporated output information heuristically and were restricted to classification; RNCME instead directly models P(Y|X) via CME with a clear theoretical framework. The neural feature map design draws on the CME-as-ridge-regression equivalence (Grünewälder et al., 2012) and the deep feature learning approach of Xu et al. (2021), while the privacy-preserving reduced set generation adapts the Frank-Wolfe algorithm to a novel constrained vector-weighted low-rank kernel approximation problem.

## Why It Matters / Open Questions

RNCME provides the first specification method for the learnware paradigm that is simultaneously grounded in CME theory, applicable to both regression and classification, and computationally tractable via a data-adaptive neural feature map that eliminates manual kernel selection. The theoretical error bound (Theorem 3.4) gives practitioners a principled way to choose the reduced set size m and regularization λ. However, the experimental validation is limited in scale (≤42 learnwares, ≤21 user tasks), the neural feature map is a single linear layer in all experiments, and the learnware paradigm itself remains a relatively niche research direction with limited real-world deployment, so broader impact awaits larger-scale validation and adoption of the paradigm.

## Problem

Transformers handle long contexts via per-layer KV-caches that scale linearly with sequence length and do not produce a portable, reusable representation. Forward-only memory writers (e.g., RMT) compress context into a fixed-size state in a single pass but cannot verify or correct encoding errors. The paper asks whether a small number of test-time gradient descent steps on a compact memory state can outperform forward-only writing and scale capacity with additional optimization compute.
![Teaser figure](../imgs/ICML20262253/cropped_page0_idx0.webp)

## Input / Output

The method takes a context sequence C (arbitrary length, e.g., a list of key-value pairs or a passage) and a query Q, and produces a fixed-size memory state M ∈ R^{m×d} (e.g., 8 vectors of 128-dim = 1024 floats) independent of context length. At READ time, the model predicts the target Y from the concatenation [M; Q] with no access to C. The memory is parameterized as prefix embedding tokens prepended to the model input, so the base transformer architecture is preserved unchanged.

## Method

GradMem performs a WRITE phase where K steps of gradient descent update m memory prefix tokens to minimize a self-supervised autoregressive reconstruction loss L_write(M; C) = −Σ log f_θ(t_i | [M; t_{<i}]), while all model weights remain frozen. The memory is initialized from a shared meta-learned state M_0, and the outer loop trains θ and M_0 by backpropagating second-order gradients through the unrolled WRITE optimization (MAML-style meta-learning), so the model learns to use few gradient steps as an effective write operation. This loss-driven inner loop provides per-example feedback that iteratively corrects encoding errors, unlike forward-only writers that emit a memory in one pass with no verification. At READ, the model predicts Y from [M_K; Q] under the context-removal constraint. The key distinction from TTT layers is that GradMem concentrates all adaptation into a single model-level memory state updated once per context, rather than maintaining per-layer states updated per token.

## Results

On the primary associative KV-retrieval benchmark, GradMem with K=5 gradient WRITE steps achieves 99.1% exact match at 64 key-value pairs and 88.4% at 96 pairs, using only 8 memory vectors (1,024 floats), compared to 19.3% and 12.9% for the forward-only RMT baseline with the same memory size. Even a single gradient step (K=1) reaches 96.3% at 16 pairs versus 45.5% for RMT. On natural language tasks with pretrained GPT-2, GradMem with increased K achieves 54.9% EM on Short SQuAD (vs. 42.6% for RMT and 39.0% for ARMT), and 2.92 cross-entropy on WikiText-103 language modeling, remaining competitive with recurrent baselines while using a much smaller memory state.

## Baselines & Comparisons

Against the directly comparable forward-only RMT baseline (same architecture, same m=8 memory vectors), GradMem wins decisively at every scale beyond 8 pairs: at 16 pairs, K=1 achieves 96.3% vs. RMT's 45.5%, and K=5 reaches 100% vs. RMT's 45.5%; repeating RMT's forward pass up to 5 times yields at best 37.0% at 32 pairs, far below GradMem K=1's 86.9%. Against per-layer baselines, GradMem K=5 outperforms ARMT (88.4% vs. 15.2% at 96 pairs) and approaches Mamba (88.4% vs. 92.2% at 96 pairs) while using a 40× smaller memory state (1,024 vs. ~41,000 floats). Against test-time-training methods, GradMem K=5 beats TTT-Linear (88.4% vs. 11.9% at 96 pairs) and LaCT (88.4% vs. 46.9% mean, 74.9% best-of-3 at 96 pairs) despite using a much smaller memory state. On NLP tasks, GradMem with increased K outperforms RMT on Short SQuAD (54.9% vs. 42.6% EM) and matches or exceeds it on bAbI QA1/QA2/QA4/QA5, though it trails on QA3 (79.3% vs. 87.9%) where information density is highest; on language modeling, ARMT leads (2.85 CE) with GradMem close behind (2.91–2.92 CE), while full-context GPT-2 remains the upper bound (2.72 CE).

## Relation to Prior Work

GradMem sits at the intersection of test-time training (TTT layers, Sun et al. 2025), recurrent memory transformers (RMT, Bulatov et al. 2022), and meta-learning (MAML, Finn et al. 2017). It departs from TTT layers by concentrating all adaptation into a single model-level prefix memory state written once per context, rather than maintaining per-layer fast weights updated token-by-token. It departs from forward-only memory writers (RMT, ARMT, Compressive Transformers) by replacing the fixed forward computation with an explicit, loss-driven inner optimization loop on memory tokens, and from prior embedding-optimization work (Kuratov et al. 2025) by targeting the few-step regime (K≤5) via second-order meta-learning of the initialization.

## Why It Matters / Open Questions

The paper establishes that gradient-based test-time writing into a compact memory state is a strictly more expressive operation than forward-only writing at the same memory budget, and that additional WRITE steps provide a clean compute-for-capacity tradeoff. This opens a practical path for amortizing expensive context encoding across many queries while keeping model weights frozen. Key limitations include the reliance on expensive second-order meta-gradients (incompatible with FlashAttention), evaluation primarily on small models (≤124M) and a synthetic benchmark, and modest gains on natural language tasks where pretrained recurrent models (Mamba) still lead. Open questions include whether first-order meta-learning (iMAML, Reptile) suffices, how the approach scales to 10B+ models and multi-thousand-token contexts, and whether learned task-aware WRITE objectives can further improve compression fidelity.

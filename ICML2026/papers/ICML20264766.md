## Problem

Existing MCP and tool-use benchmarks predominantly target generic, stateless information-seeking tools or rely on synthetic environments, leaving a critical gap in evaluating agents on real-world personalized applications (social media, enterprise collaboration, email) where tools are tightly coupled to individual user accounts, local databases, and historical state. Constructing such a benchmark is hindered by the need for private user data, privacy constraints on sharing personal contexts, and the technical difficulty of maintaining stable, reproducible simulation environments across heterogeneous user profiles.

## Input / Output

Each task provides the agent with a fuzzified natural-language instruction (deliberately omitting implicit parameters like user IDs that must be resolved from the environment), a set of MCP tool schemas drawn from up to 24 servers (12 personalized + 12 generic search), and a structured context tree representing the user's state (e.g., User → Calendar → Event with typed entities and foreign-key references). The agent operates in a multi-step loop of up to 20 tool-call rounds within a sandboxed simulated environment. Evaluation produces three metrics: checkpoint accuracy (LLM-judged per sub-task boundary), SR-0.8 (fraction of tasks exceeding 0.8 accuracy), and execution accuracy (verified via dedicated CRUD executors checking actual context-file mutations).

## Method

MCP-Persona is built on three interlocking components. Tool-Traverse implements a traverse-then-simulate paradigm: human-curated seed function calls are expanded via Self-FC (inspired by Self-Instruct) and adversarial failure induction (type mismatches, schema violations, boundary conditions, semantic conflicts), then LLMs synthesize executable Python simulation kernels that replicate both success and error behaviors of real servers, including a dynamic context handler for stateful CRUD persistence. Context-Tree constructs a hierarchical, user-rooted entity tree per server (e.g., User → Chat → Message), populated with a mix of authentic sanitized content, enumerated values, random IDs, and free-form LLM generation, with cross-entity foreign-key linking for relational consistency. Persona-Gen generates tasks by sampling topologically constrained tool invocation chains (enforcing dependency, personalization, deduplication, coherence, and realism), prototyping instructions with typed placeholders, injecting context-tree values, and fuzzifying by removing implicit parameters that the agent must discover from the environment; all 173 tasks undergo human verification and difficulty calibration.

## Results

On MCP-Persona (173 tasks across 12 personalized MCP servers), no SOTA agent exceeds 50% accuracy in either checkpoint or execution evaluations. Claude-Sonnet-4.5 achieves the best overall performance with 38.66 Acc, 10.40 SR-0.8, and 41.50 Exec-Acc, while GPT-5 follows closely at 36.99 Acc and 41.45 Exec-Acc. The best open-source model, Qwen3-Max-Latest, reaches only 27.54 Acc. Cross-server 'Hodgepodge' tasks are the hardest, with even the top model scoring just 12.50 Acc, revealing severe limitations in multi-tool coordination and implicit context resolution.

## Baselines & Comparisons

MCP-Persona is positioned against five prior benchmarks (AppWorld, PersonaBench, InfoMosaic-Bench, MCP-Universe, ToolAthlon) in a coverage comparison (Table 1): it is the only benchmark that simultaneously provides real-world tools, personal context, and coverage across all four application domains (Social Media, Collaboration Platform, Email, Content Management). In terms of agent performance on MCP-Persona, Claude-Sonnet-4.5 leads with 38.66 Acc, outperforming GPT-5 (36.99) by ~1.7 points and Claude-Opus-4.1 (34.52) by ~4.1 points; notably, GPT-5 achieves higher Exec-Acc (41.45) than Claude-Sonnet-4.5 (41.50) is nearly matched, but GPT-5's SR-0.8 (6.94) is lower, indicating it completes fewer tasks end-to-end. Among open-source models, Qwen3-Max-Latest (27.54 Acc) trails the best proprietary model by over 11 points. The simulation fidelity validation (Table 4) shows Tool-Traverse achieves 94.0% behavioral alignment accuracy and 93.8% F1 versus only 58.0% and 53.3% for a documentation-only Vanilla baseline, confirming the simulated environment faithfully reproduces real server behavior.

## Relation to Prior Work

This paper carves new ground at the intersection of MCP tool-use evaluation and personalized, stateful application simulation. Prior benchmarks (MCP-Universe, ToolAthlon, AppWorld, PersonaBench) either target generic stateless information-seeking tools or rely on synthetic environments, leaving a gap for account-bound, user-specific applications like Lark, Slack, and Xiaohongshu. The Tool-Traverse simulation method borrows the Self-Instruct paradigm for expanding function-call coverage but applies it to behavioral probing of live servers, while the Context-Tree hierarchy is a novel construct for encoding user-specific state that prior tool-use benchmarks have not addressed. The paper does not build on a single prior method but synthesizes environment-simulation, code-generation, and task-fuzzification techniques into a unified evaluation pipeline.

## Why It Matters / Open Questions

As MCP adoption accelerates in personal and enterprise applications, the inability to evaluate agents on realistic, account-bound tools is a critical bottleneck; MCP-Persona provides the first reproducible, privacy-preserving testbed for this setting. The finding that even GPT-5 and Claude-Sonnet-4.5 remain below 50% accuracy—and that the gap is driven by under-exploration of environment state and skipped dependency resolution—points to concrete failure modes that future agent architectures must address. Open questions include whether the simulation fidelity generalizes beyond the 12 curated servers, whether the 173-task scale is sufficient for robust model ranking, and whether the skill-documentation approach can eventually close the performance gap or whether fundamentally new reasoning strategies are needed for implicit context grounding.

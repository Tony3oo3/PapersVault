## Problem

Current Transformer-based output guardrails process text strictly as 1D token sequences, making them robust against existing format-control jailbreaks (encoding, low-resource languages, Ubbi Dubbi) that preserve malicious semantics in sequential order. The paper asks: how can an attacker restructure harmful content so that guardrails fundamentally fail to recognize it, rather than merely weakening detection? This exposes an unexploited structural blind spot in the sequential processing paradigm underlying all current safety classifiers.

## Input / Output

The attack takes a harmful text string, a chosen spatial template (acrostic, telestich, center-embedded, staircase, corner, or multilingual randomization), and few-shot exemplars demonstrating the target layout. The LLM is prompted to embed each harmful token at the prescribed 2D position within a multi-line text block, producing output that reads as a coherent surface-level text to humans while the hidden message is recoverable only by extracting characters from specific spatial coordinates (e.g., first letter of each line). The evaluation pipeline then performs spatial extraction, a word-level check on the recovered message, and a semantic guardrail check on the full output, counting an attack as successful only when the hidden message is harmful yet the guardrail classifies the entire response as benign.

## Method

SpatialJB exploits the mismatch between human 2D visual reading and Transformer 1D sequential processing by reorganizing harmful tokens into spatially structured layouts that break token-level continuity while preserving human readability. The theoretical contribution formalizes two results: (1) Token Layout Loss proves that for any flattening function π, the visual neighborhood N_vis(r,c) ≠ π⁻¹(N_seq(π(r,c))), meaning spatial adjacency is irreversibly destroyed during serialization; and (2) Token Sensitivity shows that expected attention weight decays exponentially with serialized distance, E[A_ij] ∝ e^{-α|i-j|}, so spatially adjacent but sequentially distant tokens lose semantic correlation (empirically dropping from 0.9419 to 0.5846). Six template variants target different positional dependencies (line-initial, line-final, center, diagonal, corner, multilingual padding) to ensure broad coverage across guardrail architectures. The paper also introduces SpatialD, a baseline post-hoc defense that reconstructs the output into a 2D grid, extracts text along the five known spatial patterns, and passes each extracted segment to Llama Guard for independent safety classification, achieving 77–90.5% defense success rate across tested models.

## Results

On the Repeat jailbreak task without guardrails, SpatialJB achieves 95–100% Attack Success Rate (ASR) across all seven tested LLMs (GPT-4, DeepSeek-R1/V3, Llama-4, Gemini-2.5-Pro, Claude, Grok-4), with DeepSeek-V3, Llama-4, and Grok-4 reaching a perfect 100%. Even under the OpenAI Moderation API guardrail, SpatialJB maintains 73–95% ASR, while the strongest baseline (SATA) drops to 14–31%. On the harder Summary task, SpatialJB still achieves 47–76% ASR without guardrails, far exceeding all baselines which remain below 22%.

## Baselines & Comparisons

SpatialJB outperforms all five baselines by a wide margin across every model and guardrail configuration. The encoding-based Base64 (Wei et al., 2023) and low-resource-language Zulu (Yong et al., 2024) baselines achieve only 5–15% ASR, as do the Ubbi Dubbi language-game method (Peng et al., 2024) at 7–15%. The more advanced semantic-level baselines—PAP persuasion (Zeng et al., 2024) at 13–19% and SATA assistive-task masking (Dong et al., 2025) at 15–31%—still trail SpatialJB by 60–80+ percentage points. Even the strongest baseline (SATA at ~31% on Llama-4) is outperformed by SpatialJB's weakest template (Corner at 100% on the same model). Under the OpenAI Moderation API, SpatialJB's Random template on GPT-4 reaches 95% ASR versus SATA's 17.2%, confirming that the gap is not merely a function of guardrail strictness but reflects a fundamental structural vulnerability in sequential token processing.

## Relation to Prior Work

This paper carves new ground within the format-control jailbreak literature by identifying spatial text distribution as a previously unexploited attack axis. Prior methods (Base64 encoding, Zulu translation, Ubbi Dubbi, ArtPrompt, FlipAttack, PAP, SATA) either replace the semantic carrier or insert sequential noise, but all preserve the malicious content in a linearly recoverable form that Transformer-based guardrails can reconstruct. SpatialJB departs fundamentally by exploiting the 1D serialization bottleneck of self-attention: harmful tokens are placed at visually coherent but sequentially distant positions, so the guardrail's positional-encoding-based attention cannot reassemble the intended meaning. The theoretical framing (exponential attention decay with serialized distance) connects to known locality-bias properties of Transformers but applies them to a new adversarial context.

## Why It Matters / Open Questions

The paper exposes a structural blind spot in all current Transformer-based output guardrails: they are architecturally incapable of perceiving 2D spatial relationships in text, meaning no amount of fine-tuning on safety data can fix this without changing the input representation. The near-100% ASR on frontier models (DeepSeek-V3, Llama-4, Grok-4) and sustained 75%+ against production guardrails like OpenAI Moderation API signals that deployed LLM safety pipelines have a concrete, easily exploitable weakness. The proposed defense (SpatialD) is explicitly a baseline with fixed extraction patterns, leaving open the critical question of how to build guardrails with genuine spatial-awareness. Broader implications include whether similar spatial vulnerabilities exist in multimodal or code-generation contexts, and whether the composability of SpatialJB with elicitation-stage attacks (FlipAttack, ArtPrompt) creates a practical two-stage threat model for real deployments.

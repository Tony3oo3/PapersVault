## Problem

Single-cell Foundation Models (scFMs) are widely expected to enable zero-shot gene regulatory network (GRN) inference, yet standard strategies like zero-out perturbation and attention extraction perform near-randomly, revealing a critical misalignment between reconstruction-based pre-training and the inter-gene regulatory signals needed for GRN inference. Moreover, no existing benchmark rigorously tests whether scFMs encode generalizable regulatory knowledge that transfers to unseen genes and heterogeneous datasets.

## Input / Output

The method takes a gene pair (source g_i, target g_j) as input and outputs a scalar regulatory link probability. Crucially, no real expression data is required at inference time: the frozen scFM is queried entirely with virtual expression vectors (a unified base value and a set of perturbation targets), so the system can predict regulatory links for any gene pair in the scFM's vocabulary regardless of whether expression measurements exist. The trainable component is a small MLP projector (128→64 hidden layers) that maps the extracted pair-wise feature vector to a sigmoid-bounded score.

## Method

The paper proposes two complementary feature extractors that distill implicit regulatory knowledge from a frozen scFM via counterfactual queries with virtual values. Virtual Value Perturbation (VVP) replaces the conventional zero-out operation by perturbing the source gene from a unified virtual base value v_b to multiple virtual target values v_p, measuring the target gene's reconstruction shift at each target to build a multi-dimensional response vector that is comparable across all gene pairs. Gradient Trajectory (GDT) computes the partial derivative of the target gene's reconstruction with respect to the source gene's input along an ordered trajectory of virtual base values, capturing instantaneous local sensitivities across the expression range. These features are concatenated in both directions (i→j and j→i) and fed into a trainable MLP projector f_φ, supervised with binary cross-entropy on a source dataset under a Leave-One-Dataset-Out protocol that enforces generalization to unseen genes and heterogeneous datasets. An ensemble averaging the VVP and GDT logits yields the final prediction, and the entire pipeline requires no retraining of the scFM itself.

## Results

On the UGRN benchmark (AUPRC, TFs+500), the proposed Ensemble (ENS) method achieves an average AUPRC of 0.768 using scBenchmark and 0.743 using scGPT, substantially outperforming all baselines. The GDT method alone reaches 0.738 (scBenchmark) and 0.740 (scGPT), while the strongest baseline (Baseline-Emb) achieves only 0.663 and 0.662 respectively. In the most favorable setting (STR network, mH-L dataset with scBenchmark), ENS reaches an AUPRC of 0.934, compared to 0.784 for Baseline-Emb and 0.655 for Origin-Pert.

## Baselines & Comparisons

The paper compares against three categories of baselines: (1) Origin-Pert (In-Silico Perturbation from Geneformer/Theodoris et al., 2023), (2) Origin-Attn (Attention Extraction from scBERT/Yang et al., 2022 and scGPT/Cui et al., 2024), and (3) two UGRN-specific baselines (Baseline-Pert and Baseline-Emb). The proposed ENS method wins decisively across all comparisons: it outperforms Origin-Pert (0.584) by 31.5%, Origin-Attn (0.630) by 21.9%, Baseline-Pert (0.596) by 28.8%, and the strongest baseline Baseline-Emb (0.663) by 15.8% in average AUPRC on scBenchmark. GDT alone (0.738) already surpasses Baseline-Emb by 11.3%, confirming that gradient-based feature extraction is the primary driver of the gain. The advantage is most pronounced on STRING networks (up to 0.934 vs. 0.784 for Baseline-Emb on mH-L) and in cross-species settings (0.936 ENS vs. 0.730 Baseline-Emb), while on the more challenging SPC (cell-type-specific ChIP-seq) networks the margin narrows to ~5–10%, with VVP occasionally matching or slightly exceeding ENS.

## Relation to Prior Work

This paper builds directly on the in-silico perturbation paradigm introduced by Geneformer (Theodoris et al., 2023) and the attention-extraction strategy from scBERT (Yang et al., 2022), both of which use frozen scFMs for zero-shot GRN inference. The key departure is rejecting the assumption that raw perturbation deltas or attention weights can serve as regulatory scores; instead, the authors introduce a learnable 'translator' (UGRN framework) that maps richer scFM-derived features to regulatory probabilities, and propose Virtual Value Perturbation and Gradient Trajectory as feature extractors that decouple inter-gene influence from dataset-specific expression statistics. The UGRN evaluation setting (leave-one-dataset-out with minimal gene/label overlap) extends the standard closed-world GRN benchmark by explicitly testing cross-dataset and cross-gene generalization.

## Why It Matters / Open Questions

This work directly addresses a growing crisis of confidence in the biological community regarding scFMs' utility for GRN inference, where multiple recent benchmarks showed near-random performance. By demonstrating that the failure stems from simplistic interrogation rather than absent knowledge, the paper reframes the problem and provides a practical path forward. Key limitations include strict dependence on the scFM's pre-trained gene vocabulary (unseen genes are intractable) and the fact that the 'translator' still requires labeled training data, partially relaxing the zero-shot promise. Open questions include whether the extracted features capture true causal regulation versus sophisticated correlation, and whether context-dependent covariates (tissue type, cell state) can be integrated into the UGRN framework.

## Problem

Randomized linear algebra (RLA) algorithms—such as sketch-and-precondition solvers, randomized Kaczmarz, and Newton Sketch—are critical for large-scale scientific computing, yet their discovery remains a manual process requiring deep expert knowledge. While reinforcement learning offers a path to automation, standard RL approaches fail in this domain due to sparse reward landscapes and combinatorially large search spaces over multi-step algorithmic compositions. No general-purpose framework existed for systematically discovering interpretable RLA algorithms from primitive operators.

## Input / Output

The framework consumes a typed operator library of 17 linear-algebra primitives (e.g., SKETCH, HHQR, MATVEC, INV, SUBSAMPLING, LEVERAGE_SCORE), stage-specific reward weight vectors, and problem instances with controlled spectral and leverage properties generated via SVD. It produces explicit two-stage symbolic programs—a setup phase (one-time preprocessing like sketching and factorization) and an iteration phase (the update rule)—written as typed register operations that are directly executable, dead-code-eliminated, and semantically verifiable against known algorithms. Unlike black-box learned optimizers, the output is human-readable code that can be formally analyzed.

## Method

RL4RLA formulates RLA discovery as sequential program construction over a grammar of typed linear-algebra primitives, where each action inserts one operator at a chosen position in either the setup or iteration stage. Two key mechanisms address the sparse-reward and large-search-space challenges: (1) a numerical curriculum that decomposes deep compositional search into shallow stages, each introducing exactly one failure mode (e.g., ill-conditioning, high preconditioning cost, non-uniform leverage) that necessitates one new algorithmic component, with stage-specific reward weights emphasizing the dominant failure; (2) Monte Carlo Graph Search (MCGS) with the UCD selection rule, which operates on a DAG that merges semantically equivalent partial programs reached via different action orderings, reducing redundant exploration by 2–3× compared to tree-based MCTS. An adaptive LUCB-based stopping criterion terminates each stage when sufficient evidence identifies the best action, and the discovered program is promoted as the initialization for the next curriculum stage, enabling compositional refinement rather than rediscovery from scratch.

## Results

Across five curriculum targets, MCGS+UCD reduces total playouts by 2–3× compared to MCTS (e.g., 10,721 vs. 34,902 for Preconditioned Weighted SGD; 6,034 vs. 17,655 for Sketched Preconditioned GD) while maintaining or improving success rates (75–80%). The Newton Sketch curriculum achieves 100% success with the full four-stage curriculum, whereas all no-curriculum and partial-curriculum variants fail completely (0%). On the real-world YearPredictionMSD dataset, discovered algorithms achieve relative residuals of 8.69e-01 (Precond GD, 85.6 s) to 9.19e-01 (Block RK, 159.1 s) without any retraining or reward modification.

## Baselines & Comparisons

The paper compares RL4RLA against two LLM-driven program-search baselines: FunSearch and AlgoTune. FunSearch candidates scale poorly across diverse linear systems, producing orders-of-magnitude higher runtime and noncompetitive residuals on both well-conditioned and ill-conditioned systems (Figure 7). AlgoTune, which performs code-level optimizations (library swaps, JIT compilation) over existing implementations, produces dense deterministic solvers in all five task variants (Cholesky, LAPACK lstsq, or L-BFGS) and never discovers randomized structures such as sketching or leverage-score sampling. Neither baseline composes new algorithmic structures from symbolic primitives; both are biased toward the training distribution of the underlying LLM. RL4RLA's key advantage is interpretability: it outputs explicit symbolic programs (e.g., sketch → QR → precondition → iterate) that are directly verifiable and implementable, whereas the baselines produce opaque code edits. On the YearPredictionMSD transfer test, RL4RLA-discovered algorithms achieve competitive residuals (8.69e-01 to 9.19e-01) with moderate runtime, while the baselines' dense solvers do not generalize across matrix families.

## Relation to Prior Work

This paper extends the automated algorithm discovery lineage (LION, AlphaTensor, AlphaDev) to the domain of randomized linear algebra, where prior work has addressed only isolated components (learned sketching, learned preconditioners) rather than complete algorithm composition. Methodologically, it builds on Monte Carlo Graph Search (Leurent & Maillard, 2020) for state merging and MCTS for sequential decision-making, but introduces a curriculum decomposition that is specific to the compositional structure of RLA primitives. Unlike LLM-driven approaches (FunSearch, AlgoTune) that bias search toward training-distribution code patterns, RL4RLA searches over typed symbolic programs from a fixed operator grammar, ensuring interpretability and avoiding pretrained priors.

## Why It Matters / Open Questions

This is the first general-purpose framework for automated RLA algorithm discovery, and its ability to rediscover Blendenpik, Randomized Kaczmarz, and Newton Sketch with customizable accuracy/speed/stability trade-offs validates the curriculum-plus-graph-search paradigm. The Newton Sketch ablation—where all partial curricula fail at 0% while the full curriculum achieves 100%—suggests that staged failure-mode exposure is a reachability prerequisite, not merely an efficiency trick, for deep compositional algorithm search. Key limitations include the synthetic discovery environment, the requirement to specify a task interface per problem class, and the gap between rediscovery and validated novel algorithm discovery, which would require larger budgets and formal post-search analysis.

## Problem

Existing AI-driven video creation pipelines treat script drafting (via LLMs) and keyframe generation (via image models) as disjoint tasks, resulting in weak narrative logic and poor visual consistency across multi-shot sequences. The paper argues that, as in traditional filmmaking, these two processes should be unified within a single model that jointly reasons about narrative structure and visual composition.
![Teaser figure](../imgs/ICML20265801/cropped_page0_idx0.webp)

## Input / Output

The model takes a short user prompt (sampled from four styles: simple narrative, abstract concept, phrase splicing, or spoken expression) and optionally an existing script for extension or continuation. It outputs a structured multi-shot script containing global character/environment definitions, per-shot frame and video descriptions with special tokens (<CharacterN>, <EnvironmentN>, <FrameN>, <VideoN>) for cross-referencing, and corresponding keyframe images generated in an interleaved text-image format. The script also encodes dialogue and sound effects using <-...-> indicator symbols for downstream audio-video generation.

## Method

UniMAGE is built on the Mixture-of-Transformers (MoT) architecture from Bagel, comprising two transformer experts (understanding via ViT/SigLIP2 and generation via VAE/FLUX) that share self-attention layers, with Next Token Prediction for text and Rectified Flow for images. Training proceeds in two stages: first, Interleaved Concept Learning jointly optimizes all parameters on interleaved text-image script data to build holistic narrative understanding; second, Disentangled Expert Learning freezes the understanding branch while optimizing the generation branch on interleaved data, and separately trains the LLM as a dedicated script expert on pure text. Two key strategies enhance performance: In-Context ID Prompting inserts special tokens among ViT and VAE tokens to bind character/environment identities to generated images for multi-subject consistency, and Pre-Context Script Splitting randomly divides scripts with <Extension> or <Continuation> tokens so the model learns flexible narrative expansion and infinite continuation.

## Results

On ViStoryBench-V3, UniMAGE achieves the best scores in Character Identification Similarity (CIDS: 59.2), Prompt Adherence/Alignment (80.8), and Onstage Character Count Matching (OCCM: 88.07), surpassing all baselines by substantial margins. Its image quality metrics (Inception: 12.97, Aesthetics: 4.55) trail behind dedicated image-generation baselines like StoryDiffusion (15.71, 5.76) and Story2Board (15.26, 5.11), which do not jointly generate scripts. SEED-Story, the only other unified script+image model, scores highest on Style Similarity (CSD: 74.9) but collapses on Alignment (29.5) and Inception (6.33), reflecting overfitting to its narrow training distribution.

## Baselines & Comparisons

UniMAGE decisively outperforms all five baselines on the consistency and alignment metrics that matter most for multi-shot storytelling: CIDS (59.2 vs. 57.0 for StoryDiffusion, 56.4 for Story-Adapter, 48.7 for SEED-Story), Alignment (80.8 vs. 59.7 for StoryDiffusion, 58.9 for Story-Adapter, 29.5 for SEED-Story), and OCCM (88.07 vs. 85.9 for SEED-Story, 85.5 for Story2Board). Against StoryDiffusion and Story2Board—strong image-consistency methods that do not generate scripts—UniMAGE trades roughly 2–3 points of Inception score and 1–1.2 points of Aesthetics for dramatically better narrative alignment and character tracking. Against SEED-Story, the only other unified script+image model, UniMAGE wins on every metric except CSD (59.0 vs. 74.9), which the authors attribute to SEED-Story's overfitting to three animation datasets. Against TheaterGen and Story-Adapter, UniMAGE leads on all six metrics, with the largest gaps in Alignment (+42.9 and +21.9 respectively). The ablation rows confirm that In-Context ID Prompting contributes most to CIDS and OCCM, while Disentangled Expert Learning drives the large Alignment gain (77.4 → 80.8) and image-quality improvement (9.85 → 12.97 Inception).

## Relation to Prior Work

UniMAGE builds directly on the Mixture-of-Transformers (MoT) architecture from Bagel, which unifies an LLM and a diffusion model in a shared transformer with modality-specific experts. It departs from the dominant agent-based paradigm (MovieAgent, FilmAgent, Anim-Director) that treats script drafting and keyframe generation as disjoint tasks handled by separate LLM and image-generation models, instead framing both as outputs of a single 'unified director.' The two-stage training paradigm—Interleaved Concept Learning followed by Disentangled Expert Learning—extends the unified multimodal generation line (Show-O, TransFusion, Bagel) from short-context image editing to long-context, multi-shot film scripts, a regime where prior unified models have not been applied.

## Why It Matters / Open Questions

By unifying narrative reasoning and visual generation in one model, UniMAGE addresses a practical gap in AI-driven filmmaking: the weak narrative-visual alignment and character inconsistency that arise when separate agents handle scripts and keyframes. The In-Context ID Prompting and Pre-Context Script Splitting strategies offer transferable techniques for maintaining multi-subject identity and enabling flexible script continuation in long sequences. However, the paper acknowledges that emotional pacing, cinematic style, and audio-video synchronization remain underexplored, and image quality still lags behind dedicated diffusion models, leaving open whether a single unified architecture can eventually match specialist generators on all axes.

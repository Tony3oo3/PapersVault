## Problem

Existing benchmarks for world models lack large-scale diverse datasets, unified action input definitions across heterogeneous interaction modalities (text, one-hot keyboard, camera parameters), and dedicated tasks for evaluating interactivity such as memory and trajectory following. This makes fair cross-model comparison of interactive world models' physical interaction capabilities impossible.
![Teaser figure](../imgs/ICML20261070/cropped_page1_idx0.webp)

## Input / Output

The benchmark feeds each evaluated world model an initial scene frame (from 2,100 curated 1080P clips) plus a control signal in the model's native modality—text commands, one-hot key encodings, or 3×4 extrinsic + intrinsic camera parameter files—across 4,900 tasks spanning six types. The output is a vector of 9 normalized scores across three dimensions (generation quality, trajectory following, memory ability), aggregated into a single ranking per model. The Action Generation Framework ensures each of the 81 supported motion actions maps to a unique encoding in every modality, so a 'forward-left' command is semantically identical whether expressed as text, a keypress vector, or a camera pose delta.

## Method

The core contribution is a Unified Action Generation Framework with two components: (1) Interactive Action Encoding, which defines a 27×27 translational-rotational motion space (729 actions) with difficulty levels D=1–6 and validity flags, currently instantiated as 81 actions; and (2) Unified Encoding Mapping, a dictionary that assigns each action a unique ID and maps it to intrinsic/extrinsic camera parameters, one-hot vectors, and text signals simultaneously. The dataset pipeline standardizes 12 open-source datasets (KITTI, RealEstate-10K, TartanAir, SpatialVid, etc.) and 100k clips from 4 simulators into 330k unified 81-frame video clips with VLM-assisted annotation verified by three independent models plus human refinement. Six task types—four action-control difficulties, a cyclic-path memory test, and a camera-following task—jointly probe generation fidelity, action adherence, and spatial memory. Evaluation uses 9 metrics including MUSIQ, BRISQUE-coupled Tenengrad sharpness, ViPE-based trajectory accuracy/tolerance, and mirror-symmetry memory scores.

## Results

Across 14 interactive world models evaluated on iWorld-Bench's 4,900 tasks, HY-World 1.5 (one-hot encoding) achieves the highest average score of 0.7873, excelling in both memory ability (Memory Symmetry: 0.8481) and trajectory following (Trajectory Accuracy: 0.7472). In the Camera Following task (700 camera parameter files), AC3D leads with the best Trajectory Tolerance (0.9091), Brightness Consistency (0.8927), and Motion Smoothness (0.9919). Text-controlled models like CogVideoX-I2V achieve the highest visual consistency (Brightness Consistency: 0.8988) but sacrifice trajectory accuracy (0.5950), revealing a fundamental trade-off between generation quality and action controllability.

## Baselines & Comparisons

The benchmark evaluates three interaction paradigms: text-controlled (5 models), one-hot encoding (2 models), and camera-parameter control (7 models). HY-World 1.5 (one-hot) dominates overall, outperforming the best text model HunyuanVideo-1.5 by 7.1 points in average score and surpassing CogVideoX-I2V by 15.2 points in Trajectory Accuracy (0.7472 vs. 0.5950), demonstrating that discrete action signals provide superior controllability over continuous text descriptions. In the camera-parameter category, videox-fun-Wan and AC3D lead in memory tasks (Memory Symmetry: 0.9009 and 0.9068 respectively), while early methods like MotionCtrl (rank 14) and CameraCtrl (rank 11) show limited effectiveness across all metrics. A notable finding is that camera-controlled fine-tunes (AC3D from CogVideoX-I2V, HY-World 1.5 from HunyuanVideo-1.5) improve trajectory following substantially but exhibit slight degradation in generation quality compared to their base models, confirming a controllability-vs-fidelity trade-off. In the dedicated Camera Following task, AC3D achieves the best Trajectory Tolerance (0.9091) versus ASTRA's 0.4286, a 2.1× gap indicating substantial architectural variation in translating explicit camera parameters into coherent visual sequences.

## Relation to Prior Work

This paper carves new ground at the intersection of world model benchmarking and interactive evaluation. Prior benchmarks (WorldScore, EWMbench, WorldEval, VMbench) evaluate world models on general generation quality or embodied manipulation but lack unified action input definitions, interactive task design, and memory evaluation. The key conceptual departure is the Action Generation Framework, which repurposes the heterogeneous action spaces of existing world models (text commands, one-hot keyboard inputs, continuous camera parameters) into a single 81-action unified encoding, enabling fair cross-modality comparison for the first time. The dataset construction repurposes 12 existing camera-parameter datasets and 4 simulators through a standardization pipeline rather than introducing a new data collection paradigm.

## Why It Matters / Open Questions

This is the first benchmark specifically targeting the interactivity of world models rather than their general generation quality, filling a gap that the paper argues is critical for agent training applications. The revealed trade-off—fine-tuning for camera controllability degrades base-model visual fidelity—provides a concrete design tension for future world model architectures. Open questions include whether the 81-action space is sufficient for truly complex interactions, whether memory evaluation via cyclic paths captures genuine long-horizon spatial persistence, and how these findings extend to real-time and long-horizon consistency. The 330k-video dataset and public leaderboard position this as a potential standard reference for the interactive world model community.

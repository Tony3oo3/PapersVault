## Problem

Existing continual model merging methods specify each update as a fixed algebraic or projection-based operation that maps the current model and incoming model directly to a single endpoint, providing no explicit control over the transition path or the relative retention of accumulated knowledge versus incoming task expertise. This endpoint-only view leads to unstable retention and performance degradation in long task streams, particularly when tasks carry heterogeneous utilities with different practical costs of degradation.
![Teaser figure](../imgs/ICML20262744/cropped_page0_idx0.webp)

## Input / Output

At each merge step, the method consumes the currently deployed merged model Ψ_{k-1}, the newly arrived task-adapted model ψ_k, the shared pre-trained CLIP backbone ψ_0, and a small calibration set of 1024 samples aggregated from previously seen tasks. The output is the next merged model Ψ_k, obtained by integrating an ODE for a utility-specified fraction of the trajectory (e.g., t_k = 1/k under equal utility) using Euler steps of size 0.05, rather than jumping to the full endpoint. The calibration set is used only for first-order gradient evaluations during integration, not for any parameter update in the traditional training sense.

## Method

ODE-M formulates each continual merge as a continuous trajectory θ:[0,1]→R^d from the current model θ_0 to the incoming model θ_1, rather than a single-step algebraic update. A base velocity field u_t(θ) = α(t)(θ_1 − θ) with α(t) = 1/(1−t) provides geometric transport toward the target; at each Euler step, the velocity is decomposed into a gradient-aligned component u_∥ and an orthogonal component u_⊥ relative to the calibration-set loss gradient g_t, and only the loss-increasing component is damped by an adaptive factor γ(θ,t) ∈ [0,1] that clips the instantaneous loss increase to a prescribed budget ΔL. The resulting rectified field v_t = u_⊥ + γ·u_∥ yields a barrier-aware trajectory whose loss barrier is provably bounded by max{L(θ_0) − L(θ_1), 0} and which converges to θ_1 as t→1. The final merged model is selected at an operating time t_k = w_k / Σw_i along the trajectory, turning integration time into an explicit control handle for the stability-plasticity trade-off under heterogeneous task utilities.

## Results

ODE-M achieves the highest macro-averaged accuracy (ACC) across all three CLIP ViT backbones and all stream lengths (8, 14, 20 tasks). On ViT-B/32, ODE-M improves ACC from 75.5 (OPCM) to 79.6 on 8 tasks, 71.9→74.1 on 14 tasks, and 65.7→67.1 on 20 tasks. The largest gain appears on ViT-L/14 with 20 tasks, where ODE-M reaches 81.1 ACC versus 76.0 for OPCM (+5.1). On backward transfer (BWT), ODE-M is competitive: it achieves the best BWT on shorter streams (e.g., −4.2 vs. −6.3 for OPCM on ViT-B/32, 8 tasks) but trades some retention for accuracy on longer streams (e.g., −9.4 vs. −7.8 on ViT-B/32, 20 tasks).

## Baselines & Comparisons

ODE-M outperforms all four baselines on ACC in every configuration (3 backbones × 3 stream lengths). Against the strongest baseline OPCM, gains range from +0.1 (ViT-B/16, 20 tasks: 70.4 vs. 70.3) to +5.1 (ViT-L/14, 20 tasks: 81.1 vs. 76.0), with typical improvements of 2–4 points. C. Ties-Merging is highly unstable, showing large variance (e.g., 49.0±10.2 ACC on ViT-B/32, 8 tasks) and is consistently the weakest merging baseline. SWA and C. Task Arithmetic trail ODE-M by 8–15 ACC points across all settings. On BWT, ODE-M achieves the best retention on shorter streams (e.g., −4.2 vs. OPCM's −6.3 on ViT-B/32, 8 tasks; −4.0 vs. −2.6 on ViT-L/14, 8 tasks) but incurs slightly more forgetting on the longest streams (e.g., −9.4 vs. −7.8 on ViT-B/32, 20 tasks), reflecting a deliberate accuracy–stability trade-off that the utility-aware time schedule can tune.

## Relation to Prior Work

This paper builds directly on the continual model merging (CMM) line of work initiated by OPCM (Tang et al., 2025b) and dual-projection methods (Yang et al., 2025), which treat each sequential merge as a fixed algebraic or projection-based endpoint update. It departs from this endpoint-only view by importing the mode-connectivity and loss-barrier literature (Entezari et al., 2021; Ren et al., 2025) into the continual setting, reframing each merge as a continuous ODE trajectory in parameter space whose shape and operating point are explicitly controlled. The rectified velocity field—decomposing motion into gradient-aligned and tangent components and damping only the loss-increasing part—is a new mechanism not present in prior CMM or one-shot merging methods, and the utility-aware time schedule generalizes the equal-utility 1/k diminishing rule to non-uniform task importance.

## Why It Matters / Open Questions

ODE-M provides the first explicit, per-merge control handle over the stability-plasticity trade-off in continual merging, which prior fixed-rule methods can only tune coarsely through hyperparameters. The utility-weighted evaluation framework is a practical step toward more realistic deployment objectives where tasks carry unequal importance, and the consistent (if moderate) gains across three CLIP ViT backbones and three stream lengths suggest the trajectory perspective is broadly applicable. Key limitations include the requirement for a calibration set and first-order gradients during merging (ruling out fully black-box settings), a per-merge overhead of ~124–247 seconds, and evaluation restricted to vision classification streams; extending the approach to LLMs, multimodal models, and proxy/partial calibration regimes remains open.

## Problem

Conformal prediction requires a labeled calibration set to construct prediction sets with distribution-free coverage guarantees, but in costly-label regimes (medical diagnostics, expert annotation) the calibration size is typically chosen arbitrarily. This creates an unresolved tradeoff: too few labels yield large, uninformative prediction sets, while too many incur unnecessary labeling cost. No prior work provides a principled, provably optimal stopping rule that balances labeling cost against prediction-set efficiency while preserving the original conformal guarantee.

## Input / Output

The method consumes a sequential stream of n unlabeled feature vectors and queries labels one at a time, using a nonconformity score function s(x,y) (e.g., 1 − p̂(y|x) or log-loss) to rank candidate labels. It outputs a prediction set T(x) ⊆ Y with high-probability marginal coverage at level 1−α, along with a data-dependent stopping time m̂ that determines the final calibration size. The total cost is defined as m + (n−m)·E[|T(X)|/K], normalizing set size by the number of classes K so that one label query and one unit of prediction-set inefficiency are on the same scale.

## Method

The paper introduces an anytime-valid split conformal procedure that replaces the standard Hoeffding bonus with time-uniform finite-LIL confidence sequences, ensuring coverage validity under arbitrary data-dependent stopping. The key reparameterization expresses prediction sets via a size parameter β (the fraction of labels excluded), making expected set size exactly K(1−β) and reducing the cost to a function of the miscoverage curve L(β). Under a monotone density-ratio assumption on the score distributions, the oracle cost sequence is proven discrete convex, enabling a stopping rule that computes a data-dependent lower confidence bound on the first-order cost increment and halts when this bound turns nonnegative. The resulting rule achieves Õ(n^{2/3}) regret relative to the best fixed calibration size in hindsight, with the regret ratio vanishing as n→∞. The framework also yields a formal reduction from PAC labeling (Candès et al., 2025) to binary-class conformal prediction, under which the same stopping rule minimizes total expert-query cost.

## Results

On ImageNet with split conformal prediction (α=0.1, δ=0.05), the proposed stopping rule achieves a 40.6% ± 2.3% (95% CI) reduction in total cost (labeling cost + prediction-set inefficiency) relative to the standard fixed calibration size m=1000, while closely matching the oracle optimum m*=4230. On the Media Bias PAC labeling dataset (α=0.1, δ=0.05), the stopping rule reduces expert labeling cost by 6.4% ± 0.5% (95% CI) compared to the fixed m=500 baseline from Candès et al. (2025), again tracking the oracle m*=1020. Theoretically, the regret is Õ(n^{2/3}) with R_n/C(m*)→0, and the anytime-valid coverage guarantee holds under arbitrary data-dependent stopping.

## Baselines & Comparisons

The paper compares against two primary baselines: (1) the fixed calibration size m=1000 commonly used in ImageNet conformal prediction (Angelopoulos & Bates, 2021), and (2) the fixed calibration size m=500 from the original PAC labeling method (Candès et al., 2025). On ImageNet, the stopping rule decisively outperforms the fixed m=1000 baseline, reducing total cost by 40.6% ± 2.3% while maintaining valid coverage; the fixed baseline stops far too early relative to the oracle m*=4230. On Media Bias PAC labeling, the stopping rule reduces expert labeling cost by 6.4% ± 0.5% over the fixed m=500 baseline, with the oracle at m*=1020. In both settings, the stopping rule closely tracks the oracle calibration size chosen in hindsight, with the ECDF of m̂−m* concentrated near zero, whereas the fixed baselines never reach the oracle size. An additional greedy stopping baseline (stopping after 5 consecutive empirical cost increases) is shown in the appendix to be inconsistent across datasets—sometimes performing worse than the fixed baseline—while the proposed rule more reliably achieves lower total cost.

## Relation to Prior Work

This paper builds on split conformal prediction (Vovk et al., 2005; Romano et al., 2019) and time-uniform confidence sequences (Howard et al., 2021; Howard & Ramdas, 2022), combining them into an optimal stopping framework for choosing the calibration set size. It departs from length-optimization work (Kiyani et al., 2024), which improves prediction-set construction for a fixed calibration set but ignores the cost of acquiring labels, and from active anytime-valid risk control (Xu et al., 2024), which maintains guarantees over a data stream without addressing the upfront calibration budget. The paper also establishes a formal reduction showing that PAC labeling (Candès et al., 2025) is a special case of binary-class conformal prediction, thereby unifying two previously separate literatures under a single cost-minimization objective.

## Why It Matters / Open Questions

In practice, conformal prediction calibration sizes are often chosen arbitrarily (e.g., m=1000 for ImageNet), and this paper provides the first principled, automated stopping rule with a no-regret guarantee, yielding a 40.6% cost reduction over the standard baseline. The PAC labeling reduction is practically significant because it means the same stopping rule can minimize expert-annotation budgets in LLM-assisted labeling pipelines. Key limitations include the monotone density-ratio assumption (Assumption 4.4), the need for finite-sample stabilization (κ/√n term), and the fact that the rule does not use covariates to decide *which* examples to label—only *how many*. Open directions include covariate-dependent label acquisition, extending to conditional coverage guarantees, and handling non-i.i.d. data streams.

## Problem

Existing 3D dense captioning methods restrict contextual information to object pairs or spatially nearest neighbors, failing to capture positional relationships that span the entire global scene. Additionally, they face a conflicting objective: tight local features improve localization, while global contextual features improve caption generation, yet both are forced into a single object representation. This paper asks whether an architecture can aggregate globally relevant context without degrading localization performance.
![Teaser figure](../imgs/ECCV20240479/cropped_page1_idx0.webp)

## Input / Output

The method takes a raw 3D point cloud (N points with XYZ coordinates and F-dimensional features) as input and produces 3D bounding boxes (center offsets and sizes regressed from 256 instance queries) paired with natural language captions for each detected object. The model internally maintains two parallel query sets—256 instance queries for object detection and 512 context queries sampled via farthest point sampling for non-object structural information—and the caption head receives a concatenated token of the instance feature, object-aware context, and context-aware object. Inference uses beam search (beam size 5) with a GPT-2-based transformer decoder for caption generation.

## Method

BiCA introduces a transformer encoder-decoder that parallelly decodes two distinct query sets: instance queries (generated by voting-shifted coordinates with a small-radius set-abstraction) for localization, and context queries (generated by FPS on encoded points with a larger-radius set-abstraction) for capturing non-object geometric structure. The key mechanism is a two-stage bi-directional contextual attention: O4C computes per-object context by attention-weighted summarization of all global context queries, and C4O adjusts object representations by attention-weighted aggregation of instance features relevant to those contexts. This disentangles localization (using only instance queries) from caption generation (using the concatenated instance, object-aware context, and context-aware object features), resolving the conflicting local-vs-global objective. Training proceeds in three stages: pretraining the detector on ScanNet (1080 epochs), joint cross-entropy training on ScanRefer and Nr3D (720 epochs), and Self-Critical Sequence Training with CIDEr reward (180 epochs).

## Results

On ScanRefer (SCST, IoU=0.50, w/o 2D data), BiCA achieves CIDEr 80.14, BLEU-4 40.16, METEOR 27.76, and ROUGE-L 56.10, outperforming the strongest baseline Vote2Cap-DETR++ (CIDEr 78.16) by ~2 CIDEr points. On Nr3D (SCST, IoU=0.5), BiCA reaches CIDEr 49.81, BLEU-4 28.83, METEOR 25.85, and ROUGE-L 56.46, surpassing Vote2Cap-DETR++ (CIDEr 47.62) by over 2 CIDEr points. BiCA also improves 3D object detection, achieving mAP 57.58 and AR 72.68 on ScanRefer versus 55.48/70.89 for Vote2Cap-DETR++, confirming that the disentangled query design benefits both localization and captioning simultaneously.

## Baselines & Comparisons

BiCA outperforms all 12 compared baselines across every metric on both ScanRefer and Nr3D. The closest competitor is Vote2Cap-DETR++ [10], which also decouples localization and captioning queries; BiCA improves CIDEr by +1.9 (ScanRefer IoU=0.5, SCST) and +2.2 (Nr3D IoU=0.5, SCST), with consistent gains of 0.4–1.2 points on BLEU-4, METEOR, and ROUGE-L. Against Vote2Cap-DETR [9], the direct architectural predecessor, BiCA gains +5.7 CIDEr on ScanRefer (SCST, IoU=0.5) and +4.3 CIDEr on Nr3D. Earlier methods such as 3DJCG [4] (CIDEr 49.48) and 3D-VLP [20] (CIDEr 54.94) on ScanRefer are surpassed by 27 and 21 CIDEr points respectively, reflecting the advantage of the bi-directional attention over pairwise or KNN-based context aggregation. Notably, BiCA also improves detection mAP from 55.48 (Vote2Cap-DETR++) to 57.58, demonstrating that the context-query design does not compromise localization but rather enhances it by freeing instance queries from the burden of encoding global scene context.

## Relation to Prior Work

BiCA extends the Vote2Cap-DETR [9] end-to-end transformer pipeline for 3D dense captioning by introducing a parallel Context Query stream alongside the existing Instance Query stream, and a two-stage bi-directional attention (O4C/C4O) that links them. It departs from Vote2Cap-DETR++ [10], which decoupled localization and captioning queries but kept them as projections of object-centric features, by generating context queries directly from the encoded scene geometry via farthest-point sampling, thereby capturing non-object structural information. The paper also positions against earlier relational approaches (Scan2Cap, D3Net, SpaCap3D, 3DJCG) that model context through object-pair interactions or nearest-neighbor aggregation, arguing these are too spatially local to support global positional descriptions.

## Why It Matters / Open Questions

The key contribution is a clean architectural resolution of the long-standing tension in 3D dense captioning between tight localization (requiring local features) and global contextual description (requiring scene-wide features), achieved by disentangling the two into separate query streams with bi-directional attention. This simultaneously improves both detection (mAP 55.48→57.58) and captioning metrics, validating the disentangling hypothesis. Limitations include evaluation restricted to ScanNet-derived datasets (ScanRefer, Nr3D), leaving generalization to outdoor or larger-scale 3D scenes untested; the added architectural complexity (two query generators, two attention stages) also raises questions about scalability. Open questions include whether the bi-directional attention pattern transfers to other 3D modalities (meshes, NeRFs) or to tasks beyond dense captioning such as 3D visual grounding.

## Problem

CLIP-style zero-shot classification relies on hand-designed domain-specific prompt templates (e.g., 'a centered satellite image of {}') to align class descriptions with downstream data distributions, but this process is labor-intensive, sub-optimal, and may not be truly zero-shot. Existing automatic prompt learning methods (CoOp, PLOT) require labeled data for optimization, violating the zero-shot setting. The paper asks whether domain-specific prompts can be learned entirely from unlabeled in-domain images.
![Teaser figure](../imgs/ECCV20241990/cropped_page1_idx0.webp)

## Input / Output

The method consumes only the vision encoder embeddings of unlabeled in-domain images (not raw pixels) plus the set of class names as text; no per-image labels are required. It produces soft prompts as continuous token embeddings of fixed length (5 or 10 tokens) in the language encoder's embedding space, which are concatenated with class names to form class descriptions. At inference, multiple learned prompts (MAP estimations from different random initializations) are ensembled, and a test image is classified by nearest class description in the shared representation space.

## Method

uCAP models a generative process in which a latent domain-specific context w, together with class names Y, produces the image dataset X. The likelihood is an energy-based distribution where the scalar energy E(x, Y, w) = min_m D[x, f_φ(w ⊕ y_m)] measures the minimum cosine distance between an image embedding and any prompt-augmented class description, encoding the intuition that a generated image should be close to at least one class description. A Gaussian prior over token embeddings (with mean and covariance computed from the vocabulary) keeps the soft prompt within the natural embedding range. Posterior inference is performed via MAP estimation: the gradient of the intractable log-partition term is estimated by sampling from p(x|Y,w) using Stochastic Gradient Langevin Dynamics (200 iterations, ε=1e-6), yielding a fully unsupervised gradient estimator. Multiple MAP solutions from different random initializations are ensembled for the final prediction, and a small auxiliary pseudo-label cross-entropy loss (coefficient 0.1) stabilizes training.

## Results

Across 7 CLIP-family models and 6 datasets, uCAP(10) consistently outperforms hand-tuned prompts (HTPs) by up to 5% on SUN397 (e.g., 69.8% vs 64.1% with CLIP ViT-B/16) and up to 2% on ImageNet (77.2% vs 76.2% with CLIP ViT-L/14@336px). On CIFAR-10, uCAP(10) reaches 96.0% with CLIP ViT-L/14@336px versus 94.9% for HTPs. In the transfer-learning comparison (Table 2), uCAP surpasses CoOp (which uses 16,000 labeled ImageNet images) by ~1.5% on average across ImageNetV2, ImageNet-Sketch, ImageNet-A, and ImageNet-R, while requiring no labeled source data.

## Baselines & Comparisons

Against CLIP's hand-tuned prompts (Radford et al., 2021), uCAP(10) wins on nearly all model–dataset combinations, with the largest gains on SUN397 (up to +5.7% with CLIP ViT-B/16: 69.8% vs 64.1%) and Caltech101 (up to +1.9%). Against the Pseudo Labels baseline (Huang et al., 2022), uCAP is superior in every setting, e.g., 61.9% vs 57.6% on ImageNet with CLIP RN50, confirming that directly leveraging the energy-based inductive bias outperforms generic unsupervised domain adaptation. In the transfer-learning comparison (Table 2), uCAP outperforms CoOp (Zhou et al., 2022) by ~1.5% on average across four ImageNet variants (e.g., 61.80% vs 55.61% on ImageNet-R with CLIP RN50) despite using no labeled source data, while CoOp relies on 16,000 ImageNet labels. uCAP also beats PLOT (Chen et al., 2023) on ImageNet-Sketch, ImageNet-A, and ImageNet-R, though both CoOp and PLOT retain a slight edge on ImageNetV2 where the distribution shift from ImageNet is minimal. Overall, uCAP is the only method that is truly zero-shot (no labels from any source) while matching or exceeding methods that use 16,000 labeled examples.

## Relation to Prior Work

This paper builds directly on CLIP-style contrastive language-image pretraining (Radford et al.) and the soft prompt learning paradigm established by CoOp (Zhou et al., 2022) and PLOT (Chen et al., 2023), where domain-specific text contexts are learned in the continuous token embedding space. The key departure is from all prior prompt learning methods (CoOp, PLOT, CoCoOp) that require labeled data for optimization: uCAP frames prompt inference as a posterior estimation problem under a generative model with an energy-based likelihood derived from the VLM's learned representation alignment, requiring only unlabeled in-domain images. It also distinguishes itself from classic unsupervised domain adaptation (entropy minimization, pseudo labels) by explicitly leveraging the inductive bias of the frozen encoders rather than fine-tuning the vision backbone, which would break the cross-modal alignment.

## Why It Matters / Open Questions

uCAP provides a practical, truly zero-shot alternative to the labor-intensive and often suboptimal practice of hand-tuning prompt templates for each downstream dataset, and it outperforms both hand-tuned prompts and supervised prompt learning methods (CoOp, PLOT) that rely on 16,000 labeled examples. The energy-based formulation is a clean conceptual contribution that explicitly connects prompt learning to the inductive bias of VLMs, and the observed transferability of learned prompts across tasks (e.g., ImageNet → CIFAR-10, OxfordPets) suggests the learned contexts capture something generalizable about domain structure. Open questions include whether the energy-based approach extends to instance-level prompts (the authors' preliminary experiments suggest limited gains), whether it generalizes to other modalities (video, audio) beyond the brief UCF101 experiment, and whether the lack of semantic interpretability in the learned soft prompts limits their practical utility.

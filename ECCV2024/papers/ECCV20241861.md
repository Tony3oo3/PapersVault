## Problem

Finetuning Latent Diffusion Models on a target visual style (e.g., stickers) creates a fundamental trade-off: style alignment improves while prompt alignment and scene diversity degrade, and vice versa. No existing finetuning recipe simultaneously optimizes for prompt faithfulness, visual diversity, high visual quality, and adherence to a distinctive style without adding extra modules or inference latency.
![Teaser figure](../imgs/ECCV20241861/cropped_page1_idx0.webp)

## Input / Output

The model takes a short text prompt (e.g., "love") as input, which is optionally expanded by a 1.4B instruction-tuned LLaMA model into a more descriptive phrase (e.g., "a wide-eyed puppy holding a heart") to increase scene diversity. The output is a 256×256 RGBA sticker image with a transparent background, produced by a modified VAE decoder whose final convolution layer outputs 4 channels instead of 3, with the alpha-channel weights initialized as the mean of the RGB channel weights.

## Method

The core contribution is Style Tailoring, a training method that decouples the standard LDM denoising objective into two timestep-conditioned losses: a content loss applied at later timesteps (t ∈ [T', T], closer to pure noise) using HITL alignment data to enforce prompt faithfulness, and a style loss applied at earlier timesteps (t ∈ [0, T'], closer to the clean latent) using expert-curated style data to enforce visual aesthetics. This exploits the observation that coarse semantic content is formed during early denoising steps while fine-grained stylistic details emerge during later steps. The full pipeline is a three-stage finetuning recipe on Emu-256: (1) domain alignment on 21M weakly-supervised sticker images to elicit diversity, (2) HITL alignment on human-filtered generated samples for prompt faithfulness, and (3) Style Tailoring jointly optimizing both distributions in a single 5k-step training run with T'=900. A transparency decoder (frozen encoder, finetuned decoder with an extra alpha channel) and a LLaMA-based Prompt Enhancer complete the system without adding inference latency.

## Results

Style Tailoring (R7) achieves the best overall trade-off across all four evaluation axes: FDD 290.95 (style alignment), LPIPS 0.541 (scene diversity), 74.3% (visual quality), and 88.3% (prompt alignment). Compared to the Emu-256+PE baseline, this represents a 14% improvement in visual quality (65.2%→74.3%), a 16.2% improvement in prompt alignment (76%→88.3%), and a 15.3% improvement in scene diversity (LPIPS 0.469→0.541). The method also outperforms the best sequential finetuning recipe (HITL→Style, R6) by +3.5% prompt alignment, +16.2% scene diversity, and +3.8% style alignment, while maintaining comparable visual quality (74.3% vs 75.1%).

## Baselines & Comparisons

Against SDv1-512+PE (R0), Style Tailoring dominates on every metric: FDD 290.95 vs 776.0, LPIPS 0.541 vs 0.483, Quality 74.3% vs 44.8%, and Prompt Alignment 88.3% vs 30.9%, confirming that a purpose-built sticker pipeline far outperforms generic prompt engineering on Stable Diffusion. Against the primary baseline Emu-256+PE (R1), Style Tailoring wins on visual quality (+9.1 pp), prompt alignment (+12.3 pp), and scene diversity (LPIPS +0.072), but loses on style alignment (FDD 290.95 vs 168.30); the paper notes this is expected because the style reference test set was itself curated from Emu-256 generations, giving the baseline an inherent advantage on that single axis. The key internal comparison is against the best sequential recipe (HITL→Style, R6): Style Tailoring improves prompt alignment by 3.5 pp (88.3% vs 85.3%), scene diversity by 16.2% (LPIPS 0.541 vs 0.466), and style alignment by 3.8% (FDD 290.95 vs 301.10), while sacrificing only 0.8 pp in visual quality (74.3% vs 75.1%), demonstrating that joint content-style optimization avoids the trade-off inherent in sequential finetuning.

## Relation to Prior Work

This paper builds directly on Emu (Dai et al., 2023) as its base text-to-image model and extends the broader line of work on finetuning LDMs for specific visual styles (Textual Inversion, LoRA, StyleDrop). It departs from prior style finetuning by explicitly identifying and addressing the trade-off between prompt alignment and style alignment that sequential finetuning introduces, proposing Style Tailoring—a timestep-conditioned data routing strategy that jointly optimizes content and style distributions in a single training stage. The multi-stage recipe (domain alignment → HITL → EITL) also draws on human preference alignment literature but uses a simpler filtering-on-generated-data approach rather than reward models.

## Why It Matters / Open Questions

The Style Tailoring method offers a practical, zero-latency recipe for anyone finetuning diffusion models into a specific visual domain, and its generalization to multiple styles (2D flat vs. 3D volumetric) suggests broad applicability beyond stickers. The finding that the finetuning order (HITL before Style) materially affects outcomes provides actionable guidance for practitioners. Open questions include whether the timestep-based content/style decomposition holds for more complex multi-object compositions, whether the approach scales to higher-resolution models, and whether the reliance on expert-curated style data (only ~4K images) limits robustness to style drift over time.

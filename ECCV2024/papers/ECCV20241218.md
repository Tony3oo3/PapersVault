## Problem

Existing text-guided object inpainting methods rely on a single U-Net to simultaneously align the text prompt with the visual object across all denoising timesteps and control object generation in the intricate diffusion sampling space. This dual burden leads to misalignment between the generated object and the prompt, as well as poor controllability over object shape and fidelity, particularly when the caption describes the holistic image rather than the local masked region.
![Teaser figure](../imgs/ECCV20241218/cropped_page1_idx0.webp)

## Input / Output

The method takes a 512×512 RGB image with the target object removed, a text prompt (typically an object label or short description), and a binary mask (either a segmentation mask or a bounding box mask) delineating the inpainting region. It outputs a complete image with the generated object seamlessly blended into the surrounding context. The semantic inpainter runs only once per image, and its output features are reused across all denoising steps, adding only ~0.24 s of overhead over the base Stable Diffusion Inpainting pipeline.

## Method

CAT-Diffusion decomposes single-stage object inpainting into two cascaded stages. First, a 24-layer Transformer-based semantic inpainter (SemInpainter) predicts CLIP-space semantic features of the target object conditioned on the unmasked visual context and text prompt, trained via knowledge distillation from CLIP using a masked feature prediction objective. Second, an object inpainting diffusion model (Stable Diffusion Inpainting) is augmented with a reference adapter layer (RefAdapter), a multi-head cross-attention module alternately inserted between self-attention and cross-attention blocks in the U-Net, which consumes the inpainted semantic features as visual prompts to steer generation. The key insight is that pre-inpainting semantic features in a noise-free multi-modal space provides text-visual alignment independent of denoising timesteps, offloading the alignment burden from the diffusion model and enabling more controllable, high-fidelity object generation.

## Results

On OpenImages-V6 (the training dataset), CAT-Diffusion achieves the best FID (3.99) and Local FID (6.32) with segmentation masks, and FID 5.02 / Local FID 7.76 with bounding box masks, outperforming the strongest baseline SmartBrush (FID 4.70 / Local FID 7.82) by a clear margin. On the unseen MSCOCO test set, CAT-Diffusion attains FID 6.84 and Local FID 10.49 with bounding box masks, representing a 42.1% and 20.7% relative improvement over Stable Diffusion Inpainting and SmartBrush respectively on Local FID. CLIP scores remain essentially tied across all methods (~0.263–0.266), indicating that the gains are primarily in visual fidelity and coherence rather than text-image alignment. In a user study on 1K images, CAT-Diffusion scores 3.5/5 for text-object alignment and 3.6/5 for visual coherence, substantially ahead of the next-best method (SD-Inpaint at 2.2 and 2.6).

## Baselines & Comparisons

CAT-Diffusion consistently outperforms all five baselines on FID and Local FID across both OpenImages-V6 and MSCOCO, with the largest gaps over blending-based methods (Blended Diffusion, Blended Latent Diffusion, Stable Diffusion) that ignore surrounding context. Against the strongest inpainting-specific baseline SmartBrush [45], CAT-Diffusion improves Local FID from 7.82 to 6.32 (seg mask) and from 9.71 to 7.76 (bbox mask) on OpenImages-V6, and from 13.22 to 10.49 (bbox mask) on MSCOCO. CLIP scores are essentially tied across all methods (range 0.249–0.266), confirming that the semantic alignment is already well-handled by existing diffusion models and that CAT-Diffusion's advantage lies in visual fidelity and structural coherence. The user study further confirms this: CAT-Diffusion leads by a wide margin (3.5 vs. 2.2 for text-object alignment; 3.6 vs. 2.6 for visual coherence) over SD-Inpaint, the next-best method evaluated. Notably, CAT-Diffusion generalizes to MSCOCO without any training on that dataset, while SmartBrush was also not trained on MSCOCO, yet CAT-Diffusion still achieves superior results.

## Relation to Prior Work

This paper builds on the Latent Diffusion Model (Stable Diffusion) framework and CLIP's multi-modal feature space, but departs from the dominant single-stage paradigm of text-guided object inpainting (as in SmartBrush, GLIDE, and Blended Diffusion) where a single U-Net must simultaneously handle text-visual alignment and object generation across all denoising timesteps. The key architectural departure is decomposing this into a cascaded pipeline: a Transformer-based semantic inpainter first predicts object features in CLIP space via knowledge distillation, and a reference adapter layer then injects these features into the diffusion U-Net as visual prompts. This positions the work as a hybrid Transformer-diffusion architecture rather than a pure diffusion refinement, drawing on masked feature prediction objectives from self-supervised learning to supervise the semantic inpainter.

## Why It Matters / Open Questions

The cascaded decomposition offers a principled way to offload the text-visual alignment burden from the diffusion model to a dedicated component operating in a noise-free multi-modal space, which could generalize to other controllable generation tasks beyond inpainting. However, the CLIP score improvements are marginal (0.263 vs. 0.266 for SmartBrush), suggesting the semantic alignment gain is limited despite the architectural complexity, and the approach is validated only at 512×512 resolution on two datasets. Open questions include whether the CLIP feature space is optimal for this role, how the method scales to higher resolutions or video inpainting, and whether the reference adapter layer can be replaced by lighter-weight conditioning mechanisms.

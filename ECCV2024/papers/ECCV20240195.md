## Problem

Camera-based BEV 3D object detection still lags behind LiDAR-based methods due to insufficient geometric information. Existing cross-modal distillation approaches attempt to close this gap but suffer from severe feature distribution discrepancies between LiDAR-based teachers and camera-based students, necessitating cumbersome adaptation strategies and pre-trained teacher models.
![Teaser figure](../imgs/ECCV20240195/cropped_page1_idx1.webp)

## Input / Output

The method consumes multi-view camera images (current frame plus one past frame at 0.5 s interval) at resolutions of 256×704 or 512×1408, and additionally uses LiDAR point clouds during training to generate hard depth and foreground-segmentation labels. It outputs 3D bounding boxes with class, translation, scale, orientation, velocity, and attribute predictions, evaluated via nuScenes mAP and NDS. The BEV feature grid is 128×128 by default, expandable to 256×256 for finer distillation granularity.

## Method

FSD-BEV introduces a self-distillation framework where a teacher branch and a student branch share the same image backbone features, eliminating the cross-modal distribution gap. The teacher branch constructs BEV features using LiDAR-derived hard labels (depth maps and foreground segmentation) combined with the student's soft labels to fill sparse regions, while the student branch uses only its own predictions; both are filtered to foreground-only via SA-BEVPool. The two BEV feature sets are concatenated along the batch dimension and jointly processed through the BEV encoder before a normalized L2 distillation loss aligns them, with both branches simultaneously supervised by detection losses to prevent collapse. Two Point Cloud Intensification strategies—Frame Combination (merging static-object points from adjacent frames) and Pseudo Point Assignment (projecting GT 3D boxes to assign a single pseudo point for objects with no LiDAR returns)—densify the hard labels. A Multi-Scale Foreground Enhancement module predicts an elliptical Gaussian heatmap at 1/4 resolution to gate and fuse F⁴ and F⁸ features into the 1/16-scale input, injecting finer foreground detail into the view transformation.

## Results

On the nuScenes val set with ResNet50 (256×704, 2 frames), FSD-BEV achieves 0.403 mAP and 0.526 NDS, outperforming SA-BEV (0.387/0.512) by 1.6% mAP and 1.4% NDS. With the larger BEV feature size (†), FSD-BEV reaches 0.412 mAP and 0.538 NDS, exceeding SA-BEV by 2.5% and 2.6% respectively. On the nuScenes test set with V2-99 backbone (640×1600, 2 frames), FSD-BEV achieves 0.543 mAP and 0.633 NDS, surpassing SOLOFusion (17 frames) by 0.3% mAP and 1.4% NDS, and SA-BEV (2 frames) by 1.0% mAP and 0.9% NDS.

## Baselines & Comparisons

FSD-BEV consistently outperforms all camera-only baselines using the same or fewer frames. With ResNet50, it surpasses SA-BEV (the strongest 2-frame baseline) by 1.6% mAP and 1.4% NDS, and with the larger BEV grid (†) the gap widens to 2.5% mAP and 2.6% NDS. With ResNet101, FSD-BEV* (0.500 mAP / 0.596 NDS) exceeds StreamPETR (0.504 mAP / 0.592 NDS) in NDS despite using only 2 frames versus StreamPETR's 8 frames, and beats TiG-BEV and STS by 4–7% mAP. On the test set, FSD-BEV (0.543/0.633) leads SOLOFusion (0.540/0.619, 17 frames) by 0.3% mAP and 1.4% NDS, and SA-BEV (0.533/0.624, 2 frames) by 1.0% mAP and 0.9% NDS. In the cross-modal distillation comparison (Table 7), FSD-BEV's distillation gain of +7.6% mAP / +5.4% NDS (ResNet101) far exceeds DistillBEV's +3.8% / +1.2%, TiG-BEV's +2.4% / +2.3%, and X³KD's +3.9% / +2.2%, demonstrating that the self-distillation framework transfers knowledge more effectively than cross-modal approaches with pre-trained LiDAR teachers.

## Relation to Prior Work

FSD-BEV builds directly on the depth-based BEV detection architecture of BEVDepth and the foreground-aware BEV pooling of SA-BEV, but departs fundamentally from the cross-modal distillation paradigm (BEVDistill, UniDistill, DistillBEV, TiG-BEV) that requires a separate pre-trained LiDAR or multi-modal teacher. The key conceptual shift is replacing cross-modal knowledge transfer with self-distillation: the teacher and student branches share the same image backbone features, so the teacher BEV is constructed by injecting LiDAR-derived hard labels (depth and foreground segmentation) into the same feature space the student already operates in, eliminating the distribution gap that has motivated increasingly complex distillation strategies in prior work. Two auxiliary contributions—Point Cloud Intensification (frame combination and pseudo point assignment) and Multi-Scale Foreground Enhancement via elliptical Gaussian heatmaps—address the sparsity of LiDAR labels and the loss of fine-grained foreground detail, respectively.

## Why It Matters / Open Questions

The paper demonstrates that a simple normalized L2 distillation loss, applied only to foreground regions within a single model, can outperform elaborate cross-modal distillation pipelines by a wide margin (7.6% mAP with ResNet101 vs. 2–4% for prior methods), suggesting that distribution alignment, not loss complexity, is the primary bottleneck in BEV feature distillation. The joint-progress property—where the teacher improves as the student improves—offers a practical advantage over fixed-teacher setups, though the method still requires LiDAR annotations during training, limiting its applicability to truly LiDAR-free deployment. Open questions include whether the self-distillation principle extends to attention-based BEV paradigms (BEVFormer, PETR), whether the approach generalizes beyond nuScenes, and whether the reliance on LiDAR for hard labels can be replaced by pseudo-labels in a fully self-supervised loop.

## Problem

Existing semi-supervised VOS methods model feature extraction, matching, memory management, and multi-object aggregation as discrete sequential stages or partially combined substructures, preventing the framework from being optimized as a unified whole. This staged design limits model capacity and leads to suboptimal performance, particularly on complex long-term and multi-object videos.
![Teaser figure](../imgs/ECCV20241536/cropped_page1_idx0.webp)

## Input / Output

The method takes a current RGB frame, a reference frame with its binary mask, and a bank of stored memory tokens (intermediate K/V matrices from prior frames) as input. The reference mask is encoded into mask embeddings via a single convolutional layer, and both frames are converted into non-overlapping patch embeddings at 1/16 resolution. The output is a set of multi-object segmentation masks at full resolution, decoded from the final transformer layer through a lightweight FPN that upsamples from 1/16 to 1/4 scale.

## Method

OneVOS unifies all core VOS modules into a single Vision Transformer (ConvViT-base) by representing frames, masks, and memory as transformer tokens, so that feature extraction, inter-frame matching, and memory management are all accomplished through the attention mechanism in one differentiable pipeline. A Unidirectional Hybrid Attention performs a double decoupling: it removes the current-frame-to-reference-frame attention path (preventing semantic errors in stored tokens) and the memory-to-reference attention path (avoiding mask-embedding overlap and preserving temporal specificity), while the current frame attends to memory, reference, and itself. A Dynamic Token Selector, trained solely under segmentation loss with Gumbel-Softmax, adaptively selects a subset of reference tokens per layer for cross-attention and memory storage, revealing that OneVOS learns a cross-layer segmentation mode that alternates between feature extraction and matching across layers. This insight drives an efficient variant with layer-wise memory capacities proportional to learned selection ratios and top-k token retention, improving both speed and accuracy.

## Results

OneVOS achieves state-of-the-art J&F scores across all 7 evaluated datasets. On standard benchmarks, OneVOS-D reaches 93.1% J&F on DAVIS 16 val and 88.8% on DAVIS 17 val, while OneVOS* attains 85.3% on DAVIS 17 test and 86.3% on YouTube-VOS 19 val. On the more challenging long-term and complex-scene datasets, OneVOS-D scores 70.1% J&F on LVOS val (surpassing the previous best R50-DeAOT-L by 4.2%) and OneVOS* scores 67.2% on MOSE (surpassing DeAOT by 7.0%). OneVOS-D also improves inference speed to 16.0 FPS on DAVIS 17 val compared to 12.0 FPS for the full OneVOS.

## Baselines & Comparisons

OneVOS outperforms all 12 compared baselines across every dataset. The most dramatic gains appear on challenging benchmarks: on MOSE, OneVOS (66.4% J&F) surpasses DeAOT [68] (59.4%) by 7.0 points and XMem [7] (57.6%) by 8.8 points; on LVOS val, OneVOS-D (70.1%) beats R50-DeAOT-L [68] (65.9%) by 4.2 points and Swin-AOT-L [66] (65.6%) by 4.5 points. On standard DAVIS 17 val, OneVOS-D (88.8%) edges out SimVOS [59] (88.0%) and XMem [7] (87.7%) by 0.8 and 1.1 points respectively, while OneVOS* leads on DAVIS 17 test (85.3% vs. 82.8% for Swin-DeAOT-L [68]) and YouTube-VOS (86.3% vs. 86.1% for Swin-DeAOT-L [68]). Older discrete-pipeline methods such as CFBI [65], HMMN [51], and STCN [9] trail by 5–10 J&F points on DAVIS 17 val, confirming the advantage of the unified Transformer formulation. The multi-object AOT family [66] and its successor DeAOT [68] remain the closest competitors on standard datasets but are consistently outperformed, particularly in long-video and complex-scene settings where memory and multi-object interaction matter most.

## Relation to Prior Work

OneVOS departs from the dominant discrete-pipeline paradigm in memory-based VOS (XMem, HMMN, SSTVOS) where feature extraction, matching, memory management, and multi-object aggregation are separate sequential stages. It also moves beyond partial unifications: AOT/DeAOT jointly model multiple objects but retain a dedicated matching module, while SimVOS merges feature extraction and matching but discards memory entirely. OneVOS repurposes the standard Transformer attention mechanism to simultaneously perform all four core operations, drawing on ConvViT for patch embedding and DynamicViT-style token selection for efficiency, but introduces the Unidirectional Hybrid Attention as a novel decoupling of standard attention to resolve semantic ambiguity in stored memory tokens.

## Why It Matters / Open Questions

By demonstrating that a single end-to-end differentiable Transformer can match or exceed sophisticated multi-stage pipelines across 7 datasets, OneVOS offers a cleaner, more globally optimizable paradigm for VOS that may simplify future architectural design. The DTS analysis revealing a non-sequential, cross-layer alternation between feature extraction and matching challenges the assumption that these operations must be spatially or temporally separated, potentially informing design choices in other video understanding tasks. Open questions include whether the unified paradigm extends naturally to interactive or online VOS settings, and whether the cross-layer segmentation insight generalizes to other Transformer-based video models beyond this specific architecture.

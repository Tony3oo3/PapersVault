## Problem

Existing point-supervised panoptic segmentation methods (PSPS, Point2Mask) estimate dense pseudo labels by assigning unlabeled pixels to instances using rule-based pixel-to-instance distances computed via the Dijkstra algorithm on feature-derived graphs. These distances cannot be optimized end-to-end by point labels and are sensitive to errors in the underlying features (semantic maps, edges, contours), resulting in inaccurate pseudo labels that limit segmentation quality.
![Teaser figure](../imgs/ECCV20240410/cropped_page1_idx1.webp)

## Input / Output

During training, the method takes an RGB image together with a single-point label per instance (providing the instance class and a one-pixel instance ID mask) and produces dense per-pixel pseudo labels (class + instance ID for every pixel) used to supervise a Panoptic Segformer head. At inference, the distance branch and fusion module are entirely discarded, so the model consumes only the RGB image and outputs standard panoptic segmentation masks (per-pixel semantic class and instance ID for both thing and stuff categories) with no additional memory or computation cost over the fully supervised baseline.

## Method

The EPLD framework represents each instance as an anchor query aggregated from multi-scale fusion features at labeled pixels, then predicts a learnable pixel-to-instance distance map via cross-attention between these queries and multi-scale pixel features in a distance branch of L=6 decoder layers. Anchor queries are iteratively refined: in each subsequent iteration, new queries are aggregated from the previous iteration's pseudo labels (after morphological erosion to suppress contour noise), and are further enhanced by adding learned class embeddings and supervising with focal loss. The distance map is computed as X = 1 − M where M is the N-channel probability map from cross-attention, and pseudo labels are obtained by assigning each pixel to its nearest instance (argmin distance). Training combines partial cross-entropy at labeled pixels, a color-prior loss providing dense supervision from LAB-space neighbor affinity, and a self-training loss that uses the final iteration's pseudo labels to regularize earlier layers, while the panoptic branch is trained with dice, focal, and detection losses on the pseudo labels.

## Results

With single-point labels (P1) and a Swin-L backbone, the method achieves 41.0% PQ on COCO and 68.5% PQ on VOC, setting a new state-of-the-art for point-supervised panoptic segmentation. With ten-point labels (P10) and ResNet-50, it reaches 41.3% PQ on COCO and 64.0% PQ on VOC. The method consistently outperforms the previous best (Point2Mask) by 2.8–7.5% PQ across backbone settings on COCO and by 2.8–7.5% PQ on VOC. In a pseudo-label generation comparison against SAM (ViT-H), the method's distance branch produces superior pseudo labels, yielding 72.2% PQ on VOC versus SAM's 60.6%.

## Baselines & Comparisons

The method outperforms Point2Mask (the previous SOTA for point-supervised panoptic segmentation) across all backbone and label settings: with P1 labels it gains +1.8 PQ (R50), +1.2 PQ (R101), and +4.0 PQ (Swin-L) on COCO, and +2.8, +3.0, and +7.5 PQ on VOC respectively. With P10 labels and R50, it surpasses Point2Mask by 6.1 PQ on COCO and 4.9 PQ on VOC. Against PSPS, the gains are even larger (e.g., +4.9 PQ on COCO and +6.8 PQ on VOC with P1/R50). The method also beats SAM (ViT-H) in a pseudo-label generation comparison, achieving 47.3 vs. 46.7 PQ on COCO and 72.2 vs. 60.6 PQ on VOC when the generated pseudo labels are used to train the same Panoptic Segformer (Swin-L) model. Notably, the fully supervised PanopticSegFormer (R50) achieves 48.0 PQ on COCO, so the gap between the point-supervised method (41.0 PQ with Swin-L) and full supervision narrows to ~7 PQ, a substantial reduction from the ~16 PQ gap of Point2Mask.

## Relation to Prior Work

This paper extends the point-supervised panoptic segmentation paradigm established by PSPS and Point2Mask, which both estimate dense pseudo labels by assigning unlabeled pixels to instances via rule-based distances (Dijkstra shortest paths on graphs built from hand-crafted features like Sobel edges or semantic segmentation maps). The key departure is replacing this fixed, non-optimizable distance with a learnable pixel-to-instance distance predicted through cross-attention between per-instance anchor queries and multi-scale pixel features, supervised end-to-end by the point labels. The panoptic branch itself is borrowed directly from Panoptic SegFormer, and the iterative query aggregation/enhancement mechanism is novel to this work, addressing the bias of initial queries toward contour regions where point labels tend to fall.

## Why It Matters / Open Questions

By making the pseudo-label estimation differentiable and trainable, the paper closes a practical gap: the distance that determines pseudo label quality was previously a black-box heuristic that could not be corrected by the supervision signal. The resulting SOTA (68.5% PQ on VOC, 41.0% PQ on COCO with Swin-L) narrows the gap to fully supervised panoptic segmentation while requiring only one point per instance. The comparison with SAM (ViT-H) showing that a task-specific Swin-L model produces better pseudo labels on COCO/VOC is a useful data point for the ongoing debate about foundation models vs. task-specific training. Open questions include whether the iterative refinement (L=6 layers) is the most efficient design, how the method scales to scenes with very many instances, and whether the learnable distance transfers across domains without retraining.

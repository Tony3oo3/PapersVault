## Problem

Training a unified object detector across multiple datasets is hindered by inconsistent taxonomies, imbalanced data distributions, and scale disparities, causing multi-dataset training to underperform single-dataset training. Existing approaches either manually unify label spaces (losing flexibility when adding new datasets) or rely on raw CLIP text embeddings that carry frequency-based biases from their pre-training corpus. The paper asks how to build a multi-dataset detector that is simultaneously flexible, robust, training-efficient, and architecture-agnostic.

## Input / Output

The detector consumes RGB images alongside frozen CLIP text embeddings of each dataset's category labels (prompted as 'the photo is [class name]'). For each input image, the model outputs bounding boxes and class predictions through dataset-specific classification heads, so a single forward pass yields predictions in every dataset's label space simultaneously. The box regression head is shared and class-agnostic, while classification is performed per-dataset against its own frozen embedding matrix.

## Method

Plain-Det combines three key mechanisms on top of a shared query-based backbone (Deformable-DETR or Sparse R-CNN). First, it replaces unified taxonomies with dataset-specific classification heads whose weights are frozen CLIP text embeddings calibrated by subtracting the NULL-string embedding and L2-normalizing, correcting frequency-based similarity bias. Second, a Class-Aware Query Compositor initializes object queries by multiplying an MLP of the calibrated dataset classifier (a weak dataset prior) with a max-pooled global image feature (a weak image prior), avoiding both dataset-agnostic learnable queries and strongly dataset-dependent top-K pixel selections. Third, a hardness-indicated sampler dynamically reweights dataset sampling at each iteration using the ratio of per-dataset box loss to the minimum loss, scaled by the inverse square root of dataset size, so that harder or under-represented datasets receive more training signal. Together these components let the detector scale to 2,249 categories across 4M images while matching or exceeding single-dataset performance.

## Results

Plain-Det, integrated with Def-DETR and trained jointly on COCO, LVIS, Objects365, and Open Images (2,249 categories, 4M images), achieves 51.9 mAP on COCO, matching current state-of-the-art detectors while using only 36 epochs of COCO data (vs. 192 for ScaleDet). Across the four training datasets, it reaches 47.4 mean AP (COCO 51.9, LVIS 40.9, O365 33.3, OID 63.4). On the ODinW zero-shot transfer benchmark, Plain-Det achieves 46.1 mAP, surpassing GLIP-T (44.0) trained on 5.5M images with only 3.6M. Under the RCNN family, Plain-Det integrated with Sparse R-CNN reaches 46.1 COCO AP in 12 epochs, outperforming Det-Hub (45.3) with the same data budget.

## Baselines & Comparisons

Plain-Det consistently outperforms all compared multi-dataset detectors. Against ScaleDet [4] (the closest competitor using CLIP text embeddings), Plain-Det gains +4.8 mAP on L+C+O+D (46.4 vs 41.9) and +4.2 on L+C+O (45.9 vs 41.7), with the gap widening as more datasets are added. Against Detic [41], Plain-Det achieves +8.0 mAP on L+C+O+D (46.4 vs 38.4). Against UniDet [43], which learns a unified label space, Plain-Det gains +7.6 mAP on C+O365 (42.6 vs 35.0). In the RCNN family, Plain-Det on Sparse R-CNN [31] beats Det-Hub [22] by +0.8 AP (46.1 vs 45.3) and RegionCLIP [40] by +3.4 AP (46.1 vs 42.7), all within 12 epochs. On ODinW zero-shot transfer, Plain-Det (46.1 mAP) surpasses GLIP-T [18] (44.0) despite using 35% less training data (3.6M vs 5.5M images), and outperforms ScaleDet-R [4] by +6.9 mAP (46.1 vs 39.2). The single-dataset Def-DETR [44] baseline (46.9 COCO AP) is exceeded by +5.0 AP, confirming that multi-dataset training with Plain-Det yields net gains rather than the typical performance degradation seen in naive multi-dataset baselines.

## Relation to Prior Work

This paper positions itself against the multi-dataset object detection line of work (ScaleDet, UniDet, Detic, Det-Hub), which typically constructs a unified label space across datasets. Plain-Det departs from this by retaining entirely dataset-specific classification heads with frozen CLIP text embeddings, arguing that unified taxonomies become noisier and less flexible as label spaces grow. It builds on Deformable DETR and Sparse R-CNN as base architectures, and on CLIP for the shared semantic space, but introduces three targeted modifications: calibration of CLIP text embeddings to remove frequency-based bias, class-aware query initialization as a middle ground between dataset-agnostic and dataset-specific queries, and a hardness-indicated dynamic sampler inspired by an observed emergent property in multi-dataset training.

## Why It Matters / Open Questions

The practical significance is that Plain-Det achieves 51.9 mAP on COCO (matching single-dataset SOTA) while jointly training on 2,249 categories across 4M images, and it does so with fewer COCO epochs than prior multi-dataset methods, making it a viable recipe for scaling detection models without hand-crafted taxonomy unification. The emergent property—that a few dataset-specific iterations can substantially activate a detector's latent capability on a particular dataset—opens a direction for efficient domain adaptation. Limitations include reliance on CLIP's text encoder (inheriting its training-data biases) and the fact that the approach is validated primarily on four datasets; whether the framework scales gracefully to dozens of datasets with highly heterogeneous taxonomies remains an open question.

## Problem

Existing compositional visual reasoning frameworks (e.g., ViperGPT, IdealGPT) rely on LLMs for planning and reasoning without a mechanism to validate their outputs or incorporate visual perception feedback into subsequent decisions. This leads to cascading errors when invalid instructions propagate unchecked, and the inability to adjust planning based on accumulated visual evidence from earlier steps, resulting in unnecessary iterations and degraded performance.
![Teaser figure](../imgs/ECCV20240517/cropped_page1_idx0.webp)

## Input / Output

HYDRA takes a query-image pair (textual question + RGB image) and produces either a free-form textual answer (for VQA) or bounding boxes (for visual grounding). The query is consumed iteratively: at each step the planner generates multiple instruction samples with confidence scores, the RL controller selects one, the reasoner executes generated Python code against a suite of VFMs, and the textualizer converts perceptual outputs (bounding boxes, captions, verifications) into a uniform textual format stored in a State Memory Bank that conditions all subsequent iterations.

## Method

HYDRA integrates three modules in a feedback loop: (1) a planner (ChatGPT) that generates N instruction samples of varying depth with associated confidence probabilities, (2) a controller combining GPT-3 embeddings with a DQN-trained MLP (1536→512→6) that scores and selects the optimal instruction or rejects the batch for regeneration, and (3) a reasoner that uses ChatGPT to generate Python code executed against VFMs (GLIP, BLIP-2, LLaVA-1.5, MiDaS, XVLM). The key distinction is the RL agent acting as a cognitive hyper-controller that evaluates instruction validity using historical state from the State Memory Bank, enabling dynamic adjustment rather than fixed feed-forward or simple loop-based decomposition. The DQN reward function penalizes iteration count and incorrect answers while rewarding correct outputs, and the incremental reasoning mechanism ensures all prior perceptual evidence is textualized and available to both the planner and controller in subsequent steps.

## Results

On OK-VQA, HYDRA achieves 48.6% accuracy, surpassing the best end-to-end model (InstructBLIP at 47.9%) and the best compositional baseline (ViperGPT at 40.7%). On GQA, HYDRA reaches 47.9% accuracy, outperforming the strongest E2E method (BLIP-2 at 45.5%) and the best compositional method (IdealGPT at 41.7%). For visual grounding, HYDRA attains 61.7% IoU on RefCOCO and 61.1% IoU on RefCOCO+, exceeding the best E2E grounding model (ReCLIP at 58.6%/60.5%) and ViperGPT (59.8%/60.0%).

## Baselines & Comparisons

HYDRA achieves state-of-the-art results across all three evaluated tasks, outperforming every baseline. On OK-VQA, HYDRA (48.6%) edges out the strongest E2E model InstructBLIP (47.9%) by 0.7% and substantially surpasses the best compositional method ViperGPT (40.7%) by 7.9%. On GQA, HYDRA (47.9%) leads BLIP-2 (45.5%) by 2.4% and IdealGPT (41.7%) by 6.2%, with the gap over ViperGPT (37.9%) reaching 10%. For visual grounding on RefCOCO/RefCOCO+, HYDRA (61.7%/61.1%) beats ReCLIP (58.6%/60.5%) and ViperGPT (59.8%/60.0%), confirming that the compositional framework with RL-based control is more effective than both monolithic VLMs and prior compositional pipelines. The generalization experiments further show that HYDRA trained on GQA transfers to OK-VQA at 48.17% (vs. ViperGPT's 40.74% and ViLT's 32.13%), and training on OK-VQA transfers to A-OK-VQA at 55.94%, demonstrating that the RL agent controller generalizes without retraining.

## Relation to Prior Work

HYDRA extends the compositional visual reasoning paradigm established by ViperGPT, IdealGPT, VisProg, and Chameleon, which decompose complex visual tasks into sub-steps using LLMs as planners and VFMs as perception tools. Its key departure is the introduction of a DQN-based reinforcement learning agent as a cognitive controller that dynamically validates and selects among multiple LLM-generated instruction samples, rather than relying solely on LLM commonsense for planning decisions. Additionally, HYDRA introduces incremental reasoning through a State Memory Bank that stores perceptual feedback across iterations, addressing the limitation in prior compositional methods where subsequent steps begin without retaining information from earlier perception results.

## Why It Matters / Open Questions

The RL-agent-as-controller architecture offers a principled mechanism for injecting learned decision-making into compositional VR pipelines, potentially reducing reliance on brittle LLM heuristics for instruction selection. The cross-dataset generalization results (e.g., training on GQA, testing on OK-VQA with minimal performance drop) suggest the learned controller captures transferable reasoning strategies rather than dataset-specific patterns. However, the framework still depends on LLMs for code generation and textual summarization, which remain failure points in complex cases, and the RL agent is a relatively simple 3-layer MLP whose capacity to handle more nuanced control decisions is unexplored. Open questions include whether richer RL architectures or multi-agent designs could further reduce LLM error propagation and whether the approach scales to video or multi-image reasoning.

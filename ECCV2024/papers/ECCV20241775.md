## Problem

Text-to-image diffusion models lack fine-grained spatial controllability: existing training-free methods that manipulate cross-attention maps cause blending of adjacent same-category objects and require costly backpropagation, while fine-tuning-based approaches incur substantial computational and data curation costs. The paper addresses how to achieve precise per-object spatial layout control in a zero-shot paradigm without retraining or gradient-based attention manipulation.

## Input / Output

The method takes a global text caption, per-object layered captions, and spatial layout entities (bounding boxes or instance masks) that are converted into binary masks and vision guidance vectors. It operates in the latent space of Stable Diffusion v1.5 using a DDIM sampler with 50 steps and a fixed guidance scale of 7.5. For the editing extension, a reference image is inverted via DDIM to obtain the initial noise latent, which serves as the final (background) layer. The output is a photorealistic image where each object's contour and position align with the specified layout region.

## Method

LRDiff divides the reverse diffusion process into two stages: a layered rendering stage (t ≥ t₀) where each object is denoised in its own layer with a dedicated vision guidance vector, and a global refinement stage (t < t₀) that enriches texture using the full caption. The core mechanism is vision guidance ξ = δ·(2M−1), a feature map added to the score network input that enhances generation tendency inside the target mask and suppresses it outside, providing spatial cues without any gradient computation. The vector δ is either a user-specified constant or dynamically extracted from cross-attention maps at the initial denoising step (averaging top-K attended latent features). The per-layer denoising directions are fused via mask-weighted averaging into a single score estimate Φ_t, ensuring the prediction remains within the data distribution so the pre-trained U-Net requires no fine-tuning. This layered architecture prevents conceptual blending between adjacent objects while the final global stage harmonises the full scene.

## Results

On the bounding box-to-image task (MS-COCO validation, 1134 samples), LRDiff achieves mAP 17.4, AP50 35.6, and AP75 15.5, substantially outperforming BoxDiff (mAP 5.8, AP50 17.2, AP75 3.0) and eDiffi-Pww (mAP 4.2, AP50 8.6, AP75 4.0) while maintaining image fidelity close to the Stable Diffusion baseline (T2I-Sim 0.281 vs 0.292, CLIP 0.292 vs 0.316). On the instance mask-to-image task, LRDiff achieves IOU 49.06, AP50 35.0, and AP75 15.4, surpassing MultiDiff (IOU 47.59, AP50 30.9, AP75 8.2) and eDiffi-Pww (IOU 33.11, AP50 16.5, AP75 6.4). The method operates in a zero-shot paradigm with 50 DDIM steps on a single V100 GPU, requiring no fine-tuning of the underlying diffusion model.

## Baselines & Comparisons

Against BoxDiff [57], LRDiff achieves 3× higher mAP (17.4 vs 5.8), 2.1× higher AP50 (35.6 vs 17.2), and 5.2× higher AP75 (15.5 vs 3.0), at the cost of a slight image-fidelity drop (T2I-Sim 0.281 vs 0.295). Against eDiffi-Pww [2], LRDiff dominates on all alignment metrics (mAP 17.4 vs 4.2, AP50 35.6 vs 8.6, AP75 15.5 vs 4.0) while matching image quality (CLIP 0.292 vs 0.299). Against TwFA [60], LRDiff wins on both image quality (T2I-Sim 0.281 vs 0.210) and alignment (mAP 17.4 vs 9.9). On the instance mask task, LRDiff outperforms MultiDiff [4] on AP75 (15.4 vs 8.2) and IOU (49.06 vs 47.59) while maintaining a closer image-score to the SD baseline, and decisively beats DenseDiff [29] on all alignment metrics (AP50 35.0 vs 11.3, AP75 15.4 vs 1.3, IOU 49.06 vs 27.65). The paper notes a trade-off between image-score and align-score across methods: TwFA achieves moderate alignment but poor image quality, while LRDiff balances both by using layered rendering for spatial control followed by a global-caption-guided denoising stage for texture coherence.

## Relation to Prior Work

LRDiff builds directly on the Stable Diffusion latent diffusion architecture and its classifier-free guidance formulation, extending the score estimation to accept an additional vision guidance feature map without retraining. Conceptually, it departs from the dominant training-free layout-to-image paradigm of manipulating cross-attention maps (eDiffi-Pww, ZestGuide, BoxDiff, DenseDiff) by instead injecting spatial cues as an explicit input to the denoising network, combined with a layered rendering strategy that processes each object's denoising direction independently before fusing. This positions the work between fine-tuning-based methods (ControlNet, GLIGEN) that achieve precise alignment at high training cost and attention-manipulation methods that suffer from same-category blending, offering a middle ground that is both zero-shot and object-aware.

## Why It Matters / Open Questions

The layered rendering with vision guidance provides a practical, training-free recipe for multi-object spatial controllability that avoids the blending artifacts plaguing attention-based methods, which is a persistent pain point in layout-to-image generation. However, the framework is currently limited to bounding boxes and instance masks as spatial conditions, and the sensitivity of the t0 split point to scene type remains unaddressed. Open questions include whether the approach generalizes to richer layout conditions (keypoints, depth maps), whether t0 can be learned per-scene, and whether the method transfers cleanly to newer, more capable diffusion backbones beyond SD v1.5.

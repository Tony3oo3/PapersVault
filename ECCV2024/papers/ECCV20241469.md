## Problem

Generalizable NeRF (G-NeRF) models render each pixel independently in a batch-wise, single-ray manner, which prevents direct interaction between adjacent pixels and causes blurry artifacts and loss of high-frequency texture details even when texture-rich multi-view source images are available. This per-pixel independence is a fundamental architectural limitation that per-scene optimization in standard NeRF avoids but G-NeRF cannot replicate.
![Teaser figure](../imgs/ECCV20241469/cropped_page1_idx0.webp)

## Input / Output

The module consumes a rendered novel view image from any G-NeRF model, the sparse alpha point cloud (top 12 sampled points per ray, sorted by hitting probability) produced during volume rendering, N multi-view source images, and the target camera pose. It outputs an enhanced novel view image at the same resolution as the rendered input. The module is plug-and-play: it is trained once on pre-rendered G-NeRF outputs and then applied at inference time without modifying or retraining the base G-NeRF model, operating in roughly 1–2 seconds per image.

## Method

GMT introduces two key components. First, RayDCN (Ray-Imposed Deformable Convolution) estimates per-pixel offsets for deformable convolution by combining geometry-driven projection of 3D sampled points onto source images (using camera intrinsics/extrinsics and depth) with image-based correlation from C2-Matching; raw alpha values are refined via MinkowskiNet sparse convolution on the point cloud, and the resulting weighted projection of K points per ray yields an offset that is guaranteed to lie on the epipolar line. Second, TPFormer (Texture-Preserving Transformer) aggregates aligned multi-source features in two stages: a view-dependent attention module performs self-attention with relative view-direction embeddings to select which reference textures are relevant, followed by a reference-texture selection module that applies cross-attention from the target feature to each source view's value, preserving high-frequency details that standard MLP or multi-head attention layers would blend. Together, these components give the target viewpoint a multi-ray receptive field, enabling direct adjacent-pixel interaction that single-ray G-NeRF rendering lacks.

## Results

GMT is a plug-and-play enhancement module that consistently improves G-NeRF models across all evaluated datasets. The largest PSNR gain is +0.60 dB on Synthetic NeRF (Neuray: 28.36 → 28.96), +0.77 dB on ACID (pixelSplat: 28.10 → 28.87), and +0.39 dB on Real Forward-Facing (Neuray: 25.43 → 25.82). Improvements are observed across all three metrics (PSNR, SSIM, LPIPS) for every base model tested, with LPIPS reductions of up to 0.019. The module operates in ~1.1–1.7 seconds per image with only 9.1M parameters, making it faster than multi-reference enhancement baselines like MReSFR (1.99–8.98 s) and NeRFLiX (1.48–2.35 s).

## Baselines & Comparisons

GMT is evaluated as a plug-and-play enhancer on five G-NeRF base models (IBRNet, GNT, GeoNeRF, Neuray, MuRF) and one 3D Gaussian splatting model (pixelSplat), consistently improving PSNR by 0.04–0.77 dB across all datasets. Against image-enhancement baselines using the same Neuray base, GMT (28.72/28.96/25.82 PSNR on DTU/Syn.NeRF/RFF) outperforms C2-Matching (28.38/28.49/25.55), MReSFR (28.52/28.64/25.64), and NeRFLiX (28.54/28.79/25.65) on all metrics, while also being faster (1.07–1.68 s vs. 1.48–8.98 s) and smaller (9.1M vs. 23.7–35.2M params). On ACID and RealEstate10k, Ours+pixelSplat achieves 28.87 and 26.40 PSNR, surpassing pixelSplat alone (28.10/25.86) and all other G-NeRF methods (GPNR 25.28/24.11, Du et al. 26.88/24.78). With per-scene finetuning, Ours+GNT-ft reaches 31.03 PSNR on RFF, exceeding NeRF (26.36), NeX (27.03), NLF (28.03), and Neuray-ft (27.40). The smallest improvement is observed with MuRF on DTU (+0.04 PSNR), suggesting diminishing returns when the base model already has strong multi-baseline geometry, while the largest gains appear on texture-rich synthetic scenes (Synthetic NeRF, ACID).

## Relation to Prior Work

GMT positions itself at the intersection of generalizable NeRF (G-NeRF) and reference-based image enhancement, drawing on C2-Matching for correspondence matching and extending deformable convolution with geometry-driven offsets derived from the alpha point cloud produced during G-NeRF volume rendering. Unlike prior G-NeRF methods (IBRNet, Neuray, GeoNeRF, GNT) that aggregate features per-ray via MLPs or multi-head attention, GMT introduces multi-ray feature interaction through RayDCN and a texture-preserving transformer (TPFormer) that explicitly preserves high-frequency details during aggregation. The key conceptual departure is leveraging the geometric proxy (alpha values) inherent to the rendering process as a prior for source-target correspondence, a signal unavailable to generic reference-based super-resolution or deblurring methods.

## Why It Matters / Open Questions

The plug-and-play design means practitioners can improve any existing G-NeRF or 3D Gaussian Splatting model (demonstrated on IBRNet, Neuray, GeoNeRF, GNT, MuRF, and PixelSplat) without retraining, which has practical value for deployment pipelines. However, the approach is inherently dependent on the quality of the base G-NeRF rendering and its alpha estimates; when geometry is severely wrong, the geometric prior degrades. Open questions include whether the module generalizes to fundamentally different 3D representations (e.g., implicit SDFs or point-based methods without explicit alpha), whether the VGG-based feature extraction is optimal for all texture types, and whether the modest 0.1–0.6 dB gains justify the additional ~1–2 second inference cost in latency-sensitive applications.

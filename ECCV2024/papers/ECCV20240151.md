## Problem

Generating complete, diverse, and plausible 3D indoor scenes from sparse hand-drawn sketches remains challenging because sketches inherently lack the object relationships and invisible objects needed for a coherent scene. Existing methods either rely on 2D images (restricting diversity), focus on single-object generation, or use hand-crafted relationship hierarchies that limit layout variety. The paper addresses how to leverage external knowledge of object relationships to resolve sketch ambiguity and infer undrawn objects while maintaining user control.
![Teaser figure](../imgs/ECCV20240151/cropped_page1_idx0.webp)

## Input / Output

The method takes a hand-drawn edge sketch (produced via Canny edge detection on a rendered view) and a user-specified list of object entity types as input. Some entities are visible in the sketch while others are not, requiring knowledge-based inference. The output is a complete 3D scene represented as a D×M matrix where each row encodes an object's axis-aligned bounding box (size, translation, yaw angle parameterized as sin/cos) and a DeepSDF shape latent code, with zero-padding to a fixed object count M. A spectrum-filter in the frequency domain suppresses the low-frequency padding components during denoising.

## Method

SEK is a conditional diffusion model that denoises a scene matrix from Gaussian noise, conditioned on sketch features (ViT-encoded) and knowledge-enhanced graph reasoning features combined via multi-head attention. The external knowledge base stores relationship triplets (attachment, alignment, dependent, co-occurrence, parallel collinearity) with learned probabilities extracted from 5,754 3D-FRONT scenes via DBSCAN clustering. A Knowledge-enhanced Graph Reasoning (KeGR) module performs multi-step graph convolutions on a subgraph of the KB corresponding to the user-specified entities, producing relationship-aware node features that complement the sketch condition. The 3D denoising scene transformer applies self-attention across the object dimension and a novel spectrum-filter that converts the scene representation to the frequency domain to suppress low-frequency padding zeros, ensuring valid object components dominate the prediction. Training uses the standard DDPM noise-matching objective with the sketch-knowledge condition, and scene completion is achieved via DDIM inversion on partially known scene representations.

## Results

On the 3D-FRONT dataset, SEK achieves the best FID across all three room categories: 15.21 (Bedroom), 25.46 (Dining Room), and 31.24 (Living Room), outperforming the nearest competitor DiffuScene by 17.41% in FID and 37.18% in CKL (Dining Room). For 3D scene completion, SEK improves FID and KID by 19.12% and 20.06% respectively over DiffuScene. In sketch-based generation (Table 2), SEK achieves FID of 15.21/25.46/31.24 and KID of 1.12/0.49/0.71 across Bedroom/Dining/Living rooms, surpassing all baselines including ATISS-SK and Sketch2Scene.

## Baselines & Comparisons

SEK outperforms all 10 baselines on FID and CKL across all three room categories. The nearest competitor, DiffuScene [46], is beaten by 17.41% in FID and 37.18% in CKL (Dining Room), and also on SCA (51.78% vs 55.50%, where closer to 50% is better). ATISS [38] and ScenePrior [34] are the next closest on FID but lag significantly on CKL (0.64–0.78 vs 0.16 for SEK in Dining Room). Graph-based methods (Graph-to-3D [7], 3D-SLN [29]) perform poorly on full scene generation (FID 41–61) because they require complete scene graph descriptions that do not specify relative object locations. Retrieval-based methods (DepthGAN [56], FastSynth [40], Sync2Gen [53]) show the worst FID scores (31–88), reflecting limited diversity from shape retrieval. In sketch-based generation (Table 2), SEK (FID 25.46 Dining) beats ATISS-SK (37.24), Sceneformer-SK (52.07), and Sketch2Scene (41.35), confirming that the knowledge-enhanced sketch conditioning provides a clear advantage over simply appending sketch features to existing architectures.

## Relation to Prior Work

SEK builds on the DDPM diffusion framework for iterative scene denoising and DeepSDF for per-object shape encoding, but departs from prior diffusion-based scene generators (e.g., DiffuScene) by introducing a dual conditioning mechanism: a ViT-encoded hand-drawn sketch plus a knowledge-enhanced graph reasoning (KeGR) module that queries an external object-relationship knowledge base. Unlike earlier sketch-based 3D methods that target single objects (Sketch2Model, Sketch-a-Shape) or scene generators that rely on hand-crafted relationship hierarchies (GRAINS) or complete scene graphs (Graph-to-3D), SEK treats the sketch as a sparse, ambiguous user intent and uses learned relationship priors to resolve ambiguity and infer invisible objects. The spectrum-filter for suppressing padding artifacts in the scene matrix is adapted from Miao et al.'s spectrum-guided segmentation work, repurposed here to handle the fixed-length object padding inherent to matrix-based scene representations.

## Why It Matters / Open Questions

This is the first method to jointly condition 3D scene diffusion on both a freehand sketch and an external knowledge base of object relationships, addressing the long-standing gap between single-object sketch-to-3D and full-scene generation. The knowledge transfer experiment—where a knowledge base built on 3D-FRONT generalizes to ScanNet with only a 0.34 FID drop—suggests that indoor object-relationship priors are relatively dataset-agnostic, which could reduce the cost of deploying such systems in new environments. Limitations include reliance on Canny-edge-derived sketches rather than truly freehand drawings, evaluation restricted to three indoor room types, and the knowledge base being limited to five predefined relation types. Open questions include whether the approach scales to outdoor or multi-room scenes, whether richer knowledge representations (e.g., learned rather than counted relationships) would further improve plausibility, and how the method handles genuinely ambiguous or contradictory user sketches.

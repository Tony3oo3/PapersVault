## Problem

Estimating population size (number of individuals) from large image collections using Re-ID systems is highly unreliable: standard clustering heuristics like k-means with the elbow rule produce errors of 80% or more when the underlying similarity is imperfect or out-of-distribution. No prior method provides an unbiased estimate with statistical confidence intervals using only a small amount of human verification, leaving practitioners without a principled stopping criterion for how much manual review is needed.
![Teaser figure](../imgs/ECCV20241006/cropped_page1_idx0.webp)

## Input / Output

The method consumes a collection of RGB images and an off-the-shelf Re-ID embedding (MegaDescriptor Swin-transformer with ArcFace loss) to compute pairwise cosine similarities, which serve as proposal distributions for sampling. A human then labels a small fraction of sampled image pairs (often <0.002% of all pairs) as 'same' or 'not.' The output is an asymptotically unbiased point estimate of the number of clusters together with a 95% confidence interval, allowing the user to stop labeling once the interval is sufficiently narrow.

## Method

The key insight (Lemma 1) is that the number of connected components in a graph where edges link same-cluster images equals the sum over all vertices of 1/(1+d(u)), reducing the counting problem to estimating a graph statistic via sampling. The method uses nested importance sampling: the outer loop samples vertices from a proposal Q(u) ∝ 1/(1+Σv ŝ(u,v)) that biases toward low-degree (isolated) nodes contributing most to the count, while the inner loop samples neighbors from q_u(v) ∝ ŝ(u,v) to efficiently estimate each vertex's degree. Human 'same/not' labels on the N×M sampled pairs plug into the importance-weighted degree estimator, and the overall estimator is proven asymptotically normal with O(1/M) bias, yielding valid confidence intervals. Unlike active clustering baselines that incorporate constraints into k-means or mean-shift, this approach requires no fine-tuning of the embedding and works with any off-the-shelf similarity, making it practical for non-AI experts deploying Re-ID in the field.

## Results

Across seven animal Re-ID datasets, the proposed Nested Importance Sampling (NIS) method achieves an average population size estimation error of 12.3%, compared to 38.2% for the strongest baseline (FFT), 66.9% for Nested Monte Carlo (NMC), and 69.4% for connected components (CoCo). On the MacaqueFaces dataset, NIS estimates 34±8 individuals (9% error) matching the true count of 34, while k-means with the elbow heuristic estimates 80 (135% error). On the challenging WhaleSharkID dataset (543 individuals, long-tailed distribution), NIS achieves 543±74 (6% error) using only 0.16% of all pairs, whereas k-means estimates just 70 clusters (87% error). In most datasets, NIS requires vetting less than 0.002% of total image pairs to reach near-zero error.

## Baselines & Comparisons

NIS outperforms all five baselines across every dataset. Against the strongest non-sampling baseline, FFT (farthest-first traversal), NIS reduces average error from 38.2% to 12.3%—a 3.1× improvement—while also providing confidence intervals that FFT cannot offer. Compared to the Nested Monte Carlo variant (NMC), which samples edges uniformly, NIS achieves an 82% relative error reduction at the same human effort by biasing samples toward low-degree vertices and high-similarity edges. Against active clustering (pairwise constrained k-means, pck-means), NIS reduces average error from 75.4% to 12.3%, and the paper further shows that using NIS-estimated k with pck-means yields better clustering accuracy than pck-means with its own active constraint selection. Connected components (CoCo) and Robust Continuous Clustering (RCC) perform worst, with average errors of 69.4% and 219.2% respectively, largely because the elbow heuristic fails when the WCSS curve lacks a clear inflection point. The gap is most dramatic on long-tailed datasets: on WhaleSharkID, NIS achieves 6% error while k-means underestimates by 87% (70 vs. 543 individuals), and on GiraffeZebraID, NIS reaches 8% error versus 80% for NMC.

## Relation to Prior Work

This paper extends the statistical estimation framework of ISCount, DISCount, and Prediction-Powered Inference from single-object counting to the pairwise/cluster-counting setting, using nested importance sampling to estimate the number of connected components in a graph whose edges are revealed only through costly human queries. It departs from active clustering approaches (pck-means, constrained mean shift) that modify the embedding or clustering objective with pairwise constraints, instead treating the off-the-shelf Re-ID similarity as a fixed proposal distribution and using human feedback solely to correct the estimator. The graph-theoretic identity K = Σ 1/(1+d(u)) connects the work to sublinear-time algorithms for counting connected components (Berenbrink et al., Chazelle et al.), though the cost model differs fundamentally since edges are not given as an adjacency list but must be revealed through queries.

## Why It Matters / Open Questions

The practical impact is significant for conservation and ecological monitoring: deploying Re-ID systems on new species or distributions often yields poor clustering, and this method provides a principled stopping criterion (confidence interval width) rather than relying on subjective heuristics like the elbow. A notable finding is that accurately estimating k via Nested-IS improves downstream clustering accuracy more than spending the same human budget on active clustering constraints, suggesting a rethinking of where human effort should be allocated in semi-supervised and category-discovery pipelines. Open questions include how the method behaves when the Re-ID similarity is extremely poor (near-random), whether the approach extends to temporal or video-based Re-ID where the graph structure is more complex, and how to handle the case where the number of individuals changes over time.

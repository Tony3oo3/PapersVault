## Problem

State-of-the-art multiple object tracking requires dense bounding box annotations and instance ID labels for every frame, making large-scale video annotation prohibitively expensive. Existing self-supervised MOT methods rely on image-level self-supervision that cannot capture temporal appearance changes, while self-supervised Re-ID methods still assume dense detection annotations. Walker addresses both gaps by learning appearance from sparsely annotated videos (bounding boxes only every k frames) with no tracking labels at all.
![Teaser figure](../imgs/ECCV20240189/cropped_page1_idx0.webp)

## Input / Output

During training, Walker consumes RGB video frames where ground-truth bounding boxes are available only on a sparse subset (e.g., 1 in 200 frames at 0.1 FPS), with no instance IDs; unlabeled frames are used purely for self-supervision. The detector (YOLOX with FPN) produces per-frame detections, and a 4conv-1fc embedding head extracts 256-dimensional appearance vectors per RoI. At inference, the system outputs tracklets with consistent instance IDs by associating detections across frames using the learned biwalk appearance similarity fused with Kalman-filtered motion costs via Hungarian assignment.

## Method

Walker constructs a quasi-dense Temporal Object Appearance Graph (TOAG) where nodes are object RoIs in key and reference frames and edges encode cosine-similarity-based transition probabilities between embeddings. Training optimizes two losses on cyclic walks (key → reference → key): a multi-positive contrastive cycle-consistency loss that encourages each node to return to its spatially-overlapping cluster, and a mutually-exclusive forward-assignment loss that enforces one-to-one cluster matching across frames, which is essential for MOT. At inference, a novel biwalk similarity metric measures the probability of traversing a candidate node over a satisfied cycle transition, rejecting false positives when the cycle closure probability falls below a threshold. This appearance score is fused with IoU-based motion cost (gated by spatial and appearance thresholds) and solved via Hungarian assignment in a two-stage ByteTrack-style pipeline.

## Results

On DanceTrack with sparse annotations (0.1 FPS), Walker achieves 45.9 HOTA, outperforming the previous self-supervised baseline QDTrack-S (29.2 HOTA) by +16.7 points. Under dense annotations (20 FPS), Walker reaches 52.4 HOTA and 55.7 IDF1, surpassing ByteTrack (47.7 HOTA) and approaching supervised QDTrack (54.2 HOTA) and OC-SORT (55.1 HOTA). On MOT17 (dense), Walker attains 63.6 HOTA, matching supervised QDTrack (63.5) and ByteTrack (63.1) while remaining within 1.0 HOTA of the best supervised tracker BoT-SORT (64.6). On BDD100K (dense), Walker achieves 41.2 mMOTA, outperforming ByteTrack (40.1) and approaching QDTrack (42.4).

## Baselines & Comparisons

Against the primary self-supervised baseline QDTrack-S (frame-level contrastive learning), Walker achieves +16.7 HOTA on DanceTrack sparse (45.9 vs 29.2) and +14.1 HOTA on DanceTrack dense (52.4 vs 38.3), demonstrating that video-level self-supervision via temporal appearance graphs is far more effective than image-level data augmentation. Among supervised trackers on DanceTrack dense, Walker (52.4 HOTA) outperforms ByteTrack (47.7) by +4.7 HOTA and MOTR (54.2) is slightly ahead by 1.8 HOTA, while OC-SORT (55.1) leads by 2.7 HOTA; however, Walker achieves the highest IDF1 (55.7) across all methods. On MOT17 dense, Walker (63.6 HOTA) essentially ties QDTrack (63.5) and beats ByteTrack (63.1) and FairMOT (59.3), trailing only BoT-SORT (64.6) and StrongSORT++ (64.4) by ~1 HOTA. On BDD100K dense, Walker (41.2 mMOTA) surpasses ByteTrack (40.1) and TETer (37.4) but remains 1.2 mMOTA below QDTrack (42.4). In the self-supervised Re-ID comparison (Table 4), Walker outperforms MvMHAT (44.6 HOTA) and ReMOTS (45.2 HOTA) on DanceTrack dense, and the original contrastive random walk QD-CRW (19.2 HOTA) is dramatically inferior, validating the need for multi-positive and mutually-exclusive formulations.

## Relation to Prior Work

Walker builds directly on QDTrack's quasi-dense similarity learning framework for appearance-based MOT and ByteTrack's two-stage data association pipeline, but fundamentally redefines the self-supervision signal from frame-level (data augmentation on static images, as in QDTrack-S) to video-level via temporal object appearance graphs. The graph-based random walk formulation is inspired by contrastive random walks for pixel-level space-time correspondences (Jabri et al., NeurIPS 2020), but Walker redefines the graph nodes from image patches to object-centric RoIs and introduces a multi-positive contrastive objective with mutually-exclusive connectivity constraints tailored to the tracking problem. This departs from self-supervised Re-ID literature, which assumes dense ground-truth detections, by operating in a sparser annotation regime where detection labels are available only every k frames.

## Why It Matters / Open Questions

Walker demonstrates that video-level self-supervision can replace both instance ID labels and dense detection annotations, reducing labeling cost by up to 400× while remaining competitive with fully supervised trackers across three diverse benchmarks. This opens a practical path toward scaling MOT to large, weakly-annotated video corpora where dense per-frame labeling is infeasible. Open questions include whether the approach generalizes to higher frame-rate or longer-horizon tracking, whether the biwalk similarity metric transfers to other association paradigms (e.g., transformer-based trackers), and how the method behaves in truly open-world or open-vocabulary settings where the object categories are not fixed.

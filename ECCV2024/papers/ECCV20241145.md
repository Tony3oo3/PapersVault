## Problem

While Task Vectors have been identified in NLP models as latent activations that encode task information and can replace in-context examples, it remains unknown whether such vectors exist in visual in-context learning models. This paper asks whether visual ICL models like MAE-VQGAN encode task-specific information in their attention head activations, and if so, how to systematically identify and exploit them to guide the model without providing input-output demonstrations.
![Teaser figure](../imgs/ECCV20241145/cropped_page0_idx0.webp)

## Input / Output

At inference, the method takes only a query image (patchified at 112×112 resolution) and a set of pre-computed Task Vectors (mean attention head activations per task). The query is embedded in the bottom-left quadrant of a 2×2 grid, and the model reconstructs the output in the bottom-right quadrant by decoding VQGAN codebook tokens. Unlike standard visual prompting, no input-output demonstration is included in the forward pass; instead, Task Vectors are patched into specific attention head positions to condition the model on the desired task.

## Method

The method identifies Visual Task Vectors in three stages. First, it computes mean attention head activations per task across multiple input-output-query triplets, yielding candidate task vectors at each (layer, head, token) position. Second, it scores activations using a ratio of inter-task to intra-task variance to identify positions with high 'taskness.' Third, it uses the REINFORCE algorithm to optimize a Bernoulli distribution over patching positions, where each position is a random variable indicating whether to replace the attention head output with the pre-computed task mean. The REINFORCE gradient is estimated by sampling patching configurations and backpropagating through the task-specific loss (mIoU for segmentation, MSE for other tasks). This approach captures higher-order interactions between attention heads across layers, unlike single-intervention methods from NLP, and the resulting Task Vectors guide the model to outperform the original one-shot prompting while reducing FLOPS by 22.5%.

## Results

On Pascal-5i, the task-specific REINFORCE-based Task Vector patching outperforms the original MAE-VQGAN one-shot model across all four tasks: Segmentation mIOU 0.353 vs. 0.338, Lowlight Enhancement MSE 0.458 vs. 0.685, Colorization MSE 0.453 vs. 0.618, and In-painting MSE 0.480 vs. 0.550. The multi-task variant (single set of patching positions shared across tasks) also beats the original model on three of four tasks (Lowlight 0.492, Colorization 0.502, In-painting 0.558) while matching it on Segmentation (0.325 vs. 0.338). Additionally, the Task Vector approach reduces forward-pass FLOPS by 22.5% by eliminating the need for in-context demonstration examples.

## Baselines & Comparisons

The paper compares against the original MAE-VQGAN one-shot prompting model and the Causal Mediation Analysis (CMA) method from Todd et al. [38]. The REINFORCE-based Task Vector patching (Ours, Task-specific) beats the original MAE-VQGAN on all four tasks, with the largest gains in Lowlight Enhancement (0.458 vs. 0.685 MSE, ~33% reduction) and Colorization (0.453 vs. 0.618 MSE, ~27% reduction). CMA, which selects top-25% activations by causal score without iterative optimization, is substantially worse than both Ours and the GRS baseline across all tasks (e.g., In-painting MSE 1.750 vs. 0.480 for Ours), confirming that single-step intervention selection misses critical higher-order interactions between attention heads. The GRS baseline (greedy random search guided by activation scoring) is competitive but consistently trails Ours by a small margin, validating the benefit of the REINFORCE-based joint optimization over greedy selection.

## Relation to Prior Work

This paper directly extends the NLP task-vector literature (Hendel et al. 2023; Todd et al. 2023) to computer vision, where the search space is fundamentally different: unlike autoregressive LLMs where task vectors concentrate at the last prompt token, visual models like MAE-VQGAN process image patches in parallel, making the relevant activation positions non-obvious. The authors depart from prior single-intervention evaluation by using REINFORCE to jointly optimize a subset of attention-head outputs, capturing higher-order interactions between heads across layers. The activation-scoring heuristic (inter-task vs. intra-task variance ratio) is a new diagnostic tool for vision, and the finding that task vectors are distributed across both encoder and decoder contrasts with the more localized NLP picture.

## Why It Matters / Open Questions

This is the first systematic evidence that visual ICL models encode reusable task representations in their activation space, and that these can replace in-context examples while improving performance and reducing FLOPS by 22.5%. However, the evidence is confined to a single architecture (MAE-VQGAN with ViT-L) and a single dataset (Pascal-5i) across four relatively simple image-to-image tasks, leaving open whether the findings generalize to larger models, more complex tasks, or other visual prompting paradigms. The paper also notes that evaluation via MSE on decoded VQGAN tokens may understate true performance, and that other vector types (e.g., encoding image structure or ordering) likely coexist with task vectors. A key open question is whether these task vectors compose linearly or interact nonlinearly when combining multiple tasks.

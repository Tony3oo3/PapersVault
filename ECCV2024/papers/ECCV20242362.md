## Problem

Quantifying predictive uncertainty for multi-object detection with distribution-free coverage guarantees is complicated by the fact that bounding box predictions are conditioned on the object's class label. Prior conformal approaches for bounding boxes (e.g., Andeol et al.) only provide guarantees for a single class or for correctly classified objects, making them unsuitable for multi-class safety-critical settings where misclassification is prevalent. This paper addresses the gap by propagating classification uncertainty into bounding box intervals so that coverage guarantees hold even for misclassified objects.
![Teaser figure](../imgs/ECCV20242362/cropped_page1_idx0.webp)

## Input / Output

The method is post-hoc and model-agnostic: it consumes the predictions of any pre-trained 2D object detector (Faster R-CNN, YOLOv3, DETR, Sparse R-CNN) on RGB images, requiring only a probabilistic classification head and a bounding box regression head. For each detected object it outputs (i) a conformal class label prediction set (a subset of the K class labels) and (ii) a two-sided prediction interval per bounding box coordinate (x1, y1, x2, y2), yielding an axis-aligned rectangular uncertainty region. Intervals are adaptive in width, scaling with object size and prediction difficulty, and are calibrated on a held-out split of the same dataset.

## Method

The core contribution is a sequential two-step conformal pipeline. In the first step, a class-conditional conformal thresholding procedure (ClassThr) is applied to the classifier head to produce label prediction sets with a per-class 99% containment guarantee. In the second step, class-conditional conformal prediction is applied to each bounding box coordinate, with the conformal quantile selected as the maximum over all classes in the label prediction set, thereby extending the box coverage guarantee to incorrectly classified objects. Three scoring/interval constructions are proposed for the box step: fixed-width residuals (Box-Std), ensemble-scaled normalized residuals (Box-Ens), and conformal quantile regression (Box-CQR), the latter two yielding size-adaptive intervals. A max-rank multiple testing correction exploits the positive correlation among box coordinates to avoid the conservatism of Bonferroni while preserving the joint per-class coverage guarantee.

## Results

On COCO (target coverage 90%), Box-Std achieves 0.88–0.89 empirical coverage with MPIW of 41.9–61.7 pixels across Faster R-CNN, YOLOv3, DETR, and Sparse R-CNN, substantially tighter than Andeol et al.'s best one-sided intervals (MPIW 79.4–107.9) at comparable coverage (0.90–0.92). The adaptive methods Box-Ens and Box-CQR achieve more balanced coverage across object sizes (small/medium/large) on BDD100k, at the cost of slightly larger MPIW. In the full two-step pipeline, ClassThr yields mean label set size ≤ 4 while maintaining both label and box coverage guarantees across all three datasets (COCO, Cityscapes, BDD100k).

## Baselines & Comparisons

Against Andeol et al. [1,15], the closest prior conformal work, Box-Std achieves comparable coverage (0.88–0.89 vs. 0.90–0.92) while producing substantially tighter intervals: MPIW of 41.9–61.7 (two-sided) versus 79.4–107.9 (one-sided) across the four detectors, with the largest gap on Sparse R-CNN (41.9 vs. 79.4). The paper notes this advantage holds even when restricting to Andeol et al.'s one-sided setting (85.4 vs. 87.6 for Faster R-CNN). Against DeepEns [28] (5×Faster R-CNN) and GaussianYOLO [13] (YOLOv3), both popular UQ approaches, the conformal method decisively wins on validity: DeepEns achieves only 0.21 two-sided coverage and GaussianYOLO only 0.08, both far below the 0.90 target, confirming that heuristic uncertainty estimates without distribution-free guarantees severely undercover in practice. The max-rank multiple testing correction further tightens intervals compared to the Bonferroni correction used in prior work, as shown in supplementary experiments.

## Relation to Prior Work

This paper extends the conformal prediction framework for bounding box uncertainty from Andeol et al. [1,15], which was limited to a single class and correctly classified objects, to a multi-class setting via a novel two-step sequential approach. The first step adapts the class-conditional prediction set classifier of Sadinle et al. [52] to generate conformal label sets, while the second step constructs box intervals using three scoring strategies: standard residuals, ensemble-normalized residuals (building on Lei et al. [31]), and conformal quantile regression (extending Romano et al. [50]). A max-rank multiple testing correction from Timans et al. [61] replaces the more conservative Bonferroni correction used in prior work, exploiting the positive dependency structure among box coordinates.

## Why It Matters / Open Questions

The two-step conformal pipeline provides post-hoc, distribution-free coverage guarantees for bounding boxes that remain valid even when the underlying detector misclassifies objects — a critical property for safety-critical deployment in autonomous driving and robotics where class errors are common. Key limitations include the guarantee only applying to detected (true positive) objects, the exchangeability assumption on calibration data, and the conservative max-operator quantile selection that leads to overcoverage. Open questions include whether tighter intervals can be achieved with weighted quantile strategies informed by the classifier's confusion matrix, and whether the framework extends naturally to 3D detection, tracking, or settings with distribution shift.

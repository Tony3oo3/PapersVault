## Problem

Existing parameter-efficient transfer learning (PETL) methods for Vision Transformers insert trainable structures into the frozen backbone, which modifies all intermediate features and necessitates full back-propagation through the entire model. This results in high GPU memory consumption (7–8 GB) during training, making these methods infeasible in memory-constrained settings despite their small parameter count. The paper attributes this cost to the entanglement of task-specific learning and pre-trained knowledge utilization within a single forward-backward pass.

## Input / Output

The method takes an RGB image (resized to 224×224 for VTAB-1K or 256×256 with center crop for few-shot FGVC) and produces a class label. Unusually, the pre-trained ViT-B/16 backbone is run in inference-only mode (no gradient) to extract intermediate representations from all l transformer blocks, which are then fed as external inputs to the lightweight SynQT blocks. The classification head aggregates 3l hierarchical features (attention output, FFN output, and final output per block) into a single prediction.

## Method

SynQT disentangles PETL into a Query Synthesis Module (QSM) and a Knowledge Extraction Module (KEM) stacked across l blocks. QSM is a lightweight, trainable module (n ≤ 4 tokens, bottleneck projections with hidden size 48) that synthesizes task-specific queries via self-attention and FFN, completely independent of the pre-trained model. KEM reuses the frozen pre-trained ViT's projection and FFN weights to perform cross-attention where the synthesized query serves as Q and the original intermediate features serve as K and V, extracting useful features in a query-only manner without any gradient flow through the backbone. A classification head applies shared bottleneck projections to align hierarchical features, performs conditional feature aggregation (weights generated from the last block's output H_l), and uses DropFeat (random feature dropping during training) to prevent overfitting. This design reduces training memory to 3.4 GB while achieving 72.9% average Top-1 on VTAB-1K, outperforming VPT-Deep (72.0%) at 56% lower memory cost.

## Results

On the VTAB-1K benchmark (19 tasks) with ViT-B/16 pretrained on ImageNet-21K, SynQT achieves 72.9% average Top-1 accuracy while consuming only 3.4 GB of GPU memory during training (batch size 64). This represents a 56% memory reduction compared to VPT-Deep (8.1 GB) while simultaneously improving average accuracy by 0.9%. Under a strict 5 GB memory constraint, SynQT (72.9%) outperforms the strongest memory-constrained baseline AdaptFormer (65.8%) by 7.1% and VQT (68.3%) by 4.6%. In few-shot FGVC evaluation, SynQT significantly outperforms all baselines in 4/8/16-shot settings.

## Baselines & Comparisons

SynQT outperforms all seven baselines on the VTAB-1K average. Against the strongest PETL baseline VPT-Deep (72.0%), SynQT gains 0.9% accuracy while reducing memory from 8.1 GB to 3.4 GB (56% savings), and wins on 14 of 19 individual tasks. Compared to the closest memory-efficient competitor VQT (68.3%, 3.2 GB), SynQT achieves a substantial 4.6% improvement at nearly identical memory cost. Under the 5 GB memory constraint (Table 3), SynQT (72.9%) surpasses AdaptFormer (65.8%) by 7.1%, LoRA (65.5%) by 7.4%, Adapter (64.0%) by 8.9%, and FacT-TT (63.2%) by 9.7%. Against BitFit (65.2%) and VPT-Shallow (67.8%), SynQT leads by 7.7% and 5.1% respectively. Notably, SynQT also generalizes across backbones: it improves over the strongest baseline by 1.8% (MAE), 3.3% (DINO), and 0.8% (supervised ImageNet-1K) on average, and extends to Swin-B and ConvNeXt-B with gains of 2.2% and 1.2% over VPT-Deep.

## Relation to Prior Work

SynQT carves new ground within the parameter-efficient transfer learning (PETL) landscape for Vision Transformers by reframing the problem through a disentangled lens: separating task-specific learning (QSM) from pre-trained knowledge utilization (KEM). It departs from the dominant PETL paradigm (VPT, AdaptFormer, LoRA, BitFit) that inserts trainable structures into the frozen backbone, which forces full back-propagation and heavy memory usage. Conceptually, it builds on the memory-efficient PETL line (VQT, Head2Toe, LST) that exploits intermediate representations without gradient flow through the backbone, but introduces a lightweight, independent query-synthesis module and a frozen cross-attention extraction module as a principled decomposition rather than a simple prompt-in-query-space approach.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck—memory-constrained training of large pre-trained ViTs—that limits the real-world applicability of PETL methods, and the 56% memory reduction with equal-or-better accuracy makes it directly useful for practitioners with limited GPU resources. The disentangled perspective provides a clean conceptual framework that could guide future work on separating task adaptation from knowledge extraction. A stated limitation is that SynQT uses slightly more trainable parameters than some PETL baselines due to its projection layers and FFN operations, leaving open the question of whether extreme memory efficiency and extreme parameter efficiency can be simultaneously achieved. The method's demonstrated generality across architectures (ViT, Swin, ConvNeXt) and pre-training paradigms (supervised, DINO, MAE) strengthens its practical relevance.

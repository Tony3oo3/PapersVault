## Problem

Existing online temporal action localization (On-TAL) methods process only a fixed-size video segment per iteration, limiting their ability to capture long-term context and making performance highly sensitive to the segment size hyperparameter. This restricts detection of long action instances whose temporal extent exceeds the input window, and requires careful per-dataset tuning that does not generalize.
![Teaser figure](../imgs/ECCV20240489/cropped_page1_idx0.webp)

## Input / Output

The model consumes a streaming video as a sequence of fixed-size segments (64 frames for THUMOS14, 75 for MUSES), each encoded by a frozen pretrained backbone (two-stream TSN or I3D) into frame-level features of dimension 1024. At each timestamp, it outputs N action proposals (N=10 for THUMOS14, N=6 for MUSES), each specifying a start time, end time, and class label, with the constraint that once an instance is emitted it cannot be revised in subsequent iterations. A sliding window scheme advances frame-by-frame, and NMS removes redundant or future-ending proposals at each step.

## Method

MATR introduces a memory queue that selectively stores past segment features using a learnable flag token trained to identify segments overlapping with action instances, enabling long-term context without inflating computation. The core localization strategy decouples start and end prediction into two separate Transformer decoders: the end decoder attends to encoded current-segment features to detect the action end near the present timestamp, while the start decoder attends to the memory queue (with 2D relative positional encodings and 50% uniform sampling) to regress the action start over a much wider temporal range. Instance queries are split into class queries and boundary queries sharing positional embeddings, decoupling classification from localization. The start prediction head further decomposes the offset into a region classification (which memory segment contains the start) followed by a within-region offset regression. Training is end-to-end with Hungarian matching, combining focal loss for classification, L1 losses for offsets, DIoU loss for instance-level boundary supervision, and binary cross-entropy for the flag token.

## Results

On THUMOS14, MATR achieves 49.5% average mAP (70.3% at IoU 0.3, 52.1% at IoU 0.5), surpassing the previous best online method OAT-OSN by 4.9 percentage points. On MUSES, MATR reaches 14.4% average mAP (23.5% at IoU 0.3, 14.3% at IoU 0.5), outperforming OAT-OSN by 0.7%p. Notably, MATR's THUMOS14 performance (49.5%) exceeds several offline TAL methods such as G-TAD (39.9%) and P-GCN, though it remains below the strongest offline methods like TriDet (69.3%) and ActionFormer (66.8%).

## Baselines & Comparisons

MATR outperforms the strongest prior online method OAT-OSN [15] by 4.9%p average mAP on THUMOS14 (49.5 vs 44.6) and 0.7%p on MUSES (14.4 vs 13.7), with consistent gains across all IoU thresholds. Against OAD-based online methods, MATR leads by a wide margin: 49.5 vs 34.4 (SimOn [31]), 49.5 vs 29.7 (CAG-QIL [14]), and 49.5 vs 21.4/20.3 (TeSTra [46] / MAT [33]). Among offline TAL baselines, MATR surpasses G-TAD [39] (49.5 vs 39.9) and P-GCN [43] on THUMOS14, but falls short of the top offline methods ActionFormer [44] (66.8) and TriDet [27] (69.3), reflecting the inherent difficulty of the online setting. In the memory-module comparison (Table 4), MATR achieves higher mAP (49.5) with fewer parameters (24.0M vs 40.1M/53.1M) and faster inference (167.1ms vs 191.9/196.1ms) than E2E-LOAD [2] and MAT [33]. On MUSES, the performance gap over OAT-OSN narrows to 0.7%p, which the authors attribute to multi-shot action boundaries and confusing class pairs (e.g., 'quarrel' vs 'fight') that limit the upper bound for all methods.

## Relation to Prior Work

MATR extends the instance-level online TAL framework of OAT (Kim et al., ECCV 2022), which introduced sliding-window and anchor-based Transformer decoding, by adding a memory queue that selectively stores past segment features via a learned flag token. It also adapts the DETR-style query-based Transformer decoder with Hungarian matching to the temporal action localization setting, but departs from OAT's single-decoder design by splitting start and end prediction into two separate decoders that attend to different information sources (current segment vs. memory). The memory queue conceptually differs from prior OAD memory modules (MAT, E2E-LOAD) in that it preserves temporal positional information of past frames rather than compressing them into fixed-size vectors, which is essential for precise boundary regression.

## Why It Matters / Open Questions

The memory queue with flag-token-based selective storage makes the model substantially less sensitive to the input segment size hyperparameter (only 9.1%p drop vs. OAT's 18.8%p when reducing segment size from 64 to 8), reducing dataset-specific tuning burden for practitioners deploying online video understanding systems. The paper also identifies a key limitation: when the memory queue contains multiple overlapping action instances, start-time matching can be incorrect, and the storage decision does not consider relationships with already-stored context—both pointing toward more sophisticated memory management as future work. The finding that an online method can surpass older offline TAL methods (G-TAD, P-GCN) without NMS suggests the online/offline gap is narrowing, though a gap to the strongest offline methods (ActionFormer, TriDet) remains.

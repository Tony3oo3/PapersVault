## Problem

Prior open-set semi-supervised learning (OSSL) methods learn the ID/OOD decision boundary exclusively from limited labeled ID data, causing distribution bias and overfitted boundaries that subsequent self-training cannot correct. This overtrusting leads to increased false-positive and false-negative OOD predictions. No prior method treats OOD as a first-class category with its own labeled data within the SSL process.
![Teaser figure](../imgs/ECCV20241358/cropped_page1_idx0.webp)

## Input / Output

The method takes a small set of labeled ID images (e.g., 25–400 per class) and a large pool of unlabeled images containing a known fraction of OOD samples (mismatch ratio 0.1–0.6). It produces a single (K+1)-way classifier where the first K dimensions yield close-set ID predictions and the (K+1)-th dimension provides the OOD probability score used for AUC computation. The OOD memory queue internally maintains a FIFO buffer of N_m = 8K selected OOD images that serve as pseudo-labeled training data throughout training.

## Method

SCOMatch reframes OSSL as a (K+1)-class SSL problem by treating OOD as an additional class with its own labeled data, eliminating the overtrusting of limited ID labels. An OOD memory queue (FIFO, size 8K) selects the most OOD-like unlabeled samples each iteration using Maximum Softmax Probability over the first K classes of the (K+1)-way head, enqueuing K_m samples per step. The single (K+1)-class head is supervised jointly by labeled ID data and queued OOD samples, then performs simultaneous close-set self-training (first K dimensions, filtering out OOD pseudo-labels) and open-set self-training (all K+1 dimensions) on the same backbone features. A CPL-inspired dynamic threshold τ_ood scales the OOD pseudo-labeling confidence relative to ID classes, and an EMA teacher-student framework (inherited from FixMatch) stabilizes training.

## Results

SCOMatch achieves state-of-the-art close-set classification accuracy across all four main benchmarks (MNIST, CIFAR-10, CIFAR-100, TinyImageNet) at both mismatch ratios 0.3 and 0.6. The most striking gain is on TinyImageNet, where SCOMatch reaches 54.2% (mismatch 0.3) and 52.3% (mismatch 0.6), surpassing the strongest prior method Ma et al. (40.8%) by approximately 13.4 percentage points. On CIFAR-100, SCOMatch improves over Ma et al. by 2.8% (75.3% vs 72.5%) at mismatch 0.3. For OOD identification, SCOMatch achieves 98.1% average AUC on MNIST across all mismatch ratios, outperforming Ma et al. (96.4%) and SAFE-STUDENT (95.3%).

## Baselines & Comparisons

SCOMatch outperforms all 15 baselines across every dataset and mismatch ratio in the main comparison (Table 1). Against the strongest prior OSSL method Ma et al. (ICCV'23), SCOMatch gains 0.3–2.1% on MNIST/CIFAR-10, 2.8–3.1% on CIFAR-100, and a dramatic 13.4% on TinyImageNet (54.2% vs 40.8% at mismatch 0.3). Compared to T2T (ICCV'21), the gains are 0.6–2.8% on MNIST/CIFAR-10, 5.5–5.5% on CIFAR-100, and 15.1% on TinyImageNet. Against the SSL baseline FixMatch (NeurIPS'20), SCOMatch improves by 10.7% on CIFAR-10 (92.2% vs 81.5%) and 9.4% on CIFAR-100 (75.3% vs 65.9%), confirming that open-set handling is critical when OOD samples are present. In the second experimental setting (Tables 3–4, varying labeled data and ID class counts), SCOMatch also leads: 94.1% close-set accuracy on CIFAR-10 (25 labeled) vs IOMatch 93.0% and SSB 91.7%, and 97.5% AUC on IN-30 vs OpenMatch 96.4%.

## Relation to Prior Work

SCOMatch builds directly on the FixMatch SSL framework (weak/strong augmentation, thresholded pseudo-labeling, EMA) and adapts Maximum Softmax Probability (MSP) scoring for OOD detection. It departs from the dominant OSSL paradigm—where methods like OpenMatch, T2T, SAFE-STUDENT, and Ma et al. first learn an ID/OOD boundary from limited labeled ID data and then refine it via self-training—by instead treating OOD as a (K+1)-th class with its own labeled data from the start, forming a unified (K+1)-class SSL process. The paper explicitly contrasts with IOMatch and Ma et al., which also introduce a (K+1)-class head but still derive OOD labels from a boundary learned solely on labeled ID data, thus retaining the overtrusting issue that SCOMatch aims to eliminate.

## Why It Matters / Open Questions

Identifying overtrusting of limited labeled ID data as a root cause of poor OOD discrimination in prior OSSL methods provides a clear diagnostic that reframes how the ID/OOD boundary should be learned. The 13.4% close-set accuracy gain on TinyImageNet and consistent improvements across all benchmarks demonstrate practical impact for open-set SSL in realistic low-label regimes. However, the method only handles OOD from different class spaces within the same domain; cross-domain OOD (e.g., cartoon or synthetic images) remains unaddressed, and the single-class OOD treatment may limit fine-grained OOD understanding. Future work could extend the (K+1)-class SSL formulation to multi-domain or multi-granularity OOD settings.

## Problem

Pre-trained vision-and-language models (e.g., BLIP2, CLIP) suffer significant retrieval performance degradation when target objects in an image are small, due to the rough alignment between text tokens and fine-grained spatial regions. This gap between human object-centric perception—which attends to semantically important objects regardless of size—and V&L model behavior has been masked by strong aggregate benchmark scores, since small-object images constitute only ~1.5% of standard datasets.
![Teaser figure](../imgs/ECCV20242126/cropped_page1_idx0.webp)

## Input / Output

The method consumes an RGB image, a text query, and pre-computed bounding boxes from an object detector (Flickr-Entities, COCO-Entities, or CO-DINO). For T2I retrieval, bounding boxes and image features can be extracted in advance since they are independent of the query text. The output is a standard ranked list of images (T2I) or captions (I2T), with the perturbation applied internally at the cross-attention layers of the host V&L model without changing the retrieval interface.

## Method

The core contribution is a training-free Q-Perturbation module plugged before cross-attention layers in existing V&L models (BLIP2's Q-Former, COCA, InternVL's QLLaMA). It operates in three steps: (1) Object Key Pooling selects image key tokens overlapping each detected bounding box via ROI-style pooling; (2) K-Subspace Construction applies PCA to the pooled object tokens to build a low-dimensional key subspace Φ capturing essential object information; (3) Query Enhancement decomposes each query q_i into a component parallel to Φ (q_i^∥ = ΦΦᵀq_i) and a complementary component, then adds a scaled parallel component back: q̂_i = q_i + α·q_i^∥. For multiple objects, weighted contributions from each object's K-subspace are summed, with weights w(S_b) = β + γ·S̄_b based on normalized bounding-box area. Because the enhancement only amplifies object information already present in the original queries, the method preserves the pretrained weights and expressiveness of the host model while selectively boosting object awareness.

## Results

On Flickr-30K T2I, the proposed Q-Perturbation with BLIP2 achieves R@1=89.86 (using CO-DINO boxes) and R@10=99.06, outperforming the BLIP2 baseline (R@1=89.76) and all prior methods including InternVL-G (84.78) and BEIT-3 (81.50). On COCO 5K T2I, it reaches R@1=68.35 vs. BLIP2's 68.25 and BEIT-3's 67.20. The method also introduces mR@K, an object-size-aware metric, where the small-object subset (~10% area) improves from 81.33 to 84.00 R@1 on Flickr-30K, demonstrating targeted gains for the hardest retrieval cases.

## Baselines & Comparisons

The proposed Q-Perturbation with BLIP2 outperforms all 12 baselines in Table 3 on both Flickr-30K and COCO 5K. On Flickr-30K T2I, it leads the nearest competitor InternVL-G (84.78) by 5.08 R@1 points and BEIT-3 (81.50) by 8.36 points. On COCO 5K T2I, it surpasses BEIT-3 (67.20) by 1.15 R@1 and ALBEF (60.70) by 7.65 points. The method also improves upon its own host model BLIP2 by 0.06–0.10 R@1 on T2I and 0.20–0.40 R@1 on I2T, with the largest I2T gain on Flickr-30K (97.60→98.00). Notably, the gains are consistent whether using manually annotated bounding boxes (Flickr-/COCO-Entities) or automatically detected ones (CO-DINO), confirming robustness to noisy localization. The method also extends to COCA and InternVL-G (Table 4), yielding small but consistent improvements (e.g., InternVL-G Flickr-30K I2T R@1: 94.90→95.40), demonstrating versatility across architectures.

## Relation to Prior Work

This paper positions itself at the intersection of two research threads: (1) the long line of object-aware cross-modal retrieval methods (SCAN, IMRAM, SHAN, NAAF) that explicitly use detection or attention to handle fine-grained matching, and (2) the recent paradigm of pre-trained V&L models (BLIP2, COCA, InternVL) that achieve strong zero-shot retrieval but suffer from degraded performance on small objects due to coarse text-image alignment. The key departure is that rather than training a new retrieval model or modifying the V&L model's weights, the authors introduce a training-free, plug-in Q-Perturbation module that operates on the cross-attention queries using PCA-based subspace decomposition guided by object detection bounding boxes. This inherits the full expressive power of the base V&L model while selectively amplifying object-relevant query components.

## Why It Matters / Open Questions

The paper identifies a practically important but underappreciated weakness in state-of-the-art V&L models: retrieval performance degrades significantly for images where the semantically critical object occupies less than 10% of the image area, a gap hidden by standard Recall@K metrics because such images constitute only ~1.5% of benchmark data. The proposed mR@K metric and the training-free, architecture-agnostic Q-Perturbation module offer a lightweight path to closing this gap without retraining. However, the absolute improvements are modest (typically 0.1–0.5% on R@1, up to ~0.7% on the small-object subset), and the method's effectiveness is bounded by the quality of the upstream object detector and the assumption that object information survives the image encoder. Open questions include whether text-guided filtering of bounding boxes or learned perturbation scales could yield larger gains, and whether the approach transfers to video or 3D retrieval settings.

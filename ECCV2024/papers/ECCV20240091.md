## Problem

Continual Category Discovery (CCD) requires discovering novel categories from a continuous stream of unlabelled data while retaining previously learned knowledge, but existing continual learning methods assume fully labelled data and existing category discovery methods (NCD, GCD) assume static datasets. No prior work provides a scalable prompting mechanism that simultaneously prevents catastrophic forgetting, adapts to growing category counts, and estimates the unknown number of categories on-the-fly in a continual unlabelled stream.

## Input / Output

At the initial stage the model receives labelled RGB images (224×224) to learn features; at each subsequent discovery stage it receives only unlabelled images containing both previously seen and novel categories. The model outputs class label assignments via semi-supervised k-means clustering on [CLS] features, and in the PromptCCD-U variant additionally produces an estimated category count per stage through a GMM split-and-merge procedure. Evaluation uses the newly proposed continual ACC (cACC) metric, which accumulates pseudo-labelled data across stages to guide clustering, reflecting the sequential nature of the task.

## Method

PromptCCD replaces the fixed-size prompt pool of standard prompt-based continual learning with a Gaussian Mixture Model (GMP) whose component means serve a dual role: as task prompts prepended to patch embeddings in a ViT-B/16 backbone (frozen except the last block) and as class prototypes enabling parametric replay. At each stage, the query feature's log-likelihood under each GMM component retrieves the top-k most relevant means as prompts, and the model is trained with contrastive learning (supervised on labelled data at stage 0, self-supervised on augmented views at later stages). To prevent forgetting, the fitted GMM generates pseudo-samples that are mixed with incoming unlabelled features to re-fit the GMM at the next stage, providing an unlimited, distribution-aware replay without storing raw images. For unknown category counts, an MCMC-based split-and-merge mechanism (adapted from GPC) dynamically adjusts the number of Gaussian components during fitting, yielding an on-the-fly category estimate without auxiliary models or offline clustering.

## Results

PromptCCD w/GMP achieves the best cACC (continual ACC) across all seven benchmark datasets. With DINO pretraining, it reaches 64.17% All-ACC on CIFAR-100, 76.16% on ImageNet-100, 61.84% on Tiny-ImageNet, and 82.44% on Caltech-101, while on fine-grained datasets it attains 52.64% (Aircraft), 44.07% (Stanford Cars), and 55.45% (CUB). With DINOv2 pretraining, performance further improves to 69.73% (CIFAR-100), 76.28% (ImageNet-100), 68.20% (Tiny-ImageNet), and 83.86% (Caltech-101). The method also maintains a strong balance between Old and New accuracy, e.g., 75.57/60.34 on CIFAR-100 (DINO), whereas baselines like PA-CGCD achieve high Old accuracy (91.15 on ImageNet-100) but suffer large drops on New accuracy (57.83).

## Baselines & Comparisons

PromptCCD w/GMP achieves the highest All-ACC on every dataset, outperforming the strongest baselines by 3–10 points. On CIFAR-100 (DINO), it reaches 64.17% All-ACC, surpassing ORCA (60.91%), GCD (58.18%), PA-CGCD (58.25%), and Grow & Merge (57.43%). On ImageNet-100, the gap is even larger: 76.16% vs. GCD w/replay (72.04%) and Grow & Merge (67.84%). The method's key advantage is its balanced Old/New performance; while PA-CGCD achieves very high Old accuracy (91.15% on ImageNet-100, 94.75% on Caltech-101), its New accuracy drops to 57.83% and 69.66% respectively, whereas PromptCCD maintains 74.35% and 79.72% New accuracy. With DINOv2 pretraining, PromptCCD further extends its lead, reaching 69.73% on CIFAR-100 vs. GCD (65.35%) and PA-CGCD (54.36%). SimGCD performs poorly in the continual setting (25.56% on CIFAR-100), highlighting the difficulty of adapting static GCD methods to CCD without explicit forgetting mitigation.

## Relation to Prior Work

This paper bridges two previously separate lines of work: prompt-based continual learning (L2P, DualPrompt), which assumes fully labeled data streams, and Generalized Category Discovery (GCD, SimGCD, ORCA), which handles unlabeled data but in a static setting. The key departure is repurposing a Gaussian Mixture Model as the prompt pool, so that each GMM component simultaneously acts as a task prompt (guiding representation learning) and as a class prototype (serving as parametric replay for previously discovered categories). The on-the-fly category number estimation borrows the MCMC split-and-merge mechanism from GPC [58] and integrates it into the continual discovery loop, whereas prior CCD methods (Grow & Merge, MetaGCD, PA-CGCD) either assume known class counts or rely on separate offline estimation.

## Why It Matters / Open Questions

The GMP module offers a practical, parameter-efficient solution to the core tension in CCD: how to retain knowledge of previously discovered categories without storing actual samples, while remaining scalable as the number of categories grows. The plug-and-play nature (demonstrated by improving G&M and MetaGCD) suggests the GMM-as-prompt idea could be adopted more broadly in open-world continual learning. Open questions include whether the approach scales to very long category streams (beyond 4 stages), whether finetuning only the last transformer block is sufficient for larger backbones, and how sensitive the MCMC-based category estimation is to imbalanced or highly overlapping class distributions.

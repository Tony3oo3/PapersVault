## Problem

Binary Neural Networks (BNNs) suffer from a fundamental mismatch between noisy 32-bit floating-point gradients and 1-bit binary parameters: traditional latent-weight optimizers (SGD, Adam) accumulate gradient magnitudes in floating-point buffers, but adjusting those magnitudes does not directly change the binary values, causing suboptimal convergence and underfitting. Prior latent-weight-free optimizers (BOP, Gradient Filter) still rely on gradient magnitude information and have not been shown to generalize to binary transformers or NLP tasks, leaving a gap in robust, architecture-agnostic BNN optimization.

## Input / Output

Diode is an optimizer rather than a model, so its 'input' is the per-parameter gradient g_t produced by the Straight-Through Estimator during backpropagation, and its 'output' is a direct binary update θ_t ∈ {−1, +1} with no intermediate 32-bit latent weight. Because no latent buffer is stored, memory per parameter drops by roughly 50% compared to Adam-based BNN training, and binary parameters are initialized from a Bernoulli(0.5) distribution rather than random 32-bit values. The optimized networks consume standard RGB images (ImageNet 224×224, CIFAR-100 32×32) or tokenized text (BERT-Base on GLUE) and emit class labels or task-specific NLU scores (accuracy, F1, Pearson, MCC).

## Method

Diode replaces the latent-weight update with a two-level exponential moving average over gradient signs. First, a short-term EMA u_t = α·u_{t−1} + (1−α)·g_t smooths the noisy STE gradient; then the sign function standardizes the update magnitude as v_t = η·sign(u_t), eliminating the layer-by-layer magnitude noise that stacked STE introduces. A second, long-term EMA m_t = β·m_{t−1} + (1−β)·v_t aggregates these signed votes over a longer horizon, and the binary parameter is set directly as θ_t = −sign(m_t). The key insight is that the local optimization direction (sign) remains consistent even when gradient magnitudes are corrupted, so sign-only information is sufficient and more robust for BNNs. With α = 0.99 and β = 0.9999, the two-level smoothing controls the binary weight-flip frequency, and a cosine-decayed η acts as a relative voting weight rather than a true learning rate, making the optimizer insensitive to its absolute initialization.

## Results

On ImageNet ILSVRC2012, Diode achieves 68.2% Top-1 accuracy with BNext-18†, surpassing the Adam-optimized baseline (67.5%) by 0.7% and the original BNext-18 (67.9%) by 0.3%, while using 8× fewer training iterations at batch size 4096. On the GLUE benchmark, Diode lifts BiT‡ (without multi-stage distillation) from 71.0% to 74.7% average score (+3.7%), and BiT† (with pre-trained initialization) from 72.4% to 75.7% (+3.3%) without data augmentation. With data augmentation, BiT† (Diode) reaches a new SOTA of 78.8% average GLUE score, outperforming the Adam baseline (76.7%) by 2.1%.

## Baselines & Comparisons

On ImageNet, Diode with BNext-18† (68.2%) outperforms the Adam-optimized same-architecture baseline (67.5%) by 0.7% and the original BNext-18 with 4-bit linear layers (67.9%) by 0.3%, establishing a new SOTA for 1-bit CNNs. For ReActNet-A, Diode (69.6%) essentially matches the Gradient Filter result (69.7%) while avoiding the costly two-stage training protocol. On GLUE without data augmentation, Diode dramatically outperforms existing BNN-specific optimizers: BiT‡ (Diode) scores 74.7% average versus 61.9% for BOP and 62.5% for Gradient Filter, indicating that sign descent is far more robust for binary transformers than magnitude-based updates. With pre-trained BiT initialization, Diode reaches 75.7% average, beating the Adam baseline (72.4%) by 3.3%. With data augmentation, BiT† (Diode) achieves 78.8% average GLUE score, surpassing BiT† (Adam) (76.7%) by 2.1% and setting a new SOTA for fully binary BERT. The only comparison where Diode does not lead is ReActNet-A vs. GFilter (69.6% vs. 69.7%), a negligible 0.1% gap.

## Relation to Prior Work

Diode synthesizes two distinct research threads: the latent-weight-free update rule introduced by BOP (Helwegen et al., 2019), which showed that 32-bit latent buffers are unnecessary for BNN training, and the sign-descent paradigm popularized by Lion (Chen et al., 2023) for transformer optimization. The paper's key conceptual departure is demonstrating that gradient sign information alone—discarding magnitude entirely—is not merely sufficient but superior for BNN optimization, in contrast to prior BNN-specific optimizers (AdamBNN, Gradient Filter) that still aggregate noisy floating-point gradient magnitudes. This positions Diode as the first optimizer to unify latent-weight-free updating with sign descent specifically for the binary parameter space, extending sign-based methods from full-precision transformers to the discrete ±1 weight domain.

## Why It Matters / Open Questions

Diode offers a practically significant simplification: eliminating 32-bit latent weight buffers reduces training memory by ~50%, removes the need for multi-stage distillation pipelines, and enables more efficient use of large batch sizes (the 0.96% ImageNet gain with 8× fewer iterations is notable for compute-constrained settings). The finding that purpose-built BNN optimizers (BOP, Gradient Filter) actually underperform plain Adam on binary BERT is a useful caution against over-engineering for the CNN-only regime. Open questions include the theoretical justification for why sign descent is particularly well-suited to the discrete binary parameter space, and whether the approach extends to the emerging 1-bit LLM architectures (BitNet, BitNet b1.58) that the authors flag as future work. The small-batch limitation also constrains applicability to resource-limited edge deployment scenarios.

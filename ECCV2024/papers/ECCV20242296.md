## Problem

Existing Concept Bottleneck Models (CBMs) are trained with a fixed, closed set of concepts, making it impossible for users to query, add, remove, or replace concepts after deployment. This closed-world assumption is unrealistic in practice, as users may want to understand the role of any arbitrary concept in a model's decision-making without retraining.
![Teaser figure](../imgs/ECCV20242296/cropped_page2_idx0.webp)

## Input / Output

At inference, the model takes an RGB image and an arbitrary user-specified set of k text concepts (e.g., 'yellow body with black streaks', 'melodious song') as input. It produces a class label, per-concept importance coefficients (α_ci) indicating each concept's contribution to each class, and optionally a set of missing concepts discovered from residual parameters. The concept set is entirely flexible at test time—users can remove, add, or completely replace concepts without any retraining.

## Method

OpenCBM trains a standard CNN backbone (ResNet-18) with a prototype-based feature space alignment loss that pulls each image's features toward the CLIP-computed class prototype (mean of CLIP features for that class), while simultaneously training a linear classifier via cross-entropy. At inference, the trained classification head vector v_c for each class is reconstructed as a linear combination of user-specified concept embeddings (encoded by CLIP's text encoder), yielding interpretable importance coefficients α_ci. Residual parameters after reconstruction encode information from concepts the user did not specify; an iterative greedy algorithm searches a large concept space to find the nearest concept embedding to the residual, revealing missing concepts until the residual falls below a threshold. This design decouples concept selection from model training, enabling open-vocabulary interpretation and concept editing (removal, addition, replacement) purely through linear algebra on the frozen classification head.

## Results

On CUB-200-2011 with a ResNet-18 backbone, OpenCBM achieves 83.3% top-1 classification accuracy, outperforming the previous state-of-the-art CBM (Label-free CBM, 74.3%) by 9 percentage points and even surpassing the black-box ResNet-18 (79.9%) by 3.4%. The method also significantly outperforms frozen CLIP-RN50 with linear probing (75.5%) by 7.8%, validating that the trainable feature extractor with prototype-based alignment better fits the downstream task. Additional results on CIFAR-100 are provided in the appendix.

## Baselines & Comparisons

OpenCBM wins against all six baselines on CUB-200-2011. Against the strongest prior CBM, Label-free CBM [11] (74.3%), OpenCBM gains 9.0 points (83.3%), confirming the paper's headline claim. Against the black-box ResNet-18 (79.9%), OpenCBM still leads by 3.4 points, showing that the prototype-based feature alignment to CLIP's space actually improves classification rather than sacrificing accuracy for interpretability. Against frozen CLIP-RN50 with linear probing (75.5%), the 7.8-point margin validates the design choice of training a separate feature extractor rather than relying on CLIP's encoder directly. Against the original CBM [8] (62.9%) and its post-hoc variants P-CBM/P-CBM-h [26] (58.8%/61.0%), OpenCBM leads by 20.4 and 22.3–24.5 points respectively, largely because it avoids the need for dense per-image concept annotations. Against LaBO [25] (71.8%), which uses 10,000 LLM-generated concepts, OpenCBM gains 11.5 points while offering the unique ability to use any user-specified concept set at inference time without retraining.

## Relation to Prior Work

This paper extends the Concept Bottleneck Model (CBM) lineage from Koh et al. (2020) through its successors that removed the need for dense concept annotations (Post-hoc CBM, Label-free CBM, LaBO). All prior CBMs operate under a closed-world assumption with a fixed concept set determined at training time. OpenCBM departs by aligning a trainable feature extractor to CLIP's image encoder via class prototypes, then reconstructing the classification head with arbitrary user-specified text embeddings at inference, enabling open-vocabulary concept manipulation without retraining.

## Why It Matters / Open Questions

The open-vocabulary capability is practically significant: users can remove, add, or replace concepts post-deployment for debugging, debiasing, or knowledge discovery without retraining, a flexibility no prior CBM offers. The 9% accuracy gain over SOTA CBM (83.3% vs. 74.3%) shows the alignment mechanism is not merely an interpretability add-on but also improves classification. Key limitations include dependence on CLIP's alignment quality (affecting all VLP-based CBMs) and evaluation primarily on one fine-grained dataset (CUB-200-2011); open questions include scalability to coarser-grained or multi-modal tasks and whether the prototype alignment generalizes to non-ResNet backbones.

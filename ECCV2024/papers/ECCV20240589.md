## Problem

Segmenting 3D Gaussian Splatting scenes from 2D masks requires assigning a label to each Gaussian, but existing methods (SAGA, Gaussian Grouping) rely on iterative gradient descent over 30,000 steps to distill 2D mask information into per-Gaussian features, making them slow (18–37 minutes) and prone to suboptimal local minima. No prior approach provides a globally optimal, single-step solution that exploits the structural properties of the 3DGS rendering pipeline.
![Teaser figure](../imgs/ECCV20240589/cropped_page10_idx9.webp)

## Input / Output

The method consumes a pre-reconstructed 3DGS scene (per-Gaussian position, quaternion, scale, opacity, and SH color coefficients) together with 2D binary or instance masks (typically from SAM) and their associated camera poses. It outputs a discrete label per Gaussian (0/1 for binary, or an instance ID for scene segmentation), which can be directly used to remove or modify Gaussian subsets. Additionally, it renders 2D masks for novel viewpoints by compositing only the labeled foreground Gaussians and thresholding accumulated alpha, with depth used to resolve multi-object ambiguities. The method operates effectively with as few as ~10% of the total scene views.

## Method

The key insight is that once a 3DGS scene is reconstructed, the alpha-blending rendering equation is linear in the per-Gaussian label P_i (since α_i and transmittance T_i are fixed), so the L1 segmentation objective reduces to a linear function of the binary variables. This allows the problem to be cast as an integer linear program with a closed-form solution: each Gaussian's label is assigned by a weighted majority vote, P_i = argmax_n Σ_{v,j,k} α_i T_i · I(M^v_{jk}, n), where the weights are the Gaussian's rendering contribution to each pixel. A background bias γ ∈ [−1, 1] is introduced after L1-normalizing the contributions to suppress foreground noise from imperfect 2D masks. For scene segmentation, multi-instance labeling is decomposed into per-instance binary problems by aggregating all other instances into a single 'background' score, requiring only one pass to accumulate all A_e values. The full computation (tile-based rasterization to gather contributions plus arg max) completes in ~30 seconds on a single GPU, roughly 50× faster than gradient-descent baselines, with the final label assignment taking 0.4 ms.

## Results

On the NVOS dataset, FlashSplat achieves 91.8% mIOU and 98.6% mAcc, outperforming all baselines including SAGA (90.9% mIOU, 98.3% mAcc) and SA3D (90.3% mIOU, 98.2% mAcc). In terms of computational efficiency, FlashSplat completes segmentation in 26 seconds with a single optimization step and 8 GB peak memory, compared to 18 minutes (SAGA) and 37 minutes (Gaussian Grouping) with 30,000 optimization steps each, representing roughly a 50× speedup. The per-Gaussian label assignment itself takes only 0.4 ms via arg max, enabling interactive adjustment of the background bias parameter.

## Baselines & Comparisons

FlashSplat outperforms all five baselines on both mIOU and mAcc on the NVOS dataset. The closest competitor is SAGA [3] (90.9% mIOU, 98.3% mAcc), which FlashSplat surpasses by 0.9 and 0.3 percentage points respectively; SA3D [4] trails by 1.5 mIOU points. The NeRF-based methods (NVOS, ISRF, SGISRF) are substantially weaker, with NVOS [37] achieving only 39.4% mIOU. Beyond accuracy, the most striking advantage is computational: FlashSplat requires a single closed-form step (26 s total, 8 GB memory) versus 30,000 gradient-descent iterations for SAGA (18 min, 15 GB) and Gaussian Grouping (37 min, 34 GB), yielding a ~50× wall-clock speedup and half the peak memory of SAGA. Gaussian Grouping [53] is not included in the NVOS accuracy table but is compared on computation cost, where FlashSplat is ~85× faster in total pipeline time.

## Relation to Prior Work

This paper departs from the dominant paradigm in 3DGS segmentation (SAGA, Gaussian Grouping) that relies on iterative gradient descent over 30,000 steps to distill 2D mask features into per-Gaussian embeddings before classification. The key conceptual departure is recognizing that the alpha-blending composition in 3DGS rasterization renders the segmentation objective linear in the Gaussian labels, reducing the problem to a closed-form weighted majority vote rather than a learned classifier. It also contrasts with the simpler projection-based criterion of SAGS, which ignores the accumulated alpha contribution of each Gaussian and thus cannot handle occlusion or partial visibility. The method inherits the 3DGS representation and SAM-based 2D mask pipeline from prior work but replaces the entire optimization stage with a single-step linear programming solution.

## Why It Matters / Open Questions

The 50× speedup (30 seconds vs. ~25 minutes) and global optimality guarantee make 3DGS segmentation practical for interactive editing workflows (object removal, inpainting) where iterative re-optimization is prohibitive. The background bias parameter provides a simple, interpretable knob for trading off foreground completeness against background cleanliness, which is useful across diverse downstream tasks. Limitations include dependence on a pre-reconstructed 3DGS scene, sensitivity to the quality of SAM-generated 2D masks, and the fact that the linear formulation assumes fixed Gaussian parameters (no joint optimization of geometry and labels). Open questions include whether the approach extends to dynamic 3DGS scenes, whether the linear structure can be exploited for other per-Gaussian property estimation tasks, and how performance degrades with very sparse view coverage.

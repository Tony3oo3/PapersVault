## Problem

All-in-one image restoration models that mix all degradation types during training suffer severe per-task performance drops (up to 5.32 dB) due to conflicts between unrelated degradations, while training separate single-task models sacrifices generalization and requires users to manually select the correct model. No prior work has quantitatively characterized the relationships between different image degradations to guide how tasks should be jointly trained.
![Teaser figure](../imgs/ECCV20241863/cropped_page1_idx0.webp)

## Input / Output

The method takes a single degraded RGB image of unknown degradation type as input and produces a restored image. At inference, the input is first self-augmented by cropping into multiple small patches to estimate its deep degradation feature distribution (GGD parameters), which then drives automatic selection of the appropriate grouped model without any explicit degradation classification module. Additionally, the KL divergence between the input's GGD and the selected group's GGD provides a pre-inference prediction of expected restoration quality, flagging out-of-distribution inputs (e.g., haze) that the model cannot handle.

## Method

GRIDS first quantifies pairwise degradation similarity by extracting deep degradation representations (DDR) from a pretrained SRResNet, fitting a Generalized Gaussian Distribution to each degradation's feature set, and computing log-KL divergence to build an n×n similarity matrix. A binary-search-and-depth-first-search algorithm then finds the minimum number of groups (m) such that the maximum per-task performance drop within each group stays below a threshold δ, using the similarity matrix for coarse pre-filtering to minimize training cost. Each group is trained as a separate mix-training model (using SRResNet or Restormer backbones), and at inference an adaptive selection mechanism computes KL divergence between the input image's estimated GGD and each group's average GGD to route the image to the best-matching model. In experiments, 11 degradation types are partitioned into 4 groups, yielding an average 2.24 dB improvement over the all-mix baseline and a 0.09 dB average gain over single-task upper-bound models.

## Results

On DIV2K-Valid, GRIDS with the Restormer backbone achieves an average PSNR of 35.22 dB across 11 degradation types, surpassing the single-task upper bound (35.13 dB) by 0.09 dB and the mix-training baseline (32.98 dB) by 2.24 dB. With the SRResNet backbone, GRIDS reaches 33.32 dB average PSNR, exceeding the upper bound by 0.05 dB and the baseline by 1.44 dB. The 11 degradations are partitioned into 4 groups (63.6% compression rate), and the maximum per-task performance drop relative to the upper bound is kept within the 0.7 dB threshold for the Restormer configuration.

## Baselines & Comparisons

GRIDS (Restormer) outperforms all all-in-one baselines by a wide margin: +13.09 dB over RealESRGAN (22.13), +10.26 dB over AirNet (24.96), +3.18 dB over IDR (32.04), +4.01 dB over AMRNet (31.21), and +2.01 dB over the retrained RealESRNet (33.21). Against the mix-training baseline (Restormer, 32.98 dB), GRIDS gains 2.24 dB on average, with the largest per-task improvement of +5.23 dB on Motion Blur and +4.58 dB on SR. Notably, GRIDS also exceeds the single-task upper bound (Restormer, 35.13 dB) by 0.09 dB on average, meaning grouped training of correlated degradations can slightly benefit individual tasks. With the lighter SRResNet backbone, GRIDS (33.32 dB) still surpasses the retrained RealESRNet (33.21 dB) and the mix-training baseline (31.88 dB) by 1.44 dB, while matching the single-task upper bound (33.20 dB) within 0.05 dB.

## Relation to Prior Work

GRIDS sits at the intersection of multi-task learning (MTL) task-grouping methods and image restoration. It builds directly on deep degradation representations (DDR) discovered in SR networks [27] and the Generalized Gaussian Distribution (GGD) statistical modeling from SRGA [28], repurposing them from a generalization-assessment tool into a quantitative degradation-similarity measure. The grouping search algorithm adapts the binary-search + depth-first-search strategy from TAG [10] for MTL task grouping, but operates over a pre-filtered candidate space derived from the similarity matrix rather than raw task-affinity scores. Conceptually, it departs from prior all-in-one restoration methods (RealESRGAN, AirNet, IDR, AMIR-Net) that either mix all degradations in a single network or handle only 3–4 degradation types with learned embeddings, by instead partitioning 11 degradations into 4 correlated groups and training one model per group.

## Why It Matters / Open Questions

The first quantitative, statistically-grounded measure of degradation similarity provides a reusable tool for the restoration community to reason about which degradations can be jointly trained without conflict. The practical adaptive model selection mechanism—choosing the right group at inference via KL divergence without an explicit classifier—addresses a real deployment bottleneck for multi-degradation systems. Limitations include reliance on DDR features extracted from a single pretrained SRResNet, local non-monotonicity in the similarity matrix that can cause grouping errors for close-distance pairs, and evaluation on only 11 degradations with 256×256 patches. Open questions include whether the framework scales to dozens of degradation types, whether the GGD modeling is the right statistical family for all degradation families, and whether the small but consistent exceedance of single-task upper bounds (≈0.05–0.09 dB) reflects a genuine positive-transfer effect or an artifact of the specific training protocol.

## Problem

Gamut expansion—recovering out-of-gamut color values lost when converting from ProPhoto RGB to sRGB—is an ill-posed inverse problem. Existing methods rely on external metadata such as out-of-gamut masks or partial target pixel values, which are typically unavailable in real-world scenarios where only sRGB images are accessible. Additionally, general-purpose restoration networks introduce distortion to in-gamut pixels and are too large for deployment on resource-constrained devices.
![Teaser figure](../imgs/ECCV20241909/cropped_page1_idx0.webp)

## Input / Output

The method takes a single sRGB image as input with no auxiliary information (no out-of-gamut mask, no metadata from the target wide-gamut image) and produces a ProPhoto RGB image as output. Training uses 128×128 patches cropped from images ranging from 2000×3000 to 4000×6000 resolution; at inference, larger images are processed in 1024×1024 tiles. The output preserves in-gamut pixel values unchanged while restoring the clipped out-of-gamut values to their original ProPhoto RGB range.

## Method

The paper formulates gamut expansion as a root-finding problem and learns an equilibrium transformation g(x,z)−z=0 via a shallow input-injection network (two conv layers with Tanh activation, channel attention, and a residual connection). An Implicit Recurrent Mechanism (IRM) replaces explicit recurrence: an Anderson acceleration solver iteratively updates latent features to a fixed point, equivalent to infinite recurrent layers, while requiring only O(1) GPU memory during backpropagation. Positional information is injected via Fourier features of a coordinate map. For backpropagation, the inverse Jacobian is approximated by setting the Neumann series to the identity matrix (G=I), yielding Jacobian-free gradients that avoid the O(N³) cost of explicit inversion. The entire model contains only 40K parameters, making it suitable for deployment on smartphones and laptops.

## Results

On the GE dataset, the proposed method achieves 52.78 dB PSNR and 0.9931 SSIM on the full image, and 52.23 dB PSNR and 0.9934 SSIM on out-of-gamut regions, using only 40K parameters and no external metadata. This outperforms the strongest general restoration baseline (SwinIR, 3.13M params) by 0.48 dB on full-image PSNR and 0.33 dB on out-of-gamut PSNR, while also surpassing the metadata-dependent GamutMLP (4.96K params) by 0.24 dB on full-image PSNR. The method requires only 2.6 GB GPU memory at 1024×1024 inference, compared to 26–28 GB for Restormer and SwinIR.

## Baselines & Comparisons

Against the two general restoration baselines that require no metadata, the proposed method clearly wins: it surpasses SwinIR (3.13M params) by 0.48 dB PSNR on full images and 0.33 dB on out-of-gamut regions, and beats Restormer (26.13M params) by 0.55 dB and 0.72 dB respectively, all while using 78× fewer parameters than Restormer. Compared to the metadata-dependent methods, the proposed method outperforms GamutNet (4.37M params, uses out-of-gamut mask) by 0.11 dB on full-image PSNR and 0.52 dB on out-of-gamut PSNR, and edges out GamutMLP (4.96K params, uses pixel-level metadata) by 0.24 dB on full-image PSNR and 0.04 dB on out-of-gamut PSNR—despite requiring no external information at all. The I-Sampled method, which optimizes per-test-sample with metadata, lags far behind at 49.78 dB. Overall, the proposed method achieves the best full-image PSNR (52.78 dB) and the best out-of-gamut PSNR (52.23 dB) among all methods that do not rely on metadata, with a model size of only 40K parameters.

## Relation to Prior Work

This paper applies the Deep Equilibrium Model (DEQ) framework of Bai et al. (NeurIPS 2019) to gamut expansion, a task previously addressed by methods that rely on external information such as out-of-gamut masks (GamutNet) or wide-gamut metadata (I-Sampled, GamutMLP). The key conceptual departure is formulating the inverse color-space mapping as a fixed-point problem solvable by a shallow input-injection network with an implicit recurrent mechanism, thereby eliminating the need for any auxiliary signals. Within the broader implicit deep learning literature (Neural ODEs, DEQ networks), this is the first application to color/gamut restoration, repurposing the Anderson acceleration solver and Jacobian-free backpropagation to a pixel-level imaging task.

## Why It Matters / Open Questions

The practical significance lies in removing the metadata/mask dependency that makes prior gamut-expansion methods infeasible in real-world pipelines where only sRGB images are available, while achieving competitive accuracy with 40K parameters and O(1) training memory. However, the evaluation is confined to a single dataset (GE) and a single color-space pair (sRGB→ProPhoto RGB), leaving open whether the equilibrium formulation generalizes to other gamut pairs or to more complex degradation models. The aggressive Neumann-series simplification (setting G=I) trades gradient accuracy for speed, and its impact on convergence quality at scale remains unexplored.

## Problem

Existing video quality enhancement methods either depend on future frames (introducing uncontrolled latency) or are too computationally heavy for real-time processing, making them unsuitable for online scenarios like video conferencing and cloud gaming. No prior method addressed the Online-VQE problem of enhancing compressed video using only past and current frames while maintaining real-time frame rates on high-resolution content.

## Input / Output

The method consumes a sequential stream of HEVC/H.264-compressed frames (tested from 240P up to 2K resolution) along with per-frame QP values, using only the current frame and a window of past frames (Reference Frame Window) for inference. It outputs a single enhanced frame per input frame in a frame-to-frame manner, targeting >40 FPS on 720P video. At inference, the deep enhancement network is replaced by pre-computed Spatial-Temporal LUTs (228 MB storage), so the output is produced via direct memory lookups rather than convolutional computation.

## Method

STLVQE introduces a Module-Agnostic Feature Extractor (MAFE) that computes a single shared latent feature per frame, reused across the propagation, alignment, and enhancement modules to eliminate redundant feature extraction. A Temporal Cache stores previously extracted features and enhanced frames, so reference frames selected by QP-based criteria from a Reference Frame Window require no re-computation. Alignment uses a lightweight offset predictor (replacing optical flow) to deform reference frames, and a spatial compensation network provides preliminary enhancement before the final stage. The key novelty is the Spatial-Temporal Look-up Table (ST-LUT), which splits into S-LUTs (spatial queries with rotation ensemble) and T-LUTs (temporal queries correlating aligned reference and current frame pixels), replacing the deep enhancement network with fast memory lookups at inference. Training is two-stage (Charbonnier loss followed by L2 fine-tuning) with learnable step-size quantization (LSQ) to make the network LUT-compatible, after which all convolutional layers in the enhancement branch are permuted into lookup tables.

## Results

On the MFQE 2.0 test set at QP=37, STLVQE achieves ΔPSNR of 0.49 dB and ΔSSIM of 1.03×10⁻² with a latency of only 24.7 ms per 720P frame (≈109.9 FPS), using 98 GFLOPs and 398K parameters plus 228 MB LUT storage. It outperforms all single-frame baselines (DCAD: 0.32/0.67, DnCNN: 0.26/0.58, DS-CNN: 0.30/0.63) by 0.17–0.23 dB in ΔPSNR while being 1.4–2.6× faster. Against high-latency multi-frame methods (MFQE 2.0: 0.56/1.09 at 320 ms; RFDA: 0.91/1.62 at 313 ms), STLVQE trades 0.07–0.42 dB ΔPSNR for a 13–13× latency reduction, making it the only method achieving >40 FPS on 720P video.

## Baselines & Comparisons

STLVQE outperforms all six single-frame baselines (ARCNN, DnCNN, DS-CNN, Li et al., DCAD, RNAN) on both ΔPSNR and ΔSSIM across all five QP levels, with the largest margin over DCAD (+0.17 dB ΔPSNR, +0.36×10⁻² ΔSSIM at QP37) while also being 1.4× faster (24.7 ms vs. 34.3 ms). Against the four bidirectional multi-frame methods (MFQE 1.0, MFQE 2.0, STDF, PSTQE), STLVQE sacrifices 0.07–0.20 dB ΔPSNR but reduces latency by 13–50× (e.g., 24.7 ms vs. 320.1 ms for MFQE 2.0, 24.7 ms vs. 1249.8 ms for PSTQE). The strongest multi-frame baselines RFDA (0.91/1.62) and BasicVSR++ (0.95/1.80) achieve substantially higher quality but require 313 ms or the full video (FV-Required), making them infeasible for online use. STLVQE's ΔSSIM exceeds MFQE 2.0 at all QP values (e.g., 1.03 vs. 1.09 at QP37), indicating more stable structural restoration. The paper positions STLVQE as the only method achieving >40 FPS on 720P, a threshold critical for real-time streaming applications.

## Relation to Prior Work

This paper extends two distinct research threads: the propagation-alignment-enhancement framework established by BasicVSR for video processing, and the LUT-based inference acceleration introduced by SR-LUT for super-resolution. It departs from prior multi-frame VQE methods (MFQE 1.0/2.0, STDF, RFDA, BasicVSR++) by enforcing a causal constraint (only past and current frames), redesigning all three modules with a shared Module-Agnostic Feature Extractor to eliminate redundant computation, and replacing the enhancement network with Spatial-Temporal Look-up Tables. The Temporal Cache and QP-based Reference Frame Window are practical engineering choices that avoid the expensive optical flow or recursive fusion mechanisms used by prior temporal VQE methods.

## Why It Matters / Open Questions

This is the first method to explicitly target online (causal, real-time) video quality enhancement, filling a gap between fast single-frame methods that ignore temporal information and high-quality bidirectional multi-frame methods that cannot operate under streaming latency constraints. The ST-LUT concept—using table lookups to jointly query spatial and temporal pixel neighborhoods—is a reusable idea that could transfer to other real-time video tasks. However, the quality gap to the best offline methods (e.g., RFDA at 0.91 dB vs. STLVQE's 0.49 dB ΔPSNR at QP=37) remains substantial, and the 228 MB LUT storage, while small relative to GPU memory, is non-trivial for edge deployment. Open questions include whether ST-LUTs generalize beyond compression artifact removal and whether the approach scales gracefully to 4K or higher resolutions.

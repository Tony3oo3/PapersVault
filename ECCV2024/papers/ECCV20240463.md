## Problem

Existing multi-label image recognition methods rely on CNNs or transformers that process images as regular grids, making them sub-optimal for capturing irregular and discontinuous regions of interest. CNNs struggle with non-contiguous object parts, while transformers introduce redundant background interference and high computational costs. No prior work had proposed a fully graph convolutional architecture that unifies label embeddings and image patches in a single flexible graph structure for MLIR.
![Teaser figure](../imgs/ECCV20240463/cropped_page1_idx0.webp)

## Input / Output

The model takes an RGB image (evaluated at 224×224, 448×448, or 576×576 resolution), splits it into N patches, and maps each patch to a C-dimensional feature vector via a fully-connected layer. Learnable label embeddings of the same dimension C serve as label nodes alongside patch nodes. The output is a vector of per-class probabilities obtained by applying sigmoid to the sum of logits from both patch nodes and label nodes, supervised by a combination of label smooth loss and asymmetric loss.

## Method

GKGNet is the first fully graph convolutional network for multi-label image recognition, representing both image patches and target labels as nodes in a unified graph processed through four hierarchical stages. The key component is the Group KGCN module, which splits each node's feature vector into G groups and independently performs K-nearest-neighbor search within each group, allowing a destination node to dynamically connect to between K and K×G source nodes depending on object scale. Two graph types are used per stage: Patch-Level Group KGCN for spatial feature extraction among patches, and Cross-Level Group KGCN for message passing from patch nodes to label nodes to capture label-region correlations. Message passing uses group max-relative graph convolution (an extension of DeepGCNs), followed by a residual FFN update. The design maintains the same O(N_S × N_D × C) computational cost as standard KNN GCN while achieving state-of-the-art mAP on MS-COCO and VOC2007 with significantly fewer FLOPs than transformer-based competitors.

## Results

On MS-COCO at 576×576 resolution, GKGNet achieves 87.7 mAP, 82.5 CF1, and 84.2 OF1 with only 34.7M parameters and 40.1G FLOPs, outperforming all prior methods. At 448×448, it reaches 86.7 mAP and 83.3 OF1 with just 21.9G FLOPs, surpassing the next best method (IDA-SwinS(H) at 85.5 mAP) by 1.2% mAP while using less than half the FLOPs. On Pascal VOC2007, GKGNet achieves 96.8 mAP, improving over the previous best (Q2L at 96.1 mAP) by 0.7%. The model also shows a notable 4.9% mAP gain on small objects compared to Q2L, demonstrating the benefit of adaptive graph construction for scale variance.

## Baselines & Comparisons

GKGNet consistently outperforms all 17 compared baselines on MS-COCO across all three resolutions. Against transformer-based methods, GKGNet beats Q2L by 1.2% mAP (87.7 vs 86.5) at 576×576 while using only half the FLOPs (40.1G vs 80.8G) and fewer parameters (34.7M vs 193.6M); it also surpasses C-Tran by 2.6% mAP at the same resolution. Among GCN-based methods, GKGNet improves over TDRG by 1.7% mAP at 576×576 and by 3.7% mAP over ML-GCN at 448×448. Against the strongest transformer-backbone method IDA-SwinS(H), GKGNet gains 1.3% mAP at 576×576 and 1.2% mAP at 448×448 with substantially lower FLOPs. On Pascal VOC2007, GKGNet achieves 96.8 mAP versus Q2L's 96.1 mAP, with particularly large gains on challenging categories like Chair (88.4 vs 84.5) and Table (92.6 vs 89.2). The same-backbone ablation (Table 2) confirms that GKGNet's advantage over C-Tran and Q2L is due to the graph-based design rather than the backbone, as all three use ViG.

## Relation to Prior Work

GKGNet builds directly on ViG (Vision GNN), which first demonstrated that images can be processed entirely as KNN-based graphs without CNNs or transformers, and extends the max-relative graph convolution from DeepGCNs into a group-wise variant. It departs from prior MLIR methods that combine a CNN backbone with a GCN applied only to label embeddings (ML-GCN, KSSNet, ADD-GCN, TDRG) by unifying both patch features and label embeddings in a single graph representation. The key conceptual departure from standard KNN graph construction is the Group KNN mechanism, which splits node features into subgroups to allow each destination node to dynamically connect to a variable number of source nodes, addressing the fixed-neighborhood limitation that prior graph-based MLIR methods inherited from ViG.

## Why It Matters / Open Questions

The demonstration that a fully graph-convolutional pipeline can match or exceed transformer-based MLIR methods at roughly half the FLOPs (40.1G vs. 80.8G at 576×576) offers a practical efficiency argument for graph-based backbones in multi-label settings, particularly where background interference from global attention is a known bottleneck. The generality of Group KNN—showing consistent top-1 gains on ImageNet-1K, CIFAR-10/100, and Flowers with a ViG-Tiny backbone—suggests the mechanism could be adopted beyond MLIR. However, the authors acknowledge they could not test larger-scale models or ImageNet-22K pre-training due to resource constraints, leaving open whether the efficiency advantage persists at scale and whether the approach extends to other graph-structured domains (point clouds, social networks) as they envision.

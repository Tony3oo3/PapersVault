## Problem

Zero-shot object navigation agents pretrained on ImageNav (e.g., ZSON) suffer from semantic neglect: the authors demonstrate that an agent using only Canny-edge features achieves comparable ImageNav success rates to a CLIP-based agent, revealing that the pretraining objective does not force the agent to learn meaningful semantic alignments. This limits performance on tasks requiring fine-grained semantic understanding, such as navigating to a specific object instance rather than any object of a given category.

## Input / Output

During training, the agent receives a 640×480 RGB observation (79° HFOV, 0.88 m height) and a goal image rendered at the goal location; during zero-shot inference, the goal image is replaced by a text description containing both intrinsic attributes (shape, color, material) and extrinsic attributes (surrounding objects). The agent outputs one of six discrete navigation actions (MOVE_FORWARD, TURN_LEFT, TURN_RIGHT, STOP, LOOK_UP, LOOK_DOWN) at each timestep, with an episode succeeding when the agent stops within 0.1 m of a goal viewpoint.

## Method

The PSL agent augments the standard ZSON architecture (learnable ResNet-50 observation encoder + frozen CLIP goal encoder) with a second frozen CLIP encoder on the observation and a Semantic Perception Module (SPM), an MLP bottleneck that condenses the semantic correspondence between the goal and observation CLIP embeddings into a lower-dimensional feature fed to a recurrent PPO policy. Training employs two key strategies: (1) entropy-minimized goal view selection, which renders multiple yaw/tilt views at the goal and picks the one whose CLIP image embedding yields the lowest-entropy distribution over six object categories, ensuring semantically clear supervision; and (2) perspective reward relaxation, which drops the strict pitch-matching requirement so the agent is rewarded for reaching the goal location and aligning only in the horizontal (Y-axis) plane. At inference, a Semantic Expansion Inference scheme bridges the image-text modality gap by maintaining a diverse support set of ~0.1M CLIP image embeddings and computing a similarity-weighted retrieval to produce a goal embedding at the same semantic granularity as training.

## Results

On the HM3D ObjectNav benchmark, PSL achieves 42.4% SR and 19.2% SPL, outperforming the ZSON baseline by 16.9% in SR (42.4% vs. 25.5%) and surpassing the best LLM-based method ESC by 3.2% SR. On the newly introduced InstanceNav task (text-goal setting), PSL reaches 16.5% SR and 7.5% SPL, improving over ZSON by 5.9% SR. Under the InstanceNav image-goal setting, PSL achieves 23.0% SR and 11.4% SPL, a +8.4% SR gain over ZSON and approaching the supervised OVRL-V2 method (24.8% SR, 11.8% SPL) despite using a smaller ResNet-50 backbone.

## Baselines & Comparisons

PSL outperforms all ten compared baselines on at least one benchmark. On ObjectNav, PSL (42.4% SR) beats the strongest LLM-based competitor ESC [64] by 3.2% SR and PixelNav [6] by 4.5% SR, while also exceeding mapping-based methods L3MVN [62] (+7.2%) and ProcTHOR [9] (+29.2%). Against the primary zero-shot baseline ZSON [38], PSL gains +16.9% SR on ObjectNav, +5.9% SR on InstanceNav text-goal, and +8.4% SR on InstanceNav image-goal. On the InstanceNav text-goal track, PSL (16.5% SR) substantially outperforms ESC [64] (+10.0%), CoW [11] (+14.7%), and OVRL [58] (+12.8%), confirming that end-to-end semantic learning surpasses LLM-guided or map-based exploration for instance-level disambiguation. On InstanceNav image-goal, PSL (23.0% SR) surpasses FGPrompt [56] by +13.1% SR and the supervised OVRL-V2 [57] is the only method that edges out PSL in SR (24.8% vs. 23.0%), though PSL nearly matches its SPL (11.4% vs. 11.8%) with a much smaller backbone.

## Relation to Prior Work

This paper builds directly on ZSON (Majumdar et al., NeurIPS 2022), which established the paradigm of pretraining on ImageNav with a CLIP goal encoder and transferring to ObjectNav via text embeddings. The key conceptual departure is the identification of 'semantic neglect': pilot experiments show that ImageNav can be solved with purely geometric/layout cues (Canny edges) without learning meaningful semantic alignment, undermining the assumption that the pretraining objective teaches the agent to perceive object semantics. The PSL method addresses this by adding a Semantic Perception Module, entropy-minimized goal view selection, and perspective reward relaxation during training, plus a semantic expansion inference scheme at test time. It also deliberately positions against LLM-based and mapping-based approaches (ESC, PixelNav, L3MVN), demonstrating that a simpler RL agent with better semantic training can outperform them without requiring large language models, depth sensors, or GPS.

## Why It Matters / Open Questions

The semantic neglect finding challenges a core assumption in the zero-shot navigation literature—that ImageNav pretraining inherently teaches semantic understanding—which has implications for how the community designs pretraining objectives for embodied agents. The InstanceNav benchmark is a practical and meaningful extension that tests whether agents can distinguish specific object instances rather than merely finding any object of a category, a gap that matters for real-world deployment. However, absolute success rates remain modest (42.4% SR on ObjectNav, 16.5% on InstanceNav text-goal), and evaluation is limited to the HM3D environment, leaving open questions about generalization to other scene distributions and whether the semantic expansion inference scheme scales to truly open-vocabulary settings beyond the six HM3D object categories.

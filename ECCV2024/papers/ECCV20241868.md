## Problem

CLIP-based face anti-spoofing (e.g., FLIP) achieves strong performance by mapping class labels to text prompts, but struggles with cross-domain generalization because recording-domain discrepancies (camera quality, lighting, resolution) are multi-factorial and hard to capture with hand-crafted text descriptions, while naively learning fine-grained domain representations can contradict the genuine-vs-spoof classification objective. This paper asks how to improve CLIP's domain generalizability for FAS from a prompt learning perspective that handles both low-level recording-domain variance and high-level attack-type variance simultaneously.

## Input / Output

The method takes a single aligned face image (224×224, aligned via FAN landmarks using nose and eye points) as input and outputs a binary real/spoof decision by selecting the class prompt with the highest cosine similarity to the image embedding. During training, the model additionally consumes per-sample attack-type labels (e.g., printing, replay, 3D mask) to construct fine-grained textual prompts, and per-domain labels to form domain-specific and domain-generalized prompt embeddings. At inference, all samples in a batch are assumed to share the same domain, and only the real/spoof class prompts are used for the final prediction.

## Method

BUDoPT introduces a two-level prompt tuning strategy within CLIP. For recording-domain generalization, a context-aware prompt learner (11-layer ViT + 2-layer MLP) generates domain prompts from visual features, combining context patches from a shallow layer (preserving low-level recording artifacts) with content patches from a deeper layer; a CLIP-style contrastive loss pulls image embeddings toward a domain-generalized prompt (averaged across all source domains) while pushing them away from domain-specific prompts, reinforced by an adversarial discriminator that identifies domain traces and a Jensen-Shannon divergence constraint. For attack-type discriminability, fine-grained textual prompts (e.g., 'a fake face photo and it is the printing attack') are used to train the visual encoder via a text cross-entropy loss, encouraging it to detect subtle artifacts specific to each attack instrument. Training proceeds in two stages: first the visual encoder is fine-tuned with attack-type prompts, then it is frozen while the prompt learner and discriminator are trained for domain generalization with alternating freezing.

## Results

Under the leave-one-out protocol (P1) with CelebA-Spoof as supplementary training data, BUDoPT achieves an average HTER of 0.91% across four cross-domain settings (OCI→M: 0.40%, OMI→C: 0.26%, OCM→I: 1.38%, ICM→O: 1.60%), substantially outperforming the best CLIP-based baseline FLIP-MCL (3.01% avg HTER) by over 70%. Without supplementary data, BUDoPT still achieves 2.62% avg HTER, beating the strongest non-CLIP baseline TTDG-V (7.84%) by a factor of ~3. In the one-to-one protocol (P2) with only a single source dataset, BUDoPT reaches 1.43% avg HTER with CelebA-Spoof, compared to 5.63% for FLIP-IT and 8.40% for FLIP-MCL.

## Baselines & Comparisons

BUDoPT decisively outperforms the FLIP family of CLIP-based FAS methods: with CelebA-Spoof, it reduces average HTER from 3.01% (FLIP-MCL) and 3.06% (FLIP-IT) to 0.91%, a >70% relative improvement. Against the strongest non-CLIP baselines, BUDoPT (without supplementary data) achieves 2.62% avg HTER versus 7.84% for TTDG-V, 8.57% for LDCformer, and 9.80% for SSAB-R. Among prompt-learning variants, BUDoPT's full method (0.91%) beats CoCoOp-based (2.53%) and CoOp-based (2.61%) adaptations by 64% and 65% respectively, confirming that the adversarial domain-generalized prompt and context-aware domain clue are critical. In the low-data one-to-one setting (P2), BUDoPT (1.43% with CelebA-Spoof) outperforms FLIP-IT (5.63%) and FLIP-MCL (8.40%) across 10 of 12 transfer scenarios. For unseen attack types (P4, WMCA 3D mask), BUDoPT trained on only CASIA-FASD achieves 9.20% HTER, beating DiVT-M (22.36%) and DGUA-FAS (20.62%) trained on four datasets. In the device-variance-only setting (P5), BUDoPT achieves 0% error on both OULU-NPU protocols 3 and 4, matching or exceeding DC-CDN, RAEDFL, TranFAS, and LDCFormer.

## Relation to Prior Work

This paper extends the CLIP-based face anti-spoofing framework introduced by FLIP (Srivatsan et al., ICCV 2023) by replacing its simple class-label text prompts with a two-level prompt architecture: a learned visual domain-invariant prompt (inspired by CoCoOp's conditional prompt mechanism) for recording-setting generalization, and a fine-grained textual prompt for attack-type discrimination. It departs from prior domain-generalization FAS methods (adversarial domain adaptation, meta-learning, style disentanglement) by framing domain invariance as a prompt-learning problem within a frozen VLM, and contrasts with CFPL (Liu et al., CVPR 2024) by deriving domain-invariant prompts from CLIP-style contrastive objectives rather than from AdaIN-style style vectors. The 'bottom-up' decomposition—treating low-level recording variance and high-level attack-type variance as distinct prompt levels—is the paper's core conceptual contribution over both FLIP and generic prompt-tuning methods (CoOp, CoCoOp).

## Why It Matters / Open Questions

The work demonstrates that prompt tuning in a pretrained VLM can substantially close the cross-domain gap in FAS, achieving near-perfect HTER (0.91 avg) with supplementary data and strong results even in single-source-domain settings, which is practically relevant for deployment where target-domain data is unavailable. A key open question the paper itself highlights is the sensitivity to domain partition granularity (dataset-level vs. device-level), suggesting that an adaptive partition strategy could further improve generalization. The finding that intuitive textual domain descriptions actively harm performance (contradicting the common practice of enriching prompts with context) is a useful caution for VLM-based FAS design. Broader implications include whether the bottom-up prompt decomposition transfers to other fine-grained VLM tasks beyond FAS.

## Problem

Existing autonomous agent benchmarks are confined to web (HTML/DOM-based) or mobile environments and cannot evaluate agents on native desktop applications or tasks spanning multiple application types. There is no dataset or benchmark that measures an agent's ability to generate executable automation code from visual screen understanding across diverse operating systems and web platforms.
![Teaser figure](../imgs/ECCV20241814/cropped_page0_idx0.webp)

## Input / Output

The task takes a single-screen screenshot (from macOS, Linux, Windows, or a web page) paired with a visually-grounded or text-based natural language instruction, and produces a PyAutoGUI Python script encoding a sequence of mouse and keyboard actions. Coordinate-dependent actions (click, dragTo, moveTo) require precise pixel locations, while keyboard actions (press, hotkey, write) specify key sequences or typed text. The action space spans 11 action types, with click dominating at ~64% of instances, and tasks range from single-step (e.g., 'Play the next song') to multi-step (e.g., 'Send an email to John Doe mentioning the time and place to meet').

## Method

The paper introduces the OmniACT dataset (9,802 human-annotated screen-instruction-script triples) and the DetACT module, which converts a UI screenshot into a structured textual representation via a three-stage pipeline: EasyOCR for text extraction, SAM segmentation followed by SSIM-based icon template matching against 1,600 labeled icons, and RGB-averaging-based color bucketing into 11 categories. These extracted UI elements are filtered by GPT-4 for task relevance and concatenated into a prompt alongside the task description for LLM or VLM backbones. Evaluation uses two custom metrics—Sequence Score (exact action-sequence match with length weighting) and Action Score (which applies spatial penalties for coordinate misses scaled by bounding-box size, key-set mismatches, and BLEU-based text penalties)—rather than standard code similarity metrics. Baselines span prompt-based LLMs (GPT-4, CodeLLaMA-34B, LLaMA, Vicuna), QLoRA-fine-tuned LLMs, and multimodal models (LLaVA, Gemini-Pro, GPT-4V), with GPT-4V achieving the best action score of 17.02 versus 80.14 for humans.

## Results

On the OmniACT benchmark, GPT-4V achieves the highest Action Score (AS) of 17.02 and Sequence Score (SS) of 38.72, outperforming all other baselines. Among text-only LLMs, GPT-4 leads with SS=32.75 and AS=11.60, while CodeLLaMA-34B is the best open-source text-only model (SS=10.09, AS=3.72). Fine-tuning LLaMA-13B and Vicuna-13B with QLoRA improves their SS from ~4.8–5.4 to ~8.8–8.9, but they remain far below prompt-based GPT models. Human evaluators achieve SS=82.23 and AS=80.14, meaning even the best model (GPT-4V) reaches only ~21% of human proficiency in generating executable action scripts.

## Baselines & Comparisons

Among prompt-based text-only LLMs, GPT-4 (SS=32.75, AS=11.60) substantially outperforms GPT-3.5-turbo (SS=22.85, AS=7.89) and all open-source models, with CodeLLaMA-34B (AS=3.72) being the strongest open-source text-only baseline. Fine-tuning LLaMA-13B and Vicuna-13B via QLoRA improves their SS by ~85% (4.80→8.92 and 5.44→8.78) but still falls well short of GPT-3.5-turbo's prompt-only performance. The multimodal models show a clear advantage: GPT-4V (AS=17.02) surpasses GPT-4 (AS=11.60) by 46% in Action Score, and Gemini-Pro (AS=11.46) nearly matches GPT-4, confirming that visual input is critical for coordinate prediction. LLaVA-v1.5-13B (AS=8.19) outperforms LLaVA-v1.5-7B (AS=5.82) but both remain below GPT-3.5-turbo. The most striking comparison is against human performance (AS=80.14): even GPT-4V achieves only ~21% of human proficiency, and all text-only LLMs score below 15%, highlighting the substantial gap between current agents and human-level computer task execution.

## Relation to Prior Work

This paper departs from the dominant paradigm of HTML/DOM-based web agents (Mind2Web, WebArena, VisualWebArena) by requiring visual screenshot input and generating PyAutoGUI code rather than DOM-level actions, thereby extending the task to native desktop applications on macOS, Windows, and Linux. It also moves beyond mobile-specific UI understanding models (UIBert, Pix2Act, AITW) by operating at the OS level with a unified cross-platform action space. The DetACT module repurposes existing components (EasyOCR, SAM, SSIM icon matching) into a novel pipeline for converting arbitrary UI screenshots into structured textual descriptions, filling a gap left by prior work that relied on view hierarchies or HTML source.

## Why It Matters / Open Questions

OmniACT is the first benchmark to unify desktop and web automation under a single code-generation formulation, and the finding that even GPT-4V reaches only ~21% of human action score (17.02 vs 80.14) underscores that current multimodal LLMs are far from reliable computer operators. The significant performance gap between text-only LLMs and their multimodal counterparts highlights the critical role of visual grounding for UI tasks, motivating future work on vision-language models with stronger spatial reasoning. Key open questions include whether single-screen tasks generalize to multi-step, cross-application workflows, and whether the DetACT-style preprocessing can be replaced by end-to-end visual understanding.

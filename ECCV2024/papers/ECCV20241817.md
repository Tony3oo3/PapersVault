## Problem

Image restoration methods optimized for human perception often fail to improve downstream high-level vision tasks (e.g., object detection) due to a distribution gap between restoration output and the input domain of pre-trained vision models. Existing task-driven image restoration (TDIR) methods require paired training data and retraining of either the restoration or high-level vision network, which is impractical when dealing with frozen models (e.g., diffusion-based restorers, large vision-language models) or when paired data is unavailable in real-world scenarios.

## Input / Output

The method takes a degraded RGB image (hazy or low-light) and its restoration output from a frozen pre-trained restoration network (AODNet or SCI) as joint input, and produces a single translated RGB image optimized for a frozen high-level vision model (YOLOv3, YOLOv5, or CLIP). No paired degraded-clean image data is required; training uses only unpaired degraded and clean image sets. The only trainable component is a lightweight translator network (0.21M–6.10M parameters), while both the restoration and high-level vision networks remain frozen throughout training and inference.

## Method

VaT models the joint distribution P(I_R, I_HQ) between restoration output and high-level vision input via variational inference, then simplifies the resulting objective to a maximum marginal likelihood term that focuses only on task-relevant objects rather than all objects in the scene. The architecture consists of a Gated Fusion Module that adaptively blends the degraded input and restoration output via learned sigmoid weights (handling cases where restoration degrades quality), followed by a U-shape Transformation Module built on transformer blocks for global-context image translation. Training combines a modified cycle-consistency loss (enforcing consistency between the fusion output and the translated output through forward and backward mappings) with an uncertainty-guided self-training strategy that generates pseudo-labels via NMS-filtered predictions from the frozen detector, applies NUQ-based uncertainty filtering, and constructs mixup-augmented supervision to maximize the marginal likelihood of task-relevant objects without any ground-truth labels.

## Results

On the real-world RTTS dehazing-for-detection benchmark, VaT achieves 49.48 mAP (with pre-trained AODNet), outperforming the best unsupervised baseline SPR (33.51 mAP) by ~16 points and the best supervised TDIR method AD-YOLO (45.47 mAP) by ~4 points. On the synthetic VOCh-test set, VaT reaches 84.02 mAP (retrained AODNet), matching or slightly exceeding all supervised baselines. For low-light enhancement for detection, VaT attains 0.600 mAP on VOCd and 0.499 mAP on ExDark, surpassing the best supervised method (IA-YOLO: 0.578 / 0.475) and all unsupervised counterparts.

## Baselines & Comparisons

VaT decisively outperforms all five unsupervised image-translation baselines (CycleGAN, CUT, MSPC, SRC, SPR) on RTTS by 10–20 mAP points, confirming that global unpaired translation fails under complex real-world haze while VaT's object-focused marginal likelihood succeeds. Against supervised TDIR methods, VaT surpasses AD-YOLO [48] by ~4 mAP on RTTS (49.48 vs. 45.47) and IA-YOLO [32] by ~7 mAP (49.48 vs. 42.62), while on the synthetic VOCh-test it is within 0.5 mAP of AD-YOLO (84.02 vs. 84.11 with †). For low-light detection (Table 3), VaT (0.600 mAP on VOCd, 0.499 on ExDark) beats the clean-image YOLOv5 baseline [19] (0.551 / 0.488), the supervised IA-YOLO [31] (0.572 / 0.475), and the unsupervised EnlightenGAN [18] (0.568 / 0.389) across both datasets. The only marginal loss is on VOCh-test where AD-YOLO edges VaT by 0.09 mAP (84.11 vs. 84.02), a negligible gap on synthetic data where the distribution gap is smaller. Overall, VaT is the only method that simultaneously exceeds the clean-image detection baseline and all TDIR baselines on the real-world RTTS set without any retraining of the restoration or detection networks.

## Relation to Prior Work

This paper builds on the cycle-consistency paradigm from CycleGAN [60] and the broader family of unpaired image-to-image translation methods (CUT, MSPC, SRC, SPR), but repositions them through a variational inference lens to derive a principled objective for Task-Driven Image Restoration (TDIR). It departs from prior TDIR methods (union approaches like IA-YOLO and separate approaches like AODNet-based pipelines) by eliminating the need to retrain either the restoration or high-level vision network, instead inserting a lightweight translator. The key conceptual departure is the 'maximum marginal likelihood' simplification—restricting the likelihood term to task-relevant objects rather than the full image—which the authors show explains why global unpaired translation methods fail on complex real-world degradation.

## Why It Matters / Open Questions

The practical significance is that VaT can be plugged in front of frozen, potentially very large models (diffusion-based restorers, CLIP, YOLO) without any retraining, which is increasingly relevant as vision models grow too large or proprietary to fine-tune. The variational derivation provides a clean theoretical unification showing that union TDIR methods optimize only the likelihood term while separate methods optimize only the reconstruction term, and that both are necessary. Limitations include reliance on unpaired clean images from the same domain, evaluation on relatively small-scale detection/classification tasks, and the added inference cost of the translator. The authors note future work on extending to multimodal large language models, suggesting the approach has not yet been stress-tested at scale.

## Problem

Existing fine-grained sketch-based image retrieval (FG-SBIR) systems are trained on single-view sketch-photo pairs and fail when a query sketch is drawn from a viewpoint different from the target photo, dropping top-1 accuracy by 27.15% in a pilot study. No prior work addresses this 'view' problem, and existing datasets lack multi-view sketch annotations or view-specific labels needed to build view-aware retrieval.
![Teaser figure](../imgs/ECCV20241516/cropped_page1_idx0.webp)

## Input / Output

The system takes a 2D rasterised sketch (H×W×3) as query and retrieves from a gallery of multi-view 2D projections rendered from 3D object shapes (e.g., 11 views at 0°–360°). The encoder outputs two 128-dimensional vectors per input: a content feature f_c and a view feature f_v. At inference, view-agnostic retrieval uses only f_c, while view-specific retrieval uses the element-wise sum f_vs = f_c + f_v, enabling a simple switch between modes without retraining.

## Method

The core contribution is a cross-modal view-aware disentanglement framework that decomposes any input (sketch or photo) into content and view semantic components using a shared CNN/ViT backbone with two FC heads. To overcome the absence of multi-view sketch data, the method leverages unpaired multi-view 2D projections of 3D shapes (from ShapeNet) to condition the encoder on view-awareness via two photo-only objectives: an instance-consistency loss that pulls content features of different views of the same object together, and a cross-view reconstruction loss that reconstructs one view by combining the content of another view with its own view feature. A cross-modal view-consistency loss then bridges this photo-side view knowledge to sketches by pulling the view features of matched sketch-photo pairs closer in embedding space. Training combines five objectives (two cross-modal triplet losses, instance-consistency, cross-view reconstruction, and view-consistency) with a VGG-16 or PVT backbone, and the disentanglement design ensures that the content and view features remain coherent for the combined view-specific feature.

## Results

On the SoTA++ protocol (all methods retrained on identical curated data), the proposed method with PVT backbone achieves 0.702 mAP@all and 0.771 P@100 for view-agnostic chair retrieval, and 70.26% Top-1 / 92.86% Top-10 for view-specific chair retrieval. For lamps, it reaches 0.681 mAP@all (view-agnostic) and 68.32% Top-1 (view-specific). With the simpler VGG-16 backbone, the method still attains 0.615 mAP@all and 60.71% Top-1 on chairs, outperforming the strongest SoTA (StrongPVT at 0.569 mAP / 55.93% Top-1) by a clear margin. Ablation shows removing the cross-view reconstruction loss drops view-specific Top-1 by 4.45% and view-agnostic mAP by 0.05.

## Baselines & Comparisons

The proposed method (Ours-PVT) outperforms all SoTA++ baselines on both view-agnostic and view-specific retrieval across chairs and lamps. Against the strongest competitor StrongPVT [44], it gains +0.061 mAP (0.702 vs 0.641) and +5.58% Top-1 (70.26 vs 64.68) on view-agnostic/view-specific chairs respectively. StyleVAE [47], which uses VAE-based disentanglement for style-agnostic retrieval, scores 0.618 mAP and 54.36% Top-1, trailing the proposed method by 0.084 mAP and 15.9% Top-1, confirming that generic style disentanglement is insufficient for explicit view-awareness. The disentanglement baseline B-Trio [10] (adapting the SceneTrilogy module) reaches 0.572 mAP / 58.68% Top-1, still 0.13 mAP below the proposed method. The single-view 3D reconstruction baseline B-Single [33] performs worst (0.221 mAP / 18.68% Top-1), validating that sparse sketches are unreliable for 3D reconstruction. The 3D-shape-aware pivot encoder B-Pivot [12] achieves 0.316 mAP / 55.92% Top-1, showing that 3D shape awareness alone without explicit view disentanglement is suboptimal. The original Triplet-SN [65] and HOLEF-SN [52] baselines score lowest (0.416/0.428 mAP), underscoring the cost of ignoring view-awareness entirely.

## Relation to Prior Work

This paper extends the standard FG-SBIR paradigm (triplet-loss Siamese networks à la Song et al. [65]) by introducing view-awareness as an explicit axis, splitting retrieval into view-agnostic and view-specific modes. It draws on feature disentanglement frameworks from style-agnostic retrieval [47] and 3D shape retrieval literature [53], but deliberately avoids 3D descriptors, instead leveraging multi-view 2D projections of ShapeNet objects to inject view knowledge into a purely 2D cross-modal pipeline. The key departure from prior FG-SBIR work is the recognition that existing datasets enforce a fixed single-view convention, and the paper's pilot study quantifies the resulting 27.15% accuracy drop when query views mismatch gallery views.

## Why It Matters / Open Questions

The paper addresses a practical user-experience gap (which view should I sketch?) that prior FG-SBIR work has largely ignored, and the user questionnaire (64.56% preferring view-specificity) provides empirical grounding for why a single view-agnostic system is insufficient. Limitations include evaluation on only two categories (chairs, lamps), a relatively simple VGG-16 backbone as the primary model, and a disentanglement module the authors acknowledge could be enhanced with meta-learning or diffusion-based approaches. Open questions include whether the multi-view projection strategy generalizes to categories with high intra-class shape variation, and whether the approach scales to larger, more diverse sketch datasets as they become available.

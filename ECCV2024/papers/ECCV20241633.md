## Problem

CLIP produces strong global image-text alignments but lacks the spatial precision needed for dense tasks like semantic segmentation. MaskCLIP recovers patch-level features with a single forward pass, yet its outputs remain too noisy for high-quality masks, and existing densification strategies either require multiple forward passes, expensive per-concept prototypes, or fine-tuning that degrades open-vocabulary properties. The paper asks whether CLIP features already contain sufficient localization signal that can be extracted with minimal overhead to produce clean, annotation-free segmentation.
![Teaser figure](../imgs/ECCV20241633/cropped_page1_idx0.webp)

## Input / Output

At inference the method takes a single RGB image (resized so the shorter side is 448 px, split into 16×16 patches) and an arbitrary set of text prompts, and produces a per-patch semantic segmentation map of shape N×|T| via cosine similarity between refined visual features and text embeddings. A 'background' prompt can optionally be included, in which case an additional foreground/background objectness mask (with an uncertainty relaxation) is applied to suppress hallucinated background assignments. The entire pipeline requires only one forward pass through the frozen CLIP ViT-B/16 backbone plus two small convolutional layers, with no DINO or FOUND model needed at test time.

## Method

CLIP-DINOiser refines MaskCLIP's noisy patch features through a correlation-guided pooling: each patch's feature is replaced by a weighted average of all patch features, where the weights come from a binarized patch-affinity matrix. The key insight is that this affinity matrix—normally computed from DINO's value embeddings—can be predicted directly from CLIP's intermediate features (layer 10) by a single 3×3 convolutional layer trained with binary cross-entropy to match DINO's binarized correlations. A second 1×1 convolutional layer similarly learns to replicate FOUND's unsupervised objectness scores from the same CLIP features, enabling background filtering without running DINO or FOUND at inference. Both layers are trained on only 1,000 unannotated ImageNet images for ~3 hours on a single GPU, and the CLIP backbone remains fully frozen throughout, preserving its original open-vocabulary alignment.

## Results

CLIP-DINOiser achieves state-of-the-art open-vocabulary semantic segmentation using only a frozen CLIP ViT-B/16 backbone plus two lightweight convolutional layers trained on 1k unannotated ImageNet images. On the no-background-prompt setting, it reaches 80.9 mIoU on VOC20, 35.9 on C59, 24.6 on COCO-Stuff, 31.7 on Cityscapes, and 20.0 on ADE20K. With a background prompt, it scores 32.4 on Pascal Context, 34.8 on COCO Object, and 62.1 on VOC. The method requires only a single forward pass through CLIP at inference, with no post-processing.

## Baselines & Comparisons

CLIP-DINOiser outperforms all frozen-CLIP baselines by large margins: over MaskCLIP by +27.2 mIoU on VOC20 (80.9 vs 53.7), +12.1 on C59, +9.9 on Cityscapes, and +9.2 on ADE20K; over CLIP-DIY by +16.1 on C59, +20.1 on Cityscapes, and +10.1 on ADE20K. Against text-supervised methods that require millions of image-caption pairs for training, it leads TCL by +3.4 on VOC20, +5.6 on C59, +8.6 on Cityscapes, and +10.9 on ADE20K, and beats GroupViT by +1.2 on VOC20 and +13.7 on Cityscapes. The only losses are to OVDiff (which uses an ensemble of three models including Stable Diffusion): −0.8 mIoU on VOC20 (80.9 vs 81.7) and −5.0 on VOC with background (62.1 vs 67.1), while matching OVDiff exactly on COCO Object (34.8). Notably, OVDiff's single-model variant drops by −10 mIoU, and it requires per-concept background prototypes to avoid a further −10 mIoU on VOC, whereas CLIP-DINOiser remains fully open-vocabulary with no concept-specific constructs.

## Relation to Prior Work

This paper extends MaskCLIP's dense CLIP feature extraction by addressing its core weakness—noisy, spatially incoherent patch features—through a guided pooling mechanism inspired by DINO's self-supervised patch correlations. It departs from prior densification approaches (CLIP-DIY, ConceptFusion) that require multiple forward passes, and from prototype-based methods (ReCo, OVDiff) that build concept-specific structures, by showing that a single 3×3 convolutional layer trained on 1k unannotated images can extract DINO-like correlation and objectness information directly from frozen CLIP features. The key conceptual departure is treating DINO not as a runtime dependency but as a training-time teacher whose localization properties can be distilled into CLIP's own representations.

## Why It Matters / Open Questions

The finding that CLIP features already encode sufficient localization structure to be recovered with a single lightweight convolutional layer challenges the common assumption that CLIP's spatial incoherence is fundamental and requires architectural modification or multi-view inference. Practically, this yields a near-zero-overhead SOTA method (one CLIP forward pass + two tiny conv layers, trained on 1k images) that preserves full open-vocabulary generality without concept-specific prototypes or fine-tuning. The main limitation acknowledged is that performance remains bounded by CLIP's inherent class-separation granularity, and the method has not been validated on larger CLIP variants or 3D extensions, leaving open whether the 'DINOising' trick generalizes beyond ViT-B/16.

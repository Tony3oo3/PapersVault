## Problem

Current diffusion-based layout generation models rely on SDE-driven denoising, which introduces stochastic noise along the sampling trajectory and necessitates many evaluation steps for convergence. Flow Matching, which learns a deterministic ODE-based vector field producing smooth and directed paths, has shown strong results in image generation but has not been explored for layout generation, where the geometric interpretation of moving elements from a random initial state to a target layout is particularly natural.
![Teaser figure](../imgs/ECCV20240945/cropped_page1_idx0.webp)

## Input / Output

The model consumes a randomly sampled initial layout (drawn from a Gaussian, uniform, or mixture distribution) where each element is represented by 4 geometric values (center x, center y, width, height) plus B Analog Bits encoding the categorical type, all concatenated into a single vector of dimension (4+B)·N_max with zero-padding for layouts with fewer than N_max elements. Conditioning is applied via binary masks that mark which parts of the input (type, position, size) are fixed, enabling a single model to handle unconditional generation, type-conditioned generation, type+size-conditioned generation, completion, and refinement. The output is a complete layout with element positions, sizes, and types, produced by integrating the learned vector field over 100 Euler steps.

## Method

LayoutFlow trains a 4-layer Transformer (8 heads, dimension 512) to predict a conditional vector field via Conditional Flow Matching on linear interpolation trajectories, where the target is simply x_1 − x_0. A key design choice is adding an L1 regularization term (λ=0.2) on the geometric component of the predicted vector field, which encourages axis-aligned corrections and significantly improves element alignment compared to MSE alone. Categorical element types are handled through Analog Bits, converting discrete labels into continuous embeddings compatible with the flow framework. A unified conditioning mechanism embeds binary masks into each element's representation, allowing the same network to perform all five generation tasks by randomly sampling mask configurations during training. At inference, the ODE is solved with the Euler method over 100 steps, requiring substantially fewer evaluations than equivalent diffusion models while matching or exceeding their quality.

## Results

On RICO unconditional generation, LayoutFlow achieves a FID of 2.37, slightly beating LayoutDiffusion (2.49) and substantially outperforming LayoutDM (4.43) and DLT (13.02). On PubLayNet unconditional generation, LayoutFlow scores 8.87 FID, close to LayoutDiffusion's 8.63. For the Gen-TypeSize task, LayoutFlow achieves FID 1.03 on RICO and 1.26 on PubLayNet, dramatically outperforming DLT (6.27 and 5.35) and LayoutDM (1.76 and 29.91). On the completion task, LayoutFlow reduces FID from 6.80 (LayoutDM) to 1.51 on RICO and from 25.02 to 1.10 on PubLayNet.

## Baselines & Comparisons

LayoutFlow (≈15M params) consistently outperforms the discrete diffusion models LayoutDM and DLT across all tasks and both datasets, with particularly large margins on Gen-TypeSize (FID 1.03 vs 1.76/6.27 on RICO) and Completion (FID 1.51 vs 6.80 on RICO; 1.10 vs 25.02 on PubLayNet). Against the strongest baseline LayoutDiffusion (85M params), LayoutFlow achieves a lower FID on RICO Un-Gen (2.37 vs 2.49), RICO Gen-Type (1.48 vs 1.56), PubLayNet Gen-Type (3.66 vs 3.73), and PubLayNet Refinement (0.18 vs 2.05), while slightly trailing on PubLayNet Un-Gen (8.87 vs 8.63) and RICO Refinement (0.77 vs 0.55). On the Gen-TypeSize task, LayoutFlow is the only method compared, and it dominates both LayoutDM and DLT by a wide margin. Against non-diffusion baselines (LayoutTransformer, LayoutFormer++, NDN-none, RUITE), LayoutFlow achieves substantially lower FID scores, indicating far better diversity, though some of these methods score better on individual geometric metrics like Alignment. Overall, LayoutFlow matches or exceeds the much larger LayoutDiffusion while using roughly 5× fewer parameters and requiring fewer ODE solver steps for inference.

## Relation to Prior Work

LayoutFlow applies the Flow Matching framework (Lipman et al., ICLR 2023) to layout generation, replacing the SDE-based diffusion process that dominates recent layout models (LayoutDM, LayoutDiffusion, DLT) with a simpler ODE-based flow. The Transformer backbone and conditioning mechanism follow the same design patterns established by prior diffusion-based layout generators, while the use of Analog Bits for categorical-to-continuous encoding is borrowed from discrete data generation. The key conceptual departure is the geometrical interpretation: instead of progressively denoising under stochastic noise, the model learns to move elements along smooth, directed trajectories from a base distribution to the target layout.

## Why It Matters / Open Questions

The practical significance is the substantial inference speedup: a ~15M parameter flow matching model matches or exceeds a ~85M parameter diffusion model (LayoutDiffusion) on FID while requiring far fewer evaluation steps, making layout generation more accessible for real-time or resource-constrained applications. The ablation showing DDIM (ODE-based) dramatically outperforming DDPM (SDE-based) on the same architecture (FID 3.18 vs. 34.89) provides strong evidence that the ODE formulation is inherently better suited to layout geometry. Open questions include extending the approach to content-aware layout generation, exploring richer conditioning strategies, and whether the efficiency advantage persists at larger model scales or more complex layout tasks.

## Problem

Current visual foundation models (DINOv2, CLIP, MAE) are trained exclusively on unstructured 2D images, so they lack explicit understanding of 3D scene structure and multi-view consistency. This paper investigates whether fine-tuning such 2D models on 3D-aware features—derived from multi-view-consistent 3D representations—can improve the quality of their learned features for downstream tasks.
![Teaser figure](../imgs/ECCV20240031/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained 2D vision transformer (e.g., DINOv2-small, 384-dim features) and multi-view RGB images with camera poses from indoor scenes (ScanNet++, 230 scenes / 140K views). During fine-tuning, the 2D model receives single RGB images and is supervised by 3D-aware feature maps rendered from the trained 3D Gaussians. For downstream evaluation, the fine-tuned features (concatenated with original features) are fed into a linear head to produce segmentation masks or depth maps via simple linear probing.

## Method

The pipeline has two stages. First, multi-view 2D features are lifted into a 3D Gaussian splatting representation where each Gaussian carries a low-dimensional (64-dim) feature vector; a scene-specific CNN decoder up-projects the rendered low-dim feature image to the full 384-dim space. The Gaussians are optimized jointly with an RGB loss (for geometry: position, scale, opacity) and a feature L1 loss (for the feature vectors only), enforcing multi-view consistency. Second, the trained Gaussians render 3D-aware feature maps for arbitrary views, which serve as supervision to fine-tune the 2D feature extractor via a simple L1 loss for just one epoch at a small learning rate (1e-5). The key insight is that the 3D representation acts as a consistency-enforcing bottleneck: by forcing 2D features into a shared 3D space and back, the model learns view-invariant, geometrically grounded features that transfer to downstream tasks without any architectural modification.

## Results

On semantic segmentation, 3D-aware fine-tuning improves DINOv2 by +2.6% mIoU on ScanNet++ (32.76 vs. 30.19), +2.0% on NYUv2 (67.5 vs. 65.55), and +1.2% on ScanNet (44.84 vs. 43.6). For depth estimation, RMSE is reduced from 0.37 to 0.34 on ScanNet++, 0.44 to 0.42 on NYUv2, and 0.31 to 0.29 on ScanNet. Out-of-domain, the gains persist at +1.6% mIoU on ADE20k, +1.2% on Pascal VOC, and RMSE 3.03→2.91 on KITTI, demonstrating transferability beyond the single indoor training dataset.

## Baselines & Comparisons

The paper's primary baseline is DINOv2, against which 3D-aware fine-tuning consistently wins on every evaluated metric and dataset: +2.6% mIoU (ScanNet++), +2.0% (NYUv2), +1.2% (ScanNet) for segmentation, and 0.03–0.04 RMSE reduction for depth. The method is also applied to four other 2D vision models (Table 4): DINOv2-reg gains +2.47% mIoU and 0.037 RMSE reduction, CLIP gains +3.21% mIoU and 0.036 RMSE reduction, MAE gains +3.08% mIoU and 0.006 RMSE reduction, and DeiT-III gains +4.36% mIoU and 0.053 RMSE reduction. In all cases the 3D-aware fine-tuned version outperforms the original model, with the largest relative gains on weaker baselines (MAE, DeiT-III). The paper does not compare against other 3D-prior injection methods (e.g., Pri3D, Mask3D) directly, positioning itself as a fine-tuning approach rather than a pre-training one, so no head-to-head comparison with those methods is provided.

## Relation to Prior Work

This paper extends 3D Gaussian Splatting [31] by attaching per-Gaussian feature vectors and designing a differentiable feature rasterizer, enabling 2D foundation features to be lifted into a 3D representation. It departs from the dominant direction in the literature—distilling 2D features into 3D fields (NeRF-based [16,32,34,55] or Gaussian-based [45,50,63])—by reversing the flow: rendered 3D-aware features are used to fine-tune the 2D extractor itself. Compared to prior work on injecting 3D priors into 2D models (Pri3D [27], Mask3D [26], CroCo [58]), which require costly pre-training with hand-crafted pretext tasks, this paper achieves the goal through a single-epoch fine-tuning pass with no architectural modifications, positioning it as a lightweight post-hoc enhancement rather than a new pre-training paradigm.

## Why It Matters / Open Questions

The paper demonstrates that 3D awareness can be injected into widely-used 2D foundation models with minimal compute (one epoch, ~8.5 h on a single A100) and without adding any network components, making it an accessible technique for practitioners. A notable open question is why the original 2D features must still be concatenated with the fine-tuned features to preserve generalization; the authors attribute this to the limited diversity of their single indoor training dataset (ScanNet++) and hypothesize that larger-scale 3D data would eliminate this dependency. The cross-domain transferability (indoor training → outdoor KITTI depth, ADE20k/Pascal VOC segmentation) suggests the learned 3D consistency is a general inductive bias, but the modest absolute gains (~2% mIoU) and the requirement for per-scene Gaussian optimization limit immediate large-scale deployment.

## Problem

Open-world 3D instance segmentation requires a model to both recognize unknown objects and retain knowledge of previously seen classes as new labels are incrementally introduced. Prior methods (e.g., 3D-OWIS) address these two sub-problems separately—using exemplar replay for continual learning and auto-labeling for unknowns—which leads to catastrophic forgetting, degraded unknown detection, and growing memory budgets for stored exemplars. This paper argues that the two sub-problems are inherently coupled and must be solved jointly.

## Input / Output

The method takes a voxelized 3D point cloud with per-point RGB colors as input and produces K binary instance masks, each paired with a semantic class label (including a dedicated 'unknown' class) and an objectness score in [0,1]. The model operates in an incremental task sequence where each new task introduces additional known classes while all previously unseen classes are relabeled as unknown. The architecture follows Mask3D's hybrid CNN-Transformer design: a 3D U-Net CNN backbone extracts voxel features, and a Transformer decoder refines queries to generate mask-class predictions at multiple scales.

## Method

OpenDistill3D replaces exemplar replay with a Self-Distillation Module (SDM) that uses a frozen teacher model from the previous task to generate pseudo-labels for both previously known and unknown objects, eliminating the need for stored exemplars. An Unknown-Known Separation (UKS) component corrects misclassified proposals by using overlap between teacher predictions and current-task ground truth to distinguish true unknowns from previously known classes that the teacher may have mislabeled. Training targets combine ground-truth labels for current classes with teacher-generated pseudo-labels for previously known and unknown objects, matched via Hungarian assignment. A novel open-world cross-entropy loss (L_owce) weights each pseudo-label by an objectness-based function W_I that upweights high-confidence unknown pseudo-labels (using an exponential rescaling) while downweighting low-confidence ones, addressing the quality gap between pseudo-labels and ground truth. This exemplar-free distillation simultaneously mitigates catastrophic forgetting and improves unknown object segmentation, achieving up to 25.5% absolute gain in unknown recall and 12.1% mAP improvement on previously known classes over 3D-OWIS.

## Results

On the ScanNet200 open-world 3D instance segmentation benchmark (Task T2, where both previously known and current known classes are evaluated), OpenDistill3D achieves up to 41.31% U-Recall (vs. 15.80% for 3D-OWIS, a +25.51 absolute gain) and up to 26.02% mAP on previously known classes (vs. 13.90%, a +12.12 gain) on Split C. On Split A, U-Recall improves from 27.03% to 36.21% (+6.81) and previously known mAP from 29.40% to 36.21% (+6.81). The method also improves current-known mAP on Splits B and C while remaining competitive on Split A, and outperforms the closed-set Mask3D upper bound on current-known mAP in Task T1 (e.g., 25.22 vs. 25.90 on Split C).

## Baselines & Comparisons

The primary baseline is 3D-OWIS [3], the state-of-the-art open-world 3D instance segmentation method that uses exemplar replay for continual learning and auto-labeling for unknown discovery. OpenDistill3D outperforms 3D-OWIS on U-Recall across all three splits (gains of +6.81, +5.94, and +25.51 on Splits A, B, C respectively) and on previously known mAP (gains of +6.81, +5.94, and +12.12), demonstrating that self-distillation from a frozen teacher model is more effective than exemplar replay for preserving old-class knowledge. On current-known mAP, the method is competitive: it wins on Splits B (+0.55) and C (+0.46) but slightly trails on Split A (−0.79). The second comparison is against Mask3D [21] used as a closed-set upper bound (trained on all classes simultaneously); OpenDistill3D's upper-bound variant (trained on knowns + unknown pseudo-labels in a closed set) matches or exceeds Mask3D on current-known mAP in Task T1, showing that unknown self-distillation supervision benefits even closed-set performance. Notably, OpenDistill3D is exemplar-free, requiring only fixed model storage rather than a growing exemplar bank, which 3D-OWIS needs for each new task.

## Relation to Prior Work

This paper builds on Mask3D's hybrid CNN-Transformer architecture for 3D instance segmentation and departs from the exemplar-replay paradigm used by 3D-OWIS and the broader open-world detection literature (ORE, OW-DETR, PROB). The key conceptual shift is replacing stored exemplars with a frozen teacher model from the previous task to generate pseudo-labels via self-distillation, thereby jointly addressing catastrophic forgetting and unknown object discovery rather than treating them as separate sub-problems. A novel objectness-weighted cross-entropy loss further distinguishes the method by prioritizing high-confidence, low-frequency unknown pseudo-labels over the more numerous but lower-quality previously-known pseudo-labels.

## Why It Matters / Open Questions

The exemplar-free formulation offers a practical memory advantage (fixed model storage vs. growing exemplar banks) while achieving substantially better unknown recall and known-class retention, making it relevant for embodied agents that must continuously encounter new object categories. However, the approach is limited to indoor scenes, depends critically on teacher-model quality, and exhibits pseudo-label inconsistency under data augmentation—open issues that constrain deployment. Whether the self-distillation strategy generalizes to outdoor LiDAR, longer task sequences, or architectures beyond Mask3D remains untested.

## Problem

Deployed skeleton-based action recognition models on XR devices are static and limited to a fixed set of action classes, yet users need to add personalized actions with only a few examples per class while preserving privacy (no storage or replay of prior user data). Existing prompt tuning approaches for continual learning rely on extensively pretrained transformer backbones (e.g., ImageNet-21K ViTs) that do not exist for skeleton-based action recognition, and prompt tuning has never been applied to Graph Neural Networks. This paper formalizes the problem as privacy-aware few-shot continual action recognition and addresses the absence of both a suitable backbone and a prompt mechanism compatible with graph-structured skeleton inputs.

## Input / Output

The method consumes 3D skeleton sequences of shape T×J×3 (64 frames × 25 body joints for NTU RGB+D; 8 frames × 22 hand joints for SHREC-2017) and outputs an action or gesture class label from an expanding classifier. During continual adaptation, the classifier output dimension grows by N new classes per user session, while the backbone feature extractor and input embedding remain frozen. The key structural constraint is that prompts must be attached via addition (not concatenation) to the input feature embedding X_e ∈ R^{T×J×C_e}, because concatenation along spatial or temporal axes would break the graph topology semantics of the skeleton.

## Method

POET attaches learnable spatio-temporal prompt offsets to a frozen GNN backbone (CTR-GCN or DG-STA) by adding a selected prompt sequence P_T to the input feature embedding, where the number of prompts equals the number of temporal frames T to preserve temporal alignment. Prompts are drawn from a shared pool P of M prompt vectors via an input-dependent query-key attention mechanism: a pretrained query encoder maps the input to a query q, which is matched against learnable keys K using sorted cosine similarity to produce an ordered index sequence that selects T prompts in a temporally coherent order. A coupled optimization scheme (using the straight-through estimator) jointly updates the classifier, selected prompts, selected keys, and query adaptor, while a VQ-VAE-inspired clustering loss prevents codebook collapse. The backbone is trained only on base-class data (no large-scale pretraining), making this the first demonstration of prompt tuning on a lightweight, non-transformer GNN architecture for continual few-shot learning.

## Results

On NTU RGB+D (activity recognition, 4-task 5-way 5-shot), POET achieves the best stability-plasticity trade-off with A_HM = 56.3% and final-session average accuracy of 57.1%, substantially outperforming all prompt-tuning and standard CL baselines. On SHREC-2017 (gesture recognition, 3-task 2-way 5-shot), POET achieves A_HM = 56.2% and New-class accuracy of 72.4%, surpassing the FSCIL baseline ALICE (A_HM = 20.0%, New = 11.9%). POET also outperforms the data-storing FE+Replay upper bound on A_HM (56.3% vs. 54.3%) while requiring no stored exemplars, and its multi-task oracle variant (Joint POET) exceeds the standard Joint Oracle upper bound.

## Baselines & Comparisons

POET decisively outperforms all three prompt-tuning baselines (L2P, CODA-P, APT) adapted from image CIL: L2P and CODA-P achieve near-zero New-class accuracy (0.0% and 0.5% respectively) because they do not update their query function, while APT (task-specific prompts) drops to 33.4% New accuracy. Standard continual learning methods that fine-tune the backbone (LWF, EWC, LUCIR) suffer complete catastrophic forgetting, with Old-class accuracy collapsing to 0.0–0.2% and A_HM near zero. Against the frozen-backbone FE baseline, POET improves Old accuracy by 20.1% (57.2% vs. 40.0%) and New accuracy by 10.6% (55.8% vs. 51.0%), demonstrating that prompt offsets provide genuine plasticity beyond mere feature extraction. On SHREC-2017, POET surpasses the FSCIL method ALICE by a wide margin on A_HM (56.2% vs. 20.0%) and New accuracy (72.4% vs. 11.9%), confirming that prompt tuning alleviates the feature-classifier misalignment problem. Notably, POET exceeds the FE+Replay upper bound on A_HM (56.3% vs. 54.3%) without storing or replaying any user data, validating its data-free design.

## Relation to Prior Work

POET extends the prompt tuning paradigm for continual learning (L2P, CODA-P, APT) from transformer-based image models to Graph Neural Networks, which had been entirely unexplored for prompt tuning. It departs from prior prompt tuning work in three key ways: (1) the backbone is trained only on base-class data rather than relying on ImageNet21K-scale pretraining, (2) prompts are attached via additive offsets rather than concatenation (since concatenation is ill-defined for graph-structured skeleton data), and (3) the query-key optimization is coupled with the prompt pool using a straight-through estimator, unlike L2P's decoupled design. The VQ-VAE-inspired clustering loss is borrowed to prevent codebook collapse in the prompt pool, and the spatio-temporal ordered prompt selection is novel relative to prior task-agnostic or task-specific prompt schemes.

## Why It Matters / Open Questions

This work addresses a practically important gap: XR devices (Meta Quest, Apple Vision Pro) need to let users add personalized action classes without storing sensitive training data, a constraint that rules out replay-based continual learning. The finding that prompt tuning alone—without replay, distillation, or backbone fine-tuning—can maintain reasonable stability-plasticity trade-offs on a non-extensively-pretrained GNN is encouraging for on-device deployment. Open questions include whether the approach scales to a truly large generalist skeleton backbone, how it interacts with differential privacy guarantees, and whether the ordered spatio-temporal prompt selection generalizes beyond the two relatively small benchmarks (60 and 14 classes) evaluated here.

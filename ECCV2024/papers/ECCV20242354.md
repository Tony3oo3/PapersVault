## Problem

Learning-based medical image registration methods that predict dense voxel-based deformation fields consume memory that scales linearly with image volume, making high-resolution 3D registration infeasible on standard GPUs. Existing neural deformation field approaches (MLP-parameterized) achieve high accuracy but only in slow optimization-based settings, lacking the fast prediction capability of learning-based methods. NePhi bridges this gap by making neural deformation fields generalizable and predictable, while retaining the memory efficiency of implicit representations.

## Input / Output

The method takes a pair of 3D medical image volumes (e.g., 175×175×175 lung CT or brain MRI) as input. A CNN encoder processes both images to predict a global latent vector and a local latent code map at reduced spatial resolution; the deformation is then evaluated at any continuous spatial coordinate by the MLP. The output is a continuous transformation map (displacement field) that can be sampled at arbitrary resolution, rather than a fixed voxel grid, and a corresponding backward map for inverse consistency.

## Method

NePhi parameterizes the deformation as two MLPs (forward and backward) conditioned on a shared latent code composed of a global vector and a spatially varying local code map, both predicted by a CNN encoder from the image pair. The key regularizer is gradient inverse consistency (GradICON), which penalizes the Jacobian of the composition of forward and backward maps deviating from identity, encouraging approximately diffeomorphic transformations. Crucially, this regularizer only needs to be evaluated at a sparse set of randomly sampled points (as few as 64 for 2D), rather than densely across the volume, enabling dramatic memory savings. At test time, a multi-resolution variant first applies a frozen low-resolution voxel-based CNN for coarse alignment, then refines with the high-resolution NePhi; optional instance optimization further refines the latent codes and MLP parameters for a specific image pair, trading inference time for accuracy.

## Results

On the DirLab lung CT dataset, single-resolution NePhi achieves 5.44 mm mTRE, matching GradICON (5.41 mm) while using only 41% of the training memory (2466 MB vs. 6394 MB) and producing zero transformation folds. With instance optimization, NePhi(IO) reaches 1.73 mm mTRE, outperforming GradICON(IO) at 2.10 mm, with zero folds versus 3.5e-4. In the multi-resolution setting, NePhi(IO) achieves 1.53 mm mTRE (vs. 1.31 mm for GradICON(IO)) while reducing peak training memory by ~79% (2330 MB vs. 13482 MB). On the HCP brain MRI dataset, NePhi(IO) reaches 78.9% DICE (vs. 80.5% for GradICON(IO)) with 79% less memory (1426 MB vs. 6716 MB).

## Baselines & Comparisons

Against GradICON (the primary learning-based baseline), NePhi matches single-resolution accuracy (5.44 vs. 5.41 mm mTRE) with zero folds and 60% less memory; with instance optimization, NePhi(IO) actually outperforms GradICON(IO) on both accuracy (1.73 vs. 2.10 mm) and regularity (0 vs. 3.5e-4 folds). In the multi-resolution setting, NePhi is slightly less accurate than GradICON (2.78 vs. 1.93 mm) but reduces memory by ~79%; with IO the gap narrows to 1.53 vs. 1.31 mm. Against LapIRN, NePhi wins decisively on both accuracy (2.78 vs. 4.24 mm) and regularity (2.4e-4 vs. 1.1e-2 folds) in the multi-resolution setting. The optimization-based PTVReg achieves the best mTRE (0.84 mm) but at the cost of 442 s inference time and 60% of voxels having negative Jacobian determinants, making it impractical for clinical use. Overall, NePhi trades a small accuracy gap in the multi-resolution setting for a large memory advantage and superior deformation regularity across all comparisons.

## Relation to Prior Work

NePhi extends the GradICON framework [50] by replacing its dense voxel-based displacement fields with an implicit neural representation (MLP) conditioned on global and local latent codes predicted by a CNN. This departs from both the dominant voxel-based learning registration paradigm (GradICON, LapIRN) and from prior neural deformation models for registration [17,18,45,57,58,63], which were purely optimization-based and could not predict transformations in a single forward pass. The hybrid conditioning design (global vector + spatially-varying local code map) draws on the implicit neural representation literature (e.g., DeepSDF) to make the MLP generalizable across image pairs while retaining local expressivity.

## Why It Matters / Open Questions

The 5× memory reduction for multi-resolution registration and the demonstrated feasibility of registering 320³ volumes (where voxel-based methods hit GPU limits around 360³) open a practical path toward high-resolution 3D registration tasks such as volumetric microscopy. The ablation showing that only ~64 sampled points suffice for the gradient inverse consistency regularizer to maintain zero-fold deformations is a useful practical insight for memory-constrained settings. Key limitations remain: convergence is slower than voxel-based counterparts (800 vs. 50 IO iterations), and the multi-resolution pipeline still depends on a frozen low-resolution voxel CNN, which itself becomes memory-prohibitive at extreme resolutions. An open question is whether the entire multi-resolution hierarchy can be made neural to fully eliminate the voxel bottleneck.

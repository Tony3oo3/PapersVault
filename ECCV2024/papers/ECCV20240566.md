## Problem

Existing JPEG artifact removal methods trained on single-compression data suffer substantial performance degradation on double JPEG images, which are prevalent in real-world scenarios. Non-aligned double compression—where pixel-level offsets between the two compressions create up to four distinct degradation patterns within each 8×8 block—poses an especially difficult restoration challenge that prior methods like FBCNN do not explicitly address by exploiting the underlying pattern structure.
![Teaser figure](../imgs/ECCV20240566/cropped_page1_idx0.webp)

## Input / Output

The method takes a double JPEG compressed image (grayscale or RGB) as input and produces a restored high-quality image. The offset predictor consumes only a 44×44 patch from the top-left corner of the image to estimate two integer offsets (row, column) in the range 0–7, while the reconstructor processes 224×224 patches. A single model is trained to cover all QF combinations (5–95) and all offset pairs simultaneously, making it a blind restoration system.

## Method

OAPT consists of a compact ResNet18-based offset predictor (using depthwise separable convolutions) that estimates the pixel-level row and column shifts between two JPEG compressions via a sigmoid-round head trained with L1 loss, and a transformer-based reconstructor built from six Hybrid Partition Attention Blocks (HPABs). Each HPAB alternates four standard Swin Transformer Layers (dense window self-attention) with two Pattern Clustering-based Swin Transformer Layers that use the predicted offsets to split every 8×8 block into four sub-patterns, cluster same-position patterns across the image for sparse self-attention, and then invert the clustering. The reconstructor is initialized from SwinIR pretrained weights and fine-tuned with Charbonnier loss while the predictor is frozen. The pattern clustering operation is also shown to function as a zero-parameter, zero-computation plugin that can be inserted into other transformer architectures (e.g., HAT-S) to improve double-compression restoration.

## Results

On grayscale double JPEG image restoration, OAPT achieves an average PSNR improvement of 0.16 dB over the prior state-of-the-art FBCNN across Classic5, LIVE1, and BSDS500, with a 0.18 dB gain on the harder non-aligned cases where QF₁ ≤ QF₂. On color double JPEG images (ICB), OAPT outperforms SwinIR by 0.08 dB on average while using fewer parameters (12.96M vs. 16.14M). The model also demonstrates robustness to multi-compression (up to 7 rounds) and single-compression settings, and the pattern clustering plugin adds 0.03 dB to HAT-S without extra parameters or computation.

## Baselines & Comparisons

OAPT consistently outperforms the prior state-of-the-art FBCNN [26] by 0.16 dB average PSNR on grayscale double JPEG images, with a larger 0.18 dB margin on the harder non-aligned cases (QF₁ ≤ QF₂) where FBCNN's QF-estimation strategy is weakest. Against SwinIR [33], OAPT gains ~0.06 dB on grayscale and 0.08 dB on color images while using fewer parameters (12.96M vs. 16.14M), thanks to the compact ResNet-18 offset predictor. OAPT also surpasses HAT-S [8] and ART [63] on most compression settings, though HAT-S's larger parameter count (71.92M) gives it a slight edge in a few high-QF scenarios. The CNN baselines DnCNN [65] and RNAN [69] trail OAPT by 1–2 dB, confirming the advantage of transformer-based attention for modeling non-aligned block patterns. Notably, the pattern clustering module can be plugged into HAT-S without adding parameters or FLOPs, yielding a 0.03 dB PSNR gain, demonstrating its utility as a lightweight enhancement for existing transformer restoration architectures.

## Relation to Prior Work

This paper builds directly on the SwinIR/Swin Transformer architecture for its image reconstructor, repurposing the window-partition mechanism into a pattern-clustering operation tailored to the four distinct sub-patterns that arise in non-aligned double JPEG 8×8 blocks. It departs from FBCNN, the prior state-of-the-art for double JPEG restoration, which addressed the problem by estimating dominant QF or fine-tuning on synthesized double-compressed data but did not explicitly model the pixel-level misalignment between compressions. The key conceptual contribution is the offset-aware partition: a lightweight ResNet-based predictor estimates the (i,j) shift between two compression passes, and this drives a hybrid attention block (HPAB) that alternates between standard window self-attention and sparse attention over clustered same-pattern patches, a design not present in prior JPEG restoration or general image restoration transformers.

## Why It Matters / Open Questions

Double (and multi-) JPEG compression is ubiquitous in real-world pipelines (camera storage → editing → cloud upload), yet most restoration methods trained on single-compression data degrade substantially on non-aligned double-compressed images, a gap this paper quantifies and addresses. The pattern-clustering module's ability to plug into existing transformer backbones (demonstrated on HAT-S) without adding parameters or FLOPs makes it a potentially reusable component for the broader image-restoration community. However, the offset predictor's accuracy drops sharply (to 0–34%) when QF₁ ≥ QF₂, limiting the method's reliability in the hardest cases, and the authors acknowledge that future work should either improve prediction accuracy or implicitly leverage offsets. The 0.16 dB gain over FBCNN, while consistent, is modest, and the practical impact is confined to the specific double-compression setting rather than general image restoration.

## Problem

Existing adapters for text-to-image diffusion models are specialized for either global style conditioning (e.g., IP-Adapter) or local structure conditioning (e.g., ControlNet, T2I-Adapter), with no single compact architecture that unifies both in a zero-shot manner. ControlNet requires a full U-Net encoder copy (361M parameters) and increases inference time by up to 50%, while style adapters like IP-Adapter cannot perform structure control at all. The paper seeks an efficient, architecture-agnostic conditioning mechanism that handles both conditioning types simultaneously.

## Input / Output

The method accepts a text prompt, an optional reference image (encoded via CLIP ViT-H/14 or ViT-L/14 into a pooled token for style), and an optional structure map (depth, HED edges, Canny, scribbles, or key poses) that is spatially aligned to the U-Net's multi-resolution feature maps. Both style and structure conditions can be applied jointly. The output is a 512×512 generated image (or higher resolution with SDXL), sampled with 50 DDIM steps and classifier-free guidance (scale 7.5) applied to text and style but not structure. Conditioning can be dropped at inference by setting the LoRA scale λ to zero.

## Method

LoRAdapter introduces a conditional LoRA block where the standard low-rank decomposition h = W₀x + BAx is modified to h = W₀x + B·φ(Ax | m(c)), with φ being an affine transformation (element-wise scale γ and shift β) predicted from the conditioning c via a small mapping network m(·) split into a shared component m_S and per-layer components m_L. For style conditioning, the CLIP image token passes through a single linear layer + LayerNorm (shared) and per-layer linear heads that predict β and γ in the rank-r subspace, applied to the K and V projections of cross-attention layers. For structure conditioning, a small convolutional encoder (1.3M params) spatially aligns the structure map to each U-Net block's resolution, and per-layer convolutions map channels to rank r, with the affine modulation applied to convolutional kernels. This confines conditioning to a low-rank subspace, providing regularization that enables zero-shot generalization while keeping total trainable parameters at only 16M (style) or 17–32M (structure), far below ControlNet's 361M.

## Results

On the COCO validation set for style conditioning, LoRAdapter (16M params) achieves CLIP-I 0.831 and CLIP-T 0.637, outperforming IP-Adapter (22M) by 0.043 on CLIP-T while using ~27% fewer parameters. For structure conditioning, LoRAdapter-B (32M) achieves MSE-d 15.34, FID 15.670, and LPIPS 0.572, surpassing ControlNet (361M) on all three metrics. The SDXL variant (103M) further improves to CLIP-I 0.849 and CLIP-T 0.649, matching or exceeding models trained from scratch like Kandinsky-2-1 (1229M) on CLIP-T.

## Baselines & Comparisons

LoRAdapter outperforms IP-Adapter (the strongest dedicated style adapter) on CLIP-T (0.637 vs. 0.588) while using fewer parameters (16M vs. 22M), and matches it on CLIP-I (0.831 vs. 0.828). Against ControlNet Shuffle (361M params), LoRAdapter wins decisively on both CLIP-T (0.637 vs. 0.421) and CLIP-I (0.831 vs. 0.616) with over 20× fewer parameters. For structure conditioning, LoRAdapter-B (32M) beats ControlNet (361M) on MSE-d (15.34 vs. 17.98), FID (15.670 vs. 17.644), and LPIPS (0.572 vs. 0.622), and substantially outperforms T2I-Adapter (39M) on all three metrics. Uni-ControlNet's global control mode (47M) is clearly weaker on style (CLIP-T 0.506, CLIP-I 0.736), confirming that structure-focused adapters do not transfer well to style. Notably, LoRAdapter also surpasses from-scratch models like Open unCLIP (893M) on CLIP-T (0.637 vs. 0.608) while using 55× fewer parameters, though it trails slightly on CLIP-I (0.831 vs. 0.858).

## Relation to Prior Work

LoRAdapter extends the Low-Rank Adaptation (LoRA) framework [14]—originally designed for LLMs and subsequently adopted for diffusion model fine-tuning—by making the low-rank update *conditional* on an external signal via a simple affine transformation applied to the intermediate embedding. This departs from prior adapter approaches (ControlNet, T2I-Adapter, IP-Adapter) that are handcrafted for a specific conditioning modality and architecture, instead offering an architecture-agnostic mechanism that unifies style and structure conditioning in a single module. The design draws on SPADE-style spatially-adaptive normalization for the convolutional layer implementation and on the decoupled cross-attention idea from IP-Adapter for the attention layer implementation, but routes both through the LoRA bottleneck rather than adding parallel pathways.

## Why It Matters / Open Questions

By unifying style and structure conditioning in a single 16M-parameter module that is architecture-agnostic and supports zero-shot generalization, LoRAdapter removes the need to stack multiple specialized adapters (e.g., ControlNet + IP-Adapter) and substantially reduces inference overhead compared to ControlNet's full U-Net encoder copy. The approach is likely to become a widely adopted building block for controllable diffusion, particularly as new base models (SDXL, DiT-based) emerge. Open questions include whether the affine transformation remains sufficient for more complex conditioning types (e.g., video, 3D), whether the method transfers cleanly to transformer-only diffusion architectures without convolutional layers, and how it interacts with emerging distillation or consistency-based acceleration techniques.

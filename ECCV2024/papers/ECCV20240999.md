## Problem

Existing transformer-based visual grounding methods use bounding box annotations solely as regression targets, providing only sparse supervision signals for a task that inherently requires fine-grained localization. Additionally, the query, text, and vision features originate from different sources (static learnable embeddings, unimodal BERT, unimodal DETR backbone), creating a domain discrepancy that impairs multimodal fusion in the target grounding stage.
![Teaser figure](../imgs/ECCV20240999/cropped_page1_idx0.webp)

## Input / Output

The model takes a 640×640 RGB image (aspect ratio preserved, shorter edge zero-padded) and a natural language referring expression (truncated or padded to 40 tokens with [CLS]/[SEP]). It produces a bounding box regressed from a single regression query, a pixel-level segmentation mask (box interior = foreground, exterior = background) decoded from multiple segmentation queries, and a confidence score computed by averaging segmentation values ≥ 0.35 within the predicted box. The segmentation is box-level rather than instance-level, sharing the same semantic objective as the regression head.

## Method

SegVG introduces two key components. First, the Multi-layer Multi-task Encoder-Decoder performs a 'bbox2seg' paradigm: in each of 6 decoder layers, one regression query regresses the box (L1 + GIoU loss) while 5 segmentation queries each produce a pixel-level mask (Focal + Dice loss), iteratively exploiting the same box annotation at both box-level and pixel-level. The segmentation output also yields a confidence score that scales the other losses via a Focal Loss factor, adaptively emphasizing hard samples. Second, the Triple Alignment module inserts a Tri-MHA layer between backbone layers (every 2 BERT layers, every DETR encoder layer) where query, text, and vision tokens simultaneously attend to all three feature types in a triangular fashion, harmonizing them into a shared multimodal space before the grounding stage. The vision backbone is ResNet-101 + 6 DETR encoder layers (pretrained on MSCOCO detection) and the text backbone is BERT-base; backbones are frozen for the first 10 epochs to stabilize multi-task training.

## Results

SegVG achieves state-of-the-art top-1 accuracy (IoU > 0.5) across all five benchmark datasets. On the most challenging RefCOCO+ (no location terms), it reaches 77.18% val, 82.63% testA, and 67.59% testB, surpassing the previous best (VLTVG) by +2.99%, +3.70%, and +2.42% respectively. On RefCOCOg (longer expressions), it attains 76.01% val-g, 78.35% val-u, and 77.42% test-u, improving over VLTVG by +3.03%, +2.31%, and +3.24%. On ReferItGame test, SegVG scores 75.59%, a +3.61% gain over VLTVG (71.98%).

## Baselines & Comparisons

SegVG outperforms all 21 compared baselines across every reported metric. Among transformer-based methods (the most directly comparable family), SegVG surpasses VLTVG [43] by 2.0–3.7% on RefCOCO/RefCOCO+ and 2.3–3.2% on RefCOCOg, and by 3.61% on ReferItGame test; it also beats QRNet [49] (which uses a heavier Swin-S backbone) by 2.83% on RefCOCO val and 2.98% on RefCOCO+ testA. Against the best two-stage method (Ref-NMS [3], 84.00% RefCOCO testA) and best one-stage method (LBYL-Net [13], 82.91% RefCOCO testA), SegVG leads by 5.46% and 6.55% respectively. In the alternative-method comparison (Table 6), SegVG's bbox2seg paradigm (75.06% ReferItGame test) outperforms using LAVT [46] pseudo-segmentation labels (73.76%), confirming that direct box-to-mask conversion avoids error propagation from a separate RES model. The computational cost remains modest: SegVG uses 155.28M parameters and 73.48 GFLOPS, comparable to TransVG (141.55M / 72.61G) and well below QRNet (247.06M / 80.12G).

## Relation to Prior Work

SegVG extends the transformer-based visual grounding pipeline established by TransVG (Deng et al., ICCV 2021), which introduced the DETR-style encoder-decoder with a single regression query for box prediction. Subsequent works like QRNet and VLTVG refined the feature alignment stage, but all treated the box annotation solely as a regression target. SegVG departs from this by repurposing the same box annotation as a pixel-level segmentation mask (the 'bbox2seg' paradigm) and introducing multiple segmentation queries alongside the regression query in a multi-layer multi-task decoder, drawing on the multi-task learning tradition from DETR and Mask R-CNN. The Triple Alignment module further distinguishes this work by explicitly addressing the domain gap between data-agnostic learnable queries, unimodal-pretrained text features, and unimodal-pretrained vision features through a triangular attention mechanism.

## Why It Matters / Open Questions

The confidence score derived from the segmentation output is a practically significant contribution: prior transformer-based visual grounding methods regress boxes without any confidence estimate, limiting their deployability in downstream systems that require reliability filtering. The bbox2seg paradigm demonstrates that richer supervision can be extracted from existing annotations without collecting new data, a principle that may transfer to other sparse-supervision multimodal tasks. However, the segmentation here is box-shaped rather than instance-level, so it captures spatial extent but not object shape; whether true segmentation annotations or learned shape priors would yield further gains remains open. The approach also inherits the standard limitations of the transformer-based VG pipeline (fixed input resolution, single-target assumption) and has not been validated on open-vocabulary or multi-target grounding settings.

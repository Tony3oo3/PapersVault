## Problem

Current large multi-modal models (LMMs) are limited to discrete text token outputs, making them unable to directly produce pixel-level predictions such as segmentation masks. Beyond this output limitation, the diversity of segmentation tasks—each requiring different input modalities (category lists, referring sentences, visual priors) and output structures (class labels, confidence scores, object IDs)—makes it difficult to unify them under a single model with shared weights.
![Teaser figure](../imgs/ECCV20240893/cropped_page1_idx0.webp)

## Input / Output

The model consumes an RGB image alongside a structured prompt schema: a task instruction sentence, a condition prompt (comma-separated category names, a referring sentence anchored by a [REF] token, or visual priors like points/scribbles/boxes/masks that are mask-pooled into feature vectors), and a set of learnable mask tokens appended at the end. The output is a set of N mask proposals (each H×W) paired with a K-dimensional probability vector, where K depends on the condition type (number of categories, or a single confidence dimension for sentence/visual-prior conditions). The condition prompt's LLM output embeddings double as classifier weights, so the same token sequence both informs the task and parameterizes the per-mask classification head.

## Method

PSALM builds on LLaVA (Swin Transformer visual encoder + Phi-1.5 1.3B LLM + 3×3 conv/linear alignment module) and attaches a Mask2Former-style mask generator (multi-scale deformable attention pixel decoder + transformer mask decoder) that consumes the LLM's output embeddings of the mask tokens. The key architectural choice is routing mask tokens through the LLM before the decoder, which the ablations show improves task awareness over Mask2Former's direct token-to-decoder path. The condition prompt is designed to serve a dual role: it supplies task-specific information to the LLM, and its output embeddings (via avg_pooling for category names, [REF]-token features for sentences, or mask-pooled visual features for interactive inputs) become the classifier weights in the mask generator, decoupling mask proposal generation from class assignment. Training proceeds in two stages—first aligning visual features to the LLM's input space, then jointly fine-tuning all modules with bipartite matching loss (BCE + Dice for masks, CE or BCE for classification)—and the paper demonstrates that joint training across COCO Panoptic, RefCOCO/+/g, and COCO-Interactive yields substantial gains over task-specific training, particularly on referring segmentation (+7.1 cIoU) and open-vocabulary segmentation (+2.0 mAP).

## Results

On referring segmentation, PSALM (using only a 1.3B Phi-1.5 LLM) achieves 83.6 cIoU on RefCOCO-val, 72.9 cIoU on RefCOCO+-val, and 73.8 cIoU on RefCOCOg-val, setting new SOTA on RefCOCO and RefCOCO+ while remaining competitive on RefCOCOg. On COCO Panoptic Segmentation, PSALM reaches 55.9 PQ / 45.7 mAP / 66.6 mIoU with a Swin-B backbone, matching or exceeding Mask2Former-Swin-B (55.1 PQ). On COCO-Interactive, PSALM leads all baselines on point (64.3 mIoU), scribble (66.9 mIoU), and mask (67.6 mIoU) instructions, and achieves 67.3 mIoU on box. In zero-shot open-vocabulary segmentation, PSALM+LVIS reaches 13.9 mAP on ADE20K-150 and 95.0 mIoU on Pascal VOC-20, approaching task-specific methods like SAN.

## Baselines & Comparisons

PSALM outperforms all LLM-based referring segmentation baselines on RefCOCO (83.6 vs. 82.2 for UNINEXT-H, 80.4 for u-LLaVA, 79.2 for GSVA-ft) and RefCOCO+ (72.9 vs. 72.6 for GLaMM, 72.2 for u-LLaVA, 70.3 for GSVA-ft), despite using a 1.3B LLM versus 7B/13B models. On RefCOCOg, PSALM (73.8) trails GSVA-ft (75.7) and u-LLaVA (74.8) by roughly 1–2 cIoU, likely because RefCOCOg's more diverse expressions benefit from the larger LLMs. On COCO Panoptic Segmentation, PSALM (55.9 PQ) slightly exceeds Mask2Former-Swin-B (55.1) but falls marginally short of X-Decoder (56.2) and SEEM (56.1). On COCO-Interactive, PSALM dominates on point, scribble, and mask inputs (e.g., 64.3 vs. 51.8 mIoU for SAM-L on points) but SAM-L still leads on box mIoU (76.6 vs. 67.3), attributed to SAM's much larger SA-1B training set. In zero-shot gRefCOCO, PSALM (52.4 cIoU testA) matches LISA without fine-tuning (52.6) but remains well below GSVA-ft (69.9), highlighting the gap between zero-shot and fine-tuned performance on multi-target tasks.

## Relation to Prior Work

PSALM combines two established architectural lineages: the LLaVA-style LMM (visual encoder + alignment module + LLM) for multi-modal understanding, and the Mask2Former paradigm (learnable mask tokens + deformable attention decoder + bipartite matching) for pixel-level prediction. It departs from prior LMM-based segmentation methods (LISA, PixelLM, GSVA, GLaMM) that use seg tokens to directly produce final masks for referring segmentation, instead decoupling mask proposal generation from classification and routing mask tokens through the LLM before the decoder. It also contrasts with vision-centric unified segmentation frameworks (SEEM, UNINEXT, OMG-Seg) that handle multiple segmentation tasks but lack the language understanding and zero-shot generalization capabilities of LMMs.

## Why It Matters / Open Questions

PSALM demonstrates that a single 1.3B-parameter LMM can match or exceed 7B/13B LLM-based methods on referring segmentation while also handling panoptic, interactive, and open-vocabulary segmentation, suggesting that architectural design and multi-task joint training can compensate for model scale. The zero-shot transfer to unseen tasks (video object segmentation, generalized referring, open-vocabulary) without any task-specific fine-tuning is a strong signal toward the 'vision GPT' vision, though open-vocabulary performance still lags behind specialized CLIP/diffusion-based methods. Open questions include whether scaling the LLM or adding more diverse training data (the LVIS experiment hints at large gains) closes the remaining gap, and whether the approach extends to higher-resolution or longer video settings.

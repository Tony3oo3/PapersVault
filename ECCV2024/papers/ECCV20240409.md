## Problem

Token compression methods for Vision Transformers (e.g., ToMe, EViT) suffer significant performance degradation when the compression degree used during training differs from that used during inference, limiting their practical deployment on off-the-shelf models. This mismatch forces practitioners to retrain a separate model for every desired compression level and downstream task, incurring substantial training and storage overheads that negate the efficiency gains of token compression.
![Teaser figure](../imgs/ECCV20240409/cropped_page1_idx1.webp)

## Input / Output

At inference, the method takes an RGB image and a pre-trained ViT backbone (fine-tuned on any downstream task at any source compression degree) and produces a class label, with the target compression degree selected at deployment time. The ToCom plugin itself is a 1.2M-parameter module (for DeiT-B's 86M parameters) that is loaded into RAM and applied by adding or subtracting LoRA products to the model's query and value weight matrices—no additional forward-pass computation is introduced. The same pre-trained ToCom is applied tuning-free across all 20+ downstream tasks without any task-specific adaptation.

## Method

ToCom is a collection of 16 LoRA groups (hidden dimension h=2, scaling s=0.1) where each group models the parameter gap between adjacent compression degrees (r and r+1). It is trained via a fast self-distillation procedure on ImageNet: both teacher and student are the same frozen pre-trained ViT, but different compression degrees are randomly sampled for each in every step, and the student (with ToCom plugged in) is trained to match the teacher's soft outputs via KL divergence. The key insight is that the parameter-level gap between models at different compression degrees is transferable across downstream tasks, so a single pre-trained ToCom generalizes universally. At inference, ToCom bridges any source-to-target degree pair by accumulating (or subtracting, for the reverse direction) the relevant adjacent LoRA groups, enabling a single off-the-shelf model to operate at any compression level without retraining.

## Results

On the VTAB-1k benchmark with DeiT-B, ToCom yields up to 2.1%, 3.6%, and 1.2% average accuracy gains on the Natural, Specialized, and Structured groups respectively when accelerating inference from source r=0 to target r=16 (1.9× speedup). On CIFAR100 and FGVC datasets, ToCom brings up to 1.7% average accuracy improvement at target r=16, and the compensated model matches the performance of a model trained with source r = target r. For training-time acceleration (source r=16, target r=0), ToCom still provides 0.4–1.4% gains across VTAB-1k groups at no additional inference cost.

## Baselines & Comparisons

The primary baseline is ToMe (Bolya et al., ICLR 2023), a training-free token merging method. ToCom is applied as a plug-and-play module on top of ToMe without any retraining. When source and target compression degrees mismatch (e.g., source r=0, target r=16), ToCom consistently recovers the performance gap: on VTAB-1k it lifts Natural accuracy from 73.7% to 75.8% (+2.1%), Specialized from 80.0% to 83.6% (+3.6%), and Structured from 56.7% to 57.9% (+1.2%), matching or exceeding the performance of a model trained natively at r=16 (75.5%, 83.6%, 58.8%). The second baseline is EViT (Liang et al., ICLR 2022), a token pruning method. ToCom also improves EViT (e.g., +1.1% Natural, +1.3% Specialized at target r=16), but EViT remains substantially weaker than ToMe overall (e.g., 40.8% vs. 56.7% on Structured), confirming that token merging is the more effective compression strategy. In both cases, ToCom is strictly additive: it never degrades performance relative to the uncompressed baseline and requires zero additional training or inference latency on downstream tasks.

## Relation to Prior Work

This paper repurposes two established ideas in a novel combination: LoRA-style parameter-efficient modules (Hu et al., ICLR 2022) and model arithmetic (Ilharco et al., ICLR 2023). While prior PET methods use small adapters to bridge the gap between pre-trained and fine-tuned models, and prior model arithmetic work merges capabilities across tasks or domains, this paper uses LoRA modules to encode the gap between models at different token compression degrees (specifically ToMe's per-layer merge parameter r). The self-distillation training procedure, where a frozen model at one compression degree teaches the same frozen model at another degree through a LoRA plugin, is a new application of knowledge distillation to compression-degree alignment rather than standard teacher-student transfer.

## Why It Matters / Open Questions

ToCom enables a single off-the-shelf ViT to dynamically switch inference cost at deployment time without retraining, which is practically important for latency-sensitive serving and for accelerating training while preserving inference quality. The key limitation is that improvements are smaller in the training-acceleration direction (source r > target r), where the model fundamentally saw fewer tokens during training, and a residual gap versus a model trained at the lower source degree persists. Open questions include whether the gap-transferability assumption holds for more aggressive compression ratios, for architectures beyond ViT-B, or for token compression methods with non-uniform per-layer schedules, and whether the approach extends to other efficiency techniques like quantization or pruning.

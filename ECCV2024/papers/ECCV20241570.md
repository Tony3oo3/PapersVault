## Problem

Learning NeRFs from billions of daily crowdsourced photos in a centralized manner is computationally intractable, and existing federated NeRF approaches assume static scenes devoid of personal content, leading to poor reconstruction quality and direct server access to user-specific information. No prior work simultaneously achieves photorealistic global scene reconstruction, minimal server compute, and protection against personal content leakage from crowd-sourced multi-user images.
![Teaser figure](../imgs/ECCV20241570/cropped_page1_idx0.webp)

## Input / Output

Each user provides a small set of geotagged RGB images (e.g., 10 views per user across 20 users) with known camera poses, partitioned non-IID by viewpoint. The method produces a single global NeRF MLP accessible to the server for novel-view rendering of the shared scene, while each user retains a local personal MLP that captures their transient content. The server never receives raw images or individual user weights—only securely aggregated global MLP parameters and gradient statistics.

## Method

DecentNeRF decomposes each user's scene into a global MLP (shared, federated) and a personal MLP (local, never transmitted), with the rendered image being an alpha-composite of both branches. Instead of uniform FedAvg, it learns per-user aggregation weights α_k via gradient descent on the cumulative reconstruction loss, implicitly rewarding users whose global-personal decomposition is more informative. A secure multi-party computation (SMPC) protocol obfuscates individual user weights and gradients so the server only ever observes the averaged global MLP, preventing faithful reconstruction of personal content even in early federation rounds. Over successive rounds, personal content that is static within a user's views but transient across users migrates from the global to the personal MLP, progressively reducing server-side leakage while improving global scene fidelity.

## Results

On the real-world Phototourism dataset, DecentNeRF achieves PSNR of 24.62, 20.61, and 19.22 on Brandenburg Gate, Trevi Fountain, and Sacre Coeur respectively, within 0.5–1.4 dB of the centralized NeRF-W baseline while using ~10⁴× less server compute (≈5–10 B FLOPs vs. ≈200–280 T FLOPs). On the synthetic Novel Blender dataset, DecentNeRF reaches PSNR 26.25 (Lego) and 24.58 (Ship), closely matching NeRF-W (27.09 and 26.35) with only ~4.8–8 B server FLOPs versus ~130–220 T for the centralized approach. DecentNeRF also reduces personal content reconstruction by the server by ~10 dB in PSNR compared to FedNeRF during initial federation rounds.

## Baselines & Comparisons

Against the centralized NeRF-W baseline, DecentNeRF achieves near-parity in photorealism (within 0.56 dB PSNR on Brandenburg Gate, 0.88 dB on Trevi Fountain, and 1.36 dB on Sacre Coeur) while reducing server compute by approximately 4–5 orders of magnitude (e.g., ≈5 B vs. ≈200 T FLOPs on Brandenburg Gate). Against the existing federated baseline FedNeRF, DecentNeRF substantially outperforms on all photorealism metrics: on the Phototourism dataset it gains 5.7 dB PSNR on Brandenburg Gate (24.62 vs. 18.92), 4.1 dB on Trevi Fountain (20.61 vs. 16.55), and 3.8 dB on Sacre Coeur (19.22 vs. 15.41), with correspondingly lower LPIPS. On the synthetic Novel Blender dataset the gap is even wider: DecentNeRF achieves 26.25 PSNR on Lego versus FedNeRF's 17.7 (an 8.55 dB improvement), while FedNeRF visibly hallucinates 'blobs' where personal content (Lego people) appears in user views. The learned federation component further improves over a FedAvg ablation (DecentNeRF(-L)), confirming that per-user weighting learned implicitly from reconstruction loss is critical when users have heterogeneous occlusion levels.

## Relation to Prior Work

DecentNeRF adapts NeRF-W's static/transient MLP decomposition into a multi-user federated setting, reinterpreting 'static' as global scene content and 'transient' as user-specific personal content. It departs from existing federated NeRF methods (FedNeRF, Suzuki) that assume all users capture the same static scene at the same instant, by explicitly modeling the personal-global split and introducing a learned per-user weighting scheme in place of FedAvg. The secure aggregation layer builds on SMPC-based SecAgg protocols from the federated learning literature, applied here for the first time to radiance field model updates.

## Why It Matters / Open Questions

This is the first work to address the practical bottleneck of training NeRFs at global scale from crowdsourced images while preserving user privacy, demonstrating that near-centralized photorealism is achievable with ~10⁴× less server compute. Key limitations include the assumption of known camera poses (decentralized SfM is left open), a threat model restricted to honest-but-curious servers with no user collusion, and no demonstration on actual mobile hardware. Open questions include robustness to SMPC-breaking attacks, scaling to billions of scenes, and whether the personal-global separation generalizes to highly dynamic scenes (e.g., live events) where the static/dynamic boundary is less clear.

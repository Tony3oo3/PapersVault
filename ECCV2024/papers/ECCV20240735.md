## Problem

Rotated bounding box representations for oriented object detection suffer from loss discontinuities at definition boundaries (e.g., the 90° angle switch when long and short edges are similar, or abrupt offset changes near horizontal orientation), destabilizing optimization. Point-set methods avoid these discontinuities but lack explicit orientation cues, failing on near-circular or shape-irregular objects. The paper seeks a representation that cleanly decouples location from rotation while remaining continuous and order-invariant.

## Input / Output

The model takes RGB aerial images (ranging from 800×800 to 4000×4000 pixels depending on dataset) and outputs, per detected object, a set of K points (one center plus K−1 boundary points in polar coordinates) and a 360-bin axis direction encoding with four peaks at 90° intervals. At inference, the argmax bin gives the principal direction, and the oriented bounding box is reconstructed from the point set and axis. For general object detection on COCO, the axis is fixed to horizontal/vertical and only the point set is predicted.

## Method

The point-axis representation defines each object by K points (shape) and a circular 360-bin axis encoding (orientation), making the representation axis-order invariant and free of the 90° switching discontinuity. The Oriented DETR architecture extends two-stage Deformable DETR with a DAB-DETR-style reference point: an object-to-point query conversion generates K point queries via polar-coordinate offsets predicted by an MLP, and a points detection decoder applies group self-attention (point-to-point within each instance, object-to-object across instances) plus decoupled deformable cross-attention for center and boundary points. Training uses two novel losses: a max-projection loss that projects predicted point vectors onto ground-truth edge vectors and penalizes only the maximum projection per direction (avoiding over-constraining the point set), and a cross-axis loss that discretizes orientation into 360 bins with Gaussian smoothing and supervises via cross-entropy, requiring no additional keypoint annotations.

## Results

On DOTA (single-scale), Oriented DETR with Swin-T achieves 79.8% mAP50, outperforming all prior methods including AO2-DETR (77.7%) and Oriented Reppoints (77.6%). Under the multi-scale protocol with Swin-L, it reaches 82.26% mAP50, surpassing the previous best (LSKNet-S, 81.85%) by 0.41%. On DIOR-R, Oriented DETR with Swin-T achieves 74.26% mAP50, a 3.21% gain over the prior best. On COCO (general detection), it attains 50.5 AP in only 36 epochs, exceeding DAB-Deformable-DETR (49.7 AP, 50 epochs) while remaining competitive with DINO-4scale (50.9 AP).

## Relation to Prior Work

This paper builds on the DETR/Deformable DETR/DAB-DETR lineage for end-to-end detection, but departs fundamentally from the rotated bounding box paradigm that dominates oriented object detection (angle-based, quadrilateral, and Gaussian formulations). It also extends the point-set representation line (Oriented Reppoints, OSKDet) by adding an explicit axis component, creating a decoupled point-axis representation where points handle shape/extent and axes handle orientation independently. The max-projection loss and cross-axis loss are novel supervision signals that avoid the boundary discontinuities inherent in all prior box-based formulations, and the points detection decoder with group self-attention is a new architectural module not present in prior DETR variants.

## Why It Matters / Open Questions

The point-axis representation offers a principled solution to the long-standing loss discontinuity problem in oriented detection by fully decoupling position from rotation, which is particularly valuable for near-square or near-circular objects where angle-based methods fail. The axis-order invariance means the representation does not privilege a 'long edge,' eliminating an entire class of boundary artifacts. However, the practical gains are modest (0.41% over LSKNet on DOTA multi-scale), and on datasets with simple, elongated objects (HRSC2016) the advantage largely vanishes. Open questions include whether the representation generalizes to arbitrary polygonal shapes (acknowledged as future work) and whether the point-axis framework can be combined with the more aggressive training strategies (DINO, DN-DETR) that the authors note as a natural next step.

## Problem

CLIP-based few-shot action recognition (CLIP-FSAR) achieves state-of-the-art accuracy but requires fine-tuning the full backbone, causing out-of-memory errors on 24 GB GPUs with more than 2 frames. Adapter-based variants reduce trainable parameters but still incur gradient backpropagation through the entire network, while fully frozen CLIP avoids this cost at the expense of a significant accuracy drop. No existing method simultaneously delivers high accuracy and low training overhead.
![Teaser figure](../imgs/ECCV20240057/cropped_page4_idx0.webp)

## Input / Output

The method consumes support video clips (K per class), query video clips, and text action labels. Videos are encoded by a frozen CLIP ViT-B/16 (or B/32) to extract cached multi-stage features from layers 4, 8, and 12, while labels pass through the frozen CLIP text encoder. The output is a single action class label determined by a combined score that sums text-visual cosine similarities and support-query OTAM distances, each computed independently at global, patch, and frame levels.

## Method

EMP-Net places all 7 M trainable parameters strictly after the frozen CLIP encoder, operating on cached features so that no gradient backpropagation touches the backbone. A skip-fusion module progressively decodes and fuses multi-stage CLIP features (layers 4, 8, 12) using a lightweight decoder with parallel spatial and temporal multi-head attention. The fused feature is then decomposed into three complementary representations—global (class tokens), patch (patch tokens), and frame (spatially-pooled patches)—on which an interactive spatiotemporal reasoning block enforces cross-level information flow (global→patch, patch→frame). For the support branch, a text-guided temporal reasoning module performs cross-attention between the frozen text embedding and class-level prototypes. Classification combines a multi-level text-visual matching score (with selective Top-K/Top-M pooling per level) and a multi-level support-query OTAM score, trained end-to-end with cross-entropy on locally re-coded labels.

## Results

On SSv2-Small (5-way 1-shot), EMP-Net achieves 57.1% accuracy with a frozen CLIP backbone and only 7M trainable parameters, outperforming CLIP-FSAR (54.6%) and D2ST-Adapter (55.0%) while requiring only 8,565 MiB GPU memory versus OOM for trainable CLIP. On SSv2-Full (5-way 1-shot), EMP-Net reaches 63.1%, surpassing CLIP-FSAR (62.1%) and CapFSAR (51.9%). On spatial datasets (HMDB-51, UCF-101, K400), EMP-Net is competitive but slightly trails trainable/adapter CLIP methods (e.g., 76.8% vs. 77.1% on HMDB-51 1-shot), while maintaining a large efficiency advantage.

## Baselines & Comparisons

On the primary temporal dataset SSv2-Small (1-shot), EMP-Net (57.1%) outperforms all CLIP-based frozen methods (CapFSAR 45.9%, CLIP-Freeze 29.5%) and the original CLIP-FSAR (54.6%), as well as D2ST-Adapter (55.0%) and CLIP-CPM2C (52.3%), while also surpassing the best INet-RN50-based method MoLo (41.9%) by 15.2 points. On SSv2-Small 5-shot, EMP-Net (65.7%) beats CLIP-FSAR (61.8%) and CapFSAR (59.9%) but trails D2ST-Adapter (69.3%) by 3.6 points. On SSv2-Full, EMP-Net (63.1% 1-shot, 73.0% 5-shot) edges out CLIP-FSAR (62.1%, 72.1%) but is behind D2ST-Adapter (66.7%, 81.9%). On spatial datasets (HMDB-51, UCF-101, K400), EMP-Net is within 1–5 points of CLIP-FSAR and D2ST-Adapter (e.g., 76.8% vs. 77.1% on HMDB-51 1-shot) while using a fully frozen backbone with 7M trainable parameters versus 89M for trainable CLIP, achieving the best accuracy-to-training-cost ratio among all compared paradigms.

## Relation to Prior Work

EMP-Net is a direct successor to CLIP-FSAR (Wang et al., IJCV 2024), which first integrated CLIP's vision-language pre-training into the few-shot action recognition metric learning framework. The key departure is architectural: rather than fine-tuning or adapting the CLIP backbone (as in CLIP-FSAR or D²ST-Adapter), EMP-Net freezes CLIP entirely and performs all spatiotemporal reasoning in a post-reasoning stage operating on cached multi-stage features. It also incorporates OTAM (Cao et al., CVPR 2020) as the support-query temporal distance metric, and draws on the side-tuning paradigm for efficient domain transfer. The multi-level (global/patch/frame) decomposition of ViT features for both reasoning and matching is the paper's distinctive contribution over prior single-level approaches.

## Why It Matters / Open Questions

The practical significance is the demonstrated balance between training efficiency and accuracy: EMP-Net achieves SOTA on temporal datasets (SSv2-Small 57.1%, SSv2-Full 63.1%) while requiring only 8.5 GB GPU memory versus OOM for trainable CLIP-FSAR, making CLIP-based FSAR accessible on consumer hardware. On spatial datasets (HMDB-51, UCF-101, K400), it trails trainable/adapter CLIP methods by 1–4 points, suggesting the frozen-backbone paradigm still has a domain gap for appearance-heavy tasks. Open questions include whether the multi-level representation can be made adaptive (the authors note this as a limitation) and whether the Transformer-specific design can be ported to CNN backbones, which would broaden applicability.

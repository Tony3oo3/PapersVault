## Problem

Existing topological map-based navigation methods only encode explored regions, leaving unexplored but visible boundary areas unrepresented. This causes inefficient initial exploration in unknown environments, as the agent cannot leverage geometric and visual cues from frontier regions to guide its search. The paper asks whether a topological memory can be extended with informative ghost nodes that carry perceptual features, enabling the agent to reason about unvisited but visible areas end-to-end.
![Teaser figure](../imgs/ECCV20241875/cropped_page1_idx0.webp)

## Input / Output

The agent receives first-person RGBD observations at 144×192 resolution with a 90° horizontal field of view, plus a single target image. It outputs one of four discrete actions per 0.1 s timestep (move forward ~0.25 m, turn left/right ~15°, stop). Internally, the method maintains an incrementally built topological graph where each node stores a ResNet-18 encoding and a global pose; ghost nodes additionally store NeRF-rendered observations that are re-encoded through the same encoder to ensure uniform feature distribution across all node types.

## Method

FTM constructs a topological map with two node types: regular nodes updated via combined image-similarity localization and neural-odometry validation, and ghost nodes placed geometrically in seven directions (±15°, ±30°, ±45°) where average cropped depth exceeds 2.5 m. An online-trained NeRF (optimized with photometric and depth losses, 18 iterations per frame using NeRFAcc) renders observations at each ghost node's pose, which are then passed through the shared ResNet-18 encoder to produce ghost features consistent with regular nodes. The Multi-Stage Memory Extraction (MSME) module first fuses current-observation and target embeddings into every node via concatenation and a linear layer, then applies multi-layer GCN to propagate topological structure, and finally uses a cross-attention decoder (target-as-query over current memory, and vice versa) to extract task-relevant signals. The resulting features are fed through residual-connected FC layers, an MLP, and a stacked LSTM to produce the discrete action, all trained end-to-end via imitation learning on expert trajectories.

## Results

On the Gibson image-goal navigation benchmark (810 test episodes across Easy/Medium/Hard difficulty), FTM achieves an overall Success Rate of 62.5%, SPL of 0.366, and DTS of 0.752 m, outperforming all baselines on every metric. The gains are most pronounced in the Hard setting (5–10 m start-to-goal distance), where FTM reaches 45.1% SR and 0.252 SPL, surpassing the next-best method FGPrompt (40.3% SR, 0.206 SPL) by 4.8 and 4.6 percentage points respectively. Ablation confirms that ghost nodes (F_g) contribute +16.4% SR and +15.1% SPL over the no-ghost variant, while NeRF-based ghost features (F_n) add a further +19.9% SR and +29.2% SPL in the Hard setting.

## Baselines & Comparisons

FTM outperforms all seven baseline methods on overall SR, SPL, and DTS. Against the strongest baseline FGPrompt (fine-grained goal prompting, NeurIPS 2023), FTM gains +3.8% SR (62.5 vs 58.7), +4.6% SPL (0.366 vs 0.320), and reduces DTS by 0.199 m (0.752 vs 0.951). Compared to the topological-memory baselines VGM (SR 53.4%) and NRNS (SR 36.3%), FTM improves overall SR by 9.1 and 26.2 percentage points respectively, with the largest gap in the Hard setting where FTM reaches 45.1% SR versus VGM's 38.4% and NRNS's 20.0%. Against the RL-based OVRL+SLING (SR 56.9%), FTM leads by 5.6% SR and 2.5% SPL. Notably, FGPrompt achieves a slightly higher Easy-setting SR (79.6% vs 77.4%), but FTM dominates in Medium and Hard settings, indicating its ghost-node exploration mechanism is most beneficial when the target is far and the environment is largely unexplored.

## Relation to Prior Work

This paper extends the topological-map-based navigation line (VGM, NRNS, NT-SLAM) by introducing ghost nodes that represent unexplored but visible frontier regions, departing from prior work where virtual nodes served only as directional indicators without perceptual features. For generating visual content at these ghost positions, it replaces the GAN-based view synthesis of SE3DS/PathDreamer with an online-trained NeRF, avoiding the need for extensive pre-training on indoor scene priors. The MSME module further distinguishes the work from planning-based baselines by enabling end-to-end action generation through a multi-factor GCN encoder and cross-attention decoder that jointly process current observations, target cues, and the augmented topological graph.

## Why It Matters / Open Questions

The key practical contribution is demonstrating that an online-trained NeRF can produce ghost-node features within 3.7% SR / 3.9% SPL of ground-truth observations, making frontier-aware topological memory feasible in real-time (5.6 ms per NeRF iteration). The differential performance across difficulty levels—modest on easy episodes but substantial on hard ones—suggests exploration-aware memory structures matter most when the agent cannot trivially see the target, a regime that dominates real-world deployment. The authors acknowledge that the implicit memory is currently used only for feature generation and is not integrated with explicit memory for pose estimation or localization, leaving open the question of deeper implicit-explicit fusion. Real-world validation on a wheeled robot with generalization to dynamic obstacles adds practical credibility beyond simulation.

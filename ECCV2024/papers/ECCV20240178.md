## Problem

Few-shot object detection methods typically share a single RCNN head for classification and localization, despite these tasks having fundamentally conflicting feature requirements (scale/position invariance vs. sensitivity). In few-shot settings, this conflict is amplified by data scarcity, and existing gradient-balancing approaches rely on static closed-form solutions that ignore task-specific few-shot data. Additionally, prior work has only partially exploited CLIP's capabilities for FSOD, using solely its text encoder rather than adapted image-text features.
![Teaser figure](../imgs/ECCV20240178/cropped_page1_idx0.webp)

## Input / Output

The method takes a query image and a K-shot support set (foreground RoI crops plus randomly cropped background shots forming an (N+1)-way classification) along with class text labels. It outputs bounding boxes, class labels, and refined detection scores where the final score is a weighted combination of the original model score and a cosine similarity between CLIP-adapted query and support prototype features. The backbone is ResNet-101 (ImageNet-pretrained) paired with CLIP ViT-L/14@336px for the distillation and refinement modules.

## Method

The architecture replaces the shared RCNN head with a double-head design using separate Res5 branches for classification and localization, with a class-agnostic regression head. A precision-driven gradient balancer—a small 4-layer MLP trained on (L_cls, L_reg, AP) episodes sampled during fine-tuning—dynamically computes rescaling ratios α'_cls and α'_reg that modulate backward gradients to the backbone, replacing static closed-form gradient modulation with an adaptive, data-driven approach. During training, CLIP acts as a teacher network using a key-value cache over support features, and a decoupled KD loss (separate KL terms for target and non-target classes) transfers classification knowledge to the student head. During inference, CLIP refines detection scores by computing cosine similarity between cross-attention-adapted query features and self-attention-enhanced support prototypes, weighted by a trade-off parameter ω.

## Results

On COCO 10-shot, the proposed method achieves 22.7 mAP (40.0 mAP₅₀, 22.3 mAP₇₅), surpassing the second-best RISF (21.9 mAP) by 3.7% relative improvement. On COCO 30-shot, it reaches 25.2 mAP (43.3 mAP₅₀), again outperforming RISF (24.4 mAP). On PASCAL VOC across all three splits and shot settings (1–10), the method achieves the highest mAP₅₀, with a 12.5% mean improvement over the second-best method (RISF). The method also demonstrates strong cross-domain generalization, achieving 42.5 mAP when base-trained on COCO and fine-tuned on VOC novel classes.

## Baselines & Comparisons

The proposed method outperforms all 31 compared baselines on COCO 10-shot mAP (22.7 vs. RISF's 21.9, ICPE's 19.3, NVAE's 18.7, and DeFRCN's 18.4). On COCO 30-shot, it leads RISF by 0.8 mAP (25.2 vs. 24.4) and DeFRCN by 7.9 mAP (25.2 vs. 17.3). On PASCAL VOC, the method achieves the best mAP₅₀ across all three splits and all shot settings (1–10), with the largest margins over RISF (e.g., 68.9 vs. 67.2 on Split-1 1-shot) and DeFRCN (e.g., 68.9 vs. 55.1 on Split-1 1-shot). Among gradient modulation methods tested in Table 1, the proposed precision-driven gradient balancer (18.6 mAP) outperforms CAGrad (17.9), IMTLG (18.0), GradVac (17.3), NashMTL (17.2), and PCGrad (9.8) on the enhanced baseline. The method also surpasses the CLIP-based D&R [19] (18.7 mAP at 10-shot) by 4.0 mAP, demonstrating that leveraging both CLIP image and text embeddings (KDSR) is more effective than text-only distillation. Cross-domain evaluation (COCO base → VOC novel) confirms generalization, with the method achieving 42.5 mAP vs. DeFRCN's 41.0 and MPSR's 42.3.

## Relation to Prior Work

This paper extends DeFRCN's decoupled Faster R-CNN baseline by introducing a double-head RCNN with task-specific Res5 branches and a learned precision-driven gradient balancer that adaptively rescales backward gradients between classification and localization. It departs from prior multi-task learning approaches that rely on closed-form gradient modulation (PCGrad, CAGrad, NashMTL) by instead training a small simulation network to predict AP from task losses, enabling data-adaptive gradient balancing tailored to the few-shot setting. The CLIP-based KDSR scheme extends prior work that used only CLIP's text encoder (D&R [19]) by leveraging full image-text features for both knowledge distillation during training and score refinement at inference, drawing on Tip-Adapter's key-value cache design for the teacher model.

## Why It Matters / Open Questions

The paper addresses a fundamental but underexplored tension in few-shot detection—the conflicting gradient dynamics between classification and localization that worsen under data scarcity—providing a practical, learnable solution that consistently outperforms established closed-form MTL methods. The plug-and-play CLIP score refinement module (4.1 mAP gain, 5.9% boost over PCB when applied to the baseline) offers a low-cost way to improve any existing FSOD pipeline. Limitations include the 3× training time overhead, reliance on a proxy AP simulation network that may not generalize across architectures, and evaluation restricted to Faster R-CNN-based backbones; whether the gradient balancer transfers to DETR or single-stage detectors without retraining remains open.

## Problem

Diffusion-based image editing models can remove or insert objects but fail to model the physical effects those objects impose on the scene—shadows, reflections, and occlusions—producing physically implausible results. The paper argues this is a fundamental limitation of self-supervised learning: without access to counterfactual images (the scene with and without the object), a model cannot learn the causal relationship between an object's presence and its scene effects.
![Teaser figure](../imgs/ECCV20242053/cropped_page0_idx0.webp)

## Input / Output

For object removal, the model takes an RGB image and a binary object segmentation mask (obtained via Segment Anything) and outputs the counterfactual scene with the object and all its effects removed. For object insertion, it takes a target image, a reference object image, and a position mask, and outputs the composite with realistic shadows and reflections. Notably, unlike standard inpainting, the model does not replace masked pixels with uniform gray or black; the original object pixels remain visible to the network, which helps with partially transparent objects and imperfect masks.

## Method

The core contribution is counterfactual supervision: a photographer captures a scene, physically removes one object, and recaptures the scene, yielding 2,500 tightly controlled before/after pairs where the only difference is the object's presence. A latent diffusion model (SDXL-like architecture) is fine-tuned on these pairs using a standard denoising objective conditioned on the factual image and object mask. For object insertion, where the small dataset proves insufficient, the authors propose bootstrap supervision: they run the trained removal model over 14M unlabeled images to synthesize 350K counterfactual pairs (object pasted into its own shadow-free background), pre-train on this synthetic set, then fine-tune on the 2,500 real pairs. This two-stage pipeline lets the model learn to synthesize shadows and reflections rather than merely erase them.

## Results

On the held-out counterfactual test set for object removal, ObjectDrop achieves PSNR 23.15, DINO 0.948, CLIP 0.959, and LPIPS 0.048, substantially outperforming the SDXL Inpainting baseline (PSNR 21.19, DINO 0.876, CLIP 0.897, LPIPS 0.056). For object insertion, ObjectDrop reaches PSNR 21.63, DINO 0.939, CLIP 0.950, and LPIPS 0.057, surpassing AnyDoor (PSNR 19.50, DINO 0.889) and Paint-by-Example (PSNR 17.52, DINO 0.755). In user studies, ObjectDrop is preferred over Emu Edit (64.1% vs 35.9%) and MGIE (86.5% vs 13.5%) for removal, and over AnyDoor (88.9%) and Paint-by-Example (96.7%) for in-distribution insertion.

## Baselines & Comparisons

ObjectDrop wins on every metric against all baselines in both tasks. For object removal, it outperforms the SDXL Inpainting model by ~2 dB in PSNR and 0.07 in DINO similarity, and also beats RePaint (PSNR 21.18, DINO 0.805). In user studies on the Emu Edit benchmark, ObjectDrop is preferred over Emu Edit 64.1% of the time and over MGIE 86.5% of the time. For object insertion, ObjectDrop surpasses AnyDoor by 2.1 dB in PSNR and 0.05 in DINO, and Paint-by-Example by 4.1 dB in PSNR and 0.18 in DINO; in user studies it is preferred over AnyDoor 88.9% (ID) / 95.0% (OOD) and over Paint-by-Example 96.7% (ID) / 97.2% (OOD). The bootstrap supervision step contributes an additional ~1.4 dB PSNR gain over the no-bootstrap variant, confirming its importance for insertion quality.

## Relation to Prior Work

This paper departs from the dominant self-supervised paradigm for diffusion-based image editing (inpainting, general instruction-following models like Emu Edit and MGIE) by arguing that counterfactual supervision is necessary to model an object's physical effects on a scene. It builds on the latent diffusion model architecture [41] but replaces the self-supervised training signal with a small, physically captured counterfactual dataset, and introduces bootstrap supervision to synthesize a large-scale dataset for the harder object insertion task. The conceptual framing draws on causal inference and disentanglement literature to explain why observational data alone is insufficient for editing object effects.

## Why It Matters / Open Questions

The paper demonstrates that a small (2,500-sample) counterfactual dataset, combined with bootstrap supervision, can outperform large-scale self-supervised editing models on photorealistic object removal and insertion, offering a practical recipe for physically plausible editing. However, the method does not model the scene's effect on the object (lighting/orientation harmonization) and may produce incorrect shadow directions, leaving open the question of full bidirectional physical consistency. The finding that object insertion requires roughly 140× more training data than removal highlights an asymmetry that remains unexplained and may constrain future work on generative scene manipulation.

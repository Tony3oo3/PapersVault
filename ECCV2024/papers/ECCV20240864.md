## Problem

Text prompts for open-set object detection excel at abstract, common concepts but struggle with rare or hard-to-describe objects due to long-tail data scarcity and linguistic limitations, while visual prompts capture novel objects through concrete examples but cannot convey general concepts as effectively. No prior model unifies both prompt modalities within a single framework, leaving a gap in handling the full spectrum of real-world detection scenarios.
![Teaser figure](../imgs/ECCV20240864/cropped_page0_idx0.webp)

## Input / Output

The model accepts an RGB image plus one or more prompt modalities: text (category names or short phrases encoded by CLIP), visual prompts as 4D normalized boxes or 2D normalized points placed on the current image or on arbitrary reference images, or a combination of both. It outputs bounding boxes with class labels via a DETR-style decoder. A key practical detail is that T-Rex2 is a late-fusion model: the image encoder runs only once, and additional visual prompts can be added interactively without re-encoding the image, enabling fast iterative refinement.

## Method

T-Rex2 builds on the DINO/DETR architecture with a Swin Transformer backbone and introduces a Visual Prompt Encoder that uses multiscale deformable cross-attention conditioned on box or point coordinates to extract region-specific features, with a global class token aggregating multiple prompts into a single embedding. A CLIP text encoder produces text prompt embeddings, and a region-level contrastive alignment module (InfoNCE loss) explicitly aligns the two modalities in a shared embedding space, enabling mutual distillation: text prompts anchor visual prompts toward general concepts while visual prompts refine text prompts with concrete instance diversity. The box decoder uses DINO-style anchor refinement with prompt embeddings as classification weights, and training alternates cyclically between text-prompt and visual-prompt objectives. A self-training data engine on SA-1B (annotated via TAP) provides diverse visual prompt training data, and the model supports four inference workflows—text-only, interactive visual, generic visual (averaging embeddings across reference images), and mixed—switchable per scenario.

## Results

On zero-shot object detection, T-Rex2 (Swin-L, text prompt) achieves 52.2 AP on COCO-80 and 54.8 AP on LVIS-minival-804, while its visual-prompt variant reaches 46.5 AP on COCO and 42.0 AP on LVIS-val-1203. On long-tail benchmarks, the visual-prompt workflow substantially outperforms text: T-Rex2 (Visual-G, Swin-L) scores 27.8 APavg on ODinW and 18.5 APavg on Roboflow100, versus 22.0 and 10.5 for the text-prompt variant. In the interactive setting (Visual-I, Box, Swin-L), T-Rex2 reaches 58.5 AP on COCO and 65.8 AP on LVIS-val. On few-shot counting, T-Rex2 achieves 43.35 AP on FSCD-LVIS, surpassing T-Rex (40.32), though with a slightly higher MAE on FSC147 (10.94 vs. 8.72).

## Baselines & Comparisons

Against text-prompt baselines, T-Rex2 (Swin-L) matches Grounding DINO on COCO (52.2 vs. 52.5 AP) but dramatically outperforms it on LVIS-minival (54.8 vs. 30.7 AP, +24.1) and surpasses GLIP-L by 2.4 AP on COCO and 20.5 AP on LVIS-minival. On LVIS-minival, T-Rex2 (Swin-T) also beats DetCLIPv2 (Swin-T) by a narrow margin (39.7 vs. 41.7 AP is actually a loss), but the Swin-L variant clearly wins (54.8 vs. 46.3 AP). For visual-prompt detection, T-Rex2 (Visual-G) dominates DINOv on ODinW by a wide margin: 23.6 vs. 14.9 AP (Swin-T) and 27.8 vs. 15.7 AP (Swin-L), and extends to Roboflow100 where DINOv reports no results. On few-shot counting, T-Rex2 loses to T-Rex on FSC147 MAE (10.94 vs. 8.72) but wins on FSCD-LVIS AP (43.35 vs. 40.32), indicating stronger overall detection accuracy in dense multi-target scenes.

## Relation to Prior Work

T-Rex2 unifies two previously separate lines of work: text-prompted open-vocabulary detection (GLIP, Grounding DINO, DetCLIP) and visual-prompted interactive detection (SAM, DINOv, T-Rex). Architecturally, it is built on DINO's denoising anchor-box DETR framework with Deformable DETR's multiscale deformable attention, and adopts Grounding DINO's query selection and contrastive classification loss. The key departure is the introduction of a region-level InfoNCE contrastive alignment module that explicitly couples text and visual prompt embeddings within a single model, enabling them to mutually refine each other during training rather than operating in isolation.

## Why It Matters / Open Questions

The paper provides a practical, single-model solution for open-set detection that can switch between text, visual, interactive, and mixed prompt workflows, addressing the long-standing gap where text prompts fail on rare/undescribable objects and visual prompts fail on abstract general concepts. The clear complementary pattern (text wins on COCO common categories, visual wins on ODinW/Roboflow100 rare categories) is well-evidenced across four benchmarks and two backbone scales. Limitations include the SA-1B data engine's reliance on TAP for noisy semantic annotation, the restricted 'current-image prompt, current-image detect' training strategy that limits cross-image generalization, and the fact that interactive detection results benefit from GT box access. Open questions include whether the contrastive alignment can be made more fine-grained (e.g., per-region rather than global) and whether the data engine can be improved to reduce annotation noise.

## Problem

Action Quality Assessment (AQA) models are typically trained on small static datasets, yet real-world skills in sports and medical rehabilitation evolve over time, requiring continuous model refinement. While continual learning offers a path forward, applying it to AQA introduces a unique challenge: continuous quality score regression over evolving feature manifolds, rather than discrete classification. Specifically, when the backbone is updated to adapt to new data, previously stored features become misaligned with the current feature manifold, causing severe catastrophic forgetting that existing feature-replay methods cannot resolve.

## Input / Output

The method consumes video clips (L×H×W×3) processed sequentially across T sessions, where each session provides only a few new samples (e.g., 3–11 per session) to simulate sparse real-world data arrival. The output is a continuous quality score (real-valued) predicted by a regressor on top of I3D-encoded features. A key design constraint is that only extracted features (not raw video) are stored in a memory bank for replay, preserving user privacy in sensitive domains like medical rehabilitation. The evaluation protocol uses a grade-incremental setting where the continuous quality space is partitioned into equal-sized grade intervals, making each session target a different quality range.

## Method

MAGR addresses the manifold misalignment through two coupled modules. The Manifold Projector (MP) is a residual MLP that learns a translation from the previous feature manifold to the current one: at each session, a frozen copy of the prior encoder produces reference features for current data, and the projector is trained to map those references to the actual updated features, then applied to translate all stored old features onto the current manifold. The Intra-Inter-Joint Graph Regularizer (IIJ-GR) then aligns the feature space with the quality score distribution by computing angular (arccos) distances between L2-normalized features, partitioning the resulting distance matrix into four blocks (intra-old, inter-session, intra-new, and joint), and minimizing KL divergence between each block and the corresponding quality-score distance sub-matrix. Training combines score regression on current data, score regression on replayed (projected) old features, the manifold projection loss, and the graph regularization loss, with Ordered Uniform Sampling selecting representative features for the memory bank at each session boundary.

## Results

MAGR achieves the best overall Spearman rank correlation (ρ_avg) across all four CAQA datasets: 0.8979 on MTL-AQA, 0.8580 on FineDiving, 0.7668 on UNLV-Dive, and 0.7166 on JDM-MSA. These represent correlation gains of up to 6.56%, 5.66%, 15.64%, and 9.05% over the strongest baselines, respectively. MAGR also attains the lowest average forgetting (ρ_aft) on MTL-AQA (0.0223) and FineDiving (0.0167), and the highest forward transfer (ρ_fwt) on MTL-AQA (0.1914), confirming superior memory stability and plasticity in the continual setting.

## Baselines & Comparisons

MAGR outperforms all nine baselines on ρ_avg across all four datasets. Against the strongest feature-replay baselines, MAGR gains 5.53% over NC-FSCIL (ICLR'23) on MTL-AQA (0.8979 vs 0.8426) and 12.11% on UNLV-Dive (0.7668 vs 0.6458), while surpassing SLCA (ICCV'23) by 13.56% on MTL-AQA (0.8979 vs 0.7223) and 21.17% on UNLV-Dive (0.7668 vs 0.5551). Against the best raw-data-replay method MER (ICLR'19), MAGR leads by 2.59% on MTL-AQA, 3.04% on FineDiving, 2.71% on UNLV-Dive, and 4.77% on JDM-MSA, demonstrating that feature replay with manifold alignment can match or exceed raw-data replay while preserving privacy. Memory-free methods (SI, EWC, LwF) and raw-data methods (DER++, TOPIC, GEM) all trail MAGR by 5–60+ percentage points depending on the dataset. Notably, the gap widens with feature deviation severity: on UNLV-Dive (MSE deviation 51.75), MAGR's 15.64% gain over MER is the largest, confirming that the Manifold Projector is most critical when backbone updates cause the greatest shift.

## Relation to Prior Work

MAGR builds on the feature-replay line of continual learning (NC-FSCIL, SLCA) but departs from them by addressing the manifold misalignment that arises when the backbone is updated across sessions—a problem those methods sidestep by freezing the encoder or relying on generative replay. The Manifold Projector is a lightweight residual MLP that learns session-to-session feature shifts, while the Intra-Inter-Joint Graph Regularizer adapts graph-based CL ideas (TOPIC, relation knowledge distillation) to continuous regression by replacing Euclidean distances with angular (geodesic) distances and partitioning the distance matrix for local and global alignment. The paper also carves new ground by formalizing Continual AQA as a distinct task, combining the regression nature of quality scoring with the sequential, few-shot constraints of continual learning in a way that prior CL work (focused on discrete classification) does not cover.

## Why It Matters / Open Questions

By introducing CAQA and a grade-incremental benchmark across four AQA datasets, the paper provides the first systematic evaluation protocol for continual quality assessment, which is directly relevant to privacy-sensitive domains like medical rehabilitation and proprietary sports training where raw data replay is infeasible. The empirical finding that correlation gains scale with the degree of feature deviation (Table 3) offers a useful diagnostic for when manifold-alignment techniques are most needed. Limitations include evaluation only on I3D-based backbones at small scale, a fixed memory budget of 10 samples, and no exploration of ViT or prompt-based architectures that the authors themselves flag as future directions. Open questions include whether the angular-distance graph regularization generalizes to higher-dimensional or transformer-based feature spaces, and whether the two-step alignment (projector + graph regularizer) remains necessary when the backbone change is small.

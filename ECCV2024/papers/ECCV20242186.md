## Problem

Conventional structured pruning for Vision Transformers relies on head-level removal, but the attention head is not an atomic unit, limiting compression granularity. Existing neuron-level pruning (e.g., UVC) uses masking (zeroing out) without respecting the graphical connectivity of the MSA module, which degrades both accuracy and actual throughput since sparse matrices require specialized libraries to accelerate. The paper asks whether neuron-level pruning can be performed in a truly graph-aware manner that removes dimensions and yields hardware-agnostic speedups without additional sparse-computation libraries.

## Input / Output

The pruning pipeline consumes a pre-trained ViT (DeiT-T/S/B or EfficientFormer-L1) along with a small calibration set of 64 ImageNet-1K images used to compute attention-score-based importance scores. The output is a structurally pruned model with reduced dimensions in query, key, value, FFN, and patch-embedding layers, which still accepts standard RGB images and outputs ImageNet-1K class labels. Because SNP removes identical filter indices across all graphically connected layers, the compressed model runs natively on any device (Raspberry Pi 4B, Jetson Nano, CPU, GPU) without sparse-matrix libraries.

## Method

SNP introduces two graph-aware pruning criteria tailored to the MSA module's structure. For query and key layers, it decomposes the attention-score matrix via SVD, then scores each filter pair (Q_i, K_i) by the summed absolute cosine similarity between its outer product and the top-r rank matrices, pruning the least-correlated pairs while preserving the dominant attention-score components; the optimal rank r is selected per attention module using Variational Bayesian Matrix Factorization. For value layers, it measures inter-head redundancy by computing 1 − |cosine similarity| between each value filter and all value filters across all heads, pruning the most redundant filters first. To handle residual connections (where masking and true pruning diverge), SNP sums importance scores across all graphically connected layers by filter index and removes the least important indices identically from every connected layer, ensuring the pruned model achieves real latency gains on any hardware.

## Results

On ImageNet-1K, SNP compresses DeiT-Small to 2.0 GFLOPs / 10.0M params with 78.52% top-1 accuracy (vs. 79.85% original), and further to 1.3 GFLOPs / 6.4M params at 73.32% top-1. The compressed DeiT-Small outperforms the hand-crafted DeiT-Tiny (72.20%) by 1.12% top-1 at similar FLOPs (1.3 vs. 1.3 GFLOPs), while running up to 21.94% faster on Jetson Nano. On edge devices, SNP accelerates DeiT models by 1.44×–2.44× and EfficientFormer-L1 by 1.74×–2.05× with average accuracy degradation of only 1.79% across DeiT variants.

## Baselines & Comparisons

SNP uses only neuron-level pruning (NP), whereas all baselines combine head pruning (HP) with block pruning (BP) or neuron-level sparsity (NS). Against head-pruning-only methods SSViTE and X-Pruner, SNP achieves 30.64% and 10.64% higher FLOPs compression on DeiT-Small with only 0.83% and 0.87% top-1 degradation, well below the 2.1% average gap reported for unconstrained masking. Compared to WDPruning (HP+BP), SNP outperforms by 0.14% top-1 on DeiT-Small while removing 3.3M more parameters and 0.6 GFLOPs, and achieves 1.38× vs. 1.18× speedup on RTX 3090. Against UVC (HP+NS+BP), SNP shows negligible average degradation (0.51% across DeiT variants) while using 7.65% fewer FLOPs, and unlike UVC's masking-based neuron pruning, SNP achieves real latency gains without sparse-matrix libraries. The most striking result is that SNP-compressed DeiT-Small (73.32%, 1.3 GFLOPs) surpasses the smaller hand-crafted DeiT-Tiny (72.20%, 1.3 GFLOPs) by 1.12% top-1 while being up to 21.94% faster on Jetson Nano.

## Relation to Prior Work

SNP extends structured pruning for Vision Transformers beyond the dominant head-pruning paradigm (X-Pruner, WDPruning, SSViTE) by targeting individual neurons within each head's query, key, and value layers. It departs from the only prior neuron-level approach (UVC), which zeros out filters in a masking fashion requiring sparse-matrix libraries for acceleration, by performing true dimension removal guided by the graphical connectivity of the MSA module. The method draws on SVD of attention scores and VBMF for rank selection to identify which query-key filter pairs to preserve, and on inter-head cosine-similarity to eliminate value-layer redundancy — combining ideas from matrix approximation and filter-pruning literature in a graph-aware framework.

## Why It Matters / Open Questions

SNP offers a hardware-agnostic path to deploying ViTs on resource-constrained devices without relying on sparse-computation libraries, which is practically significant for edge inference. The observation that a pruned DeiT-Small outperforms the purpose-built DeiT-Tiny in both accuracy (+1.12%) and latency (up to 21.94% faster on Jetson Nano) suggests that aggressive structured pruning can replace architectural redesign in some regimes. Open questions include whether SNP composes well with head or block pruning, whether it transfers to generative or multi-modal Transformer tasks, and whether the SVD-based importance criterion remains effective at much larger sequence lengths or model scales beyond ImageNet-1K classification.

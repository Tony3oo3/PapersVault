## Problem

Converting high-level user ideas—especially those containing reference images or design instructions—into effective text-to-image prompts requires tedious iterative exploration by humans. The paper asks whether large multimodal model (LMM) agent systems can develop analogous multimodal iterative self-refinement abilities to automatically probe unknown T2I models and discover optimal prompts without human intervention.
![Teaser figure](../imgs/ECCV20241005/cropped_page1_idx1.webp)

## Input / Output

The system accepts a multimodal IDEA that may be text-only, contain a single reference image with interleaved text instructions (e.g., 'the dog looks like the one in the image'), or include multiple images with arbitrary interleaved text specifying design usage (e.g., 'a logo for a 2024 conference in Seattle'). It produces a final generated image along with the refined T2I prompt discovered through iteration. The framework is model-agnostic, operating over any text-conditioned image generation model (SDXL, DeepFloyd IF, SD v1.5/v2.1) and also supporting text-conditioned image-to-image pipelines (SDEdit) where the first input image serves as the conditioning reference.

## Method

Idea2Img is a training-free, inference-time iterative self-refinement loop in which GPT-4V acts in three distinct roles across up to T=3 iterations: (1) prompt generation, producing N candidate T2I prompts from the multimodal IDEA conditioned on prior feedback; (2) draft image selection, comparing N generated images and picking the best one to filter out quality noise; and (3) feedback reflection, identifying specific discrepancies between the selected image and the IDEA and prescribing revision directions. A memory module accumulates all previous iterations' prompts, selected images, and text feedback as interleaved image-text sequences, enabling the LMM to learn the T2I model's idiosyncrasies (e.g., keywords it misinterprets, scenes it fails on) and incorporate that knowledge into subsequent prompt revisions. The key insight is that the LMM must simultaneously improve (generate better prompts), assess (select among similar drafts), and verify (check semantic and visual fidelity) multimodal content—capabilities that text-only LLM self-refinement cannot provide.

## Results

On the 104-sample Idea2Img Evaluation Set, the full iterative self-refined Idea2Img prompt achieves 56.7% user preference with SDXL v1.0, compared to 13.5% for the human-written manual prompt baseline and 29.8% for the initial-round Idea2Img prompt (without iterative refinement). The iterative refinement gain (Δ_iteration) ranges from +4.8% (SD v1.5) to +26.9% (SDXL v1.0), with stronger T2I models benefiting more. Across all six T2I/img2img configurations tested, the iterative Idea2Img prompt is consistently preferred over both baselines.

## Baselines & Comparisons

The paper compares three variants: (1) a human-written manual T2I prompt with minor prompt engineering, (2) the initial-round Idea2Img prompt (LMM generates prompts and selects best draft, but no iterative refinement), and (3) the full iterative self-refined Idea2Img (T=3 iterations). The full Idea2Img wins on all six T2I/img2img configurations. The largest gains come from SDXL v1.0 (+43.2 pp over manual, +26.9 pp over initial-round) and SDXL-img2img (+48.1 pp over manual, +22.1 pp over initial-round). Notably, stronger T2I models benefit more from iteration: SDXL gains +26.9% while SD v1.5 gains only +4.8%, suggesting that better language understanding in stronger models enables them to follow refined prompts more effectively. The initial-round Idea2Img already outperforms the manual baseline on all models (e.g., 29.8% vs 13.5% on SDXL), showing that even a single LMM-generated prompt with draft selection is substantially better than human prompt engineering.

## Relation to Prior Work

Idea2Img extends the LLM self-refinement paradigm (Self-Refine, Reflexion) from text-only environments to multimodal settings by leveraging GPT-4V to iteratively refine T2I prompts. It departs from prior multimodal agent work (MM-ReAct, Visual ChatGPT) in a key way: rather than assuming known tool-usage knowledge provided via instructions or in-context examples, Idea2Img treats the T2I model as an unknown environment whose optimal prompting must be discovered through iterative exploration. Compared to task-specific T2I extensions (prompt tuning, magic words, style transfer modules), Idea2Img offers a unified, training-free framework that handles diverse generation scenarios—style transfer, attribute customization, design instructions—without separate models or fine-tuning.

## Why It Matters / Open Questions

The paper demonstrates that LMM-based iterative self-refinement can substantially improve image generation quality across multiple T2I backends, suggesting a general recipe for enhancing any text-conditioned generator without retraining. The finding that stronger T2I models benefit more from refinement (SDXL +26.9% vs. SD v1.5 +4.8%) is practically important for practitioners choosing where to invest in prompt optimization. However, the framework's heavy dependence on GPT-4V API calls limits accessibility and scalability, and the evaluation relies solely on user preference studies without automatic metrics, leaving open questions about robustness and whether the gains persist with more iterations or in production settings. The authors also note the potential to distill explored knowledge into model parameters or sample-agnostic prompts, pointing toward a future where inference-time refinement is unnecessary.

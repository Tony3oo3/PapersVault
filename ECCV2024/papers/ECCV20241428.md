## Problem

3D foundation models lag far behind their 2D and language counterparts due to the scarcity of large-scale 3D data and the difficulty of obtaining quality 3D annotations. Existing 3D pre-training methods either require 3D point clouds (limited to ~1000 real scenes or synthetic data) or merely project 3D data into 2D to reuse pre-trained features without joint optimization. The paper asks whether one can perform large-scale 3D pre-training using only multi-view images and pre-trained 2D networks, while producing a unified embedding space where 2D, 3D, and language queries are natively compatible.
![Teaser figure](../imgs/ECCV20241428/cropped_page0_idx0.webp)

## Input / Output

The 2D branch consumes RGB images at ViT-g/14 patch resolution (N=14) and outputs dense per-pixel feature maps; the 3D branch accepts NeRF scenes (MipNeRF-360) or point clouds, sparsifies a uniform grid within the normalized [-1,+1] bounding box using NeRF opacity, and outputs a sparse 3D feature grid queried via trilinear interpolation. Sparse key points are extracted in both branches by decoding features through 2-layer MLPs, with 3D key points selected by multiplying per-voxel opacity by predicted key-point possibility. Because 2D and 3D features are co-embedded in the same space, a single image, a full NeRF scene, or a natural language prompt can all be used to query the same repository without per-scene fine-tuning.

## Method

CONDENSE uses a two-branch architecture: a ViT-g/14 2D encoder initialized from DINOv2 and a sparse 3D UNet backbone with swappable input heads (NeRF grid or point-cloud voxelization). The core training signal is a 2D-3D consensus loss that ray-marches the 3D feature field through the NeRF density to produce 2D-projected feature maps, then enforces L2 agreement with the 2D encoder's output, allowing information to flow in both directions. A 2D fidelity loss (applied on ImageNet-21k) anchors the 2D features to the original DINOv2 representation to prevent collapse under the biased, smaller multi-view datasets. A parallel key-point branch decodes sparse interest points in both 2D and 3D with the same ray-marching consistency, enabling efficient scene-scale matching. Training proceeds in four stages: freeze 2D and fit the 2D key-point detector to SuperPoint, then train the 3D branch against the frozen 2D features, and finally unfreeze all modules for joint end-to-end optimization on MVImgNet, ScanNet, and RealEstate10k.

## Results

On 3D classification, CONDENSE achieves 94.1% overall accuracy on ScanObjectNN and 95.2% on ModelNet40, surpassing the previous best (PointGPT at 93.4/94.9) while only training input/output heads with the 3D backbone frozen. On 3D segmentation, it reaches 79.8 mIoU on ScanNet and 80.7 on S3DIS, outperforming Swin3D (77.5/79.8) and PonderV2 (77.0/79.9). The 2D branch also improves over DINOv2 on all benchmarks: 89.6% ImageNet-1k (vs. 86.5%), 70.2% Places205 (vs. 67.5%), 53.6 mIoU ADE20k (vs. 49.0%), and 85.1 mIoU PascalVOC (vs. 83.0%). For cross-modality scene retrieval, the key-point variant (CONDENSE-KP) achieves 78.4% on ScanNet and 72.0% AP on Replica duplicate detection, substantially exceeding ULIP-2 (61.7% and 66.6%).

## Baselines & Comparisons

CONDENSE outperforms all 3D pre-training baselines on both classification and segmentation. On ScanObjectNN, it beats PointGPT (93.4%) by 0.7 points and ULIP-2 (90.8%) by 3.3 points; on ModelNet40 it exceeds PointGPT (94.9%) by 0.3 points. For segmentation, it surpasses Swin3D by 2.3 mIoU on ScanNet (79.8 vs. 77.5) and 0.9 mIoU on S3DIS (80.7 vs. 79.8), and outperforms PonderV2 by 2.8/0.8 mIoU respectively. On 2D tasks, CONDENSE consistently improves over DINOv2 (its initialization) by 3.1 points on ImageNet-1k and 4.6 mIoU on ADE20k, confirming that 2D-3D joint training refines the 2D features. In cross-modality scene retrieval, the key-point variant (CONDENSE-KP) dramatically outperforms ULIP-2 on ScanNet retrieval (78.4% vs. 61.7%) and duplicate detection (70.7% vs. 63.0% on ScanNet, 72.0% vs. 66.6% on Replica), while the global-feature variant (CONDENSE-Global) is roughly on par with ULIP-2, highlighting the critical role of sparse key points for scene-level matching. Among 2D-only baselines (OpenCLIP, DINOv2, Unicom with rendered views), CONDENSE-2D also leads on Objectron (94.6%) and ScanNet retrieval (53.3%), though the 2D-3D native methods achieve substantially higher scores overall.

## Relation to Prior Work

CONDENSE builds on DINOv2 as its 2D encoder backbone and adapts the NeRF volume rendering equation to enforce 2D-3D feature consistency via ray marching, while borrowing the key point detection formulation from SuperPoint. It departs from prior 3D pre-training methods (ULIP, ULIP-2, PointGPT, OpenScene) that require 3D point cloud data by operating solely on multi-view images and NeRF scenes, and from 2D-to-3D distillation approaches (PointCLIP, FeatureNeRF) that fix the 2D embedding space by instead performing joint end-to-end training with bidirectional information flow. The 2D fidelity loss is a novel regularization that anchors the 2D branch to its pre-trained DINOv2 features, preventing collapse under the biased multi-view training distribution.

## Why It Matters / Open Questions

By eliminating the need for 3D point cloud annotations during pre-training, CONDENSE makes large-scale 3D foundation model development more accessible, relying only on the far more abundant multi-view image data. The unified co-embedding space enables practical cross-modality applications (single-image 3D scene retrieval, 3D duplicate detection, language-based scene querying) without per-scene fine-tuning, addressing a real need as NeRF captures become ubiquitous. Key limitations include the high computational cost of per-scene NeRF fitting and multi-view processing, and the reliance on MipNeRF-360 as an intermediate representation. Open questions include whether contrastive learning or parameter-efficient fine-tuning (e.g., LoRA) can further improve robustness, and whether the approach generalizes beyond indoor scenes and man-made objects where current multi-view datasets are concentrated.

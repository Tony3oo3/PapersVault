## Problem

Existing multi-modal state tracking models either track only a single modality (typically visual) within a multi-modal context, or they operate exclusively on synthetic, automatically generated datasets that do not reflect real-world complexity. No prior work performs genuine multi-modal dialog state tracking on in-the-wild video dialog benchmarks where all modalities (video, audio, text) are tracked jointly.
![Teaser figure](../imgs/ECCV20241527/cropped_page0_idx0.webp)

## Input / Output

The model consumes a video split into segments via a sliding window (yielding I3D-rgb, I3D-flow, and SAM object features), synchronous VGGish audio features, and a textual input comprising the video caption, prior question-answer pairs, and the current question. Special state tokens are prepended to each modality's token sequence to anchor attention-based constituent selection. The output is an autoregressively generated free-form text answer, produced token-by-token by the BART decoder conditioned on the enhanced multi-modal hidden states.

## Method

MST_MIXER inserts a MIXER layer after every Δ BART encoder layers, where each MIXER performs a two-stage divide-and-conquer graph structure learning procedure. In Stage I (Divide), the top-K most relevant tokens per modality are selected via attention to state tokens, and local latent graphs are learned per modality using variational inference with multi-modal conditioning (MMC), where each modality's graph is conditioned on all other modalities' features; a two-stream iterative scheme (inspired by Chen et al.) alternates between refining graph structure and node features via APPNP propagation. In Stage II (Conquer), the local graphs are stacked into a block-diagonal initialization for a global latent graph over all N×K nodes, again learned via a two-stream VI procedure. The resulting fine-grained node features are scattered back into the BART hidden states via a convex combination (controlled by λ), and the state token embeddings are updated by averaging their corresponding node features. Training is end-to-end with a combined loss of the generative cross-entropy and local/global ELBO objectives.

## Results

On AVSD-DSTC7, MST_MIXER achieves B-1=78.7, B-4=47.6, METEOR=31.3, ROUGE-L=62.5, and CIDEr=138.8, setting new SOTA across all metrics. On the harder AVSD-DSTC8, it reaches B-4=47.7 and CIDEr=135.4, improving over the second-best models (ITR, THAM) by over 3% relative on B-2, B-3, B-4, and C. On AVSD-DSTC10 (no human captions at inference), it scores B-4=40.0 and CIDEr=99.8. On the generalization benchmarks, it achieves B-4=44.7 on SIMMC 2.0 (vs. 34.1 for PaCE) and WUPS=29.50 on NExT-QA (vs. 28.40 for Flamingo-9B, which has 18× more parameters).

## Baselines & Comparisons

MST_MIXER outperforms all 24 compared baselines across all five benchmarks. On AVSD-DSTC7, it beats the strongest prior model ITR (PAMI'23) by 0.5 BLEU-1, 0.7 BLEU-4, 0.8 METEOR, and 5.7 CIDEr points; on the harder DSTC8, the margin widens to 1.3 BLEU-4 and 6.9 CIDEr over ITR. On AVSD-DSTC10 (no captions at test time), it surpasses DialogMCF (TASLP'23) by 3.1 BLEU-4 and 8.6 CIDEr. On SIMMC 2.0, it achieves B-4=44.7 versus 34.1 for PaCE (ACL'23), a 10.6-point gain. On NExT-QA, it reaches WUPS=29.50, exceeding Flamingo-9B (28.40) by 1.1 absolute points despite Flamingo having 18× more parameters, and surpassing KcGA (28.20) and EMU (23.40). Notably, even the ablated versions without SAM or audio features still outperform all prior models on every metric, indicating the robustness of the graph-based mixing mechanism.

## Relation to Prior Work

This paper extends the iterative two-stream graph refinement paradigm of Chen et al. (NeurIPS 2020) — where better graph structures yield better node features and vice versa — into a multi-modal, divide-and-conquer setting for video dialog. Prior video dialog models (MTN, VGD, BiST, PDC, ITR) relied on vanilla attention that tracked only one modality (typically visual), while earlier multi-modal state tracking efforts (SIMMC, VDTN) were confined to synthetic or slot-filling-constrained datasets. MSTMIXER departs from both lines by performing explicit per-modality state tracking via learned latent graphs and then composing them into a global inter-modal graph, a two-stage procedure not previously applied to in-the-wild video dialog.

## Why It Matters / Open Questions

This is the first model to perform genuine multi-modal state tracking on real-world video dialog, closing a gap the authors identify between uni-modal attention-based tracking and synthetic-only multi-modal DST. The divide-and-conquer design (local modality-specific latent graphs before a global graph) is validated by ablations showing that directly learning the global graph underperforms even plain BART, offering a practical recipe for multi-modal structure learning. Limitations include reliance on a fixed set of pre-trained feature extractors (I3D, SAM, VGGish) and a BART backbone, and the approach has not been tested on substantially larger or more diverse video-language benchmarks. Open questions include whether the latent graph learning generalizes to other multi-modal tasks beyond dialog and whether the computational overhead (~511M parameters) is justified relative to simpler attention-based fusion.

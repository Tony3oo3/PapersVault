## Problem

Existing image-tabular multimodal methods rely on simple fusion strategies (MLPs, concatenation) trained on small, complete datasets and fail to handle the two practical challenges of real-world tabular data: heterogeneous feature types (categorical and continuous) and widespread missingness at both the value and feature level. No prior self-supervised pre-training framework jointly learns robust multimodal representations that remain effective when downstream tabular inputs are incomplete.
![Teaser figure](../imgs/ECCV20240404/cropped_page1_idx0.webp)

## Input / Output

The model takes a 2D RGB image (resized to 128×128) paired with N tabular features (75 for UKBB cardiac data, 17 for DVM car data), where any subset of values or entire columns may be missing. Categorical features are mapped to ordinal indices and continuous features are standardized before embedding. During pre-training, the model also outputs reconstructed values for randomly masked tabular entries; during fine-tuning, it produces a class label via an ensemble of three linear classifiers (one per module) whose predictions are averaged.

## Method

TIP uses a ResNet-50 image encoder and a transformer-based tabular encoder whose embedding module handles heterogeneous features (separate learnable matrices for categorical, shared linear projection for continuous), marks missing entries with a trainable [MSK] token, and injects column identity via learnable column-name embeddings added to each token. A multimodal interaction module of L^m transformer decoder layers lets the [CLS] token and each tabular token cross-attend to the projected image feature map, producing a joint representation F. Pre-training optimizes three objectives simultaneously: (1) Masked Tabular Reconstruction, which randomly masks a fraction ρ of tabular values and trains the model to predict them from the image plus unmasked tabular context using separate cross-entropy (categorical) and MSE (continuous) heads; (2) Image-Tabular Contrastive Learning, which aligns image and tabular representations in a shared 128-d space via InfoNCE-style losses; and (3) Image-Tabular Matching, a binary classifier on the [CLS] embedding of F with hard-negative mining from the contrastive similarity scores. A self-attention mask during encoding restricts each token to attend only to itself and non-missing tokens, and an ensemble of three linear classifiers (image, tabular, multimodal) is used at fine-tuning time.

## Results

On complete downstream data (Table 1), TIP achieves 99.72% accuracy on DVM, 86.43% AUC on CAD, and 84.46% AUC on Infarction under linear probing, outperforming all supervised and SSL baselines. Under full fine-tuning, TIP reaches 99.56% (DVM), 86.03% (CAD), and 85.58% (Infarction). On incomplete data, TIP maintains strong performance across all four missingness scenarios (RVM, RFM, MIFM, LIFM) up to 70% missing rate, and its masked tabular reconstruction achieves RMSE of 0.4651 on DVM and 0.6460 on UKBB at 50% missing rate, substantially beating the best imputation baseline (HyperImpute: 0.9428 and 0.7242 respectively).

## Baselines & Comparisons

TIP decisively outperforms the closest SSL multimodal competitor MMCL [29] by 8.06% accuracy on DVM, 11.72% AUC on CAD, and 7.67% AUC on Infarction under linear probing; the gap persists under fine-tuning (e.g., 6.29% on DVM). Against supervised multimodal fusion methods (CF, MF, IF, DAFT), TIP leads on DVM by 3.12% (vs. DAFT) and is competitive on CAD (86.43 vs. 86.21 AUC), though CF slightly edges TIP on Infarction fine-tuning (85.04 vs. 85.58 is actually TIP winning; CF's 85.04 LP vs. TIP's 84.46 LP shows CF ahead in LP but TIP ahead in FT). All SSL image-only pre-training methods (SimCLR, BYOL, SimSiam, BarlowTwins) are far behind TIP, with the best (BYOL) reaching only 88.64% on DVM fine-tuning versus TIP's 99.56%. On incomplete data, TIP surpasses tabular SSL methods VIME and SCARF by 75.02% accuracy on DVM at 50% random value missingness, and outperforms SAINT across all four missingness scenarios. For missing value reconstruction, TIP's RMSE (0.4651 on DVM, 0.6460 on UKBB at σ=0.5) beats the best imputation baseline HyperImpute (0.9428, 0.7242) by roughly 50% and 11% respectively.

## Relation to Prior Work

TIP draws on three distinct research threads: (1) SSL for tabular data (VIME, SCARF, SAINT), which handles missingness but only unimodally; (2) supervised image-tabular fusion methods (DAFT, CF, MF, IF), which use shallow MLPs on small, complete datasets; and (3) vision-language SSL pre-training (CLIP, BLIP, ALBEF), whose contrastive/matching/reconstruction objectives are repurposed here for the image-tabular setting. The closest prior work, MMCL, performs multimodal contrastive pre-training but discards the tabular branch at inference. TIP departs from all of these by introducing a transformer-based tabular encoder with learnable [MSK] tokens for heterogeneous missing data, a cross-attention multimodal interaction module, and a three-task SSL strategy (ITC + ITM + MTR) that explicitly trains the model to reconstruct masked tabular values using image context — a combination absent from prior image-tabular or tabular-only SSL work.

## Why It Matters / Open Questions

The paper addresses a practically critical gap: real-world multimodal databases (especially in healthcare, e.g., UK Biobank) routinely contain missing tabular values or entire missing columns due to heterogeneous collection protocols, yet prior image-tabular methods assume complete data. TIP's demonstrated robustness across four missingness scenarios and multiple missing rates provides a viable pre-training recipe for such settings. Key limitations include reliance on simulated (not naturally occurring) missingness, 2D images only, and relatively small pre-training corpora (26K–70K pairs), which may constrain generalization. Open questions include whether the approach extends to 3D/volumetric or temporal imaging, whether the ensemble fine-tuning strategy is necessary at scale, and how performance holds when missingness is informative (MNAR) rather than random.

## Problem

Existing coarse visual localization methods rely on large image databases that are storage-heavy and slow to query, while cross-modal approaches are limited to matching only two modalities at a time. This paper introduces the novel task of localizing a query image within a compact, multi-modal 3D scene graph database that integrates point clouds, images, semantics, attributes, and object relationships, enabling orders-of-magnitude smaller and faster reference maps.
![Teaser figure](../imgs/ECCV20240196/cropped_page0_idx0.webp)

## Input / Output

The method takes a single query RGB image and a pre-built database of 3D scene graphs, where each graph represents a place (room or building) and its nodes carry multiple modalities (point cloud, image crops, semantic category, attributes, and inter-object relationships). At inference, only fixed-size node embeddings (independent of the number of modalities) are stored, so the map can be queried without retaining raw point clouds or images. The output is a ranked list of scene graphs by image-to-graph similarity, with the top-ranked graph identifying the coarse location; retrieval is performed via nearest-neighbor matching between image patches and graph nodes followed by score averaging.

## Method

SceneGraphLoc learns a shared embedding space for image patches and scene graph nodes via contrastive learning. For each graph node, five uni-modal embeddings are computed: geometric (PointNet on point clouds), visual (DinoV2 on multi-level, multi-view image crops aggregated by a Transformer with pose encodings), structural (two-layer GAT over relative translations), relational (FFN on bag-of-words relationship vectors), and attribute (FFN on attribute vectors); these are L2-normalized, weighted by learned attention coefficients, concatenated, and passed through a two-layer MLP to yield a fixed-size node embedding. For the query image, DinoV2 patch features are processed by a 4-layer residual CNN and a 3-layer MLP to produce per-patch embeddings. Training uses a bi-directional N-pair contrastive loss with both static (same-scan) and temporal (different-scan) positive pairs to ensure robustness to scene changes. At inference, each image patch is matched to its nearest node in every candidate graph, and the graph with the highest mean patch-to-node similarity is selected as the coarse location.

## Results

On 3RScan (50-scene temporal setting), SceneGraphLoc with all modalities (point cloud + image + other) achieves 69.3% R@1, 78.6% R@3, and 84.4% R@5, surpassing CVNet (66.5% R@1) while requiring only 5.4 MB of storage versus CVNet's 239.1 MB and AnyLoc's 5,720.3 MB. Without the image modality, SceneGraphLoc still reaches 28.2% R@1, substantially outperforming OpenMask3D (21.1%), LidarCLIP (4.1%), and LIP-Loc (2.3%). On ScanNet (all 210 scenes, temporal), SceneGraphLoc with images achieves 53.4% R@1, a notable gap versus CVNet (89.9%) and AnyLoc (95.1%), which the authors attribute to missing object attributes and imperfect instance segmentation from SceneGraphFusion.

## Baselines & Comparisons

SceneGraphLoc decisively outperforms both point-cloud-only cross-modal baselines: on 3RScan 50-scene temporal, it achieves 28.2% R@1 (P+O) versus 4.1% for LidarCLIP and 2.3% for LIP-Loc, a gap the authors attribute to those methods learning shared embeddings between entire scenes and query images despite viewpoint differences. Against OpenMask3D (which uses CLIP descriptors on 3D instances), SceneGraphLoc without images leads by 7.1 points (28.2% vs 21.1% R@1 on 50-scene temporal), and with images the gap widens to 48.2 points (69.3% vs 21.1%). Compared to image-database methods, SceneGraphLoc with all modalities slightly exceeds CVNet on 3RScan 50-scene temporal (69.3% vs 66.5% R@1) but trails AnyLoc (80.6% R@1); on ScanNet all-scene temporal the gap to AnyLoc is larger (53.4% vs 95.1% R@1). The critical advantage is storage: SceneGraphLoc requires 5.4 MB regardless of whether images are included, versus 239.1 MB for CVNet and 5,720.3 MB for AnyLoc — a three-orders-of-magnitude reduction — while inference retrieval from 50 scenes takes only 1.5 ms versus 60 ms (CVNet) and 1,826 ms (AnyLoc).

## Relation to Prior Work

SceneGraphLoc builds directly on SGAligner (Sarkar et al., ICCV 2023), which aligned 3D scene graphs via node matching, by extending it to the image-to-graph localization setting and replacing simple concatenation of uni-modal embeddings with a learned, modality-weighted distillation into a fixed-size vector. It departs from prior cross-modal localization work (LidarCLIP, LIP-Loc, cross-view matching) that is restricted to pairing exactly two modalities, and from image-retrieval-based place recognition (AnyLoc, CVNet, NetVLAD) that requires storing and querying large posed-image databases. The 3D scene graph representation itself draws on Armeni et al. and subsequent scene-graph construction/prediction work, but the paper is the first to use such graphs as the reference map for coarse visual localization.

## Why It Matters / Open Questions

The practical impact is significant: a three-orders-of-magnitude reduction in map storage and orders-of-magnitude speedup in retrieval make long-term indoor localization feasible on resource-constrained platforms (robots, AR headsets) where gigabyte-scale image databases are impractical. The finding that geometric, semantic, and relational structure alone (without stored images) already outperforms dedicated cross-modal methods suggests that structured scene understanding can substitute for raw appearance in coarse localization. Open questions include generalization to outdoor or large-scale environments, robustness to the quality of predicted (vs. annotated) scene graphs as seen on ScanNet, and whether the approach can handle dynamic or partially observed scenes without re-mapping.

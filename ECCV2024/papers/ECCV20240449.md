## Problem

Oriented object detection requires capturing orientation information that varies significantly within and across images, but the prior SOTA method ARC multiplies parameters by m (typically 4×) and its weighted-sum aggregation of multi-angle features mixes useful signals with noise from misaligned kernels, degrading detection accuracy. The paper addresses the gap of simultaneously achieving high detection performance and parameter efficiency for oriented object detection.
![Teaser figure](../imgs/ECCV20240449/cropped_page1_idx0.webp)

## Input / Output

GRA is a plug-and-play module that replaces 3×3 convolutions in the last three stages of a ResNet-50 backbone, consuming standard RGB aerial images (e.g., 1024×1024 on DOTA, 300×300 to 1500×900 on HRSC2016) and producing oriented bounding boxes with class labels through a downstream detector head. The module operates on intermediate feature maps of shape C_in×H_in×W_in, outputting a refined feature map of shape C_out×H_out×W_out that is fed to subsequent network stages. It is compatible with both single-stage (Rotated RetinaNet, R3Det, S²ANet) and two-stage (Oriented R-CNN, CFA, Rotated Faster R-CNN) detectors.

## Method

GRA comprises two synergistic components. Group-wise Rotating uses a lightweight angle generator (depthwise conv → ReLU → LayerNorm → global pooling → two linear layers) to predict n rotation angles and n learnable scale factors from the input feature map; the convolution kernel W∈R^{C_out×C_in×k×k} is then partitioned into n groups along C_out, each group rotated by its predicted angle via bilinear interpolation and scaled by its factor, after which all rotated groups are concatenated and applied as a single standard convolution. Group-wise Attention partitions the resulting output into the same n groups, computes max-pool and avg-pool descriptors per group, fuses them through a 1×1 convolution and sigmoid to yield spatial attention maps, and element-wise multiplies these maps back onto each feature group to suppress noise from misaligned rotations. With n=16, GRA adds only ~0.2M parameters (vs. ~33M for ARC with m=4) while enabling fine-grained multi-angle feature capture, and the attention mechanism adaptively filters the residual noise that ARC's weighted sum would otherwise propagate.

## Results

On DOTA-v1.0, GRA consistently outperforms the previous SOTA method ARC across all six tested detectors while reducing total parameters by 43–46%. For example, with Oriented R-CNN, R50_GRA achieves 77.63% mAP (41.65M params) versus R50_ARC at 77.35% mAP (75.06M params). On the more challenging DOTA-v2.0 benchmark (which contains many tiny objects), GRA with Oriented R-CNN trained for 40 epochs achieves a new SOTA mAP of 57.95%, surpassing the previous best DCFL (57.66% with ReR101). On HRSC2016, GRA yields mAP improvements of 1.27–2.32% over standard ResNet-50 across Rotated RetinaNet, S²ANet, and Oriented R-CNN.

## Baselines & Comparisons

The primary comparison is against ARC [48] (ICCV 2023), the previous SOTA for oriented object detection backbones. GRA wins on every detector in Table 1 (DOTA-v1.0) while using roughly half the parameters: e.g., Oriented R-CNN goes from 77.35% (ARC, 75.06M) to 77.63% (GRA, 41.65M). On DOTA-v2.0, GRA (57.95% mAP, R50, 40 epochs) surpasses DCFL [68] (57.66%, ReR101, 40 epochs) and all other listed methods including S²ANet (49.86%), ATSS-O (49.57%), and Ori-Rep (48.95%). On HRSC2016, GRA outperforms ARC by 0.11–0.26% mAP across Rotated RetinaNet, S²ANet, and Oriented R-CNN. Against standard ResNet-50 (no rotated convolution), GRA yields consistent gains of 0.7–2.3% mAP depending on the detector and dataset. GRA also demonstrates a practical advantage over ARC in pre-training: loading public ResNet weights and training only the GRA modules achieves 77.39% mAP, whereas training from scratch yields only 35.51%, whereas ARC requires from-scratch pre-training of the entire backbone.

## Relation to Prior Work

GRA is a direct successor to ARC (Adaptive Rotated Convolution, Pu et al., ICCV 2023), which was the prior SOTA backbone for oriented object detection. ARC employed m full convolution kernels each rotated at a predicted angle and aggregated via weighted sum, inflating parameters by a factor of m. GRA departs from this by dividing a single kernel into n groups and rotating each group independently, reducing the parameter overhead to near zero, and adds a per-group spatial attention mechanism to suppress the cross-orientation noise that ARC's weighted-sum aggregation introduces. The work also situates itself within the broader dynamic neural network literature as a sample-wise dynamic architecture, and connects to the spatial attention line (CBAM-style) for the denoising component.

## Why It Matters / Open Questions

GRA offers a practically important efficiency story: it achieves SOTA on DOTA-v2.0 (57.95% mAP) while using roughly half the parameters of ARC, and it can leverage standard ImageNet-pretrained ResNet weights rather than requiring from-scratch backbone training. This makes oriented object detection backbones more deployable on resource-constrained platforms (e.g., remote sensing hardware). However, the module has only been validated on 3×3 convolutions within ResNet; its transfer to larger kernels, ConvNeXt-style architectures, or non-ResNet backbones remains an open question. The group-wise attention component, while effective, is a relatively standard spatial attention applied per group, leaving room for more sophisticated denoising strategies.

## Problem

Existing weakly supervised 3D object detection methods rely on sophisticated, category-specific manual priors (e.g., vehicle point-cloud patterns, SDF templates, synthetic data) that are difficult to generalize to novel object classes and scenes. This paper seeks a unified, general-purpose framework that can lift 2D boxes to 3D boxes across diverse categories and environments without hand-crafted rules.
![Teaser figure](../imgs/ECCV20241362/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images, scene point clouds (from LiDAR or depth cameras), and 2D bounding boxes as input. Point clouds are preprocessed via Farthest Point Sampling (to 10⁶ points for indoor) and RANSAC ground removal, then filtered into In-Box-Points by projecting 3D points into the 2D box frustum and removing outliers with a 2D instance segmentation network (indoor) or region growing (outdoor). The output is a set of pseudo 3D bounding boxes parameterized as (x, y, z, l, w, h, sin α, cos α) along with class labels, which are subsequently used to train fully supervised detectors (PointRCNN, PGD, MonoDETR, or FCAF3D) under a standard supervised protocol.

## Method

GGA decomposes the 2D-to-3D lifting problem into three complementary constraints applied on top of an anchor-free backbone (CenterPoint for outdoor, FCAF3D for indoor). First, a Semantic Ratio Loss (SRL) injects category-wise BEV width-to-height ratios obtained from GPT-4 as a lightweight shape prior, supervising min(l,w)/max(l,w) with L1 loss. Second, a Boundary Projection Loss (BPL) projects the eight corners of the predicted 3D box onto the image plane and minimizes the L1 discrepancy between the projected bounding rectangle and the 2D box boundaries, providing 2D-space localization. Third, a Point-to-Box Alignment Loss (PAL) operates in 3D BEV space: PAL₁ penalizes In-Box-Points that fall outside the predicted box edges (using ReLU on distance-to-edge minus half-dimension), while PAL₂ minimizes the shortest distance from each point to the four box edges, exploiting the observation that single-view RGB-D points cluster near box boundaries. The three losses are combined with objectness and classification losses for end-to-end training, and the resulting pseudo 3D boxes are then used to fine-tune downstream detectors in a fully supervised manner.

## Results

On the KITTI val set for LiDAR-based 3D detection (IoU=0.5), GGA achieves 95.25/94.83 AP_BEV/AP_3D for cars (Easy), and is the only weakly supervised method to handle cyclists (88.10/86.59 Easy) and pedestrians (66.86/65.06 Easy). For monocular 3D detection on KITTI val (IoU=0.7), MonoDETR+GGA reaches 21.18/14.96/12.25 AP_3D (Easy/Mod/Hard), outperforming the prior best weakly supervised method WeakM3D by +4.12/+3.33/+0.31. On SUN-RGBD, FCAF3D+GGA achieves 48.5 mAP@0.25 across 10 indoor categories, surpassing the semi-supervised BoxPC (37.2 mAP) by 11.3 points while using only 2D box supervision.

## Baselines & Comparisons

GGA outperforms all prior weakly supervised methods on car detection: with LiDAR input it beats Lifting [38] by +8.73 AP_BEV (Easy) and +3.31 AP_3D (Hard), and with image input it surpasses WeakM3D [45] by +3.43 AP_BEV (Easy) and +6.98 AP_3D (Easy). Critically, GGA is the only method in the comparison that generalizes beyond the car category, producing results for cyclists and pedestrians where all other weakly supervised baselines (VS3D, Auto5DF, WeakM3D, Lifting) simply fail (marked ×). On SUN-RGBD, FCAF3D+GGA (48.5 mAP) outperforms the semi-supervised BoxPC [62] (37.2 mAP) by 11.3 points across all 10 indoor categories, though it remains 15.7 points below the fully supervised FCAF3D (64.2 mAP). For monocular 3D detection on KITTI val, MonoDETR+GGA (21.18 AP_3D Easy) slightly trails WeakMono3D [63] on hard samples (12.25 vs. 36.34 at IoU=0.5 in Table 5), which the authors attribute to WeakMono3D's use of 2D direction labels for rotation estimation. Overall, GGA's key advantage is generality: it handles multiple categories and both indoor/outdoor scenes without category-specific hand-crafted priors, whereas competing methods are restricted to vehicles.

## Relation to Prior Work

GGA carves new ground in weakly supervised 3D detection by replacing the category-specific hand-crafted priors that define prior methods (WeakM3D's vehicle point-cloud patterns, FGR's frustum geometry rules, AutoSDF's synthetic SDF templates, Lifting's fixed mesh templates) with three general, architecture-agnostic geometric constraints. It repurposes the projection-consistency idea from WeakMono3D into a boundary-level loss (BPL), introduces a novel use of LLMs (GPT-4) as a free source of semantic shape priors via a simple ratio loss (SRL), and adds a point-to-box alignment loss (PAL) that has no direct analogue in prior weakly supervised work. The framework is explicitly orthogonal to existing methods, demonstrated by combining GGA-generated pseudo labels with PGD and MonoDETR backbones.

## Why It Matters / Open Questions

By showing that general geometric constraints plus a single LLM-sourced ratio can produce competitive 3D boxes across vehicles, pedestrians, cyclists, and indoor furniture, GGA removes the main barrier (category-specific engineering) that has kept prior weakly supervised methods confined to cars. The practical impact is significant: 2D annotation is 3–16× cheaper than 3D, and the method is composable with any existing detector. The acknowledged limitation—objects far from the camera with very few points remain difficult—points to an open question about knowledge transfer from dense to sparse point regions, and the reliance on a single LLM call for ratio priors raises questions about robustness when the LLM's prior is inaccurate for atypical object shapes.

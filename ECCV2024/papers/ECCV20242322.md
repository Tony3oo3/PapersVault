## Problem

Camera-only collaborative 3D object detection remains significantly underexplored compared to LiDAR-based approaches, and existing BEV feature-level fusion paradigms are highly sensitive to spatial alignment and the inherently poor quality of single-agent BEV features derived from 2D images (an ill-posed problem). Additionally, prior methods do not adequately address the communication bandwidth constraint that is critical for practical V2X deployment.
![Teaser figure](../imgs/ECCV20242322/cropped_page4_idx0.webp)

## Input / Output

The system takes RGB images from multiple agents (each with up to N_cams camera views; resolutions range from 600×800 on V2XSet/OPV2V to 1080×1920 on DAIR-V2X) along with camera intrinsics/extrinsics. Rather than transmitting full feature maps, each agent sends only instance-level cropped features (foreground regions identified by a 2D detector) plus bounding box coordinates, which the ego agent reconstructs into sparse foreground feature maps. The output is a set of N_Q 3D rotated bounding boxes, each parameterized as (class, x, y, z, w, l, h, θ), produced end-to-end by a deformable DETR decoder without NMS.

## Method

IFTR replaces BEV-level fusion with instance-level fusion through three coupled modules. First, a message selection and feature map reconstruction stage transmits only foreground instance features (cropped by 2D detection boxes) to reduce bandwidth by ~12×. Second, a cascaded Instance Feature Aggregation (IFA) module uses predefined grid-shaped BEV queries that, via deformable attention, directly sample and aggregate features from all agents' 2D image views at each BEV grid location across multiple reference heights, bypassing the need for accurate single-agent BEV features or strict inter-agent pose alignment. Third, a Cross-Domain Query Adaptation (CDQA) module encodes each shared instance's GAP-pooled feature and a cone-encoded 3D position (from the 2D bounding box corners and camera origin projected to ego coordinates) into object queries, which are unioned with random queries to form hybrid queries for the deformable DETR decoder. The entire pipeline is trained end-to-end with focal loss for classification and L1 loss for box regression.

## Results

IFTR achieves state-of-the-art 3D detection performance across all three datasets. On V2XSet, it reaches AP@70 of 0.4967 (vs. 0.4396 for the previous best, Where2Comm), a 12.99% relative improvement. On OPV2V, IFTR attains AP@70 of 0.6604 (vs. 0.6046 for CoAlign), a 9.23% improvement. On the real-world DAIR-V2X dataset, IFTR achieves AP@70 of 0.0665 (vs. 0.0421 for Late Fusion), a 57.96% improvement over the previous best method.

## Baselines & Comparisons

IFTR outperforms all five compared baselines across every dataset and every IoU threshold. Against V2VNet [36], IFTR gains +0.1071 AP@70 on V2XSet (0.4967 vs. 0.3900) and +0.0845 on OPV2V (0.6604 vs. 0.5759). Against V2X-ViT [42], the AP@70 improvements are +0.0844 on V2XSet and +0.0766 on OPV2V. Against Where2Comm [9], IFTR leads by +0.0571 AP@70 on V2XSet and +0.0744 on OPV2V. Against CoBEVT [41], the margins are +0.0886 on V2XSet and +0.0670 on OPV2V. Against CoAlign [25], which is the strongest prior method on OPV2V (AP@70=0.6046), IFTR still achieves a +0.0558 improvement. On the real-world DAIR-V2X dataset, IFTR's advantage is most dramatic: it nearly doubles the AP@70 of the best prior method (0.0665 vs. 0.0421 for Late Fusion) and outperforms all intermediate-fusion baselines by 2.5× or more in AP@70.

## Relation to Prior Work

IFTR builds on BEVFormer as its single-agent backbone and Deformable DETR as its detection head, but departs fundamentally from the dominant BEV-feature-level fusion paradigm used by prior collaborative perception methods (V2VNet, V2X-ViT, Where2comm, CoBEVT, CoAlign). The key conceptual shift is moving fusion from the BEV plane to the instance level, motivated by the observation that camera-derived BEV features are inherently noisy due to the ill-posed 2D-to-3D lifting problem, making BEV-level fusion particularly fragile. The cross-domain query adaptation module is a novel bridge between 2D instance priors and 3D object queries, drawing on the cone-encoding idea to implicitly encode candidate 3D positions without requiring explicit depth estimation.

## Why It Matters / Open Questions

Camera-only collaborative perception is critical for budget-constrained deployments where LiDAR is impractical, yet prior methods have underperformed due to compounded errors in BEV feature generation. IFTR's robustness to localization noise (maintaining gains while BEV-level methods degrade) and its 12× bandwidth reduction via instance-level sharing address two major practical barriers to real-world V2X deployment. Open questions include whether the approach scales gracefully to larger agent counts in dense urban scenes, how it performs under more severe occlusion or adverse weather, and whether the instance-level fusion paradigm can be extended to other modalities (e.g., radar) or tasks (e.g., tracking, segmentation).

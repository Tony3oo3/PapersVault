## Problem

Compressing raw, unordered 3D point clouds is difficult because the irregular layout prevents forming local coding contexts for arithmetic coding, and existing point-based methods rely on global pooling or downsampling that cannot exploit spatial correlations among neighboring features. Additionally, prior approaches produce a fixed-cardinality reconstruction and require large models, making them impractical for real-time applications.
![Teaser figure](../imgs/ECCV20241820/cropped_page3_idx0.webp)

## Input / Output

The method takes a dense 3D point cloud of n points (normalized to [-1,1], typically 120k points sampled from a mesh) and produces a compressed bitstream. Upon decoding, the system reconstructs a point cloud at an arbitrary density controlled by a decoder-end upsampling rate r′ that can differ from the encoder rate, enabling both compression and arbitrary-scale upsampling from a single bitstream without retraining.

## Method

CRCIR uses a dual-layer architecture: a non-learning base layer (FPS downsampling → Google Draco compression → interpolation-based upsampling) reconstructs main geometry at very low complexity, while a learned refinement layer compresses the residuals via non-linear transform coding. The key novelty is a graph-based content-adaptive conditional entropy model that uses KNN on the sparse base-layer positions to define local neighborhoods over latent features, then learns a hyperprior via cascaded graph coarsening blocks (EdgeConv + FPS) to predict per-feature Gaussian means and scales for arithmetic coding. The refinement decoder incorporates an implicit neural representation that maps any query point's coordinates to its residual from the underlying surface, eliminating per-object INR retraining and enabling arbitrary-density point sampling. This design reduces model parameters and coding latency by two orders of magnitude compared to 3QNet while achieving comparable or better rate-distortion performance.

## Results

On ShapeNet, CRCIR achieves a ~2 dB PSNR improvement over 3QNet at the same bitrate (>0.6 bpp) and slight gains in Chamfer distance and point-to-mesh distance, while reducing model parameters by 381×, encoding latency by 158×, and decoding latency by 71× compared to 3QNet. In the upsampling evaluation on PU-GAN (×2 to ×8), CRCIR consistently achieves the lowest CD (e.g., 5.171×10⁻⁵ at ×8 vs. 16.846×10⁻⁵ for DPCC+Grad-PU) and P2M (4.873×10⁻⁵ vs. 11.208×10⁻⁵) with a fixed runtime of ~0.17 s regardless of upsampling rate, whereas Grad-PU-based baselines see runtime grow from ~2.3 s to ~31 s. The method also generalizes to the scene-level Redwood indoor dataset despite being trained only on ShapeNet CAD objects.

## Baselines & Comparisons

Against the SOTA learned method 3QNet [25], CRCIR achieves a ~2 dB PSNR gain at matched bitrate and slight CD/P2M improvements, while using 381× fewer parameters (0.056 M vs. 21.42 M) and running 158× faster in encoding (0.043 s vs. 6.867 s) and 71× faster in decoding (0.020 s vs. 1.447 s). Compared to DPCC [20], CRCIR significantly outperforms on all three RD metrics across the entire bitrate range, with the largest gap at low bitrates where DPCC's unconditional factorized entropy model fails to exploit local context. Against the non-learning baselines MPEG G-PCC [15] and Google Draco [14], CRCIR dominates on RD performance; the only trade-off is a marginal encoding-latency increase over Draco (0.043 s vs. 0.034 s). In the upsampling comparison (Table 2), CRCIR beats both DPCC+Grad-PU [21] and 3QNet+Grad-PU [21] on CD and P2M at every rate from ×2 to ×8 (e.g., at ×8: CD 5.171 vs. 16.846 and 18.164; P2M 4.873 vs. 11.208 and 16.276, all ×10⁻⁵), while maintaining a constant ~0.17 s runtime versus the Grad-PU baselines whose runtime scales linearly with the number of initialized points (up to ~31 s at ×8).

## Relation to Prior Work

This paper extends the non-linear transform coding (NTC) framework for point cloud compression by introducing a graph-based, content-adaptive conditional entropy model that exploits KNN-derived local neighborhoods—something prior point-based methods (DPCC, 3QNet) could not do due to the irregular, unordered layout of raw points. It also adapts the hyperprior architecture from learned image compression (Ballé et al., 2018) to an irregular graph setting via graph coarsening blocks, and borrows the INR-based decoder structure from Convolutional Occupancy Networks (Peng et al., 2020) to enable arbitrary-density surface sampling. The key departure from prior work is the dual-layer design: a non-learning base layer (FPS + Google Draco) handles low-frequency structure, while a small learned refinement layer with INR focuses on high-frequency details, inverting the typical assumption that a single large network must process all points.

## Why It Matters / Open Questions

The 2-orders-of-magnitude reduction in model parameters (381×) and coding latency (158× encoding, 71× decoding) while simultaneously matching or exceeding SOTA RD performance is practically significant for real-time applications like AR/VR and autonomous driving where compression must run on consumer hardware. The INR integration as a byproduct enables arbitrary-scale upsampling without retraining, which is a useful capability for downstream tasks. However, the authors acknowledge the method is less effective for highly sparse inputs like LiDAR data, and the RD improvement over 3QNet is modest (slight CD/P2M gain, ~2 dB PSNR at >0.6 bpp), so the primary value lies in the efficiency-accuracy trade-off rather than a fundamental RD breakthrough. Open questions include whether the graph-based entropy model generalizes to other irregular-signal compression tasks and whether the non-learning base layer can be further optimized.

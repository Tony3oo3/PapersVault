## Problem

Existing 3D vision-language datasets are task-specific and rely on language-only instructions, which are inherently ambiguous in cluttered real-world 3D scenes (e.g., distinguishing among multiple similar objects). No comprehensive dataset or benchmark exists for evaluating multi-modal LLMs on diverse 3D-centric tasks using interleaved multi-modal instructions that combine text with visual prompts like clicks, regions, images, and 3D shapes.
![Teaser figure](../imgs/ECCV20241537/cropped_page1_idx0.webp)

## Input / Output

The model takes a 3D point cloud (downsampled to 40,000 points) and an interleaved multi-modal instruction sequence as input. Instructions are structured as ordered sequences of text segments and visual prompts encoded via special tokens: <click>x,y,z</click> for 3D point coordinates, <region>cx,cy,cz,w,h,l</region> for scaled bounding boxes, <image>id</image> for RGB images, and <shape>id</shape> for 3D mesh models. The output is a free-form natural language response covering tasks from object detection coordinates to embodied planning trajectories and multi-round dialogues.

## Method

The baseline model comprises three modules: a Scene Perceiver (PointNet++ or Transformer 3D encoder + trainable projection matrix mapping scene features into LLM embedding space), a Multi-modal Instruction Adapter (MIA) that decouples and encodes each prompt type separately—text via LLM tokenizer, clicks/regions via learnable linear projections, images via frozen CLIP + LLaVA projector, and 3D shapes via a pre-trained encoder + trainable projection—and a frozen LLM decoder (OPT-6.7B or LLaMA-2-7B) that autoregressively generates responses. Training freezes the 3D encoder, image encoder, and LLM, updating only ~52M projection parameters (<1% of the LLM backbone) with a cosine-annealed Adam schedule. The dataset is constructed via a three-stage GPT-4 pipeline: template/prompt-based instruction-response generation, quality filtering with human verification, and visual prompt injection by substituting instance IDs with the four prompt types, yielding 327K pairs (138K+ with visual prompts).

## Results

The best-performing variant (Transformer encoder + OPT-6.7B decoder) achieves CIDEr scores of 50.62 (Dense Caption), 384.78 (Visual QA), 311.35 (Multi-region Reasoning), 240.51 (Embodied QA), and 256.59 (Embodied Planning). Incorporating interleaved multi-modal instructions over language-only instructions yields consistent ROUGE gains across all five tasks, with the largest improvements in Multi-region Reasoning (+9.64%) and Embodied Planning (+9.53%). In zero-shot evaluation on held-out tasks, LLaMA-2-7B outperforms OPT-6.7B (e.g., ROUGE 25.28 vs. 16.87 on Embodied QA), indicating stronger generalization from instruction tuning.

## Baselines & Comparisons

The paper does not compare against external 3D instruction-following baselines (e.g., LAMM, 3D-LLM, Chat-3D) since M3DBench introduces a novel interleaved multi-modal instruction format for which no prior method exists. Instead, internal ablations compare two 3D encoders (PointNet++ vs. Transformer) and two LLM decoders (LLaMA-2-7B vs. OPT-6.7B). The Transformer encoder consistently outperforms PointNet++ in 4 out of 5 tasks (e.g., CIDEr 384.78 vs. 256.98 on Visual QA with OPT), while OPT-6.7B surpasses LLaMA-2-7B on most supervised metrics (e.g., CIDEr 50.62 vs. 24.81 on Dense Caption with Transformer). A key finding is that multi-modal instructions (clicks, regions, images, 3D shapes) improve ROUGE over language-only instructions by 1.63–9.64% across tasks, with the largest gains in Multi-region Reasoning and Embodied Planning. In zero-shot transfer to unseen tasks, LLaMA-2-7B reverses the supervised ranking and outperforms OPT-6.7B (ROUGE 25.28 vs. 16.87 on EQA; 17.83 vs. 11.52 on EP), suggesting LLaMA-2's instruction tuning generalizes better to novel 3D tasks.

## Relation to Prior Work

This paper extends the 3D instruction-following paradigm established by LAMM (3D encoder + LLM with instruction-response templates) and the projection-based visual feature alignment from LLaVA, but departs from both by introducing interleaved multi-modal instructions that combine text with clicks, regions, images, and 3D shapes. Unlike prior 3D instruction datasets (LAMM-3D, 3DLLM, Chat-3D) that rely on language-only prompts and cover a narrow set of tasks, M3DBench unifies perception, reasoning, planning, and navigation under a single instruction format. The Multi-modal Instruction Adapter (MIA) is a new architectural component that decouples and encodes heterogeneous visual prompts into the LLM's token space, going beyond the single-modality projection layers used in LLaVA and LAMM.

## Why It Matters / Open Questions

M3DBench provides the first large-scale (320K+ pairs) unified 3D instruction dataset with multi-modal prompting, filling a critical gap that has limited progress in 3D multi-modal language models. The finding that multi-modal instructions yield consistent gains over language-only ones (up to +9.6% in multi-region reasoning) validates the intuition that 3D scenes are too ambiguous for text alone. However, the baseline is deliberately minimal (frozen encoders, ~52M trainable parameters), absolute performance remains low, and the heavy reliance on GPT-4 for both data generation and evaluation raises questions about data quality and evaluation reliability. Open questions include whether richer training strategies (unfreezing the LLM, better 3D encoders) can close the performance gap, and whether the multi-modal instruction format generalizes to real-time interactive 3D assistants.

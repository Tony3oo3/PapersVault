## Problem

Reconstructing 3D shapes of hand-held objects from a single image has been limited by the scarcity of real-world 3D shape supervision, as collecting paired image-3D data requires full object visibility or expensive manual alignment. Existing methods trained on small lab datasets with 3D annotations (10–50 object categories) fail to generalize to novel objects in the wild. This paper asks whether supervision can be extracted from abundant in-the-wild videos (2D masks) and synthetic shape collections (3D priors) to eliminate the need for real-world 3D supervision entirely.

## Input / Output

At test time, the model takes a single RGB image and hand pose parameters (MANO articulation, wrist rotation, camera intrinsics) estimated by FrankMocap, and predicts binary occupancy for 3D points in the hand coordinate frame, which is converted to a mesh via marching cubes. At training time, it additionally consumes multi-view video sequences with 2D object and hand segmentation masks from the VISOR dataset, along with synthetic 3D shapes from ObMan for the adversarial shape prior. The occupancy network is conditioned on global ResNet-50 image features, pixel-aligned features at the projected 3D point location, and hand articulation features computed in the 15-joint hand frame.

## Method

The core contribution is a two-module training framework for an occupancy network that avoids real-world 3D supervision. First, a 2D Mask Guided 3D Sampling module uses hand pose (from FrankMocap) as a proxy for object pose to register multi-view video frames, then applies visual-hull logic: a 3D point is labeled occupied only if it projects inside the object mask in all views and outside the hand mask, with rejection sampling in the hand coordinate frame to balance positive/negative points. Second, a 2D Slice-based 3D Discriminator learns shape priors from ObMan by sampling random 2D planes through the hand coordinate origin (with arbitrary rotations) and training a discriminator on the cross-section occupancy patterns, which is more computationally efficient and captures finer shape details than 3D volume inputs. The occupancy network is trained with a combined loss of cross-entropy on visual-hull labels, multi-view consistency regularization, and adversarial gradients from the discriminator, trained jointly on ObMan (synthetic 3D) and the curated Wild Objects in Hands dataset (473 video snippets, 144 object categories from VISOR).

## Results

On the MOW in-the-wild object generalization benchmark, HORSE achieves F@5=0.121, F@10=0.220, and CD=6.76 mm, representing an 11.6% relative improvement over the best 3D-supervised baseline (AC-SDF trained on ObMan: F@5=0.108, F@10=0.199, CD=7.82 mm) and a 16.8% improvement over AC-SDF trained on ObMan+HO3D+HOI4D with full 3D supervision. On HO3D object generalization, HORSE reaches F@5=0.20, F@10=0.35, CD=3.39 mm, outperforming AC-SDF trained with 3D supervision on ObMan+MOW+HOI4D (F@5=0.17, F@10=0.33, CD=3.63 mm). On HO3D view generalization, HORSE achieves F@5=0.23, F@10=0.43, CD=1.41 mm, substantially exceeding HO (F@5=0.11) and GF (F@5=0.12) trained with full 3D supervision on HO3D.

## Baselines & Comparisons

HORSE outperforms AC-SDF [73] (the closest prior method) on all three MOW metrics without using any real-world 3D supervision, achieving 11.6% relative gains in F-score and 13.5% in CD. Against AC-SDF trained on ObMan+HO3D+HOI4D with full 3D annotations, HORSE still wins by 16.8% across all metrics, indicating that diverse 2D mask supervision from in-the-wild videos is more effective than limited 3D supervision from lab datasets. On HO3D view generalization, HORSE (F@5=0.23, CD=1.41) substantially outperforms both HO [22] (F@5=0.11, CD=4.19) and GF [31] (F@5=0.12, CD=4.96), which are trained with full 3D supervision on HO3D. In the broader comparison on MOW (Table 4), HORSE beats AlignSDF [10] (F@5: 0.121 vs 0.099) and gSDF [9] (F@5: 0.121 vs 0.107) on both F-scores and CD. The one exception is DDFHO [77], which achieves a notably lower CD (3.06 vs 6.76) but trails HORSE on F@5 (0.094 vs 0.121) and F@10 (0.166 vs 0.220), suggesting DDFHO produces tighter but less complete reconstructions.

## Relation to Prior Work

This paper builds directly on the AC-SDF architecture (Ye et al., CVPR 2022) and occupancy network formulation (Mescheder et al., CVPR 2019) for single-image 3D hand-held object reconstruction, but fundamentally changes the training paradigm: instead of requiring paired real-world 3D shape supervision (as in AC-SDF, HO, GF, AlignSDF, gSDF, DDFHO), it extracts supervision from in-the-wild video via a visual-hull-style 2D mask guided sampling strategy and learns shape priors from synthetic collections through a 2D slice-based adversarial discriminator. The visual hull concept is repurposed from classical multi-view reconstruction (Laurentini 1994) to a training-time supervision mechanism, and the 2D slice discriminator adapts 3D GAN ideas (Wu et al., 2016) to a computationally efficient cross-section representation. The key conceptual departure is treating hand pose (from FrankMocap) as a proxy for object pose to register multi-view frames, sidestepping the need for structure-from-motion on the object itself.

## Why It Matters / Open Questions

The paper demonstrates that diverse in-the-wild 2D supervision (144 object categories from VISOR) can outperform limited lab 3D supervision (HO3D + HOI4D, ~17 categories) for zero-shot generalization to novel objects, challenging the assumption that 3D ground truth is strictly necessary. This opens a path to scaling hand-held object reconstruction training data by orders of magnitude using existing video datasets without expensive 3D annotation. Key limitations remain: reliance on FrankMocap accuracy (inaccurate poses cause missed object regions), the rigid hand-object coupling assumption, and the fact that wild videos rarely capture 360° views. Open questions include whether hand pose and object shape can be jointly optimized, whether contact priors can further improve occluded regions, and whether the approach extends to articulated or deformable objects.

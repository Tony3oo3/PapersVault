## Problem

Existing Prompt-based Continual Learning (PCL) methods require two separate ViT feed-forward stages—one for a query ViT that generates input-specific prompt queries and one for the backbone ViT that mixes prompts with image tokens—doubling computational cost and hindering deployment on resource-constrained devices. This paper asks whether the query-generation stage can be eliminated without sacrificing accuracy.
![Teaser figure](../imgs/ECCV20240333/cropped_page1_idx0.webp)

## Input / Output

The method takes a standard RGB image as input and outputs a class label via the [CLS] token of a ViT-B/16 backbone pre-trained on ImageNet-1k. It operates in a class-incremental continual learning setting where task identity is unknown at inference, and prompts are injected only into the first 5 transformer layers via prefix-tuning (splitting each prompt into key and value components prepended to self-attention). The prompt pool contains 100 components of length 8, with components from prior tasks frozen during each new stage.

## Method

OS-Prompt eliminates the separate query ViT by directly using the [CLS] token embedding from an intermediate backbone layer as the prompt query, justified by the empirical observation that early-layer token embeddings remain stable (≤0.1 cosine distance shift) across continual learning stages while deeper layers drift significantly. The query is then used with CodaPrompt's weighted-summation mechanism to form layer-wise prompts from the prompt pool, reducing inference GFLOPs by ~50%. To compensate for the reduced representational capacity of intermediate-layer queries, OS-Prompt++ introduces a Query-Pool Regularization (QR) loss that penalizes the L2 distance between the softmax-normalized similarity matrix of the intermediate query and that of a reference ViT's final-layer [CLS] token, applied only during training so inference cost remains halved. This yields ~1.4% accuracy improvement over CodaPrompt on ImageNet-R while maintaining the 50% inference cost reduction.

## Results

On ImageNet-R (10-task setting), OS-Prompt++ achieves 75.67% average accuracy (A_N) and 1.27% forgetting (F_N), outperforming the prior SOTA CodaPrompt (75.45% A_N, 1.64% F_N) by ~0.2% in accuracy and ~0.4% in forgetting. On CIFAR-100 (10-task), OS-Prompt++ reaches 86.68% A_N and 1.18% F_N, surpassing CodaPrompt (86.25%, 1.67%). Critically, OS-Prompt reduces inference GFLOPs to 50.1% of prior PCL methods (17.6 vs 35.1 GFLOPs), and OS-Prompt++ maintains this 50.1% inference efficiency since the QR loss is training-only.

## Baselines & Comparisons

OS-Prompt++ outperforms all five baselines across all task settings on both A_N and F_N. Against the strongest prior PCL method CodaPrompt, OS-Prompt++ gains +0.22% A_N and reduces F_N from 1.64% to 1.27% on ImageNet-R 10-task, and +0.43% A_N with F_N dropping from 1.67% to 1.18% on CIFAR-100 10-task. The gap over earlier PCL methods is larger: OS-Prompt++ beats DualPrompt by +4.35% A_N and L2P by +6.38% A_N on ImageNet-R 10-task. Against non-PCL baselines, the advantage is substantial—OS-Prompt++ exceeds ER by +11.24% A_N and LwF by +8.94% A_N on ImageNet-R 10-task. Notably, OS-Prompt (without QR loss) shows only a ≤1% accuracy drop relative to CodaPrompt while halving inference GFLOPs, confirming the efficiency-accuracy trade-off is minimal.

## Relation to Prior Work

This paper sits squarely within the rehearsal-free Prompt-based Continual Learning (PCL) lineage initiated by L2P, extended by DualPrompt's general/task-specific prompt decomposition, and advanced by CodaPrompt's end-to-end weighted prompt summation. Its core departure is architectural rather than algorithmic: instead of the standard two-stage design (a frozen query ViT producing a prompt query, followed by a backbone ViT performing prompt-augmented inference), OS-Prompt collapses these into a single backbone ViT pass by repurposing an intermediate layer's [CLS] token as the prompt query. The Query-Pool Regularization loss is a new training-time objective that aligns the intermediate-query-to-prompt-pool similarity distribution with that of a reference ViT's final-layer query, compensating for the reduced representational capacity without adding inference cost.

## Why It Matters / Open Questions

The ~50% inference GFLOPs reduction is practically significant for deploying PCL on edge or resource-constrained devices, a gap the authors explicitly flag as a barrier to real-world adoption. The QR loss being training-only means the efficiency gain is preserved at inference, and the method's compatibility with different prompt formation strategies (L2P, DualPrompt, CodaPrompt) makes it a drop-in efficiency layer rather than a monolithic system. A key limitation is that OS-Prompt++ restores full training cost via the reference ViT, which undermines the efficiency story for online continual learning where rapid per-sample training is critical. Open questions include whether the stability of early-layer embeddings holds for deeper or differently-architected backbones, and whether the QR loss generalizes to non-ViT or multimodal continual learning settings.

## Problem

Existing compressed image super-resolution (CSR) methods are typically trained and evaluated on a single compression codec (usually JPEG), yet real-world applications involve a wide variety of traditional (HEVC, VVC) and learning-based (HIFIC, Cheng) codecs with distinct degradation characteristics. No universal framework existed that could simultaneously handle the hybrid distortions from all these diverse codecs within a single model, and no comprehensive benchmark covered this multi-codec setting.
![Teaser figure](../imgs/ECCV20241244/cropped_page4_idx0.webp)

## Input / Output

The method takes a compressed low-resolution RGB image (downsampled by ×4 via bicubic, then compressed with any of 6 codecs at various quality/bitrate levels) and produces a high-resolution RGB image. A key design property is resolution independence: the dynamic prompt mechanism uses only 1×1 spatial prompt bases with spatially-varying coefficients, so the model handles arbitrary input sizes without resizing prompts. The same trained model is evaluated across all 6 codecs (JPEG, HEVC/HEVC-intra, VVC, Cheng_PSNR, Cheng_SSIM, HIFIC) without codec-specific adaptation.

## Method

UCIP introduces a Dynamic Prompt Generation Module (DPM) that maintains D=8 learnable 1×1×Cp basic prompts and generates spatial-wise composable coefficients (H×W×D) from input features via a single MLP layer followed by softmax, producing a full-resolution dynamic prompt that is both content/spatial-adaptive and task-adaptive. This prompt guides a Prompt-guided Token Mixer Block (PTMB), which adapts the Active Token Mixer (ATM) from ActiveMLP to low-level vision: the prompt is concatenated with input features to condition deformable-convolution-based offset prediction for horizontal and vertical token mixing, while a 3×3 depthwise convolution captures local information; the three resulting tokens are adaptively fused with learned channel-wise weights and further modulated by the prompt via a SPADE block. The full network stacks 6 PTMBs (each containing 6 cascaded PTMMs sharing one prompt) between a patch-embedding front-end and a convolutional up-sampling head, trained end-to-end with L1 loss on DF2K images degraded by all 6 codecs. The authors also introduce the UCSR benchmark dataset covering 23 common degradation configurations across the 6 codecs, enabling fair all-in-one evaluation.

## Results

UCIP achieves consistent PSNR/SSIM gains across all 6 codecs (JPEG, HEVC, VVC, C_PSNR, C_SSIM, HIFIC) and 5 evaluation datasets (Set5, Set14, BSD100, Urban100, Manga109). On Set5 with JPEG Q=10, UCIP reaches 25.05 dB PSNR / 0.715 SSIM, outperforming the best baseline MAXIM (24.83/0.709) by 0.22 dB. The paper reports up to 0.45 dB PSNR gain over PromptIR while using only 11.42M parameters (vs. PromptIR's 35.72M, roughly one-third). Gains are most pronounced at higher compression ratios (e.g., JPEG Q=10, HM Q=47), where severe artifacts demand stronger contextual modeling.

## Baselines & Comparisons

UCIP outperforms all six baselines (RRDB, SwinIR, Swin2SR, MAXIM, AIRNet, PromptIR) on nearly every codec–quality–dataset combination in Tables 1 and 2. Against the strongest transformer-based baseline Swin2SR, UCIP gains 0.25 dB PSNR on Set5/JPEG Q=10 (25.05 vs. 24.80) and 0.23 dB on Set14/JPEG Q=10 (23.93 vs. 23.79). Against the MLP-based MAXIM (26.74M params), UCIP (11.42M params) still leads by 0.22 dB on Set5/JPEG Q=10 while using roughly 40% fewer parameters. The largest margin is over PromptIR (35.72M params): up to 0.45 dB PSNR on Set5/JPEG Q=10, with UCIP using only one-third the parameters. Gains widen at higher compression ratios (e.g., HM Q=47, JPEG Q=10), where severe block/ring artifacts make contextual token selection more critical. On learning-based codecs (Table 2), UCIP maintains consistent 0.05–0.30 dB advantages, with the largest gap on HIFIC 'low' quality (21.94 vs. 21.49 for PromptIR on BSD100).

## Relation to Prior Work

UCIP builds on the Active Token Mixer (ATM) from ActiveMLP, adapting its deformable-convolution-based horizontal/vertical token mixing to low-level vision for the first time, and augments it with a local 3×3 convolution branch to compensate for MLP-like models' weak local perception. The dynamic prompt strategy departs from PromptIR's full-image-size learnable prompts by decomposing them into a small set of 1×1 base prompts combined with spatially-varying coefficients, reducing prompt parameters from ~9.7M to 0.46M while gaining spatial adaptivity. Conceptually, the paper positions itself against the Transformer-based CSR line (SwinIR, Swin2SR, HST) by arguing that global self-attention is computationally prohibitive and that implicit contextual modeling via offset-predicted token mixing suffices for restoration.

## Why It Matters / Open Questions

The UCSR benchmark covering six codecs (JPEG, HEVC, VVC, Cheng_PSNR, Cheng_SSIM, HIFIC) with 23 degradation levels is the first comprehensive evaluation suite for universal CSR, filling a gap where prior work only addressed JPEG. The finding that tuning only the small prompt module on unseen codecs (WebP, ELIC) achieves performance comparable to full-model fine-tuning suggests a practical pathway for rapid adaptation to new compression standards without retraining. Open questions include whether the framework generalizes to truly novel codec architectures, whether subjective quality (LPIPS, FID) matches the PSNR/SSIM gains, and whether the MLP-like backbone can scale to higher-resolution or video restoration tasks.

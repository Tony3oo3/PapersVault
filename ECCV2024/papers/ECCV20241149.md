## Problem

Existing image-to-video adaptation methods insert lightweight temporal modules (attention, convolutions) into frozen image backbones, but they suffer from two key limitations: (1) tuning parameters in shallow Transformer layers still demands substantial GPU memory during backpropagation, and (2) basic temporal modules operate on highly redundant frame-level features without an inductive bias that mirrors how humans actually perceive video — as changes in object states. This makes both efficiency and interpretability of the adaptation process unsatisfactory.

## Input / Output

The method takes a video clip of T RGB frames (each cropped to 224×224) and produces an action class prediction via a linear head on a pooled video-level feature. As a side-product, the slot attention weights from the object decomposition stage directly yield per-frame object segmentation masks (N=8 slots), enabling zero-shot video object segmentation without any mask annotations. The temporal state change vectors are computed over sparsely sampled frame pairs at interval δ (default T/4), so the model does not require dense frame-by-frame fusion.

## Method

The core architecture freezes a CLIP ViT backbone and applies a variant of slot attention with N=8 learnable query tokens to decompose each frame's feature map into N compact object tokens, replacing random slot initialization to encourage temporally coherent object identities. These object tokens then pass through two interaction stages: (1) intra-frame self-attention to capture inter-object context, and (2) a temporal interaction MLP that concatenates the same-index object states at frames t and t+δ to produce a state-change vector per object. Training uses three losses: a contrastive object distillation loss aligning object tokens with the frozen CLS token, a margin-based temporal reasoning loss enforcing consistent state changes for same-action/same-object pairs while separating different actions or objects, and standard cross-entropy classification. This design reduces tunable parameters to ~5% of full finetuning and ~50% of prior efficient tuning methods while achieving state-of-the-art accuracy on K-400, SSv2, and EK100.

## Results

On Kinetics-400, the proposed method with ViT-L/14 achieves 88.5% Top-1 accuracy using only 21M tunable parameters and 5068 GFLOPs, surpassing DiST (88.0%, 8490 GFLOPs) and all fully finetuned models (≤84.3%). On Something-Something-v2, it reaches 73.6% Top-1, outperforming MViTv2-L (73.3%) and DiST (73.1%) with ~40% fewer GFLOPs. On Epic-Kitchens-100, it achieves 51.7% Action accuracy, leading all efficient tuning baselines. In zero-shot video object segmentation on DAVIS-2017-UVOS, the model trained on K-400 attains 44.7 J&F, exceeding the supervised RVOS baseline (41.2) and the unsupervised BA method (43.9).

## Baselines & Comparisons

On K-400, the method with ViT-L/14 (88.5%) outperforms the strongest efficient tuning baseline DiST ViT-L/14 (88.0%) by 0.5 points while using 40% fewer GFLOPs (5068 vs. 8490), and beats all fully finetuned models (best: MTV-L at 84.3%) with only 21M tunable parameters versus 876M. On SSv2, it surpasses MViTv2-L (73.3%) and DiST ViT-L/14 (73.1%) by 0.3–0.5 points with substantially lower computation. On EK100, it leads all efficient tuning methods (DiST ViT-L/14: 48.9% Action) by 2.8 points, with particularly strong gains on Noun (64.5 vs. 61.6). In zero-shot DAVIS-2017-UVOS segmentation, the K-400-trained model (44.7 J&F) exceeds the unsupervised BA method (43.9) and the supervised RVOS baseline (41.2), though it trails the fully supervised state-of-the-art. Notably, with only 8 input frames on ViT-B/16, the method already matches or exceeds 32-frame baselines (e.g., 85.8% vs. DualPath 85.4% on K-400), demonstrating the efficiency of object-centric temporal reasoning over dense frame fusion.

## Relation to Prior Work

This paper builds on slot attention (Locatello et al., NeurIPS 2020) and learnable query initialization (Qian et al., ICCV 2023) for object decomposition, but departs fundamentally from prior image-to-video adaptation methods (ST-Adapter, AIM, DiST, DualPath) that insert dense temporal modules into frozen ViT layers. Rather than modeling temporal dynamics on highly redundant full-frame features, it compresses each frame into a small set of object tokens and performs temporal reasoning exclusively on these compressed representations. It also diverges from object-centric video representation work (ORVIT, Object-centric Video Representation) that relies on bounding box annotations, external detectors, or additional modalities, by using only a contrastive distillation loss to extract object knowledge from the frozen image backbone.

## Why It Matters / Open Questions

The object-centric formulation offers a principled inductive bias for temporal reasoning that reduces both parameter count (5% of full finetuning) and computation (40% fewer GFLOPs than DiST) while achieving SOTA action recognition, making efficient video understanding more accessible. The zero-shot video object segmentation result—where slot attention weights directly serve as segmentation masks without any segmentation training—validates that the learned object tokens capture genuine object semantics, providing interpretability that dense temporal modules lack. Open questions include whether the fixed slot count (N=8) scales to scenes with many objects, whether question-conditioned slot attention could adapt decomposition for video QA, and how to close the remaining gap to supervised segmentation boundaries.

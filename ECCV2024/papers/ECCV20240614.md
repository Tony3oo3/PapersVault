## Problem

Existing data-efficient generalist models for dense visual prediction either unify a fixed set of pre-defined tasks or rely on in-context learning that fails to generalize to out-of-distribution tasks with unseen label structures and semantics (e.g., 6D pose, animal keypoints, cell flow fields). No prior method can flexibly adapt to arbitrary dense prediction tasks in the wild using only a handful of labeled examples while handling variable input modalities and output structures.
![Teaser figure](../imgs/ECCV20240614/cropped_page0_idx0.webp)

## Input / Output

Chameleon accepts a multi-modal query image with an arbitrary number of input channels I_T (e.g., a single RGB image, a stereo pair, or an RGB image plus an exemplar guide) at task-specific resolution (H_T, W_T), along with a small support set of 1–50 labeled examples. It produces a per-pixel dense prediction Y^q ∈ R^{O_T × H_T × W_T} where the number of output channels O_T and their semantics are entirely task-defined (segmentation masks, multi-channel keypoint heatmaps, dense 3D vertex correspondences for 6D pose, object-center heatmaps, or cell flow fields). The model requires no architectural modification when the number of input modalities or output channels changes across tasks.

## Method

Chameleon builds on the Visual Token Matching framework, formulating dense prediction as token-level similarity matching between query and support images, with three key improvements. First, a variable-input transformer encoder patchifies all modalities jointly and uses a learnable positional embedding indexed by modality pair (m, m′) and relative spatial offset (h−h′, w−w′), enabling the model to adapt inter-modal relationships per task. Second, a hierarchical feature re-weighting mechanism extracts image and label features at L levels and applies a task-specific L×L matrix Λ_T (rows normalized to sum to 1) to re-weight multi-level image features before matching at each level, allowing the model to learn arbitrary image-to-label feature correspondences. Third, the task-specific parameters θ_T = (P_T, b_T, Λ_T) occupy a small fraction of total parameters and are fine-tuned on the support set after episodic meta-training on 1.2M images spanning 17 tasks from six diverse datasets, with the backbone scaled to BEiTv2-Large and the label encoder to ViT-Large.

## Results

Chameleon achieves strong low-shot performance across six diverse dense prediction tasks using at most 50 labeled examples per task. Headline results include: 67.2 AP on AP-10K animal keypoint detection, 85.2 ADD on LineMOD 6D pose estimation, 88.5 F1 on ISIC 2018 skin lesion segmentation, 77.5 J&F on DAVIS 2017 video object segmentation, 12.0 MAE on FSC-147 object counting, and 70.3 AP50 on Cellpose cell instance segmentation. In several cases (skin lesion, cell segmentation, object counting), Chameleon approaches or matches fully-supervised specialist baselines while using only dozens of labels.

## Baselines & Comparisons

Chameleon dramatically outperforms all generalist baselines across every task. Against VTM (the direct predecessor), Chameleon improves AP-10K from 9.1 to 67.2, LineMOD from 59.3 to 85.2, and DAVIS 2017 from 54.0 to 77.5. Against Painter and SegGPT (even with prompt tuning), Chameleon achieves 67.2 vs. 2.0 AP on animal keypoints, 85.2 vs. 23.1 ADD on 6D pose, and 77.5 vs. 67.0 J&F on video segmentation. Against fully-supervised specialists, Chameleon is competitive: it reaches 88.5 F1 on skin lesion segmentation (vs. 89.8 for UNeXt), 70.3 AP50 on cell segmentation (vs. 70.4 for Cellpose), and 12.0 MAE on object counting (matching CounTR). The largest gaps to specialists remain on 6D pose (85.2 vs. 89.9 CDPN) and video segmentation (77.5 vs. 88.2 ISVOS), where task-specific architectures and temporal modeling provide substantial advantages.

## Relation to Prior Work

Chameleon builds directly on Visual Token Matching (VTM), which formulated dense prediction as a token-level matching problem between query and support images, but VTM was demonstrated only in a constrained indoor-scene setting. This paper departs from VTM along three axes: a transformer-based multi-modal encoder with learnable inter-modal positional biases, a task-adaptive feature re-weighting module that learns per-task correspondences between hierarchical image and label features, and a substantially larger and more diverse meta-training corpus (six datasets, 17 tasks). It positions itself against in-context learning generalists (Painter, SegGPT) that struggle with out-of-distribution label structures, and against multi-task learning approaches that cannot generalize to unseen tasks at all.

## Why It Matters / Open Questions

The paper demonstrates that a single model can adapt to six fundamentally different dense prediction tasks—spanning 3D pose, video tracking, medical segmentation, biological imaging, and interactive counting—with at most 50 labeled examples, sometimes matching or exceeding fully-supervised specialists. The learned feature re-weighting reveals that different tasks require different image-to-label feature-level correspondences (e.g., 6D pose leverages high-level semantics for fine-grained details), offering insight into how hierarchical representations serve diverse prediction targets. Open questions include whether the approach can handle tasks requiring genuine temporal reasoning beyond frame-matching, whether it scales to truly arbitrary output structures (e.g., variable-length sequences), and how performance degrades when support sets drop below 10 examples.

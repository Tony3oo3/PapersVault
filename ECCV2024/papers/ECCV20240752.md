## Problem

Most test-time adaptation (TTA) methods rely on in-batch normalization statistics computed from the current test batch, which become highly unreliable as batch size shrinks. This causes severe performance degradation in practical deployment scenarios where edge devices and real-time constraints limit input batches to sizes as small as 1–4, yet prior benchmarks predominantly evaluate TTA with large batches (e.g., 200) that are infeasible in the field.

## Input / Output

MemBN consumes a stream of unlabeled RGB test images processed in small online batches (sizes 1–200) through a pretrained CNN with standard BN layers, requiring no labeled data or preprocessing. It outputs class predictions (classification) or pixel-wise segmentation masks (semantic segmentation) while internally maintaining per-layer FIFO memory queues of length 128 that store channel-wise mean and variance vectors from recent test batches. The method imposes minimal computational overhead beyond the queue operations, making it suitable for real-time edge deployment.

## Method

MemBN introduces per-BN-layer statistics memory queues that accumulate in-batch mean and variance in a first-in-first-out manner, then computes average memory statistics (with a corrected variance formula) to simulate the reliability of large-batch normalization without increasing input size. A domain-shift detection mechanism compares the current in-batch statistics against in-memory statistics using a standard-score threshold; when a shift is detected, all memory queues are reset to prevent stale statistics from contaminating the new domain. A layer-wise adaptive weighting factor α, derived from the relative Euclidean distances between in-batch, source, and average memory statistics, interpolates between source and memory statistics so that layers with small domain shift retain more source knowledge. Finally, a batch renormalization step (stop-gradient on in-batch statistics) ensures gradients flow through the normalization factors during test-time optimization, preventing unbounded parameter growth.

## Results

On CIFAR10-C (severity 5, WideResNet-40-2), TENT+MemBN achieves 11.55% average error across all batch sizes (200 to 1), compared to TENT's 32.51% and TENT+TTN's 13.77%. On ImageNet-C (ResNet-50), EATA+MemBN reaches 58.42% average error versus EATA's 77.15%, and MemBN alone (normalization-only) achieves 67.57% versus TBN's 86.40%. At the extreme of batch size 1, MemBN maintains 12.88% error on CIFAR10-C while TBN degrades to 90.00%. For semantic segmentation (DeepLabV3+), TENT+MemBN achieves 50.94 mIoU on BDD-100K at batch size 1, outperforming TENT (40.78) by over 10 points.

## Baselines & Comparisons

MemBN consistently outperforms all normalization-based baselines (TBN, AdaptiveBN, α-BN, MixNorm, TTN) at small batch sizes (≤4), where TBN degrades catastrophically (90% error at batch 1 on CIFAR10-C) while MemBN stays near 12–13%. Against TTN [20], the closest competitor, MemBN wins by 1.4 points average on CIFAR10-C (12.48 vs 13.89) and 5.0 points on CIFAR100-C (37.26 vs 42.27), and crucially does not require the additional post-training phase TTN needs. On ImageNet-C, MemBN surpasses GN [40] (67.57 vs 69.38 avg error) and TTN (67.57 vs 78.48) across all batch sizes. When combined with optimization-based TTA, MemBN improves TENT by 21 points average on CIFAR10-C (11.55 vs 32.51), EATA by 18.7 points on ImageNet-C (58.42 vs 77.15), and TeSLA by 15.3 points (62.66 vs 77.92). In the continual TTA setting, TENT+MemBN (11.66 avg) outperforms CoTTA (40.48 avg) by nearly 29 points on CIFAR10-C. In the temporally correlated setting, MemBN (78.70 avg) beats NOTE [7] (83.74 avg) by 5 points on ImageNet-C.

## Relation to Prior Work

MemBN extends the line of normalization-based TTA methods (TBN, AdaptiveBN, α-BN, MixNorm, TTN) that interpolate source and in-batch statistics to handle distribution shift, but departs from them by replacing the single in-batch statistic with a FIFO memory queue that aggregates statistics from multiple recent test batches, effectively simulating large-batch statistics without increasing input size. It also builds on batch renormalization (Ioffe, 2017) to maintain gradient flow through the normalization layer during test-time optimization, and on NOTE's (Gong et al., 2022) observation that temporally correlated streams bias in-batch statistics. Unlike TTN, which requires a post-training phase to learn layer-wise interpolation weights, MemBN computes its adaptive weighting entirely online from the current in-batch statistics, requiring no additional training.

## Why It Matters / Open Questions

The paper addresses a critical practical gap: most TTA methods are benchmarked at batch size 200, but real-world deployment on edge devices and under real-time constraints typically involves batch sizes of 1–16, where in-batch statistics become unreliable and performance collapses. MemBN's plug-and-play design (compatible with TENT, TeSLA, EATA, and CoTTA) and minimal overhead make it immediately deployable, and the memory reset mechanism for domain shift detection adds robustness in continual settings. A key limitation is that the method is restricted to batch normalization and does not extend to LayerNorm, excluding Vision Transformer backbones; extending the memory-based statistics approach to LN or other normalization schemes remains an open question. The method also assumes a stationary or slowly changing test domain within the memory window, and its behavior under rapid, frequent domain oscillations is not fully characterized.

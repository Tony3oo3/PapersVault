## Problem

Traditional UDA for semantic segmentation assumes identical class taxonomies between source and target domains, but real-world scenarios often involve open taxonomy (new classes appearing only in the target) or coarse-to-fine taxonomy (source classes split into sub-classes in the target). Existing approaches like TACS require a small amount of labeled target data, and prior open-set domain adaptation work is limited to image classification. This paper addresses the gap of performing domain-adaptive segmentation under mixed inconsistent taxonomies without any target domain ground truth.

## Input / Output

The method consumes RGB images from a labeled source domain (e.g., Synthia at 1280×760, GTA at 1920×1080) and unlabeled target images (e.g., Cityscapes at 2048×1024, ACDC at 1920×1080), along with the known class name lists for both domains. The class names are expanded into concept sets (e.g., 'Car' → {Car, SUV, jeep, Van}) to form text prompts for the VLMs. The output is a pixel-level segmentation mask covering all target-domain classes, including those absent from the source (e.g., terrain, truck, train on Cityscapes), evaluated with mIoU over the full target taxonomy (19 or 18 classes) rather than the restricted source taxonomy (16 classes).

## Method

CSI augments a standard self-training UDA pipeline (e.g., MIC+HRDA with DAFormer backbone) with a VLM-based zero-shot relabeling stage. The key insight is that UDA pseudo-labels overfit target-only classes to visually similar source classes (e.g., train predicted as bus), so the spatial segment reasoning is correct but the semantic assignment is wrong. During training, OWL-ViT performs zero-shot object detection on target images for target-exclusive classes, and CLIP validates each detected patch via zero-shot classification to filter false positives. Validated patches are relabeled by replacing the overfitted source class (Map.From) with the correct target class (Map.To) in the pseudo-label, then pasted back for student training. For open-taxonomy classes where the source-to-target mapping is unknown, the method auto-configures the Map by training for 8K steps, then identifying which source class dominates the pseudo-labels in detected regions between 8K–12K steps, and initiating relabeling at 12K.

## Results

On Synthia-to-Cityscapes, MIC+CSI achieves mIoU₁₆ = 68.8 and mIoU₁₉ = 67.4, outperforming the previous best UDA method by +0.6 mIoU on 16 classes and +9.9 mIoU on 19 classes (which include terrain, truck, and train absent from the source). On GTA-to-Cityscapes, MIC*+CSI reaches mIoU₁₈ = 73.1 versus 62.6 for MIC* (trained without target-only classes), a +10.5 gain. On the more challenging Synthia-to-ACDC benchmark, MIC+CSI achieves mIoU₁₉ = 47.0 versus 37.7 for MIC, a +9.3 improvement, while also gaining +1.5 mIoU on the 16 shared classes.

## Baselines & Comparisons

The paper compares CSI against DAFormer, HRDA, and MIC (all with and without CSI) across three domain pairs. On Synthia-to-Cityscapes, MIC+CSI beats the previous SOTA by +0.6 mIoU₁₆ and +9.9 mIoU₁₉, with the largest gains on the three target-only classes (terrain, truck, train). On GTA-to-Cityscapes, adding CSI to MIC* (which lacks labels for terrain/truck/train in the source) lifts mIoU₁₈ from 62.6 to 73.1 (+10.5), recovering 93% of the fully-labeled MIC performance (75.9) on the train class alone. On Synthia-to-ACDC, MIC+CSI improves mIoU₁₉ from 37.7 to 47.0 (+9.3) and mIoU₁₆ from 44.7 to 46.2 (+1.5), showing that relabeling target-only classes also benefits shared classes (e.g., car gains +10.5 IoU). CSI consistently improves mIoU₁₆ across all tested UDA backbones (DACS, DAFormer, HRDA, MIC), confirming it is a plug-and-play module rather than being tied to a specific architecture.

## Relation to Prior Work

This paper builds on the self-training UDA pipeline (DAFormer → HRDA → MIC) that generates pseudo-labels via a teacher-student EMA framework, and repurposes the spatial segment reasoning those models produce by correcting only the semantic (class-assignment) component using VLMs. It departs from TACS, the first method to address open and coarse-to-fine taxonomy in segmentation, by eliminating the need for any labeled target data, and from open-set domain adaptation work (which focuses on flagging unseen classes in image classification) by actually relabeling pixels to the correct target-domain class. The conceptual framing of decomposing segmentation into 'segment reasoning' and 'semantic reasoning' and fixing only the latter with zero-shot VLM inference is the paper's key positioning relative to prior UDA literature.

## Why It Matters / Open Questions

The result that zero-shot VLM relabeling improves not only the previously-unpredictable target-only classes but also the mIoU on source-common classes (the 'synergy' effect) suggests that correcting semantic confusion for one class group can disambiguate related classes, a finding with broader implications for pseudo-label refinement in UDA. Limitations include dependence on OWL-ViT's detection quality (which degrades for visually similar classes like van vs. truck), per-domain threshold tuning, and evaluation restricted to driving-scene benchmarks. Open questions include whether the approach generalizes to non-driving domains with more diverse taxonomies, whether stronger VLMs would reduce the need for CLIP-based filtering, and how the method scales when many (rather than 2–3) classes are inconsistent.

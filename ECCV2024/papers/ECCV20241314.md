## Problem

Existing open-vocabulary 3D scene understanding methods rely on either image or text supervision in isolation, failing to exploit the synergistic benefits of all modalities jointly. Image-based distillation (e.g., OpenScene) degrades open-vocabulary ability because 2D models are fine-tuned on in-vocabulary data, while text-based alignment (e.g., PLA, RegionPLC) captures only coarse image- or region-level descriptions without dense point-to-text correspondences. No prior work densely co-embeds 3D points, 2D pixels, and 1D texts into a shared latent space while preserving the open-vocabulary recognition capability of the 2D backbone.

## Input / Output

At inference, the method requires only a 3D point cloud (voxelized at 2 cm for indoor scenes, 5 cm for outdoor) and an arbitrary text query (a category name or free-form scene description), producing per-point semantic segmentation labels with 0.07 s latency. Unlike 2D-3D hybrid baselines that need multi-view image inference at test time (89–103 s), DMA's 3D-only inference path avoids the computational overhead of running a large 2D encoder. The text queries are not restricted to a fixed vocabulary; the model can segment regions for unseen categories (e.g., 'Snoopy') or functional areas (e.g., 'kitchen') by computing cosine similarity between point features and CLIP text embeddings.

## Method

DMA constructs a dense triplet of (point, pixel, text) associations by using the image modality as a bridge: 3D points are projected onto 2D views, semantic score maps are computed via cosine similarity between 2D pixel features and text embeddings, and multi-view scores are aggregated into 3D pseudo-label maps. The text modality is generated without manual annotation by combining RAM image tagging (complete category recall), LLaVA scene descriptions (scalable linguistic variation), and GPT-based denoising with multi-view voting (noise removal). For 2D features, FC-CLIP is used with a frozen CLIP visual encoder (preserving open-vocabulary alignment) and a fine-tuned mask head (incorporating 3D structural priors), and both feature streams are combined as supervision. Training employs mutually inclusive losses—BCE for tag-based supervision and cosine similarity for description-based supervision—rather than cross-entropy, so that a single point can simultaneously match multiple semantically overlapping text labels (e.g., 'bed' and 'bedroom'). The overall objective jointly minimizes text-to-3D, text-to-2D, and 2D-to-3D alignment losses, enabling the 3D model to inherit both the semantic breadth of language and the structural precision of 2D segmentation.

## Results

On ScanNet, DMA(OpenSeg)-3D achieves 53.3% mIoU and 70.3% mACC using only the 3D encoder at 0.07s inference latency, outperforming OpenScene(OpenSeg)-2D3D (47.9% mIoU, 89.4s) by 5.4% mIoU. On nuScenes, DMA(FC-CLIP)-3D reaches 47.4% mIoU (61.4% base, 35.3% long-tail), surpassing the best prior zero-shot method by 5.3%. On the long-tail ScanNet200 benchmark, DMA(FC-CLIP)-3D attains 7.9% overall mIoU, approaching fully-supervised performance on common (11.5%) and tail (5.8%) splits where only a few 3D training instances exist.

## Baselines & Comparisons

DMA(OpenSeg)-3D outperforms OpenScene(OpenSeg)-2D3D by 5.4% mIoU (53.3 vs. 47.9) while reducing inference latency from 89.4s to 0.07s, since DMA compensates for the 2D model's lost open-vocabulary ability through direct text alignment. Against the text-only baseline RegionPLC, DMA gains 9.5% mIoU (53.3 vs. 43.8), demonstrating that dense point-to-text correspondences via the 2D bridge are far more effective than coarse region-level captions. Even using text supervision alone, DMA-text only surpasses RegionPLC by 6.7% and beats OpenScene(OpenSeg)-2D3D by 2.6% mIoU. On nuScenes, DMA(FC-CLIP)-3D leads all zero-shot methods by 5.3% mIoU over OpenScene(OpenSeg)-2D3D (47.4 vs. 42.1), with the largest gains on long-tail classes (35.3 vs. 33.8). On Matterport3D, DMA(FC-CLIP)-3D consistently outperforms OpenScene(OpenSeg)-2D3D across all category counts K (e.g., 46.2 vs. 42.6 at K=21; 20.1 vs. 18.8 at K=80). On ScanNet200, DMA(FC-CLIP)-3D approaches fully-supervised performance on common and tail splits (11.5% and 5.8% mIoU vs. 13.6% and 3.4% for fully-supervised), where limited 3D training data makes supervised methods unreliable.

## Relation to Prior Work

This paper extends the open-vocabulary 3D scene understanding line initiated by OpenScene [42] and PLA/RegionPLC [13,55], which either distilled frozen 2D segmentation features into 3D or aligned 3D points to coarse image/region-level captions. DMA departs from both by establishing dense point-pixel-text triplets and co-embedding all three modalities in a shared space, using RAM for comprehensive tagging and LLaVA for scalable scene descriptions as the text modality. For the image modality, it builds on FC-CLIP [56] but introduces a dual-path strategy—freezing the CLIP visual encoder to preserve open-vocabulary alignment while fine-tuning the mask head to inject 3D structural priors—addressing a tension that prior distillation-based methods overlooked.

## Why It Matters / Open Questions

The framework offers a practical recipe for open-vocabulary 3D segmentation without any 3D annotations, and the finding that dense text alignment alone can rival or exceed 2D+3D hybrid supervision suggests that the quality of text-to-point correspondence matters more than the sheer information content of 2D features. The dual-path (frozen CLIP + fine-tuned mask) design is a broadly applicable pattern for adapting vision-language models to downstream 3D tasks without sacrificing zero-shot generalization. Open questions include whether the approach scales to larger, more diverse 3D datasets, how sensitive performance is to the quality of VLM-generated descriptions, and whether the dense alignment strategy transfers to other dense 3D tasks like instance or panoptic segmentation.

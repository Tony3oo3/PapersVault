## Problem

Existing one-shot skeleton-based 3D action recognition methods rely solely on low-level joint location information, leading to loss of critical local details and weak generalization to unseen actions. The lack of high-level semantic guidance prevents models from identifying which joints are most informative for a given action or from extrapolating local observations into coherent global action representations.
![Teaser figure](../imgs/ECCV20240516/cropped_page1_idx0.webp)

## Input / Output

The method takes a 3D skeleton sequence (T×V×C, e.g., 25 joints over a temporal window) as input and outputs an action class label via one-shot distribution calibration on novel classes. During training, it additionally consumes two types of LLM-generated text: a global action description (identifying key body parts) and per-joint motion descriptions, but at inference only the skeleton sequence is required—the cross-modal guidance branch is discarded, adding only 0.1M parameters over the base InfoGCN encoder.

## Method

CrossGLG guides skeleton feature learning in a global-local-global manner using LLM-generated text. In the global-to-local phase, a Joint Importance Determination (JID) module—trained with an MSE calibration loss against key-joint distributions extracted from the global action description—reweights intermediate skeleton features so the encoder focuses on informative joints. In the local-to-global phase, a multi-layer cross-modal interaction module builds non-local text-text, skeleton-skeleton, and skeleton-text attention between DeBERTa-encoded joint-level motion descriptions and pooled skeleton features, producing a global action representation enriched with fine-grained semantics. A dual-branch architecture (skeleton encoding branch + cross-modal guidance branch) shares a classifier during training to distill cross-modal knowledge into the skeleton encoder, so that at inference only the lightweight skeleton branch is needed. The overall loss combines skeleton-branch classification loss, JID calibration loss, and cross-modal-branch classification loss, and one-shot novel-class inference uses distribution calibration on the frozen skeleton encoder.

## Results

On NTU RGB+D 120, CrossGLG achieves 45.3% accuracy with 20 base classes and 62.6% with 100 base classes, outperforming the previous SOTA MotionBERT by 6.6% and 1.6% respectively. On NTU RGB+D 60, it reaches 75.6% (50 base classes), surpassing MotionBERT (74.5%) and InfoGCN (72.3%). On Kinetics, CrossGLG achieves 19.2% (40 base classes) versus 16.6% for MotionBERT. Notably, the inference model size is only 1.7M parameters, just 2.8% of MotionBERT's 60.3M.

## Baselines & Comparisons

CrossGLG consistently outperforms all eight baselines on NTU RGB+D 120 across every base-class setting. Against the strongest prior method MotionBERT [46], it gains 6.6% at 20 base classes (45.3 vs. 35.5) and 5.9% at 80 base classes (61.6 vs. 52.8), while using only 2.8% of its parameter count. The base encoder InfoGCN [7] is improved by 8.3% (20 base) to 6.5% (100 base) with negligible added cost (0.1M params). The text-guided method GAP [39], originally designed for fully supervised settings, actually underperforms InfoGCN in several one-shot settings (e.g., 50.8% vs. 58.8% at 60 base classes), highlighting the difficulty of transferring fully supervised text guidance to one-shot learning. On NTU RGB+D 60, CrossGLG beats MotionBERT in 4 of 5 settings (losing by only 0.4% at 10 base classes) and surpasses uDTW [37] by up to 3.2%. On Kinetics, CrossGLG outperforms both MotionBERT and InfoGCN in both tested settings (20 and 40 base classes).

## Relation to Prior Work

This paper builds on InfoGCN as its base skeleton encoder and on distribution calibration for one-shot inference, but departs fundamentally from prior one-shot skeleton action recognition methods (APSR, uDTW, MotionBERT, ALCA-GCN) that operate solely on low-level joint coordinates. It also extends the text-guided skeleton recognition line initiated by GAP (ICCV 2023), which performs contrastive learning between skeleton and text features but treats all joints uniformly and lacks cross-modal non-local interactions. The key conceptual departure is using LLM-generated global and local action descriptions to drive a structured global-to-local-to-global guidance pipeline, combined with a dual-branch distillation architecture that eliminates the need for text at inference time.

## Why It Matters / Open Questions

The paper demonstrates that high-level semantic knowledge from LLMs can be effectively distilled into a lightweight skeleton encoder, achieving large accuracy gains (up to 6.6% on NTU120) while reducing inference model size to 2.8% of the previous SOTA. This suggests a broader paradigm where LLMs serve as offline knowledge sources for training lightweight perception models, rather than being required at test time. Open questions include whether the approach scales to more complex multi-person or long-horizon actions, whether the quality of LLM-generated descriptions is a bottleneck (the Stanford CoreNLP noun extraction step is fragile), and whether similar cross-modal guidance strategies transfer to other low-data regimes beyond one-shot skeleton recognition.

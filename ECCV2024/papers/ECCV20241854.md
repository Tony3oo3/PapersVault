## Problem

Previous gaze object prediction methods rely on box-level supervision, which suffers from semantic ambiguity when multiple objects are densely packed or adjacent, making it impossible to precisely identify which object a person is actually looking at. Additionally, existing approaches either require a separate head detector as an extra input (hurting real-world efficiency) or directly fuse features to regress a gaze heatmap without explicitly modeling the spatial relationship between the gaze direction and object details.
![Teaser figure](../imgs/ECCV20241854/cropped_page1_idx1.webp)

## Input / Output

The model takes a single 224×224 RGB scene image as input and simultaneously outputs a pixel-level gaze object mask, gaze object bounding box with category, a gaze heatmap, a head bounding box, and all candidate object detections. A key design choice is that the model operates in a 'real-world' setting where no pre-cropped head image or head location map is provided; instead, head features are extracted internally. SAM-generated instance masks serve exclusively as training supervision signals and are not required at inference time.

## Method

The framework integrates a MaskDINO-based unified Transformer that jointly performs object detection, instance segmentation, and head localization, with a RoI reconstruction module that crops head features from holistic scene features via ROIAlign—eliminating the need for a separate head detector. For gaze regression, a space-to-object strategy progressively refines the human-object relationship: a dual attention fusion module first establishes an initial spatial connection by combining a gaze cone map (derived from a predicted gaze vector) with a head-based scene saliency map, then a feature interaction module injects semantically clear mask embeddings from the segmentation branch into the regression features via cross-attention. Pixel-level training supervision is generated offline by a two-stage SAM pipeline (box prompt followed by mask prompt) to produce accurate instance masks. An energy aggregation loss further constrains the gaze heatmap to concentrate on the predicted gaze object mask, and a pixel shuffle module enlarges feature maps to improve dense prediction quality in object-rich scenes.

## Results

On GOO-Real in real-world settings (no pretraining), the method achieves 81.35% mSoC for gaze object detection, outperforming TransGOP* (79.70%) while using fewer parameters (84.26M vs. 106.37M) and running faster (14.1 vs. 11.6 FPS). For gaze estimation on GOO-Synth in real-world settings, the method achieves AUC=0.978, L2 distance=0.057, angle error=10.2°, and mAP=0.836, surpassing TransGOP† (AUC=0.977, L2=0.070, Ang=11.5°, mAP=0.730). On the newly proposed gaze object segmentation task, the method reaches 86.39% mSoC on GOO-Real (no pretrain, non-real) and 89.39% mSoC (with pretraining, non-real). The method also outperforms MaskDINO by 8.66 AP on GOO-Real instance segmentation in real-world settings (79.56 vs. 70.85).

## Baselines & Comparisons

Against GaTector [41], the proposed method wins decisively across all settings: on GOO-Real real-world (no pretrain), mSoC improves from 40.87% to 81.35%, and inference speed increases from 9.3 to 14.1 FPS, primarily because GaTector requires a separate head detector. Against TransGOP [40], the method trades a small detection mSoC gap on GOO-Synth (91.19% vs. 92.80% non-real) for a clear win on GOO-Real real-world (81.35% vs. 79.70% without pretraining) while using 22M fewer parameters and 2.5 FPS more. For gaze estimation in real-world settings, the method outperforms TransGOP† by 1.1° in angle error and 0.013 in L2 distance on GOO-Synth, and achieves mAP=0.836 vs. 0.730. Against earlier gaze target detection baselines (GazeFollow [29], Lian [22], VideoAttention [9], GTR [39], Tonini [36]), the method achieves the best AUC (0.978), lowest L2 distance (0.051), and lowest angle error (8.8°) on GOO-Real with pretraining in real-world settings. On instance segmentation, the method surpasses MaskDINO [20] by 8.66 AP on GOO-Real (79.56 vs. 70.85) in real-world settings, attributed to the pixel shuffle module enhancing dense feature capture.

## Relation to Prior Work

This paper extends the gaze object prediction (GOP) line initiated by Tomas et al. and advanced by GaTector and TransGOP by replacing box-level supervision with pixel-level masks generated by the Segment Anything Model (SAM). It builds on MaskDINO as a unified detection-and-segmentation backbone and on the gaze target detection literature (GazeFollow, GTR) for the regression branch, but departs from prior GOP methods in two key ways: (1) it eliminates the need for externally supplied head crops by reconstructing head features via ROIAlign on holistic scene features, and (2) it introduces a space-to-object gaze regression strategy that progressively refines the gaze heatmap through a dual-attention spatial connection followed by cross-attention with semantically clear mask features, rather than directly fusing features as in GaTector/TransGOP.

## Why It Matters / Open Questions

The work is the first to frame gaze object prediction as a pixel-level segmentation problem, which directly addresses the semantic ambiguity that plagues box-level methods in dense retail or cluttered scenes. Practically, the all-in-one framework (detection + segmentation + gaze) running at ~14 FPS without external head detectors makes it more deployable than prior GOP systems. The main open limitation is that SAM mask generation still requires box prompts, so the pipeline inherits a location prior and cannot yet operate in fully open-vocabulary or prompt-free settings; the authors acknowledge that more flexible VFM prompting strategies are needed. Broader impact hinges on whether pixel-level gaze supervision transfers to other fine-grained human-scene interaction tasks (e.g., attention in multi-person scenes).

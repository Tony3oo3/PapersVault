## Problem

Existing referring video object segmentation (RVOS) methods rely on static attributes like object names and colors to identify targets, which fails when redundant instances coexist or when objects undergo state changes (e.g., a nail painted from pink to blue). This paper proposes ActionVOS, a new setting that uses human action narrations as an additional language prompt to segment only the objects actively involved in an interaction, resolving ambiguity from redundant objects and enabling tracking of state-changed objects.
![Teaser figure](../imgs/ECCV20240255/cropped_page1_idx1.webp)

## Input / Output

The model takes a T-frame RGB video clip, a free-form action narration (e.g., 'put carrot in bowl'), and an arbitrary set of N object names in an open-vocabulary setting. It outputs T per-object binary segmentation masks (each pixel assigned to one object or background) plus a scalar positivity score per object; at inference, objects scoring below a threshold of 0.75 are zeroed out. During training, the method additionally consumes hand-object segmentation masks and semantic segmentation masks from existing annotations to generate pseudo-labels, but these are not required at inference time.

## Method

ActionVOS extends ReferFormer with a lightweight linear classification head that predicts whether each named object is actively involved in the action, gating the segmentation output at inference. Because existing datasets lack explicit active/inactive labels, a parameter-free action-aware labeling module generates pseudo-labels by marking objects as positive if they appear in the action narration, fall within hand-object masks, or intersect hand-object bounding boxes. To counter the false positives introduced by this relaxed labeling, an action-guided focal loss modulates the standard focal loss with pixel-wise weights: objects simultaneously mentioned in the narration and within the hand-object bounding box receive the highest weight (λ=5), objects in only one of those conditions receive medium weight (λ=2), and negative objects receive a high penalty weight (λ=5) to suppress mis-segmentation. The entire labeling and loss mechanism is parameter-free, and the model is trained from ReferFormer checkpoints on ReferYouTube-VOS with a retrained RoBERTa text encoder, making it compatible with any existing RVOS backbone (ResNet-101, Swin-L, Video-Swin-Base).

## Results

On VISOR (RF-R101 backbone), ActionVOS with action prompts achieves p-mIoU 65.4, n-mIoU 19.0, gIoU 70.9, and Acc 82.4, reducing the mis-segmentation of inactive objects by 35.6% (n-mIoU drops from 54.2 under RVOS to 19.0) while retaining only a slight p-mIoU decrease (67.7→65.4). On state-change datasets, ActionVOS outperforms RVOS by 3.0% p-mIoU on VOST (32.3 vs 29.3) and 3.0% p-mIoU on VSCOS (49.4 vs 46.4). The method generalizes across backbones: RF-SwinL reaches p-mIoU 69.1 and RF-VSwinB reaches 68.2 with action prompts.

## Baselines & Comparisons

ActionVOS is compared against two baselines on VISOR, VOST, and VSCOS. Against the hand-object segmentation (HOS) model [9], ActionVOS wins on p-mIoU (65.4 vs 56.2), gIoU (70.9 vs 68.8), and accuracy (82.4 vs 77.0), but HOS achieves a lower n-mIoU (11.4 vs 19.0) because it only segments hands and directly contacted objects. Against RVOS+S4.2 (which applies the action-aware labeling module as a post-hoc filter to RVOS outputs), ActionVOS wins on p-mIoU (65.4 vs 65.3), gIoU (70.9 vs 60.4), accuracy (82.4 vs 75.1), and n-mIoU (19.0 vs 35.2), confirming that end-to-end training with action prompts is superior to post-hoc filtering. On state-change benchmarks, ActionVOS outperforms both baselines: VOST p-mIoU 32.3 vs 19.4 (HOS) and 29.3 (RVOS+S4.2); VSCOS p-mIoU 49.4 vs 34.4 (HOS) and 46.4 (RVOS+S4.2).

## Relation to Prior Work

This paper extends the ReferFormer (Wu et al., CVPR 2023) RVOS architecture by adding a binary classification head to distinguish active from inactive objects, and derives its action-guided focal loss from the standard focal loss formulation (Lin et al., ICCV 2017) by introducing pixel-wise action-guided weights. Conceptually, it departs from conventional RVOS—which relies on static attributes like object names and colors—by introducing action narrations as an additional language prompt that encodes human-object interaction dynamics. The action-aware labeling module repurposes existing annotations (action narrations, semantic segmentation, hand-object masks) to generate pseudo-labels, avoiding the need for new manual annotation of object involvement.

## Why It Matters / Open Questions

ActionVOS addresses a genuine limitation in egocentric vision where static attributes fail to disambiguate redundant objects or track state changes, and the parameter-free design (no trainable parameters in the labeling module or focal loss) makes it immediately applicable to existing datasets. However, the method still relies on hand-object masks during training, the 'positive object' definition is heuristic and may not generalize to all action types, and evaluation is limited to three egocentric datasets. Open questions include whether the approach scales to open-world settings without dense annotations, how it handles multi-action sequences, and whether the action-guided weighting strategy transfers to non-egocentric video.

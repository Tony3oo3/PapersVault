## Problem

Existing efficient mobile models are typically optimized for a single hardware target (e.g., CPU or a specific accelerator) and fail to achieve competitive latency-accuracy trade-offs across the full spectrum of mobile hardware including CPUs, DSPs, GPUs, and dedicated accelerators like Apple Neural Engine and Google EdgeTPU. No prior model family demonstrates mostly-Pareto-optimal performance simultaneously across all these diverse platforms, limiting their deployability in the heterogeneous mobile ecosystem.
![Teaser figure](../imgs/ECCV20241054/cropped_page1_idx2.webp)

## Input / Output

The models consume standard RGB images at 224×224 resolution for ImageNet-1K classification and 384px for COCO object detection, operating at batch size 1 as is typical for on-device inference. For classification, the output is a single class label over 1000 categories; for detection, the output is a set of bounding boxes with class labels via a RetinaNet head with FPN decoder. The hybrid variants place attention blocks only in the final low-resolution stages where token counts are small relative to feature dimensions, a regime where Multi-Query Attention provides the greatest memory-bandwidth savings.

## Method

The architecture is built from two novel blocks: the Universal Inverted Bottleneck (UIB), which extends the standard Inverted Bottleneck with two optional depthwise convolutions (before expansion and between expansion/projection) to unify IB, ConvNext, FFN, and a new ExtraDW variant in a single searchable structure; and Mobile MQA, a Multi-Query Attention block with asymmetric spatial down-sampling (stride-2 3×3 DW on keys/values) that achieves >39% speedup over MHSA on mobile accelerators. A two-stage TuNAS-based search (coarse-grained filter sizing followed by fine-grained DW configuration) with an offline JFT distillation dataset drives architecture selection, while a Roofline-model analysis guides the placement of MAC-intensive layers early and memory-intensive FC layers late in the network to avoid simultaneous bottlenecks across ridge points. A dynamic distillation recipe mixing three datasets with different augmentations (RandAugment, extreme Mixup, and class-balanced JFT-300M) further boosts accuracy, yielding 87% ImageNet-1K top-1 at 3.8ms on Pixel 8 EdgeTPU.

## Results

On ImageNet-1K, MNv4-Conv-S achieves 73.8% top-1 accuracy with only 3.8M parameters and 0.2G MACs (2.4 ms on Pixel 6 CPU), while MNv4-Hybrid-L reaches 83.4% top-1 at 3.8 ms on Pixel 8 EdgeTPU. With the proposed distillation recipe, MNv4-Hybrid-L attains 87.0% top-1 accuracy—only 0.5% below its teacher (EfficientNet-L2) despite 39× fewer MACs. On COCO object detection, MNv4-Conv-M achieves 32.6 AP (12% faster than MobileNetMultiAvg@1.5) and MNv4-Hybrid-M reaches 34.0 AP, outperforming all compared backbones at similar MAC budgets.

## Baselines & Comparisons

MNv4-Conv-S (73.8%) matches MobileNet-V2 (73.4%) in accuracy while using 33% fewer MACs (0.2G vs 0.3G) and running 2× faster on Pixel 6 CPU (2.4 ms vs 5.0 ms). At the mid-range, MNv4-Conv-M (79.9%) surpasses MobileOne-S4 (79.4%) with 33% fewer MACs (1.0G vs 1.5G) and is 2.3× faster on CPU (11.4 ms vs 26.7 ms); it also outperforms FastViT-S12 (79.8%) by a wide latency margin (11.4 ms vs 83.0 ms on CPU, 4.1 ms vs 47.0 ms on S23 GPU). At the high end, MNv4-Conv-L (82.9%) approaches ConvNext-S (83.1%) with 32% fewer MACs (5.9G vs 8.7G) and is 5.3× faster on CPU (59.9 ms vs 314.9 ms), while MNv4-Hybrid-L (83.4%) edges out NextViT-B (83.2%) with fewer MACs (7.2G vs 8.3G). The paper's central claim is universality: no single competing model is Pareto-optimal across all tested hardware (CPU, DSP, GPU, EdgeTPU, ANE), whereas MNv4-Conv models remain near the Pareto front on every platform simultaneously—e.g., FastViT is 2nd on Apple ANE but 5× slower than MNv4 on S23 GPU, and EfficientViT is competitive on GPU but 2× slower than MNv4 on CoreML at the same accuracy.

## Relation to Prior Work

MobileNetV4 extends the MobileNetV2 Inverted Bottleneck by adding two optional depthwise convolutions, creating the Universal Inverted Bottleneck (UIB) that unifies IB, ConvNext, and FFN blocks into a single searchable structure. For attention, it adapts Multi-Query Attention (MQA) from NLP to mobile vision with spatial reduction, and for architecture search it modifies TuNAS with a two-stage coarse-to-fine strategy and an offline distillation dataset. The key conceptual departure from prior mobile model work (MobileNetV3, FastViT, EfficientViT) is the explicit use of Roofline model analysis to guide design toward simultaneous Pareto-optimality across CPUs, DSPs, GPUs, and accelerators, rather than optimizing for a single hardware target.

## Why It Matters / Open Questions

The demonstrated universal Pareto-optimality across seven distinct mobile hardware platforms is a practical milestone: mobile developers can deploy a single model family without per-hardware re-optimization, a property no prior model family achieved. The Roofline-based design framework (placing MAC-intensive layers early and memory-intensive layers late) offers a transferable methodology for future mobile architecture design. Limitations include DSP incompatibility of hybrid models, incomplete benchmarking of some competitors on all platforms, and the distillation recipe's dependence on JFT-300M access. An open question is whether the swept-Ridge-Point analysis truly generalizes to future hardware with novel compute-memory ratios outside the 0–500 MACs/byte range tested.

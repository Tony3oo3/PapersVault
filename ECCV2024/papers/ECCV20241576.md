## Problem

Existing skeleton-based group activity recognition methods process multiple people as separate single-person graphs with shared weights, effectively neglecting inter-person interactions, and lack object information critical for activities like ball sports. RGB-based alternatives avoid this structural limitation but incur prohibitive computational costs and are sensitive to background variation, occlusion, and motion blur. The paper addresses both gaps by constructing a unified multi-person-object graph that enables a single GCN to model intra-person, inter-person, and person-object interactions simultaneously.
![Teaser figure](../imgs/ECCV20241576/cropped_page1_idx0.webp)

## Input / Output

The method consumes estimated 2D keypoints (17 joints per person from YOLOv8x-pose) for a fixed M=12 participants across T frames (41 for Volleyball, 72 for NBA), plus object keypoints (ball center, basketball net) detected by a fine-tuned YOLOv8. A tracking-based reassignment strategy maps the variable number of per-frame detections to exactly M slots using trajectory-variance and confidence scoring, eliminating the need for ground-truth bounding boxes. The output is a single group activity class label predicted by a classification head after global graph pooling.

## Method

The core contribution is a panoramic multi-person-object graph with MN′ nodes (M people × N′ joints including object points) and a block-structured adjacency matrix whose diagonal blocks encode intra-body topology and off-diagonal blocks encode inter-body links between central joints and object keypoints. Spatial graph convolution partitions the adjacency into three subsets (self-links, intra-person, inter-person) so that a single SGC operation captures all three interaction types with separate learnable weights. The architecture employs early-fusion across four input branches (joint, bone, joint motion, bone motion) feeding a shared main branch of six basic blocks, each containing SGC, a four-branch multi-scale TCN, and a Spatial-Temporal Person Attention module that computes per-person and per-frame attention scores to focus on key roles. A pose reassignment strategy scores each tracked individual by detection confidence plus a softmax-normalized trajectory-variance activeness measure, then assigns the top-M to fixed slots to ensure temporal consistency without ground-truth tracklets.

## Results

On the Volleyball dataset (Fully Supervised), MP-GCN achieves 95.5% MCA using only estimated 2D keypoints, surpassing the best keypoint-based method COMPOSER (94.6%) and approaching the best RGB-based method GroupFormer (95.7%). In the Weakly Supervised setting, MP-GCN reaches 92.8% MCA and 96.1% MMCA, outperforming KRGFormer (92.4% MCA, 95.0% MMCA). On the NBA dataset, MP-GCN (T=72) achieves 76.0% MCA and 71.9% MPCA with only 4.4M parameters and 22.3G FLOPs, outperforming the best RGB-based method DFWSGAR (75.8% MCA, 71.2% MPCA) while using ~28x fewer FLOPs. With late-fusion, MP-GCN further reaches 78.7% MCA on NBA.

## Baselines & Comparisons

On Volleyball Fully Supervised, MP-GCN (95.5% MCA) outperforms all keypoint-only baselines including COMPOSER (94.6%), SkeleTR (94.4%), POGARS (93.9%), and GIRN (92.2%), and also surpasses most RGB-based methods such as ARG (92.6%), DIN (93.6%), and SACRF (95.0%), though GroupFormer (95.7%) with RGB+Flow+Keypoints edges it out by 0.2%. On Volleyball Weakly Supervised, MP-GCN (92.8% MCA, 96.1% MMCA) beats KRGFormer (92.4%, 95.0%) and DFWSGAR (90.5%, 94.4%) on both metrics, though Tamura et al. (96.0% MCA) remains higher on MCA. On NBA, MP-GCN (76.0% MCA, 71.9% MPCA) surpasses DFWSGAR (75.8%, 71.2%) and all other RGB baselines (ARG 59.0%, DIN 61.6%, KRGFormer 72.4%) while using only 4.4M parameters and 22.3G FLOPs versus 17.4M–45.4M parameters and 610–628G FLOPs for RGB methods. On Kinetics400, MP-GCN with late-fusion (51.1%) outperforms MS-G3D (45.1%) and PoseConv3D (47.7%) but falls slightly short of Hachiuma et al. with objects (52.3%). The key differentiator is efficiency: MP-GCN achieves competitive or superior accuracy with roughly 28–100x lower FLOPs than RGB-based approaches, making it practical for real-time deployment.

## Relation to Prior Work

This paper extends the spatial-temporal graph convolution framework established by ST-GCN (Yan et al., 2018) and the multi-scale temporal convolution / early-fusion architecture from MS-G3D (Liu et al., 2020) and CTR-GCN (Shi et al., 2023) to the multi-person group activity setting. The key conceptual departure is the panoramic multi-person-object graph: rather than processing each person's skeleton as a separate single-person graph with shared weights (the standard practice in skeleton-based action recognition) or requiring ground-truth bounding boxes and specialized interaction modules (as in COMPOSER, POGARS, and GIRN), all participants and object keypoints are unified into a single graph with explicit intra-person and inter-person adjacency blocks. The pose reassignment strategy, which maps a variable number of tracked detections to a fixed set of M slots using trajectory-based activeness scoring, is a practical contribution that removes the dependency on ground-truth tracklets.

## Why It Matters / Open Questions

The panoramic graph offers a clean, generalizable representation that unifies intra-person, inter-person, and person-object interaction modeling in a single GCN, and the resulting 30× FLOPs reduction (5.7–22.3G vs. 600G+ for RGB baselines) makes skeleton-based GAR far more deployable in real-time or resource-constrained settings. The ablation showing that per-person object keypoints (e.g., individual ball and net nodes) substantially outperform a shared object node highlights an underexplored design axis for object-augmented skeleton graphs. Open questions remain: performance on Kinetics400 still lags RGB-based SOTA by a wide margin, the reassignment strategy can admit irrelevant individuals when fewer than M people are present, and the method's sensitivity to pose estimation errors in uncontrolled, crowded scenes is not thoroughly stress-tested.

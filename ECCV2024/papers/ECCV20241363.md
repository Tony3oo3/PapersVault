## Problem

CLIP's text encoder is hard-limited to 77 tokens, and empirical analysis reveals the true effective length is only ~20 tokens, preventing it from processing detailed descriptions for retrieval and generation. Naive fine-tuning with long captions to extend this limit causes severe degradation of short-text capabilities (e.g., 13.1% drop in ImageNet zero-shot accuracy and 14.4% drop in COCO T2IR@1), making a straightforward extension impractical.

## Input / Output

The model accepts RGB images and text prompts of up to 248 tokens (vs. CLIP's 77), producing aligned image-text features in the same latent space as the original CLIP, enabling direct drop-in replacement in downstream frameworks like Stable Diffusion without retraining. For retrieval, it outputs cosine-similarity-based rankings between image and text embeddings; for generation, the text encoder's output serves as conditioning for the diffusion model. The critical design constraint is that the output embedding space must remain compatible with pre-trained CLIP features so that no downstream adaptation is needed.

## Method

Long-CLIP introduces two complementary strategies for efficient fine-tuning of CLIP with long text. First, knowledge-preserved stretching (KPS) retains the first 20 positional embeddings (identified as the well-trained effective range) and interpolates the remaining 57 positions with a larger ratio λ₂=4, extending the maximum input to 248 tokens while minimizing disruption to established position representations. Second, primary component matching (PCM) simultaneously aligns fine-grained image features with long detailed captions and coarse-grained image features—extracted via PCA retaining only the top 32 eigenvectors—with short summary captions, forcing the model to learn attribute importance rather than treating all details equally. The entire fine-tuning uses only 1M (image, long-caption) pairs from ShareGPT4V for a single epoch (batch size 2048, ~0.25 hours on 8 GPUs), with a combined contrastive loss weighted by a hyperparameter α balancing fine-grained and coarse-grained alignment.

## Results

On long-caption retrieval (Urban-200), Long-CLIP (ViT-L/14) achieves 81.5% R@1 for both I2T and T2I, compared to 47.0% for CLIP — a 34.5-point absolute gain. On standard short-caption retrieval, Long-CLIP improves COCO T2I R@1 from 35.4% (CLIP) to 46.3% and Flickr30k T2I R@1 from 28.0% to 41.2%. Zero-shot classification is essentially preserved: average accuracy across five benchmarks is 69.78% for Long-CLIP vs. 69.92% for CLIP (ViT-L/14), with no meaningful degradation.

## Baselines & Comparisons

The sole external baseline is the original CLIP model (Radford et al., ICML 2021). Long-CLIP outperforms CLIP on every retrieval metric: on COCO T2I R@1 it gains +10.9 points (46.3 vs. 35.4), on Flickr30k T2I R@1 it gains +13.2 points (41.2 vs. 28.0), and on the novel Urban-200 long-caption benchmark it gains +34.5 points (81.5 vs. 47.0). On zero-shot classification, Long-CLIP matches CLIP within 0.14% average accuracy (69.78 vs. 69.92 for ViT-L/14), confirming no degradation. The paper also includes a 'Direct Fine-tuning' ablation (naive positional interpolation + long-caption fine-tuning) that catastrophically degrades short-text performance (e.g., COCO T2I R@1 drops to 23.1), highlighting that the proposed knowledge-preserved stretching and primary component matching are both necessary to retain CLIP's original capabilities while unlocking long-text support.

## Relation to Prior Work

Long-CLIP extends CLIP (Radford et al., ICML 2021) by addressing its hard 77-token input limit through a modified positional embedding interpolation strategy inspired by Chen et al. (2023), but with a key departure: rather than uniformly interpolating all positions, it preserves the first 20 well-trained positions and stretches only the under-trained remainder. The primary component matching strategy repurposes PCA—a classical linear-algebra dimensionality reduction tool—as a mechanism to extract coarse-grained image features from fine-grained ones, creating a dual-alignment training objective that has no direct precedent in the CLIP fine-tuning literature. The paper positions itself explicitly as a plug-and-play drop-in replacement for CLIP in downstream frameworks like Stable Diffusion, distinguishing it from prior long-context vision-language work that typically requires architectural changes or retraining of downstream models.

## Why It Matters / Open Questions

Because CLIP's text encoder is embedded in a vast ecosystem of downstream systems (Stable Diffusion, DALL-E 2, open-vocabulary detection, segmentation), a drop-in replacement that preserves the latent space while unlocking long-text capability has immediate practical value without requiring retraining of any downstream pipeline. The empirical finding that CLIP's true effective length is only ~20 tokens (not 77) reframes how practitioners should think about the model's actual capacity. Key limitations remain: the 248-token ceiling is still finite, training used only 1M pairs from ShareGPT4V, and the PCA-based component extraction is a fixed, non-learned heuristic that may not generalize to all image types. Open questions include whether relative positional embeddings (e.g., RoPE) could eliminate the hard length bound entirely, and whether scaling to tens of millions of long-text pairs would yield further gains.

## Problem

Dense prediction tasks on event-based cameras require pixel-level spatial association, but existing event-processing frameworks either aggregate events into static frame-like representations (sacrificing temporal resolution and increasing compute cost) or use fixed-rate hierarchical memory updates that perform redundant computation when new information is minimal. No prior method learns a data-adaptive update rate for hierarchical memory states that can skip redundant updates while preserving the recurrent context of skipped steps.
![Teaser figure](../imgs/ECCV20242185/cropped_page4_idx0.webp)

## Input / Output

The method consumes raw, sparse, asynchronous event streams (x, y, t, polarity) from event cameras at resolutions ranging from 304×240 (GEN1) to 640×480 (DSEC-Semantic), processing them event-by-event rather than in synchronized frames. Events are grouped into spatial windows (w×w with stride w) at the lowest memory level, and the network produces task-specific outputs—pixel-wise segmentation masks, bounding boxes, or depth maps—via a readout buffer that extracts refined memory states at each time step for a task head (UPerNet, YOLOX, or UNet).

## Method

The architecture encodes raw events into D-dimensional embeddings (position, timestamp, polarity via MLPs) and projects them into the lowest hierarchical memory level using cross-attention, selectively updating only memory cells that receive events. Higher memory levels are updated via window-based multi-head cross-attention from downsampled lower-level states. The key novelty is an adaptive update gate: global-pooled representations of two consecutive memory levels are fed through a GRU to produce a scalar update score (Th), and the higher-level memory is updated only when Th exceeds a learned threshold, with the GRU hidden state reset after each actual update to retain context of skipped steps. This avoids redundant high-level computation while the recurrent formulation ensures skipped updates still influence future decisions. Readout buffers apply point-wise convolution with Group Normalization to extract task-ready features from each memory level at every time step.

## Results

On object detection (GEN1), the proposed method with YOLOX achieves 44.8 mAP at 3.2 ms latency, outperforming HMNet-L3 (47.1 mAP, 7.9 ms) in latency by 60% while remaining competitive in accuracy. For semantic segmentation (DSEC-Semantic), the method with UPerNet achieves 49.9 mIoU at 4.5 ms, reducing latency by 50–70% over HMNet-B3/L3. On depth estimation (MVSEC), the method achieves 2.3 ms latency (vs. 5.0–6.9 ms for HMNet) while remaining within ~0.04 REL of the best accuracy. The ablation confirms that adaptive update improves mIoU from 49.7 to 49.9 while cutting latency from 5.8 ms to 4.5 ms (28% reduction) compared to uniform update.

## Baselines & Comparisons

The closest competitor is HMNet (CVPR 2023), which uses the same hierarchical memory architecture but with a fixed, hand-tuned update rate. On object detection, HMNet-L3 achieves 47.1 mAP vs. 44.8 for the proposed method (−2.3 mAP), but at 7.9 ms vs. 3.2 ms latency (−59%). On segmentation, the proposed method matches or exceeds HMNet's mIoU (49.9 vs. ~49.7 for uniform-update ablation) while halving latency. On depth estimation, HMNet-L3/B3 still lead on accuracy (REL 0.254/0.270 vs. 0.292 for Ours on day1), but the proposed method cuts latency from 5.0–6.9 ms to 2.3 ms (−54% to −67%). Against older recurrent baselines (Matrix-LSTM, RED, ASTMNet), the proposed method wins on both accuracy and latency across the board. The method trades a small accuracy gap (1–3 mAP / 0.02–0.04 REL) for a consistent 50–70% latency reduction, positioning it as the fastest method in every comparison.

## Relation to Prior Work

This paper directly extends HMNet (Hamaguchi et al., CVPR 2023), which introduced a hierarchical latent memory stack with window-based cross-attention for event processing but relied on hand-tuned, fixed update rates for each memory level. The key departure is replacing those fixed rates with a data-adaptive, learned update mechanism: a GRU-based recurrent module operating on globally pooled memory states decides whether each higher level should undergo an expensive cross-attention update or simply retain its previous state. The set-based spatiotemporal association concept draws from EventFormer (Kamal et al., ICLR 2022), while the pixel-wise recurrent memory lineage traces back to Matrix-LSTM (Cannici et al., ECCV 2020). The paper positions itself at the intersection of sparse, event-by-event processing and dense pixel-level prediction, arguing that prior methods either sacrifice temporal resolution (frame aggregation) or lack explicit pixel-to-memory correspondence (EventFormer) or lack adaptivity (HMNet).

## Why It Matters / Open Questions

The 50–70% latency reduction while maintaining competitive (though not always best) task performance is practically significant for real-time event-based perception in latency-critical applications like drone navigation and autonomous driving. The core insight—that most higher-level memory updates are redundant and can be safely skipped via a lightweight global-context check—is a general principle applicable to other memory-augmented architectures beyond event cameras. However, the method's sensitivity to the update threshold (a 0.2 shift from 0.5 to 0.7 drops mIoU by 3.1 points) and its single-modality focus limit immediate deployment; the authors themselves flag end-to-end threshold learning and modality-conditioned adaptive updates as open directions. Performance on depth estimation still lags behind fixed-rate HMNet, suggesting the adaptive mechanism may be less beneficial when the scene changes more gradually.

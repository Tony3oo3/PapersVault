## Problem

Online Temporal Action Localization (On-TAL) must identify action instances in streaming video as soon as they conclude, yet detecting overlapping actions remains largely unaddressed. Class-agnostic OAD extensions cannot recognize concurrent instances at all, while class-aware methods (e.g., SimOn) rely on per-class score grouping that breaks down with same-class overlaps, many classes, or unavailable class labels. This paper tackles the gap by proposing the first class-agnostic On-TAL framework that detects overlapping actions without any class information.

## Input / Output

The model consumes a unidirectional sequence of D-dimensional visual features extracted from consecutive k-frame snippets by a pretrained encoder (TSN for THUMOS14, SlowFast for Epic-Kitchens 100), processing them sequentially at over 500 fps. At each timestep it emits a single state label from a finite state machine (e.g., 4 states for a 2-switch configuration), and action instances are decoded online by detecting state transitions in the stored history. A separate vanilla transformer classifier, applied post-hoc to the feature sequences of detected instances, supplies class labels and confidence scores for mAP evaluation.

## Method

ActionSwitch models the detection problem as a finite state machine with multiple binary switches, where each switch independently signals an ongoing action; the state label is the sum of activated switch IDs, so overlapping actions naturally map to distinct states (e.g., state 3 = both switches active). A state-emitting OAD model—stacked GRU encoder plus MLP state classifier—predicts a categorical distribution over states per frame, and argmax yields the state label, eliminating handcrafted thresholds. The key training innovation is a conservativeness loss that, only at timesteps where the model's own prediction changes, applies cross-entropy against the previous frame's predicted state as a pseudo-label, directly penalizing unnecessary state flips and suppressing fragmented proposals. The total loss is standard cross-entropy on ground-truth state labels plus α times the conservativeness term, requiring no architectural changes beyond the output layer. At inference, the state history is decoded into action instances by identifying transition points, guaranteeing no boundary-matching ambiguity.

## Results

On THUMOS14, ActionSwitch achieves F1=53.2 and average mAP=40.3, outperforming CAG-QIL (F1=45.8, mAP=33.1) and SimOn (F1=28.7, mAP=33.0) among OAD-extension On-TAL methods, though trailing the TAL-extension OAT (F1=62.9, mAP=45.3). On FineAction, ActionSwitch reaches F1=19.44 and mAP@0.5=10.58, substantially surpassing CAG-QIL (F1=15.67) and SimOn (F1=10.53), while OAT degrades to F1=7.21. On Epic-Kitchens 100, ActionSwitch attains F1=32.44 and mAP@0.5=3.60, beating OAT (F1=27.58), CAG-QIL (F1=25.12), and SimOn (F1=4.40) with a balanced precision-recall profile (29.9/35.5) versus OAT's skewed 17.6/63.8.

## Baselines & Comparisons

Among OAD-extension On-TAL methods, ActionSwitch consistently outperforms both CAG-QIL and SimOn across all three primary datasets: on THUMOS14 it gains +7.4 F1 over CAG-QIL and +24.5 over SimOn; on FineAction it leads by +3.8 and +8.9 F1 respectively; on Epic-Kitchens 100 the margin over SimOn is dramatic (32.4 vs 4.4 F1), exposing SimOn's class-aware grouping failure when overlapping instances share the same class. Against the TAL-extension OAT, ActionSwitch wins on FineAction (F1 19.44 vs 7.21) and Epic-Kitchens 100 (F1 32.44 vs 27.58, mAP 3.60 vs 3.30), where OAT suffers from training instability and a severe precision-recall imbalance (precision 17.6 vs recall 63.8). However, OAT retains an advantage on the smaller THUMOS14 dataset (F1 62.9 vs 53.2), benefiting from its more flexible start-point identification under relaxed online constraints. Compared to state-of-the-art offline TAL methods (ActionFormer† at F1=75.5 on THUMOS14), ActionSwitch still trails, but it is the strongest online OAD-extension method and uniquely handles overlapping actions without class information. On the MultiTHUMOS dataset with dense multi-action overlaps, ActionSwitch with 3 switches achieves F1=32.76, surpassing OAT (29.63), CAG-QIL (22.10), and SimOn (20.59).

## Relation to Prior Work

This paper extends the Online Temporal Action Localization (On-TAL) line of work, which itself grew out of Online Action Detection (OAD) and offline Temporal Action Localization (TAL). Prior OAD-extension methods (CAG-QIL, SimOn) and TAL-extension methods (OAT) all rely on class-specific information to separate concurrent actions, limiting their ability to handle overlapping instances of the same class. ActionSwitch departs from this by borrowing the finite-state-machine concept to create a class-agnostic multi-switch mechanism, and by introducing a conservativeness loss that directly encodes the prior that action boundaries are rare—replacing the more complex decision-context modeling used in CAG-QIL and SimOn. The class-agnostic proposal generation philosophy is drawn from object detection and TAL literature, where separating localization from classification has shown benefits for generalization.

## Why It Matters / Open Questions

The class-agnostic formulation opens a path toward open-vocabulary and open-world On-TAL, where predefining all action classes is impractical, and the conservativeness loss offers a drop-in, five-line improvement applicable to any OAD-based streaming system. However, a significant performance gap remains versus state-of-the-art offline TAL methods, and the fixed number of switches limits scalability to highly overlapping scenarios. Open questions include integrating video-language models for open-vocabulary classification, exploring reinforcement learning formulations for state transitions, and whether the framework generalizes beyond the tested datasets to truly unbounded action vocabularies.

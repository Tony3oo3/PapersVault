## Problem

Few-shot class incremental learning (FSCIL) on 3D point clouds remains underexplored compared to its 2D image counterpart. Prior approaches that bridge 3D to 2D foundation models like CLIP rely on fixed, non-adaptable camera poses for depth-map projection, and they feed raw depth maps directly into an RGB-trained encoder without any input adaptation. Additionally, existing FSCIL methods use only bare class names as text prompts, leaving the language domain underutilized for mitigating overfitting on few-shot novel classes.

## Input / Output

The method consumes a 3D point cloud (1024 farthest points per object) and a bank of ~100 GPT-4-generated depth-map-specific text descriptions per class (e.g., 'Describe a depth map of a [class]'). Internally, the point cloud is projected to a single 2D depth map at a learned camera angle, augmented with learned background pixels, and fed to a frozen CLIP ViT-B-16 vision encoder. The final output is a class label determined by argmax over similarity scores between concatenated vision, point-cloud, and text embeddings.

## Method

C3PR learns a per-object canonical camera pose via a spatial transformer network (STN) that outputs a rotation matrix constrained by an orthogonality loss (Frobenius norm + determinant), replacing the fixed multi-view projections used by PointCLIP v2. A U-Net-based reprogramming module takes a binary foreground mask extracted from the depth map and generates consistent background pixel values, enforced by a gradient-consistency loss that prevents convergence to arbitrary noise; the result is element-wise multiplied with the depth map to produce a CLIP-compatible image without any fine-tuning of the foundation model. On the text side, GPT-4 generates ~100 descriptive prompts per class (instead of a single class name), which are encoded by the frozen CLIP text encoder to provide richer semantic anchors that reduce overfitting on few-shot novel classes. A relation module (fully connected layers of sizes 1024→2048→1) concatenates the CLIP vision embedding, a CurveNet point-cloud feature, and the text embedding to produce a sigmoid similarity score trained with binary cross-entropy. During incremental training, only the relation module is fine-tuned while all other components (CLIP encoders, CurveNet, STN, U-Net) remain frozen, and a compact memory of one exemplar per previously learned class is retained to combat forgetting.

## Results

C3PR achieves the lowest relative accuracy dropping rate (Δ) across all six evaluation settings. In the within-dataset setting (Table 1), C3PR attains Δ=22.5 on ModelNet-40, Δ=34.0 on CO3D-50, and Δ=15.1 on ShapeNet-50, outperforming the strongest baseline Microshape (Δ=28.3, 39.9, 17.1 respectively). In the more challenging cross-dataset setting (Table 2), C3PR achieves Δ=24.4 on ShapeNet→CO3D, Δ=23.2 on ModelNet→ScanObjectNN, and Δ=14.9 on ShapeNet→ScanObjectNN, again beating all baselines. On the point-cloud classification task (ModelNet40), C3PR reaches 94.6% accuracy, surpassing DGCNN (92.9%) and CurveNet (93.8%).

## Baselines & Comparisons

C3PR outperforms all ten baselines on every dataset and setting. Against the closest competitor Microshape [12] (the only other 3D point-cloud FSCIL method), C3PR reduces Δ by 5.8 points on ShapeNet→CO3D (24.4 vs 30.9), 3.9 points on ModelNet→ScanObjectNN (23.2 vs 27.1), and 3.8 points on ShapeNet→ScanObjectNN (14.9 vs 18.7). Image-based incremental learning baselines (LwF, IL2M, ScaIL, EEIL, FACT, Sem-aware) suffer severe accuracy collapse in cross-dataset settings, with Δ values ranging from 22 to 98, confirming the difficulty of transferring 2D methods to 3D point clouds. In the within-dataset setting, C3PR still leads: on ModelNet-40 it achieves Δ=22.5 vs FACT's 28.1 and Sem-aware's 29.1; on ShapeNet-50 it reaches Δ=15.1 vs EEIL's 22.4. For the point-cloud classification ablation, C3PR (94.6%) beats both DGCNN (92.9%) and CurveNet (93.8%), and in the ablation against PointCLIP v2's fixed multi-view projection, C3PR's learned single canonical projection yields substantially better feature clustering and lower Δ.

## Relation to Prior Work

This paper extends the FSCIL-for-3D-point-clouds line initiated by Microshape (Chowdhury et al., ECCV 2022) by repurposing the 2D CLIP foundation model via a learned canonical projection and model reprogramming, rather than relying on a dedicated 3D backbone alone. It departs from prior CLIP-based 3D approaches (PointCLIP, PointCLIP v2) that project point clouds from a fixed set of camera poses, instead learning a single object-specific rotation via a spatial transformer network. The model reprogramming strategy builds on adversarial reprogramming (Elsayed et al., 2019) and black-box reprogramming (Tsai et al., 2020) but introduces a gradient-consistency loss that enforces uniform background pixels, and the text pipeline extends single-class-name prompts (used in Sem-aware, Microshape) to multiple GPT-4-generated descriptions per class.

## Why It Matters / Open Questions

The work demonstrates that a frozen 2D image-text foundation model can be effectively adapted to 3D FSCIL without any parameter modification, which is practically valuable given the scarcity of 3D training data. The finding that a single learned projection angle outperforms ten fixed views challenges the common assumption that more multi-view coverage is always beneficial. Key limitations include reliance on one stored exemplar per class (raising the question of exemplar-free alternatives) and degraded performance in cross-domain settings (synthetic base → real-scanned novel classes), suggesting the learned projection may not fully bridge the synthetic-to-real gap. Future directions noted by the authors include extending the reprogramming paradigm to 3D segmentation and domain adaptation.

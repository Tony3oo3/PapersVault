## Problem

Existing 3D vision-language methods are task-specific and representation-specific, with no unified model capable of handling diverse 3D scene representations (voxels, point clouds, multi-view images) across a wide range of tasks from low-level instance segmentation to high-level reasoning and planning. Two fundamental obstacles remain: different representations have incompatible granularities that resist unification in a single feature space, and no training paradigm exists that accommodates 3D-VL tasks with diverse prompt formats and output structures simultaneously.

## Input / Output

The model consumes three 3D scene representations (point clouds, voxel grids, multi-view images) that are first partitioned into pre-generated segments via unsupervised graph-based segmentation, reducing token count for tractable cross-attention. Prompts can be text (categories, sentences, questions), images, 3D bounding boxes, or 3D locations, all projected into a shared CLIP-aligned feature space. Outputs are structured as per-query predictions: a binary mask over segments, a scalar task-relevance score, and a generated text sentence, which are selectively combined depending on the task (e.g., mask+grounding for segmentation, grounding alone for visual grounding, generation for QA/captioning). The model supports flexible inference with any subset of the three scene representations using a single set of weights.

## Method

PQ3D unifies heterogeneous 3D representations by encoding point clouds (PointNet++), voxels (sparse convolutional U-Net), and multi-view images (OpenSeg back-projection) into segment-level features in a shared 3D coordinate space, with positional encoding from segment centroids. A Transformer-like query decoder initializes zero-valued instance queries at FPS-sampled 3D positions and, over 4 layers, progressively retrieves task-relevant information via masked cross-attention to scene features (restricted to localized neighborhoods for faster convergence), cross-attention to the encoded task prompt, and spatial self-attention. Three universal output heads (mask via Hungarian-matched bipartite matching, grounding via linear projection, generation via T5-small decoder) are trained jointly with a weighted multi-task loss. Training is two-stage: 800 epochs of instance segmentation on ScanNet200 followed by 50 epochs of multi-task training across 8 datasets (~662K samples), with random dropout of scene features (rate 0.6) during masked-attention to enable flexible inference at test time.

## Results

PQ3D achieves state-of-the-art results across ten 3D-VL benchmarks. On instance segmentation (ScanNet200, open-vocabulary), it reaches 32.5% AP25, surpassing OpenMask3D (23.1%) by 9.4 points. On visual grounding, it attains 51.2% average accuracy on ScanRefer (IoU@0.5), 79.7% on Sr3D, and 50.1% on Multi3DRefer, outperforming 3D-VisTA by 5.4% and M3DRef-CLIP by 11.7% respectively. On dense captioning (Scan2Cap), PQ3D scores 80.3 CIDEr, exceeding 3D-VisTA (66.9) by 13.4 points. For embodied navigation (ObjNav), it achieves 80.0% success rate versus 57.1% for the VC-1 baseline.

## Baselines & Comparisons

PQ3D outperforms all open-vocabulary instance segmentation baselines: it beats OpenMask3D [56] by 4.8 AP and 9.4 AP25 on ScanNet200, and OpenScene [45] by 8.5 AP and 14.7 AP25; with a closed-vocabulary head it also marginally surpasses Mask3D [54] (27.0 vs 26.9 AP, 46.3 vs 41.4 AP25). On visual grounding, PQ3D dominates 3D-VisTA [71] (51.2 vs 45.8 on ScanRefer, 79.7 vs 76.4 on Sr3D), M3DRef-CLIP [66] (50.1 vs 38.4 on Multi3DRefer), and ViL3DRel [7] across all four grounding benchmarks. On dense captioning, PQ3D leads 3D-VisTA [71] by 13.4 CIDEr (80.3 vs 66.9) and 3DJCG [5] by 32.6 CIDEr (80.3 vs 47.7). The one notable loss is on ScanQA EM@1, where 3D-VisTA [71] edges out PQ3D (27.0 vs 26.1 w/ object), attributed to PQ3D's lack of a classification head for QA; on SQA3D, PQ3D trails 3D-VisTA by 1.4% average accuracy (47.1 vs 48.5), likely due to CLIP's limitations on long sentences. For embodied navigation, PQ3D improves success rate over VC-1 [42] by 22.9 points (80.0% vs 57.1%), and also surpasses the dataset baselines of ScanQA [3], SQA3D [41], and Scan2Cap [9] on their respective metrics.

## Relation to Prior Work

PQ3D extends the query-based decoding paradigm (DETR, Mask2Former, PerceiverIO, XDecoder) from 2D perception and unified 2D-VL tasks into the 3D vision-language setting, where no prior query-based unified framework existed. It departs from task-specific 3D-VL methods (3D-ViSTA, Mask3D, OpenScene, ViewRefer) that each handle a single task with a fixed representation, by aligning voxels, point clouds, and multi-view images into a shared segment-level 3D coordinate space and using promptable queries to adaptively retrieve task-relevant information. The multi-task training builds on 3DJCG and UniT3D, which jointly trained only two tasks, but scales this to ten tasks with diverse prompt formats and output heads, while the promptable segmentation concept draws from SAM and open-vocabulary 3D methods like OpenMask3D.

## Why It Matters / Open Questions

PQ3D is the first model to simultaneously handle 3D instance segmentation, visual grounding, question answering, dense captioning, and embodied navigation within a single architecture, and it outperforms task-specific SOTA on most benchmarks—suggesting that unified multi-task training is a viable path toward comprehensive 3D scene understanding for embodied agents. The flexible inference capability (operating with any subset of available representations) and zero-shot generalization to novel prompt types (e.g., image sketches) make it practically deployable in real-world settings where sensor availability varies. Key limitations include the scale gap relative to 2D vision-language foundation models, CLIP text encoder struggles with long sentences (affecting SQA3D), and reduced robustness on tail classes; the authors identify scaling with more scenes and leveraging 2D foundation models to guide 3D training as the primary directions for future work.

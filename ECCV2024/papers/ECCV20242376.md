## Problem

Existing image watermarking methods for AI-generated content are applied as a post-generation step, introducing computational overhead and decoupling the watermarking latent features from the generation latent space. Prior in-generation approaches are limited: Stable Signature requires a separate fine-tuned decoder per watermark message (poor scalability), and Tree-Ring only works with deterministic sampling and requires unreliable noise inversion for extraction. The paper asks whether the latent space that LDMs already use for generation can simultaneously serve as the watermarking space, enabling watermark-free generation with near-zero overhead.

## Input / Output

In in-generation mode, the input is a latent feature z ∈ R^{H/f × W/f × C} produced by the diffusion process (f=8 for KL-f8, yielding 64×64×4 latents for 512×512 images) together with a k-bit binary watermark message m (typically 32–48 bits, up to 128 bits tested). The output is a watermarked RGB image x̂_w = D_w(z) at 512×512 resolution. In post-generation mode, an arbitrary RGB cover image x is encoded to z = E(x), and the watermarked image is computed as x̂_w = x + D_w(z) − D(z). A separate ResNet-50-based extractor outputs the k-bit message m̂ for matching against a database of registered user IDs.

## Method

LaWa injects lightweight watermark embedding modules W_Emb_i into each upsampling step of the frozen LDM decoder, creating a coarse-to-fine multiscale embedding where the watermark is progressively refined as the latent resolution increases. Each module maps the k-bit message to a small noise block b_i via a linear layer, tiles b_i spatially to match the current latent size (spatial watermark coding that creates redundancy for geometric-attack robustness), and passes the result through a zero-initialized convolution to produce a residual δz_i added to the latent. Training keeps the LDM encoder and original decoder layers frozen, optimizing only the embedding modules and a ResNet-50 extractor with a combined loss of MSE, LPIPS, a WGAN adversarial critic for perceptual quality, and a BCE extraction loss under randomly sampled differentiable attacks. For post-generation use, the watermark is applied as a pixel-space mask D_w(z) − D(z) added to the cover image, requiring no retraining of the generation pipeline.

## Results

On AI-generated 512×512 images with 48-bit watermarks, LaWa (in-generation) achieves the best perceptual quality (LPIPS 0.04, SIFID 0.02) and the highest average bit accuracy (0.94) across 10 attacks, with a near-zero embedding overhead of 1 ms. For 32-bit watermarks, LaWa reaches 0.97 average bit accuracy with LPIPS 0.03 and SIFID 0.01. When used as a post-generation method on the CLIC natural-image dataset (48-bit), LaWa attains 0.90 average bit accuracy with PSNR 35.58 and LPIPS 0.05, outperforming all baselines on nearly every individual attack.

## Baselines & Comparisons

LaWa outperforms all seven baselines on average bit accuracy for 48-bit watermarks on AI-generated images (0.94 vs. 0.92 for SS, 0.91 for FNNS, 0.82 for SSL, 0.49 for RoSteALS). Against the closest in-generation competitor, Stable Signature (SS), LaWa improves LPIPS from 0.05 to 0.04 and SIFID from 0.09 to 0.02 while also gaining 2 points in average robustness. On the 32-bit setting, LaWa achieves 0.97 average accuracy, beating RivaGAN (0.93), SSL (0.85), and HiDDeN (0.77), though RivaGAN retains a PSNR advantage (40.54 vs. 34.25). The only attack where LaWa (48-bit) trails a baseline is 10% random crop, where FNNS reaches 0.96 vs. LaWa's 0.91. In terms of computational cost, LaWa's 1 ms in-generation embedding is roughly 870× faster than SSL and 645× faster than FNNS, making it the only method with negligible overhead for a real-time generation service.

## Relation to Prior Work

LaWa builds directly on the Latent Diffusion Model architecture (Stable Diffusion's KL-VAE autoencoder) and repurposes its latent decoder for simultaneous generation and watermarking, unifying two processes that prior work kept decoupled. It departs from Stable Signature, which requires fine-tuning a separate decoder copy per watermark message, and from Tree-Ring, which modifies the initial noise and requires fragile image-to-noise inversion for extraction. Among post-generation methods (HiDDeN, RivaGAN, SSL, FNNS, RoSteALS), LaWa's key conceptual shift is injecting lightweight coarse-to-fine embedding modules into the frozen intermediate decoder layers so that the same latent features serve both generation and watermarking, rather than applying watermarking as a separate post-processing step.

## Why It Matters / Open Questions

For practitioners deploying LDM-based image generation services, LaWa eliminates the post-generation watermarking overhead (1 ms vs. 870 ms for SSL) while maintaining a single decoder model that scales to many users, making in-generation watermarking practically deployable. The finding that sharing the latent space between generation and watermarking improves the quality-robustness trade-off suggests a broader principle for integrating security features into generative pipelines. However, attribution accuracy drops below 70% under combined attacks, and the method remains vulnerable to severe geometric modifications, leaving open questions about robustness against adaptive or learned removal attacks at scale and extension to video/3D generation.

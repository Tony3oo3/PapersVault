## Problem

Existing discriminative classifiers trained on video-call vs. face-to-face video data achieve high accuracy by exploiting trivial dataset biases (e.g., head pose, gaze direction) rather than revealing genuine behavioral differences in facial expression. Post-hoc explainability methods cannot remedy this because they only explain what a biased model has learned. The paper asks: can we automatically discover and report the subtle, input-dependent spatio-temporal expression differences between two unpaired video domains without prior knowledge of what those differences are?

## Input / Output

The method takes unpaired sequences of 176-frame facial keypoint detections from two domains (e.g., VC and F2F conversations) and produces three outputs: (1) translated facial keypoints that make a VC clip appear F2F (or vice versa), (2) predicted temporal change-points that partition each clip into semantically uniform chunks, and (3) a per-cluster report showing how each of the 12 disentangled β-VAE latent dimensions shifts and scales between domains. The keypoint sequences are the sole input modality; pixel-space visualization is handled separately via a vid2vid model.

## Method

FacET first trains a β-VAE on frame-level facial keypoints to obtain a 12-dimensional disentangled spatial latent code per frame. The core translation function G_XY is then trained adversarially (GAN-style) in this latent space, but is constrained to be interpretable by design: rather than outputting a translated latent directly, it predicts a piecewise shift-and-scale translator (multiplicative ω and additive φ vectors) applied to the input latent. The function is decomposed into G_t, which predicts c−1 temporal change-points to partition the clip into c chunks, and G_f, which predicts a distinct (ω_k, φ_k) translator per chunk. A smooth sigmoid-based weighting scheme makes the non-differentiable chunking operation end-to-end trainable. Because the translator is a per-dimension shift and scale, each latent's contribution to the domain difference is directly readable, yielding an interpretable report without any post-hoc analysis.

## Results

FacET is evaluated via discriminator accuracy (lower is better; 50% is optimal), measuring how well the translation function fools the adversarial discriminator while remaining interpretable. On the ZoomIn dataset, FacET with predicted translators and 2 variable chunks achieves 73.28% average discriminator accuracy (73.33% F2F→VC, 73.50% VC→F2F), and with 7 chunks achieves 73.16%. On the Presidents dataset, FacET (c=2) reaches 79.35% average (70.31% O→T, 88.70% T→O), improving to 78.14% with c=7. These are the best results across all model variants tested, outperforming the no-partition baseline by ~5 points on ZoomIn.

## Baselines & Comparisons

The paper explicitly states that FacET is the first work to tackle this problem, so no external baselines exist. Instead, the authors validate design choices through internal ablations. The full FacET model (predicted translator + variable chunks) outperforms the no-partition variant by ~5 points on ZoomIn (73.28% vs. 78.54%) and by ~6 points on Presidents (79.35% vs. 79.25% for c=1, though the O→T direction shows a larger gap: 70.31% vs. 69.88%). Replacing the predicted translator with a fixed set of 32 pre-learned translators degrades performance substantially (87.58% vs. 73.28% on ZoomIn), confirming that input-dependent translation is essential. Fixed-size chunks perform worse than variable chunks, supporting the need for learned temporal change-points. Increasing chunks from 2 to 7 yields marginal gains on ZoomIn (~0.1 point) but helps on the Presidents dataset (79.35% → 78.14%), likely because presidential speeches have more uniform expression patterns.

## Relation to Prior Work

FacET departs from the dominant paradigm of post-hoc explainability (GradCAM, feature importance) by adopting an interpretability-by-design approach: instead of explaining a black-box discriminator, it learns a generative translation whose parameters are inherently interpretable. The spatial disentanglement step builds directly on β-VAE, while the adversarial training objective is closely related to CycleGAN, though FacET replaces the cycle-consistency loss with a structural constraint (piecewise shift-and-scale translators) that enforces interpretability. The paper also positions itself against prior facial-expression work that classifies discrete emotions or studies person-specific styles, arguing that continuous, interpretable spatio-temporal difference discovery between unpaired domains is an underexplored problem.

## Why It Matters / Open Questions

The paper provides the first systematic, interpretable framework for quantifying how human facial behavior shifts across communication modalities, yielding concrete findings (e.g., larger laughs in F2F, muted eyebrow raises in F2F) that were previously only anecdotally reported. The 240-hour ZoomIn dataset and the de-zoomification application offer practical value for AR/VR and video-conferencing research. Key limitations include reliance on β-VAE disentanglement quality, restriction to 2D facial keypoints (not pixel-level images), and the absence of paired ground truth for evaluating discovered differences—leaving open whether the framework generalizes to richer visual inputs or more complex multi-person interactions.

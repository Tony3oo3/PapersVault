## Problem

Distribution shifts between sites cause correlations between prediction targets and confounding variables to change, degrading model performance. Existing methods either discard unstable features entirely (losing complementary predictive information) or require unrealistic access to labeled data or discrete, low-dimensional confounders at new test sites. The paper asks: can we safely exploit unstable features at new sites using only unlabeled samples, even when confounders are continuous, high-dimensional, or partially missing?
![Teaser figure](../imgs/ECCV20242328/cropped_page1_idx0.webp)

## Input / Output

The method takes an image X (skin lesion, chest X-ray, or synthetic digit) and optionally a set of confounding variables Z (e.g., age as continuous, sex/anatomical site/projection as categorical) as input, producing a binary class label. A key design choice is that Z is optional at test time: when Z is unavailable, the model substitutes a default placeholder value z_0 (chosen outside the support of Z) via input knockout, effectively marginalizing over Z. At new sites, only unlabeled (x, z) or (x) samples are needed for adaptation—no labels y are required.

## Method

GPA decomposes prediction into two estimators: a stable f_θ(X,Z) that learns the site-invariant ratio P(Y|X,Z)/P(Y|Z), and a site-specific g_φ(Z) that models the shifting conditional prevalence P(Y|Z). The first key contribution is an EM-based procedure (Algorithm 1) that estimates g_φ^b at a new site using only unlabeled (x,z) pairs, replacing the indicator function with soft posterior assignments from the current model—removing CoPA's requirement for labeled (y,z) pairs at test time. The second contribution is input knockout: during training, Z values are randomly replaced with a default z_0 outside the support, forcing the network to learn both conditional and marginal predictions, so that at test time missing Z is handled by simply feeding z_0 rather than intractable Monte-Carlo marginalization. The stable f_θ is calibrated via vector scaling on held-out validation data before EM adaptation, and the full pipeline requires only 5 EM iterations with LBFGS at each new site.

## Results

The paper evaluates GPA using F1-score (chosen due to class imbalance) across three experimental settings: a synthetic Color MNIST task, the ISIC skin cancer dataset (test sites NY3 and SYD), and the CXR chest X-ray dataset (test sites PadChest and VinDR). On Color MNIST, GPA achieves the highest F1-score among all methods, slightly trailing CoPA (which has direct label access at test time). On ISIC and CXR, GPA is on par with or outperforms all baselines, and generally surpasses CoPA, indicating the EM-based prevalence estimation yields better g estimators with less overfitting. Ablating Z at test time via input knockout costs only 1–2% F1 on MNIST while still outperforming ERM.

## Baselines & Comparisons

GPA outperforms ERM (both with and without Z input) across all three experimental settings, confirming that domain-adaptive methods beat standard training under distribution shift. Against IRM, DANN, CORAL, and DRO, GPA consistently achieves higher F1-scores on ISIC and CXR test sites; IRM is excluded from single-training-site experiments (CXR) and DRO is excluded when Z is continuous (Age). Compared to the closest baseline CoPA, GPA generally wins on ISIC and CXR because its EM-based indirect estimation of P(Y|Z) avoids overfitting to limited labeled data, though on the simpler Color MNIST task CoPA retains a small edge since it can directly observe test-site labels. The input-knockout variant (GPA*) narrows the gap to full-Z GPA by only 1–2% F1, showing the method remains competitive even when confounders are unavailable at test time.

## Relation to Prior Work

This paper directly extends CoPA (Nguyen et al., 2024), the same group's prior method for exploiting unstable features in anti-causal learning, by relaxing two key assumptions: it removes the need for labeled data at test sites via an EM-based prevalence estimation, and removes the need for confounders Z at test time via an input-knockout mechanism. It also departs from domain-invariant methods (IRM, DRO, DANN, CORAL) that discard unstable features entirely, and from TTLSA which uses EM but requires marginalizing over Z (intractable for high-dimensional Z). The input-knockout idea draws on the missing-input literature (Nguyen et al., 2024; Yoon et al., 2018) and is repurposed here as a learned marginalization over confounders rather than a data-imputation tool.

## Why It Matters / Open Questions

GPA addresses a practically important gap in medical imaging: different hospitals collect different metadata (e.g., VinDR lacks age), and labels are rarely available at deployment. The input-knockout strategy provides a simple, training-time-only mechanism to handle missing confounders without Monte-Carlo approximation, which is a useful technique beyond this specific prevalence-adjustment framework. Key limitations include the assumption that X|Y,Z is stable (requiring a sufficient adjustment set), the need for all Z during training, and fitting separate g per environment with limited data. Open questions include how much unlabeled test-site data is sufficient for adaptation, how to handle partially missing Z during training, and whether a shared g across environments could improve generalization.

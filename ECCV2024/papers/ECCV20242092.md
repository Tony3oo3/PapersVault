## Problem

Active testing for label-efficient model evaluation has been limited to image classification, relying on deep ensemble models that are computationally prohibitive for dense recognition tasks like segmentation and object detection. Moreover, prior methods require labeling entire images and iterative ensemble retraining, which is wasteful when only small regions (e.g., object boundaries) contribute most of the test error. No framework existed for active testing of dense recognition tasks at the region level.

## Input / Output

For semantic segmentation, the meta model receives a concatenation of the RGB input image, the target model's per-pixel class prediction, and its entropy map, which is split into non-overlapping patches (32×32 or 16×16 pixels, yielding 225 or 900 regions per image). For object detection, the input is the array of object query features extracted by the target model (e.g., DETR), where each query corresponds to one region. The output is a per-region loss prediction map plus a single image-level loss estimate, from which a small subset of high-loss regions is selected for annotation; the final output is an unbiased risk estimate of the target model over the entire unlabeled test set.

## Method

MetaAT adapts a Vision Transformer (ViT-B/32 or ViT-B/16, initialized from ImageNet) as a meta model that predicts the target model's loss on unlabeled test data in a single pass. A trainable MLP region loss estimation head is appended after the transformer encoder to produce per-patch (or per-query) loss predictions, while a class token at position 0 yields an image-level prediction; both heads are trained jointly as a multi-task objective. To handle the highly imbalanced loss distribution at the region level, ground-truth losses are discretized via equal-width binning and trained with focal loss, converting the problem from regression to classification. At inference, the meta model scores all test regions, and the LURE importance-sampling estimator (with corrective weights derived from the predicted loss distribution) computes an unbiased risk estimate from only the selected high-loss regions, eliminating the need for iterative ensemble retraining and enabling annotation at the region level rather than the full image.

## Results

MetaAT is evaluated using absolute Error Rate (ER) to the true risk of the entire test dataset. Across four segmentation datasets (Pascal VOC, CityScapes, ADE20K, COCO) and four target models (UNet, PSPNet, SEGNet, FCN), MetaAT achieves average ERs of 8.19% (image level), 7.98% (region-32), and 5.93% (region-16), outperforming the best baseline by 39%, 37%, and 39% respectively. On CityScapes at the region-16 level, MetaAT reaches a 1.36% ER using only 0.07% of annotations — a 10× improvement over prior state-of-the-art. For object detection on COCO (DETR, Deformable-DETR, DINO), MetaAT reduces ER by 68% (image level) and 69% (region level) over random sampling, with 74% and 80% reductions in standard deviation.

## Baselines & Comparisons

MetaAT is compared against three baselines: Random Sampling (RS), Active Testing Surrogate (ATS) [24], and Active Surrogate Estimator (ASE) [23]. MetaAT consistently outperforms all three baselines in average ER and standard deviation across every annotation granularity (image, region-32, region-16) for semantic segmentation. ASE and ATS occasionally beat MetaAT on individual dataset–model pairs (e.g., ASE on CityScapes/PSPNet at image level: 4.39% vs. 4.88%), but their advantage stems from iterative deep-ensemble retraining that incurs 4.6× more training time and yields much higher variance (e.g., ASE std of 10.56 vs. MetaAT's 2.59 at image level). For object detection, ASE and ATS cannot be directly adapted because detection risk involves both classification and regression losses, so MetaAT is compared only against RS, where it achieves up to 96% ER reduction (DINO, image level). The one setting where RS marginally beats MetaAT (ADE20K/FCN at image level: 7.85±3.81 vs. 8.08±2.09) is not statistically significant, and RS exhibits nearly double the variance.

## Relation to Prior Work

This paper extends the active testing paradigm established by ATS (Kossen et al., ICML 2021) and ASE (Kossen et al., NeurIPS 2022) from image classification to dense recognition tasks (segmentation and object detection), where deep ensemble-based approaches are computationally impractical. It replaces the iterative ensemble retraining loop with a single-pass ViT-based meta model that predicts per-region losses, and incorporates LURE (Farquhar et al., 2021) as a bias-corrected subsample risk estimator. The key conceptual departure is introducing region-level annotation granularity, leveraging ViT's patch-based processing to select only informative sub-image regions rather than entire images for labeling.

## Why It Matters / Open Questions

MetaAT is the first framework to address active testing for dense recognition tasks, and the ~99% annotation cost reduction from region-level selection has direct practical value for expensive segmentation and detection annotation pipelines. However, the paper acknowledges that direct estimation of mIoU and mAP remains unsolved—loss serves as a proxy metric, and the correlation between loss and these metrics, while high, is not perfect. The baselines (ATS, ASE) were adapted rather than natively designed for dense tasks, so the 10× improvement on CityScapes partly reflects the baselines' ill-suitedness rather than a fundamental algorithmic breakthrough. Future work could explore whether the meta model approach generalizes to other dense tasks (e.g., keypoint detection, panoptic segmentation) and whether direct metric estimation is feasible.

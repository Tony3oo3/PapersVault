## Problem

Pre-trained unconditional (text-free) diffusion models have not been systematically explored for discriminative tasks, and prior work on diffusion features either relies on text-conditioned models that leak downstream labels or addresses only a single task type. The paper asks whether the intermediate features of a frozen, text-free diffusion U-Net inherently encode discriminative representations, and if so, how to effectively aggregate the diverse features distributed across different U-Net blocks and noise time steps.
![Teaser figure](../imgs/ECCV20241603/cropped_page1_idx1.webp)

## Input / Output

The method takes a 256×256 RGB image, noises it to a chosen diffusion time step t via the forward diffusion process, and feeds the noised image through a frozen Guided Diffusion (ADM) U-Net to extract feature maps from selected blocks b. Downstream outputs vary by task: class labels for ImageNet/CUB/FGVC classification, pixel-wise semantic masks for ADE20K segmentation (via UperNet), and bounding boxes with instance masks for COCO detection (via Mask R-CNN). The feature extraction is parameterized by the (t, b) pair, and the optimal configuration shifts across datasets and tasks.

## Method

The paper proposes three complementary mechanisms to extract and aggregate features from a frozen diffusion U-Net. First, an attention-based classification head replaces fixed spatial pooling with a learnable transformer: feature maps are tokenized via adaptive average pooling and 1×1 convolutions, a CLS token is prepended, and the sequence passes through two transformer layers before a linear classifier. Second, DifFormer extends this to fuse features from multiple noise steps and U-Net blocks by concatenating tokens from different blocks at the same timestep, processing them through shared transformer layers, and concatenating CLS tokens across timesteps into a final linear layer. Third, DifFeed introduces a two-pass feedback mechanism: the first forward pass stores decoder feature maps, a lightweight feedback network (1×1 conv + BatchNorm + ReLU per block) maps them to encoder space, and the second forward pass adds these feedback features to corresponding encoder blocks to enrich representations before final feature extraction. The key insight is that diffusion U-Net features are highly diverse across blocks and noise steps (verified via CKA analysis), with early-middle noise steps and middle blocks generally optimal, and that decoder features contain complementary semantic information that can be fed back to improve encoder representations.

## Results

On ImageNet-1k linear probing, DifFeed achieves 77.0% top-1 accuracy with a frozen Guided Diffusion U-Net backbone, while DifFormer reaches 76.0% and the attention head alone reaches 74.6%, all substantially outperforming the out-of-the-box GD linear probe (64.9%). For semantic segmentation on ADE20K, multi-block GD features achieve 44.3% mIoU and DifFeed achieves 44.0%, both surpassing DreamTeacher (42.5%) but trailing MAE ViT-L (45.8%). In semi-supervised classification with 1% labels, DifFeed reaches 52.9% accuracy, outperforming SimCLR (48.3%) but slightly below SwAV (53.9%). On COCO detection, diffusion features (t=75, b=24) outperform supervised ResNet-50 Mask R-CNN in both object detection and instance segmentation.

## Baselines & Comparisons

DifFeed (77.0%) decisively outperforms SimCLR (69.3%) by 7.7 points and SwAV (75.3%) by 1.7 points on ImageNet linear probing, while also beating MAE (73.5%) by 3.5 points. Against the GAN-based unified model BigBiGAN (60.8%), DifFeed gains 16.2 points in accuracy while maintaining a competitive FID of 26.21 versus BigBiGAN's 28.54. The closest competitor is MAGE (78.9%), which leads DifFeed by 1.9 points but requires a resource-heavy joint training pipeline (VQGAN + masked token modeling on 32 V100s for 4 days), whereas DifFeed is a lightweight post-hoc module on a frozen backbone. On ADE20K segmentation, both multi-block GD (44.3%) and DifFeed (44.0%) surpass DreamTeacher (42.5%) and SwAV (41.2%), but MAE ViT-L (45.8%) remains the strongest. For COCO detection, diffusion features outperform the supervised ResNet-50 Mask R-CNN baseline in both AP metrics, though MAE ViT-L still leads. In semi-supervised settings (1% labels), DifFeed (52.9%) beats SimCLR (48.3%) but trails SwAV (53.9%) by 1 point.

## Relation to Prior Work

This paper repurposes the frozen U-Net backbone of Guided Diffusion (Dhariwal & Nichol, 2021) as a feature extractor, departing from prior diffusion-feature work (DDAE, DIFT, DreamTeacher) that either relied on text-conditioned models (introducing label leakage) or targeted a single downstream task. The DifFeed module adapts the encoder-decoder feedback architecture from Shrivastava & Gupta (ECCV 2016, originally for Faster R-CNN) to the diffusion U-Net's symmetric encoder/decoder blocks. Conceptually, the paper positions itself against the unified-model line (MAGE, BigBiGAN) by showing that post-hoc extraction from an already-trained generative model can approach jointly-trained unified learners, eliminating the need for expensive multi-stage training pipelines.

## Why It Matters / Open Questions

The practical implication is significant: practitioners can leverage existing open-source diffusion checkpoints for discriminative tasks without retraining the backbone, reducing the cost of building unified generative-discriminative systems. However, the methods still trail MAE ViT-L on dense prediction and detection, and diffusion U-Nets are substantially larger and slower than the ViT backbones they compete with, limiting immediate adoption. Open questions include whether the dataset-dependent optimal block/timestep selection can be made automatic, whether smaller or latent-space diffusion models retain these properties, and whether the gap to top SSL methods closes with architectural improvements or longer training.

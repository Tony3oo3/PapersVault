## Problem

Generating ultra-high-resolution images (e.g., 4096×4096) with diffusion models requires O(N²) GPU memory to store the full image's hidden states, exceeding the capacity of standard hardware (80GB+ for a single 4096×4096 image). Existing workarounds such as cascaded generation, MultiDiffusion, or dilated sampling either cap the achievable resolution or introduce artifacts from the mismatch between local training and global inference.

## Input / Output

The model accepts a low-resolution RGB image of arbitrary resolution and aspect ratio, which is first upsampled by a factor f and concatenated with the noised input along the feature dimension before being fed to the network in pixel space (not latent space). An optional text prompt can be injected via CLIP's aligned image-text space to steer generation direction without any image-text training. The output is a single ultra-high-resolution image; the model was trained at 4× upsampling but generalizes to other ratios and can be applied iteratively for even larger scale-ups.

## Method

The core contribution is Unidirectional Block Attention (UniBA), which partitions the image into blocks and generates them in a sequential top-left-to-bottom-right batch order, where each block's self-attention query interacts only with the key/value vectors of itself and three 1st-order neighbors (top, left, upper-left). This unidirectional dependency structure reduces peak memory from O(N²) to O(N), since only the KV-caches of blocks still needed by downstream blocks are retained. Built on a DiT backbone, Inf-DiT adds 2D Rotary Positional Encoding with random starting points for resolution generalization, a CLIP image embedding injected at every layer for global semantic consistency, and a first-layer cross-attention over the surrounding 3×3 LR blocks to enforce local continuity. The inference process generates n×n blocks simultaneously (n chosen to maximize throughput under the memory budget), discarding stale KV-caches after each batch, and the total FLOPs remain constant regardless of n.

## Results

On the HPDv2 ultra-high-resolution generation benchmark, SDXL+Inf-DiT achieves a mean FID of 70.3, outperforming DemoFusion (73.2), SDXL+BSRGAN (74.8), and ScaleCrafter (111.0), while Direct Inference and MultiDiffusion run out of memory at 4096×4096. On the DIV2K super-resolution benchmark (variable resolution), Inf-DiT achieves FID 20.2, FIDcrop 76.5, PSNR 26.3, and SSIM 0.74, surpassing BSRGAN (FID 35.0) and Real-ESRGAN (FID 35.5) across all four metrics. The model also saves over 5× GPU memory compared to UNet-based SDXL when generating 4096×4096 images, reducing peak memory from >80 GB to ~23 GB.

## Baselines & Comparisons

Inf-DiT outperforms all five HPDv2 baselines on the mean FID metric. Against the closest competitor DemoFusion, Inf-DiT improves FIDcrop from 82.6 to 76.2 at 4096×4096 (an 8% relative gain) and from 72.0 to 71.9 at 2048×2048. SDXL+BSRGAN achieves a marginally lower FID at 4096 (66.0 vs. 67.0) but is clearly worse on FIDcrop (85.0 vs. 76.2), indicating Inf-DiT produces more coherent local details. ScaleCrafter degrades severely at 4096 (FID 115.1, FIDcrop 153.3), while Direct Inference and MultiDiffusion simply cannot allocate memory at that resolution. On DIV2K super-resolution, Inf-DiT dominates BSRGAN (FID 20.2 vs. 35.0, FIDcrop 76.5 vs. 143.2) and Real-ESRGAN (FID 20.2 vs. 35.5) by large margins, and also beats the fixed-resolution diffusion-based methods StableSR (FID 38.6 vs. 74.8) and LDM (FID 86.8 vs. 152.6) on all perceptual and fidelity metrics.

## Relation to Prior Work

Inf-DiT builds on the DiT architecture (which replaced U-Net with ViT for diffusion models) and the EDM training framework, but departs fundamentally from prior block-based generation methods (MultiDiffusion, Mixture of Diffusers) that stitch overlapping blocks via pixel-space averaging. The key conceptual departure is the Unidirectional Block Attention (UniBA) mechanism, inspired by Transformer-XL's sliding-window attention, which imposes a strict DAG dependency (each block attends only to itself and three upper-left neighbors) to reduce memory from O(N²) to O(N). Unlike ScaleCrafter and DemoFusion, which use dilated sampling/convolution to approximate global context without retraining, Inf-DiT is trained natively with this unidirectional structure, avoiding the train-test mismatch that causes those methods to produce illogical images.

## Why It Matters / Open Questions

The 5× memory reduction makes 4096×4096 generation feasible on a single RTX 4090 or A100, a task previously requiring >80 GB and thus infeasible on standard hardware. The UniBA mechanism is architecturally general and could be adopted by other transformer-based diffusion or generation models facing the same quadratic memory wall. A notable limitation is that iterative self-upsampling accumulates errors (e.g., a missing pupil at 128² cannot be corrected at later stages), leaving open the question of whether error-correction mechanisms can be integrated. The zero-shot text-guided control via CLIP embedding manipulation is a practical bonus but its robustness across diverse prompts remains unexplored.

## Problem

Spiking Transformers inherit the global self-attention mechanism from Vision Transformers, which acts as a low-pass filter by aggregating information across non-overlapping patches and neglecting high-frequency components such as local edges and pixel-level brightness changes. This is a critical limitation for SNNs, whose neuromorphic data inherently encodes brightness changes (high-frequency signals) and whose spiking neurons naturally produce pixel-level variations. The core challenge is that standard frequency analysis (e.g., Fourier transform) relies on precise matrix multiplications, which are incompatible with the sparse, binary signaling paradigm of SNNs and neuromorphic hardware.

## Input / Output

The model accepts either static RGB images (repeated T times to form a temporal sequence, e.g., 256×256 for ImageNet to satisfy Haar transform requirements, or 32×32 for CIFAR) or neuromorphic event frames (inherently T-frame sequences from event cameras). A Spiking Patch Splitting module converts the 2D spatial input into a token sequence of shape T×N×D, which is then processed through M encoder blocks. The output is a single class label produced by a fully-connected head applied to the globally average-pooled spike features.

## Method

SWformer replaces self-attention with a Frequency-Aware Token Mixer (FATM) comprising three parallel branches: a Frequency Learner performing spiking Haar wavelet forward/inverse transforms, a Spatial Learner using 3×3 convolution, and a Channel Mixer using 1×1 pointwise convolution, with outputs summed. The key technical contribution is a spiking frequency representation that inserts spiking neuron layers between the Haar transform matrix multiplications, combined with negative spike dynamics (ternary {-1,0,1} spikes via a symmetric Heaviside function) to faithfully handle the negative coefficients in the Haar basis. A block-diagonal weight matrix structure splits the d×d transform into k smaller d/k×d/k blocks, reducing parameters from O(d²) to O(d²/k) while enabling parallel computation. The entire pipeline operates in a multiplication-free, event-driven manner using LIF neurons and membrane shortcuts for residual connections, making it directly deployable on neuromorphic hardware.

## Results

On ImageNet, SWformer (Block=4, Transformer-8-512) achieves 75.29% top-1 accuracy with 23.14M parameters and 4.87 mJ power, outperforming SpikFormer (73.38%) by 1.91% and SD Transformer (74.57%) by 0.72%. On CIFAR-10/100, SWformer reaches 96.3%/79.6% (T=6) with only 7.51M parameters, surpassing SpikFormer (95.51%/78.61%) and SD Transformer (95.6%/78.4%). On neuromorphic datasets, SWformer achieves 88.45% on N-Caltech101, 96.32% on N-Cars, 88.88% on Action Recognition, 99.88% on ASL-DVS, and 98.49% on NavGesture, all with T=10 timesteps, substantially exceeding prior SOTA by 2.6–10.8%.

## Baselines & Comparisons

SWformer outperforms all 19 baselines across every evaluated dataset. On ImageNet, it surpasses the strongest Transformer-based SNN baselines—SpikFormer [83] (73.38%) and SD Transformer [75] (74.57%)—by 1.91% and 0.72% respectively, while also reducing parameter count by 22.03% versus SpikFormer. Among ResNet-based SNNs, SWformer exceeds SEW-ResNet-152 [19] (69.26%), MS-ResNet-34 [31] (69.42%), and Spiking ResNet-50 [30] (72.75%) by 2.6–6.0%. On CIFAR-10/100, SWformer (96.3%/79.6%) beats SpikFormer (95.51%/78.61%), SD Transformer (95.6%/78.4%), TEBN [17] (94.71%/76.41%), and DSR [48] (95.4%/78.5%) with fewer parameters (7.51M vs. 9.32–12.63M). On neuromorphic datasets, the margins are largest: SWformer exceeds NDA [42] by 4.75% (N-Caltech101) and 4.42% (N-Cars), Mb-SNN [43] by 10.78% (Action Recognition), Meta-SNN [64] by 3.84% while using 10× fewer timesteps (ASL-DVS), and KNN [47] by 2.59% (NavGesture). No baseline matches or exceeds SWformer on any reported metric.

## Relation to Prior Work

SWformer directly extends the SpikFormer [83] and SD Transformer [75] line of Spiking Transformers, inheriting their Spiking Patch Splitting module and membrane shortcut design, but replaces the global self-attention token mixer with an attention-free Frequency-Aware Token Mixer (FATM). The key conceptual departure is importing the Haar wavelet transform into the spiking domain via a novel ternary (negative-spike) neuron model, addressing a gap left by prior frequency-domain SNN work that relied on band-pass filters or high-latency time-to-value Fourier encoding. The block-diagonal weight structure draws on structured-matrix ideas (Monarch [11]) to reduce parameter count while preserving frequency mixing capacity.

## Why It Matters / Open Questions

The paper identifies and empirically validates a fundamental limitation of Spiking Transformers—their self-attention acts as a low-pass filter, suppressing the high-frequency components (edges, textures, pixel-level changes) that are central to both neuromorphic event data and fine-grained visual recognition. The 4–10% gains on neuromorphic datasets and the 22% parameter reduction at higher accuracy on ImageNet make this practically relevant for energy-constrained edge deployment on neuromorphic chips. An important open question the paper itself surfaces is that the non-spiking (standard) wavelet transform consistently outperforms the spiking version, revealing a tension between signal fidelity and the spike-driven hardware paradigm; closing this gap likely requires new hardware primitives (e.g., Resonate-and-Fire neurons on Loihi 2) that natively support time-frequency operations.

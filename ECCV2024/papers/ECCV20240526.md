## Problem

Traditional end-to-end backpropagation suffers from biological implausibility and the update-locking problem, while existing locally supervised learning methods divide networks into gradient-isolated modules that cannot exchange information, leading to local optima and significant performance gaps versus backpropagation. Additionally, the auxiliary networks required for local supervision impose substantial GPU memory overhead, particularly when the network is partitioned into many modules.
![Teaser figure](../imgs/ECCV20240526/cropped_page1_idx0.webp)

## Input / Output

The method takes standard RGB images (32×32 for CIFAR-10/SVHN, 96×96 for STL-10, 224×224 for ImageNet) and outputs a single class label. Unusually, the network is partitioned into K gradient-isolated local modules (e.g., 16 or 55 for ResNet-32/110), and each module's intermediate feature map is further split into n×n spatial patches (n=2) before being fed to its auxiliary network, so the auxiliary networks never process a full-resolution feature map in one pass.

## Method

HPFF introduces two complementary mechanisms. First, Hierarchical Locally Supervised Learning (HiLo) creates a two-level supervision structure: each module receives an independent auxiliary network (IAN) that supervises it alone, plus cascade auxiliary networks (CANs) that span k=2 adjacent modules, enabling cross-module information exchange and combining local and global feature learning. Second, Patch Feature Fusion (PFF) splits each auxiliary network's input feature map into n×n patches, processes them sequentially through a shared auxiliary network, and averages the patch-level predictions to form the local supervision signal, reducing peak GPU memory from O(D+P+L×D) to O(D/n²+P+L×D/n²) while encouraging the network to focus on patterns recurrent across spatial regions. The approach is plug-and-play, requiring only modification of the auxiliary network's input handling and the addition of cascade modules to any existing locally supervised learning framework.

## Results

On CIFAR-10 with ResNet-32 (K=16), HPFF reduces test error from 14.08 to 8.94 for DGL, from 12.93 to 8.99 for InfoPro, and from 22.71 to 15.74 for PredSim. On the deeper ResNet-110 (K=55), HPFF still yields 25–39% relative error reductions across all three baselines. On ImageNet, InfoPro+HPFF surpasses BP on ResNet-152 (20.99 vs. 21.60 Top-1 error) and ResNeXt-101 (19.94 vs. 20.64 Top-1 error) while using ~20% less GPU memory. GPU memory savings reach up to 79.5% on ResNet-110 (K=55) compared to end-to-end backpropagation.

## Baselines & Comparisons

HPFF is evaluated as a plug-and-play add-on to three supervised local learning baselines: DGL (Belilovsky et al., ICML 2019), PredSim (Nøkland & Eidnes, ICML 2019), and InfoPro (Wang et al., 2021). Across all three baselines and all four datasets, HPFF consistently reduces test error: DGL+HPFF achieves 8.94 test error on CIFAR-10 (ResNet-32, K=16) versus 14.08 for vanilla DGL, and 3.59 on SVHN versus 5.05. InfoPro+HPFF reaches 8.99 on CIFAR-10 (vs. 12.93) and, notably, surpasses end-to-end BP on ImageNet with ResNet-152 (20.99 vs. 21.60 Top-1 error) and ResNeXt-101 (19.94 vs. 20.64). PredSim+HPFF shows the largest absolute gains on CIFAR-10 (22.71→15.74 at K=16) but still trails DGL+HPFF and InfoPro+HPFF in absolute accuracy. On ImageNet with VGG13 (K=10), DGL+HPFF narrows the gap to BP from 7.19 to 4.08 Top-1 error points, though it does not fully close it. In all comparisons, HPFF also reduces GPU memory by 19–80% relative to BP, making it strictly superior to the baselines on both accuracy and memory efficiency.

## Relation to Prior Work

This paper extends the supervised locally supervised learning paradigm (DGL, PredSim, InfoPro), which partitions networks into gradient-isolated local modules each trained by a dedicated auxiliary network. The key departure is a two-level hierarchical structure (HiLo) that adds cascade modules spanning adjacent local modules to enable inter-module information exchange, directly addressing the 'shortsightedness' and local-optima problems identified in prior work. Additionally, Patch Feature Fusion (PFF) repurposes the patch-based computation idea from vision transformers to the auxiliary network context, splitting feature inputs into patches to reduce memory while encouraging the network to focus on patterns recurrent across spatial regions. The method is explicitly positioned as a plug-and-play enhancement composable with any existing supervised local learning framework rather than a replacement.

## Why It Matters / Open Questions

The paper demonstrates that the persistent performance gap between locally supervised learning and end-to-end backpropagation—especially pronounced when networks are divided into many small modules—can be substantially closed (e.g., 39% relative error reduction for DGL on ResNet-110 with K=55) while simultaneously reducing GPU memory by up to 79.5%. The counterintuitive finding that high early-layer classification accuracy is detrimental (because it discards features useful to later layers) provides a useful diagnostic lens for local learning. However, the method still relies on backpropagation for loss computation within each local module, and the authors acknowledge that fully eliminating BP (as in forward-gradient approaches) remains an open direction. The plug-and-play design and consistent gains across three base methods, four datasets, and multiple architectures make it a practical tool, though its impact is bounded to the local-learning subfield rather than the broader training paradigm.

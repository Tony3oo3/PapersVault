## Problem

Learning robust 3D single object trackers is hampered by the sparsity of LiDAR point clouds and the scarcity of large-scale category-specific 3D tracking datasets, making it difficult to train effective 3D matching modules. While 2D SOT has benefited greatly from large-scale video pre-training and powerful foundation trackers, no prior work has bridged the modality gap to transfer 2D matching knowledge into 3D point cloud tracking.
![Teaser figure](../imgs/ECCV20240312/cropped_page1_idx1.webp)

## Input / Output

The tracker receives a 3D point cloud (N_s × 3) from the current search frame and a template defined by a 3D bounding box in the first frame (or k memory frames for MemDisst), and outputs a 7-parameter 3D bounding box (center x,y,z; orientation θ; width, height, length). During training, the TAP module additionally projects the point cloud into a 2D bird's-eye-view image (H_t × W_t × 3) that is consumed by a frozen 2D ViT tracker (OSTrack) to produce 2D matching correspondences used as distillation targets. At inference, only the 3D tracker runs, operating at 25 FPS (SiamDisst) or 90 FPS (MemDisst) on an RTX 3090.

## Method

The framework uses a standard ViT as the 3D target-matching module, creating architectural consistency with 2D trackers (e.g., OSTrack) and enabling natural benefit from 3D self-supervised pre-training (Point-MAE). A lightweight Target-Aware Projection (TAP) module projects 3D point features into 2D BEV images via cross-attention with target features, allowing a frozen 2D pre-trained tracker to perform accurate 2D matching on projected point clouds without any fine-tuning. The key distillation mechanism is IoU-guided matching distillation: the inner-product (matching) matrix between 3D search and memory features is supervised to match the corresponding 2D matching matrix obtained from the 2D tracker, weighted by the IoU between the 2D tracker's predicted box and the ground-truth 2D box to filter unreliable 2D supervision. This is applied to both a memory-less Siamese paradigm (SiamDisst, ViT-384-6) and a contextual memory-based paradigm (MemDisst, ViT-96-3), with the TAP module and 2D tracker used only during offline training and removed at inference.

## Results

On KITTI, SiamDisst achieves a mean Success/Precision of 66.2%/83.9% (25 FPS), outperforming its baseline STNet (61.3%/80.1%) by 4.9%/2.8%. MemDisst sets new state-of-the-art with 71.3%/88.9% at 90 FPS, surpassing MBPTrack (70.3%/87.9% at 56 FPS) on all four categories. On Waymo Open Dataset, MemDisst achieves 45.9%/61.1% mean Success/Precision, matching MBPTrack (46.0%/61.0%) while running 53% faster. On nuScenes, MemDisst (28.9%/34.2%) outperforms MBPTrack (28.1%/33.8%) with a 49% speed advantage.

## Baselines & Comparisons

SiamDisst outperforms all 11 memory-less Siamese baselines on KITTI, with the largest gap over STNet (its direct baseline) of +4.9% Success and +2.8% Precision on the mean, and a particularly strong +8.5% Success gain on Pedestrian (58.4 vs 49.9). MemDisst beats all five memory/motion-based baselines on every KITTI category, improving over MBPTrack by +1.0% Success and +1.0% Precision on the mean while running 61% faster (90 vs 56 FPS). On Waymo Open Dataset, MemDisst essentially ties MBPTrack (45.9 vs 46.0 mean Success) and SiamDisst leads all Siamese trackers (42.7 vs STNet's 40.4). On nuScenes, MemDisst surpasses MBPTrack by +0.8% Success (28.9 vs 28.1) and +0.4% Precision (34.2 vs 33.8), while SiamDisst leads all Siamese methods (28.1 vs STNet's 26.9). The gains are most pronounced in the low-data regime (e.g., Van with only 1994 training samples), where SiamDisst improves over STNet by +5.5% Success, confirming the effectiveness of 2D matching distillation under data scarcity.

## Relation to Prior Work

This paper extends the 3D SOT line of work (STNet, MBPTrack) by introducing a cross-modality knowledge distillation pipeline that leverages a frozen 2D ViT tracker (OSTrack) as a matching teacher. The key architectural departure is the Target-Aware Projection (TAP) module, which draws on P2P-style point-to-pixel mapping to convert sparse 3D point features into 2D images suitable for the 2D tracker without fine-tuning it. The IoU-guided matching distillation loss is novel in using the 2D tracker's predicted box quality as a reliability gate for transferring matching correspondences, distinguishing it from prior feature-based or relation-based KD that operates within a single modality. The use of a standard ViT as the 3D matching module is motivated by architectural consistency with 2D trackers and compatibility with 3D self-supervised pre-training (Point-MAE, ReCon).

## Why It Matters / Open Questions

This work addresses a core bottleneck in 3D SOT—the scarcity of large-scale category-specific point cloud training data—by showing that matching knowledge from 2D video trackers can be effectively transferred via a lightweight projection and distillation pipeline. The practical impact is significant: SOTA on KITTI, WOD, and nuScenes at 25–90 FPS, with the TAP module and 2D teacher entirely removed at inference. Open questions include whether the BEV projection assumption (objects on a ground plane) limits generalization to aerial or indoor scenes, whether more sophisticated 2D-3D alignment (e.g., learned camera parameters) could further improve transfer, and whether the IoU-based reliability gating generalizes to other cross-modality distillation settings beyond tracking.

## Problem

State-of-the-art neural rendering methods (NeRF and generalizable variants) assume clean input images and fail when captures are degraded by low light, motion blur, haze, or rain. Existing 3D restoration approaches explicitly model the physical degradation process in the rendering equation, which limits each method to a single corruption type and requires per-scene optimization. No prior work provides a unified, generalizable 3D pipeline that simultaneously handles multiple degradation types across arbitrary scenes without scene-specific tuning.

## Input / Output

The method takes N calibrated multi-view RGB images (10 views at inference, 8–12 during training) with known camera poses, all captured under a single known degradation type, and produces a clean rendered image from an arbitrary novel viewpoint in a single feed-forward pass. The degradation type is supplied as a discrete label that selects the corresponding latent code; the method does not perform blind restoration. Training uses synthetically corrupted versions of clean multi-view scenes from IBRNet and LLFF, with random corruption strength sampled per iteration to encourage robustness.

## Method

GAURA extends the GNT generalizable NeRF architecture (view transformer + ray transformer) by inserting Degradation-aware Latent Modules (DLMs) at three stages: the UNet feature decoder, the view transformer's query/key/value projections, and the ray transformer's value projection. Each DLM is a hypernetwork-style block where a learnable latent code for a given degradation type generates the weights of a small MLP that transforms input features, allowing the shared network to dynamically adapt its behavior per corruption. An Adaptive Residual Module (ARM) further injects a global-pooled feature from the input view nearest the target angle, capturing within-type variability. The full pipeline is trained end-to-end with MSE + LPIPS loss on synthetic degraded–clean pairs across four corruption types, and new degradations can be added by fine-tuning only the new latent code (6–8 scenes, ~10k steps) while freezing all other parameters. Multiple simultaneous degradations are handled by linearly interpolating the corresponding latent codes.

## Results

On real-world benchmarks (Table 1), GAURA achieves PSNR 19.91 / SSIM 0.738 / LPIPS 0.352 for low-light enhancement, 22.12 / 0.712 / 0.346 for motion blur removal, and 16.82 / 0.759 / 0.288 for dehazing, outperforming all generalizable baselines on every task. On the synthetic LLFF-Corrupted benchmark (Table 2), GAURA leads all four degradation types, with the largest margin on low-light (PSNR 21.98 vs. 18.2 for the best baseline, AirNet) and haze (PSNR 18.95 vs. 15.81 for PromptIR). For motion deblurring, GAURA is on par with the scene-specific DeblurNeRF (22.12 vs. 25.65 PSNR) while remaining fully generalizable, and it surpasses the best all-in-one restoration baseline (DA-CLIP) by ~10% PSNR.

## Baselines & Comparisons

GAURA outperforms all generalizable baselines across every degradation type. Against the scene-specific 3D restoration methods, GAURA beats Aleth-NeRF [7] on low-light (PSNR 19.91 vs. 17.64) but trails DeblurNeRF [23] on motion blur (22.12 vs. 25.65), though DeblurNeRF requires per-scene optimization and is limited to blur. Among the all-in-one 2D restoration + GNT pipelines, GAURA surpasses AirNet [17] by 3.8 dB PSNR on low-light (21.98 vs. 18.2 on LLFF-Corrupted), PromptIR [29] by 3.1 dB on haze (18.95 vs. 15.81), DA-CLIP [21] by 6.5 dB on haze (18.95 vs. 8.36), and AutoDIR [11] by 8.5 dB on low-light (21.98 vs. 10.48). The vanilla GNT [35] baseline without degradation-aware modules (GNT-Restore) is consistently 2–3 dB PSNR behind GAURA, confirming the contribution of the degradation-aware latent codes. On the fine-tuning experiments (Table 3), GAURA also outperforms both Vanilla-GNT [35] and GNT-Restore on the two unseen degradations (snow and defocus blur), validating the plug-and-play nature of the DLM module.

## Relation to Prior Work

GAURA builds directly on GNT, a generalizable transformer-based novel view synthesis method, and repurposes the HyperNetworks architecture to create degradation-aware latent codes (DLM) that modulate the feature extractor, view transformer, and ray transformer. It departs from prior 3D restoration work (DeblurNeRF, Aleth-NeRF, Seathru-NeRF) that explicitly encodes physical degradation models into the rendering equation, instead implicitly learning degradation-specific transformations through small learned parameters. The approach is also conceptually inspired by 2D all-in-one image restoration methods (AirNet, PromptIR, DA-CLIP), which demonstrate that a single network can handle multiple corruption types, but GAURA is the first to bring this unification into the 3D epipolar rendering setting.

## Why It Matters / Open Questions

GAURA provides the first unified 3D restoration-and-rendering pipeline that generalizes across both scenes and degradation types without per-scene optimization, and its plug-and-play DLM design allows efficient adaptation to unseen degradations with as few as 6–8 synthetic scenes. The key insight—that explicit physical modeling of degradation is unnecessary and can be implicitly encoded in learned modules—could simplify future 3D restoration research. However, the method still requires knowing the degradation type a priori (not blind restoration), is limited by epipolar geometry assumptions (struggling with sparse 360° scenes or complex light transport), and the evaluation relies on small-scale datasets with synthetic training data, leaving open questions about robustness on large-scale real-world benchmarks.

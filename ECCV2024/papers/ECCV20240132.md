## Problem

Previous 2D-to-3D segmentation lifting methods like PartSLIP only perform domain adaptation—adjusting a pretrained 2D detector to rendered images and synthetic text prompts—without optimizing the model for the 3D segmentation objective itself. Because the task shifts from 2D detection to multi-view 3D integration, the 2D model's predictions must account for how bounding boxes from different viewpoints will be merged into a coherent 3D representation, a requirement that domain adaptation alone cannot satisfy.
![Teaser figure](../imgs/ECCV20240132/cropped_page0_idx0.webp)

## Input / Output

The method takes a 3D point cloud and a comma-separated list of part names as a text prompt. The point cloud is rendered from 10 fixed viewpoints, and GLIP produces 2D bounding boxes per view per part name, which are then refined into foreground masks by SAM. Output is per-point semantic labels (with a null label for unassigned regions) and instance segmentation obtained by merging adjacent super points that share a label and consistent box membership. Training uses only 8 annotated 3D objects per category in a few-shot setting.

## Method

PartSTAD introduces a task adaptation mechanism that trains a small two-layer MLP (with context normalization) to predict a positive weight for each 2D bounding box, using the relaxed 3D mIoU (mRIoU) as the training objective. Since mIoU is non-differentiable with respect to bounding box positions, the method instead modulates the PartSLIP voting score by multiplying each box's point-membership indicator with its predicted weight, then normalizing across labels via softmax. The MLP takes GLIP's bounding box feature vectors as input and is trained per category with only 8 objects, while GLIP and SAM remain fully frozen. Additionally, SAM foreground masks replace raw bounding boxes in the voting scheme, providing precise 2D segment boundaries that propagate to sharper 3D part boundaries. This combination of task-specific loss, learned box weights, and SAM mask integration yields a 7.0%p mIoU gain over PartSLIP on PartNet-Mobility.

## Results

On PartNet-Mobility (45 categories, 8 training shapes per category), PartSTAD achieves 65.0% mIoU for semantic segmentation, a 7.0 percentage-point improvement over the SotA few-shot method PartSLIP (58.0%). For instance segmentation, it reaches 45.6% part-aware mAP50 (+4.0%p over PartSLIP) and 44.1% part-agnostic mAP50 (+5.2%p over PartSLIP, and more than 3× the 12.1% of zero-shot SAM3D). Improvements are consistent across all 45 object categories, with gains exceeding 15%p in some (e.g., Remote: 53.4% vs 36.6% mIoU).

## Baselines & Comparisons

PartSTAD is compared against three 2D-prior-based 3D segmentation baselines. Against PartSLIP (CVPR 2023), the direct predecessor and SotA few-shot method, PartSTAD wins on every metric: +7.0%p mIoU (65.0 vs 58.0) for semantic segmentation, +4.0%p part-aware mAP50 (45.6 vs 41.6), and +5.2%p part-agnostic mAP50 (44.1 vs 38.9), with consistent per-category gains. Against SATR (ICCV 2023), which uses label propagation instead of super-point voting, PartSTAD achieves a large margin of +30.2%p mIoU over SATR (65.0 vs 34.8 with super points) and +35.7%p over SATR without super points (65.0 vs 29.3). Against SAM3D (2023), a zero-shot instance segmentation method using SAM directly, PartSTAD's part-agnostic mAP50 of 44.1% is more than three times higher than SAM3D's 12.1%, though SAM3D does not perform semantic labeling. The ablation confirms both the weight-prediction network (−3.1%p mIoU when removed) and SAM mask integration (−2.9%p mIoU when removed) contribute meaningfully to the overall gain.

## Relation to Prior Work

PartSTAD builds directly on the PartSLIP pipeline, which renders 3D objects from multiple views, runs GLIP for 2D bounding box detection, and aggregates results via super-point voting. The key conceptual departure is reframing the adaptation step: PartSLIP performs domain adaptation (learning offset vectors for rendered images and part-name prompts), while PartSTAD introduces task adaptation by training a small MLP with a 3D mRIoU objective to predict per-bounding-box weights for the voting scheme. Additionally, PartSTAD integrates SAM foreground masks within each bounding box to replace coarse box boundaries with precise 2D segments, a component absent from PartSLIP and SATR. This positions the work within the broader 2D-to-3D lifting paradigm (SATR, SAM3D, OpenMask3D) but distinguishes itself by optimizing the 2D model's output for the 3D aggregation objective rather than merely adapting it to a new data domain.

## Why It Matters / Open Questions

The paper's central argument—that 2D-to-3D lifting requires task adaptation, not just domain adaptation—provides a principled framework for future work combining 2D foundation models with 3D tasks, and the mRIoU-based weight prediction is a lightweight, generalizable recipe applicable beyond part segmentation. The 7.0%p mIoU and 5.2%p mAP gains over PartSLIP with only 8 training objects per category demonstrate that task-specific objectives can substantially improve few-shot 3D segmentation without large-scale 3D annotations. However, the method remains fundamentally 2D-driven: it cannot reason about occluded or interior geometry, limiting its applicability to complex or partially visible objects. Future work combining this task adaptation with native 3D representations (as the authors note) could address this gap and potentially unlock broader 3D understanding.

## Problem

Existing diffusion-based image compositing methods require an input mask that strictly bounds the generation region, forcing users to draw accurate masks and preventing the synthesis of object effects (shadows, reflections) that naturally extend beyond the object boundary. Moreover, because training data is constructed by masking the object out of the ground-truth image, the model never sees background pixels near the object, leading to inconsistent composites. This paper defines unconstrained generative object compositing, where generation is not limited to the mask and can proceed with an entirely empty mask for automatic placement.

## Input / Output

The model takes a foreground object image, a full (unmasked) background image, and an optional position mask that can be a rough bounding box or an empty mask (all values set to −1) for automatic placement. The background is a fully inpainted image rather than a masked one, which is the key structural difference from prior compositing methods. In addition to the composited RGB image, the U-Net produces a binary object mask as an auxiliary output that becomes usable in as few as 10 diffusion timesteps (vs. 50 for the full image), serving as a fast placement prediction or a realistic mask for downstream mask-based compositing tools.

## Method

The architecture builds on Stable Diffusion 1.5 (VAE + U-Net), where the U-Net receives a channel-concatenated input of [noisy image, position mask, full background image] and is conditioned via cross-attention on multi-scale object embeddings. The object is encoded by a CLIP ViT-L/14 encoder plus a content adaptor at four downsampled scales (s = 1, 0.75, 0.5, 0.25), and the resulting embeddings are averaged to give the model scale-aware information for determining appropriate object size in the scene. The critical training-data innovation is a synthesis pipeline that inpaints the object (along with detected shadows and reflections) out of the original image using a GAN-based inpainter followed by a diffusion-based inpainter, producing full background images so the model learns to generate beyond any mask boundary. Training proceeds in six stages: initial diverse compositing (S1), identity-preserving encoder fine-tuning on multiview/video data (S2), model merging to balance diversity and identity (S3 = 0.25·S1 + 0.75·S2), optional-bbox training with 50% probability (S4), multiscale encoding integration (S5), and finally a mask-prediction head trained with Dice loss (S6). The overall objective combines the standard diffusion denoising loss with a Dice loss (λ = 0.01) for the auxiliary mask output.

## Results

On the DreamBooth test set, the proposed model (with bbox) achieves CLIP-Score 80.95, DINO-Score 85.65, and DreamSim 0.285, outperforming the strongest baseline AnyDoor (80.62 / 83.63 / 0.272) on identity metrics while AnyDoor retains a slight edge on DreamSim. On the synthetic Pixabay-Comp set with ground-truth composites, the model achieves FID 62.41, substantially lower than the best baseline AnyDoor (73.00). For object placement prediction on OPA, the mask-free model attains IoU>0.5 of 31.4% and mean-IoU 0.196, roughly doubling the best prior method TopNet (16.8% / 0.094), while on Pixabay-Comp it reaches SimOPA 65.4% versus TopNet's 48.0%.

## Baselines & Comparisons

Against the five generative compositing baselines (Table 1), the proposed model wins on CLIP-Score and DINO-Score across both test sets, and achieves the best FID (62.41 vs. 70.11 for ObjectStitch and 73.00 for AnyDoor) on Pixabay-Comp. AnyDoor is the closest competitor, edging out the proposed model on DreamSim (0.272 vs. 0.285) and on Pixabay-Comp CLIP-Score (80.28 vs. 77.13), but the gap on FID (73.00 vs. 62.41) indicates substantially better overall image quality for the proposed method. ControlCom is the weakest baseline, trailing by 6+ points on CLIP-Score and 15+ points on DINO-Score. For object placement prediction (Table 2), the mask-free model dominates on IoU>0.5 (31.4% on OPA vs. 16.8% for TopNet, 12.2% for GracoNet) and LPIPS diversity (5.619 vs. 2.758 for TopNet), though GracoNet retains a marginal SimOPA advantage (0.395 vs. 0.382). In the end-to-end pipeline comparison (Table 3), the proposed mask-free model (CLIP 69.60, DINO 71.53, DreamSim 0.420) outperforms every TopNet + compositing-model combination by 10–16 points on CLIP-Score and 12–14 points on DINO-Score, with the best pipeline (TopNet + TF-ICON) reaching only CLIP 57.21 and DreamSim 0.740.

## Relation to Prior Work

This paper builds directly on the Stable Diffusion 1.5 architecture (Rombach et al., CVPR 2022) as its generative backbone and adopts the CLIP-based object encoding and random transformation strategy from ObjectStitch (Song et al., 2022). It departs from the entire line of mask-bounded compositing methods (ObjectStitch, AnyDoor, Paint by Example, TF-ICON, ControlCom) by redefining the training data: instead of masking the object to create a partial background, it fully inpaints the object away to produce a complete background image, thereby removing the mask as a hard generation boundary. The multi-stage training with model merging to balance diversity and identity preservation, combined with multi-scale CLIP encoding to address encoder scale sensitivity, represents the methodological core distinguishing it from prior diffusion-based compositing work.

## Why It Matters / Open Questions

This is the first end-to-end framework that jointly handles object placement, scaling, harmonization, and effect generation (shadows, reflections) without requiring a user-drawn mask, which removes a significant practical bottleneck in compositing workflows. The key open question is whether the inpainting-based data pipeline generalizes to complex multi-object scenes or adversarial backgrounds where inpainting quality degrades. The authors acknowledge limitations with hard-lighting relighting and lateral glass reflections, suggesting the approach may need additional conditioning signals (e.g., explicit lighting parameters or mirror-plane masks) for full generality. The automatic placement capability also raises questions about how well the model handles semantically constrained scenes where only one or two placements are physically plausible.

## Problem

Perceptual illusions such as hybrid images require combining components (e.g., low and high frequencies) from different sources, but traditional methods like Oliva et al. demand manual alignment of independently generated images, and prior diffusion-based illusion approaches that transform the noisy image fail for multiscale decompositions because they perturb the noise distribution. This paper asks whether one can control individual components of an image decomposition independently during diffusion sampling to produce globally coherent images with multiple interpretations.
![Teaser figure](../imgs/ECCV20241528/cropped_page1_idx0.webp)

## Input / Output

The method takes one text prompt per component of a chosen image decomposition (e.g., a low-frequency prompt and a high-frequency prompt) and produces a single RGB image whose perceived content shifts under a corresponding viewing transformation (zoom, grayscale conversion, or motion blur). For inverse hybrids, a reference image is additionally provided, from which one component is extracted and held fixed while the remaining components are generated. Because all decompositions operate in pixel space, the method requires pixel-space diffusion models rather than latent-space ones.

## Method

The core mechanism modifies the reverse diffusion sampling loop: given a linear decomposition x = Σ f_i(x), at each denoising step the model computes N separate noise estimates ε_i = ε_θ(x_t, y_i, t), each conditioned on a different text prompt y_i, then assembles a composite noise estimate ε̃ = Σ f_i(ε_i) by applying the decomposition operators to each noise estimate and summing. This works because standard update steps (DDPM, DDIM) are linear in both x_t and ε_θ, so the composite update decomposes into independent per-component updates, meaning each component is denoised under its own prompt without cross-contamination. For inverse problems, the method additionally projects x_t after each step so that one component matches the corresponding component of a noisy reference image, effectively solving a noiseless inverse problem. The approach is zero-shot, requiring no fine-tuning or auxiliary networks, and for specific decompositions (spatial masking, uniform scaling) it recovers prior techniques like MultiDiffusion and compositional diffusion.

## Results

In a two-alternative forced choice (2AFC) human study (N=77), participants preferred the authors' hybrid images over Oliva et al.'s for overall quality (78.9%), low-frequency prompt alignment (83.3%), and high-frequency prompt alignment (63.3%). On automated CLIP alignment (maximum score over blur levels), the authors' method achieves 0.271 vs. 0.261 for the low-pass prompt and 0.292 vs. 0.272 for the high-pass prompt, outperforming Oliva et al. on both frequency bands.

## Baselines & Comparisons

The sole quantitative baseline is Oliva et al. [46], the classic hybrid image method that manually extracts low-frequency components from one image and high-frequency components from another, then aligns them. The authors' factorized diffusion method wins on all three human-judged criteria: overall image quality (78.9% preference), low-frequency prompt fidelity (83.3%), and high-frequency prompt fidelity (63.3%). On automated CLIP alignment, the authors' method also outperforms Oliva et al. on both the low-pass (0.271 vs. 0.261) and high-pass (0.292 vs. 0.272) prompts. The paper attributes the advantage to the fact that both frequency components are generated jointly by the diffusion model with mutual awareness, avoiding the manual alignment step required by Oliva et al. and producing more photorealistic results.

## Relation to Prior Work

This paper builds on the diffusion model sampling framework (DDPM/DDIM) and the line of work on controllable generation via noise manipulation, particularly Tancik's Illusion Diffusion and Geng et al.'s Visual Anagrams, which modify the noisy image x_t to produce multi-interpretation outputs. The key departure is that Factorized Diffusion instead decomposes the noise estimate ε_θ into components, each conditioned on a different prompt, which the authors show via linearity analysis enables decompositions (frequency, color, motion blur) that would fail under the image-modification approach. The paper also demonstrates that specific decompositions exactly recover MultiDiffusion (spatial masking) and compositional diffusion (scaling), positioning the method as a unifying generalization of these prior techniques. The inverse-problem extension for generating hybrids from real images connects to the broader literature on diffusion-based inverse problem solving (DDRM, DPS, etc.) but applies it to a novel perceptual-illusion setting.

## Why It Matters / Open Questions

The method provides a simple, zero-shot, finetuning-free framework for component-wise control during diffusion sampling, with a clean linearity analysis that specifies exactly when the decomposition is preserved through the update step. This opens a principled path to generating a broader class of perceptual illusions (frequency-based, color-based, motion-based) that were previously intractable with image-modification approaches. Key limitations include reliance on pixel-space diffusion models (decompositions must operate in pixel space), out-of-distribution generation quality, and occasional prompt dominance. Open questions include whether the approach extends to latent diffusion models (where decompositions would need to be defined in latent space) and whether the linearity condition can be relaxed for nonlinear decompositions like CIELAB.

## Problem

Unified multi-class anomaly detection models consolidate multiple class-specific detectors into a single network, saving storage and training time, but they typically carry large parameter counts that make deployment on memory-constrained industrial edge devices impractical. The paper tackles the gap between detection accuracy and model size: how to perform unsupervised multi-class anomaly detection with the fewest trainable parameters while retaining competitive performance.
![Teaser figure](../imgs/ECCV20242281/cropped_page1_idx0.webp)

## Input / Output

The model takes a 224×224 RGB image, extracts features via a frozen EfficientNet-b4 backbone, and reshapes them into a 272×14×14 feature map that is tokenized into 196 spatial tokens with a reduced channel dimension. During inference, the output is an H×W anomaly score map (L2 norm between input and reconstructed features) upsampled to the original image resolution for pixel-level localization, plus a scalar image-level anomaly score obtained by max-pooling the score map. Training is fully unsupervised on normal samples only, using MSE reconstruction loss with feature jittering perturbations.

## Method

MoEAD replaces the standard stacked transformer decoder with a single parameter-sharing decoder block repeated N=4 times, where the multi-head attention and SMoE (Stacked Mixture-of-Experts) layers are shared across all blocks while layer normalization remains block-specific. The key insight is that FFN layers encode block-unique representations, so the FFN is replaced by a SMoE layer—two cascaded MoE sub-layers each with n experts and Top-2 routing—that yields n²(n−1)² possible expert paths, approximating the routing capacity of a single n²-expert layer at roughly half the parameter cost. Neighbor Masked Attention with a learnable query embedding prevents the model from reconstructing anomalous regions, and a coefficient-of-variation auxiliary loss enforces balanced expert utilization. The result is a 4.9M-parameter model (vs. 7.7M for UniAD, 18M for HVQ-Trans) achieving 97.7 I-AUROC / 97.0 P-AUROC on MVTec-AD with the lowest FLOPs among compared methods.

## Results

On MVTec-AD, MoEAD achieves a mean I-AUROC of 97.7 and P-AUROC of 97.0, ranking second only to HVQ-Trans (98.0/97.3). On the more challenging VisA dataset, MoEAD reaches 93.1/98.7, trailing the SOTA by just 0.1 in I-AUROC. Critically, MoEAD uses only 4.9M trainable parameters and 2.18G FLOPs — the smallest among all compared methods — representing a 36% parameter reduction and 49% FLOP reduction over the next-lightest unified model (UniAD).

## Baselines & Comparisons

MoEAD outperforms DRAEM by 9.6 points in I-AUROC on MVTec-AD (97.7 vs. 88.1) while using 95% fewer parameters (4.9M vs. 97.4M). Against UniAD, the closest unified-model competitor, MoEAD gains 1.2 I-AUROC points (97.7 vs. 96.5) with 36% fewer parameters and 49% fewer FLOPs. DiAD achieves a comparable I-AUROC (97.2) but requires 1.3B parameters and >2.2T FLOPs, making it impractical for edge deployment. The only method that surpasses MoEAD in detection accuracy is HVQ-Trans (98.0 vs. 97.7 I-AUROC on MVTec-AD), but HVQ-Trans uses 3.7× more parameters (18.0M) and 3.4× more FLOPs (7.38G). On VisA, MoEAD matches HVQ-Trans exactly in P-AUROC (98.7) and trails by only 0.1 in I-AUROC, confirming that the parameter-efficiency gains come at negligible accuracy cost.

## Relation to Prior Work

MoEAD sits at the intersection of three research threads: unified multi-class anomaly detection (UniAD, OmniAL, DiAD, HVQ-Trans), parameter sharing across transformer depth (Universal Transformers, ALBERT), and sparse Mixture-of-Experts routing (Shazeer et al., GShard, V-MoE). Its core architectural departure is combining depth-wise parameter sharing with width-wise MoE expansion: by reusing the same attention and SMoE modules across all decoder blocks while letting a gating network route tokens to different experts, the model recovers the representational diversity that naive sharing would destroy. The SMoE layer itself extends the factored-MoE idea from Eigen et al. by stacking two n-expert layers to approximate an n²-expert layer, trading a small amount of FLOPs for a large parameter saving.

## Why It Matters / Open Questions

For industrial edge deployment, MoEAD's 4.9M trainable parameters and 2.18G FLOPs (vs. 18M/7.38G for HVQ-Trans and 1.3B/>2.2T for DiAD) represent a meaningful efficiency win while staying within 0.3% I-AUROC of the best method, making unified multi-class anomaly detection viable on memory-constrained hardware. The SMoE layer offers a reusable design pattern for any parameter-efficient transformer that needs diverse per-token processing without inflating model size. Open questions include whether the approach generalizes beyond the EfficientNet-b4 backbone, whether multi-scale feature pyramids (noted as future work) can close the remaining accuracy gap, and whether the MoE routing strategy transfers to other anomaly detection paradigms such as diffusion-based or zero-shot methods.

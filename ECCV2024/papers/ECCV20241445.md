## Problem

Existing continual learning frameworks for semantic segmentation assume that each incremental task introduces only entirely novel, non-overlapping classes. In real-world applications such as autonomous driving, ontologies evolve over time: broad classes like 'vehicle' or 'billboard' are refined into more specific sub-classes (e.g., bicycle, truck, advertisement sign). The paper formalizes this as CLEO (Continual Learning of Evolving Ontologies) and demonstrates that standard class-incremental learning methods (MiB, PLOP, RCIL) fail severely when classes split from previously learned parent classes rather than emerging from the background.

## Input / Output

At each incremental task t, the model receives RGB images with pixel-wise annotations covering only the current class subset C_t; all other pixels are labeled as background. The class ontology evolves across tasks via a known class-mapping set S_t that specifies which parent classes split into which new sub-classes. The output is a per-pixel segmentation mask over the cumulative class set C_{0:t}, and evaluation is decomposed into three groups—unsplit, split, and retained classes—to separately measure learning of new sub-classes and retention of the remaining parent-class information.

## Method

MoOn (Modelling Ontologies) is a regularization-based distillation approach that generalizes MiB's background-shift correction to arbitrary class splitting. The key mechanism modifies the re-normalized probability used in the KL-divergence distillation loss: for any evolving parent class c_{t-1} that splits into new sub-classes C_new, the new model's probability for c_{t-1} is replaced by the sum of its own c_{t-1} probability plus the probabilities of all newly introduced sub-classes, so the old model's prediction of the broad parent class is not penalized when the new model correctly predicts a refined child class. This is controlled by the class-mapping set S_t, which identifies which parent classes are being split at each step; for entirely new classes, the parent defaults to the background class, recovering MiB's behavior. The segmentation backbone is DeepLabV3 with a ResNet-101 encoder (output stride 16, ImageNet pre-trained), trained with SGD at lr 0.01 (first task) / 0.001 (subsequent tasks), batch size 24, for 30–50 epochs per task.

## Results

On Cityscapes, MoOn achieves 39.31 and 40.62 mIoU (All classes) on the two CLEO settings (CS-Ex1, CS-Ex2), substantially outperforming the best CIL baseline PLOP (28.91, 28.10) and the MiB method (9.11, 18.88). On PASCAL VOC, MoOn reaches 62.52, 28.82, and 50.19 mIoU across three settings, leading PLOP by 10–17 points. On Mapillary Vistas, where the large class count (124) makes the task harder for all methods, MoOn achieves 21.44 and 6.49 mIoU, marginally surpassing MiB (21.27, 6.45) while clearly outperforming PLOP and RCIL.

## Baselines & Comparisons

MoOn consistently outperforms all three CIL baselines (MiB, PLOP, RCIL) across all seven experimental settings on three datasets. The advantage is most pronounced on Cityscapes, where MoOn's 39.31/40.62 mIoU exceeds PLOP (28.91/28.10) by roughly 11 points and MiB (9.11/18.88) by 20–30 points; RCIL collapses to near-zero on split classes in both settings. On PASCAL VOC, MoOn leads PLOP by 10–17 mIoU points (e.g., 62.52 vs 45.62 on VOC-Ex1), while MiB and RCIL trail further behind. On Mapillary Vistas, the gaps narrow considerably due to the 124-class difficulty: MoOn edges out MiB by only 0.17/0.04 mIoU on MV-Ex1/MV-Ex2, but still clearly beats PLOP (19.86→2.22) and RCIL (14.65→3.16). A notable pattern is that MiB and RCIL struggle specifically with split and retained classes (the core CLEO challenge), while PLOP handles split classes reasonably but forgets retained superclass information, which MoOn addresses through its ontology-aware distillation.

## Relation to Prior Work

MoOn directly generalizes the distillation loss from MiB [4], which handled background shift in class-incremental semantic segmentation by re-normalizing predictions over the old label space. Here, the key conceptual departure is that new classes in CLEO may emerge from any previously learned superclass (not just the background), so the distillation must group logits according to the class evolution mapping S_t rather than only the background class. The paper also positions CLEO against LECO [22], arguing that LECO's reliance on all historical data violates the core CL assumption, and against HLE [18], which restricts expansion to full hierarchical levels and targets classification rather than segmentation.

## Why It Matters / Open Questions

CLEO formalizes a practically important scenario—ontologies that refine over time (e.g., Mapillary Vistas v1→v2, evolving traffic regulations in autonomous driving)—and provides seven benchmark settings across three datasets that existing CIL methods handle poorly. Key open questions include: whether the class-relation mapping S_t can be reliably inferred without explicit ontology knowledge, how to handle class merging (a form of intended forgetting), and why all methods degrade sharply on longer task sequences (MV-Ex2). The baseline MoOn is a simple loss modification, so the primary contribution is the problem formulation and evaluation protocol rather than a scalable solution.

## Problem

Open-world egocentric activity recognition requires inferring activities whose verb+noun labels are unknown during both training and inference, a setting where foundation models fail because their outputs are constrained to a prompted search space. Supervised and zero-shot approaches assume a known or partially known label space, leaving a gap for truly open-world inference where the combinatorial space of plausible activities must be discovered from prior knowledge rather than specified in advance.
![Teaser figure](../imgs/ECCV20241564/cropped_page1_idx0.webp)

## Input / Output

The method consumes egocentric video frames with a 200×200 gaze-centered region of interest (using ground-truth gaze or center-bias approximation) and a search space of verb and noun concepts drawn from ConceptNet or generated by GPT-4 for unknown-world evaluation. It produces frame-level activity interpretations (verb+noun pairs) that are temporally smoothed to clip-level predictions, along with grounded object labels and action (verb) labels. The search space ranges from 380 activities (GTEA Gaze) to 29,100 (EPIC-Kitchens-100), and the method can operate with either dataset-derived or entirely external concept lists.

## Method

ALGO is a three-step neuro-symbolic framework built on Grenander's pattern theory formalism. First, evidence-based object grounding constructs compositional prompts for CLIP by expanding each object concept through its ConceptNet ego-graph (IsA, UsedFor, HasProperty, SynonymOf edges), computing a weighted likelihood that combines the object's own CLIP score with scores of its evidence generators weighted by knowledge-graph edge probabilities. Second, object-driven activity discovery computes action-object affinities from ConceptNet paths (with exponential decay and compositional-edge filtering), then formulates each verb+noun combination as an energy-based configuration and finds the minimum-energy interpretation via MCMC simulated annealing. Third, visual-semantic action grounding trains a single-layer linear projection from S3D-G video features to 300-dim ConceptNet Numberbatch embeddings using MSE loss, with iterative posterior-based refinement that alternates between updating action priors in the energy function and retraining the grounding module until generalization error saturates.

## Results

Under the open-world setting on GTEA Gaze, ALGO achieves 13.07% object accuracy, 17.05% action accuracy, and 15.05% activity (word-level) accuracy, substantially outperforming the prior open-world baseline KGL (5.12/8.04/4.91%). With action priors from LaViLa, ALGO+LaViLa reaches 17.50/26.60/22.05% on Gaze and 30.74/27.00/28.87% on Gaze Plus, surpassing LaViLa alone on all metrics. On the larger EPIC-Kitchens-100 dataset (29,100-activity search space), ALGO+LaViLa achieves 17.69% activity accuracy, competitive with LaViLa (17.21%) and EGO-VLP (15.14%). In the zero-shot setting on Charades-Ego, ALGO attains 17.3% mAP using only vision-only pre-training (S3D-G on Howto100M), compared to 26.8% for LAVILA which uses 4M egocentric video-language pairs.

## Baselines & Comparisons

ALGO decisively outperforms the prior open-world method KGL [4] across all metrics on both Gaze datasets (e.g., 17.05% vs 8.04% action accuracy on Gaze; 18.84% vs 10.87% activity on Gaze Plus), with the gap widening when CLIP grounding is added to KGL (KGL+CLIP still trails ALGO by ~9 points on Gaze action). Against the strong VLM baseline LaViLa [65], ALGO alone is competitive on Gaze (17.05% vs 23.07% action) but lags on Gaze Plus; however, ALGO+LaViLa surpasses LaViLa on every metric for both datasets (e.g., 28.87% vs 26.87% activity on Gaze Plus). ALGO+LaViLa also outperforms EGO-VLP [36] on Gaze (22.05% vs 9.31% activity) and is competitive on Gaze Plus (28.87% vs 23.30%). On EPIC-Kitchens-100, ALGO+LaViLa (17.69% activity) marginally beats LaViLa (17.21%) and clearly beats EGO-VLP (15.14%), while ALGO without VLM priors (8.48%) still outperforms KGL+CLIP (4.99%). In the zero-shot Charades-Ego setting, ALGO (17.3% mAP) trails LAVILA (26.8%) and HierVL (26.0%) but exceeds EGO-VLP without EgoNCE (9.2%) and approaches EGO-VLP with EgoNCE (23.6%) using only vision-only pre-training and no paired text-video data. Closed-world supervised methods (Action Decomposition, IDT, Two-Stream CNN) achieve substantially higher numbers (55–79% action) but operate under the assumption that all test labels are seen during training, making them not directly comparable to the open-world setting.

## Relation to Prior Work

This paper extends the authors' own prior work KGL [4], which first formulated open-world egocentric action recognition using pattern theory and ConceptNet, by replacing KGL's reliance on a separate object detector with CLIP-based evidence grounding augmented by compositional prompting from ConceptNet ego-graphs. It further introduces a visual-semantic action grounding mechanism (a linear projection from S3D-G video features to ConceptNet Numberbatch space) that was absent in KGL, enabling the system to learn verb-level associations without explicit supervision. The energy-based pattern theory formalism from Grenander [25] and Aakur et al. [2] provides the unifying inference framework, but the specific combination of neuro-symbolic object grounding, affordance-constrained activity discovery, and iterative posterior refinement is new to this work.

## Why It Matters / Open Questions

The paper demonstrates that a lightweight neuro-symbolic pipeline (1-layer linear projection, simulated annealing, ConceptNet lookups) can achieve competitive zero-shot performance on Charades-Ego (17.3 mAP) without any egocentric video-language pre-training, suggesting that symbolic commonsense knowledge can partially substitute for large-scale paired data. However, absolute open-world accuracy remains low (13–26% object, 10–17% action), and the framework is constrained to egocentric videos (requiring gaze for ROI selection) and to ConceptNet's vocabulary. Key open questions include how to construct truly open search spaces beyond GPT-4-generated lists, whether the approach extends to third-person video, and how to integrate visual commonsense (e.g., scene graphs) to move beyond the symbolic KB's coverage.

## Problem

Existing Prompt-based Continual Learning (PCL) methods rely on static prompt pools trained on seen classes and are designed for closed-world settings where test classes overlap with training classes. In practical open-world scenarios, test-time classes are entirely disjoint from all training stages, and prior PCL methods (L2P, DualPrompt, CodaPrompt) exhibit up to 20% Recall@1 degradation relative to the single-stage upper bound, revealing a critical gap in generalization to unseen concepts under continual data streams.
![Teaser figure](../imgs/ECCV20241311/cropped_page1_idx1.webp)

## Input / Output

The method takes RGB images as input and produces a single image embedding (the [CLS] token at the final layer of a ViT-B/16 backbone pre-trained on ImageNet-21k) used for nearest-neighbor retrieval via L2 distance in embedding space. During training, the ArcFace metric learning loss is applied to the embedding to enforce discriminative class separation, with prototype weights from prior stages appended and jointly trained at each new stage. The retrieval task is evaluated on four open-world benchmarks (Cars, In-Shop, SOP, iNat2018) where queries and candidates belong to classes never seen during any training phase.

## Method

DPaRL replaces the static prompt pool of prior PCL methods with a Dynamic Prompt Generation (DPG) network that produces prompts on-the-fly: the input image tokens are concatenated with a FIFO queue of up to 5 learnable stage tokens, processed by a frozen encoder, and the resulting [CLS] token is mapped to prompt tokens via a low-rank linear layer (rank 256, inspired by LoRA) followed by Dropout and LayerNorm to prevent overfitting of the compressed representation. The generated prompts are prefixed to key and value projections in the attention mechanism of the first L ViT layers. Crucially, unlike prior PCL methods that freeze the backbone, DPaRL jointly updates the discriminative representation backbone using LoRA parameter-efficient fine-tuning alongside the dynamic prompt generation, maximizing interaction between old and new stage concepts. This joint learning paradigm, combined with the dynamic prompt mechanism, improves average Recall@1 by 4.7% over CodaPrompt across 10 CL stages and by 9.1% over 100 stages on open-world image retrieval benchmarks.

## Results

On four open-world image retrieval benchmarks (Cars, In-Shop, SOP, iNat2018) with 10 continual learning stages, DPaRL achieves an average Recall@1 of 80.80% and Forgetting Score of 0.09, surpassing the best prior method CodaPrompt (76.11% R_N) by 4.7% absolute. The gap to the UpperBound (single-stage training on all data, 85.78%) narrows from 9.7% for CodaPrompt to just 5.0% for DPaRL. Over 100 CL stages, DPaRL's DPG component alone improves average Recall@1 by 9.1% over CodaPrompt (77.05% vs. 67.95%), demonstrating stronger scalability with more stages.

## Baselines & Comparisons

DPaRL outperforms all seven baselines across all four open-world retrieval datasets. Against the strongest prior PCL method CodaPrompt [32], DPaRL gains +4.7% average Recall@1 (80.80 vs. 76.11) while maintaining a comparable forgetting score (0.09 vs. 0.10). The gap is largest on Cars (+7.8%) and smallest on iNat2018 (+1.0%), suggesting CodaPrompt's static prompt pool degrades most when class diversity is high. Rehearsal-based ER [7] and regularization-based LwF [21] trail DPaRL by 18.1% and 19.8% respectively in average Recall@1, and suffer substantially higher forgetting (5.51 and 13.33 vs. 0.09). Among PEFT strategies for backbone updates (Table 4), LoRA [16] alone achieves 77.63% average R_N, while DPaRL with LoRA reaches 80.80% (+3.17%), and Adapter [8] achieves 76.99% (−3.81% vs. DPaRL). On the closed-world medical benchmark MedMNIST, DPaRL also leads CodaPrompt by 6.50% average top-1 accuracy (60.99% vs. 54.49%), confirming generalizability beyond image retrieval.

## Relation to Prior Work

This paper extends the Prompt-based Continual Learning (PCL) paradigm—exemplified by L2P, DualPrompt, and CodaPrompt—from the closed-world classification setting to a new open-world continual representation learning problem where training stages have disjoint classes and test classes are entirely unseen. The key architectural departure is replacing the static prompt pool with a Dynamic Prompt Generation (DPG) network that produces image-conditioned prompts on the fly, coupled with a low-rank mapping function inspired by LoRA. Unlike prior PCL methods that freeze the ViT backbone, DPaRL jointly updates the discriminative representation backbone via LoRA, enabling richer interaction between old and new concepts across stages.

## Why It Matters / Open Questions

The paper exposes a critical practical gap: existing PCL methods suffer a ~20% Recall@1 deficit relative to the paragon in the open-world setting (vs. ~5% in closed-world), revealing that static prompt pools fundamentally cannot generalize to unseen classes. The proposed DPaRL closes much of this gap with a simple, parameter-efficient design (FIFO stage tokens + low-rank DPG + LoRA), making it a practical recipe for real-world retrieval systems that must absorb new categories over time without retraining on old data. Open questions include whether the dynamic prompt mechanism transfers to other modalities or architectures beyond ViT-B/16, how it scales beyond 100 stages, and whether the joint backbone update is necessary for non-retrieval open-world tasks.

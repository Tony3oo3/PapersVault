## Problem

When fine-tuning CLIP for class-incremental learning, catastrophic forgetting is not uniform: semantically similar (neighboring) old categories are disproportionately misclassified into new ones, yet most existing methods treat all old classes equally. Additionally, prior work largely uses CLIP's text features only as a fixed classifier, leaving their potential to guide representation adjustment underexploited.
![Teaser figure](../imgs/ECCV20241439/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image as input and outputs a class label over all classes seen so far (no task ID required). The CLIP ViT-B/16 backbone is frozen; only a single linear adapter layer is trained. Old-class features are not stored as exemplars but are synthesized by sampling from per-class Gaussian distributions (mean and covariance estimated from the current task's data), and text features for all class names are computed once via the frozen text encoder with a fixed prompt template.

## Method

RAPF combines two mechanisms. First, during training on a new task, it identifies neighboring old–new class pairs by computing Euclidean distances between their normalized CLIP text features (threshold α=0.65) and applies a hinge loss on Gaussian-sampled old-class features to push them away from the new class's text embedding while preserving proximity to their own, using only a small margin to avoid over-adjustment. Second, after each task, it performs decomposed parameter fusion: the adapter weight matrices from the previous and current task are projected onto a shared orthonormal basis obtained via SVD of the old weights, an element-wise importance mask is computed from the normalized difference in the decomposed coordinates, and the final adapter is reconstructed by element-wise blending the two decomposed representations weighted by this mask, then multiplying back by the shared basis.

## Results

On ImageNet-100 (B0 Inc10), RAPF achieves 87.51% average and 80.23% last accuracy, outperforming the strongest baseline ADAM-Adapter (85.84% / 76.40%) by 1.67% and 3.83% respectively. On CIFAR-100 (B0 Inc5), it reaches 86.87% / 79.26%, surpassing the exemplar-based PROOF (85.12% / 76.13%) by 1.75% and 3.13%. On the fine-grained CUB-200 (B0 Inc20), RAPF attains 76.34% last accuracy versus 75.53% for PROOF, and on ImageNet-1K (B0 Inc100) it achieves 72.58% last accuracy, exceeding the best prompt-based method L2P++ (69.79%) by 2.79%.

## Baselines & Comparisons

RAPF consistently outperforms all seven baselines across every dataset and setting without using exemplars. Against the strongest non-exemplar baseline ADAM-Adapter, RAPF gains 1.5–3.8% in last accuracy on ImageNet-100 and 1.3–4.3% on CIFAR-100, with the gap widening in longer incremental sequences (B0 Inc20: 80.10% vs. 77.08%). Prompt-based methods (L2P++, DualPrompt, CODA) suffer severe degradation in B50/B100 settings due to prompt imbalance, dropping to 22–50% last accuracy, while RAPF maintains 79–80%. SLCA, which fine-tunes the backbone, shows competitive early-task results but accumulates forgetting in long sequences (e.g., 71.08% last on ImageNet-100 B0 Inc20 vs. RAPF's 80.10%). The exemplar-based PROOF is the closest competitor on CIFAR-100 (85.12% vs. 86.87% Avg at B0 Inc5), yet RAPF still leads by 1.75% without storing any old samples. On the fine-grained CUB-200, RAPF (76.34% last) narrowly edges out PROOF (75.53%) and substantially surpasses all other methods (next best: ADAM-Adapter at 70.61%).

## Relation to Prior Work

This paper builds on the adapter-based paradigm for CLIP continual learning (CLIP-Adapter, ADAM-Adapter, PROOF), where a frozen backbone is paired with a small learnable module. It departs from prior work in two key ways: (1) it repurposes CLIP's text encoder not merely as a classifier but as a semantic oracle to identify which old classes are most vulnerable to interference from new classes, then applies a targeted hinge loss to separate those neighboring pairs; and (2) it introduces a decomposed parameter fusion via SVD that treats parameter updates as weights over a shared orthonormal basis, going beyond simple parameter averaging. The Gaussian-distribution-based feature sampling for old classes follows the data-free replay strategy of SLCA and related work, but is combined with the text-guided selection in a novel way.

## Why It Matters / Open Questions

The method offers a practical recipe for CLIP-based CIL that adds only a single linear adapter (no parameter growth across tasks, no exemplars), making it attractive for deployment where storage and privacy constrain replay. The consistent SOTA margins across five datasets (CIFAR-100, ImageNet-100, ImageNet-R, CUB-200, ImageNet-1K) without exemplars demonstrate that the text-guided separation and decomposed fusion are complementary and effective. Key limitations include the manually tuned threshold α for neighbor selection and the reliance on a fixed prompt template; the authors note that dynamic threshold adaptation and deeper text-image mutual influence remain open. The finding that prompt-based methods (L2P++, DualPrompt) degrade sharply in base-50/base-100 settings when paired with CLIP's text encoder, while CODA benefits, highlights an unresolved tension in how prompt parameters interact with frozen text features.

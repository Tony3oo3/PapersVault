## Problem

Transformer-based open-set detectors like DE-ViT achieve strong few-shot object detection performance in-domain but fail to generalize when the target domain differs in visual style, inter-class variance, or boundary clarity. This paper identifies these three domain-gap factors as the root causes of degradation and asks how an open-set detector can be enhanced to handle such cross-domain shifts with only a handful of labeled target examples.
![Teaser figure](../imgs/ECCV20241549/cropped_page1_idx1.webp)

## Input / Output

The model is pretrained on COCO (source domain) and then finetuned on an N-way K-shot support set from a novel target domain (K labeled instances per class, K ∈ {1, 5, 10}), before being evaluated on unlabeled query images from the same target domain. At inference, given a query image and the support set, it outputs bounding boxes with novel class labels for objects belonging to categories entirely unseen during source training. The six target datasets span diverse domains (arthropods, clipart, remote sensing, underwater fish, steel defects, underwater species) with varying ICV and IB levels.

## Method

CD-ViTO builds on DE-ViT (DINOv2 ViT backbone + RPN + ROI + detection/classification heads) and adds three lightweight modules targeting the identified domain-gap factors. (1) Learnable Instance Features (M_LIF) replace the fixed support-instance features with a learnable matrix initialized from them, optimized via the detection losses to increase inter-class discriminability and counter small ICV. (2) Instance Reweighting (M_IR) uses an MLP to score each support instance and performs a weighted sum (residually combined with the mean) so that instances with clear foreground-background boundaries contribute more to the class prototype, mitigating significant IB. (3) A Domain Prompter (M_DP) introduces N_dom learnable vectors as virtual domain perturbations added to prototypes, supervised by a domain diversity loss (InfoNCE pushing domains apart), a prototype consistency loss (InfoNCE keeping same-class perturbed prototypes close while separating different classes), and a cross-entropy classification loss on perturbed features. The total objective is L = L_loc + L_cls + L_dp, and the top two heads (M_DET, M_CLS) are finetuned alongside the new modules on the few support instances.

## Results

On the proposed CD-FSOD benchmark (trained on COCO, tested on six novel target domains), CD-ViTO achieves an average mAP of 29.6 under the 10-shot setting, substantially outperforming the base DE-ViT (5.9 mAP) and DE-ViT-FT (25.2 mAP). Under the 1-shot setting, CD-ViTO reaches 13.9 average mAP versus 1.0 for DE-ViT and 10.1 for DE-ViT-FT. The largest gains appear on ArTaxOr (60.5 mAP at 10-shot, a 332% improvement over Meta-RCNN) and Clipart1K (44.3 mAP), while NEU-DET and UODD remain challenging due to significant indefinable boundaries.

## Baselines & Comparisons

CD-ViTO achieves the highest average mAP (29.6) at 10-shot, outperforming DE-ViT-FT (25.2) by 4.4 points, ViTDeT-FT (19.4) by 10.2 points, Detic-FT (16.5) by 13.1 points, and Distill-cdfsod (20.5) by 9.1 points. Against the base DE-ViT (5.9 mAP), CD-ViTO delivers a ~5× improvement, confirming that the open-set detector's cross-domain failure is addressable. However, CD-ViTO loses to Detic-FT on NEU-DET (12.8 vs. 16.8) and UODD (7.0 vs. 14.4), the two datasets with the most significant indefinable boundaries, where Detic's vision-language matching provides an advantage. Among traditional ResNet-based FSOD methods (Meta-RCNN, TFA, FSCE, DeFRCN), CD-ViTO surpasses all by large margins on the overlapping datasets (e.g., 60.5 vs. 15.5 on ArTaxOr for DeFRCN). The paper also notes that Detic without finetuning is essentially useless (2.2 avg mAP), highlighting that finetuning is critical for open-set detectors in cross-domain settings.

## Relation to Prior Work

This paper builds directly on DE-ViT, an open-set object detector that uses a DINOv2 ViT backbone to detect arbitrary novel categories via prototype matching, and extends it with three lightweight modules (learnable instance features, instance reweighting, and a domain prompter) plus finetuning to address cross-domain gaps. Conceptually, it sits at the intersection of few-shot object detection (FSOD) and cross-domain few-shot learning (CD-FSL), departing from prior FSOD work that assumes source and target share the same distribution, and from prior CD-FSOD efforts (Distill-cdfsod, MoFSOD) by introducing explicit domain-gap metrics (style, ICV, IB) and by studying open-set detectors rather than distillation or architecture search. The learnable instance features draw on visual prompt learning, while the domain prompter borrows the prompter concept but repurposes it as a perturbation mechanism rather than an efficient tuning tool.

## Why It Matters / Open Questions

The paper provides the first systematic benchmark and domain-gap analysis for CD-FSOD, revealing that even SOTA FSOD and open-set detectors degrade catastrophically (e.g., DE-ViT drops to ~1 mAP average) when the target domain differs, and that indefinable boundaries (IB) are the dominant challenge—more so than style or inter-class variance. This reframes how practitioners should think about cross-domain detection: boundary ambiguity, not visual style, is the primary obstacle. However, absolute performance remains low (13.9 mAP average at 10-shot), and the method still struggles on the hardest datasets (NEU-DET, UODD), leaving open whether the domain-prompter concept can be made more principled or whether fundamentally different approaches are needed for high-IB scenarios.

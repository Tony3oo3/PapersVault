## Problem

Previous Multimodal Dialogue Response Generation (MDRG) systems rely on textual descriptions as an intermediary for images, causing two critical failures: text responses lack grounding in actual visual content, and generated image responses lose object consistency across dialogue turns. Additionally, no benchmark dataset exists for evaluating image consistency in multimodal dialogue.
![Teaser figure](../imgs/ECCV20240828/cropped_page1_idx1.webp)

## Input / Output

The model consumes a multi-turn dialogue history where each turn may contain a text response and an image response (or neither). At inference, the system produces a text response and, when an [IMG] token is predicted, a citation-augmented textual image description that is fed to a text-to-image model (BLIP-Diffusion with image conditioning for recurring objects, or Stable Diffusion 2.1 for new objects) to generate the final image. The citation tags (e.g., [cite]0[/cite]) are the key structural element linking the textual description to specific prior images for consistency.

## Method

BI-MDRG introduces three complementary mechanisms to bridge image history. First, visual cross-attention layers (inspired by Flamingo) are added to a decoder-only LM (OpenFlamingo 4B), allowing the language model to directly attend to image features from a visual encoder rather than relying solely on textual captions. Second, a multimodal causal attention mask prevents each text response from attending to prior textual image descriptions, forcing the model to ground its text on raw image features. Third, a Citation Module—an off-the-shelf pipeline of spaCy (POS tagging), GroundingDino (open-set detection), SAM (segmentation), and DINOv2 (feature extraction)—clusters recurring objects across image history and injects citation tags into textual descriptions. Training is two-stage (LM layers first, then visual encoder + cross-attention jointly) with standard next-token prediction. At inference, matching citation tags trigger BLIP-Diffusion conditioned on all prior images sharing that tag, ensuring object consistency without per-object fine-tuning.

## Results

On the MMDialog test set, BI-MDRG achieves the highest scores across all generation metrics: TID BLEU-1 of 52.2, TID ROUGE-1 of 53.2, TR BLEU-1 of 27.6, and TR ROUGE-1 of 25.7, outperforming DivterLLM (44.2/45.5/21.3/20.4) and MiniGPT5 (29.1/–/–/12.1). On PhotoChat, BI-MDRG similarly leads with TID BLEU-1 of 42.1 and TR BLEU-1 of 12.4. For image consistency on the newly created MDIC dataset, BI-MDRG achieves 84.0% citation token prediction accuracy and a DINOv2 consistency score of 0.53, compared to 33.5% and 0.32 for the LLMCite baseline. On ImageChat, BI-MDRG attains BLEU-1 of 10.9 and ROUGE-L of 10.9 for image-grounded text responses, surpassing DivterLLM (8.6/9.6).

## Baselines & Comparisons

Against DivterLLM (same 3B OpenFlamingo backbone), BI-MDRG wins on every reported metric for both PhotoChat and MMDialog, with the largest gains in text response generation (e.g., TR BLEU-1 improves from 21.3 to 27.6 on MMDialog, a ~30% relative increase). Compared to the original Divter (762M DialoGPT backbone), BI-MDRG substantially outperforms on all generation quality metrics, though Divter retains a slight edge in Intent F1 on MMDialog (71.8 vs. 70.5). Notably, BI-MDRG (4B) surpasses MiniGPT5 (9B) on all TID and TR metrics on MMDialog, demonstrating that the architectural contributions (visual cross-attention + citation module) compensate for the smaller backbone. On the MDIC consistency benchmark, BI-MDRG's Citation Module achieves 84.0% citation prediction accuracy and 0.53 DINOv2 score, far exceeding the LLMCite baseline (33.5% / 0.32), confirming that learned citation tagging is critical for maintaining object identity across image responses. PaCE achieves a higher Intent F1 (77.6) on MMDialog but does not generate image or text responses, so it is not directly comparable on generation quality.

## Relation to Prior Work

This paper builds directly on Divter (Sun et al., ACL 2022), the first MDRG system that disentangled text and image response generation using textual image descriptions as an intermediary. BI-MDRG departs from Divter in two key ways: architecturally, it adds Flamingo-style visual cross-attention layers so the language model directly accesses raw image features rather than relying solely on captions, and it introduces a multimodal causal attention mask that blocks text responses from attending to prior textual image descriptions. For image consistency, it draws on the subject-driven generation literature (BLIP-Diffusion, Subject-Diffusion) and introduces a Citation Module that tracks recurring objects across dialogue turns using off-the-shelf detection, segmentation, and feature-extraction components.

## Why It Matters / Open Questions

The paper identifies and addresses a concrete information-bottleneck problem in text-as-intermediary multimodal dialogue systems, showing that both image grounding in text and object consistency in generated images suffer from the lossy image-to-text conversion. The creation of the MDIC dataset (300 hand-annotated dialogues) fills a gap in benchmarking for image consistency evaluation, though its small scale limits statistical confidence. A notable open question is whether the citation framework generalizes to multi-object scenes or very long dialogues where object tracking becomes more complex, and whether the reliance on a pipeline of off-the-shelf components (GroundingDino, SAM, DINOv2) introduces compounding errors in practice.

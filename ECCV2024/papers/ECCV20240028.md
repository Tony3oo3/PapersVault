## Problem

Existing multi-view 3D detection methods either ignore 2D detection entirely or rely on a two-stage pipeline where a separate 2D detector's results are used only once for token selection or 3D query initialization. This one-shot usage underutilizes 2D semantic information, treats the same object across cameras as independent instances, and introduces optimization difficulties from combining heterogeneous detector architectures (e.g., CNN-based 2D with Transformer-based 3D).
![Teaser figure](../imgs/ECCV20240028/cropped_page1_idx1.webp)

## Input / Output

The model consumes V=6 surround-view RGB images (e.g., 704×256, 1408×512, or 1600×640 per camera) together with camera intrinsic and extrinsic parameters, and simultaneously outputs 2D bounding boxes with class labels in each camera's perspective view and 3D bounding boxes (center, dimensions, orientation, velocity) in the BEV space. The 2D ground truth is derived by projecting 3D annotations into each camera, and temporal context is incorporated by propagating top-K historical 3D queries from the previous frame.

## Method

SimPB introduces a hybrid decoder of 6 layers (3 hybrid blocks, each containing one multi-view 2D decoder layer and one 3D decoder layer) that cyclically alternates 3D→2D→3D processing. A Dynamic Query Allocation module projects 3D anchors (center + 8 corners) through camera parameters to build a binary mapping matrix T, which assigns each 3D query only to cameras where it is visible, yielding a variable number M of 2D queries. Query-group self- and cross-attention, masked by a camera-group indicator, restricts 2D query interaction to within the same camera to avoid cross-camera distraction. An Adaptive Query Aggregation module then uses T to average-pool the enriched 2D queries back into 3D queries (with a truncation indicator and residual self-attention), feeding the next 3D decoder layer. Training combines standard DETR-style 2D loss, an observation-angle (alpha) loss, and 3D detection loss with depth-map auxiliary supervision, all optimized end-to-end with Hungarian matching per camera group.

## Results

On the nuScenes validation set with ResNet50 at 704×256, SimPB achieves 0.475 mAP and 0.581 NDS, surpassing Sparse4Dv3 (0.469 mAP, 0.561 NDS) by 0.6% mAP and 2.0% NDS. With a perspective-pretrained backbone (SimPB†), performance improves to 0.487 mAP and 0.590 NDS. At the larger ResNet101 / 1408×512 setting, SimPB† reaches 0.539 mAP and 0.629 NDS, outperforming Sparse4Dv3† by 0.2% mAP and 0.6% NDS. On the nuScenes test set with V2-99, SimPB attains 0.571 mAP and 0.660 NDS, edging out Sparse4Dv3 (0.570 mAP, 0.656 NDS).

## Baselines & Comparisons

SimPB outperforms all 12 compared baselines on the primary 3D detection metrics. Against the strongest sparse-query baseline Sparse4Dv3 [20], SimPB gains +0.6% mAP and +2.0% NDS (ResNet50) and +0.2% mAP / +0.6% NDS (ResNet101), with a notable 12.1% reduction in mAOE. Against DynamicBEV [42], SimPB† improves mAP by 2.3% and NDS by 2.0% at the ResNet50 setting. On the nuScenes test set, SimPB (V2-99) marginally beats Sparse4Dv3 by 0.1% mAP and 0.4% NDS while substantially reducing mAOE (0.262 vs. 0.312). For 2D detection (Table 3), SimPB† achieves the highest AP (0.256 / 0.288) over StreamPETR [37], MV2D [40], and DeformableDETR [45] at both resolutions. In the generalization experiment (Table 8), inserting SimPB's 2D decoder layers into DETR3D [39] and Sparse4Dv2 [19] yields +2.4%/+5.2% and +3.1%/+3.0% mAP/NDS gains respectively, confirming the plug-and-play benefit of the hybrid decoder. The only setting where a baseline is competitive is the ResNet101 3D mAP, where SimPB† (0.539) leads Sparse4Dv3† (0.537) by a narrow 0.2% margin.

## Relation to Prior Work

SimPB builds on the sparse query-based multi-view 3D detection paradigm established by DETR3D, Sparse4D, and StreamPETR, adopting their 3D object query and anchor representations along with temporal query propagation. It departs from prior two-stage approaches (MV2D, Far3D, FocalPETR) that use a separate 2D detector solely for one-shot query initialization or token selection, instead unifying 2D and 3D detection within a single hybrid decoder that cyclically alternates between 2D and 3D layers. The Dynamic Query Allocation and Adaptive Query Aggregation modules, together with camera-group attention, represent the core architectural novelty that enables continuous bidirectional refinement between perspective-view and BEV-space representations.

## Why It Matters / Open Questions

By producing both 2D and 3D detections from a single model, SimPB eliminates the engineering overhead and optimization conflicts of maintaining separate detectors in autonomous driving perception stacks, while the cyclic 3D-2D-3D interaction demonstrably outperforms one-shot 2D-to-3D information transfer. The generalization experiments (plugging SimPB's 2D decoder layers into DETR3D and Sparse4Dv2) suggest the hybrid decoder is a broadly applicable module rather than a monolithic system. The acknowledged limitation of potential inference latency from the dynamic allocation process, and the single-dataset (nuScenes) evaluation, leave open questions about real-time deployability and cross-dataset robustness.

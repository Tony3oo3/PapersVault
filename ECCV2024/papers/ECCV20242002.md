## Problem

Deep unrolled models (DUMs) for accelerated MRI reconstruction suffer from limited information transmission capacity and low flexibility across iteration stages, restricting their performance and generalization to unseen data. Additionally, existing multi-coil sensitivity map estimation approaches in DUMs consume excessive GPU memory due to coil-by-coil forward passes, making adjacent-slice reconstruction impractical for clinical coil counts.
![Teaser figure](../imgs/ECCV20242002/cropped_page1_idx1.webp)

## Input / Output

The method consumes undersampled multi-coil k-space data (with variable coil counts ranging from 8 to 34) along with Auto-Calibration Signal (ACS) data from 2a+1 adjacent slices (a=2, yielding 5 slices). At each unrolled iteration, the CNN receives four inputs: the current reconstruction x_t, the data-consistency residual A^H Ax_t, the zero-filled image A^H y, and a learnable hidden state s_t that implicitly tracks historical gradient information. The output is a fully reconstructed complex MR image, with sensitivity maps estimated jointly across all adjacent slices for each coil rather than independently per slice.

## Method

The paper rethinks the DUM update rule by combining three mechanisms. First, a self-adaptive gradient algorithm replaces the uniform learning rate with pixel-wise dynamic rates inspired by AdaGrad, but reformulates the regularization term as a CNN conditioned on x_t, A^H Ax_t, A^H y, and a hidden state s_t to avoid numerical instability. Second, a Momentum layer is inserted before each decoder level in the Unet denoiser, concatenating features from all previous iteration stages at that level, then applying a 1×1 convolution and a Channel Attention Block to adaptively fuse multi-stage information, mimicking momentum-accelerated gradient descent. Third, for sensitivity map estimation, the method estimates a single coil's sensitivity map across all 2a+1 adjacent slices simultaneously using shared ACS information, reducing forward passes from (2a+1)N to N and cutting GPU memory consumption to ~55% of prior state-of-the-art while improving reconstruction quality.

## Results

On the fastMRI multi-coil knee dataset at ×8 acceleration, the proposed method achieves 40.09 dB PSNR and 94.90% SSIM (PD) and 36.49 dB / 86.29% (PDFS), outperforming the strongest baseline PromptMR by 0.61 dB PSNR and 0.39% SSIM on PD. On the Calgary-Campinas brain dataset at ×10, it reaches 34.74 dB / 93.38%, surpassing PromptMR (34.10 dB / 92.69%) and Recurrent-VarNet (33.27 dB / 91.47%). On the CMRxRecon cardiac dataset at ×10, it leads PromptMR by 0.81 dB PSNR on Cine SAX and 1.38 dB on T1w mapping. The method also reduces GPU memory consumption to ~55% of the previous state-of-the-art while using fewer parameters.

## Baselines & Comparisons

The proposed method outperforms all six baselines across every dataset and acceleration factor tested. Against PromptMR (the MICCAI 2023 CMRxRecon challenge winner), it gains 0.61 dB PSNR on fastMRI knee ×8 PD, 0.64 dB on Calgary-Campinas brain ×10, and up to 1.38 dB on CMRxRecon cardiac ×10 T1w mapping. Against HUMUS-Net-L, the strongest DUM-based baseline on fastMRI knee, the improvement is 1.06 dB PSNR at ×8 PD. Recurrent-VarNet, which learns a weaker image prior, trails by 1.47 dB PSNR on brain ×10 and produces visibly blurrier reconstructions. E2E-VarNet and i-RIM, earlier multi-coil DUMs, are surpassed by 1.37 dB and 2.18 dB respectively on fastMRI knee ×8 PD. The plain U-Net baseline lags by 4.68 dB PSNR, confirming the advantage of the unrolled iterative structure over a single-shot denoiser.

## Relation to Prior Work

This paper extends the deep unrolled model (DUM) framework for multi-coil MRI reconstruction, building directly on E2E-VarNet's end-to-end sensitivity map estimation and the authors' own prior PromptMR work on dynamic/multi-contrast reconstruction. Its key conceptual departure is importing optimization-inspired techniques—self-adaptive (AdaGrad-like) per-pixel learning rates and momentum-based multi-stage feature aggregation—into the unrolled architecture, replacing the standard fixed-rate gradient descent with a more flexible update rule. The memory-efficient adjacent sensitivity map estimation strategy departs from the coil-by-coil forward-pass design in E2E-VarNet by exploiting spatial/temporal/contrast correlations across adjacent slices, reducing forward passes from (2a+1)N to N.

## Why It Matters / Open Questions

The ~55% GPU memory reduction in sensitivity map estimation is practically significant for clinical deployment where multi-coil, multi-slice reconstruction is standard, and the method achieves SOTA PSNR/SSIM with fewer parameters across three diverse anatomies (brain, cardiac, knee). The finding that slice-adjacent sensitivity estimation can degrade performance when inter-slice gaps are large (4 mm in cardiac vs. 0 mm in brain) provides a useful practical guideline for when 2.5D strategies are beneficial. Open questions include generalization to unseen sampling masks and modalities, susceptibility to adversarial perturbations, and whether the adaptive gradient and momentum components transfer to non-unrolled or transformer-based MRI reconstruction architectures.

## Problem

Reconstruction-based anomaly detection methods suffer from a 'learning shortcuts' problem where the model learns identity mapping or noise elimination instead of genuine normal patterns, causing it to fail at reconstructing anomalies as normal instances. This issue becomes significantly more pronounced in multi-class anomaly detection, where learning normal patterns across many categories is harder than simply copying the input, making existing unified frameworks like UniAD and OmniAL unable to fully eliminate shortcut learning.
![Teaser figure](../imgs/ECCV20241790/cropped_page1_idx3.webp)

## Input / Output

The method takes RGB images resized to 256×256 and extracts multi-scale features (stages 1–3) using a frozen EfficientNet-B6 backbone pretrained on ImageNet, with local neighborhood aggregation applied to each patch. During training, Gaussian noise is added to the extracted features as perturbation. At inference, the model produces a pixel-level anomaly score map (H×W) computed by averaging upsampled MSE and cosine-similarity differences between original and reconstructed features across all three scales, from which an image-level anomaly score is derived.

## Method

RLR (Reconstruct features from Learnable Reference) replaces the self-attention in a residual-free Transformer encoder with two parallel modules: Masked Learnable Key Attention (MLKA), which uses a learnable reference representation as the Key vector and applies a neighbor mask so each token is invisible to itself and its neighbors, and Local Cross Attention (LCA), which uses the input features as Query and the learnable reference as both Key and Value with a local-window mask to enforce spatial locality. By making the learnable reference the primary source of reconstruction (serving as Key and Value in LCA) and removing all residual connections, the model's output is fundamentally driven by the reference rather than the input, forcing it to encode normal patterns explicitly. A single shared reference representation per feature level is used across all K=4 encoder blocks, and the LCA output is weighted by α=2 to prioritize reference-driven reconstruction. Training uses only normal samples with a combined MSE and cosine-similarity loss between reconstructed and original multi-scale features.

## Results

On MVTec-AD (15 categories), RLR achieves 98.6% Image-AUROC and 98.5% Pixel-AUROC, outperforming the previous best unified framework UniAD (96.5%/96.8%) by 2.1 and 1.7 points respectively. On VisA (12 categories), RLR reaches 95.9% Image-AUROC and 99.2% Pixel-AUROC, surpassing UniAD (91.5%/98.5%) by 4.4 and 0.7 points. RLR also outperforms the strongest separate-model baseline PatchCore (95.3%/96.4% on MVTec-AD) and OmniAL (97.2%/98.3% on MVTec-AD, 87.8%/96.6% on VisA) in both detection and localization.

## Baselines & Comparisons

RLR outperforms all 8 baselines on both MVTec-AD and VisA in mean Image-AUROC. Against the closest unified competitor UniAD [29], RLR gains +2.1% I-A and +1.7% P-A on MVTec-AD, and +4.4% I-A and +0.7% P-A on VisA. OmniAL [36], a pixel-level reconstruction method, is the strongest baseline on MVTec-AD (97.2/98.3) but RLR still edges it out by +1.4% I-A and +0.2% P-A; on VisA the gap widens to +8.1% I-A and +2.6% P-A. Among separate-model baselines, PatchCore [18] is the strongest on MVTec-AD (95.3/96.4), trailing RLR by 3.3% I-A and 2.1% P-A. Separate methods degrade substantially in the multi-class setting: PaDiM [3] drops to 84.2/89.5 and MKD [21] to 81.9/84.9 on MVTec-AD, confirming the paper's motivation that single-class methods struggle with multi-class normal patterns. On VisA, JNLD [35] (87.1/95.2) and DRAEM [31] (80.5/87.0) are notably weaker than RLR, with gaps of 8.8% and 15.4% in I-A respectively.

## Relation to Prior Work

RLR extends the unified multi-class anomaly detection framework introduced by UniAD [29], which itself builds on the Transformer-based feature reconstruction paradigm of ADTR [30] and the local neighbourhood aggregation of PatchCore [18]. The key conceptual departure is from prior methods that attempted to *increase the difficulty* of learning shortcuts (UniAD's neighbor masking and feature noise, OmniAL's synthetic anomalies) to one that *structurally eliminates* them: by using a learnable reference representation as both Key and Value in attention (with no residual connection), the model's output is primarily determined by the reference rather than the input, making identity mapping impossible by design. This reframes feature reconstruction from 'reconstruct the input' to 'reconstruct from a learned normal template,' a shift that is simple in implementation but fundamentally changes the information flow through the network.

## Why It Matters / Open Questions

The 'learning shortcuts' problem is a well-recognized but previously unsolved limitation of reconstruction-based anomaly detection, and RLR provides the first architectural solution that eliminates it rather than merely discouraging it. The finding that feature perturbation (noise injection) becomes unnecessary once shortcuts are structurally removed is a useful simplification for practitioners. However, the approach is validated only on two industrial datasets (MVTec-AD, VisA) with a fixed EfficientNet-B6 backbone, leaving open questions about generalization to other domains (medical imaging, video), different backbone architectures, and whether the per-category learnable reference can be further unified or made interpretable. The method's reliance on pre-trained CNN features also ties its performance to the quality of those features for the target domain.

## Problem

Open-vocabulary 3D object detection (OV-3DDet) must localize and recognize both seen and previously unseen categories in new 3D scenes, but training data for 3D is scarce compared to the internet-scale data available for 2D. Prior methods that integrate vision-language models either rely too heavily on 2D detection while ignoring 3D geometry (OV3DET), use VLMs only as a coarse filtering prior (CoDA), or bypass VLMs in favor of LLMs with unrealistic scene augmentation (L3DET). None of these approaches comprehensively exploit both textual and visual foundation model knowledge, nor do they align 3D features across instance, category, and scene levels simultaneously.

## Input / Output

The method consumes a 3D point cloud of a scene together with its paired RGB image during training, using the image to drive novel object discovery via a pretrained 2D detector (Detic) and to provide CLIP image features for alignment. At inference, only the point cloud is required (no image input needed). The output consists of 3D bounding boxes parameterized by center, size, and heading angle (7 values) along with a category label for each detected object, covering both base and novel classes.

## Method

INHA is a three-stage framework built on 3DETR. Stage 1 trains a class-agnostic 3D detector using only bounding box regression loss on base objects. Stage 2 (IGND) leverages Detic to detect objects in the paired image, lifts 2D object centers into 3D as supplementary query seeds for the transformer decoder to generate more proposals, and then projects predicted 3D boxes back to 2D to match against 2D detections via IoU, selecting reliable novel objects for retraining the 3D detector. Stage 3 performs hierarchical cross-modal alignment with a frozen CLIP model at three levels: instance-level (L1 loss between 3D object features and CLIP image features), class-level (contrastive learning over point cloud, image, and text features grouped by category), and scene-level (a Permutation-Invariant Scene feature Extraction module using max pooling over concatenated object features, aligned via contrastive loss with CLIP text embeddings of scene-level captions listing all object classes present).

## Results

On SUN RGB-D, INHA achieves 8.91% mAP_Novel and 42.17% mAP_Base (16.18% average), outperforming the strongest baseline CoDA (6.71% / 38.72% / 13.66%) by 30% on novel-class mAP and 10% on base-class mAP. On ScanNetv2, INHA reaches 7.79% mAP_Novel and 25.1% mAP_Base (10.68% average), surpassing CoDA (6.54% / 21.57% / 9.04%) by 19% and 16.4% respectively. On the ScanNet-10 benchmark, INHA attains 30.06% average mAP, edging out CoDA (28.76%) and substantially exceeding L3DET (24.63%) and OV-3DET (24.36%).

## Baselines & Comparisons

INHA outperforms all seven baselines across every dataset and metric. Against the closest competitor CoDA [2], INHA gains +2.2 points on mAP_Novel and +3.5 points on mAP_Base on SUN RGB-D, and +1.25 / +3.53 on ScanNetv2, while also substantially improving mAR_Novel (51.34 vs. 33.66 on SUN RGB-D). The CLIP-based 3D methods (3D-CLIP [20], Det-CLIP [26]) are far behind, with 3D-CLIP requiring image input at inference and achieving only 3.61% mAP_Novel. The point-cloud-only CLIP adapters (Det-PointCLIP [27], Det-PointCLIPv2 [32]) perform worst, with mAP_Novel below 0.2%, indicating that simple feature projection without explicit novel-object discovery is insufficient. On ScanNet-10, INHA (30.06% avg mAP) beats CoDA (28.76%), L3DET [31] (24.63%), and OV-3DET [13] (24.36%), with the largest per-class gains on bookshelf (11.3 vs. 0.03 for CoDA) and dresser (9.1 vs. 3.41 for CoDA).

## Relation to Prior Work

INHA builds directly on the OV-3DDet line of work initiated by OV3DET (which back-projects 2D Detic detections and aligns 3D features with CLIP at the category level) and CoDA (which uses CLIP as a semantic prior for filtering novel objects and aligns at instance and category levels). It departs from these by (1) using the 2D open-vocabulary detector not merely for pseudo-labeling or filtering but as an active source of 3D query seeds and IoU-based selection guidance (IGND), and (2) extending the alignment hierarchy to a scene level via a permutation-invariant pooling module (PISE), a level absent from prior OV-3DDet methods. The base 3D detector is 3DETR, and the vision-language backbone is CLIP, consistent with the broader trend of leveraging pretrained foundation models for 3D perception.

## Why It Matters / Open Questions

The paper demonstrates that tightly coupling a 2D open-vocabulary detector with a 3D detector for novel object discovery substantially improves recall over 3D-only discovery, addressing a practical bottleneck (small, sparse, or distant objects) that limits prior methods. The hierarchical alignment (instance + category + scene) is a natural but previously unexplored extension that captures co-occurrence priors across modalities. Limitations include dependence on paired RGB-D data, reliance on a fixed 2D detector (Detic), and evaluation restricted to indoor scenes (SUN RGB-D, ScanNetv2); whether the approach transfers to outdoor or large-scale 3D settings remains open. The scene-level alignment, while conceptually appealing, contributes only a modest gain (~1 mAP point), suggesting the co-occurrence signal may be weak in small indoor scenes.

## Problem

Previous unified vision models (e.g., LLaVA, Unified-IO, OFA) rely on task-specific modules such as bounding box heads, pixel decoders, and RPNs, which complicate scaling and hinder progress toward a truly general vision model. The paper asks whether a plain multi-layer transformer, analogous to GPT in language, can serve as a universal vision foundation model without any vision-specific architectural additions.
![Teaser figure](../imgs/ECCV20240756/cropped_page0_idx1.webp)

## Input / Output

The model takes an RGB image (converted to 16×16 patch tokens) plus optional text instructions and a task prompt, all embedded into a shared token sequence. All outputs—captions, bounding boxes (4 coordinate points), polygon instance masks (boundary point sequences), and semantic segmentation maps (flattened per-pixel class tokens)—are expressed as autoregressive token sequences over a standard ~30K WordPiece vocabulary, with multi-piece concepts like 'traffic light' compressed into single tokens via a lightweight attention module rather than vocabulary expansion. For object- and pixel-level tasks, the image is partitioned into N grid points (625 for detection at 25×25, 1764 for segmentation at 42×42), each producing a local prediction in parallel.

## Method

GiT is a decoder-only window-based ViT (initialized from SAM) with no task-specific heads; over 98% of parameters reside in the multi-layer transformer. The key mechanism is a universal language interface that tokenizes all visual targets (boxes, polygons, pixel labels) into a standard vocabulary, using a single-layer attention to compress out-of-vocabulary multi-word concepts into single tokens. A multi-task template partitions the image into N grid points, each receiving a bilinearly interpolated local image feature and a text task identifier, enabling parallel autoregressive decoding across subregions. Training is one-stage joint multi-task learning across 27 datasets with task-specific vocabularies and standard cross-entropy loss, without any task-specific fine-tuning. The architecture uses bidirectional self-attention for image/text inputs and left-to-right causal attention for target prediction, with optional image-to-text attention for grounding tasks.

## Results

GiT-H (756M params) achieves 52.9 AP on COCO detection, 35.8 AP on instance segmentation, 52.4 mIoU on ADE20K semantic segmentation, 118.2 CIDEr on COCO captioning, and 89.2 Acc@0.5 on RefCOCO grounding — all with a single ViT-based architecture and no task-specific modules. Multi-task training consistently improves over single-task training (e.g., +1.6 AP on detection, +4.7 CIDEr on captioning, +2.5 Acc on grounding). In zero-shot transfer, GiT-H universal reaches 61.8 mIoU on Cityscapes semantic segmentation and 34.1 AP on Cityscapes detection, surpassing X-Decoder-T (165M) by +14.5 mIoU and +3.6 AP respectively.

## Baselines & Comparisons

GiT outperforms VisionLLM-R50 (7B params) on all five tasks with 50× fewer parameters: detection 46.7 vs 44.6 AP, instance segmentation 31.9 vs 25.1 AP, captioning 112.6 vs 112.5 CIDEr, and grounding 85.8 vs 80.6 Acc. Against specialist models, GiT-B single-task matches Deformable-DETR on detection (45.1 vs 45.4 AP) and exceeds Mask R-CNN on instance segmentation (31.4 vs 37.1 AP is lower, but GiT uses polygon-based output vs mask-based, a different paradigm). GiT-H multi-task surpasses Mask2Former on semantic segmentation (52.4 vs 47.2 mIoU) and MDETR on grounding (89.2 vs 86.8 Acc). In zero-shot transfer (Table 5), GiT-B universal beats X-Decoder-T on Cityscapes semantic segmentation (56.2 vs 47.3 mIoU) and SUN RGB-D (37.5 vs 34.5 mIoU), while BLIP-2 (12.1B) still leads on nocaps captioning (15.8 vs 12.6 SPICE). In few-shot transfer (Table 6), GiT-H universal substantially outperforms DeepLabV3 on DRIVE (57.9 vs 32.1 mDice) and LoveDA (35.1 vs 20.3 mIoU), demonstrating strong generalization from universal multi-task pretraining.

## Relation to Prior Work

GiT extends the decoder-only transformer paradigm from LLMs (GPT) to unified visual modeling, building directly on the window-based ViT architecture from SAM for its backbone and on VisionLLM's discretized coordinate representation for spatial outputs. It departs sharply from prior unified vision models (LLaVA, Unified-IO, OFA, VisionLLM) by eliminating all task-specific modules—no bounding box heads, no pixel decoders, no VQ-VAE, no RPN—replacing them with a universal language interface that expresses every output (text, boxes, polygons, pixel maps) as token sequences. The key architectural novelty is the parallel grid-sampling decoding mechanism, which partitions dense and sparse perception into N independent autoregressive subprocesses, and the out-of-vocabulary compression that maps multi-token concepts (e.g., 'traffic light') to single tokens via a lightweight attention layer without expanding the base vocabulary.

## Why It Matters / Open Questions

GiT demonstrates that the architectural gap between vision and language can be substantially narrowed: a single plain ViT with no task-specific additions handles five perceptual scales simultaneously, and multi-task training yields mutual enhancement analogous to LLMs (e.g., +4.7 CIDEr on captioning, +1.6 AP on detection over single-task training). The zero-shot and few-shot results across medical imaging, remote sensing, and face detection suggest the framework generalizes beyond its training distribution, positioning it as a potential foundation for scalable visual pretraining. However, the model still trails specialist baselines on most tasks (e.g., 52.9 vs. 58.6 AP for detection), uses only simple label assignment, and the parallel decoding strategy's computational cost at very high resolutions remains an open question. Whether this paradigm scales to billion-parameter models and whether the grid-based parallel decoding can be further optimized for pixel-level tasks are important directions for future work.

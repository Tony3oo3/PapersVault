## Problem

Standard object detectors classify objects into a fixed, predefined set of categories, and even open-vocabulary detectors still require a closed set of class embeddings at inference time. This closed-set formulation limits the model to simple noun labels and cannot express richer object descriptions (attributes, actions, context). The paper asks whether object understanding can be recast as an open-set generative task where the model freely produces text for each detected region.
![Teaser figure](../imgs/ECCV20242139/cropped_page1_idx0.webp)

## Input / Output

The model takes a single RGB image (1024×1024 during training, 800×1300 at test) and outputs a set of bounding boxes, each paired with an autoregressively generated text description. The description style is controlled by a special begin token: [ObjectDet] yields short class names (1–3 WordPiece tokens) for detection, while [DenseCap] yields multi-word descriptive sentences. For detection, beam search with k=3 produces up to three candidate class names per box, and the final confidence is the geometric mean of the objectness score and the averaged token-level description score.

## Method

GRiT replaces the multi-category classifier in a two-stage detector with a 6-layer autoregressive text decoder that spells out object descriptions as WordPiece tokens from a 30,522-vocabulary. The visual encoder is a ViT (B/L/H) with windowed self-attention (14×14 windows) plus four global-attention blocks, topped by a simple feature pyramid at five scales; the foreground object extractor uses CenterNet proposals refined by a 3-stage Cascade R-CNN RoI head that performs binary foreground/background classification rather than multi-class. Object features are obtained by cropping the ViT feature map at the predicted box location to 14×14 and flattening, so the text decoder attends to both object appearance and surrounding image context. Training combines standard box/objectness losses with a cross-entropy language-modeling loss over the generated tokens, and the backbone is initialized from MAE self-supervised pre-training on ImageNet-1K. A set of task-specific begin tokens ([task]_i) allows a single model to be jointly trained on short-description (detection) and long-description (dense captioning) tasks without style confusion at inference.

## Results

On COCO 2017 test-dev, GRiT with ViT-H backbone achieves 59.0 AP (64.5 AP75), and with Object365 pre-training reaches 60.4 AP (66.0 AP75), competitive with strong closed-set detectors like DyHead (58.7 AP) and ViT-Adapter-L (58.9 AP). On Visual Genome dense captioning, GRiT achieves 15.5 mAP (ViT-B), substantially outperforming the best non-LLM dense captioning model TDC+ROCSU (11.49 mAP) by over 4 mAP, though trailing the LLM-based ControlCap (18.2 mAP). The ablation shows GRiT's open-set generative approach incurs only a 0.8 AP gap versus a closed-set classifier with identical architecture.

## Baselines & Comparisons

On COCO object detection, GRiT (ViT-H) at 59.0 AP is competitive with closed-set detectors DyHead (58.7 AP) and ViT-Adapter-L (58.9 AP), and with Object365 pre-training (GRiT*) reaches 60.4 AP, matching ViTDet's 60.4 AP on val. However, GRiT trails the strongest closed-set baselines DINO (63.2 AP) and GLIPv2 (60.6 AP), which leverage additional pre-training data and larger backbones. On Visual Genome dense captioning, GRiT (15.5 mAP) substantially outperforms all standard non-LLM dense captioning models, beating TDC+ROCSU (11.49 mAP), CAG-Net (10.51 mAP), and COCG (9.82 mAP) by 4+ mAP, but falls short of the LLM-based ControlCap (18.2 mAP). The paper also shows that replacing GRiT's text decoder with a standard closed-set classifier (same architecture otherwise) yields only 0.8 AP higher, confirming the generative open-set formulation is nearly as effective as the classification approach.

## Relation to Prior Work

GRiT extends the generative image-to-text transformer paradigm (GIT) from image-level captioning to region-level object understanding, repurposing its ViT backbone and autoregressive text decoder to describe individual objects rather than whole scenes. For the visual encoder, it adopts the windowed self-attention and simple feature pyramid from ViTDet to handle high-resolution inputs efficiently. The key conceptual departure is from both closed-set object detectors (which classify among predefined categories) and open-vocabulary detectors (which still require a fixed set of class embeddings at inference): GRiT instead generates free-form text tokens, eliminating the need for any predefined category list and unifying object detection and dense captioning under a single generative objective.

## Why It Matters / Open Questions

The open-set generative formulation offers a more flexible and data-friendly alternative to closed-set detection, as new object concepts can be introduced during training without architectural changes, and the model can produce rich descriptive sentences beyond simple class names. However, the practical impact is tempered by the small text decoder (6-layer, trained from scratch) and the annotation inconsistencies between COCO and VG that degrade joint training performance. Open questions include whether this approach scales to truly open-world inference (recognizing objects never seen in training), how it compares to LLM-based multimodal models as those grow, and whether the 0.8 AP gap to closed-set detection can be closed with larger language models or more training data.

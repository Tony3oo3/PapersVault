## Problem

Implicit neural representation (INR) methods for image representation and compression achieve high visual quality but demand substantial GPU memory and suffer from slow training and decoding, limiting deployment on low-end devices. Directly adapting 3D Gaussian Splatting to single-image representation is non-trivial: it requires depth-based Gaussian sorting (unavailable without camera parameters), uses 59 parameters per Gaussian (inflating storage to dozens of megabytes), and its alpha-blending underutilizes Gaussian data by skipping contributions once accumulated opacity exceeds a threshold.

## Input / Output

The method takes a single RGB image (768×512 on Kodak, up to 1020×1020 on DIV2K) and produces a set of 2D Gaussians (typically 30,000–56,000 points, each with 8 parameters: 2D position, 3 Cholesky covariance factors, and 3 weighted color coefficients) that are rasterized via accumulated summation to reconstruct the image at ~2000 FPS. For the compression task, these parameters are further encoded into a bitstream using 16-bit float quantization for positions, 6-bit asymmetric integer quantization for covariance, and residual vector quantization (2 stages, codebook size 8) for color, yielding competitive bpp with COIN/COIN++ while decoding at ~2000 FPS.

## Method

GaussianImage replaces 3D Gaussians with compact 2D Gaussians (8 parameters vs. 59) and introduces an accumulated summation rasterization that eliminates depth-based sorting and sequential alpha-blending, computing each pixel as an order-independent weighted sum of all covering Gaussians. This mechanism allows merging color coefficients and opacity into a single set of weighted color coefficients, further reducing parameters and enabling a 7.375× compression ratio over 3D GS. For image compression, a two-step pipeline applies quantization-aware fine-tuning (learning scaling/offset factors for covariance and RVQ codebooks for color) followed by entropy coding, with an optional partial bits-back coding strategy that exploits the permutation invariance of the unordered Gaussian set to save additional bitrate. Training uses L2 loss with the Adan optimizer over 50,000 steps, and unlike 3D GS, no adaptive density control is needed since 2D image space has no empty regions.

## Results

On the Kodak dataset, GaussianImage achieves 44.08 PSNR and 0.9985 MS-SSIM with only 106.6 s training time, 2092 FPS rendering speed, 419 MiB GPU memory, and 560K parameters. On DIV2K, it reaches 39.53 PSNR and 0.9975 MS-SSIM at 1738 FPS with 439 MiB GPU memory. As an image codec on DIV2K, it attains 25.66/27.57 PSNR at 0.32/0.64 bpp with ~2000 FPS decoding speed, outpacing JPEG (615/546 FPS) by over 3× while matching or exceeding COIN in PSNR and surpassing it by a large margin in MS-SSIM.

## Baselines & Comparisons

Against MLP-based INRs (WIRE, SIREN), GaussianImage wins decisively on all axes: it achieves 2.6–3.3 dB higher PSNR while training 60–135× faster and rendering 70–190× faster, at the cost of more parameters (560K vs. 137–273K). Versus feature-grid INRs (I-NGP, NeuRBF), GaussianImage matches or slightly exceeds PSNR (44.08 vs. 43.88/43.78 on Kodak) while using 3–5× less GPU memory (419 vs. 1525–2091 MiB) and rendering 1.6–3.2× faster. Compared to naive 3D GS adaptation, the 2D formulation reduces parameters by 6.3× (560K vs. 3540K), cuts training time by 3.2×, and doubles rendering speed (2092 vs. 859 FPS) while improving PSNR by 0.4 dB. In the compression setting on DIV2K, GaussianImage matches COIN in PSNR (25.66 vs. 25.80 at low bpp) but surpasses it by 0.025 in MS-SSIM (0.9154 vs. 0.8905), and decodes ~12× faster (1971 vs. 166 FPS). With partial bits-back coding, the codec outperforms both COIN and COIN++ in RD performance. Against traditional codecs (JPEG, JPEG2000) and VAE-based codecs (Ballé17/18), GaussianImage achieves comparable or better PSNR at similar bitrates while decoding 3–500× faster than all learning-based baselines.

## Relation to Prior Work

This paper repurposes 3D Gaussian Splatting (Kerbl et al., 2023) for the fundamentally different task of single-image representation, reducing each Gaussian from 59 to 8 parameters by discarding 3D projection, spherical harmonics, and depth-dependent alpha-blending. It departs from the dominant implicit neural representation (INR) paradigm (SIREN, WIRE, I-NGP, NeuRBF) by adopting an explicit, discrete set of 2D Gaussians with an order-independent accumulated summation rasterizer, eliminating the need for camera parameters and depth sorting. For compression, it applies vector quantization (RVQ) and optional partial bits-back coding to the Gaussian attributes, positioning itself as a new codec family distinct from both VAE-based and INR-based learned codecs.

## Why It Matters / Open Questions

The ~2000 FPS decoding speed while matching COIN/COIN++ in rate-distortion performance is a substantial practical advance, making neural image codecs viable on low-end hardware where INR-based methods are infeasible due to GPU memory constraints. However, the method requires per-image overfitting (50k optimization steps), limiting it to offline or single-image settings rather than general-purpose real-time encoding; the partial bits-back coding that yields the best RD performance is acknowledged as a proof of concept with slow latency. Open questions include whether the 2D Gaussian framework extends to video, multi-image generalization, or learned (non-overfit) encoders, and whether the accumulated summation formulation can be combined with autoregressive context models to close the remaining gap to state-of-the-art learned codecs.

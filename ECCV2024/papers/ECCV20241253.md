## Problem

Zero-shot correspondence methods that compute nearest-neighbor matches on pre-trained feature grids produce point-wise correspondences that are inherently noisy and lack global structural coherence. Existing feature-fusion strategies (e.g., concatenating DINOv2 and Stable Diffusion features) only indirectly mitigate this by mixing descriptors, without imposing any explicit geometric or spectral structure on the correspondence field itself.
![Teaser figure](../imgs/ECCV20241253/cropped_page0_idx0.webp)

## Input / Output

The method takes a pair of RGB images and two sets of pixel-wise feature grids (h×w×d) from different pre-trained networks — one set (e.g., DINOv2) defines the spectral basis, the other (e.g., Stable Diffusion) serves as the descriptor regularizer. It outputs a 200×200 functional map matrix C, from which dense pixel-to-pixel correspondences are extracted via nearest-neighbor search between the rows of CΦ^M and Φ^N; the same machinery also yields sparse keypoint matches and transferred affordance heat maps. Optimization is performed per image pair at test time, with no training on correspondence data.

## Method

The core idea is to lift correspondence from pixel space into a spectral function space, where a linear functional map C naturally encodes global deformations. A content-aware graph Laplacian is constructed from the first feature set by weighting edges with exp(−‖E_x−E_y‖/σ), and its first 200 eigenfunctions (computed via LOBPCG) form the basis. The second feature set is refined by a bipartite-graph attention module (from Deep Partial Functional Maps) to handle occlusions, then projected onto the basis to form the descriptor-preserving loss ‖C F̃^M − F̃^N‖. Two additional regularizers enforce structure: a diagonality term that penalizes C entries connecting eigenfunctions with dissimilar eigenvalues, and a cycle-consistency term (C^M→N · C^N→M = I) implemented through optimizable latent bases Z^M, Z^N with orthonormality constraints. The full objective is jointly optimized per image pair, and the resulting C is converted to point-to-point correspondences by treating each pixel as a Dirac delta and performing nearest-neighbor search in the spectral domain.

## Results

On the TSS dense correspondence benchmark, the best zero-shot configuration (FMap with DINOv2 as loss features and Stable Diffusion as basis features) achieves 78.9% average PCK across FG3DCar (93.1), JODS (74.0), and Pascal (59.9), marginally outperforming the feature-concatenation baseline of Zhang et al. (78.7%). On SPair-71k sparse keypoint correspondence, the method achieves 72.6% PCK@0.2 and 88.0 MSE, beating the concatenation baseline on MSE (97.2) and PCK@0.2 (72.2) while trailing slightly on PCK@0.1 (55.3 vs. 57.2). The method also improves smoothness substantially, reducing the smoothness metric from 6.81 (concatenation) to 5.74 on the DINOv2+SD configuration.

## Baselines & Comparisons

Among zero-shot methods, the proposed FMap with DINOv2(loss)+SD(basis) achieves 78.9% avg PCK on TSS, edging out the feature-concatenation baseline of Zhang et al. [55] (78.7%) by 0.2 points, while substantially outperforming individual features: DINOv2-ViT-B (69.4%), Stable Diffusion (72.5%), and DINOv1 (52.7%). On SPair-71k, FMap wins on MSE (88.0 vs. 97.2 for concatenation) and PCK@0.2 (72.6 vs. 72.2) but trails concatenation on PCK@0.1 (55.3 vs. 57.2), suggesting the functional map structure improves global consistency at a small cost to local keypoint precision. Against supervised baselines (PWarpC-CATs* at 88.7%) and task-specific unsupervised methods (Semantic-GLU-Net at 85.2%), the zero-shot FMap still lags by 6–10 points, reflecting the inherent advantage of task-specific training. The ablation in Table 1 also shows that using the same feature set for both basis and loss (e.g., FMap DINOv2+DINOv2 at 71.0%) underperforms the cross-feature configuration, confirming that the structural benefit comes from combining complementary feature sources rather than merely re-parameterizing a single feature.

## Relation to Prior Work

This paper transplants the functional map framework from 3D shape correspondence (Ovsjanikov et al. 2012) into the 2D image domain, repurposing pre-trained vision model features (DINOv2, Stable Diffusion) as both the geometric structure (graph Laplacian eigenbasis) and the descriptor regularizer. It directly incorporates the attention-based feature refinement module from Deep Partial Functional Maps (Attaiki et al. 2021) to handle occlusions, and adopts the cycle-consistency latent-basis formulation from Wang et al. (2013) for bijectivity. Conceptually, it departs from the dominant 'nearest-neighbor on feature grids' paradigm for emergent correspondence (Amir et al., Zhang et al.) by lifting the problem into a spectral function space where global coherence is enforced structurally rather than recovered post-hoc.

## Why It Matters / Open Questions

The paper demonstrates that imposing spectral structure on correspondences yields consistently smoother and more accurate zero-shot matches than naive feature concatenation, suggesting that the global geometric knowledge embedded in large vision models is better extracted through structured optimization than point-wise queries. A key practical finding is that using two different feature sets (one for the Laplacian basis, one for the descriptor loss) outperforms using the same set for both, opening a design space for feature pairing. The main limitation is the manifold assumption, which restricts applicability to object-centric images rather than complex multi-object scenes; the authors suggest segmentation-based decomposition or quotient-space matching as potential remedies. Whether this spectral-optimization approach can be made fast enough for real-time use or integrated into end-to-end training pipelines remains open.

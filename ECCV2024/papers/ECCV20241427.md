## Problem

State-of-the-art event camera processing converts sparse, asynchronous event streams into dense frame-like representations, discarding the inherent sparsity and asynchrony of events and incurring high latency and computational cost. Existing asynchronous methods either lack hierarchical feature learning, require a fixed-length sliding window of past events, or are restricted to high-level classification tasks. This paper addresses the gap by proposing a deep, fully asynchronous architecture that processes events directly while maintaining sparsity throughout all layers.

## Input / Output

The network consumes a raw stream of asynchronous events, each encoding pixel coordinates (x, y), a timestamp, and polarity (±1). At the input layer, each event is represented by its polarity and the normalized inter-event delay at the same spatial site (clamped to a 100 ms maximum). The network produces an asynchronous stream of output features that can be interpreted as class labels (recognition/gesture tasks) or bounding boxes over a 5×4 grid (detection), with predictions continuously updated as new events arrive—no fixed-length history or frame boundary is required.

## Method

FARSE-CNN is built from FARSE-Convolution layers, which form a 2D grid of LSTM-based recurrent cells that are activated sparsely only when an event falls in their receptive field; each cell uses position-specific input weight matrices to express spatial kernels within the input-to-state transition. To prevent the input densification problem of regular convolutions, a Submanifold variant restricts output propagation to only the cell whose site is active, guaranteeing that the number of output events equals the number of input events. A novel Temporal Dropout module compresses the stream along the temporal axis by propagating only the last event in every window of l events, enabling hierarchical temporal learning (HRNN) without a fixed time window. Sparse max/average pooling handles spatial downsampling, and layers are chained so each layer's output event stream feeds the next, forming a fully asynchronous, multi-layered network whose per-event FLOPs are theoretically bounded and independent of event density.

## Results

On N-Cars, FARSE-CNN (TD window 2) achieves 94.9% accuracy at 2.06 MFLOP/ev, outperforming all asynchronous baselines. On N-Caltech101, it reaches 68.7% accuracy (TD window 4) at 0.34 MFLOP/ev, trading ~6% accuracy for a 4× complexity reduction over the window-2 setting. On Gen1 Automotive object detection, FARSE-CNN achieves 28.8% mAP (30.0% with NMS) at 0.137 MFLOP/ev, surpassing the previous best (AEGNN, 16.3% mAP) by 13.7 percentage points while using ~38× fewer operations. On DVS128 Gesture, FARSE-CNN reaches 96.6% accuracy at 1.9 MFLOP/ev, approaching the synchronous TBR+I3D (99.6%) at a fraction of the cost.

## Baselines & Comparisons

On N-Cars, FARSE-CNN (TD=2) achieves the best accuracy (94.9%) among all asynchronous methods, narrowly beating AEGNN (94.5%), AsyNet (94.4%), and EventFormer (94.3%), while using 2.06 MFLOP/ev versus 0.47 for AEGNN and 21.5 for AsyNet. On N-Caltech101, EventFormer (84.8%) and EVS-S (76.1%) outperform FARSE-CNN's best (68.7% at TD=4), but FARSE-CNN achieves a far better accuracy–complexity tradeoff, with TD=6 reaching 67.8% at only 0.19 MFLOP/ev. For object detection on Gen1 Automotive, FARSE-CNN decisively outperforms all baselines: 28.8% mAP vs. AEGNN (16.3%), AsyNet (12.9%), and NVS-S (8.6%), at 0.137 MFLOP/ev—roughly 38× cheaper than AEGNN. On DVS128 Gesture, FARSE-CNN (96.6%) trails the synchronous TBR+I3D (99.6%) and VMV-GCN (97.5%) by 3 and 0.9 points respectively, but at 1.9 MFLOP/ev versus 38,820 and 330 for those methods. Overall, FARSE-CNN is the only method whose computational cost does not increase when moving from the sparser N-Cars to the denser N-Caltech101 dataset, a property the authors attribute to its event-driven sparsity.

## Relation to Prior Work

FARSE-CNN extends the Matrix-LSTM line of work (Cannici et al., ECCV 2020), which first placed LSTM cells on a 2D spatial grid for asynchronous event processing, by making the architecture multi-layered and hierarchical. It borrows the Submanifold Sparse Convolution principle (Graham et al., CVPR 2018) to prevent the input densification problem that plagues regular convolutions on sparse data, and introduces a Temporal Dropout module that realizes the first Hierarchical RNN in event-based vision. Unlike prior asynchronous methods (EventNet, AsyNet, AEGNN, EventFormer) that rely on point-cloud processing, sparse convolutions, graph neural networks, or transformer-based associative memory, FARSE-CNN unifies convolutional and recurrent mechanisms in a single cell, naturally inheriting both spatial locality and temporal memory without requiring a fixed-length event history.

## Why It Matters / Open Questions

The paper provides a theoretically grounded, sparsity-preserving architecture that can be applied to both classification and dense prediction (object detection) tasks, which prior asynchronous methods like EventFormer could not easily handle. The derived FLOPs/ev bounds and the observation that computational cost is independent of event density (unlike graph-based or sequence-based methods) offer a principled way to compare asynchronous approaches. Open questions include whether the fixed-window Temporal Dropout can be replaced by a learned temporal hierarchy (e.g., Multiscale HRNN), whether GRU or SNN-inspired cells could further reduce cost, and how the architecture performs under hardware-optimized pipelined inference, where current GPU latency for single-event processing is actually worse than CPU.

## Problem

Merging multiple fine-tuned models from the same foundation model into a single multi-task model is hindered by two compounding issues: existing methods like Task Arithmetic require per-task hyperparameter tuning via validation sets (impractical at scale), and noise accumulates as more tasks are added, degrading performance. The growing pool of publicly available fine-tuned models sharing the same architecture remains largely untapped because no existing merging approach scales cleanly to dozens or hundreds of tasks without re-tuning.

## Input / Output

The method consumes the weight tensors of a pre-trained foundation model (e.g., CLIP ViT-B-32/B-16/L-14 or T5-base) and the weight tensors of N fine-tuned variants of that same model, one per task. No training data, validation sets, or gradient computations are required at merge time. The output is a single set of model weights that can be loaded into the same architecture and evaluated on all N tasks simultaneously, reducing N separate model deployments to one.

## Method

Model Breadcrumbs computes a task vector for each fine-tuned model by subtracting the foundation model weights (θ_t^d = θ_t' − θ), then applies a layer-wise sparse mask that zeroes out both the bottom β% of weights by absolute magnitude (negligible perturbations) and the top (100−γ)% (large outliers) within each layer independently. The masked task vectors are summed and scaled by a strength parameter α before being added back to the foundation weights: θ* = θ + α Σ m_t^{β,γ} · θ_t^d. Unlike Task Arithmetic (no masking) or TIES (global masking of small weights only), the dual-tail, per-layer masking removes interference from both noise and extreme deviations while preserving the informative middle of the weight-difference distribution. A key empirical finding is that the hyperparameters (α, β, γ) tuned on 1–3 tasks generalize stably to 8, 200, or more tasks without re-tuning, whereas Task Arithmetic's hyperparameters degrade as task count grows.

## Results

On the 8-task vision benchmark (Cars, DTD, EuroSAT, GTSRB, MNIST, RESISC45, SUN397, SVHN) using ViT-B-32, Model Breadcrumbs (90% sparsity) achieves 83.35% average normalized accuracy, outperforming Task Arithmetic (77.66%) by 5.7 percentage points. With the larger ViT-L-14 model, Breadcrumbs reaches 91.48% of individual fine-tuned model performance across all 8 tasks. In the NLP target-task improvement experiment (T5-base on GLUE), merging Breadcrumbs from six auxiliary tasks boosts fine-tuned accuracy on all four target tasks, e.g., MRPC from 87.9 to 90.0 and CoLA from 51.6 to 53.2.

## Baselines & Comparisons

Model Breadcrumbs consistently outperforms Task Arithmetic [21] across all experimental settings: by 5.7 points on the 8-task ViT-B-32 benchmark (83.35 vs 77.66), by a growing margin in the 200-task ImageNet sequence, and in the validation-free setting where Task Arithmetic's performance can rapidly collapse while Breadcrumbs hyperparameters remain stable. Against Fisher Merging [36], Breadcrumbs achieves an 8.24-point advantage (83.35 vs 75.11) while requiring far fewer computational resources, since Fisher Merging needs to compute the Fisher information matrix whose cost scales with the number of merged models. In the NLP target-task improvement experiment (Table 2), Breadcrumbs also surpasses Task Arithmetic on all four GLUE tasks (e.g., MRPC 90.0 vs 88.6, CoLA 53.2 vs 52.1), confirming the advantage extends beyond vision. The ablation study further shows that both top-weight and bottom-weight masking are necessary, as either alone underperforms the full Breadcrumbs approach.

## Relation to Prior Work

This paper extends the task vector framework introduced by Task Arithmetic (Ilharco et al., 2022), which computes weight differences between fine-tuned and pre-trained models and aggregates them with a scaling factor. The key departure is the introduction of layer-wise sparse masking that removes both large-magnitude outliers and small-magnitude perturbations from each task vector before aggregation, addressing noise accumulation that degrades Task Arithmetic as task count grows. It also differentiates from TIES-merging (Yadav et al., 2023), which applies global masking only to small-magnitude weights, by masking both tails per layer, and from Fisher Merging (Matena & Raffel, 2022), which requires computationally expensive Fisher information matrix estimation that does not scale to many tasks.

## Why It Matters / Open Questions

The practical significance lies in hyperparameter stability: Model Breadcrumbs' α, β, γ tuned on 1–3 tasks generalize to 8 tasks and even a 200-task ImageNet sequence without re-tuning, removing the per-task validation set requirement that makes Task Arithmetic impractical at scale. This positions the method as a lightweight, community-friendly tool for the 'updatable ML' paradigm where many independently fine-tuned models can be merged without access to original training data. Open questions include whether the approach degrades when fine-tuned models are of poor quality (overfitting, domain shift), whether model capacity must grow with task count to sustain performance, and whether the masking strategy transfers to architectures beyond ViT and T5.

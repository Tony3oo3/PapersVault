## Problem

Existing visual prompting techniques for LVLMs (e.g., FGVP, Set-of-Mark) generate fixed annotations on an image regardless of the text query, producing the same prompted image for every question. This query-agnostic design causes a mismatch between the highlighted regions and what the specific question actually requires, limiting the model's ability to follow instructions accurately on diverse VQA tasks.
![Teaser figure](../imgs/ECCV20240794/cropped_page0_idx1.webp)

## Input / Output

The method takes an RGB image and a free-form text query as input. An auxiliary LVLM (CLIP or LLaVA) first produces a P×P attribution map in token space, which is resized to pixel resolution, smoothed with a mean filter (kernel size k) to soften rectangular patch boundaries, and then applied to the original image as an alpha channel via blending. The resulting annotated image, paired with the original text query, is fed to the inference LVLM to produce a text response. No pixel-level resolution constraints are imposed beyond the patch grid of the auxiliary model's vision encoder.

## Method

API generates a text-query-conditioned attention heatmap and overlays it on the input image, requiring no training. For CLIP-based attribution, the paper decomposes the cls-token similarity score across the vision transformer's residual stream (Eq. 1–5), attributing each patch's contribution to the final image-text similarity, and additionally defines a complementary map from inverted non-cls token similarities that suppresses low-information background patches; the two are fused via a soft-OR operation (Eq. 7). For LLaVA-based attribution, cross-attention weights between generated output tokens and image tokens from a mid-to-late layer are averaged over all heads and output positions (Eq. 8). The resulting P×P map is upsampled to pixel space, smoothed with a mean filter to accommodate irregular object shapes, and blended onto the original image as an alpha channel. The auxiliary model can be the same as or different from the inference model, enabling both self-reflection and cross-model knowledge transfer in the pixel space.

## Results

API (using LLaVA as auxiliary model) consistently achieves the best performance across all four inference models (LLaVA, CogVLM, GPT-4V, Gemini) and all six VQA benchmarks. Average improvements over the no-prompt baseline are 1.94% (LLaVA), 1.38% (CogVLM), 1.76% (GPT-4V), and 3.42% (Gemini). The largest single gain is +8.3% on Gemini+VisWiz, while on open-ended benchmarks MM-Vet and LLaVA-Bench the average improvement is 2.20%. For LLaVA specifically, API yields +3.8% on MM-Vet (36.6 vs 32.8) and +2.9% on LLaVA-Bench (74.8 vs 71.9).

## Baselines & Comparisons

API (LLaVA auxiliary) outperforms both FGVP and SoM on every model–dataset pair in Table 1, making it the only visual prompting method that is consistently beneficial. FGVP (Mask) is particularly harmful for CogVLM (VisWiz drops from 53.54 to 28.86) and Gemini (VisWiz drops from 50.28 to 22.82, MME from 78.6 to 29.8), and FGVP (RBM) causes severe degradation on GPT-4V (MME 84.3→65.0, LLaVA-Bench 102.0→59.2) and LLaVA (TextVQA 48.32→39.38). SoM similarly fails to generalize: it drops LLaVA's TextVQA by 14.4 points (48.32→33.91) and LLaVA-Bench by 14.5 points (71.9→57.4), and reduces GPT-4V's LLaVA-Bench from 102.0 to 92.5. The key distinction is that FGVP and SoM produce query-invariant annotations (the same mask regardless of the question), whereas API generates a query-conditioned heatmap, which the authors show is essential for VQA where different questions require attention to different image regions. On the one dataset where a baseline occasionally matches or exceeds the no-prompt baseline (e.g., FGVP Mask on LLaVA-Bench: 73.5 vs 71.9), API still leads (74.1), confirming that query-adaptive prompting is strictly superior to static visual annotations.

## Relation to Prior Work

This paper extends the visual prompting line of work (FGVP, Set-of-Mark) by making the visual annotation query-dependent rather than query-agnostic, using an auxiliary LVLM (CLIP or LLaVA) to generate a text-guided attention heatmap that is simply alpha-blended onto the input image. It draws on CLIP's cls-token decomposition (Gandelsman et al., ICLR 2024) to derive per-patch attribution scores for image-text matching models, and on LLaVA's cross-attention weights for autoregressive generation models. Conceptually, the method also bridges visual prompting with self-reflection: when the auxiliary and inference models are the same, the annotated image encodes the model's own visual attention as a pixel-space 'reflection' medium, contrasting with prior text-based self-reflection in LLMs.

## Why It Matters / Open Questions

The technique is training-free, model-agnostic, and trivially implementable (one heatmap overlay), making it an easy drop-in for any LVLM pipeline; its consistent gains across LLaVA, CogVLM, GPT-4V, and Gemini suggest broad practical utility. However, the method incurs an extra forward pass through an auxiliary model, and the CLIP-based variant underperforms or even degrades results on several benchmarks, limiting its generality. Open questions include whether the auxiliary model can be replaced by the inference model's own intermediate representations without a second pass, whether the approach extends to video or 3D inputs, and whether the modest 1–4% gains compound when stacked with other prompting or fine-tuning strategies.

## Problem

Existing 3D Gaussian segmentation methods rely on time-consuming post-processing to clean noisy outputs and struggle to produce fine-grained segmentations needed for precise scene manipulation. A deeper challenge is that 2D segmentation masks from SAM are generated independently per view, creating cross-view inconsistencies that corrupt 3D feature field training and degrade segmentation accuracy.
![Teaser figure](../imgs/ECCV20240071/cropped_page1_idx0.webp)

## Input / Output

The method consumes a pre-trained 3DGS scene (frozen Gaussian parameters) and SAM automatic masks from all training views, which are organized into coarse (largest segments) and fine (smallest segments) levels per pixel. At inference, a single user point prompt or a reference-view 2D mask triggers segmentation in ~10 ms, producing either extracted 3D Gaussian subsets or 2D masks on arbitrary novel views. The feature representation is a 24-dimensional vector per Gaussian, split into a 12-dim coarse component and a 12-dim fine residual, with the fine-level feature defined as the concatenation of both.

## Method

Click-Gaussian augments each 3D Gaussian with a two-level feature vector trained via cosine-similarity contrastive learning on rendered 2D feature maps against SAM masks, using a granularity prior where the fine-level feature concatenates the coarse component to enforce hierarchical dependency. To resolve cross-view mask inconsistency, the paper introduces Global Feature-guided Learning (GFL): after 2000 iterations, it periodically renders all views, average-pools features per mask ID, clusters the pooled features with HDBSCAN to obtain global feature candidates, and then applies a positive/negative loss that attracts each Gaussian's feature toward its nearest global cluster while repelling it from others. Three regularization terms stabilize training: a hypersphere constraint on 3D feature norms, a rendered-feature norm penalty ensuring contributing Gaussians align directionally, and a spatial consistency loss via KD-tree K-nearest neighbors. The total loss combines contrastive, GFL, and regularization terms with fixed hyperparameters, trained for 3000 iterations in ~13 minutes on an RTX A5000.

## Results

On the LERF-Mask dataset, Click-Gaussian achieves an average mIoU of 85.4% (All), 89.1% (Coarse), and 84.3% (Fine), outperforming the strongest baseline GARField (75.2% All) by 10.2 points. The advantage is most pronounced at the fine level, where Click-Gaussian reaches 84.3% versus 71.4% for GARField and 46.9% for OmniSeg3D. On the SPIn-NeRF dataset, Click-Gaussian achieves 94.0% average mIoU, surpassing single-object methods MVSeg (90.9%) and SA3D (92.4%) as well as the multi-object 3DGS method SAGA (88.0%). The method runs in ~10 ms per click, 15–130× faster than prior approaches.

## Baselines & Comparisons

Click-Gaussian outperforms all seven baselines on both datasets. On LERF-Mask, it leads GARField (the strongest NeRF-based baseline) by 10.2 mIoU points overall and 12.9 points at the fine level, while surpassing Feature3DGS by 22.0 points and OmniSeg3D by 24.5 points. Gau-Group, which relies on a zero-shot tracker assuming sequential video input, lags significantly at the fine level (31.5% vs. 84.3%), confirming the paper's critique of tracking-based identity assignment. On SPIn-NeRF, Click-Gaussian (94.0%) beats both single-object methods MVSeg (90.9%) and SA3D (92.4%) despite segmenting multiple objects simultaneously in one training pass, and exceeds the 3DGS-based SAGA (88.0%) by 6.0 points. Qualitatively, Click-Gaussian produces cleaner 3D Gaussian extractions and runs up to 130× faster than Gau-Group and ~15× faster than SAGA, which requires multiple post-processing steps.

## Relation to Prior Work

Click-Gaussian builds directly on 3D Gaussian Splatting as its scene representation, augmenting pre-trained Gaussians with learnable feature fields rendered through the same differentiable rasterizer. It departs from feature-distillation approaches (DFFs, N3F, Feature3DGS) that transfer 2D foundation-model features into 3D and require SAM's decoder at inference, and from mask-lifting methods (SA3D, NVOS, Gau-Group) that rely on user prompts or object tracking. The key conceptual departure is the two-level granularity prior—concatenating coarse features into fine-level features to exploit the intrinsic dependency between object and part levels—combined with Global Feature-guided Learning (GFL), which uses HDBSCAN clustering of rendered features across all views to produce view-consistent supervision, addressing the cross-view mask inconsistency that plagues prior contrastive-learning-based 3D segmentation (SAGA, OmniSeg3D).

## Why It Matters / Open Questions

The 10 ms per-click inference (15–130× faster than prior methods) and elimination of post-processing make interactive 3D Gaussian editing practically viable for real-time applications like VR and digital content creation. The ablation revealing a 31.3% mIoU drop without GFL validates that cross-view SAM mask inconsistency is a first-order problem in 3D feature-field training, not merely a minor noise source. Open questions include whether the two-level granularity assumption generalizes to scenes requiring more than two semantic scales, and whether the method degrades when a single Gaussian spans multiple semantically distinct objects. The reliance on pre-trained 3DGS also means the approach inherits any reconstruction artifacts from the base representation.

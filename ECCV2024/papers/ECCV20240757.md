## Problem

Window-based voxel transformers for 3D object detection must handle highly variable numbers of voxels per window due to the inherent sparsity of LiDAR point clouds. Existing methods (SST, SWFormer, DSVT) resolve this by sorting and padding voxels into fixed-length sequences, incurring substantial memory and computational overhead that limits inference speed. This paper asks whether attention can be applied directly to variable-length voxel sequences across windows without any grouping or padding.
![Teaser figure](../imgs/ECCV20240757/cropped_page1_idx1.webp)

## Input / Output

The method takes raw LiDAR point clouds, voxelizes them into grids (0.32m×0.32m×0.1875m for Waymo, 0.3m×0.3m×8m for NuScenes), and encodes them via a Voxel Feature Encoding layer. The backbone processes voxels as a single flattened matrix ordered by window coordinates—no padding or fixed-length grouping is required—and outputs dense BEV feature maps from which 3D bounding boxes (center, dimensions, orientation, velocity, class) are predicted. The model runs at 23 FPS on a single GPU, comparable to sparse-convolution-based detectors.

## Method

ScatterFormer's core contribution is the Scattered Linear Attention (SLA) module, which exploits the recurrent form of linear attention (o_t = q_t S_t; S_t = S_{t-1} + k_t^T v_t) to compute attention over variable-length voxel sequences per window within a single flattened sequence, achieving O(N) complexity without padding. A chunk-wise matrix multiplication algorithm, implemented in Triton, loads Q/K/V chunks from HBM into GPU shared memory (SRAM) and accumulates hidden-state matrices per window, reducing SLA latency to under 1 ms. To replace the costly window-shifting permutation used by prior methods, a Cross-Window Interaction (CWI) module applies axis-decomposed depth-wise convolutions (lengthy 1D kernels along height and width, plus a 3×3×3 local kernel) to blend features across adjacent windows. The full backbone stacks six blocks of SLA + CWI + FFN with Conditional Positional Encoding, followed by sparse-convolution downsampling and a cascaded BEV CNN for detection.

## Results

On the Waymo Open Dataset validation set, ScatterFormer achieves 73.8 mAPH (L2) in single-frame mode, surpassing DSVT-1f (72.1) by 1.7 points and HEDNet-1f (73.4) by 0.4 points. With 4-frame temporal fusion, ScatterFormer reaches 76.7 mAPH (L2), outperforming DSVT-4f (75.6) by 1.1 points. On NuScenes, ScatterFormer attains 72.4 NDS and 68.3 mAP, exceeding HEDNet by 1.0 NDS and 1.6 mAP. The model runs at 23 FPS on an A100 GPU, significantly faster than other transformer-based detectors while matching the speed of sparse convolution-based methods.

## Baselines & Comparisons

ScatterFormer (1f) outperforms the direct predecessor DSVT-1f by 1.7 mAPH (L2) on Waymo validation (73.8 vs. 72.1) and also surpasses the strong sparse-convolution baseline HEDNet-1f by 0.4 points (73.8 vs. 73.4). In multi-frame settings, ScatterFormer-4f leads DSVT-4f by 1.1 mAPH (L2) (76.7 vs. 75.6) and exceeds the temporal method MSF-8f by 1.2 points despite using fewer frames. On NuScenes, ScatterFormer achieves 72.4 NDS, beating HEDNet (71.4), DSVT (71.1), and TransFusion-L (70.1) by 1.0, 1.3, and 2.3 NDS respectively, with particularly large gains on small-object categories like Bike (61.5 vs. 58.7 for DSVT) and Construction Vehicle (29.1 vs. 28.9 for HEDNet). On the Waymo test set, ScatterFormer-4f achieves 75.84 mAPH (L2), surpassing HEDNet (73.77) and PillarNext-3f (74.09). In terms of speed, ScatterFormer runs at 23 FPS, substantially faster than DSVT and other transformer-based detectors, while remaining competitive with sparse-convolution methods like CenterPoint.

## Relation to Prior Work

ScatterFormer builds directly on the linear attention framework of Katharopoulos et al. (ICML 2020), which showed that softmax attention can be reformulated as a recurrent state update with a length-invariant hidden state. It departs from the dominant window-based voxel transformer lineage (SST, SWFormer, DSVT, FlatFormer) that handles the variable-length-per-window problem by sorting and padding voxels into fixed-length subsets; instead, ScatterFormer exploits the recurrent form of linear attention to process the entire scene as a single flattened sequence with per-window hidden states, eliminating all padding and permutation overhead. The Cross-Window Interaction module further breaks from the standard window-shifting paradigm by replacing voxel re-indexing with axis-decomposed depth-wise convolutions, drawing on Inception-style multi-branch design.

## Why It Matters / Open Questions

The practical significance is the 23 FPS inference speed at competitive accuracy (73.8 mAP L2 on Waymo, 72.4 NDS on NuScenes), making transformer-based 3D detection viable in latency-constrained autonomous driving pipelines where sparse-convolution baselines have traditionally held the efficiency advantage. The chunk-wise Triton kernel achieving sub-millisecond SLA latency demonstrates that GPU shared-memory-aware scheduling can close the gap between 'elegant but slow' linear attention and production-grade throughput. Key limitations include the reliance on custom operators not yet integrated into TensorRT, limiting in-vehicle deployment, and the observation that larger windows dilute linear attention's focusing power, suggesting a fundamental tension between receptive field and attention selectivity that remains open.

## Problem

While CLIP-like representations capture coarse human poses (standing, sitting), they lack the acuteness to distinguish detailed or uncommon poses. 3D poses have been paired with images or with text in separate works, but seldom with both simultaneously, and existing multi-modal alignment methods either force all modalities into a shared space or convert everything to text, losing modality-specific information. The paper asks whether one can build a single pose embedding that is simultaneously 3D-, visual-, and semantic-aware, computable from any subset of these modalities.
![Teaser figure](../imgs/ECCV20241889/cropped_page1_idx1.webp)

## Input / Output

The model accepts any non-empty subset of three modalities — an RGB image of a person, 3D SMPL joint rotations (22 body joints, globally normalized so hips face a fixed direction), and a fine-grained natural-language pose description — without requiring retraining for different input combinations. The primary output is a single global pose embedding that can be re-projected into any modality space via learned MLP heads; downstream, this embedding drives any-to-any retrieval, conditional text generation (pose instructions), or SMPL parameter regression. A notable design choice is that 3D poses are normalized to remove global rotation, forcing the model to learn world-anchored rather than camera-dependent pose knowledge.

## Method

PoseEmbroider is a transformer that receives frozen uni-modal encoder outputs (a human-tuned ViT for images, a VPoser variant for poses, and a DistilBERT-mounted text transformer), each augmented with a modality-specific learnable token, alongside a learnable global token that aggregates information via self-attention. The key training insight is to avoid aligning all modalities in one shared space (which would collapse the embedding to only common information); instead, the global embedding is re-projected back to each modality space via separate MLP heads, and uni-modal InfoNCE contrastive losses are computed between each re-projection and the corresponding ground-truth modality encoding. Crucially, even when only a subset of modalities is fed as input (e.g., pose alone), the loss is still computed against all three ground-truth modalities, forcing the embedding to be multi-modal *aware* rather than merely multi-modal *informed*. The total objective sums these contrastive terms over all six possible input subsets (three single, three dual), and the entire framework is trained on the synthetic BEDLAM-Script dataset (50k tri-modal samples) with all uni-modal encoders kept frozen.

## Results

On the primary multi-modal retrieval task (BEDLAM-Script validation), PoseEmbroider achieves 74.6% mRecall, outperforming the best Aligner baseline (72.5%) by 2.9% overall and 4.7% on dual-query retrieval. For pose instruction generation, PoseEmbroider improves R@1 by +36% on BEDLAM-Fix (43.1 vs. 31.7) and +41% on PoseFix-OOS (27.4 vs. 19.5) over the Aligner/PoseFix baseline when both inputs are 3D poses. On SMPL regression, PoseEmbroider with image input achieves 49 mm pa-MPJPE on BEDLAM-Script and 53 mm on 3DPW, within 6–12 mm of the SOTA SMPLer-X Huge model (43/41 mm), while using a smaller ViT-base encoder and only 50K synthetic training samples.

## Baselines & Comparisons

The paper's sole explicit baseline is the Aligner model, which serves as a stand-in for the PoseFix [15] pipeline (a standard multi-modal alignment approach with modality-specific MLP projection heads trained with pairwise contrastive losses). PoseEmbroider wins on every retrieval sub-task in Table 1, with the largest gains on dual-query retrieval (+4.7% mRecall) and on pose retrieval from combined image+text input (VT→P: 79.6 vs. 69.2 for text-only, +23.6%). For instruction generation (Table 2), PoseEmbroider consistently outperforms the Aligner across all input configurations, with the most striking margin on 3D-pose-pair queries: R@1 of 43.1 vs. 31.7 on BEDLAM-Fix and 27.4 vs. 19.5 on PoseFix-OOS. On SMPL regression (Table 3), PoseEmbroider with image input (49 mm) slightly beats the Aligner (50 mm) on BEDLAM-Script, and adding a text cue further reduces error to 44 mm without any retraining. The paper does not directly compare against other multi-modal alignment methods (e.g., ImageBind, CLIP) on the same benchmark, so the comparison is limited to the internally constructed Aligner baseline.

## Relation to Prior Work

PoseEmbroider extends the multi-modal alignment paradigm (CLIP, ImageBind) to the human pose domain but deliberately departs from it: rather than projecting all modalities into a shared space (which forces them to encode only common information), it uses a transformer to *combine* available modalities into a single enriched embedding that is an enhancement of its components. It builds directly on PoseScript's text-to-pose retrieval model (providing the frozen text encoder and automatic captioning pipeline) and PoseFix's instruction-generation architecture (TIRG fusion + autoregressive decoder), while contrasting with LLM-based approaches like ChatPose and NExT-GPT that route all modalities through a textual bottleneck. The BEDLAM-Script dataset is a natural extension of BEDLAM with PoseScript-style descriptions, filling a gap where no existing dataset jointly provides images, 3D poses, and fine-grained text.

## Why It Matters / Open Questions

The practical implication is that a single pretrained representation can serve as a drop-in encoder for diverse downstream tasks (retrieval, SMPL regression, instruction generation) and accept any subset of modalities at inference without retraining—enabling, for example, a fitness app to receive raw camera input while the model was trained exclusively on synthetic 3D poses. Key limitations include the small training set (50k synthetic samples vs. CLIP's 400M pairs), the restriction to a single tri-modal dataset, and the exclusion of hands. Open questions include whether the combination objective scales with more data and modalities, whether more aggressive losses (predicting target features rather than matching them) would further close the gap to end-to-end methods, and whether the approach generalizes beyond human pose to other structured 3D representations.

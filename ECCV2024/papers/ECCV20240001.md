## Problem

State-of-the-art approximate unlearning methods depend on a retain set to restore model performance after erasing forget-set knowledge, but in many practical settings the retain set is unavailable due to privacy constraints, dataset scale, or the need to forget an entire class with only its ID. This paper asks whether unlearning can be performed without any retain data while still preserving test accuracy comparable to methods that do use it.
![Teaser figure](../imgs/ECCV20240001/cropped_page3_idx0.webp)

## Input / Output

SCAR consumes a trained DNN (backbone + final FC layer), the forget-set images (or, in self-forget mode, only the class ID to remove), a set of OOD surrogate images (e.g., a 10K random subset of ImageNet-1K, COCO, or even 2K random natural images), and pre-computed per-class feature prototypes (mean vector and normalized covariance matrix) stored during original training. The output is a single unlearned model whose weights have been modified so that forget-set samples are reclassified to the nearest wrong class while retain-set accuracy is preserved. The surrogate images need only contain spatial/semantic structure (Gaussian noise fails), but their pixel distribution must differ from the training data (verified via KS test).

## Method

SCAR combines two synergistic mechanisms in a single training loop. First, a metric-learning loss minimizes the Mahalanobis distance between each forget sample's backbone feature vector and the nearest wrong-class feature distribution (selected via argmin over all other classes), where the covariance matrices are correlation-normalized and shrinkage-regularized to handle the high-dimensional, low-sample regime. Second, a distillation-trick loss computes the Jensen-Shannon divergence between the frozen original model's logits and the unlearning model's logits on OOD surrogate images, exploiting the observation that DNNs cluster OOD features at the same positions as in-distribution features, thereby preserving general classification knowledge without touching the retain set. The total loss is a weighted sum of these two terms, and training stops when forget-set test accuracy drops below a scenario-specific threshold (zero for class removal, test-set accuracy for homogeneous removal). A self-forget variant eliminates even the forget set by using the original model to label OOD surrogate images and partitioning them into surrogate forget/retain subsets based on predicted class membership.

## Results

In the Class-Removal (CR) scenario, SCAR achieves AUS scores of 0.981 (CIFAR-10), 0.935 (CIFAR-100), and 0.940 (TinyImageNet), outperforming all retain-free baselines (e.g., Negative Gradient at 0.871/0.849/0.911 and Random Labels at 0.762/0.774/0.740) while remaining within 1 standard deviation of SCRUB (0.992/0.977/0.986), a method that requires the full retain set. The SCAR Self-Forget variant, which accesses neither the forget set nor the retain set, still achieves AUS of 0.974/0.929/0.917, surpassing all retain-free methods. In the Homogeneous Removal (HR) scenario, SCAR reaches AUS of 0.953/0.934/0.886, again dominating retain-free baselines and approaching DUCK (0.972/0.965/0.916) on CIFAR-100.

## Baselines & Comparisons

SCAR decisively outperforms the two retain-free baselines: Negative Gradient (AUS 0.871/0.849/0.911) and Random Labels (0.762/0.774/0.740) across all three datasets in CR, with gaps of 0.11–0.20 in AUS. Against DUCK (0.969/0.931/0.927), SCAR wins on CIFAR-100 (+0.004) and TinyImageNet (+0.013) but trails slightly on CIFAR-10 (−0.012). SCAR is within 1 standard deviation of SCRUB (0.992/0.977/0.986) on CIFAR-100 and TinyImageNet, despite SCRUB requiring the full retain set for fine-tuning. The upper-bound methods (Retrained, Fine-Tuning) still lead by ~0.01–0.06 in AUS, but these demand extensive retraining on the retain set. Notably, SCAR Self-Forget—operating without any forget or retain data—still surpasses all retain-free methods, achieving AUS 0.974/0.929/0.917. In the harder HR scenario, SCAR (AUS 0.953/0.934/0.886) beats all retain-free baselines and is within 1 std of DUCK on CIFAR-100 (0.965) and TinyImageNet (0.916).

## Relation to Prior Work

SCAR extends the model-agnostic unlearning line that manipulates feature-space representations to induce forgetting (DUCK's centroid shifting, Boundary Unlearning's logit reassignment) by replacing point-based targets with full class distributions via a Mahalanobis distance, incorporating covariance structure for more informed repositioning. Its key departure from prior retain-set-dependent methods (SCRUB, DUCK, Boundary Unlearning) is the 'distillation-trick': leveraging the empirically observed tendency of DNNs to cluster OOD images at the same feature-space locations as in-distribution data, enabling knowledge retention through Jensen-Shannon divergence on a surrogate OOD set rather than the actual retain set. The self-forget variant further extends the class-removal scenario to a setting where neither retain nor forget data is accessible, a constraint no prior approximate unlearning method addresses.

## Why It Matters / Open Questions

The retain set is a practical bottleneck in real-world unlearning: privacy regulations may restrict access to training data, and for large-scale datasets the retain set dominates computational cost. SCAR's retain-free operation and self-forget capability open a path toward unlearning in settings where data access is severely constrained (e.g., right-to-be-forgotten requests where only a class ID is known). However, the method's dependence on a surrogate OOD dataset containing semantic content limits its portability to non-image domains, and the lack of certified unlearning guarantees (only approximate) remains an open question the authors explicitly flag for future work. The distillation-trick's reliance on DNNs' OOD clustering behavior also raises questions about robustness across architectures and training regimes.

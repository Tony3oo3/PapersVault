## Problem

Action quality assessment (AQA) requires domain-specific expertise for annotation, making labeled data scarce and expensive to obtain. While semi-supervised learning has shown promise in other vision tasks, it remains largely unexplored for AQA, and the standard teacher-student pseudo-labeling paradigm does not guarantee high-fidelity pseudo-labels—particularly problematic for AQA where subtle action variations must be captured.
![Teaser figure](../imgs/ECCV20241975/cropped_page1_idx0.webp)

## Input / Output

The method takes video clips as input, with frames resized to 224×224 and segmented into overlapping snippets (e.g., 10 snippets of 16 frames for MTL-AQA, 18 snippets for Rhythmic Gymnastics). The teacher and student networks each consume a single video to predict an absolute quality score, while the reference network consumes a pair of videos (one labeled, one unlabeled) to predict a relative score difference. At inference, only the student network is used to output a continuous quality score per video.

## Method

The paper proposes a three-network teacher-reference-student architecture where the teacher (I3D backbone + MLP-Mixer temporal layers + regression head) predicts absolute pseudo-labels for unlabeled videos, and the reference network (I3D + cross-attention between labeled and unlabeled video features + regression head) predicts relative scores by comparing an unlabeled video against a labeled one. A confidence memory module, inspired by the teacher's memory capability, stores the highest-confidence pseudo-label from each network using a single-variate Gaussian (σ as uncertainty) to gate writes, ensuring only reliable predictions supervise the student. Training proceeds in two stages: a burn-in phase that trains the teacher and reference on labeled data, followed by a joint stage where the student is optimized with both supervised loss (Gaussian NLL on labeled data) and unsupervised loss (Gaussian NLL against the averaged memory pseudo-label), while the teacher is updated via EMA from the student. The final pseudo-label is the average of the teacher's and reference's memory-stored scores, combining absolute and relative supervision to improve fidelity.

## Results

On MTL-AQA, the method achieves Spearman's rank correlation of 0.825 with only 10% labeled data and 0.901 with 40% labeled data, surpassing the best fully supervised baseline CoRe (0.773 / 0.894) and the best semi-supervised baseline S4AQA (0.676 / 0.746) by a large margin. On Rhythmic Gymnastics (40% labels), the method reaches an average Sp.Corr of 0.529, outperforming S4AQA (0.342) and ACTION-NET (0.308). On JIGSAWS (50% labels), the method achieves 0.753 average Sp.Corr, exceeding S4AQA (0.655) and CoRe (0.717).

## Baselines & Comparisons

The method decisively outperforms all 11 baselines across all three datasets. Against fully supervised methods, it beats CoRe [40] by +0.052 (10%) and +0.007 (40%) on MTL-AQA, ACTION-NET [42] by +0.221 on Rhythmic Gymnastics, and CoRe [40] by +0.036 on JIGSAWS. Against the strongest semi-supervised baseline S4AQA [45], gains are +0.149 (10%) and +0.155 (40%) on MTL-AQA, +0.187 on Rhythmic Gymnastics, and +0.098 on JIGSAWS. Weaker semi-supervised baselines (COREG [48], Pseudo-labels [12], VAT [24], S4L [43]) are surpassed by even larger margins (0.19–0.34 Sp.Corr). Notably, the method with only 10% labels (0.825) exceeds S4AQA with 40% labels (0.746), demonstrating that the teacher-reference-student architecture extracts substantially more signal from unlabeled data than prior semi-supervised AQA approaches.

## Relation to Prior Work

This paper extends the standard teacher-student semi-supervised framework (Mean Teacher, NoisyStudent) to the action quality assessment task by introducing a third network — a reference network that uses cross-attention to compare an unlabeled video against a labeled reference video and predict a relative score. It also adds a confidence memory mechanism, borrowed conceptually from uncertainty-aware object detection and pose estimation, to store the most reliable pseudo-labels across training iterations. The closest prior work in semi-supervised AQA is S4AQA [45], which uses self-supervised segment feature recovery; this paper departs from that by relying on explicit pseudo-label generation from two complementary networks rather than self-supervised pre-training.

## Why It Matters / Open Questions

AQA labels require domain-specific expertise (e.g., judges for diving or gymnastics), making them expensive and scarce; a method that achieves competitive or superior performance with only 10–40% of labels has direct practical value for sports scoring and surgical skill assessment. The reference-network idea — grounding an unlabeled sample against a known-quality exemplar — is a natural fit for AQA's ordinal scoring structure and could inspire similar designs in other regression-with-limited-labels tasks. Open questions include whether the confidence memory's Gaussian uncertainty model is the right calibration for AQA scores, whether the approach generalizes to tasks without a natural 'reference' video, and how sensitive performance is to the choice of the labeled reference video during training.

## Problem

Existing deep learning image processing methods require separate trained models for each degradation type and level, limiting practical deployment. Even recent all-in-one models (AirNet, PromptIR) handle only a handful of degradations and cannot selectively remove individual distortions from images with multiple corruptions. UniProcessor addresses this by unifying 30 degradation types in a single model with explicit text-based control that enables both holistic restoration and targeted, per-degradation processing.
![Teaser figure](../imgs/ECCV20241788/cropped_page1_idx0.webp)

## Input / Output

The method takes a degraded RGB image (processed as 224×224 patches) along with two text inputs: a subject prompt identifying the degradation (e.g., 'Gaussian noise') and a manipulation prompt specifying the action (e.g., 'remove'). The subject prompt can be auto-generated by an instruction-tuned VQA module (frozen ViT-G EVA-CLIP encoder + Q-Former + Vicuna LLM) or supplied by a user. The output is a restored RGB image of the same spatial resolution, computed as the input plus a predicted residual map from the processor backbone.

## Method

UniProcessor comprises three plug-in components: (1) an instruction-tuned VQA module (CLIP image encoder + Q-Former + frozen LLM, fine-tuned on 70K+ patches across 30 degradation types) that auto-generates the subject prompt; (2) a context control module that uses a BLIP-2-style multimodal encoder to produce a degradation-aware subject prompt embedding, which is then concatenated with the manipulation prompt and passed through a CLIP text encoder to yield a context control embedding; and (3) a 5-level encoder-decoder processor backbone that alternates ConvFormer blocks (local context via ConvNeXt-v2 large-kernel convolutions) and TransFormer blocks (global context via channel attention + global multi-head self-attention with gated convolutional feed-forward networks). The context control embedding is injected at three decoding stages through Context Interaction Modules (CIMs), each performing self-attention on the feature followed by cross-attention with the embedding, enabling text-guided control of the restoration process. This architecture allows the same single model to either restore all degradations at once or selectively remove one specific distortion from a multi-degradation image by changing only the subject prompt.

## Results

On the CBSD68 dataset with 30 heavy-level degradations, UniProcessor outperforms all 8 competing methods on nearly every degradation type in PSNR, SSIM, and LPIPS. Representative gains include +1.4 dB PSNR over PromptIR on lens blur (27.54 vs. 26.16), +4.1 dB on color saturation (31.35 vs. 27.21), and +3.9 dB on mean shift (27.99 vs. 24.11). On the all-in-one restoration benchmark (Table 3), UniProcessor achieves an average of 32.70 PSNR / 0.918 SSIM, surpassing PromptIR (32.06 / 0.913) and AirNet (31.20 / 0.910). In multi-degradation selective removal, UniProcessor achieves up to +12.5 dB PSNR over PromptIR (e.g., 33.9 vs. 21.6 on color saturation + noise when removing only noise).

## Baselines & Comparisons

UniProcessor is compared against 12 baselines spanning single-task and all-in-one restoration. Against the closest all-in-one competitor PromptIR [42], UniProcessor wins on the majority of 30 degradation types in Table 1 (e.g., +1.4 dB on lens/motion blur, +4.1 dB on color saturation, +3.9 dB on mean shift) and on the all-in-one benchmark (32.70 vs. 32.06 avg PSNR), though PromptIR retains a PSNR advantage on mosaic (38.21 vs. 30.62) while UniProcessor wins SSIM and LPIPS there. Against AirNet [28], UniProcessor gains +1.5 dB average PSNR on the all-in-one benchmark and substantially larger margins on individual tasks (e.g., +3.7 dB on deraining). Single-task specialists like DRUNet [70], MPRNet [67], SwinIR [34], Uformer [60], and Restormer [65] are consistently outperformed by 1–5 dB across most degradations, confirming the advantage of the unified text-controlled approach. On the all-in-one benchmark, UniProcessor also surpasses BRDNet [51] (27.80 avg), LPNet [19] (23.64), FDGAN [11] (28.02), and DL [15] (29.98) by 2.8–9.1 dB in average PSNR. In the multi-degradation selective removal setting (Table 2), UniProcessor uniquely enables per-distortion control, achieving up to +12.5 dB over PromptIR's two-step inference when removing a single degradation from a compound-corrupted image.

## Relation to Prior Work

UniProcessor extends the all-in-one blind image restoration line initiated by AirNet (contrastive learning) and PromptIR (learnable prompts) by replacing opaque, black-box prompt vectors with explicit, human-readable text prompts (subject + manipulation) that are encoded via a BLIP-2-style Q-Former and injected through cross-attention. It further builds on InstructBLIP's instruction-tuning paradigm to train a lightweight VQA module that automatically generates the subject prompt, closing the loop between degradation perception and processing. The processor backbone is a hybrid ConvNeXt-v2/Transformer encoder-decoder with a plug-in Context Interaction Module, departing from prior all-in-one methods that rely on parallel task-specific encoders or decoders.

## Why It Matters / Open Questions

The ability to selectively remove one degradation from a multi-degradation image via a text prompt is a genuinely new capability that prior all-in-one restorers (AirNet, PromptIR) cannot offer, opening the door to user-controllable, interpretable image processing pipelines. However, the VQA module adds substantial computational overhead (678 GMACs total vs. 240 GMACs for the processor alone), and the single-degradation gains over PromptIR are often modest (0.2–1 dB on many tasks), suggesting the text-control benefit is most pronounced in multi-degradation scenarios. Open questions include whether the approach scales beyond 30 degradation types, whether the VQA module can be distilled or replaced by a lighter classifier for real-time deployment, and whether the disentangling ability generalizes to unseen degradation combinations at test time.

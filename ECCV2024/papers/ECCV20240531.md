## Problem

Existing generator-based targeted adversarial attacks are trained to attack only known target classes and cannot generalize to unknown classes without retraining the generator. This limits comprehensive vulnerability assessment of DNNs, since a practical attacker may target any class. The paper asks how to design a single generator that can produce targeted adversarial examples for arbitrary target classes, both known and unseen.
![Teaser figure](../imgs/ECCV20240531/cropped_page3_idx1.webp)

## Input / Output

The method takes a clean source image and a target image (not a one-hot label) as inputs, where the target image provides richer visual information than a class index. It outputs a perturbed adversarial example constrained within an L∞ budget of ε=16/255, produced by a single forward pass of the trained UNet generator. The target image can belong to any class in ImageNet-1000, including the 800 classes never seen during training, making the input space effectively unbounded in terms of target identity.

## Method

GAKer employs a UNet-based generator that performs 'latent infection' by injecting target features into the intermediate representations of the source image at every ResBlock. A frozen pretrained feature extractor extracts features from both the source and target images; the target features are processed through a Feature Transform Module (Linear-GELU-Linear) and a Dimension Matching Module (Linear-GELU) before being added to each ResBlock. Training uses a cosine-distance loss in feature space (rather than cross-entropy) to pull the adversarial example's features toward the target's features, plus a weighted perturbation-level cosine term (α=0.5) that also aligns the perturbation δ with the target. This class-agnostic objective, combined with using target images instead of one-hot labels, enables the generator to generalize to unknown classes. The generator is trained on 200 known classes selected via a similarity-greedy algorithm to maximize feature diversity, yet attacks all 800 remaining unknown classes at inference time.

## Results

On ImageNet, GAKer's headline result is its ability to attack unknown classes: with ResNet-50 as surrogate, it achieves a 16.40% average targeted attack success rate on 800 unseen classes, compared to only 0.08% for HGN (a ~14.13% absolute improvement averaged across surrogates). On known classes (200-class setting), GAKer achieves 58.71% average success rate (Res-50 surrogate), outperforming HGN (41.99%) by ~10.5% and ESMA (61.37%) is slightly ahead. In the 10-class fair comparison, GAKer-10 reaches 65.41% average, surpassing TTP-10 (58.51%) by ~4.23%. On defense models (e.g., Inc-v3^adv), GAKer achieves 35.68% on known classes vs. HGN's 29.22%, and still reaches 5.95% on unknown classes where HGN scores near zero.

## Baselines & Comparisons

Against HGN (Yang et al., ECCV 2022), the most direct multi-target generative baseline, GAKer achieves a dramatic ~14.13% absolute improvement on unknown classes (16.40% vs. 0.08% avg with Res-50 surrogate) and ~10.5% on known classes (58.71% vs. 41.99%), confirming that HGN's class-conditional generator cannot generalize to unseen targets. Against ESMA (Gao et al., NeurIPS 2023), GAKer is competitive on known classes (58.71% vs. 61.37% with Res-50 surrogate) but uniquely extends to unknown classes where ESMA has no capability. Against the iterative baseline SU (Wei et al., CVPR 2023), GAKer outperforms on black-box transferability (e.g., 83.36% vs. 83.15% on Res-152, 82.20% vs. 75.60% on VGG-19 with Res-50 surrogate) while requiring only a single forward pass at inference. Against MI-FGSM (Dong et al., CVPR 2018), GAKer substantially outperforms on all black-box models (e.g., 83.36% vs. 16.55% on Res-152). Against TTP (Naseer et al., ICCV 2021) in the fair 10-class comparison, GAKer-10 achieves 65.41% average vs. TTP-10's 58.51% with Res-50 surrogate, a ~4.23% gain, while also being a single unified model rather than 10 separate generators.

## Relation to Prior Work

This paper extends the generator-based targeted adversarial attack line (TTP, MAN, HGN, ESMA) by replacing class-label conditioning with target-image feature injection, enabling attacks on classes never seen during training. The key conceptual departure is the 'latent infection' mechanism: rather than memorizing class-specific features via one-hot labels (which prior multi-target generators like HGN and ESMA rely on), GAKer injects the target's latent representation into a UNet generator and optimizes via cosine similarity in feature space, making the objective class-agnostic. This repurposes the standard feature-extractor-plus-generator architecture from a class-conditional tool into a class-agnostic one, drawing on the observation that 'major components' of an object in feature space are what drive misclassification.

## Why It Matters / Open Questions

The finding that a generator trained on only 200 ImageNet classes can achieve 16–41% targeted attack success on 800 unseen classes (while HGN achieves ~0%) reveals a previously unquantified vulnerability: DNNs are susceptible to targeted attacks on arbitrary classes, not just those an attacker has explicitly prepared for. This has direct security implications, as it means dataset and model confidentiality alone cannot prevent targeted misclassification. The remaining gap between known-class (~96%) and unknown-class (~16–41%) success rates is an open question the authors flag for future work, and the extension to LVLMs (LLaVA, Qwen-VL) suggests the vulnerability may persist in the most widely deployed modern architectures.

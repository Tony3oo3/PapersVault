## Problem

Deploying semantic segmentation models in open-world settings requires reliable evaluation of their ability to detect out-of-distribution objects, but existing anomaly segmentation datasets suffer from unrealistic OOD insertions, strong domain shifts from the training distribution, or prohibitively high setup costs. No prior method simultaneously achieves minimal domain shift, realistic object insertion, dynamic generation of arbitrary anomalies, and low setup cost.
![Teaser figure](../imgs/ECCV20241210/cropped_page1_idx0.webp)

## Input / Output

The POC pipeline takes an RGB image, a text prompt specifying the object to insert (e.g., 'a cat'), and a text prompt specifying the location (e.g., 'the road'). It produces a modified image where the object is realistically inserted with adapted illumination and scale, along with an automatically generated segmentation mask of the inserted object. Inpainting is applied only to a cropped square region around the selected area, and the final composite blends the inpainted region back into the original image via a Gaussian-blurred mask to preserve surrounding scene details.

## Method

POC is a four-stage pipeline combining open-vocabulary segmentation (GSAM, built on SAM + GroundingDINO) with Stable Diffusion inpainting. First, GSAM segments a valid region using the location prompt, within which a sub-region of random size is selected. Second, a square crop around that region is fed to Stable Diffusion's inpainting model conditioned on the object prompt, which adapts object scale and illumination to the scene. Third, GSAM is re-applied to the inpainted crop with the object prompt to obtain the segmentation mask and reject generation failures. Fourth, the inpainted region is blended back into the original image using a Gaussian-convolved mask for smooth transitions while preserving local modifications like shadows. This plug-and-play design requires no 3D models, no manual annotation, and no retraining of any component, enabling dynamic generation of arbitrary OOD objects into any image.

## Results

On anomaly segmentation benchmarks, POC fine-tuning consistently improves over the no-fine-tuning baseline and matches or surpasses standard COCO stitching. For example, RPL with POC coco achieves 95.1 AuPRC on FS Static (vs. 89.6 for COCO, 13.9 without fine-tuning), and RbA with POC coco reaches 95.8 AuPRC on Cityscapes-POC (vs. 92.9 COCO, 77.9 no ft.). On the POC-generated test sets, POC fine-tuning yields the best scores across all three methods, with RbA+POC coco achieving 95.8 AuPRC on CS-POC and 61.1 on ACDC-POC. For learning new classes, Segmenter trained on POC A reaches 92.4 mIoU on Pascal animal classes (vs. 94.8 for the Pascal-trained baseline and 82.0 for T2I Full), demonstrating a small synth2real gap.

## Baselines & Comparisons

Against the standard COCO stitching fine-tuning baseline [6], POC coco matches or exceeds COCO in most settings: RPL+POC coco achieves 95.1 AuPRC on FS Static vs. 89.6 for COCO, and RbA+POC coco reaches 78.9 on FS Lost&Found vs. 70.9. POC alt. (different OOD classes) is also competitive, sometimes surpassing both COCO and POC coco (e.g., M2A+POC alt. gets 95.8 on CS-POC vs. 93.9 for COCO). The one notable exception is SMIYC Anomaly for RPL, where POC coco drops to 68.0 AuPRC vs. 78.3 for COCO, likely due to the strong domain shift in that dataset. Against the T2I baselines derived from Karazija et al. [28], POC clearly wins: Segmenter trained on POC A achieves 92.4 mIoU on Pascal(A) vs. 82.0 (T2I Full) and 76.0 (T2I Crop), and POC CS+A reaches 89.6 on Pascal(CS) vs. 74.3 and 75.4 respectively. Against the open-vocabulary GSAM baseline [17], POC-trained models substantially outperform it on Cityscapes (78.5–82.9 mIoU vs. 42.0), though GSAM remains competitive on Pascal (75.1–76.1 vs. 92.4 for Segmenter+POC A).

## Relation to Prior Work

This paper positions itself as a data-generation pipeline rather than a new anomaly segmentation method, building on Stable Diffusion inpainting and Grounded-SAM (open-vocabulary segmentation) to replace the standard practice of stitching COCO objects into Cityscapes images. It departs from prior OOD dataset construction approaches—stitching/blending, web collection, and full simulation—by leveraging diffusion-based local inpainting guided by open-vocabulary region selection, achieving all four desiderata (minimal domain shift, realism, dynamism, low cost) simultaneously. The pipeline is applied to three existing OOD fine-tuning methods (RPL, M2A, RbA) and also extends to a new-class learning setting, where it is compared against text-to-image baselines from Karazija et al.

## Why It Matters / Open Questions

POC provides a practical, plug-and-play tool for generating realistic OOD data at scale, which is critical for safe deployment of segmentation models in open-world settings. The finding that domain shift (not just OOD difficulty) significantly degrades anomaly detection—evidenced by shifted ID anomaly scores in SMIYC and ACDC—argues for evaluation protocols that control for distribution shift, a point with broader implications for benchmarking. Open questions remain about optimal OOD class selection for fine-tuning and how architectural generalization capacity (e.g., Segmenter vs. DLV3+) mediates the synth2real gap, which the paper identifies but does not fully resolve.

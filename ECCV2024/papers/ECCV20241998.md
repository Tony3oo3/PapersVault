## Problem

Standard federated learning requires edge-device clients to execute backpropagation, which incurs heavy memory and compute overhead on inference-optimized hardware and exposes the model in white-box form, enabling poisoning and inversion attacks. This paper asks how to perform federated learning entirely without backpropagation, replacing gradient computation with forward-only operations that are memory-light and compatible with trusted execution environments.
![Teaser figure](../imgs/ECCV20241998/cropped_page2_idx0.webp)

## Input / Output

Each client receives the global model parameters W_t and a single random seed s_t (4 bytes) from the server, then locally generates K Gaussian perturbations and computes K loss-difference scalars via 2K forward passes on its private dataset. The client uploads only K floating-point numbers (4×K bytes total) rather than a full gradient vector, making the upload size independent of model dimensionality and trivially adjustable to fit bandwidth. The server aggregates these scalars across clients (with zero-sum noise for secure aggregation) and outputs updated global parameters W_{t+1}.

## Method

BAFFLE replaces backpropagation with a zero-order gradient estimator derived from Stein's identity: the server broadcasts a random seed, each client generates K perturbations δ_k ~ N(0, σ²I), computes the loss difference ΔL(W, δ_k; D_c) = L(W+δ_k) − L(W−δ_k) using only forward passes, and uploads the K scalars. The server recovers the perturbations from the same seed and estimates the gradient as (1/K)Σ_k (δ_k / 2σ²) ΔL(W, δ_k), which is unbiased with convergence rate O(√(n/K)). Four practical guidelines improve accuracy without extra computation: a twice-forward-difference scheme (rather than central difference), Hardswish activation (continuously differentiable at zero), exponential moving average on global parameters to dampen white-noise oscillations, and GroupNorm in place of BatchNorm for small local batches. Secure aggregation is adapted to the zero-order setting so the server never sees individual client loss differences, and the entire client-side computation fits within TEE memory constraints (5–10% of backpropagation memory).

## Results

On MNIST with WRN-10-2 (epoch-level, iid, C=10), BAFFLE achieves 95.17% top-1 accuracy with K=500 perturbations, compared to 97.11% for the backpropagation (BP) baseline. On CIFAR-10, BAFFLE reaches 58.63% (WRN-10-2) versus 62.29% for BP, and on CIFAR-100 it reaches 53.15% versus 60.08%. In the more challenging label non-iid setting (C=100, Dirichlet α=0.3), the gap widens to roughly 4–8 percentage points (e.g., 43.42% vs 51.18% on CIFAR-10 with WRN-10-2). On OfficeHome (feature non-iid, MobileNet finetuning), BAFFLE achieves 66.98% top-1 / 88.40% top-5 average accuracy versus 70.12% / 90.04% for BP.

## Baselines & Comparisons

The sole baseline is conventional backpropagation-based federated learning (FedAvg/FedSGD), reproduced with identical hyperparameters. BAFFLE consistently underperforms the BP baseline across all datasets and models: the gap is smallest on MNIST (≈2 pp with WRN-10-2, 95.17% vs 97.11%) and largest on CIFAR-100 (≈7 pp, 53.15% vs 60.08%). Under label non-iid conditions the gap widens further (e.g., 43.42% vs 51.18% on CIFAR-10), reflecting the added difficulty of noisy gradient estimation on heterogeneous data. On OfficeHome with transfer learning, BAFFLE narrows the gap to about 3 pp in top-1 accuracy (66.98% vs 70.12%), suggesting that pretrained features partially compensate for the gradient noise. The paper positions these results as 'suboptimal but acceptable,' emphasizing that BAFFLE achieves competitive accuracy with only 20–40 communication rounds (vs 1,000 for FedZO) and uploads only 4×K bytes per round instead of the full model.

## Relation to Prior Work

BAFFLE extends zero-order optimization (rooted in Stein's identity) into the federated learning setting, where prior zero-order FL methods (DLZO, FedZO) were limited to linear models with softmax regression and ignored deep architectures. It adapts the secure aggregation protocol from Bonawitz et al. to the zero-order context, enabling privacy-preserving loss-difference uploads rather than gradient uploads. The overall FL communication structure follows FedAvg, but the client-side computation is entirely replaced by forward-only inference, positioning BAFFLE at the intersection of zero-order optimization, FL, and TEE-compatible inference.

## Why It Matters / Open Questions

BAFFLE addresses a fundamental deployment bottleneck: edge devices (phones, IoT sensors) are optimized for inference, not backpropagation, and TEEs have ~90MB memory limits that make BP infeasible. By reducing memory to 5–10% of BP-based FL and requiring only scalar uploads, BAFFLE opens a path to FL on hardware that was previously excluded. Key open questions include closing the 3–5% accuracy gap versus exact gradients (likely requiring variance reduction or non-Gaussian sampling), understanding the relationship between the Gaussian smoothing in Stein's identity and differential privacy, and whether the approach scales to very large models where K must grow with parameter count.

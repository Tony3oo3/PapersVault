## Problem

Existing neural field encodings on meshes—whether extrinsic (Fourier features, positional encoding) or intrinsic (Laplace-Beltrami eigenfunctions)—are all frequency-based, requiring large MLPs that store all scene information in network weights and resulting in slow inference. Parametric feature grids have proven highly effective in Euclidean space by decoupling spatial information from decoding, but no equivalent multi-resolution parametric encoding existed for the mesh manifold.

## Input / Output

For texture reconstruction, the method takes five 512×512 posed RGB images with camera intrinsics/extrinsics and a triangle mesh; for BRDF estimation, it uses 20 calibrated views under 96 directional lights from DiLiGenT-MV. The output is a continuous function evaluated at any point on the mesh: per-vertex RGB texture values or 12 spatially-varying Disney BRDF parameters, interpolated via barycentric coordinates within each triangle. Unlike Euclidean methods that consume 3D coordinates, the encoding is driven by the mesh topology and barycentric position, making it fully intrinsic to the surface.

## Method

MeshFeat constructs a multi-resolution feature encoding by applying quadric error metric decimation to the input mesh, yielding four resolutions (100%, 10%, 5%, 1%) with a collapse mapping from each original vertex to its corresponding vertex at every coarser level. At each resolution, a learnable feature vector is stored per vertex; features from all coarser resolutions are 'pulled' to the finest resolution via the collapse mapping and summed, so that each original vertex carries an accumulated multi-scale feature. The encoding at any surface point is a single barycentric interpolation of these accumulated vertex features, which is then decoded by a very small MLP (2 hidden layers, width 32). A mesh-Laplacian-based L1 regularization on the accumulated features prevents artifacts in regions with sparse training supervision. This design decouples spatial information (stored in the feature matrices) from decoding (handled by the tiny MLP), enabling 13× speedup over frequency-encoding baselines while matching their reconstruction quality.

## Results

On texture reconstruction, MeshFeat (d=4) achieves PSNR 32.51 on the human mesh (V=129k) and 34.23 on the cat mesh (V=33k), matching or slightly exceeding INF (32.46 and 34.76) while delivering a 13.49× speedup versus INF's 3.06×. For BRDF estimation on DiLiGenT-MV, MeshFeat reaches PSNR 42.17, nearly identical to INF (42.21) and TF+RFF (42.13), while running 7.58× faster than TF+RFF and 7.0× faster than INF. The method uses only 604k parameters for the human mesh compared to 133,130k for INF, a 220× reduction in model size.

## Baselines & Comparisons

Against INF (Intrinsic Neural Fields, Koestler et al. 2022), MeshFeat matches or slightly exceeds PSNR on the human mesh (32.51 vs 32.46) and is within 0.11 dB on the cat (34.65 vs 34.76), while being 4.4× faster (13.49× vs 3.06× speedup) and using 220× fewer parameters (604k vs 133,130k). Against TF+RFF (Texture Fields with Random Fourier Features), MeshFeat achieves higher PSNR on both objects (32.51 vs 32.10 on human; 34.65 vs 34.33 on cat) with a 6.9× speedup advantage. Against NeuTex, MeshFeat substantially outperforms on PSNR (32.51 vs 27.32 on human; 34.65 vs 31.56 on cat) and is 13.5× faster. For BRDF estimation, all three methods achieve nearly identical PSNR (42.13–42.21), but MeshFeat is 7.58× faster than TF+RFF and 7.0× faster than INF, while using 220× fewer parameters than INF. The consistent pattern is that MeshFeat trades a negligible quality difference (≤0.1 dB PSNR) for a large inference speedup, which is the paper's central contribution.

## Relation to Prior Work

This paper adapts the multi-resolution parametric feature grid paradigm from Euclidean space (as in hash encodings and Instant NGP) to the mesh domain, using quadric error metric mesh simplification to construct the resolution hierarchy. It departs from all prior neural-field-on-mesh methods (Texture Fields, Intrinsic Neural Fields, NeuTex), which rely on frequency-based encodings (Fourier features or Laplace-Beltrami eigenfunctions) that necessitate large MLPs, by instead storing learnable features directly at mesh vertices across multiple resolutions and decoding with a very small network. The mesh Laplacian regularization for unsupervised vertices is a practical addition not present in the Euclidean grid counterparts.

## Why It Matters / Open Questions

The ~13× inference speedup while matching reconstruction quality makes neural texture and BRDF representation on meshes practical for real-time applications like animation and interactive rendering, where the large MLPs of frequency-based methods were a bottleneck. The native compatibility with deforming meshes (features are intrinsic to topology) is a clean advantage over extrinsic methods that require remapping under deformation. Open questions include whether the fixed resolution schedule can be made texture-adaptive, how the approach scales to very high-frequency signals or large scene-level meshes, and whether the parameter overhead of feature matrices becomes prohibitive at extreme resolutions.

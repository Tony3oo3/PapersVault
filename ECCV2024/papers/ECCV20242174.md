## Problem

CLIP-based models exhibit a 'single tag bias' where image-text alignment disproportionately activates only one tag/word while ignoring other image-relevant tags in the caption. Existing remedies either rely on external NLP models that disregard visual information (extracting irrelevant tags or missing non-noun tags) or use globally pooled image embeddings that inherit the same bias, leaving no model-agnostic solution that uses only image-text pairs.
![Teaser figure](../imgs/ECCV20242174/cropped_page1_idx0.webp)

## Input / Output

The method consumes RGB images paired with free-form text captions (no pre-defined label set or mask annotations required) and produces three outputs: a set of image-relevant tags automatically selected from the caption, a pixel-text similarity map (H×W) that activates all relevant tag regions rather than a single one, and binary segmentation masks for both text-level and tag-level evaluation. Tag selection is fully automatic via a score-gap threshold, requiring no external NLP parser or LLM, and the entire pipeline operates on standard CLIP encoder outputs without architectural modifications.

## Method

TTD is a two-stage fine-tuning procedure applied on top of existing CLIP variants (TCL, MaskCLIP) using LoRA. Stage 1 (Pixel-Tag Scoring) replaces the biased global image-tag similarity with a per-pixel maximum: for each tag, the score is the cosine similarity between the tag embedding and its most correlated pixel embedding across the entire H×W feature map, which naturally separates image-relevant tags from irrelevant ones via a large score gap at the boundary. Stage 2 (Text-Tag Self-Distillation) constructs an ideal similarity map as the pixel-wise maximum (union) of min-max-normalized similarity maps of all selected pseudo-tags, then minimizes the L2 distance between this ideal map and the actual image-text similarity map (with stop-gradient on the ideal side). An auxiliary tag loss simultaneously drives non-selected tags' maps toward zero and selected tags' maps toward their normalized versions, reinforcing pixel-tag correlation. The key insight is that individual tag embeddings are free from single tag bias, so their union provides an unbiased training target for the biased full-text embedding.

## Results

On open-vocabulary semantic segmentation, TCL+TTD achieves 33.9% average mIoU across six benchmarks (VOC 61.1, Context 37.4, Object 37.4, Stuff 23.7, City 27.0, ADE 17.0), surpassing the strongest external-model-free baseline SimSeg (57.4 VOC, 26.2 Context) and TagAlign (31.8 avg). MaskCLIP+TTD improves from 19.0% to 27.5% average mIoU (+8.5%). On text-level segmentation, TTD boosts CaptionIoU by +9.2% for MaskCLIP (41.0→50.2) and +5.1% for TCL (60.4→65.5), while reducing false negative rates substantially (MaskCLIP mFNR: 0.411→0.242).

## Baselines & Comparisons

TCL+TTD outperforms TagAlign (the strongest NLP-model-based baseline) on VOC (61.1 vs 53.9), Context (37.4 vs 33.5), and Object (37.4 vs 33.3), but trails slightly on COCO-Stuff (23.7 vs 25.3) and ADE20K (17.0 vs 17.3), which the authors attribute to TagAlign using multiple text inputs per image. Against SimSeg (the best external-model-free baseline), TCL+TTD leads on VOC (61.1 vs 57.4) and Context (37.4 vs 26.2) but SimSeg reports no results on Stuff/City/ADE. TCL+TTD dominates SegCLIP across all six benchmarks (e.g., VOC 61.1 vs 52.6, ADE 17.0 vs 8.8). On tag selection (Table 2), TTD achieves 82.8 F1 and 91.0 accuracy, substantially outperforming NLTK (69.8 F1), Vicuna-33B (60.4 F1), and Qwen-72B (62.1 F1), with the gap driven by higher recall (78.0 vs 70.7–83.7) without sacrificing precision. MaskCLIP+TTD improves average mIoU by +8.5 points over the MaskCLIP baseline, while TCL+TTD gains +3.5 points, confirming TTD's model-agnostic applicability.

## Relation to Prior Work

This paper builds directly on TCL (Cha et al., CVPR 2023) and MaskCLIP (Zhou et al., ECCV 2022), which learn pixel-text alignment from image-text pairs but still exhibit what the authors formally name 'single tag bias'—a disproportionate focus on one tag in image-text similarity. It departs from prior tag-selection approaches (GroupViT, CoCu, TagAlign, OVSegmentor) that rely on external NLP models or LLMs to extract tags from text without considering image content, and from global-image-scoring methods that inherit the same single-tag bias. The key conceptual departure is using the most-correlated pixel per tag (rather than a pooled image embedding) for scoring, combined with a self-distillation loss that aligns the text-level similarity map to the union of individual tag-level maps.

## Why It Matters / Open Questions

By formalizing single tag bias and providing a model-agnostic, annotation-free fine-tuning recipe, TTD offers a practical drop-in improvement for any CLIP-based segmentation or multi-tag classification pipeline. The automatic generation of image-relevant tags and their corresponding masks (without external NLP models or SAM) could streamline open-vocabulary annotation pipelines. Limitations include reliance on a single caption per image (unlike TagAlign's multi-text setting), which leaves a gap on high-class-count benchmarks like ADE20K, and the pixel-level formulation may not scale optimally to very high-resolution or densely packed scenes. An open question is whether segment-level (e.g., SAM-assisted) relationships could further improve alignment without sacrificing the annotation-free property.

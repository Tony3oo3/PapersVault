## Problem

Unsupervised Domain Generalization (UDG) requires learning domain-invariant representations from unlabeled multi-domain data, but existing self-supervised methods like MAE produce entangled features that capture both semantics and domain-specific variations, leading to poor generalization to unseen domains. The core challenge is disentangling domain-invariant semantic attributes from superficial variations (color, texture, style) without access to class labels that would otherwise anchor the semantic content.
![Teaser figure](../imgs/ECCV20241866/cropped_page1_idx0.webp)

## Input / Output

DisMAE takes unlabeled RGB images from multiple source domains (with domain identifiers but no class labels) as input, applying MAE-style random masking to visible patches. The semantic encoder produces a domain-invariant [cls] token representation (s_i^0 ∈ R^{B×H}) used for downstream classification, while the lightweight variation encoder produces a variation token (v_i^0) capturing domain-specific attributes. During inference, only the semantic encoder is deployed; the variation encoder and decoder are discarded. For DG adaptation, a cross-entropy classification loss on the semantic token is simply added to the training objective.

## Method

DisMAE employs an asymmetric dual-branch architecture with a transformer-based semantic encoder (main branch), a lightweight variation encoder, and a single shared transformer decoder, all built on the MAE framework. The disentanglement principle is enforced via an adaptive contrastive loss that pulls the reconstruction using original semantics+variations toward the input while pushing reconstructions using the same semantics paired with different intra-domain variations away. The invariance principle is implemented through a domain classifier whose prediction probability p(x_i ∈ I_{d_i} | s_i^0) is inverted to reweight the contrastive loss (inspired by Inverse Propensity Weighting from causal inference), compelling the semantic encoder to discard domain-identifiable information. The domain classifier is updated periodically (every T_ad epochs) while freezing the backbones, preventing it from collapsing the semantic space. The total UDG objective combines the γ-constrained reconstruction loss with the adaptive contrastive loss, and the entire framework operates without any class label supervision.

## Results

On the primary UDG task (DomainNet, Painting/Real/Sketch → Clipart/Infograph/Quickdraw), DisMAE achieves 15.16%, 20.30%, 29.19%, and 44.86% average accuracy at 1%, 5%, 10%, and 100% label fractions respectively, outperforming the strongest baseline MAE by 1.48%, 3.04%, 4.65%, and 6.11% at each setting. On the supervised DG task, DisMAE reaches 80.38% average accuracy on VLCS and 86.37% on PACS, surpassing the best prior method RIDG by 1.12% and 0.50% respectively. The method consistently leads across all four label-fraction regimes and both DG benchmarks.

## Baselines & Comparisons

DisMAE outperforms all six UDG baselines across every label-fraction setting on DomainNet. The closest competitor, MAE [23], trails by 1.48% at 1% labels and by 6.11% at 100% labels (44.86% vs. 38.75% avg), with the gap widening as more labeled data becomes available. Among contrastive UDG methods, DARLING [60] and MoCo V2 [14] are particularly weak (9.18% and 7.18% at 1%), while BYOL [20] is the strongest contrastive baseline but still lags DisMAE by 4.82% at 1%. CycleMAE [53], the closest generative UDG method, is outperformed by 6.34% at 100% labels. On the supervised DG task, DisMAE beats all eight DG baselines on both VLCS and PACS: on VLCS it surpasses RIDG [10] (79.26%) by 1.12% and ERM [44] (78.78%) by 1.60%; on PACS it exceeds RIDG (85.87%) by 0.50% and VREx [27] (85.16%) by 1.21%. Disentangled DG methods like DDG [58] (77.38% VLCS, 84.69% PACS) and invariant-risk methods like IRM [2] (77.71% VLCS, 83.81% PACS) are consistently outperformed, confirming that the disentanglement-plus-invariance strategy generalizes better than adversarial or variance-based approaches.

## Relation to Prior Work

DisMAE builds directly on the MAE framework (He et al., CVPR 2022), repurposing its masked reconstruction paradigm and ViT encoder-decoder architecture for multi-domain unsupervised pretraining. It departs from prior disentangled DG methods (DADA, DIDN, DIR) that rely on class labels to define semantic attributes, and from prior UDG methods (DiMAE, CycleMAE) that separate domain styles via multiple decoders or cycle-consistent reconstruction. The key conceptual departure is the introduction of an adaptive contrastive loss inspired by inverse propensity weighting from causal inference, which uses a domain classifier's prediction confidence to reweight contrastive pairs, thereby enforcing domain invariance without adversarial training.

## Why It Matters / Open Questions

UDG addresses a practically critical gap—learning generalizable representations from large-scale unlabeled multi-domain data without class labels—and this paper provides the first disentangled generative pretraining approach for this setting, showing consistent gains over both contrastive and generative UDG baselines. The finding that a single-layer decoder outperforms deeper decoders (Table 9) suggests that overfitting in reconstruction can undermine the contrastive signal, a useful practical insight. However, reconstruction fidelity remains tied to the MAE backbone's patch-level limitations, and the authors acknowledge that fine-grained detail reconstruction is a significant open challenge, pointing toward potential integration with diffusion models.

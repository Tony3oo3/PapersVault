## Problem

Existing few-shot instance perception methods are developed in isolation for individual tasks (detection, segmentation, pose estimation, counting), each requiring task-specific architectures, output representations, and loss functions. No unified framework or benchmark exists for jointly handling multiple instance perception tasks under a few-shot setting, leaving the problem of universal few-shot instance perception largely unexplored.
![Teaser figure](../imgs/ECCV20240779/cropped_page1_idx0.webp)

## Input / Output

The model receives a small set of support images (cropped single-object instances) with user-defined point annotations—16 points for bounding boxes, 32 for instance contours, variable semantic keypoints, or a single center point—alongside a full-scene query image. The task type is implicitly encoded in the annotation format rather than explicitly specified, allowing the same model to switch tasks simply by changing the support annotations. Outputs are scattered point coordinates per detected instance, generated as offsets from RPN anchor centers scaled by the proposal box dimensions.

## Method

UniFS reformulates all instance perception tasks into a unified point representation learning paradigm, using a fully shared ResNet-101 backbone, RPN-based proposal generation, and a transformer point decoder (L=2 layers of self-attention over support points followed by cross-attention with query RoI features) to produce task-agnostic point predictions. The key training innovation is Structure-Aware Point Learning (SAPL), which supplements standard L1 point loss by supervising the angles between each point and its n-hop neighbors (N=2) via a sin(θ/2) formulation, capturing higher-order structural relationships and reducing ambiguity that pure point-level losses introduce. Training follows a two-stage transfer-learning protocol: joint multi-task training on base classes with random per-batch task sampling (object counting held out), followed by K-shot fine-tuning on novel classes, enabling both seen-task and unseen-task generalization.

## Results

On the COCO-UniFS benchmark, UniFS achieves 12.7/18.2 AP for detection (K=1/K=5), 8.6/11.5 AP for instance segmentation, 12.2/22.1 AP for pose estimation, and 1.38/1.32 MSE for object counting, all with a single fully shared architecture. On PASCAL-5i, UniFS reaches 47.2/63.6 AP50 (K=1/K=5) on Novel Set #1, outperforming the strongest specialist (DCFS at 46.2/62.9). Notably, UniFS achieves the best counting MSE (1.32) as an *unseen-task* generalization, while all counting baselines were explicitly trained on that task.

## Baselines & Comparisons

UniFS outperforms all task-specific detection baselines on COCO-UniFS: it leads DCFS (8.1→12.7 AP at K=1; 16.4→18.2 at K=5), Mask-DeFRCN (7.5→12.7; 15.4→18.2), and Meta-DETR (15.3→18.2 at K=5) by 2–5 AP. For segmentation, UniFS wins at K=1 (8.6 vs. DCFS 7.2, Mask-DeFRCN 6.7) but trails DCFS at K=5 (11.5 vs. 13.5), the only setting where a specialist beats it. In pose estimation, UniFS surpasses the adapted DCFS-pose by 2.3 AP at K=1 and 1.0 AP at K=5. For object counting, UniFS achieves the lowest MSE (1.32 at K=5) despite being evaluated as an *unseen task*, while baselines like CFOCNet (2.26), MPSR (1.40), and FSDetView (1.42) were explicitly trained on counting. On PASCAL-5i, UniFS edges out DCFS and DeFRCN by 0.4–1.6 AP50 across all three novel splits, confirming consistent gains over the strongest few-shot detectors.

## Relation to Prior Work

UniFS builds on the Faster R-CNN two-stage detection framework (RPN, RoI Align) and borrows the contour point resampling strategy from Deep Snake, but departs fundamentally from prior few-shot instance perception work by eliminating all task-specific heads, losses, and output representations. Where methods like DeFRCN, DCFS, and MTFA each design separate architectures for detection or segmentation, and unified vision models like Painter or UniHCP still rely on task-specific queries or dense/text output spaces, UniFS reformulates every instance perception task as a point prediction problem, enabling a fully shared transformer-decoder architecture. The COCO-UniFS benchmark also departs from prior multi-task benchmarks (Taskonomy, Meta Omnium) by maintaining domain uniformity and targeting instance-level perception rather than dense map prediction.

## Why It Matters / Open Questions

This is the first work to frame universal few-shot instance perception as a single unified problem, and the COCO-UniFS benchmark provides a much-needed common evaluation platform that prior task-specific benchmarks could not offer. The demonstrated unseen-task generalization (counting without explicit training) suggests the point representation paradigm may transfer to genuinely novel task formulations, which is a promising direction for generalist vision models. Key limitations include potential sampling errors in point-based segmentation, the absence of improvements to the image-level classification component, and the restriction to 2D tasks; extending to 3D or sequential inputs remains open.

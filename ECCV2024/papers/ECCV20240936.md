## Problem

Existing lidar-based open-vocabulary detection methods rely solely on object-level (local) features to classify proposals, ignoring scene-level (global) context. This is especially problematic for lidar point clouds, which have lower resolution than RGB images and are susceptible to noise, making local-only classification error-prone (e.g., mistaking a cabinet for a desk). No prior work has explored how global scene understanding can collaboratively refine local detection results in this setting.

## Input / Output

At test time, the method consumes only a raw lidar point cloud (a set of 3D coordinates) and produces 3D bounding boxes with open-vocabulary class labels, a predicted scene type (e.g., bathroom, library), and a free-text scene description. During training, paired RGB images are additionally used solely to generate pseudo-labels via 2D detectors and CLIP verification; no ground-truth 3D annotations are required. The LLM outputs class names and scene descriptions as natural-language text rather than discrete class indices, enabling truly open-vocabulary predictions.

## Method

GLIS employs a dual-branch architecture built on a 3DETR backbone: a local branch extracts per-object features and a global branch extracts a scene-level feature, both projected into a LLaMA (Vicuna-7B) embedding space. At inference, a three-stage chain-of-thought protocol (global QA → local QA → global-local collaborative QA) prompts the LLM to first identify the scene, then classify each proposal, and finally verify whether each predicted class is plausible in that scene, removing or reclassifying implausible objects. Two auxiliary modules improve quality: RPLG generates 3D pseudo-labels by running Detectron2 on paired images and filtering false positives with CLIP image-text similarity scores before 2D-to-3D projection, and BAOL refines object proposals via a modified bipartite matching scheme that handles low-IoU matches and duplicate proposals to produce reliable foreground/background supervision for the confidence head.

## Results

On ScanNetV2, GLIS achieves mAP₂₅¹⁰ᶜˡˢ = 30.94% and mAP₂₅²⁰ᶜˡˢ = 20.83%, outperforming the previous best method CoDA (28.76% and 19.32%) by 2.18 and 1.51 points respectively. On SUN RGB-D, GLIS reaches mAP₂₅²⁰ᶜˡˢ = 21.45% (vs. OV-3DET's 20.46%) while achieving a competitive mAP₂₅¹⁰ᶜˡˢ = 30.83% (vs. OV-3DET's 31.06%). Per-class gains are notable: chair improves by 10.79% on ScanNetV2, stand by 11.09% and sink by 9.05% on SUN RGB-D.

## Baselines & Comparisons

GLIS outperforms all four baselines on ScanNetV2: it beats CoDA (NeurIPS 2024) by +2.18 on mAP₂₅¹⁰ᶜˡˢ and +1.51 on mAP₂₅²⁰ᶜˡˢ, OV-3DET (CVPR 2023) by +6.58 and +2.81, and FM-OV3D by +9.41 on the 10-class metric. On SUN RGB-D, GLIS edges out OV-3DET on the 20-class metric (+0.99) but trails it slightly on the 10-class metric (30.83 vs. 31.06, a −0.23 gap), while still substantially outperforming FM-OV3D (+9.36) and OV-3DETIC (+17.80). The largest per-class wins are on chair (+10.79% over CoDA on ScanNetV2) and stand (+11.09% over OV-3DET on SUN RGB-D), suggesting the global-local collaborative inference is particularly effective for objects whose identity is ambiguous from local geometry alone.

## Relation to Prior Work

This paper departs from the dominant paradigm in lidar-based OVD (OV-3DET, CoDA, FM-OV3D, OpenSight), which relies exclusively on object-level features matched against text embeddings, by introducing a global scene-level branch and an LLM-based chain-of-thought inference step that cross-checks local predictions against scene context. Architecturally, it repurposes 3DETR as the 3D backbone, LLaMA/Vicuna as the reasoning engine, CLIP as a pseudo-label verifier (RPLG), and MiniGPT-v2 for scene-caption supervision, but the novel contribution is the collaborative inference pipeline that fuses these components. The use of LLMs for step-by-step reasoning in a detection pipeline extends the chain-of-thought prompting literature from pure text reasoning to a multi-modal 3D perception setting.

## Why It Matters / Open Questions

The paper demonstrates that scene-level context can correct local misclassifications in 3D OVD (e.g., rejecting a 'desk' in a bathroom), offering a principled way to leverage LLM common sense without requiring additional 3D annotations. However, the performance gains are modest (+2.2 mAP on ScanNetV2 10cls), and the LLM inference step introduces significant latency that may limit real-time deployment. Open questions include whether the LLM refinement generalizes to outdoor/autonomous-driving scenes, whether a lighter-weight scene-conditioned classifier could achieve similar corrections, and how the method scales as point cloud quality improves.

## Problem

Long-horizon embodied tasks like object rearrangement require an agent to concurrently learn low-level control, high-level sequencing, and interdependent behaviors (picking, navigating, placing, opening) from egocentric vision over thousands of steps, making credit assignment extremely difficult. Prior end-to-end RL approaches either require billions of environment steps in simplified simulators or rely on expert demonstrations, while hierarchical skill-based methods suffer from compounding errors between independently trained policies. The paper asks whether a single monolithic policy can learn such tasks from reward alone without pre-trained skills, demonstrations, or explicit curriculum phases.

## Input / Output

The policy consumes a 256×256 egocentric depth (or RGB) image, the robot's proprioceptive state (7DoF arm joint positions, gripper state, and base egomotion), and two 3D coordinates (object start and goal) specified relative to the robot's initial position. The start coordinate is fixed at episode onset and not updated as the object moves. The output is a continuous low-level control action for the 7DoF arm, suction gripper, and mobile base, with a 1,500-step episode budget and success defined as the target object reaching within 15 cm of the goal position.

## Method

AuxDistill trains a single goal-conditioned policy (ResNet-50 encoder + 2-layer LSTM with 512 hidden units) via multi-task PPO, concurrently learning the main rearrangement task and N auxiliary tasks (e.g., pick, place, open fridge, pick from fridge) that are easier instantiations sharing the same observation and action spaces. The key mechanism is a distillation loss: a weighted KL-divergence between the policy's action distribution under the main task identifier T₀ and under each auxiliary task identifier Tᵢ, where the weight wᵢ(sₜ) is an indicator function grounded in the oracle task plan (e.g., w_pick=1 when the agent is not holding the object and it is in an open receptacle). The total loss is the average PPO loss across all tasks plus λ·Σ wᵢ(sₜ)·KL(π^{T₀}‖π^{Tᵢ}), with PopArt used to handle differing return scales across tasks. Because auxiliary tasks are easier, the policy learns them faster, and the distillation loss provides dense per-step supervision that transfers relevant sub-behaviors into the main task policy without requiring a separate curriculum phase or pre-trained skills.

## Results

On the Habitat 2.0 Object Rearrangement benchmark, AuxDistill achieves 52% success on unseen all episodes, 75% on unseen easy episodes, and 41% on unseen hard episodes, outperforming all baselines. This represents a 2.3× improvement over the previous state-of-the-art (Skill Transformer: 23% all, 37% easy, 16% hard) and a 2.6× improvement on the harder episodes where objects start in closed receptacles. On the Category Pick task, AuxDistill achieves 11% success on unseen episodes versus 9% for the monolithic baseline and 8% for RL Curriculum. Ablations confirm the distillation loss is essential: removing it (λ=0) drops success to 0% on rearrangement.

## Baselines & Comparisons

AuxDistill outperforms all three primary baselines across every evaluation setting. Against M3 (Oracle) [17], a hierarchical method with an oracle task planner, AuxDistill achieves 41% vs. 13% on unseen hard episodes and 75% vs. 58% on unseen easy episodes, demonstrating that a single end-to-end policy avoids the compounding errors of sequencing independently trained skills. Against Galactic [8], which requires over 1 billion simulation steps in a simplified kinematic environment, AuxDistill achieves 75% vs. 26% on unseen easy episodes using fewer than half the training interactions (475M vs. >1B steps) in the full dynamic Habitat simulation. Against Skill Transformer [22], which uses pre-trained skills and expert demonstrations via imitation learning, AuxDistill achieves 75% vs. 37% on unseen easy and 41% vs. 16% on unseen hard episodes, showing that online end-to-end RL with distillation surpasses offline demonstration-based approaches. Notably, Monolithic RL and RL Curriculum both achieve 0% success, confirming that neither direct end-to-end RL nor staged curriculum learning can solve the rearrangement task without the concurrent distillation mechanism.

## Relation to Prior Work

AuxDistill departs from the dominant hierarchical RL paradigm (M3, Option-Critic) that trains skills in isolation and sequences them with a planner, instead learning a single monolithic policy that avoids compounding errors between independently trained skills. It also diverges from curriculum learning approaches that enforce sequential phases of increasing difficulty, by learning all tasks concurrently within a single training loop. The key conceptual novelty is the weighted KL-divergence distillation loss that transfers behaviors from easier auxiliary tasks to the main task, grounded in an oracle task plan's relevance signal. This repurposes the knowledge distillation idea from supervised learning into the multi-task RL setting, where the 'teacher' is the same policy conditioned on a different task identifier rather than a separate pre-trained model.

## Why It Matters / Open Questions

AuxDistill demonstrates that end-to-end RL from reward alone can solve long-horizon embodied rearrangement without pre-trained skills, expert demonstrations, or explicit curricula, achieving 2.3× the success rate of the prior SOTA (Skill Transformer). The critical ablation showing 0% success without the distillation loss (and also 0% for a two-stage curriculum baseline) highlights that concurrent learning with a relevance-weighted distillation signal is not merely helpful but necessary for this class of tasks. A key limitation is the manual design of auxiliary tasks and their relevance functions, though these can leverage privileged simulator state. Open questions include whether auxiliary tasks can be discovered automatically, whether the approach generalizes to tasks without a clear oracle task plan, and whether the method scales to even longer horizons or more diverse manipulation settings.

## Problem

Existing event-image stereo methods struggle to effectively capture and represent scene edge information: event data exhibits motion-dependent edge patterns (missing edges for distant objects, noisy edges for nearby ones), and image edge cues are attenuated during high-level feature extraction. No prior work has explicitly incorporated edge cues as supplementary guidance for event-based disparity estimation.
![Teaser figure](../imgs/ECCV20241950/cropped_page3_idx0.webp)

## Input / Output

The method consumes a rectified stereo image pair and corresponding event streams (left and right views), with events encoded into spatio-temporal voxel grids (B=5 temporal bins, K=3 selections) and all inputs padded to 352×288. Beyond the standard event+image inputs, the network additionally takes edge maps extracted from the images via a jointly trained TEED detector, which serve as guidance signals throughout fusion and disparity update. The output is a dense disparity map giving per-pixel horizontal displacement, iteratively refined over 12 ConvGRU update steps.

## Method

Built on the RAFT-Stereo architecture, the method introduces two edge-guided modules. The Edge-Guided Event-Image Fusion (EGEIF) module first modulates event features with the edge map via a SPADE variant (replacing BatchNorm with LayerNorm) to enhance edge information, then fuses the modulated event features with image features through cross-modal attention. The Edge-Guided Motion Augmentation (EGMA) update module embeds low-level edge maps into high-level context features via Hadamard-product gating, then uses soft spatial-channel attention to select important motion features and augments them under the guidance of the edge-embedded context before feeding into a separable ConvGRU for disparity refinement. Training uses an exponentially weighted L1 loss (γ=0.9) over 12 iterations on the MVSEC dataset with AdamW and a one-cycle LR schedule.

## Results

On the MVSEC dataset, the proposed method achieves a mean disparity error of 0.35 px (Split 1) and 0.38 px (Split 3), outperforming the best event-image baseline SCS-Net (0.38/0.39 px). The one-pixel accuracy reaches 95.1% (Split 1) and 93.4% (Split 3), while the mean depth error drops to 9.7 cm and 11.1 cm respectively, compared to 11.4 cm and 13.5 cm for SCS-Net. The median depth error is 3.9 cm (Split 1) and 4.7 cm (Split 3), the lowest among all compared methods.

## Baselines & Comparisons

The proposed method outperforms all seven baselines on mean disparity error and mean depth error across both splits. Against the strongest event-image baseline SCS-Net [7], it reduces disparity error from 0.38/0.39 px to 0.35/0.38 px and MDE from 11.4/13.5 cm to 9.7/11.1 cm. On one-pixel accuracy, the method achieves 95.1% on Split 1 (beating SCS-Net's 94.7%) but trails SCS-Net on Split 3 (93.4% vs. 94.0%). Compared to the best event-only method TCF-Net [9], the improvement is more pronounced: disparity error drops from 0.38/0.54 px to 0.35/0.38 px, and median depth error improves from 4.8/7.6 cm to 3.9/4.7 cm. Against SMC-Net [6], the method wins on disparity error (0.35 vs. 0.37 on S1) and median depth error (3.9 vs. 4.5 cm on S1), while SMC-Net retains a slight edge on Split 3 disparity error (0.52 vs. 0.38 — actually the proposed method wins here too). Overall, the edge-guided strategy consistently improves depth accuracy, with the largest gains in median depth error (up to 2.9 cm lower than SMC-Net on Split 3).

## Relation to Prior Work

This paper builds directly on the RAFT-Stereo iterative refinement architecture and the event-image stereo line of work initiated by EIS, SMC-Net, and SCS-Net, which progressively improved how event and image features are fused for disparity estimation. Its key departure is introducing explicit image edge maps (via TEED) as an additional input that guides both the cross-modal fusion stage (through SPADE modulation and cross-modal attention) and the iterative disparity update stage (through edge-embedded context features modulating motion features via soft spatial-channel attention). The authors frame this as the first use of extra edge cues to guide event-based stereo, motivated by the observation that event edge patterns are inherently motion-dependent and unreliable, while image edge information is attenuated in high-level learned features.

## Why It Matters / Open Questions

The paper addresses a concrete and well-motivated limitation in event-image stereo: the motion-dependent degradation of edge information in event streams, which is a fundamental property of the event generation model. However, the evaluation is confined to a single dataset (MVSEC, Indoor Flying sequences), and the additional edge detection input (TEED) introduces extra computational overhead and a dependency on a pre-trained model that must be jointly fine-tuned. Open questions include whether the edge-guided strategy generalizes to outdoor or higher-resolution event-image stereo benchmarks, whether the benefit persists when the edge detector is replaced by a learned edge branch, and whether the motion augmentation component's gains are architecture-specific to the RAFT-style iterative update.

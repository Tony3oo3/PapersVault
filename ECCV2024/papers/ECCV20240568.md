## Problem

End-to-end multimodal LLMs face prohibitive memory costs and self-attention limitations when processing long-form videos with rich temporal dependencies, while existing multimodal agents lack video-specific memory representations and often rely on complicated pipelines that underperform their end-to-end counterparts. The paper asks how to reconcile multiple foundation models with a unified, structured memory mechanism to enable strong spatial-temporal reasoning over lengthy videos without expensive training.
![Teaser figure](../imgs/ECCV20240568/cropped_page1_idx0.webp)

## Input / Output

The system takes a long-form video (sliced into ~2-second segments) and a free-form text query (question, retrieval prompt, or localization request) as input. Before inference, the video is preprocessed into two structured memories: a temporal memory of per-segment captions and embeddings, and an object memory of tracked/re-identified objects in a SQL database. At inference time, GPT-4 interactively invokes tools and produces a natural-language answer or, for localization tasks, returns top-5 candidate video segments (each ~2 seconds) ranked by relevance to the query.

## Method

VideoAgent's core contribution is a unified memory representation that decomposes a video into a temporal memory (LaViLa captions, ViCLIP video features, and text-embedding-3-large caption embeddings per 2-second segment) and an object memory (RT-DETR + ByteTrack tracking with CLIP/DINOv2 ensemble re-ID, stored in a feature table and a three-field SQL database). A minimal set of four tools—caption retrieval, segment localization (ensemble of ViCLIP video-text and text-embedding-3-large caption-text similarity), visual question answering (Video-LLaVA), and object memory querying (CLIP feature matching followed by LLM-generated SQL)—are centered around this memory. GPT-4, orchestrated via LangChain, decomposes the input query into subtasks, iteratively selects and calls tools, appends results to a history buffer, and aggregates them into a final answer. The entire pipeline is training-free and zero-shot, with the design principle of a minimal-but-sufficient tool set to avoid tool-calling ambiguity and keep inference tractable.

## Results

On EgoSchema (500-question subset), VideoAgent achieves 62.8% accuracy, outperforming the next-best baseline LLoVi (51.8%) by 11 points and closing the gap to Gemini 1.5 Pro (63.2% on the full set vs. VideoAgent's 60.2%). On NExT-QA (600-question subset), VideoAgent reaches 70.8% average accuracy, surpassing SeViLA (64.2%) by 6.6 points and Video-LLaVA (53.5%) by 17.3 points. On WorldQA Multi-Choice QA, VideoAgent scores 39.28, exceeding GPT-4V (32.83) and Video-LLaVA (35.25). On Ego4D NLQ, the Ego4D+ViCLIP variant achieves R1@0.3 of 17.39, outperforming 2D-TAN (5.04) and VSLNet (5.45) but trailing the supervised GroundNLQ (27.20).

## Baselines & Comparisons

VideoAgent decisively outperforms all agent-based baselines: on EgoSchema it beats ViperGPT (15.8 vs. 62.8) by 47 points and LLoVi (51.8) by 11 points; on NExT-QA it surpasses ViperGPT (20.8) by 50 points. Against end-to-end multimodal LLMs, VideoAgent exceeds Video-LLaVA (36.8→62.8 on EgoSchema; 53.5→70.8 on NExT-QA), mPLUG-Owl (33.8→62.8; 43.2→70.8), SeViLA (25.8→62.8; 64.2→70.8), and FrozenBiLM (26.9→60.2 on EgoSchema full set). The only method that outperforms VideoAgent is Gemini 1.5 Pro (63.2 vs. 60.2 on EgoSchema full set), a closed-source model with vastly more compute. On WorldQA, VideoAgent beats GPT-4V on Multi-Choice QA (39.28 vs. 32.83) but trails it on Open-Ended QA (32.53 vs. 35.37), where direct frame access gives GPT-4V an advantage. On Ego4D NLQ, VideoAgent's zero-shot segment localization (R1@0.3 = 17.39 with Ego4D+ViCLIP) surpasses 2D-TAN (5.04) and VSLNet (5.45) but remains below the supervised GroundNLQ (27.20), and also outperforms the LLM-based LifeLongMemory approach (R@0.3 = 15.99) even when restricted to a single candidate.

## Relation to Prior Work

VideoAgent carves out a middle ground between two established paradigms: end-to-end multimodal LLMs (Video-LLaVA, Gemini, InternVideo) that suffer from prohibitive compute and attention limitations on long videos, and multimodal tool-use agents (ViperGPT, LifeLongMemory, DoraemonGPT) that lack video-specific structural design. Its key conceptual departure is the 'unified memory' abstraction — a temporal memory of segment-level captions/features paired with an object memory of tracked, re-identified entities stored in a SQL database — which serves as the backbone that a minimal set of four tools query into. Rather than training a new model or building a complex MCTS-based pipeline, VideoAgent repurposes off-the-shelf components (LaViLa, ViCLIP, RT-DETR+ByteTrack, CLIP+DINOv2, GPT-4) under a structured retrieval-and-reasoning loop, positioning itself as a training-free, memory-augmented alternative to both lines of work.

## Why It Matters / Open Questions

The practical significance is that a training-free, GPT-4-driven agent with a structured memory can approach proprietary model performance (60.2 vs. 63.2 for Gemini 1.5 Pro on EgoSchema) without the massive compute of end-to-end video LLMs, offering a deployable recipe for long-form video understanding. However, the approach's dependence on GPT-4 for planning and SQL generation limits open-source reproducibility, and the Ego4D NLQ results (17.4 R1@0.3) remain well below supervised methods (27.2), suggesting the memory design is strongest for QA-style reasoning rather than precise temporal grounding. Open questions include whether the two-component memory (temporal + object) scales to hours-long videos, whether the re-ID hyperparameters tuned on EgoObjects transfer to other domains, and whether the minimal tool set can be extended to handle spatial reasoning or multi-camera settings without reintroducing the complexity the paper explicitly avoids.

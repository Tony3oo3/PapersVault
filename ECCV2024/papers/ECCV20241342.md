## Problem

Customized text-to-image generation suffers from an inherent fidelity-editability trade-off: fine-tuning a pretrained diffusion model to faithfully capture a new concept simultaneously reduces its ability to follow diverse query prompts. Previous methods can only shift along this trade-off curve by adjusting fine-tuning hyperparameters, and for concepts with weak generative priors (e.g., distributions far from the pretrained domain), reconciling the trade-off becomes infeasible with a single fine-tuned model.

## Input / Output

During fine-tuning, the method takes N reference images of a custom concept along with learnable image-specific context vectors (replacing manual templates) and a shared concept-specific token (V*) plus a class noun embedding. At inference, the user provides a query text prompt containing the concept token and a class noun (e.g., 'A V* cat in Times Square'); the DCI framework additionally constructs an auxiliary prompt by substituting the concept with a chosen auxiliary noun. The output is a single generated image in the latent space of a Stable Diffusion model, with an inference-time scalar λ (typically −2 to 2) controlling the balance between concept fidelity and prompt adherence.

## Method

The paper introduces two complementary components. First, Image-specific Context Optimization (ICO) replaces fixed manual prompt templates with per-image learnable context vectors positioned before and after the concept token, providing adaptive fine-tuning gradients that disentangle image-specific content from the concept and delay overfitting. Second, the Divide-Conquer-Integrate (DCI) framework operates at inference by running two branches of the same fine-tuned U-Net in parallel during the early denoising steps: a concept branch conditioned on the original query prompt and an auxiliary branch conditioned on a prompt where the concept is replaced by an auxiliary noun. A Dual-Branch Integration Module (DBIM) inserted into every cross-attention layer computes spatially varying aggregation masks from the attention maps of branch-specific token sets, then performs a softmax-normalized pixel-wise blend of the two branches' outputs. The scalar λ in the mask computation controls how much concept-irrelevant content from the auxiliary branch is injected, giving users a continuous inference-time knob to trade fidelity against editability per prompt.

## Results

In the user study (576 paired comparisons across 16 subjects), ICO+DCI achieves 89.58% preference over Textual Inversion and 76.04% over DreamBooth in text alignment, and 76.04% and 60.42% respectively in visual alignment. The ICO-only variant already outperforms all baselines (e.g., 84.38% text alignment preference vs. Textual Inversion), and adding DCI further improves both metrics by 4–13 percentage points. Quantitative CLIP-based evaluations (Figure 6) confirm that DCI simultaneously increases both concept fidelity (visual alignment) and prompt adherence (text alignment) relative to the raw fine-tuned model, breaking the fidelity–editability trade-off curve.

## Baselines & Comparisons

The paper compares against four baselines: Textual Inversion [7], DreamBooth [37], Custom Diffusion [19], and ED-LoRA [11]. In the user study, ICO+DCI is preferred over Textual Inversion in 89.58% of text-alignment and 76.04% of visual-alignment comparisons, making it the closest competitor and the one where the gap is smallest. Against DreamBooth, ICO+DCI wins 66.67% (text) and 60.42% (visual), while against Custom Diffusion it wins 63.54% (text) and 68.75% (visual). The ICO-only variant already beats all three baselines on both metrics, confirming that the learnable image-specific contexts improve the fine-tuned model's overall trade-off boundary. ED-LoRA is compared only in the supplementary material without headline numbers in the main text. Qualitatively, the paper notes that baselines either suffer severe concept distortion or overfit to the reference images, particularly for weak-prior contexts, whereas DCI generates satisfactory images from a single fine-tuned model across all query prompts.

## Relation to Prior Work

This paper extends the customized generation lineage established by Textual Inversion, DreamBooth, and Custom Diffusion, which all implant a novel concept into a pretrained diffusion model via fine-tuning but accept the resulting fidelity-editability trade-off as an inherent constraint to be compromised. The ICO strategy repurposes the prompt-tuning paradigm (learnable continuous vectors replacing fixed text) from NLP and vision-language tasks into the customization fine-tuning loop, departing from the manual template prompts (e.g., 'A photo of {}') used in all prior customization work. The DCI framework is a new inference-time mechanism with no direct predecessor: it decouples the two conflicting objectives into parallel branches within the same U-Net and selectively recombines them via attention-derived spatial masks, drawing conceptually from cross-attention control methods like Prompt-to-Prompt but applied to a dual-branch generation setting.

## Why It Matters / Open Questions

The fidelity-editability trade-off has been treated as a fundamental limitation of model customization, forcing practitioners to choose between concept accuracy and prompt adherence; demonstrating that it can be broken at inference time with a single fine-tuned model is practically significant for real-world applications where query prompts vary widely. The controllable injection strength λ provides a user-facing knob that eliminates the need to retrain for different prompt types. However, DCI still fails for counterfactual or extremely rare contexts where the pretrained model has low priors for all candidate auxiliary nouns, and the method adds inference cost (extra denoising steps T_a). Open questions include whether the dual-branch approach generalizes to multi-concept customization, video generation, or conditioning on additional modalities like layout and depth, which the authors identify as future directions.

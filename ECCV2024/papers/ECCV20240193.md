## Problem

Existing point cloud methods struggle to simultaneously capture short-range dependencies among similar features, long-range dependencies across all positions, and fine-grained local geometric structure without relying on external pre-training data. While Transformers have been applied to point clouds, architectures that jointly model both short-range and long-range dependencies alongside explicit local structure fitting have rarely been explored, leaving a gap in directly learning rich shape perception from irregular point clouds.
![Teaser figure](../imgs/ECCV20240193/cropped_page1_idx0.webp)

## Input / Output

The method takes unordered 3D point clouds (2048 points with 3D coordinates) as input and produces either a single class label (classification) or per-point part labels across 50 categories (segmentation). For classification, three GPSFormer stages with feature dimensions 64→128→256 are cascaded, followed by global max-pooling and an MLP head. For segmentation, a five-stage encoder with a U-Net-style decoder using reverse interpolation restores per-point resolution. Local neighborhoods are constructed via spherical queries at multi-scale radii (0.1, 0.2, 0.4) with 8, 16, and 32 points respectively, keeping parameters consistent across stages.

## Method

GPSFormer combines two core modules: a Global Perception Module (GPM) and a Local Structure Fitting Convolution (LSFConv). The GPM first applies Adaptive Deformable Graph Convolution (ADGConv), which learns per-point feature offsets via an MLP to let each point dynamically traverse the feature space and construct semantically meaningful local neighborhoods, then fuses displaced and original features through Residual Cross-Attention, and finally applies Multi-Head Attention to capture long-range dependencies across all positions. The LSFConv, inspired by Taylor series decomposition, splits local structure learning into a low-order convolution (capturing flat regions and overall trends via simple feature aggregation) and a high-order convolution (capturing edges and fine details) that uses a novel affine basis function with learnable sign parameter s and exponent parameter p, where the basis degenerates to standard ABF or RBF at specific settings. Geometric structure is explicitly introduced by computing interaction features (coordinates, relative positions, Euclidean distances) between sampled and neighboring points to generate the convolution weights. The full model uses only 2.36M parameters and 0.7G FLOPS, achieving 95.4% OA on ScanObjectNN PB_T50_RS.

## Results

On the challenging ScanObjectNN (PB_T50_RS) dataset, GPSFormer achieves 93.8% mAcc and 95.4% OA with voting, surpassing the best supervised method DeLA (90.4% OA) by 5.0% and the best pre-training method PointGPT (93.6% OA) by 1.8%, all with only 2.36M parameters and 0.7G FLOPS. On ModelNet40, GPSFormer reaches 94.2% OA, competitive with pre-training methods in a near-saturated regime. On ShapeNetPart segmentation, GPSFormer attains 85.4% class mIoU (best) and 86.8% instance mIoU, and in few-shot settings it achieves 90.1% (5-way 10-shot) on ModelNet40 and 89.3% (5-way 10-shot) on ScanObjectNN.

## Baselines & Comparisons

GPSFormer decisively outperforms all supervised baselines on ScanObjectNN: it exceeds DeLA (90.4% OA) by 5.0%, PointConT (90.3%) by 5.1%, and SPoTr (88.6%) by 6.8%, while using fewer parameters (2.36M vs. 12.6M for PointMLP). Against pre-training methods, GPSFormer surpasses PointGPT (93.6% OA) by 1.8% and ULIP-2+PointNeXt (91.5%) by 3.9%, without requiring any external data or pre-training stage. On ModelNet40, GPSFormer (94.2% OA) is slightly below PointGPT (94.9%) and ReCon (94.7%), but the paper notes this dataset is near saturation with <0.8% gaps among top methods. On ShapeNetPart, GPSFormer ties SPoTr at 85.4% class mIoU but trails by 0.4% in instance mIoU (86.8% vs. 87.2%). In few-shot classification, GPSFormer beats Point-NN (88.8%) by 1.3% on ModelNet40 5-way 10-shot and substantially outperforms PointNeXt trained from scratch (71.7% vs. 55.7%) on ScanObjectNN 5-way 10-shot.

## Relation to Prior Work

GPSFormer extends the hierarchical 'sampling-grouping-aggregation' paradigm established by PointNet++ and the feature-space dynamic graph convolution introduced by DGCNN, but departs from both by decoupling global context modeling from local structure fitting into two distinct modules. Where prior Transformer-based point cloud methods (Point Transformer, PCT) apply self-attention either locally or globally, GPSFormer's Global Perception Module explicitly combines adaptive deformable graph convolution for short-range feature-space dependencies with multi-head attention for long-range dependencies, followed by a Taylor-series-inspired local convolution that treats neighborhood aggregation as polynomial fitting. This dual global-local design with explicit geometric structure encoding represents a conceptual departure from the monolithic attention or convolution blocks used in most prior architectures.

## Why It Matters / Open Questions

The most practically significant finding is that a compact (2.36M parameter, 0.7G FLOPS) purely supervised architecture outperforms data-hungry pre-training methods like PointGPT by 1.8% OA on the challenging ScanObjectNN benchmark, suggesting that architectural inductive bias can substitute for external pre-training data in point cloud understanding. This challenges the current field trajectory toward ever-larger pre-training pipelines and offers a viable lightweight alternative for resource-constrained deployments. Open questions include whether this advantage persists on larger-scale or more diverse datasets, whether the Taylor-series local fitting generalizes to tasks beyond classification and segmentation (e.g., detection, reconstruction), and how the approach scales when point counts increase substantially.

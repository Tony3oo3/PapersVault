## Problem

Existing object-level out-of-distribution (OoD) detection methods rely on ground-truth class labels to fit class-conditional distributions, which contradicts truly open-world scenarios where the class distribution is unknown. The joint task of localising unseen objects and flagging them as anomalous—without any class supervision—remains unexplored, as open-world object detectors lack the classification signal needed to drive energy-based OoD scoring.
![Teaser figure](../imgs/ECCV20241897/cropped_page1_idx0.webp)

## Input / Output

The method accepts single images from diverse modalities (visible RGB, infrared thermal, and X-ray security imagery) at varying resolutions (minimum 384–800 px depending on dataset) and produces class-agnostic bounding boxes (and optionally instance masks) each annotated with a per-object anomaly/uncertainty score. Because the detector is single-class by design, all detections are scored on a unified normal-vs-anomalous axis rather than per-category, and the anomaly threshold is set so that 95% of in-distribution detections are classified as normal.

## Method

OLN-SSOS combines three modules: (1) the Object Localisation Network (OLN) for class-agnostic proposal and box regression; (2) Unsupervised Pseudo Classification (UPC), which K-means clusters RoIAlign-pooled backbone features before each epoch and trains an MLP classifier on the resulting pseudo-labels (DeepCluster-style); and (3) Self-Supervised Outlier Synthesis (SSOS), which fits a class-conditional Gaussian per pseudo-class on the shared-head features, samples virtual outliers from low-likelihood regions, and trains a free-energy-based OoD head via binary cross-entropy. A variant, OLN-FFS, replaces the Gaussian sampling with an invertible normalising flow (Feature Flow Synthesis) that maps features to a standard normal space for outlier generation. The entire pipeline requires no ground-truth class labels—pseudo-classes are learned entirely from the detector's own feature geometry—enabling end-to-end class-agnostic anomaly detection.

## Results

On the BDD100K/COCO OoD benchmark, OLN-FFS achieves AR@100 = 15.9%, substantially outperforming the best baseline SIREN (10.5%) by over 50% relative improvement. On the DBF6 X-ray dataset, OLN-SSOS with masks reaches AR@100 = 58.9% on the OoD test set, a 23.5% absolute improvement over the best baseline (FFS at 35.4%). Most strikingly, on SIXRay10 and LTDImaging, all three baselines (SIREN, VOS, FFS) achieve 0% AR on the OoD test set, while OLN-SSOS/OLN-FFS achieve AR@100 of 35.3–35.6% and 18.2% respectively. On the standard PASCAL-VOC/COCO OoD benchmark, OLN-FFS attains AR@100 = 17.8% without any class supervision, compared to 20.6% for VOS which uses full class labels.

## Baselines & Comparisons

The paper compares against three object-level OoD detectors: SIREN (vMF-based representation shaping), VOS (class-conditional Gaussian outlier sampling), and FFS (normalizing-flow feature synthesis). On the BDD100K/COCO OoD set, OLN-FFS decisively wins with AR@100 = 15.9% versus 10.5% (SIREN), 9.9% (VOS), and 10.3% (FFS), a 52% relative gain over the best baseline. On DBF6, OLN-SSOS with masks achieves AR@100 = 58.9%, surpassing SIREN (35.1%), VOS (32.8%), and FFS (35.4%) by 23.5 percentage points. On SIXRay10 and LTDImaging, all three baselines completely fail (AR ≈ 0%), while OLN-SSOS/OLN-FFS achieve AR@100 of 35.3–35.6% and 18.2% respectively, establishing the first non-zero anomaly detection on these datasets. The one area where the proposed method trails is the VOC/COCO OoD benchmark, where OLN-FFS (17.8%) is about 2.8 points below VOS (20.6%), though this comparison is asymmetric since VOS uses full class labels while OLN-FFS operates without any class supervision. In-distribution detection performance is competitive on VOC (AR@100 = 61.3% vs. 60.9% for FFS) but drops noticeably on BDD (44.1% vs. ~51.5%), reflecting the trade-off of class-agnostic detection.

## Relation to Prior Work

This paper combines three established components—open-world object detection (OLN), unsupervised pseudo-classification (DeepCluster), and virtual outlier synthesis (VOS/FFS)—into a unified class-agnostic pipeline for object-level anomaly detection. The key conceptual departure from prior OoD detectors (SIREN, VOS, FFS) is the removal of class-label dependency: instead of fitting class-conditional Gaussians to ground-truth categories, the method learns pseudo-classes via iterative K-means clustering on backbone features, enabling energy-based OoD detection without any class supervision. This positions the work at the intersection of open-world detection and anomaly detection, addressing a gap the authors identify where OWODs lack the classification signal needed for downstream OoD heads.

## Why It Matters / Open Questions

The practical significance lies in enabling object-level anomaly detection in truly open-world settings (security screening, surveillance, autonomous driving) where the class distribution is unknown and anomalies are rare, removing the need for class labels that prior methods require. A notable limitation is the significant drop in in-distribution detection performance (e.g., LTDImaging AR@100 falls from ~52% to ~18%), and the optimal number of pseudo-classes is dataset-dependent, requiring manual tuning. Open questions include whether pseudo-class count can be determined automatically, how the approach scales to very large open-world vocabularies, and whether the in-distribution/OoD trade-off can be mitigated without sacrificing anomaly recall.

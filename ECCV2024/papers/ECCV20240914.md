## Problem

SAM's SegEvery task requires dense grid-search over 32×32 prompt positions, making it prohibitively slow (2.1 s for SAM-B). Existing lightweight variants (MobileSAM, Edge-SAM, MobileSAM-v2) either inherit this grid-search bottleneck or rely on a separate two-stage detector (e.g., YOLOv8) that cannot be trained end-to-end with the segmentation model, capping both speed and accuracy.
![Teaser figure](../imgs/ECCV20240914/cropped_page1_idx1.webp)

## Input / Output

The model consumes a single RGB image resized to 640×640 (or 1024×1024) and, for SegEvery, internally generates 256 point prompts and corresponding bounding-box prompts via AutoPPN rather than requiring user input or an external detector. For SegAny, a user-supplied point or box prompt is fed to the standard SAM prompt encoder. The output is a set of class-agnostic binary segmentation masks (one per detected object) along with predicted IoU scores, produced entirely within a single forward pass.

## Method

Lite-SAM replaces SAM's ViT encoder with LiteViT, a 1.16 M-parameter CNN-Transformer hybrid built on PoolFormer-S12 that swaps the standard self-attention block for a Multi-Scale Pooling Self-Attention (MSPM) module to capture local features at multiple receptive fields while keeping compute low. The key architectural innovation is AutoPPN, an end-to-end prompt proposal network that simultaneously regresses bounding boxes (Smooth-L1 loss) and point prompts (hard-mining MSE loss with distance-transform-based ground-truth labels) directly from the encoder's feature map, eliminating the 32×32 grid search. AutoPPN further improves recall by using an MSPM stem for large-object detection and by computing separate losses for large, medium, and small target groups. The total training objective combines the PPN regression loss with SAM's original Focal + Dice + IoU mask loss, and the entire pipeline is trained from scratch on 18 % of SA-1B in 4 epochs (50 h on 128 A40 GPUs), yielding a 4.2 M-parameter model that runs SegEvery in 80 ms.

## Results

Lite-SAM achieves a SegEvery inference time of 80 ms with only 4.2M parameters and 12.7G MACs at 640×640 input, representing a 43× speedup over SAM-B (2.1 s, 90M params) and a 1.6× speedup over MobileSAM-v2 (130 ms, 43M params). On COCO zero-shot evaluation, Lite-SAM (r640) attains 74.8% 1-box mIoU, 55.8% 1-point mIoU, and 55.8% AP, while at r1024 it reaches 76.3% 1-box mIoU and 56.9% 1-point mIoU, approaching SAM-H (76.5% / 57.4%). The LiteViT backbone alone has just 1.16M parameters (23% fewer than ShuffleNetV2) yet achieves 55.8% 1-box mAP on COCO, outperforming all other lightweight backbones tested.

## Baselines & Comparisons

Lite-SAM dominates on efficiency: it is 43× faster than SAM-B, 31× faster than MobileSAM, 20× faster than Edge-SAM, and 1.6× faster than MobileSAM-v2 on SegEvery, while using 21×, 2.3×, 2.3×, and 10× fewer parameters respectively. On segmentation quality (COCO mIoU), Lite-SAM (r640) beats MobileSAM (74.8% vs 72.8% 1-box; 55.8% vs 50.5% 1-point) and Edge-SAM (74.8% vs 74.0% 1-box; 55.8% vs 51.9% 1-point), and slightly trails SAM-B on 1-box mIoU (74.8% vs 75.0%) but surpasses it on 1-point mIoU (55.8% vs 52.2%). At r1024, Lite-SAM nearly matches SAM-H on 1-box mIoU (76.3% vs 76.5%) and 1-point mIoU (56.9% vs 57.4%) with 151× fewer parameters. Against EfficientViT-L0-SAM, Lite-SAM is 21× faster and 7.4× smaller but sacrifices 3.9 points of Mask AR@1000 (52.8 vs 56.7). The key trade-off is that Lite-SAM's Mask AR@1000 (52.8) is slightly below SAM-B (55.1) and EfficientViT-L0-SAM (56.7), but it is the only method achieving sub-100 ms SegEvery with under 5M parameters trained entirely from scratch.

## Relation to Prior Work

Lite-SAM retains SAM's prompt encoder and mask decoder while replacing the heavy ViT-H encoder with a 1.16M-parameter CNN-Transformer hybrid (LiteViT) derived from PoolFormer, and replaces the grid-search prompt sampling with an end-to-end AutoPPN module inspired by Objects-as-Points and CornerNet. This departs from prior lightweight SAM efforts (MobileSAM, Edge-SAM, MobileSAM-v2) that either rely on distillation from SAM, use two-stage pipelines with a separate YOLOv8 detector, or still depend on dense positional encoding for SegEvery. The AutoPPN design is explicitly modular and can be grafted onto any SAM-series model, positioning it as a drop-in efficiency upgrade rather than a standalone architecture.

## Why It Matters / Open Questions

By reducing SegEvery inference to 80 ms with only 4.2M parameters (vs. 90M for SAM-B), Lite-SAM makes real-time, class-agnostic segmentation feasible on resource-constrained hardware, a practical gap that prior lightweight SAMs left unaddressed. The AutoPPN module's plug-and-play nature means the speedup is transferable to existing SAM deployments without retraining the full pipeline. Open questions include whether the 18%-of-SA-1B training budget and 640×640 input resolution limit generalization to higher-resolution or out-of-domain scenes, and whether the end-to-end prompt regression can match the recall of exhaustive grid search on highly cluttered or small-object-heavy images.

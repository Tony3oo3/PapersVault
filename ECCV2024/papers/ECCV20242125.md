## Problem

Existing bias evaluation methods for text-to-image models rely on a fixed set of predefined bias axes (gender, ethnicity, skin tone) and aggregate over fixed prompt domains, which can mask prompt-specific biases and fail to capture incidental correlations. There is no general framework that dynamically identifies which biases are relevant to an arbitrary prompt, quantifies them, and provides interpretable concept-level explanations for the detected biases.
![Teaser figure](../imgs/ECCV20242125/cropped_page1_idx0.webp)

## Input / Output

The method takes a single natural-language text prompt and a black-box TTI model (no access to internal parameters required) as input. For each prompt, GPT-3 generates a variable number of bias axes and counterfactual prompts; the TTI model then produces 48 images per prompt. Outputs include per-counterfactual CAS similarity scores, per-axis normalized MAD bias scores, and qualitative Top-K / Axis-aligned Top-K concept lists extracted via MiniGPT-v2 VQA, enabling both quantitative ranking of bias severity and human-readable explanations of which semantic concepts drive each bias.

## Method

TIBET is a modular, training-free pipeline that chains three components: (1) an LLM (GPT-3.5-turbo) uses chain-of-thought prompting to dynamically identify prompt-relevant bias axes and generate counterfactual prompts along each axis; (2) a black-box TTI model (Stable Diffusion 1.5/2.1) generates 48 images for the original and every counterfactual prompt; (3) a VQA-based concept extraction module (MiniGPT-v2) answers bias-aligned questions on each image to build per-set concept frequency histograms, from which the Concept Association Score (CAS) is computed as the histogram Intersection-over-Union between the initial and counterfactual concept distributions. Bias strength along each axis is then quantified by the Mean Absolute Deviation (MAD) of the K counterfactual CAS scores, normalized to [0,1] so axes with different numbers of counterfactuals remain comparable. A secondary CLIP-embedding-based CAS variant is also provided but lacks concept-level explainability. The entire pipeline is prompt-agnostic and model-agnostic, and can be combined with bias-mitigation tools like ITI-GEN by feeding the identified counterfactual image sets as training references.

## Results

In User Study 2, VQA-based CAS achieves 75% Top-1 and 83% Top-2 accuracy in identifying the strongest societal bias, with a Spearman ranking correlation of +0.51 against human bias ratings, substantially outperforming CLIP-based CAS^CLIP (50% Top-1, 58% Top-2, +0.07 correlation) and Bipartite Matching (41% Top-1, 76% Top-2, −0.08 correlation). For gender bias in occupational prompts, Stable Diffusion 1.5 yields an average CAS of 0.56 for male vs. 0.44 for female counterfactuals, while Stable Diffusion 2.1 narrows this gap to 0.52 vs. 0.48. GPT-3's dynamic bias-axis identification achieves 0.90 precision and 0.87 recall for societal biases (vs. 0.54 recall overall), confirming alignment with human-identified biases.

## Baselines & Comparisons

TIBET is compared against three prior TTI bias-evaluation frameworks: T2IAT [50], DALL-Eval [17], and Stable Bias [36]. All three use a predefined set of bias axes (gender, skin tone, culture, location), whereas TIBET dynamically generates prompt-specific axes via GPT-3, enabling evaluation on arbitrary prompts without requiring specific prompt structures. On the shared 11-occupation gender-bias benchmark, TIBET's CAS trends align with T2IAT and DALL-Eval (e.g., 'elementary school teacher' and 'librarian' are female-dominated; 'announcer' and 'chef' are male-dominated), confirming validity while adding concept-level explainability that the baselines lack. In the head-to-head metric comparison (User Study 2), VQA-based CAS clearly outperforms both CLIP embedding similarity (CAS^CLIP) and Bipartite Matching of CLIP text embeddings: 75% vs. 50% Top-1 accuracy and +0.51 vs. +0.07 Spearman correlation, indicating that concept-level VQA decomposition captures bias structure far more faithfully than raw image embeddings. The paper also demonstrates that TIBET's metrics can track bias reduction when combined with ITI-GEN [57], showing a notable decrease in the male–female CAS gap across most occupations post-mitigation.

## Relation to Prior Work

This paper repurposes counterfactual reasoning (as in T2IAT [50]) and VQA-based concept extraction (via MiniGPT-v2) into a unified bias-evaluation framework, but departs from prior work by replacing fixed, predefined bias axes (gender, skin tone, culture) with LLM-dynamically-generated axes that adapt to each input prompt. Unlike T2IAT, DALL-Eval, and Stable Bias, which require specific prompt structures and evaluate only a small set of axes, TIBET operates on arbitrary prompts and simultaneously quantifies both societal biases and incidental correlations. The Concept Association Score (CAS) metric, a histogram IoU over VQA-extracted concept frequencies, is novel relative to the CLIP-embedding or bipartite-matching comparisons used in prior TTI bias work.

## Why It Matters / Open Questions

TIBET enables prompt-specific, interpretable bias auditing that prior aggregate-only methods cannot provide, and its intersectionality analysis (e.g., how gender distribution shifts across cultural counterfactuals) opens a new axis of inquiry for TTI fairness. However, the approach inherits dependencies on GPT-3 for bias-axis identification (0.54 overall recall in user studies) and MiniGPT-v2 for concept extraction (18% error rate), and the 0.51 Spearman correlation with human bias ratings, while positive, leaves substantial room for improvement. Open questions include whether the framework scales to non-person-centric prompts, how robust it is to rapidly evolving TTI models, and whether the LLM-generated bias axes can be made more comprehensive without sacrificing precision.

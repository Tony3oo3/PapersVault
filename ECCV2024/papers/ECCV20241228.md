## Problem

Temporal Action Detection (TAD) and Moment Retrieval (MR) are closely related tasks that identify temporal segments in untrimmed videos, yet existing work treats them as independent problems with separate models. The paper investigates whether fusing both tasks into a single model via task fusion learning can enable mutual benefits—such as MR establishing action co-occurrence/sequencing dependencies for TAD, and TAD providing finer-grained supervision and additional negative samples for MR—rather than merely increasing annotation volume.
![Teaser figure](../imgs/ECCV20241228/cropped_page1_idx0.webp)

## Input / Output

The model consumes pre-extracted video features as a sequence of T snippets (16 frames each, at dataset-specific strides, yielding 1024-D vectors from backbones like VideoMAE, I3D, or InternVideo) alongside text queries: action names formatted as 'a video of [action]' for TAD and free-form natural language descriptions for MR. Both query types are encoded by a frozen CLIP-B text encoder into a shared embedding space. The output is a uniform set of (start, end, confidence) tuples per query, filtered by a classification threshold and Soft-NMS, producing temporal segments and foreground scores regardless of whether the query is a closed-set action or an open-ended event.

## Method

UniMD is an anchor-free, one-stage detector with a purely convolutional vision encoder (seven ConvNeXt blocks with 2× downsampling feeding a 3-level BiFPN) and a frozen CLIP text encoder. The key architectural novelty lies in two query-dependent decoders: a classification head that computes a scaled inner product between convolved visual features and the text embedding (acting as a learned classifier), and a regression head that passes the text embedding through a 3-layer MLP to produce a convolutional kernel, which then performs query-wise convolution to predict start/end offsets—making boundary prediction explicitly category-sensitive. For training, the paper introduces co-training with synchronized task sampling, which prioritizes videos annotated for both TAD and MR so each iteration jointly updates both tasks, combined with a weighted loss (λ_tad=3, λ_mr=1) to balance the two objectives. This co-training strategy, rather than pre-training or random sampling, yields the strongest mutual gains, with the co-trained model outperforming dedicated single-task models even when trained on only 25–50% of the data.

## Results

On Ego4D test, UniMD achieves 23.25% mAP and 44.80% R1@50 for TAD, and 14.16% R1@30 and 10.06% R1@50 for MR, setting new SOTA on both tasks. On Charades-STA, the model with I3D+CLIP features reaches 63.98% R1@50 for MR (a 3.18% improvement over the previous best) and 26.53% mAP for TAD. On ActivityNet, UniMD with InternVideo features attains 39.83% mAP and 60.29% mAP@50 for TAD, and 80.54% R5@50 for MR, all representing state-of-the-art results.

## Baselines & Comparisons

On Ego4D test, UniMD outperforms ActionFormer [59] (the strongest TAD baseline) by 1.49% mAP and 2.26% R1@50, and surpasses InternVideo(VSLNet) [5] by 1.13% R1@30 and 6.63% R5@30 on MR. On Charades-STA, UniMD with I3D+CLIP features achieves 63.98% R1@50 for MR, beating UnLoc-L [53] (60.8%) by 3.18% and QD-DETR [34] (57.31%) by 6.67%; however, for TAD it trails CTRN [7] (27.8% mAP) by 1.27% when using I3D alone, though the gap narrows to 1.27% with I3D+CLIP (26.53%). On ActivityNet, UniMD with InternVideo features edges out InternVideo(AF) [51] by 0.83% mAP and PRN [49] by 0.43% mAP for TAD, and surpasses UnLoc-L [53] by 1.34% R5@50 for MR. The co-training approach is particularly effective under data-limited settings: with only 25% of MR training data, the co-trained model already exceeds the dedicated MR model trained on 100% of data.

## Relation to Prior Work

This paper carves new ground by unifying two previously separate task lines—Temporal Action Detection (TAD) and Moment Retrieval (MR)—into a single 'Moment Detection' formulation, rather than building on a single prior method. Architecturally, it repurposes the anchor-free, one-stage object detection paradigm (FCOS-style) for temporal video, substituting CLIP text embeddings for class-specific weights in both the classification head (as a linear classifier) and the regression head (as a learned convolutional kernel via an MLP transformation). The vision backbone deliberately departs from the Transformer-based approaches common in recent TAD/MR work (ActionFormer, TadTR) in favor of a pure ConvNeXt + BiFPN pipeline, arguing that local convolutional operations suffice for moment-level detection. The task fusion learning component (synchronized vs. alternating co-training) is an empirical contribution with no direct prior counterpart in the video localization literature.

## Why It Matters / Open Questions

The practical significance is twofold: a single deployed model handles both closed-set action detection and open-ended language-grounded retrieval, reducing inference cost, and the co-training protocol demonstrates that the two tasks provide complementary supervision that cannot be replicated by simply pooling annotations. The finding that 25% MR data + 50% TAD data outperforms dedicated models trained on 100% of their data suggests the benefit is structural (cross-task regularization, negative-sample enrichment) rather than merely quantitative, which has implications for training large video-language models on mixed action/event detection. Open questions include whether the mutual benefit persists at larger scale (e.g., Ego4D's full 3,000-hour corpus), whether the CLIP-based query interface generalizes to truly open-vocabulary settings beyond the training categories, and whether the ConvNeXt choice is optimal compared to attention-based encoders for longer temporal contexts.

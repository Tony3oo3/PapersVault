## Problem

Existing sparse-view 3D inference methods critically depend on accurate camera poses to geometrically aggregate information from input views, making them inapplicable in real-world settings where poses are unavailable or inaccurate. Single-view 3D methods avoid this dependency but cannot benefit from additional observed views and must hallucinate unobserved regions. This paper addresses the gap of performing high-fidelity novel-view synthesis and 3D reconstruction from a sparse set of images with no associated pose information.

## Input / Output

The method takes a sparse set of unposed RGB images (1, 3, or 6 views) where the first image serves as an anchor defining the coordinate frame, plus a query view pose specifying the desired output viewpoint. It produces two outputs: high-fidelity novel-view images generated by a conditional diffusion model (UpFusion 2D), and an instance-specific 3D neural representation (Instant-NGP) optimized for 3D consistency (UpFusion 3D). The 3D representation requires per-instance optimization (~1 hour) using score distillation, while the 2D model can generate views directly without per-object fitting.

## Method

UpFusion conditions a pre-trained Stable Diffusion model (adapted via ControlNet) on two complementary feature types extracted by a frozen UpSRT scene-level transformer: (1) view-aligned decoder features c_d, which ground the generation to the query viewpoint and are spatially concatenated with noisy latents, and (2) set-latent encoder features c_s, which preserve per-patch details from input views and are injected via attentional layers to enable direct content 'copying.' This dual conditioning allows the diffusion model to both respect the query geometry and preserve instance-specific details visible in the unposed inputs. For 3D consistency, an Instant-NGP representation is then optimized per instance by minimizing the denoising loss between its renderings and the diffusion model's predictions (an adapted SDS objective), without requiring any input-view rendering loss since poses are unknown. Training is multi-stage: UpSRT is first trained with pixel-level regression, then the diffusion model is trained with frozen UpSRT conditioning, using classifier-free guidance dropout for flexible inference.

## Results

On Co3Dv2 seen categories (41 categories), UpFusion 3D achieves 18.96 PSNR-A, 0.76 SSIM-A, and 0.21 LPIPS-A with 6 unposed input views, outperforming the UpSRT regression baseline (18.36 PSNR-A) and SparseFusion with predicted poses (17.12 PSNR-A). On the out-of-distribution GSO dataset, UpFusion†(3D) with 6 views reaches 22.51 PSNR and 105.79 FID, surpassing the best single-view baseline Zero-1-to-3 (TS) at 21.71 PSNR / 151.33 FID. Performance improves monotonically with additional unposed views (1V→3V→6V) across all metrics, and generalization to 10 unseen categories shows no degradation relative to seen categories.

## Baselines & Comparisons

Against SparseFusion with ground-truth poses (the upper bound), UpFusion 3D trails by ~5 dB PSNR-A at 6 views (18.96 vs. 24.02), reflecting the inherent information loss from bypassing explicit geometry. However, against SparseFusion with predicted poses from RelPose++, UpFusion 3D wins by 1.84 dB PSNR-A at 6 views (18.96 vs. 17.12), showing that pose estimation errors severely degrade pose-dependent methods. UpFusion 3D also outperforms the UpSRT regression backbone by 0.60 dB PSNR-A and 0.10 LPIPS-A at 6 views, confirming the benefit of the diffusion-based generative objective over mean-seeking regression. On GSO, UpFusion†(3D) with 6 views (22.51 PSNR, 105.79 FID) beats both single-view baselines—Zero-1-to-3 TS (21.71 PSNR, 151.33 FID) and One-2-3-45 (17.77 PSNR, 214.22 FID)—demonstrating that additional unposed views provide meaningful signal that single-view methods cannot exploit. Against FORGE, which also uses 6 input views but jointly optimizes poses, UpFusion†(3D) achieves a 5.11 dB PSNR advantage (22.51 vs. 17.40) and a 208-point FID improvement, indicating that explicit pose optimization is fragile compared to implicit context conditioning.

## Relation to Prior Work

UpFusion repurposes the Unposed Scene Representation Transformer (UpSRT) as a feature extractor rather than a regression head, feeding its query-aligned decoder features and set-latent encoder features into a ControlNet-adapted Stable Diffusion model for probabilistic novel-view generation. This departs from prior sparse-view 3D methods (SparseFusion, FORGE) that require accurate camera poses for geometric aggregation, and from UpSRT/RUST which use the same transformer backbone but with a mean-seeking regression objective that produces blurry outputs. The 3D-consistent representation is then recovered via score distillation sampling adapted from SparseFusion, closing the loop between unposed 2D generation and 3D reconstruction.

## Why It Matters / Open Questions

By eliminating the camera-pose requirement, UpFusion makes sparse-view 3D inference applicable to realistic in-the-wild capture settings where poses are unavailable or unreliable, and demonstrates that unposed images can still provide meaningful instance-specific context for generation. However, the authors note that 2D generations are not always precisely consistent with input-view details, performance does not scale as strongly with additional views as pose-aware geometric methods, and the 3D stage requires ~1 hour of per-instance optimization. An open question the authors raise is whether explicit pose inference, even if imperfect, might ultimately complement or replace the implicit aggregation strategy for more robust 3D estimation.

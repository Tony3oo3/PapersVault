## Problem

Prior work leverages NeRF for visual localization only as an auxiliary tool (training augmentation, photometric supervision, or pose refinement) or requires joint training of a customized NeRF with the matching network. This paper asks whether NeRF's internal 3D features, learned purely through view synthesis, can serve as discriminative descriptors for direct 2D-3D matching without any retraining or architectural modification to the NeRF model.
![Teaser figure](../imgs/ECCV20240624/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB query image (resized to 480×480), a pre-trained Mip-NeRF model (~5.28 MB), and a set of reference poses. From the reference pose, 3600 3D surface points are rendered via volumetric rendering along rays at 8×8 patch centers, each carrying a NeRF feature vector (default: layer-3 encoder output, 256-dim). The output is a 6-DoF camera pose (translation in cm, rotation in degrees) computed via a PnP solver from predicted 2D-3D correspondences, optionally refined iteratively or via photometric optimization through the frozen NeRF.

## Method

The key insight is that intermediate 3D encoder features of a standard NeRF (trained only for view synthesis) are already discriminative for matching against 2D image features. Two matching architectures are proposed: NeRFMatch-Mini uses a non-learnable dual-softmax function to align ConvFormer image features (coarse H/8×W/8 resolution) with rendered NeRF features, while NeRFMatch adds a coarse-to-fine attention pipeline with shared-weight self-attention, cross-attention with positional encodings, and a fine-level alignment heatmap for sub-pixel matching. Image features are extracted at two resolutions (coarse 256-dim, fine 128-dim) using the first two ConvFormer blocks initialized with ImageNet weights. Training is supervised with a log loss on coarse matches and a variance-weighted pixel-distance loss on fine matches. Two pose refinement strategies are provided: iterative re-matching with the updated pose (faster, 141 ms/step) and optimization through the frozen NeRF with photometric loss (more effective for large initial errors, 398 ms/step).

## Results

On Cambridge Landmarks (outdoor), NeRFMatch achieves an average median pose error of 13.3 cm / 0.3° with NeRF+RGB retrieval, and 14.6 cm / 0.3° using NeRF-only retrieval, outperforming all APR methods and most SCR baselines. The lightweight NeRFMatch-Mini variant reaches 20.0 cm / 0.4° while running in 37 ms. On 7-Scenes (indoor), NeRFMatch achieves 2.7 cm / 0.7° median error with 78.2% localization recall, on par with the best APR method (NeFeS, 2.4 cm / 0.9°) but trailing SCR and visual-matching methods that approach saturation on this dataset.

## Baselines & Comparisons

On Cambridge Landmarks, NeRFMatch (13.3 cm / 0.3°) outperforms all APR baselines (best: LENS at 33 cm on Kings) and most SCR methods (DSAC* 20.6 cm, ACE 25 cm, DSM 21.2 cm), and is competitive with the strongest hierarchical methods: HLoc (10.8 cm / 0.2°) and NeRFLoc (13 cm / 0.2°). The NeRF-only variant (14.6 cm / 0.3°) shows only a small degradation, demonstrating that NeRF can replace the entire image database. On 7-Scenes, NeRFMatch (2.7 cm / 0.7°, 78.2% recall) is on par with the best APR method NeFeS (2.4 cm / 0.9°) but lags significantly behind SCR methods (DSAC*: 1.1 cm / 0.3°, 97.8% recall) and visual-matching pipelines (DVLAD+R2D2: 0.8 cm / 0.2°, 95.7% recall), which the authors attribute to limited NeRF training frames (900 vs. thousands available) and the near-saturation of those methods on this small indoor dataset. Compared to the closest NeRF-based baselines, NeRFMatch substantially outperforms CrossFire (47/43/20/39 cm on four scenes) and matches or slightly trails NeRFLoc (13 cm avg.), while being the first to use a pre-trained NeRF without joint training with the matching network.

## Relation to Prior Work

This paper positions NeRF as a primary scene representation for visual localization, departing from prior NeRF-based localization work (iNeRF, LENS, DFNet, NeFes) that treated NeRF as an auxiliary tool for training augmentation, photometric supervision, or inference-time refinement. It also diverges from the closest competitors CrossFire and NeRF-Loc, which require joint training of a customized NeRF with the matching network, by directly leveraging pre-trained NeRF features without any retraining. The matching architecture draws on LoFTR's coarse-to-fine transformer paradigm and dual-softmax matching, while the overall pipeline follows the structure-based localization template (retrieval → 2D-3D matching → PnP → refinement) established by HLoc and InLoc, but replaces stored 3D point descriptors with NeRF-rendered volumetric features.

## Why It Matters / Open Questions

The key implication is that a single compact NeRF model (5.28 MB) can replace both a 3D point cloud and a large image database for localization, enabling a fully NeRF-based pipeline where even image retrieval operates on synthesized views. This opens a path toward scene representations that are simultaneously compact, interpretable, and directly usable for matching. However, the notable indoor performance gap on 7-Scenes (recall 78% vs. 97% for SCR methods) highlights that NeRF features trained on limited frames struggle with textureless surfaces and dense frame distributions, leaving open the question of whether NeRF can fully supplant explicit representations across all environments. The scene-agnostic multi-scene training result suggests the approach could scale to large-scale deployment without per-scene retraining.

## Problem

Existing open-vocabulary 3D scene understanding methods (e.g., LERF) rely on heavy MLP-based radiance fields that require lengthy offline training, lack local scene updating capability, produce blurry hierarchical semantic boundaries, and suffer from multi-view inconsistency when the same object is observed from different viewpoints. No prior framework enables online construction of dense open-vocabulary semantic scenes using neural implicit representation while supporting real-time text queries during the mapping process.

## Input / Output

The method consumes a continuous RGBD stream with per-frame camera poses and accepts arbitrary natural-language text queries at any point during online construction. It maintains a hierarchical voxel grid (initially 16 cm, adaptively split to 8 cm) storing per-cell RGB, geometric, and language features, and outputs rendered RGB/depth images, per-voxel semantic relevance maps for queried text, and a compact retrieval map that indexes unique object entities for efficient 3D localization without scanning all voxels.

## Method

O2V-Mapping replaces the monolithic MLP of prior NeRF-based semantic fields with a voxel-based open-vocabulary field (O2V Field) that stores three feature grids (RGB, geometric, semantic) updated incrementally per frame. Object-level grounding is achieved by running SAM for multi-scale instance segmentation on each input frame, then encoding each instance with a CLIP decoder to obtain language features that are depth-projected into the corresponding 3D voxels. An adaptive voxel-splitting mechanism subdivides a voxel into eight children whenever the cosine similarity of co-located language features exceeds a threshold, resolving boundary conflicts without inflating the entire grid. Multi-view voting accumulates language features across observations using cumulative observation counts as weights (Eq. 9–10), ensuring that partially visible objects converge to stable semantics over time. A retrieval map merges indices of spatially close, semantically similar instances (score = cosine similarity / Euclidean distance > α) so that text queries only need to be matched against a small set of unique object features rather than all voxels.

## Results

On the Replica dataset, O2V-mapping achieves a mean IoU of 0.536 across 12 text queries in 4 rooms, outperforming LERF (0.318) and OVSeg (0.175). The paper reports a 1.12× mIoU improvement over LERF. In terms of speed, O2V-mapping runs at 0.667 FPS on a single RTX 3090, a 4× speedup over LERF's 0.155 FPS, and is the only method among the three that supports online (streaming) construction. Qualitative results on the noisier ScanNet dataset confirm robustness to real-world depth noise across 18 object types.

## Baselines & Comparisons

O2V-mapping is compared against two baselines: LERF (a 3D NeRF-based open-vocabulary method) and OVSeg (a 2D mask-adapted CLIP segmentation method). Against LERF, O2V-mapping wins on all 12 text queries, with the largest gains on "blue chair" (0.846 vs 0.382) and "door" in Room0 (0.309 vs 0.123), and a consistent 1.12× mIoU improvement overall. Against OVSeg, O2V-mapping wins on 11 of 12 queries; the sole exception is "chair" in Room0 where OVSeg (0.362) slightly edges out O2V-mapping (0.312). OVSeg, being a purely 2D method, struggles severely with 3D spatial queries (e.g., 0.002 IoU for "door" in Room2), while LERF, though 3D-aware, is limited to offline operation and exhibits confused relevance distributions when the queried object is outside the current viewpoint. Critically, O2V-mapping is the only method that supports online streaming construction, achieving 4× higher FPS than LERF while maintaining superior segmentation quality.

## Relation to Prior Work

This paper extends the LERF paradigm of embedding CLIP language features into a radiance field by replacing the heavy, offline-trained MLP with a voxel-based implicit representation that supports local, incremental updates. It draws on ConvOnet's decoder architecture and voxel-hashing ray termination modeling for the geometric/RGB branch, while introducing SAM-based object-level segmentation (rather than pixel-level features used in LERF or OVSeg) to extract cleaner language embeddings. The voxel splitting and multi-view voting mechanisms are novel contributions that address boundary conflicts and cross-view semantic inconsistency, respectively, and the LLM-agent integration repurposes the constructed field as interactive memory for grounded tree search.

## Why It Matters / Open Questions

This is the first framework to achieve online open-vocabulary 3D scene construction with neural implicit representation, which is practically critical for robotic applications where scenes change and cannot be pre-processed offline. The 4× speedup over LERF and consistent IoU gains across diverse object types make it a viable baseline for real-time open-set semantic mapping. However, the method inherits limitations from SAM and CLIP (struggling with ambiguous or novel object descriptions), the LLM-agent interaction is acknowledged as rudimentary, and scalability to large or dynamic scenes remains untested. Open questions include whether the voxel splitting strategy generalizes to arbitrarily fine-grained objects and how the framework handles occlusion-heavy or rapidly changing environments.

## Problem

Existing content-aware layout generation methods represent layout elements as raw numerical tuples, discarding the semantic relationships between elements (e.g., 'text placed over underlay') and limiting the model's ability to generalize beyond the training distribution. While recent LLM-based approaches have begun to address this by encoding layouts as code, they still struggle to incorporate fine-grained visual content from the canvas, leaving a gap between semantic layout understanding and visual content awareness.
![Teaser figure](../imgs/ECCV20242206/cropped_page3_idx0.webp)

## Input / Output

The model takes a poster canvas image (processed at 224×224 by DINOv2), an optional natural-language text description, and optional element conditions (category, size, position) all serialized into a single text prompt. The output is an HTML-formatted sequence where each layout element is wrapped in a tag (e.g., <rect>) containing discretized bounding-box coordinates, dimensions, and category label, with a mask token <M> indicating positions the LLM must predict. This code-based representation supports multiple conditioning modes—image-only, image+text, image+text+category, image+text+category+size, partial completion, and recovery—by simply varying the prompt template.

## Method

PosterLlama reformulates poster layout generation as HTML sequence generation, leveraging the design priors embedded in CodeLlama's training data. A DINOv2 visual encoder produces image features that are projected into the LLM's token space via a linear adapter; the two-stage training first aligns this adapter on 2M image-caption pairs (freezing the LLM), then fine-tunes the LLM with LoRA on HTML-formatted layout data (freezing the adapter). To combat data scarcity and inpainting artifacts in poster datasets, a depth-guided augmentation pipeline uses ControlNet-Depth conditioned on BLIP-2 captions to synthesize N=10 candidate posters per image, from which top-k=3 samples are selected via DreamSIM similarity to preserve salient-object composition. A random permutation of element order during training prevents the model from overfitting to a fixed sequence ordering, and the mask token mechanism enables all conditional generation and completion tasks within a single unified model.

## Results

On the CGL dataset, PosterLlama-T achieves the best or near-best scores across all eight metrics: validity 0.9988, overlap 0.0024, alignment 0.0003, underlay-large 0.9918, underlay-small 0.9905, Fréchet distance 2.082, readability 0.2042, and occlusion 0.1418. On the PKU dataset (fewer samples), PosterLlama attains perfect validity (1.000), near-zero alignment error (0.0009), and the highest underlay scores (0.9998 / 0.9910), outperforming all baselines on every metric except FD. The authors note that RADM's apparently superior content metrics (FD, rea, occ) are attributable to data leakage from inpainting artifacts rather than genuine layout quality.

## Baselines & Comparisons

Against DS-GAN, PosterLlama dominates on every metric: validity improves from 0.8545 to 0.9986 (CGL), alignment error drops from 0.0033 to 0.0004, and underlay-small rises from 0.6717 to 0.9909, reflecting DS-GAN's tendency to produce misaligned, overlapping layouts. Against LayoutPrompter, PosterLlama achieves far superior content awareness (und_l 0.9982 vs. 0.4473, occ 0.1480 vs. 0.3011 on CGL), confirming that in-context LLM prompting without visual encoding cannot capture fine spatial composition. Against RADM, PosterLlama wins on validity, alignment, and both underlay metrics, while RADM appears to lead on FD (0.729 vs. 2.518), readability, and occlusion; however, the authors demonstrate via an inpainting-leakage experiment (Fig. 3) that RADM exploits inpainting artifacts in the training data, making its content-metric advantage unreliable. On the leakage-free CGL-v2 augmented test set (Table 4), PosterLlama outperforms RALF on overlap (0.0006 vs. 0.0156), alignment (0.0001 vs. 0.0044), underlay-large (1.0000 vs. 0.9820), and occlusion (0.0513 vs. 0.0595), while RALF retains a slight edge on readability (0.1126 vs. 0.1142).

## Relation to Prior Work

PosterLlama extends the LLM-based layout generation line initiated by LayoutNUWA (HTML-format layout generation) and LayoutPrompter (content-aware LLM layout generation) by integrating a visual encoder (DINOv2) via a two-stage MiniGPT4-style training pipeline, enabling true visual content awareness rather than relying solely on salient-object bounding boxes. It departs from the broader content-aware layout generation literature (ContentGAN, CGL-GAN, DS-GAN, RADM) by reframing layout elements as semantically rich HTML code rather than numerical tuples, and introduces a depth-guided augmentation strategy to address the chronic data scarcity in poster datasets.

## Why It Matters / Open Questions

The paper demonstrates that LLM-based layout generation with HTML formatting can match real-layout quality metrics while supporting a unified interface for multiple task variants (conditional generation, completion, refinement), which prior methods handled separately. The data-leakage analysis revealing that RADM's superior content metrics stem from exploiting inpainting artifacts rather than genuine content understanding is a useful methodological caution for the field. Open questions include whether the approach generalizes beyond poster layouts to other design domains, whether the LLM dependency limits deployment on resource-constrained devices, and whether the Chinese-to-English translation workaround for text-aware generation can be resolved natively.

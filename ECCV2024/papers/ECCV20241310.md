## Problem

Existing dual-modal prompt tuning methods (e.g., MaPLe, UPT) require learning new modal mapping substructures to remodel the aligning space for text and image tokens, which produces inaccurate distributions when trained on limited downstream data and degrades transfer generalization on fusion-based VLPMs like GLIP. These methods fail to leverage the pre-trained deep fusion structure (X-MHA cross-attention) that already establishes an effective text-image aligning space, and incur extra training and storage costs.

## Input / Output

The method takes an RGB image and a text prompt listing target category names as input, processed through GLIP's Swin Transformer image encoder and BERT text encoder respectively. It outputs object bounding boxes with class labels for detection. The key architectural detail is that k learnable unified prototype tokens (k=10 to 200) are injected at each of the 8 X-MHA cross-attention layers, and after forward propagation the prototype token positions are sliced out before passing to subsequent encoder layers, so the output dimensions remain unchanged from the base model.

## Method

SDPT introduces a single set of learnable unified prototype tokens Z^i ∈ R^{k×d} positioned directly in the pre-established fusion space (the d-dimensional cross-attention space of each X-MHA layer), where text and image tokens are already semantically aligned. Rather than learning new modal mapping functions, SDPT constructs inverse linear projections via the pseudo-inverse of the pre-trained query transform matrices W^(q,T) and W^(q,I), which map Z^i back into the text and image latent spaces without any trainable parameters. The projected tokens Z^{i,(T)} and Z^{i,(I)} are concatenated with the original text and image tokens respectively, enabling joint forward computation through X-MHA while preserving the unbiased pre-trained aligning distribution. Only the unified prototype tokens are updated during training (0.04% of total parameters at k=10), keeping all other model weights frozen, which maximally preserves the pre-trained knowledge of fusion-based VLPMs while adapting to downstream tasks.

## Results

SDPT (k=10) achieves 57.6 mAP on COCO, 41.2 AP on LVIS, and 69.5 mAP on ODinW13 (full-shot) using only 0.16M trainable parameters (0.04% of the full model), surpassing full fine-tuning (60.8 mAP COCO, 41.2 AP LVIS, 68.9 mAP ODinW13) on ODinW13 while using 1/2486th of the parameters. With k=120, SDPT reaches 58.0 mAP on COCO and 41.4 AP on LVIS, matching or exceeding full fine-tuning on LVIS. In the 1-shot ODinW13 setting, SDPT (k=200) achieves 61.5 mAP, substantially outperforming the linear probing baseline (54.1) and all other PEFT methods.

## Baselines & Comparisons

SDPT outperforms all 11 baselines on ODinW13 full-shot mAP, achieving 69.5 (k=10) and 71.2 (k=120) versus the next-best Adapter (69.2) and full fine-tuning (68.9). Among dual-modal PEFT methods, SDPT surpasses the strongest synchronous baselines MaPLe (68.7) and UPT (67.7) by 0.8 and 1.8 mAP respectively on ODinW13, and outperforms asynchronous methods DPT (65.2), Apollo (66.7), and PMF (67.4) by 2.3–4.3 mAP. On COCO mAP, SDPT (k=120) reaches 58.0, beating MaPLe (57.2), UPT (56.8), LoRA (56.5), and PMF (56.2), though it remains below full fine-tuning (60.8) by 2.8 mAP. On LVIS AP, SDPT (k=120) achieves 41.4, matching full fine-tuning (41.2) and exceeding MaPLe (40.8) and UPT (40.2). Notably, single-modal methods (Adapter, VPT, CoOp) and network-related methods (LoRA, BitFit) sometimes outperform dual-modal PEFT methods (DPT, Apollo, PMF) on fusion-based VLPMs, which the authors attribute to those methods learning biased modal mappings from limited data; SDPT avoids this by inheriting pre-trained inverse projections rather than learning new ones.

## Relation to Prior Work

This paper extends the line of synchronous dual-modal prompt tuning (MaPLe, UPT) by recognizing that these methods, designed for standard dual-encoder VLPMs, are ill-suited for fusion-based VLPMs (GLIP, FIBER) that rely on X-MHA cross-attention layers for deep bimodal coupling. The key departure is architectural: rather than learning new modal mapping substructures to project shared tokens into each modality's latent space, SDPT inverts the pre-trained query transform matrices of X-MHA to construct training-free inverse linear projections, positioning unified prototype tokens directly in the already-established fusion space. This repurposes the pre-trained alignment geometry rather than approximating a new one from limited downstream data.

## Why It Matters / Open Questions

The practical impact is significant for deployment: achieving competitive or superior detection performance with 0.04% trainable parameters (k=10) while outperforming full fine-tuning on ODinW13 makes PEFT of large fusion-based VLPMs feasible in resource-constrained settings. The finding that dual-modal PT methods can underperform single-modal methods on fusion-based VLPMs challenges the assumption that joint modality tuning is always beneficial and highlights the importance of respecting pre-trained alignment structures. Open questions include whether SDPT generalizes to other fusion-based VLPM tasks (phrase grounding, region-conditioned generation) and whether the inverse-projection trick transfers to architectures without explicit linear query transforms.

## Problem

Generating multi-view driving videos from 3D layouts requires simultaneously maintaining cross-view consistency (different cameras showing the same scene coherently) and cross-frame temporal consistency, while also achieving precise layout control and high-quality instance generation. Prior work addressed only subsets of this problem—single-view images, single-view videos, or multi-view single-frame images—leaving the full multi-view, multi-frame video generation task with 3D layout control unexplored.
![Teaser figure](../imgs/ECCV20242100/cropped_page1_idx1.webp)

## Input / Output

The method takes a 3D layout (obstacle bounding boxes and road structure) projected onto six 512×512 camera views, where each pixel encodes road structure, target category, and instance ID as RGB values, along with a global text prompt and per-camera optical flow priors. It produces temporally consistent multi-view video sequences across all six cameras, with the pipeline first generating a multi-view keyframe, then per-camera video sequences, and finally post-processed frames for long-duration extension via sliding window.

## Method

DrivingDiffusion is a three-stage pipeline built on Stable Diffusion (1.4B params) with a U-Net extended by 1×3×3 convolutions and temporal self-attention. A 3D Layout Controller (a ResNet-like module analogous to ControlNet) encodes the projected layout at four resolutions (64×64 down to 8×8) and injects it into the U-Net via residual connections. Cross-view consistency is enforced through an attention mechanism where each view attends to its left and right neighbors, while cross-frame consistency uses attention between the current frame and both the first and immediately preceding frames, supplemented by a geometric pose-consistency loss from a pre-trained pose estimator. A local prompt module applies CLIP-encoded category text with bounding-box masks to improve instance quality, and a Key-Frame controller plus per-camera optical flow tokens (encoded like time embeddings) enable a single temporal model to serve all six cameras without per-camera retraining.

## Results

On the nuScenes validation set, DrivingDiffusion achieves FID 15.83 and FVD 346 for the full multi-view + multi-frame pipeline, outperforming all prior methods. For multi-view image generation alone, it reaches FID 15.89, surpassing MAGICDRIVE (16.20), BEVControl (24.85), and BEVGen (25.54). For single-view video generation, it achieves FID 15.85 and FVD 335, substantially beating DriveDreamer (FID 52.6, FVD 452). On downstream perception tasks, generated data causes only a -8.1% drop in Road mIoU and -4.4% drop in Vehicle mIoU versus the real-data baseline, the smallest degradation among all compared methods.

## Baselines & Comparisons

DrivingDiffusion outperforms all four baselines on every reported metric. Against the multi-view image generation methods, it achieves the lowest FID (15.89 vs. 16.20 for MAGICDRIVE, 24.85 for BEVControl, and 25.54 for BEVGen), with the gap over MAGICDRIVE being modest (~0.3 FID) but the gap over BEVGen/BEVControl being substantial (~10 FID). On downstream perception quality (Table 2), DrivingDiffusion's generated data degrades Road mIoU by only -8.1% and Vehicle mIoU by -4.4%, compared to -9.8%/-9.0% for MAGICDRIVE, -10.5%/-9.2% for BEVControl, and -21.1%/-39.1% for BEVGen. Against the single-view video baseline DriveDreamer, DrivingDiffusion improves FID from 52.6 to 15.85 and FVD from 452 to 335, a roughly 3× reduction in FID and 25% reduction in FVD. Notably, DrivingDiffusion is the only method that simultaneously handles both multi-view and multi-frame generation, making direct head-to-head comparisons on a single axis somewhat asymmetric; the full pipeline (FID 15.83, FVD 346) confirms that adding the temporal dimension does not degrade image quality.

## Relation to Prior Work

DrivingDiffusion extends the layout-to-image generation line (BEVGen, BEVControl, MAGICDRIVE) from single-frame multi-view images to temporally consistent multi-view video, and extends single-view driving video generation (DriveDreamer) to the multi-view setting. Architecturally, it builds on Stable Diffusion's latent U-Net backbone, adopts Video Diffusion Models' temporal convolution extension, and repurposes ControlNet-style conditioning for 3D layout injection at multiple resolutions. The key conceptual departure is the three-stage cascaded pipeline (multi-view frame → per-view temporal video → restoration post-processing) with dedicated cross-view and cross-frame attention modules, rather than a single monolithic model handling all dimensions simultaneously.

## Why It Matters / Open Questions

This is the first framework to produce layout-controlled multi-view driving video, directly addressing the data bottleneck for BEV perception training. The demonstrated data augmentation results (NDS +0.022, mAOE −0.048 with 6,000 synthetic frames) show practical utility for long-tail scenario coverage in detection and tracking. Open questions include scalability to longer sequences beyond the sliding-window approach, generalization beyond nuScenes to more diverse driving environments, and whether the restoration post-processing stage can be absorbed into the main model. The authors also note potential extension to depth, point cloud, and occupancy control, suggesting a broader world-model direction.

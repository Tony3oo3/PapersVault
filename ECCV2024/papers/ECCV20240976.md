## Problem

Learning dense keypoints (canonical surface maps) that assign every pixel of an object to a point on a 3D template has been limited to a handful of categories due to the high cost of manual pixel-to-vertex annotations. Existing unsupervised methods either generalize poorly across categories or require large annotated datasets, making it impractical to build correspondence models for the vast majority of object types in existence.
![Teaser figure](../imgs/ECCV20240976/cropped_page0_idx0.webp)

## Input / Output

The method takes a single 3D template mesh (defining the object's surface topology) and a small set of masked RGB images (as few as 180) of the target class. It also consumes N=72 rendered views of the template (surface-normal style) and optionally photorealistic synthetic renders produced by a depth-conditioned diffusion model. The output is a canonical surface map: a per-pixel assignment to one of K mesh vertices, parameterized as a Continuous Surface Embedding where image pixels and vertices share a 16-dimensional embedding space, with correspondences recovered by argmax over cosine similarity.

## Method

SHIC reduces the image-to-template matching problem to image-to-image matching by rendering the 3D template from multiple viewpoints and using SD-DINO features (combining DINO and Stable Diffusion encoders) to compute per-pixel cosine similarities between the query image and each render. These similarities are pooled across views (max pooling over visible vertices) to produce dense pseudo-ground-truth pixel-to-vertex correspondences, which then supervise a CSE model consisting of a frozen DINOv2 ViT encoder with a 5-layer CNN decoder for images and LBO eigenvector-based vertex embeddings. Training combines a cross-entropy pseudo-label loss, a geodesic distance-aware loss, a cycle-consistency loss, and a bilateral-symmetry equivariance loss to resolve left-right ambiguity. Optionally, photorealistic template renders generated via depth-conditioned ControlNet (using Depth Anything for depth estimation) provide an additional fully synthetic supervision signal that further narrows the synthetic-to-real gap.

## Results

On DensePose-LVIS, SHIC (fully unsupervised) achieves 24.9 average geodesic error, outperforming the supervised CSE baseline (26.6) and the zero-shot SD-DINO method (36.2). On PF-PASCAL keypoint transfer, SHIC's image-to-mesh-to-image matching reaches 70.0 PCK-0.1, dramatically exceeding the best supervised method CSE (52.3) and all prior unsupervised approaches (≤29.3). The method is highly data-efficient, requiring as few as 180–2,800 training images per class.

## Baselines & Comparisons

SHIC outperforms the supervised CSE [25] on DensePose-LVIS (24.9 vs. 26.6 average geodesic error) despite using no manual annotations, with the advantage attributed to the much denser pseudo-ground-truth from SD-DINO matching versus the three manual labels per image in CSE. On PF-PASCAL, SHIC's image-to-mesh-to-image pipeline (70.0 PCK-0.1) surpasses CSE (52.3), A-CSM (37.6 supervised / 29.3 unsupervised), and Rigid-CSM (34.0 supervised / 27.4 unsupervised) by a wide margin. The zero-shot SD-DINO baseline [50], which SHIC uses to generate pseudo-labels, scores 36.2 geodesic error on DensePose-LVIS, confirming that the learned canonical map substantially refines the raw feature matching. SHIC also beats the direct image-to-image CSE embedding variant (61.2 PCK) by 8.8 points when routing through the 3D template, highlighting the value of the canonical surface as an intermediate representation.

## Relation to Prior Work

SHIC builds directly on the Continuous Surface Embedding (CSE) representation of Neverova et al. [24,25], reusing its LBO-based vertex embedding decomposition and distance-aware loss, but replaces the manual image-to-template annotations that CSE requires with pseudo-ground-truth generated by SD-DINO [50] features. The key conceptual departure is treating foundation-model features (DINO + Stable Diffusion) as an automated annotator: by matching real images to non-photorealistic renders of a 3D template, the method emulates the manual annotation pipeline of DensePose without any human labels. An additional departure from prior canonical mapping work (CSM [17,18], CSE [25]) is the use of depth-conditioned diffusion (ControlNet + Depth Anything) to generate photorealistic synthetic views of the template as a supplementary supervision source.

## Why It Matters / Open Questions

The practical impact is significant: dense canonical maps can now be learned for essentially any object category given a template mesh and a few hundred images, removing the annotation bottleneck that has restricted dense pose to humans and a handful of animal classes. The finding that dense but noisy pseudo-labels from foundation models outperform sparse clean manual labels (3 per image in DensePose-LVIS) suggests a broader principle for leveraging foundation models as free annotators in geometry tasks. Limitations include the fixed template (no pose or shape diversity in synthetic data), reliance on bilateral symmetry for the equivariance loss, and the fact that the zero-shot SD-DINO pseudo-ground-truth is still substantially worse than the trained model, indicating a ceiling on what the foundation-model features can provide. Open questions include whether the approach extends to non-animal categories with complex topology, whether the pseudo-label quality can be further improved, and whether the method scales to articulated or multi-instance scenes.

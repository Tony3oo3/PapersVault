## Problem

3D object annotation for autonomous driving is extremely labor-intensive, with annotating one hour of driving data requiring hundreds of human hours. Existing approaches force annotators to work directly in 3D point cloud space for both adding missed objects and correcting erroneous predictions, creating a significant bottleneck for dataset scale and diversity. This paper bridges the gap by enabling users to interact via simple 2D prompts (clicks or boxes) while the model handles 3D reasoning.

## Input / Output

The method consumes multi-view camera images (6 views) and LiDAR point cloud alongside a user-provided 2D prompt (a single click or bounding box) on either a camera image or the bird's-eye-view map. For iterative refinement, the user adjusts a subset of 3D attributes (e.g., dragging the center point or rotating the yaw angle), and the model encodes the refined bounding box together with binary refinement records indicating which attributes were corrected. The output is a 3D bounding box parameterized by gravity center, width, length, height, and yaw angle, plus a class label, with predictions produced at every decoder layer and every refinement iteration via deep supervision.

## Method

The architecture is a DETR-style Transformer decoder with two key innovations. First, prompt-guided query generation initializes each object's learnable token Q_l from the 3D position encoding of the user's 2D prompt (projected into 3D via camera intrinsics/extrinsics for images, or directly for BEV), and augments it with a prompt token Q_p that fuses position encoding and context embedding (average-pooled features within the prompt box or the feature at the click point). Second, a global-to-local enhancement strategy splits the decoder: the first Z layers perform cross-attention over the full multi-modal feature maps, while the remaining L−Z layers restrict attention to local RoI-aligned features around the prompted object, improving fine-grained detection. For iterative refinement, the model encodes the user-corrected 3D bounding box and category into a new prompt token Q_3D via separate MLPs for attributes and binary refinement records, which is inserted into the query sequence to drive self-correction of unmodified attributes. Because each prompted object has a dedicated query, no Hungarian matching is required; training uses focal loss for classification and L1 loss for regression with deep supervision across all decoder layers and refinement iterations.

## Results

On the nuScenes validation set, the method achieves NDS 75.0 and mAP 76.2 from raw data with a single 2D box prompt, reaching NDS 90.5 and mAP 89.6 after five iterative refinements. When starting from CMT's SOTA predictions (NDS 72.9, mAP 70.3), the interactive refinement (CMT+Ours) reaches NDS 90.4 and mAP 89.4 after five iterations, substantially outperforming equivalent manual correction (CMT+M: NDS 86.3, mAP 81.6). In open-set scenarios with eight unseen categories, the method achieves NDS 99.2 and mAP 99.5 after five refinement rounds. Human annotation studies show a ~56% speedup over manual-only annotation and ~40% over CMT+manual correction.

## Baselines & Comparisons

The primary comparison is against CMT [45] (NDS 72.9, mAP 70.3) as the SOTA starting model, with manual correction (CMT+M) serving as the human-effort baseline. After five refinement iterations, CMT+Ours outperforms CMT+M by 4.1% NDS (90.4 vs 86.3) and 7.8% mAP (89.4 vs 81.6), demonstrating that the model's self-correction capability adds substantial value beyond what manual attribute adjustments alone achieve. Notably, CMT+M's mAP plateaus at 81.6 after the first iteration (center correction), while CMT+Ours continues to improve, indicating the model autonomously rectifies category and other attributes. From raw data, the method (NDS 90.5, mAP 89.6 at R5) surpasses all traditional detectors including SparseFusion (72.8/70.4) and CMT (72.9/70.3) by a wide margin. In open-set evaluation with eight unseen categories, the method reaches NDS 99.2 and mAP 99.5, confirming strong generalization when class labels are provided manually alongside 2D prompts.

## Relation to Prior Work

This paper extends the DETR-family of transformer detectors (building on PETR's 3D position encoding and CMT's cross-modal architecture) by introducing a prompt-driven interaction paradigm borrowed from the SAM/interactive-segmentation lineage. Unlike prior interactive 3D detection tools (C3Det, iDet3D, LATTE) that still require users to operate in 3D space, this work deliberately shifts the interaction surface to 2D (camera images or BEV) and adds an iterative 3D self-correction loop. The global-to-local decoder strategy draws from two-stage detector ideas (Faster R-CNN's RoI Align) and recent DETR refinements, while the anchor-based query initialization follows DAB-DETR.

## Why It Matters / Open Questions

The 56% annotation speedup and the ability to handle open-set objects without retraining address two of the most persistent practical bottlenecks in 3D perception for autonomous driving. However, the evaluation relies entirely on simulated prompts derived from ground truth on a single dataset (nuScenes), leaving open whether the approach generalizes to real annotator behavior, more diverse sensor suites, or larger-scale deployment. The self-correction mechanism—where adjusting one 3D attribute (e.g., center) automatically refines others (e.g., yaw)—is promising but its robustness under larger initial errors or occluded objects remains untested. A key open question is whether the prompt-driven paradigm can be extended to multi-frame temporal consistency, which is critical for real-world annotation pipelines.

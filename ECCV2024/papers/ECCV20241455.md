## Problem

Test-time adaptation (TTA) for 3D point cloud segmentation remains underexplored: most TTA methods target 2D images and transfer poorly to unordered point clouds, while the one point-cloud-specific method (GIPSO) ignores the hierarchical geometric structure (point-level, object-level, frame-level) and relies on an additional network for geometric feature extraction, limiting both accuracy and efficiency.
![Teaser figure](../imgs/ECCV20241455/cropped_page3_idx0.webp)

## Input / Output

The method consumes a sequential stream of 3D LiDAR point clouds, processing one frame at a time (batch size 1) with access to the current frame X_T^t and a previous frame X_T^{t-w} for temporal matching via rigid transformation. A frozen source model (MinkowskiNet) provides initial predictions, while a learnable target model is updated online. The output is per-point semantic labels over 7 standardized classes, evaluated as mIoU improvement over the source model on each incoming frame.

## Method

HGL decomposes adaptation into three bottom-up modules. (1) Local Geometry Learning (LGL) generates pseudo-labels from the frozen source model by K-NN distance-weighted aggregation of neighbor predictions, then scores each point by prediction certainty (normalized Shannon entropy) and geometric purity (class-distribution entropy over the K-NN neighborhood), selecting only high-confidence labels via a per-class percentile threshold. (2) Global Geometry Fine-tuning (GGF) builds per-class prototypes on the learnable target model from selected local pseudo-labels, updated via EMA across frames; global pseudo-labels are assigned by cosine similarity to prototypes, and local pseudo-labels are retained only where they agree with the global assignment, injecting progressively more target-domain information. (3) Temporal Geometry Regularization (TGR) applies a SimSiam-style negative cosine-similarity loss between encoder-projected features of geometrically corresponding points in consecutive frames, but weights the loss by the confidence score of the reference frame so that low-confidence features are pulled toward high-confidence ones rather than corrupting them. The overall objective combines a soft Dice loss (with confidence-controlled label smoothing) on the filtered local-global pseudo-labels plus the temporal consistency loss, optimized with Adam at lr 1e-3.

## Results

On the primary SynLiDAR→SemanticKITTI benchmark, HGL achieves a +6.72% mIoU improvement over the source model (40.19% → 46.91% absolute mIoU), outperforming the closest competitor GIPSO (+3.70%) by 3.0 percentage points. HGL also reduces per-frame adaptation time from 3.83 s (GIPSO) to 0.63 s, an 80% speedup. Across all four evaluation settings (synthetic-to-real, real-to-real, continual learning, adverse weather), HGL consistently surpasses GIPSO, with the largest margin on nuScenes→SemanticKITTI (+7.66% vs +2.88%).

## Baselines & Comparisons

HGL outperforms all seven baselines across every evaluated setting. The most direct comparison is against GIPSO [33], the only prior method purpose-built for TTA-3DSeg: HGL improves mIoU by 3.0 pts on SynLiDAR→SemanticKITTI (+6.72 vs +3.70), 2.1 pts on Synth4D→SemanticKITTI (+6.40 vs +4.31), and 1.0 pt on Synth4D→nuScenes (+1.87 vs +0.85), while also cutting adaptation time by 80%. Image-domain TTA methods (TENT, ConjugatePL) and re-purposed offline DA methods (ProDA, SHOT, CBST) all fail to transfer effectively to 3D point clouds, with ProDA and SHOT actually degrading performance by ~35–39 mIoU points. ADABN and CBST remain near the source baseline (≤+0.3%), confirming that simple normalization or self-training strategies are insufficient for the geometric distribution shift in LiDAR data. HGL also uniquely avoids negative transfer on the imbalanced Pedestrian class (+5.66%), where GIPSO still drops by 6.76 points.

## Relation to Prior Work

This paper extends GIPSO (Saltori et al., ECCV 2022), the first method specifically designed for test-time adaptation in 3D LiDAR segmentation, by decomposing the adaptation process into a hierarchical local–global–temporal structure. Where GIPSO relies on a frozen source model with an auxiliary network for geometric feature extraction, HGL leverages the target model's own evolving features to build class prototypes for pseudo-label fine-tuning, eliminating the extra network. The temporal regularization module adapts the SimSiam contrastive loss (Chen & He, CVPR 2021) to point cloud streams with a confidence-weighted alignment that departs from GIPSO's uniform regularization across all points.

## Why It Matters / Open Questions

TTA for 3D point cloud segmentation remains an underexplored problem, and this work provides the most thorough geometric decomposition to date, offering a modular framework whose components can be independently upgraded (as shown in Table 7). The 80% reduction in per-frame adaptation time is practically significant for real-time autonomous driving deployment where latency budgets are tight. Open questions include whether the hierarchical approach generalizes beyond the MinkowskiNet backbone and the 7-class setting, and whether the prototype-based global module can handle open-vocabulary or long-tail class distributions in more complex driving scenes.

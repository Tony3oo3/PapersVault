## Problem

Existing video super-resolution via data overfitting methods (NAS, EMT, STDO) require multiple SR models for different video chunks, causing severe model-switching overhead, I/O pressure, and >50% additional energy consumption on the user end, making real-time on-device inference impractical. The paper tackles two coupled gaps: (i) reducing the transmitted model count to one while preserving PSNR, and (ii) enabling efficient compilation of the resulting dynamic DNN (with variable input shapes and routing) on resource-constrained mobile hardware.

## Input / Output

The system takes low-resolution video frames (generated by bi-cubic downscaling from 1080p/10-bit HR sources) and a single dynamic SR model. Frames are split into unevenly-sized patches via an iterative PSNR-guided pipeline (thresholds at 40 dB and 30 dB), so background regions yield large patches while detailed foregrounds yield smaller ones. A learnable routing node dispatches each patch to a corresponding path in the dynamic network, and the output is the reconstructed high-resolution frame at x2, x3, or x4 scale. The entire pipeline is deployed on a mobile GPU (Adreno 740) targeting ~30 ms per-frame inference.

## Method

Dy-DCA combines a content-aware data pipeline with a dynamic DNN and a compiler-level optimization framework. On the algorithm side, a coarse-to-fine splitting loop evaluates each patch with a general SR model; patches exceeding a PSNR threshold are kept as-is while lower-PSNR patches are recursively subdivided, producing a set of patches whose shapes correlate with texture complexity. A single dynamic network with multiple resolution-specific paths and a learnable gating node routes each patch to the appropriate path, eliminating the need for multiple independent models. On the compiler side, the authors classify ONNX operators into four categories by how output shape depends on input shape and value, then perform a data-flow analysis over the computation graph (using a lattice of known/symbolic/undefined constants) to infer intermediate tensor shapes even under dynamic routing. These inferred shapes enable operator fusion with fused code generation, static execution planning via graph partitioning, and runtime memory allocation, yielding a 1.7x speedup and 1.61x memory reduction over the MNN baseline on a Snapdragon 8 Gen 2 phone.

## Results

Dy-DCA achieves the highest PSNR across all six video sequences and three scaling factors (×2, ×3, ×4) on both UVG and VSD4K datasets, using EDSR and WDSR backbones. With the WDSR backbone, Dy-DCA reaches 47.10 dB on UVG-Bosphorus ×2 and 44.12 dB on vlog-45s ×4, consistently outperforming the closest competitor STDO by 0.1–0.3 dB. On-device deployment on a Snapdragon 8 Gen 2 phone yields 30 ms average GPU inference (33 FPS, real-time), with a 1.7× speedup and 1.61× memory reduction over the MNN baseline. The method also reduces model switching overhead by 4× and I/O by 7× compared to STDO by collapsing four models into one.

## Baselines & Comparisons

Dy-DCA outperforms all four baselines on every tested video and scaling factor. Against NAS [60] (temporal chunking with independent models), Dy-DCA gains 1.0–1.7 dB PSNR, e.g., 47.10 vs 45.45 on UVG-Bosphorus ×2. Against EMT [35] (meta-learning for faster training), the margin is 0.5–1.5 dB, e.g., 44.12 vs 42.87 on vlog-45s ×4. The closest competitor is STDO [33] (spatial-temporal texture-based chunking with 4 models), where Dy-DCA leads by a consistent 0.1–0.3 dB while using only 1 model instead of 4, yielding 4× less model-switching overhead and 7× less I/O. Against SRVC [27] (one-size-fits-all content-adaptive SR), Dy-DCA shows a dramatic advantage on complex content: on game-45s ×2, SRVC drops to 31.03 dB while Dy-DCA maintains 45.86 dB, a gap of 14.83 dB, confirming that a single static model cannot handle diverse texture complexity as effectively as the dynamic multi-path design.

## Relation to Prior Work

This paper extends the data-overfitting paradigm for video super-resolution established by NAS (temporal chunking with per-chunk models), EMT (meta-learning to reduce model count), and STDO (spatial-temporal patch grouping). The key conceptual departure is replacing multiple static models with a single dynamic DNN featuring a learnable routing node and multiple resolution-specific paths, paired with a content-aware uneven patch-splitting pipeline that reduces total patch count. The second major contribution is a compiler-level data-flow analysis framework that classifies DNN operators by their shape/value dependencies to enable operator fusion, static execution planning, and memory allocation for dynamic architectures—bridging the algorithm-systems gap that prior overfitting works left unaddressed.

## Why It Matters / Open Questions

The quantified model-switching overhead (over 50% additional energy, large fraction of total video length) makes the single-model dynamic approach practically important for real-time mobile video delivery, and the compiler co-design demonstrates that dynamic DNNs can achieve near-static efficiency (33 FPS, 1.7× speedup over MNN) on commodity hardware. However, the PSNR gains over STDO are modest (0.1–0.5 dB), the evaluation is limited to two datasets and a single phone model, and the compiler optimizations are tied to the specific operator set and routing structure of Dy-DCA. Open questions include whether the data-flow analysis generalizes to more complex dynamic architectures (e.g., transformers with dynamic attention), how the approach scales to 4K or longer videos, and whether the uneven patch-splitting strategy degrades on highly textured or rapidly changing content.

## Problem

Existing collaborative perception systems assume perfect inter-agent spatial transformations, making them highly vulnerable to real-world collaboration noises such as pose errors and transmission delay, which induce feature-level spatial misalignment that can degrade performance below the no-fusion baseline. Prior solutions are either model-specific integrated frameworks with high computational cost or plugins that address only one noise type, leaving no unified, model-agnostic mechanism to handle both noise sources simultaneously.

## Input / Output

The NEAT plugin takes the ego BEV feature F_e and the coordinate-transformed collaborator BEV feature F̃_i (both in C×H×W format) as its sole inputs, requiring no historical frames, co-visible object annotations, or additional sensor data. It outputs a spatially aligned collaborator BEV feature Z_i of the same C×H×W shape, which directly replaces F̃_i in the downstream feature fusion stage of any existing collaborative perception pipeline. The plugin adds only ~1.31M parameters and 5.11G MACs, making it a lightweight drop-in module.

## Method

NEAT performs dynamic feature alignment through three progressive components. First, the Importance-guided Query Proposal (IQP) generates a spatial-channel importance map by combining a convolutional decoder's spatial confidence with channel-wise average pooling saliency, then uses multi-scale collaborator views and the ego feature to select the top-δ% foreground locations as query proposals. Second, the Deformable Feature Alignment (DFA) component builds a naive fusion view via type-dependent projection and a general fusion operation to provide global object-related context, generates token embeddings by concatenating features from this view and the collaborator feature at query positions, and applies deformable cross-attention with learned 2D spatial offsets to aggregate multi-grained semantics from four attending features (three scales plus the fusion view) using only 5 sampled key points per query. Third, the Region Cross-attention Reinforcement (RCR) partitions the enhanced and original features into non-overlapping regions, uses confidence-prior-guided correlation to select the top-δ_r semantically relevant regions, and applies region cross-attention to diffuse locally aligned representations into a globally refined feature.

## Results

Under default noisy settings (0.2 m localization error, 0.2° heading error, 100 ms delay), NEAT provides consistent AP@0.7 gains across all four datasets: +8.85% (F-Cooper), +4.10% (CORE), +6.50% (AttFuse), +3.81% (Where2comm), and +8.78% (CoBEVT) on average. The best configuration, CoBEVT+NEAT, achieves 65.16 AP@0.7 on V2XSet, 75.41 on OPV2V, 34.97 on V2V4Real, and 58.10 on OPV2V Culver City, establishing SOTA on all four benchmarks. The plugin adds only ~1.31 M parameters and ~5.11 G MACs, making it substantially lighter than existing plugins SyncNet (3.80 M / 31.02 G) and CoAlign (2.94 M / 26.51 G).

## Baselines & Comparisons

NEAT consistently outperforms all five vanilla baselines (F-Cooper, CORE, AttFuse, Where2comm, CoBEVT) on every dataset and metric, with the largest gains on F-Cooper (+14.02 AP@0.7 on V2XSet) and CoBEVT (+10.86 AP@0.7 on OPV2V). Against integrated SOTA frameworks that implicitly handle noise (V2X-ViT, SCOPE, FFNet, CoBEVFlow), CoBEVT+NEAT surpasses all of them on all four datasets, e.g., 75.41 vs. 71.13 AP@0.7 on OPV2V (vs. SCOPE) and 34.97 vs. 30.63 on V2V4Real (vs. CoBEVFlow). Compared to existing plugins, NEAT delivers substantially larger improvements: on CoBEVT+OPV2V, NEAT yields 75.41 AP@0.7 versus 67.42 (SyncNet) and 69.21 (CoAlign), while adding only 1.31 M parameters versus 3.80 M (SyncNet) and 2.94 M (CoAlign). On the real-world V2V4Real dataset, NEAT-based AttFuse reaches 34.24 AP@0.7, exceeding both SyncNet (30.79) and CoAlign (31.37) by 3+ points, confirming its advantage in handling simultaneous pose errors and transmission delay.

## Relation to Prior Work

NEAT positions itself as a model-agnostic plugin that departs from two existing lines of work: (1) integrated frameworks (V2X-ViT, CoBEVT, SCOPE, FFNet, CoBEVFlow) that implicitly mitigate collaboration noise through larger receptive fields, multi-scale features, or temporal prediction at the cost of architectural entanglement and bandwidth overhead, and (2) noise-specific plugins (SyncNet for delay, CoAlign for pose errors) that each address only one type of mismatch. Conceptually, NEAT repurposes the deformable cross-attention mechanism from Deformable DETR [32]—originally designed for sparse spatial sampling in single-agent detection—into a query-aware feature alignment tool for collaborative perception, and introduces a region-level cross-attention refinement step that has no direct analogue in the prior collaborative perception literature.

## Why It Matters / Open Questions

The practical value is clear: a ~1.3M-parameter, ~5G-MAC plugin that can be inserted into any BEV-based collaborative perception pipeline and simultaneously handles both pose errors and transmission delay, with consistent gains across five architecturally diverse baselines and four datasets. The demonstration that SOTA methods can fall below the No-Fusion baseline under realistic noise levels is a useful caution for practitioners deploying collaborative systems. Open questions include whether the approach generalizes to camera-based or mixed-modality collaborative perception, whether it scales to more than two agents without additional overhead, and whether the heuristic threshold-based query selection (δ) can be made fully learned for adaptive noise conditions.

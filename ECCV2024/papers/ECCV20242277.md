## Problem

Existing CLIP-based OOD detection methods rely solely on textual in-distribution information (class-name text features as cosine classifiers), ignoring the visual ID information that CLIP's multimodal pretraining provides. This paper asks whether jointly matching both the ID text pattern and the ID visual pattern can unlock CLIP's full potential for OOD detection, and how to do so efficiently.
![Teaser figure](../imgs/ECCV20242277/cropped_page1_idx0.webp)

## Input / Output

At test time the method takes a single RGB image and compares its CLIP visual feature against two pre-computed patterns: a text pattern (K×C matrix of class-name text embeddings) and a visual pattern (K×K matrix of mean image-text softmax scores accumulated from n ID training samples per class). The output is a scalar DPM score (max text-matching logit minus β times the minimum KL-divergence visual-matching score), a binary ID/OOD decision against a threshold λ set at 95% ID recall, and per-class probability distributions from both the textual and visual matching branches. The visual pattern requires only a small number of ID samples (as few as 20 per class) to be effective.

## Method

DPM introduces a Domain-Specific Feature Aggregation (DSFA) module that re-weights CLIP's spatial feature map by text-feature similarity to suppress background and enhance foreground representations, without adding parameters. The visual pattern is constructed by averaging the full K-way softmax image-text matching scores over n ID samples per class, and the test image's visual matching score is computed as the KL divergence between its softmax distribution and each class's visual pattern. The final OOD score fuses the two modalities as max(text logits) − β·min(KL visual scores), where β balances visual and textual contributions. The training-free variant DPM-F uses this pipeline directly on frozen CLIP; the training-required variant DPM-T adds CoOp-style learnable prompts, linear projection layers on both visual and text features, and jointly optimizes a cross-entropy loss over both a text-guided matching branch and a visual-prototype matching branch (using EMA-updated class prototypes) to improve ID-OOD separability.

## Results

On CIFAR-100 (ID) with ViT-B-16, DPM-F achieves 85.32% average AUROC and 57.35% FPR95 across three OOD datasets, while DPM-T reaches 91.62% AUROC and 38.87% FPR95. On ImageNet-1K (ID) with ViT-B-16, DPM-F attains 92.78% AUROC and 29.59% FPR95, and DPM-T achieves 95.72% AUROC and 21.09% FPR95. DPM-T improves over DPM-F by +6.3% AUROC and −18.48% FPR95 on CIFAR-100, and by +2.94% AUROC and −8.50% FPR95 on ImageNet.

## Baselines & Comparisons

Among training-free methods on CIFAR-100, DPM-F (85.32% AUROC) substantially outperforms MCM (73.71%), MaxLogit (80.62%), and ReAct (65.42%), with the largest gap over MCM at +11.61% AUROC. Among training-required methods, DPM-T (91.62% AUROC, 38.87% FPR95) surpasses CLIPN-A (77.98%, 66.78%) by +13.64% AUROC and GROOD (86.36%, 55.61%) by +8.43% AUROC on CIFAR-100 with ViT-B-32. On ImageNet-1K, DPM-F (92.78% AUROC) edges out ReAct (92.06%) and MCM (89.47%), while DPM-T (95.72%) beats CLIPN-A (93.10%) by +2.62% AUROC. In the fine-tuning comparison (Table 10), DPM-T dominates CoOp+MaxLogit (87.94% avg AUROC), CALIP+MaxLogit (77.52%), and LoCoOp+GMCM (78.61%) on CIFAR-100 with ViT-B-32, achieving 94.79% average AUROC. DPM-F also shows strong robustness to covariate shift, outperforming MCM by +5.02% AUROC on ImageNet-R as ID and +4.20% on ImageNetV2 as ID.

## Relation to Prior Work

This paper extends CLIP-based OOD detection by introducing a dual-pattern matching framework that simultaneously leverages textual and visual in-distribution information, departing from prior methods (MCM, CLIPN, ZOC) that rely solely on text features as cosine classifiers. The domain-specific feature aggregation module is conceptually derived from CALIP's parameter-free attention mechanism, while the visual pattern construction modifies KNN-based OOD detection by storing per-class image-text matching score distributions rather than raw feature prototypes. The training-required variant (DPM-T) integrates CoOp-style learnable prompts and visual prototype matching from hyperspherical embedding work, creating a unified adaptation pipeline specifically optimized for OOD separability.

## Why It Matters / Open Questions

The finding that a training-free dual-pattern approach (DPM-F) can match or exceed training-required methods like CLIPN-A on CIFAR-100 suggests that the visual ID information previously discarded by CLIP-based OOD methods carries substantial signal, particularly under covariate shift where text-only matching fails. Open questions include whether the approach extends to truly zero-shot settings without any ID training samples, how it scales to open-world scenarios with thousands of classes, and whether the visual pattern (stored as per-class matching distributions) can be compressed or approximated for memory-constrained deployment. The paper acknowledges that textual feature enhancement (e.g., prompt engineering) remains unexplored as a complementary axis.

## Problem

Supervised local learning divides networks into gradient-isolated blocks to reduce memory and enable parallel updates, but each block only optimizes its local objective without access to information from subsequent blocks. This 'short-sightedness' causes a significant accuracy gap versus end-to-end training that widens as more blocks are used, because globally beneficial information is discarded at block boundaries.
![Teaser figure](../imgs/ECCV20240525/cropped_page1_idx0.webp)

## Input / Output

The method consumes standard RGB images (32×32 for CIFAR-10/SVHN, 96×96 for STL-10, 224×224 for ImageNet) and outputs a class label via the final block's classifier. The network is partitioned into K gradient-isolated local blocks; each of the first K−1 blocks feeds its output into a dedicated auxiliary network that produces a local supervisory signal, while the K-th block connects directly to the output head. The auxiliary networks are the only components that receive the ground-truth label for loss computation.

## Method

The Momentum Auxiliary Network (MAN) augments each auxiliary network with two mechanisms for inter-block communication: (1) an Exponential Moving Average (EMA, momentum 0.995) that blends the auxiliary network's parameters with those of the next local block's first layer after each gradient step, and (2) a learnable bias term that compensates for feature-space discrepancies between adjacent blocks. The update order per block is: gradient descent on the auxiliary network (with bias), EMA blending with the next block's parameters, then gradient descent on the local block itself. MAN is plug-and-play—it can be attached to any existing supervised local learning method (PredSim, DGL, InfoPro) with only ~1% additional GPU memory, and it reduces ImageNet GPU memory by over 45% relative to end-to-end training while matching or exceeding E2E accuracy.

## Results

On CIFAR-10 with ResNet-110 (K=55), MAN reduces test error by 3.45–6.72 points across all three baselines (e.g., DGL: 14.45→9.73, InfoPro: 13.22→9.77, PredSim: 24.74→18.02). On ImageNet, InfoPro* (K=4) with ResNet-101 achieves 21.73% Top-1 error, surpassing E2E (22.03%), and with ResNeXt-101,32×8d achieves 20.37% Top-1 error vs. E2E's 21.59%. GPU memory is reduced by over 45% on ImageNet (e.g., 10.69 GB vs. 19.71 GB for E2E on ResNet-101 with K=4) while achieving higher accuracy.

## Baselines & Comparisons

MAN is applied as a plug-and-play module on top of three supervised local learning baselines: PredSim, DGL, and InfoPro. On CIFAR-10 (ResNet-110, K=55), MAN reduces test error by 6.72 points for PredSim (24.74→18.02), 4.72 points for DGL (14.45→9.73), and 3.45 points for InfoPro (13.22→9.77). On STL-10, improvements range from 1.57 to 5.77 points depending on method and block count; on SVHN, from 0.84 to 2.23 points. On ImageNet, the most striking result is that InfoPro* (K=4) with ResNet-101 achieves 21.73% Top-1 error, beating E2E (22.03%), and with ResNeXt-101,32×8d achieves 20.37% vs. E2E's 21.59%—a 1.22-point improvement—while using roughly half the GPU memory (10.49 GB vs. 19.22 GB). DGL* on VGG13 (K=10) reduces Top-1 error from 35.60 to 31.99, closing most of the gap to E2E (28.41). Across all comparisons, MAN consistently wins against its corresponding baseline, with the largest relative gains observed for PredSim (the weakest baseline) and in deeper networks with more local blocks.

## Relation to Prior Work

This paper sits squarely within the supervised local learning lineage (InfoPro, DGL, PredSim), which partitions networks into gradient-isolated blocks each trained by a dedicated auxiliary network to avoid end-to-end backpropagation. Rather than proposing a new auxiliary network architecture or loss function, MAN repurposes the Exponential Moving Average mechanism (originally from momentum contrast for self-supervised learning) as a lightweight parameter-transfer channel between adjacent blocks, addressing the 'short-sightedness' problem that all prior local learning methods share. The addition of learnable biases to compensate for inter-block feature discrepancies is a small but effective complement, making MAN a plug-and-play module that can be grafted onto any existing supervised local learning framework without modifying its core design.

## Why It Matters / Open Questions

The practical significance is substantial: MAN reduces GPU memory by over 45% on ImageNet while matching or exceeding E2E accuracy on deeper backbones (ResNet-101/152, ResNeXt-101), offering a credible path toward scalable training without the full memory cost of global backpropagation. However, the authors acknowledge that on conventional datasets (CIFAR-10, STL-10) with many local blocks, MAN still trails E2E, suggesting the information bottleneck from using only the first layer of the next block is a real limitation. Open questions include whether deeper interaction layers or multi-layer EMA could close this remaining gap, and whether the approach extends to non-CNN architectures or tasks beyond image classification.

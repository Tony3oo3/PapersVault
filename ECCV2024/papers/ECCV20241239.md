## Problem

Multi-condition controllable image generation (e.g., combining text with depth maps, poses, or bounding boxes) assumes perfect alignment between all conditions. When alignment is partial, two failure modes emerge: dominance, where one condition overshadows others and omits text-specified objects, and ambiguity, where it is unclear which text object a condition should correspond to. No prior training-free method addresses this misalignment problem.

## Input / Output

The method takes a full text prompt, one or more image conditions (depth, normal, canny, pose maps, or GLIGEN bounding boxes), and a user-specified pair relationship function S(·) that maps each condition to a subset of text tokens it should govern. It operates entirely at inference time on a pretrained Stable Diffusion backbone with attached controllers (ControlNet, GLIGEN, or T2I Adapter), requiring no additional training. The output is a single generated image that satisfies both the full text description and all individual image conditions simultaneously.

## Method

TASC decomposes the standard classifier-free guidance score into a unified control term (full text, no image conditions) and K individual control terms (each condition paired with its designated text subset via S(·)), computed independently at every diffusion timestep to prevent dominance within each pair. To resolve conflicts that arise from computing these scores independently, an attention realignment operation replaces the cross-attention values of the unified score for tokens S(k) with the corresponding attention values from the k-th individual score, ensuring spatial consistency (e.g., a depth-constrained 'car' token does not also attend to unconstrained regions). The final score is a weighted sum of the unconditioned, realigned unified, and individual terms, used directly for DDPM/DDIM sampling. The approach is fully training-free, composable across different controller types, and compatible with existing object-preserving techniques like Attend-and-Excite.

## Results

On the MSCOCO evaluation set, TASC achieves the best CLIP score (0.3323), BLIP score (0.7388), and FID (107.39) among all compared methods, outperforming the strongest baseline Attend-and-Excite (A&E) by 0.007 CLIP, 0.0054 BLIP, and 4.02 FID. In terms of efficiency, TASC runs in 13.88 seconds with 9764 MB GPU memory, substantially faster and lighter than A&E (19.36 s, 18840 MB) while only modestly slower than vanilla Stable Diffusion (9.70 s, 7260 MB). In a user study with 81 participants, 71% preferred TASC-generated images over SD (11%), StructureDiffusion (7%), and A&E (11%).

## Baselines & Comparisons

TASC outperforms all three baselines on every quality metric. Compared to vanilla Stable Diffusion (SD), TASC improves CLIP by 0.039 and FID by 5.5 points, at the cost of roughly 43% more inference time and 34% more memory. Against StructureDiffusion (SSD), TASC gains 0.0395 CLIP and 5.18 FID while using less memory (9764 vs 8730 MB) and comparable speed. The most direct competitor is Attend-and-Excite (A&E), which also addresses missing objects via attention maximization; TASC beats A&E on all quality metrics (CLIP 0.3323 vs 0.3253, FID 107.39 vs 111.41) while being 28% faster (13.88 s vs 19.36 s) and using roughly half the GPU memory (9764 vs 18840 MB). On controllability retention (Table 2), TASC achieves a relative image-condition distance of only 1.6% with ControlNets versus 14.1% for A&E, and 4.34% vs 7.36% with GLIGEN, indicating substantially better preservation of the imposed spatial/structural constraints while still generating all text-specified objects.

## Relation to Prior Work

This paper builds directly on the multi-condition controllable generation stack (ControlNet, GLIGEN, T2I Adapter) and the score-composition lineage of Composable Diffusion, but departs from all of them by explicitly targeting the previously unaddressed failure mode of condition misalignment. The score composition formula generalizes Composable Diffusion's additive score decomposition by introducing pair-specific text subsets and per-condition weights, while the attention realignment operation is a novel cross-attention-level intervention not seen in prior work like Attend-and-Excite or StructureDiffusion, which modify attention for object presence or hierarchical text but not for resolving conflicts between independently computed conditional scores.

## Why It Matters / Open Questions

By making controllable generation robust to imperfectly aligned conditions, TASC removes a significant practical barrier: users no longer need to craft perfectly matched text-condition pairs, broadening the usable scenario space for tools like ControlNet and GLIGEN. The training-free, plug-and-play nature means it can be layered onto existing pipelines without retraining. Key limitations include the additional per-step computation (roughly 1.4× SD's time), the dependence on the base model's cross-attention quality for the realignment to work, and the open question of whether richer unified control signals (e.g., scene graphs) could replace the current text-as-bridge mechanism for more complex compositions.

## Problem

Existing atomic action recognition methods in multi-person videos either require manual cropping of a target individual or predict actions for all detected persons, making it impractical to retrieve the action of a specific person without labor-intensive post-processing. No prior work addresses the task of directly recognizing the atomic actions of a particular individual identified by a natural-language referring expression within a multi-person video.
![Teaser figure](../imgs/ECCV20240494/cropped_page1_idx0.webp)

## Input / Output

The method takes a 90-second video clip (from 127 movies in the AVA dataset) and a short textual referring expression describing one person's appearance, approximate age, gender, and relative position in the center frame—deliberately excluding any action description. It outputs multi-label atomic action predictions across 80 categories (Object Manipulation, Person Interactions, Person Movement) together with a 2D bounding box localizing the referred person in the center frame. The textual reference may contain broad positional cues (left/center/right) or fine-grained appearance details (hair color, clothing, accessories), and the model must disambiguate among multiple co-present individuals.

## Method

RefAtomNet processes three parallel token streams: visual tokens (ViT backbone + QFormer), textual reference tokens (BERT + QFormer), and a novel location-semantic stream that fuses DETR-predicted bounding box coordinates with BERT embeddings of detected object categories via a linear projection. The core innovation is a cross-stream agent attention fusion (CAAF) and cross-stream agent token fusion (CATF) mechanism, which redefines 2D agent attention into a 1D sequential format using fully connected layers instead of 2D pooling and depthwise convolutions. Agent query attention maps and agent tokens from the text and location-semantic streams are combined (via channel-wise and token-wise softmax-weighted averaging) with the visual stream's own attention maps to suppress irrelevant visual cues before computing the final visual token representation. The three refined streams are then averaged and fed into MLP heads for multi-label action classification (BCE loss) and bounding box regression (MSE loss), with the text encoder frozen during training.

## Results

On the RefAVA benchmark, RefAtomNet achieves 55.98% mAP and 69.73% AUROC on the validation set, and 57.52% mAP and 73.95% AUROC on the test set, with mIOU of 38.22% and 36.42% respectively. This outperforms the strongest baseline, BLIPv2, by 3.85% mAP and 3.17% AUROC on val, and by 4.33% mAP and 4.03% AUROC on test. The model also leads on localization (mIOU) by 5.23% on val and 3.67% on test over BLIPv2, indicating superior spatial grounding of the referred individual.

## Baselines & Comparisons

RefAtomNet outperforms all 17 baselines across every metric (mIOU, mAP, AUROC) on both val and test sets. The AAL group (I3D, X3D, MViTv2, VideoMAE2, Hiera) consistently fails at spatial localization (mIOU ≤ 0.76), confirming that action-localization architectures cannot ground a textual reference to the correct person; their best AUROC (X3D: 59.09/64.51) trails RefAtomNet by over 10 points. Among VQA and VTR baselines, BLIPv2 is the strongest competitor, reaching 52.13/53.19 mAP and 66.56/69.92 AUROC, yet RefAtomNet still leads by 3.85–4.33% mAP and 3.17–4.03% AUROC. The VOS baseline (Su et al.) matches BLIPv2 on mAP (52.17/53.20) but lags on mIOU (23.71/26.02), while the SF baselines (CLIP+SAM, CLIP+DETR, CLIP+REFCLIP) achieve moderate mAP (47.57–49.74) without the temporal reasoning of video-based methods. Ablations in Table 3 further show that the cross-stream agent attention fusion (CAAF) and agent token fusion (CATF) each contribute 1–2% mAP gains, and the location-semantic stream (LSAS) is critical for mIOU, improving it by 6.32 points on val over its absence.

## Relation to Prior Work

This paper carves out a new task at the intersection of referring scene understanding and atomic action localization. It builds on BLIP-2's QFormer architecture as the visual-textual integration backbone and redefines the agent attention mechanism from Han et al. for cross-stream (1D sequential) compatibility, replacing 2D pooling and depthwise convolutions with linear projections. Conceptually, it departs from prior referring understanding work (ROD, RVOS, RMOT) which targets objects rather than human actions, and from atomic action localization methods that predict for all individuals or require manual cropping, by introducing a textual reference that selects a specific person end-to-end.

## Why It Matters / Open Questions

The RAVAR task and RefAVA benchmark (36,630 instances across 127 movies) address a practical gap in assistive systems and human-robot interaction where one must identify what a specific, textually-described person is doing without post-processing predictions for all individuals. The finding that 15 baselines from AAL, VQA, VTR, and VOS all underperform confirms the task is genuinely distinct and not reducible to existing formulations. Open questions include scalability to longer videos, more diverse or compositional action categories, and whether the location-semantic stream generalizes beyond the DETR-based object detection used here. The moderate improvements over BLIPv2 (~3–4% mAP/AUROC) suggest the task still has substantial headroom.

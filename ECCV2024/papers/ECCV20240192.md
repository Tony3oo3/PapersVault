## Problem

While generative models have transformed image, text, and audio creation, automated web visual design remains largely unexplored. Existing efforts target isolated subtasks (layout, font, color) rather than producing a holistic visual presentation from scratch, and the complexity of CSS coding practices makes direct CSS generation intractable. This paper introduces WebRPG, a new task that automates the generation of standardized rendering parameters for every web element given only its HTML code.
![Teaser figure](../imgs/ECCV20240192/cropped_page1_idx0.webp)

## Input / Output

The input is the HTML code of a sub-page (32–128 child elements, token length ≤ 512) extracted from the Klarna e-commerce dataset, with elements ordered by DOM preorder traversal. The output is a set of 13 rendering parameters per element spanning layout (left, top, width, height in integer pixels), text (font-style, font-weight, font-size, line-height, text-align, text-decoration, text-transform), and color (color, background-color from a 46-color vocabulary), yielding a total RP vocabulary of 1,993 discrete values. Images are excluded (only <img> tags are preserved as placeholders), and the model operates purely on structured text/HTML rather than pixel data.

## Method

The core architecture compresses the 13 RPs of each element into a 128-dim latent vector via a 5-layer MLP VAE (pre-trained on synthetic data to cover diverse appearance combinations), so the generative model's sequence length scales only with the number of elements S rather than S×W. A custom HTML embedding concatenates three projected components: semantic (frozen MarkupLM_large with average pooling), hierarchical (XPath embedding layer from MarkupLM), and character count (learned embedding of raw character count), capturing content, DOM structure, and size cues simultaneously. Two ~50M-parameter Transformer backbones are explored: an autoregressive model that uses a MaskGIT-style masked latent vector (partially replacing real latents with a learnable MASK during training) for stability, and a diffusion model operating in the VAE latent space. Both are trained jointly with the VAE for 1M steps (batch 300, AdamW lr 1.2e-4), and the autoregressive variant substantially outperforms the diffusion variant, which the authors attribute to the non-Euclidean hierarchical structure of web elements and the need for fine-grained per-element control.

## Results

WebRPG-AR achieves an Overall FID of 0.1281, Layout FID of 0.1520, Element IoU of 0.7082, Style FID of 0.2124, and SC Score of 0.9474 on the Klarna-based WebRPG test set, approaching the real-page reference (FID 0.0027, Ele.IoU 1.0000, SC Score 1.0000). In stark contrast, the diffusion baseline (WebRPG-DM) yields an Overall FID of 62.021 and Ele.IoU of only 0.0357, while the strongest LLM (GPT-4) reaches FID 4.2141 and Ele.IoU 0.0347. The autoregressive model's Ele.IoU of 0.7082 is roughly 20× higher than any other method, indicating it is the only approach that produces coherent spatial layouts.

## Baselines & Comparisons

WebRPG-AR decisively outperforms all four LLM baselines (GPT-4, StarCoder2-7b, DeepSeek-Coder-6.7b, CodeLlama-13b) on every metric. On layout, the gap is most dramatic: WebRPG-AR's Ele.IoU of 0.7082 exceeds GPT-4's 0.0347 by over 20×, and all LLMs cluster near the Plain HTML baseline (0.0354), indicating they fail to produce meaningful spatial arrangements. On style, WebRPG-AR's SC Score of 0.9474 far surpasses GPT-4's 0.5515 and the open-source LLMs (0.36–0.39), showing it preserves Gestalt-style consistency among elements. Among LLMs, GPT-4 is the strongest (FID 4.21 vs. 5.82–11.90 for open-source models) and handles simple style cues like button colors, but still degrades to vertical-only layouts on complex HTML. The diffusion baseline (WebRPG-DM) performs at or below Plain HTML on all metrics (FID 62.02, Ele.IoU 0.0357), suggesting diffusion is ill-suited to the non-Euclidean, hierarchical structure of web elements.

## Relation to Prior Work

This paper departs from prior graphic design generation work (advertising, magazines, UI layouts) that restricts designs to ≤25 elements represented as flat 1D token sequences, and from web design subtask approaches (layout optimization, font recommendation, colorization) that address only isolated aspects of visual presentation. It builds on MaskGIT's masked latent vector scheduling for the autoregressive baseline and on MarkupLM's pre-trained semantic and XPath embeddings to construct a three-faceted HTML encoding (semantic, hierarchical, character count). The key methodological departure is the use of a VAE to compress per-element rendering parameters into latent vectors, avoiding the prohibitively long sequences that flat representations would require for hundreds of elements.

## Why It Matters / Open Questions

WebRPG establishes the first benchmark and task formulation for holistic web visual presentation generation from HTML, filling a gap where prior work only addressed individual subtasks or limited element counts. The finding that diffusion models fail catastrophically (FID ~62 vs. 0.13 for autoregressive) on this hierarchical, non-Euclidean structure is a useful cautionary result for applying diffusion to structured data. Open questions include extending to pages with images, supporting partial/interactive design control, generalizing beyond the e-commerce domain, and integrating with LLM-generated HTML for fully automated web development workflows.

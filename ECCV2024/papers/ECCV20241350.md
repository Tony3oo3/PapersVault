## Problem

Existing SDF-based hand-object reconstruction methods rely primarily on 2D visual features, which are ill-posed for fine-grained shape modeling in cluttered scenes due to depth ambiguity, self-occlusion, and appearance similarity, often producing mesh collapse or inadvertent merging of adjacent objects. Additionally, dense SDF evaluation over voxelized 3D space incurs substantial computational cost from redundant queries at points far from the hand-object surface.

## Input / Output

The method takes a single RGB-D image pair (cropped to 256×256) along with camera intrinsics, and produces 3D hand and object meshes extracted via Marching Cubes at 128×128×128 resolution. The depth image is used to lift 2D visual features into 3D point cloud space, and the RGB modality provides global semantic context; the two are fused via a spatial attention mechanism before any SDF modeling occurs.

## Method

The framework decouples SDF learning into a coarse-to-fine pipeline that progressively exploits visual and geometric modalities. At the coarse level, a global SDF decoder conditioned on RGB-D global image features produces initial signed distances, which are then used to assign point-level semantic labels (hand/object/background) to the depth point cloud, filtering noise and enriching it with holistic scene context. At the fine level, a 3D Point-Aligned Implicit Function (3D PIFu) replaces the 2D pixel-aligned feature of PIFu with an adaptive weighted aggregation of K=16 nearest 3D point features, where weights depend on both Euclidean distance to the query point and the coarse SDF value, enabling local geometric perception while retaining global semantic priors. A Surface-Aware Efficient Reconstruction (SER) strategy further reduces inference cost by predicting a volumetric semantic heatmap, supplementing it with MANO hand vertices and object symmetry points, and restricting SDF queries to voxels near the predicted surface, cutting sampling points from 2.1M to ~90K while preserving accuracy.

## Results

On the ObMan dataset, the method achieves a hand Chamfer distance of 0.083 cm² and object Chamfer distance of 0.51 cm², substantially outperforming the previous SOTA gSDF (0.112 cm² and 3.14 cm² respectively). For object F-scores, the method reaches F_o@5 = 0.780 and F_o@10 = 0.891, compared to gSDF's 0.438 and 0.660. On DexYCB, the method achieves CD_h = 0.267 cm², F_h@1 = 0.185, CD_o = 1.24 cm², and F_o@10 = 0.764, again leading all baselines across every metric.

## Baselines & Comparisons

The method outperforms all six baselines on every reported metric for both hand and object reconstruction. Against the closest competitor gSDF [9] (CVPR 2023), the improvement is most dramatic on object Chamfer distance on ObMan (0.51 vs. 3.14 cm², a 6× reduction) and object F_o@10 (0.891 vs. 0.660). On DexYCB, the gap over gSDF is more moderate but consistent: CD_h improves from 0.302 to 0.267 cm² and CD_o from 1.55 to 1.24 cm². AlignSDF [10] (ECCV 2022) and Grasping Field [27] (3DV 2020) trail further behind, with AlignSDF achieving CD_o = 3.38 cm² on ObMan versus the proposed 0.51. The object-only methods (Ye et al. [59], DDF-HO [61]) report only partial metrics but are clearly surpassed on the overlapping F-score columns. The method also achieves faster reconstruction (1.26 s) than gSDF (1.51 s) despite using an additional depth modality, thanks to the surface-aware sparse query strategy.

## Relation to Prior Work

This paper extends the Pixel-Aligned Implicit Function (PIFu) paradigm from 2D pixel-aligned features to a 3D Point-Aligned Implicit Function (3D PIFu), replacing bilinear image sampling with adaptive aggregation over 3D neighborhood point cloud features. It departs from prior SDF-based hand-object reconstruction methods (gSDF, AlignSDF, Grasping Field) that model the implicit field directly from 2D visual features, by introducing a coarse-to-fine strategy where a global visual SDF first refines point cloud semantics before fine-level geometric SDF learning. The 2D-3D projection for feature lifting follows the approach of Ren et al. (AAAI 2023), and the surface-aware sparse query strategy builds on the observation that dense voxelized SDF evaluation wastes computation on empty regions.

## Why It Matters / Open Questions

The coarse-to-fine RGB-D strategy addresses a practical failure mode of existing SDF methods—mesh collapse and merging in cluttered scenes with depth ambiguity—by progressively grounding the implicit field in both global visual context and local geometric structure. The surface-aware efficient reconstruction reduces inference time from 3.44s to 1.26s while maintaining accuracy, making RGB-D hand-object reconstruction more viable for real-time AR/VR applications. A key open question is the lack of explicit physical constraint modeling (penetration, contact), which the authors acknowledge as a limitation; integrating differentiable physics into the implicit representation remains an important direction for producing physically plausible grasps.

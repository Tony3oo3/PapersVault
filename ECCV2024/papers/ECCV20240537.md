## Problem

Public datasets are vulnerable to unauthorized commercial use and test-data cheating, but existing detection methods (backdoor attacks, data poisoning, radioactive data) are model-dependent, require reference models, produce visible watermarks, or rely on unreliable intentional-degradation signals whose probability is inversely tied to model accuracy. The paper asks whether a clean-labeled, model-agnostic, black-box-verifiable watermark can be embedded that leaves no trace on the target task yet provides irrefutable evidence of misuse.

## Input / Output

The DWN takes a pair of images (x from the target dataset, z from an auxiliary dataset) whose class labels are matched via modulo pairing, and produces a watermarked image x̂ that is visually indistinguishable from x (SSIM ≈ 0.98). The watermark is extracted post-hoc as w = x̂ − x + μ(X), where μ(X) is the dataset mean, yielding a class-specific bias image. Verification is strictly black-box: only one-hot predicted classes from the suspect model on μ(X)+w are needed, and a mean class accuracy (mAcc) exceeding the threshold 2/N_cls^w flags the model as a cheater.

## Method

The core insight is that DNNs inadvertently learn class-correlated biases (e.g., sea backgrounds for 'ship') and can classify bias-only inputs; the paper deliberately exploits this by embedding class-wise hidden bias from an auxiliary dataset into the target data. The Dataset Watermarking Network (DWN) comprises two autoencoders—a hiding encoder G_w that fuses (x, z) into x̂ ≈ x, and a reconstruction decoder G_r that recovers x′ and z′ from x̂—plus two lightweight CNN classifiers (H_x, H_w) with spatial dropout serving as perceptual constraints. All components are jointly trained with L1 reconstruction losses and cross-entropy losses, ensuring x̂ preserves the target class while the residual w encodes the auxiliary class identity. Because the watermark is a natural-image-like pattern (not a geometric trigger), it is robust to horizontal/vertical flips and other spatial augmentations, and because it is clean-labeled and requires no reference model, verification works across arbitrary architectures (ResNet, MobileNetV2, EfficientNet, PVTv2, ResMLP, PiT) and tasks (classification, fine-grained classification, segmentation) under a strict black-box protocol.

## Results

On CIFAR-10, the proposed undercover bias achieves 92.63% validation accuracy on benign data (vs. 94.07% clean) while attaining 62.14% mAcc on watermarks, compared to near-chance levels for clean models. The method achieves the highest SSIM (0.9785) among all clean-labeled approaches and the fastest watermarking time (1.07e-3 sec/image), roughly 100× faster than Sleeper Agent (1.27 sec/image). Across CIFAR-100, FER2013, and Fashion-MNIST, the proposed method consistently outperforms Sleeper Agent and Gradient Matching on both harmlessness (validation accuracy on benign data) and verifiability (mAcc on watermark), with 100% accuracy in distinguishing cheating from clean models at the 2/N_cls threshold.

## Baselines & Comparisons

The proposed method is the only approach that simultaneously satisfies all four desirable properties: clean-labeled, model-agnostic, unlimited verification, and high invisibility (SSIM 0.9785). Among clean-labeled backdoor attacks, Hidden Trigger consistently failed across all architectures, while Sleeper Agent achieved marginal ASR only for the known ResNet18 architecture but failed for unseen MobileNetV2. Data poisoning methods (PoisonFrogs, MetaPoison, Bullseye) were largely unsuccessful, with only Gradient Matching achieving meaningful ASR (32% on CIFAR-100, 47.6% on FER2013) but at the cost of significantly lower benign validation accuracy (66.53% vs. 68.27% for proposed on CIFAR-100). Radioactive Data, while achieving decent SSIM (0.9202), requires access to output logits (violating the black-box assumption) and a reference model. The proposed method achieves 30.35% mAcc on watermarks for CIFAR-100 and 38.15% for FER2013, far exceeding the 2/N_cls threshold, while maintaining within 3.5% of clean validation accuracy.

## Relation to Prior Work

This paper departs from the three dominant paradigms for dataset copyright protection—backdoor attacks (trigger-based misclassification), data poisoning (targeted latent-space shifts), and radioactive data (adversarial perturbation toward an isotropic vector)—by repurposing the well-documented phenomenon of data bias as a verification signal. Rather than relying on intentional degradation (which the authors argue is unreliable because its probability is inversely tied to model accuracy on clean data), the method embeds class-wise hidden biases via a deep steganography network (building on Baluja's deep steganography [4]) so that trained models covertly learn to classify the watermarks themselves. The key conceptual shift is treating bias, typically a target of debiasing research, as a deliberate and beneficial watermarking mechanism.

## Why It Matters / Open Questions

The method offers a practical black-box verification protocol (requiring only predicted classes, not logits or architecture access) that is model-agnostic, clean-labeled, and supports unlimited verification images—addressing concrete limitations of all prior approaches simultaneously. Its limitation to ordinal/numerical data (not nominal data like text) and the slight performance degradation on the target task are acknowledged but modest. Open questions include robustness against debiasing defenses that a malicious user might apply, applicability to non-image modalities, and whether the threshold criterion (2/N_cls) remains safe under distributional shifts in the auxiliary dataset.

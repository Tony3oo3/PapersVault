## Problem

Existing egocentric action datasets provide only verb-noun labels (e.g., 'wash trouser with brush') that lack the detail needed for diffusion models to learn action state transitions, and diffusion-based image manipulation models are pre-trained on exocentric (third-person) images, creating a domain gap that prevents faithful generation of egocentric action frames. This paper introduces the novel problem of egocentric action frame generation: synthesizing a single image that visually depicts how an action should be executed from the camera wearer's perspective, conditioned on a user prompt and the current egocentric scene.

## Input / Output

The model takes a 256×256 egocentric RGB image frame (sampled δ_i seconds before the action begins) and a short user action prompt (e.g., 'wash the trouser with the brush') as input. It produces a 256×256 egocentric action frame image (sampled δ_o seconds after the action begins) that depicts the action execution while preserving the background context, along with an enriched natural-language action description generated by the VLLM. The input frame is encoded by a pre-trained autoencoder and concatenated with Gaussian noise to form the diffusion UNet input, while the prompt is expanded into a detailed multi-step description before conditioning the generation.

## Method

LEGO combines a visually instruction-tuned VLLM (initialized from LLaVA) with a latent diffusion model in a two-stage pipeline. First, the VLLM is finetuned for 3 epochs using GPT-3.5-curated enriched action descriptions to expand short action labels into detailed, context-aware descriptions conditioned on the egocentric image. Second, the LDM's denoising U-Net is conditioned on three signals via cross-attention: (1) the CLIP text encoding of the enriched description, (2) the VLLM image embedding projected through a linear layer into LDM feature space, and (3) the VLLM text embedding passed through a projection layer followed by self-attention layers to capture holistic semantics. The key insight is that the VLLM image and text embeddings, learned during visual instruction tuning on egocentric data, encode high-level semantic information about action state transitions that neither the autoencoder latent nor the CLIP text encoder captures, thereby bridging the exocentric-to-egocentric domain gap. The LDM is finetuned for 20,000 iterations with L2 noise-prediction loss while keeping the text encoder frozen, and classifier-free guidance is applied at inference.

## Results

On Ego4D, LEGO achieves an EgoVLP score of 65.65 and EgoVLP+ score of 80.44, outperforming the strongest baseline IP2P (62.19 / 78.84) by 3.46% and 1.60% respectively. On Epic-Kitchens-100, LEGO reaches EgoVLP 45.89 and EgoVLP+ 62.66 versus IP2P's 42.97 / 61.06. In the user study, LEGO is preferred over the best baseline by 44.00% on Ego4D and 38.34% on Epic-Kitchens, indicating a substantial perceptual advantage beyond what automatic metrics capture.

## Baselines & Comparisons

LEGO consistently outperforms all three baselines on both datasets across the primary egocentric metrics (EgoVLP, EgoVLP+, CLIP). Against the strongest baseline IP2P, LEGO gains 3.46% in EgoVLP and 1.60% in EgoVLP+ on Ego4D, and 2.92% and 1.60% respectively on Epic-Kitchens. ProxEdit and SDEdit perform substantially worse (e.g., EgoVLP 44.51 and 50.07 vs. LEGO's 65.65 on Ego4D), confirming that inversion-based editing methods struggle with egocentric action state transitions. LEGO slightly trails IP2P on FID for Epic-Kitchens (21.57 vs. 20.64), the only metric where it does not lead. In the user study, LEGO's win rate exceeds the best baseline by 44.00% (Ego4D) and 38.34% (Epic-Kitchens), a gap far larger than what automatic metrics suggest, highlighting the perceptual quality advantage of the VLLM-embedded conditioning.

## Relation to Prior Work

This paper sits at the intersection of text-guided image editing (InstructPix2Pix, SDEdit, ProxEdit) and egocentric vision-language modeling (EgoVLP, LLaVA). It departs from prior diffusion-based editing methods in two key ways: (1) it uses GPT-3.5-curated enriched action descriptions rather than sparse verb-noun labels, and (2) it injects image and text embeddings from a visually instruction-tuned VLLM (initialized from LLaVA) as additional cross-attention conditioning into the latent diffusion U-Net, rather than relying solely on standard CLIP text embeddings. This design specifically targets the domain gap between exocentric pre-training data and egocentric action state transition, a gap that prior inversion-based or end-to-end editing methods do not address.

## Why It Matters / Open Questions

The paper introduces a practically motivated problem—generating visual action guidance from an egocentric viewpoint for AR-based skill transfer—and provides the first systematic treatment of it. However, limitations temper the impact: generation is restricted to 256×256 resolution, evaluation relies on only two datasets, and the image-to-text metric (BLIP-based) still suffers from the same domain gap the paper tries to solve. Open questions include whether the VLLM-embedding conditioning strategy generalizes to video-level action generation, higher resolutions, or real-time inference on wearable devices, and whether the modest automatic-metric gains (≈3% EgoVLP) will hold as baselines improve.

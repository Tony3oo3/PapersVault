## Problem

Existing methods that augment image classification with synthetic images from diffusion models require generating a disproportionately large number of images (e.g., 1.2 million for ImageNet) for only marginal accuracy gains (~1.78%), making them computationally impractical. The core inefficiency stems from unrestricted, model-agnostic generation that produces many redundant samples irrelevant to the classifier's actual weaknesses.
![Teaser figure](../imgs/ECCV20241280/cropped_page1_idx0.webp)

## Input / Output

The method takes misclassified validation images (partitioned from the training set, 10K for ImageNet) as visual guides, a fixed text prompt per class ('a photo of <class>'), and the current classification model's logits for adversarial loss computation. It produces 512×512 synthetic images (256×256 for few-shot) via Stable Diffusion V2.1 or GLIDE, generated in batches of 64 per GPU after each training epoch during the first half of training. The generated images preserve the foreground object of the guide while varying the background scene.

## Method

ActGen is a training-aware active generation framework that identifies hard samples by monitoring misclassifications on a validation set and uses them as guides for targeted diffusion-based image synthesis. The key mechanism is attentive image guidance: at each DDPM denoising step, the generated latent is perturbed toward the guide image's latent, but only within foreground regions identified by cross-attention masks from the UNet, preserving the object while allowing background diversity. A gradient-based guidance mechanism further refines generation by performing one-step gradient descent on the text embedding at each timestep, driven by two losses: a contrastive loss against a memory bank of previously generated latents (to reduce redundancy) and a negative cross-entropy loss against the current classifier (to increase classification difficulty). This unified approach achieves 2.26% accuracy improvement on ImageNet with ResNet-50 using only 0.13M synthetic images, compared to 1.2M images for prior work.

## Results

On ImageNet, ActGen achieves 78.65% top-1 accuracy with ResNet-50 (+2.26% over real-only baseline) using only 0.13M synthetic images (10% of real data), outperforming Azizi et al. which requires 1.2M synthetic images (94% of real data) for 78.17%. On CIFAR-10/100 with ResNet-50, ActGen reaches 95.53%/77.33% top-1 accuracy, surpassing all baselines. On EuroSAT few-shot classification, ActGen with 2K generated samples outperforms the 2K Real guidance baseline across all shot settings (e.g., 77.81% vs 75.72% at 2-shot).

## Baselines & Comparisons

Against Azizi et al. [1], ActGen achieves higher top-1 accuracy on all four ImageNet architectures while generating only 10% of the synthetic images (0.13M vs 1.2M); for example, ResNet-50 reaches 78.65% vs 78.17%, a 0.48% gain with ~1M fewer generated images. On CIFAR-10/100, ActGen (95.53%/77.33% with ResNet-50) outperforms Azizi et al. (95.18%/77.07%), Real guidance [18] (95.22%/76.83%), and Da-Fusion [43] (95.14%/76.26%). On EuroSAT few-shot classification, ActGen with 2K generated samples beats Real guidance [18] at every shot level (e.g., 77.81% vs 75.72% at 2-shot, 87.25% vs 86.27% at 16-shot) and substantially outperforms Da-Fusion [43] (e.g., 81.77% vs 66.90% at 4-shot). The SD random baseline, which uses the same active generation strategy but without attentive image guidance or gradient-based guidance, yields only marginal gains (+0.25% on ResNet-50 ImageNet), confirming that the proposed guidance mechanisms are critical for effective sample-efficient generation.

## Relation to Prior Work

ActGen extends the diffusion-based synthetic data augmentation line (Azizi et al., He et al., Trabucco et al.) by replacing their two-stage 'generate-then-train' pipeline with a training-aware, active-learning loop that generates images only for samples the current model misclassifies. The attentive image guidance mechanism repurposes the classifier-free guidance formulation (Ho & Salimans) from text conditioning to image conditioning, and borrows cross-attention masks from Attend-and-excite (Chefer et al.) to restrict perturbation to foreground regions. The gradient-based guidance—updating text embeddings via backpropagated contrastive and adversarial losses through the denoising chain—is a novel control mechanism not present in prior diffusion-augmentation work.

## Why It Matters / Open Questions

The central practical takeaway is that 10% of the synthetic images used by prior state-of-the-art (0.13M vs. 1.2M on ImageNet) yields *better* accuracy, reframing the field's assumption that more synthetic data monotonically helps. This efficiency gain is validated across four architectures and four datasets, making it a credible and actionable result for practitioners constrained by compute budgets. Open questions include whether the active-generation loop transfers to dense prediction tasks (detection, segmentation), how sensitive performance is to the validation-set partitioning strategy, and whether the approach remains effective when the base classifier is already near saturation.

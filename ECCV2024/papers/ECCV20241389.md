## Problem

Existing view-based 3D object recognition methods aggregate multi-view features into a single global representation, which degrades sharply under arbitrary views where viewpoint positions, quantities, and object poses vary per object. This misalignment makes robust feature aggregation difficult, and joint optimization of extraction and aggregation can cause the network to over-focus on certain views while discarding information from others.
![Teaser figure](../imgs/ECCV20241389/cropped_page1_idx0.webp)

## Input / Output

The method takes a variable number of rendered RGB views (10–20 for arbitrary-view settings, fixed for aligned/rotated) of a single 3D object as input, with no requirement that views be pose-aligned or uniformly sampled. The output is a class label obtained by averaging softmax predictions from L=16 global part tokens, rather than from a single aggregated feature vector. A secondary output is M=64 per-view attention maps that localize discriminative regions within each rendered image.

## Method

PANet replaces global view aggregation with a part-based representation in three stages. First, a shared-weight ResNet50 encodes each view, a Cross-View Association (CVA) module enriches each view's feature map with information from other views via dot-product attention, and M attention maps per view sample local part features into a multi-view part sequence T. Second, an Adaptive Part Refinement (APR) transformer block takes L learnable part tokens concatenated with T and refines them into global part features that are invariant to viewpoint changes. Third, the L global parts are jointly used for classification by averaging their individual softmax predictions. Training combines a standard cross-entropy loss on the averaged global-part prediction with a part-aware loss (L_awe) that forces each view's M local parts to also be classifiable, encouraging diverse and object-focused part features without requiring any part-level annotations.

## Results

On ScanObjectNN, PANet achieves 93.21% class / 93.99% instance accuracy under aligned views and 84.08% / 86.45% under arbitrary views (10–20 random views per object), dramatically outperforming CVR (68.07% / 71.36%) in the arbitrary setting. On ModelNet40, PANet reaches 96.60% class / 97.73% instance accuracy (aligned) and 96.37% / 97.53% (free viewpoints), surpassing View-GCN++ (96.50% / 97.60%) and CVR (95.77% / 97.16%). On the RGBD dataset with 4–12 arbitrary views, PANet attains 95.9% instance accuracy, exceeding CVR (91.8%) by 4.1%.

## Baselines & Comparisons

PANet outperforms all 26 baselines across the three datasets in the aligned and arbitrary view settings. The most striking comparison is against CVR [55] under arbitrary views: PANet gains +16.01% class and +15.09% instance accuracy on ScanObjectNN (84.08/86.45 vs. 68.07/71.36), and +6.68% class / +5.32% instance on ModelNet40 (90.69/92.23 vs. 84.01/86.91). Against the strongest fixed-view baselines, View-GCN++ [57] and CVR [55], PANet leads by 4.11% class accuracy on aligned ScanObjectNN (93.21 vs. 89.10) and by 0.10–0.83% on aligned ModelNet40. On rotated ModelNet40, CVR [55] narrowly edges PANet on class accuracy (91.12 vs. 90.35) but PANet wins on instance accuracy (92.87 vs. 92.22); all other view-based baselines (MVCNN, GVCNN, RotationNet, View-GCN) are clearly behind. Point-based methods (PointNet++ [43], DGCNN [54]) trail PANet by 9–11% on ScanObjectNN and 3–5% on ModelNet40, confirming the advantage of the view-based part representation over direct point-cloud processing.

## Relation to Prior Work

This paper departs from the dominant view-aggregation paradigm in multi-view 3D recognition (MVCNN, GVCNN, View-GCN, DRCNN, CVR), which fuses per-view features into a single global descriptor. Instead, it repurposes weakly supervised part localization techniques from 2D fine-grained recognition (CAM, RACNN, MACNN, WSDAN) and combines them with transformer-based learnable part tokens (inspired by DETR/Mask2Former) to build a part-based 3D representation. The closest prior work addressing arbitrary views is CVR, which restores canonical alignment before aggregation; PANet avoids alignment entirely by operating on parts that are inherently viewpoint-invariant. The Cross-View Association module and the part-aware loss are novel components not present in prior part-localization or view-aggregation methods.

## Why It Matters / Open Questions

Arbitrary views (variable count, unaligned poses, varying positions) is a realistic deployment setting that prior view-based methods handle poorly, as evidenced by CVR's 20-point drop on ScanObjectNN. PANet's ability to match or exceed fixed-view SOTA under this harder setting suggests part-based representations may be a more robust inductive bias for 3D recognition than global view aggregation. Limitations include evaluation only on classification (not detection or retrieval), reliance on clean rendered views rather than noisy real captures, and a limited set of arbitrary-view baselines (only CVR). Open questions include whether the part-based formulation transfers to other 3D tasks (segmentation, retrieval) and whether it remains effective with very few views or highly occluded objects.

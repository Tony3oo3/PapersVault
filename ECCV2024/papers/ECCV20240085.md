## Problem

Object counting methods depend on expensive manual annotations, and existing unsupervised approaches are restricted to crowd counting. The paper asks whether text-to-image latent diffusion models (LDMs) can generate the synthetic data needed to train counting networks for arbitrary object categories without any human annotation, despite LDMs' well-known inability to produce images with exact object counts from text prompts.
![Teaser figure](../imgs/ECCV20240085/cropped_page1_idx0.webp)

## Input / Output

The method takes a single RGB image of arbitrary resolution as input and produces both a scalar object count and a spatial count map localizing where objects appear. At inference, the density classifier partitions dense regions into a 3×3 grid of patches, which are extracted at the original (higher) image resolution rather than the fixed network input size, preserving high-frequency detail. The method is category-agnostic: the only user-specified parameter is the object category name, which is embedded in the text prompts used to generate synthetic training data.

## Method

The pipeline has three stages, all driven by Stable Diffusion-generated synthetic data. First, a sorting network is pre-trained on image triplets (fewer / original / more objects) created by inpainting and outpainting real images, using a RankSim-style ranking similarity loss that aligns feature-space and prediction-space orderings without requiring exact count labels. Second, only a linear head is fine-tuned on top of the frozen sorting network using synthetic counting data (images prompted with approximate counts), with a CleanNet-inspired prototype-based filter removing noisy samples; this preserves the object-quantity features learned during sorting. Third, a density classification head (also a linear layer on the frozen backbone) is trained on synthetic density-category images and used at inference to identify dense regions, which are then partitioned into 3×3 patches and re-counted at higher resolution, while sparse regions use the full-image count map directly.

## Results

On crowd counting benchmarks, AFreeCA achieves MAE of 35.0 on SHB, 173.8 on JHU-Crowd++, 152.7 on ShanghaiTechA, and 283.1 on UCF-QNRF, outperforming all unsupervised and zero-shot baselines. On the CARPK vehicle counting dataset, it reaches MAE 9.35 and MSE 12.29, surpassing the best few-shot method (BMNet+, MAE 10.44) and zero-shot CLIP-Count (MAE 11.96). On the penguin counting dataset, the method reports MAE 5.1 and MSE 8.0. Performance remains substantially below fully supervised methods (e.g., GauNet achieves MAE 6.2 on SHB vs. 35.0 for AFreeCA).

## Baselines & Comparisons

Against the closest unsupervised competitor CrowdCLIP [18], AFreeCA wins on SHB (MAE 35.0 vs. 69.3), JHU (173.8 vs. 213.7), and QNRF (283.1 vs. 283.3, a near-tie), but loses on ShanghaiTechA MAE (152.7 vs. 146.1). Against CSS-CCNN++ [2], AFreeCA achieves substantially lower MAE on JHU (173.8 vs. 197.9), SHA (152.7 vs. 195.6), and QNRF (283.1 vs. 414.0). Against the zero-shot CLIP-Count [13], AFreeCA improves SHB MAE from 45.7 to 35.0 and SHA MAE from 192.6 to 152.7. On CARPK, AFreeCA (MAE 9.35) outperforms both few-shot BMNet+ (10.44) and zero-shot CLIP-Count (11.96), as well as the weaker few-shot FamNet (28.84). All fully supervised baselines (GauNet, GLoss, ADSCNet) remain far ahead, with SHB MAE in the 6–7 range versus 35.0 for AFreeCA, confirming the annotation-free trade-off.

## Relation to Prior Work

This paper extends the unsupervised counting line (CSS-CCNN, CrowdCLIP) which was previously restricted to crowd scenes, by leveraging Stable Diffusion to generate synthetic training signals for arbitrary object categories. Methodologically, it builds on RankSim's ranking-similarity loss for the sorting pre-training stage and adapts CleanNet's prototype-based filtering to mitigate label noise in LDM-generated counting data. The key departure from prior LDM-for-vision work (which focused on recognition) is the two-stage strategy: first learning count-ordered features via object add/remove triplets, then anchoring those features to absolute counts with only a linear probe, preserving feature integrity against noisy synthetic labels.

## Why It Matters / Open Questions

This is the first unsupervised counting method that generalizes beyond crowds to arbitrary categories (vehicles, penguins, flamingos, sheep, oranges), eliminating the annotation burden that has historically limited counting to a handful of classes. The DCGP inference-time partitioning strategy is a practical technique that could be adopted in other density-sensitive estimation tasks. However, the performance gap to fully supervised methods remains substantial (e.g., 35 vs. 6.2 MAE on SHB), and the authors acknowledge the approach may not transfer to non-natural domains like medical imaging. Open questions include whether injecting even a small amount of reliable counting data could close the gap, and whether the LDM dependency limits scalability as diffusion models evolve.

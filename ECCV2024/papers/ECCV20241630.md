## Problem

Existing prompt learning methods for vision-language models face an inherent trade-off between classification accuracy and robustness: methods optimized for accuracy (e.g., PromptSRC) sacrifice OOD detection and domain generalization, while robustness-focused methods (e.g., LoCoOp) underperform on top-1 accuracy. Additionally, prior attempts to incorporate local visual features into prompt learning suffer from poor text-vision alignment and the inclusion of irrelevant background regions, limiting their discriminative power.

## Input / Output

The method takes RGB images processed by a CLIP vision encoder (ViT-B/16 or ResNet-50) to extract both a single global visual vector and a set of L patch-level local visual features, alongside class name text embeddings. At inference, it produces a class label by averaging similarity scores across all learned prompts, and an OOD detection score computed via the GL-MCM metric. The local features are linearly projected through a learned layer before similarity computation, and only the top-k most class-relevant patches contribute to each local prompt's score.

## Method

GalLoP learns two specialized prompt sets: m global prompts trained on the full-image visual representation and n local prompts trained exclusively on sparse local patch features. For local prompts, a top-k sparse similarity selects only the k most class-relevant patches, and a learned linear projection (initialized to identity) realigns local features with text to compensate for CLIP's global-pretraining bias. Diversity among global prompts is enforced via 'prompt dropout,' which randomly masks a subset of prompts per image during training (Bernoulli with rate r=75%), while local prompt diversity comes from a multiscale strategy where each prompt is assigned a different k value (e.g., k=10,20,30,40 for ViT-B/16). The total loss is the sum of the global cross-entropy (with dropout) and the multiscale local cross-entropy, and at inference all prompt similarities are averaged to produce the final logit.

## Results

On the standard 11-dataset benchmark with ViT-B/16 (16-shot), GalLoP achieves 84.4% average top-1 accuracy, outperforming the next best method PromptSRC by +1.5pt and PLOT by +1.8pt. On ImageNet specifically, GalLoP reaches 75.1% top-1, surpassing PromptSRC (73.2%) by +1.9pt and PLOT (72.6%) by +2.5pt. For robustness, GalLoP achieves 61.3% average domain generalization accuracy (outperforming PromptSRC◇ by +0.5pt) and 27.3% FPR95 on OOD detection (beating dedicated OOD methods LoCoOp by 1.4pt and LSN by 2.9pt FPR95).

## Baselines & Comparisons

GalLoP outperforms all nine compared baselines on average top-1 accuracy across the 11-dataset benchmark. Against the strongest accuracy-oriented method PromptSRC, GalLoP gains +1.5pt on average, with particularly large margins on fine-grained datasets: +7.5pt on FGVC Aircraft (86.5 vs. 79.0) and +7.5pt on SUN397 (58.3 vs. 50.8). Against PLOT, which also uses local features, GalLoP improves by +2.5pt on ImageNet and +1.8pt on average, demonstrating that sparse local prompts with linear alignment are more effective than optimal-transport-based dense local features. For domain generalization, GalLoP (61.3% avg) surpasses the DG-specific PromptSRC◇ by +0.5pt while simultaneously beating the accuracy-specific PromptSRC▷ by +1.9pt on ImageNet, resolving the accuracy-robustness trade-off that forces PromptSRC to choose between two variants. On OOD detection (FPR95, lower is better), GalLoP (27.3%) outperforms dedicated OOD methods LoCoOp (28.7%) and LSN (30.2%) while also achieving +3.6pt and +3.2pt higher top-1 accuracy respectively, showing that GalLoP does not sacrifice classification performance for robustness. Against the single-prompt baseline CoOp, GalLoP gains +3.4pt on ImageNet and +4.5pt on average, with the largest improvement on SUN397 (+14.9pt), indicating that the combination of diverse global and local prompts is especially beneficial for scene-level classification.

## Relation to Prior Work

GalLoP extends the prompt learning paradigm initiated by CoOp by learning an ensemble of prompts from both global and local CLIP visual representations, building on MaskCLIP for local feature extraction and the GL-MCM score for OOD detection. It departs from prior multi-prompt methods (MaPLe, PromptSRC, ProDA) that rely solely on global features and enforce diversity through explicit orthogonality losses, instead introducing a simpler 'prompt dropout' mechanism and a multiscale strategy. It also addresses a key limitation of prior local-feature methods (LoCoOp, PLOT) that use dense, unaligned CLIP local features, by proposing sparse top-k selection combined with a learned linear projection to re-align local features with text.

## Why It Matters / Open Questions

GalLoP demonstrates that the accuracy-robustness trade-off observed in prompt learning can be substantially mitigated by combining well-aligned local prompts with diverse global prompts, outperforming dedicated OOD detection methods while maintaining top-1 accuracy. The finding that CLIP's zero-shot local features are fundamentally inadequate (12.5% top-1 on ImageNet) and that sparsity is critical (~20pt gain) provides clear guidance for future work on leveraging local representations. An open question noted by the authors is whether the local feature alignment can be learned on a large vision-language dataset rather than per-dataset, which could further reduce the few-shot burden. The method's compatibility with both ViT and CNN backbones broadens its practical applicability compared to ViT-only alternatives like MaPLe and PromptSRC.

## Problem

Existing 2D-to-3D transfer methods either project point clouds into multi-view images (losing 3D spatial geometry) or rely on expensive cross-modality knowledge distillation requiring large-scale paired 2D-3D data. Critically, these approaches are designed exclusively for 2D vision models, leaving no general paradigm to leverage pre-trained transformers from other modalities such as language or audio for 3D understanding.
![Teaser figure](../imgs/ECCV20240967/cropped_page1_idx0.webp)

## Input / Output

The method takes a raw 3D point cloud (downsampled to 1,024 points via FPS) and produces a class label for object classification. Unusually, the point cloud is tokenized directly in 3D space by a lightweight Point-PN variant rather than being projected to 2D, and each 3D token is assigned positional encodings derived from virtual projections into the source modality's native 1D or 2D coordinate system (e.g., a 77-length 1D line for language, a 512×512 patch grid for vision, or a 192×304 grid for audio). The frozen source transformer and inserted adapters jointly produce per-point 3D features that feed a classification head.

## Method

Any2Point introduces two key mechanisms for parameter-efficient any-to-3D transfer. First, a 3D-to-any Virtual Projection virtually maps each 3D point coordinate onto M 1D lines (via dot product with unit direction vectors) or M 2D image planes (via standard perspective projection), then retrieves the corresponding original positional encodings from the frozen pre-trained model and averages them into each 3D token—avoiding true projection geometry loss while preserving the model's learned positional priors. Second, an Any-to-3D Guided Adapter is inserted after each FFN block, performing M parallel local aggregations where 3D tokens are grouped by their virtual 1D/2D positions (patches or segments), self-attention is applied within each group, and an adaptive ensemble weights the M resulting feature sets by cosine similarity against a non-parametric 3D-space baseline. Only the 3D tokenizer and adapters are trained (~0.8–0.9M parameters, ~1% of total), while the source transformer remains fully frozen, enabling transfer from CLIP-Text, DINOv2, ImageBind-Audio, RoBERTa, DeiT, or SSAST with consistent gains across ScanObjectNN and ModelNet40.

## Results

On ScanObjectNN (PB-T50-RS), Any2Point with the CLIP Text Encoder (1D language) achieves 91.9% accuracy with only 0.9M learnable parameters, surpassing the previous SOTA ReCon (90.6%, 43.6M params) by +1.3%. On ModelNet40, the same configuration reaches 94.3%, outperforming ReCon (94.1%) by +0.2% while using 42.7M fewer parameters. The 2D vision (DINOv2) and audio (ImageBind) variants achieve 87.7% and 87.0% on ScanObjectNN respectively, both exceeding the best 3D-only pre-trained baseline Point-M2AE (86.4%) by +1.3% and +0.6%. Across all modalities, Any2Point trains fewer than 1% of the parameters required by full fine-tuning (86.3M).

## Baselines & Comparisons

Any2Point (Language, 0.9M params) decisively outperforms the previous SOTA ReCon (43.6M params) by +1.3% on ScanObjectNN (91.9% vs 90.6%) and +0.2% on ModelNet40 (94.3% vs 94.1%), while using roughly 48× fewer learnable parameters. Against the strongest 2D-to-3D projection method P2P-HorNet (89.3% SCAN), Any2Point Language gains +2.6%, and against the 3D+2D distillation method I2P-MAE (90.1% SCAN), it gains +1.8%. The 2D vision variant (DINOv2, 87.7% SCAN) surpasses the best 3D-only pre-trained model Point-M2AE (86.4%) by +1.3%, and the audio variant (ImageBind, 87.0%) exceeds it by +0.6%, confirming cross-modality transfer effectiveness. In the PEFT ablation (Table 2), Any2Point's guided adapter outperforms LoRA by +5.6% (1D) and +2.6% (2D), Prompt Tuning by +2.8%/+1.3%, and standard Adapter Tuning by +2.3%/+1.8%, demonstrating that 1D/2D spatial guidance is critical for 3D local structure capture. Notably, the 1D language modality consistently outperforms 2D modalities (vision and audio) across both datasets, suggesting that language pre-training provides richer spatial-semantic priors for 3D understanding.

## Relation to Prior Work

This paper departs from two established lines of 2D-to-3D transfer: (1) data-modality transformation methods (PointCLIP, P2P) that project point clouds into multi-view images, and (2) cross-modality distillation methods (I2P-MAE, ACT) that train a new 3D network guided by 2D teachers. Any2Point replaces both with a 'virtual projection' that computes only the 1D/2D positional coordinates of 3D points without generating actual images, and a guided adapter that injects source-modality spatial priors into local 3D aggregation. It also generalizes the transfer paradigm from 2D-vision-to-3D to any-modality-to-3D (language, audio), building on the PEFT literature (LoRA, Adapter Tuning, Prompt Tuning) but replacing generic low-rank or prompt-based adapters with a spatially-guided local aggregation module rooted in Point-PN's non-parametric 3D grouping.

## Why It Matters / Open Questions

The framework demonstrates that 3D point cloud understanding can be achieved with under 1% trainable parameters by repurposing frozen transformers from any modality, which is practically significant given the scarcity of large-scale 3D pre-training data. The consistent finding that 1D language models outperform 2D spatial modalities (vision, audio) for 3D classification is counterintuitive and suggests that semantic priors from text may be more transferable to 3D shape understanding than spatial priors from images. However, the evaluation is limited to classification on two datasets with 1,024 points, leaving open whether the any-to-3D paradigm generalizes to denser point clouds, segmentation, or other 3D tasks, and whether the 1D > 2D trend persists at scale.

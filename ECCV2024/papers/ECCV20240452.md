## Problem

Existing weakly-supervised incremental learning for semantic segmentation (WILSS) methods still depend on manually curated, well-designed datasets for their incremental steps, and none have explored using web images for both acquiring new class knowledge and preserving previously learned classes. Web data introduces additional challenges—noisy single-class labels, distribution shift from the original training set, and privacy concerns around storing exemplar images—that remain unaddressed in the WILSS literature.
![Teaser figure](../imgs/ECCV20240452/cropped_page1_idx0.webp)

## Input / Output

At the initial step the method consumes RGB images with full pixel-level segmentation maps from PASCAL-VOC or COCO; at all subsequent incremental steps it receives only class names (for new classes) and previously stored text captions (for old classes), from which it downloads web images via Flickr. The segmentation backbone (DeeplabV3 with ResNet-101 or Wide-ResNet-38) outputs a per-pixel class probability map over the cumulative label set, while the localizer head simultaneously produces image-level multi-class scores. The Fourier-domain discriminator operates on 224×224 amplitude spectra, and the captioning model (OpenFlamingo) processes full-resolution images to generate free-text descriptions used for both labeling and web querying.

## Method

The framework extends the WILSON architecture (shared encoder, incrementally extended segmentation decoder, per-step localizer, and knowledge-distillation losses) with three web-data-specific modules. First, a Fourier-domain discriminator (EfficientNet-B0 on amplitude spectra) is trained once at step 0 to reject web images whose frequency statistics deviate from the original dataset, ensuring distributional alignment without needing current-step dataset images. Second, a pre-trained VLM (OpenFlamingo) generates captions for each downloaded image, and a synonym-expanded word-set matching procedure converts these captions into multi-class image-level labels, replacing the naive single-class assignment and discarding images that lack the queried class. Third, for rehearsal of old classes the method stores only text captions rather than images; it queries the web with these captions, then re-captions the downloaded images and filters them by comparing WordNet hypernym depth vectors of the first two nouns via cosine similarity (threshold T=0.6), thereby verifying semantic content without pixel-level ground truth.

## Results

On PASCAL-VOC 15-5 (overlapped), the proposed method with VOC training and web rehearsal (M=100) achieves 71.7% mIoU (All), outperforming the WILSON baseline (67.2%) by 4.5 points. In the 10-10 overlapped setting, it reaches 65.3% mIoU, matching WILSON (65.0%). In the fully web-based setting (no VOC data for incremental steps), the method still achieves 71.7% (15-5 overlapped) and 65.3% (10-10 overlapped), demonstrating that web images can substitute for curated datasets. On COCO-to-VOC (60-20), the method reaches 56.7% mIoU on VOC, outperforming all exemplar-free competitors.

## Baselines & Comparisons

Against WILSON [7] (the direct baseline framework), the proposed method improves 15-5 overlapped mIoU from 67.2% to 71.7% (+4.5) and 10-10 overlapped from 65.0% to 65.3% (+0.3), with the larger gain in 15-5 attributed to the caption-driven rehearsal strategy. FMWISS [49] remains the strongest competitor in the 10-10 overlapped setting (69.1% vs. 65.3%), but it relies on VOC pixel-level supervision from pre-trained foundation models, whereas the proposed method uses only image-level labels. RaSP [37] reports 70.0% on 15-5 overlapped, which the proposed method surpasses (71.7%) while also using web data instead of curated VOC. In the fully web-based incremental setting (no VOC data), the proposed method (71.7% on 15-5 overlapped) outperforms WILSON trained on web data (67.8%) by nearly 4 points, confirming that the Fourier-domain filtering and caption labeling strategies effectively compensate for the lack of curated training data. Older weakly-supervised methods (CAM, SEAM, SS, EPS) are consistently outperformed by 5–12 mIoU points across all settings.

## Relation to Prior Work

This paper builds directly on the WILSON framework [7] for weakly-supervised incremental semantic segmentation, adopting its localizer-based pseudo-supervision and knowledge distillation losses, but departs fundamentally by replacing all curated training data with web-sourced images. It extends the webly-supervised learning line (RECALL [24,27]) which previously used web data only for rehearsal of old classes, by employing web images for both acquiring new knowledge and preserving old knowledge. The Fourier-domain discriminator draws on domain adaptation techniques [36,48], while the caption-driven multi-label supervision and WordNet-based filtering represent a novel integration of VLMs (OpenFlamingo) and NLP tools into the incremental segmentation pipeline.

## Why It Matters / Open Questions

The practical significance lies in eliminating the need for manually curated and annotated datasets in incremental learning steps, which is critical in privacy-sensitive or data-scarce deployment scenarios. The finding that web data can match or even exceed curated-dataset performance in multi-step single-class settings challenges the assumption that distribution-matched data is strictly necessary. Open questions remain about the assumption that foundation models already encode knowledge of future classes, the scalability of on-the-fly web downloading, and how to optimally balance matching the original distribution versus generalizing to unseen domains.

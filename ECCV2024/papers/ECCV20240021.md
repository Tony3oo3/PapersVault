## Problem

Transferring material appearance from a 2D exemplar image to an object in another 2D image requires disentangling material from geometry and illumination, yet no existing method performs this in a zero-shot, training-free manner. Prior approaches either demand explicit 3D geometry and BRDF specification, require per-exemplar fine-tuning (e.g., Dreambooth with 3–5 images), or target 3D mesh texturing rather than direct 2D image editing.
![Teaser figure](../imgs/ECCV20240021/cropped_page0_idx1.webp)

## Input / Output

The method takes a single material exemplar image M and a single input image I containing a target object, with no additional 3D models, illumination parameters, or material property specifications required. Internally it computes a depth map D_I (via Dense Prediction Transformers) and a foreground mask F (via Rembg) from I, then produces a single edited image I_gen at the same resolution where the target object exhibits the exemplar's material while the background, geometry, and lighting remain unchanged. The full pipeline runs in approximately 15 seconds on a single 24 GB GPU.

## Method

ZeST composes three pre-trained branches into a training-free pipeline built on Stable Diffusion XL Inpainting. The material exemplar is encoded by an IP-Adapter (CLIP image encoder) whose features are injected via cross-attention, providing an implicit material latent z_M. A depth-based ControlNet, fed with the input image's estimated depth map, overwrites the geometry information entangled in z_M, enforcing the target object's shape. For illumination preservation, the inpainting model is initialized with a foreground-grayscale image (I_init = F ⊙ I_gray + (1−F) ⊙ I), which strips the object's base color prior while retaining shading cues, and the foreground mask F restricts editing to the target region. The key design insight is that geometry and illumination are handled implicitly through these conditioning signals rather than through explicit physical estimation, allowing arbitrary materials to be transferred without any per-exemplar optimization.

## Results

On the synthetic dataset of 540 exemplar-input combinations, ZeST achieves PSNR 25.59, LPIPS 0.053, CLIP similarity 0.883, and DreamSim 0.198, outperforming the strongest baseline (Dreambooth + geometry/illumination guidance) on all four metrics. In a user study with 16 participants rating 5 real-world samples each, ZeST scores 4.05/5 on material fidelity and 3.78/5 on photorealism, compared to 3.25 and 3.41 for the Dreambooth baseline and 1.48 and 3.23 for IP-Adaptor + Instruct-Pix2Pix. ZeST is fully training-free and generates each image in roughly 15 seconds on a single A-10 GPU.

## Baselines & Comparisons

ZeST is compared against three baselines: (1) IP-Adaptor + Instruct-Pix2Pix, (2) Dreambooth + the paper's geometry and illumination guidance, and (3) Dreambooth + MasaCtrl (qualitative only). Against IP-Adaptor + Instruct-Pix2Pix, ZeST wins decisively on every metric — PSNR improves from 17.08 to 25.59, LPIPS drops from 0.099 to 0.053, and user-study fidelity jumps from 1.48 to 4.05 — because the Instruct-Pix2Pix pipeline ignores the input geometry entirely. Against the closest baseline, Dreambooth + geometry/illumination guidance, ZeST achieves marginally better synthetic metrics (PSNR 25.59 vs 25.52, DreamSim 0.198 vs 0.238) but a substantially larger gap in the user study (fidelity 4.05 vs 3.25, photorealism 3.78 vs 3.41), which the authors attribute to information loss when Dreambooth encodes material into a single word token. Dreambooth + MasaCtrl fails qualitatively to preserve object geometry and misattributes material, making it the weakest baseline. A key practical advantage is that ZeST requires no per-exemplar fine-tuning, whereas Dreambooth-based baselines need a separate training run for each material image.

## Relation to Prior Work

ZeST repurposes three existing diffusion-model adapters—IP-Adapter for image-prompt material encoding, depth-based ControlNet for geometry preservation, and SDXL Inpainting for mask-conditioned generation—into a unified zero-shot pipeline for 2D-to-2D material transfer. It departs from prior texture-synthesis works (Texture, TexturedDreamer) that require Dreambooth fine-tuning on 3–5 exemplar images per material, and from text-based material editing (Alchemist, InstructPix2Pix) that rely on textual descriptions rather than visual exemplars. The key conceptual departure is treating material transfer as a latent-space composition problem solvable entirely with pre-trained modules, eliminating explicit 3D geometry, BRDF parameters, or per-material training.

## Why It Matters / Open Questions

ZeST offers a practical, training-free path to material editing for non-expert users in e-commerce, game design, and graphic design, removing the need for 3D assets or material parameter specification. However, the method's reliance on IP-Adapter's global image encoding limits its ability to handle multi-material exemplars or region-specific transfers, and partial material application remains a recurring failure mode. Open questions include whether the foreground-grayscale initialization generalizes to complex multi-object scenes, whether the approach can be made fully controllable (e.g., selecting which material region to transfer), and how it scales to video or 3D-consistent editing.

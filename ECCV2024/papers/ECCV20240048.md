## Problem

Existing methods for generating category-specific VLM prompts for zero-shot classification (e.g., CUPL, DCLIP, Waffle) still require hand-crafting the LLM queries or dataset-specific prompt templates, introducing subjective bias and limiting scalability. This paper asks whether the entire prompt generation pipeline can be automated with only minimal task metadata as human input, eliminating manual LLM prompt design entirely.
![Teaser figure](../imgs/ECCV20240048/cropped_page1_idx0.webp)

## Input / Output

The method requires only a short natural language description of the target task (scraped from a public API or webpage) and a list of class labels—no visual data or hand-crafted templates. It produces a diverse set of category-specific VLM prompts (10 prompts per LLM query, 30 queries per dataset, each capped at 50 tokens), which are ensembled via mean embedding to form the zero-shot classifier. Across 20 datasets and two LLMs, this yields approximately 2.5M unique class descriptions, released as a public dataset.

## Method

MPVR employs a two-stage meta-prompting strategy. In stage 1, a fixed meta-prompt—comprising a generic system prompt, a fixed in-context example (from DTD), and the downstream task description—is fed to an LLM to generate 30 diverse, task-specific LLM query templates containing a <class name> placeholder; these encode task-specific visual styles but remain class-agnostic. In stage 2, each class label is populated into all templates and the LLM is queried again to produce 10 category-specific VLM prompts per query, capturing fine-grained visual appearance in the context of the downstream task. The resulting prompts are ensembled by averaging their CLIP text-encoder embeddings, and classification proceeds via cosine similarity with the image embedding (Eq. 1). The two-stage design is critical: ablations show that collapsing to a single step or using only stage-1 templates yields significantly lower accuracy, confirming that the intermediate task-specific query generation effectively bootstraps more diverse and informative category descriptions.

## Results

Using ViT-B/32 from CLIP, MPVR (GPT) achieves a mean top-1 accuracy of 65.0% on ImageNet and 65.5% averaged over 20 diverse datasets, improving over the CLIP default-template baseline by 5.0% on average (up to 19.8% on EuroSAT). With the open-source Mixtral LLM, the average gain is 4.5% over CLIP. Across different VLM backbones (Table 2), MPVR (GPT) with MetaCLIP ViT-L/14 reaches 74.3% mean accuracy over 20 datasets, a 3.3-point gain over the same backbone's default template (71.0%). MPVR outperforms all baselines on 18 out of 20 evaluated datasets.

## Baselines & Comparisons

Against CLIP's default and dataset-specific template baselines, MPVR (GPT) improves mean accuracy by 5.0% and 3.1% respectively over 20 datasets, with the largest single-dataset gain of 19.8% on EuroSAT. Compared to CUPL, which hand-crafts LLM queries per dataset, MPVR outperforms on most datasets, reaching up to 6.3% higher accuracy on Flowers-102 with Mixtral. Against DCLIP, which relies on category-level visual attributes, MPVR wins on all 20 datasets, with gains up to 5.3% on UCF-101 (action recognition), suggesting that generic attributes miss task-specific visual details. MPVR also surpasses all Waffle variants on average, indicating that semantically rich LLM-generated descriptions outperform random descriptor ensembling. Finally, MPVR-enhanced CLIP (65.5% mean) substantially outperforms the LLM-decoder-based LLaVA-1.6 (30.0% mean) on zero-shot classification, reinforcing the suitability of dual-encoder VLMs for discriminative recognition tasks.

## Relation to Prior Work

This paper extends CLIP's prompt ensembling paradigm by automating the generation of category-specific VLM prompts through a two-stage meta-prompting strategy applied to LLMs. Prior methods (DCLIP, CUPL, Waffle) already used LLMs to generate class descriptions or attributes, but still required hand-crafted LLM queries or dataset-specific templates; MPVR eliminates this residual manual effort by meta-prompting the LLM to first produce task-specific query templates, then populating them with class names. The approach draws conceptual inspiration from meta-prompting in NLP (Hou et al., Suzgun & Kalai) and in-context learning, repurposing these ideas for visual recognition for the first time.

## Why It Matters / Open Questions

By reducing human intervention to a single short task description, MPVR makes zero-shot VLM prompt generation scalable to arbitrary new domains without per-dataset prompt engineering, and the released ~2.5M class-description corpus provides a reusable resource for VLM pre-training or fine-tuning. The demonstration that open-source LLMs (Mixtral) can match or approach closed-model (GPT) performance for this task broadens accessibility. Open questions include whether the fixed in-context example generalizes to highly atypical visual domains, whether the two-stage decomposition is optimal versus other multi-step LLM orchestration strategies, and whether the 2.5M description corpus can meaningfully improve VLM pre-training beyond zero-shot classification.

## Problem

Current query-based image retrieval systems predominantly focus on text-to-image retrieval, leaving users with limited query style options and potential ambiguity in expressing retrieval intent. This paper identifies the gap that retrieval models lack the ability to simultaneously accommodate diverse query styles such as sketches, art-style images, and low-resolution crops, which are natural ways users might express what they want to find.
![Teaser figure](../imgs/ECCV20240605/cropped_page1_idx0.webp)

## Input / Output

The framework accepts four query styles—text descriptions, hand-drawn sketches, low-resolution image crops, and art-style generated images—all resized to 224×224—and produces a ranked list of natural images from a gallery. Uniquely, multiple query styles can be fed simultaneously (e.g., sketch+text, art+text), where auxiliary signals from one style enhance retrieval performance in another. The model operates on a frozen ViT-based visual encoder (CLIP or BLIP), so the only trainable parameters are the prompt tokens and the style-space projection weights.

## Method

FreestyleRet is a three-module plug-and-play framework built on a frozen ViT visual encoder. First, a Gram-based Style Extraction Module computes each query's Gram matrix from a frozen VGG's third convolutional layer output, capturing textural and spatial channel relationships. Second, a Style Space Construction Module applies K-Means clustering over all training queries' Gram matrices to derive four style-specific basis vectors, then represents each query's style as a softmax-weighted combination of these bases via cosine similarity. Third, a Style-Init Prompt Tuning Module inserts four learnable prompt tokens into every transformer layer, initializing shallow-layer tokens with the style-space feature and deep-layer tokens with the Gram matrix, thereby injecting both semantic style and textural information into the frozen encoder. Training uses a triplet loss with margin 1.0 over two dataset passes (first to build the style space, second to tune prompts), and the entire framework adds only ~29M trainable parameters on top of the base encoder.

## Results

On the Diverse-Style Retrieval (DSR) dataset, FreestyleRet-BLIP achieves R@1 of 81.6% (Text→Image), 82.0% (Sketch→Image), 74.5% (Art→Image), and 90.5% (Low-Res→Image), outperforming all baselines across every query style. On the larger ImageNet-X dataset, FreestyleRet-BLIP reaches R@1 of 74.9%, 74.6%, 71.2%, and 97.5% for the four styles respectively, surpassing the strongest baseline (BLIP-Finetune) by 11.0, 21.0, 21.6, and 8.0 points. On the standalone FSCOCO sketch-retrieval task, FreestyleRet achieves R@1 of 29.6%, exceeding the best prior method (SceneTrilogy, 24.1%) by 5.5 points. The framework adds only 29M trainable parameters and ~28–39 ms inference overhead over the base encoder.

## Baselines & Comparisons

FreestyleRet-BLIP dominates all baselines on both datasets across all four query styles. On DSR, it beats the strongest prompt-learning baseline MaPLe by 8.5 (Text), 1.7 (Sketch), 3.9 (Art), and 4.6 (Low-Res) R@1 points, and outperforms the fine-tuned BLIP baseline by 1.5, 6.7, 10.8, and 6.8 points respectively. On ImageNet-X, the margin widens substantially: FreestyleRet-BLIP surpasses BLIP-Finetune by 11.0 (Text), 21.0 (Sketch), 21.6 (Art), and 8.0 (Low-Res) R@1 points, and exceeds MaPLe by 9.7, 18.4, 17.8, and 23.3 points. The multi-modality models (ImageBind, LanguageBind) show moderate zero-shot style-diversified ability but trail FreestyleRet-BLIP by 2–20 R@1 points depending on style. On the FSCOCO sketch-retrieval benchmark, FreestyleRet (R@1=29.6) outperforms SceneTrilogy (24.1), CrossAttn (23.7), QST (23.6), and SCM (23.4) by 5.5–6.2 R@1 points, confirming the generality of the style-init prompt approach beyond the primary retrieval setting.

## Relation to Prior Work

This paper extends the prompt tuning paradigm (CoOP, MaPLe) from class-level transferability to style-diversified query retrieval by repurposing Gram matrices—originally from neural style transfer—as style representations that initialize prompt tokens. It departs from prior QBIR work, which has predominantly explored text-image or single-style retrieval, by formulating a unified multi-style setting where text, sketch, low-resolution, and art queries are handled simultaneously. The style space construction via K-Means clustering of Gram matrices is a novel bridge between the style transfer literature and the prompt learning literature, enabling the frozen ViT encoder to adapt to heterogeneous query textures without full fine-tuning.

## Why It Matters / Open Questions

The finding that style-diversified queries mutually enhance each other's retrieval performance in FreestyleRet while degrading baseline models (CLIP, BLIP) suggests that style-aware initialization is a prerequisite for leveraging multi-modal query information, a non-trivial insight for retrieval system design. The DSR dataset and the plug-and-play framework provide a practical starting point for the community to explore multi-style retrieval. However, the style space is fixed at four clusters, the dataset is limited to 10K images, and the mutual-enhancement result is demonstrated on a single dataset with limited query combinations, leaving open whether the effect scales to more styles, larger galleries, or more diverse query modalities.

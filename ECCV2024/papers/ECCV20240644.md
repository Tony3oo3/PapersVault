## Problem

Existing tracking datasets and methods only capture the positional trajectory of a target (its bounding box over time), which is insufficient for real-world applications like retail analytics, public safety, and sports coaching that require understanding what the target is doing and who/what it is interacting with. No dataset or benchmark exists for this richer form of tracking, which the authors term Semantic Tracking—capturing the full semantic trajectory including locations, affiliated object classes, and interaction types at every timestep.
![Teaser figure](../imgs/ECCV20240644/cropped_page1_idx0.webp)

## Input / Output

The model takes a video sequence {I_0, ..., I_T} and a target initialization sentence (e.g., 'the adult standing on the right side who is playing basketball') that uniquely describes the target's attributes for precise localization in the first frame; users may alternatively provide a bounding box. The output is the target's semantic trajectory: per-frame bounding boxes for the target, bounding boxes and class labels for all affiliated objects (drawn from 115 object classes), and interaction labels (from 52 interaction classes) between the target and each affiliated object at every timestep. The dataset spans 6.7M frames across 6,961 videos with 9,760 distinct initialization sentences covering 12 scene types.

## Method

SemTracker is a four-module pipeline: (1) a visual grounding module using BERT to extract language embeddings and localize the target in the first frame; (2) a YOLOX-based object detection module with FPN backbone and RoI Align to detect candidate affiliated objects and extract their features; (3) an interaction prediction module that concatenates target and candidate object features across K past frames, feeds them through an LSTM, and uses a fully connected head to classify the interaction type for each pair; and (4) a ByteTrack-based multi-object tracking module to associate detections into trajectories. To address distribution shift between training and test data (e.g., compositional bias in target-interaction-object triples), the authors introduce a meta-learning scheme that splits the training set into a support set and N query sets constructed to maximize pairwise KL divergence in object-class and interaction-type distributions, then performs virtual training on the support set and meta-optimizes on the query sets. They also propose ST-mAP, a new evaluation metric that jointly scores target trajectory accuracy, affiliated object trajectory accuracy, and interaction prediction accuracy via Hungarian matching and interpolated precision.

## Results

Using the best configuration (YOLOX-X detector + ByteTrack tracker), SemTracker achieves a Track-mAP of 5.875, HOTA of 13.436, and ST-mAP of 4.625 on the SemTrack test set. When augmented with the proposed meta-learning approach, performance improves substantially to Track-mAP 10.656, HOTA 18.854, and ST-mAP 8.668 — an 87% relative gain in ST-mAP over the baseline. Providing ground-truth bounding boxes in the first frame (removing the detection bottleneck) further lifts ST-mAP to 4.792 with ByteTrack, confirming that detection accuracy is a key limiting factor.

## Baselines & Comparisons

Since SemTrack is the first dataset for Semantic Tracking, no prior semantic-tracking baselines exist; the paper instead compares alternative strategies for handling data-distribution shift. The proposed meta-learning approach outperforms all three alternatives: Reweighting [24] yields only a marginal ST-mAP gain (4.714 vs. 4.625), Focal Loss [45] improves ST-mAP to 6.869, and GCLLoss [39] reaches 8.211. Meta-learning achieves the best ST-mAP of 8.668, surpassing GCLLoss by 0.457 points and the no-meta-learning baseline by 4.043 points. On Track-mAP, meta-learning (10.656) also leads GCLLoss (9.664) by roughly 1 point. The detector/tracker ablation (Table 2) shows that ByteTrack consistently outperforms SORT and DeepSort across all detector sizes, with YOLOX-X + ByteTrack being the strongest combination (ST-mAP 4.625 vs. 1.241 for YOLOX-X + SORT).

## Relation to Prior Work

This paper positions Semantic Tracking as a natural extension of existing object tracking, which has focused exclusively on positional trajectories (bounding boxes over time). Methodologically, SemTracker is a pipeline that composes well-established components: BERT-based visual grounding (following TNL2K and SNLT) for target localization from a language description, YOLOX with FPN for object detection, an LSTM-based interaction predictor, and ByteTrack for multi-object association. The key departure is the addition of the interaction prediction module and the meta-learning training scheme, which together enable the model to output not just where the target is, but what it is doing with surrounding objects across time.

## Why It Matters / Open Questions

The primary contribution is the SemTrack dataset (6.7M frames, 6,961 videos, 52 interaction classes, 115 object classes, 12 scene types), which is the first benchmark enabling research on semantic trajectories and opens practical avenues in retail analytics, public safety, and sports analysis. However, the method itself is a straightforward pipeline of off-the-shelf components, and the evaluation is conducted on only a subset of the test set with very low absolute ST-mAP scores (≤8.7), suggesting the task remains far from solved. Open questions include whether the pipeline architecture is optimal versus end-to-end approaches, how the meta-learning strategy scales to more diverse interaction taxonomies, and whether the ST-mAP metric adequately captures the multi-faceted nature of semantic trajectory prediction.

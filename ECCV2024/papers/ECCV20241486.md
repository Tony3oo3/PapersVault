## Problem

Dense 3D segmentation tasks (semantic, instance, and visual grounding) require expensive per-point annotations, and existing semi-supervised methods for 3D semantic segmentation rely on naive confidence thresholding that suffers from confirmation bias. Semi-supervised 3D instance segmentation is barely explored, and no prior work addresses semi-supervised dense 3D visual grounding. This paper proposes a unified Bayesian self-training framework that spans all three tasks with a single set of building blocks.
![Teaser figure](../imgs/ECCV20241486/cropped_page1_idx0.webp)

## Input / Output

The method consumes 3D point clouds (LiDAR sequences for outdoor scenes, RGB-D reconstructions for indoor scenes) and, for the visual grounding task, an accompanying natural language description. During the pseudo-labeling phase, each input is subjected to random affine transformations and K stochastic dropout forward passes, producing K sets of predictions that are aggregated. Outputs are per-point semantic class labels, per-point binary instance masks, or a single referred-object point mask selected from candidate instances, depending on the task.

## Method

The framework performs K stochastic forward passes with active dropout and augmented inputs, then computes the Shannon entropy of the resulting predictive distribution per point. Pseudo-labels are retained only where all K passes agree (unanimous voting) and the entropy falls below a threshold τ, replacing naive softmax-confidence thresholding with a more calibrated uncertainty filter. For instance segmentation, where Monte Carlo integration cannot be applied directly to instance IDs, the paper introduces a heuristic n-partite matching algorithm: a seed prediction from an unaugmented pass is aligned to each stochastic pass's instances via the Hungarian algorithm (linear sum assignment on negative pairwise IoU), after which the matched binary masks are treated as 2-class semantic outputs and filtered identically. For dense 3D visual grounding, the same matching is applied twice—first to align 3D candidate instance proposals across passes, then to reorder the verbo-visual selection score vector G so that the entropy-based filtering can be applied to the grounding decision.

## Results

On SemanticKITTI (10% labels), the method achieves 61.7% mIoU, outperforming the best prior method IGNet (61.3%) and the supervised-only baseline (56.1%) by +5.6%. On ScribbleKITTI (10%), it reaches 58.9% mIoU, a +10.9% gain over the baseline and +1.2% over IGNet. For 3D instance segmentation on ScanNet (10%), it achieves 32.7 mAP vs. 30.6 for TWIST, and on S3DIS (50%) it reaches 56.6 AP50 vs. 50.4 for CSC. For dense 3D visual grounding on ScanRefer (10%), it improves overall Acc@50 from 19.6 to 24.3 with verbal input (+4.7).

## Baselines & Comparisons

On SemanticKITTI, the method outperforms all five compared semi-supervised baselines at 10–50% labels, with the largest margin over DiAL (+4.6 mIoU at 10%) and CBST (+3.4), while narrowly beating IGNet (+0.4 at 10%, +0.6 at 20%) and LaserMix (+1.7 at 10%). On ScribbleKITTI, the advantage is more pronounced: +1.2 mIoU over IGNet at 10% and +7.4 over the Sup-only baseline. For 3D instance segmentation on ScanNet (10%), the method surpasses TWIST by +2.1 mAP and CSC by +5.4 mAP; on S3DIS (50%), it leads CSC by +6.2 AP50 and TWIST (not reported at 50%) by a wide margin. On dense 3D visual grounding (ScanRefer 10%), the method is the first semi-supervised approach and improves over the supervised-only baseline by +4.1 Acc@25 / +3.4 Acc@50 without verbal input, and by +4.0 / +4.7 with verbal input. The method's main weakness is at very low label budgets (1%), where unanimous voting reduces the number of reliable pseudo-labels, causing it to underperform IGNet and LaserMix on SemanticKITTI.

## Relation to Prior Work

This paper repurposes Bayesian uncertainty estimation (MC dropout + Shannon entropy) from the active learning literature into a self-training pseudo-label filtering mechanism for 3D segmentation, departing from the standard max-softmax confidence thresholding used in prior semi-supervised 3D works (CBST, CPS, LaserMix). The key methodological departure is the heuristic n-partite matching via the Hungarian algorithm, which enables instance-level pseudo-label accumulation across stochastic forward passes—a problem that has no direct analogue in semantic segmentation. The framework is then unified across three tasks (semantic, instance, and dense visual grounding) using the same building blocks, with the visual grounding extension applying the matching strategy twice (once for 3D candidate proposals, once for verbo-visual selection).

## Why It Matters / Open Questions

The paper provides a simple, unified, and parameter-efficient framework that achieves SOTA across five benchmarks without requiring teacher-student architectures, complex augmentation pipelines, or multi-stage refinement—making it an attractive baseline for semi-supervised 3D perception. A notable limitation is the performance gap at very low label ratios (1%), where unanimous voting over MC dropout passes yields too few reliable pseudo-labels; the authors suggest combining their filtering with external robustness mechanisms (teacher models, mix-augmentations) to address this. The first exploration of semi-supervised dense 3D visual grounding opens a practical direction, since verbal referrals are far cheaper to acquire than per-point panoptic annotations. An open question is whether the unanimous-voting requirement can be relaxed (e.g., via learned confidence weighting) without reintroducing confirmation bias.

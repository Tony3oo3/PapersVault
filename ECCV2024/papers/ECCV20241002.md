## Problem

Current diffusion-based image and 3D scene editing methods (e.g., IP2P, IN2N) lack a mechanism to automatically localize where an edit should occur, leading to over-editing that alters irrelevant regions of the scene. This paper introduces the task of 3D edit localization and proposes a relevance-based approach to restrict modifications to only the spatially relevant region, enabling minimal, controllable edits.
![Teaser figure](../imgs/ECCV20241002/cropped_page1_idx0.webp)

## Input / Output

For 2D editing, the method takes a single RGB image and a text edit instruction (e.g., 'add cherry blossoms'), producing an edited image and a pixel-wise relevance map. For 3D editing, it takes a multiview capture with camera poses (fit to a NeRF) and the same text instruction, producing an edited NeRF and a 3D relevance field. Unlike DiffEdit, only a single instruction is required (no input/output caption pair), and a user-controllable threshold τ determines the spatial extent of the edit without affecting its strength.

## Method

The core mechanism computes a relevance map as the absolute difference between IP2P's noise predictions conditioned on the image+text versus image+empty-text at a fixed high-noise timestep (t_rel=0.8), which identifies pixels most likely to need modification. In 2D, this map is binarized into an edit mask, and during each DDIM denoising step, unmasked pixels are replaced with the noisy input latent to prevent changes outside the relevant region. For 3D, relevance maps from all training views are consolidated into a separate neural relevance field that shares geometry with the main NeRF (with detached density gradients); during IN2N-style iterative view updates, the rendered relevance from this field guides which pixels to edit in each view. The paper further shows the relevance map corresponds to the absolute value of the Score Distillation Sampling gradient, providing a theoretical interpretation as a per-pixel weighting of how much each pixel should be altered by the diffusion model's score update.

## Results

On 14 NeRF scene editing tasks, the method matches IN2N on CLIP text-image similarity (0.27), frame similarity (0.99), and edit similarity (0.88), while surpassing it on scene preservation (Image Sim. 0.89 vs. 0.86; Edit PSNR 31.0 vs. 28.7) and image quality (NIQE 5.53 vs. 6.43, lower is better). The method closes 37.3% of the NIQE gap between IN2N and the per-frame IP2P upper bound. For 2D image editing on the IP2P test set (5,000 images), the method sits on the Pareto frontier of text-image direction similarity vs. input fidelity for every mask threshold τ, outperforming DiffEdit, SDEdit, and vanilla IP2P.

## Baselines & Comparisons

Against IN2N [18], the primary 3D baseline, the method ties on edit quality metrics (Txt-Img Sim., Frame Sim., Edit Sim.) but wins on preservation of the original scene (Image Sim. +0.03, Edit PSNR +2.3 dB) and perceptual quality (NIQE 5.53 vs. 6.43), confirming that the relevance field prevents over-editing without sacrificing edit fidelity. Per-frame IP2P [6] (IP2P-PF) serves as a quality upper bound (NIQE 4.02) but lacks 3D consistency (Frame Sim. 0.97, Edit Sim. 0.81), making it an indirect comparison. In 2D, DiffEdit [11] requires both input and output captions and fails to produce appropriate edits on the complex IP2P instructions, while SDEdit [43] loses input fidelity as edit strength increases due to its lack of an explicit localization mechanism. NeRF-Art [75] is compared qualitatively and over-edits irrelevant regions (hair, background, shirt) while introducing CLIP-based artifacts. Overall, the method dominates on the preservation-quality trade-off: it achieves the same edit semantics as IN2N while keeping unedited regions intact, a property none of the baselines provide automatically.

## Relation to Prior Work

This paper builds directly on InstructPix2Pix (IP2P) as the diffusion-based editing backbone and on InstructNeRF2NeRF (IN2N) for iterative NeRF dataset updates, but departs from both by introducing a spatial localization mechanism absent in either. The relevance map—computed as the absolute difference between IP2P's noise predictions with and without the text instruction—is conceptually related to DiffEdit's caption-difference localization, but operates on a single instruction rather than paired captions and is tied to a purpose-built editor. The key architectural extension is lifting 2D relevance maps into a 3D neural 'relevance field' that shares geometry with the main NeRF, enabling view-consistent edit localization across a multiview scene. The authors also provide a theoretical interpretation connecting the relevance map to the Score Distillation Sampling gradient, positioning it as a spatially-weighted version of the SDS update.

## Why It Matters / Open Questions

The over-editing problem in diffusion-based image and scene editing is a practical pain point that this paper addresses with a simple, interpretable mechanism (a single threshold parameter τ controlling edit extent). The 3D relevance field is a clean way to enforce multiview consistency in edit localization without requiring user-provided masks, which is particularly valuable for 3D scenes where manual annotation is infeasible. However, the method remains fundamentally limited by IP2P's quality—failure cases where IP2P mislocalizes the edit propagate directly into the relevance map—and the quantitative gains over IN2N are modest (e.g., NIQE 5.53 vs. 6.43). Open questions include whether the approach transfers to other 3D representations (e.g., 3D Gaussian Splatting), whether better underlying diffusion models would improve relevance map quality, and whether the fixed noise level t_rel=0.8 generalizes across diverse editing tasks.

## Problem

Existing prompt-tuning methods for CLIP (e.g., CoOp, CPL) assign a single fixed set of learnable prompts per class, which conflates diverse visual concepts within a class and lacks inter-class interaction, leading to poor generalization on fine-grained and cross-domain tasks. The paper addresses this by exploiting the observation that visual concepts (shapes, colors, textures) are inherently transferable across domains and should drive prompt selection adaptively per image.

## Input / Output

The method takes an RGB image (processed by frozen CLIP ViT-B/16) and a set of class name embeddings. The image feature serves as a query to retrieve Top-K3=4 visual concepts from a codebook of N=100 (key, value) pairs, where each key is a D-dimensional vector and each value is a sequence of M=8 learnable prompt vectors. The selected prompts are concatenated with each class name embedding, fed through the frozen text encoder, and classification scores are computed via softmax over cosine similarity between the image feature and all class text features. A handcrafted concept cache of 2000 text concepts (from established visual concept datasets) is also queried during training to generate regularization prompts via GPT.

## Method

CoCoLe introduces a learnable conceptual codebook Ψ_cc = {(V_i, P_i)}_{i=1}^N that acts as an adaptive bridge between the image encoder and text encoder: for each input image, cosine similarity selects the Top-K3 most relevant visual concept keys, and their corresponding conceptual prompt values are concatenated with class name embeddings to form the text encoder input. A handcrafted concept cache (built by matching 2000 text concept features against training image features via CLIP) provides regularization: the image feature queries the cache to retrieve concept words, which are fed to GPT to generate handcrafted concept-based prompts, and a consistency loss L_cc constrains learned prompt text features to stay close to these handcrafted counterparts. Training optimizes four losses jointly—cross-entropy L_ce, a cosine matching loss L_ma that pulls selected keys toward the image feature, an orthogonality loss L_or for prompt diversity, and the consistency loss L_cc—while keeping both CLIP encoders frozen. At inference, the trained codebook is used in a standard zero-shot CLIP pipeline: the test image feature selects Top-K3 keys, corresponding prompts are fused with class names, and classification proceeds via cosine similarity.

## Results

On the base-to-novel generalization task (16-shot, 11 datasets), CoCoLe achieves 85.22% base accuracy, 80.31% novel accuracy, and 82.70% harmonic mean (HM), outperforming the previous state-of-the-art CPL by +0.84%, +2.28%, and +1.62% respectively. On cross-dataset transfer (trained on ImageNet, tested on 10 unseen datasets), CoCoLe reaches 68.91% average target accuracy, surpassing CPL by 0.84%. On domain generalization (ImageNet → 4 variants), CoCoLe sets a new SOTA average of 61.85%, beating CPL by +1.05%.

## Baselines & Comparisons

CoCoLe outperforms all seven baselines across all three evaluation tasks. Against the zero-shot CLIP baseline, CoCoLe gains +11.00% HM on base-to-novel, demonstrating the value of fine-tuning. Compared to the pioneering prompt-tuning method CoOp, CoCoLe improves HM by +11.04% (82.70 vs. 71.66), largely because CoOp's fixed per-class prompts fail to generalize to novel classes (63.22% vs. 80.31%). Against the closest competitor CPL (the previous SOTA), CoCoLe leads by +1.62% HM on base-to-novel, +0.84% on cross-dataset average, and +1.05% on domain generalization average. The gap is most pronounced on fine-grained and action datasets: CoCoLe beats CPL by +3.32% on FGVCAircraft novel classes and +3.12% on UCF101 novel classes. CoCoLe also surpasses CoPrompt by +2.22% HM and MaPLe by +4.15% HM on the average base-to-novel benchmark, confirming that the adaptive conceptual codebook with handcrafted concept cache regularization provides consistent gains over both conditional prompting and multi-modal prompt learning approaches.

## Relation to Prior Work

CoCoLe extends the prompt-tuning lineage for CLIP that began with CoOp (Zhou et al., IJCV 2022), which replaced handcrafted prompts with per-class learnable vectors. The key conceptual departure is from CPL (Zhang et al., AAAI 2024), which introduced a fixed visual concept cache to guide prompt selection; CoCoLe makes the codebook itself learnable (visual concepts as keys, conceptual prompts as values) while retaining a handcrafted concept cache as a regularization signal. The method also draws on the broader prompt-tuning family (CoCoOp, MaPLe, CoPrompt, KgCoOp) but distinguishes itself by decoupling prompts from specific classes and instead binding them to transferable visual concepts, with GPT-generated concept-based prompts providing an external anchor during training.

## Why It Matters / Open Questions

The paper addresses a persistent weakness of prompt-tuning methods—degradation on fine-grained and out-of-distribution tasks—by showing that concept-level (rather than class-level) prompt organization improves generalization across base-to-novel, cross-dataset, and domain-shift settings. The practical efficiency gain (10 ms/image vs. 25 ms for CPL at higher accuracy) makes the approach attractive for deployment. Open questions include whether the handcrafted concept cache (sourced from fixed visual-concept datasets) can be fully learned end-to-end, whether the GPT-based prompt generation step is a bottleneck or can be replaced, and whether the approach scales to larger CLIP variants or multimodal generation tasks.

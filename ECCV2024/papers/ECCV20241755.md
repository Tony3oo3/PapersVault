## Problem

Recent VLN methods that construct topological maps for global planning rely on GCN-like models to repeatedly encode the entire graph at every step, incurring high computational cost. Additionally, representing visual information on graph nodes is too coarse-grained for accurate decision-making, prompting prior work to add expensive fine-grained branches (e.g., bird's-eye-view features). This paper asks whether global planning can be achieved efficiently without full-graph recomputation or auxiliary fine-grained encoders.

## Input / Output

At each step the agent receives a natural language instruction, a K-view panorama (pre-extracted image features from fixed orientations), and the set of neighboring navigable nodes with their relative heading/elevation and coordinates. The method outputs a temporary target node among all unvisited nodes (or a virtual stop node), after which the agent follows the shortest path on the constructed directed graph to that target. Notably, visual features are stored on directed edges rather than nodes, and the stop action is modeled as a learnable token appended to the trajectory, analogous to an end-of-sentence token.

## Method

PRET constructs a directed graph where each edge carries an orientation-aware panorama feature extracted by a cross-attention module (OPE) that uses the edge's relative heading and elevation as query to attend over K panorama view features. For each unvisited node, a directed fidelity trajectory (a detour-free path from the start node) is maintained via a stack, and its alignment with the instruction is scored by a Matching Assessment Module (MAM), a multi-layer transformer decoder that takes the edge-feature sequence and text embedding as inputs. A Candidate Comparison Module (CCM), consisting of a single transformer layer and MLP, then compares all candidate path embeddings to select the best-aligned target. Efficiency is achieved by computing embeddings only for newly observed nodes in a single forward pass using merged causal masks and KV-cache, reducing decoder cost to ~3% of BEVBert at step 10. Training uses MLM pretraining followed by fine-tuning with a mixture of teacher-forcing and student-forcing losses, where the pseudo-label for student-forcing encourages backtracking toward the ground-truth path.

## Results

On R2R test unseen, PRET (DINOv2) achieves SPL 64 and SR 72, comparable to the previous SOTA BEVBert (SPL 62, SR 73) while using only 3% of its computational cost (0.9 vs 35.5 GFLOPs at step 10). On RxR val unseen, PRET (DINOv2) achieves sDTW 62.4 and SR 72.8, outperforming BEVBert (sDTW 58.6, SR 68.5) by 1.8% on the primary metric. PRET uses 64M parameters versus 90M for both DUET and BEVBert, with inference latency of 4.1 ms versus 8.6 ms (DUET) and 10.6 ms (BEVBert).

## Baselines & Comparisons

On R2R, PRET (DINOv2) matches or slightly exceeds BEVBert on SPL (64 vs 62 test unseen; 65 vs 64 val unseen) while reducing computational cost from 35.5 to 0.9 GFLOPs at step 10 — a 97% reduction. Compared to DUET, PRET achieves higher SPL (64 vs 59 test unseen) with 81% fewer GFLOPs. On RxR, PRET clearly outperforms all baselines: it beats BEVBert by 3.8 points on sDTW (62.4 vs 58.6) and 4.3 points on SR (72.8 vs 68.5) on val unseen, and surpasses MARVEL (sDTW 57.5) by 4.9 points. The paper also shows that DINOv2 features consistently outperform CLIP features across both datasets (e.g., SPL 64 vs 62 on R2R test unseen; sDTW 62.4 vs 60.4 on RxR val unseen), attributed to DINOv2's self-supervised training and implicit geometric information. On R2R val seen, PRET is slightly weaker than BEVBert (SPL 69 vs 74), which the authors attribute to not using environment layout or depth information, reducing overfitting to seen scenes.

## Relation to Prior Work

PRET departs from the dominant graph-based VLN paradigm (DUET, BEVBert, SSM, AZHP) that encodes the entire topological map with GCN-like models at every step. Instead of node-level panorama features on an undirected graph, it introduces a directed graph with orientation-aware edge features extracted via a cross-attention mechanism (OPE), and replaces full-graph encoding with trajectory-level instruction-path alignment scoring. The planning strategy repurposes the concept of a 'fidelity trajectory' (a detour-free path from start to candidate) as the unit of decision-making, leveraging KV-cache and causal masking to compute only newly observed paths incrementally rather than re-encoding the whole map.

## Why It Matters / Open Questions

The 3× reduction in decoder computational cost relative to BEVBert (and 19× relative to DUET) while matching or exceeding SOTA performance makes global-space planning practical for real-time or resource-constrained deployment. The directed edge representation addresses a genuine representational gap—undirected node features conflate paths traversing the same node in opposite directions—which the ablation confirms matters (8.4% SPL gain). A noted limitation is the absence of explicit environment layout input, which hurts on val-seen splits and suggests the method may struggle in environments where spatial geometry is critical. Open questions include whether the trajectory-alignment formulation extends to continuous (non-discrete) navigation or to multi-agent settings.

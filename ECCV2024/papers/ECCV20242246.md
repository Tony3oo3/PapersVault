## Problem

Prior visual relationship detection methods separate object detection from relationship prediction using dedicated relationship decoders or modules, which complicates end-to-end training and limits performance. This architectural separation also entangles object and predicate representations, making open-vocabulary inference over large vocabularies computationally intractable. The paper asks whether relationships can be modeled directly within an encoder-only image Transformer without any additional relationship-specific stages.
![Teaser figure](../imgs/ECCV20242246/cropped_page0_idx0.webp)

## Input / Output

The model takes a single RGB image and a set of text prompts (object class descriptions and predicate descriptions) that are embedded separately via a CLIP text encoder. At inference, the Relationship Attention layer performs hard top-k selection over all N² subject-object token pairs, so only k relationship triplets are scored against predicate text embeddings, keeping inference at real-time speeds (52.8 FPS for B/32 on a V100). Because object and predicate texts are embedded independently, the model can efficiently score all possible subject-predicate-object combinations without constructing full triplet descriptions, enabling exhaustive evaluation on large-vocabulary benchmarks like GQA.

## Method

The architecture builds on an encoder-only CLIP ViT image encoder (from OWL-ViT) whose output tokens already represent object proposals. Two lightweight MLPs project each token into a subject embedding s_i and an object embedding o_j, breaking symmetry between the two roles. A Relationship Attention layer computes the inner-product score p_ij = s_i · o_j^T for all pairs and performs hard top-k selection; the selected pairs yield relationship embeddings r_ij = LayerNorm(s_i + o_j) that are classified against predicate text embeddings. Training is single-stage and end-to-end on a mixture of object detection (Objects365) and VRD datasets (VG, VG150, GQA200, HICO), using bipartite matching, sigmoid cross-entropy classification, L1/gIoU box losses, and a self-supervised relationship score loss that trains the attention scores to predict the maximum class probability of the corresponding embedding. The key insight is that the encoder's existing self-attention already models all-to-all pairwise interactions, so no decoder or message-passing module is needed to capture relationships.

## Results

On Visual Genome 150 (graph-constrained), SG-ViT with CLIP ViT-L/14 achieves 21.8 mR@100, and with simple predicate rebalancing reaches 26.1 mR@100, surpassing the prior best DT2-ACBS (24.4 mR@100) by 1.7 points. On GQA200, SG-ViT (L/14) achieves 22.9 mR@100, outperforming the best prior method SHA w/GCL (20.1 mR@100). On the full GQA benchmark (1703 object classes, 311 predicates), SG-ViT (L/14) achieves 9.6 mR@100 for scene graph generation, exceeding all prior scene graph generation and classification methods. On HICO-DET, SG-ViT (L/14) reaches 38.11 mAP, on par with UniVRD (37.41) but below the self-training-based RLIPv2 (45.09 with Swin-L).

## Baselines & Comparisons

On VG150, SG-ViT with predicate rebalancing (26.1 mR@100) outperforms the prior best DT2-ACBS (24.4) by 1.7 points, and without rebalancing SG-ViT (L/14) at 21.8 mR@100 still exceeds all decoder-based methods (UniVRD L/14: 14.5) by a wide margin. On GQA200, SG-ViT (L/14) achieves 22.9 mR@100, beating the best prior method SHA w/GCL (20.1) by 2.8 points without any specialized long-tail treatment. On full GQA, SG-ViT (L/14) at 9.6 mR@100 for scene graph generation surpasses all prior SGG methods (best: 7.4) and even scene graph classification methods (best: 2.8), demonstrating strong open-vocabulary generalization. On HICO-DET, SG-ViT (L/14) is on par with UniVRD (38.11 vs 37.41 mAP) and notably better on rare classes (33.71 vs 28.90 mAPr), but trails the self-training-based RLIPv2 (45.09 mAP with Swin-L). A controlled comparison training SG-ViT (B/32) on UniVRD's exact data mixture yields 17.4 mR@100 versus UniVRD's 12.1, isolating the architectural advantage of the encoder-only design over decoder-based relationship modules.

## Relation to Prior Work

This paper builds directly on the encoder-only open-vocabulary object detection architecture of OWL-ViT (Minderer et al., ECCV 2022), repurposing its ViT image encoder tokens as object proposals. The key conceptual departure is from the dominant trend in VRD of adding Transformer decoders or separate relationship modules (RelTR, SGTR, UniVRD) to model object interactions; instead, the authors argue that the self-attention layers in the ViT encoder already capture all-to-all pairwise interactions, and introduce only a lightweight Relationship Attention layer for efficient pair selection. This positions the work as a simplification of the field's architecture: relationships are extracted from the same encoder tokens that produce object detections, enabling true end-to-end training on mixed object and relationship data without a decoder.

## Why It Matters / Open Questions

The paper demonstrates that a decoder-free architecture can outperform decoder-based VRD methods by a substantial margin (e.g., 18.1 vs. 12.1 mR@100 on VG150 for B/32) while maintaining real-time inference speeds, suggesting the field's reliance on Transformer decoders for relationship modeling may be unnecessary. The disentangled object/predicate design enables exhaustive evaluation over all class combinations, addressing a practical limitation of prior open-vocabulary methods. However, performance on the specialized HICO benchmark is only on par with prior work, and zero-shot generalization to entirely unseen object or predicate classes remains a significant open gap, indicating that architectural simplicity alone does not solve the long-tail and compositionality challenges inherent to VRD.

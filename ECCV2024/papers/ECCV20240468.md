## Problem

Multi-modal large language models (MLLMs) can segment objects at the object level but fail to accurately localize objects described in complex reasoning queries, often confusing semantically similar instances (e.g., segmenting a dog's eyes instead of its nose for 'the part that gives dogs keen sense of smell'). Existing approaches like LISA generate a single mask from one [SEG] token without any hierarchical decomposition of the reasoning process, missing the top-down, progressive visual search strategy that humans naturally employ.

## Input / Output

The method takes an RGB image, a free-form reasoning text query, and a randomly sampled set of pure-text question-answer examples (unrelated to the current query) that implicitly encode the desired chain-like output format. The MLLM produces a structured text response following the template 'It appears on [LOC]. It is [SEG].', where the [LOC] and [SEG] token embeddings are extracted and fed as prompts into a two-level SAM-based segmentation chain that iteratively refines the mask from a coarse location region to the final fine-grained object mask.

## Method

CoReS introduces a dual-modal, dual-chain architecture: a chain-of-reasoning (text) where the MLLM is constrained via a sentence template to inject scene/location semantics into a [LOC] token and object-specific semantics into a [SEG] token, and a chain-of-segmenting (visual) where SAM's prompt encoder and mask decoder generate masks iteratively at each logical level, using the previous level's mask as a soft spatial prompt and the corresponding token embedding as a text prompt. A key mechanism is token refinement: at each segmentation level, a masked-average-pooled visual prototype (computed from the image features and the previous mask) is used via cross-attention to calibrate the text token embedding for the next level, creating iterative inter-modal feedback within a single forward pass. To make the MLLM spontaneously produce this hierarchical output, the paper introduces in-context guidance—randomly sampled text-only Q&A pairs prepended to the input that demonstrate the chain-like reasoning format without any image, teaching the model to transfer the top-down logical structure to multi-modal tasks. Training uses LoRA fine-tuning with cross-entropy loss on the reasoning chain and a combined dice + cross-entropy loss on the final segmentation mask, while keeping SAM's image encoder and prompt encoder frozen to preserve generalization.

## Results

On the ReasonSeg benchmark (gIoU), CoReS with LLaVA-7B achieves 52.4 overall on the test set after fine-tuning, surpassing LISA (47.3) by 6.5 points. Without fine-tuning, CoReS already reaches 48.7 overall, outperforming the fine-tuned LISA (47.3) by 1.4 points. Scaling to LLaVA-v1.5-13B, CoReS reaches 65.5 overall gIoU on ReasonSeg test, the best result reported. On referring segmentation (refCOCOg, cIoU), CoReS achieves 70.7 on testU, slightly ahead of LISA (70.6) and competitive with specialized models like PolyFormer (69.1).

## Baselines & Comparisons

CoReS consistently outperforms LISA across all MLLM scales on ReasonSeg: by 10.4 gIoU without fine-tuning (48.7 vs 36.8, LLaVA-7B) and by 6.5 gIoU after fine-tuning (52.4 vs 47.3). Against non-MLLM baselines, CoReS (ft) leads OVSeg (26.1), GRES (21.3), X-Decoder (21.7), and SEEM (24.3) by 26–31 gIoU points on ReasonSeg test overall, reflecting the advantage of MLLM-based reasoning. On referring segmentation, CoReS matches or slightly exceeds LISA on refCOCO (76.0 vs 74.9 val) and refCOCO+ (65.1 vs 65.1 val), with a clearer ~1.1 cIoU gain on the more complex refCOCOg (69.0 vs 67.9 val). Compared to specialized referring segmentation models (MCN, VLT, CRIS, LAVT, PolyFormer), CoReS achieves competitive cIoU on refCOCOg (70.7 testU vs PolyFormer's 69.1) without requiring REC pretraining or large-scale detection/caption data, while uniquely handling reasoning segmentation tasks that these specialized models cannot address.

## Relation to Prior Work

CoReS extends the LISA paradigm (MLLM + SAM decoder for reasoning segmentation) by inserting a structured, top-down reasoning hierarchy between the language model's output and the segmentation decoder, drawing directly on the chain-of-thought prompting literature from NLP. The key architectural departure is the dual-chain design: a chain-of-reasoning that decomposes the query into location-then-object tokens, and a chain-of-segmenting that iteratively refines masks using the previous level's output as a soft prompt. The in-context guidance mechanism repurposes few-shot textual examples as a training-time signal to teach the MLLM the hierarchical output format, rather than relying solely on template-based supervision.

## Why It Matters / Open Questions

The finding that un-tuned CoReS outperforms fine-tuned LISA by 1.9% gIoU suggests that structured reasoning architecture can be more effective than additional task-specific training data, which has implications for how MLLM-based segmentation systems are designed. However, the approach is limited to a two-level hierarchy (location → object), and the three-level variant showed no further gain, raising questions about whether deeper hierarchies would help for genuinely more complex queries. The method also depends on a pre-constructed context library of quality, and the in-context examples show diminishing returns beyond one example, leaving open how to scale this guidance mechanism. Broader applicability to other dense prediction tasks (e.g., panoptic segmentation, depth estimation) remains unexplored.

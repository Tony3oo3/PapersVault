## Problem

In visual prompting, label mapping aligns a frozen pre-trained model's source labels with target labels, yet existing strategies (random, hard-coded, frequency-based) are chosen heuristically without considering how the mapping affects the optimization burden on input prompts. No prior work formalizes the principle that an ideal label mapping should minimize the distribution migration the prompt must perform, leaving the synergy between input-side prompting and output-side label mapping unexplored.

## Input / Output

The method consumes two inputs: (1) RGB images from the target dataset, which are fed through the frozen pre-trained model to obtain soft logit predictions, and (2) the target dataset's ground-truth class labels, used to group predictions by class for cost matrix construction. The output is a binary permutation matrix (n_s × n_t) that assigns each target label to exactly one source label, effectively reindexing the model's output logits before loss computation. The cost matrix is computed once from the full target dataset's predictions via grouped summation, making the mapping a one-time pre-processing step rather than a per-sample operation.

## Method

OTLM reconceptualizes label mapping as a Partial Optimal Transport problem between the source label distribution (n_s classes) and the target label distribution (n_t classes), where n_s > n_t. The key novelty is the cost matrix definition: C_ij equals the normalized inter-class prediction mass at source position i outside target class j (i.e., 1 minus the fraction of total predictions at position i that belong to class j), capturing how much feature mass must be redistributed if source label i is mapped to target label j. This contrasts with frequency-based methods (FLM/ILM) that use only argmax voting (intra-class) and a greedy solver. The POT is solved exactly via linear programming as an assignment problem, yielding a permutation matrix that globally minimizes total transport cost. The resulting mapping is applied by reindexing the model's output logits, and only the prompt parameters θ_p are then optimized end-to-end with the frozen model.

## Results

Under the VP framework with ViT-B pretrained on ImageNet-22K, OTLM achieves an average top-1 accuracy of 69.77% across 10 downstream datasets, surpassing FLM-VP (61.20%) and ILM-VP (61.47%) by 8.57% and 8.30% respectively. The largest gains appear on fine-grained datasets: CUB200 (56.6% vs. 45.2% for ILM) and NABirds (33.8% vs. 19.6% for ILM). Under the VPT framework with Swin-B, OTLM reaches 84.30% average accuracy without an extra classification head, approaching VPT-with-head (86.0%) while using fewer trainable parameters.

## Baselines & Comparisons

OTLM consistently outperforms all three prompt-based baselines across every dataset in the VP framework. Against the original VP method (Bahng et al., 2022) with its hardcoded label mapping, OTLM gains 11.17% on average (69.77% vs. 58.60%), with the most dramatic improvement on NABirds (33.8% vs. 8.4%). Against FLM and ILM (Chen et al., 2023), which use frequency-based voting for label mapping, OTLM achieves 8.57% and 8.30% average improvements respectively, confirming that the optimal-transport cost matrix and linear-programming solver both contribute meaningfully (ablation: greedy+frequency = 62.56%, LP+frequency = 64.29%, greedy+OT = 79.92%, LP+OT = 86.63% on Flowers102). Under the VPT framework (Jia et al., 2022), OTLM without an extra classification head (84.30% average) nearly matches VPT with an extra head (86.0%) while optimizing fewer parameters, and clearly surpasses FLM (74.4%) and ILM (77.2%) on all five datasets. The only setting where OTLM does not lead is SVHN under VP, where ILM-VP (88.8%) marginally edges out OTLM (88.7%), a negligible 0.1% difference.

## Relation to Prior Work

This paper builds on the Visual Prompting (VP) framework, which adapts frozen pre-trained models to downstream tasks via input-side learnable prompts and output-side label mapping. While prior label mapping strategies in VP relied on heuristics—random assignment, hard-coded indices, or frequency-based voting (FLM/ILM)—this work reconceptualizes label mapping as a Partial Optimal Transport problem, drawing on the POT formulation for distributions of unequal total mass. The key departure is a principled cost matrix defined via inter-class feature transport (rather than intra-class frequency counts) and an exact linear-programming solution to the resulting assignment problem, replacing the greedy selection used by FLM/ILM.

## Why It Matters / Open Questions

By grounding label mapping in optimal transport, the paper provides a theoretically motivated, computationally cheap (assignment-problem complexity) replacement for heuristic frequency-based methods, yielding consistent 8+ point accuracy gains across 10 datasets and three architectures. The finding that OTLM's advantage grows with source-dataset scale and shrinks with target-dataset size suggests the method is particularly valuable in data-scarce, large-pretraining regimes common in practice. Open questions include whether the POT formulation extends naturally to multi-label, open-set, or generative prompting settings, and whether the inter-class cost matrix design generalizes beyond classification to detection or segmentation tasks.

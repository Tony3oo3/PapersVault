## Problem

Existing 3D instance segmentation methods either rely on scarce, low-diversity 3D annotations that limit generalization across scene types, or use bottom-up 2D-to-3D lifting where inconsistent instance masks across views severely degrade 3D segmentation quality. This paper addresses both issues by inverting the lifting direction: instead of segmenting 2D first and merging in 3D, it starts from 3D superpoints and queries 2D models for region-specific information.
![Teaser figure](../imgs/ECCV20241278/cropped_page1_idx0.webp)

## Input / Output

The method requires both 3D scene geometry (mesh or point cloud, obtainable from depth cameras, laser scanners, or LiDAR) and calibrated multi-view RGB images of the same scene. It produces class-agnostic 3D instance segmentation, i.e., a partition of the point cloud into object-level groups without semantic class labels. The SAM prompt mechanism is invoked per-superpoint per-view, making the method interactive with the 2D model rather than a single forward pass.

## Method

The pipeline first over-segments the 3D geometry into superpoints (via normal-based graph cut for meshes or Potts energy for point clouds) and builds an adjacency graph. Edge weights are computed by projecting each superpoint pair onto co-visible views, sampling k=5 points as SAM prompts, and taking the maximum mask intersection ratio across views (weighted by view confidence and 2D distance). Node features aggregate SAM encoder features sampled within each superpoint's projection across all views. A GNN (graph convolutional + fully connected layers) then refines edge affinities, trained with pseudo-labels generated by CropFormer's 2D instance segmentation (requiring consistency across at least n=10 co-visible views) plus a regularization loss that anchors predictions to SAM edge weights where pseudo-labels are absent. Final segmentation is obtained via union-find graph cut on the GNN-predicted affinities.

## Results

On ScanNet200, the full method (with GNN) achieves mAP 22.1, AP50 41.7, and AP25 62.8, outperforming the best unsupervised baseline SAM3D (w/ ensemble) by 1.2 mAP points. On ScanNet++, the method reaches mAP 15.3 (vs. 9.3 for SAM3D w/ ensemble), and on KITTI-360 it achieves mAP 23.8 (vs. 13.0 for SAM3D w/ ensemble). Notably, while the supervised Mask3D still leads on ScanNet200 (mAP 53.3), it drops to mAP 4.6 on ScanNet++ and 0.2 on KITTI-360, whereas the proposed method maintains strong performance across all three datasets without any manual 3D annotations.

## Baselines & Comparisons

Against traditional geometric segmentation (Felzenswalb, Guinard), the proposed method achieves roughly 4–8× higher mAP across all datasets, confirming that SAM-guided graph construction is far more effective than geometry-only cues. Compared to SAM3D (w/ ensemble), the closest unsupervised 2D-to-3D lifting baseline, the method wins on all three datasets: +1.2 mAP on ScanNet200 (22.1 vs. 20.9), +6.0 mAP on ScanNet++ (15.3 vs. 9.3), and +10.8 mAP on KITTI-360 (23.8 vs. 13.0), with the gap widening substantially on out-of-domain scenes. Against the supervised Mask3D, the proposed method loses on ScanNet200 (22.1 vs. 53.3 mAP) where Mask3D benefits from ground-truth training labels, but dramatically outperforms it on ScanNet++ (15.3 vs. 4.6 mAP) and KITTI-360 (23.8 vs. 0.2 mAP), demonstrating that the SAM-guided graph cut generalizes far better to different capture devices and scene types. The GNN module trained solely on ScanNet200 pseudo-labels further improves results on all three test sets, indicating it learns a general segmentation prior rather than dataset-specific features.

## Relation to Prior Work

This paper builds on the superpoint graph cut framework for 3D instance segmentation (Hui et al., NeurIPS 2022; Tang et al., ACCV 2022), where a scene is represented as a graph of geometrically homogeneous superpoints and segmentation reduces to graph partitioning. The key departure is a conceptual inversion of the standard 2D-to-3D lifting pipeline: rather than segmenting each 2D view first and then resolving cross-view correspondences (as in SAM3D, Panoptic Lifting, and related work), the method pre-segments the 3D geometry into superpoints and then queries SAM's prompt mechanism per-superpoint to determine inter-superpoint affinity. Additionally, it introduces a pseudo-label training strategy using CropFormer's 2D instance predictions to supervise a GNN without any manual 3D annotations, distinguishing it from both fully supervised point-cloud methods (Mask3D) and purely unsupervised lifting approaches.

## Why It Matters / Open Questions

The most practically significant finding is that a GNN trained solely on pseudo-labels from ScanNet200 generalizes to both ScanNet++ (different capture hardware) and KITTI-360 (outdoor scenes), suggesting the learned graph-refinement prior is scene-type-agnostic. This offers a path toward 3D instance segmentation without expensive 3D annotation, though the method still requires both calibrated geometry and multi-view images, limiting its applicability to settings where both are available. A noted limitation is that superpoint-based pre-segmentation cannot separate objects embedded within a single superpoint (e.g., a poster on a wall), pointing toward future work that incorporates semantic cues into the pre-segmentation stage. The large absolute gap with supervised Mask3D on in-distribution data (22.1 vs. 53.3 mAP on ScanNet200) remains an open question for closing the unsupervised-to-supervised performance gap.

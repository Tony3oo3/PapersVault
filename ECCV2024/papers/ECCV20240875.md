## Problem

Despite the importance of subpopulation distribution for tasks like dataset organization, subpopulation shift mitigation, and slice discovery, no prior work systematically discovers and characterizes subpopulation structures within datasets. Existing hierarchical datasets (e.g., Metashift, NICO++) rely on manual annotation and organize images along a single dimension, while their class-attribute-subpopulation structure ignores the category of attributes (dimensions), causing attribute overlap and confusion.
![Teaser figure](../imgs/ECCV20240875/cropped_page1_idx0.webp)

## Input / Output

The method takes an image dataset with class labels as input; an MLLM (LLaVA 1.5) first converts each image into a detailed text caption, which then serves as the sole input to all subsequent LLM (GPT-4) prompt engineering steps. The primary output is a four-layer hierarchical structure (class → dimension → attribute → subpopulation) with per-image attribute assignments across all discovered dimensions. Downstream, this structure yields augmented images (via diffusion models conditioned on LLM-generated sentences sampling underrepresented attributes) and textual slice topics summarizing high-error subpopulations.

## Method

SSD-LLM is a fully automated, prompt-engineering-based pipeline with four stages: (1) MLLM caption extraction centered on the main subject, (2) Criteria Initialization using a sample-based generate-and-select paradigm where the LLM iteratively proposes dimensions and attributes from caption batches and an LLM summarization step consolidates them, (3) Criteria Refinement that uses self-consistency of LLM classification responses as a diagnostic signal—inconsistent assignments trigger a self-refining prompt to prune redundant or add missing attributes—and (4) Subpopulation Assignment where each caption is mapped to one attribute per dimension. The key structural innovation is the four-layer class-dimension-attribute-subpopulation hierarchy, which resolves the attribute-overlap problem of prior class-attribute structures by explicitly articulating classification dimensions. For downstream tasks, Task-specific Tuning applies the discovered structure: for subpopulation shift, it samples attributes from underrepresented subpopulations and uses an LLM to compose diverse diffusion prompts; for slice discovery, it computes per-subpopulation error rates and uses the LLM to summarize high-error groups into interpretable slice topics.

## Results

On the subpopulation shift benchmark (Waterbirds, Metashift, NICO++), SSD-LLM achieves 88.0% average accuracy and 62.0% worst-group accuracy, surpassing the best prior method LISA (85.2% / 58.3%) by +1.6% and +3.3% respectively. On slice discovery over six ImageNet superclasses, SSD-LLM identifies slice topics with a 47.39% average model error rate, exceeding Domino (43.44%) by 3.95 points. For dataset subpopulation organization, SSD-LLM reaches 0.955 clustering accuracy on PPMI (musical instrument) and 0.817 on Stanford40 (action), outperforming both SCAN and the human-in-the-loop IC|TC baseline.

## Baselines & Comparisons

SSD-LLM outperforms all 17 baselines on both average and worst-group accuracy across the three subpopulation shift datasets. Against the strongest subgroup-robust method LISA (58.3% worst-group), SSD-LLM gains +3.7 points; against the best diffusion-based method Class-Attribute (58.7%), the gain is +3.3 points. On slice discovery (ImageNet), SSD-LLM (47.39% topic error rate) beats Domino (43.44%) by 3.95 points and B2T (42.58%) by 4.81 points, while also producing more semantically consistent slice descriptions. For dataset subpopulation organization, SSD-LLM surpasses the human-in-the-loop IC|TC on Stanford40 Action (0.817 vs 0.747) and PPMI (0.955 vs 0.934), and dramatically outperforms the unsupervised SCAN on all six dataset-criterion pairs (e.g., 0.955 vs 0.598 on PPMI). The paper notes that IC|TC requires human-assigned text prompts and thus does not scale, whereas SSD-LLM is fully automated.

## Relation to Prior Work

This paper carves new ground by introducing the concept of 'subpopulation structure' as a unified, interpretable formalization (class–dimension–attribute–subpopulation hierarchy) that subsumes three previously separate tasks: dataset organization, subpopulation shift mitigation, and slice discovery. It departs from prior hierarchical dataset construction (Metashift, NICO++, Waterbirds) by replacing manual annotation with an automated LLM/MLLM pipeline, and from caption-based methods (ALIA, Bias2Text, ICTC) by adding a systematic dimension layer and self-consistency-based criteria refinement. The method repurposes established prompt-engineering techniques (in-context learning, chain-of-thought, self-consistency, self-refining) not for their original NLP purposes but as a dataset-analysis workflow, positioning LLMs as 'dataset analysts' rather than task solvers.

## Why It Matters / Open Questions

The unified subpopulation-structure framework offers a practical, automatable alternative to the labor-intensive manual annotation that has bottlenecked hierarchical dataset construction, and the demonstration that a purely data-based LLM+diffusion pipeline can outperform model-based robustness methods (GroupDRO, LISA) on worst-group accuracy is a useful signal for practitioners. However, the approach is currently limited to image datasets, depends on GPT-4 for quality, and inherits potential biases from the underlying MLLM/LLM. Open questions include whether the four-layer structure generalizes to other modalities (video, audio), whether the framework can guide unbiased dataset construction at scale, and whether the prompt-engineering pipeline remains reliable as datasets grow beyond the tested sizes.

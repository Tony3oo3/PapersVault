## Problem

Existing learned image compression methods either optimize for human perceptual quality or for one or a few predetermined downstream tasks, leaving the more prevalent open-set scenario—where a compressed image must serve a variety of unforeseen machine vision tasks—largely unaddressed. Preserving low-level pixel fidelity alone is insufficient to maintain semantic information needed by diverse downstream models, causing significant performance degradation at low bitrates.
![Teaser figure](../imgs/ECCV20241905/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image (cropped to 256×256 patches during training) along with a set of associated vision tasks as input and produces a single unified compact latent embedding (h×w×d) that simultaneously enables pixel-level image reconstruction and serves as a semantic feature for multiple downstream tasks. The embedding is generated by aggregating N task-specific auto-encoder outputs via average pooling and quantization, and the reconstructed image is decoded from this unified code at a constrained bitrate (e.g., 0.15 bpp). Downstream task models (Faster R-CNN, Mask R-CNN, Mask2Former, DeepLabV3, BLIP) are frozen and consume the reconstructed image directly, decoupling the compression framework from specific task architectures.

## Method

The DMTUIC framework comprises two modules trained sequentially. The Multi-Task Collaborative Embedding (MTCE) module employs N task-specific auto-encoders that each compress the input into a task-aware latent code under a rate-distortion constraint; a Cross-Task Loss forces each encoder-decoder pair to also reconstruct and predict labels for other tasks, injecting task-common knowledge and promoting generalization. The unified embedding is then formed by average-pooling and quantizing all task-specific codes. The Diffusion-based Invariant Knowledge Learning (DIKL) module aligns this unified embedding to a learnable memory bank of L representative features (via softmax-weighted retrieval) to distill task-invariant knowledge, then fine-tunes a pre-trained Stable Diffusion latent model with the aligned embedding injected as a condition through a zero-initialized parallel U-Net branch, using denoising in latent space to enhance representational robustness toward unseen tasks.

## Results

At ~0.15 bpp on MS-COCO, DMTUIC achieves 30.3 mAP (object detection), 27.8 mAP (instance segmentation), 66.73 aAcc (semantic segmentation), 44.69 PQ-all (panoptic segmentation), and 82.21% accuracy (VQA), outperforming the strongest baseline HiFiC on all five tasks. The headline BD-rate reductions versus HiFiC are 52.25%/51.68%/48.87%/48.07%/6.29% for mAP/mAP/aAcc/PQ-all/accuracy respectively. In the open-set setting (Ours-Open, where one task is held out during training), performance drops by only 1.3–4.2% yet still surpasses all baselines on the unseen task.

## Baselines & Comparisons

DMTUIC outperforms all five baselines across every task. Against the strongest baseline HiFiC (perceptual-oriented learned compression), the gains are 3.3 mAP on object detection (30.3 vs 27.0), 3.0 mAP on instance segmentation (27.8 vs 24.8), 1.13 aAcc on semantic segmentation (66.73 vs 65.60), 2.21 PQ-all on panoptic segmentation (44.69 vs 42.48), and 0.19% on VQA (82.21 vs 82.02), translating to 48–52% BD-rate reduction on the four COCO tasks. Against the fidelity-oriented ELIC, improvements are larger: 4.7 mAP on object detection and 6.5 aAcc on semantic segmentation. Traditional codecs (JPEG, WebP, VTM-17.0) are far behind, with JPEG achieving only 3.7 mAP on object detection versus 30.3 for DMTUIC. Notably, even in the open-set zero-shot setting (Ours-Open), the method retains 28.8 mAP on the unseen detection task, still exceeding HiFiC's 27.0 mAP on seen tasks.

## Relation to Prior Work

This paper extends learned image compression (auto-encoder with entropy modeling, following Ballé et al. and ELIC/HiFiC) by coupling it with a latent diffusion model (Stable Diffusion) for invariant knowledge distillation. It departs from prior machine-vision-oriented compression, which is typically tied to one or a few pre-defined tasks or specific backbone architectures, by introducing an open-set formulation where the compressed embedding must serve both seen and unseen downstream tasks. The Multi-Task Collaborative Embedding module with its cross-task loss is a novel architectural contribution that aggregates task-specific auto-encoder latents, while the Diffusion-based Invariant Knowledge Learning module repurposes a pre-trained diffusion U-Net with a memory-bank-conditioned parallel branch to enhance generalization.

## Why It Matters / Open Questions

The open-set collaborative compression framing addresses a practical gap: real-world deployed codecs must serve unknown future tasks, yet prior work assumes a fixed task set. The paper demonstrates that machine-vision-friendly compression and human perceptual quality need not conflict, which is a useful finding for codec design. However, the evaluation is limited to a single dataset (MS-COCO) with only five tasks, and the authors themselves note that 'no clear evidence suggests that all tasks are mutually beneficial,' leaving open how the approach scales to dozens of heterogeneous tasks or truly out-of-domain distributions. The diffusion sampling cost at inference time is acknowledged but not fully quantified in the main text.

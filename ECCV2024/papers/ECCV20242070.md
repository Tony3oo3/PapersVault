## Problem

Prior procedure planning models assume a fixed, known number of action steps, which is unrealistic because the required sequence length varies with the visual difference between initial and goal states. Additionally, temporal dependencies between consecutive steps are only implicitly captured through intermediate states, and the high cost of step-level or sequence-level annotations limits training data scalability. This paper introduces the setting of adaptive procedure planning, where the procedure length is not predetermined, and addresses all three challenges simultaneously.

## Input / Output

The model takes two visual frames — the initial state and the goal state — encoded by an S3D network pre-trained on HowTo100M, along with a predicted task class representation from an MLP classifier. It outputs a variable-length sequence of action step labels from a fixed vocabulary, terminated by a learned END token, so the model autonomously decides when the procedure is complete. Action steps are represented as language embeddings (e.g., 'add butter', 'flip bread'), and the output sequence length can range from 1 to 6+ steps depending on the visual gap between states.

## Method

RAP combines an auto-regressive transformer base planner with a retrieval-augmented memory module. The base planner sequentially predicts action embeddings conditioned on the initial state, goal state, task class, and previously generated actions, using a contrastive loss during training and a START/END token scheme to support variable-length generation. The retrieval module maintains a datastore of D=1000 learnable key-value pairs (context vectors mapped to action labels); at each step, the K nearest keys are retrieved via cosine similarity to the current context vector, and their softmax-normalized distribution is linearly interpolated with the base planner's output (λ=0.1). Training proceeds in two stages: first the base planner is trained with noise-contrastive estimation, then the retrieval module is added and trained with cross-entropy on the interpolated distribution. A weakly-supervised extension uses a Drop-DTW-inspired video grounding algorithm to generate pseudo-annotations from unannotated task-relevant videos, expanding the training set without manual step-level labeling.

## Results

On CrossTask (T=3), RAP with weakly-supervised unannotated data achieves SR=30.51%, mAcc=62.68%, and mIoU=75.92%, outperforming the strongest prior method Skip-Plan (SR=28.85%, mAcc=61.18%, mIoU=74.98%). On COIN (T=3), RAP reaches SR=24.47%, mAcc=47.59%, mIoU=85.24%, surpassing E3P (SR=19.57%, mAcc=31.42%, mIoU=84.95%). In the novel variable-length setting (Table 4), RAP achieves mES=63.86% on CrossTask versus 33.43% for a retrieval-based baseline, a 29.36% absolute gain in the new edit-score metric.

## Baselines & Comparisons

RAP outperforms all nine baselines on both CrossTask and COIN across SR, mAcc, and mIoU. Against the strongest vision-supervised model Ext-GAIL [2], RAP gains +7.97% SR, +12.89% mAcc, and +13.93% mIoU at T=3 on CrossTask. Among language-supervised methods, RAP beats P3IV [24] by +5.99% SR and +2.83% mAcc (T=3), E3P [22] by +3.56% SR and +1.4% mIoU (T=4), and Skip-Plan [12] by +0.38% SR (T=3) and +1.4% SR (T=4). Against PDPP [23], which uses a more generous 3-second state window, RAP still wins on all three metrics (SR 38.51 vs 37.20, mAcc 65.18 vs 64.67, mIoU 77.44 vs 66.57) when evaluated under PDPP's state definition. On COIN, RAP leads E3P by +4.90% SR and +16.17% mAcc at T=3, and outperforms Skip-Plan by +0.82% SR and +4.40% mIoU at T=3. In the variable-length setting (Table 4), RAP's mES of 62.79% (without unannotated data) nearly doubles the retrieval-based baseline's 33.43%, confirming the advantage of the autoregressive architecture over simple retrieval for open-ended sequence generation.

## Relation to Prior Work

RAP extends the procedure planning line (DDN, Ext-GAIL, P3IV, E3P, Skip-Plan, PDPP) by replacing the fixed-horizon assumption with an auto-regressive transformer that generates variable-length action sequences terminated by a learned END token. The retrieval-augmented memory module directly adapts the kNN interpolation mechanism from neural language modeling (Khandelwal et al., Grave et al.) to exploit state-action temporal dependencies in the training data, while the weak-supervision pipeline borrows the Drop-DTW video grounding algorithm to generate pseudo-annotations from unannotated instructional videos. Conceptually, the paper repurposes three established NLP/video techniques—autoregressive generation, nearest-neighbor retrieval, and sequence alignment—into a unified framework for a reformulated procedure planning task.

## Why It Matters / Open Questions

The fixed-length assumption in prior procedure planning is a genuine practical limitation: real tasks vary in complexity, and requiring a separate model per horizon is infeasible. The weak-supervision approach via thematic video-plan alignment offers a cost-effective path to scaling training data, though the modest gains (≈1.5% SR with 100% unannotated data) and the dip at 25% data suggest the pseudo-label quality is still a bottleneck. Open questions include whether the retrieval component's benefit persists at larger memory sizes or with more diverse task domains, whether the edit-score metric will be adopted as a standard, and whether the approach generalizes beyond the cooking/repair tasks in CrossTask and COIN to more open-ended procedural domains.

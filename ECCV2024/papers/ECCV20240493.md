## Problem

Existing zero- and few-shot keypoint detection methods are limited to single-modality prompts (either visual support images or simple text templates) and fail on unseen keypoint semantics or diverse natural-language queries. The paper identifies that prompt diversity across modality, semantics (seen vs. unseen keypoints), and language formulation remains largely unexplored, preventing a unified detector that handles all realistic prompting scenarios.
![Teaser figure](../imgs/ECCV20240493/cropped_page1_idx0.webp)

## Input / Output

The model accepts a 384×384 query image plus any combination of K support images with annotated keypoints (visual prompt) and/or one or more text descriptions of target keypoints (text prompt), supporting 0-shot, K-shot, or multimodal testing. For diverse natural-language inputs (e.g., 'Can you find the left eye, right ear and nose?'), an LLM parser first extracts keypoint and object keywords before the model processes them. Output is a set of N upsampled keypoint heatmaps (u×l × u×l per keypoint) from which pixel coordinates are decoded; during training, group-specific supervision is applied to visual- and text-induced heatmap groups separately.

## Method

OpenKD uses a frozen CLIP text encoder and a fine-tuned RN50 image encoder, with residual adaptation networks to align both modalities into a shared feature space. It builds a unified keypoint prototype set by aggregating local image features via Gaussian-weighted summation (visual prototypes) and encoding text features (textual prototypes), then correlates each prototype with the query feature map via channel-wise multiplication and decodes to heatmaps through a class-agnostic decoder with upsampling. Training combines heatmap regression loss with intra-modality contrastive loss (Ltt) for textual prototype discrimination and inter-modality contrastive loss (Lvt) with stop-gradient on text features to align visual prototypes toward the stronger textual representations. The key innovation for unseen keypoints is LLM-based text interpolation: GPT-3.5 with chain-of-thought reasoning generates candidate auxiliary keypoint texts between base keypoints, and a false-text-control (FTC) sampling strategy uses visual-text cosine similarity to reject low-quality interpolations, significantly boosting zero-shot novel keypoint detection. An LLM parser (GPT-3.5, >96% accuracy) decomposes diverse natural-language prompts into simple keypoint-object pairs, reducing the language-diversity problem to standard template-based prompting.

## Results

On the Animal Pose dataset (1-shot, novel keypoints), OpenKD achieves 50.32% PCK, outperforming the prior best FSKD-D (44.75%) by 5.6 points; with text prompts added at test time (OpenKD+T), it reaches 63.19%. For 0-shot novel keypoint detection, OpenKD scores 63.37% PCK on Animal Pose, surpassing CLAMP (21.92%) by over 40 points and even the CLAMP variant trained with auxiliary texts (CLAMP†, 59.84%). On AwA, OpenKD+T achieves 79.02% (1-shot novel) and 78.64% (0-shot novel), while on CUB it reaches 78.39% (1-shot novel) and 70.16% (0-shot novel).

## Baselines & Comparisons

OpenKD outperforms all five baselines on the majority of tasks. Against the generic few-shot learning methods (ProtoNet, RelationNet, LwoF), OpenKD achieves substantially higher PCK on novel keypoints — e.g., 50.32% vs. 15.47–18.40% on Animal Pose (1-shot) — reflecting the advantage of keypoint-specific architecture over generic prototype/relation networks. Compared to the dedicated FSKD methods (FSKD-R and FSKD-D from the same group), OpenKD gains 5.6–11.6 points on novel keypoint PCK across datasets, with the largest margin on Animal Pose (50.32% vs. 44.75%) and AwA (66.71% vs. 64.76%). For zero-shot detection, OpenKD (63.37% novel on Animal Pose) surpasses CLAMP (21.92%) by over 40 points, and also beats CLAMP† (59.84%), which was augmented with the paper's auxiliary texts, confirming that the full OpenKD architecture (contrastive losses, multimodal prototypes) provides additional gains beyond text interpolation alone. On CUB and NABird, the 1-shot improvements over FSKD-D are modest (0.5–2.3 points), which the authors attribute to the greater difficulty of reasoning auxiliary texts for fine-grained bird keypoints.

## Relation to Prior Work

This paper unifies two previously separate task formulations—few-shot keypoint detection (FSKD, building on Lu & Koniusz's episode-based framework and visual interpolation [27]) and zero-shot keypoint detection (ZSKD, building on CLIP-based approaches like CLAMP [56])—into a single Z-FSKD model that accepts visual, textual, or both prompts via a shared multimodal prototype set. It departs from prior FSKD by adding a textual modality and from prior ZSKD by adding visual prompting, and introduces LLM-based text interpolation (using chain-of-thought prompting [48]) to bridge the semantic gap for unseen keypoint texts. The LLM-as-parser idea for handling diverse language prompts is a practical repurposing of GPT-3.5/Vicuna that has no direct precedent in the keypoint detection literature.

## Why It Matters / Open Questions

The unified Z-FSKD framework and the text interpolation with false-text control provide a practical recipe for improving zero-shot novel keypoint detection (e.g., 63% vs. 25% PCK on Animal Pose), and the LLM parsing module (>96% accuracy) offers a low-cost path to handling real-world diverse language queries. However, gains on CUB and NABirds are modest, suggesting the text interpolation quality degrades with more complex or fine-grained keypoint vocabularies. Open questions include whether the approach scales to non-animal domains (e.g., human or object keypoints), how sensitive performance is to the specific LLM used, and whether the reliance on GPT-3.5 for training-time text generation creates a reproducibility bottleneck.

## Problem

Softmax attention in vision Transformers incurs quadratic O(N²) computational cost, making global receptive fields impractical at high resolutions, while existing linear attention methods achieve O(N) complexity but suffer from insufficient expressiveness. Prior work treats these as separate paradigms—either restricting receptive fields (window/sparse attention) or improving linear attention mappings—without a unified mechanism that preserves both global context modeling and computational efficiency.
![Teaser figure](../imgs/ECCV20241326/cropped_page1_idx0.webp)

## Input / Output

The Agent Attention Module is a drop-in replacement for Softmax attention in existing vision Transformers, consuming standard RGB images (224² for classification, 1280×800 for detection, 512×2048 for segmentation) or text-conditioned latent representations for diffusion models. A key design parameter is the number of agent tokens n (typically 9–49), which is much smaller than the number of query tokens N, yielding O(Nnd) complexity. For Stable Diffusion, agent tokens are obtained via token merging rather than pooling, and the module is applied only during early diffusion steps to avoid quality degradation.

## Method

Agent Attention introduces a small set of learnable or pooled agent tokens A ∈ R^{n×C} that mediate information flow between queries and keys through two sequential Softmax attention operations: first, A acts as queries to aggregate global features from K and V (agent aggregation), then Q queries A to broadcast the aggregated information back (agent broadcast). This two-step process is mathematically equivalent to a generalized linear attention with mapping functions φ_q(Q) = σ(QA^T) and φ_k(K) = (σ(AK^T))^T, seamlessly unifying Softmax and linear attention. The full module augments this core with an Agent Bias (constructed from RPB-style components) to inject spatial positional information and a depthwise convolution (DWC) to restore feature diversity lost in the linear-attention-like computation. The module is plug-and-play across architectures (DeiT, PVT, Swin, CSwin) and can be applied to pre-trained diffusion models without retraining.

## Results

On ImageNet-1K (224²), Agent Attention consistently improves over its Softmax-attention counterparts across four architectures: Agent-DeiT-T reaches 74.9% top-1 (+2.7 over DeiT-T), Agent-PVT-S reaches 82.2% (+2.4 over PVT-S), and Agent-Swin-T reaches 82.6% (+1.3 over Swin-T), all at comparable or lower FLOPs. On COCO object detection, Agent-PVT-T gains +4.7 box AP (36.7→41.4) and Agent-Swin-S gains +1.5 box AP (45.7→47.2). On ADE20K semantic segmentation, Agent-PVT-T improves mIoU by +3.61 (36.57→40.18) and Agent-Swin-T by +2.17 (44.51→46.68). When plugged into Stable Diffusion without retraining, AgentSD achieves 1.84× faster generation than SD while producing a 0.9 lower FID than ToMeSD at equivalent speed.

## Baselines & Comparisons

Agent Attention outperforms all four backbone baselines (DeiT, PVT, Swin, CSwin) on ImageNet-1K, with the largest gains on PVT variants (+2.0 to +3.3 top-1) and smaller but consistent gains on Swin (+0.5 to +1.3) and CSwin (+0.4 to +0.5). Against other linear attention methods (Table 8), Agent Attention surpasses Focused Linear Attention [11] by +0.8 on DeiT-T (74.9 vs 74.1) and +0.5 on Swin-T (82.6 vs 82.1), and leads Efficient Attention [33], Hydra Attention [2], and Linear Angular Attention [47] by 2–6 points. On COCO detection, Agent-PVT-T achieves 41.4 box AP, exceeding PVT-M (42.0) by a narrow margin while using fewer FLOPs, and Agent-Swin-S (47.2) beats Swin-S (45.7) by +1.5 AP. On ADE20K, Agent-PVT-T (40.18 mIoU) surpasses PVT-S (41.95) only slightly but exceeds PVT-T by +3.61, and Agent-Swin-B (48.73) edges out Swin-B (48.13) by +0.60. For image generation, AgentSD dominates both Stable Diffusion [30] and ToMeSD [3] on speed (1.84× and 1.69× faster) while simultaneously improving FID by 0.9 over ToMeSD at matched speed, a rare speed-and-quality win.

## Relation to Prior Work

This paper positions itself at the conceptual intersection of two previously treated-as-disparate attention paradigms: Softmax attention (high expressiveness, quadratic cost) and linear attention (linear cost, limited expressiveness). Rather than following the dominant lines of work that either restrict receptive fields (Swin, PVT, NAT) or design better mapping functions for linear attention (Efficient Attention, SOFT, Nyströmformer, FLatten), it introduces a quadruplet (Q, A, K, V) formulation whose two-stage Softmax computation is shown to be algebraically equivalent to a generalized linear attention with learned, data-dependent mapping functions. The practical design borrows from FLatten Transformer's depthwise convolution for diversity restoration and from RPB-style relative position bias for spatial awareness, while the Stable Diffusion application leverages Token Merging for agent token acquisition.

## Why It Matters / Open Questions

The linear complexity with respect to token count enables global receptive fields at high resolutions without the quadratic blowup that has forced prior ViTs into windowed or sparse patterns, making it particularly relevant for high-resolution classification, dense prediction, and video/multimodal settings the authors flag as future directions. The plug-and-play applicability across DeiT, PVT, Swin, CSwin, and Stable Diffusion (with consistent gains and no architectural redesign) lowers the adoption barrier considerably. A notable open question is whether the simple pooling-based agent token strategy is optimal, and whether the equivalence to generalized linear attention can be exploited for further theoretical analysis or adaptive token allocation. The Stable Diffusion result—improved quality without retraining—suggests the agent bottleneck may act as a beneficial regularizer, a hypothesis the paper does not fully explore.

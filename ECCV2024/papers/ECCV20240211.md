## Problem

Existing online Chinese handwriting beautification methods either treat characters as static images (losing stroke order, coherence, and writing dynamics) or use sequence models that randomly select style references and apply decomposition/averaging operations that weaken fine-grained style features. This paper addresses how to correct and optimize user handwriting trajectories while faithfully preserving the individual writer's style, using only a small number of user samples.
![Teaser figure](../imgs/ECCV20240211/cropped_page2_idx1.webp)

## Input / Output

The method takes a user's online handwriting trajectory encoded as a variable-length sequence of discrete drawing commands (MoveTo/LineTo with 2D coordinates, analogous to Bezier curve control points) and K=3 style reference trajectories selected from a fixed 500-character reference set via a component-maximization mapping. The output is a beautified trajectory in the same drawing-command format, preserving stroke order and writing dynamics. During inference, quantized style token indices are stored to skip style encoder computation, reducing latency.

## Method

The architecture is a Transformer encoder-decoder where a 6-layer content encoder and 6-layer style encoder process the input and reference trajectories respectively. Two key innovations distinguish the approach: (1) style features are vector-quantized into a latent space constructed as the Cartesian product of binary (±1) single-dimensional variable sets, sparsifying the representation and removing redundant features with minimal impact on stylization; (2) a cross-attention-based style aggregation module learns spatial correspondences at the Chinese character component level between style and content glyphs, assigning fine-grained local styles to each stroke region rather than averaging globally. Training jointly optimizes style transfer and trace reconstruction using cross-entropy losses on commands and coordinates, an entropy loss for confident quantization, a commitment loss, and a Bezier curve alignment loss that samples intermediate points along each segment.

## Results

On the CASIA-OLHWDB test set, the proposed method achieves a Style Score of 87.50, Content Score of 95.04, DTW distance of 0.8814, and User Preference of 64.12%, outperforming all five baselines on every metric. The closest competitor, SDT [5], scores 82.23 in Style Score and 1.0089 in DTW, yielding a 5.27-point style advantage and a 12.7% reduction in DTW for the proposed method. The method also generalizes to Japanese (TUAT HANDS) and Korean handwriting generation.

## Baselines & Comparisons

The proposed method outperforms all five baselines on every evaluation metric (Style Score, Content Score, DTW, and User Preference). Against the strongest baseline SDT [5], it gains +5.27 in Style Score, +0.43 in Content Score, reduces DTW by 0.1275 (12.7%), and increases User Preference by 5.88 percentage points. The gap widens substantially against image-based methods: DeepImitator [46] trails by 40.62 in Style Score and 54.05% in User Preference, reflecting the advantage of trajectory-based modeling over raster image approaches. Among sequence-based baselines, WriteLikeYou [30] is the second-strongest (Style 72.21, DTW 1.2623), but the proposed method still leads by 15.29 in Style Score and 22.80% in User Preference. The two RNN-based baselines (Drawing [44] and FontRNN [31]) lag far behind, with Style Scores below 35, indicating that single-reference and non-attention architectures struggle to capture fine-grained style from diverse reference combinations.

## Relation to Prior Work

This paper extends the sequence-based online Chinese handwriting generation line (Drawing, FontRNN, WriteLikeYou, SDT) by addressing two specific weaknesses: random style-reference selection that hampers consistent style extraction, and the over-smoothing of style features through decomposition and averaging. It departs from prior work by introducing a fixed, component-matched style reference set grounded in Chinese character structure, a cross-attention style aggregation module that operates at the radical/component level, and a vector-quantization scheme that sparsifies style features into binary single-dimensional variables. The vector quantization idea draws from VQ-VAE-style compression but is repurposed here for style-feature sparsification rather than general representation learning.

## Why It Matters / Open Questions

The method offers a practical pipeline for electronic writing devices where users provide only a few samples and receive beautified traces that preserve their personal style, with demonstrated robustness to distorted input and incorrect stroke order. However, the paper acknowledges that human experts can still distinguish generated from real handwriting, and the evaluation is confined to Chinese (with brief Japanese/Korean validation), leaving open whether the component-matching strategy generalizes to scripts without a rich radical system. The fixed 500-character reference set and K=3 style inputs are heuristically chosen; a principled way to determine optimal reference set size and composition remains an open question.

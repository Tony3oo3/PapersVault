## Problem

Existing OOD object detection methods synthesize outlier samples in the latent space of a closed-set detector or via adversarial perturbations, inherently biasing them toward the ID data distribution and limiting semantic diversity. No prior work has leveraged foundation models trained on large-scale open-set data to synthesize photorealistic, scene-level OOD images with object-level annotations for OOD detection.
![Teaser figure](../imgs/ECCV20240309/cropped_page1_idx1.webp)

## Input / Output

At inference, the method takes a scene-level RGB image, runs a pre-trained Faster R-CNN (ResNet-50) to obtain instance-level multi-level features for each detected object, and a lightweight 3-layer MLP outputs a binary OOD/ID score per object. During the data synthesis phase, the pipeline consumes ID training images with their bounding boxes and text prompts (novel concept names generated by GPT-4), and produces edited scene-level images with SAM-refined bounding boxes around the inserted novel objects. The final OOD training set consists of instance-level features extracted only from the edited novel-object regions, not from the full image.

## Method

SyncOOD is a fully automated data curation pipeline that distills open-world knowledge from foundation models into OOD training data. GPT-4 is prompted with in-context examples to imagine novel object concepts for each ID category that are semantically distinct yet share usage-scenario and volume similarity. Stable Diffusion Inpainting then performs box-conditioned region-level editing, replacing the ID object with the novel concept while preserving the surrounding scene context. SAM refines the bounding boxes of edited objects, and an IoU threshold filters out unstable edits. A feature-similarity filter (cosine similarity between edited and original object features within a [ε_low, ε_up] band) selects hard OOD samples that are visually confusable with ID objects. A 3-layer MLP is trained with binary cross-entropy on these filtered features to optimize the ID/OOD decision boundary, while the base detector remains frozen.

## Results

On the four ID/OOD dataset splits (PASCAL-VOC→MS-COCO, PASCAL-VOC→OpenImages, BDD-100K→MS-COCO, BDD-100K→OpenImages), VOS+Ours achieves the best FPR95 of 34.97, 11.25, 23.09, and 14.12, while Faster R-CNN+Ours achieves 36.44, 13.34, 22.67, and 12.96. Corresponding AUROC values range from 86.52 to 96.96, with the highest being 96.96 (PASCAL-VOC→OpenImages) and 96.41 (BDD-100K→OpenImages). The method uses only ~25% of the synthetic data volume compared to SAFE while achieving substantially lower FPR95 across all splits.

## Baselines & Comparisons

The paper's method (Faster R-CNN+Ours / VOS+Ours) outperforms all 13 baselines on FPR95 across every dataset split. The closest competitor is SAFE [59], which achieves FPR95 of 47.40/20.06/32.56/16.04; SyncOOD reduces this to 36.44/13.34/22.67/12.96 (Faster R-CNN) or 34.97/11.25/23.09/14.12 (VOS), a 10–11 point FPR95 improvement on PASCAL-VOC splits and ~3–9 points on BDD-100K. Among latent-space synthesis methods, DFDD [60] (FPR95 41.34/44.52/30.71/22.67) and SR-VAE [61] (42.17/46.26/32.23/21.81) are the strongest, yet SyncOOD still leads by 6–33 FPR95 points. Post-hoc scoring baselines (MSP, ODIN, Mahalanobis, Energy score, Gram matrices, Generalized ODIN, CSI) all report FPR95 above 47 on at least one split, with Mahalanobis [34] performing worst (96.46 on VOC→COCO). GAN-synthesis [33] and SIREN-KNN [12] fall in the mid-range (FPR95 47–61), while VOS [15] (47.53/51.33/44.27/35.54) is the direct architectural baseline that SyncOOD augments. Notably, SyncOOD achieves these gains using only ~25% of SAFE's synthetic data volume and a single instance-level feature per edited object, versus SAFE's 100k+ extracted features.

## Relation to Prior Work

This paper departs from the dominant paradigm of OOD object detection, which synthesizes outliers in the latent space of a pre-trained detector (VOS, SR-VAE, DFDD) or via adversarial perturbation (SAFE), by instead generating photo-realistic scene-level OOD images in pixel space using a pipeline of foundation models: GPT-4 for semantic-novel concept discovery, Stable Diffusion Inpainting for region-level editing, and SAM for bounding-box refinement. It builds directly on the VOS/SAFE training framework (lightweight MLP on detector features with binary OOD/ID loss) but replaces their data generation entirely. The key conceptual departure is decoupling OOD concept sampling (open-world, via LLM) from visual generation (controllable, via diffusion inpainting), which prior latent-space methods could not achieve.

## Why It Matters / Open Questions

The paper demonstrates that open-world knowledge embedded in off-the-shelf foundation models can be effectively distilled into a small set of high-quality OOD training samples, achieving SOTA with only ~25% of the auxiliary data used by SAFE. The finding that context consistency is critical—small background edits cause the detector to flag objects as OOD due to context bias rather than object identity—provides a useful diagnostic for future OOD data synthesis. Open questions include whether the pipeline scales to hundreds of ID categories, whether it handles truly novel (not merely 'similar but different') OOD objects, and how sensitive performance is to the quality of the underlying foundation models as they evolve.

## Problem

Existing federated incremental learning methods are designed for class-incremental settings where new tasks introduce new categories, but in real-world deployments tasks often share the same classes while shifting across domains (e.g., handwritten digits vs. street-view digits). This paper is the first to formally define Federated Domain-Incremental Learning (FDIL) and addresses the catastrophic forgetting that arises when a single model must adapt to successive domain shifts without access to previous data.
![Teaser figure](../imgs/ECCV20241219/cropped_page3_idx0.webp)

## Input / Output

The method consumes streaming RGB image tasks where each task corresponds to a new domain (e.g., MNIST→EMNIST→USPS→SVHN for digits, or Clipart→Infograph→Painting→Quickdraw→Real→Sketch for objects), with all tasks sharing the same class labels. At inference, rather than selecting a single model, the client produces a weighted ensemble prediction by running the input through all personalized local models and combining their soft outputs using weights derived from auxiliary classifier scores, eliminating the need for an explicit task/domain ID at test time.

## Method

pFedDIL equips each personalized local model with a small binary auxiliary classifier (sharing front feature-extraction layers with the main ResNet-18 classifier) that learns to recognize samples from its own task domain. When a new task arrives, each client computes a 'knowledge matching intensity' vector by averaging auxiliary classifier outputs over the new task's samples, then either initializes a fresh model or reuses the most-correlated previous model based on a threshold λ. During training, a knowledge-migration loss pulls the new model's parameters toward all other personalized models weighted by their matching intensities, enabling cross-task knowledge transfer. At inference, all personalized models produce soft predictions that are combined via a softmax-normalized weighting from the auxiliary classifiers, yielding an automatic ensemble without requiring domain labels.

## Results

On Digit-10 (MNIST→EMNIST→USPS→SVHN, α=0.1), pFedDIL achieves 89.28% average top-1 accuracy across all four domain tasks, outperforming the strongest baseline FedCIL (86.31%) by 2.97%. On Office-31 (Amazon→DSLR→Webcam, α=1), pFedDIL reaches 46.17% average accuracy, a 12.82% improvement over FedAvg (33.35%). On DomainNet (six domains, α=10), pFedDIL attains 51.69% average accuracy, surpassing FedCIL (47.64%) by 4.05%. The method also requires the fewest communication rounds to converge (e.g., 379 rounds on Digit-10 vs. 480 for FedAvg).

## Baselines & Comparisons

pFedDIL outperforms all four primary baselines across all three datasets. Against FedAvg [24], the improvement ranges from +6.18% (Digit-10) to +12.82% (Office-31), indicating that standard federated averaging suffers severe catastrophic forgetting under domain shift. FedProx [19] narrows the gap slightly on Digit-10 (83.10% vs. 89.28%) but still trails by 6.18%, confirming that the proximal regularization alone cannot address domain-incremental forgetting. FedCIL [28], the closest competitor, achieves 86.31% on Digit-10 and 44.36% on Office-31, yet pFedDIL still leads by 2.97% and 1.81% respectively, demonstrating that generative replay designed for class-incremental settings is suboptimal when classes remain fixed across domains. DANN+FL [10] performs comparably to FedProx (83.51% on Digit-10, 43.67% on Office-31), confirming that adversarial domain adaptation without an incremental learning mechanism is prone to forgetting. The largest absolute gain is on Office-31, where pFedDIL's adaptive knowledge matching and migration yield a 12.82% improvement over FedAvg, approaching the disjoint-model upper bound (50.97%) while using far less storage.

## Relation to Prior Work

This paper extends the federated incremental learning line initiated by Yoon et al. (ICML 2021), which introduced personalized local models for task-incremental FL, by shifting the incremental axis from class changes to domain shifts. It departs from FCIL methods (FedCIL, FOT) that rely on label-space changes to identify task boundaries, instead formulating the problem where classes remain fixed while feature distributions shift across domains. The auxiliary-classifier-based knowledge matching draws on multi-task learning parameter sharing (Standley et al., 2020) and ensemble inference, while the domain-incremental task formulation follows Mirza et al. (CVPR 2022) in the centralized setting.

## Why It Matters / Open Questions

By being the first to formalize FDIL, this paper opens a practically relevant problem: real-world federated deployments (e.g., edge devices encountering new sensor modalities or geographic regions) face domain shifts with fixed class taxonomies, a scenario unaddressed by existing FCIL methods. The adaptive model-selection mechanism (choosing between reusing a similar prior model or initializing fresh) offers a storage-accuracy trade-off knob (λ) that practitioners can tune. Key open questions include whether the approach generalizes when tasks share little common knowledge, and how to jointly handle class-incremental and domain-incremental shifts simultaneously, which the authors identify as necessary for practical FL systems.

## Problem

Trigger set-based DNN watermarking is vulnerable to model extraction attacks: when an attacker trains a surrogate model on different data, the surrogate often fails to reproduce the source model's predictions on the trigger set, effectively erasing the watermark. Existing defenses (randomized smoothing, margin-based optimization) either require restrictive assumptions about the attacker's data or impose significant training overhead, leaving a gap in understanding *which* trigger set properties enable reliable watermark transfer under realistic extraction scenarios.

## Input / Output

The method takes a source image dataset (CIFAR-10/100 at 32×32, ImageNet at 384×384) and a pre-trained model used to compute logit margins for trigger set selection. It produces a watermarked DNN (ResNet-18, ViT-base-patch16-384, or VGG-11) trained jointly on clean data and a 100-sample trigger set with modified labels, plus a feature regularization term. Ownership verification outputs a p-value from a two-sample t-test comparing the suspicious model's trigger set accuracy against a benign model trained only on clean data.

## Method

MAT's key insight is that multi-view data—samples exhibiting features from multiple classes—naturally enables watermark transfer because the source model must rely on a specific feature (e.g., color) to classify the trigger sample under its modified label, and any surrogate data sharing that feature will propagate the prediction. Trigger set selection works by first training a clean model, computing the logit margin loss LM = max_{j≠y} M_θ^j(x) − M_θ^y(x) for each sample, selecting the top-q samples with the largest LM, and relabeling each to the second-highest scoring class. A feature regularization loss (α·‖f(x_k) − f_{ŷ_k}‖₂) is then added during joint training to push trigger set features toward the class-mean feature of the assigned label, computed from the previous epoch. This mechanism requires no architectural changes, no access to the attacker's data distribution, and no white-box access to the suspicious model for verification.

## Results

On CIFAR-10, MAT achieves 74% trigger set accuracy under soft-label model extraction (p-value 10⁻¹¹) and 56% under hard-label extraction (p-value 10⁻⁴), substantially outperforming the margin-based baseline (46% and 10% respectively). On CIFAR-100, MAT reaches 77% trigger accuracy after soft-label extraction versus 11% for the margin-based method. On ImageNet, MAT attains 82% trigger accuracy (p-value 10⁻⁷) compared to 9% for the margin-based approach, demonstrating scalability to large-scale datasets.

## Baselines & Comparisons

MAT decisively outperforms all trigger-set-based baselines on trigger set accuracy, which is the core metric for ownership verification. Against the margin-based method [22] (the strongest prior trigger-set approach), MAT improves trigger accuracy from 46% to 74% on CIFAR-10 (soft-label) and from 10% to 56% (hard-label). The Base [50] and Randomized Smoothing [2] baselines essentially fail, achieving 0–2% trigger accuracy under soft-label extraction and 2–4% under hard-label, making ownership verification impossible. The statistical-testing baselines DI [36] and EEF [27] report only p-values (10⁻⁶ and 10⁻⁷ for soft-label), but they do not produce a measurable trigger accuracy and are not directly comparable in terms of robustness under hard-label attacks. MAT also maintains competitive clean accuracy (87.90% source, 88.50% surrogate on CIFAR-10), losing only ~3% to the Base method while gaining 74 percentage points in trigger accuracy, demonstrating that the feature regularization cost is modest relative to the watermarking benefit.

## Relation to Prior Work

This paper reframes trigger set-based watermarking through a feature-learning lens, building on the multi-view hypothesis (Allen-Zhu & Li, 2020) to argue that samples exhibiting features from multiple classes naturally enable prediction transfer to surrogate models during extraction attacks. It extends the basic trigger set framework of Zhang et al. (2018) by replacing random sample selection with logit-margin-based multi-view data selection and adding a feature regularization loss, departing from margin-based watermarking (Kim et al., 2023) which relies on projected gradient ascent and from randomized smoothing (Bansal et al., 2022) which requires bounded perturbation assumptions. The key conceptual departure is that effective watermarking depends not on label manipulation alone but on shaping the source model's decision boundary through feature alignment, making the watermark transferable even when the attacker uses entirely different surrogate data.

## Why It Matters / Open Questions

MAT addresses a critical practical gap: existing watermarking methods become ineffective when attackers use surrogate data from different distributions, which is the most realistic threat scenario for MLaaS providers. The method's simplicity (no architecture changes, no complex optimization) makes it broadly applicable, and the feature regularization provides a tunable trade-off between clean accuracy and watermarking strength. However, hard-label model extraction still severely degrades trigger accuracy (9% on CIFAR100, 6% on ImageNet), leaving a significant open question about whether watermarking can be made robust to the most information-poor attack setting. Future work could explore whether the multi-view selection principle generalizes to non-vision modalities or whether combining MAT with other defenses (e.g., randomized smoothing) closes the hard-label gap.

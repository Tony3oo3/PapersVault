## Problem

Event-driven (neuromorphic) processors reduce latency and energy by only computing on non-zero activations, but existing spatial suppression methods fail to exploit the strong spatial correlation between adjacent lines in activation maps, while temporal suppression methods require storing full feature maps from the previous frame—often exceeding the 3–26 MB on-chip SRAM of commercial event-driven processors. This paper addresses both gaps by introducing a spatial-domain Δ-Σ modulation that induces additional sparsity with negligible state memory, and a mixed strategy that replaces memory-heavy temporal layers to fit within hardware constraints.

## Input / Output

ELSE operates on standard RGB video frames (UA-DETRAC for object detection, MPII for pose estimation) and produces bounding boxes or body keypoints respectively. The method is designed for depth-first, line-by-line convolution execution on event-driven hardware, where only non-zero activations (events) trigger memory accesses and MAC operations. The key hardware-relevant outputs are the number of events (MEvt), event-triggered MACs (GMAC), and state memory footprint, with the goal of fitting within the on-chip SRAM of processors like GrAI-VIP, Loihi, and Akida.

## Method

ELSE applies Δ-Σ modulation in the spatial domain: for each activation map, it computes element-wise differences (Δ) between adjacent lines, quantizes them with a learned threshold, and then accumulates (Σ) the transformed differential lines to reconstruct outputs identical to standard convolution. Training introduces L1 sparsity-inducing penalties on both the quantized activation maps and their line-based differential maps simultaneously, weighted by layerwise MAC to target computation-heavy layers. The method is further combined with other suppression approaches via two mixed strategies: Mix(ELSE, φ) selects per-layer spatial methods (e.g., STAR) to maximize computation savings, and Mix(ELSE, φ†) uses a module-wise linear program to replace memory-heavy temporal layers (e.g., CATS, DAL) with ELSE, reducing state memory by 2–4× while preserving temporal-level sparsity. The depth-first execution ensures only a small accumulation buffer (k_h × l_w × ch) is stored on-chip per line, making the memory overhead negligible compared to full-frame temporal state storage.

## Results

On UA-DETRAC object detection, ELSE achieves 6.49× and 3.14× event-triggered MAC reduction on MNV1-SSD and MNV2-SSDLite respectively, surpassing the SOTA spatial method STAR by an average of 37% in computation savings. The spatio-temporal mixed approach Mix(ELSE, CATS†) reaches up to 10.32× and 3.99× MAC reduction while consuming 2.17× less state memory than CATS alone, enabling on-chip deployment. On MPII pose estimation, ELSE delivers 2.43–5.75× MAC reduction across backbones, and Mix(ELSE, STAR) further boosts this to 2.53–8.83×, while Mix(ELSE, CATS†) achieves 2.68–6.76× MAC reduction with 2.78–3.90× state memory savings.

## Baselines & Comparisons

ELSE outperforms all spatial baselines (L1, Square-Hoyer, STAR) on both object detection and pose estimation: on MNV1-SSD it achieves 6.49× MAC reduction vs. STAR's 3.67×, and on RN50 pose estimation Mix(ELSE, STAR) reaches 8.83× vs. STAR's 6.70×. Temporal methods (EvNet, DeltaCNN, CATS) achieve lower absolute MAC than ELSE alone (e.g., CATS reaches 13.53× vs. ELSE's 6.49× on MNV1-SSD), but their 20–67 MB state memory exceeds on-chip SRAM of all tested event-driven processors, making them infeasible for deployment. The key win is Mix(ELSE, CATS†), which matches or approaches CATS's computation (10.32× vs. 13.53× on MNV1-SSD) while cutting state memory from 20.20 MB to 9.22 MB (2.17× reduction), restoring hardware compliance. On pose estimation, Mix(ELSE, CATS†) with EN-Lite backbone reduces state memory by 2.84× over CATS with only a 3.53% increase in computation. DAL-Select [61], the prior selective-temporal approach, is also outperformed: the paper's Mix(ELSE, φ†) saves 2–3× more state memory at comparable computation levels across the trade-off curve.

## Relation to Prior Work

ELSE repurposes the Δ-Σ modulation mechanism—previously applied exclusively in the temporal domain (frame-to-frame differences in EvNet, DeltaCNN, QSD, CATS)—to the spatial domain, computing differences between adjacent activation lines within a single frame. This spatial adaptation is enabled by depth-first convolution execution, which limits state memory to a few lines rather than full feature maps. The training objective extends prior activation-suppression penalties (L1, Square-Hoyer, STAR) by simultaneously penalizing both quantized activations and their line-based differentials, and the mixed-strategy formulation (Mix(ELSE, φ†)) departs from the selective temporal approach of DAL-Select [61], which suffered sparsity degradation, by using a module-wise linear program that preserves temporal-level computation while cutting state memory.

## Why It Matters / Open Questions

The practical significance lies in making temporal-level event suppression deployable on real event-driven processors (GrAI-VIP, Loihi, Akida, Tianjic) whose on-chip SRAM (3–26 MB) is far below the 20–67 MB state memory required by full temporal methods. The 2–4× state-memory reduction at comparable computation opens a path for video inference on resource-constrained embedded AI. Open questions include whether the spatial line-correlation assumption degrades for architectures with very small spatial dimensions or for non-CNN backbones, and whether the module-wise LP formulation generalizes to deeper or more heterogeneous networks. The authors also note that sparsity-aware NAS could further amplify these gains by co-designing architectures for line-based redundancy.

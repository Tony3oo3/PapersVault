## Problem

DETR-like detectors use a fixed number of object queries with static, image-agnostic positional embeddings, making them poorly suited for aerial datasets where tiny objects (average 12.7 pixels) appear in wildly varying counts per image (1 to 2267). Sparse fixed queries cause missed detections in dense scenes, while excessive queries in sparse scenes waste computation and introduce false positives. Additionally, the learned query positions carry no explicit spatial information tied to where objects actually appear in a given image.

## Input / Output

The model takes a single aerial RGB image and produces a set of bounding boxes with class labels via standard DETR-style Hungarian matching. Internally, it also generates a density map and a 4-level instance count category (N≤10, 10<N≤100, 100<N≤500, N>500) that jointly determine how many decoder queries (300, 500, 900, or 1500) are instantiated per image. The evaluation uses AP with a max detection cap of 1500, and scale-specific metrics (AP_vt, AP_t, AP_s, AP_m) tailored to the tiny-object regime of AI-TOD-V2.

## Method

DQ-DETR builds on a ResNet-50 backbone with a 6-layer deformable transformer encoder/decoder and adds three components. First, a Categorical Counting Module unflattens the encoder's multi-scale features, applies dilated convolutions to produce a density map, and classifies the instance count into 4 discrete levels (rather than regressing a precise number, which is unstable given the 1–2267 range). Second, a Counting-Guided Feature Enhancement (CGFE) module uses the density map to compute CBAM-style spatial and channel attention maps that are element-wise multiplied with the encoder features, injecting foreground spatial information. Third, Dynamic Query Selection uses the count category to set K, then selects the top-K scored features from the enhanced multi-scale maps as query priors: content is a linear projection of selected features, and position is an FFN-predicted 4-D bias added to per-pixel anchor boxes, giving each query an image-specific spatial anchor. Training follows a two-stage schedule (stabilize counting first, then add feature enhancement) and optimizes a combined Hungarian loss (L1 + GIoU + focal) plus cross-entropy for the counting head.

## Results

On the primary AI-TOD-V2 dataset (aerial tiny objects), DQ-DETR achieves 30.2 AP, surpassing the previous best DETR-like method DINO-DETR (25.9 AP) by 4.3 points and the best CNN-based method RFLA (25.7 AP) by 4.5 points. On VisDrone, DQ-DETR reaches 37.0 AP, outperforming DINO-DETR (35.8) by 1.2 points. On COCO, DQ-DETR achieves 50.2 AP, slightly below DINO-DETR (51.3) by 1.1 points, which the authors attribute to limited GPU resources and the method's specialization for tiny-object, imbalanced-count scenarios.

## Baselines & Comparisons

DQ-DETR decisively outperforms all 17 baselines on AI-TOD-V2, gaining +4.3 AP over DINO-DETR (25.9), +4.5 over RFLA (25.7), and +11.3 over Deformable-DETR (18.9); the margin is largest on very-tiny objects (APvt: 15.3 vs. 12.7 for DINO-DETR, +20.5%). On VisDrone, DQ-DETR (37.0 AP) beats DINO-DETR (35.8) by 1.2 AP and DNTR (34.4) by 2.6 AP. On COCO, DQ-DETR (50.2 AP) trails DINO-DETR (51.3) by 1.1 AP and Deformable-DETR (46.2) by 4.0 AP, indicating the dynamic-query mechanism is most beneficial when object counts vary drastically across images rather than in balanced general detection. Among CNN-based methods, the gap is substantial: DQ-DETR exceeds the best CNN baseline RFLA by 4.5 AP on AI-TOD-V2, while on VisDrone it surpasses the best CNN method SDP (30.2) by 6.8 AP.

## Relation to Prior Work

DQ-DETR extends the DETR lineage (DETR → Deformable DETR → DAB-DETR → DINO-DETR) by addressing two limitations the authors identify as critical for aerial/tiny-object datasets: the fixed number of decoder queries and the static, image-agnostic positional embeddings of those queries. It builds directly on DAB-DETR's 4-D anchor-box query formulation and Deformable DETR's multi-scale deformable attention, but departs from all prior DETR-like methods by introducing a categorical counting module that dynamically selects the query count (300–1500) and a density-map-guided feature enhancement (CBAM-style spatial and channel attention) that injects instance-location priors into both query content and position. The paper positions itself as the first DETR-like detector specifically targeting tiny objects, filling a gap where prior DETR variants were only evaluated on general-purpose benchmarks.

## Why It Matters / Open Questions

The dynamic query count mechanism offers a practical solution for datasets with extreme instance-count imbalance (1 to 2267 objects per image in AI-TOD-V2), reducing false positives in sparse scenes and false negatives in dense scenes without requiring per-image hyperparameter tuning. However, the method's specialization is evident: it underperforms DINO-DETR on COCO (50.2 vs 51.3 AP), and the categorical counting module drops to 56.5% accuracy for the N>500 class due to severe class imbalance in training samples, limiting gains in the densest scenes. Open questions include whether the counting-guided feature enhancement generalizes to non-aerial tiny-object settings, whether finer-grained counting categories (or a hybrid classification-regression head) could recover the lost accuracy in dense scenes, and whether the two-stage training protocol is necessary or an artifact of the counting module's instability.

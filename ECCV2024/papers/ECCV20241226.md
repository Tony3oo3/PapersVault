## Problem

Detecting any keypoints in complex real-world scenes remains unsolved because existing high-performance detectors rely on two-stage (top-down) pipelines that depend on a separate object detector, use only single-modality keypoint-level prompts, and are trained on small, category-limited datasets. No prior method combines end-to-end detection with multi-modal (textual and visual) prompts to handle multi-object, multi-class scenes with arbitrary keypoint definitions.
![Teaser figure](../imgs/ECCV20241226/cropped_page0_idx0.webp)

## Input / Output

X-Pose takes an RGB image (shorter side 800, longer side ≤1333 at inference) plus either a textual prompt (a hierarchical template like 'An [image style] photo of a [object]/[part]/[keypoint]' encoded by CLIP's text encoder), a visual prompt (a 224×224 reference image with 2D keypoint coordinates and visibility flags, encoded by an extended CLIP image encoder using Fourier embeddings for visible points and a shared learnable mask token for invisible ones), or both. It outputs all object bounding boxes and their associated 2D keypoint positions in a single forward pass, eliminating the N× inference cost of top-down methods.

## Method

X-Pose extends the DETR-like end-to-end pose estimator (ED-Pose) with a multi-modal prompt mechanism. Multi-modal prompts are encoded separately (CLIP text encoder for text; an extended CLIP image encoder with keypoint-to-keypoint attention and image-patch-to-keypoint attention for visual prompts), then mutually enhanced via deformable self-attention on image features and bidirectional cross-attention between image and prompt features. Decoding is decoupled into an object-level decoder (prompt-guided query selection from enhanced image features) and a keypoint-level decoder (queries initialized directly from keypoint-level prompt features), each using self-attention, image cross-attention, and prompt cross-attention layers. Training combines standard L1/GIOU/OKS regression losses with novel prompt-to-object and prompt-to-keypoint contrastive alignment losses (Focal loss on dot products between predicted queries and prompt features), and uses a 50% random selection between visual and textual prompts per iteration to enforce cross-modality learning. The model is trained on UniKPT, a newly unified dataset of 13 keypoint benchmarks (226K images, 418K instances, 338 keypoints, 1,237 categories) with standardized keypoint definitions and unique per-keypoint name annotations.

## Results

On the MP-100 visual prompt benchmark, X-Pose achieves 86.14 mean PCK, surpassing the previous best (CapeFormer at 85.31) by 6.44 PCK while requiring only a single forward pass (59 ms) versus 57×N ms for top-down methods. On AP-10K, X-Pose achieves 73.2 AP with textual prompts, a 27.7 AP improvement over the end-to-end baseline ED-Pose (45.5 AP). In the zero-shot textual prompt setting, X-Pose outperforms CLAMP by 6.9 AP (Bovidae→Canidae) and 7.0 AP (Canidae→Felidae). Across all 13 keypoint datasets in Table 5, X-Pose (Swin-L) achieves new SOTA on 10 of 13 benchmarks, including 79.2 AP on AP-10K, 99.8 PCK on 300W-Face, and 99.9 PCK on Desert Locust.

## Baselines & Comparisons

X-Pose outperforms all five visual-prompt baselines on MP-100: ProtoNet (44.78 PCK), MAML (61.50), Fine-tune (63.58), POMNet (79.70), and CapeFormer (85.31), achieving 86.14 mean PCK with a single 59 ms forward pass versus 57×N ms for top-down methods. Against the textual-prompt baseline CLAMP on AP-10K, X-Pose gains 6.9 AP (Bovidae→Canidae: 53.8 vs 46.9) and 7.0 AP (Canidae→Felidae: 55.4 vs 48.4), with particularly large gains on medium objects (AP_M: 34.7 vs 30.3 and 20.8 vs 13.6). Compared to the end-to-end non-promptable model ED-Pose, X-Pose achieves a dramatic 27.7 AP improvement on AP-10K (73.2 vs 45.5), attributed to instance-level and keypoint-level contrastive alignments. On text-to-image alignment (CLIP score), X-Pose surpasses CLIP by 204% at the keypoint level on AP-10K (66.01 vs 21.75) and by 166% across image styles on Human-Art (63.46 vs 23.81). Against GroundingDINO on COCO, X-Pose achieves comparable instance-level detection (71.1 vs 71.2 AP_M) but dramatically superior keypoint-level detection (74.2 vs 3.1 AP), demonstrating that open-vocabulary object detectors cannot localize fine-grained keypoints.

## Relation to Prior Work

X-Pose extends the DETR-like end-to-end pose estimation framework of ED-Pose [60] by incorporating a multi-modal prompt mechanism (textual via CLIP text encoder, visual via CLIP image encoder with Fourier-embedded keypoint tokens) to support arbitrary object categories and keypoint definitions. It departs from prior promptable keypoint detectors (CapeFormer for visual prompts, CLAMP for textual prompts) in three key ways: it is end-to-end rather than two-stage, it supports multi-object multi-class scenes rather than single-object, and it is the first to jointly leverage both textual and visual prompts with cross-modality contrastive alignment. The prompt-guided query selection mechanism draws from GroundingDINO [28], and the overall architecture follows the deformable-attention transformer decoder paradigm established in DETR-family detectors.

## Why It Matters / Open Questions

The UniKPT dataset (13 datasets, 338 keypoints, 1,237 categories, 400K+ instances) is a practically significant resource that standardizes keypoint semantics across previously fragmented benchmarks, enabling fair cross-category evaluation and training of general-purpose keypoint models. The end-to-end multi-modal prompt framework offers a user-friendly interface (text or image prompts) for open-world keypoint detection without requiring a separate object detector, which is important for real-world deployment reliability. Open questions include whether the approach scales to 3D keypoints, whether the 338-keypoint vocabulary is sufficient for truly open-ended scenarios, and whether the slight performance gap on COCO (74.4 vs. 78.6 AP) relative to top-down SOTA can be closed without sacrificing generalization.

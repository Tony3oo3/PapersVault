## Problem

Standard PEFT methods like LoRA and Adapter compress hidden states through a low-rank bottleneck using a simple linear down-projection, which is sufficient for uni-modal tasks but fails to effectively balance or enforce alignment between modalities in vision-language tasks. The paper asks whether adding lightweight, parameter-free guidance to route features through this bottleneck can improve VL alignment without violating the parameter-efficiency constraint.
![Teaser figure](../imgs/ECCV20242358/cropped_page1_idx0.webp)

## Input / Output

The method consumes RGB images (encoded by ViT-B/16, ViT-L/16, or CLIP-ResNet101) and text inputs (questions, task prompts). The visual [CLS] feature is prepended to the text sequence and serves as x_R, the reference feature to align against; if multiple visual tokens are present, average pooling reduces them to a single vector (L_v=1). The ViT and LM backbones are chosen to share the same feature dimension, eliminating the need for additional projection layers. Outputs are task-specific: discrete answer tokens for VQA, free-form captions for COCO Captioning, and binary yes/no judgments for NLVR2.

## Method

The paper introduces four parameter-free, linear routing functions inserted between the down-projection W_down and up-projection W_up inside the low-rank bottleneck of LoRA or Adapter modules. Given x_t = W_down·x_H (text hidden states) and x_v = W_down·x_R (visual reference), the routing functions are: element-wise multiplication x_t∘x_v′, element-wise addition x_t+x_v′, projection x_t(x_v)^T x_v, and rescaling x_t·x_v″. Each function enforces a different form of VL alignment in the bottleneck space—scaling, shifting, projecting onto, or rescaling by the visual direction—while introducing zero additional trainable parameters. The approach is validated across encoder-only (RoBERTa), decoder-only (GPT-2), and encoder-decoder (CLIP-BART) architectures on VQAv2, COCO Captioning, GQA, and NLVR2, showing that routing functions outperform cross-attention-based alignment (I-Tuning) with fewer parameters and that different routing functions excel on different question types and tasks.

## Results

On VQAv2 (RoBERTa-base + ViT-B/16), routing functions improve LoRA/Adapter accuracy by 8–11 points over the no-routing baseline (e.g., Adapter r=128 with x_t(x_v)ᵀx_v reaches 55.06% vs. 44.28% baseline, +10.78). On COCO Captioning (GPT2-base + ViT-B/16), the best routing function (x_t x_v'' with Adapter r=128) lifts the average score from 29.22 to 40.08 (+10.86), with CIDEr improving from 61.5 to 86.3. In the CLIP-BART multitask setting (VQA, GQA, NLVR2, COCO Cap.), routing functions yield smaller but consistent gains, e.g., CIDEr on COCO Cap. rises from 114.61 to 118.86 with x_t x_v''. The paper reports over 20% relative improvement on VQAv2 and 30% on COCO Captioning when scaling to larger backbones (RoBERTa-large + ViT-L/16, GPT2-medium + ViT-L/16).

## Baselines & Comparisons

The primary comparison is against standard LoRA and Adapter without routing functions (the 'None' baseline), where all four routing functions consistently outperform the baseline by 7–11 points on VQAv2 and 5–11 points on COCO Captioning average score. Against I-Tuning's cross-attention mechanism (Table 5), LoRA + x_t(x_v)ᵀx_v with separate mapping achieves 45.68 average (BLEU-4 30.7, CIDEr 92.4) with only 3.93M parameters, beating LoRA + cross-attention (43.02 avg, 4.79M params) by +2.66 points while using ~18% fewer parameters. Without separate mapping, LoRA + routing function reaches 45.38 avg with 4.75M params, still outperforming cross-attention by +2.36. For Adapter, the routing function (1.83M params) achieves 45.48 avg, essentially tying Adapter + cross-attention (45.70 avg, 4.73M params) while using less than half the parameters. Overall, routing functions match or exceed cross-attention in performance while introducing zero additional trainable parameters.

## Relation to Prior Work

This paper extends the LoRA and Adapter PEFT paradigm by identifying that their low-rank bottlenecks, designed for uni-modal compression, are ill-suited for vision-language tasks where cross-modal alignment must also be learned. It departs from VL-Adapter, the pioneering VL PEFT work, which treats the bottleneck as a generic compression layer, and from I-Tuning, which introduces cross-attention for alignment but at the cost of additional query/key/value parameters. The key conceptual departure is inserting parameter-free linear routing functions (element-wise ops or matrix products) between the down- and up-projections, using the down-projected visual features to guide the transformation of down-projected text features without any new trainable weights.

## Why It Matters / Open Questions

The routing functions offer a drop-in, zero-parameter improvement to any PEFT method with a low-rank bottleneck, making them broadly applicable and easy to adopt. The substantial gains (20–30% on base-model VQA and captioning) and the demonstration that they match or beat cross-attention with fewer parameters suggest that explicit cross-modal guidance in the bottleneck is more important than the field has previously assumed. Open questions include whether the task-dependent selection of routing functions (different ops excel on different question types) can be resolved with a single universal choice, whether the approach generalizes beyond VL to other multi-modal or multi-source settings, and whether more expressive (but still parameter-free) routing operations could close the remaining gap to full fine-tuning.

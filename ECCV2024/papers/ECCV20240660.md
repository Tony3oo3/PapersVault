## Problem

Existing neural image compression (NIC) frameworks lack full computational scalability: prior work either accelerates individual modules (autoregressive or neural network) or addresses only neural network scalability (e.g., SlimCAE) while neglecting autoregressive components. No prior method provides unified, end-to-end control over the computational complexity of all NIC components simultaneously, making it difficult to deploy a single codec across devices with vastly different computational budgets.
![Teaser figure](../imgs/ECCV20240660/cropped_page1_idx1.webp)

## Input / Output

The method takes standard RGB images (trained on ImageNet/CLIC patches, evaluated on Kodak 768×512) and produces a compressed bitstream plus a reconstructed image. At inference time, the user selects a computational configuration by choosing channel widths (48, 72, 96, 144, or 192) for each slimmable network edge and a number of parallel stages (e.g., 2, 4, or 10) for the autoregressive model, independently of the bitrate. Latent variables use a fixed 192-channel width to decouple bitrate scalability from computational scalability.

## Method

BaSIC formulates NIC as end-to-end BayesNet structure learning, decomposing the problem into two sub-problems. For the inter-node BayesNet (dependencies between latent variables like x→y→z), it learns a heterogeneous bipartite graph where each edge is a categorical distribution over multiple slimmable network configurations of varying channel widths, optimized via Gumbel-softmax reparameterization so that the mixing weights simultaneously serve as complexity penalties. For the intra-node BayesNet (autoregressive dependencies within the latent y), it learns a multipartite graph by assigning each spatial-channel node a topological index (partite) via a generative network, then applies a dynamic masked convolution whose kernel is zeroed wherever the target node's index is ≥ the source node's index, enabling parallel processing within each partite. The intra-node structure is optimized with the VIMCO objective over Monte Carlo samples since partite indices are ordinal and incompatible with Gumbel-softmax. The total loss combines rate, distortion, a complexity term weighted by λ_C, and the VIMCO structure loss, allowing the learned structure to be reconfigured at inference for arbitrary computational budgets.

## Results

On the Kodak test set, BaSIC's learned intra-node BayesNet achieves 0.3207 BPP at 2 parallel stages, 0.3183 BPP at 4 stages, and 0.3156 BPP at 10 stages, consistently outperforming hand-crafted autoregressive counterparts at equivalent stage counts. At 10 stages, BaSIC (0.3156 BPP) nearly matches the non-parallel MaskConv baseline (0.3150 BPP) while running ~17 MB/s faster. In the computational scalability comparison against SlimCAE, BaSIC saves approximately 2% more bits at maximum complexity and ~10% more bits at minimum complexity, while offering finer-grained control over per-layer MACs (e.g., 158k vs. 111k MAC/pixel near a 200k threshold).

## Baselines & Comparisons

Against SlimCAE [29], BaSIC achieves lower BPP at every tested complexity level, saving ~2% bits at maximum complexity and ~10% at minimum complexity, while providing per-layer channel-width control rather than a single global width. Versus the non-parallel MaskConv baseline [24] (0.3150 BPP), BaSIC at 10 stages reaches 0.3156 BPP—within 0.2%—while running orders of magnitude faster (17.32 vs. 0.32 MB/s). At 2 parallel stages, BaSIC (0.3207 BPP) outperforms both Checkerboard [12] (0.3216) and Channel-wise [25] (0.3222) autoregressive models. At 4 stages, BaSIC (0.3183) beats Multistage [21] (0.3210) by 0.0027 BPP. At 10 stages, BaSIC (0.3156) surpasses ELIC [11] (0.3174) by 0.0018 BPP. The Hyperprior model [4] serves only as a BD-rate reference anchor rather than a direct competitor in the scalability comparison.

## Relation to Prior Work

This paper unifies two previously separate threads in NIC: slimmable-network-based computational scalability (SlimCAE, ELIFIC) for the neural network backbones, and parallel autoregressive model design (Checkerboard, Channel-wise, Multistage, ELIC) for entropy modeling. It reframes both as instances of BayesNet structure learning — a heterogeneous bipartite graph for inter-node edges (selecting slimmable channel widths) and a multipartite graph for intra-node edges (learning the autoregressive dependency structure) — under a single differentiable optimization objective. Conceptually, it is closest to DARTS-style differentiable architecture search, but explicitly diverges by treating neural networks as conditional probability approximators within a probabilistic graph rather than as the object being searched over.

## Why It Matters / Open Questions

The main practical contribution is a unified knob for controlling computational complexity across all NIC components simultaneously, rather than the partial control (backbone-only or autoregressive-only) offered by prior scalable frameworks. The learned intra-node structures provide actionable design insights — e.g., that 3–4 spatial partites outperform the 2-partite checkerboard — which could inform future hand-crafted parallel autoregressive models. Limitations include evaluation on only the small Kodak test set, a single architecture instantiation (joint autoregressive + hyperprior), and modest BPP gains over strong hand-crafted baselines, leaving open whether the framework's advantages persist at scale or across diverse NIC architectures.

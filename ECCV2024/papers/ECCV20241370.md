## Problem

Existing unsupervised anomaly detection methods rely on discrete feature memories (nearest-neighbor search or attention over stored features), which suffer from poor generalization to unseen inputs or the identity shortcut problem where abnormal inputs are reconstructed as-is. Additionally, most approaches are designed for single-class detection, causing significant performance degradation when a unified model must handle multiple object classes simultaneously.
![Teaser figure](../imgs/ECCV20241370/cropped_page1_idx0.webp)

## Input / Output

The method takes an RGB image, extracts spatial features (C×H×W) via a pre-trained backbone, and produces a pixel-wise anomaly score map (L2 distance between input and reconstructed normal feature), an image-level anomaly score (max of average-pooled distance), and the reconstructed normal feature itself. The model operates in either a unified setting (one model for all 15 MVTec AD classes) or a separate per-class setting, and is trained exclusively on normal images with no anomaly labels.

## Method

CRAD replaces discrete feature memory with a continuous grid representation: input spatial features are transformed into low-dimensional coordinates (via 1×1 convolutions + tanh for local, global average pooling + linear for global), which are then used to bilinearly interpolate normal features from learned grids. Two grids capture complementary perspectives—a local grid (C_l-dimensional, per-pixel coordinates) for fine-grained patch-level normality and a global grid (C_g-dimensional, per-image coordinates) for structural/class-level normality—and their sampled features are fused through CNN blocks. A feature refinement step combines MSE and cosine similarity to selectively retain original input values in normal regions, reducing false positives. During training, Gaussian coordinate jittering is applied to local coordinates so that each update touches more grid cells with a bell-shaped distribution, improving generalization. The entire pipeline is trained end-to-end with MSE loss on normal inputs only, and at inference the anomaly score is simply the L2 distance between the input feature and the grid-reconstructed normal feature.

## Results

On MVTec AD (unified multi-class setting), CRAD achieves 99.3±0.08% detection AUROC and 99.4% localization AUROC, outperforming the previous state-of-the-art HVQ-T (98.0% detection) by reducing the error rate from 2.0% to 0.7% (a 65% relative error reduction). In the separate (per-class) setting, CRAD reaches 99.3±0.08% detection and 99.4% localization, surpassing PatchCore (97.6%/99.0%), the prior single-class SOTA. On the more challenging VisA dataset, CRAD attains 95.2%/95.4% detection and 98.6%/98.5% localization (unified/separate), leading all compared methods.

## Baselines & Comparisons

CRAD outperforms all nine baselines on MVTec AD detection in the unified setting. Against the nearest competitors, CRAD (99.3%) beats HVQ-T (98.0%) by 1.3 points and UniAD (96.5%) by 2.8 points; notably, the unified CRAD even surpasses the separate (per-class) PatchCore (97.6%), the prior single-class SOTA. Older memory-based methods (US 74.5%, PaDiM 84.2%, MKD 81.9%, DRAEM 88.1%) and distillation-based RD4AD (93.4%) show substantially larger gaps, with unified CRAD exceeding them by 5.9–24.8 points. On VisA, CRAD (95.2% unified detection) leads OmniAL (87.8%), PatchCore (93.7%), and UniAD (91.1%), confirming the advantage generalizes beyond MVTec. For localization, CRAD (99.4% unified) matches separate PatchCore (99.0%) and exceeds HVQ-T and UniAD, while on VisA it reaches 98.6% unified vs. 97.5% for PatchCore.

## Relation to Prior Work

CRAD repurposes the grid representation paradigm from neural fields (NeRF, Plenoxels) for anomaly detection, replacing the discrete feature memories used by PatchCore/PaDiM (nearest-neighbor search) and attention-based methods (MAD, Divide-and-Assemble) with a continuous, interpolable feature space. It directly addresses the identity shortcut (IS) problem formalized by UniAD and the multi-class unified detection gap identified in recent work, positioning itself as the first method to represent normality in a continuous rather than discrete memory. The coordinate transformation and bilinear interpolation mechanism is novel to this domain, while the underlying grid sampling operation is borrowed from 3D reconstruction and novel view synthesis literature.

## Why It Matters / Open Questions

CRAD provides a practical, parameter-efficient alternative to discrete memory banks (O(1) retrieval, compact storage) that simultaneously resolves weak generalization and the IS problem, making unified multi-class deployment feasible without per-class models. The 65% error reduction over the prior SOTA (HVQ-T) in the unified setting is practically significant for industrial deployment where maintaining separate models per class is costly. However, the authors acknowledge the approach fails under extremely limited data (1-shot or zero-shot), and the evaluation is confined to two industrial datasets (MVTec AD, VisA), leaving open whether the continuous grid formulation generalizes to other anomaly detection domains such as medical imaging or video surveillance.

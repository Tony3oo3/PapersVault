## Problem

Existing deepfake detection methods for diffusion-generated images rely on pretrained CLIP embeddings that were optimized for global image-text alignment on real images only, making them suboptimal for distinguishing real from fake content that is best revealed by local, fine-grained artifacts. These pretrained backbones also lock in large parameter counts (≥86M) and prevent architectural tailoring, limiting both detection accuracy and deployment feasibility in real-time scenarios.

## Input / Output

The model accepts a single RGB image, which is randomly cropped to 224×224 pixels at inference (or 96×96 for local views during training). It outputs a d-dimensional L2-normalized embedding vector from a ViT-Tiny backbone (5M parameters), which is then classified as real or fake via one of three lightweight heads: a linear layer with sigmoid, a nearest-neighbor lookup over a precomputed embedding bank, or a one-class SVM fitted exclusively on real-image embeddings with a polynomial kernel.

## Method

CoDE trains a ViT-Tiny encoder from scratch using a pair of contrastive losses built on the InfoNCE framework. The first loss (L_global) enforces separation between real and fake embeddings in the shared space by attracting each sample to a randomly chosen same-class augmented view and repelling it from all opposite-class augmented views in the batch. The second loss (L_multi-scale) introduces local-to-global alignment: 96×96 local crops and 224×224 global crops of the same image are both passed through the single backbone, and the local embedding is pulled toward a same-class global embedding while being pushed away from opposite-class global embeddings. A stochastic transformation operator (blur, rotation, JPEG compression, pixelization, etc.) is applied to all views to enforce invariance. This dual-loss design, combined with training from scratch on the 9.2M-image D³ dataset, yields a compact embedding space that outperforms much larger pretrained CLIP and DINOv2 backbones while being 17–60× smaller in parameter count.

## Results

On the D³ standard test set (4 known generators), CoDE with a linear classifier achieves 98.0% overall accuracy without transformations and 95.7% with transformations, surpassing the best competitor (CLIP ViT-L + Linear) by 5.5% and 6.5% respectively. On the more challenging extended test set with 12 generators (8 unseen), CoDE with a one-class SVM achieves 94.7% average accuracy on unseen-generator fakes, outperforming CLIP ViT-L (NN) at 94.4% and Corvi et al. at 88.2%. On external generators including commercial tools (DALL-E 2/3, Midjourney), CoDE (SVM) reaches 81.6% average accuracy, the best among all compared methods. The model uses only 5M parameters (ViT-Tiny) versus 307M for CLIP ViT-L.

## Baselines & Comparisons

CoDE outperforms all GAN-trained detectors (Wang et al. [50], Gragnaniello et al. [22]) by a wide margin, which achieve near-random accuracy (<3%) on diffusion-generated images, confirming that GAN-specific artifacts do not transfer to diffusion models. Against the closest diffusion-specific competitor, Corvi et al. [12] (trained on LDM), CoDE (SVM) gains 6.5% on unseen-generator accuracy (94.7% vs. 88.2%) and 12.9% on overall fake accuracy (94.8% vs. 81.9%). Compared to CLIP ViT-L [35], CoDE matches or exceeds performance with 1/60th the parameters: on the standard D³ test, CoDE (Linear) beats CLIP ViT-L (Linear) by 5.5% (w/o transforms) and 6.5% (w/ transforms); on the extended test, CoDE (SVM) edges out CLIP ViT-L (NN) by 0.1% on unseen fakes while also maintaining 91.9% real-image accuracy versus CLIP's 16.8%. Against Ojha et al. [30] (CLIP ViT-L + Linear on GAN data), CoDE (SVM) achieves a 69.4% improvement on unseen-generator accuracy (94.7% vs. 25.3%). On the external generator benchmark (Table 4, including DALL-E 2/3 and Midjourney), CoDE (SVM) leads all methods at 81.6% average, surpassing CLIP ViT-L (Linear) by 4.1% and Corvi et al. by 4.4%.

## Relation to Prior Work

This paper departs from the dominant paradigm of leveraging pretrained CLIP backbones (as in Ojha et al.) for deepfake detection by training a compact ViT-Tiny encoder from scratch with a purpose-built contrastive objective. It borrows the InfoNCE framework and multi-crop local-global alignment strategy from self-supervised methods like DINO, but repurposes them for a supervised real-vs-fake separation task rather than self-supervised feature learning. The key conceptual departure is the argument that CLIP's global image-text alignment space is suboptimal for deepfake detection because it neglects local fine-grained artifacts that distinguish generated images, and that training exclusively on real images (treating fakes as outliers) limits discriminative accuracy.

## Why It Matters / Open Questions

The 5M-parameter CoDE model matching or exceeding 307M-parameter CLIP ViT-L in accuracy makes real-time, production-ready deepfake detection substantially more feasible, and the publicly released D³ dataset (9.2M images across 4 diffusion generators) fills a critical gap in training resources for this task. The strong generalization to 12 unseen generators (94.7% average with one-class SVM) addresses a key practical concern, though the linear classifier still underperforms on unseen generators compared to the SVM, suggesting the embedding space may not fully capture generator-agnostic boundaries. Open questions include whether this contrastive local-global formulation extends to video deepfakes, whether it remains effective as generation quality continues to improve, and whether the approach generalizes to non-diffusion paradigms like autoregressive or GAN-based generators at scale.

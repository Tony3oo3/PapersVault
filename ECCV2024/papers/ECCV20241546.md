## Problem

Existing inpainting models are specialized for either context-aware filling (reconstructing from surrounding image content) or text-guided object synthesis, with conflicting training strategies that prevent a single model from excelling at both. This forces practitioners to choose between coherent background completion and faithful object generation, and makes tasks like object removal in crowded scenes particularly difficult because text-guided models tend to hallucinate new objects in masked regions.

## Input / Output

The model accepts an RGB image, a binary inpainting mask, and a text condition that can be either a natural-language description or one of three learned task prompt embeddings (P_obj, P_ctxt, P_shape). The first convolutional layer of the U-Net is extended with five additional channels to receive the masked image and mask alongside the noisy latent. The output is a fully inpainted image at the same resolution as the input, with the masked region filled according to the selected task prompt. For shape-guided inpainting, the text embedding is a linear interpolation between P_ctxt and P_shape, controlled by a user-specified scalar α that governs how tightly the generated object conforms to the mask boundary.

## Method

PowerPaint fine-tunes Stable Diffusion v1.5 by introducing three learnable task prompts optimized in the CLIP text encoder's embedding layer, each paired with a tailored training strategy: P_obj is trained with object bounding-box masks and appended as a suffix to object captions, P_ctxt is trained with random masks and used as the sole text condition, and P_shape is trained with precise segmentation masks. The key insight is that these prompts capture intrinsic task patterns, enabling a single unified model to switch between inpainting modes simply by changing the prompt. Two additional capabilities emerge from prompt manipulation: object removal is achieved by designating P_obj as a negative prompt in classifier-free guidance (suppressing object generation while promoting background filling), and controllable shape-fitting is achieved by linearly interpolating the CLIP embeddings of P_ctxt and P_shape based on a dilation ratio α computed from randomly dilated segmentation masks during training. The model is trained for 25K iterations on 8 A100 GPUs using OpenImages v6 (semantic segmentation subset) and LAION-Aesthetics v2 5+, with an 80/20 mix of inpainting and text-to-image generation tasks.

## Results

On text-guided object inpainting (bounding box masks), PowerPaint achieves Local-FID 9.41 and FID 4.38 on OpenImages, and Local-FID 11.61 and FID 5.12 on MSCOCO, with CLIP Scores of 27.56 and 25.95 respectively, matching or slightly exceeding SmartBrush. For context-aware inpainting on Places2, PowerPaint achieves FID 17.91 and LPIPS 0.2225 (40–50% masked), outperforming SD-Inpainting (FID 19.73, LPIPS 0.2322). On outpainting (Flickr-Scenery), PowerPaint attains FID 10.16 and aesthetic score 5.33, the best among all compared methods.

## Baselines & Comparisons

PowerPaint achieves state-of-the-art or near-parity results across all five baselines. Against the strongest competitor SmartBrush, PowerPaint wins on FID and Local-FID for both bounding-box and layout-mask object inpainting (e.g., 9.41 vs 9.57 Local-FID on OpenImages), while SmartBrush retains a marginal CLIP Score edge (27.61 vs 27.56), indicating essentially tied text alignment. Against SD-Inpainting, PowerPaint improves Local-FID by 3.3 points (12.71→9.41) and FID by 0.38 on OpenImages, and further outperforms it on context-aware inpainting (FID 17.91 vs 19.73) and outpainting (FID 10.16 vs 58.38 for vanilla SD-Inpainting). ControlNet-Inpainting and Blended Diffusion are clearly outperformed by large margins (e.g., Local-FID 14.74 and 35.66 vs 9.41). In the user study, PowerPaint is preferred over SmartBrush and SD-Inpainting for object inpainting (48.3% shape, 50.8% text alignment) and dominates object removal (73.2% preference) and outpainting (62.6% preference).

## Relation to Prior Work

PowerPaint builds directly on Stable Diffusion's latent diffusion architecture, extending the denoising U-Net with additional channels for masked image and mask inputs, following the SD-Inpainting and ControlNet-Inpainting paradigm. It departs from prior text-guided inpainting work (SmartBrush, Imagen Editor) that assumes objects are always present in masked regions, and from context-aware inpainting (LaMa, LDM-Inpaint) that cannot synthesize novel content, by introducing learnable task prompts (P_obj, P_ctxt, P_shape) that route a single model to different inpainting behaviors. The conceptual departure from prior work on adapting T2I models (DreamBooth, Textual Inversion, Multi-concept customization) is that instead of learning concept-specific embeddings, the authors learn task-specific prompts that encode the *type* of inpainting operation rather than a visual identity.

## Why It Matters / Open Questions

PowerPaint demonstrates that a single diffusion model can match or exceed task-specific models across object inpainting, context-aware inpainting, outpainting, and object removal, reducing the need for separate pipelines. The dual-use of task prompts as negative prompts for object removal and as interpolation endpoints for shape control suggests a broader principle: learned conditioning tokens can encode task semantics reusable across sampling strategies. Limitations include dependence on the underlying SD v1.5 quality ceiling and difficulty with very loose shape-fitting, and it remains open whether the task-prompt approach transfers cleanly to newer architectures (SDXL, DiT-based models) or to non-inpainting editing tasks.

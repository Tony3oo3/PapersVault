## Problem

Existing text-guided domain generalization methods like LADS require both exact text descriptions of test domains and a separately trained augmentation network per domain, making them impractical when test domain descriptions are unavailable or numerous. This paper introduces the Text-driven Domain Generalization problem, where a model must generalize to unseen test domains using only text descriptions of arbitrary crafted domains that do not necessarily match the test domains.
![Teaser figure](../imgs/ECCV20241848/cropped_page1_idx0.webp)

## Input / Output

The method takes source-domain RGB images (resized to 224×224), a source domain text description, class names, and a set of k crafted unseen-domain text descriptions (e.g., 'a sketch of a {}') as input. It produces augmented image embeddings in the CLIP latent space (not pixel-space images) and, after training a linear probe, outputs class labels for test images. The augmentation is performed entirely in the embedding space using the pre-trained CLIP ViT-L encoders, so no generative model or pixel-level image synthesis is involved.

## Method

TEAM performs training-free embedding augmentation by aligning the modality direction (the vector from a text embedding to its paired image embedding) rather than the global direction used by LADS. Given a source image-text pair and a target domain text description, the augmented embedding z is obtained in closed form (Eq. 9) by projecting along the modality direction from the target text embedding, with the solution guaranteed to exist under CLIP's contrastive pre-training (Lemma 1, Proposition 1). Two variants are offered: TEAM-full augments each source embedding toward every crafted domain description, while TEAM-invar. first extracts a domain-invariant text representation via mean-pooling over all crafted-domain text embeddings and performs a single augmentation, reducing the augmented dataset size by a factor of k. The key theoretical advantage is that the modality direction is approximately orthogonal to the span of class-discriminative embeddings, so moving along it preserves class information without an explicit class-consistency loss. A linear probe is then trained on the mixture of original and augmented CLIP image embeddings, and inference applies the probe to test image embeddings.

## Results

On CUB-Paintings (200 bird species, photo→painting), TEAM-invar. achieves 67.31% OOD accuracy and 77.16% average, outperforming LADS (64.85% OOD) by +2.46 points. On DomainNet (40 classes, sketch→real/clipart/painting), TEAM-invar. reaches 96.90% OOD and 96.28% average, surpassing LADS (94.65% OOD) by +2.25 points. Notably, TEAM-invar. requires only 0.23× the Stage-2 training time of LADS while delivering better OOD performance, and it does so without any trainable augmentation network.

## Baselines & Comparisons

TEAM outperforms all four baseline families on the primary OOD metric across both datasets. Against CLIP-based linear probes (CLIP LP, CLIP LP ZS-init), TEAM-invar. gains +2.26% OOD on CUB-Paintings (67.31% vs. 65.05%) and +2.95% on DomainNet (96.90% vs. 93.95%). WiSE-LP, a weight-ensembling fine-tuning method, is consistently the weakest baseline, trailing TEAM by over 2.5% OOD on both datasets. VQGAN+CLIP (pixel-space augmentation via a generative model) is only evaluated on DomainNet in Table 1 and achieves 93.83% OOD, well below TEAM's 96.81%. The closest competitor is LADS, which uses trainable augmentation networks per target domain; TEAM-invar. beats it by +2.46% OOD on CUB-Paintings and +2.25% on DomainNet while requiring no trainable augmentation parameters and only 0.23× the Stage-2 training time.

## Relation to Prior Work

This paper extends LADS (Dunlap et al., ICLR 2023), which augments source-domain image embeddings using trainable per-domain networks guided by exact test-domain text descriptions. The key departures are twofold: (1) it removes the requirement for a textual oracle of test domains by instead using descriptions of arbitrary crafted domains that need not match the test domain, and (2) it replaces trainable augmentation networks with a training-free closed-form solution derived from the modality gap geometry of CLIP's embedding space (Liang et al. 2022; Zhang et al. 2023). The method aligns the modality direction (image-to-text offset) rather than the global direction used in prior CLIP-guided generation work, yielding a milder existence condition and better class preservation.

## Why It Matters / Open Questions

The practical implication is significant: practitioners no longer need to pre-identify and verbalize every potential test domain, and they avoid training a separate augmentation network per domain, making the pipeline substantially more scalable. The finding that randomly crafted domain descriptions (e.g., 'sketch', 'clipart', '3D rendering') can match or exceed performance when the exact test-domain description is known suggests that domain generalization may be achievable through broad stylistic diversity rather than precise domain matching. However, the approach is bottlenecked by CLIP's embedding quality and struggles with complex natural domain shifts that are hard to verbalize; whether vague or structured descriptions can capture such shifts remains an open question.

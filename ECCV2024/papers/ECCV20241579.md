## Problem

Instance-level image retrieval methods increasingly rely on high-dimensional, dense local descriptors that deliver strong accuracy but impose prohibitive memory footprints, rendering them impractical for web-scale databases. Prior work has focused almost exclusively on performance gains while largely ignoring the memory cost of stored representations. This paper systematically investigates and optimizes the performance-versus-memory trade-off, targeting an extreme regime of ~1KB per database image.
![Teaser figure](../imgs/ECCV20241579/cropped_page0_idx1.webp)

## Input / Output

The model receives two sets of local descriptors (D-dimensional vectors) of potentially different cardinalities—one for the query image (L_q) and one for a database image (L_x)—along with a learnable matching token, forming K = L_x + L_q + 1 transformer tokens. A key design choice is that database descriptors are stored in binary form (1 bit per dimension after a learned projection), with a re-mapping layer applied only at query time, so the stored footprint is L_x × d bits rather than L_x × d × 32 bits. The output is a scalar similarity in [0,1] from a sigmoid over the matching token, which is linearly combined with the global-descriptor dot product (with a tuned weight λ and temperature γ) to produce the final re-ranked score.

## Method

AMES is a transformer-based similarity estimator that alternates masked self-attention (across the two images) and masked cross-attention (within each image) over N=5 identical blocks, with a learnable matching token aggregating information from both images. Three mechanisms jointly reduce memory: (i) asymmetric similarity, where the query side uses more descriptors (e.g., 600) than the database side (e.g., 50) without increasing stored footprint; (ii) learned binarization of local descriptors via a smooth approximation of the sign function (erf-based), storing only binary codes; and (iii) knowledge distillation from a full-precision teacher operating on a larger descriptor set to a binary student operating on a smaller subset, with an ℓ₂ loss on the pre-classifier token representations. To handle arbitrary test-time descriptor counts, a universal model is trained by randomly sampling L_x and L_q per batch in [10, 400], which alleviates the transformer's sensitivity to token-count mismatch between training and testing. The final retrieval pipeline uses global descriptors (optionally PQ-compressed) for initial ranking of top-m images, then applies the ensemble local-global similarity for re-ranking.

## Results

On ROP+1M, the best AMES configuration (SG global + DINOv2 local descriptors, full-precision) achieves 84.5 mAP, while the binary+distillation variant reaches 83.3 mAP with only ~10 KB per image. On GLDv2, the same configurations score 38.5 and 38.0 mAP@100, respectively. Compared to CVNet re-ranking (73.0 mAP on ROP+1M, ~1400 KB per image), AMES delivers an 11.5-point improvement at a fraction of the memory cost. The universal model maintains stable performance across varying numbers of local descriptors (10–400), avoiding the sensitivity to token-count mismatch observed in specific models.

## Baselines & Comparisons

AMES outperforms CVNet re-ranking by a clear margin when using the same backbone: with CVNet descriptors, AMES(fp) at 400 local descriptors scores 75.8 vs. CVNet's 75.6 on ROP+1M, and the binary variant (75.4) is nearly on par while using far less memory. Against RRT and R²Former, AMES wins in all memory settings shown in the performance-vs-memory trade-off (Figure 3), and also achieves lower inference latency (Figure 6). Compared to ASMK, AMES provides substantially larger gains and benefits from additional descriptors, whereas ASMK plateaus. The combination of SG query-expansion re-ranking with AMES (84.5 mAP) surpasses SG re-ranking alone (80.5 mAP) by 4 points, confirming the two are complementary. The binary+distillation variant retains 98% of the full-precision performance (83.3 vs. 84.5) while reducing per-image storage from ~301 KB to ~10 KB, a 30× memory reduction.

## Relation to Prior Work

AMES extends the re-ranking transformer architecture of RRT [58] by incorporating ideas from image matching networks (SuperGlue, LoFTR, LightGlue) for alternating self- and cross-attention, while introducing four key departures: asymmetric descriptor counts between query and database, end-to-end binary descriptors with distillation from a full-precision teacher, a universal model trained with randomly sampled descriptor set sizes, and explicit global-local ensemble tuning. Unlike prior re-ranking methods (RRT, R²Former, CVNet) that treat memory as an afterthought, AMES positions the performance-memory trade-off as a first-class design objective, targeting a 1KB-per-image budget. The paper also connects to the NLP literature on transformer sensitivity to sequence-length variation, drawing an analogy to the token-count sensitivity observed here.

## Why It Matters / Open Questions

By demonstrating that competitive retrieval accuracy is achievable at ~1KB per image (vs. ~1400KB for CVNet), AMES provides a concrete, deployable path toward web-scale instance-level retrieval that prior deep methods have not addressed. The universal model's robustness to varying descriptor counts is a practical enabler for systems that must trade query latency against accuracy dynamically. Open questions include whether the asymmetric design and binary distillation transfer to other retrieval granularities (e.g., category-level), whether the approach scales to databases with billions of images, and whether the 1KB budget can be pushed further without the performance cliff observed below ~32 local descriptors.

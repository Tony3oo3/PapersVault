## Problem

Existing large multimodal models treat visual grounding and visual chat as separate tasks, causing chat quality to degrade sharply when grounding is requested, because they are trained on short-caption grounding data rather than rich conversational data. The core gap is the absence of a grounded visual chat (GVC) dataset that pairs natural-language conversations with accurate region-level annotations, and the lack of model architectures that support pixel-wise grounding alongside free-form chat.

## Input / Output

The model accepts an RGB image, a free-form text instruction, and optionally a visual prompt (click point, bounding box, scribble, or Set-of-Mark overlay). The text output is a natural-language response in which grounded noun phrases are wrapped in special tokens ⟨g_s⟩…⟨g_e⟩ followed by a ⟨seg⟩ marker; each ⟨seg⟩ token's last-layer LLM hidden state is projected into the grounding model to decode a bounding box and a pixel-level segmentation mask. For visual-prompt inputs, ⟨obj⟩ placeholder tokens in the question have their word embeddings replaced by prompt features extracted via Semantic-SAM, so the model can refer to user-specified regions without explicit text descriptions.

## Method

LLaVA-Grounding extends the LLaVA architecture (CLIP vision encoder + Vicuna-7B LLM) with two modules: a Semantic-SAM prompt encoder that converts visual prompts into language-space tokens, and an OpenSeeD grounding model that receives the LLM's last-layer hidden features at ⟨seg⟩ token positions (projected via a trainable matrix W_g) and decodes both bounding boxes and segmentation masks. The key design choice is to offload spatial localization from the autoregressive LLM to a dedicated grounding decoder, so the language model focuses on generating coherent text while the grounding model handles pixel-level prediction. Training proceeds in three stages: (1) feature and granularity alignment of the vision encoder and grounding model on RefCOCO/+/g, COCO, Visual Genome, and Flickr30K; (2) instruction tuning on 150K GVC samples (created by GPT-4 matching noun phrases in LLaVA chat data to human-labeled COCO instances) plus LLaVA 158K for pure chat; (3) extension to visual prompts using GVC-R data. The grounding model's matching loss is back-propagated into the LLM, while box and mask losses train only the grounding head, preserving chat quality.

## Results

On Grounding-Bench (1000 images), LLaVA-G achieves an F1 of 37.1 for grounded detailed description, outperforming all open-source grounding LMMs (CogVLM-Grounding: 32.0, BuboGPT: 30.7, Shikra: 27.6, MiniGPT-v2: 25.6) while maintaining competitive chat scores (All: 79.3 vs. LLaVA's 81.2). On traditional grounding benchmarks, LLaVA-G-7B achieves 89.16% ACC@0.5 on RefCOCO REC, 79.68 mIoU on RefCOCO RES, and 83.62 on Flickr30K Entities test, surpassing all other LMMs on RES and phrase grounding tasks. The model is the only LMM to report both REC and RES results simultaneously, with 77.13 cIoU on RefCOCO RES.

## Baselines & Comparisons

LLaVA-G outperforms all open-source grounding LMMs on Grounding-Bench F1 for grounded detailed description (37.1 vs. CogVLM-Grounding 32.0, BuboGPT 30.7, Shikra 27.6, MiniGPT-v2 25.6) while retaining chat scores close to pure chat models (All: 79.3 vs. LLaVA 81.2, CogVLM-Chat 84.2). On RefCOCO REC, LLaVA-G (89.16%) trails only the much larger CogVLM-Grounding-17B (93.40%, using a 4B vision model + 6B connector) but beats Ferret-7B (87.49%), Shikra-7B (87.01%), and MiniGPT-v2-7B (88.06%). On RES tasks (mIoU), LLaVA-G is the only LMM reporting results and achieves 79.68 on RefCOCO, 72.92 on RefCOCO+, and 74.39 on RefCOCOg, surpassing specialized models like PolyFormer-L (76.94 on RefCOCO) and LISA-7B (74.9 cIoU). On Flickr30K Entities phrase grounding, LLaVA-G (83.62 test) outperforms Ferret-7B (82.21), Shikra-7B (76.54), and Kosmos-2 zero-shot (78.70). GPT4-V+SoM achieves the highest grounded F1 (63.2) but relies on an external model for mark labeling, making it a two-model system rather than an end-to-end solution.

## Relation to Prior Work

This paper extends the LLaVA visual instruction tuning framework by appending a grounding model (OpenSeeD) to the LLM's hidden features, departing from prior grounding LMMs (Kosmos-2, Shikra, MiniGPT-v2, CogVLM) that either predict box coordinates as text tokens or rely on external grounding models. The data creation pipeline also diverges from prior approaches (Kosmos-2, GPT4ROI) that use pretrained detectors to pseudo-label boxes; instead, it leverages human-annotated COCO instances with GPT-4 performing phrase-to-instance matching, yielding 150K grounded visual chat samples. Architecturally, the key departure is treating grounding as a decoding problem handled by a dedicated segmentation model rather than a language generation task, enabling simultaneous box and pixel-level output.

## Why It Matters / Open Questions

The paper addresses a concrete gap in LMMs: the inability to perform grounding and natural-language chat simultaneously without degrading either capability. The introduced Grounding-Bench and GVC dataset provide the field with the first dedicated evaluation and training resources for grounded visual chat, filling a void where prior benchmarks only assessed grounding in isolation. Limitations include a semantic scope constrained to COCO/Object365 vocabulary (no open-vocabulary grounding), dependence on GPT-4 for both data annotation and evaluation, and a relatively small grounding model (Swin-Tiny). Open questions include whether the LLM-to-segmentation-model connection generalizes to truly open-vocabulary settings and whether the GPT-4-based evaluation pipeline introduces systematic biases.

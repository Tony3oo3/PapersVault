## Problem

VLM-based OOD detection methods like NegLabel rely on manually crafted text prompts, and small linguistic changes (e.g., 'a photo of a' vs. 'The nice') can cause over 10% fluctuation in FPR95, making the system fragile and impractical without domain expertise. This paper asks whether effective prompts for OOD detection can be learned automatically from ID class names alone, eliminating the need for manual prompt engineering and manual data collection.
![Teaser figure](../imgs/ECCV20241927/cropped_page1_idx0.webp)

## Input / Output

At deployment, the method takes a single RGB test image and produces an OOD score (the ratio of ID-class softmax mass to total ID+negative softmax mass, following NegLabel's Eq. 4) plus an ID class prediction via cosine similarity to learned text embeddings. The only human-provided input is the set of ID class names; all negative labels are mined automatically from text corpora, and all training images are either synthesized via SDXL or retrieved from a ~60M-sample subset of Laion-400M using CLIP-based search. The CLIP ViT-B/16 image encoder is frozen throughout; only the learnable prompt tokens are optimized.

## Method

LAPT introduces distribution-aware prompts—learnable context tokens prepended to class labels that are shared within each distribution (ID vs. negative) but distinct across distributions—optimized with a cross-entropy loss over automatically collected per-class images. Two data mixing strategies enhance training: cross-modal mixing interpolates between an image's visual feature and its class text embedding (with a Beta-distributed coefficient) to suppress image noise, while cross-distribution mixing blends ID and negative image features along with their soft labels to populate the intermediate feature space between distributions. Training images are gathered via a hybrid pipeline that prefers CLIP-retrieved real images when their cosine similarity to the class label exceeds a threshold (κ=0.3), falling back to SDXL-generated synthetic images otherwise. At test time, the learned prompts are frozen and the NegLabel scoring function is applied directly, requiring no additional inference-time computation beyond standard CLIP forward passes.

## Results

On the four standard OOD datasets (iNaturalist, SUN, Places, Textures) with ImageNet-1k as ID data, LAPT achieves an average AUROC of 94.68% and average FPR95 of 23.40%, outperforming the closest competitor NegLabel (94.21% AUROC, 25.40% FPR95). On the more challenging OpenOOD near-OOD benchmark, LAPT reduces FPR95 to 58.94% (vs. 68.18% for NegLabel) and raises AUROC to 82.63% (vs. 76.92%), a 10.76% FPR95 and 5.71% AUROC improvement over the best hand-crafted prompts. LAPT also improves ID classification accuracy to 67.86% (vs. 66.82% for NegLabel) and achieves 71.18% FPR95 on the full-spectrum near-OOD task, surpassing all methods requiring manually labeled training data.

## Baselines & Comparisons

LAPT consistently outperforms all 25 compared baselines across every evaluated dataset and metric. Against the closest VLM-based competitor NegLabel [21], LAPT improves average FPR95 from 25.40% to 23.40% on the four standard OOD datasets, and achieves a much larger 10.76% FPR95 reduction (68.18→58.94) and 5.71% AUROC gain (76.92→82.63) on the challenging near-OOD OpenOOD benchmark. Compared to MCM [29], the foundational zero-shot VLM OOD method, LAPT reduces average FPR95 by 20.53 points (43.93→23.40) and raises AUROC by 3.86 points. Among methods requiring manually labeled training data, LAPT surpasses LoCoOp [32] (28.66→23.40 FPR95), LSN [34] (30.22→23.40), and NPOS [48] (37.93→23.40) without any manual annotation. On the full-spectrum OOD task (Table 3), LAPT also beats all methods requiring labeled data (e.g., LSA [28]: 70.56→71.18 FPR95 near-OOD; AugMix+SHE [17,66]: 84.45→71.18), while simultaneously improving ID classification accuracy from 60.11% (NegLabel) to 61.17%.

## Relation to Prior Work

LAPT directly extends NegLabel (Jiang et al., ICLR 2024), which introduced negative label mining and a combined ID/negative scoring function for CLIP-based OOD detection, and MCM (Ming et al., NeurIPS 2022), which established the foundational paradigm of using CLIP text representations as ID prototypes. The key departure is replacing NegLabel's hand-crafted text prompts with learnable distribution-aware prompt tokens, and replacing manually collected training images with automated sample collection via SDXL text-to-image generation and CLIP-based retrieval from Laion-400M. Unlike prior prompt-learning OOD methods (LoCoOp, CLIPN, LSN) that require few-shot ID samples or large-scale multi-modal data, LAPT needs only ID class names as input, making it fully autonomous.

## Why It Matters / Open Questions

By eliminating the labor-intensive and linguistically sensitive manual prompt engineering step, LAPT makes VLM-based OOD detection substantially more deployable in practice, with a 10.76% FPR95 gain over the best hand-crafted prompts on challenging near-OOD detection. The method also improves ID classification accuracy and covariate-shift robustness simultaneously, addressing the full-spectrum OOD detection setting. However, performance remains dependent on the quality and diversity of automatically collected training images, and the 60M-scale WebData used for retrieval is far smaller than the 5B-scale data underlying the generators, leaving open how to better balance semantic consistency and visual diversity in automated collection at scale.

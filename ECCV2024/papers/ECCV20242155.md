## Problem

Existing FSCIL methods fine-tune the entire backbone, causing overfitting on base classes and poor transferability to new few-shot classes, while prompt-based CIL methods require sufficient data in each incremental task to train task-specific prompts—data that is unavailable in few-shot settings. ASP addresses both limitations simultaneously by fixing the pre-trained ViT backbone and designing prompts that generalize without per-task retraining.
![Teaser figure](../imgs/ECCV20242155/cropped_page5_idx0.webp)

## Input / Output

The model takes RGB images resized to 224×224 as input and outputs a class label via cosine similarity between the extracted feature embedding and class prototypes (prototypical network classifier). The ViT-B/16 backbone is frozen throughout; only prompts inserted between attention blocks and a small prompt encoder are trained. Training occurs exclusively on the base task with sufficient data, after which incremental tasks require only N-way K-shot samples (e.g., 5-way 5-shot) with no further prompt training—only an EMA update of the average prompt features.

## Method

ASP decomposes prompts into two components: (1) Attention-aware Task-Invariant Prompts (TIP), initialized with identical values so that attention weights on each prompt token remain uniform across all tasks, forcing them to encode only shared, class-invariant knowledge; and (2) Self-Adaptive Task-Specific Prompts (TSP), generated by a compact prompt encoder (two small networks f_μ and f_Σ) that maps frozen backbone features to prompt vectors, trained with an Information Bottleneck objective that maximizes correlation with labels while minimizing correlation with extraneous input information. The TSP for each image blends its own encoded features with the average prompt features (p_avg) over the training set to prevent overfitting to a single sample, and p_avg is updated via EMA when new incremental tasks arrive. An additional Anchor Loss pulls class features toward estimated class centers (selected as the most representative anchor sample per class each epoch) to enlarge inter-class margins and reserve space for future classes.

## Results

On CIFAR-100, ASP achieves a final-task accuracy (A_T) of 86.7%, average accuracy (A_avg) of 89.0%, performance dropping rate (PD) of 5.5, and Harmonic Accuracy (HAcc) of 85.3%. On ImageNet-R, ASP reaches A_T of 69.7%, A_avg of 75.3%, PD of 13.5, and HAcc of 67.0%. On CUB-200, ASP attains A_T of 83.5%, A_avg of 83.8%, and HAcc of 83.4%. ASP surpasses the second-best method by 2.7%, 2.9%, and 7.2% on A_T across the three datasets, and by up to 9.2% on A_avg (ImageNet-R).

## Baselines & Comparisons

ASP outperforms all eight baselines on every metric across all three datasets. Among FSCIL methods, TEEN is the closest competitor (A_avg 87.3% vs. ASP's 89.0% on CIFAR-100; 63.9% vs. 75.3% on ImageNet-R), with ASP gaining 1.7–11.4% on A_avg. Classical CIL methods (iCaRL, Foster) suffer severe forgetting (PD 27–37) and poor new-class learning (HAcc 11–58). The original prompt-based CIL methods (L2P, DualP, CodaP) are particularly weak under few-shot conditions, achieving near-zero HAcc (0.0–0.1%) because their key-query prompt selection overfits the few-shot classifier head; even after replacing the classifier with a prototypical network (L2P+, DualP+, CodaP+), they still trail ASP by 3.7–11.3% on A_avg and 10–17% on HAcc. ASP's advantage is most pronounced on ImageNet-R, where the 10-way 5-shot setting amplifies the data-hungry weakness of prompt-based baselines.

## Relation to Prior Work

ASP builds directly on the complementary prompting architecture of DualP (task-invariant + task-specific prompts) and the prompt-based CIL framework of L2P, but departs from both in critical ways. Where DualP and L2P rely on a key-query mechanism to select task-specific prompts from a fixed pool (requiring sufficient training data per task), ASP replaces this with a compact prompt encoder guided by an Information Bottleneck objective, so that task-specific prompts are generated adaptively from input images without needing many samples. The attention-aware initialization of TIP (identical values across all prompt tokens to enforce uniform attention) is a novel twist on DualP's task-invariant prompts, and the IB-guided variational encoder draws on Alemi et al.'s deep variational information bottleneck framework, repurposing it for prompt generation rather than representation learning.

## Why It Matters / Open Questions

The paper identifies and quantifies a significant gap: existing prompt-based CIL methods (L2P, DualP, CodaP) achieve near-zero Harmonic Accuracy on new classes under few-shot settings, essentially failing to learn anything about incremental tasks. ASP's IB-guided prompt encoder and EMA-based p_avg update offer a practical, rehearsal-free solution that bridges this gap, making prompt-based CIL viable in data-scarce incremental scenarios. Limitations include evaluation on only three datasets with a single ViT-B/16 backbone, and the EMA update for p_avg is a simple heuristic whose theoretical grounding is limited. Open questions include whether the approach scales to very long task sequences, whether it generalizes to other backbone architectures (e.g., CLIP-based or convolutional), and whether the IB objective can be further refined to capture richer task-specific structure.

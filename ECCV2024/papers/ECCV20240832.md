## Problem

Pre-trained 3D point cloud classifiers suffer significant performance degradation when deployed on real-world noisy point clouds due to distribution shifts from occlusion, scale variation, and sensor noise. While test-time input adaptation via diffusion models (DDA) has shown promise in 2D, naively transferring it to 3D is suboptimal because it ignores the geometric structure of point clouds and incurs prohibitive computational cost from backpropagating through the diffusion model.
![Teaser figure](../imgs/ECCV20240832/cropped_page1_idx0.webp)

## Input / Output

The method takes a single corrupted 3D point cloud (N×3 coordinates, zero-centered and scaled to a unit ball for the classifier, standardized to unit variance for the diffusion model), a pre-trained point cloud diffusion model (Point-E base40M-uncond), and a pre-trained classifier. It outputs a geometrically transformed point cloud (rotation + per-point displacement applied) and a class probability vector; optionally, K=5 stochastic transformations are averaged via voting. The entire adaptation of one instance completes in under 1 second on a single GPU.

## Method

CloudFixer parameterizes the input transformation as a 6D-parameterized rotation matrix plus per-point displacement, then iteratively optimizes these parameters by minimizing the Chamfer distance between the transformed point cloud and the denoised estimation from a pre-trained diffusion model (forward pass only, no backpropagation through the diffusion network). The Chamfer distance is chosen over L2 to respect the permutation-invariant nature of point clouds, and a per-point regularization weighted by inverse k-NN distance allows flexible correction of noisy isolated points while preserving core geometry. The diffusion model is queried at randomly sampled timesteps in [0.02T, 0.12T] over 30 optimization steps with AdaMax. An optional online model adaptation variant (CloudFixer-O) additionally minimizes KL-divergence between the classifier's predictions on the original and adapted inputs, updating all layers except the classification head.

## Results

On ModelNet40-C with a challenging batch size of 1 (Point2Vec), CloudFixer achieves 78.23% average accuracy across 15 corruptions, improving over the unadapted baseline (62.09%) by 16.1 points and outperforming the closest competitor DDA (74.37%) by 3.9 points. Under mild conditions (batch size 64, i.i.d. stream), CloudFixer-O reaches 81.49% average accuracy, surpassing TENT (78.85%) and DUA (73.01%). On PointDA-10 (DGCNN), CloudFixer with voting achieves 65.23% average accuracy, matching DDA (65.35%) while being ~25× faster in adaptation time (0.93s vs. 23.6s per sample).

## Baselines & Comparisons

CloudFixer decisively outperforms all model-adaptation baselines in the challenging batch-size-1 setting: TENT and SHOT suffer complete model collapse (4.29% and 4.04% avg, near random), while PL, SAR, DUA, and LAME remain within 1–2 points of the unadapted baseline. Among per-sample methods, MEMO (70.75%) provides only marginal gains over unadapted, whereas DDA (74.37%) is the strongest competitor but still trails CloudFixer by 3.9 points on average, with the gap widening to 5.3 points on noise corruptions (87.38% vs. 82.05%) and 7.4 points on transformation corruptions (81.22% vs. 73.86%). Under mild conditions (batch size 64), CloudFixer-O (81.49%) surpasses TENT (78.85%) and DUA (73.01%), confirming that the input-adaptation strategy remains effective even when model-adaptation methods have sufficient data. On PointDA-10, CloudFixer with voting (65.23%) essentially ties DDA (65.35%) in accuracy while being ~25× faster per sample. MATE, the only 3D-specific test-time training method, achieves 59.23% (batch 1) and 60.87% (batch 20) with PointMAE, both below CloudFixer-O's 68.53% and 72.68% respectively.

## Relation to Prior Work

CloudFixer extends the 2D diffusion-driven input adaptation paradigm of DDA (Gao et al., CVPR 2023) to 3D point clouds, but departs in three key ways: it parameterizes the transformation as a rotation matrix plus per-point displacements rather than optimizing raw coordinates, it uses Chamfer distance to respect point cloud permutation invariance instead of the L2 loss implicit in Score Distillation Sampling, and it avoids backpropagation through the diffusion model entirely by using only a forward pass for denoising guidance. It also sits in contrast to the dominant model-adaptation TTA line (TENT, SHOT, SAR, DUA), which the paper shows collapses under realistic constraints like batch size 1 or temporally correlated streams. The diffusion model itself is borrowed from the 3D generation literature (Point-E), repurposed here as a domain-translation oracle rather than a generator.

## Why It Matters / Open Questions

CloudFixer is the first test-time input adaptation method for 3D point clouds that operates in under one second per instance, making it viable for real-time applications like autonomous driving where model-adaptation TTA is infeasible. The demonstrated robustness under batch size 1, label distribution shifts, and temporally correlated streams addresses a practical gap that model-adaptation methods cannot fill. Open questions include whether the approach extends to other 3D tasks (segmentation, detection), how it scales to much larger point clouds (e.g., full LiDAR scenes with 100k+ points), and whether the pre-trained diffusion model requirement limits deployment in domains where no such model exists. The online model adaptation component (CloudFixer-O) remains restricted to i.i.d. settings with sufficient batch size, leaving a gap for the most challenging streaming scenarios.

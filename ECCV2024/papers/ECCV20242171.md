## Problem

In multi-agent collaborative perception, heterogeneous agent models produce intermediate features with significant domain gaps that cause performance degradation when fused directly. Existing domain adaptation methods (e.g., MPDA, HEAL) either re-train neighbor encoders or ego detection heads, breaking model integrity and preventing backward compatibility with legacy immutable agents. The open challenge is to learn non-destructive domain adapters that preserve original models while remaining compatible with continually emerging new agent architectures.

## Input / Output

The method takes two BEV feature maps of potentially different spatial dimensions and channel counts (H×W×C vs H'×W'×C') generated by different point cloud encoders (e.g., PointPillar vs VoxelNet with different voxel resolutions). A reshaping operation (max-pooling + 1×1 convolution) first unifies spatial dimensions and channels before semantic transformation. The output is 3D object detection results produced by the ego agent's original, frozen detection head, ensuring that the agent's standalone perception performance is completely unaffected when collaborative mode is bypassed.

## Method

PnPDA comprises a semantic converter (Φ_S) that projects neighbor features into the ego semantic space, a semantic enhancer (Θ_T) that enriches ego features via intra-domain attention, and a semantic calibrator that computes inter-domain attention (DETR-style, with enhanced teacher features as queries and transformed student features as key-values) to supervise both. Training is two-stage: a pre-training phase uses a task-agnostic contrastive loss (inter-object discrimination on pillar-wise features) to align semantics without touching the downstream detection task, followed by fine-tuning with standard detection losses where the calibrator is discarded. The enhancer is updated via exponential moving average to preserve original teacher semantics and prevent training instability. For forward compatibility, a standard semantic space is trained so that newly emerging agents only need to train a single converter to standard semantics, while the ego agent converts from standard to its own semantics, enabling plug-and-play integration through two semantic transformations.

## Results

On the OPV2V dataset, PnPDA achieves an average AP@0.5 of 80.9% and AP@0.7 of 62.9% across two heterogeneous scenarios (pp8-pp4 and pp8-vn4) and four fusion networks, outperforming the SOTA domain adaptation method MPDA by 9.13% and 6.55% respectively. In the large-domain-gap scenario (pp8 ego with vn4 neighbor), PnPDA gains 7.43% AP@0.5 over the simple HETE baseline. The enhancer alone provides an additional 5.7%/3.9% AP@0.5/AP@0.7 improvement over the base encoder, confirming its role in boosting representational capacity.

## Baselines & Comparisons

PnPDA is compared against MPDA [3] (ICRA 2023), the primary SOTA method for heterogeneous feature domain adaptation in collaborative perception. PnPDA outperforms MPDA in 7 out of 8 scenario-fusion combinations, with the largest margins in Hetero Scenario 2 (large domain gap): +24.7 AP@0.5 with V2X-ViT (81.3 vs. 56.6) and +5.3 AP@0.5 with F-cooper (65.5 vs. 57.7). The one exception is Where2comm in Hetero Scenario 2, where MPDA achieves 62.7 AP@0.5 vs. PnPDA's 68.6 (PnPDA still wins), and Where2comm in Hetero Scenario 1 where MPDA edges out PnPDA by 0.2 AP@0.5 (75.7 vs. 75.9 — actually PnPDA still wins by 0.2). The paper also notes that MPDA's task-specific adapter is limited when the detection head is frozen, whereas PnPDA's task-agnostic converter preserves model integrity. A simple HETE baseline (max-pool + 1×1 conv for dimension alignment only) is also included, showing PnPDA's semantic transformation provides substantial gains over mere spatial/channel alignment, especially under large domain gaps.

## Relation to Prior Work

This paper departs from prior heterogeneous collaborative perception methods (MPDA, HEAL) that break model integrity by retraining neighbor encoders or ego detection heads. It repurposes knowledge distillation (teacher-student with EMA) and DETR-style query-key-value attention into a non-destructive domain adapter framework, where a semantic converter transforms neighbor features into ego semantics and a semantic enhancer strengthens ego representations. The standard-semantics concept is borrowed from HEAL but restructured into a two-step transformation pipeline (neighbor→standard→ego) to achieve forward compatibility without requiring the ego agent to retrain for each new model. Contrastive learning with object-level positive/negative pairs provides task-agnostic supervision during pre-training, distinguishing it from MPDA's task-specific attention-based adaptation.

## Why It Matters / Open Questions

The plug-and-play, non-destructive property addresses a critical deployment gap: real-world fleets contain legacy models whose encoders and heads cannot be retrained, yet must still participate in collaborative perception. The forward-compatibility design (two-step semantic transformation via a standard space) means new models join with only independent converter training, reducing the combinatorial adapter burden. However, the work is limited to point-cloud features on a single simulated dataset (OPV2V), and the authors acknowledge that extending to multi-modal (image) features remains open. Whether the standard-semantics approach scales to large, diverse fleets with many heterogeneous architectures in real-world conditions is untested.

## Problem

Existing in-context image generation models, notably Prompt Diffusion, over-rely on text prompts and fail to transfer visual characteristics (style, texture, color palette) from context examples when the prompt is absent, revealing they cannot truly learn from visual context. Additionally, prior work is limited to a single source-target context pair and does not support variable or multiple context examples for few-shot scenarios.
![Teaser figure](../imgs/ECCV20242068/cropped_page1_idx1.webp)

## Input / Output

The model takes a query image (HED, segmentation, depth, canny, sketch, or real image) that defines the output layout, one to three visual context images (target examples showing desired appearance), and an optional text prompt. All inputs are processed at 256×256 resolution; context images and prompts are encoded by frozen CLIP ViT-L/14 encoders, while the query image passes through a trainable ControlNet-style encoder. The output is a generated 256×256 image (forward tasks) or an image map such as HED, segmentation, or depth (reverse tasks).

## Method

Context Diffusion separates layout control from fine-grained visual conditioning: the query image is injected spatially via a trainable LDM encoder copy connected through zero-convolution layers (ControlNet setup), while visual context images are injected as cross-attention conditioning alongside text embeddings. Each context image is encoded by a frozen CLIP ViT-L/14, the resulting token sequences are summed across all k images, linearly projected to the text embedding dimension, and concatenated with text embeddings in the cross-attention layers of the UNet backbone. This design lets the model learn from visual context, text prompt, or either alone, and naturally supports a variable number of context images (k ∈ {1,2,3} in experiments) for few-shot settings. Training is multi-task on 310k synthetic image-caption pairs with HED, segmentation, and depth maps, using random k per batch and 50% prompt dropout for classifier-free guidance, with only the ControlNet encoder copy and cross-attention projection layers trained.

## Results

In human evaluation (win rate), Context Diffusion achieves 48.6% average win rate on in-domain tasks and 55.2% on out-of-domain tasks, compared to 21.1% and 25.2% for Prompt Diffusion. The most striking gap appears in the context-only (C) setting, where Context Diffusion wins 80.2% of votes in-domain and 63.7% out-of-domain, versus just 4.5% and 22.8% for Prompt Diffusion. On offline FID metrics for in-domain map-to-image tasks, Context Diffusion achieves 12.3/13.4/12.9 (HED/seg/depth, C+P) versus 12.8/16.7/15.9 for Prompt Diffusion, with the largest gap in the context-only setting (e.g., 17.7 vs 22.5 FID for HED-to-image).

## Baselines & Comparisons

Against Prompt Diffusion [48], Context Diffusion wins decisively in the context-only (C) setting, achieving 80.2% vs 4.5% win rate in-domain and 63.7% vs 22.8% out-of-domain, demonstrating that Prompt Diffusion cannot truly learn from visual examples without text. In the combined C+P setting, Context Diffusion also leads (36.3% vs 28.5% in-domain; 52.3% vs 26.9% out-of-domain), with the out-of-domain gap being particularly large. The only setting where Context Diffusion slightly underperforms is in-domain prompt-only (29.6% vs 30.4%), a near-tie. On offline FID metrics, Context Diffusion consistently achieves lower (better) scores across all three in-domain map-to-image tasks in both C+P and C settings. Against ControlNet [54], the comparison is limited to a qualitative zero-shot prompt-only evaluation (Figure 7), where Context Diffusion produces more realistic images while also generalizing across multiple tasks without requiring task-specific retraining.

## Relation to Prior Work

This paper builds directly on ControlNet's architecture for encoding query images as spatial layout controls and on the Latent Diffusion Model backbone, but departs from the closest prior work, Prompt Diffusion, in two key ways. First, it injects visual context images as cross-attention conditioning (concatenated with text embeddings) rather than as a control signal, treating them at the same representational level as text. Second, it supports a variable number of context images (few-shot) and requires only target images rather than source-target pairs, which the ablation shows adds no useful information. The use of frozen CLIP encoders for both text and visual context, with a linear projection to align dimensions, is a straightforward but effective design choice that distinguishes it from Prompt-Free Diffusion, which removes text entirely.

## Why It Matters / Open Questions

The paper reveals that Prompt Diffusion's claimed in-context learning capability is largely illusory: without a text prompt, its context-only win rate drops to 4.5%, suggesting it was relying on textual guidance rather than truly learning from visual examples. This reframes the in-context image generation literature and motivates architectures that can genuinely extract style, palette, and object appearance from visual examples alone. Limitations include the small synthetic training set (310k images at 256×256), the restriction to at most 3 context images in experiments, and evaluation against a single baseline. Open questions include whether the few-shot scaling benefit persists with more than 3 examples, whether the approach generalizes to higher resolutions and real-world (non-synthetic) data, and how it compares to retrieval-augmented or personalization-based alternatives for style transfer.

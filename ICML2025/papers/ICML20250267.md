## Problem

Existing grouped clustering methods (HDP, nested DP, vHDPMM) assume all groups are measured on the same set of variables, forcing the exclusion of valuable group-specific idiosyncratic variables (e.g., cancer-specific clinical markers in pan-cancer studies). No prior method jointly models shared and group-specific variables in a unified nonparametric framework where local variables can refine global clusters while preserving cross-group cluster sharing.
![Teaser figure](../imgs/ICML20250267/cropped_page8_idx3.webp)

## Input / Output

The method takes J groups of observations where each observation x_ji is partitioned into local variables x_ji^L (present only in group j, with potentially different dimensions p_j across groups) and global variables x_ji^G (shared across all groups, e.g., PCA-reduced gene expression). It produces a two-level hierarchical clustering: global-level cluster labels k_jt_{ji} that are comparable across groups, and local-level labels t_ji that subdivide global clusters within each group. The hierarchical nesting guarantees that observations sharing a local cluster necessarily share a global cluster, but not conversely.

## Method

The GLocal DP assigns each group a random measure G_j ~ DP(α, U_j ⊗ V), where U_j is a group-specific base measure on local factors and V ~ DP(γ, H) is a shared base measure on global factors. The product structure ensures that global atoms (drawn from V) are shared across groups while local atoms (drawn from U_j) are group-specific, creating a two-level cluster hierarchy. Unlike the vHDPMM's sequential approach (model global first, then local conditionally), the GLocal DP models both jointly, so local variables can influence global-level clustering. The paper provides stick-breaking and finite-mixture-limit characterizations, proves exponential truncation error bounds for both the prior and posterior, and develops a CAVI algorithm with mean-field variational distributions (multinomial for cluster indicators, beta for stick-breaking weights, normal-Wishart for Gaussian kernel parameters) that scales to large datasets.

## Results

On synthetic data (3 groups, 3 global variables, 2–4 local variables, 50 replications), GLocal DP achieves higher ARI than HDP at the global level and higher ARI than per-group GMM at the local level, with the gap widening as local-variable separation increases. On the TCGA pan-gastrointestinal cancer dataset (92 esophageal, 363 stomach, 173 colon, 120 rectal patients; 60,483 genes reduced to 10 PCs as global variables), GLocal DP identifies shared global clusters between colon and rectal cancers and refines them into cancer-specific local subclusters using variables such as CEA, smoking history, positive lymph nodes, and BMI. The VI algorithm converges in under 9 minutes on a MacBook Pro M1 (K = T = 30, 20 restarts), and MCMC vs. VI comparisons show comparable clustering accuracy with VI offering significant computational savings.

## Baselines & Comparisons

Against HDP (Teh et al., 2006), GLocal DP consistently achieves higher ARI at the global level across all tested separations of local variables, because HDP can only use the shared global variables while GLocal DP leverages both global and local information. Against per-group Gaussian Mixture Models, GLocal DP achieves higher ARI at the local level, demonstrating that the hierarchical global-local structure yields better subcluster identification than fitting independent GMMs to each group. Against the Versatile Hierarchical Dirichlet Process Mixture Model (vHDPMM, Dinari & Freifeld, 2020), both methods perform comparably when clusters are well-separated regardless of the true generative model, but GLocal DP outperforms vHDPMM under less-separated conditions even when vHDPMM is the data-generating model, highlighting the advantage of the joint (rather than hierarchical) modeling framework. The paper also notes that the two models are not special cases of one another and employ fundamentally different posterior inference strategies (CAVI vs. split-merge MCMC).

## Relation to Prior Work

This paper extends the Hierarchical Dirichlet Process (HDP) by introducing a group-specific base measure U_j alongside the shared base measure V, enabling clustering of grouped data where each group has its own set of idiosyncratic variables in addition to shared variables. It departs fundamentally from the vHDPMM (Dinari & Freifeld, 2020) in construction: while vHDPMM models global variables first and then conditionally models local variables within each global cluster, GLocal DP defines a joint distribution over both, so that sharing a local cluster implies sharing a global cluster. The variational inference algorithm adapts the truncated CAVI framework of Blei & Jordan (2006) to the two-level stick-breaking structure, and the paper contributes novel truncation error bounds for the resulting finite approximation.

## Why It Matters / Open Questions

The method addresses a practically important gap in pan-cancer genomics and other multi-domain settings where clinical or domain-specific variables are only available for certain subgroups, and existing grouped clustering methods must discard this information. The finding that local variables (e.g., CEA levels, smoking history) refine shared molecular clusters into prognostically distinct subclusters demonstrates tangible scientific value beyond pure clustering accuracy. Open questions include extending the framework to incorporate the group-clustering feature of the nested DP, handling covariate-assisted clustering, and relaxing the conditional independence assumption between local and global variables given the latent factors.

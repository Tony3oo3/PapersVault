## Problem

Translating natural language problem descriptions into solver-ready optimization models remains a human-expertise bottleneck, even though solving algorithms have matured significantly. Prior LLM-based autoformulation approaches generate complete formulations in a single pass or via multi-agent pipelines, lacking systematic exploration of the vast, problem-dependent hypothesis space and robust mechanisms for evaluating whether a formulation faithfully captures the intended problem. This paper formalizes autoformulation as a search problem and identifies three core challenges: the enormous and problem-dependent hypothesis space, efficient exploration under formulation uncertainty and redundancy, and the absence of a reliable correctness signal.

## Input / Output

The method takes a single natural language problem description (e.g., a supply chain or resource allocation scenario) and produces a set of functionally distinct optimization models, each consisting of a mathematical formulation structured as a JSON dictionary with four fields (parameters/decision variables, objective function, equality constraints, inequality constraints) and a corresponding Gurobi solver script generated by a deterministic parser. The output is not a single model but up to T distinct formulations ranked by estimated reward, enabling Pass@N and Best-of-N evaluation protocols. Formulations are represented with symbolic mathematical expressions in Python string syntax, using parameter-defined variables rather than hard-coded values.

## Method

The autoformulator decomposes formulation into four sequential stages (parameters/decision variables → objective → equality constraints → inequality constraints) and searches this hierarchical space using Monte-Carlo Tree Search with depth 4. At each node, an LLM (GPT-4) generates H candidate component formulations conditioned on the partial formulation and problem description; SMT solvers then prune trivially equivalent candidates (e.g., 2x+3y vs. 3y+2x) by checking logical equivalence of constraint systems, reducing the search space by roughly 80% on average. Partial formulations are scored via LLM-based comparative ranking (normalized to [0,1]) to initialize node values, while complete formulations receive a dual reward combining a binary solver-optimality indicator with an LLM comparative correctness score against fixed baseline models. Node selection uses UCT with a blended value (λ·prior + (1−λ)·backpropagated), balancing exploitation of high-value branches with exploration of under-visited ones, and the process runs for T rollouts to produce a diverse set of candidate formulations.

## Results

On four real-world benchmarks (NL4OPT, IndustryOR, MAMO ComplexLP, ComplexOR), the Autoformulator achieves formulation correctness of 92.62%, 48.0%, 62.3%, and 72.2% respectively using all rollouts (T=16, H=10, I=3). With just one rollout (N=1), the method already matches or exceeds the strongest baseline (ORLM) on NL4OPT (85.24% vs. 85.7%) and ComplexOR (66.7% vs. 44.4%), and with three rollouts (N=3) it surpasses all baselines across every benchmark. The metric is execution accuracy: the proportion of problems where the autoformulated model yields the correct optimal objective value (within 5% tolerance).

## Baselines & Comparisons

Against ORLM (Tang et al., 2024), the closest competitor, the Autoformulator wins on all four benchmarks at N=3 (e.g., 92.21% vs. 90.2% on NL4OPT, 61.4% vs. 56.3% on MAMO, 72.2% vs. 61.1% on ComplexOR), with the gap widening on harder benchmarks. Against OptiMUS (AhmadiTeshnizi et al., 2024), the Autoformulator achieves comparable performance at N=1 on ComplexOR (66.7% vs. 66.7%) but pulls ahead at N=3 (72.2% vs. 66.7%) and dominates on NL4OPT (92.21% vs. 78.8%). Against Chain-of-Experts (Xiao et al., 2023), the Autoformulator leads by a wide margin on all shared benchmarks (e.g., 92.21% vs. 64.2% on NL4OPT, 61.4% vs. 40.2% on MAMO). Against Reflexion (Shinn et al., 2023), the gap is largest, with the Autoformulator outperforming by 39+ points on NL4OPT and 53+ points on ComplexOR. Notably, the Autoformulator matches ORLM at N=1 on NL4OPT, demonstrating that the hierarchical MCTS search is effective even with a single rollout, while additional rollouts exploit the structured exploration to discover more diverse correct formulations.

## Relation to Prior Work

This paper builds on the MCTS framework (Coulom, 2006) and recent LLM-based autoformulation work (Chain-of-Experts, OptiMUS, ORLM), but departs from prior multi-agent approaches that generate complete formulations in a single pass. The key methodological departure is a hierarchical decomposition of the formulation into four sequential components (parameters, decision variables, objective, constraints) explored via MCTS, combined with SMT-based symbolic pruning to eliminate trivially equivalent branches and comparative LLM evaluation for correctness scoring. Unlike prior works that rely on LLMs for both formulation and code generation, this paper uses a deterministic parser for the computational representation, isolating the search problem to the mathematical formulation step.

## Why It Matters / Open Questions

Autoformulation addresses a genuine bottleneck in optimization modeling where human expertise is the limiting factor, and this paper provides the first systematic search-based framework with principled evaluation for the task. However, the method is currently limited to LP/MILP problems, relies on expensive GPT-4 calls across multiple rollouts, and the correctness evaluation still shows only 82% agreement with expert judgment. Open questions include scaling to non-convex and Type-II/III problems requiring creative reformulations, reducing compute cost, and whether the search trajectories can inform LLM finetuning for more efficient inference.

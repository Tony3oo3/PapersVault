## Problem

Existing parameter-efficient fine-tuning (PEFT) methods for pre-trained 3D vision models operate primarily at the token level and fail to capture the geometric information inherent in point clouds, resulting in a significant performance gap compared to full fine-tuning. This paper addresses the need for a 3D-specific PEFT approach that explicitly leverages the spatial and shape structure of point clouds to achieve competitive accuracy with minimal trainable parameters.
![Teaser figure](../imgs/ICML20250032/cropped_page0_idx0.webp)

## Input / Output

The method takes a raw 3D point cloud (2048 points for ScanObjectNN, 1024 for ModelNet40) and produces a class label. At the input level, P learnable point prompts (P=20 for ScanObjectNN, P=5 for ModelNet40) are concatenated with the original points, and the Point Shift Prompter generates instance-specific coordinate shifts that modify the input geometry before token embedding. The output is a single class prediction from a classification head that combines the [CLS] token, the maximum patch token, and the global shape feature extracted by the Point Shift Prompter.

## Method

GAPrompt freezes the pre-trained 3D transformer backbone and introduces three geometry-aware modules trained with only ~2.19% of total parameters. First, a Point Prompt appends P learnable 3D coordinates to the input point cloud, giving the model explicit point-level geometric cues. Second, a Point Shift Prompter performs hierarchical FPS+KNN downsampling with lightweight PointNet layers to extract a global shape feature vector, then upsamples to generate per-point coordinate shifts that compact the input geometry; this shape feature also modulates prompt tokens and adapter layers via learned scale factors. Third, a Prompt Propagation mechanism uses FPS and KNN on the input tokens to identify center-neighbor geometric relationships, randomly injects shape-enhanced prompt tokens into these local neighborhoods (analogous to dropout), and propagates the modified center features back to all tokens via PointNet++-style interpolation. This design ensures that instance-specific shape information is woven into every transformer block's feature extraction rather than being confined to a single input-level perturbation.

## Results

On the hardest ScanObjectNN variant (PB_T50_RS), GAPrompt achieves 90.67% accuracy with Point-FEMAE (0.6M params, 2.19% trainable) and 94.31% with PointGPT-L (2.0M params, 0.55%), surpassing full fine-tuning of all four base models by 0.35–1.77%. On ModelNet40, GAPrompt reaches 96.2% with PointGPT-L, a new state-of-the-art without voting. Across all four pretrained backbones, GAPrompt consistently outperforms IDPT, DAPT, and Point-PEFT while using fewer trainable parameters (0.6–2.0M vs. 0.7–10.0M) and adding negligible FLOPs overhead (~5.0G vs. 7.0–75.2G for competitors).

## Baselines & Comparisons

GAPrompt outperforms all three 3D-specific PEFT baselines (IDPT, DAPT, Point-PEFT) on every base model and dataset. On PB_T50_RS with Point-FEMAE, GAPrompt (90.67%) beats IDPT (88.38%) by 2.29%, DAPT (88.51%) by 2.16%, and Point-PEFT (89.35%) by 1.32%, while using fewer parameters (0.6M vs. 0.7–1.7M). Against full fine-tuning, GAPrompt surpasses Point-MAE by 0.39%, ReCon by 0.03%, PointGPT-L by 0.91%, and Point-FEMAE by 0.45% on PB_T50_RS, and achieves 96.2% on ModelNet40 with PointGPT-L versus 94.1% for full fine-tuning. In Table 2, GAPrompt (85.57%) also dominates NLP/2D PEFT methods on PB_T50_RS with Point-MAE: it exceeds VPT (81.09%) by 4.48%, Adapter Tuning (83.93%) by 1.64%, SSF (82.58%) by 2.99%, and AdapterFormer (83.45%) by 2.12%, while using comparable or fewer parameters (0.6M vs. 0.4–0.9M). The only case where GAPrompt does not lead is ModelNet40 with Point-FEMAE, where Point-PEFT edges it by 0.2% (94.3% vs. 94.5% is actually GAPrompt winning; Point-PEFT gets 94.3%), confirming GAPrompt's consistent superiority.

## Relation to Prior Work

GAPrompt extends the parameter-efficient fine-tuning (PEFT) paradigm—prompt tuning and adapter tuning—from NLP and 2D vision to 3D point clouds, building on the hierarchical feature extraction machinery of PointNet++ (FPS, KNN, feature propagation) for its Point Shift Prompter and Prompt Propagation modules. It departs from prior 3D-specific PEFT methods (IDPT, DAPT, Point-PEFT) by operating at the point level rather than solely at the token level: it introduces learnable point clouds as explicit geometric prompts and extracts instance-specific shape features that modulate both prompt tokens and adapters. This positions GAPrompt as a geometry-aware refinement of the token-prompting lineage, arguing that the irregular, unstructured nature of point clouds demands input-level geometric cues that token-level prompts alone cannot capture.

## Why It Matters / Open Questions

GAPrompt demonstrates that capturing instance-specific geometric information at the input level can close—and in several cases slightly exceed—the gap between PEFT and full fine-tuning for 3D point cloud classification, using only ~2% of trainable parameters and negligible extra FLOPs. This is practically significant for practitioners who need to adapt large pre-trained 3D models (Point-MAE, ReCon, PointGPT, Point-FEMAE) to downstream tasks without the storage and compute cost of full fine-tuning. However, the evaluation is limited to classification on two datasets; open questions include whether geometry-aware prompting generalizes to denser tasks like segmentation or detection, whether it transfers across fundamentally different pre-training objectives (contrastive vs. generative), and whether the Point Shift Prompter's hierarchical architecture scales to very large point clouds.

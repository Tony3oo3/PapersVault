## Problem

Differentially private federated learning (DP-FL) struggles to scale to large language models because full model weights cannot be stored or trained on client devices. Existing DP synthetic data methods (e.g., Private Evolution) rely on iterative prompt refinement via in-context learning and discard low-scoring synthetic samples, limiting how effectively LLMs can be aligned to private client data. This paper asks whether the private client feedback already collected by these methods can be repurposed as reinforcement learning rewards to directly fine-tune an LLM's weights for higher-quality synthetic data generation.

## Input / Output

The method takes a pre-trained LLM (LLaMA-3-8B) as the synthetic data generator, a small downstream model (e.g., DistilGPT2 with 82M parameters) to be aligned, a sentence embedding model for similarity scoring, and a base prompt template. Each round, the server generates K×J synthetic text samples (e.g., 1800 prompts × 10 samples = 18,000 samples), sends their embeddings to participating clients, and receives DP-noised cosine similarity score vectors (clipped to unit norm, with Gaussian noise scaled by 1/L). The final output is a large synthetic dataset (up to 1M samples) used to fine-tune the downstream model, which is then deployed to client devices for local inference without further server communication.

## Method

POPri reformulates DP synthetic data generation as an LLM policy optimization problem by treating client feedback scores as RL rewards. In each of T rounds, the server generates J synthetic samples from each of K prompts using the current LLM; participating clients compute the average cosine similarity between each synthetic sample and their private data, clip the resulting score vector to unit norm, add Gaussian noise, and securely aggregate. For each prompt, the server constructs a DPO preference pair using the highest-scoring sample as 'chosen' and the 5th-ranked sample as 'rejected' (avoiding the last rank to prevent uninformative pairs and rank 2 to avoid DP-noise-induced mislabeling). The LLM is then fine-tuned via the DPO loss with LoRA (rank 4, α=8) on all attention and projection matrices, iteratively improving its ability to generate samples that better match the private data distribution. This replaces PE's in-context prompt refinement with direct weight-level alignment, and replaces nearest-neighbor histogram scoring with denser cosine similarity scoring that yields meaningful preference pairs for all prompts.

## Results

On the bioRxiv dataset at ε=1, POPri achieves 34.8% next-token prediction accuracy, outperforming PE (31.1%), DP-FedAvg (28.3%), and DP-FTRL (28.2%), closing the gap between fully-private (ε=0, 27.9%) and non-private (ε=∞, 41.5%) by 58%. On Congressional Speeches at ε=1, POPri reaches 30.4% versus 27.0% for PE and 29.0% for DP-FedAvg. On the central DP benchmarks, POPri achieves 29.4% on PubMed (vs. 27.9% for Aug-PE) and 40.2% on OpenReview text classification (vs. 37.0% for Aug-PE) at ε=1.

## Baselines & Comparisons

POPri outperforms all four baseline families across every dataset and privacy level tested. Against DP-FedAvg and DP-FTRL (the DP-FL baselines), POPri gains +6.5 and +6.6 percentage points on bioRxiv at ε=1 (34.8% vs. 28.3%/28.2%), and +1.4 points on Congress (30.4% vs. 29.0%). Against the Private Evolution baselines (PrE-Text and Aug-PE), POPri improves by +3.7 points on bioRxiv (34.8% vs. 31.1%), +3.4 points on Congress (30.4% vs. 27.0%), +1.5 points on PubMed (29.4% vs. 27.9%), and +3.2 points on OpenReview (40.2% vs. 37.0%). Notably, POPri also outperforms the PE+SFT ablation (which fine-tunes directly on top-scoring samples without preference optimization) by 6.2 points on bioRxiv at ε=1, confirming that the DPO-based policy optimization step is critical. The gap-closing metric is most dramatic on bioRxiv, where POPri recovers 58% of the non-private-to-fully-private gap versus only 23% for PE and ~3% for DP-FL.

## Relation to Prior Work

This paper builds directly on the Private Evolution (PE) framework (Lin et al., 2023; Xie et al., 2024; Hou et al., 2024), which iteratively refines LLM prompts using DP client feedback to generate synthetic data for on-device model training. The key departure is a reformulation: rather than using client feedback solely to select in-context examples (PE) or to perform supervised fine-tuning on top-scoring samples (PE+SFT), POPri treats the DP-noised similarity scores as RL rewards and applies Direct Preference Optimization (DPO, Rafailov et al., 2023) to fine-tune the LLM's weights. This shifts the problem from prompt engineering to policy optimization, and from discarding low-quality samples to exploiting the full preference signal. The paper also introduces LargeFedBench, a new federated text benchmark with 134k+ clients, addressing the contamination and scale limitations of prior FL text datasets.

## Why It Matters / Open Questions

POPri closes the accuracy gap between fully-private and non-private settings by up to 58% (vs. 28% for prior synthetic-data methods and 3% for DP-FL), making private on-device learning substantially more practical. The LargeFedBench benchmark is a significant practical contribution, providing uncontaminated, regularly-updated federated data at production scale for LLM-era evaluation. Open questions remain: the paper acknowledges that POPri inherits biases from the public LLM (e.g., language mismatch could force clients to vote on irrelevant samples), that running too many rounds causes overfitting, and that the method is more server-compute-intensive than PE. A key future direction is designing DP synthetic data algorithms where clients can actively counteract public LLM failures based on their own data.

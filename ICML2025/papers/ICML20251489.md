## Problem

Existing federated prompt learning (FPL) methods for vision-language models maintain in-distribution accuracy but fail at out-of-distribution detection, while centralized OOD-robust methods break down under federated data heterogeneity. The core gap is the inability to simultaneously preserve class-level separation (for ID generalization) and distribution-level separation (for OOD detection) across heterogeneous clients, and to ensure consistent OOD discrimination from a global perspective rather than relying on each client's local view.

## Input / Output

The method consumes RGB images encoded by a frozen ViT-B/16 CLIP image encoder and class-name text embeddings, producing both a class label (via softmax over similarity scores between image features and fused ID prompts) and an OOD detection score computed as Maximum Concept Matching (MCM) between image features and OOD prompt text features. Three sets of 16-length, 512-dimensional prompt vectors are maintained: C global ID prompts, C local ID prompts per client, and U=100 OOD prompts initialized from WordNet candidate class names selected by negative cosine similarity to ID class embeddings.

## Method

FOCoOp introduces two complementary modules operating at different levels. At the client level, the Bi-level OOD Separations (BOS) module jointly optimizes three prompt sets under a bi-level distributionally robust optimization objective: global prompts are perturbed within an optimal-transport ball (preserving geometric structure of the feature space) to enforce class-level separation, while OOD prompts are perturbed within an unbalanced-OT ball (capturing both geometric uncertainty and non-geometric contamination) to enforce distribution-level separation between ID images and OOD text. At the server level, the Global-view OOD Consistency (GOC) module aggregates client prompts and applies semi-unbalanced optimal transport (solved via Frank-Wolfe) to align the OOD prompt distribution with the global ID prompt distribution; the top-M OOD prompts most similar to global prompts are used to calibrate the aggregated global prompts via exponential moving average, while the most distant OOD prompts are retained for detection, thereby resolving the ambiguity where one client's OOD prompts match another client's ID data.

## Results

On CIFAR-100 under Pathological Non-overlap (K=10), FOCoOp achieves 93.85% ACC, 91.47% CACC, 19.50% FPR95, and 95.42% AUROC, substantially outperforming the strongest OOD-aware baseline FedGalLoP (91.19% ACC, 41.45% FPR95, 89.64% AUROC). On TinyImageNet under the same setting, FOCoOp reaches 88.35% ACC and 21.73% FPR95, nearly halving the FPR95 of the next-best method (PromptFolio at 42.84%). Under the more challenging Pathological Overlap (K=100) setting, FOCoOp still leads with 94.10% ACC and 24.00% FPR95 on CIFAR-100, while FedGalLoP drops to 57.78% FPR95. On domain generalization, FOCoOp achieves 87.68% average on DomainNet and 98.16% on Office-Caltech10, marginally surpassing FedGalLoP (87.30% and 97.99%).

## Baselines & Comparisons

FOCoOp outperforms all seven baselines on every metric across both CIFAR-100 and TinyImageNet under both heterogeneity settings. The closest competitor on generalization is PromptFolio (91.82% ACC on CIFAR-100), but it lags FOCoOp by 2.03% in ACC and by 24.76 points in FPR95 (44.26 vs. 19.50), revealing that standard FPL methods sacrifice OOD detection for accuracy. Among OOD-aware baselines, FedGalLoP is the strongest, achieving 91.19% ACC and 89.64% AUROC on CIFAR-100, yet its FPR95 of 41.45 is more than double FOCoOp's 19.50, indicating inconsistent OOD discrimination across heterogeneous clients. FedLoCoOp and FedLAPT perform worst overall (ACC below 65% and FPR95 above 77%), confirming that directly adapting centralized OOD prompt-tuning methods to federated settings fails under data heterogeneity. On domain generalization (Table 4), FOCoOp leads with 87.68% average on DomainNet and 98.16% on Office-Caltech10, narrowly beating FedGalLoP (87.30% and 97.99%), while FedLAPT trails significantly at 80.41% and 83.79% respectively.

## Relation to Prior Work

FOCoOp extends the federated prompt learning (FPL) line of work (PromptFL, FedOTP, PromptFolio) by introducing an explicit OOD detection objective alongside the standard generalization-personalization trade-off. It builds on CoOp-style prompt tuning for CLIP and borrows the optimal-transport-based global-local prompt cooperation from FedOTP, but departs from prior FPL methods by adding a third set of OOD prompts and a server-side calibration step. The OOD detection component draws on centralized VLM OOD methods (CLIPN, LoCoOp, LAPT) and federated OOD work (FOG, FOSTER, FOOGD), but is the first to integrate these into a federated prompt-learning pipeline with a three-prompt architecture and bi-level distributionally robust optimization.

## Why It Matters / Open Questions

The paper identifies and addresses a concrete gap: existing FPL methods that achieve strong in-distribution accuracy (e.g., 91–94% on CIFAR-100) collapse on OOD detection (FPR95 > 38), making them unreliable for open-world deployment. The semi-unbalanced OT calibration at the server is a practical mechanism for resolving the inconsistency of locally-trained OOD prompts across heterogeneous clients, a problem that prior federated OOD methods (FOG, FOSTER) sidestep by operating in centralized or non-prompt settings. Open questions include scalability to larger VLMs (tested only on ViT-B/16), dependence on WordNet for OOD prompt initialization, and whether the MCM-based detection score generalizes to truly novel semantic shifts absent from any lexical database.

## Problem

While Mamba's input-dependent SSM parameters (the S6 layer) empirically outperform its time-invariant S4D predecessor, it remained unclear how input selectivity concretely translates into improved function approximation, long-range memorization, and associative recall. The paper addresses this gap by providing mechanistic, theoretical explanations for Mamba's capabilities and identifying how the S6 layer interacts with convolution and gating to solve specific tasks.
![Teaser figure](../imgs/ICML20251007/cropped_page5_idx1.webp)

## Input / Output

The analysis operates on discrete token sequences drawn from finite vocabularies. For KEEP n-TH, the input is a sequence of T tokens (optionally augmented with time positional encoding) and the output is the n-th token. For MQAR, the input consists of κ key-value pairs followed by shuffled query keys interwoven with noise tokens, and the model must output the value associated with each query key at its position. For INDUCTION HEADS, the input is a token sequence and the output at each position is the token immediately following the most recent prior occurrence of the current token. All tasks use supervised training with cross-entropy loss on synthetic sequences.

## Method

The paper provides three theoretical pillars. First, it proves the S6 layer can represent Haar wavelet projections by exploiting input-dependent discretization Δ(x) to approximate Heaviside step functions, yielding O(2^{-N/3m}) approximation error for piecewise-constant functions versus O(N^{-1}) for S4D's Fourier bases. Second, sensitivity analysis reveals that S6 suffers exponential memory decay like S4D, but input selectivity allows dynamic counteraction by pushing λΔ(x_t)→0 to 'freeze time' and preserve information. Third, the paper constructs explicit 1-layer Mamba, Mamba-2, and Mamba-S4D architectures that exactly solve MQAR by organizing the hidden state matrix so columns are indexed by keys and store associated values, with convolution filtering key-value pairs and B_t/C_t routing information to/from the correct column. A key architectural insight is the proposed Mamba-Δ^T variant, which applies input-dependent Δ along the state dimension N rather than the embedding dimension d, enabling selective erasure of outdated key-value associations and exact INDUCTION HEADS solution with model size depending only on vocabulary size, not sequence length.

## Results

On the KEEP FIFTH task (T=50, |V|=128), Mamba+PE achieves 100% accuracy with 9.2k parameters, matching Transformer (1.0, 6.4k params), while Mamba without PE (0.08) and S4D (0.09) both fail. On MQAR, the paper proves that 1-layer Mamba (N=κ), Mamba-2 (N=log κ), and Mamba-S4D (N=1) can all solve the task exactly, with empirical results (Fig. 2) confirming the theoretical model-size bounds are tight. On INDUCTION HEADS, the proposed Mamba-Δ^T variant matches or exceeds standard Mamba across all model sizes, reaching 100% accuracy only above the theoretical bound d=2|V|, N=|V| (Fig. 3).

## Baselines & Comparisons

Against S4D (Gu et al., 2022a), Mamba with input selectivity achieves a decisive win on KEEP FIFTH (1.00 vs. 0.09 accuracy), demonstrating that S6's ability to represent Haar wavelets is critical for approximating discontinuous signals. On MQAR, S4D requires a larger embedding (d=O(κ log|V|)) and relies on gating, while Mamba and Mamba-2 solve it without gating using smaller states. Against vanilla Mamba (Gu & Dao, 2023), the Mamba-Δ^T variant (which applies Δ along the state dimension N rather than embedding dimension d) performs equally or better on INDUCTION HEADS across all tested model sizes, confirming that the original Mamba's choice of Δ placement is suboptimal for this task. Against Mamba-2 (Dao & Gu, 2024), the paper shows Mamba-2 is strictly more parameter-efficient on MQAR (d=O(log κ + log|V|), N=log κ vs. Mamba's d=O(κ+log|V|), N=κ), thanks to its three independent convolutions enabling a shift-1 kernel for B_t. Overall, the paper positions Mamba-2 as the most efficient architecture for associative recall, while identifying Mamba-Δ^T as a targeted improvement over vanilla Mamba for induction-heads-style tasks.

## Relation to Prior Work

This paper extends the SSM expressivity analysis lineage (HiPPO → S4/S4D → Mamba → Mamba-2) by moving beyond the general universal-approximation results of Cirone et al. (2024) and Orvieto et al. (2024) to characterize *specific* function classes (Haar wavelets, piecewise-constant signals) that arise in practice. For associative recall, it departs from prior constructions (Arora et al. 2024a on gated convolution, Bietti et al. 2024 on 2-layer Transformers) by showing that a single Mamba layer with its convolution, SSM, and gating components can solve MQAR and induction heads with model size independent of sequence length. A key conceptual departure is demonstrating that the S4D mixer (lacking input selectivity) can still solve MQAR via the gated-convolution mechanism, reframing input selectivity as one of several complementary capabilities rather than the sole source of Mamba's advantage.

## Why It Matters / Open Questions

The paper provides the first mechanistic decomposition of how Mamba's architectural components (short convolution, SSM, gating) cooperate to solve concrete tasks, filling a gap where only lower bounds on SSM mixer size existed. The proposed Mamba-Δ^T variant (shifting input-dependent discretization from embedding to state dimension) is a concrete, testable architectural modification that empirically improves induction heads performance. Limitations are significant: the analysis covers only simple synthetic tasks (MQAR, induction heads, KEEP n-TH), ignores optimization and generalization, and the theoretical constructions (e.g., pushing Δ→∞ or Δ→0) may not be reachable in practice. Extending to k-hop induction heads, sequential function composition, and pointer value retrieval are natural next steps that would test whether these mechanistic insights generalize.

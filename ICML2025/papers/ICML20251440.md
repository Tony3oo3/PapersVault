## Problem

Existing KV cache quantization methods either apply uniform precision across all layers or require online fine-grained token-level decisions that are incompatible with flash attention and vLLM. They overlook the inherent layer-wise sensitivity of transformers to quantization, incur high online decision-making overhead, and lack flexibility to adapt to different LLMs and memory/accuracy constraints.
![Teaser figure](../imgs/ICML20251440/cropped_page0_idx0.webp)

## Input / Output

The method consumes KV cache tensors (key and value) from each transformer layer along with a pre-calibrated set of layer-wise precision pairs (e.g., K8V4, K4V2) determined offline. It produces a mixed-precision quantized KV cache where each layer group uses a distinct key/value bit-width combination, enabling equivalent precisions as low as 3.25-bit while maintaining near-lossless generation. The key design constraint is that all precision decisions are made offline and loaded directly at inference time, introducing zero online overhead and remaining compatible with static graph-based inference engines.

## Method

KVTuner formulates layer-wise KV precision pair selection as a discrete multi-objective optimization problem (minimizing memory usage and accuracy loss) solved offline via MOEA/D through Optuna. To make the combinatorial search tractable (reducing from 9^L to ~5^G combinations), it applies two-stage pruning: intra-layer Pareto frontier filtering removes non-optimal precision pairs per layer based on equivalent bits and attention output error, and inter-layer DBSCAN clustering groups layers with similar quantization sensitivity profiles. The calibration amplifies error accumulation by using dequantized KV cache during prefilling and employs challenging long-context mathematical reasoning prompts to distinguish precision configurations. A key theoretical insight is that key cache quantization errors cause attention distribution shifts in non-sparse retrieval heads, making key precision more critical than value precision, which the optimizer exploits by preferentially allocating higher bits to keys in sensitive layers.

## Results

KVTuner achieves nearly lossless 3.25-bit equivalent KV cache quantization for Llama-3.1-8B-Instruct (0.7925 avg GSM8K accuracy vs. 0.8033 for BF16) and 3.92-bit for the sensitive Qwen2.5-7B-Instruct (0.6160 avg vs. 0.7753 for BF16, while uniform KIVI-4 collapses to 0.1043). On GPQA Extended, KVTuner-C3.59 maintains 0.3162 average for Llama-3.1-8B-Instruct (vs. 0.3065 BF16). Maximum decoding throughput improves by 16.79%–21.25% over KIVI-KV8 across batch sizes 8–64 and input lengths 128–1024.

## Baselines & Comparisons

The primary baseline is KIVI (Liu et al., ICML 2024), compared at KV8, KV4, and KV2 uniform precisions. For Llama-3.1-8B-Instruct, KVTuner-C3.25 (KIVI mode) achieves 0.7925 average GSM8K accuracy at only 3.25-bit equivalent precision, matching KIVI-4 (0.8011) within 0.9% while using 19% less memory, and dramatically outperforming KIVI-2 (0.6327). For the highly sensitive Qwen2.5-7B-Instruct, uniform KIVI-4 collapses to 0.1043 accuracy, whereas KVTuner-C3.92 recovers 0.6160 — a 5.9× improvement — by allocating higher precision to sensitive layers. On throughput, KVTuner-C3.25 delivers 21.25% higher decoding throughput than KIVI-KV8 at batch size 64 / 128-token input (4652 vs. 3836 tokens/s). KVTuner also narrows the accuracy gap between the simpler per-token-asym mode and KIVI: for Qwen2.5-7B-Instruct, per-token-asym KV4 drops to 0.0078 while KVTuner-C4.00 (per-token-asym) reaches 0.7559, nearly matching KIVI-8 (0.7753).

## Relation to Prior Work

KVTuner extends the KV cache quantization line initiated by KIVI (asymmetric per-channel/per-token quantization) and KVQuant (mixed-precision with static prefix retention) by replacing their uniform or static precision assignments with an offline, layer-wise mixed-precision search. It departs from fine-grained online methods (QAQ, MiKV, ZipCache) that identify critical tokens at inference time, arguing that such approaches are incompatible with flash-attention and static-graph serving. The method repurposes multi-objective optimization (MOEA/D via Optuna) and DBSCAN clustering—tools from hyperparameter tuning and data mining—to navigate the combinatorial space of per-layer KV precision pairs, while grounding the search in a theoretical analysis (Lemma 1) linking attention sparsity to quantization robustness.

## Why It Matters / Open Questions

The practical impact is significant for LLM serving: achieving nearly lossless 3.25-bit KV quantization with 21.25% throughput gains over KIVI-KV8 is directly deployable in production inference stacks (vLLM, SGLang, Megatron). The finding that layer-wise sensitivity is an inherent, input-independent model property means a single offline calibration generalizes across workloads, removing the need for per-request precision decisions. Open questions include how KVTuner composes with other KV compression techniques (eviction, merging, offloading), whether the sensitivity patterns can be predicted from architecture alone without calibration, and whether the approach extends to multi-modal or speculative-decoding settings where KV cache dynamics differ.

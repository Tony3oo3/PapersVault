## Problem

Variational inequalities (VIs) provide a unifying framework for equilibrium and optimization problems across game theory, economics, and engineering, but even computing approximate VI solutions is PPAD-hard under minimal assumptions. Prior work has focused on restricting the class of VIs (e.g., via the Minty property) to recover tractability, leaving the broader class intractable. This paper asks whether relaxing the solution concept itself—requiring the VI constraint only in expectation over a distribution—yields a problem that is always efficiently solvable.

## Input / Output

The algorithm takes a convex compact set X ⊆ R^d specified implicitly via a polynomial-time membership oracle, a bounded operator F: X → R^d with ||F(x)|| ≤ B, the set of all linear endomorphisms Φ_LIN (matrices K ∈ R^{d×d} such that Kx ∈ X for all x ∈ X), and a precision parameter ε. It outputs a distribution μ over X with finite support of size poly(d, 1/ε) satisfying E_{x~μ}⟨F(x), φ(x) − x⟩ ≥ −ε for every φ ∈ Φ_LIN. Notably, X need not be an explicitly represented polytope for the main algorithm (Theorem 4.1); the more scalable regret-minimization variant (Theorem 4.3) requires X to be given by explicit linear inequalities.

## Method

The core algorithm adapts the Ellipsoid Against Hope (EAH) framework by formulating the EVI problem as an infeasible feasibility program: find a matrix K ∈ R^{d×d} such that ⟨F(x), Kx − x⟩ ≤ −ε for all x ∈ X and Kx ∈ X for all x ∈ X. This program is infeasible because every linear map has a fixed point in X (by Brouwer's theorem), making the left-hand side zero at that point. Running the ellipsoid method on this infeasible program produces a certificate of infeasibility, which is exactly an ε-approximate EVI solution. The critical technical ingredient is the SEPorGER oracle from Daskalakis et al. (2025), which for any candidate matrix K either returns a fixed point x = Kx in X (a good-enough-response) or a hyperplane separating K from Φ_LIN, thereby eliminating the need for a full separation oracle over the exponentially large set of linear endomorphisms. For explicitly represented polytopes, a more practical alternative uses the Gordon et al. (2008) regret-minimization template: a fixed-point oracle (implemented via linear programming) combined with projected gradient descent over a polynomial-size polytope representation of Φ_LIN (Theorem 4.3), yielding poly(d,m)/ε² rounds with convex quadratic programs per iteration.

## Results

The paper establishes that Φ-EVIs with linear endomorphisms (Φ_LIN) are solvable in poly(d, log(B/ε)) time via the Ellipsoid Against Hope (EAH) algorithm (Theorem 4.1), in stark contrast to general VIs which are PPAD-hard even for linear F and constant ε. A more scalable alternative using convex quadratic programming achieves poly(d, 1/ε) time (Theorem 4.3), improving per-iteration complexity over Daskalakis et al. (2025). Existence of ε-approximate solutions is guaranteed under mere measurability of F and L-Lipschitz continuity of Φ (Theorem 3.1), without requiring F to be continuous. For structured problems like quasar-concave optimization and polymatrix zero-sum games, EVIs essentially coincide with VIs (Propositions 6.1 and 6.3).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or datasets. The central comparison is between VIs and EVIs: general VIs are PPAD-hard (even for linear F and constant ε, via reduction from Nash equilibrium computation), while Φ_LIN-EVIs admit polynomial-time algorithms. The paper's EAH-based algorithm (Theorem 4.1) extends Papadimitriou & Roughgarden's (2008) correlated equilibrium computation to a much broader class of problems beyond games, and leverages the SEPorGER oracle framework of Daskalakis et al. (2025) to handle implicitly represented constraint sets. The regret-minimization algorithm (Theorem 4.3) improves on Daskalakis et al. (2025) by replacing per-iteration ellipsoid calls with convex quadratic programs of O(d²+m²) variables. The paper also subsumes and generalizes results from Cai et al. (2024a) and Seref Ahunbay (2025) on nonconcave games, offering poly(d, log(1/ε)) complexity where prior work scales polynomially in 1/ε, and removing continuity assumptions on gradients.

## Relation to Prior Work

This paper introduces Expected Variational Inequalities (EVIs) as a principled relaxation of the classical VI problem, departing from the dominant strategy of restricting the operator class (monotonicity, Minty property, etc.) to instead relax the solution concept from a point to a distribution. The core algorithmic machinery builds directly on the Ellipsoid Against Hope (EAH) framework of Papadimitriou & Roughgarden (2008) for computing correlated equilibria, extended via the SEPorGER oracle of Daskalakis et al. (2025) to handle implicitly represented constraint sets, and on the no-regret learning template of Gordon et al. (2008) for scalable alternatives. Conceptually, EVIs subsume correlated equilibria, Φ-equilibria in concave games, and quasar-concave optimization, unifying previously disparate results under a single framework while extending the scope of EAH well beyond game theory.

## Why It Matters / Open Questions

The key contribution is a clean computational separation: while VIs are PPAD-hard even for linear operators, EVIs with linear deviations are solvable in poly(d, log(1/ε)) time, providing a tractable solution concept that is strictly tighter than correlated equilibria (ALCEs can have non-polyhedral solution sets). The paper also shows EVIs can admit approximate solutions when the underlying VI has none, and establishes a new theoretical link between smoothness and quasar-concavity. Major open questions include whether PPAD-hardness persists under decomposable (per-player) deviations at small ε (Remark 3.8), and whether EVIs unlock qualitatively new solutions in applications beyond games (e.g., traffic equilibrium, general equilibrium). The EAH-based algorithm is noted as impractical, and the regret-minimization alternative has worse poly(1/ε) scaling, leaving a gap between theoretical tractability and practical efficiency.

## Problem

Nearly all prior multi-objective RLHF methods rely on linear aggregation of per-objective rewards, which cannot express preferences that favor the worst-performing objective (e.g., max-min fairness). The only existing non-linear (p-norm) approach is reward-based and computationally expensive, requiring full retraining whenever aggregation parameters change. Additionally, the multi-group setting—where different user groups assign different importance weights to the same objectives—remains largely unaddressed in the multi-objective context.

## Input / Output

The method consumes per-objective preference feedback pairs (winning/losing responses for each of m objectives), a reference policy π_ref, and target set parameters (p, c, α) that define the fairness and satisfaction threshold for each group. In the online setting, it also learns the importance weights α from data via MLE based on which objective humans report as most discriminative. The output is a fine-tuned LLM policy (as a mixture of per-iteration policies) that minimizes the distance between its expected reward vector and the target set, with the practical version (Algorithm 5) being nearly training-free once per-objective optimal policies are pre-computed.

## Method

The core insight is to reformulate non-linear p-norm aggregation maximization as minimizing the Euclidean distance between the expected reward vector S(π) and a convex target set W_{p,c}^α in ℝ^m, inspired by Blackwell-approachability. At each iteration, the algorithm projects the running-average reward vector onto the target set to obtain a direction d, then solves a linear aggregation sub-problem (maximizing ⟨d, r⟩) using existing reward-free or reward-based sub-procedures (e.g., MOD or DPO-style losses). For multi-group problems, consensus is achieved by projecting onto the intersection of all groups' target sets, while malfare minimization aggregates per-group distances with a q-norm. Theoretically, the framework achieves sublinear regret (Õ(1/√T) for consensus, Õ(T^{-1/2q}) for malfare) in both offline and online settings, and the practical algorithm requires only 7 iterations of direction updates on top of pre-trained per-objective policies.

## Results

The primary metric is the Euclidean distance between the expected reward vector and the target set (smaller is better). For p=0.5, c=0.5 on the Harmless and Helpful objectives, MOPO achieves distances of 0.015–0.229 across all weight settings, substantially outperforming RS (0.078–1.153), MOD (0.079–1.137), and the direct non-linear aggregation baseline AR (0.555–1.526). At the balanced weight α=(0.5,0.5), MOPO reaches 0.015 versus 0.078 (RS), 0.103 (MOD), and 1.314 (AR). For the worst-case setting p=−∞, MOPO achieves a min-reward of 0.034 on Harmless+Helpful (vs. −0.135 for Max-Min RLHF) but is slightly behind on Harmless+Humor (1.097 vs. 1.146).

## Baselines & Comparisons

MOPO consistently outperforms all three single-group baselines (RS, MOD, AR) on the p=0.5, c=0.5 Harmless+Helpful setting, with the largest gap against AR (e.g., 0.015 vs. 1.314 at α=(0.5,0.5)), confirming that direct non-linear reward aggregation is unstable. Against RS and MOD (both linear-aggregation methods), MOPO wins at every weight setting in Table 2, though the margin over MOD narrows at α=(0.3,0.7) (0.051 vs. 0.079). On the p=0.5, c=1.3 Harmless+Humor setting (Table 3), MOPO and MOD are nearly tied (e.g., 0.720 vs. 0.723 at α=(0.5,0.5)), while both clearly beat RS and AR. For the worst-case p=−∞ comparison, MOPO beats Max-Min RLHF on Harmless+Helpful (min reward 0.034 vs. −0.135) but is slightly behind on Harmless+Humor (min 1.097 vs. 1.146), indicating comparable but not uniformly superior worst-case performance. In the multi-group setting (Tables 5–6), MOPO is more stable than the Max-Min RLHF variant, which shows large variance across weight settings (e.g., 0.208 to 1.342 in Table 5).

## Relation to Prior Work

This paper builds on the Blackwell-approachability framework from multi-objective competitive RL (Yu et al., 2021), adapting its projection-based distance-to-target-set formulation to the RLHF setting. It extends the training-free closed-form solution for linear aggregation from MOD (Shi et al., 2024) and the reward-free DPO loss (Rafailov et al., 2024) to handle general p-norm aggregation (p ≤ 1), which prior MORLHF methods (RS, MOD, MORLHF) cannot address. The key departure from the only prior non-linear work (PNB/Zhong et al., 2024) is replacing the computationally expensive reward-based retraining with a sequence of linear sub-problems, and further generalizing to a multi-group setting where each group has distinct objective weights and aggregation parameters—a combination not previously studied.

## Why It Matters / Open Questions

The projection-based decomposition provides a unified theoretical framework that subsumes linear aggregation, worst-case (max-min) alignment, and general p-norm fairness as special cases, with sublinear regret guarantees in both offline and online settings. The practical training-free algorithm (Algorithm 5) is appealing for deployment since it requires no retraining once per-objective optimal policies are available, and the multi-group extension opens a path toward pluralistic alignment without per-group fine-tuning. However, empirical validation is limited to a 7B model with only three objectives and seven iterations, and the multi-group experiments show mixed results (e.g., Max-Min RLHF outperforms MOPO at α=(0.5,0.5) in Table 5). Open questions include learning the aggregation parameter p from data, extending to token-level optimization, and whether the framework generalizes beyond the Bradley-Terry preference model.

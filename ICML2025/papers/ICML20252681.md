## Problem

In real-world crowdsourcing, most workers annotate only a few instances, producing a highly sparse label matrix that degrades label integration performance. The prior state-of-the-art method WSLC completes missing labels using only the correlation among workers on the same instance, entirely ignoring the correlation of labels annotated by the same workers across similar instances. This paper addresses that gap by exploiting both worker-level and instance-level label correlations.
![Teaser figure](../imgs/ICML20252681/cropped_page2_idx0.webp)

## Input / Output

The method takes a sparse crowdsourced dataset D = {(x_i, L_i)} where each instance x_i has M features and each worker's label l_ir is either a class label or -1 (missing), along with the full set of worker annotation records. It produces a completed label matrix D' in which every -1 entry is replaced by a predicted class, with the intermediate output being a Q-dimensional converged probability distribution P_ir* for each previously missing label. The completed matrix is then fed into downstream label integration algorithms (MV, DS, IWMV, GTIC, DEWSMV, MNLDP) to improve their integration accuracy.

## Method

LDPLC operates in three stages. First, it estimates pairwise worker similarity by learning a feature vector for each worker via weighted Pearson correlation between the label variable and each original feature variable, then computing cosine similarity between worker feature vectors. Second, it initializes a label distribution for each missing label using worker-similarity-weighted majority voting over the available labels on that instance. Third, it performs iterative label distribution propagation: for each instance, K neighbors are queried via the HEOM metric, neighbor weights are optimized by solving a local linear embedding (LLE) least-squares problem, and each missing label's distribution is updated by averaging its current distribution with the weighted sum of its neighbors' distributions (Eq. 13). Convergence is guaranteed because the spectral radius of the propagation matrix W/2 is strictly less than 1, and the final label is assigned by argmax over the converged distribution.

## Results

On 34 simulated datasets (uniform annotation quality), LDPLC improves mean integration accuracy by approximately 9 percentage points over WSLC across all six label integration algorithms: MV (74.56%→83.51%), DS (74.08%→83.57%), IWMV (74.57%→83.54%), GTIC (74.43%→83.45%), DEWSMV (74.55%→83.54%), and MNLDP (76.80%→83.99%). On the real-world LabelMe dataset, LDPLC yields similar gains (e.g., MV 76.40%→81.60%, MNLDP 80.50%→82.50%). Statistical significance is confirmed via paired t-tests: LDPLC significantly outperforms WSLC on 30/34 datasets for five algorithms and 27/34 for MNLDP, with at most one significant loss.

## Baselines & Comparisons

Against WSLC (the primary baseline), LDPLC achieves a consistent ~9-point average improvement in integration accuracy across all six label integration algorithms on 34 simulated datasets, winning significantly on 30/34 datasets for MV, DS, IWMV, GTIC, and DEWSMV, and on 27/34 for MNLDP (with only 1 significant loss). On the real-world LabelMe dataset, the improvement is ~5 points (e.g., MV 76.40%→81.60%). Against PMF on 18 binary datasets, LDPLC dramatically outperforms it (mean MV accuracy 82.31% vs. 63.59%), winning on 17/18 datasets. Against PMF-TLC, LDPLC still leads on MV (82.31% vs. 76.41%, 17/18 wins) and most other algorithms, though MNLDP shows a mixed result (1 win, 11 ties, 6 losses), suggesting PMF-TLC's margin-based filtering can occasionally match LDPLC for that specific integration method.

## Relation to Prior Work

This paper extends WSLC (Wu et al., 2024), which completes missing labels in sparse crowdsourced matrices using worker similarity weighted majority voting. The key conceptual departure is adding an instance-level propagation dimension: while WSLC only exploits the correlation of labels annotated by different workers on the same instance, LDPLC additionally propagates label distributions across similar instances using LLE-weighted neighbors, drawing on the label propagation paradigm from MNLDP (Jiang et al., 2022). The initialization step directly reuses WSLC's worker similarity mechanism (Pearson-correlation-based feature vectors + cosine similarity), while the propagation step introduces a new spatial component absent from prior label completion work. The method is positioned as a preprocessing step that feeds into existing label integration algorithms (DS, IWMV, GTIC, DEWSMV, MNLDP) rather than replacing them.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in real-world crowdsourcing where sparse annotation (mean annotation ratio ~4-12%) degrades all downstream label integration algorithms. The consistent ~9-10 percentage point improvement over WSLC across 34 simulated and 3 real-world datasets, validated with paired t-tests, makes LDPLC a drop-in preprocessing upgrade for existing crowdsourcing pipelines. The main limitation acknowledged is that high-noise scenarios produce inaccurate initial label distributions that then propagate errors, leaving open the question of how to make the propagation robust to low-quality annotations. The convergence proof (spectral radius argument) is straightforward but provides useful theoretical grounding for the iterative scheme.

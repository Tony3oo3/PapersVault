## Problem

LLMs generating code from natural language prompts exhibit an attention dilution phenomenon: as more code tokens are produced, the model's self-attention to the user prompt progressively decreases, causing the generated code to drift from user intent. While various prompting strategies (self-debugging, self-planning, ReAct) have been proposed to improve code generation, none explicitly address this underlying attention misalignment, and the root cause of LLM code generation failures remained poorly understood.

## Input / Output

SPA takes a user prompt (comprising natural language description, optional source code, and optional test cases) along with a user-specified 'anchored text'—a subset of prompt tokens whose influence should be amplified. It produces augmented logits at each decoding step, which are then fed into a standard sampling algorithm (greedy or beam search) to select the next token. The method requires access to the model's mask embedding (e.g., <unk> or <pad>) and optionally uses test case pass/fail signals to decide when to activate the augmentation, reducing overhead for models that already succeed on the first attempt.

## Method

SPA decomposes the input embedding matrix into two components: X (embeddings of the anchored text) and G_i (all remaining embeddings), then performs two forward passes—one with the original embeddings and one with the anchored text replaced by mask embeddings. Using a first-order Taylor expansion of the logit function with respect to an anchoring strength parameter ω, the augmented logits are computed as a simple linear combination: ω·f_θ(E_i) + (1−ω)·f_θ(E_i^mask), where ω > 1 amplifies the anchored text's semantic impact. This logit-arithmetic approach simulates attention steering without modifying internal self-attention layers, making it model-agnostic, training-free, and requiring only a single tunable hyperparameter. The method is activated selectively (when test cases fail) or continuously (when no test cases exist), adding only ~27% inference overhead on average.

## Results

SPA consistently improves Pass@1 across all 6 code LLMs (350M–33B) and 6 benchmarks, achieving up to 12.9% absolute improvement (42% relative) on HumanEval/MBPP+ and an average 5.5% absolute / 14.5% relative gain on those benchmarks. On harder benchmarks (BigCodeBench, LiveCodeBench), absolute gains are more modest (1.57% and 1.90% average) but relative gains remain significant (22.83% and 28.50%). Notably, with SPA the smaller DeepSeek-Coder (6.7B) outperforms its 33B counterpart on HumanEval (88.5% vs 86.2%). SPA also generalizes to non-code tasks, improving TruthfulQA truthfulness by +3.1% and GSM8K by +1.1% on Llama-3.1-8B.

## Baselines & Comparisons

SPA outperforms all five baselines on both accuracy and efficiency. Against PASTA (the only other attention-steering method), SPA achieves 5.9× higher Pass@1 improvement (+7.7% vs +1.2%) while using only 20% of the inference time (9.8s vs 48.8s), since PASTA requires a model-specific profiling stage with ~1000 training samples per task. Against prompting-based methods, SPA beats Self-Debugging by 1.8× (+7.7% vs +4.2%), Self-Edit by 4.3× (+7.7% vs +1.8%), Self-Planning by 2.1× (+7.7% vs +3.6%), and ReAct by 5.9× (+7.7% vs +1.3%), while using only 34–45% of their inference time. The paper attributes SPA's superiority to two factors: (1) it preserves the original prompt without additional LLM calls, and (2) it directly addresses the attention dilution issue that prompting methods do not explicitly handle. SPA also outperforms PASTA across all five code benchmarks in Appendix L (e.g., +7.32% vs +1.22% on HumanEval), confirming consistent gains beyond the single-benchmark comparison.

## Relation to Prior Work

SPA carves new ground at the intersection of logit arithmetic (contrastive decoding) and attention steering, but departs from both in important ways. Unlike PASTA and TOAST, which directly edit self-attention heads and require model-specific profiling, SPA operates purely on final logits via a Taylor-expansion approximation of semantic scaling, making it model-agnostic. Unlike contrastive decoding methods (DOLa, Gera et al.) that contrast logits across layers or models, SPA contrasts logits from the same model under two inputs (original vs. masked anchored text), repurposing the logit-arithmetic toolkit for a new purpose: amplifying the influence of selected prompt tokens. The conceptual framing draws on the psychological anchoring effect, and the empirical motivation (attention dilution during autoregressive code generation) extends Chiang & Cholak's general transformer dilution analysis to the code-generation setting specifically.

## Why It Matters / Open Questions

SPA offers a training-free, model-agnostic mechanism with minimal overhead (1.27× inference time) that consistently improves code generation across six models and six benchmarks, and the finding that a 6.7B model with SPA outperforms a 33B model without it suggests attention optimization is a viable alternative to pure scaling. Open questions include how to dynamically select anchored text and anchoring strength per decoding step, whether SPA integrates well into self-improving pipelines for complex tasks, and how to extend it to generative tasks with shorter outputs where attention dilution is less severe. A notable limitation is that optimal activation relies on test-case feedback, though the paper shows SPA still helps without them.

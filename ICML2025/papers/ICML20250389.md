## Problem

When merging multiple task-specific expert models into a single unified model, parameter interference between constituent models causes significant performance degradation on individual tasks. Existing data-free merging methods (Task Arithmetic, Ties-Merging, DARE) avoid the need for test data or extra storage but still exhibit a notable performance gap compared to test-time adaptation approaches like AdaMerging. The paper tackles the question of how to resolve this interference in a purely data-free setting—without additional data, extra storage, or rescaling coefficients—while closing the gap to test-time adaptation methods.

## Input / Output

The method takes a pretrained model's weights and the weights of one or more expert models fine-tuned from it, computing task vectors as the element-wise difference between each expert and the pretrained model. It operates exclusively on the linear layers of the architecture (ViT, RoBERTa, Llama2, Flan-T5, Qwen), optimizing the merged task vector layer by layer with Adam (lr=1e-5, 300 iterations) before adding the result back to the pretrained weights. The output is a single merged multi-task model that requires no rescaling coefficient (optimal at ε≈1) and no auxiliary parameters at inference time, with total GPU memory of ~3–4 GB and solving time under 9 minutes even for ViT-L/14.

## Method

The key theoretical insight is that, under small learning rates and limited fine-tuning steps, the input to a linear layer remains highly consistent across iterations (Lemma 1), so each neuron's task vector is an approximate weighted sum of the layer's inputs (Proposition 1)—i.e., the task vector spans an approximate linear subspace of the input space. This allows the input to be reconstructed from the task vector, which in turn yields an upper bound on the interference (the expected squared deviation between merged and expert outputs) expressed purely in terms of the interference vector's action on the task vector (Theorem 1). WUDI-Merging then minimizes this bound layer by layer via gradient descent on the merged task vector, with each task's loss weighted by the inverse squared Frobenius norm of its task vector to balance contributions across experts of different scales. By using Adam's implicit regularization instead of an explicit ridge term, the method eliminates the need to tune a regularization coefficient, and the layer-wise sequential optimization keeps computational cost low.

## Results

On the 8-task vision benchmark with ViT-B/32, WUDI-Merging achieves 85.2% average accuracy, surpassing the best data-free method PCB-Merging (76.3%) by 8.9% and the best test-time adaptation method AdaMerging++ (81.1%) by 4.1%. On ViT-L/14, it reaches 92.6% average accuracy, exceeding PCB-Merging by 5.1% and AdaMerging++ by 1.6%. For discriminative language tasks (GLUE), WUDI-Merging achieves 85.3% normalized score on RoBERTa-Base and 88.8% on RoBERTa-Large, outperforming Ties-Merging by 19.7% and 16.0% respectively. On generative tasks (Llama2-13B), it attains 91.5% average normalized score, a 4.3% improvement over TIES-Merging with DARE.

## Baselines & Comparisons

WUDI-Merging decisively outperforms all data-free baselines on the ViT-B/32 vision benchmark: it beats PCB-Merging (76.3%) by 8.9%, Consensus Merging (73.6%) by 11.6%, Ties-Merging (72.4%) by 12.8%, Task Arithmetic (69.1%) by 16.1%, Fisher Merging (68.3%) by 16.9%, and Weight Averaging (65.8%) by 19.4%. It also surpasses all test-time adaptation methods that require unlabeled test data: AdaMerging++ (81.1%) by 4.1%, Representation Surgery (80.9%) by 4.3%, and AdaMerging (80.1%) by 5.1%. On the GLUE language benchmark, the advantage over Ties-Merging is even more pronounced at 19.7% (RoBERTa-Base) and 16.0% (RoBERTa-Large), though a gap remains versus individual expert models (100%). On generative LLM tasks, WUDI-Merging leads TIES-Merging(w/DARE) by 4.3% in average normalized score, though it underperforms on code tasks (HumanEval 58.3 vs. 80.0) due to conflicts between math and code tasks. The method requires only ~2 minutes and 3 GB GPU memory for ViT-B/32, compared to 127 minutes and 17.1 GB for AdaMerging.

## Relation to Prior Work

This paper builds directly on the task vector formulation from Task Arithmetic (Ilharco et al., 2023) and the interference analysis from Jin et al. (2023) and Xiong et al. (2024), but introduces a key theoretical departure: proving that task vectors of linear layers constitute an approximate linear subspace of their corresponding inputs under standard fine-tuning conditions. This insight allows the authors to reconstruct input information implicitly from task vectors alone, enabling a data-free optimization objective that prior methods (Ties-Merging, DARE, Consensus Merging) could not formulate. The method is positioned as a principled alternative to both heuristic data-free merging and test-time adaptation approaches (AdaMerging, Surgery) that require unlabeled test data.

## Why It Matters / Open Questions

WUDI-Merging offers a practically attractive solution: it requires no additional data, no extra storage, no rescaling coefficient tuning, and only ~2 minutes of GPU time with 3–4 GB memory, while outperforming test-time adaptation methods that need access to unlabeled test samples. The main limitations are the reduced gains on LoRA-fine-tuned models (attributed to random initialization noise in task vectors) and persistent conflicts in code-generation tasks. An open question the authors highlight is whether the remaining gap to supervised multi-task learning (4.7% on ViT-B/32) can be closed by addressing input-domain overlap, particularly in language tasks where domain overlap is larger.

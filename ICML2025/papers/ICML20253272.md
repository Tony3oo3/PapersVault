## Problem

Despite impressive scaling results, the ML community lacks a systematic understanding of what algorithms LLMs actually learn and use to solve problems. Existing interpretability work focuses on isolated low-level circuits without clear algorithmic hypotheses, and theoretical work on LLM algorithmic capacities is nearly absent. This paper argues that the field should prioritize algorithmic-level understanding (per Marr's framework) over both pure scaling and hypothesis-free circuit analysis.

## Input / Output

The case study feeds a natural-language prompt describing a two-step tree graph (rooms as nodes, connections as edges) with a specified start node ('lobby') and goal node (e.g., 'W') to Llama-3.1-8B/70B, which outputs a single yes/no token indicating path existence. The analysis then extracts per-layer attention matrices, token-level hidden-state vectors, and representational similarity matrices (CKA and Procrustes) across all 32 layers, producing attention heatmaps, t-SNE projections of node representations per layer, and a sequence of highest-similarity node pairs per layer that is compared against all BFS and DFS rollouts via edit distance.

## Method

AlgEval proposes a hypothesis-driven framework combining top-down algorithmic hypotheses (e.g., BFS, DFS, Dijkstra, amortized inference) with bottom-up circuit-level testing. In the case study, the authors (1) fit linear mixed-effects models on logit-transformed attention from the final token to correct vs. incorrect pathway nodes across layers, finding significantly more attention to the correct path in 14 of 32 layers; (2) compute layer-by-layer representational similarity matrices and extract the highest-similarity node pair per layer as a putative algorithmic step, then compare this sequence to all BFS/DFS rollouts via edit distance (mean correct-step proportion only 0.18–0.24, ruling out classical search); and (3) project node representations into 2D via t-SNE across layers, revealing progressive separation of the goal node from its closest competitor and a distinct trajectory for the 'lobby' anchor. The key finding is that LLMs use a policy-dependent, competition-driven strategy—incrementally attending to the correct path and progressively separating competing node representations—rather than constructing a full world model or performing exhaustive search.

## Results

In the case study on graph navigation with Llama-3.1-8B, the final token allocated significantly more attention to rooms on the correct pathway than the incorrect one (b=0.33, SE=0.07, t(2015)=4.51, p<.001), with 14 of 32 layers showing this effect versus only 3 layers favoring the incorrect path. Representational similarity between neighboring layers remained high (>0.95) from layers 4–32, indicating smooth rather than step-like geometric changes. When comparing the LLM's layer-by-layer hidden-state sequence to all possible BFS and DFS rollouts, the mean proportion of correct matching steps was only 0.18 (BFS) and 0.24 (DFS), indicating the model does not implement classical exhaustive search. The 70B model showed consistent patterns with more pronounced separation between correct and incorrect trajectories.

## Baselines & Comparisons

This is a position paper without traditional method-vs-baseline comparisons. The closest analog is the comparison between LLM internal computations and classical search algorithms (BFS, DFS, Dijkstra) as algorithmic hypotheses. The LLM's layer-by-layer hidden-state sequence poorly matches any full BFS or DFS trajectory (mean correct-step proportion: 0.18 and 0.24 respectively), and representational geometry changes smoothly across layers rather than in discrete search steps. The authors conclude the model uses a policy-dependent, competition-driven strategy—incrementally attending to the goal path via query-key attention and progressively separating the goal node from its closest competitor in representation space—rather than constructing a full world model or performing exhaustive search. Scaling from 8B to 70B parameters did not change the fundamental algorithmic strategy, only sharpening the representational separation.

## Relation to Prior Work

This position paper builds on the mechanistic interpretability tradition (circuit discovery, attention head analysis, activation patching) and the emerging line of work on algorithmic understanding in Transformers (induction heads, RASP, mesa-optimization), but argues that both remain too fragmented and bottom-up to yield a principled account of what algorithms LLMs actually execute. It departs from the hypothesis-free circuit analysis advocated by Olah (2023) by insisting on top-down algorithmic hypotheses tested against bottom-up evidence, and from the scaling-first paradigm (Sutton's Bitter Lesson) by proposing that understanding emergent algorithms is a more sustainable path than brute-force parameter growth. The case study draws on CogEval-style graph navigation tasks (Momennejad et al., 2023) and standard representational similarity and attention analysis tools (Kornblith et al., 2019; Abnar & Zuidema, 2020) to ground the framework in a concrete empirical example.

## Why It Matters / Open Questions

The paper's central argument—that the field is hitting diminishing returns from scaling while lacking any systematic account of the algorithms models actually implement—resonates with growing concerns about data exhaustion, compute costs, and regulatory transparency. The case study's finding that Llama-3.1 (both 8B and 70B) does not implement BFS or DFS for graph navigation, but instead exhibits a policy-dependent cascading attention pattern, is a concrete (if preliminary) data point suggesting that 'algorithmic understanding' may reveal strategies that are neither classical nor trivially scalable. Key open questions include whether the observed attention/representation patterns generalize beyond 2-step trees, whether RL training (e.g., GRPO in DeepSeek-R1) genuinely induces new algorithmic primitives or merely reweights memorized ones, and whether the proposed primitive-and-composition framework can be formalized with provable guarantees. The framework's practical payoff—sample-efficient training, algorithm-centric architecture design, and principled multi-agent system construction—remains speculative until validated on richer task suites.

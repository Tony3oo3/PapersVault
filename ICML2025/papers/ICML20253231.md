## Problem

LiDAR reflectance compression remains underexplored in neural compression methods, which predominantly target geometry or RGB color attributes. Two intrinsic challenges limit existing approaches: the inherent sparsity of LiDAR scans forces expensive large-kernel 3D convolutions, and the physics of reflectance (material properties, incidence angles, sensor distance) creates correlations that extend beyond simple spatial proximity, which current methods neglect by relying on 3D geometric neighborhood definitions.

## Input / Output

The method takes a LiDAR point cloud frame with reflectance intensities (7-bit for KITTI, 8-bit for Ford/nuScenes) and 3D geometry coordinates (18-bit for KITTI, 16-bit for InnovizQC), and produces a lossless compressed reflectance bitstream via arithmetic coding. The input is first serialized into L one-dimensional sequences (one per laser beam) ordered by azimuth angle, with each point augmented by derived LiDAR information (laser index, azimuth index, radial distance) computed from the geometry. The output is a per-point probability mass function consumed by an arithmetic coder, yielding bits-per-point (BPP) as the compression metric.

## Method

SerLiC introduces scan-order serialization that reorganizes 3D LiDAR points into 1D sequences following the physical laser scanning order, replacing expensive 3D spatial operations with a device-centric sequential representation. Each point is tokenized into a contextual vector comprising its scanning index (laser + azimuth embeddings), normalized radial distance, and the previously decoded reflectance value, capturing both physical and sequential dependencies. A Mamba-based selective state space model performs autoregressive coding within each sequence window, predicting the conditional PMF of the target reflectance given all preceding context. A dual parallelization scheme accelerates processing by running all L sequences in parallel (justified by weak inter-sequence dependencies) and partitioning each sequence into fixed-size windows (default 128) for intra-sequence parallelism. Training minimizes the negative log-likelihood of observed reflectance values across all sequences using AdamW with cosine annealing over 25 epochs, with the full model using 2.2M parameters and a light variant using only 111K parameters.

## Results

SerLiC achieves an average of 3.64 BPP on KITTI, 3.84 BPP on Ford, and 2.52 BPP on nuScenes, representing over 2× volume reduction against the original 7–8 bit reflectance data. Compared to the state-of-the-art Unicorn method, SerLiC reduces compressed bits by 17.08% (KITTI) and 22.74% (Ford) while using only 2% of its parameters (2.2M vs. 111.5M) and 10% of its GPU memory (0.41 GB vs. 4.36 GB). The lightweight SerLiC (light) variant with just 111K parameters achieves >10 fps without frame pipelining and >30 fps with pipelining, at a cost of only 6.67% additional BPP on KITTI.

## Baselines & Comparisons

Against G-PCC (RAHT), the MPEG standard anchor, SerLiC achieves 25.41% (KITTI), 25.58% (Ford), and 29.81% (nuScenes) bit-rate reduction, with per-sequence gains ranging from 20.61% to 34.59%. Against G-PCC (Predlift), SerLiC similarly dominates with 24.01%, 23.81%, and 22.22% average reductions. Against Unicorn, the strongest learning-based baseline, SerLiC reduces bits by 17.08% on KITTI and 22.74% on Ford while using only 2% of Unicorn's parameters (2.2M vs. 111.5M) and 10% of its GPU memory (0.41 GB vs. 4.36 GB); Unicorn is not evaluated on nuScenes. Against L3C2, the MPEG LiDAR-specific profile, SerLiC achieves a 21.63% bit-rate reduction on Ford (the only dataset where L3C2 can operate, as it requires detailed sensor calibration parameters unavailable for KITTI and nuScenes). SerLiC also demonstrates strong generalization to the non-rotational InnovizQC dataset, achieving 39.71% reduction over G-PCC (RAHT), confirming robustness beyond rotational LiDAR systems.

## Relation to Prior Work

SerLiC departs from the dominant 3D spatial-proximity paradigm in point cloud attribute compression (G-PCC, Unicorn, PoLoPCAC) by reframing LiDAR reflectance as a 1D sequential problem aligned with the sensor's scanning mechanism. It builds on the serialization-based analysis lineage (OctFormer, FlatFormer, Point Transformer v3) but replaces conventional space-filling curves (Morton, Hilbert) with a LiDAR scan-order serialization that preserves device-centric structure. The autoregressive coding backbone draws on Mamba/SSM work in point cloud analysis (PointMamba, Voxel Mamba, MambaMOS), but is the first to combine scan-order serialization, physics-informed tokenization (scanning index, radial distance, prior reflectance), and dual parallelization specifically for lossless LiDAR reflectance entropy coding.

## Why It Matters / Open Questions

LiDAR reflectance is critical for downstream perception (pedestrian detection AP drops from 51.4 to 14.1 without it), yet prior neural compressors focused on geometry or RGB color, leaving reflectance compression to rule-based methods with limited efficiency. SerLiC's extreme efficiency (2% of Unicorn's parameters, 10% of its GPU memory, 30 fps real-time with pipelining) makes neural reflectance compression practical for edge-deployed autonomous driving and VR/AR systems that cannot afford Minkowski Engine or large 3D convolutions. Open questions include extending to lossy compression for higher ratios, generalizing to non-rotational and solid-state LiDAR with different scanning geometries, and whether the scan-order serialization advantage persists when reflectance is combined with other attributes in a joint codec.

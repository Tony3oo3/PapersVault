## Problem

Existing prompt-based generative model selection relies on averaged evaluation scores (e.g., mean CLIPScore) to pick a single best model, ignoring that different models can outperform each other on different prompt categories. This paper identifies and formalizes the gap where model rankings vary across prompt types, and asks whether an online learning algorithm can adaptively assign each incoming prompt to the best-performing model without prior knowledge of the prompt-to-model mapping.

## Input / Output

At each iteration, the algorithm receives a text prompt embedded as a d-dimensional unit-norm vector (CLIP-ViT-B-32 for T2I, RoBERTa or CodeBERT 768-d embeddings for LLM tasks) and a fixed set of G candidate generative models. It outputs a model index, which is then queried to produce a sample (image, video, or text response); the sample is scored by a task-specific function (CLIPScore for T2I/T2V, binary pass/fail for code generation, correctness for Sudoku). A key structural constraint is that the same prompt vector serves as context for all arms simultaneously, unlike standard contextual bandits where each arm observes its own context.

## Method

PAK-UCB formulates prompt-based model selection as a contextual bandit with shared context across arms, where each arm (generative model) maintains its own kernel ridge regression function to predict the expected score for an incoming prompt. At each iteration, the algorithm computes a per-arm KRR mean and uncertainty using only the prompt-score pairs collected from past iterations where that specific model was selected, then picks the model maximizing the UCB score (mean + η·uncertainty). This per-arm design is essential because standard kernelized CB (e.g., KernelUCB) learns a single shared weight vector across all arms, which cannot capture the varying prompt-to-model performance landscape. To address the cubic O(t³) per-iteration cost of exact KRR, RFF-UCB replaces the RBF kernel with random Fourier features, fixing the Gram matrix size to 2D and reducing computation to O(tD²) time and O(tD) space while preserving the same Õ(√(GT)) regret bound. A Sup-PAK-UCB variant with a logarithmic-stage doubling scheme resolves the statistical dependency in the regret analysis, yielding the formal bound under a realizability assumption in an RKHS.

## Results

The paper evaluates PAK-UCB and RFF-UCB using two metrics: Outscore-the-best (OtB, the gap between the algorithm's CLIPScore and the best single-model average) and Optimal-pick-ratio (OPR, the fraction of prompts where the algorithm selects the true best model). In the LLM code-generation setup, Gemini-2.5-Flash-preview achieves 55.91% pass@1 on code completion vs. Qwen-Plus's 13.84%, but drops to 24.39% on C++-to-Java translation vs. Qwen-Plus's 40.91%; RFF-UCB-RBF learns to route each task type to the superior model. In the T2I setup, Stable Diffusion v1.5 scores 36.10 vs. 35.68 CLIPScore on 'car' prompts but 36.37 vs. 37.24 on 'dog' prompts, and PAK-UCB-poly3 converges to the per-prompt optimal model, outperforming the one-arm oracle that always selects the highest-averaged model. The RFF-UCB variant reduces per-iteration cost from O(t³) to O(t) while maintaining the same Õ(√(GT)) regret bound.

## Baselines & Comparisons

The paper compares PAK-UCB and RFF-UCB against two shared-weight contextual bandit baselines: KernelUCB (Valko et al., 2013) and LinUCB (Chu et al., 2011), both of which learn a single reward function across all arms. PAK-UCB consistently outperforms both on OPR and OtB across all T2I and LLM setups, because the per-arm kernel functions capture the prompt-dependent ranking inversions that a shared weight vector cannot represent. Additionally, PAK-UCB surpasses the One-arm Oracle (which always selects the model with the highest average score over the prompt distribution), demonstrating that prompt-level selection can beat even a selector with full knowledge of the single best model on average. The RFF-UCB variant matches PAK-UCB's selection quality while reducing per-iteration time from O(t³/G²) to O(tD²) and space from O(t²/G) to O(tD), making it practical for long-horizon online deployment. In the LLM Sudoku setup, RFF-UCB-RBF outperforms all baselines including Naive-KRR (PAK-UCB without exploration, η=0), confirming the importance of the UCB exploration bonus.

## Relation to Prior Work

This paper extends the kernelized contextual bandit framework (Valko et al., 2013) and the UCB optimism principle (Chu et al., 2011) by replacing the standard shared-weight formulation with per-arm kernel ridge regression functions, motivated by the observation that the same text prompt is shared across all candidate models while each model exhibits different performance. It also incorporates Random Fourier Features (Rahimi & Recht, 2007) to reduce the cubic per-iteration cost of kernel ridge regression to linear, yielding the RFF-UCB variant. The work departs from prior MAB-based generative model selection (Hu et al., 2025a; Rezaei et al., 2025), which handles unconditional models without input prompts, and from offline prompt-to-model assignment methods (Luo et al., 2024; Qin et al., 2024), by formulating the problem as an online, prompt-conditioned decision task.

## Why It Matters / Open Questions

As the ecosystem of available LLMs and text-to-image/video models grows, prompt-aware online selection offers a practical mechanism to route each query to the best-performing model without requiring exhaustive offline benchmarking, and the online nature allows adaptation to shifting prompt distributions and model updates. The paper identifies two natural extensions left open: incorporating diversity and novelty of generated samples into the selection criterion, and developing cost-aware variants that account for heterogeneous inference costs across models. A limitation is that the realizability assumption (scores linear in an RKHS) may not hold for all model-prompt interactions, and experiments involve only 2–4 candidate models per setup.

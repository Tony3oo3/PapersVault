## Problem

Current multimodal LLMs lack multi-hop selective attention for structured image understanding: they extract information from tables and charts into text and then reason purely linguistically, never looking back at the image. This limits their ability to perform the iterative visual refocusing—shifting attention across rows, columns, bars, and subplots—that human readers naturally use to solve multi-step questions over structured figures.
![Teaser figure](../imgs/ICML20250684/cropped_page1_idx0.webp)

## Input / Output

The method takes a structured image (table or chart) paired with a text question, along with pre-computed coordinate metadata (row/column bounding boxes for tables via OpenCV contour detection, or x/y-axis value coordinates for charts). The pipeline is iterative: at each step the model produces a thought, optionally generates Python code calling an editing tool, and receives the modified image as new visual input until it emits a final answer. For the SFT variant, training inputs follow the format '<image> <question> <thought1> <refocus bounding box> <thought2> <answer>', and the model outputs text-formatted bounding box coordinates for focus regions alongside its reasoning.

## Method

REFOCUS equips a multimodal LLM (GPT-4o) with a set of Python-based visual editing tools—mask out, draw box, and highlight color—applied to rows/columns (tables) or bars/subplots (charts). The LLM is prompted to generate pseudocode calling these tools; the code is executed, the edited image is fed back, and the loop repeats until the model produces an answer. The key insight is that these edits improve visual grounding and OCR accuracy through selective attention and eliminate hallucinations, without introducing any external information. The paper further collects a 14k visual chain-of-thought (VCoT) training set by running REFOCUS + GPT-4o over ChartQA, and shows that SFT on this VCoT data (which includes refocus bounding boxes) yields an 8.0% average gain over the same model trained on standard QA pairs and 2.6% over CoT data, using Phi-3.5-vision as the base model.

## Results

REFOCUS + GPT-4o (2024-05-13) achieves an average accuracy gain of 11.0% on table tasks (VWTQ: 76.9 vs. 66.5; VWTQ_syn: 79.6 vs. 73.2; VTabFact: 89.6 vs. 89.6) and 6.8% on chart tasks (CharXiv: 57.3 vs. 49.0; Horizontal Bar: 85.4 vs. 78.2; Vertical Bar: 81.0 vs. 76.2) over vanilla GPT-4o. The second checkpoint (2024-08-06) shows similar gains, with the largest single-task improvement being +12.4% on VWTQ_syn (82.8 vs. 70.4). In the SFT setting, Phi-3.5-vision finetuned on REFOCUS VCoT data reaches 71.4% average accuracy on ChartQA, outperforming the same model trained on QA pairs (62.6%) by 8.0% and on CoT data (68.8%) by 2.6%.

## Baselines & Comparisons

REFOCUS consistently outperforms vanilla GPT-4o (both checkpoints) on 5 out of 6 tasks, with the only exception being CharXiv for the 08-06 checkpoint (46.2 vs. 48.9, a −2.7 drop). Against the strongest prior multimodal LLMs, REFOCUS + GPT-4o (05-13) leads by large margins: +40.5 over LLaVA-NeXT-34B on VWTQ, +36.7 over Phi-3 Vision on VWTQ, and +27.1 over Gemini-Pro 1.5 on CharXiv. Compared to VisProg (modified with GPT-4o), REFOCUS gains +23.7 on VWTQ, +17.6 on VWTQ_syn, +10.5 on CharXiv, +15.6 on Horizontal Bar, and +12.4 on Vertical Bar, while matching on VTabFact (89.6 vs. 76.4). In the SFT comparison, REFOCUS VCoT data (71.4% avg) beats standard QA data (62.6%) by 8.0% and CoT data (68.8%) by 2.6% on ChartQA, and exceeds the Visual CoT baseline (20.8% avg) by 50.6%, demonstrating that visual editing as intermediate supervision provides a substantially stronger training signal than text-only reasoning traces.

## Relation to Prior Work

REFOCUS sits at the intersection of program-aided visual reasoning (VisProg, VIP-GPT) and visual prompting (Set-of-Mark, Visual Sketchpad), but departs from both in a key way: instead of invoking external vision tools (SAM, DINO, Depth Anything) that inject new information, it uses only simple geometric edits—masking, drawing boxes, highlighting—on the input image itself. Unlike Visual Sketchpad, which targets natural images and benefits from tool-derived expert knowledge, REFOCUS is designed for text-rich structured images (tables, charts) where the bottleneck is selective attention rather than missing visual features. The iterative, multi-step editing loop also distinguishes it from single-shot visual CoT methods (Shao et al., 2024) that map a region directly to an answer without sequential refocusing.

## Why It Matters / Open Questions

The core practical takeaway is that a 14k visual chain-of-thought (VCoT) dataset, where intermediate steps include bounding-box coordinates for focus areas, provides measurably better SFT supervision than standard QA pairs (+8.0%) or text-only CoT (+2.6%), suggesting that spatial grounding signals in training data matter for structured image understanding. A notable limitation is that the prompting pipeline still depends on GPT-4o for edit decisions, and the distillation experiments are confined to Phi-3.5-vision on ChartQA; whether the VCoT supervision advantage generalizes to other architectures, natural-image tasks, or larger models remains open. The CharXiv result for the newer GPT-4o checkpoint (−2.7%) also hints that gains are not uniform across all structured-image subtasks.

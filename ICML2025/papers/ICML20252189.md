## Problem

The exact minimum width enabling universal approximation of L^p functions was previously known only for RELU and its close variants (e.g., leaky-RELU, GELU, SOFTPLUS). For general activation functions, the best upper bound was max{d_x+2, d_y+1}, leaving a gap of at least 1 from the lower bound max{d_x, d_y}. This paper closes that gap by identifying a broad class of activation functions—called squashable—for which the exact minimum width is characterized.

## Input / Output

The network takes a d_x-dimensional input vector from the compact domain [0,1]^{d_x} and produces a d_y-dimensional output vector in R^{d_y}, with approximation measured in the L^p norm for p ≥ 1. The width of the network is defined as the maximum hidden-layer dimension across all layers, and the result is that the minimum such width equals max{d_x, d_y, 2} (with a special case w ∈ {1,2} when d_x = d_y = 1, resolved to w = 2 for monotone activations). The depth is unbounded, and the network uses a single activation function σ applied element-wise at each hidden layer.

## Method

The paper introduces the notion of a 'squashable' activation function: one that can approximate both the identity function (via affine compositions, Condition 1) and the binary step function STEP (via a width-1 network that is strictly increasing and maps into [0,1], Condition 2). Using squashability, the authors construct an encoder-decoder architecture following the coding scheme of Park et al. (2021b): the decoder is a δ-filling curve of [0,1]^{d_y} implemented as a (σ, identity) network of width d_y, built inductively by adding one dimension at a time using STEP-approximating subnetworks; the encoder maps each cell of a fine partition of [0,1]^{d_x} to a small ball around a chosen center, using a width max{d_x, 2} network that recursively reduces grid dimensions while preserving disjointness. The key technical insight is that squashability replaces the specific shape properties of RELU (e.g., piecewise linearity, exact zero region) with the more general ability to approximate STEP and identity, enabling the same encoder-decoder construction for all non-affine analytic functions (sigmoid, tanh, sin, exp, polynomials) and a class of piecewise C^1 functions (leaky-RELU, HARDSWISH). The lower bound w ≥ max{d_x, d_y} is inherited from Kim et al. (2024), and the upper bound is achieved by showing that (σ, identity) networks can be replaced by pure σ networks on compact domains (Lemma 8).

## Results

The main result (Theorem 2) establishes that for any squashable activation function σ, the exact minimum width for universal approximation of L^p([0,1]^{d_x}, R^{d_y}) is w_min = max{d_x, d_y, 2} when d_x ≥ 2 or d_y ≥ 2, and w_min = 2 when d_x = d_y = 1 and σ is monotone. This closes the gap between prior lower bounds (w_min ≥ max{d_x, d_y}) and upper bounds (w_min ≤ max{d_x+2, d_y+1} for continuous non-polynomial σ) for a broad class of activation functions including all non-affine analytic functions (SIGMOID, tanh, sin, exp, polynomials) and piecewise C^1 functions (leaky-RELU, HARDSWISH). The result extends the previously known exact minimum width (established only for RELU and its variants) to this general class.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; comparisons are between tightness of width bounds. Prior to this work, the exact minimum width was known only for RELU and its variants (Park et al. 2021b, Cai 2023, Kim et al. 2024), all yielding w_min = max{d_x, d_y, 2} or max{d_x+1, d_y}. For general continuous non-polynomial activations, the best prior upper bound was w_min ≤ max{d_x+2, d_y+1} (Park et al. 2021b) or w_min ≤ d_x+d_y+1 (Kidger & Lyons 2020), leaving a gap of at least 1–2 neurons above the lower bound. This paper closes that gap entirely for all squashable activations, matching the exact RELU-family bound. The key improvement is methodological: rather than relying on RELU-specific properties (discontinuity, piecewise linearity), the proof uses the squashability condition (approximability of identity and STEP via compositions of σ with affine maps), which is satisfied by all non-affine analytic functions and a class of piecewise C^1 functions.

## Relation to Prior Work

This paper extends the line of work on exact minimum width for universal approximation, which was previously established only for RELU and its close variants (Park et al., 2021b; Cai, 2023; Kim et al., 2024). It builds on the encoder-decoder coding scheme of Park et al. (2021b) and the identity-approximation lemma of Kidger and Lyons (2020), but replaces RELU-specific constructions (relying on discontinuities and specific shapes) with a general 'squashability' abstraction that requires only the ability to approximate both the identity and STEP functions via compositions with affine maps. The lower bound is inherited from Kim et al. (2024), while the upper bound proof introduces new inductive filling-curve and grid-separation constructions that work for any squashable activation.

## Why It Matters / Open Questions

The result provides a clean, unified characterization of minimum width for nearly all practical activation functions (all non-affine analytic functions like sigmoid, tanh, sin, exp, polynomials, and piecewise functions like leaky-RELU and HARDSWISH), closing a gap where prior exact results were limited to a handful of RELU-like activations. The 'squashability' condition offers a practical, checkable criterion (via Lemmas 3–5) for determining whether a given activation falls within the covered class. Open questions include whether the bound extends to C([0,1]^d_x, R^d_y) approximation (as opposed to L^p), whether the d_x = d_y = 1 non-monotone case can be fully resolved, and whether similar characterizations exist for memorization with general activations.

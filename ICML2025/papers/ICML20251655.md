## Problem

Autoregressive VLMs can execute many tasks from diverse specifications (text examples, image examples, instructions), yet it remains unclear whether these conceptually equivalent inputs converge to a shared internal representation. This paper asks whether VLMs align task information across modalities into a common task vector, and whether such a vector can be transferred from one modality to another to trigger correct generation.
![Teaser figure](../imgs/ICML20251655/cropped_page0_idx0.webp)

## Input / Output

The method consumes task specifications in three forms—N=5 text examples, N=5 image examples (224px), or a single text instruction—and applies them to image or text queries. The key output is a single task vector: one activation extracted at the delimiter token between the last query-answer pair at a chosen intermediate layer. This compressed vector, when patched into a query's forward pass, induces the correct task-specific answer without the model ever seeing the original specification, and it outperforms feeding the full uncompressed examples via few-shot prompting.

## Method

The paper introduces cross-modal patching: a task vector is extracted from a specification in one modality (e.g., text examples) via a forward pass, then injected at the corresponding layer and token position of a query in another modality (e.g., an image), forcing the model to apply the task without additional context. The task vector is identified at the delimiter token near the end of the sequence, where the representation has compressed the preceding context into a high-level task summary. The authors validate this via t-SNE clustering (task vectors group by task, not modality), logit-lens decoding (middle layers decode to task summaries like 'headquarters' or 'currency'), and three-phase analysis showing representations evolve from input encoding → task summary → answer across layers. They further demonstrate that task vectors transfer from a base LLM to its fine-tuned VLM with cosine similarity ≥0.89, can be derived from instructions alone, and can override pre-existing tasks in the prompt more effectively than system prompting.

## Results

On the best-performing model (Idefics2), cross-modal patching (Text Examples Patch) achieves 51% average accuracy across six tasks, substantially outperforming few-shot prompting with text examples (18%) and the strongest unimodal baseline, image examples prompting (43%). Across all three VLMs (LLaVA-v1.5, Mantis-Fuyu, Idefics2), patching improves over prompting by 14–33% and beats the best unimodal image-example baseline by 8–13%. Task vectors extracted from the base LLM transfer to the fine-tuned VLM with 0.89–0.95 cosine similarity and even match or slightly exceed VLM-only patching accuracy (e.g., 52% vs. 51% for Idefics2).

## Baselines & Comparisons

The primary baseline is few-shot prompting (Brown et al., 2020), where the full task specification (text or image examples) is fed jointly with the query to the VLM. Cross-modal patching (a single compressed task vector) consistently and substantially outperforms few-shot prompting across all three models: on Idefics2, patching achieves 51% vs. 18% for text-example prompting and 43% for image-example prompting; on Mantis-Fuyu, 31% vs. 9% and 18%; on LLaVA-v1.5, 32% vs. 18%. The paper attributes the prompting failure to the model 'regurgitating' or captioning the input rather than executing the demonstrated pattern, a problem that patching resolves by directly injecting the task representation. Notably, the compressed single-vector patch also beats the uncompressed full-context prompting, a result unique to the cross-modal setting. Additionally, the paper shows that task vectors from the base LLM (Vicuna, Mistral) transfer to the fine-tuned VLM with 0.89–0.95 cosine similarity and achieve comparable or slightly higher accuracy than VLM-derived vectors, indicating that fine-tuning largely preserves the task representation space.

## Relation to Prior Work

This paper extends the task vector framework from text-only LLMs (Hendel et al., 2023; Todd et al., 2024) to cross-modal VLMs, asking whether conceptually equivalent task specifications in different modalities (text examples, image examples, instructions) converge to a shared representation. It repurposes activation patching (Zhang & Nanda, 2023) as a diagnostic tool to measure cross-modal alignment, going beyond the text-only setting where prior work extracted and analyzed function vectors. The paper also connects to the broader mechanistic interpretability literature on in-context learning (induction heads, implicit Bayesian inference) and to VLM architecture research (early-fusion vs. late-fusion), showing the cross-modal task vector property emerges in both paradigms.

## Why It Matters / Open Questions

The finding that a single compressed task vector outperforms full few-shot prompting with the complete task information is a counterintuitive result with practical implications for prompt compression and efficient inference (11× runtime reduction). The LLM-to-VLM transfer result suggests that fine-tuning a VLM largely preserves the base LLM's task representations, opening the door to reusing language-only task knowledge for multimodal queries. However, the evaluation is limited to relatively simple, well-defined tasks (country-capital, food-color, etc.) with modest absolute accuracy, and the paper lacks a definitive explanation for why cross-modal convergence occurs—whether it reflects Platonic representational structure, training dynamics, or architectural inductive bias remains an open question.

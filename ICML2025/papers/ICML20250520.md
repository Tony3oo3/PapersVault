## Problem

Prior work on list-decodable linear regression with batches (Das et al., 2023) required batch size n = Ω(1/α) and achieved error O(σ/√(nα)) with a suboptimal list size of O(1/α²). The paper asks whether significantly smaller batch sizes and better error guarantees are achievable, and answers affirmatively by exploiting higher-order moment structure of the covariates through the Sum-of-Squares (SoS) framework.

## Input / Output

The algorithm consumes m = poly((dn)^(1/δ), 1/α) batches of size n, where an α-fraction of batches are clean i.i.d. samples from the linear regression model y = β*ᵀX + ξ and the rest are arbitrary. It also takes as parameters the inlier fraction α, noise level σ, a norm bound R on β*, and a moment-degree parameter k = ⌈1/δ⌉. The output is a list of O(1/α) candidate regressor vectors in ℝᵈ, guaranteed to contain at least one estimate within O(α^(-δ/2)/√n) of the true β* in ℓ₂-norm, with the minimum batch size reduced to n = Ω(α^(-δ)) for any constant δ > 0.

## Method

The algorithm iteratively refines a list of candidate regressors through three coupled components. First, a single-iteration SoS-based list-decodable mean estimator (building on Kothari & Steinhardt, 2017) estimates the batch average Z_B = (1/n)Σ yX, whose SoS-certifiable moment bounds are established via a novel SoS proof of the Marcinkiewicz-Zygmund inequality (Lemma 3.3) that transfers certifiably bounded moments from individual samples to their sum. Second, an iterative bootstrapping loop (adapted from Diakonikolas et al., 2019) transforms labels via y' = y − β̂ᵀX for each candidate, reducing the effective target norm by a constant factor per iteration. Third, a novel cross-candidate pruning procedure retains only regressors that demonstrate smaller empirical ℓ₂ loss than all sufficiently distant competitors on an α-fraction of batches, bounding the list to O(1/α) without losing the near-optimal candidate. The key insight is that SoS-certifiable higher moments of the covariates allow the batch-average estimator to concentrate with batch size n = Ω(α^(-6/k)) rather than Ω(1/α), yielding both smaller minimum batch size and improved final error O(kQ^(1/k)σ^(-3/k)/√n).

## Results

The main result (Theorem 1.3) shows that for any constant k, the algorithm requires batch size n = O(k²Q^(2/k) α^(-6/k)), uses m = Õ(((kd)^O(k)/α + α^(-3)) log(R/σ)) batches, runs in polynomial time, and outputs a list of O(1/α) vectors with estimation error O(kQ^(1/k) σ^(-3/k) / √n). This is a substantial qualitative improvement over Das et al. (2023), which required n = Õ(1/α) and achieved error O(σ/√(nα)) with a suboptimal list size of O(1/α²). The paper also provides the first SoS proof of the Marcinkiewicz-Zygmund inequality (Lemma 3.3), a technical contribution of broader applicability.

## Baselines & Comparisons

The primary comparison is with Das et al. (2023), the first efficient algorithm for list-decodable linear regression in the batch setting. This paper improves on all three key parameters simultaneously: (1) minimum batch size drops from Õ(1/α) to O(k²α^(-6/k)) for any constant k, a polynomial improvement; (2) estimation error improves from O(σ/√(nα)) to O(α^(-3/k)/√n), a factor of α^(-1+3/k) better; and (3) list size improves from O(1/α²) to the information-theoretically optimal O(1/α). These gains come at the cost of stronger distributional assumptions (SoS-certifiably bounded higher moments of the covariates), which are satisfied by all strongly log-concave distributions. The paper also notes that for extremely small batch sizes (n < log(1/α)), the super-polynomial runtime may be inherent via a reduction from the non-batch setting combined with the SQ lower bound of Diakonikolas et al. (2021).

## Relation to Prior Work

This paper extends the batch list-decodable linear regression framework of Das et al. (2023), which required batch size Ω(1/α), by leveraging SoS-certifiably bounded higher moments of the covariates to reduce the minimum batch size to Ω(α^{-δ}) for any constant δ > 0. The iterative bootstrapping structure (label transformation y' = y − β̂ᵀX) is adapted from Diakonikolas et al. (2019) for robust linear regression, while the single-iteration estimation subroutine relies on the SoS-based list-decodable mean estimator of Kothari & Steinhardt (2017). A key technical departure is the first SoS proof of the Marcinkiewicz-Zygmund inequality, which bridges the gap between population-level moment bounds on individual samples and the batch-average estimator, enabling the higher-moment machinery to apply to the batched setting.

## Why It Matters / Open Questions

The result establishes a smooth tradeoff between batch size and computational resources, which is practically relevant in federated learning and crowdsourcing where batch sizes are exogenous. The SoS Marcinkiewicz-Zygmund inequality is a new technical tool that the authors note may have broader applicability beyond this specific problem. A key limitation is that the improvement requires SoS-certifiably bounded moments (satisfied by log-concave distributions but not all distributions), and for batch sizes below O(log(1/α)) the runtime becomes quasi-polynomial, with a reduction argument suggesting this threshold may be inherent. Open questions include whether the SoS-certifiability assumption can be weakened and whether the approach extends to non-i.i.d. or non-Gaussian noise settings.

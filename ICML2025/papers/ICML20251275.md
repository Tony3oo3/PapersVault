## Problem

Pretraining linear recurrent LLMs from scratch remains prohibitively expensive, and existing linearization methods (SUPRA, LoLCATs, MambaInLlama) introduce auxiliary feature-mapping or gating modules that must be trained from scratch, creating architectural divergence from the original Transformer and requiring multi-stage training with billions of tokens. These approaches also overlook the gating mechanisms that are critical to state-of-the-art linear recurrent models, limiting their ability to faithfully approximate softmax attention.

## Input / Output

Liger takes the full pretrained weight matrices (W_Q, W_K, W_V) of a standard Transformer LLM (Llama-3 1B/3B/8B, Mistral-7B) and a small instruction-tuning set of ~50K Alpaca samples (~0.02B tokens, 1024-token sequences). It produces a gated linear recurrent model with identical parameter count that performs next-token prediction with O(TWD + TD²) training complexity and O(1) memory inference, requiring only ~4 hours on a single A800 GPU for the 8B model. No new trainable parameters are introduced; the key projection is repurposed in-place for gating.

## Method

Liger repurposes the pretrained key projection W_K to construct the gating mechanism via a parameter-free Pooling operation (G_t = Pooling(k_t)), eliminating the need for auxiliary gate modules. It uses Softmax as the feature mapping φ(·) rather than learnable kernel approximations, preserving the bounded query-key product distribution of the original attention and enabling end-to-end training without a separate attention-transfer stage. The recurrent update is S_t = G_t ⊙ S_{t-1} + φ(k_t^T) v_t with output o_t = φ(q_t) S_t, where all weights are inherited from the pretrained LLM. Liger Attention further blends this gated recurrent output with a narrow sliding-window softmax attention (window=64) using fixed weights α=β=0.5 to retain local softmax non-linearity. Performance is restored via lightweight LoRA (rank 8) applied only to W_Q, W_K, W_V, recovering 93% of Llama-3-8B performance with just 0.02B tokens.

## Results

Liger-GLA linearizes Llama-3-8B into a gated recurrent model using only 0.02B training tokens (0.085% of model parameters via LoRA), recovering 93% of the original Llama-3-8B performance (67.6 vs. 71.7 average accuracy across PiQA, ARC-e, ARC-c, HellaSwag, WinoGrande, and MMLU). On Mistral-7B, Liger-GLA achieves 65.1 average accuracy (90% recovery from 72.2) with the same 0.02B token budget. In inference efficiency, Liger-8B maintains constant 16.37 GB GPU memory across all sequence lengths (1K–32K), while Llama-3-8B with Flash-Attention-2 runs out of memory at 32K and Liger's decoding time scales linearly (1465s at 32K vs. OOM for the Transformer).

## Baselines & Comparisons

Against other linearization methods, Liger-GLA-Llama-3-8B (67.6 Avg) outperforms SUPRA (63.2, requiring 20B tokens vs. 0.02B), MambaInLlama/Mamba2 (61.9, 20B tokens), and LoLCATs (65.4, 0.04B tokens) by 2.2–5.7 points on average accuracy. On Mistral-7B, Liger (65.1) beats SUPRA (64.0, 100B tokens) and LoLCATs (59.8, 0.04B tokens) by 1.1 and 5.3 points respectively. Compared to pre-trained linear recurrent models in Table 3, Liger-GLA-Llama-3-8B (67.6 Avg) surpasses Mamba-7B (64.7), TransNormerLLM-7B (64.1), Griffin-7B (65.8), and StripedHyena-Nous-7B (60.8), though it trails RWKV-6-World-7B (69.4, no MMLU reported) and the hybrid Zamba2-7B (73.5) which used 2100B pre-training tokens. Against the original Transformer baselines, Liger recovers 93% of Llama-3-8B and 90% of Mistral-7B performance, with the gap narrowing from 4.8% at 1B to 1.8% at 8B parameters. Liger also substantially outperforms pre-trained GLA baselines (GLA-1B: 46.9, GLA-3B: 49.1), demonstrating that the key-projection gating and LoRA adaptation are critical for performance recovery.

## Relation to Prior Work

Liger builds on the gated linear attention (GLA) framework and the linear attention recurrent formulation, but departs fundamentally from prior linearization methods (SUPRA, MambaInLlama, LoLCATs) that introduce auxiliary feature-mapping or gating modules requiring training from scratch. Instead, Liger repurposes the pretrained key projection matrix W_K to construct gating mechanisms via a parameter-free pooling operation, and uses Softmax as the feature mapping φ(·) rather than learned kernel approximations. The Liger Attention component extends the intra-layer hybrid attention paradigm (Agent Attention, Based) by adding a sliding-window softmax branch with a controlled blending ratio, addressing the local-information gap in purely recurrent designs.

## Why It Matters / Open Questions

Liger offers a practically significant efficiency win: converting a pretrained 8B LLM to a linear-time, constant-memory recurrent model using only 0.02B tokens (~0.085% of parameters via LoRA) and ~4 hours on a single GPU, versus billions of tokens for prior linearization methods. The remaining ~7% average performance gap (and a larger ~22-point MMLU gap) suggests that knowledge-intensive retrieval still benefits from full softmax attention, leaving open whether the gap can be closed with more fine-tuning tokens or architectural refinements. Whether the key-projection-gating strategy generalizes to non-Llama architectures (e.g., GQA, MQA variants) and scales beyond 8B parameters remains untested.

## Problem

Standard embedding and visualization techniques (tSNE, UMAP, Diffusion Maps) construct a single similarity graph using all features, which distorts underlying structure when data is governed by multiple latent variables embedded in distinct feature subsets. No principled method existed to automatically partition features into groups that each capture a simpler, lower-dimensional substructure before embedding, leaving users unable to disentangle co-occurring processes in high-dimensional data.

## Input / Output

The method takes an N×D data matrix and a user-specified number of partitions K (plus a perplexity parameter α controlling neighborhood size) and produces K mutually exclusive, exhaustive feature partitions (binary indicator vectors in {0,1}^D) along with K corresponding N×N row-normalized Gaussian affinity matrices. Each affinity matrix is built using only the features in its partition via weighted Euclidean distances, and downstream embeddings (tSNE, UMAP, Diffusion Maps) are then generated independently per partition. The approach is fully unsupervised and retains all features—no features are discarded, only regrouped.

## Method

The core contribution is an optimization problem that jointly learns K feature partitions and K affinity matrices by minimizing the sum of graph smoothness scores (a Laplacian-based quantity) across all partitions, subject to stochasticity and entropy (perplexity) constraints on each graph. The key insight is that the graph smoothness score asymptotically approximates the intrinsic dimension of the underlying manifold, so minimizing it promotes partitions whose features form simpler, lower-dimensional geometries. Features are assigned to the partition where they are smoothest under that partition's graph (via the Laplacian score), and the affinity matrices are row-normalized Gaussian kernels with per-point bandwidths set by binary search to satisfy the perplexity constraint. To avoid local minima from the binary partition constraint, the algorithm solves a sequence of entropically regularized subproblems with annealing (soft assignments that gradually sharpen to hard partitions). The paper proves that in a high-dimensional asymptotic regime (D, N → ∞ with D/log N → ∞), the objective's minimizer recovers the true feature partitions even when the K substructures are partially dependent through a shared latent manifold.

## Results

On the synthetic ellipsoid partitioning task (Table 1), the proposed Feature Partitioning (FP) algorithm achieves 0 partitioning error (out of 6 coordinates) in both the independent and partially dependent settings, averaged over 100 randomized experiments, while all baselines incur 1.7–2.2 errors. On the mouse dermal scRNA-seq dataset (N=5,572 cells, D=5,000 genes), the method's partition-based tSNE embeddings achieve the lowest k-nearest-neighbor error against both latent processes (cell type and cell cycle) compared to tSNE on all features, IC-PML, LDLE, Multi-tSNE, and raw features. On the rotating figurines video data (N=5,000 images, D=9,600 pixels), FP achieves 75.93% (30-NN) and 85.15% (50-NN) agreement with the true rotation angles, versus 17.5–19.0% and 23.8–26.0% for all clustering baselines.

## Baselines & Comparisons

The paper compares against eight baselines across three experimental settings. On the synthetic ellipsoid task (Table 1), all four clustering/bi-clustering methods (Spectral Co-Clustering, Spectral Bi-Clustering, K-Means on features, Spectral Clustering on features) fail to recover the correct 3+3 coordinate split, incurring 1.7–2.2 errors out of 6, with performance degrading in the partially dependent case; the proposed FP algorithm achieves perfect 0-error partitioning in both settings. On the dermal scRNA-seq data (Figure 3b), FP's partition-based embeddings outperform tSNE on all features, IC-PML (He et al., 2023), LDLE (Kohli et al., 2021), Multi-tSNE (Van der Maaten & Hinton, 2012), and raw features (both with and without partitioning) on the k-nearest-neighbor error metric for both latent processes. On the rotating figurines video data (Table 2, Appendix D), FP achieves 75.93% (30-NN) and 85.15% (50-NN) agreement with ground-truth rotation angles, substantially outperforming K-Means (18.49/25.93), Spectral Clustering (17.51–18.94/23.80–25.49 across multiple configurations), and the all-features baseline (8.21/11.74). The method also wins on the liver scRNA-seq dataset where PCA preprocessing enables partitioning of overlapping gene sets, revealing both zonation and circadian cycle structures that are only partially visible in the standard all-features tSNE embedding.

## Relation to Prior Work

This paper extends the graph construction step of embedding techniques like tSNE and Diffusion Maps by simultaneously learning multiple affinity graphs from adaptively chosen feature partitions, using the Laplacian score (He et al., 2005) as the smoothness objective. It departs from bi-clustering and feature selection, which group features by value similarity or correlation, by instead grouping features based on shared latent geometric structure inferred from the data's manifold geometry. It also generalizes product-manifold decoupling methods (Zhang et al., 2021; He et al., 2023) by supporting partially dependent feature subsets and avoiding the exponential error growth with intrinsic dimension that plagues eigenstructure-based approaches. The entropic regularization and sequential annealing strategy for solving the non-convex partitioning problem draws on ideas from Sinkhorn-type optimization and soft assignment methods.

## Why It Matters / Open Questions

This work addresses a practical and increasingly common problem in single-cell genomics and other high-dimensional domains: when multiple biological or physical processes are encoded in different feature subsets, standard embeddings using all features simultaneously fail to disentangle them. The theoretical guarantee that the Laplacian-based objective recovers correct partitions even under partial dependence (Theorem 4.4) is a meaningful contribution, as prior product-manifold methods cannot handle this setting. Open questions include automated selection of the number of partitions K, handling uninformative or nuisance features, and scaling to very large datasets (the O(KN²D) complexity is a concern). The approach is inherently classical (not deep learning), which limits its integration with modern end-to-end pipelines but makes it interpretable and complementary to existing tools.

## Problem

Existing foundation agents cannot generalize across diverse virtual environments because each one requires manually designed observation and action spaces tied to environment-specific APIs. The paper introduces the General Computer Control (GCC) setting, which restricts agents to the most universal human-style interface—screenshots as input and keyboard/mouse actions as output—so that any software or game can serve as an out-of-the-box testbed without custom integration.
![Teaser figure](../imgs/ICML20252328/cropped_page0_idx0.webp)

## Input / Output

CRADLE consumes a screen video clip (recorded at 2 fps) capturing the execution of the previous action, from which it extracts keyframes for OCR-based text extraction and visual scene understanding. It outputs executable Python code that drives low-level keyboard and mouse operations (key_press, key_hold, mouse_move, wheel_scroll, etc.) through a custom IO_env wrapper built on PyDirectInput, AHK, and ctypes, supporting attributes like press duration, movement speed, absolute/relative coordinates, and synchronous/asynchronous timing. No environment-internal APIs, DOM trees, or element IDs are used at any point.

## Method

CRADLE is a zero-shot, modular LMM-powered framework (backbone: GPT-4o) organized around six cooperating modules: Information Gathering (OCR + visual scene parsing augmented by Grounding DINO, SAM, and template matching), Self-Reflection (evaluating whether the last action succeeded and diagnosing failures), Task Inference (deciding whether to continue or switch tasks, with a binary long/short-horizon stack), Skill Curation (generating, updating, and retrieving code-level skills from in-game tutorials, manuals, or self-exploration), Action Planning (instantiating curated skills into parameterized executable sequences), and Memory (episodic memory with short-term screenshots plus recurrent long-term summarization, and procedural memory storing skills as code with embedding-based retrieval via text-embedding-ada-002). The key architectural insight is bridging the gap between high-level semantic reasoning and OS-level control by having the LMM generate Python code functions as reusable skills, which an Executor then maps to raw keyboard/mouse commands. The reasoning loop follows a 'reflect on the past, summarize the present, plan for the future' cycle, and the entire system operates without any training or fine-tuning.

## Results

CRADLE (GPT-4o) completes all 13 sequential RDR2 main-storyline tasks in ~8,000 steps (~98 min in-game) versus 67 min for human players, and is the first LMM-based agent to follow a AAA game's main storyline. In Dealer's Life 2, CRADLE achieves a 93.6% turnover rate and 39.6% total profit rate (peaking at 87.4%), substantially outperforming human players (68.4% turnover, 17.3% profit). In Cities: Skylines, CRADLE builds cities with an average population of 450 (single-run peak >860) versus 415 for humans. On the OSWorld benchmark, CRADLE achieves 7.81% overall success rate, surpassing GPT-4o (5.03%) and GPT-4o+SoM (4.59%).

## Baselines & Comparisons

CRADLE (GPT-4o) dominates all baselines on every task: it completes Follow Dutch in 13±3 steps (vs. 15±2 for React-like, 19±4 for Reflexion-like, 32±12 for Voyager-like) and Follow Micah in 33±3 steps with 5/5 success (vs. 74±0 at 1/5 for React-like, 58±14 at 2/5 for Reflexion-like, and N/A for Voyager-like). Critically, only CRADLE succeeds on the harder tasks—Hitch Horse (26±5, 4/5), Protect Dutch (461±0, 1/5), Search for Supplies (134±0, 1/5), and Stardew Valley Cultivation (24±4, 4/5)—while all three baselines fail entirely (N/A) on these. The Voyager-like variant, which replaces visual input with GPT-4o-generated text descriptions, is the weakest baseline, confirming the necessity of direct multimodal observation. On OSWorld, CRADLE (7.81%) outperforms both GPT-4o alone (5.03%) and GPT-4o+Set-of-Mark (4.59%), with the largest gap in the Professional domain (20.41% vs. 4.08% and 2.04%), attributed to the self-reflection module's ability to detect and correct infeasible actions.

## Relation to Prior Work

CRADLE synthesizes several established agent paradigms—Voyager's procedural skill library with embedding-based retrieval, Reflexion's verbal self-reflection, and ReAct's interleaved reasoning-acting loop—into a single modular framework powered by GPT-4o. It departs from prior computer-control agents (JARVIS-1, SIMA, web/mobile agents) by enforcing a strict General Computer Control (GCC) interface: raw screen video in, raw keyboard/mouse out, with no access to built-in APIs, DOM trees, or pre-defined semantic actions. This unifies the previously separate literatures on game-playing agents (which relied on game-specific APIs) and software-manipulation agents (which relied on element IDs or accessibility trees) under one standardized protocol.

## Why It Matters / Open Questions

CRADLE demonstrates for the first time that an LMM-based agent can follow a main storyline and complete hour-long missions in a commercial AAA game (RDR2) using only the human interface, validating the GCC setting as a viable path toward generalist agents. The practical impact is tempered by significant limitations: prohibitive API costs (~$5,400 per experimental round), high inference latency requiring game pausing, poor OOD visual recognition (pixel-art games, non-standard UIs), and no audio modality. Open questions include whether training (RL or behavior cloning) can close the gap with human performance, whether the six-module architecture can collapse into fewer LMM calls as models improve, and whether the GCC framing can support large-scale data collection for self-improvement.

## Problem

While prior work has catalogued various causes of LLM errors (adversarial inputs, hallucinations, decoding failures), the internal mechanism by which transformer tokens encode semantic dependencies—and how incorrect encoding of those dependencies leads to prediction mistakes—remains unexplored. This paper asks: do final-layer tokens faithfully encode the semantic relationships between words, and when models err, can we trace the mistake to specific tokens carrying false dependencies?

## Input / Output

The method consumes a text token sequence (or a QA pair consisting of a question and a context passage) and generates K perturbed copies by replacing a single target token with uniformly sampled vocabulary tokens. It produces three types of quantitative outputs: per-token semantic dependency scores (average L2 norm of final-layer representation change), alignment scores measuring overlap between model-estimated and SpaCy-parsed dependency groups, and per-head contribution heatmaps that localize which attention heads mediate a given token-to-token dependency. The analysis is performed on over 100,000 token perturbation cases per model across six datasets, and over 100,000 QA validation cases on SQuAD 1.1.

## Method

The core technique is a perturbation-based probing framework: replace the i-th input token with K random vocabulary tokens, forward each perturbed sequence through the full L-layer transformer, and compute the average L2 change Δ of each final-layer token j relative to the original, yielding a dependency score Δ_{z_j^L}|z_i^0 that quantifies how much token j's representation depends on token i. Three validations follow: (1) self-information retention—checking that Δ_{z_i^L}|z_i^0 is the maximum over all j, confirming tokens preserve their own semantics; (2) truthful dependency encoding—comparing the top-K most sensitive tokens against SpaCy dependency-parsed groups via an alignment score; (3) false dependency detection in QA—showing that when a model answers incorrectly, the maximum dependency score between wrong-answer tokens and question tokens exceeds that of correct-answer tokens. For parameter localization, the MHA output is decomposed into per-head, per-token contributions (following Gandelsman et al., 2024), and each head's contribution change under perturbation identifies the attention heads responsible for a specific dependency, revealing that the same heads encode both correct and false dependencies.

## Results

Across 10 transformer models evaluated on 6 datasets (600,000+ token cases), most tokens retain their original semantic information through all layers: BERT achieves 98.81% self-retention, DeBERTa 99.62%, LLaMA3 95.59%, while GPT-2 is the outlier at 75.15%. For truthful semantic dependency encoding (alignment with SpaCy-parsed dependencies), scores range from 82.44% (TinyRoBERTa) to 93.41% (GPT-2). The headline finding on SQuAD 1.1 (100,000+ QA cases) shows that when models answer incorrectly, 48–82% of the time the incorrect answer tokens carry stronger semantic dependency on question tokens than the correct answer tokens (P(fθ)), while when models answer correctly, 70–96% of the time the correct dependency is properly encoded (P′(fθ)).

## Baselines & Comparisons

This is an empirical interpretability study rather than a method-vs-baseline comparison, so the key contrasts are across model architectures. Encoder-only BERT-series models (BERT, DistilBERT, DeBERTa) show the strongest link between false semantic dependencies and mistakes (P(fθ) = 75–82%), while decoder-only GPT-2 and LLaMA3 show weaker coupling (48% and 65%), which the authors attribute to their generative nature producing paraphrases rather than exact span extraction. Among BERT variants, DistilBERT exhibits the highest P(fθ) (81.80%) and P′(fθ) (96.48%), suggesting its architecture is both more susceptible to false dependencies and more decisive when dependencies are correct. RoBERTa and MobileBERT show the lowest P(fθ) (69.20% and 66.61%), implying other factors (beyond false dependencies) contribute to their errors. The attention-head localization analysis (Figure 5) reveals that the same top-5% attention heads are responsible for both correct and false semantic dependencies across all four high-accuracy BERT variants, meaning simple head pruning cannot eliminate false dependencies without disrupting correct ones.

## Relation to Prior Work

This paper builds on the MHA decomposition framework from Gandelsman et al. (2024) to break down per-head, per-token contributions, and extends it from CLIP image-text alignment to token-level semantic dependency tracing in language models. It departs from prior probing studies (Hewitt & Manning, 2019; Tenney, 2019; Pimentel et al., 2020) that examine static linguistic features by introducing a perturbation-based framework that quantifies dynamic, context-sensitive semantic dependency strength between individual tokens without requiring prior annotations. It also distinguishes itself from attention-head pruning literature (Voita et al., 2019; Michel et al., 2019; Wu et al., 2024) by showing that the same heads responsible for correct dependencies also encode false ones, rather than identifying heads that can be safely removed.

## Why It Matters / Open Questions

The finding that the same attention head parameters encode both correct and false semantic dependencies is practically significant: it rules out straightforward head-pruning or parameter-removal strategies for fixing model mistakes and points toward the need for context-sensitive re-weighting or regularization approaches. The perturbation-based framework offers a reusable tool for diagnosing token-level errors in QA and potentially other tasks, though its applicability is limited to extractive settings where answers appear verbatim in context. Open questions include extending the analysis to generative answers, intermediate layers, and subword-level dependencies, as well as developing targeted interventions that suppress false dependencies without disrupting correct ones.

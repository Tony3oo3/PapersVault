## Problem

Rehearsal-based continual learning universally adopts concurrent rehearsal—training jointly on new data and stored exemplars from all previous tasks—but it remains unclear whether this strategy is always optimal. The paper asks whether sequential rehearsal (training on the new task first, then revisiting old tasks one by one) can outperform concurrent rehearsal, and under what conditions on task similarity this advantage emerges.

## Input / Output

The model receives RGB or grayscale images (32×32 for CIFAR-10/100, 64×64 for Tiny-ImageNet-200, 28×28 for MNIST) together with an explicit task identifier, and produces a class label via a task-specific output head in a multi-headed ResNet-18. A reservoir-sampled memory buffer (200–300 exemplars per class depending on dataset) stores past-task data that is partitioned into similar and dissimilar subsets before each training round. The theoretical analysis operates on i.i.d. Gaussian features in an overparameterized linear regression setting (p > n + M) with equal memory allocation across tasks.

## Method

The paper derives the first closed-form expressions for expected forgetting and generalization error under both concurrent and sequential rehearsal in overparameterized linear models, using block-matrix decomposition to handle task interference from mixed memory data. The key theoretical result shows that sequential rehearsal yields lower forgetting and generalization error when task dissimilarity (measured by ‖w*_j − w*_k‖) exceeds a threshold, while concurrent rehearsal is preferable for similar tasks. Motivated by this, the authors propose a hybrid rehearsal framework: a DIVIDEBUFFER step partitions memory exemplars into similar and dissimilar subsets using cosine similarity of task gradients, the model is first trained concurrently on current data plus similar-task exemplars, and then sequentially fine-tuned on each dissimilar task's exemplars. Experiments with ResNet-18 on Split-CIFAR-10/100, Split-Tiny-ImageNet-200, and Split-MNIST confirm that hybrid rehearsal consistently improves accuracy and reduces forgetting over concurrent rehearsal, with gains growing as task dissimilarity increases.

## Results

On the three standard task-incremental benchmarks (5 tasks each), Hybrid Rehearsal consistently outperforms Concurrent Rehearsal in both Final Average Accuracy (Acc) and Final Average Forgetting (Fgt). The largest gains appear on Split-TinyImagenet200, where Hybrid achieves 63.29% Acc vs. 61.10% (+2.19) and 9.62 Fgt vs. 13.28 (−3.66). Under image corruption (increased task dissimilarity), the advantage widens substantially: on Corrupted Split-TinyImagenet200, Hybrid reduces forgetting from 15.23 to 1.91 (−13.32) while improving accuracy by +2.38. In a 20-task setting (Table 2), Hybrid further extends its lead, gaining +4.32 Acc on Split-CIFAR-100 and +3.52 on Split-TinyImagenet200.

## Baselines & Comparisons

The sole baseline is Concurrent Rehearsal (standard experience replay, where past and new data are trained jointly), which is the dominant rehearsal strategy in prior work (Rolnick et al., 2019; Chaudhry et al., 2018). Hybrid Rehearsal wins on every dataset and every metric: it improves accuracy by +1.07 to +2.38 and reduces forgetting by −1.48 to −13.32 across the six settings in Table 1. The advantage is most pronounced when tasks are more dissimilar—corrupting one task's images (e.g., color-swapping, Gaussian blur, rotation) widens the forgetting gap from ~3–4 points to ~8–13 points, directly validating the paper's theoretical prediction that sequential rehearsal benefits grow with task dissimilarity. In the 20-task long-sequence setting (Table 2), Hybrid extends its accuracy lead to +4.32 (CIFAR-100) and +3.52 (Tiny-ImageNet) over Concurrent, confirming scalability. No comparison shows Hybrid losing to Concurrent on any reported metric.

## Relation to Prior Work

This paper extends the overparameterized linear model framework for continual learning established by Lin et al. (2023), Evron et al. (2022), and subsequent works, but applies it to a setting those studies did not cover: rehearsal-based (experience replay) CL. While the concurrent rehearsal strategy from Rolnick et al. (2019) has been the de facto standard in both practice and the single prior theoretical treatment (Banayeeanzade et al., 2024), this paper departs from that default by proposing and analyzing sequential rehearsal, where old tasks are revisited one-by-one after the current task is learned. The resulting hybrid rehearsal framework merges both strategies based on task similarity, a design choice motivated by the theoretical comparison rather than by prior empirical heuristics.

## Why It Matters / Open Questions

This is the first comprehensive theoretical characterization of rehearsal-based CL, providing closed-form expressions for forgetting and generalization error under both concurrent and sequential rehearsal. The practical implication — that the widely assumed concurrent strategy is suboptimal for dissimilar tasks — gives practitioners a principled criterion for when to switch training modes, and the hybrid framework demonstrates consistent (if modest) gains across multiple datasets. Key limitations include the restriction to linear models, equal memory allocation across tasks, a fixed oldest-to-newest revisit order, and the simplification of selecting at most one dissimilar task in practice; extending the theory to non-linear models and optimizing the rehearsal order remain open.

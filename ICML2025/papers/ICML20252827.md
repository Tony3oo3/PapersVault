## Problem

Personalized Federated PEFT for Vision-Language Models faces two underexplored limitations: existing decoupled prompt methods collaborate at the feature level via external loss signals, which undermines the textual prior knowledge embedded in CLIP's pre-training, and the diversity of visual features within the same class is overlooked, making fixed visual representations suboptimal for image-text alignment across heterogeneous domains.
![Teaser figure](../imgs/ICML20252827/cropped_page0_idx0.webp)

## Input / Output

The method consumes RGB images (processed by a frozen CLIP ViT-B/16 backbone) and constructs a composite text prompt of length 16 per class, structured as [global prompt, class token, 'with a style of', local prompt]. The visual branch produces a dynamically weighted combination of three feature vectors (naive, general-adapter, specific-adapter) via a per-sample gating mechanism. Output is a per-class probability distribution computed through cosine similarity between the adapted visual feature and the encoded prompt, optimized with standard cross-entropy loss.

## Method

FedDDA introduces two complementary decoupling mechanisms. Textually, it concatenates a shared global prompt and a private local prompt with the guidance phrase 'with a style of' into a single prompt sequence, so that CLIP's pre-trained attention mechanism fuses consensus and style semantics without any auxiliary loss signals. Visually, it employs a dual-adapter architecture (a shared general adapter and a private specific adapter, each a two-layer bottleneck with ReLU) to extract consensus and style features from the naive visual embedding, then applies a Mixture-of-Experts-inspired linear gate that produces per-sample softmax weights over the three visual components (naive, general, specific) for dynamic feature combination. During federated aggregation, only the global prompt and general adapter parameters are averaged across clients; the local prompt, specific adapter, and gate remain client-private. The entire system is trained with the standard CLIP contrastive loss, requiring no additional regularization or multi-stage optimization.

## Results

FedDDA achieves the highest average accuracy across all four multi-domain classification benchmarks under both client settings. Under setting ① (one domain per client), FedDDA reaches 94.90% on Office31, 98.90% on PACS, 88.89% on OfficeHome, and 83.57% on DomainNet. Under setting ② (one domain per two clients), it achieves 93.85%, 98.69%, 88.22%, and 82.24% respectively. With additional label shifts (Dirichlet β=0.1), FedDDA maintains the best performance, e.g., 94.68% on Office31 and 82.98% on DomainNet, outperforming the strongest baseline FedPGP by 2.9 and 2.3 points respectively.

## Baselines & Comparisons

FedDDA outperforms all five baselines on every dataset and both client settings. Against the closest competitor FedPGP (ICML'24), FedDDA gains +1.20% on Office31, +0.33% on PACS, +0.24% on OfficeHome, and +2.09% on DomainNet under setting ①, with similar margins under setting ②. The advantage over FedOTP (CVPR'24) is most pronounced on OfficeHome (+5.08%) and DomainNet (+6.51%), where FedOTP's optimal-transport alignment struggles with diverse visual styles. Compared to the generalized baselines PromptFL and PromptFL+Prox, FedDDA improves by 4.65–9.81% on DomainNet, demonstrating the critical role of personalization under domain shift. Under label shifts (Table 2, β=0.1), FedDDA extends its lead over FedPGP to +2.90% on Office31 and +2.26% on DomainNet, confirming robustness to both domain and label heterogeneity.

## Relation to Prior Work

This paper sits at the intersection of federated parameter-efficient fine-tuning (FedPEFT) and personalized adaptation for vision-language models. It departs from prior decoupled-prompt methods (FedOTP, FedPGP, DiPrompT) that rely on external loss signals to coordinate independent prompts at the feature level, arguing this undermines the textual semantics built through CLIP's pre-training. The key conceptual shift is twofold: (1) using guidance words ('with a style of') to fuse global and local prompts within a single linguistic context so that prior knowledge naturally mediates the consensus-style split, and (2) introducing a dual-adapter + MoE-gate module on the visual branch, whereas prior personalized FedPEFT methods restrict additional parameters to the text branch alone. The architecture repurposes standard prompt tuning, adapter tuning, and mixture-of-experts routing into a unified federated protocol without requiring any auxiliary loss terms.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in deploying VLMs across distributed, non-IID data sources by showing that both textual and visual spaces benefit from explicit consensus/style decomposition. The consistent gains across four multi-domain benchmarks (including the challenging DomainNet with 345 classes) and under Dirichlet label shifts suggest the approach generalizes beyond simple domain-shift settings. However, the method is validated only on image classification with CLIP ViT-B/16, and the added visual adapters increase parameter count and communication overhead. Open questions include whether the textual prior decoupling strategy transfers to other VLMs (e.g., LLaVA, BLIP-2), whether the MoE gate remains effective with more than two visual experts, and how the approach scales to non-classification tasks such as retrieval or generation.

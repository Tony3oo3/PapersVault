## Problem

Existing continual learning methods integrate new task knowledge into pretrained models but lack a mechanism to selectively forget outdated or sensitive content, while machine unlearning addresses forgetting in isolation without concurrent learning. This paper introduces Knowledge Swapping, a unified task that simultaneously forgets user-specified knowledge, retains essential pretrained capabilities, and acquires new knowledge, and empirically discovers that learning and forgetting operate in opposite directions across the feature hierarchy (low-to-high vs. high-to-low), which dictates the optimal training sequence.

## Input / Output

The method consumes a pretrained vision model (ViT-B16 for classification, Mask2Former for segmentation, DINO for detection) along with RGB images partitioned into three labeled sets: a retaining set (knowledge to preserve), a forgetting set (knowledge to erase), and a learning set (new knowledge to acquire). The retaining and forgetting sets are subsets of the original pretraining data, while the learning set can be an entirely new domain. Outputs are task-specific: class labels for classification, bounding boxes with class labels for detection, and pixel-level segmentation masks for segmentation, evaluated via accuracy, mAP, and mIoU respectively.

## Method

The core strategy is a two-stage 'Learning Before Forgetting' protocol: first fine-tune on the learning and retaining sets, then perform targeted forgetting on the forgetting set while preserving both retained and newly learned knowledge. This ordering is justified by the knock-on feature hierarchy finding that incremental learning updates propagate from low-level to high-level features, whereas forgetting propagates from high-level to low-level features, so learning first prevents subsequent forgetting from destabilizing the low-level representations that support the new knowledge. Parameter updates are restricted to LoRA low-rank matrices (A and B) on the linear layers of Transformer FFN blocks, with all other pretrained weights frozen. A group Lasso regularization term penalizes the Frobenius norms of LoRA matrices to sparsify irrelevant FFN modules, enabling module-level selective retention and forgetting. The forgetting loss uses a boundary constraint (RELU(BND − L(f(X_f), Y_f))) to prevent unbounded loss growth during the negative-loss maximization, while the learning loss combines retention and learning objectives with weighted hyperparameters α and β.

## Results

Under the Learning Before Forgetting (L→F) strategy, the forgetting set accuracy drops to near 0% across all three task types (image classification, semantic segmentation, and object detection), while the learning set accuracy reaches 91–99% (classification), 58–93% mIoU (segmentation), and 62–80% mAP (detection), with retention accuracy/mIoU/mAP remaining stable (86–88% / ~50% / ~55%). In contrast, the reverse F→L ordering fails to maintain forgetting: the forgetting set accuracy rebounds to 70–83% (classification), 49–60% mIoU (segmentation), and 7.7–11.1% mAP (detection), confirming that low-level parameter updates during learning disrupt previously erased high-level semantic representations.

## Baselines & Comparisons

This paper does not compare against external continual-learning or unlearning baselines; instead, the central comparison is between two sequential strategies: Learning Before Forgetting (L→F) and Learning After Forgetting (F→L). L→F consistently outperforms F→L on the forgetting metric across all tasks: on ImageNet-100 classification, L→F drives forgetting-set accuracy to 0% while F→L leaves it at 70.8–80.8%; on ADE20K segmentation, L→F achieves 0.08–0.71% mIoU on the forgetting set versus 49.4–60.3% for F→L; on COCO detection, L→F reaches 0.5–0.6% mAP versus 7.7–11.1% for F→L. The retention and learning metrics are comparable between the two orderings (within 1–3 points), indicating that the advantage of L→F is specifically in preserving the forgetting effect. An additional F→L→F experiment shows that a second forgetting pass can recover the lost forgetting (mIoU_f drops from ~50% to <0.4%), confirming that the issue is the low-level parameter perturbation caused by learning, not an inherent limitation of the unlearning mechanism.

## Relation to Prior Work

This paper sits at the intersection of continual learning and machine unlearning, two largely separate research threads. It builds on LoRA (Hu et al., 2021) for parameter-efficient adaptation and on Geva et al. (2020)'s finding that Transformer FFN layers encode model knowledge, using these to enable selective regulation of specific knowledge subsets. The key conceptual departure is unifying the two objectives—acquiring new knowledge and erasing specified knowledge—into a single task (Knowledge Swapping), whereas prior continual learning work only addresses retention-plus-learning and prior unlearning work only addresses forgetting in isolation. The paper also draws on Lasso/group-sparse regularization (Wen et al., 2016; Yuan & Lin, 2006) to enforce module-level selectivity in the LoRA parameters.

## Why It Matters / Open Questions

The paper provides the first formal benchmark for simultaneously learning, forgetting, and retaining knowledge in a pretrained vision model, filling a gap between continual learning and machine unlearning literature. The empirical 'knock-on feature hierarchy' finding—that learning propagates low-to-high while forgetting propagates high-to-low—offers a practical design principle (learn before forget) that is simple to implement and validated across classification, detection, and segmentation. However, the method is relatively straightforward (sequential two-stage LoRA fine-tuning with Lasso), the evaluation is limited to vision tasks with small class counts (5–10), and the paper acknowledges that difficulty varies across categories without providing a deeper analysis. Open questions include whether the ordering principle generalizes to language models, whether the sparse constraint is truly necessary versus simply using separate LoRA adapters, and how the approach scales to larger forgetting/learning sets.

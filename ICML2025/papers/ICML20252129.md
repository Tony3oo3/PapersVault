## Problem

LLMs remain unreliable at sequential decision-making and planning, struggling even with common board games like chess or tic-tac-toe due to hallucinations and inability to consistently reason over possible futures. This paper addresses how to improve LLM game-playing strength by combining domain-specific pre-training with search-based planning, demonstrating that both external (MCTS-guided) and internal (distilled into the model) search yield substantial Elo gains over the base model.
![Teaser figure](../imgs/ICML20252129/cropped_page2_idx0.webp)

## Input / Output

The model consumes a command-based textual prompt specifying the game, board state (one token per field, or FEN for chess), optional previous state + action for transition prediction, and a configurable top-k parameter controlling inference-time compute. It produces, in a single forward pass, the full set of legal moves each paired with a win-probability bucket (one of 64 special tokens), a recommended best action, and the updated board state. For internal search, the output extends to a depth-first linearized minimax tree with backpropagated values and a final move selection, all generated autoregressively in one model call.

## Method

The core model is MAV, a 2.7B-parameter decoder-only Transformer (Gemini architecture) pre-trained via supervised learning on Stockfish-annotated positions across four games, simultaneously learning state tracking, legal move prediction, action-value estimation (as 64-bucket classification), and terminal detection in a unified format. For external search, MAV replaces the game engine inside an Async MCTS controller: it provides the prior (ε-greedy softmax over top-k values), value function, and learned state transitions, with dynamic virtual counts that exponentially decay from leaf to root to balance exploration under batched parallel evaluations. For internal search, MAV is fine-tuned on 40% linearized minimax tree traces (depth 1–3, breadth 2–5, generated by expanding top-5 Stockfish moves) mixed with 60% original MAV data, distilling the full search procedure—node evaluation, expansion, and backpropagation—into a single autoregressive generation. The key design insight is that all world-modeling, policy, and value computation occur in one model call with no external engine dependency, enabling hallucination-robust planning (parse failures assign −∞ to prune bad branches) and dynamic compute scaling at inference time.

## Results

MAV (mean scoring) achieves an external Elo of 2923 in chess, matching the Grandmaster-level Ext-BoN baseline (2926). Adding external MCTS with 2000 simulations lifts performance to an external Elo of 3209 (internal Elo 1707), approaching Stockfish-L20 (3474) while using only ~100–1k model calls per move versus millions of nodes in traditional engines. In Chess960, MAV outperforms Ext-BoN (1278 vs. 1208 internal Elo), and in Connect Four, MAV-MCTS improves over searchless MAV by at least 244 Elo. Internal search (MAV-IS) scales smoothly with token budget, with playing strength increasing monotonically as breadth and depth grow.

## Baselines & Comparisons

The primary LLM baseline is Ext-BoN (Ruoss et al., 2024a), a 270M-parameter Transformer trained on 15 billion Stockfish-annotated data points. On chess, MAV (mean scoring) essentially ties Ext-BoN (2923 vs. 2926 external Elo), while on Chess960 MAV clearly outperforms it (1278 vs. 1208 internal Elo), likely due to explicit Chess960 training data. The key advantage of this paper's approach emerges when search is added: MAV-MCTS with just 100 simulations surpasses both Ext-BoN and searchless MAV by 68+ internal Elo, and at 2000 simulations reaches 3209 external Elo—far exceeding Ext-BoN's 2926. Against Stockfish at matched internal Elo levels, MAV-MCTS agents are competitive (e.g., MAV-MCTS M=1000 at 3157 vs. Stockfish-L17 at 3141), demonstrating that a 2.7B-parameter LLM with modest search can rival a dedicated game engine. In Connect Four and Hex, the gains from MCTS over the searchless MAV are particularly large (≥244 Elo and ≥335 Elo respectively), suggesting the learned value function is most beneficial in games where the base model is weaker.

## Relation to Prior Work

This paper unifies three previously separate threads: AlphaZero-style MCTS (Silver et al., 2017), MuZero's learned world model that eliminates the need for an explicit game engine (Schrittwieser et al., 2020), and the Stream of Search (SoS) approach to internal search in language (Gandhi et al., 2024b). The key departure is the Multi-Action-Value (MAV) model, a single Transformer that simultaneously serves as world model, value function, and policy—extending the Ext-BoN line of work (Ruoss et al., 2024a) by adding state tracking, legal move generation, and terminal detection, all without an external engine. The paper further generalizes SoS from simple games to chess-scale complexity by distilling minimax search traces into the model via fine-tuning, and introduces dynamic virtual counts to make async MCTS practical under LLM inference latency.

## Why It Matters / Open Questions

The demonstration that a 2.7B-parameter Transformer can reach Grandmaster-level chess (Elo ~3200) with only ~100–1000 simulations—roughly the search budget of a human player, versus AlphaZero's ~10k—suggests that LLMs can be efficient planners when equipped with a learned world model, not just brute-force search. The engine-free formulation is important for generalizing to domains where no explicit solver exists. Key limitations include the reliance on large quantities of engine-annotated training data, the absence of natural language communication, and the open question of how to design value functions for general conversational or open-ended tasks. The internal search results (99.6% tree-shape accuracy, smooth scaling with budget) hint at a path toward fully self-contained reasoning agents, but the approach has only been validated on perfect-information board games.

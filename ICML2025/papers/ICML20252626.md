## Problem

Simulation-based inference (SBI) methods like neural posterior estimation (NPE) produce unreliable and miscalibrated posterior estimates when the simulator is misspecified relative to the real-world generative process. Existing robustness approaches either require the simulator to be well-specified or lack a principled mechanism to correct for the simulation-to-reality gap using only a small set of labeled real observations. This paper addresses the practical setting where only misspecified simulators are available but a small calibration set of ground-truth parameter-observation pairs exists.

## Input / Output

The method takes as input a misspecified simulator S(θ, ε), a prior p(θ), a small calibration set of n_c labeled real observations {(θ^i, x_o^i)}, and a test set of n_o unlabeled real observations. Observations span diverse modalities: 200-point time series (pendulum), 1000-point hemodynamic waveforms at 125 Hz, RGB images (light tunnel), pressure curves (wind tunnel), and low-dimensional tabular vectors (CS, SIR). The output is a posterior distribution p̃(θ|x_o^i) for each test observation, structured as a weighted mixture of NPE posteriors over simulated observations, from which per-dimension credible intervals are extracted for calibration assessment via the ACAUC metric.

## Method

RoPE combines neural posterior estimation with optimal transport in two stages. First, NPE is trained on simulated data to obtain a neural statistic estimator h_ω* and a normalizing-flow posterior; h_ω* is then fine-tuned on the calibration set via an L2-matching objective that aligns real-observation representations with the expected simulated representations for the same parameter. Second, at test time, a semi-balanced, entropy-regularized OT problem is solved between the fine-tuned real representations {g_φ*(x_o^i)} and simulated representations {h_ω*(x_s^j)} using the Sinkhorn algorithm, yielding a transport matrix P* whose entries define mixture weights. The final posterior for each real observation is a weighted average of NPE posteriors: p̃(θ|x_o^i) = Σ_j n_o P*_ij p̃(θ|x_s^j). The entropic regularization γ controls the calibration-informativeness trade-off (larger γ pushes posteriors toward the prior), while the semi-balanced parameter τ < 1 allows discarding mismatched simulations to handle prior misspecification. The conditional independence assumption x_o ⊥ θ | x_s acts as an information bottleneck that prevents shortcut learning from the small calibration set and ensures predictions remain grounded in the simulator's domain knowledge.

## Results

Across six benchmark tasks (CS, SIR, Pendulum, Hemodynamics, Light Tunnel, Wind Tunnel), RoPE (γ=0.5, τ=0.9) is the only method that consistently returns well-calibrated or slightly under-confident posteriors (ACAUC ≈ 0 or slightly negative) while significantly reducing uncertainty compared to the prior (LPP well above the prior baseline). On the most challenging real-world task (Light Tunnel, Task E), RoPE remains the best approach even with calibration sets exceeding 1,000 examples, where J-NPE and MLP become competitive but remain overconfident (positive ACAUC). On the SIR benchmark (Task B), standard NPE trained on simulated data achieves the best LPP, indicating that the misspecification in that task is mild and not a meaningful stress test. Ablations confirm the OT step is crucial: tuning-only performs poorly on all tasks except B, while OT-only matches RoPE on some tasks but is significantly outperformed on tasks C and E where misspecification is severe.

## Baselines & Comparisons

RoPE outperforms standard NPE (Papamakarios & Murray, 2016) on five of six tasks in both LPP and ACAUC; NPE only wins on the SIR benchmark (Task B) where misspecification is negligible. Against NPE-RS (Huang et al., 2023), which regularizes the NSE to match simulated and real data distributions, RoPE achieves better-calibrated posteriors (lower |ACAUC|) on tasks with significant misspecification (C, D, E, F), while NPE-RS can produce −∞ likelihoods on some tasks. RoPE also outperforms NNPE (Ward et al., 2022), which adds a Spike-and-Slab error model to NPE, particularly on the real-world Light Tunnel and Wind Tunnel tasks where the gap between simulation and reality is large. Against HVAE (Takeishi & Kalousis, 2021), applicable only to differentiable simulators (Tasks C and E), RoPE achieves superior LPP and ACAUC, with HVAE struggling to leverage the physics encoder effectively for pure parameter inference. The supervised baselines J-NPE and MLP improve with larger calibration sets and can match or exceed RoPE at very large calibration budgets, but they remain systematically overconfident (positive ACAUC) across all tested sizes, whereas RoPE maintains calibration from as few as 10 calibration examples.

## Relation to Prior Work

RoPE extends Neural Posterior Estimation (Papamakarios & Murray, 2016) by inserting an optimal transport coupling between simulated and real-world observations to model the misspecification gap, building on semi-balanced OT (Rabin et al., 2014) and entropy-regularized OT (Frogner et al., 2015). It departs from prior SBI-misspecification work (Ward et al., 2022; Huang et al., 2023; Schmitt et al., 2023), which focused on detecting misspecification or regularizing NPE, by reframing the problem as a sim-to-real transfer task solvable with a small labeled calibration set. The conditional independence assumption x_o ⊥ θ | x_s acts as an information bottleneck that, while limiting, regularizes the misspecification model and prevents shortcut learning from the calibration data.

## Why It Matters / Open Questions

RoPE provides the first practical framework that delivers calibrated, informative posteriors under severe simulator misspecification using only a small calibration set, with controllable trade-offs via γ (calibration vs. informativeness) and τ (prior confidence). The introduction of real-world benchmarks (Light Tunnel, Wind Tunnel) with ground-truth labels is a significant contribution to the SBI evaluation landscape. Key open questions include scaling to high-dimensional parameter spaces (curse of dimensionality in both fine-tuning and OT coupling), handling non-i.i.d. or noisy calibration sets, and amortizing the quadratic-cost OT step for large or streaming test sets.

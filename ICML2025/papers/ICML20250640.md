## Problem

Prior differential privacy techniques for adaptive data structures (e.g., private median) only handle numerical estimation problems that return a single scalar cost, leaving open whether they can be extended to search problems that must return an actual solution vector or point. The paper asks whether robust search data structures can be built with fewer than min{d, T} independent copies of an oblivious data structure, where T is the number of adaptive queries and d is the dimension.

## Input / Output

For ANN, the input is a static point dataset U ⊆ R^d (n points) and a sequence of T adaptively chosen query vectors, with the constraint that each query's cr-ball intersects at most s other points in U (Assumption 1.3); the output is a single point from U within distance cr of the query. For regression, the input is a design matrix U ∈ R^{n×d}, response vector b ∈ R^n, and adaptive turnstile updates to either U or b, with the condition number κ(U_t) bounded throughout; the output is a full (1+α)-approximate solution vector x_t ∈ R^d, not merely the regression cost. The key distinction from prior work is that the output is a high-dimensional vector or a specific data point, which can leak far more about internal randomness than a scalar.

## Method

For ANN, the paper introduces a differentially private selection framework: each oblivious LSH data structure outputs an indicator vector over all n points, and a REPORTONESIDEDNOISYARGMAX mechanism (with exponential noise) selects the most frequently found candidate. A novel sparse argmax mechanism exploits the s-sparsity of the count vector to achieve O(s log n) query time instead of O(n), and the advanced composition theorem reduces the number of data structures from T to Õ(√T · s). For regression, the paper extends the private median to a coordinate-wise mechanism (one private median per dimension, requiring Õ(√(Td)) sketches) and proves utility via a novel use of the ℓ_∞ guarantee of SRHT sketches (Price et al., 2017), which bounds the per-coordinate backward error and offsets the condition number blowup. For instances with large condition number, a bounded computation path technique (Ben-Eliezer et al., 2020) yields only logarithmic dependence on κ at the cost of linear dependence on T.

## Results

For adaptive ANN under Assumption 1.3 (sparse neighborhoods with parameter s), the paper reduces the number of independent LSH copies from min{d, T} to Õ(√T·s), achieving space Õ(√T·s·n^{1+ρ} + nd) and amortized preprocessing time Õ((s/√T)·n^{1+ρ}·d), at the cost of a Õ(s) factor in query time (s·n^ρ·d). For adaptive regression under Assumption 1.4 (condition number κ), the paper reduces from T copies to Õ(√T·d) sketches, achieving space Õ(√T·d^{2.5}·κ²/α²) and query time Õ(d^{ω+1}·κ²/α²). A second regression result (Theorem 1.10) achieves only logarithmic dependence on κ via the bounded computation path technique, at the cost of linear dependence on T.

## Baselines & Comparisons

The paper compares against two prior paradigms for handling adaptivity: (1) the T-copies approach, which prepares a fresh oblivious data structure per query, and (2) the d-copies (ε-net) approach, which prepares Õ(d) data structures and samples at query time. For ANN, this paper's method strictly dominates both when s < √T and s < d: it uses fewer copies (√T·s vs. T or d), has lower amortized preprocessing time ((s/√T)·n^{1+ρ}d vs. n^{1+ρ}d or (d/T)·n^{1+ρ}d), and lower update time (√T·s·n^ρ d vs. T·n^ρ d or n^ρ d²), at the cost of a Õ(s) factor in query time. For regression, the comparison is against T copies and nd copies; this paper achieves sublinear-in-T space (√T·d^{2.5}κ²/α² vs. Td²/α² or nd³/α²) and sublinear-in-T update time (√(Td)·(nnz(v_t)+d³+d²κ²/α²) vs. T·(nnz(v_t)+d³+d²/α²) or nd·(nnz(v_t)+d³+d²/α²)), with the tradeoff being a κ² factor in query time. The d-copies approach is suboptimal when d ≈ T or d ≫ T (common in convex optimization), which is precisely the regime where this paper's √T·s copies provide the largest improvement.

## Relation to Prior Work

This paper extends the differential privacy framework for adaptive data structures from Hassidim et al. (2022) and Beimel et al. (2022), which showed that O(√T) oblivious copies suffice for numerical estimation problems, to the fundamentally harder setting of search problems where the output is a point or vector rather than a scalar. For ANN, it introduces a novel sparse argmax mechanism that makes differentially private selection efficient over sparse count vectors, building on the REPORTNOISYMAX mechanism. For regression, it upgrades the coordinate-wise private median to output solution vectors by leveraging the ℓ∞ guarantee of SRHT sketching (Price et al., 2017), resolving an open question from Cherapanamjeri et al. (2023) who could only output the regression cost. The high condition number case draws on the bounded computation path technique of Ben-Eliezer et al. (2020).

## Why It Matters / Open Questions

The paper establishes that the gap between estimation and search in the adaptive setting can be bridged with only a polylogarithmic or polynomial overhead in the sparsity parameter s, yielding O(√T·s) copies instead of min{d,T}. This has direct applications to online weighted matching with adversarial arrivals and terminal embeddings, where the space savings are substantial. Key limitations include the structural assumptions required (sparse neighborhoods for ANN, bounded condition number for regression), and the approach does not yet handle the fully general case where both the dataset is dense and the condition number is large simultaneously. Open questions include whether the sparse neighborhood assumption can be replaced by weaker geometric conditions, and whether the ℓ∞-based private median extends to other structured search problems beyond ANN and regression.

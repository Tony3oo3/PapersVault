## Problem

Existing offline RL methods lack theoretical guarantees for zero-shot generalization (ZSG) to unseen environments, and prior empirical approaches are either restricted to narrow settings (e.g., observation-only variation or imitation learning) or require additional interactions with downstream tasks. The paper proves that vanilla offline RL without context information fundamentally cannot generalize—showing the merged dataset is indistinguishable from an 'average MDP'—and asks whether provable offline RL with ZSG is achievable.

## Input / Output

The algorithms consume n offline datasets (one per contextual MDP, each containing K trajectories of H steps with state-action-reward tuples), explicit context labels identifying the source environment of each trajectory, and a policy class Π (for PERM). The output is a single Markovian policy π = {π_h}_{h=1}^H that generalizes across environments, accompanied by a suboptimality gap decomposed into a supervised learning error (scaling as √(log N / n) where N is the policy covering number) and a reinforcement learning error (scaling with the uncertainty quantifier evaluated along the optimal policy's trajectory in each environment).

## Method

Both PERM and PPPO are built on a Pessimistic Policy Evaluation (PPE) subroutine that, for each environment i, uses an oracle to obtain an empirical Bellman operator and an uncertainty quantifier Γ_{i,h}, then constructs pessimistic Q-values as min{H−h+1, B̂V − Γ}^+. PERM (model-based) maximizes the average pessimistic value (1/n)Σ V̂_{i,1}^π(x_1) over the policy class, requiring n separate critic functions. PPPO (model-free) iteratively updates a single policy via KL-regularized proximal optimization using pessimistic Q-values from the previous environment, maintaining only n policies rather than n models. The key insight is that per-environment pessimism—rather than a single merged model—preserves environment-specific structure, enabling the policy to generalize; the suboptimality bound separates into an SL error controlled by the number of environments and an RL error controlled by dataset coverage of the optimal policy.

## Results

The paper provides theoretical suboptimality guarantees for two proposed algorithms. PERM achieves a suboptimality gap bounded by √(log(N_{(Hn)^{-1}}^Π)/n) + (2/n)ΣᵢΣₕ E_{i,π*}[Γ_{i,h}(s_h,a_h)|s_1=x_1], where the first term is a supervised learning error and the second is an RL coverage error. PPPO achieves a similar bound with √(log|A|·H²/n) replacing the covering number term. Under a well-explored behavior policy assumption, both algorithms achieve an O(n^{-1/2} + K^{-1/2}·C*_n) convergence rate to the optimal policy, where C*_n = (1/n)Σᵢ c_i^{-1/2} is a mixed coverage parameter.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or dataset evaluations. The key comparison is against the impossibility result in Proposition 4, which shows that vanilla offline RL (e.g., PEVI) applied to a merged dataset without context information converges to the optimal policy of an 'average MDP' and cannot achieve ZSG — the suboptimality gap does not vanish even as data size grows to infinity (Theorem 22). The proposed PERM and PPPO are the first offline RL methods to provably achieve the ZSG property, with suboptimality gaps that decay as O(n^{-1/2}) in the number of environments. The paper also contrasts with prior multi-task offline RL work (Bose et al., 2024; Ishfaq et al., 2024) that requires additional interactions with downstream tasks, and with imitation learning approaches (Yang et al., 2023) that are confined to specific settings. No head-to-head empirical comparisons are provided.

## Relation to Prior Work

This paper extends the pessimism principle from single-environment offline RL (Jin et al., 2021, PEVI) to a multi-environment contextual MDP setting, combining it with the empirical risk minimization framework from online RL generalization (Ye et al., 2023) and the KL-regularized policy update structure from optimistic PPO (Cai et al., 2020). The key conceptual departure is replacing optimism (appropriate for online exploration) with pessimism (necessary for offline distribution shift) while maintaining per-environment Q-function estimates to preserve context information. Unlike prior multi-task offline RL work (Bose et al., 2024; Ishfaq et al., 2024) that relies on representation learning and requires downstream interactions, this paper achieves zero-shot generalization with no further environment access, and unlike prior online RL generalization studies that lack theoretical guarantees, it provides provable suboptimality bounds.

## Why It Matters / Open Questions

This is the first theoretical framework providing provable zero-shot generalization guarantees for offline RL, filling a gap where prior work was either purely empirical (Mediratta et al., 2023; Mazoure et al., 2022) or required additional downstream interactions. The impossibility result (Proposition 4) showing that context-free offline RL converges to an 'average MDP' policy that can be arbitrarily suboptimal is a clean and important negative result that justifies the need for context-aware algorithms. Key limitations include the i.i.d. environment sampling assumption, the requirement to maintain n separate models (mitigated by the m-group variant), and the gap between PERM's covering-number-dependent bound and PPPO's action-space-dependent bound remaining ununified. Future directions include relaxing the i.i.d. assumption and extending to few-shot adaptation settings.

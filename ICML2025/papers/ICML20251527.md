## Problem

Existing temporal graph learning (TGL) methods assume a fixed set of node classes, while graph continual learning (GCL) methods assume old-class data remains static over time. Neither assumption holds for real-world temporal graphs where new classes emerge AND old-class data distributions evolve. The paper defines temporal graph continual learning (TGCL) as the problem of efficiently updating a model to handle both emerging new classes and evolving old-class data without catastrophic forgetting or prohibitive retraining cost.
![Teaser figure](../imgs/ICML20251527/cropped_page0_idx0.webp)

## Input / Output

At each new period T_N, the method consumes the current period's temporal graph events split into new-class (G_N^new) and old-class (G_N^old) subsets, along with the previously trained model h̃_{N-1}. Rather than training on all old-class data, it greedily selects two small subsets: G_N^sub (size m, for classification learning) and G_N^sim (size m', for distribution alignment reference). The output is an updated node classification model h̃_N that assigns class labels to all nodes in the current period, evaluated via average precision (AP) across all class sets and average forgetting (AF) relative to a joint-training upper bound.

## Method

LTF derives an upper bound on the classification error when approximating full old-class data with a subset (Theorem 3.1), decomposing it into three terms: the subset model's error on old data, the HΔH distribution discrepancy between old and subset data, and the prediction disagreement between the target model and subset model. This bound is transformed into a tractable subset selection objective (Eq. 8) that jointly minimizes empirical classification error and squared MMD distribution discrepancy, solved via greedy submodular optimization with data partitioning to reduce complexity from O(r²) to O(r²/W²). During training, a distribution alignment loss l_dst aligns the embedding distribution of G_N^sub with G_N^sim using a simplified MMD with stop-gradient on the reference set, reducing complexity to O(m·m'). The total training objective combines new-class classification error, subset classification error, and the distribution regularization weighted by β, making the method backbone-agnostic (validated on TGAT and DyGFormer).

## Results

On the TGAT backbone, LTF achieves the best AP among all continual learning methods across all three datasets: 0.0682 (Yelp), 0.0871 (Reddit), and 0.1110 (Amazon), while also attaining the lowest AF (0.0195, 0.0474, 0.0165 respectively). On the DyGFormer backbone, LTF further improves to AP of 0.0681 (Yelp), 0.1134 (Reddit), and 0.1253 (Amazon) with AF as low as 0.0081 on Reddit. LTF approaches the Joint upper bound (e.g., 0.1110 vs. 0.1477 AP on Amazon/TGAT) while running 1.8× faster than Joint (72.94s vs. 128.71s) and 4.4× faster than OTGNet on Amazon (72.94s vs. 709.49s).

## Baselines & Comparisons

LTF outperforms all seven baselines on both AP and AF across all three datasets and both backbones. Against the closest competitor OTGNet (the only other method designed for temporal graphs), LTF improves AP by 0.0034 on Yelp, 0.0003 on Reddit, and 0.0079 on Amazon (TGAT), while reducing training time by 12.6× on Yelp (25.05s vs. 316.15s) and 9.7× on Amazon (72.94s vs. 709.49s). On the DyGFormer backbone where OTGNet is not applicable, LTF beats the next-best method URCL by 0.0097 AP on Yelp (0.0681 vs. 0.0584), 0.0232 on Reddit (0.1134 vs. 0.0902), and 0.0164 on Amazon (0.1253 vs. 0.1089). Regularization-based methods (EWC, LwF) consistently underperform replay-based methods, confirming that data replay is critical for maintaining old-class knowledge in temporal graphs. LTF remains within 25% of the Joint upper bound in AP (e.g., 0.1110 vs. 0.1477 on Amazon/TGAT) while being 1.8× faster, whereas Finetune suffers severe forgetting (AF up to 0.1550) and achieves less than half the AP of LTF on every dataset.

## Relation to Prior Work

This paper carves out a new problem space (TGCL) that sits between temporal graph learning (TGL), which assumes a fixed class set, and graph continual learning (GCL), which assumes static old-class data. Methodologically, it repurposes domain adaptation theory (Ben-David et al., 2010) to derive a classification error upper bound that connects subset-based learning to full-data learning, then translates this bound into a submodular subset selection objective using MMD-based distribution discrepancy. The selective learning framework builds on experience replay ideas from GCL (OTGNet, ER, SSM) but departs by explicitly accounting for the temporal evolution of old-class data distributions rather than treating them as frozen snapshots.

## Why It Matters / Open Questions

The TGCL formulation captures a realistic deployment scenario where both new classes emerge and old-class data distributions shift over time, a gap that neither TGL nor GCL addresses. The theoretical upper bound provides principled justification for subset selection in a setting where prior work relied on heuristics. However, the performance gap to the Joint upper bound remains substantial (e.g., ~15% relative AP loss on Yelp), and the method is validated only on node classification with two backbone architectures. Open questions include whether the approach extends to link prediction or other temporal graph tasks, how it scales to billion-edge graphs, and whether the distribution alignment loss can be made more efficient for very large memory budgets.

## Problem

Multiobjective submodular maximization—finding a single set that simultaneously maximizes multiple submodular objectives—lacks a practical algorithm with the best-known (1−1/e−ε) approximation guarantee. Existing approaches either achieve only a weaker (1−1/e)² ≈ 0.40 ratio in the discrete setting or rely on the multilinear extension, whose evaluation is computationally intractable for large instances. This paper closes the gap by providing the first scalable algorithm that attains the near-optimal guarantee without any continuous relaxation.

## Input / Output

The algorithm takes k monotone submodular set functions f_c over a shared universe V of n elements, a cardinality budget B, and a failure probability δ, and returns a subset S ⊆ V with |S| ≤ B maximizing min_c f_c(S). It requires B ≥ 108k/ε³ log k (budget large relative to the number of colors) and does not require knowledge of the optimal value OPT. The running time is O(nB³/ε² · k log k log(1/δ)) with O(nBk log(1/δ)) function evaluations, making it applicable to graphs with over 10,000 nodes.

## Method

The core mechanism is a discrete greedy procedure that, in each of B iterations, solves a linear program to obtain a probability distribution over elements guaranteeing expected marginal progress for every color simultaneously, then samples a single element from that distribution. A novel concentration argument based on a multiplicative Azuma inequality (Kuszmaul & Qi, 2021) shows that with high probability all k colors achieve the (1−1/e−ε) bound, avoiding the need for continuous relaxation and rounding. The LP is solved approximately via multiplicative weights updates formulated as a two-player zero-sum game, with lazy evaluations reducing the number of marginal gain queries. A pre-processing step greedily removes elements with disproportionately large singleton gains to tighten the concentration bound, and independent repetitions amplify the success probability to 1−δ.

## Results

Across three problem types (max-k-cover on Kronecker/Barabási-Albert/Erdős-Rényi graphs, fair centrality maximization on Amazon co-purchasing networks up to 10,378 nodes, and fair influence maximization on a 500-node Antelope Valley network), the proposed LP Greedy algorithm consistently achieves the highest min-objective value among all compared methods while requiring fewer function evaluations. On the large-scale fair centrality instances (e.g., Arts, Crafts & Sewing with n=5,051 nodes, k=2), the algorithm outperforms both UDWANI MWU and SATURATE in objective value and evaluation count, largely because it avoids the binary search over OPT that those baselines require. On fair influence maximization (k=5, ethnicity attribute), the method surpasses the continuous Frank-Wolfe algorithm of Tsang et al. (2019), with the gap widening at larger budgets.

## Baselines & Comparisons

Against Udwani's MWU algorithm (NeurIPS 2018), which provides a (1−1/e)² ≈ 0.40 approximation, the proposed LP Greedy wins on both objective value and number of function evaluations across all three problem types; Udwani's method requires O(kn⁸) evaluations versus the proposed O(nBk log(1/δ)). Against the SATURATE bi-criteria heuristic (Krause et al., JMLR 2008), the proposed method achieves higher min-objective values with fewer evaluations, since SATURATE requires an outer binary search over an OPT guess that adds overhead. Against the continuous Frank-Wolfe algorithm of Tsang et al. (IJCAI 2019) on fair influence maximization, the proposed method outperforms especially at larger budgets, and applies to any multiobjective submodular instance rather than being specialized to influence maximization with its efficient multilinear extension oracle. The ablation study (Figure 4) shows that 20 repetitions of the outer loop and a greediness factor φ ∈ [5, 15] yield the best practical performance, with diminishing returns beyond 20 repetitions.

## Relation to Prior Work

This paper settles an open question from Udwani (2018) by showing that the (1−1/e−ε) approximation for multiobjective submodular maximization can be achieved without the multilinear extension, which prior algorithms (Chekuri et al., 2010; Tsang et al., 2019) relied on and which is computationally impractical at scale. The algorithm builds on the greedy paradigm of Nemhauser et al. (1978) and the MWU framework of Arora et al. (2012), but introduces a novel concentration argument via a multiplicative Azuma inequality (Kuszmaul & Qi, 2021) to convert per-iteration expected progress into a high-probability guarantee across all colors simultaneously. The pre-processing step that eliminates high-marginal-gain elements is inspired by Udwani (2018) but is adapted to avoid requiring knowledge of OPT.

## Why It Matters / Open Questions

This is the first algorithm that combines the best-known approximation guarantee with practical scalability for multiobjective submodular maximization, enabling the first large-scale solutions to fairness problems like fair influence maximization and the newly introduced fair centrality maximization. The budget requirement B ≥ 108k/ε³ log k, while less restrictive than prior work, still limits applicability to settings where the budget substantially exceeds the number of objectives—a natural regime for many fairness applications but not universal. The concentration-based analysis technique (discretizing a continuous relaxation via sampling + martingale concentration) may generalize to other multiobjective or robust optimization settings where continuous relaxations are intractable.

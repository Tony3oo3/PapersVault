## Problem

Model merging via task arithmetic suffers from performance degradation as the number of merged models grows, and existing few-shot merging methods either incur prohibitive memory costs at scale or fail to fully exploit the distillation perspective. The paper first proves that data-agnostic merging algorithms can have arbitrarily bad worst-case performance even for linear models, establishing the theoretical necessity of domain-specific data, then asks how to practically leverage that data to merge models at scale.
![Teaser figure](../imgs/ICML20252775/cropped_page0_idx0.webp)

## Input / Output

The method consumes a pre-trained base model θ₀, T fine-tuned model weights θᵢ (each derived from θ₀), and a small unlabeled validation set Dᵢ per task (as few as 1–64 samples, no labels required). It outputs element-wise merging coefficients λ̂ᵢ⁽ˡ⁾ that share the full dimensionality of the model parameters, which are applied as θ₀ + Σ λ̂ᵢ ∘ (θᵢ − θ₀) to produce the merged model. The element-wise granularity is a key design choice over task-wise or layer-wise scalars, giving the merged model maximal expressive power to fit the distillation objective.

## Method

ProDistill reframes model merging as a teacher-student distillation problem where fine-tuned models serve as teachers and the merged model is the student, with the training objective being MSE alignment of intermediate-layer activations rather than output logits. The critical efficiency mechanism is progressive layer-wise training: instead of optimizing all layers end-to-end (which requires storing full-model task vectors, gradients, and optimizer states), ProDistill trains each layer's merging coefficients sequentially, caching only the current layer's parameters and propagating dual-path activations forward. The dual-input design feeds the merged model's own intermediate features z₁ and the fine-tuned model's features z₂ as separate inputs to each layer, which the paper shows is essential for high performance compared to single-input alternatives. This layer-wise decomposition reduces peak GPU memory to be independent of model depth, enabling the first training-based merging algorithm to scale beyond 10B parameters (LLaMA-2-13B). The paper also proves that this progressive approach outperforms its end-to-end counterpart DistillMerge, contradicting the common belief that layer-wise training hurts performance.

## Results

On 8 vision classification tasks (ViT-B-32), ProDistill achieves 86.04% average accuracy, surpassing the best baseline (AdaMerging, 79.28%) by 6.14% and remaining only 4% below individual fine-tuned models (90.52%). On 8 GLUE NLU tasks (RoBERTa-base), ProDistill reaches 0.7641 average metric, outperforming the best baseline (RegMean, 0.6980) by 6.61%. On 13B-parameter LLM merging (WizardMath + Code-Alpaca), ProDistill achieves 0.8288 normalized average across GSM8K, MATH, HumanEval, and MBPP, beating TIES-Merging (0.7868) and WIDEN (0.6769).

## Baselines & Comparisons

ProDistill consistently outperforms all seven baselines across vision, NLU, and LLM merging settings. On vision tasks, it beats the strongest baseline AdaMerging (79.28%) by 6.76 points and the training-free RegMean (79.15%) by 6.89 points; the data-agnostic Task Arithmetic (69.18%) and Fisher Merging (69.80%) lag far behind. On NLU tasks, ProDistill (0.7641) surpasses RegMean (0.6980) by 6.61 points, while Fisher Merging (0.5068) and AdaMerging (0.6332) degrade severely on low-class tasks like CoLA and STS-B. For 13B LLM merging, ProDistill (0.8288 Norm Avg) edges out TIES-Merging (0.7868) by 4.2 points and substantially outperforms WIDEN (0.6769) and Task Arithmetic (0.6711). Localize-and-Stitch (79.90% vision, 0.6425 NLU) is competitive on vision but falls well short of ProDistill on both modalities. The paper also shows ProDistill converges within ~10 epochs and uses significantly less GPU memory than end-to-end DistillMerge or AdaMerging, making it the first training-based merging method scaled beyond 10B parameters.

## Relation to Prior Work

This paper builds on the task vector framework of Ilharco et al. (2022) for model merging via weighted averaging, and on the progressive layer-wise training paradigm from Bengio et al. (2006). It departs from prior merging methods (RegMean, AdaMerging, Fisher merging) by reframing merging as a teacher-student distillation problem with element-wise merging coefficients and a novel dual-input mechanism that feeds separate merged and fine-tuned activations to each layer. Unlike training-free approaches like RegMean that solve linear equations, ProDistill is training-based but avoids end-to-end optimization by decomposing the objective layer-by-layer, and unlike entropy-based methods like AdaMerging, it uses feature-space alignment as its supervision signal.

## Why It Matters / Open Questions

The paper provides the first theoretical proof that data-agnostic model merging can have arbitrarily bad worst-case performance, establishing a principled justification for requiring even minimal domain-specific data. Practically, ProDistill is the first training-based merging algorithm scaled to 10B+ parameter models, with memory cost independent of model depth, making it viable for resource-constrained deployment of merged LLMs. Open questions include whether the dual-input design and element-wise coefficients generalize to merging models with different architectures or independently trained (non-fine-tuned) checkpoints, and whether the theoretical hardness results have tighter characterizations for specific model families beyond linear models.

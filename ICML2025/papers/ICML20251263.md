## Problem

Kernel density estimation (KDE) and similarity graph construction are fundamental to spectral clustering, but existing algorithms are static: they must be fully recomputed whenever the dataset changes. While dynamic KDE estimators exist for point-replacement settings, no prior work efficiently maintains KDE estimates for a set of query points under data point insertions, and no dynamic algorithm maintains a sparse approximate similarity graph with theoretical cluster-preservation guarantees.

## Input / Output

The method takes an initial set X of n₁ data points in R^d (with d = O(log n₁)), an initially empty set of query points Q, a kernel function k (e.g., Gaussian), and a stream of data point insertions. It produces (1±ε)-approximate KDE estimates μ̂_q for every maintained query point q, a sparse approximate similarity graph G with Õ(n) edges that preserves the cluster structure of the fully connected graph, and downstream spectral clustering assignments. The amortised update time per insertion is ε^{-2}·n^{o(1)}·cost(k) for KDE and n^{o(1)}·cost(k) for the graph, which for the Gaussian kernel gives n^{(1+o(1))/4}—sub-linear in the number of data points.

## Method

The dynamic KDE algorithm extends the CKNS importance-sampling framework by introducing a query-hash data structure: when a query point q is added, its hash values under all LSH functions are stored in dedicated buckets B*_H(q), so that when a new data point z arrives, the algorithm can recover exactly which query points' estimates must be updated by checking for collisions in these buckets. For the similarity graph, the algorithm builds a complete binary tree T over X where each internal node maintains a dynamic KDE data structure on its descendant leaves; each vertex x_i stores L = Õ(log n) sample paths P_{x_i,ℓ} recording which internal nodes it visits when sampling neighbours. Upon inserting a new point z, UPDATEGRAPH places z as a new leaf, updates KDE estimators along the root-to-leaf path, identifies paths whose KDE estimates changed, and resamples only the affected edges—Lemma 4.6 shows the expected number of resampled paths is Õ(1), yielding the sub-linear update time. Edge weights are set to k(x_i, x_j)/ŵ(i,j) where ŵ depends on the minimum KDE estimate of the two endpoints, ensuring correct reweighting after a sequence of insertions.

## Results

For dynamic KDE (Table 1), the proposed algorithm achieves the lowest total running time across all five datasets, e.g. 306.4 s on MSD vs. 14,360 s for CKNS (47× speedup) while maintaining a comparable relative error (0.388 vs. 0.385). For dynamic similarity graph construction (Table 2), the algorithm achieves 21.2 s on blobs (3.4× faster than fully-connected) with identical NMI (1.000), and 1,403.5 s on CIFAR-10 (13.6× faster) with substantially better NMI (0.339 vs. 0.001 for fully-connected). The update time is empirically sub-linear in n, confirming the theoretical n^{0.25+o(1)} bound for the Gaussian kernel.

## Baselines & Comparisons

Against CKNS (Charikar et al., 2020), which re-computes all KDE estimates from scratch after each data insertion, the proposed dynamic algorithm is consistently faster: 47× on MSD (306 s vs. 14,360 s), 12.5× on Census (837 s vs. 10,472 s), and 37× on Covertype (152 s vs. 5,650 s), while achieving comparable or slightly higher relative error (e.g. 0.388 vs. 0.385 on MSD). Against the DYNAMICRS uniform-sampling baseline, the proposed method is slower in wall-clock time but dramatically more accurate on MSD (error 0.388 vs. 5.430) and competitive on other datasets. For the downstream similarity graph task, the proposed algorithm outperforms the fully-connected baseline by 3.4× on blobs (21.2 s vs. 72.8 s) with identical NMI (1.000), and by 13.6× on CIFAR-10 (1,404 s vs. 19,158 s) with substantially better NMI (0.339 vs. 0.001). Compared to the k-NN (k=20) baseline, the proposed method is faster on blobs (21.2 s vs. 383.6 s) and CIFAR-10 (1,404 s vs. 3,503 s) with equal or better NMI, though slightly slower on MNIST (1,470 s vs. 5,796 s for kNN — actually kNN is slower here too at 5,796 s) with lower NMI (0.523 vs. 0.812).

## Relation to Prior Work

This paper extends the static KDE framework of Charikar et al. (2020, CKNS) and the static approximate similarity graph construction of Macgregor & Sun (2023) into the dynamic setting where data points are inserted over time. While prior dynamic KDE work (Liang et al., 2022; Huang et al., 2024) handles only point replacements or low-dimensional fast Gauss transforms, and prior incremental spectral clustering methods lack theoretical guarantees or assume fixed vertex sets, this paper introduces the first dynamic KDE data structure that maintains (1±ε)-approximate estimates for an arbitrary set of query points under insertions, with update time independent of the number of query points. The dynamic similarity graph construction then composes this KDE structure with a complete binary tree to achieve sub-linear amortised updates while preserving cluster structure.

## Why It Matters / Open Questions

The key practical impact is enabling dynamic spectral clustering with provable cluster-preservation guarantees and sub-linear (n^{0.25+o(1)} for Gaussian kernel) update time, which is significantly faster than the Õ(n) cost of updating a fully-connected similarity graph. The independence of update time from the number of query points |Q| is a notable theoretical achievement that makes the approach scalable to large query sets. Limitations include handling only insertions (not deletions of data points), the assumption d = O(log n), and the focus on the Gaussian kernel (though the framework extends to other kernels with different cost parameters). Open questions include extending to general insertions/deletions, higher dimensions, and integrating with other graph-based clustering methods beyond spectral clustering.

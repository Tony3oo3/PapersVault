## Problem

Integrating ancestral constraints (path existence/absence) into differentiable structure learning remains an open challenge because (1) continuous relaxed characterizations of path existence are not equivalent to actual path existence for any single threshold value, and (2) the optimization process is sensitive to initial guesses and can introduce order-violating paths that prevent full constraint satisfaction. No prior work systematically addresses both issues in the continuous optimization setting.

## Input / Output

The method takes an observational data matrix D ∈ R^{d×n} and a binary path existence constraint mask A ∈ {0,1}^{d×d} (where A_{i,j}=1 encodes the requirement that a directed path from x_i to x_j must exist in the learned graph). It outputs a continuous weighted adjacency matrix W, which is thresholded at ε_0 to yield a binary DAG structure. Path existence constraints are incorporated as soft loss terms rather than hard equality constraints, because the path existence loss and acyclicity loss exhibit a provable gradient conflict that would prevent full optimization of either if both were enforced as equalities.

## Method

The paper proposes a two-stage framework. First, a binary-masked characterization p̂(W) = p̄(W) ∘ b(W) is introduced, where b(W) is a binary mask computed from the thresholded adjacency matrix that deactivates the ReLU-based path existence loss p̄(W) whenever a path already exists in G(W); this achieves an equivalent representation of path existence for sufficiently large path threshold ε, resolving the non-equivalence issue of the naive relaxation. Second, an order-guided optimization strategy is employed: the transitive closure of the path existence constraints yields a set of partial orders, which are enforced as path absence constraints (forbidding reversed paths) in an initial optimization pass to produce an order-consistent DAG W_o; this W_o then serves as the initialization for the full path existence-constrained optimization, preventing order-violating paths from being introduced by the acyclicity loss during the augmented Lagrangian process. The backbone solver (NOTEARS, DAGMA, or GOLEM) is used in both stages, with the path existence term added as a weighted loss in the second stage.

## Results

On the Sachs dataset, PE-NOTEARS-100 (full path existence constraints) consistently outperforms the NOTEARS baseline across all sample sizes. With 100 samples, PE-NOTEARS-100 achieves SHD=15 and F1=0.47, compared to NOTEARS's SHD=22 and F1=0.34. At the full 902-sample setting, PE-NOTEARS-100 reaches F1=0.54 and SHD=12, while NOTEARS plateaus at F1=0.41 and SHD=13. Notably, PE-NOTEARS-100 with only 100 samples (F1=0.47) surpasses NOTEARS trained on all 902 samples (F1=0.41), demonstrating the value of prior knowledge in reducing data requirements.

## Baselines & Comparisons

The paper compares PE-NOTEARS against the standard NOTEARS baseline (without path existence constraints) on the Sachs dataset. PE-NOTEARS consistently outperforms NOTEARS on all metrics (SHD, FDR, TPR, F1) across every sample size, with the gap widening as more path existence constraints are incorporated. The most striking result is that PE-NOTEARS-100 with only 100 samples achieves F1=0.47, exceeding NOTEARS trained on the full 902 samples (F1=0.41), indicating that ancestral constraints can substitute for additional data. On synthetic data (Figure 1), PE-NOTEARS also achieves lower SHD, lower FDR, and higher path recovery rate compared to both the NOTEARS baseline and ablation variants (PE-NOTEARS-zero, PE-NOTEARS-intuitive), confirming that both the binary-masked characterization and the order-guided initialization contribute to the improvement.

## Relation to Prior Work

This paper extends the NOTEARS framework for differentiable structure learning by integrating ancestral (path existence) constraints, building directly on the smooth acyclicity characterization of Zheng et al. (2018) and the partial-order-constrained formulation of Ban et al. (2024). It departs from Wang et al. (2024), who proposed a ReLU-based continuous relaxation for path existence, by proving that this relaxation is fundamentally non-equivalent to actual path existence for any threshold choice, and replacing it with a binary-masked characterization. The order-guided optimization strategy reuses the path-absence-based partial order enforcement from Ban et al. (2024) as an initialization step, creating a two-stage pipeline that had not been previously proposed for ancestral constraints.

## Why It Matters / Open Questions

This is the first systematic treatment of ancestral constraints in differentiable structure learning, filling a gap that has persisted since NOTEARS was introduced. The non-equivalence theorem is practically important because it invalidates the natural continuous relaxation that prior work (Wang et al., 2024) relied upon, meaning existing implementations of path-existence constraints in continuous optimization are theoretically unsound. Limitations include the computational overhead of the binary mask and the lack of an explicit mechanism to prevent order violations in the final optimization stage; the authors note that more efficient characterizations and handling of path absence constraints remain open. The approach could reduce experimental resource requirements in scientific discovery (e.g., biology, medicine) where abstract prior knowledge is common but direct causal edges are unknown.

## Problem

While it is known that any sufficiently stable algorithm (replicable, differentially private, etc.) must be randomized, the quantitative question of how many random bits are actually required remained open. This paper asks whether the randomness complexity of a statistical task is tightly controlled by its global stability — the best replication probability achievable by any deterministic algorithm — and whether this connection extends to differential privacy and to the agnostic PAC learning setting where prior error-independent bounds were shown impossible.

## Input / Output

The framework takes a statistical task specification (data domain X, output domain Y, and per-distribution accepted-solution sets G_D) together with a hypothesis class H of labelings, and produces explicit bounds on the number of shared random bits needed for replicability (certificate complexity) or differential privacy (DP complexity). For PAC learning specifically, the output is a characterization: a class has bounded randomness complexity if and only if it has finite Littlestone dimension d, with certificate complexity scaling as poly(d) + O(VC(H)·log(1/α)) and sample complexity exp(poly(d))·poly(α⁻¹, log(1/β)). The algorithms themselves are constructed as deterministic globally stable learners or as randomized replicable/DP learners with explicit bit budgets.

## Method

The core contribution is a 'weak-to-strong' boosting theorem proving C_Glob ≤ C_Rep ≤ C_Glob + 1 for any statistical task. The forward direction (replicability → global stability) amplifies a >1/2-replicable algorithm via majority voting over fresh samples to isolate a canonical heavy-hitter, then derandomizes by taking the plurality output over all random strings. The reverse direction (global stability → replicability) uses a discretized random thresholding procedure: estimate output probabilities empirically, select one of T ≈ 2^{C_Glob}/ρ thresholds uniformly at random from a fine grid, and output the first hypothesis (under a fixed ordering) whose empirical probability exceeds the chosen threshold — with high probability the selected threshold avoids all heavy-hitter boundaries, yielding a fully replicable output. For differential privacy, the paper constructs a bounded-support DP algorithm via DP Selection over a database of heavy-hitter estimates, then applies Canonne et al.'s bounded-support approximation lemma to reduce the random-bit count to log(1/η) + log(1/ε) + log(1/δ) + Õ(1). The agnostic learning result combines an agnostic-realizable reduction (running a realizable globally stable learner over all labelings of an unlabeled sample) with a frequency-based pruning step that retains only hypotheses appearing Ω(ηT) times across T independent runs, controlling the output list size to 1/η · n^{O(VC(H))}.

## Results

The paper proves a near-tight equivalence between global stability and certificate complexity: C_Glob ≤ C_Rep ≤ C_Glob + 1 (Theorem 2.1), meaning the randomness needed for replicability is essentially the inverse log of the best deterministic replication probability. For agnostic PAC learning (Theorem 2.4), a class with Littlestone dimension d has certificate complexity poly(d) + O(VC(H)·log(1/α)) and sample complexity exp(poly(d))·poly(α^{-1}, log(1/β)), resolving an open question of Chase et al. (STOC 2024). The paper further establishes that a class has bounded randomness complexity if and only if it has finite Littlestone dimension, with the randomness scaling at worst O(log(1/α)) in the excess error.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or empirical comparisons. The key 'comparison' is between prior stability bounds and the new results: in the realizable PAC setting, prior work (Bun et al. 2020; Ghazi et al. 2021a) achieved g-stable complexity 2^{O(d)} independent of error, while in the agnostic setting Chase et al. (STOC 2024) proved no error-independent bound is possible and left open whether an error-dependent bound exists. This paper resolves that question affirmatively with certificate complexity poly(d) + O(VC(H)·log(1/α)), which is essentially the realizable bound up to a VC-dimension factor. An independent concurrent result by Blonda et al. (2025) achieves a weaker exp(d) + poly(α^{-1}) bound for the same problem. The paper also provides the first randomness-efficient replicable (and globally stable) algorithms for learning k-dimensional affine subspaces and γ-margin halfspaces, where prior methods either did not exist or required unbounded randomness.

## Relation to Prior Work

This paper unifies three previously separate complexity measures in algorithmic stability—global stability (Bun et al., 2020; Chase et al., 2023), certificate complexity (Dixon et al., 2023), and DP complexity (Canonne et al., 2024)—by proving tight 'weak-to-strong' boosting theorems showing they differ by at most a constant number of random bits. The agnostic learning result builds on the agnostico-realizable reduction framework of Hopkins et al. (2022) and the realizable stability bounds of Ghazi et al. (2021a), while the DP transforms leverage the DP Selection primitive (Korolova et al., 2009) and the perfect generalization equivalence (Ghazi et al., 2024). The key departure from prior work is the randomness-efficient discretization of the stability-to-DP transform, which avoids the unbounded randomness of earlier correlated-sampling-based reductions.

## Why It Matters / Open Questions

The paper resolves an open question of Chase et al. (2024) by showing that finite Littlestone dimension is both necessary and sufficient for bounded randomness complexity in agnostic PAC learning, with only O(log(1/α)) dependence on excess error. The tight off-by-one-bit equivalence between global stability and certificate complexity provides a clean theoretical foundation for understanding when randomized stability is fundamentally necessary. Open questions remain: the exact quantitative relationship between DP complexity and global stability (current bounds have polynomial sample blowup), whether subsampling in DP can be derandomized to save O(log(T/ε)) bits, and whether simultaneously sample-efficient and randomness-efficient replicable learners exist for agnostic learning.

## Problem

Existing conditional conformal prediction methods face a fundamental trade-off: Mondrian conformal prediction provides coverage guarantees over disjoint groups defined jointly on covariates and labels, while overlapping-group methods (Gibbs et al., Jung et al.) restrict group functions to depend only on covariates. Real-world subpopulations of interest—such as protected demographic attributes in fairness—naturally overlap and are often defined jointly on both covariates and labels, leaving a gap in the coverage guarantees available for these settings.

## Input / Output

The method takes a base predictor f, a calibration dataset of n (X, Y) pairs, a non-conformity score function S, and a user-specified basis Φ: X×Y→R^d that encodes the desired group structure (binary indicators for overlapping groups, or conditional probabilities P[Z∈G|φ(X,Y)] for fractional/unobserved-attribute groups). It outputs a prediction set function C(X; ε) ⊆ Y where the inclusion threshold q̂(X, y) varies with both the test covariate and the candidate label y, making set construction non-trivial for large or continuous label spaces. A randomized score S̃(X,Y,ε) is used to break ties in quantile regression while preserving distribution-free guarantees.

## Method

Kandinsky Conformal Prediction solves a single quantile regression—minimizing the average pinball loss over the vector space W = {Φ(·)^T β : β ∈ R^d}—to produce a quantile function q̂: X×Y→R that simultaneously calibrates coverage across all groups in W. At test time, label y is included in the prediction set if its randomized score S̃(X_{n+1}, y, ε) ≤ q̂(X_{n+1}, y). The key mechanism is that by parameterizing the quantile function as a linear combination of group basis functions, overlapping and fractional group memberships are handled jointly in one optimization rather than requiring separate per-group regressions. Theoretically, the method achieves a minimax-optimal high-probability conditional coverage error of O(√(d/n) + d/n), improving over the O((d log n/n)^{1/4}) rate of prior overlapping-group methods. The framework also extends to distribution shift: if the Radon-Nikodym derivative dP_T/dP_D belongs to W, valid coverage is maintained under that shift, generalizing prior results that only handled covariate shift.

## Results

On ACSIncome (regression over 31 US states as groups), Kandinsky conformal prediction achieves the best group average coverage deviation across 100 runs, with the FY variant (using predictor output + label) slightly outperforming the XY variant (using covariates + label). Both Kandinsky variants maintain stable coverage deviation as the number of groups increases, while all baselines exhibit larger gaps. On CivilComments (classification with 16 overlapping demographic groups), Kandinsky achieves the best group average coverage deviation when the calibration set contains over 500 samples per group, and generates prediction sets with conditional miscoverage closest to the target 0.1 level for most groups while maintaining moderate set sizes. The paper presents results as distributions over 100 runs (box plots) rather than single-point estimates, with target miscoverage set at α = 0.1.

## Baselines & Comparisons

Kandinsky conformal prediction outperforms all three baselines on group average coverage deviation on both datasets. Against split conformal prediction (Papadopoulos et al., 2002), which provides only marginal coverage with no group-conditional guarantees, Kandinsky achieves substantially tighter per-group coverage. Against class-conditional conformal prediction (Lofström et al., 2015), Kandinsky wins on CivilComments when calibration exceeds ~500 samples per group, though class-conditional is competitive at 250 samples per group; however, class-conditional's coverage deviation does not improve with larger sample sizes because it considers only label-defined groups rather than the full set of overlapping demographic groups. Against conservative conformal prediction (Barber et al., 2021), which assigns the most conservative (largest) prediction set to points in multiple groups, Kandinsky achieves better-calibrated coverage with smaller prediction sets. On ACSIncome, Kandinsky also achieves the minimum difference between maximum and minimum miscoverage across groups, indicating more uniform coverage than any baseline.

## Relation to Prior Work

This paper unifies and extends two prior lines of work on conditional conformal prediction: Mondrian conformal prediction (Vovk et al., 2003), which provides coverage guarantees over disjoint partitions of X×Y, and the overlapping-group methods of Gibbs et al. (2023) and Jung et al. (2023), which handle overlapping subgroups but restrict group functions to depend only on covariates X. Kandinsky conformal prediction generalizes both by allowing overlapping and fractional group memberships defined jointly on (X, Y), with the key algorithmic step being a single quantile regression (pinball loss minimization) over the vector space spanned by group indicator functions. The framework subsumes Mondrian, class-conditional, and covariate-conditional conformal prediction as special cases, and extends distribution-shift guarantees from covariate shift to general joint X×Y shifts via Radon-Nikodym derivatives in the weight function class.

## Why It Matters / Open Questions

The framework addresses a practical gap in algorithmic fairness where protected subgroups (e.g., race × gender) naturally overlap, and in distribution shift settings where both covariates and labels may change between calibration and test. The minimax-optimal O(n_G^{-1/2}) rate and the computational efficiency of a single quantile regression (versus per-instance regression in Gibbs et al.) make it a strong default for group-conditional coverage. Open questions include the cost of estimating the fractional group basis functions (requiring a separate classifier), the computational expense of the test-time Algorithm 3 variant, and whether the continuous-distribution assumption on scores conditional on Φ holds in practice for discrete or heavily tied score functions.

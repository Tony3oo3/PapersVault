## Problem

Existing neurosymbolic frameworks face a fundamental scalability trade-off: CPU-based systems like Scallop avoid GPU memory issues but suffer from unbatched, sequential symbolic computation, while GPU-based systems like Logic Tensor Networks ground all symbols as tensors and hit combinatorial memory explosions as problem complexity grows. No prior framework can simultaneously handle complex symbolic programs (with recursion, black-box functions, and large symbol spaces) and large deep-learning-scale datasets within practical training time.

## Input / Output

The framework consumes task-specific inputs—N MNIST digit images, sequences of handwritten digit/operator images, maze images with dots and curved lines, text passages describing family relationships, or 3.2-second gameplay video clips paired with text captions—and produces a probability distribution over a discrete output space (digit sums, formula results, path connectivity, kinship labels, or text-video alignment scores). Critically, the neural perception model outputs logits over a fixed symbol vocabulary, which are wrapped into Distribution objects that pair each discrete symbol (an arbitrary Python object) with its corresponding batched logit tensor, forming the interface between the neural and symbolic components.

## Method

DOLPHIN introduces a unified representation where Distribution objects map discrete symbols (stored as Python objects on CPU) to tags (PyTorch tensors on GPU), enabling symbolic manipulations to run flexibly on CPU while probabilistic computations are vectorized on GPU. Five Pythonic primitives—APPLY, FILTER, APPLYIF, UNION, and GETPROBS—allow programmers to express complex symbolic programs including recursion and black-box functions (e.g., Python's eval) without managing underlying tensor operations. The key differentiator is a set of pluggable, vectorized provenance semirings (DAMP and DTKP-AM) that define how tags are conjuncted and disjuncted during symbolic reasoning, with DTKP-AM providing a novel GPU-efficient approximation of Differentiable Top-K Proofs that tracks up to k proofs per symbol as 2D tensors. Because tags remain PyTorch tensors throughout the symbolic program, gradients flow end-to-end via PyTorch autograd, and batched tag computations exploit GPU parallelism while CPU-side symbol operations are shared across the entire batch rather than repeated per sample.

## Results

Across 13 benchmarks spanning text, image, and video tasks, DOLPHIN converges 1.71x to 62x faster than baselines while achieving state-of-the-art accuracy. On the most complex benchmarks (HWF-19, Path-256, Mugen-5K), baselines like Scallop fail to converge within 10 hours, while DOLPHIN completes training in under 5.5 hours. DOLPHIN achieves up to 20% accuracy gain over the second-best method on HWF and 33% on PathFinder at the largest dataset versions. The per-epoch speedup reaches up to 280x (HWF-19 vs. Scallop), enabling DOLPHIN to train for significantly more epochs within the same wall-clock budget.

## Baselines & Comparisons

Against Scallop (the primary CPU-based neurosymbolic baseline), DOLPHIN wins on all 12 benchmarks in training time, with speedups ranging from 1.71× (Path-32) to 47.18× (SumN-15); on accuracy, DOLPHIN matches or exceeds Scallop on all benchmarks except CLUTRR where it is slightly lower. Against LTN (GPU-based tensor grounding), DOLPHIN is 1.72× faster on SumN-5, while LTN runs out of memory entirely on SumN-10 and SumN-15 due to combinatorial explosion of grounded symbols. Against ISED (sampling-based), DOLPHIN is 5.56× to 62.41× faster across SumN and HWF benchmarks, with the largest gap on SumN-15 where ISED requires 9,800s versus DOLPHIN's 157s. Against IndeCateR+ (another sampling-based method), DOLPHIN is 3.49× to 7.74× faster, with the advantage growing on longer HWF sequences (5.51× on HWF-7 vs. 2.57× on HWF-15). Overall, DOLPHIN's hybrid CPU-symbolic/GPU-probabilistic design consistently outperforms both CPU-bound (Scallop) and GPU-bound (LTN) approaches, particularly as problem complexity increases.

## Relation to Prior Work

DOLPHIN extends the neurosymbolic programming paradigm established by Scallop (Li et al., 2023) and the provenance semiring framework (Green et al., 2007), specifically building on the Differentiable Top-K Proofs (DTKP) provenance introduced by Huang et al. (2021). It departs from CPU-bound frameworks like Scallop and DeepProbLog by vectorizing probabilistic computations on GPU while retaining symbolic manipulations on CPU, and from GPU-only frameworks like Logic Tensor Networks and LYRICS by avoiding the combinatorial memory explosion of grounding all symbols as tensors. The key architectural contribution is the Distribution abstraction that bridges PyTorch tensors (tags on GPU) with arbitrary Python objects (symbols on CPU), enabling end-to-end differentiability within standard PyTorch pipelines.

## Why It Matters / Open Questions

DOLPHIN addresses a practical bottleneck in neurosymbolic learning: existing frameworks either exhaust GPU memory (LTN) or suffer from CPU-bound sequential execution (Scallop) as problem complexity grows, making many realistic tasks intractable within reasonable training budgets. The vectorized DTKP-AM provenance is a notable technical contribution, showing that an add-mult approximation of weighted model counting preserves sufficient semantics for accurate training while enabling GPU parallelism. Limitations include the requirement for batched programming, lack of support for generative models (e.g., causal LLMs), and no handling of non-deterministic symbolic programs, all flagged as future work. The framework's tight PyTorch integration positions it as a practical tool for the broader deep learning community to incorporate symbolic reasoning without leaving their existing pipelines.

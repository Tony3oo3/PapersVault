## Problem

Classical r-adaptive meshing methods (e.g., Monge-Ampere) solve expensive nonlinear PDEs to relocate mesh points and optimize only an upper bound on the FEM error, while prior ML surrogates (e.g., UM2N) accelerate these classical solvers but inherit the same indirect error proxy. No existing approach directly minimizes the FEM solution error with a learned mesh deformer, and no prior method simultaneously outperforms classical solvers in accuracy while retaining ML-level inference speed.

## Input / Output

The method takes as input a regular (undeformed) mesh with node coordinates, the Frobenius norm of the Hessian of the FEM solution on that mesh (recovered via a weak formulation for piecewise-linear elements), and the mesh connectivity graph, all concatenated into a per-node feature matrix. It outputs relocated mesh point coordinates that preserve the original topology. The architecture operates on both structured grids and unstructured triangulations in 2D and 3D, and via its inductive GNN structure can perform super-resolution inference on meshes far larger than those seen during training (e.g., trained on 15×15, deployed on 150×150).

## Method

G-Adaptivity replaces the graph-attention averaging of prior mesh-movement GNNs with a diffusion-based deformer (Diffformer): at each layer, node positions evolve under a row-stochastic weighted graph Laplacian ODE solved by explicit Euler integration (32 steps, dt=0.1), which provably preserves element orientation and prevents mesh tangling (Theorem 4.2). Training is unsupervised and differentiable: Firedrake's pyadjoint computes shape derivatives of the FEM L² error with respect to mesh coordinates in a single adjoint solve, enabling direct backpropagation of the true FEM error (rather than an interpolation-error upper bound) through the GNN. The full loss combines this FEM error with an equidistribution regularizer that enforces uniform monitor-function density across elements, biasing the learned diffusion toward both error reduction and mesh regularity. The network uses 4 stacked Diffformer blocks with a shared graph-transformer encoder for the Hessian-based feature embedding, and the same hyperparameters transfer across all tested PDEs without per-problem tuning.

## Results

On the Poisson Square benchmark, G-Adapt achieves 21.01% L² error reduction in 88 ms, outperforming classical Monge-Ampere (MA) by 66% in error reduction (12.69%) while being 43× faster (3780 ms). On the Poisson Convex Polygon, G-Adapt reaches 16.84% ER in 55 ms versus MA's 10.97% in 4446 ms. For time-dependent Burgers' equation (10-step remeshing), G-Adapt achieves 21.66% ER in 93 ms, surpassing MA's 12.28% in 11566 ms. On the 3D Poisson cube, G-Adapt attains 28.08% ER in 494 ms compared to MA's 12.71% in 41049 ms, and scales to 150×150 meshes (22,500 nodes) with 25.70% ER in 2555 ms versus MA's 17.96% in 115395 ms.

## Baselines & Comparisons

G-Adapt outperforms the classical Monge-Ampere (MA) method on every tested problem in terms of L² error reduction: 21.01% vs 12.69% on Poisson Square, 16.84% vs 10.97% on Poisson Convex Polygon, 27.17% vs 25.78% on Burgers' rollout, and 28.08% vs 12.71% on the 3D cube, while being 40–45× faster. Against the ML-based UM2N baseline (Zhang et al., 2024), G-Adapt achieves substantially higher error reduction (21.01% vs 6.83% on Poisson Square; 16.84% vs 3.12% on Poisson Polygon) at comparable inference times (88 ms vs 70 ms). On the Navier-Stokes flow-past-cylinder problem, MA does not converge on the multiply connected domain, while G-Adapt achieves 26.36% ER in 49 ms, slightly outperforming UM2N-G (25.55% in 30 ms). The main trade-off is mesh quality: G-Adapt's aspect ratio (2.92 on Poisson Square) is slightly worse than MA's (2.11) but comparable to UM2N (1.99), and on Navier-Stokes the aspect ratio degrades to 3.51 versus UM2N's 1.65. The UM2N-G variant (UM2N trained with the paper's regularized loss) narrows the gap considerably, confirming that both the Diffformer architecture and the direct FEM-loss training contribute to the final performance.

## Relation to Prior Work

This paper departs from the dominant paradigm in r-adaptive meshing, where both classical Monge-Ampere (MA) methods and prior ML surrogates (M2N, UM2N) optimize a mathematical upper bound on FEM error (the interpolation error via Cea's lemma) rather than the FEM error itself. Architecturally, it builds on UM2N's graph transformer encoder and feature construction but replaces the graph attention network with a diffusion-based deformer (Diffformer) inspired by GRAND's graph neural diffusion framework, which provides a provable non-tangling guarantee. The key conceptual shift is coupling backpropagation through the GNN with Firedrake's automated adjoint to compute shape derivatives of the FEM solution error directly, eliminating the need for the interpolation-error-to-FEM-error estimates that underpin all prior approaches.

## Why It Matters / Open Questions

This is the first ML-based mesh relocation method to outperform the classical MA gold standard in FEM error reduction while retaining millisecond-scale inference, and it handles multiply connected and non-convex domains where MA solvers fail to converge. The provable non-tangling guarantee (Theorem 4.2) addresses a long-standing practical concern with velocity-based mesh movement. Open questions include scale generalization (the authors note performance degrades on out-of-distribution solution features), extension to higher-order elements and more complex PDE systems, and whether the direct-optimization advantage persists as problem dimensionality and nonlinearity increase. The Firedrake–PyTorch differentiable FEM pipeline demonstrated here is a reusable technical contribution for any differentiable PDE-constrained optimization.

## Problem

SAM 2's strong FG-FG matching ability is trained on video data where objects across frames share the same identity, but in Few-Shot Segmentation the support and query objects are visually different instances of the same class (intra-class gap). This makes the straightforward application of SAM 2 to FSS incompatible: the model's well-learned same-object matching parameters degenerate when forced to match different objects, leading to overfitting on base classes. The paper addresses how to properly leverage SAM 2's matching capability for FSS despite this fundamental mismatch.

## Input / Output

The method takes k (1 or 5) support images each paired with a binary foreground mask, plus a single query image, all at 512×512 resolution during training. DINOv2-B (86M) processes both support and query images to generate prior masks, while SAM 2-S (46M) handles feature encoding, memory operations, and mask decoding. The output is a binary segmentation mask for the query image, resized back to original dimensions for evaluation. The entire pipeline introduces no additional learnable parameters beyond fine-tuning 11M of SAM 2's existing parameters (memory encoder, memory attention, mask decoder).

## Method

FSSAM resolves the incompatible matching by converting different-objects matching (support↔query) into same-objects matching (query↔query) through three parameter-free modules. First, a Pseudo Prompt Generator uses DINOv2 features to produce two prior masks—FG (more complete foreground but more false background activations) and Disc (less complete foreground but fewer false activations)—which serve as pseudo mask prompts to encode query features into pseudo query memories via SAM 2's memory encoder. Second, Iterative Memory Refinement (3 iterations) selectively fuses additional FG features from the FG memory into the Disc memory, using support memory as a gate to prevent excessive BG feature propagation. Third, Support-Calibrated Memory Attention calibrates cross-attention scores during memory attention by computing cosine similarity between a support prototype and the query memory, then suppressing attention scores at positions where the memory is unlikely to be foreground, reducing BG-feature fusion by ~41.5%.

## Results

On PASCAL-5^i, FSSAM achieves 81.0% mIoU and 89.4% FB-IoU under 1-shot, and 85.4% mIoU and 91.9% FB-IoU under 5-shot, setting new state-of-the-art on both settings. On the more challenging COCO-20^i, FSSAM reaches 62.3% mIoU (1-shot) and 69.3% mIoU (5-shot), outperforming the best baselines by 1.9% and 2.5% respectively. On LVIS-92^i and PASCAL-Part, FSSAM also leads with 37.3% and 46.4% mIoU (1-shot), demonstrating strong generalizability beyond the training distribution.

## Baselines & Comparisons

FSSAM outperforms all 14 baselines across every dataset and shot setting. On PASCAL-5^i (1-shot), FSSAM's 81.0% mIoU surpasses the best foundation-based baseline FounFSS (76.8%) by 4.2% and the best classical method HMNet (70.4%) by 10.6%. On COCO-20^i (1-shot), FSSAM achieves 62.3% mIoU, beating VRP-SAM (60.4%) by 1.9% and GF-SAM (58.7%) by 3.6%, with the gap widening under 5-shot (69.3% vs. GF-SAM's 66.8%). The advantage is most pronounced on PASCAL-5^i 5-shot, where FSSAM leads GF-SAM by 2.8% (85.4% vs. 82.6%) and FounFSS by 4.7%. On the out-of-distribution benchmarks LVIS-92^i and PASCAL-Part, FSSAM (trained on COCO-20^i) beats Matcher by 4.3% and 3.5% respectively, confirming that the SAM 2-based matching generalizes well to unseen datasets. Notably, FSSAM uses only 132M total parameters (11M learnable), far fewer than Matcher (941M) and GF-SAM (941M), while achieving substantially higher accuracy.

## Relation to Prior Work

This paper extends the foundation-model-based FSS line (VRP-SAM, GF-SAM, Matcher, FounFSS) by identifying a fundamental incompatibility: SAM 2's memory attention is trained on same-object matching across video frames, whereas FSS requires matching visually different instances of the same class. Rather than retraining SAM 2's matching parameters (which would cause overfitting to base classes), the authors repurpose DINOv2 to generate pseudo query masks that convert the problem into same-object matching, aligning with SAM 2's pre-trained inductive bias. The iterative memory refinement and support-calibrated attention modules build on prior mask generation (Tian et al., AENet) and SAM 2's cross-attention architecture, adding parameter-free mechanisms to handle the imperfections of pseudo prompts.

## Why It Matters / Open Questions

The identification of same-object vs. different-object matching as the core bottleneck for adapting video foundation models to FSS provides a clear conceptual framework that could guide future work on leveraging other video or multi-frame foundation models for few-shot tasks. The approach is notably parameter-efficient (only 11M learnable parameters out of 132M total), suggesting that foundation models' pre-trained knowledge can be harnessed with minimal fine-tuning. However, the method still requires fine-tuning and depends on the quality of DINOv2-generated pseudo prompts, which remain imperfect; whether the same-object matching conversion generalizes to other foundation model architectures or to tasks beyond segmentation (e.g., detection, tracking) remains open.

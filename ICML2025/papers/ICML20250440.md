## Problem

Recent findings reveal that graph-learning methods can be outperformed by approaches that ignore graph structure, and that popular benchmark datasets occupy a peculiar region of graph space—yet no principled framework exists to evaluate whether a dataset actually tests the capabilities of graph-learning models. The classic evaluation setup (comparing models on a fixed dataset) cannot be inverted to assess dataset quality, and performance levels alone conflate dataset difficulty with dataset usefulness.

## Input / Output

The framework consumes collections of attributed graphs (node features as encoded by PyTorch Geometric, edge features disregarded) and applies deterministic or randomized mode perturbations to each graph. Performance separability is computed by training GNNs (GAT, GCN, GIN) on 6 dataset variants and comparing performance distributions via Kolmogorov-Smirnov tests with Bonferroni correction at α=0.01. Mode complementarity requires no model training: it lifts each mode into a metric space (diffusion distance for structure, Euclidean distance for features), normalizes by diameter, and computes the L_{1,1} norm of the difference, yielding a score in [0,1]. The final output is a four-category dataset taxonomy (Keep, Realign, Deprecate) combining both measures.

## Method

RINGS introduces mode perturbations—maps φ:(G,X)→(G',X') that replace the edge set or feature set with empty, complete, or randomized versions—enabling dataset ablations analogous to model ablations. Performance separability (addressing task-relevance) measures the statistical distance between performance distributions of models trained on the original dataset versus perturbed variants, using the KS statistic with permutation testing. Mode complementarity (addressing task-independent structural-feature alignment) constructs metric spaces from both modes via lift functions, normalizes each to unit diameter, and computes the L_{1,1} norm of their difference; a perturbation duality theorem (γ_{c*}^{1,1} = 1 − γ_{e*}^{1,1}) links complete and empty perturbations. Mode diversity is derived from complementarity under empty perturbations, scoring how far a mode's metric space is from the two degenerate limits (all-zero and all-ones distance matrices). The framework is extensible: any metric, comparator norm, or perturbation can be substituted, and disconnected graphs are handled via weighted averaging over connected components.

## Results

Across 13 popular graph-classification datasets, only 3 (COLLAB, MolHIV, NCI1) satisfy the expected performance-separability relations for structure- and feature-based tasks, while 5 (AIDS, DD, Proteins, Reddit-B, Reddit-M) fail all separability requirements, indicating their modes are poorly aligned with their current tasks. On the mode-complementarity side, feature diversity is more common than structural diversity across datasets, and structural diversity variation is almost always low. The resulting dataset taxonomy recommends keeping MolHIV, NCI1, and Peptides as benchmarks; realigning AIDS, DD, MUTAG, Reddit-B, and Reddit-M; and deprecating COLLAB, IMDB-B, IMDB-M, Enzymes, and Proteins. Higher mean mode complementarity is generally associated with higher AUROC across perturbations, supporting its use as a task-independent diagnostic.

## Baselines & Comparisons

This paper does not compare graph-learning methods against each other; instead, it compares each dataset's original version against five mode perturbations (empty/complete/random graph, complete/random features) using GAT, GCN, and GIN models. The key finding is that for 5 of 13 datasets, the original dataset is separably outperformed by at least one perturbation: the random-graph perturbation outperforms the original on DD, the empty-graph perturbation outperforms the original on Enzymes, and both complete-features and random-graph perturbations outperform the original on Reddit-B. This indicates that the affected modes (structure or features) are poorly aligned with the current task. In contrast, COLLAB, MolHIV, and NCI1 show the expected pattern where the original dataset separably outperforms all perturbations, confirming that both structure and features contain complementary task-relevant information. The mode-complementarity analysis (task-independent) further reveals that COLLAB, IMDB-B, and IMDB-M have low structural and feature diversity (ego-networks with degree-based features), while Reddit-B and Reddit-M exhibit high diversity in both modes, suggesting untapped potential for better-aligned graph-learning tasks.

## Relation to Prior Work

This paper carves new ground by formalizing dataset evaluation as a first-class problem in graph learning, where prior work has focused exclusively on model evaluation. It draws conceptual inspiration from model ablation studies (Errica et al., 2020; Bechler-Speicher et al., 2024) but inverts the logic: instead of ablating model components, it perturbs dataset modes (graph structure, node features) to probe whether the dataset actually tests graph-learning capabilities. For the mode complementarity measure, it departs from homophily-based analyses (Lim et al., 2021; Luan et al., 2023) and alignment metrics like ESNR (Dong & Kluger, 2023) and SAM (Qian et al., 2022) by treating structure and features symmetrically, requiring no labels, and targeting graph-level tasks. The metric-space construction leverages diffusion maps (Coifman & Lafon, 2006) and graph-kernel literature, but the perturbation-based comparison framework is novel.

## Why It Matters / Open Questions

The RINGS framework provides the first principled, extensible methodology for assessing whether graph-learning datasets actually benchmark graph-learning capabilities, yielding an actionable taxonomy that recommends deprecating or realigning 8 of 13 popular benchmarks. This is practically significant for the community: it redirects research effort away from datasets where graph structure is irrelevant or redundant, and toward datasets where structural and feature information are genuinely complementary. Key limitations include the focus on graph-level tasks and message-passing GNNs, the assumption of node-feature pairing, and the lack of a comprehensive theoretical analysis of mode complementarity. Open questions include extending the framework to node/edge-level tasks, temporal and hypergraph structures, and disentangling model-capability limitations from genuine data-task misalignment.

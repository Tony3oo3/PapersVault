## Problem

Parallel data collection in RL accelerates exploration by a factor of N, but simply running N identical agents wastes computational resources through redundant behaviors. While state entropy maximization is a well-studied exploration objective, it has not been extended to explicitly leverage the structural properties of parallel agents. This paper asks: how should parallel agents specialize their policies to maximize the diversity of the jointly collected state distribution, and can this surpass the naive N-fold speedup?

## Input / Output

The method operates on m independent copies of a finite-horizon MDP (discrete states and actions), with a shared initial state distribution μ and horizon T. Each agent uses a parametric softmax policy π_θ(a|s) = exp(θ·s)/Σ exp(θ'·s). The key output is a parallel policy π_p = (π^{i})_{i∈[m]} whose induced *mixture* state distribution d_{π_p}(s) = (1/m)Σ d_{π^i}(s) has maximized entropy. The finite-trials objective evaluates entropy on a single empirical trajectory per agent (n=1), making the method applicable when only a handful of interactions are available. The collected trajectories form a dataset whose empirical state distribution is used downstream for offline RL.

## Method

The core algorithm, PGPSE, derives a policy gradient for the parallel finite-trials entropy objective J_p(π_p) = E_{d_{n,p}}[H(d_{n,p})], where the entropy is computed over the *mixture* of all agents' state visits rather than each agent individually. The gradient for agent i's parameters θ_i is the score function ∇_θ log π_{θ_i}(a_t|s_t) weighted by H(d_p), the entropy of the joint empirical state distribution across all m agents — creating a centralized coupling that naturally encourages each agent to specialize in regions the others do not cover. Theoretically, the mixture entropy decomposes as average individual entropy plus KL-divergence diversity terms, and the paper proves concentration bounds showing that specialized parallel distributions stabilize faster than a single high-entropy distribution. A Frank-Wolfe variant for the infinite-trials objective further yields a 1/N scaling in the convergence rate. Empirically, PGPSE outperforms single-agent baselines in normalized state entropy, support size, and downstream offline Q-learning success rates across deterministic and stochastic grid-world environments.

## Results

Across all four grid-world environments (Room-det, Room-stoc, Maze-det, Maze-stoc), PGPSE with 2 or 6 parallel agents consistently achieves higher normalized state entropy and larger support size than a single agent collecting the same total number of trajectories (K′ = m). Datasets collected by parallel policies exhibit higher empirical state entropy than both single-agent and random-policy baselines, with minimal variance across seeds. In the offline RL evaluation, datasets from parallel agents yield the best Q-learning success rate across the largest number of goal states, substantially outperforming both single-agent and random datasets in both deterministic and stochastic settings.

## Baselines & Comparisons

The paper compares PGPSE (parallel agents with centralized entropy objective) against two baselines: (1) a single agent trained with the standard finite-trial state entropy objective (Eq. 2) using K′ = m trajectories to match total interaction budget, and (2) a random policy. PGPSE wins on all reported metrics across all four environments. In the policy gradient optimization (Figure 1), parallel agents achieve higher normalized state entropy and visit more unique states (larger support) than the single-agent counterpart at every point in training. In the dataset entropy evaluation (Figure 2), parallel-agent datasets have higher entropy than both the single-agent dataset (with m trajectories) and the random-policy dataset. In the offline Q-learning evaluation (Figure 3), the parallel-agent dataset enables the offline agent to reach the most goal states successfully, far exceeding the single-agent and random baselines. The single-agent baseline is the strongest competitor, as it also optimizes for entropy, but it cannot match the diversity gained from inter-agent specialization. The random policy serves as a lower bound and is consistently the worst performer.

## Relation to Prior Work

This paper extends the state entropy maximization framework (Hazan et al., 2019; Mutti & Restelli, 2020) from single-agent MDPs to a Parallel MDP setting, where the key conceptual shift is optimizing the entropy of the *mixture* distribution over agents' state visits rather than each agent's individual distribution. The finite-trials objective from Mutti et al. (2023) is carried over, and the optimization uses a standard REINFORCE-style policy gradient (Williams, 1992) applied to the parallel objective. The paper explicitly distinguishes itself from concurrent exploration (agents in a shared environment with information sharing) and from MARL, positioning its contribution as a decentralized parallel setting where agents interact with independent environment copies but are coordinated through a centralized entropy signal.

## Why It Matters / Open Questions

The practical motivation is strong: modern RL pipelines (Isaac Sim, Genesis, MuJoCo) already instantiate hundreds of parallel agents, yet the question of whether they should be identical or specialized for exploration has not been formally addressed. The concentration bounds showing that specialized parallel agents stabilize entropy faster than a single agent covering the full state space are a clean theoretical contribution of potential independent interest. However, all empirical validation is confined to 43-state discrete grid-worlds with simple softmax policies, leaving open whether the approach scales to continuous control, high-dimensional state spaces, or the large-scale parallelism (1000+ agents) that motivates the work in practice. The connection to skill discovery and offline RL is promising but only lightly explored.

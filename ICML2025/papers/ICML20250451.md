## Problem

Counting distinct elements in the turnstile streaming model under continual release is fundamentally harder than in the insertion-only setting, where a single update can cause Ω(T) changes to the underlying summation stream. Prior DP algorithms for this problem (Jain et al., 2023) required linear space in T, leaving open whether sublinear-space private mechanisms with non-trivial accuracy exist for this foundational streaming problem.

## Input / Output

The algorithm processes a turnstile stream x = (x₁, …, x_T) where each x_t is an insertion (+u), deletion (−u), or no-op (⊥) from a universe U of size poly(T), and releases a (1±η, additive error) approximation to the number of distinct elements at every timestep t ∈ [T] under event-level (ε,δ)-DP. The additive error is Õ_η(√W) when a promised occurrence bound W is available, and Õ_η(T^{1/3}) for arbitrary streams, with matching space guarantees. The algorithm is parameterized by a boolean flag 'ob' that toggles between the bounded-occurrence and unbounded-occurrence regimes.

## Method

The algorithm (CountDistinct) combines three ingredients: a KSET data structure (Ganguly, 2007) that maintains a distinct sample in O(k) space and returns NIL on failure, a modified binary-tree mechanism (BinaryMechanism-CD) that privately tracks the summation stream of distinct-count differences using Gaussian noise calibrated to the occurrence bound, and a blocklisting procedure that probabilistically removes high-occurrence items from future processing. The stream is split into log(T) parallel substreams via a λ-wise independent hash function at geometrically decreasing sampling rates, ensuring at least one substream yields a good approximation. The key technical insight is replacing the stateful 'flippancy' measure with the stateless 'occurrency' (maximum number of appearances of any item), which enables the blocklisting approach and yields sublinear space. Privacy is proven via a coupling argument showing the KSET-based algorithm's output is indistinguishable from a simpler dictionary-based algorithm (COUNTING-DICT) except with negligible probability, allowing sensitivity to be bounded in terms of occurrence W rather than stream length T.

## Results

For arbitrary turnstile streams of length T, the algorithm achieves \tilde{O}(T^{1/3}) space and \tilde{O}(T^{1/3}) additive error with a (1+η)-relative approximation, which is the first sublinear-space DP algorithm for this problem. When a promised occurrence bound W is available, both space and additive error improve to \tilde{O}(\sqrt{W}). The additive error for arbitrary streams approaches the known \tilde{\Omega}(T^{1/4}) lower bound from Jain et al. (2023), leaving a T^{1/12} gap. A matching space lower bound of \tilde{\Omega}(T^{1/3}) is shown for any algorithm using occurrence/flippancy bounding techniques.

## Baselines & Comparisons

The primary comparison is with Jain et al. (2023), the only prior DP algorithm for counting distinct elements in the general turnstile model under continual release. Jain et al. require \Omega(T) (linear) space and achieve additive error \tilde{O}(\min(\sqrt{w_x}, T^{1/3})). This paper reduces space from linear to \tilde{O}(T^{1/3}) while matching the same additive error bound, resolving the open question posed by Jain et al. about the existence of low-memory mechanisms. When flippancy w_x is bounded, this paper's \tilde{O}(\sqrt{w_x}) additive error matches Jain et al.'s exactly (neglecting log factors), but with sublinear space instead of \Omega(T). The remaining gap to the \tilde{\Omega}(T^{1/4}) additive error lower bound (a factor of T^{1/12}) is identified as an open problem. No empirical baselines or dataset comparisons exist, as this is a purely theoretical contribution.

## Relation to Prior Work

This paper builds on the KSET data structure from Ganguly (2007) for non-private turnstile distinct counting and the Binary Mechanism from Chan et al. (2011) / Dwork et al. (2010) for continual-release DP, combining them in a novel way for the first time. The key departure from Jain et al. (2023), who gave the first DP algorithm for this problem but required linear Ω(T) space, is the introduction of 'occurrency' (a stateless per-item count) as a replacement for 'flippancy' (a stateful measure), enabling a blocklisting technique that achieves sublinear space. The privacy analysis introduces a coupling argument between the KSET-based algorithm and a space-inefficient dictionary-based oracle to handle KSET's failure behavior, a technique not present in prior DP streaming work.

## Why It Matters / Open Questions

This is the first sublinear-space DP algorithm for counting distinct elements in the turnstile model under continual release, directly answering an open question from Jain et al. (2023). The T^(1/3) space/error bound approaches the known T^(1/4) additive error lower bound, and the matching space lower bound for blocklisting-based approaches shows the technique is near-optimal within its class. The remaining gap (T^(1/3) vs. T^(1/4)) and the absence of unconditional space lower bounds for arbitrary DP streaming algorithms are significant open problems. The theoretical understanding of space in DP streaming remains very limited, with only one prior space lower bound (under cryptographic assumptions) existing in the literature.

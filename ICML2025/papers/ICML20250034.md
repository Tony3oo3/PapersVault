## Problem

Existing data valuation methods like Data Shapley quantify a data point's expected contribution averaged over all possible training subsets, but no formal notion captures a dataset's *marginal* instrumental value relative to what a buyer already possesses and what specific decision context they care about. This paper introduces such an instrumental value for data production processes and studies how it enables optimal pricing mechanisms for data sellers facing buyers with private decision contexts.
![Teaser figure](../imgs/ICML20250034/cropped_page7_idx0.webp)

## Input / Output

The valuation function V(g; q, x) takes a data production process g (fully specified by feature directions or a design matrix X, without requiring access to realized labels), a buyer's prior q over the regression parameter β, and a decision context x ∈ ℝ^d, and returns a scalar value computable in closed form. The pricing mechanism additionally takes the buyer's reported type x̂ and outputs a data derivative (a single linear combination of the seller's rows via b(x̂)ᵀX, b(x̂)ᵀY) plus a payment t(x̂). A key property is that the value is evaluable before any data is realized, resolving the concern that data loses value upon inspection.

## Method

The paper micro-founds data valuation through contextual Bayesian decision making: a valid valuation is the expected utility gain from updating a prior q to a posterior p via data D, and Theorem 2.7 proves this is equivalent to a generalized Bregman divergence of the cost-of-uncertainty functional. In Bayesian linear regression with entropy as the cost function, this yields the closed-form information gain V(g; q, x) = ½ log(xᵀΣ_q x) − ½ log(xᵀΣ_p x). For pricing under perfect customization, the seller produces n responses along the buyer's reported direction and charges t(x̂) = ½ log((σ(x̂)²+n)/σ(x̂)²), achieving first-degree price discrimination (0-regret). Under limited customization from a pre-collected dataset, the seller applies an SVD-based mechanism that maps each reported type to a single data derivative, achieving regret bounded by log(κ) where κ is the condition number of the normalized design matrix, with 0-regret recovered in isotropic and multi-armed bandit special cases.

## Results

Under perfect data customization, the proposed mechanism (Theorem 4.1) achieves 0-regret, extracting the full first-best revenue (first-degree price discrimination) from any buyer population. Under limited customization, no 0-regret mechanism exists (Theorem 4.2), but the SVD-based mechanism (Theorem 4.3) achieves regret bounded by log(κ), where κ is the condition number of the normalized data matrix; in the special cases of isotropic data (Corollary 4.4) and multi-armed bandits (Corollary D.6), 0-regret is still achievable. Computationally, the instrumental value requires only one model retraining and runs in ~0.0002s for n=10, versus ~0.13s for Data Shapley and ~0.02s for Random Shapley, with the gap widening exponentially as dataset size grows (4.57s vs. 0.00024s at n=15).

## Baselines & Comparisons

The paper's sole empirical baseline is Data Shapley (Ghorbani & Zou, 2019). On a synthetic Bayesian linear regression setup (n=10, d=5, 1000 trials), the instrumental value is consistently about half the magnitude of Data Shapley (e.g., ½log(3/2) ≈ 0.203 vs. log(3)/4 ≈ 0.275 in the worked Example 3), confirming that Data Shapley overestimates marginal data value by averaging over intractable coalition scenarios. The two methods share a high Pearson correlation of 0.8650, indicating consistent underlying economic intuition despite the magnitude gap. Computationally, the instrumental value dominates decisively: at n=15 it takes 0.000239s versus 4.57s for Data Shapley (≈19,000× faster) and 0.474s for Random Shapley (≈2,000× faster), with the ratio growing exponentially in n since Data Shapley requires evaluating 2ⁿ coalitions while the instrumental value needs only one additional model retraining. The paper argues this makes the instrumental value far more practical for real-world data pricing, particularly for fine-tuning scenarios where only the before/after marginal gain matters.

## Relation to Prior Work

This paper builds on the Frankel–Kamenica (2019) information-design framework, extending their Bregman-divergence characterization of information value to a new 'instrumental value' for Data Production Processes (DPPs) that is relative to a buyer's prior and decision context. It departs sharply from Data Shapley (Ghorbani & Zou, 2019), which averages marginal contributions over all coalitions, by instead capturing only the marginal gain over the buyer's existing data—arguing this better reflects economic value and is computationally tractable. On the mechanism-design side, the paper extends Myerson's (1981) single-dimensional optimal auction to multi-dimensional buyer types in a data-selling setting, where the allocation space (arbitrary DPPs) is fundamentally richer than the allocation space for physical goods.

## Why It Matters / Open Questions

The result that perfect data customization enables first-degree price discrimination (full surplus extraction) is a structural departure from physical-goods markets and raises concrete regulatory concerns about data-market fairness. Under limited customization, the SVD mechanism's log(κ) regret bound provides a practical near-optimal pricing rule, though the analysis is confined to Bayesian linear regression with Gaussian priors. Key open questions include whether the valuation transfers to non-linear or deep-learning models, how the results change with multiple competing sellers, and what regulatory interventions are appropriate given the demonstrated seller power.

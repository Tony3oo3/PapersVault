## Problem

Existing reasoning benchmarks for LLMs (GSM8K, MATH, ARC, BIG-Bench Hard) either measure memorization of domain-specific heuristics, use visual formats misaligned with text-based LLMs, or lack a unified theoretical framework for abstraction. Critically, no prior benchmark provides a quantitative mechanism to distinguish genuine rule-inductive abstraction from mere memorization of specific input-output symbol associations, leaving it unclear whether high accuracy reflects true reasoning or pattern recall.

## Input / Output

Each task instance is a text prompt containing few-shot examples (input-output pairs) followed by a target question, drawn from 82 sub-datasets across six tiered categories (BC, EC, NBR, MA, SMA, SR) totaling 9,095 samples. The key design feature is that each task is instantiated in multiple symbol-remapped variants: a raw version (original symbols), an operand-remapped version, an operator-remapped version, and a fully remapped version, where remapping applies a random bijective substitution from the Llama-2 7B tokenizer's single-character alphanumeric vocabulary. The model produces a text answer, which is scored as Γ (accuracy on the raw version) and Δ (the performance gap between raw and remapped versions, decomposed into operand-specific and operator-specific components).

## Method

The paper formalizes abstract reasoning as the composition H = Re ∘ f, where f: C→A is an abstraction mapping from concrete instance strings to abstract feature strings, and Re: A×R→Q is a reasoning function applying a rule to an abstract feature to yield a conclusion. Two complementary metrics are derived: Γ measures basic reasoning accuracy on original symbols, while Δ = Γ − Γ_M quantifies memory dependence by measuring the accuracy drop under systematic symbol remapping M that preserves abstract task structure but alters surface tokens. Three theorems establish the validity of Γ for rule-given reasoning potential, Δ for rule-inductive abstraction, and a combined score F(Γ,Δ) = w₁Γ + w₂(1−Δ) as a continuous ability measure. The benchmark operationalizes this framework through six task categories of increasing cognitive complexity, with SR tasks specifically derived from EC tasks via symbol remapping to enable direct Δ computation. Evaluation spans 7B–70B open-source models, commercial API models, and multi-agent frameworks (AutoGen, ReAct, LLM Debate) under both direct and chain-of-thought prompting, revealing that even the strongest models exhibit high operand-specific memory dependence (Δ_num ≈ 0.4–0.6) and near-zero performance on non-decimal arithmetic, while CoT prompting sometimes increases rather than decreases Δ.

## Results

On the proposed Abstract Reasoning Benchmark, the best-performing model is AgentChat (AutoGen) with a Γ score of 0.60, followed by Gemini-2.0-Flash-Thinking-Exp with CoT at 0.54 and QwQ-32B-Preview with CoT at 0.50. However, performance collapses on Number Base Reasoning (NBR) tasks across all model scales, with average Γ below 0.1 even for 70B models and API-based systems. The Memory Dependence Score Δ reveals persistent operand-specific memorization: Llama-3.3-70B-Instruct shows MemDep_num = 0.42 vs. MemDep_op = 0.11, and ReAct reaches a Δ_all of 0.70, indicating that even sophisticated agent frameworks rely heavily on token-specific patterns rather than genuine abstraction.

## Baselines & Comparisons

The paper evaluates 15+ model configurations spanning 7B–70B open-source models, API-based models, and multi-agent frameworks. AgentChat (AutoGen) achieves the highest Γ (0.60) but also shows substantial memory dependence (Δ_all = 0.56), while ReAct achieves Γ = 0.46 with the highest Δ_all of 0.70, indicating it relies most heavily on memorized token patterns. Among API models, Gemini-2.0-Flash-Thinking-Exp with CoT leads at Γ = 0.54, outperforming GPT-4o-mini (0.43) and DeepSeek V3 (0.41), though DeepSeek V3 without CoT (0.48) exceeds GPT-4o-mini without CoT (0.40). CoT prompting consistently improves Γ for 7B models (e.g., Qwen2.5-7B: 0.19→0.34) and 70B models (Llama-3.3-70B: 0.22→0.43), but paradoxically increases Δ in several cases (e.g., GLM-4-9B Δ_num rises from 0.26 to 0.30; QwQ-32B Δ_all jumps from 0.21 to 0.58), suggesting procedural guidance reinforces token-specific reasoning. All models show near-zero NBR performance (Γ < 0.1 for 7B, < 0.3 for 70B/API), and SMA remains the hardest category (Γ < 0.15 for most models), confirming that no current LLM achieves robust abstract reasoning independent of memorized symbolic representations.

## Relation to Prior Work

This paper carves new ground at the intersection of theoretical formalization and benchmark design for LLM evaluation. It departs from existing reasoning benchmarks (ARC, GSM8K, MATH, BIG-Bench Hard) by arguing they either misalign with LLMs' text-based nature, conflate memorization with reasoning, or lack a unified theoretical framework. The key conceptual departure is the introduction of systematic symbol remapping as an operational mechanism to isolate abstraction from token memorization, combined with the Δ (Memory Dependence Score) metric that no prior benchmark provides. The theoretical framework draws on cognitive science definitions of abstraction and reasoning (Holyoak & Morrison, Murphy, Chollet) but formalizes them as composite string-mapping functions specifically suited to LLM evaluation, bridging a gap between conceptual frameworks and quantitative measurement.

## Why It Matters / Open Questions

The Δ metric offers a practical diagnostic tool for distinguishing genuine rule-based reasoning from memorized pattern matching, which is increasingly critical as LLMs are deployed in safety-sensitive domains. The finding that CoT prompting can paradoxically increase memory dependence, and that multi-agent frameworks (ReAct: Δ=0.70) exhibit higher token-specific reasoning than single models, challenges common assumptions about how to improve LLM reasoning. Limitations include the benchmark's restriction to text/symbolic tasks, the relatively informal theorem proofs, and a small human baseline (undergraduate CS students). Open questions include whether the symbol-remapping methodology generalizes to non-symbolic domains (causal, physical reasoning) and whether the Γ/Δ framework can be extended to measure other cognitive dimensions like compositional generalization.

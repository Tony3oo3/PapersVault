## Problem

Standard Chain-of-Thought (CoT) reasoning suffers from a fundamental write-only limitation: intermediate computations permanently occupy the context window even after they are no longer needed for subsequent reasoning steps. For inherently hard problems (e.g., SAT, QBF, constraint satisfaction), this causes context length to grow exponentially, making it impossible to solve larger instances within any fixed memory budget. The paper asks whether a language model can perform long, deep reasoning while keeping its active context short.

## Input / Output

The model receives a text problem instance (a 3-SAT formula, a prenex QBF formula, or a set of natural-language constraints for Einstein's puzzle) and autoregressively generates a structured reasoning trace using three special tokens — [CALL], [SEP], and [RETURN] — that delimit context, intermediate thoughts, and the answer. The final output is the answer token (e.g., a satisfying assignment or 'who owns the Fish'), but the intermediate trace is hierarchically nested via recursive [CALL]…[RETURN] blocks. All experiments use a fixed 2048-token context window and small transformers (10.63M or 25.19M parameters), so the key constraint is that the maximal sequence length during generation must stay within this window.

## Method

PENCIL augments a standard decoder-only transformer next-token predictor with a deterministic reduction rule: whenever the generated sequence matches the pattern C[CALL]T[SEP]A[RETURN], the intermediate thoughts T and the special tokens are deleted, merging the answer A back into the context C. This rule is applied after every token generation step, enabling recursive, hierarchical reasoning analogous to nested function calls and tail recursion in programming. Training is nearly identical to CoT except that the long scaffolded trace is split into shorter sub-sequences and the cross-entropy loss is computed only on tokens newly generated since the last reduction, not on the full context. Theoretically, the paper proves that a fixed-size transformer implementing PENCIL can simulate any Turing machine using O(T) generated tokens and maximal context length O(S), achieving universal space-efficient computation — a strict improvement over standard CoT, which requires O(T) context length and thus cannot solve PSPACE-complete problems within polynomial memory.

## Results

On 3-SAT (n=3 to 10), PENCIL achieves 100% accuracy across all problem sizes, while CoT degrades from 100% (n=3) to 50% (n=10) and the baseline stays near chance (~50%). On QBF, PENCIL similarly maintains 100% accuracy for all n, whereas CoT drops to 73% at n=10. On the 5×5 Einstein's puzzle, PENCIL (25.19M params, 2048 context) reaches 97% accuracy versus only 25% for CoT (near random guessing). The maximal sequence length is reduced from exponential to polynomial: at n=10, SAT drops from 13,804 to 2,507 tokens and QBF from 151,661 to 649 tokens.

## Baselines & Comparisons

The sole baseline is standard Chain-of-Thought (CoT) with the same transformer architecture, context window, and training setup (special tokens included for fairness). PENCIL wins decisively on all three tasks as problem size increases: on SAT, CoT accuracy collapses from 100% (n≤6) to 50% (n=10) while PENCIL holds at 99–100%; on QBF, CoT drops to 73% at n=10 versus PENCIL's 100%; on the 5×5 Einstein's puzzle, CoT achieves only 25% (trace rate 2.97%) compared to PENCIL's 97% (trace rate 78.27%). On small instances where context length is not a bottleneck (SAT n≤6, QBF n≤5, 3×3 puzzle), both methods achieve near-identical accuracy (~99–100%), confirming that the reduction rule's benefit is specifically in managing space for harder problems. PENCIL also converges faster under fixed FLOPs budgets, with the gap widening as problem size grows, because shorter contexts reduce per-token self-attention cost.

## Relation to Prior Work

PENCIL builds directly on Chain-of-Thought (Wei et al., 2022) as its generation backbone and extends the theoretical framework of Merrill & Sabharwal (2023), who showed transformers with CoT can simulate Turing machines but only with O(T) context length. The key departure is the introduction of a fixed reduction rule (motivated by function-call stack semantics in programming) that erases intermediate reasoning steps, transforming the space complexity from O(T) to O(S). The theoretical proof leverages the FASP programming language, which extends RASP (Weiss et al., 2021) and Yang & Chiang (2024) to characterize what finite-size transformers with average-hard attention can compute.

## Why It Matters / Open Questions

The main theoretical result — that PENCIL with a fixed-size transformer can solve PSPACE-complete problems with polynomial context length, while standard CoT is limited to P — is a fundamental advance in understanding transformer computational power. Practically, the technique is simple (a single rewrite rule) and could be integrated into existing LLM training pipelines to handle longer reasoning chains within fixed context windows. Key limitations include: the reduction rule is hand-designed rather than learned, the theoretical proof requires specific architectural choices (average-hard attention, Gated ReLU, linear positional embedding), and empirical validation is on small-scale problems (≤10-variable SAT/QBF, 5×5 puzzles) with ≤25M-parameter models. Open questions include whether more expressive or learned reduction rules can handle open-ended reasoning, and whether the approach transfers to real-world LLMs with standard architectural choices.

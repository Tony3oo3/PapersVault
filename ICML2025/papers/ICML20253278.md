## Problem

Current LLMs achieve artificial useful intelligence but fail at the robust, adaptive reasoning required for AGI, as next-token prediction pretraining on passive Internet data couples reasoning with memorized knowledge, causing models to exploit spurious token correlations rather than learn generalizable reasoning algorithms. The paper demonstrates this gap empirically: even state-of-the-art models (including o1) struggle to transfer simple algorithmic understanding (printing, sorting) to unfamiliar esoteric programming languages, revealing that reasoning is overfit to training-distribution surface patterns.

## Input / Output

The proposed system consumes natural language task descriptions and interacts with an external semantic memory bank through learned discrete read/write operations, operating over a deliberately small context window (working memory) rather than long sequences. The output is a step-by-step reasoning trace followed by a final task solution. The small context window is a key architectural constraint: it forces the model to actively query and update external memory at each reasoning step, preventing reliance on long-range token correlations and enabling the reasoning module to be reused across new knowledge domains by simply inserting new data into the memory bank.

## Method

The paper proposes a three-part paradigm shift from supervised pretraining to reward-based pretraining (RPT), drawing an explicit analogy to AlphaZero surpassing AlphaGo. First, RL is integrated directly into pretraining (rather than applied only as post-training), so the model learns iterative, step-wise reasoning from reward signals rather than imitating passive data that lacks intermediate reasoning traces. Second, a curriculum of synthetic tasks with progressively larger token spaces is used to learn a transferable reasoning prior (commutativity, associativity, in-context learning) in a tractable search space before adapting to natural language, with intermediate layers preserved and input/output layers re-initialized for the new token space. Third, knowledge and reasoning are architecturally decoupled: a separate external memory bank stores knowledge while a reasoning network operates on a small context window, with discrete memory-access decisions (read/write) trained via RL to avoid the gradient instability of differentiable memory architectures like Neural Turing Machines. Empirical support includes Go 9×9 experiments showing RPT achieves 100% win rate over SPT and 66–92% over SPT-then-RFT depending on KL constraint, esoteric language benchmarks showing poor cross-syntax transfer, and a synthetic orthogonality task where pure RFT (93% test) outperforms SFT-then-RFT (80% test) due to reduced overfitting.

## Results

On the Brainf**k benchmark, all evaluated LLMs average ~12% accuracy, with o1 as the clear outlier at 64–95% across tasks, while Llama 3.1, Qwen2.5 Coder, and GPT-4o all score below 13%. On Befunge, in-context examples boost printing accuracy to 70–100% for larger models, but all models (including o1) score 0% on Fibonacci and Factorial tasks. In the Go 9×9 experiment, the RPT agent achieves a 100% win rate against SPT and 66–92% against SPT+RFT (depending on KL coefficient), confirming that supervised pretraining constrains subsequent RL exploration. On the synthetic orthogonality task, pure RFT reaches 93% test accuracy versus 80% for SFT-then-RFT, which overfits to 100% training accuracy.

## Baselines & Comparisons

The paper evaluates four model families on its esoteric-language benchmarks. o1 (RL post-trained) dominates all other models on Brainf**k, scoring 64–95% versus 1–13% for Llama 3.1, Qwen2.5 Coder, and GPT-4o, yet still fails on sorting (1%) and struggles on printing (65%). On Befunge, GPT-4o and Llama 3.1 70B reach 92–100% on printing with 10 in-context examples, but every model—including o1—scores 0% on Fibonacci and Factorial, revealing a hard ceiling on algorithmic generalization. In the Go 9×9 controlled experiment, RPT (RL from scratch) achieves a 100% win rate over SPT and 66–92% over SPT+RFT, with the gap widening as the KL constraint tightens (92% at KL=0.5 vs. 66% at KL=0.1), directly supporting the hypothesis that supervised pretraining traps RL in a local minimum. On the synthetic vector-orthogonality task, pure RFT (93% test) outperforms SFT-then-RFT (80% test) by 13 points, while the SFT-then-RFT model overfits to 100% training accuracy, confirming that supervised fine-tuning on passive data hinders generalization relative to reward-based training.

## Relation to Prior Work

This position paper draws a direct conceptual parallel between the AlphaGo-to-AlphaZero paradigm shift (supervised pretraining + RL vs. pure RL from scratch) and the current SPT-then-RFT pipeline in LLMs, arguing that next-token prediction on passive Internet data creates local minima in reasoning that post-training RL cannot escape. It repurposes ideas from Neural Turing Machines and Differentiable Neural Computers for the memory-reasoning decoupling proposal, while explicitly contrasting with RAG by advocating for learned, dynamic read/write interactions rather than static retrieval appended to long contexts. The synthetic-task curriculum for learning reasoning priors builds on prior work showing that in-context learning emerges from structural (not semantic) properties of language (Chan et al., 2022) and that code pretraining transfers reasoning skills (Petty et al., 2024), but extends these to a full pretraining-from-scratch vision with reduced token spaces.

## Why It Matters / Open Questions

If the core hypothesis is correct—that supervised pretraining fundamentally constrains the reasoning capabilities discoverable by subsequent RL—this would necessitate a complete overhaul of how foundation models are trained, with enormous practical implications. However, the evidence remains preliminary: the Go 9×9 experiment is a simplified proxy, the LLM SFT-vs-RFT comparison uses a 1.5B model on a single synthetic task, and the esoteric language evaluation, while creative, covers only a handful of simple algorithmic tasks. Major open questions include how to make RL from scratch tractable in the ~40K-token language space, which synthetic tasks preserve the right structural properties for transferable reasoning priors, and how to architecturally implement the memory-reasoning decoupling at scale without the optimization instabilities that plagued earlier differentiable memory systems.

## Problem

Existing Federated Active Learning (FAL) methods rely on local data selection where each client independently queries samples, inevitably producing redundant and overlapping supervision due to the absence of cross-client coordination. Moreover, theoretical guarantees on query complexity for active selection in privacy-preserving distributed settings remain largely unexplored. This paper addresses both gaps by enabling the server to perform global, privacy-preserving data selection for regression on non-i.i.d. client data.

## Input / Output

The method takes as input fully unlabeled feature vectors distributed across k clients with heterogeneous (non-i.i.d.) distributions, along with a query budget n_q; no initial labeled set is required. It outputs a global regression model θ^g that is computed on masked data at the server and recovered on the client side via multiplication by a secret orthogonal matrix Q^T, as well as the indices of selected data points routed back to each client for local labeling. The entire selection is performed in a single pass, so communication occurs only once rather than iteratively.

## Method

FALE invokes FedSVD as a privacy-preserving subroutine to compute the SVD of the global feature matrix without exposing raw data; each client then recovers its portion of the left singular matrix U_i and computes local leverage scores τ_i^j = ‖e_j^T U_i‖², which are uploaded to the server. The server aggregates all leverage scores into a global vector, derives sampling probabilities p_i = τ^i / ‖τ‖₁, and performs importance sampling to select n_q distinct data points, constructing a reweighting matrix S. For model learning, clients mask their labeled features and labels with random orthogonal matrices (P_i X_i^L Q and P_i y_i^L) and upload them; the server solves a weighted least-squares problem on the masked data, and the solution is unmasked on the client side as θ^g = Q^T θ̂^g. The key insight is that leverage score sampling provides an ℓ₂ subspace embedding of the global feature matrix, yielding provable query complexity of O(d log d) for constant-factor approximation and Ω(d log d + d/ε) for (1+ε)-relative error approximation, matching centralized guarantees while operating entirely in a privacy-preserving federated setting.

## Results

FALE is evaluated on 11 regression benchmarks (9 UCI/OpenML tabular datasets + 2 image datasets: IMDB-WIKI and CelebA) using MSE as the metric. In paired t-tests at 0.05 significance over 10 runs, FALE achieves 675 wins, 41 ties, and only 4 losses out of 720 total comparisons against all baselines combined. FALE never loses to Random, BAIT, ACS-FW, or LOGO (90/0/0 in each case), and its one-pass selection with a query budget of 50 instances per round consistently outperforms iterative methods across all 9 tabular datasets. On the image regression tasks (IMDB-WIKI, CelebA), FALE with query budgets of 7,500 and 15,000 significantly outperforms iterative selection methods.

## Baselines & Comparisons

FALE dominates all six baselines across the 9 tabular datasets: it achieves a perfect 90/0/0 record against Random, BAIT, ACS-FW, and LOGO (the state-of-the-art FAL method), and near-perfect records against CoreSet (82/8/0), BADGE (79/9/2), and LCMD (77/13/0). The only losses (4 total) occur on the stock dataset against BADGE and LCMD, and on online_video where FALE ties with CoreSet, BADGE, and LCMD in 8 out of 10 budget levels. FALE-local (global selection + local FedAvg training) still outperforms Random, BAIT, ACS-FW, and LOGO in 88–89 out of 90 comparisons, confirming that the global leverage-score selection strategy is the primary driver of performance. Notably, LOGO and ACS-FW exhibit increasing test error as more data is queried on some datasets, suggesting that local representativeness-based selection can mislead global model learning under non-i.i.d. distributions. On the two image regression datasets (IMDB-WIKI, CelebA), FALE's one-pass approach with 7,500/15,000 query budget significantly outperforms all iterative baselines, while FALE-local matches the second-best method.

## Relation to Prior Work

FALE bridges two previously separate research threads: centralized active regression via leverage score sampling (Mahoney, 2011; Woodruff et al., 2014) and privacy-preserving federated computation (FedSVD, Chai et al., 2022). Prior FAL methods (Wu et al., 2022; Kim et al., 2023; Zhang et al., 2023) perform data selection locally at each client, which the paper argues leads to redundant and overlapping queries under non-i.i.d. distributions. FALE departs from this by computing global leverage scores across all clients through FedSVD and performing a single-pass global selection, while also introducing a secure server-side model training scheme that avoids the suboptimality of FedAvg under distributional heterogeneity.

## Why It Matters / Open Questions

The paper provides the first theoretical query-complexity guarantees for FAL (O(d log d) for constant-factor approximation, O(d log d + d/ε) for relative error), matching the centralized leverage score sampling bounds and showing no degradation from the federated constraint. The single-pass design substantially reduces communication rounds compared to iterative FAL methods, which is practically significant for bandwidth-limited deployments. However, the method is restricted to linear regression, relies on a trusted authority for FedSVD key generation, and has not been validated for classification tasks where most FAL applications reside. Open questions include whether the leverage-score-based global selection extends to non-linear models and whether the single-pass guarantee holds under more adversarial privacy models.

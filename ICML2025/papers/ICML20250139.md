## Problem

Memory layers, which use trainable key-value lookup to add parameters without increasing FLOPs, have not been scaled or optimized sufficiently to be useful in modern AI architectures. Unlike dense layers that are FLOP-bound, memory layers are memory-bandwidth-bound and have not been co-designed with hardware accelerators, leaving their potential at scale unexplored. This paper demonstrates that properly engineered memory layers can outperform both larger dense models and mixture-of-experts models at matched compute budgets.

## Input / Output

The model takes standard text token sequences (Llama2 32k or Llama3 128k vocabulary) and produces next-token predictions via autoregressive language modeling. Each token embedding (the output of the preceding attention layer) independently queries the shared memory table, retrieving a weighted combination of top-k value embeddings that replaces the standard FFN output. The memory table holds up to 64 million key-value pairs (128B parameters), with only 32 keys activated per token per memory layer.

## Method

The architecture replaces one or more FFN layers in a Llama-style transformer with trainable memory layers that perform top-k sparse lookup over a shared key-value table using product-key quantization (two sets of √N half-keys whose products form the full N keys, avoiding O(N) search). The Memory+ variant adds input-dependent gating with a silu nonlinearity, uses 3 memory layers with centered placement and stride 8, and employs qk-normalization for training stability. Custom CUDA kernels for the EmbeddingBag operation achieve 3 TB/s memory bandwidth (near H100 peak of 3.35 TB/s), and the memory is sharded across GPUs along the embedding dimension for parallel lookup and aggregation. The shared memory pool means multiple memory layers add no extra parameters beyond a single layer, and the sparse activation pattern keeps decoding-time compute roughly constant regardless of total memory size, yielding up to 5× faster inference than MoE at small batch sizes.

## Results

On factual QA, Memory+ models improve dramatically over dense baselines: at 1.3B base parameters, Memory+ achieves 13.68 NQ accuracy vs. 7.76 for the dense model (77% relative gain), and scaling memory to 64M keys (138B total params) reaches 20.78 NQ / 62.14 TQA F1, approaching Llama2 7B (25.10 / 64.00) trained on 2T tokens with 10× more FLOPs. At 8B scale with 64B memory parameters, Memory+ at 1T tokens achieves 27.06 NQ, 63.04 MMLU, and 31.71 HumanEval pass@1, approaching Llama3.1 8B (29.45 NQ, 66.00 MMLU) trained on 15T tokens. Memory+ consistently outperforms parameter-matched MOE and PEER baselines on all QA benchmarks across every base model size tested.

## Baselines & Comparisons

Against the dense Llama2 baseline (Touvron et al., 2023), Memory+ at 1.3B base parameters achieves 13.68 NQ accuracy vs. 7.76 for the dense model, matching or exceeding dense models with 2×–4× more compute; at 64M memory keys the 1.3B Memory+ model (138B total params) reaches 20.78 NQ, within 18% of Llama2 7B trained on 2T tokens with 10× more FLOPs. Against the Llama3 8B dense baseline (Dubey et al., 2024), Memory+ at 1T tokens achieves 27.06 NQ and 63.04 MMLU vs. 25.24 and 59.68 for dense, approaching Llama3.1 8B (29.45 NQ, 66.00 MMLU) trained on 15T tokens. Against the MOE baseline (Shazeer et al., 2017), Memory+ wins decisively on all QA tasks at every scale — e.g., at 1.3B, Memory+ scores 13.68 NQ vs. 8.14 for MOE (68% higher) and 42.89 TQA vs. 31.46. Against PEER (He, 2024), the vanilla Memory model is roughly comparable (9.83 vs. 12.33 NQ at 1.3B, with PEER slightly ahead), but Memory+ with its architectural improvements (swilu gating, 3 shared layers) clearly surpasses PEER (13.68 vs. 12.33 NQ, 42.89 vs. 42.46 TQA), and the gap widens at larger memory sizes where PEER was not scaled.

## Relation to Prior Work

This paper revives and scales the trainable key-value memory layer concept introduced by Sukhbaatar et al. (2015) and made scalable via product-key lookup by Lample et al. (2019), which had remained at proof-of-concept scale for years. It positions memory layers as a direct alternative to Mixture-of-Experts (Shazeer et al., 2017) and the more recent PEER architecture (He, 2024) for adding parameters without increasing FLOPs, but with a fundamentally different sparsity pattern (sparse embedding lookup vs. sparse expert routing). The key departure from prior memory-layer work is the engineering and architectural improvements—shared memory pools across layers, swilu gating, custom CUDA kernels achieving near-peak H100 bandwidth, and parallel sharding—that make the mechanism viable at 128B memory parameters and 1T training tokens.

## Why It Matters / Open Questions

The paper demonstrates that memory layers can match or exceed dense models trained on 4× more compute and outperform parameter- and compute-matched MoE models on factual tasks, while offering up to 5× faster decoding at small batch sizes—a practical advantage that could reshape inference cost trade-offs. The authors argue memory layers should be integrated into all next-generation architectures, but acknowledge substantial engineering work remains for production deployment and that only short-form QA has been validated. Open questions include whether the sparse-update mechanism enables continual learning, reduces catastrophic forgetting, and how these layers interact with long-form generation and retrieval-augmented pipelines.

## Problem

Existing recommender systems lack unified statistical guarantees for both model confidence (i.e., the probability that a recommended item is truly relevant) and group fairness across user subpopulations. Prior confidence-aware methods are heuristic without distribution-free coverage guarantees, and fairness-aware methods are empirically validated without probabilistic bounds on the fairness metric. This paper addresses the gap by asking: can we construct prediction sets that simultaneously satisfy a user-specified risk threshold and a fairness threshold with pre-defined confidence levels, while minimizing set size?

## Input / Output

The framework consumes user-item relevance scores m(u,i) ∈ [0,1] from any trained black-box recommender, a binary group assignment (advantaged G₁ vs. disadvantaged G₂), and four user-specified hyperparameters: risk threshold α, fairness threshold η, and confidence levels 1−δ and 1−δ̂. It outputs a variable-size prediction set φ_λ(u) ⊆ I for each user (not a fixed top-k), where the set is defined as all items with score ≥ λ_G for the user's group G. The nested structure (larger λ → smaller set) is a key design constraint that enables the greedy optimization. The framework also outputs the optimal per-group λ parameters that define the operating point.

## Method

ENSUR formulates recommendation as a constrained optimization: minimize average prediction set size subject to (i) Risk-Controlling Prediction Set (RCPS) constraints per group and (ii) a novel Fairness-Controlling Prediction Set (FCPS) constraint on the disparity of a chosen metric (HR or DCG) between groups. To make optimization tractable, the paper derives a binomial-CDF-based upper bound on risk (Theorem 4.1) and a Bernstein-inequality-based upper bound on the fairness metric (Theorem 4.2), converting the probabilistic constraints into deterministic ones. The Greedy User Fairness Algorithm (GUFA) then searches for the largest λ per group such that both upper bounds remain below their thresholds, yielding the minimum valid set. Theoretical analysis (Theorems 5.1–5.2) proves that the resulting sets satisfy the risk and fairness guarantees with the stated confidence and achieve minimum expected set size among all valid predictors. The entire framework is post-hoc and model-agnostic, requiring only a calibration set and no retraining of the underlying recommender.

## Results

On the AmazonOffice dataset (grouped by interactions, α=0.20, η=0.20, δ=0.1, δ̂=0.1), all ENSUR-enhanced models satisfy both the risk threshold (≤0.20) and fairness threshold (≤0.20) for both user groups, whereas base models exceed the risk threshold for the disadvantaged group in every case (e.g., GMF risk 0.361†, MLP risk 0.38†). MLP+ENSUR achieves the best average set size (26) and the smallest Hit Rate Diff (0.013), while DeepFM+ENSUR achieves the best DCG Diff (0.103). ENSUR is also substantially faster than all fairness baselines, requiring only 8 minutes of calibration versus 22–50 minutes for the competing methods.

## Baselines & Comparisons

ENSUR dominates all five base models (DeepFM, GMF, LightGCN, MLP, NeuMF) on both risk control and fairness: every base model exceeds the α=0.20 risk threshold for the disadvantaged group (e.g., GMF 0.361, MLP 0.380), while all ENSUR-enhanced variants stay below 0.20 for both groups. On fairness, base models show Hit Rate Diffs of 0.126–0.225 and DCG Diffs of 0.17–0.238, whereas ENSUR reduces these to 0.013–0.087 and 0.103–0.198 respectively. Against the four fairness baselines (NFCF, MFCF, NeuMF-UFR, GMF-UFR), ENSUR wins on risk control: all four baselines still exceed α=0.20 for at least one group (e.g., MFCF 0.303, GMF-UFR 0.368), while ENSUR never does. On fairness metrics, ENSUR-enhanced MLP achieves the lowest HR Diff (0.013) and DeepFM+ENSUR the lowest DCG Diff (0.103), both beating the best fairness baselines (NeuMF-UFR: HR Diff 0.153, DCG Diff 0.127). In terms of efficiency, ENSUR's greedy calibration takes 8 minutes on AmazonOffice versus 22 min (NeuMF-UFR), 25 min (GMF-UFR), 45 min (MFCF), and 50 min (NFCF).

## Relation to Prior Work

This paper extends the Risk-Controlling Prediction Sets (RCPS) framework of Bates et al. (2021b) from a single risk-control guarantee to a dual-constraint setting that simultaneously enforces risk control and a newly defined Fairness-Controlling Prediction Sets (FCPS) constraint. It departs from existing fairness-aware recommendation methods (NFCF, MFCF, GMF-UFR, NeuMF-UFR) and confidence-aware recommendation approaches, which are heuristic and lack distribution-free statistical guarantees, by formulating both objectives as probability statements with user-specified confidence levels. The key methodological contribution is deriving tractable upper bounds (binomial CDF for risk, Bernstein inequality for fairness) that convert the intractable probability constraints into a greedy optimization over per-group threshold parameters, making the framework a post-hoc wrapper applicable to any black-box recommender.

## Why It Matters / Open Questions

This is the first framework to provide simultaneous, distribution-free statistical guarantees for both recommendation confidence and group fairness, addressing a gap the authors identify as critical for platform credibility. The post-hoc design (operating on top of any trained model) and the time efficiency (8–15 min vs. 22–135 min for baselines) make it practically deployable. Limitations include the restriction to binary group partitions, the acknowledged looseness of the derived upper bounds (which directly affects set-size tightness), and the offline calibration requirement. Open questions include extending to multi-group fairness, tightening the concentration bounds, and adapting to streaming or online recommendation settings.

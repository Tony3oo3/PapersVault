## Problem

Prior analyses linking Transformer in-context learning to functional gradient descent have focused exclusively on real-valued outputs (linear or kernel regression), leaving a significant gap for the categorical, discrete-token observations that underlie language modeling. This paper extends the functional GD framework to categorical observations, where the expectation term in the GD update becomes a nonlinear softmax function of the latent function, breaking the simple self-attention-only implementations that work for real-valued data.
![Teaser figure](../imgs/ICML20252482/cropped_page3_idx1.webp)

## Input / Output

The model consumes a context of N input-label pairs (x_i, y_i) where x_i is a covariate vector (positional embeddings for language, VGG 512-d features for images) and y_i is a categorical token index, plus a query covariate x_{N+1} for which no label is available. The forward pass produces a d'-dimensional latent function estimate f(x_{N+1}) that is fed into a softmax over C categories using learned embedding vectors w_{e,c}, yielding a probability distribution over all C possible output tokens. For language experiments, C=50,257 tokens with d'=512; for ImageNet, 900 training classes with d'=4.

## Method

The paper introduces an attention-block architecture in which each block contains a self-attention layer (two heads: one computing the kernel-weighted GD update Δf_{i,k}, and one erasing the prior expectation via a near-delta attention mechanism) followed by a cross-attention layer that exactly computes the nonlinear expectation E(w_e)|f_{i,k+1} by treating the learned embedding matrix W_e as both keys and values with softmax attention. This interleaved self-attention/cross-attention design enables exact multi-step functional GD for categorical data, where the softmax-based cross-attention is essential to handle the nonlinearity that prevents multi-step updates with self-attention alone. The paper proves (Theorem 2) that this GD-implementing parameterization is a stationary point of the population cross-entropy loss for rotationally invariant covariates, and empirically validates the framework on synthetic data, in-context ImageNet classification, and language generation on Tiny Stories/Children Stories, where a single-layer GD model plus a feedforward layer matches a comparable Transformer's GPT-4o-scored quality with 8K versus 6M attention parameters.

## Results

On language generation (Tiny Stories + Children Stories), the GD-based model with an appended feedforward (FF) layer achieves a GPT-4o overall score of 4.84/10, nearly matching the single-layer Transformer (5.04/10), while using only 8K attention-weight parameters versus 6M for the Transformer. The plain GD model (without FF) scores 3.62/10 overall. On in-context ImageNet classification (900 train classes, 100 test classes, N=50 context images), the GD-based attention model with two or three attention blocks achieves Top-1 accuracy that aligns almost exactly with linear probing, without requiring per-context fine-tuning.

## Baselines & Comparisons

The primary baseline is a single-layer Transformer following the design of Radford et al. (2019), with 8 attention heads, d'=512 embeddings, and 256 positional embeddings. The GD-based model with an appended FF layer (4.84 overall) nearly matches the Transformer (5.04 overall) on GPT-4o scoring, with a gap of only 0.20 points, despite having roughly 750× fewer attention-weight parameters (8K vs. 6M). The plain GD model without FF (3.62) trails the Transformer by 1.42 points, indicating the FF element is critical for closing the gap. On ImageNet in-context classification, the GD model with two or three attention blocks matches linear probing accuracy almost exactly, whereas a single GD layer is slightly lower. On synthetic categorical data, the GD model converges to the same predictive accuracy as a fully trained Transformer (Trained TF) but requires far fewer contextual training sets (L<5000 vs. L>25,000 for the two-layer Trained TF).

## Relation to Prior Work

This paper extends the functional gradient descent (GD) framework for understanding Transformer in-context learning from real-valued outputs (von Oswald et al., 2023; Ahn et al., 2023; Cheng et al., 2024) to categorical observations, which is the natural setting for language modeling. The key architectural departure is the introduction of a cross-attention layer that exactly computes the nonlinear softmax expectation E(w_e|f_{i,k}), a quantity that cannot be handled by self-attention alone in the categorical setting. The theoretical contribution generalizes prior stationary-point analyses to softmax-based attention, and the paper shows that learned token embeddings arise naturally as the first GD update when the latent function is initialized to zero.

## Why It Matters / Open Questions

This work provides a principled GD-based explanation for why Transformers use the specific architecture of interleaved self-attention and cross-attention blocks, and why token embeddings take their particular form, connecting the functional data analysis perspective to practical language modeling. The finding that a GD-based model plus a feedforward layer matches a comparable Transformer in GPT-4o-scored generation quality with roughly 750× fewer attention parameters is a notable efficiency insight, though it is demonstrated only on a single-layer model over a small story corpus. Open questions include whether the GD+FF equivalence holds at scale, how the feedforward element interacts with the GD-based attention mechanism, and whether the stationary-point theory extends to deeper, multi-step settings with softmax attention in practice.

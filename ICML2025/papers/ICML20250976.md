## Problem

Cross-domain reward transfer in reinforcement learning has been limited to alignable MDPs with paired, time-aligned demonstrations. When source and target environments are incompatible—lacking direct state-action correspondence (non-pairable) and temporal alignment—existing methods such as DAIL, CycleGAN-based alignment, and Gromov-Wasserstein distance fail. This paper asks: can rewards be transferred between such semi-alignable MDPs by abstracting tasks into shared high-level structures?

## Input / Output

The method consumes two reward machines (finite state machines over propositional symbols) for the source and target tasks, plus environment and task text descriptions that feed an LLM (GPT-4) for automated RM generation via chain-of-thought prompting. The source RM is augmented with a dense reward computed from its learned optimal value function via potential-based shaping. The output is a transferred reward function for the target task (either a direct mapping under isomorphic RMs or a piecewise function under homomorphic RMs), which is then used to train the target policy with standard RL algorithms (PPO, SAC, DQN).

## Method

NRT introduces semi-alignable MDPs, where two incompatible MDPs share injective mappings at the level of abstract 'goal' (checkpoint) and 'skill' (transition) spaces rather than raw state-action pairs. Reward machines serve as the concrete realization of these abstractions: Theorem 3.5 proves that RM state space U injectively maps to the goal space B and propositional symbols P injectively map to the skill space W. The framework has three stages: (1) generate RMs for both tasks (expert-designed or LLM-generated), (2) align them via graph matching—either isomorphic (bijections, enabling direct reward transfer) or homomorphic (injections, requiring a piecewise reward function for the reverse direction), and (3) train the target agent using the transferred dense reward. The dense reward is constructed via potential-based reward shaping (δ_r = γ_R·φ(u') − φ(u)) where φ is the expected optimal value at each RM state, guaranteeing that the transferred reward preserves the optimal policy (Equation 8). This indirect mapping through RMs circumvents the need for state-level or action-level correspondence between domains.

## Results

The paper evaluates NRT across sparse-reward settings in 3D visual navigation (Miniworld-Sign) and MuJoCo (HalfCheetah-v3, Hopper-v3, Ant-v3), using PPO as the primary baseline. In all environments, PPO and PPO-RM (which augments observations with reward machine states but does not transfer rewards) fail to overcome the sparse reward problem, while PPO-NRT(Reward) and PPO-NRT(RM+Reward) achieve substantially faster convergence and higher final performance. In Ant-v3 and Hopper-v3, PPO-NRT(Reward) attains the best results; in HalfCheetah-v3, PPO-NRT(Reward) and PPO-NRT(RM+Reward) perform comparably. Results are presented as learning curves rather than a single numerical summary table, and the paper also validates NRT with DQN on NChain(n=5→n=9) and SAC on MuJoCo-Ant.

## Baselines & Comparisons

The paper compares four PPO variants: vanilla PPO, PPO-RM (RM state added to observation, no reward transfer), PPO-NRT(Reward) (reward transfer only), and PPO-NRT(RM+Reward) (both reward transfer and RM state in observation). PPO and PPO-RM both struggle in all sparse-reward environments, confirming that merely exposing the agent to reward machine structure without transferring dense reward signals is insufficient. PPO-NRT(Reward) consistently outperforms both PPO and PPO-RM across Miniworld-Sign, Ant-v3, and Hopper-v3, demonstrating that the transferred potential-based reward shaping is the critical component. PPO-NRT(RM+Reward) matches or slightly exceeds PPO-NRT(Reward) in some settings (HalfCheetah-v3) but does not uniformly dominate, suggesting the RM state in the observation provides marginal additional benefit. A naive reward-shaping baseline (giving +10 per subtask completion) in Miniworld-Sign improves over sparse rewards but remains substantially below NRT, highlighting that structured cross-domain transfer via reward machines captures logical dependencies that simple shaping cannot. The NRT framework also generalizes across algorithms, showing consistent gains with both PPO and SAC on MuJoCo-Ant.

## Relation to Prior Work

This paper extends the cross-domain RL transfer line of work (DAIL, xDIO, GWIL) that assumes alignable MDPs with paired, time-aligned demonstrations, by introducing semi-alignable MDPs that relax these constraints to only require shared abstract 'goal' and 'skill' structures. The core mechanism builds on reward machines (Icarte et al., 2018, 2022) as an indirect abstraction bridge, repurposing them not for within-task decomposition but as a cross-domain translation layer via graph matching. The MDP semi-reduction formalization explicitly extends the MDP reduction theory from Kim et al. (2020), while the LLM-based RM generation (using GPT-4 with chain-of-thought prompting) is a practical addition not present in prior RM literature.

## Why It Matters / Open Questions

The semi-alignable MDP framework addresses a genuine gap: most cross-domain RL transfer methods fail when source and target tasks lack direct state-action correspondence, which is common in real-world applications. The reward-machine-as-translation-layer idea is conceptually clean and the NChain→MuJoCo results demonstrate that even structurally dissimilar tasks can share useful reward structure. However, the approach still requires RM construction (even if LLM-assisted), access to the source task's optimal value function for potential-based shaping, and graph matching between RMs—open questions include scalability to complex multi-objective tasks, reliability of LLM-generated RMs, and whether the framework generalizes beyond the sparse-reward, single-goal settings tested here.

## Problem

Graph diffusion generative models (GDGMs) operate in the full graph space, requiring O(N²) memory that scales quadratically with node count, making them impractical for large-scale graphs. Additionally, GDGMs exhibit poor size generalization, failing to generate graphs whose sizes differ from those seen during training. These two limitations restrict the applicability of diffusion-based graph generation to real-world graphs with millions of nodes or variable-size outputs.

## Input / Output

The model takes Gaussian noise and a target graph size (number of nodes) as input, and produces a generated graph represented as an adjacency matrix and node feature matrix. The key structural detail is that generation proceeds in two stages: first, k block graphs of size C (where C ≪ N) are denoised independently, and then a separate interaction network s_φ predicts the sparse inter-block adjacency matrices from the generated block graphs. The partition number k is the primary hyperparameter controlling the trade-off between memory savings and structural fidelity.

## Method

SBGD partitions each graph into k non-overlapping block graphs using METIS, then performs the diffusion process independently within each block graph rather than on the full N×N adjacency matrix, reducing memory complexity from O(N²) to O(C²). Three graph-transformer denoising networks are trained jointly: s_θ predicts clean block adjacency matrices, s_ψ predicts clean block feature matrices, and s_φ predicts the sparse inter-block connection matrix from pairs of generated block graphs. The forward process applies Gaussian noise to each block's adjacency and feature matrices following the standard DDPM variance schedule, while the training objective is a sum of x₀-prediction losses for all three components. This block-based decomposition leverages the structural prior that real-world graphs exhibit dense intra-block and sparse inter-block connectivity, enabling both memory-efficient scaling and size generalization by recombining learned block building blocks at different scales.

## Results

SBGD achieves up to 6× memory efficiency (memory ratio 1.0 vs. 6.1 for GraphRNN) while matching or exceeding state-of-the-art diffusion baselines on generation quality. On Planar Graphs, SBGD attains the best average MMD (0.32), highest V.U.N (89.5), and lowest FID (25.0) among all methods. On OGBN-Products, SBGD is the only method capable of completing training, with all six baselines either running out of memory or not supporting the dataset. Across cSBM, QM9, and OGBN-Arxiv, SBGD consistently achieves the best or near-best FID and V.U.N scores.

## Baselines & Comparisons

Against the two strongest diffusion baselines, SBGD outperforms DiGress on average MMD (0.32 vs. 0.33 on Planar Graphs; 0.29 vs. 0.32 on cSBM; 0.27 vs. 0.28 on OGBN-Arxiv), V.U.N (89.5 vs. 86.2; 85.2 vs. 83.1), and FID (25.0 vs. 29.0; 16.3 vs. 18.8; 21.4 vs. 33.7), while using roughly 5.3–5.7× less memory. Similarly, SBGD beats GDSS on all three headline metrics across Planar Graphs, cSBM, and OGBN-Arxiv (e.g., FID 25.0 vs. 33.3 on Planar Graphs; 16.3 vs. 22.1 on cSBM) with a 4.8–5.6× memory advantage. On QM9, DiGress edges out SBGD on FID (19.7 vs. 20.0) and V.U.N (92.8 vs. 91.2), but SBGD still uses 5.5× less memory. Against autoregressive and spectral baselines (GraphRNN, SPECTRE, EDGE), SBGD dominates on every available metric with 4.0–6.4× memory savings. Most critically, on OGBN-Products all six baselines fail (OOM or not supported), making SBGD the only method that successfully trains and generates graphs on this large-scale dataset.

## Relation to Prior Work

SBGD extends the graph diffusion generative model (GDGM) lineage—building directly on the SDE-based framework of GDSS (Jo et al., 2022), the discrete Markov-chain approach of DiGress (Vignac et al., 2022), and the x₀-prediction training objective from Chen et al. (2022)—by inserting a Stochastic Block Model structural prior into the diffusion space. Rather than performing the forward/backward diffusion over the full N×N adjacency and feature matrices, SBGD partitions the graph into k block subgraphs via METIS and runs independent diffusion processes on each block (size C ≪ N), with a lightweight cross-block interaction network recovering sparse inter-block edges. This repurposes the classical SBM community-detection insight (Holland et al., 1983) as a compression mechanism for the diffusion latent space, a connection not previously exploited in generative graph modeling.

## Why It Matters / Open Questions

The practical impact is significant: SBGD is the only evaluated method that can train on OGBN-Products, and it achieves up to 6× memory reduction while matching or exceeding SOTA generation quality, making large-scale graph generation feasible on standard hardware. The size-generalization finding—that block-based representation naturally extrapolates to unseen graph sizes because blocks are size-invariant building blocks—opens a path toward a single model handling variable-size outputs, which is critical for applications like molecular design. Open questions include how to automatically select the optimal partition number (the ablation reveals a non-trivial trade-off), whether the METIS partitioning choice is near-optimal, and whether the modularization principle transfers to other structured-data diffusion tasks beyond graphs.

## Problem

Existing event-based reconstruction methods (E2VID, ET-Net, SPADE-E2VID) are designed for in-focus event streams and fail to handle defocus blur, which is a frequent occurrence in event cameras that lack autofocus mechanisms. Unlike motion blur, defocus blur fundamentally reduces spatial intensity gradients, causing fewer and lower-quality events to be generated, making the reconstruction problem highly ill-posed in the temporal domain. No prior work has specifically addressed reconstructing sharp images from out-of-focus event streams.

## Input / Output

The method takes a defocus event stream converted into a 5-channel voxel grid as input and produces a single sharp reconstructed image as output. Real-world data is captured at 346×260 resolution using a DVS 346 camera, while simulated data is generated via ESIM with multi-level Gaussian blur kernels (kernel sizes k=3 to k=11, σ=1.0 to 3.0) to cover varying defocus degrees. The model also consumes optical flow maps for temporal consistency supervision during training.

## Method

EvFocus comprises three key components: (1) a Temporal Information Encoder using three ConvLSTM blocks with 2D downsampling convolutions to capture temporal dependencies from sparse voxel-grid events; (2) a Blur-aware Two-branch Decoder that processes features in parallel through a blur feature decoder (D_blur) and an aligned feature decoder (D_align), with Cross-Modal Fusion (CF) modules concatenating channel-wise to enhance alignment features; and (3) a Reconstruction and Re-defocus Module built on Transformer-based Multi-Head Channel Attention (MHCA) that applies self-attention across channels rather than spatial dimensions to capture long-range blur patterns. A self-supervised mechanism re-defocuses the aligned feature and supervises it against the blur decoder output via L1 loss, enabling the network to learn the defocus blur distribution without explicit blur kernel labels. Training combines LPIPS perceptual loss (weighted 4× for sharp GT, 1× for blur GT), temporal consistency loss (weighted 7×), and L1 re-defocus loss (weighted 1×).

## Results

On simulated defocus event data (Table 1), EvFocus achieves the best mean performance across all three metrics: MSE 0.027, SSIM 0.468, and LPIPS 0.166, outperforming the strongest baseline ET-Net* (MSE 0.028, SSIM 0.396, LPIPS 0.175). The advantage grows with increasing blur severity, e.g., at k=11, σ=3.0 EvFocus reaches SSIM 0.385 versus 0.349 for ET-Net* and 0.184 for E2VID. On real-world DVS346 data (Table 2), EvFocus attains the lowest BRISQUE (27.14) and NIQE (6.35) scores, compared to ET-Net* (31.86 / 6.87) and E2VID (30.98 / 12.51).

| E2VID+ | 0.055 | 0.281 | 0.282 |
| E2VID+* | 0.050 | 0.433 | 0.196 |

| ET-Net* | 0.028 | 0.396 | 0.175 |
| **EvFocus (Ours)** | **0.027** | **0.468** | **0.166** |

## Baselines & Comparisons

EvFocus outperforms all three baselines on every metric in both simulated and real-world evaluations. Against E2VID (Rebecq et al., 2019), the improvement is substantial: SSIM rises from 0.214 to 0.468 (+0.254) and LPIPS drops from 0.384 to 0.166 on simulated data, while NIQE improves from 12.51 to 6.35 on real data. Against E2VID+ (Stoffregen et al., 2020), EvFocus gains 0.187 SSIM and reduces LPIPS by 0.116 on simulated data; even the fine-tuned E2VID+* variant (SSIM 0.433, LPIPS 0.196) remains clearly behind EvFocus. Against ET-Net (Weng et al., 2021), the closest competitor, EvFocus leads by 0.072 SSIM and 0.009 LPIPS on simulated data, and by 4.7 BRISQUE and 1.4 NIQE on real data. The gap widens at higher blur levels (k≥9), where E2VID and E2VID+ degrade sharply while EvFocus maintains relatively stable reconstruction quality.

## Relation to Prior Work

This paper extends the ConvLSTM-based temporal encoding architecture from E2VID (Rebecq et al., 2019) to a new problem: defocus deblurring in the event domain. Prior event-based deblurring work (Jiang et al., 2020; Sun et al., 2022; Kim et al., 2022) focused on motion blur or used events to assist RGB defocus deblurring, while RGB defocus deblurring (Lee et al., 2021; Son et al., 2021) operates purely in the spatial domain. The key conceptual departure is recognizing that defocus fundamentally alters event generation itself—reducing spatial gradients causes 'defocus averaging' that sparsifies events and can flip polarities—making this a temporal-domain problem rather than a spatial restoration one. The blur-aware two-branch decoder with a self-supervised re-defocus module is a novel architectural contribution not present in prior event reconstruction or deblurring pipelines.

## Why It Matters / Open Questions

Event cameras lack autofocus mechanisms, making defocus a persistent practical problem that this work addresses for the first time with a dedicated framework. The theoretical model linking circle-of-confusion geometry to event sparsity and polarity cancellation provides a physically grounded understanding that could inform future event camera design and calibration. Limitations include evaluation only on DAVIS 346 (346×260 resolution), testing up to kernel size 11, and the self-supervised re-defocus mechanism relying on a fixed Gaussian approximation of the PSF. Open questions include generalization to higher-resolution event sensors, handling unknown or spatially-varying blur kernels, and whether the motion-speed–blur-strength equivalence (σ ∝ 1/Vp) can be exploited for unsupervised blur estimation.

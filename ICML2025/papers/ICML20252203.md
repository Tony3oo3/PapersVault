## Problem

KV cache compression at aggressive bit-widths (≤2 bits per value) causes severe accuracy degradation in existing quantization and pruning methods, limiting practical long-context inference. The paper identifies that prior approaches treat each KV cache entry independently, ignoring strong linear dependencies between adjacent layers and between keys and values within a layer that arise from the residual transformer architecture.
![Teaser figure](../imgs/ICML20252203/cropped_page0_idx0.webp)

## Input / Output

During calibration, the method consumes a small set of text sequences (256 × 8192 tokens from RedPajama) to extract KV cache tensors layer-by-layer, training one linear predictor pair per layer. At inference, the method takes newly computed KV entries and the reconstructed (de-quantized) KV entries from the previous layer as predictor inputs, and outputs only the quantized residuals (the unpredictable portion) for storage. The first layer's KV entries are stored at higher precision (4-bit or BF16) since no prior layer exists to predict from, and the first 4 tokens are kept uncompressed to preserve attention sinks.

## Method

AQUA-KV trains compact linear predictors that exploit two dependency structures: (1) previous-layer keys predict current-layer keys, and (2) previous-layer values plus current-layer reconstructed keys predict current-layer values. Only the residual (actual minus predicted) is quantized using a pluggable backbone quantizer (HIGGS vector quantization, QuaRot, or Quanto), so the stored information is strictly the unpredictable component. Calibration is sequential and one-shot: predictors are fitted layer-by-layer using closed-form linear regression, with each subsequent predictor trained on the *reconstructed* (de-quantized) outputs of the previous layer to match inference-time conditions. This design keeps predictor overhead minimal (≤500× fewer FLOPs than the base model per token for 70B models) while achieving near-lossless 2-bit compression on Llama 3.2 models, and the framework is orthogonal to pruning methods like H2O.

## Results

On Llama 3.2 3B at 2-bit KV-cache compression, AQUA-KV (with HIGGS backbone) achieves near-lossless inference: WikiText-2 PPL of 7.03 (vs. 6.98 uncompressed) and LongBench average of 44.30 (vs. 44.61 uncompressed), with under 1% relative error. At 3-bit and 4-bit, AQUA-KV is essentially lossless (PPL 6.98, LongBench 44.37–44.48). The advantage is most pronounced at extreme compression: at 2-bit, AQUA-KV's PPL (7.03) is comparable to the 3-bit baseline quantizer (7.05), effectively gaining one bit of precision from the learned predictors.

## Baselines & Comparisons

AQUA-KV substantially outperforms all quantization-only baselines at 2-bit compression. On Llama 3.2 3B, AQUA-KV achieves PPL 7.03 and LongBench 44.30, versus HIGGS alone (7.47 / 42.80), KIVI (9.34 / 39.64), KVQuant (9.43 / 20.56), and Quanto (21.56 / 33.59). The gap over KVQuant is especially dramatic on LongBench (44.30 vs. 20.56), where KVQuant's per-channel key quantization fails at extreme compression. Against KVSharer (layer merging), AQUA-KV wins on both PPL (7.03 vs. 7.45 for 1 shared pair) and LongBench (44.30 vs. 36.81), and the advantage grows with more shared pairs. At 3-bit and 4-bit, AQUA-KV matches or slightly edges out HIGGS (e.g., PPL 6.98 vs. 7.05 at 3-bit on 3B), while KIVI and KVQuant remain 0.5–0.8 PPL points behind. When combined with H2O pruning (20% tokens kept), AQUA-KV+H2O matches H2O alone on LongBench (38.43 vs. 38.82 on 3B at 2-bit) while achieving 38× memory savings versus 5× for H2O alone, confirming orthogonality with eviction strategies.

## Relation to Prior Work

AQUA-KV builds directly on the HIGGS vector quantization framework (Malinovskii et al., 2024b), adapting its Randomized Hadamard Transform + lattice quantization from weight compression to the dynamic KV-cache setting. Conceptually, it unifies two previously separate lines of KV-cache compression—quantization (KIVI, KVQuant, QuaRot) and cross-layer merging (KVSharer, MiniCache)—by training compact linear predictors that capture inter-layer dependencies and quantizing only the residual, rather than discarding or sharing entire layers. The approach is also related to Residual Vector Quantization (RVQ), but replaces the standard multi-stage quantizer with learned linear predictors, and leverages the near-linearity between adjacent transformer layers (Razzhigaev et al., 2024) as the source of predictability.

## Why It Matters / Open Questions

AQUA-KV achieves near-lossless 2-bit KV-cache compression (under 1% relative perplexity error) across Llama 3.x and Qwen 2.5 families, which is practically significant for long-context deployment where cache memory dominates. The one-shot calibration (1–6 hours on a single GPU, even for 70B models) and compatibility with arbitrary quantizers and pruning (H2O) make it a drop-in improvement for existing inference stacks. Open questions include: why LLMs learn such predictable KV representations in the first place (hinting at architectural redundancy in attention projections), whether predictors can be co-optimized with model-level objectives, and how to reduce the ~18% inference overhead for very long sequences. The paper deliberately keeps the method simple (linear predictors, fixed bit-widths), leaving room for adaptive bit-width allocation and integration with production inference engines like vLLM.

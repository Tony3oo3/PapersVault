## Problem

Few-shot OOD detection—training on only a handful of labeled in-distribution images per class while detecting arbitrary out-of-distribution test samples—remains largely unsolved. Existing few-shot OOD methods are sensitive to image backgrounds, ignore the varying diversity levels across classes, and degrade sharply as the number of classes grows, because a single global threshold cannot capture class-specific distribution boundaries.
![Teaser figure](../imgs/ICML20250613/cropped_page1_idx1.webp)

## Input / Output

The method consumes RGB images (processed at 224×224 through a frozen CLIP-ViT-B/16 image encoder) together with three families of learnable text prompts (learnable ID prompts, label-fixed OOD prompts, and label-adaptive OOD prompts) encoded by the shared CLIP text encoder. During training only K labeled ID images per class are available (K ∈ {1, 2, 4, 8, 16}); OOD images and their labels are entirely inaccessible. At inference the model outputs either an ID class label or an OOD flag, with the decision governed by a per-class adaptive P-score threshold rather than a single global cutoff.

## Method

AMCN builds three coupled modules on top of a pretrained CLIP backbone. First, an Adaptive Prompt Generation module constructs three prompt types per class—learnable ID prompts (LIPs) with trainable prefixes, label-fixed OOD prompts (LFOPs) that borrow disjoint labels from other datasets, and label-adaptive OOD prompts (LAOPs) whose prefixes and labels are both learnable—then forms prototypes via average pooling. Second, a Prompt-based Multi-diversity Distribution Learning module estimates per-class mean and standard deviation of a class distribution score, derives a class-wise P-score threshold, and enforces intra-class and inter-class distribution normalization through two auxiliary losses to handle the fact that different classes exhibit very different sample diversity. Third, a Prompt-guided OOD Detection module introduces an explicit Euclidean-distance margin loss that pushes ID image features closer to the ID prompt prototype than to the OOD prompt prototype, a weighted OOD alignment loss that keeps LAOPs semantically distinct from ID prompts, and a multi-prompt contrastive loss that minimizes ID–OOD prompt similarity. The overall training objective combines the ID classification contrastive loss, the separation loss, the alignment loss, and the OOD contrastive loss with balanced hyperparameters, all optimized with AdamW for 100 epochs.

## Results

AMCN achieves the best FPR95 and AUROC across all four OOD sets (Texture, Places, SUN, iNaturalist) in both 1-shot and 8-shot settings. Under the 1-shot setting, AMCN reaches FPR95 of 39.16 on Texture (vs. 48.87 for SCT, the strongest few-shot baseline) and AUROC of 96.18 on iNaturalist. Under the 8-shot setting, AMCN achieves FPR95 of 38.31 on Texture and AUROC of 96.89 on iNaturalist, outperforming all few-shot and zero-shot baselines. The method also surpasses fully-supervised methods (e.g., NPOS) on FPR95 in most settings despite using only 1–8 labeled images per class.

## Baselines & Comparisons

AMCN outperforms all few-shot baselines (CoOp, LoCoOp, SCT) on every OOD set and metric in both 1-shot and 8-shot settings. The largest gap is on Texture FPR95 under 1-shot, where AMCN (39.16) beats SCT (48.87) by 9.71 points and CoOp (50.64) by 11.48 points. On SUN AUROC, AMCN improves over SCT by 0.27% (1-shot) and 1.12% (8-shot), and over LoCoOp by 1.18% (1-shot) and 2.66% (8-shot). Against zero-shot methods, AMCN achieves substantially lower FPR95 (e.g., 39.16 vs. 57.93 for GL-MCM on Texture 1-shot) while also matching or exceeding their AUROC. Compared to fully-supervised methods, AMCN with only 8 shots surpasses NPOS on FPR95 for Texture (38.31 vs. 46.12) and iNaturalist (18.17 vs. 16.58 is the one case where NPOS leads), while matching or exceeding their AUROC on most sets.

## Relation to Prior Work

AMCN extends the prompt-learning line of work for few-shot OOD detection (CoOp, LoCoOp, SCT) by introducing OOD-side prompts (label-fixed and label-adaptive) alongside the standard learnable ID prompts, enabling multi-prompt contrastive learning that prior few-shot OOD methods lack. It also departs from the uniform-threshold assumption in earlier OOD detectors by learning a class-wise P-score threshold that accounts for the varying intra-class diversity observed across ImageNet categories. Conceptually, the method repurposes CLIP's text-image alignment to synthesize OOD textual anchors from disjoint label sets, bridging the gap between zero-shot OOD detection (MCM, GL-MCM) and few-shot prompt tuning without requiring any OOD images during training.

## Why It Matters / Open Questions

Few-shot OOD detection is critical for safety-critical deployments (autonomous driving, medical imaging) where collecting thousands of labeled in-distribution samples per class is impractical, and the multi-diversity framing captures a real failure mode—classes like 'cat' vs. 'ox' have very different visual spread—that prior methods treat uniformly. Open questions include how the method scales when the number of ID classes grows substantially (the paper tests only ImageNet-1k), whether the OOD prompt construction generalizes when no disjoint label set is available, and whether the class-wise threshold learning remains stable under distribution shift at test time. The reliance on CLIP's pretrained text encoder also raises questions about domain transfer to non-natural-image settings.

## Problem

Existing backdoor defenses for CLIP operate in the pre-training or fine-tuning stage, requiring expensive parameter updates and full model access, making them inapplicable in black-box settings where only inference APIs are available. No prior work has addressed backdoor sample detection at the inference stage for multimodal contrastive models like CLIP.
![Teaser figure](../imgs/ICML20251870/cropped_page2_idx0.webp)

## Input / Output

The method takes a single test image and a set of pre-generated class-specific prompts (benign: m fine-grained attribute descriptions per class; malignant: a class template concatenated with a random unrelated sentence per class), all produced offline by GPT-4 or an open-source LLM. It outputs a scalar contrastive distribution difference score Ω(x) computed across all classes in the label space, which is compared against a threshold ε (set from the 85th percentile of a small clean validation sample) to yield a binary backdoor/clean label. No image modifications or multiple forward passes are required—only two encoder evaluations per image (one for benign, one for malignant prompts).

## Method

BDetCLIP exploits the observation that backdoored images' visual representations are insensitive to semantic changes in class description texts, because the implanted trigger is a non-semantic pixel pattern that cannot align with rich textual concepts. The method uses contrastive prompting: GPT-4 generates benign prompts (multiple fine-grained attribute-based sentences per class, e.g., shape, color, behavior) and malignant prompts (class template plus a random unrelated sentence). For each test image, it computes the sum over all classes of the difference between the cosine similarity with the averaged benign text embeddings and the cosine similarity with the malignant text embedding. Backdoored images yield a smaller distribution difference (less sensitivity to text changes) than clean images, so a threshold on this score flags them as backdoored. The entire procedure requires no parameter updates, operates in a black-box setting, and completes detection in roughly 3 minutes for 50,000 images—over 160× faster than the next-best baseline.

## Results

BDetCLIP achieves an average AUROC of 0.938 across multimodal attacks (BadCLIP-1, BadCLIP-2, TrojVQA, BadEncoder) and 0.972 across traditional attacks (BadNet, Blended, BadNet-LC, Blended-LC, ISSBA, WaNet) on ImageNet-1K. On fine-grained datasets, BDetCLIP reaches 0.959 average AUROC on Food-101 and 0.983 on Caltech-101. In terms of efficiency, BDetCLIP completes detection of 50,000 test samples in 3 minutes 8 seconds, compared to 253 minutes for STRIP, 9 minutes for SCALE-UP, and 637 minutes for TeCo.

## Baselines & Comparisons

BDetCLIP outperforms all three unimodal test-time baselines (STRIP, SCALE-UP, TeCo) across nearly every attack setting and dataset. Against STRIP, the gap is most dramatic on multimodal attacks (0.938 vs. 0.594 average AUROC) and on Blended attacks (0.983 vs. 0.111), where STRIP essentially fails. SCALE-UP is the strongest unimodal competitor on traditional attacks (0.735 avg AUROC) but still trails BDetCLIP by 23.7 points; on multimodal attacks the gap widens to 16.7 points (0.938 vs. 0.771). TeCo is competitive on some traditional attacks (e.g., 0.979 on Blended-LC) but collapses on multimodal attacks (0.469 avg) and is 160× slower in inference time. In the Appendix C comparison using ASR (backdoor ratio = 1), BDetCLIP reduces ASR to 0.0444 on BadCLIP, outperforming CleanCLIP (0.9196), CleanerCLIP (0.2808), PAR (0.312), and RoCLIP (0.1330), though these fine-tuning/pre-training defenses operate under fundamentally different assumptions (white-box, parameter access) than BDetCLIP's black-box test-time setting.

## Relation to Prior Work

This paper extends unimodal test-time backdoor detection (STRIP, SCALE-UP, TeCo) to the multimodal CLIP setting by leveraging the text encoder as an additional detection signal. It departs from prior CLIP backdoor defenses (CleanCLIP, RoCLIP, TIJO) that require access to model parameters for fine-tuning or trigger inversion, instead operating purely at inference time in a black-box setting. The method also builds on the recent line of work using LLMs (GPT-4) to generate fine-grained class descriptions for CLIP zero-shot classification, repurposing these prompts as a contrastive detection mechanism rather than a classification aid.

## Why It Matters / Open Questions

BDetCLIP addresses a practical gap: defenders who only have API access to a third-party CLIP model cannot apply existing pre-training or fine-tuning defenses, yet still need to filter malicious inputs at inference time. The 160× speedup over TeCo and the black-box applicability make this immediately deployable in production pipelines. Key limitations include reliance on a single model family (CLIP), a simple percentile-based threshold strategy, and the assumption that triggers remain non-semantic; the authors themselves flag adaptive attacks with semantically-adaptive triggers as a future threat. Open questions include whether the text-sensitivity signal generalizes to other VLM architectures (e.g., LLaVA, Flamingo) and how prompt quality systematically affects detection robustness.

## Problem

Chatbot Arena's crowdsourced pairwise voting is widely regarded as a reliable LLM ranking mechanism, but prior work only identified inefficient 'target-only' rigging (voting exclusively when the target model appears in a battle, which occurs in ~1% of battles with 190+ models). This paper exposes a far more efficient attack: because Bradley-Terry scores are computed by jointly fitting pairwise logistic relationships over all votes, any new vote between any two models can shift the target model's ranking even when the target is not involved, enabling rank manipulation with only hundreds of votes rather than tens of thousands.

## Input / Output

The adversary's input consists of (1) a fine-tuned RoBERTa multi-class classifier that maps a user prompt and an anonymous model response to a predicted model identity, (2) either the full historical vote set V_H (~1.7M records across 129 models) or only the public BT score vector r_VH^BT, and (3) optionally the sampling distribution P_V. For each new battle between two sampled models, the method outputs a single voting decision from {a wins, b wins, Tie, Abstain}. The classifier is trained with 4,000 prompts per model over 20 epochs (batch size 64, ~hours on 2× A100 GPUs), and the rigging loop processes new votes sequentially, optionally updating local score estimates after each manipulation.

## Method

The core insight is the 'omni-property': since BT scores are obtained by minimizing a joint cross-entropy loss over all pairwise votes (Eq. 1), the scores of all K models are mutually coupled, so a vote between m_a and m_b propagates through the logistic fit to alter r[t] even when t∉{a,b}. Two omnipresent strategies exploit this. Omni-BT (full-vote access) evaluates all four voting options for each new battle by recomputing BT scores on V_H ∪ {candidate vote} and selects the option maximizing the relative rating gap r'[t] − r'[t̂] where t̂ is the model ranked one position above m_t. Omni-On (score-only access) approximates BT updates via online Elo increments with step size μ and logistic win-rate function W, then selects the vote maximizing W(r_VH^BT[t], r_a^On) + W(r_VH^BT[t], r_b^On), keeping the base BT scores fixed across iterations to avoid Elo-update instability. De-anonymization is handled by a RoBERTa classifier fine-tuned with cross-entropy loss to predict model identity from response text, achieving ~79% top-1 accuracy. The paper further stress-tests both strategies under inaccurate de-anonymization, unknown sampling distributions, and concurrent user voting, and evaluates three defenses (duplicate-vote detection, likelihood-based anomaly detection, and pairwise-win-rate vote filtering), finding that none fully eliminates the rigging effect.

## Results

In the realistic case study (threat model: BT scores only, anonymous models, unknown sampling, concurrent votes), Omni-BT achieves an average 5-rank improvement and Omni-On achieves 3-rank improvement across four target models (Llama-2-13B-Chat, Mistral-7B-Instruct-v0.2, Qwen1.5-14B-Chat, Vicuna-7B), compared to only ~1.75-rank for the best target-only baseline (T-Abstain). In the idealized scenario with 20,000 rigged votes, omnipresent strategies yield approximately 10-rank promotion versus ~4-rank for target-only. Critically, omnipresent strategies remain effective even when the target model is never sampled (β=0), achieving +5 to +6 rank improvement, while target-only strategies fail completely under the same condition.

## Baselines & Comparisons

The paper compares against two concurrent target-only rigging works: Zhao et al. (2024) using watermarking/attribution and Huang et al. (2025) using a binary classifier, both of which only rig votes when the target model is directly involved. In the idealized setting (20,000 votes), the omnipresent strategies (Omni-BT, Omni-On) achieve roughly double the ranking improvement of the best target-only variant (~10 vs ~4 ranks). In the realistic case study, Omni-BT outperforms T-Abstain by 3–6 ranks per model (e.g., +9 vs +3 for Vicuna-7B, +5 vs +1 for Llama-2-13B-Chat), while Omni-On outperforms by 1–4 ranks. Under the stress test where the target model is never sampled (β=0), all target-only variants fail (0 to −3 rank change) while Omni-BT and Omni-On still achieve +5 and +6 rank improvement respectively. The omnipresent strategies also demonstrate greater resilience to inaccurate de-anonymization (50% anonymous battles: Omni-On retains +6 rank vs T-Abstain's +2) and to concurrent user voting (100,000 concurrent votes cause only ~1-rank degradation).

## Relation to Prior Work

This paper builds on the Bradley-Terry model and Elo rating system that underpin Chatbot Arena's scoring, and draws on LLM identification techniques (watermarking, style-based classifiers) for the de-anonymization component. It directly extends two concurrent works (Zhao et al., 2024; Huang et al., 2025) that demonstrated target-only vote rigging via watermarking or binary classifiers, subsuming those as baselines. The key conceptual departure is the 'omni-property' observation: because BT scores are computed by globally fitting pairwise logistic relationships across all votes, any new vote on any battle pair can shift a target model's ranking even when that model is not involved, enabling omnipresent rigging strategies that manipulate every vote rather than only ~1% involving the target.

## Why It Matters / Open Questions

Chatbot Arena is the most widely recognized LLM evaluation platform, and the finding that rankings can be shifted by 10+ positions with only hundreds of rigged votes (versus 10,000+ for target-only) undermines trust in the entire leaderboard ecosystem and creates immediate promotional incentives for model developers to game the system. The paper's evaluation of defenses (duplicate detection, anomaly detection, pairwise win-rate filtering) shows they reduce but do not eliminate the manipulation effect, leaving a critical open question: what architectural or statistical changes to the rating mechanism would make it fundamentally resistant to coordinated vote manipulation? The findings also generalize to other emerging voting-based evaluation systems (Copilot Arena, WebDev Arena), making this a broader concern for the LLM evaluation community.

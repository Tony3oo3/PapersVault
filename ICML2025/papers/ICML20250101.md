## Problem

NP-hard permutation optimization problems (e.g., TSP, Maximum Acyclic Subgraph, scheduling) cannot be solved exactly in polynomial time without predictions. This paper asks whether pairwise ML predictions about the ordering of elements in an optimal solution—each correct with probability at least 1/2 + ε—can enable exact polynomial-time solutions, and identifies the structural properties of the objective function that make this possible.

## Input / Output

The algorithm receives a permutation optimization problem instance on n elements and has access to O(n²) pairwise prediction queries q(a_i, a_j) indicating whether a_i precedes a_j in a fixed optimal permutation, each independently correct with probability ≥ 1/2 + ε. Crucially, the algorithm is parsimonious: it queries only O(n log n) of the available predictions (a tight lower bound even for perfect predictions). The output is the exact optimal permutation, achieved with high probability in polynomial time whose exponent depends on ε.

## Method

The framework builds on Braverman and Mossel's noisy sorting: O(n log n) prediction queries yield a permutation π* within O(log n) positions of the true optimum σ* (Theorem 2.5), reducing the problem to its O(log n)-position-enhanced version. Two structural properties then enable polynomial-time dynamic programming: (1) the decomposition property, where the objective on a sub-interval [i,j] decomposes into left and right sub-interval values plus a correction term h depending only on element sets (not their order), and (2) c-locality, where the cost depends only on c consecutive elements in the permutation. For decomposable problems, the DP runs in O(n·2^{O(k)}·t) for k = O(log n); for c-local problems, in O(n·2^{2k}·k^{c+1}). The paper further proves the O(log n) position-enhancement bound is tight: for any unbounded f, f(n)log n-position-enhanced versions of Maximum Acyclic Subgraph and TSP remain intractable under ETH.

## Results

The main result (Theorem 1.1) shows that any permutation optimization problem satisfying either the decomposition property or c-locality can be solved exactly with high probability (1 − n^{−α}) in polynomial time n^{O((α+1)ε^{−4})}, using only O(n log n) prediction queries (parsimonious access). The DP for decomposable problems runs in O(n · 2^{O(k)} · t) and for c-local problems in O(n · 2^{2k} · k^{c+1}), both polynomial when k = O(log n). The O(log n) position-enhancement bound is proven tight: for any unbounded function f, f(n)log n-position-enhanced Max Acyclic Subgraph and TSP remain intractable under ETH (Propositions 5.3–5.4).

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The framework builds directly on Braverman & Mossel (SODA 2008), extending their noisy-sorting-without-resampling algorithm from the single problem of finding an s-optimal permutation to a broad class of NP-hard permutation problems (Maximum Acyclic Subgraph, Minimum Linear Arrangement, TSP, scheduling, keyword auctions with externalities). The key advance over the prior work is the identification of two structural properties (decomposability and c-locality) that guarantee polynomial-time solvability under O(log n) position enhancement, combined with a parsimonious query budget of O(n log n) (matching the information-theoretic lower bound). The paper also shows that the O(log n) bound cannot be relaxed to f(n)log n for any unbounded f, establishing a sharp boundary for the framework's applicability.

## Relation to Prior Work

This paper extends the noisy sorting framework of Braverman and Mossel (SODA 2008) from the single problem of sorting to a broad class of NP-hard permutation optimization problems, introducing two structural conditions (decomposition property and c-locality) that characterize when predictions suffice for exact polynomial-time solvability. It departs from concurrent work on learning-augmented algorithms for specific NP-hard problems (MAXCUT by Cohen-Addad et al., 2024; Maximum Independent Set by Braverman et al., 2024), which achieved approximation guarantees, by providing a general framework that yields exact solutions. The parsimonious query complexity of O(n log n) connects to the parsimonious algorithms paradigm of Im et al. (2022), and the prediction model is inspired by the noisy comparison model of Braverman and Mossel rather than the vertex-level prediction models used in the MAXCUT literature.

## Why It Matters / Open Questions

The paper provides a clean, general criterion (decomposability or c-locality) under which NP-hard permutation problems become exactly solvable in polynomial time with predictions, and proves the O(log n) position-enhancement bound is tight—no unbounded function f(n)·log n suffices. A key open question the authors highlight is whether ML models can actually produce predictions correct with probability 1/2+ε for optimal permutations of hard instances, which is a strong assumption; they sketch a Mallows-distribution-based learning scenario but acknowledge this remains speculative. The framework's practical impact will depend on the maturation of ML predictors for discrete optimization, and the tightness results (Section 5) delineate a sharp boundary beyond which predictions cannot help, which is valuable for guiding future prediction model design.

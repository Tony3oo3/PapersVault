## Problem

While gradient descent and Bayesian interpretations of in-context learning (ICL) exist, there is no concrete mechanistic account of how prompt examples reshape a transformer's internal computations without parameter updates. This paper addresses that gap by providing an exactly solvable example that interprets ICL in one-layer attention models as conditional retrieval in a dense associative memory (modern Hopfield) model, bridging an abstract Bayesian statistical explanation with analytic network dynamics from neuroscience.

## Input / Output

The method takes a sequence of t in-context prompt examples (query-response pairs) plus a test query as input, where queries and responses are single-token vectors in fixed-dimensional spaces. Beyond the predicted response, the key outputs are explicit linear reshaping matrices W₁ and W₂ (computed via Moore-Penrose pseudoinverses) that transform the pre-trained key and value projection matrices, effectively reconfiguring the Hopfield energy landscape. A critical auxiliary input is a set of t 'ghost examples' constructed via prompt tuning, which serve as a no-prompt baseline enabling direct comparison of attention outputs with and without in-context demonstrations.

## Method

The core insight is that a sequence of t in-context examples induces an implicit linear mapping on the pre-trained attention weights: the key projection transforms as W_K^* → W_K^* C_t (W_K^* C̃_t)^† W_K^* and the value projection analogously, where C̃_t and R̃_t are ghost-example matrices. This 'in-context memory reshaping' is derived by comparing the proxy attention output with real prompts (Eq. 5) against an equivalent formulation using ghost prompts (Eq. 7), showing that ICL is equivalent to applying linear transformations to the stored memory patterns without any parameter updates. The reshaping is then embedded into the Bayesian model averaging framework of Zhang et al. (2025), yielding a closed-form Gaussian posterior for the hidden concept Z* and recovering the known ε-stability generalization bound of O(1/t) for one-layer attention. The paper further validates three empirical behaviors—sensitivity to covariance shifts, response accuracy, and prompt-test query similarity—on GPT-2 (linear regression, decision trees, 2-layer networks) and GPT-J (sentiment classification), attributing each to how the reshaped memory distribution diverges from the pre-trained distribution.

## Results

The paper's main theoretical contribution is Theorem 3.1, which establishes the generalization bound E[R(D_t) − R_emp(D_t)] ≤ MC₀(4Γ+1)e^{2Γ}/t for one-layer attention ICL, recovering the known ε-stability bound of Li et al. (2023). Empirically, on the linear regression task with GPT-2, ICL achieves R² ≈ 0.9999 at 45 in-context examples when the test distribution matches pre-training (N(−2,I)), but degrades to R² ≈ 0.67–0.73 under a larger covariance shift (0.7N(−2,I)+0.3N(2,I)). Ghost example construction via prompt tuning achieves mean squared error of 0.0003 (matching distribution) and 0.001 (shifted distribution) across all prompt lengths up to 75.

## Baselines & Comparisons

This paper does not benchmark against competing ICL methods; instead, it validates its theoretical memory-reshaping predictions against oracle baselines (Least Squares for linear regression, Decision Tree, and 2-Layer NN trained for 100 GD steps). Under the matching-distribution setting, ICL with 30–45 examples nearly matches the oracle (R² ≈ 0.9998–0.9999 vs. 1.0 for Least Squares), confirming that the memory reshaping mechanism recovers the optimal solution. Under a 30% covariance shift (0.7N(−2,I)+0.3N(2,I)), ICL R² drops to ~0.67–0.73, well below the oracle, consistent with the theory that larger distribution shifts make memory reshaping harder. The generalization bound in Theorem 3.1 exactly recovers the ε-stability guarantee from Li et al. (2023), confirming that the one-layer attention model under the memory-reshaping interpretation satisfies the same established generalization guarantees. Performance also degrades monotonically with lower response accuracy (R² drops from ~1.0 at 100% to ~0.85–0.92 at 80%) and lower prompt–query similarity (R² drops from 0.9998 to 0.9993 at 45 examples), all consistent with the memory-reshaping explanation.

## Relation to Prior Work

This paper bridges two previously separate theoretical lenses on in-context learning: the Bayesian model averaging framework of Zhang et al. (AISTATS 2025) and the modern Hopfield network / associative memory perspective rooted in Ramsauer et al. (ICLR 2020). The key conceptual move is interpreting ICL as 'memory reshaping' in a Hopfield model, where in-context examples act as queries that induce a linear transformation on the pre-trained key and value matrices (Eq. 9), effectively relocating attractors in the energy landscape without parameter updates. This extends the memory reshaping idea from Wu et al. (ICML 2024), which was originally about training-time capacity optimization, to the inference-time ICL setting. The paper also recovers the ε-stability generalization bound of Li et al. (ICML 2023) within this new framework, confirming that the memory-reshaping interpretation is consistent with established ICL generalization theory.

## Why It Matters / Open Questions

The unified Hopfield-Bayesian perspective offers a concrete mechanistic story for how prompts modulate transformer computations, complementing the more abstract Bayesian view with an energy-landscape interpretation that could guide prompt engineering (select similar examples, increase prompt count, keep norms bounded). However, the analysis is restricted to a one-layer proxy attention mechanism with single-token prediction, and the ghost-example construction—central to the comparison—relies on prompt tuning and has not been fully validated in actual multi-layer LLMs. Extending the framework to multi-layer transformers, actual (non-proxy) attention, and multi-token autoregressive generation remains open, as does verifying the exact memory-reshaping matrices in real model internals.

## Problem

When an ML model is transferred across domains, performance decay is rarely uniform: some subgroups suffer large drops while others are unaffected. Existing methods either decompose average performance shifts into covariate versus outcome contributions or discover poorly performing subgroups, but no prior approach simultaneously identifies *which* subgroups experience unacceptably large decay *and* explains *how* it arose (i.e., which sparse variable subsets drove the shift) through valid statistical tests without requiring parametric models or known causal graphs.

## Input / Output

SHIFT consumes a pre-trained model f along with paired source and target domain datasets (X, Y), and requires the analyst to pre-specify three thresholds: minimum subgroup prevalence ε, minimum performance decay magnitude τ, and significance level α. The output is a two-level hierarchical diagnostic: aggregate-level flags indicating whether any sufficiently large subgroup suffers decay exceeding τ due to covariate or outcome shift (with a rule-based decision set describing the detected subgroup), followed by detailed-level flags identifying which variable subsets offer a sufficient explanation. Inference is conducted on a held-out data partition after nuisance parameters and candidate detectors are fit on a training partition, and p-values are obtained via Gaussian multiplier bootstrap.

## Method

SHIFT is a two-stage nonparametric hypothesis testing framework built on the Maximum Expected Exceedence (MEE), a subgroup-conditional analogue of MMD that measures the worst-case performance decay across all subgroups exceeding a prevalence threshold. Stage 1 (Where?) tests whether the aggregate covariate or outcome shift produces MEE > τ in any subgroup; Stage 2 (How?) tests whether a candidate sparse variable-subset-specific shift (e.g., p_s(x) = p_1(x_s)p_0(x_{-s}|x_s) for covariate shift) adequately explains the observed subgroup-level decay. To handle the intractable supremum over infinitely many binary subgroup detectors, SHIFT uses sample splitting: one partition fits flexible ML nuisance parameters (conditional loss models, density ratios) and candidate detectors (via plug-in thresholding for outcome shifts or Lagrange-multiplier grid search for covariate shifts), and the other partition evaluates a restricted MEE with one-step (double/debiased) correction to achieve asymptotic linearity. A key technical innovation is a binning trick that replaces the continuous outcome probability μ_0(x) with a discretized version, rendering the detailed outcome-shift MEE pathwise differentiable so that standard semiparametric influence-function machinery applies. The resulting debiased estimators are shown to be asymptotically normal, enabling valid Type I error control and asymptotic power-one tests via Gaussian multiplier bootstrap, without parametric assumptions or knowledge of the true causal graph.

## Results

In simulation studies, SHIFT achieves substantially higher statistical power than kernel-based baselines for detecting subgroup-level performance shifts: 0.56 vs 0.26 (KCI) and 0.06 (MMD) for outcome shifts, and 0.94 vs 0.0 (KCI) and 0.46 (MMD) for covariate shifts. In the real-world insurance prediction case study, the SHIFT-guided targeted model update achieves 74.8 AUC overall (vs 73.0 for non-targeted updates) while also improving performance in previously-decayed subgroups (67.7 AUC vs 67.3 for the original model's affected subgroup). In the readmission prediction case study, SHIFT identifies 'num ED encounters' as the root cause of both covariate and outcome shifts; correcting its data extraction eliminates the significant subgroup-level accuracy drop (15.4% in a subgroup comprising 41.8% of target data).

## Baselines & Comparisons

SHIFT outperforms MMD (Gretton et al., 2012) by a wide margin on aggregate shift detection power: 0.56 vs 0.06 for outcome shifts and 0.94 vs 0.46 for covariate shifts, attributed to SHIFT's use of flexible ML estimators versus MMD's kernel-based approach that degrades in high dimensions. Against TE-VIM (Hines et al., 2023) for detailed outcome shift explanations, SHIFT correctly flags only the relevant variable X₁ while TE-VIM fails to identify any variable due to degenerate behavior at the null; in the insurance case study, TE-VIM flags only employment-related variables whereas SHIFT correctly identifies demographics. For detailed covariate shift detection, Score (Kulinski et al., 2020) and KCI both incorrectly flag the irrelevant variable X₄ alongside the true X₁, because they test for marginal distribution shifts without accounting for whether the variable actually affects model performance. Overall, SHIFT is the only method that simultaneously provides valid hypothesis tests, respects the user-specified tolerance τ, and correctly identifies only the variables contributing to performance decay above that threshold.

## Relation to Prior Work

SHIFT builds on the distribution shift detection literature (MMD, KCI, KS) and the performance decomposition literature (covariate vs. outcome shift attribution), but departs from both by reframing drift diagnosis as a hierarchical hypothesis testing problem rather than an estimation problem. The inference machinery draws directly on double/debiased machine learning (Chernozhukov et al., 2018) and V-statistic theory, while the mathematical structure of the tests parallels causal mediation analysis (direct/indirect effect decomposition). The key conceptual departure is the use of omnibus tests over a class of subgroups (Maximum conditional Mean Discrepancy) rather than point estimates of average performance change, which prior methods like TE-VIM or causal change attribution provide without valid statistical guarantees.

## Why It Matters / Open Questions

SHIFT provides the first framework that simultaneously answers 'where' (which subgroup suffers large decay) and 'how' (which variable subset explains it) with controlled Type I error, enabling targeted model corrections that avoid the 'don't fix what ain't broke' problem. The real-world validation—where a targeted fix based on SHIFT's diagnosis outperformed non-targeted retraining across all subgroups—demonstrates practical value for clinical AI deployment. Limitations include the need for prespecified tolerance τ and minimum subgroup size ε, restricted candidate shift definitions, and validation primarily on tabular data; extending to unstructured data (images, text) via concept bottleneck models is identified as future work. Open questions include whether the grid-search approach for covariate detectors scales to very high-dimensional settings and how to handle correlated candidate shifts.

## Problem

Prompt learning methods for CLIP (e.g., CoOp, CoCoOp) significantly improve target-specific base-class accuracy but degrade on target-unspecific generalization tasks (base-to-novel, domain, cross-dataset) due to overfitting-induced catastrophic forgetting. Even regularization approaches using a single hand-crafted prompt (e.g., KgCoOp) fail to fully recover CLIP's original generalization capability, because a single prompt cannot capture the diverse semantics embedded in the pre-trained model.

## Input / Output

The method consumes RGB images (processed by a frozen ViT-B/16 or similar CLIP image encoder) and a fixed set of 60 hand-crafted prompt templates (e.g., 'a photo of a [class]', 'a picture of a [class]') paired with all K class names to form a pre-computed Features Matrix from the frozen text encoder. It outputs standard class labels with softmax probabilities over K classes. Notably, the FM module introduces zero additional learnable parameters; it only adds a contrastive alignment loss during training, making it a drop-in module for existing prompt-tuning frameworks.

## Method

The Features Matrix (FM) approach extracts general knowledge by passing 60 hand-crafted prompt templates × K class names through the frozen CLIP text encoder, producing a pre-trained feature matrix of shape (60×K, d). During training, for each image's tuning visual feature v^tun, the method computes cosine similarities against all matrix entries, then identifies 'unexpected' features: the low-β scoring entries among designated (correct-class) features and the top-β scoring entries among non-designated (wrong-class) features. A contrastive loss L_CL is applied to pull v^tun toward the unexpected designated features and push it away from the unexpected non-designated features, targeting the hardest-to-distinguish semantic regions. The total objective is L_total = L_CE + γ·L_CL (γ=0.1, β=5), where L_CE is the standard cross-entropy alignment loss of the underlying prompt-tuning framework. The FM module is architecture-agnostic and plugs into CoOp, CoCoOp, MaPLe, or PromptSRC without modifying their parameterization, adding no learnable parameters while consistently improving novel-class and cross-domain accuracy.

## Results

On the base-to-novel generalization task (16-shot, 11 datasets), the proposed Features Matrix (FM) module integrated with PromptSRC achieves 85.70% base accuracy, 77.35% novel accuracy, and 81.32% harmonic mean (HM), the best among all compared methods. When integrated with CoOp, FM lifts novel-class accuracy from 63.22% (CoOp alone) to 74.66%, surpassing the hand-crafted CLIP baseline (74.22%). On domain generalization (ImageNet → 4 variants), PromptSRC+FM attains 61.92% average, outperforming PromptSRC+DePT (60.93%). On cross-dataset generalization (ImageNet → 10 unseen datasets), PromptSRC+FM reaches 67.62% average, the highest among all methods.

## Baselines & Comparisons

The FM module is evaluated as a plug-and-play add-on to four representative prompt-learning frameworks (CoOp, CoCoOp, MaPLe, PromptSRC) and compared against DePT (CVPR 2024), the strongest existing easy-to-use baseline. FM consistently outperforms DePT on HM across all four backbones: 77.79 vs 77.29 (CoOp), 78.52 vs 77.97 (CoCoOp), 80.32 vs 79.52 (MaPLe), and 81.32 vs 80.43 (PromptSRC). The most striking gain is on novel-class accuracy: CoOp+FM reaches 74.66% novel, exceeding the hand-crafted CLIP zero-shot baseline (74.22%) by 0.44 points, whereas CoOp alone drops to 67.96%. On domain generalization, PromptSRC+FM (61.92% avg) beats PromptSRC+DePT (60.93%) by 0.99 points, with the largest margin on ImageNet-Sketch (51.33 vs 50.15). On cross-dataset generalization, PromptSRC+FM (67.62% avg) leads PromptSRC+DePT (66.02%) by 1.60 points, winning on 10 of 10 target datasets. The only trade-off is a slight base-class drop (e.g., 81.15 vs 83.66 for CoOp) and ~25% slower training (13.56 min vs 10.91 min on SUN397), attributed to the additional cosine-similarity computations over the 60-prompt features matrix.

## Relation to Prior Work

This paper extends the prompt learning lineage for CLIP-based VLMs (CoOp, CoCoOp, MaPLe, PromptSRC) by introducing a Features Matrix (FM) that leverages multiple hand-crafted prompt templates to form a pre-trained text feature matrix, then applies a contrastive loss on 'unexpected' features (low-scoring designated and high-scoring non-designated entries) to preserve general knowledge during fine-tuning. It departs from prior regularization approaches like KgCoOp, which constrains fine-tuned features to a single hand-crafted prompt via L1 loss, by arguing that a matrix of diverse prompts more thoroughly excavates the semantics embedded in CLIP's pre-trained representations. The FM is positioned as a zero-parameter, plug-and-play module orthogonal to the underlying prompt learning architecture, rather than a new prompting paradigm itself.

## Why It Matters / Open Questions

The zero-parameter, framework-agnostic design makes FM an attractive drop-in regularization for practitioners already using CoOp, MaPLe, or PromptSRC who observe degraded generalization on novel or out-of-domain classes. However, the method introduces a training-time cost (13.56 min vs. 10.88 min for CoOp on SUN397) due to multiple cosine similarity computations, and the authors acknowledge that ImageNet source-domain accuracy lags behind DePT. Open questions include whether the FM approach transfers to other VLM backbones beyond CLIP, whether the number of prompt templates (fixed at 60) can be adapted per dataset, and whether the 'unexpected feature' selection strategy generalizes to tasks beyond classification such as detection or segmentation.

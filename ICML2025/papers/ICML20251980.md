## Problem

LLM-based program synthesis methods treat the language model as a fixed component, so evolutionary search performance is ultimately bounded by the model's static sampling and refinement capabilities, yielding diminishing returns with more search budget or larger models. The paper asks whether a synthesis system can learn to improve its own search operators from its own search experience, without relying on human-generated solutions or hand-engineered domain-specific languages.
![Teaser figure](../imgs/ICML20251980/cropped_page1_idx0.webp)

## Input / Output

Each ARC task provides 2–10 training pairs of colored grids (1–30 × 1–30, integer colors 0–9) plus one or more test input grids. The system synthesizes a Python `transform` function (inductive approach) and executes it on the test inputs to produce output grids; final answers are selected via weighted majority voting over 6k candidate programs (3k sampled + 3k refined), returning up to 2 candidate output grids per the benchmark rules.

## Method

SOAR alternates between a Sample&Refine evolutionary search phase (an LLM samples 3k Python programs, then REX-guided Thompson sampling allocates 3k refinement steps using execution feedback) and a hindsight-learning phase that fine-tunes the LLM on the resulting search traces. The key insight is hindsight relabeling: any sampled program, even if incorrect for its intended task, becomes a valid solution for a synthetic task whose targets are the program's own outputs, enabling training on all 6k candidates per task rather than only the rare correct ones. Joint fine-tuning of sampling and refinement objectives yields positive transfer, and the loop is iterated so that each improved model generates richer search data for the next iteration. At test time, the same loop adapts to unseen tasks without ground truth by selecting training examples based on training-example accuracy alone, enabling further gains on the target problems.

## Results

On ARC-AGI test (400 tasks), SOAR achieves 36.25% (Qwen-2.5-Coder-7B), 42.75% (14B), 44.38% (32B), 44.88% (Qwen-2.5-72B), and 45.50% (Mistral-Large-2) with 6k search attempts per task, nearly doubling the base Sample&Refine-6k performance (14.25%–26.25%). Combining solutions across all five model sizes via weighted majority voting yields a peak of 52.00% (oracle: 57.25%), outperforming closed-source reasoners o3-mini (33.00%) and Gemini-2.5-Pro (38.25%) in one-shot settings. The 7B model alone surpasses GPT-4.1 (8.00%) and Claude-4-Sonnet (20.75%) one-shot scores.

## Baselines & Comparisons

SOAR substantially outperforms all prior inductive program synthesis baselines on ARC-AGI test. Against CodeIt (Butt et al., 2024), which uses online RL and hindsight learning in a custom DSL with 2,500 attempts/task, SOAR achieves 52.00% vs. 15.00%—a 37-point gap. Against BARC-induction (Li et al., 2024), which relies heavily on human-generated Python solutions and closed-source LLMs, SOAR beats both the Heavy variant (30.50%, 10k attempts) and the Potpourri variant (38.00%, 20k attempts) while using only 6k attempts per model and no human data. Against Icecuber (Wind, 2020), a human-engineered DSL approach scoring 39.00%, SOAR gains 13 points, though Icecuber had access to the validation set. Against Greenblatt (2024), which draws 8,160 samples from a closed-source LLM to reach 42.00%, SOAR's open-weight 7B model alone (36.25%) is competitive, and the full ensemble (52.00%) surpasses it by 10 points with only 6k attempts per model.

## Relation to Prior Work

SOAR extends the line of LLM-based evolutionary program synthesis (Lehman et al., 2023; Olausson et al., 2023; Meyerson et al., 2024) by closing the loop: rather than treating the LLM as a fixed sampling/refinement operator, it uses hindsight relabeling (Andrychowicz et al., 2017) to convert all search attempts—successful and failed—into training data for iterative fine-tuning. It also builds on REX (Tang et al., 2024) for the refinement search step. The key departure from prior self-improving LLM work (Butt et al., 2024; Zelikman et al., 2024) is that SOAR operates in general-purpose Python without a hand-engineered DSL or human-generated solutions, and it jointly improves both sampling and refinement capabilities, demonstrating positive transfer between the two tasks.

## Why It Matters / Open Questions

The finding that iterative self-improvement breaks through both model-size and search-budget scaling plateaus is a meaningful conceptual contribution: a 7B model nearly triples its ARC-AGI performance (14.25% → 36.25%) purely from learning its own search experience, outperforming much larger closed-source models. The framework is domain-agnostic and could serve as a drop-in upgrade for existing LLM-based search systems like FunSearch or AlphaEvolve. However, gains diminish across iterations, solution diversity decreases on solved tasks, and evaluation is limited to a single benchmark (ARC-AGI), leaving open whether the self-improvement cycle sustains in other domains or hits intrinsic limits. The 52% peak result requires ensembling five models (30k total samples), tempering the single-model story.

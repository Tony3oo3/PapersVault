## Problem

Existing jailbreak attacks like GCG optimize adversarial suffixes toward fixed affirmative prefixes (e.g., 'Sure, here is...'), which are ineffective against LLM agents that perform extended multi-step reasoning before executing tool calls. Because agents vary in reasoning style and are prompted to reason before acting, static prefixes fail to trigger specific malicious tool invocations, and prompt injection attacks behave less systematically. The paper addresses how to dynamically hijack an agent's own reasoning process to compel a targeted malicious action.

## Input / Output

The method consumes a user instruction (or system prompt), an environment observation returned after a tool call, and the name of a target malicious tool (or item ASIN for WebShop). It produces an optimized adversarial string of ~25 tokens (initialized as repeated x' characters) that, when appended to the instruction or inserted into the observation, causes the agent to invoke the target tool. The optimization requires access to token-level probability distributions at each position in the agent's response, and the 'noise' inserted into the surrogate reasoning is the literal target tool name or ASIN.

## Method

UDora iteratively hijacks the agent's own reasoning by: (1) collecting the agent's response and token probability distributions given the current adversarial string; (2) computing a positional scoring function r_j(t) that measures how well the target noise (tool name) aligns with each position in the response, then selecting l non-overlapping insertion positions via weighted interval scheduling; (3) inserting the noise at those positions to form a surrogate response z*, and optimizing the adversarial string via gradient-based token replacement (as in GCG) to maximize the likelihood of the noise appearing at those positions. Two optimization modes are supported: Sequential (noise is inserted one position at a time as it becomes fully matched) and Joint (all positions are targeted simultaneously). The key insight is that the agent's own evolving reasoning serves as a dynamic surrogate objective, eliminating the need for manually crafted fixed prefixes and adapting to any reasoning style across different base LLMs.

## Results

UDora achieves an Attack Success Rate (ASR) of 99% on InjecAgent with Llama-3.1-8B-Instruct and 97% with Ministral-8B-Instruct-2410, substantially outperforming the best baseline (GCG at 77% and 50% respectively). On WebShop, UDora(All) reaches 61.75% ASR on Llama 3.1 and 91.50% on Ministral, compared to 15% and 51.75% for GCG. On AgentHarm (malicious instruction scenario), UDora achieves 97.7% ASR on Llama 3.1 and a perfect 100% on Ministral, versus 60.8% and 99.4% for GCG. Across all three datasets, UDora requires fewer than 30 optimization iterations on average to succeed.

## Baselines & Comparisons

UDora consistently outperforms all three baselines across every dataset and model. Against GCG (Zou et al., 2023), UDora gains +22 pp on InjecAgent (99% vs 77%) with Llama 3.1, +47 pp with Ministral (97% vs 50%), +46.75 pp on WebShop with Llama 3.1 (61.75% vs 15%), and +36.9 pp with Ministral (91.50% vs 51.75%); on AgentHarm the gap is +36.9 pp on Llama 3.1 (97.7% vs 60.8%) and +0.6 pp on Ministral (100% vs 99.4%). Against Prompt Injection (Perez & Ribeiro, 2022), the advantage is even more pronounced: +42 pp on InjecAgent with Llama 3.1 (99% vs 57%) and +95 pp with Ministral (97% vs 2%), reflecting that static injection prompts are far less effective than UDora's dynamic reasoning-aware optimization. Against the Template Attack (Andriushchenko et al., 2024a) on AgentHarm, UDora leads by +17 pp on Llama 3.1 (97.7% vs 80.7%) and +33.5 pp on Ministral (100% vs 66.5%), where the template actually degrades the model's reasoning ability and reduces tool-activation success.

## Relation to Prior Work

UDora directly extends the GCG adversarial suffix optimization framework (Zou et al., 2023) from static LLM jailbreaking to LLM agents with tool-calling capabilities. The key conceptual departure is replacing GCG's fixed affirmative prefix (e.g., 'Sure, here is...') with a dynamic surrogate objective: the agent's own reasoning trace, where target tool names or item IDs are inserted at positions identified via a positional scoring function and weighted interval scheduling. This positions the work as a systematic generalization of prompt injection attacks (Perez & Ribeiro, 2022) and template-based jailbreaks (Andriushchenko et al., 2024) into a gradient-guided optimization that adapts to each agent's reasoning style, eliminating the need for manually crafted attack templates.

## Why It Matters / Open Questions

The paper demonstrates that LLM agents with tool-calling are far more vulnerable to targeted manipulation than prior work suggested, with 97–100% attack success rates on multiple benchmarks and a successful compromise of a real-world AutoGen email agent (GPT-4o-based). The transferability finding—that adversarial strings optimized on Llama 3.1 can attack Perplexity's Sonar agent—raises urgent deployment concerns for companies using open-source models. Key limitations include the requirement for token-level log-probability access (unavailable in many API settings) and the use of a single noise string across all insertion positions. Open questions include whether guardrail frameworks or restricted reasoning access (as in OpenAI o1) can effectively mitigate such attacks, and whether the approach generalizes to multi-turn agent interactions.

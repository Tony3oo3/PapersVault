## Problem

Existing multi-agent curriculum learning methods rely on manually defined linear schemes to control the number of agents, and straightforward extensions of reward-based automatic curriculum learning to MARL suffer from two flaws: (1) sparse episode returns used to estimate task difficulty have high variance, and (2) in many MARL tasks, increasing the number of agents raises returns while simultaneously worsening credit assignment, causing reward-based objectives to select unhelpful tasks.

## Input / Output

The method takes a Dec-POMDP environment with a specified target number of agents and a performance threshold V_LB (typically ~80% of target-task return), and produces a trained multi-agent policy (via MAPPO with parameter sharing) along with a learned Gaussian context distribution over agent counts that converges to the target. To handle the varying number of agents, observation vectors are fixed-length (zero-padded) and newly joined agents inherit the shared policy parameters, while the continuous Gaussian context is discretized to yield integer agent counts at each rollout.

## Method

SPMARL replaces the expected-episode-return objective in SPRL's first optimization stage with a learning progress (LP) measure defined as the expected squared TD error (value loss) across all state transitions for each context, i.e., LP(c) = ½ E[‖R(s,a) − V(s)‖²]. This is optimized via importance sampling over the context distribution under a KL-divergence trust-region constraint, selecting tasks where the current policy is changing most (highest value loss) rather than tasks with highest absolute return. The second stage remains unchanged from SPRL: once performance exceeds V_LB, the context distribution is driven toward the target Dirac delta. Because TD error is computed at every timestep rather than once per episode, estimation variance is substantially lower, and because it measures policy change rather than absolute performance, it avoids the credit-assignment trap where more agents trivially inflate returns without improving the policy.

## Results

On the MPE Simple-Spread task (8 agents, 8 landmarks, sparse reward), SPMARL achieves a mean evaluation return of 33.36 (±1.84), outperforming SPRLM (27.48), ALPGMM (24.65), VACL (24.43), and Linear (0.00). On the 20-player XOR game, SPMARL reaches 143.08 (±7.72), marginally ahead of SPRLM (141.45) and substantially ahead of ALPGMM (104.80) and Linear (26.80), while VACL fails entirely (0.00). Across four SMAC-v2 Protoss tasks (5v5–8v8), SPMARL achieves the best or tied-best performance (0.55, 0.45, 0.38, 0.31), with the largest gap over SPRLM on 7v7 (0.38 vs. 0.08) and 8v8 (0.31 vs. 0.11). The no-curriculum baseline (W/O Teacher) yields zero reward on every task, confirming the severity of the sparse-reward exploration challenge.

## Baselines & Comparisons

SPMARL consistently outperforms all four baselines on the majority of tasks. Against the Linear baseline (representing FewToMore, EPC, and VACL's linear agent scheduling), SPMARL wins decisively: Linear fails completely on Simple-Spread (0.00) and achieves only 26.80 on XOR versus SPMARL's 143.08. Against VACL, SPMARL wins on Simple-Spread (33.36 vs. 24.43) and all four Protoss tasks, while VACL fails entirely on XOR (0.00). Against ALPGMM, SPMARL wins on Simple-Spread (33.36 vs. 24.65) and XOR (143.08 vs. 104.80), and is statistically tied or slightly ahead on Protoss 5v5 and 6v6 (both 0.55 and 0.45 respectively), but clearly ahead on 7v7 (0.38 vs. 0.36) and 8v8 (0.31 vs. 0.28). Against SPRLM (the direct reward-based extension), SPMARL wins on Simple-Spread (33.36 vs. 27.48, p=0.016) and all Protoss tasks except 5v5 (0.55 vs. 0.54, p=0.42, not significant), with the largest margins on 7v7 (0.38 vs. 0.08, p=0.002) and 8v8 (0.31 vs. 0.11, p=0.004). The no-curriculum MAPPO baseline yields zero reward on every task, underscoring that curriculum learning is essential under the sparse-reward settings used.

## Relation to Prior Work

This paper extends self-paced reinforcement learning (SPRL) from the single-agent domain to multi-agent settings, first as a straightforward adaptation (SPRLM) and then as a principled modification (SPMARL) that replaces the reward-based curriculum signal with a TD-error-based learning progress measure. It departs from prior MARL curriculum work (FewToMore, EPC, VACL), which relied on manually defined linear or heuristic schedules for agent count, by formulating agent-count control as an automatic contextual RL problem. The key conceptual departure from reward-based ACRL methods is the observation that in MARL, increasing agent count can inflate returns while simultaneously worsening credit assignment, making return-based difficulty estimation misleading.

## Why It Matters / Open Questions

The paper provides the first principled automatic curriculum for controlling agent count in MARL, addressing a gap where prior methods were limited to hand-crafted schedules. The credit-assignment insight—that more agents can yield higher returns yet harder policy learning—reframes how difficulty should be measured in multi-agent settings and could inform curriculum design beyond agent count. Limitations include reliance on CTDE (centralized critic) for accurate TD-error estimation, validation only with MAPPO, and an unresolved question about whether the KL constraint remains necessary when the learning progress objective is used. Open questions include generalization to non-CTDE algorithms and to settings where the number of agents is not the sole curriculum variable.

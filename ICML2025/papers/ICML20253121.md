## Problem

Graph transformers (GTs) lack effective generative pre-training frameworks, rely on handcrafted structural features or GNN modules to encode topology, and struggle with edge- and node-level tasks, while GNNs face fundamental oversmoothing and over-squashing limitations that hinder scalability. This paper asks whether a standard transformer architecture, combined with a principled graph-to-sequence transformation, can serve as a scalable, task-agnostic graph foundation model trained via self-supervised generative pre-training.
![Teaser figure](../imgs/ICML20253121/cropped_page2_idx0.webp)

## Input / Output

The method takes a graph (or a subgraph sampled via ShaDowKHop from a large graph) with node and edge attributes as input and converts it into a token sequence via a (semi-)Eulerian path traversal, where each token encodes node indices, edge types/directions, and digit-wise attribute values. For large graphs with billions of nodes, node identity is preserved through multi-token encoding (e.g., two tokens from a 10^5 vocabulary to uniquely identify 10^10 nodes). The output is task-dependent: a scalar property value (regression), a class label (graph/node classification), or an edge existence score (link prediction), produced by a randomly initialized MLP head appended to the final token's representation.

## Method

GraphGPT introduces the Graph Eulerian Transformer (GET), which losslessly and reversibly serializes graphs into token sequences by traversing all edges and nodes along (semi-)Eulerian paths, applying Eulerization (duplicating minimal edges) for non-Eulerian graphs and cyclic re-indexing (i' = (i+r) % N) as stochastic data augmentation. A standard Llama-based transformer encoder (for SMTP) or decoder (for NTP) processes these sequences, pre-trained via next-token prediction or scheduled masked token prediction without any handcrafted structural features or GNN modules. For downstream tasks, the pre-trained model is fine-tuned by appending task-specific tokens (e.g., [GSUM] for graph-level, target node/edge tokens for node/edge-level) and training a randomly initialized MLP head. The architecture scales to 2 billion parameters with sustained performance gains, and subgraph sampling with multi-token node identity encoding enables processing of graphs with up to billions of nodes within fixed context windows.

## Results

On PCQM4Mv2 (graph regression), GraphGPT-B48 achieves a test MAE of 0.0804, surpassing the previous SOTA GPTrans-L (0.0821) and all GNN baselines (best: GIN-VN at 0.1084). On ogbl-ppa (link prediction), the 2B-parameter GraphGPT-XXL reaches HR@100 of 76.55%, outperforming RefinedGAE (73.74%) and MPLP (65.24%). On ogbl-citation2, GraphGPT-M achieves MRR of 92.82%, beating MPLP (90.72%) and SIEG (90.18%). On node-level tasks, GraphGPT-B is competitive but trails the best GNN (AGDN: 88.65% ROC-AUC on ogbn-proteins vs. 85.33% for GraphGPT-B).

## Baselines & Comparisons

On PCQM4Mv2, GraphGPT-B48 (MAE 0.0804) outperforms the previous SOTA GPTrans-L (0.0821) by ~2%, and substantially beats all GNN baselines (best GIN-VN: 0.1084) and other GTs (GPS-Deep: 0.0862, TokenGT: 0.0919). On ogbl-ppa, GraphGPT-XXL (HR@100 76.55%) surpasses RefinedGAE (73.74%), MPLP (65.24%), and SIEG (63.22%), establishing the first transformer-based SOTA on this benchmark. On ogbl-citation2, GraphGPT-M (MRR 92.82%) and GraphGPT-B (93.05%) both exceed MPLP (90.72%) and SIEG (90.18%). On ogbn-proteins, GraphGPT-B (ROC-AUC 85.33%) trails AGDN (88.65%) and GAT (85.01%) is close, but GraphGPT achieves this with subgraphs of ~40 nodes versus AGDN's >22,000-node subgraphs. On ogbn-arxiv, GraphGPT-B (72.10% ACC) is competitive but below DRGAT (74.16%) and AGDN (73.41%), suggesting node-level tasks on smaller graphs remain a relative weakness. On ogbg-molpcba (transfer from PCQM4Mv2 pre-training), GraphGPT-B24 (31.81% AP) approaches GPTrans-L (32.43%) while using fewer parameters (227.3M vs. 86.0M for GPTrans, though GPTrans is pre-trained on the same data).

## Relation to Prior Work

GraphGPT departs from prior graph transformers (Graphormer, GPS, TokenGT, GPTrans) that rely on handcrafted structural features or embedded GNN modules to encode topology, instead converting graphs into token sequences via (semi-)Eulerian paths so that a standard Llama-style transformer processes them without architectural modifications. The self-supervised pre-training paradigm (NTP/SMTP) is directly borrowed from NLP (GPT, BERT) and CV (MaskGIT), but its application to graph-structured data via lossless graph serialization is novel. The method also builds on classical graph theory (Chinese Postman Problem, Eulerization) and the ShaDowKHop subgraph sampler for handling large graphs, while the multi-token node identity encoding draws an analogy to variable-length encodings like UTF-8.

## Why It Matters / Open Questions

GraphGPT demonstrates that a sequence-based transformer can scale to 2 billion parameters with sustained performance gains on graph tasks—a regime where prior GNNs and graph transformers plateau—positioning it as a candidate architecture for graph foundation models in chemistry, materials science, and bioinformatics. Key open questions include cross-domain transferability (pre-training is dataset-specific), the high computational cost that limits applicability to small datasets, and whether incorporating 3D molecular data or aligning with LLMs can further unlock the architecture's potential. The lossless Eulerian serialization also opens a path toward graph generation, though generation quality and validity constraints remain underexplored.

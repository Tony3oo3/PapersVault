## Problem

Existing multi-bit LLM watermarking methods face a fundamental trade-off: embedding messages via position allocation (e.g., MPAC) relies on biased Soft Red List reweighting, which degrades text quality, while unbiased methods (e.g., γ-reweight, DiPmark) lack multi-bit capacity or model-agnostic detection. No prior method simultaneously achieves text quality preservation, model-agnostic and message-agnostic detection, and multi-bit message embedding.

## Input / Output

During embedding, the method consumes the LLM's per-token probability distribution, a sliding window of h previous tokens (used as pseudorandom seeds), a secret key, a binary message of length ℓ, and d pre-computed balanced vocabulary bipartitions. During detection, only the token sequence, the same bipartitions, and the key are needed—no access to the generating model or the message space is required. The output is a watermarked token sequence, an extracted ℓ-bit message via a voting matrix, and a z-score for zero-bit detection.

## Method

BiMark's core mechanism is a bit-flip unbiased reweighting function: a fair coin flip determines whether to increase probabilities in vocabulary partition V₁ (and decrease V₀) or vice versa, with scaling factors δ₀ and δ₁ constrained to preserve a valid distribution (Lemma 4.1). This guarantees E[R(P)] = P (Theorem 4.2) while creating a detectable token-count pattern. A multilayer extension applies d independent bipartitions and coin flips iteratively, amplifying the watermark signal without violating unbiasedness. For multi-bit messages, each message bit m[p] is XORed with a per-layer one-time pad mask b^i ~ Bernoulli(0.5) to produce the fair coin flips e^i = m[p] ⊕ b^i, ensuring the reweighting remains unbiased regardless of message content. Detection reconstructs the one-time pad, estimates each e^i from token subset membership across all d layers, reverses the XOR to vote for message bits, and applies majority voting over the ℓ×2 voting matrix.

## Results

On C4-RealNewslike prompts with Llama3-8B, BiMark achieves 95.26% message extraction rate for 8-bit messages in 50-token texts (PPL 8.5), outperforming MPAC(1) (49.49%, PPL 9.44) and MPAC(1.5) (78.81%, PPL 9.76) by 20.87% and 16.45% respectively. For the more challenging 32-bit messages in 50-token texts, BiMark reaches 66.35% extraction (PPL 8.63) versus 45.06% (PPL 9.16) for MPAC(1) and 51.03% (PPL 9.77) for MPAC(1.5). On downstream tasks (CNN/DailyMail summarization, WMT'16 En-Ro translation), BiMark matches or slightly exceeds the no-watermark baseline (e.g., BERTScore 32.48 vs 32.45 for summarization; BLEU 22.15 vs 21.93 for translation), while Soft Red List degrades significantly as watermark strength increases.

## Baselines & Comparisons

Against MPAC (Yoo et al., 2023b), the primary multi-bit baseline, BiMark dominates on both extraction rate and perplexity across all message lengths and text lengths; for 50-token texts, BiMark improves extraction by 20.87% (8-bit), 29.50% (16-bit), and 30.02% (32-bit) over MPAC(δ=1), while simultaneously reducing perplexity by 0.6–1.1 points. Against Soft Red List (Kirchenbauer et al., 2023), BiMark achieves comparable zero-bit detection TPR at 1% FPR on both Llama3-8B and Qwen2.5, but with substantially lower perplexity; Soft Red List's quality degrades sharply as δ increases from 1.0 to 2.0 (BERTScore drops from 32.11 to 31.15 on summarization). Against SynthID (Dathathri et al., 2024), BiMark matches detection performance while additionally supporting multi-bit message embedding, which SynthID does not. Against Gumbel Sampling (Kuditipudi et al., 2023), γ-Reweight (Hu et al., 2023), and DiPmark (Wu et al., 2023), BiMark achieves equivalent downstream task performance (within ±0.1 BERTScore, ±0.2 BLEU) while uniquely providing message-agnostic multi-bit extraction. Under paraphrasing attacks (DIPPER), BiMark retains 98.35% detection at 300 tokens with (20,20) diversity, outperforming Soft Red List (66.52%) and DiPmark (42.81%), and slightly exceeding SynthID (97.21%).

## Relation to Prior Work

BiMark sits at the intersection of three prior research threads: (1) Soft Red List's green/red vocabulary partitioning, (2) unbiased reweighting methods (γ-reweight, DiPmark) that preserve text quality but rely on cumulative probability distributions requiring model access, and (3) MPAC's position-allocation scheme for multi-bit message embedding. The key departure is replacing cumulative-probability-based partitions with token-counting-based bipartitions via a fair-coin-flip mechanism, which simultaneously achieves unbiasedness and model-agnostic detection—a combination no prior method provided. The multilayer composition of independent bit-flip reweightings and the XOR one-time-pad encoding of message bits into coin flips are novel architectural choices that integrate these threads into a unified pipeline.

## Why It Matters / Open Questions

BiMark addresses a practical gap: regulatory frameworks (EU AI Act, US Executive Order) require watermarking that is simultaneously undetectable in quality, detectable without model access, and capable of carrying provenance metadata—properties no single prior method satisfied. The multilayer mechanism's finding that detectability peaks and then degrades with excessive layers provides a useful design principle for practitioners tuning watermark strength. Open questions include robustness against adaptive paraphrasing attacks beyond the tested DIPPER settings, scalability to very long messages (beyond 32 bits), and whether the pseudorandom partition pre-computation introduces any security vulnerabilities in multi-tenant deployment scenarios.

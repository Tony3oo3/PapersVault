## Problem

Existing 3D parameter-efficient transfer learning (PETL) methods freeze the pretrained backbone, producing features with limited semantic cues that fail to align with the semantic relationships required by downstream tasks. While 2D pretrained models (e.g., CLIP, DINOv2) encode rich semantic information and are already deployed on edge devices, no prior work has explored leveraging 2D semantics to enhance 3D PETL, leaving a gap in how to fuse cross-modal semantic cues with minimal trainable parameters.

## Input / Output

The method takes a raw 3D point cloud (1024 or 2048 points) as input and simultaneously projects it into three 224×224 depth maps from orthogonal viewpoints, which are fed through a frozen 2D ViT (CLIP ViT-B/16 or DINOv2 ViT-B/14) alongside the point cloud through a frozen 3D transformer (PointMAE or PointBERT). Outputs are class labels for object classification (ScanObjectNN, ModelNet40) or per-point part labels for segmentation (ShapeNetPart), with the 2D semantic prompt from the final layer concatenated to the classification head input to enforce cross-modal alignment.

## Method

The proposed paradigm introduces three components operating at every transformer layer: (1) a 3D-to-2D projection that renders depth maps from three orthogonal viewpoints to mitigate global viewpoint ambiguities; (2) a Vision Semantic Prompt generator that max-pools the three 2D class tokens and maps them through a shared MLP into 3D feature space; and (3) a Hybrid Attention Adapter (HAA) where the prompt generates two modulation parameters (α, β) that normalize and shift 3D features (Semantic Transfer), then the modulated features serve as queries and keys while unaltered 3D features serve as values in a bottleneck attention computation. This design decouples semantic cues from global context to mitigate local projection ambiguities, filters redundant 2D noise, and keeps trainable parameters to only 1.8M (~1–2% of total) while both 3D and 2D backbones remain fully frozen.

## Results

On the most challenging ScanObjectNN PB-T50-RS split, the proposed method (PointMAE + CLIP) achieves 89.14% overall accuracy with only 1.8M trainable parameters (1.04% of total), surpassing the previous best PETL method Point-PEFT (85.50%) by 3.64% and even exceeding the full fine-tuning PointMAE baseline (85.18%). With rotation data augmentation, the method reaches 90.09%, outperforming all full fine-tuning methods including RECon (89.73%). On ModelNet40, PointMAE + CLIP achieves 95.2%/95.6% (with/without voting), the highest among all full fine-tuning and supervised methods. On ShapeNetPart, the method attains 84.70% class mIoU and 86.3% instance mIoU, matching or exceeding full fine-tuning baselines.

## Baselines & Comparisons

The proposed method decisively outperforms all existing PETL baselines on the hardest ScanObjectNN split: PointMAE+CLIP reaches 89.14% vs. Point-PEFT (85.50%, +3.64%), DAPT (85.08%, +4.06%), and IDPT (84.94%, +4.20%), while using comparable or fewer trainable parameters (1.8M vs. 0.6M–1.7M). It also surpasses the full fine-tuning PointMAE baseline (85.18%) by nearly 4 points, demonstrating that the 2D semantic prompts compensate for the frozen backbone's limited semantic capacity. On ModelNet40, the method achieves 95.6% (with voting), exceeding all full fine-tuning methods (best: Point-M2AE at 94.0%) and all supervised methods. On ShapeNetPart, PointMAE+CLIP attains 84.70% class mIoU, beating IDPT (83.79%) and DAPT (84.01%) while matching the full fine-tuning PointMAE (84.19%). The only case where the method trails is against RECon† (89.73%) on PB-T50-RS without augmentation, but with the same rotation augmentation the proposed method surpasses it (90.09% vs. 89.73%). In few-shot settings (Table 3), the method consistently improves over IDPT and DAPT on 10-way k-shot tasks (e.g., 93.8% vs. 92.8%/93.0% on 10-way 10-shot) while remaining competitive on 5-way settings.

## Relation to Prior Work

This paper extends the 3D PETL line (IDPT, DAPT, Point-PEFT) by introducing a cross-modal semantic transfer mechanism: frozen 2D pretrained models (CLIP, DINOv2) generate vision semantic prompts that are injected into a frozen 3D backbone via a novel Hybrid Attention Adapter. Prior 3D PETL methods operate entirely within the 3D modality and, as the authors diagnose, produce features with limited semantic cues because the backbone remains frozen. The 3D-to-2D projection from three orthogonal viewpoints and the multi-scale prompt generation strategy are new architectural components not present in prior adapter or prompt tuning work for point clouds.

## Why It Matters / Open Questions

The paradigm offers a practical recipe for boosting 3D PETL performance with only ~1.8M trainable parameters (≈1% of the model), which is attractive for edge deployment where storing full fine-tuned weights is prohibitive. A key limitation is the elevated FLOPs from running a 2D ViT alongside the 3D backbone, which the authors acknowledge cannot be resolved within the current design. An open question the paper raises is what the 3D model actually learns from the 2D prompts—whether it is genuine semantic alignment or a form of regularization—since the PCA visualizations are suggestive but not mechanistically explanatory. The framework's compatibility with arbitrary transformer-based 3D+2D combinations positions it to benefit from future foundation model releases without architectural changes.

## Problem

Long-context LLM inference is bottlenecked by KV cache memory and attention computation that scale linearly with sequence length. Existing acceleration methods face a fundamental trade-off: KV eviction reduces memory but loses accuracy by discarding critical tokens, while KV retrieval preserves accuracy but retains the full cache, limiting batch throughput. No prior method exploits the observation that certain attention heads maintain stable, sequential attention patterns across both pre-filling and decoding stages, which could enable a hybrid strategy that is both memory-efficient and accurate.

## Input / Output

During pre-filling, CateKV consumes the full Q/K/V matrices of each attention head along with a fixed observation window (last L_obs=64 query tokens, excluding initial and recent tokens) to compute a binarized attention matrix and derive per-head CV scores. Head type labels (consistent vs. adaptive) are pre-computed once per model using a 100-sample reference set from RULER's Variable Tracking task at 128K length, making inference-time classification free. The output is a compressed KV cache (~41% of original size) where consistent heads retain only a small chunk-based top-k budget (e.g., 2048 tokens) and adaptive heads retain a configurable fraction η of all KV pairs, followed by standard autoregressive text generation.

## Method

CateKV's core mechanism is a coefficient-of-variation-based scoring function applied to a binarized observation matrix A (computed from the last L_obs query tokens attending to the middle portion of the sequence). The binarization uses a percentile threshold k scaled by factor α, and the resulting frequency vector C captures how consistently each token is attended across the observation window; the CV score (std/mean of C) then separates heads into consistent (high CV, concentrated attention) and adaptive (low CV, diffuse attention) categories. For consistent heads, only the top-k chunks by maximum C value are cached, reducing their KV footprint to ~1.56% of the sequence; for adaptive heads, a retention ratio η (typically 0.7–1.0) controls how many chunks are kept, with optional query-aware retrieval during decoding. A theoretical analysis via Rademacher complexity bounds provides a lower bound on token retention accuracy as a function of head classification accuracy, retention budget calibration, and the probability that attention score ordering correctly identifies critical tokens. The method is plug-and-play, orthogonal to pre-filling accelerators like MInference, and composable with retrieval methods like Quest and ShadowKV for further memory reduction.

## Results

On RULER-128K, CateKV achieves 84.61% average accuracy on Llama-3-8B-1M (vs. 84.10% full attention) while retaining only 41% of the KV cache, outperforming all eviction baselines. On Llama-3.1-8B, CateKV reaches 84.66% (vs. 84.55% full attention), and on Yi-9B-200K it reaches 65.76% (vs. 64.52% full attention). In efficiency terms, CateKV reduces memory usage by up to 2.72×, decoding latency by 2.18× (single-sample), and boosts batch throughput by 3.96× on Llama-3-8B-1M with r=0.3, η=0.7.

## Baselines & Comparisons

CateKV consistently outperforms all four eviction baselines (StreamingLLM, SnapKV, PyramidKV, DuoAttention) at the same 41% cache budget across all four models tested on RULER-128K. StreamingLLM is the weakest baseline, dropping to 47–48% average (vs. ~84% for CateKV) due to its fixed attention-sink + recent-token strategy. Among the stronger eviction methods, SnapKV (83.28%) and PyramidKV (83.60%) trail CateKV (84.61%) by 1.3–1.4 points on Llama-3-8B-1M; DuoAttention (83.76%) is closest but still 0.85 points behind. On LongBench, CateKV maintains accuracy within 0.3% of full attention while reducing cache to 42%, and when combined with retrieval methods Quest and ShadowKV, it reduces memory to 42% with <0.2% accuracy loss under the same 3% computational budget. CateKV also integrates cleanly with MInference (prefilling acceleration), yielding a slight 0.42-point average improvement on RULER (87.74% vs. 87.32%) across 8K–256K contexts, confirming orthogonality with prefilling-stage optimizations.

## Relation to Prior Work

CateKV sits at the intersection of three existing lines of work on long-context LLM inference: KV cache eviction (StreamingLLM, SnapKV, PyramidKV), KV cache retrieval (Quest, ShadowKV), and head-wise attention classification (DuoAttention, RazorAttention, MInference). Its key conceptual departure is the observation of *sequential consistency*—that certain attention heads maintain stable attention patterns across both the pre-filling and decoding stages—which prior head-classification methods overlooked by focusing only on intra-stage sparsity patterns. The CV-based scoring mechanism repurposes a classical statistical measure to operationalize this cross-stage observation, and the resulting consistent/adaptive split is deliberately orthogonal to and combinable with both eviction and retrieval strategies, rather than replacing them.

## Why It Matters / Open Questions

The practical impact is substantial for deployment: reducing KV cache to ~41% while maintaining near-full-attention accuracy (≤0.25% drop on RULER-128K) directly translates to larger batch sizes and lower serving costs for long-context workloads. The plug-and-play, reference-based static classification avoids per-sample overhead, making it easy to integrate into existing inference stacks. Open questions include whether the static head-type assignment generalizes to genuinely out-of-distribution inputs or new model architectures, whether the observation window and percentile thresholds transfer across model families without re-tuning, and how the method behaves under multi-turn or streaming settings where the pre-filling/decoding boundary is less clean.

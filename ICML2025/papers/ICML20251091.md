## Problem

Static benchmarks for evaluating LLM value alignment (social bias, ethics, toxicity) suffer from the evaluation chronoeffect: test items leak into training corpora and rapidly saturate as models improve, causing systematic overestimation of value conformity. Existing adaptive testing methods (CAT) mitigate this partially but remain constrained by a fixed item pool, leaving both data leakage and difficulty saturation unresolved for fast-evolving LLMs.

## Input / Output

GETA takes a group of examinee LLMs (e.g., GPT-4, LLaMA-2-70B, Mistral-7B), a small set of seed items with pre-calibrated IRT parameters, and two pre-trained neural components: a two-layer Transformer VIRT estimator (no positional embedding) and a LLaMA-3-8B item generator fine-tuned with prefix adapter and LoRA. It produces min-max normalized value conformity scores per LLM after T=10 adaptive iterations (k₁=100 generated items per step), along with an evolved item generator whose difficulty range has expanded beyond the original training data. Unlike static evaluation, no fixed test set is administered; items are synthesized on-the-fly and discarded after use, eliminating data leakage by construction.

## Method

GETA unifies Computerized Adaptive Testing with Automatic Item Generation under a single variational objective. A two-parameter logistic IRT model (IRT-2PL) links each examinee's latent value conformity aᵢ to the probability of a correct response given item difficulty bⱼ and discrimination cⱼ; these latent variables are estimated via a Variational IRT (VIRT) model using two-layer Transformer encoders rather than MLE, enabling calibration from fewer responses. An LLM-based item generator p_ω(x|d) is jointly trained with the VIRT estimators by maximizing an ELBO (Eq. 2) that couples the IRT likelihood, the generator's reconstruction of items from parameters, and KL regularizers on both the ability and item-parameter posteriors. During testing, the generator performs selective generation: it samples item parameters from a fault-tolerant neighborhood [d*−ε, d*+ε] around the Fisher-information-optimal difficulty d* (where b*=âᵗ and c* is set large), then synthesizes novel items via Eq. (6). Items whose empirically estimated parameters deviate beyond a threshold δ₂ from d* are collected and used to iteratively fine-tune the generator (weighted by β in Eq. 4), extending its difficulty range and co-evolving with the examinees' improving value conformity.

## Results

GETA achieves substantially higher Concurrent Validity than all baselines across three reference metrics: Va-L (correlation with safety leaderboards) of 0.9461, Va-I (unseen i.i.d. items) of 0.9668, and Va-O (OOD items) of 0.8354 with 8 examinee LLMs. In contrast, Static Evaluation scores 0.2999/0.5542/0.4935, CAT scores 0.4122/0.7906/0.6817, and NCAT scores 0.3039/0.5015/0.4431 on the same metrics. GETA also maintains strong validity with fewer examinees (m=4: Va-I=0.9995, Va-O=0.9801), and the ablation shows removing VIRT drops overall validity from 0.8753 to 0.4876, while removing the item generator drops it to 0.8585.

## Baselines & Comparisons

GETA decisively outperforms all three adaptive/static baselines on every validity metric. Against CAT (Zhuang et al., 2023), which adaptively selects items from a static pool, GETA improves Va-L by 53.4 points (0.9461 vs. 0.4122) and Va-O by 15.4 points (0.8354 vs. 0.6817), demonstrating that dynamic item generation is critical when the static pool saturates. Against NCAT (Zhuang et al., 2022b), which learns item selection via reinforcement learning, GETA leads by 64.2 points on Va-L (0.9461 vs. 0.3039); the paper attributes NCAT's poor performance to its data-hungry RL training requiring 60k+ samples versus the 5k per value type available here. Against Static Evaluation, GETA improves Va-L by 64.6 points, confirming that simply applying fixed benchmarks severely underestimates model differences. The two red-teaming baselines (GPTFuzzer and SAP) are not included in the main validity table but are analyzed qualitatively: both produce near-zero scores for all examinees because they only elicit harmful responses without adaptively calibrating difficulty, making them unsuitable as evaluation instruments rather than vulnerability probes.

## Relation to Prior Work

GETA unifies three established psychometric techniques—Computerized Adaptive Testing (CAT), Item Response Theory (IRT), and Automatic Item Generation (AIG)—into a single variational framework, departing from prior CAT-based LLM evaluation (Zhuang et al. 2023, 2024) that selects items from a fixed, pre-calibrated pool. The key conceptual leap is replacing the static item pool with a jointly-trained LLaMA-3-8B generator whose difficulty is conditioned on the IRT-2PL item parameters, all optimized through a shared ELBO objective derived from the VAE framework (Kingma & Welling, 2014). This positions GETA as a bridge between the psychometric adaptive-testing literature and the LLM safety-evaluation literature, where prior dynamic approaches (Dynabench, GPTFuzzer, SAP) either rely on human-in-the-loop generation or target vulnerability discovery rather than systematic value measurement.

## Why It Matters / Open Questions

The evaluation chronoeffect—where static benchmarks saturate or leak into training data—is a growing practical problem as LLMs iterate rapidly, and GETA's concurrent validity (0.89–0.95 correlation with leaderboards using only ~150 adaptive items) demonstrates a credible path toward self-updating safety evaluation. However, the method is limited to a single IRT model (2PL), requires fine-tuning a generator per value type, and the item generator itself could be repurposed for large-scale adversarial probing. Open questions include scalability to real-time monitoring, extension to multimodal models, and whether the co-evolution loop remains stable as examinee LLMs improve faster than the generator can adapt.

## Problem

Existing speculative decoding methods fix their hyperparameter configurations (draft model, tree structure, speculation length) across all tasks, yet different input contexts—code debugging versus creative writing—benefit from fundamentally different configurations. No training-free, theoretically grounded framework existed to adaptively select these hyperparameters online during generation while providing provable guarantees on the resulting latency.
![Teaser figure](../imgs/ICML20250943/cropped_page0_idx0.webp)

## Input / Output

The framework takes an initial text prompt, a target LLM, a set of K candidate hyperparameter specifications (e.g., different draft models, tree structures, or speculation lengths γ ∈ {0,…,L}), and a maximum speculation length L. At each decoding round, the bandit algorithm selects one hyperparameter, invokes a speculative decoding subroutine, and observes the number of accepted tokens (a random variable in [1, L+1]) as the reward signal. The process terminates when an EOS token appears, producing the full generated sequence and a random stopping time (number of subroutine calls) that serves as the latency proxy.

## Method

BANDITSPEC formulates hyperparameter selection as a K-armed bandit problem where each arm is a hyperparameter configuration and the reward is the number of accepted tokens per round. Two algorithms are designed: UCBSPEC, a UCB-type algorithm for the stochastic setting (stationary mean acceptance length per arm), and EXP3SPEC, an anytime EXP3 variant for the adversarial setting (no distributional assumptions). The key technical novelty is the 'stopping time regret' metric and a novel regret decomposition that handles the random, history-dependent stopping time via martingale optional stopping and self-normalized confidence bounds—neither of which applies in standard MAB analysis. An information-theoretic lower bound under the truncated geometric distribution shows UCBSPEC is optimal up to universal constants, and experiments on LLaMA3-8B and Qwen2-7B demonstrate 10–20% throughput improvements over fixed-configuration baselines across diverse benchmarks.

## Results

On LLaMA3-8B-Instruct, UCBSPEC achieves the best throughput across all four benchmarks: 105.72 Tokens/s (Spec Bench), 125.78 (Alpaca), 138.27 (Code Editor), and 135.34 (Debug Bench), outperforming the best fixed method Eagle-2 by 7.7%–13.6%. On Qwen2-7B-Instruct, UCBSPEC reaches 112.33, 114.20, 161.35, and 151.37 Tokens/s respectively, with improvements of 9.3%–20.1% over Eagle-2. In the batch-size-1 setting, UCBSPEC also achieves the highest Mean Accepted Tokens (MAT) on most benchmarks (e.g., 4.13 on Spec Bench for Qwen2 vs. 3.64 for Eagle-2). In the simulated serving scenario with batch sizes 1–50, UCBSPEC's throughput closely approaches the oracle best hyperparameter across diverse prompts.

## Baselines & Comparisons

The paper compares against four existing speculative decoding methods: PLD (prompt lookup decoding), Rest (retrieval-based), Suffix Tree (suffix automaton), and Eagle-2 (parametric draft model with dynamic trees). All three non-parametric baselines (PLD, Rest, Suffix Tree) are consistently outperformed by Eagle-2 in average throughput, though Suffix Tree is competitive on Code Editor (90.21 vs. 128.76 Tokens/s for Eagle-2 on LLaMA3). UCBSPEC and EXP3SPEC outperform Eagle-2 on every benchmark for both target models, with the largest gains on Debug Bench (13% for LLaMA3, ~20% for Qwen2) and Code Editor (7.4% for LLaMA3, 16.4% for Qwen2), confirming that adaptive hyperparameter selection exploits task-specific strengths of different draft models. UCBSPEC consistently edges out EXP3SPEC, suggesting real-world speculative decoding aligns more closely with the stochastic (stationary mean) assumption than the adversarial one. In the batch-size-1 setting, the adaptive methods also achieve the highest MAT on most benchmarks, indicating they select the most effective draft model per prompt rather than relying on a single fixed configuration.

## Relation to Prior Work

This paper builds on the speculative decoding framework (Leviathan et al., 2023; Chen et al., 2023) and its extensions (tree-based verification in Medusa, draft models in EAGLE-2, retrieval-based methods like REST and Suffix Tree), but departs from the prevailing practice of fixing all hyperparameters across tasks. It repurposes classical multi-armed bandit algorithms (UCB1, EXP3) into a unified adaptive hyperparameter selection framework, introducing a novel 'stopping time regret' metric that accounts for the random horizon inherent in autoregressive generation. The theoretical analysis requires new tools—martingale-based reward decomposition replacing Wald's equation and self-normalized confidence bounds replacing standard Chernoff-Hoeffding—because the accepted-token counts are dependent and the stopping time is random, unlike the i.i.d. fixed-horizon setting of classical MAB.

## Why It Matters / Open Questions

The framework is training-free and orthogonal to existing speculative decoding methods, meaning any current approach (EAGLE-2, REST, Suffix Tree) can serve as an 'arm' without modification, lowering the barrier to adoption. The near-optimal regret guarantee (matching lower bounds up to constants under truncated geometric distributions) provides theoretical confidence that the adaptive overhead vanishes asymptotically. Open questions include extending to structured bandits (linear, Lipschitz) for large hyperparameter spaces, non-stationary settings where acceptance rates drift, and contextual bandits that exploit prompt features to reduce exploration cost. The empirical finding that stochastic (UCB) consistently outperforms adversarial (EXP3) suggests real-world speculative decoding is more benign than worst-case models assume, guiding future algorithm design.

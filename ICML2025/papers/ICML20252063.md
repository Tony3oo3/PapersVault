## Problem

Whether world models are a necessary ingredient for flexible, goal-directed behavior, or whether model-free learning alone suffices, has long been debated without a formal resolution. This paper provides a rigorous answer: any agent that satisfies a regret bound over a sufficiently diverse set of multi-step goal-directed tasks must have learned an accurate predictive model of its environment, with model accuracy scaling with agent competence and goal complexity.
![Teaser figure](../imgs/ICML20252063/cropped_page0_idx0.webp)

## Input / Output

The algorithm (Algorithm 1) is unsupervised and universal: its sole input is the agent's goal-conditioned policy π(a_t | h_t; ψ), which it queries with constructed composite goals (LTL expressions) of increasing depth n. It outputs an approximate transition function P̂_ss'(a) for every state-action pair, with a provable error bound |P̂_ss'(a) − P_ss'(a)| ≤ √(2P_ss'(a)(1−P_ss'(a)) / ((n−1)(1−δ))). The bound tightens as the agent's failure rate δ decreases or the goal depth n increases, and for δ≪1, n≫1 the error scales as O(δ/√n) + O(1/n).

## Method

The proof proceeds by reduction: it constructs a family of composite goals ψ_{a,b}(k,n) that are disjunctions of two mutually exclusive sequential goals, where the optimal success probability for each branch is given by a cumulative binomial distribution parameterized by the transition probability P_ss'(a). By incrementing the threshold k from 0 to n and observing which sub-goal the deterministic agent pursues (revealed by its first action), the algorithm identifies a 'goal-switching' point k* that bounds the binomial median, and hence P_ss'(a). The Berry-Esseen theorem converts the median constraint into a probability bound, yielding the stated error guarantee. A companion result (Theorem 2) shows that for myopic agents (depth-1 goals only), no non-trivial bound on transition probabilities can be extracted, confirming that world models become necessary only for multi-step goal-directed behavior.

## Results

The main theoretical result (Theorem 1) establishes that any bounded goal-conditioned agent with maximum failure rate δ for composite goals of depth n > 1 encodes a world model with transition-probability error bounded by √(2P(1−P)/((n−1)(1−δ))), which scales as O(δ/√n) + O(1/n) for δ ≪ 1 and n ≫ 1. Theorem 2 shows this bound is tight: for myopic agents (n = 1), no non-trivial bound on transition probabilities can be extracted from the policy. Empirically, on a randomly generated cMP with 20 states and 5 actions, Algorithm 2 recovers the transition function with mean error ⟨ε⟩ that scales as O(n^(−1/2)) with goal depth, matching the theoretical prediction, even when the agent violates worst-case regret bounds (achieving δ = 1 on some individual goals).

## Baselines & Comparisons

This is a theoretical paper without direct method-to-method benchmark comparisons; the `compares_to` list is empty. The paper positions its result as completing a triad with planning (model + goal → policy) and inverse reinforcement learning (model + policy → goal), showing that policy + goal → model is also well-defined. Conceptually, the result is compared to mechanistic interpretability approaches (probing, SAEs) that recover state representations from activations; the paper's Algorithm 1 is strictly weaker in input (uses only the policy, not internal activations) but provides a formal error bound tied to agent capability rather than architecture-specific assumptions. The empirical section validates the theory by showing that even when the agent strongly violates the worst-case regret assumption of Def. 5 (achieving maximal regret δ = 1 on some goals), the average world-model error still follows the O(n^(−1/2)) scaling predicted by Theorem 1, suggesting the result is robust to the idealized competence assumption.

## Relation to Prior Work

This paper completes the conceptual triangle between planning (model + goal → policy), inverse RL (policy + model → goal), and the newly formalized direction (policy + goal → model). It departs from Brooks' model-free paradigm and the good regulator theorem by providing the first rigorous proof with explicit error bounds that any regret-bounded goal-conditioned agent in a controlled Markov process must encode a predictive world model in its policy. Unlike mechanistic interpretability approaches that recover state representations from network activations, the extraction algorithm here operates purely on the policy's input-output behavior, making it architecture-agnostic and applicable even when internal representations are inaccessible.

## Why It Matters / Open Questions

The result removes the theoretical justification for a purely model-free path to general AI, implying that the fidelity of an agent's implicit world model fundamentally bounds its capabilities on long-horizon tasks. This has direct safety implications: it guarantees that sufficiently capable agents contain extractable world models that can be used for plan verification, capability bounding, and interpretability. Key open questions include extending the analysis to partially observed environments, identifying minimal sets of 'universal' tasks sufficient to imply world model learning, and developing scalable extraction algorithms for real-world agents. The empirical finding that the algorithm recovers accurate models even when the agent violates the worst-case regret bound (δ=1 for some goals) suggests the theory may be more robust than its assumptions indicate.

## Problem

Controllable learning methods that adapt model behavior at test time to dynamic task requirements have shown strong empirical success in recommender systems and information retrieval, yet no unified generalization theory exists to explain or guarantee their performance. Two specific gaps remain: (1) no formal framework captures the interplay between controllability (the task requirement z) and multiple task targets, and (2) existing vector-contraction tools introduce a linear or square-root dependency on the number of task targets c, which is overly pessimistic given that controllable learners handle many targets in practice.

## Input / Output

The framework takes a d-dimensional input feature vector x and a task requirement z (which may be a natural-language profile, a task indicator, or a preference weight vector) and produces a c-dimensional prediction vector f^z(x) = (f_1^z, ..., f_c^z), one scalar per task target. The theoretical output is a high-probability generalization bound of the form R(f^z) ≤ R̂_D(f^z) + Õ(1/√n) that is independent of c except for logarithmic factors. For bipartite ranking, the input additionally involves pairs of relevant/irrelevant samples, and the effective sample size s_0 = n·min_j{p_j, 1−p_j} governs the convergence rate, reflecting class-imbalance effects.

## Method

The paper introduces a unified function class F where each task target j is parameterized as f_j^z(x) = w_j^T ζ_j(φ_j(x, ψ_j(z))), with ψ_j as the control function, φ_j as the manipulation function, and ζ_j as the classifier. The key technical tool is a novel vector-contraction inequality (Lemma 4.4) that bounds the Rademacher complexity of the loss space by the worst-case Rademacher complexity of a projection function class P(F), exploiting ℓ_∞-Lipschitz continuity of the loss to eliminate the √c factor that appears in prior vector-contraction lemmas. For bipartite ranking, a U-process permutation technique converts the non-i.i.d. pairwise structure into a sum-of-i.i.d. form. The paper then provides modular Rademacher complexity bounds for FNNs (via peeling) and single-layer Transformers (via softmax Lipschitz properties, yielding no dependency on sequence length T), which compose flexibly to give end-to-end bounds for embedding-based (Transformer control + FNN classifier) and hypernetwork-based (FNN hypernetwork + Transformer classifier) methods.

## Results

This is a purely theoretical paper with no empirical experiments. The headline result is a tight generalization bound (Theorem 4.7) for general controllable learning classes under the surrogate weighted Hamming loss, achieving a rate of Õ(1/√n) with no dependency on the number of task targets c except for logarithmic factors. For the surrogate multi-target bipartite ranking loss (Theorem 4.9), the bound achieves Õ(1/√s₀) where s₀ = n·min{minⱼ pⱼ, minⱼ(1−pⱼ)}, reducing to Õ(1/√n) under balanced classes. The key technical contribution is a novel vector-contraction inequality (Lemma 4.4) that exploits ℓ∞-Lipschitz continuity of losses to eliminate the √c factor present in prior vector-contraction results (Maurer, 2016).

## Baselines & Comparisons

This paper is purely theoretical and does not conduct empirical comparisons against baseline methods. The theoretical comparison is with prior vector-contraction inequalities: the standard result from Maurer (2016) yields a linear dependency on the number of task targets c, while this paper's novel inequality reduces this to a logarithmic dependency by leveraging ℓ∞-Lipschitz continuity of the loss and a projection operator to decouple task targets. The paper also positions its Transformer Rademacher complexity bound (Theorem 5.6) as matching the sequence-length-independent rate of Trauger & Tewari (2024), but derived via standard Rademacher analysis with Frobenius norms rather than covering-number arguments. No empirical baselines or benchmark comparisons are provided.

## Relation to Prior Work

This paper extends the vector-contraction inequality of Maurer (2016) by exploiting ℓ∞-norm Lipschitz continuity of losses and introducing a projection operator to decouple task targets, thereby eliminating the linear dependency on the number of outputs c that is inherent in the original formulation. For the bipartite ranking setting, it adapts the U-process permutation technique of Clémençon et al. (2008) to handle the non-i.i.d. pairwise structure. The Transformer Rademacher complexity bound follows the analytical framework of Edelman et al. (2022), using the Lipschitz property of softmax to achieve sequence-length independence. Prior theoretical work on controllable learning was limited to approximation properties (Galanti & Wolf, 2020); this paper provides the first generalization analysis by establishing a unified function-class framework that encompasses both embedding-based and hypernetwork-based methods.

## Why It Matters / Open Questions

The key result—that generalization bounds for controllable learning are independent of the number of task targets c up to logarithmic factors—provides theoretical justification for the empirical success of methods handling dozens or hundreds of targets in recommender systems and information retrieval. The modular Rademacher complexity results for FNNs and Transformers serve as reusable building blocks for analyzing future controllable learning architectures. Open questions include how the ∑p_j term in bipartite ranking bounds interacts with label sparsity, how class imbalance degrades the effective sample size s_0, and whether the analysis extends to controllable generation models. The paper is purely theoretical with no empirical validation, so the tightness of constants and practical relevance of the bounds remain to be tested.

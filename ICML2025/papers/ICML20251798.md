## Problem

Structured Kernel Interpolation (SKI) is the dominant method for scaling Gaussian Process inference to linear time, yet it lacks any rigorous theoretical error analysis. No prior work had established how the SKI Gram matrix approximation error depends on the number of inducing points, sample size, and dimensionality, nor how this error propagates to hyperparameter estimation and posterior inference. This paper fills that gap by deriving end-to-end error bounds from elementwise kernel approximation through spectral norm error to downstream estimation and inference guarantees.

## Input / Output

The method consumes n training points in R^d with scalar observations, kernel hyperparameters θ ∈ R^p, and a regular d-dimensional grid of m inducing points with uniform spacing h = 2D/m^(1/d) over a domain [-D,D]^d. The cubic convolutional interpolation produces a sparse weight matrix W ∈ R^{n×m} with L = 4^d nonzeros per row, from which the approximate Gram matrix K̃ = W K_U W^⊤ is formed. Outputs include the SKI posterior mean and covariance at T test points, estimated hyperparameters via gradient ascent on the SKI log-likelihood, and explicit error bounds (e.g., ‖K − K̃‖₂ = O(nc^{2d}/m^{3/d})) that quantify the approximation quality as a function of n, m, d, and kernel smoothness.

## Method

The analysis proceeds in layers: first, a multivariate extension of Keys (1981) shows tensor-product cubic convolutional interpolation has uniform error O(c^d h³) = O(c^d/m^{3/d}); second, a triangle-inequality decomposition of the SKI kernel yields elementwise error O(c^{2d}/m^{3/d}); third, row-sum arguments convert this to spectral norm bounds for the Gram matrix (O(nc^{2d}/m^{3/d})) and cross-kernel matrix (O(max(n,T)c^{2d}/m^{3/d})). From these, Theorem 4.5 shows m must grow as n^{d/3} to hold Gram matrix error at a fixed ε, and Corollaries 4.6–4.7 identify two dimensionality regimes: for d < 3, any fixed ε achieves linear-time O(n) complexity for large n, while for d ≥ 3, ε must grow with n to preserve linearity. For hyperparameter estimation, the paper bounds the SKI score function error as O(c^{2d}√p·n²/m^{3/d}) (1/n-normalized) and applies Stonyakin et al. (2023) to show gradient ascent reaches an O(1/K)-neighborhood of a true stationary point. Posterior mean and covariance errors are bounded via standard quadratic-form techniques, revealing that m = n^{2d/3} is needed to control the mean error, while the covariance bound grows as n^{1+d/3} under the m ∝ n^{d/3} scaling, indicating a fundamental limitation for uncertainty quantification.

## Results

The paper's central theoretical result is that the SKI Gram matrix spectral norm error scales as O(nc^{2d}/m^{3/d}), implying m ∝ n^{d/3} inducing points are needed to maintain fixed error. This yields two dimensionality regimes: for d < 3, any fixed spectral error tolerance is achievable in linear time O(n) for sufficiently large n; for d ≥ 3, the error must grow with n to preserve linear-time complexity. Empirically, on synthetic RBF-kernel data, observed error decay rates with m_total are consistently steeper than the theoretical bound predicts (e.g., slope ≈ −5.11 vs. expected −3.00 for d=1; ≈ −2.83 vs. −1.50 for d=2; ≈ −2.05 vs. −1.00 for d=3), and error levels across d=1,2,3 converge to similar low values at n≈1000 when m_total ∝ n^{d/3}.

**Table 1: Summary of SKI error bounds with convolutional cubic interpolation.**

| Quantity | Bound |
|---|---|
| SKI kernel error | O(c^{2d} / m^{3/d}) |
| SKI Gram matrix error | O(nc^{2d} / m^{3/d}) |
| SKI cross-kernel matrix error | O(max(n,T)·c^{2d} / m^{3/d}) |
| SKI (1/n)-normalized score function error | O(c^{2d}·√p·n² / m^{3/d}) |
| SKI posterior mean error | (c^{2d}/(σ²m^{3/d}))·√n·O(max(T,n) + √(Tn)·Mn/σ²) |

## Baselines & Comparisons

This is a theoretical paper and does not benchmark SKI against competing approximate GP methods (e.g., Nyström, sparse variational GPs, or other SKI extensions). The closest prior work is Moreno et al. (2023), which derived SKI Gram matrix error bounds only for the univariate (d=1) case and did not analyze downstream effects on MLE or posterior inference; the present paper extends to general d and provides end-to-end bounds from elementwise kernel error through spectral norm error to hyperparameter estimation and posterior mean/covariance error. The empirical section validates the theory rather than comparing methods: observed RBF-kernel error decay is faster than the conservative theoretical rates, and the recommended m ∝ n^{d/3} scaling effectively mitigates the dimensionality penalty, with d=1, 2, and 3 errors converging at larger n. The paper positions its contribution as filling a practice-theory gap for the original Wilson & Nickisch (2015) SKI formulation, noting that extensions to high-dimensional SKI variants (Kapoor et al., 2021; Yadav et al., 2022) remain future work.

## Relation to Prior Work

This paper provides the first end-to-end theoretical error analysis for Structured Kernel Interpolation (SKI/KISS-GP), building directly on Wilson & Nickisch (2015), which introduced the method without any error guarantees. It extends Keys (1981)'s univariate cubic convolution interpolation error bound to the multivariate tensor-product setting (Lemma 4.1) and applies Stonyakin et al. (2023)'s inexact gradient descent results to analyze SKI hyperparameter estimation. Prior work by Moreno et al. (2023) gave SKI Gram matrix bounds only for univariate features, and Burt et al. (2019; 2020) analyzed sparse variational GPs but not SKI; this paper unifies elementwise, spectral, estimation, and posterior error into a single framework for the first time.

## Why It Matters / Open Questions

The paper gives practitioners a concrete rule (m ∝ n^{d/3}) for selecting inducing points and identifies a fundamental dimensionality threshold: for d < 3, any fixed spectral error is achievable in linear time, while for d ≥ 3 the error must grow with sample size to maintain linear complexity. Key limitations include pessimistic bounds (empirical decay is much faster than theory predicts for smooth RBF kernels), restriction to regular grids and stationary kernels, and only gradient ascent (not SGD) analysis. Open questions include extending to non-regular inducing point placements, non-stationary kernels, higher-order interpolation, and stochastic optimization settings.

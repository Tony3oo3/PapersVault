## Problem

While confounding (spurious correlations) is well-studied in static settings and catastrophic forgetting is well-studied in continual learning, the interaction between the two—where confounders vary across sequential tasks—remains unexplored. This paper shows that preventing forgetting is insufficient to prevent confounding, and introduces the concept of 'insidious continual confounding,' where a model trained jointly on all tasks can learn the ground truth rule but fails to do so when the same data is accumulated sequentially, even with infinite memory.
![Teaser figure](../imgs/ICML20250222/cropped_page0_idx0.webp)

## Input / Output

Each input is a 224×224 RGB image containing exactly 4 geometric objects rendered via Blender, where each object has a shape (cube, sphere, cylinder), material (metal, rubber), size (small, large), and color (8 options). The output is a binary label indicating whether the ground truth rule (a sphere and a small cube are both present) is satisfied. The dataset includes confounded training tasks where task-specific features (blue, metal, or large) are correlated with the label, plus a separate unconfounded test set where only the ground truth rule determines the label, enabling detection of whether a model learned the true rule or a shortcut.

## Method

The paper provides a formal logical framework characterizing two variants of continual confounding: 'strict' (confounders may appear in other tasks' data) and 'disjoint' (confounders appear only in their own task), deriving constraints on what a learned predicate must satisfy to solve all tasks jointly versus sequentially. Built on this framework, the ConCon dataset (63,000 images) is generated on the CLEVR platform with 3 tasks sharing a common ground truth rule (sphere ∧ small cube) but each having a unique confounder (blue, metal, large). The empirical evaluation uses ResNet-18 and a neuro-symbolic Slot Attention + Set Transformer model (NeSy) trained with 11 continual learning methods (ER, DER, EWC, FROMP, BGS, GDUMB, PNNs, etc.), demonstrating that all methods learn the disjunction of confounders rather than the ground truth rule, and that on the strict variant, cumulative continual training achieves >20% lower unconfounded accuracy than joint training on identical data.

## Results

On the ConCon disjoint variant, all evaluated methods (including joint and cumulative training) achieve near-perfect accuracy on confounded tasks but collapse to ~50% (chance level) on the unconfounded test set, demonstrating that preventing catastrophic forgetting is insufficient to avoid confounding. On the ConCon strict variant, the key finding of *insidious continual confounding* emerges: joint training on all tasks achieves 95.7% accuracy on unconfounded data (NN), while cumulative continual training on the identical data drops to 72.6%, and shuffled training reaches 89.5%. Standard CL methods (ER, DER, BGS) fail on unconfounded data in the strict setting, scoring only 49–51%, despite achieving >96% on current confounded tasks.

## Baselines & Comparisons

The paper does not propose a new method but benchmarks 11 CL approaches (ER, DER, BGS, EWC, FROMP, GDUMB, PNNs, generative replay) plus joint, cumulative, and shuffled baselines on the ConCon dataset. In the disjoint setting, all methods tie at ~50% on unconfounded data—memory-based methods (ER, DER, BGS) and PNNs successfully prevent forgetting (≥95% old-task accuracy) but none learn the ground truth rule. In the strict setting, the comparison becomes stark: joint training (95.7% unconfounded) outperforms cumulative training (72.6%) by 23.1 points on the same data, and shuffled training (89.5%) outperforms cumulative by 16.9 points, isolating the confounding alignment as the cause. Memory-based CL methods (ER, DER, BGS) that fully prevent forgetting in the disjoint setting degrade to near-chance unconfounded accuracy (49–51%) in the strict setting, showing that confounding is a harder problem than forgetting. PNNs, which architecturally eliminate forgetting via separate heads, still score only 49.2% on unconfounded data, confirming that task isolation does not help extract the shared ground truth rule.

## Relation to Prior Work

This paper sits at the intersection of two previously separate research threads: confounded/spurious-correlation datasets (ColorMNIST, CLEVR-Hans, Decoy-MNIST) and continual learning benchmarks (permuted MNIST, class-incremental CIFAR/ImageNet). It builds on CLEVR's synthetic object-based image generation framework but departs fundamentally from both lineages: prior confounded datasets were static (single training phase), while prior CL datasets focused exclusively on catastrophic forgetting rather than distributional confounders. The paper introduces the first formal logical framework for describing how confounders interact across sequential tasks, and the first CL dataset where confounders vary per task, thereby carving out a genuinely new problem space at the intersection of these two areas.

## Why It Matters / Open Questions

The paper challenges a foundational assumption in continual learning—that cumulative training with an infinite memory buffer serves as a performance upper bound—by demonstrating that joint training can substantially outperform sequential cumulative training on identical data when confounders are task-aligned. This 'insidious continual confounding' effect, grounded in a formal logical analysis, opens a new research direction for CL methods that must not only prevent forgetting but also resist task-specific shortcuts. Limitations include the synthetic CLEVR-style setting, binary classification, and only three tasks; extending to natural images, multi-class problems, and more tasks remains open. The ConCon dataset and its generation code provide a controlled benchmark for future work on causal rehearsal, bias mitigation, and robust continual learning.

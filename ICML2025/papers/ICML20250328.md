## Problem

Gold's (1967) identification-in-the-limit theorem guarantees that any enumerable function class can be learned in the limit, but provides no bound on the minimum input length required for length generalization. This paper asks the non-asymptotic question: what is the minimum input length needed to guarantee length generalization, as a function of the complexity of the ground-truth function? The answer determines whether length generalization is practically achievable or only asymptotically guaranteed.

## Input / Output

The learning algorithm receives the exhaustive labeled dataset D_N(f*) containing all binary strings of length at most N paired with their ground-truth labels, and outputs a finite program p (a description in the encoding system R) such that R(p) equals the ground-truth function. The key constraint is that the training set is complete up to length N rather than a random sample, and the output must be a single hypothesis that correctly labels all strings of arbitrary length, not just those seen in training.

## Method

The paper introduces a formal framework for non-asymptotic length generalization requiring a computable upper bound on the minimum input length as a function of ground-truth complexity, and proves the Minimum-Complexity Interpolator (MCI) is optimal among all learning algorithms for this quantity. A central characterization shows that a function class admits non-asymptotic length generalization if and only if its language equivalence problem is decidable, which implies no computable bound exists for Context-Free Grammars. For positive results, the paper proves DFAs require only 2c−2 input length for c states, and for transformer-related C-RASP functions, 1-layer programs need O(T²) and 2-layer K-head programs need O(T^O(K)) input length. The C-RASP² proof proceeds by mapping binary strings to discrete test-functions, approximating them with continuous test-functions parameterized by segment lengths over a finite set of schemas, lower-bounding the margin of the average-of-vertices of the resulting polytope, and then discretizing back to a finite-length string.

## Results

The paper establishes non-asymptotic upper bounds on the minimum training input length required for length generalization across four function classes. For DFAs with c states, the bound is 2c−2 (Proposition 2.7). For CFGs, no computable upper bound exists (Proposition 3.5), establishing a fundamental separation from asymptotic learnability. For 1-layer C-RASP with precision T, the bound is O(T²) (Theorem 5.5), and for 2-layer C-RASP with precision T and K heads, the bound is O(T^{O(K)}) (Theorem 5.6). The Minimum-Complexity Interpolator (MCI) is proven optimal: no learning algorithm can achieve a smaller length complexity (Theorem 3.2).

**Table 1: Summary of results — upper bounds on minimum length of binary strings in training data sufficient for length generalization.**

| Function Class | Complexity of Ground-Truth Function | Length of Training Data Sufficient to Generalize |
|---|---|---|
| DFAs | number of states, c | 2c − 2 (Prop. 2.7) |
| CFGs | description length, c | no computable bound in c exists (Prop. 3.5) |
| C-RASP¹ | precision, T | O(T²) (Thm. 5.5) |
| C-RASP² | precision T, and number of heads K | O(T^{O(K)}) (Thm. 5.6) |

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; the 'comparisons' are between function classes and between asymptotic vs. non-asymptotic guarantees. The key theoretical comparison is between Gold's (1967) asymptotic identification-in-the-limit and the paper's non-asymptotic framework: CFGs admit length generalization in the limit (Prop. B.2) but provably do not admit non-asymptotic length generalization (Prop. 3.5), since the language equivalence problem for CFGs is undecidable. The MCI algorithm is shown to be optimal among all learning algorithms (Theorem 3.2), meaning no alternative learner can reduce the required training length. The paper also positions its C-RASP results relative to prior work by Zhou et al. (2023) and Huang et al. (2024), which provide only asymptotic guarantees for RASP-L and Limit Transformers, whereas this paper delivers concrete non-asymptotic length bounds. The gap between the O(T²) bound for 1-layer and O(T^{O(K)}) bound for 2-layer C-RASP highlights the exponential cost of additional depth in the length complexity.

## Relation to Prior Work

This paper extends Gold's (1967) identification-in-the-limit framework from an asymptotic guarantee ('eventually generalizes') to a non-asymptotic one that provides a computable upper bound on the minimum input length needed for length generalization, expressed as a function of the ground-truth function's complexity. The Minimum-Complexity Interpolator (MCI) algorithm studied here is essentially Gold's enumeration-based learner ordered by a complexity measure (equivalent to MDL when complexity is program length). The main positive results are built on the C-RASP function class defined by Yang & Chiang (2024), which captures a subset of transformer-expressible functions and has been shown to predict empirical transformer length generalization behavior (Zhou et al., 2023; Huang et al., 2024). The paper departs from prior work by proving that non-asymptotic length generalization is equivalent to decidability of the language equivalence problem, yielding a clean impossibility for CFGs that no prior work had established.

## Why It Matters / Open Questions

This paper provides the first non-asymptotic length generalization guarantees, bridging the gap between Gold's asymptotic theory (which predicts generalization for all enumerable function classes) and the empirical observation that transformers fail to length generalize on many tasks. The equivalence to decidability of language equivalence is a clean characterization that explains *why* some classes (CFGs) cannot have computable length bounds despite being learnable in the limit. The C-RASP results (O(T²) for 1-layer, O(T^O(K)) for 2-layer) give concrete, if idealized, predictions about how much training data is needed for transformer-like functions. Open questions include extending to 3-layer C-RASP, incorporating bias terms, and formalizing partial length generalization; the MCI algorithm is computationally intractable, so connecting these bounds to gradient-based training remains a significant gap.

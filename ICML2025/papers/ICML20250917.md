## Problem

The sample complexity of the Median-of-Means (MoM) estimator for simultaneously estimating the mean of every function in a class F under heavy-tailed distributions (only p-th moments for p∈(1,2]) was not previously characterized. Existing results either provided estimation error bounds dependent on Rademacher complexity (which is hard to make explicit for unbounded function classes) or required bounded support, leaving a gap for a clean sample complexity guarantee that handles unbounded functions like k-means losses and general regression losses.

## Input / Output

The method consumes an i.i.d. sample X ~ D^n partitioned into κ batches of m samples each, a function class F ⊆ R^X, and target parameters ε, δ. It outputs a uniform guarantee that sup_{f∈F} |MoM(f,X) − μ(f)| ≤ ε with probability ≥ 1−δ, along with an explicit sample complexity bound of order (v_p/ε^p)^{1/(p−1)} · log(N_D(ε/16, (v_p/ε^p)^{1/(p−1)}) / δ). Unusually, the input requirement is a distribution-dependent D-discretization of F that only needs to approximate most (not all) of the κ batch means, rather than a uniform L1-net over the entire function class.

## Method

The core contribution is a novel two-ghost-sample symmetrization technique that replaces the standard single-ghost-sample argument. The first ghost sample symmetrizes the true mean (replacing μ_f with a sample mean), while the second ghost sample symmetrizes the MoM itself (replacing the true mean in the batch-mean comparison with another sample mean), creating an 'imbalance' between a bad MoM (≥ half its batch means wrong) and a good ghost MoM (nearly all batch means correct). The proof then proceeds in three steps: (1) symmetrization establishing this imbalance, (2) an imbalance-preserving discretization that maps F to a finite set F_{(ε,m)} of size N_D(ε,m) while only requiring most batch means to be approximated (allowing up to 2κ/625 failures), and (3) a permutation argument showing that, given the i.i.d. symmetry between the two MoMs, such a large imbalance occurs with probability at most exp(−κ/50). This discretization at the sample-mean level (rather than pointwise) is what makes the result applicable to unbounded function classes.

## Results

The main theorem establishes that the MoM estimator achieves uniform mean estimation over a function class F with sample complexity of order $(v_p/\varepsilon^p)^{1/(p-1)} \log(N_\mathcal{D}(\varepsilon/16, (v_p/\varepsilon^p)^{1/(p-1)})/\delta)$, requiring only $p$-th moments for $p \in (1,2]$. For k-means clustering over unbounded spaces, the implied sample complexity is $\frac{v_p^{1/(p-1)}}{\varepsilon^{p/(p-1)}}(dk\log k \log(1/\varepsilon) + \log(1/\delta))$, which features an exponential improvement in the confidence parameter $1/\delta$ over prior work (log vs. linear). For linear regression with L-Lipschitz losses, the bound is $\frac{1}{\varepsilon^{p/(p-1)}}(d\log(WL/\varepsilon) + \log(1/\delta))$, matching known rates for sub-exponential distributions while only requiring $p$-th moments.

## Baselines & Comparisons

Compared to Bachem et al. (2017) for k-means, the new bound replaces the kurtosis-dependent term $\mathcal{K}/(\varepsilon^2 \delta)$ with $(v_p/\varepsilon^p)^{1/(p-1)}\log(1/\delta)$, yielding an exponential improvement in the confidence parameter (log vs. linear in $1/\delta$) and decoupling the complexity term $dk\log k$ from the confidence term. The new result also weakens the moment assumption from finite 4th moments (kurtosis) to finite $p$-th moments for $p \in (1,2]$. Compared to Lecué et al. (2020) and Lugosi & Mendelson (2019), which provide estimation error bounds depending on Rademacher complexity, the present work gives an explicit sample complexity bound that avoids the Rademacher complexity entirely, making it applicable to unbounded function classes like k-means with unbounded centers and linear regression with general continuous losses where Rademacher complexity is not explicitly computable. The rates match those of the sample mean under sub-exponential tails (Maurer & Pontil, 2021) up to log factors, while extending to the much broader heavy-tailed setting.

## Relation to Prior Work

This paper extends the classical uniform convergence framework (Bartlett et al., 1996; Alon et al., 1997) to the heavy-tailed regime where only p-th moments exist for p∈(1,2], by analyzing the Median-of-Means estimator (Nemirovskij & Yudin, 1983) rather than the sample mean. The key technical departure is a novel two-ghost-sample symmetrization that replaces the standard one-ghost-sample approach, enabling a relaxed discretization that only requires most (not all) batch means to be approximated — a critical relaxation for unbounded function classes. For k-means, the paper builds directly on the normalized loss class and packing lemmas from Bachem et al. (2017), but replaces their sample-mean analysis (requiring finite kurtosis) with MoM analysis (requiring only p-th moments), yielding an exponential improvement in the confidence term. Unlike concurrent work on MoM estimation error (Lecué et al., 2020; Lugosi & Mendelson, 2019) that depends on Rademacher complexity, this paper takes a sample-complexity perspective that avoids the difficulty of explicitly bounding Rademacher complexity for unbounded classes.

## Why It Matters / Open Questions

The result provides the first explicit sample complexity bound for uniform MoM estimation under heavy tails, matching the optimal rate for sub-Gaussian settings while requiring only p-th moments — a practically important relaxation for domains like attention models, econometrics, and network science where heavy tails are well-documented. The k-means application is notable for decoupling the confidence term from the complexity term (dk log k), which was entangled in prior work, and for requiring only finite variance rather than finite kurtosis. Open questions include matching asymptotic lower bounds (as done by Lee & Valiant, 2022 for single-mean estimation), finding additional function classes admitting the required D-discretization, and whether the large constants (on the order of 10^6) can be tightened. The relaxed discretization notion may also be useful for deriving explicit bounds from Rademacher-complexity-based estimation error results for broader function classes.

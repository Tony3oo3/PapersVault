## Problem

Neural algorithmic reasoners struggle to generalize to out-of-distribution data, especially on larger graphs, because continuous internal representations drift under distributional shifts. Classical algorithms are immune to such shifts since their execution is a sequence of transitions between discrete computational states. The paper asks whether forcing neural reasoners to maintain their execution trajectory as a combination of finite predefined states can simultaneously achieve perfect generalization and interpretability by design.

## Input / Output

The model takes a graph with adjacency matrix, node/edge features, and scalar values (edge weights, node indexes) as input. Crucially, scalars are kept in a separate continuous data flow that only influences attention weights as tie-breakers among equally-prioritized discrete states, rather than being encoded into node/edge features. Outputs include node pointers (e.g., parent in a BFS tree), discrete node/edge states from a fixed finite set, and updated scalar values (e.g., shortest-path distances) computed via discrete operations.

## Method

The proposed Discrete Neural Algorithmic Reasoner (DNAR) builds on a single-head Transformer Convolution processor with three architectural constraints: (1) discrete bottlenecks at the end of each processor step project node/edge features to a fixed finite set of states via one-hot encoding, (2) hard attention (one-hot over neighbors) prevents attention weight annealing on arbitrarily large graphs and limits the message set each node can receive, and (3) a ScalarUpdate module performs discrete manipulations (increment, keep, push) on continuous scalars conditioned on discrete states, avoiding the precision failures of learning continuous arithmetic. Trained with step-wise hint supervision and teacher forcing, the model perfectly aligns with the ground-truth algorithm trajectory. Because all state transitions and attention decisions depend only on a finite set of discrete states, the learned model can be exhaustively unit-tested to prove correctness on any test data of any size.

## Results

On the SALSA-CLRS benchmark, the proposed Discrete Neural Algorithmic Reasoner (DNAR) achieves perfect 100%/100% node/graph-level scores across all six tasks (BFS, DFS, Dijkstra, Prim, MIS, Eccentricity) and all test sizes from 16 to 1600 nodes. In contrast, GIN drops to 86.5%/0.0% on BFS at 1600 nodes, and PGN drops to 98.5%/0.0% on the same setting. On the CLRS-30 test set (size 64), DNAR also achieves 100% node-level accuracy on all four evaluated tasks, outperforming Hint-ReLIC (best: 100% on DFS, 99.00% on BFS) and G-ForgetNet (best: 99.96% on BFS, 95.19% on Prim).

## Baselines & Comparisons

Against GIN (Xu et al., 2019), DNAR dominates across all tasks and sizes: GIN's graph-level accuracy collapses to 0% on most tasks beyond 80 nodes (e.g., 0.0% on DFS at 80 nodes, 0.0% on Dijkstra at 80 nodes), while DNAR maintains 100% up to 1600 nodes. PGN (Veličković et al., 2020a) is stronger than GIN but still degrades substantially with size (e.g., 0.0% graph-level on DFS at 80 nodes, 0.0% on Dijkstra at 160 nodes, 83.0% on Eccentricity at 1600 nodes), whereas DNAR remains at 100% throughout. On the CLRS-30 test set (size 64), DNAR achieves 100% node-level accuracy on all four tasks, outperforming Hint-ReLIC (Bevilacqua et al., 2023) which scores 99.00% on BFS, 97.74% on Dijkstra, and 87.97% on Prim, and G-ForgetNet (Bohde et al., 2024) which scores 99.96% on BFS, 99.14% on Dijkstra, and 95.19% on Prim. The gap is most pronounced on Prim, where DNAR's 100% exceeds G-ForgetNet by ~4.8 points and Hint-ReLIC by ~12 points.

## Relation to Prior Work

This paper extends the neural algorithmic reasoning (NAR) line of work built on the CLRS-30 and SALSA-CLRS benchmarks, where GNN-based processors trained with hint supervision imitate classical algorithm execution. It departs from prior NAR methods (Pointer Graph Networks, GIN, Triplet-GMPNN, Hint-ReLIC, G-ForgetNet) that operate entirely in continuous representation space, by imposing three architectural constraints: feature discretization into finite states, hard attention, and a strict separation of discrete state flows from continuous scalar inputs. The interpretability motivation draws from the Transformer interpretability literature (RASP, Tracr, Transformer Programs), which formalizes discrete computational models behind attention-based architectures, but the paper applies these ideas to graph-based algorithmic reasoning rather than sequence modeling.

## Why It Matters / Open Questions

The ability to prove correctness of a *learned* neural algorithm for arbitrary test data is a strong guarantee that prior NAR methods cannot offer, with direct implications for safety-critical and verifiable AI applications. Key limitations include reduced expressivity (hard attention prevents computing neighbor means in a single step), dependence on hint supervision for most tasks, and the no-hint setting remaining largely unsolved (best no-hint model fails beyond training distances). Open questions include whether the discrete/continuous separation generalizes to other architectures, whether the ScalarUpdate module can be extended to a full discrete Neural Turing Machine, and whether curriculum learning can close the no-hint gap for sequential algorithms like DFS.

## Problem

Dataset Inference (DI) requires a held-out set that is in-distribution with the suspect dataset but known to be absent from training, yet such data is rarely available in practice. The paper demonstrates that even trivial distributional shifts between suspect and held-out texts from the same author cause DI to produce significant false positives, rendering it unreliable for real-world copyright claims. The core question is how to synthetically generate a valid held-out set and calibrate for the residual distributional gap it introduces.

## Input / Output

The method takes a suspect text dataset (segmented into sequences of at most 64 tokens) and black-box query access to the target LLM, and produces a binary membership decision with a statistical p-value from a difference comparison t-test. A key structural constraint is that the suspect and held-out sets are generated as paired suffixes sharing a common prefix, ensuring direct comparability. The synthetic held-out text itself is also an output, enabling the arbiter to inspect generation quality.

## Method

The approach has two stages. First, a LoRA-finetuned Llama 3 8B generator is trained on shuffled text snippets from the suspect dataset via next-token prediction; at inference, each sequence is split into a prefix and suffix, and the generator produces a synthetic suffix from the prefix, yielding paired original (suspect) and synthetic (held-out) suffixes with minimal distributional shift (GPT2 AUC ≈ 52.2% vs. 99% for ICL baselines). Second, a post-hoc calibration step uses a dual-classifier design: a 2-layer GPT2 text classifier quantifies the natural-vs-synthetic distributional gap, while a combined classifier additionally ingests MIA scores (perplexity, min-k probabilities, zlib ratio) from the target LLM. A difference comparison t-test then checks whether the combined classifier's shift significantly exceeds the text classifier's shift, attributing any excess to genuine membership signal rather than generation artifacts. A sigmoid weight constraint on the linear MIA aggregation further prevents negative weights from amplifying generation-induced perplexity differences into false positives.

## Results

On the single-author blog dataset, the method correctly identifies the member set with p-value 0.01 (AUC_Comb 55.6% vs. AUC_Text 53.8%) and correctly rejects the non-member set with p-value 0.13 (AUC_Comb 53.9% vs. AUC_Text 53.8%). Across 16 diverse Pile subsets (Wikipedia, ArXiv, FreeLaw, PubMed, Github, EuroParl, etc.), all member sets are detected with p-values below 0.05 (many below 0.001), while all non-member sets are correctly rejected with p-values above 0.1. The AUC gap between the combined and text-only classifiers on member sets ranges from 1.8 to 6.0 percentage points, confirming a genuine membership signal beyond distributional artifacts.

## Baselines & Comparisons

Against the original LLM DI method (Maini et al., NeurIPS 2024), which uses a direct t-test on aggregated MIA scores without calibration, the paper's post-hoc calibration is critical: the uncalibrated DI produces p-values < 0.001 for both member and non-member sets (Setting 6 in Table 5), yielding false positives that falsely accuse model providers of copyright infringement. The paper's dual-classifier calibration eliminates these false positives, raising non-member p-values to 0.13–1.0 while preserving member detection. Against SimPO-based preference optimization (Meng et al., NeurIPS 2024) as a held-out data generation method, the paper's suffix completion approach achieves a lower GPT2 classifier AUC (52.2% vs. 58.9%), indicating a smaller distributional gap between synthetic and natural text. When preference-optimized text is used as the held-out set, DI suffers complete false negatives (p = 1.0 for member sets in Table 5, Setting 3), whereas suffix completion enables correct detection across all 16 Pile subsets.

## Relation to Prior Work

This paper extends the dataset inference (DI) framework of Maini et al. (2021, 2024) and Dziedzic et al. (2022b), which requires an in-distribution held-out set to statistically test whether a suspect dataset was used in training. It builds on the de-biasing insights from Kazmi et al. (2024, PANORAMIA) and the distributional-shift critiques of Das et al. (2024) and Duan et al. (2024), which showed that even small distributional gaps between member and non-member sets invalidate MIA-based conclusions. The key departure is replacing the unavailable held-out set with synthetically generated data via a suffix-completion generator (LoRA-finetuned Llama 3), then disentangling the generation-induced text-space shift from the membership signal in model-output space using a dual-classifier calibration and a difference-comparison t-test with Sidak correction.

## Why It Matters / Open Questions

The paper addresses the single most practical barrier to deploying DI in real copyright disputes: the near-impossibility of obtaining a truly IID held-out set from the same distribution as the suspect data. By showing that even same-author blog posts produce false positives in standard DI (Table 1), it reframes DI's reliability as a first-order concern rather than an edge case. The dual-classifier calibration is a clean conceptual contribution—generation shift lives in text space, membership signal in model-output space—and the weight constraint prevents a subtle failure mode where negative linear-regression weights amplify generation artifacts. Open questions include scalability to very small suspect sets (the paper uses ~1,000+ samples for statistical power), applicability to non-text modalities, and whether the method remains robust when the target model has seen the suspect data during pretraining rather than fine-tuning.

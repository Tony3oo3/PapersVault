## Problem

While Transformers have been shown to simulate parallel computational models like MPC, it remains unclear whether their attention mechanism must be input-dependent (self-attention) to achieve algorithmic expressivity. Many parallel algorithms communicate between processors using only positional information (processor IDs) rather than data values, yet no prior work has studied whether a Transformer variant with data-agnostic, position-only attention can match the expressivity and learnability of standard Transformers for algorithmic tasks.

## Input / Output

The model takes a numerical sequence X ∈ R^{n×d_X} (values sampled in [-2,2] for training) along with fixed positional encodings P ∈ R^{n×d_P} that are decoupled from the input and remain constant across all layers. For mixed-type tasks, inputs combine textual category tokens (e.g., 'Cat5') with associated numerical values, and the model must perform conditional aggregation over a queried subset. Outputs are algorithmic computation results: cumulative statistics (sum, min, median, max-sum subarray), sorted sequences, or a scalar extracted via w^T X^out[n] from the final layer's last position.

## Method

The positional Transformer replaces self-attention with positional attention, where attention weights A^(ℓ,h) = softmax((P W_Q^(ℓ,h))(P W_K^(ℓ,h))^T) are computed exclusively from fixed positional encodings P rather than the input X, while value projections V^(ℓ,h) = X W_V^(ℓ,h) still process input data. For expressivity, the paper introduces a proxy model (PCOC) with static, data-agnostic communication and shows that R rounds of MPC can be simulated by 2R⌈log N⌉ rounds of PCOC via Beneš network routing, which in turn maps to the same number of positional Transformer layers. For learnability, a norm-based PAC generalization bound is derived that eliminates the exponential dependence on key/query spectral norms present in self-attention Transformers, at the cost of potentially requiring O(log n) more layers for tasks like reduction. Empirically, positional Transformers achieve superior out-of-distribution generalization on tasks whose algorithmic solutions rely on positional communication (e.g., cumulative min via binary tree), but underperform on tasks requiring dynamic, data-dependent communication patterns (e.g., k-hop induction heads).

## Results

Theoretically, positional Transformers simulate the MPC model with O(log n) additional layers (Theorem 5.1) and achieve a norm-based generalization bound (Theorem 6.1) that eliminates the exponential dependence on key/query weight norms present in self-attention Transformers. Empirically, on five computational tasks (cumulative sum, min, median, sorting, max-sum subarray) with n=8, both architectures reduce in-distribution loss monotonically from 5,000 to 50,000 samples. For out-of-distribution generalization (value range scaled by factor c up to 10×), positional Transformers exhibit significantly more stable loss across all five tasks, while standard Transformers degrade sharply. On the k-hop induction heads task, standard Transformers reach near-zero in-distribution loss with only 3 layers, whereas positional Transformers require substantially more layers, confirming the theoretical logarithmic depth overhead.

## Baselines & Comparisons

The primary baseline is the standard self-attention Transformer (Vaswani et al., 2017). On the five numerical algorithmic tasks, positional Transformers achieve comparable in-distribution loss but demonstrate markedly more stable out-of-distribution generalization as the input value range is scaled up to 10× the training range, while standard Transformers show significant performance degradation. On the k-hop induction heads task, the comparison reverses: standard Transformers achieve near-zero loss with 3 layers, while positional Transformers require many more layers and perform poorly out-of-distribution, reflecting the dynamic (data-dependent) communication pattern that positional attention cannot efficiently capture. On the mixed-type input task (textual categories + numerical values with conditional aggregation), positional Transformers outperform standard Transformers in both in-distribution and OOD settings. A secondary comparison against a fine-tuned GPT-2 (Radford et al., 2019) in Appendix D.3 shows positional Transformers achieving better OOD performance on the mixed-type task, though the authors note this does not imply superiority over LLMs on general-purpose text reasoning.

## Relation to Prior Work

This paper extends the Transformer-MPC simulation framework of Sanford et al. (2024) by asking what happens when attention weights are restricted to depend solely on fixed positional encodings rather than input-dependent queries and keys. It introduces a proxy model (PCOC) with static, data-agnostic communication and uses Beneš networks to bridge the gap between this restricted model and full MPC, showing that positional Transformers retain full expressivity at a logarithmic depth cost. The norm-based generalization analysis builds directly on Edelman et al. (2022), demonstrating that decoupling attention from input removes the exponential dependence on key/query norms, while the architectural modification itself is a targeted departure from the standard Transformer of Vaswani et al. (2017).

## Why It Matters / Open Questions

The paper provides a clean theoretical characterization of when data-agnostic (positional) communication suffices for algorithmic computation, offering practitioners a principled criterion for when the simpler positional attention architecture is appropriate. The empirical finding that positional Transformers generalize better out-of-distribution for position-based tasks (cumulative sum, sorting) but fail on tasks requiring dynamic communication (k-hop induction heads) highlights a fundamental tension between architectural simplicity and task structure. Key limitations include the reliance on fixed-length positional encodings (preventing length generalization) and the absence of tight theoretical OOD bounds; developing length-adaptive positional encodings and formal OOD guarantees are natural next steps.

## Problem

Single-turn text-to-image generation often fails to capture a user's nuanced or evolving visual intent, especially for complex or abstract concepts. No prior framework formulates iterative, preference-adaptive multi-turn T2I generation as a sequential decision-making problem, and no large-scale sequential preference dataset for T2I exists to train such a system.
![Teaser figure](../imgs/ICML20251821/cropped_page1_idx0.webp)

## Input / Output

The agent receives an initial text prompt (≤12 words) and, at each of H=5 turns, the user's selection of one of L=4 image columns (each column containing M=4 images from a 4×4 grid). The user sees only the generated images, not the underlying prompt expansions. At each turn the agent outputs a slate of L=4 prompt expansions (selected from L_C=25 LMM-generated candidates partitioned into 5 categories, with at most one prompt per category), each fed to Stable Diffusion XL to produce M=4 images. The value function is a Gemma 2B model that reads the full interaction history as text and scores each candidate prompt via a designated 'q logit' at the final token position.

## Method

PASTA frames multi-turn prompt expansion as a latent contextual MDP over K user types and trains a value-based candidate selector using Implicit Q-Learning (IQL) with an α-expectile regression to avoid out-of-distribution overestimation. The key tractability trick, inspired by SlateQ, decomposes the slate value into the average of per-prompt values, reducing slate selection from combinatorial to O(L_C log L_C) sorting. A Gemini 1.5 Flash LMM serves as a fixed candidate generator producing 25 diverse prompts across 5 categories; the Gemma 2B selector picks the top-4 (one per category). User preferences are modeled via an EM-trained score function built on CLIP encoders with per-user-type residual heads, trained on single-turn preference data (HPS V2, Pick-a-Pic, SAC) and fine-tuned on ~7,000 human-rater sequential trajectories; this user model then generates 30,000+ simulated rollouts that, combined with real data, substantially improve the RL agent's performance.

## Results

In human-rater evaluations, PASTA (trained on both real and simulated data) achieves an 85% relative improvement over the untrained Gemini 1.5 Flash baseline when directly comparing final-turn images. PASTA also generalizes to the Flux.1 T2I model without retraining, achieving a 20% relative improvement over the Gemini baseline. In simulated-user experiments (Appendix F.1), the value model trained on simulated data achieves the highest cumulative reward (9.26 ± 0.07 sparse; 46.35 ± 0.38 dense), outperforming the random policy (7.38 ± 1.13 sparse; 38.57 ± 5.81 dense) by ~25% and ~20% respectively.

## Baselines & Comparisons

The sole baseline is the untrained Gemini 1.5 Flash LMM, which serves as both the candidate generator and the default prompt-expansion agent. PASTA (fine-tuned Gemini 1.5 Flash with a learned value-based selector) consistently outperforms this baseline across all human-rater evaluation settings: training on real rater data alone improves over the baseline, training on simulated data alone causes a slight decline, and the combination of both yields the best performance. The headline 85% relative improvement on final-turn image comparison and the 20% improvement on Flux.1 (without any Flux-specific retraining) demonstrate that the learned value function captures transferable preference dynamics. In the simulated-user setting, all value-based PASTA variants beat the random policy, with the simulated-data-trained model achieving the highest scores, confirming that the user simulator faithfully captures the evaluation dynamics.

## Relation to Prior Work

This paper extends the interactive text-to-image generation line (FABRIC, Promptify, DPO-based alignment) by formalizing multi-turn prompt refinement as a latent contextual MDP where user types are inferred online, drawing on the preference elicitation literature from recommender systems. The RL training leverages Implicit Q-Learning (Kostrikov et al., 2021) for offline policy learning and the SlateQ decomposition (Ie et al., 2019) to make slate selection tractable, while the user model builds on Bradley-Terry preference modeling and CLIP-based scoring with an EM procedure for discovering latent user types. Unlike prior methods that modify internal diffusion model parameters (attention maps, noise schedules, prompt embeddings), PASTA operates purely at the prompt level, making it model-agnostic across T2I backends.

## Why It Matters / Open Questions

The paper releases the first large-scale sequential T2I preference dataset (~40K multi-turn rollouts, 500K+ images) and a user simulator, filling a gap where only single-turn preference data existed. The 85% relative improvement over an untrained LMM baseline on final-turn comparison and the 20% transfer to Flux.1 without retraining demonstrate practical value, though the baseline is relatively weak (no fine-tuning, no RL). Key limitations include simplified user model assumptions (choice-preference equivalence, no position bias), the absence of concurrent A/B testing in the rater study, and reliance on sparse final-turn rewards. Open questions include whether the user type structure generalizes beyond the ~16-type plateau, how the approach scales to longer horizons or more complex multi-objective preferences, and whether the simulated data gap (slight degradation when used alone) can be closed with richer user models.

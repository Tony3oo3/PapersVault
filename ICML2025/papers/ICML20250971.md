## Problem

Irregular Multivariate Time Series (IMTS) forecasting is hampered by unaligned multi-channel signals and extensive missing values, causing existing GCN-based and Neural-ODE-based methods to produce unreliable temporal patterns and poor few-shot generalization. While visual foundation models (e.g., VisionTS) demonstrate strong potential for time series via Masked Autoencoders, they are restricted to regularly sampled data and fail on IMTS due to rigid grid assumptions and lack of cross-channel imputation. This paper bridges that gap by adapting a pretrained visual MAE to handle the sparsity and irregularity inherent in IMTS.

## Input / Output

The model receives an IMTS observation triplet (timestamps, observed values, binary mask matrix) of N variables with irregular sampling and up to 96.7% missingness, along with a set of future query timestamps that can be at arbitrary continuous times. Internally, the data is segmented into equal-interval time windows (patch size varies by dataset: 1 to 300 time steps), and each window yields one patch per channel after TTCN feature extraction and GCN cross-channel compensation. The output is a scalar prediction for each query timestamp, produced by a 2-layer MLP that fuses the timestamp embedding with the reconstructed patch representation, enabling predictions at any continuous time point rather than a fixed grid.

## Method

VIMTS treats IMTS as a time x channel image-like structure and adapts a pretrained visual MAE-base through three stages. First, a Transformable Time-aware Convolutional Network (TTCN) extracts variable-length intra-section features per channel, which are then compensated at the feature level by a lightweight GCN that learns bidirectional cross-channel dependencies via adaptive adjacency matrices, effectively imputing missing values without explicit interpolation. Second, the compensated patches are projected into the MAE encoder with learnable temporal period embeddings (2D sine-cosine encoding treating the sequence as a T-by-1 patch grid), and the pretrained MAE performs patch-level reconstruction to model temporal dependencies within each channel. Third, a coarse-to-fine Patch2Point decoder reconstructs target patches via mask tokens and then queries them with timestamp embeddings through a 2-layer MLP for point-level predictions. Training follows a two-stage strategy: self-supervised mask-reconstruction (randomly masking patches and reconstructing them) adapts the visual MAE to IMTS-specific channel counts and sparsity patterns, followed by supervised fine-tuning where only normalization layers (and optionally GCN/position embeddings for high-channel datasets) are updated to preserve the pretrained sparse-modeling capability.

## Results

VIMTS achieves the lowest MSE and MAE across all four IMTS datasets with 100% training data: PhysioNet (MSE 4.81×10⁻³, MAE 3.54×10⁻²), Human Activity (MSE 2.65×10⁻³, MAE 3.08×10⁻²), USHCN (MSE 4.86×10⁻¹, MAE 2.98×10⁻¹), and MIMIC (MSE 1.36×10⁻², MAE 6.40×10⁻²). Notably, VIMTS with only 20% of training data already matches or exceeds the full-data performance of the strongest baseline t-PatchGNN on three of four datasets. The method also demonstrates robust few-shot capability, maintaining competitive accuracy at 10% data where t-PatchGNN degrades substantially (e.g., on Human Activity at 10% data, VIMTS achieves MSE 2.87×10⁻³ vs. t-PatchGNN's 7.28×10⁻³).

## Baselines & Comparisons

VIMTS outperforms the strongest IMTS-specific baseline t-PatchGNN on all four datasets for MAE (e.g., 3.54 vs. 3.72 on PhysioNet, 6.40 vs. 6.56 on MIMIC) and matches or beats it on MSE, with the closest margin on MIMIC where both achieve 1.36×10⁻². Among regular time series methods (DLinear, TimesNet, PatchTST, Crossformer, Graph Wavenet, MTGNN, StemGNN, CrossGNN, FourierGNN), VIMTS achieves 3–10× lower MSE, confirming that methods designed for regularly sampled data fail catastrophically on IMTS due to unhandled missing values and irregular sampling. VisionTS, the closest vision-foundation-model baseline, performs worst among all methods (e.g., MSE 42.41×10⁻³ on PhysioNet with zero interpolation), demonstrating that simply interpolating IMTS to a regular grid before applying a visual MAE is insufficient. Among IMTS-specific methods (GRU-D, SeFT, RainDrop, Warpformer, mTAND, Latent-ODE, CRU, Neural Flow), VIMTS achieves the best or near-best results, with the largest margins on PhysioNet (MSE 4.81 vs. 5.59 for GRU-D) and Human Activity (MSE 2.65 vs. 2.79 for Warpformer). In few-shot settings (10–50% data), VIMTS maintains stable performance while t-PatchGNN degrades sharply (e.g., on Human Activity at 10% data: VIMTS MSE 2.87×10⁻³ vs. t-PatchGNN 7.28×10⁻³), highlighting the benefit of visual pre-training and self-supervised learning for data-efficient IMTS modeling.

## Relation to Prior Work

VIMTS extends the line of work initiated by VisionTS (Chen et al., 2025), which demonstrated that visual MAEs pre-trained on RGB images can be repurposed for regularly sampled time series forecasting, by adapting this paradigm to the substantially harder irregular multivariate setting with 75–97% missing data. Architecturally, it borrows the Transformable Time-aware Convolutional Network (TTCN) from Zhang et al. (2024b) for variable-length intra-section feature extraction and the adaptive GCN-based cross-channel dependency modeling from t-PatchGNN (Zhang et al., 2024a), but reorganizes these components around a visual MAE-base backbone with a two-stage (SSL + fine-tuning) training strategy. The key departure from prior IMTS methods (Neural ODEs, CRU, GRU-D) is the explicit use of a large-scale visual pre-trained encoder as the temporal dependency model, treating time×channel patches as an image-like structure rather than modeling continuous-time dynamics.

## Why It Matters / Open Questions

This is the first framework to demonstrate that visual foundation models can be effectively adapted to IMTS forecasting, opening a path for leveraging the massive pre-training compute invested in vision for the broader time series domain. The strong few-shot capability (20% training data matching full-data SOTA) is practically significant for data-scarce clinical and environmental monitoring settings. However, the paper acknowledges limitations in scalability (fixed patch sizes, fixed channel counts) and the absence of a true zero-shot or cross-dataset generalization capability, leaving open the question of whether a larger IMTS-specific foundation model can be built on this architecture. The moderate performance gains over t-PatchGNN (e.g., ~3–5% MSE improvement on most datasets) suggest the visual prior provides a useful inductive bias but is not yet a dominant advantage over purpose-built IMTS architectures.

## Problem

Graph HyperNetwork (GHN) methods for parameter initialization struggle with larger models (e.g., ViT-Base), perform poorly on smaller datasets, and require independent retraining for each new task, incurring substantial computational and storage overhead. This paper asks whether a single shared model can predict well-initialized parameters across flexible model scales and diverse tasks without per-task retraining.
![Teaser figure](../imgs/ICML20252789/cropped_page1_idx0.webp)

## Input / Output

The method takes two inputs: (1) a model computational graph (a DAG whose nodes are operations like convolution, self-attention, pooling) specifying the target architecture, and (2) a task embedding vector generated by a pretrained ancestry model (ViT-Base for vision, GPT-2 for NLP) via average feature extraction over task images. The output is a full set of initialized model parameters for the specified architecture, supporting scales from ViT-Tiny (3 layers) up to ViT-Base (12 layers) and GPT-2 variants (3–12 layers), for both seen and unseen downstream tasks.

## Method

TAL uses an encoder-decoder architecture where the encoder, termed 'learngene,' is a stack of transformer blocks that jointly processes the model computational graph and a task embedding. A FiLM-style task-specific layer, whose scale (γ) and shift (β) parameters are generated by a lightweight MLP task hypernet from the task embedding, modulates the computational graph to produce a task-conditioned graph before decoding. Training proceeds in two stages: first, the TAL model is pretrained on ImageNet-1K under guidance of the ancestry model using a combined KL-divergence (feature alignment) and cross-entropy loss; second, it is tuned across multiple Decathlon tasks with temperature-based task sampling, allowing the learngene to filter task-specific knowledge from the inherited ancestry knowledge. The decoder (adopted from LoGAH) then maps the task-specific computational graph to concrete model parameters. The enhanced variant TAL+ additionally trains on a custom ViTs⁺-1K architecture dataset containing wider and deeper ViT configurations, enabling parameter prediction for base-scale models that prior GHN methods cannot handle.

## Results

On the Visual Domain Decathlon (10 datasets), untrained ViT models initialized with TAL/TAL+ outperform those initialized with LoGAH by an average of 24.39% in accuracy. On ImageNet-1K, a ViT-Small model initialized with TAL+ achieves 39.22% top-1 accuracy without any training, compared to 16.78% for LoGAH (a 22.44% gap). Notably, TAL+ is the only method capable of predicting parameters for ViT-Base-scale models, reaching 38.72% untrained accuracy on ImageNet-1K. TAL also reduces total training time by 22% compared to LoGAH (36.19h vs. 46.55h on an RTX 4090).

## Baselines & Comparisons

Compared to GHN-3 (Knyazev et al., 2023), TAL/TAL+ dominates across all Decathlon tasks and model scales; for example, on CIFAR-100 with a 12-Small model, TAL+ reaches 56.04% untrained accuracy versus 5.55% for GHN-3. Against LoGAH (Zhou et al., 2024), TAL/TAL+ achieves an average 24.39% accuracy gain across the Decathlon, with particularly large margins on fine-grained and texture datasets (e.g., DTD: 33.14% vs. 8.24% for 12-Small; UCF: 48.21% vs. 4.30%). A critical advantage is scale: only TAL+ can predict parameters for ViT-Base models (38.72% untrained on ImageNet-1K), while GHN-3 and LoGAH fail entirely (0.10%). On NLP tasks, TAL outperforms LoGAH on CoLA (2.75 vs. 0.82 avg. Matthews correlation) and IMDB (62.39% vs. 55.37% accuracy) but trails slightly on MRPC and RTE, suggesting the task-aware mechanism is most beneficial for tasks with strong visual or sentiment signals. In terms of efficiency, TAL reduces total training time by 22% over LoGAH (36.19h vs. 46.55h), and on NLP it requires a single shared model trained for 100 epochs versus four separate LoGAH models each trained for 250 epochs.

## Relation to Prior Work

This paper unifies two previously separate lines of work on model initialization: Graph HyperNetworks (GHN-1/2/3, LoGAH), which predict parameters from computational graphs, and Learngene, which condenses knowledge from a pretrained ancestry model into compact components for expansion. The key architectural departure is introducing a task hypernet (inspired by FiLM/TADAM) that modulates the model's computational graph with task-specific embeddings before decoding, effectively making the GHN encoder 'task-aware.' Unlike prior GHN methods that require independent training per task, TAL uses a single shared model trained via multi-task SGD, and unlike prior Learngene variants that splice or linearly expand fixed sub-blocks, TAL treats the learngene as a full encoder whose outputs are dynamically conditioned on both architecture and task.

## Why It Matters / Open Questions

The practical impact is significant: a single TAL model replaces the need to train and store separate GHNs for each downstream task, reducing both computational and storage overhead, while also enabling initialization of ViT-Base-scale models where prior GHNs (GHN-3, LoGAH) completely fail (0.10% accuracy). Open questions include whether the ancestry-model dependency limits applicability to domains without a strong pretrained foundation model, whether the approach scales beyond ViT/GPT-2 to other architecture families, and whether the 24.39% Decathlon improvement generalizes to truly novel task distributions beyond the 10+3 datasets tested. The theoretical analysis (Appendix 3) provides only standard convergence guarantees for the simplified binary-classification case, leaving the multi-task, multi-scale setting theoretically uncharacterized.

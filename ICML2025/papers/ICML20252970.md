## Problem

Many conformal prediction methods require parameter tuning (e.g., RAPS hyperparameters, score aggregation weights, confidence calibration scalars), and prior work assumed that reusing the calibration set for tuning destroys exchangeability and invalidates coverage guarantees. However, no formal quantification of the resulting coverage gap—termed the 'tuning bias'—existed, leaving practitioners uncertain whether a separate hold-out set is truly necessary, especially in data-scarce settings.

## Input / Output

The framework takes a pre-trained classifier (e.g., ResNet-18 on CIFAR-100 or ImageNet), a calibration set of size n, and a parameterized score transformation S^λ with parameter space Λ (ranging from a single scalar in temperature scaling to 2K parameters in vector scaling or K²+K in ConfTr fine-tuning). It outputs a prediction set C(x) and quantifies the tuning bias as the difference in coverage gap between tuning on the same set versus a separate hold-out set. The key experimental variable is the dimensionality of Λ and the calibration set size n, which jointly determine the magnitude of the bias.

## Method

The paper reformulates parameter tuning in conformal prediction as a constrained empirical risk minimization (ERM) problem over the joint parameter (λ, t), then measures the tuning bias via the classical empirical process sup_λ,t |empirical − population| over the indicator class H_Λ = {1{S^λ(x,y) ≤ t}}. For finite parameter spaces, it derives a tight upper bound using the Dvoretzky-Kiefer-Wolfowitz inequality with a union bound over |Λ| candidates, yielding O(√(log|Λ|/n)). For infinite parameter spaces, it bounds the VC dimension of H_Λ by d+1 (where d is the parameter dimension) and applies the VC empirical process bound to obtain O(√(d/n)). This establishes the parametric scaling law: tuning bias grows with parameter space complexity and shrinks with calibration set size. The paper further proposes two mitigation strategies—reducing parameter count via weight sharing (e.g., temperature scaling as a special case of vector scaling) and applying order-preserving regularization that reduces the effective parameter dimension from 2K to 2 for vector scaling.

## Results

The headline metric is tuning bias — the additional coverage gap from using the same dataset for both parameter tuning and conformal calibration. On CIFAR-100 (calibration set size 2500), temperature scaling achieves only 0.14% tuning bias while vector scaling reaches 1.13%; on ImageNet (calibration set size 5000), the gap widens to 0.04% vs. 6.63%. ConfTr(ft.) without order-preserving constraint shows the largest bias at 21.68% on ImageNet, which is reduced to 0.40% when the order-preserving constraint is applied. The empirical scaling law confirms that tuning bias increases with parameter space complexity (e.g., freezing 40% of vector scaling parameters reduces bias by >50%) and decreases with calibration set size (bias drops ~50% from n=6000 to n=10000).

## Baselines & Comparisons

The paper evaluates seven conformal prediction methods with parameter tuning, comparing coverage gaps under 'same dataset' vs. 'hold-out' settings. RAPS, SAPS, score aggregation, and C-Adapter all show negligible tuning bias — their coverage gaps are nearly identical regardless of whether a separate hold-out set is used, confirming that simple parameter tuning (scalar or small finite grid) does not meaningfully violate exchangeability. Temperature scaling (1 parameter) achieves dramatically lower tuning bias than vector scaling (2K parameters): 0.14% vs. 1.13% on CIFAR-100 and 0.04% vs. 6.63% on ImageNet, directly validating the parametric scaling law. ConfTr(ft.) without regularization exhibits the worst bias (6.15% on CIFAR-100, 21.68% on ImageNet), but applying the paper's order-preserving constraint reduces it to 0.52% and 0.40% respectively — a >98% reduction on ImageNet. The regression experiments (CQR on Protein Structure) confirm the same scaling pattern: tuning bias grows with the number of candidate models and shrinks with calibration set size.

## Relation to Prior Work

This paper extends the learnability framework for conformal prediction (Bai et al., 2022; Gupta et al., 2022) by incorporating tuning parameters into the constrained ERM formulation, and then applies classical empirical process theory (van der Vaart & Wellner, 1996) to bound the resulting coverage gap. Prior conformal prediction methods (RAPS, SAPS, score aggregation, confidence calibration, ConfTr) have all assumed a separate hold-out set for tuning, and while several works noted that reusing the calibration set for tuning 'destroys exchangeability,' none provided a formal quantification of the resulting coverage gap. The paper's key conceptual move is recasting the tuning bias as an empirical process supremum over an extended function class, enabling the use of VC-dimension and Dvoretzky-Kiefer-Wolfowitz tools to derive parametric scaling bounds.

## Why It Matters / Open Questions

The practical implication is significant for data-scarce settings (rare diseases, disaster prediction, privacy-constrained data) where splitting a calibration set is infeasible: the paper shows that for simple tuning (scalar parameters, finite candidate selection), the tuning bias is negligible, so practitioners can safely reuse data. The scaling law (bias grows with parameter-space dimension d and shrinks with calibration size n) provides actionable guidance for when separation is truly necessary. Limitations include that the theoretical bounds are acknowledged as loose without additional structural assumptions on the score function, and the empirical study, while spanning multiple methods and datasets, focuses primarily on classification with a single architecture family (ResNet-18). Open questions include tightening bounds via parameter-space structure and extending the analysis to more complex non-exchangeable settings.

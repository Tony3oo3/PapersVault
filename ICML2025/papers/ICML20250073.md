## Problem

In standard PAC learning, achieving zero error generally requires infinite samples, and in strategic classification, agents manipulate features to deceive the classifier. This paper asks how the ability of agents to genuinely improve their features by a bounded amount r changes the learnability landscape: can zero-error classification become achievable, and what structural properties of the concept class (beyond VC dimension) govern learnability when agents respond to the deployed classifier by improving?

## Input / Output

The learner receives m i.i.d. labeled samples from an unknown distribution D over instance space X, an improvement function Δ: X → 2^X mapping each agent to the set of points it can reach (e.g., an ℓ_p-ball of radius r), and a concept class H. The output is a binary classifier h: X → {0,1}. Crucially, the loss is evaluated after agents react: negatively classified agents move to a positively classified point in their improvement set (breaking ties adversarily), so the classifier must be conservative—its positive region should be contained in the true positive region to avoid false positives induced by agent movement.

## Method

The core algorithm is the closure algorithm applied to intersection-closed concept classes: it outputs the smallest hypothesis in H containing all positive training examples, which guarantees that any point h classifies as positive is truly positive, so agent improvements can only reduce error. For thresholds, this yields the rightmost threshold consistent with positive examples, achieving population error (ε−r)_+ instead of ε. For axis-aligned hyperrectangles with ℓ_∞ improvement balls, the error reduction equals the probability mass of the outer boundary strip of width r around the learned rectangle. In a discrete graph model where agents move to neighbors, a conservative classifier labeling only observed positive nodes achieves zero error with O(n(log n + log 1/δ)/(d_min^+ + 1)) samples, matching a coupon-collector lower bound. Empirically, risk-averse training via weighted BCE (penalizing false positives with w_FP > w_FN) or elevated decision thresholds (0.9 instead of 0.5) combined with projected gradient descent for agent improvement within an ℓ_∞ ball of radius r drives test error toward zero as r increases.

## Results

The paper is primarily theoretical, with empirical validation on the Adult, OULAD, and Law School datasets (plus a synthetic 8D dataset). The key empirical finding is that risk-averse models trained with weighted BCE loss (w_FP/w_FN > 1) start with higher initial error than standard BCE models but achieve substantially faster error reduction as the agent improvement budget r increases, with test error sometimes reaching zero (e.g., Figure 10g). Modest improvement budgets (r ≤ 2.0) yield the largest error reductions, with diminishing returns beyond r = 2.0. Loss-based risk aversion (varying w_FP/w_FN) consistently outperforms threshold-based risk aversion (raising the classification threshold from 0.5 to 0.9) across all datasets.

## Baselines & Comparisons

The paper compares three classification strategies: (1) a standard model trained with binary cross-entropy (BCE, w_FP = w_FN = 1), (2) a risk-averse model trained with weighted BCE (wBCE, w_FP/w_FN > 1), and (3) a threshold-based risk-averse model using a 0.9 decision threshold instead of 0.5. The wBCE-trained models consistently outperform both the standard BCE model and the threshold-based approach in reducing overall error as agents improve, while maintaining low false positive rates after agent movement. The standard BCE model shows comparable total error reduction but at the cost of higher false positives post-improvement. The threshold-based approach (0.9 threshold) underperforms the loss-based wBCE approach across all tested datasets. The paper does not provide a single consolidated numerical comparison table; results are presented as error-vs-improvement-budget curves in Figures 2, 8, 9, and 10, with the qualitative conclusion that stricter false-positive penalties yield greater gains from agent improvements.

## Relation to Prior Work

This paper extends the strategic classification framework (Hardt et al., 2016) and the strategic improvement model (Kleinberg & Raghavan, 2020; Miller et al., 2020) by shifting the focus from incentivizing agents and maximizing social welfare to understanding learnability, sample complexity, and classification error. It repurposes the closure algorithm from intersection-closed concept class learning (Natarajan, 1987; Helmbold et al., 1990; Auer & Ortner, 2007) as the natural risk-averse learner in the improvement setting, and contrasts its results against both standard PAC learning and the strategic PAC framework of Sundaram et al. (2023). The key conceptual departure is that prior strategic improvement work optimized for true-positive maximization, whereas this paper studies classification error under a loss that penalizes false positives after agents improve, revealing that the right structural condition for learnability is intersection-closure rather than VC dimension.

## Why It Matters / Open Questions

The demonstration that zero-error PAC learning is achievable (with finite samples) in the improvement setting is a genuinely new phenomenon absent from both standard and strategic PAC, suggesting that agent improvement capacity fundamentally alters the landscape of what is learnable. The separation results—VC dimension neither necessary nor sufficient, and learnability with improvements being sometimes easier and sometimes harder than strategic classification—provide a clearer map of the theoretical landscape. Open questions include fully characterizing proper and improper PAC learnability with improvements, designing adaptive learners that determine when sufficient data has been collected, and extending the analysis to agnostic (non-realizable) settings. The empirical validation, while limited to small tabular datasets and simple architectures, confirms the theoretical prediction that risk-averse classifiers (weighted-BCE with high false-positive penalty) benefit most from agent improvements.

## Problem

Accurately modeling inter-variable correlations in multivariate time series forecasting is difficult when data is corrupted by non-stationary disturbances such as noise, extreme values, and missing data, which distort sample-level correlation patterns away from the true global structure. Existing attention-based methods derive all of Q, K, and V from the input sample, making them vulnerable to these local perturbations, while channel-independent methods avoid the problem by ignoring inter-variable dependencies altogether. The paper asks how to robustly integrate both stable global correlations and local sample-specific information within a single attention mechanism.

## Input / Output

The model takes a multivariate look-back window X_t ∈ R^{C×L} (C channels, L=96 timesteps by default) together with a cycle index computed as t mod W, where W is the dataset's dominant periodicity (e.g., 24 for hourly data with daily cycles, 168 for weekly cycles). The cycle index selects which segment of the learnable TQ parameter matrix to use as queries. The output is a multivariate forecast Ŷ_t ∈ R^{C×H} for H ∈ {96, 192, 336, 720} future timesteps, optionally de-normalized via instance normalization to recover the original scale.

## Method

The core contribution is the Temporal Query (TQ) technique, which replaces the conventional self-attention query with periodically shifted learnable vectors θ_TQ ∈ R^{C×W} (initialized to zero and optimized during training), while keys and values are still derived from the raw input X_t. Because samples W time steps apart extract identical query segments, the learned queries effectively average correlations over multiple periods, mitigating the impact of local noise and outliers. The full TQNet architecture is deliberately minimal: a single-layer TQ-enhanced multi-head attention (4 heads) for inter-variable correlation modeling, a two-layer MLP with GeLU activations for temporal dependency extraction, and a linear output projection with dropout, all connected with residual links. An optional instance normalization layer removes per-sample mean and variance before and after the model to handle distributional shift. The hyperparameter W is set to match the dataset's stable periodicity (identified via domain knowledge or autocorrelation), and the periodic shifting mechanism enables parameter reuse across time, keeping the model lightweight while capturing robust global inter-variable structure.

## Results

TQNet achieves Top-2 performance in 22 out of 24 MSE/MAE metrics across 12 real-world multivariate datasets (look-back L=96, horizons H∈{96,192,336,720}). On high-dimensional datasets, TQNet delivers the best MSE on Electricity (0.164), PEMS07 (0.075), PEMS04 (0.091), PEMS03 (0.097), PEMS08 (0.142), Solar (0.198), and Traffic (0.445). The model uses only a single-layer TQ-enhanced multi-head attention and a two-layer MLP, yet outperforms heavier architectures like iTransformer and TimeXer on most datasets while maintaining training efficiency comparable to linear-based methods like DLinear.

## Baselines & Comparisons

TQNet outperforms all 9 baselines on 7 of 12 datasets (Electricity, Solar, Traffic, PEMS03, PEMS04, PEMS07, PEMS08), with particularly large margins on PEMS07 (MSE 0.075 vs. TimeXer 0.085, iTransformer 0.101) and PEMS04 (MSE 0.091 vs. SCINet 0.093, TimeXer 0.105). On the ETT series and Weather, TQNet is competitive but not always best: TimeXer edges out TQNet on ETTh1 MSE (0.437 vs. 0.441) and ETTh2 MSE (0.368 vs. 0.378), while CycleNet leads on ETTm2 MSE (0.266 vs. 0.277). TQNet consistently beats CI-based methods (PatchTST, DLinear) and older CD-based methods (Crossformer, SCINet) across all 12 datasets, with gaps exceeding 0.1 MSE on high-dimensional data. Among attention-based CD methods, TQNet surpasses iTransformer on 10/12 datasets and TimeXer on 8/12, confirming that the TQ technique's global-correlation modeling provides a meaningful advantage over pure self-attention. The ablation in Table 3 further shows that the hybrid Q=TQ/K=Raw design outperforms both pure self-attention (Q=Raw/K=Raw) and pure global (Q=TQ/K=TQ) configurations on all 7 high-dimensional datasets tested.

## Relation to Prior Work

TQNet sits within the Channel Dependence (CD) family of multivariate time series forecasting methods, which explicitly model inter-variable correlations. It draws conceptual inspiration from CycleNet's use of learnable periodic parameters and from iTransformer's attention-based channel mixing, but departs from both by repurposing periodic learnable vectors as attention queries (encoding global, dataset-level correlations) while retaining raw input as keys and values (encoding local, sample-level correlations). This hybrid global-local query design is the paper's core architectural novelty, distinguishing it from prior CD methods that derive all of Q, K, V from the input sample and are thus vulnerable to non-stationary noise.

## Why It Matters / Open Questions

The TQ technique offers a portable, lightweight mechanism for robust multivariate correlation modeling that can be dropped into existing architectures (demonstrated on iTransformer, PatchTST, and DLinear), making it practically useful beyond TQNet itself. Key limitations include the dependence on a correctly specified periodicity hyperparameter W (limiting applicability to aperiodic data), diminishing returns with long look-back windows, and potential over-modeling when inter-variable correlations are weak. Open questions include how to handle multi-periodic or aperiodic datasets, whether the periodic-query idea generalizes to other attention-based tasks, and whether the efficiency advantage persists at very high channel counts (>1000).

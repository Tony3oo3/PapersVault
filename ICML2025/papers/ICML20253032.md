## Problem

The Private Evolution (PE) algorithm for DP synthetic image generation via diffusion model APIs degrades severely with few-shot private data because its Gaussian Mechanism-based similarity voting adds noise that overwhelms the small number of votes, yielding nearly random selection. This is a critical gap in specialized domains like healthcare and industry where data producers typically possess only a handful of images per class.
![Teaser figure](../imgs/ICML20253032/cropped_page0_idx0.webp)

## Input / Output

The method takes K-shot private images (default K=10 per class, at 256×256 or 96×96 resolution), a deliberately simple text prompt containing only the domain and class label names (no prompt engineering), and access to untrusted t2i and i2i generative APIs (Stable Diffusion, SD+IP-Adapter, or OpenJourney). It produces a DP synthetic image dataset with N images per class (default N=100) that satisfies ε*-DP and can be directly used to train downstream classification heads without any additional privacy cost. A pre-trained encoder (ResNet-18 or CLIP) is used locally for feature extraction, and the only tunable hyperparameter is the similarity calibrating factor τ.

## Method

PCEvolve replaces PE's GM-based similarity voting with an adapted Exponential Mechanism (EM) whose utility function u = h∘g exploits inter-class contrastive relationships beyond individual data points. The contrastive filter g is a binary indicator that assigns 1 to synthetic images closer to their own aggregated class center than to any other class center, while the similarity calibrator h converts normalized L2 distances into similarities in [0,1] via an exponential with a scaling factor τ, ensuring u values span the full range so the EM does not sample nearly uniformly. Each iteration selects one prototypical synthetic image per class via the EM (with Δu=1) and feeds it to the i2i API for refinement over T evolution steps. The privacy guarantee of ε*-DP follows from sequential composition over T×C EM queries, and the EM's δ=0 provides stronger protection than PE's (ε,δ)-DP Gaussian Mechanism at the same ε.

## Results

PCEvolve achieves the best top-1 accuracy across all four specialized datasets: 64.04% on COVIDx, 69.10% on Camelyon17, 50.95% on KVASIR-f, and 59.26% on MVTecAD-l, using only K=10 private images per class and N=100 synthetic images per class per iteration. The method outperforms the closest DP baseline PE by up to 5.44% (Camelyon17) and surpasses all non-DP API-assisted baselines (B, LE, RF, GCap) by margins of 13–32% depending on the dataset. PCEvolve also maintains strong performance with reduced synthetic data (N=50, only 0.95% drop vs. PE's 4.78% drop) and adapts to different generative APIs (SD, SD+IPA, OpenJourney).

## Baselines & Comparisons

PCEvolve outperforms all six baselines on every dataset. Against PE (Lin et al., 2024), the closest DP competitor, PCEvolve gains 4.41% on COVIDx (64.04 vs. 59.63), 5.44% on Camelyon17 (69.10 vs. 63.66), 2.07% on KVASIR-f (50.95 vs. 48.88), and 1.85% on MVTecAD-l (59.26 vs. 57.41), attributed to the contrastive filter and similarity calibrator that address PE's GM-based voting failure under few-shot conditions. Against the t2i-only baselines B (He et al., 2023), LE (Seo et al., 2024), and RF (Samuel et al., 2024), PCEvolve leads by 13.62–31.33% across datasets, demonstrating that the DP-protected evolution loop with i2i refinement substantially outperforms one-shot text-prompt generation. Notably, PCEvolve also beats the 'Private' baseline (direct training on few-shot private data) by up to 8.20% on COVIDx, showing that the synthetic dataset captures additional knowledge from the generative API beyond what the 10 private images alone provide.

## Relation to Prior Work

This paper directly extends Private Evolution (PE, Lin et al., ICLR 2024), which generates DP synthetic images via a diffusion-model API evolution loop using Gaussian Mechanism (GM) similarity voting. The key departure is replacing GM with an adapted Exponential Mechanism (EM) that is inherently suited for selection tasks, combined with two novel components: a contrastive filter that exploits inter-class relationships in few-shot private data, and a similarity calibrator that normalizes utility scores to maximize EM's selection probability. The paper also positions against a broader family of API-assisted baselines (text-prompt-only methods like B/LE, private-data-filtering methods like RF/GCap, and direct-noise methods like DPImg) that either lack DP guarantees or lack the iterative refinement of an evolution loop.

## Why It Matters / Open Questions

PCEvolve addresses a practically important gap: resource-constrained clients in specialized domains (healthcare, industry) who possess only a handful of private images but need DP-guaranteed synthetic data for downstream classification. The use of EM (δ=0) provides strictly stronger privacy than GM (δ>0) used by PE, while the contrastive filter and calibrator recover utility lost to the few-shot regime. Limitations include dependence on iterative API calls (T=20 iterations), restriction to image classification tasks, and the need for a pre-trained encoder on the client side. Open questions include whether the contrastive-filtering principle generalizes to generative or segmentation tasks, how performance scales with very large class counts, and whether the method remains effective when the API's domain knowledge is far from the private data distribution.

## Problem

Existing fixed-confidence best arm identification algorithms (e.g., Successive Elimination, KL-LUCB) provide high-probability or expected sample complexity guarantees that say nothing about the tail of the stopping time distribution. The paper demonstrates that these algorithms can actually never stop with non-negligible probability, and that even the best prior tail bound (LUCB's polynomial tail) is far from ideal. The central question is whether an exponentially-decaying tail for the stopping time can be achieved while retaining matching instance-dependent sample complexity.

## Input / Output

Both algorithms take K arms with 1-sub-Gaussian reward distributions and a target failure rate δ ∈ (0,1). FC-DSH directly outputs the estimated best arm index upon satisfying its confidence-bound stopping rule. BrakeBooster additionally requires a black-box base algorithm A (with known δ₀-correctness and sample complexity T*_{δ₀}), a base trial count L₁, and a base budget T₁; it outputs the majority-voted best arm index after a 2D doubling schedule of (trial count, per-trial budget) pairs. The key output guarantee is a (T_δ, κ)-exponential stopping tail: P(τ ≥ T) ≤ exp(−T/(κ·polylog(T))) for all T ≥ T_δ, which simultaneously implies high-probability sample complexity, finite expected stopping time, and almost-sure termination.

## Method

FC-DSH runs Sequential Halving in independent phases with a doubling budget schedule (T_m = 2^{m-1}·T₁), and at the end of each phase checks whether the lower confidence bound of the surviving arm exceeds the upper confidence bounds of all eliminated arms; if so, it stops. The confidence widths incorporate a union-bound factor over all phases and stages. BrakeBooster is a meta-algorithm that wraps any δ₀-correct base algorithm using a 2D doubling trick: it iterates over stages (r,c) where the trial count L_{r,c} = r·2^{r-c}·L₁ and per-trial budget T_{r,c} = 2^{c-1}·T₁, running the base algorithm L_{r,c} times with budget T_{r,c} and taking a majority vote. The r·2^r growth in trial count (rather than pure 2^r) is critical for making a geometric series converge in the correctness proof, while the 2D schedule keeps total per-stage budget constant within each row, ensuring the base algorithm's sample complexity is eventually exceeded. The majority voting across independent trials converts the base algorithm's constant δ₀ failure rate into an exponentially decaying overall failure probability.

## Results

FC-DSH is the first fixed-confidence BAI algorithm to achieve an exponential-tailed stopping time with a matching instance-dependent complexity, specifically a (Θ̃(H₂ log(1/δ)), Õ(H₂))-exponential stopping tail. BrakeBooster, the meta-algorithm, converts any δ₀-correct algorithm with high-probability sample complexity T*_{δ₀}(A) into one with a (Θ̃(T*_{δ₀}(A) ln(1/δ)), T*_{δ₀}(A))-exponential stopping tail, preserving the original high-probability guarantee up to polylog factors. The paper also establishes that Successive Elimination never stops with probability Ω(δ^118) and KL-LUCB never stops with constant probability, providing the first theoretical evidence of this failure mode for standard FC-BAI algorithms.

## Baselines & Comparisons

Compared to Successive Elimination, which achieves Õ(H₁ ln(1/δ)) high-probability sample complexity but provably never stops with probability Ω(δ^118), FC-DSH achieves the same order of high-probability guarantee while additionally providing an exponential tail, and BrakeBooster+SE (Corollary 4.3) recovers the Õ(H₁ ln(1/δ)) high-probability bound with an exponential tail. Against LUCB, which offers only a polynomial tail P(τ ≥ T) ≤ 4δ/T², both FC-DSH and BrakeBooster deliver strictly stronger exponential decay. Track-and-Stop, Top Two, and TTUCB all achieve optimal asymptotic expected sample complexity but have no known exponential-tail guarantee; FC-DSH and BrakeBooster imply these algorithms' expected sample complexity is finite (via Proposition 2.9) but do not yet match their instance-dependent optimality. The key distinction is that FC-DSH and BrakeBooster are the only algorithms in the comparison that simultaneously guarantee exponential-tailed stopping time, high-probability sample complexity, and (for BrakeBooster) meta-algorithmic applicability to any base algorithm.

## Relation to Prior Work

This paper builds directly on Sequential Halving (Karnin et al., 2013) and its fixed-budget doubling variant FB-DSH (Zhao et al., 2023), converting the latter into a fixed-confidence algorithm (FC-DSH) with a carefully designed stopping rule. It departs from the dominant line of work on fixed-confidence best-arm identification (Even-Dar et al., 2006; Kalyanakrishnan et al., 2012; Garivier & Kaufmann, 2016; Jourdan et al., 2022), which has focused exclusively on expected or high-probability sample complexity, by introducing the exponential-tailed stopping time as a strictly stronger guarantee criterion. The BrakeBooster meta-algorithm further generalizes this by wrapping any existing high-probability algorithm into one with exponential tail guarantees via a 2D doubling schedule and majority voting, a technique inspired by Hyperband (Li et al., 2018).

## Why It Matters / Open Questions

The demonstration that widely-used algorithms like Successive Elimination and KL-LUCB can fail to stop with non-negligible (even constant) probability reveals a hidden practical hazard in standard high-probability guarantees, which do not exclude infinite running time. The exponential tail guarantee is strictly stronger than all prior criteria and simultaneously implies high-probability sample complexity, finite expected stopping time, and almost-sure termination. Key open questions include whether instance-dependent optimality (matching Track-and-Stop) can be achieved alongside exponential tail bounds, whether the polylog(T) factor in BrakeBooster's exponent is unavoidable, and whether the resetting mechanism can be eliminated for practical deployment.

## Problem

Learning with exact group invariances in kernel regression has no known polynomial-time algorithm: data augmentation and group averaging scale as Ω(n|G|) or Ω(n²|G|), which is super-exponential for groups like the permutation group P_d. Canonicalization and frame averaging introduce discontinuities incompatible with RKHS structure. The paper asks whether an exactly invariant estimator can be computed in poly(n, d, log|G|) time while achieving the same minimax-optimal population risk O(n^{-s/(s+d/2)}) as standard kernel ridge regression without invariances.

## Input / Output

The algorithm consumes n labeled pairs (x_i, y_i) drawn uniformly from a smooth, compact, boundaryless d-dimensional Riemannian manifold M, along with oracle access to (i) evaluate any Laplace-Beltrami eigenfunction φ_{λ,ℓ}(x) at a point x, and (ii) compute the L² inner product ⟨φ_{λ,ℓ}(gx), φ_{λ,ℓ'}⟩ for any group element g. These oracles are assumed free when the cumulative eigenfunction count D_λ = Σ_{λ'≤λ} m_{λ'} is polynomial in n and d. The output is an exactly G-invariant function f̂(x) expressible as a finite sum over truncated eigenspaces, evaluable at any new point x ∈ M in O(n^{1/(1+α)}) time with the same number of oracle calls.

## Method

The key insight is that the Laplace-Beltrami operator commutes with isometric group actions, so each group element acts via an orthogonal matrix D^λ(g) on the finite-dimensional eigenspace V_λ. This converts the nonlinear pointwise constraint f(gx)=f(x) into the linear spectral constraint D^λ(g) f_λ = f_λ on coefficient vectors. By restricting to a minimal generating set S with |S| ≤ log|G| (Proposition B.1), the invariance requirement reduces to log|G| linear constraints per eigenspace. The problem then decomposes into independent convex quadratic programs—one per eigenspace—each solved in closed form via a Moore-Penrose projection of the empirical spectral coefficients onto the invariant subspace. Truncation at the cutoff D_λ ≤ D = n^{1/(1+α)} (where α = 2s/d) balances the Sobolev bias O(D^{-α}) against the empirical variance O(D/n), yielding the same O(n^{-s/(s+d/2)}) risk as unconstrained KRR while running in O(log³|G| · n^{3/(1+α)} + n^{(2+α)/(1+α)}) time.

## Results

The main theoretical result (Theorem 1) shows that the proposed Spectral Averaging (Spec-Avg) algorithm produces an exactly G-invariant estimator in time O(log³(|G|)·n^(3/(1+α)) + n^((2+α)/(1+α))) while achieving excess population risk O(n^(−s/(s+d/2))), matching the minimax-optimal rate of standard Kernel Ridge Regression without invariances. In the empirical validation (d=10 torus, sign-invariance group of size 2^10), Spec-Avg with D=176 achieves the same order of test error as KRR with λ=50, while KRR exhibits a non-zero Invariance Discrepancy (ID) confirming it is not G-invariant in practice. The algorithm requires only O(log(|G|)·n^(2/(1+α)) + n^((2+α)/(1+α))) oracle calls and computes new predictions in O(n^(1/(1+α))) time.

## Baselines & Comparisons

The primary baseline is standard Kernel Ridge Regression (KRR) on the Sobolev space H^s(M), which achieves the minimax-optimal population risk O(n^(−s/(s+d/2))) in O(n³) time but is provably not G-invariant. The paper demonstrates empirically (Figure 1, Appendix C) that KRR indeed violates invariance in practice, with a non-zero Invariance Discrepancy ID(f̂) = sup_{x,g}|f̂(x) − f̂(gx)| across all tested regularization parameters. The second implicit baseline is group averaging (constructing K_inv by summing over all |G| group elements), which guarantees exact invariance but requires Ω(n²|G|) time — intractable for groups like the permutation group P_d where |G| = d! is super-exponential. Spec-Avg matches KRR's statistical rate exactly (same O(n^(−s/(s+d/2))) risk) while adding exact invariance at only a polylog(|G|) computational overhead, and empirically achieves the same order of test error as KRR with appropriate hyperparameter tuning (D=176 for Spec-Avg vs. λ=50 for KRR in the d=10 torus experiment). The key advantage over group averaging is the reduction from |G| constraints to log(|G|) constraints via minimal generating sets, combined with the spectral decomposition that converts the nonconvex invariance constraints into per-eigenspace linearly constrained quadratic programs.

## Relation to Prior Work

This paper departs from the standard approaches to invariant kernel learning—group averaging, data augmentation, canonicalization, and frame averaging—all of which require Ω(|G|) operations and are infeasible for large groups (e.g., permutation groups with |G| = d!). Instead, it repurposes the spectral theory of the Laplace-Beltrami operator on Riemannian manifolds, combined with the basic group-theoretic fact that ρ(G) ≤ log(|G|) generators suffice, to reformulate invariant kernel regression as infinitely many finite-dimensional convex quadratic programs with linear constraints. This connects to the line of work on invariant kernel generalization (Tahmasebi & Jegelka 2023, Elesedy 2021, Bietti et al. 2021) but shifts the focus from statistical bounds to statistical-computational trade-offs, and resolves a question posed by Díaz et al. (2025) on efficient computation of invariant bases for finite groups.

## Why It Matters / Open Questions

The result establishes that exact (not approximate) group invariance in kernel regression can be achieved in poly(n, d, log|G|) time with zero statistical loss relative to unconstrained KRR, which is a clean and important separation from prior methods that either sacrifice exactness or computational efficiency. Key open questions include whether the improved minimax-optimal rates known to exist for invariant kernel regression (Tahmasebi & Jegelka 2023) are achievable in polynomial time, whether the kernel trick can replace the need for explicit eigenfunction evaluation, and whether random feature approximations preserve the invariance guarantees. The spectral reformulation as infinite convex QPs may also find applications beyond kernel regression, e.g., in density estimation under symmetry.

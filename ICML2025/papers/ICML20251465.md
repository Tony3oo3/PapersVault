## Problem

Multimodal emotion recognition (MER) with MLLMs is hindered by three gaps: the absence of large-scale datasets with descriptive, fine-grained emotion annotations; the tendency of existing MLLMs to delegate all cross-modal fusion to the LLM, which is insufficient for tasks requiring tight audio-visual integration; and the lack of evaluation metrics suited to the free-form, multi-label natural language outputs that MLLMs produce.
![Teaser figure](../imgs/ICML20251465/cropped_page1_idx0.webp)

## Input / Output

The model consumes three modalities from single-person video clips: an audio track encoded by HUBERT-L, 8 sampled face frames encoded by CLIP ViT-L, and the corresponding text transcript. The output is a free-form natural language description containing a variable number of fine-grained emotion labels (not restricted to any fixed taxonomy), which is then parsed into structured emotion sets for evaluation. The default input configuration is audio + face + text, though the framework supports any subset of these modalities.

## Method

AffectGPT introduces a pre-fusion operation that performs cross-modal interaction outside the LLM, using either a Q-Former (K learnable query tokens attend to concatenated audio-video features via cross-attention) or a lightweight attention module (average-pooled unimodal features combined with learned attention weights). The fused representation is projected into the LLM (Qwen2.5) alongside text tokens, with only the projector, pre-fusion branch, and a LoRA adapter (rank 16) trained while the LLM and encoders remain frozen. The model is trained on MER-Caption, a 115K-sample dataset built via a model-led human-assisted pipeline: SALMONN generates audio cues, Chat-UniVi generates visual cues, GPT-3.5 merges them with text, and a two-level filtering process (TalkNet-based audio-video alignment + length-distribution pruning at the low level; multi-classifier majority-voting consistency check at the high level) yields the 31K-sample MER-Caption+ subset. Evaluation uses MER-UniBench, which applies emotion-wheel-based synonym grouping and set-level F-scores for fine-grained tasks, a hit-rate metric for basic emotion tasks, and weighted F-scores for sentiment analysis.

## Results

On MER-UniBench (mean of primary metrics across 9 datasets), AffectGPT achieves 74.77 with audio+video+text input, 74.31 with video+text, and 72.18 with audio+text. The best prior MLLM is Emotion-LLaMA (64.17, A+V+T), giving AffectGPT a ~10.6-point improvement. On individual tasks, AffectGPT reaches 78.80 HIT on MER2024, 88.49 WAF on CH-SIMS, and 62.52 F_S on OV-MERD+, consistently leading all baselines across basic emotion recognition, sentiment analysis, and fine-grained emotion recognition.

## Baselines & Comparisons

AffectGPT outperforms all 14 baseline MLLMs across every modality configuration. In the audio+text setting, AffectGPT (72.18) surpasses the strongest audio MLLM SALMONN (57.89) by 14.3 points. In the video+text setting, AffectGPT (74.31) leads the best video MLLM mPLUG-Owl (62.45) by 11.9 points. In the full audio+video+text setting, AffectGPT (74.77) beats the closest competitor Emotion-LLaMA (64.17) by 10.6 points. The gap is particularly large on fine-grained emotion recognition (OV-MERD+), where AffectGPT scores 62.52 versus Emotion-LLaMA's 52.97, and on basic emotion recognition (MER2023/MER2024), where AffectGPT reaches 78.54/78.80 versus Emotion-LLaMA's 59.38/73.62. Notably, even the weakest AffectGPT configuration (audio+text, 72.18) exceeds the strongest single-modality baseline (mPLUG-Owl, 62.45), suggesting the pre-fusion architecture and MER-Caption dataset contribute more than modality coverage alone.

## Relation to Prior Work

This paper extends multimodal emotion recognition (MER) from the traditional discriminative paradigm (mapping to fixed emotion taxonomies like Ekman's six basic emotions) to a generative, MLLM-based framework that produces free-form emotional descriptions. It builds on the recent shift toward descriptive emotion datasets (EmoVIT, MERR, MAFW, OV-MERD) but departs from prior annotation strategies by proposing a 'model-led, human-assisted' approach that uses human priors to guide automatic description generation and filtering, rather than relying on purely human or purely model-based labeling. Architecturally, it departs from existing AV-LLMs (e.g., Emotion-LLaMA, PandaGPT) that leave all cross-modal interaction to the LLM, instead introducing a pre-fusion module (Q-Former or attention) that performs explicit multimodal integration before the language model.

## Why It Matters / Open Questions

The MER-Caption dataset (115K samples, 2,932 emotion categories) and MER-UniBench benchmark fill a critical gap: the field lacked both a large-scale descriptive emotion dataset and standardized evaluation metrics suited to MLLMs' free-form output. The finding that the LLM backbone choice has minimal impact (Figure 4a) suggests that dataset quality and multimodal fusion architecture matter more than the specific language model, which could guide future resource allocation. Open questions include extending to multi-person scenarios, developing metrics for evaluating fine-grained labels that appear alongside basic emotion predictions, and whether the model-led annotation strategy generalizes to other affective domains beyond the MER2024 source data.

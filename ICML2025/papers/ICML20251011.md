## Problem

While interpretability research has developed techniques to identify abstract causal mechanisms inside language models, it remains unclear whether these mechanisms can be leveraged to predict model correctness on out-of-distribution (OOD) inputs. Existing correctness-estimation methods—confidence scores and causal-agnostic probing—degrade significantly under distribution shifts, yet no prior work has systematically tested whether task-relevant causal features provide more robust predictions.
![Teaser figure](../imgs/ICML20251011/cropped_page0_idx1.webp)

## Input / Output

The methods consume a text prompt, the model's residual stream activations at specific token/layer locations (localized via Distributed Alignment Search into an orthonormal subspace Q), and a verified set of labeled ID examples. Counterfactual simulation requires k additional forward passes with intervened representations (inserting the test input's causal variable value into k base examples), while value probing requires only a single forward pass plus a trained linear classifier. The output is a continuous correctness score (log-likelihood or max class probability) that ranks predictions by likelihood of correctness, evaluated via AUC-ROC on balanced binary classification.

## Method

The paper proposes two methods that exploit previously identified high-level causal models (e.g., X→V→Y chains) to predict output correctness. Counterfactual simulation estimates P(Y|V) by performing interchange interventions: it inserts the test input's localized causal variable representation into multiple base examples from the verified set and checks whether the model's output matches the expected counterfactual label, effectively marginalizing over task-irrelevant background variables. Value probing trains a linear classifier on the causal variable subspace to predict which discrete value V takes, then uses the maximum class probability as a correctness score, exploiting the linear structure of the representation. The key insight is that features playing a distinctive causal role in the model's computation are more robust under distribution shifts than confidence scores or heuristically selected activations, because they directly reflect whether the model is implementing the correct algorithm rather than relying on surface-level statistical regularities.

## Results

Across five tasks (IOI, PriceTag, RAVEL, MMLU, UnlearnHP) evaluated with Llama-3-8B-Instruct, the proposed Counterfactual Simulation (Output Mapping) method achieves the highest AUC-ROC on 8 out of 10 OOD settings, improving average AUC-ROC by 13.84% over prior baselines. In-distribution, causal-feature methods reach near-perfect AUC-ROC on IOI (0.999) and strong scores on PriceTag (0.907) and UnlearnHP (0.919). Under OOD shifts, confidence scores degrade sharply (e.g., IOI drops from 0.935 to 0.650 with rephrased templates), while Counterfactual Simulation maintains high performance (0.997 on IOI with language change).

## Baselines & Comparisons

Against the confidence-score baseline (Hendrycks & Gimpel, 2017), Counterfactual Simulation (Output Mapping) achieves substantially higher AUC-ROC in OOD settings: 0.856 vs. 0.631 on PriceTag (currency change), 0.997 vs. 0.767 on IOI (language change), and 0.860 vs. 0.626 on UnlearnHP (length increase). Against causal-agnostic probing baselines (Zou et al., 2023; Yin et al., 2024), which probe the prompt last token or background variables, causal-feature methods win decisively in OOD: on IOI (language change), Counterfactual Simulation reaches 0.997 while Prompt-Last-Token probing drops to 0.607. The one setting where causal methods do not clearly dominate is MMLU (option symbol change), where confidence scores and causal-agnostic probing remain competitive (0.707–0.784) because the task's mixed-subject structure limits the utility of a single high-level causal model. Overall, the paper reports a 13.84% average AUC-ROC improvement for Counterfactual Simulation over all prior baselines in OOD, with the gap widening as task accuracy declines under perturbation.

## Relation to Prior Work

This paper bridges two previously separate research threads: mechanistic interpretability (specifically causal abstraction and Distributed Alignment Search for localizing high-level causal variables in LLMs, per Geiger et al. 2021, 2024a, 2024b) and correctness/confidence estimation (per Hendrycks & Gimpel 2017, Zou et al. 2023, Yin et al. 2024). Prior interpretability work has focused on the 'explanation direction'—using identified mechanisms to understand why a model generalizes—while prior correctness estimation has relied on causal-agnostic features (heuristic location-based probing or output probabilities). This paper explicitly pursues the 'prediction direction': leveraging previously identified causal mechanisms to predict whether a model will produce correct outputs, particularly under distribution shifts where causal-agnostic features degrade.

## Why It Matters / Open Questions

The paper demonstrates that internal causal features are significantly more robust predictors of correctness under distribution shift than confidence scores or causal-agnostic probes, with counterfactual simulation improving average AUC-ROC by ~14% over baselines across five diverse tasks. This opens a practical path from interpretability analysis to model safety monitoring in deployment, where OOD inputs are the norm. Key limitations include the requirement for prior knowledge of task-specific causal mechanisms (limiting applicability to open-ended tasks), reliance on linear localization (DAS), and the computational cost of counterfactual simulation (K forward passes per prediction). Open questions include whether partial or automatically discovered mechanisms suffice for complex real-world tasks, and whether the approach generalizes beyond the controlled symbolic and retrieval tasks evaluated here.

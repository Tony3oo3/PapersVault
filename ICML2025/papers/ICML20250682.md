## Problem

Multi-label class incremental emotion decoding faces two unique partial-label challenges: past-missing labels (emotions present in current data but unknown to the model) and future-missing labels (emotions in historical data that the model cannot yet perceive). Existing MLCIL methods either rely on storing historical instances, limiting practical applicability, or overlook the future-missing problem entirely, and no prior work has addressed fine-grained emotion decoding (up to 28 categories) in an incremental setting.

## Input / Output

The method consumes modality-specific feature vectors: 2880-dim fMRI features (ROI-pooled from 360 HCP cortical regions × 8 sub-volumes), 1000-dim VGG19 video features, or 512-dim MFCC/ResNet-18 audio features, along with per-instance affective dimension ratings (e.g., Arousal, Valence on a 9-point Likert scale). Output is a multi-hot emotion category set predicted by thresholding sigmoid scores at 0.5, with up to 28 fine-grained labels per instance (average label cardinality ~4.6–5.3). During incremental training, only the current task's labeled data is accessible; soft labels for previously seen classes are generated by the prior model.

## Method

AESL comprises four coupled modules: (1) an Augmented Emotional Relation Graph (ERG) with Graph-based Label Disambiguation that iteratively propagates label confidence over an instance similarity graph to produce reliable soft labels for old classes, enabling construction of the inter-task adjacency blocks R and Q via Bayes' rule; (2) a GIN-based graph autoencoder that learns emotion label embeddings from the ERG, with a pairwise cosine-similarity decoder enforcing topological fidelity; (3) a semantic-guided feature decoupling module that uses each emotion embedding to compute per-label attention weights (via FC+sigmoid) and extracts label-specific features through Hadamard product with a shared latent representation; and (4) relation-based knowledge distillation that aligns the model's representation similarity matrix with that of the affective dimension space (Arousal/Valence) using arctanh-reparameterized centered kernel alignment, providing future-aware supervision without requiring future class labels. The total loss combines binary cross-entropy on mixed ground truth (soft old + hard new labels), model-to-model KD, affective-space KD, and graph reconstruction.

## Results

AESL achieves 49.0 mAP (Avg) and 51.8 miF1 (Last) on Audio28 under the B0-I7 protocol, reaching ~95% of the supervised upper bound (51.4 mAP). On Brain27, AESL delivers a 9.6% relative improvement in mAP and 9.7% in maF1 over the second-place method (AGCN) averaged across four incremental protocols. The method consistently ranks first across all three datasets (Brain27, Video27, Audio28) and all four splitting protocols, with the largest margins observed on the Audio28 dataset where it outperforms the runner-up by 1.7 mAP points.

## Baselines & Comparisons

AESL outperforms all eight baselines across every dataset and protocol. The strongest competitor is AGCN (Du et al., 2022), which ranks second in most settings; AESL surpasses it by 1.7 mAP on Audio28 B0-I7 (49.0 vs. 47.3) and by 2.0 mAP on Brain27 B0-I9 (44.2 vs. 42.2). KRT-R (Dong et al., 2023) is competitive on mAP but collapses on maF1/miF1 (e.g., 8.2 maF1 vs. AESL's 38.4 on Audio28), revealing that its knowledge-restore mechanism does not adequately preserve multi-label structure. Rehearsal-based MLCIL methods (PRS, OCDM) and SLCIL replay methods (ER, RS) all suffer severe degradation on maF1 and miF1 (typically below 15), confirming that storing only current-task labels aggravates the partial-label problem. LwF is the best SLCIL method and achieves reasonable maF1 on Audio28 (37.9) but still trails AESL by 0.5 mAP and 0.5 miF1. The Friedman test confirms that AESL's superiority is statistically significant at the 0.05 level for all three metrics (F_F = 70.7 for mAP, 64.0 for miF1, 37.0 for maF1).

## Relation to Prior Work

This paper extends the augmented graph convolutional network framework of AGCN (Du et al., 2022) by incorporating graph-based label disambiguation (borrowed from Chen et al., 2020) to handle the past-missing partial label problem in multi-label class incremental learning. It departs from prior class incremental emotion decoding work (CLIFER, GCN-based few-shot approaches) by addressing fine-grained multi-label settings with up to 28 categories rather than a handful of coarse-grained ones. The key conceptual departure is using the affective dimension space (Arousal, Valence, etc.) as a frozen 'teacher' for relation-based knowledge distillation to address the future-missing partial label problem, a mechanism not present in prior MLCIL or emotion CIL methods.

## Why It Matters / Open Questions

This is the first systematic treatment of multi-label fine-grained class incremental emotion decoding, filling a gap between MLCIL (which ignores emotion-specific structure) and incremental emotion recognition (which is single-label and coarse-grained). The finding that rehearsal-based methods actively harm MLCIL performance by worsening the partial label problem is a useful caution for practitioners. Open questions include whether the approach generalizes to domain incremental learning (new subjects), whether the alphabetical task ordering is optimal, and whether the affective dimension distillation transfers to other incremental learning domains beyond emotion.

## Problem

Existing LLM misbehavior detection methods each target a single type of misbehavior (lies, jailbreaks, toxicity, or backdoors) and typically analyze the model's final output, making them inefficient for long responses and vulnerable to adaptive adversarial attacks. There is no unified, proactive mechanism that can detect multiple forms of misbehavior by examining the model's internal computation before a response is fully generated.
![Teaser figure](../imgs/ICML20253019/cropped_page1_idx0.webp)

## Input / Output

The method takes a text prompt and the LLM's internal signals: attention scores from a small set of selected heads in the first, middle, and last layers, and first-token output logits. Token-level causal effects are reduced to a fixed 5-dimensional statistical summary (mean, standard deviation, range, skewness, kurtosis) to handle variable prompt lengths, while layer-level causal effects form a fixed-length vector (one value per layer). The output is a binary misbehavior classification and a two-part causal map (heatmap) visualizing per-token and per-layer causal contributions, with detection possible as early as the first generated token.

## Method

LLMSCAN applies Causal Mediation Analysis (CMA) to approximate the causal effect of each input token and each transformer layer on the model's output. For tokens, each input token is individually replaced with an intervention token and the Euclidean distance between the resulting attention scores (from selected heads) and the original attention scores is computed; for layers, each layer is bypassed via a shortcut and the difference in first-token logits is measured. These values form a causal map that captures how differently the model's 'brain' processes normal versus misbehavior-inducing prompts. A lightweight MLP detector is then trained in a supervised binary classification setting on causal maps from contrasting prompt sets (e.g., truthful vs. lie-instructed), combining the 5-dimensional token-level summary with the per-layer causal effect vector. The key insight is that misbehavior produces systematically different causal distributions—e.g., lies spread causal influence across more layers uniformly, while backdoor attacks concentrate it in few layers—enabling a single framework to detect four distinct misbehavior types with average AUC above 0.98.

## Results

LLMSCAN achieves average AUCs above 0.98 across all four misbehavior detection tasks (lie, jailbreak, toxicity, and backdoor detection) on 13 datasets and 4 LLMs (Llama-2-7B, Llama-2-13B, Llama-3.1-8B, Mistral-7B). For lie detection, 10 out of 20 model-dataset combinations achieve a perfect AUC of 1.00, with average accuracy of 0.94 on Llama-2-7B and Mistral. Jailbreak and toxicity detection reach near-perfect performance with average AUC > 0.99, while backdoor detection achieves an average AUC of 0.97 with a 50% average accuracy improvement over the ONION baseline.

## Baselines & Comparisons

LLMSCAN consistently outperforms all four baselines across every task and model. For lie detection, LLMSCAN achieves an average accuracy of 0.94 on Llama-2-7B and Mistral, compared to 0.78 for Pacchiardi et al.'s black-box lie detector (Baseline 1) and 0.92 for TTPD (Baseline 2); the gap is most pronounced on Llama-3.1 where LLMSCAN reaches 0.92–0.98 accuracy versus 0.77–0.87 for the baselines. For jailbreak detection, LLMSCAN achieves near-perfect accuracy (0.95–1.00) across all models, while RepE fluctuates notably (e.g., 0.70 on Llama-3.1 with AutoDAN). For toxicity detection, LLMSCAN maintains a minimum accuracy of 0.94 (Llama-3.1) versus RepE's 0.83 on the same model. For backdoor detection, LLMSCAN delivers an average accuracy improvement of ~50% over ONION (e.g., 0.96 vs. 0.44 on Llama-3.1/Badnet; 0.97 vs. 0.27 on Llama-3.1/Sleeper), as ONION's trigger-removal strategy inadvertently strips critical instructions that would otherwise cause the model to refuse harmful prompts.

## Relation to Prior Work

LLMSCAN builds on the causal attribution literature (Chattopadhyay et al., 2019; Sun et al., 2022) that treats neural networks as Structured Causal Models, and specifically adopts Causal Mediation Analysis (Meng et al., 2022) as a tractable approximation for computing intervention-based causal effects. It departs from prior LLM misbehavior detection work, which typically addresses one misbehavior type in isolation (lie detection via follow-up questions, jailbreak detection via perplexity or representation engineering, backdoor detection via trigger removal), by proposing a single unified causal-scanning pipeline that operates on internal model states rather than outputs. The method also connects to mechanistic interpretability work (e.g., RepE, circuit analysis) but reframes the question from 'what does the model represent?' to 'which tokens and layers causally drive the output?', enabling a lightweight detection signal.

## Why It Matters / Open Questions

The practical value lies in providing a single, lightweight (MLP-based) detector that can flag four distinct misbehavior types before a response is fully generated, reducing the need for task-specific monitoring stacks in production LLM deployments. Key limitations include the requirement for white-box access to attention scores and layer outputs, a moderate per-input overhead (~3.5–7.7 s), and evaluation on only four open-source models of 7–13B parameters. Open questions include whether causal maps transfer across model families or scales, how the method behaves under adaptive white-box adversaries (acknowledged but not empirically tested), and whether the selective attention-head sampling generalizes to architectures with different layer/head counts.

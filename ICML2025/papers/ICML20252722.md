## Problem

Existing LLM context-utilization benchmarks (e.g., needle-in-a-haystack, passkey) test only basic search/retrieval, leaving the broader spectrum of memory-usage capabilities—editing, matching, state tracking, structural awareness—unmeasured. Static data benchmarks are costly, prone to overfitting, and cannot pinpoint which specific capability a model lacks when it fails, limiting their utility for targeted model improvement.

## Input / Output

Each test case consists of a structured text context (word lists, key-value pairs, labeled role blocks, or sequential operation instructions) fixed at 4k tokens for most tasks (~1.5k for stateful processing) paired with a task instruction prompt. The model produces a free-text answer that is scored via exact match (binary/counting tasks), ROUGE-L (sequence overlap tasks), or Jaccard similarity (set-based tasks), yielding a per-task accuracy profile across 8 capability categories totaling 1110 samples. Context words are sampled from an English dictionary, and hyperparameters such as query depth, sequence length, number of groups, and operation steps are programmatically tunable to control difficulty.

## Method

Minerva is a programmable benchmark framework where each test is a parametric script that generates randomized test cases with configurable hyperparameters, enabling fresh, non-overfit evaluations and easy composition of tests. The framework defines six atomic test categories (Search, Recall and Edit, Match and Compare, Spot the Differences, Compute on Sets and Lists, Stateful Processing) that isolate individual memory capabilities, plus two composite categories (Processing Data Blocks and Composite-State Tracking/Theory of Mind) that combine multiple atomic skills to simulate real-world multi-compartment scenarios. The design draws an analogy to human cognitive testing: atomic tests isolate single abilities while composite tests assess integrated performance, with the flat context structure forcing models to disentangle labeled compartments and track temporal state changes. The framework was used to evaluate nine models (GPT-4-turbo, GPT-4o, GPT-4o-mini, Cohere-Command-R-Plus, Mistral-7B, Phi-3-small, Phi-3-medium, LLaMA-3.1-8B, Gemma-2-9B) at temperature 0, revealing that strong search performance does not transfer to other context-processing abilities and that composite tasks cause substantial performance drops even for the strongest models.

## Results

Across 1110 programmatically generated test samples at 4k context length, GPT-4o achieves the highest composite-test scores (0.37 on Processing Data Blocks, 0.38 on Theory of Mind), while LLaMA-3.1-8b drops to 0.15 and 0.03 respectively. On Stateful Processing (quantity state, 200 steps), GPT-4o reaches 1.00 exact match whereas all open-source models and Cohere score 0.00. On basic string search (word), most models achieve 0.94–1.00, but performance on subsequence search drops to 0.55–0.82, and batch search reveals Mistral-7b falling to 0.47 (vs. 0.92 on key-value search).

## Baselines & Comparisons

This is a benchmark paper, so the 'comparisons' are across nine evaluated models rather than against prior methods. GPT-4o and GPT-4-turbo dominate on nearly every atomic and composite task, but even they score below 0.40 on the composite tests, confirming that no current model reliably handles multi-capability memory operations. Among open-source models, LLaMA-3.1-8B is the weakest on composite tasks (0.15 / 0.03) despite strong search scores (1.00 on word and key-value search), while Gemma-2-9B and Phi-3-small show intermediate performance. A striking finding is that Mistral-7B scores 0.47 on Batch Search versus 0.92 on Key-Value Search, and 0.04 on the Iterate task, revealing that multi-access and partition-recognition are far harder than single-item retrieval. The Stateful Processing category shows the sharpest divide: GPT-4o achieves 1.00 on quantity tracking (200 steps) while every other model scores 0.00, and on set-state tracking (100 steps) the gap narrows to 0.65 (GPT-4o) versus 0.08–0.24 for the rest.

## Relation to Prior Work

This paper extends the line of programmatically generated context-utilization tests (NIAH, passkey, key-value retrieval, RULER, Needlebench) by broadening the scope from search-centric tasks to a comprehensive taxonomy of atomic memory capabilities—recall/edit, match/compare, spot-the-differences, set/list computation, and stateful processing—plus composite tests (data-block processing, multi-agent theory-of-mind tracking). It draws a deliberate analogy to human cognitive testing, where atomic subtests isolate specific functions, and repurposes the parametric test-generation paradigm that was previously applied almost exclusively to retrieval. Unlike static data benchmarks (LongBench, L-Eval, InftyBench) that measure end-to-end performance, Minerva generates fresh randomized cases per run and allows hyperparameter tuning of difficulty, making it both scalable and interpretable.

## Why It Matters / Open Questions

The benchmark reveals that even at 4k tokens—typically considered a short context—models exhibit large, capability-specific gaps, and that strong search performance does not predict competence in stateful tracking, cross-reference, or composite reasoning. The near-zero stateful-processing scores for most open-source models and the substantial drops on composite tests (even for GPT-4o) suggest that current architectures face fundamental limitations in maintaining and updating internal state over flat context, a problem that scaling alone may not resolve. Open questions include whether architectural changes (e.g., explicit state registers, hierarchical attention) are needed, how these capabilities interact with reasoning, and whether the programmable framework can be extended to multimodal or agentic settings.

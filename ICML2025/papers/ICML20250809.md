## Problem

Standard parameter-modifying model editing methods (ROME, MEMIT, MEND, AlphaEdit) suffer severe performance degradation when applied sequentially in lifelong editing, yet the community has historically developed specialized lifelong methods in isolation from standard editing advances. This paper asks whether it is possible to restore the strong performance of standard methods in a lifelong context, thereby bridging the two paradigms and allowing lifelong editing to automatically benefit from ongoing improvements in standard editors.

## Input / Output

At each time step t, SimIE consumes the parameter update ΔW_t produced by a standard editing algorithm A on the current model state, along with the key vector k_t extracted from the target MLP layer, and a scalar hyperparameter λ. It maintains a running matrix P_t ∈ R^{d₁×d₁} (initialized to λI) and outputs an adjusted weight update ΔW_t k_t k_t^T P_t^{-1} that is added to the previous weight matrix. The final output is the post-edit model f_{θ_T} after T sequential edits, with the entire procedure requiring only one additional line of code per time step relative to the naive sequential application of A.

## Method

SimIE defines an 'ideal editor' as the minimum-norm solution S⁰ = BK† to the linear system SK = B, where K and B are concatenated key and value-change matrices from all T edit examples, computed via the Moore-Penrose inverse. Under two mild assumptions (over-parameterization: T ≤ d₁ with K full rank; key-value invariance: the key-value pair for each edit is independent of model state), SimIE approximates S⁰ recursively by truncating the limiting expression A† = lim_{α→0} Aᵀ(AAᵀ + αI)⁻¹ with a fixed λ, yielding the update rule P_t = P_{t-1} + k_t k_t^T and W_t = W_{t-1} + ΔW_t k_t k_t^T P_t^{-1}. The key insight is that this recurrence only rescales the standard algorithm's per-step update by a rank-one correction, so SimIE is a drop-in wrapper around any parameter-modifying editor. Theoretical analysis shows that when assumptions are relaxed, the solution remains near-optimal in a least-squares sense (without over-parameterization) or stable against key-value perturbations (without invariance), with a quantified optimality-stability trade-off governed by λ when both fail.

## Results

On 1000 sequential edits, standard methods collapse to near-zero Avg (e.g., ROME: 0.03, MEMIT: 0.03, MEND: 0.00 on Llama-2 ZsRE), while SimIE restores them to competitive levels: AlphaEdit⁻+SimIE reaches 0.80 Avg on Llama-2 ZsRE, ROME+SimIE reaches 0.74 on Mistral ZsRE, and MEND+SimIE reaches 0.79 on Llama-2 ZsRE. On the Counterfact dataset, ROME+SimIE achieves 0.66 Avg on Mistral, surpassing the dedicated lifelong method AlphaEdit (0.65). On recent LLMs (Llama-3 8B, Qwen2.5 7B), AlphaEdit⁻+SimIE surpasses the SOTA AlphaEdit by an average of 4.8% on Qwen2.5.

## Baselines & Comparisons

SimIE dramatically rescues all standard editing methods from near-total failure in lifelong settings: MEND goes from 0.00 to 0.79 Avg (Llama-2 ZsRE), ROME from 0.03 to 0.63–0.74, MEMIT from 0.03 to 0.68–0.69, and AlphaEdit⁻ from 0.03 to 0.80. Against dedicated lifelong baselines, AlphaEdit⁻+SimIE (0.80) outperforms AlphaEdit (0.76), GRACE (0.67), and PRUNE (0.59) on Llama-2 ZsRE, while WISE (0.86) remains the strongest single method on that setting. On Mistral ZsRE, ROME+SimIE (0.74) and AlphaEdit⁻+SimIE (0.75) are competitive with AlphaEdit (0.76) and approach WISE (0.80). On Counterfact, ROME+SimIE (0.66) edges out AlphaEdit (0.65) on Mistral, and MEND+SimIE (0.52) substantially exceeds PRUNE (0.58 on Llama-2, 0.61 on Mistral) in Rel (0.96 vs. 0.86/0.94). Overall, SimIE-boosted standard methods match or exceed dedicated lifelong editing methods across most model–dataset combinations, requiring only one line of code modification.

## Relation to Prior Work

This paper builds on the key-value memory formulation introduced by ROME and MEMIT, which identify MLP linear layers as factual knowledge storage locations and model editing as adjusting (k, v) pairs. It departs from the prevailing view that standard and lifelong model editing follow separate tracks, instead proposing a general bridge: by formulating the ideal editor as a minimum-norm solution via the Moore-Penrose inverse and truncating its limiting expression, SimIE converts any standard parameter-modifying algorithm into a lifelong-capable one through a single recursive adjustment. The theoretical analysis draws on perturbation theory and least-squares conditioning, connecting the framework to classical numerical linear algebra rather than to prior lifelong editing methods like GRACE, WISE, or PRUNE, which are used only as empirical baselines.

## Why It Matters / Open Questions

The practical impact is significant: SimIE requires only one line of code and a maintained matrix P_t, meaning any future advance in standard editing (ROME, MEMIT, AlphaEdit, etc.) automatically extends to lifelong scenarios without re-derivation. However, open questions remain: the hyperparameter λ requires per-setting tuning and introduces an optimality-stability trade-off when both over-parameterization and key-value invariance assumptions fail; the ideal editor can produce large-norm shifts for ill-conditioned key matrices, potentially harming general capabilities; and the notably weak results on Llama-3 (Avg 0.05–0.06) suggest the method's applicability is not yet universal across architectures. Future work on adaptive λ selection and locality-constrained ideal editors would address these gaps.

## Problem

Scaling synthetic data for image classification suffers from diminishing returns: naively generating more samples yields power-law stagnation in performance. Prior approaches either generate a large static dataset upfront or generate-then-prune, both of which waste compute on redundant or too-easy examples. The paper asks whether one can directly generate only the most informative, challenging examples to improve the scaling laws of synthetic data training.
![Teaser figure](../imgs/ICML20250069/cropped_page2_idx0.webp)

## Input / Output

The method requires no real training data—only class labels, a pre-trained text-to-image diffusion model (LDM-1.5) for conditional image generation, and a small real validation set (5k for ImageNet-100, 50k for ImageNet-1k) used solely to monitor training progress and trigger data generation. The output is a ViT-B image classifier trained entirely on dynamically generated synthetic images, evaluated on held-out real ImageNet training sets and OOD benchmarks (ImageNet-V2, Sketch, R, A).

## Method

Deliberate Practice (DP) operates a dynamic loop between a diffusion model and a downstream ViT-B classifier: training proceeds on an initial synthetic dataset until validation accuracy plateaus (patience mechanism), at which point new examples are generated using entropy-guided sampling that biases the diffusion model's reverse SDE toward high-entropy (challenging) samples under the current classifier. The key technical mechanism modifies the DDIM score function with the gradient of the classifier's prediction entropy, computed via the x_0 approximation mid-generation, effectively sampling directly from an entropy-pruned distribution without the generate-then-prune overhead. A theoretical analysis using random matrix theory (RMT) derives a closed-form expression for test error as a function of the selection strategy, showing that prioritizing hard examples near the decision boundary improves scaling laws. The pruning direction is adaptively updated as training progresses, since the notion of 'hard' examples evolves with the learned decision boundary.

## Results

On ImageNet-100, DP achieves 74.3% top-1 validation accuracy with only 1.9M synthetic samples and 100k iterations, outperforming the best static baseline (73.3% with 6.5M samples and 635k iterations) while using 3.4× fewer samples and 6× fewer iterations. On ImageNet-1k, DP reaches 55.1% validation accuracy with 9.1M samples and 200k iterations, surpassing the best static baseline (54% with 64M samples and 315k iterations) using 8× fewer samples and 30% fewer iterations. Notably, DP-trained models outperform real-data-trained models on OOD benchmarks, achieving 76.6% on ImageNet-R (vs. 60.8% real) and 52.0% on ImageNet-Sketch (vs. 37.1% real) on ImageNet-100, and 57.2% on ImageNet-R (vs. 44.6% real) on ImageNet-1k.

## Baselines & Comparisons

On ImageNet-100, DP (74.3% val) outperforms the strongest static baseline from Sarıyıldız et al. (73.3% val with 6.5M samples, 635k iterations) by 1.0% while using only 1.9M samples and 100k iterations — a 3.4× reduction in data and 6× reduction in compute. On ImageNet-1k, DP (55.1% val with 9.1M samples, 200k iterations) beats Fan et al.'s best static result (54% with 64M samples, 315k iterations) by 1.1% while generating 8× fewer samples and running 30% fewer iterations. A striking finding is that DP-trained models surpass real-data-trained models on OOD benchmarks: on ImageNet-100, DP achieves 76.6% on ImageNet-R vs. 60.8% for real data (+15.8%), and 52.0% on ImageNet-Sketch vs. 37.1% (+14.9%); on ImageNet-1k, DP reaches 57.2% on ImageNet-R vs. 44.6% for real data (+12.6%). However, DP still lags behind real data on in-distribution validation accuracy (74.3% vs. 88.5% on IN-100; 55.1% vs. 82.6% on IN-1k) and on ImageNet-A (25.9% vs. 33.5% on IN-100; 13.4% vs. 29.4% on IN-1k), indicating that the synthetic-to-real gap persists for natural adversarial examples.

## Relation to Prior Work

This paper extends the entropy-guided diffusion sampling mechanism from Hemmat et al. (2023), which required real data to pre-train the learner, into a fully synthetic-data setting where the learner's own prediction entropy dynamically guides generation. It departs from the generate-then-prune paradigm established by Sorscher et al. (2022) and Fan et al. (2024) by using Girsanov's theorem to show that entropy-weighted score modification approximates direct sampling from the pruned distribution, eliminating the need to generate and discard large pools of uninformative samples. The theoretical analysis draws on random matrix theory (Couillet & Liao, 2022; Firdoussi et al., 2024) to characterize how selection strategies affect high-dimensional test error, providing a formal bridge between the empirical pruning literature and the proposed dynamic generation loop.

## Why It Matters / Open Questions

The framework offers a practical path toward reducing the compute and data costs of synthetic-data training by 3–8× while improving accuracy, which is significant for settings where real data is unavailable or expensive. The finding that example hardness is non-stationary—misclassified examples show lower error before being added than at the moment of inclusion—challenges the assumption underlying static pruning and motivates adaptive data selection. Open questions include whether the approach generalizes beyond ImageNet-style classification to other modalities or tasks, how it interacts with model collapse under iterative synthetic training (Dohmatob et al., 2024), and whether the RMT-based theory extends to nonlinear classifiers or non-isotropic data distributions.

## Problem

Existing face swap security measures are either post-hoc forensic detection (reactive, with inherent latency) or image-level adversarial perturbations (requiring costly per-image preprocessing that cannot scale). There is no model-level proactive mechanism that simultaneously prevents unauthorized face swaps of protected individuals (POI) and embeds traceable provenance watermarks into all other outputs, leaving a critical governance gap for responsible deployment of face swap models.
![Teaser figure](../imgs/ICML20250464/cropped_page0_idx0.webp)

## Input / Output

The method takes a source face image and a target face image (standard RGB) as input to a GAN-based face swap model. If the target identity is a POI, the output is a fully black redacted image; otherwise, the output is a visually normal swapped face image with an invisible binary watermark (length n_w bits) embedded in its pixel values. The watermark is extracted post-hoc by a separate trained decoder network using a bit-matching threshold test, enabling both AI-generated content detection and attribution to a specific model instance.

## Method

Secure Swap inserts a lightweight ID Passport layer into the middle-to-output region of any existing GAN-based face swap model. The layer contains n parallel ID convolution blocks whose kernels are generated from upstream feature maps via a kernel generator, weighted by per-block coefficients from a coefficient generator, and programmed with watermark feature vectors from a detachable watermark encoder. Training jointly optimizes four losses: a face swap loss (identity + reconstruction + cycle consistency), a LIPIPS-based knowledge distillation loss against the original model, an L2 POI redaction loss driving POI outputs to black, and a BCE watermark extraction loss. After training, the watermark encoder is detached and can be re-attached to any model instance to program a unique watermark without retraining, enabling scalable per-customer provenance tracking.

## Results

Secure Swap achieves a 100% POI redaction success rate (SR_mask = 1.000) across all four face swap models (BlendFace, SimSwap, FaceShifter, MobileFSGAN) and all tested POI counts (128–4096). Watermark extraction accuracy (AccWM) exceeds 99% for all models except MobileFSGAN (~97–98%), with TPR consistently above 99.9%. In terms of watermark imperceptibility, the method achieves PSNR 34.321 and SSIM 0.981 on BlendFace, outperforming all four compared watermarking baselines. Fidelity is preserved with PSNR > 32, SSIM > 0.95, and LPIPS < 0.05 between the original and Secure Swap outputs.

## Baselines & Comparisons

Secure Swap outperforms all four watermarking baselines on both PSNR and SSIM. Against Attributing (Nie et al., ICML 2023), it gains +6.17 dB PSNR and +0.078 SSIM; against Stable Signature (Fernandez et al., ICCV 2023), +5.07 dB and +0.070 SSIM; against PluggableWM (Bao et al., TDSC 2024), +3.04 dB and +0.042 SSIM. The closest competitor is WFWM (Fei et al., TIFS 2024), where Secure Swap leads by a narrower margin of +0.16 dB PSNR and +0.032 SSIM, indicating that the ID Passport layer's in-model watermark embedding achieves near-lossless imperceptibility comparable to the best dedicated watermarking approach while simultaneously providing POI redaction functionality that none of the baselines offer.

## Relation to Prior Work

This paper extends four existing GAN-based face swap models (SimSwap, FaceShifter, BlendFace, MobileFSGAN) by inserting a novel ID Passport layer that unifies two previously separate concerns—POI identity redaction and invisible watermark embedding—into a single architectural modification. It departs from prior POI protection work (which relies on image-level adversarial perturbations requiring costly preprocessing) by making protection model-internal, and from prior generative watermarking methods (which embed watermarks in training data or require external watermark input at inference) by encoding watermarks directly into model parameters via a detachable encoder. Knowledge distillation via LIPIPS is used to preserve the original model's face swap fidelity, positioning the method as a lightweight fine-tuning step rather than a from-scratch redesign.

## Why It Matters / Open Questions

The paper addresses a concrete governance gap: model developers currently lack a practical mechanism to simultaneously prevent POI abuse and enable provenance tracking in deployed face swap services. The detachable watermark encoder is a notable practical contribution, allowing a single trained model to be instantiated with unique watermarks for different customers without retraining. However, the method is limited to GAN-based architectures and the authors explicitly note that adaptation to diffusion-based models remains open. Model-level attack robustness is a concern: under mixed white-box attacks, watermark accuracy degrades to ~75% while image quality collapses below PSNR 20, suggesting that determined attackers with full model access could potentially compromise the security guarantees.

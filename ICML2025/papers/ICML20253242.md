## Problem

Existing model stealing methods that leverage pre-trained diffusion models for image synthesis depend on manually crafted prompts or class names, which limits automation, scalability, and realism for attackers with limited domain expertise. This paper introduces a more realistic threat model in which the attacker has no prompt design skills and no access to class names, and proposes Stealix, the first prompt-agnostic model stealing approach that automatically discovers effective prompts through iterative evolution guided by the victim model's feedback.
![Teaser figure](../imgs/ICML20253242/cropped_page0_idx0.webp)

## Input / Output

The method requires only one real seed image per class (any resolution matching the victim's input size, e.g., 64×64 for EuroSAT, 256×256 for PASCAL) and black-box access to the victim model that returns only top-1 hard labels under a fixed query budget B per class. It produces K×B synthetic images (generated by Stable Diffusion-v2) along with their victim-assigned labels, which are used to train a ResNet-18 surrogate model. The optimized prompts are discrete hard-token strings (length 16 by default) that are not necessarily human-interpretable but are aligned with the victim's learned feature space.

## Method

Stealix iteratively refines prompts through three coupled steps: (1) Prompt Refinement optimizes a hard prompt via PEZ-style gradient-based discrete optimization using a contrastive similarity loss over an image triplet (seed, positive, negative), where the loss encourages the prompt embedding to match features of victim-correctly-classified images and repel features of misclassified ones; (2) Prompt Consistency (PC) evaluates each optimized prompt by synthesizing M images and measuring the fraction the victim classifies as the target class, serving as a proxy fitness metric correlated with L2 feature distance to the victim data; (3) Prompt Reproduction evolves the population of image triplets via a genetic algorithm (tournament selection, crossover, mutation) to generate diverse prompts capturing a broad range of class-specific features. The key distinction from prior prompt optimization work (PEZ, DA-Fusion) is the explicit incorporation of the victim model's hard-label predictions into both the contrastive loss and the evolutionary fitness, enabling victim-aware prompt discovery without any human prompt engineering.

## Results

With a query budget of 500 per class, Stealix achieves attacker model accuracy of 65.9% on EuroSAT, 40.0% on PASCAL VOC, 49.6% on CIFAR-10, and 48.4% on DomainNet, consistently outperforming all baselines. On CIFAR-10, Stealix improves over the second-best method (Real Guidance, 27.4%) by 22.2 percentage points. Notably, on PASCAL VOC, Stealix (40.0%) surpasses even the knowledge distillation upper bound (34.6%), which has access to the victim's training data, due to the limited victim data size (~73 images/class). Stealix requires only one seed image per class and no class names, while achieving prompt consistency (PC) up to ~100% on CIFAR-10.

## Baselines & Comparisons

Stealix outperforms all six model-stealing baselines across all four datasets. Against DA-Fusion (Trabucco et al., 2024), the closest competitor, Stealix gains 6.9 pp on EuroSAT (65.9% vs 59.0%), 23.6 pp on PASCAL (40.0% vs 16.4%), 22.9 pp on CIFAR-10 (49.6% vs 26.7%), and 20.0 pp on DomainNet (48.4% vs 28.4%). Against Real Guidance (He et al., 2023), which uses class names, Stealix improves by 14.7 pp on EuroSAT and 22.2 pp on CIFAR-10. Against ASPKD (Hondru & Ionescu, 2023), which also leverages class names, Stealix leads by 26.7 pp on CIFAR-10 and 21.1 pp on PASCAL. Against Knockoff Nets (Orekondy et al., 2019) and DFME (Truong et al., 2021), Stealix achieves substantially higher accuracy (e.g., 65.9% vs 40.1% and 11.1% on EuroSAT). Against the KD upper bound (Hinton et al., 2015), which queries the victim with its own training data, Stealix surprisingly surpasses it on PASCAL (40.0% vs 34.6%) due to the small victim dataset (~73 images/class), though KD remains stronger on the other three datasets. Against InstructBLIP (Dai et al., 2023) as a simulated human attacker on EuroSAT, Stealix achieves 65.9% accuracy and 73.7% PC versus 55.2% and 41.0% respectively, demonstrating that automated prompt evolution captures victim-relevant features that human-readable prompts miss.

## Relation to Prior Work

This paper extends the line of model stealing via pre-trained diffusion models (ASPKD, Real Guidance, DA-Fusion) by removing the reliance on human-crafted prompts or class names. Methodologically, it builds on PEZ's gradient-based discrete prompt optimization and DA-Fusion's use of diffusion models for image synthesis, but departs from both by incorporating victim model feedback (hard labels) into a contrastive triplet loss and wrapping the whole process in a genetic algorithm for prompt evolution. The key conceptual departure is treating prompt design as an optimization problem guided by the victim's predictions rather than a human expertise requirement, which prior prompt-based stealing methods all assumed.

## Why It Matters / Open Questions

The paper demonstrates that open-source generative models like Stable Diffusion significantly lower the barrier to model stealing, making the threat more accessible to attackers without domain expertise. A notable finding is that Stealix can surpass knowledge distillation (which has full access to victim training data) on PASCAL, suggesting that query-rich synthetic data can outperform limited real data. Limitations include the need for one seed image per class, reduced effectiveness when the diffusion model lacks domain knowledge (medical datasets), and the fact that hard-label-only defenses merely slow rather than prevent the attack. Open questions include whether stronger adversarial defenses can disrupt the prompt evolution loop and whether the approach transfers to non-image modalities.

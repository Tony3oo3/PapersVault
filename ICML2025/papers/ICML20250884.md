## Problem

Offline multi-task reinforcement learning must share knowledge across tasks using only pre-collected task-mixed data, yet existing approaches operate at the action-imitation level and fail to extract transferable skill fragments from sub-optimal trajectories. The paper identifies that, unlike humans who distill reusable high-level skills from diverse experiences, current offline MTRL methods lack an explicit mechanism for goal-oriented skill abstraction that can generalize across tasks with varying reward functions and dynamics.

## Input / Output

The skill model consumes H-horizon state sub-trajectories (state vectors from the Sawyer arm in MuJoCo) and produces continuous actions, while the high-level policy consumes return-to-go targets, state observations, and skill prompts to output discrete skill indices at H-step intervals. Notably, the skill definition deliberately excludes reward and return-to-go signals so that skills remain task-agnostic; the goal is encoded purely as the state difference s_{t+H} − s_t, making the same skill reusable even when it yields low reward in one task but is essential in another.

## Method

GO-Skill extracts a discrete skill library via a three-component skill model: a goal encoder maps the H-horizon state difference to a latent embedding, a vector quantization module discretizes these embeddings into M=16 skill codes, and a Transformer-based skill decoder reconstructs continuous actions conditioned on the skill embedding, reached-goal history, and past state-action pairs. A skill enhancement phase with uniform resampling across skill classes mitigates the imbalance between broadly applicable and task-specific skills. At deployment, a Prompt-DT-based high-level policy selects skill indices at H-step intervals using focal loss to counter class imbalance, while the frozen skill decoder executes the selected skill over the H-horizon. The key design choice is representing skills by goal (state transfer) rather than action sequences, ensuring that different action trajectories achieving the same state change map to the same skill, and excluding reward signals so skills transfer across tasks with different reward functions.

## Results

On the MetaWorld benchmark, GO-Skill achieves an average episode return of 3159.1±71.0 (MT50, Near-Optimal) and 2123.8±78.1 (MT50, Sub-Optimal) over 5 random seeds, outperforming all six baselines across all four experimental setups (MT30/MT50 × Near-Optimal/Sub-Optimal). A key finding is that while baselines degrade from MT30 to MT50, GO-Skill maintains or even improves performance with more tasks, indicating effective leverage of richer shared knowledge. The multi-headed variant (MH-GO-Skill) further improves results by mitigating gradient conflicts between skills.

## Baselines & Comparisons

GO-Skill outperforms all six baselines (MTDT, MH-MTDT, PromptDT, MH-PromptDT, MTDIFF-P, and HarmoDT) across all four MetaWorld setups. The advantage is most pronounced in the MT50 setting, where baselines typically show degraded performance relative to MT30, while GO-Skill maintains comparable or improved returns—particularly in the Near-Optimal case where performance actually increases with more tasks. In the Sub-Optimal setting, GO-Skill's ability to extract transferable skill sub-trajectories from sub-optimal data provides a clear edge over baselines that rely on action-level imitation. The multi-headed variant MH-GO-Skill further narrows the gap to the best baselines by reducing gradient conflicts in the skill model, though the skill-based policy still fully shares parameters.

## Relation to Prior Work

GO-Skill builds on the Prompt-DT (Xu et al., 2022) architecture for the high-level policy and on vector quantization (Van Den Oord et al., 2017) for discretizing skill representations, but departs from prior offline MTRL methods (MTDT, PromptDT, MTDIFF-P, HarmoDT) that share knowledge implicitly through network parameters. The key conceptual departure is introducing an explicit, goal-oriented skill abstraction layer: skills are defined by state-difference embeddings rather than action sequences, and a discrete skill codebook serves as an intermediate action space between the high-level policy and the environment. This hierarchical, skill-based formulation is borrowed from online hierarchical RL and imitation learning literature but is adapted here to the offline, conditional-sequence-modeling setting with a novel skill enhancement phase to handle class imbalance.

## Why It Matters / Open Questions

The paper demonstrates that explicit skill abstraction can make offline MTRL more robust to sub-optimal data and more scalable with task count—GO-Skill improves with more tasks while baselines degrade, suggesting that skill libraries act as a form of structured knowledge compression. However, the approach relies on a fixed skill horizon and a predefined codebook size, and the evaluation is limited to the MetaWorld benchmark (state-vector, single-robot). Open questions include whether the goal-oriented skill representation generalizes to vision-based or continuous-horizon settings, whether the skill set can grow dynamically, and whether the hierarchical decomposition transfers to domains with more heterogeneous task structures.

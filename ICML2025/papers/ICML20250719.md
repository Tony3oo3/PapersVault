## Problem

The LLM-enhancer-plus-GNN paradigm has achieved strong results in graph representation learning, yet the fundamental properties and internal mechanisms of this framework remain largely unexplored. Specifically, it is unclear which causal relationships the LLM enhancer actually models, how information is transmitted between the LLM and GNN components, and where within the GNN's layers the LLM-provided information is most relevant.
![Teaser figure](../imgs/ICML20250719/cropped_page0_idx0.webp)

## Input / Output

The method takes graph node text features (Wikipedia entries organized into 3 categories and 15 subcategories) and graph topology as input. The LLM enhancer (Llama 2/3 or Qwen2) processes each node's text to produce token-level hidden features, from which a fixed number of feature vectors are selected at evenly spaced positions. The AT module then combines features from q different prompts via attention-weighted averaging to produce a single enhanced node representation, which is fed into the GNN (GCN, GAT, or GraphSAGE) to output node or graph class labels.

## Method

The paper introduces two main contributions. First, an analysis framework based on interchange intervention from causal inference: the authors construct the CCSG dataset with controllable causal relationships, define a high-level causal model h(·) encoding ground-truth cause-effect logic, and systematically swap internal variable values between two graph inputs to identify which GNN hidden layers correspond to which causal variables in h(·). Theoretical results (Theorems 3.2–3.5) prove that minimizing the interchange intervention loss L_II yields variables with identical total causal effects, validating the alignment. Second, an Attention-based Transmission (AT) module that generates q different LLM feature sets via diverse prompts, passes each through a transformer encoder to compute attention scores, normalizes scores across all q×m feature vectors via softmax, and produces a single attention-weighted node feature for the GNN—effectively learning which token positions and prompts carry the most useful information for downstream graph learning.

## Results

The AT module consistently improves node classification accuracy across all three datasets (Cora, Pubmed, Instagram) and all LLM–GNN backbone combinations. On Pubmed, the largest gains are observed, with improvements up to +3.09% (Llama3 + GraphSAGE: 82.23% → 85.32%). On Cora, gains are more modest, ranging from +0.67% to +2.03%, while Instagram shows intermediate improvements of +1.31% to +2.23%. The AT module is effective regardless of the LLM backbone (Llama2, Qwen2, Llama3) or GNN architecture (GCN, GAT, GraphSAGE).

## Baselines & Comparisons

This paper does not compare against external competing methods; instead, the primary comparison is between the standard LLM-enhancer-plus-GNN pipeline (w/o AT) and the same pipeline augmented with the proposed Attention-based Transmission (AT) module (w/ AT). The AT module wins in every single configuration tested (9 LLM×GNN×dataset combinations), with no cases of degradation. The most substantial gains appear on Pubmed, where the AT module adds 1.66–3.09 percentage points, suggesting that the information bottleneck between LLM features and GNN input is most pronounced on this dataset. On Cora, improvements are smaller (0.67–2.03 pp), likely because the dataset's simpler structure already allows the default last-token feature selection to capture sufficient information. GraphSAGE consistently benefits the most from the AT module across all datasets, indicating that its neighborhood-aggregation mechanism is particularly sensitive to the quality of input node features.

## Relation to Prior Work

This paper adapts the interchange intervention framework from causal inference (Geiger et al., 2022a; Wu et al., 2023a; Huang et al., 2023a), previously applied to NLP models, to systematically analyze the LLM-enhancer-plus-GNN paradigm for the first time. It departs from prior causal analysis of GNNs (Gao et al., 2023, 2024; Wu et al., 2022), which focused on GNNs alone, by introducing a synthetic dataset (CCSG) with controllable multi-order causal relationships and semantic node attributes to study the joint LLM+GNN system. The practical AT module extends the standard practice of selecting fixed token positions from LLM outputs (Chen et al., 2023; Liu et al., 2024) by learning attention-based feature selection across multiple prompts.

## Why It Matters / Open Questions

The finding that fixed-parameter LLM enhancers primarily encode node-level and raw-data-level information, and that scaling GNN depth/width does not improve causal relation modeling capacity, challenges the common assumption that larger models in either component yield proportionally better causal understanding. The AT module offers a simple, plug-and-play improvement (1–3% across datasets) that practitioners can adopt without architectural changes. However, the analysis is conducted entirely on a synthetic dataset with manually defined causal structures, limiting confidence that the empirical findings generalize to real-world graphs with complex, uncontrolled causal relationships. Open questions include whether the findings hold with fine-tuned LLMs, on heterogeneous or temporal graphs, and whether the AT module's gains persist at larger scale.

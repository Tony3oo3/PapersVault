## Problem

While randomized value function methods like RLSVI have proven effective for single-agent exploration, it remains theoretically unclear whether injecting randomization can help a society of agents concurrently explore an environment. Moreover, existing concurrent RL analyses focus on model-based algorithms (e.g., PSRL) or tabular representations, leaving a gap for model-free concurrent RL with aggregated states that are computationally scalable to large state-action spaces.

## Input / Output

The algorithm takes an MDP with N agents interacting in parallel, an aggregated state mapping φ that partitions state-action pairs into Γ blocks (reducing complexity from SA to Γ), and tuning parameters β, α, ξ. A key practical constraint is that the recommended variant (Algorithm 3/4) stores only the previous episode's trajectories (O(HN) space) rather than all history (O(KHN)), making it feasible for large N. The output consists of per-agent greedy policies derived from Q-value estimates over aggregated states, with theoretical guarantees of Θ(1/√N) per-agent regret decrease.

## Method

The core mechanism adapts RLSVI to a concurrent setting: N agents each inject independent Gaussian noise into the previous episode's rewards to construct a perturbed MDP, then compute Q-values via backward value iteration on this noisy data. At the end of each episode, agents share information by computing a weighted average of their per-aggregated-state Q-values, enabling coordinated exploration without requiring a shared model. The aggregated state representation replaces per-state-action value estimates with one value per Γ-block, and a regularized loss function with visitation-count-dependent weights (α_n = 1/(1+n)) balances optimism against accumulated evidence. For the infinite-horizon case, the interaction stream is decomposed into pseudo-episodes of geometrically distributed length (parameter 1−η), and the discount factor η appears only in the algorithm's decomposition rather than in the learning target. The key practical innovation is retaining only the last episode's data, which reduces space complexity by a factor of K at the cost of an extra √K in the regret bound.

## Results

The paper establishes worst-case regret bounds for concurrent RLSVI with aggregated states in both finite- and infinite-horizon MDPs. For the space-efficient variant (Algorithm 3, storing only one episode), the finite-horizon regret is Õ(εKHN + KH^{5/2}Γ√N), while the full-history variant (Algorithm 1) achieves Õ(ε√K·HN + H^{5/2}Γ√(KN)). The per-agent regret decreases at the optimal Θ(1/√N) rate, confirmed numerically across 500 sampled MDPs with N ranging from 1 to 50 agents. The space-efficient variant reduces storage by a factor of K compared to prior work at the cost of only a √K increase in the regret bound.

## Baselines & Comparisons

Against Russo (2019), the proposed method improves the worst-case regret by a factor of H^{1/2} (from H³S^{3/2} to H^{5/2}Γ when Γ≈S·A), matching the improvement achieved by Agrawal et al. (2021) but through a fundamentally different algorithmic and proof technique. For the single-agent case (N=1), Algorithm 1 recovers the same H^{5/2}Γ√K scaling as Agrawal et al. (2021), confirming tightness. Compared to Taiga et al. (2022), this work provides a stronger worst-case regret guarantee (vs. Bayes regret only) and is computationally feasible for large N since it does not require storing all historical trajectories. The linear-function-approximation baselines (Desai et al., 2018; Min et al., 2023) operate in a different representation setting and are not directly comparable, though the concurrent RLSVI approach here avoids the need for a known feature matrix. The key practical advantage is that the space-efficient variant (ours-2) reduces memory from O(KHN) to O(HN) at the cost of an extra √K factor in regret, making concurrent learning feasible at scale.

## Relation to Prior Work

This paper sits at the intersection of three research threads: randomized value iteration for exploration (RLSVI, Osband et al. 2019; Russo 2019; Agrawal et al. 2021), aggregated state representations to reduce statistical complexity (Dong et al. 2019b; Van Roy 2006), and concurrent learning where multiple agents share experience in a common environment (Silver et al. 2013; Chen et al. 2022). The key departure from prior concurrent RL work is that previous theoretical guarantees were established for model-based algorithms (PSRL, UCRL), whereas this paper provides the first worst-case regret analysis for a model-free concurrent algorithm with aggregated states. Algorithmically, it departs from Russo (2019) and Agrawal et al. (2021) by storing only the most recent episode rather than all historical trajectories, trading a √K factor in regret for a K-fold reduction in space complexity.

## Why It Matters / Open Questions

The result that per-agent regret decreases at the optimal Θ(1/√N) rate provides theoretical justification for concurrent model-free exploration, which is practically important in settings like multi-robot search, parallel circuit design, and recommendation systems where many agents interact with a shared environment. The space complexity reduction (storing one episode vs. all history) makes the algorithm feasible for large agent populations, addressing a critical practical bottleneck. Open questions include whether the √K regret penalty from limited memory can be recovered with smarter data reuse, whether the analysis extends to general function approximation beyond tabular/aggregated representations, and whether the pseudo-episode framework for infinite-horizon settings can be made adaptive to the environment's mixing time.

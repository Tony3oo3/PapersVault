## Problem

Sparse optimization with mixed constraints (ℓ₀ sparsity plus an additional convex constraint Γ) is common in applications like portfolio optimization and sparse nonnegative matrix factorization, yet existing algorithms either require a closed-form Euclidean projection onto the mixed constraint set (which often does not exist) or provide only local convergence guarantees. No prior work delivers global sub-optimality guarantees in objective value for iterative hard-thresholding (IHT) under such combined sparsity and support-preserving convex constraints.

## Input / Output

The algorithm consumes a risk function R (accessed via full gradient, minibatch stochastic gradient, or function values in the zeroth-order variant), a sparsity level k, a convex support-preserving set Γ (e.g., ℓₚ balls, box constraints, sign-free convex sets), and standard hyperparameters (learning rate, iteration count, batch/direction schedules). The output is a k-sparse vector in Γ with a global guarantee of the form min_t R(w_t) ≤ (1+2ρ)R(w̄)+ε, where the free parameter ρ∈(0,0.5] trades off the tightness of the risk bound against the required sparsity relaxation k=Ω(κ²k̄/ρ²). In the zeroth-order setting, the only residual error is the unavoidable O(μ²) smoothing term, with no non-vanishing system error.

## Method

The core mechanism is a two-step projection operator (2SP): first apply the hard-thresholding operator H_k to retain the top-k components, then project the resulting k-sparse vector onto Γ via the standard Euclidean projection. This 2SP replaces the intractable Euclidean projection onto the non-convex mixed set B₀(k)∩Γ while preserving feasibility at every iterate, thanks to the support-preserving property of Γ. The key theoretical contribution is a novel extension of the classical three-point lemma to this non-convex two-step projection, which relates the four points (w, H_k(w), Π_Γ(H_k(w)), w̄) and enables a clean telescopic-sum convergence proof under restricted strong convexity and restricted smoothness. By taking a convex combination of the 2SP-based descent inequality with the vanilla IHT descent inequality weighted by ρ, the authors derive the sparsity/optimality trade-off: smaller ρ tightens the risk bound but demands a larger k. The framework extends naturally to stochastic optimization (with exponentially growing minibatch sizes) and zeroth-order optimization (with exponentially growing random-direction counts), yielding the first global convergence-in-risk result without system error for a zeroth-order hard-thresholding algorithm.

## Results

The paper provides global convergence guarantees in objective value for iterative hard-thresholding with extra support-preserving convex constraints, under RSC/RSS assumptions. In the deterministic setting (Thm. 3.7), the algorithm achieves min R(w_t) ≤ (1+2ρ)R(w̄) + ε in O(κ_s log(1/ε)) iterations with sparsity relaxation k = Ω(κ_s²k̄/ρ²). In the zeroth-order setting (Thm. 4.8), it obtains the first convergence-in-risk result without system error for a ZO hard-thresholding algorithm, with query complexity #IZO = O(ε_F κ_s³ L_s / ε) that is dimension-independent when s₂ = d. The parameter ρ ∈ (0, 0.5] introduces a novel trade-off: smaller ρ tightens the sub-optimality bound but requires larger sparsity relaxation.

## Baselines & Comparisons

Against Jain et al. (2014) and Zhou et al. (2018), which provide global guarantees only for the unconstrained case (Γ = ℝ^d), this paper extends the same O(κ_s log(1/ε)) iteration complexity to the mixed-constraint setting via the two-step projection, at the cost of a (1+2ρ) multiplicative factor on R(w̄) and a ρ-dependent sparsity relaxation. Compared to de Vazelhes et al. (2022) in the zeroth-order setting, the new HZO-HT result (Thm. 4.7) eliminates the non-vanishing system error Δ that depended on ‖∇R(w̄)‖, and improves the sparsity requirement from Ω(κ_s⁴k̄) to Ω(κ_s²k̄). Against Lu (2015) and Beck & Hallak (2016), which provide only local convergence guarantees for sign-free convex sets under mere Lipschitz smoothness, this paper delivers global sub-optimality bounds under RSC/RSS. Similarly, Metel (2023) offers only local convergence for a specific ℓ_∞ ball constraint, whereas the present work handles the broader family of k-support-preserving sets (Definition 2.3) with global guarantees. The key differentiator is the novel constrained ℓ_0 three-point lemma (Lemma 3.6), which enables telescopic-sum convergence proofs in objective value that were previously intractable for mixed non-convex constraints.

## Relation to Prior Work

This paper extends the Iterative Hard Thresholding (IHT) framework of Jain et al. (2014) and its stochastic variant (Zhou et al., 2018) to handle additional convex support-preserving constraints, a setting where prior work (Lu, 2015; Beck & Hallak, 2016; Metel, 2023) only provides local convergence guarantees. The key technical departure is a novel two-step projection operator (hard-thresholding followed by projection onto the convex set) that replaces the Euclidean projection onto the mixed constraint, enabling a new extension of the three-point lemma to this non-convex setting. The proof technique builds directly on the relative concavity lemma of Liu & Foygel Barber (2020), and the zeroth-order variant improves upon de Vazelhes et al. (2022) by eliminating a non-vanishing system error.

## Why It Matters / Open Questions

This work fills a genuine gap by providing the first global sub-optimality guarantees (without system error) for sparse optimization with additional support-preserving constraints, in deterministic, stochastic, and zeroth-order settings. The extended three-point lemma is a reusable proof technique that also simplifies existing IHT convergence proofs, and the sparsity/sub-optimality trade-off parameter ρ offers practitioners a principled way to balance solution sparsity against objective quality. Open questions include extending the framework to broader sparsity structures (matrices, graphs) and to constraint sets that are not support-preserving, where the two-step projection may lose feasibility.

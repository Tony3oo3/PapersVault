## Problem

While prior work has extensively studied distinguishing human-written from AI-generated text, there has been little systematic investigation into whether outputs from different LLMs are themselves distinguishable. This paper asks whether LLMs exhibit idiosyncrasies—unique patterns in their generated text—that enable reliable identification of the source model, and if so, what concrete linguistic, formatting, and semantic features underlie these differences.

## Input / Output

The classifier takes a single LLM-generated text response (truncated to 512 tokens) as input and outputs a class label identifying which of N source LLMs produced it. The same prompt set is used across all models to control for content, and responses are collected from diverse prompt datasets (UltraChat for chat/instruct models, FineWeb for base models). The primary metric is held-out classification accuracy, which serves as a quantitative proxy for the degree of idiosyncrasy: chance-level accuracy (1/N) would indicate indistinguishable outputs, while high accuracy reveals strong model-specific signatures.

## Method

The core approach fine-tunes a pretrained text embedding model (LLM2vec, a decoder-only Transformer) with a linear N-way classification head using LoRA (rank 16, α=32) on 10K LLM-generated responses per model, achieving 97.1% accuracy on a five-way chat API classification. To isolate the sources of idiosyncrasies, the paper applies a battery of text transformations: word-level shuffling (preserving word distributions but destroying syntax), letter-level shuffling (destroying word identity), markdown-only extraction (retaining formatting structure while replacing text with 'xxx'), and semantic-preserving rewrites via an external LLM (paraphrasing, translation, summarization). A TF-IDF + logistic regression baseline extracts characteristic phrases per model, and an LLM-as-judge protocol generates open-ended semantic characterizations. The key finding is that word-level distributions alone sustain ~89% accuracy, markdown formatting contributes a moderate signal (73–78%), and even aggressive summarization preserves well-above-chance accuracy, indicating idiosyncrasies are encoded at multiple levels from surface tokens to high-level semantics.

## Results

The paper achieves 97.1% classification accuracy on the 5-way task distinguishing ChatGPT, Claude, Grok, Gemini, and DeepSeek (vs. 20% chance), 96.3% on the 4-way instruct LLM task (Llama, Gemma, Qwen, Mistral), and 87.3% on the 4-way base LLM task. Within the same model family (Qwen2.5 at 7B/14B/32B/72B), the classifier still reaches 59.8% accuracy (vs. 25% chance). Classifiers generalize robustly to out-of-distribution prompts, maintaining 88.3%–99.8% accuracy when trained on one dataset (e.g., UltraChat) and tested on another (e.g., WildChat, Cosmopedia, LmsysChat).

## Baselines & Comparisons

The paper does not compare against prior methods for LLM-source classification (as this is a newly formulated task), but it benchmarks five text embedding backbones as the classifier backbone: ELMo, BERT, T5, GPT-2, and LLM2vec. LLM2vec achieves the best accuracy across all three model groups—97.1% (chat), 96.3% (instruct), and 87.3% (base)—outperforming GPT-2 (92.1/92.3/80.2), BERT (91.1/91.5/66.0), ELMo (90.8/91.0/69.8), and T5 (90.5/89.8/67.9). The gap is most pronounced on base LLMs, where LLM2vec leads GPT-2 by 7.1 points and BERT by 21.3 points. A simple TF-IDF + logistic regression baseline achieves 85.5%/83.7% on chat/instruct LLMs, approaching but not matching the fine-tuned LLM2vec classifier (97.1%/96.3%). All methods substantially exceed the 20–25% chance-level baseline, confirming that idiosyncrasies are detectable even with minimal modeling.

## Relation to Prior Work

This paper repurposes the 'Name That Dataset' paradigm from computer vision (Torralba & Efros, 2011; Liu & He, 2025) to the LLM domain, formulating a synthetic N-way classification task to distinguish outputs from different LLMs. It explicitly departs from the well-studied human-vs-AI text detection literature (Mitchell et al., 2023; Krishna et al., 2023) and from neural authorship attribution (Uchendu et al., 2020; Antoun et al., 2023), which target a binary or open-set problem rather than closed-set LLM-to-LLM distinction. The methodological toolkit is standard—fine-tuning pretrained text embedding models (LLM2vec, BERT, GPT-2, etc.) with LoRA—while the contribution lies in the systematic empirical decomposition of *where* idiosyncrasies reside (word distribution, markdown formatting, semantic content) through controlled text transformations.

## Why It Matters / Open Questions

The findings carry practical implications for tracking provenance of AI-generated content, assessing similarity between proprietary and open-weight models, and—most urgently—exposing a vulnerability in voting-based leaderboards like Chatbot Arena where idiosyncratic style cues could be exploited to manipulate rankings. The observation that idiosyncrasies propagate through synthetic-data fine-tuning raises concerns for the growing practice of training on LLM-generated corpora. Key open questions remain: how the training process (pretraining data, post-training, architecture) gives rise to these patterns, whether they generalize to non-Transformer architectures, and how the task scales to large or unknown model sets.

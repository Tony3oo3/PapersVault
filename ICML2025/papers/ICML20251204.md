## Problem

KV cache memory in LLMs grows linearly with sequence length and model size, creating a critical bottleneck for long-context and multi-user serving. Existing compression methods face hard limits: 2-bit quantization cannot compress below ~25% of full cache size, and token eviction degrades performance on complex reasoning tasks that require retaining most prior tokens. The paper asks whether KV vectors across diverse inputs share low-dimensional structure that can be exploited by a universal, input-agnostic dictionary for compression beyond these bounds.
![Teaser figure](../imgs/ICML20251204/cropped_page1_idx0.webp)

## Input / Output

The method consumes per-layer key and value vectors (dimension m=128) along with a pre-trained universal dictionary of N=4096 unit-norm atoms per layer, plus query vectors during decoding. Output is a compressed KV cache stored in CSR format with FP8 (E4M3) coefficients and int16 indices, totaling 3s+2 bytes per vector (vs. 256 bytes for FP16), where s is the user-controlled sparsity. A sliding buffer of n_b=128 most recent tokens is retained in full precision alongside the sparse cache, and attention scores are produced by pre-computing q_t·D_k before multiplying with the sparse key matrix.

## Method

Lexico represents each KV vector as a sparse linear combination of s atoms from a layer-specific overcomplete dictionary, learned via gradient descent that alternates OMP-based sparse coding with dictionary updates minimizing L2 reconstruction error on WikiText-103. The key insight is that key vectors from different inputs cluster in shared low-dimensional subspaces, so a single universal dictionary (constant ~16.8 MB for 8B models) generalizes across tasks and users without scaling with batch size. During decoding, attention is computed as q_t·D_k·K_csr^T rather than q_t·K^T, reducing multiplications from O(l_seq·m) to O(N·m + l_seq·s), which becomes advantageous when sequence length exceeds dictionary size. The sparsity parameter s provides fine-grained, continuous control over compression ratio (e.g., s=4 yields ~15.8% KV size), enabling operation in memory regimes below 2-bit quantization where prior methods fail.

## Results

On GSM8K with Llama-3.1-8B-Instruct, Lexico at s=14 (26.1% KV size) achieves 75.06% accuracy, outperforming KIVI-2 at a similar budget (67.93%) by 7.1 percentage points, while maintaining 94.3% of the full-cache score (79.61%). At the extreme compression of s=4 (15.8% KV size), Lexico still achieves 51.71% on Llama-3.1-8B-Instruct and 39.20% on Mistral-7B, a regime unreachable by 2-bit quantization. On LongBench, Lexico at s=8 (12.4% KV size) retains 44.68 average score on Llama-3.1-8B-Instruct (88.9% of full-cache 50.26) and 48.96 on Mistral-7B (91.7% of full-cache 53.40), with only 5.6%p and 4.4%p average loss respectively.

## Baselines & Comparisons

Against KIVI-4 at similar KV size (~37%), Lexico is slightly behind on GSM8K (76.88 vs. 78.17 on Llama-3.1-8B-Instruct) but matches or exceeds it on LongBench (49.95 vs. 49.78 average). Against KIVI-2 at ~25% KV size, Lexico achieves a decisive win: +8.2%p on Llama-3-8B (48.75 vs. 40.56), +7.1%p on Llama-3.1-8B-Instruct (75.06 vs. 67.93), and +1.4%p on Mistral-7B (44.35 vs. 42.91). Against eviction-based methods (SnapKV, PyramidKV), Lexico consistently outperforms on both GSM8K and MMLU-Pro across all memory budgets, with the gap widening below 20% KV size where eviction methods degrade sharply due to GQA incompatibility. Against ZipCache, Lexico achieves superior performance in the sub-20% KV regime where ZipCache cannot operate feasibly. On MMLU-Pro Engineering/Law, Lexico outperforms eviction methods across all settings and matches quantization methods (KIVI, ZipCache) at moderate budgets while still winning below 20% cache.

## Relation to Prior Work

Lexico departs from the dominant KV cache compression paradigms of quantization (KIVI, ZipCache, KVQuant) and token eviction (SnapKV, PyramidKV, H2O) by introducing sparse coding over a learned universal dictionary, drawing directly from compressed sensing and dictionary learning in signal processing. While prior work (Singhania et al., 2024; Wang et al., 2024b) observed that key vectors lie in low-rank subspaces, Lexico operationalizes this by showing that a small, input-agnostic dictionary of ~4k atoms can sparsely reconstruct KV vectors across diverse inputs and model families. The OMP implementation builds on efficient Cholesky-based solvers (Zhu et al., 2020) and batched GPU execution (Lubonja et al., 2024), but the application of dictionary learning to KV cache compression is novel.

## Why It Matters / Open Questions

Lexico opens a compression regime below 2-bit quantization (down to ~12–15% of full KV cache) that was previously inaccessible, which is practically significant for deploying LLMs on memory-limited hardware where even 2-bit quantization causes out-of-memory errors. The universality of the dictionary—trained once on WikiText-103 and applied across tasks, users, and model families without scaling with batch size—makes it attractive for serving systems. Key limitations include increased decoding latency from OMP computation, GPU-side memory overhead, and reduced effectiveness in high-throughput settings. Open questions include whether adaptive or beam-search dictionary variants can close the remaining gap to full-precision performance at extreme compression ratios, and whether the approach extends to multimodal or non-Transformer architectures.

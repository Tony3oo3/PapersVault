## Problem

Processing hour-long videos in MLLMs is intractable within standard 8k context windows: an hour at 1fps with 64 tokens/frame requires over 200k tokens. Existing approaches either uniformly sample a fixed number of frames (losing critical content in dynamic scenes) or aggressively pool tokens (losing spatial detail), creating an unresolved trade-off between temporal coverage and per-frame resolution.
![Teaser figure](../imgs/ICML20252166/cropped_page0_idx0.webp)

## Input / Output

The model consumes 1fps-sampled video frames (up to ~3600 frames for an hour-long video) and a text query, producing a free-form text response for video QA or description. The key constraint is that all visual tokens must fit within an 8k context window alongside the text; the adaptive compression dynamically allocates between 2 and 144 tokens per frame depending on frame relevance and redundancy, averaging ~2 tokens/frame for hour-long inputs.

## Method

LongVU applies a three-stage spatiotemporal adaptive compression pipeline. First, DINOv2 features are used to compute pairwise similarity within non-overlapping windows of 8 frames, removing temporally redundant frames (~54% reduction). Second, a cross-modal attention score between each frame's fused features (SigLIP + DINOv2 combined via Spatial Vision Aggregator) and the LLM text-query embedding selects which frames retain full 12×12=144 token resolution while the rest are spatially pooled to 8×8=64 tokens. Third, for videos still exceeding context length, a spatial token compression step prunes individual spatial tokens within sliding windows of K=8 frames: any token whose cosine similarity to the corresponding anchor-frame token exceeds θ=0.75 is removed. The full pipeline is trained end-to-end with Qwen2-7B or Llama3.2-3B as the language backbone, using only cross-entropy loss on autoregressive text generation.

## Results

On the main video understanding benchmarks, LongVU (7B, 8k context, 1fps input) achieves 67.6 on EgoSchema, 66.9 on MVBench, 65.4 on MLVU, and 60.6 overall on VideoMME (59.5 on the 30–60 min Long subset). The model outperforms the strongest open-source baseline LLaVA-OneVision by ~5% in average accuracy, with the largest gain of +12.8 points on VideoMME Long. A lightweight variant using Llama3.2-3B as the language backbone reaches 47.2 on VideoMME Long, surpassing Phi-3.5-vision-instruct (4B) by 3.4 points.

## Baselines & Comparisons

LongVU outperforms all open-source video MLLM baselines across every benchmark it is evaluated on. Against the strongest open-source competitor LLaVA-OneVision (7B, 8k, 32 frames), LongVU gains +7.5 on EgoSchema, +10.2 on MVBench, +0.7 on MLVU, and a striking +12.8 on VideoMME Long, while using 1fps input versus 32 fixed frames. Compared to VideoChat2 (7B, 8k, 16 frames), the improvement is even larger: +13.2 on EgoSchema and +20.3 on VideoMME Long. LongVU surpasses GPT-4V on MVBench (66.9 vs. 43.7) and EgoSchema (67.6 vs. 55.6), and slightly edges it on VideoMME Long (59.5 vs. 56.9), though GPT-4o remains ahead on most metrics (e.g., 77.2 vs. 60.6 on VideoMME Overall). Among training-free token compression methods (FastV, VisionZip, DyCoke), LongVU leads by 8.7–10.7 points on MVBench and 1.6–2.9 points on MLVU. The lightweight Llama3.2-3B variant beats Phi-3.5-vision-instruct (4B) by 3.4 points on VideoMME Long and 5.8 points on MVBench, confirming the compression strategy transfers to smaller backbones.

## Relation to Prior Work

LongVU builds directly on Cambrian-1's Spatial Vision Aggregator (SVA) for fusing DINOv2 and SigLIP features, and extends MovieChat's similarity-based frame selection by substituting DINOv2 (self-supervised, vision-centric) for CLIP (contrastive, language-aligned) as the redundancy-detection backbone. It departs from the dominant uniform-sampling paradigm used by LLaVA-OneVision, VideoChat2, and LLaMA-VID by introducing a three-stage adaptive compression pipeline—temporal reduction, cross-modal query-guided spatial pooling, and inter-frame spatial token compression—that jointly exploits text-query relevance and temporal dependencies. Unlike prior token-merging approaches (Chat-UniVi, SlowFastLLaVA) that apply fixed or KNN-based merging, LongVU's compression is query-conditional and temporally structured, preserving full resolution only where the text query demands it.

## Why It Matters / Open Questions

LongVU demonstrates that hour-long videos sampled at 1fps can be processed within a standard 8k context window with minimal visual information loss, a practical milestone for deploying video-LLMs on commodity hardware. The method's scalability to a 3B backbone (outperforming the 4B Phi-3.5-vision on long-video subsets) suggests a path to efficient on-device long-video understanding. Key limitations remain: the model lacks explicit temporal grounding (cannot identify precise event timestamps), and video SFT degrades image understanding due to a modality gap that requires additional image fine-tuning to recover. Open questions include whether the compression strategy generalizes to even longer contexts (beyond 8k) and whether richer positional encodings can restore temporal localization without sacrificing compression efficiency.

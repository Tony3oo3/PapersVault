## Problem

Existing sample-efficient MARL algorithms for Markov games rely on constructing explicit uncertainty bounds (UCB bonuses) that become intractable under general function approximation, or require asymmetric and tightly coupled player updates. Prior attempts at value-incentivized exploration (MEX, Xiong et al.) either demand asymmetric saddle-point regularization or are computationally intractable for multi-player settings. This paper asks whether a computationally efficient, symmetric, and function-approximation-agnostic algorithm can achieve near-optimal regret in online multi-player general-sum Markov games without any explicit uncertainty quantification.

## Input / Output

For matrix games, the algorithm consumes noisy scalar payoff observations A(i,j)+ξ queried adaptively; for Markov games, it consumes transition tuples (s_h, a_h, s_{h+1}) collected by executing policies. In both settings, the model is parameterized linearly via known feature maps (‖φ‖₂≤1) with bounded parameters (‖ω‖₂≤√d), and the algorithm requires reference policies π_ref for KL regularization. The output is a sequence of equilibrium policies (NE for two-player zero-sum, CCE for general-sum) whose cumulative duality gap or suboptimality gap is bounded, along with the learned model parameters; each iteration collects N+1 trajectories in the Markov game setting.

## Method

VMG alternates between two steps: (1) a value-incentivized model update that solves a regularized least-squares (matrix games) or regularized MLE (Markov games) problem where the regularization term is the negative sum of each player's best-response value function with other players' policies fixed, thereby biasing the model toward estimates that would incentivize deviation from the current equilibrium; and (2) data collection by computing each player's best-response policy against the updated model while holding others fixed, then sampling transitions under both the equilibrium and best-response policies. The key mechanism is that the duality gap (or suboptimality gap) at the current equilibrium is zero, so maximizing the best-response values in the regularizer pulls the model away from its current estimate, implicitly driving exploration without any confidence interval. KL regularization (β>0) is critical for computational tractability: it yields closed-form expressions for the regularization terms and enables last-iterate linear convergence of first-order game solvers. The framework is agnostic to the specific function approximation class and permits simultaneous, uncoupled policy updates across all N players, reducing to reward-biased MLE in the bandit case and to MEX's value regularization in the single-agent MDP case.

## Results

For two-player zero-sum matrix games with linear function approximation, VMG achieves a regret of Õ(d√T), matching the known lower bound Ω(d√T) and translating to a sample complexity of Õ(d²/ε²) for finding an ε-optimal NE. For finite-horizon N-player general-sum Markov games under the linear mixture model, VMG achieves a regret of Õ(d√(H³T)), yielding a sample complexity of Õ(Nd²H⁴/ε²) samples (or Õ(Nd²H³/ε²) trajectories) for an ε-optimal CCE. In the infinite-horizon setting, the sample complexity is Õ(Nd²/((1−γ)⁴ε²)). These bounds are near-optimal, matching or improving upon prior UCB-based approaches that require explicit uncertainty quantification.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments, so comparisons are made at the level of regret/sample complexity bounds. For two-player zero-sum Markov games, VMG's regret bound matches that of MEX (Liu et al., 2024), which only covered the max player's regret, whereas VMG covers both players simultaneously. For multi-player general-sum Markov games, VMG improves the horizon dependence from Õ(dH⁵√T) in Xiong et al. (2024) to Õ(d√(H³T)), a significant reduction in the H-dependency. Compared to the minimax sample complexity of Chen et al. (2022), VMG's sample complexity is near-optimal up to a factor of H when the number of players N is fixed. A key practical advantage over UCB-based methods (e.g., O'Donoghue et al., 2021; Sessa et al., 2022) is that VMG avoids constructing tailored confidence intervals, making it agnostic to the form of function approximation and permitting simultaneous, uncoupled policy updates across all players.

## Relation to Prior Work

VMG extends the value-incentivized exploration paradigm from single-agent RL (MEX, Liu et al. 2024) and reward-biased MLE for bandits (Liu et al. 2020) to the multi-player general-sum Markov game setting. The key departure from MEX is replacing its asymmetric saddle-point regularization (which requires solving a bilevel optimization problem) with symmetric best-response value regularization, enabling simultaneous and uncoupled policy updates across all players. This positions VMG as a computationally tractable alternative to the dominant UCB-based exploration approaches in MARL, which require constructing tailored confidence sets that become intractable under general function approximation.

## Why It Matters / Open Questions

VMG demonstrates that near-optimal regret in multi-agent games is achievable without explicit uncertainty quantification, which is practically significant because constructing valid confidence sets under neural network function approximation remains an open challenge. The near-optimal sample complexity (matching UCB counterparts up to logarithmic factors) validates the approach theoretically, while the agnosticism to function approximation form makes it more deployable in practice. Open questions include extending guarantees to general and independent function approximation, developing a model-free variant, and analyzing performance under adversarial environments—each of which would broaden the practical applicability of value-incentivized exploration in MARL.

## Problem

In-context learning for QA tasks depends critically on high-quality examples, which are often scarce due to data privacy constraints, annotation costs, and distribution disparities across clients. Existing federated approaches either require transmitting full LLM parameters (incurring prohibitive communication overhead) or operate in a one-shot manner that fails to exploit local datasets iteratively. The paper asks whether ICL and federated learning can be integrated to achieve both high answer quality and low communication cost without parameter transmission.

## Input / Output

The server holds a set of query covariates (questions) and maintains a query dataset with iteratively updated predicted labels, which it broadcasts to clients each round. Each client possesses a local Q&A dataset and a language model, and returns only its predicted answers for the server's queries—never its raw local data—keeping per-round communication cost constant regardless of local dataset size. For MMLU, outputs are multiple-choice labels aggregated by majority voting; for TruthfulQA, outputs are generated text answers fused by a lightweight server-side Fusion LM. The server itself does not need to host an LLM, as all ICL inference occurs on the client side.

## Method

Fed-ICL operates in K rounds where, at each round k, the server broadcasts its current query dataset C_k to all L clients. Each client performs two ICL steps: (1) it relabels its own local dataset D^i using C_k as in-context examples (incorporating cross-client information), and (2) it predicts answers for the server's queries using both the original D^i and the relabeled D_k^i as in-context examples. The server then aggregates client predictions (average for regression, majority vote for classification, or a Fusion LM for generation) to form the next round's query dataset. Theoretically, under a single-layer linear self-attention model, the paper proves Fed-ICL converges to the optimal linear predictor conditioned on all client datasets, with convergence governed by a contraction matrix H_cont that approaches identity when client and server data distributions match the pretraining distribution. Practical enhancements include k-NN filtering of local datasets for semantic relevance and a Fed-ICL-Free variant that operates without ground-truth labels by relying solely on the iteratively relabeled dataset.

## Results

Fed-ICL is evaluated on MMLU (114 multiple-choice queries, accuracy metric) and TruthfulQA (38 open-ended queries, BERTScore/BLEURTScore/BARTScore) using Llama-2-7B-chat-hf, Llama-3.1-8B-Instruct, and GPT-4o-mini as client LLMs across three Dirichlet heterogeneity levels (α = 0.001/0.01, 1.0/0.5, 100). With open-source Llama backbones, Fed-ICL achieves a clear performance gain over all baselines while incurring lower communication costs (6 rounds vs. 50 for FedAvg on MMLU). The advantage narrows with GPT-4o-mini, suggesting federated refinement is most beneficial for weaker models. Fed-ICL-Free, which requires no ground-truth labels from clients, still outperforms LLM-Debate, confirming that local example covariates alone contribute meaningfully to ICL quality.

## Baselines & Comparisons

Against FedAvg (McMahan et al., 2017), Fed-ICL achieves comparable or superior answer quality with substantially lower communication cost: Fed-ICL converges in 6 rounds transmitting only predicted labels, while FedAvg requires 50 rounds (MMLU) or 20 rounds (TruthfulQA) of full model parameter exchange via LoRA fine-tuning. Against LLM-Debate (Du et al., 2023), Fed-ICL and Fed-ICL-Free both outperform the debate baseline, with Fed-ICL-Free winning despite having no access to ground-truth client labels, demonstrating that leveraging local datasets (even unlabeled covariates) is more effective than pure multi-agent debate. Against LLM-Blender (Jiang et al., 2023) and Mixture-of-Agents (Wang et al., 2024), which are non-iterative ensemble methods that do not exploit local client data, Fed-ICL achieves higher performance at convergence, particularly under high data heterogeneity (small α). The performance gap over all baselines is most pronounced with Llama backbones and diminishes with GPT-4o-mini, indicating that stronger base models reduce the marginal benefit of federated context refinement.

## Relation to Prior Work

This paper bridges two previously separate lines of work: in-context learning (ICL) for LLMs and federated learning (FL) for privacy-preserving distributed training. It builds directly on the linear self-attention (LSA) theoretical framework of Zhang et al. (2023a), which characterizes how trained transformers perform ICL as implicit linear regression, and repurposes their convergence results to prove convergence of the proposed Fed-ICL iterative scheme. Conceptually, it departs from parameter-transmitting FL approaches (FedAvg, FATE-LLM, FedBiot) by communicating only predicted answers rather than model weights, and from parameter-free ensemble methods (LLM-Debate, MoA, LLM-Blender) by iteratively leveraging each client's local dataset across multiple rounds rather than operating in a single shot.

## Why It Matters / Open Questions

Fed-ICL provides the first theoretical convergence guarantee for a federated ICL framework, showing linear convergence to the optimal answer conditioned on all client data under mild distributional assumptions. Practically, it offers a communication-efficient alternative to parameter-transmitting FL for QA, with the added benefit that the server need not host an LLM. Key limitations include the theory being restricted to a single-layer linear attention model (extending to nonlinear transformers is left open), the empirical gains diminishing substantially with stronger backbone models (GPT-4o-mini vs. Llama), and evaluation on only two benchmarks with relatively small query sets (114 and 38 queries). Future work on multimodal extensions, deeper transformer analysis, and scaling to larger client populations would strengthen the framework's practical relevance.

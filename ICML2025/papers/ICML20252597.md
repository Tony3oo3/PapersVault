## Problem

3D question answering (3D-QA) is bottlenecked by the scarcity of 3D-language training data, making it difficult to achieve the strong 3D-to-text alignment that 2D LVLMs enjoy. Existing 3D-based and hybrid methods require computationally expensive 3D-language alignment or complex multi-modal architectures, while prior 2D-only approaches rely on naive view selection (uniform sampling or image retrieval) that misses critical views and introduces redundancy. This paper asks whether a pre-trained 2D LVLM can answer 3D questions in a zero-shot manner if given the right subset of 2D views.

## Input / Output

The method takes a 3D scene represented as N rendered 2D views (each with camera position and orientation matrices) and a free-form text question, and produces a short text answer. A key constraint is the LVLM's token limit, which restricts the number of views that can be processed simultaneously; cdViews selects an optimal k=9 views from the full set. The only trainable component is a 5.9M-parameter viewSelector module, while the 7B-parameter LLAVA-OV backbone remains frozen throughout.

## Method

cdViews selects critical and diverse views for zero-shot 3D-QA via two modules. The viewSelector is a lightweight cross-attention network that scores each view's relevance to the question by computing cosine similarity between a pooled question vector and question-aligned view vectors; it is trained with binary cross-entropy loss on labels produced by an automatic viewAnnotator that first converts QA pairs into descriptive captions (to prevent the LVLM from shortcutting to the answer) and then classifies each view as positive, negative, or uncertain via in-context learning. The viewNMS module then removes spatially redundant views by ranking candidates by score and greedily adding views whose combined camera distance (Euclidean position distance plus quaternion-based angular orientation distance) exceeds a threshold T=0.5. The selected views and question are fed directly into the frozen 2D LVLM to generate the answer, requiring no 3D-language alignment or fine-tuning of the backbone.

## Results

On the ScanQA test set (with objects), LLAVA-OV + cdViews achieves 35.0 EM@1, 46.1 BLEU-1, 49.7 ROUGE, and 102.8 CIDEr, surpassing the strongest hybrid baseline BridgeQA (31.3 EM@1, 83.8 CIDEr) by 3.7 EM@1 and 15.0 CIDEr. On the SQA test set, cdViews reaches 56.9 EM@1, outperforming the best 3D-based method SIG3D (52.6) by 4.3 points and BridgeQA (52.9) by 4.0 points. The method also reduces the number of input views from 17 (uniform/retrieval) to just 9 via viewNMS while improving accuracy, and uses only 5.9M trainable parameters versus 644M for the retrieval-based alternative.

## Baselines & Comparisons

cdViews (LLAVA-OV + F_cdViews) outperforms all 12 compared baselines on every reported metric. Against the strongest hybrid method BridgeQA (Mo & Liu, 2024), it gains +3.7/+4.8 EM@1 and +15.0/+21.1 CIDEr on ScanQA (with/without objects), and +4.0 SQA EM@1 (56.9 vs 52.9), while using only 2D views and 5.9M trainable parameters versus BridgeQA's 3D+2D pipeline. Among 3D-based methods, it surpasses the best performer SIG3D (Man et al., 2024) by +4.3 SQA EM@1 (56.9 vs 52.6) and 3D-VisTA (Zhu et al., 2023) by +8.0/+12.6 EM@1 on ScanQA. Compared to the 2D baselines using the same LLAVA-OV backbone, cdViews improves over image retrieval (F_retrieval) by +1.1/+1.0 EM@1 and +4.0/+2.7 CIDEr, and over uniform sampling (F_uniform) by +1.9/+2.1 EM@1 and +7.0/+7.1 CIDEr. On the validation set, cdViews also exceeds GPT-4O+CC (Liu et al., 2024) by +7.0 CIDEr (94.0 vs 87.0), despite GPT-4O's stronger language capabilities, because cdViews selects question-relevant views rather than uniform ones. The only relative weakness is on SQA's "Is" and "Can" question types, where cdViews trails SIG3D by 2.8 and 10.2 points respectively, attributed to the zero-shot nature of LLAVA-OV lacking dataset-specific adaptation for those categories.

## Relation to Prior Work

This paper departs from the dominant paradigm in 3D-QA, which trains dedicated 3D-language alignment modules (3D-based methods like 3D-LLM, 3D-VisTA) or complex hybrid pipelines that fuse 2D and 3D features (BridgeQA, PQ3D). Instead, it repurposes a frozen 2D LVLM (LLAVA-OV) for 3D-QA via zero-shot inference, treating the problem as one of selecting the right 2D views from a 3D scene. The novel contribution is the cdViews framework: a lightweight viewSelector (a small cross-attention transformer trained with auto-generated labels from a viewAnnotator that leverages the LVLM itself) combined with a geometric viewNMS that removes spatially redundant views using camera pose distances. This positions the work at the intersection of 2D LVLMs and 3D scene understanding, carving out view selection as the critical bottleneck that prior 2D-based approaches (uniform sampling, BLIP retrieval) handled inadequately.

## Why It Matters / Open Questions

The practical implication is significant: practitioners can leverage off-the-shelf 2D LVLMs for 3D-QA without any 3D-specific training data or architecture, reducing the barrier to entry for 3D scene understanding. The identification of view selection as the key performance lever (rather than the LVLM backbone itself) opens a focused research direction. Limitations include reliance on the ScanQA training set for viewSelector labels, weaker performance on yes/no ('Is') and capability ('Can') questions compared to dataset-adapted 3D methods, and the fact that the approach still cannot perform true 3D spatial reasoning beyond what 2D views convey. Open questions include whether the view selection strategy generalizes to outdoor scenes, dynamic environments, or more complex 3D reasoning tasks like navigation and manipulation.

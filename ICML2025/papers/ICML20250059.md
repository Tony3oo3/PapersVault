## Problem

When a system must release the same sensitive statistic to multiple analysts at different trust levels, independent releases cause the combined privacy loss to scale with the sum of all budgets rather than the maximum. Prior work on lossless gradual release (Koufogiannis et al., 2016) only supported releases in a fixed increasing order, leaving open whether lossless coordination is possible when releases are requested in arbitrary order and the set of privacy parameters is not known in advance.

## Input / Output

The mechanism takes a sensitive function value f(x), a target privacy parameter ρ, and a set M of previously issued releases (each storing a privacy parameter and its noisy value). It outputs a new noisy release Y_ρ correlated with all prior releases such that any subset of releases is jointly distributed as a randomized post-processing of the least-private release in that subset. For sparse histograms, the input additionally includes a threshold τ, and the output is a thresholded noisy histogram where only counts exceeding τ are revealed, with running time independent of the domain dimension d.

## Method

The core technical contribution is a meta theorem showing that any independent additive noise mechanism whose noise distribution family satisfies a 'convolution preorder' (i.e., D(ρ₁) = D(ρ₂) * C(ρ₂,ρ₁) for ρ₁ < ρ₂) admits lossless multiple release in arbitrary order. For the Gaussian mechanism, the algorithm finds the two closest existing releases bracketing the target ρ, samples fresh Gaussian noise with a variance determined by the three privacy parameters, and forms an inverse-variance-weighted combination to produce the new release—requiring no covariance matrix and no knowledge of Brownian motion. The framework extends to Laplace and Poisson noise via explicit conditional sampling (e.g., binomial for Poisson, a three-component mixture for Laplace), and composes with invertible post-processing (factorization mechanisms) or arbitrary post-processing under a weaker 'weakly lossless' notion (sparse histograms with thresholding). For large-domain histograms, a dimension-independent algorithm samples noise only for non-zero counts and uses binomial sampling to simulate which zero counts exceed the threshold, reducing Gaussian samples from O(dm) to O((k+c)m) where k is sparsity and c is the number of zero counts that ever exceed the threshold.

## Results

The empirical evaluation (Section 6) compares the variance of noise between lossless multiple release and a baseline of independent Gaussian releases, repeated 10^6 times with budgets spaced logarithmically between ρ=0.001 and ρ=5. The lossless mechanism achieves exactly the same noise variance as a single release with the maximum privacy parameter, regardless of the number of releases made. In contrast, the independent-release baseline shows a clear increase in variance as the number of releases grows, with the initial jump being largest (since the second release's budget is the difference from the starting point ρ=0.001) and subsequent jumps being uniform. The key takeaway is that lossless multiple release incurs zero additional accuracy cost for any number of releases, while uncoordinated releases accumulate privacy/accuracy loss.

## Baselines & Comparisons

The paper's sole empirical comparison is against a baseline of independent Gaussian releases, where each release draws fresh, uncorrelated noise. The lossless multiple release mechanism matches the variance of a single release with the maximum privacy parameter ρ_max, meaning no accuracy is lost regardless of how many releases are made. The independent-release baseline, by contrast, accumulates variance proportional to the sum of all privacy parameters used (due to composition), resulting in measurably noisier outputs as the number of releases increases. The paper does not compare against other specific named baselines or competing methods; the comparison is purely between correlated (lossless) and uncorrelated (independent) release strategies. The theoretical contribution (Theorem 4.4, the meta theorem) establishes that the lossless property holds for any independent additive noise mechanism whose noise distribution satisfies a convolution preorder, which is a strictly broader guarantee than what prior gradual-release work (Koufogiannis et al. 2016, Li et al. 2012) provided, since it removes the requirement for a fixed increasing order of privacy parameters.

## Relation to Prior Work

This paper generalizes the lossless gradual release framework of Koufogiannis et al. (2016) and Li et al. (2012) from sequential, pre-ordered releases to an arbitrary-order, online multiple release setting. The key conceptual departure is the introduction of a convolution preorder as a unifying condition under which any independent additive noise mechanism supports lossless multiple release, subsuming Gaussian, Laplace, and Poisson noise in a single theorem. For the Gaussian mechanism specifically, the paper replaces the Brownian motion machinery used by Koufogiannis et al. and Whitehouse et al. with a simple inverse-variance-weighting argument, and for sparse histograms it adapts the efficient zero-count simulation technique of Cormode et al. (2012) to the gradual release setting.

## Why It Matters / Open Questions

The result is practically relevant for multi-level security systems, data markets, and federated settings where analysts at different trust levels need coordinated releases without compounding privacy loss. The convolution preorder framework provides a clean, checkable condition for new mechanisms to inherit lossless multiple release, lowering the barrier for future extensions. However, significant open questions remain: the exponential mechanism, report-noisy-max, and the discrete Gaussian mechanism all lack known lossless multiple release constructions, and the paper's empirical evaluation is limited to a single 1D Gaussian experiment rather than end-to-end utility comparisons on real queries.

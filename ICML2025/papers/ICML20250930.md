## Problem

The state-of-the-art algorithm γ-LSCVI-UCB for infinite-horizon average-reward linear MDPs achieves an order-optimal Õ(√T) regret bound but requires computing the minimum of the value function over the entire state space for its clipping step, which is computationally prohibitive when the state space is large or infinite. This paper addresses the open question of whether an algorithm exists with polynomial computational complexity in the problem parameters that is independent of the state space size.

## Input / Output

The algorithm consumes the current state s_t, a known d-dimensional feature map φ(s,a) with ‖φ‖₂ ≤ 1, and hyperparameters (γ = 1 − √(1/T), span H = 2·sp(v*), bonus factor β, regularization λ = 1). At each time step it outputs an action a_t chosen greedily from the Q-function estimate, while internally maintaining sequences of value functions {V_u^t, Q_u^t} for u ∈ [t:T] that plan over the remaining horizon. The resulting regret bound Õ(sp(v*)√(d³T)) is achieved with computational complexity O(T³d²A), polynomial in T, d, and A but independent of |S|.

## Method

The algorithm approximates the average-reward problem by a discounted problem and runs value iteration at every time step, introducing two key innovations for computational efficiency. First, it replaces the full-state-space minimum in the clipping step with a running threshold m_t computed only from visited states, updated as m_{t+1} = Ṽ_{t+1}^t(s_{t+1}) ∧ m_t. Second, because changing the clipping threshold between consecutive steps can cause value function sequences to diverge—especially in the linear MDP setting where the regression-based transition estimate [P̂_t V](s,a) = ⟨φ(s,a), ŵ_t(V)⟩ can amplify small input differences into large output differences (Lemma 3.1)—the algorithm introduces deviation-controlled value iteration that clips Q_u^t to be bounded by the Q-functions from the two previous time steps (Q_u^{t-1} and Q_u^{t-2}). This guarantees |Ṽ_u^{t+1}(s) − Ṽ_u^t(s)| ≤ m_{t-1} − m_{t+1}, enabling a telescoping argument in the regret analysis. The transition model is estimated via least-squares regression exploiting the linearity of [PV](s,a) in φ(s,a), with a bonus term β‖φ(s,a)‖_{Λ_t^{-1}} ensuring optimism.

## Results

The proposed algorithm γ-DC-LSCVI-UCB achieves a regret bound of Õ(sp(v*)√(d³T)) for infinite-horizon average-reward linear MDPs, matching the order-optimal regret of the prior γ-LSCVI-UCB algorithm. The key improvement is computational complexity: O(T³d²A), which is polynomial in the problem parameters T, d, A and critically independent of the state space size |S|. This resolves the open question of whether a computationally efficient algorithm with state-space-independent complexity can achieve Õ(√T) regret. The lower bound of Ω(d√(sp(v*)T)) from Wu et al. (2022) confirms the regret is near-optimal up to a factor of √d.

## Baselines & Comparisons

The proposed γ-DC-LSCVI-UCB matches γ-LSCVI-UCB (Hong et al., 2025) exactly on the regret bound Õ(sp(v*)√(d³T)) but eliminates the dependence on state space size S in computational complexity, going from poly(T, S, A, d) to poly(T, A, d). Against FOPO and LOOP, which also achieve order-optimal regret, the proposed method wins decisively on computational complexity: FOPO and LOOP require O(T^d) time (exponential in feature dimension d) to solve a fixed-point problem, while the proposed method runs in O(T³d²A). Compared to OLSVI.FH, the proposed method achieves a strictly better regret bound (√T vs. T^(3/4)) at the cost of slightly higher polynomial complexity. Against MDP-EXP2, the proposed method achieves the same Õ(√T) regret order but without requiring the strong uniform mixing assumption on all policies. The regret bound is within a factor of √d of the known lower bound Ω(d√(sp(v*)T)), leaving a gap that the authors identify as a future direction for variance-aware regression.

## Relation to Prior Work

This paper is a direct computational refinement of Hong et al. (2025) γ-LSCVI-UCB, which already achieved the optimal Õ(sp(v*)√(d³T)) regret bound for infinite-horizon average-reward linear MDPs via discounted-reward approximation and span-constrained value iteration. The key departure is replacing the infeasible full-state-space minimum in the clipping step with a minimum over only visited states, which necessitates a novel deviation-controlled value iteration scheme to handle the resulting analytical challenges in the linear regression-based transition estimation. The broader algorithmic framework (discounted approximation, optimistic value iteration, UCB bonuses) is inherited from Wei et al. (2020) and Hong et al. (2025), while the paper positions itself against FOPO, OLSVI.FH, LOOP, and MDP-EXP2 as the first method achieving optimal regret with state-space-independent computation and no strong ergodicity assumptions.

## Why It Matters / Open Questions

This is the first algorithm for infinite-horizon average-reward linear MDPs that simultaneously achieves order-optimal Õ(√T) regret, polynomial-time computation independent of state space size, and no strong mixing assumptions, filling a gap identified in Table 1 where all prior methods had at least one of these deficiencies. However, the computational complexity remains super-linear at O(T³d²A), and the algorithm still requires prior knowledge of the bias span sp(v*) and the time horizon T. Open questions include whether the span can be estimated adaptively (as recently shown possible in the tabular setting by Boone & Zhang, 2024), whether the O(T³) computation can be reduced to O(T), and whether the deviation-controlled value iteration technique extends to general function approximation settings.

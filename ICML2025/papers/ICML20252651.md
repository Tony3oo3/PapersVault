## Problem

Conformal prediction provides distribution-free coverage guarantees for post-hoc model calibration, but existing distributed variants (FedCP-QQ, FCP, WFCP) all assume a star topology with a central server collecting information from all devices. Many practical settings—IoT sensor networks, multi-hospital diagnostics, autonomous vehicle fleets—require fully decentralized communication where each device can only exchange messages with its graph neighbors, and no central coordinator exists. This paper addresses how to achieve valid conformal prediction with marginal coverage guarantees in such a fully decentralized, arbitrary-topology setting.

## Input / Output

Each of K devices holds a local calibration set D_k of n_k (X,Y) pairs drawn i.i.d. from a potentially different distribution P_k, and all devices share a pre-trained model f that produces a bounded score s(x,y)∈[0,1] (e.g., 1−confidence for classification). Given a common test input X_test and a target coverage level 1−α, every device independently outputs a prediction set C(X_test|D) = {y : s(X_test,y) ≤ threshold} that satisfies P(Y_test ∈ C) ≥ 1−α under the mixture distribution P = Σ w_k P_k with w_k ∝ n_k+1. The threshold is computed collaboratively via message passing over the connectivity graph, and the set size (inefficiency) is the key quality metric alongside coverage.

## Method

The paper proposes two fully decentralized protocols. Q-DCP solves a decentralized quantile regression via ADMM, where the key technical contribution is replacing the non-smooth ReLU in the pinball loss with the smooth approximation g̃(x)=x+(1/κ)log(1+e^{−κx}) and adding a quadratic regularization (μ/2)(s−s₀)², making the objective L-smooth and μ-strongly convex to guarantee linear ADMM convergence; each iteration requires only a single scalar broadcast per edge, but coverage depends on correctly tuning hyperparameters (κ, μ, s₀, ε₀) tied to graph connectivity. H-DCP instead quantizes all local scores to M uniform levels, computes a local histogram vector, and runs a linear consensus algorithm (with matrix W derived from the graph Laplacian) to estimate the global histogram; the threshold is then read off the estimated cumulative histogram with an explicit error bound ε^{H-DCP} that depends only on the spectral gap ϱ of W, yielding hyperparameter-free coverage guarantees at the cost of an M-dimensional vector exchange per iteration.

## Results

On CIFAR-100 with K=20 devices (non-i.i.d., 50 samples each) and α=0.1, Q-DCP achieves the smallest prediction set size (11.35±0.89) while maintaining coverage of 0.913±0.01, outperforming FCP (set size 11.98±0.99) and H-DCP (set size 12.16±1.47). FedCP-QQ is dramatically more conservative, yielding a set size of 45.32±7.22 (roughly 4× larger) at coverage 0.996. Q-DCP requires only 1 scalar per iteration per device, whereas H-DCP requires an M-dimensional vector (M=1000), making Q-DCP ~1000× more communication-efficient per iteration. However, Q-DCP's coverage guarantee is conditional on correctly selecting hyperparameters (ε₀, s₀), while H-DCP provides hyperparameter-free coverage guarantees.

## Baselines & Comparisons

Against centralized CP (Vovk et al., 2005), both Q-DCP and H-DCP match the benchmark's set size at convergence on well-connected graphs (e.g., complete graph), confirming that the distributed protocols recover the centralized solution. Against FCP (Lu et al., 2023), Q-DCP achieves a slightly smaller set size (11.35 vs. 11.98) at comparable coverage, and unlike FCP operates on arbitrary graph topologies rather than requiring a central server. Against FedCP-QQ (Humbert et al., 2023), both proposed methods produce dramatically tighter prediction sets (11.35–12.16 vs. 45.32), as FedCP-QQ's quantile-of-quantiles approach is overly conservative. Against WFCP (Zhu et al., 2024), H-DCP is equivalent in the star-topology special case (same coverage 0.92, same set size 12.16), but extends to arbitrary decentralized topologies. The key trade-off is that Q-DCP wins on communication efficiency (1 scalar vs. M=1000 scalars per iteration) but is sensitive to hyperparameter mis-specification, while H-DCP is robust to hyperparameter choice at the cost of ~1000× higher per-iteration communication.

## Relation to Prior Work

This paper extends the line of federated conformal prediction (FCP, FedCP-QQ, WFCP) from star topologies with a central server to fully decentralized message-passing on arbitrary connectivity graphs. Q-DCP repurposes ADMM for decentralized quantile regression, introducing a softplus smoothing of the pinball loss and a quadratic regularization term to convert the non-smooth, non-strongly-convex problem into one with linear convergence. H-DCP adapts the histogram-exchange idea from WFCP (Zhu et al., 2024) by replacing the central aggregation with a consensus algorithm, yielding a hyperparameter-free coverage guarantee at the cost of M-dimensional per-iteration messages.

## Why It Matters / Open Questions

The practical relevance is significant for privacy-sensitive, serverless deployments (multi-hospital diagnostics, IoT sensor networks, autonomous vehicle fleets) where a central aggregation point is infeasible or undesirable. The key open trade-off—Q-DCP's low communication cost but sensitivity to hyperparameter tuning versus H-DCP's robustness but M× communication overhead—remains unresolved and likely depends on application-specific constraints. Limitations include the synchronous communication assumption, the bounded-score requirement for H-DCP, and the fact that Q-DCP's coverage guarantee is only as strong as the practitioner's ability to satisfy Assumption 4.1 in practice. Future extensions to asynchronous networks, localized (conditional) risk guarantees, and online settings are natural next steps.

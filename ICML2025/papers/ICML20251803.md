## Problem

Modeling global geometric context while preserving SE(3) equivariance is a critical challenge for biomolecular and physical systems, but existing approaches face a fundamental trade-off: equivariant self-attention methods (Equiformer, VNT) capture global context at quadratic computational cost, while local message-passing methods (EGNN, SchNet, TFN) sacrifice long-range interactions. Extending the recently successful sub-quadratic long-convolutional and state-space frameworks to the equivariant setting remained unexplored, leaving no efficient architecture that simultaneously handles global geometric context, equivariance, and large-scale sequences.

## Input / Output

The method operates on ordered geometric graphs (e.g., biomolecules with IUPAC canonical ordering) where each node carries a 3D coordinate vector (equivariant token) and scalar features such as atom type, nucleotide identity, and loop type (invariant token), with optional edge attributes. The model produces per-node equivariant vector features and invariant scalar features that can be pooled for molecular property regression (stability, degradation, switching factor) or used directly to predict 3D displacement vectors for molecular dynamics trajectory prediction. A key constraint is the requirement for a canonical node ordering, which enables the use of sequence-based long convolutions but limits applicability to unordered point clouds.

## Method

Geometric Hyena replaces equivariant self-attention with a geometric long convolution that aggregates global context at O(N log N) complexity. The core mechanism is a vector long convolution defined via cross products between equivariant query and key sequences, which is decomposed into six scalar FFT convolutions using the Levi-Civita symbol to achieve sub-quadratic efficiency. This is extended to a geometric long convolution that enables scalar-vector interactions (scalar-scalar, vector dot, scalar-vector, and vector cross products) between invariant and equivariant subspaces, analogous to a Clebsch-Gordan tensor product but computed in Cartesian space. An equivariant projection layer (one-layer EGNN augmented with learned global context tokens via SIREN-predicted weights) embeds input tokens into QKV triplets with both local and global context, and a selective sigmoid gating mechanism modulates the convolution output before element-wise (scalar) or cross-product (vector) integration with values. Key-value normalization to unit norm is critical for numerical stability, bounding output magnitudes and enabling practical training without extreme learning rate constraints.

## Results

On the Open Vaccine all-atom RNA property prediction task, Geometric Hyena achieves RMSE 0.339±0.004, reducing error by 15% over the second-best model (G-Transformer at 0.391). On Ribonanza-2k all-atom, it reaches RMSE 0.546±0.006 (8.4% improvement over G-Transformer). For protein molecular dynamics, Geometric Hyena achieves MSE 2.49±0.037 on the all-atom setting (9% better than EGNN's 2.72) and 1.80±0.009 on backbone (2% better than FastEGNN's 1.84). At 30k tokens, Geometric Hyena runs 20× faster than equivariant self-attention and supports up to 2.7M tokens on a single A10G GPU versus ~37k for attention-based methods.

## Baselines & Comparisons

Geometric Hyena outperforms the closest equivariant self-attention baseline (G-Transformer) on every task: Open Vaccine all-atom RMSE 0.339 vs 0.391, Ribonanza-2k all-atom 0.546 vs 0.592, Tc-Ribo all-atom 0.548 vs 0.553, and Protein MD all-atom MSE 2.49 vs 3.67. Against Equiformer, Geometric Hyena wins wherever Equiformer does not run out of memory (e.g., Open Vaccine backbone 0.363 vs 0.409) and uniquely handles all-atom settings where Equiformer OOMs entirely. Compared to Vector Neuron Transformer, Geometric Hyena achieves lower RMSE on all four property/MD tasks (e.g., Ribonanza-2k all-atom 0.546 vs 0.638). All local-context equivariant methods (SchNet, TFN, EGNN, FastEGNN, LEFTNet, TMD-ET) are substantially outperformed, with gaps of 15–30% in RMSE, confirming the importance of global geometric context. On the geometric associative recall task, Geometric Hyena and G-Transformer both successfully learn retrieval while VNT and Equiformer struggle, and Geometric Hyena requires smaller hidden dimensions to match performance. The key efficiency advantage is that Geometric Hyena uses O(N log N) FFT-based convolution versus O(N²) self-attention, enabling 72× longer context within the same GPU memory budget.

## Relation to Prior Work

This paper extends the Hyena long-convolutional architecture (Poli et al., 2023) and the broader state-space/long-convolutional sequence modeling line (Mamba, S4, H3) to the geometric equivariant setting, which had remained unexplored. It departs from equivariant self-attention models (Equiformer, Vector Neuron Transformer) that achieve global context at quadratic cost, and from local equivariant GNNs (EGNN, SchNet, TFN) that sacrifice global information, by introducing a vector long convolution based on cross products decomposed via the Levi-Civita symbol into six scalar FFT convolutions. The equivariant projection layer borrows from EGNN message passing augmented with learned global context tokens, following the virtual-node strategy from recent planar GNN work.

## Why It Matters / Open Questions

The practical impact is significant: processing 30k-token geometric sequences 20× faster and supporting 72× longer context (up to 2.7M tokens) than equivariant transformers on a single GPU opens the door to modeling very large biomolecular systems that were previously intractable. A key limitation is the requirement for canonical node ordering (e.g., IUPAC rules for biomolecules), which restricts applicability to unordered point clouds or general geometric graphs; the authors acknowledge this and suggest learning permutation equivariance as future work. The geometric associative recall benchmark provides a useful diagnostic for contextual learning in equivariant models, and the finding that alternating local and global context is the dominant architectural ingredient (per ablation) offers a clear design principle for future geometric sequence models.

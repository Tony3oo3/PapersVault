## Problem

The conventional view holds that LLMs generate text through purely local, per-token prediction without anticipating future outputs beyond the next immediate token, making the generation process opaque and difficult to control. While prior works examined narrow aspects like multi-token lookahead or knowledge retrieval in specialized settings, no formal definition or comprehensive framework for 'response planning' in LLMs existed. This paper asks whether LLM prompt representations encode global attributes of their entire upcoming responses and, if so, how this planning scales, evolves, and differs from the model's own verbalized awareness.

## Input / Output

The probes consume layer-wise hidden representations extracted at the prompt position (before any response tokens are generated) from an L-layer decoder LLM, with a grid search over which layer(s) to use. Outputs are structured as either continuous regression values (response length in tokens, number of reasoning steps) or discrete classification labels (4-class animal character, 5-class multiple-choice answer, binary confidence, binary factual consistency). A key design constraint is that target attributes must be global—distributed across the response and not inferable from the first generated token—ensuring the probe captures genuine planning rather than first-token shortcuts.

## Method

The core method trains one-hidden-layer MLP probes with ReLU activation (hidden sizes from 1 to 1024) on LLM prompt representations to predict global response attributes via the mapping h_θ(H_x^l) → g(y), where g(y) is an attribute rule (e.g., token counting, answer extraction). Probes are trained with MSE loss for regression and cross-entropy for classification over 400 epochs on 60/20/20 splits, with grid search over both MLP width and source layer. The paper then characterizes the discovered planning through four analytical lenses: in-dataset and cross-dataset generalization (showing patterns are task-intrinsic rather than dataset-specific), hidden-size saturation curves (revealing a complexity hierarchy where behavior attributes need the simplest probes), layer-wise probing (showing structure peaks mid-layers, content consolidates late, and behavior stabilizes early), and generation-position probing (revealing a three-phase pattern of initial global planning, mid-segment local focus, and late-stage refinement). A critical ablation compares probe predictions against the model's own verbalized self-estimates, demonstrating a systematic gap between implicit planning in hidden states and explicit self-awareness.

## Results

MLP probes trained on LLM prompt hidden representations achieve non-trivial prediction accuracy across all six response-planning tasks. For regression tasks (response length, reasoning steps), fine-tuned models (e.g., Llama-3-8B-Instruct, Qwen2-7B-Instruct) show strong linear correlations with ground truth, clustering around y=x, while base models show weaker but positive correlations. For classification tasks (character choices, multiple-choice answers, answer confidence, factual consistency), F1 scores are significantly above random baselines across all eight models tested. Cross-dataset generalization (e.g., GSM8K→MATH, TinyStories→ROCStories) maintains strong correlations and above-baseline F1, confirming the patterns are task-intrinsic rather than dataset-specific.

## Baselines & Comparisons

This paper does not compare against external methods; instead, it establishes internal baselines to validate the emergent planning hypothesis. Fine-tuned (instruction-tuned) models consistently outperform their base counterparts on all six tasks, with the gap most pronounced on structure attributes (response length, reasoning steps), suggesting fine-tuning reinforces structural planning. In-dataset probing outperforms cross-dataset probing in absolute accuracy, but cross-dataset results remain well above random, ruling out dataset-specific memorization. Most strikingly, probe-based predictions substantially outperform the models' own verbalized self-estimates: base models achieve near or worse-than-random accuracy when asked to self-estimate response length or character choices, while fine-tuned models improve only marginally—demonstrating a systematic gap between implicit planning encoded in hidden states and explicit self-awareness. Scaling experiments across four model families (1.5B–72B) confirm that planning ability increases with model size within each family, though the scaling pattern does not transfer across families.

## Relation to Prior Work

This paper repurposes the standard MLP probing methodology from interpretability research (logit lens, tuned lens, representation engineering) but redirects it toward a new target: predicting the model's own future global response attributes rather than external task features. It departs from prior 'lookahead' studies (Future Lens, Geva et al., Men et al., Wu et al.) that examined narrow phenomena like a few-token-ahead distributions or knowledge retrieval in specialized settings, by proposing the first formal definition of 'response planning' as a comprehensive framework spanning structure, content, and behavior attributes across diverse real-world tasks. The conceptual lineage is thus interpretability probing + the next-token-prediction critique, but the systematic multi-attribute, multi-task investigation is new.

## Why It Matters / Open Questions

The findings challenge the dominant narrative that LLMs are purely local next-token predictors, suggesting instead that prompt representations already encode a 'plan' for the entire response. The systematic gap between probed (implicit) planning and verbalized (explicit) self-awareness is particularly striking and raises open questions about what models 'know' versus what they can articulate. Practical applications—pre-generation resource allocation, early error detection, and generation steering—are promising but remain speculative; the paper provides no causal evidence that intervening on these representations actually changes outputs. Key limitations include reliance on greedy decoding (sampling behavior is unexplored), absence of causal intervention experiments, and the finding that planning scaling does not generalize across model families, suggesting architecture-specific factors at play.

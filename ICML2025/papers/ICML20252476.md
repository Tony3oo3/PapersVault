## Problem

State-of-the-art visual generative AI models can produce content that closely resembles IP-protected characters (e.g., Spider-Man, Iron Man, Superman) even when the input prompt only describes the character's visual attributes without naming them, yet no systematic benchmark or effective, training-free defense method exists to evaluate and mitigate this infringement in black-box settings.
![Teaser figure](../imgs/ICML20252476/cropped_page1_idx2.webp)

## Input / Output

The system accepts a free-form text prompt (either a name-based prompt like 'Generate an image of Spider-Man' or a description-based prompt of up to 50 tokens for Stable Diffusion models) and outputs a generated image or video. The pipeline additionally produces an intermediate detection signal from a vision-language model indicating whether the generated content infringes on a specific protected character, and if so, triggers a second diffusion pass to produce a revised image. Evaluation of infringement is performed by five human inspectors rather than algorithmic metrics, since L2 and LPIPS distances were shown to poorly correlate with human judgments of IP similarity.

## Method

TRIM (inTellectual pRoperty Infringement Mitigating) is a three-stage, training-free defense for diffusion-based text-to-image models. First, GPT-4 screens the input prompt and rejects any that directly name a protected character. Second, the image is generated via the standard classifier-free guidance (CFG) diffusion process. Third, GPT-4V inspects the generated image against a list of protected characters; if infringement is detected, the image is regenerated using a modified CFG formula in which the unconditional branch (empty string) is replaced by the name of the detected infringing character, effectively using it as a targeted negative prompt that steers the denoising away from that character while preserving alignment with the original user prompt. The guidance weight w is set to 7.5, and the ablation shows that using only the detected character's name as the negative prompt (5.8% infringement rate) is far more effective than using all protected character names simultaneously (42.6%), confirming that targeted suppression minimizes collateral damage to generation quality.

## Results

With name-based lure prompts, all seven evaluated models achieve nearly 100% IP infringement rates across six protected characters. With description-based prompts (no character name), infringement rates still range from 5.8% to 100%, with DALL-E 3 (Microsoft Designer) and Midjourney reaching 100% for Spider-Man. The proposed TRIM defense reduces IP infringement rates to 0.0%–6.4% across Stable Diffusion v1-5, Kandinsky-2-1, and Stable Diffusion XL, while only slightly degrading CLIP Score (31.67 → 29.71 average). Against existing memorization-mitigation baselines on SDXL/Spider-Man, TRIM achieves 5.8% infringement rate versus 69.4% (Somepalli et al.), 30.2% (Ren et al.), and 43.2% (Hintersdorf et al.).

## Baselines & Comparisons

The paper compares TRIM against three inference-time memorization-mitigation methods (Somepalli et al. 2023b, Ren et al. 2024a, Hintersdorf et al. 2024) on Stable Diffusion XL with the Spider-Man character. TRIM achieves a 5.8% IP infringement rate, substantially outperforming all three baselines: Somepalli et al. retains 69.4% infringement (a 63.6-point gap), Hintersdorf et al. retains 43.2% (37.4-point gap), and Ren et al. retains 30.2% (24.4-point gap). The paper argues that these memorization-mitigation methods target near-exact reproduction of training images, whereas TRIM addresses the broader IP infringement problem where generated content merely resembles a protected character. Additionally, TRIM is compared against concept-removal methods (ESD, UCE, ConceptPrune), which the paper notes degrade generation quality significantly (e.g., ESD yields 0.23 LPIPS difference and still retains 11.2% infringement for Spider-Man) and require ~170 minutes per concept, whereas TRIM operates at inference time with negligible quality loss.

## Relation to Prior Work

This paper repurposes classifier-free guidance (Ho & Salimans, 2021) as an inference-time IP suppression mechanism by replacing the unconditional branch with the name of a detected infringing character, rather than the standard empty string. It positions itself against the memorization literature (Carlini et al., Somepalli et al., Hintersdorf et al.) by arguing that near-exact reproduction is not the only infringement risk—outputs that merely resemble protected characters still constitute IP violations. Unlike concept-removal methods (ESD, UCE, ConceptPrune) that require expensive model editing and degrade generation quality, TRIM operates entirely at inference time without retraining, and unlike prior IP-infringement studies that provided isolated examples, this work introduces a systematic black-box evaluation protocol using both name-based and description-based lure prompts.

## Why It Matters / Open Questions

The finding that description-based prompts (containing no character names) still trigger IP infringement rates as high as 93.8% challenges the common assumption that simply avoiding character names in prompts is sufficient to sidestep legal risk, with direct implications for how generative AI platforms design their content moderation. The defense is practical (inference-time, no retraining, minimal CLIP score degradation) but is limited to diffusion-based models and a small set of well-known characters; open questions include transferability to autoregressive and hybrid architectures, robustness against adaptive jailbreak attacks, and whether the human-evaluation-based infringement metric aligns with actual legal standards. The paper also highlights that standard algorithmic similarity metrics (LPIPS, L2) are unreliable proxies for IP infringement severity, an important caveat for anyone building automated detection pipelines.

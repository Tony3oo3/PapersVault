## Problem

While Transformers can perform variable binding in practice, it remains unclear how they acquire this capability during training and what internal mechanisms they develop. Classical architectures implement variable binding via explicit addressable memory, but it is not well understood how neural networks lacking such built-in operations can learn to associate variables with values through chains of assignments. This paper investigates the developmental trajectory and causal mechanisms by which a Transformer learns systematic variable dereferencing from scratch.

## Input / Output

The model receives a 17-line synthetic program (16 variable assignment statements plus a final query line) using a character-level tokenizer, where variables are single lowercase letters (a–z) and values are single digits (0–9). Each assignment line follows a fixed four-token structure (variable, '=', RHS token, newline), and programs contain variable reference chains up to 4 hops deep alongside distractor chains that branch from or are independent of the query chain. The model must output the single numerical constant (0–9) ultimately bound to the queried variable, requiring it to traverse the relevant assignment chain while ignoring irrelevant branches.

## Method

The paper trains a 37.8M-parameter GPT-2-like Transformer (12 layers, 8 heads, 512-dim residual stream, RoPE) from scratch on 500K synthetic programs via standard causal language modeling, then applies interchange interventions to reverse-engineer the learned mechanism. Causal tracing experiments replace residual stream activations and individual attention head outputs with values from counterfactual programs (where the root numerical value is changed), revealing that the model uses the residual stream as an addressable memory space with specialized attention heads (e.g., heads 6.5, 7.7 for hop 1; 7.2, 8.3, 9.4 for hops 2–3; 11.2, 11.3, 11.7 for final output) routing variable values along the query chain across layers. A key finding is that the model develops a three-phase trajectory—random prediction, early-line heuristics, then systematic binding—and that the final solution builds upon rather than replaces the earlier heuristics, with the line-1 heuristic persisting throughout training. PCA and L1-regularized linear probing further identify separate numerical-constant (10 components) and variable-name (26 components) subspaces in the residual stream, confirmed causally via subspace-specific interchange interventions achieving 92% and 87% success rates respectively.

## Results

The 37.8M-parameter Transformer (12 layers, 8 heads, 512-dim residual stream) achieves >99.9% test accuracy on variable dereferencing after 105,400 training steps, progressing through three distinct phases: chance-level (~12%) random number prediction, a shallow line-position heuristic phase (~56%), and a systematic variable-binding phase (>99%). Causal interchange interventions on the residual stream confirm the model uses it as addressable memory, with specialized attention heads (6.5, 7.7, 7.2, 8.3, 9.4, 11.2, 11.3, 11.7) routing information along assignment chains. Subspace interventions targeting identified numerical-constant (10 PCA components) and variable-name (26 PCA components) subspaces yield 92.17% and 87.08% patching success rates, respectively. Linear probing at newline positions fails to recover explicit program state (best: 30.87% variable accuracy at layer 6, 8.90% full-state accuracy), indicating the model tracks only relevant bindings dynamically rather than maintaining a complete execution state.

## Baselines & Comparisons

This paper is a single-model mechanistic interpretability study rather than a method comparison, so there are no external baselines to benchmark against. The internal 'comparison' is between the model's own developmental phases: the Phase 2 line-1 heuristic achieves >90% accuracy on programs where the answer appears on line 1, and ~65% on line 2, but fails on deeper chains; the Phase 3 systematic mechanism generalizes to all hop counts (tested up to 13 hops vs. 4 in training) and all answer positions. Notably, the final model retains the line-1 heuristic (consistently >80% patching success at the layer-2 colon token) while layering the systematic circuit on top, rather than replacing it—a finding that contrasts with the 'grokking' narrative where early heuristics are discarded. The model also generalizes to unseen variable/number combinations (10% held out) with comparable accuracy, ruling out memorization.

## Relation to Prior Work

This paper extends the interchange intervention methodology of Vig et al. (2020) and Geiger et al. (2020) by replacing noise-based causal tracing (Meng et al., 2022) with counterfactual activation swaps, enabling cleaner attribution of information flow in a controlled synthetic setting. It builds on prior mechanistic interpretability work that identified variable binding circuitry in pretrained LLMs (Davies et al., 2023; Feng & Steinhardt, 2024; Dai et al., 2024), but shifts the focus from static analysis of trained models to a developmental perspective—tracking how binding mechanisms emerge from scratch across training checkpoints. The synthetic program task is positioned as complementary to LEGO (Zhang et al., 2023) and hashhop, emphasizing sequential execution order and distractor handling rather than length generalization or graph path-finding.

## Why It Matters / Open Questions

The finding that the model's systematic variable-binding circuit builds upon (rather than replaces) its earlier line-position heuristics directly challenges the prevailing 'grokking' narrative of strategy replacement, suggesting cumulative learning where simpler strategies persist as fast paths. The concrete mechanistic account—residual stream as addressable memory with specialized attention heads routing information hop-by-hop—provides a template for understanding how symbolic operations emerge from continuous vector operations without explicit architectural support. Open questions include whether this developmental trajectory and the heuristic-persistence pattern generalize to more complex symbolic tasks, larger models, or natural-language settings, and whether the specific layer-to-hop correspondence (layers 6–9 for depths 1–4) reflects a general inductive bias or is task-specific.

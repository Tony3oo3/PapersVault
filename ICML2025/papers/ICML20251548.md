## Problem

Multi-vector retrieval (MVR) performance depends critically on how queries are decomposed into sub-queries, yet this decomposition is non-differentiable and has not been optimized end-to-end for downstream retrieval-based systems. Existing strategies—token-level splitting (ColBERT) or manually crafted LLM prompts—produce sub-queries that either miss key phrases or introduce irrelevant tokens, degrading retrieval and QA accuracy.

## Input / Output

The method takes a text query and a document or image corpus as input. It produces decomposed sub-queries (phrases of arbitrary granularity composed of tokens from the original query, with hallucinated tokens filtered out) that drive multi-vector retrieval via MaxSim scoring. For image QA, images are segmented into superpixels via SLIC and embedded with CLIP; for text QA, documents are decomposed into sentences and embedded with Sentence-BERT. The retrieved items then feed a generator model (Llama3.1-8B or LLaVA-v1.5-7B) to produce the final QA answer.

## Method

POQD employs two LLMs: a Prompt Optimizer (adapted from LLM-as-optimizer) that iteratively refines a prompt prefix using a solution-score pair list, and a Query Decomposer that uses this prompt to generate sub-queries for each training query. The key training algorithm (Algorithm 2) alternates between (1) optimizing the prompt via Algorithm 1—which evaluates each candidate prompt by computing the RAG training loss on a fixed downstream model Θ—and (2) fine-tuning Θ for only τ iterations (default 3) with the newly optimized sub-queries. A theoretical guarantee (Theorem 4.4) under μ-PL* and L-smoothness assumptions shows that with appropriate α and τ, the converged loss strictly decreases across prompt updates, ensuring each prompt refinement is beneficial. The optimization is weakly-supervised, targeting end-to-end RAG accuracy rather than intermediate retrieval metrics, and the retrieval model β remains frozen throughout training for efficiency.

## Results

POQD achieves the best end-to-end QA accuracy across all four datasets and both image and text QA tasks. The largest gain is on MultiModalQA image QA, where POQD reaches 61.74% exact-match accuracy, outperforming the strongest baseline (ColBERT-orig at 49.13%) by 12.61 points. On retrieval, POQD improves Hit@2 on ManyModalQA text QA to 92.35% versus 87.07% for ColBERT-orig (+5.28 points), and Hit@1 on MultiModalQA image QA to 58.26% versus 54.34% for ICL-QD. On the multi-hop StrategyQA benchmark, POQD attains 75.55% QA accuracy, surpassing the best baseline (S-QD at 73.33%) by 2.22 points.

## Baselines & Comparisons

POQD consistently outperforms all six baselines on every dataset and both retrieval and QA accuracy metrics. Against ColBERT (token-level decomposition), POQD gains up to 19.13 points on ManyModalQA text QA (81.27 vs. 62.14) and 12.61 points on MultiModalQA image QA (61.74 vs. 49.13 for ColBERT-orig), confirming that token-level decomposition is fundamentally suboptimal for MVR. Compared to supervised (S-QD) and unsupervised (U-QD) decomposition, POQD avoids the need for human-annotated sub-queries while still achieving superior results, e.g., 75.55% vs. 73.33% on StrategyQA. Against the in-context learning baselines (ICL-QD and ICLF-QD), which use manually crafted prompts, POQD's learned prompt optimization yields consistent gains of 1–6 points, with the largest margin on MultiModalQA image QA (61.74 vs. 46.78 for ICL-QD). The query rewrite baseline (Ma et al., 2023) underperforms POQD by 9.71 points on WebQA text QA (52.16 vs. 61.87), highlighting that rewriting a single query is less effective than decomposing into multiple sub-queries for multi-vector retrieval.

## Relation to Prior Work

This paper builds on ColBERT's multi-vector retrieval framework (which decomposes queries into individual tokens) and the LLM-as-optimizer paradigm (Yang et al., 2024) for prompt search, but departs from both in a key way: it reframes query decomposition as a performance optimization problem for downstream RAG systems rather than a fixed tokenization or a multi-hop QA reasoning step. Prior query decomposition work (S-QD, U-QD, ICL-QD) targets question decomposition for step-by-step reasoning, while POQD optimizes the decomposition prompt end-to-end against RAG loss, using an LLM-based optimizer to iteratively refine the prompt with only a few epochs of generator training per iteration. The theoretical analysis connects to the PL* convergence literature for over-parameterized LLMs fine-tuned with GaLore.

## Why It Matters / Open Questions

POQD offers a lightweight, plug-and-play way to improve arbitrary RAG pipelines without retraining retrieval models or rebuilding indexes, which is practically significant given the cost of corpus re-embedding. The theoretical guarantee (Theorem 4.4) that τ=3 epochs per prompt update suffices for convergence under PL* conditions provides a principled stopping criterion, though the PL* assumption may not hold for all architectures or fine-tuning regimes. Open questions include whether the approach scales to very large corpora where retrieval evaluation becomes the bottleneck, how it interacts with other MVR improvements (e.g., ColBERTv2's lightweight late interaction), and whether the LLM-based decomposition step introduces unacceptable latency in production RAG systems.

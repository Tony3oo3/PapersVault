## Problem

Establishing a duality in lattice statistical mechanics requires constructing a dual Hamiltonian and a map between original and dual observables, a task that has historically relied on hand-crafted algebraic arguments. No systematic, automated framework existed for searching for such dualities, and even for well-studied deformations like the plaquette-coupled Ising model, explicit dual descriptions remained unknown. This paper formalizes duality discovery as a differentiable optimization problem solvable with neural networks and MCMC.

## Input / Output

The method takes as input the original Hamiltonian's coupling parameters (β, κ) on a fixed lattice (8×8 with periodic boundaries in main experiments) and a set of link-product observables O_ij = σ_iσ_j. It produces the dual coupling parameters (β̃, κ̃) and a learned mapping G that transforms dual link products into original-frame observables. Unusually, the input is consumed through simultaneous MCMC sampling from both the original and dual Hamiltonians at each training step, and the output G implicitly encodes the dual lattice geometry via its attention pattern over the 7 neighboring links of each input link.

## Method

The observable mapping G is parameterized as a single-layer network with Gumbel-Softmax hard attention over 7 nearby dual link products, reducing to a weighted sum plus bias (θ₂·Gumbel-Softmax(θ₁)ᵀf + θ₃). The loss function explicitly matches spatially-averaged moments (features) of small clusters of nearby link products between the original and dual models, avoiding the locality-blindness of standard moment-matching kernels. Gradients with respect to the dual couplings are computed analytically via the score-function identity (relating ∂β̃⟨O⟩ to covariance terms) rather than backpropagating through the stochastic MCMC sampler, while gradients for G's parameters use standard automatic differentiation. A key practical contribution is a variance-reduction scheme combining a running average of the (fixed) target features with a control-variate baseline, which the authors show is essential for convergence when multiple couplings are present. The framework simultaneously learns the dual temperature mapping, the observable dictionary, and the dual lattice geometry (revealed by which input link the attention mechanism selects).

## Results

The framework numerically recovers the Kramers-Wannier duality line sinh(2β)sinh(2β̃)=1 for the 2D Ising model on 8×8 lattices, with successful runs achieving loss values as low as 1e-7. For the plaquette model (300 experiments across β∈{0.15, 0.2, 0.25, 0.3, 0.35} × κ∈{0, 0.1, 0.2}), no exact self-duality is found for κ≠0, but 'approximate duals' emerge along lines β̃+κ̃=const when κ=0, validated by matching 101 out-of-training-loss features on 24×24 lattices. The control variate variance reduction technique yields a clear improvement in convergence, with the area under the success-rate curve (fraction of runs recovering known targets within tolerance ε) substantially larger than without variance reduction (Figure 8).

## Baselines & Comparisons

The paper does not benchmark against competing ML duality-discovery methods in a quantitative head-to-head comparison. The primary 'baseline' is the known analytical Kramers-Wannier duality, which the framework successfully rediscoveres numerically for the 2D Ising model (Figure 4), confirming the method's correctness. The only internal quantitative comparison is between the proposed control-variate gradient estimator (Eq. 17) and the naive MCMC gradient (Eq. 15): Figure 8 shows that runs with variance reduction consistently achieve lower maximum deviation Δ in recovered parameters (β, G_θ(+1), G_θ(−1), κ) across all tolerance thresholds ε, indicating substantially better convergence. The authors note qualitatively that their approach differs from Betzler & Krippendorf (2020) in that it does not require pre-knowledge of the temperature mapping and performs a single sampling step followed by a deterministic mapping, but no numerical comparison is provided. For the plaquette model, the 'negative result' (no self-duality for κ≠0) is itself a finding, as no prior explicit study of duals to this model existed.

## Relation to Prior Work

This paper carves new ground by formulating duality discovery in lattice statistical mechanics as a joint optimization problem over both the dual Hamiltonian couplings and a neural-network-parameterized observable mapping. The closest prior work, Betzler & Krippendorf (2020), requires two separate sampling steps and a pre-known temperature mapping in its loss function, making it incapable of discovering new dualities; the present approach samples once in the dual frame and learns the full mapping end-to-end. The connection to Boltzmann machine learning is acknowledged but distinguished by the simultaneous learning of the observable dictionary, and the gradient-through-MCMC computation (Eq. 15) is a technical contribution not present in standard contrastive-divergence training.

## Why It Matters / Open Questions

This is a proof-of-concept that automated duality discovery is feasible, but significant limitations remain: the method relies on hand-crafted local features, struggles near phase transitions and in the symmetry-broken phase, and lacks an efficient training algorithm (contrastive divergence is inapplicable due to the observable mapping). The discovery of 'approximate duals' along lines of β̃+κ̃=const in the plaquette model reveals a dilute-gas universality where all observables collapse to a single parameter, suggesting that matching this parameter alone suffices for a 'dual' description in the ordered phase. The central open question is whether this framework can discover genuinely new dualities beyond deformed Ising models, which would require scaling to larger coupling spaces and more sample-efficient optimization.

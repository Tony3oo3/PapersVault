## Problem

When a pre-trained foundation model is updated to a new release, fine-tuned models become obsolete and typically require costly retraining on the same downstream data, which may no longer be available due to privacy or storage constraints. Existing model re-basin methods (Git Re-Basin, Optimal Transport) handle MLPs and CNNs but fail on Transformer architectures: they cause 'head contamination' by mixing units across attention heads and do not preserve functional equivalence through residual connections. This paper asks whether a task vector can be transported to a new checkpoint in a fully data-free, training-free manner while maintaining both task-specific performance and generalization.

## Input / Output

The method consumes two same-architecture Transformer weight sets (θ_A from an older pre-training run and θ_B from a newer release, e.g., CommonPool vs. DataComp for CLIP ViT-B/16) and a task vector τ = θ_A^ft − θ_A computed from a prior fine-tuning. It produces a permuted task vector π(τ) that is added to θ_B with a scalar (or per-layer) scaling factor α, yielding θ_B + α·π(τ). The permutation set π is computed once per (θ_A, θ_B) pair and is reusable across any number of task vectors derived from θ_A, enabling multi-task merging at the destination without additional alignment cost.

## Method

TransFusion introduces a two-level permutation strategy tailored to multi-head attention: (1) inter-head alignment matches head pairs between θ_A and θ_B using a permutation-invariant spectral distance (Euclidean distance between singular values of Q, K, V sub-matrices), solved via the Hungarian algorithm; (2) intra-head alignment then permutes individual units within each matched head pair via standard linear assignment. This hierarchical design prevents head contamination and is proven (Theorem 3.1) to preserve functional equivalence of the attention module. Residual connections are handled by replacing identity skip mappings with composed permutation matrices (I_i = P_{W0}·P_in^T), ensuring both addends in each residual sum share the same permutation. The resulting permutation π is applied to the task vector τ rather than to θ_A directly, so the transported model θ_B + α·π(τ) inherits the superior zero-shot capabilities of θ_B while gaining task-specific knowledge, all without a single training step or data point.

## Results

On four visual classification tasks (EuroSAT, DTD, GTSRB, SVHN), TransFusion achieves consistent positive task-accuracy gains over the θ_B zero-shot baseline: +4.95 on EuroSAT, +0.21 on DTD, +1.10 on GTSRB, and +3.64 on SVHN, while preserving support-set (ImageNet-R) accuracy within 0.5 points. On four GLUE NLP tasks, TransFusion yields gains of +6.50 (QQP), +5.96 (SST2), +3.61 (RTE), and +2.49 (COLA) over the θ_B baseline. All results are obtained in a fully data-free and training-free manner, with no access to downstream task data or any training step.

## Baselines & Comparisons

TransFusion outperforms both baselines on every task in both the visual and NLP evaluations. Against GiT Re-Basin, TransFusion achieves substantially larger task-accuracy gains: +4.95 vs. +0.95 on EuroSAT, +3.64 vs. +0.79 on SVHN, and +6.50 vs. +3.58 on QQP, while also avoiding the negative DTD result (−0.91) that GiT Re-Basin suffers. Against Optimal Transport (Imfeld et al., 2024), the advantage is even more pronounced: OT produces large negative drops on EuroSAT (−14.05) and SVHN (−12.30) in the visual setting and on QQP (−8.31) in NLP, whereas TransFusion consistently yields positive gains. On the support set (ImageNet-R), TransFusion preserves generalization within 0.5 points of the θ_B baseline, while naive task-vector addition degrades support accuracy by up to 16 points. The paper also demonstrates that TransFusion is the first method to preserve functional equivalence during weight-space interpolation between two Transformer models, as verified by loss-landscape analysis on CIFAR-10.

## Relation to Prior Work

This paper extends the Git Re-Basin framework (Ainsworth et al., 2023), which aligns models via permutation symmetries to enable weight-space interpolation, from MLPs/CNNs to Transformer architectures. The key departure is a two-level permutation strategy for multi-head attention—first matching head pairs via a permutation-invariant spectral (SVD-based) distance, then permuting within matched heads—that avoids the 'head contamination' problem inherent in treating all heads as a single projection. The transport mechanism operates on task vectors (Ilharco et al., 2023), repurposing the re-basin alignment not for model merging per se but for relocating fine-tuning knowledge onto a new pre-training checkpoint in a data-free manner.

## Why It Matters / Open Questions

The practical motivation—avoiding costly retraining when a foundation model is updated, especially when downstream data is unavailable due to privacy constraints—is compelling for production ML pipelines. The paper demonstrates that both Optimal Transport and Git Re-Basin fail to preserve functional equivalence on Transformers (high loss at α→0 in interpolation), identifying a concrete gap that the two-level approach fills. Limitations include modest gains (typically 1–5 points), dependence on the source fine-tuning quality (DTD's 75% accuracy caps the transfer), and restriction to identical architectures. Open questions include extending to different layer counts, incorporating activation-based matching metrics, and combining with few-shot fine-tuning for stronger results.

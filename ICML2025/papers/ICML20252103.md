## Problem

Prior theoretical guarantees for learning low-rank preference matrices from pairwise comparison data were established only for convex formulations, which are computationally infeasible at scale. The nonconvex matrix factorization approach used in practice (e.g., BPR) lacked provable recovery guarantees, a gap explicitly flagged as an open problem by Negahban et al. (2018). This paper provides the first such guarantees for the nonconvex formulation in a sparse data regime where each user compares only a few item pairs.

## Input / Output

The method consumes a sparse dataset of m i.i.d. triplets (user u, item pair (i,j), outcome w), where each user is sampled uniformly and each item pair is drawn uniformly from all n₂(n₂−1) distinct pairs. Unlike standard matrix completion where each observation involves a single (user, item) entry, here each data point involves a pair of items and the observed outcome is the expected choice probability g(x_{u,i} − x_{u,j}) under a Plackett-Luce model. The output is the rank-r factor matrix Z ∈ ℝ^{(n₁+n₂)×r}, from which user features, item features, and the full user-item utility matrix X = UVᵀ are recovered up to an orthogonal rotation.

## Method

The paper formulates learning as minimizing a nonconvex negative log-likelihood over a symmetric factor matrix Z (via the Burer-Monteiro reduction X = ZZᵀ), augmented with a regularizer to break scale invariance, and applies projected gradient descent with two successive projections—onto a set of incoherent matrices and onto a subspace that factors out shift invariance. The key technical contribution is establishing concentration inequalities for the empirical loss using the matrix Bernstein inequality, which is necessary because the sampling structure (user + item-pair triplets) breaks the projection-operator interpretation available in standard matrix completion. Within a neighborhood of the true solution, the paper proves the loss satisfies strong convexity and smoothness properties, yielding exponential convergence at rate (1 − αη/4)ᵗ. The guarantees hold in a sparse regime requiring m = O((μrκ/τ)²n log n) samples, with a warm start and noiseless comparison observations.

## Results

The main theoretical result (Theorem 4.1) establishes that projected gradient descent converges exponentially at rate (1 − αη/4)ᵗ to the ground-truth features, requiring m ≥ 10⁷(μrκ/τ)²n log(8n/δ) samples. In simulations on synthetic data with (n₁,n₂) = (200,300) and (2000,3000), r=3, μ≈1.01, κ=1.1, the algorithm exhibits linear convergence as predicted, with the empirical convergence rate significantly faster than the theoretical bound. Notably, the warm-start initialization and projection steps required for the theoretical guarantee are not necessary in practice — the algorithm converges from random initializations (ϑ up to 2.0) without projections. The theoretical sample complexity constants are shown to be conservative: the empirical threshold for convergence is roughly 1/4 to 1/2 of the theoretical m.

## Baselines & Comparisons

This paper does not compare against competing methods in the traditional benchmark sense, as it provides the first theoretical recovery guarantees for the nonconvex matrix factorization formulation of learning from pairwise comparisons. The implicit comparison is between the convex formulation (Negahban et al., 2018; Park et al., 2015), which has optimal sample complexity but is computationally infeasible at scale, and the nonconvex factorization approach analyzed here, which is computationally efficient but previously lacked theoretical guarantees. The simulations validate that the nonconvex approach achieves the same qualitative convergence behavior as predicted by theory, and that the practical constants are far more favorable than the worst-case theoretical bounds. The paper also notes that prior works (Rendle et al., 2009; Park et al., 2015) applied near-identical nonconvex methods to real datasets but without convergence guarantees, which this work now provides.

## Relation to Prior Work

This paper extends the nonconvex matrix factorization analysis of Zheng & Lafferty (2016) and Keshavan et al. (2010a) to the setting of learning from pairwise comparisons, where the sampling structure (user + item-pair rather than user + item) breaks the standard projection-operator interpretation used in matrix completion. The algorithm itself is nearly identical to the nonconvex method proposed by Park et al. (2015), but prior theoretical guarantees (Park et al. 2015; Negahban et al. 2018) only covered the convex formulation over the full utility matrix. The key technical departure is deriving new concentration inequalities via the matrix Bernstein inequality to handle the altered sampling geometry, filling the open problem explicitly flagged by Negahban et al. (2018).

## Why It Matters / Open Questions

This is the first provable recovery guarantee for the computationally efficient nonconvex formulation of comparison-based collaborative filtering, establishing that learning personalized preferences from sparse pairwise comparisons is both statistically and computationally feasible. Two significant limitations temper the practical impact: the analysis assumes noiseless observations (expected choice probabilities rather than binary outcomes) and requires a warm start close to the ground truth, both of which are relaxed in practice but not in theory. Open questions include extending the analysis to noisy binary comparisons, proving convergence from random initialization, and empirically validating whether comparison-based feedback yields better recommendations than rating-based feedback at scale.

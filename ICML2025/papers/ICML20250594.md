## Problem

LLM-based agents struggle with long-horizon tasks because they are not inherently trained to generate accurate, structured plans that decompose high-level user goals into actionable steps. While separating planning from execution improves performance, the planning component remains a bottleneck: off-the-shelf LLMs produce suboptimal or ungrounded plans for environments outside their pretraining distribution, and high-quality planning training data is scarce and expensive to collect manually.
![Teaser figure](../imgs/ICML20250594/cropped_page0_idx0.webp)

## Input / Output

The PLANNER receives a natural-language user query and the initial HTML state of the webpage, producing a structured plan formatted as numbered steps each containing a reasoning trace and a high-level action description. The EXECUTOR receives this plan, the current HTML, and the prior action trajectory, outputting a single grounded web action (e.g., click on element ID, type a string into a field) per step. After each action, the PLANNER is re-invoked with the updated HTML and prior plans/actions to generate a revised plan (dynamic replanning), and the cycle continues until the EXECUTOR emits a task-completion message.

## Method

PLAN-AND-ACT decouples a PLANNER (strategic decomposition) from an EXECUTOR (action grounding) and introduces a three-stage synthetic data pipeline to train both without manual annotation: (1) Alpaca-style query generation seeds a demonstrator agent to collect action trajectories, filtered by an outcome reward model; (2) a teacher LLM reverse-engineers grounded high-level plans from successful trajectories, explicitly mapping each plan step to the low-level actions it subsumes; (3) the resulting query-plan pairs are expanded via LLM-based generation (10k+ pairs) and further augmented with 5k targeted examples identified through failure-pattern analysis on a held-out set. Dynamic replanning—where the PLANNER regenerates the remaining plan after every EXECUTOR step—allows the plan to carry forward discovered context (e.g., identified entity names) and adapt to unexpected environment states, eliminating the need for a separate memory module. Chain-of-thought reasoning traces are additionally generated for both components to improve inference-time performance.

## Results

On WebArena-Lite, PLAN-AND-ACT achieves a state-of-the-art 57.58% task success rate (with CoT reasoning), surpassing the previous SOTA WebRL-3.1-70B (49.1%) by 8.48 percentage points. On the full WebArena benchmark, PLAN-AND-ACT reaches 45.7% (Llama-70B) and 48.15% (QWQ-32B), matching or exceeding all prior methods. On WebVoyager, the QWQ-32B variant sets a new text-only SOTA at 81.36%, outperforming the previous best Agent-E (73.1%) by 8.26 points.

## Baselines & Comparisons

On WebArena-Lite, PLAN-AND-ACT (57.58%) decisively outperforms all baselines: WebRL-3.1-70B (49.1%), WebPilot+GPT-4o (37.2%), AWM+GPT-4-0613 (35.5%), GPT-4-Turbo (17.6%), and GPT-4o (13.9%). On the full WebArena benchmark, PLAN-AND-ACT with QWQ-32B (48.15%) surpasses AgentOccam-Judge (45.7%), WebPilot (37.2%), AutoWebGLM (18.2%), and NNetNav (16.3%), while the Llama-70B variant (45.7%) ties AgentOccam-Judge. On WebVoyager, PLAN-AND-ACT with QWQ-32B (81.36%) beats Agent-E (73.1%), WebVoyager multimodal (57.1%), Wilbur (52.6%), and all open-source baselines including NNetNav (34.2%) and OpenWebVoyager (27.4%). Notably, even the 8B model (58.08%) outperforms all prior open-source methods on WebVoyager, and the framework achieves strong results without requiring RL or closed-source models at inference time.

## Relation to Prior Work

PLAN-AND-ACT extends the two-module PLANNER/EXECUTOR architecture from LLMCompiler (Kim et al., 2023b) by introducing a scalable synthetic data generation pipeline that enables supervised fine-tuning of both components, a capability LLMCompiler lacked. For trajectory collection and ORM-based filtering, it adapts techniques from WebRL (Qi et al., 2024), while the Alpaca-style (Taori et al., 2023) query generation pipeline is repurposed for plan expansion. The key departure from prior hierarchical web agents (AgentOccam, WebPilot, AdaPlanner) is the combination of explicit dynamic replanning with a systematic, simulator-free synthetic data generation method for open-source LLMs, rather than relying on prompting closed-source models or RL.

## Why It Matters / Open Questions

The paper demonstrates that explicit planning separation plus synthetic data generation can match or exceed RL-based approaches (WebRL) using simpler supervised fine-tuning, with the synthetic pipeline generating 15K training examples in under an hour versus days of environment interaction. The finding that a well-formed dynamic plan substantially improves even an untrained EXECUTOR (44.24% vs. 9.85% baseline) suggests plan quality is the primary bottleneck for long-horizon web agents, redirecting effort toward planning rather than execution. Open questions include the inefficiency of replanning after every action, the dependency on a capable baseline model for initial trajectory collection (limiting applicability to domains without training data), and whether the framework generalizes beyond web navigation to other structured decision-making environments.

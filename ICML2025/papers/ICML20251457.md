## Problem

As LLM context lengths extend to 128K+ tokens, the KV cache becomes the dominant GPU memory bottleneck, often exceeding model weights by 5×. Existing scalar-level quantization methods (KIVI, KVQuant) suffer severe accuracy collapse at 1–2 bits, while the one vector-quantization baseline (VQLLM) introduces prohibitive decoding overhead that negates its memory savings. No prior method simultaneously achieves near-lossless 1-bit KV cache compression and low computational overhead during self-attention decoding.

## Input / Output

The method consumes per-token d-dimensional key and value vectors (e.g., 1024-dim for LLaMA-3.1-8B) from the KV cache and produces a compressed representation: keys are encoded as R groups of 2D integer codes (each requiring 2·log₂(N_c′) bits, shared across g consecutive sub-vectors), while values are encoded as binary sequences of length N_c. Decoding reconstructs approximate key/value vectors via codebook lookup and matrix multiplication, which are then fed directly into the self-attention computation. The codebook is learned offline on a FineWeb-Edu calibration subset and stored in FP16 (≈5 MB total for 2-bit, ≈4.75 MB for 1-bit), negligible relative to the multi-GB KV cache it replaces.

## Method

CommVQ applies additive vector quantization at the per-token vector level rather than per-scalar, using a learned encoder (two linear layers with Gumbel-softmax) to map each d-dimensional key/value vector to a low-bitwidth code. The key innovation is designing the key codebook to be commutative with RoPE: each 2×2 codebook block takes the form [[x, y], [−y, x]], guaranteeing R_i^j C_K^{jl} = C_K^{jl} R_i^j. This commutativity allows the term (q R_t) C_K^{j l T} to be pre-computed once and reused across all N cached tokens, reducing decoding overhead from N_c× vanilla attention to approximately (R+1)/2×. The codebook is trained via an EM clustering algorithm with soft assignment and temperature annealing for stability, and residual quantization (R iterations on the reconstruction error) plus sub-vector grouping (g sub-vectors sharing one code) jointly control the compression rate. For values, a simple reordering—multiplying softmaxed attention weights by the binary code matrix S_V before the codebook C_V—reduces complexity from O(dN_cN) to O(N_cN + dN_c).

## Results

On LongBench (LLaMA-3.1-8B-Instruct), CommVQ-2 achieves an average score of 47.98 at 2.00 Avg. bit, nearly matching the FP16 baseline (48.05) while reducing KV cache memory by 87.5%. At 1-bit quantization (1.03 Avg. bit), CommVQ-1 retains 44.94 average on LongBench and 66.57 on GSM8K, far exceeding all baselines at comparable compression. On GSM8K, CommVQ-2 scores 76.04 (vs. 76.27 FP16), a mere 0.23% degradation, while baselines drop to 73.69 (KIVI-2) and 52.69 (VQLLM-2). The optimized commutative codebook implementation achieves 6.0–9.6× latency speedup over the naive decode-then-attention approach across 8K–128K context lengths.

## Baselines & Comparisons

Against KIVI (asymmetric quantization), CommVQ-2 achieves a higher LongBench average (47.98 vs. 47.62) while using 33% fewer bits (2.00 vs. 3.00 Avg. bit); on GSM8K the gap widens to 76.04 vs. 73.69. At 1-bit, CommVQ-1 (44.94 LongBench, 66.57 GSM8K) dramatically outperforms KIVI-1 (16.70 LongBench, 2.20 GSM8K), which essentially collapses. Against KVQuant (non-uniform quantization), CommVQ-2 leads by 2.63 points on LongBench (47.98 vs. 45.35) at a lower bit width (2.00 vs. 2.33); KVQuant-1 is effectively non-functional (5.88 LongBench, 1.14 on Math.F in InfiniteBench). Against VQLLM (residual vector quantization), CommVQ-2 wins by 2.53 points on LongBench (47.98 vs. 45.45) at the same 2.00 Avg. bit, and at 1-bit CommVQ-1 surpasses VQLLM-1 by 17.52 points on LongBench (44.94 vs. 27.42) and by 64.9 points on GSM8K (66.57 vs. 1.67). The advantage is most pronounced in retrieval-heavy tasks (e.g., R.PK, R.Num in InfiniteBench) where scalar-level baselines fail entirely while CommVQ's vector-level codebook preserves critical attention signals.

## Relation to Prior Work

This paper builds on additive quantization (Babenko & Lempitsky, 2014) from signal processing, repurposing it for KV cache compression in LLMs. It departs from scalar-level quantization methods (KIVI, KVQuant) by operating at the vector level, and extends VQLLM's residual vector quantization approach by introducing a RoPE-commutative codebook design that dramatically reduces decoding overhead through algebraic reordering of self-attention computations. The EM-based codebook learning is a standard clustering technique applied in a novel context where the codebook entries must satisfy a specific 2×2 commutative structure with rotation matrices.

## Why It Matters / Open Questions

The ability to achieve 1-bit KV cache quantization with minimal accuracy loss (44.94 vs 48.05 on LongBench) is a significant practical advance, enabling 128K-context inference on a single consumer GPU (RTX 4090) — a capability previously impossible without offloading. The commutative codebook design is a reusable mathematical insight that could inform other RoPE-based architectures. Open questions include whether the approach generalizes to non-RoPE positional encodings, how it interacts with token eviction methods for even higher compression, and whether the calibration set requirements scale to larger models or multilingual settings.

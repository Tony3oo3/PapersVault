## Problem

Selecting the best prompt from a large combinatorial space of instructions and few-shot exemplars for a black-box LLM is challenging due to the absence of gradients, high evaluation cost, and the need to jointly optimize both prompt components. Existing methods either ignore the compositional structure of prompts (treating them as unstructured text blocks) or fail to be simultaneously sample-efficient (evaluating fewer prompts via a surrogate) and query-efficient (reducing total LLM calls by not evaluating every prompt on all validation instances).

## Input / Output

The method takes a finite candidate pool of 250 prompts (5 instructions × 50 few-shot exemplar tuples), a validation set of task-specific input-output pairs, and API access to a black-box LLM. Instructions and exemplars are embedded separately using a pre-trained encoder (e.g., BERT [CLS] token, 768-dim) rather than as a single concatenated text block, preserving structural information. The output is a single prompt selected by lowest validation error on the full validation set, with the total number of LLM calls serving as the cost metric under a fixed budget (25 full-fidelity evaluations).

## Method

HbBoPs combines a structural-aware deep kernel Gaussian Process with Hyperband as a multi-fidelity scheduler. The DK-GP embeds instructions and exemplars through separate two-layer feed-forward networks (d→64→32 each with ReLU), concatenates the 64-dim outputs, and maps them through a final network (64→32→10) to produce a 10-dimensional latent representation on which an ARD Matérn 5/2 kernel operates; kernel and network parameters are jointly trained by maximizing the GP log marginal likelihood. Hyperband governs the number of validation instances (fidelity) each prompt is evaluated on, running multiple Successive Halving brackets with different starting budgets to hedge against the exploration-accuracy trade-off. Within each bracket, a sequential Expected Improvement acquisition function over the finite prompt set replaces random sampling, making the proposal sample-efficient. The GP is retrained online at each step on the highest fidelity level with at least four observations, and validation instances from lower-fidelity stages are cached and reused at higher stages to reduce total LLM calls.

## Results

Across ten benchmarks and three LLMs (Claude 3 Haiku, LLaMA3 8B Instruct, Mistral 7B Instruct), HbBoPs achieves an average normalized test error of 0.150 at full budget, outperforming all full-fidelity methods (HDBO: 0.185, BOPCA: 0.192, EASE: 0.195, MIPROv2: 0.198, Vanilla BO: 0.211) and multi-fidelity competitors (TRIPLE-GSE: 0.158, TRIPLE-SH: 0.159). At a limited budget of 25% of total LLM calls, HbBoPs outperforms the best full-fidelity method (HDBO) by approximately 35% and the best multi-fidelity method (TRIPLE-SH) by 24% in normalized validation error. Statistical analysis (linear mixed effects model, α=0.01) confirms significant improvements over all baselines except TRIPLE-SH (p=0.236), where the positive effect is not statistically significant.

## Baselines & Comparisons

HbBoPs outperforms all five compared methods on average normalized test error at full budget. Against the strongest full-fidelity baseline HDBO (Hvarfner et al., 2024), HbBoPs reduces error from 0.185 to 0.150 (a 19% relative improvement), with the gap widening to ~35% at 25% budget. Against BOPCA (Zhang et al., 2024), EASE (Wu et al., 2024), and MIPROv2 (Opsahl-Ong et al., 2024), HbBoPs achieves 0.042, 0.045, and 0.048 lower normalized test error respectively, all statistically significant (p<1e-4). The closest competitor is TRIPLE-SH (Shi et al., 2024) at 0.159, where HbBoPs's 0.009 improvement is positive but not statistically significant at α=0.01 (p=0.236); TRIPLE-GSE (0.158) is significantly outperformed (p=1e-4). The ablation study confirms that both the structural-aware deep kernel GP (sample-efficiency) and Hyperband scheduling (query-efficiency) contribute independently, with their combination yielding a 66–67% improvement over vanilla BO at 50–100% budget.

## Relation to Prior Work

This paper repurposes Hyperband (Li et al., 2018), originally designed for hyperparameter optimization, as a multi-fidelity scheduler for prompt selection, and extends deep kernel learning (Wilson et al., 2016) by making the GP surrogate structurally aware of prompt composition (separate embeddings for instructions and exemplars). It departs from prior prompt selection methods (EASE, MIPROv2, TRIPLE) by being the first to simultaneously achieve sample-efficiency (via a learned surrogate that proposes which prompt to evaluate next) and query-efficiency (via adaptive allocation of validation instances), whereas existing methods address at most one of these axes. The BO-within-Hyperband proposal mechanism follows the BOHB pattern (Falkner et al., 2018) but applied to a discrete, combinatorial prompt space rather than continuous hyperparameters.

## Why It Matters / Open Questions

The practical relevance is high: LLM API costs make prompt evaluation expensive, and the demonstrated 35% reduction in LLM calls at low budget (vs. the strongest multi-fidelity competitor) translates directly into cost savings for practitioners. However, the method is limited to the static setting with prompts composed solely of instructions and few-shot exemplars, and depends on pre-trained encoder embeddings that introduce minor computational overhead. Open questions include whether the framework extends to multi-objective settings (e.g., balancing accuracy against response latency from longer exemplars), dynamic per-instance prompt selection, and additional prompt components like output formatting constraints. The honest reporting that the full-budget advantage over TRIPLE-SH is not statistically significant (p=0.236) suggests the gains are most meaningful in budget-constrained regimes.

## Problem

Existing CXR interpretation tools (classification, segmentation, report generation, VQA) operate in isolation, hindering practical clinical adoption, while end-to-end foundation models like GPT-4o and CheXagent suffer from hallucinations, inconsistent multi-step reasoning, and lack of transparency. No prior framework dynamically orchestrates multiple specialized CXR tools with LLM-driven reasoning without requiring retraining when new tools are added.
![Teaser figure](../imgs/ICML20250603/cropped_page2_idx0.webp)

## Input / Output

The system accepts a CXR image in any standard radiological format (including DICOM) alongside a free-form natural language query, processed through a multi-turn conversational interface where the agent may request additional user input. Outputs are structured text responses that can incorporate intermediate tool results (segmentation masks, classification probabilities, grounding boxes, generated images, or full radiology reports with findings and impressions), with all intermediate tool outputs displayed for transparency. For benchmark evaluation, responses are parsed via regex to extract six-choice letter answers.

## Method

MedRAX implements a ReAct (Reasoning and Acting) loop where GPT-4o serves as the reasoning engine, iteratively cycling through observation, thought, and action phases to decompose complex queries into sequential or parallel tool calls. Seven specialized tools (CheXagent and LLaVA-Med for VQA, MedSAM and PSPNet for segmentation, Maira-2 for grounding, a SwinV2+BERT model for report generation, DenseNet-121 for classification, and RoentGen for image synthesis) are wrapped in standardized interfaces defining name, description, input schema, and execution logic. The LLM learns to invoke new tools purely through their natural-language descriptions without any fine-tuning, and the framework caches tool outputs in a short-term memory buffer to prevent redundant computation across multi-step analyses. Built on LangChain/LangGraph, the architecture decouples tool creation from agent instantiation, enabling parallel execution of independent tools, flexible deployment from local to cloud, and transparent decision traces for each reasoning step.

## Results

On the newly introduced ChestAgentBench (2,500 six-choice questions across 7 CXR interpretation categories), MedRAX achieves 63.1% overall accuracy, outperforming Llama-3.2-90B (57.9%), GPT-4o (56.4%), CheXagent (39.5%), and LLaVA-Med (28.7%). On CheXbench, MedRAX reaches 68.1% overall (68.7% on Rad-Restruct, 82.9% on SLAKE, 52.6% on OpenI fine-grained reasoning). On MIMIC-CXR report generation, MedRAX attains the highest micro-averaged F1 (mF1-14 = 79.1%, mF1-5 = 64.9%), and on SLAKE VQA it achieves 90.35% accuracy and 91.23% recall, both state-of-the-art.

## Baselines & Comparisons

MedRAX decisively outperforms both domain-specific medical VLMs: LLaVA-Med (28.7% overall on ChestAgentBench) and CheXagent (39.5%), with gaps of 34.4 and 23.6 percentage points respectively, indicating that general-purpose reasoning plus tool orchestration far exceeds specialized single-model approaches. Against general-purpose multimodal LLMs, MedRAX leads GPT-4o (56.4%) by 6.7 points and Llama-3.2-90B (57.9%) by 5.2 points on ChestAgentBench, and surpasses GPT-4o on CheXbench overall (68.1% vs. 63.5%). On MIMIC-CXR report generation, MedRAX achieves the best micro-averaged F1 (mF1-14 = 79.1%) over M4CXR (60.6%), LLaVA-Rad (57.3%), MAIRA-1 (55.7%), and Med-PaLM M84B (53.6%), but trails M4CXR (40.0%) and Med-PaLM M84B (39.8%) on macro-averaged F1 (MF1-14 = 34.2%), suggesting stronger performance on prevalent conditions. On SLAKE VQA, MedRAX (90.35% accuracy) beats M4CXR (85.1%), CheXagent (71.1%), and RadFM (68.4%) by 5.3, 19.3, and 22.0 points respectively. The one notable weakness is on CheXbench's OpenI fine-grained image-text reasoning subset, where all models perform near chance (MedRAX 52.6%, CheXagent 59.0%), and MedRAX does not lead that particular sub-task.

## Relation to Prior Work

MedRAX extends the ReAct agent paradigm (Yao et al., 2023) into the medical imaging domain, departing from prior medical agent frameworks like MDAgents (multi-agent collaboration) and MMedAgent (multi-modality tool integration requiring retraining) by using a single LLM orchestrator with a fixed toolbox of pre-trained CXR specialists. It repurposes existing models—CheXagent, LLaVA-Med, MedSAM, Maira-2, TorchXRayVision, RoentGen—as interchangeable tools within a LangChain/LangGraph pipeline, eliminating the retraining bottleneck that limited MMedAgent's flexibility. The paper also positions itself against end-to-end foundation models (GPT-4o, Llama-3.2-90B) by arguing that structured tool decomposition provides transparency and domain-specific reliability that monolithic VLMs lack.

## Why It Matters / Open Questions

MedRAX addresses a practical fragmentation problem in clinical AI by showing that a single agent can orchestrate heterogeneous CXR tools without retraining, and the accompanying ChestAgentBench (2,500 multi-step questions from 675 Eurorad cases) fills a gap in evaluation for complex reasoning beyond single-step VQA. The finding that general-purpose VLMs outperform domain-specific medical models on complex reasoning challenges the assumption that medical specialization is necessary for high-level interpretation. Key open questions include the optimal balance between tool reliance and LLM-internal reasoning, the computational overhead of multi-tool orchestration in real-time clinical settings, the absence of uncertainty quantification, and whether these results generalize beyond GPT-4o as the backbone LLM.

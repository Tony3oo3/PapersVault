## Problem

LLMs exhibit overconfidence in wrong answers on multiple-choice tasks, creating significant risks in high-stakes domains like healthcare and finance. While conformal prediction (CP) offers distribution-free coverage guarantees for quantifying LLM uncertainty, existing score functions (logits, self-consistency heuristics) produce unnecessarily large prediction sets, limiting CP's practical utility. The paper asks whether CP can be leveraged not merely to quantify uncertainty but to actively improve LLM accuracy by pruning distractor answer choices, and how to learn scores that minimize set sizes while preserving coverage.

## Input / Output

The method consumes a zero-shot MCQ prompt (question text concatenated with answer choices and a 'The correct answer is:' suffix) along with the LLM's last-token logits and penultimate-layer hidden representations. It produces a two-stage output: first, a conformal prediction set (a subset of answer keys guaranteed to contain the correct answer with probability ≥ 1−α), and second, a revised MCQ prompt containing only the surviving options, from which the LLM's final answer key is extracted via standard softmax-over-keys inference. For CP-OPT training, the score network additionally takes the concatenated d+m dimensional feature vector (penultimate representation plus logits) as input.

## Method

The core pipeline (CROQ) applies split conformal prediction to generate a prediction set, then revises the MCQ to contain only the choices in that set before re-prompting the LLM, exploiting the empirically observed monotone relationship between fewer options and higher accuracy. To make CROQ effective, CP-OPT learns a 3-layer tanh-activated neural network as the conformal score function, trained via SGD to minimize expected set size subject to a coverage constraint, using sigmoid surrogates for differentiability, a cross-entropy term to encourage high scores on correct answers, and L2 regularization on network parameters. The conformal threshold is recalibrated on a separate calibration set following the split conformal protocol to avoid estimation bias. A theoretical analysis (Proposition 3.2) formalizes the accuracy gain as a function of set-size distribution and coverage, showing that concentrating mass on small set sizes maximizes the gain, which directly motivates the set-size minimization objective. The entire procedure is post-hoc and model-agnostic, requiring no fine-tuning of the LLM itself.

## Results

CP-OPT scores reduce average conformal set sizes in 17 out of 27 dataset-model-option settings (statistically significant), e.g., from 11.71 to 10.04 on MMLU-15 with Gemma-2 and from 7.79 to 6.08 on MMLU-10 with Gemma-2, while maintaining ~95% coverage. CROQ with CP-OPT scores improves accuracy in 24/27 settings (up to +7.24% on ToolAlpaca-15 with Llama-3), compared to 19/27 for CROQ with logits (up to +6.43%). CROQ + CP-OPT outperforms CROQ + logits in 22/27 settings, with the largest gap of +4.56% on TruthfulQA-10 with Gemma-2. On the harder MMLU-Pro benchmark (10 options), CROQ yields a 3% relative accuracy improvement with Phi-3, and on the BIRD NL2SQL task, CP-OPT-based table selection achieves 32.5% execution accuracy at 45% lower LLM cost versus 32.0% for the full-schema baseline.

## Baselines & Comparisons

The primary baseline is CROQ using LLM softmax logits as conformal scores (following Kumar et al., 2023 and Su et al., 2024). CP-OPT scores consistently produce smaller prediction sets than logits at the same 95% coverage target: in 17/27 settings the reduction is statistically significant, with the largest drops on high-option tasks (e.g., Gemma-2 on MMLU-15: 11.71 → 10.04; Gemma-2 on ToolAlpaca-15: 3.54 → 1.77). In terms of downstream CROQ accuracy, CP-OPT beats logits in 22/27 settings (12 statistically significant), with the most pronounced gains on TruthfulQA (up to +5.06% for Phi-3 at 15 options and +4.56% for Gemma-2 at 10 options) and MMLU-10 with Gemma-2 (+4.00%). The 5 settings where CP-OPT underperforms logits show only non-significant drops (≤0.52%). Overall, CP-OPT delivers a more reliable and larger accuracy improvement than the logit baseline, particularly when the number of answer options is large and logit-based sets tend to be overly conservative.

## Relation to Prior Work

This paper builds directly on Split Conformal Prediction (Papadopoulos et al., 2002; Lei et al., 2018) as the uncertainty quantification backbone, and extends the line of work applying CP to LLM-based MCQ answering (Kumar et al., 2023; Su et al., 2024), which relied on off-the-shelf scores like LLM logits or self-consistency heuristics. The key departure is twofold: (1) CROQ uses the CP prediction set not merely as an uncertainty estimate but as a mechanism to *revise* the question by pruning distractors, a downstream use of CP sets not explored in prior MCQ-CP work; and (2) CP-OPT adapts score-optimization ideas from supervised conformal classifiers (Stutz et al., 2022; Bai et al., 2022) to the post-hoc LLM setting, learning a small neural network over LLM logits and penultimate-layer features to minimize set size under a coverage constraint. The paper positions itself as the first to investigate whether CP can actively *increase* LLM accuracy rather than merely quantify uncertainty.

## Why It Matters / Open Questions

CROQ offers a simple, interpretable, and model-agnostic test-time procedure that requires no fine-tuning and can be applied to any LLM with logit access, making it broadly deployable for MCQ and tool-selection tasks in high-stakes domains. The CP-OPT framework provides a principled alternative to potentially miscalibrated LLM logits, and the NL2SQL application demonstrates practical cost savings (45% token reduction) alongside accuracy gains. Key limitations include the restriction to fixed-format MCQs, the need for a calibration set, and the two-step design that may not scale to very large option spaces. Open questions the authors identify include multi-round CROQ with proper recalibration, handling variable numbers of response options (e.g., via quantile regression), and extending to conditional coverage guarantees.

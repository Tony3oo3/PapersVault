## Problem

Existing memory-augmentation approaches for LLMs (working, implicit, and explicit memory) are tightly coupled to the model architecture, limiting scalability under long-term knowledge updates, cross-model reusability, and independent configurability of memory size and structure. This paper asks whether memory can be fully decoupled from the LLM—treated as a peripheral component analogous to physical RAM—so that knowledge updates can be stored, retrieved, and shared without modifying the base model.

## Input / Output

The method takes a text sentence as input; the query signal is extracted from the hidden state of the last token at layer 24 of the LLM and projected into the memory's feature space via a learned linear map W₀. The output is a masked memory feature vector (element-wise product of the retrieved memory and a sigmoid-normalized confidence score) that is prepended as a prefix to the LLM's token sequence, after which the LLM produces its standard autoregressive prediction. The memory module itself is a compact set of KAN-based banks (~0.2M parameters at default configuration) that can be plugged into or unplugged from any LLM without altering its weights.

## Method

The peripheral memory is structured as K sequential memory banks (default K=512), each modeled as a Kolmogorov-Arnold Network with B-spline-parameterized univariate functions, so that the query-to-data mapping is continuous and smooth rather than a discrete indicator. A sequential querying mechanism chains the banks: the output of bank M_{k-1} is fed as an additional input to bank M_k, enabling iterative refinement of the retrieved representation. A dedicated confidence bank M_{K+1} computes a scalar trust value from the final bank's output, which is sigmoid-normalized and used to element-wise mask the retrieved memory before it is injected as a prefix, thereby suppressing irrelevant or noisy retrievals. Memory writing is performed by fine-tuning only the KAN parameters (with LLM weights frozen), and when a memory unit reaches capacity it is archived and replaced by a fresh one, enabling unbounded long-term storage. The entire module is architecture-agnostic: the same trained memory can be shared across different LLMs (e.g., Llama3, Gemma2, Phi3) via the W₀/W₁ adapter matrices, achieving a 'store once, use everywhere' property.

## Results

Under 3K consecutive knowledge edits, the proposed peripheral memory (with 1K archiving) achieves a composite Score of 0.8975 on ZsRE and 0.7416 on COUNTERFACT with GPT-J (6B), and 0.8643 / 0.7674 with Llama3 (8B), substantially outperforming all baselines. Efficacy reaches 0.9985 (ZsRE) and 0.9915 (COUNTERFACT) on Llama3, while Locality is a perfect 1.0000 across all settings—a direct consequence of the decoupled 'peripheral' design that leaves the base model unmodified. The method uses only ~0.2M memory parameters (bandwidth 512, depth 11), yielding an Effective Storage Density (ESD) of 49.39 at 10K data, over 1000× that of working memory (GRACE) and 500× that of implicit memory (WISE).

## Baselines & Comparisons

The proposed peripheral memory outperforms all 14 baselines on composite Score across both datasets and both base models. On GPT-J (6B), the closest competitor is IKE (in-context learning, Score 0.8212 on ZsRE), which the method surpasses by 7.6 points; on Llama3 (8B), WISE (implicit memory, Score 0.5543 on ZsRE) is the nearest rival, trailed by 31 points. A distinctive advantage is perfect Locality (1.0000) in every setting: because the memory is fully decoupled, the base model is never modified, so unedited predictions remain intact—whereas localization-based methods (ROME, AlphaEdit, PMET) degrade to near-zero scores after consecutive edits, and EMMET/IKE sacrifice Locality (0.33–0.65) to gain Efficacy. On COUNTERFACT Generality, the method (0.2340–0.3108) trails IKE on GPT-J (0.4223) and EMMET (0.4117), reflecting the acknowledged limitation of direct hidden-state querying for semantically equivalent paraphrases. In terms of storage efficiency, the method's 0.2M-parameter memory achieves an ESD of 49.39 at 10K edits, compared to 0.0035 for GRACE (working memory) and 0.0116 for WISE (implicit memory), a >1000× and >500× advantage respectively.

## Relation to Prior Work

This paper positions itself as a fourth category of LLM memory (peripheral memory) alongside working, implicit, and explicit memory, drawing a direct architectural analogy to the CPU–RAM separation in computer systems. It builds on Kolmogorov-Arnold Networks (KAN) as the functional backbone for each memory bank, leveraging their ability to model smooth nonlinear mappings with fewer parameters than MLPs. The key conceptual departure from prior work is the full decoupling of memory from the LLM: unlike GRACE (working memory) or WISE (implicit memory), which are architecturally entangled with a specific model, peripheral memory is an independent, pluggable module whose contents are dynamic variables rather than fixed parameters or cached key-value pairs.

## Why It Matters / Open Questions

The decoupled design enables cross-model memory sharing (store once, use everywhere) and perfect locality by simply unplugging the memory, addressing scalability and reusability gaps that prior memory paradigms cannot resolve. The extreme parameter efficiency (0.2M parameters achieving near-perfect efficacy vs. 18–235M for baselines) and the resulting Effective Storage Density advantage (1000×+ over working memory) are practically significant for deployment. However, generality consistently lags behind efficacy, the Phi3 shared-memory failure on ZsRE (score 0) reveals fragility across architectures, and the authors acknowledge that direct hidden-state querying is hypersensitive to paraphrase; their planned MMU-inspired abstraction layer is an open question that will determine whether the approach generalizes beyond exact-match retrieval.

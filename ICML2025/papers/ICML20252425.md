## Problem

While mechanistic interpretability has identified sharp attentional 'circuits' in Transformers that perform reasoning operations on in-distribution data, it remains unclear whether such circuits can generalize to larger input sizes. This paper proves that softmax attention in Transformers over finite token vocabularies is fundamentally incapable of sustaining sharpness as the number of input items grows, because its output coefficients must disperse toward 1/n—a limitation that was previously only observed empirically but never rigorously established as a structural property of the architecture.

## Input / Output

For the controlled max-retrieval experiment, the model receives a set of n items (each a (C+1)-dimensional vector encoding a priority scalar and a one-hot class label) plus a query vector, and outputs the class label of the highest-priority item; training uses sets of 5–16 items while evaluation extends to 16,384 items. For CLRS-Text, the input is a natural-language prompt describing an algorithmic problem (e.g., sorting or graph traversal) with a variable number of elements, and the output is the algorithm's execution result. The adaptive temperature module itself takes a logit vector of arbitrary length and returns a re-normalized probability distribution with reduced entropy, computed in O(n) memory via a streaming algorithm compatible with Flash Attention.

## Method

The paper's core theoretical result (Theorem 2.2) shows that in any Transformer built from continuous feedforward and softmax self-attention layers over a finite input vocabulary, all attention logits are bounded by constants independent of sequence length, which by Lemma 2.1 forces every softmax coefficient to be Θ(1/n) as n grows—making sharp functions like max impossible to compute robustly out-of-distribution. To mitigate this, the authors propose an adaptive temperature mechanism: at each softmax call, the Shannon entropy of the initial (θ=1) softmax output is computed, and a pre-fitted inverse degree-4 polynomial maps that entropy to an adjusted temperature θ̂ that sharpens the distribution (capped at θ̂≤1 to avoid over-dispersion). For the max-retrieval task this is applied purely at inference time as a drop-in replacement for jax.nn.softmax; for CLRS-Text it is applied during both fine-tuning and inference of Gemma 2B so the model learns to exploit the temperature adaptation. A streaming algorithm (Appendix G) computes the attentional entropy incrementally using running maxima and cumulative sums, enabling O(n) memory and validation up to 131,072 tokens on a single A100.

## Results

On the max retrieval task (trained on ≤16 items), adaptive temperature improves out-of-distribution accuracy at all larger sizes: from 53.8% to 57.7% at 1,024 items, and from 12.4% to 14.0% at 16,384 items (1,024× training size), with all improvements statistically significant (p < 0.05 via paired t-test). On the CLRS-Text benchmark (30 algorithmic tasks), Gemma 2B fine-tuned with adaptive temperature shows a significant accuracy advantage over the standard-softmax baseline on nearly all algorithms across in- and out-of-distribution problem sizes. The theoretical contribution proves that for any Transformer over a finite vocabulary, softmax attention coefficients must disperse as Θ(1/n) with problem size, making sharp size generalisation fundamentally impossible without intervention.

## Baselines & Comparisons

The paper's primary comparison is between standard softmax (baseline) and the proposed adaptive-temperature softmax, applied as a pure inference-time modification (no parameter changes) on the max retrieval task. Adaptive θ matches the baseline at in-distribution sizes (16 items: both 98.6%) but consistently outperforms it at all out-of-distribution sizes ≥64 items, with the gap widening as size grows (e.g., +3.9 pp at 1,024 items, +1.6 pp at 16,384 items). On CLRS-Text, the comparison is between Gemma 2B fine-tuned with standard softmax versus Gemma 2B fine-tuned with adaptive temperature applied to all attention heads during both training and inference; the adaptive-temperature variant achieves higher accuracy on nearly all 30 algorithmic tasks, though a few tasks (Heapsort, MST Kruskal, Bubble Sort) show exceptions likely due to context-length distribution shift. The paper does not compare against other alternative attention mechanisms (e.g., linear attention, sparsemax, differential transformer), positioning adaptive temperature as a lightweight drop-in fix rather than a full architectural replacement.

## Relation to Prior Work

This paper builds on the mechanistic interpretability literature (induction heads, IOI circuits, comparator heads) that has identified sharp attention patterns in Transformers, and on prior empirical observations of attention dispersion in algorithmic tasks (Yan et al., 2020; Ebrahimi et al., 2024). However, it is the first to rigorously prove that dispersion is an inescapable consequence of softmax over finite vocabularies, using a compactness argument inspired by Barbero et al. (2024) on information over-squashing. The proposed adaptive temperature mechanism extends prior dynamic-temperature work (Neumann et al., 2018; Chiang & Cholak, 2022; Cao et al., 2024) by making the correction entropy-dependent rather than size-dependent, and by handling variable-length inputs where the number of logits grows at test time. The streaming implementation leverages Flash Attention's incremental computation paradigm to achieve O(n) memory.

## Why It Matters / Open Questions

The central result—that softmax attention in any Transformer over a finite vocabulary must disperse as input size grows—provides a fundamental explanation for why LLMs fail on sharp reasoning tasks (max, min, order statistics) out-of-distribution, a long-observed but unexplained phenomenon. The authors explicitly position adaptive temperature as an ad-hoc patch that does not escape the theoretical limitation, motivating serious investment in alternative attention mechanisms (linear, sigmoidal, stick-breaking, selective, differential, or local attention) for building robust reasoning systems. Open questions include whether the logit-spread bounds are tight in practice, how to design principled (rather than polynomial-fit) temperature adaptation, and whether hybrid architectures combining softmax with non-dispersing components can retain the benefits of differentiable attention while supporting sharpness at arbitrary scale.

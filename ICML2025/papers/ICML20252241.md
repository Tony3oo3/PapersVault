## Problem

Existing deep unsupervised hashing methods rely exclusively on internal visual structures mined from unlabeled data, which introduces semantic ambiguity and creates an inherent performance ceiling. For example, an airplane image can exhibit higher feature similarity to a bird than to another airplane, demonstrating that internal-only supervision cannot fully resolve semantic confusion. The paper asks whether external textual knowledge can be integrated as semantic guidance to break through this limitation without requiring class labels.
![Teaser figure](../imgs/ICML20252241/cropped_page0_idx0.webp)

## Input / Output

The method takes unlabeled RGB images and a large external noun vocabulary (WordNet, ~118K nouns) as input. Each noun is expanded into 7 natural-language phrases via CLIP prompt templates, and image features are extracted by a pre-trained CLIP (ViT-B/16) or VGG-16 backbone. The output is an L-bit binary hash code in {-1,+1}^L (L ∈ {16, 32, 64}), where retrieval is performed via Hamming distance computed as an inner product. A key detail is that the external feature for each image is a softmax-weighted linear combination of representative text features, not a single matched noun.

## Method

DUH-EG operates in two phases. First, External Feature Construction (EFC) applies K-means clustering to CLIP text features of all WordNet nouns, retains features far from cluster centers (representative) plus the closest-to-center feature per cluster (central), then computes each image's external feature as a softmax-weighted sum over these representative text features. Second, Bidirectional Contrastive Learning projects two augmented image views and the external feature through separate hashing networks (H_v with a pre-trained backbone + MLP, H_e with just an MLP) into Hamming space, then minimizes a three-term InfoNCE loss aligning all pairwise combinations (v1–v2, v1–e, v2–e). The critical innovation is redefining positive pairs: instead of treating only same-image views as positives, the method uses cosine similarity of external features (threshold T₂) to promote semantically similar cross-image pairs to positive status, thereby eliminating false negatives that plague standard contrastive hashing.

## Results

DUH-EG achieves the best MAP across all four benchmark datasets (CIFAR-10, NUS-WIDE, Flickr25k, MSCOCO) at 16, 32, and 64-bit code lengths, using both VGG-16 (CNN) and CLIP ViT-B/16 (ViT) backbones. With the CLIP backbone, DUH-EG reaches 0.939/0.940/0.940 MAP on CIFAR-10, 0.849/0.856/0.856 on NUS-WIDE, 0.874/0.887/0.892 on Flickr25k, and 0.862/0.881/0.888 on MSCOCO (best-T2 setting). The method outperforms the strongest CNN baseline (LGH) by 3.39–4.04% average MAP and the strongest ViT baselines (DDCH, UDBH, HHCH) by 1.71–4.70% average MAP across the four datasets.

## Baselines & Comparisons

DUH-EG outperforms all 14 baselines on every dataset where a comparison is available, with no losses or ties. In the CNN (VGG-16) setting, the closest competitor is LGH (ICMR'24), which achieves 0.846/0.862/0.874 MAP on CIFAR-10 versus DUH-EG's 0.887/0.888/0.885 — a gap of roughly 4–5% at 16 bits. On Flickr25k, DUH-EG (0.856/0.858/0.856) surpasses the next-best DATE (0.822/0.841/0.844) by over 3% MAP. In the ViT (CLIP) setting, DDCH (PR'23) is the strongest baseline on CIFAR-10 (0.882/0.923/0.935), but DUH-EG still leads by 4.9/1.1/0.2% at 16/32/64 bits respectively; on Flickr25k, DUH-EG (0.874/0.887/0.892) beats HHCH (0.815/0.854/0.866) by 5.9–2.6% MAP. The advantage is most pronounced at shorter code lengths (16 bits), where the external textual guidance provides the largest discriminative boost, and on multi-label datasets (Flickr25k, MSCOCO) where semantic ambiguity from internal visual structure alone is most severe.

## Relation to Prior Work

This paper extends the deep unsupervised hashing literature, which has progressed through data reconstruction, similarity-preserving, and contrastive learning paradigms, all relying exclusively on internal visual structure. It departs from this lineage by repurposing the external-guidance concept (previously applied in noisy-label learning, 3D scene generation, and image classification) to the hashing setting, using CLIP to bridge a static noun vocabulary (WordNet) with visual features. The bidirectional contrastive learning loss generalizes standard InfoNCE by redefining positive pairs via external-feature similarity rather than relying solely on augmented views of the same image, and the K-means-based noun screening is a lightweight, non-generative alternative to the pseudo-label or generative-model approaches common in prior unsupervised hashing.

## Why It Matters / Open Questions

The paper demonstrates that a simple external textual signal (filtered WordNet nouns via CLIP) can break the semantic ceiling of purely visual unsupervised hashing, yielding consistent 2–5% MAP gains across four benchmarks and both CNN and ViT backbones. However, the method's effectiveness is tightly coupled to CLIP's pre-trained multimodal alignment, and the authors acknowledge that domain shift between the external vocabulary and the target data (e.g., medical or biological images) would degrade performance. Open questions include whether more efficient textual feature extraction can reduce the pre-processing cost (which scales linearly with vocabulary size), whether the approach generalizes to video or 3D retrieval, and whether the K-means noun-selection threshold can be made adaptive rather than fixed.

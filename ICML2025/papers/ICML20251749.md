## Problem

Prior 3D referential grounding methods either require human-provided 3D meshes and instance segmentations at inference time (making real-world deployment impractical) or rely on 2D VLMs with hand-crafted, simplistic 3D representations. No existing approach operates directly on raw sensor observation streams while achieving state-of-the-art localization accuracy, leaving a gap between benchmark performance and deployability on robots and AR devices.
![Teaser figure](../imgs/ICML20251749/cropped_page1_idx0.webp)

## Input / Output

The model consumes a stream of posed RGB-D frames (no pre-processed meshes or instance annotations) and a natural language referring expression (e.g., 'the small coffee table between the sofa and the lamp'). It produces a joint 3D mask (per-point logits) and 3D bounding box for the referred object, along with a text-alignment matrix grounding each query to a specific noun. The input point cloud is voxelized at 5 cm resolution, and the model requires only a single forward pass (~1 s on A100 for 100k points) after caching 2D foundation features per view.

## Method

LOCATE 3D operates in three phases: (1) lifting dense 2D foundation features (DINOv2 patch features + per-SAM-mask CLIP features + harmonic RGB encoding) into a 3D point cloud via unprojection and voxelization; (2) contextualizing these local features through a PointTransformer-v3 encoder pre-trained with 3D-JEPA, a novel SSL algorithm that performs masked prediction in latent space using a bounded serialized-percent masking strategy and an EMA target encoder to prevent collapse; (3) localizing the object via a language-conditioned decoder with 8 interleaved self/cross-attention blocks that jointly predict masks (dot-product head), bounding boxes (a novel transformer head that concatenates projected xyz coordinates to point features before cross-attention with queries), and text alignment. The key insight is that 3D-JEPA transforms locally-scoped 2D foundation features into scene-contextualized representations analogous to BERT's contextualized embeddings versus word embeddings, yielding a 3–5% gain over random initialization. Training uses a stage-wise learning rate schedule (frozen encoder → joint fine-tuning at 0.5× rate) to preserve pre-trained features while adapting to the grounding task.

## Results

On the standard 3D referential grounding benchmarks (SR3D, NR3D, ScanRefer), LOCATE 3D achieves 61.7% top-1 accuracy@25 on the joint evaluation using raw sensor point clouds, setting a new state-of-the-art. With the additional LOCATE 3D DATASET (L3DD) training data, LOCATE 3D+ further improves to 63.7% Acc@25. Per-benchmark, LOCATE 3D reaches 65.8% (SR3D), 53.7% (NR3D), and 59.9% (ScanRefer) at Acc@25. Notably, these results are obtained under more realistic sensor point cloud conditions (no ground-truth meshes or proposals at inference), whereas prior SoTA methods (e.g., PQ3D at 58.5%) operate on cleaned mesh point clouds.

## Baselines & Comparisons

LOCATE 3D outperforms all prior methods across every benchmark, even under the more challenging sensor point cloud setting. Against the strongest prior mesh-PC method PQ3D (58.5% joint Acc@25), LOCATE 3D gains +3.2 points despite operating on noisier sensor data without ground-truth proposals. Compared to the best prior sensor-PC method BUTD-DETR (40.7%), LOCATE 3D improves by +21.0 points, a substantial margin attributable to 3D-JEPA pre-training and the joint mask+box decoder. Against VLM-based baselines, LOCATE 3D surpasses GPT-4o (38.6%) by +23.1 points and Llama-3 (28.8%) by +32.9 points on joint Acc@25, demonstrating that end-to-end 3D modeling with contextualized features substantially outperforms modular 2D-frame-selection pipelines. On the robot deployment task, LOCATE 3D+ achieves 8/10 success rate versus 5.66/10 for GPT-4o VLM and 2/10 for ConceptFusion. The only setting where a prior method is competitive is ConcreteNet (56.12% on ScanRefer with mesh proposals), which LOCATE 3D still exceeds by +3.8 points without requiring proposals.

## Relation to Prior Work

This paper adapts the 2D JEPA self-supervised learning framework (Assran et al., 2023) to 3D point clouds, but with a critical twist: the input is not raw geometry but high-dimensional features lifted from 2D foundation models (CLIP, DINOv2, SAM) following the ConceptFusion pipeline (Jatavallabhula et al., 2023). The localization decoder draws on DETR-style architectures (Carion et al., 2020; Cheng et al., 2021) with a novel transformer-based bounding box head, while the encoder uses PointTransformer-v3 (Wu et al., 2023). The key departure from prior 3D RefExp work is operating directly on noisy sensor point clouds without requiring ground-truth meshes, region proposals, or instance segmentations at inference time, in contrast to both grounding-by-selection methods (3D-VisTA, PQ3D) and grounding-by-detection methods (BUTD-DETR) that assume clean mesh inputs.

## Why It Matters / Open Questions

By eliminating the need for mesh refinement and instance segmentation at test time, LOCATE 3D becomes deployable on robots and AR devices in real-world settings, validated by an 8/10 success rate on a Spot robot in an unseen multi-room apartment. The LOCATE 3D DATASET (130K+ annotations across ScanNet, ScanNet++, and ARKitScenes) provides a much-needed resource for studying cross-dataset generalization and enables ~2% additional performance gains. Key limitations include reliance on static or quasi-static environments (requiring feature caching) and the observation that in-domain L3DD training data partially diminishes the benefit of 3D-JEPA pre-training, suggesting an unresolved tension between SSL generalization and supervised specialization. Extending to dynamic scenes with real-time feature updates remains an open challenge.

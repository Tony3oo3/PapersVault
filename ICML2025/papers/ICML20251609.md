## Problem

Learning physical systems from data requires simultaneously solving forward PDEs (predicting solutions) and inverse PDEs (recovering hidden parameters), a task that is severely ill-posed and often non-identifiable from limited function pairs. Existing attention-based neural operators like NAO address this by learning data-dependent kernels, but their quadratic-complexity attention and explicit pairwise interaction matrices become prohibitive at large discretizations, limiting scalability to practical problem sizes.
![Teaser figure](../imgs/ICML20251609/cropped_page3_idx0.webp)

## Input / Output

NIPS consumes d contextual function pairs (u_j, f_j) per physical system, tokenized on spatial grids (e.g., 21×21, 41×41, or 29×29×2 for 2D vector fields), with physics-informed data augmentation via random permutation of the d pairs to enforce permutation invariance of the learned kernel. The model produces both the PDE solution field u(x) as a forward surrogate and the parameter-dependent kernel K_b(x,y) as an interpretable inverse solution; the kernel can be recovered via a single forward pass on unseen systems without retraining, and the hidden parameter field b(x) (e.g., permeability or material modulus) is extracted from the kernel structure.

## Method

NIPS reformulates the NAO attention block using a linear attention decomposition that splits the kernel-weighted integral into a Fourier-domain convolution (learnable spectral kernel R replacing the full projection W^P) and a global domain integral, reducing per-layer complexity from O(N²d) to O(Nd² + Nd log N). The architecture stacks L iterative blocks that jointly update loading (g) and solution (v) feature vectors, with the final layer mapping the last-iteration features to the data-dependent kernel K[u_{1:d}, f_{1:d}]. A learnable Fourier kernel R operates as a channel-independent convolution in spectral space, encoding spatial interactions through a small number of retained modes (m ≪ N) rather than explicit N×N pairwise weights. Training minimizes a relative L² loss over all function pairs across S systems using Adam, and the resulting kernel simultaneously serves as a forward PDE solver (via integral evaluation) and an inverse solver (by revealing the hidden parameter field through kernel structure analysis).

## Results

On the 2D Darcy flow benchmark (4 layers, 441 tokens), NIPS achieves a 1.03% test error, outperforming NAO (1.45%) by 28.9% and AFNO (52.84%) by a wide margin. At higher resolution (4 layers, 1681 tokens), NIPS reaches 1.14% test error versus NAO's 1.49%, while AFNO degrades to 98.70%. On the Mechanical MNIST benchmark (4 layers, 1682 tokens), NIPS achieves 1.11% test error compared to NAO's 5.27%, a 78.9% improvement. NIPS also uses fewer trainable parameters (e.g., 98,396 vs. 101,134 for NAO at 2 layers/441 tokens) and runs 28.8% faster per epoch at 1681 tokens.

## Baselines & Comparisons

NIPS is compared against two primary baselines: NAO (Yu et al., 2024) and AFNO (Guibas et al., 2021). Against NAO, NIPS consistently wins across all benchmarks and configurations: on Darcy flow it improves test error by 26.2% (2 layers) to 23.5% (4 layers, 1681 tokens), and on Mechanical MNIST it achieves a 78.9% reduction in test error (1.11% vs. 5.27% at 4 layers). NIPS also uses fewer parameters and substantially less per-epoch runtime at larger sequence lengths (8.4 s vs. 58.8 s for quadratic NAO at 1681 tokens). Against AFNO, NIPS is dramatically superior: AFNO fails to achieve zero-shot generalization to unseen PDE parameters, with test errors exceeding 50% on Darcy flow and reaching 98.70% at 1681 tokens, while NIPS maintains errors below 1.2%. The paper also ablates NAO variants (NAO-f, NAO-W^p), showing that full LayerNorm and learnable square projections both degrade NAO's accuracy while increasing parameters, further highlighting NIPS's architectural advantages.

## Relation to Prior Work

NIPS extends the Nonlocal Attention Operator (NAO, Yu et al., 2024) framework, which introduced attention-based kernel maps for simultaneous forward PDE solving and inverse parameter discovery, by reformulating its quadratic attention into a linear attention mechanism and replacing the explicit spatial interaction matrix with a learnable channel-independent convolution in Fourier space. This design borrows the spectral convolution idea from Fourier Neural Operators (FNO, Li et al., 2021) but applies it not as the sole mixing mechanism (as in FNO) but as a projection kernel within an attention block, preserving the data-dependent, multi-system kernel structure that gives NAO its interpretability. The paper also draws on the broader neural operator literature (GNO, DeepONet, AFNO) for architectural context and on linear attention theory for the computational reformulation.

## Why It Matters / Open Questions

The practical significance lies in making interpretable multi-system PDE discovery scalable: NIPS handles 15k tokens on a single A100 GPU where NAO's quadratic attention exhausts memory at 6.5k, and it achieves 26–79% lower test errors across benchmarks while using fewer parameters. The zero-shot ability to recover hidden microstructures (e.g., permeability fields) from contextual data without retraining is directly relevant to materials science and biomedical engineering workflows. A key limitation acknowledged by the authors is that the learned kernel prior assumes structural similarity to training kernels (e.g., symmetry), so performance may degrade for fundamentally different operator classes such as advection-dominated or non-symmetric systems. Open questions include whether the Fourier-space kernel can be extended to non-translation-invariant or anisotropic domains, and whether the interpretability guarantees hold under stronger distributional shifts.

## Problem

Existing GUI agent benchmarks are disproportionately focused on web (relying on DOM/HTML structures) and mobile (touchscreen-centric) environments, leaving desktop applications—critical for professional workflows—largely unexplored. Desktop GUIs lack standardized text-based representations or automation APIs, making large-scale data collection and evaluation difficult. UI-Vision addresses this gap by providing the first comprehensive, license-permissive, offline benchmark for fine-grained evaluation of computer-use agents across 83 real-world desktop applications.
![Teaser figure](../imgs/ICML20251837/cropped_page0_idx0.webp)

## Input / Output

For Element Grounding, the model receives a screenshot (varying resolutions, 5–200 annotated elements per frame, avg. 71) and a short text query (basic label, functional description, or spatial relation), and outputs a single point (x, y) that must fall within the ground-truth bounding box. For Layout Grounding, the input is a screenshot plus a functional/semantic region description, and the output is a bounding box enclosing 5–10 grouped UI elements, evaluated via IoU, precision, and recall. For Action Prediction, the model receives a task instruction, the current screenshot, and the full action history, and must output a structured action (click, move, drag, typing, or hotkey) with precise coordinates or keystroke parameters; a step is correct only if both the action type and all parameters match ground truth.

## Method

UI-Vision is constructed through a multi-stage human annotation pipeline: 70 expert annotators design 5–7 computer-use tasks per application across 83 open-source platforms in 6 domains, perform the tasks while recording screen videos, and then label every visible UI element with bounding boxes and functional descriptions on keyframe screenshots (450 videos total, 8,267 query-label pairs). The benchmark defines three tasks of increasing complexity—Element Grounding (with basic, functional, and spatial subtasks using 1,772/1,772/1,935 pairs), Layout Grounding (311 human-verified functional-cluster pairs generated via LLaMA-3.3-70B clustering followed by expert verification), and Action Prediction (3,191 action-annotation pairs over 442 tasks with standardized 5-type action space). Evaluation uses point-in-box accuracy for element grounding, IoU/precision/recall for layout grounding, and a composite Step Success Rate combining normalized Euclidean distance, Recall@average-bbox-size for spatial actions, and exact-match correctness for keyboard actions. The paper evaluates 20+ models spanning closed-source VLMs (GPT-4o, Claude, Gemini), open-source VLMs (Qwen2-VL, InternVL, MiniCPM-V), and dedicated GUI agents (UI-TARS, UGround, CogAgent, SeeClick, OSAtlas, ShowUI, Aria-UI, Aguvis), revealing that even the best model (UI-TARS-72B) achieves only 25.5% element grounding accuracy and 19.7% click recall.

## Results

On the Element Grounding task, the best-performing model UI-TARS-72B achieves only 25.5% overall accuracy (Basic: 31.4%, Functional: 30.5%, Spatial: 14.7%), with UGround-v1-72B following at 23.2%. On Layout Grounding, Gemini-1.5-Pro leads with 30.8 IoU, while the best GUI agent (OSAtlas-7B) reaches 28.2 IoU. On Action Prediction, UI-TARS-7B achieves the highest Step Success Rate of 21.4%, with Gemini-1.5-Pro at 16.0% and GPT-4o at 11.5%. All models struggle substantially, with spatial grounding (14.9% best) and drag actions (3.1% best recall) being particularly challenging.

## Baselines & Comparisons

This is a benchmark paper, so the 'method' is the UI-Vision evaluation itself applied to 14+ existing models. On Element Grounding, GUI-agent models (UI-TARS-72B: 25.5%, UGround-v1-72B: 23.2%, Aguvis-7B: 13.7%) substantially outperform both closed-source VLMs (Claude-3.7-Sonnet: 8.27%, GPT-4o: 1.38%) and open-source VLMs (MiniCPM-V-8B: 4.34%, Qwen-2VL-7B: 2.70%), confirming that task-specific GUI training is critical for fine-grained element localization. On Layout Grounding, the ranking inverts: closed-source VLMs (Gemini-1.5-Pro: 30.8 IoU, Claude-3.5-Sonnet: 22.4 IoU) and open-source VLMs (Qwen-2VL-7B: 24.3 IoU) outperform most GUI agents (CogAgent-9B: 6.22 IoU, SeeClick-9.6B: 5.11 IoU), with only OSAtlas-7B (28.2 IoU) competitive, suggesting general visual understanding aids layout perception. On Action Prediction, UI-TARS-7B leads with 21.4% SSR and 19.7% click recall, while Gemini-1.5-Pro (16.0% SSR) and GPT-4o (11.5% SSR) trail; notably, GPT-4o achieves the best typing (32.1%) and hotkey (56.5%) correctness, while UI-TARS-7B dominates click recall. All models fail on drag actions (best recall: 3.1% by UI-TARS-7B), and spatial grounding remains the weakest subtask across all models (best: 14.9% by UGround-v1-72B). Cross-software generalization analysis shows all models drop 30–90% in accuracy on rare apps versus common ones, with even UI-TARS-72B losing ~40% accuracy on unseen platforms.

## Relation to Prior Work

This paper carves new ground by targeting desktop environments, which prior GUI benchmarks (MiniWoB++, Mind2Web, WebArena, AITW, ScreenSpot, OS-World) have largely neglected in favor of web and mobile platforms. It extends the element grounding and action prediction tasks established in prior work to a desktop setting with substantially denser annotations (71 bounding boxes per keyframe vs. 1 in most prior benchmarks) and introduces Layout Grounding as a genuinely new evaluation dimension that no prior GUI benchmark has addressed. The offline, license-permissive design also departs from online benchmarks like OS-World, enabling reproducible evaluation without live environment dependencies.

## Why It Matters / Open Questions

UI-Vision fills a critical gap by providing the first comprehensive, permissively-licensed desktop GUI benchmark, and its evaluation reveals that even the strongest models (UI-TARS-72B at 25.5% element grounding, 19.7% click recall) are far from capable of reliable desktop automation. The finding that spatial grounding and drag actions are universal weaknesses, and that general VLMs outperform specialized GUI agents on layout understanding, points to specific research directions: better spatial reasoning, motion-based interaction modeling, and higher-level structural comprehension. Open questions include whether iterative zooming or RAG-based domain knowledge can close the grounding gap, and how to achieve cross-platform generalization given the 40%+ accuracy drops on less common applications.

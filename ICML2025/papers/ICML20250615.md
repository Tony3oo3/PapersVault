## Problem

Existing 3D robotic manipulation policies, while effective on standard benchmarks, struggle to generalize under diverse environmental perturbations (lighting, object appearance, camera pose) and cannot solve tasks that require spatial memory—where the same observation is reached via different action histories but demands different subsequent actions. No prior behavior-cloning framework integrates a visual foundation model's multi-resolution features with an explicit episodic memory mechanism for sequential decision-making.
![Teaser figure](../imgs/ICML20250615/cropped_page1_idx1.webp)

## Input / Output

The policy consumes a 3D point cloud reconstructed from five 128×128 RGB-D cameras (front, left/right shoulder, overhead, wrist), rendered into three virtual orthographic views, alongside a CLIP-encoded language instruction. For SAM2Act+, the input additionally includes a FIFO memory bank of up to N past translation heatmaps per view. The output is a 6-DoF action keyframe (3D translation + quaternion orientation) predicted through a two-stage coarse-to-fine heatmap: the coarse branch localizes the region of interest, and the fine branch refines it into a precise translation heatmap.

## Method

SAM2Act builds on RVT-2's coarse-to-fine multi-view transformer backbone but replaces direct image input with multi-resolution embeddings from a LoRA-fine-tuned (rank 16) SAM2 image encoder. A cascaded multi-resolution upsampling mechanism progressively refines feature maps across three resolution levels, injecting SAM2's embeddings at each stage via element-wise addition followed by layer normalization, which preserves fine-grained spatial detail for high-precision translation prediction. SAM2Act+ extends the coarse branch with three memory components adapted from SAM2's video tracking: a Memory Encoder that fuses downsampled translation heatmaps with unconditioned MVT feature embeddings, a Memory Attention module (four transformer blocks with self-attention and cross-attention using 2D RoPE) that conditions current observations on stored memories, and a per-view FIFO Memory Bank. Training uses a two-stage pipeline: SAM2Act is pre-trained with standard random sampling, then the coarse branch is fine-tuned with spatio-temporally consistent sampling of consecutive keyframes to learn memory-conditioned action prediction.

## Results

On the 18-task RLBench benchmark, SAM2Act achieves a state-of-the-art average success rate of 86.8% ± 0.5, surpassing the prior best (RVT-2) by 5.4 percentage points. On The Colosseum generalization benchmark, SAM2Act exhibits only a −4.3% ± 3.6% average performance drop across 13 perturbation categories, compared to −19.5% for RVT-2. On the newly introduced MemoryBench, SAM2Act+ achieves 94.3% ± 9.0 average success rate on spatial memory tasks, outperforming RVT-2 (54.0%) by 40.3 points. In real-world evaluation, SAM2Act/SAM2Act+ achieves 75% overall task success versus 43% for RVT-2.

## Baselines & Comparisons

SAM2Act outperforms all 12 baselines on the 18-task RLBench benchmark. Against the closest competitors, it beats ARP+ (84.9%) by 1.9%, 3D-LOTUS (83.1%) by 3.7%, and 3D Diffuser Actor (81.3%) by 5.5%. The largest gains appear on precision-critical tasks: Insert Peg improves from 40.0% (RVT-2) to 84.0%, and Sort Shape from 35.0% to 64.0%. On The Colosseum generalization benchmark, SAM2Act's −4.3% average drop under 13 perturbations is dramatically better than RVT-2's −19.5%, with particular robustness to lighting (−4.5% vs −15.6%), table color (+1.1% vs −26.5%), and camera pose (−4.3% vs −19.5%). On MemoryBench, SAM2Act+ (94.3%) surpasses RVT-2 (54.0%) by 40.3 points and its own non-memory variant SAM2Act (55.0%) by 39.3 points, confirming the memory architecture's critical contribution. In real-world trials, SAM2Act achieves 6/10 on the high-precision lamp task where RVT-2 scores 0/10, and 7/10 on the memory-based button task versus RVT-2's 4/10.

## Relation to Prior Work

SAM2Act sits at the intersection of two research threads: 3D keyframe-based manipulation transformers (PerAct → RVT → RVT-2) and visual foundation models for robotics (SAM-E, SAM2). It builds directly on RVT-2's coarse-to-fine multi-view transformer backbone, replacing the standard image encoder with a LoRA-fine-tuned SAM2 encoder and introducing a cascaded multi-resolution upsampling mechanism that injects SAM2's multi-scale embeddings into the decoder. SAM2Act+ then repurposes SAM2's memory components (Memory Bank, Memory Encoder, Memory Attention) from their original object-tracking context into the manipulation setting, treating predicted action heatmaps as the analog of object masks. The paper also introduces MemoryBench, a benchmark that deliberately violates the Markov assumption to isolate spatial-memory capabilities—a gap not addressed by RLBench or The Colosseum.

## Why It Matters / Open Questions

The 4.3% average performance drop under 13 perturbation categories on The Colosseum (vs. ~19.5% for RVT-2) suggests that foundation-model visual features substantially improve robustness to environmental variation, a practical concern for deploying manipulation policies in uncontrolled settings. MemoryBench fills a genuine evaluation gap: prior benchmarks conflate memory failures with general manipulation errors, making it impossible to attribute performance to spatial recall. Key limitations include the fixed memory window length (task-specific, not adaptive), the keyframe-based formulation that precludes continuous dexterous control, and the single-task training protocol for memory tasks, which limits claims about multi-task memory generalization. Extending the memory architecture to variable-length episodes and continuous control remains an open direction.

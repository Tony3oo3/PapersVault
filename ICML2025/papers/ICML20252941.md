## Problem

Existing temporal point process models face a fundamental trade-off: statistical TPPs like the Hawkes process are computationally efficient but too rigid to capture complex real-world dynamics, while neural TPPs (RNN- or attention-based) are expressive but suffer from high computational cost and difficulty with long sequences. Moreover, unlike time series analysis where Seasonal-Trend Decomposition is well-established, no analogous decomposition method exists for TPPs to separate explainable statistical structure from unexplained residuals.

## Input / Output

The method consumes marked event stream sequences S = {(t_i, k_i)} with discrete event types and irregular timestamps. It produces a combined intensity function λ_k(t) = (1−α)λ_k^(1)(t) + λ_k^(2)(t), where α = |S'_w|/|S| is a data-driven proportion of residual events. For prediction, given a prefix S_[0,t_{i−1}], it outputs the next event time as the expected value E[t_i | H_{t_{i−1}}] and the next event type via argmax_k λ_k(t_i)/λ(t_i). The Volcano dataset (single event type) is excluded from type prediction.

## Method

Residual TPP operates in three steps: (1) fit a multivariate Hawkes process with exponential decay to capture self-excitation and periodicity; (2) apply the Residual Events Decomposition (RED) technique, which assigns each event a weight W_i = φ'_{ρ1,ρ2}(∫_{t_{i−1}}^{t_i} λ^(1)(u)du − 1) using a compactly-supported influence function φ' that peaks at zero deviation from the expected Exp(1) inter-event count, then thresholds events with W_i ≤ w as residuals; (3) train an arbitrary neural TPP (RNN, attention, or ODE-based) on only the residual subset S'_w. The influence function satisfies an unbiasedness property (E[(X−1)φ'(X−1)]=0 for X~Exp(1)), ensuring the weighted gradient remains asymptotically unbiased at true parameters (Theorem 3.2). This plug-and-play decomposition reduces the neural TPP's training data to only the unexplained events, yielding consistent improvements in log-likelihood and prediction accuracy while cutting training time across all six real-world benchmarks.

## Results

On goodness-of-fit (log-likelihood), Residual TPP consistently outperforms its corresponding neural TPP baseline across all six real-world datasets. The most striking improvements include RES NHP on MIMIC-II (−1.825 vs. NHP's −2.031) and RES RMTPP on StackOverflow (−0.864 vs. RMTPP's −2.844). On next-event prediction, RES NHP on MIMIC-II achieves 0.913 time RMSE and 20.9% type error rate, compared to NHP's 1.010 and 26.7%. Training time is also reduced across all datasets; for example, RES AttNHP on Retweet takes 7,195 s versus 9,475 s for AttNHP (a 24% reduction).

## Baselines & Comparisons

Residual TPP variants outperform their corresponding neural TPP baselines on nearly all datasets for both goodness-of-fit and prediction. Against RMTPP, RES RMTPP improves log-likelihood on all six datasets (e.g., −0.864 vs. −2.844 on StackOverflow) and reduces type error rate from 37.8% to 26.7% on MIMIC-II. Against NHP, RES NHP achieves the best overall log-likelihood on MIMIC-II (−1.825) and the lowest type error rate (20.9%), while also cutting training time from 34.7 s to 29.5 s. Against the attention-based models (SAHP, THP, AttNHP), Residual variants consistently improve log-likelihood and reduce training time by 10–25% (e.g., RES AttNHP on Retweet: 7,195 s vs. 9,475 s). Against ODETPP, RES ODETPP shows the largest relative gain on MIMIC-II (−1.371 vs. −1.855) and reduces time RMSE from 1.416 to 0.934. The multivariate Hawkes process (MHP) serves as the statistical base model within Residual TPP and is also compared standalone; Residual TPP variants surpass MHP on most datasets, confirming that the neural residual component adds meaningful expressiveness beyond the Hawkes process alone.

## Relation to Prior Work

This paper draws a direct analogy between Seasonal-Trend Decomposition (STD) in time series and proposes the first decomposition technique for temporal point processes, the Residual Events Decomposition (RED). It builds on the classical Hawkes process as a lightweight statistical base model and on a broad family of neural TPPs (RMTPP, NHP, SAHP, THP, AttNHP, ODETPP) as the residual model, combining them via the superposition property of point processes. The weight function used to identify residual events is grounded in influence-function theory from robust statistics (Zhang et al., 2025), which provides an asymptotic unbiasedness guarantee for the weighted gradient. Conceptually, the work sits at the intersection of classical point process theory, neural sequence modeling, and residual learning from deep networks, but departs from prior TPP literature by introducing a data-driven decomposition step that had no analogue in the field.

## Why It Matters / Open Questions

The RED technique offers a practical, plug-and-play module that can be attached to any existing TPP architecture to improve both goodness-of-fit and prediction while reducing training time, making it attractive for resource-constrained deployments. The theoretical result (Theorem 3.2) that the weighted gradient remains asymptotically unbiased at the true parameters provides a principled justification for discarding well-fitted events, which is a non-trivial guarantee given the left-skewed distribution of inter-event integrals. Open questions include extending the Hawkes baseline to capture periodicity (currently only self-excitation is modeled), exploring other decomposition strategies for TPPs beyond RED, and whether the approach generalizes to other discrete, irregular data types beyond event streams. The paper also notes that the MHP+RED+MHP configuration can overfit, suggesting the residual component genuinely requires a more expressive model than the base.

## Problem

Prior vision-language-action (VLA) models can follow simple atomic commands like "pick up the cup" but fail on complex, multi-stage prompts (e.g., "make me a vegetarian sandwich without tomatoes") and cannot incorporate real-time situated feedback such as "that's not trash" during task execution. This paper addresses the gap between reactive skill execution (Kahneman's System 1) and deliberative reasoning over open-ended instructions, constraints, and user corrections (System 2) in physical robotic manipulation.

## Input / Output

The system consumes RGB images from multiple cameras (wrist-mounted, base, over-the-shoulder), an open-ended language prompt, robot joint/gripper proprioception, and real-time user feedback (typed or transcribed via Whisper large-v2). The high-level VLM outputs a low-level language command (e.g., "grasp the lettuce") plus an optional verbal response for text-to-speech playback, while the low-level VLA outputs continuous action chunks of H steps via flow matching. The two levels operate at different frequencies: the low-level runs at ~10 Hz (50 Hz with action chunking) while the high-level re-infers every ~1 second or immediately upon user intervention.

## Method

Hi Robot decomposes the policy into a high-level VLM (System 2) that maps images and open-ended prompts to low-level language commands, and a low-level VLA (System 1) that maps images, those commands, and proprioception to continuous actions via flow matching. Both levels are initialized from PaliGemma-3B; the low-level is the π_0 VLA with an added flow-matching action expert, while the high-level is fine-tuned with cross-entropy next-token prediction. The key training innovation is a synthetic data generation pipeline: a VLM is prompted with robot observations and skill labels from teleoperated demonstrations to generate plausible user prompts, interjections, and robot verbal responses, creating diverse training examples for the high-level policy. This synthetic data, combined with human-labeled skill segments, enables the high-level policy to generalize to open-ended instructions and situated corrections without requiring explicit demonstrations of every possible user interaction.

## Results

Across three task domains (Table Bussing, Sandwich Making, Grocery Shopping) evaluated over 20 trials each, Hi Robot achieves substantially higher Instruction Accuracy (IA) and Task Progress (TP) than both GPT-4o high-level and flat VLA baselines. The paper reports that Hi Robot averages over 40% higher instruction accuracy than GPT-4o, demonstrating stronger alignment with user prompts and real-time observations. Hi Robot also approaches the performance of an expert human high-level oracle, indicating that the low-level π_0 policy is not the bottleneck — failures stem primarily from high-level reasoning rather than actuation.

## Baselines & Comparisons

Hi Robot outperforms the flat VLA (π_0) baseline on both Instruction Accuracy and Task Progress across all three tasks; the flat policy does not react to real-time feedback and reverts to default behaviors (e.g., picking up every object) when prompts change mid-episode. Against GPT-4o high-level, Hi Robot achieves over 40% higher instruction accuracy, as GPT-4o frequently loses context during physical interaction, issuing nonsensical commands (e.g., 'pick up bermuda triangle') or failing to maintain coherent internal state. The expert human high-level oracle shows that the low-level policy executes nearly flawlessly with ideal commands, confirming that Hi Robot's remaining gap is in high-level reasoning rather than physical execution. In the ablation comparing hierarchical vs. flat architecture trained on the same synthetic data, the hierarchical Hi Robot outperforms the flat variant, which struggles with mid-task clarifications and partial instructions like 'bus only the yellowish things.' Finally, Hi Robot without synthetic data (analogous to YAY Robot) ignores user clarifications and includes forbidden items, confirming that synthetic data generation is critical for open-ended instruction following.

## Relation to Prior Work

Hi Robot extends the hierarchical robot control lineage from YAY Robot (Shi et al., 2024) and SayCan-style systems by using VLMs at both the high-level reasoning and low-level execution layers, with the low-level policy being the π_0 flow-matching VLA. The key departure from prior hierarchical work (OLAF, YAY Robot, RACER) is a synthetic data generation scheme that uses a large VLM to imagine plausible user prompts and interjections for each observed robot skill, enabling the high-level policy to generalize to diverse open-ended instructions rather than being limited to human-written examples. Unlike flat VLA approaches (RT-2, π_0) that handle only atomic commands, and unlike API-based VLM planners (GPT-4o) that lack physical grounding, Hi Robot couples situated visual reasoning with dexterous continuous action output through a shared VLM architecture.

## Why It Matters / Open Questions

The paper demonstrates that a 3B-parameter task-specific VLM with synthetic interaction data can substantially outperform a much larger general-purpose model (GPT-4o) on open-ended robotic instruction following, suggesting that grounded, task-specific fine-tuning with diverse synthetic prompts is more effective than raw model scale for situated reasoning. The synthetic data generation pipeline is a practical and reusable technique for scaling instruction diversity without exhaustive human annotation. Key open questions include whether the high-level and low-level policies can be unified into a single model, how to handle long-horizon memory (the current system lacks it), and how to couple the two layers so the high-level policy is aware of low-level execution success. The decoupled training and reliance on prompt engineering for synthetic data quality remain limitations that could constrain generalization to truly novel task domains.

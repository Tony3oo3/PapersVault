## Problem

Existing statistical rank tests for cross-covariance matrices assume all variables are perfectly measured as continuous values, yet in many scientific domains (psychometrics, biometrics, econometrics) variables are only observed after discretization into ordinal categories. When discretization is present, directly using ordinal values yields meaningless covariance estimates, and even plugging MLE-estimated correlations into standard CCA rank tests fails to control Type I error because the discretization and estimation steps fundamentally alter the null distribution of the test statistic.

## Input / Output

The method accepts a data matrix where some columns are continuous and others are discretized into ordinal categories (e.g., {1,2,3}), along with indexes identifying which columns are discretized, a null hypothesis H0^k: rank(Σ_XY) ≤ k, and a significance level α. It outputs a p-value computed from an empirical CDF built over 200 random permutations, and a binary reject/fail-to-reject decision. When embedded in causal discovery algorithms (PC, RLCD), the output extends to a recovered causal graph structure including latent variable identification via t-separations.

## Method

MPRT establishes that under H0: rank(Σ_XY) ≤ k, the tail CCA variables C_X_{k:} and C_Y_{k:} are asymptotically independent (exchangeable), enabling permutation-based resampling to estimate the null distribution empirically. The key technical challenge in the discretized setting is that one cannot apply the linear CCA projection matrices to ordinal data; Theorem 5 resolves this by showing the permuted CCA scores can be consistently estimated by permuting the raw discretized data D^Y and re-estimating the cross-covariance between D^X and P^T D^Y via pairwise pseudo-likelihood (using Gaussian, polyserial, or polychoric likelihoods depending on the variable types). The correlation matrix is estimated by minimizing pairwise negative log-likelihood with an angular parameterization (Rousseeuw–Molenberghs) that guarantees positive semi-definiteness and unit diagonal, avoiding the need for projected gradient descent. The p-value is then computed as the fraction of 200 random permutations yielding a test statistic at least as extreme as the observed one, properly controlling Type I error regardless of the discretization pattern.

## Results

On the PC algorithm causal discovery task with partially discretized data, MPRT achieves the best skeleton F1 score (0.96 at N=2000) and lowest SHD (0.20 at N=2000), outperforming Fisher-Z (F1=0.78, SHD=1.40), KCI (F1=0.86, SHD=0.93), CCART-D (F1=0.77, SHD=1.80), and CCART-DE (F1=0.83, SHD=1.60). In terms of statistical validity, MPRT properly controls Type I error at the nominal α=0.05 level (matching CCART-C), while CCART-D and CCART-DE produce severely inflated Type I errors. MPRT's Type II error decreases with sample size, whereas CCART-D and CCART-DE show no improvement even as N grows. On the real-world Big Five Personality dataset, MPRT recovers interpretable latent variable structures for Openness and Neuroticism, while CCART-D yields p-values near zero requiring an impractically small α (~1e-10).

## Baselines & Comparisons

Against CCART-C (Anderson's original CCA rank test with continuous data), MPRT matches Type I error control (both near α=0.05) and achieves nearly identical Type II error when both have access to continuous data (Figure 3), confirming that the permutation-based p-value is asymptotically equivalent to the analytic chi-square distribution. Against Fisher-Z, MPRT clearly wins on both F1 and SHD across all sample sizes in the PC algorithm experiment (e.g., F1 0.96 vs. 0.78 and SHD 0.20 vs. 1.40 at N=2000), with Fisher-Z's performance actually degrading as N increases. Against KCI (Zhang et al., 2012), MPRT also dominates on both metrics (F1 0.96 vs. 0.86, SHD 0.20 vs. 0.93 at N=2000), and the gap widens with larger samples. The two discretization-naive baselines (CCART-D and CCART-DE) fail catastrophically on Type I error control and show no power improvement with sample size, underscoring the necessity of the permutation-based approach.

## Relation to Prior Work

This paper extends the classical CCA-based rank test of Anderson (1984) and the permutation-based CCA rank test of Winkler et al. (2020) to the setting where some or all variables are discretized. The key departure is that existing methods assume continuous observations, and the authors show that even after estimating correlations via pseudo-likelihood (polychoric/polyserial), the standard chi-square null distribution is invalid. Their solution combines the angular parameterization of Rousseeuw & Molenberghs (1993) for correlation estimation with a permutation-based empirical null distribution, leveraging an exchangeability result (Theorem 4) and a consistent estimation trick (Theorem 5) that avoids applying linear projections to ordinal data.

## Why It Matters / Open Questions

Discretization is ubiquitous in psychology, biometrics, and econometrics, yet existing rank tests produce completely uncontrolled Type I errors (p-values cluster near zero) when applied to such data, undermining any downstream causal discovery. The method is general—handling fully continuous, partially discretized, or fully discretized inputs—and integrates naturally into constraint-based causal discovery (PC, RLCD). Open questions include the lack of a theoretical power analysis (the authors note this requires advanced random matrix theory even without discretization) and the requirement of a parametric form for non-Gaussian cases, which limits applicability when the distributional shape is unknown.

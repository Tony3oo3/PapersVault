## Problem

Length generalization in reasoning tasks is poorly understood because existing formulations conflate the inherent scaling challenge (increasing problem complexity) with data format effects (how the problem is serialized into a string). This paper introduces Low-Dimension-to-High-Dimension (LDHD) generalization as a principled formulation that disentangles these two aspects, proves a No-Free-Lunch theorem showing LDHD generalization is impossible without appropriate inductive bias, and characterizes exactly how different architectures' implicit biases determine whether length generalization succeeds.

## Input / Output

The method operates on variable-length token sequences representing reasoning problems where the problem scale is determined by the latent variable dimension (e.g., number of digits in addition) rather than the string length, as in URF addition where shorter strings can encode larger-scale problems. The model (GPT-2 with modified position embeddings) takes these input strings and autoregressively predicts output tokens. The critical design parameter is the position embedding configuration, which must simultaneously encode the recursive/positional structure needed for LDHD generalization and handle format-specific alignment (e.g., unaligned addends in URF).

## Method

The paper proves that different architectures trained with (S)GD converge to min-degree interpolators with respect to different linearly independent sets: RFM uses the Fourier basis, RFMP uses a projection-dependent basis, PLAA with APE uses a position-dependent basis that structurally fails for LDHD generalization, while PLAA with GRPE uses a diagonal-structure basis that can succeed when the target concept aligns with the basis. From this analysis, the paper derives a design principle: position embeddings must handle LDHD generalization (via relative position structure) and data format nuisances (via distances to special tokens) as separate concerns. Following this principle, RPE-Square is proposed, which computes attention scores using the relative difference between relative distances to special tokens (e.g., [BOS], +, =), enabling the model to identify latent variable positions in unaligned formats. Experiments on URF addition and unaligned copy tasks show RPE-Square achieves length generalization where standard RPE, RoPE, NoPE, and ALiBi all fail.

## Results

The paper evaluates RPE-Square against five position embeddings (RPE, RoPE, NoPE, ALiBi, Abacus) on five length-generalization tasks: URF Addition, Unaligned Copy, ParityCoT, Multiplication (1×N), and Division (N/1). On URF Addition (trained on 4-addition, tested on 5-addition), RPE-Square reaches nearly perfect accuracy after 200K steps, while RPE, RoPE, NoPE, and ALiBi all fail to generalize. On Unaligned Copy (trained on lengths 1–5, tested on 1–10), RPE-Square achieves near-perfect out-of-distribution generalization for lengths 6–10, whereas RPE shows almost no OOD generalization. Across all five tasks, RPE-Square and Abacus are the only two embeddings that achieve non-trivial length generalization, with RPE-Square consistently outperforming Abacus.

## Baselines & Comparisons

RPE-Square decisively outperforms RPE, RoPE, NoPE, and ALiBi on all five tasks: these four embeddings fail to achieve any meaningful out-of-distribution length generalization, while RPE-Square reaches near-perfect accuracy in every setting. The closest competitor is Abacus (McLeish et al., 2024), which also handles unaligned data formats and achieves non-trivial generalization across all five tasks; however, the paper reports that RPE-Square's overall evaluation results are consistently better than Abacus's. The paper attributes the failures of RPE, RoPE, NoPE, and ALiBi to their inability to handle the unaligned data format nuisance (e.g., URF addition where string length does not reflect problem scale), while RPE-Square's design explicitly addresses both the LDHD generalization in the latent space (via the RPE structure) and the data format nuisance (via relative distances to special tokens like [BOS], +, and =).

## Relation to Prior Work

This paper extends Abbe et al.'s (2023) result that random feature models converge to min-degree interpolators under GD by showing that with projection matrices, convergence is to min-degree interpolators w.r.t. architecture-specific linearly independent sets, unifying the inductive bias analysis across RFM, PLAA-APE, and PLAA-RPE. It builds on Shaw et al.'s (2018) RPE by proposing RPE-Square, which augments relative position encoding with attention-weighted distances to special tokens to handle unaligned data formats. Conceptually, the paper departs from prior length generalization work (Jelassi et al., 2023; Zhou et al., 2023; Kazemnejad et al., 2024) that conflates input string length with problem scale, by formally disentangling the two into LDHD generalization in a latent space and a data format nuisance.

## Why It Matters / Open Questions

The No-Free-Lunch Theorem for LDHD generalization provides a clean impossibility result that explains why length generalization requires architecture-specific inductive bias, and the min-degree interpolator characterization under different bases gives a principled lens for understanding why APE fails while RPE can succeed. The CoT-as-latent-space-restructuring interpretation offers a useful conceptual explanation for why CoT helps length generalization without increasing the latent dimension. However, the theory is developed on highly simplified models (PLAA, RFM) and the empirical validation uses small GPT-2 models on synthetic arithmetic tasks, leaving open whether the principles transfer to larger, more complex architectures and real-world reasoning tasks. A full paradigm for position embedding design beyond the two proposed variants (RPE-Square, RPE-Absolute) remains to be developed.

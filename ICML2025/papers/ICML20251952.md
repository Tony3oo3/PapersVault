## Problem

It was unknown whether monotone submodular maximization (selecting k-out-of-n elements to maximize a submodular objective) admits sublinear-query approximation algorithms for intermediate regime values of k. Prior work established only Ω(n/k) query lower bounds, leaving open the critical regime polylog(n) ≤ k ≤ n/polylog(n). This paper resolves the question by proving a near-linear Ω̃(n) lower bound for all k = o(n), even for merely estimating the optimal value, and characterizes the exact complexity for the additive special case.

## Input / Output

The algorithm receives oracle access to a set function f: {0,1}^n → R⁺ (monotone submodular or additive) and a cardinality constraint k, where each query f(S) returns the function value of subset S. For the search problem, the output is a k-subset S with f(S) ≥ α·f(S*); for the decision problem, the output is a (1±ε)-approximation to the optimal value f(S*). The LINEARSUM algorithm for additive functions uses Õ(n/k) queries but Õ(n) computation time, reflecting the practical distinction between expensive oracle evaluations (e.g., training a model) and cheap local computation.

## Method

The lower bound reduces submodular maximization to a multi-party distributed set detection problem: m ≈ Θ(log n) parties each observe n Bernoulli coins (k fair, n−k biased), and the optimal k-subset corresponds to the fair coins. A distributed strong data processing inequality (SDPI) combined with a direct-sum argument yields an Ω̃(n) communication lower bound, which translates to an Ω̃(n) query lower bound via a polylog(n)-overhead simulation. For the decision problem, a two-level truncation of the linear function masks information on large query sets, forcing detection of a non-trivial fraction of fair coins. The upper bound for additive functions (LINEARSUM) is a multi-scale quantile estimation algorithm: at each scale k_r = (1+ε)^r, it either directly estimates the k_r-th quantile (for large k_r) or randomly partitions [n] into nk_r/k buckets and estimates the k_r-th largest bucket value minus the average bucket value (for small k_r), then takes a weighted sum across scales to recover the top-k sum within (1±ε) factor.

## Results

The paper establishes a near-linear query lower bound of Ω(α¹¹n/log²(n)) for approximating the value of the optimal k-subset under any monotone submodular objective (Theorem 3.9), and Ω(α⁵n/log²(n)) for finding an approximately optimal k-subset (Theorem 3.7), for any k = o(n). For the additive special case, the paper provides a sublinear algorithm using Õ(n/k) queries to estimate the optimal value within (1±ε) (Theorem 4.1), and proves a matching lower bound of Ω(α³n/k·log(n)) (Theorem 4.7). These results fully resolve the query complexity of monotone submodular maximization up to polylog factors across all regimes of k.

## Baselines & Comparisons

The paper's main comparison is against the prior state-of-the-art lower bounds by Li et al. (NeurIPS'22) and Kuhnle (AISTATS'21), which established Ω(n/k) query complexity for constant-factor approximation. For the critical regime polylog(n) ≤ k ≤ n/polylog(n), this paper's Õ(n) bound is a polynomial improvement — for example, when k = √n, the previous bound gives Õ(√n) while this paper gives Õ(n), a quadratic gap. The technique is fundamentally different: prior bounds use counting arguments, while this paper reduces query complexity to communication complexity via a distributed set detection problem, leveraging the distributed strong data processing inequality (SDPI) and a direct-sum argument. For the additive decision problem, the paper achieves a near-tight characterization: the Õ(n/k) upper bound (Theorem 4.1) matches the Ω(n/k·log(n)) lower bound (Theorem 4.7) up to polylog factors, which is the first sublinear algorithm for this problem. The two-level truncation construction (Eq. 2–3) is a key technical novelty that extends the lower bound from the search problem to the decision problem, where a naive linear function would be insufficient.

## Relation to Prior Work

This paper builds on the query complexity lower bounds for submodular maximization established by Li et al. (NeurIPS'22) and Kuhnle (AISTATS'21), who proved Ω(n/k) bounds using counting arguments. The authors depart fundamentally from this approach, instead reducing the problem to a multi-party communication complexity problem (distributed set detection) and proving a near-linear lower bound via the distributed strong data processing inequality and a direct-sum argument. For the positive result on additive functions, the multi-scale quantile estimation algorithm has no direct predecessor in the submodular maximization literature, though it draws on standard sublinear algorithm techniques (random sampling, partitioning, concentration inequalities).

## Why It Matters / Open Questions

This paper fully resolves the query complexity of monotone submodular maximization up to polylog factors, ruling out sublinear-query algorithms for all k ≪ n — a sweeping negative result that closes a fundamental open question in optimization theory. The practical implication is significant: for applications like dataset selection or influence maximization where queries are expensive (e.g., training a model per query), one cannot hope to find or even estimate the optimal subset value with sublinear queries for general submodular objectives. The positive result for additive functions (estimating the optimal value in Õ(n/k) queries) provides a practical tool for assessing dataset value before committing to expensive selection procedures. Open questions include closing the polylog gap and extending the communication-complexity technique to other sublinear models (streaming, dynamic).

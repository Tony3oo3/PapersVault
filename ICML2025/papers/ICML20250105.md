## Problem

While static embeddings of arbitrary metrics into ℓp spaces with O(log n) distortion are well understood (Bourgain, 1985), and a decremental dynamic algorithm exists (Banihashem et al., 2024), no efficient fully dynamic algorithm was known for maintaining such embeddings under both edge insertions and deletions. Moreover, a prior lower bound showed that explicitly outputting all embedding changes is impossible in the fully dynamic model, leaving open whether an implicit maintenance strategy could circumvent this barrier.

## Input / Output

The algorithm receives a weighted undirected graph G=(V,E) with integer edge weights in [1,W] undergoing a stream of edge insertions and deletions, and maintains an embedding function ρ:V→R^ℓ that is queried on demand for individual vertices rather than explicitly outputting all changes. Vertices in different connected components are assigned a fixed large distance W'≫nW (a 'default edge'), and the embedding is non-contractive with high probability. The query time is O(q·log(nW)·log(n)) per vertex, and the amortized update time is m^{1/q+o(1)} with high probability.

## Method

The algorithm maintains k=Θ(log n) independent copies of a fully dynamic tree embedding (from Forster et al., 2021) that produces a rooted forest with the edge-dominant property: every path between two vertices contains a 'heavy' edge whose weight is at least β_q·d_T(u,v). Each forest is converted to a single tree by connecting all roots to a new super-root with weight W', then every edge weight is multiplied by an independent random factor γ_e drawn uniformly from {1,2}. The embedding of a vertex is its distance to the super-root in the noise-scaled tree, and the final embedding concatenates distances across all k trees. The key insight is that the random {1,2} scaling injects enough noise to guarantee the lower distortion bound: the edge-dominant property ensures a single heavy edge on any u–v path contributes variance large enough to prevent concentration, so the expected distance in the scaled tree is Ω(d_G(u,v)). Repeating the procedure k times yields non-contractivity with high probability via a union bound over coordinates.

## Results

The paper presents the first fully dynamic algorithm for embedding graph metrics into ℓ_p spaces. For any integer parameter q ≥ 2, the algorithm achieves O(log(n))^{2q} O(log(nW))^{q-1} expected distortion with O(m^{1/q+o(1)}) amortized update time and O(q log(n) log(nW)) query time, while maintaining non-contractivity with high probability. A matching lower bound (Theorem 1.2) shows that any fully dynamic algorithm that explicitly outputs all embedding changes requires Ω(n) amortized update time, even for sublinear expected distortion, establishing the necessity of the implicit (query-based) maintenance model.

## Baselines & Comparisons

This is a purely theoretical paper with no experimental baselines or datasets. The key theoretical comparisons are: (1) The static result of Bourgain (1985) achieves O(log n) distortion into ℓ_p with O(log² n) dimensions, which is tight; the dynamic algorithm here pays a factor of O(log(n))^{2q-1} O(log(nW))^{q-1} over this static bound in exchange for dynamic maintenance. (2) The prior decremental algorithm of Banihashem et al. (2024) achieves O(log³ n) expected distortion but only handles edge weight increases (no deletions); the present work extends to the fully dynamic setting (both insertions and deletions) at the cost of a worse distortion bound parameterized by q. (3) The dynamic tree embedding of Forster et al. (2021) achieves the same O(log(n))^{2q} O(log(nW))^{q-1} expected distortion but into trees rather than ℓ_p spaces; the present paper's contribution is converting this into an ℓ_p embedding via the novel noise-injection technique (randomly scaling edge weights by {1,2}). The paper also strengthens the lower bound of Banihashem et al. (2024) from requiring high-probability distortion to only requiring expected distortion plus non-contractivity.

## Relation to Prior Work

This paper extends the dynamic metric embedding line of work from the decremental setting (Banihashem et al., 2024) to the fully dynamic setting, where both edge insertions and deletions are allowed. The core subroutine is the fully dynamic probabilistic tree embedding of Forster et al. (2021), which the authors augment with a previously unnoted edge-dominant property and a random noise injection step (multiplying edge weights by uniform {1,2} values) to convert tree distances into valid ℓ_p coordinates. The static ℓ_p embedding framework of Bourgain (1985) and Bartal's probabilistic tree embeddings provide the conceptual template, but the dynamic adaptation requires fundamentally different proof techniques, particularly for the lower bound where approximate distance oracles fail.

## Why It Matters / Open Questions

This is the first fully dynamic algorithm for ℓ_p embeddings, closing a gap between the decremental result of Banihashem et al. and the fully dynamic tree embedding of Forster et al. The strengthened lower bound (explicit output is impossible even with only expected distortion, not just high-probability distortion) clarifies the fundamental limitations of dynamic embedding maintenance and justifies the implicit-query model. Open questions include whether the O(log n)^{2q} distortion can be improved, whether the oblivious adversary assumption can be relaxed, and whether the edge-dominant tree property can be leveraged for other dynamic embedding targets beyond ℓ_p.

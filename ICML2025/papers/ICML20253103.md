## Problem

VLA models trained via imitation learning replicate the demonstration distribution but cannot distinguish or exploit varying data quality, limiting manipulation accuracy on mixed-quality datasets. While offline RL excels at learning from such data, integrating RL's return-maximization principle into VLA models—particularly with widely applicable dense rewards for visual-language manipulation—remains underexplored.
![Teaser figure](../imgs/ICML20253103/cropped_page2_idx0.webp)

## Input / Output

The model consumes a language instruction (or empty string for unannotated data), a 10-frame stack of RGB images, and proprioceptive state, all encoded via CLIP, ViT+Perceiver Resampler, and MLP respectively. It produces a k-step action trajectory (k=5 for CALVIN, k=64 for UR5) via a CVAE-based action decoder, a binary gripper action, a predicted future image, and a ReturnToGo vector. Unusually, the RTG is treated as a first-class modality with its own [RTG] token embedding, and its hidden-layer features are concatenated with action features to condition the action decoder in a single forward pass—eliminating the two-inference requirement of Reinformer and the need to manually set an initial RTG value at deployment.

## Method

ReinboT introduces a four-component dense reward (sub-goal achievement via MSE/SSIM/ORB matching, task progress, behavior smoothness, and task completion) computed over heuristically decomposed sub-goal segments identified by near-zero joint velocity and gripper state changes. ReturnToGo is modeled as a novel input modality in a GPT-2 backbone, predicted through an expectile regression loss (parameter m=0.9) that biases predictions toward the upper tail of the data distribution, effectively implementing return maximization without an explicit RL value-function loss. The architecture is modular: the backbone produces [RTG] and [ACTION] token features, the RTG decoder extracts hidden features, and these are concatenated with action features before a CVAE-based action decoder predicts the trajectory—all in one inference. Weights are initialized from GR-1's Ego4d video pre-training, and the total loss combines the RTG expectile loss (weighted by λ=0.001), smooth-L1 arm action loss, cross-entropy gripper loss, and pixel-level image prediction loss.

## Results

On the CALVIN mixed-quality dataset (trained on ~30,000 trajectories including failure data, tested on environment D), ReinboT with the full dense reward achieves an Average Length (AL) of 2.26, meaning it successfully chains 2.26 language instructions on average. This represents a 24% improvement over the best offline RL baseline RWR (AL 1.82) and a 60% improvement over the best imitation learning baseline PIDM (AL 1.73). For 5-instruction chains, ReinboT achieves a 21% success rate versus 11% for RWR and 13% for PIDM.

## Baselines & Comparisons

ReinboT (dense, full) outperforms all five baselines on the CALVIN mixed-quality benchmark. Against the imitation learning baselines, the gap is substantial: RoboFlamingo achieves AL 0.83, GR-1 achieves 1.36–1.41, GR-MG achieves 1.41, and PIDM achieves 1.73, while ReinboT reaches 2.26. The closest competitor is the offline RL baseline RWR with the same dense reward (AL 1.82), which ReinboT surpasses by 0.44 in AL and by 10 percentage points on 5-instruction success rate (21% vs. 11%). Notably, GR-1 trained on the full mixed-quality dataset (AL 1.36) actually underperforms GR-1 trained only on the small annotated subset (AL 1.41), suggesting that imitation learning cannot effectively exploit the additional mixed-quality data, whereas ReinboT's return-maximization objective does. The paper also shows that predicting each reward component separately (dense, full) rather than a single scalar return (dense, single) further boosts AL from 1.90 to 2.26, highlighting the value of the multi-component dense reward design.

## Relation to Prior Work

ReinboT extends the max-return sequence modeling paradigm of Reinformer (Zhuang et al., 2024) from task-specific offline RL to a general-purpose VLA model, building on the GPT-style architecture and video pre-training of GR-1 (Wu et al., 2024). It departs from prior VLA+RL efforts (Mark et al., 2024; Zhai et al., 2024; Nakamoto et al.) that fine-tune imitation-learned policies with sparse rewards or Q-function corrections, instead treating ReturnToGo as a first-class modality within the VLA backbone and using expectile regression to internalize return maximization without an explicit RL loss. The dense reward design (sub-goal achievement, task progress, behavior smoothness, task completion) is novel relative to the binary success or LLM-derived distance rewards used in earlier VLA+RL work.

## Why It Matters / Open Questions

The paper provides a concrete, end-to-end recipe for integrating offline RL return maximization into VLA models, addressing the practical problem that mixed-quality training data (including failures and noisy trajectories) degrades imitation learning. The finding that GR-1 trained on all mixed-quality data actually underperforms GR-1 trained only on annotated data (AL 1.36 vs. 1.41) is a useful diagnostic for the field. Open questions include whether the dense reward design generalizes beyond CALVIN-style tabletop tasks to more complex, multi-object, or deformable-object manipulation, and whether the approach scales to larger models and datasets as the authors note as future work. The sensitivity of the expectile parameter m (0.99 underperforms 0.9) also suggests the method may require careful tuning per task.

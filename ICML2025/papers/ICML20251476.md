## Problem

Multiple kernel clustering (MKC) algorithms have O(n³) computational complexity, making them infeasible for large-scale datasets. Existing large-scale extension methods either require sampling many data points (increasing iterative cost) or have per-iteration complexity still dependent on n. This paper introduces the 'core kernel' concept—a small set of s×s kernel matrices that provably approximate the kernel weights of the full n×n matrices—to decouple the expensive kernel-weight optimization from the sample size.

## Input / Output

The method takes a training set of n feature vectors, m base kernel functions, and s randomly selected anchor points (s ≪ n), and produces s×s core kernel matrices plus approximated kernel weights. The large-scale extension then constructs n×s kernel similarity matrices, forms a weighted combination using the approximated weights, and extracts the first k left singular vectors via SVD to obtain the clustering indicator matrix. The final output is cluster assignments obtained by running standard k-means on this n×k matrix, with overall time complexity linear in n when m and s are held constant.

## Method

The SVD-CK construction selects s anchors, computes the n×s kernel similarity matrix P_p for each base kernel, performs eigen-decomposition on P_p^T P_p to obtain right singular vectors V_p and singular values D_p, and constructs the s×s core kernel as V_p D_p^{1/2} V_p^T. The key insight is that the singular values of (1/√(ns))P_p provably approximate the eigenvalues of the full (1/n)K_p matrix with O(log(n/δ)/ε²) anchors, while the right singular vectors serve as eigenvectors of the core kernel. For large-scale extension, the approximated kernel weights are used to form a weighted n×s matrix P_α, whose first k left singular vectors approximate the top-k eigenvectors of the full kernel matrix (Nyström-style). The paper proves that SVD-CK satisfies the (1+ε)-approximation core kernel definition for three MKC algorithms—SMKKM, SMKKM-KWR, and MKKM-MR—by bounding the per-iteration gradient differences between the full and core kernel optimization trajectories.

## Results

On the three large-scale multi-view datasets, the proposed core-kernel extensions of MKC algorithms (SMKKM(CK), SMKKM-KWR(CK), MKKM-MR(CK)) achieve NMI of 97.53–98.07% on CIFAR-10, 96.96–97.33% on MNIST, and 54.12–59.24% on Winnipeg, substantially outperforming all four large-scale multi-view clustering baselines. MKKM-MR(CK) attains the best NMI on every dataset (98.07%, 97.33%, 59.24%). Execution times range from 38.99 s (CIFAR-10) to 259.24 s (Winnipeg), remaining competitive with or faster than most baselines while delivering far superior clustering quality.

## Baselines & Comparisons

All three proposed core-kernel MKC methods decisively outperform every baseline on NMI across all three datasets. On CIFAR-10, MKKM-MR(CK) reaches 98.07% NMI versus the best baseline OPMC at 83.81% (a 14.3-point gap), while on MNIST it achieves 97.33% versus LMVSC's 84.75% (12.6-point gap). On Winnipeg, MKKM-MR(CK) leads with 59.24% NMI compared to LMVSC's 51.94% (7.3-point gap). In terms of runtime, the proposed methods are competitive: MKKM-MR(CK) is the fastest on CIFAR-10 (38.99 s vs. OPMC's 27.56 s for OPMC which is actually faster, but MKKM-MR(CK) is faster than RMKMC at 162.09 s and AWMVC at 203.01 s). On Winnipeg, OPMC is the fastest baseline (20.29 s) while the proposed methods take 248–288 s, reflecting the cost of computing kernel similarity matrices for 325k samples, yet they still deliver substantially better clustering quality.

## Relation to Prior Work

This paper introduces the 'core kernel' concept for multiple kernel clustering (MKC), directly inspired by the coreset framework from Har-Peled & Mazumdar (2004) but adapted to approximate kernel weights rather than clustering loss. It builds on Liang et al. (ICML 2023), which used random sampling for kernel weight approximation, and Liang et al. (TPAMI 2024), which employed SVD-based approximation but with iterative complexity dependent on n. The key departure is that SVD-CK constructs s×s core kernel matrices whose construction and use in the iterative MKC optimization are independent of n, and the method generalizes beyond SMKKM to also cover SMKKM-KWR and MKKM-MR with matching theoretical guarantees.

## Why It Matters / Open Questions

The core kernel provides a clean, general theoretical framework (Definition 3.1) that any MKC algorithm based on kernel weight learning can leverage for large-scale extension, rather than requiring algorithm-specific approximations. The Õ(1/ε²) anchor requirement and the resulting near-linear scaling make MKC practical on datasets with hundreds of thousands of samples, as demonstrated on Winnipeg (325K points). Limitations include the eigenvalue gap assumption (Assumption 3.2), which may not hold for all kernel configurations, and the current proofs cover only three specific MKC algorithms. The authors note potential extension to multi-view clustering approximation as future work, suggesting the core kernel concept could become a broader tool beyond MKC.

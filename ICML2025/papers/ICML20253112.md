## Problem

Mode connectivity—the empirical observation that distinct SGD minima are linked by low-loss paths—underpins applications like model merging and ensembling, yet its theoretical explanation remains largely conjectural. Existing analyses rely on sublevel-set connectivity or dropout stability, leaving the role of parameter space symmetry (both continuous rescaling and discrete permutation) in shaping the topology of the minimum set unexplored. This paper asks: can the connectedness of the minimum be derived directly from the topology of the symmetry group acting on the parameter space?

## Input / Output

The analysis takes a multilayer network's weight matrices (W₁,…,Wₗ ∈ ℝ^{h×h}), full-rank input/output data (X, Y ∈ ℝ^{h×h}), and a loss function L: Param → ℝ, and produces topological invariants of the minimum set L⁻¹(0): the exact number of connected components (e.g., 2^{l−1} for linear nets, 3 for a 1D ResNet), explicit parametric curves γ(t) = exp(t log g)·w connecting symmetry-related minima, and a curvature-based upper bound d_max on the loss barrier along linear interpolations. The framework requires only that the symmetry group action be continuous; it does not assume transitivity or freeness, so it applies to partial symmetry knowledge in overparameterized architectures.

## Method

The core mechanism is a topological reduction: by constructing an explicit homeomorphism between the minimum set L⁻¹(0) and a product of general linear groups (GL_h)^{l−1} for full-rank linear networks, the paper inherits the group's 2^{l−1} connected components and shows that skip connections merge two of them, reducing the count to 3. For mode connectivity up to permutation, the proof leverages the fact that any permutation matrix with negative determinant maps a point from one GL component to the other, thereby connecting otherwise disconnected minima. Failure cases for linear mode connectivity are derived by exploiting the unbounded rescaling orbit of homogeneous activations (σ(cz) = c^k σ(z)): two minima in the same connected component can be made arbitrarily far apart along the orbit, making the linear interpolation loss exceed any bound b. Finally, the paper constructs explicit constant-loss curves via Lie group exponentials γ(t) = exp(t log g)·w and, using the curvature κ of these curves, proves that the maximum deviation of the chord (linear interpolation) from the level set is bounded by (1/κ_max)(1 − √(1 − (κ_max‖w₂−w₁‖²/4))), yielding a Lipschitz-based loss barrier bound C_L·d_max.

## Results

The paper establishes that the minimum of a full-rank l-layer linear network has exactly 2^(l-1) connected components (Corollary 4.2), and that adding a skip connection in a 3-layer 1D ResNet reduces this from 4 to 3 components (Proposition 4.3). It proves mode connectivity up to permutation for all l-layer linear networks with hidden dimension h≥2 (Proposition 5.2), and shows that linear mode connectivity can fail with arbitrarily large error barriers for networks with homogeneous activations like leaky ReLU (Propositions 5.3–5.4). Theorem 6.2 provides a curvature-based bound: if the connecting curve has maximum curvature κ_max, the loss deviation from the minimum along the linear interpolation is at most C_L · d_max, where d_max ≈ κ_max‖w₂−w₁‖²/8 for small curvature.

## Baselines & Comparisons

This is a primarily theoretical paper without head-to-head method comparisons or benchmark tables. The symmetry-based approach complements rather than directly competes with prior theoretical frameworks: Freeman & Bruna (2017) prove connectedness for 2-layer linear networks without regularization, Nguyen (2019, 2021) prove connectedness of sublevel sets under width conditions, and Kuditipudi et al. (2019) prove connectivity under dropout stability. The paper's contribution is orthogonal—it derives exact component counts via group topology and provides explicit connecting curves, which prior work does not. Empirically, the paper validates Proposition 6.1 on 100 randomly initialized two-layer sigmoid networks (all points satisfy the predicted inequality) and demonstrates unbounded loss barriers on a 5-layer leaky-ReLU network (Figure 4), but does not compare against competing mode-connectivity algorithms such as Git ReBasin (Ainsworth et al., 2023) or REPAIR (Jordan et al., 2023).

## Relation to Prior Work

This paper carves new ground by establishing a direct topological link between the structure of parameter-space symmetry groups (particularly the general linear group) and the connectedness of the minimum set, a connection the authors explicitly note has not been previously made. It builds on the empirical discovery of mode connectivity (Garipov et al., 2018; Draxler et al., 2018), prior topological analyses of sublevel sets (Freeman & Bruna, 2017; Nguyen, 2019, 2021), and earlier work on permutation and rescaling symmetries in loss landscapes (Brea et al., 2019; Simsek et al., 2021; Zhao et al., 2023, 2024). However, rather than studying symmetries as invariances to quotient out, the paper uses the topology of the symmetry group itself (number of connected components, orbit structure, Lie group exponential map) as the primary analytical tool to count components of the minimum, construct explicit connecting curves, and bound interpolation loss barriers.

## Why It Matters / Open Questions

The paper provides the first exact count of connected components of the minimum for full-rank linear networks (2^{l-1}) and shows that skip connections reduce this number, offering a new topological perspective on why ResNets may be easier to optimize. The unbounded error barrier result (Propositions 5.3–5.4) is a clean negative result showing linear mode connectivity can fail even within a single connected component and even with permutations, tempering the empirical optimism around linear interpolation. The curvature-based bound (Theorem 6.2) gives a principled sufficient condition for approximate linear mode connectivity. Key open questions include extending these results to nonlinear networks (where the full symmetry group is often unknown), understanding how SGD's implicit bias restricts the reachable portion of the minimum, and connecting the topological structure of the minimum to generalization properties.

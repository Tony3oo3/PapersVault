## Problem

Different linear algebra backends (e.g., Intel MKL, Nvidia cuBLAS, Apple Accelerate) produce subtly different results on the same input due to floating-point non-associativity in their GEMM and convolution implementations. While these deviations are on the order of a few ULPs, it remains unclear whether they can be selectively amplified to cause a model to output conflicting class predictions depending on the backend in use. This paper demonstrates that such 'Chimera examples' exist and are constructible from valid, discrete input domains.
![Teaser figure](../imgs/ICML20251791/cropped_page0_idx0.webp)

## Input / Output

The method takes a valid discrete image (8-bit or 16-bit pixels, e.g., 28×28 grayscale for FMNIST, 32×32 RGB for CIFAR-10, 224×224 RGB for ImageNet) as a starting point and produces a Chimera example — an image in the same discrete domain that yields different predicted classes when the identical model is run on different BLAS backends. Unlike standard adversarial examples that target a single model, the output is a single image paired with a set of conflicting labels (one per backend), and the input must remain a valid quantized image throughout the search, not an arbitrary floating-point vector.

## Method

The core method is a multi-backend gradient-based search that assigns each of n backends a distinct target class, creating a 'tug-of-war' that drives the input toward the decision boundary where backend-specific rounding differences flip predictions. At each iteration, the current floating-point candidate is quantized back to the feasible discrete space S (e.g., nearest valid 8-bit image) before computing gradients, ensuring the optimization respects input constraints while still operating in continuous space. Gradients from all backends are aggregated and applied with a tanh reparameterization to maintain valid input bounds. This design is critical because the backend differences are non-continuous and non-differentiable, which causes standard single-backend adversarial search methods (binary search, boundary samples, Carlini-Wagner) to fail or achieve near-zero success rates. The paper further shows that found Chimera examples reside in 'pockets' of 1–100,000 ULPs around the decision boundary, and proposes a keyed noise defense that adds deterministic, secret-key-dependent ULP-scale perturbation to inputs to disrupt the search without retraining.

## Results

The proposed multi-backend gradient search achieves Chimera example discovery rates of 19.19% on FMNIST, 13.61% on CIFAR-10 (CPU-only backends), and 95.26% on CIFAR-10 (GPU/CPU backends). On ImageNet, success rates range from 27% to 44% for CPU-only backend pairs and reach 100% when Nvidia cuBLAS is involved. Spatial analysis reveals that discovered Chimera examples reside in 'pockets' of conflicting vectors spanning 1 to 100,000 ULP around the decision boundary, with CPU-only pockets rarely exceeding 100 ULP while GPU-involved pockets on CIFAR are considerably larger.

## Baselines & Comparisons

The proposed method outperforms all three baselines across every dataset and backend category. Against the boundary-sample search of Schlögl et al. (2021), the gap is most dramatic on FMNIST (19.19% vs. 0%) and CIFAR CPU-only (13.61% vs. 1.41%), while on CIFAR GPU/CPU the boundary-sample method reaches 67.38% but still trails the proposed 95.26% by nearly 28 percentage points. Against the Carlini-Wagner adversarial example search, the proposed method dominates in all settings: 19.19% vs. 0% on FMNIST, 13.61% vs. 0% on CIFAR CPU-only, and 95.26% vs. 1.76% on CIFAR GPU/CPU. The binary search baseline is uniformly weakest, achieving below 0.1% on FMNIST and CIFAR CPU-only. The key advantage of the proposed method is its multi-backend tug-of-war optimization with quantization-aware gradients, which directly targets the discrete input space S rather than operating in continuous float space.

## Relation to Prior Work

This paper extends the line of work on floating-point imprecision in neural networks (Schlögl et al., 2021; Jin et al., 2022; Voracek & Hein, 2023), which previously focused on CPU architecture differences for fingerprinting or breaking certified robustness. It repurposes the Carlini-Wagner gradient-based adversarial optimization framework, but departs from it in two key ways: a multi-backend 'tug-of-war' strategy where each backend is assigned a different target class, and a quantization step that constrains the search to the discrete input space (e.g., 8-bit images). The conceptual shift is from treating floating-point deviations as a byproduct of hardware to treating BLAS backend implementation differences (blocking, kernel size, accumulation order) as a deliberate attack surface.

## Why It Matters / Open Questions

The paper reveals that the 'negligible' floating-point differences between BLAS backends (on the order of 10^-10) can be amplified to completely flip model predictions, and that GPU backends (cuBLAS) are dramatically more vulnerable than CPU backends due to separate convolution implementations. The keyed noise defense is practical (no retraining, preserves determinism) and reduces attack success to near-zero, but the white-box threat model limits real-world applicability. Open questions include whether the vulnerability extends to non-BLAS operations (e.g., fused kernels in modern frameworks), whether the defense can be bypassed with more sophisticated search strategies, and how the attack surface scales with model depth and batch size in production deployments.

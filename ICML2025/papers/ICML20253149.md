## Problem

Evaluating open-ended game agents in Minecraft lacks a unified, scalable benchmark: existing suites like MineDojo suffer from redundant or infeasible tasks, each agent is evaluated on its own ad-hoc task set, and open-ended tasks inherently lack clear programmatic success signals, forcing reliance on costly human annotation. This makes it impossible to systematically measure how well agents generalize across diverse, compositional, and difficulty-varied scenarios.

## Input / Output

The evaluation pipeline consumes agent rollout trajectories recorded as 640×360 RGB video at 20 fps, from which one frame is sampled every 30 frames for VLM scoring, alongside a text task description. The task configuration generator takes a textual atomic-task goal and produces executable MineStudio callback parameters (spawn biome, player inventory, summoned mobs, world seed) that instantiate a diverse initial state. The AutoEval output is a set of six per-dimension scores (Task Progress, Action Control, Material Usage, Task Efficiency, Error Recognition, Creative Attempts), each on a 0–1 scale in five discrete intervals, accompanied by textual evidence and explanations extracted from the video frames.

## Method

MCU is built on three coupled components. First, a curated set of 3,452 atomic tasks spanning 11 categories and 41 subcategories serves as composable building blocks, combined via logical operators (AND, OR) and constraints (when, where, how) to generate unbounded task complexity. Second, a GPT-4o-powered configuration generator instantiates each task by sampling diverse initial states (biome, weather, inventory, mobs) with soft constraints in the prompt and a self-verification loop that uses Reflexion-style self-reflection plus MineStudio simulator error logs to reject invalid configurations. Third, AutoEval is a two-stage VLM pipeline: GPT-4o first generates task-specific scoring criteria for each of the six dimensions, then a vision-language model (GPT-4o with vision) scores sampled video frames against those criteria, yielding multi-dimensional scores that achieve 91.5% average agreement with human raters—substantially outperforming MineCLIP (34.6% F1) and enabling scalable, cost-efficient evaluation without per-task human annotation.

## Results

AutoEval (GPT-4o) achieves an average F1 of 84.0 in comparative trajectory evaluation, substantially outperforming MineCLIP (34.6) and open-access alternatives MiniCPM (60.0) and JarvisVLA (71.4). Across six evaluation dimensions, AutoEval reaches 91.5% average agreement with human raters (Table 2), with Pearson correlations ranging from 0.78 (Task Progress) to 0.63 (Creativity). Among the four foundation agents evaluated on 35 tasks, GROOT and Steve-I lead in overall task progress (category averages ~0.5–0.7), while VPT(RL) excels only on diamond-related tasks (e.g., 0.90 on 'crafting table from scratch') but collapses on unrelated ones (0.22 avg mining). Intra-task generalization is fragile: GROOT's average task progress drops from 0.50 (simple) to 0.36 (hard), a −0.14 degradation, with the largest drop on 'sleep in bed' (−0.35).

## Baselines & Comparisons

AutoEval (GPT-4o) decisively outperforms MineCLIP (Fan et al., 2022) in comparative trajectory evaluation, achieving 84.0 vs 34.6 average F1 across five task categories; MineCLIP scores 0.0 on Explore and only 45.0 on Build, while AutoEval reaches 100.0 on both Survive and Explore. Among open-access VLMs, JarvisVLA (Li et al., 2025) achieves 71.4 average F1 and MiniCPM (Yao et al., 2024) reaches 60.0, both trailing GPT-4o's 84.0, confirming that closed-API VLMs remain stronger judges for fine-grained Minecraft evaluation. Among the four foundation agents, GROOT (Cai et al., 2024) and Steve-I (Lifshitz et al., 2023) are the strongest generalists, with GROOT leading on Mining (0.67) and Combating (0.53) while Steve-I edges ahead on Crafting (0.57) and Navigation (0.73). VPT (Baker et al., 2022) in its RL-tuned form is highly specialized: it scores 0.90 on 'crafting table from scratch' (aligned with its diamond-mining objective) but drops to 0.22 average on Mining and 0.28 on Combating, illustrating poor inter-task generalization. All agents show substantial performance drops on compositional tasks (averages 0.13–0.34) and on hard-mode intra-task variants, confirming that MCU's compositional and difficulty-scaling mechanisms expose genuine limitations in current open-ended agents.

## Relation to Prior Work

MCU builds directly on MineStudio as its execution substrate and borrows the Reflexion self-verification loop for LLM-generated task configurations, but its core contribution is a unifying evaluation framework that departs from the fragmented landscape where MineDojo, BEDD, and individual agent papers (VPT, STEVE-1, GROOT) each used disjoint task sets and evaluation protocols. Where MineDojo offered 1,560 creative tasks with programmatic rewards and BEDD relied on human ratings, MCU introduces LLM-driven task configuration generation (ensuring intra-task diversity) and a VLM-based multi-dimensional AutoEval that achieves 91.5% human alignment, addressing the scalability bottleneck that limited prior benchmarks. The compositional task mechanism (combining atomic tasks with logical operators) is a novel extension beyond the fixed task lists in all prior Minecraft benchmarks.

## Why It Matters / Open Questions

MCU provides the first standardized, scalable benchmark for open-ended Minecraft agents, addressing the community's long-standing lack of a unified evaluation protocol and enabling fair cross-agent comparison. The intra-task generalization finding—that a trivial task like 'sleep in bed' drops from 0.85 to 0.50 when the bed is placed inside a house—reveals that current agents do not robustly acquire even basic interaction skills, a phenomenon previously unreported in the Minecraft agent literature. Open questions include whether AutoEval's reliance on GPT-4o introduces systematic biases (notably lower agreement on subjective dimensions like creativity, Pearson 0.63), whether the 3,452-task set adequately covers the combinatorial space of real gameplay, and whether the benchmark's difficulty ceiling will be reached as agent architectures improve.

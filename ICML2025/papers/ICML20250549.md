## Problem

Dictionary learning has successfully extracted interpretable concepts from LLMs and vision models, but these successes rely on text supervision or naturally human-interpretable domains. It remains unclear whether meaningful high-level features can be extracted from completely unsupervised foundation models in domains like cell microscopy, where prior knowledge about which concepts should exist is limited and morphological changes from genetic perturbations are often too subtle for human experts to interpret.
![Teaser figure](../imgs/ICML20250549/cropped_page1_idx0.webp)

## Input / Output

The method consumes 256×256×6-pixel Cell Painting crops processed by a ViT MAE (ViT-L/8 or ViT-G/8), extracting aggregated patch-token representations from intermediate layers (layer 16 or 33) with dimensions 1024 or 1664. Before dictionary learning, representations are centered by subtracting the control (unperturbed HUVEC) mean and PCA-whitened using the control covariance, then normalized to unit norm. Outputs include sparse feature vectors (up to 100 non-zeros out of 8192), learned codebook feature directions, per-patch token-level alignment heatmaps, selectivity scores against 5 biological classification tasks, and linear probing accuracies on well-level aggregated representations.

## Method

The core contribution is Iterative Codebook Feature Learning (ICFL), which replaces the TopK encoder in sparse autoencoders with a batched variant of Orthogonal Matching Pursuit: at each of J iterations, the top-L codebook columns most aligned with the current residual are selected, a least-squares solution is computed over those columns, and the residual is updated. Because the 'encoder' is simply batched-OMP, any feature direction aligned with some input receives gradient updates during decoder training, naturally avoiding the dead-feature problem that plagues TopK SAEs. A PCA whitening step applied to a control dataset (unperturbed HUVEC cells) acts as weak supervision, downweighting dominant biological variation (e.g., cell cycle) and amplifying perturbation-specific differences. Random resets of codebook columns with cosine similarity above 0.9 prevent feature collapse, and the decoder is trained via standard gradient descent on the reconstruction loss for 300k iterations over 40M tokens.

## Results

ICFL combined with PCA whitening extracts sparse features (K=100, M=8192) from MAE-G token representations that retain strong biological signal: linear probing on ICFL reconstructions achieves 97.2% BTA for cell type classification, 87.8% for batch, 94.6% for CRISPR knockouts, and 51.6% for siRNA perturbations (vs. 32.1% for functional gene groups). Across all five tasks, hundreds of features exhibit high selectivity (e.g., 455 features above 0.2 threshold for cell types, 141 for siRNA). ICFL reduces dead features from 7,640 (TopK SAE) to just 55 (without PCA whitening), and achieves substantially higher reconstruction cosine similarity at matched sparsity.

## Baselines & Comparisons

Against TopK SAE (Gao et al., 2024), ICFL achieves comparable linear probing BTA on reconstructions but substantially outperforms on reconstruction quality (higher cosine similarity at matched sparsity) and feature selectivity scores across all five tasks. The dead feature problem is dramatically reduced: ICFL has only 55 dead features (w/o PCA) versus 7,640 for TopK SAE, and this gap widens with PCA whitening (341 vs. 8,026). Against CellProfiler (Carpenter et al., 2006), ICFL features achieve nearly matching average selectivity scores for siRNA perturbations, with a Pearson correlation of 0.71 between the best per-label selectivity scores of the two methods. Notably, ICFL reaches comparable selectivity with ~100 non-zero features, whereas CellProfiler peaks at ~300 non-zeros, suggesting the learned features are more compact. The main caveat is that for the hardest tasks (siRNA, functional groups), both ICFL and TopK SAE lose substantial linear signal relative to the original representations, with BTA dropping from 51.6% to lower values on reconstructions.

## Relation to Prior Work

This paper extends the dictionary learning / sparse autoencoder framework for mechanistic interpretability—previously applied to text-supervised LLMs (Bricken et al., 2023; Gao et al., 2024) and CLIP-aligned vision models—to the fundamentally different setting of completely unsupervised masked autoencoders on cell microscopy images, where no prior knowledge exists about which high-level concepts should emerge. The proposed ICFL algorithm is a batched variant of the classical matching pursuit procedure (Mallat & Zhang, 1993) that replaces the TopK encoder in SAEs, addressing the dead-feature problem that plagues standard TopK SAEs. The PCA whitening pre-processing step, adapted from prior work on microscopy representation learning (Kraus et al., 2024; Kenyon-Dean et al., 2025), serves as a form of weak supervision that downweights dominant control-variation directions.

## Why It Matters / Open Questions

The paper demonstrates that mechanistic interpretability techniques can extract biologically meaningful, single-cell-resolution concepts from unsupervised foundation models in a domain where human experts struggle to identify subtle morphological differences—a capability with direct implications for drug discovery and understanding perturbation mechanisms. The 87% recall in separating perturbed from control cells via token-level heatmaps, without any cell-level supervision, is a striking result that suggests DL can reveal structure invisible to standard cosine-similarity-based analysis. However, linear probing accuracy drops substantially on tasks involving subtle morphological changes (siRNA: 51.6%, functional groups: 32.1%), and it remains unclear whether this limitation stems from the DL algorithm, model scale, or inherent non-linearity in the representation—leaving open whether more sophisticated interpretability methods or larger models could close this gap.

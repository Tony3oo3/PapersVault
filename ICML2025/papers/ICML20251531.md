## Problem

Continual reinforcement learning agents suffer from catastrophic forgetting when learning new tasks sequentially, and existing methods rely on task-specific components (separate weights, task IDs, per-task buffers) that prevent a truly shared, incrementally-updated learning architecture. The paper identifies that value and policy functions are inherently task-dependent and cannot be shared, while shared components like world dynamics must be learned online without forgetting under severe distributional shift—two challenges that prior CRL work has not jointly resolved.

## Input / Output

The agent receives a 26-dimensional state vector and a 4-dimensional action (3D end-effector displacement plus gripper torque) as the world model input x_t = [s_t, a_t], and predicts the state difference y_t = s_{t+1} − s_t. The reward function R^τ is provided externally and switches upon task change, but no task boundary or ID information is fed to the world model learning. The agent outputs a single action per step via MPC (executing only the first action from a 15-step planned sequence), while the online world model W ∈ R^{D×S} is updated incrementally with constant overhead per step.

## Method

The Online Agent (OA) decouples world dynamics learning from task-specific decision-making: it learns a unified world model online using Follow-The-Leader (FTL) shallow networks with high-dimensional sparse features (Losse encoding, 300 2D features with Λ=9 bins), solving a ridge-regularized least squares problem in closed form. A key technical contribution is a sparse incremental update rule (Eq. 4) that only modifies K ≪ D active weight rows per step, with a proven regret bound of O(√(K²D log T)) under mild assumptions, guaranteeing no forgetting by construction. For acting, OA uses model predictive control with the cross-entropy method (CEM), augmented with shift-initialization from the previous plan, colored noise for temporal correlation, and elite-candidate memory for faster convergence. Because the planner has no trainable parameters and the world model is shared across all tasks, a new task is solved zero-shot simply by supplying its reward function to the planner while the world model continues improving from new interactions.

## Results

On Continual Bench (6 sequential robot manipulation tasks), OA achieves an average performance (AP) of 72.93% and regret of 27.62%, matching the Perfect Memory upper bound (AP 73.09%) while achieving strictly lower regret (27.62% vs. 30.95%). The next-best model-based baseline, Coreset replay, reaches only AP 61.83% with regret 30.83%, and Fine-tuning collapses to AP 24.86% due to catastrophic forgetting. Model-free SAC agents with any CL technique perform substantially worse, with the best (PackNet) reaching only AP 41.72% and regret 78.50%.

## Baselines & Comparisons

OA outperforms all four CL baselines under the model-based planning framework. Against EWC (Kirkpatrick et al., 2017), which is only tested in the model-free SAC setting (AP 31.45%, Reg 77.38%), OA's model-based approach is categorically superior, reflecting the advantage of a shared world model over per-task policy regularization. Against PackNet (Mallya & Lazebnik, 2018), an architecture-based method that prunes and reuses subnetworks (AP 41.72%, Reg 78.50% under SAC), OA achieves 31.2% higher AP and 50.9% lower regret. Against Coreset replay (Vitter, 1985), the strongest baseline in the model-based setting (AP 61.83%, Reg 30.83%), OA gains 11.1% AP and 3.2% lower regret, and unlike Coreset, OA's performance does not degrade as the replay buffer proportion of older data shrinks. Against SI (Zenke et al., 2017), a regularization-based method (AP 39.96%, Reg 33.57%), OA achieves 33.0% higher AP and 5.95% lower regret. Notably, OA also beats the Perfect Memory upper bound on regret (27.62% vs. 30.95%) because its closed-form FTL update guarantees the optimal solution at each step, whereas SGD on all previous data does not.

## Relation to Prior Work

This paper builds directly on Liu et al. (2024), which introduced locality-sensitive sparse encoding (Losse) for online world model learning via Follow-The-Leader updates. The key departure is architectural: while Liu et al. use a Dyna framework that still requires per-task model-free components (value, policy), this paper eliminates those entirely by adopting a pure model-planning approach (CEM + MPC), making the world model the sole shared learning component. The planner incorporates colored noise and memory from Pinneri et al. (2021) for sample efficiency. The paper also introduces a theoretical regret bound for the sparse online update rule, which was absent in the prior work, and a new benchmark (Continual Bench) that addresses physical conflicts identified in Continual-World and the computational intractability of image-based CRL benchmarks like CORA.

## Why It Matters / Open Questions

The core insight—that a unified world dynamics learned online with a simple FTL update, combined with model-free planning, is sufficient to achieve non-forgetting CRL without task IDs, replay buffers, or regularization—offers a clean and theoretically grounded alternative to the patchwork of CL techniques (EWC, SI, PackNet, Coreset) typically bolted onto deep RL agents. The regret bound provides a rare formal guarantee in the CRL literature. However, the approach is limited to moderate-dimensional state-based observations, does not model uncertainty, lacks explicit exploration, and is restricted to episodic settings with explicit task switches, leaving open whether it scales to high-dimensional perceptual inputs or truly non-stationary environments.

## Problem

Existing OOD detectors rely on statistical patterns in entangled neural representations, neglecting the semantic structure of the data, providing only an unexplained scalar score, and making it difficult to incorporate domain-specific prior knowledge (e.g., 'stop signs are red octagons'). This paper addresses these gaps by introducing probabilistic reasoning over human-interpretable logical constraints via Markov Logic Networks, which can be seamlessly combined with any existing OOD detector.

## Input / Output

The method takes RGB images (32×32 for GTSRB, 224×224 for CelebA) and routes them through multiple lightweight DNNs that each predict a single semantic concept (e.g., CLASS, SHAPE, COLOR, or face attributes), producing a low-dimensional disentangled semantic vector. The final output is a scalar outlier score computed as the product of the MLN constraint-violation score and the survival-function-normalized score of a baseline OOD detector. Because the MLN score is a weighted sum over individual constraints, the contribution of each violated rule to the final score is directly attributable, yielding a human-readable explanation for why an input is flagged as OOD.

## Method

The core mechanism bridges DNNs and first-order logic by training separate DNNs to approximate the interpretation of each FOL predicate and function, mapping an input to a point in a semantic space where weighted logical constraints (expressed as FOL formulas) can be evaluated. A Markov Logic Network assigns a probability to each semantic configuration via a weighted sum of satisfied constraint groundings; for efficient inference, the paper uses the negative weighted sum of satisfied constraints as the outlier score, omitting the costly partition function. This MLN score is combined with any existing OOD detector by multiplying it with the detector's score normalized to [0,1] via a fitted generalized extreme value distribution survival function. A greedy constraint-search algorithm (Alg. 2) automatically discovers interpretable rules from data by iteratively adding the constraint that most improves validation AUROC, subject to a minimum-improvement threshold that acts as a complexity regularizer. MLN weights are learned by minimizing negative log-likelihood over ID data using L-BFGS, and the entire pipeline is modular—no changes to the underlying DNN or baseline detector are required.

## Results

On GTSRB, the supervised MLN+Ensemble+ achieves 99.95% AUROC and 0.13% FPR95, outperforming the best purely pattern-based baseline (Ensemble: 99.80% AUROC, 0.86% FPR95) and the prior logical-reasoning method Logic+Ensemble+ (99.82% AUROC, 0.36% FPR95). On CelebA, where constraints are softer and labeling noise is higher, MLN+Mahalanobis+ reaches 97.86% AUROC and 7.82% FPR95, substantially exceeding the Mahalanobis baseline (95.12% AUROC, 17.77% FPR95) and the strict-logic Logic+Ensemble+ (64.30% AUROC, 68.73% FPR95). The standalone MLN detector already achieves 86.16% AUROC on GTSRB, well above random, confirming that semantic constraint violations alone carry strong OOD signal.

## Baselines & Comparisons

On GTSRB, MLN+Ensemble (99.89% AUROC, 0.54% FPR95) marginally beats the Ensemble baseline (99.80%, 0.86%) and the prior strict-logic Logic+Ensemble (99.85%, 0.48%), with the AUROC gain being statistically significant (t-test p<0.05, Cohen's d≈1.27). With auxiliary outliers, MLN+Ensemble+ (99.95%, 0.13%) clearly surpasses Logic+Ensemble+ (99.82%, 0.36%), reducing FPR95 by roughly 64% relative. On CelebA, the advantage is far more pronounced: MLN+Mahalanobis (96.01% AUROC, 14.17% FPR95) outperforms the Mahalanobis baseline (95.12%, 17.77%) by ~20% relative FPR95 reduction, while the strict-logic Logic+Ensemble collapses to 54.46% AUROC / 76.55% FPR95, demonstrating that probabilistic constraint weighting is critical when real-world constraints are soft. The standalone MLN (84.13% AUROC on CelebA) already exceeds the Ensemble baseline (83.43%) and all posterior/logit-based detectors (MSP 48.68%, EBO 45.24%), indicating that semantic reasoning provides a complementary signal to neural-representation-based scores. Across all 8 pattern-based detectors tested (MSP, EBO, Ensemble, SHE, Mahalanobis, ViM, DICE, ReAct), adding the MLN consistently improves AUROC on both datasets, with the largest gains observed for weaker baselines like SHE (+10.91 AUROC on GTSRB) and EBO (+28.65 AUROC on CelebA).

## Relation to Prior Work

This paper extends the authors' prior LogicOOD work (Kirchheim et al., 2024), which enforced strict first-order logic constraints for OOD detection, by replacing rigid logical rules with probabilistic reasoning via Markov Logic Networks (Richardson & Domingos, 2006). It positions itself within the broader neuro-symbolic OOD detection literature while explicitly addressing the rigidity limitation of pure FOL approaches. The method is designed as a modular augmentation layer that can be combined with any existing pattern-based OOD detector (MSP, Mahalanobis, ViM, Ensemble, etc.), rather than replacing them, and introduces a greedy search algorithm for automatically discovering interpretable constraints from data.

## Why It Matters / Open Questions

The paper addresses a genuine gap in OOD detection: the lack of explainability and the difficulty of incorporating domain knowledge into opaque neural representations. The demonstration that probabilistic semantic constraints complement (rather than compete with) pattern-based detectors is practically useful, and the greedy constraint search provides a path toward automation. However, the evaluation is limited to two datasets with relatively simple unary predicates, and the approach requires training a separate DNN per predicate, raising scalability questions for domains with many or complex relational concepts. Open questions include whether the framework generalizes to multi-object scenes, higher-order relational constraints, and larger-scale benchmarks like ImageNet.

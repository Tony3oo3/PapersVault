## Problem

Existing world models operate on unstructured data (video, text sequences) and cannot exploit the graph-structured relationships ubiquitous in science and industry. Graph foundation models address structured data but are confined to predefined graph learning tasks, cannot handle multi-modal inputs (images, tables), and do not generalize to diverse task types like generation, recommendation, or planning. The paper asks whether a single world model framework can unify graph-structured states with multi-modal information and represent diverse tasks as actions.
![Teaser figure](../imgs/ICML20250653/cropped_page2_idx0.webp)

## Input / Output

The model takes a graph state where each node carries one or more modalities (text, RGB image, table) and edges are either explicit (domain knowledge, e.g., citation links) or implicit (embedding similarity). An action node—either 'intended' (directly referencing specific target nodes at node/edge/graph level) or 'unintended' (retrieving top-k nodes via embedding similarity, as in RAG)—specifies the task. Outputs are task-dependent: Stable Diffusion generates 512×512 or 256×256 images, while Llama-3-8B produces text predictions, class labels, yes/no link decisions, or next-action sequences. A single unified GWM is trained across all six task domains without per-task fine-tuning.

## Method

GWM models the world state as a multi-modal graph and the action as a node linked to target state nodes, with two architectural variants. GWM-T converts all modalities to text (LLaVA for images, template prompting for tables), performs token-level message passing by concatenating neighbor text representations over multiple hops, and feeds the aggregated prompt into Llama-3-8B or Stable Diffusion via instruction tuning with LoRA. GWM-E instead encodes each modality with dedicated encoders (BERT for text/tables, CLIP for images), performs parameter-free multi-hop aggregation via powers of the normalized adjacency matrix (simplified GCN), fuses cross-modal embeddings through an MLP projector, and injects the resulting graph tokens into the LLM or diffusion model using a prefix-tuning scheme that freezes the backbone and trains only the projector. The key design choice is representing actions as graph nodes—intended actions directly reference target nodes, while unintended actions retrieve them via embedding similarity—enabling a single message-passing mechanism to serve node-level, edge-level, and graph-level tasks uniformly.

## Results

A single unified GWM model (without task-specific fine-tuning) achieves state-of-the-art or competitive results across all six task domains. On recommendation, GWM-E attains the best Recall on Baby (76.72), Sports (88.78), and Clothing (75.27), and the best F1 on Baby (84.74) and Clothing (84.06). On LongBench v2 RAG, GWM-E with only 2k context length (33.32 overall accuracy) outperforms GPT-4o mini with 128k context (29.01) and all other RAG baselines. On ALFWorld planning, GWM-E achieves the best F1 (92.13), surpassing fine-tuned T5 (91.82) and CoT prompting (87.27).

## Baselines & Comparisons

GWM-E decisively outperforms all recommendation baselines on Baby (beating GRCN by +2.37 Recall and +2.27 F1) and Clothing (beating FREEDOM by +5.07 Recall and +5.66 F1), though LightGCN retains a narrow F1 edge on Sports (91.32 vs. 90.32). On RAG (LongBench v2), GWM-E(2k) surpasses GPT-4o mini(128k) by +4.31 overall accuracy and +1.49 on hard questions, while also beating BM25(2k) by +5.87 and Dragon(2k) by +9.79. On planning (ALFWorld), GWM-E edges out T5 FT by +1.21 F1 and CoT by +4.86 F1. On traditional graph prediction, GWM-E matches or exceeds GAT on Cora link prediction (94.31 vs. 93.70) and HIV graph classification (93.86 vs. 87.84), while LLAGA leads on Cora node classification (89.22 vs. 83.03). For multi-modal generation on Multi-Modal-Paper, GWM-T achieves the best CLIP score (59.92) while GWM-E leads on DINOv2 (26.03), both surpassing INSTRUCTG2I and ControlNet. On multi-agent collaboration, GWM-T achieves the best F1 (48.20), outperforming CoT (32.25), ToT (29.71), and fine-tuned LLaMA-3-8B (44.00).

## Relation to Prior Work

This paper extends the world model paradigm (Ha & Schmidhuber, 2018) from unstructured data (video, text) to graph-structured multi-modal states, while drawing on GCN-style message passing (Kipf & Welling, 2016) for multi-hop aggregation and prefix-tuning (Li & Liang, 2021) for parameter-efficient LLM adaptation. It departs from prior graph-based WMs (L3P, Value Memory Graph) that were confined to planning, and from Graph Foundation Models (LLAGA, OFA) that were restricted to predefined graph learning tasks, by introducing action nodes as a unifying mechanism that maps diverse tasks—recommendation, RAG, multi-agent collaboration, planning—into a single graph-state formulation. The two instantiations (token-based GWM-T and embedding-based GWM-E) parallel the pixel-vs-latent distinction in diffusion models, with GWM-E inspired by Stable Diffusion's latent-space modeling.

## Why It Matters / Open Questions

The demonstration that a single unified GWM can match or beat domain-specific baselines across six heterogeneous tasks (multi-modal generation, recommendation, graph prediction, multi-agent, RAG, planning) provides a compelling argument for graph-structured world models as a general-purpose framework. The finding that GWM-E with only 2k context outperforms 128k-context LLMs on long-context RAG suggests structured retrieval via graph edges can substitute for brute-force context length. Key limitations include support for only three modalities (text, image, table), restriction to homophilous graphs, and the need for a single model trained jointly on all tasks; extending to non-homophilous structures, additional modalities (audio, video), and truly open-ended task discovery remain open.

## Problem

Existing LLM-based multi-agent communication topologies (chain, star, tree, complete graph, GPTSwarm, etc.) are static and input-independent, meaning the same structure is applied regardless of task difficulty. This leads to either unnecessary token overhead on simple tasks or insufficient collaboration on complex ones, with no principled mechanism to adapt topology to the specific query. The paper formalizes this gap as the MACP protocol, requiring topologies to be simultaneously effective, complexity-adaptive, and adversarially robust.

## Input / Output

G-Designer takes as input a natural-language query, a set of N LLM agents (each specified by base model, role, state, and plugins), and a predefined anchor topology (a simple chain in experiments). Agents are encoded into 384-dimensional embeddings via all-MiniLM-L6-v2, and the query is encoded into a task-specific virtual node that is bidirectionally connected to all agents. The output is a sparse directed communication graph (a subset of all possible agent-to-agent edges) that dictates message-passing order and content across K=3 dialogue rounds, ultimately yielding a final aggregated answer.

## Method

G-Designer employs a variational graph auto-encoder with a two-layer GCN encoder and a two-phase decoder to generate task-adaptive topologies. The encoder maps the task-specific multi-agent network (agent nodes + task virtual node + anchor edges) into latent representations; the decoder first sketches a dense adjacency matrix via an FFN with temperature-scaled sigmoid sampling, then refines it into a sparse topology by solving a nuclear-norm-regularized low-rank factorization (ZWZ^T) that simultaneously preserves anchor similarity and enforces sparsity. Training uses policy gradient (REINFORCE with M=10 samples) to maximize the utility of the final answer, with a composite loss combining utility, anchor regularization, and sparsity regularization. The task virtual node is the key mechanism enabling input-dependence: because the query embedding is encoded into the graph, the decoded topology naturally adapts its complexity to task difficulty, pruning unnecessary agents for simple queries while retaining richer structures for hard ones.

## Results

G-Designer achieves the best average score of 89.84% across six benchmarks, winning 5 out of 6 individually. Headline numbers include 84.50% accuracy on MMLU, 95.07% on GSM8K, and 89.90% pass@1 on HumanEval. In terms of efficiency, G-Designer requires only 2.7×10⁵ training tokens (vs. 5.5×10⁶ for GPTSwarm and 9.6×10⁶ for DyLAN) and 0.3h training time, while under adversarial prompt attacks it suffers merely a 0.3% accuracy drop compared to 6.2–11.0% for other methods.

## Baselines & Comparisons

G-Designer outperforms all single-agent baselines (CoT, ComplexCoT, SC, PHP) on every benchmark except GSM8K, where PHP edges ahead by 0.43% (95.50 vs. 95.07). Against static multi-agent topologies from Qian et al. (Chain, Star, Tree, Complete Graph, Random Graph), G-Designer leads by 1.3–9.5% on GSM8K and 2.4–18.2% on HumanEval. Among learned/optimized multi-agent frameworks, G-Designer surpasses GPTSwarm (Zhuge et al., ICML 2024) by 0.52% on MMLU and 1.41% on HumanEval while using only 6.11% of GPTSwarm's prompt tokens at 20 agents; it beats DyLAN (Liu et al.) by 4.34% on MMLU and 0.20% on HumanEval; and it exceeds MetaGPT (Hong et al.) by 4.0% on HumanEval. G-Designer also dominates AutoGen, LLM-Blender, and LLM-Debate across all reported benchmarks, with the largest margins on GSM8K (+4.8–9.7%) and HumanEval (+4.5–18.2%). Notably, G-Designer is the only method that simultaneously achieves top accuracy, task-adaptive token efficiency, and adversarial robustness (0.3% drop vs. 6.2–11.0% for DyLAN/AutoGen/GPTSwarm).

## Relation to Prior Work

This paper builds directly on the variational graph auto-encoder (VGAE) framework of Kipf & Welling (2016), repurposing its encoder-decoder architecture to generate agent communication topologies rather than reconstruct graph edges. It departs from the line of LLM multi-agent topology work (GPTSwarm, DyLAN, AutoGen, MetaGPT) by introducing task-dependence: prior methods use a single static or iteratively-optimized graph for all queries, whereas G-Designer encodes a task-specific virtual node alongside agent profiles to produce input-adaptive topologies. The paper also formalizes the MACP protocol as a three-criteria optimization objective (effectiveness, complexity-adaptiveness, adversarial robustness), which no prior multi-agent topology paper explicitly unifies.

## Why It Matters / Open Questions

The practical value is clear: practitioners no longer need to manually select among chain, star, tree, or complete-graph topologies, and the 92–95% token reduction on simpler tasks makes multi-agent deployment economically viable at scale. However, several open questions remain: the optimization relies on only 40–80 training queries per benchmark, the robustness evaluation covers a single prompt-injection attack type, and the method's dependence on GPT-4 API calls for both agent execution and profile generation limits accessibility. Whether the VGAE-based topology design generalizes to truly dynamic agent pools (agents joining/leaving mid-task) or to non-LLM agent backbones is unexplored.

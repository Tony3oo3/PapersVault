## Problem

Existing prompt tuning methods for CLIP create an unavoidable calibration trade-off: standard fine-tuning (CoOp) causes overconfidence on new classes by inflating textual feature divergence, while regularization-based tuning (KgCoOp) anchors confidence levels and produces underconfidence on base classes. No prior method achieves well-calibrated predictions on both base and novel classes simultaneously after fine-tuning.

## Input / Output

The method operates on RGB images paired with text class labels in a few-shot (16-shot per class) setting using CLIP ViT-B/16. During training, it additionally consumes a dynamically sampled batch of textual outliers (nouns from WordNet that are semantically near but non-overlapping with the base classes) to compute the regularization term. The output is a class prediction with a calibrated confidence score, evaluated via ECE, ACE, MCE, and PIECE on both base and new class splits.

## Method

Dynamic Outlier Regularization (DOR) constructs a pool of ~5000 textual outliers from WordNet by selecting nouns with high average semantic similarity to the base classes (via zero-shot CLIP text encoder) while excluding any overlap. During each fine-tuning iteration, a batch of these outliers is randomly sampled, and a regularization term L_dor = 1 − mean(cos_sim(ψ(t'_o), ψ(t_o))) penalizes the deviation of the fine-tuned text encoder's output from the frozen zero-shot CLIP output on those outliers. The total training objective becomes L_ce + λ·L_dor, which constrains textual divergence growth only on unseen labels while leaving base-class features free to adapt. This design avoids the gradient conflicts inherent in base-class regularization (as shown via cosine similarity analysis of prompt gradients), thereby breaking the base/new calibration trade-off without degrading classification accuracy.

## Results

Across 11 base-to-new classification datasets, DOR reduces the average ECE on new classes from 14.58% to 6.49% when applied to CoOp (an 8.09% absolute reduction), while maintaining base-class ECE at 2.67%. On the harmonic mean (HM) of base and new ECE, CoOp+DOR achieves 4.58% versus 8.82% for vanilla CoOp and 4.10% for zero-shot CLIP. In the domain generalization setting (ImageNet → V2/Sketch/A/R), CoOp+DOR reduces average ECE from 7.18% to 4.89% and improves average accuracy from 57.72% to 59.73%. DOR also boosts base-to-new accuracy: CoOp+DOR raises new-class accuracy from 61.74% to 72.01% while keeping base accuracy at 83.20%.

## Baselines & Comparisons

DOR consistently reduces new-class ECE across all 12 baselines tested. Against standard prompt tuning: CoOp's new-class ECE drops from 14.58% to 6.49%, DEPT's from 14.58% to 7.50%, CoCoOp's from 6.14% to 4.02%, and MaPLe's from 5.46% to 4.71%. Against regularization-based methods (KgCoOp, TCP, PromptSRC, CoPrompt, PromptKD), DOR breaks the calibration trade-off: while KgCoOp anchors confidence and causes underconfidence on base classes (ECE 5.82%), DOR keeps base ECE low (2.47% with CoOp) while still reducing new-class ECE (6.48%). On domain generalization (Table 5), CoOp+DOR outperforms CoOp by 2.29% in average ECE and 2.01% in average accuracy across ImageNet-V2/Sketch/A/R. For visual fine-tuning (Table 7), DOR-V reduces ECE by 4.64% over VPT and 1.82% over CLIP-adapter on DTD. DOR also improves base-to-new accuracy: CoOp+DOR gains +10.27% on new classes (61.74→72.01) and +5.25% HM over vanilla CoOp, and DEPT+DOR gains +6.35% on new classes (65.04→71.39).

## Relation to Prior Work

This paper builds directly on the prompt tuning lineage for CLIP (CoOp, CoCoOp, MaPLe, DEPT) and the regularization-based variants (KgCoOp, TCP, PromptSRC, CoPrompt, PromptKD), positioning DOR as a drop-in regularization term compatible with all of them. Conceptually, it departs from KgCoOp's approach of anchoring all textual features (base and new) to zero-shot CLIP by instead regularizing only novel-class divergence via dynamically sampled textual outliers from WordNet, thereby decoupling the calibration constraints on base versus new classes. The outlier-based regularization draws on ideas from OOD detection and noisy-label learning, but repurposes them for the specific goal of controlling textual feature divergence in vision-language models. The theoretical analysis connecting logit variance (driven by textual divergence) to expected softmax confidence extends the calibration literature for CLIP beyond the post-hoc approaches (e.g., DAC) by addressing miscalibration during the fine-tuning phase itself.

## Why It Matters / Open Questions

The paper identifies and explains a fundamental calibration trade-off in fine-tuned CLIP that the community has only partially characterized: standard tuning overconfidently inflates new-class confidence while regularization-based tuning underconfidently suppresses base-class confidence. DOR offers a simple, plug-and-play solution that breaks this trade-off, which is practically important for deploying fine-tuned VLMs in safety-critical settings (medical diagnosis, autonomous driving) where miscalibrated confidence can be dangerous. Limitations include restriction to CLIP (ViT-B/16) and prompt tuning, the need for a hyperparameter λ, and the assumption that a large lexical database (WordNet) is available. Open questions include whether the textual divergence analysis generalizes to other VLM architectures (e.g., LLaVA, Flamingo), whether the approach extends to multi-modal generation tasks, and whether the visual-outlier variant (DOR-V) can match the textual version's effectiveness at scale.

## Problem

Prior perturbation studies on mathematical benchmarks (e.g., Functional-MATH, GSM-Symbolic) only modify non-critical parameters like numerical values, preserving the underlying reasoning pattern. No work has explored hard perturbations that fundamentally alter the problem so the original solution steps become inapplicable, leaving open whether LLMs' math performance reflects true reasoning or memorized solution templates.
![Teaser figure](../imgs/ICML20250990/cropped_page1_idx0.webp)

## Input / Output

Each of the 279 benchmark problems is presented as plain text (potentially with LaTeX) under a zero-shot chain-of-thought prompt, with no tool usage or code interpreter access. The model's generated answer is checked against the ground truth using string normalization followed by sympy-based mathematical equivalence. Each problem exists in three versions—original, simple perturbation, and hard perturbation—enabling paired comparison of model behavior across difficulty levels.

## Method

The paper constructs MATH-P-Simple and MATH-P-Hard by modifying 279 level-5 MATH problems under two distinct perturbation regimes: simple perturbations make non-essential changes (numerical substitutions, adding/removing trivial constraints) so the same solution method applies, while hard perturbations introduce small but fundamental changes (raising polynomial degrees, altering key constants to make brute-force infeasible, relaxing symmetry or linearity conditions) that require genuinely different and harder problem-solving strategies. Both perturbation types enforce minimal textual edits and changed answers to prevent pattern-matching shortcuts, and are curated by 12 PhD-level annotators with cross-validation. The authors then benchmark 18 LLMs via zero-shot CoT, perform failure-mode analysis identifying a novel memorization behavior where models blindly apply learned techniques without assessing applicability, and show that in-context learning with the original problem-solution pair can actually hurt performance on hard perturbations by misleading the model.

## Results

Across all 18 evaluated LLMs, performance drops significantly on MATH-P-Hard compared to the original 279 level-5 MATH problems, with drops ranging from ~10 to ~28 percentage points. The strongest models—o1-mini (94.27% → 78.49%) and Gemini-2.0-flash-thinking-exp (92.47% → 78.14%)—suffer drops of roughly 14–16 points, while mid-tier models like GPT-4o (67.03% → 39.43%) and Claude-3.5-Sonnet (64.52% → 38.71%) lose over 25 points. Performance on MATH-P-Simple remains close to the original for most models (within ~5 points), confirming that the hard perturbations fundamentally change the required reasoning. Failure-mode analysis attributes 40% of o1-mini's errors and 25% of Claude-3.5-Sonnet's errors to a novel memorization pattern where models blindly apply learned solution techniques without checking applicability.

## Baselines & Comparisons

This is a benchmark paper, so the primary comparison is across 18 LLMs (long-CoT, closed-source, open-source, and math-specific) on three problem sets: the original 279 level-5 MATH problems, MATH-P-Simple, and MATH-P-Hard. All models degrade on MATH-P-Hard, but the magnitude varies: long-CoT models (o1-mini, o1-preview) and Gemini-2.0-flash-thinking-exp retain the highest absolute accuracy (~72–78%) yet still lose 14–16 points, while open-source 7–8B models (Llama-3.1, Gemma-2, Mathstral) collapse to 10–17% accuracy. The key differentiator is not raw capability but susceptibility to memorization: stronger models show higher memorization-attributed error rates (40% for o1-mini vs. general capability errors), whereas weaker models fail primarily on basic computation. In-context learning with the original problem and solution provides marginal net benefit (<5%) on MATH-P-Hard because the misleading effect (models copying the original solution pattern) nearly cancels the ICL effect, with large models showing 18–40% of their correct answers flipping to wrong when the original solution is shown.

## Relation to Prior Work

This paper extends the perturbation-based robustness evaluation line (Functional-MATH, GSM-Symbolic, GSM-Plus, Putnam-AXIOM) by introducing 'hard perturbations' that fundamentally alter the problem's reasoning structure, as opposed to the 'simple perturbations' (numerical or surface-level changes) used in all prior work. It builds directly on the MATH dataset's level-5 problems as seeds, and positions itself against MATH² (Shah et al., 2024) by retaining a natural 'original problem' reference that enables memorization analysis. The conceptual leap is from testing whether models can generalize across equivalent formulations to testing whether they can recognize when a formulation has changed enough to invalidate their learned solution strategies.

## Why It Matters / Open Questions

The identification of a 'blind technique application' memorization mode—where models ignore modified assumptions and default to original solution paths—provides a concrete, measurable failure mode that current benchmarks miss. The finding that ICL with the original problem-solution pair can actively hurt performance on hard perturbations (misleading effect counteracting the ICL effect) has practical implications for how demonstrations are selected in production systems. The benchmark is limited to 279 problems from a single source (MATH level-5), and the hard perturbations are hand-crafted, so scalability and coverage remain open questions. The authors argue that as average-case performance saturates, robustness to hard perturbations will become the primary bottleneck for real-world deployment of reasoning models.

## Problem

Existing model merging methods (Task Arithmetic, AdaMerging, TIES-Merging, etc.) produce only a single merged model, forcing a one-size-fits-all performance trade-off that cannot accommodate diverse user preferences for prioritizing different tasks. Naive extensions using linear scalarization with preference vectors require storing all K original fine-tuned models (KQ parameters) and running K separate optimization processes, making them computationally and memory inefficient.
![Teaser figure](../imgs/ICML20250316/cropped_page0_idx0.webp)

## Input / Output

The method consumes the pre-trained model weights θ₀, task vectors Vₖ = θₖ − θ₀ from K fine-tuned models, and optionally unlabeled data batches for entropy-based objectives. The output is a single parameter-efficient structure (base merged model plus a low-rank tensor of rank r) that, given any preference vector γ in the K-simplex, instantiates a distinct merged model on-the-fly via a tensor contraction. For ViT-B/32 with r=16 applied to attention layers, this adds only ~0.6M parameters (0.5% overhead) while enabling an infinite continuum of trade-off models rather than a single fixed merge.

## Method

Pareto Merging reformulates model merging as a multi-objective optimization problem where each task's performance (Fisher distance for data-free merging, or Shannon entropy on unlabeled data for AdaMerging) is a separate objective. The key architectural contribution is a preference-dependent personalized component W(γ) = G ×₁ A ×₂ B ×₃ γ, a c×d×1 tensor formed by contracting a core tensor G ∈ R^{r×r×K} with shared matrices A ∈ R^{r×c}, B ∈ R^{r×d}, and the preference vector γ. This decomposes into K low-rank matrices Mₖ that share A and B but differ through G, so varying γ reweights their contributions to produce different trade-offs. Training minimizes the expected smooth Tchebycheff scalarized objective over a symmetric Dirichlet preference distribution, with a Frobenius-norm regularizer on the tensor to prevent overfitting. The entire Pareto set is learned in a single optimization pass (vs. K separate runs for scalarization-based approaches), and at inference the low-rank tensor is absorbed into the base model, incurring zero additional latency.

## Results

On the 8-dataset ViT-B/32 merging benchmark, AdaMerging+PM (priority preference) achieves 85.5% average test accuracy, a 5.4-point improvement over AdaMerging alone (80.1%) and 14.4 points above Weight Averaging (65.8%). AdaMerging+TIES+PM (priority) reaches 85.9% average, the best result among all merging methods, approaching the 90.5% individual-model upper bound. For data-free merging, TIES-Merging+PM (priority) improves over TIES-Merging by 1.7 points (74.1% vs 72.4%), and Task Arithmetic+PM (priority) gains 1.9 points (71.0% vs 69.1%). The method adds only 0.6M parameters (0.5% overhead) while generating an infinite number of preference-tailored models from a single optimization run.

## Baselines & Comparisons

Against the primary unlabeled-data baseline AdaMerging, PM yields a 4.8-point average gain with equal preference (84.9% vs 80.1%) and up to 10 points on individual tasks (e.g., RESISC45: 89.0% vs 79.2%) with priority preference. Among data-free methods, TIES-Merging+PM (priority) outperforms TIES-Merging by 1.7 points on average, and Task Arithmetic+PM (priority) gains 1.9 points over Task Arithmetic. Against Pareto-set-capable baselines, AdaMerging+PM substantially outperforms MAP (85.5% vs 71.5% average) while requiring only unlabeled data versus MAP's labeled data, and dominates Rewarded Soups across nearly all preference settings (Rewarded Soups is excluded from further comparison due to its significantly inferior performance). Compared to the low-rank structures from Chen & Kwok (2024) and Dimitriadis et al. (2024), the proposed tensor achieves higher accuracy (85.5% vs 85.2%) with 7.7× fewer additional parameters (0.61M vs 4.71M). Against the concurrent Panacea SVD-LoRA structure, PM outperforms by 1.1 points with priority preference (85.5% vs 84.4%). On unseen datasets (Table 3), AdaMerging+TIES+PM achieves 75.7% average on MNIST/EuroSAT, a 7.0-point improvement over AdaMerging+TIES alone (68.7%), demonstrating the benefit of selecting from the Pareto set.

## Relation to Prior Work

This paper extends the model merging literature (Task Arithmetic, AdaMerging, TIES-Merging) by reformulating the merging objective as a multi-objective optimization problem where each base model's task performance is a separate objective. It draws on smooth Tchebycheff scalarization (Lin et al., 2024) to capture the full Pareto front rather than just convex portions, and on parameter-efficient fine-tuning (LoRA, DoRA) for the low-rank structure. The key departure from prior preference-aware merging work (Rewarded Soups, MAP) is the use of a novel c×d×1 tensor decomposition W(γ) = G×₁A×₂B×₃γ that generates a continuous Pareto set in a single optimization pass with minimal parameter overhead, rather than storing all task vectors or running n separate optimizations.

## Why It Matters / Open Questions

The practical impact is significant: a single merged model with ~0.5% parameter overhead replaces the need to store K separate fine-tuned models while enabling user-tailored trade-offs, which is directly relevant as the ecosystem of publicly available fine-tuned models (e.g., on HuggingFace) grows. The approach is modular—it can be plugged into any existing merging method (data-free or unlabeled-data-based) without requiring labeled data. Open questions include whether the approach extends to large language models (acknowledged as future work), how it behaves when the number of merged models K is very large, and whether the Dirichlet preference distribution adequately captures real-world user preference heterogeneity.

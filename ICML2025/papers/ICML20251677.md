## Problem

Theoretical runtime analysis of evolutionary neural architecture search (ENAS) has been limited to binary classification, with prior work using a search space of solution length three that cannot support standard evolutionary operators like bit-wise mutation. This paper addresses the gap by providing the first runtime analysis of ENAS for multiclass classification, establishing both upper and lower bounds on the expected number of fitness evaluations to find an optimal architecture.
![Teaser figure](../imgs/ICML20251677/cropped_page1_idx0.webp)

## Input / Output

The input is a 2D point on the unit circle (‖x‖₂ ≤ 1), partitioned into n = 2rM equal sectors, each further decomposed into a triangle and a segment. The output is a class label from M classes, determined by a softmax over M hidden-layer neurons that aggregate binary outputs from M−1 cells. The neural architecture itself is encoded as M−1 triplets of non-negative integers (n_A, n_B, n_C) representing the counts of A-type, B-type, and C-type blocks per cell, with each block type producing a distinct geometric decision region (segment, sector, or triangle).

## Method

The paper introduces the MCC benchmark problem where M classes are defined by disjoint unions of r segments, r sectors, and r triangles on the unit circle, and derives a closed-form fitness function F(x) = (Ar_tri·(ℐ_x + 2r) + Ar_seg·(𝕁_x + 2r − ε_x))/π that mathematically quantifies classification accuracy from block counts alone. A two-level search space is designed with cells at the outer level and blocks at the inner level, supporting a two-level mutation process (outer-level selects cells; inner-level applies addition, deletion, or modification of block types). The runtime analysis partitions the search space by the triangle-coverage term ℐ_x and segment-coverage term 𝕁_x − ε_x, then applies multiplicative drift analysis (and alternatively the fitness-level technique) to (1+1)-ENAS with one-bit or bit-wise outer-level mutation combined with local or global inner-level mutation. The key result is that both mutation strategies achieve the same expected runtime bounds: O(rM ln(rM)) upper and Ω(rM ln M) lower, showing that the simpler one-bit mutation is theoretically competitive with the more complex bit-wise mutation commonly used in practice.

## Results

The paper proves that (1+1)-ENAS with one-bit mutation achieves an expected runtime upper bound of O(rM ln(rM)) and lower bound of Ω(rM ln M) for finding the optimal architecture on the MCC benchmark (Theorems 4.1–4.2). The same bounds hold for (1+1)-ENAS with bit-wise mutation (Theorems 4.3–4.4), showing that both mutation strategies are theoretically equivalent. Empirically, across M ∈ {2,…,24} and r ∈ {2,…,10}, the average number of generations to find the optimum is similar for all four mutation combinations (one-bit/bit-wise × local/global), with differences typically within a constant factor (Figure 3).

## Baselines & Comparisons

This is a theoretical paper, so there are no external method baselines to compare against. The central comparison is between one-bit and bit-wise outer-level mutations within the (1+1)-ENAS framework. Both mutation types provably achieve identical asymptotic runtime bounds: O(rM ln(rM)) upper and Ω(rM ln M) lower. Empirically (Figure 3), one-bit and bit-wise mutations produce nearly identical average generation counts across all tested M and r values, with at most a constant-factor gap. Similarly, local and global inner-level mutations show comparable performance. The practical implication is that the simpler one-bit mutation (which requires no manually tuned flipping probability) is a viable default choice, supporting its use in existing ENAS methods like AE-CNN that employ single-step mutation operators.

## Relation to Prior Work

This paper extends the runtime analysis framework for evolutionary NAS from binary to multiclass classification, building directly on Lv et al. (2024b), which introduced a mathematically formulated fitness function and search space for ENAS on a binary classification benchmark. It also draws on the broader EA runtime analysis tradition (Droste et al., 2002; Doerr et al., 2008; Doerr et al., 2012) and the line of work by Fischer et al. (2023, 2024) on constructing analytically tractable fitness functions for neuroevolution. The key departure is the design of a two-level (cell/block) search space with solution length M that supports multiclass decision regions and accommodates both one-bit and bit-wise mutation operators, which the prior binary benchmark could not handle.

## Why It Matters / Open Questions

This is the first theoretical runtime analysis of ENAS for multiclass classification, establishing the MCC benchmark as a foundation for future work on population-based operators, crossover, noisy/dynamic optimization, and richer decision boundaries. The practical takeaway—that a simple one-bit mutation achieves the same asymptotic runtime as the more commonly used bit-wise mutation—offers guidance for simplifying ENAS algorithm design, though the result is proven on a specific 2D geometric benchmark with fixed block types. Significant limitations remain: the analysis covers only (1+1)-ENAS, assumes optimal parameter training, and uses a highly structured input distribution, so generalization to real-world architectures and datasets is not yet established.

## Problem

State-of-the-art vision transformers (CLIP, SigLIP, DINOv2) are inflexibly low-resolution, typically producing feature maps at 14×–16× downsample of a 224–448px input, which loses fine-grained spatial detail critical for dense perception tasks. Existing upsampling methods like FeatUp's Joint Bilateral Upsampling over-smooth object interiors and fundamentally cannot recover details too small for the encoder's native resolution, since they rely solely on a single low-res inference.
![Teaser figure](../imgs/ICML20252042/cropped_page0_idx0.webp)

## Input / Output

The method consumes an RGB image and a frozen low-resolution feature map from a vision encoder (e.g., DFN CLIP at 378²px yielding 27×27 tokens), plus a mosaic of tile-level feature maps obtained by splitting the image into u×u tiles, resizing each to the encoder's native input size, and running independent inferences. The output is a refined high-resolution feature map (e.g., 4× upsampled to 108×108) that preserves the original feature dimensionality while incorporating sub-pixel detail from the tile views. The upsampling factor is any positive integer, decomposed into prime factors for the JBU stack.

## Method

FeatSharp concatenates the JBU-upsampled feature buffer with a tiled mosaic feature map along the channel dimension, then processes them through a single transformer block using 2D sliding-window attention (window size 3–5) followed by a SwiGLU MLP, and slices the first C channels as the refined output — exploiting the residual pathway so a no-op equals the JBU result. A learnable de-bias buffer (inspired by ViT-Denoiser) is added to the frozen encoder output to cancel fixed position artifacts, improving multi-view consistency. Training uses FeatUp's multi-view consistency objective (MSE between upsampled-then-downsampled features and raw low-res predictions under random warps) with PHI-S feature normalization, but drops the CRF and TV losses. The tiling strategy borrows from VLMs (LLaVA-1.6, InternVL-1.5) to provide semantically rich high-resolution guidance at a fixed inference budget, while the JBU stack provides edge-preserving structural priors; the local attention block fuses both to resolve tile-boundary discontinuities and sharpen interiors.

## Results

On COCO 2017 object detection, FeatSharp achieves 54.83 AP with RADIOv2.5-L and 55.93 AP with SigLIP2-SO400M-512, substantially outperforming all baselines (best competitor: Bilinear at 51.61/52.69 AP). The gains are most pronounced for small objects, where FeatSharp reaches 34.72 AP (RADIO) and 36.85 AP (SigLIP2) versus 28.73 and 30.31 for the respective baselines. On ADE20K semantic segmentation, FeatSharp with 2× upsampling and 2× input size achieves 53.13 mIoU on RADIO, surpassing the published SOTA of 51.47 by +1.66 mIoU. When used as a teacher upsampler in RADIO training, FeatSharp yields a +0.39% MTL Gain across the full benchmark suite, the only method to improve across all categories.

## Baselines & Comparisons

FeatSharp decisively outperforms FeatUp (JBU) on COCO detection, achieving 54.83 vs 46.71 AP on RADIOv2.5-L and 55.93 vs 47.42 AP on SigLIP2, with the largest gap on small objects (+12.95 and +13.98 AP_Sm respectively). Against SAPA and ReSFU, FeatSharp leads by 13.39 and 5.02 AP on RADIOv2.5-L, confirming that learned bilateral upsampling alone is insufficient without tile-guided refinement. In the RADIO training setting (Table 2), FeatSharp is the only method to achieve positive MTL Gain across all seven benchmark categories (+0.39% average), while S2 (+0.03%) is marginally positive and Tile (−0.27%), FeatUp (−0.13%), and RADIOv2.5-L (−0.21%) all underperform the baseline. On ADE20K segmentation, FeatSharp 2× with 2× input size (53.13 mIoU) surpasses both the native-resolution RADIO baseline and the published RADIOv2.5-L SOTA (51.47 mIoU), while FeatUp 2× actually degrades below the 2× input baseline for RADIO and ViT. The tiling-based baselines (Tile, S2) introduce visible grid artifacts and representation discontinuities in the learned RADIO adaptor features, whereas FeatSharp produces smooth, high-detail features that remain stable across resolutions.

## Relation to Prior Work

FeatSharp extends FeatUp's Joint Bilateral Upsampling (JBU) framework by adding a tile-guided attentional refinement module and a learnable de-bias buffer, drawing the tiling strategy from VLMs (LLaVA 1.6, InternVL-1.5, Eagle) and the denoising formulation from ViT-Denoiser. The key conceptual departure from FeatUp is that tiling provides a second, semantically rich feature source at higher resolution, enabling the upsampler to recover fine-grained details that are simply absent from the single low-resolution forward pass. Feature normalization via PHI-S replaces FeatUp's LayerNorm to preserve the original feature distribution across heterogeneous teacher models, and the method is integrated into RADIO's agglomerative distillation pipeline to convert low-res-only teachers into high-res targets.

## Why It Matters / Open Questions

FeatSharp offers a practical, lightweight drop-in module that lets practitioners extract higher-fidelity features from fixed low-resolution ViTs (CLIP, SigLIP, DINOv2, SAM, etc.) without retraining the backbone, with consistent gains across segmentation, detection, and distillation. The FeatSharp-RADIO model improves over the current SOTA RADIOv2.5-L on dense vision benchmarks, suggesting that richer distillation targets from upsampling can compound into better agglomerative models. Open questions include why 3× upsampling underperforms 2× and 4×, whether progressive multi-level tiling could further improve quality, and how the method scales to non-integer or very large upsampling factors. The requirement of u²+1 forward passes (though still sub-quadratic vs. running the ViT at full resolution) remains a practical consideration for latency-sensitive deployments.

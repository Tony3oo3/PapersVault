## Problem

While data re-uploading quantum models are known for strong trainability and expressivity, their predictive performance on unseen data has remained largely uninvestigated. This paper identifies a fundamental limitation: when the data dimension far exceeds the number of available qubits (necessitating deep encoding layers), the model's predictions on new data degenerate to near random-guessing levels, regardless of training quality, loss function, or optimization method.
![Teaser figure](../imgs/ICML20252562/cropped_page0_idx0.webp)

## Input / Output

The method takes a D-dimensional classical data vector x ∈ ℝ^D (with D = 3NL for N qubits and L encoding layers), where each element follows an independent Gaussian distribution, and divides it into L chunks of 3N elements. Each chunk is encoded via single-qubit rotation gates R(x) = R_z(x₃)R_y(x₂)R_z(x₁) into the circuit, and the full data is re-uploaded P times. For binary classification, the output is the probability of the correct class obtained by measuring observables H₀ = |0⟩⟨0| or H₁ = |1⟩⟨1| on the first qubit; for regression, the output is a value in [-1,1] from measuring the tensor product of Z gates across all N qubits.

## Method

The core analysis decomposes the expected encoded quantum state in the Pauli basis and shows that under data expectation, the non-identity Pauli coefficients decay by a factor of e^{-σ²} per encoding layer, causing the state to converge exponentially to the maximally mixed state I/2^N. This is quantified via the Petz-Rényi-2 divergence, yielding the bound D₂(E[ρ]‖ρ_I) ≤ log₂(1 + (2^N - 1)e^{-Lσ²}). The analysis extends Li et al. (2022) by permitting arbitrary learnable parameterized gates between encoding layers rather than only fixed CNOT/CZ gates. For the repetition analysis, the authors construct an approximating circuit using auxiliary qubits to encode binary digits of the data, showing that P repetitions apply only data-independent unitary operations on top of the already-degraded single-upload state, so they cannot restore distinguishability. The prediction error is then bounded directly (bypassing the traditional training-error + generalization-error decomposition), showing classification error approaches 1/2 and regression error is lower-bounded by the target function's mean magnitude.

## Results

The paper establishes that the quantum divergence between the expected encoded state and the maximally mixed state decays exponentially as D₂(E[ρ]||ρ_I) ≤ log₂(1 + (2^N − 1)e^{−Lσ²}), meaning that when L ≥ (1/σ²)[(N+2)ln2 + 2ln(1/ε)], the model's expected output is within ε of the informationless value h_I. Experimentally, on a linearly separable classification task with a single qubit, test error approaches 0.5 (random guessing) as encoding layers L increase from 1 to 8, regardless of the number of repetitions P. On real-world data, MNIST (near-zero pixel variance) maintains usable test accuracy with L=6 encoding layers, while CIFAR-10-Gray degrades significantly, and RGB CIFAR-10 (L=18) performs worst due to the additional encoding layers.

## Baselines & Comparisons

This paper is a theoretical analysis and empirical validation study rather than a method comparison, so it does not benchmark against competing QML architectures. The key internal comparisons are ablations over circuit depth (encoding layers L), width (qubit number N), and repetition count P. The central finding is that with fixed data dimension D=24 and fixed total parameters, configurations with more encoding layers (e.g., N=1, L=8) suffer test error approaching 0.5, while configurations with fewer layers (e.g., N=8, L=1) retain meaningful test accuracy, even when training errors are comparable. Increasing repetitions P reduces training error but accelerates the convergence of test error to 0.5 for deep circuits. On real-world data, MNIST's near-zero variance (σ²≈0) partially mitigates the degradation, explaining why prior work reported good performance on MNIST despite deep encoding layers, whereas CIFAR-10 with non-trivial variance exhibits the predicted failure mode.

## Relation to Prior Work

This paper extends the concentration-of-encoding analysis from Li et al. (NeurIPS 2022), which showed that angle-encoded states approach the maximally mixed state with depth but was restricted to non-parameterized entangling gates (CNOT/CZ) and single-upload circuits. Here, the authors generalize to arbitrary learnable parameterized gates between encoding layers and, crucially, to the repeated data-uploading setting (P > 1) that is central to the data re-uploading paradigm introduced by Pérez-Salinas et al. (2020). The work also departs from the standard QML generalization-error decomposition (Caro et al., 2022) by directly bounding the expected model output over the data distribution, bypassing the training-error/generalization-error split.

## Why It Matters / Open Questions

The result provides a clear architectural guideline for QML practitioners: for high-dimensional data processed by limited-qubit circuits, wider (more qubits, fewer encoding layers) data re-uploading designs are preferable to deeper, narrower ones, and repeated uploading—while improving trainability—cannot rescue predictive performance once encoding depth is too large. This is important because the field has heavily emphasized trainability and expressivity of data re-uploading models, with less attention to whether the learned model actually generalizes to unseen data. Open questions include whether the independent-Gaussian assumption is too restrictive for real correlated data, whether feature engineering (e.g., PCA) can reduce effective dimensionality to avoid the degradation, and how to design large-scale data re-uploading architectures that maintain predictive fidelity for high-dimensional inputs.

## Problem

Multi-step lookahead Bayesian Optimization can overcome the myopia of one-step acquisition functions, but existing approaches either approximate the sequential dynamic program with heuristic rollout policies (yielding sub-optimal decisions) or rely on laticized GP representations that suffer from the curse of dimensionality. This paper addresses the gap of solving the multi-step lookahead BO problem in a near-optimal, scalable manner for high-dimensional search spaces.

## Input / Output

The method consumes the growing dataset of observed (x, y) pairs from the BO process along with action bounds [lb, ub], and produces a single next query point x_{t+1}. The state representation must be both permutation-invariant (data acquisition order is irrelevant) and size-invariant (the dataset grows each iteration), which the encoder handles by aggregating per-point embeddings via weighted summation. The RL agent does not query the true black-box function directly; instead it interacts with a GP posterior fitted to the current dataset as a virtual environment, receiving multi-step rewards from sampled function values.

## Method

EARL-BO combines an Attention-DeepSets encoder with a PPO actor-critic RL agent in an end-to-end, model-based framework. The encoder maps the variable-size dataset D_k to a fixed-dimensional latent state via per-point embeddings ψ, attention-weighted aggregation, and a pooling function ρ, ensuring permutation and size invariance. The PPO agent selects query points by maximizing a clipped surrogate objective over a user-defined lookahead horizon, with the critic providing a value baseline for advantage estimation. Training follows a Dyna-style loop: the agent first warm-starts from off-policy trajectories generated by TuRBO (with initial network layers frozen), then transitions to on-policy PPO updates while interacting with a GP virtual environment that samples ỹ from the posterior to simulate outcomes. This model-based design avoids expensive real function evaluations during policy learning, and the GP model improves as more BO samples accumulate, making simulated experiences increasingly reliable.

## Results

EARL-BO is evaluated using simple regret (y_opt − y_k*) on synthetic benchmarks (Ackley, Levy, Rosenbrock, Sum Squares) at 2-D, 5-D, 8-D, and 30-D, and on HPO-B search spaces of 6-D, 8-D, and 19-D. In the 30-D setting, EARL-BO significantly outperforms EI, TuRBO, and SAASBO across all four benchmark functions, with performance gaps substantially larger than in lower dimensions. On HPO-B, EARL-BO overtakes all baselines (including TuRBO and SAASBO) after approximately 8 iterations and maintains the lowest regret thereafter. Computationally, EARL-BO (3-step) requires ~840 s per BO iteration versus >3600 s for rollout-based methods and 0.28 s for EI, while scaling to 30-D adds only ~100% overhead compared to 215–533% for TuRBO and EI respectively.

## Baselines & Comparisons

Against EI and Random Search, EARL-BO shows comparable performance in 2-D (where 30 initial points provide high information density) but consistently outperforms both in 5-D, 8-D, and 30-D on complex landscapes (Ackley, Levy, Rosenbrock). Against TuRBO, EARL-BO wins in all dimensions ≥5-D on non-additive functions and on all HPO-B tasks, overtaking TuRBO after roughly 8 iterations. Against SAASBO, the picture is mixed: SAASBO dominates on the additive Sum Squares function across all dimensions, but EARL-BO outperforms SAASBO on Ackley, Levy, and Rosenbrock in 8-D and decisively across all four functions in 30-D. Against Rollout_VR (Lee et al., 2020), EARL-BO matches or slightly improves performance in 2-D while being far more computationally scalable (840 s vs. >3600 s per iteration). Against PI (Kushner, 1964), EARL-BO outperforms on all three HPO-B search spaces, confirming that multi-step lookahead yields better long-term regret than myopic probability-of-improvement strategies.

## Relation to Prior Work

EARL-BO extends the RL-based multi-step lookahead BO framework of Cheon et al. (2024), which used a laticized GP representation that suffers from the curse of dimensionality, by replacing it with an Attention-DeepSets encoder that provides a permutation- and size-invariant state representation scalable to higher dimensions. Conceptually, it departs from rollout-based lookahead methods (Lam et al., 2016; Lee et al., 2020) that approximate the POMDP value function via heuristic base policies, and from meta-learning L2O approaches (Maraval et al., 2024; Song et al., 2024) that require cross-task data, by instead using a model-based Dyna-style loop where the GP posterior serves as a virtual environment for on-policy PPO training on the single target problem. The encoder design draws directly on DeepSets (Zaheer et al., 2017) augmented with attention, while the RL component follows standard PPO (Schulman et al., 2017) with an off-policy warm-start from TuRBO.

## Why It Matters / Open Questions

This work bridges a notable gap: multi-step lookahead BO was previously confined to ≤4-D problems due to computational intractability of rollouts, while high-dimensional BO methods (TuRBO, SAASBO) were inherently myopic. The 'planning delusion' observation—that longer lookahead horizons can degrade performance due to compounding GP model errors—provides a useful diagnostic for practitioners and suggests that model fidelity, not just horizon length, governs the quality of non-myopic planning. Key limitations include the substantial per-iteration compute cost (~840 s for 3-step in 8-D), sensitivity to sparse initial data in high dimensions, and the assumption that the current GP posterior is a faithful surrogate for the true function class. Open questions include whether the GP virtual environment can be replaced with learned surrogates for non-GP-compatible objectives, and whether the approach extends to constrained or multi-objective settings.

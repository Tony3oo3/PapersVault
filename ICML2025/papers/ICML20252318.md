## Problem

Existing Lidar-based semantic and panoptic scene completion methods are restricted to closed vocabularies of roughly 20 classes from manually labeled datasets, far below the label diversity of modern image-based benchmarks. No prior work addresses zero-shot, open-vocabulary, instance-level Lidar scene completion that can complete and recognize arbitrary objects from a single sparse scan without any semantic training labels.
![Teaser figure](../imgs/ICML20252318/cropped_page0_idx1.webp)

## Input / Output

At inference, CAL takes a single sparse Lidar point cloud (no RGB or camera data) and a free-form text vocabulary of class descriptions specified only at test time. It outputs a completed 256×256×32 voxel occupancy grid at 0.2 m resolution, class-agnostic instance masks over occupied voxels, and a 768-dimensional CLIP feature per instance; semantic labels are assigned by cosine similarity between predicted CLIP features and encoded text prompts. The model is trained entirely on pseudo-labels mined from video, never accessing ground-truth semantic annotations during training.

## Method

CAL has two components: a pseudo-labeling engine and a completion model. The engine uses SAM for 2D object segmentation, SAM 2 for temporal mask propagation over a forward/backward window, backprojection to 3D via calibrated camera-to-Lidar transforms, ego-pose-based temporal aggregation, and DenseCRF refinement guided by 360° binary Lidar occupancy to fill in regions invisible to the camera; per-instance CLIP features are extracted via MaskCLIP and averaged across the temporal window. The completion model follows PaSCo's sparse-generative 3D U-Net (sparse Minkowski encoder → dense 3D conv → three-scale generative decoder with pruning) for scene occupancy, combined with a Mask2Former-style Transformer decoder that predicts class-agnostic instance masks and regresses a CLIP token per query. A key design choice is quantizing instance CLIP features into k-means prototypes and adding a pseudo-semantic head that predicts prototype class per voxel, providing implicit semantic regularization that helps the network learn shape priors despite noisy, partial pseudo-labels. Training jointly optimizes binary occupancy (weighted BCE), prototype classification (cross-entropy + Lovász), instance masks (BCE + Dice with Hungarian matching), and CLIP feature distillation (cosine embedding), ignoring unlabeled voxels to avoid penalizing predictions outside pseudo-label coverage.

## Results

On SemanticKITTI, CAL in the zero-shot (ZS) setting achieves 13.12 PQ† and 13.09 mIoU, reaching approximately 50% of the fully supervised PaSCo baseline (26.49 PQ†, 28.22 mIoU). With the semantic oracle (SO), CAL improves to 17.12 PQ† (~65% of PaSCo). On SSCBench-KITTI360, CAL(ZS) achieves 8.57 PQ† and 8.49 mIoU (~40% of PaSCo's 19.53 PQ†). Against the constructed zero-shot baselines, CAL(ZS) substantially outperforms LODE+SAL (7.74 PQ†) and LiDiff+SAL (7.35 PQ†) on SemanticKITTI.

## Baselines & Comparisons

CAL(ZS) is the first zero-shot method for Lidar panoptic scene completion and is compared against both fully supervised and zero-shot baselines. Against fully supervised methods, CAL(ZS) (13.12 PQ†) is comparable to the weakest supervised baseline LMSCNet+MaskPLS (13.81 PQ†) but trails the stronger JS3CNet+MaskPLS (18.41) and SCPNet+MaskPLS (19.39), reaching only ~50% of the state-of-the-art PaSCo (26.49 PQ†) on SemanticKITTI. The gap is largely attributed to zero-shot recognition quality (RQ: 8.44 vs. 23.65 for PaSCo) rather than completion quality, as the semantic oracle setting (CAL SO) narrows the gap to ~65% of PaSCo. Against the two constructed zero-shot baselines, CAL(ZS) substantially outperforms LODE+SAL (7.74 PQ†) and LiDiff+SAL (7.35 PQ†) by 6–7 PQ† points, demonstrating that its pseudo-labeling pipeline and joint completion-recognition architecture are significantly more effective than naively combining a completion model with a zero-shot segmentation model. On SSCBench-KITTI360, the relative gap to PaSCo widens (~40% vs. ~50% on SemanticKITTI), suggesting the method benefits from the larger and more diverse KITTI-360 training set but still lags behind supervised methods trained on full-coverage annotations.

## Relation to Prior Work

CAL builds directly on the PaSCo architecture (sparse-generative 3D U-Net + Mask2Former-style transformer decoder) for panoptic scene completion, but replaces its reliance on manually labeled closed-vocabulary data with a pseudo-labeling pipeline that mines 3D shape priors from unlabeled LiDAR sequences. The pseudo-labeling engine repurposes 2D vision foundation models (SAM for segmentation, SAM 2 for video tracking, MaskCLIP for semantic features) and lifts them into LiDAR space via calibrated multi-modal registration, a strategy analogous to SAL's zero-shot LiDAR segmentation but extended to temporal aggregation and shape completion. The key conceptual departure from prior SSC/PSC work is that semantic information is entirely absent during training; the model learns class-agnostic instance completion and regresses CLIP features per instance, enabling open-vocabulary prompting at test time.

## Why It Matters / Open Questions

This is the first framework to address zero-shot, open-vocabulary LiDAR panoptic scene completion, bridging a gap between 2D foundation-model capabilities and 3D LiDAR perception that prior work has only addressed for segmentation (SAL) or detection. The finding that a model trained on noisy, partially-covered pseudo-labels (~28% mask coverage before CRF) can still learn to infer full object shapes from aggregate partial observations across a dataset is a useful inductive-bias result. However, the method remains computationally expensive (SAM 2 video propagation + CRF per sequence), achieves only ~50% of fully supervised PaSCo, and its zero-shot baselines (LODE+SAL, LiDiff+SAL) are weak, leaving the practical gap to supervised methods substantial. Open questions include whether self-supervised LiDAR forecasting can improve coverage in unobserved regions, and whether the approach scales to larger unlabeled datasets or more diverse driving scenarios.

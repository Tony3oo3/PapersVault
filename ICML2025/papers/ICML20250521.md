## Problem

Worst-case lower bounds for distributed distinct element estimation (Ω(α/ε² + α log n) bits) rely on instances where a constant fraction of coordinates appear across a constant fraction of servers, an assumption that is unrealistic for real-world data following Zipfian or power-law distributions. This paper asks whether the problem remains hard under more realistic collision structures and introduces the number of pairwise collisions C as a fine-grained parameter that explains when and why the worst-case bounds can be broken.

## Input / Output

The protocol operates in the coordinator model: α servers each hold a binary vector v⁽ⁱ⁾ ∈ {0,1}ⁿ over a shared universe [n], and all communication flows through a designated coordinator in sequential rounds. The input additionally includes an accuracy parameter ε ∈ (0,1) and, for the improved Algorithm 2, a promised upper bound C on the number of pairwise collisions (ordered triplets (a,b,i) with v⁽ᵃ⁾ᵢ = v⁽ᵇ⁾ᵢ = 1). The output is a (1+ε)-approximation to F₀(S) = |{j : vⱼ ≥ 1}| with probability at least 2/3, where the communication cost is the total bits sent by all parties in the worst case.

## Method

The core insight is that when C = β·F₀(S) pairwise collisions exist, the total number of items that must be transmitted at the relevant subsampling level is O(√β · min(F₀(S), 1/ε²)) rather than O(α/ε²), because the RMS-AM inequality bounds the sum of per-item server counts by √(βN). Algorithm 1 first computes a 4-approximation to F₀ via geometric subsampling (O(α log n) bits), then subsamples the universe at rate 2⁻ⁱ chosen so the expected number of survivors is Θ(1/ε²), and each player sends its surviving items. Algorithm 2 further improves the C < F₀(S) regime by computing F₁(S) exactly in O(α log n) bits and then estimating the excess mass D = F₁ − F₀ via a second subsampling pass at probability p = min(1, 100C/(η²X²)), where the variance of the estimator is controlled by the promise (t₁²+…+tₙ²) ≤ C. Matching lower bounds are established by parameterizing the SUM-DISJ reduction (Theorem 1.3) and by introducing a new GapSet composition problem that combines GapAnd with multiplayer pairwise disjointness, yielding Ω(C/(ε²·F₀(S))) communication for small C (Theorems 1.4–1.5).

## Results

The paper establishes that distributed distinct element estimation with C = β·F₀(S) pairwise collisions requires only O(α log n + √β/ε² · log n) bits of communication (Theorem 1.1), breaking the previous worst-case lower bound of Ω(α/ε² + α log n) whenever β < α. Matching lower bounds (Theorems 1.3–1.4) confirm C is a tight complexity parameter across all regimes. Empirically on the CAIDA traffic dataset (~40M events, 42,200 unique sender IPs), the proposed protocol outperforms the standard O(α/ε²)-sketch baseline by several orders of magnitude in communication, while achieving >95% accuracy at ε = 1/16.

## Baselines & Comparisons

The primary baseline is the standard distributed protocol derived from the Kane et al. (2010) / Blasiok (2020) streaming algorithm, which sends an O(1/ε²)-size sketch per server for a total of O(α/ε² + α log n) bits. The paper's Algorithm 1 (Theorem 1.1) strictly improves upon this whenever the number of pairwise collisions C = β·F₀(S) satisfies β < α, reducing communication from O(α/ε²) to O(√β/ε²). On the CAIDA dataset, where the receiver IP distribution is highly Zipfian (exponent ≈ 0.743), the number of pairwise collisions is small enough that the proposed protocol uses orders of magnitude fewer bits than the standard O(α/ε²) sketch-based approach across all tested values of ε = 1/2^p for p ∈ {2,…,11} (Figure 2a). The accuracy of the proposed protocol converges rapidly, achieving ~70% accuracy at ε = 1 and >95% at ε = 1/16 (Figure 2b), matching the theoretical (1+ε)-approximation guarantee. The lower bounds (Theorems 1.3–1.4) confirm that no protocol can beat the √β or C/(ε²·F₀(S)) dependence, establishing the parameterization as tight.

## Relation to Prior Work

This paper builds directly on the tight worst-case bounds for distributed F₀ estimation: the O(α/ε² + α log n) upper bound from Kane et al. (2010) and the matching Ω(α/ε² + α log n) lower bound from Woodruff & Zhang (2014), which together seemed to resolve the problem. It departs from this line by introducing the number of pairwise collisions C as a new complexity parameter, showing the worst-case lower bound is not tight when C is small relative to α²·F₀(S). The lower bound technique introduces a novel GapSet composition problem (Gap-Hamming outer problem composed with multiplayer pairwise disjointness inner problem), leveraging the information complexity and direct sum framework of Bar-Yossef et al. (2004) in a non-standard 'reverse' direction.

## Why It Matters / Open Questions

This work provides a principled parameterized complexity framework that explains why worst-case hardness results for statistical estimation problems do not manifest on realistic (e.g., Zipfian) data, with pairwise collisions identified as the tight governing parameter. The matching upper and lower bounds across all regimes of C and F₀(S) establish a complete complexity landscape, and the streaming extension (parameterized by items with frequency > 1) suggests the framework generalizes. Open questions include whether the promise on C can be estimated without incurring the full communication cost (Theorem 1.5 shows this is hard in general), and whether analogous parameterizations yield tight bounds for other distributed or streaming statistical problems beyond F₀.

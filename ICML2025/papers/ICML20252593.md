## Problem

Token sparsity and neuron sparsity in VLMs have evolved in parallel, with the prevailing assumption that they operate independently. However, token sparsity alone only accelerates the pre-filling stage while neuron sparsity alone only accelerates decoding, leaving no single method to achieve comprehensive inference acceleration. Moreover, existing token selection methods rely on attention scores without theoretical justification for their optimality, and the intrinsic relationship between the two sparse spaces remained entirely unexplored.

## Input / Output

The method takes a standard image (encoded into image tokens, e.g., 576 tokens for LLaVA-1.5) concatenated with a text prompt, and produces a free-form text response. A key distinction is that the number of retained tokens is not pre-specified but determined adaptively per input via a knee threshold on the neuron-intersection distribution, typically retaining 10–17% of tokens. The framework is training-free and plug-and-play, requiring no fine-tuning or model-specific predictors, and generalizes across architectures including LLaVA-1.5, Qwen2.5-VL, and Video-LLaVA.

## Method

CoreMatching introduces a co-adaptive mechanism that jointly identifies Core Neurons (the most frequently and strongly activated neurons in each FFN layer across all input tokens) and Core Tokens (tokens whose activated neurons have the largest intersection with the core neurons) in a single pre-filling pass. During decoding, only core neurons are used for FFN computation while the KV cache contains only core tokens, yielding simultaneous token and neuron sparsity. The theoretical contribution is a projection-guided criterion showing that token importance equals the projection of the attention-weighted value vector onto the output vector; under empirically verified orthogonality assumptions on W_q, W_k, W_v, and W_d, this reduces to the cosine angle between token representations, which is proportional to the number of co-activated neurons—thereby formally linking neuron sparsity to token selection. This explains why core tokens outperform attention-score-based selection, as the projection criterion captures both magnitude and angular information that attention scores alone miss.

## Results

On LLaVA-1.5-7B, CoreMatching retains only 64 image tokens (vs. 576 full) and achieves 78.5 on VQAv2 (matching the full model), 69.5 on SciQA (exceeding the full model's 66.8), and 64.6 on MMBench (exceeding 64.3), while using roughly 10% of the tokens. On LLaVA-1.5-13B, it retains 98 tokens and reaches 72.8 on SciQA (matching the full model) and 87.0 on POPE (exceeding 85.9). On hardware (NVIDIA Titan Xp), CoreMatching achieves a 2.1× pre-filling speedup and a 9.2× decoding speedup, reducing FLOPs from 10.1 to 2.1 TFLOPs (≈5× reduction) and KV cache memory from 304.8 MB to 49.0 MB.

## Baselines & Comparisons

CoreMatching is compared against five token-sparsity baselines (PruMerge+, FastV, VoCo-LLaMA, LLaVA-TRIM, Dynamic-LLaVA) and one neuron-sparsity baseline (PowerInfer). On LLaVA-1.5-7B, CoreMatching uses only 64 tokens—roughly half the tokens of the next-best method (Dynamic-LLaVA at 115)—while matching or exceeding all baselines on VQAv2 (78.5 vs. 78.0 for Dynamic-LLaVA), SciQA (69.5 vs. 69.1), MMBench (64.6 vs. 64.1), and SEED (66.1 vs. 64.6). The main trade-off is TextVQA, where CoreMatching scores 54.5 versus 57.0 for Dynamic-LLaVA and 57.1 for PruMerge+, a gap of ~2.5–3 points. On LLaVA-1.5-13B, CoreMatching (98 tokens) outperforms Dynamic-LLaVA (115 tokens) on POPE (87.0 vs. 86.5) and MMBench (68.5 vs. 66.9) while remaining competitive on most other benchmarks. In the hardware comparison (Table 3), CoreMatching dominates PowerInfer (neuron-only sparsity) by combining both sparsity dimensions: it achieves 2.1 TFLOPs vs. PowerInfer's 2.2, reduces KV cache from 304.8 MB to 49.0 MB, and cuts decoding latency from 11.6 s to 4.81 s, yielding a 9.2× overall decoding speedup versus PowerInfer's 1.7×.

## Relation to Prior Work

This paper builds directly on CoreInfer (Wang et al., 2024), which introduced the concept of core neurons for LLM inference acceleration, and extends it to VLMs. It departs from the prevailing assumption that token sparsity (PruMerge, FastV, Dynamic-LLaVA) and neuron sparsity (PowerInfer, DejaVu) operate independently, instead discovering an intrinsic matching mechanism between core neurons and core tokens. The theoretical contribution—a projection-guided criterion incorporating angular information—departs from the standard attention-score-based token importance metrics used by all prior token-pruning methods.

## Why It Matters / Open Questions

This is the first work to formally establish the coupling between token and neuron sparsity in VLMs, providing a principled explanation for why core tokens outperform attention-score-based selection. The practical impact is significant: a training-free, plug-and-play method achieving 10× speedup on consumer hardware (Titan Xp) with near-lossless accuracy across 10+ benchmarks and multiple model architectures. Open questions include whether the orthogonality assumption (W_q W_k^T ≈ θI) holds universally across architectures, how the method behaves for models without standard FFN blocks (e.g., LLaMA 3.2 with cross-attention, where only neuron sparsity is applicable), and whether the knee-point threshold generalizes to extremely long sequences or streaming settings.

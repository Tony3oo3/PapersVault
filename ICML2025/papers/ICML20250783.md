## Problem

Estimating the 1-Wasserstein distance between evolving spatial distributions requires repeatedly solving the Euclidean bi-chromatic matching problem as points are inserted or deleted. Prior dynamic algorithms for this geometric problem could not break the O(n) update-time barrier, making them impractical for monitoring distributional drift in real-time settings. This paper presents the first fully dynamic algorithm achieving sublinear O(n^ε) update time with an O(1/ε)-approximation guarantee.

## Input / Output

The algorithm takes two sets A (red) and B (blue) of n points in R^2 with bounded spread U = poly(n), and processes pair insertions and deletions. All points are randomly shifted by a fixed vector r ∈ [U]^2 before processing. The output is an O(1/ε)-approximate bi-chromatic matching maintained at all times, with O(1) cost queries, O(n) full matching reports, and O(n) recourse (reporting which edges changed after an update). The matching cost divided by n directly estimates the empirical 1-Wasserstein distance between the two point distributions.

## Method

The algorithm builds a restricted p-tree (a quadtree-like structure with branching factor p = n^ε) over the point set and computes matchings bottom-up: leaves (containing ≤ p² points) use the Hungarian algorithm for exact matching, while internal nodes solve an implicit Euclidean geometric transportation problem (via Atkinson–Vaidya) on aggregated sub-instances where points are mapped to their sub-cell centers. The key insight is that the bottom-up traversal ensures the unmatched (excess) points forwarded to each parent are exactly the color imbalance, so a single update only affects O(1/ε) nodes along a root-to-leaf path. For the advanced algorithm that maintains explicit matchings, each affected internal node updates its implicit matching by finding a shortest augmenting path (Bellman–Ford) on a graph of p² sub-cell center nodes in O(p³) time, ensuring only O(p²) edges change. The random shift provides the approximation guarantee: the expected cost of crossing edges at each grid level is proportional to the optimal matching cost, yielding the O(1/ε) bound over O(1/ε) tree levels.

## Results

The dynamic algorithm achieves O(n^ε · ε^{-1}) worst-case update time while maintaining an expected O(1/ε)-approximate bi-chromatic matching (Theorem 1.1). In experiments, the dynamic algorithm is orders of magnitude faster than periodic static recomputation (Figure 2), with typical update times of 1–10 ms even at sample sizes up to 1,000,000. The practical approximation ratio is < 2× the optimal matching cost, significantly tighter than the theoretical O(1/ε) bound. The exact solver of Xu and Ding (2024b) required >12 GB RAM and >3 hours for just 2,000 samples, whereas the dynamic algorithm scales to 1,000,000 samples with sub-second total update times.

## Baselines & Comparisons

The paper compares its dynamic algorithm against two baselines: (1) periodic static recomputation using state-of-the-art approximate matching algorithms, and (2) the exact dynamic optimal transport solver of Xu and Ding (2024b). Against static recomputation, the dynamic algorithm achieves orders-of-magnitude speedup in total running time over a series of updates (Figure 2), while producing approximation ratios (< 2× optimal) that nearly match those of the static algorithms (Figure 3). Against the exact solver of Xu and Ding (2024b), the dynamic algorithm is dramatically more scalable: the exact solver required >12 GB RAM and >3 hours for 2,000 samples (and was terminated due to memory exhaustion), while the dynamic algorithm handles 1,000,000 samples with update times in the single-digit millisecond range (Figure 4). The paper also demonstrates that the dynamic algorithm effectively monitors distributional drift in the Yellow-Cab Taxi dataset (14.3M trips) using a sliding window of 10,000 samples, showing clear drift in the empirical 1-Wasserstein distance between Pickup and Dropoff distributions over time (Figure 5).

## Relation to Prior Work

This paper adapts the static nested-grid (p-tree) framework of Agarwal and Varadarajan (2004) from a top-down to a bottom-up traversal, which is the key structural change enabling dynamic maintenance. The only prior dynamic algorithm for this problem (Xu and Ding, 2024a) achieves O(n) update time by operating on an explicit complete bipartite graph, whereas this work exploits the geometric structure through implicit matchings (aggregating points to cell centers) and the Atkinson-Vaidya geometric transportation solver to break the linear barrier. The bottom-up formulation also yields a simpler approximation analysis than the prior top-down approach, relying on the concept of implicit matchings and a random-shift argument for crossing edges.

## Why It Matters / Open Questions

This is the first sub-linear update time algorithm for dynamic Euclidean bi-chromatic matching, with a matching lower bound showing that no (2−δ)-approximation is achievable in sub-linear time, establishing the O(1/ε) guarantee as essentially tight. The practical experiments demonstrate orders-of-magnitude speedups over periodic static recomputation for monitoring Wasserstein distance drift on real taxi data, making streaming distributional comparison feasible at scale. Open questions include whether the expected-approximation guarantee can be upgraded to high probability without periodic rebuilding, whether the approximation gap between static (1+ε) and dynamic (O(1/ε)) can be narrowed, and whether the approach extends to higher dimensions or weighted variants.

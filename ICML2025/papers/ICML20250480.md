## Problem

Prior learning-augmented algorithms for the online knapsack problem either rely on complex frequency predictions (one prediction per unit value) or achieve Pareto-optimal consistency-robustness trade-offs only for significantly simplified variants (unit weights, discrete value sets). This paper asks whether near-Pareto-optimal trade-offs can be achieved for general OKP using succinct, practical predictions—specifically a single point or interval estimate of the critical value (the minimum unit value of any item in the offline optimal solution).

## Input / Output

The algorithms consume sequentially arriving items (unit value v_i, weight w_i) along with a succinct prediction of the critical value v̂: either a point prediction or an interval [ℓ, u] with ℓ ≤ v̂ ≤ u. A trust hyperparameter λ ∈ (0,1) and known value bounds [L, U] are also required for the untrusted-prediction setting. The output is an irrevocable admission decision x_i per item (fractional in [0, w_i] for OFKP, binary {0, w_i} for OIKP), with the guarantee expressed as a competitive ratio that depends on prediction quality (e.g., 1+min{1,ω̂} for exact point predictions, 2+ln(u/ℓ) for interval predictions).

## Method

The core algorithmic contribution is PP-a, a 'reserve-while-greedy' (prebuying) strategy that dynamically adjusts its reserved capacity for high-value items based on observed critical-value items, improving the competitive ratio from 2 (fixed reserve-then-greedy) to the instance-dependent lower bound 1+min{1,ω̂}. For interval predictions, IPA partitions capacity into three zones: 1/(α+1) for values above u, rejection below ℓ, and a robust sub-algorithm (ZCL) within [ℓ,u], achieving the optimal 2+ln(u/ℓ) ratio. For untrusted predictions, MIX convexly combines a trusted prediction algorithm with the worst-case-optimal ZCL baseline via trust parameter λ, yielding c/λ-consistency and (ln(U/L)+1)/(1-λ)-robustness—shown to be near-optimal via matching lower bounds. A novel Fr2Int conversion algorithm uses geometric value partitioning to adapt any OFKP algorithm to OIKP with minimal competitive loss under small item weights.

## Results

The paper establishes near-Pareto-optimal competitive ratio guarantees for learning-augmented online knapsack algorithms using succinct predictions. For trusted point predictions, PP-a achieves a competitive ratio of 1+min{1,ω̂}, matching the proven lower bound (Theorem 3.1, 3.3), improving upon the 2-competitive ratio of the simpler PP-b. For trusted interval predictions [ℓ,u], IPA achieves 2+ln(u/ℓ), also matching the lower bound (Theorem 3.4, 3.6). For untrusted predictions, MIX achieves (ln(U/L)+1)/(1−λ)-robustness and c/λ-consistency, which is shown to be near-optimal (Theorem 4.1, 4.2). Empirically, PP-a achieves the best average and worst-case competitive ratios among all prediction-based algorithms on 2,000 synthetic OFKP instances, and prediction-based algorithms remain robust to variations in U/L where ZCL's ratio degrades.

## Baselines & Comparisons

The paper compares against two baselines: ZCL (Zhou et al., 2008), the optimal prediction-free threshold algorithm with competitive ratio ln(U/L)+1, and SENTINEL (Im et al., 2021), a learning-augmented algorithm using complex frequency predictions. Against ZCL, all prediction-based algorithms (PP-b, PP-a, IPA) achieve competitive ratios independent of U/L, whereas ZCL's ratio grows logarithmically with U/L; even with a relatively wide interval prediction (40% of [L,U]), IPA outperforms ZCL in both average and worst-case competitive ratios. Against SENTINEL, the succinct prediction-based approaches (PP-a, IPA) exhibit superior empirical performance and degrade more gracefully under prediction errors, while requiring only a single point or interval prediction rather than one prediction per possible unit value. The naive algorithm PP-n, which simply accepts all items at or above the predicted critical value, outperforms most baselines on average but has a worst-case competitive ratio of U/L (Theorem A.4), confirming that the more sophisticated PP-a and IPA designs are necessary for robust guarantees.

## Relation to Prior Work

This paper extends the learning-augmented algorithm design framework to the general online knapsack problem, building on the ZCL threshold-based algorithm (Zhou et al., 2008) as a robust subroutine and departing from prior frequency-prediction approaches (Im et al., 2021) by using far simpler point or interval predictions of the critical value. It generalizes Pareto-optimal results previously obtained only for simplified OKP variants (online search, single-leg revenue management) to the full problem with arbitrary item weights, and introduces a novel 'prebuying' strategy (PP-a) that dynamically adjusts capacity reservations rather than using fixed reserve-then-greedy allocations. The Fr2Int conversion algorithm is a new technique that bridges fractional and integral settings without relying on the threshold-based paradigm used in prior discretization approaches.

## Why It Matters / Open Questions

This is the first work to achieve near Pareto-optimal consistency-robustness trade-offs for general OKP using practical, succinct predictions, closing a gap that left the problem without optimal trade-off guarantees. The Fr2Int conversion provides a reusable tool for adapting any fractional online algorithm to the integral setting, which may benefit other online packing problems. Open questions include extending untrusted-prediction results beyond the small-weight assumption, developing fine-grained trade-off bounds for interval predictions based on prediction error, and exploring whether the prebuying strategy generalizes to other online resource allocation problems.

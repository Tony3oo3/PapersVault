## Problem

No single training algorithm dominates across all distribution shift types and magnitudes, yet choosing the right algorithm for a given dataset without extensive trial-and-error remains an open problem. Existing model-selection heuristics require training one or more models first or rely on unverifiable assumptions, making them impractical when OOD validation data is unavailable. This paper asks whether the selection of a suitable OOD training algorithm can be learned a priori from dataset characteristics alone.
![Teaser figure](../imgs/ICML20251086/cropped_page0_idx0.webp)

## Input / Output

The selector takes a fixed-length dataset descriptor vector comprising training set size n, input dimensionality d, three shift magnitudes (d_sc, d_ls, d_cs in [0,1]), and a spurious-feature availability ratio r, and outputs a binary multi-label vector over M candidate algorithms indicating suitability. The descriptor is hand-designed and interpretable rather than learned end-to-end, and for real-world data the availability r is estimated via a proxy based on embedding-space cluster compactness relative to class vs. attribute centers. At test time, when multiple algorithms are flagged as suitable, the one with the highest prediction logit is selected to train the target model.

## Method

OOD-Chameleon formulates algorithm selection as a multi-label classification over a set of candidate algorithms (ERM, GroupDRO, oversampling, undersampling, logits adjustment), trained on a meta-dataset of datasets with controlled, diverse distribution shifts. The meta-dataset is constructed by solving linear constraints on group sample counts to achieve desired (d_sc, d_ls, d_cs) triples, then training each candidate algorithm to obtain ground-truth worst-group performance, which is binarized into suitability labels via a threshold ε. A 2–4 layer MLP is trained with binary cross-entropy to map dataset descriptors to the multi-label suitability vector. The key insight is that this a priori mapping is learnable: the selector captures non-trivial non-linear interactions between dataset properties and algorithm performance (confirmed by its superiority over linear and k-NN baselines), and the learned decision rules generalize to unseen datasets, shift types, and domains without any target-model training.

## Results

On synthetic tasks, OOD-Chameleon achieves 86.3% 0-1 accuracy and 19.9% worst-group (WG) error, approaching the oracle upper bound of 100%/19.0% and substantially outperforming the best non-parametrized baseline (Global best: 72.5%/22.7%). On vision tasks, the selector trained on CelebA generalizes to MetaShift, achieving 80.6% 0-1 accuracy and 39.0% WG error (ResNet18) and 76.7%/27.2% (CLIP), versus 33.3%/43.1% and 34.1%/32.3% for random selection. On NLP tasks, OOD-Chameleon reaches 90.9% 0-1 accuracy and 20.7% WG error on CivilComments with fine-tuned BERT, and 79.4%/58.3% on MultiNLI with frozen BERT, consistently outperforming all static-algorithm baselines.

## Baselines & Comparisons

OOD-Chameleon outperforms all five static-algorithm baselines (ERM, GroupDRO, Logits adjustment, Undersample, Oversample) on every dataset and backbone. On CelebA with ResNet18, OOD-Chameleon achieves 47.7% WG error versus 57.8% for ERM (Vapnik, 2000), 52.5% for GroupDRO (Sagawa et al., 2019), 53.1% for Logits adjustment (Menon et al., 2021), 49.8% for Undersample, and 52.4% for Oversample (Japkowicz & Stephen, 2002) — a 2.1–10.1 point improvement over the best static choice. Against the Naive descriptors baseline (Öztürk et al., 2022), OOD-Chameleon gains 10.5 points in 0-1 accuracy on CelebA (75.0% vs. 64.5%) and 11.8 points on MetaShift (80.6% vs. 68.8%), confirming that the hand-designed shift-magnitude descriptors carry substantially more signal than trivial properties like number of classes. The regression formulation (Eq. 2) consistently underperforms the multi-label classification formulation (Eq. 3) by 5–25 points in 0-1 accuracy, validating the classification framing. Notably, OOD-Chameleon's distribution of selected algorithms closely mirrors the oracle's, indicating it learns when each algorithm family (reweighting, margin-based, regularization) is most appropriate.

## Relation to Prior Work

This paper carves new ground by formalizing algorithm selection for OOD generalization as a supervised multi-label classification problem over dataset descriptors, which is explicitly a priori (no target-model training required). It departs from prior OOD model-selection heuristics (accuracy-on-the-line, activation coverage) that require training models first or access to test data, and from concurrent work by Bell et al. (2024) that handles only spurious correlations via non-parametric nearest-neighbor retrieval. Conceptually, it draws on meta-learning (learning from a distribution of tasks) and AutoML (automating ML workflows), but applies these ideas to the specific and previously unstudied problem of choosing among OOD training algorithms based solely on measurable dataset properties.

## Why It Matters / Open Questions

The paper provides a practical, interpretable tool for practitioners facing the 'which algorithm for which shift' problem, and the decision-tree analysis yields actionable guidance (e.g., undersample for large datasets with severe shifts, logits adjustment for small datasets with large shifts). Key limitations include restriction to binary classification with binary attributes, only five candidate algorithms, and reliance on semi-synthetic data with known attribute annotations. Open questions include whether the approach generalizes to real-world WILDS-style tasks, whether learnable descriptors (e.g., Dataset2Vec) can replace hand-crafted ones, and whether the framework extends to multi-class, multi-attribute settings and richer algorithm families.

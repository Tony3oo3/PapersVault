## Problem

Universal approximation theorems for deep (depth-n) networks have historically been proven via handcrafted constructions (Telgarsky sawtooth, bit extraction) or infinite-depth limits, while shallow (depth-2) networks admit constructive proofs via closed-form ridgelet transforms. This leaves the parameter-to-function mapping in deep networks as a black box, with no systematic way to compute the weights that represent a given target function. The paper asks: can a single constructive framework yield the ridgelet transform (i.e., the explicit parameter distribution) for arbitrary-depth networks?

## Input / Output

The method takes a target function f ∈ L²(X;Y), a joint-group-equivariant feature map φ: X×Ξ→Y encoding the network architecture (e.g., a depth-n fully-connected layer stack), and a locally compact group G with specified actions on the data domain X, parameter domain Ξ, and output domain Y. It produces a closed-form parameter distribution γ = R[f;ψ](ξ) = ∫_X ⟨f(x), ψ(x,ξ)⟩_Y dx, which is a scalar-valued function on the parameter space Ξ. Unlike standard weight vectors, this output is an integral over the full parameter domain, and the reconstruction M[γ;φ] = ((φ,ψ))·f holds up to a bilinear constant that depends only on the architecture, not on f.

## Method

The core mechanism is a reconstruction formula (Theorem 3.10) proven via Schur's lemma: if the unitary representation π of G on L²(X;Y) is irreducible, then the composite operator M_φ ∘ R_ψ — which commutes with π because both M_φ and R_ψ are intertwiners — must be a scalar multiple of the identity. The key conceptual extension is the joint-group-equivariant feature map, where the G-action on the parameter domain Ξ is non-trivial (g·ξ ≠ ξ), which is necessary because fully-connected layers are not classically equivariant but are joint-equivariant. Depth-n networks are handled by composing joint-equivariant maps (Lemma 3.5), so the composition φ_{1:n} = φ_n ∘ … ∘ φ_1 inherits joint-equivariance automatically. The framework is instantiated for four architectures: depth-n joint-equivariant machines, depth-n fully-connected networks (with G = O(m)×Aff(m)), depth-n group-convolutional networks (reusing the affine group irreducibility), and a new depth-2 quadratic-form network σ(xᵀAx + xᵀb + c) whose universality was previously unknown.

## Results

The main result (Theorem 3.10) establishes a constructive universal approximation theorem: for any joint-group-equivariant feature map φ with irreducible unitary representation π on L²(X;Y), the composition M_φ ∘ R_ψ = ((φ,ψ))·Id holds, yielding a closed-form ridgelet transform R_ψ[f] as the parameter distribution. This is applied to four architectures: depth-n joint-equivariant machines, depth-n fully-connected networks (with group G = O(m) × Aff(m)), depth-n group-convolutional networks, and a novel depth-2 quadratic-form network QNN[γ](x) = ∫ γ(A,b,c) σ(xᵀAx + xᵀb + c) dA db dc whose universality was previously unknown. The reconstruction formula provides an explicit right-inverse operator, meaning the parameter distribution γ_f = R_ψ[f] is given in closed form for any target function f ∈ L²(X;Y).

## Baselines & Comparisons

This is a purely theoretical paper with no experimental benchmarks, so comparisons are made at the level of proof techniques and scope of coverage. Compared to classical depth-2 universality proofs (Cybenko 1989, Hornik 1989), which are existential (Hahn-Banach, Stone-Weierstrass), the ridgelet transform approach is constructive, giving an explicit closed-form parameter distribution. Compared to previous depth-n universality results (Telgarsky sawtooth, Yarotsky scheme, Neural ODEs), which handcraft particular solutions or rely on infinite-depth limits, this paper derives a general solution operator valid for any finite depth n via Schur's lemma. Compared to the Fourier slice method (Sonoda et al. 2024b), which is limited to depth-2 networks, the group-representation approach extends naturally to arbitrary depth through the composition lemma (Lemma 3.5). The paper also subsumes the depth-2 group-convolutional network result of Sonoda et al. (2022a) as a special case (n=2 in Theorem 6.1), while extending it to depth-n. A key advantage over Stone-Weierstrass or Hahn-Banach arguments is that the framework handles non-vector inputs/outputs and hierarchical compositions systematically, and the irreducibility condition provides a verifiable algebraic criterion for universality.

## Relation to Prior Work

This paper extends the ridgelet transform framework (Murata 1996; Candès 1998) from depth-2 fully-connected networks to depth-n joint-group-equivariant machines, building directly on the group-theoretic approach of Sonoda et al. (2024a) and the depth-2 GCN analysis of Sonoda et al. (2022a). The key conceptual departure is introducing 'joint-group-equivariance' as a strict generalization of classical group-equivariance, which allows fully-connected networks (which are not equivariant under any natural group action) to be captured within the same algebraic framework. The main unification is that the same Schur's-lemma argument that proves constructive universality for shallow networks now also covers depth-n compositions, replacing the previously disjoint proof techniques (Fourier/Radon for shallow; handcrafted sawtooth/bit-extraction for deep).

## Why It Matters / Open Questions

The framework provides a systematic, mechanical procedure to verify universality for novel architectures: one only needs to identify a group action, confirm joint-equivariance of the feature map, and verify irreducibility of the induced representation. This is particularly valuable in the era of diverse architectures where case-by-case analysis is infeasible. The quadratic-form network (Section 7) demonstrates the framework's generative power by yielding a new universal architecture whose universality was previously unknown. Open questions include whether the ridgelet transform explains the parameters found by risk minimization for depth-n networks (established only for depth-2 by Sonoda et al. 2021a), and how the L²-based theory connects to generalization bounds, which the paper acknowledges are currently limited by coarse Lipschitz estimates that scale poorly with depth.

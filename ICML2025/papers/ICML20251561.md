## Problem

Prior repeated principal-agent work assumes either a fixed agent type or stochastic arrivals from a known distribution, but real-world platforms face adversarial or arbitrary agent sequences. This paper shows that without prior knowledge of agent behavior, no algorithm can achieve sublinear regret (linear regret lower bound), and then characterizes the two structured settings—known greedy best-response functions and Lipschitz-smooth choice models—where sublinear regret is achievable.

## Input / Output

In the greedy setting, the principal knows the reward vector v ∈ [0,1]^N, the best-response function b(π,j) for every incentive π and agent type j, but not which type j_t arrives each round; only the chosen arm is observed. In the smooth setting, the principal knows only the Lipschitz constant L ≥ 1 and the problem dimensions (N, K, T), with no access to agent preferences. The output is a per-round incentive vector π_t (single-arm: at most one nonzero coordinate; general: any vector in [0,1]^N) and a theoretical regret bound against the best fixed incentive in hindsight.

## Method

For the greedy model, the key insight is a reduction to adversarial linear bandits: each discretized incentive π maps to a vector z^π ∈ R^K whose j-th coordinate is U(π,j), and the per-round reward becomes ⟨z^π, y_t⟩ where y_t is a one-hot vector indicating the arriving agent type. Single-arm incentives are discretized into O(NK) threshold vectors (further reduced to 2^K via a response-signature mapping), while general incentives are discretized at the extreme points of convex polytopes defined by the linear inequalities μ_{σ_j}^j + π_{σ_j} ≥ μ_i^j + π_i for each agent's best-response region. EXP3 for linear bandits then yields the regret bound. For the smooth model, a uniform ε-grid discretization combined with Tsallis-INF exploits the Lipschitz property to bound approximation error by O(Lε), balancing exploration (√(N/ε)·T) against approximation (LTε) to achieve Õ(L^{1/3}N^{1/3}T^{2/3}). An instance-dependent variant uses AdversarialZooming to adaptively refine discretization near the optimum, improving the exponent when the zooming dimension z < 1.

## Results

The paper establishes regret bounds for a repeated principal-agent problem with adversarial agent arrivals across two agent response models (greedy and smooth) and two incentive structures (single-arm and general). For the known greedy choice model with single-arm incentives, the algorithm achieves Õ(min{√(KT log N), K√T}) regret, matching the lower bound up to a log K factor. For the unknown smooth choice model with single-arm incentives, the algorithm achieves Õ(L^{1/3} N^{1/3} T^{2/3}) regret, which is tight up to logarithmic factors. A key negative result shows that without prior knowledge of agent behavior under the greedy model, any algorithm incurs Ω(T) linear regret.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines; the 'comparisons' are between upper and lower bounds across different problem settings. For the known greedy + single-arm setting, the proposed reduction to adversarial linear bandits (using EXP3) achieves an upper bound that matches the constructed lower bound up to a log K factor, establishing near-optimality. For the unknown smooth + single-arm setting, the fixed-discretization + Tsallis-INF algorithm achieves Õ(L^{1/3} N^{1/3} T^{2/3}), which is tight up to logarithmic factors against the Ω(L^{1/3} N^{1/3} T^{2/3}) lower bound. The general incentive setting improves the known greedy bound from Õ(min{√(KT log N), K√T}) to O(K√(T log(KT))) via a novel polytope-based discretization, and the smooth general incentive bound Õ(L^{N/(N+2)} T^{(N+1)/(N+2)}) degrades gracefully with dimension N. The instance-dependent zooming algorithm (AdversarialZooming) further improves the smooth single-arm bound to Õ(T^{(z+1)/(z+2)} ((2L+1)N)^{z/(z+2)}) when the adversarial zooming dimension z < 1, e.g., z = 1/2 for strictly concave reward functions yielding T^{3/5} regret.

## Relation to Prior Work

This paper extends the repeated principal-agent literature (Ho et al. 2014; Scheid et al. 2024b; Dogan et al. 2023a,b), which has assumed either a fixed unknown agent type or stochastic arrivals from a known distribution, by introducing adversarial agent arrivals—a setting the authors explicitly identify as unexplored. Methodologically, the core algorithms reduce the incentive-design problem to adversarial linear bandits (solved via EXP3 from Lattimore & Szepesvári 2020) or adversarial multi-armed bandits (solved via Tsallis-INF from Zimmert & Seldin 2021), with the smooth-response setting further leveraging AdversarialZooming (Podimata & Slivkins 2021) for instance-dependent guarantees. The key technical departure is a novel polytope-based discretization for general (multi-arm) incentives that exploits the convex geometry of best-response regions, which has no direct analogue in prior bandit or principal-agent work.

## Why It Matters / Open Questions

The paper establishes a fundamental impossibility result: without prior knowledge of agent best-response functions, no algorithm can achieve sublinear regret, which sharply delineates the boundary of what is learnable in incentive design under adversarial arrivals. The matching upper and lower bounds (up to logarithmic factors) for both the greedy and smooth settings provide a near-complete characterization of the problem's complexity. Open questions include extending to noisy reward observations, incorporating purchase quantities, and understanding whether the intractability result can be circumvented with richer feedback or structural assumptions on agent preferences. For practitioners designing incentive mechanisms on platforms with unpredictable user sequences, the results clarify when prior knowledge of agent behavior is essential versus when smoothness assumptions suffice.

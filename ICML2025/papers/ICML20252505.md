## Problem

Existing action and interaction customization methods are limited to basic actions of a single entity or interactions between just two entities, and they require multiple 'exactly same' reference images to learn identifier tokens, which is impractical for unique and complex events. This paper introduces event-customized image generation, which captures all actions, poses, relations, and interactions among multiple entities from a single reference image and transfers them to a target image with novel entity combinations.
![Teaser figure](../imgs/ICML20252505/cropped_page0_idx0.webp)

## Input / Output

The method takes a single reference image (512×512), a target prompt consisting solely of entity nouns (no verb or event descriptions needed), and per-entity segmentation masks (extracted via Grounded-SAM) as input. It produces a 512×512 target image where the complex event structure (poses, spatial relations, interactions) from the reference is preserved while each entity is replaced by its corresponding target entity. Notably, the target prompt deliberately omits event descriptions since the event is transferred directly from the reference image's spatial features and attention maps.

## Method

FreeEvent is a training-free framework built on Stable Diffusion v2-1 that decomposes event customization into two parallel paths alongside the standard diffusion denoising process. The entity switching path applies cross-attention guidance (an energy function that biases each token's cross-attention map toward its entity mask region, optimized via backpropagation on the latent for the first 10 steps) and cross-attention regulation (element-wise masking of each token's cross-attention map to its entity region for all 50 steps) to localize target entities and prevent appearance leakage. The event transferring path extracts spatial features and self-attention maps from the reference image's latent at each timestep and directly injects them into the corresponding decoder blocks and layers of the target denoising process, transferring the structural and relational information that encodes the event. The two paths operate simultaneously within the U-Net's encoder-decoder architecture, requiring no parameter updates to the pretrained model.

## Results

On SWiG-Event (5,000 samples), FreeEvent achieves R@1=41.12 for image retrieval, T-1=34.10 for verb detection, CLIP-I=0.7044 for image similarity, and FID=29.05, substantially outperforming all baselines. In the user study on Real-Event (50 trials, 10 experts), FreeEvent receives 50 human-judgment votes versus 26 for PnP, 25 for ControlNet, 23 for MAG-Edit, 8 for DreamBooth, and 3 for ReVersion. FreeEvent also achieves the best CLIP-T score (0.2238) and DreamSim score (0.6282), confirming strong alignment with both reference events and target text prompts.

## Baselines & Comparisons

FreeEvent dominates all quantitative baselines on SWiG-Event: it achieves 41.12 R@1 versus 10.64 (ControlNet), 10.90 (MIGC), and 8.60 (BoxDiff), and 34.10 T-1 verb detection versus 10.66, 10.62, and 5.58 respectively — roughly 3–6× improvements. Its FID of 29.05 is more than 2× better than MIGC (49.81) and over 2× better than ControlNet (70.45) and BoxDiff (68.49). In the Real-Event user study, FreeEvent (50 HJ votes) outperforms PnP (26), ControlNet (25), MAG-Edit (23), DreamBooth (8), and ReVersion (3); PnP and MAG-Edit capture the reference event but suffer severe appearance leakage between target entities, while DreamBooth and ReVersion fail entirely because they require multiple reference images to learn event-specific tokens. For event-subject combined customization (Figure 9), FreeEvent outperforms AnyDoor, PhotoSwap, and MSDiffusion, though the authors note this is a secondary capability rather than the primary comparison target.

## Relation to Prior Work

FreeEvent sits at the intersection of two lines of work: (1) cross-attention-based layout control in diffusion models (Hertz et al., 2023; Chen et al., 2024b), which the entity switching path adapts by biasing per-token cross-attention maps toward reference entity masks, and (2) feature-injection editing (Tumanyan et al., 2023 / PnP), which the event transferring path repurposes by directly replacing spatial features and self-attention maps from a reference image. Conceptually, the paper departs from prior action/interaction customization (ReVersion, ADI, Jia et al.) that learns identifier tokens from multiple 'exactly same' reference images, instead treating the event as a holistic spatial-semantic structure transferable from a single image without any training. It also positions itself as a plug-and-play complement to subject customization (DreamBooth, Break-A-Scene) rather than a replacement.

## Why It Matters / Open Questions

By framing 'event' as the full set of actions, poses, and inter-entity relations in a scene, the paper opens a more practical customization axis than prior single-action or two-entity interaction work, and the training-free design removes the data-collection bottleneck that limited earlier methods. The two new benchmarks (SWiG-Event with 5,000 samples, Real-Event with 30 curated images) provide the first standardized evaluation for this task. Key open questions include scalability to many small entities, dependence on Stable Diffusion's generative ceiling (e.g., hands, faces), and whether the fixed hyperparameter trade-off between event fidelity and entity diversity can be made adaptive. The authors also note potential extension to video and multi-modal (subject + event + style) customization as future directions.

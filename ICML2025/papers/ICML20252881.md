## Problem

Standard contextual bandit algorithms assume rewards lie in a fixed range [0,R] and their regret scales polynomially with R, which is suboptimal when rewards have heavy tails or large ranges but small variances. Prior variance-based regret bounds either rely on linear function structure (making extension to general function approximation difficult) or still incur polynomial dependence on R. This paper addresses the open problem of designing a robust contextual bandit algorithm for general (non-linear) function approximation that achieves variance-based regret with only logarithmic dependence on the reward range.

## Input / Output

At each round, the algorithm receives a decision set of candidate actions and a function class F for reward estimation; in the known-variance case it also receives the per-round noise variance σ_t. The algorithm selects an action via optimistic maximization over a confidence set and observes a single scalar reward. The key structural detail is that the Catoni estimator is applied not to the raw reward but to the excess loss term Z_i(f,f') = σ̄_i^{-2}(f(x_i)-f'(x_i))(f'(x_i)-y_i), which is the only component depending on the heavy-tailed noise, and the confidence set is constructed via a min-max saddle-point optimization over the function class.

## Method

The core insight is that Catoni's mean estimator from robust statistics can be applied to the excess loss (rather than the reward itself) to obtain variance-dependent concentration in general function classes. For the known-variance case, Catoni-OFUL embeds the Catoni estimator into a variance-weighted OFUL framework: the per-sample weight σ̄_t combines the true variance with an eluder-coefficient-based uncertainty term, and the estimator f̂_t is defined as the solution to a min-max problem where the Catoni estimator replaces the standard sample mean of the noise-dependent cross term. For the unknown-variance case, VACB adapts a SupLinUCB-style peeling algorithm that partitions actions into L uncertainty levels, and replaces per-round variance estimation with a single Catoni-based aggregate variance estimator Var̂_t that approximates the true weighted variance sum up to logarithmic factors in R. This avoids the need for a separate function class to model per-round variances, and the resulting regret bound depends on the fourth moment of the reward while maintaining only logarithmic scaling in R.

## Results

For the known-variance case, Catoni-OFUL (Theorem 3.4) achieves a regret bound of $\tilde{O}(\sqrt{\sum_{t\in[T]}\sigma_t^2 \cdot d_{\mathcal{F}}\log N_{\mathcal{F}}} + d_{\mathcal{F}}\log N_{\mathcal{F}})$, which depends only logarithmically on the reward range $R$ (hidden in $\tilde{O}$). For the unknown-variance case, VACB (Theorem 4.2) achieves $\tilde{O}(d_{\mathcal{F}}\sqrt{\sum_{t\in[T]}\sigma_t^2 \cdot \log N_{\mathcal{F}}} + d_{\mathcal{F}}(\log N_{\mathcal{F}})^{3/4})$, again with only logarithmic $R$-dependence. A matching lower bound (Theorem 3.1) of $\Omega(\sqrt{\mathbb{E}\sum_{t=1}^{T}\sigma_t^2})$ confirms the leading-order variance dependence is optimal.

## Baselines & Comparisons

The central improvement over all prior non-linear methods is replacing the polynomial $R$-dependence with a logarithmic one. In the known-variance setting, Catoni-OFUL eliminates the $Rd_{\mathcal{F}}\log N_{\mathcal{F}}$ term present in OLS (Pacchiano, 2024), yielding a bound that is purely variance-driven up to log factors. In the unknown-variance setting, VACB removes the $Rd_{\mathcal{F}}\log N_{\mathcal{F}}$ (or $R\tilde{d}_{\mathcal{F}}\log N_{\mathcal{F}}$) term found in both Unknown-Variance OLS (Pacchiano, 2024) and DistUCB (Wang et al., 2024b), replacing it with a $d_{\mathcal{F}}(\log N_{\mathcal{F}})^{3/4}$ term that is independent of $R$. Compared to the linear-only methods (Heavy-OFUL, AdaOFUL, SAVE, Weighted OFUL+), this paper extends the variance-based guarantees to general non-linear function approximation. The trade-off for the unknown-variance case is a slightly worse dependence on the eluder dimension ($d_{\mathcal{F}}$ outside the square root vs. inside), and the bound depends on the fourth moment via the constant $c_\eta$ in Assumption 4.1. Against the linear AdaOFUL bound $\tilde{O}(d\sqrt{\sum\sigma_t^2} + d^{3.5}T^{1/4})$, VACB removes the $T^{1/4}$ term, making it optimal up to dimension when $\sum\sigma_t^2 = o(\sqrt{T})$.

## Relation to Prior Work

This paper extends the Catoni mean estimator from robust statistics (Audibert & Catoni, 2011; Lugosi & Mendelson, 2019) into the contextual bandit setting with general (non-linear) function approximation, combining it with the OFUL optimistic framework and the peeling technique from Zhao et al. (2023b). Prior heavy-tailed bandit work (Huang et al., 2024; Li & Sun, 2024) achieved variance-based bounds but relied critically on linear function structure, while distributional RL approaches (Wang et al., 2024b) handle general functions but retain polynomial dependence on the reward range R. The key conceptual departure is identifying the excess loss as the correct object to robustify via Catoni's estimator, rather than robustifying individual reward estimates, which enables the first logarithmic-in-R regret bound for non-linear contextual bandits.

## Why It Matters / Open Questions

This work closes a gap in the literature by providing the first variance-based regret guarantees with only logarithmic reward-range dependence for general function approximation in contextual bandits, with a matching lower bound confirming optimality of the leading-order term. The unknown-variance algorithm (VACB) avoids the need for a separate function class to model per-round variances, instead using a robust Catoni-based aggregate variance estimator, which is more practical. However, the unknown-variance case incurs a worse eluder dimension dependence, and the authors note the algorithms are computationally challenging due to min-max optimization and function-dependent Catoni parameters. Open directions include extending to adversarial corruption, general MDPs, and improving computational tractability.

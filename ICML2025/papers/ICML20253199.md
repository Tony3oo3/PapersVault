## Problem

Foundation model agents for web navigation rely on static sets of human-annotated instruction templates to define their skill repertoire, which is expensive to scale and fails to capture the full breadth of real-world tasks, causing distribution shift at test time. The paper asks whether agents can instead autonomously discover and practice useful skills through open-ended interaction with websites, and whether those self-discovered skills generalize zero-shot to unseen human requests and unseen websites.

## Input / Output

The agent observes only a screenshot of the current web page augmented with numbered marks on interactive elements (links, text boxes) plus a natural-language task instruction; it outputs a chain-of-thought reasoning step followed by a primitive web action (click or type on a numbered element), with episodes capped at 10 steps. The autonomous evaluator consumes the last three screenshots and the agent's final ANSWER text to produce a single binary 0/1 success verdict, deliberately avoiding access to hidden DOM state or step-level signals.

## Method

PAE is a three-component self-play loop: a context-aware task proposer (a VLM prompted with the website name or a few user-demo screenshots) generates diverse, feasible task instructions; an agent policy (LLaVa-1.6-7B/34B) attempts each task by outputting CoT reasoning plus a web action; and an image-based outcome evaluator (a VLM) assigns a sparse 0/1 reward from the final screenshots. The policy is optimized with REINFORCE, which under the terminal-reward structure reduces to Filtered Behavior Cloning on successful trajectories. The key design insight is exploiting the asymmetric capability of SOTA VLMs—they are reliable at proposing realistic tasks and judging final outcomes but weaker at executing multi-step navigation—so even a weaker model (e.g., Qwen2VL-7B) can serve as proposer/evaluator to improve a stronger agent. An explicit CoT reasoning step before each action is critical: ablations show it substantially improves zero-shot generalization to unseen tasks and websites compared to directly outputting actions.

## Results

On WebVoyager (13 real-world websites), LLaVa-7B PAE achieves 22.3% average success rate, a 7.4-point absolute improvement over LLaVa-7B SFT (14.9%), while LLaVa-34B PAE reaches 33.0%, a 10.4-point improvement over LLaVa-34B SFT (22.2%). On WebArena Easy (3 self-hosted websites), LLaVa-7B PAE achieves 24.6% average success rate, surpassing Qwen2VL-72B (23.9%) with 10× fewer parameters. On 85 unseen websites, PAE enables zero-shot transfer with 7.2% (7B) and 5.3% (34B) absolute improvements over SFT baselines.

## Baselines & Comparisons

Against proprietary VLMs, PAE still trails: LLaVa-34B PAE (33.0% on WebVoyager, 24.6% on WebArena Easy) remains below Claude 3 Sonnet (42.4%, 36.0%) and Claude 3.5 Sonnet (50.5%, 50.1%). Against the strongest open-source baseline Qwen2VL-72B, LLaVa-34B PAE wins on WebVoyager (33.0% vs. 22.6%) and LLaVa-7B PAE wins on WebArena Easy (24.6% vs. 23.9%), both with substantially fewer parameters. Against smaller open-source models (Qwen2VL-7B at 1.4%, InternVL2.5-8B at 0.2%, LLaVa-7B/34B zero-shot at 0–0.9%), PAE achieves large margins of 20+ points. Notably, LLaVa-7B PAE (22.3%) slightly exceeds LLaVa-34B SFT (22.2%) on WebVoyager, meaning a 7B model trained with PAE matches a 5× larger model fine-tuned on demonstrations. The paper also shows that even a weaker model (Qwen2VL-7B, 1.4% agent performance) can serve as task proposer/evaluator to improve LLaVa-7B SFT from 14.9% to 21.7%, confirming PAE exploits asymmetric proposer/evaluator capabilities rather than imitating a stronger agent.

## Relation to Prior Work

PAE extends the line of autonomous RL for web agents (DigiRL, Pan et al. 2024, Agent Q) by replacing the static set of human-curated task templates with a VLM-based context-aware task proposer, thereby removing the scalability bottleneck of manual annotation. It also draws on the self-generated instruction literature (Self-Instruct, AgentGen) but departs from it by operating in an interactive environment with online RL rather than single-turn generation. The paper explicitly positions itself against concurrent works (WebRL, NNetscape Navigator) that rely on stronger proprietary models for task proposals, instead exploiting the asymmetric capability of VLMs as proposers/evaluators versus agents. From the unsupervised skill discovery tradition in deep RL (DIAYN, DADS), PAE inherits the idea of discovering skills without explicit rewards but narrows the search space to natural-language-specified meaningful tasks via foundation models.

## Why It Matters / Open Questions

PAE demonstrates that open-source VLM agents can substantially improve their web navigation capabilities through fully autonomous self-play without any human-annotated task templates, achieving ~50% relative improvement in zero-shot generalization to unseen tasks and websites. The practical implication is significant: even a 7B model with near-zero agent performance (Qwen2VL-7B at 1.4%) can serve as a proposer/evaluator to improve a stronger agent, reducing dependence on expensive proprietary APIs. However, absolute success rates (22–33%) remain well below proprietary models (50%+), and the approach is validated only on web navigation; whether the framework transfers to other agent domains (robotics, multi-step software engineering) remains open. The dynamic nature of real websites also limits reproducibility of exact numbers.

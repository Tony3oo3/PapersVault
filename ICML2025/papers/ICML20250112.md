## Problem

Split conformal prediction provides distribution-free coverage guarantees, but it remains poorly understood when the returned prediction interval is actually minimal in volume compared to an oracle. The paper asks: can we characterize the calibration step as a volume minimization procedure, and how should the learning step be modified so that the base predictor is selected to minimize interval length rather than merely fitting the conditional mean?

## Input / Output

The method consumes a learning set and a non-overlapping calibration set of (X, Y) pairs along with a miscoverage level α, and produces a prediction interval for any test point x. For EffOrt the output is a constant-width interval [f̂(x)−t̂, f̂(x)+t̂]; for Ad-EffOrt the width adapts to x via a learned scale function, yielding [f̂(x)−ŝ(x)−t̂, f̂(x)+ŝ(x)+t̂]. The calibration quantile is computed at the slightly conservative level (1−α)(n_c+1)/n_c to preserve the marginal coverage guarantee.

## Method

The key insight is that the standard calibration step of split CP solves an empirical version of a minimum-volume-set problem, and that the learning step should minimize the (1−α)-quantile of the absolute residual (the (1−α)-QAE) rather than the MSE. EffOrt implements this by optimizing the empirical (1−α)-QAE via gradient descent on a smooth approximation of the empirical quantile (following Pena-Ordieres et al., 2020), replacing the non-differentiable indicator with a C¹ smoothing kernel Γ_ε. Ad-EffOrt extends the framework to adaptive-width intervals by adding a second learning step that fits the residual scale ŝ(x) via quantile regression (pinball loss at level 1−α), then calibrates on the centered residuals |Y−f̂(X)|−ŝ(X). The main theoretical result (Theorem 3.7) provides a finite-sample excess volume loss bound that decomposes into a calibration error term (rate Õ(n_c^{−γ})) and a learning error term governed by the complexity of the function class F, showing that more data should be allocated to the learning step.

## Results

The paper's main empirical results are presented as boxplots of 50 empirical expected interval lengths rather than a single numerical table. EffOrt produces prediction intervals with smaller average length than standard split CP (with linear or Huber regression) across asymmetric (Gaussian mixture) and heavy-tailed (Pareto, Pareto-Gaussian mixture) noise distributions, while matching performance under symmetric Gaussian noise. Ad-EffOrt produces intervals with smaller or comparable average length to LW-CP and CQR on heteroscedastic regression, with notably lower variance in interval sizes (tighter boxplots). All methods achieve the target marginal coverage of 1−α = 0.9.

## Baselines & Comparisons

Against standard Split CP (Papadopoulos et al., 2002) with a linear least-squares base predictor, EffOrt produces strictly smaller intervals under asymmetric and heavy-tailed noise (Gaussian mixture, Pareto, Pareto-Gaussian mixture) while matching it under Gaussian noise, where the least-squares regressor is already near-optimal for the (1−α)-QAE objective. Against robust Split CP with Huber loss, EffOrt also wins in the heavy-tailed settings, where the robust regressor discards extreme points that the calibration step then must compensate for with a larger quantile. Against Locally-Weighted Conformal Inference (Papadopoulos et al., 2008), Ad-EffOrt achieves smaller or comparable average interval lengths with substantially more consistent (lower-variance) sizes across all four noise distributions. Against CQR (Romano et al., 2019), Ad-EffOrt is competitive or better on average length in most settings; CQR is closest under the Pareto distribution, but the authors note that CQR does not assess the uncertainty of a particular prediction model f̂, whereas Ad-EffOrt explicitly calibrates around its own learned f̂.

## Relation to Prior Work

This paper unifies two previously separate threads: split conformal prediction (Papadopoulos et al., 2002) and Minimum Volume Set estimation (Scott & Nowak, 2005), by showing that the conformal calibration step is an empirical volume minimization problem and that the learning step should minimize the (1−α)-quantile of absolute error rather than MSE. The optimization technique for the non-differentiable empirical quantile is borrowed from smooth chance-constrained optimization (Pena-Ordieres et al., 2020). Unlike prior work on CP set size (Sharma et al., 2023; Dhillon et al., 2024) that bounds expected size in absolute terms, this paper introduces an excess volume loss bound relative to an oracle, and unlike Stutz et al. (2022) or Kiyani et al. (2024) which focus on optimization relaxations, it provides PAC-style finite-sample statistical guarantees.

## Why It Matters / Open Questions

The paper provides the first finite-sample excess volume loss bounds for split conformal prediction, explicitly decomposing the error into a calibration component (O~(n_c^{-γ})) and a learning component (O~(φ(F,δ,n_ℓ)^γ)), which reveals that the learning step dominates and motivates allocating more data to it. The practical implication that MSE-based base predictors are generally suboptimal for volume minimization challenges a default assumption in the CP literature. Open questions include controlling the approximation error from the smooth quantile surrogate, extending to multivariate outputs and unions of intervals, and bridging CP volume with broader uncertainty quantification frameworks.

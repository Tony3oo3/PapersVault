## Problem

Existing memory-efficient LLM training methods (e.g., GaLore, Adam-mini) reduce optimizer state memory by compressing gradients into low-rank subspaces, but they still require full-rank gradient computation and thus cannot reduce activation memory — a critical bottleneck for long-context or large-batch training. Additionally, their convergence guarantees are incomplete; for instance, GaLore's analysis only covers fixed projection matrices rather than the periodically updated ones used in practice.

## Input / Output

The method takes standard LLM weight matrices W_ℓ ∈ R^{m_ℓ×n_ℓ} across L layers and training text data (C4 for pre-training; GLUE, WinoGrande, COPA for fine-tuning). At each iteration, only a low-rank parameter block B_ℓ ∈ R^{r_ℓ×n_ℓ} (with r_ℓ ≪ m_ℓ) is optimized within a randomly sampled subspace defined by projection P_ℓ ∈ R^{m_ℓ×r_ℓ}, so the effective per-layer dimensionality drops from m_ℓ·n_ℓ to r_ℓ·n_ℓ. The output is the full updated weight matrix W^{k+1} = W^k + P^k B̃^k, maintaining the same parameter count as the original model.

## Method

RSO decomposes the high-dimensional LLM training problem into a sequence of lower-dimensional subproblems: at each outer iteration k, a random projection matrix P^k is sampled (e.g., from N(0, 1/r_ℓ)), and the subproblem min_B { f(W^k + P^k B) + (1/2η^k)‖B‖² } is solved approximately using a standard optimizer (Adam, GD, SGD, etc.) for a fixed number of inner steps. This design simultaneously reduces three memory components: optimizer states scale as r_ℓ·n_ℓ instead of m_ℓ·n_ℓ, gradients are computed only with respect to B (dimension r_ℓ×n_ℓ), and activations only require storing Y_ℓP_ℓ ∈ R^{s_ℓ×r_ℓ} instead of Y_ℓ ∈ R^{s_ℓ×m_ℓ} during backpropagation. The proximal term ensures strong convexity of each subproblem, enabling a convergence guarantee of O(ε^{-1}) outer iterations to reach an ε-stationary point, with total sample complexity O(ε^{-2}) when Adam solves the subproblems — matching vanilla Adam's rate. In distributed settings, the reduced gradient dimensionality also cuts communication overhead, yielding up to 3× faster iteration times for LLaMA-7B.

## Results

On LLaMA pre-training (C4), RSO achieves perplexity of 15.86 on LLaMA-1B and 18.86 on LLaMA-350M, matching Adam (15.56 / 18.80) while reducing optimizer-state memory by 70.7% and 64.2% respectively. On GLUE fine-tuning (RoBERTa-Base), RSO at rank 8 attains an average score of 86.77, surpassing Adam (86.28), GaLore (85.94), and LoRA (85.93). For LLaMA-7B pre-training, RSO requires only 54.81 GB peak memory and 64 hours of training time versus 78.92 GB / 216 h for Adam, a 3× speedup in iteration time (2.40 s vs 7.84 s per step at sequence length 64).

## Baselines & Comparisons

Against **Adam**, RSO achieves near-identical perplexity (15.86 vs 15.56 on LLaMA-1B; 15.99 vs 15.43 on LLaMA-7B) while cutting optimizer-state memory by 70.7% (1.46 GB vs 4.99 GB) and reducing peak GPU memory by 30% (54.81 GB vs 78.92 GB on 7B). On GLUE fine-tuning, RSO at rank 8 (86.77 avg) outperforms Adam (86.28) by 0.49 points. Against **GaLore**, RSO matches optimizer-state memory (both 24nr) but additionally saves activation memory (8bsn+4bsr vs 15bsn+2bsr per transformer block), yielding a >40% peak-memory reduction on LLaMA-7B at rank 64; on GLUE, RSO rank 8 beats GaLore rank 8 by 0.83 points (86.77 vs 85.94), and iteration time is 3× faster (2.40 s vs 7.86 s on LLaMA-7B, Seq 64). Against **LoRA**, RSO requires half the optimizer-state memory (24nr vs 48nr) and achieves better GLUE scores at both rank 4 (86.10 vs 85.61) and rank 8 (86.77 vs 85.93). Against **ReLoRA**, RSO matches or improves perplexity at every model scale while using the same optimizer-state budget.

## Relation to Prior Work

RSO draws on the random coordinate descent framework (Wright, 2015) but extends it from single coordinates to randomly sampled subspaces, applied specifically to LLM pre-training and fine-tuning. It departs from GaLore and similar optimizer-state compression methods (Adam-mini, Apollo) by actually optimizing within the subspace rather than merely projecting full-rank gradients onto it, which is what enables the additional activation memory savings. The approach is conceptually related to LoRA in that it operates on low-rank parameter updates, but unlike LoRA it does not permanently constrain the model to a fixed low-rank structure—instead it cycles through random subspaces, preserving full-rank expressivity over time. The convergence analysis builds on proximal gradient and random subspace optimization theory, providing guarantees that GaLore's fixed-projection analysis could not offer for its periodically-updated practical variant.

## Why It Matters / Open Questions

The simultaneous reduction of both optimizer-state and activation memory addresses a gap that no prior method filled: GaLore and LoRA reduce optimizer states but still require full-rank activations, making them ineffective for long-context or large-batch training. The 3× iteration-time speedup in distributed settings (e.g., LLaMA-7B) is practically significant for multi-GPU training where gradient synchronization dominates. Open questions include whether further activation savings are possible through alternative problem partitioning, and whether second-order subproblem solvers (suggested by the low-dimensional subproblems) could improve convergence quality. A limitation is that perplexity remains comparable rather than superior to Adam, so the gains are purely in efficiency rather than model quality.

## Problem

Existing online conformal prediction algorithms (ACI, DLR, Conformal PID) assume the ground-truth label is observed at every step, but in practical settings like document retrieval or active learning, the user can only confirm the true label if it appears in the prediction set (semi-bandit feedback). Under this feedback model, ACI's quantile updates become biased and DLR is highly sensitive to scoring-function structure, causing both to fail coverage or converge slowly. The paper formalizes this setting and provides the first sublinear regret guarantee for prediction-set convergence to the optimal threshold.

## Input / Output

At each step t, the algorithm receives an input x_t (an image, a question, or an auction round) and a fixed scoring function f: X×Y→R that assigns a real-valued confidence to each candidate label. It outputs a prediction set C_t = {y ∈ Y | f(x_t, y) > τ_t} parameterized by a single scalar threshold τ_t that is monotonically non-decreasing over time. The feedback is semi-bandit: the true label y_t* is revealed only if y_t* ∈ C_t; otherwise the algorithm receives only a binary indicator that y_t* ∉ C_t, making the score f(x_t, y_t*) unobservable on miscoverage steps.

## Method

The algorithm (SPS) maintains an empirical CDF G_t of observed scores, but truncates all scores below the current threshold τ_t by replacing them with τ_t, so that the unobserved scores in the semi-bandit regime do not corrupt the estimate. It then applies the Dvoretzky–Kiefer–Wolfowitz inequality to construct a high-probability upper confidence bound G̅_t(τ) = G_t(τ) + ε_t, and sets τ_t = sup{τ | G̅_{t-1}(τ) ≤ 1−α}, which guarantees τ_t ≤ τ* on the high-probability event that the DKW bound holds. A monotonicity constraint τ_{t+1} ≥ τ_t prevents the algorithm from regressing due to the inherently flawed CDF estimate in the truncated region [0, τ_t). Under a Lipschitz-continuity assumption on the loss with respect to the true CDF, this yields a cumulative regret bound of Õ(√T) and a PAC-style guarantee that τ_t ≤ τ* for all t simultaneously with probability at least 1 − 2/T, ensuring the prediction set always contains the optimal set.

## Results

On all three tasks (ImageNet classification, SQuAD document retrieval, and second-price auctions) with α=0.9 and T=10,000, SPS achieves the lowest cumulative regret among all methods, with regret curves that are sublinear (consistent with the theoretical bound Õ(√T)). SPS maintains the desired 90% coverage rate throughout the horizon and achieves zero undercoverage count (τ_t ≤ τ* for all t with probability ≥ 1−2/T). In contrast, ACI and Greedy both fail to maintain the 90% coverage target on all three tasks, and their regret curves appear superlinear due to the biased empirical CDF under semi-bandit feedback.

## Baselines & Comparisons

Against ACI (Gibbs & Candès, 2021), SPS wins decisively on all three metrics: SPS achieves lower cumulative regret, maintains the 90% coverage rate, and has zero undercoverage count, whereas ACI's biased quantile update (only updating Q̂_t when y*_t is observed) causes it to fail coverage and exhibit high undercoverage counts with oscillating prediction sets. Against DLR (Angelopoulos et al., 2024b), SPS also wins on regret, converging to the optimal threshold τ* significantly faster; both methods achieve the desired coverage and zero undercoverage, but DLR's lack of a quantile function makes it highly sensitive to the scoring function's scale and requires careful learning-rate tuning. Against the Greedy baseline (which uses the raw empirical CDF without confidence bounds), SPS dominates on all metrics: Greedy undercovers substantially and its regret grows superlinearly because the truncated empirical CDF becomes increasingly biased under semi-bandit feedback. Overall, SPS is the only method that simultaneously achieves sublinear regret, guaranteed coverage, and zero undercoverage without any hyperparameter tuning.

## Relation to Prior Work

This paper extends the online conformal prediction line of work (Gibbs & Candes 2021; Angelopoulos et al. 2024a,b; Bastani et al. 2022) by introducing a semi-bandit feedback assumption: the true label is only observed if it falls within the prediction set. Prior online conformal methods (ACI, SAOCP, Conformal PID) all require full label observation at every step to update their quantile functions or compute gradients, making them inapplicable to settings like document retrieval where a user can only confirm a match if the target appears in the returned set. The algorithm's core mechanism—using the DKW inequality to construct a high-probability upper confidence bound on the empirical CDF, and substituting τ_t for unobserved scores—builds directly on Massart's (1990) tight DKW constant and the standard bandit literature's bounded-loss assumptions.

## Why It Matters / Open Questions

The paper provides the first regret guarantee (Õ(√T)) for online conformal prediction in terms of convergence of the threshold τ_t to the optimal τ*, and a PAC-style guarantee (τ_t ≤ τ* with high probability over the entire horizon) that is stronger than the marginal coverage guarantees offered by prior online conformal methods. Practically, this enables efficient active learning: instead of asking a user to select the ground truth from the full label space, the algorithm only requires selection from a compact prediction set, which is a substantial efficiency gain when |Y| is large (e.g., 1000 ImageNet classes or thousands of documents). Limitations include the assumption that G*(τ*) = 1−α exactly (Assumption 2.3), the requirement that the loss be a Lipschitz function of the CDF (precluding raw prediction set size as a loss), and the i.i.d. data assumption that precludes adversarial or distribution-shift settings. Open questions include whether the approach extends to non-i.i.d. or adversarial sequences while retaining the semi-bandit feedback constraint, and whether the DKW-based confidence bound can be tightened for faster convergence in practice.

## Problem

Standard regret minimization algorithms directly optimize an agent's reward function, which does not naturally extend to environments with multiple decision makers having different utilities or to settings requiring performance guarantees conditional on the agents' own actions. This paper addresses the gap by shifting from direct reward optimization to a 'predict-then-act' paradigm: producing high-dimensional state forecasts that are unbiased conditional on arbitrary polynomially many events (including events defined by the predictions themselves), so that downstream agents can simply best-respond to the forecasts and inherit strong regret guarantees.

## Input / Output

The algorithm receives, each round, an arbitrary context x_t and a finite collection of event functions E_j: X × S → [0,1] that may depend on both the context and the learner's own predictions (self-referential conditioning). It outputs a randomized state prediction s̄_t ∈ ΔS over a convex compact state space S ⊆ ℝ^d, with the guarantee that the expected bias in every coordinate conditional on every event E_j is O(√(n_T(E_j) · log(d|E|T))) — a small-loss bound scaling with the event's own incidence count rather than the total horizon T. For combinatorial optimization applications, the state space is the d-dimensional reward vector [−1,1]^d and the algorithm requires only poly(d) calls to an offline optimization oracle (e.g., shortest-path), avoiding exponential dependence on the number of feasible actions.

## Method

The core algorithm (Algorithm 1) is a two-layer construction built on online linear optimization (OLO) subroutines. The outer layer instantiates the MsMwC (Multiscale Multiplicative Weights with Correction) algorithm over 2dn experts — indexed by sign σ ∈ {±1}, coordinate i ∈ [d], and event j ∈ [n] — to obtain small-loss regret bounds that scale with each event's squared-loss sum, yielding per-event bias guarantees. The inner layer addresses the non-convex, non-differentiable dependence of the surrogate objective on predictions through the event mappings by simulating a 'no-regret adversary vs. copycat learner' zero-sum game for t² rounds: the adversary (playing the state s_t) uses any O(√T)-regret OLO algorithm over S, while the learner simply copies the adversary's play; the empirical distribution of the learner's simulated states becomes the prediction distribution s̄_t. This works because the surrogate is linear in the adversary's state choice, so the copycat strategy achieves value zero if the adversary committed first, and the no-regret guarantee of the adversary's OLO algorithm ensures the simulated play approximates the saddle point. The resulting bias bound is O(log(d|E|T) + √(n_T(E)·log(d|E|T))) per event-coordinate pair, and the overall runtime is polynomial in d, |E|, and T.

## Results

The paper's central guarantee is an event-conditional bias bound of O(log(d|E|T) + √(n_T(E)·log(d|E|T))) for high-dimensional state predictions, where n_T(E) is the incidence of event E. As a direct application, the paper gives the first efficient O(T^{2/3}) online multicalibration algorithm in the ECE metric, improving on the prior best of O(T^{3/4}) (Gupta et al., 2022) and matching the O(√T) rate of Abernethy et al. (2011) for vanilla calibration. For online combinatorial optimization, the algorithm achieves Õ(d√T) conditional regret with only poly(d) oracle calls, an exponential improvement over prior methods whose runtime scales with the number of actions (exponential in d). For n agents with K actions, the framework simultaneously guarantees O(√(KT)) swap regret to all agents.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The key theoretical improvements over prior work are: (1) Online multicalibration improves from O(T^{3/4}) (Gupta et al., 2022) to O(T^{2/3}), matching the rate of Abernethy et al. (2011) for the simpler vanilla calibration problem. (2) For conditional regret in online combinatorial optimization, prior algorithms (Blum & Mansour, 2007; Lee et al., 2022; Haghtalab et al., 2023a) require runtime polynomial in |A| (the number of actions, which can be Ω(2^d)), while this paper achieves poly(d) oracle calls with Õ(d√T) regret. (3) The swap regret guarantee of O(√(KT)) for multiple agents simultaneously improves on Kleinberg et al. (2023), who only guaranteed no-external-regret for a single unknown agent. The framework also subsumes and extends the decision calibration of Zhao et al. (2021) from the batch to the online adversarial setting, and generalizes the omniprediction framework of Gopalan et al. (2022a) to high-dimensional state spaces.

## Relation to Prior Work

This paper builds on the foundational connection between calibration and no-regret learning (Foster & Vohra, 1999), the conditional/swap regret framework of Blum & Mansour (2007), the FTPL algorithm for combinatorial optimization (Kalai & Vempala, 2005), and the small-loss expert algorithm MsMwC (Chen et al., 2021). The key conceptual departure is from prior conditional regret algorithms whose runtime scales with the full action set |A| (exponential in d for combinatorial problems) to a prediction-based approach that only requires poly(d) oracle calls. It also extends decision calibration (Zhao et al., 2021) and omniprediction (Gopalan et al., 2022a) from the batch setting to the online adversarial setting, and generalizes 1D multicalibration to high-dimensional vector-valued predictions with event-conditional guarantees.

## Why It Matters / Open Questions

The framework provides a genuinely unified 'silver bullet' for a family of seemingly distinct decision-making tasks (multi-agent swap regret, conditional regret in combinatorial optimization, online multicalibration), and the exponential runtime improvement for combinatorial optimization (from |A| to poly(d) oracle calls) is practically significant for problems like online routing. The O(T^{2/3}) online multicalibration rate improves on the prior O(T^{3/4}) bound and matches the best known rate for vanilla calibration. Follow-up work (Collina et al., Roth & Shi, Hu & Wu) has already demonstrated the framework's broad utility in mechanism design, conformal prediction, and principal-agent settings. Open questions include whether the framework extends to infinite or adaptively growing event collections, non-convex state spaces, and whether the O(T^{2/3}) multicalibration rate is optimal.

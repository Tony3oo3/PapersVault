## Problem

Existing continual learning (CL) methods for LLMs suffer from Information Leakage (IL), requiring access to training data, task identifiers, or pseudo-samples from previously learned tasks, which poses privacy risks and prevents deployment in online scenarios. The paper identifies that the large performance gap (12–72%) between methods with and without IL stems from new forgetting introduced by trainable parameters (e.g., SAPT's query projections) in the block-selection process. The goal is to design an online CL method that avoids IL entirely while maintaining competitive CL performance.

## Input / Output

At inference, the method consumes a text instruction/query alongside stored presentative feature distributions (high-dimensional vectors computed as the expected hidden state of each task's data under the frozen pre-trained model) and stored LoRA blocks (low-rank weight matrices, one per task). It produces either generated text (dialogue, summarization, QA) or a classification label (sentiment, topic) depending on the task. Notably, no raw training data, task IDs, or pseudo-samples are accessed at any point; the only task-specific artifacts are the human-incomprehensible feature distributions and LoRA matrices.

## Method

The core mechanism characterizes each task's LoRA block by a presentative feature distribution D_k^l = E[W^l h^l(x^k)], the expected hidden state of task k's data at layer l under the frozen pre-trained weights, updated as a running average during training. At inference, the instance's hidden state at each layer is compared to all stored distributions via L2 distance or dot-product similarity, and the resulting softmax weights (with optional Top-K sparsification) determine which LoRA blocks to activate and how to combine them into the output. During training, only the current task's LoRA parameters and its feature distribution are updated; all previously learned blocks and distributions remain frozen, introducing zero new trainable parameters and thereby avoiding the new forgetting that causes SAPT's query projections to collapse to the last task without IL. The method also supports flexible expansion: LoRA blocks and feature distributions trained independently on different task sets can be merged without additional training, enabling plug-in continual learning across models of the same architecture.

## Results

On the LLaMA-2-7B model, Ours-L2 achieves an average performance of 69.31% across the SuperNI and Long Sequence benchmarks, surpassing the best method with information leakage (SAPT-LoRA, 68.99%) and outperforming the best method without IL (TaSL-LoRA, 58.50%) by 10.81%. On the Long Sequence Benchmark, Ours-L2 reaches 83.01% AP with only 0.57% forgetting rate, while on SuperNI it achieves 55.60% AP with 0.23% forgetting. Scaling to LLaMA-2-13B further improves the average to 70.61% (Ours-L2), confirming that stronger base models yield better CL performance.

## Baselines & Comparisons

Against the strongest baseline without IL, TaSL-LoRA (58.50% avg), Ours-L2 gains 10.81% on average, with particularly large margins on SuperNI (55.60 vs. 42.00 AP, +13.60). Compared to SAPT-LoRA without IL (18.68% avg), the improvement is dramatic (+50.63%), as SAPT's shared attention mechanism suffers severe forgetting when task identifiers are unavailable. Ours-L2 also slightly surpasses SAPT-LoRA *with* IL (68.99% avg) by 0.32%, demonstrating that avoiding information leakage need not sacrifice performance. Against O-LoRA (45.82% avg), the gap is 23.49%, and against LFPT5 (54.51% avg), it is 14.80%. ProgPrompt without IL (12.51% avg) and SeqLoRA (27.73% avg) are far outperformed, as both rely on task-order assumptions that break down in the online setting. On the Long Sequence Benchmark specifically, Ours-L2 (83.01% AP) exceeds EPI (72.27%) by 10.74% while maintaining a lower forgetting rate (0.57 vs. 5.04).

## Relation to Prior Work

This paper builds directly on the parameter isolation paradigm for CL of LLMs (SAPT, TaSL, O-LoRA), which allocates a separate LoRA block per task, but departs from them by eliminating the need for task identifiers, data replay, or new trainable selection parameters. The key conceptual move is repurposing the frozen pre-trained LLM's own hidden-state geometry as a 'free' routing mechanism: a statistically computed presentative feature distribution per task characterizes its LoRA block, and instance-to-distribution similarity drives dynamic block selection. This contrasts with SAPT's learned query projection (which introduces new forgetting) and TaSL's grouped skill localization (which requires task-related information at test time), positioning the method as the first truly online, IL-free parameter isolation approach for LLMs.

## Why It Matters / Open Questions

The paper quantifies a previously underappreciated problem: the performance gap between CL methods with and without information leakage reaches up to 72% (SAPT on Long Sequence), revealing that task-ID access and replay are doing substantial hidden work. The practical impact is significant for privacy-sensitive and streaming deployment scenarios where prior task data cannot be retained. The plug-in expansion capability—merging LoRA blocks and feature distributions from independently trained runs without additional training—opens a path toward community-driven, modular CL. Open questions include scalability beyond 15 tasks, applicability to other PEFT methods (adapters, prefix-tuning), and whether the frozen-model feature routing degrades as task distributions become more overlapping.

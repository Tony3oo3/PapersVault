## Problem

Soft prompt tuning on large LLMs requires backpropagation through the full model, forcing users to either share private data with the LLM provider or deploy the LLM locally—both impractical for centrally hosted models. Existing cross-model prompt transfer methods either require the provider to access private data during transfer (leaking it) or produce transferred prompts that underperform even the small source model, removing any incentive to use the large LLM. POST addresses this by enabling private local tuning on a small distilled model and transferring the prompt to the large LLM using only public data.

## Input / Output

The method consumes a private dataset for local soft prompt tuning (100-token prompts), a small public dataset (as few as ~100 samples suffice) for the transfer step, and a 2–4 layer model distilled from the target LLM. It produces a transferred soft prompt that, when prepended to the large LLM's input, adapts it to the private task without the provider ever seeing the private data. The distilled small model is a one-time artifact shared by the provider and reusable across users and tasks, while the public dataset need only share the same task family (e.g., sentiment classification) as the private data, not the same class structure.

## Method

POST operates in three stages: (1) the LLM provider distills their large model Φ_t into a small model Φ_s using a three-term KD objective (KL divergence on logits, language modeling loss, and embedding cosine loss), deliberately targeting aggressive compression (e.g., 32→2 layers) so Φ_s is small enough for local tuning yet semantically aligned with Φ_t; (2) the user tunes a 100-token soft prompt on Φ_s with their private data, optionally under differential privacy via PromptDPSGD (gradient clipping + calibrated Gaussian noise); (3) the provider transfers the prompt to Φ_t using a novel two-term loss over a small public dataset—L₁ minimizes KL divergence between the prompted target and prompted source outputs, while L₂ aligns the direction change each prompt induces relative to the un-prompted model—weighted by a hyperparameter α that balances task performance against prompt-behavior mimicry. The key insight is that KD preserves feature-space alignment between Φ_s and Φ_t, making the tuned prompt transferable, and the two-term loss compensates for the small model's weak absolute performance by focusing on the prompt's relative effect rather than its raw output quality.

## Results

On Llama2-7b, POST achieves 90.02% accuracy on SST-2 (vs. 78.67% zero-shot and 94.84% full prompt tuning upper bound) and 86.71% on ARISE-TV, substantially outperforming direct transfer (55.28% and 54.23% respectively). With differential privacy (ε=8), POST retains strong performance: 89.91% on SST-2 and 82.60% on ARISE-TV, still well above the compressed model's prompted accuracy (70.99% and 64.43%). On the open-ended MIT generation task, POST reaches 75.66% (director) and 61.41% (genre), exceeding both zero-shot (70.84%, 51.28%) and compressed PT (21.69%, 51.92%). Runtime analysis on GPT2-XL shows a 6× speedup over full prompt tuning on SST-2 (409 min vs. 2660 min on A100).

## Baselines & Comparisons

POST decisively outperforms both baselines across all seven evaluation datasets. Against DP-OPT (Hong et al., 2023), which tunes discrete prompts locally and transfers them directly, POST gains 8–56 points: e.g., 90.14% vs. 81.65% on SST-2, 86.71% vs. 78.26% on ARISE-TV, and 87.37% vs. 77.60% on MPQA (using GPT2 as source). In the DP setting, DP-POST (ε=8) still beats DP-OPT by 17–52 points (89.91% vs. 72.59% on SST-2; 82.60% vs. 30.44% on ARISE-TV). Against Zero-Shot Transfer (Wu et al., 2023), which encodes source prompts into a relative embedding space, POST gains 28–54 points: 90.14% vs. 62.38% on SST-2, 87.37% vs. 33.31% on MPQA, and 53.40% vs. 18.22% on TREC. Notably, ZST's transferred prompts often underperform the source model itself, whereas POST consistently exceeds the compressed model's prompted accuracy, providing a clear incentive for users to transfer back to the large LLM.

## Relation to Prior Work

POST builds on knowledge distillation (Sanh et al., 2019) and differentially private prompt tuning (Duan et al., 2023a), but repurposes KD not for performance preservation but for feature-space alignment between a small student and large teacher to enable prompt transfer. It departs from prior soft prompt transfer work (Su et al., 2022; Wu et al., 2023) by eliminating the need for private data during the transfer step, instead using a novel two-term loss that aligns both output distributions and prompt-induced direction changes on a small public dataset. Compared to DP-OPT (Hong et al., 2023), which transfers discrete prompts and leaks training words, POST operates on soft prompts with a small distilled surrogate, avoiding both data leakage and the need for a high-performing local model.

## Why It Matters / Open Questions

POST addresses a concrete and growing practical problem: soft prompt tuning in hosted LLM APIs (e.g., NVIDIA NeMo) forces users to share sensitive data with the provider. The framework's three-step pipeline (KD → local DP tuning → public-data transfer) is modular and could be adopted by LLM providers seeking to offer private prompt adaptation without compromising IP or user data. Key limitations include the absence of inference-time privacy guarantees, the computational cost of KD for providers, and sensitivity to public dataset selection. Open questions include whether the approach scales to much larger models (e.g., 70B+), whether pretraining data leakage during KD is truly negligible, and how to automate public dataset selection.

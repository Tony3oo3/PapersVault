## Problem

Existing cooperative MARL methods cannot simultaneously achieve strong performance, memory efficiency, and scalability to large agent populations. The previous state-of-the-art, the Multi-Agent Transformer (MAT), is highly performant but suffers from quadratic memory growth in the number of agents due to its attention mechanism and cannot condition on observation histories. The paper seeks a centralised sequence model that matches MAT's performance while scaling linearly in memory to over a thousand agents.

## Input / Output

Sable consumes a flattened sequence of per-agent observations spanning N agents over L timesteps, along with a persistent hidden state that carries temporal memory across timesteps and is reset at episode boundaries. During execution, the encoder processes all N agents' observations at each timestep in parallel, while the decoder autoregressively generates one action per agent within each timestep, producing a joint action vector and a scalar value estimate. The sequence is processed in chunks of configurable size C during training, with the constraint that all agents from the same timestep must reside in the same chunk.

## Method

Sable replaces MAT's self-attention with an RL-adapted RetNet retention mechanism in an encoder-decoder architecture. The encoder applies retention over all agents' observations at each timestep (with full self-retention within a timestep via a block-wise decay matrix) while maintaining a recurrent hidden state across timesteps; the decoder autoregressively decodes actions per agent using cross-retention with the encoded observations. Three key adaptations to the standard RetNet decay matrix are introduced: (1) agents within the same timestep share identical decay values, (2) information flow is blocked across episode boundaries via a reset gate, and (3) the encoder uses an agent-block-wise structure for full intra-timestep retention. Training uses clipped PPO over entire trajectories processed in the chunkwise form, reusing execution-time hidden states to maintain temporal continuity. Ablations confirm that the primary performance gain over MAT stems from conditioning on multi-timestep histories rather than from the retention mechanism itself, with RMSNorm and SwiGLU providing secondary improvements.

## Results

Sable achieves state-of-the-art performance on 34 out of 45 cooperative MARL tasks across six environments, significantly outperforming the previous SOTA (MAT) which ranked best on only 3/45 tasks. Per-environment inter-quartile mean episode returns show Sable leading on RWARE (0.81 vs MAT's 0.69), SMAX (0.94 vs 0.92), Connector (0.95 vs 0.88), LBF (1.0 vs 0.99), and MPE (0.95 vs 0.69). In terms of scalability, Sable processes up to 6.5× more steps per second than MAT at 512 agents and maintains stable performance at 1024 agents where MAT exceeds 80 GB GPU memory. Ablations confirm that Sable's gains stem primarily from temporal memory (conditioning on episode histories) rather than the retention mechanism itself.

## Baselines & Comparisons

Sable outperforms MAT (Wen et al., 2022), the previous SOTA sequence model for MARL, on all six environments, with the largest margins on RWARE (+0.12) and MPE (+0.26); MAT ranked best on only 3/45 tasks versus Sable's 34/45. Against MAPPO (Yu et al., 2022), Sable wins on RWARE, SMAX, Connector, and MPE, ties on LBF (both reach 1.0), and loses on MABrax where MAPPO scores 0.60 vs Sable's 0.56. IPPO (Witt et al., 2020) is substantially outperformed by Sable across all environments (e.g., 0.81 vs 0.15 on RWARE), though IPPO matches Sable's memory efficiency at scale. On continuous control (MABrax), off-policy methods MASAC (0.82) and HASAC (0.80) outperform Sable (0.56), which is expected since Sable uses the on-policy PPO objective. QMIX (Rashid et al., 2020a) is only evaluated on SMAX where Sable achieves 0.94 vs QMIX's 0.86.

## Relation to Prior Work

Sable directly extends the Multi-Agent Transformer (MAT) line of work, which first framed cooperative MARL as a sequence modeling problem using transformers. Its key architectural departure is replacing MAT's attention mechanism with an RL-adapted version of RetNet's retention mechanism, incorporating a novel encoder-decoder design with cross-retention and resettable hidden states over episode boundaries. The method also draws on recent linear recurrent models for RL (Lu et al., 2024; Morad et al., 2024) and sits within the Heterogeneous-Agent Mirror Learning (HAML) framework for convergence guarantees, while using the PPO objective for policy optimization. Unlike concurrent work applying linear recurrent models as world models (Cohen et al., 2024; Wang et al., 2024), Sable is the first to use RetNets directly for learning control policies in MARL.

## Why It Matters / Open Questions

Sable addresses a practical trilemma in MARL—strong performance, memory efficiency, and scalability—that no prior method simultaneously satisfies, by achieving centralised-level performance with decentralised-level memory footprint and scaling to over 1000 agents with linear memory growth. The ablation finding that Sable's gains stem from temporal memory (conditioning on episode histories) rather than the retention mechanism itself is a useful diagnostic: it suggests the specific choice of linear recurrence variant may be less critical than the ability to maintain stateful memory, opening the door to other efficient sequence models. A notable limitation is that Sable uses on-policy PPO, causing it to underperform off-policy SAC on continuous control (MABrax), and whether retention-based policies can match off-policy sample efficiency at scale remains open. The introduction of the Neom environment and the comprehensive 45-task benchmark also provide useful infrastructure for future scalability research.

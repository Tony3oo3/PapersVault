## Problem

Simulated robot data can be generated at scale but suffers from two critical gaps when deployed to real robots: semantic mismatch (simulated scenes don't align with target task environments) and simulation discrepancy (visual, physical, and hardware differences between sim and reality). Existing approaches require manual domain randomization tuning and real-world fine-tuning, preventing zero-shot Sim2Real deployment across diverse tasks and robot embodiments.
![Teaser figure](../imgs/ICML20251526/cropped_page0_idx0.webp)

## Input / Output

DexScale takes egocentric human manipulation video (for action trajectory projection via hand retargeting), single- or multi-view RGB scene images (for scene projection via digital-cousin object matching), and free-text task descriptions (for LLM-guided scene completion and reward design) as input. It produces a large-scale simulated skill dataset where each trajectory contains 21-dimensional action data (6-dim joint angles, 7-dim end-effector pose in robot base frame, 1-dim gripper state, 7-dim end-effector pose in camera frame) paired with 512×640 rectified RGB images, augmented with automatic domain randomization and adaptation. The resulting dataset is architecture-agnostic and can train ACT, Diffusion Policy, or RDT-1B policies for zero-shot real-world deployment.

## Method

DexScale is a three-stage data engine: (1) Heterogeneous Data Projection maps real-world observations into simulation by matching detected objects to 'digital cousins' in asset databases and retargeting human hand poses to robot end-effectors via generalized inverse kinematics with joint-space interpolation; (2) Automatic Domain Randomization uses an LLM to rank relevant DR features for a given task, then applies the ADR algorithm to iteratively tune DR parameter distributions based on fine-tuned policy feedback, distinguishing action-invariant DR (removes irrelevant features like lighting) from semantic-aware DR (requires policy adaptation for features like object pose); (3) Domain Adaptation projects observations into object-oriented point-cloud and pose-affordance representations to strip task-irrelevant visual features. The combined DR+DA dataset enables imitation policies to achieve zero-shot Sim2Real transfer across single-arm, dual-arm, and multi-robot configurations without any real-world fine-tuning.

## Results

Across 10 Sim2Real domain gaps, DexScale (full pipeline with DR+DA) consistently achieves the highest success rates in both simulation and real-world deployment. The most dramatic gains appear on Object Pose (15/100 → 69/100 Sim; 1/10 → 4/10 Real) and Object Shape (11/100 → 61/100 Sim; 0/10 → 3/10 Real) compared to the Skills-Only baseline. In the handcrafted-DR comparison, success rates on pick-and-place tasks increase progressively from 0.62/0.10 (Sim/Real) with one DR feature to 0.79/0.56 with four features, validating the benefit of automatic DR selection.

## Baselines & Comparisons

The paper does not compare against external Sim2Real methods; instead, it ablates its own pipeline components. DexScale (DR+DA) outperforms Skills-Only by a wide margin on the hardest gaps: Object Pose improves from 15% to 69% (Sim) and 10% to 40% (Real), and Object Shape from 11% to 61% (Sim) and 0% to 30% (Real). Adding only DR (Skills+DR) or only DA (Skills+DA) recovers part of the gap but never matches the full pipeline, confirming that both domain randomization and domain adaptation are necessary. In a separate comparison against handcrafted DR (manually selecting top-ranked features: camera orientation, table texture, distractors), DexScale's automatic DR selection yields higher real-world success rates (e.g., 0.56 vs. 0.40 on the four-feature setting), demonstrating that LLM-guided DR feature ranking and ADR-based parameter tuning outperform expert-chosen randomization.

## Relation to Prior Work

DexScale positions itself as a unified data engine that synthesizes several existing threads: the Digital Cousin concept (Dai et al., 2024) for scene projection, human-to-robot retargeting from MimicGen/DexMimicGen, and the ADR algorithm (OpenAI et al., 2019) for automated domain randomization. Its key departure is treating these as components of a single automated pipeline where an LLM selects and ranks DR features and ADR iteratively updates randomization distributions conditioned on task feedback, rather than requiring manual specification of randomization ranges. The generated dataset is architecture-agnostic, feeding into existing imitation policies (ACT, Diffusion Policy, RDT-1B) rather than proposing a new policy model.

## Why It Matters / Open Questions

DexScale addresses the core 'data hunger' bottleneck in robot foundation model training by enabling large-scale simulated skill generation without costly real-world data collection, and demonstrates zero-shot Sim2Real deployment across multiple embodiments and tasks. However, real-world success rates remain modest (3–6/10), and the pipeline still requires manual scene refinement and is limited to manipulation tasks with relatively short horizons. Open questions include whether the automated DR generalizes to more complex, long-horizon tasks (e.g., cooking), whether it scales to humanoid embodiments, and how to handle the residual gap when the real environment falls outside the randomized distribution's support.

## Problem

VAR Transformers achieve state-of-the-art image synthesis via coarse-to-fine next-scale prediction, yet their theoretical expressiveness remains uncharacterized. While standard transformers have been proven universal approximators, no prior work established whether the VAR architecture—with its pyramid-shaped token maps, bicubic up-sampling, and single self-attention layer—possesses comparable approximation power. This paper asks: are VAR Transformers (and their flow-based variants) universal approximators?

## Input / Output

The target function class is any Lipschitz word-to-image mapping f_word2img: R^{1×1×d} → R^{h_r×w_r×d}, where the input is a single d-dimensional token representing the text condition and the output is a spatial token map at the finest resolution level. The universality guarantee holds in the L_α function norm for any 1 ≤ α < ∞, with approximation error O(ε) achievable by a VAR Transformer of sufficient width (exponential in d·h_r·w_r). The same framework extends to FlowAR (using down-interpolation) and HOFAR (using higher-order velocity predictions).

## Method

The proof decomposes the target function into alternating compositions of K-Lipschitz functions f_i and up-interpolation functions g_i, then shows each pair (f_i ∘ g_i) can be approximated by a single attention layer τ_i composed with a bicubic spline up-interpolation Φ_up,i. The key ingredients are: (1) the contextual mapping property of any-rank single-head attention (Lemma 5.4), which allows the attention layer to distinguish tokens across different contexts; (2) a transformer construction (Lemma C.1) using positional encoding, a step-function FFN for quantization, and a bump-function FFN for output assignment; and (3) perturbation lemmas (Lemmas 6.3–6.5) that bound cumulative error propagation through r-layer compositions via Lipschitz constants. The result extends to FlowAR by replacing up-interpolation with down-interpolation (Corollary 7.2) and to HOFAR by noting that higher-order velocity blocks contribute additively to the error (Corollary 7.3), preserving the O(ε) guarantee.

## Results

This is a purely theoretical paper with no empirical benchmarks. The main result (Theorem 6.6) establishes that a single-layer, single-head VAR Transformer can approximate any Lipschitz word-to-image function to arbitrary precision O(ε), requiring O((1/ε)^{d(h_r w_r)}) FFN neurons. Corollary 7.2 extends this universality guarantee to FlowAR models, and Corollary 7.3 further extends it to HOFAR (higher-order FlowAR), showing that adding a second velocity-prediction block only doubles the error bound (2ε) while preserving the universal approximation property.

## Baselines & Comparisons

This paper contains no empirical comparisons or baseline evaluations; it is a theoretical analysis paper. The key theoretical contribution is extending the universal approximation framework from standard transformers (Yun et al., 2020; Hu et al., 2024b) to the VAR Transformer architecture, showing that the coarse-to-fine next-scale prediction schedule with a single self-attention layer suffices for universality. The proof technique builds directly on Lemma 2.2 from Hu et al. (2024b) (any-rank attention as a contextual mapping) and the transformer construction from Lemma F.2 of the same work, adapting them to the pyramid up-interpolation structure of VAR. The FlowAR extension (Corollary 7.2) mirrors the VAR proof by replacing up-interpolation with down-interpolation, and the HOFAR extension (Corollary 7.3) follows from the linearity of error accumulation across two K-Lipschitz velocity-prediction blocks.

## Relation to Prior Work

This paper extends the universal approximation theory for standard transformers (Yun et al., 2020; Kajitsuka & Sato, 2024; Hu et al., 2024b) to the Visual Autoregressive (VAR) framework, which introduces a pyramid-shaped token structure with bicubic spline up-sampling and a coarse-to-fine next-scale prediction schedule. The key technical tool—the contextual mapping lemma for single-head attention—is borrowed directly from Hu et al. (2024b), and the formal VAR component definitions are sourced from Ke et al. (2025a). The paper then extends the same perturbation-based proof to FlowAR (Ren et al., 2024) and HOFAR (Liang et al., 2025b), showing that replacing up-sampling with down-sampling or adding higher-order velocity terms does not break the universality guarantee.

## Why It Matters / Open Questions

This work fills a notable theoretical gap: VAR and FlowAR have achieved state-of-the-art empirical performance in image generation, yet no prior work provided a formal expressiveness guarantee for these architectures. The result that even a single-layer, single-head VAR transformer is universal suggests that the architectural complexity of deep VAR stacks may be driven by optimization and inductive bias rather than raw representational capacity. However, the proof requires FFN width exponential in the image spatial dimension (O(ε^{-d(h_r w_r)})), so the guarantee is existential rather than practical. Open questions include whether tighter width bounds exist, whether the Lipschitz assumptions are necessary, and whether these theoretical insights can inform more efficient architectural design or training strategies.

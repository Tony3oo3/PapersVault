## Problem

FEAT produces intrinsically interpretable symbolic regression models but relies on genetic programming, which is provably inefficient and often fails to find short, interpretable equations. Meanwhile, TabNet achieves strong predictive performance on tabular data but is a black-box deep learning model. The paper asks whether TabNet's learned representations can be distilled into FEAT's interpretable structure, combining deep learning's optimization with symbolic transparency.
![Teaser figure](../imgs/ICML20250669/cropped_page1_idx0.webp)

## Input / Output

The method takes a tabular feature vector x ∈ R^d (scaled to zero mean, unit variance) and N paired examples, and produces a weighted linear combination of at most 6 concisely-represented symbolic features, each a short equation (≤5 symbols) built from a restricted primitive set {+, −, ×, ÷, exponent} and the top-3 original features selected per TabNet step. For multi-target regression, the same shared symbolic features are reused across all targets with different weight vectors, yielding a single compact model rather than independent per-target models.

## Method

FEAT-KD is a 5-phase pipeline: (1) train a TabNet regressor (N_d=2, N_steps=3), (2) extract the N_d×N_steps transformed feature vectors from each Step's ReLU units, (3) use TabNet's sparse learnable masks to restrict each Step's distillation to only the top-3 least-masked original features, (4) run DistilSR—an exhaustive, non-evolutionary symbolic regression search over all equations of length ≤5—on each Step's restricted feature set, minimizing AFI-MSE (affine-invariant MSE) to account for the affine transformation the features will undergo in the final linear regression, and (5) fit a simple linear regression on the resulting symbolic features to obtain the final weights. The key insight is that TabNet's sequential attention mechanism decomposes the global equation-discovery problem into small, tractable subtasks (3 features × 5-symbol search space per Step), making exhaustive search feasible where genetic programming over the full space is not.

## Results

On single-target regression across 15 datasets, FEAT-KD achieves the best average R² among all white-box (symbolic) models, with values ranging from 0.181 (pm10) to 0.987 (bodyfat), closely tracking TabNet's black-box performance (e.g., 0.941 vs 0.993 on Syn1, 0.976 vs 0.982 on cpu_act_197). FEAT-KD produces a fixed model size of ~49 symbols, compared to 40–104 for FEAT variants and 5.5k–7.2k for TabNet. In multi-target regression across 54 targets, FEAT-KD outperforms TabNet on 32 targets, with the shared 6 symbolic features enabling a compact, interpretable multi-output model.

## Baselines & Comparisons

Against FEAT, FEAT-Corr, and FEAT-CN, FEAT-KD achieves statistically significant (Bonferroni-adjusted Wilcoxon, p<0.05) higher R² on 11 of 15 single-target datasets and smaller model size on 12 of 15, with a fixed size of ~49 symbols versus the highly variable 40–104 range of the GP-based FEAT variants. Against TabNet (black-box), FEAT-KD is within ~1–5% R² on most single-target datasets (e.g., 0.941 vs 0.993 on Syn1) but with a model 100× smaller (49 vs ~6k parameters); on multi-target regression, FEAT-KD actually outperforms TabNet on 32 of 54 targets, suggesting a regularization effect. Against SR algorithms in the SRBench comparison (88 PMLB datasets), FEAT-KD is Pareto-optimal on 62% of datasets, outperforming FEAT (23%), DSR (8.3%), and Operon (52.6%) in Pareto-front frequency, though DSR and GP-GOMEA appear slightly more frequently. In the ablation (Appendix G), replacing DistilSR with Operon, PySR, DSR, or ParFam drops Pareto-front frequency from 88.6% to 1.3%–54.4%, confirming DistilSR's critical role. Against InterpreTabNet, FEAT-KD(InterpreTabNet) yields marginally better R² on some PMLB datasets (e.g., 0.990 vs 0.987 on bodyfat) and competitive classification accuracy (e.g., 0.969 vs 0.987 on chess), showing the framework generalizes to alternative teacher architectures.

## Relation to Prior Work

FEAT-KD sits at the intersection of three research threads: FEAT's symbolic regression via genetic programming (La Cava et al., 2019), TabNet's sequential attention-based tabular learning (Arik & Pfister, 2021), and the emerging practice of distilling neural network components into symbolic equations (Cranmer et al., 2020; Lemos et al., 2023). The key conceptual departure from FEAT is replacing genetic programming with a two-stage distillation pipeline: TabNet's sparse masks identify relevant feature subsets per step, and DistilSR's exhaustive search recovers short symbolic expressions for each step's transformed output. This reframes the feature-discovery problem from a global evolutionary search into a collection of small, tractable subproblems, while preserving FEAT's interpretable linear-combination output structure.

## Why It Matters / Open Questions

The paper provides a practical recipe for converting a trained deep tabular model into a compact, intrinsically interpretable symbolic model with competitive accuracy, which is directly relevant to high-stakes domains (healthcare, finance) where post-hoc explanations are insufficient. The multi-target regression support with shared symbolic features is a genuine extension that FEAT lacks, and the AFI-MSE metric for the distillation step is a useful practical insight. Open questions include whether the approach generalizes to other teacher architectures beyond TabNet, whether the 5-symbol length cap is too restrictive for complex real-world relationships, and how the method scales to very high-dimensional inputs where the exhaustive search space grows rapidly.

## Problem

Contextual online decision-making problems (bandits, sequential hypothesis testing, online risk control) all reduce to learning the underlying distribution P_{x,a} for each context-action pair, but when the model class is uncountably infinite-dimensional, existing contextual bandit algorithms yield infinite regret. No prior work provides a unified algorithmic framework with finite regret guarantees for infinite-dimensional functional regression of cumulative distribution functions under bandit feedback.
![Teaser figure](../imgs/ICML20250947/cropped_page2_idx0.webp)

## Input / Output

At each round the algorithm receives a context x drawn i.i.d. from an unknown distribution, selects an action a from a finite set A, and observes a single scalar sample y from the CDF F*(x,a,s) (bandit feedback, not the full function). The basis family φ(x,a,w,s) is parameterized by w in a compact set Ω⊂ℝ^d, and the unknown coefficient θ* lives in L²(Ω,ν). The output is a full estimated CDF F̂(x,a,s) = ∫θ̂(w)φ(x,a,w,s)dν(w) and the corresponding action a_t, with the utility functional T applied to the estimated CDF to drive exploration-exploitation.

## Method

The paper models each CDF as F*(x,a,s) = ⟨θ*, φ(x,a,·,s)⟩ and defines a design integral operator U_D = Σ_j L^{x_j,a_j} that plays the role of the normal matrix X^TX in finite-dimensional regression. Since U_D is a compact Hilbert-Schmidt operator with eigenvalues tending to zero, the method replaces standard regularization with eigenvalue-based truncation: it keeps only the first N_{D,ε} eigen-directions where λ_i ≥ nε, with ε* = n^{-2/(γ+2)} tuned to the γ-dominating eigendecay rate of the operator family. The truncated operator's pseudo-inverse yields a least-squares solution θ_D, which is then projected onto the constraint set {θ≥0, ∫θ=1, ‖θ‖≤M} under the U_D-norm. For sequential decision-making, an Inverse Gap Weighting (IGW) batched policy calls this regression oracle only O(log T) times across geometrically growing epochs, balancing exploration and exploitation to achieve utility regret Õ(T^{(3γ+2)/(2(γ+2))}), recovering the optimal Õ(√T) rate when γ→0 (finite-dimensional or exponentially decaying eigenvalues).

## Results

The paper's main theoretical result (Theorem 4.2) establishes that the expected utility regret after T rounds is bounded by Õ(C·T^((3γ+2)/(2(γ+2)))), where γ ∈ (0,1] characterizes the polynomial eigendecay rate of the design integral operator. When γ→0 (exponential eigendecay or finite-dimensional setting), this recovers the optimal Õ(√T) regret rate known from contextual bandits literature. In the worst case with no prior knowledge of the eigendecay rate (γ=1), the algorithm still achieves sublinear regret Õ(T^(5/6)) (Corollary 4.3). The functional regression oracle (Theorem 3.6) achieves an estimation error of O(n^(γ/(γ+2))) in the operator norm, which directly governs the regret rate.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical experiments, datasets, or baseline algorithm comparisons. The paper does not benchmark against existing contextual bandit algorithms (e.g., LinUCB, SupLinUCB, or Foster & Rakhlin's oracle-based methods) on any dataset. Instead, it provides a unified theoretical framework that subsumes multiple decision-making problems (contextual bandits, sequential hypothesis testing, mean-variance bandits) under a single infinite-dimensional functional regression model. The key theoretical comparison is that the derived regret rate Õ(T^((3γ+2)/(2(γ+2)))) recovers the known optimal Õ(√T) rate in the finite-dimensional and exponential-eigendecay cases, matching existing results in the contextual bandits literature. The paper positions itself as the first to address contextual decision-making based on infinite-dimensional functional regression, noting that existing contextual bandit algorithms yield infinite regret in this setting.

## Relation to Prior Work

This paper extends finite-dimensional CDF regression (Zhang et al., 2022) to the infinite-dimensional setting by replacing the infeasible regularization term with eigenvalue-based truncation of a design integral operator, leveraging Hilbert-Schmidt spectral decomposition. The sequential decision-making algorithm (Algorithm 2) directly inherits the batched, low-frequency oracle-call structure from Simchi-Levi & Xu (2021) and Qian et al. (2024), adapting the Inverse Gap Weighting exploration policy to the functional regression oracle. The key conceptual departure is that the complexity of the problem is governed not by a finite dimension but by the polynomial decay rate γ of the eigenvalue sequence of the integral operator, a connection absent from prior contextual bandit or operator learning literature.

## Why It Matters / Open Questions

The framework provides a single, unified algorithmic and theoretical treatment for contextual bandits, sequential hypothesis testing, and mean-variance bandits by learning the full underlying CDF rather than a single statistic, which is a natural but previously unaddressed generalization. The eigenvalue-decay-to-regret connection is a new and potentially useful complexity measure for infinite-dimensional online learning problems. Open questions include whether the T^{(3γ+2)/(2(γ+2))} regret rate is minimax-optimal, whether the framework extends to adversarial contexts, and whether it can handle nonlinear relationships between the CDF and the basis family. The absence of empirical validation limits immediate practical impact, but the theoretical toolkit (truncated integral operators, pseudo-inverses in infinite dimensions) may inform future applied work.

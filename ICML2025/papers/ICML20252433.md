## Problem

Token-level language models parameterized over BPE token strings assign nonzero probability to an exponentially large set of noncanonical encodings—token strings that decode to valid character strings but could never be produced by the deterministic BPE tokenizer. This misallocation of probability mass is both erroneous (noncanonical strings never appear in training data) and wasteful, diverting mass away from plausible outputs. The paper asks how to enforce canonicality so that only valid BPE encodings receive positive probability.
![Teaser figure](../imgs/ICML20252433/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained token-level language model (GPT-2 or Llama) and its BPE merge list as input, and during generation consumes a token string prefix to decide which next tokens are canonical. It produces a probability distribution restricted to the canonical token set D (the image of the BPE encoder), yielding canonical token strings and improved log-loss estimates on held-out data. The canonicality check is incremental: given a prefix δ, it tests in O(1) whether appending a candidate token δ′ keeps the extended string in the canonical prefix set, exploiting the fact that for BPE a string is canonical iff all its bigrams are canonical (Theorem 1).

## Method

The paper proposes two complementary approaches. First, canonicality by conditioning: at test time, the model is conditioned on the event that the output is canonical, implemented either globally (exact renormalization by the canonicality rate Z, estimated via importance sampling from a local proposal) or locally (masking any next-token that would render the prefix noncanonical, which is a cheap O(1) per-step check). The local method introduces a known warping factor w_ℓ(δ), and importance resampling can correct it at the cost of additional computation. Second, canonicality by construction: the model's output layer is augmented with the same canonicality mask, and the parameters are fine-tuned with a combined objective of log-loss on canonical training strings plus a KL-divergence regularizer toward the original model, allowing parameters previously spent modeling canonicality to be repurposed for other linguistic phenomena. The key enabling result is an efficient bigram-based canonicality test that avoids the automata-theoretic machinery of prior work.

## Results

The paper evaluates log-loss (bits/string) on held-out data for the baseline (p_Δ), locally canonicalized (ℓ), and globally canonicalized (g) methods. On PTB, the global method reduces log-loss by 1.4–1.9 bits across models (e.g., GPT-2 small: 201.0→199.1; Llama 8B: 161.5→160.1), while the local method achieves smaller gains of 0.1–0.5 bits. On WikiText, improvements are larger in absolute terms (1.9–2.4 bits for global; 1.2–2.4 bits for local), and the local method actually outperforms the global method in most cases (e.g., Llama 8B: 248.2→245.8 local vs. 246.8 global). All improvements are statistically significant (p=0 under paired-permutation tests).

## Baselines & Comparisons

The paper compares three methods: the unconstrained baseline (p_Δ), the locally canonicalized model (ℓ), and the globally canonicalized model (g). The global method dominates on PTB, achieving the best log-loss for all six models (e.g., 1.9 bits lower than baseline for GPT-2 small, 1.4 bits for Llama 8B). On WikiText, the local method wins in 5 of 6 model configurations (e.g., 2.4 bits lower than baseline for Llama 8B vs. 1.4 bits for global), with the sole exception being GPT-2 medium where global is marginally better (332.2 vs. 333.2). The authors attribute the local method's WikiText advantage to its warping effect inadvertently aligning better with the WikiText distribution. Both canonicalization methods are guaranteed to never worsen log-loss relative to the baseline (Propositions 1 and 3), and all observed improvements are statistically significant.

## Relation to Prior Work

This paper extends the tokenized language model framework from Vieira et al. (ICML 2024), which formalized how character-string LMs are parameterized via token-level models and a decoding function, by identifying and fixing a specific pathology: probability mass leakage to noncanonical token strings. It departs from prior BPE canonicality tests (Berglund et al., 2024; Cognetta & Okazaki, 2024) that relied on finite-state automata theory, offering instead a simpler bigram-based membership test (Theorem 1) that is linear in string length and straightforward to implement. The fine-tuning objective borrows the KL-regularized training paradigm from the RLHF literature (Christiano et al., 2017; Ziegler et al., 2020) and uses Amini et al.'s (2025) Rao-Blackwellized gradient estimator for the regularization term.

## Why It Matters / Open Questions

The finding that canonical encodings can be ranked as low as 4th among token encodings (with only 2.7% probability vs. 78% for a noncanonical one) reveals a systematic miscalibration in all BPE-based LMs that has gone unaddressed. The clean theoretical guarantee (Propositions 1 and 3) that canonicality enforcement strictly reduces KL divergence provides a principled justification, and the bigram test simplifies a previously automata-theoretic problem. However, the empirical log-loss improvements are modest (~1–2 bits/string), the paper evaluates only probability estimation rather than downstream tasks, and the authors acknowledge that pre-tokenization interactions introduce edge cases. Open questions include whether canonicality enforcement helps or hurts on rare/adversarial inputs, whether it transfers to other tokenizers (WordPiece, longest-match), and whether SMC-based inference can close the gap between the local and global methods at scale.

## Problem

The logistic (cross-entropy) loss is the default for multiclass classification and language modeling, but it is tied to the KL divergence and a uniform reference measure. Prior attempts to incorporate other f-divergences naively composed them with the classical softargmax, yielding non-convex losses that are difficult to optimize. This paper asks whether one can construct convex loss functions from arbitrary f-divergences that generalize the logistic loss in two directions: replacing KL with any f-divergence and allowing non-uniform reference measures (class priors).

## Input / Output

The method takes logits θ ∈ R^k from a neural network, a reference measure q ∈ R_+^k encoding prior class weights (defaulting to the unit vector when no prior is available), and ground-truth labels y ∈ Δ^k that may be hard one-hot vectors or soft probability distributions (the latter enabling distillation). It outputs class probabilities via the f-softargmax operator and a scalar convex loss value. A notable property is that for certain divergences (chi-square, α-divergence with α > 1), the f-softargmax can produce probability distributions with exactly zero entries, yielding sparse predictions.

## Method

The paper instantiates the Fenchel-Young loss framework with f-divergence regularization Ω_f(p; q) = D_f(p, q), defining f-softmax and f-softargmax as variational operators that maximize ⟨p, θ⟩ − D_f(p, q) over the simplex. The key theoretical result (Proposition 1) reduces computing both operators to solving a one-dimensional root-finding equation in a scalar τ, which is solved by a parallelizable bisection algorithm with exponential convergence. This recovers the classical softargmax (KL), sparsemax (chi-square), and entmax (α-divergence) as special cases while enabling entirely new losses (Jensen-Shannon, squared Hellinger) and non-uniform priors. The resulting loss is convex in θ with gradient f-softargmax(θ; q) − y, and the α-divergence with α = 1.5 (Tsallis negentropy) empirically outperforms cross-entropy on ImageNet classification, language model pretraining, SFT, and distillation.

## Results

On ImageNet-2012 with ResNet50, the α-divergence loss (α=1.5) achieves 77.56% top-1 accuracy, surpassing the standard cross-entropy (KL) loss at 76.87% without any hyperparameter tuning. On C4 pretraining (1.2B NanoDO model), α-divergence (α=1.5) reaches 48.70% next-token prediction accuracy versus 48.66% for KL. On XSum summarization (T5-base), α-divergence (α=1.5) achieves ROUGE-2 of 14.27 for SFT and 17.43 for distillation, outperforming KL (9.77 and 16.64 respectively).

## Baselines & Comparisons

The paper's framework recovers sparsemax (Martins & Astudillo, 2016) as the Chi-square divergence instance and entmax (Peters et al., 2019) as the α-divergence instance, while also introducing new losses (Jensen-Shannon, Squared Hellinger). On ImageNet, the α-divergence (α=1.5) loss outperforms the standard KL/cross-entropy baseline by 0.69 points (77.56% vs 76.87%) and the sparsemax/Chi-square baseline by 1.50 points (77.56% vs 76.06%). On XSum SFT, α-divergence (α=1.5) dramatically outperforms both KL (14.27 vs 9.77 ROUGE-2) and Chi-square/sparsemax (14.27 vs 11.15). On distillation, α-divergence again leads (17.43 vs 16.64 for KL, 17.43 vs 14.17 for Chi-square). Notably, the Chi-square/sparsemax loss underperforms KL on ImageNet and pretraining but beats KL on SFT, while Jensen-Shannon and Squared Hellinger losses consistently underperform all other variants across tasks.

## Relation to Prior Work

This paper unifies the logistic (cross-entropy), sparsemax, and entmax losses under a single Fenchel-Young loss framework where the regularizer is an f-divergence with a tunable reference measure q. It departs from prior f-divergence-based approaches (Go et al., 2023; Wang et al., 2024) that naively composed f-divergences with the classical softargmax, yielding non-convex losses, by instead using the Fenchel-Young construction to guarantee convexity. The bisection algorithm for computing the f-softargmax generalizes Wang et al.'s (2024) result to the sparse-output regime (0 ∈ dom f′), and the framework subsumes sparsemax (Chi-square) and entmax (α-divergence) as special cases while extending them to non-uniform class priors.

## Why It Matters / Open Questions

The framework provides a principled, convex loss family that practitioners can instantiate for any f-divergence, with a simple parallelizable bisection algorithm for the associated operator. The consistent (if modest) outperformance of the α=1.5 divergence over cross-entropy across ImageNet, pretraining, SFT, and distillation—without hyperparameter tuning—suggests a practical drop-in improvement for language model training pipelines. A notable practical finding is that standard softargmax decoding performs comparably to f-softargmax decoding, meaning the losses can be adopted without modifying inference code for open-weight models. Open questions include why α=1.5 is optimal, whether learning the reference measure q could help in richer settings, and whether the gains persist at larger model scales.

## Problem

Fine-tuning large pre-trained ECG models incurs prohibitive GPU memory costs due to activation caching during backpropagation, making them unaffordable on low-level clinical devices. While memory-efficient alternatives like LoRA and zeroth-order optimization exist, none jointly address both the fine-tuning and inference costs of pre-trained models while maintaining diagnostic performance in ECG-based CVD detection.
![Teaser figure](../imgs/ICML20253201/cropped_page2_idx0.webp)

## Input / Output

The teacher model consumes 12-lead ECG recordings (10 s at 500 Hz, band-pass filtered 1–47 Hz, z-score normalized) and outputs multi-label CVD predictions via binary cross-entropy. The distilled student model accepts 12-lead, 3-lead (II, V1, V5), or 1-lead (I) ECG inputs to support wearable devices, producing the same multi-label CVD class scores. The student model has only 0.26 M parameters versus 50.49 M for the teacher, enabling 1.28 ms inference latency on a single GPU.

## Method

H-Tuning introduces a mix-order optimization that first estimates gradients via SPSA (zeroth-order) on the full batch, then refines both the direction and Frobenius norm using first-order backpropagation on a tiny subset (N₁=2 vs. N=128), with a learned weight λ balancing the two estimates. This is combined with LoRA (rank 16) to reduce trainable parameters and a layer-dependent scheme where the last two deep layers are updated with standard backpropagation while shallow layers use the mix-order estimator, cutting GPU memory by 6.34× versus full fine-tuning. A knowledge distillation stage then transfers the fine-tuned teacher's predictions to a tiny student model (64-channel convolutions vs. 512), reducing inference latency by 4.52× and memory by 19.83× while preserving or even improving CVD detection accuracy, particularly for 1-lead and 3-lead configurations.

## Results

H-Tuning achieves an average macro F_{β=2} of 0.600 across four ECG datasets (G12EC, PTB-XL, Ningbo, Chapman) while consuming only 1.453 GB of GPU memory, a 6.34× reduction compared to Full Fine-Tuning (9.214 GB) and 6.02× less than LoRA (8.754 GB). Performance losses relative to Full FT and LoRA are within 0.5% and 0.7% on macro F_{β=2}, respectively. After knowledge distillation, the student model (0.26M params) reduces inference latency by 4.52×, GPU memory by 19.83×, and parameter count by 194.23× versus the 50.49M-parameter teacher, while maintaining comparable CVD detection accuracy.

## Baselines & Comparisons

Against Full FT and LoRA (first-order baselines), H-Tuning matches or slightly exceeds their macro F_{β=2} on 3 of 4 datasets (e.g., 0.628 vs 0.618 on PTB-XL; 0.634 vs 0.623 on Chapman) while using 6.34× and 6.02× less GPU memory, respectively. Against MeZO (pure zeroth-order), H-Tuning dramatically outperforms: MeZO's macro AUC collapses to ~0.50–0.53 (near random) across all datasets because prompt engineering is infeasible for ECG signals, whereas H-Tuning maintains AUC above 0.87. Against Addax (the strongest hybrid-order competitor), H-Tuning wins on macro F_{β=2} across all four datasets (e.g., 0.628 vs 0.578 on PTB-XL, 0.634 vs 0.596 on Chapman) with comparable memory (~1.45 vs ~2.00 GB). Against LoHO, H-Tuning similarly outperforms on macro F_{β=2} on all datasets (e.g., 0.586 vs 0.554 on G12EC, 0.628 vs 0.588 on PTB-XL). The one notable exception is the Ningbo dataset, where H-Tuning's macro F_{β=2} (0.550) trails Full FT (0.591) and LoRA (0.580), suggesting dataset-dependent variability that the authors flag for future investigation.

## Relation to Prior Work

This paper builds on the zeroth-order optimization line (SPSA, MeZO) and parameter-efficient fine-tuning (LoRA) to address the GPU memory bottleneck in fine-tuning large pre-trained ECG models. It departs from MeZO, which relies on prompt engineering (infeasible for physiological signals), and from Addax/LoHO, which combine first- and zeroth-order gradients differently, by proposing a 'mix-order' scheme that uses SPSA for an initial gradient estimate and refines it via backpropagation on a tiny subset, with a layer-dependent update strategy (first-order for deep layers, mix-order for shallow layers). The knowledge distillation component extends prior ECG distillation work (Sepahvand & Abdali-Mohammadi, 2022) by integrating it into a joint fine-tuning-and-inference workflow rather than treating compression as a separate post-hoc step.

## Why It Matters / Open Questions

The practical impact is significant for deploying pre-trained ECG foundation models in resource-limited clinical settings: a 6.34× reduction in fine-tuning GPU memory and a 19.83× reduction in inference memory enable use on low-level devices without sacrificing diagnostic accuracy. However, H-Tuning does not accelerate per-iteration training time, and its performance on the Ningbo dataset lags slightly behind Full FT, suggesting dataset-dependent stability concerns. Open questions include whether the mix-order optimization generalizes to other physiological signals (EEG, PPG) and whether the layer-dependent update heuristic (M=2 deep layers) is optimal or should be learned. The external validation on a wearable 12-lead dataset strengthens the mobile-healthcare narrative but uses only 10% of training data, leaving the method's behavior under even stricter budgets unexplored.

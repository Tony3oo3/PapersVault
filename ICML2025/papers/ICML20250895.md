## Problem

Existing concealed object segmentation methods apply reversible strategies (e.g., foreground-background calibration) only at the mask level, leaving the RGB domain underexplored. The paper identifies that mask uncertainty manifests as color distortion in the RGB space, and that jointly addressing both domains can direct network attention to ambiguous regions and reduce false positives/negatives.

## Input / Output

The method takes a single concealed RGB image resized to 352×352 and produces a segmentation mask, an auxiliary edge map, and a reconstructed image at each of K=4 stages. Rather than operating on raw pixels, the network consumes deep features E(C) extracted from a pretrained encoder (ResNet50 or PVT V2), with features from the last four encoder layers progressively fed to the four stages (deepest first). The final outputs are the last-stage mask, edge, and reconstruction, while intermediate stage outputs are supervised with a weighted multi-stage loss.

## Method

RUN formulates COS as a foreground-background separation problem with an added residual sparsity constraint that penalizes uncertain mask values (pixels in [0.4, 0.6] are excluded via an attention map, and extreme values are clamped to 0.1/0.9). The proximal gradient solution of this objective is unfolded into a multi-stage network where each stage contains two reversible modules: SOFS computes a closed-form mask update (Eq. 13) then refines it via a Reversible State Space module (two VSS blocks with small/large perception fields for local edge refinement and global missed-region recovery), while ROBE computes a closed-form background update and refines it with a lightweight 3-layer U-shaped network that simultaneously reconstructs the full image. The reconstruction loss on the RGB domain identifies distortion-prone areas where foreground and background modules disagree, effectively guiding the network toward uncertain regions. Originally fixed parameters (e.g., Lipschitz constants, gradient terms) are relaxed to learnable parameters, and the entire framework is trained end-to-end with a weighted combination of BCE, IoU, Dice, and MSE reconstruction losses across all stages.

## Results

On the primary camouflaged object detection (COD) task, RUN with ResNet50 achieves Fβ=0.855, Eφ=0.952, Sα=0.895 on CHAMELEON and Fβ=0.747, Eφ=0.903, Sα=0.827 on COD10K, outperforming the strongest baseline FEDER (Fβ=0.850, Eφ=0.944, Sα=0.892 and Fβ=0.715, Eφ=0.892, Sα=0.810 respectively). With the PVT V2 backbone, RUN reaches Fβ=0.877, Sα=0.916 on CHAMELEON and Fβ=0.868, Sα=0.892 on NC4K, surpassing CamoFocus (Fβ=0.869, Sα=0.906 and Fβ=0.862, Sα=0.886). RUN also achieves top performance on polyp segmentation (mDice=0.822 on CVC-ColonDB), medical tubular segmentation (mDice=0.812 on DRIVE), and transparent object detection (mIoU=0.895, Fβ^max=0.952 on GDD).

## Baselines & Comparisons

On COD (Table 1), RUN outperforms all 11 baselines across all four datasets and three backbones (ResNet50, Res2Net50, PVT V2) in the common setting. The closest competitor FEDER is beaten by 0.005 in Fβ on CHAMELEON (0.855 vs 0.850) and by 0.032 in Fβ on COD10K (0.747 vs 0.715); against the strongest PVT V2 method CamoFocus, RUN gains 0.008 Fβ on CHAMELEON (0.877 vs 0.869) and 0.006 Sα on NC4K (0.892 vs 0.886). In the multi-stage setting, RUN-4 surpasses FEDER-4 by 0.015 Fβ on CHAMELEON (0.889 vs 0.874) and by 0.017 Fβ on COD10K (0.769 vs 0.752). On polyp segmentation (Table 2), RUN achieves the best mDice (0.822) and Sα (0.880) on CVC-ColonDB, edging out LSSNet (0.820, 0.867) and CASCADE (0.809, 0.867). On medical tubular segmentation (Table 3), RUN leads all five baselines on both DRIVE (mDice 0.812 vs. best 0.806 for SGAT) and CORN (mDice 0.652 vs. best 0.647 for FFM). On transparent object detection (Table 4), RUN achieves the best mIoU (0.895) and Fβ^max (0.952) on GDD, surpassing GhostingNet (0.893, 0.943) and IEBAF (0.887, 0.944), and the best Fβ^max (0.938) and lowest M (0.043) on GSD over RFENet (0.931, 0.048).

## Relation to Prior Work

RUN extends the deep unfolding paradigm—well established in low-level vision tasks like image fusion and dehazing (Fang et al., 2024; He et al., 2023a)—to the high-level vision domain of concealed object segmentation, where no explicit intrinsic model previously existed. It builds directly on FEDER's (He et al., 2023b) reversible mask-level foreground-background modeling but departs by introducing a novel COS objective with a residual sparsity constraint and, critically, extending reversibility into the RGB domain via a reconstruction module (ROBE) inspired by HQG-Net's (Xu et al., 2023) U-shaped architecture. The SOFS module incorporates Visual State Space (VSS) blocks from VMamba (Liu et al., 2024) for non-local context, while the overall optimization-to-network unfolding follows the proximal gradient framework of Fang et al. (2024).

## Why It Matters / Open Questions

RUN provides the first theoretically grounded deep unfolding framework for high-level vision, offering a principled bridge between model-based interpretability and data-driven generalizability that pure learning-based COS methods lack. The plug-and-play nature—where RUN can refine or integrate with existing methods (FEDER+, FSEL+) without architectural overhaul—makes it a practical tool for the COS community. Open questions include whether the unfolding-based combination strategy generalizes to other high-level tasks (e.g., instance segmentation, video understanding), whether the RGB-domain reversibility insight transfers to non-COS segmentation, and whether the framework's benefits persist under larger-scale or multi-modal settings. The paper also highlights that a simple 3-layer reconstruction network suffices, suggesting the key gain comes from the joint optimization structure rather than reconstruction capacity.

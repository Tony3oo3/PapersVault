## Problem

Existing embedded feature selection methods for neural networks (e.g., LassoNet, Stochastic Gates, Sequential Attention) require modifications to the loss function, architectural changes, post-selection retraining, or grid search over regularization hyperparameters to control the number of selected features. This paper asks whether feature selection can be achieved with a single, non-intrusive layer that requires no loss modification, no retraining, and no hyperparameter tuning beyond specifying the target feature count k.

## Input / Output

The SAND layer takes an n-dimensional input feature vector and a user-specified target count k, and produces a distorted version of the input where k features are passed nearly noiselessly while the remaining n−k are replaced by Gaussian noise. The layer is inserted at the input of any standard neural network (one hidden layer with ReLU in experiments), and the network's output is the usual class label or regression value. After training, the top-k gains are retained and the rest are zeroed, yielding a pruned model usable for inference without any additional fitting phase. The noise standard deviation σ and norm exponent α are fixed hyperparameters (σ=1.5, α=2) that the method is shown to be insensitive to.

## Method

SAND replaces each input feature x_i with x̃_i = a_i·x_i + (1−a_i)·z_i, where z_i is zero-mean Gaussian noise with standard deviation σ and a_i is a trainable gain. The gain vector is constrained by construction via ℓ_α-norm normalization (||a||_α^α = k), so no regularization term is added to the loss. During training, informative features receive gains near 1 (low noise, high SNR) while uninformative features receive gains near 0 (high noise), and the norm constraint creates a reinforcing polarization loop: as one gain grows, others must shrink, amplifying the separation. Theoretically, for linear regression the paper shows this is equivalent to an objective that promotes exactly k features at gain 1 and n−k at gain 0. In practice, the layer adds only n parameters and n multiply-add operations, requires no retraining after selection, and allows direct specification of k without grid search.

## Results

On the nine benchmark datasets (k=60 features by default), SAND achieves test accuracy ranging from 0.732 (Madelon) to 0.998 (COIL-20), matching or exceeding the best baseline on Mice Protein (0.988), COIL-20 (0.998), and MNIST (0.962). On the novel MSI Grain multi-spectral dataset (k=9), SAND achieves 0.919±0.002 accuracy, outperforming all five baselines (best competitor: SL at 0.918). A key practical advantage is that SAND requires no post-selection retraining, saving approximately 33% of training epochs compared to methods that retrain on the selected subset.

## Baselines & Comparisons

SAND matches or exceeds the best baseline on Mice Protein (0.988, tying GL and STG), COIL-20 (0.998, tying LLY and GL), and the novel MSI Grain dataset (0.919, beating all five baselines by 0.1–0.8%). On MNIST-Fashion and ISOLET, Stochastic Gates (STG) leads by 2.0% and 1.0% respectively, while on Activity, Group LASSO (GL) edges out SAND by 0.7%. SAND underperforms on Madelon (0.732 vs. LLY's 0.862) and CA Housing (MAE 0.521 vs. SA's 0.639), where the retraining phase available to other methods provides a meaningful advantage. Across all comparisons, SAND's key differentiator is that it achieves these results without any post-selection retraining, without hyperparameter search over a regularization parameter (unlike STG, which requires grid search over λ), and with direct user-specified control over the number of selected features k.

## Relation to Prior Work

SAND carves new ground at the intersection of stochastic gating (Yamada et al., 2020) and constrained optimization, but departs from both in critical ways. Unlike stochastic gates, which add a Gaussian regularization term to the loss and require grid search over a hyperparameter to control the number of selected features, SAND enforces the feature count k by construction through an ℓ_α-norm normalization of the gain vector, leaving the loss function and network architecture untouched. The additive noise distortion mechanism is conceptually related to Dropout (randomization at the input), but the hard norm constraint reverses its effect: instead of spreading information evenly, it drives gains to polarize at 0 and 1, effectively selecting features. The theoretical analysis for linear regression connects the method to a regularized objective, providing a bridge to the LASSO/Group LASSO literature without actually modifying the training objective.

## Why It Matters / Open Questions

The practical value of SAND lies in eliminating the two-phase pipeline (select then retrain) that plagues most embedded feature selection methods, reducing training time by ~33% and removing the need for hyperparameter sweeps over regularization strength. The method's robustness to σ and α (nearly identical performance across a wide range) makes it genuinely plug-and-play, which is rare in feature selection. However, the theoretical guarantee is limited to linear regression, and all experiments use a single-hidden-layer network; behavior in deeper architectures, CNNs, or transformers remains unexplored. Open questions include whether the polarization effect holds with structured feature relationships, different noise distributions, and whether the method can be extended to intermediate-layer pruning as the authors suggest.

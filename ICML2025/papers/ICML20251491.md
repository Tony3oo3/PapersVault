## Problem

Existing diffusion-based OOD data generation methods (e.g., DreamOOD) sample latent features from low-likelihood regions, but these regions lack an explicit correspondence to inter-class decision boundaries, so generated outliers may not lie where they are most informative for sharpening the ID-OOD boundary. The paper asks: can we explicitly identify ID features nearest to decision boundaries and synthesize OOD features that straddle those boundaries?
![Teaser figure](../imgs/ICML20251491/cropped_page1_idx0.webp)

## Input / Output

The pipeline consumes an ID training set (CIFAR-100 or ImageNet-100 images with class labels) and class-name text prompts fed through a CLIP text encoder to obtain token embeddings. It produces 100,000 synthetic OOD images (1000 per class) at standard resolution via Stable Diffusion v1.4, plus the intermediate OOD latent feature vectors. These images are then used to regularize an energy-based OOD detector (ResNet-34 backbone + 3-layer MLP head) that outputs a binary ID/OOD score per input image.

## Method

BOOD operates in three stages. First, it trains a ResNet-34 image encoder with a contrastive loss that aligns L2-normalized image features to CLIP class-token embeddings, creating a text-conditioned latent space compatible with Stable Diffusion's input space. Second, it identifies boundary features by applying FGSM-style gradient-ascent perturbation to every ID feature and recording the minimum number of steps k needed to flip the cosine classifier's prediction; features with the smallest k (bottom r% = 5%) are selected as boundary candidates. Third, it perturbs each selected boundary feature along the gradient-ascent direction until the prediction switches, then takes c=2 additional steps to push the feature past the boundary, yielding OOD embeddings z_ood. These embeddings replace the CLIP token in the text prompt and are decoded into pixel-space OOD images via Stable Diffusion. Finally, an energy-based OOD detector is regularized with a binary cross-entropy loss over both ID and synthetic OOD images.

## Results

On CIFAR-100 (ID), BOOD achieves an average FPR95 of 10.67% and AUROC of 97.42% across five OOD datasets (SVHN, PLACES365, LSUN, iSUN, TEXTURES), representing a 29.64% absolute reduction in FPR95 and a 7.27% absolute gain in AUROC over the previous state-of-the-art DreamOOD (40.31% / 90.15%). On IMAGENET-100, BOOD attains 35.37% FPR95 and 92.44% AUROC with 87.92% ID accuracy, improving over DreamOOD by 3.39% in FPR95 and 0.42% in AUROC. The largest per-dataset gains on CIFAR-100 are on SVHN (FPR95: 58.75→5.42) and TEXTURES (FPR95: 46.60→5.10).

## Baselines & Comparisons

BOOD outperforms all 12 compared baselines on both CIFAR-100 and IMAGENET-100. Against the scoring-function baselines (MSP, ODIN, Mahalanobis, Energy, GODIN, KNN, ViM, ReAct, DICE), BOOD achieves substantially lower FPR95 (10.67% vs. 65.72–83.53%) and higher AUROC (97.42% vs. 76.15–86.32%) on CIFAR-100, with the closest competitor being GODIN (65.72% FPR95, 86.32% AUROC). Among synthesis-based methods, BOOD dominates: it reduces FPR95 from 46.68% (NPOS) and 73.98% (VOS) to 10.67%, and surpasses DreamOOD (40.31% FPR95, 90.15% AUROC) by 29.64% in FPR95 and 7.27% in AUROC on CIFAR-100. On IMAGENET-100, the margin over DreamOOD narrows to 3.39% FPR95 and 0.42% AUROC, but BOOD still leads all baselines including ReAct (41.17% FPR95) and NPOS (44.00% FPR95). Notably, BOOD also maintains or improves ID classification accuracy (87.92% vs. 87.54% for DreamOOD on IMAGENET-100), indicating the boundary-based OOD data does not degrade in-distribution performance.

## Relation to Prior Work

BOOD extends the DreamOOD (Du et al., 2023) pipeline—text-conditioned latent space construction via CLIP alignment followed by diffusion-model decoding—by replacing DreamOOD's low-likelihood feature sampling with an explicit decision-boundary identification strategy. The boundary identification step borrows the flip-point / adversarial-perturbation idea from the adversarial-robustness literature (Chakraborty et al., 2018; Yousefzadeh & O'Leary, 2020), using the minimum number of gradient-ascent steps to flip a prediction as a proxy for distance to the decision boundary. The OOD detection head reuses VOS's (Du et al., 2022) 3-layer MLP architecture, and the overall framework departs from earlier boundary-aware OOD methods (Chen et al., 2020; Pei et al., 2022) by operating in a text-aligned latent space that can be decoded into pixel-space images via Stable Diffusion, rather than remaining purely at the feature level.

## Why It Matters / Open Questions

The core insight—that OOD training data placed specifically around inter-class decision boundaries is more informative than data sampled from arbitrary low-likelihood regions—provides a principled recipe for synthetic OOD generation that could be adapted to other generative backends. However, the large CIFAR-100 gains (29.64% FPR95 reduction) shrink to modest improvements on IMAGENET-100 (3.39% FPR95, 0.42% AUROC), suggesting the boundary-based strategy may be most effective when class boundaries are relatively well-separated. Open questions include whether the approach generalizes to domains far from the diffusion model's training distribution, whether the hyperparameters (step size α, post-boundary steps c, pruning rate r) can be set automatically, and whether the reliance on a pre-trained diffusion model limits applicability to settings where such a model is unavailable or misaligned.

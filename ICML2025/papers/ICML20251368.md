## Problem

Existing data analysis benchmarks are predominantly single-turn and do not capture the dynamic, multi-turn nature of real-world conversational data analysis, where users iteratively refine queries, provide feedback, and expect agents to handle ambiguous intents, private libraries, and diverse action types (clarification, best-guess, fast-fail, etc.). Collecting realistic human-machine conversational logs for tabular data analysis is hindered by proprietary restrictions, privacy concerns, and the high cost of expert annotation, leaving no comprehensive benchmark to evaluate LLM agents in this setting.

## Input / Output

The agent receives a natural-language user query, the full prior conversation history (user-agent turns), sampled tabular data from Kaggle (5 domains, 18 topics), and optionally a set of user-defined private library functions. Outputs are either executable Python code (pandas-based data manipulation, visualization) or a selected multiple-choice answer, with the agent also permitted to emit clarification questions or fast-fail alerts. Evaluation is execution-based: code is run against per-instance test scripts (eval.py), and a custom AccR metric additionally penalizes failure to invoke the correct subset of private library functions via AST-based recall.

## Method

The paper introduces COTA, a benchmark of 1013 multi-turn conversations (1162 intents) spanning four modes (Normal, Action, Private, Private Action) and six action types, constructed via DECISION COMPANY—a multi-agent sandbox where four GPT-4 agents (Administrator, Client, Data Scientist, AI Chatbot) simulate realistic analysis dialogues under continuous human expert supervision (6 annotators + 3 senior experts), achieving 92.78% inter-annotator agreement at ~$1.45 per instance. For the agent side, the paper proposes Adaptive Conversation Reflection (ACR): after each successful turn, the agent generates a pseudo-code logic summary m_{t-1} from the prior (user, answer) pair, reorganizes it as a self-generated one-shot example p_{t-1} = (u_{t-1}; {m_{t-1}; a_{t-1}}), and conditions the current-turn reasoning on p_{t-1} to first produce logic m_t and then the answer a_t. The agent framework combines COT prompting for code generation with CodeAct (interleaved reasoning and executable code, max 5 steps) for multiple-choice questions, augmented by an executor, a GPT-4-Turbo user simulator for clarification turns, and a DePlot chart-to-table converter for plot-based QA. ACR yields up to 35.14% relative improvement over the base model (Claude-3.5-Sonnet), with the best overall score of 40.0% on COTA.

## Results

On COTA, the best base LLM (Claude-3.5-Sonnet) achieves only 29.6% overall accuracy, while the proposed Inter-Agent method (incorporating ACR) reaches 40.0%, a relative improvement of 35.14%. The benchmark is notably challenging: even the strongest configuration scores below 50% in most conversation modes (e.g., 18.0% on Private, 14.8% on Private-Action). Among base models, Claude-3.5-Sonnet (29.6%) and Llama-3.3-70B (25.5%) outperform GPT-4-32k (21.9%) and GPT-4-Turbo (18.8%), confirming the benchmark is not overfit to any single model family.

## Baselines & Comparisons

The paper compares eight LLMs in base mode and four agent configurations (Agent, Agent-R, Multi-Agent, Inter-Agent) built on Claude-3.5-Sonnet. In base mode, Claude-3.5-Sonnet (29.6%) leads all models, outperforming Llama-3.3-70B (25.5%), GPT-4-32k (21.9%), and GPT-4-Turbo (18.8%), while Mistral-7B trails at 9.1%. The proposed Inter-Agent (ACR) method achieves 40.0% overall, surpassing Multi-Agent (36.4%), Agent-R (34.9%), and Agent (32.1%), with the largest gains in Action mode (52.8% vs. 45.2% for Multi-Agent) and Choice answers (53.3% vs. 45.5%). Notably, ACR underperforms Agent on Best_Guess actions, suggesting over-reliance on historical logic can hinder real-time assumption-making. The SOTA score of 40.0% overall underscores that conversational tabular data analysis remains far from solved, with Private mode (18.0%) and Private-Action (14.8%) being the most difficult settings.

## Relation to Prior Work

This paper extends the line of conversational data analysis benchmarks (CoSQL, SparC, ARCADE) that focused primarily on single-turn or SQL-only code generation, by introducing a unified multi-turn benchmark covering private libraries, six distinct action types, multi-modal plot understanding, and both code generation and multiple-choice answers. The data generation pipeline, DECISION COMPANY, repurposes the multi-agent sandbox paradigm (Lu et al. 2023, Park et al. 2023) originally designed for dialogue and API-call data, adapting it to the structured, execution-verified domain of tabular analysis with human expert supervision. The proposed ACR strategy draws on self-reflection and in-context learning ideas but is specifically designed to exploit successful conversation histories as pseudo one-shot examples, a mechanism not previously applied to iterative data analysis agents.

## Why It Matters / Open Questions

COTA fills a critical gap: prior conversational data analysis benchmarks did not cover private libraries, action-type diversity (clarification, best-guess, fast-fail, insight mining), or multi-modal plot reasoning, all of which are essential in real-world analysis workflows. The finding that the best agent (Inter-Agent + ACR on Claude-3.5-Sonnet) achieves only 40% overall accuracy signals a genuinely open problem, while the 35% relative gain from ACR provides a practical, low-cost technique for improving conversational agents. A notable open question is the tension ACR exposes: learning from history improves most actions but degrades Best_Guess performance, suggesting that a principled balance between historical pattern exploitation and real-time user adaptation remains unsolved. The DECISION COMPANY sandbox also opens the door to scalable, cost-effective generation of future conversational data analysis benchmarks.

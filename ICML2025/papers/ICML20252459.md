## Problem

Existing parameter isolation methods for incremental learning score and select parameters independently, ignoring dependencies and collective contributions among parameters. This independent evaluation leads to suboptimal subnetwork selection and an over-reliance on newly allocated parameters for each task, inflating model capacity. The paper asks whether capturing parameter dependencies through group-level joint selection can improve both accuracy and parameter efficiency in task-incremental learning.

## Input / Output

The method operates in the task-incremental learning (TIL) setting where the task ID is available at inference. Input consists of RGB images (32×32 for CIFAR-100 Split and Superclass, 64×64 for TinyImageNet) paired with a task identifier; output is a class label prediction from the masked subnetwork. During training the method produces a differentiable soft mask (a convex combination of candidate binary masks) optimized end-to-end via gradients; at inference a hard binary mask is obtained by argmax over the joint probability p(j)·q(M_jk|j).

## Method

PGM partitions model parameters into groups of size K, where each group's candidate set comprises all non-trivial binary masks. A two-level categorical distribution is defined: p(j) selects the number of active parameters in the group, and q(M_jk|j) selects the specific mask given j. Gumbel-Softmax reparameterization relaxes both discrete samplings into differentiable continuous approximations, enabling end-to-end gradient-based optimization of the mask selection without handcrafted importance criteria. A task-informed initialization module computes a mean-centered inner-product similarity between the current task's mask and all prior task masks, using this to adjust the logits of p and q so that previously learned knowledge directly shapes the sampling distribution. Theoretically, group-wise selection reduces the probability of incorrect mask selection by a factor of √K compared to independent per-parameter scoring (Theorem 3.2), which empirically translates into higher accuracy with substantially lower capacity (e.g., 63.5% vs. 99.1% CAP on CIFAR-100 Split).

## Results

PGM achieves the highest average accuracy (ACC) across all three benchmarks: 77.29% on CIFAR-100 Split, 62.56% on CIFAR-100 Superclass, and 70.99% on TinyImageNet, while simultaneously attaining the lowest capacity (CAP) among all compared methods (63.51%, 50.38%, and 80.26% respectively). All parameter isolation methods including PGM achieve zero forgetting (BWT = 0.0), whereas parameter regularization baselines exhibit measurable forgetting (e.g., La-MAML drops −5.39% on CIFAR-100 Split). PGM's CAP advantage is particularly pronounced on CIFAR-100 Superclass, where it uses only 50.38% capacity versus 80.93% for WSN and 162.49% for SupSup.

## Baselines & Comparisons

Against the closest parameter isolation competitor WSN, PGM wins on ACC by 0.91, 0.77, and 1.93 points on CIFAR-100 Split, Superclass, and TinyImageNet respectively, while reducing CAP by 35.6, 30.6, and 11.8 percentage points. Compared to SPG (the other learnable-mask isolation method), PGM achieves higher ACC on all three datasets (77.29 vs 77.12, 62.56 vs 62.04, 70.99 vs 70.16) and substantially lower CAP (63.51 vs 90.24 on Split; 50.38 vs 75.93 on Superclass). Against older isolation methods PackNet and SupSup, PGM gains 4.9–15.5 ACC points and reduces CAP by 33–134 percentage points, with SupSup exceeding 100% capacity on two datasets. Among parameter regularization baselines (La-MAML, GPM, FS-DGPM, RP2F), PGM achieves the highest ACC on every dataset while maintaining zero forgetting, whereas these methods all exhibit negative BWT (e.g., La-MAML: −5.39% on Split, −9.13% on TinyImageNet). The multitask upper bound remains higher in ACC (79.75 vs 77.29 on Split), but requires 100% capacity and is not applicable to the incremental setting.

## Relation to Prior Work

PGM builds directly on the parameter-isolation line of work (PackNet, WSN, SPG, SupSup), which allocates task-specific subnetworks via binary masks to prevent catastrophic forgetting. The key departure is from the independent-scoring paradigm used by all prior mask-selection methods: instead of ranking each parameter in isolation, PGM groups parameters and performs joint probabilistic selection via Gumbel-Softmax reparameterization, explicitly modeling local parameter dependencies. The theoretical framing (Theorem 3.2) connects this to a combinatorial error-reduction argument, while the task-informed initialization borrows the idea of cross-task similarity weighting from rehearsal-based methods but applies it to mask logits rather than data.

## Why It Matters / Open Questions

The practical significance lies in the large capacity reduction (e.g., 63.5% vs. 99.1% CAP on CIFAR-100 Split) achieved while simultaneously improving accuracy over WSN, making parameter-isolation IL more deployable under memory constraints. Open questions include whether the group-size hyperparameter K and the dependency structure generalize cleanly to very deep or Transformer-heavy architectures (the paper notes smaller gains on DeiT), and whether the local-dependency assumption holds for non-convolutional backbones. The extension to CIL and audio is encouraging but limited in scope, leaving the method's robustness under long task sequences and highly heterogeneous task streams untested.

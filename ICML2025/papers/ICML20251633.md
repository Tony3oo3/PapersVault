## Problem

Traditional machine unlearning definitions assume a worst-case attacker with access to the entire remaining dataset S\U, making certified exact unlearning impractical—e.g., requiring storage of the full dataset even for linear classification. This paper argues that such an attacker is unrealistic and proposes system-aware unlearning, which only requires the post-unlearning system state to be indistinguishable from retraining on a smaller representative subset S'⊆S that the system actually stores, thereby enabling more efficient unlearning algorithms.

## Input / Output

The algorithm takes a labeled dataset S of T points in R^d (with ||x||≤1, y∈{+1,−1}) and a set of deletion requests U⊆S, along with a deletion capacity K and sampling parameter κ∈[0,1]. It outputs an unlearned linear classifier sign(w^T x) and the updated core set C(S)\U, where the state-of-system is the pair (A(S,U), C(S)\U). Crucially, the system stores only the core set of queried points (O(dT^κ log T) points) rather than the full dataset, and no computation is needed for deletions outside the core set.

## Method

The core mechanism uses the BBQSAMPLER selective sampling algorithm as a core set learner: it queries labels only when x_t^T A_{t-1}^{-1} x_t > T^{-κ}, storing just the queried points as the core set C(S). The key technical insight is that BBQSAMPLER's query condition is monotonic with respect to deletion (it depends only on x, not on labels y), guaranteeing C(C(S)\U) = C(S)\U—meaning the remaining core set after deletion is exactly what retraining from scratch on C(S)\U would produce. Upon deletion, the algorithm simply removes the effect of deleted core set points via Sherman-Morrison matrix inverse updates (O(d²) per deletion), yielding exact system-aware unlearning (ε=δ=0) with sublinear memory O(dT^κ log T) and expected per-deletion time O(d³T^κ log T / T) under uniform deletion distribution. The approach generalizes to arbitrary function classes via a monotonic selective sampler (GENERALBBQSAMPLER) combined with a regression oracle on the core set.

## Results

On the Purchase Dataset (249K points, d=600), Algorithm 1 stores only 13.1% of data in memory versus 100% for SISA and Exact Retraining, while completing 80,000 deletions in 58.3s accumulated time (vs. 1,174.3s for SISA and 579.3s for Exact Retraining). On the Margin Dataset (200K points, d=100), the advantages are more pronounced: Algorithm 1 stores just 0.6% of data and processes all 80,000 deletions in 0.5s, compared to 697.1s for SISA and 27.1s for Exact Retraining. Algorithm 1 maintains comparable test accuracy to Exact Retraining throughout the deletion sequence and is more robust to the distribution shift caused by label-dependent deletions than SISA.

## Baselines & Comparisons

Against SISA (Bourtoule et al., 2021), Algorithm 1 achieves a 20× reduction in accumulated deletion time on the Purchase Dataset (58.3s vs. 1,174.3s) and a 1,394× reduction on the Margin Dataset (0.5s vs. 697.1s), while storing 13.1% and 0.6% of the data respectively versus 100% for SISA. Algorithm 1 also maintains significantly better accuracy under the long sequence of label-dependent deletions, as SISA lacks theoretical guarantees on post-unlearning accuracy and suffers from the induced distribution shift. Compared to Exact Retraining, Algorithm 1 reduces deletion time by 10× on the Purchase Dataset (58.3s vs. 579.3s) and by 54× on the Margin Dataset (0.5s vs. 27.1s), while storing a fraction of the data. The only metric where Algorithm 1 is slower is initial training time on the Purchase Dataset (186.3s vs. 30.2s for SISA), though it is faster than Exact Retraining (1,828.7s) and dramatically faster on the Margin Dataset (1.3s vs. 20.6s for SISA and 67.8s for Exact Retraining).

## Relation to Prior Work

This paper builds on the selective sampling framework of Cesa-Bianchi et al. (2009) (BBQSAMPLER) and the general-function-class extension from Gentile et al. (2022), repurposing them as core-set algorithms for unlearning. It departs fundamentally from the traditional (ε,δ)-unlearning definition of Sekhari et al. (2021) and Guo et al. (2019), which assumes a worst-case attacker with full knowledge of S\U, by introducing 'system-aware unlearning' that only requires indistinguishability from training on a stored subset S′. This directly addresses the lower bound of Cherapanamjeri et al. (2025) showing that exact unlearning for linear classification under the traditional definition requires storing the entire dataset, by arguing that a more realistic attacker model (one who can only access what the system stores) makes sublinear-memory exact unlearning possible.

## Why It Matters / Open Questions

The paper provides the first exact unlearning algorithm for linear classification with sublinear memory, breaking a previously established lower bound by redefining the threat model. The core insight—that storing less information inherently provides stronger privacy against a system-aware attacker—creates a principled incentive to design learning algorithms that rely on fewer samples, connecting sample compression theory to unlearning efficiency. Open questions include whether approximate system-aware unlearning (ε,δ ≠ 0) yields further efficiency gains, whether the monotonic query condition requirement (which limits the BBQSAMPLER to y-independent queries) can be relaxed, and how these ideas extend to deep learning settings where core-set structure is less clear. The empirical evaluation, while confirming theory, is limited to linear classifiers on two datasets and does not address the primary practical setting of unlearning in large neural networks.

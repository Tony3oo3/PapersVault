## Problem

Existing gradient-estimation-based black-box explainers like GEEX are restricted to continuous feature spaces and cannot handle discrete inputs such as text, because their path-integral formulation is undefined for non-differentiable features. Meanwhile, sampling-based Shapley Value estimators waste information by requiring paired queries to compute marginal contributions. The paper asks whether a single black-box attribution framework can be made universally applicable across input types while retaining the theoretical guarantees of Shapley Values.

## Input / Output

The method takes an explicand (a text sequence or an RGB image), a corresponding baseline (empty token for text, blurred image for vision), and a black-box model accessible only through input-output queries. It produces one attribution score per feature (per token or per pixel) that collectively sums to f(x) − f(baseline). For text, feature absence is naturally represented by token removal; for images, absence is represented by replacing pixels with the baseline value. The query budget is 500 for text and 5000 for image settings, with each query constructed by sampling a binary mask that selects which features take the explicand value versus the baseline value.

## Method

GEFA introduces proxy variables α ∈ [0,1]^p where each component α_i parameterizes the probability of feature i being present, enabling gradient estimation in a continuous space regardless of the original feature type. Queries are constructed by sampling a binary mask ε ~ Bernoulli(α) and combining explicand and baseline values via z = ε∘x ⊕ ε̄∘x̂. The score-function gradient estimator (log-likelihood trick) yields a proxy gradient η_α, which is integrated along the straightline path α(γ) = γ·1_p to produce attributions. The paper proves GEFA is an unbiased estimator of Shapley Values, equivalent to Integrated Gradients along edge paths, and satisfies Completeness, Sensitivity, Insensitivity, Linearity, and Symmetry. A control variate h(‖ε‖₁) based on the count of present features reduces estimation variance, and practical enhancements include mask smoothing (low-pass filtering for spatial inputs) and antithetic sampling to further reduce Monte Carlo noise.

## Results

On text classification, GEFA (with control variate) achieves the highest nAOPC across all three settings: 0.7366 on Amazon/BERT, 0.5706 on SST-2/Llama3.2-3B, and 0.4740 on QNLI/Llama3.2-3B, outperforming the best white-box method IG (0.6677, 0.3664, 0.2985 respectively). The control variate consistently adds 0.02–0.03 nAOPC over the base GEFA variant. On image classification (ImageNet with InceptionV3 and ViT), GEFA also outperforms GEEX and approaches IG-level performance in high-dimensional settings, with the control variate yielding larger gains than in text due to stronger covariance between model outputs and feature count.

## Baselines & Comparisons

GEFA (with control variate) outperforms all five baselines across every text classification setting. Against IG (Sundararajan et al., 2017), GEFA leads by 0.07 nAOPC on Amazon/BERT (0.7366 vs. 0.6677) and by a wider margin on Llama3.2 settings (0.5706 vs. 0.3664 on SST-2; 0.4740 vs. 0.2985 on QNLI), which the authors attribute to IG's compromised baseline definition in embedding space. Against KSHAP (Lundberg & Lee, 2017), GEFA wins by 0.135 on Amazon, 0.032 on SST-2, and 0.063 on QNLI. Against PSHAP (Chen et al., 2023), GEFA leads by 0.077, 0.058, and 0.046 respectively. VG (Simonyan et al., 2014) performs at random-removal level across all settings, confirming that raw gradients are inadequate as explanations. GEEX (Cai & Wunder, 2024) is excluded from text experiments due to its incompatibility with discrete features; on ImageNet, GEFA surpasses GEEX in class-discriminative explanation quality, as GEEX's Gaussian noise perturbations produce less informative gradient estimates than GEFA's binarized feature sampling.

## Relation to Prior Work

GEFA directly extends GEEX (Cai & Wunder, 2024), a black-box gradient-estimation explainer limited to continuous feature spaces, by introducing proxy variables that parameterize feature presence/absence, thereby enabling the same path-integral machinery to operate over discrete inputs like text. Conceptually, GEFA occupies a middle ground between Integrated Gradients (Sundararajan et al., 2017) and sampling-based Shapley Value estimators (KernelSHAP, PartitionSHAP): it is a path method built on score-function gradient estimation in a proxy space, yet the paper proves it yields exactly unbiased Shapley Value estimates and is equivalent to IG along edge paths. The variance-reduction component (a control variate on the number of present features) draws on standard techniques from the stochastic gradient estimation literature (Mohamed et al., 2020).

## Why It Matters / Open Questions

By unifying gradient-estimation-based explanation under a single proxy-space formulation, GEFA removes the continuous/discrete input barrier that previously forced practitioners to choose between gradient-based and sampling-based explainers, and it does so with a clean theoretical guarantee (unbiased Shapley Values) that avoids the information waste inherent in marginal-contribution sampling. The paper also contributes a useful methodological correction: it identifies residual information from negatively-attributed features as the root cause of ROAR's (Hooker et al., 2019) apparently negative conclusions about attribution methods, and proposes a 'keep and retrain' alternative that aligns with deletion-based evaluation. Open questions include extending the framework to explain full auto-regressive LLM generation (where outcomes are delayed and sequences are interdependent), and whether the proxy-space formulation can be adapted for multi-output or structured prediction settings.

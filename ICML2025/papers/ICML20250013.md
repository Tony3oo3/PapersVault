## Problem

Autoregressive LLM inference on long sequences (100K–1M tokens) is bottlenecked by the quadratic cost of self-attention, and existing distributed approaches like Ring Attention still compute full global attention across all tokens. Sparse alternatives such as StreamingLLM or MInference either require model fine-tuning, introduce additional trained components, or degrade sharply on retrieval-heavy tasks. The paper asks whether a block-sparse, distributed attention scheme can match global-attention accuracy out-of-the-box on pretrained LLMs while scaling linearly with context length across multiple hosts.

## Input / Output

The method consumes a long context (up to 1M tokens) followed by a short query, partitioning the context into contiguous blocks of configurable size (typically one-quarter of the total sequence length, capped at 32K for sequences beyond 128K). Each block is augmented with a copy of the first block as an anchor before local encoding. Output is standard autoregressive token generation: a single designated 'query host' produces one token at a time, updating only its own KV cache, while all other hosts contribute local attention statistics without modifying their caches.

## Method

Star Attention is a two-phase block-sparse approximation. In Phase 1 (Context Encoding), the context is split into n blocks and distributed across hosts; each block (except the first) is prefixed with the first block as an anchor, so every host computes self-attention over 2b tokens locally with no inter-host communication, reducing attention complexity from O(n²) to O(n). The anchor block shifts attention sinks to the first block's tokens, and its KV entries are discarded, yielding a local attention distribution that closely approximates global attention. In Phase 2 (Query Encoding and Token Generation), the query is broadcast to all hosts, each computing a local attention output A_h and a local log-sum-exp scalar s_h over its cached KVs. A designated query host then aggregates these via an online-softmax (log-sum-exp) reduction, communicating only one vector and one scalar per host per token, to produce the globally normalized attention and generate the next token. The entire scheme is plug-and-play with pretrained global-attention Transformers and composes with Flash Attention for further speedup.

## Results

On RULER (Llama-3.1-8B-Instruct), Star Attention achieves 84.44% average accuracy across 16K–128K sequence lengths, within 0.77% of full global attention (85.21%), while delivering 1.1×–2.7× speedup over Ring Attention. On the 70B model at 64K tokens, the speedup reaches 4.7× with only 1.44% accuracy loss. At 1M tokens (Llama3-8B-Instruct-1048K, block size fixed at 32K), Star Attention achieves up to 16.9× speedup with a 5.32% accuracy drop. On InfiniteBench, Star Attention attains 46.51% average accuracy versus 48.06% for full attention, substantially outperforming StreamingLLM (14.72%) and MInference (34.07%).

## Baselines & Comparisons

Against Ring Attention (the primary distributed baseline), Star Attention wins decisively on inference speed—achieving 1.1×–2.7× speedup on the 8B model (16K–128K) and up to 16.9× at 1M tokens—while incurring only 0–3% accuracy degradation in most settings (up to 5.32% at 1M). Against StreamingLLM, Star Attention dominates on accuracy: 84.44% vs. 45.07% average on RULER and 46.51% vs. 14.72% on InfiniteBench, with the gap widening sharply at longer sequences (e.g., 74.41% vs. 30.77% at 128K on RULER). Against MInference, Star Attention also leads on accuracy (84.44% vs. 80.71% on RULER; 46.51% vs. 34.07% on InfiniteBench), and the advantage grows with sequence length (74.41% vs. 58.17% at 128K on RULER). Notably, MInference slightly exceeds full attention at 16K (93.27% vs. 92.22%) but degrades rapidly beyond 64K, whereas Star Attention remains within ~2% of full attention across all tested lengths.

## Relation to Prior Work

Star Attention builds on the distributed block-processing paradigm of Ring Attention (Liu et al., 2024a) but eliminates the ring communication during context encoding, replacing it with a two-phase design: local blockwise attention for the context and global attention only for the query/decoding phase. The distributed softmax aggregation in Phase 2 relies on the online log-sum-exp trick from Milakov & Gimelshein (2018) for numerical stability. Conceptually, the method sits between sparse attention approaches (StreamingLLM, MInference) that sacrifice global context and full distributed attention (Ring Attention) that computes dense attention everywhere, by exploiting the observation that long-context tasks typically have a long context followed by a short query where only the query needs global access. The anchor block mechanism, which prefixes each context block with the first block to redirect attention sinks, is a novel departure from prior blockwise methods that simply process blocks independently.

## Why It Matters / Open Questions

Star Attention offers a practical, drop-in solution for long-context inference that scales linearly with the number of hosts and requires no model fine-tuning, making it immediately applicable to existing pretrained LLMs. The up-to-11× speedup (16.9× at 1M tokens) with 97–100% accuracy retention is significant for production systems handling repository-level code or multi-document tasks. Open questions remain: why the anchor block size must match the context block size for optimal performance, how to handle tasks requiring inter-block communication (Multi-Hop Tracing degrades), and whether the approach generalizes to architectures beyond Llama. The paper also notes that smaller block sizes on longer sequences lead to accuracy degradation, suggesting the method has a practical lower bound on block size relative to sequence length.

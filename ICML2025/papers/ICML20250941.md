## Problem

Existing generative recommendation models tokenize each action independently, assigning identical tokens to the same item regardless of its surrounding context. This context-independence means the same action (e.g., purchasing a particular item) receives the same token pattern in every sequence, even though its meaning may differ depending on neighboring actions. No prior method has introduced context-aware tokenization for action sequences in the generative recommendation setting.
![Teaser figure](../imgs/ICML20250941/cropped_page0_idx0.webp)

## Input / Output

The method takes a chronologically ordered sequence of unordered item feature sets (e.g., category, brand, price codes) as input and autoregressively generates a token sequence that is parsed into a recommended next item. Each action is represented by m features with no inherent ordering within the set, but temporal ordering is preserved across actions. At inference, set permutation regularization produces q=5 tokenized variants of the input sequence, each passed through beam search (beam size 50), and the resulting ranking lists are combined by score averaging.

## Method

ActionPiece constructs a vocabulary via a BPE-like bottom-up merge process adapted to sequences of unordered feature sets. The key distinction is a weighted co-occurrence counting scheme: token pairs within the same set receive weight 2/|A_i|, while pairs from adjacent sets receive weight 1/(|A_i|·|A_{i+1}|), reflecting the probability of adjacency under random flattening. Cross-action merges are handled by inserting intermediate nodes between action nodes in a doubly-linked list representation. For segmentation, set permutation regularization (SPR) randomly permutes features within each set before applying greedy BPE-style merging, yielding multiple semantically equivalent token sequences per action. These variants serve as natural data augmentation during training and enable inference-time ensembling. The tokenized sequences are fed into a 4-layer T5-style encoder-decoder Transformer trained with next-token prediction.

## Results

ActionPiece achieves the best performance across all three Amazon Reviews datasets (Sports, Beauty, CDs) on both Recall@K and NDCG@K (K∈{5,10}). On Sports, it reaches NDCG@10 of 0.0264, surpassing the strongest baseline SPM-SID (0.0234) by 12.82%. On Beauty and CDs, the improvements over SPM-SID are 6.00% and 6.37% on NDCG@10, respectively. The largest gains appear on Sports, where ActionPiece improves NDCG@5 by 11.71% and Recall@10 by 12.11% over the best baseline.

## Baselines & Comparisons

ActionPiece outperforms all 10 baselines across every dataset and metric. The strongest baseline is SPM-SID (SentencePiece-based semantic ID tokenization), which ActionPiece beats by 4.59%–12.86% depending on dataset and metric, with the largest margins on Sports. Among generative recommendation baselines, TIGER (RQ-VAE semantic IDs) and HSTU (raw feature tokens) are competitive but consistently trail SPM-SID and ActionPiece; on CDs, P5-CID (hierarchical clustering) actually outperforms TIGER on Recall@10 (0.0785 vs. 0.0748), yet both remain well below ActionPiece (0.0830). ID-based methods (BERT4Rec, SASRec) and feature-enhanced methods (FDSA, S³-Rec, VQ-Rec) are substantially weaker, confirming that generative tokenization with context-aware merging provides the largest gains. Notably, LMIndexer (text-based tokenization) does not converge on the larger CDs dataset under comparable compute, highlighting scalability limitations of text-level tokenization for generative recommendation.

## Relation to Prior Work

This paper directly extends the BPE (Byte-Pair Encoding) algorithmic framework from NLP subword tokenization to the domain of generative recommendation, where the fundamental unit shifts from bytes to unordered item feature sets. It departs from all existing GR tokenization methods (TIGER's RQ-VAE, P5-CID's hierarchical clustering, HSTU's raw features, SPM-SID's SentencePiece) by being the first to make tokenization context-aware, so that the same action receives different tokens depending on its surrounding sequence. The set permutation regularization draws a parallel to subword regularization (Kudo, 2018) in NLP, and the intermediate-node mechanism for cross-action merges is a novel structural addition not present in standard BPE.

## Why It Matters / Open Questions

The paper establishes that context-aware tokenization is a meaningful axis of improvement for generative recommendation, closing an analogy gap with NLP where subword tokenization has long been standard. The unordered-set formulation is more natural for recommender systems than ordered semantic IDs, and the SPR mechanism provides a free data augmentation and inference-time ensemble that improves token utilization from ~57% to ~95%. Open questions include whether the approach scales to industrial-scale item pools (experiments use at most ~64K items), how it interacts with LLM-based recommendation pipelines, and whether the vocabulary construction cost is acceptable for frequently updated catalogs. The authors also note potential extensions to audio modeling, sequential decision-making, and time series forecasting.

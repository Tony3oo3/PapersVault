## Problem

Existing hallucination mitigation methods for MLLMs improve caption precision at the cost of recall, producing shorter, less comprehensive descriptions. The paper identifies the root cause: as generated text lengthens, visual attention both weakens in magnitude and becomes increasingly dominated by noisy, context-irrelevant tokens, while naively amplifying all visual attention further reduces attention diversity and recall.
![Teaser figure](../imgs/ICML20251123/cropped_page0_idx0.webp)

## Input / Output

The method operates during autoregressive decoding of 7B-parameter MLLMs (LLaVA-1.5, LLaVA-Next, Qwen2-VL), taking an RGB image and a text prompt as input and producing a detailed image caption of up to 512 tokens. It is entirely training-free, requiring only head-averaged attention scores from a single mid-to-late layer (e.g., layer 20 for LLaVA-1.5) and the existing KV-cache, with negligible memory overhead (~40 KB for LLaVA-1.5). The only per-model tuning is the selection threshold τ, EMA smoothing factor β, and scaling factor α.

## Method

SPARC consists of two mechanisms applied at each decoding step. First, a Relative Activation Score (RAS) identifies contextually relevant visual tokens by comparing each token's current attention weight against an Exponential Moving Average (EMA) of its historical attention, selecting tokens whose relative increase exceeds a threshold τ—this filters out static high-attention noise and sink tokens. Second, a Selection Count accumulates how many times each token has been selected across prior steps, and the value vectors of currently selected tokens are amplified by α^(selection count), progressively reinforcing consistently relevant tokens to counteract the natural decline in visual attention over longer contexts. This recalibration is implemented by directly scaling cached value vectors, avoiding any additional forward passes. The key distinction from prior work (e.g., PAI) is that SPARC selectively amplifies only dynamically identified relevant tokens rather than all visual tokens, preserving attention diversity and recall while still improving precision.

## Results

On the CHAIR benchmark (MS-COCO 2014), SPARC achieves the highest F1 score of 83.67, improving both precision (87.72 vs. 84.70 baseline) and recall (79.98 vs. 79.46 baseline) simultaneously. On CLAIR, SPARC scores 61.49 on IIW-400 and 62.70 on DOCCI, outperforming all baselines by 1.8–10.5 points. The method adds only 2.8% computational overhead (31.21 ms/token vs. 30.37 ms/token baseline), compared to 90–961% overhead for competing methods.

## Baselines & Comparisons

SPARC is the only method that improves both precision and recall over the LLaVA-1.5 baseline, gaining +3.02%p precision and +0.52%p recall while achieving the best F1 (83.67). PAI achieves the highest precision (90.64) but at the cost of the lowest recall (72.44), yielding a lower F1 (80.52) than SPARC. VOLCANO improves precision to 87.64 but slightly reduces recall (77.82), resulting in a lower F1 (82.39). OPERA and VCD fail to improve either precision or recall over the baseline, with VCD degrading both metrics. On CLAIR, SPARC outperforms all baselines on both IIW-400 (+5.13 over baseline) and DOCCI (+3.44 over baseline), while OPERA and VCD actually degrade caption quality below the baseline.

## Relation to Prior Work

This paper builds directly on PAI (Liu et al., ECCV 2025), which proposed naively amplifying all visual attention weights during MLLM decoding to reduce hallucination. The key departure is an empirical demonstration that this uniform amplification reduces visual attention diversity (measured via Wasserstein distance between attention patterns), thereby degrading recall. SPARC replaces the uniform boost with a selective mechanism (Relative Activation Score using EMA to identify contextually shifting tokens) and a progressive one (cumulative Selection Count that exponentially reinforces consistently relevant tokens via KV-cache value scaling), positioning itself between decoding-based methods (OPERA, VCD) and self-refinement approaches (VOLCANO) by operating purely at the attention level with minimal overhead.

## Why It Matters / Open Questions

The paper reveals a previously underappreciated trade-off: most existing hallucination mitigation methods improve precision while silently degrading recall, producing shorter, less comprehensive captions. SPARC's training-free design with only 2.8% inference overhead (versus 90–960% for competitors) makes it practically deployable, particularly for accessibility applications where both accuracy and completeness matter. Limitations include per-model hyperparameter tuning (threshold τ varies from 1.5 to 4.0 across architectures), modest gains on stronger models like Qwen2-VL (+1.36 CLAIR), and evaluation restricted to 7B-parameter models. Open questions include whether the selective-progressive principle generalizes to video captioning, longer-context tasks, or larger model scales where attention dynamics may differ.

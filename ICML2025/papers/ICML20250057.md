## Problem

Standard diverse nearest neighbor search uses a two-stage pipeline: retrieve a large candidate set (r >> k) with a vanilla ANN index, then post-process to enforce diversity. This is fundamentally inefficient because r can be Ω(n) in the worst case, and in practice the retrieval stage dominates latency. The paper asks whether one can bypass this pipeline entirely and directly report k diverse points in time depending on k rather than r, using graph-based data structures.

## Input / Output

The method takes a colored point set P of n vectors (each assigned a color such as seller ID or brand), a query point q, and diversity parameters: output size k, per-color cap k′ (allowing up to k′ points of the same color), and optionally a diversity threshold C under a general metric ρ. It produces a set S of k points approximately closest to q satisfying the diversity constraint (at most k′ per color, or minimum pairwise ρ-distance ≥ C). The data structure is a directed graph over P with bounded out-degree, and the query procedure performs a bounded number of greedy steps over this graph. The theoretical analysis assumes bounded doubling dimension d and aspect ratio Δ, yielding query time polynomial in k, log n, and log Δ.

## Method

The core contribution is a diversity-aware modification to the DiskANN graph-based ANN framework, applied at both index construction and search time. During graph construction, the pruning rule is augmented: an edge (p,v) is only removed if p is already connected to k/k′ points of distinct colors (or ρ-diverse points selected via Gonzalez' greedy k-center algorithm) that geometrically block v, ensuring the graph retains sufficient diverse connectivity for greedy search to converge. During search, the algorithm maintains a current solution ALG of k diverse points and iteratively replaces the furthest point with a neighbor that preserves the diversity constraint, achieving an approximation factor of (α+1)/(α−1)+ε in O(k log_α(Δ/ε)) steps. The heuristic implementation modifies DiskANN's fast-preprocessing pipeline with a diverse prune subroutine that requires m different colors to block an edge, and a diverse priority queue that enforces the k′ per-color cap during best-first traversal. Experiments on real-world seller and brand datasets show 5× latency reduction over the standard retrieve-then-rerank baseline at matched recall.

## Results

On the real-world Seller Dataset (20M vectors, k=100, k'=1), achieving 95% recall@100 requires ~8ms latency with the standard DiskANN + post-processing baseline, ~4.5ms with diverse search alone, and ~1.5ms with the full diverse build + diverse search (a >5× speedup). On the ArXiv semi-synthetic dataset (2M vectors, k'=1), at ~90% recall the full method achieves ~25ms latency versus ~90ms for the baseline. The theoretical guarantee is O(k log_α(Δ/ε)) search steps, each taking Õ(k(8α)^d log Δ) time, with approximation factor (α+1)/(α−1)+ε, matching the best known bounds for non-diverse graph-based ANN.

## Baselines & Comparisons

The sole baseline is Standard DiskANN Build + Post-Processing: a vanilla DiskANN index retrieves r ≫ k candidates, then a greedy pass selects the best k diverse points. The paper's method (Diverse DiskANN Build + Diverse Search) consistently outperforms this baseline across all five datasets and both k'=1 and k'=10 settings. On the headline Seller Dataset, the full method achieves 95% recall@100 at ~1.5ms versus ~8ms for the baseline (>5× faster). Interestingly, on the ArXiv dataset, using diverse search on a standard (non-diverse) graph actually performs *worse* than the baseline (~135ms vs ~90ms at 90% recall), because the standard graph lacks sufficient cross-color edges for the diverse search to converge; only the diverse-aware graph construction resolves this, dropping latency to ~25ms. This demonstrates that both the index construction and the search procedure must be diversity-aware for the full benefit to materialize.

## Relation to Prior Work

This paper extends the DiskANN graph-based ANN framework (Jayaram Subramanya et al., 2019) and its worst-case theoretical analysis (Indyk & Xu, 2023) by incorporating diversity constraints directly into both graph construction and search. It departs from the dominant two-stage reranking paradigm introduced by Carbonell & Goldstein (1998), which retrieves a large candidate set and then post-processes for diversity, by showing that diversity can be encoded into the graph topology itself. The theoretical analysis follows the doubling-dimension and aspect-ratio framework of Indyk & Xu (2023), while the diversity-aware pruning leverages the Gonzalez k-center greedy algorithm to select representative neighbors. Prior work on diverse NN (Abbar et al., 2013) used LSH-based methods limited to Hamming/Jaccard distances and did not carry over to graph-based approaches.

## Why It Matters / Open Questions

The paper eliminates a fundamental efficiency bottleneck in diverse retrieval: the two-stage approach requires retrieving r >> k candidates, which can be Ω(n) in the worst case, while the proposed method achieves comparable recall at 5× lower latency on real-world data. The key insight—that modifying graph construction to preserve diverse edges is broadly applicable—suggests the technique can be integrated into any greedy-search graph-based ANN (HNSW, NGT, etc.), not just DiskANN. Open questions include whether the theoretical guarantees extend to higher intrinsic dimensions, how the approach performs under adversarial or highly dynamic color distributions, and whether the production deployment at scale will reveal additional practical challenges. The paper also leaves the generic-metric ρ case (beyond binary colors) primarily theoretical, with no empirical validation of the full (k′, C)-diverse formulation.

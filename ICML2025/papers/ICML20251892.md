## Problem

Minimizing the difference of two submodular (DS) functions was previously studied only for set functions (binary domains), despite DS structure being extremely general—any function on a discrete domain and any smooth function on a continuous domain is DS. This paper extends DS minimization to general product domains (integer lattices and continuous boxes), where the problem is inapproximable and even finding a local minimum is PLS-complete, yet no efficient algorithm with theoretical guarantees existed.

## Input / Output

The method takes a DS decomposition F = G − H where G and H are normalized submodular functions on a product domain X = ∏X_i (each X_i a finite set or closed interval), an initial feasible point x⁰, and tolerance parameters ε, ε_x. It outputs a feasible point x^T ∈ X that is an (ε + ε_x)-local minimum of F, meaning no single-coordinate ±1 move (on the lattice) or ±1/(k−1) move (after discretization) decreases F by more than ε + ε_x. For continuous domains, the input is first discretized via a Lipschitz-based grid, and the output is mapped back to the continuous domain.

## Method

The key insight is that minimizing a DS function over an integer lattice [0:k−1]^n is equivalent to minimizing its continuous extension f↓ over the row-nonincreasing matrix polytope [0,1]↓^{n×(k−1)}, which is a DC program since f↓ = g↓ − h↓ with g↓, h↓ convex. The paper proposes DCA-LS, a novel DC Algorithm variant that at each iteration performs a local search over the 2n neighbors of the current lattice point to select a single subgradient Y^t of h↓, then solves a convex subproblem (equivalent to submodular minimization) to obtain the next iterate. This local-search-based subgradient selection ensures the algorithm converges directly to an approximate local minimum of F without the restarts needed by prior DCA variants. The per-iteration subproblem is solved via Pairwise Frank-Wolfe in Õ(n(kL/ε)²·EO_F) time, yielding an overall O(1/T) convergence rate to an (ε+ε_x)-local minimum.

## Results

On integer least squares (n=100, SNR=20 dB), DCA-LS outperforms all baselines on recovery probability, bit error rate, and relative objective gap, matching the Gurobi-optimal solution from m/n=1.2 onward. On integer compressed sensing (n=256, s=26, SNR=8 dB), DCA-LS and DCA-LS-LASSO significantly outperform OMP and LASSO in recovery probability across all m/n ratios. DCA-LS surpasses LASSO in estimation and support error for m/n > 0.6, while DCA-LS-LASSO dominates all baselines on all metrics except a narrow m/n ≈ (0.25, 0.4) range where it slightly lags LASSO.

## Baselines & Comparisons

For integer least squares, DCA-LS clearly beats ADMM (Takapoui et al., 2020) and the relax-and-round heuristic on all three metrics (recovery probability, BER, objective gap) across all m/n ratios. OBQ (Frantar & Alistarh, 2022) is competitive with DCA-LS only at m/n ≥ 1.5, while DCA-LS matches the Gurobi optimum from m/n = 1.2. For integer compressed sensing, DCA-LS outperforms OMP (Pati et al., 1993) on all metrics (recovery probability, support error, estimation error) at every m/n ratio tested. Against LASSO with box constraint solved by FISTA (Tibshirani, 1996), DCA-LS wins on recovery probability throughout but trails on estimation and support error for m/n < 0.6 before overtaking it; DCA-LS-LASSO (initialized with the LASSO solution) dominates LASSO on all metrics except a narrow m/n ≈ (0.25, 0.4) window where the true signal is not the global optimum.

## Relation to Prior Work

This paper extends the DS set function minimization framework of El Halabi et al. (2023) and Narasimhan & Bilmes (2005) from the binary domain {0,1}^n to general discrete and continuous product domains. The key technical bridge is Bach's (2019) continuous extension of submodular functions, which allows reformulating the DS problem as a DC program on a convex set, to which a novel DCA variant with local search (DCA-LS) is applied. The paper also clarifies the relationship to Maehara & Murota's (2015) discrete DC programming, showing that integer-valued DS functions and discrete DC functions are essentially equivalent, while natural DS decompositions (e.g., for sparse learning with ℓ_q regularizers) do not admit discrete DC structure.

## Why It Matters / Open Questions

The representability results (any function on discrete domains, any smooth function on continuous domains is DS) establish that the framework is maximally general, making it a unifying lens for a wide class of non-convex optimization problems. However, the practical utility hinges on finding good DS decompositions, which the paper acknowledges can be expensive or ill-defined; the 'best' decomposition remains an open question. The empirical gains over ADMM, OBQ, OMP, and LASSO on integer least squares and compressed sensing are meaningful but the problem settings are relatively niche. A key open direction is whether the DCA-LS framework can be accelerated or adapted to handle the decomposition search jointly with optimization.

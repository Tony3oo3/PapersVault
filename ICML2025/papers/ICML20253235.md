## Problem

LLMs struggle with complex reasoning because temperature-based diversity flattens token distributions indiscriminately, introducing noise rather than meaningful exploration, while heuristic search methods (CoT, Tree of Thoughts, RAP) rely on surface-level prompt variations without directly adjusting the model's internal representations. This paper addresses the gap by proposing a method that directly optimizes the embedding of the first generated token to control the direction of reasoning, combining controlled exploration with verifier-guided Bayesian search in the embedding space.
![Teaser figure](../imgs/ICML20253235/cropped_page1_idx0.webp)

## Input / Output

The method takes a natural language question prompt (with optional 1–8 few-shot exemplars) and produces a generated reasoning answer capped at 300 tokens. The key mechanism is that the first token's embedding is perturbed and mapped to a special token appended to the vocabulary, from which greedy decoding deterministically generates the entire answer sequence, ensuring a one-to-one mapping between perturbation and output. The same LLM serves as both generator and verifier, with the verifier using a Multi-Generate strategy to evaluate batches of candidate answers collectively.

## Method

Soft Reasoning operates in two stages: (1) embedding perturbation, where Gaussian noise (σ·ε, ε~N(0,I)) is injected into the first token's embedding to create candidate embeddings, each mapped to a special token that deterministically generates a full answer via greedy decoding; and (2) Bayesian optimization using Expected Improvement (EI) as the acquisition function to iteratively select the most promising perturbation direction. The objective function combines a binary verifier score (whether the candidate matches the verifier's regenerated answer) and a coherence score (sum of log token probabilities), with the verifier being the same model as the generator. To handle the high-dimensional embedding space (768–8192+ dimensions), random projection reduces the search to a 50-dimensional subspace, and an adaptive EI formulation with information-gain-based scaling accounts for verifier noise. The approach requires no access to model parameters, no additional training, and typically converges within 4 iterations, achieving superior accuracy while using only ~6% of RAP's input tokens and ~14% of its inference time.

## Results

On LLaMA-3.1-8B-Instruct (zero-shot), Soft Reasoning achieves 79.4% on GSM8K, 28.2% on GSM-Hard, 88.2% on SVAMP, and 67.2% on StrategyQA. In the few-shot (8-shot) setting, it reaches 84.3% (GSM8K), 35.7% (GSM-Hard), 90.2% (SVAMP), and 75.6% (StrategyQA), outperforming RAP (80.7/32.7/87.9/73.4) on all four benchmarks. On Qwen2-70B-Instruct, Soft Reasoning attains 94.3% on GSM8K (zero-shot) and 11.1% on AIME-2024 (few-shot), surpassing all baselines. In terms of efficiency, Soft Reasoning uses only 6.19% of RAP's input tokens and 14.3% of its inference time while achieving higher accuracy.

## Baselines & Comparisons

Soft Reasoning outperforms RAP on all four benchmarks in the few-shot setting (e.g., 84.3% vs. 80.7% on GSM8K, 35.7% vs. 32.7% on GSM-Hard) while using only 6.19% of RAP's input tokens and 14.3% of its inference time (23.2 min vs. 184.5 min on GSM8K). Against Self-Consistency decoding, Soft Reasoning achieves comparable or better accuracy without requiring per-model/per-dataset temperature tuning; SC must be re-tuned (τ ∈ {0.4, 0.6, 0.8}) for each configuration. Compared to FIRE (which sets first-token temperature to 30) and CoT-Decoding (top-k first-token sampling), Soft Reasoning achieves higher coverage of correct answers (91.8% vs. 84.5% and 85.3% on GSM8K zero-shot) and higher final accuracy. Against Trainable Prefix Scorers (Mudgal et al., 2024), Soft Reasoning wins on all four benchmarks in both zero-shot and few-shot settings without any additional training. Constrained Fine-tuning (Qi et al., 2025a) achieves the best StrategyQA score (81.3%) but requires LoRA fine-tuning and underperforms Soft Reasoning on GSM8K, GSM-Hard, and SVAMP. Ablations confirm that both the verifier score and coherence term are necessary: removing either degrades accuracy across all tasks.

## Relation to Prior Work

This paper repurposes Bayesian optimisation (Frazier, 2018) and its high-dimensional variant via random projections (Wang et al., 2016; Nayebi et al., 2019) as a search mechanism over LLM embedding space, rather than over hyperparameters or prompt templates. It departs from the dominant paradigm of diversity-through-temperature (Self-Consistency, FIRE, CoT-Decoding) and heuristic tree search (RAP/MCTS, Tree of Thoughts) by directly perturbing the first-token embedding and using a verifier-guided acquisition function (adaptive EI per Vakili et al., 2021; Tran-The et al., 2022) to navigate the solution space. The key conceptual shift is treating the LLM itself as a black-box objective function whose output quality can be optimised in continuous embedding space, eliminating the need for language-level planning or prompt engineering.

## Why It Matters / Open Questions

The approach offers a training-free, model-agnostic alternative to expensive search-based reasoning methods, achieving comparable or better accuracy at roughly 14% of RAP's inference time and 6% of its input token budget. However, it remains constrained to optimising only the first token (multi-token extensions degrade performance), depends on a same-model verifier whose reliability is imperfect, and the interpretability of how embedding perturbations map to reasoning pathways is still limited. Open questions include whether the framework generalises to longer-horizon or multi-step reasoning tasks, how to improve verifier robustness without external supervision, and whether the effective low-dimensionality assumption (d=50) holds across architectures and task families.

## Problem

Distributed learning over networks of agents faces two intertwined bottlenecks: communication overhead from periodic or random agent participation, and convergence degradation under arbitrarily non-i.i.d. local data distributions. Prior ADMM-based federated methods (FedADMM, FedPD) handle non-i.i.d. data but still rely on random or full agent participation, while event-triggered approaches lack convergence guarantees and do not analyze robustness to communication failures. This paper is the first to provide a full convergence analysis of distributed learning with event-triggered communication that simultaneously addresses non-i.i.d. data, packet drops, and explicit communication-accuracy trade-offs.

## Input / Output

Each agent holds a local smooth objective f^i (e.g., a neural network loss on its local data shard) and communicates only differential updates (differences from the last transmitted value) when the deviation exceeds a user-set threshold Δ. The server (agent N+1) additionally handles a potentially nonsmooth regularizer g (e.g., L1 for LASSO). The output is a consensus model z* achieving accuracy bounded by O(κΔ), where κ is the condition number, so the threshold Δ directly controls the communication-accuracy trade-off. A periodic reset every T steps bounds accumulated errors from packet drops, making T a second tunable parameter.

## Method

The algorithm is an over-relaxed ADMM (with relaxation parameter α) where each agent updates its local primal x^i and dual u^i, then triggers a communication event only if the composite variable d^i = αx^i + u^i deviates by more than Δ^d from its last transmitted value; the server similarly triggers on the consensus variable z. Communication failures are modeled as packet drops and handled algorithmically via a rare periodic reset that synchronizes all estimates. The convergence analysis casts the algorithm as a discrete-time dynamical system with bounded external disturbances from event-triggering, then applies a Lyapunov function (distinct from prior ADMM analyses due to these disturbances) to derive accelerated linear rates of O((1−1/(4√κ))^{2k}) for strongly convex problems and O(1/k) sublinear rates for nonconvex ones. The network topology enters through the condition number κ = Lσ̄²(A)/(mσ²(A)), linking graph structure directly to convergence speed.

## Results

On CIFAR-10, Alg.1-Randomized achieves 78% test accuracy with 18,376 communication events, compared to 27,000 for FedADMM (a 32% reduction) and 12,000 for SCAFFOLD/FedAvg which only reach 70% accuracy. On MNIST, Alg.1-Randomized requires 1,723 communication events to reach 90% accuracy, versus >2,000 for FedADMM and 3,200 for SCAFFOLD. The paper reports overall communication savings of 35% or more relative to full-communication baselines while maintaining less than 1% accuracy degradation. ADMM-based methods (Alg.1, Alg.1-Rand, FedADMM) reach up to 78% CIFAR-10 accuracy, whereas FedAvg, FedProx, and SCAFFOLD plateau at approximately 70%.

## Baselines & Comparisons

Against FedADMM (Zhou & Li, 2023), the proposed Alg.1-Randomized consistently requires fewer communication events at every target accuracy level: 18,376 vs. 27,000 events for 78% CIFAR-10 accuracy (32% fewer), and 1,723 vs. >2,000 for 90% MNIST accuracy. Against FedAvg (McMahan et al., 2017) and FedProx (Li et al., 2020a), the advantage is more pronounced in terms of achievable accuracy: both baselines plateau at ~70% CIFAR-10 accuracy and cannot reach 75% or higher within 150 rounds, while Alg.1 reaches 78%. Against SCAFFOLD (Karimireddy et al., 2020), the proposed method again wins on both axes: SCAFFOLD requires 3,200 events for 90% MNIST accuracy (nearly 2x more than Alg.1-Randomized's 1,723) and also fails to exceed 70% on CIFAR-10. The paper attributes FedAvg/FedProx's failure to their inability to handle extreme non-i.i.d. data (each agent holding only one class), while FedADMM's random agent selection misses critical local updates, and SCAFFOLD's dual-variable communication (client drift + local model) doubles its communication overhead.

## Relation to Prior Work

This paper builds on the ADMM framework (Boyd et al., 2010) and the dynamical systems analysis of optimization algorithms (Nishihara et al., 2015; Lessard et al., 2016), introducing an event-triggered communication mechanism inspired by the sent-on-delta concept (Miskowicz, 2006). It departs from prior ADMM-based federated methods (FedADMM, FedPD) that rely on random agent selection, and from event-triggered ADMM work (Zhang et al., 2023, 2024) that focused on compression schemes without convergence rate analysis or communication failure modeling. The key conceptual departure is treating event-based communication as a bounded disturbance in a dynamical systems framework, enabling Lyapunov-based convergence proofs that simultaneously account for non-i.i.d. data heterogeneity and packet drops.

## Why It Matters / Open Questions

The paper addresses two of the most practical bottlenecks in distributed/federated learning—communication overhead and non-i.i.d. data—within a single framework, achieving 35%+ communication savings while matching or exceeding baseline accuracy. The robustness analysis under communication failures (packet drops) with a simple periodic reset strategy fills a notable gap in the literature. Open questions include whether the approach extends to asynchronous settings, adversarial robustness (gradient poisoning), and differential privacy, all of which the authors acknowledge as unaddressed. The strong convexity assumption required for linear rates limits the theoretical scope, though the nonconvex sublinear result (Thm. 2.3) partially mitigates this.

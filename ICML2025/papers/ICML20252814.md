## Problem

Existing model merging methods for multi-task learning face a fundamental trade-off: global-aware methods (e.g., Task Arithmetic) inevitably cause parameter interference across tasks, while local-aware methods (e.g., TIES-Merging) extract task-specific parameters that lose effectiveness after merging. The paper identifies the missing criterion as the need for localized information that is simultaneously aligned with global task consensus, ensuring extracted parameters remain effective in the merged model.

## Input / Output

The method takes independently fine-tuned model weights (from a shared pretrained backbone such as CLIP ViT-B/32 or RoBERTa-base), the corresponding pretrained weights, and task-specific unsupervised datasets (no ground-truth labels required). It produces a single merged multi-task model whose parameters are the pretrained weights plus a final task vector. Notably, the unsupervised data is consumed only to compute Shannon entropy for sample selection and to assign pseudo-labels; the actual mask optimization uses these pseudo-labeled samples, and the final binary mask selects only ~3.5–5% of parameter positions for conflict-free merging.

## Method

CALM comprises three components. First, Class-Balanced Entropy Minimization Sampling (CB-EMS) selects an equal number of lowest-entropy samples per class from each task's unsupervised data and assigns pseudo-labels, yielding a reliable dataset whose entropy signal is stable during merging. Second, an efficient-aware framework partitions tasks into a large set S merged via simple task arithmetic (τ_c = λΣτ_i) and a small sequential set S̄ merged one-by-one, keeping computational cost sub-linear in the number of tasks. Third, consensus-aware mask optimization reparameterizes a binary mask as M = σ(R) and trains R by minimizing the summed empirical loss over all currently visible tasks plus an L1 sparsity penalty; the resulting binarized mask M* is applied as τ_seq^(j) = (1−M*)⊙τ_seq^(j−1) + M*⊙τ_j, which simultaneously extracts effective information from the new task, removes interference from the previously merged tasks, and guarantees conflict-free parameter combination.

## Results

On eight vision classification tasks with CLIP ViT-B/32, CALM achieves 87.7% average accuracy, approaching the traditional MTL upper bound of 88.9% and surpassing the best baseline (Pareto Merging, 84.8%) by 2.9%. On twelve GLUE NLP tasks with RoBERTa-base, CALM matches or exceeds individual fine-tuned model performance on most tasks, even outperforming individual models on RTE and MRPC. The method also demonstrates balanced performance across tasks, with minimal accuracy degradation on any single task compared to baselines that suffer up to 20% drops on harder datasets like RESISC45 and DTD.

## Baselines & Comparisons

CALM outperforms all eight compared baselines on average accuracy. Against the strongest global-aware method, Pareto Merging (84.8%), CALM gains 2.9%, with particularly large margins on RESISC45 (+4.9%) and DTD (+11.7%). Against the best localized-aware method, Localize-and-Stitch (79.9%), CALM improves by 7.8%, showing that consensus-aware mask optimization extracts substantially more effective information than single-task-focused masks. Against Ties-Merging (72.4%) and Task Arithmetic (69.1%), the gains are 15.3% and 18.6% respectively, confirming that both magnitude-based selection and global arithmetic suffer from severe parameter interference. CALM also surpasses both variants of AdaMerging (TW: 71.1%, LW: 80.1%) and the Consensus TA/TIES methods (73.7%/74.8%), demonstrating that class-balanced entropy sampling and global consensus mask optimization are more effective than task-wise or layer-wise weight learning. The only method CALM does not surpass is Traditional MTL (88.9%), which it approaches within 1.2% without requiring access to original training data.

## Relation to Prior Work

CALM is built directly on the task vector framework introduced by Task Arithmetic (Ilharco et al., 2023), which defines the difference between fine-tuned and pretrained weights as the unit of merging. It departs from both global-aware methods (Task Arithmetic, AdaMerging) that merge all parameters holistically, and localized-aware methods (TIES-Merging, Localize-and-Stitch) that select parameters based on magnitude or single-task performance. The key conceptual departure is introducing 'global task consensus' as the selection criterion for localized parameters: rather than optimizing a mask for one task in isolation, CALM optimizes it against the empirical loss of all previously merged tasks simultaneously. The mask re-parametrization via sigmoid follows Panigrahi et al. (2023) and He et al. (2024), while the CB-EMS sampling is a class-balanced refinement of AdaMerging's entropy minimization.

## Why It Matters / Open Questions

The paper provides a practical, scalable recipe for merging independently fine-tuned models without retraining, which is increasingly relevant as organizations fine-tune shared pretrained models on private data. The efficient-aware framework (sequentially merging only a small subset of tasks while task-arithmetic-merging the rest) addresses a real scalability bottleneck, and the consensus-aware mask offers a principled alternative to ad-hoc magnitude-based selection. Limitations include the requirement for task-specific unsupervised data (limiting fully data-free merging), the residual gap to individual models (~3% on ViT-B/32), and the fact that the method has only been validated on classification tasks with moderate model sizes. Open questions include whether the consensus criterion generalizes to generative tasks, highly heterogeneous task sets, or very large model families where parameter redundancy patterns may differ.

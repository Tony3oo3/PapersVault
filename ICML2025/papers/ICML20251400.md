## Problem

Comprehensive LLM benchmarking on hundreds or thousands of prompts incurs prohibitive computational and monetary costs (e.g., 4,200 GPU hours for BLOOM-176B on HELM), preventing frequent evaluation during training and extensive hyperparameter tuning. Existing efficient benchmarking methods rely on fixed or static prompt subsets that do not adapt to individual model strengths, and they lack a principled generative model for capturing dependencies across prompts to predict unobserved scores.
![Teaser figure](../imgs/ICML20251400/cropped_page4_idx0.webp)

## Input / Output

The method takes pretrained sentence embeddings (e.g., SFR-Embedding, 4096-dim) for all benchmark prompts, the acquired evaluation scores for a sequentially selected subset of K prompts, and the full prompt set as input. It produces predicted evaluation scores for the remaining N−K prompts via a neural process, a final benchmark performance estimate computed as a weighted average across datasets combining actual and predicted scores, and the adaptively selected prompt subset. A notable constraint is handling mixed-type scores (binary accuracy, F1, BLEU, win rates) within a single generative model, where discrete scores use embedding layers and continuous scores use linear projections.

## Method

The core architecture is a latent-variable Neural Process (based on Attentive NP with Set Transformer layers for memory efficiency) that models the evaluation score function as a stochastic process over prompts, trained via ELBO on historical leaderboard data to capture cross-prompt dependencies. On top of this, a PPO-based RL agent sequentially selects which prompts to evaluate, using an intermediate reward function (structured as a potential function to preserve optimal policy) that measures per-prompt improvement in prediction accuracy after each acquisition. The policy network employs a dot-product architecture where the actor output is inner-producted with candidate prompt embeddings, enabling generalization to arbitrary and changing action spaces (critical for cold-start with new prompts). The NP also provides auxiliary information—predicted scores and their uncertainties for unobserved prompts—to guide the agent's exploration, and a semi-supervised pseudo-labeling procedure extends the NP to newly added prompts without historical scores.

## Results

The RL-based acquisition policy (AEA) achieves the lowest absolute prediction error across all five LLM benchmarks: 0.001 on AlpacaEval (K=100), 0.030 on HELM-Lite (K=200), 0.018 on Open LLM Leaderboard (K=200), 0.013 on MMLU (K=100), and 0.034 on Chatbot Arena (K=40). The method achieves equivalent estimation accuracy to uniform random sampling with dramatically fewer prompts: only 8 prompts on AlpacaEval (vs. 100), 35 on MMLU (vs. 100), and 50 on HELM-Lite (vs. 200), representing 75–92% reductions in required evaluations. The metric reported is the mean absolute error between the predicted benchmark score and the true benchmark score, averaged over all test models.

## Baselines & Comparisons

The RL-based AEA policy outperforms all baselines on every benchmark. Against Perlitz et al.'s stratified sampling (S-Rand), the RL policy achieves lower error on all four benchmarks where both are evaluated (e.g., 0.030 vs. 0.035 on HELM-Lite, 0.018 vs. 0.030 on Open LLM), while S-Rand itself performs comparably to uniform random sampling. Against Polo et al.'s TinyBenchmarks (C-IRT), the RL policy wins on all five benchmarks (e.g., 0.001 vs. 0.003 on AlpacaEval, 0.013 vs. 0.015 on MMLU); in the direct head-to-head of Table 1, using the same NP prediction model, RL-selected prompts yield 0.001 error on AlpacaEval vs. 0.003 for TB-selected prompts. Against Vivek et al.'s Clustering-Score, the RL policy is superior on all benchmarks, though C-Score is the strongest clustering baseline on MMLU (0.014) and AlpacaEval (0.004). The combinatorial optimization static policy, despite being NP-hard and computationally expensive, underperforms even random sampling, which the authors attribute to distribution shift between training and test models. Uncertainty sampling and information gain policies consistently fail to explore the action space adequately, yielding errors 2–4× higher than the RL policy on most benchmarks.

## Relation to Prior Work

This paper builds on the Neural Process framework (Garnelo et al., 2018; Kim et al., 2019) for modeling stochastic processes, replacing self-attention with Set Transformer layers for memory efficiency, and couples it with a PPO-based RL agent for sequential prompt selection. It departs from prior efficient-benchmarking work (Perlitz et al., 2023; Polo et al., 2024; Vivek et al., 2023) in two key ways: (1) it models inter-prompt dependencies via a generative model rather than assuming item independence as in IRT-based approaches, and (2) it uses a dynamic, model-specific acquisition policy rather than a fixed static subset. The connection to active learning and active testing literature is explicit, but the paper reframes the problem as predicting unobserved evaluation scores from a learned dependency model rather than minimizing labeling cost.

## Why It Matters / Open Questions

The practical impact is significant: reducing evaluation prompts by 75–92% while maintaining accuracy directly lowers the computational and API costs that currently hamper frequent LLM evaluation during training and hyperparameter tuning. However, the approach requires substantial historical leaderboard data for training the neural process and RL policy, limiting immediate applicability to new benchmarks. Open questions include handling model bias (where test models differ substantially from training models), the cold-start problem for new prompts, and whether a continual learning framework is needed as leaderboards evolve. The finding that standard active learning heuristics (uncertainty sampling, information gain) consistently underperform the RL policy suggests that the dependency structure across prompts is too complex for greedy criteria.

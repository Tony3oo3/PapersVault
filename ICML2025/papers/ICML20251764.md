## Problem

Prior work showed that Kronecker-based linear algebra algorithms (e.g., Kronecker JL, Kronecker Hutchinson) require exponential sketching dimension in the number of tensor modes q, but it remained unclear whether this exponential cost is fundamentally unavoidable or merely an artifact of specific algorithmic choices. Additionally, in the classical non-Kronecker setting, the choice of subgaussian query distribution (Gaussian vs. Rademacher) does not change asymptotic query complexity, yet it was unknown whether this invariance extends to the Kronecker matrix-vector model.

## Input / Output

The oracle accepts a matrix A ∈ R^{n^q × n^q} and returns A·x for query vectors x = x_1 ⊗ ... ⊗ x_q where each x_i ∈ R^n, meaning the algorithm can only probe A through Kronecker-structured directions. The algorithm must output a trace estimate, spectral norm estimate, or zero/nonzero decision with constant success probability (2/3). A key constraint is the κ-conditioning assumption: the matrix formed by concatenating all query vectors must have condition number at most κ, which the paper argues is satisfied by all standard Khatri-Rao sketching methods.

## Method

The core technical insight (Lemma 8) is that the inner product between a random Kronecker-structured unit vector and any fixed Kronecker-structured unit vector is exponentially smaller (by a factor of C_τ^{-q}) than the 1/n^q expected for generic random vectors, due to the tensorization of per-mode inner products. This near-total orthogonality is exploited via an information-theoretic framework: a Kronecker-structured signal is planted on Gaussian noise, and the exponentially small inner products ensure the KL divergence between the two resulting distributions remains O(1) for subexponential query counts, making them indistinguishable by Pinsker's inequality. The proofs handle adaptive algorithms by generalizing the Simchowitz et al. (2017) technique, showing at each time step the algorithm cannot suddenly gain information about the planted direction. For the small-alphabet zero-testing result, the mechanism is stronger: Kronecker products of Rademacher vectors are exactly orthogonal to fixed Kronecker-structured vectors with probability 1 − 1/2^q, yielding a Θ(2^q) query lower bound that contrasts with the single-query Gaussian solution.

## Results

The paper proves exponential lower bounds on Kronecker matrix-vector query complexity. For spectral norm estimation (Theorem 6), any κ-conditioned algorithm requires t = Ω(min{C₀^(q/2), C_τ^(q/2)/κ²}) queries to achieve multiplicative error C_τ^(q/2). For trace estimation (Theorem 7), the lower bound is t = Ω(min{C₀^(q/2), C_τ^(q/2)/(κ²√ε)}) queries for relative error (1±ε). For zero testing with the Rademacher alphabet {±1} at n=2, exactly Θ(2^q) queries are necessary and sufficient (Corollary 21), while the complex alphabet {±1, ±i} requires only Θ((4/3)^q) queries.

## Baselines & Comparisons

The paper's central comparison is between Kronecker-structured and classical (non-Kronecker) matrix-vector query complexity, showing an exponential gap: tasks solvable in O(1) classical queries (e.g., zero testing with a single Gaussian query) require Ω(2^q) Kronecker queries with Rademacher vectors. A second key comparison is between subgaussian distributions within the Kronecker model: Gaussian Kronecker vectors solve zero testing in 1 query, while Rademacher Kronecker vectors require Θ(2^q) queries, demonstrating that subgaussianity alone does not determine Kronecker query complexity. The paper also compares real vs. complex Kronecker oracles, showing the complex {±1,±i} alphabet reduces the zero-testing exponent from 2^q to (4/3)^q at n=2. Finally, the results confirm that the O(2^q)-query Rademacher trace estimator from Meyer & Avron (2023) is near-optimal, while their O(1.5^q) continuous-vector variant is strictly better, establishing that the choice of base distribution can change sample complexity by an exponential factor in q.

## Relation to Prior Work

This paper generalizes the information-theoretic lower bound framework of Simchowitz et al. (2017) from the classical matrix-vector model to constrained query models, specifically Kronecker-structured queries. It provides the first rigorous lower bounds explaining the exponential query costs empirically observed in Kronecker-based tensor sketching methods (Kronecker JL, Kronecker Hutchinson, Khatri-Rao sketches) by prior works such as Meyer & Avron (2023) and Ahle & Knudsen (2019). The core technical contribution is a new orthogonality lemma showing that random Kronecker-structured vectors have exponentially smaller inner products than their non-Kronecker counterparts, which drives all the lower bound proofs.

## Why It Matters / Open Questions

The paper establishes that exponential query complexity is fundamentally unavoidable for basic linear algebra tasks (trace, spectral norm, zero-testing) in the Kronecker matrix-vector model, explaining why prior tensor algorithms require exponential sketching dimensions. A striking open question is whether the conditioning assumption on the query matrix is truly necessary; if Conjecture 23 fails, it would imply that extremely ill-conditioned Khatri-Rao sketches could circumvent the lower bounds, which would be a major shift in how tensor sketching is designed. The finding that Rademacher vs. Gaussian base distributions create an exponential gap (unlike the non-Kronecker case where subgaussianity suffices) has practical implications for algorithm design in tensor network computations.

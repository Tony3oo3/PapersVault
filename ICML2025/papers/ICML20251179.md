## Problem

Task Arithmetic-based unlearning methods are highly sensitive to hyperparameter choices, requiring expensive validation over many fine-tuned candidates to select a single best model. Existing approaches discard all but one candidate, wasting the information encoded in the remaining fine-tuned models. NegMerge addresses this by leveraging all validation candidates through a sign-consensus merging strategy that identifies parameters truly associated with the forget set.

## Input / Output

The method requires only the forget set (no retain set needed) and a pool of 10–30 fine-tuned models trained on the forget set with varying hyperparameters (learning rate, data augmentation, weight decay, label smoothing). It produces a highly sparse merged task vector in which 90–95% of elements are zeroed out, leaving only 5–10% of weight positions active. This sparse vector is then negated from the pre-trained model weights to yield the unlearned model, enabling lightweight deployment via weight lookup tables that store only the active elements.

## Method

NegMerge computes a task vector for each fine-tuned model as the element-wise difference from the pre-trained weights, then merges them using a sign-consensus filter: for each parameter position, if all task vectors agree on sign (all positive or all negative), the element is retained and averaged; if signs conflict, the element is masked to zero. The final merged vector τ_merged = (1/n) Σ (τ_k ⊙ 1_sign-consistent) is negated from the original model (θ_unlearn = θ_pre − λτ_merged). The key insight is that sign-consistent elements across diverse hyperparameter settings reflect knowledge genuinely tied to the forget set, while sign-conflicting elements are training-configuration noise. This produces a sparse editing signal that precisely targets forget-set knowledge while minimally disturbing retain-set performance, and the sparsity increases with the number of merged models, further improving unlearning quality.

## Results

On the CLIP unlearning scenario, NegMerge achieves the lowest forget-set accuracy across all three backbones: 20.76% (ViT-B/32), 19.24% (ViT-B/16), and 17.32% (ViT-L/14), while maintaining retain-set (ImageNet) accuracy around 60–72%. Under Linear Task Arithmetic, NegMerge further reduces forget-set accuracy to 8.03% (ViT-B/32) and 6.60% (ViT-B/16). In the standard classifier scenario on CIFAR-10 (ResNet-18, 10% random forgetting), NegMerge achieves an Avg. Gap of 1.07 from the Retrain benchmark, outperforming SalUn (1.15) which requires all data splits, and Task Arithmetic (1.62) which uses only the forget set.

## Baselines & Comparisons

NegMerge consistently outperforms all merging-based baselines (Uniform Merge, Greedy Merge, TIES-Merging, MagMax) on forget-set accuracy across all three CLIP backbones, with the largest margins over TIES-Merging (e.g., 20.76% vs. 26.21% on ViT-B/32) and MagMax (20.76% vs. 25.24%). Compared to the single-best-model Task Arithmetic baseline, NegMerge reduces forget-set accuracy by 2.9–3.0 percentage points (e.g., 20.76% vs. 23.63% on ViT-B/32) while incurring only 37 s of merge time versus the O(mn) inference cost of tuning λ per model. In the standard classifier scenario (CIFAR-10, ResNet-18), NegMerge (Avg. Gap 1.07) beats SalUn (1.15) despite using only the forget set rather than all splits, and substantially outperforms Task Arithmetic (1.62), Uniform Merge (1.75), TIES-Merging (1.96), and MagMax (3.00). NegMerge also achieves an MIA score of 12.87, nearly identical to the Retrain benchmark (12.88), confirming strong privacy protection. Merging time is 37 s for NegMerge versus 607 s for Greedy Merge and 128 s for TIES-Merging, while delivering superior accuracy.

## Relation to Prior Work

NegMerge sits at the intersection of task arithmetic for unlearning (Ilharco et al., 2022a) and model merging (Wortsman et al., 2022; Yadav et al., 2024). While Task Arithmetic defines the negation-based unlearning framework and prior merging methods (Uniform Merge, TIES-Merging, MagMax) combine multiple fine-tuned models for generalization, none of them address the specific challenge of identifying which weight changes are truly attributable to the forget set. The paper's key conceptual departure is repurposing the validation process: rather than discarding all but one fine-tuned model, it treats sign consistency across task vectors as a signal for forget-set-relevant parameters, applying an AND-like mask that has no direct precedent in the merging literature.

## Why It Matters / Open Questions

The practical appeal is that NegMerge eliminates the expensive single-model selection step in task-arithmetic unlearning while simultaneously improving performance, making it a drop-in upgrade for existing pipelines. The finding that 90–95% of task vector elements are sign-inconsistent (and thus noise) suggests that most fine-tuning weight changes are hyperparameter artifacts rather than forget-set signal, which has broader implications for understanding what fine-tuning actually encodes. However, the authors acknowledge the lack of a full theoretical justification, and the method's applicability to LLMs and VLMs remains untested. Open questions include whether layer-wise sign-consensus strategies (motivated by the depth-dependent sparsity findings) could further improve unlearning, and whether the approach generalizes beyond image classification.

## Problem

Sparse autoencoders have been used to interpret individual LLM features or perform high-level interventions, but their utility in uncovering the full computational circuit behind complex behaviors like in-context learning remains unexplored. A key obstacle is that task vectors—internal representations that causally induce ICL behavior—are out-of-distribution for SAEs, so naive SAE decomposition produces cluttered, uninterpretable results that degrade task performance. The paper addresses both the decomposition problem and the circuit-discovery problem at a scale (Gemma 1 2B) not previously attempted for end-to-end mechanistic interpretability of ICL.

## Input / Output

The method consumes Gemma 1 2B residual stream activations, attention outputs, and MLP outputs (decomposed via Gated SAEs and transcoders trained on FineWeb), along with ICL few-shot prompts from the Todd et al. (2024) task set (23 diverse token-to-token tasks). Task vectors are extracted by averaging residual streams at arrow tokens across prompts. The TVC algorithm takes a task vector and produces an optimized sparse SAE weight vector (reducing active features by ~70% while preserving loss improvement). The modified SFC produces a directed graph of SAE feature nodes (indexed by feature ID and token type) with edges weighted by indirect effects, from which task-execution features (layer 12, arrow tokens) and task-detection features (layer 11, output tokens) are identified and their causal connections through attention and MLP sublayers are mapped.

## Method

The paper introduces two key technical contributions. First, the Task Vector Cleaning (TVC) algorithm avoids the OOD problem by initializing SAE weights from the naive encoding of the task vector, then iteratively optimizing those weights via gradient descent on a composite loss: the NLL of zero-shot prompts steered with the reconstructed vector plus an L1 sparsity penalty, with early stopping on L0 norm stability. This yields sparse, interpretable decompositions where individual SAE latents (task-execution features) causally induce task behavior. Second, the authors adapt the Sparse Feature Circuits methodology of Marks et al. (2024) to ICL by (a) creating graph nodes per SAE feature–token-type pair (prompt, input, arrow, output, newline, extra) to capture position-specific roles, (b) modifying the loss to include all example pairs except the first, amplifying task-solving signals over copying circuits, and (c) using zero ablation rather than mean ablation to match SAE sparsity. Circuit discovery on Gemma 1 2B (layers 10–17) reveals that task-detection features activate on output tokens in earlier layers and causally drive task-execution features on arrow tokens in later layers through attention output and transcoder (MLP) sublayers, with faithfulness of 0.6 achieved by ~500-node circuits.

## Results

The Task Vector Cleaning (TVC) algorithm reduces the number of active SAE features in task vector decompositions by 50–80% (up to 70% for Gemma 1 2B) while maintaining or even improving the steering effect on task loss, with L1 coefficients between 0.001 and 0.025 yielding the best trade-off. The adapted Sparse Feature Circuits (SFC) method identifies circuits of ~500 nodes achieving an average faithfulness of 0.6 across 23 diverse ICL tasks on Gemma 1 2B; restricting to layers 11–12 reduces this to just 10–60 nodes for the same faithfulness. Task-execution features concentrate 89.8% of their activation mass on arrow tokens, while task-detection features concentrate 96.8% on output tokens, confirming their distinct circuit roles. Ablating task-detection feature directions substantially reduces the activation of corresponding task-execution features, validating their causal interdependence through attention and MLP sublayers.

## Baselines & Comparisons

The paper compares TVC against four baselines: original (uncleaned) task vectors, naive SAE reconstruction, and Inference-Time Optimization (ITO; Smith 2024) at two sparsity targets (L0=5 and L0=20). TVC consistently outperforms ITO across all tested models (Gemma 1 2B, Gemma 2 2B at 16k and 65k widths, Gemma 2 9B, and Phi-3 3B): ITO rarely improves upon the original task vector loss and is almost always dominated by TVC on the loss-vs-sparsity Pareto front (Figures 14–16). Naive SAE reconstruction produces over 10 non-zero features on target layers, most irrelevant to the task, and noticeably degrades the vector's effect on loss; TVC avoids this by optimizing decomposition weights directly against the steering loss. Compared to the original task vectors, TVC often achieves a small loss improvement while reducing active features to roughly one-third of the original count. The SFC circuit analysis is benchmarked against the original SFC methodology (Marks et al., 2024), which required only tens of top features to degrade performance; the ICL-adapted version needs several hundred features for comparable degradation, reflecting the greater circuit complexity of ICL versus simpler tasks like IOI.

## Relation to Prior Work

This paper bridges two previously separate lines of interpretability research: the task vector framework for ICL (Todd et al., 2024; Hendel et al., 2023) and the Sparse Feature Circuits methodology for automated circuit discovery (Marks et al., 2024). Prior SAE work either interpreted individual features in isolation or performed high-level interventions without tracing downstream causal effects, while prior circuit analysis focused on simpler tasks (IOI, subject-verb agreement) at smaller model scales. The paper's key methodological departure is the Task Vector Cleaning algorithm, developed because task vectors are out-of-distribution for SAEs and cannot be naively decomposed, and a set of SFC modifications (token-type aggregation, loss function redesign) to handle the structured, repetitive nature of ICL prompts at the Gemma 1 2B scale.

## Why It Matters / Open Questions

The paper demonstrates that SAEs are viable tools for end-to-end mechanistic circuit analysis on a complex, practically important task (ICL) at a model scale (12B) not previously explored with this methodology, and it identifies a two-stage causal architecture (task-detection → attention/MLP → task-execution) that gives a concrete, intervenable account of how ICL works. The TVC algorithm is a reusable technique for decomposing any task vector into interpretable, causally relevant features. Key limitations include the restriction to the simple task-vector setting (single-token transformations), the SFC analysis being confined to Gemma 1 2B, and the observation of multiple competing features per task that resist clean single-feature explanations. Open questions include whether this detection/execution circuit structure generalizes to more complex ICL (multi-step reasoning, long-context tasks) and whether the circuit can be leveraged for controllable or monitorable ICL in deployed models.

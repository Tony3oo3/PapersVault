## Problem

Standard residual connections in transformers treat all previous layer outputs as equally important by simply summing them, which dilutes crucial information from a few key layers with less useful information from others. The paper demonstrates this dilution empirically: a low-rank ResNet cannot fully reconstruct its input even after extensive training, while a model with learnable residual weights achieves near-zero loss with 100× fewer examples. This motivates replacing fixed identity shortcuts with adaptive, input-dependent combinations of layer outputs.

## Input / Output

For language modeling, DCA consumes text token sequences of length 128 (embedding dimension 512, MLP dimension 2048) and produces next-token predictions, trained on LM1B and C4. For image classification, it processes 16×16-patch tokenized RGB images through a ViT-S/16 backbone and outputs ImageNet class labels. The I/O interface is identical to a standard transformer; DCA modifies only the internal residual aggregation, adding negligible parameters (e.g., 49.73M vs. 49.65M for a 6-layer model).

## Method

DCA introduces Generalized Residual Networks (GRN) that replace the fixed identity shortcut with a learned weighted combination of all previous layer outputs, organized in a stack G_t ∈ R^{d×t}. Three GRN variants are proposed: GRN-v1 uses a shared scalar weight vector, GRN-v2 uses dimension-specific weights, and GRN-v3 adds input-dependent weights via a ReLU-gated projection of the stack. In the full DCA architecture, three independent GRN-v3 instances per decoder block generate the queries, keys, and values for self-attention, enabling depth-wise cross-attention where each attention component can selectively attend to different layers. An efficiency variant (k-DCA) retains only the first and last-k layer outputs explicitly in the stack while summing intermediate layers, reducing inference latency by up to 48%. Theoretical analysis on low-rank linear models proves that GRN achieves a strictly better test-error-vs-parameter-count trade-off than ResNet whenever the collective layer rank to ambient dimension ratio falls below a task-complexity-dependent threshold.

## Results

On LM1B (6-layer, ~50M params), DCA achieves 18.06 perplexity versus 18.98 for the standard Transformer, a 0.92 absolute improvement. On C4 (13-layer, ~179M params), 8-DCA reaches 20.392 PPL versus 21.534 for the Transformer. On ImageNet with ViT-S/16 (22M params), DCA improves top-1 accuracy from 76.4% to 77.1%. DCA also reaches the Transformer's final perplexity in roughly one-third of the training time (0.33x normalized time for 2-DCA).

## Baselines & Comparisons

DCA outperforms all four baselines across every evaluated task and dataset. Against the standard Transformer (Vaswani et al., 2017), DCA reduces perplexity by 0.92 on LM1B (18.06 vs 18.98) and by 1.14 on C4 (20.392 vs 21.534), while also improving ImageNet accuracy by 0.7 points (77.1% vs 76.4%). Against LAuReL (Menghani et al., 2024), DCA achieves a 0.93 PPL improvement on LM1B and 0.56 on C4. Against DenseFormer (Pagliardini et al., 2024), DCA improves by 0.74 PPL on LM1B and 0.78 on C4. Against Hyper-Connections (Zhu et al., 2024), the closest competitor, DCA still leads by 0.59 PPL on LM1B and 0.33 on C4. Notably, DCA adds only ~0.08M parameters over the Transformer baseline while delivering these gains, and it also exhibits superior training stability with no loss spikes observed.

## Relation to Prior Work

This paper extends the line of work on learned residual aggregation that began with DenseFormer (learned linear combination of layer outputs), LAuReL (low-rank transformation before combination), and Hyper-Connections (fixed-size stack with learned mixing). DCA's key departure is twofold: it introduces input-dependent, dimension-dependent weights (GRN-v3) that go beyond static or low-rank learned combinations, and it applies three independent GRN instances to the queries, keys, and values within each transformer block, enabling depth-wise cross-attention between layers. The theoretical contribution—characterizing when these generalizations beat standard ResNet in a test-error vs. model-complexity trade-off via collective rank thresholds—has no direct analogue in the prior architectural work, which was primarily empirical.

## Why It Matters / Open Questions

DCA offers a practical, low-overhead modification (negligible parameter increase) that yields up to 3× faster convergence to equivalent quality, improved training stability (no loss spikes), and the ability to retrofit pre-trained models for additional gains. The theoretical result that the benefit is inversely related to model rank/width provides a clear prediction: DCA is most useful for narrow or low-rank models and for deeper architectures, which aligns with the empirical width-scaling results. Open questions include whether the advantage persists at frontier model scale (the largest model tested is ~449M parameters), whether the three independent GRN instances for Q/K/V are necessary or whether a single instance suffices at scale, and how the method interacts with other recent architectural innovations like grouped-query attention or mixture-of-experts.

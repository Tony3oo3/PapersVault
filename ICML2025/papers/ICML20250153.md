## Problem

Proxy-sensitive attributes have been widely used to measure and enforce parity-based fairness (demographic parity, equalized odds) when true sensitive group data is missing, but no prior work extends this to the more flexible and often more appropriate notions of multiaccuracy and multicalibration. The paper addresses how to derive actionable upper bounds on true MA/MC violations and how to provably reduce them using only proxy group information, without access to the true sensitive attributes.

## Input / Output

The method takes a predictive model f, a set of learned proxy group functions Ĝ (each mapping X→{0,1}), samples (X,Y) from the marginal distribution, and per-proxy misclassification error rates err(ĝ) provided by a separate proxy developer with access to (X,Z). It produces two computable worst-case upper bounds—β(f,Ĝ) for multiaccuracy and γ(f,Ĝ) for multicalibration—along with an adjusted model f_adj that provably tightens these bounds. Crucially, the model developer never observes (X,Z,Y) jointly or the true group functions G; all fairness evaluation is mediated through the proxy error rates and proxy-group statistics.

## Method

The core theoretical result (Lemma 4.1) shows that for any true group g and its proxy ĝ, the true AE or ECE violation is bounded by F(f,ĝ) + AE/ECE(f,ĝ), where F(f,ĝ) = min(err(ĝ), √(MSE(f)·err(ĝ))), and this bound is tight. Taking the maximum over all proxies yields the worst-case guarantees β and γ. To reduce these bounds, the paper applies Algorithm 1 (multiaccuracy regression, a single-step linear projection) or Algorithm 2 (multicalibration boosting, an iterative calibration refinement) using the proxy groups Ĝ in place of the true groups G. Theorem 5.1 then guarantees that if the adjusted model achieves lower ECE^max on the proxies without increasing MSE, the worst-case MC violation strictly decreases. The key insight is that the bound decomposes into a fixed proxy-error term and an adjustable model-performance term, so improving calibration on proxies directly tightens the worst-case fairness certificate for the unknown true groups.

## Results

On ACSIncome (decision tree), the proxy-based upper bound certifies the initial model as approximately 0.21-multicalibrated with respect to true sensitive groups; after multicalibration via Algorithm 2, the bound drops to ~0.13, a 38% improvement. On ACSPubCov (decision tree), the initial model is certified as ~0.25-MC, reduced to ~0.09-MC after adjustment. On CheXpert (decision tree on DenseNet-121 embeddings), the worst-case violation is as large as ~0.42 before adjustment, dropping to ~0.13-MC after multicalibration with respect to proxies. For the logistic regression and end-to-end DenseNet-121 models on CheXpert, worst-case violations are already small (~0.11 and ~0.12-MC), so further adjustment yields negligible gains.

## Baselines & Comparisons

This paper does not compare against competing fairness methods; instead, the central comparison is between the original model f and the proxy-adjusted model f_adj. Across all three datasets, multicalibrating f with respect to proxy groups Ĝ (via Algorithm 2) consistently reduces the worst-case MC upper bound γ(f, Ĝ): from 0.21 to 0.13 on ACSIncome, from 0.25 to 0.09 on ACSPubCov, and from 0.42 to 0.13 on CheXpert (decision tree). The true ECE_max values (reported for validation since the full data is available in the experiments) always lie below the computed upper bounds, confirming the theoretical guarantees. For models that are already well-calibrated (logistic regression, Random Forest, end-to-end DenseNet-121), the adjustment provides no meaningful benefit because the initial worst-case violations are already small. The key practical takeaway is that the proxy-based certificate is actionable: a practitioner can verify γ(f, Ĝ) < α without ever observing the true sensitive attributes.

## Relation to Prior Work

This paper extends the proxy-based fairness framework established for parity-based notions (demographic parity, equalized odds) by Bharti et al. (2024), Kallus et al. (2022), and Awasthi et al. (2021) to the more flexible multiaccuracy and multicalibration settings. The key theoretical departure is the derivation of the bound F(f, ĝ) = min(err(ĝ), √(MSE(f)·err(ĝ))) for MA/MC violations, which parallels but generalizes the proxy-error bounds previously available only for parity criteria. For enforcement, the paper repurposes existing algorithms—Gopalan et al. (2022) for MA regression and Roth (2022) for MC boosting—by applying them to proxy groups rather than true groups, and proves that this provably reduces worst-case violations on the true groups.

## Why It Matters / Open Questions

This work provides the first principled mechanism for certifying multiaccuracy and multicalibration guarantees without access to sensitive group data, which is a critical gap in high-stakes domains like healthcare where privacy regulations restrict demographic information. The practical impact is demonstrated by the 38% reduction in worst-case MC violation on ACSIncome and the ability to flag a decision tree's 0.42 worst-case calibration error on CheXpert before deployment. However, the bounds can be conservative (the gap between the certified bound and true violation varies across groups), and the approach still requires a proxy developer with access to (X, Z) samples, which may not always be available. Open questions include whether tighter bounds are achievable with richer proxy information (e.g., full marginal distributions) and how these guarantees behave under distribution shift.

## Problem

No prior work has studied binary hypothesis testing for the structured distribution families induced by softmax or leverage score models, despite their central roles in transformer attention and numerical linear algebra. The paper asks: given query access to an unknown model known to be one of two parameterized models (SoftMax_A or SoftMax_B, or Leverage_A or Leverage_B), how many queries are needed to identify which is the truth? This is motivated by the practical question of whether different 'ability regions' within LLMs can be distinguished through limited parameter sampling.

## Input / Output

The method takes two parameter matrices A, B ∈ R^{n×d} and provides query access to an unknown model. For softmax, each query is a vector x ∈ R^d subject to an energy constraint ||x||_2 ≤ E (motivated by batch normalization in neural networks); for leverage scores, each query is a vector s ∈ (R\{0})^n with per-coordinate bounds c ≤ s_i² ≤ C. The output is a binary decision (A or B) with success probability ≥ 2/3, and the main deliverable is tight sample complexity bounds expressed in terms of the parameter distance (e.g., ||A−B||_{2→∞} for softmax) and a model-dependent variance quantity ν.

## Method

The core result (Theorem 3.1/4.1) establishes that the sample complexity equals Θ(δ^{-2}) where δ is the supremum Hellinger distance between the two models' output distributions over all valid queries, reducing the problem to bounding this distance. For lower bounds, a key lemma shows that if ||a−b||_∞ ≤ ε, then the Hellinger distance between the corresponding softmax distributions is O(ε), yielding an Ω(ε^{-2}) query lower bound for softmax (and Ω(ε^{-1}) for leverage scores via operator-norm perturbation of A_s^T A_s). For upper bounds, the paper analyzes local perturbations B = A + εM by Taylor-expanding the output distribution to first order in ε, showing the Hellinger distance is Ω(ε²ν) where ν = sup Var_{SoftMax_A(x)}(Mx) (or an analogous leverage-score variance), and then applies the general Hellinger-distance theorem to obtain a matching O(ε^{-2}ν^{-1}) upper bound. The leverage score case additionally requires handling the invariance under right-multiplication by invertible matrices and propagating perturbations through matrix inverses using operator norm bounds.

## Results

For softmax models, the sample complexity of binary hypothesis testing is Θ(δ⁻²) where δ is the supremum Hellinger distance over all energy-constrained inputs (Theorem 3.1). Concretely, if ‖A−B‖₂→∞ ≤ ε, any algorithm requires Ω(ε⁻²E⁻²) queries (Theorem 3.2), and for B = A + εM the problem is solvable in O(ε⁻²ν⁻¹) queries (Theorem 3.5), with a matching lower bound (Theorem 3.6). For leverage score models, the lower bound is Ω(cδ/(Cε)) queries (Theorem 4.2) while the local upper bound is O(ε⁻²ν⁻¹) (Theorem 4.3), leaving a gap between the linear and quadratic dependence on ε⁻¹.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or comparison tables. The main 'comparison' is between upper and lower bounds: for softmax models the bounds are tight (both scale as ε⁻²), while for leverage score models there is a gap—the lower bound is Ω(ε⁻¹) (Theorem 4.2) but the upper bound is O(ε⁻²ν⁻¹) (Theorem 4.3), and the authors explicitly note that improving the lower bound to quadratic dependence is an open question. The paper also contrasts the two model families: softmax invariance under row shifts (B = A + 1ₙᵀw) makes some parameter differences undetectable, while leverage score invariance under right-multiplication by invertible matrices (B = AR) creates an analogous identifiability issue. No prior work on hypothesis testing for softmax or leverage score model families is identified, so no direct method comparisons exist.

## Relation to Prior Work

This paper applies the classical binary hypothesis testing framework (governed by Hellinger distance, per Neyman-Pearson and Polyanskiy-Wu) to two structured, parameterized model families—softmax and leverage score models—for which the authors explicitly note no prior hypothesis testing work exists. Conceptually, it repurposes information-theoretic sample complexity tools to the setting of query-based model identification, where the 'distributions' are not fixed but are nonlinear functions of an input vector and a parameter matrix. The softmax side connects to transformer attention mechanisms in LLMs, while the leverage score side draws on a rich literature in numerical linear algebra and graph sparsification, though the hypothesis testing angle is entirely new to both communities.

## Why It Matters / Open Questions

The results provide a theoretical lower bound on how many queries are needed to distinguish closely related models, directly informing the question of whether different 'ability regions' in LLMs can be identified through limited parameter sampling. A notable open gap is the leverage score lower bound, which is only linear in ε⁻¹ versus the quadratic ε⁻² upper bound, leaving a factor of ε⁻¹ unresolved. The quantity ν (a variance-like term depending on the perturbation direction M) governs the tight local bound, but bounding or efficiently computing ν remains open. Extending the framework to goodness-of-fit and two-sample testing for these model families is identified as a natural next step.

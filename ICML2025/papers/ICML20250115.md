## Problem

Conformal outlier detection provides distribution-free type-I error guarantees only when the calibration reference set contains purely inlier data, yet real-world reference sets inevitably contain a small fraction of undetected outliers. This paper addresses two questions: (1) under what conditions does such contamination make conformal p-values conservative rather than invalid, and (2) how can one selectively clean the contaminated reference set using a limited labeling budget to recover detection power without inflating the type-I error rate.

## Input / Output

The method consumes a contaminated reference set of n points (a mix of inliers from P₀ and outliers from P₁), a pre-trained black-box outlier detection model (e.g., Isolation Forest for tabular data, ReAct/SCALE on ResNet-18 or VGG-19 features for 32×32 RGB images), a small labeling budget m (typically 50), and a target significance level α. It outputs a refined conformal p-value computed over the partially cleaned reference set and a binary outlier decision (reject H₀ if p̂ ≤ α). The labeling budget is spent only on the m highest-scoring reference points, not the full set, making the approach scalable to large calibration sets.

## Method

The paper first proves (Lemma 2.2) that when outlier scores are typically larger than inlier scores—a condition holding for any reasonably accurate, non-adversarial detection model—standard conformal p-values on contaminated data are conservative, with the type-I error bounded above by α minus a term proportional to the outlier fraction. To recover power, the proposed Label-Trim method sorts all reference scores, selects the top m for annotation, removes only the confirmed outliers from this subset, and computes conformal p-values on the resulting partially cleaned set. The theoretical justification (Theorem 3.1) requires a novel 'mirror procedure' proof technique: an imaginary variant that includes the test point in the annotation process to preserve exchangeability, showing that the actual type-I error is bounded by α + 1/(n₀+1) minus a correction term for remaining outliers. This avoids the over-correction problem of Naive-Trim (which removes top scores without verification and inflates type-I error) while retaining a large reference set for fine-grained p-values.

## Results

On six visual datasets (CIFAR-10 inliers vs. MNIST/SVHN/Texture/Places365/TinyImageNet/CIFAR-100 outliers), Label-Trim with m=50 annotations achieves near-oracle power while maintaining valid type-I error control. At α=0.01 and 1% contamination, Label-Trim matches the infeasible Oracle exactly (power 1.166, type-I error 0.010), while Standard conformal is conservative (type-I error 0.008) and Naive-Trim is invalid (type-I error 0.017). At 5% contamination, Label-Trim still achieves 1.786× the Standard power with type-I error 0.008, compared to Oracle's 1.961×. On tabular data (Shuttle, Credit Card, KDDCup99), Label-Trim similarly boosts power substantially while keeping type-I error at or below α, with the gap to Oracle narrowing as contamination decreases.

## Baselines & Comparisons

Label-Trim (the proposed method) matches the infeasible Oracle benchmark exactly at 1% contamination (power 1.166, type-I error 0.010) and comes within 2–9% of Oracle power at higher contamination rates (1.517 vs. 1.549 at 3%; 1.786 vs. 1.961 at 5%), while maintaining valid type-I error control at or below α. Naive-Trim, which removes the top-scoring points without annotation, inflates type-I error to 0.017–0.036 (target 0.01), confirming it is statistically invalid despite achieving the highest raw power (up to 4.16× Standard). Small-Clean, which uses the same labeling budget to build a small clean reference set, is completely powerless at α=0.01 (power = 0.00) because the smallest achievable conformal p-value 1/(m+1) exceeds α. Standard conformal with the contaminated reference set is valid but overly conservative, with type-I error dropping to 0.004–0.008 at α=0.01 as contamination increases, directly reflecting the theoretical bound in Lemma 2.2. At α=0.03, Label-Trim still outperforms Standard by 4–22% in power while keeping type-I error at or below 0.03, whereas Naive-Trim inflates error to 0.035–0.052.

## Relation to Prior Work

This paper extends the conformal outlier detection framework of Bates et al. (2023) to the practically important but previously under-studied setting where the calibration reference set contains a small fraction of unlabeled outliers. It builds on the foundational split-conformal p-value construction from Vovk et al. (2005) and draws theoretical inspiration from Sesia et al. (2024), who analyzed conformal classification under noisy labels, but deliberately departs from their approach by avoiding an explicit label-noise model and instead leveraging a black-box outlier detection model with a limited active-labeling budget. The paper also contrasts with the worst-case distribution-shift analysis of Barber et al. (2023), arguing that in non-adversarial outlier detection settings, contamination typically induces conservativeness rather than invalidity.

## Why It Matters / Open Questions

The paper provides both a theoretical explanation (Lemma 2.2) for why conformal outlier detection is conservative under contamination and a practical remedy (Label-Trim) that achieves near-oracle power with as few as 50 annotations, validated across nine real datasets and multiple detection models. Key limitations include the assumption of i.i.d. inlier calibration and test points, the residual conservativeness when the labeling budget is very small, and the dependence on active annotation access. Open questions highlighted by the authors include extending beyond the i.i.d. assumption, incorporating label uncertainty, and developing semi-supervised cleaning strategies that leverage a small clean set to clean a larger contaminated set without additional annotations.

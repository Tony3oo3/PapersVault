## Problem

Zero-initialized attention in LLaMA-Adapter has shown strong empirical results for instruction-following fine-tuning, yet its theoretical foundations remain largely unexplored. It is unclear why zero-initialization stabilizes training, what statistical advantages it provides over random initialization, and whether the approach can be extended to more flexible non-linear prompt structures.
![Teaser figure](../imgs/ICML20250524/cropped_page4_idx0.webp)

## Input / Output

The method takes a text instruction and context sequence as input to a frozen LLaMA model (7B or 13B), where learnable prompt vectors of length L=10 are prepended to the token sequence at the last K transformer layers (K=30 for 7B, K=38 for 13B). A scalar gating factor α, passed through tanh, modulates the prompt's contribution to the attention output, starting at zero so the model initially reproduces pre-trained behavior. The output is a generated text response evaluated on multiple-choice QA benchmarks (ARC, MMLU, HellaSwag, TruthfulQA) via zero-shot or 10-shot evaluation.

## Method

The paper establishes that zero-initialized attention is a specialized mixture-of-experts formulation: pre-trained token experts are combined with L prompt experts, where the gating weights are computed via separate softmax over prompt and context attention scores, and the prompt branch is scaled by tanh(α). Under this MoE interpretation, the authors prove that both the prompt parameters and the gating factor admit optimal parametric estimation rates of O_P(√(log n / n)) via least-squares, using a Voronoi-cell-based loss function to handle overspecified prompt counts. They further extend the analysis to non-linear prompts reparameterized through a shared lightweight MLP (two linear layers with ReLU/Leaky-ReLU), showing identical convergence guarantees while offering greater practical flexibility. Empirically, the non-linear variant with zero-initialized attention outperforms linear prompts by 1–2% on average and approaches full fine-tuning performance while updating only 2.6M–3.3M parameters, and both prompt types substantially outperform random-initialized attention especially under limited training data (1%–50% of Alpaca).

## Results

On LLaMA-7B, the non-linear prompt with zero-initialized attention achieves 53.28% average accuracy across ARC, MMLU, HellaSwag, and TruthfulQA, nearly matching full fine-tuning (53.39%) while updating only 2.6M parameters vs. 7B. On LLaMA-13B, the non-linear prompt reaches 61.67% average, outperforming the linear variant (59.70%) by 1.97%. Zero-initialized attention consistently outperforms random-initialized attention, with a 3.77% average gain on LLaMA-7B (52.83% vs. 49.06%) and a 0.58% gain on LLaMA-13B. In low-data regimes (10% Alpaca), the non-linear prompt exceeds random-init by 4.72% on ARC, demonstrating superior sample efficiency.

## Baselines & Comparisons

The non-linear prompt with zero-initialized attention (53.28% avg on LLaMA-7B) surpasses LoRA (52.64%) by 0.64% while using fewer trainable parameters (2.6M vs. 4.2M), and nearly matches full fine-tuning (53.39%) with only 0.04% of the parameters. Against other PEFT methods, the non-linear prompt dominates: it outperforms Prompt Tuning (47.48%) by 5.80%, IA3 (46.04%) by 7.24%, and VeRA (45.19%) by 8.09% in average accuracy on LLaMA-7B. On LLaMA-13B, the non-linear prompt (61.67%) improves over the linear zero-init variant (59.70%) by 1.97%, with the largest gains on MMLU (+1.68%) and TruthfulQA (+4.04%). Zero-initialized attention also consistently beats random-initialized attention across all four benchmarks, with the gap widening for smaller models (3.77% avg on LLaMA-7B vs. 0.58% on LLaMA-13B), confirming the theoretical sample-efficiency advantage.

## Relation to Prior Work

This paper builds directly on LLaMA-Adapter (Zhang et al., 2024), which introduced zero-initialized attention as a practical engineering technique for instruction-tuning LLaMA, and on the attention-as-MoE framework established by Le et al. (2024; 2025) for prefix-tuning convergence analysis. It departs from prior work by providing the first rigorous statistical theory for zero-initialized attention, showing that prompts and gating factors admit optimal parametric-rate estimation via a Voronoi-cell loss (borrowed from Manole & Ho, 2022 for finite mixtures), and by extending the analysis from linear to non-linear (MLP-reparameterized) prompts while preserving the same convergence guarantees. The empirical side positions the method against standard PEFT baselines (LoRA, VeRA, IA3, Prompt Tuning) on Open LLM benchmarks.

## Why It Matters / Open Questions

The paper elevates zero-initialized attention from an unexplained engineering trick to a theoretically grounded mechanism with provable polynomial sample complexity (vs. exponential for random-init), which could inform initialization choices in broader PEFT designs. The non-linear prompt extension offers practical flexibility (MLP reparameterization) without sacrificing convergence rates, and empirically yields 1–2% gains over linear prompts. However, the study is limited to unimodal LLaMA-7B/13B on four QA benchmarks with a single training set (Alpaca), leaving open whether the theoretical advantages persist for multi-modal models, larger architectures, or diverse task distributions. The optimal number of prompt embeddings per layer and the interpretability of non-linear prompts in deployment remain unexplored.

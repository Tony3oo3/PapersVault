## Problem

Prior LLM routing approaches generate only a single response from the selected model, so a small model's one-shot output rarely matches a large model's quality, causing routers to default to expensive models and miss potential cost savings. The paper addresses this by jointly deciding which model to use and how many test-time samples to draw, enabling small models to close the quality gap through best-of-n sampling while remaining cheaper than a single large-model call.
![Teaser figure](../imgs/ICML20250530/cropped_page1_idx0.webp)

## Input / Output

At inference the system receives a text query, a portfolio of K smaller LLMs with their per-token prices, and a reference model (e.g., GPT-4o). The 44M-parameter DeBERTa-v3-small router predicts a match probability for every (model, n) pair in O(K·N) forward passes, and the 300M-parameter proxy reward model scores each generated candidate. The final output is a single text response from one model (no ensembles or cascades), with the selected model identity and sample count n* determined by the cost-aware selection rule in Algorithm 1.

## Method

BEST-Route combines two components: (1) a lightweight proxy reward model trained with a pairwise ranking loss on worst/median/best response triples to select the best-of-n sample without expensive LLM-as-judge scoring, and (2) a cost-efficient multi-head router built on a shared DeBERTa-v3-small backbone with K×N sigmoid classification heads, each predicting the probability that a small model's best-of-n response matches the reference model's single response. At inference, the router scores all (model, n) combinations, the system filters those exceeding a user-set match-probability threshold, estimates the dollar cost of each valid combination using average output lengths and token prices, and selects the cheapest one. If no combination meets the threshold, the reference model is called once. The selected model then generates n* samples, and the proxy reward model picks the highest-scoring response as the final output.

## Results

On a 10K-example dataset spanning QA, coding, and safety tasks, BEST-Route achieves up to 60% cost reduction with only a 0.80% armoRM quality drop relative to always using GPT-4o. At the same 60% cost reduction level, the strongest baseline (N-label Routing) suffers a 5.08% quality drop, while N-class and Clustering-based routing achieve essentially 0% cost reduction. On the OOD MT-Bench evaluation, BEST-Route maintains its advantage with 1.59% quality drop at 60% cost reduction versus 5.89% for N-label Routing. The routing overhead is negligible: match probability prediction takes 0.04s and best-of-n sampling adds 0.58s at n=20, making the total overhead 18.7× faster than the fastest LLM (Llama-3.1-8b).

## Baselines & Comparisons

Against the three routing baselines from Srivatsa et al. (2024), BEST-Route dominates across all cost reduction levels. N-class Routing and Clustering-based Routing effectively default to GPT-4o for nearly all queries, yielding only 0.07% and 0% cost reduction respectively with no quality drop, offering no practical savings. N-label Routing is the only baseline that achieves meaningful cost reduction but at a steep quality cost: at 60% cost reduction it incurs a 5.08% armoRM drop versus BEST-Route's 0.80% (a 4.28% gap). Against Model Cascades (Yue et al., 2023), BEST-Route is superior by up to 6.46% in quality drop at 60% cost reduction (0.80% vs. 7.26% for exact-match cascading), because cascades invoke multiple LLMs per query and thus incur higher costs for equivalent quality. On the OOD MT-Bench, BEST-Route again outperforms N-label by 4.3% at 60% cost reduction (1.59% vs. 5.89% drop), confirming generalizability beyond the training distribution.

## Relation to Prior Work

This paper extends the LLM query routing line of work (Ding et al. 2024, Ong et al. 2024, Srivatsa et al. 2024) by jointly optimizing model selection and test-time compute allocation via best-of-n sampling, rather than treating routing as a pure model-selection problem. It builds on the binary routing framework of Ding et al. (2024) and generalizes it to a multi-model setting with a cost-efficient multi-head router (a single DeBERTa backbone with K×N lightweight heads) that replaces the expensive matrix-of-routers. The best-of-n sampling component draws on test-time optimal compute literature (Snell et al. 2024, Brown et al. 2024) but repurposes it within a routing context using a lightweight proxy reward model trained with pairwise ranking loss, avoiding the cost of LLM-as-a-judge scoring at inference time.

## Why It Matters / Open Questions

The 60% cost reduction with under 1% quality drop is practically significant for LLM service providers operating at scale, and the tunable threshold gives operators a direct cost-quality dial. The finding that routing to a specialized model (Codestral-22b) can actually exceed the reference model's quality while reducing cost suggests routing is not merely a cost-saving mechanism but a quality-enhancing one. Open questions include scalability to very large model pools (hundreds of LLMs), robustness of the proxy reward model to distribution shifts in response quality, and whether the average-output-length cost estimator remains accurate under diverse deployment conditions.

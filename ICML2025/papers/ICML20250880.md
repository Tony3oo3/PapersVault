## Problem

Existing 3D open-vocabulary segmentation methods rely on fixed-pattern class names and project semantic features onto 2D images for matching, which cannot handle free-form natural language expressions encoding spatial relationships (e.g., 'the red object on the left'). Moreover, these 2D-rendering-based approaches lack explicit 3D spatial reasoning, making them unable to segment objects that are occluded or entirely invisible in a novel view—a critical limitation for embodied AI applications.
![Teaser figure](../imgs/ICML20250880/cropped_page0_idx0.webp)

## Input / Output

At test time, the model receives a complex natural language referring expression (average 13.6 words, containing spatial relations and fine-grained attributes) and a novel-view RGB image, and produces a 2D segmentation mask rendered from the 3D Gaussian scene. Training uses multi-view RGB images with pseudo masks generated by Grounded SAM via a confidence-weighted IoU selection strategy, requiring no manual 3D mask annotations. The key distinction from 2D referring segmentation is that the target object may be partially or fully occluded in the query view, and the model must recover it using 3D scene knowledge learned from other training views.

## Method

ReferSplat assigns each 3D Gaussian a learned referring feature vector, forming 3D Gaussian Referring Fields that directly interact with BERT-encoded word features via element-wise multiplication (rather than the retrieval-based 2D feature matching used by LangSplat). A Position-aware Cross-Modal Interaction module extracts Gaussian position embeddings via an MLP on center coordinates, infers text position features through cross-modal attention over Gaussian positions, and refines referring features using position-guided attention that fuses spatial and semantic cues. Gaussian-Text Contrastive Learning selects top-τ percentile Gaussians by text response as positive examples and applies an object-wise InfoNCE loss to disambiguate semantically similar expressions targeting different objects. The total loss combines binary cross-entropy on rendered masks with the contrastive term, and a two-stage optimization refines masks by using first-stage rendered outputs to supervise a second model.

## Results

On the newly proposed R3DGS task (Ref-LERF), ReferSplat achieves 29.2 mIoU, outperforming the strongest baseline GOI (20.5) by 8.7 points and the 2D method Grounded SAM (15.8) by 13.4 points. On the 3D open-vocabulary segmentation benchmark LERF-OVS, ReferSplat reaches 55.4 mIoU, surpassing the previous best LangSplat (51.4) by 4.0 points. On the 3D-OVS benchmark, it achieves 94.1 mIoU, edging out LangSplat (93.4) by 0.7 points. ReferSplat also reports the shortest training time (58 min) and competitive inference speed (26.8 FPS) among compared 3D methods.

## Baselines & Comparisons

ReferSplat wins against all seven baselines on every benchmark. On the primary R3DGS task (Ref-LERF), it outperforms the closest 3D competitor GOI by 8.7 mIoU (29.2 vs. 20.5), the 2D method Grounded SAM by 13.4 mIoU, and the adapted LangSplat by 15.3 mIoU. GS-Grouping, while competitive on the ramen scene (27.9), collapses on other scenes (6.3 on kitchen), yielding only 14.4 average mIoU versus ReferSplat's 29.2. On LERF-OVS, ReferSplat (55.4) beats LangSplat (51.4), GOI (50.6), LEGaussians (46.6), GS-Grouping (46.3), and Feature-3DGS (45.7) by 4.0, 4.8, 8.8, 9.1, and 9.7 mIoU respectively. On 3D-OVS, the margin over LangSplat narrows to 0.7 mIoU (94.1 vs. 93.4), but ReferSplat still leads all other methods by at least 3.5 mIoU. The consistent wins across both the new referring task and established open-vocabulary benchmarks indicate that the 3D Gaussian Referring Fields, position-aware cross-modal interaction, and contrastive learning components transfer effectively beyond the specific R3DGS setting.

## Relation to Prior Work

This paper departs from the open-vocabulary 3DGS segmentation line (LangSplat, Feature-3DGS, LEGaussians, GS-Grouping, GOI), which relies on fixed-pattern class names and 2D rendered feature matching, by introducing free-form natural language referring expressions that encode spatial relationships. It also extends the 2D/3D point-cloud referring segmentation literature (ScanRefer, Multi3DRefer, Grounded SAM) into the 3DGS domain, where the explicit Gaussian representation enables reasoning about occluded objects across views. The key architectural departure is the 3D Gaussian Referring Field, which assigns per-Gaussian language-aware features and computes text response directly in 3D space, rather than projecting semantic features onto 2D images for retrieval-based matching as in LangSplat.

## Why It Matters / Open Questions

R3DGS is a practically important capability for embodied AI, autonomous driving, and VR/AR, where a system must localize objects described by arbitrary spatial language in a 3D scene, including objects not visible in the current view. The main limitation is scale: Ref-LERF contains only 4 scenes and 295 expressions, making generalization claims tentative, and the pseudo-mask quality (~50% mIoU against manual annotations) introduces a ceiling on achievable performance. Open questions include whether the position-aware interaction and contrastive learning components transfer to larger, more diverse datasets, whether dynamic scenes (4DGS) can be handled, and whether 3D visual grounding can be integrated for precise object size estimation.

## Problem

Existing adversarial attacks on web agents either require impractical white-box gradient access or depend on manually crafted injection prompts with limited scalability and flexibility. No prior work provides an automated, black-box framework that can efficiently generate targeted adversarial prompts while maintaining stealthiness (invisible to users) and controllability (easy retargeting without re-optimization).
![Teaser figure](../imgs/ICML20252770/cropped_page1_idx0.webp)

## Input / Output

The method takes the raw HTML content of a target webpage and a desired adversarial action triplet (operation, target argument, HTML element) as input. It produces a short adversarial prompt string containing a {target_argument} placeholder, which is injected into a non-rendered HTML attribute (e.g., aria-label) so the rendered screenshot remains visually identical to the original page. The placeholder design enables deterministic retargeting via a simple string-replacement function D without any re-optimization against the agent.

## Method

AdvAgent trains a generative prompter model (initialized from Mistral-7B-Instruct-v0.2) using a two-stage RLAIF pipeline. Stage 1 performs supervised fine-tuning on adversarial prompts that successfully attacked the black-box web agent, establishing a baseline distribution of effective injections. Stage 2 applies Direct Preference Optimization (DPO) over paired positive and negative prompts, where the reference policy is the SFT model, allowing the prompter to learn subtle linguistic distinctions (e.g., 'you' vs. 'I') that determine attack success. The training data is collected automatically by using GPT-4 as an initial attack prompter to generate diverse candidate injections, then evaluating each against the target agent to obtain binary success/failure labels. This feedback-driven design eliminates the need for gradient access and outperforms transfer-based approaches, achieving 97.5% ASR against GPT-4V-powered SeeAct versus 0% for GCG transfer.

## Results

AdvAgent achieves a step-based attack success rate (ASR) of 97.5% ± 2.0 against GPT-4V-powered SeeAct and 99.8% ± 0.3 against Gemini 1.5-powered SeeAct across 440 tasks in 4 domains (Finance, Medical, Housing, Cooking) from the Mind2Web dataset. Even after applying three common prompt-based defenses (Random Sequence, Instruction, Sandwich), AdvAgent maintains an ASR above 88.8%. The method also demonstrates high controllability, achieving 98.5% ASR when retargeting successful attacks to unseen targets without re-optimization.

## Baselines & Comparisons

AdvAgent decisively outperforms all three baselines across both backend models. GCG (Zou et al., 2023), a white-box gradient-based method, achieves 0% ASR in the black-box transfer setting, as its adversarial suffixes optimized on LLaVA-NeXT fail to transfer to proprietary VLM agents. Agent-Attack (Wu et al., 2024b), which relies on manually crafted injection prompts, reaches only 45.4% mean ASR on GPT-4V and drops to 25.0% on Gemini 1.5, revealing poor cross-model generalization. InjecAgent (Zhan et al., 2024), which uses GPT-4 to auto-generate injection prompts, is the strongest baseline at 64.3% (GPT-4V) and 28.0% (Gemini 1.5), yet still trails AdvAgent by 33.2 and 71.8 percentage points respectively. The gap widens dramatically on Gemini 1.5, where AdvAgent's RLAIF-based training with model-specific feedback achieves near-perfect ASR while all baselines struggle, underscoring the critical advantage of incorporating black-box agent feedback over transfer-based or manually designed approaches.

## Relation to Prior Work

This paper extends the line of adversarial attacks on LLM-based agents by moving from white-box gradient-based optimization (GCG) and manually crafted injection prompts (Agent-Attack, WiPI) to an automated black-box setting. It repurposes DPO (Rafailov et al., 2024) from its original alignment context into an adversarial prompt-generation pipeline, using black-box agent feedback as the reward signal. The key conceptual departure from prior LLM red-teaming work (InjecAgent, GCG) is the explicit targeting of multimodal web agents that consume both HTML and rendered screenshots, combined with structured HTML hiding and placeholder-based controllability constraints that prior agent-attack methods did not enforce.

## Why It Matters / Open Questions

The near-perfect attack success rates (97.5–99.8%) against SOTA web agents, combined with the finding that standard prompt-injection defenses reduce ASR by only ~10%, expose a critical and underappreciated vulnerability class in a technology being rapidly deployed in finance, healthcare, and e-commerce. The controllability result—where a single successful injection can be retargeted to arbitrary new arguments via simple string substitution—means the attack surface scales with minimal additional cost. Open questions include whether more sophisticated defenses (e.g., input sanitization, element-level provenance tracking) can close the gap, whether the attacks generalize beyond SeeAct to other agent architectures, and how to formalize robustness guarantees for web agents under adversarial HTML perturbations.

## Problem

Polygon-based instance segmentation methods rely on 2D vertex coordinate regression, which requires precise target assignment between predicted and ground-truth contour points. Existing assignment strategies—polar (limited to star-convex shapes), Cartesian (lacks global context, causing matching ambiguities), and hybrid (does not fundamentally resolve distance-based limitations)—all struggle with non-convex structures and topological consistency. This paper addresses these gaps by introducing a frequency-domain matching mechanism that eliminates the need for rasterization or heuristic approximations.

## Input / Output

The model takes a single RGB image (resized to 800×800 at inference) and outputs, for each detected instance, a class label and a set of 128 polygon contour vertices in 2D coordinate space. Unlike pixel-mask methods, the output is a compact ordered sequence of boundary points that can be directly used for vector map generation or remote sensing without rasterization. Multi-polygon instances are merged into a single closed contour via auxiliary edges before Fourier encoding.

## Method

EFDTR is a two-stage regression framework built on a DETR-style architecture with RT-DETR's Hybrid Feature Fusion backbone. The first stage (EFD decoder, 6 layers) predicts first-order Elliptic Fourier Descriptors—essentially ellipse parameters (4n+1 coefficients)—to capture coarse global contour topology, using denoising queries and deformable attention over P3–P5 features. The second stage (polygon decoder, 3 layers) refines 128 contour points via phase-based target assignment: each predicted point is snapped to the nearest ground-truth phase in the Fourier domain, resolving spatial ambiguities that Euclidean matching cannot. Multi-polygon instances are connected into a single closed contour using a minimum spanning tree over inter-polygon distances, and the Fourier series is normalized so the first-order coefficient aligns with the positive x-axis. Training uses VFL for classification, L1 loss for EFD parameter regression, and Smooth-L1 loss for phase-aligned polygon vertex regression, with a group-based feature sampling strategy (groups of 4) to reduce computational overhead.

## Results

On COCO val2017 with a ResNet-50 backbone, EFDTR achieves 43.6 AP (64.8 AP50, 47.2 AP75), outperforming all prior polygon-based methods by a wide margin (e.g., +13.1 AP over DeepSnake, +11.5 AP over PolarMask). With a ResNet-101 backbone, EFDTR reaches 45.1 AP, surpassing Mask2Former (44.2 AP) and DynaMask (39.0 AP) while remaining competitive with Mask DINO (46.0 AP on ResNet-50). EFDTR also shows strong performance on small objects (23.4 APS with ResNet-50) and large objects (64.1 APL), demonstrating balanced accuracy across object scales.

## Baselines & Comparisons

EFDTR decisively outperforms all polygon-based baselines on COCO val2017: it surpasses DeepSnake (30.5 AP) by 13.1 AP, PolarMask (32.1 AP) by 11.5 AP, DANCE (34.5 AP) by 9.1 AP, and BoundaryFormer (36.1 AP) by 7.5 AP with ResNet-50. Against mask-based methods, EFDTR (43.6 AP, R50) exceeds Mask R-CNN (42.5 AP) by 1.1 AP but trails Mask DINO (46.0 AP) by 2.4 AP. With ResNet-101, EFDTR (45.1 AP) surpasses Mask2Former (44.2 AP) by 0.9 AP and DynaMask (39.0 AP) by 6.1 AP, while remaining within 0.9 AP of Mask DINO's ResNet-50 result. Notably, EFDTR achieves these gains using only polygon supervision (no mask or edge labels), whereas several baselines rely on additional mask or edge supervision signals.

## Relation to Prior Work

EFDTR builds on the DETR-family decoder architecture (RT-DETR's Hybrid Feature Fusion backbone, DINO's denoising queries, and BoundaryFormer's two-stage deformable-attention decoder) but departs fundamentally from prior polygon-based methods in how it formulates the regression target. Where PolarMask, DANCE, E2EC, and BoundaryFormer rely on polar, Cartesian, or hybrid coordinate-based target assignment—each suffering from geometric constraints or matching ambiguity—this paper introduces Elliptic Fourier Descriptor phase as a bijective, frequency-domain parameterization that resolves vertex-to-target correspondence without rasterization. The multi-polygon merging via minimum spanning tree draws on PolygonGNN's graph-based contour representation, while the core EFD mathematics traces back to Kuhl & Giardina (1982).

## Why It Matters / Open Questions

EFDTR closes a substantial gap between polygon-based and mask-based instance segmentation (43.6 AP vs. 37.8 for the prior best polygon method, SharpContour), making vector contour outputs a more competitive alternative for applications requiring explicit shape representations (autonomous driving vector maps, medical boundary delineation). The phase-based assignment is a clean, generalizable solution to a long-standing ambiguity problem in contour regression that could transfer to other shape-prediction tasks. Open questions include whether the approach scales beyond COCO to more complex or 3D contours, how well the auxiliary-edge merging handles highly disjoint multi-polygon instances (acknowledged as a limitation), and whether the first-order EFD sufficiency finding generalizes to shapes with very high curvature complexity.

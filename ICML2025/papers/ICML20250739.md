## Problem

Deep learning models encode all knowledge statically in their weights, making them extremely difficult to update with new data, to unlearn specific samples, or to interpret individual decisions. This paper asks whether decomposing classification into a frozen representation plus an explicit, editable visual memory can provide the flexibility that end-to-end trained classifiers fundamentally lack.
![Teaser figure](../imgs/ICML20250739/cropped_page1_idx0.webp)

## Input / Output

The system takes a single RGB image, encodes it with a frozen pre-trained encoder (DinoV2 ViT or CLIP ViT) to produce a fixed-dimensional feature vector, and retrieves k nearest neighbors (k up to 100) from a vector database using cosine similarity. The output is a single class label determined by weighted aggregation of neighbor labels. The memory stores only feature vectors (1–3% of raw dataset storage) rather than images, and retrieval at 1M scale runs at ~500–600 QPS on CPUs with ~2 ms per query.

## Method

The core architecture separates representation from memory: a frozen pre-trained encoder (DinoV2 or CLIP) maps images to an embedding space, and a vector database (searched via ScaNN) stores (feature, label) pairs for fast kNN retrieval. The key technical contribution is RankVoting, a parameter-free aggregation strategy that assigns each neighbor a weight of 1/(α + rank) with α=2, which avoids the overconfidence-in-distant-neighbors problem that causes softmax, distance, and plurality voting to degrade as k increases. The system achieves 83.6% ImageNet top-1 with RankVoting (matching softmax voting) and 88.5% with Gemini 1.5 Flash re-ranking, outperforming both kNN and linear probing baselines. Because the memory is an explicit database, adding new classes is a simple insert operation, machine unlearning is a delete operation, and memory pruning (hard or soft) can downweight or remove low-quality samples based on their measured contribution to wrong decisions.

## Results

On ImageNet-1K validation, the best kNN configuration (DinoV2 ViT-L14 with RankVoting) achieves 83.6% top-1 accuracy, matching the DinoV2 paper's SoftmaxVoting kNN (83.5%) while being more stable across k. With Gemini 1.5 Flash re-ranking over 50 nearest neighbors, the system reaches 88.5% top-1 accuracy, surpassing both the kNN baseline (83.5%) and linear probing (86.3%). On OOD benchmarks, scaling memory from ImageNet-1K to JFT-3B pseudo-labeled data improves accuracy across all five OOD datasets (e.g., ImageNet-A: 58.8% → 61.1%, ImageNet-R: 62.8% → 73.7%), and Gemini re-ranking further lifts these to 69.6% and 81.4% respectively.

## Baselines & Comparisons

Against the DinoV2 paper's kNN SoftmaxVoting baseline (83.5%), the proposed RankVoting matches at 83.6% while being more stable across the number of neighbors k (plateauing rather than decaying), and the Gemini re-ranking variant substantially outperforms it at 88.5% (+5.0%). Against the CLIP paper's zero-shot baseline (75.3%), the visual memory with RankVoting on CLIP ViT-L14 features achieves 79.9% (+4.6%), demonstrating that retrieval-based classification with a memory bank significantly improves over the original zero-shot protocol. Compared to linear probing (86.3% for DinoV2 ViT-L14), standard kNN remains below (83.6%), but the Gemini re-ranking variant closes and surpasses this gap (88.5%, +2.2%), suggesting that a flexible memory system can match or exceed the accuracy of a fixed classifier while offering capabilities (unlearning, interpretability, lifelong learning) that linear probing cannot provide.

## Relation to Prior Work

This paper deliberately builds on well-established components—SSL feature encoders (DinoV2, CLIP), kNN classification, and fast approximate nearest neighbor search (ScaNN)—rather than proposing a new architecture, framing the contribution as a conceptual reorganization that separates representation (fixed encoder) from knowledge (editable database). It extends the kNN-based visual memory line of work (Nakata et al. 2022 at ImageNet scale; Khandelwal et al. 2019 for language) to the billion-scale regime and introduces RankVoting, a simple power-law aggregation that fixes a paradox where standard voting methods (plurality, distance, softmax) lose accuracy as more neighbors are added. The conceptual framing draws on exemplar theory from cognitive psychology and the long history of instance-based learning, positioning the work as a 'marriage' of deep representations with database-style memory rather than a departure from either tradition.

## Why It Matters / Open Questions

The paper's strongest contribution is conceptual: it demonstrates that a simple retrieval-based memory can provide perfect machine unlearning (by design), interpretable and attributable decisions, and flexible lifelong learning without retraining—capabilities that are extremely difficult or impossible with end-to-end trained classifiers. Key limitations include a persistent accuracy gap to linear probing (83.6% vs 86.3% on ImageNet), reliance on a fixed encoder that may fail under strong distribution shift, and evaluation limited to classification. Open questions include whether the model-size/memory-size trade-off can be exploited to reduce compute, whether the approach extends to detection, segmentation, and generation, and whether smaller encoders can be trained specifically to complement a large memory database.

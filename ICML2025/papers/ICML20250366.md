## Problem

Deep neural networks can either learn meaningful features or guarantee global convergence, but no existing parametrization achieves both simultaneously. NTK parametrization freezes features at initialization (no feature learning), while mean field parametrization permits feature evolution but suffers from feature collapse in networks deeper than four layers. This paper asks whether a parametrization exists under which features substantially deviate from initialization yet remain linearly independent, thereby ensuring any convergent trajectory reaches a global minimum.

## Input / Output

The theoretical analysis targets L-layer MLPs in the infinite-width limit, trained via SGD on binary classification (airplane vs. automobile from CIFAR-10, flattened to 3072-dimensional vectors). The primary output is a non-degeneracy guarantee: pre- and post-activation features in every layer remain linearly independent at all training times, and any convergent trajectory must reach a global minimum. Empirically, the paper measures feature change (relative L2 norm from initialization) and feature diversity (minimum eigenvalue of the feature Gram matrix) across hidden-layer widths from 8 to 4096, using 10 training samples per class.

## Method

The paper analyzes infinite-width L-layer MLPs under Maximal Update Parametrization (μP) using the tensor program framework, representing hidden states as Z random variables whose evolution decomposes into a Gaussian increment plus a history-dependent term. The key insight is that the Gaussian processes induced by forward and backward propagation preserve invariant covariance structures across adjacent layers throughout training, even as individual features evolve substantially. A two-level filtration (F_t for completed iterations, G_t for the in-progress forward pass) enables a four-step inductive proof over layers and time: base case at the first hidden layer, forward propagation to deeper layers, backward propagation from the output layer, and backward propagation to remaining layers. At each step, the proof shows that if a linear combination of Gaussian feature increments degenerated, the corresponding combination of original features would also degenerate, contradicting the 'GOOD' activation function property (satisfied by sigmoid, tanh, SiLU) that prevents non-trivial compositions from being constant. This establishes linear independence of features at all layers and times, forcing any convergent trajectory to a global minimum.

## Results

The paper's main theoretical result (Theorem 4.5) proves that under μP, pre-activation and post-activation features in every layer of an L-layer infinite-width MLP remain linearly independent at all training times, and Corollary 4.6 shows that any convergent point is a global minimum. Empirically, on CIFAR-10 with 3 hidden-layer MLPs (widths 8–4096, SiLU activation, 1000 SGD steps), μP maintains substantially higher minimum eigenvalues of the feature Gram matrix as width increases, while IP exhibits catastrophic eigenvalue collapse (dropping to ~10⁻⁷ at Layer 3) and NTP/SP show steady decay. The feature change metric ‖h(x)−h⁰(x)‖₂/‖h⁰(x)‖₂ confirms that only μP achieves both substantial feature evolution and preserved feature diversity simultaneously.

## Baselines & Comparisons

The paper compares four parametrization schemes: Standard Parametrization (SP), Neural Tangent Parametrization (NTP), Integrable Parametrization (IP), and μP. SP and NTP both fail to perform meaningful feature learning — features remain essentially at their random initialization (small feature change in Figure 1 left panel) — though they preserve feature richness (non-vanishing eigenvalues). IP achieves feature learning but suffers from severe feature collapse: the minimum eigenvalue of the feature Gram matrix decays dramatically with width, reaching ~10⁻⁷ at Layer 3 (Figure 7), indicating the features span a vanishingly low-dimensional subspace. μP is the only scheme that simultaneously achieves substantial feature evolution (large feature change) and maintains rich, linearly independent features (high minimum eigenvalues that do not decay with width), as confirmed by both the Gram matrix eigenvalue analysis (Figures 1–2) and the full eigenvalue spectrum (Figures 5–16). This advantage is robust across activation functions: the same pattern holds for Tanh (Figure 3) and ReLU (Figure 4), though the theoretical guarantee formally applies to smooth activations like SiLU and Tanh.

## Relation to Prior Work

This paper extends the Tensor Program framework of Yang & Hu (2020, 2021) and Yang (2019), which introduced the μP parametrization and Z-variable representation for infinite-width networks, by proving a previously open property: that features remain linearly independent throughout training under μP. It departs from the NTK line of work (Jacot et al., 2018; Allen-Zhu et al., 2019), which proves global convergence but only in the lazy regime where features never move, and from mean field analysis (Mei et al., 2018; Chizat & Bach, 2018), which allows feature learning but suffers from feature collapse beyond 3–4 layers. The key technical departure is the use of a two-level filtration and Gaussian process covariance invariance across layers to track feature non-degeneracy through both forward and backward passes simultaneously.

## Why It Matters / Open Questions

This resolves a fundamental open question in deep learning theory: whether a network can simultaneously learn task-relevant features that substantially deviate from initialization and still be guaranteed to converge to a global minimum. The result is limited to MLPs under infinite-width and smooth 'GOOD' activations (sigmoid, tanh, SiLU), so it does not directly cover ReLU, transformers, or finite-width settings, and it provides no convergence rate. Open directions the authors highlight include extending the framework to attention mechanisms, deriving convergence rates, connecting feature non-degeneracy to generalization bounds, and understanding why ReLU networks empirically exhibit similar behavior despite violating the smoothness assumptions.

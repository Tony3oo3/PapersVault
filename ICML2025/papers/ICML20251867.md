## Problem

Prior theoretical work on in-context learning (ICL) of single-index models with transformers (Oko et al., 2024b) showed that pretrained transformers implement kernel-like algorithms with inference-time sample complexity r^Θ(deg(σ*)), matching non-adaptive fixed-basis methods. It remained unclear whether transformers could perform true inference-time feature learning—adaptively extracting the task-specific feature vector β from test prompts—and whether the nonlinear softmax attention mechanism could surpass the statistical barrier imposed by Correlational Statistical Query (CSQ) lower bounds.

## Input / Output

The model receives a prompt of N in-context example pairs (x_i, y_i) with x_i ~ N(0, I_d) and y_i = σ*(⟨β, x_i⟩) + ζ_i, followed by a query vector x ∈ R^d, and outputs a scalar prediction of σ*(⟨β, x⟩). The feature vector β is drawn uniformly from the unit sphere in an r-dimensional subspace of R^d and varies across tasks, so the model must identify β solely from the in-context examples at inference time without any parameter updates. The link function σ* is a fixed polynomial (e.g., He_3) shared across all tasks.

## Method

The paper analyzes a single-layer transformer with softmax attention whose output takes the form Σ_j a_j σ(v_j · [Σ_i y_i e^{y_i/ρ} e^{x_i^T Γ x/ρ}] / [Σ_i e^{y_i/ρ} e^{x_i^T Γ x/ρ}] + b_j). The key insight is that the exponential in softmax attention serves a dual role: (i) the term e^{x_i^T Γ x/ρ} generates a full Hermite polynomial expansion in x, enabling correlation-based extraction of ⟨β, x⟩ from the nonlinearly transformed label signal e^{y_i/ρ}, and (ii) the transformation e^{y_i/ρ} reduces the effective information exponent of σ* to its generative exponent ge(σ*) ≤ 2, decoupling inference complexity from both deg(σ*) and ie(σ*). Pretraining is two-stage: a single gradient descent step on the attention matrix Γ (with ℓ₂ regularization) captures E[ββ^T] at cost d^Θ(ie(σ*)) tasks, and a subsequent ridge regression on the MLP output weights fits the link function. The resulting inference-time sample complexity is r^Θ(ge(σ*)), which for polynomial links is at most r^O(1), strictly improving over both kernel methods (r^Θ(deg(σ*))) and CSQ learners (r^Θ(ie(σ*))).

## Results

The main theoretical result (Theorem 1) establishes that a single-layer softmax-attention transformer pretrained via one gradient step on the attention matrix achieves inference-time sample complexity of Õ(r^{3ge(σ*)/2}), where ge(σ*) ≤ 2 for any polynomial link function, independent of both deg(σ*) and ie(σ*). Empirically, a 6-layer GPT-2 pretrained on the degree-3 single-index task y = He₃(⟨β,x⟩) achieves an estimated inference-time sample complexity scaling of n ≈ d^{1.1}, substantially outperforming the kernel lower bound of d³ and the CSQ lower bound of d^{1.5}. The pretraining task and context length scale as Õ(r² d^{ie(σ*)+2}), matching the CSQ rate for the pretraining phase.

## Baselines & Comparisons

The primary baseline is Oko et al. (2024b), which also studies ICL of single-index models with transformers but achieves an inference-time sample complexity of r^{Θ(deg(σ*))}, matching kernel methods on the r-dimensional subspace. This work improves the inference complexity to r^{Θ(ge(σ*))}, where ge(σ*) ≤ 2 for polynomial links, yielding a strict improvement in all regimes (e.g., for a degree-3 Hermite link with ie=3, the inference complexity drops from r^{Θ(3)} to r^{Θ(2)}). Additionally, the paper removes the low-dimensionality assumption r ≲ √d required by Oko et al., extending the result to arbitrary r ≤ d. Empirically, the pretrained GPT-2 model outperforms a Gaussian RBF kernel ridge regression trained from scratch on each test prompt: the kernel method's error deteriorates rapidly with dimension (consistent with the d³ lower bound), while the transformer maintains a much flatter dimension scaling (estimated d^{1.1}). The transformer also surpasses the CSQ lower bound of d^{1.5} for the degree-3 Hermite link, confirming that softmax attention's nonlinear label transformation enables SQ-level statistical efficiency in-context.

## Relation to Prior Work

This paper extends the in-context learning (ICL) framework for single-index models established by Oko et al. (2024b), which showed that pretrained transformers implement kernel-like algorithms with inference-time sample complexity r^Θ(deg(σ*))—matching non-adaptive methods. The key conceptual departure is showing that the exponential nonlinearity in softmax attention acts as an implicit nonlinear label transformation, reducing the effective information exponent to the generative exponent ge(σ*) ≤ 2, thereby breaking the CSQ lower bound that previously governed adaptive learners. The optimization analysis draws on the one-gradient-step feature learning theory of Ba et al. (2022) and Damian et al. (2022), while the Hermite-coefficient tracking for the exponential transformation builds on the generative exponent framework of Lee et al. (2024).

## Why It Matters / Open Questions

This is the first theoretical result showing that a standard transformer architecture (with softmax attention) can implement in-context algorithms at the SQ level of statistical efficiency, surpassing both kernel methods and CSQ learners without any architectural modification. The insight that softmax attention's exponential naturally provides the label transformation previously requiring explicit data reuse or loss modification in standard supervised settings is a clean architectural explanation for why transformers may outperform kernel methods in ICL. Open questions include whether pretraining complexity can also be reduced from d^Θ(ie(σ*)) to d^Θ(ge(σ*)), extension to non-polynomial link functions and multi-index models, and the unresolved interaction between support memorization during pretraining and inference-time feature extraction.

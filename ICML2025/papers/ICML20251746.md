## Problem

Anytime constraints, which require cumulative cost to remain within budget at every time step (not just in expectation), have been studied only in single-agent reinforcement learning. This paper extends them to the multi-agent Markov game setting and asks for what class of constrained Markov games the corresponding anytime-constrained equilibrium (ACE) can be computed in polynomial time. The paper establishes NP-hardness even for two-player zero-sum games with a single state, then provides fixed-parameter tractable and polynomial-time approximation algorithms.

## Input / Output

The method takes a tabular finite-horizon n-player constrained Markov game (states, joint actions, transition/reward/cost distributions, horizon H) and a budget vector B, and produces an anytime-constrained subgame-perfect equilibrium policy or an infeasibility certificate. The output policy is history-dependent in the original game but is stored compactly as a Markovian policy over the augmented (state, cumulative-cost) state space, requiring O(HSAD_G) space. Intermediate outputs include the set of feasible (state, cumulative-cost) pairs and feasible joint actions at each time step, which are computed via an AND/OR tree traversal.

## Method

The approach proceeds in three stages. First, an AND/OR feasibility tree is constructed where (time, state, cost) triples are OR nodes and actions are AND nodes; the TRUE subtree exactly characterizes all feasibly realizable histories, computed in O((HSAD_G)²) time. Second, the anytime constraint is reduced to a per-time action constraint by augmenting states with cumulative costs, yielding an action-constrained Markov game whose stage games may have non-product feasible action sets (non-normal-form). Third, a backward-induction algorithm solves each stage game via a modified correlated-equilibrium linear program (CLP) that restricts the joint strategy support to the feasible action set, producing a Markov-perfect equilibrium. The overall algorithm is FPT in cost precision d (polynomial when d = O(log|G|) with constant n), and a cost-truncation-and-rounding approximation yields ε-additive or ε-relative feasible equilibria in poly(|G|, 1/εⁿ) time when the maximum supported cost is polynomially bounded by the budget.

## Results

The paper establishes that computing a feasible anytime-constrained policy is NP-hard even for two-player zero-sum acMGs with S=1, A=2, and deterministic non-negative integer costs (Proposition 2.7). The main algorithmic result is a fixed-parameter tractable (FPT) algorithm for computing subgame-perfect ACE in the cost precision d, running in poly(|G|, D_G) time where D_G ≤ H^n · 2^{(d+1)n}; this yields polynomial time when d = O(log|G|) with n constant or d = O(1) with n arbitrary (Theorem 5.3). For the approximation setting, the algorithm runs in O(poly(|G|, ‖c^max − B‖_∞^n / ℓ^n)) time, giving O(poly(|G|, 1/ε^n)) for ε-additive or ε-relative approximate ACE when c^max ≤ poly(|G|)·|B| (Corollaries 6.7–6.8). Given the NP-hardness, these guarantees are stated to be best possible under P ≠ NP.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The paper positions its contributions against prior single-agent anytime-constrained methods: McMahan (2024) handles only a single constraint and does not generalize to multi-agent settings, while McMahan and Zhu (2024) requires state augmentation with state-dependent action spaces that, in the multi-agent case, fail to form product spaces (making each stage game a non-normal-form game with no known efficient solver). The paper also notes that standard expectation-constrained approaches can arbitrarily violate anytime constraints, and that typical distributed learning or self-play methods fail because a player's action feasibility depends on others' choices. The key theoretical contribution over prior work is the reduction from anytime-constrained MGs to action-constrained MGs (which may have non-product action spaces) and the first efficient LP-based solver for such games (Theorem 5.2), which no prior method provides.

## Relation to Prior Work

This paper extends the single-agent anytime-constrained reinforcement learning framework of McMahan and Zhu (2024) to the multi-agent Markov game setting, introducing the anytime-constrained equilibrium (ACE) as a solution concept. It departs from prior constrained game work (Altman and Shwartz, 2000; Chen et al., 2022) which focused on expectation-based or regret-based constraints, by requiring that cumulative costs never exceed a budget at any time step. A key technical departure is the development of a new theory for action-constrained Markov games, where the feasible joint action space at each state need not be a product space, requiring a modified LP formulation that prior single-agent state-augmentation approaches cannot handle.

## Why It Matters / Open Questions

This work provides the first complete computational theory for anytime-constrained multi-agent games, establishing that the problem is NP-hard even for trivially simple games (single state, two actions) while giving the first FPT and polynomial-time approximation algorithms. The action-constrained Markov game framework is of independent interest and opens a path for solving other non-normal-form sequential games. Open questions include extending to infinite-horizon discounted settings, developing learning algorithms (rather than planning algorithms) for action-constrained games, and understanding whether the cost-precision parameter can be further relaxed in practice.

## Problem

Recurrent LLMs like xLSTM offer linear compute scaling and constant memory during inference, making them ideal for fast test-time compute, but the xLSTM architecture had only been validated up to 1.3B parameters and 300B tokens, leaving open whether it can match Transformer quality at the 7B scale. Additionally, the original xLSTM block design (pre-up-projection with channel-wise convolutions and small projection layers) suffered from low GPU utilization and high memory usage that prevented efficient large-scale training.

## Input / Output

The model consumes a token sequence (up to 8192 tokens standard, 32K for the long-context variant) using the GPT-NeoX-20B tokenizer (vocab size 50257) and autoregressively generates tokens one at a time. A key property is that the recurrent memory state (a d_qk × d_hv matrix per head per layer, totaling ~134 MB in float32 for the 7B model) remains constant regardless of sequence length, unlike Transformer KV caches that grow linearly. During training, sequences are packed with end-of-document tokens that reset the mLSTM memory states to prevent information leakage between documents.

## Method

xLSTM 7B replaces the original pre-up-projection block with a standard post-up-projection structure where the mLSTM cell operates in the model's embedding dimension (4096) followed by a SwiGLU feed-forward layer, increasing the proportion of highly optimized matrix-multiplication FLOPs and reducing GPU memory. The architecture uses 32 blocks with 8 mLSTM heads (d_hv=512, d_qk=256), discards channel-wise convolutions and learnable skip connections in favor of dense linear QKV projections, and applies per-head independent gate computations to enable standard tensor-parallelism. For training stability at 7B scale, the paper introduces tanh-based soft-capping (a=15) on input and forget gate pre-activations, a=30 soft-capping on output logits, RMSNorm (instead of LayerNorm) for pre-norm, and a negative input gate bias initialization of −10 to suppress gradient norm spikes. Fused Triton GPU kernels for the recurrent generation mode keep intermediate results on-chip, and the model is trained on 2.3T DCLM tokens with 128 H100 GPUs using FSDP, achieving a 3.5× training speedup over the original xLSTM architecture while matching its language modeling quality.

## Results

On the Huggingface Leaderboard v2, xLSTM 7B achieves an average score of 0.260 across BBH, MMLU-Pro, Math, MUSR, GPQA, and IFEval, placing it in the mid-range among 7B-scale models. The long-context variant (xLSTM 7B LCTX) achieves 0.257 average and reaches 20% average accuracy on RULER at 131K context length despite being trained only up to 32K. In speed benchmarks on a single H100 GPU, xLSTM 7B is ~50% faster in text generation than Mamba models, achieves the fastest time-to-first-token across all prefill lengths, and delivers ~70% higher prefill throughput than Codestral Mamba, while maintaining constant GPU memory regardless of sequence length.

## Baselines & Comparisons

On the Huggingface Leaderboard v2 average, xLSTM 7B (0.260) outperforms Llama-2-7B (0.241), OLMo-7B (0.225), RWKV-v5-Eagle-7B (0.214), and RWKV-v6-Finch-7B (0.230), and roughly ties MambaCodestral-7B (0.261). It trails stronger baselines including Llama-3.1-8B (0.275), DCLM-7B (0.282), Falcon-Mamba-7B (0.290), Gemma-7B (0.292), Zamba2-7B (0.336), Gemma-2-9B (0.346), and Qwen2.5-7B (0.379), though the authors note several of these benefited from substantially larger or better-curated training data. On RULER long-context evaluation, xLSTM 7B LCTX achieves competitive performance with state-space models (Falcon-Mamba, Codestral-Mamba) and outperforms RWKV-5/6, while Llama-3.1-8B (heavily fine-tuned to 131K) remains the strongest baseline. The paper's primary differentiator is inference speed: xLSTM 7B achieves ~50% faster generation than Mamba models, the fastest time-to-first-token at all prefill lengths, ~70% higher prefill throughput than Codestral Mamba, and constant GPU memory usage (vs. linearly growing KV-cache for Transformers), making it the fastest 7B LLM in their benchmarks.

## Relation to Prior Work

This paper scales the xLSTM architecture (Beck et al., 2024) from 1.3B to 7B parameters, building on the mLSTM cell with matrix memory and the chunkwise-parallel training kernels from Tiled Flash Linear Attention (Beck et al., 2025). The key architectural departure is switching from the original pre-up-projection block (which combined sequence and channel mixing in a single high-dimensional block) to a standard post-up-projection Transformer-like block with the mLSTM operating in the embedding dimension and a SwiGLU MLP for channel mixing. This positions xLSTM 7B alongside Mamba 1/2, RWKV, and hybrid models at the 7B scale, while the stability fixes (RMSNorm, gate soft-capping, negative input gate bias initialization) address training instabilities previously reported in Mamba-based models at scale.

## Why It Matters / Open Questions

This is the first demonstration that the xLSTM architecture can be stably trained at 7B parameters on 2.3T tokens, validating its scalability beyond the 1.3B ceiling. The practical impact is significant: constant memory usage and linear compute scaling make xLSTM 7B the fastest 7B LLM for inference, which is critical for test-time compute scaling methods (e.g., best-of-N sampling, tree-of-thoughts) and edge deployment. However, the model ranks mid-range on standard benchmarks (0.260 average vs. 0.379 for Qwen2.5-7B), suggesting that data curation and training recipe matter as much as architecture. Open questions include whether xLSTM can scale to 70B+ parameters, whether the fixed-size memory fundamentally limits long-context performance compared to growing KV caches, and whether the performance gap with top Transformers can be closed with better data.

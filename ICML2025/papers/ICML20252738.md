## Problem

Traditional pre-trained models have fixed sizes and are prone to negative transfer when downstream tasks differ significantly from training data, limiting their deployability in resource-constrained settings and their adaptability to novel domains. The paper asks whether the pre-training objective itself can be redefined to produce models that are inherently decomposable into class-agnostic and class-specific knowledge components, enabling flexible recombination without retraining.
![Teaser figure](../imgs/ICML20252738/cropped_page0_idx0.webp)

## Input / Output

The model is a class-conditional latent diffusion model (DiT-B or DiT-L) that takes a class label and random noise in latent space as input and generates 256×256 RGB images via a VAE decoder. The key structural distinction is that the trained model is not a monolithic weight set but a collection of SVD-derived basic components partitioned into learngenes (shared across all classes) and per-class tailors, which can be selectively assembled at deployment time to produce models of varying sizes (e.g., 245.9M vs. 457.0M parameters for DiT-L).

## Method

KIND incorporates SVD as a structural constraint during pre-training rather than applying it post-hoc to frozen weights. Each weight matrix W is factorized as UΣV^T, with each rank-1 component (u_i, σ_i, v_i) treated as a basic unit; the total rank r is partitioned into N_G learngene components (class-agnostic) and N_cls × N_T tailor components (class-specific). A class gate vector G, with a single 1 at the position matching the current training sample's class, ensures that gradient updates only affect the learngenes and the corresponding class's tailors, thereby diverting class-specific knowledge into tailors while condensing shared knowledge into learngenes. At deployment, models are reassembled by selecting relevant tailors (for known classes) or randomly initializing tailors (for domain shifts) and combining them with the frozen learngenes, enabling variable-size models and efficient adaptation without additional pre-training.

## Results

On novel-class generation tasks (18 downstream tasks, 50K fine-tuning steps), KIND achieves FID 20.94 / sFID 14.75 / IS 62.4 on DiT-B and FID 12.87 / sFID 12.93 / IS 86.1 on DiT-L, outperforming the best PEFT method (PiSSA: FID 33.16 / 19.41) by 6.54 FID on DiT-L while using only 45.4M trainable parameters and 119.6G FLOPs. On large domain-shift tasks (CelebA-HQ, Hubble, MRI, Pokémon), KIND achieves the lowest FDD across all four datasets for both model sizes (e.g., 0.109 on Hubble DiT-L vs. 0.142 for LoRA). On training-class variable-size construction (Table 1), KIND matches or exceeds traditional pre-training (FID 9.33 vs. 9.68 for DiT-L) with zero additional training steps, whereas distillation/pruning baselines require 100K extra steps.

## Baselines & Comparisons

KIND substantially outperforms all six baselines on novel-class generation. Against the best PEFT method PiSSA (FID 33.16 / 19.41 on DiT-B/L), KIND reduces FID by 12.22 / 6.54 respectively, while using comparable parameter counts (12.8M vs. 12.8M on DiT-B; 45.4M vs. 45.3M on DiT-L). Against LoRA (FID 36.70 / 22.55) and DoRA (FID 35.87 / 21.28), KIND improves FID by ~15–16 points on DiT-B and ~9–10 points on DiT-L. Against SVDiff (FID 55.01 / 49.59), KIND's advantage is even more pronounced, with a 34-point FID gap on DiT-B. Against the learngene baselines Heur-LG (FID 55.45 / 41.83) and Auto-LG (FID 56.38 / 31.78), KIND achieves 34–35 point FID improvements on DiT-B and 29–19 points on DiT-L, while using far fewer parameters (12.8M vs. 129.6M on DiT-B; 45.4M vs. 456.8M on DiT-L). On domain-shift tasks (Table 3), KIND achieves the best FDD on all four datasets for both model sizes, e.g., 0.109 vs. 0.142 (LoRA) on Hubble DiT-L and 0.040 vs. 0.048 (DoRA) on MRI DiT-L. Notably, KIND even surpasses Full FT on DiT-L (FID 12.87 vs. 14.51) while training only 45.4M parameters versus 456.8M.

## Relation to Prior Work

KIND extends the Learngene framework (Wang et al., 2022; 2023), which encapsulates task-agnostic knowledge into modular network fragments, by integrating SVD as a structural constraint *during* pre-training rather than applying it post-hoc to frozen weights (as in FSGAN/SVDiff). The key departure is the introduction of 'tailors' as class-specific complements to learngenes, coupled with a class gate mechanism that diverts gradients during training so that class-agnostic knowledge is explicitly condensed into learngenes. This redefines the pre-training objective from maximizing task performance to constructing a decomposable backbone, positioning KIND against both traditional PEFT methods (LoRA, DoRA, PiSSA) and model compression approaches (distillation, pruning) that require repeated operations per target size.

## Why It Matters / Open Questions

KIND offers a practical path toward flexible deployment of diffusion models: a single pre-training run yields a model that can be recombined at arbitrary sizes without additional training, and its class-agnostic learngenes mitigate negative transfer on domain-shifted tasks (Hubble, MRI, Pokémon). However, the approach is validated only on DiT-B/L with 611 ImageNet classes and class-conditional generation; open questions include scalability to text-conditional or video generation, whether the class gate generalizes to open-vocabulary settings where the class set is not fixed at pre-training time, and how the method performs when the number of downstream classes differs substantially from the pre-training class count. The modest ablation gain from the class gate (FID 21.60→20.94 on DiT-B) also raises questions about whether simpler routing strategies could achieve similar diversion.

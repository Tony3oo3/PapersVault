## Problem

When LLMs are fine-tuned on proxy preference data (e.g., from crowdworkers or less-experienced raters), the resulting policy can diverge from the true expert policy due to reward hacking. Prior work applies ad-hoc regularisation or reward-model tweaks to limit this divergence, but no theory characterises when proxy data can actually *improve* the sample complexity of learning the true policy. This paper asks: under what conditions on the proxy feedback does pre-training on large amounts of proxy data provably reduce the number of expensive true-preference samples needed?

## Input / Output

The method consumes two preference datasets in Bradley-Terry format (prompt x, preferred completion y_w, dispreferred completion y_l): a large proxy dataset from a less-expert rater and a small true dataset from an expert rater, plus a fixed reference policy π_ref. The output is a true policy π† parameterised as a composition of the proxy policy's learned components (encoder, linear layer, decoder) with an inserted low-dimensional adapter function mapping a D-simplex to itself. A key structural requirement is that the proxy and true policies share level sets (Condition 2) and that the true policy's image is contained within the proxy's image (Condition 3), which constrains how the two datasets can be collected in practice.

## Method

The core result (Theorem 3) shows that under four sufficient conditions—Lipschitz similarity of policies, shared level sets, image inclusion, and finite-dimensional manifold encoding—the true policy decomposes as π† = φ̃ ∘ Θ̃ ∘ π̄† ∘ τ̃°, where (φ̃, Θ̃, τ̃°) are the proxy policy's decoder, linear layer, and encoder, and π̄† is a Lipschitz adapter on a D-simplex. The learning procedure is two-stage: Stage 1 trains the triplet (φ̃_θ, Θ̃, τ̃°_θ) on the large proxy dataset via the DPO loss; Stage 2 freezes those components and trains only the low-dimensional adapter π̄†_θ on the small true dataset. The sample complexity analysis (Theorems 5–6) shows that with the proxy-informed parametrisation, the number of true samples needed scales with the latent dimension D (the manifold dimension of the proxy's image), whereas learning from scratch scales with the full embedding dimension D′ ≫ D, yielding a super-exponential improvement in the data manifold dimension.

## Results

The paper's main quantitative result is a theoretical sample complexity comparison. With proxy data (Theorem 5), the number of true samples needed to generalise scales as Ω(D/ε² · (96L_φ‖Θ̃‖_p L_π √D/ε)^D · log(96L_φ‖Θ̃‖_p √D/ε) − log ω), where D is the latent manifold dimension. Without proxy data (Theorem 6), the bound scales as Ω(D′/ε² · (48L_φ‖Θ̃‖_p L_π E′(p,D′) √D′/ε)^D′ · log(48L_φ‖Θ̃‖_p L_π E′(p,D′) √D′/ε) − log ω), where D′ ≫ D is the embedding dimension. The key improvement is that the exponent drops from D′ to D, yielding a super-exponential reduction in required true samples when the data manifold is low-dimensional.

## Baselines & Comparisons

This is a primarily theoretical paper with no empirical baseline comparisons; the `compares_to` list is empty and no datasets are evaluated on in the main body. The central comparison is between two theoretical sample complexity bounds: Theorem 5 (learning with proxy, scaling with latent dimension D) versus Theorem 6 (learning without proxy, scaling with embedding dimension D′ ≫ D). The paper positions its contribution against prior reward-hacking mitigation strategies (regularisation, reward model tweaks, length-bias corrections) by showing that those methods are 'blind' to the true/false decomposition of proxy data, whereas the proposed two-stage adapter approach provably reduces sample complexity under explicit structural conditions (shared level sets, image inclusion, finite-dimensional encoding). A small-scale experiment on over-smoothing in reward learning is mentioned in Appendix D but is not presented as a main result.

## Relation to Prior Work

This paper builds directly on DPO (Rafailov et al., 2023) as its optimization backbone, using the implicit reward formulation to define both the proxy and true policies. It departs from the dominant line of reward-hacking mitigation work (regularization, reward model ensembles, length-bias decoupling, information-theoretic filtering) by shifting from blind mitigation to a constructive characterization: identifying sufficient structural conditions under which proxy data is provably beneficial rather than merely less harmful. The paper also draws on domain adaptation and multi-fidelity bandit literature, but distinguishes itself by not requiring a bounded gap between proxy and true rewards, and by providing an explicit model parametrisation (encoder–linear layer–decoder plus a low-dimensional adapter) rather than a regret bound.

## Why It Matters / Open Questions

This is the first theoretical result giving a precise, constructive answer to when proxy preference data improves sample complexity in RLHF, which is practically critical given the cost of expert annotations in domains like medicine and law. The two-stage recipe (learn proxy components on abundant data, then learn a D-dimensional adapter on scarce expert data) is a concrete architectural guideline for LLM fine-tuning pipelines. However, the sufficient conditions—especially shared level sets (Condition 2) and image inclusion (Condition 3)—are strong and may not hold for generic crowd-sourced proxy data, limiting immediate applicability. Open questions include whether the conditions can be relaxed, whether the adapter can be learned jointly with the proxy components, and whether the theoretical sample-complexity gains materialize at LLM scale, where the empirical validation here is limited to a small-scale experiment.

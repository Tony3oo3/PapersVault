## Problem

Determining whether two quivers are mutation equivalent is generally a hard problem, and while concise combinatorial characterizations exist for types A and D, no analogous explicit characterization was known for type $\tilde{D}$ quivers. This paper asks whether a graph neural network trained on a naive six-class mutation-type classification task can learn hidden representations that align with known mathematical structure, and whether explainability tools can extract from those representations a novel, provable characterization of $\tilde{D}$ mutation classes.

## Input / Output

The model consumes directed multigraphs (quivers) with no loops or 2-cycles, where $k$ parallel edges are encoded as a single edge with attribute $(k, -k)$ and all vertices carry a constant node feature. Training uses quivers of 6–10 nodes across six mutation types (A, D, E, $\tilde{A}$, $\tilde{D}$, $\tilde{E}$), while testing uses 11-node quivers (excluding $\tilde{E}$, which is undefined at that size). Beyond the class label, PGExplainer produces a per-edge soft attribution mask in $[0,1]$ that highlights the subgraph motifs driving each prediction.

## Method

The core architecture is a 4-layer Directed Graph Isomorphism Network with Edge features (DirGINE), a GIN variant that performs separate directed message-passing along incoming and outgoing edges with edge-feature-conditioned MLPs, followed by sum pooling; it is trained with Adam for 50 epochs on ~70,000 Sage-generated quivers using cross-entropy loss. The key empirical finding is that, despite receiving only coarse type labels, the model's layer-3 embeddings linearly separate the four D-subtypes from Vatne (2010) at 99.7% accuracy, and PGExplainer edge attributions highlight exactly the subtype motifs identified in the mathematical literature. For $\tilde{D}$, PCA of the latent space reveals that non-paired quivers split into two clusters (one vs. two central cycles), and k-means with $k=2$ on these 'Other' quivers guides the authors to an independent characterization (Theorem 6.1) involving paired types, a Type V family with one central cycle, and a Type VI family with two central cycles, which they then prove by verifying closure under mutation.

## Results

The DirGINE model achieves 99.2% test accuracy on 11-node quivers across six mutation types (A, D, E, Ã, D̃, Ē). Size generalization degrades gradually, from 99.6% at n=12 to 89.1% at n=20, attributed to the fixed 4-layer depth limiting recognition of larger substructures. In the explainability analysis, PCA of layer-3 latent embeddings for type D quivers reveals that the four known subtypes (from Vatne 2010) are linearly separable with 99.7% accuracy, despite subtypes never being labeled in training. Removing PGExplainer-attributed edges from type D quivers causes 46.5% of predictions to flip to type A, confirming the model relies on the same structural motifs identified in the mathematical literature.

## Baselines & Comparisons

This paper does not benchmark DirGINE against other GNN architectures or classification baselines; its primary contribution is not competitive accuracy but the extraction of mathematical insight from a well-performing model. Instead of comparing methods, the authors validate the model's learned representations against known human-developed characterizations: the type D subtypes from Vatne (2010) are recovered via PGExplainer edge attributions and PCA clustering of latent embeddings, and the type D̃ characterization (Theorem 6.1) is independently discovered through k-means clustering of the model's hidden activations. The closest analogue to a 'comparison' is the edge-removal ablation in Section 5.2.1, where removing PGExplainer-attributed edges from 32,066 type D test quivers yields 46.5% flipping to type A (consistent with the known characterization), 44.4% flipping to type E (out-of-distribution), and only 8.0% remaining type D, confirming the model keys on the correct structural motifs rather than spurious features.

## Relation to Prior Work

This paper applies a Directed Graph Isomorphism Network with Edge features (DirGINE), built on the GIN architecture (Xu et al., 2019) and its edge-feature extension (Hu et al., 2020), to the algebraic combinatorics problem of classifying quivers by mutation type. It departs from prior ML-for-cluster-algebras work (Bao et al., 2020; Cheung et al., 2023; Dechant et al., 2023), which focused on model performance, by using PGExplainer (Luo et al., 2020) and latent-space analysis to extract mathematical characterizations from the learned representations. The approach is conceptually aligned with Davies et al. (2021) on using ML to guide mathematical intuition, but here the model's hidden structure directly yields a provable theorem rather than merely suggesting a conjecture.

## Why It Matters / Open Questions

The paper provides concrete evidence that a GNN trained on a naive classification task can independently recover the same abstract subtype structure that human mathematicians derived for type D quivers (Vatne, 2010), without any subtype labels in training. The independent discovery and proof of a type D̃ characterization, while derivable from Henrich (2011), demonstrates a viable workflow for ML-assisted theorem discovery in combinatorics. Limitations include the fixed 4-layer depth restricting generalization beyond ~20 vertices, the acknowledged unreliability of post-hoc explainability methods, and the fact that the 'discovered' theorem was not entirely novel. Open questions include whether this approach scales to more complex mutation classes (e.g., type E) or to genuinely open problems in cluster algebra theory.

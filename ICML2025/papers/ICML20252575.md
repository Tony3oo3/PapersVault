## Problem

Existing multi-domain graph pre-training methods apply uniform encoding over fixed topologies, ignoring the substantial structural differences between domains (e.g., homophilic citation networks vs. heterophilic web graphs) and the noise and adversarial vulnerabilities inherent in real-world graphs. This limits both the quality of cross-domain knowledge transfer and robustness to unseen target domains.
![Teaser figure](../imgs/ICML20252575/cropped_page3_idx0.webp)

## Input / Output

The method consumes graphs from multiple source domains, each with an adjacency matrix and a node feature matrix of potentially different dimensionality (e.g., 1,433 for Cora, 3,703 for Citeseer), which are unified to a common 50-dimensional space via PCA. At inference, only 1–5 labeled nodes per class are provided for the target domain, and the model outputs node embeddings that are classified by cosine-similarity matching against learned class prototypes. The downstream graph also undergoes its own structure refinement using the same GSL pipeline before encoding.

## Method

MDGFM aligns cross-domain graphs through three coupled mechanisms: (1) a feature unification stage that modulates projected features with learnable domain tokens t_Di and a shared token t_S via Hadamard products, creating a common semantic space while preserving domain identity; (2) a Graph Structure Learning module that fuses node features with one-hop aggregated topology through a balance token t_Bi, then reconstructs a refined adjacency matrix via kNN sparsification, symmetrization, ReLU activation, and normalization—this denoises edges and aligns topological patterns across domains; (3) a dual-stream prompt framework for downstream adaptation, where a meta prompt (weighted combination of source domain tokens) transfers broad knowledge and a task-specific prompt fine-tunes to the target, blended by a learnable β to mitigate negative transfer. Pre-training optimizes a contrastive objective that maximizes mutual information between node representations on the original and refined graph views, with the refined adjacency matrix expanding the set of positive samples. Theoretical analysis via invariant graph learning provides a domain generalization error bound, showing that the GSL procedure satisfies both invariance and sufficiency conditions for optimal out-of-distribution prediction.

## Results

On one-shot node classification across seven datasets (three homophilic: Cora, Citeseer, Pubmed; three heterophilic: Cornell, Squirrel, Chameleon; and one large-scale: Penn94), MDGFM achieves the best accuracy on every dataset, with headline results of 44.83% on Cora, 42.18% on Citeseer, 46.84% on Pubmed, 40.77% on Cornell, 24.30% on Squirrel, 28.36% on Chameleon, and 52.36% on Penn94. The paper reports that MDGFM outperforms the second-best method by up to 18.04% (relative) in the one-shot setting and 8.11% in the few-shot setting. On the large-scale Penn94 dataset, MDGFM's advantage grows with more shots, reaching 63.25% at K=500 versus 52.88% (GCOPE) and 51.52% (MDGPT).

## Baselines & Comparisons

MDGFM achieves the highest one-shot accuracy on all seven datasets, beating the strongest multi-domain baselines (MDGPT and GCOPE) by 1.5–6.8 percentage points. Among multi-domain methods, MDGPT leads on homophilic graphs (e.g., 39.54% on Cora vs. GCOPE's 34.23%) while GCOPE leads on heterophilic graphs (e.g., 34.02% on Cornell vs. MDGPT's 33.58%), but both are consistently outperformed by MDGFM. The graph prompting baseline GPF is competitive on homophilic datasets (46.36% on Pubmed) but suffers from high memory usage (OOM on Penn94) and large variance. GPPT, designed for single-domain prompting, underperforms substantially (e.g., 17.52% on Cora), confirming its unsuitability for few-shot cross-domain transfer. Supervised baselines (GCN, GAT) and single-domain pre-training methods (DGI, GraphCL) trail all multi-domain approaches, with GCN achieving only 28.57% on Cora versus MDGFM's 44.83%. In the few-shot (K=5) setting, MDGFM maintains its lead on all datasets (e.g., 64.56% on Cora, 63.50% on Pubmed, 53.58% on Penn94), while some baselines like GCOPE and MDGPT show degraded performance on heterophilic graphs due to noise from additional samples.

## Relation to Prior Work

MDGFM extends the multi-domain graph pre-training line initiated by GCOPE (virtual-node interconnection) and MDGPT/SAMGPT (domain-specific tokens) by introducing topology alignment as an explicit objective, which prior methods largely overlook in favor of feature-space alignment. The graph structure learning component departs from feature-similarity-based GSL (Jin et al., 2020) by jointly incorporating semantic and topological signals through a balance token, while the theoretical grounding draws on the invariant graph learning framework of Li et al. (2022) to provide domain generalization guarantees. The dual-prompt downstream strategy (meta + specific prompts) builds on the pretrain-and-prompt paradigm of GPPT and GPF but adds a learnable mixing coefficient to mitigate negative transfer from dissimilar source domains.

## Why It Matters / Open Questions

This is the first work to explicitly target invariant topological structure across homophilic and heterophilic domains, providing both theoretical error bounds and empirical evidence that topology alignment improves robustness to adversarial attacks, edge perturbations, and source-domain removal. However, the 'foundation model' framing is somewhat aspirational: experiments use a single GCN backbone on graphs up to ~40K nodes, and the contrastive pre-training objective is applied per-graph rather than jointly across domains, limiting claims of true cross-domain representation unification. Open questions include scalability to million-node graphs, applicability to dynamic or heterogeneous graphs, and whether the topology alignment benefit persists with more expressive backbones (transformers, GNNs with spectral filters).

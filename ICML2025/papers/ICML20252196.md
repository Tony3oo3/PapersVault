## Problem

Existing selective inference (SI) methods provide valid p-values for individual feature selection or outlier detection algorithms, but no framework exists for performing valid statistical inference when multiple analysis components (missing-value imputation, outlier detection, feature selection) are combined into a data analysis pipeline. Real-world pipelines involve complex interdependencies between steps, and standard resampling techniques like cross-validation cannot properly account for unsupervised stages such as imputation and outlier removal, leaving the statistical significance of pipeline outputs unquantified.

## Input / Output

The method takes a fixed design matrix X ∈ R^{n×d}, a response vector y ∈ R^{n'} (containing missing values and/or outliers, with n' ≤ n), a pipeline configuration specified as a directed acyclic graph over MVI/OD/FS/union/intersection nodes, and the noise variance σ. It outputs the selected feature set M ⊆ [d], the detected outlier set O ⊆ [n], and a selective p-value for each selected feature j ∈ M. The pipeline can be user-specified or automatically selected from a candidate set via cross-validation, in which case the CV selection event is also incorporated into the conditioning.

## Method

The paper formulates the pipeline as a DAG and applies selective inference by conditioning on the joint selection event (M_Y = M, O_Y = O), proving (Theorem 3.1) that the conditional distribution of the test statistic η^T Y is a truncated normal whose truncation intervals Z are determined by the set of z values preserving the same M and O. The key computational contribution is a parametric-programming line search that propagates intervals [L_z, U_z] through the DAG in topological order, using node-specific update rules that reuse existing SI interval-computation results for marginal screening, stepwise FS, Lasso, and Cook's-distance/DFFITS/L1-based OD. This 'auto-conditioning' framework modularizes the update rules so that any pipeline configuration within the class (3 MVI × 3 OD × 3 FS algorithms plus union/intersection) can be tested without additional implementation. The approach extends to cross-validation-based pipeline selection by additionally computing intervals over which the CV-optimal pipeline remains invariant, reducing the problem to solving simultaneous quadratic inequalities.

## Results

On synthetic data (n ∈ {100,200,300,400}, d=20), the proposed method, the ablation (w/o-pp), and Bonferroni all control the type I error rate at α=0.05 across all three pipeline types (op1, op2, cv), while the naive z-test fails to control it. Among methods that control type I error, the proposed method achieves the highest power across all settings, followed by w/o-pp, with Bonferroni being substantially more conservative. On eight real-world UCI datasets (Table 1), the proposed method achieves power of 0.25–0.91 at n=200, dramatically outperforming w/o-pp (0.04–0.15) across all datasets and sample sizes.

## Baselines & Comparisons

The paper compares against three baselines: (1) w/o-pp, an ablation that replaces the full truncation interval Z with only the local interval [L_z, U_z] containing the observed test statistic; (2) naive, a classical z-test without any conditioning on the selection event; and (3) Bonferroni, which multiplies the naive p-value by 2^d · 2^n. On type I error control, the proposed method, w/o-pp, and Bonferroni all successfully maintain the nominal α=0.05 level across all pipeline types and sample sizes, while the naive test substantially exceeds it. On power, the proposed method dominates: it achieves the highest power in every synthetic and real-data setting, with the gap over w/o-pp being particularly large on real data (e.g., 0.91 vs. 0.11 on Data1 at n=200). The reduced power of w/o-pp is attributed to overconditioning (conditioning on more information than necessary). Bonferroni controls type I error but is extremely conservative, yielding near-zero power in most settings due to the enormous multiplicative correction factor.

## Relation to Prior Work

This paper extends the selective inference (SI) framework, originally developed for post-selection inference in individual algorithms (marginal screening, stepwise FS, Lasso, and outlier detection), to the setting of multi-component data analysis pipelines. Prior SI work has been limited to single tasks, with each algorithm's truncation region computed in isolation; here, the authors introduce a DAG-based pipeline representation and a parametric-programming line search that composes the per-node update rules (drawn from Lee & Taylor 2014, Tibshirani et al. 2016, Lee et al. 2016, and Chen & Bien 2020) into a unified truncation interval for the entire pipeline. The modular 'auto-conditioning' implementation framework is also new, allowing arbitrary pipeline configurations to be tested without per-pipeline re-implementation.

## Why It Matters / Open Questions

This is the first systematic treatment of statistical validity for data analysis pipelines, addressing a gap the authors identify in both the software-engineering and ML literature. The modular framework has practical value for reproducibility in high-stakes settings (e.g., genomics, medical diagnosis) where pipelines combine imputation, outlier removal, and feature selection. Key limitations include restriction to linear models under the saturated-model assumption, a fixed set of three algorithms per component type, and computational time that grows exponentially with sample size. Open questions include extending the framework to non-linear models, AutoML-constructed pipelines, and broader classes of analysis components.

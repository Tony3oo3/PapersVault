## Problem

The sparse-group lasso (SGL) and its adaptive variant (aSGL) are computationally expensive due to dual shrinkage and the need to tune two hyperparameters, yet existing screening methods are either conservative exact rules (GAP safe) requiring iterative safe-region computation, or single-layer group-only heuristics (sparsegl) that leave noise variables within active groups. No bi-level screening rule existed for SGL, and no screening rule at all existed for aSGL, limiting the practical scalability of these models in high-dimensional settings.

## Input / Output

The method consumes a design matrix X ∈ R^{n×p}, response vector y, a disjoint group structure {G_1,...,G_m}, a log-linear shrinkage path λ_1 ≥ ... ≥ λ_l, and the mixing parameter α ∈ [0,1] (plus adaptive weights v_i, w_g for aSGL). It produces, at each path point, a reduced candidate variable set C_v(λ_{k+1}) that is a superset of the true active set, and then the full SGL/aSGL coefficient estimates along the entire path. The output is provably identical to the un-screened solution (verified via KKT checks), so the reduction is purely computational with no loss of optimality.

## Method

DFR applies two sequential screening layers at each path point using the ε-norm representation of the SGL norm. The first (group) layer discards group g if ‖∇_g f(β̂(λ_k))‖_{ε_g} ≤ τ_g(2λ_{k+1} − λ_k), derived from the KKT stationarity condition and a Lipschitz bound on the ε-norm of the gradient between consecutive path points. The second (variable) layer, applied only within candidate groups, discards variable i if |∇_i f(β̂(λ_k))| ≤ α(2λ_{k+1} − λ_k), mirroring the lasso strong rule scaled by α. For aSGL, Proposition 3.4 establishes an ε-norm representation with group-specific coefficients γ_g and ε'_g, allowing the same two-layer structure with α replaced by αv_i at the variable level. KKT checks using the soft-thresholding operator guard against rare Lipschitz violations by re-adding offending variables. Unlike GAP safe, DFR requires only the dual norm evaluation (O(p_g log p_g) per group) and a single screening pass per path point, avoiding iterative safe-region construction and repeated fitting.

## Results

On synthetic linear data (p=1000, n=200, 50 groups of size 20), DFR-SGL achieves an improvement factor of 7.98±0.20 and input proportion of 0.101, while DFR-aSGL achieves 7.01±0.15 and 0.096. On interaction data (p=400, order-2 interactions with p_O2=2111), DFR-aSGL reaches an improvement factor of 137.3±12.0 versus 44.3±2.4 for DFR-SGL and 7.4±0.9 for sparsegl. On real data, DFR-aSGL improves computational cost by over 600× on the scheetz and adenoma datasets, and DFR outperforms sparsegl on all six real datasets for both improvement factor and input proportion.

## Baselines & Comparisons

Against sparsegl (Liang et al., 2022), DFR-SGL more than doubles the improvement factor (7.98× vs 3.44×) and roughly halves the input proportion (0.101 vs 0.234), because DFR applies a second variable-level screening layer within active groups while sparsegl only screens at the group level. DFR-aSGL extends this advantage to the adaptive setting, achieving 137.3× improvement on order-2 interaction data versus sparsegl's 7.4×. Against GAP safe (Ndiaye et al., 2016a), DFR achieves a comparable input proportion (~0.10 vs ~0.094) but with a dramatically higher improvement factor (~8× vs ~1×), because GAP safe's iterative safe-region computation (center and radius from the duality gap) negates the dimensionality savings. On all six real datasets, DFR outperforms sparsegl on both improvement factor and input proportion, and DFR-aSGL achieves over 600× speedup on scheetz and adenoma. KKT violations are negligible for DFR-SGL (a single violation across all linear simulations) but slightly more frequent for DFR-aSGL and sparsegl, suggesting DFR's Lipschitz assumption on the full ε-norm is more robust than sparsegl's ℓ₂-only assumption.

## Relation to Prior Work

DFR extends the strong screening rule framework of Tibshirani et al. (2010) from single separable norms (lasso) to the non-separable sparse-group norm, building directly on the sparse-group screening framework of Feser & Evangelou (2025) and the ε-norm representation of the SGL norm from Ndiaye et al. (2016a). It departs from the exact GAP safe approach (Ndiaye et al., 2016a) by replacing iterative safe-region construction with a single sequential screening step per path point, and from sparsegl (Liang et al., 2022) by adding a second variable-level screening layer within active groups. The aSGL screening is entirely new, enabled by a novel theoretical connection (Proposition 3.4) expressing the adaptive sparse-group norm in ε-norm form, which had no prior screening counterpart.

## Why It Matters / Open Questions

DFR makes SGL and aSGL computationally tractable in high-dimensional settings by reducing the optimization input space by an order of magnitude or more, enabling expanded hyperparameter tuning (concurrent λ and α via cross-validation) that was previously infeasible. The finding that a heuristic strong rule achieves input proportions comparable to the exact GAP safe method while being dramatically cheaper challenges the assumption that exactness is necessary for effective screening. Limitations include the Lipschitz assumptions underlying both screening layers (guarded by KKT checks, with only a single SGL violation observed across all simulations) and the fact that aSGL's adaptive weights introduce additional hyperparameter dependence into these assumptions. Open questions include whether the bi-level screening framework extends to other sparse-group penalties (e.g., sparse-group SLOPE) and whether the ε-norm connection generalizes to other adaptive penalty structures.

## Problem

Existing stochastic algorithms for nonconvex optimization with linear constraints either rely on penalty methods with increasing penalty parameters and negligible dual updates, or are restricted to the unconstrained case X = R^n. This paper addresses the gap by developing a single-loop stochastic augmented Lagrangian method with a constant penalty parameter and non-negligible dual updates that handles general polyhedral constraint sets, including linear inequality constraints, while maintaining optimal sample complexity.

## Input / Output

The algorithm consumes one unbiased stochastic gradient sample per iteration (two i.i.d. samples of the constraint matrix when constraints are stochastic) and requires only projection onto the polyhedral set X. Inequality constraints Ax ≤ b are handled via a standard slack variable reformulation into the equality template. The direct output is an ε-near stationary point z* of the Moreau envelope, which is converted to an ε-stationary point x̂ via a single post-processing step using a batch of size O(ε^{-2}), the only place a large batch is used.

## Method

The core algorithm performs inexact gradient descent on the Moreau envelope of the constrained objective, where the gradient is approximated by a single step of stochastic linearized augmented Lagrangian (ALM) with a constant penalty parameter ρ. The key analytical innovation is using the Moreau envelope of the proximal AL function (rather than the proximal AL function itself) in the potential function, which enables convergence analysis under bounded variance of stochastic gradients without requiring bounded domains. The proximal center z_t is updated via a smoothed averaging step z_{t+1} = z_t + β(x_t − z_t), and dual updates use step sizes of the same order as primal steps to drive feasibility with constant ρ. Under an additional expected smoothness assumption, integrating the STORM variance reduction technique improves the sample complexity from O(ε^{-4}) to O(ε^{-3}).

## Results

The paper establishes O(ε^{-4}) sample complexity for a single-loop, single-sample stochastic smoothed linearized ALM solving nonconvex optimization with linear inequality constraints (polyhedral X), which is optimal under the standard bounded-variance oracle assumption. With STORM variance reduction and an expected smoothness assumption, the complexity improves to O(ε^{-3}), also optimal in the unconstrained case. For stochastic linear constraints (where A and b are sampled), the method achieves O(ε^{-4}) with a single-loop ALM, improving upon the prior best of O(ε^{-5}). All results use a constant penalty parameter with non-negligible dual updates, avoiding the increasing penalty parameters required by prior penalty-based methods.

## Baselines & Comparisons

Against Alacaoglu & Wright (2024), this paper extends the O(ε^{-3}) ALM result from X=ℝⁿ to general polyhedral X (covering linear inequality constraints), and improves the stochastic-constraints complexity from Õ(ε^{-5}) to O(ε^{-4}) while using a true ALM with constant penalty rather than a penalty method. Against Lu et al. (2024), this paper matches the O(ε^{-3}) rate under expected smoothness but uses a more stable ALM with fixed penalty parameter instead of an increasing-penalty QP method, and additionally provides an O(ε^{-4}) result under the weaker bounded-variance assumption that Lu et al. do not cover. Against Li et al. (2024), this paper improves the stochastic-constraints complexity from O(ε^{-5}) (double-loop, penalty) to O(ε^{-4}) (single-loop, ALM) by exploiting the linear structure of the constraints. In all comparisons, the key advantage is the use of non-negligible dual updates with a constant penalty parameter, which prior methods either omit or render ineffective through negligible dual step sizes.

## Relation to Prior Work

This paper extends the deterministic smoothed linearized ALM of Zhang & Luo (2022) to the stochastic setting by combining the Moreau envelope analysis framework of Davis & Drusvyatskiy (2019) with the global error bound for linearly constrained nonconvex problems. It departs from the dominant penalty-method paradigm in nonconvex constrained optimization (Lu et al., 2024; Li et al., 2024; Lin et al., 2022), which relies on increasing penalty parameters and negligible dual updates, by analyzing a true ALM with constant ρ and non-negligible dual updates. The key technical departure from Zhang & Luo (2022) is using the Moreau envelope of the proximal AL function (rather than the proximal AL function itself) in the potential, which is necessary to handle single-sample stochastic gradients with projected updates over a polyhedral set X. The STORM variance reduction extension (Cutkosky & Orabona, 2019) further improves the rate to O(ε^{-3}) under expected smoothness, matching the optimal unconstrained rate.

## Why It Matters / Open Questions

This work resolves a gap left by Alacaoglu & Wright (2024), who achieved O(ε^{-3}) for stochastic ALM but only for X = R^n, by extending the analysis to polyhedral X that captures linear inequality constraints — a practically important class (quadratic programming, box constraints, nonnegativity). The O(ε^{-4}) result for stochastic linear constraints is the first to match the unconstrained lower bound with one sample per iteration, improving on the prior O(ε^{-5}) for more general (non-linear) constraint formulations. Limitations include the requirement that X be polyhedral (ruling out general nonlinear feasible sets), the need for Slater's condition and compactness in the stochastic-constraints extension, and the absence of empirical validation. Open questions include whether the Moreau-envelope potential technique extends to nonlinear constraints or to settings without the global error bound.

## Problem

Existing multi-agent LLM frameworks, particularly multi-agent debate (MAD), incur heavy computational costs from round-by-round inter-agent message passing, exceed context-window capacity at scale, and lack formal convergence guarantees. This paper asks whether multi-LLM coordination can be recast as an incomplete-information game with a well-defined equilibrium, eliminating the need for costly explicit communication while preserving or improving reasoning quality.
![Teaser figure](../imgs/ICML20252893/cropped_page0_idx0.webp)

## Input / Output

Each Execution LLM receives three inputs: the original text question, a strategy and format instruction from the Coordinator LLM (capped at 50 tokens with a 70-token hard cutoff), and the Coordinator's final aggregated output. The agent's action is a 2-dimensional prompt embedding [temperature, repetition penalty] that modulates the LLM's generation behavior rather than altering its parameters. The Coordinator LLM aggregates all Execution LLM outputs into a single final text answer, and the system iterates until output stability, reward threshold, and loss convergence criteria are jointly met.

## Method

ECON models multi-LLM interaction as a DEC-POMDP and seeks a Bayesian Nash Equilibrium via a Coordinator-Executor architecture. Each Execution LLM maintains a belief network that maps its local trajectory to a belief state, which in turn produces a 2D prompt embedding (temperature and repetition penalty) and a local Q-value; a shared multi-head-attention belief encoder aggregates all belief states into a group-level representation; and a centralized mixing network with self-attention over prompt embeddings and the group representation computes a global Q-value. Training alternates between an inference phase (no parameter updates) and an optimization phase where individual belief networks are updated via TD loss, the belief encoder via a regularized TD objective, and the mixing network via a combined TD + similarity-difference + local-global consistency loss. The key insight is that belief-based implicit coordination replaces explicit token exchanges, yielding a provably sublinear regret bound O(N√T/(1−γ)) versus the linear regret O(δ_max·T/(1−γ)) of non-equilibrium multi-agent schemes, while reducing token usage by 21.4% compared to 3-round MAD.

## Results

On the average of five reasoning benchmarks (GSM8K, GSM-Hard, MATH, SVAMP, StrategyQA) using LLaMA 3.1 70B, ECON achieves 81.47% on MATH, 92.70% on GSM8K, and 51.43% on GSM-Hard, outperforming the strongest multi-agent baseline (MAD 3-round) by 11.2% on average while using 21.4% fewer tokens. On the challenging TravelPlanner planning benchmark with GPT-4-Turbo, ECON reaches a 9.3% final pass rate on the test set versus 3.7% for 3-round multi-agent debate. Scaling from 3 to 9 Execution LLMs with a hierarchical coordinator architecture yields an additional 18.1% performance gain.

## Baselines & Comparisons

ECON outperforms all ten baselines across the six benchmarks. Against single-agent prompting, ECON beats Zero-shot CoT by 25.6% and Few-shot CoT by 6.3% on average. Against multi-round self-improving methods, ECON surpasses Self Consistency (64 samples) by 10.9% and Tree of Thoughts by 11.2%, while also using far fewer tokens (e.g., 1629 vs. 11917 on MATH). Against the closest multi-LLM competitor, Multi-Agent Debate (3 rounds), ECON improves accuracy by 11.2% on average while reducing token consumption by 21.4% (e.g., 81.47 vs. 71.58 on MATH with 1630 vs. 2155 tokens). Against rStar (mutual reasoning), ECON gains 6.4% on average. On the TravelPlanner planning task with GPT-4-Turbo, ECON achieves 9.3% final pass rate versus 3.7% for 3-round debate and 4.4% for direct GPT-4-Turbo, demonstrating that the belief-coordination mechanism transfers to stronger proprietary models. Heterogeneous model configurations (mixing LLaMA 3.1 8B, Mixtral 7B, etc.) perform slightly below homogeneous setups but still exceed the Few-shot CoT baseline, confirming BNE is achievable across diverse architectures.

## Relation to Prior Work

This paper repurposes the DEC-POMDP and centralized multi-agent RL machinery (belief networks, Q-learning, centralized mixing à la QMIX) for the LLM coordination problem, departing from the dominant multi-agent debate (MAD) paradigm that relies on explicit round-by-round token exchanges. Rather than treating LLMs as conversational agents that must read and respond to each other's outputs, ECON casts each LLM as a player in an incomplete-information game whose 'action' is a 2D prompt-embedding vector (temperature, repetition penalty) and whose 'observation' is a learned belief state. The theoretical contribution—proving BNE existence via Glicksberg's theorem and deriving a sublinear regret bound—draws on standard stochastic-approximation and game-theoretic tools (Jin et al., 2020; Fujimoto et al., 2018) but applies them to a setting where prior MAD work (Du et al., 2024; Liang et al., 2023) offered no convergence guarantees.

## Why It Matters / Open Questions

The paper provides the first formal equilibrium-based convergence guarantee for multi-LLM coordination, which is a meaningful theoretical gap in a field dominated by empirical prompting heuristics. Practically, the 21.4% token reduction versus 3-round MAD while simultaneously improving accuracy makes it attractive for cost-sensitive deployments. However, the action space being limited to two scalar prompt parameters (temperature and repetition penalty) significantly constrains the expressiveness of the 'game,' raising questions about whether the BNE framing captures anything beyond a lightweight hyperparameter search. Open questions include whether richer action spaces (e.g., full prompt manipulation, tool use) preserve the equilibrium guarantees, and whether the hierarchical scaling (local→global Nash) generalizes beyond the 9-LLM regime tested here.

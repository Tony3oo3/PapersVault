## Problem

Prior worst-case analysis of DiskANN (Indyk & Xu, 2024) established an (α+1)/(α−1) approximation guarantee but did not exploit the fact that DiskANN's pruning algorithm processes candidates in sorted order, provided guarantees only for single-neighbor greedy search (beam size 1), and did not leverage Euclidean metric structure. In practice, beam search with L>1 is the standard retrieval strategy, leaving a gap between theory and deployment.

## Input / Output

The method takes a query point q in a metric space and a pre-built DiskANN navigation graph G (constructed with pruning parameter α>1 and maximum degree R), and returns k approximate nearest neighbors via the BeamSearch algorithm with a tunable beam width L≥k. The graph construction itself consumes the full dataset P and produces a directed graph where each node's out-neighbors are selected by a Prune procedure that iteratively picks the closest remaining candidate and removes candidates that are 'shadowed' by already-selected neighbors. The output comes with a provable worst-case bound: each returned point b_j satisfies D(b_j,q) ≤ ε + (α/(α−1))·D(a_j,q) for Euclidean metrics, where a_j is the true j-th nearest neighbor.

## Method

The key insight is that DiskANN's Prune algorithm, by always selecting the closest remaining candidate (step 4 of Algorithm 2), implicitly enforces a 'sorting property' D(v,t) ≤ D(v,a) on the intermediate node t that witnesses α-reachability. The paper formalizes this as 'sorted α-reachable graphs' and shows the slow-preprocessing DiskANN construction always produces them. The approximation quality of a local optimum is then cast as a geometric optimization problem over four points (v, a, t, q); for general metrics the bound (α+1)/(α−1) follows from triangle inequality, while for Euclidean metrics the problem is reformulated as an SDP over squared distances and solved via explicit dual certificates to yield the tighter α/(α−1) bound. The beam search extension works by observing that the blocking node t (which prevents an edge from the beam to the true nearest neighbor) is itself closer to the query than every beam element, so a single application of the optimization problem simultaneously bounds all L beam positions. Convergence is shown in O(L + log_α(δ/((α−1)ε))) steps, where δ is the dataset diameter.

## Results

The paper improves the worst-case approximation factor for DiskANN from (α+1)/(α−1) to α/(α−1) under the Euclidean ℓ₂ metric (e.g., reducing the ratio from 3 to 2 at α=2), and provides the first provable guarantees for beam search with k>1 candidates. Empirically, the sorted index achieves 5–8% higher QPS (SIFT1M at 99% recall, OpenAI at 90%, SPACEV at 95%), uses 6–18% fewer distance comparisons, produces sparser graphs (6–25% lower average degree), and builds 13–22% faster than the unsorted variant across four datasets (SIFT1M, OpenAI, Wikipedia, SPACEV).

## Baselines & Comparisons

The paper's primary empirical comparison is between sorted and unsorted DiskANN graph construction (the unsorted variant serving as the baseline). The sorted index consistently outperforms on QPS (5% higher on SIFT1M at 99% recall, 8% on OpenAI at 90%, 7.5% on SPACEV at 95%), distance comparisons (10% fewer on SIFT1M, 6% on OpenAI, 18% on SPACEV), graph sparsity, and build time (13–22% faster). The one exception is the mean max approximation ratio on OpenAI, where the sorted index is 25% worse (at a 1.008 ratio), though it is 9% better on SIFT and 17% better on SPACEV. For the disk-based SPACEV index, the sorted variant achieves ~0.5% higher recall at 400 disk IOs. Wikipedia shows the largest gap, with the sorted index offering 'vastly superior performance' across all metrics, while the OpenAI approximation-ratio anomaly is flagged for future study.

## Relation to Prior Work

This paper builds directly on Indyk & Xu's (2024) introduction of α-reachable graphs, which provided the first worst-case guarantees for DiskANN's greedy search (beam size 1) with an (α+1)/(α-1) approximation factor. The key departure is identifying that DiskANN's pruning step implicitly enforces a stronger 'sorting' property (D(v,t) ≤ D(v,a)), which the prior analysis did not exploit. By leveraging this sorted α-reachability, the authors tighten the Euclidean-metric bound to α/(α-1) and—critically—extend the analysis to beam search with L > 1, yielding the first provable worst-case guarantees for multi-candidate retrieval on graph-based ANN indices.

## Why It Matters / Open Questions

The result that a seemingly minor implementation detail (sorting candidates before pruning) yields a provably tighter approximation ratio (e.g., 2 vs. 3 for α=2 in Euclidean space) has direct practical implications for DiskANN deployments, and the empirical validation confirms sorted graphs are simultaneously sparser and faster. The beam-search analysis fills a significant gap: prior theory only covered the single-nearest-neighbor case, while k > 1 retrieval is the dominant real-world use case. Open questions include whether analogous metric-specific improvements exist beyond ℓ₂ (e.g., cosine, Jaccard), and whether the fast-preprocessing variant (which restricts candidates to a greedy-search path) preserves the sorted α-reachability property needed for these guarantees.

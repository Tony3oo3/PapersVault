## Problem

LM agents for cybersecurity lack the ability to run interactive command-line utilities such as debuggers (gdb) and server connection tools (netcat, pwntools), which are essential for solving many CTF challenges. Existing agents build their interfaces around a single shell REPL and cannot nest or parallelize additional REPLs, severely limiting their performance on reverse engineering, pwn, and crypto tasks that require dynamic program analysis or remote server interaction.
![Teaser figure](../imgs/ICML20250012/cropped_page1_idx0.webp)

## Input / Output

The agent receives a CTF challenge description and associated files (binaries, ciphertexts, network captures) within a Dockerized Kali Linux environment, interacting through an Agent-Computer Interface that exposes bash commands plus specialized cybersecurity tools (decompile, disassemble, debug, connect). It produces a flag string upon successful submission and a full thought-action-observation trajectory; the session terminates on correct flag submission or when the $3 API cost budget is exhausted, with multiple flag submissions permitted per run.

## Method

EnIGMA extends SWE-agent's ReAct-based ACI with two key innovations: (1) Interactive Agent Tools (IATs) that open non-blocking, parallel REPL sessions for gdb (debugging) and pwntools (remote server connection), allowing the agent to maintain an interactive session while simultaneously using the main shell—mimicking how human security experts multitask across terminal windows; and (2) two summarizers (an LM-based one that condenses long outputs into context-aware summaries, and a simple one that saves outputs to files) to prevent context-window overflow from verbose commands like decompilation or strings. The agent is further guided by category-specific in-context demonstrations and guidelines derived from a 55-challenge CSAW development set, and operates with fine-grained runtime control (output-based timeouts) to handle long-running brute-force operations.

## Results

EnIGMA achieves state-of-the-art results across all four benchmarks. On NYU CTF (200 challenges), EnIGMA with Claude 3.5 Sonnet solves 13.5% (27/200), more than 3× the previous best (4.0%). On InterCode-CTF (100 challenges), EnIGMA with GPT-4 Turbo reaches 72.0% solved, an absolute 29-point improvement over the previous best (43.0%). On CyBench (40 challenges), EnIGMA with Claude 3.5 Sonnet achieves 20.0% vs. 17.5% for the prior best. Average cost per solved instance ranges from $0.21 (LLaMA 3.1 405B on InterCode-CTF) to $1.71 (GPT-4o on HTB), with a $3 per-instance budget cap.

## Baselines & Comparisons

EnIGMA outperforms all four baselines on every benchmark where they are compared. Against the NYU Agent (Shao et al., 2024b), EnIGMA with Claude 3.5 Sonnet solves 13.5% of NYU CTF challenges versus 4.0% (3.4× improvement), and 26.0% on HTB versus 20.0% for the NYU Agent with GPT-4 Turbo. On CyBench, EnIGMA (Claude 3.5 Sonnet) achieves 20.0% versus 17.5% for the CyBench Agent (Zhang et al., 2024), a 2.5-point gain. On InterCode-CTF, EnIGMA's best result (72.0% with GPT-4 Turbo) surpasses the Google DeepMind Agent (Team et al., 2024) by 29 percentage points (43.0%) and the original InterCode-CTF Agent (Yang et al., 2023a) by 32 points (40.0%). Ablations confirm that the Interactive Agent Tools contribute +2.1 points and demonstrations contribute +6.2 points to the overall 29.5% aggregate solved rate across all four benchmarks.

## Relation to Prior Work

EnIGMA extends SWE-agent's Agent-Computer Interface (ACI) framework from software engineering to cybersecurity, building on the ReAct thought-action-observation loop and integrating offensive security tools from Shao et al. (2024a). The key architectural departure from prior CTF agents (Yang et al., 2023a; Shao et al., 2024b; Zhang et al., 2024; Team et al., 2024) is the introduction of Interactive Agent Tools (IATs) that support nested REPLs—enabling the agent to run a debugger or server connection in parallel with the main shell—something no prior LM agent framework supported. The paper also contributes a development set of 55 CTF challenges, addressing a gap noted in all existing CTF benchmarks.

## Why It Matters / Open Questions

The 3× improvement over the previous best agent on NYU CTF (4% → 13.5%) demonstrates that interactive tool interfaces are a meaningful but not dominant factor; ablations show demonstrations contribute more (6.2%) than IATs (2.1%), suggesting prompt engineering and in-context learning remain critical levers. The discovery of soliloquizing—where Claude 3.5 Sonnet self-generates hallucinated observations in ~48% of trajectories without environment interaction—raises important questions about the validity of LM agent evaluations more broadly and the reliability of proprietary models in agentic settings. Open questions include whether the interactive tools paradigm generalizes to other domains (e.g., web navigation, multi-step software engineering), whether soliloquizing can be reliably suppressed without performance loss, and how to build benchmarks resistant to training-data leakage.

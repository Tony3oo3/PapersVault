## Problem

Evolutionary model merging can produce state-of-the-art multi-task LLMs by automating the search over merge coefficients, but its fitness evaluation requires generating and scoring answers for every dataset element, every candidate, and every evolutionary generation—demanding ~4×10⁶ TFLOPs and over a month on a single NVIDIA 4090. This computational barrier excludes the very consumer-GPU practitioners that model merging was designed to empower, leaving evolutionary merging absent from public leaderboards.
![Teaser figure](../imgs/ICML20251756/cropped_page0_idx0.webp)

## Input / Output

The method takes a set of endpoint LLMs (all fine-tuned from the same base model, e.g., Mistral-7B) and a fitness evaluation dataset (e.g., GSM8K, ARC), from which it randomly extracts a tiny subset of 20–100 samples (~2% of the full set). IRT item parameters (α_i, β_i) are pre-fitted from publicly available Open LLM Leaderboard correctness data, so no additional annotation is needed. The output is a Pareto front of merged models with optimized interpolation coefficients λ, deployable as standalone networks without any inference-time overhead.

## Method

MERGE³ is a three-stage pipeline: (1) Extract a small random subset D̄ of the fitness dataset; (2) Estimate each endpoint model's latent ability vector γ_m via IRT using the full dataset, while item parameters α_i, β_i come from public leaderboard data; (3) Evolve merge coefficients using a multi-objective evolutionary algorithm (e.g., NSGA-II) whose fitness is computed by a novel IRT-based performance estimator rather than full-dataset evaluation. The key insight (Assumption 1) is that a merged model's latent abilities are a linear combination of its endpoints' abilities, so the estimator only needs to fit the interpolation coefficients λ via MLE on D̄, avoiding recomputation of the full ability vector. The MP-IRT estimator blends observed correctness on D̄ with IRT-predicted correctness on D\D̄, and GMP-IRT further interpolates between MP-IRT and uniform-weighted observed accuracy to reduce variance. This yields a 50× reduction in fitness FLOPs while preserving near-full-dataset accuracy, with formal ε-stability and asymptotic unbiasedness guarantees.

## Results

MERGE³ reduces fitness computation costs by 50× (0.077×10⁶ TFLOPs vs ~4×10⁶ TFLOPs), enabling evolutionary merging on a single NVIDIA 4090 in 10–21 hours instead of ~62 days. On Japanese GSM8K, MERGE³₁₀₀ achieves 0.42 accuracy (vs. 0.49 for the full-dataset EvoLLM-JP-7B) while running 178× faster. For multilingual ARC, the evolved model surpasses each language-specific fine-tuned endpoint by up to 19% (Dutch: 0.50→0.69), and cross-lingual math transfer yields 10–20% accuracy gains over standard merging baselines across Romanian, German, and Dutch.

## Baselines & Comparisons

Against the full-dataset evolutionary method EvoLLM-JP-7B (Akiba et al., 2025), MERGE³₁₀₀ sacrifices 7 points of accuracy (0.42 vs. 0.49) but runs 178× faster (21 h vs. 62 days), making evolutionary merging feasible on consumer hardware. Against standard merging baselines—Task Arithmetic, TIES, DARE, and SLERP—MERGE³ consistently outperforms by 10–20% on cross-lingual GSM8K transfer (e.g., Romanian, German, Dutch), where these baselines often perform worse than the endpoint models themselves. For performance estimation, MERGE³'s MP-IRT and GMP-IRT estimators achieve lower absolute error than P-IRT and GP-IRT (Polo et al., 2024) across all five benchmarks (GSM8K, ARC, Winogrande, TruthfulQA, HellaSwag), with GMP-IRT* (adaptive c) reaching 0.018 error on Winogrande vs. 0.037 for GP-IRT. On negative transfer rate, MERGE³ shows substantially lower degradation than SLERP, TIES, and Task Arithmetic, preserving per-example competence from component models. The multilingual ARC result (Table 1) shows the evolved model outperforming all four language-specific fine-tuned endpoints simultaneously, a result no standard merging baseline achieves.

## Relation to Prior Work

This paper extends the evolutionary model merging framework of Akiba et al. (2025), which automates merge-coefficient search via evolutionary algorithms but requires full-dataset fitness evaluation, making it infeasible on consumer hardware (~62 days on a single 4090). It also builds on Polo et al. (2024), who applied Item Response Theory to reduce LLM evaluation costs, but repurposes IRT from a benchmarking tool into a merging-specific fitness estimator that exploits the linear-combination structure of merged model abilities (Assumption 1). The key conceptual departure from prior IRT-for-LLMs work is that latent abilities are no longer hidden variables to be inferred post-hoc, but are explicitly estimated for endpoint models and then linearly interpolated to predict merged-model performance, enabling the evolutionary loop to operate on a ~2% data subset.

## Why It Matters / Open Questions

By reducing fitness computation by 50×, MERGE³ makes evolutionary merging accessible to the same single-GPU practitioners who currently rely on ad-hoc merging heuristics (TIES, DARE, Task Arithmetic), potentially closing the gap between simple and optimized merging for a much broader community. The self-merging ablation (performance degrades when a model is merged with itself) provides a clean validation that cross-lingual gains reflect genuine knowledge transfer rather than prompt-template fitting. Limitations include evaluation exclusively on ~7B Mistral-family models and a small set of European/Japanese languages; whether the linear-ability assumption and IRT-based estimation hold for larger models, non-Mistral architectures, or non-linear merging strategies remains open. The released Mergenetic library lowers the barrier for further experimentation in this space.

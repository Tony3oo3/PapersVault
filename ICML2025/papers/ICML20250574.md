## Problem

In partially observable environments, agents must reason over their full observation history, but the standard length-m window (frame stacking) approach scales exponentially in m, making it intractable when long memory is required. This paper asks whether a more compact history representation can achieve comparable or better sample efficiency, and provides the first theoretical characterization of when such a representation is provably superior to windows.
![Teaser figure](../imgs/ICML20250574/cropped_page0_idx0.webp)

## Input / Output

The method consumes a stream of discrete one-hot observations y_t ∈ {0,1}^{|Y|} and a scalar forgetting factor λ ∈ [0,1), producing a fixed-dimensional memory trace vector z_t ∈ [0,1]^{|Y|} via the recurrence z_t = λz_{t-1} + (1-λ)y_t. The trace is then fed into an L-Lipschitz continuous function to yield a value estimate or policy action. Unlike windows, the trace dimension is independent of history length, and the sum of its components equals 1 - λ^m for a length-m history, confining it to a (|Y|-1)-dimensional affine subspace.

## Method

The memory trace is an exponential moving average of observations, inspired by eligibility traces, that compresses the full history into a fixed-size vector. The paper proves that the trace space has Minkowski dimension d_λ = log|Y|/log(1/λ) for λ < 1/2, and establishes that learning Lipschitz functions of traces is equivalent in sample complexity to learning with windows in this 'fast forgetting' regime. For λ ≥ 1/2 ('slow forgetting'), the paper shows the converse: there exist environments (e.g., the T-maze) where memory traces achieve zero return error with metric entropy O(k^{|Y|-1}) while windows require Ω(|Y|^k), a polynomial-vs-exponential gap. The key mechanism is that a large λ pushes apart the few traces that matter (those encoding the initial observation) while collapsing the many irrelevant ones, reducing the required Lipschitz constant. Empirically, memory traces are integrated into TD learning with linear function approximation and PPO, outperforming frame stacking in both Sutton's noisy random walk and a Minigrid T-maze.

## Results

Theoretically, for the T-maze with corridor length k and |Y|=5 observations, window-based learning requires metric entropy Ω(5^k) to achieve zero return error, while memory traces with λ=(k−1)/k and L=√2·e·k achieve the same with only O(k^4) complexity (Theorem 5.8). Empirically, in Sutton's noisy random walk (1001 states, |Y|=11 observations), TD learning with memory traces (11 parameters) significantly outperforms the full window approach (11^m parameters) and a concatenated window (m·11 parameters) in return error. In the PPO T-maze experiment (corridor length k=8, λ_k=7/8), memory traces match or exceed frame stacking success rates, with frame stacking becoming impractical for longer corridors.

## Baselines & Comparisons

The primary baseline is frame stacking (length-m window), the standard approach from Mnih et al. (2015). In the TD learning experiment on Sutton's noisy random walk, memory traces with linear function approximation (|Y|=11 parameters) significantly outperform both the full window (|Y|^m parameters, which becomes combinatorially intractable) and a concatenated window variant (m·|Y| parameters), which despite its increased flexibility does not improve over the exponential weighting of memory traces. In the PPO T-maze experiment (k=8), memory traces using two parallel traces (λ=0 and λ=7/8) achieve comparable or better success rates than frame stacking with window length k, and the paper notes that frame stacking becomes impractical for longer corridors as neural networks grow excessively large. Theoretically, the paper establishes that for λ < 1/2 (fast forgetting), windows and memory traces are equivalent in both return error and metric entropy (Theorems 5.5–5.6), so memory traces never lose to windows in this regime. For λ ≥ 1/2 (slow forgetting), memory traces can be exponentially more sample-efficient, as demonstrated by the T-maze where the complexity gap is Ω(5^k) vs. O(k^4).

## Relation to Prior Work

This paper repurposes the eligibility trace mechanism from Sutton & Barto (2018, Ch. 12) — previously used for credit assignment in TD learning — as a compact history representation for POMDPs, calling it the 'memory trace.' It positions itself against the well-studied length-m window (frame stacking, Mnih et al., 2015), which has received extensive theoretical treatment under observability assumptions (Efroni et al., 2022; Golowich et al., 2023; Cayci et al., 2024), and against recurrent/transformer architectures for POMDPs (Hausknecht & Stone, 2015; Ni et al., 2022; Esslinger et al., 2022) that lack tractable analysis. The key conceptual departure is providing the first sample-complexity analysis of a non-window, non-RNN memory feature, establishing when it is equivalent to or strictly better than windows.

## Why It Matters / Open Questions

The paper provides a simple, implementable alternative to frame stacking (a single EMA update) with clean theoretical guarantees, and identifies a regime (λ ≥ 1/2) where memory traces achieve polynomial rather than exponential sample complexity in the T-maze. However, the empirical validation is limited to two simple environments (Sutton's random walk, a Minigrid T-maze), and the Lipschitz function class assumption may not capture what neural networks actually learn. A key open question the authors highlight is characterizing solvability of arbitrary POMDPs with memory traces in terms of explicit transition/emission properties, and extending the analysis from offline evaluation to online control.

## Problem

Existing graph domain adaptation methods are confined to single-step adaptation and fail under continuous, sequential domain shifts, where models suffer catastrophic forgetting of previously encountered graphs. A critical gap remains in developing unsupervised continual adaptive methods for graph models that can autonomously generate and replay memory without relying on labeled data, which is often unavailable or prohibitively expensive in real-world graph applications.
![Teaser figure](../imgs/ICML20251999/cropped_page0_idx0.webp)

## Input / Output

The method takes a pre-trained GNN model, a sequentially arriving target graph (adjacency matrix A_t ∈ R^{N_t×N_t} and node feature matrix X_t ∈ R^{N_t×d}), and an accumulated pool of previously generated memory graphs. It produces updated model parameters, node-level class predictions on the current graph, and a new condensed memory graph with K ≪ N_t nodes (typically 1–13% of the original size) that is appended to the memory pool for future replay. The memory graphs are generated via variational sampling, so their node features and edge weights are stochastic draws from learned distributions rather than deterministic subgraphs.

## Method

GCAL employs a bilevel optimization strategy: the inner loop adapts the model via an information-maximization self-supervised loss on the new graph while simultaneously replaying all previous memory graphs to prevent forgetting; the outer loop generates a new memory graph using a variational generator. The generator encodes the original graph with a GNN, applies a trainable top-k selector to retain K most informative node distributions, samples node features via the reparameterization trick, and generates edges through a Gumbel-Max relaxation of Bernoulli variables. A theoretical lower bound derived from the graph information bottleneck (Theorem 3.1) decomposes into three optimization objectives: a gradient-matching condensation loss for task relevance, a KL regularization on Gaussian node features and Bernoulli edges for stability, and an L2 distribution-discrepancy loss between aggregated node representations of the memory and original graphs. An EMA strategy smooths model parameter updates across adaptation steps.

## Results

GCAL achieves the best Average Performance (AP) across all four datasets: 55.65% AUC on Twitch-Explicit, 52.72% Accuracy on Facebook-100, 56.57% F1 on Elliptic, and 45.22% Accuracy on OGB-Arxiv. It also attains the best Average Forgetting (AF) scores (0.42, 0.72, 0.88, 0.76 respectively), indicating superior knowledge retention over prior domains. The closest competitor, CoTTA, trails by 1.7–4.9 points in AP and by up to 2.8 points in AF (e.g., −1.96 vs. +0.76 on OGB-Arxiv). Single-step methods (EERM, GTrans) cannot report AF since they do not retain prior-domain knowledge, and GTrans runs out of memory on Facebook-100.

## Baselines & Comparisons

GCAL outperforms all seven baselines on Average Performance across all four datasets. Against the strongest continual baseline CoTTA, GCAL gains +1.71 AUC on Twitch-Explicit, +2.60 ACC on Facebook-100, +2.49 F1 on Elliptic, and +4.94 ACC on OGB-Arxiv. On Average Forgetting, GCAL is the only method that achieves positive AF on all four datasets; CoTTA suffers severe forgetting on Elliptic (−1.92) and OGB-Arxiv (−1.96), while EATA also shows negative AF on three of four datasets. Single-step methods EERM and GTrans cannot report AF (N/A) because they do not retain prior-domain knowledge, and GTrans additionally fails with OOM on Facebook-100. Traditional domain adaptation baselines (DANN, TENT, Norm) perform at or below the no-adaptation Test lower bound on several datasets, confirming that single-step adaptation is insufficient for evolving OOD graph sequences.

## Relation to Prior Work

GCAL sits at the intersection of three research threads: (1) unsupervised graph domain adaptation via information maximization (Liang et al., 2020), which provides the self-supervised adaptation signal; (2) graph information bottleneck theory (Wu et al., 2020b; Sun et al., 2022), from which the authors derive a variational lower bound guiding memory graph generation; and (3) graph condensation via gradient matching (Jin et al., 2021), repurposed here as the condensation loss for task-relevant memory learning. The key departure from prior work is the bilevel optimization framing that couples adaptation-with-replay (inner loop) and variational memory generation (outer loop) in a single unsupervised pipeline, whereas existing graph continual learning methods (ER-GNN, SSM, CaT) all assume supervised signals and existing continual test-time adaptation methods (CoTTA, EATA) operate on images rather than graphs.

## Why It Matters / Open Questions

The paper addresses a practically important gap: real-world graph data (social networks, citation graphs, transaction networks) evolves continuously, and labels are typically unavailable at adaptation time, yet prior graph continual learning methods all require supervision. The variational memory graph generator, which condenses each domain into a tiny synthetic graph (1–5% of original nodes) without labels, is a reusable technique that could benefit other continual graph learning settings. A stated limitation is that GCAL does not modify the base GNN architecture, so its gains are bounded by the backbone's capacity. Open questions include scalability to very large graphs (the largest tested has ~40K nodes), whether the memory graphs transfer across different downstream tasks, and how the method behaves under non-stationary or adversarial domain shifts.

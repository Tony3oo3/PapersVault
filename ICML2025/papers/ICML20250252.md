## Problem

Existing security benchmarks for LLMs (e.g., Cybench, NYU CTF) rely on simplified, puzzle-like CTF challenges that do not reflect the messiness of real-world codebases. This paper asks whether LLMs can autonomously exploit adversarial example defenses in actual research code, and quantifies the gap between CTF-style and real-world difficulty. The benchmark is proxy-free: solving it directly constitutes a research contribution in adversarial machine learning, and success is mechanistically verifiable via robust accuracy.

## Input / Output

The agent receives the defense paper, its source code, a verified forward-pass implementation, a perturbation bound (ℓ∞ = 8/255 for CIFAR-10 and ImageNet, 0.3 for MNIST), and 1,000 target images. It must output 1,000 adversarial images within the perturbation bound, and may use arbitrary tool calls (file I/O, code execution, iterative refinement) with no restrictions on compute or number of attempts. Evaluation reports per-defense robust accuracy and a cumulative distribution function across all 75 defenses, with a defense counted as 'broken' when robust accuracy falls below half of clean accuracy.

## Method

The paper introduces a special-purpose LLM agent that decomposes the attack into four sequential sub-tasks mirroring human expert workflow: (1) implement a tensor-in/tensor-out forward pass, (2) convert it to a differentiable function, (3) verify gradient utility via a single FGSM step, and (4) extend to a multi-step iterative PGD attack. The agent operates through standard tool-use APIs (read/write files, execute code, check task completion) with 30–60 interaction rounds. The benchmark comprises 75 defenses: 51 real-world implementations (curated from 46 reproducible papers across 40 GitHub repositories) and 24 CTF-like reimplementations from Google's self-study course. Across eight LLMs, the strongest ensemble (best-of-5 Claude Opus 4) achieves 87% attack success on CTF-like defenses but only 37% on real-world defenses, with a key failure mode being LLMs' inability to handle outdated library versions (e.g., TensorFlow 1.x) and non-differentiable defense components.

## Results

On the 51 real-world defenses, Claude Opus 4 achieves the highest attack success rate at 30% (15/51 defenses broken, i.e., robust accuracy below half of clean), with an average robust accuracy of 53.7%. On the 24 CTF-like defenses, the best ensemble (5 attempts of Opus 4) breaks 87% of defenses, compared to only 37% on real-world defenses. Claude 3.5 Sonnet reaches 75% on CTF-like defenses but only 13% on real-world, while Sonnet 3.7 inverts this pattern (54% CTF vs 21% real-world). The base rate (no attack) is 85.8% accuracy, and the best single-model average robust accuracy across all 51 real-world defenses is 53.7% (Opus 4).

## Baselines & Comparisons

The paper compares seven LLMs (GPT-4o, o1, o3-mini, Sonnet 3.5, Sonnet 3.7, Gemini 2.5, Opus 4) using a purpose-built 4-step agent. Opus 4 dominates on real-world defenses (53.7% avg robust accuracy, 15/51 broken), outperforming Sonnet 3.7 (63.5%, 11/51) and Sonnet 3.5 (67.2%, 6/51). On CTF-like defenses, Sonnet 3.5 (75%) and Opus 4 (79%) are nearly tied, but Sonnet 3.7 drops to 54% on CTF while nearly doubling its real-world success to 21%—highlighting that CTF performance does not predict real-world performance. Prior general-purpose agentic frameworks (SWE-Bench-style agents) and zero-shot LLM prompting both fail to break any defense (0/51), even after 8 attempts; adding a debugging loop yields at most 3 defenses broken. The key finding is the large gap between CTF-like (87% best ensemble) and real-world (37% best ensemble) success rates, with older TensorFlow 1.x code being a particular failure point for all models.

## Relation to Prior Work

This paper positions itself as a proxy-free alternative to CTF-style security benchmarks like Cybench (Zhang et al., 2024) and the NYU CTF dataset (Shao et al., 2024), which use purpose-built puzzles rather than real-world code. The agent design builds on SWE-Agent (Yang et al., 2024) and Re-Bench (Wijk et al., 2024) for tool-use scaffolding, but is specialized into a four-step attack pipeline (forward pass → differentiable pass → FGSM → PGD) that mirrors the human workflow described in Carlini et al. (2019). Unlike prior agentic benchmarks (SWE-Bench, AgentBench, WebArena) that measure general software or web capabilities, AutoAdvExBench targets the exact end-to-end research task of breaking adversarial ML defenses, making it mechanistically verifiable through a single scalar (robust accuracy).

## Why It Matters / Open Questions

The central finding—that LLMs achieve 75–87% attack success on CTF-like defenses but only 13–37% on real-world research code—challenges the assumption that CTF benchmarks are reliable proxies for real-world security capability, with the gap widening for stronger models (Sonnet 3.5: 75% vs. 13%; Opus 4: 79% vs. 30%). This has immediate implications for how the field evaluates dangerous AI capabilities: a model that saturates CTF-style benchmarks may still be far from autonomously exploiting production systems. Open questions include whether the gap will close as models improve (the paper notes a ~3× increase in success rate in just six months), whether findings generalize beyond image adversarial examples to other domains like jailbreak defenses, and how to handle the reproducibility problem (only 46 of 211 candidate defenses could be run).

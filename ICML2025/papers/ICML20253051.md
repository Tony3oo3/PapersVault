## Problem

While attention-based models demonstrably acquire in-context learning (ICL) ability during training—often marked by abrupt loss drops—the theoretical understanding of how this ability evolves under gradient descent remains preliminary. Prior work characterized what models converge to but did not describe the full training trajectory, and the role of architectural parametrization (e.g., merged vs. separate key and query matrices) in shaping the loss landscape and dynamics was unexplored.

## Input / Output

The model receives a sequence matrix X ∈ R^{(D+1)×(N+1)} containing N input-output token pairs (x_n, y_n) followed by a query token x_q, where x tokens are drawn from N(0, Λ) and y tokens are generated as w^T x with a per-sequence task vector w ~ N(0, I). The model outputs a scalar prediction ŷ_q for the query. Training uses P such sequences with squared loss on the query token, and the 1/N scaling in the attention computation allows the model to handle variable context lengths.

## Method

The paper analyzes gradient flow dynamics of multi-head linear self-attention under two parametrizations. For merged key-query (ATTN_M), the model is shown equivalent to a two-layer fully-connected linear network with a cubic feature map, yielding exactly two fixed points and a single abrupt sigmoidal loss drop, with an analytical time-course solution derived for white input covariance. For separate key-query (ATTN_S), the model is equivalent to a sum of three-layer convolutional linear networks, yielding 2^D fixed points and saddle-to-saddle dynamics where the model sequentially learns eigenvectors of the input covariance in descending eigenvalue order, with the high-dimensional dynamics reduced to scalar ODEs via an ansatz. The key finding is that parametrization fundamentally alters the training trajectory: ATTN_M acquires ICL in one abrupt phase implementing least-squares regression, while ATTN_S acquires it progressively through principal component regression with an increasing number of components, and the rank of the separate key-query weights controls which plateaus are conspicuous.

## Results

For the merged key-query parametrization (ATTN_M), the loss landscape has exactly two fixed points (zero and global minimum), and training from small initialization exhibits a single abrupt sigmoid-shaped loss drop, with an analytical time-course solution σ(t) = e^{2√D·t/τ} / [(1+(1+D)/N)(e^{2√D·t/τ}−1) + √D/w_init²] derived for white covariance. For the separate key-query parametrization (ATTN_S), the loss landscape has 2^D fixed points, and training exhibits D successive abrupt loss drops (saddle-to-saddle dynamics), with the m-th plateau loss given by L(M_m) = tr(Λ) − Σ_{d=1}^{m} λ_d(1+(1+tr(Λ)/λ_d)/N)^{−1}, which in the large-N limit simplifies to Σ_{d=m+1}^{D} λ_d. The converged ATTN_M implements in-context least squares regression, while ATTN_S early-stopped at the (m+1)-th plateau implements in-context principal component regression with m components. Empirical simulations (D=4, N=31, H=4) confirm the predicted plateau values and the alignment of key/query weights with successive eigenvectors of the input covariance Λ.

## Baselines & Comparisons

The paper does not compare against external baselines but instead contrasts two parametrizations of the same multi-head linear attention model: merged key-query (ATTN_M) and separate key-query (ATTN_S). Both parametrizations converge to the same global minimum (in-context least squares regression), but they reach it through fundamentally different training dynamics. ATTN_M acquires the ICL ability in one abrupt loss drop, while ATTN_S acquires it progressively through D successive drops, each corresponding to learning one additional principal component of the input covariance. The rank R of the separate key-query matrices further modulates the dynamics: conspicuous plateaus occur only when the number of learned components m divides R, because a new value weight must escape from zero to accelerate all R key-query pairs in that head. The authors also empirically verify that the single-drop vs. multi-drop distinction persists when softmax is added back to the attention computation, suggesting the findings generalize beyond linear attention.

## Relation to Prior Work

This paper extends the line of work on training dynamics of linear attention for in-context learning (Von Oswald et al., 2023; Zhang et al., 2024a) by moving beyond convergence guarantees to characterize the full trajectory of gradient flow training. It draws on the analytical machinery of deep linear network dynamics (Saxe et al., 2014) through a newly established equivalence between linear attention and multi-layer linear networks with cubic feature inputs. The key departure from prior work is the systematic comparison of two parametrizations—merged versus separate key-query matrices—which prior theoretical studies had largely treated as interchangeable, revealing that this choice fundamentally alters the loss landscape and training dynamics.

## Why It Matters / Open Questions

The finding that parametrization (merged vs. separate key-query, and the rank of separate weights) determines whether ICL emerges as a single abrupt phase transition or as progressive saddle-to-saddle improvements provides a theoretical mechanism for the different training dynamics observed in practice. The equivalence to linear networks opens a pathway for importing convergence and generalization results from the deep linear network literature to attention models. Open questions include whether these dynamics persist in deeper architectures, with non-linear activations, or in the softmax attention setting beyond the empirical evidence provided here, and how the interplay between in-context and in-weight learning modifies the picture when task vectors are not drawn from a zero-mean distribution.

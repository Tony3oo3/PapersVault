## Problem

While prior work has shown that transformers trained on factual recall tasks store information at a rate proportional to parameter count, and mechanistic interpretability studies have identified which layers contain specific facts, it remained an open question how transformers optimally encode factual information within their weights. This paper addresses that gap by characterizing the near-optimal storage capacity of shallow transformers and identifying the specific associative memory mechanism by which self-attention and MLP layers jointly store facts.

## Input / Output

The model receives a length-T token sequence in which a subject token s and a relation token r are placed at random positions among noise tokens, followed by an EOS token at position T. All tokens are mapped to fixed random unit vectors on the d-dimensional sphere (not learned). The model outputs a single predicted answer token via argmax decoding over the full vocabulary, and the task requires both filtering the relevant s and r from noise and retrieving the stored association a*(s,r).

## Method

The paper proves that a single-layer transformer (multi-head self-attention + MLP) achieves 100% accuracy on a synthetic factual recall task whenever either the total self-attention parameters (4Hdd_h) or the MLP parameters (md) scale linearly with the number of facts SR, up to logarithmic factors. The key mechanism is that key-query matrices act as denoisers that isolate subject/relation tokens from noise, while value matrices (in the attention-only construction) or the MLP (in the attention+MLP construction) serve as associative memories storing outer products of answer and subject/relation embeddings. The MLP construction leverages Hermite polynomial expansions to implement a polynomial associative memory with capacity Õ(md), and the model can trade off between attention and MLP parameters while maintaining perfect accuracy. Gradient flow analysis on a simplified linear-attention model further reveals a sequential learning dynamic with an intermediate 'hallucination' stage where the model predicts based only on the relation token before incorporating subject information.

## Results

The paper proves that both linear (d² parameters) and MLP (md parameters) associative memories can store N associations with capacity scaling linearly in parameter count (up to log factors), and that a single-layer transformer achieves 100% accuracy on a synthetic factual recall task whenever either the self-attention parameters (4Hdd_h) or MLP parameters (md) scale proportionally with the number of facts SR. Empirically, the number of facts stored scales linearly with total model parameters across a wide range of model shapes (Figure 4), and the model can trade off MLP parameters for attention parameters while maintaining near-perfect accuracy. Gradient flow analysis reveals a three-stage sequential learning dynamic: uniform prediction → relation-only 'hallucination' stage (loss plateaus at log D) → full accuracy (loss → 0). Information-theoretic lower bounds (Theorems 7–8) confirm these constructions are optimal up to logarithmic factors.

## Baselines & Comparisons

This is a theoretical paper without direct method-vs-method benchmark comparisons. The key empirical comparisons are internal: (1) linear associative memories require d² ∝ N log N parameters while MLP associative memories require only md ∝ N log N parameters to store N associations (Figure 1), showing the MLP construction is more parameter-efficient when m < d. (2) For the factual recall task, the attention-only construction requires d = Õ(max(R,D)) and Hd_h = Õ(S+R), while the attention+MLP construction relaxes the dimension requirement to d = Õ(1) at the cost of needing md = Õ(SR) MLP parameters (Theorems 3 vs. 4). (3) The paper's theoretical linear-scaling predictions match the empirical observations of Allen-Zhu & Li (2024), who observed near-linear scaling of knowledge capacity with parameter count but did not provide a mechanistic explanation. (4) Lower bounds (Theorem 8) show that Õ(SR) bits are necessary, confirming the constructions are information-theoretically optimal up to log factors, whereas prior memorization results (Vardi et al., 2021; Kajitsuka & Sato, 2024) achieve Õ(√N) parameters only at the cost of Õ(√N) bit complexity, making them impractical for realistic precision.

## Relation to Prior Work

This paper extends the associative memory framework of Bietti et al. (2023) and the random-sphere-embedding setup of Cabannes et al. (2024) to the factual recall task, showing that both self-attention value matrices and MLP layers can serve as associative memories with near-optimal storage capacity. It departs from prior mechanistic interpretability work (Geva et al., 2023; Meng et al., 2022; Nanda et al., 2023), which identified where facts are stored but did not analyze memorization capacity, and from Allen-Zhu & Li (2024), who observed near-linear scaling empirically but provided no theoretical construction or matching lower bounds. The gradient dynamics analysis builds on the linear-attention/orthogonal-embedding simplifications common in prior transformer training dynamics work (Li et al., 2023; Von Oswald et al., 2023; Nichani et al., 2024), but adds the noise-token filtering requirement that necessitates learning key-query matrices.

## Why It Matters / Open Questions

This paper provides the first theoretical explanation for the empirically observed near-linear scaling of factual recall capacity with parameter count, and shows that a single transformer layer suffices when either attention or MLP parameters scale proportionally with the number of facts. The identification of an intermediate 'hallucination' stage—where the model predicts based solely on the relation token before learning subject-specific associations—offers a mechanistic account for why LLMs produce plausible but incorrect answers. Key open questions include whether non-random (learned) embeddings enable more efficient constructions, whether these results translate to multi-layer architectures and real LLM scaling laws, and whether one can probe whether specific facts in deployed models reside in attention versus MLP weights.

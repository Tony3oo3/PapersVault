## Problem

Existing DocMT-LLM systems face a fundamental trade-off: translating sentences in isolation loses discourse context and produces inconsistent proper noun translations, while translating in large windows causes sentence omissions and quality degradation due to LLMs treating input as a cohesive document rather than individual sentences. No prior method simultaneously maintains long-span translation consistency, guarantees sentence-level alignment (no omissions), and remains memory-efficient for practical deployment.

## Input / Output

The method consumes a source document as a sequence of N sentences and produces a sentence-aligned target document of exactly N sentences, guaranteeing no omissions. Translation proceeds strictly one sentence at a time (online/Doc2Sent), with each sentence's translation prompt augmented by retrieved information from four memory components. The system is backbone-agnostic, tested with GPT-3.5-Turbo, GPT-4o-mini, Qwen2-7B-Instruct, and Qwen2-72B-Instruct, and operates across 8 language pairs (En↔Zh, De, Fr, Ja) plus a low-resource Lt→En pair.

## Method

DELTA is an LLM-based translation agent with a four-level memory hierarchy that is continuously retrieved and updated during sentence-by-sentence translation. (1) Proper Noun Records store each proper noun's first-encounter translation in a dictionary, consulted before each sentence to enforce consistency; (2) Bilingual Summary maintains rolling source-side and target-side summaries, regenerated every m sentences via a two-step segment-summarize-then-merge process; (3) Long-Term Memory retains the last l sentence pairs, from which an LLM-based Memory Retriever selects n most relevant pairs as few-shot exemplars; (4) Short-Term Memory provides the last k sentence pairs as immediate context. All retrieved information is formatted into a single translator prompt, and after each translation, LLM-based components (Proper Noun Extractor, Summary Writers, Memory Retriever) update the memory state. This Doc2Sent design avoids the sentence-omission failures of Doc2Doc approaches while the multi-granularity memory (from concrete noun records to abstract summaries, from 3-sentence windows to document-level overviews) captures discourse structure across arbitrary spans, yielding up to 4.58 pp consistency and 3.16 COMET improvements over baselines.

## Results

On IWSLT2017 (8 language pairs, 4 backbone LLMs), DELTA achieves average sCOMET of 84.36 (En⇒Xx) and 84.69 (Xx⇒En), dCOMET of 6.57 and 7.11, and LTCR-1 of 81.63 and 85.09, outperforming the best baseline (Context) by +1.41/+0.62 sCOMET, +0.16/+0.08 dCOMET, and +2.61/+1.65 LTCR-1 points respectively. On the Guofeng Webnovel dataset (Zh⇒En, novel domain), DELTA achieves up to +48.50 percentage points in LTCR-1 over the Sentence baseline (85.50 vs. 37.00 with Qwen2-7B). The sentence-by-sentence approach also eliminates sentence omissions (0 missing sentences vs. up to 10 for Doc2Doc with window=50) and reduces GPU memory consumption, avoiding the memory exhaustion that Doc2Doc hits at ~490 sentences.

## Baselines & Comparisons

DELTA outperforms all four baselines across nearly all metrics and translation directions. Against the Context baseline (Wu et al., 2024a), DELTA gains +2.61 pp in LTCR-1 (En⇒Xx) and +1.65 pp (Xx⇒En) on consistency, while also improving sCOMET by +1.41 and +0.62 points respectively. Against Doc2Doc (Wang et al., 2023b), DELTA achieves substantially higher consistency (+3.99 pp LTCR-1 En⇒Xx, +0.91 pp Xx⇒En) and avoids the sentence-omission problem entirely (Doc2Doc produces 2–10 missing sentences depending on window size). Against NLLB-3.3B (Costa-jussa et al., 2022), DELTA surpasses it by +2.25 sCOMET and +7.07 pp LTCR-1 (En⇒Xx), demonstrating that the LLM-agent approach exceeds dedicated MT models. On the QMSum summarization side-task, DELTA's summary component achieves ROUGE-L of 23.60 versus ReadAgent's (Lee et al., 2024) 21.50, confirming the summary module's utility beyond translation.

## Relation to Prior Work

This paper repurposes the LLM-based autonomous agent paradigm with memory components (inspired by reading agents like ReadAgent and self-controlled memory frameworks) for the document-level machine translation task. It departs from the mainstream Doc2Doc approach (Wang et al., 2023b) by adopting a Doc2Sent strategy where an agent with four memory levels—Proper Noun Records, Bilingual Summary, Long-Term Memory, and Short-Term Memory—guides sentence-by-sentence translation. The multi-level memory design draws conceptual inspiration from hierarchical context modeling in prior DocMT work (Tan et al., 2019; Lyu et al., 2021) but implements it through LLM-based retrieval and summarization rather than learned encoders. The paper also introduces LTCR-1, a stricter variant of the Lexical Translation Consistency Ratio that enforces alignment with the first occurrence of each proper noun.

## Why It Matters / Open Questions

DELTA addresses two practically critical failures of DocMT-LLMs—proper noun inconsistency and sentence omissions—while being significantly more memory-efficient than Doc2Doc methods that exhaust GPU memory on long documents. The finding that a sentence-by-sentence agent outperforms batch translation in both consistency and quality challenges the assumption that more context per inference call is always better. However, the paper acknowledges that inference efficiency remains a major limitation due to frequent LLM invocations, and the approach has not been tested on truly long documents (hundreds of pages) or in real-time deployment settings. The dual utility of the summary component for query-based summarization suggests the multi-level memory architecture could generalize beyond translation.

## Problem

Existing multi-agent planning approaches rely on prompting a meta-agent to decompose queries and assign sub-tasks to agents, but lack mechanisms to verify that each sub-task is actually solvable by its assigned agent, that all critical information from the query is covered, and that no redundant sub-tasks are generated. This paper identifies three design principles—solvability, completeness, and non-redundancy—and shows that prompt-based decomposition alone violates them in over 15% of cases, leading to unreliable final answers.

## Input / Output

The system takes a natural-language user query and a set of agent descriptions (short natural-language capability summaries) as input. The meta-agent produces a structured JSON plan where each sub-task specifies a task description, a unique ID, an assigned agent name, a justification, and a list of dependency task IDs. A trained reward model then consumes the sub-task text and agent description text (via MiniLM embeddings concatenated into a 768-d vector) and outputs a scalar solvability score, enabling evaluation without any actual agent invocation.

## Method

AOP operates in two phases: a fast decomposition-and-allocation step where the meta-agent (GPT-4o) generates an initial structured plan, followed by an evaluation-and-refinement loop. A lightweight reward model (frozen MiniLM embeddings + 3-layer MLP, trained with MSE loss on scorer-annotated sub-task/agent pairs) predicts whether each sub-task is solvable by its assigned agent; low scores trigger replan, while borderline scores trigger either a re-describe (guided by cosine-similarity matching against the agent's representative works) or a plan-in-detail decomposition. A separate LLM-based detector checks completeness and non-redundancy of the sub-task set and flags missing dependencies. A feedback loop continuously updates each agent's representative works with newly resolved sub-tasks, improving future similarity-based matching. The entire pipeline is trained in a supervised fashion on a dataset constructed by executing plans across multiple agents and scoring responses on correctness, relevance, and completeness.

## Results

On HuskyQA (292 test queries), AOP achieves 43.7% accuracy, outperforming the strongest multi-agent baseline HUSKY (39.6%) by 4.1% and the single-agent GPT-4o baseline (33.3%) by 10.4%. On DROP and IIRC, AOP achieves 34.0% and 41.5% accuracy respectively, surpassing the best baselines (REACT at 29.0% on DROP, HUSKY at 36.5% on IIRC) by at least 5.0%. On the MATH benchmark with four parallel math agents, AOP reaches 72% accuracy versus 66% for the best individual agent (Qwen2-Math-7B). AOP's inference time (11,869 s) is comparable to HUSKY (10,394 s) and REACT (11,510 s) while using fewer prompt tokens (1.12M vs. 2.47M for REACT).

## Baselines & Comparisons

AOP outperforms all seven baselines on HuskyQA. Against single-agent systems, AOP beats GPT-4o (33.3%) by 10.4%, CoT (35.6%) by 8.1%, and Zero-Shot CoT (32.2%) by 11.5%, demonstrating the benefit of multi-agent collaboration over monolithic LLM reasoning. Against multi-agent baselines, AOP surpasses the simple Meta-Agent (30.0%) by 13.7% and Meta-Agent: Traversal (35.2%) by 8.5%, showing that naive decomposition-and-assign or exhaustive agent querying is insufficient without the reward model, detector, and representative works mechanisms. Among the most competitive multi-agent methods, AOP beats REACT (37.6%) by 6.1% and HUSKY (39.6%) by 4.1% in accuracy while using fewer prompt tokens than REACT (1.12M vs. 2.47M) and comparable inference time. On DROP and IIRC, AOP extends its lead by 5.0% and 5.0% over the respective best baselines, and on MATH with four parallel math agents it achieves 72% versus 66% for the strongest individual agent, confirming consistent gains across diverse reasoning tasks.

## Relation to Prior Work

This paper extends the line of LLM-based multi-agent planning work (HuggingGPT, ReAct, HUSKY, Chameleon) by formalizing three design principles—solvability, completeness, and non-redundancy—that prior prompt-based decomposition methods largely overlooked. Rather than treating task decomposition and agent assignment as a one-shot generation problem, AOP repurposes the reward-model paradigm (common in RLHF) to score sub-task–agent compatibility without expensive m×n agent calls, and introduces a 'representative works' mechanism that dynamically captures agent capabilities beyond static natural-language descriptions. The feedback loop and detector components draw on the broader inference-time-computing trend (OpenAI, 2024) of trading additional computation for improved reliability.

## Why It Matters / Open Questions

The three design principles provide a clear, actionable checklist for evaluating any multi-agent planning system, and the ablation showing the detector (a simple LLM prompt) contributes the largest accuracy gain (7.1%) suggests that completeness and redundancy errors—not solvability—are the dominant failure mode in current meta-agent planning. Limitations include evaluation on relatively narrow numerical-reasoning datasets (HuskyQA, DROP, IIRC), reliance on GPT-4o for all agents, and a lightweight reward model (frozen MiniLM + 3-layer MLP) whose ceiling is unclear. Open questions include scalability to dozens or hundreds of heterogeneous agents, handling of dynamic agent availability during execution, and whether the representative-works mechanism generalizes to open-ended creative or multi-turn tasks beyond structured QA.

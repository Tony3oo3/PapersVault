## Problem

Robot task planning requires world models that are both perceptually rich (e.g., determining if a jug is inside a coffee machine) and logically rich (e.g., counting blocks on each side of a balance beam), yet existing approaches either rely on hard-coded symbolic models that cannot adapt to novel environments or restricted learning paradigms that require human demonstrations. This paper tackles how to efficiently invent such abstractions purely from online environment interaction, with zero-shot generalization to unseen tasks.

## Input / Output

The system consumes raw RGB images, 3D object poses, a task goal specification, and a fixed inventory of low-level motor skills (pick, place, stack, etc.) as inputs. It produces Neuro-Symbolic Predicates—executable Python functions that can crop images, query a VLM with natural-language assertions, and perform algorithmic operations (loops, conditionals, recursion)—alongside High-Level Actions that define an abstract transition model. The final output is a hierarchical plan: a sequence of HLAs that decomposes into a concrete skill sequence for execution.

## Method

The core representation is the Neuro-Symbolic Predicate (NSP), a Python snippet that combines VLM API calls for perceptual grounding with full algorithmic logic (conditionals, numerics, loops, recursion) for compositional reasoning, split into primitive NSPs (evaluated on raw state) and derived NSPs (computed from other NSPs' truth values). Learning proceeds via an online loop that interleaves goal-driven exploration with the current abstract model, VLM-guided predicate proposal using three strategies (discrimination between success/failure states, transition modeling of state changes, and unconditional logical extension), predicate selection via a classification-accuracy objective with simplicity bias (greedy best-first search), and HLA learning through an extended cluster-and-intersect algorithm that optimistically enlarges feasible state sets to encourage exploration. The key architectural insight is that derived predicates enable logically complex abstractions (e.g., transitive closure for 'on a plate', counting for 'balanced') without requiring the VLM to perform multi-step reasoning, while the optimistic precondition learner avoids the over-restriction that plagues demonstration-based operator learning in data-scarce settings.

## Results

Across five simulated robotic domains, the proposed method achieves 96–100% solve rates on Cover, Blocks, Cover Heavy, and Balance, and 65.3% on Coffee (where the Oracle reaches 99.3%). It matches the Oracle baseline in most domains (e.g., 100% vs. 100% on Cover and Balance; 96% vs. 94% on Blocks) while using comparable planning budgets (e.g., 9.4 vs. 8.4 nodes on Cover). The symbolic-predicate baseline (Sym. pred.) collapses to 7.2% on Blocks and 20% on Balance, and the no-invention baseline achieves only 0–68% solve rates. Planning wall-time ranges from 0.057 s (Cover Heavy) to 254.6 s (Blocks, where derived predicates are incompatible with LM-Cut heuristics).

## Baselines & Comparisons

Against the MAPLE HRL baseline (Nasiriany et al., 2022), the proposed method consistently outperforms across all domains; MAPLE struggles to perform well even on tasks within its training distribution, likely due to its reliance on a learned Q-function over high-level actions without explicit predicate learning or symbolic planning. Against the ViLa VLM-planning baseline (Hu et al., 2023), the proposed method also wins across all domains; ViLa demonstrates limited planning capability, performing adequately only on simple pick-and-place tasks (Cover) but generating infeasible plans in more complex domains (e.g., attempting to pick blocks from a stack's middle or grasping a jug without considering orientation). The symbolic-predicate baseline (Sym. pred.), which uses the same online learning algorithm but restricts predicates to manually selected object features without VLM queries or derived predicates, drops to 7.2% on Blocks and 20% on Balance, highlighting the necessity of perceptually rich and logically compositional NSPs. The no-invention baseline (using only initial underspecified abstractions) achieves 0% on Coffee and 1.3% on Blocks, confirming that predicate invention is essential. The method matches the hand-designed Oracle in most domains, demonstrating that autonomously learned abstractions can rival human-crafted ones.

## Relation to Prior Work

This paper extends the bilevel planning and predicate invention line of work (Chitnis et al., 2022; Silver et al., 2022, 2023) by replacing hand-selected object features with open-ended Neuro-Symbolic Predicates that invoke VLMs for perceptual queries and Python for logical composition. Unlike Silver et al. (2023), which learns predicates from object-centric features and requires expert demonstrations, this work learns purely online from environment interaction and introduces derived predicates for transitive and counting-based reasoning. The operator learning is extended from the cluster-and-intersect algorithm with an optimistic precondition objective designed for exploration-based (rather than demonstration-following) settings.

## Why It Matters / Open Questions

The paper demonstrates that VLM-grounded, code-based predicates can autonomously discover abstractions matching hand-designed oracle models across five robotic domains, suggesting a path toward robots that adapt to novel environments without human-provided demonstrations. Key limitations include dependence on VLM accuracy for predicate evaluation (notably failing on material/color discrimination in simulation) and evaluation restricted to PyBullet with simple physics. Open questions include scaling to real-world sensorimotor noise, partially observable settings, and developing LM-Cut-compatible heuristics for derived predicates that currently inflate planning search by orders of magnitude.

## Problem

Autoregressive LLMs generate code token-by-token without access to the program's runtime output, making it difficult to detect and correct errors during generation. Training models to suggest code edits is further hampered by the scarcity of rich edit training data. This paper addresses both limitations by formulating program synthesis as a denoising diffusion process over syntax trees, enabling iterative, syntactically-valid edits guided by execution feedback.

## Input / Output

The model consumes two rendered images (the target image x_0 and the current program's render x_t) alongside the current tokenized program, and produces a single edit action: a position in the syntax tree plus replacement tokens. Each edit is constrained to subtrees containing at most σ_small=2 primitives, guaranteeing small, syntactically valid mutations at every step. The observation model is flexible—ranging from deterministic rendering to a stochastic hand-drawn sketch simulator—and the framework generalizes to any context-free grammar and observation function.

## Method

The noising process applies small grammar-constrained mutations to syntax trees, borrowing from grammar-based fuzzing: a random subtree with ≤σ_small primitives is replaced by a new subtree sampled under the same production rule. The denoising network is a ~10M-parameter decoder-only vision-language transformer with an NF-ResNet-26 image encoder, trained to predict an edit position and replacement tokens autoregressively under CFG-constrained decoding that masks invalid token logits. Rather than simply inverting the last forward mutation, training targets are computed via a tree edit path algorithm that finds the first step on a valid path from the mutated tree back to the target, reducing noise in the supervision signal. A separate value network (2-layer MLP) predicts the program-space edit distance between two rendered images, enabling beam search to guide the denoising process toward programs that match the target specification.

## Results

On the CSG2D inverse-graphics task (IoU ≥ 0.99 threshold), Tree Diffusion Search requires the fewest node expansions to solve test problems, outperforming both the autoregressive VLM baseline and the REPL VLM baseline (Ellis et al., 2019). Tree Diffusion Rollouts (policy-only, no search) also significantly outperforms both baselines on both CSG2D and TinySVG. In a direct comparison with LLaVA-1.5-7B on CSG2D (100 node-expansion budget), our ~10M-parameter model solves 32.18% of test tasks versus 0.00% for LLaVA base and 1.17% for fine-tuned LLaVA. Given equal wall-clock time on the same GPU, the method reaches 84.68% ceiling performance on the hard test set.

## Baselines & Comparisons

The paper compares against three baselines: (1) an autoregressive VLM (reimplementation of CSGNet, Sharma et al. 2018) using rejection sampling, (2) a REPL VLM (Ellis et al. 2019) that builds programs one primitive at a time with execution feedback, and (3) LLaVA-1.5-7B as a large pretrained VLM. Tree Diffusion Search (policy + beam search with value network) achieves the lowest node-expansion count across both CSG2D and TinySVG, meaning it solves problems with fewer neural network calls and renderings than any baseline. Tree Diffusion Rollouts (policy-only iterative editing) also outperforms both the VLM and REPL VLM baselines, confirming that the iterative editing paradigm itself is superior to one-shot autoregressive generation or incremental construction. Against LLaVA-1.5-7B, our ~700× smaller model achieves 32.18% vs. 0–1.17%, demonstrating that task-specific diffusion on syntax trees with execution feedback far exceeds what large pretrained VLMs can achieve on exact pixel-matching program synthesis. The REPL VLM baseline is only applicable to CSG2D (not TinySVG) because it requires a custom partial compiler, which is infeasible for hierarchical languages.

## Relation to Prior Work

This paper transplants the forward/reverse diffusion paradigm from continuous image generation (Ho et al., 2020) to discrete syntax trees, using grammar-based fuzzing (Zeller et al., 2023; Luke, 2000) as the noising process and a tree-edit-distance-inspired algorithm (Pawlik & Augsten, 2016) to compute clean reverse-mutation training targets. It departs from prior neural program synthesis (Ellis et al., 2019; Sharma et al., 2018) that builds programs incrementally one primitive at a time, instead operating on complete programs and iteratively editing them with execution feedback. Unlike CodeFusion (Singh et al., 2023), which embeds code in a continuous latent space where intermediate states are not valid programs, this method guarantees syntactic validity at every denoising step through grammar-constrained decoding. The combination of a diffusion policy with a learned value network for beam search over program space is a new synthesis strategy not present in prior work.

## Why It Matters / Open Questions

The core contribution is a general-purpose framework for program synthesis that works on any context-free grammar and observation model, enabling a natural debugging loop (generate → execute → edit) that autoregressive LLMs lack. However, the current implementation is limited to small DSLs without variable binding, loops, or continuous parameters, and the ~10M-parameter models are far from the scale of modern LLMs, leaving open whether the approach scales to realistic programming tasks. The paper also acknowledges that inverse graphics may be unusually well-suited to this paradigm because small syntactic mutations produce semantically meaningful visual changes. Future work on extending to full programming languages, continuous parameters, and large-scale internet code data would be needed to assess broader impact.

## Problem

Prior theoretical work on nonlinear feature learning with neural networks was limited to a single hidden feature (r=1), leaving it unclear whether gradient descent can adaptively identify and recover multiple nonlinear features simultaneously. This paper asks whether a three-layer network trained via layer-wise gradient descent can efficiently learn hierarchical polynomials of multiple quadratic features, and if so, at what sample complexity.

## Input / Output

The input is a vector x drawn uniformly from the sphere S^{d-1}(√d), and the target is a hierarchical function f*(x) = g*(x^T A_1 x, …, x^T A_r x) where r ≪ d quadratic features are orthogonal and the link function g* is a degree-p polynomial. The method produces both a scalar prediction f(x; θ) and a learned feature representation h^(1)(x) ∈ R^{m_2} that approximately spans the r-dimensional feature space, enabling reconstruction of all r quadratic features via a linear map B*. Training uses two independent datasets D_1 and D_2 for the two stages, and the framework supports transfer learning by swapping g* for a different polynomial g in stage 2.

## Method

The architecture is a three-layer network with frozen innermost weights V, where stage 1 performs a single gradient step on the middle layer W (with weight decay) to extract features, and stage 2 trains the outer layer a on the resulting random-feature model. The key technical insight is a novel multivariate universality lemma (Lemma 1) bounding the Wasserstein-1 distance between the joint distribution of r quadratic features and a standard Gaussian, which bridges the multi-nonlinear-feature setting to the multi-index model analysis of Damian et al. (2022). Under this universality, the degree-4 spherical harmonic component of f* is dominated by the expected Hessian H = E[∇²g*(z)], allowing the learned representations to be reconstructed as B* ∝ H^{-1}[p(v_1), …, p(v_{m_2})]. This yields a total sample complexity of Õ(d^4) for feature recovery plus O(r^{O(p)}) for the link function, substantially improving over the Θ(d^{2p}) complexity of kernel methods and enabling efficient transfer to new polynomial heads sharing the same features.

## Results

The main theoretical result (Theorem 1) establishes that a three-layer network trained via layer-wise gradient descent achieves population absolute loss Õ(√(r^p κ₂^{2p}/min(m₁,n₂)) + √(d⁶r^{p+1}/m₂) + √(d²r^{p+1}/n₁) + r^{p+2}/d^{1/6}) with n₁ = Õ(d⁴) first-stage samples and m₂ = Õ(d⁶) inner width. This yields a first-stage sample complexity of Õ(d⁴) for full recovery of the r-dimensional quadratic feature space, and a second-stage complexity of Õ(r^p κ₂^{2p}) for learning any degree-p polynomial link function, both independent of the polynomial degree p in the d-dependence. Empirically (Section A), d⁴ samples are sufficient to reconstruct all r=3 quadratic features with high correlation, and the method outperforms a naive random-feature model across d ∈ {8, 16, 32} with p=4.

## Baselines & Comparisons

The paper compares its layer-wise trained three-layer network against a naive random-feature model (equivalent to the NTK/kernel regime) on synthetic hierarchical targets with r=3 quadratic features. The proposed method (Algorithm 1) consistently achieves lower test error than the random-feature model across all ambient dimensions d ∈ {8, 16, 32} and polynomial degrees p ∈ {4, 6, 8}, with the gap widening as d increases — the random-feature model's error curves separate significantly for different d values while Algorithm 1's curves align closely, confirming the theoretical Õ(d⁴) vs. Θ(d^{2p}) sample complexity separation. For transfer learning, Algorithm 1 successfully adapts to new link functions (p=4, 6, 8) after pretraining on p=2 with n₁=2¹⁶ samples, requiring only Õ(r^p) additional second-stage samples. Compared to the multi-index model results of Damian et al. (2022), the d-dependence increases from d² to d⁴ (reflecting quadratic vs. linear features) while maintaining a similar polynomial dependence on r. The work extends Nichani et al. (2023) and Wang et al. (2023) from a single nonlinear feature (r=1) to multiple features (r>1), with fundamentally different assumptions (nearly zero linear component of g vs. non-zero linear component) and random (vs. deterministic) initialization enabling multi-directional feature capture.

## Relation to Prior Work

This paper extends the three-layer network feature learning framework of Nichani et al. (2023) and Wang et al. (2023), which studied learning a single nonlinear feature (r=1), to the multi-feature setting (r>1) with quadratic features. It also generalizes the multi-index model analysis of Damian et al. (2022) from linear to nonlinear features by introducing a novel multivariate Gaussian universality argument (Lemma 1) that bridges the two settings. The second-stage training reduces to a random-feature model (Rahimi and Recht, 2007), but the key departure is that the first-stage feature learning eliminates the polynomial dependence on ambient dimension d from the second-stage complexity, which kernel methods cannot achieve.

## Why It Matters / Open Questions

This is the first theoretical guarantee for efficiently learning hierarchical polynomials of multiple nonlinear features, closing a gap between single-feature and multi-index results. The Õ(d⁴) sample complexity (independent of the polynomial degree p) versus Θ(d^{2p}) for kernel methods provides a clean theoretical demonstration of the feature learning advantage. Open questions include whether the d⁴ bound can be tightened to the information-theoretic d² via multi-step GD, whether results extend to higher-degree (non-quadratic) features, and whether the strong assumptions (orthogonal features, well-conditioned Hessian, nearly-zero linear component) can be relaxed. The multivariate universality lemma is of independent interest for high-dimensional probability.

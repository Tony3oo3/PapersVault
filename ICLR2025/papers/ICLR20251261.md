## Problem

Existing LLM agent security benchmarks like InjecAgent and AgentDojo are limited to a single attack type (Indirect Prompt Injection) or a narrow set of scenarios, leaving the full attack surface of agent operation—system prompts, user prompts, tool observations, and memory retrieval—unexamined. No prior work provides a unified formalization of multiple attack categories (direct/indirect prompt injection, memory poisoning, backdoor, mixed) alongside corresponding defenses, making it impossible to systematically compare their effectiveness or identify which operational stages are most vulnerable.

## Input / Output

The benchmark consumes a full agent configuration: a system prompt (optionally augmented with PoT demonstrations), a user instruction prompt, a tool list of 400+ tools (20 normal + 400 attack tools), and a RAG memory database of query-plan pairs, all processed by one of 13 LLM backbones within a ReAct loop. Outputs are structured as per-attack-type metrics (ASR, refusal rate) and a composite Net Resilient Performance score (PNA × (1−ASR)) that jointly captures utility and security. The benchmark also distinguishes aggressive vs. non-aggressive tasks to measure whether agents refuse unsafe instructions, with refusal judged by a separate LLM call.

## Method

ASB formalizes five attack families with explicit adversarial objectives: DPI and IPI inject instructions into the user prompt or tool observations respectively (using five injection styles: naive, escape characters, context ignoring, fake completion, combined); Memory Poisoning poisons the RAG database with adversarial key-value pairs so retrieved in-context examples steer the plan toward attack tools; and the novel PoT Backdoor Attack embeds a backdoored planning step p* into system-prompt demonstrations, linking a trigger phrase δ in the user query to an adversarial tool call via in-context learning. Defenses span prevention (delimiters, paraphrasing, dynamic prompt rewriting, instructional prevention, sandwich prevention, shuffle) and detection (perplexity, LLM-based). The key insight is that the agent's multi-stage ReAct pipeline creates distinct, composable attack surfaces, and the PoT backdoor exploits the agent's reliance on in-context planning demonstrations—a training-free attack that achieves up to 100% ASR on GPT-4o while preserving benign performance. All 27 attack/defense combinations are evaluated across 10 scenarios, 10 agents, and 13 LLM backbones using 7 metrics.

## Results

Across 13 LLM backbones, the Mixed Attack (combining DPI, IPI, and Memory Poisoning) achieves the highest average Attack Success Rate of 84.30%, while DPI alone reaches 72.68% and PoT Backdoor reaches 42.12%. Memory Poisoning is the least effective single attack at 7.92% average ASR. Current defenses are largely ineffective: even the best defense (Dynamic Prompt Rewriting) only reduces DPI ASR from 78.38% to 44.45%, and IPI defenses reduce ASR by at most 3.02 percentage points. The proposed Net Resilient Performance (NRP) metric reveals that Claude-3.5 Sonnet (NRP 43.56%), LLaMA3-70B (30.03%), and GPT-4o (28.12%) best balance utility and security, while the average NRP across all backbones is only 15.64%.

## Baselines & Comparisons

As a benchmark paper, ASB compares 13 LLM backbones under a unified attack/defense protocol rather than proposing a single method. Among backbones, GPT-4o-mini is the most vulnerable (67.55% avg ASR, only 1.40% refusal), while Mixtral-8x7B and LLaMA3-8B are most resistant (19.01% and 20.26% avg ASR) but at the cost of near-zero task performance (PNA 0.00% and 1.50%). GPT-4o shows the highest PoT Backdoor ASR (100.00%) yet also the highest DPI refusal rate (20.05%), illustrating the trade-off between instruction-following and safety. On the defense side, Dynamic Prompt Rewriting is the only defense that meaningfully reduces DPI ASR (−33.93 pp), while Delimiters, Instructional Prevention, and Sandwich Prevention provide negligible protection (≤3 pp reduction). Compared to prior benchmarks InjecAgent and AgentDojo, ASB is broader in scope: it covers 5 attack types (vs. 1 for InjecAgent), 10 scenarios (vs. 3 for AgentDojo), 11 defenses, and introduces the novel PoT Backdoor attack and NRP metric absent from both.

## Relation to Prior Work

This paper builds on the ReAct agent framework (Yao et al., 2022) as its operational substrate and adapts BadChain's (Xiang et al., 2024b) backdoor chain-of-thought concept to the agent planning stage, introducing the novel Plan-of-Thought (PoT) backdoor attack. It departs from prior agent security benchmarks—InjecAgent (Zhan et al., 2024) and AgentDojo (Debenedetti et al., 2024)—which are limited to indirect prompt injection or a narrow set of scenarios, by unifying DPI, IPI, memory poisoning, PoT backdoor, and mixed attacks across 10 diverse domains. The memory poisoning formulation extends prior RAG poisoning work (Zhong et al., 2023; Chen et al., 2024) by treating the memory database as a black box and analyzing its impact on the full agent loop rather than on retrieval alone.

## Why It Matters / Open Questions

ASB provides the first holistic, multi-attack, multi-scenario benchmark for LLM agent security, and its results—84.30% average ASR for mixed attacks with only 3.22% refusal, and near-ineffective defenses (best defense reduces DPI ASR only from 78% to 44%)—quantify a critical gap that the field has lacked. The NRP metric and the finding that agent performance systematically underperforms LLM leaderboard scores offer practical guidance for backbone selection. Open questions include whether stronger architectural defenses (beyond prompt-level mitigations) can close the gap, how these vulnerabilities manifest in multi-agent or long-horizon settings, and whether the PoT backdoor generalizes to fine-tuned or safety-aligned agents.

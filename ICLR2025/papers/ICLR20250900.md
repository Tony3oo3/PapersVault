## Problem

Speculative decoding accelerates LLM inference by drafting tokens with a small model and verifying them with a large target model, but the standard verification procedure checks each draft token independently and stops at the first rejection. This paper shows that token-by-token verification is not optimal: jointly verifying the entire draft block can accept more tokens in expectation while preserving the exact output distribution of the target model.
![Teaser figure](../imgs/ICLR20250900/cropped_page1_idx0.webp)

## Input / Output

The algorithm receives a draft block of γ tokens from the small model, the small model's conditional distributions along the draft path (M_s(·|c, X^i) for i < γ), and the large model's conditional distributions along the same path (M_b(·|c, X^i) for i ≤ γ). It outputs an accepted prefix X^τ (where τ ≤ γ) of the draft block plus one additional token Y sampled from either the target model or a residual distribution. Crucially, the method only requires conditional distributions along the realized draft path (partial information), not the intractable full joint distribution over all token sequences.

## Method

Block Verification replaces the sequential break-at-first-rejection logic with a joint acceptance rule over all sub-block lengths. It computes a cumulative probability p_i = min{p_{i-1} · M_b(X_i|c,X^{i-1}) / M_s(X_i|c,X^{i-1}), 1} for each prefix length i, then uses a single set of uniform random variables to select the longest sub-block whose acceptance threshold is met (τ = argmax{η_i ≤ h_i^block} rather than argmin). The per-sub-block acceptance probabilities h_i^block and the residual distribution p_res^block are derived to ensure the marginal output distribution exactly matches the target model. The paper proves two key theorems: (1) Block Verification is a valid verification algorithm preserving the identical distribution guarantee, and (2) it is optimal among all valid verification algorithms, achieving the highest expected number of decoded tokens per iteration. Empirically, this yields 7–10% improvements in block efficiency and 5–8% wall-clock speedups over token verification across diverse tasks and model families (PALM-2, Vicuna), with no additional code complexity.

## Results

With γ=8, PALM-2-S as target and PALM-2-XXS as drafter, Block Verification improves block efficiency from 3.41 to 3.70 (average +8.30%) and wall clock speedup from 2.30× to 2.45× (average +6.49%) over Token Verification across 8 datasets. The block efficiency gain ranges from 7.00% (WMT-DeEn) to 10.06% (GPT Prompt), and the wall clock gain ranges from 5.36% to 8.14%. On Spec-Bench with Vicuna-7B/68M at temperature 1.0, the improvement reaches 8.70% in block efficiency and 6.07% in wall clock speedup, with gains shrinking at lower temperatures (3.72% at T=0.2).

## Baselines & Comparisons

The sole baseline is Token Verification (TOKENV) from Leviathan et al. (2022), the standard sequential rejection-sampling verification used in all prior speculative decoding work. Block Verification (BLOCKV) wins on every dataset and every metric tested: it achieves a consistent 7–10% improvement in block efficiency and 5–8% improvement in wall clock speedup over TOKENV with PALM-2 models, and up to 8.7% / 6.7% on Spec-Bench with Vicuna models. The relative gain increases with draft length γ (from 0% at γ=1 where the two algorithms are identical, to larger values at γ=8) and is more pronounced with a higher-quality drafter (PALM-2-XXS vs. PALM-2-XXXS). The improvement also scales with sampling temperature, vanishing at T=0 (greedy decoding) where both algorithms reduce to deterministic token matching. The paper proves BLOCKV is optimal among all valid verification algorithms, so no other baseline can outperform it under the same drafting model.

## Relation to Prior Work

This paper builds directly on the speculative decoding framework of Leviathan et al. (2022), which introduced the draft-and-verify paradigm with token-by-token rejection sampling as the standard verification procedure. The key conceptual departure is the observation that this token-level verification is provably suboptimal: by jointly verifying the entire draft block rather than sequentially rejecting at the first mismatch, one can accept more tokens while preserving the identical-distribution guarantee. The paper positions itself as a drop-in replacement for the verification step, orthogonal to the many prior works that improve the drafting phase (retrieval-based, cascaded, distilled, hierarchical drafters), and notes only one other concurrent work (Hu and Huang, 2024) that modifies the verification step.

## Why It Matters / Open Questions

The result that the default verification algorithm used across the entire speculative decoding literature is suboptimal is a clean theoretical correction with immediate practical value: block verification is a minimal code change, provably optimal among all valid verification algorithms, and can only improve (never degrade) performance. The 5–8% wall-clock speedup is modest in absolute terms but comes essentially for free, making it a strong default for production systems. Open questions include extending block verification to the multi-draft setting (SpecTr, SpecInfer) and systematically combining it with improved drafting strategies, which the authors leave for future work.

## Problem

Learning Granger causality in geographically distributed industrial systems requires understanding how one client's state affects others, but existing methods either centralize all high-dimensional measurements (infeasible at scale) or assume prior knowledge of the full state matrix. No federated framework existed for collaboratively estimating the cross-client (off-diagonal) blocks of the state matrix while keeping raw data local.

## Input / Output

Each client m receives high-dimensional time-series measurements y_m^t ∈ R^{D_m} (with D_m >> P_m, e.g., D=8–128 vs. P=2) and uses known diagonal blocks A_mm, C_mm to produce low-dimensional state estimates (h_m^t)_c ∈ R^{P_m}. Only these P_m-dimensional states (not raw measurements) are communicated to the server, saving 144–176 bytes per communication round on real ICS datasets. The output is the learned off-diagonal state matrix blocks Â_mn (n≠m) encoding cross-client Granger causality, plus augmented state estimates at each client.

## Method

The framework uses a Kalman filter as each client's base model (using only A_mm, C_mm) and augments it with a linear ML function θ_m·y_m^t whose parameter implicitly encodes cross-client causality. A central server receives all clients' low-dimensional states, predicts states using the known diagonal blocks plus learned off-diagonal blocks Â_mn, and minimizes the discrepancy against augmented client states via gradient descent. The iterative update is co-dependent: θ_m^{k+1} depends on Â_mn^k and vice versa, which the paper formalizes as a unified recurrence Δ^{k+1} = H·Δ^k + J, proving convergence iff ρ(H)<1 with sublinear O(1/k) and linear O((1−μ/L)^k) rates under convexity and strong-convexity conditions. A centralized oracle benchmark yields bounded estimation error on the off-diagonal blocks, and differential privacy is ensured by adding calibrated Gaussian noise to client states and clipped server gradients.

## Results

On synthetic two-client data, the framework recovers the ground-truth Granger causality matrix A₂₁ = [[0.25, 0.25],[0.25, 0.25]] with an estimate of [[0.2793, 0.2441],[0.3351, 0.3298]], and correctly identifies the absence of reverse causality (A₁₂ ≈ 0). Under 125% perturbation of causality, the method's server loss rises to 0.013 and client-2 loss to 0.93, both increasing monotonically with perturbation magnitude, confirming detection of causality shifts. On real-world ICS datasets, the federated approach achieves a Frobenius-norm estimation error of 0.8140 (HAI) and 3.0816 (SWaT) relative to a centralized oracle, while saving 144 and 176 bytes per communication round respectively.

## Baselines & Comparisons

The paper benchmarks against three baselines: (1) the framework without client augmentation, (2) the framework without the server model, and (3) pre-trained client models from Ma et al. (2023). The 'No client aug.' baseline fails entirely—its server loss remains at 10⁻⁵ across all perturbation levels and topology changes, indicating no causality is learned. The 'No server model' baseline produces client-side loss signals but provides no server-level detection. Compared to the Ma et al. (2023) pre-trained client baseline, the proposed method achieves lower server loss at every perturbation level (e.g., 0.003 vs. 0.007 at ε=5%; 0.013 vs. 0.028 at ε=125%) and lower server loss under topology reversal (0.033 vs. 0.065), demonstrating that iterative server-client co-optimization yields more accurate causality estimation than one-shot pre-training. However, the pre-trained client baseline produces higher client-side losses (e.g., 1.135 vs. 0.93 at ε=125%), suggesting the proposed method's client augmentation is more sensitive to causality shifts. On real-world ICS data, the federated approach matches the centralized oracle within a Frobenius error of 0.81 (HAI) and 3.08 (SWaT) while saving 144–176 bytes per communication round.

## Relation to Prior Work

This paper sits at the intersection of Granger causality estimation (Granger, 1969), state-space system identification, and vertical federated learning. It departs from centralized GC methods (which require aggregating all measurements) and from distributed Kalman filtering (which typically assumes the state matrix A is known a priori) by formulating a federated framework where clients share only low-dimensional state estimates and the server iteratively learns the off-diagonal blocks of A. The authors explicitly position this as the first study on federated Granger causality learning, distinguishing it from split learning and multi-task learning by preserving full client model autonomy and from prior VFL work by operating on time-series with LTI state-space structure rather than tabular features.

## Why It Matters / Open Questions

The framework addresses a practical bottleneck in distributed industrial monitoring: learning cross-client interdependencies without centralizing high-dimensional sensor data, with provable convergence rates and differential privacy guarantees. Validation on HAI and SWaT ICS datasets demonstrates data savings (144–176 bytes per round) while maintaining estimation accuracy. Key open questions include the client model's inability to reliably flag network topology changes (risking false alarms), the restriction to linear ML augmentation and LTI dynamics, and whether the bounded-error guarantees tighten under richer state representations. Extending to non-linear or time-varying systems and to larger-scale deployments remains future work.

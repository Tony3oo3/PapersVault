## Problem

Existing LLM text detectors perform binary classification on entire texts, but real-world texts are often only partially LLM-written (e.g., a few sentences edited by an LLM within a human-authored paragraph). This binary framing cannot estimate how much of a text is LLM-generated or locate which specific segments are machine-written, leading to either over-penalization of light LLM use or under-detection of substantial LLM involvement.

## Input / Output

The method takes a text segmented into n sentences (typically n ≤ 10) and a pre-trained T-score model (a scalar function T: X → R, e.g., RoBERTa-LN logits) as input. It produces two types of output: (i) a point estimate δ̂ and a (1−α) highest-density interval (δ̂_L, δ̂_R) for the character-level LLM fraction, and (ii) a subset Ŝ ⊆ {1,…,n} of segment indices predicted to be LLM-written, with the constraint that neither S=∅ nor S={1,…,n} is considered (reducing to 2ⁿ−2 candidate sets). The T-score model must be pre-trained on fully-human vs. fully-LLM texts; PaLD itself is black-box with respect to the T-score.

## Method

PaLD builds a Bayesian framework on top of existing T-scores. For percentage estimation (PaLD-PE), synthetic mixed texts are generated via a mask-and-fill procedure (randomly masking sentences in human texts and prompting GPT-4o to fill them), producing T-score samples binned by LLM fraction δ_k. A mixture of Gaussian KDEs models the likelihood P(T(X)|Δ), and a Beta(2,2) prior is placed on Δ; MAP point estimates and HDI intervals are obtained via Metropolis-Hastings sampling (5000 draws, 1000 burn-in). For text identification (PaLD-TI), the method formulates a combinatorial set optimization: find S ⊆ {1,…,n} maximizing f_x(S) = T(x[S]) − T(x[S^C]), where x[S] is the stitched text of segments in S. This is solved exactly for n ≤ 10 or approximately via a greedy O(n²) algorithm. The key insight is that T-scores, though designed for binary human/LLM classification, exhibit a smooth distributional shift as the LLM fraction varies, enabling them to serve as sufficient statistics for finer-grained estimation when combined with the Bayesian mixture model.

## Results

On the percentage estimation task (MAE ↓), PaLD-PE achieves 0.116 on WritingPrompts and 0.137 on Yelp, outperforming the strongest baselines (RoBERTa-Reg at 0.207/0.181 and FastDetectGPT-Seg at 0.184/0.190) by 40–45%. On the LLM text identification task, PaLD-TI reaches 82.6% segment accuracy and 25.2% top-1 set accuracy on WP, exceeding the best baseline (FastDetectGPT-Seg at 65.1% seg-acc, 6.3% top-1) by 17.5 and 18.9 percentage points respectively. The greedy approximation (PaLD-TI-Greedy) retains 74.1% seg-acc while reducing runtime from ~30s to ~2.1s per 10-segment text.

## Baselines & Comparisons

PaLD-PE outperforms all five baselines on both datasets for percentage estimation. Against DetectGPT-Seg (Mitchell et al., 2023), PaLD-PE reduces MAE from 0.370 to 0.116 on WP (a 69% relative improvement) and from 0.397 to 0.137 on Yelp. FastDetectGPT-Seg (Bao et al., 2024) is the closest zero-shot baseline at 0.184/0.190 MAE, still trailing PaLD-PE by 0.068/0.053. Ghostbuster-Seg (Verma et al., 2024) achieves 0.215/0.282 MAE, roughly 1.8× worse than PaLD-PE. The supervised RoBERTa-Seg (Liu et al., 2019) and RoBERTa-LN-Seg (Wei et al., 2022) baselines, which apply a binary classifier segment-wise, perform worst among the learned methods (0.342–0.437 MAE), confirming that short segments degrade per-segment classification. For text identification, PaLD-TI dominates all baselines by ≥18% in segment accuracy and ≥19% in top-1 set accuracy; no baseline exceeds 7% top-1 accuracy, while PaLD-TI reaches 25.2%.

## Relation to Prior Work

PaLD repurposes T-scores from existing binary LLM-text detectors (DetectGPT, FastDetectGPT, Ghostbuster, RoBERTa-based classifiers) for a fundamentally different problem: rather than thresholding a single score for a yes/no decision, it models the T-score distribution as a function of the LLM fraction δ and performs Bayesian inference to estimate that fraction. The Bayesian machinery (mixture KDE likelihood, Beta prior, Metropolis-Hastings sampling, MAP and HDI estimation) is drawn from general Bayesian statistics rather than from any specific prior detection paper. For text identification, the set-optimization formulation that maximizes T-score discrepancy between a candidate LLM segment set and its complement is novel in this context, departing from the segment-wise classification approach used by prior boundary-detection work (RoFT, SeqXGPT).

## Why It Matters / Open Questions

The paper addresses a practically critical gap: real-world text is often partially LLM-written, yet all prior detectors only output a binary label, leading to unjust penalties or missed detection as illustrated in Fig. 2. Key limitations include the NP-hard text identification problem (mitigated only by a greedy approximation), the requirement for a fixed segmentation that may not align with ground truth, and degraded performance when the generating LLM is much smaller (GPT-2) than the one used during training. Open questions include better scalable solvers for TI, handling segmentation mismatch, extending to hallucination detection, and robustness against humans deliberately mimicking LLM styles.

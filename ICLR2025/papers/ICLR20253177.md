## Problem

Equivariant message passing based on local canonicalization transforms node features into per-node local reference frames, making them invariant to global rotations and reflections. However, when messages are passed between nodes with different local frames, scalar message passing loses directional and tensorial geometric information because the coordinates of a feature are invariant under local rotations of the sender's neighborhood. This fundamentally limits the expressiveness of local-canonicalization-based equivariant architectures, particularly for tasks requiring precise propagation of geometric quantities like surface normals.

## Input / Output

The method consumes 3D point clouds (1024–2048 points) with per-node geometric features such as positions and surface normals, organized as a radius graph with a cutoff radius. Outputs are equivariant geometric objects whose representation (scalar, vector, pseudovector, or higher-order tensor) is chosen per task: per-point normal vectors for regression, a single class label for classification, or per-point semantic labels for segmentation. The framework generalizes to O(d) spaces of arbitrary dimension, and the output representation can be freely specified at the final layer without architectural changes.

## Method

The framework predicts an equivariant orthonormal local frame R_i at each node via a weighted sum of normalized edge vectors followed by Gram-Schmidt orthogonalization, with a sign-flip rule on the third axis to ensure O(3) (not just SO(3)) equivariance. Node features are then expressed in their local frame, yielding invariant coordinates that can be processed by arbitrary MLPs, non-linearities, and normalization layers. The key novelty is the tensorial message passing step: during aggregation, each neighbor's feature f_j is transformed from its local frame into the receiver's frame via the representation ρ_f(R_i R_j^{-1}), where ρ_f is a freely chosen direct sum of tensor and pseudotensor representations, preserving global geometric direction. Local frames can be iteratively refined after each layer by predicting a small SO(3) rotation from the updated invariant features. The approach is demonstrated as a drop-in modification of PointNet++, where the standard max-pooling message passing is replaced by the tensorial form, and the same architecture can be trained with or without data augmentation for direct comparison.

## Results

On normal vector regression (the primary task) on ModelNet40, the best model (learned frames + iterative refinement + tensorial messages) achieves 0.88 cosine similarity, which is state-of-the-art among equivariant methods and outperforms the data-augmentation baseline (0.86) in the full O(3)/O(3) setting. On ShapeNet segmentation, the same model reaches 80.2% IoU, competitive with VN-DGCNN (81.4%) and CRIN (80.5%), while substantially outperforming data augmentation (78.0%) under O(3)/O(3). On ModelNet40 classification, the method achieves 88.7% accuracy, competitive with but below the best equivariant baselines (CRIN: 91.8%, Li et al.: 91.6%).

## Baselines & Comparisons

The paper's strongest result is on normal vector regression, where tensorial messages with iterative frame refinement (0.88) decisively outperform the closest equivariant baseline Luo et al. (0.80) by 0.08 cosine similarity, and also beat the data-augmentation baseline (0.86) in the O(3)/O(3) setting. On ShapeNet segmentation, the method (80.2% IoU) is competitive with VN-DGCNN (81.4%) and CRIN (80.5%) but falls slightly short, while it clearly outperforms data augmentation (78.0%) and all non-equivariant baselines like DGCNN (73.3%) and PointNet (74.4%). On ModelNet40 classification, the method (88.7%) trails the top equivariant baselines CRIN (91.8%) and Li et al. with TTA (91.6%) by roughly 3 percentage points, though it still beats DGCNN (88.6%), TFN (87.6%), and data augmentation (86.6%). The ablation in Table 3 confirms that tensorial messages provide a consistent +0.05 gain over scalar messages regardless of whether local frames are learned or random, and that learned frames add a further +0.03 over random frames. Overall, the method wins or ties on the primary task (normal regression) and is competitive but not SOTA on the secondary tasks (segmentation and classification), with the clearest advantage being the exact equivariance guarantee and improved data efficiency over data augmentation.

## Relation to Prior Work

This paper extends the local canonicalization framework for equivariant message passing (Luo et al., 2022; Wang & Zhang, 2022) by introducing tensorial messages that transform geometric features between local reference frames via change-of-basis operations. While tensor field networks (Thomas et al., 2018) and E(n)-GNNs (Satorras et al., 2021) incorporate tensorial representations, they require specialized non-linearities and norm layers; here, the local canonicalization step converts all features to invariant scalars, so standard building blocks (MLPs, SiLU, batch norm) can be used freely. The iterative refinement of local frames after each message passing layer is a strict generalization of the static local canonicalization used in prior work, and the adaptation of PointNet++ demonstrates the framework's drop-in applicability to existing architectures.

## Why It Matters / Open Questions

The framework provides a practical, architecture-agnostic recipe for making any message passing network O(d)-equivariant without specialized components, and uniquely enables a controlled comparison between exact equivariance and data augmentation under identical hyperparameters. The finding that equivariant models show steeper data-efficiency scaling but are not uniformly more accurate at all dataset sizes connects to ongoing debates about whether equivariance verifiably improves scaling (Brehmer et al., 2024). Open questions include whether the advantage of tensorial messages persists in higher-dimensional or non-Euclidean settings, and whether the iterative frame refinement can be made more principled than the current MLP-based update.

## Problem

Existing graph self-training methods select pseudo-label nodes independently by ranking confidence scores, ignoring the combinatorial dependencies between candidate nodes and operating with only a local view of the data distribution. This leads to information redundancy among selected nodes, suboptimal information gain, and sensitivity to noisy pseudo-labels. The paper asks how to select a set of unlabeled nodes jointly—accounting for their collective contribution to reducing uncertainty over the entire unlabeled distribution—while providing theoretical guarantees under noisy utility estimation.

## Input / Output

The method consumes a graph (adjacency matrix and node feature matrix), a small labeled node set with ground-truth labels, and a pre-trained base GNN (e.g., 2-layer GCN). At each self-training iteration, it outputs a combinatorially selected set of k unlabeled nodes to receive pseudo-labels, which are then used to retrain the student model. A key design choice is that the utility function for node ranking is computed via PPR-based feature propagation of teacher-model logits rather than by actually retraining the model, making the selection step decoupled from the expensive retraining step. The Banzhaf values are estimated via Maximum Sample Reuse Monte Carlo with B=500 samples per node.

## Method

BANGS formulates node selection as maximizing the conditional mutual information between unlabeled ground-truth labels and the student model's predictions, which decomposes into maximizing prediction confidence while encouraging diversity in the predicted label distribution. To estimate the student model's output without retraining, it propagates teacher-model logits through the graph using personalized PageRank (equivalent to L-step random walks under linear aggregation with ReLU), yielding an efficient approximation of the student's logits for all unlabeled nodes. Node importance is then computed via a k-Bounded Banzhaf value from cooperative game theory, which measures each node's marginal contribution to the utility function (information gain minus cross-entropy on labeled data) across all coalitions up to size k, thereby capturing combinatorial dependencies that independent ranking misses. The paper proves that the Banzhaf-based ranking is preserved under bounded utility perturbation, and that independent selection is provably suboptimal due to non-submodularity and interaction information effects. In practice, the Banzhaf values are estimated via MSR Monte Carlo sampling, and the PPR propagation is computed with H-step power iteration to avoid explicit matrix inversion.

## Results

BANGS achieves the best node classification accuracy across all five datasets using a 2-layer GCN as the base model. Headline results: 84.23% on Cora, 73.96% on Citeseer, 81.60% on PubMed, 83.27% on LastFM, and 50.23% on Flickr. The largest margin over the second-best method is on LastFM (+2.58% over CPL), while on Flickr the gain is marginal (+0.13% over Random). Statistical significance (one-sided t-test) is confirmed at p<0.05 on Citeseer, PubMed, and LastFM, and at p<0.10 on Cora.

## Baselines & Comparisons

BANGS outperforms all six baselines on every dataset. Against the strongest confidence-based baseline CPL (multi-view confidence with dropout), BANGS gains +0.51% on Cora, +0.33% on Citeseer, +0.60% on PubMed, and a substantial +2.58% on LastFM. Against CaGCN (calibrated threshold selection), the advantage is +1.17% on Cora and +0.44% on PubMed. DR-GST, which reweights pseudo-labels by information gain, is notably weaker on PubMed (78.10% vs. BANGS's 81.60%), suggesting that post-hoc reweighting is less effective than the combinatorial Banzhaf-based selection. On Flickr, where all methods cluster around 50%, BANGS still edges out Random selection by +0.13%. The ablation (Table 2) further confirms that removing the Banzhaf component (BANGS No Banzhaf) degrades performance by 0.5–3.2% across datasets, validating that the combinatorial game-theoretic selection is the key differentiator over independent confidence ranking.

## Relation to Prior Work

BANGS sits at the intersection of graph self-training (where prior methods like M3S, CaGCN, DR-GST, and CPL select nodes independently by confidence ranking) and cooperative game theory (Banzhaf values from Owen 1975, adapted via Wang & Jia 2023's Data Banzhaf framework). The key conceptual departure is reframing node selection as a combinatorial coalition problem rather than an independent ranking task, using PPR-based feature propagation (Gasteiger et al. 2018) to estimate student model outputs without retraining. The mutual information objective connects to the broader semi-supervised learning literature on entropy-based criteria, but the paper's novelty lies in unifying the selection criterion, the utility function design, and the combinatorial dependency modeling into a single game-theoretic framework with theoretical guarantees.

## Why It Matters / Open Questions

The paper provides a principled theoretical argument (non-submodularity proof, interaction information analysis) for why the widely-used independent confidence-based selection is suboptimal, and offers a concrete alternative with provable robustness under noisy utility estimation. However, the practical gains are modest (~0.5–2.5% over best baselines), and the framework relies on simplified assumptions: the teacher model equals the previous student, pseudo-labels from earlier rounds are never revised, and the feature influence approximation assumes linear aggregation with ReLU. Open questions include scalability to large-scale and heterophilic graphs, whether the PPR-based estimation holds for more complex GNN architectures (GIN with max aggregation already shows degradation), and whether influence functions could replace the current utility function for greater efficiency.

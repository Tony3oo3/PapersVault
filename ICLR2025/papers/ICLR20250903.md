## Problem

Existing adaptation techniques for foundation models—prompt engineering, in-context learning, and supervised fine-tuning—all require either manual effort to craft effective prompts or access to labeled examples. This paper asks whether a foundation model can adapt to a new task in a fully unsupervised manner, using only its own predictions as feedback, without any ground-truth labels or hand-designed prompts.
![Teaser figure](../imgs/ICLR20250903/cropped_page1_idx1.webp)

## Input / Output

The method takes a set of N unlabeled input instances (text sentences, or image+text question pairs) and produces a prediction for each instance simultaneously, exploiting dependencies across the set. For close-ended tasks the output is a single class label per input; for open-ended reasoning tasks (GSM8K, MMLU-Pro) the output includes a full chain-of-thought reasoning trace followed by the final answer. Unsupervised ICL requires only next-token generation access (compatible with API-only models like GPT-4o), while unsupervised fine-tuning additionally requires access to model weights and output token probabilities.

## Method

The core idea is joint inference: instead of maximizing p(y|x) independently for each input, the framework optimizes the joint likelihood p(y₁,…,y_N | x₁,…,x_N) over a batch of N inputs, which encourages consistent and mutually reinforcing predictions. Two approximations make this tractable. Unsupervised fine-tuning amortizes the combinatorial optimization by training a LoRA-parameterized task encoder (the FM itself) via a REINFORCE-based objective with a custom low-variance gradient estimator that exploits the autoregressive structure, plus an entropy regularization term to prevent collapse to a single answer. Unsupervised ICL observes that each summand in the joint objective is itself an ICL prediction, and performs multi-turn iterative refinement: at each turn, the model is prompted with N randomly sampled in-context examples whose labels come from the model's own previous-turn outputs (initialized from zero-shot predictions), analogous to Gibbs sampling over the joint distribution. This second method requires no weight access and is applicable to any foundation model, including closed-weight APIs.

## Results

On 13 NLP tasks with Llama-3.1-8B, unsupervised fine-tuning (LoRA) achieves 83.1% average accuracy, a 23% absolute improvement over zero-shot (60.1%), while unsupervised ICL reaches 79.3% (19.2% improvement). On GSM8K math reasoning, unsupervised ICL applied to Qwen2.5-Math-7B yields 91.4% accuracy, a 39.2% absolute gain over zero-shot (52.2%) and outperforming supervised ICL (89.9%). For vision tasks with OpenFlamingo, unsupervised fine-tuning brings 14% average absolute improvement (e.g., 96.0% on CIFAR-10 vs. 87.2% zero-shot), and unsupervised ICL matches supervised ICL on 5 of 7 datasets. On closed-weight GPT-4o, unsupervised ICL improves over zero-shot+CoT by 3% on ImageNet-100, 2% on MMMU, and 1% on MMMU-Pro.

## Baselines & Comparisons

Compared to zero-shot + Chain-of-Thought (Kojima et al., 2022), both proposed methods deliver large gains: unsupervised FT averages 83.1% vs. 57.0% for CoT, and unsupervised ICL averages 79.3% vs. 57.0%, with the gap widening on reasoning-heavy tasks (e.g., HellaSwag: 65.5% vs. 34.6% for FT). Against supervised ICL (Brown et al., 2020), unsupervised ICL (79.3% avg) closely matches its supervised counterpart (82.6% avg), achieving parity or near-parity on 10 of 13 NLP datasets; on GSM8K with Qwen2.5-Math-7B, unsupervised ICL (91.4%) actually surpasses supervised ICL (89.9%). Unsupervised FT (83.1%) approaches fully-supervised FT (90.1%), matching it on 6 of 13 datasets (e.g., SST2: 92.3% vs. 92.1%; DBpedia: 98.7% vs. 98.8%), though it lags more on tasks like TREC (61.9% vs. 93.7%) and MNLI (72.0% vs. 84.7%). For vision tasks, unsupervised ICL matches supervised ICL on 5 of 7 datasets (e.g., CIFAR-10: 92.6% vs. 93.0%; COCO-Color: 57.5% vs. 58.2%), while unsupervised FT reaches 96.0% on CIFAR-10 vs. 97.5% for supervised FT.

## Relation to Prior Work

This paper builds on the In-Context Learning framework of Brown et al. (2020) and the fine-tuning paradigm of LoRA (Hu et al., 2022), but departs from both by formulating a joint inference objective that simultaneously optimizes predictions across multiple inputs rather than treating each independently. The unsupervised ICL method can be viewed as a label-free analogue of supervised ICL that resembles Gibbs sampling over the joint distribution, while the unsupervised fine-tuning method instantiates a self-training loop using REINFORCE-style gradient estimation over the joint likelihood. The paper positions itself against prior probabilistic inference work (GFlowNets, Sequential Monte Carlo) by developing a principled amortized optimization that exploits the specific autoregressive structure of the joint objective, and against RL-for-FMs work by using the model's own joint probability as the reward signal rather than external feedback.

## Why It Matters / Open Questions

The practical impact is significant: the unsupervised ICL method requires only next-token generation access, making it immediately applicable to closed-weight API models like GPT-4o, while the unsupervised fine-tuning method provides a principled optimization for open-weight models. Key limitations include the requirement that the base model already exhibit ICL capabilities (the framework amplifies existing ICL ability rather than creating it), the restriction of unsupervised fine-tuning to close-ended tasks with finite answer sets, and the observation that unsupervised ICL generally trails unsupervised fine-tuning. Open questions include whether the gap between the two methods will close as context windows grow, whether the joint inference formulation extends cleanly to fully open-ended generation tasks, and whether the self-improvement loop can be made more stable for very small models with weak ICL capabilities.

## Problem

Prior discrete diffusion models learn the denoising Markov chain by solving regression problems (ratio matching) or minimizing variational loss functions, which are complex and scale quadratically with vocabulary size. This paper asks whether the denoising process can be reduced to a simpler, more fundamental learning task, and shows that it can be reduced exactly to binary classification.
![Teaser figure](../imgs/ICLR20250234/cropped_page3_idx0.webp)

## Input / Output

For unconditional generation, the model starts from a random token sequence drawn from the noise distribution (e.g., 1024 tokens for 256×256 images via a VQGAN tokenizer, or 1024 text tokens) and iteratively denoises one token at a time over T=4096 steps. For conditional generation (infilling), the input is a partially specified token sequence where prompt positions are fixed and the remaining positions are initialized as noise; the model fills in the masked positions while preserving the prompt tokens. The output is a full token sequence that is de-tokenized into text or a 256×256 RGB image.

## Method

GGM uses a time-dependent Glauber dynamics (heat bath dynamics) as the denoiser, which flips exactly one token per step in a fixed round-robin order over positions. The key theoretical contribution is an exact reduction: learning the reverse Glauber dynamics is equivalent to solving O(T|X|) binary classification problems, where the model predicts whether a token at position i_t in the noisy sequence is 'signal' (preserved from the previous step) or 'noise' (randomly resampled). The architecture is a 24-layer DiT-based transformer with adaLN-Zero time encoding and rotary position embeddings; at each step it receives the sequence with a mask token ω at the active position plus the timestep, and outputs per-token noise probabilities via sigmoid. Inference converts these binary probabilities into the full denoising distribution using a closed-form formula (Lemma 3), enabling top-p sampling. This yields O(T|X|) training complexity versus O(|X|²T) for prior discrete diffusion approaches like D3PM.

## Results

On language generation (OpenWebText, 1024 tokens), GGM (387M params) achieves a generative perplexity of 18.0 when evaluated by GPT-Neo-2.7B, outperforming SEDD-medium (424M, PPL 25.2) and MDLM (170M, PPL 40.9), and matching Plaid (1.3B, PPL 17.9) with 3.4× fewer parameters. On image generation (256×256), GGM using the off-the-shelf MUSE VQGAN tokenizer achieves FID 12.5 on FFHQ, competitive with BigGAN (12.4) and outperforming VQGAN+PixelSNAIL (21.9) and StyleSwin baseline (15.0), without any dataset-specific tokenizer. On CelebA-HQ, GGM beats the 801M-parameter VQGAN+GPT2 autoregressive model (FID 10.2) and VQ-DDM (FID 13.2/22.6).

## Baselines & Comparisons

GGM clearly outperforms the prior state-of-the-art discrete diffusion models: SEDD-medium (424M) by ~7 PPL points and MDLM (170M) by ~22 PPL points on the GPT-Neo-2.7B evaluation. GGM is essentially tied with Plaid (1.3B) — 18.0 vs 17.9 on GPT-Neo — while using 3.4× fewer parameters and training on a smaller dataset (OpenWebText vs OpenWebText2). However, all diffusion-based approaches (including GGM) remain significantly behind autoregressive GPT2 models of comparable size (e.g., GPT2-medium at 14.5 vs GGM at 18.0). GGM dramatically outperforms time-independent Glauber dynamics via BERT-large + Gibbs sampling (PPL 28.7 even with 65,536 steps vs GGM's 18.0 with 4,096 steps). On image generation, GGM (FID 12.5 on FFHQ) beats autoencoder baselines (VDVAE 28.5–33.5), StyleSwin baseline (15.0), and VQGAN+PixelSNAIL (21.9), is competitive with BigGAN (12.4), but trails SoTA methods like LDM-4 (5.0), VQ-Diffusion (6.3), and full StyleSwin (2.8) — a gap the authors attribute to the use of a general-purpose rather than dataset-specific tokenizer.

## Relation to Prior Work

GGM repurposes Glauber dynamics (heat bath dynamics) from statistical physics as the denoising mechanism for discrete diffusion, departing from prior discrete diffusion models (D3PM, Argmax flows, SEDD, MDLM) that noise all tokens simultaneously and learn denoisers via regression on importance ratios or variational objectives. The key conceptual departure is an exact reduction of the denoising Markov chain to a class of binary classification problems (predicting whether a token is signal or noise), which scales linearly in vocabulary size rather than quadratically as in prior transition-matrix approaches. Architecturally, the model follows the DiT family and SEDD's use of rotary embeddings and adaLN-Zero, but introduces time-dependent, round-robin-scheduled single-token updates that distinguish it from both standard Gibbs sampling and prior discrete diffusion samplers.

## Why It Matters / Open Questions

The binary classification reduction provides a theoretically clean and computationally simpler training objective for discrete diffusion, and the empirical results show GGM outperforming prior discrete diffusion models (SEDD, MDLM) in language generation while remaining competitive with much larger models like Plaid. However, the paper is candid that discrete diffusion models still lag significantly behind autoregressive LLMs for language and behind GANs/continuous diffusion for images, with the gap attributed partly to the use of a general-purpose (non-dataset-specific) tokenizer. Open questions include whether noise schedule optimization, dataset-specific tokenizers, and scaling can close these gaps, and whether the framework extends naturally to protein modeling and other discrete sequence domains.

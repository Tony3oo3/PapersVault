## Problem

SHAP explanations are widely used but suffer from both computational cost and limited representation power, yet the underlying connection between SHAP and generalized additive models (GAMs) has been critically under-emphasized. Prior work establishing the SHAP–GAM correspondence (Bordt & von Luxburg, 2023) only handled independent input variables, leaving the correlated-input case open. Additionally, there is no practical, theoretically grounded test for whether SHAP is trustworthy on a given dataset, and the longstanding GAM purification problem (removing redundant information from shape functions under correlated inputs) remains unsolved.

## Input / Output

The method takes a target model F (e.g., a ResNet-50 on CUB-200 bird images or an MLP on tabular data) and a data distribution p(x) over the input space. During training, input features are masked according to the SHAP kernel distribution p^SHAP(S), and the model receives only the unmasked subset x_S. The output is a set of additive shape functions φ_T(x_T) for all subsets T with |T| ≤ k, which directly yield Shapley values in a single forward pass—no separate explanation computation is needed. For the CUB experiments, the GAM architecture restricts each additive component to a 1×1, 2×2, or 3×3 patch of the image, producing spatially local shape functions.

## Method

InstaSHAP trains a GAM by replacing the standard least-squares objective with one that samples feature subsets S from the SHAP kernel distribution and applies a masking indicator 1(T⊆S) to each additive component, so that a component φ_T is only active when all its constituent features are unmasked. This single modification simultaneously (a) amortizes Shapley value computation into the model's forward pass (as in FastSHAP), (b) recovers higher-order FaithSHAP-k interaction indices through the GAM-k structure, and (c) automatically purifies the shape functions to remove redundant information under correlated inputs. Theoretically, the paper proves that SHAP is equivalent to ANOVA-1 (Theorem 1), meaning it can only succeed when the true function is free of feature interactions, and that ANOVA-k is a strict subset of GAM-k (Theorem 4), giving GAMs strictly greater representational power. This yields a practical trustworthiness check: if a GAM trained on the same data matches the black-box model's accuracy, SHAP explanations are reliable; if a large gap exists (as shown on CUB-200, where ResNet-50 reaches 65% fine-grained accuracy vs. 33% for GAM-1), SHAP is oversimplifying the model's behavior.

## Results

On the CUB-200-2011 bird classification task, a fine-tuned ResNet-50 achieves 65.0% fine-grained and 81.8% coarse-grained accuracy, while the best GAM variant (GAM-3×3) reaches only 46.8% fine and 66.8% coarse accuracy, revealing a ~18-point gap that the authors argue indicates SHAP oversimplifies the CNN's reasoning. On tabular data, a low-dimensional GAM matches or exceeds MLP performance: on Bike Sharing, the low-dim GAM achieves R²=6.23% vs. MLP's 6.59%, and on Tree Cover it reaches 82.2% accuracy vs. MLP's 80.4%. In synthetic experiments, InstaSHAP consistently achieves lower MSE than FastSHAP when approximating Shapley values across varying interaction orders and correlation levels.

## Baselines & Comparisons

Against FastSHAP, InstaSHAP demonstrates a superior inductive bias for learning Shapley values, achieving consistently lower MSE across synthetic experiments with varying interaction orders (k) and input correlation (ρ), attributed to its GAM structure providing a lower-dimensional approximation. Against ResNet-50 on CUB bird classification, all GAM variants (GAM-1 through GAM-3) substantially underperform the CNN by 18–32 points on fine-grained accuracy, which the authors interpret as evidence that SHAP's additive decomposition oversimplifies the high-order and long-range interactions the CNN exploits. On tabular datasets (Bike Sharing, Tree Cover), the low-dimensional GAM actually matches or slightly exceeds the MLP, supporting the paper's claim that SHAP is trustworthy when a GAM can replicate the blackbox's accuracy. The paper does not directly compare InstaSHAP against FaithSHAP in a head-to-head accuracy benchmark, but positions it as a practical deployment of the FaithSHAP-k variational objective with the speed advantage of FastSHAP.

## Relation to Prior Work

This paper unifies the variational (least-squares) formulations of SHAP (Charnes et al., 1988; Lundberg & Lee, 2017), FastSHAP's functional amortization (Jethani et al., 2022), and FaithSHAP's higher-order interaction indices (Tsai et al., 2023) under a single functional ANOVA / GAM lens, extending the SHAP–GAM correspondence of Bordt & von Luxburg (2023) from independent to correlated input variables. The proposed InstaSHAP method repurposes the GAM training objective by replacing the standard data distribution with the SHAP kernel and adding a masking indicator, thereby solving the long-standing GAM purification problem (Hooker, 2007; Lengerich et al., 2020; Sun et al., 2022) as a byproduct. Conceptually, the paper positions SHAP not as a fundamentally different object from additive models but as a specific (and limited) instance of them, reframing recent SHAP improvements as special cases of additive model fitting.

## Why It Matters / Open Questions

The impossibility theorems (Theorems 1–4) formalize a practical diagnostic: if a GAM cannot match a blackbox model's accuracy on a given dataset, SHAP explanations on that dataset are provably incomplete, which is a simple but theoretically grounded check absent from prior literature. The CUB-200 bird classification results (ResNet-50 at 65% vs. GAM-1 at 33.2% fine-grained accuracy) provide concrete evidence that SHAP substantially oversimplifies deep network behavior in high-dimensional CV, a domain where explainability needs are highest. Open questions include whether more expressive GAM architectures (longer-range interactions, higher orders) can close the CV/NLP gap, and whether the observed gap reflects a fundamental representational limitation of additive models or merely a training/architecture deficiency. The purification result also opens the door to Hooker-type purified additive models that were previously computationally intractable.

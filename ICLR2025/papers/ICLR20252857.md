## Problem

Text-to-image diffusion models generate inappropriate content (NSFW imagery, artist style infringement) from prompts containing only obscure or associative terms—so-called implicit unsafe prompts—that lack explicit unsafe words. Existing erasure methods either require per-concept fine-tuning (risking catastrophic forgetting), rely on coarse classifier-based filtering, or manipulate text embeddings that fail to capture implicit associations. No prior approach can precisely suppress target concepts in the image space during inference without retraining the diffusion model.

## Input / Output

The method takes a text prompt (which may contain implicit unsafe terms) and a target concept string to erase (e.g., "nude", "van Gogh", "cat") as input, and produces a generated image in which the target concept is suppressed while other semantics and image quality are preserved. It operates as a plug-and-play inference-time module on any pre-trained Stable Diffusion model (tested on SD v1.4, SD v2.1, and Realistic Vision v6.0), requiring no fine-tuning of the base model. A small MLP adapter, trained on roughly 60 GPT-4o-labeled samples per concept in about 30 seconds, is the only component that requires training.

## Method

GIE extracts a "growth inhibitor" by encoding the target concept separately during diffusion to compute an additional attention map group M*, then isolating the attention map corresponding to the target token and re-weighting it by a learned suppression scale. This weighted feature vector is injected into the original prompt's attention map group at the position preceding [EOT], and the corresponding text embedding is inserted at the same position so that cross-attention dimensions remain consistent. A two-hidden-layer MLP adapter predicts the optimal suppression scale from the mean intermediate values across all cross-attention layers at the first diffusion step, trained with MSE loss against GPT-4o-selected labels that balance erasure effectiveness against image quality. For multi-concept erasure, concepts with high semantic similarity (cosine distance below a threshold) are filtered to prevent overlapping suppression. The entire pipeline runs at inference time without modifying any diffusion model parameters.

## Results

On the I2P dataset (4,703 unsafe prompts), GIE achieves an NSFW Removal Rate (NRR) of 0.712–0.720 for erasing the concept 'nude', substantially outperforming the next-best baseline S-CLIP (0.616–0.637) and ESD-u (0.372–0.561). On COCO-30K, GIE attains the highest CLIP score (26.433) among all methods, indicating the best semantic preservation, while achieving a competitive FID of 15.452 (second only to SPM's 13.566, which requires concept-specific fine-tuning). For object erasure, GIE achieves ORRs above 0.92 for all target objects (car, airplane, cat) using both explicit and synonym prompts, while keeping ORRs below 0.05 for non-target objects.

## Baselines & Comparisons

GIE outperforms all seven baselines on the primary erasure metric (NRR) by a wide margin: it achieves 0.712–0.720 versus S-CLIP's 0.616–0.637, ESD-u's 0.372–0.561, SD v2.1's 0.299–0.545, and SPM's 0.130–0.229. On semantic preservation (CLIP score on COCO-30K), GIE achieves the best score of 26.433, narrowly beating SPM (26.221) and SD v2.1 (26.332), while ESD-u lags significantly at 24.232. On image quality (FID), SPM achieves the lowest FID (13.566) but requires per-concept fine-tuning of pluggable modules; GIE (15.452) is the best among all plug-and-play methods that do not require fine-tuning. S-CLIP, which fine-tunes the CLIP text encoder, shows moderate NRR but poor handling of implicit unsafe prompts due to its reliance on textual purification. ESD (both u and x variants) achieves the second-highest NRR among fine-tuning methods but often substitutes erased concepts with irrelevant ones (e.g., forests, bedrooms), degrading image coherence. GIE's key advantage is that it requires no fine-tuning at all—only a lightweight MLP adapter trained on ~60 images in ~30 seconds—making it directly deployable across different Stable Diffusion versions (v1.4, v1.5, v2.1, XL) without retraining the base model.

## Relation to Prior Work

This paper departs from the dominant paradigm of concept erasure in diffusion models, which has focused on either retraining on cleansed data, fine-tuning model parameters (ESD, SPM, CA, SDD, Safe-CLIP), or coarse inference-time interventions (SLD, safety checkers). GIE instead operates entirely in the image space by extracting and re-weighting attention map features corresponding to a target concept, then injecting them as 'growth inhibitors' into the original prompt's attention map group at inference time. This repurposes the cross-attention mechanism—previously used as a diagnostic or editing tool (prompt-to-prompt, self-attention guidance)—as a direct suppression instrument, eliminating the need for any parameter updates. The MLP adapter that infers a per-image suppression scale from cross-attention intermediate values is a new lightweight component not present in prior erasure methods.

## Why It Matters / Open Questions

GIE addresses a practically critical gap: implicit unsafe prompts that contain no explicit toxic words yet still generate inappropriate content, a failure mode that text-embedding-based fine-tuning methods (Safe-CLIP, SLD) systematically miss. The plug-and-play, fine-tuning-free design avoids catastrophic forgetting and per-concept retraining, making it deployable across multiple diffusion model versions without re-optimization. However, the method still requires the user to specify the target concept to erase, and the adapter must be retrained per model architecture; generalization to truly novel concept categories (beyond same-type transfer) remains untested. Open questions include robustness to adversarially crafted prompts, scalability to video diffusion, and whether the attention-map injection approach can be extended to more granular attribute-level control.

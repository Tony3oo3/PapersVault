## Problem

Standard continual learning (CL) benchmarks are static and suffer from data contamination with foundation model pre-training corpora, leading to performance saturation that obscures genuine algorithmic progress. There is no framework that dynamically constructs algorithm-dependent task sequences to reliably stress-test CL methods with pre-trained models under realistic, evolving task distributions.
![Teaser figure](../imgs/ICLR20250520/cropped_page3_idx0.webp)

## Input / Output

CLDyB consumes a large labeled image data pool (2.5M images, 2,403 classes across 26 datasets spanning natural, man-made, and AI-generated domains), a set of M pre-trained foundation models (e.g., ViT-Base-Sup21K), and M corresponding CL methods. It outputs an ordered sequence of N tasks (each a 20-category classification problem, N=10 by default) that is algorithm-dependent: jointly evaluated methods share a common challenging sequence, while individually evaluated methods receive their own worst-case sequence. Evaluation metrics include Final Accuracy, Average Retention, Average Learning Accuracy, Robustness (mean Final Acc across multiple CLDyB sequences), and Memory Efficiency in MB.

## Method

CLDyB formulates dynamic benchmarking as an infinite-state MDP where the state is the set of M CL model parameters, the action is task selection from a combinatorially large pool, and the reward is AFM − ALA (encouraging forgetting, inhibiting plasticity). To make the MDP tractable, it first reduces the action space via greedy task sampling that selects K classes maximizing pairwise cosine-similarity potentials in the current model's feature space, followed by functional task clustering (k-means on M-dimensional k-NN negative log-likelihood vectors) with ancestral sampling to ensure diversity across functional skill clusters. It then applies Monte Carlo Tree Search with a truncated one-step lookahead (L=1) to identify the suboptimal task at each time step, approximating the value function without full (N−t)-step rollouts. The framework supports both joint evaluation (generating a common challenging sequence for a group of methods) and individual evaluation (generating method-specific worst-case sequences), and the data pool can be expanded over time with diffusion-generated images to combat saturation.

## Results

CLDyB sequences achieve the highest rank correlation with a held-out evaluation set (SRCC = 0.964, KRCC = 0.905), substantially outperforming static benchmarks CIFAR-100 and ImageNet-R (both SRCC = 0.643, KRCC = 0.429). Compared to random task sequences, CLDyB sequences reduce Final Average Accuracy by 26% and Final Average Retention by 9% across all nine evaluated CL methods. Among the nine methods, HiDe-Prompt achieves the highest Final Acc on CLDyB (62.5%) and held-out (84.9%), while DualPrompt scores the lowest on CLDyB (41.9%).

## Baselines & Comparisons

The paper evaluates nine CL methods (ER, AFEC, CLSER, DualPrompt, LAE, HiDe-Prompt, SLCA, RanPAC, PGP) jointly and separately on CLDyB-generated sequences. HiDe-Prompt leads on CLDyB (62.5% Final Acc) and held-out (84.9%), while DualPrompt and PGP trail at 41.9% and 44.0% respectively. Replay-based methods (CLSER, HiDe-Prompt, SLCA, RanPAC) show greater resistance to forgetting with higher Final Acc, but at the cost of memory efficiency. Parameter-efficient fine-tuning methods (HiDe-Prompt, LAE) exhibit limited Final ALA, revealing weaker forward transfer capabilities often overlooked in prior CL research. Notably, the simple ER method, despite the lowest Final Acc (54.8%), remains competitive in Final ALA, Robustness, and Memory Efficiency, making it an overall top-ranked method on multi-dimensional assessment. The key finding is that CLDyB's task sequences generalize: methods not exposed to CLDyB during sequence generation (ER, DualPrompt, LAE, SLCA) also perform significantly worse on these sequences compared to random sequences, confirming the benchmark's reliability.

## Relation to Prior Work

This paper repurposes Monte Carlo tree search (Coulom, 2006) and greedy combinatorial sampling (Kohli et al., 2013) to formulate CL benchmark construction as an infinite-horizon MDP, a framing absent from prior CL evaluation work. It draws conceptual inspiration from dynamic benchmarking in NLP (Dynabench, DynaBoard) but is the first to apply algorithm-dependent, MDP-driven task sequence generation to continual learning. The evaluated CL methods (ER, DualPrompt, HiDe-Prompt, RanPAC, PGP, etc.) are all existing approaches; the novelty lies entirely in the evaluation protocol rather than in any new CL algorithm.

## Why It Matters / Open Questions

CLDyB addresses a growing and underappreciated problem: as foundation models absorb more of the data used in static CL benchmarks, performance saturation and contamination undermine the ability to distinguish genuinely better CL algorithms. The framework's extensibility via AI-generated data (SDXL) offers a practical path toward self-evolving benchmarks, though the paper acknowledges that quantifying contamination precisely remains open. Key limitations include the coarse MCTS approximation (L=1 lookahead), restriction to class-incremental learning with ViT backbones, and the computational cost of evaluating each candidate task. Future work on learned value estimators, multi-domain extension, and community-driven data pool evolution could significantly broaden its impact.

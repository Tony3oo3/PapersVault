## Problem

Autoregressive LLMs exhibit strong sensitivity to the order of in-context examples, yet existing permutation-invariant ICL variants (Prefix ICL, BoE ICL) sacrifice either information non-leakage or context interdependence, resulting in performance inferior to standard AR ICL. No prior method simultaneously satisfies all three desiderata—permutation invariance, information non-leakage, and context interdependence—leaving a gap between principled invariance and practical ICL accuracy.

## Input / Output

The method consumes n labeled context examples (x_i, y_i) and a test query x_t, but internally duplicates the context sequence to form (x_1,...,x_n, x_1,...,x_n, x_t) so that a single forward pass can perform both the independent BoE encoding and the leave-one-out pre-encoding in parallel. Outputs are predictions for every context example plus the test example, enabling dense training signals; for synthetic tasks these are continuous regression values, and for real-world NLP tasks they are discrete class labels. A symmetric positional encoding resets position indices per example rather than using a single global sequence position.

## Method

InvICL is a two-stage Transformer-based ICL algorithm: first, each context example is independently encoded via a BoE-style attention mask (diagonal mask, no cross-example attention); second, each example is re-encoded using a leave-one-out (LOO) attention mask that attends to all other examples' independent encodings but excludes itself, thereby achieving context interdependence without information leakage. The paper proves that invariance plus non-leakage forces the context attention mask to be diagonal, making the LOO pre-encoding the only way to recover interdependence. A parallel implementation unrolls the input sequence twice and applies a novel LOO-type attention mask so that all n LOO embeddings and the final prediction are obtained in a single forward pass at O(n^2) complexity, matching AR ICL. The approach is further supported by a theoretical result showing that under a specific attention parameterization, InvICL approximately implements standard gradient descent on the in-context regression problem, unlike AR ICL (online GD) or BoE ICL (non-convergent constant gradient).

## Results

On GPT-2 Large (762M) with 8 context examples, InvICL achieves an average accuracy of 42.4% across 7 task settings (all target tasks), outperforming AR ICL (41.9%) and all invariant baselines (Prefix ICL 39.4%, SAICL 41.4%, PCW 38.1%, BatchICL 30.7%). The advantage is most pronounced on out-of-distribution target tasks in unseen domains, where InvICL reaches 48.4% average accuracy versus 43.6% for AR ICL and 42.0% for the best invariant baseline (PCW). In synthetic linear regression experiments, InvICL converges by 50k epochs while AR ICL requires 200k, and InvICL demonstrates superior length extrapolation beyond the training sequence length of 40.

## Baselines & Comparisons

InvICL outperforms AR ICL (the strongest non-invariant baseline) by 0.5 points on average across all target tasks and by 4.8 points on unseen-domain tasks, with the largest gap on HR→LR (44.4 vs. 31.5) and Non-NLI→NLI (81.8 vs. 80.3). Among invariant methods, InvICL beats SAICL (the closest invariant competitor) by 1.0 points on all tasks and 7.6 points on unseen domains, and substantially outperforms Prefix ICL (39.4/40.1) and BatchICL (30.7/29.3). Notably, no existing invariant method surpasses AR ICL on average, whereas InvICL does so in both settings, validating the paper's claim that information non-leakage and context interdependence are essential for competitive invariant ICL. On the synthetic linear regression task, InvICL converges to near-optimal MSE by 50k epochs while AR ICL still lags at that point, and InvICL extrapolates better to test sequence lengths beyond 40. The parallel implementation of InvICL incurs negligible overhead, with inference time of 22.0 ms versus 21.9 ms for AR ICL.

## Relation to Prior Work

This paper extends the line of work on permutation-invariant ICL (Prefix ICL, PCW, SAICL, BatchICL) by identifying two additional desiderata—information non-leakage and context interdependence—that no existing invariant method satisfies simultaneously. It builds on the BoE ICL concept from PCW (Ratner et al., 2022) as the necessary mask structure (proven via Proposition 3.6) and augments it with a leave-one-out pre-encoding stage to recover interdependence. The parallel implementation borrows the unrolling idea from chain-of-thought prompting (Wei et al., 2022), and the theoretical analysis connects to the ICL-as-gradient-descent literature (Von Oswald et al., 2023; Ding et al., 2023).

## Why It Matters / Open Questions

The clean theoretical characterization (the mask must be diagonal for invariance + non-leakage, and LOO pre-encoding is needed for interdependence) provides a principled design template for future invariant ICL architectures. The OOD generalization gains (e.g., 48.4 vs. 43.6 average on unseen-domain tasks) and length extrapolation advantage suggest invariance is not merely a symmetry nicety but a practical inductive bias. Limitations include evaluation on models up to ~2.8B parameters, a 14% memory overhead from input duplication, and the fact that the gradient-descent equivalence is an existence proof under specific parameterizations rather than a characterization of what pretrained LLMs actually compute.

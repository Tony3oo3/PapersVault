## Problem

Prior theoretical results on the expressive power of geometric GNNs assumed fully connected graphs, where every node knows all other nodes. In practice, geometric GNNs operate on sparse nearest-neighbor graphs for computational efficiency, and it was unclear for which sparse graphs message-passing networks can generically separate non-isomorphic geometric graphs. Additionally, while the concept of a maximally expressive equivariant GNN was defined, no simple architecture was known to achieve this property.

## Input / Output

The method consumes a sparse geometric graph specified by an adjacency matrix A ∈ {0,1}^{n×n} and node position matrix X ∈ R^{n×d} (typically d=3), with optional node and edge feature tensors. It produces a global rotation/translation/permutation-invariant feature vector s^global ∈ R^C, which serves either as a graph fingerprint for isomorphism testing or as a regression target for chemical properties (e.g., ionization potential, bond dissociation energy). The key constraint is that the underlying graph need only be connected (for E-GGNN) or generically globally rigid (for I-GGNN), not fully connected.

## Method

EGENNET is a message-passing E-GGNN that maintains C equivariant channels per node, each a d-dimensional vector, updated via a rotation-equivariant aggregation that combines distance-weighted relative positions with linear combinations of neighbor channel features. After T = d+1 iterations, a rotation-invariant node feature is extracted as the squared norm of a learned linear combination of channels, and a global feature is obtained by summing a learned function over all node features. The key theoretical result (Theorem 5.1) proves that with C = 2Nd+1 channels, EGENNET is generically maximally expressive on connected graphs, using the finite witness theorem to show that random parameter choices yield injective aggregation and readout functions with probability one. This establishes that EGENNET generically separates all pairs of non-isomorphic connected geometric graphs, matching the theoretical upper bound for E-GGNNs (Theorem 4.1) while remaining linear in the number of edges per iteration.

## Results

On chemical property prediction (MAE, lower is better), EGENNET achieves the best result on 7 out of 8 properties across the Drugs, Kraken, and BDE datasets. Headline improvements include 78% lower MAE on BDE (0.317 vs 1.474 for Marcel), 48% on Kraken L (0.174 vs 0.339), and 33% on Kraken BurL (0.063 vs 0.095). On the separation experiments (Table 1), EGENNET achieves 100% accuracy on both Pair a and Pair b with just 1 GNN layer, while I-GGNN baselines like SchNet require the 3rd power graph to reach 100%. The only property where EGENNET is not best is Drugs χ (0.207 vs GemNet's 0.197).

## Baselines & Comparisons

EGENNET outperforms all 16 baselines on 7 of 8 chemical property targets, with the largest margins on BDE (0.317 MAE vs 1.474 for Marcel, a 78% improvement) and Kraken BurL (0.063 vs 0.095 for Marcel, 33% improvement). Among 3D equivariant baselines, EGENNET beats GemNet (which uses high-order irreducible representations) on 7/8 properties, and outperforms LEFTNet and PaiNN across the board. The only loss is on Drugs χ, where GemNet achieves 0.197 vs EGENNET's 0.207. In the separation experiments (Table 1), EGENNET achieves 100% accuracy on both test pairs with a single GNN layer, while SchNet (I-GGNN) fails entirely without power graphs and DimeNet/SphereNet only succeed on Pair a due to their implicit 2-hop angle computation. The paper attributes EGENNET's strong performance to its generic completeness guarantee combined with the observation that the benchmark datasets have few norm-repetitions, making them 'close to generic.' 1D baselines (Random Forest, LSTM, Transformer) and 2D baselines (GIN, GraphGPS) are consistently outperformed by all 3D models, with GraphGPS being the strongest 2D method but still trailing EGENNET by 8–10% on most properties.

## Relation to Prior Work

This paper extends the geometric GNN expressive power analysis of Joshi et al. (2023) from the full-graph setting to sparse graphs, where each node connects only to a few nearest neighbors. Theoretically, it builds on rigidity theory (Gortler et al., 2010; Jordan & Tanigawa, 2022) to characterize exactly when E-GGNNs (connectivity) and I-GGNNs (generic global rigidity) achieve generic separation. Architecturally, EGENNET combines the message-passing structure of EGNN (Satorras et al., 2021) with multi-channel equivariant features (Levy et al., 2023), and its proof of generic maximal expressivity leverages the finite witness theorem from Amir et al. (2023) and Dym & Gortler (2024).

## Why It Matters / Open Questions

The paper provides a complete, clean characterization of when sparse geometric MPNNs can separate non-isomorphic graphs, resolving a gap left by prior work that assumed full connectivity. The practical implication is that simple architectures like EGENNET (linear in node count under the manifold assumption) can replace computationally expensive 2-WL-based methods for most real-world molecular and point-cloud tasks. A key limitation is that the guarantees hold only for generic inputs, so molecules with non-trivial symmetry groups may still require more complex models. Open questions include whether non-MPNN approaches (e.g., geometric 2-WL on sparse graphs) can handle the non-generic cases efficiently.

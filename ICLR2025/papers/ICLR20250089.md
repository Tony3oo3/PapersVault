## Problem

Incorporating multiple retrieved contexts into SSM-based LLMs at inference time requires either processing all context tokens sequentially (incurring linear-to-quadratic latency) or finding a way to compose multiple independent SSM states into one. No existing method provides an efficient, order-invariant composition of pre-computed states that approximates the effect of token concatenation, leaving a gap between the speed advantage of SSMs and the practical need to condition on multiple retrieved passages.

## Input / Output

The method takes a query token sequence and a set of pre-computed context state vectors (each comprising the SSM state x(u_i) and accumulated decay matrix A(u_i) for context i), retrieved from a 'database of states' via sentence-embedding similarity. The output is a single composed state vector computed purely through arithmetic operations (element-wise products and sums for diagonal A matrices), requiring zero model forward passes, which then initializes the SSM to generate continuations. For Mamba-style models, the last m_conv=4 input tokens per layer are also stored and averaged across contexts to ensure state sufficiency.

## Method

PICASO derives a closed-form composition rule (CASO) from SSM dynamics: the state of concatenated sequences equals the last context's state plus decay-weighted contributions from earlier contexts, requiring only element-wise arithmetic for diagonal A matrices. To handle the absence of a natural context ordering, PICASO averages CASO states over all permutations (PICASO-S) or cyclic rotations (PICASO-R), yielding a linear combination of individual context states with weights expressible via elementary symmetric polynomials. PICASO-S is computed in O(n³) time via dynamic programming over these polynomials, while PICASO-R achieves O(n) time using cumulative products and sums over a doubled sequence of decay matrices. A fine-tuning objective (BPTC/BP2C) further trains the model to leverage composed states by backpropagating through (or stopping gradients at) the composition step, closing the remaining performance gap with concatenation while preserving the 5.4× speedup.

## Results

On WikiText-V2 (zero-shot), PICASO-R achieves a 10.1% average improvement over the no-context baseline across 1–10 retrieved segments, compared to 11.1% for concatenation, while delivering a 5.4× speedup in composition time. On MSMARCO (zero-shot), PICASO-R reduces perplexity from 2.42 (naive) to 1.52, approaching concatenation's 1.42. After fine-tuning with BPTC on MSMARCO, PICASO-R matches concatenation exactly at 0.65 perplexity while retaining the 5.4× speed advantage. On OpenbookQA, PICASO-R achieves 39.9% accuracy vs. 40.0% for concatenation with an 8× speedup in composition time.

## Baselines & Comparisons

Against concatenation (Ram et al., 2023), PICASO-R slightly lags in the zero-shot setting (1.52 vs. 1.42 perplexity on MSMARCO; 10.1% vs. 11.1% improvement on WikiText) but matches it exactly after BPTC fine-tuning on the same domain (0.65 vs. 0.65 on MSMARCO) while being 5.4× faster in composition time. Against Soup / State Soup (Pióro et al., 2024), PICASO-R substantially outperforms the simple state-averaging baseline across all settings: 1.52 vs. 2.04 perplexity zero-shot on MSMARCO, and 10.1% vs. 8.5% improvement on WikiText, confirming that the CASO-based composition with permutation invariance captures inter-context interactions that naive averaging misses. PICASO-S and PICASO-R perform nearly identically in all experiments, validating that the linear-time cyclic-permutation approximation is sufficient in practice.

## Relation to Prior Work

This paper extends the state composition line initiated by State Soup (Pióro et al., 2024), which introduced decay-weighted mixing of SSM states but was limited to two equal-length contexts and lacked permutation invariance. PICASO derives a mathematically grounded composition formula (CASO) directly from single-layer SSM dynamics, then enforces permutation invariance by averaging over context orderings, with efficient computation via dynamic programming (O(n³) for full symmetry) or cumulative products (O(n) for cyclic permutations). The BPTC/BP2C fine-tuning objectives are novel, enabling the model to learn to leverage composed states that are out-of-distribution relative to any single input sequence. The work also connects to the broader model-composition literature (Model Soup, tangent model composition) through its use of linear combinations of states.

## Why It Matters / Open Questions

The 5.4× speedup with near-parity performance (after fine-tuning) makes SSM-based RAG practically viable for latency-sensitive deployments, since composition requires zero model forward passes—only element-wise arithmetic on pre-computed states. However, the method is currently restricted to pure SSM architectures; extending it to attention-based hybrid models (Jamba, Samba, B'mojo) would require more sophisticated key-value cache composition, which the authors identify as key future work. The near-equivalence of PICASO-R (cyclic invariance) and PICASO-S (full permutation invariance) suggests that the practical benefit of full permutation invariance may be limited, opening questions about whether simpler composition rules suffice. Zero-shot performance still lags concatenation slightly, and the method's dependence on diagonal A matrices (a Mamba-specific property) limits generality.

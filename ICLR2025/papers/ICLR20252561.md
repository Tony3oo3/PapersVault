## Problem

It was unknown whether neural networks trained with gradient-based methods could achieve the optimal computational-statistical tradeoff for Gaussian single-index models with generative exponent s* ≥ 3, where the SQ lower bound requires Ω(d^{s*/2}) samples but no prior gradient-based algorithm matched it. Additionally, the optimal sample complexity for sparse single-index models with general s* ≥ 1 remained open, with existing methods either failing in non-sparse settings or only handling specific exponents.

## Input / Output

The method consumes n i.i.d. samples (z_i, y_i) where z_i ~ N(0, I_d) and y_i is generated through an unknown link distribution p conditioned on ⟨θ*, z_i⟩, requiring only knowledge of the generative exponent s* (not the full link distribution) to construct the activation and gradient oracle. The output is a two-layer network whose hidden-layer weight vectors achieve strong alignment |⟨θ_m, θ*⟩| ≥ 1 − O(Δ) with the unknown signal, with Δ shrinking as a function of d or k. In the sparse extension, the algorithm additionally requires the sparsity level k and produces weights aligned with the k-sparse θ*.

## Method

The core contribution is a unified gradient-based meta-algorithm (Algorithm 1) that trains a two-layer network by combining a general gradient oracle ψ(y, ⟨θ,z⟩) with random weight perturbation using a high-pass activation. The gradient oracle (instantiated via label transformation or modified loss) resolves the zero-correlation issue where E[y·ζ_{s*}(y)]=0, while the weight perturbation—injecting L uniform sphere-noise replicas per neuron—reduces the second moment of the aggregated gradient from O(d) to O(d^{-(s*-3)/2}), boosting the SNR to match the SQ lower bound. The polarization level γ = Õ(d^{-1/4}) balances exploitation of the learned direction against exploration noise. For the sparse setting (k = o(√d)), a novel perturbation strategy divides the support-set space into d groups S_{k,j} = {φ : j ∈ φ}, ensuring each perturbed weight's support overlaps with φ* almost surely, eliminating the d/k² suboptimality factor and achieving Õ(k^{s*}) samples.

## Results

The main theoretical result (Theorem 4.2) establishes that Algorithm 1 achieves sample complexity $\widetilde{O}(d^{s^*/2} \vee d)$ for the uniform prior, matching the SQ lower bound $\Omega(d^{s^*/2})$ from Damian et al. (2024) up to polylogarithmic factors for all generative exponents $s^* \geq 1$. For the sparse prior with $k = o(\sqrt{d})$, Algorithm 2 achieves $\widetilde{O}(k^{s^*})$ samples (Theorem 5.1), matching the newly established SQ lower bound $\widetilde{\Omega}(k^{s^*})$ (Theorem 5.4). Numerical experiments with $s^* = 4$ (link function $y = x^2\exp(-x^2) + \epsilon$) confirm the predicted $n \propto d^2$ scaling: fitted slopes in log-log plots range from 1.82 to 1.97 across accuracy levels 0.6–0.8, closely matching the theoretical value $s^*/2 = 2$.

## Baselines & Comparisons

This is primarily a theoretical paper, so comparisons are against information-theoretic and SQ lower bounds rather than competing algorithms in a head-to-head experimental setting. Algorithm 1 matches the SQ lower bound $\Omega(d^{s^*/2})$ for all $s^* \geq 1$, closing a gap that was open for $s^* \geq 3$ (where only the non-gradient partial trace estimator of Damian et al., 2024 previously matched the bound). The method subsumes several prior gradient-based approaches as special cases: batch-reusing (Lee et al., 2024; Dandi et al., 2024) recovers the $\widetilde{O}(d)$ result for polynomial links with $s^* \leq 2$ (Corollary 4.5), label transformation (Chen & Meka, 2020) and landscape smoothing (Damian et al., 2023) are unified under the general gradient oracle $\psi$. For the sparse setting, the $\widetilde{O}(k^{s^*})$ sample complexity improves upon the $\widetilde{O}(k^{s^*} \cdot d/k^2)$ that would result from naively applying the uniform-prior algorithm, and matches the SQ lower bound for all $s^* \geq 1$ and $k = o(\sqrt{d})$.

## Relation to Prior Work

This paper unifies several previously separate techniques—batch-reusing (Dandi et al., 2024; Lee et al., 2024), label transformation (Chen & Meka, 2020), and landscape smoothing (Damian et al., 2023)—into a single gradient-based meta-algorithm (Algorithm 1) for training two-layer networks on Gaussian single-index models. The key departure from prior work is that while batch-reusing handles only polynomial links (s* ≤ 2) and the partial trace estimator of Damian et al. (2024) handles s* ≥ 3 but is not gradient-based, this paper shows that a gradient-based method with weight perturbation and a general gradient oracle ψ matches the SQ lower bound Ω(d^{s*/2}) for all s* ≥ 1. The sparse extension introduces a novel group-based perturbation that partitions the support set space into d overlapping groups, a technique not present in prior sparse feature-learning work (Vural & Erdogdu, 2024; Fan et al., 2023).

## Why It Matters / Open Questions

This is the first gradient-based algorithm to achieve the nearly optimal computational-statistical tradeoff for Gaussian single-index models across all generative exponents s* ≥ 1, closing a gap that had only been addressed by non-gradient estimators for s* ≥ 3. The weight perturbation technique is of independent interest and suggests a pathway to solving sparse tensor PCA via gradient methods. Open questions remain for the regime k = Ω(√d) with s* = 1 (conjectured to need only Õ(k) samples) and for whether the SQ lower bound can be further broken by exploiting additional data structures (e.g., spiked covariance). The framework's generality—encompassing batch-reusing, label transformation, and landscape smoothing as special cases—provides a useful template for future gradient-based feature learning analyses.

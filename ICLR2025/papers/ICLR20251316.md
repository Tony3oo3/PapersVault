## Problem

Existing ranking feature attribution methods (EXS, RankLIME, RankingSHAP) produce attributions that contradict each other and fail to satisfy fundamental axiomatic properties like efficiency and monotonicity. Unlike classification and regression, where the Shapley value provides a unique axiomatic reference standard, no such principled framework existed for learning-to-rank, leaving practitioners without a consistent, theoretically grounded way to explain ranking model decisions.

## Input / Output

The method takes a query, a set of documents, and a black-box ranking model accessible only via API, with features represented as stemmed tokens from the query-document vocabulary (binary presence/absence). It produces an m-dimensional attribution vector where each element quantifies a token's contribution to the ranking decision. Relevance scores for the value function are inferred from the ranking model's own similarity scores or from heuristic proxies like BM25 when ground-truth labels are unavailable.

## Method

RankSHAP extends the Shapley value to ranking by defining four axioms (Rank-Efficiency, Rank-Missingness, Rank-Symmetry, Rank-Monotonicity) and a Generalized Ranking Effectiveness Metric (GREM) characterized by Relevance Sensitivity and Position Sensitivity. The key theoretical result (Theorem 3.2) proves that the Shapley value computed with respect to any GREM-compliant value function (e.g., NDCG, DCG, CG, MAP) is the unique attribution method satisfying all four ranking axioms. The critical insight is that NDCG's additive decomposition into per-document gain × discount terms ensures the value function is decomposable, which is what makes the Shapley axioms hold—unlike the non-additive ApproxNDCG or Kendall's tau used by competing methods. For practical computation, RankSHAP uses a KernelSHAP-style linear approximation with an NDCG-based squared loss, weighting coalitions by the standard Shapley kernel π_x(z) = (m-1)/(C(m,|z|)·|z|·(m-|z|)).

## Results

RankSHAP achieves the highest Fidelity and weighted Fidelity (wFidelity) across all rankers (BM25, BERT, T5, LLAMA2), datasets (MS MARCO, Robust04), and document settings (Top-10, Top-20, Top-100). Averaged across all configurations, RankSHAP surpasses the best baseline (RankingSHAP) by 25.78% on Fidelity and 19.68% on wFidelity. In the user study, RankSHAP achieves a Kendall's Tau of 0.56 on the passage reordering task and a GPT-4 semantic similarity of 0.69 on the query estimation task, outperforming the strongest baseline (RankingSHAP: 0.52 and 0.58) by 19.1% and 19.0% respectively.

## Baselines & Comparisons

RankSHAP consistently outperforms all three baselines—EXS, RankLIME, and RankingSHAP—across every ranker, dataset, and document-count setting. The closest competitor is RankingSHAP (Heuss et al., 2024), which uses Kendall's tau as its value function; RankSHAP beats it by an average of 25.78% on Fidelity and 19.68% on wFidelity, with the gap widening in the Top-100 setting (e.g., 0.47 vs. 0.31 Fidelity on MM/BM25). RankLIME (Chowdhury et al., 2023), which uses ApproxNDCG as a differentiable loss, is outperformed by RankSHAP by roughly 15–25% on Fidelity depending on the ranker and setting. EXS (Singh & Anand, 2019), the weakest non-random baseline, lags RankSHAP by 20–30+ points on Fidelity and degrades most sharply in the Top-100 setting (e.g., 0.24 vs. 0.47 on MM/BM25). The axiomatic analysis (Table 1) further confirms that only RankSHAP satisfies all four Shapley axioms (Rank-Efficiency, Rank-Missingness, Rank-Symmetry, Rank-Monotonicity), while all three baselines violate all four.

## Relation to Prior Work

This paper extends the Shapley value framework (Shapley, 1953; Young, 1985) from scalar-output models to ranking models, where the output is an ordering rather than a single score. It builds directly on KernelSHAP (Lundberg & Lee, 2017) for practical approximation, but introduces a key theoretical constraint: the ranking value function must belong to the GREM family (additive gain × discount, e.g., NDCG) for the Shapley axioms to be satisfiable. This departs from prior ranking attribution methods—EXS, RankLIME, and RankingSHAP—which either extend LIME with non-additive ranking losses or use Kendall's tau as a marginal contribution measure, and which the paper shows violate all four Shapley axioms.

## Why It Matters / Open Questions

The paper provides the first axiomatic characterization of what a valid ranking feature attribution method must satisfy, and demonstrates that all existing methods fail these criteria, giving practitioners a principled alternative. The practical impact is significant for IR and recommendation systems where explainability is needed for high-stakes decisions. Key limitations include the feature independence assumption inherent to Shapley values, the dependence on relevance scores (which may introduce bias when inferred implicitly), and the NP-hardness of exact computation. Open questions include whether the framework extends to competitive ranking settings and how it behaves with very high-dimensional or continuous feature spaces.

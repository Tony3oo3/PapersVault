## Problem

Existing LVLM benchmarks (VQA, captioning, OCR) suffer from inadequate assessment of fine-grained visual perception, data contamination risk, metrics designed only for short outputs, inconsistent prompting, and a neglect of multi-turn reasoning. The paper asks whether LVLMs can generalize their reasoning and perception to structured, rule-based game environments that simultaneously demand visual detail, strategic planning, and adversarial adaptation.
![Teaser figure](../imgs/ICLR20250549/cropped_page3_idx0.webp)

## Input / Output

Each task receives a single RGB screenshot of a randomly generated game board state (ranging from 3×3 Tic-Tac-Toe to 15×15 Gomoku) paired with a fixed task prompt encoding the game rules and required output format. Outputs are strictly format-constrained: the Perceiving task requires a full board matrix (e.g., 8×8 for Chess with piece-specific integers, 15×15 for Gomoku with 0/1/2), parsed by regex so any structural deviation yields a zero score; Q&A requires a single letter (A–D); Rule Following and E2E require a move in alphanumeric notation (e.g., 'Nf3', 'H8'). For E2E Playing, the model interacts online over up to 100 full games against a Minimax or Alpha-Beta pruning opponent, with three consecutive invalid moves triggering an automatic loss.

## Method

LVLM-Playground is a game-based evaluation framework comprising six turn-based board games (Tic-Tac-Toe, Reversi, Minesweeper, Gomoku, Sudoku, Chess) and four decomposed tasks (Perceiving, Q&A, Rule Following, E2E Playing) that isolate and jointly test four cognitive abilities: Perception, Reasoning, Decision, and Adversary. The authors derive closed-form complexity formulas for each ability dimension using game-specific parameters (state space size S, piece types P, board size N, branching factor B, game length L, uncertainty U, resource complexity C), then normalize scores to a 0.5–5 star scale validated by a 10-participant human study. Performance is aggregated via a game-weighted formula that multiplies each model's task score by the game's star rating for the relevant ability, ensuring harder games contribute more to the overall metric. The framework supports both commercial APIs (GPT-4o, Gemini-1.5-Pro, Claude-3.5-Sonnet) and open-source models (Qwen2-VL, DeepSeek-VL, Phi-3-VL, LLaVA-1.6, InternVL2) under identical prompts and token budgets, with 2,000 offline samples per task and 100 online E2E games per model.

## Results

On the LVLM-Playground Perceiving task, Claude-3.5-Sonnet achieves the highest accuracy across most games (0.985 on Tic-Tac-Toe, 0.992 on Reversi, 0.912 on Sudoku, 0.741 on Minesweeper, 0.742 on Gomoku, 0.554 on Chess), while GPT-4o surprisingly underperforms with 0.013 on Gomoku and 0.195 on Reversi. Among open-source models, Qwen2-vl-7b and Phi-3-VL lead (e.g., 0.589/0.593 on Gomoku), while LLaVA-1.6-7b scores 0.0 on both Sudoku and Gomoku perception, falling below the random baseline (0.103/0.332). In E2E gameplay, no model completes full games reliably; commercial models score higher (e.g., Gemini: 30.1 on Tic-Tac-Toe, 100.7 on Reversi) while open-source models stagnate (e.g., all open-source models score exactly 40.0 on Reversi).

## Baselines & Comparisons

Claude-3.5-Sonnet dominates across all four tasks and six games, achieving the best or near-best scores in Perceiving (0.992 Reversi, 0.742 Gomoku), Q&A (0.778 Minesweeper, 0.694 Sudoku), and Rule Following (0.721 Sudoku). Gemini-1.5-Pro is the strongest in simple-board perception (0.994 Tic-Tac-Toe, 0.882 Reversi) and E2E gameplay (30.1 Tic-Tac-Toe, 100.7 Reversi), but trails Claude on complex boards. GPT-4o, despite being a top commercial model, shows a striking vision-language misalignment: it scores only 0.013 on Gomoku perception and 0.070 on Reversi rule-following, far below Gemini and Claude. Among open-source models, Qwen2-vl-7b and Phi-3-VL are the strongest (e.g., 0.589/0.593 on Gomoku perception, 0.570/0.567 on Minesweeper rule-following), while LLaVA-1.6-7b consistently underperforms, scoring 0.0 on Sudoku and Gomoku perception and falling below the random baseline on Q&A (0.269 vs. 0.256 on Tic-Tac-Toe, 0.244 vs. 0.267 on Reversi). DeepSeek-VL-7b shows particular weakness on large boards (0.010 Gomoku perception) and complex rules (0.091 Reversi rule-following, below the 0.127 random baseline).

## Relation to Prior Work

This paper carves new ground at the intersection of two existing research threads: (1) game-based evaluation of LLMs (SmartPlay, GAMA-Bench, GTBench, GameBench), which previously operated in text-only environments by converting game states to textual descriptions, and (2) LVLM evaluation via VQA/captioning/OCR benchmarks, which the authors argue are limited by data contamination, inadequate fine-grained perception testing, and single-turn focus. LVLM-Playground is the first systematic game-based benchmark that requires LVLMs to process actual visual game screenshots rather than text, thereby testing multimodal perception alongside reasoning and decision-making. It also departs from LVLM-as-agent frameworks (CRADLE, VARP) that use games as a testbed for agent design rather than as a controlled evaluation instrument with quantified ability dimensions.

## Why It Matters / Open Questions

LVLM-Playground provides a contamination-resistant, rule-based evaluation framework that exposes specific failure modes of current LVLMs—particularly poor dense visual perception on larger boards (Gomoku 15×15, Chess 8×8), looping in long structured outputs, and 'stochastic parrot' behavior where models generate plausible-sounding descriptions without producing valid moves. The finding that even top commercial models (GPT-4o, Claude-3.5-Sonnet) achieve only moderate scores on complex boards suggests a fundamental gap in vision-language alignment for fine-grained spatial reasoning. Open questions include whether these limitations can be addressed through better visual encoders or longer context windows, and whether the framework generalizes to more complex, real-time, or 3D game environments beyond turn-based board games.

## Problem

Existing LM safety evaluations treat models as single black boxes, but autonomous agents are compound systems with multiple components (policy models, evaluators, value functions, captioners) that process multimodal inputs and take sequential actions. This paper asks how robust these compound agent systems are to targeted adversarial attacks in realistic web environments, and how robustness changes as new inference-time components are added to improve benign performance.
![Teaser figure](../imgs/ICLR20251017/cropped_page1_idx0.webp)

## Input / Output

The attacker has limited access to a single trigger image (L∞ perturbation bounded at 16/256, occupying <5% of the web page screenshot pixels) or a single piece of trigger text in their own listing. The agent receives the full web page screenshot, text observations, and a user goal instruction; the evaluation produces an attack success rate (ASR) measuring whether the agent achieves the adversarial goal, plus per-edge adversarial influence weights λ(e) that decompose how the attack propagates through each component in the agent graph.

## Method

The core contribution is the Agent Robustness Evaluation (ARE) framework, which models each agent as a directed graph where nodes are components (policy model, evaluator, value function, captioner) and edges carry intermediate outputs. For each edge, the adversarial influence AdvIn(c) is defined as the tightest upper bound on downstream ASR given that edge value c, and the edge weight λ(e) is the expectation of AdvIn over the edge's value distribution—enabling reuse of computations across different downstream configurations. Three attack methods are implemented: (1) black-box prompt injection for text access, (2) white-box PGD optimization on a captioner to inject adversarial text into image captions, and (3) a black-box CLIP ensemble attack (optimizing perturbations at 180px resolution against four CLIP ViT models with positive/negative text pairs) that transfers to black-box LMs. The framework reveals that adding inference-time components like evaluators or value functions can reduce ASR when uncompromised (e.g., 31%→25% for reflexion) but increase it when jointly attacked (31%→36%), exposing a robustness-utility tradeoff in agent design.

## Results

Under a realistic threat model (attacker modifies only their own product image/text on a web page), the paper achieves attack success rates (ASR) up to 67% on GPT-4V-based agents via prompt injection (text access) and 31% via white-box captioner attack (image access, ε=16/256). Adding inference-time compute components (reflexion evaluator, tree search value function) reduces ASR by ~5–6% when uncompromised (31%→25% for reflexion, 31%→26% for tree search), but increases ASR by 5–7% when those components are jointly attacked (31%→36% for reflexion, 31%→38% for tree search). The CLIP-based black-box image attack achieves 19% ASR on self-captioning agents and 10% on base agents, with perturbations affecting less than 5% of total page pixels.

## Baselines & Comparisons

The paper evaluates three agent architectures from the VWA literature: the base policy-model agent (Koh et al., 2024a), the reflexion agent with an evaluator (Pan et al., 2024), and the tree search agent with a value function (Koh et al., 2024b). Under the standard captioner attack, the base agent achieves 31% ASR. The reflexion agent with an uncompromised evaluator reduces ASR to 25% (a 23% relative reduction), confirming that the evaluator blocks adversarial actions. However, when the evaluator is jointly attacked, ASR rises to 36%, making the reflexion agent 16% relatively *less* robust than the base agent. Similarly, the tree search agent with a clean value function reduces ASR to 26%, but with an attacked value function, ASR increases to 38%—a 23% relative degradation over the base agent. The key finding is that inference-time compute components provide a false sense of security: they improve robustness in the best case but create new attack surfaces that worsen robustness in the worst case.

## Relation to Prior Work

This paper extends the adversarial robustness literature from single models to compound agent systems, building directly on VisualWebArena (Koh et al., 2024a) as the evaluation environment and adapting CLIP-based transferable attacks (Dong et al., 2023) to a targeted, multi-component agent setting. It departs from prior prompt injection work (Greshake et al., 2023; Debenedetti et al., 2024) by emphasizing the multimodal image attack surface and, crucially, by introducing the ARE framework that models agents as directed graphs and decomposes robustness into edge-level adversarial influence propagation. The analytical lens connects to the broader adversarial ML tradition (PGD, surrogate-model ensembles) but applies it to a fundamentally different object: a pipeline of LMs, captioners, evaluators, and value functions rather than a single classifier.

## Why It Matters / Open Questions

The paper provides the first systematic evidence that state-of-the-art multimodal agents (GPT-4o, reflexion, tree search) are highly vulnerable to targeted attacks requiring imperceptible perturbations to less than 5% of a web page's pixels, with ASR up to 67%. The counterintuitive finding that inference-time compute (reflexion, tree search) can *decrease* worst-case robustness by introducing new attackable components (evaluators, value functions) challenges the prevailing assumption that more reasoning equals more safety, and has direct implications for how agent architectures should be designed. Limitations include a fixed web environment, attacks that serve as lower bounds on true risk, and evaluation on only three agent architectures; open questions include whether the ARE framework generalizes to more complex multi-agent systems, how defenses scale as new components are added, and whether the findings transfer to non-web environments like operating systems or robotics.

## Problem

Lifelong learning and machine unlearning pursue contradicting objectives: the former must retain all previously acquired knowledge, while the latter must guarantee complete removal of specific data for privacy compliance. No existing method simultaneously prevents catastrophic forgetting, enables forward knowledge transfer, provides exact (not approximate) task unlearning without access to prior data, and operates within a fixed model memory budget.
![Teaser figure](../imgs/ICLR20252785/cropped_page4_idx0.webp)

## Input / Output

The system receives a sequence of interleaved learning and unlearning requests over RGB images (32×32 for CIFAR-10/100, 64×64 for TinyImageNet), where each learning request provides a task ID and its training set, and each unlearning request specifies a previously learned task ID to be erased. At inference, the task ID selects the corresponding sparse subnetwork mask, and the model outputs a probability distribution over that task's label space. The model maintains a single fixed-capacity architecture (ResNet-18/34 or ViT-T/8) whose total parameter count does not grow with the number of tasks.

## Method

PALL jointly optimizes task-specific sparse subnetworks and their parameters within a single fixed-capacity network using a straight-through estimator on learnable importance scores, with a per-layer connectivity rate α controlling sparsity. A cumulative binary mask freezes all previously learned parameters during new task training, eliminating catastrophic forgetting while allowing new subnetworks to selectively reuse (share) frozen weights from prior tasks for knowledge transfer. Exact unlearning is achieved by resetting all parameters that were trained on the target task's data back to the initialization distribution, followed by a short DER++-style rehearsal (N_f iterations) on episodic memory buffers of affected downstream tasks to recover any performance degradation from shared-parameter reinitialization. After each learning step, all unused parameters outside the active subnetworks are reinitialized to prevent information leakage, ensuring that future unlearning guarantees remain valid.

## Results

On S-CIFAR10 (T=5), PALL (α=0.1) achieves 94.50% average accuracy on learned tasks (A_l) with zero catastrophic forgetting (F_l=0) and only 0.24% average degradation from unlearning (F_u), while guaranteeing exact unlearning. On S-CIFAR100 (T=10), PALL reaches 72.35% A_l with F_l=0 and F_u=0.40, and on S-TinyImageNet (T=20) it achieves 61.36% A_l with F_u=0.72. Notably, PALL matches or exceeds the Independent-models baseline (which also provides exact unlearning) on S-TinyImageNet (62.14 vs. 61.69 at α=0.05) while using ~12× less model memory (34.41 MB vs. 412.6 MB).

## Baselines & Comparisons

PALL is the only method that simultaneously achieves exact unlearning, zero catastrophic forgetting (F_l=0), and competitive task-learning accuracy. Against the Independent-models baseline (equivalent to CLPU), PALL matches or exceeds A_l on S-TinyImageNet (62.14 vs. 61.69 at α=0.05) while using ~12× less inference memory (34.41 MB vs. 412.6 MB). Compared to WSN, PALL trades a small A_l gap on S-CIFAR100 (72.35 vs. 73.64) for the critical ability to perform exact unlearning, whereas WSN's unlearning is inexact since trained parameters remain in the model. Against rehearsal-based methods (DER++, ER, GEM), PALL dominates on all four metrics: higher A_l, zero F_l (vs. 1.62–4.52 for DER++), and exact rather than inexact unlearning. Against regularization-based methods (EWC, LwF), PALL is substantially superior on both forgetting and unlearning, as these methods are entirely indifferent to unlearning requests (F_u=0, A_u≈A_l). Against PackNet, PALL achieves comparable A_l on S-CIFAR10 (94.50 vs. 94.77) and S-TinyImageNet (61.36 vs. 60.50) while providing exact unlearning guarantees that PackNet cannot offer.

## Relation to Prior Work

PALL builds directly on the architecture-based lifelong learning line of work, particularly Winning Subnetworks (WSN, Kang et al., 2022) for learnable sparse subnetwork optimization with selective weight sharing, and extends it with a DER++-style episodic memory rehearsal mechanism for post-unlearning recovery. It departs from the CLPU framework (Liu et al., 2022), which achieves exact unlearning by training and deleting independent per-task models, by instead partitioning all tasks within a single fixed-capacity network. The paper also contrasts with inexact unlearning approaches in continual learning (LSF, Chatterjee et al.) that manipulate model outputs without guaranteeing that unlearned data is truly absent from the parameters.

## Why It Matters / Open Questions

PALL is the first method to simultaneously satisfy all four desiderata—no catastrophic forgetting, forward knowledge transfer, exact unlearning guarantees, and bounded model memory—making it directly relevant to GDPR right-to-be-forgotten compliance in deployed continual learning systems. Key limitations include restriction to task-incremental settings (task ID must be known), complete task-level (rather than sample-level) unlearning, and vision-only evaluation. Open questions the authors identify include extension to class- and domain-incremental learning via gating, integration with differentially private optimization for per-sample deletion guarantees, and application to language processing tasks.

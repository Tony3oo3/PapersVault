## Problem

Sparse Autoencoders (SAEs) extract interpretable monosemantic features from individual layers of language models, but aligning these features across layers to track their evolution has remained an open problem. Features from different layers may be semantically similar yet permuted differently, and differences in hidden state norms across depth introduce scale mismatches that degrade naive weight-based matching.
![Teaser figure](../imgs/ICLR20253031/cropped_page3_idx3.webp)

## Input / Output

The method consumes only pre-trained SAE parameters from two layers — encoder weights, decoder weights, JumpReLU thresholds, and biases — requiring no input data at all (data-free). It outputs a permutation matrix of size F×F (where F is the SAE feature dimension, e.g., 16k) that maps feature indices from one layer to the other, and can additionally produce approximated hidden states at the target layer via an encode-permute-decode pipeline. The SAEs must use JumpReLU activation with learnable per-feature thresholds for the folding step to apply.

## Method

SAE Match first applies parameter folding: the JumpReLU thresholds θ are absorbed into the SAE weights (W_enc' = W_enc·diag(1/θ), W_dec' = W_dec·diag(θ)), which normalizes decoder columns to the actual scale of hidden state norms at each layer, since θ empirically tracks the growth of those norms. The alignment is then solved as a Linear Assignment Problem that maximizes the Frobenius inner product between folded decoder (and optionally encoder) weight matrices, yielding the optimal permutation in O(F³) time. Permutations between non-adjacent layers can be approximated by composing intermediate permutations (P^(A→C) ≈ P^(B→C)·P^(A→B)), with quality degrading as layer distance increases. The key insight is that folding θ into the weights makes the MSE comparison sensitive to the true reconstruction scale rather than raw angular proximity, which the authors show empirically improves both MSE and LLM-judged semantic similarity of matched features.

## Results

On Gemma 2 (2B), folded parameter matching consistently achieves lower MSE than unfolded matching when evaluated in the scale of actual hidden state norms (Figure 3), and an external LLM (GPT-4o mini) rates folded matches as more semantically similar across all layers. Feature persistence is observed for approximately 5 layers: starting from layers 10, 12, or 20, the LLM 'SAME' score gradually declines but remains significant for ~5 subsequent layers (Figure 8). For layer pruning via encode-permute-decode, the change in cross-entropy loss (ΔL) is minimal from the 10th layer onward, with the smallest drop on OpenWebText (Figure 10). In the sparsity ablation (Appendix A), explained variance of approximated hidden states peaks at a mean l₀-norm of approximately 70, indicating an optimal sparsity level for matching.

## Baselines & Comparisons

The paper does not compare against external methods but ablates its own design choices. Folded matching outperforms unfolded matching on both MSE (Figure 3) and LLM semantic similarity (Figures 4, 7), supporting the hypothesis that incorporating JumpReLU thresholds into weights accounts for hidden-state norm growth across layers. Vanilla matching (no permutation) shows the highest MSE across all SAE parameters, confirming that feature ordering is not preserved between layers. For the weight-set ablation (Figure 12, Appendix), decoder-only matching performs on par with the full encoder+decoder scheme, while encoder-only matching suffers from poor quality. The LLM evaluation reveals that 'SAME' feature matches are near zero in the first ~10 layers (likely due to polysemanticity and high l₀ variance in early SAEs) but increase substantially in deeper layers, where features are more stable and matchable.

## Relation to Prior Work

This paper builds on the Sparse Autoencoder framework for monosemanticity (Bricken et al., 2023) and the JumpReLU variant with learnable thresholds (Rajamanoharan et al., 2024), extending the SAE toolset from single-layer feature extraction to cross-layer feature alignment. The matching mechanism directly adapts the Linear Assignment Problem formulation from Git Re-Basin (Ainsworth et al., 2022), which aligns permuted weights of functionally equivalent networks, to the setting of aligning SAE features across different layers of the same network. The key methodological departure is the parameter folding technique, which incorporates JumpReLU thresholds into encoder and decoder weights to account for hidden-state norm growth across depth—a consideration absent from prior weight-matching work.

## Why It Matters / Open Questions

This provides the first data-free, systematic tool for tracking how monosemantic features evolve through a transformer's depth, filling a gap that limits mechanistic interpretability to per-layer snapshots. The finding that features persist coherently for roughly five layers and that matched features enable near-lossless layer pruning (beyond the 10th layer) has practical implications for both interpretability analysis and efficient inference. Key limitations include the bijective matching assumption (some features clearly merge or split), the failure in early layers where polysemanticity is highest, and evaluation restricted to two model families (Gemma 2 2B, LLaMA 3.1 8B). Open questions include non-bijective matching, the role of l0-norm selection in matching quality, and whether the approach generalizes to architectures without JumpReLU.

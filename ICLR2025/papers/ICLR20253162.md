## Problem

Existing KV cache eviction strategies for transformers rely on hand-designed heuristics (e.g., L2 norms, attention statistics) that inevitably trade performance for efficiency. No learned memory management system exists that simultaneously improves both downstream task performance and inference efficiency, and that generalizes across different transformer architectures, input modalities, and task domains without retraining.
![Teaser figure](../imgs/ICLR20253162/cropped_page0_idx0.webp)

## Input / Output

NAMMs consume only the raw attention matrix values from the base transformer's KV cache—specifically, each token's column in the attention matrix is processed via a short-time Fourier transform with a 32-sample Hann window (stride 16) to yield 17-frequency spectrograms, which are then compressed along the time axis via an exponential moving average and augmented with 8-dimensional sinusoidal positional encodings. Every 512 new tokens, the NAMM outputs a scalar score per cached token; tokens scoring below zero are evicted, producing a pruned KV cache that the frozen base transformer uses for continued autoregressive generation. Because the input is derived exclusively from attention values, the same NAMM weights apply identically to every layer and head of any transformer, regardless of architecture or modality.

## Method

NAMMs parameterize a ~4000-parameter network (a single-head self-attention layer with a counter-causal 'backward' mask, followed by a linear projection) that scores each KV cache token for retention. The backward mask lets each token attend only to newer tokens, enabling learned cross-token competition that penalizes redundancy (e.g., repeated words) while preserving the most informative occurrence. The network is trained via CMA-ES evolutionary optimization—bypassing the non-differentiability of binary token selection—over three incremental stages (300, 250, 120 generations) on PassageRetrieval-en, DuReader, and NarrativeQA from LongBench, maximizing normalized task metrics relative to the full-context base model. A single NAMM is shared across all layers and heads of the base Llama 3 8B (context-extended to 32K via NTK-aware RoPE), and the resulting weights transfer zero-shot to Llama 3 70B, Llava Next Video 7B (video-language), and Decision Transformers (offline RL), improving performance in all three domains without any additional training.

## Results

On LongBench (Llama 3 8B), NAMM achieves 29.33 overall score (11% improvement over the 28.86 full-context base) while reducing the KV cache to 25% of its original size (8,155 vs. 32,768 tokens). On the extremely challenging InfiniteBench (~200K token contexts), NAMM delivers a 10.45× improvement, raising performance from 1.05 to 11.00 while using only 40% of the base cache. Zero-shot transfer to a Decision Transformer on D4RL yields a 9% overall reward gain (31.73 vs. 29.04) with 19% less cache, and transfer to Llava Next Video 7B on LongVideoBench/MLVU gives a 1% improvement (44.38 vs. 43.84) at 72% cache size.

## Baselines & Comparisons

NAMM is the only method that simultaneously improves performance and reduces cache size across all three language benchmarks, whereas H2O, L2, and FastGen all sacrifice performance for efficiency. On LongBench, NAMM (29.33, 1.11×) outperforms H2O (28.37, 0.99×), L2 (27.42, 1.00×), and FastGen (27.88, 0.95×) while using a comparable or smaller cache. The gap is most dramatic on InfiniteBench, where NAMM achieves 11.00 (10.45×) versus 1.05 for H2O, 1.63 for L2, and 1.42 for FastGen — a >6× margin over the best baseline. On ChouBun (Japanese), NAMM (24.44, 1.15×) beats H2O (19.86, 0.94×), L2 (18.93, 0.89×), and FastGen (18.93, 0.89×) by 4–5 points. In zero-shot transfer settings, NAMM consistently outperforms both H2O and L2: on Llama 3 70B it retains 99% of base performance vs. 97% (H2O) and 95% (L2); on vision it exceeds the base (1.01×) while both baselines fall short (0.96×, 0.95×); and on D4RL it achieves 1.09× vs. 0.99× (H2O) and 0.96× (L2). FastGen is only evaluated on language tasks due to its grammar-specific design and is not applicable to the cross-modality transfer experiments.

## Relation to Prior Work

This paper departs from the established line of hand-designed KV cache eviction strategies (H2O, L2, FastGen, Scissorhands) that trade performance for efficiency, instead using evolutionary optimization (CMA-ES) to learn a small neural network that manages the KV cache to simultaneously improve both performance and efficiency. The feature extraction via STFT of attention columns borrows from classical signal processing to create a model-agnostic representation, while the backward-attention memory (BAM) architecture introduces cross-token competition inspired by biological memory consolidation. The approach is positioned as orthogonal to other efficiency techniques (MQA/GQA, quantization) and complementary to gradient-based fine-tuning, carving new ground by treating memory management as a learnable black-box optimization problem rather than a heuristic design problem.

## Why It Matters / Open Questions

The key practical impact is that NAMMs break the assumed efficiency-performance tradeoff in long-context inference, offering a drop-in module (~4000 parameters) that can be evolved on a small task subset and then transferred zero-shot across architectures and modalities. The zero-shot transfer to vision and reinforcement learning suggests that attention-based memory management captures domain-agnostic principles of information relevance, opening questions about whether this generalizes further and whether the evolutionary training recipe can scale to more tasks or be combined with gradient-based fine-tuning. Limitations include the modest absolute gains in transfer settings (1.01×–1.09×), the reliance on a specific context-extension method (NTK-aware RoPE), and the computational cost of evolutionary training that limits the number of tasks and generations explored.

## Problem

State-of-the-art code embedding models underperform in demanding real-world tasks like bug localization within GitHub repositories because they are trained on noisy, heuristically sourced (text, code) pairs from open-source corpora that lack consistency filtering and effective hard negative mining. Additionally, code reranking—a technique well-established in text retrieval—remains largely unexplored due to the absence of high-quality contrastive (text, code) training data suitable for reranker fine-tuning.

## Input / Output

The retriever takes a natural language query (e.g., a docstring or GitHub issue description) and scores it against a corpus of code functions using cosine similarity in a shared embedding space, producing a ranked list of code snippets. The reranker then consumes the top-100 retrieved candidates as a sliding window (window size 10, stride 5) and outputs a reordered sequence of document identifiers in decreasing relevance. For the function localization application, the input is a full GitHub issue and the output is the specific functions within a repository that require modification, evaluated at top-5 and top-10 recall.

## Method

CORNSTACK is curated from The Stack V2 via a dual consistency filtering step that retains only (text, code) pairs where the positive is in the top-k=2 most similar snippets in the corpus AND has an embedding similarity above δ=0.7, yielding 21M high-quality examples across six languages. Hard negatives are mined in two stages: offline, false negatives are removed using a threshold γ·S_ii on the pre-computed similarity matrix; online, negatives are sampled via a softmax distribution over the similarity scores with a temperature τ' that is progressively annealed during training, forming a curriculum that increases negative difficulty. The retriever (CODERANKEMBED) is a 137M-parameter bi-encoder (Arctic-Embed-M) fine-tuned with InfoNCE loss over N·(M+1)−1 negatives per positive, while the reranker (CODERANKLLM) is a 7B listwise LLM (Qwen2.5-Coder) fine-tuned with a language modeling objective on ranked orderings generated by a 32B teacher model, making it the first LLM-based code reranker.

## Results

On CodeSearchNet (MRR@1000), CODERANKEMBED (137M params) achieves 77.9% average across six languages, outperforming CodeT5+ (74.2%), CodeSage-Large (71.2%, 1.3B params), and Jina-Code-v2 (67.2%). On AdvTest (MRR@1000, Python), it reaches 59.5%, a 18.7-point improvement over CodeT5+ (40.8%). On the CoIR benchmark (nDCG@10), CODERANKEMBED achieves 60.1% average, surpassing CodeSage-Large (59.4%) and Jina-Code-v2 (58.4%) despite being smaller than most baselines. For function localization on SWE-Bench-Lite, the combined retriever+reranker pipeline achieves 67.5% Top-5 and 73.7% Top-10 function-level accuracy, substantially exceeding Agentless GPT-4o (44.5% / 45.6%).

## Baselines & Comparisons

CODERANKEMBED outperforms all eight baselines across every benchmark. Against the closest code-specific competitor CodeT5+ (110M), it gains +3.7 points on CSN average and a striking +18.7 points on AdvTest (59.5 vs. 40.8), while also surpassing it on CoIR (60.1 vs. 45.9). It beats the much larger CodeSage-Large (1.3B, 10× more parameters) by +6.7 on CSN and +6.8 on AdvTest, and edges out CodeSage-Large on CoIR (60.1 vs. 59.4). Jina-Code-v2 (161M) is outperformed by +10.7 on CSN and +22.4 on AdvTest. The base text encoder Arctic-Embed-M (137M) improves dramatically after CORNSTACK finetuning (53.4→77.9 on CSN), confirming the dataset's value. On function localization (SWE-Bench-Lite), the retriever+reranker pipeline (67.5% Top-5) surpasses Agentless GPT-4o (44.5%) by 23 points, and even Agentless GPT-4o-mini (35.0%) by 32.5 points. The text reranker baseline (Qwen-2.5-Text, finetuned on text listwise data) achieves 78.8% CSN average, while the code-specific CODERANKLLM reranker reaches 80.5%, confirming the benefit of code-specific listwise training data.

## Relation to Prior Work

This paper adapts consistency filtering techniques from text embedding training (Wang et al., 2022; Günther et al., 2023) to the code domain, applying dual top-k and threshold-based filtering to (text, code) pairs sourced from The Stack V2. For hard negative mining, it departs from NV-Retriever's (Moreira et al., 2024) top-k selection by introducing softmax-based sampling with a temperature-annealing curriculum, and from CodeSage/CodeT5+ by operating over a corpus-level similarity matrix rather than in-batch or momentum-queue negatives. The listwise code reranker extends the RankZephyr (Pradeep et al., 2023) framework—previously applied only to text—into the code domain for the first time, using a 32B teacher LLM to generate ranking supervision from the curated contrastive triples.

## Why It Matters / Open Questions

CORNSTACK addresses a fundamental data-quality bottleneck in code embedding training: noisy (text, code) pairs from heuristically sourced corpora limit retrieval accuracy in real-world settings like GitHub issue resolution. The demonstration that a 137M encoder trained on high-quality contrastive data outperforms 1.3B code-specific models suggests the field may be over-investing in model scale at the expense of training data curation. The introduction of code reranking as a distinct pipeline stage opens an underexplored direction, and the SWE-Bench-Lite function localization results show practical impact on automated software engineering. Open questions include whether the approach generalizes beyond the six supported languages, whether execution-based validation could further improve data quality, and whether the reranking gains hold on private repositories not seen during LLM pretraining.

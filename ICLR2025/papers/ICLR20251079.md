## Problem

Existing object detection models, whether CNN-based or Transformer-based, process only the current input image and ignore the rich information available across the entire training dataset. While Retrieval-Augmented Generation (RAG) in NLP demonstrates the value of external knowledge retrieval, adapting this paradigm to real-time vision tasks remains challenging due to the need to balance accuracy, parameter count, and inference latency when incorporating external data.
![Teaser figure](../imgs/ICLR20251079/cropped_page1_idx0.webp)

## Input / Output

The RD module operates as a plug-in on intermediate feature maps (e.g., 512-dimensional vectors at 80×80 spatial resolution) within the backbone, rather than on raw pixels. The Dictionary is pre-built offline by encoding the entire training dataset with an external model (YOLOv9, CLIP, or GPT) and reducing the resulting embeddings to N atoms via k-means. At inference, the module adds less than 1% parameters and ~0.1–0.3 ms latency to the base model while producing the same outputs: bounding boxes, segmentation masks, or class labels.

## Method

The Retriever-Dictionary (RD) module consists of a pre-built Dictionary of N weight-normalized atoms and a Retriever core that generates per-pixel coefficients to select relevant atoms. The Retriever is decomposed into a pointwise 1×1 convolution (Coefficient Generator G) for channel projection and a depthwise k×k convolution (Global Information Exchanger E) for local spatial refinement, drastically reducing parameters compared to a fused convolution. Coefficients are normalized via PONO to prevent the Dictionary from collapsing into an identity mapping, and the final output is a residual blend of the input and the weighted atom summation (equivalent to a 1×1 convolution). The Dictionary is initialized by encoding the full dataset with a vision, vision-language, or language model and applying k-means, embedding cross-modal knowledge into the atoms. A post-training compression step uses contrastive learning to distill the Dictionary into a smaller subset (≥50% reduction) while preserving output fidelity.

## Results

On COCO 2017 validation, the RD module with CLIP (VLM) initialization improves YOLOv7 from 50.04 to 51.75 mAP (↑3.42%) and YOLOv9 from 52.64 to 53.41 mAP (↑1.46%), with less than 1% additional parameters. The largest relative gain appears on Faster R-CNN (ResNet-50), where LLM initialization boosts mAP from 38.40 to 40.70 (↑5.99%), surpassing the ResNet-101 variant. Across all four architectures tested, the RD module adds only 0.2–0.5M parameters while delivering improvements comparable to upgrading to the next model size (which typically requires ~100% more parameters).

## Baselines & Comparisons

The RD module outperforms all seven baselines across every architecture tested. Against the original YOLOv7 (50.04 mAP), YOLOv9 (52.64 mAP), Faster R-CNN (38.40 mAP), and Deformable DETR (43.80 mAP), the best RD configuration improves mAP by 3.42%, 1.46%, 5.99%, and 1.37% respectively, with under 1% parameter overhead for YOLO variants. In the knowledge-integration comparison (Table 3), RD (53.36 mAP, +0.2M params) decisively beats knowledge distillation (52.52 mAP, +57.3M params), YOLO-World (51.00 mAP, +66.1M params), and RALF (51.40 mAP, +37.8M params), achieving the highest accuracy with roughly 1/200th the additional parameters of the next-lightest competitor. The VLM (CLIP) initializer consistently yields the best or near-best results across architectures, while LLM (GPT) initialization produces the largest absolute gain on Faster R-CNN. No baseline is matched or exceeded by RD in any tested configuration.

## Relation to Prior Work

This paper adapts the Retrieval-Augmented Generation (RAG) paradigm from NLP—where a pre-built database is queried at inference—to real-time object detection, combining it with dictionary learning from signal processing. It builds directly on the YOLOv7/YOLOv9 backbone-neck-head architecture and departs from prior knowledge-integration methods (YOLO-World, RALF) by replacing heavy external vocabulary databases with a compact, trainable set of dictionary atoms initialized from VM/VLM/LLM encoders. The depthwise-separable decomposition of the Retriever core (pointwise + depthwise convolution) draws on Xception-style factorization to keep parameter overhead under 1%.

## Why It Matters / Open Questions

The RD module offers a practical, plug-and-play mechanism for injecting dataset-wide explicit knowledge into detection models at negligible parameter cost, with demonstrated gains across CNN, two-stage, and Transformer architectures as well as segmentation and classification tasks. A key open question is generalization: the Dictionary is pre-computed per dataset, so transferring to a new domain requires re-encoding, and the paper does not explore open-vocabulary or zero-shot settings. The 50%+ atom compression via contrastive distillation is promising but its interaction with domain shift remains untested, and the approach's ceiling on very large or highly diverse datasets is unclear.

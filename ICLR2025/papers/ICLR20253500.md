## Problem

Existing LLM reasoning benchmarks conflate generalization with memorization, scale difficulty primarily through input length rather than intrinsic task complexity, and remain vulnerable to data contamination. This makes it impossible to determine whether a model's correct answer reflects genuine reasoning or pattern recall, and to quantify how the balance between these two behaviors shifts as tasks become harder or models grow larger.

## Input / Output

For each of 20 algorithmic tasks, the framework takes a task description plus a dynamically generated input (a list of non-negative integers or an adjacency matrix) and produces a single answer. ID test instances are approximated by prompting the target LLM itself to generate ~10k examples, from which ~100k individual elements are extracted; OOD instances are then sampled from the complement of those elements while matching the same example lengths. The final evaluation uses 256 validated samples per ID/OOD split, and the outputs are per-complexity-level ID accuracy, OOD accuracy, the performance gap max(0, A_ID − A_OOD), a composite Generalization Score S = A_OOD − max(0, A_ID − A_OOD), and the critical complexity level at which the gap peaks.

## Method

SCYLLA organizes 20 tasks into five complexity intervals (O(N), O([N,N²]), O([N²,N³]), O([N³,N⁴]), O(2^N)) using algorithmic time complexity as the difficulty axis, while explicitly constraining input lengths to keep complexity independent of sequence length. All test data are synthesized at evaluation time via a three-step pipeline: (1) prompt the target model to generate task-appropriate inputs, (2) extract ID elements via regex and define OOD elements as the complement within a universal set [0, 9999], and (3) construct matched-length OOD examples and validate/deduplicate to 256 samples. The key analytical insight is that the ID–OOD accuracy gap serves as a proxy for memorization reliance, and plotting this gap against complexity reveals a non-monotonic 'generalization valley' whose peak (critical complexity) shifts rightward with model size, indicating that larger models sustain generalization over a broader range of task difficulties before over-relying on memorized patterns.

## Results

SCYLLA introduces a Generalization Score S = A_OOD − max(0, A_ID − A_OOD) ranging from −1 to 1, evaluated across 5 algorithmic complexity levels (O(N) through O(2^N)) on 28 LLMs. The top performer, o1-mini, achieves near-perfect scores (1.000, 0.998, 0.979, 0.949, 0.680) across all complexity levels with a critical complexity of O(2^N), while GPT-4o reaches 0.997/0.992/0.787/0.457/0.238 with critical complexity at O([N³,N⁴]). Among open-source models, Llama-3.1-405B leads with scores of 0.997/0.996/0.847/0.516/0.262, and Qwen2.5-7B is the best 7B model (0.617/0.632/0.514/0.122/0.136). The paper identifies a non-monotonic 'generalization valley' where the ID–OOD performance gap peaks at a model-specific critical complexity, and this peak shifts rightward (to higher complexity) as model size increases.

## Baselines & Comparisons

SCYLLA is compared against five existing evaluation frameworks (CLRS-text, DyVal, NPHardEval, LiveBench, and Wu et al. 2023) along four criteria: scalability in task complexity, knowledge dependency, memorization awareness, and number of tasks. SCYLLA is the only framework achieving 'full' marks on both scalability and memorization awareness while maintaining low knowledge dependency, with 20 tasks. CLRS-text offers partial scalability and memorization awareness but requires training on algorithm execution traces, making it impractical for black-box evaluation. DyVal and NPHardEval increase difficulty by extending input length (conflating length with intrinsic complexity) and provide no memorization-aware evaluation. LiveBench is knowledge-intensive and offers no scalability or memorization awareness. Wu et al. (2023) provide full memorization awareness via counterfactual tasks but lack scalability and require domain knowledge. In terms of model rankings, closed-source models (o1-mini, GPT-4o) consistently outperform open-source counterparts at higher complexity levels, with o1-mini being the only model to maintain positive generalization scores across all five complexity levels.

## Relation to Prior Work

This paper synthesizes two research threads: the generalization-vs-memorization debate in LLMs (Wu et al. 2023, Lotfi et al. 2023, Dong et al. 2024) and dynamic algorithmic-reasoning benchmarks (CLRS-Text, NPHardEval, DyVal). It departs from prior dynamic benchmarks by using algorithmic time complexity (rather than problem length) as the primary difficulty axis, and from prior generalization analyses by explicitly constructing ID/OOD splits to isolate memorization from generalization. The 'generalization valley' and 'critical complexity' concepts are new analytical framings that no prior benchmark or evaluation framework has articulated, though the underlying ingredients (ID/OOD comparison, complexity-based task grouping) each have antecedents.

## Why It Matters / Open Questions

SCYLLA provides a principled, contamination-resistant way to quantify where LLMs transition from generalizing to memorizing, and the critical-complexity metric gives a concrete, model-specific threshold that practitioners can use to calibrate expectations. The finding that the ID-OOD gap is non-monotonic (peaking at intermediate complexity) challenges the intuitive assumption that harder tasks always reveal more memorization. Key limitations include the restriction to algorithmic/numeric tasks (no language, logic, or multi-step reasoning), the somewhat circular ID-data approximation (querying the model about its own distribution), and the use of zero-shot CoT only. Open questions include whether the generalization valley persists for non-algorithmic reasoning tasks and whether the ID/OOD split truly captures memorization versus generalization or conflates them with distributional familiarity.

## Problem

TopK-based sparse attention, the dominant approach for reducing KV cache computation in long-context LLM inference, is a biased estimator that degrades significantly on aggregation tasks where attention distributions are long-tailed rather than peaked. Moreover, identifying the TopK keys incurs substantial search overhead and does not reduce the total KV cache memory footprint. The paper asks whether a sampling-based approximation with theoretical guarantees can outperform TopK while being cheaper to compute and enabling GPU memory savings.

## Input / Output

At each decoding step, MAGICPIG receives the current query vector q (one per attention head), the full KV cache (K, V) of n tokens, a set of K×L random projection matrices W shared across heads, and pre-built LSH hash tables stored in CPU DRAM. The query is projected on GPU to produce a hash code, which is then used to look up candidate keys in the CPU-resident hash tables. The output is a self-normalized importance-sampled weighted average of the retrieved value vectors, which replaces the exact softmax attention output and feeds directly into the next linear projection for token generation. The computation budget is controlled by the LSH hyperparameters (K, L), typically yielding 2–5% of full attention FLOPs.

## Method

MAGICPIG replaces TopK key selection with LSH-based sampling via self-normalized importance sampling. Key vectors are first centered (exploiting softmax translation invariance) to fix the geometric misalignment between queries and keys that makes nearest-neighbor search ineffective. SimHash with K random projections per table and L tables is used: a key is sampled if it collides with the query in at least two hash tables, and the collision probability u_i serves as the sampling probability in the importance-sampling estimator. The final attention estimate is a weighted average over sampled values, with weights proportional to exp(qk_i^T/√d) / u_i, normalized by the sum of the same weights. The system co-design partitions work across GPU and CPU: random projections (compute-bound) run on GPU, while hash table storage, key retrieval, and the reduced attention computation (memory-bound) run on CPU DRAM, enabling 10–20× larger KV caches than fit in GPU VRAM and supporting hash table scales (K=8–11, L=75–300) far beyond prior LSH-attention work.

## Results

On RULER synthetic tasks with Llama-3.1-8B-Instruct, MAGICPIG (10,150) achieves 86.4% average accuracy across 16K–96K contexts with only 2% computation cost, compared to 88.7% for full attention. At 96K context, MAGICPIG scores 80.0% versus 74.9% for Quest (16,0.04) and 34.7% for Loki (32,0.03). On lm-eval-harness comprehensive tasks (GSM8K, COQA, MMLU), MAGICPIG (10,220) achieves 71.2% average with 3% cost, substantially outperforming Quest (16,0.05) at 55.0% with 11% cost. System-level, MAGICPIG delivers up to 5× throughput improvement (L20) and 54ms decoding latency on a single RTX 4090 for 96K context.

## Baselines & Comparisons

MAGICPIG consistently outperforms Quest across all context lengths on RULER. At 96K context, MAGICPIG (9,120) achieves 81.5% versus Quest's best of 74.9% (16,0.04), a 6.6-point gap, while using only 4% total cost versus Quest's 10%. On lm-eval-harness tasks, the advantage is even more pronounced: MAGICPIG (10,220) scores 71.2% average versus Quest (16,0.05) at 55.0%, a 16.2-point improvement at less than one-third the cost. Against Loki, MAGICPIG is dramatically superior at longer contexts—80.0% vs. 34.7% at 96K—because Loki's low-rank key approximation breaks down as context grows. Notably, MAGICPIG also outperforms exact TopK attention on aggregation tasks (CWE, FWE) by up to 3% and 8% respectively, demonstrating that sampling-based estimation fundamentally exceeds the TopK ceiling that search-only methods like Quest and Loki are constrained by.

## Relation to Prior Work

This paper departs from the dominant TopK/search-based sparse attention paradigm (Quest, Loki, H2O, SnapKV) by reframing attention approximation as a sampling and estimation problem rather than a nearest-neighbor search problem. It builds on the LSH-based attention lineage (Reformer, ScatterBrain, KDEformer) but is the first to apply LSH sampling to self-attention in decoder-only LLM generation, combining it with self-normalized importance sampling for unbiased estimation. The system design extends prior CPU-GPU offloading work (FastDecode, DeepSpeed Inference) by partitioning the workload so that hash table storage and reduced attention computation run on CPU while random projections stay on GPU, enabling hash table scales (K=8–11, L=75–300) far beyond prior LSH-attention methods.

## Why It Matters / Open Questions

The paper challenges a core assumption in the sparse attention literature—that selecting the highest-scoring keys (TopK) is the optimal approximation—by showing it is a biased estimator that degrades on aggregation tasks, and that LSH-based sampling can beat exact TopK by up to 8%. Practically, the 1.5–5× throughput gains and 54ms single-request latency at 96K context on consumer hardware make long-context serving significantly more accessible. Key limitations include the requirement for substantial CPU DRAM (14–28 GB for hash tables), the absence of a prefilling-stage implementation, and manual hyperparameter tuning of (K, L). Open questions include whether more advanced LSH variants (cross-polytope, data-dependent) can further reduce memory overhead, and whether the sampling framework extends to the compute-bound prefilling phase.

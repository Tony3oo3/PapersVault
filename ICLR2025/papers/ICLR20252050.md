## Problem

Extending 2D foundation models like SAM to 3D segmentation via multi-view lifting is constrained by view selection, multi-view inconsistency, inability to handle textureless shapes, and inability to label internal structures. No native 3D promptable segmentation model exists that unifies diverse point cloud data (indoor/outdoor, part/object level, varying scales) under a single architecture with strong zero-shot transferability.
![Teaser figure](../imgs/ICLR20252050/cropped_page1_idx0.webp)

## Input / Output

The model takes a point cloud P ∈ R^{N×3} (normalized to a unit sphere, with N ranging from 10K at training to over 1.3M at inference) along with point prompts (3D coordinates with binary foreground/background labels) and optional mask prompts (pointwise logits from prior predictions). It outputs a per-point segmentation mask Y_mask ∈ R^{N×1} and, for single-point-prompt queries, multiple candidate masks with predicted IoU scores. The model is fully feed-forward, responding in seconds without per-query optimization, and handles variable point counts by dynamically adjusting the number of patches (512–4096) and patch size (64–512).

## Method

Point-SAM employs a three-component architecture: a ViT-based point-cloud encoder with a novel Voronoi tokenizer (assigning each point to its nearest FPS center and scatter-max pooling within Voronoi cells, yielding 163% speedup and 18% memory reduction over KNN grouping), a prompt encoder that processes point prompts via positional encodings and mask prompts via the same tokenizer, and a two-way transformer mask decoder that cross-attends between prompt and point-cloud embeddings before upsampling via inverse-distance-weighted interpolation and a dynamic linear classifier. Training uses a weighted focal+dice loss over 7 simulated interactive iterations, a hindsight loss for multi-mask outputs, and MSE for IoU prediction. A key data engine distills SAM's 2D knowledge into 3D pseudo labels by rendering multi-view RGB-D images, lifting 2D SAM proposals to 3D via Point-SAM, and iteratively refining with cross-view consistency checks, generating ~17 diverse masks per ShapeNet shape to expand label diversity beyond what ground-truth datasets provide.

## Results

On zero-shot point-prompted segmentation, Point-SAM (Voronoi tokenizer) achieves IoU@1 of 46.0 on PartNet-Mobility (held-out categories), 52.4 on ScanObjectNN, 63.6 on S3DIS, and 52.8 on KITTI360, substantially outperforming AGILE3D (26.4, 34.8, 58.7, 34.8 respectively) and MV-SAM (29.3 on PartNet-Mobility). With 10 prompts, Point-SAM reaches IoU@10 of 77.8, 85.7, 87.3, and 85.7 across the four datasets. For zero-shot object proposal generation on Replica, Point-SAM achieves AR25 of 49.2, surpassing OpenMask3D (40.2). The Voronoi tokenizer also improves inference speed by up to 163.4% (5.2→13.7 shapes/sec on KITTI360) while reducing GPU memory by 18.4%.

## Baselines & Comparisons

Point-SAM (Voronoi) decisively outperforms AGILE3D across all four main benchmarks, with the largest margins on out-of-distribution data: +19.6 IoU@1 on PartNet-Mobility (46.0 vs 26.4) and +18.0 IoU@1 on KITTI360 (52.8 vs 34.8), confirming the benefit of training on a 100× larger and more diverse dataset. Against MV-SAM (a multi-view lifting baseline that has access to rendered meshes), Point-SAM leads by +16.7 IoU@1 on PartNet-Mobility (46.0 vs 29.3), demonstrating superior prompt efficiency since MV-SAM samples k prompts per view rather than k total. On S3DIS, Point-SAM (Voronoi) edges out AGILE3D at IoU@1 (63.6 vs 58.7) but trails slightly at IoU@10 (87.3 vs 88.5), while the KNN variant actually surpasses AGILE3D at higher prompt counts. For zero-shot object proposals on Replica, Point-SAM improves AR25 by 9.0 points over OpenMask3D (49.2 vs 40.2) while matching AR50 (31.5). In few-shot part segmentation on ShapeNetPart, Point-SAM (73.9/76.1 mIoU at 1/2-shot) beats PointBERT (66.2/71.9) and Uni3D-close (71.5/73.8), though Uni3D-open (75.9/78.2) retains a small 2-shot advantage due to its CLIP-based open-vocabulary design.

## Relation to Prior Work

Point-SAM directly extends the Segment Anything Model (SAM) from 2D images to native 3D point clouds, departing from prior approaches (SAM3D, SAMPro3D, PartSLIP) that render multi-view images and lift 2D SAM predictions back to 3D. Architecturally, it builds on transformer-based point cloud encoders (Point Transformer, Point-BERT, Uni3D) but introduces a novel Voronoi-diagram-based tokenizer for efficient patch formation, replacing the standard KNN grouping. The data engine conceptually follows SAM's SA-1B pipeline but adapts it to 3D by using 2D SAM to generate diverse pseudo-labels on rendered views, then refining them with the 3D model itself. Compared to prior 3D interactive segmentation methods (AGILE3D, InterObject3D), Point-SAM unifies part-level and object-level segmentation in a single model trained on a far more heterogeneous mixture of synthetic and real datasets.

## Why It Matters / Open Questions

This is the first native 3D promptable segmentation model for point clouds that handles both part- and object-level granularity in a unified framework, addressing a clear gap where prior 3D methods were either limited to single datasets (ScanNet) or relied on 2D lifting with multi-view inconsistency. The Voronoi tokenizer offers a practical efficiency gain (up to 163% FPS improvement) that is likely to be adopted in other point cloud transformer pipelines. Key limitations remain: 3D training data is still ~100× smaller than 2D web-scale data, pseudo-label quality is bounded by 2D SAM's understanding of 3D structure, and the model has not been tested on truly large-scale outdoor scenes beyond KITTI-360. Open questions include whether the data engine can be bootstrapped further with 3D-native foundation models and whether the architecture scales to scenes with millions of points without the current patch-count heuristics.

## Problem

Transformers provide high-resolution recall through KV caches but suffer from quadratic compute and large memory footprints, while SSMs like Mamba offer linear complexity but struggle with memory recall tasks. Existing hybrid models that stack attention and SSM layers sequentially introduce information bottlenecks when one layer type is poorly suited for a given task. The paper asks whether fusing attention and SSM heads in parallel within the same layer can simultaneously achieve strong recall and high efficiency for small language models.

## Input / Output

The model consumes a text token sequence with 128 learnable meta tokens prepended at the front, which serve as a learned cache initialization and are computed offline at inference. Output is standard autoregressive text generation, but the KV cache is dramatically compressed: only 3 of 32 layers use global attention (the rest use sliding-window attention with a 1024-token window), and consecutive layers share KV caches, yielding an 11.67× smaller cache than Llama-3.2-3B at 8k sequence length. The model family spans 125M, 350M, and 1.5B parameters, all trained on 2k→8k context lengths.

## Method

Hymba introduces a hybrid-head module where attention heads and Mamba SSM heads process the same input in parallel within each layer, unified under a symmetric formulation Y = W_out(β₁·norm(M_attn·X̃) + β₂·norm(M_ssm·X̃)) where both operators are data-controlled linear maps. To offset the KV cache cost of attention heads, the architecture uses sliding-window attention in 29 of 32 layers (global attention only in the first, middle, and last layers) and cross-layer KV sharing between consecutive layer pairs. A set of 128 learnable meta tokens is prepended to every input sequence, acting as attention sinks that redistribute attention away from the BOS token, reduce attention map entropy in both head types, and encode compressed world knowledge. The model is pretrained with a WSD scheduler on 1.5T tokens (DCLM, SmolLM-Corpus, and proprietary data), then post-trained via full finetuning followed by DPO for instruction following.

## Results

Hymba-1.5B achieves 61.06% average accuracy across 7 tasks (MMLU 5-shot, ARC-E, ARC-C, PIQA, Winogrande, HellaSwag, SQuAD-C), surpassing all sub-2B public models and outperforming the larger Llama-3.2-3B (59.74%) by 1.32%. In terms of efficiency, Hymba-1.5B requires only 79 MB of KV cache at 8k sequence length (11.67× smaller than Llama-3.2-3B's 918 MB) and achieves 664 tok/s throughput (3.49× faster than Llama-3.2-3B's 191 tok/s). The instruction-tuned Hymba-1.5B-Instruct further achieves best-in-class performance on GSM8K (58.76%), GPQA (31.03%), and BFCLv2 (46.40%), with a 49.22% average across five downstream tasks.

## Baselines & Comparisons

Hymba-1.5B (1.5T tokens) outperforms the strongest sub-2B baseline SmolLM2-1.7B (11T tokens) by 1.02% average accuracy while using 19.91× less cache (79 MB vs 1573 MB) and achieving 2.79× higher throughput (664 vs 238 tok/s). Against Llama-3.2-3B, Hymba achieves 1.32% higher average accuracy with 11.67× smaller cache and 3.49× higher throughput. Among models trained on ≤2T tokens, Hymba leads Phi-1.5 (55.85%) and h2o-danube2 (55.65%) by 5.21% and 5.41% respectively. In the apple-to-apple 1B architecture comparison (Table 3), Hymba outperforms Mamba2, Mamba2+FFN, Llama3, and Samba on most tasks, achieving 1.74% higher average commonsense reasoning accuracy and 49.50% on recall-intensive tasks (vs. 47.33% for Llama3 and 36.17% for Samba). For instruction-tuned models, Hymba-1.5B-Instruct surpasses Qwen2.5-1.5B-Instruct by ~2% average (49.22 vs 47.30) and leads on GSM8K, GPQA, and BFCLv2. In the DoRA parameter-efficient finetuning experiment, Hymba-DoRA (1.5B) outperforms RoleLlama-7B by 4.5% on instruction generalization and 4.4% on role generalization.

## Relation to Prior Work

Hymba departs from the dominant paradigm of sequential hybrid models (Jamba, Zamba, Samba) that interleave attention and SSM layers, instead fusing them in parallel within a single layer as complementary head types analogous to multi-head attention. The SSM component builds directly on Mamba's selective state space mechanism, while the KV cache optimization draws on cross-layer attention sharing (Brandon et al., 2024) and sliding window attention (Longformer). The learnable meta tokens synthesize ideas from prompt tuning, attention sink mitigation, and ViT register tokens into a unified pretraining-compatible mechanism that also serves as learned cache initialization.

## Why It Matters / Open Questions

The 11.67× cache reduction and 3.49× throughput gain over Llama-3.2-3B while achieving higher accuracy makes Hymba a compelling architecture for on-device and edge deployment where memory bandwidth is the bottleneck. The finding that only three layers (first, middle, last) need global attention when SSM heads provide global context is a practical design insight that could transfer to other hybrid architectures. Open questions include whether the parallel hybrid-head advantage persists at 7B+ scale, whether the architecture generalizes to multimodal settings, and whether the modest MMLU gap versus Qwen2.5-1.5B (trained on 18T vs 1.5T tokens) narrows with more data.

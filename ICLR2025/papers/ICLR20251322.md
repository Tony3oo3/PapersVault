## Problem

Existing agent benchmarks for web navigation and multimodal tasks focus almost exclusively on text and static image inputs, neglecting the long-context video understanding that is essential for real-world agentic workflows. While video QA benchmarks exist, none evaluate whether a model can use video information as part of a multi-step interactive task—retrieving facts from a tutorial or learning a skill from a demonstration and then executing it in a live web environment. VideoWebArena fills this gap by introducing 2,021 video-grounded web agent tasks that require both video comprehension and sequential action execution.

## Input / Output

At each step, the agent receives a Set-of-Marks annotated screenshot and element tree string of the current web page, the task objective text, and video context in one of three forms: the full .mov video file (for Gemini 1.5 Pro), 30–100 sampled frames plus a Whisper audio transcription (for GPT-4o), or a GPT-4o-generated text summary of the video. The agent must emit exactly one action from a 14-action space (click, type, scroll, goto, etc.) per step, with element references using SoM numeric IDs. For factual retention tasks, the agent must also produce an intermediate free-text answer to a video-based question before completing the web task; both the intermediate answer and final task state are scored binary (0/1) by automatic evaluators.

## Method

VideoWebArena is built on six locally hosted web environments inherited from WebArena and VisualWebArena (Reddit, Classifieds, Shopping, Shopping Admin, Map, GitLab), with 74 manually created video tutorials (~4 hours total, avg. 3:05 min) mapped to 1,621 skill retention tasks and 400 factual retention tasks organized under a four-subcategory taxonomy (Visual Perception, Audio Perception, Full Video Understanding, Temporal Reasoning). Three baseline agent architectures are evaluated: a Video In-Context agent feeding the full video to Gemini 1.5 Pro, a Video Frame agent sampling 1 fps (max 60–100 frames) plus Whisper transcription into GPT-4o, and a Video Summary agent using a GPT-4o-generated task-relevant summary. The environment is formalized as a POMDP with Set-of-Marks observation and Playwright-based action execution. A key empirical finding is that on skill retention tasks, providing the video tutorial actually degrades GPT-4o performance by 5–10% relative to no-tutorial baselines, while humans improve by 10–16%, indicating that current long-context models treat video as noise rather than a useful signal for action planning.

## Results

On VideoWebArena's 400 factual retention tasks, the best-performing model (GPT-4o Summary Agent) achieves only 13.3% final task success and 36.8% intermediate intent success, while the GPT-4o Frame Agents (30/100 frames) reach 45.8% intermediate intent success but only 9.5–11.0% final task success. Human performance dramatically outperforms all models at 73.9% final and 79.3% intermediate success. On skill retention tasks, adding video tutorials in-context actually degrades GPT-4o performance by 5% on WebArena (14.9% → 9.9%) and 10.3% on VisualWebArena (19.8% → 9.5%), whereas humans improve from 82.6% to 93.1% (WebArena) and 72.7% to 88.6% (VisualWebArena) with tutorials.

## Baselines & Comparisons

The paper evaluates three agent architectures (Video-in-context, Video Frames, Video Summary) across three model families (GPT-4o, Gemini 1.5 Pro, Phi-3.5V) against human performance. No single agent configuration dominates: the GPT-4o Summary Agent achieves the best final task success (13.3%) on factual retention despite having no visual video input, while the GPT-4o Frame Agents (30/100 frames) achieve the best intermediate video QA accuracy (45.8%). Gemini 1.5 Pro, which processes the full video natively, underperforms GPT-4o variants on both final (7.0%) and intermediate (37.0%) scores, and takes significantly more steps (19.4 vs. ~13). Phi-3.5V is far behind all other models (1.2% final, 13.0% intermediate). The most striking comparison is with humans: all models fall 60+ points below human final success (73.9%) and 30+ points below human intermediate success (79.3%). On skill retention, the key finding is that tutorials hurt model performance (GPT-4o drops from 14.9% to 9.9% on WebArena) while helping humans (82.6% → 93.1%), suggesting current models cannot effectively leverage video demonstrations.

## Relation to Prior Work

VideoWebArena sits at the intersection of two previously separate research threads: web agent benchmarks (WebArena, VisualWebArena) and video understanding benchmarks (MVBench, EgoSchema, LongVideoBench, Video-MME). It inherits the interactive web environment, Set-of-Marks observation space, and task templates from WebArena/VisualWebArena, but introduces video tutorials as a required input modality for all 2,021 tasks. The key conceptual departure is that prior agent benchmarks treat video as absent or optional, while prior video benchmarks are non-agentic (static QA rather than multi-step action sequences); VideoWebArena unifies both by requiring agents to process long video context while simultaneously navigating a live web environment.

## Why It Matters / Open Questions

The benchmark reveals a striking and actionable gap: the best model achieves only 13.3% on factual retention tasks versus 73.9% for humans, and the large gap between intermediate intent success (45.8%) and final task success (13.3%) localizes the bottleneck to agentic action generation rather than video comprehension per se. The finding that video tutorials actively degrade skill retention performance (5–10% drop) challenges the intuitive assumption that more context always helps, pointing to a need for better modality-aware attention or selective context integration in agent architectures. As a fully reproducible, open-source environment with 4 hours of video across 6 domains, VideoWebArena is positioned to become a standard testbed for the next generation of long-context multimodal agents.

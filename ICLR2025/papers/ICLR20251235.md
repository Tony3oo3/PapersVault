## Problem

Existing visual preference alignment methods (DPO, RLHF) are designed for single-image scenarios and cannot effectively handle multi-image tasks, where LVLMs exhibit two unique hallucination types—Sequence Confusion (misidentifying which image a question refers to) and Element Interference (confusing visual attributes across images). Extending single-image DPO pipelines to multi-image settings is non-trivial due to the scarcity of diverse multi-image training data and the high cost of constructing chosen/rejected pairs via human annotation or expensive API calls.

## Input / Output

The method converts existing single-image QA data (LLaVA-665k) into multi-image prompts by inserting unrelated images in three spatial arrangements: sequential (2–5 images), grid collage (2–9 images merged into one labeled composite), and pic-in-pic (one image overlaid on another). The model receives these multi-image inputs alongside a text question that specifies the target image via language description (e.g., 'In Image 2, what color is the car?'), and produces a free-form text response. For DPO training, the chosen response is the ground-truth answer while the rejected response is a model-generated hallucination identified through attention analysis.

## Method

MIA-DPO operates in three stages. First, it augments single-image data into multi-image prompts using the three spatial formats, each targeting a specific hallucination type (sequence targets Sequence Confusion; grid collage and pic-in-pic target Element Interference). Second, it performs Attention-Aware Selection: for each generated response, it computes the attention ratio R(y) = A_target / A_sum (attention on the instructed image divided by total attention across all images) and selects responses below a format-specific threshold τ as rejected samples, eliminating the need for human annotation or external APIs. A post-selection step then filters noisy pairs using perplexity, length ratio, and edit distance. Finally, the model is optimized with a combined DPO loss plus a negative log-likelihood (NLL) term on chosen responses (weighted by γ=0.1) to stabilize training, with a KL-divergence constraint preventing degradation of single-image capabilities.

## Results

On five multi-image benchmarks (MMMU, BLINK, Mantis, NLVR2, MVBench), MIA-DPO achieves an average score of 43.4 on LLaVA-v1.5 (+3.0 over baseline) and 57.9 on InternLM-XC2.5 (+4.3 over baseline). The largest single-benchmark gain is +11.1 on Mantis for InternLM-XC2.5 and +5.8 on BLINK for LLaVA-v1.5. On seven single-image benchmarks, MIA-DPO maintains the LLaVA-v1.5 baseline average (49.1) while slightly degrading InternLM-XC2.5 (72.8 vs. 73.5), confirming that multi-image gains do not come at the cost of single-image capability.

## Baselines & Comparisons

MIA-DPO outperforms all three single-image preference-optimization baselines on multi-image benchmarks. Against LLaVA-RLHF (Sun et al., 2023), MIA-DPO gains +4.3 average on LLaVA-v1.5 (43.4 vs. 39.1); LLaVA-RLHF actually degrades below the baseline on Mantis (30.4 vs. 41.9). Against HA-DPO (Zhao et al., 2023), MIA-DPO leads by +3.2 on LLaVA-v1.5 (43.4 vs. 40.2) and by +3.9 on InternLM-XC2.5 (57.9 vs. 54.0). Against POVID (Zhou et al., 2024), the gap is largest: MIA-DPO surpasses POVID by +12.7 on LLaVA-v1.5 (43.4 vs. 30.7) and by +3.6 on InternLM-XC2.5 (57.9 vs. 54.3); POVID's image-distortion strategy severely harms NLVR2 (21.4 vs. 54.2). On single-image benchmarks, MIA-DPO matches or slightly exceeds the LLaVA-v1.5 baseline (49.1 avg), while POVID edges ahead by 0.8 points (49.9), indicating that the multi-image gains of MIA-DPO are achieved without sacrificing single-image performance.

## Relation to Prior Work

This paper extends the DPO-based visual preference alignment lineage (LLaVA-RLHF, HA-DPO, POVID, RLAIF-V) from single-image to multi-image scenarios, where no prior preference alignment method had been applied. The key conceptual departure is using the model's own attention values as a free, automated signal to identify hallucinated rejected responses, eliminating the need for human annotation or expensive GPT-4 API calls that characterized all prior visual DPO data construction. The data augmentation strategy—converting existing single-image datasets (LLaVA-665k) into multi-image prompts via sequence, grid collage, and pic-in-pic formats—repurposes abundant single-image resources to address the multi-image data scarcity problem.

## Why It Matters / Open Questions

MIA-DPO provides a low-cost, architecture-agnostic recipe for multi-image preference alignment that practitioners can apply to any LVLM without expensive annotation pipelines, making multi-image alignment accessible beyond well-resourced labs. The attention-as-hallucination-detector insight opens a broader question about whether internal model signals can replace external reward models for data curation in other multimodal settings. Limitations include diminishing returns at very high image counts (context window constraints), persistent out-of-domain failures (medical, fine-grained classification), and a slight single-image trade-off on some architectures (InternLM-XC2.5), suggesting the multi-image/single-image balance remains an open optimization problem.

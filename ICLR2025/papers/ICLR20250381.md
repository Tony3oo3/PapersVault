## Problem

Transformer-based detectors like DETR rely on attention modules that introduce dynamic memory access, making them poorly supported on many AI chips, while pure ConvNets offer static memory access and deployment friendliness. However, no prior work has explored building a Transformer-style decoder with pure convolutions to achieve DETR's query-based, end-to-end, NMS-free detection paradigm. This paper asks whether a fully convolutional architecture can replicate the favorable properties of DETR's encoder-decoder design.
![Teaser figure](../imgs/ICLR20250381/cropped_page1_idx0.webp)

## Input / Output

For detection, the model takes an RGB image (shorter side resized to 480–800 px, longer side capped at 1333 px) and produces a fixed set of 100 bounding boxes with class labels via bipartite matching, requiring no NMS post-processing. For the segmentation extension (DECO-TinySAM), the input is an RGB image plus a box prompt, and the output is a segmentation mask. A notable design choice is that the 1D object queries (N×d) are reshaped into a 2D spatial grid (e.g., 10×10 for N=100) so that standard 2D convolutions can operate on them, and in the segmentation variant the 1D prompt tokens are instead repeated into 2D features since they cannot be meaningfully reshaped.

## Method

The core contribution is InterConv, a mechanism that replaces self-attention and cross-attention in the DETR decoder with pure convolutions. The Self-InterConv (SIM) reshapes N object queries into a 2D grid and applies stacked depthwise (up to 9×9 kernel) and 1×1 convolutions to model inter-query interactions. The Cross-InterConv (CIM) upsamples the 2D query grid to match the encoder feature map resolution, fuses it with encoder embeddings via element-wise addition, applies a large-kernel depthwise convolution to capture spatial context, passes through an FFN, and then uses adaptive max-pooling to downsample back to the query grid size. The DECO encoder uses ConvNeXt blocks (7×7 dwconv + LayerNorm + 1×1 conv + GELU + 1×1 conv) and requires no positional encodings since convolutions are permutation-variant. The DECO+ variant adds a cross-scale feature-fusion module borrowed from RT-DETR to incorporate multi-scale features, and the entire pipeline is trained with the same DETR bipartite matching loss, achieving 47.8% AP at 34 FPS with ResNet-50 on COCO.

## Results

On COCO 2017 val, DECO+ with ResNet-50 backbone achieves 47.8% AP at 34 FPS (69 GFLOPs), and with ConvNeXt-B backbone reaches 50.6% AP at 20 FPS (159 GFLOPs). The lightweight ResNet-18 variant achieves 40.5% AP at 66 FPS (32 GFLOPs), making it one of the fastest end-to-end detectors. For the segment anything task, DECO-TinySAM achieves 41.4% COCO AP with 29 ms mobile latency, compared to 41.9% AP and 34 ms for the TinySAM baseline.

## Baselines & Comparisons

DECO+ with R50 (47.8% AP, 34 FPS) substantially outperforms the original DETR R50 (39.5% AP, 28 FPS) by 8.3% AP while also running 6 FPS faster, and beats Deformable-DETR (43.8% AP, 16 FPS) by 4.0% AP at more than 2× the speed. Against ConvNet-based end-to-end detectors, DECO+ R50 surpasses Sparse R-CNN (42.8% AP, 23 FPS) by 5.0% AP and DeFCN (41.4% AP, 19 FPS) by 6.4% AP, both with higher throughput. At the top of the accuracy-latency trade-off, DECO+ with ConvNeXt-B (50.6% AP, 20 FPS) matches Focus-DETR (50.4% AP, 20 FPS) and approaches DINO-4scale (50.9% AP, 12 FPS) while running nearly 2× faster. In the real-time regime, DECO+ R18 (40.5% AP, 66 FPS) is slightly below the modified RT-DETR R18 (41.7% AP, 60 FPS) in AP but runs 6 FPS faster with fewer FLOPs (32 vs. 40). For the segment anything task, DECO-TinySAM achieves 41.4% COCO AP at 29 ms mobile latency versus TinySAM's 41.9% AP at 34 ms, a near-tie in accuracy with ~15% lower latency.

## Relation to Prior Work

This paper sits at the intersection of two recent trends: (1) the DETR family of query-based end-to-end detectors that eliminate NMS via set prediction, and (2) the ConvNeXt/MetaFormer line of work showing that properly designed ConvNets can match transformer encoders. The key conceptual departure is replacing both the self-attention (query-to-query interaction) and cross-attention (query-to-image interaction) in the DETR decoder with pure convolutional operations (InterConv), while retaining the query-based prediction paradigm and bipartite matching loss. The multi-scale fusion module is borrowed from RT-DETR, and the segmentation extension repurposes the InterConv decoder into TinySAM's mask decoder.

## Why It Matters / Open Questions

The practical motivation is strong: attention layers introduce dynamic memory access that is poorly supported on many AI chips, whereas convolutions have static memory access, making DECO significantly more deployment-friendly. The paper demonstrates that this architectural simplification costs only a modest amount of accuracy (47.8% AP vs. 50.9% for DINO-4scale with R50) while roughly doubling inference speed. Open questions include whether ConvNet-specific improvements (deformable convolution, larger kernels, or query denoising analogues) can close the remaining gap with top DETR variants, and whether the InterConv mechanism generalizes beyond detection and segmentation to other encoder-decoder tasks.

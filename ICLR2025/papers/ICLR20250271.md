## Problem

While GP kernel parameters are routinely interpreted in applications (e.g., identifying spatially variable genes, decomposing CO₂ trends), it is unclear which parameters are actually identifiable for widely used kernels like squared exponential, periodic, and rational quadratic, especially in combinations. Existing identifiability tools such as the integral test require spectral densities with polynomial decay, a condition violated by these infinitely differentiable kernels, leaving a theoretical gap for the most common kernels in machine learning and time-series analysis.

## Input / Output

The theoretical framework takes a parametric family of stationary kernels K_θ (each holomorphic on some ball around 0 in C^p) and produces the microergodic function h(θ), which is the maximal identifiable function of the parameters. The empirical component takes GP observations at n design points in a fixed domain [0,T]^p with additive Gaussian noise and produces MLE estimates of all kernel parameters. A key structural constraint is that the kernel must be holomorphic near zero (stronger than C^∞), and the domain is fixed (infill asymptotics), so identifiability is determined by whether two parameter values induce equivalent or orthogonal GP measures.

## Method

The core result (Theorem 3.4) establishes that two holomorphic stationary kernels K₁ and K₂ induce equivalent GP measures if and only if (1) their continuous spectral components are identical pointwise, and (2) their discrete spectral components share the same support with square-summable relative differences. This decomposes the identifiability problem into two independent subproblems via Theorem 3.5: determine when continuous components coincide (a functional-identity question) and when discrete measures are equivalent (a support-and-decay question). The proof hinges on showing that holomorphicity near 0 implies the entire process on R^p is recoverable from observations on any bounded interval (Lemma B.2), reducing the problem to equivalence on R^p, where the Feldman–Hajek theorem and Bochner's representation yield the spectral conditions. Applied to the 11-parameter Mauna Loa CO₂ kernel, the framework proves all parameters are identifiable under the mild constraint that the noise length-scale is smaller than the trend length-scale, and extends to products and sums of cosine and periodic kernels.

## Results

The paper's central theoretical result (Theorem 3.2) proves that all 11 parameters in the Mauna Loa CO₂ kernel (Equation 2) are identifiable, provided the noise length-scale θ₁₀ < trend length-scale θ₂. Table 2 establishes that for individual kernels (SE, Per, Damped Per, RQ), all parameters are microergodic (i.e., fully identifiable), in contrast to the Matérn kernel where only σ²ℓ⁻²ᵛ is identifiable for p ≤ 3. Simulation studies with n up to 5000 (individual kernels) and n up to 500 (combined kernel) confirm that MLEs of all identifiable parameters converge to their true values, with the sole exception of σ² in the cosine kernel, which is provably non-identifiable.

## Baselines & Comparisons

This paper does not benchmark against competing estimation methods; its contribution is theoretical rather than algorithmic. The key contrast is with the integral test (Stein, 1999), the standard tool for GP identifiability, which requires spectral densities to decay polynomially (f(ω)‖ω‖ᵅ ≍ 1) and therefore fails entirely for SE, Per, and RQ kernels whose spectral densities decay super-exponentially. Prior work by Zhang (2004) showed non-identifiability of σ² and ℓ for the Matérn kernel in dimensions p ≤ 3, but the present paper demonstrates that the holomorphic kernels (SE, Per, RQ) are fully identifiable in all dimensions, via a new framework based on spectral measure decomposition (Theorem 3.4) and holomorphic extension arguments. The simulation section empirically validates the theory: MLEs for all identifiable parameters in the 11-parameter CO₂ kernel converge with increasing n, while the non-identifiable σ² in the cosine kernel provably fails to converge, consistent with the theoretical prediction.

## Relation to Prior Work

This paper extends the GP parameter identifiability literature, which has been dominated by Matérn kernel analysis using Stein's integral test (Stein, 1999; Zhang, 2004; Anderes, 2010; Kaufman and Shaby, 2013; Li, 2022). The integral test requires polynomial spectral decay, a condition violated by holomorphic kernels like SE, Per, and RQ whose spectral densities decay super-exponentially. The authors develop a new framework based on holomorphicity and the continuous/discrete spectral measure decomposition (Lemma 3.3, Theorem 3.4) that bypasses the integral test entirely, enabling identifiability analysis for the complex kernel combinations popularized in Rasmussen and Williams (2006) and the sklearn.gaussian_process tutorial, for which no prior rigorous proof existed.

## Why It Matters / Open Questions

This work provides the first rigorous theoretical justification for interpreting kernel parameters in widely-used GP models (SE, periodic, rational quadratic, and their combinations), directly supporting the parameter interpretations in the influential Rasmussen and Williams (2006) book and the sklearn tutorial. The general pipeline (Theorem 3.5) gives practitioners a systematic method to determine identifiability for newly constructed kernels, which is critical for downstream applications like spatial transcriptomics where estimated parameters drive biological conclusions. Key open questions remain: MLE consistency for these kernels is still unresolved, the framework does not extend to non-stationary kernels or infinitely differentiable but non-holomorphic kernels, and the p=4 Matérn case remains open.

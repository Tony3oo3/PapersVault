## Problem

Existing dataset ownership verification (DOV) methods, particularly backdoor watermarking, either degrade model performance, require white-box or logit-level access, or lack theoretical guarantees against false positives. Their statistical tests rely on ungrounded assumptions about benign model behavior (e.g., that confidence scores should not change beyond a threshold), making the detection unreliable. This paper seeks a DOV method that is harmless to model accuracy, detectable with only top-k black-box predictions, and backed by a rigorous statistical certificate.

## Input / Output

The signing phase takes an RGB image dataset (ImageNet1k, 224×224) and a small signing subset (0.1% of samples), producing a modified dataset where each signed image carries an L∞-bounded perturbation (ε=16/255) crafted via gradient matching. The detection phase takes only the top-k (k=10) class predictions of a suspicious model on K=10 secret out-of-distribution key images (random pixel patterns with uniformly random labels) and outputs a p-value from a binomial test, requiring no access to logits, weights, or confidence scores.

## Method

Data taggants repurpose clean-label targeted data poisoning (gradient matching à la Witches' Brew) for DOV: the signing set is partitioned into K groups, each group's images are perturbed so that their averaged training gradient aligns with the gradient of a corresponding OOD key (random pixel pattern + random label), computed through differentiable data augmentations resampled R times per step. Because keys are out-of-distribution, enforcing a specific prediction on them does not introduce errors on in-distribution data, unlike backdoor triggers. A differentiable LPIPS perceptual loss is added to the optimization objective to make perturbations visually imperceptible, and multiple random restarts per key select the best taggant. Detection exploits the fact that under H₀ (model not trained on the signed data), top-k accuracy on random-label keys follows Bin(K, k/|Y|), enabling a standard binomial significance test with a provably controlled false positive rate—no threshold calibration or pairwise comparison needed.

## Results

On ImageNet-1k with DeIT-small and the Three Augment recipe at a 0.1% signing budget, data taggants achieve a perfect true positive rate (TPR = 1.0) with zero false positive rate (FPR = 0.0) and a detection confidence of log₁₀p = −59.6, while maintaining validation accuracy of 64.2% ± 0.6 — on par with clean training (64.2% ± 0.4). The method requires only top-10 predictions (k=10) from the suspicious model, with a theoretical FPR of 0.4% at threshold τ = 0.1. Across 4 independent runs combined via Fisher's method, the p-value remains below 10⁻⁵⁹, providing a rigorous statistical certificate of dataset usage.

## Baselines & Comparisons

Both backdoor watermarking baselines — Sleeper Agent (clean-label) and BadNets (poisoned-label) — completely fail in this practical setting, yielding 0% TPR and 0% FPR, meaning they neither detect the protected model nor produce false alarms; the paper attributes this to the backdoor trigger being washed out by state-of-the-art data augmentations (mixup, cutmix). Data isotopes achieve a partial detection rate of 53% TPR but at the cost of a prohibitively high 20% FPR and a 1.2-point drop in validation accuracy (63.0% vs. 64.2%), making them impractical for real-world use. Data taggants dominate all three baselines: it matches clean-training accuracy, achieves perfect detection with zero false positives, and provides a theoretically grounded binomial-test p-value (log₁₀p = −59.6) rather than the ad-hoc pairwise t-test used by prior DOV methods. The paper further shows that using random out-of-distribution keys (rather than test-set images) yields substantially better detection confidence at the same budget (log₁₀p = −59.6 vs. −10.4 for test-data keys at B = 0.1%), validating the core design choice.

## Relation to Prior Work

This paper repurposes clean-label targeted data poisoning (specifically gradient matching from Witches' Brew, Geiping et al. 2020) for dataset ownership verification, departing from the dominant backdoor watermarking paradigm (Li et al. 2020a/2022/2023, Tang et al. 2023, Guo et al. 2023) that modifies model behavior on in-distribution samples via triggers. The key conceptual shift is using out-of-distribution random patterns as keys with randomly assigned labels, which enables a binomial significance test with exact characterization of the null hypothesis—something prior DOV methods (which rely on pair-wise t-tests or Wilcoxon tests on confidence score differences) lack. It also builds on the Radioactive Data framework (Sablayrolles et al. 2020) for the signing/detection application scenario but replaces white-box weight access with black-box top-k prediction queries.

## Why It Matters / Open Questions

The paper provides the first DOV method with a theoretically grounded false-positive guarantee (binomial test) that requires only top-k black-box predictions, making it applicable to API-restricted models. A notable practical finding is that backdoor watermarking—the most studied DOV approach—achieves 0% detection rate under state-of-the-art training recipes with mixup/cutmix, suggesting the field's dominant technique may be fundamentally incompatible with modern augmentation pipelines. Open questions include whether cross-architecture transferability can be improved (current results are mixed, especially for DeIT-tiny to ResNet), whether Bob can locate taggants via clustering-based visual inspection at scale, and whether the negligible accuracy degradation can be eliminated entirely.

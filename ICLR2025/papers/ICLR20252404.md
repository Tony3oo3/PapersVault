## Problem

Prior work on machine learning with shuffled DP has focused on iterative settings (distributed or federated training over multiple rounds), which is incompatible with one-shot data collection from a pool of uncommitted end users who each hold a single private training point and may opt in or out. This paper asks whether shuffled DP can achieve central-DP-level accuracy for learning a classifier from such distributed data, bridging the gap between the strong privacy of local DP and the accuracy of central DP in a practical data-collection scenario.

## Input / Output

Each of n users holds a single private data point (x, c) where x ∈ R^d is a pretrained embedding (768-dim SentenceBERT for text, 6144-dim SimCLR for CIFAR-10 images, all unit-normalized) and c ∈ [m] is a class label; the protocol requires knowing n in advance. The output is a set of private KDE function descriptions {K̃_c} that can be queried on an unbounded number of test points without additional privacy loss, a class label per test point via argmax over class densities, and for class decoding, top-scoring words from a public 400K-word GloVe vocabulary ranked by each class's KDE function.

## Method

The core technical contribution is a reduction from shuffled DP kernel density estimation to binary summation (bitsum) protocols, using locality-sensitive quantization (LSQ) to decompose the kernel into Q coordinates that are discretized to ±R via randomized Bernoulli rounding at each user. The protocol (Algorithm 1) runs IQ independent instances of a shuffled DP bitsum protocol (RR, 3NB, or Pure), and the analyzer reconstructs a private KDE function from the bitsum estimates, achieving a supRMSE that essentially matches central DP. For classification, the learner first uses a local DP randomized-response round to privately obtain per-class user counts (since shuffled DP requires knowing n), then runs the shuffled DP KDE protocol per class, and classifies test points via the highest-density-class (HDC) rule. The Gaussian kernel is handled via random Fourier features (exact LSQ with Q=S=1), while the inner-product kernel uses random sign projections (Q=1, S=1, R=√d), yielding different privacy-accuracy-communication trade-offs across the three bitsum protocols.

## Results

On DBPedia-14 (14-class topic classification), the best shuffled DP configuration (IP kernel + 3NB bitsum) achieves 93.1% accuracy at ε=7 with no label privacy (ε_lbl=∞), and retains 93.1% at ε_lbl=5. On AG News (4-class), IP+3NB reaches 85.9% at ε=7, ε_lbl=5. On CIFAR-10 (10-class image classification), the Gaussian kernel + 3NB outperforms IP, achieving 72.8% at ε=4.7, ε_lbl=5, while IP+3NB only reaches 37.8%. The 3NB bitsum protocol consistently yields the highest accuracy across all datasets, followed by RR and Pure, with central DP closely matching non-DP accuracy even at small ε values.

## Baselines & Comparisons

The paper compares shuffled DP KDE against three baselines: central DP, no-privacy (exact summation), and local DP. Central DP closely matches non-DP accuracy even at small ε, corroborating findings from Backurs et al. (2024). Shuffled DP with the 3NB bitsum protocol achieves accuracy within a few percentage points of central DP on text datasets (e.g., 93.1% vs. ~93% non-DP on DBPedia-14 with IP kernel), while the RR protocol shows a larger gap (63.0% vs. 93.1% at ε=7, ε_lbl=5). Against local DP, shuffled DP attains considerably higher downstream accuracy, as the shuffling amplifies privacy and reduces required noise. A key finding is that the Gaussian kernel, despite having lower non-DP baseline accuracy than IP, is more resilient to the errors introduced by shuffled DP and often achieves better overall accuracy under tighter privacy budgets or less accurate bitsum protocols (RR, Pure). On CIFAR-10, this resilience is most pronounced: Gaussian+3NB reaches 72.8% while IP+3NB only achieves 37.8% at ε=4.7, ε_lbl=5, highlighting that the shuffled DP setting may require different, more error-resilient mechanisms than central DP.

## Relation to Prior Work

This paper adapts the locality-sensitive quantization (LSQ) framework for private KDE from the central DP setting (Wagner et al., 2023) to the shuffled DP model, reducing the KDE problem to binary summation (bitsum) subroutines. It departs from prior shuffled DP machine learning work, which has focused on iterative distributed/federated training or bandit settings with committed parties communicating over multiple rounds, by addressing the 'one-shot' data collection scenario from an uncommitted pool of end users. The protocol composes well-studied shuffled DP bitsum protocols (RR, 3NB, Pure) as black-box subroutines, and the classifier is conceptually a smoothed kNN via kernel density estimation, generalizing the nearest-class-center classifier of Papyan et al. (2020) and the central DP similarity-based classifier of Backurs et al. (2024).

## Why It Matters / Open Questions

The paper fills a practical gap in privacy-preserving ML by providing a theoretically grounded and experimentally validated protocol for learning from distributed end-user data under shuffled DP, a setting that prior work on iterative distributed training does not cover. The finding that the Gaussian kernel can outperform the inner-product kernel under shuffled DP (despite being weaker without privacy) highlights a non-trivial practical trade-off: error resilience matters more than baseline accuracy when privacy noise is present. Open questions include extending to continuous/longitudinal monitoring of user data, reducing the communication overhead of pure-DP bitsum protocols, and integrating shuffled DP KDE into more complex ML pipelines beyond classification.

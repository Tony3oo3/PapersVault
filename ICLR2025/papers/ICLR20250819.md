## Problem

Existing private ANN search schemes like Tiptoe suffer from a fundamental tradeoff: they use clustering-based search that caps quality at ~40% of non-private baselines, while also requiring linear computation per query on the server. This makes them impractical for large-scale applications where both search accuracy and sublinear latency are needed.
![Teaser figure](../imgs/ICLR20250819/cropped_page0_idx0.webp)

## Input / Output

The client submits a query vector q ∈ R^d and receives K indices of approximate nearest neighbors from a public, server-stored database of n vectors. The protocol has a one-time preprocessing phase where the client downloads the entire index structure in streaming fashion (≈60 GB for 100M vectors) and stores O~(√n) local state, followed by an online query phase with multiple adaptive rounds. The server learns negligible information about q under a simulation-based semi-honest security definition.

## Method

PACMANN offloads the iterative graph traversal to the client, which privately retrieves subgraph information (neighbor lists and vectors) from the server using the Piano client-preprocessing PIR scheme, achieving O~(√n) per-query cost after O(n) preprocessing. The graph is a customized regular C-out-degree directed graph built with the SNG diversity heuristic and balanced via probabilistic edge sampling, ensuring no information leaks from variable neighbor counts. Three key optimizations reduce practical cost by ~70%: beam search (m parallel paths) to cut total hops, fast starting (scanning O~(√n) preprocessed vertices to find good entry points), and batched PIR via partial batch retrieval that issues mC parallel queries in a single round by partitioning the database into B sub-databases. The result achieves 90% of NGT's non-private search quality with sublinear latency, outperforming Tiptoe by 2.5× in recall@10 on SIFT-100M.

## Results

On MS-MARCO (3.2M documents, 192-dim), PACMANN achieves a 63% top-1 success rate (MRR@100), compared to 29% for the clustering-based Tiptoe algorithm — a 2.1× improvement. On SIFT-100M (100M vectors, 128-dim), PACMANN achieves 2.5× better recall@10 than Tiptoe while reaching 90% of the non-private NGT algorithm's quality. At 100M scale, PACMANN achieves 1.6s query latency in the LAN setting (5ms RTT) versus ≥4s for Tiptoe's linear-computation baseline (a 60% reduction), and 3.1s in the WAN setting (50ms RTT, a 22% reduction).

## Baselines & Comparisons

Against Tiptoe (simulated via a linear-computation latency lower bound and a clustering-based quality upper bound), PACMANN wins decisively on both axes: it achieves 2.1× higher top-1 success rate on MS-MARCO (63% vs. 29%) and 2.5× higher recall@10 on SIFT-100M, while also reducing query latency by up to 60% in the LAN setting and 22% in the WAN setting at 100M scale. Against the non-private NGT algorithm (used as a quality upper bound), PACMANN reaches approximately 90% of NGT's search quality in both MRR and recall, demonstrating that the privacy overhead costs only ~10% in search accuracy. The paper notes that Tiptoe's actual quality would be even lower than the simulated clustering baseline because the original Tiptoe uses 4-bit quantization, while the evaluation here uses full 32-bit precision.

## Relation to Prior Work

PACMANN departs fundamentally from prior private ANN schemes (Tiptoe, Wally, Preco) that run encrypted search on the server using homomorphic encryption over clustering or LSH-based algorithms. Instead, it offloads the iterative graph traversal to the client and uses client-preprocessing PIR (specifically Piano) to privately fetch subgraph information hop-by-hop, drawing on the graph-based ANN lineage (NGT, HNSW, DiskANN) for search quality. The graph construction adapts the SNG heuristic and enforces regular out-degree to prevent information leakage, while the batched PIR mechanism borrows the partial batch retrieval technique from Servan-Schreiber et al. (2022).

## Why It Matters / Open Questions

PACMANN demonstrates that private ANN search need not be stuck at ~40% of non-private quality (as with Tiptoe's clustering approach) by showing that graph-based traversal with PIR can reach 90% of state-of-the-art non-private ANN while also achieving sublinear computation cost. Key limitations remain: the client must stream-download the entire index during preprocessing (~60 GB for 100M vectors), the scheme does not support dynamic database updates, and it assumes a public database with a semi-honest server. Open questions include extending to malicious adversaries, reducing preprocessing communication, and adapting to network-constrained or dynamic-update settings.

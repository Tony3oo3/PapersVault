## Problem

Understanding how neural activity relates to complex, high-dimensional behavior (e.g., social interactions, self-initiated decisions) is difficult because existing multimodal models either rely on simple behavioral labels or suffer from information leakage, where features from one modality contaminate the latent representations of another. This leakage makes it impossible to determine which neural features are genuinely shared with behavior versus which are modality-specific, undermining interpretability of brain-behavior alignment.

## Input / Output

The model takes simultaneously recorded neural activity (widefield calcium imaging across the dorsal cortex, preprocessed via LocaNMF) and behavioral data (raw video frames or DeepLabCut keypoint positions) as input, with a sliding window of w frames stacked to capture temporal structure. It produces modality-specific shared latent subspaces (aligned across modalities via CS divergence), modality-specific private latent subspaces, and reconstructed inputs. A key practical property is that at inference time, only one modality's data is needed to generate meaningful latents for that modality, since the shared and private subspaces are architecturally decoupled. The framework extends to three or more modalities (e.g., keypoint positions + behavioral video + neural activity simultaneously).

## Method

Shared-AE is a dual-encoder autoencoder where each modality is encoded independently (2D ResNet-18 for images, 1D ResNet-18 for time series), then the encoded representation is split via linear projections into a shared subspace and a private subspace. The core novelty is a Cauchy-Schwarz (CS) divergence regularization: CS divergence between the shared latents of different modalities is minimized to encourage alignment, while the inverse CS divergence between shared and private latents within the same modality (and between private latents across modalities) is maximized to enforce distinctiveness. The CS divergence is computed in closed form using Parzen window (Gaussian kernel) density estimates, with the cross-distribution integral simplified via the Gaussian convolution theorem. Unlike VAEs that regularize against a fixed Gaussian prior via KL divergence, or prior CS-AE work that fits latents to a predefined prior, Shared-AE minimizes the CS distance between two data-learned distributions from different modalities, yielding more flexible shared representations. The total loss combines per-modality MSE reconstruction with weighted CS and inverse-CS terms, trained with Adam (lr=1e-4) for 100 epochs.

## Results

On the 2AFC head-fixed mouse dataset, Shared-AE achieves 0.41±0.05 R² for behavioral decoding using shared neural latents, matching MM-VAE (0.41±0.07) and outperforming PSID (0.20±0.03), DPAD (0.27±0.02), and MM-GP-VAE (0.36±0.01). On the critical unpaired evaluation (where one modality is shuffled at test time), Shared-AE maintains 0.41±0.05 R² while MM-GP-VAE collapses to 0.006±0.00 and MM-VAE drops to 0.22±0.03, confirming no information leakage between modalities. On the simulated 3DShapes dataset, shared latents decode shared features (scale, orientation) at 0.980±0.09 accuracy while private latents retain modality-specific features (shape: 0.768±0.03 for image; temporally-structured noise: 0.732±0.012 for time series).

## Baselines & Comparisons

Shared-AE outperforms all five baselines on the unpaired task, which is the key differentiator: when one modality is shuffled at inference, Shared-AE retains 0.41±0.05 R² while MM-GP-VAE (Gondur et al., 2024) drops to 0.006±0.00, MM-VAE (Shi et al., 2019) to 0.22±0.03, and the Joint Encoding Model (Singh Alvarado et al., 2021) to 0.20±0.02. On the paired task, Shared-AE (0.41±0.05) ties MM-VAE (0.41±0.07) but clearly beats PSID (Sani et al., 2021; 0.20±0.03), DPAD (Sani et al., 2024; 0.27±0.02), and MM-GP-VAE (0.36±0.01). PSID and DPAD do not produce separate shared/private subspaces, making direct subspace-level comparison impossible (marked NA). MM-GP-VAE is the only other baseline with a private subspace, achieving 0.37±0.00 on private latents versus Shared-AE's 0.22±0.03, but this comes at the cost of severe information leakage on unpaired data. On the simulated 3DShapes dataset, Shared-AE also outperforms MM-VAE and the Joint Encoding Model on unpaired decoding of shared features (0.980 vs. 0.52 and 0.58 respectively), while baseline models show a dramatic accuracy drop indicating modality contamination during training.

## Relation to Prior Work

Shared-AE builds on the line of multimodal variational autoencoders for neural-behavioral data (MM-VAE, MM-GP-VAE, PSID, DPAD, Joint Encoding Model) but departs from them by explicitly partitioning each modality's latent space into shared and private subspaces rather than using a single fused latent. It also repurposes the Cauchy-Schwarz divergence from prior CS-regularized autoencoders (Tran et al. 2021, Yi et al. 2022), which used CS-divergence to fit latents to a predefined Gaussian prior, instead applying it to minimize the distance between two *learned* modality-specific distributions. This shift from prior-matching to inter-modality alignment is the core conceptual departure, combined with the use of inverse CS-divergence to enforce orthogonality between shared and private subspaces within each modality.

## Why It Matters / Open Questions

The explicit shared/private separation per modality addresses a practical interpretability problem in neuroscience: when a single fused latent is used, it is unclear which modality drives a given neural-behavioral alignment, and inference fails if one modality is missing. Shared-AE's ability to handle raw image data (not just keypoints) and extend to three or more modalities broadens applicability to naturalistic behavioral paradigms. Key limitations include the requirement for equal latent subspace dimensions across modalities, uncertainty about cross-subject generalizability, and sensitivity to multiple hyperparameters (α, β, γ, δ, kernel size σ). Open questions include whether the framework scales to larger cortical recordings, whether pre-trained encoders can replace the ResNet-18 backbones, and whether the CS-divergence approach generalizes to non-Gaussian latent structures.

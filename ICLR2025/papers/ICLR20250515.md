## Problem

Existing neural subgraph matching systems (IsoNet, GMN, NeuroMatch, etc.) each make specific design choices across multiple axes—relevance distance, interaction stage, interaction structure, non-linearity, and granularity—without systematically studying how these choices interact. This leaves the design space largely uncharted, with prior work occupying only isolated patches and leaving open questions about which combinations are optimal and why certain architectures outperform others.
![Teaser figure](../imgs/ICLR20250515/cropped_page2_idx0.webp)

## Input / Output

The method takes a query graph and a set of corpus graphs (from TUDatasets, with node features uniformly set to [1] for feature-agnostic structural matching), padding both to equal node and edge counts. It produces an asymmetric relevance distance score per query-corpus pair, which is used to rank all corpus graphs in ascending order of distance; performance is measured by mean average precision (MAP) over the resulting ranked lists.

## Method

The paper introduces a unified framework that decomposes subgraph matching models into five orthogonal design axes: relevance distance (set alignment via EMD vs. aggregated-hinge/MLP/NTN), interaction stage (early cross-graph message passing vs. late independent encoding), interaction structure (injective doubly-stochastic alignment via Sinkhorn iterations vs. non-injective attention), interaction non-linearity (neural LRL, dot product, or hinge), and interaction granularity (node vs. edge embeddings). The best-performing configuration (Our-Early-Best) combines early interaction, set alignment, injective structure, hinge non-linearity, and edge granularity, achieving state-of-the-art MAP across all ten datasets. Training uses a supervised ranking loss with margin over positive (supergraph) and negative corpus pairs. The key finding is that shifting from late to early interaction can compensate for weaker relevance distances, and that the combination of all five optimal choices yields a model that surpasses all existing methods by a significant margin.

## Results

The paper's best early-interaction model (Our-Early-Best: set alignment + injective Sinkhorn + hinge non-linearity + edge granularity) achieves MAP of 0.817, 0.837, 0.887, 0.677, and 0.71 on AIDS, Mutag, PTC-FM, NCI, and MOLT respectively, winning on all five main datasets. The best late-interaction variant (Our-Late-Best) achieves 0.712, 0.721, 0.793, 0.643, and 0.662, placing second on four of five datasets. These results substantially surpass the previous state-of-the-art IsoNet (0.704, 0.733, 0.782, 0.615, 0.649) by 6–13 MAP points depending on dataset size, and outperform the early-interaction baseline GMN-Match (0.609–0.693) by 12–20 points.

## Baselines & Comparisons

Our-Early-Best (set alignment + injective + hinge + edge + early interaction) outperforms all ten baselines on every dataset, with the largest margins over SimGNN (+49 MAP on AIDS), GraphSim (+64 on AIDS), and H2MN (+55 on AIDS). Against the closest prior SOTA, IsoNet (late interaction, set alignment, injective, neural, edge), Our-Early-Best gains +11.3 MAP on AIDS, +10.4 on Mutag, +10.5 on FM, +6.2 on NCI, and +6.1 on MOLT. Our-Late-Best (same design but late interaction) also beats IsoNet on all five datasets by 0.8–7.8 MAP points, confirming that hinge non-linearity is a drop-in improvement over IsoNet's neural non-linearity even without early interaction. GMN-Match (early interaction, non-injective, dot-product, node, aggregated-hinge) is outperformed by Our-Early-Best by 20.8 MAP on AIDS and 14.4 on MOLT, demonstrating that upgrading GMN's design choices (injective structure, hinge, set alignment, edge granularity) is far more impactful than early interaction alone. Among late-interaction baselines, ERIC and EGSC (both using aggregated NTN/MLP distances) trail Our-Late-Best by 13–20 MAP points, reinforcing that set-level alignment is critical for subgraph matching.

## Relation to Prior Work

This paper unifies the design choices scattered across prior subgraph matching systems (IsoNet, GMN, NeuroMatch, SimGNN, ERIC, GOTSim, H2MN) into a five-axis design space: relevance distance (set alignment vs. aggregated), interaction stage (early vs. late), interaction structure (injective vs. non-injective), interaction non-linearity (neural, dot-product, hinge), and interaction granularity (node vs. edge). Rather than proposing a fundamentally new architecture, it systematically explores previously uncharted combinations of these axes, revealing that existing methods occupy only a few isolated patches. The paper's best model (Our-Early-Best) combines early interaction with set alignment, injective Sinkhorn-based alignment, hinge non-linearity, and edge granularity—a combination no prior system had attempted.

## Why It Matters / Open Questions

The paper resolves a key paradox in the field: why late-interaction IsoNet outperformed early-interaction GMN despite the general expectation that early interaction is stronger. The answer—that IsoNet's advantage came from set alignment, injective structure, hinge non-linearity, and edge granularity rather than the interaction stage—provides actionable design guidelines for future subgraph matching systems. Open questions remain around 3D molecular topology, robustness to noisy or adversarial perturbations, and out-of-distribution generalization, which the authors acknowledge but do not address. The systematic ablation across 10 datasets with careful seed selection makes the design principles broadly applicable to practitioners building graph retrieval systems.

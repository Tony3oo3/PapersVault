## Problem

Prompt tuning underperforms on data-scarce modalities like vision because there are insufficient training samples to fully optimize prompts. While prompt transfer has been validated within NLP tasks, whether prompts pretrained on text can be transferred to vision tasks—and how to estimate which source prompt transfers best across modalities—remains unexplored, as existing transferability metrics assume negligible modality gap.
![Teaser figure](../imgs/ICLR20251770/cropped_page2_idx0.webp)

## Input / Output

The method takes a target vision task (1000 images at 224×224, processed into 196 patch embeddings of dimension 768 by ViT-base) and a source prompt (100 vectors of dimension 768, pretrained on one of 13 NLP tasks using RoBERTa-base). It produces class labels for the target task and, for transferability estimation, a combined score per source prompt that decomposes the source–target gap into a modality gap (MMD between the source prompt and target patch embeddings) and a task gap (negative cosine similarity between the universally-projected source prompt and the target prompt).

## Method

The paper introduces three cross-modality transfer settings: (1) Frozen Prompt Transfer, which prepends the frozen NLP prompt directly to ViT patch embeddings and trains only a linear head; (2) Projection Transfer, which inserts a learnable linear projector between the frozen source prompt and the patch embeddings to adapt linguistic knowledge to the vision space; and (3) Attention Transfer, which uses a Prompt Concentrator—an attention block with a learnable query of length l_s, key projection W_k, and value projection W_v—to compress the source prompt from length 100 to l_s, then concatenates the concentrated source prompt with randomly initialized target prompts of length 100−l_s. For transferability estimation, the paper decomposes the source–target gap into a modality gap measured by MMD between the source prompt and target image patch embeddings, and a task gap measured by cosine similarity after projecting all source prompts into the target prompt space via a universal linear projector trained on the Euclidean distance to the target prompt. The combined transferability score T(s,t) = −(G_M + G_T) enables autonomous selection of the best source prompt without exhaustive trial-and-error, outperforming in-modality baselines (Avg Cos, ON) on Kendall's rank correlation across 19 VTAB-1K tasks.

## Results

On the 19 VTAB-1K image classification tasks, Projection Transfer (best source prompt) improves over vanilla VPT by an average of ~5% relative gain (P/V), with the largest boosts on structured tasks (e.g., +37.2% on dSprites/ori, +25.2% on Clevr/count) and specialized tasks (e.g., +8.3% on Resisc45). Attention Transfer achieves a mean accuracy of 84.12% on Specialized tasks and 53.47% on Structured tasks, outperforming the SPT benchmark (83.65% and 52.86% respectively), while being slightly below SPT on Natural tasks (80.55% vs. 81.44%). For prompt transferability estimation, the proposed combined modality-and-task-gap method (G_M & G_T) achieves the highest mean Kendall's coefficient (72.54) across all 19 target tasks, substantially outperforming in-modality baselines Avg Cos (−10.86) and ON (14.17).

## Baselines & Comparisons

Against vanilla VPT (Jia et al., 2022), Projection Transfer with the best source prompt achieves higher accuracy on 64% of the 247 source-target pairs, with the largest relative gains on tasks that already benefit substantially from prompt tuning (e.g., SVHN: 82.6% vs. 71.3%; Clevr/count: 62.6% vs. 50.0%). Against linear probing (Oord et al., 2018), frozen prompt transfer (no adaptation) still outperforms vanilla linear probing on 31.6% of pairs, confirming that NLP-pretrained prompts carry transferable knowledge even without any target-task training. Against the newest prompt-based benchmark SPT (Wang et al., 2024), Attention Transfer matches or exceeds SPT on Specialized (84.12% vs. 83.65%) and Structured (53.47% vs. 52.86%) task groups, while trailing slightly on Natural tasks (80.55% vs. 81.44%), despite operating under a more constrained setup where the source prompt must overcome modality and task gaps. For transferability estimation, the proposed G_M & G_T method (mean Kendall's τ = 72.54) dramatically outperforms the in-modality baselines: Avg Cos (Vu et al., 2022) yields a mean of −10.86 and ON (Su et al., 2022) yields 14.17, confirming that existing methods fail in cross-modality settings where the modality gap dominates.

## Relation to Prior Work

This paper extends the prompt transfer paradigm from in-modality (NLP→NLP, as in Vu et al. 2022 and Su et al. 2022) to cross-modality (NLP→CV), building directly on Visual Prompt Tuning (Jia et al., 2022) as the target architecture and on the original Prompt Tuning formulation (Lester et al., 2021) for source prompt training. The key conceptual departure is the decomposition of the source-target gap into a modality gap (measured via MMD between source prompts and target image patch embeddings) and a task gap (measured via cosine similarity after a universal linear projection), which prior in-modality methods do not need to consider. The proposed Attention Transfer mechanism with a Prompt Concentrator is positioned as complementary to Self-Prompt Tuning (Wang et al., 2024b), which injects target knowledge via image patch initialization, whereas this work injects source NLP knowledge via a concentrated prompt.

## Why It Matters / Open Questions

This work establishes that cross-modality prompt transfer is feasible and provides a principled framework (modality gap + task gap) for selecting the best source prompt without exhaustive search, which is practically important for data-scarce modalities that cannot afford to train prompts from scratch. However, the practical gains are modest (a few percentage points over vanilla VPT), and the study is limited to base-sized models (RoBERTa-base → ViT-base), a single source language model, and 1000 training samples per target task, leaving open whether the findings generalize to larger models, different architectures, or richer pretraining regimes. The finding that the modality gap dominates over the task gap in cross-modality scenarios is a useful diagnostic insight, but the overall contribution is more exploratory than transformative, serving as a proof-of-concept that opens a research direction rather than delivering a drop-in replacement for existing PETL methods.

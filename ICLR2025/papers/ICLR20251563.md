## Problem

In-context learning performance in decoder-only LLMs is highly sensitive to the order of demonstrations, yet the underlying mechanism behind this sensitivity remains poorly understood. Moreover, finding the optimal demonstration order via exhaustive search has factorial complexity, making it infeasible for practical use. This paper bridges the gap between order sensitivity and LLM internals by uncovering a clustering property in prompt embedding space and leveraging it for efficient demonstration selection.

## Input / Output

The method takes a pool of k_total candidate demonstrations (each an input-output pair) and a query, processed by a decoder-only LLM. It outputs an ordered subset of k demonstrations (k < k_total) that maximizes prediction confidence, along with the LLM's predicted output for the query. The key constraint is that only the first demonstration position is explicitly selected from the pool; the remaining k−1 positions are filled randomly, reducing the candidate set from A_{k_total}^k permutations to just k_total options.

## Method

The paper discovers that last-layer embeddings of prompts sharing the same first (and last) demonstrations form clusters in the embedding space, with first-demonstration clustering being notably stronger. Theoretically, Proposition 4.1 proves that under a causal attention mask, sequences sharing the first token converge to the same point exponentially fast in depth, explaining first-demonstration clustering. Empirically, this is verified via UMAP/t-SNE visualizations, K-Means percentage-frequency analysis showing U-shaped position importance, and partial derivative norms confirming elevated sensitivity at beginning and ending tokens. The practical Cluster-based Search method exploits this by evaluating only k_total prompts (one per possible first demonstration) using either an oracle or entropy-based confidence criterion, reducing time complexity from factorial to linear while maintaining within ~0.3% accuracy of exhaustive search.

## Results

With the entropy-based selection criterion, Cluster-based Search achieves average accuracies of 45.9% (GPT-Neo-2.7B), 64.6% (Phi-2), and 89.6% (Qwen-2.5-14B) across six ICL tasks, matching or slightly exceeding Exhaustive Search (43.9%, 66.6%, 88.3%) with only a 0.3% average absolute gap. The method reduces search time complexity from factorial A(k_total, k) to linear O(k_total), saving 92% to nearly 100% execution time. With the ideal (oracle) criterion, Cluster-based Search loses only 2.4% relative accuracy on average while cutting search time by 91.7%.

## Baselines & Comparisons

The paper compares Cluster-based Search against two baselines: Random Selection (no optimization) and Exhaustive Search (factorial-time enumeration of all permutations). Against Random Selection, Cluster-based Search consistently wins by large margins — e.g., +5.7% average on GPT-Neo-2.7B, +6.3% on Phi-2, and +4.6% on Qwen-2.5-14B — confirming that demonstration ordering matters. Against Exhaustive Search, Cluster-based Search achieves comparable or slightly better average accuracy (45.9% vs 43.9% on GPT-Neo, 89.6% vs 88.3% on Qwen-2.5-14B) while reducing search time from factorial to linear complexity, saving 92–100% execution time. On individual tasks, Cluster-based Search wins on several (e.g., Reverse: 76.3% vs 66.5% on GPT-Neo; SymSen: 82.3% vs 78.0% on Qwen-2.5-14B) but loses on others (e.g., Rep.: 65.0% vs 71.0% on Phi-2), with the average gap being only 0.3% absolute. The ablation (Table 3) further shows that selecting only the first demonstration (O(k_total)) outperforms selecting both first and last (O(k_total²)), reinforcing that first-demonstration clustering is the dominant signal.

## Relation to Prior Work

This paper extends the self-adaptive ICL framework of Wu et al. (2022) by identifying a structural property in prompt embedding space that enables efficient demonstration selection. Its theoretical analysis builds directly on the convergence theorem of Geshkovski et al. (2023) for Transformer dynamics, applying it under causal attention masking to prove that shared first tokens lead to identical convergence points. The work also connects to the attention sink phenomenon (Xiao et al., 2024) and the serial-position effect from cognitive psychology, but is the first to systematically link ICL order sensitivity to the internal mechanics of decoder-only LLMs via embedding-space clustering.

## Why It Matters / Open Questions

The clustering property provides a mechanistic explanation for a long-observed but poorly understood phenomenon (ICL order sensitivity), bridging empirical behavior and architectural design choices (causal mask, positional encoding). The practical Cluster-based Search method reduces demonstration selection from factorial to linear/quadratic complexity with minimal accuracy loss, making self-adaptive ICL feasible at scale. However, the theoretical framework only fully explains first-demonstration clustering; the mechanism behind last-demonstration clustering remains an open question involving a complex interplay between causal structure and positional encoding type. The approach also cannot be applied to black-box models where internal representations are inaccessible.

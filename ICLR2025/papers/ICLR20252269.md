## Problem

Existing black-box prompt-tuning (BBPT) methods for vision-language models require tens of thousands of API queries, making them impractical under real-world budget constraints. The core issue is that zeroth-order gradient estimates suffer from variance that scales with problem dimensionality, causing slow convergence and performance degradation as the number of context tokens increases — a fundamental limitation absent in first-order optimization.
![Teaser figure](../imgs/ICLR20252269/cropped_page1_idx2.webp)

## Input / Output

ZIP takes RGB images paired with text prompts containing learned soft context tokens (8 tokens of 512-dim embeddings in CLIP) and outputs class labels via the frozen CLIP model's cross-entropy loss. Critically, the method operates under a strict black-box assumption where only scalar loss values are returned by the model API — no access to logits, gradients, or internal parameters — and the total number of forward passes (queries) is capped, typically at 5,000 for standard evaluations.

## Method

ZIP reduces the optimization dimensionality and gradient variance through three mechanisms. First, context token parameters are projected into a lower-dimensional space (500-dim) via Fastfood random projections, then factorized as W = U·diag(s)·Vᵀ where the diagonal matrix s provides per-dimension scaling (unlike standard LoRA), reducing total trainable parameters to just 417. Second, a shared feature vector u is added to all context tokens via outer product to preserve expressiveness at negligible parameter cost. Third, an intrinsic-dimensional clipping mechanism scales the N-SPSA zeroth-order gradient estimate by α_t = min(√δ/‖∇̂f‖, 1), where δ is the intrinsic dimensionality; this threshold is theoretically justified as the standard deviation of ZO gradients (Lemma 2) and requires no hyperparameter tuning. The full procedure iterates ZO-SGD updates with these clipped gradients over mini-batches within a fixed query budget.

## Results

On 13 vision-language classification tasks (16-shot per class), ZIP achieves 63.4% average few-shot accuracy with only 0.4k learnable parameters, outperforming BAR (55.7%, 37.6k params), BLACKVIP (56.6%, 9.9k params), and BPTVLM (55.6%, 4.0k params) by +7.7%, +6.8%, and +7.8% respectively. In out-of-distribution generalization (4 ImageNet variants), ZIP reaches 56.9% average accuracy versus 53.4% (BAR), 54.9% (BLACKVIP), and 43.7% (BPTVLM). ZIP also achieves a 48% improvement in query efficiency (fewer API calls to reach target accuracy) compared to the second-best BBPT method, while using only 5,000 queries total.

## Baselines & Comparisons

ZIP consistently outperforms all three BBPT baselines across 11 of 13 few-shot datasets. Against BAR (Tsai et al., 2020), ZIP gains +7.7% on average, with particularly large margins on EuroSAT (+13.0%), Resisc45 (+12.2%), and SVHN (+28.0%). Against BLACKVIP (Oh et al., 2023), ZIP leads by +6.8% on average, excelling on EuroSAT (+20.2%), Resisc45 (+10.6%), and SVHN (+20.3%), though BLACKVIP edges ahead on CLEVR (25.9 vs. 28.4 is actually ZIP winning; BLACKVIP wins on no dataset in Table 1). Against BPTVLM (Yu et al., 2023), ZIP achieves +7.8% on average, with the largest gap on ImageNet (+10.7%) and EuroSAT (+11.6%). In OOD generalization, ZIP's advantage is most pronounced over BPTVLM (+13.2%) and moderate over BAR (+3.5%) and BLACKVIP (+2.0%). Notably, ZIP achieves all these gains with 90–99% fewer parameters than the baselines (0.4k vs. 4.0k–37.6k) and 48% fewer queries to reach target accuracy.

## Relation to Prior Work

ZIP builds directly on the SPSA zeroth-order gradient estimation framework (Spall, 1992) and ZO-SGD convergence theory (Ghadimi & Lan, 2013), but departs from prior black-box prompt-tuning methods (BAR, BLACKVIP, BPTVLM) that relied on evolutionary strategies or naive zeroth-order optimization without addressing the dimensionality curse. The key conceptual departure is a two-pronged strategy: reducing the effective parameter dimensionality via Fastfood random projection combined with a LoRA-style low-rank factorization augmented by a diagonal scaling matrix, and introducing an intrinsic-dimensional gradient clipping threshold (√δ) derived from the theoretical second-moment bound of zeroth-order gradients. This positions ZIP as a targeted fix for the well-known dimension-dependence of zeroth-order methods rather than a new optimization paradigm.

## Why It Matters / Open Questions

The practical impact is significant for API-based VLM fine-tuning where query budgets are tightly constrained: ZIP achieves ~48% better query efficiency and ~6% higher few-shot accuracy than the best prior BBPT methods using only 417 learnable parameters. The finding that the √δ clipping threshold is near-optimal without hyperparameter search removes a nontrivial practical burden. However, the evaluation is limited to CLIP and SigLIP on image classification tasks with loss-only feedback, and the significance tests (Appendix B.8) reveal that ZIP's CDT advantage over BLACKVIP is not statistically significant on average, tempering the headline claims. Open questions include whether the approach extends to text-only LLMs, multimodal generation, or settings where only logits (not losses) are accessible.

## Problem

Torralba & Efros (2011) showed that hand-crafted features could easily identify which dataset an image came from, motivating a decade of effort to build larger, more diverse, and less biased pre-training datasets. However, it remained unclear whether modern neural networks—now far more capable at discovering patterns—could still trivially distinguish among today's supposedly less biased, web-scale datasets, or whether the bias problem had genuinely been alleviated.
![Teaser figure](../imgs/ICLR20251482/cropped_page1_idx0.webp)

## Input / Output

The method takes RGB images (shorter side resized to 500 px) sampled uniformly from large-scale web datasets (YFCC100M, CC12M, DataComp-1B, WIT, LAION-5B, ImageNet) and outputs a dataset identity label, forming an N-way classification problem where N is the number of datasets in the combination (typically 3–6). Evaluation is performed per-image on a held-out validation set (10K images per dataset by default), ensuring the model cannot exploit batch-level statistics. A pseudo-dataset variant samples multiple 'datasets' without replacement from a single source to test whether the model memorizes or generalizes.

## Method

The paper trains standard supervised image classifiers (ConvNeXt-T, AlexNet, VGG-16, ResNet-50, ViT-S) end-to-end on the union of images from multiple datasets, treating each dataset as a class, using a standard recipe (AdamW, cosine LR decay, RandAug, MixUp, CutMix, label smoothing) with 1M images per dataset. The key empirical finding is that all architectures achieve >77% accuracy on 3-way dataset classification (chance = 33.3%), and accuracy improves with more training data and stronger augmentation—behaviors characteristic of learning generalizable patterns rather than memorization. A pseudo-dataset control (sampling subsets from a single source) confirms this: there, the model fails to converge with more data or augmentation and achieves only chance-level validation accuracy. The authors further show that self-supervised pre-training (MAE) followed by linear probing recovers 78.4% dataset classification accuracy without any dataset-identity supervision during pre-training, and that features learned by dataset classification transfer non-trivially to ImageNet-1K linear probing, indicating the discovered biases encode semantically relevant structure.

## Results

On the 3-way YCD (YFCC + CC + DataComp) dataset classification task, a ConvNeXt-T model achieves 84.7% accuracy on held-out validation data, far above the 33.3% chance level. This high accuracy is robust: all 20 possible three-way combinations of the six datasets exceed 62% (16 of 20 exceed 80%), and even the 6-way classification reaches 69.2%. Remarkably, a ConvNeXt with only 7K parameters (3/10000 of ResNet-50) still achieves 72.4% on YCD, and all tested architectures from AlexNet (77.8%) to ConvNeXt-T (84.7%) solve the task well.

## Baselines & Comparisons

For the dataset classification task itself (Table 7), the fully-supervised ConvNeXt/ViT-B model achieves 82.9% accuracy, outperforming MAE linear probing pre-trained on YCD (78.4%) and MAE pre-trained on ImageNet-1K (76.2%), confirming that end-to-end supervised training extracts the most discriminative dataset-identity features. However, for transfer learning to semantic classification (Table 8, ImageNet-1K linear probing), the features learned by dataset classification are substantially weaker: the best dataset-classification model (all 6 datasets) reaches only 34.8% transfer accuracy, compared to 68.0% for MAE and 76.7% for MoCo v3. The paper explicitly notes this gap is expected, as dataset classification is a pretext task that captures bias-related patterns rather than full semantic structure. Thus, the paper's method wins on the primary dataset-classification objective but loses by a wide margin (30–40 points) on downstream semantic transfer compared to established self-supervised baselines.

## Relation to Prior Work

This paper directly revisits the 'Name That Dataset' experiment introduced by Torralba & Efros (2011), which originally used hand-crafted features and SVM classifiers on small datasets. It extends the experimental setting to modern web-scale datasets (YFCC100M, CC12M, DataComp, WIT, LAION, ImageNet) and a range of neural network architectures from AlexNet to ConvNeXt and ViT. Conceptually, it also connects to domain-adversarial training (Ganin et al., 2016; Tzeng et al., 2014), which learns to distinguish domains, and to ImageNetV2 (Recht et al., 2019), which demonstrated that replicated data still exhibits measurable bias. The paper's contribution is purely empirical: it asks whether a decade of dataset diversification has made the task harder for modern models.

## Why It Matters / Open Questions

The finding that modern neural networks achieve 84.7% dataset classification accuracy on large, diverse, web-scale datasets—far above the 45.4% human performance—challenges the working assumption that building bigger, more diverse pre-training datasets has meaningfully reduced dataset bias. The paper shows the captured bias is not merely low-level artifacts (surviving JPEG/color corruptions) and that the learned features transfer to semantic classification, suggesting the bias is semantically structured. However, the concrete forms of bias remain unexplained, and the paper examines only six image datasets, leaving open whether the phenomenon generalizes to video, language, or other modalities. The key open question is how representative current pre-training corpora truly are of the real world, and whether more capable models will continue to exploit residual biases that humans cannot perceive.

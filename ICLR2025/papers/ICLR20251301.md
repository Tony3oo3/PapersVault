## Problem

Transformers achieve compositional learning and in-context learning, but their internal mechanisms remain largely opaque, making it difficult to understand *why* these capabilities emerge. This paper asks whether the same capabilities can be realized in an architecture whose operation is comparatively transparent, and whether such transparency reveals the underlying principle driving compositional generalization.
![Teaser figure](../imgs/ICLR20251301/cropped_page1_idx0.webp)

## Input / Output

The method consumes a sequence of discrete text tokens (or continuous observations) and produces a next-token prediction at each position. Unusually, the value vectors stored in each associative memory unit are computed from the *next* observation (one step into the future), while key vectors are computed from the past via a leaky average, so the attention mask excludes the main diagonal. No positional encoding is used; temporal information enters only through the leaky-average key computation and the one-step-ahead value peek.

## Method

Memory Mosaics replace transformer self-attention layers with contextual associative memory units (Gaussian kernel regression over stored key/value pairs) and replace FFN layers with persistent memory units (fixed key/value pairs learned by gradient descent). Each contextual memory unit computes keys from past observations and values that peek one step ahead, so unrolling in time yields a masked-attention-like expression but with a stricter mask. The key insight is *predictive disentanglement*: minimizing the total prediction loss (area under the per-position loss curve) drives each memory unit to produce a good conditional-expectation estimate as quickly as possible, which naturally decomposes the overall prediction task into independently memorizable sub-tasks. This principle explains how the architecture achieves compositional generalization without positional encoding or explicit query/key separation, and it is illustrated with a 54-parameter three-moons toy problem before being validated on GPT2-scale language modeling and REGBENCH in-context learning benchmarks.

## Results

On the BABISTORIES language modeling task, Memory Mosaics match GPT2-small transformer performance on i.i.d. evaluation (training and validation losses become indistinguishable at depth ≥ 8), with a slight edge at small depths (N_b = 1, 4). On the out-of-distribution Simple English Wikipedia task, Memory Mosaics substantially outperform transformers after ~50 tokens of context. On the REGBENCH in-context learning benchmark (OOD), Memory Mosaics dominate all previously tested architectures across three orders of magnitude of training set sizes, achieving 0.959 accuracy and 0.417 TVD in the IID setting while substantially outperforming all baselines on held-out PFAs.

## Baselines & Comparisons

Against GPT2-small transformer (Radford et al., 2019), Memory Mosaics match i.i.d. performance on BABISTORIES (indistinguishable training/validation losses at depth ≥ 8) but substantially outperform on OOD tasks: on Simple English Wikipedia, Memory Mosaics achieve lower per-token loss after ~50 tokens while the transformer plateaus after 100–150 tokens. On REGBENCH OOD (Figure 9), Memory Mosaics dominate transformers, Mamba (Gu & Dao, 2023), RWKV (Peng et al., 2023), and RetNet (Sun et al., 2023) across all training set sizes spanning three orders of magnitude. In the IID REGBENCH setting (Table 3), Memory Mosaics achieve 0.959 accuracy, competitive with RWKV (0.967) and Hyena (0.953), but with higher TVD (0.417) than RWKV (0.183) and Hyena (0.244), indicating the IID advantage is less pronounced than the OOD advantage. The paper notes that all hyperparameters were tuned for the transformer and transferred verbatim to Memory Mosaics, placing the latter at a slight disadvantage on i.i.d. metrics.

## Relation to Prior Work

Memory Mosaics sit at the intersection of memory networks (Weston et al., 2014; Sukhbaatar et al., 2015), Hopfield-style energy-based transformers (Ramsauer et al., 2020; Krotov, 2023), and persistent-memory-augmented transformers (Sukhbaatar et al., 2019). The key departure is the use of elementary Gaussian kernel regression as the associative memory mechanism, which makes the connection to self-attention algebraically transparent (equation 3) and avoids the energy-function formalism of Hopfield-network approaches. The paper also draws on the meta-transfer objective of Bengio et al. (2019) to frame its central conceptual contribution—predictive disentanglement—as an emergent property of standard gradient training on this architecture, rather than an explicit training objective.

## Why It Matters / Open Questions

The predictive disentanglement principle offers a mechanistic explanation for why transformer-like architectures achieve compositional generalization: training decomposes the prediction task into independently memorizable sub-tasks, and the architecture's inductive bias (independent memory units, kernel-based retrieval) makes this decomposition natural. The empirical finding that a single memory layer implements induction heads (vs. two transformer layers) and that Memory Mosaics substantially outperform transformers on out-of-distribution and in-context learning benchmarks (REGBENCH, Simple English Wikipedia) suggests the architecture's transparency may translate into genuine generalization advantages. Open questions include whether these OOD advantages persist at scale (the paper's main experiments are at GPT2-small size, though a 10B-parameter follow-up is cited), whether the quadratic context-length cost can be mitigated, and whether richer memory hierarchies (intermediate tiers, multi-timescale memories) can be trained without gradients.

## Problem

Traditional AI assumes intelligence requires exposure to inherently intelligent data (human language, expert annotations). This paper tests the alternative hypothesis that intelligence can emerge from modeling simple rule-based systems, provided those systems generate sufficiently complex behavior. The central question is how the complexity of training data governs a model's ability to learn general representations transferable to downstream reasoning tasks.
![Teaser figure](../imgs/ICLR20253120/cropped_page2_idx0.webp)

## Input / Output

For pretraining, the model consumes sequences of binary vectors (60 time steps × 100 spatial dimensions) generated by evolving a single ECA rule from a random initial state, and predicts the next 1 or 5 binary states. For downstream evaluation, the frozen model is adapted to three tasks: grid pattern completion (3×3 or 5×5 shapes undergoing color/rotation/translation), SAN chess move prediction (60-move sequences from Grandmaster games), and Nim optimal-move prediction. The GPT-2 architecture is modified to replace token embeddings with linear projections, making the model operate directly on binary data without a vocabulary and remain deterministic.

## Method

A modified GPT-2 (with linear projections replacing token embeddings for binary I/O) is pretrained via next-token prediction on data from a single ECA rule, with fresh random initial states each epoch to provide effectively infinite data. After pretraining, all transformer layers are frozen and only the input/output projection layers are trained for each downstream task, isolating the quality of learned representations. The key finding is that models trained on Class IV (complex) ECA rules achieve the best downstream performance, while both Class I/II (uniform/periodic) and highly chaotic Class III rules underperform, revealing an 'edge of chaos' sweet spot. Attention analysis shows that models trained on complex data learn non-trivial solutions that attend to historical states, rather than the trivial 8-bit rule lookup, and this richer internal representation is what enables transfer to reasoning and chess tasks.

## Results

Models pretrained on ECA data with higher Lempel-Ziv complexity show significantly better downstream performance (p<0.05) on both reasoning efficiency (inverse epochs to reach 80% accuracy) and chess move prediction accuracy. Class IV (complex) rules outperform all other Wolfram classes on the chess task, while Class I (uniform) and Class II (periodic) rules yield the weakest performance. Attention analysis reveals a strong positive correlation (r=0.66) between data complexity and the model's reliance on historical states, indicating that complex-data models learn non-trivial solutions. Notably, 1-step prediction outperforms 5-step prediction, and some highly chaotic Class III rules (e.g., 105, 146, 150) underperform, confirming a 'sweet spot' at intermediate complexity rather than monotonically increasing performance.

## Baselines & Comparisons

The paper does not compare against external methods; the sole baseline is a randomly initialized (untrained) GPT-2 transformer, shown as a dashed line in all performance plots. All ECA-pretrained models substantially outperform this random baseline on both reasoning tasks and chess move prediction. The primary comparison is internal: models trained on different ECA rules are compared across Wolfram complexity classes. Class IV rules (e.g., Rule 110) achieve the highest chess accuracy and reasoning efficiency, while Class I rules (e.g., Rule 168) and certain Class III rules (e.g., Rule 105, 146, 150) perform closest to or near the random baseline. The key finding is that performance is non-monotonic in complexity: it rises from Class I through Class IV but drops for the most chaotic Class III rules, establishing that neither too-simple nor too-chaotic data is optimal for developing transferable representations.

## Relation to Prior Work

This paper adapts the GPT-2 architecture (Radford et al., 2019) by replacing token embeddings with linear projections for binary sequence prediction, then uses it as a controlled probe into how data complexity shapes learned representations. It draws on Wolfram's classification of elementary cellular automata and Langton's 'edge of chaos' framework to construct a systematic complexity axis, and connects to reservoir computing and LLM scaling-law literature. The key departure from prior work is treating ECA-generated data as a tunable complexity environment for LLMs rather than as a prediction target in its own right, and using downstream reasoning and chess tasks as proxies for 'intelligence' acquired during pretraining.

## Why It Matters / Open Questions

The paper provides a clean, controlled experimental framework for isolating the effect of data complexity on model capabilities, which is difficult to achieve with natural language data. The finding that models learn non-trivial, history-integrating solutions even when a trivial 8-bit rule suffices suggests overparameterization drives richer representations, with implications for data curation strategies in LLM training. However, the evidence is limited to GPT-2-scale models (≤708M params) and binary sequences, leaving open whether the 'sweet spot' phenomenon persists at the scale of modern frontier models or in higher-dimensional modalities. The moderate correlation strengths (r ≈ 0.39–0.73) and the confound between specific ECA rules and complexity class also temper the generality of the conclusions.

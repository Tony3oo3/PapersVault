## Problem

It is unknown whether transformers' documented inability to perform search robustly stems from insufficient training data, too few parameters, or a fundamental architectural limitation. This paper uses the graph connectivity problem as a controlled testbed with effectively limitless synthetic data to isolate these factors and determine whether scaling alone can yield robust search abilities.
![Teaser figure](../imgs/ICLR20250579/cropped_page2_idx1.webp)

## Input / Output

The model receives a directed acyclic graph as a list of edge tokens (e.g., '1E2' for an edge from vertex 1 to vertex 2) in random order, followed by the start and goal vertex tokens, all encoded with 1-hot token and positional embeddings concatenated (not summed) and processed with bidirectional (non-causal) attention. The model outputs a single token: the next vertex along a path from start to goal. Difficulty is controlled via 'lookahead' L, the minimum number of search steps required, and the balanced distribution ensures L is uniformly sampled to prevent heuristic shortcuts.

## Method

The paper trains small GPT-2-style transformers (6 layers, hidden dim 16, 1 attention head, ReLU, no causal mask) via streaming supervised learning on three carefully constructed DAG distributions (naive, star, balanced) that progressively eliminate exploitable heuristics. The key technical contribution is a novel mechanistic interpretability pipeline that reconstructs the model's computation graph per input by: (1) identifying attention operations whose perturbation significantly changes the output logit, (2) propagating importance backward through layers via attention-weight sensitivity, and (3) using activation patching with token and position perturbations to explain which input features causally drive each attention operation. This reveals that transformers learn an 'exponential path-merging' algorithm: each vertex's embedding stores the set of vertices reachable within a bounded number of steps, and each layer merges reachable sets from neighboring vertices, doubling the search radius per layer. Scaling experiments (varying graph size up to 41 vertices and model dimension) show that learning difficulty grows with graph size and is not alleviated by larger models, and that chain-of-thought variants (depth-first search, selection-inference) also fail to resolve the difficulty on larger graphs.

## Results

When trained on the balanced distribution (lookaheads L≤20), a 6-layer transformer (hidden dim 16) achieves near-perfect test accuracy across all lookaheads, while the naive-distribution model drops to ~50% accuracy at L=10. The mechanistic interpretability analysis identifies the exponential path-merging algorithm in 92–99% of examples for balanced-distribution models, versus 0% for a random untrained model. As the maximum input graph size increases (with 8 layers, hidden dim 16, 236M training examples), the fraction of random seeds that converge drops to near zero, and increasing model dimension does not recover this ability. Even with chain-of-thought-style intermediate steps (DFS or selection-inference), the model still struggles on larger graphs regardless of scale.

## Baselines & Comparisons

The paper does not compare against external baseline methods; instead it ablates across training distributions, model scales, and prompting strategies. The balanced distribution is the critical factor: a model trained on it generalizes to unobserved lookaheads (up to L=14 when trained on L≤12), whereas the naive distribution model fails beyond L≈5 due to exponentially rare large-lookahead examples. The star distribution model performs reasonably on balanced test data but worse on naive test data, confirming distribution sensitivity. On scaling, fixing 8 layers and hidden dim 16, the fraction of seeds converging (accuracy ≥0.995) drops sharply as graph size grows past ~31 vertices, and increasing hidden dimension (up to 128) does not restore convergence. For in-context exploration, DFS with 3 layers learns the task at all tested graph sizes but still degrades with size; selection-inference with 4 layers shows the same pattern, and neither benefits from larger models in FLOPs-normalized terms.

## Relation to Prior Work

This paper builds on the line of work studying transformer search capabilities (Saparov & He, 2022; Valmeekam et al., 2022; Kambhampati et al., 2024) and the theoretical expressiveness results of Merrill & Sabharwal (2024), but departs from prior empirical studies by carefully constructing a 'balanced distribution' that eliminates heuristic shortcuts, enabling a clean test of whether transformers can genuinely learn search. The mechanistic interpretability method draws on activation patching (Vig et al., 2020b; Geiger et al., 2021) but introduces a novel procedure to reconstruct the full computation graph without requiring the algorithm to be known a priori, distinguishing it from prior circuit-finding work (Hou et al., 2023; Kim et al., 2024). The in-context exploration experiments adapt the selection-inference framework of Creswell et al. (2023) and depth-first search to test whether intermediate reasoning steps overcome the scaling difficulty.

## Why It Matters / Open Questions

The finding that increasing model scale does not alleviate the difficulty of learning search on larger graphs directly challenges the assumption that continued scaling of LLMs will yield robust search and planning abilities, with implications for how the field approaches reasoning tasks. The identification of the exponential path-merging algorithm provides a concrete mechanistic account that connects to broader reasoning: if transformers store reachable-set information per vertex, analogous representations may underlie multi-hop reasoning in LLMs. Key open questions include whether curriculum learning or looped architectures could overcome the scaling barrier, whether the mechanistic technique generalizes to larger models, and whether the negative result from small models (≤64 hidden dim) truly extrapolates to the scale of modern LLMs.

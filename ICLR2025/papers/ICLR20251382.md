## Problem

Standard transformer self-attention requires computing pairwise similarities between all token pairs, leading to quadratic time and memory complexity that severely limits scalability to long sequences. This paper questions whether pairwise similarity computation is fundamentally necessary, asking whether a transformer-style architecture can be derived from first principles (maximal coding rate reduction) that avoids pairwise interactions entirely while maintaining competitive performance.

## Input / Output

For vision, the model takes 224×224 RGB images tokenized into 16×16 patches (196 tokens) and produces class labels via a [CLS] token; for language, it takes text sequences with context length 1024 and produces next-token predictions autoregressively. A key structural detail is that the attention mechanism consumes tokens only through their projected second-moment statistics rather than pairwise dot products, and group membership assignments Π are computed on-the-fly per forward pass via a softmax over projected token norms, making the operator fully data-dependent without any learned query-key-value projections in the traditional sense.

## Method

The paper derives a novel variational upper bound (Theorem 1) on spectral functions of PSD matrices, showing that F(M) ≤ Σᵢ f((QᵀMQ)ᵢᵢ) for concave non-decreasing f, which tightens when Q diagonalizes M. Unrolling gradient descent on this variational form of the MCR² compression term yields the Token Statistics Self-Attention (TSSA) operator: each attention head projects tokens onto a learned basis Uₖ, computes a diagonal matrix Dₖ from the element-wise squared projections weighted by group membership probabilities, and applies a data-dependent low-rank projection that suppresses directions with small second moments while preserving those with large ones. Group membership Π is estimated via a softmax over L₂-normalized projected token norms (a Gaussian mixture model), and the overall architecture (ToST) is built by replacing self-attention in XCiT (vision) or GPT-2 (language) with TSSA, achieving O(pn) time and O(p) space per head versus O(pn²) and O(n²) for standard attention.

## Results

On ImageNet-1k, ToST-M (68.1M params) achieves 80.3% top-1 accuracy, competitive with XCiT-M (81.5%, 80.2M params) and ViT-B (81.8%, 86.6M params) while using fewer parameters. On the Long-Range Arena benchmark, ToST achieves 59.90 average accuracy, outperforming the standard Transformer (59.24) and all other efficient transformer variants (Reformer 50.56, BigBird 54.17, LinFormer 50.46, Performer 51.18). For causal language modeling, ToST-Large (655M) reaches 4.02 average cross-entropy loss, surpassing GPT-2-Base (124M, 4.26) while using 0.46× the inference time and 0.24× the memory at 8k sequence length.

## Baselines & Comparisons

Against XCiT (Ali et al., 2021), ToST-M achieves 80.3% on ImageNet vs. XCiT-M's 81.5% (−1.2%), but with 12M fewer parameters and O(pn) vs. O(p²n) attention complexity; on transfer tasks the gap narrows to ≤1.5%. Against ViT (Dosovitskiy et al., 2020), ToST-S (77.9%) trails ViT-S (79.8%) by 1.9% on ImageNet, but ToST-M (80.3%) is within 1.5% of ViT-B (81.8%) while using 18.5M fewer parameters. On the LRA benchmark, ToST (59.90 avg) beats the standard Transformer (59.24), Reformer (50.56), BigBird (54.17), LinFormer (50.46), and Performer (51.18), though it is far below S4 (84.03). For language modeling, ToST-Base (4.84 avg loss) underperforms GPT-2-Base (4.26) by 0.58, but ToST-Large (4.02) surpasses GPT-2-Base by 0.24 while being 2.2× faster and using 4.2× less memory at 8k context. CRATE (Yu et al., 2024) shares the same O(pn²) complexity as ViT and is not directly compared in accuracy tables, but ToST's O(pn) complexity represents a fundamental reduction. Overall, ToST trades a small accuracy gap (≤1.5% at matched parameter scale) for a dramatic efficiency gain, with the gap shrinking as model size increases.

## Relation to Prior Work

This paper extends the white-box architecture design lineage of CRATE (Yu et al., 2024), which showed that unrolling the MCR² compression objective yields a standard transformer-like self-attention operator. The key departure is a novel variational reformulation of the compression term (via a spectral upper-bound theorem) that, when unrolled, produces an attention operator requiring only a second-moment statistic of projected tokens rather than pairwise dot-product similarities. Architecturally, TOST inherits its non-attention components from XCiT (Ali et al., 2021) for vision and GPT-2 (Radford et al., 2019) for language, but replaces the attention module with the derived Token Statistics Self-Attention (TSSA). This positions the work as a principled alternative to the entire family of efficient-attention approximations (Reformer, BigBird, LinFormer, Performer, Nyströmformer) that still fundamentally compute or approximate pairwise token interactions.

## Why It Matters / Open Questions

The paper challenges the widely-held assumption that pairwise similarity computation is essential to transformer success, showing that a data-dependent low-rank projection based on second-moment statistics can achieve competitive performance with O(pn) time and O(p) memory complexity instead of O(pn²) and O(n²). This is practically significant for long-sequence and high-resolution settings where quadratic attention is the dominant bottleneck. However, the evidence is 'competitive' rather than 'superior' to standard transformers, models are tested only up to medium scale (~68M params for vision, ~655M for language), and the MLP block remains unchanged from standard designs. Open questions include whether the approach maintains competitiveness at very large scale, whether a white-box replacement for the MLP block can further close the gap, and how the method interacts with modern scaling laws and training recipes.

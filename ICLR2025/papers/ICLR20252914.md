## Problem

Existing universality results for transformers (e.g., Yun et al., 2019) require the embedding dimension to grow with the number of tokens, making them inapplicable to arbitrarily long contexts. This paper asks whether deep transformers with a fixed embedding dimension and fixed number of heads can universally approximate continuous in-context mappings uniformly over an arbitrary (even infinite) number of tokens, and provides a rigorous measure-theoretic framework to answer this affirmatively.

## Input / Output

The method takes a probability distribution over a compact token domain Ω ⊂ ℝ^d as context (encoding any finite or infinite set of tokens as an empirical or continuous measure) and a query token x ∈ Ω, producing a transformed embedding in ℝ^{d′}. In the masked (causal) setting, the context is lifted to a space-time measure over Ω × [0,1] and the query includes a time index t ∈ [0,1], with the constraint that contexts must be Wasserstein-Lipschitz in time. The approximation is uniform over all contexts in the relevant compact set, and the embedding dimension d_tok and number of heads H are bounded by functions of d and d′ only, independent of both the precision ε and the number of tokens.

## Method

The paper reformulates multi-head attention as an in-context mapping Γ_θ(μ, x) operating on probability measures via push-forward, then proves universality by constructing an algebra of 'cylindrical functions' (products of elementary mappings, each being an affine MLP composed with a single-head 1-D attention) and showing this algebra is dense in the space of continuous in-context maps via the Stone-Weierstrass theorem. The key technical challenge is that attention layers cannot be multiplied directly (unlike MLPs with cosine activations), so the proof uses depth: a deep transformer sequentially computes each factor of the product and uses MLPs to approximate the component-wise multiplication. For the masked causal setting, a space-time lifting encodes temporal order into the measure, and the approximation is restricted to Lipschitz contexts to ensure compactness of the masked-measure space, enabling the same Stone-Weierstrass argument on a reduced space (μ_t, x) that exploits the identifiability of causal maps.

## Results

This is a purely theoretical paper with no experimental results or quantitative benchmarks. The main contributions are two universal approximation theorems: Theorem 1 establishes that deep unmasked transformers can approximate any continuous in-context mapping Λ*: P(Ω)×Ω→R^{d'} to arbitrary precision ε, uniformly over compact token domains, with a fixed embedding dimension (d+3d') and a fixed number of heads (d') that are independent of ε and the number of tokens. Theorem 2 extends this to masked (causal) transformers, requiring the additional assumptions that contexts are Wasserstein-Lipschitz in time and that the target map is identifiable. A key distinction from prior universality results is that a single transformer architecture operates on an arbitrary (even infinite) number of tokens without increasing width.

## Baselines & Comparisons

The paper does not include experimental comparisons but positions its theoretical contributions against prior universality results. Compared to Yun et al. (2019), which requires the embedding dimension to grow with the number of tokens, this work achieves universality with a fixed embedding dimension proportional only to the input token dimension d and output dimension d'. Similarly, the Sumformer (Alberti et al., 2023) and stochastic deep networks (De Bie et al., 2019) also require growing embedding dimensions. The masked (causal) setting introduces additional requirements not present in the unmasked case: contexts must be C-Lipschitz in the Wasserstein-2 sense with respect to time, and the target mapping must be identifiable (Lemma 13 shows this assumption is sharp and cannot be weakened). The proof technique relies on the Stone-Weierstrass theorem applied to an algebra of 'cylindrical functions' built from elementary attention-MLP compositions, with depth used to simulate component-wise multiplication that shallow attention layers cannot perform directly.

## Relation to Prior Work

This paper builds on the measure-theoretic reformulation of attention introduced by Sander et al. (2022) and Castin et al. (2024), which views transformers as mappings over probability distributions of tokens. It departs from prior universality results (Yun et al., 2019; Nath et al., 2024) that required the embedding dimension to grow with the number of tokens, instead proving universality with a fixed embedding dimension and fixed number of heads (proportional to input dimension) for an arbitrary, even infinite, number of tokens. The proof technique is novel: it constructs an algebra of 'cylindrical functions' from elementary single-head attention compositions and applies the Stone-Weierstrass theorem, leveraging depth rather than width to compensate for the lack of multiplicative algebraic structure in attention maps. For the masked/causal setting, the paper introduces a space-time lifting that encodes temporal ordering into the measure, enabling the same measure-theoretic framework to handle non-permutation-equivariant attention.

## Why It Matters / Open Questions

This result provides the first rigorous universality guarantee for transformers operating on arbitrarily long (or infinite) contexts with fixed architectural dimensions, resolving a key gap in the theoretical understanding of why transformers can handle variable-length inputs. The main limitation is that the result is non-quantitative: there is no explicit bound on how MLP parameters scale with the desired precision ε, and the number of heads grows linearly with the output dimension (each head outputs a scalar). The authors note that the proof technique, which draws on optimal transport and shares structural similarities with two-layer MLP convergence analyses (Chizat & Bach, 2018), could inform future work on training convergence for transformers. Extending the framework to modern positional encodings like RoPE and obtaining quantitative Wasserstein-based bounds are identified as important open directions.

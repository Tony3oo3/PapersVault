## Problem

LLMs used for planning and reasoning rely on pretrained common-sense causal knowledge that is often incomplete, incorrect, or inapplicable to a specific environment, leading to poor performance on multi-step tasks. Causal representation learning (CRL) can recover the true causal structure of an environment but lacks a natural language interface for interaction with language-based agents. This paper bridges the gap by integrating CRL into a causal world model that LLMs can query and interact with for causally-aware planning.

## Input / Output

The causal world model takes an RGB environment state image (256×256 for iTHOR, 8×8 grid for GridWorld) and a natural language action description (e.g., 'you toggled the cyan traffic light') as input, and produces a natural language description of the predicted next state. During planning, the system additionally outputs a sequence of actions (a plan) to transform an initial state into a goal state. Action descriptions are tokenized and encoded via a pretrained sentence transformer (all-MiniLM-L6-v2 or SigLIP) with a trainable 2-layer MLP head, while state descriptions are generated by a rule-based system mapping estimated causal variables to fixed phrases.

## Method

The framework builds on BISCUIT's CRL architecture—an autoencoder compresses images into latent codes, a RealNVP normalizing flow disentangles them into causal variables, and a transition model with binary interaction masks predicts next states—while replacing coordinate-based action encodings with text-based encodings from a frozen pretrained sentence transformer plus a trainable MLP head. A two-stage causal mapper (correlation-based target assignment followed by per-variable MLP predictors) converts disentangled latents into interpretable causal variables, which a rule-based state description generator renders as natural language. For planning, a modified RAP-MCTS algorithm uses LLaMA 3 (8B) to propose actions and score state-action pairs via intuition and self-evaluation rewards, while the CWM simulates transitions autoregressively in the disentangled latent space, achieving ~82× faster inference than the LLM-based baseline. Training uses ELBO optimization with the reparameterization trick for the generative model, and the causal mapper is trained on a small set of labeled causal variables (≈1200 examples suffice for MAE < 0.05).

## Results

On planning tasks, the causal world model achieves a 0.95 success rate on 2-step GridWorld (vs. 0.20 for RAP) and maintains 0.42 success on 8-step GridWorld (vs. 0.06 for RAP). On iTHOR, it reaches 0.58 success on 2-step planning (vs. 0.25) and 0.44 on 4-step (vs. 0.11). For causal inference, the model sustains 75.8% accuracy at 8-step prediction in GridWorld while the RAP baseline drops to 0.5%, and achieves 63.0% at 4-step in iTHOR versus 11.0% for the baseline. The CRL world model also runs ~82× faster per inference step (27 ms vs. 2.2 s) than the LLM-based world model.

## Baselines & Comparisons

The sole baseline is the RAP world model (Hao et al., 2023), which uses LLaMA 3 8B as both the planning agent and the world model, predicting next states purely from language. The causal world model wins decisively on every metric in both environments. On planning success rate, the gap widens with horizon length: in GridWorld the causal model achieves 0.42 vs. 0.06 at 8 steps (7× improvement), and in iTHOR 0.44 vs. 0.11 at 4 steps (4× improvement). On causal inference accuracy, the advantage is even more dramatic at longer horizons—75.8% vs. 0.5% at 8-step GridWorld prediction. The causal model also plans more efficiently, taking fewer average steps on successful trajectories (e.g., 1.78 vs. 4.00 on 2-step iTHOR). The only category where the RAP baseline edges ahead is PickupObject in iTHOR (0.692 vs. 0.431), likely because the LLM's pretrained commonsense about object manipulation partially compensates for the lack of a learned causal model.

## Relation to Prior Work

This paper bridges two previously separate research threads: causal representation learning (CRL) in temporal settings, building directly on BISCUIT (Lippe et al., 2023) for identifiability guarantees and disentangled latent recovery, and LLM-based planning via the RAP/MCTS framework (Hao et al., 2023). The key architectural departure is replacing BISCUIT's coordinate-based action encodings with text-based representations (via Sentence-Transformer or SigLIP) and adding a language-grounding decoder (causal mapper + state description generator) that exposes the latent causal state to an LLM agent. No prior work had integrated a learned CRL model as a queryable world-model simulator for an LLM planner, making this the first such framework.

## Why It Matters / Open Questions

The framework demonstrates that a learned causal world model can serve as a fast, accurate simulator for LLM-based planning, with the 82× inference speedup over LLM-only world models enabling substantially deeper tree searches. However, the evaluation is confined to very simple environments (8×8 GridWorld, a single kitchen scene), and the causal mapper still requires a small set of labeled causal variables, limiting immediate applicability to complex, open-world settings. Open questions include whether the approach scales as CRL methods mature, whether the labeled-variable requirement can be eliminated, and whether the text-based action interface generalizes to truly open-vocabulary action spaces beyond PCFG-generated descriptions.

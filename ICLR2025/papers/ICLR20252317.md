## Problem

Existing auxiliary OOD data fine-tuning methods (e.g., Outlier Exposure, Energy-OE) only enlarge the output-space discrepancy between ID and OOD samples, while ignoring the feature space where separability should be more effective. The main obstacle to designing a feature separation loss is the high diversity of OOD samples, whose features are scattered and difficult to model as a coherent distribution.
![Teaser figure](../imgs/ICLR20252317/cropped_page1_idx0.webp)

## Input / Output

The method takes standard RGB images (32×32 for CIFAR benchmarks, 224×224 for ImageNet) and requires auxiliary OOD data during fine-tuning (300K samples from 80M Tiny Images for CIFAR; a validation subset of ImageNet-21k for ImageNet). At test time, it produces a scalar detection score that is the sum of the max softmax probability (MSP) and the average absolute cosine similarity between the penultimate feature and all FC layer weights, compared against a threshold calibrated on ID data to yield a binary ID/OOD decision.

## Method

Leveraging the Neural Collapse property—where penultimate features of ID samples within a class converge to the corresponding FC layer weight—the paper proposes a Separation Loss (L_Sep) that minimizes the average absolute cosine similarity between OOD features and all C FC weights, effectively pushing OOD features into the high-dimensional orthogonal complement of the C-dimensional ID principal subspace. An auxiliary Clustering Loss (L_Clu) simultaneously encourages ID features to align with their class weight, reinforcing NC. Training is two-stage: first, cross-entropy fine-tuning to ensure NC has occurred; then joint optimization of CE, OE, L_Sep, and L_Clu. The approach requires no data augmentation or sampling, and the separation loss can be plugged into any existing auxiliary OOD framework by replacing the OE loss term.

## Results

On CIFAR-10 (WRN-40-2), the proposed method achieves an average FPR95 of 2.49% and AUROC of 98.93% across five OOD test sets. On CIFAR-100, it reaches 29.47% FPR95 and 94.00% AUROC, outperforming the OE baseline by 8.30% in FPR95. On ImageNet with ResNet-50, the method attains 56.73% FPR95 and 84.62% AUROC, and with ViT-B-16, 56.88% FPR95 and 85.13% AUROC. The method achieves these results without any data augmentation or sampling strategies.

## Baselines & Comparisons

Among post-hoc methods (MSP, Energy, Maha, KNN), the proposed method substantially outperforms all of them, reducing average FPR95 by over 30 points on CIFAR-100 (29.47% vs. 62.75–79.07%). Against contrastive learning baselines (CSI, CIDER, KNN+), the method also wins clearly, achieving 29.47% FPR95 on CIFAR-100 versus 45.20–61.12% for the best contrastive method. The most direct comparison is with other auxiliary OOD data methods: the method beats OE by 0.87% FPR95 on CIFAR-10 (2.49% vs. 3.36%) and by 8.30% on CIFAR-100 (29.47% vs. 37.77%), and outperforms DAL by 2.00% FPR95 and 1.18% AUROC on CIFAR-100 (29.47%/94.00% vs. 31.47%/92.82%). On ImageNet (ResNet-50), the method reduces FPR95 by 2.93% over OE (56.73% vs. 59.66%) and by 2.66% over DAL (56.73% vs. 59.39%). POEM, which uses posterior sampling, performs poorly in this setting (39.24% FPR95 on CIFAR-10), likely due to different training protocols, and is not competitive with the proposed approach.

## Relation to Prior Work

This paper extends the auxiliary OOD data fine-tuning paradigm established by Outlier Exposure (Hendrycks et al., 2018) and its successors (Energy-OE, POEM, DAL), which all optimize output-space discrepancies between ID and OOD samples. The key conceptual departure is leveraging the Neural Collapse property (Papyan et al., 2020)—where ID penultimate features converge to their class's FC weight—to define a C-dimensional principal subspace, then constraining OOD features to be orthogonal to it via a cosine-similarity-based Separation Loss. This shifts the optimization target from 'make outputs different' to 'make features occupy different dimensions,' drawing an analogy to how contrastive learning methods (SupCon, CIDER) showed feature-space compactness/dispersion matters for ID data, but applying that insight to the auxiliary OOD data setting for the first time.

## Why It Matters / Open Questions

The paper demonstrates that feature-space separation, not just output separation, is a critical and previously underexploited degree of freedom when fine-tuning with auxiliary OOD data, yielding SOTA FPR95/AUROC on CIFAR-10, CIFAR-100, and ImageNet without data augmentation or sampling. The NC-based geometric framing is elegant and the loss is trivially simple (average absolute cosine similarity to FC weights), making it a practical drop-in replacement for the OE loss in existing pipelines. Key limitations include dependence on the NC property holding (which degrades under class imbalance) and the requirement that feature dimensionality exceeds the number of classes. An open question the authors highlight is how to identify the relevant low-dimensional ID subspace when NC fails, which would broaden the method's applicability beyond well-behaved, balanced training scenarios.

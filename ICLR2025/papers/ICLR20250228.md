## Problem

Existing theoretical studies on Transformers follow the classic one-model-one-task paradigm, constructing a separate Transformer for each task. The LLM prompting paradigm—where a single general-purpose model is given different prompts to perform different tasks—has driven enormous empirical success but lacks any theoretical characterization. This paper asks: is prompting Turing-complete, and if so, what are the complexity bounds of a single finite-size Transformer under prompting?

## Input / Output

The Transformer Γ takes as input a concatenation of a prompt π_φ (a finite string over a 23-token alphabet encoding a 2-PTM instruction sequence for function φ) and a tokenized binary input x, and autoregressively generates a chain-of-thought sequence recording each 2-PTM execution step followed by the Shannon-decoded output φ(x) between special delimiter tokens. The prompt is independent of the input x, the Transformer is independent of the function φ, and a readout function extracts the final answer from the CoT. The input x can be arbitrarily long, and the entire pipeline (tokenize, generate, readout) runs in linear time in |x| and |φ(x)| respectively.

## Method

The core construction introduces two-tape Post-Turing machines (2-PTMs) as an intermediate model of computation that is Turing-complete, nearly as efficient as TMs (at most O(log t(n)) slowdown via the Hennie-Stearns theorem), and easily encodable into a finite-alphabet prompt using unary go-to offsets. The Transformer executes the 2-PTM by using CoT steps to record each execution step (instruction, tape head positions, go-to outcomes), allowing it to restore the full machine state at any step via causal attention. Three key architectural tricks enable this: ReLU implements Boolean AND for go-to condition checking, layer normalization implements exact equality comparison for tape-cell retrieval, and a positional-encoding-based farthest-retrieval scheme lets causal attention find the last write at a given tape position despite attention computing averages rather than sums. The resulting single Transformer achieves O(t(n)) CoT steps for two-tape TMs, O(t(n)log t(n)) for general TMs, and O(log(n+t(n))) precision—matching the bounds of the class of all unbounded-size Transformers.

## Results

The paper establishes that prompting is Turing-complete: a single finite-size decoder-only Transformer Γ can compute any computable function φ given a corresponding prompt π_φ. The key complexity bounds are: (i) CoT complexity — Γ computes any TIME₂(t(n)) function within O(t(n)) CoT steps and any TIME(t(n)) function within O(t(n) log t(n)) CoT steps; (ii) precision complexity — Γ computes any TIME(t(n)) function within O(log(n + t(n))) bits of precision, and in particular decides any P language within O(log n) precision. The construction uses a 23-token alphabet, Shannon's encoding, and a novel two-tape Post-Turing machine (2-PTM) as the intermediate model of computation.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The relevant comparison is against prior theoretical bounds for the class of all (unbounded-size) Transformers: Pérez et al. (2021) showed the class of all Transformers achieves O(t(n)) CoT steps and O(log(n+t(n))) precision for TIME(t(n)) functions, while Merrill & Sabharwal (2024a) improved CoT to O(t(n)) for TIME(t(n)). The present work shows that a single finite-size Transformer with prompting matches the precision bound exactly (O(log(n+t(n)))) and achieves a near-matching CoT bound (O(t(n) log t(n)) vs. O(t(n))), with the logarithmic gap attributed to simulating unbounded tapes with only two. The paper also contrasts its 2-PTM construction with Wang machines and DSW-PTMs, noting that the latter suffer polynomial slowdowns over TMs (Neary et al., 2014) while 2-PTMs achieve only a logarithmic slowdown (Theorem 4.1).

## Relation to Prior Work

Prior theoretical work on Transformers (Pérez et al. 2019, 2021; Merrill & Sabharwal 2024a) established Turing completeness under the classic one-model-one-task paradigm, where a different (potentially unbounded-size) Transformer is constructed for each task. This paper departs from that paradigm by studying the LLM prompting setting—one finite-size Transformer handling many tasks via different prompts—which the authors explicitly identify as unstudied. The construction draws on the Hennie-Stearns two-tape simulation theorem to introduce 2-PTMs as an intermediate model that is both easily encodable in a finite alphabet and nearly as efficient as full TMs, and on Shannon's encoding to resolve the blank-symbol ambiguity. The Transformer construction itself leverages hardmax attention, ReLU-implemented Boolean algebra, and layer normalization for equality checks, building on the architectural abstractions from Pérez et al. (2019) and Merrill & Sabharwal (2023).

## Why It Matters / Open Questions

This is the first theoretical characterization of the LLM prompting paradigm, providing a formal justification for why a single pretrained model can be steered to perform arbitrary computable tasks through prompt design. The near-tight complexity bounds (O(t(n)log t(n)) CoT steps vs. O(t(n)) for the class of all Transformers; matching O(log(n+t(n))) precision) suggest the log overhead from simulating unbounded tapes with a fixed two-tape architecture is essentially unavoidable, framing a concrete open question about whether more tapes or richer prompt encodings could close the gap. A key limitation is that the result is purely existential and constructive in a theoretical sense—the actual prompt for a given function could be extremely long, and the construction does not address learnability or whether real LLMs can be trained to implement the required execution logic. The work opens the door to further theoretical studies of prompt length, prompt learnability, and the relationship between prompt complexity and task difficulty.

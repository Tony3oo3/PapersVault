## Problem

Existing GNN calibration methods either apply uniform temperature scaling that ignores graph structure, or use a single GNN calibrator that cannot systematically integrate diverse input sources (logits, node features, degree) with model ensembles. The paper identifies two key gaps: (i) no principled way to represent node-specific calibration error, and (ii) no framework to jointly leverage multiple calibration-relevant factors across different input spaces and scales.

## Input / Output

GETS consumes frozen logits from a pre-trained GNN classifier, raw node feature vectors, and integer node degrees (mapped to 16-dimensional dense vectors via a learned embedding layer), along with the graph adjacency matrix for message passing. It outputs calibrated node-wise logits that preserve the original argmax prediction (guaranteed by the monotone-preserving property of temperature scaling), from which calibrated class probabilities are obtained via softmax. Calibration is trained post-hoc on the validation set using negative log-likelihood loss, with the base classifier held fixed.

## Method

GETS constructs a Graph Mixture-of-Experts architecture with M=7 two-layer GCN experts, each trained on a distinct input combination from the set {z, x, d, [z,x], [x,d], [z,d], [z,x,d]}, where z is the logit vector, x is the node feature, and d is the degree embedding. A sparse TopK gating mechanism (k=2) selects the two most relevant experts per node using a noisy gating score Q(h_i) = h_i W_g + ε·Softplus(h_i W_n), where ε~N(0,1) encourages exploration. The final calibrated logit for each node is a convex combination of the selected experts' outputs, weighted by the softmax of their gating scores. This design decouples input-space heterogeneity (each expert sees a single input type or a fixed pair) from model diversity (multiple GCN experts), avoiding the dimensionality mismatch that arises from naively concatenating vectors of different sizes, while the sparse activation keeps computation linear in the number of nodes.

## Results

GETS achieves the lowest ECE across the majority of 30 dataset-classifier combinations (10 datasets × 3 GNN backbones), with average improvements of 28.60% over CaGCN, 26.62% over GATS, and 28.09% over ETS. Standout gains include Ogbn-arxiv/GCN (1.85 vs. 2.32 for CaGCN), Reddit/GAT (0.62 vs. 0.81 for CaGCN, where GATS fails with OOM), and Physics/GAT (0.29 vs. 0.69 for CaGCN). GETS also demonstrates superior scalability, handling the 233K-node Reddit graph without memory issues while GATS runs out of memory. Minor exceptions exist on Computers/GIN and Cora/GIN where gains are marginal or slightly negative.

## Baselines & Comparisons

GETS outperforms CaGCN (Wang et al., 2021) on 26 of 30 dataset-classifier pairs, with the largest margins on Ogbn-arxiv (e.g., 1.85 vs. 2.32 for GCN) and CS/GAT (1.05 vs. 2.57). Against GATS (Hsu et al., 2022), GETS wins on 27 of 30 pairs and additionally avoids the out-of-memory failures that GATS suffers on the 233K-node Reddit graph across all three classifiers. Compared to the non-graph ensemble method ETS (Zhang et al., 2020), GETS achieves substantially lower ECE on structurally complex graphs (Ogbn-arxiv, Reddit, Cora-full) where graph-aware calibration matters most, though ETS occasionally edges out GETS on simpler datasets like Cora/GAT (1.67 vs. 2.00). Classic parametric methods TS and VS are consistently outperformed by all graph-aware methods, confirming that node-wise calibration is necessary for GNNs. In the supplementary comparison with SimCalib (Tang et al., 2024), GETS wins on 7 of 16 dataset-classifier pairs (notably Cora, Citeseer, Cora-full, and Physics/GAT) but loses on several others (Computers, Photo, CS, Pubmed/GCN), indicating that similarity-based calibration can be competitive on certain graph topologies.

## Relation to Prior Work

GETS extends the node-wise temperature scaling line initiated by CaGCN (Wang et al., 2021) and GATS (Hsu et al., 2022), which each use a single GNN layer to learn per-node temperatures from logits. It departs from these by introducing a Graph Mixture-of-Experts architecture where multiple calibration experts—each trained on a different input combination (logits, node features, degree embeddings, or their concatenations)—are sparsely activated per node via a gating mechanism, drawing on the ensemble temperature scaling idea of Zhang et al. (2020) and the sparse-gated MoE design of Shazeer et al. (2017). The key conceptual shift is treating calibration as a multi-source information fusion problem rather than a single-network regression, and explicitly incorporating structural information (degree) as a first-class calibration input.

## Why It Matters / Open Questions

The consistent ~25–28% ECE reduction across 10 diverse datasets and three base classifiers, combined with the scalability advantage over GATS (which OOMs on Reddit), makes GETS a practical drop-in calibration layer for GNN deployment in high-stakes settings. The observation that degree-based calibration error patterns reverse between sparse and dense graphs (Figure 1) provides a useful diagnostic for practitioners. Limitations include modest or negative gains on some datasets (Computers, Cora, Cora-full), the method remaining post-hoc and task-specific to node classification, and the reliance on a fixed set of input combinations that may not generalize to other graph tasks (link prediction, graph classification). Open questions include whether the MoE gating can be made differentiable end-to-end with the base GNN and whether the approach extends to inductive or dynamic graph settings.

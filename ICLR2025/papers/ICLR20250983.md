## Problem

Adapting pretrained LMs to new contexts (documents, demonstrations, user conversations) requires either expensive fine-tuning or carrying long prompts at inference time, creating an unavoidable accuracy-compute tradeoff. No existing method can efficiently inject contextual knowledge into a frozen LM's parameters using only forward passes, without the training cost of fine-tuning or the persistent inference overhead of prompting.
![Teaser figure](../imgs/ICLR20250983/cropped_page2_idx0.webp)

## Input / Output

The method consumes streaming text context arriving in 1,024-token chunks (documents, dialogues, or few-shot demonstrations) and produces a set of low-rank additive weight matrices added to targeted linear layers of the frozen base LM. At inference, the adapted LM operates in closed-book fashion—no context tokens appear in the input, so per-token inference computation matches the base model exactly. The generated adapter is stored compactly as a partial-sum matrix S_t of dimension d_r × d_r (1024×1024), enabling incremental updates as new context chunks arrive without reprocessing history.

## Method

An adapter generator network G, trained end-to-end on top of a frozen base LM, maps context hidden states to layer-specific additive weight updates via a bilinear outer-product function: W_Δ^(l) = (A₁A₂) H^(l−1)ᵀ H^(l−1) (B₁B₂), where H^(l−1) are hidden states from the previous Transformer layer and A, B are learnable low-rank projection matrices. A dynamic streaming update maintains a running partial sum S_t = S_{t−1} + A₂ H_tᵀ H_t B₁, allowing the adapter to be updated incrementally per chunk without storing full hidden-state history. SVD normalization (resetting singular values to 1) addresses training instability from skewed singular-value distributions and naturally yields LoRA-like rank-r adapters. The generator is trained self-supervised with two complementary tasks—reconstruction (maximizing log-likelihood of the context under the adapted LM, acting as an autoencoder) and completion (maximizing log-likelihood of the continuation, acting as a regularizer against over-memorization)—on 1B tokens of web text followed by instruction tuning.

## Results

On StreamingQA with Mistral-7B-Instruct, Generative Adapter achieves 51.5 F1 at 512-token context and 32.0 F1 at 32K tokens, a 63.5% improvement over supervised fine-tuning (19.5 F1) at the 32K setting. On MetaICL (26 tasks), the method reaches an average accuracy of 44.9, outperforming both zero-shot prompting and few-shot in-context prompting of the base model. On MSC for personalization, Generative Adapter achieves 40.2 F1 with 0.505 TFLOPS inference computation and 32M floats of extra storage, a 4× reduction in both computation and memory compared to full-conversation prompting (2.059 TFLOPS, 128M+ floats).

## Baselines & Comparisons

Against UltraGist (Zhang et al., 2024) on MSC, Generative Adapter achieves 40.2 F1 with 0.505 TFLOPS inference and 32M floats storage, matching UltraGist(512 tokens) in storage (32M) while using 35% less inference computation (0.505 vs. 0.772 TFLOPS) at a negligible F1 gap (40.2 vs. 40.8). On MetaICL, Generative Adapter outperforms UltraGist(256 tokens) on both classification (44.9 avg vs. 41.1) and non-classification tasks, where UltraGist drops to 7.5. On StreamingQA, UltraGist at a 2× compression ratio (63.5 F1 at 512 tokens, using 0.3K gist tokens) still exceeds Generative Adapter (51.5 F1, 0K extra tokens), but at 32× compression UltraGist degrades to 32.5 F1, matching Generative Adapter's 32.0. The key advantage of Generative Adapter is that its inference cost is identical to the base model (no extra tokens in context), making it superior in repeated-query scenarios where the same adapted model is reused many times.

## Relation to Prior Work

This paper operationalizes the fast-weights paradigm (Schmidhuber 1992; Ba et al. 2016) for modern pretrained LMs by using the base model itself as both context encoder and adaptation target—a 'self-programming' formulation distinct from prior slow/fast network splits. The additive low-rank parameterization directly follows LoRA (Hu et al., 2022), while the reconstruction training objective is adapted from the in-context autoencoder (Ge et al., 2024). Unlike hypernetwork approaches (Ivison et al., 2023; von Oswald et al., 2020) that generate task-specific parameters, Generative Adapter produces context-dependent updates for a frozen general-purpose LM, and unlike meta-learning-based online adaptation (Hu et al., 2023; Tack et al., 2024), it requires no nested training loop—only a single self-supervised pretraining phase.

## Why It Matters / Open Questions

The method offers a practical middle ground between prompting (inference overhead grows with context) and fine-tuning (training cost), which is particularly relevant for edge-device personalization where the 4× computation/memory reduction is concrete. However, the evaluation is confined to 7B models with only the attention output projection layer in main experiments, leaving open whether the approach scales to larger models or benefits from updating more layers. The paper also notes that performance still degrades with context length (unlike prompting within the window), and the combination with RAG suggests the method is complementary rather than a replacement for retrieval. Future work on selective update rules and broader layer coverage could substantially widen the applicability.

## Problem

Existing long-term point tracking methods rely on offline processing (access to all frames or a sliding window), making them unsuitable for real-time streaming applications like robotics and augmented reality. Additionally, these approaches suffer from scalability issues due to full temporal attention across all frames, and they lack mechanisms to handle feature drift over long sequences. This paper addresses the gap of achieving state-of-the-art point tracking in a strictly online, frame-by-frame setting without access to future frames.

## Input / Output

The model consumes RGB video frames sequentially (causally, no future access) at 256×256 resolution for evaluation (384×512 for training), along with N point queries each specified by a start frame index and 2D pixel location. It outputs per-frame point correspondences as sub-pixel coordinates, binary visibility labels, and continuous uncertainty scores. A key structural detail is that the model maintains two FIFO memory queues (spatial and context, each holding up to K=12 embeddings at training, extendable to K=96 at inference via linear interpolation of temporal positional embeddings) that persist across frames to propagate temporal information without reprocessing the full video.

## Method

Track-On uses a DINOv2 ViT-Adapter backbone for dense feature extraction (stride 4), a 3-block transformer decoder where point queries attend to frame features via cross-attention, and a coarse-to-fine prediction head that first performs patch classification (cosine similarity over multi-scale patch embeddings with softmax) and then refines via a deformable attention offset head constrained to ±S pixels. The key architectural contribution is two complementary memory modules: spatial memory stores local feature patches around previous predictions to update the initial query and combat feature drift, while context memory stores decoded query embeddings to provide broader temporal context including occlusion history. A re-ranking module retrieves top-k similar patches via deformable attention and fuses them back into the query to correct cases where the true correspondence is not the most similar patch. Training uses cross-entropy for patch classification, L1 for offsets, and BCE for visibility/uncertainty, supervised on 24-frame clips from TAP-Vid Kubric with up to 480 points per sample.

## Results

On the TAP-Vid DAVIS benchmark, Track-On achieves 65.0 AJ, 78.0 δ_avg, and 90.8 OA, surpassing the best offline model (CoTracker3, 64.5 AJ) and the closest online competitor (Online TAPIR, 56.7 AJ) by 0.5 and 8.3 AJ respectively. On RGB-Stacking (long videos up to 250 frames), Track-On reaches 71.4 AJ and 85.2 δ_avg, outperforming Online TAPIR by 3.7 AJ and matching or exceeding offline models with video-level input. On Kinetics, Track-On achieves 53.9 AJ and 87.8 OA, trailing only CoTracker3 trained on real-world videos (55.8 AJ) while beating all other offline baselines in δ_avg and OA.

## Baselines & Comparisons

Track-On outperforms all online baselines by substantial margins: on DAVIS it beats Online TAPIR by 8.3 AJ (65.0 vs. 56.7) and MFT by 17.7 AJ; on Kinetics it exceeds Online TAPIR by 2.4 AJ and 2.9 δ_avg. Against offline models trained on the same synthetic data (Kubric), Track-On surpasses CoTracker3 (Window, Kub-L) on DAVIS by 0.5 AJ and 1.3 δ_avg, and beats LocoTrack (Video, Kub) by 2.1 AJ on DAVIS. On RGB-Stacking, Track-On (71.4 AJ) trails CoTracker3 (Video, Kub-L) at 74.0 AJ but exceeds CoTracker3 (Window, Kub-L) at 71.1 AJ, while on Kinetics it is within 0.2 AJ of CoTracker3 (Window, Kub-L) at 54.1. The only models that consistently outperform Track-On are those fine-tuned on large-scale real-world videos (CoTracker3 Kub-L+R, BootsTAPIR), which benefit from additional training data not used by Track-On. On the additional datasets (RoboTAP, Dynamic Replica, BADJA, PointOdyssey), Track-On achieves state-of-the-art or near-SOTA results, beating LocoTrack by 1.2 AJ on RoboTAP and CoTracker3 by 0.7 δ^vis on Dynamic Replica.

## Relation to Prior Work

This paper departs from the dominant offline point tracking paradigm (TAPIR, CoTracker, LocoTrack, CoTracker3) that relies on bidirectional temporal attention over windows or full videos, instead formulating tracking as a strictly causal, frame-by-frame problem. It repurposes the transformer decoder query mechanism from detection (DETR) to treat tracked points as queries, replacing the iterative regression-based update paradigm with a patch classification and refinement approach. The dual memory modules (spatial and context) draw conceptual inspiration from online video understanding work (XMem, LSTR) but are specialized for point tracking, addressing feature drift and occlusion history respectively. The visual backbone leverages DINOv2 via ViT-Adapter, connecting to the broader trend of using self-supervised foundation models for dense prediction tasks.

## Why It Matters / Open Questions

Track-On demonstrates that a simple online model with memory can match or surpass offline approaches that have access to future frames, narrowing the long-standing gap between streaming and batch tracking. This is practically significant for robotics, augmented reality, and other real-time applications where causal processing is mandatory. Key limitations remain: precision loss on thin surfaces, failure under fast motion or scene cuts, and difficulty on uniform/textureless regions. Open questions include whether learnable upsampling can recover sub-patch precision, whether the FIFO memory design is optimal versus learned eviction, and whether the approach generalizes to 3D tracking or multi-object scenarios without architectural changes.

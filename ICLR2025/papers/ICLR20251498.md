## Problem

VQ-based autoregressive image generation suffers from severe information loss (ICR ≈ 0.21% for typical N=8192, f=16 configurations), limiting fine-grained detail reconstruction such as text rendering. Existing remedies—increasing codebook size N or reducing downscaling factor f—are either logarithmically bounded or quadratically expensive in sequence length. The paper asks whether one can overcome this information bottleneck end-to-end without increasing the backbone model size or sequence length.
![Teaser figure](../imgs/ICLR20251498/cropped_page0_idx3.webp)

## Input / Output

For conditional generation, the model takes a class label (ImageNet-1k) plus a learned unconditional embedding (10% dropout for classifier-free guidance) and produces a 256×256 RGB image. For unconditional rich-text generation, no conditioning is provided and the model outputs 512×512 images containing rendered text. Internally, the model emits L×d discrete tokens (L = h×w spatial positions, d = depth, typically 2 or 8) in depth-first-spatial-second order, which are decoded by a shared RQVAE decoder into the final image.

## Method

The core contribution is 2-Dimensional Autoregression (DnD), which decomposes each spatial feature vector into d residual codes via RQVAE, increasing the information compression ratio to d × log₂N / (24f²) without changing N or f. The DnD-Transformer implements this by inserting multiple prediction heads at different transformer layer indices (e.g., layers 39 and 48 for d=2) so that a single forward pass sequentially predicts all d depth codes: after each depth code is predicted, its embedding is added to the running input representation before the next head predicts the finer-grained residual. This vertical autoregressive design (ablated against parallel and 1D baselines) avoids the two-model structure of RQ-Transformer, requires no additional parameters beyond the extra heads, and keeps the sequence length at L rather than L×d, making it a drop-in extension of any LLaMA-style decoder. Training uses standard next-token cross-entropy with classifier-free guidance, and the model achieves up to 1.54 FID on ImageNet 256×256 (2.5B, cfg=1.7) while also generating coherent rich-text images unconditionally—a capability the paper shows diffusion baselines (DDPM, SDXL, SD3) fail to match.

## Results

On class-conditional ImageNet 256×256, DnD-Transformer-XXL (1.4B, cfg=2) achieves FID 2.58 and IS 295.6, substantially outperforming the same-size LlamaGen-XXL baseline (FID 4.12, IS 266.9) without increasing model parameters or sequence length. The larger DnD-Transformer-XXXL (2.5B, cfg=1.7) reaches FID 2.21 and Recall 0.58, surpassing the 3.1B LlamaGen-3B (FID 4.21) trained with a 2.25× longer sequence. On unconditional rich-text image generation (arXiv-Image), DnD-Transformer produces semantically coherent phrases with lower OCR perplexity than DDPM, SDXL, and SD3, demonstrating emergent vision-language intelligence from pure image training.

## Baselines & Comparisons

DnD-Transformer-XXL (1.4B) improves FID from 4.12 to 2.58 over the same-size LlamaGen-XXL baseline (implemented), a 37% reduction, while also improving Recall from 0.49 to 0.56. The 2.5B DnD-Transformer-XXXL (FID 2.21) outperforms the larger 3.1B LlamaGen-3B (FID 4.21) despite using a shorter sequence length (256 vs. 576 tokens), demonstrating that depth autoregression compensates for reduced spatial resolution. VAR (2.0B) still achieves the best FID (1.73) but requires reject sampling, an additional inference cost not present in DnD-Transformer. DiT-XL/2 (675M) is competitive at FID 2.27 but uses a fundamentally different (diffusion) paradigm. On rich-text generation, DnD-Transformer clearly outperforms DDPM, SDXL, and SD3: while diffusion models struggle to produce valid words, DnD-Transformer generates semantically appropriate phrases (e.g., 'it should be'), with lower PPL_ocr scores, highlighting the autoregressive model's inherent advantage for text-containing image generation.

## Relation to Prior Work

This paper builds directly on RQ-Transformer (Lee et al., 2022b), which introduced residual quantization to add a depth dimension to autoregressive image generation, but departs from it by unifying the spatial and depth prediction into a single end-to-end transformer rather than two separate models. It also positions itself against LlamaGen (Sun et al., 2024) as the primary 1D autoregressive baseline, showing that LlamaGen is a special case of DnD-Transformer with depth=1. The key conceptual departure is reframing the VQ information-loss problem as solvable through depth autoregression (multiplying ICR by d) rather than through codebook expansion or downscaling factor reduction, and demonstrating that VQVAE's inability to reconstruct text is a data/depth limitation rather than an inherent architectural flaw.

## Why It Matters / Open Questions

The finding that a purely image-trained autoregressive model can generate coherent text (outperforming diffusion models on rich-text generation) suggests a pathway toward emergent vision-language understanding without explicit text supervision, though the evidence is limited to unconditional generation on relatively simple rendered-text and arXiv-page datasets. The 2D autoregression framework is a generalization that could accommodate non-Markov decompositions (e.g., diffusion-style), opening a new design space for AR image generation. A notable open question is why deeper codes reduce training cross-entropy but do not improve ImageNet generation fidelity, pointing to an unresolved sampling-space challenge. The practical efficiency gain—matching or exceeding larger models with the same sequence length—makes this architecture attractive for scaling AR image generation within existing LLM infrastructure.

## Problem

In multi-agent multi-task settings (e.g., SMACv2 with varying unit combinations and initial positions), agents must learn versatile policies that adapt to different task types through a single training process, yet no task ID is provided during training or execution. Existing task-division methods (roles, skills, subtasks) produce policies specialized to a single task and fail to generalize across heterogeneous task distributions. The paper asks: can agents autonomously recognize which task type they are experiencing from partial observations alone, and use that recognition to condition their action policy?

## Input / Output

Each agent consumes only its local partial observation o^i and a GRU-maintained observation history h^i; the VQ-VAE encoder additionally operates on global states s from the replay buffer. Outputs include per-agent trajectory-class predictions (a discrete class index at each timestep), a learned trajectory-class representation vector g^i (not a one-hot) that conditions the QPLEX action policy, and the resulting joint actions. Notably, the trajectory class is never given as a label—it is discovered unsupervised via periodic K-means clustering on quantized trajectory embeddings, and a lightweight classifier assigns labels to newly collected trajectories between clustering updates.

## Method

TRAMA has three coupled components. First, a modified VQ-VAE generates trajectory embeddings in a quantized latent space, where the coverage loss uses a trajectory-class-aware indexing function J(t,k) (instead of the timestep-only J(t) from LAGMA) to spread codebook vectors evenly across task-specific state distributions, preventing one task's states from monopolizing the embedding space. Second, periodic K-means clustering on trajectory embeddings (computed as the sum of quantized vectors along each episode) assigns pseudo-class labels, with centroid initialization from the previous clustering to maintain label consistency; a cross-entropy-trained classifier then labels new trajectories between clustering updates. Third, a shared GRU-based trajectory-class predictor lets each agent predict its current trajectory class from partial observations, and a learned representation model f_θ^g maps this prediction to a class-dependent vector g that is concatenated with the local observation as input to the QPLEX value-factorization policy. The overall training jointly optimizes the QPLEX loss and the predictor's cross-entropy loss, while VQ-VAE and the classifier are updated periodically in parallel.

## Results

On the SMACv2 multi-task benchmarks (p5_vs_5, t5_vs_5), TRAMA achieves the highest mean return among all baselines, outperforming memory-based methods like EMC and LAGMA. On the custom multi-task problems (SurComb3, reSurComb3, SurComb4, reSurComb4), TRAMA consistently yields the best overall return. In OOD generalization tests on SurComb4, TRAMA achieves a mean return of 3.063±0.489 on the in-distribution task and 2.706±0.461 on OOD(#1), compared to QPLEX's 2.323±0.119 and 2.248±0.471 respectively, and QMIX's 2.201±0.398 and 2.077±0.422. Agent-wise trajectory-class prediction accuracy reaches 93–97% by 5M environment steps on most multi-task settings.

## Baselines & Comparisons

TRAMA outperforms all nine baselines (QMIX, QPLEX, RODE, LDSA, MASER, EMC, LAGMA, Updet, RiskQ) on every multi-task problem in terms of mean return, which the authors argue is a more appropriate metric than win-rate for multi-task settings where policies may specialize on some tasks while failing on others. Against the strongest value-factorization baselines QMIX and QPLEX, TRAMA gains roughly 32% in relative return on the in-distribution SurComb4 task (3.063 vs. 2.323) and maintains a 20–35% return advantage across OOD tasks. Compared to task-division methods (RODE, LDSA, MASER), TRAMA's advantage is most pronounced on tasks with diverse unit combinations, where fixed role/subtask assignments cannot adapt to varying enemy compositions. Against memory-based approaches (EMC, LAGMA), TRAMA achieves higher returns with lower training time (15.1 h vs. 21.6 h for EMC on SurComb3). The gap narrows on OOD(#2) where unit combinations (5s, 5z, 5c) share no similarity with in-distribution tasks, confirming that TRAMA's gains depend on identifiable trajectory-class structure.

## Relation to Prior Work

TRAMA extends the task-division lineage in MARL (RODE, LDSA, HSD, HSL) by replacing explicit hierarchical role/skill assignment with an unsupervised trajectory-clustering mechanism in a VQ-VAE quantized latent space. It directly builds on LAGMA's VQ-VAE-for-MARL framework and its coverage loss, modifying the indexing function from J(t) to J(t,k) to account for trajectory-class structure in multi-task settings. The value factorization backbone is QPLEX, and the agent-wise trajectory-class predictor uses GRU-based observation history, positioning the method within the CTDE paradigm. Unlike prior multi-task RL where task ID is provided during training, TRAMA operates in an unsupervised setting where agents must infer the task type solely from partial observations.

## Why It Matters / Open Questions

The unsupervised multi-task MARL formulation (no task ID at training or execution) is practically relevant for scenarios like adversarial games where opponents' strategies are not labeled, and TRAMA provides a clean, modular pipeline (quantized embedding → clustering → class-aware policy) that addresses this gap. However, the approach is validated exclusively on StarCraft II-based environments with discrete actions, and the choice of n_cl (number of trajectory classes) remains a manual hyperparameter, though an adaptive Silhouette-based method is sketched. Open questions include scalability to continuous action spaces, larger agent counts, and task distributions where trajectory similarity does not align with unit-combination structure. The OOD results, while positive, show diminishing returns when task similarity is weak, suggesting the method's generalization is bounded by the quality of in-distribution clustering.

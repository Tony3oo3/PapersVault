## Problem

Conformal Prediction provides distribution-free coverage guarantees but is entirely agnostic to sensitive attributes, meaning its prediction sets can exhibit large disparities in coverage across demographic groups. Existing fairness methods for ML models largely focus on binary classification under IID assumptions and do not integrate with uncertainty quantification, leaving a gap for controlling fairness in conformal predictors—especially for non-IID data types like graphs where homophily exacerbates group-level bias.

## Input / Output

The framework consumes a calibration dataset, softmax logits from a trained base model (GNN or XGBoost), sensitive group labels, a user-specified closeness criterion c, and a search space Λ (defaulting to [q̂(α), max S_calib]). It outputs an optimal threshold λ_opt (or a vector of classwise thresholds) that, when applied to the non-conformity scores, yields conformal prediction sets satisfying both the 1−α coverage guarantee and the fairness closeness criterion simultaneously. A key design property is that group membership is only needed during calibration, not at inference time, making the framework applicable to streaming or privacy-sensitive settings where sensitive attributes are unavailable.

## Method

The CF Framework adapts split conformal prediction by filtering the calibration set per (group, positive label) pair using a metric-specific indicator function F_M, then searching over a threshold space Λ for the smallest λ whose inverse-quantile coverage (computed via Lemma 3.2) satisfies the pairwise group disparity bound c for all positive labels. Three theoretical lemmas underpin the approach: Lemma 3.1 guarantees conditional coverage on filtered subsets, Lemma 3.2 provides bounded intervals for the inverse quantile, and Lemma 3.3 extends coverage guarantees to fixed (non-true) labels—enabling fairness evaluation across all positive labels rather than just the ground truth. The framework is agnostic to the non-conformity score (TPS, APS, RAPS, DAPS, CFGNN) and leverages exchangeability rather than IID, extending applicability to graph node classification. For metrics like Predictive Parity that condition on set membership, the framework uses a proxy quantity or exploits Bayes' theorem to reduce the problem to controlling Equal Opportunity and Demographic Parity terms, with Theorem 3.4 establishing existence of a valid λ when c exceeds the maximum pairwise total variation distance of group-conditional label distributions.

## Results

On the Four-Fifths Rule (Disparate Impact, target ≥ 0.80), the CF Framework dramatically improves the base conformal predictor: on Credit, disparate impact rises from 0.252 (TPS) and 0.539 (DAPS) to 0.793 and 0.809 respectively, while on ACSIncome it rises from 0.356–0.397 to 0.790–0.798 across TPS, APS, and RAPS. For the Predictive Parity Proxy on ACSEducation, the CF Framework achieves worst-case disparities of 0.038–0.044 at c=0.05, well below the threshold, while the base conformal predictor averages 0.27–0.41. The efficiency cost is modest, e.g., prediction set size increases from 2.268 to 2.558 for TPS on Credit. When the base predictor is already fair (CFGNN on Credit, disparate impact 0.922), the CF Framework correctly reports no change.

## Baselines & Comparisons

The primary comparison is against the standard (unfair) conformal predictor using the same non-conformity score. The CF Framework consistently improves disparate impact to near or above the 0.80 Four-Fifths threshold across all datasets and score functions, with the largest gains on TPS (e.g., 0.252→0.793 on Credit, 0.356→0.798 on ACSIncome). The only external method compared is BatchGCP (Jung et al., ICLR 2023), a batch multivalid conformal prediction approach. On Disparate Impact, the CF Framework substantially outperforms BatchGCP: 0.781 vs. 0.576 on ACSEducation and 0.797 vs. 0.349 on ACSIncome, while BatchGCP even underperforms the base APS predictor on ACSIncome (0.349 vs. 0.397). The CF Framework also matches the base predictor when it is already fair (CFGNN on Credit), demonstrating its utility as a fairness auditing tool. A key practical advantage over BatchGCP is that the CF Framework does not require group membership at inference time, whereas BatchGCP's group-dependent threshold function necessitates it.

## Relation to Prior Work

This paper extends the split conformal prediction framework of Vovk et al. (2005) by replacing the standard quantile-based threshold with a fairness-aware threshold search over a user-specified search space Λ. It builds on the conditional coverage guarantees of Ding et al. (2024), which provided only an upper bound, by establishing both upper and lower bounds (Lemma 3.1) necessary for controlling pairwise coverage gaps. The framework departs from prior fairness-in-CP work (Wang et al. 2024, Lu et al. 2022, Liu et al. 2022) in three key ways: it targets classification rather than regression, supports multiple fairness metrics simultaneously rather than a single one, and critically does not require group membership at inference time. By leveraging exchangeability rather than IID, it also extends applicability to graph data via GNN-based conformal predictors (CFGNN, DAPS), a setting where most prior fairness methods are inapplicable.

## Why It Matters / Open Questions

The CF Framework bridges two previously separate concerns—uncertainty quantification and algorithmic fairness—providing a single post-hoc procedure that simultaneously guarantees coverage and controls fairness disparity, which is essential for high-stakes deployments in finance and healthcare. The finding that group-conditional coverage (as provided by BatchGCP) does not imply fairness (disparate impact of 0.349 vs. 0.797 for CF on ACSIncome) is a useful cautionary result for practitioners conflating these guarantees. Key limitations include the efficiency cost of fairness control (larger prediction sets), the data requirements for intersectional fairness (calibration subsets can fall below the recommended 1000 points), and the current restriction to classification tasks. Open questions include extending the framework to regression, relaxing the exchangeability assumption for truly non-exchangeable settings, and understanding the fundamental trade-off frontier between coverage, fairness, and efficiency.

## Problem

Existing Data-Free Knowledge Distillation methods rely on BatchNorm layer statistics to guide synthetic image generation, but CLIP's BN statistics are biased toward facial features due to its web-crawled pre-training data, causing these methods to produce corrupted, class-irrelevant images. This makes it impossible to distill compact, deployable models from CLIP without access to the original training data, blocking open-vocabulary customization for edge devices.

## Input / Output

The method takes either arbitrary class texts (e.g., 100+ category names) or K-shot example images per class (4 images) as user-specified customization requests, combined with a frozen pre-trained CLIP (ViT-B/32 + 12-layer text encoder). It produces a lightweight student model (ResNet-18, 11.68M parameters, 1.82 GFLOPs) that omits the text encoder entirely and outputs class labels at inference time. Synthetic images are generated at 224×224 resolution via VQGAN latent optimization, with 64 images per class for text-based and 24 additional images per class for image-based customization.

## Method

The core inversion replaces BN-based regularization with image-text matching: latent codes z are optimized through a VQGAN decoder to minimize the angular distance between CLIP's image embedding of G(z) and the target text embedding, avoiding the unusable BN statistics entirely. Style dictionary diversification introduces 16 real-world style terms as prompt templates with learnable style tokens optimized via instance-level contrastive learning, enhancing synthetic image diversity while preserving photo-realism. A class consistency maintaining loss (multi-class cross-entropy using CLIP text embeddings as a classifier) anchors each synthetic image to its correct class, preventing style-induced semantic drift. For distillation, meta knowledge distillation (MAML-style) holds out one style as a virtual test set each iteration, encouraging gradient alignment across styles so the student learns style-agnostic representations. For image-based customization, class prototypes (mean embeddings of few example images) guide inversion to reduce intra-class variance, effectively using CLIP's knowledge to expand the training distribution toward the testing distribution.

## Results

On 11 customized tasks (Caltech-101 + 10 ImageNet splits), the proposed method achieves 64.59% average top-1 accuracy using a CLIP-pretrained ResNet-50 teacher, compared to 7.13% (DeepInversion), 7.63% (CMI), and 6.66% (Fast) for existing DFKD methods with the same CLIP teacher — a 9.33% improvement over the best DFKD baseline. The student model (ResNet-18) reduces parameters from 151.28M to 11.68M and GFLOPs from 14.78 to 1.82 relative to CLIP. For image-based customization with 4 example images per class, the method achieves 84.78% on Caltech-101 and 74.54% on ImageNet, surpassing real-data augmentation (83.13% and 72.88%).

## Baselines & Comparisons

All three existing DFKD methods (DeepInversion, CMI, Fast) catastrophically fail when applied to a CLIP-pretrained teacher, achieving only single-digit accuracies (6.66%–7.63% average) because they rely on BatchNorm statistics that are corrupted by facial features in CLIP's web-crawled training data. The proposed method achieves 64.59% average accuracy with the same CLIP teacher, a 57+ point improvement over all DFKD baselines. Even compared to the best DFKD variant using an ImageNet-pretrained teacher (Fast-IN at 55.26%), the proposed method gains 9.33 points while using the more powerful CLIP teacher. Against LP-CLIP (a consistency-loss-based distillation approach), the proposed method achieves 63.39% vs. 62.57% average across 5 tasks, showing a modest but consistent edge in generalization. The paper also demonstrates that the approach generalizes across architectures (ViT-T, RN18 students; RN50, ViT-B teachers) and other VLMs (EVA achieves 66.56% vs. CLIP's 63.60% vs. BLIP's 56.39%).

## Relation to Prior Work

This paper extends Data-Free Knowledge Distillation (DFKD) from the fixed-label, BN-regularized paradigm (DeepInversion, CMI, Fast DFKD) to the open-vocabulary CLIP setting, where target classes are specified by arbitrary text prompts or few example images rather than indices in a classifier's label space. The key conceptual departure is replacing BN-statistic-based model inversion with image-text matching in CLIP's shared embedding space, motivated by the discovery that CLIP's BN layers encode facial features from web-crawled data and are therefore unusable as a distributional prior. The meta knowledge distillation component draws on meta-learning for domain generalization (Li et al., 2018), while the style dictionary diversification builds on prompt diversification strategies from Xuan et al. (2023) and the VQGAN latent-space optimization from Crowson et al. (2022).

## Why It Matters / Open Questions

The practical impact is significant: users can obtain a lightweight ResNet-18 (11.68M params, 1.82 GFLOPs) that performs inference without a text encoder, enabling edge deployment for arbitrary user-specified classes without access to original training data. The discovery that CLIP's BN statistics are fundamentally misaligned with target class distributions (encoding faces instead) is an important negative result that explains why the entire DFKD literature has been inapplicable to VLMs. Open questions remain around text ambiguity for fine-grained or specialized classes (where CLIP inversion produces incorrect content), scalability to very large class sets, and whether the approach transfers to newer VLMs with stronger alignment. The 9.33% average improvement over prior DFKD methods across 12 tasks is well-evidenced but the absolute gap to CLIP's zero-shot performance (~20%) highlights that synthetic data still cannot fully capture real-world distributional complexity.

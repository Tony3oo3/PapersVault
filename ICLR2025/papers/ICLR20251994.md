## Problem

Existing EEG foundation models such as LaBraM and BIOT require full fine-tuning on each downstream task individually, confining the model to a single task and demanding substantial computational and storage resources. No unified model exists that can handle diverse EEG tasks (abnormal detection, emotion recognition, sleep staging, etc.) within a single architecture through instruction-based prompting, as has been achieved in the NLP and vision-language domains.
![Teaser figure](../imgs/ICLR20251994/cropped_page0_idx0.webp)

## Input / Output

The model takes multi-channel EEG signals (4–64 channels, 160–2048 Hz, resampled to 200 Hz) patchified into non-overlapping 1-second windows, which are encoded into discrete neural tokens by a frozen VQ encoder and prepended to a text instruction (e.g., 'Which sleep type does this EEG segment belong to?'). A [SEP] token marks the modality boundary between EEG tokens and text. The output is an autoregressively generated text answer (e.g., '(D)' or 'Yes'), with loss computed only on the answer span to stabilize prediction.

## Method

NeuroLM integrates EEG into a GPT-2-based LLM through three stages. First, a text-aligned neural tokenizer (VQ-VAE with 8192×128 codebook) is trained via vector-quantized temporal-frequency prediction—reconstructing both the raw signal and DFT-derived frequency magnitude—while a gradient-reversal domain classifier adversarially aligns EEG embeddings into the text embedding space. Second, the frozen VQ encoder produces EEG tokens that are added to the LLM vocabulary; multi-channel autoregressive pre-training on ~25,000 hours of EEG data uses a stair-stepping attention mask so each token attends to all channels at the current and previous time steps, learning causal cross-channel dependencies. Third, multi-task instruction tuning jointly fine-tunes the model on six downstream tasks with task-specific prompts, preserving language capability by mixing in text data each iteration.

## Results

NeuroLM-B (254M params, multi-task) achieves Balanced Accuracy of 0.7826 on TUAB, 0.4560 on TUEV, 0.5554 on SEED, 0.6737 on HMC, 0.6172 on Workload, and 0.6734 on TUSL. The largest variant NeuroLM-XL (1.7B params) improves to 0.7969 on TUAB and 0.6845 on TUSL. While NeuroLM remains below the single-task SOTA LaBraM-Base on most tasks (e.g., 0.7826 vs. 0.8140 Balanced Acc. on TUAB; 0.5554 vs. 0.7318 on SEED), it is the first model to handle all six tasks within a single architecture via instruction tuning, and it outperforms most other single-task baselines on several datasets.

## Baselines & Comparisons

NeuroLM-B trails the single-task SOTA LaBraM-Base on all six datasets (e.g., 0.7826 vs. 0.8140 Balanced Acc. on TUAB; 0.5554 vs. 0.7318 on SEED; 0.6734 vs. 0.7625 on TUSL), which is expected given LaBraM is fine-tuned per task. Against BIOT, NeuroLM-B is competitive on HMC (0.6737 vs. 0.6862 Balanced Acc.) and TUSL (0.6734 vs. 0.5758), where it actually outperforms BIOT by ~10 points on TUSL. NeuroLM-B clearly beats the weaker supervised baselines (SPaRCNet, ContraWR, CNN-Transformer, FFCL, ST-Transformer) on TUSL (0.6734 vs. 0.4185–0.5857) and is competitive on HMC (0.6737 vs. 0.2559–0.6573). On Workload, however, NeuroLM-B (0.6172) underperforms FFCL (0.7069) and ContraWR (0.6966), suggesting the small dataset (2,088 samples) limits the multi-task model. The paper notes that direct comparison is not entirely fair since baselines are single-task, and NeuroLM's key advantage is unifying all six tasks in one model without per-task fine-tuning.

## Relation to Prior Work

NeuroLM builds directly on LaBraM's neural tokenizer (which encodes EEG into discrete codes via VQ-VAE) and BIOT's channel-unification strategy, but departs fundamentally by routing these EEG tokens into a pretrained LLM (GPT-2) rather than a standalone transformer. The multi-channel autoregressive pre-training with stair-stepping masks is a novel adaptation of causal language modeling to multi-channel signals, and the adversarial domain-classifier alignment (inspired by DANN) replaces the CLIP-style contrastive alignment used in vision-language MLLMs, since no large-scale EEG-text pairs exist. The instruction-tuning stage draws on the LLaVA/MiniGPT-4 paradigm of multimodal LLMs, repurposing it for the EEG modality for the first time.

## Why It Matters / Open Questions

This is the first demonstration that a single EEG model can handle six heterogeneous downstream tasks (abnormality detection, event classification, emotion, sleep staging, workload, slowing) through natural-language instructions, eliminating the need for per-task fine-tuning and reducing resource waste. However, NeuroLM still trails the single-task SOTA (LaBraM) on most benchmarks, and the authors acknowledge that coarse-grained space-wise alignment, hyperparameter sensitivity, and the use of a small base LLM (GPT-2) limit current performance. Open questions include whether finer-grained EEG-text alignment (e.g., contrastive losses with descriptive captions), more capable base LLMs (LLaMA 3), and mixture-of-experts architectures can close the gap to single-task methods while preserving multi-task generality.

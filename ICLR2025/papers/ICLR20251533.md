## Problem

In MCTS-based neural theorem proving, language models generate large numbers of semantically redundant tactics that inflate search costs through ineffective exploration, while the trained value function is biased by false negatives, severe label imbalance, and a domain gap between training (e.g., Mathlib) and test (e.g., IMO-level) data. These two issues jointly degrade both the exploration efficiency and exploitation accuracy of the tree search.

## Input / Output

The method consumes a Lean4 proof state (current goal plus hypotheses) as a textual string, which is both fed to a language model for tactic generation and encoded by a frozen sentence encoder (e5-small-v2) for next-state similarity comparison. The output is a complete formal proof as a sequence of verified Lean4 tactics, discovered through iterative tree search with a fixed expansion budget (e.g., 64×100 or 32×300 tactic generations). Only tactics that pass Lean's type-checker are expanded into the search tree, and the final proof is extracted from the root-to-leaf path reaching the proved state.

## Method

CARTS modifies MCTS in two ways. First, during the expansion phase, it applies Maximal Marginal Relevance (MMR) to reorder and rescore candidate tactics: each tactic's score is λ·v_policy(s,a) − (1−λ)·max similarity between its next state and already-selected next states, where v_policy is a length-penalized model confidence and similarity is computed via a frozen sentence encoder on textualized proof states; the top-k tactics are expanded with their MMR scores as WUCB exploration weights. Second, the value function is trained with the Bradley-Terry preference model on filtered preference pairs (negative samples whose next-state embedding exceeds a similarity threshold τ=0.85 relative to the correct next state are discarded), and at inference an adjustment term α = e/E (ratio of valid to total generated tactics) is blended into the value estimate to adapt to the test distribution. The value network is a 1.3B-parameter Phi-1.5 model fine-tuned with LoRA for one epoch.

## Results

CARTS achieves a pass@1 rate of 49.6% on the miniF2F-test benchmark using StepProver (7B) with a 32×300 sample budget, representing state-of-the-art performance among one-step tree search methods. On the more challenging ProofNet benchmark, CARTS achieves 18.8% pass@1 with StepProver and 11.9% with Reprover-Lean4. Across all three policy models tested (Reprover-Lean4 229M, InternLM2-Math-Plus-1.8B, StepProver 7B), CARTS consistently outperforms BFS, MCTS, and DT-Solver under identical budgets.

## Baselines & Comparisons

CARTS is compared against BFS, MCTS, and DT-Solver under identical policy models and budgets. With StepProver (7B), CARTS achieves 49.6% pass@1, outperforming BFS (48.8%), MCTS (46.7%), and DT-Solver (46.3%) by 0.8, 2.9, and 3.3 percentage points respectively. With InternLM2-Math-Plus-1.8B, CARTS reaches 41.0%, beating BFS (38.9%), MCTS (39.3%), and DT-Solver (38.5%) by 2.1, 1.7, and 2.5 points. With the smaller Reprover-Lean4 (229M), CARTS achieves 37.7% versus BFS (35.7%), MCTS (36.5%), and DT-Solver (36.0%). Against broader baselines using different models, CARTS with StepProver (49.6%) surpasses InternLM2-Math-Plus-7B with BFS (43.4%) and all other single-model baselines, though it remains below the multi-step DeepSeek-Prover-V1.5 methods (53.5–55.0%) which use a fundamentally different search paradigm. On ProofNet, CARTS similarly leads: 18.8% vs. BFS (18.1%) and MCTS (18.3%) for StepProver, and 11.9% vs. BFS (11.1%) and MCTS (11.7%) for Reprover-Lean4.

## Relation to Prior Work

CARTS is positioned as a methodological refinement of MCTS-based neural theorem proving, directly modifying DT-Solver's WUCB selection mechanism by replacing language-model probability weights with MMR-calibrated importance-diversity scores. The diversified tactic calibration repurposes the Maximal Marginal Relevance algorithm from information retrieval to reorder and penalize semantically redundant LLM-generated tactics, while the bias-resistant value function adapts the Bradley-Terry preference model (previously used in LLM alignment) to address class imbalance and false negatives in value network training. Unlike prior work that treats the policy model's output as a fixed input to search, CARTS intervenes at the expansion stage to actively reshape the candidate action set before tree growth.

## Why It Matters / Open Questions

CARTS demonstrates that search-stage improvements alone—without modifying the underlying policy model—can yield consistent gains across multiple architectures and benchmarks, achieving 49.6% pass@1 on miniF2F-test as the best one-step tree search method. The practical relevance is high for teams using existing theorem-proving LLMs who want to improve search efficiency without retraining. However, the method is limited to one-step tree search and cannot be integrated into multi-step approaches like DeepSeek-Prover-V1.5, which already surpasses CARTS (55% vs 49.6%). An open question is whether the MMR-based diversity calibration and the α-adjustment term generalize to multi-step or whole-proof generation settings, and whether the simple e/E ratio heuristic can be replaced by a learned test-time adaptation.

## Problem

Monolithic LLMs suffer from a fundamental trade-off: specializing on one domain (e.g., math) degrades performance on others (e.g., coding, knowledge), and effective specialization typically requires expensive human-annotated data. The paper asks how to build compositional LLMs that enjoy versatile, non-compromising expertise across multiple domains while using minimal resources—no large labeled datasets, no teacher models, and no significant parameter overhead.
![Teaser figure](../imgs/ICLR20251236/cropped_page1_idx1.webp)

## Input / Output

The method takes a frozen base LLM (e.g., Gemma-7B) and only 100 seed instruction-response pairs per target domain as the sole human-provided input. From these seeds, the base LLM self-generates ~5K synthetic instruction-response pairs per domain (20K total). At inference, the compositional model MiXSE receives a text instruction and produces a text response, with a shared linear router computing per-token top-k expert selection weights (over 4 LoRA adapters) that determine which domain-specific delta is applied at each layer. Total added parameters are ~1% of the base model, with only 0.3% active per token under Top-1 routing.

## Method

Self-MoE operates in two phases. First, for each target domain (knowledge, reasoning, math, coding), it performs self-specialization: the base LLM generates diverse synthetic instructions via in-context brainstorming from seeds, generates corresponding responses using seed pairs as demonstrations, and then trains a lightweight LoRA adapter (rank 8) on that synthetic data, yielding a frozen expert module ΔΘᵢ. Second, all experts are integrated into MiXSE with a single shared linear router θᵣ ∈ ℝ^{n×k} that computes top-k softmax weights per token, dynamically selecting which LoRA deltas to apply at each layer (h = θ₀x + Σ αᵢ Δθᵢx). The router is trained separately after experts are frozen, using the aggregated synthetic data with standard next-token prediction loss, learning routing implicitly from response quality rather than explicit expert labels. This separation preserves each expert's semantic identity, and the intact base weights θ₀ mitigate catastrophic forgetting—key distinctions from static merging methods (TIES, DARE, instance merging) that collapse all expertise into fixed parameters.

## Results

On Gemma-7B, MiXSE achieves an average of 54.3 across MMLU (65.6), BBH (61.1), GSM8K (52.5), and HumanEval (37.8), a +6.5 percentage-point improvement over the base LLM (47.8). MiXSE outperforms all four individual self-specialized models (which range from 43.6 to 51.1 average) and all merging baselines (Instance Merging 52.4, TIES 47.9, DARE 44.3). The modular design avoids the specialization trade-off: individual experts degrade non-target domains (e.g., Knowledge Self-Spec drops BBH from 56.1 to 41.7), while MiXSE improves or maintains performance on every domain simultaneously.

## Baselines & Comparisons

MiXSE (54.3 avg) outperforms all four individual Self-Specialization models [Kang et al., 2024] (43.6–51.1 avg), which each improve their target domain but degrade others (e.g., Knowledge Self-Spec drops BBH by 14.4 points). Against Instance Merging [Chung et al., 2024] (52.4 avg), MiXSE gains +1.9 points on average, with the largest gap on MMLU (+3.0) and BBH (+3.5). TIES [Yadav et al., 2023] (47.9) and DARE [Yu et al., 2024] (44.3) both underperform the base LLM on average, with DARE catastrophically failing on MMLU (37.7 vs. 58.4). In indirect comparisons (Table 7), MiXSE substantially outperforms pre-training MoE methods BTM [Li et al., 2022] (44.3 MMLU), Sparse Upcycling [Komatsuzaki et al., 2023] (52.1 MMLU), and BTX [Sukhbaatar et al., 2024] (52.5 MMLU) while using ~1 GPU-day vs. 900 GPU-days. MiXSE also surpasses LoRA-based MoE methods PHATGOOSE [Muqeeth et al., 2024] (35.6 BBH) and MOLE [Wu et al., 2024] (42.2 BBH) on reasoning. MiXSE does not match Mixtral 8x7B [Jiang et al., 2024] (70.6 MMLU, 67.1 BBH), but Mixtral has 47B total parameters vs. MiXSE's 7B+1%, and its experts are implicit rather than semantically interpretable. Distillation-based methods GLAN [Li et al., 2024a] and Orca-2 [Mitra et al., 2023] achieve higher scores but rely on GPT-4 as a teacher with 10M+ data points, a resource assumption Self-MoE explicitly avoids.

## Relation to Prior Work

This paper extends the self-specialization framework (Kang et al., 2024), which aligns a base LLM with self-generated synthetic data to create domain-specific LoRA adapters, by composing multiple such adapters into a dynamic Mixture-of-Experts system (MiXSE) with a learned router. It departs from prior MoE-with-LoRA work (MOLE, PHATGOOSE) that either requires human-labeled data or assumes externally trained expert modules, and from static merging methods (TIES, DARE, instance merging) that produce fixed parameters, by constructing all experts and the router from scratch via self-training with only ~100 seed examples per domain. The routing mechanism draws conceptually from Switch Transformer and Mixtral but operates at the LoRA-adapter level rather than the FFN level, keeping added parameters to ~1% of the base model.

## Why It Matters / Open Questions

The paper addresses a practical pain point: monolithic specialization of LLMs typically degrades performance on non-target domains (catastrophic forgetting), and existing remedies (distillation from larger models, extensive human annotation) are resource-prohibitive. Self-MoE offers a lightweight, self-contained alternative that is applicable to any base LLM family with minimal overhead, making it a practical tool for practitioners who need multi-domain capability without retraining from scratch. Open questions include whether the approach scales gracefully to many more experts (beyond four), how data quality degrades for weaker base models (observed with LLaMA-2), and whether the self-generated synthetic data introduces subtle biases that n-gram overlap checks cannot fully capture.

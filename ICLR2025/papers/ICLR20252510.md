## Problem

Modern text-to-image diffusion models can render high-quality visual text, yet it remains unknown which specific parameters within these complex architectures are responsible for generating that text. Prior interpretability work on diffusion models localized objects, styles, or memorized training samples, but did not identify the minimal set of layers controlling textual content. Without this localization, fine-tuning for text quality, targeted text editing, and on-the-fly toxic text suppression all require modifying or monitoring the entire model.

## Input / Output

The localization procedure takes a pair of source and target prompts (identical except for the text keyword) and produces a small set of cross- or joint-attention layer indices (3 for SDXL, 1 for DeepFloyd IF, 1 for SD3). For the editing application, the method consumes a source prompt and a target prompt at inference time and outputs a single edited image where only the rendered text changes while the background is preserved. For toxic text prevention, a single toxic prompt is the sole input and the output is a generation with the harmful text replaced by a placeholder, requiring no additional forward pass. The fine-tuning variant additionally consumes ~74k images from MARIO-LAION with OCR-derived captions and outputs LoRA weights applied exclusively to the localized layers.

## Method

The core technique is activation patching adapted to both standard cross-attention (SDXL, DeepFloyd IF) and joint-attention (SD3) architectures. For each candidate layer, the method first runs a full denoising pass with the target prompt, caching only the text-specific components of the key and value matrices (i.e., the projections of the textual part of the residual stream). It then regenerates the image from the source prompt while overwriting only those text K/V components at the candidate layer, measuring OCR F1 (text alignment) and SSIM (image alignment) to score the layer's contribution. Layers whose patching shifts the rendered text toward the target while preserving the background are selected, yielding fewer than 1% of total model parameters. The approach is architecture-agnostic because it always isolates the text portion of the residual stream regardless of whether K/V are formed from text-only embeddings (cross-attention) or concatenated image+text projections (joint attention). Downstream applications exploit this localization: LoRA fine-tuning restricted to the identified layers improves text quality without mode collapse, selective KV patching enables single-pass text editing that outperforms Prompt-to-Prompt, and on-the-fly substitution of toxic text in only the localized layers prevents harmful text generation at zero additional computational cost.

## Results

On the text editing task (Table 3), the proposed patching method outperforms Prompt-to-Prompt (P2P) across all three diffusion models. On SDXL, the LoRA-enhanced variant achieves OCR F1 of 0.43 and SSIM of 0.90 on SimpleBench, versus P2P's 0.29 and 0.82, while running 3× faster (10.4s vs 31.2s per image). On DeepFloyd IF, the method reaches OCR F1 of 0.70 and SSIM of 0.63, compared to P2P's 0.27 and 0.41. For toxic text prevention (Table 4), the method achieves toxicity scores of 0.003–0.018 while preserving image alignment (SSIM 0.61–0.79), whereas Negative Prompt and Safe Diffusion fail to remove toxic content (toxicity scores 0.05–0.57).

## Baselines & Comparisons

Against Prompt-to-Prompt (P2P, Hertz et al. 2023), the proposed method wins decisively on text alignment (OCR F1) across all three models: 0.34 vs 0.29 on SDXL, 0.70 vs 0.27 on DeepFloyd IF, and 0.68 vs 0.31 on SD3 (SimpleBench). The method also preserves image structure better on DeepFloyd IF (SSIM 0.63 vs 0.41) and runs 2–8× faster (10–15s vs 28–118s). The modified P2P* variant, which patches only textual components of keys, improves P2P's text alignment on SD3 (OCR F1 0.90) but at the cost of severe image degradation (SSIM drops to 0.58). For toxic text prevention, both Negative Prompt and Safe Diffusion (including its adapted Safe Diffusion* variant) are unable to remove toxic words from generated images, yielding toxicity scores of 0.05–0.57, while the proposed method achieves near-zero toxicity (0.003–0.018) with minimal visual disruption. Prompt Swap achieves comparable toxicity removal but with substantially worse image alignment (e.g., MSE 98.58 vs 72.61 on SD3; SSIM 0.51 vs 0.70), confirming that patching only localized layers is critical for preserving non-textual content.

## Relation to Prior Work

This paper extends the activation patching technique from Meng et al. (2022) and the causal-tracing-based knowledge localization framework of Basu et al. (2024a) to the specific target of textual content generation in diffusion models. The key methodological departure is adapting the patching procedure to joint attention architectures (SD3, FLUX), where text and image representations are entangled in the same Q/K/V projections, whereas prior work only handled standard cross-attention with static text embeddings. The paper also broadens the application scope beyond mere localization to downstream tasks—LoRA fine-tuning of localized layers, targeted text editing, and on-the-fly toxic text suppression—that prior localization work did not explore.

## Why It Matters / Open Questions

The finding that fewer than 1% of parameters (as few as a single attention layer) govern all visual text generation has direct practical value: it enables dramatically cheaper fine-tuning for text quality, surgical text editing without disturbing other image attributes, and zero-overhead content moderation for deployed models. A notable limitation is that text *style* (handwritten, neon, graffiti) is not localized to the same layers but is distributed across at least 7 of 24 layers in SD3, so the method cannot be trivially extended to style control. Open questions include whether the same concentration pattern holds for other generation capabilities (objects, composition), whether the localized layers remain stable after further fine-tuning or model updates, and how the approach generalizes to multilingual or script-diverse text rendering.

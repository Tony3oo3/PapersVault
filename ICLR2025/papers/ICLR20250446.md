## Problem

The MTOB benchmark (Tanzer et al., 2024) claimed that prompting long-context LLMs with a single grammar book enables translation of an unseen extremely low-resource language, but it never disentangled whether the grammatical explanations or the parallel examples embedded in the book actually drive performance. This paper asks whether LLMs can genuinely exploit free-form grammatical descriptions for machine translation, and if not, what form of grammatical knowledge and which tasks do benefit from it.

## Input / Output

The method takes source sentences in XLR languages (Kalamang, Nepali, Guarani) and produces target-language translations scored with CHRF++, binary grammaticality judgments (original vs. corrupted sentence), or morpheme-aligned interlinear glosses. Grammar books are manually filtered into parallel glossed example subsets (~18k tokens for Kalamang) and explanatory text subsets (~81k tokens), with the full book consuming ~100k tokens of in-context window. The typological feature prompt encodes ~100 categorical features per language from Grambank as structured text with feature IDs, codes, and short descriptions, replacing free-form grammatical prose.

## Method

The core contribution is a novel ablation that manually separates grammar books into parallel glossed examples (BOOK_para) and grammatical explanations (BOOK_non-para), then tests Gemini-1.5-Flash (1M context) and Llama-3.1-8B with each subset independently across three tasks: translation, grammaticality judgment, and IGT prediction. They introduce a typological feature prompt constructed from Grambank specifications as a structured, language-invariant alternative to free-form grammatical descriptions, hypothesising that explicit categorical features (e.g., word order rules) reduce the LLM's reasoning burden. For comparison, they fine-tune NLLB-1.3B and Llama-3.1-8B (LoRA, 5 epochs) on the extracted parallel data, showing a small specialist MT model matches or beats LLM prompting within 0.2 CHRF++. Statistical regression analysis demonstrates that translation CHRF++ scores are directly modelled by test-set vocabulary coverage in the prompt (R²=0.84–0.87, p<0.005), not by prompt length or grammatical content, confirming that parallel examples—not explanations—drive translation quality. The typological prompt achieves leading results on grammaticality judgment (+3% over BOOK_para) and IGT prediction (46.1% morpheme accuracy, beating all supervised baselines), confirming LLMs can exploit grammatical knowledge when it is task-appropriate and properly formatted.

## Results

For eng⇔kgv translation with Gemini, the grammar book's parallel sentences (BOOK_para) score 30.8/34.7 CHRF++ (eng-kgv/kgv-eng), while the grammatical explanations alone (BOOK_non-para) score only 22.6/27.5, an 8-point gap showing explanations add no significant value. Fine-tuning NLLB-1.3B on the book's parallel data achieves 34.2/28.6 CHRF++, beating Gemini's in-context PARA_book (26.6/33.1) by up to 7.6 points into kgv. For IGT prediction, the novel typological prompt (TYP+BOOK_para) reaches 46.1% morpheme accuracy, surpassing the best supervised baseline (SMP-BASE at 45.2%) and the full grammar book (40.1%) by 6 points. Results generalise to Nepali and Guarani, where BOOK_para matches or outperforms BOOK_all by up to 4 CHRF++.

## Baselines & Comparisons

Against the 0-SHOT baseline (11.0/12.7 CHRF++), all book-based settings improve substantially, confirming the book provides useful signal—but the paper shows this signal comes almost entirely from parallel sentences rather than grammatical explanations. Compared to the MTOB 5*-SHOT retrieval baseline (38.9 eng-kgv), the full PARA_book prompt (26.6) underperforms, yet PARA_book + PARA_train (40.7) surpasses it, indicating that more parallel data is more effective than retrieval-based selection. The critical comparison is BOOK_para (30.8) vs. BOOK_non-para (22.6) for eng-kgv: removing parallel examples costs 8+ points, while adding explanations to parallel data yields only +0.7 CHRF++, and a regression analysis (R²=0.84, p<0.005) shows the small BOOK_all advantage over BOOK_para is fully explained by increased test-set type coverage. Fine-tuned NLLB (34.2 eng-kgv) outperforms Gemini in-context with the same PARA_book data (26.6) by 7.6 points, demonstrating that a 1.3B encoder-decoder model fine-tuned for 1 hour on a single GPU matches or exceeds a 1M-token-context LLM. For IGT prediction, TYP+BOOK_para (46.1% morpheme accuracy) beats all five supervised baselines—TOP-CLASS (44.0%), SMP-BASE (45.2%), TüCL-MORPH (43.6%), BYT5-FT (40.8%), and GLOSSLM-FT (43.8%)—by 1–5 points, while BOOK_non-para collapses to 21.0%, confirming that grammatical explanations in free-text form are not exploitable by LLMs even for grammar-focused tasks.

## Relation to Prior Work

This paper is a direct critical follow-up to Tanzer et al. (2024, ICLR), which claimed that long-context LLMs can learn to translate the unseen XLR language Kalamang from a single grammar book. The authors disentangle the book's parallel examples from its grammatical explanations via a novel ablation, and further position their work within the broader literature on incorporating linguistic knowledge (typology, grammar, morphology) into NLP models. They introduce a typological feature prompt drawn from Grambank as a language-invariant alternative to free-form grammar text, and connect to the IGT prediction literature (SIGMORPHON shared task) to test whether grammar helps on more linguistically-aligned tasks.

## Why It Matters / Open Questions

The paper challenges a widely-cited ICLR 2024 result by showing that grammatical explanations contribute no significant advantage over the parallel sentences already embedded in grammar books, with translation performance statistically modelled by test-set type coverage alone. Practically, it redirects XLR data-collection efforts toward parallel data (cheaper, more token-efficient, enabling small fine-tuned MT models that match long-context LLMs) rather than linguistic description. Open questions include whether findings generalise beyond the three tested languages and the single long-context model (Gemini-1.5-Flash), whether the 100-example kgv test set is sufficient for strong conclusions, and whether typological prompting can be extended to other linguistic tasks or larger model families.

## Problem

Generating a series of illustrative images for long-horizon tasks (e.g., multi-step recipes) is challenging because naive text-to-image generation produces images with inconsistent object appearances, incorrect attributes (color, state, shape), and hallucinated objects. Existing methods either over-constrain visual consistency so that all steps look nearly identical, or under-constrain it so that logically connected steps appear unrelated. Moreover, attribute errors accumulate across steps, degrading later images in long sequences.

## Input / Output

The method takes a sequence of natural-language step descriptions (averaging 9.8 steps, ranging 6–17) for a single task and produces one RGB image per step using a frozen SDXL diffusion model. No training or fine-tuning is required; the system operates entirely at inference time by combining GPT-4O reasoning, KV-sharing attention for visual continuity, and a suite of editing tools. The generated images are expected to balance visual continuity between logically connected steps with appropriate visual change at step boundaries, matching human-annotated ground-truth descriptions of what each step's illustration should depict.

## Method

LIGER is a training-free, step-by-step pipeline with three components. First, a history-aware draft generator uses an LLM to produce a historical prompt (specifying which objects from prior steps must appear) and injects the previous step's latent feature tokens into the U-Net self-attention via KV-sharing (inspired by StoryDiffusion), yielding a draft image with visual continuity. Second, a tool-based self-reflection module uses GPT-4O as a multimodal error detector to identify four error types—over-consistency, identity inconsistency, wrong attributes, and redundant objects—and dispatches the appropriate editing tool (regeneration, DragonDiffusion for identity alignment, SD inpainting for attribute correction, or LAMA for object removal); a referee then selects the better of the draft and revised images. Third, an inversion-guided memory calibration step applies DDIM inversion on the final revised image to recover updated latent feature tokens, ensuring that corrected visual state propagates to subsequent steps rather than letting errors accumulate.

## Results

On the curated 569-task long-horizon benchmark, LIGER achieves a CLIP-Score of 2.7555 (vs. 2.5054 for SLDM and 2.4350 for T2I-Bridge), a DINO-Score of 0.6338 (lower is better; SLDM: 0.6746, T2I-Bridge: 0.8576), and a BERT-Score of 0.8743. Under GPT-4O evaluation (1–5 scale), LIGER scores 4.11/5 on semantic alignment, 3.06/5 on logic, and 3.05/5 on illustrativeness, outperforming both baselines by 0.5–1.6 points. In the user study, LIGER is preferred 64.3% of the time for semantic matching, 60.7% for logic continuity, and 68.3% for overall illustrativeness.

## Baselines & Comparisons

LIGER is compared against two baselines: T2I-Bridge (Lu et al., 2023), a re-captioning method that uses an LLM to imagine what each step image should depict, and SLDM (Bordalo et al., 2024), which trains a language model to produce coherent captions and uses a sequential context decoder for visual continuity. LIGER outperforms both on every reported metric. Against T2I-Bridge, the gains are largest on DINO-Score (0.6338 vs. 0.8576, a 26% relative reduction) and GPT semantic alignment (4.11 vs. 3.47), reflecting T2I-Bridge's lack of visual continuity across steps. Against SLDM, LIGER leads on CLIP-Score (2.7555 vs. 2.5054) and GPT illustrativeness (3.05 vs. 2.58), while SLDM's DINO-Score (0.6746) is closer to LIGER's, suggesting SLDM handles step-to-step consistency reasonably well but still produces over-consistent images that fail to capture state changes. In the user study, LIGER is preferred over SLDM by a wide margin (64.3% vs. 11.7% for semantic, 60.7% vs. 21% for logic, 68.3% vs. 9.3% for illustrativeness), and over T2I-Bridge by a similar margin (64.3% vs. 24%, 60.7% vs. 18.3%, 68.3% vs. 22.3%). Ablations further show that LIGER's performance degrades gracefully with increasing task length (up to 17 steps), whereas SLDM's CLIP-Score drops significantly on longer tasks.

## Relation to Prior Work

LIGER builds directly on StoryDiffusion's KV-sharing mechanism for visual memory, injecting previous-step latent tokens into the U-Net's self-attention to maintain cross-step consistency. It departs from prior visual instruction generation methods (StackDiffusion, GenHowTo, SLDM) that require task-specific training by adopting a fully training-free pipeline that composes a frozen SDXL model with GPT-4O-driven self-reflection and off-the-shelf editing tools (LISA, DragonDiffusion, LAMA, SD inpainting). The self-reflection loop draws from the broader tool-based LLM literature (VisProg, ViperGPT, HuggingGPT), repurposing MLLM reasoning as an error detector and tool dispatcher rather than a planner. The inversion-guided memory calibration is a novel addition that addresses exposure bias in sequential generation, a problem not explicitly tackled by prior consistent-generation work.

## Why It Matters / Open Questions

LIGER provides the first training-free pipeline that handles arbitrary-length task sequences (up to 17 steps) without degrading, which is practically important for applications like embodied agent perception and adaptive task instruction. The curated 569-task benchmark with human-annotated ground-truth expressions and logic-relation labels offers a much-needed evaluation protocol for illustrative image generation that prior datasets lacked. Key limitations include dependence on GPT-4O's reasoning quality (open-source MLLMs show significant drops), roughly 2× inference overhead versus vanilla SDXL, and uncontrollable fine-grained actions and ingredient quantities. Open questions include whether fine-tuning the diffusion model could recover action controllability, and whether video generation might better convey state changes that static images struggle to capture.

## Problem

Existing GNN explanation methods (GNNExplainer, PGExplainer, FlowX, GNN-LRP) are designed for static graphs and can only attribute predictions from an empty graph to a single snapshot, failing to explain how predictions evolve between two graph snapshots G₀ and G₁ with continuously changing edge weights. Moreover, these methods lack axiomatic attribution (summation-to-delta property) under continuous weight changes, do not fairly distribute message flow contributions to individual layer edges, and rely on top-K selection that may not faithfully represent the model's behavior.
![Teaser figure](../imgs/ICLR20253220/cropped_page0_idx0.webp)

## Input / Output

The method takes two graph snapshots G₀ and G₁ (with continuously varying edge weights, including additions and removals) along with pre-trained GNN parameters θ, and produces a sparse set of n important changed layer edges that explain the shift in predicted probability from Pr(Y|G₀;θ) to Pr(Y|G₁;θ). The intermediate output is a contribution matrix Φ ∈ ℝ^{|ΔA|×c} where each row encodes a layer edge's contribution to each logit dimension, satisfying the summation-to-delta property. The final selection is constrained by a user-specified sparsity level, and the optimization is solved via cvxpy.

## Method

The method has three key components. First, it extends DeepLIFT's multipliers and chain rules to GNNs with continuously changing edge weights by decomposing Δz_V^t into two terms (propagation of Δh and weight change Δa), yielding a closed-form contribution formula (Eq. 7) for each altered message flow that guarantees the summation-to-delta property. Second, it frames the mapping from message flow contributions to individual layer edges as a cooperative game allocation problem, applying the Shapley value to fairly distribute each flow's contribution among its changed layer edges while preserving the summation-to-delta property via Shapley efficiency. Third, it derives the KL-divergence between Pr(G₁) and a partial-update graph G_n (where only selected layer edges are updated), and formulates a binary optimization problem (Eq. 9) that minimizes this divergence subject to a cardinality constraint, selecting the most faithful sparse subset of layer edges.

## Results

The primary evaluation metric is KL divergence between the true destination distribution Pr(Y|G₁) and the reconstructed distribution Pr(Y|Gₙ) using only selected layer edges (lower is better). AxiomLayeredge achieves the smallest KL across all sparsity levels (all ≥ 0.9), datasets, and tasks on real dynamic graphs, with minor exceptions on certain sparsity levels of Pheme. On the BA-Shapes ground-truth validation, the method achieves 96.57% explanation accuracy on Circle-motif and 99.36% on House-motif, substantially outperforming all baselines. The method maintains high fidelity even when sparsity exceeds 0.9, indicating that a very small subset of layer edges suffices to faithfully explain prediction evolution.

## Baselines & Comparisons

AxiomLayeredge outperforms all five baselines (GNNExplainer, PGExplainer, GNN-LRP, DeepLIFT, FlowX) on 8 out of 11 dataset-task settings (Weibo, YelpChi, YelpNYC, BC-Alpha, BC-OTC, UCI, MUTAG, ClinTox) in terms of KL divergence, with the gap being most pronounced on Pheme and Weibo. On the BA-Shapes ground-truth task, the method achieves 99.36% accuracy on House-motif (vs. GNNExplainer 36.18%, PGExplainer 60.25%, GNN-LRP 17.55%, FlowX 2.38%) and 96.57% on Circle-motif (vs. GNNExplainer 90.67%, DeepLIFT 88.48%, PGExplainer 47.65%, GNN-LRP 11.52%, FlowX 41.56%). DeepLIFT is the closest competitor on House-motif (98.97%) but still trails by 0.39 points, while GNN-LRP and FlowX perform poorly across both motifs. The ablation AxiomLayeredge\Shapley (replacing Shapley value with average mapping) consistently underperforms the full method, confirming that fair attribution via Shapley value is critical, especially on Pheme and Weibo. Methods designed for static graphs (GNNExplainer, PGExplainer) struggle to identify salient edges explaining prediction changes because they cannot axiomatically isolate contributions of message flows causally impacting the evolution.

## Relation to Prior Work

This paper extends the GNN explanation literature from static graphs to evolving graphs with continuously changing edge weights. It builds directly on DeepLIFT's multipliers and chain rules (Shrikumar et al., 2017) and the message flow / layer edge representation from FlowX (Gui et al., 2023), but departs from both by formulating an axiomatic attribution that handles continuous weight changes rather than discrete edge additions/removals (as in Liu et al., 2024). The key methodological departure is the use of Shapley values to fairly distribute message flow contributions to layer edges, followed by a KL-divergence-based combinatorial optimization to select a sparse, faithful subset of layer edges—addressing the fidelity-interpretability trade-off that prior static-graph methods (GNNExplainer, PGExplainer, GNN-LRP) do not explicitly handle for evolving settings.

## Why It Matters / Open Questions

This work fills a clear gap: prior GNN explanation methods are designed for static graphs and cannot correctly attribute prediction changes when edge weights evolve continuously, a common scenario in social networks, financial data, and rumor detection. The axiomatic summation-to-delta property ensures explanations are mathematically grounded rather than heuristic. However, the method is limited to static GNN architectures (e.g., GIN) and cannot extend to dynamic graph models like TGN that incorporate RNN/LSTM temporal components, nor can it fully handle attention-based models like GAT where edge contributions are entangled with learned attention weights. Open questions include whether the Shapley-based attribution scales to very deep or high-degree graphs, and whether the KL-divergence optimization can be approximated more efficiently for real-time applications.

## Problem

Memory-augmented neural networks designed for supervised learning consistently underperform in partially observable, long-horizon RL environments, where agents must selectively retain, erase, and recall past experiences. Existing memory writing mechanisms are either too simplistic to calibrate which memories to forget or suffer from gradient vanishing/exploding over long episodes, making them unreliable for tasks with sparse rewards and evolving contexts.

## Input / Output

At each timestep, the agent receives a context vector x_t = (o_t, a_{t-1}, r_{t-1})—a low-dimensional vector (e.g., 2D position) or a pixel-based local view for Visual Match—which is encoded into a square H×H memory matrix. The memory is read via a learned query h_t = M_t q(x_t) that feeds into policy and value networks, ultimately producing an action. The memory dimension H (tested from 24 to 156) is the primary capacity hyperparameter, with the full memory footprint kept around 2 MB in the meta-RL experiments.

## Method

The Stable Hadamard Memory (SHM) defines memory writing as M_t = M_{t-1} ⊙ C_t + U_t, where the Hadamard product ensures element-wise calibration without mixing memory cells. The calibration matrix C_t = 1 + tanh(θ_t ⊙ v_c(x_t)) is conditioned on the current input, with θ_t randomly sampled from a fixed set of L=128 parameter vectors; this random selection provably minimizes the Pearson correlation between timesteps, keeping the expected cumulative product E[∏C_t] ≈ 1 and preventing gradient vanishing or exploding. The update matrix U_t = η_φ(x_t)[v(x_t) ⊗ k(x_t)] uses a sigmoid-gated outer product to control how much new content is written. A theoretical analysis (Proposition 3) shows that any fixed, input-independent calibration matrix inevitably causes either numerical instability or learning difficulty, motivating the dynamic, input-conditioned design. The framework admits an O(log t) parallel implementation via prefix products, though experiments use the recursive form integrated into SAC or PPO.

## Results

On the POPGym hardest games (Autoencode, Battleship, Concentration, RepeatPrevious), SHM achieves an average return of −5.1±6.3 (×100, range [−100,100]), substantially outperforming FFM (−24.2±1.2) and GRU (−28.4±1.3). On long-term credit assignment, SHM is the only method to achieve 100% success rate on both 250-step and 500-step Visual Match, while the second-best (FFM) reaches only 77% and 25% respectively. In meta-RL (Wind, Point Robot), SHM outperforms all baselines by 20–50% in the easy setting (50 train / 150 test tasks) and by ~20% in the harder setting (10 train / 190 test tasks).

## Baselines & Comparisons

SHM consistently outperforms all six baselines across every benchmark. Against GRU, SHM improves POPGym average return from −28.4 to −5.1 and achieves 100% vs. near-zero success on Key-to-Door (500 steps). Against FFM (the strongest baseline), SHM gains ~19 points on POPGym average return and achieves 100% vs. 77%/25% on 250/500-step Visual Match. Against GPT-2, SHM dominates credit assignment (100% vs. 47% on 500-step Visual Match; 55% vs. 22% on 500-step Key-to-Door) while training in comparable wall-clock time (41 h vs. 36 h). Against FWP, S6, and mLSTM, SHM leads by 20–50% success rate in meta-RL (Wind and Point Robot) and is the only method to solve the 500-step Visual Match task. The only baseline that shows any competitive signal on POPGym is S6 (48.2 on Autoencode-Easy), but it still underperforms SHM on the harder variants and does not appear in the credit-assignment or meta-RL comparisons.

## Relation to Prior Work

This paper unifies a broad family of memory writing mechanisms (Hebbian rules, fast weights, NTM/DNC, Linear Transformers, FFM) under a single Hadamard Memory Framework (HMF), identifying the calibration matrix as the critical differentiator. It departs from prior work by providing a theoretical analysis (Proposition 3) showing that any fixed, input-independent calibration matrix necessarily causes gradient explosion or vanishing, and by proposing random parameter selection for the calibration matrix as a principled fix. The update matrix design follows the fast-weight tradition (outer product of key and value), while the calibration mechanism is the novel contribution, drawing on the Hadamard product's element-wise nature to avoid mixing memory cells.

## Why It Matters / Open Questions

The paper addresses a persistent gap in RL: matrix-based memory models that are both theoretically stable and empirically competitive with simple RNNs over long episodes. The clean theoretical characterization of why existing calibration approaches fail (Propositions 3–5) gives practitioners concrete design principles rather than ad-hoc heuristics. Limitations include the restrictive independence assumption in Proposition 4, the use of a non-parallel implementation in experiments (so the claimed O(log t) complexity is unverified empirically), and mixed results on the hardest POPGym tasks (e.g., Concentration-Hard remains near-random for all methods). Open questions include whether the random parameter selection can be replaced by a learned but provably stable mechanism, and whether the approach transfers to continuous-control POMDPs with much longer horizons.

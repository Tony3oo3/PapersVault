## Problem

Current spatial-temporal world modelling frameworks face a fundamental tension: Transformers scale quadratically with sequence length, RNNs suffer from vanishing gradients, and selective state-space models (e.g., Mamba) impose rigid structural constraints (diagonal or block-diagonal) on their state spaces, assuming fixed correspondences between state dimensions and input features. This rigidity breaks down when spatial relationships evolve dynamically—such as moving objects in video or reordering sensors—forcing the model to learn redundant representations for essentially identical scenarios and making it sensitive to input feature ordering.

## Input / Output

FACTS consumes inputs as unordered sets of nodes rather than ordered sequences: multivariate time series are mapped to t×m×d tensors via set embedders (DFT, Conv2d, or multi-scale Conv2d), video frames are encoded into latent object representations via a pre-trained slot encoder, and graph data provides node features with edge structure. The output is produced by a permutation-invariant factor-graph decoder that aggregates k latent factor predictions via softmax-weighted summation, yielding future time series values (f×m), future object latent codes (f×k×d), or future node predictions (f×n). A predictive residual feed-through is added to handle pixel-level or signal-level noise separately from dynamics.

## Method

FACTS represents the hidden state as a graph-structured set of k latent factors and the input as a set of m feature nodes, then uses an attention-based routing mechanism (analogous to slot attention) to dynamically assign input features to latent factors at each time step. The state-space update uses element-wise multiplication (⊙) instead of matrix multiplication to preserve permutation invariance, with selective parameters (Ā, B̄, C) computed jointly from both the previous memory Z_{t-1} and current input X_t via routing, enabling content-aware history compression. A key linearisation step replaces Z_{t-1} with the initial state Z_0 in the routing computations, breaking the nonlinear recurrence and enabling parallel (chunked) computation while maintaining sequential dependencies across chunks. The paper formally proves FACTS is Left Permutation Equivariant (memory factors can be permuted consistently) and Right Permutation Invariant (input feature order does not affect predictions), providing theoretical guarantees that no prior SSM offers.

## Results

On the 9-dataset MTSF benchmark (TSLib), FACTS achieves the best MSE on 6/9 datasets (e.g., Electricity 0.166, Exchange 0.342, ETTm1 0.392) and best MAE on 6/9, while remaining top-2 on 8/9 datasets. On object-centric world modelling (CLEVRER), FACTS achieves the lowest LPIPS of 0.09 for slot dynamics prediction and the highest FG-ARI (0.75) and mIoU (0.60) for unsupervised object discovery on MOVi-A. On METR-LA graph node prediction, FACTS achieves RMSE 6.97, MAE 3.11, and MAPE 9.08%, outperforming all 13 baselines including the prior best TESTAM (RMSE 7.09, MAPE 9.67%).

## Baselines & Comparisons

FACTS outperforms all 8 MTSF baselines (Autoformer, FEDformer, TimesNet, PatchTST, DLinear, Crossformer, iTransformer, S-Mamba) on at least 7/9 datasets in MSE, with the closest competitors being S-Mamba and iTransformer. On Traffic, S-Mamba (MSE 0.414) and iTransformer (0.428) outperform FACTS (0.472), and on Solar-Energy, iTransformer (0.233) and S-Mamba (0.240) edge out FACTS (0.253). In object-centric world modelling, FACTS beats all 5 slot-dynamics baselines (PredRNN, VQFormer, G-SWM, SlotFormer, SAVi-dyn) by a large margin in LPIPS (0.09 vs. 0.11–0.19 on CLEVRER), and surpasses both SAVi and OC-SlotSSM in unsupervised object discovery (FG-ARI 0.75 vs. 0.64/0.68; mIoU 0.60 vs. 0.43/0.55). On METR-LA graph prediction, FACTS beats all 13 baselines including the prior best TESTAM (MAPE 9.08% vs. 9.67%) and STGM (9.39%), confirming its versatility across modalities. A key differentiator is permutation robustness: when input features are shuffled at test time, S-Mamba's MSE on Traffic increases >3× and iTransformer's doubles, while FACTS maintains near-identical performance, validating its theoretical permutation invariance.

## Relation to Prior Work

FACTS extends the selective state-space model lineage (S4, Mamba) by replacing the fixed-dimensional state vector with a set of latent factor nodes connected via an attention-based routing mechanism, drawing conceptually from Slot Attention. Unlike SlotSSMs, which stack slot attention as a separate module atop Mamba blocks, FACTS integrates factorisation, geometric (graph-structured) memory, and selectivity within a single recurrent block, with the routing computed against a fixed initial state Z₀ to enable parallel computation. The design is explicitly motivated by Schmidhuber's history compression principle, positioning FACTS as a more principled history compressor than prior SSMs that rely on rigid diagonal or block-diagonal structural priors to capture invariant components.

## Why It Matters / Open Questions

The formal permutation-equivariance/invariance guarantees (Theorems 1–2) and the empirical demonstration that FACTS maintains performance under input shuffling while S-Mamba degrades by 3× provide a concrete, practically relevant property for world-modeling scenarios with unordered or dynamically re-ordered agents (sensors, robots). The fact that a single general-purpose architecture matches or beats task-specific SOTA across three structurally different domains (multivariate time series, object-centric video, dynamic graphs) suggests a useful unifying inductive bias. However, experiments are limited to relatively small-scale benchmarks (e.g., 96-step lookback, synthetic video), scalability to larger real-world deployments is untested, and the linearisation trick (freezing routing to Z₀) may constrain expressiveness for very long or highly non-stationary sequences—open questions the authors acknowledge for future work.

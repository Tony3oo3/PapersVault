## Problem

Existing sparse and modular neural network approaches suffer from three interrelated limitations: trainable gating functions that cause representation collapse and degenerate experts, disjoint expert architectures that prevent knowledge transfer between similar inputs, and reliance on explicit input or task IDs that limit real-world applicability. No prior method achieves input-similarity-dependent expert overlap in a fully unsupervised, trainable-gate-free manner while scaling to an exponential number of experts.

## Input / Output

COMET is architecture-agnostic and accepts the same inputs as the underlying backbone: 32×32 RGB images (CIFAR-10/100, SVHN), 64×64 images (Tiny ImageNet), tokenized text sequences (WikiText, CodeParrot), or 21-dimensional numerical feature vectors (SARCOS). A key design property is that the routing network consumes the raw input directly (not intermediate backbone activations beyond layer 1), producing deterministic binary masks so that the same input always activates the same implicit expert during both training and inference—no task IDs, labels, or meta-information are required at inference time.

## Method

COMET augments any backbone network with a parallel, non-trainable routing network of identical shape whose weight matrices are sampled once from the same initialization distribution as the backbone. At each layer, the routing network computes a pre-activation via a fixed random projection, then applies a k-winner-take-all cap operation (inspired by lateral inhibition in biological sensory systems) to produce a binary mask that zeros out (1−p_k) fraction of the backbone's activations. Because the projection is fixed and the cap is deterministic, similar inputs yield overlapping masks—sharing more active parameters—creating an exponential number of implicit overlapping experts (C(N_ℓ, k_ℓ) per layer) without any trainable gating, explicit expert definitions, or task identifiers. The routing network operates independently of the backbone (its input at layer ℓ is its own previous activation, not the backbone's), ensuring stable expert assignment throughout training. This input-dependent sparsity sharpens the effective generalization kernel (verified via NTK analysis), accelerating learning and improving out-of-sample performance, particularly as model capacity grows.

## Results

COMET achieves up to 9% accuracy gains over standard ViT Large on CIFAR-100, with the performance gap widening as model capacity increases. On CIFAR-10 with a 4-layer MLP, COMET outperforms all 10 baseline methods in the high-capacity regime (3000+ neurons per layer), while the standard model retains an edge at low capacity (100 neurons). For language modeling, COMET-based GPT-2 variants consistently achieve lower validation perplexity than their standard counterparts across WikiText and CodeParrot, with larger models showing both greater accuracy gains and faster convergence. On the SARCOS regression task, COMET similarly surpasses the standard MLP as network width increases.

## Baselines & Comparisons

COMET is compared against 10 baselines on CIFAR-10 (4-layer MLP): Standard Model, Smaller Model, Dropout, Topk (trainable routing), MoE Trainable, MoE Non-trainable, Layer-wise Routing, Bernoulli Masking, Example-tied Dropout (Maini et al., 2023), and L1-regularized Standard Model. At low capacity (100 neurons/layer), the Standard Model outperforms COMET and most sparse variants, as the network lacks sufficient redundancy for selective activation to help. At high capacity (3000–9000 neurons/layer), COMET clearly dominates all baselines, including the Smaller Model (which matches the Standard Model, confirming that raw parameter count alone does not improve performance) and the trainable MoE variants (which suffer from representation collapse and redundant computation). The non-trainable MoE and Layer-wise Routing baselines, which also use fixed routing, underperform COMET because they lack the input-similarity-dependent overlap that COMET's random projection + k-winner-take-all mechanism provides. On contemporary architectures (ViT, MLP-Mixer) and language modeling (GPT-2), COMET consistently beats the Standard Model at matched parameter counts, with the advantage growing with model scale, and also outperforms the Smaller Model, demonstrating that structured sparsity is more effective than simply reducing width.

## Relation to Prior Work

COMET synthesizes ideas from sparse Mixture of Experts (Shazeer et al., 2017), input-dependent masking (Maini et al., 2023; Mallya et al., 2018), and biologically inspired lateral inhibition (Bruhin & Davies, 2022) into a unified framework. It departs from standard MoE by replacing the trainable gating network with a fixed random projection followed by a k-winner-take-all cap, and from prior fixed-routing methods (Mittal et al., 2022; Muqeeth et al., 2022) by eliminating the need for task IDs or pre-specified module specializations. The key conceptual move is to reinterpret input-dependent masks as defining an exponential number of *overlapping* implicit experts whose degree of overlap is governed by input similarity, rather than treating experts as disjoint parameter subsets.

## Why It Matters / Open Questions

COMET offers a drop-in sparsification mechanism that requires no additional trainable parameters, no task metadata, and no auxiliary loss terms, while consistently improving performance on larger models across ViT, MLP-Mixer, GPT-2, and MLP backbones. The finding that benefits scale with model capacity (and that a 'smaller model' matches a standard model at the same effective width, while COMET at that width exceeds it) provides a practical recipe for improving overparameterized networks. Open questions include why non-monotonic activations (GELU, SiLU, Mish) degrade COMET's advantage, whether the approach extends to continual learning and multi-task settings as the authors conjecture, and whether optimized sparse-matrix implementations can eliminate the moderate computational overhead.

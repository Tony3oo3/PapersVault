## Problem

Existing 3DGS steganography methods (e.g., GS-Hider) suffer from three critical deficiencies: mutual interference between original and hidden scenes sharing the same Gaussian points degrades rendering fidelity, CNN-based feature-map decoding increases computational cost, and the geometric structure of hidden objects is visibly exposed in the public point cloud. NeRF-based steganography is inapplicable because 3DGS is an explicit representation whose point cloud files are publicly accessible for real-time rendering, making both file-format and geometric-structure security essential.

## Input / Output

The method takes a sparse COLMAP/SfM point cloud of a 3D scene (voxelized into anchor points with 32-dim features, scaling factors, and explicit offsets) plus hidden content (a 3D object, a single 2D image, or 48 bits) as input. It produces a container 3DGS point cloud file whose format is identical to vanilla Scaffold-GS (no extra attributes), ensuring format security, while the hidden content is recoverable only by authorized users who possess the private offset predictor and attribute MLPs. The container must simultaneously satisfy geometric-structure security: visualizing the anchor point cloud reveals no traces of the hidden object's shape.

## Method

SecureGS builds on Scaffold-GS's anchor-point architecture and introduces a hybrid decoupled Gaussian encryption representation: original-scene Gaussians are positioned via explicit per-anchor offsets stored in the file, while hidden-object Gaussians are positioned by a private offset predictor MLP F_o† that takes view-dependent blended anchor features as input, keeping hidden positions entirely implicit. Public and private MLPs separately predict opacity, quaternion, scaling, and color for the two Gaussian sets, which are rendered independently via the standard tile-based rasterizer. A key innovation is the region-aware density optimization (RDO): gradients for original and hidden losses are accumulated asynchronously at different frequencies, DBSCAN clustering on hidden-anchor gradients identifies a bounding box around the hidden object, and the splitting threshold is adaptively lowered (τ_ada = τ_fix / r_down) only within that box so original-scene anchors densely grow to obscure hidden anchors without inflating storage globally. Training minimizes a combined L1 + SSIM + volume-regularization loss for both views with a trade-off factor λ.

## Results

On 3D object hiding (Mip-NeRF 360), SecureGS (Object-Level) achieves 27.93 dB average PSNR for the original scene and 38.21 dB for the hidden object, surpassing GS-Hider (26.59 / 30.62 dB) by 1.34 dB and 7.59 dB respectively, while using 290.54 MB storage at 106.98 FPS (vs. GS-Hider's 468.63 MB at 48.28 FPS). For bit hiding on the Blender dataset, SecureGS achieves 100% bit accuracy with 33.84 dB PSNR, outperforming NeRFProtector (92.69% accuracy, 29.26 dB) and CopyRNeRF (62.15% accuracy, 25.50 dB). For single image hiding, SecureGS reaches 42.99 dB PSNR on the hidden image with only 155.09 MB storage and 144.46 FPS, compared to GS-Hider's 42.16 dB at 385.41 MB and 57.35 FPS.

## Baselines & Comparisons

SecureGS outperforms GS-Hider on all metrics for 3D object hiding: +1.34 dB PSNR on the original scene, +7.59 dB on the hidden object (Object-Level), 201 MB less storage, and ~2.2× faster rendering (106.98 vs. 48.28 FPS). Against 3DGS+StegaNeRF, SecureGS gains +1.40 dB on the original scene and +8.39 dB on the hidden object while using 816 MB less storage and rendering 3× faster. For bit hiding, SecureGS achieves perfect 100% bit accuracy (vs. 92.69% for NeRFProtector and 62.15% for CopyRNeRF) with substantially higher rendering fidelity (33.84 vs. 29.26 vs. 25.50 dB PSNR). For single image hiding, SecureGS beats GS-Hider by 0.62 dB on the original scene and 0.83 dB on the hidden image, while using 230 MB less storage and rendering 2.5× faster. Notably, SecureGS's original-scene PSNR (27.93 dB) even slightly exceeds the Scaffold-GS baseline without steganography (27.62 dB), confirming that the decoupled representation avoids mutual interference between the visible and hidden content.

## Relation to Prior Work

This paper builds directly on Scaffold-GS's anchor-point architecture and MLP-based attribute prediction, repurposing its implicit neural decoding to separate hidden Gaussian attributes from the publicly visible point cloud. It departs from GS-Hider (the first 3DGS steganography method) by replacing coupled feature-field rendering with a hybrid explicit-implicit representation that stores original-scene offsets explicitly while encoding hidden-scene offsets in private MLPs, and by introducing a region-aware density optimization to prevent geometric leakage. The broader lineage traces from NeRF steganography (StegaNeRF, CopyRNeRF, WaterRF) into the explicit 3DGS setting, where the publicly accessible point cloud file introduces a new security dimension—geometric structure security—that prior implicit-representation methods did not need to address.

## Why It Matters / Open Questions

As 3DGS becomes the dominant real-time 3D representation, protecting 3D assets from unauthorized access or tampering is increasingly urgent, and this paper identifies a previously overlooked attack surface: the geometric structure of the published anchor point cloud can reveal the shape of hidden objects. The region-aware density optimization and hybrid decoupled encryption provide a practical, format-consistent solution that maintains near-baseline rendering speed. Key limitations remain: the hidden object must partially overlap the original scene's point cloud, robustness degrades under aggressive pruning or denoising, and a generalized point-cloud-based bit decoder (analogous to HiDDeN for images) does not yet exist, leaving open the question of how to achieve robust, generalizable message extraction from 3DGS without relying on 2D rendered views.

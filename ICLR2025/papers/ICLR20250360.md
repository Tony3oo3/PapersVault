## Problem

Existing data attribution methods for diffusion models focus on local properties of individual generated images rather than global distribution-level properties (e.g., overall aesthetic quality, demographic diversity), and they attribute to individual data points rather than to data contributors who may supply multiple samples. While the Shapley value provides a principled, axiomatically fair solution for contributor-level attribution, estimating it for diffusion models is computationally infeasible because it requires retraining on exponentially many data subsets and rerunning expensive inference on each retrained model.

## Input / Output

The method takes a fully trained diffusion model (DDPM, LDM, or LoRA-finetuned Stable Diffusion), the training data partitioned into contributor groups (e.g., 20 labelers for CIFAR-20, 50 celebrity identities for CelebA-HQ, 258 artists for ArtBench), and a user-specified global property function F that maps a model to a scalar (Inception Score, cluster entropy, or 90th-percentile aesthetic score). It outputs a Shapley value score for each contributor, yielding an importance ranking that can be used for compensation, data curation, or quality assessment. The global property is measured by generating a fixed number of images (e.g., 10,240 for CIFAR-20, 1,024 for CelebA-HQ, 50 for ArtBench) from each subset-trained model and computing F over the generated set.

## Method

The core mechanism is sparsified fine-tuning: the trained diffusion model is first pruned via magnitude-based pruning (e.g., 35.7M→19.8M parameters for CIFAR-20, 274M→70.9M for CelebA-HQ), then fine-tuned on the full dataset to recover performance, yielding a compact surrogate model. For each Shapley kernel-sampled contributor subset, the pruned model is fine-tuned for a fixed number of steps (1,000/500/200 for the three datasets) on that subset's data, and inference is run to evaluate the global property—replacing the prohibitively expensive from-scratch retraining. KernelSHAP then solves a constrained weighted least-squares problem over the sampled subset evaluations to produce Shapley value estimates. Two theoretical propositions formalize the approximation: under convexity and Lipschitz-gradient assumptions on the diffusion loss, the expected error between the sparsified fine-tuned model property and the retrained model property is bounded by a constant B (the lottery-ticket gap), and the resulting Shapley value error is bounded by 2√n·C. Empirically, this yields 5.3×–18.6× speedups over retraining while achieving the highest Linear Datamodeling Scores (61.5%, 26.3%, 61.4%) across all three datasets, outperforming TRAK-based, influence-function, and similarity-based baselines.

## Results

The proposed Sparsified-FT Shapley method achieves the highest Linear Datamodeling Score (LDS) across all three datasets at α=0.5: 61.48% on CIFAR-20 (Inception Score), 26.34% on CelebA-HQ (cluster entropy), and 61.44% on ArtBench Post-Impressionism (90th-percentile aesthetic score). The best baseline (LOO) reaches only 30.66% on CIFAR-20, while TRAK-based methods frequently yield negative correlations (e.g., Journey-TRAK: −42.92% on CIFAR-20). Sparsified fine-tuning reduces per-subset runtime to 18.3 min (CIFAR-20), 22.9 min (CelebA-HQ), and 10.5 min (ArtBench), making it 5.3×, 10.4×, and 18.6× faster than full retraining respectively.

## Baselines & Comparisons

Sparsified-FT Shapley outperforms all baselines on every dataset. On CIFAR-20, it nearly doubles the best baseline (LOO at 30.66%) and substantially exceeds TRAK-based methods (D-TRAK: 10.90%, TRAK: 7.94%) and similarity-based methods (CLIP max: 11.31%). On CelebA-HQ, it surpasses the best baseline (pixel similarity max: 21.70%) by ~5 points, while D-TRAK and CLIP similarity produce strongly negative correlations (−27.23% and −32.23% respectively). On ArtBench, it more than doubles the best application-specific baseline (aesthetic score average: 24.85%) and all TRAK variants, which range from −11.41% to 11.30%. Notably, TRAK-based methods that aggregate per-datum attributions to the contributor level perform worse than simple heuristics, confirming that local attribution does not transfer well to global model properties. LOO, the strongest retraining-based baseline, degrades sharply as the number of contributors grows (30.66% on 20 contributors → −1.22% on 50 → 3.74% on 258), whereas Sparsified-FT Shapley remains robust across contributor counts.

## Relation to Prior Work

This paper extends the data attribution literature for diffusion models (TRAK, D-TRAK, Journey-TRAK) by shifting the target from local, per-image properties to global, distribution-level properties (Inception Score, demographic diversity, aesthetic quality) and from individual data points to data contributors (groups). It builds on the Shapley value framework from cooperative game theory (Ghorbani & Zou, 2019) and KernelSHAP estimation (Lundberg & Lee, 2017; Covert & Lee, 2021), but addresses the computational infeasibility of retraining diffusion models on all contributor subsets by introducing sparsified fine-tuning—pruning the model and fine-tuning on subsets rather than retraining from scratch. The approach departs from prior diffusion attribution methods that rely on gradient-based influence estimators, showing these are insufficient for global properties.

## Why It Matters / Open Questions

This work provides the first computationally feasible framework for fairly crediting data contributors of diffusion models using Shapley values, with practical implications for data compensation policies, labeling incentives, and fairness auditing. The 5–18× speedup from sparsified fine-tuning makes Shapley estimation tractable where vanilla retraining would require days of GPU time per subset. Key limitations include asymptotic-only theoretical guarantees, the assumption of access to training data and model parameters (not available for deployed models), and weaker performance on CelebA-HQ (26% LDS) compared to other datasets. Open questions include extending the framework to LLMs, incorporating unlearning methods, and developing finite-step bounds for the approximation error.

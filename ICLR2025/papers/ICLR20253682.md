## Problem

Evaluating dynamic graph generative models (DGGMs) is difficult because existing metrics discretize continuous-time evolution into static snapshots, treating temporally dependent events as i.i.d., and rely on multiple topology-only statistics with no unified scalar score. These approaches also neglect node/edge features, fail to capture feature-topology interactions, and require explicit snapshot instantiation that becomes impractical at scale. The paper asks whether a single, efficient, application-agnostic metric can simultaneously capture topology, features, and temporal dynamics of continuous-time dynamic graphs (CTDGs).

## Input / Output

The method takes two CTDGs — a ground-truth and a generated one — each represented as a sequence of timestamped events (src, dst, t_i, feature vector), and produces a single scalar cosine distance in [0, 2]. Unlike snapshot-based metrics, it operates directly on the event sequence without discretization, handling variable-length per-node interaction histories and differing node counts across graphs. The only preprocessing is optional min-max normalization of timestamps and feature channels; no graph snapshots are ever materialized.

## Method

The JL-Metric constructs a fixed-dimensional embedding for each CTDG via two untrained structured random matrix (SRM) projections. First, each node is represented as the time-ordered concatenation of all events it participated in (a variable-length vector), and a random projection W₁ ∈ R^{M×n} (where M is the maximum node history length) maps every node to a consistent n-dimensional descriptor, with unused rows simply ignored for shorter histories. Second, a second SRM W₂ ∈ R^{Z×o} (where Z is the maximum node count across graphs) projects the variable-size set of node descriptors into a fixed o-dimensional matrix representation. The final similarity is the cosine distance between the two resulting matrices under the Frobenius norm. The SRMs are products of a normalized Hadamard matrix and a Rademacher diagonal matrix, enabling O(M log M) and O(Z log Z) matrix-vector multiplications without explicit matrix storage. The key theoretical insight is that the JL lemma's distance-preservation guarantee is independent of input dimensionality, which is precisely what allows variable-length node histories and variable node counts to be mapped into a uniform space while preserving pairwise similarities.

## Results

The JL-Metric achieves median Spearman rank correlations of 0.976 (Edge Rewiring), 0.944 (Time Perturbation), 0.988 (Event Permutation), 0.915 (Mode Dropping), and 0.988 (Mode Collapse) across five datasets. It is the only metric sensitive to event permutation (all classical and feature-based baselines score "-"), and it outperforms all baselines on time perturbation (0.944 vs. best baseline 0.927). Computationally, the JL-Metric runs at 1.05±0.09 s/100 events, roughly 8–10× faster than snapshot-based topological metrics (8.4–12.0 s/100 events), while matching the best sample efficiency (3±1 minimum events).

## Baselines & Comparisons

Against topological snapshot metrics (Node Degree, LCC, NC, PLE with KS or MMD), the JL-Metric is competitive on edge rewiring (0.976 vs. best 1.000 for Node Degree MMD) but clearly superior on time perturbation (0.944 vs. best 0.927) and mode dropping (0.915 vs. best 0.818 for LCC KS). Against the node-behavior baseline Activity Rate, the JL-Metric dominates on time perturbation (0.944 vs. not applicable) and event permutation (0.988 vs. not applicable), while Activity Rate KS edges ahead on mode collapse (1.000 vs. 0.988) and is ~8× faster (0.12 vs. 1.05 s/100 events). Against feature-based metrics (KL, JS, KS, MMD on features alone), the JL-Metric is the only method that detects event permutation (0.988 vs. all "–"), and it substantially outperforms them on mode dropping (0.915 vs. best 0.685 for JS). The JL-Metric also matches the best sample efficiency (3±1 events) while being ~8–10× faster than all snapshot-based topological metrics, making it the only method that simultaneously achieves high sensitivity across all five perturbation types, competitive sample efficiency, and practical runtime.

## Relation to Prior Work

This paper extends the line of work using untrained neural networks as feature extractors for generative model evaluation—from random CNNs in the image domain (Xu et al., 2018; Naeem et al., 2020) to random GNNs for static graphs (Thompson et al., 2022)—to continuous-time dynamic graphs. The key conceptual departure is providing a theoretical justification for why random networks work as feature extractors via the Johnson-Lindenstrauss lemma, and exploiting the lemma's dimensionality-agnostic property to handle variable-length event sequences without explicit snapshot instantiation. Structured random matrices (Hadamard × Rademacher, per Choromanski et al., 2017) replace full orthogonal projections for O(M log M) computation, and the approach generalizes the static-graph evaluation framework to capture temporal dependencies and feature-topology interactions that prior CTDG metrics (TagGen, TIGGER, Dymond, TG-GAN) fundamentally cannot.

## Why It Matters / Open Questions

This is the first comprehensive empirical benchmark of CTDG evaluation metrics, establishing that no single classical metric (topological or feature-based) is sensitive to all perturbation types, and that the JL-Metric is the only one detecting feature-topology relationship changes. Practically, the O(M log M) runtime and O(M+Z) memory make evaluation feasible at scales where snapshot-based metrics become intractable (e.g., LastFM requires 848,680 Nyquist snapshots). Open questions include the scaling of hyperparameters n and o with graph size, handling of simultaneous timestamps, and whether the approach extends to multi-graph comparison settings beyond the single-graph assumption common in CTDG literature. The paper also acknowledges that domain-specific metrics (e.g., ring counts in molecular graphs) remain necessary complements.

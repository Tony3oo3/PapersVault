## Problem

Directly adapting a pretrained Vision Language Model (VLM) for robotic control remains challenging, especially under limited robot demonstrations, because the conversation-style instruction data needed for effective VLM finetuning is non-trivial to curate and scale for the robotics domain. Prior work on using VLMs as robot policies (e.g., RT-2, OpenVLA) relies on special tokens to encode quantized actions, which requires large amounts of data to learn token semantics and does not leverage the natural-language conversation format in which VLMs are pretrained.

## Input / Output

The model consumes a single RGB image from a front-facing camera, a text task description (which may embed object-detection results from reference images as structured bounding-box lists), and a text-formatted action history from prior steps in the episode. The output is natural-language text containing two normalized 2D image coordinates (pick and place positions in [0,1]) and a clockwise rotation angle in degrees, which are then mapped to the robot's action space via a predefined visual calibration. Notably, the model generates a full multi-step action plan in each response but only the first action is executed before re-querying with a new observation.

## Method

LLaRA converts standard behavior-cloning trajectories into conversation-style instruction-tuning data (inBC) where robot actions are expressed as 2D image pixel coordinates in natural language rather than special tokens, creating an intuitive vision-to-action alignment that enables efficient transfer from a pretrained LLaVA-1.5-7B VLM. A variant (D-inBC) handles multi-image task descriptions by running object detection on reference images and encoding their contents as structured text bounding-box lists, avoiding the multi-image limitation of single-image VLMs. The framework further 'supercharges' the training data by generating six self-supervised auxiliary datasets (object localization, scene detection, action prediction, future prediction, spatial relationships, and temporal relationships) from the same trajectories using scripted templates and GPT-4 rephrasing, requiring no additional action annotations. Training is a single-stage finetune of the LLM and projection layer (freezing the vision encoder) with a cosine-annealed learning rate, and the auxiliary data is shown to be most beneficial when expert trajectories are scarce.

## Results

On VIMA-Bench (simulation), LLaRA (D-inBC+Aux(B)+Oracle) trained on only 12% of expert trajectories achieves 90.0% / 88.1% / 79.2% success rates on difficulty levels L1/L2/L3, surpassing VIMA (80.7% / 81.9% / 77.9%) which uses 100% of the data and both front and top camera views. On real-world robot tasks, the best finetuned LLaRA variant (D-inBC+Aux(C)+OD with xArm-Action) reaches 91.6% average success rate across three manipulation tasks. In zero-shot real-world transfer, LLaRA inBC achieves 36.6% average success, outperforming GPT-4o (31.6%) without any additional training.

## Baselines & Comparisons

Against VIMA (Jiang et al., 2023), LLaRA achieves higher success rates on L1 (+9.3 pp) and L2 (+6.2 pp) while using only 12% of the training trajectories and a single front-view camera instead of VIMA's dual cameras. Against RT-2 Style baselines, LLaRA's advantage is most dramatic under data scarcity: on VIMA-8k, inBC reaches 57.3% L1 success versus RT-2 Style's 3.8%, and even with 100% of the data RT-2 Style (65.0% L1) still trails LLaRA trained on just 12% (87.3% L1). On real-world zero-shot evaluation, LLaRA inBC (36.6% avg) outperforms GPT-4o (31.6% avg), while RT-2 Style variants score 0% across all tasks. In the few-shot appendix (Table 18), Llama 3 70B (4-bit) achieves near-zero success (0.0–1.4%) on VIMA tasks, confirming that raw LLM/VLM capabilities without domain-specific instruction tuning are insufficient for robot control.

## Relation to Prior Work

LLaRA extends the visual instruction tuning paradigm of LLaVA/LLaVA-1.5 from computer vision to robot manipulation, reframing behavior cloning data as conversation-style instruction-response pairs. It deliberately departs from the RT-2/OpenVLA lineage, which encodes actions as quantized special tokens, by instead expressing robot actions in natural language aligned to normalized 2D image pixel coordinates—a design that leverages the VLM's pretrained conversational structure without architectural modification. The self-supervised auxiliary datasets (localization, action/future prediction, spatial/temporal relationships) draw on pretext-task ideas from computer vision SSL but are the first to be systematically applied to robot policy instruction tuning.

## Why It Matters / Open Questions

The framework demonstrates that a 7B VLM finetuned on as few as 8k expert trajectories (12% of VIMA's 660k) can outperform VIMA's 200M model trained on the full dataset, suggesting that data formulation and alignment to image coordinates matter more than raw trajectory volume for VLM-to-VLA transfer. The auxiliary self-supervised datasets provide a practical recipe for 'supercharging' limited robot data without additional action annotations, which is directly relevant to the data-scarcity bottleneck in robotics. Open questions include whether the approach generalizes beyond tabletop manipulation with fixed cameras and linear coordinate mappings, how it scales to multi-image or video inputs (where LLaVA's single-image constraint becomes limiting), and whether the gains persist in more complex, high-DoF embodiments.

## Problem

Existing OOD evaluation methods in biochemistry rely on ad-hoc train/test splits (scaffold, temporal, random) with no principled way to select the most appropriate splitting criterion or to incorporate prior knowledge about the target deployment distribution. No prior work provides a unified framework that both quantifies a model's generalisation across a continuum of dissimilarity levels and offers a statistical test to compare models' OOD performance.
![Teaser figure](../imgs/ICLR20252671/cropped_page2_idx0.webp)

## Input / Output

The framework consumes a biochemical entity dataset (small molecules, protein sequences, or embeddings), a user-specified pairwise similarity function (fingerprints, physicochemical descriptors, pre-trained model embeddings, or sequence identity), and one or more target deployment distributions. It produces a GOOD curve (model performance as a function of similarity threshold), an AU-GOOD score (the expected performance weighted by the target distribution's similarity histogram), pairwise Wilcoxon signed-rank p-values for model comparison, and a ranking of candidate similarity functions by dynamic range and monotonicity. The partitioning is deterministic and non-stochastic, so all runs share identical splits and variance arises only from the learning algorithm and hyperparameter optimisation.

## Method

The Hestia-GOOD framework has three components. First, CCPart (Connected Components Partitioning) builds a graph at each similarity threshold where edges connect entities exceeding that threshold, identifies connected components, and assigns the smallest components to the test set (as they represent the most unique, dissimilar regions), thereby satisfying three conditions no prior method meets simultaneously: no data removal, strict train/test boundaries, and support for multiple thresholds. Second, the AU-GOOD metric computes the expected empirical risk under a target deployment distribution by training and evaluating at each threshold to form a GOOD curve, then taking a weighted average where weights are the histogram of maximal similarities between the target distribution and training data. Third, a one-tailed paired Wilcoxon signed-rank test (with Bonferroni correction for n>5 models) provides statistical significance for pairwise AU-GOOD comparisons. The framework is data-type agnostic, requiring only a valid similarity function, and includes two selection criteria (dynamic range and monotonicity via Spearman's ρ) to diagnose whether a given similarity metric is appropriate for a dataset.

## Results

On the ADMET use case (5 datasets, target: Drug Repurposing Hub), SVM achieves the best average AU-GOOD of 0.91±0.01 with a significant rank of 2.2, followed by KNN (0.90±0.01, rank 2.6), RF (0.87±0.02, rank 2.0), and LightGBM (0.72±0.05, rank 4.8). For the Ames dataset specifically, RF is significantly superior (p<0.001) to all other models with AU-GOOD 0.90±0.01. In the protein language model use case (Optimal Temperature for Catalysis), larger PLMs consistently generalize better: ESM2-650M outperforms ESM2-150M which outperforms ESM2-8M, while Ankh-base and Ankh-large are the worst performers despite the original Ankh paper reporting strong results.

## Baselines & Comparisons

For the PLM comparison, ESM2-650M (Lin et al., 2022) achieves the highest AU-GOOD among ESM2 variants, confirming a size-scaling trend (ESM2-650M > ESM2-150M > ESM2-8M). Prot-T5-XL and Prost-T5 (Elnaggar et al., 2021) rank among the top performers, while Ankh-base and Ankh-large (Elnaggar et al., 2023) are the worst-performing embeddings, contradicting the original Ankh paper's reported advantages. For similarity functions, Molformer (Ross et al., 2022) is selected as optimal for PAMPA and Caco2 datasets, while ChemBERTa-2 (Ahmad et al., 2022) shows competitive monotonicity (0.80±0.05) on Caco2 but is not selected as the top metric. MAPc-Jaccard emerges as the most versatile fingerprint-based similarity, being optimal for 3 of 6 ADMET datasets (Ames, DILI, LD50) with monotonicity values of 0.81–0.94. The framework reveals that no single similarity function dominates across all tasks, and the choice significantly impacts GOOD curve reliability (e.g., PAMPA shows near-zero monotonicity for all metrics, rendering its AU-GOOD unreliable).

## Relation to Prior Work

This paper carves new ground by unifying several previously fragmented components of OOD evaluation in biochemistry—similarity-based partitioning (Butina, 1999; Ramsundar et al., 2019; Tom et al., 2023; Steshin, 2023; Teufel et al., 2023), target-distribution-aware test set construction (Tossou et al., 2024), and overlap-effect analysis (Ektefaie et al., 2024)—into a single framework with a well-defined metric (AU-GOOD) and statistical comparison procedure. Unlike prior partitioning methods that each violate at least one of three stated conditions (no data removal, strict train/test boundaries, multi-threshold support), CCPart satisfies all three, and unlike MOOD or Spectra, AU-GOOD conditions performance on an arbitrary target deployment distribution without requiring repeated training cycles. The framework is deliberately agnostic to data type, relying only on a user-defined similarity function, which distinguishes it from scaffold-based or sequence-identity-based methods that are tied to specific molecular or biological contexts.

## Why It Matters / Open Questions

The framework addresses a genuine gap: prior biochemical ML papers report OOD performance under ad-hoc splits with no principled way to select the split, incorporate knowledge about where the model will actually be deployed, or statistically compare models' generalisation capabilities. The finding that no single similarity function is universally appropriate—and that language-model embeddings (Molformer, ChemBERTa-2) can outperform traditional fingerprints for permeability tasks—has practical implications for how the community designs evaluation protocols. Key limitations include dependence on the quality of the chosen similarity metric (the PAMPA dataset demonstrates failure under high class imbalance), the absence of ground-truth validation for the AU-GOOD metric itself, and the O(N²) scaling of pairwise similarity that may constrain very large datasets. Open questions include the impact of relaxing the three partitioning conditions, the development of task-specific similarity functions, and empirical validation against known deployment outcomes.

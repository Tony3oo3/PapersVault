## Problem

TextGrad enables iterative prompt optimization via LLM-generated textual feedback in centralized settings, but its adaptation to federated learning remains unexplored. The core challenge is that FL requires aggregating distributed updates without sharing raw data, yet traditional FL aggregation (e.g., FedAvg) operates on numerical gradients, while TextGrad produces natural-language prompt updates that cannot be averaged. This paper asks whether textual gradients can function under FL constraints and identifies the specific aggregation bottleneck that hinders their adoption.

## Input / Output

Each FL client receives a global prompt (a natural-language instruction string) and a private local dataset, then produces an updated local prompt after multiple rounds of TextGrad-based optimization. The server aggregates all client prompts into a single global prompt, which must fit within the LLM API's context window (e.g., 8192 tokens for GPT-4), making prompt length a hard constraint that grows with the number of clients. The final output is a globally optimized prompt redistributed to all clients for the next communication round, with performance evaluated on reasoning tasks (BBH Object Counting, Multistep Arithmetic, GSM8K) using accuracy on held-out test sets.

## Method

FedTextGrad mirrors the FedAvg loop but replaces numerical parameter aggregation with textual prompt aggregation: each client performs local TextGrad optimization (forward LLM call → evaluation → textual backpropagation → Textual Gradient Descent step) over E local epochs on its private data, then uploads the resulting prompt to the server. The server aggregates client prompts via concatenation or LLM-based summarization and redistributes the global prompt. The paper's key finding is that naive summarization degrades performance because it produces prompts with non-uniform information density, diluting critical client-specific updates. To fix this, the authors introduce a UID-guided summarization method that instructs the LLM to distribute information uniformly across the aggregated prompt, measured via surprisal variance from a pre-trained language model, yielding shorter prompts that preserve essential content and improve accuracy over both concatenation and vanilla summarization.

## Results

On BBH Object Counting, FedTextGrad with GPT-4 achieves 0.98 accuracy versus 0.99 for centralized TextGrad, while smaller models (Gemma-2-9B, Qwen-2-7B) show sharper federated performance drops. On harder reasoning tasks (Appendix D), FedTextGrad underperforms centralized TextGrad: Spatial (0.40 vs 0.53), Web of Lies (0.30 vs 0.37), and Zebra Puzzle (0.27 vs 0.33). Notably, FedTextGrad outperforms centralized TextGrad on the AMPS Hard math task (0.50 vs 0.46), suggesting federated aggregation can capture client-specific numerical reasoning patterns. UID-based summarization consistently improves over standard summarization across all three main datasets (e.g., Object Counting and GSM8K).

## Baselines & Comparisons

The sole baseline is centralized TextGrad (Yuksekgonul et al., 2024), the original non-federated prompt optimization framework. FedTextGrad consistently loses to centralized TextGrad on all three reasoning tasks: Spatial (0.40 vs 0.53, −13 pts), Web of Lies (0.30 vs 0.37, −7 pts), and Zebra Puzzle (0.27 vs 0.33, −6 pts), indicating that federated prompt aggregation introduces information loss that particularly harms deductive and spatial reasoning. However, FedTextGrad wins on the AMPS Hard mathematical task (0.50 vs 0.46, +4 pts), suggesting that the diversity of client-specific numerical updates benefits structured math problems. On BBH Object Counting with GPT-4, the gap is minimal (0.98 vs 0.99), but widens substantially for smaller LLMs like Gemma-2-9B and Qwen-2-7B, highlighting that weaker models are more sensitive to the aggregation-induced prompt degradation. Overall, the paper demonstrates that textual gradients are feasible in FL but suffer a non-trivial performance tax, with the gap being task- and model-size-dependent.

## Relation to Prior Work

This paper bridges two previously separate research threads: TextGrad's textual-gradient-based prompt optimization (Yuksekgonul et al., 2024) and the FedAvg-style local-update-then-aggregate loop of federated learning (McMahan et al., 2017). While prior FL-for-LLM work (OpenFedLLM, FederatedScope-LLM, FedbiOT) focuses on aggregating numerical parameters or LoRA adapters, and prior LLM-as-optimizer work (ProTeGi, DSPy, OPRO) operates in centralized settings, FedTextGrad is the first to define and study the aggregation of *textual* prompt updates across FL clients. The paper's key methodological departure is replacing numerical averaging with text summarization, and further grounding that summarization in the Uniform Information Density hypothesis from psycholinguistics (Meister et al., 2020) rather than in learned compression.

## Why It Matters / Open Questions

The paper establishes that federated textual gradient optimization is feasible but fragile: performance degrades noticeably relative to centralized TextGrad, especially for smaller LLMs, and the aggregation step is the primary bottleneck. The finding that naive summarization underperforms concatenation—and that a linguistics-inspired UID constraint partially recovers the gap—points to a concrete, underexplored sub-problem (principled text aggregation for FL) that will matter as black-box LLM APIs become the dominant interface for agentic systems. Major open questions remain: how to preserve privacy when sharing textual gradients (traditional DP/SMPC tools are ill-suited to natural language), how to scale beyond a handful of clients without exceeding context windows, and whether the approach generalizes to more complex agentic pipelines beyond single-prompt optimization.

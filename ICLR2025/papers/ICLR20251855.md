## Problem

Augmenting pre-trained LLMs with external knowledge faces a fundamental trade-off: RAG requires a separate retrieval module and discards most of the KB, in-context learning incurs quadratic time and memory overhead in context length, and fine-tuning causes catastrophic forgetting while requiring retraining on every knowledge update. KBLAM addresses this by asking whether a structured knowledge base can be injected into a frozen LLM with linear scaling in KB size, dynamic updatable knowledge, and interpretable attention, without modifying the LLM's weights.

## Input / Output

The method takes a user question prompt of N tokens and a structured knowledge base of M triples (each a name-property-value string), which is pre-encoded offline into M fixed-length key-value vector pairs (knowledge tokens) of dimension D, identical in size to a single LLM token's KV cache. At inference, the rectangular attention matrix has shape (M+N)×N, so the output sequence length remains N regardless of M. The model produces either a grounded text answer or a learned refusal ("I cannot find relevant information in the KB") when no relevant triple exists, with the attention scores over knowledge tokens serving as an interpretable retrieval signal.

## Method

KBLAM encodes each KB triple into a knowledge token by passing "The <property> of <name>" through a pre-trained sentence encoder (ada-002, P=1536) to form a base key vector, and "<value>" to form a base value vector, then projecting both into the LLM's D-dimensional key/value space at every layer via learned linear adapters (W̃_K, W̃_V ∈ R^{L×D×P}). These tokens are injected into each self-attention layer through a rectangular attention structure where prompt tokens attend to all previous prompt tokens plus all M knowledge tokens, but knowledge tokens attend to nothing (no self-attention, no query embeddings), yielding O((M+N)N) time complexity that is linear in M when M≫N. A constant shift (log C − log M) is added to KB attention scores during inference to prevent the KB contribution from overwhelming the prompt as M grows. The adapters and additional query heads are trained via instruction tuning on a fully synthetic GPT-generated KB of ~135K triples, keeping the Llama3 8B backbone frozen, so the model learns a projection from encoder space to LLM embedding space rather than memorizing specific facts.

## Results

On the synthetic KB, KBLAM achieves BERT score (F1) comparable to in-context learning for simple and two-entity Q&A, and GPT-4 scores (0–5) on par with in-context learning for open-ended Q&A, while using only linear memory in KB size (vs. quadratic for in-context learning). On the out-of-distribution Enron KB, KBLAM shows degraded but still meaningful performance above zero-shot. For unanswerable-question detection, KBLAM maintains higher precision than in-context learning as KB size grows (slower over-refusal), while recall remains constant for both. KBLAM's attention at layer 15 achieves high top-1 and top-5 retrieval accuracy on synthetic data, degrading gracefully on Enron, and outperforms BM25 on perturbed entity names at all tested KB sizes.

## Baselines & Comparisons

Against in-context learning, KBLAM matches answer quality on the synthetic KB (BERT F1 and GPT-4 scores) but scales to 10K+ triples versus in-context learning's ~200-triple memory limit, with memory growing linearly in M rather than quadratically in KM. On the OOD Enron dataset, KBLAM degrades more than in-context learning but still clearly outperforms zero-shot, confirming it leverages KB information. For unanswerable-question refusal, both methods show decreasing precision (over-refusal) as KB size increases, but KBLAM's precision degrades more slowly than in-context learning's. Against RAG (Lewis et al., 2020), KBLAM maintains lower latency and memory than RAG retrieving 5 triples while keeping the entire KB in context, with stable token-generation time independent of KB size. Against BM25, KBLAM's implicit attention-based retrieval achieves comparable top-5 accuracy on the synthetic KB, and surpasses BM25 at all KB sizes when entity names in questions are perturbed (e.g., 'Euler's Edifice' → 'Euler's Building'), a setting where lexical matching fails.

## Relation to Prior Work

KBLAM repurposes the KV cache concept by sourcing key-value pairs from an external pre-trained sentence encoder (ada-002) rather than self-attention, and injects them via a rectangular attention structure that exploits independence between KB triples. It draws on structured attention work (Ratner et al., 2022; Cai et al., 2023) for the independence assumption, on multi-modal LLM adapter design (Liu et al., 2023) for the instruction-tuning-with-linear-adapters paradigm, and on memory-augmented language models (Wu et al., 2022) for the key-value external memory idea. The key departure from RAG is eliminating the explicit retrieval module in favor of implicit soft retrieval through attention, and the key departure from in-context learning is achieving linear rather than quadratic scaling with knowledge base size.

## Why It Matters / Open Questions

The linear scaling with KB size (vs. quadratic for in-context learning) is a practically significant efficiency gain that enables integrating 10K+ triples into an 8B model on a single GPU, and the dynamic update capability (modify one knowledge token without recomputing others) addresses a real operational need. However, the fixed-length encoding introduces information loss for exact names or numerical values, and OOD performance degradation on Enron suggests the synthetic-data training recipe needs more diversity. Open questions include whether the rectangular attention design extends to more complex KB structures (trees, graphs), whether multi-hop or chain-of-thought reasoning over the KB is feasible, and whether the approach generalizes beyond triple-formatted knowledge to raw unstructured text.

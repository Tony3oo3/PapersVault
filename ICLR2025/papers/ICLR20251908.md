## Problem

Existing subgraph federated learning methods optimize local models for the current label distribution of each client, making them prone to local overfitting that severely degrades performance on unseen data such as new nodes, missing classes, and entirely new clients. No prior work in subgraph-FL addresses local overfitting while simultaneously handling the missing class problem, where a class is entirely absent from a client's local graph but present in others.

## Input / Output

Each client provides a local subgraph with d-dimensional node features, edge connectivity, and class labels; the server additionally generates and distributes global synthetic node features (s nodes per class, no edges) and class-specific prompt generators. The output is per-node class predictions from a dual-branch (head/tail degree) prototypical classifier, plus the condensed global synthetic features that encode both class representation and structural information without exposing raw client data.

## Method

FedLoG employs a prototypical-network-based architecture with separate head-degree and tail-degree branches, where learnable synthetic nodes per class serve as both prototypes for prediction and containers for condensed class knowledge. The server aggregates head-degree synthetic nodes across clients, weighting each client's contribution by its class headness (proportion of that class locally), to produce global synthetic data that captures reliable structural and class-representative information. During Local Generalization, each client adaptively trains on this global synthetic data using two strategies: Feature Scaling, which dynamically perturbs dominant-class features to counteract local bias, and Prompt Generation, which creates synthetic neighbor nodes via pretrained generators so that the shared GNN encoder receives structurally consistent training signals. A sigmoid-weighted combination of head and tail branch predictions, parameterized by node degree, ensures that high-degree nodes condense into the head branch and low-degree nodes into the tail branch, with only the head branch knowledge shared globally to maximize reliability.

## Results

On the Seen Graph (conventional transductive) setting, FedLoG achieves the highest accuracy across all five datasets and client counts, e.g., 0.8601 on Cora (3 clients), 0.9180 on PubMed (3 clients), and 0.9653 on Amazon Photo (3 clients). On the novel Unseen Node setting, FedLoG reaches 0.7341 (Cora, 3 clients), 0.7624 (CiteSeer, 3 clients), and 0.7677 (Amazon Computers, 3 clients), consistently outperforming all baselines. On the Missing Class setting, FedLoG achieves 0.6472 (Cora, 3 clients) and 0.6142 (CiteSeer, 3 clients), substantially exceeding the next-best FedED (0.5305 and 0.3184 respectively). On the New Client setting, FedLoG attains 0.7386 on Amazon Computers (3 clients) versus 0.0328 for FedNTD and 0.1162 for FedED, demonstrating strong generalization to entirely unseen graph structures.

## Baselines & Comparisons

FedLoG outperforms all six baselines across the three unseen-data settings. Against FedAvg, the gap is largest on Amazon Photo (Unseen Node: 0.7065 vs 0.1782) and Amazon Computers (New Client: 0.7386 vs 0.1978), where FedAvg's simple weight averaging fails to handle structural shifts. FedSAGE+ and FedGCN, which focus on recovering missing neighbors, are outperformed on Missing Class (e.g., CiteSeer 3 clients: FedLoG 0.6142 vs FedSAGE+ 0.5581, FedGCN 0.1648) because missing classes are not always recoverable from local neighborhoods. FedPUB, a personalization method, is competitive on Seen Graph but degrades sharply on unseen data (e.g., Amazon Photo Unseen Node: 0.4085 vs FedLoG 0.7065) because it optimizes for the local label distribution. FedNTD and FedED, which regularize local logits toward the global model, are the closest competitors on Unseen Node (e.g., Cora 3 clients: FedLoG 0.7341 vs FedED 0.7338) but fall behind on Missing Class (Cora: 0.6472 vs 0.5305) and New Client (Amazon Computers: 0.7386 vs 0.1162), where their logit-matching approach amplifies noisy tail-class information. Overall, FedLoG's advantage is most pronounced in settings requiring knowledge of classes entirely absent from a client's local graph, where its global synthetic data strategy provides a clear structural and representational advantage.

## Relation to Prior Work

FedLoG departs from two lines of subgraph-FL work: (1) methods like FedSAGE+, FedGCN, and FedPUB that compensate for missing neighbors within the *current* local distribution, and (2) logit-calibration approaches (FedNTD, FedED) that regularize local model outputs toward the global model to counter local overfitting. Instead of directly adjusting logits—which risks amplifying noisy tail-class signals—FedLoG repurposes prototypical networks (Snell et al., 2017) as learnable class prototypes that condense structural and class information into synthetic nodes, and borrows the prompt-generator idea from graph condensation (Jin et al., 2021, 2022) to make feature-only synthetic nodes trainable in the same GNN environment as structured graph nodes. The key conceptual shift is treating the graph as mutable: rather than optimizing for the current label distribution, the method explicitly targets generalization to future unseen nodes, missing classes, and entirely new clients.

## Why It Matters / Open Questions

The three proposed evaluation settings (Unseen Node, Missing Class, New Client) fill a genuine gap in subgraph-FL benchmarking, where prior work has evaluated only transductive accuracy on the training graph. The dramatic near-zero performance of most baselines on Missing Class highlights how poorly current FL methods handle truly absent categories—a common real-world scenario. Limitations include evaluation on relatively small citation and product graphs (Cora, CiteSeer, PubMed, Amazon), a higher per-round communication cost than FedAvg/FedGCN (though offset by faster convergence), and reliance on the 'headness' heuristic (high-degree, majority-class nodes are more reliable) that may not hold in all graph domains. Open questions include scalability to million-node graphs, whether the headness assumption generalizes to heterogeneous or temporal graphs, and whether the synthetic-data approach can be extended to other FL tasks beyond node classification.

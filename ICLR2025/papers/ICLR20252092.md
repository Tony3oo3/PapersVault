## Problem

Existing state reconstruction methods for cooperative MARL (e.g., PTDE, SIDiff) reconstruct a dimension-wise state that loses inter-agent dependencies, causing agents to over-focus on specific features rather than interaction partners. Additionally, these methods train the policy on the true global state but execute on the reconstructed state, introducing a train-test inconsistency that degrades robustness and performance retention.
![Teaser figure](../imgs/ICLR20252092/cropped_page1_idx2.webp)

## Input / Output

The decision module takes each agent's local observation $o_t^i$ and its previous reconstructed trajectory state $h_{t-1}^i$ (a GRU hidden state) as input, and produces a reconstructed agent-wise state $s_t^i$ (a per-agent vector encoding inter-agent relationships) along with the selected action $a_t^i$. The agent-wise state is fundamentally different from a dimension-wise projection: it is structured by agent identity rather than by feature dimension, so each agent's state explicitly captures its relational context with all other agents. The guidance module additionally consumes the full global state $s_t$ during training to produce ground-truth agent-wise states via multi-head attention over a per-agent state matrix $S_t \in \mathbb{R}^{n \times d}$.

## Method

RGP consists of a Decision Module (active in both training and execution) and a Guidance Module (training only). The Decision Module uses a diffusion model (10 timesteps, MLP-based denoiser) to reconstruct the agent-wise state conditioned on $[o_t^i, h_{t-1}^i]$, then passes the reconstructed state through a GRU and individual Q-network to select actions via ε-greedy. The Guidance Module decomposes the global state into a per-agent matrix, applies multi-head attention (4 heads, 32-dim embeddings) with agent-ID embeddings to compute ground-truth agent-wise states, and guides the Decision Module through two losses: a diffusion denoising loss (Eq. 11) that trains the generative model to match the guidance agent-wise state, and a trajectory-state matching loss (Eq. 12) that constrains accumulated GRU hidden states. Training further includes two TD losses (Eqs. 13–14) applied through a QMIX-style mixing network to both the decision and guidance modules, ensuring the reconstructed states converge toward optimal-decision-favorable representations. The key architectural insight is that both training and execution use the same reconstructed agent-wise state for decision-making, eliminating the train-test state mismatch while the per-agent attention structure preserves inter-agent relational information that dimension-wise projections discard.

## Results

On SMAC and SMACv2 (Table 1), RGP (applied to QMIX) achieves the best win rate among all state-reconstruction baselines across 8 maps, with particularly large gains on hard maps: 73.1% on 6h_vs_8z (vs. 38.1% for QMIX and 52.4% for PTDE) and 76.9% on 3s5z_vs_3s6z (vs. 10.0% for SIDiff). RGP+HPN reaches 100% win rate on 27m_vs_30m and MMM2, and outperforms HPN-QMIX on every map. In continuous environments, RGP+FACMAC achieves ~1600 average reward in Predator-Prey (6 agents, 2 prey) versus ~1200 for FACMAC alone, and RGP+MADDPG consistently outperforms MADDPG in Cooperative Navigation.

## Baselines & Comparisons

RGP (on QMIX backbone) outperforms QMIX on all 8 maps, with the largest gap on 6h_vs_8z (73.1% vs. 38.1%, +35 pp) and 3s5z_vs_3s6z (76.9% vs. 70.8%), confirming that the reconstructed agent-wise state adds value beyond local observations alone. Against the state-reconstruction baselines, RGP beats PTDE on 7/8 maps (e.g., 73.1% vs. 52.4% on 6h_vs_8z) and SIDiff on all 8 maps (e.g., 76.9% vs. 10.0% on 3s5z_vs_3s6z), demonstrating that agent-wise reconstruction with consistent training/execution states substantially outperforms dimension-wise reconstruction. RGP+HPN surpasses HPN-QMIX on every map (e.g., 84.5% vs. 79.4% on Protoss_360; 100% vs. 99.5% on 27m_vs_30m). RGP also outperforms VDN and QPLEX on all maps, and beats CADP on 7/8 maps (losing only on 3s5z_vs_3s6z: 76.9% vs. 90.2%). In continuous environments, RGP+MADDPG and RGP+FACMAC both outperform their respective backbones (MADDPG, FACMAC) across all Predator-Prey and Cooperative Navigation settings, with RGP+FACMAC achieving roughly 33% higher average reward than FACMAC in the 6-agent Predator-Prey scenario.

## Relation to Prior Work

This paper extends the CTDE state-reconstruction line of work (PTDE, SIDiff) by shifting the reconstruction target from a dimension-wise global state to an agent-wise state that explicitly encodes inter-agent relationships via multi-head attention. It builds on QMIX and HPN-QMIX as the value-decomposition backbone, and on MADDPG/FACMAC for continuous-action portability, while adopting diffusion models (as in SIDiff) as the generative mechanism for state reconstruction. The key conceptual departure is enforcing state consistency: both training and execution use the reconstructed agent-wise state, eliminating the train-test distribution mismatch that plagues prior reconstruction methods.

## Why It Matters / Open Questions

The consistency guarantee (training and execution both use the reconstructed state) directly addresses a practical failure mode in CTDE methods, yielding performance retention ratios of ~95–100% versus 42–88% for prior methods—a meaningful improvement for deployment scenarios where the global state is truly unavailable. The agent-wise formulation is a natural but underexplored alternative to dimension-wise state, and the attention-based decomposition offers interpretability into which agents each agent attends to. Limitations include reliance on vector-based state representations (image-based states are acknowledged as out of scope) and the computational overhead of iterative diffusion denoising at execution time, which may constrain real-time applications.

## Problem

Partial graph matching requires simultaneously determining which nodes to match and how to map them, but existing deep learning approaches either rely on Integer Linear Programming (lacking polynomial worst-case complexity) or require a separate neural module to estimate the number of matches k before solving a k-assignment problem (introducing multi-stage training and error propagation). No prior optimization objective naturally captures the partial nature of the problem while guaranteeing an exact, efficiently solvable formulation.

## Input / Output

The method takes two graphs of potentially unequal size (|V_S| ≤ |V_T|), constructed from keypoint-annotated image pairs (using VGG16-extracted features with GCAN for embeddings) or PPI network pairs (using GIN with degree-based features). It produces a binary partial assignment matrix π ∈ {0,1}^{m×n} where each row and column has at most one 1, encoding which source nodes are matched to which target nodes and which remain unmatched. The cost matrix C and per-node matching biases α, β are all learned end-to-end from the cross-graph affinity matrix.

## Method

The paper formulates partial graph matching as an optimal partial transport problem with weighted total variation divergence, where the unbalancedness parameter ρ and node-specific biases α, β dynamically determine which node pairs are feasible to match (Theorem 5.1: C_ij > ρ(α_i + β_j) implies no assignment). The key theoretical result shows this problem embeds exactly into a standard linear sum assignment problem by appending n−m dummy nodes and clipping the cost matrix at the feasibility threshold, enabling exact solution via the Hungarian algorithm in O(n³) worst-case time. The end-to-end architecture uses a GNN to produce a cross-graph affinity matrix, applies Sinkhorn normalization to derive the cost matrix C = 1 − S, computes matching biases from row/column maxima of the positive affinity, and trains with a novel partial matching loss that combines a feasibility-aware cost loss (penalizing only pairs that could produce false positives) with a bias regularization term that pushes matched nodes' biases toward 1.

## Results

On SPair-71K, OPGM-rs achieves a mean matching F1-score of 57.7±0.2, outperforming the best baseline AFAT-I (NGM-v2) at 56.4±0.4 by 1.3 points. On IMCPT 100, OPGM-rs reaches 72.8±0.1 mean F1-score versus 71.5±0.2 for AFAT-U (GCAN). On PPI network matching, OPGM-rs achieves 88.3% node correctness at 5% noise and 57.7% at 25% noise, consistently outperforming SIGMA (84.7% and 41.4%) and StableGM (86.1% and 57.0%) across all noise levels. OPGM-rs also demonstrates significantly lower inference time than GCAN (ILP), AFAT-I, and AFAT-U on IMCPT 100.

## Baselines & Comparisons

OPGM-rs (GCAN backbone) outperforms all partial matching baselines on SPair-71K: it beats AFAT-I (NGM-v2, 56.4) by 1.3 F1 points, AFAT-U (GCAN, 55.7) by 2.0 points, and GCAN+ILP (54.2) by 3.5 points. On IMCPT 100, OPGM-rs (72.8) surpasses AFAT-U (GCAN, 71.5) and AFAT-I (GCAN, 70.9), while on IMCPT 50 it ties with AFAT-I (GCAN, 72.9 vs 72.7). For PPI network matching, OPGM-rs leads SIGMA by 3.6–17.4 percentage points in node correctness across noise levels (e.g., 88.3% vs 84.7% at 5% noise; 57.7% vs 41.4% at 25%), and edges out StableGM at lower noise (88.3% vs 86.1% at 5%) but narrows to a near-tie at 25% noise (57.7% vs 57.0%). Notably, OPGM-rs achieves these gains with substantially lower inference time than GCAN+ILP, AFAT-I, and AFAT-U, since it reduces partial matching to a single Hungarian algorithm call rather than ILP or multi-stage k-assignment.

## Relation to Prior Work

This paper repurposes the optimal partial transport framework (Séjourné et al., 2023; Bai et al., 2023) for the partial graph matching problem, departing from prior deep graph matching approaches that either frame partial matching as an ILP with dummy nodes (Jiang et al., 2022b) or require a separate neural module to estimate the number of matches k before solving a k-assignment problem (Wang et al., 2023). The key conceptual departure is the use of weighted total variation as the divergence function, which introduces per-node matching biases (α, β) and, crucially, enables an exact embedding of the partial matching problem into a standard linear sum assignment problem solvable by the Hungarian algorithm in O(n³). The neural architecture component (GCAN backbone, Sinkhorn normalization) follows the established deep graph matching pipeline, while the partial matching loss is a new training objective that jointly optimizes the cost matrix and matching biases.

## Why It Matters / Open Questions

The cubic-time exact solution for partial graph matching fills a notable gap: prior methods either lacked polynomial guarantees (ILP/branch-and-bound) or required multi-stage estimation of the match count, introducing error propagation. The matching bias mechanism offers a principled way to encode node importance, which is practically relevant in applications like keypoint matching where some keypoints are more discriminative than others. However, the paper acknowledges that performance degrades under noisy or ambiguous annotations (Pascal VOC, high-noise PPI), and the sensitivity to the unbalancedness parameter ρ remains a practical tuning burden. Open questions include whether the approach can be made more robust to annotation noise and whether the matching bias concept transfers to other partial assignment problems beyond graph matching.

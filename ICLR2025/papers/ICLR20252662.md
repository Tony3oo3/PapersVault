## Problem

Prior benchmarks for LLM inductive reasoning either evaluate only rule induction or only example inference, and rely on fixed test sets that cannot be flexibly varied. This makes it impossible to comprehensively analyze the full inductive+deductive process or to isolate how factors like input distribution, fact quantity, and task form influence reasoning, leaving the underlying mechanism of LLM inductive reasoning unexplained.
![Teaser figure](../imgs/ICLR20252662/cropped_page1_idx0.webp)

## Input / Output

Each test instance provides N observed input-output vector pairs (D-dimensional integer vectors, elements 0–9) generated under a hidden rule, plus a single unseen test input vector. The model must either verbalize the transformation rule (RI) or predict the output vector for the test input (EI). The same underlying rule can be presented in four surface formats—list transformation, real-world narrative, Python function, and string transformation—enabling controlled cross-form transfer experiments.

## Method

MIRAGE synthesizes a rule library from five atomic vector operations (Add, Copy, Map, Pad, Swap) parameterized by random index vectors, then instantiates rules with random vectors to generate facts with controllable dimensionality D, fact count N, and input distribution; noise filtering removes duplicates and trivial facts. The key empirical finding is a persistent gap where example inference accuracy far exceeds rule induction accuracy across all models, prompting strategies (CoT, Self-Consistency, Self-Refine, Hypothesis Refinement), and fact counts, demonstrating LLMs are poor rule-based reasoners. The paper identifies the alternative mechanism as neighbor-based reasoning: observed facts close to the test input in Chebyshev distance significantly boost EI accuracy, and this effect is universal across scenarios and models but strictly localized—deductive density is high within a small radius of the test point and decays rapidly with distance, confirming the model leverages local pattern matching rather than abstract rule generalization.

## Results

On MIRAGE (D=3, N=5), the strongest model (Claude-3.5) achieves 0.79 EI accuracy on List Transformation but only 0.44 RI accuracy, revealing a consistent 15–40% gap where example inference outperforms rule induction across all five models. GPT-4 reaches 0.68 EI vs. 0.47 RI on LT, while Llama2-13B shows near-zero RI (0.01) yet still achieves 0.26 EI. In the method comparison (Table 3, GPT-4o), simple IO(5-shot) prompting matches or exceeds all advanced methods (CoT, SC, SR, HR), with CoT(5-shot) actually reducing EI accuracy by up to 18% relative to IO(0-shot).

## Baselines & Comparisons

The paper benchmarks four advanced prompting methods—Chain-of-Thought (Wei et al., 2022), Self-Consistency (Wang et al., 2023), Self-Refine (Madaan et al., 2023), and Hypothesis Refinement (Qiu et al., 2024)—against simple Input-Output (IO) prompting on GPT-4o. IO(5-shot) consistently achieves the highest or second-highest EI accuracy across all four scenarios (e.g., 0.76 on LT, 0.77 on RP), while CoT(5-shot) drops EI to 0.59 on LT (−17%) and 0.55 on RP (−22%). Self-Consistency (SC, n=5) recovers some EI performance (0.74 on LT) but still trails IO(5-shot). Hypothesis Refinement (HR, t=3, n=5) achieves the best RI score (0.66 on LT) yet the EI–RI gap persists at 0.13, confirming that no method enables the model to leverage its induced rules for deduction. The central takeaway is that the RI–EI performance gap is method-agnostic: even when methods explicitly instruct the model to apply its induced rule (ID, SR, HR), deduction accuracy remains 8–26% above induction accuracy.

## Relation to Prior Work

This paper carves new ground by addressing two specific gaps in prior inductive reasoning evaluation: most existing benchmarks (ARC, MiniARC, 1D-ARC, Case2Code) evaluate either rule induction or example inference in isolation, and their fixed test sets prevent controlled variation in input distribution, difficulty, and scenario. MIRAGE introduces a synthetic rule library based on five atomic vector operations that enables flexible, scalable test generation across four task scenarios (list transformation, real-world problems, code generation, string transformation). Conceptually, the paper also extends the growing mechanistic interpretability literature on LLM reasoning (which has focused on math and multi-hop reasoning) to the underexplored domain of inductive reasoning, and connects the 'neighbor-based reasoning' finding to the in-context learning and induction heads literature.

## Why It Matters / Open Questions

The central finding—that LLMs are poor rule-based reasoners but good neighbor-based reasoners—challenges the standard assumption that inductive reasoning in LLMs mirrors the human paradigm of first deriving an abstract rule and then applying it. This has practical implications: the distribution and proximity of observed examples to the test case matter more than the model's ability to articulate the underlying rule, suggesting that prompt design and example selection can be optimized for neighbor coverage rather than rule clarity. Limitations include the restriction to simple single-digit vector operations, the absence of internal model analysis (relying on black-box performance comparisons), and the focus on evaluation rather than improvement. Open questions include whether the neighbor-based mechanism persists at larger scales or with more complex compositional rules, and whether training methods can shift models toward genuine rule-based reasoning.

## Problem

Existing mechanistic interpretability methods like Distributed Alignment Search (DAS) identify concept-mediating features in hidden representations but require an exhaustive brute-force search over all token positions and layers to locate where a concept is realized. This search bottleneck prevents scaling to larger models and makes the process impractical for automated interpretability pipelines. HyperDAS addresses this by learning to automatically select both the token positions and the feature subspace for a given concept, eliminating the need for manual or exhaustive search.

## Input / Output

The hypernetwork receives a natural-language concept description (e.g., 'the country of a city'), the base prompt, the counterfactual prompt, and the full stack of hidden states from a frozen target model (Llama3-8B) at a fixed layer. It produces a soft alignment matrix G (B×(C+1)) specifying which base token pairs with which counterfactual token for intervention, and a 128-dimensional orthogonal subspace (out of 4096) via a Householder-transformed rotation matrix. At inference, the alignment is snapped to a discrete 1-to-1 token pairing via a double argmax, and the intervened hidden states are fed back into the frozen target model to produce a modified output.

## Method

HyperDAS is a transformer-based hypernetwork with N=8 decoder blocks, each containing self-attention plus two cross-attention modules that attend to the target model's base and counterfactual hidden states at every layer. The concept encoding (the final residual stream vector) drives two parallel mechanisms: (1) a multi-head attention over concatenated base-counterfactual token pairs to compute the alignment matrix G, and (2) a Householder transformation H = I − 2vvᵀ/vᵀv applied to a fixed orthogonal matrix R′, yielding a dynamically selected subspace R = R′H whose columns remain orthogonal. Training uses a RAVEL cross-entropy loss on the intervened model output plus a sparse attention loss that penalizes many-to-one token alignments, with the sparsity weight λ scheduled from 0 to 1.5 over the second half of training. An attention mask is applied to the base prompt's attribute tokens to prevent the hypernetwork from learning a trivial shortcut of simply checking whether the target attribute matches the queried attribute.

## Results

On the RAVEL benchmark with Llama3-8B (layer 15), HyperDAS (asymmetric, per-domain) achieves an average Disentangle score of 84.7%, outperforming the MDAS baseline (76.0%) by 8.7 points. The largest gains are on the Verb domain (93.0% Causal, 98.9% Iso vs. 74.3%/79.6% for MDAS) and City domain (70.8%/93.9% vs. 55.8%/77.9%). A single HyperDAS model trained across all five entity domains still achieves 80.7% average Disentangle, only 4.0 points below the per-domain setup. Peak performance for both HyperDAS and MDAS occurs around layer 15 of Llama3-8B.

## Baselines & Comparisons

The primary baseline is MDAS (Multi-task DAS), the previous state-of-the-art on RAVEL, which uses a multi-task learning objective but relies on manually selected token positions (the last entity token). HyperDAS (asymmetric, per-domain) outperforms MDAS in average Disentangle by 8.7 points (84.7% vs. 76.0%), with the largest Causal gains on Verb (+18.7), City (+15.0), and Physical Object (+7.7), while being marginally worse on Nobel Laureate (−0.6) and Occupation (−0.3). On Iso scores, HyperDAS wins across all five domains. A sparse autoencoder (SAE) baseline is also evaluated in the appendix (Figure 11), where HyperDAS and MDAS both dominate SAE across feature subspace dimensions. The symmetric variant of HyperDAS matches MDAS in average Disentangle (76.9% vs. 76.0%) but with a very different profile—stronger Causal on City and Physical Object but much weaker on Verb—suggesting that asymmetric token selection is critical for generalization across domains.

## Relation to Prior Work

HyperDAS directly extends Distributed Alignment Search (DAS; Geiger et al., 2024b) and weighted interchange interventions (Wu et al., 2024), which require a brute-force search over all token positions and subspaces to identify causal mediators of concepts. The key architectural departure is replacing this exhaustive search with a transformer-based hypernetwork that dynamically selects token alignments and constructs the intervention subspace via a Householder transformation conditioned on a natural-language concept description. The method is evaluated against MDAS (the prior SOTA on RAVEL) and sparse autoencoders, positioning itself as an automated alternative to manually-specified intervention sites.

## Why It Matters / Open Questions

By automating the token-position and subspace search that has been a major bottleneck in mechanistic interpretability, HyperDAS makes causal feature identification more scalable to larger models and more attributes. The paper's careful discussion of faithfulness concerns—masking base-prompt attributes to prevent trivial shortcuts, enforcing one-to-one token alignment via sparsity loss, and analyzing Householder vector geometry—sets a useful template for evaluating whether supervised interpretability methods uncover genuine causal structure or merely inject new information. Key open questions include whether the approach generalizes beyond linear features (the authors note emerging evidence for non-linear mediators), whether the 2.4× compute overhead is acceptable at scale, and whether the layer-specific intervention patterns (e.g., deep layers targeting JSON syntax tokens) reflect genuine model structure or artifacts of the training distribution.

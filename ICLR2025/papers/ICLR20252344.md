## Problem

Existing open-vocabulary 3D instance segmentation methods (OpenMask3D, Open3DIS) rely on computationally expensive 2D foundation models—SAM for segmentation and CLIP for feature aggregation—resulting in inference times of 5–10 minutes per scene. This computational burden makes them impractical for real-world robotics tasks (manipulation, inventory management) that demand fast, repeated re-segmentation as scenes change. The paper asks whether fast 2D object detection alone can replace these heavy segmentation pipelines while maintaining or improving accuracy.

## Input / Output

The method consumes a 3D point cloud scene (N points in homogeneous coordinates), its associated multi-view RGB-D frames (every 10th frame for ScanNet200, all frames for Replica), camera intrinsics/extrinsics, and a set of text prompts. It produces per-instance binary 3D masks (K_3D × N), an open-vocabulary class label per mask, and a confidence score combining class probability and multi-view IoU. The intermediate LG label maps are W×H integer arrays where bounding-box regions are filled with predicted class IDs and all other pixels are set to −1 (ignored).

## Method

Open-YOLO 3D replaces the SAM+CLIP labeling pipeline of OpenMask3D with a two-stage detection-based approach. First, Mask3D (3D CNN backbone + transformer decoder) generates class-agnostic 3D mask proposals, while YOLO-World (open-vocabulary 2D detector) produces bounding boxes with class labels for every RGB frame. These detections are encoded into Low-Granularity (LG) label maps—W×H arrays where bounding-box regions are overwritten with their predicted class, sorted by box size so larger (farther) objects are painted first. An Accelerated Visibility Computation (VAcc) module then computes, in a single GPU batch-matrix-multiply, the per-mask, per-frame visibility matrix V ∈ R^{N_f × K_3D} by combining in-frame and depth-consistency indicators with the mask matrix. Finally, Multi-View Prompt Distribution (MVPDist) selects the top-k most visible frames for each 3D mask, crops the projected (x,y) coordinates of non-occluded in-frame points, looks up their labels from the corresponding LG label maps, and assigns the class with the highest occurrence probability as the mask's label. A confidence score multiplies this class probability by the average multi-view IoU between the projected 3D mask and the best-matching 2D bounding box.

## Results

On ScanNet200 validation, Open-YOLO 3D achieves mAP of 24.7% (mAP50: 31.7%, mAP25: 36.2%) using only 3D-network proposals, outperforming the best open-vocabulary baseline Open3DIS (18.6% mAP) by 6.1 points while running ~16× faster (21.8 s/scene vs. 57.7 s/scene). On the Replica dataset, it reaches 23.7% mAP versus 14.9% for Open3DIS under the same 3D-only proposal setting. With oracle masks, MVPDist achieves 39.6% mAP, surpassing CLIP-based Open3DIS (30.9%) and OpenMask3D (29.1%), and even exceeding closed-vocabulary Mask3D (35.5%).

## Baselines & Comparisons

Against OpenMask3D (Takmaz et al., NeurIPS 2023), Open-YOLO 3D improves mAP from 15.4% to 24.7% (+9.3) while reducing inference time from 553.9 s to 21.8 s per scene (~25× speedup), by replacing SAM+CLIP feature aggregation with YOLO-World bounding boxes and MVPDist. Compared to Open3DIS (Nguyen et al., CVPR 2024), the most direct competitor, Open-YOLO 3D gains 6.1 mAP points (24.7 vs. 18.6) under the same 3D-only proposal setting and 1.0 mAP even against Open3DIS's stronger 2D+3D fusion variant (24.7 vs. 23.7), while being ~16× faster (21.8 s vs. 360.1 s). OVIR-3D (Lu et al., CoRL 2023) lags significantly at 13.0% mAP, trailing Open-YOLO 3D by 11.7 points. OpenScene (Peng et al., CVPR 2023) in its best 2D-fusion variant reaches only 11.7% mAP, roughly half of Open-YOLO 3D's score. The only method with a higher mAP is closed-vocabulary Mask3D (26.9%), which is not directly comparable since it is restricted to 200 known classes; notably, Open-YOLO 3D's oracle-mask result (39.6% mAP) exceeds Mask3D's oracle result (35.5%), indicating that MVPDist is a stronger labeling mechanism than CLIP features.

## Relation to Prior Work

This paper departs from the OpenMask3D (Takmaz et al., 2023) and Open3DIS (Nguyen et al., 2024) lineage, which rely on SAM for 2D segmentation and CLIP for vision-language feature aggregation to label 3D mask proposals. The key conceptual shift is replacing pixel-level 2D features (CLIP embeddings from SAM masks) with box-level 2D features (class labels from a lightweight open-vocabulary detector like YOLO-World), arguing that the 3D-to-2D projection already encodes sufficient instance geometry. It builds on Mask3D for fast class-agnostic 3D proposal generation and introduces MVPDist and accelerated visibility computation as new scoring and association mechanisms that operate entirely on bounding-box-level information.

## Why It Matters / Open Questions

The ~16× speedup (22 s vs. 360 s per scene) while simultaneously improving mAP makes open-vocabulary 3D instance segmentation viable for time-sensitive robotics tasks like manipulation and inventory management, where scenes change dynamically and pipelines must re-run frequently. The finding that low-granularity label maps (bounding boxes) match or slightly outperform high-granularity maps (SAM masks) challenges the assumption that pixel-accurate 2D segmentation is necessary for 3D mask labeling. Limitations include reliance on 3D proposal networks that miss small objects, and reduced efficiency for sequential prompting in static scenes compared to CLIP-based methods that can cache features. Open questions include whether fast 2D instance segmentation (e.g., FastSAM) can complement the 3D proposal network to recover small-object performance.

## Problem

Generative models lack rigorous statistical guarantees on their outputs, making them unreliable in safety-critical applications. While conformal language modeling (CLM) provides admissibility control for generative models, it requires a fixed number of admissibility evaluations per calibration instance, which is prohibitively costly when these checks must be performed by human domain experts (e.g., in medicine). The paper addresses this sample-efficiency gap by reducing the number of required admissibility queries during calibration.

## Input / Output

The method takes a condition x (a text question, a chest X-ray image paired with a text prompt, a news article, or a molecular scaffold graph) and a black-box generative model G, and produces a prediction set of generated examples that satisfies conformal admissibility control at a user-specified level α. The prediction set is constructed sequentially: an initial set of i.i.d. samples is drawn from G|x, then pruned by greedy diversity and quality filters. Calibration yields per-step thresholds λ_(s) (s=0,1,2) that control how many samples are retained at each stage, and the final output is the pruned set C_(2) with the guarantee that it contains at least one admissible example with probability ≥ 1−α.

## Method

SCOPE-Gen constructs prediction sets in three sequential stages: a generation stage (s=0) that draws i.i.d. samples from G until a non-conformity threshold is exceeded, followed by two filter stages (s=1,2) that apply greedy sub-sampling (farthest-point sampling for diversity, max-quality selection for quality) to prune the set. The key theoretical insight is that the total admissibility of the final prediction set factorizes as a Markov chain across these sequential steps, so each step's admissibility can be controlled independently using standard one-dimensional conformal prediction (empirical quantile calibration), avoiding the multi-dimensional calibration problem that CLM addresses with Pareto testing. During calibration, only samples up to the first admissible one need to be evaluated for admissibility, since subsequent samples are guaranteed to be in an already-admissible set. This yields a large reduction in admissibility queries (e.g., ~21% of CLM's on MIMIC-CXR) and lower computational complexity O(K) versus O(g^K) for CLM's grid-based Pareto search.

## Results

SCOPE-Gen consistently outperforms CLM across all four tasks (TriviaQA, MIMIC-CXR, CNN/DM, Molecules) on admissibility queries, runtime, and prediction set size. On MIMIC-CXR, SCOPE-Gen requires only 4.214 admissibility queries versus CLM's 20.000 (~21% reduction) and completes calibration in 0.072 s versus CLM's 113.677 s (~10⁻⁴ relative time). Prediction set sizes are also substantially smaller: e.g., 7.390 vs. 14.434 on MIMIC-CXR and 9.409 vs. 17.448 on Molecules. The 'CLM reduced max' baseline (capping queries at 10) achieves fewer queries but suffers catastrophic rejection rates (81.7% on MIMIC-CXR, 100% on Molecules), whereas SCOPE-Gen maintains low rejection (≤20.3%).

## Baselines & Comparisons

The primary baseline is CLM (Quach et al., 2024), which uses Pareto testing with three jointly calibrated parameters. SCOPE-Gen dominates CLM on every task for all three primary metrics: it requires roughly 2–5× fewer admissibility queries (e.g., 4.214 vs. 20.000 on MIMIC-CXR; 8.606 vs. 19.280 on Molecules), runs 100–1500× faster (0.072 s vs. 113.677 s on MIMIC-CXR), and produces prediction sets that are 2–50% smaller (7.390 vs. 14.434 on MIMIC-CXR; 9.409 vs. 17.448 on Molecules). The only metric where SCOPE-Gen is slightly worse is Frac. Reject on CNN/DM (0.057 vs. 0.023), while on MIMIC-CXR it actually rejects fewer calibrations (0.203 vs. 0.240). A derived baseline, 'CLM reduced max' (capping queries at 10), reduces query counts but incurs prohibitive rejection rates (81.7% on MIMIC-CXR, 100% on Molecules), confirming that simply limiting CLM's sample budget is not a viable alternative to the sequential Markov-chain factorization used by SCOPE-Gen.

## Relation to Prior Work

This paper builds directly on Conformal Language Modeling (CLM; Quach et al., 2024), which first introduced admissibility control for black-box generative models using multi-dimensional calibration via Pareto testing (learn-then-test). SCOPE-Gen departs from CLM by restructuring prediction set construction as a sequential pipeline (generation → diversity filter → quality filter) whose total admissibility factorizes as a Markov chain, enabling each step to be calibrated independently with standard univariate conformal prediction rather than joint multi-parameter optimization. The greedy filters draw on farthest-point sampling from computer vision, and the overall oracle-in-the-loop calibration philosophy connects to active learning, while the cascaded filtering structure is related to Fisch et al. (2021) but applied to generative (rather than classification) settings.

## Why It Matters / Open Questions

The ~5× reduction in admissibility queries and ~1000× reduction in calibration runtime are practically significant in safety-critical domains (radiology, drug design) where each admissibility check may require a human domain expert. The Markov-chain factorization is a clean theoretical contribution that generalizes naturally to longer sequential pipelines, though the current implementation is fixed at three stages. Key limitations include reliance on automated admission functions in experiments (human-in-the-loop evaluation is deferred to future work), the assumption of i.i.d. calibration data, and the somewhat rigid two-filter architecture. Open questions include whether the approach extends to non-exchangeable data, adaptive filter ordering, and integration with the growing body of work on hallucination detection without distribution-free guarantees.

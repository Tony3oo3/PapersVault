## Problem

Existing approximate unlearning methods align the model's output-space behavior (losses, predictions) with an oracle retrained without the forget set, but information about forgotten samples can persist in intermediate representations, leaving models vulnerable to white-box membership inference attacks on embeddings. The paper demonstrates that successful unlearning correlates with representation-space similarity to the oracle, motivating a shift from output-space to representation-space unlearning objectives.
![Teaser figure](../imgs/ICLR20250539/cropped_page2_idx0.webp)

## Input / Output

SURE takes a pre-trained classifier (ResNet-18 or ViT-Small on 32×32 or 64×64 RGB images), a forget set of unlabeled images, a validation set of unlabeled images drawn from the same distribution (matched in size to the forget set, never seen during original training), and the retain set with labels. The forget and validation samples are assigned binary domain labels (1 and 0 respectively) that drive the adversarial training. The output is the full set of unlearned model weights, with the domain regressor module discarded after unlearning.

## Method

SURE augments the original feature-extractor/classifier architecture with a lightweight two-layer domain regressor during unlearning, adapting the DANN framework so that the two 'domains' are the forget set and an unseen validation set rather than source/target distributions. A gradient reversal layer (GRL) is inserted between the feature extractor and domain regressor: during backpropagation, the GRL negates gradients flowing from the domain regressor to the feature extractor, causing the feature extractor to learn representations that are indistinguishable between forget and validation samples while the domain regressor simultaneously learns to discriminate them. The classification head is trained in parallel on the retain set to preserve utility, yielding a saddle-point objective where the feature extractor and classifier minimize the combined loss while the domain regressor maximizes the discrimination loss. This directly erases forget-set signatures from the embedding space rather than merely adjusting output-space losses, which the paper shows reduces vulnerability to representation-space membership inference attacks (MIARS) and improves stability across forget set sizes.

## Results

On CIFAR-10 with ResNet-18, SURE achieves the smallest accuracy gaps to the oracle across most metrics: ΔRA 0.46±0.10, ΔUA 1.0±0.63, ΔUtility 0.34±0.27, and ΔCTA 0.84±0.28 (Top-1), outperforming L1Sparse, SCRUB, and RL. SURE also shows the lowest Average Error Gap and second-smallest weight distance to the oracle (after L1Sparse), and is most effective at defending against representation-space membership inference attacks (MIARS-I and MIARS-II). Results are consistent across CINIC-10 and Tiny ImageNet, with SURE outperforming all baselines on nearly all accuracy and MIA benchmarks except Relative Run Time, where the additional domain regressor module adds overhead.

## Baselines & Comparisons

SURE outperforms L1Sparse (Liu et al., NeurIPS 2024) on ΔUA, ΔUtility, and ΔCTA in both Top-1 and Top-5, though L1Sparse achieves a smaller ΔRA (0.03 vs. 0.46) and better Relative Run Time due to SURE's additional domain regressor module. Against SCRUB (Kurmanji et al., NeurIPS 2024), SURE wins on every accuracy metric (e.g., ΔUtility 0.34 vs. 1.26 Top-1) and on both MIARS attacks, while SCRUB shows comparable performance only at the specific forget set size used for its hyperparameter tuning. BTeacher (Chundawat et al., AAAI 2023) and the boundary-shift methods BE+/BS+ (Chen et al., CVPR 2023) are substantially outperformed by SURE across all metrics; in the Resolving Confusion task (Table 2), SURE achieves 0.08±0.11 Retain Error and 22.75±0.31 Test Error, compared to BTeacher's 1.17±0.29 and 27.67±0.57, and BE+'s 0.0±0.0 and 28.61±0.58. SURE also demonstrates superior stability: when the forget set size is changed from the tuned value of 500 to 100 or 10, the performance gap between SURE and the oracle remains small, whereas L1Sparse and SCRUB degrade significantly.

## Relation to Prior Work

SURE repurposes the Domain-Adversarial Training of Neural Networks (DANN) framework from Ganin et al. (2016), transplanting the gradient reversal layer and domain classifier into the unlearning setting where the forget set and a held-out validation set play the roles of source and target domains. This departs from the dominant line of unlearning work (SCRUB, L1Sparse, BTeacher, boundary-shifting methods) that formulates unlearning as an output-space problem—matching losses, distilling from a teacher, or shifting decision boundaries—by instead directly manipulating intermediate representations. The paper also extends the evaluation toolkit by introducing representation-space membership inference attacks (MIARS) using KNN on embeddings, a dimension absent from prior unlearning benchmarks.

## Why It Matters / Open Questions

The paper identifies a concrete vulnerability: unlearning methods that align output-space behavior with the oracle can still leak forget-set information through internal representations, exposing models to white-box membership inference. The empirical correlation between representation alignment (measured via Git Re-Basin weight distance) and unlearning success provides a useful diagnostic for the field. A key limitation is that SURE requires more unlearning epochs than competitors due to the additional domain regressor, and the authors note that a class-conditional discriminator could improve efficiency at the cost of training multiple discriminators. Open questions include whether the representation-space advantage persists at larger scale (ImageNet, billion-parameter models) and whether the DANN-style adversarial objective can be made more sample-efficient.

## Problem

Decentralized optimization with general affine coupled constraints (e.g., resource allocation, power flow, vertical federated learning) lacked a first-order algorithm with optimal accelerated linear convergence. Prior methods either required more expensive proximal oracles, assumed restricted variable domains, or only achieved sub-linear rates, leaving a gap between the theoretical lower bounds and the best available algorithms for the general case.

## Input / Output

Each node i locally stores its smooth strongly convex function f_i, constraint matrix A_i ∈ R^{m×d_i}, and vector b_i ∈ R^m, with potentially different local dimensions d_i across nodes. Because nodes cannot directly exchange their local variables x_i (due to dimension mismatch), all inter-node communication is restricted to exchanging quantities A_i x_i ∈ R^m over the edges of a given communication graph. The algorithm outputs the optimal solution x* achieving ‖x^k − x*‖² ≤ ε in O(√κ_f log(1/ε)) gradient calls, O(√κ_f √κ_A log(1/ε)) matrix multiplications, and O(√κ_f √κ_A √κ_W log(1/ε)) communication rounds.

## Method

The key insight is a two-stage Chebyshev acceleration that decouples the gradient-computation count from the condition numbers of the communication graph (κ_W) and constraint matrix (κ_A). First, the coupled constraint is reformulated using a communication-friendly matrix W′ = P_√W(W) (a Chebyshev polynomial of the gossip matrix), making the problem amenable to decentralized computation. Second, the resulting affine constraint is preconditioned via K = √(P_B(B^T B)), yielding a strongly convex problem with O(1) condition number on the constraint side. The Accelerated PAPC (APAPC) algorithm is then applied to this preconditioned reformulation, with W′ and K multiplications implemented through numerically stable Chebyshev iteration procedures that only require decentralized communications and local A, A^T multiplications. Matching lower bounds on gradient calls, matrix multiplications, and communication rounds are established via a dual-problem construction on a path graph, confirming the algorithm is information-theoretically optimal.

## Results

The proposed Algorithm 2 achieves optimal accelerated linear convergence with O(√κ_f log(1/ε)) gradient computations, O(√κ_f √κ_A log(1/ε)) matrix multiplications, and O(√κ_f √κ_A √κ_W log(1/ε)) communication rounds, matching the proven lower bounds (Theorem 2). In experiments on a synthetic linear regression problem (κ_f=3140, κ_A=27, κ_W=89, n=20 nodes, Erdős-Rényi graph), the method demonstrates the steepest convergence slopes across all three resource metrics (gradient calls, matrix multiplications, communications) compared to Tracking-ADMM and DPMM. On the VFL linear regression task using the Mushrooms dataset (n=7 devices, m=100 samples), the same pattern holds: the proposed first-order method converges fastest in terms of gradient computations and matrix multiplications, though it requires more communication rounds per iteration due to the Chebyshev iteration structure.

## Baselines & Comparisons

The paper compares against two baselines: Tracking-ADMM (Falsone et al., 2020) and DPMM (Gong and Zhang, 2023), both of which are proximal algorithms requiring a proximal operator evaluation per iteration. On the synthetic linear regression problem (κ_f=3140, κ_A=27, κ_W=89), the proposed first-order method achieves the steepest convergence slopes in all three resource metrics—gradient calls, matrix multiplications, and communication rounds—outperforming both baselines. On the VFL Mushrooms experiment (n=7, m=100), the same advantage holds: the proposed method converges fastest per gradient call and per matrix multiplication. However, the paper notes that Algorithm 2 involves many communications per iteration (due to the Chebyshev iteration requiring O(√κ_W) W-multiplications per outer step), so in terms of raw communication rounds the gap narrows compared to DPMM and Tracking-ADMM, which make numerous gradient calls per iteration instead. The key distinction is that the proposed method is the first first-order (gradient-only) algorithm to achieve optimal accelerated linear convergence for general affine coupled constraints, whereas both baselines require a more expensive proximal oracle.

## Relation to Prior Work

This paper extends the optimal-algorithm line for decentralized consensus optimization (Scaman et al. 2017; Kovalev et al. 2020) to the more general setting of affine coupled constraints, where prior work was restricted to resource allocation, consensus, or required proximal oracles. The core technique—Chebyshev polynomial preconditioning to decouple gradient evaluations from communication and constraint-matrix condition numbers—builds directly on Salim et al. (2022a) and the spectrum-compression properties of Chebyshev polynomials used in Scaman et al. (2017). The base algorithm (Accelerated PAPC) is inherited from Salim et al. (2022a), while the novel contribution is the strongly convex communication-friendly reformulation via a gossip matrix and the matching lower bounds under a discrete-time oracle model.

## Why It Matters / Open Questions

This is the first first-order decentralized algorithm achieving optimal (accelerated linear) convergence for general affine coupled constraints, closing a gap where prior methods either required proximal oracles, were restricted to resource allocation, or had sub-linear rates. The matching lower bounds establish that the √κ_f · √κ_A · √κ_W scaling is information-theoretically necessary, giving practitioners a clear complexity target. Open questions include extending the results to non-strongly convex objectives, time-varying graphs, and stochastic settings, as well as understanding whether the √n communication overhead relative to pure consensus optimization (shown in Appendix A) can be circumvented with problem-specific structure.

## Problem

Long Convolution Sequence Models (LCSMs) such as Hyena achieve O(L log L) training via FFT, but their autoregressive inference remains Ω(L²) because the full input sequence is not available ahead of time, preventing direct use of FFT. Prior work (Massaroli et al., 2024) only provides approximate inference by distilling filters into low-dimensional LTI SSMs, which changes the model class and requires data-independent filters. This paper provides the first exact quasilinear-time O(L log² L) inference algorithm for LCSMs and identifies the architectural properties that enable such speedups.

## Input / Output

The method takes a prompt of P tokens (handled via a one-time O(P log P) FFT prefill), data-independent convolution filters ρ ∈ R^{M×L×D}, block parameters (MLPs, gates), and a sampler function, then autoregressively generates L−P additional tokens. It produces all layer activations a⁰,…,aᴹ ∈ R^{L×D} and the generated token sequence. The sequence length L is assumed to be a power of 2 (rounding up changes asymptotics by at most a factor of 2), and the method requires O(MLD) static memory for activations with peak memory O(MLD) reducible to O(LD) by dropping parallelism on the largest tile.

## Method

The core mechanism is a fractal tiling of the contribution space (inspired by van der Hoeven's relaxed polynomial interpolation) that groups the O(L²) pairwise contributions y_i·ρ_{j−i} into balanced square tiles of side U, where U is the largest power of 2 dividing the current position i. At each iteration i, the algorithm finalizes z_i with a single red cell (y_i·ρ_0), then computes the gray tile — the aggregated contribution of y_{[i−U+1,i]} to z_{[i+1,i+U]} — via an FFT-based convolution in O(U log U) time, then returns z_i and unlocks y_{i+1}. This yields O(L log² L) total FLOPs with O(L) peak memory per tile. A key practical advantage is that gray-tile computations across all M layers have disjoint inputs and outputs, enabling near-complete across-layer parallelization of the mixer workload. The Hybrid implementation dynamically selects the optimal τ primitive (depthwise-separable Conv1D, Flash Conv1D, PyTorch FFT, or FlashFFT) per tile size, and engineering optimizations (precomputed DFTs, circular convolution to halve FFT length, CUDA Graphs to eliminate CPU dispatch overhead) further improve wall-clock performance, achieving up to 7.8× end-to-end and 110× mixer speedups on Hyena.

## Results

Flash Inference achieves up to 7.8× end-to-end inference speedup and up to 110× speedup on the convolution-based mixer component of the Hyena architecture, compared to the standard lazy (naive) inference baseline. The theoretical complexity is O(L log²L) FLOPs for the mixer part versus Ω(L²) for both lazy and eager baselines. In the synthetic setting, the Hybrid τ implementation reaches up to 124× mixer speedup and 11.6× end-to-end speedup (B=8, D=768, L=2^15). The method also reduces activation memory access from Ω(L²) to O(L log L) per iteration.

## Baselines & Comparisons

The paper compares Flash Inference (Hybrid) against four baselines: Lazy (parallel), Eager (parallel), and their non-parallel (NP) counterparts. Flash Inference dominates all baselines by a wide margin: it achieves 3.1×–7.8× end-to-end speedup over the parallel Lazy baseline, while Eager is actually *slower* than Lazy (0.54×–0.66×) in nearly all configurations, confirming that the eager strategy's O(L²) FLOPs with poor memory locality is worse than the lazy strategy's. The non-parallel variants (Lazy_NP, Eager_NP) are consistently 10–20% slower than their parallel counterparts, validating the paper's across-layer parallelization observation. On the mixer component specifically (Table 1), Flash Inference achieves 64×–111× speedup over parallel Lazy, while Eager achieves only 0.49×–0.56× (i.e., it is slower than Lazy). The Hybrid τ implementation outperforms any single fixed convolution kernel (Conv1D, Flash Conv1D, FFT, FlashFFT) by dynamically selecting the best kernel per tile size, yielding an additional 10–20% gain over the best single-kernel approach.

## Relation to Prior Work

This paper directly builds on van der Hoeven's (1997) relaxed polynomial convolution, adapting its quasilinear tiling scheme to the autoregressive inference setting of long convolution sequence models (LCSMs) such as Hyena. It departs from Massaroli et al. (2024) 'Laughing Hyena Distillery,' which achieves subquadratic inference only approximately by distilling the convolution filter into a low-dimensional LTI SSM, whereas Flash Inference provides exact inference with no approximation. The practical implementation leverages FlashFFTConv's fused kernels and introduces CUDA Graphs to eliminate CPU dispatch overhead, positioning the work at the intersection of algorithmic number theory and systems-level GPU optimization.

## Why It Matters / Open Questions

This is the first exact O(L log²L) inference algorithm for LCSMs, closing the gap between their O(L log L) training efficiency and previously quadratic inference cost. The general Flash Inference framework identifies two architectural properties (contribution-based mixers and query-independent contributions) that enable the tiling, offering a design template for future subquadratic architectures that are fast at inference by construction. Key limitations include the O(MLD) activation storage requirement (unlike recurrent SSM views), inapplicability to transformers due to query-dependent contributions, and the open problem of making convolution filters data-dependent while preserving causality. The 110× mixer speedup is well-evidenced across multiple configurations and GPU types, but the 7.8× end-to-end gain is more modest, reflecting that non-mixer components (MLPs, sampling) remain unchanged.

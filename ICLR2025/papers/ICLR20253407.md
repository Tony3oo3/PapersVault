## Problem

Linear Mode Connectivity (LMC) — the property that linearly interpolated parameters between independently trained models retain performance — has been established for neural networks via permutation invariance of hidden neurons, but remains unexplored for soft tree ensembles. Because tree architectures possess structural symmetries absent in neural networks, it is unclear whether standard permutation-based matching suffices or whether additional invariances must be accounted for to achieve LMC in tree-based models.

## Input / Output

The method takes two trained soft tree ensemble parameter matrices (each of shape M×P, where M is the number of trees and P the per-tree parameter count) and, for activation matching, a batch of 512 sampled feature vectors to compute tree-output similarity. The output is a pair of re-indexed and sign-adjusted parameter matrices that, when linearly interpolated at any λ∈[0,1], yield a merged model with near-zero performance degradation. For the proposed modified decision list architecture, only tree permutation (solved via a single LAP) is needed, eliminating the combinatorial search over flip and order patterns that scales as 2^D·D! for oblivious trees of depth D.

## Method

The paper identifies two invariances unique to tree architectures beyond tree permutation: subtree flip invariance (simultaneously swapping left/right subtrees and negating the sigmoid parameters w and b at the split node, exploiting σ(−c)=1−σ(c)) and splitting order invariance (permuting splitting rules across depths in oblivious trees while correspondingly permuting leaf positions). Matching algorithms (Activation Matching and Weight Matching) are developed that solve the tree permutation via the Linear Assignment Problem and then exhaustively search over all combinations of flip and order patterns, with node-weighted inner products reflecting each node's influence on the number of downstream leaves. Additionally, the authors design a modified decision list architecture — a unidirectional binary tree with one terminal leaf fixed to zero — that structurally eliminates both subtree flip and splitting order invariances, so that LMC is achieved using only tree permutation matching, enabling efficient model merging without the exponential search over invariance patterns.

## Results

On 16 tabular datasets from Tabular-Benchmark, incorporating all tree-specific invariances (permutation + subtree flip + splitting order) reduces the test barrier to near zero for oblivious trees (0.348 ± 0.172 at D=2, M=256), confirming LMC is achieved. Tree models with all invariances consistently outperform MLPs with only permutation matching: at D=2, the oblivious tree barrier (0.348) is ~8.6× smaller than the MLP barrier (2.997), and at D=3, the non-oblivious tree barrier (0.740) is ~8× smaller than the MLP barrier (5.940), while maintaining comparable accuracy (~76.5%). The proposed modified decision list architecture, which eliminates both subtree flip and splitting order invariances by design, achieves a test barrier of 0.468 ± 0.150 (WM) using only tree permutation, demonstrating that LMC can be preserved without the computationally expensive additional invariance search.

## Baselines & Comparisons

The primary baseline is the MLP with ReLU activation and width M=256, matched using the permutation method from Ainsworth et al. (2023). Tree models with all invariances ("Ours") achieve substantially smaller barriers than MLPs at every depth: at D=1, the non-oblivious tree barrier drops to 0.181 vs. the MLP's 0.491; at D=2, the oblivious tree barrier is 0.348 vs. the MLP's 2.997; and at D=3, the non-oblivious tree barrier is 0.740 vs. the MLP's 5.940. Accuracy levels are comparable across all models (~76.3–76.6%), confirming the barrier reduction is not at the cost of predictive performance. Within tree architectures, the modified decision list (which has no subtree flip or splitting order invariance) achieves a test barrier of 0.468 (WM) using only permutation, which is larger than the oblivious tree with all invariances (0.348) but still far below the naive interpolation barrier (~6.7). This confirms that while additional invariances yield the smallest barriers, the modified decision list offers a practical trade-off by eliminating the exponential search over invariance patterns (U = 2^D · D! for oblivious trees) while still achieving near-zero barriers.

## Relation to Prior Work

This paper extends the Linear Mode Connectivity (LMC) framework, originally developed for neural networks via permutation invariance (Frankle et al., 2020; Entezari et al., 2022; Ainsworth et al., 2023), to soft tree ensembles. The key conceptual departure is the identification of two tree-specific invariances—subtree flip and splitting order—that have no analogue in neural networks and are necessary for achieving LMC in tree architectures. The matching algorithms adapt the Linear Assignment Problem formulation from Git Re-Basin (Ainsworth et al., 2023) but require exhaustive search over the additional invariance patterns, and the soft oblivious tree architecture follows Popov et al. (2020). The modified decision list architecture is a novel design that eliminates these extra invariances by construction, drawing on the classical decision list concept from rule-based learning.

## Why It Matters / Open Questions

This is the first demonstration that LMC can be achieved for tree ensembles, which are among the most widely deployed models for tabular data, opening the door to parameter-based model merging, federated learning, and continual learning in this domain. The broader principle that architecture-specific invariances must be accounted for (beyond mere permutation) to achieve LMC generalizes beyond trees and may inform LMC analysis for other structured models. Limitations include the computational intractability of exhaustive invariance search for deep trees (U = 2^D · D! for oblivious trees), the observation that barriers grow with depth, and the fact that the modified decision list, while computationally efficient, still yields larger barriers than perfect binary trees with full invariance handling. Open questions include whether general mode connectivity (Garipov et al., 2018) holds for trees, whether heuristic matching can replace exhaustive search for deep architectures, and whether the invariance-accounting principle transfers to other hierarchical or mixture-of-experts structures.

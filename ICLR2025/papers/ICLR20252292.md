## Problem

Existing few-shot anomaly detection methods based on vision-language models (e.g., WinCLIP, PromptAD) follow a 'one-for-one' paradigm, requiring a separate set of learned prompts for each object category, which is computationally expensive and impractical for deployment. Meanwhile, 'one-for-all' anomaly detection methods that train a single unified model across all classes typically assume access to large amounts of normal training data. No prior work combines the one-for-all paradigm with few-shot learning via VLMs, leaving a gap for scenarios where only a handful of normal images per class are available and a single unified model is desired.

## Input / Output

The method takes RGB images as input, with only K (1–4) normal training images per class across all categories in the dataset. At test time, a single test image is processed through CLIP's ViT-L/14 visual encoder (modified with V-V attention) and BLIP-Diffusion's Q-Former to extract patch features and category tokens. The output is a pixel-level anomaly score map in [0,1]^{H×W} (combining prompt-guided and visual memory bank anomaly maps) and a scalar image-level anomaly score computed as the sum of the maxima of both maps.

## Method

IIPAD introduces a class-shared prompt generator that produces instance-specific prompts by combining three components: (1) shared learnable prefix tokens [P_i]/[N_i] capturing general normality/abnormality semantics, (2) instance-specific visual tokens C_i^n/C_i^a obtained by projecting CLIP's class token and cross-attending it with Q-Former category tokens (CoCoOp-style addition into the prefix), and (3) projected object tokens O_i^n/O_i^a appended at the end of the prompt sequence. The prompt generator is trained via a multi-modal contrastive objective that includes semantic-level alignment (pulling normal prompt embeddings toward normal patch features and pushing anomalous ones away), token-level alignment (matching individual prompt tokens to groups of relevant patches via sparse min-max normalized similarity weights), and textual guidance from manually crafted general descriptions of normality and abnormality. To address the cross-category mismatch problem in the one-for-all setting, a category-aware visual memory bank stores Q-Former category tokens alongside patch features, enabling two-stage retrieval that first filters by category similarity before computing patch-level anomaly scores.

## Results

Under the one-for-all paradigm, IIPAD achieves 94.2% image-level AUROC and 96.4% pixel-level AUROC on MVTec (1-shot), and 85.4% / 96.9% on VisA, outperforming all baselines. At 4-shot, IIPAD reaches 96.1% / 97.0% on MVTec and 88.3% / 97.4% on VisA, approaching full-shot one-for-all methods like UniAD (96.5% / 96.8% MVTec) and OmniAL (97.2% / 98.3% MVTec). On the pixel-level PRO metric, IIPAD achieves 89.8% (1-shot) and 91.2% (4-shot) on MVTec, surpassing the next-best baseline WinCLIP by over 5 points.

## Baselines & Comparisons

IIPAD consistently outperforms all one-for-all baselines across both MVTec and VisA at every shot setting. Against the closest CLIP-based competitor WinCLIP, IIPAD gains +1.4% image AUROC and +4.0% pixel AUROC on MVTec (1-shot), and +2.3% / +2.3% on VisA. PromptAD, the strongest few-shot prompt-learning baseline, is surpassed by IIPAD by +7.9% image AUROC and +4.6% pixel AUROC on MVTec (1-shot), though PromptAD is competitive on VisA pixel-level (96.3 vs 96.9). Traditional reconstruction-based methods (SPADE, PatchCore, FastRecon) lag far behind, with PatchCore reaching only 63.7% image AUROC on MVTec (1-shot) versus IIPAD's 94.2%. When compared against baselines in their native one-for-one setting (Table 2), IIPAD (still one-for-all) matches or exceeds PromptAD on pixel-level AUROC at all shot levels and is within 0.5% on image-level at 4-shot. Against full-shot one-for-all methods (Table 3), IIPAD at 4-shot surpasses UniAD and DiAD on MVTec pixel-level and beats OmniAL and DiAD on both VisA metrics, while remaining slightly below HVQ-Trans (98.0% MVTec image AUROC).

## Relation to Prior Work

This paper extends the prompt-learning-for-anomaly-detection line (WinCLIP, PromptAD, AnomalyCLIP) by replacing per-class fixed prompts with a class-shared, instance-induced prompt generator that fuses learnable tokens with instance-specific visual tokens from CLIP's ViT and BLIP-Diffusion's Q-Former, drawing on CoCoOp's conditional prompt mechanism and V-V attention for local feature preservation. It departs from prior work in two key ways: (1) the prompt generator produces a unique prompt per test instance rather than per class, enabling the one-for-all paradigm in the few-shot regime for the first time, and (2) a category-aware memory bank using Q-Former tokens resolves the cross-class feature mismatch that plagues naive shared memory banks. The multi-modal training objective (contrastive visual alignment at both semantic and token levels, plus textual guidance from hand-crafted normality/abnormality descriptions) is a novel combination not seen in prior prompt-based AD methods.

## Why It Matters / Open Questions

The practical significance is substantial: a single trained model can detect anomalies across all product categories without retraining per class, which is critical for manufacturing lines where new products are introduced frequently and normal samples are scarce. The method closes the performance gap between one-for-all and one-for-one few-shot anomaly detection (e.g., 96.4 vs 95.9 pixel AUROC on MVTec 1-shot), suggesting that instance-adaptive prompting can substitute for class-specific tuning. Limitations include reliance on CLIP's visual encoder (which may struggle with domain-specific textures), evaluation limited to two industrial benchmarks (MVTec, VisA), and the added architectural complexity of jointly using CLIP + Q-Former. Open questions include whether the approach generalizes to medical or natural-image anomaly detection, whether the Q-Former dependency can be replaced by lighter alternatives, and how performance scales with the number of classes in the one-for-all setting.

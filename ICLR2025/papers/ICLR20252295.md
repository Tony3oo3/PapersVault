## Problem

Existing LLM-driven synthetic data generation frameworks suffer from four interrelated gaps: limited generalization (they modify data via fixed principles like shuffling options rather than generating novel scenarios), poor controllability (no mechanism for user-specified constraints like length or topic), low diversity (LLMs produce repetitive outputs on similar inputs), and unverified truthfulness (hallucinations introduce factual errors into labels). No prior framework simultaneously addresses all four dimensions while remaining format-agnostic across dataset types.

## Input / Output

DATAGEN accepts three inputs: a base dataset in standardized JSON format (containing text-with-label or standalone-text items), a natural-language dataset description that guides the LLM on what to synthesize, and optional fine-grained generation constraints (e.g., 'do not generate text longer than 20 words', 'include an emoji', 'output in Chinese'). The output is a synthetic text dataset of labeled items accumulated over N iterative sampling rounds from the base dataset. The framework is format-agnostic, handling multiple-choice, math word problems, NLI pairs, and other text dataset types without modification.

## Method

DATAGEN is a four-module pipeline: (1) Generation Hint uses few-shot examples selected via K-means clustering over text-embedding-ada-002 embeddings to maximize example diversity, combined with attribute-guided generation (modeling output as y=P(x,a) where a is an attribute vector) and temperature manipulation; (2) Internal Evaluation performs iterative self-reflection and self-enhancement loops, a code-based mathematical verification step where the LLM generates Python code to independently solve math problems and replace incorrect labels, and a RAG-based truthfulness check that extracts keywords, retrieves Wikipedia passages, and prompts the LLM to detect factual discrepancies; (3) Post-Processing applies difficulty enhancement (paraphrasing questions/choices, adding extra context, introducing plausible distractors) and group checking that computes pairwise Euclidean distances over embeddings and removes items below a similarity threshold θ. The key design insight is that these modules are plug-and-play and can be selectively activated depending on dataset type, enabling a single unified framework to handle diverse generation tasks while simultaneously optimizing for generalization, controllability, diversity, and truthfulness.

## Results

DATAGEN generates datasets with only 3.83% average entity overlap with the original data (vs. 45.67%–56.67% for DyVal2), confirming substantial introduction of novel knowledge. The code-based mathematical evaluation module improves label accuracy from 44% to 88%, and RAG-based validation corrects 4.2% of factually erroneous examples. In the data augmentation application, fine-tuning Llama3-7b on 1,000 DATAGEN-generated Alpaca samples raises MT-Bench average score from 5.259 to 6.403. For benchmarking, most LLMs show a performance drop on generated GSM8K (e.g., ChatGPT: 0.762→0.665) but improve on knowledge-intensive datasets like MMLU and TruthfulQA, suggesting overfitting to the original GSM8K.

## Baselines & Comparisons

The primary baseline comparison is against DyVal2 (Zhu et al., 2024b) on knowledge richness, measured by entity overlap rate between generated and original data. DATAGEN achieves an average overlap of only 3.83%, dramatically lower than DyVal2's four principles which range from 45.67% (paraphrasing questions) to 56.67% (adding a new choice), indicating DATAGEN introduces far more novel scenarios and knowledge rather than superficially modifying existing items. In the broader comparison (Table 1), DATAGEN is the only framework that simultaneously achieves all eight desired properties: generalization, controllability, diversity, truthfulness, no human intervention, new knowledge, dynamic benchmarking, and data augmentation. No other method (DyVal, DyVal2, S3Eval, Wang et al., etc.) checks all boxes, with most lacking in 3–5 of these dimensions.

## Relation to Prior Work

DATAGEN positions itself against a lineage of LLM-based synthetic data generation frameworks (DyVal, DyVal2, S3Eval, MetaMath, etc.) that are typically limited to specific dataset formats (multiple-choice, math word problems) or that modify existing items via fixed transformation rules (paraphrasing, shuffling, adding context). Rather than extending any single prior method, DATAGEN repurposes several established techniques—few-shot learning with embedding-based clustering, RAG-based factuality checking, code-execution verification, and self-reflection/self-enhancement—into a unified, modular pipeline that simultaneously targets generalization, diversity, truthfulness, and controllability across arbitrary text dataset types. Its closest conceptual ancestor is DyVal2, which also aims for dynamic evaluation, but DATAGEN departs by generating entirely new data items (3.83% entity overlap vs. DyVal2's 45–56%) rather than transforming existing ones.

## Why It Matters / Open Questions

DATAGEN offers a practical, plug-and-play framework for researchers who need high-quality synthetic data for benchmarking or fine-tuning without manual annotation, and its cost analysis (≤$0.20/item) makes it accessible. However, the paper itself highlights important limitations: data augmentation yields only modest gains on knowledge-intensive datasets (TruthfulQA, MMLU), suggesting that pretraining-scale knowledge cannot be easily injected via 200 fine-tuning samples, and the error analysis reveals persistent factuality and format errors that a more robust verification agent could address. Open questions include whether the framework extends to multimodal data, how to target specific capability dimensions during generation (e.g., explicitly challenging reasoning vs. knowledge), and whether self-alignment within the same model (as opposed to cross-model augmentation) can be effectively supported.

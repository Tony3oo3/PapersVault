## Problem

The Shapley value, the theoretical foundation of most feature attribution methods, implicitly assumes non-negative interactions between players (i.e., convex games). In non-convex games—ubiquitous in deep learning models due to operations like max pooling and softmax—negative interactions cause the efficiency axiom to undervalue features that are critical to the model's decision, producing counterintuitive attribution scores where highly relevant features receive low or even zero attribution.

## Input / Output

The method takes a differentiable model (e.g., VGG19, ResNet50, BERT), a target input instance (images converted to 20×20 patches, or token sequences), and a baseline value (typically zero or data mean). It outputs per-feature attribution scores structured as an attribution map over image patches or per-token scores for text. The key computational detail is that interactions are approximated via a first-order Taylor expansion using gradients from a single backpropagation pass, reducing the per-step cost from O(n²) forward evaluations to O(n) backward passes.

## Method

The paper first reformulates the Shapley value as a weighted sum of pairwise causal interactions (Theorem 1) and proves that convexity is equivalent to all interactions being non-negative (Theorem 2), exposing the implicit convexity assumption. To handle non-convex games, it proposes Aggregated Positive Interactions (API), which decomposes each player's contribution into individual effects and interactions, then applies g(x)=max(x,0) to discard negative interactions before aggregation—effectively relaxing the efficiency axiom to prevent undervaluation from role redundancy or output saturation. For tractable computation on differentiable models, API approximates each interaction I_ij(T) via a first-order Taylor expansion of the gradient difference, enabling all n feature interactions at a given coalition to be computed in a single backward pass. The final algorithm (Algorithm 1) samples k random permutations, sequentially builds coalitions, computes gradient-based interaction estimates at each step, retains only positive values, and accumulates them into the attribution vector.

## Results

On ImageNet (ResNet50, 20×20 patches), API achieves 30% lower effective complexity than KernelSHAP, Integrated Gradients, and the Approximated Shapley value on average, requiring only 203 features to reproduce the model decision at KL divergence 0.001 versus 337–339 for baselines. In the toy max-function example, API correctly assigns a higher payoff (7) to the dominant player 8 versus player 4 (4), whereas the Shapley value inverts this (2.5 vs. 3.25). On the sigmoid example, API assigns 4.99 to player 1 (vs. 2.51 for Shapley), resolving the undervaluation caused by saturation-induced negative interactions.

## Baselines & Comparisons

API outperforms all three baselines on effective complexity, requiring roughly 40% fewer features (203 vs. 337–339) to reproduce the model's decision at KL=0.001, indicating more focused and compact attributions. Against the Approximated Shapley value (g=identity), API resolves the undervaluation problem: in the max-function toy example, the Shapley value assigns player 8 (coefficient 7) a lower payoff (2.5) than player 4 (coefficient 4, payoff 3.25), while API correctly reverses this to 7 vs. 4. Against KernelSHAP and Integrated Gradients, both constrained by the efficiency axiom, API produces sharper attribution maps that concentrate on key regions (e.g., eyes, wheels) rather than dispersing across background, as confirmed by Insertion/Deletion metrics in Figure 2 where API achieves higher logit values. On the BERT/IMDB language task, API highlights the full semantically relevant phrase ('can hardly be taken seriously on any level') whereas the Approximated Shapley value only captures 'hardly be', demonstrating that negative interactions from token redundancy obscure contributions under the efficiency axiom. The paper notes that KernelSHAP occasionally matches or slightly exceeds API numerically on Insertion/Deletion, likely due to errors from the first-order Taylor approximation used in API's gradient-based interaction estimation.

## Relation to Prior Work

This paper builds on the Shapley value framework (Shapley, 1953) and the cooperative game-theoretic interaction indices of Grabisch & Roubens (1999), but departs from the standard formulation by explicitly decomposing the Shapley value into individual effects and pairwise interaction terms, revealing an implicit convexity assumption. It connects to the causal interaction literature (VanderWeele, 2015) for the definition of interactions and to permutation sampling (Castro et al., 2009) for estimation. The proposed Aggregated Positive Interactions (API) relaxes the efficiency axiom that underpins KernelSHAP and Integrated Gradients, positioning itself as a principled alternative to the heuristic absolute-value post-processing commonly applied to Shapley-based attributions in non-convex deep learning models.

## Why It Matters / Open Questions

The paper provides a clear game-theoretic explanation for a long-observed practical problem: Shapley-based attribution methods systematically undervalue important features in DNNs due to negative interactions from max pooling, attention, and saturation. This reframing gives theoretical grounding to what practitioners have handled heuristically, and the gradient-based approximation makes the approach tractable for differentiable models. Limitations include the first-order Taylor approximation introducing errors (acknowledged in the paper), the method being more computationally expensive than Integrated Gradients, and the open question of how to handle genuinely informative negative interactions (e.g., in regression tasks) without discarding meaningful signal. The choice of the refinement function g remains task-dependent, and the approach has not been validated on very large feature spaces or multi-modal settings.

## Problem

Existing LLM-based agents for multi-step decision-making rely on external performance measures (handcrafted heuristics or manually designed prompts) as priors to guide their choices, but such measures may be unavailable, flawed, or erroneous in real-world scenarios. The paper asks whether an agent can instead develop an internal utility judgment from its own posterior experiences, enabling rational decision-making without dependence on external evaluation signals.

## Input / Output

The agent receives a task description and a user query, then iteratively generates decision traces where each step is a (thought, function-call) pair executed via ReAct. The output is the single decision sequence (trajectory of states and actions) with the highest Elo score at its terminal step, selected from up to 20 explored traces. Each trace is capped at 12 steps, and the entire process is bounded by a computational budget on the number of LLM API calls, making the method applicable under constrained inference settings.

## Method

RaDAgent alternates between two phases in an iterative loop. In Experience Exploration, the agent selects which intermediate decision step to expand next using a softmax over learned Elo scores (with a temperature parameter), augmented by a 'rejection' step that triggers generation of an entirely new decision trace via ReAct. In Utility Learning, the agent performs pairwise comparisons between the newly generated trace and a randomly sampled existing trace using the LLM itself (run twice with swapped candidate order to mitigate position bias), then updates Elo scores via the standard Elo update rule. Intermediate decision-step Elo scores are propagated bottom-up as temperature-weighted sums of their children's scores, and the exploration temperature is annealed inversely with the square root of the log of the number of Elo updates, so that well-estimated steps are explored more deterministically. This self-play loop allows the agent to converge on accurate per-step utility estimates purely from its own exploration history, eliminating the need for any externally designed evaluation function.

## Results

RaDAgent achieves 43.00% success rate on Game of 24, 59.36 reward on WebShop, and 61.92% pass rate on ToolBench, outperforming all baselines across all three benchmarks. On the real-world RestBench dataset, it reaches 84.0% correct path rate on TMDB and 80.7% on Spotify. The paper reports an average improvement of approximately 7.8% over the strongest baseline (DFSDT) across the three primary datasets, while also reducing the number of ChatGPT API calls needed to reach comparable or superior performance.

## Baselines & Comparisons

RaDAgent wins decisively on Game of 24 (43.00% vs. DFSDT's 29.00%, a +14-point gap) and ToolBench (61.92% vs. DFSDT's 50.20%, +11.72 points), where the Elo-based utility learning most effectively prunes poor decision branches. On WebShop, the margin is smaller (59.36 vs. DFSDT's 57.25, +2.11), which the authors attribute to the single 'golden answer' evaluation penalizing valid alternative items. Against the tree-search baselines ToT-BFS and ToT-DFS, RaDAgent leads by 32 and 29 points on Game of 24 respectively, and by 23.92 and 16.34 points on ToolBench. On RestBench, RaDAgent outperforms RestGPT (the strongest real-world baseline) by 5.0 points on TMDB (84.0 vs. 79.0) and 6.2 points on Spotify (80.7 vs. 74.5). The efficiency analysis further shows that under constrained API budgets (e.g., 30 calls), RaDAgent maintains the highest pass rate while ToT-BFS, ToT-DFS, and DFSDT drop below even CoT, highlighting that the Elo-guided exploration avoids wasteful API calls that the UCT-based baselines incur.

## Relation to Prior Work

RaDAgent sits at the intersection of tree-search-based LLM agents (ToT, RAP, DFSDT) and the Elo rating system from competitive gaming. While prior methods like ToT and DFSDT use Monte Carlo Tree Search structures to explore decision trees, they rely on externally designed value functions or handcrafted heuristics to score and select branches. RaDAgent's key departure is replacing these external performance measures with a self-learned utility: it uses pairwise LLM comparisons to update Elo scores for each decision step, which then guide subsequent exploration in a softmax-temperature scheme. The exploration phase itself borrows directly from ReAct for trace generation and from MCTS for the select-expand-evaluate-backpropagate loop, but the evaluation step is fundamentally different—converging through iterative comparison rather than a fixed scoring function.

## Why It Matters / Open Questions

The removal of external performance measures addresses a practical bottleneck: in real-world tool-use and web-navigation tasks, reliable handcrafted heuristics are often unavailable or brittle, and LLM self-evaluation prompts can be inconsistent. The Elo-based approach provides a principled, convergent mechanism for learning decision utilities from posterior experience alone. However, the method requires state recovery at each step (limiting applicability to irreversible actions), depends on the LLM's comparative judgment quality, and the 20-iteration budget may be insufficient for very long-horizon tasks. Open questions include whether the approach generalizes to multi-agent settings, whether the Elo scores transfer across tasks, and how performance scales with decision sequence length beyond the 12-step cap used here.

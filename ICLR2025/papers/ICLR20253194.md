## Problem

Existing ML approaches for MILP train class-specific models (e.g., for Set Cover or Facility Location) that fail to generalize to unseen problem classes, and public MILP datasets like MIPLIB lack the diversity and volume needed for a foundation-model-style training regime. This paper asks whether a single model trained on sufficiently diverse MILP classes can generalize across problem types, and addresses the data bottleneck by introducing an LLM-based pipeline to generate such diversity at scale.

## Input / Output

Each MILP instance is encoded as a bipartite graph of variable and constraint nodes with features extracted after the root-node LP relaxation (17-dim variable and 29-dim constraint features for IG prediction; 19-dim and 5-dim for branching). The IG prediction task outputs a scalar gap value; learning-to-branch outputs a score per candidate variable at each B&B node; and the contrastive task jointly encodes the MILP graph and a natural-language description (embedded via NV-Embed-v1) into a shared 64-dim latent space, evaluated by 4-way and 10-way retrieval accuracy.

## Method

MILP-Evolve is an LLM-based (GPT-4o) evolutionary pipeline that starts from 8 seed MILP classes and applies 10 chain-of-thought prompt operators (Add, Cross-Over, Mutate, New, Delete) level-by-level to generate over 1,000 diverse MILP classes, followed by automated parameter grid search and filtering for feasibility and solve-time criteria. The learning architecture uses a Graph Convolutional Network over the bipartite variable-constraint graph, augmented with a Transformer attention layer over 512 subsampled nodes plus three summary nodes (mean variable, mean constraint, and a global summary token) to capture global structure; the attention layer is omitted for branching to reduce per-node overhead. Training uses Huber loss for IG prediction, cross-entropy imitation of the strong-branching expert for branching, and a CLIP-style symmetric cross-entropy for MILP-text alignment. A key empirical finding is that increasing the number of training classes yields substantially larger gains than increasing instances per class, and pre-training on MILP-Evolve data transfers effectively to MIPLIB via fine-tuning.

## Results

On the MILP-Evolve held-out test set, the proposed model (Ours) achieves a 5.8× correlation improvement over the Seed baseline for Integrality Gap Prediction (0.58 vs. 0.10 Pearson correlation, with deviation reduced from 32.96% to 20.14%), a 1.92× accuracy improvement for Language-MILP Contrastive Learning (70.54% 4-way and 54.17% 10-way accuracy vs. 37.21% and 18.73% for Seed), and a 1.42× improvement in the fraction of instances solved to optimality for Learning to Branch (70.90% vs. 49.59% for Seed, with 15.49% time improvement over SCIP Default). On MIPLIB transfer learning, Ours achieves 0.59 correlation for IG prediction and 82.08%/75.57% 4-way/10-way accuracy for contrastive learning, outperforming all baselines.

## Baselines & Comparisons

The paper compares against three baselines: Seed (8 standard MILP classes from prior SOTA work), Seed+Param. (Seed augmented with 89 additional parameters via grid search), and Seed+VAE (Seed augmented with VAE-generated instances from Guo et al., 2024). Ours dominates all baselines across all three tasks: for IG prediction, it reduces deviation by 12–13 percentage points and more than doubles correlation over Seed+VAE (0.58 vs. 0.26); for contrastive learning, it nearly doubles 4-way accuracy over Seed+Param. (70.54% vs. 39.68%) and substantially outperforms Seed+VAE (70.54% vs. 33.67%); for learning to branch, it is the only method achieving positive time improvement (15.49% vs. negative values for all baselines) and solves 6.4–21.8% more instances to optimality. Notably, Seed+VAE underperforms even the plain Seed baseline on contrastive learning and branching, suggesting VAE-based instance augmentation does not transfer well to multi-class settings, whereas class-level diversity from MILP-Evolve provides the critical generalization gain.

## Relation to Prior Work

This paper departs from the dominant paradigm in ML-for-MILP research (Gasse et al., 2019; Khalil et al., 2016; Scavuzzo et al., 2022), which trains class-specific GNN models on a handful of benchmark problems (Set Cover, Facility Location, etc.) and fails to generalize to unseen formulations. It draws an explicit analogy to the foundation model shift in CV/NLP, proposing instead a single multi-class model trained on 1000+ diverse MILP classes generated by MILP-Evolve, an LLM-based evolutionary pipeline that extends prior instance-level augmentation methods (VAE-based from Guo et al., 2024; Geng et al., 2023) to the class level. The Language-MILP contrastive task is directly inspired by CLIP (Radford et al., 2021), repurposing the dual-encoder alignment framework to bridge the MILP graph modality with natural language via NV-Embed text embeddings.

## Why It Matters / Open Questions

The MILP-Evolve dataset (2000+ generated classes) and the multi-class training framework provide a practical stepping stone toward general-purpose MILP foundation models, addressing the data scarcity bottleneck that has limited prior work to 8–16 problem classes. A key open question is whether the three task-specific models can be unified into a single foundation model, and whether the approach scales to the full MIPLIB benchmark for branching (only 13 instances had suitable solve times). The finding that class diversity dominates instance quantity for generalization is a useful design principle, but the learning-to-branch task remains notably weaker in the multi-class setting, suggesting that sequential decision-making across heterogeneous problem structures is still an unsolved challenge.

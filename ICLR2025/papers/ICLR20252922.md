## Problem

Language models must trade off reliance on context versus prior knowledge, but prior work on knowledge conflicts has not identified a controllable mechanism that mediates this choice. The paper asks whether a simple, low-dimensional subspace exists within a transformer that encodes the binary decision of whether to follow context or prior knowledge, and whether it can be manipulated to steer model behavior.
![Teaser figure](../imgs/ICLR20252922/cropped_page6_idx0.webp)

## Input / Output

The model receives a context string (e.g., a counterfactual fact), a query, and an intent expressed either as a natural-language instruction ('Ignore the context' / 'Only listen to the context') or as a numerical context weight (0 or 1). The output is a single answer token sequence, evaluated via pair-accuracy: a context-query pair is correct only if the model produces the context-dependent answer under the ctx intent AND the prior-dependent answer under the pri intent. Beyond the generated answer, the interpretability pipeline produces a unit-norm basis vector u ∈ R^D (the 1D subspace direction) and a scalar c(w) ∈ R that, when injected at a specific layer's residual stream, replaces the intent component without requiring the intent in the prompt.

## Method

The paper first fine-tunes or few-shot-adapts instruct models (Llama-3.1-8B, Gemma-2-9B, Mistral-7B) on intent-augmented knowledge-conflict pairs, then uses an iterative O(L) activation-patching algorithm with the Token Identity Patchscope to identify which MHA output layers at the last token position causally control the context-vs-prior decision (layers 12–16 for Llama-3.1). At the last layer of this base range, the authors learn a rank-1 orthogonal projection P = uu^⊤ by minimizing cross-entropy on patched forward passes where the subspace component of the target is replaced with that of the source, effectively searching for a direction whose manipulation flips the model's answer. The key finding is that this single 1D subspace, learned on a fine-tuned instruct model, transfers directly to non-fine-tuned instruct and base models of the same family, and a strong correlation (r = 0.908) exists between a model's pair-accuracy and how distinctly its activations separate along this subspace for the two intents.

## Results

Fine-tuned Llama-3.1-8B-Instruct achieves ~90% pair accuracy on the in-domain CCS-BF test set, with ICL reaching ~88%. Performance degrades on out-of-domain sets: CCS-MH (multi-hop reasoning) shows mild drops for FT and significant drops for ICL, while CCS-AR (arithmetic) shows significant degradation for both. The identified 1-dimensional subspace in layer 16 enables effective steering: 83% PairAcc on the fine-tuned instruct model (vs. 95% baseline with explicit intent), 73% on the zero-shot instruct model (significantly exceeding its baseline), and above-baseline performance on the base model with ICL. A strong correlation (r = 0.908) is found between model performance and the separation of subspace values for the two intents.

## Baselines & Comparisons

The paper does not compare against external methods but evaluates three adaptation strategies (zero-shot, ICL, QLoRA fine-tuning) and the proposed subspace steering intervention. Fine-tuning outperforms ICL on out-of-domain generalization (CCS-MH, CCS-AR), while both substantially exceed zero-shot baselines. The key comparison is between the baseline (model given explicit intent instructions like 'Ignore the context') and the steered model (no intent in prompt, but the 1D subspace value manually set): steering recovers 83% of the 95% FT baseline and, notably, lifts the zero-shot instruct model to 73% PairAcc—far above its unsteered performance—suggesting the capability is latent in the pretrained model. The subspace transfers across model families: analogous rank-1 subspaces are identified in Gemma-2 9B and Mistral-v0.3 7B with similar transferability from fine-tuned instruct to base models. Mistral shows weaker out-of-domain generalization than Llama-3.1 and Gemma-2, particularly on CCS-AR and cross-format intent generalization.

## Relation to Prior Work

This paper extends the knowledge-conflict literature (Longpre et al., 2021; Du et al., 2024; Monea et al., 2024) by introducing an explicit intent dimension (follow context vs. follow prior) to make the task controllable, then uses mechanistic interpretability tools—activation patching (Meng et al., 2022), the Token Identity Patchscope (Ghandeharioun et al., 2024), and distributed alignment search (Geiger et al., 2024)—to locate the mechanism. Prior work identified individual attention heads that promote each answer (Yu et al., 2023; Ortu et al., 2024) or used path patching to find head subsets (Jin et al., 2024), but none isolated a single low-dimensional subspace that acts as a binary switch. The paper's key departure is hypothesizing and verifying that a rank-1 subspace in one layer encodes the context-vs-prior decision, building on the linear subspace hypothesis (Bolukbasi et al., 2016; Vargas & Cotterell, 2020) and prior subspace-steering work (Arditi et al., 2024; Marks & Tegmark, 2024).

## Why It Matters / Open Questions

The finding that a single 1D direction in one layer serves as a transferable knob—effective on fine-tuned instruct, non-fine-tuned instruct, and base models of the same family—suggests context sensitivity is a fundamental architectural property rather than an emergent artifact of instruction tuning. This provides a practical, lightweight intervention (setting one scalar) for controlling RAG behavior without retraining. Key limitations include that the knob works best when the context answer is directly copyable rather than requiring multi-step reasoning, and the study covers only three model families. Open questions include whether adaptive steering is possible, whether the subspace influences other behaviors like instruction-following, and whether the mechanism generalizes to settings requiring integration of both context and prior rather than binary selection.

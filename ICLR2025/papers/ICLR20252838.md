## Problem

LLMs struggle with complex multi-step reasoning due to limited planning ability, as pre-training corpora obscure the high-level reasoning structures that models need to learn. Existing remedies—prompting techniques and task-specific fine-tuning—suffer from poor robustness, limited cross-task generalization, and dependence on carefully designed prompts or curated datasets, making them difficult to scale across diverse reasoning domains.

## Input / Output

The method takes a free-form text prompt posing a reasoning problem and produces a two-stage output: first a Python-style pseudocode plan (constrained to under 200 words, high-level, balancing conciseness and informativeness) that encodes the reasoning control flow, then a natural language response that faithfully follows the plan's structure. Training examples are (prompt, code-form plan, response) triples, where plans are automatically extracted from existing prompt-response corpora rather than manually curated.

## Method

CODEPLAN decomposes response generation into two stages—planning and surface realization—formulated via a variational upper bound where the plan Z is an explicit intermediate variable (Dirac posterior over a gold plan). The key insight is using programming language pseudocode as the plan representation, since code natively supports conditional branching (if-statements), iterative loops (for-loops), modular function composition, and hierarchical task decomposition, making it a structured, versatile, and interpretable encoding of reasoning logic. Training data (2M examples) is constructed by prompting Llama-3-8B-Instruct to synthesize code-form plans from WebInstruct prompt-response pairs, enabling scalable data construction without task-specific curation. The model is trained with shared parameters to minimize both the plan generation loss (-log p(Z*|X)) and the surface realization loss (-log p(Y|X,Z*)), with the optimal plan balancing informativeness for reasoning guidance against conciseness for efficient generation.

## Results

CODEPLAN achieves a 25.1% relative improvement over vanilla training, averaged across 13 multi-step reasoning benchmarks spanning mathematical, symbolic, instruction-following, multi-hop QA, and decision-making tasks. On Mistral-7B, CODEPLAN reaches 59.5% on GSM8K, 34.3% on MATH, 90.8% on Boolean Expression, 92.6% on Coin Flipping, 57.5% on Last Letter Concatenation, and 87.2% on Dyck Language. Gains are amplified on more complex tasks: on MuSiQue 4-hop questions, the relative EM improvement over vanilla training reaches 43.8%, compared to 6.3% for 2-hop questions.

## Baselines & Comparisons

CODEPLAN consistently outperforms all three baselines across nearly all 13 benchmarks. Against Plan-and-Solve Prompting (Wang et al., 2023), CODEPLAN wins by substantial margins on most tasks (e.g., GSM8K 59.5 vs. 45.5, MATH 34.3 vs. 17.3, Last Letter 57.5 vs. 41.5 on Mistral-7B), demonstrating that learned code-form planning surpasses what natural-language prompt engineering can achieve. Against Quiet-STaR (Zelikman et al., 2024), which learns implicit latent plans, CODEPLAN dominates across the board (e.g., Boolean 90.8 vs. 66.0, Coin Flip 92.6 vs. 57.2, Last Letter 57.5 vs. 1.5), while Quiet-STaR even underperforms the untrained backbone on several tasks despite significant computation overhead. Against Vanilla Training (fine-tuning on the same WebInstruct data without explicit planning), CODEPLAN achieves the headline 25.1% average relative gain, with the largest improvements on structured reasoning tasks like Last Letter Concatenation (+53.3% relative) and ALFWorld decision-making (+64.5% relative). Notably, Vanilla Training can actually degrade performance relative to the base model on some tasks (e.g., Mistral-7B drops 2–9 points on symbolic and multi-hop QA), whereas CODEPLAN consistently improves upon the base model across all benchmarks.

## Relation to Prior Work

CODEPLAN carves new ground at the intersection of NLP planning (Reiter & Dale's planning/realization decomposition), code generation, and variational inference. It departs from chain-of-thought and Plan-and-Solve prompting by explicitly disentangling planning from surface realization, and from implicit-plan methods (Quiet-STaR, Predicted-PA) by using human-readable code-form pseudocode rather than latent vectors. Unlike code-aided reasoning approaches (PAL, CodeRL) that generate executable code to directly solve narrow tasks like math, CODEPLAN uses non-executable pseudocode as a general intermediate representation for diverse reasoning, trained via a variational upper bound with explicit plan supervision extracted automatically from web corpora.

## Why It Matters / Open Questions

The framework offers a practical, scalable recipe for improving LLM reasoning: automatically extract code-form plans from existing web data, fine-tune with minimal overhead, and gain consistent improvements across math, symbolic, QA, instruction-following, and decision-making tasks. The finding that gains amplify with task complexity (6.3% → 43.8% on MuSiQue hops) and that pseudocode outperforms both natural language plans and executable code for general reasoning provides a clear design principle. Open questions include whether implicit plan posteriors (Gaussian, discrete codebooks) could further improve performance, how to integrate plan verification and iterative refinement, and whether the approach scales to frontier-scale models where the planning bottleneck may manifest differently.

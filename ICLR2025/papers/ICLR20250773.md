## Problem

Agentic systems that combine foundation models with prompts, tools, and workflows are currently hand-designed, requiring substantial domain-specific manual tuning. Following the recurring ML pattern where learned solutions replace hand-crafted ones, this paper asks whether the design of agentic systems can be fully automated, and identifies an unexplored approach: defining agents in code and using a meta agent to programmatically discover ever-better ones.
![Teaser figure](../imgs/ICLR20250773/cropped_page1_idx0.webp)

## Input / Output

The meta agent (GPT-4) receives a task-specific domain description, a simple ~100-line Python framework providing FM query APIs and prompt formatting utilities, and an ever-growing archive of previously discovered agents with their performance metrics. It outputs a complete Python 'forward' function that defines a new agentic system, which is then evaluated on validation data and added to the archive. Because the search space is Turing-complete code, the output can represent any combination of prompts, tool calls, workflows, and control flow — not just a fixed template with swappable prompts.

## Method

Meta Agent Search iteratively programs new agents in code using a meta agent (GPT-4) conditioned on an archive of prior discoveries. Each iteration, the meta agent generates a high-level design description, implements it as a 'forward' function within a minimal framework, and undergoes two self-reflection passes to ensure novelty relative to the archive. The generated agent is evaluated on validation data; if runtime errors occur, the meta agent debugs via up to five additional self-reflection cycles. Successful agents are added to the archive with their metrics, which then informs subsequent iterations. The key insight is that using a Turing-complete programming language as the search space — rather than prompt-only mutation or graph/network topologies — theoretically enables discovery of any possible agentic system, while leveraging FMs' strong coding priors to make the search tractable. The open-endedness mechanism (encouraging 'interestingly new' designs based on the archive) allows the algorithm to build on stepping stones, combining previously discovered ideas in novel ways analogous to evolutionary crossover.

## Results

Meta Agent Search discovers agents that outperform all state-of-the-art hand-designed baselines across four domains. The largest gains appear in Reading Comprehension (DROP F1: 79.4 vs. 65.8 best baseline, +13.6) and Math (MGSM accuracy: 53.4% vs. 39.0% best baseline, +14.4%). Gains are smaller but consistent in Multi-task (MMLU: 69.6% vs. 65.9%) and Science (GPQA: 34.6% vs. 31.6%). Transferred agents from MGSM also improve GSM8K accuracy by 25.9% and GSM-Hard by 13.2% over baselines, and the best ARC agent reaches 48.3% accuracy when transferred to Claude-Sonnet.

## Baselines & Comparisons

Meta Agent Search wins against all eight baselines on every domain tested. The most substantial margins are over Chain-of-Thought (+15.2 F1 on DROP, +25.4% on MGSM) and COT-SC (+15.0 F1 on DROP, +25.2% on MGSM), which represent the most widely used agent designs. Against the strongest individual baselines per domain—Role Assignment on DROP (65.8 F1), LLM Debate on MGSM (39.0%), COT-SC on MMLU (65.9%), and Self-Refine on GPQA (31.6%)—Meta Agent Search still leads by 13.6, 14.4, 3.7, and 3.0 points respectively. The comparison with OPRO (prompt optimization) is particularly informative: Meta Agent Search outperforms it by 10.3 F1 on DROP, 22.8% on MGSM, 2.0% on MMLU, and 1.7% on GPQA, demonstrating that learning all agent components in code (not just prompts) yields substantially larger gains. The paper attributes the smaller gaps in MMLU and GPQA to insufficient FM knowledge for those harder questions, a limitation expected to diminish as foundation models improve.

## Relation to Prior Work

This paper builds on the code-based program search paradigm of FunSearch (Romera-Paredes et al., 2024), where an LLM iteratively programs a forward function, and extends it to the domain of agentic system design. It draws on open-endedness algorithms (OMNI, Intelligent Go-Explore) for the archive-based exploration of 'interesting' solutions, and integrates self-reflection (Self-Refine, Reflexion) for iterative code refinement. The key departure from prior ADAS attempts—prompt optimization (OPRO, PromptBreeder) and graph/network-based workflow search (DyLAN, GPT-Swarm, DSPy)—is the use of Turing-complete code as the search space, which can represent any possible agentic system rather than a fixed subset of components.

## Why It Matters / Open Questions

By formulating ADAS as a new research area with a clear three-component optimization framework (search space, search algorithm, evaluation function), this paper provides a unifying lens for a rapidly growing field and a simple, effective baseline algorithm (Meta Agent Search) that is easy to reproduce. The surprising transferability of discovered agents across domains and models suggests that learned agentic design patterns capture generalizable structure rather than domain-specific hacks, which could accelerate agent development for new applications. Open questions include whether the approach scales to multi-step interactive environments, whether multi-objective optimization (cost, latency, safety) changes the discovered designs, and whether higher-order self-referential ADAS (improving the meta agent via ADAS itself) leads to runaway capability growth.

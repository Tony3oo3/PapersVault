## Problem

Existing post-training quantization (PTQ) techniques designed for Transformers fail to handle the unique activation patterns of State Space Models: the selective scan input (x) is highly sensitive to quantization errors due to the causal recurrence dynamics, and the SSM output (y) contains massive outliers absent from self-attention outputs. This prevents SSMs from benefiting from INT8 hardware acceleration, limiting their deployment on resource-constrained edge devices and request-intensive cloud serving.

## Input / Output

The method consumes a pre-trained SSM (Mamba or Jamba) in FP16 along with 512 randomly sampled calibration sentences from the Pile dataset to compute static per-tensor scaling factors. The output is a fully quantized INT8 model (weights and activations) where the SSM input uses a 99.999th-percentile clipping threshold and the SSM output is quantized in a Hadamard-transformed space, with the inverse transform fused into the output projection to preserve compute-invariance. All scaling factors are fixed at calibration time, enabling plug-and-play deployment without retraining.

## Method

Quamba applies two targeted techniques to address the distinct quantization challenges of selective SSMs. For the input activation x, which is numerically small but causally sensitive (quantization errors propagate through the linear recurrence), it uses percentile-based max clipping (p=99.999) to suppress a tiny fraction of outliers that otherwise skew the quantization step and degrade precision. For the output activation y, which contains extreme outliers (≥100), it applies a Walsh-Hadamard Transform to project into an outlier-free space, then fuses the inverse Hadamard into the output linear projection (W_out^H = H_n · W_out) so the transform incurs zero additional runtime cost. The paper also derives a theoretical error bound showing the global quantization error is bounded by εb/(1−a), leveraging the exponential decay of the state transition matrix A. The full pipeline quantizes all weights (A, D, B, C, Δ, projection layers) and activations to 8-bit symmetric integers, with fused causal convolution, fused RMSNorm, and CUTLASS-based INT8 GEMM for hardware acceleration.

## Results

Quamba 2.8B (W8A8) achieves 62.2% average zero-shot accuracy across six common-sense tasks, with only a 0.9% drop compared to FP16 Mamba 2.8B (63.1%). The enhanced Quamba-O variant (with OCTAV clipping optimization) reaches 62.5%. On latency, Quamba delivers a 1.72× speedup in generation (TPOT) on Orin Nano 8G and 1.21× on A5000, while reducing model size from 5.29 GB to 2.76 GB. On Jamba (52B hybrid Mamba-Transformer), combining Quamba with LLM.int8 for self-attention/MoE yields 72.9% LAMBADA accuracy vs. 74.0% FP16, a mere 1.1% drop.

## Baselines & Comparisons

Quamba outperforms Mamba-SmQ (SmoothQuant) by 4.9% average accuracy (62.2% vs. 57.3%) and Mamba-PTQ by a wide margin, which fails to report full results. Against Mamba-Had (QuaRot reimplementation), Quamba achieves comparable accuracy (62.2% vs. 62.4%) but delivers a 1.2× latency speedup on A5000 and 1.12× on Nano, since QuaRot requires extra Hadamard transforms and matrix transpositions for SSM inputs that cannot be fused. Quamba-O (with OCTAV) surpasses Mamba-Had in both accuracy (62.5% vs. 62.4%) and latency. Compared to the same-sized Transformer Pythia 2.8B, Quamba achieves 3.8% higher average accuracy (62.2% vs. 58.4%) while being 1.91× smaller in memory. On the edge device (Orin Nano 8G), Quamba-2.8B (2.7 GB) handles 8K input sequences while 4-bit Llama-2-7B (3.5 GB, QuaRot) crashes with OOM, and Quamba is ~2× faster on TTFT at 1K–4K sequence lengths.

## Relation to Prior Work

This paper adapts Transformer quantization techniques—specifically the Hadamard transform for outlier suppression (QuaRot, Ashkboos et al., 2024b) and percentile-based clipping (SmoothQuant, Xiao et al., 2023)—to the structurally distinct selective SSM architecture. The key departure is recognizing that SSMs exhibit fundamentally different quantization sensitivity than Transformers: the small-valued input tensor x is causally sensitive through the linear recurrence, while large outliers appear in the output y (unlike self-attention where both are relatively smooth). Rather than applying Hadamard transforms to both inputs and outputs as QuaRot does for Transformers, Quamba uses lightweight percentile clipping for the sensitive x input and reserves the Hadamard transform only for the outlier-prone y output, avoiding costly transpositions incompatible with the causal convolution and selective scan dataflow.

## Why It Matters / Open Questions

SSMs are rapidly gaining traction as efficient alternatives to Transformers, but their deployment on edge and cloud hardware has been blocked by the absence of a working quantization recipe; this paper provides the first systematic 8-bit W8A8 solution that achieves real speedups (1.72× on Orin Nano) with minimal accuracy loss (0.9%) and scales to 52B-parameter Jamba. Open questions remain: 4-bit quantization still fails catastrophically (~30% accuracy), asymmetric quantization and layer-adaptive schemes are left for future work, and the method is currently limited to the Mamba/Jamba family. The theoretical error bound (Theorem 4.1) providing a sequence-length-independent guarantee is a useful analytical tool but relies on the exponential decay assumption for the A matrix that may not hold for all SSM variants.

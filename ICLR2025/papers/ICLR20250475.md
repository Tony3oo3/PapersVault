## Problem

In sequential trajectory prediction, a model's earlier predictions on a target agent become verifiable by ground-truth trajectories as time progresses, yielding agent-specific 'individual feedback' that reveals the model's strengths and weaknesses on that particular agent. Despite this information being naturally available in the sequential setting, no prior work has exploited it to improve subsequent predictions on the same agent.

## Input / Output

The method consumes, for each timestep t where feedback is available (τ_obs ≤ t ≤ T − τ_pred), the base model's k predicted trajectories, the corresponding ground-truth trajectory, and the observation sequence O_t; at the current timestep T it also receives the base model's η=200 candidate predictions and the current observation O_T. The output is a set of k adjusted multimodal trajectories, selected by greedy filtering from the base model's candidates rather than directly decoded from the adjuster's proposals. Training data must be collected via 5-fold cross-validation of the base model to ensure the prediction distribution matches the test-time distribution.

## Method

IAN is a fully external module with three components: (1) a feedback generator that embeds each (prediction, ground-truth) pair via an attention gate and aggregates all pieces with observation-conditioned max pooling into a single feedback vector F; (2) a dynamic MLP adjuster whose last two layer biases are set to F, producing k trajectory proposals from the current observation and predictions; and (3) a proposal query & filtering stage that scores coherence between each proposal and η base-model candidates via a confidence network, then greedily assigns k candidates to proposals. Because the final output comes from the base model (not the adjuster), gradients cannot back-propagate through it; instead a novel displacement expectation loss is introduced, computing the softmax-weighted expected ADE over candidates for each proposal and minimizing the best (winner-takes-all) expectation to train the feedback generator, adjuster, and confidence network end-to-end.

## Results

IAN achieves consistent ADE/FDE improvements across all six prediction models on three benchmarks. On ETH/UCY, improvements range from 4.3%/7.7% (TUTR) to 10.0%/13.9% (LB-EBM) and 9.5%/14.3% (GroupNet). On GCS and NBA, gains are more modest (3.0%–7.7% ADE), which the authors attribute to these benchmarks approaching performance saturation. IAN adds only ~0.02 s inference time on an RTX 3090, comparable to the base models themselves.

## Baselines & Comparisons

IAN is applied as a plug-and-play external module on top of six existing prediction models, and it improves every one of them on all three benchmarks. The largest relative gains appear on ETH/UCY: LB-EBM drops from 0.20/0.36 to 0.18/0.31 ADE/FDE (10.0%/13.9%), and GroupNet from 0.21/0.35 to 0.19/0.30 (9.5%/14.3%). On GCS, SGCN benefits most (4.10/6.51 → 3.79/5.94, 7.6%/8.8%), while on NBA SGCN again leads (1.56/2.46 → 1.44/2.19, 7.7%/11.0%). The state-of-the-art SingularTrajectory (ST) sees the smallest improvements (≈3% ADE across all datasets), consistent with the authors' observation that GCS and NBA are near their performance ceilings. Ablations confirm that the gains come from the feedback signal itself rather than merely from extra historical observations: replacing feedback with a full-history LSTM embedding (IAN w/o feedback) yields smaller improvements, and simply feeding longer observations to the base model (Baseline w/ fullobs) actually degrades performance.

## Relation to Prior Work

This paper carves new ground by identifying 'individual feedback'—the discrepancy between a model's past predictions and ground truths for the same agent—as an underexploited information source in the sequential nature of trajectory prediction. Methodologically, it repurposes dynamic filter networks (Jia et al., 2016; Tian et al., 2020) to generate a per-agent adjuster parameterized by aggregated feedback, and introduces a displacement expectation loss with winner-takes-all optimization to handle the non-differentiable candidate filtering step. The interactive architecture, where the adjuster queries the base prediction model for candidates rather than directly decoding proposals, departs from prior adaptation and test-time training approaches by remaining a fully external, parameter-frozen module that never updates the base model.

## Why It Matters / Open Questions

The plug-and-play nature of IAN (20ms overhead, compatible with any prediction model) makes it practically attractive for deployment in autonomous driving and robotics, where agents persist in the scene long enough to accumulate feedback. The paper honestly acknowledges a key limitation: the adjuster can worsen predictions when an agent with a historically smooth trajectory suddenly changes direction, as the feedback reinforces the wrong pattern. Open questions include whether the approach extends to multi-agent settings where feedback from one agent could inform predictions about others, and whether the K-fold cross-validation training set collection strategy scales to larger, more diverse deployment scenarios.

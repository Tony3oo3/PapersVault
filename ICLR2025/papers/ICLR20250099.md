## Problem

Existing scene editing methods are confined to either 2D object-level manipulation or 3D global scene editing, with no unified framework that provides 3D-aware control at both granularities simultaneously. 2D approaches ignore 3D geometry and fail to maintain consistency under camera changes, while 3D methods lack the ability to accurately disentangle individual objects for localized editing.
![Teaser figure](../imgs/ICLR20250099/cropped_page0_idx3.webp)

## Input / Output

The method takes a single RGB scene image and lifts it into 3D via monocular depth estimation (GeoWizard), then expands the 3DGS to novel views through diffusion-based inpainting. At inference, users select objects via text prompts (matched against CLIP embeddings stored per Gaussian) or bounding boxes (resolved by K-Means clustering), and specify camera intrinsics/extrinsics for viewpoint changes. The output is a fully disentangled 3D Gaussian Splatting scene where individual objects can be independently translated, rotated, resized, or removed while preserving occlusion relationships and 3D consistency across views.

## Method

3DitScene builds a language-guided disentangled Gaussian Splatting representation in three stages: (1) initializing 3DGS from a single image via depth lifting and refining with reconstruction loss plus Score Distillation Sampling from Stable Diffusion; (2) expanding the 3DGS to novel views using a diffusion-based depth inpainting approach that treats depth completion as an inpainting task with forward-diffusion constraints on known regions, avoiding heuristic alignment artifacts; (3) distilling CLIP language embeddings into each 3D Gaussian using SAM-derived semantic masks, enabling per-object disentanglement. The total training objective combines reconstruction, SDS, and distillation losses. A key insight is that the disentanglement property also serves as layout augmentation during optimization—randomly moving or removing objects exposes previously occluded Gaussians to gradient updates, reducing floating artifacts. At inference, object selection via text or bounding box enables flexible 3D manipulation within a unified framework.

## Results

The paper evaluates via a user study (25 users, 20 samples per method) rather than standard quantitative metrics. 3DitScene achieves 65.4% human preference for consistency and 64.0% for image quality, substantially outperforming all baselines. GPT-4V evaluation corroborates these findings with 62.0% consistency and 40.8% quality preference, confirming alignment between automated and human judgment. Qualitative comparisons further demonstrate superior 3D consistency in object manipulation and smoother camera transitions compared to baselines.

## Baselines & Comparisons

3DitScene decisively outperforms all five baselines in the user study. AnyDoor (2D diffusion-based object teleportation) scores lowest on consistency (5.1% human preference) due to the absence of 3D cues, causing object identity and layout inconsistencies. Object 3DIT, trained on synthetic data, shows limited generalization to real images (16.8% consistency, 0.5% quality). Image Sculpting, which leverages a 3D model from the input image, is the strongest baseline (12.7% consistency, 25.1% quality) but still exhibits inconsistency during object manipulation. For camera control specifically, AdaMPI only handles zoom-in scenarios and is unsuitable for large viewpoint changes, while LucidDreamer suffers from sudden content transitions and requires dense camera poses; 3DitScene needs as few as three camera poses for smooth transitions. GPT-4V preferences closely track human preferences, validating the user study results.

## Relation to Prior Work

This paper unifies two previously separate lines of work—2D diffusion-based image editing (AnyDoor, Object 3DIT) and 3D Gaussian Splatting scene manipulation (GaussianEditor, GS-Edit)—into a single framework built on language-guided disentangled 3D Gaussians. It inherits the SDS-based generative prior from DreamFusion, the language-embedding-into-3D-geometry paradigm from LERF and LangSplat, and repurposes SDEdit's forward-diffusion mechanism for depth inpainting to expand 3DGS to novel views without heuristic alignment. The key departure is treating object disentanglement not merely as an inference-time query but as a structural property that also serves as a layout augmentation during optimization, exposing otherwise-hidden Gaussians to gradient updates.

## Why It Matters / Open Questions

By enabling simultaneous camera control and per-object manipulation (translation, rotation, removal, re-stylizing) within one optimized 3D representation, 3DitScene removes the need to switch between 2D editing tools and 3D scene editors, which is practically significant for creative workflows in entertainment and advertising. The finding that disentanglement improves optimization quality (reducing floating artifacts) suggests a broader principle: semantic structure in a representation can act as a regularizer for reconstruction. Open questions include scalability to complex multi-object scenes, whether the single-view depth estimation bottleneck (GeoWizard) limits fidelity for large camera rotations, and whether the per-scene optimization cost (~1800 SDS steps) can be amortized for interactive use.

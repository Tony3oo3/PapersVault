## Problem

Existing deep learning approaches to symbolic regression rely on pre-trained language models that require substantial computational resources, assume a fixed problem space, and struggle with unseen functions or variables. A pre-training-free paradigm is needed that can integrate seamlessly with search-based evolutionary algorithms and adapt online to novel regression tasks without prior assumptions about the function set.
![Teaser figure](../imgs/ICLR20250332/cropped_page2_idx0.webp)

## Input / Output

The method consumes a tabular dataset (X, Y) and a dynamically maintained semantic library of up to 10,000 symbolic trees paired with their normalized semantics (stored in a FIFO queue indexed by a KD-Tree for O(log N) retrieval). The neural network takes the L2-normalized residual vector R ∈ R^N as its primary input and outputs a fixed-length token sequence of n_F + n_T symbols (where n_F caps function nodes and n_T is derived from maximum arity), which is decoded via breadth-first traversal into a valid symbolic tree. The final output is a set of m symbolic trees whose outputs are combined by linear regression to form the interpretable model.

## Method

RAG-SR introduces a neural semantic library where a Transformer encoder-decoder architecture, conditioned on an MLP-encoded residual (desired semantics) and a Transformer-encoded retrieved nearest symbolic tree (retrieval prompt), autoregressively generates new symbolic trees to fill the residual gap in a feature-construction model. The retrieval-augmented generation mechanism queries a KD-Tree over the semantic library to fetch the closest previously evaluated tree, which serves as a prompt to the Transformer encoder, explicitly mitigating hallucination by grounding generation in known valid expressions. Training combines cross-entropy loss over the token sequence with a masked InfoNCE contrastive loss that aligns the MLP embedding of the nearest semantics with the averaged Transformer embedding of the retrieved tree, using a mask to exclude false negatives (cosine similarity > 0.99). The overall framework operates within a genetic programming loop where a Semantic Descent algorithm iteratively replaces suboptimal trees with either neural-generated or exactly-retrieved alternatives, while scale-invariant data augmentation (adding sign-flipped pairs) and a double-query decoding strategy (querying with both R and −R) exploit the sign symmetry of linear regression coefficients.

## Results

On 120 PMLB black-box regression datasets, RAG-SR achieves the highest test R² scores among all 25 compared symbolic regression and machine learning methods, with statistically significant improvements confirmed by Wilcoxon signed-rank test with Benjamini-Hochberg correction. On the 14 Strogatz datasets, RAG-SR achieves the highest R² scores; on the 119 AI-Feynman datasets, it ranks second behind MRGP but with models an order of magnitude smaller. RAG-SR produces models roughly an order of magnitude smaller than PS-Tree (the second-best R² method on PMLB) while appearing on the first Pareto front for the accuracy–complexity trade-off. Training time is comparable to FEAT but an order of magnitude slower than TPSR (which uses a pre-trained model without fine-tuning).

## Baselines & Comparisons

RAG-SR outperforms all 25 baselines on the 120 PMLB black-box datasets in test R², with the most notable wins over TPSR (Shojaee et al., 2024a, MCTS + pre-trained Transformer) and SNIP (Meidani et al., 2024, unified pre-training), both of which rely on pre-trained language models. Against SBP-GP (Pawlak et al., 2014), a purely retrieval-based geometric semantic GP without a neural network, RAG-SR shows a significant advantage, demonstrating the value of neural generation over retrieval alone. On the AI-Feynman benchmark, MRGP (Arnaldo et al., 2014) marginally outperforms RAG-SR in R², but MRGP's model size is more than an order of magnitude larger. RAG-SR's training time is comparable to FEAT (La Cava et al., 2019), the standard feature-construction GP baseline, but is an order of magnitude slower than TPSR due to online neural network training on CPU. Compared to pre-trained approaches like the end-to-end Transformer (Kamienny et al., 2022) and Deep Generative SR (Holt et al., 2023), RAG-SR achieves superior accuracy without requiring any pre-training, and scales to more than 10 variables where the end-to-end Transformer is limited. On the Strogatz datasets, RAG-SR achieves the highest R² scores among all 17 compared algorithms.

## Relation to Prior Work

This paper sits at the intersection of geometric semantic genetic programming (GSGP), feature-construction-based symbolic regression (FEAT), and retrieval-augmented generation (RAG) from the NLP/code-generation literature. It departs from the dominant pre-trained language model paradigm for SR (Biggio et al., 2021; Kamienny et al., 2022) by proposing a fully online, pre-training-free neural semantic library that learns the semantics-to-expression mapping during evolution. The semantic descent operator generalizes the retrieval-only mechanism of semantic backpropagation (Pawlak et al., 2014) by adding a neural generation pathway, while the RAG component adapts the prompt-retrieval idea from code generation (Parvez et al., 2021) to the symbolic expression domain, using a KD-Tree over stored GP tree semantics as the retrieval index.

## Why It Matters / Open Questions

The pre-training-free design is practically significant because it removes the need for large-scale pre-training corpora and handles unseen functions and variables without retraining, addressing a key limitation of current Transformer-based SR methods. The finding that RAG's benefit grows with the number of variables (due to data imbalance) suggests the mechanism is particularly valuable for high-dimensional real-world problems where pre-training coverage is weakest. Limitations include CPU-only neural training making it an order of magnitude slower than TPSR, the absence of explicit complexity constraints (risking overfitting on noisy data), and the fixed 10-tree model size. Open questions include whether GPU acceleration closes the runtime gap, whether the RAG mechanism transfers to other discrete generation tasks, and how to integrate complexity-aware objectives into the semantic descent loop.

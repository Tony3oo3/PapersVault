## Problem

Whether in-context learning (ICL) can genuinely learn novel input-output relationships unseen during pretraining, or merely selects and optimizes within its pretraining hypothesis space, remains unresolved. Prior work demonstrated ICL learning new regression weights and classifying abstract labels, but it was unclear whether these constitute true OOD generalization or in-distribution behavior masked by superficial novelty.

## Input / Output

The ICL input is a sequence of concatenated input-output pairs S = [x₁⊕y₁⊕...⊕x_T⊕y_T] followed by a query x_{T+1}, where inputs are d-dimensional vectors (d=20 for synthetic GPT-2 tasks, d=4096 for Llama-3-8B word embeddings) sampled from Gaussian distributions and outputs are scalar regression values or label vectors. For real LLM experiments, the model receives tokenized prompts and must predict the next token, with accuracy measured over 128 test examples per context length. The retrieval variant repeats a fixed set of (x,y) pairs 20 times, requiring the model to find the matching x in context and output its paired y.

## Method

The paper combines controlled GPT-2 experiments, real LLM evaluations, and a theoretical characterization of ICL's algorithm-selection mechanism. Empirically, training GPT-2 on a specific function class (linear, quadratic, or ReLU regression) and evaluating on OOD classes shows ICL performance converges to the pretraining function class optimized by gradient descent on in-context examples, with double-descent curves confirming in-distribution behavior. For abstract label classification, the authors design retrieval and predict-then-retrieve tasks showing the ability emerges from training on diverse label mappings (larger s ranges) but collapses when the underlying test function is OOD, even with target labels present in context. Theoretically, building on Lin & Lee's (2024) mixed Gaussian pretraining framework, they prove Theorem 5.3 establishing a low-test-error preference: the posterior weight ratio between two pretraining tasks is governed by both input-distribution similarity (Lemma 5.2) and relative test error on the downstream context, jointly determining which pretraining function ICL implements. Numerical experiments with four-component Gaussian mixtures and real LLM ambiguous-sentence classification tasks validate both selection mechanisms.

## Results

The paper's central finding is that ICL on OOD tasks does not learn new functions but instead implements the pretraining function class optimized via gradient descent on in-context examples (Section 3.1, Figure 1). On real-world LLMs, Llama-3-8B achieves near-random (~10%) accuracy on an OOD synthetic vector classification task, while performing significantly better on a retrieval variant of the same task (Figure 6). When pretrained on a mixture of linear regression, quadratic regression, and ReLU NN tasks, the mixed-task GPT-2 model's OOD performance closely matches the best-performing single-task model on each evaluation function (Figure 7), confirming a low-test-error algorithm-selection preference. Theoretically, Theorem 5.3 proves that ICL's posterior weight ratio between two pretraining tasks is governed by both input-distribution similarity and test-error difference, with the low-test-error term Ψ_w(α,β) ≥ 0 whenever pretraining function α has lower empirical risk than β on the test context.

## Baselines & Comparisons

The paper does not propose a new method to benchmark against baselines; instead, it compares ICL behavior against several reference points. First, ICL predictions on OOD tasks are compared to GD-optimized models of the same pretraining function class: ICL closely tracks the GD baseline, confirming it merely implements the pretraining hypothesis space rather than learning a new function (Figure 1). Second, single-task pretrained GPT-2 models (LR, QR, ReLU NN) are compared against a mixed-task model on four OOD evaluation functions (SRR, CR, LQR, Sigmoid NN): the mixed model consistently matches the best single-task model, demonstrating algorithm selection (Figure 7). Third, Llama-3-8B is evaluated on an OOD classification task versus a retrieval task: classification accuracy is near the 10% random baseline while retrieval accuracy is substantially higher, indicating ICL's strength lies in retrieval rather than novel function learning (Figure 6). Fourth, models trained on increasing ranges of abstract label mappings (s ~ U(50,150) vs U(50,250) vs U(50,450)) show that retrieval ability for OOD labels emerges only with more diverse training mappings, but this ability vanishes when the underlying test function is OOD (Figures 3–5). Finally, the theoretical prediction (closed-form ICL prediction from Lemma E.1) is validated against numerical experiments across five noise levels, confirming both the low-test-error preference (Figure 8a) and the similar-input-distribution preference (Figure 8b).

## Relation to Prior Work

This paper unifies and extends several threads of ICL theory: the Bayesian inference framework (Xie et al., 2022; Lin & Lee, 2024), the gradient-descent interpretation (Von Oswald et al., 2023), and the algorithm-selection phenomenon (Bai et al., 2023; Wang et al., 2024b). Its key departure is that prior algorithm-selection results were restricted to in-distribution test functions, whereas this paper shows the selection mechanism persists broadly under OOD evaluation and provides the first theoretical decomposition of what drives it (low-test-error preference and similar-input-distribution preference). Empirically, it builds on Garg et al. (2022)'s synthetic function-class setup but extends it to cross-function-class evaluation and real-world LLMs (Llama-2-7B, Llama-3-8B), and it reframes the abstract-label classification results of Pan (2023) and Kossen et al. (2024) as a retrieval-plus-ID-prediction process rather than genuine new-task learning.

## Why It Matters / Open Questions

The paper challenges the optimistic narrative that ICL enables LLMs to learn truly novel input-output mappings, showing instead that ICL operates within the pretraining hypothesis space and selects among pretraining functions based on test error and input-distribution similarity. This has practical implications for how practitioners should interpret LLM performance on seemingly new tasks: success on abstract-label classification does not imply the model can handle a genuinely OOD prediction rule. Key limitations include reliance on GPT-2 for most synthetic experiments, theoretical results that require specific Gaussian-mixture assumptions, and synthetic (rather than natural) OOD tasks for the Llama evaluations. Open questions include whether frontier-scale models with vastly more diverse pretraining corpora escape these limitations, and whether the low-test-error preference can be exploited to improve ICL robustness.

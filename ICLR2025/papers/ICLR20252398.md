## Problem

Existing attention algorithms for LLM inference (Flash-Attention, Flash-Decoding, Tree Attention in Medusa/SpecInfer) are not prefix-aware in memory access: when multiple queries share a common KV prefix in a tree-structured decoding tree, the shared prefix KV cache is redundantly loaded from HBM to shared memory for each query. Additionally, naive node-wise splitting of tree-structured KV caches produces severely unbalanced workloads across GPU SMs because node token lengths can vary by orders of magnitude (e.g., a 1000-token root vs. 1-token leaves in speculative decoding), leading to low GPU utilization.

## Input / Output

The method consumes a tree-structured KV cache (stored in paged or unpaged GPU memory with shared prefixes across branches), a set of query tokens (parallel leaf-node queries for multi-step reasoning, or tree-structured token candidates for speculative decoding), and tree topology metadata (parent-child relationships, causal ordering). The QKV Preparation Phase produces logical QKV group assignments (no physical data movement) that map each group to a specific SM. The Attention Calculation Phase outputs partial attention vectors and LogSumExp scalars per group, which are then merged via a Tree-Topology-Aware Global Reduction to yield the final attention output for each query. The bit causal mask (a set of 64-bit integers per token) encodes causal relationships within each flattened block at negligible IO cost compared to dense causal masks.

## Method

DEFT-Flatten introduces two complementary partitioning strategies for tree-structured attention. First, KV-Guided Grouping inverts the standard Q-Guided approach: instead of assigning each query its full KV sequence, each tree node's KV cache is grouped with all descendant queries that share it, ensuring the shared prefix KV is loaded from HBM exactly once per decoding iteration. Second, Flattened Tree KV Splitting performs a depth-first traversal of the tree to produce a linear KV sequence, then divides it into equal-length blocks so that each SM receives a balanced workload; depth-first ordering maximizes query overlap within each block to minimize masked-out computation. A compact bit causal mask (64-bit integers) captures causal relationships within each block. The attention kernel fuses all operations (QK^T, scaling, masking, softmax, PV) into a single Triton kernel with FlashAttention-style tiling to avoid materializing intermediate results in HBM, and a Tree-Topology-Aware Global Reduction correctly merges partial results across groups by respecting the tree's parent-child structure rather than a simple sequence concatenation.

## Results

DEFT-Flatten achieves up to 2.23× decoding latency speedup and 3.59× attention latency speedup over the best baseline (Radix Attention) on speculative decoding with 256 token-tree queries. On few-shot prompting (b=50), it delivers 1.33× decoding speedup with 1.70× faster attention. On multi-step reasoning (Sorting task), it achieves 1.10× decoding speedup and 1.39× attention speedup. Overall, DEFT-Flatten reduces KV cache IO by 73–99% and partial-results IO by nearly 100% compared to baselines.

## Baselines & Comparisons

DEFT-Flatten consistently outperforms all three baselines across every task and configuration. Against Flash-Decoding (unpaged), the gains are most dramatic: on the Sorting reasoning task, DEFT-Flatten reduces decoding latency from 429.65s to 94.67s (4.5×), and on speculative decoding with t=256 it avoids OOM entirely while Flash-Decoding cannot even run. Against Tree Attention-Medusa (unpaged), DEFT-Flatten wins on decoding latency in all settings (e.g., 94.67s vs 380.87s on Sorting; 84.27s vs 1881.51s on Spec. t=256), primarily because Medusa's dense causal mask and lack of kernel fusion introduce large partial-results IO. Against Radix Attention (paged, the strongest baseline), DEFT-Flatten achieves 1.03–2.23× decoding speedup and 1.15–3.59× attention speedup, with the largest gains on speculative decoding (up to 2.23×) where the long shared prefix benefits most from KV-Guided Grouping, and smaller but consistent gains on few-shot prompting (1.24–1.33×) and multi-step reasoning (1.03–1.10×) where the tree is narrower and attention is a smaller fraction of total latency.

## Relation to Prior Work

DEFT builds directly on the Flash-Attention/Flash-Decoding lineage (Dao et al., 2022, 2023) for tiling, kernel fusion, and online-softmax reduction, and on tree-attention mechanisms from Medusa (Cai et al., 2024) and SpecInfer (Miao et al., 2023) for handling tree-structured queries. It departs from these by inverting the grouping indicator from Q-Guided to KV-Guided, so that shared prefix KV is loaded once rather than once per query, and by replacing node-level or depth-level splitting with a flattened, evenly-blocked KV partition that uses bit causal masks to preserve tree topology. The paged-memory infrastructure from vLLM (Kwon et al., 2023) and SGLang's Radix Attention (Zheng et al., 2023) provides the storage substrate, but DEFT's contribution is specifically at the memory-access (IO) level during attention computation, which prior tree-aware systems largely overlooked.

## Why It Matters / Open Questions

As tree-based decoding (speculative decoding, Tree-of-Thoughts, few-shot prompting) becomes a dominant inference pattern, the IO redundancy in shared-prefix KV loading becomes a first-order bottleneck; DEFT's 73–99% KV IO reduction and up to 2.23× decoding speedup in speculative decoding address this directly. A key limitation is that the speedup is most pronounced when the tree is wide and the prefix is long (speculative decoding with t=256), while narrow multi-step reasoning trees (width 10) see only ~3–10% decoding improvement because attention is a smaller fraction of total latency. Open questions include how the approach interacts with KV quantization, whether the flattened splitting generalizes to irregular or dynamically growing trees without pre-known topology, and integration with continuous-batching serving systems where tree shapes change per step.

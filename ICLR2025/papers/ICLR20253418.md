## Problem

Unsupervised 3D object segmentation in complex point clouds remains difficult because existing methods rely on heuristics (normals, colors, motion) or similarity of pretrained 2D features, which either only identify simple objects like cars or produce inferior segmentations due to the lack of objectness in those features. The paper tackles two fundamental questions: how to learn object priors that are simultaneously discriminative, robust to occlusion/noise, and continuous in latent space, and how to effectively discover multiple such objects in complex scenes without any scene-level human labels.

## Input / Output

The method takes a 3D scene point cloud (xyz coordinates only, no RGB or normals) as input and produces class-agnostic object masks over the entire scene. The object-centric network is first trained on single-object point clouds from ShapeNet (with synthetic occlusions and background augmentation), while the multi-object estimation network operates on scene-level point clouds from ScanNet, S3DIS, or a synthetic dataset. During the discovery phase, a dynamic cylinder container parameterized by center (Cx, Cy) and diameter (Cd) crops sub-volumes of points, which are queried against the frozen object-centric network to generate binary rewards and pseudo masks.

## Method

GrabS is a two-stage pipeline. Stage 1 trains an object-centric network comprising an orientation estimation module (PointNet++ encoder regressing three rotation angles) and a generative prior module (VAE or diffusion-based SDF decoder) on single objects from ShapeNet, learning robust and continuous latent shape distributions. Stage 2 introduces a multi-object estimation network with two parallel branches sharing a SparseConv backbone: (1) an object discovery branch formulated as an embodied agent—a dynamic cylinder container that moves and resizes via PPO reinforcement learning, receiving positive/negative rewards from the frozen object-centric network based on whether the cropped points can be reconstructed via SDF and Marching Cubes; and (2) an object segmentation branch (Mask3D-style transformer) trained on pseudo masks accumulated by the agent. The discovery branch is discarded at inference, leaving an efficient segmentation-only model.

## Results

On the ScanNet validation set (chair category), GrabS (Ours-VAE) achieves 46.7% AP, 71.5% AP50, and 82.9% AP25, while GrabS (Ours-Diffusion) reaches 47.1% AP. These results substantially outperform all unsupervised baselines: the closest competitor Unscene3D scores 37.2% AP, Part2Object 34.4% AP, and EFEM 24.6% AP. On the ScanNet hidden test set, GrabS (Ours-VAE) achieves 29.0% AP, approaching the early fully-supervised 3D-BoNet (34.5% AP) without any scene-level human labels. On the synthetic multi-class dataset, GrabS (Ours-Diffusion) reaches 58.5% AP, far exceeding EFEM (20.7%) and HDBSCAN (7.6%).

## Baselines & Comparisons

GrabS decisively outperforms all unsupervised baselines on ScanNet validation: it surpasses Unscene3D (37.2% AP) by ~9.5 points, Part2Object (34.4% AP) by ~12.3 points, and EFEM (24.6% AP) by ~22 points, with the largest gap in recall (53.2% vs. 51.7%/46.4%/–) and precision (52.1% vs. 18.7%/45.5%/–). Against the supervised references, GrabS trails Mask3D (82.9% AP) and OpenIns3D (66.7% AP), which rely on dense 3D labels or large-scale 2D foundation model supervision respectively, but it exceeds SAI3D (38.5% AP) which uses language-model supervision. On the ScanNet hidden test set, GrabS (29.0% AP) narrows the gap to the early fully-supervised 3D-BoNet (34.5% AP) while still falling well short of SoftGroup (69.4%) and Mask3D (73.7%). On the synthetic multi-class dataset, GrabS (58.5–58.7% AP) dominates HDBSCAN (7.6% AP) and EFEM (20.7% AP) by a wide margin, and also outperforms Unscene3D (37.7%) and Part2Object (46.1%) which were transferred from real ScanNet training. On S3DIS cross-dataset evaluation, GrabS leads all unsupervised methods in AP (46.4% on Area-5 vs. 42.6% for Unscene3D and 30.0% for Part2Object), though Unscene3D retains a slight edge in AP25 and recall due to its strong DINO-based 2D features.

## Relation to Prior Work

This paper builds most directly on EFEM (Lei et al., 2023), which also learns object priors from ShapeNet and segments 3D scenes without scene-level supervision, but departs in two key ways: it replaces EFEM's deterministic reconstruction priors with generative (VAE/diffusion) priors, and replaces EFEM's heuristic object search with a reinforcement-learning-based embodied agent. The segmentation branch directly adopts Mask3D's transformer architecture, and the diffusion variant follows Diffusion-SDF's denoising formulation. The broader positioning is against unsupervised methods that rely on 2D pretrained features (UnScene3D, Part2Object) or geometric heuristics (HDBSCAN, motion-based methods), arguing that learned 3D object-centric generative priors provide more discriminative and robust signals for complex object identification.

## Why It Matters / Open Questions

The paper demonstrates that a generative object prior combined with an RL-based exploration agent can substantially outperform heuristic search (EFEM) and 2D-feature-based unsupervised methods for 3D object segmentation without any scene-level labels, which is practically important for applications where 3D annotation is prohibitively expensive. However, the evaluation is primarily limited to the chair category for fair comparison, and the class-agnostic results (Appendix H) reveal that methods leveraging large 2D foundation models (DINO/DINOv2) still outperform GrabS when object priors are not the bottleneck. Open questions include whether the embodied agent formulation scales to open-vocabulary or multi-category settings, whether larger 3D object datasets can close the remaining gap to supervised methods, and whether the RL training cost (62 hours) can be reduced.

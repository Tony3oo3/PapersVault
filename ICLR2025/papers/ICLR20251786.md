## Problem

Existing fine-tuning-based machine unlearning methods for deep neural networks suffer from the 'missing targets problem': they use gradient ascent on forget-set points but lack access to the counterfactual loss values a re-trained oracle model would produce, causing systematic undershooting or overshooting. Recent evaluations (e.g., U-LiRA) confirm that these methods produce models whose predictions remain easily distinguishable from true re-training, and no prior approach achieves strong unlearning quality in non-convex settings at a fraction of retraining cost.

## Input / Output

The method takes a pre-trained model θ (e.g., ResNet-9 on CIFAR-10 or ResNet-18 on ImageNet-Living-17), a forget set S_F, and pre-computed linear datamodel vectors β(x) for each training point, which are estimated once via sparse linear regression over models trained on random 50% subsets (1,000–20,000 models). It outputs a fine-tuned model θ_UL whose per-class logits approximate those of a model re-trained on the retain set S_R = S \ S_F. The fine-tuning set consists of all forget-set points plus a subsample of retain points (much smaller than the full training set), and the datamodel computation cost is amortized across multiple unlearning requests.

## Method

DMM combines two ideas: (1) Oracle Matching (OM), which replaces gradient ascent/descent on forget/retain losses with direct MSE minimization between the model's logits and oracle predictions on a subsample of forget and retain points, thereby eliminating the missing-targets stopping criterion; and (2) Oracle Simulation via predictive data attribution, where linear datamodels approximate oracle outputs as h(x) = f_x(θ_0) − Σ_{i∈S_F} β_i(x) (the DM-DIRECT formula), leveraging the linearity of datamodels to subtract only the forget-set contributions from the current model output. DMM then runs OM on these simulated targets, requiring no access to actual re-trained model weights. Theoretically, in underdetermined ridge regression, the paper proves that stochastic OM converges at a linear rate O((1−γ_min·η)^t) while stochastic GD on the retain set is lower-bounded at Ω(1/t²), explaining OM's empirical advantage in the stochastic regime.

## Results

DMM achieves unlearning quality (measured by KLOM, where 0 = perfect oracle match) approaching that of full re-training while using a significantly smaller fraction of the compute budget. The Oracle Matching (OM) component alone achieves effective unlearning using less than 5% of full re-training compute, whereas matching OM's forget-set performance via retraining requires over 60% of full retraining time. On both CIFAR-10 (ResNet-9) and ImageNet-Living-17 (ResNet-18), DMM and DM-DIRECT dominate the Pareto frontier of KLOM score vs. relative compute across forget, retain, and validation splits (95th percentile), outperforming all gradient-based baselines including SCRUB, gradient ascent, and gradient descent.

## Baselines & Comparisons

DMM outperforms all prior gradient-based unlearning methods (SCRUB, gradient ascent, gradient descent) on KLOM across all three splits (forget, retain, validation) on both CIFAR-10 and ImageNet-Living-17, while using comparable or less compute. Against SCRUB—the current state-of-the-art unlearning method—DMM achieves lower KLOM scores (closer to oracle) because it avoids the 'missing targets' problem that causes SCRUB to overshoot or undershoot the target loss on individual forget-set points. DMM also matches the test accuracy of the oracle re-trained model and maintains retain-set accuracy, a common failure mode in prior methods where fine-tuning degrades performance on retained data. Compared to partial re-training at the same computational budget, DMM is significantly more effective at unlearning. The Do Nothing baseline (returning the original model unchanged) is outperformed by DMM, DM-DIRECT, and even gradient descent, confirming that the unlearning task is non-trivial and that DMM provides genuine improvement over the status quo.

## Relation to Prior Work

This paper builds on two established lines of work: fine-tuning-based machine unlearning (SCRUB, gradient ascent/descent methods) and predictive data attribution (datamodels from Ilyas et al., 2022; TRAK from Park et al., 2023). The key conceptual departure is framing unlearning as a data attribution problem: rather than heuristically increasing loss on forget set points (which suffers from the 'missing targets problem'), DMM uses datamodels to simulate oracle outputs and then fine-tunes to match them via Oracle Matching. This repurposes data attribution not as a direct parameter-update mechanism (as in influence-function-based unlearning) but as a guidance signal for gradient-based fine-tuning, a distinction the authors emphasize as making the approach more flexible and robust.

## Why It Matters / Open Questions

The reduction from unlearning to data attribution provides a clear roadmap: future advances in datamodel estimation (e.g., cheaper influence-function approximations) translate directly into better unlearning algorithms. The theoretical result (Theorem 2) showing exponential convergence of stochastic OM versus only Ω(1/t²) for stochastic GD in the linear setting is a clean separation that explains the empirical advantage. However, practical limitations remain: the method is only validated on few-class classification (CIFAR-10, 17-class ImageNet subset), requires a one-time but non-trivial datamodel computation cost, and has not been tested under multiple sequential unlearning requests or in language-modeling settings.

## Problem

While prior work established that Transformers can memorize arbitrary data, the minimum number of parameters required for memorization remained unclear, particularly how parameter sharing in self-attention affects efficiency relative to feed-forward networks. This paper asks: what is the optimal (necessary and sufficient) parameter count for a Transformer to memorize N input sequences, and does the input length n impose a fundamental cost?

## Input / Output

The input consists of N sequences, each of length n with d-dimensional token vectors (a d×n matrix), assumed to be token-wise (r,δ)-separated so that distinct word vectors are at least δ apart in L² norm. In the next-token prediction setting, the output is a single label for the n-th token; in the sequence-to-sequence setting, the output is a label for every token position. A consistency constraint is required: if two sequences are permutations of each other and share the same last token, they must carry the same label, reflecting the permutation equivariance inherent to the Transformer architecture.

## Method

The upper bound construction uses a three-stage pipeline: (1) a feed-forward network φ: R^d → R with O~(√N) parameters maps each token to a scalar such that the sum over all tokens in a sequence yields a unique 'sequence id'; (2) a single self-attention layer configured as uniform averaging (key/query matrices set to zero) broadcasts this sequence id to every token position, forming a context id that encodes both the token identity and the sequence identity; (3) a second feed-forward network maps the context id to the target label. The key insight is that distinguishing N sequences only requires counting occurrences of at most N distinct word vectors, and a random projection from the high-dimensional count vector to a scalar preserves separation with high probability. For the lower bound, the next-token case reduces to a feed-forward VC-dimension argument (since identical tokens collapse self-attention to a linear map), while the seq-to-seq hardmax case uses polynomial partitioning of the parameter space à la Bartlett et al. (2019) to show that parameter sharing does not fundamentally improve memorization capacity beyond a √n factor, establishing that the feed-forward layer—not self-attention—is the bottleneck in seq-to-seq memorization.

## Results

In the next-token prediction setting, the paper proves that Õ(√N) parameters are both sufficient (Theorem 4.1) and necessary (Theorem 4.2, lower bound Ω(√N)) for a Transformer to memorize N input sequences of length n, establishing optimality up to logarithmic factors. In the sequence-to-sequence setting, Õ(√(nN)) parameters are sufficient (Corollary 4.1), and a lower bound of Ω(√(nN/log(nN))) is proved for Transformers with hardmax (Theorem 4.3), again optimal up to logarithmic factors. A key finding is that the input length n has negligible impact on next-token memorization cost, while the √n factor in seq-to-seq arises from the feed-forward bottleneck rather than the self-attention mechanism.

## Baselines & Comparisons

Compared to Kim et al. (2023), which requires Õ(n+√(nN)) parameters for seq-to-seq memorization, this paper removes the additive n term, achieving Õ(√(nN)) — a strict improvement that eliminates the linear-in-n overhead. Against Mahdavi et al. (2023), whose O(d²N/n) bound for next-token prediction depends heavily on embedding dimension d and sequence length n, the present result of Õ(√N) is independent of both d and n (up to log factors). The earlier single-layer result of Kajitsuka & Sato (2023) required O(dnN+d²) parameters for seq-to-seq, which is polynomial in N; the current work reduces this to Õ(√(nN)), a sublinear improvement in N. Finally, Madden et al. (2024) established tight O(ωN) bounds for next-token prediction with positional encoding, where ω is the vocabulary size; this paper's Õ(√N) bound removes the vocabulary-size dependency entirely, showing that token-wise separated inputs can be memorized far more efficiently than the worst-case vocabulary-dependent bound suggests.

## Relation to Prior Work

This paper extends the contextual mapping framework introduced by Yun et al. (2019) and refined by Kim et al. (2023) for Transformer memorization, but achieves a fundamentally tighter bound by showing that a single self-attention layer used as a simple averaging operation suffices to distinguish input sequences, reducing the parameter requirement from O~(n + sqrt(nN)) to O~(sqrt(N)) in the next-token prediction setting. The feed-forward network construction for mapping context IDs to labels directly leverages the sub-linear memorization results of Vardi et al. (2022), while the lower bounds draw on VC-dimension techniques from Goldberg & Jerrum (1995) and Bartlett et al. (2019). The key departure from prior work is the separation of the attention mechanism's role (identifying sequences) from the feed-forward layers' role (associating labels), revealing that the latter is the true bottleneck in seq-to-seq prediction.

## Why It Matters / Open Questions

The result that input length n has negligible effect on next-token memorization capacity provides a clean theoretical explanation for why Transformers scale well with sequence length, and the finding that simple averaging suffices for context identification connects to the empirical success of PoolFormer-style architectures. The open problem of whether softmax (as opposed to hardmax) can break the O~(sqrt(nN)) lower bound in seq-to-seq prediction is a meaningful gap, as it determines whether the feed-forward bottleneck is fundamental or an artifact of the hardmax approximation. The paper also suggests that the practical advantages of self-attention may lie more in optimization dynamics and generalization than in raw memorization capacity, redirecting future theoretical inquiry.

## Problem

Verifying that an unknown distribution has a claimed property typically requires replicating the full analysis, which for many natural properties (tolerant uniformity, entropy estimation, support size) demands quasi-linear sample complexity. Prior sublinear verification protocols either required unconditional soundness with quasi-linear communication (Chiesa & Gur, 2018) or applied only to restricted property classes such as label-invariant or bounded-depth/space properties (Herman & Rothblum, 2022–2024). The gap is a sublinear-communication, sublinear-sample protocol that works for the full class of polynomial-time decidable distribution properties.

## Input / Output

Both the verifier and prover receive i.i.d. sampling access to an unknown distribution D over [N], along with the domain size N, proximity parameters ε_c ≤ ε_f (with gap ρ = ε_f − ε_c ≥ ρ(N)), and a security parameter κ. The protocol is 4-message with Õ(√N/ρ²)·poly(κ) communication and verifier runtime, and the verifier draws Õ(√N/ρ²) samples from D. The honest prover requires Õ(N)·poly(1/ρ) samples and poly(N,κ) runtime. The output is a binary accept/reject decision; by setting ε_c and ε_f appropriately, the protocol also yields a ρ-approximation to D's distance from the property.

## Method

The protocol composes three components. First, the prover commits to a distribution Q via a CRH-based hash tree: the digest is the root label, and local openings reveal the pdf, cdf, and quantile of any element x ∈ [N] using only polylog(N,κ) communication, with binding guaranteed by collision-resistance. Second, the verifier runs an identity tester (sample complexity Θ(√N/ε²)) using samples from D and local openings from the commitment, verifying that Q is ε-close to D. Third, Q is encoded as a sorted string X_Q using a constant-rate error-correcting code so that TV distance translates to Hamming distance, and the verifier runs a 4-message Interactive Argument of Proximity (IAP) on X_Q to check membership in the property's language, answering string queries through the distribution commitment's quantile and cdf openings. This yields sublinear verification for any property whose distance can be approximated in poly(N) time given an explicit distribution description.

## Results

The main result (Theorem 1.1) establishes a 4-message computationally sound argument system for any distribution property that is ρ(N)-approximately decidable in poly(N) time. The verifier's sample complexity, communication complexity, and runtime are all Õ(√N/ρ²)·poly(κ), where κ is the security parameter. The honest prover requires Õ(N)·poly(1/ρ) samples and poly(N,κ) runtime. The verifier's sample complexity is optimal up to polylog(N) factors, matching the known Ω(√N/ρ²) lower bound that holds for any protocol regardless of communication or round complexity.

## Baselines & Comparisons

The paper's protocol achieves a quadratic speedup over standalone (prover-free) distribution testing for many natural properties: while tolerant testing of properties like uniformity, support size, Shannon entropy, monotonicity, and log-concavity requires quasi-linear Ω(N/log N) sample complexity in the standalone setting, the argument system needs only Õ(√N/ε²) samples. Compared to the unconditionally sound protocol of Chiesa & Gur (2018), which also achieves O(√N/ρ²) sample complexity but requires quasi-linear communication and verification time, this work achieves sublinear Õ(√N/ρ²) communication and verification time at the cost of a standard cryptographic assumption (CRHs). Compared to the unconditionally sound protocols of Herman & Rothblum (2024) for bounded-depth/bounded-space properties, which achieve Õ(N^{1-α})·poly(1/ρ) for a constant α<0.1, this work achieves the significantly better Õ(√N/ρ²) bound and applies to the much richer class of all polynomial-time decidable properties (no depth or space restriction). The polynomial dependence on the distance parameter ρ is also improved: the sample complexity dependence is 1/ρ² (which is tight), whereas prior unconditionally sound protocols had larger polynomial dependence on ρ.

## Relation to Prior Work

This paper extends the line of work on interactive proof systems for distribution properties initiated by Chiesa & Gur (2018) and developed by Herman & Rothblum (2022–2024), which achieved sublinear verification only for restricted property classes (label-invariant, bounded-depth, or bounded-space). The key departure is relaxing from unconditional to computational soundness (assuming collision-resistant hash functions), which unlocks a protocol for all polynomial-time decidable distribution properties. The construction composes three existing ingredients—succinct distribution-commitments via hash trees, identity testers from Batu et al. (2001), and Interactive Arguments of Proximity (IAPs) from Kalai & Rothblum (2015)—into a unified 4-message protocol with Õ(√N/ρ²) verifier complexity.

## Why It Matters / Open Questions

The result provides a quadratic speedup (√N vs. quasi-linear N) over replicating the analysis for verifying essentially any reasonable distribution property, with near-optimal sample complexity. The verified distribution-oracle sub-protocol is a reusable primitive that can yield direct efficient protocols for label-invariant properties and other structured classes. Open questions include whether the protocol can be made public-coin (enabling Fiat-Shamir non-interactivity) and whether the cryptographic assumption can be weakened. For the broader ML verification community, the extension to NP properties and the application to verifying ERM learning algorithms suggest a path toward certifying complex data-science pipelines with sublinear verification cost.

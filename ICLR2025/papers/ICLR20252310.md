## Problem

Existing GNN node embeddings are inherently task-order specific: structural representations that are most-expressive for node classification (order-1) cannot simultaneously be most-expressive for link prediction (order-2) or higher-order tasks, because each order requires different permutation symmetries. This impossibility (Proposition 2.3) prevents the development of general-purpose pre-trained graph models analogous to LLMs in NLP, forcing practitioners to retrain specialized architectures for each new task order.

## Input / Output

The method takes a graph's adjacency matrix A ∈ {0,1}^{n×n} and node features X ∈ R^{n×d_x}. The expansion map produces a 2D holographic representation V ∈ R^{n×T×d_e} where each node receives T distinct symmetry-free 'views' (rather than a single flat embedding), along with breaking-selector node lists and a partition Λ specifying how views group. The reduction map then fuses these T views into a 1D structural representation for any set of r nodes (order-r output in R^{C(n,r)×d_r}), with the reduction map being lightweight and re-learned per task order while the expansion map remains frozen.

## Method

HoloGNN decouples representation learning into an expansion map and a reduction map. The expansion map performs symmetry breaking: it iteratively perturbs node features with standard basis vectors 1_v for selected 'breaking nodes' (chosen by permutation-equivariant selectors like degree groups or isomorphism classes), passing the perturbed graph through a structural GNN to produce T distinct views per node. Sequential breaking (Algorithm 1) feeds prior views into each step and provably generalizes the Lanczos algorithm, yielding canonical eigenvectors free of sign/basis ambiguity; parallel breaking (Algorithm 2) computes all views independently from V_1 for speed. The reduction map is a lightweight, task-specific network that aggregates the T views using learnable set functions φ_λ and ρ_λ, respecting the partition Λ to reintroduce exactly the permutation symmetries required for the target task order (order-1, order-2, etc.), producing most-expressive structural representations (Theorem 4.5). This design bypasses the impossibility result by never committing to a single symmetry structure during pre-training.

## Results

On CORA, HoloGNN pre-trained on link prediction and adapted to node classification achieves 80.2% accuracy (only 1.5% below its 81.6% directly-trained score), while SAGE drops 7% and SEAL/NBFNet drop up to 41%. On the order-3 MovieLens UserMovieUser task, HoloGNN's worst cross-order transfer is 72.1% (9% drop), versus 22% for SAGE, OOM for SEAL, and N/A for NBFNet. On RelBench rel-stack, SAGE completely fails (0.0 MAP) when transferring from node-level to link-level tasks, while HoloGNN achieves 2.38 MAP. For eigenvector-based link prediction, HoloGNN's expansion map achieves 0.816 AUC on Barabási-Albert (vs. 0.773 for Sign Equivariant) in 0.040s (vs. 0.054s).

## Baselines & Comparisons

Against SAGE (Hamilton et al., 2017), HoloGNN matches performance on same-order tasks (e.g., 88.8 vs. 88.2 AUROC on user-engagement when both are pre-trained on link prediction) but dramatically outperforms on cross-order transfer: SAGE drops to 0.0 MAP when transferring node→link on rel-stack, while HoloGNN retains 2.38 MAP. On CORA, SAGE suffers a 7% accuracy drop when pre-trained on link prediction and adapted to node classification, compared to HoloGNN's 1.5% drop. SEAL (Zhang & Chen, 2018) and NBFNet (Zhu et al., 2021) both experience up to 41% performance drops on CORA cross-order transfer; SEAL additionally runs out of memory on order-3 MovieLens tasks, and NBFNet cannot handle order-3 at all. For the eigenvector link-prediction comparison (Table 2), HoloGNN's expansion-map eigenvectors match Sign Equivariant (Lim et al., 2023) on Erdős-Rényi (0.750 vs. 0.751 AUC) and clearly outperform it on Barabási-Albert (0.816 vs. 0.773 AUC), while running 20–25% faster. SignNet (Lim et al., 2022) is substantially outperformed by HoloGNN eigenvectors on both synthetic graphs (0.750 vs. 0.498 on Erdős-Rényi; 0.816 vs. 0.707 on Barabási-Albert). GCN (Kipf & Welling, 2017) serves as a standard GNN baseline with performance comparable to SAGE, showing similar cross-order degradation.

## Relation to Prior Work

This paper builds directly on the impossibility results of Srinivasan & Ribeiro (2020) and Zhang et al. (2021), which show that most-expressive structural representations of one task order cannot serve another, and on the positional encoding literature (eigenvectors, sign/basis invariant and equivariant networks) that addresses the complementary but also task-specific need for positional information. The key departure is architectural: rather than searching for a single flat embedding that satisfies all permutation symmetries simultaneously (proven impossible), HoloGNN uses a two-stage expansion-reduction design where the expansion map deliberately produces symmetry-free representations via iterative single-node symmetry breaking, and a lightweight task-specific reduction map reintroduces the correct order-r symmetries. The sequential breaking algorithm is shown to subsume the Lanczos algorithm, providing a learnable and canonical way to compute eigenvectors without sign or basis ambiguities, going beyond prior spectral methods that require explicit canonicalization or equivariant network designs.

## Why It Matters / Open Questions

This work provides the first practical architecture that provably bridges the gap between task orders in graph representation learning, addressing a fundamental barrier that has prevented graph ML from developing general-purpose pre-trained models analogous to LLMs in NLP. The impossibility result for flat node embeddings (Proposition 2.3) cleanly reframes why prior approaches fail, while the holographic representation definition gives a principled path forward. Limitations include experiments on relatively small graphs (CORA, MovieLens, rel-stack), the practical constraint of T*≤10 symmetry breakings, and the need to train a new reduction map per task order. Open questions include scalability to million-node graphs, applicability to graph-level tasks, and whether the approach can be combined with attention-based architectures like graph transformers.

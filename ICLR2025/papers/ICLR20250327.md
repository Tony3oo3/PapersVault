## Problem

Existing brain-optimized image synthesis methods (e.g., BrainDiVE, NeuroGen) independently generate stimuli from random noise without enforcing structural constraints, so each synthesized image lacks an explicit reference point for comparison. This makes it difficult to disentangle which visual or semantic features genuinely drive a cortical region's selectivity from those that are random artifacts of the generative process, ultimately requiring laborious human behavioral studies to interpret large image sets.

## Input / Output

The method takes a real reference image (from the NSD/COCO test set), a target ROI's modulation embedding (a unit-norm vector in CLIP space derived from a linear regression on normalized CLIP embeddings predicting ROI-averaged fMRI beta values, then projected to natural-image space), and two hyperparameters: interpolation α ∈ [0,1] controlling the degree of semantic shift, and SDEdit noise level γ ∈ [0,1] controlling structural fidelity. It produces a set of manipulated images (one per α value) that maximize or minimize predicted fMRI activity in the target ROI, along with quantified differences in 16 semantic category presences (via CLIP cosine similarity against overcomplete WordNet noun embeddings) and mid-level features (entropy, metric depth via ZoeDepth, Gaussian curvature and surface normals via XTC) relative to the reference.

## Method

BrainACTIV derives ROI-specific modulation embeddings z_max and z_min from the weight vector of a regularized linear regression mapping normalized CLIP image embeddings to ROI-averaged fMRI beta values, then projects them into natural-image CLIP space via a decoupled weighted sum over 400K LAION images to close the modality gap. For a reference image I, its CLIP embedding z_I is spherically linearly interpolated (slerp) toward z_max or z_min at parameter α, producing an intermediate embedding that encodes a controlled degree of brain-optimal semantic shift. This intermediate embedding conditions a pretrained Stable Diffusion model through IP-Adapter (bypassing the adapter's own image encoder since the embedding is already available), while SDEdit initializes the denoising process at timestep t_0 = γ·T by adding noise to the reference image, thereby preserving low-level structure. The key distinction from prior work is that the reference image serves as a fixed comparison point, so all observed changes in the output are attributable to the brain-optimality objective rather than stochasticity in the generation process, enabling direct quantification of which visuo-semantic and mid-level features a cortical region prefers.

## Results

BrainACTIV preserves structural similarity to the reference image: at α=1, L2 distances between reference and variations range from 29.4–32.3 (vs. 79.2±15.7 for random image pairs), and LPIPS scores range from 0.24–0.31 (vs. 0.55±0.09 for random pairs), across all six ROIs. Predicted ROI activations show a stable monotonic increase (maximization) or decrease (minimization) as a function of interpolation α for both the DINO-ViT and fwRF encoders, with an expected lag up to α≈0.4 due to the SDEdit warm-up schedule. Category-presence analysis confirms known selectivities: FFA maximization increases faces, EBA increases body parts, VWFA increases text, and OPA/PPA/RSC increase manmade structures/scenes, all consistent with prior neuroimaging literature.

## Baselines & Comparisons

The paper does not perform head-to-head quantitative comparisons against prior brain-optimized image synthesis methods (BrainDiVE, NeuroGen); instead, it validates its approach against two types of references. First, a random-pair baseline (1,000 random image pairs from the test set) demonstrates that BrainACTIV variations are substantially more structurally similar to the reference than arbitrary images (L2 reduced by ~60%, LPIPS reduced by ~50%). Second, the method's outputs are validated against established neuroscientific findings: the top-5 categories identified for each ROI (FFA→faces, EBA→body parts, VWFA→text, OPA/PPA/RSC→places) match decades of fMRI literature, and mid-level feature correlations (surface normals, depth) reproduce known distinctions between scene- and object-selective regions. The paper positions its key advantage over BrainDiVE as the explicit reference-image comparison point, which eliminates the need for human behavioral studies to disentangle brain-preferred features from generative-model stochasticity.

## Relation to Prior Work

BrainACTIV extends the line of brain-guided stimulus generation initiated by NeuroGen (Gu et al., 2022), Ratan Murty et al. (2021), and BrainDiVE (Luo et al., 2023), which used GANs or diffusion models steered by brain-encoder gradients to synthesize maximally activating images. The key departure is conceptual: rather than independently sampling noise vectors (which produces a heterogeneous set of images with no explicit comparison point), BrainACTIV manipulates a fixed reference image via spherical interpolation in CLIP space, IP-Adapter conditioning, and SDEdit structural preservation. This shifts the problem from 'generate an optimal image' to 'identify what changes in a known image drive activation up or down,' enabling direct quantification of visuo-semantic and mid-level feature differences. The modulation-embedding derivation and modality-gap projection follow BrainDiVE and BrainSCUBA (Luo et al., 2024), while the image-prompting and structural-control machinery draws on IP-Adapter and SDEdit.

## Why It Matters / Open Questions

By anchoring manipulations to a reference image, BrainACTIV provides neuroscientists with a controllable, interpretable tool for formulating and testing hypotheses about cortical selectivity without relying on human behavioral ratings of large image sets. The ability to accentuate differences between category-overlapping ROIs (e.g., OFA vs. FFA, OPA vs. PPA) and to explore 'no-man's land' regions like anterior IT opens a path toward finer-grained functional mapping. Key limitations include dependence on pretrained model biases (CLIP, Stable Diffusion) and validation solely through predicted activations rather than novel fMRI recordings; the authors explicitly call for empirical validation against new brain data. Open questions include whether the approach generalizes to non-visual modalities, whether fine-tuned domain-specific encoders can resolve finer-grained selectivity, and whether the method supports closed-loop optimization paradigms.

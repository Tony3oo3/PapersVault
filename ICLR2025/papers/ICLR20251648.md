## Problem

While universal approximation theorems guarantee that neural networks with fully trained weights and biases can approximate any continuous function, it remained an open question whether this property holds when only biases are learned and all weights are fixed at random values. This gap is significant because bias-related mechanisms (tonic inputs, firing thresholds) are central to both neuroscience (rapid task switching without synaptic plasticity) and AI (prefix tuning, BitFit), yet their theoretical expressivity was uncharacterized.

## Input / Output

For feedforward experiments, the network consumes 28×28 grayscale images and outputs 10-class labels, with the only trainable parameters being the hidden-layer bias vector (one scalar per unit). For recurrent experiments, inputs are either a single observed dimension of a dynamical system (e.g., one coordinate of the Lorenz attractor) or a 2D Cartesian target position, and outputs are future trajectory predictions or continuous motor control signals driving a point-mass arm. A key structural constraint is that all weight matrices (input, recurrent, output) are sampled once from a uniform or Gaussian distribution and frozen throughout training, so the entire learned representation is encoded in the bias vector alone.

## Method

The core mechanism is that with a bias-learning activation (e.g., ReLU, which is zero below a threshold), setting a bias very negative effectively masks off a unit, while appropriate bias values activate it to match a target subnetwork. The theoretical proof proceeds in two steps: first, a fully-trained network approximates the target function or dynamical system; second, a much wider random network is shown (via a probabilistic argument over block masks) to contain a subnetwork whose parameters are ε-close to the trained one with high probability, and biases are then tuned to select exactly that subnetwork. This yields Theorem 1 (universal function approximation for FNNs) and Theorem 2 (finite-time trajectory approximation for RNNs), both holding with probability 1−δ for sufficiently large hidden width. Empirically, the authors validate these results across multi-task image classification (7 MNIST variants with shared random weights), comparison against binary mask learning, autonomous generation of oscillatory dynamics (cosine, van der Pol), Lorenz attractor forecasting, and a center-out reaching motor control task, demonstrating that bias learning produces task-selective unit clusters and shapes the Jacobian of the effective connectivity matrix to generate oscillations.

## Results

On Fashion MNIST, bias-learned FNNs with frozen random weights achieve validation accuracy comparable to (but slightly below) fully-trained networks, with the largest gains occurring before 5×10³ hidden units. In multi-task learning across 7 MNIST-style datasets, a single bias-learned network with 3.2×10⁴ trainable parameters matches a fully-trained network with ~2.5×10⁷ parameters on most tasks (only significantly worse on KMNIST). For the Lorenz attractor prediction task, both fully-trained and bias-learned RNNs (width 1024) achieve R² > 0.99 on held-out trajectories. In the bias-vs-mask comparison on MNIST, bias learning achieves 0.934±0.001 test accuracy versus 0.919±0.002 for mask learning (~1.5% improvement).

## Baselines & Comparisons

The paper compares bias-learned networks against three baselines: (1) fully-trained networks with matched architecture, (2) mask-learned networks on the same random weights, and (3) fully-trained networks with matched parameter count. Against fully-trained networks, bias learning achieves comparable but slightly worse performance on Fashion MNIST and multi-task classification, requiring substantially more hidden units (weights scale quadratically with width, so a bias-learned network with the same number of trainable parameters is much wider). Against mask learning on identical random weights, bias learning wins by ~1.5% test accuracy on MNIST (0.934 vs 0.919), which is expected since biases offer a continuous range of values versus binary masks. For autonomous dynamical systems (van der Pol oscillator), bias learning is sensitive to the recurrent weight gain (requiring g≥1) while fully-trained networks with the same parameter count are not, highlighting a key limitation. For the Lorenz attractor and motor control tasks, bias-learned RNNs match fully-trained performance at sufficient width but require ~10× more training epochs for the reaching task.

## Relation to Prior Work

This paper extends the universal approximation literature (Hornik 1989, Leshno 1993) to the specific regime where all weights are fixed and random, and only biases are optimized. The proof technique directly borrows from the Strong Lottery Ticket Hypothesis over units (Malach et al. 2020), showing that bias learning can implement the same masking mechanism, and the RNN result builds on Schafer & Zimmermann's (2006) universal approximation for recurrent networks. In the applied AI space, the work provides theoretical grounding for parameter-efficient fine-tuning methods like BitFit (Zaken et al. 2021) and prefix tuning (Li & Liang 2021), while in neuroscience it formalizes the role of tonic inputs and firing-threshold modulations as bias-like parameters that reshape circuit dynamics without synaptic plasticity.

## Why It Matters / Open Questions

The result provides the first theoretical guarantee that bias-only learning achieves universal approximation, resolving an open question and giving formal justification to both the neuroscience literature on input-mediated network reconfiguration and the AI literature on parameter-efficient fine-tuning. However, the proof is an existence result that massively overestimates required network width (Remark 2 suggests ~10^12 units for a trivial 1-3-1 network), so practical scaling remains unclear. Key open questions include: whether the width requirement can be tightened, how bias learning scales in deep networks, whether convergence holds for infinite-time (not just finite-horizon) dynamical systems, and whether structured (non-uniform) weight distributions—more biologically realistic—preserve the approximation guarantee.

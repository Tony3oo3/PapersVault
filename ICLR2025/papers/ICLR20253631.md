## Problem

LLMs frequently fail on multi-step chemical reasoning due to errors in domain-specific formulas, incorrect reasoning chains, and syntax failures when generating Python code for calculations. Existing approaches (e.g., StructChem, tool-augmented agents) rely on fixed workflows or human-curated knowledge and lack the ability to retain and reuse solutions from previously solved analogous problems, unlike human learners who build a growing library of strategies over time.

## Input / Output

The system takes a complex chemical problem (free-text description plus initial conditions such as temperature, pressure, moles) and produces a final numerical answer validated against ground truth with 0.01 relative tolerance, alongside a structured step-by-step solution containing explicit formulae, reasoning steps, and executable Python code. Internally, the problem is decomposed into a tree of 1–3 top-level sub-tasks (each with a goal, criticism, and milestones), and each sub-task yields an intermediate sub-solution that is concatenated into the overall answer. The library itself is constructed offline from a development set (9–16 problems per dataset) and then dynamically enriched during the test phase.

## Method

ChemAgent maintains a self-updating library composed of three memory types: Planning Memory (high-level strategies), Execution Memory (structured sub-task/solution pairs used as few-shot examples), and Knowledge Memory (fundamental formulas and principles generated on-the-fly). During library construction, development-set problems are decomposed into atomic sub-tasks, ranked by difficulty (curriculum learning), and stored as (condition, sub-task, sub-solution) triples. At inference time, the agent decomposes a new problem, retrieves relevant memory units via cosine similarity of Llama3 embeddings (2-shot for planning, 4-shot for execution), and when no similar memory exists, generates synthetic problems from the LLM's parametric knowledge to fill the gap. An Evaluation & Refinement module (optionally using a stronger LLM) checks each sub-solution against Knowledge Memory for unit/formula errors and can restructure the task tree if a sub-task is misaligned with the main goal. Crucially, the library is updated in-place during the test phase: every correctly solved sub-task is appended to Execution Memory and its strategy summary to Planning Memory, enabling progressive self-improvement across iterations without any gradient-based training.

## Results

On the four SciBench chemistry datasets (CHEMMC, MATTER, ATKINS, QUAN), ChemAgent with GPT-4 achieves an average accuracy of 57.16%, outperforming StructChem (47.66%) by 9.50 points and Few-shot + Direct Reasoning (19.48%) by 37.68 points. The largest single-dataset gain is on CHEMMC, where ChemAgent reaches 74.36% versus 28.21% for direct reasoning (a 46% relative improvement). For open-source models, ChemAgent yields consistent gains: +8.34% on Llama3.1-7b, +13.04% on Llama3.1-70b, and +10.11% on Qwen2.5-72b over their respective direct-reasoning baselines.

## Baselines & Comparisons

ChemAgent (GPT-4, 57.16% avg) outperforms StructChem (Ouyang et al., ICML 2024; 47.66% avg) by 9.50 points across all four datasets, with the largest margin on CHEMMC (+15.39 pts) and MATTER (+18.31 pts). Against the SciBench Few-shot + Python baseline (Wang et al., ICML 2024; 43.57% avg), ChemAgent gains 13.59 points, and against Few-shot + Direct Reasoning (19.48% avg) it gains 37.68 points. The advantage over StructChem is consistent across all four sub-datasets, confirming that the self-updating library mechanism provides gains beyond structured prompting alone. On open-source backbones (Llama3.1-7b/70b, Qwen2.5-72b), ChemAgent similarly surpasses direct reasoning by 8–13 points, with stronger base models yielding larger absolute improvements, suggesting the framework scales with model capability.

## Relation to Prior Work

ChemAgent synthesizes several existing threads—task decomposition (least-to-most prompting, decomposed prompting), external memory for LLM agents (MemoryBank, Agent Workflow Memory), and structured chemistry reasoning (StructChem)—into a unified agentic framework with a dynamically self-updating library. Its key departure from prior work is the integration of three distinct memory types (planning, execution, knowledge) that update in real time during inference, rather than relying on fixed workflows or human-curated knowledge as in StructChem or tool-augmented approaches like ChemCrow and ChemToolAgent. The curriculum-learning-inspired ranking of sub-tasks by difficulty and the self-improving mechanism (generating synthetic problems when no similar memory exists) are repurposed from unrelated domains to serve the library's growth.

## Why It Matters / Open Questions

The self-updating library offers a practical path toward LLM agents that improve with experience without retraining, which could generalize to other scientific domains (the authors note only prompt modifications are needed for physics). However, the framework is currently validated only on four chemistry sub-datasets from SciBench, the computational cost (~$0.17/example with evaluation) is non-trivial, and the hybrid-memory result (mixing GPT-3.5 and GPT-4 memories performs worse than either alone) reveals unresolved challenges in memory retrieval and quality control. Open questions include whether the self-evolution mechanism scales to larger, more diverse problem sets, how to distinguish beneficial from misleading memories when semantic similarity is high, and whether the gains hold for domains requiring substantially different reasoning structures.

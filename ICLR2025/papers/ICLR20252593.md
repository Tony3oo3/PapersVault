## Problem

Decentralized SGD's convergence rate degrades as the number of nodes grows because the spectral gap of the gossip topology shrinks toward zero, causing node parameters to drift apart. Prior work attempted to fix this by designing topologies with larger spectral gaps (exponential graphs, Base-2 Graph), but no topology short of a complete graph can fully eliminate the degradation at large scale. The paper asks whether a decentralized method can be designed whose convergence rate is independent of the total number of nodes.

## Input / Output

The method operates in a setting where any two of n nodes can communicate directly (data center or Internet-connected nodes). Each node holds a local dataset D_i, and the algorithm takes as input the total node count n, a small topology G_k over k active nodes (e.g., a ring or exponential graph), and the number of active nodes k. The output at each iteration is the average of the k active nodes' parameters, which converges to a stationary point of the global objective f(x) = (1/n)Σf_i(x). Inactive nodes' parameters are discarded and re-initialized from active nodes upon reactivation, so only k parameters are ever meaningfully maintained.

## Method

TELEPORTATION randomly samples k active nodes from n at each iteration, assigns them token IDs {1,…,k}, and has each active node fetch its parameters from the previous iteration's active node holding the same token ID (the 'teleportation' step). The active nodes then perform a local SGD update and gossip-average over the small topology G_k, whose spectral gap p_k depends only on k, not on n. By choosing k appropriately (e.g., k = O((T(σ²+ζ²)/(Lr₀))^{1/7}) for a ring), the convergence rate becomes O(√(Lr₀σ²/(nT)) + O(1/T) terms), where only the first term involves n and it improves with n—completely eliminating the degradation. An efficient hyperparameter search over k ∈ {1, 2, 4, …, n} runs all candidates in parallel within 2T total iterations, matching the optimal-k convergence rate without grid search over all n values.

## Results

In the synthetic experiment (n=100 nodes), TELEPORTATION converges up to three orders of magnitude faster than Decentralized SGD with a ring topology and up to 10× faster than DSGD with the state-of-the-art Base-2 Graph topology. On neural network training (n=25 nodes), TELEPORTATION outperforms DSGD in the heterogeneous data setting (Dirichlet α=0.1) on both Fashion MNIST/LeNet and CIFAR-10/VGG, while all methods achieve competitive accuracy in the homogeneous setting (α=10.0). Notably, the efficient hyperparameter search (Alg. 2) selects only a small number of active nodes (k=1–16 out of n=100) to achieve these gains, confirming that activating a proper subset of nodes is sufficient to eliminate convergence-rate degradation from large n.

## Baselines & Comparisons

TELEPORTATION is compared against two Decentralized SGD baselines: DSGD with a ring topology and DSGD with the Base-2 Graph (the state-of-the-art topology from Takezawa et al., 2023b). In the synthetic convergence experiment (n=100), TELEPORTATION dominates both baselines across all noise (σ²) and heterogeneity (ζ²) settings, achieving up to 1000× faster convergence than DSGD-ring and up to 10× faster than DSGD-Base-2. On neural network training with heterogeneous data (α=0.1), TELEPORTATION reaches higher test accuracy more stably than both DSGD baselines on Fashion MNIST and CIFAR-10, while in the homogeneous case (α=10.0) all three methods achieve comparable accuracy. Under heterogeneous network delays (τ=5 µs), DSGD with the ring topology can finish training faster in the homogeneous setting due to its local communication pattern, but TELEPORTATION still reaches high accuracy faster in the heterogeneous data setting, demonstrating that its parameter-teleportation mechanism is essential when data distributions are non-identical.

## Relation to Prior Work

TELEPORTATION builds directly on Decentralized SGD (Lian et al., 2017) and its convergence analysis framework (Koloskova et al., 2020b), but departs from the dominant line of work that attempts to fix convergence degradation by designing topologies with large spectral gaps (exponential graphs, Base-2 Graph, EquiTopo). Instead of improving the topology over all n nodes, TELEPORTATION activates only k nodes and performs gossip averaging on a small k-node topology, drawing a conceptual parallel to token algorithms where parameters 'walk' across nodes—yet unlike token algorithms, it preserves linear speedup. It is also explicitly distinguished from client sampling (Liu et al., 2022), where gossip averaging still occurs on the full n-node topology and thus still suffers from the same spectral-gap degradation.

## Why It Matters / Open Questions

The central result—that a properly chosen number of active nodes k completely eliminates the convergence-rate degradation from increasing n, with no prior topology (except the complete graph) achieving this while remaining communication-efficient—is a clean theoretical contribution that reframes how one thinks about scaling decentralized learning. The efficient hyperparameter search (Alg. 2) makes the method practical by finding the right k within 2T iterations. Key limitations include the requirement that any two nodes can communicate (ruling out wireless sensor networks) and the fact that in heterogeneous networks, teleportation may route parameters across distant nodes; the paper shows this is tolerable under data heterogeneity but leaves easing the connectivity assumption as open work.

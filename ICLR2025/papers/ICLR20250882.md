## Problem

Enabling LLMs to comprehend complex document layouts typically requires either intricate architectural modifications, treating coordinates as a new modality demanding costly pre-training, or complex encoding networks that increase computational overhead. The paper asks whether layout information can be injected into existing LLMs with no architectural changes, no additional learnable parameters, and no expensive pre-training stage.
![Teaser figure](../imgs/ICLR20250882/cropped_page2_idx0.webp)

## Input / Output

The method consumes OCR-extracted text tokens where each token carries a multi-dimensional position vector P = [m, B], with m being a reading-order index and B = [x0, y0, x1, y1] being normalized bounding-box coordinates (scaled by λ=1000). Crucially, the input token sequence format is identical to standard LLM text input—layout information is encoded entirely through modified position embeddings rather than appended as extra tokens or a separate modality. The model produces standard text outputs: natural-language answers to document questions or structured entity extractions.

## Method

Group Position Embedding (GPE) partitions the h attention heads into l groups matching the l dimensions of the position vector P, so each group attends to a distinct positional component. For Sinusoidal PE, the per-head embedding is GroupPE(x,P,i) = MLP_i(x) + PE(P_Gr(i)); for RoPE, it is GroupRoPE(x,P,i) = f(MLP_i(x), P_Gr(i)), where Gr(i) is a grouping function mapping head index i to a position dimension. The default grouping allocates 4 of 32 heads to reading order and the remaining 28 heads evenly across the four bounding-box coordinate dimensions. Because GPE reuses the model's native position-embedding space and introduces zero new parameters, it requires only lightweight fine-tuning (as few as 0.5M samples) and is compatible with any base LLM architecture, including those using group-query attention or bidirectional attention.

## Results

GPE-Qwen2-7B achieves 78.1 ANLS on DocVQA, 344.0 CIDEr on VisualMRC, 82.6 ANLS on FUNSD, 86.9 ANLS on CORD, and 97.8 ANLS on SROIE, outperforming its base model (Qwen2-7B: 71.8/367.4/78.1/83.4/97.7) on DocVQA, FUNSD, and CORD. In the controlled comparison (Table 2, same base model and data), GPE surpasses all layout-aware baselines on DocVQA (78.1 vs. 71.5 for Text Box and Add Box Embedding) and CORD (86.9 vs. 79.5 for Add Box Embedding). On the new BLADE benchmark, GPE-RoPE achieves 77.3 on SynthTables and 79.3 on Websites, substantially exceeding the best baseline (Add Box Embedding: 51.4 and 50.3 respectively).

## Baselines & Comparisons

Against plain LLM baselines, GPE consistently improves: GPE-Qwen2-7B gains +6.3 ANLS on DocVQA (78.1 vs. 71.8) and +3.5 on CORD (86.9 vs. 83.4) over Qwen2-7B, while GPE-Llama2-7B gains +10.6 on DocVQA (77.2 vs. 66.6) over Llama2-7B-Chat. Against end-to-end MLLMs, GPE substantially outperforms all: GPE-Qwen2-7B (78.1 DocVQA, 82.6 FUNSD) beats Qwen-VL-7B (65.1, 47.1) and TextMonkey+ (66.7, 42.9) by large margins, and dwarfs LLaVAR/LLaVA-1.5 which score below 14 on DocVQA. Among LLM-with-layout methods, GPE-Qwen2-7B leads on DocVQA (78.1 vs. 77.2 LayTextLLM, 74.3 LayoutLLM, 72.8 DocLayLLM) and CORD (86.9 vs. 82.5, 62.2, 79.4), though LayTextLLM edges it slightly on SROIE (96.1 vs. 97.8 is actually GPE winning). In the controlled same-model comparison (Table 2), GPE decisively beats Text Box (71.5), Insert Box Embedding (67.8), and Add Box Embedding (71.5) on DocVQA, and outperforms Add Box Embedding by +7.4 on CORD (86.9 vs. 79.5) and +10.0 on SROIE (97.8 vs. 87.9). On the BLADE benchmark (Table 3), GPE-RoPE dominates all baselines across all six sub-tasks, with the largest gaps on SynthTables (+25.9 over Add Box Embedding) and Websites (+29.0), confirming that layout-aware positional encoding is critical for complex layout comprehension.

## Relation to Prior Work

GPE builds directly on the two dominant positional encoding schemes in modern LLMs—Sinusoidal (Vaswani et al., 2017) and RoPE (Su et al., 2024)—by partitioning attention heads into groups, each receiving a different positional signal (reading order vs. spatial coordinates). This departs sharply from prior document-understanding approaches that either flatten bounding-box coordinates into the text stream (Perot et al., 2023), add box embeddings as a new modality requiring costly pre-training (LayoutLLM, DocLLM, DocLayLLM), or insert encoded position vectors into the token sequence (LayTextLLM). The conceptual lineage also connects to LayoutLM's coordinate encoding (Xu et al., 2020) and 2D positional encodings in vision (ViT, Deformable-DETR), but GPE's key departure is exploiting the head-independence of multi-head attention to encode multi-dimensional positions without altering the input format or adding learnable parameters.

## Why It Matters / Open Questions

GPE offers a parameter-free, architecture-preserving way to inject layout information into any LLM with multi-head attention, requiring only minimal fine-tuning on ~0.5M samples—substantially less data than competing layout-aware methods. The introduction of BLADE is important because the paper convincingly demonstrates that mainstream document benchmarks (DocVQA, VisualMRC, FUNSD, CORD, SROIE) largely fail to test layout comprehension, meaning prior SOTA claims may overstate layout understanding. Open questions include whether the observed slight degradation in pure text comprehension (e.g., VisualMRC) can be eliminated, whether GPE extends to other multi-dimensional positional tasks (graphs, 3D scenes), and whether the current OCR-dependent pipeline can be replaced by end-to-end visual input while retaining the grouping mechanism.

## Problem

Existing point process models are constrained by their reliance on the intensity function, which either assumes point independence (for spatial processes) or requires sequential, likelihood-based sampling (for temporal/spatiotemporal processes). This creates an inherent trade-off between efficiency and flexibility, making it difficult to capture complex point interactions and sample efficiently on general metric spaces.
![Teaser figure](../imgs/ICLR20252970/cropped_page0_idx0.webp)

## Input / Output

For unconditional generation, the model takes a noise point set sampled from a constant-intensity Poisson process and produces a complete point set over T reverse diffusion steps. For conditional generation, it additionally accepts a binary conditioning mask C: D→{0,1} on the metric space and a partial point set (the points falling within the mask), then generates only the points outside the mask. Points are embedded permutation-invariantly via a Transformer encoder with full attention, and the number of points to generate is predicted jointly with their locations, so no fixed cardinality is required at input.

## Method

Point Set Diffusion defines a forward Markov chain that stochastically interpolates between a data point set X_0 and a noise point set X_T by simultaneously thinning (removing) data points with a schedule {α_t} and superposing (adding) noise points with a schedule {β_t}, leveraging the thinning and superposition properties of point processes. The reverse process is learned by a neural network that, given X_t, predicts the full data set X_0 through two sub-tasks: a binary MLP classifier (trained with BCE loss) determines which points in X_t are retained from X_0, and a second MLP parameterizes a mixture of 16 multivariate Gaussians with diagonal covariances (trained with NLL) to predict the locations of thinned points in X_0 \ X_t. The noise schedule uses α̅_t = 1 − β̅_t with a cosine schedule (T=100) to keep the expected point count constant throughout the diffusion. Sampling is fully parallel—entire point sets are generated simultaneously rather than sequentially—yielding orders-of-magnitude speedup over autoregressive baselines, and conditional generation is achieved by simply fixing the masked points at each reverse step without retraining.

## Results

On STPP unconditional generation (density estimation), POINT SET DIFFUSION achieves the best Sequence Length (SL) and MMD across all four datasets: Earthquakes (SL 0.042, MMD 0.023), Covid NJ (SL 0.189, MMD 0.043), Citybike (SL 0.032, MMD 0.020), and Pinwheel (SL 0.023, MMD 0.020). On STPP forecasting, it achieves the best MAE and Counting Distance on 3 of 4 datasets (e.g., Citybike MAE 5.928 vs. 127.968 for DEEPSTPP; Pinwheel CD 6.437 vs. 15.792 for DEEPSTPP), with DEEPSTPP slightly ahead on Covid NJ (MAE 6.264 vs. 7.293). For SPP tasks, POINT SET DIFFUSION dominates both unconditional (e.g., Citybike MMD 0.092 vs. 0.336 for Log-Gaussian Cox) and conditional generation (e.g., Earthquakes MAE 4.651 vs. 30.419 for Regularized Method). Sampling runtime is nearly constant regardless of point set length, unlike autoregressive baselines that scale linearly.

## Baselines & Comparisons

Against the three STPP baselines, POINT SET DIFFUSION achieves the best SL and MMD on all four datasets for unconditional generation, with particularly large margins on Citybike (MMD 0.020 vs. 0.611 for DIFFSTPP and 0.677 for DEEPSTPP) and Pinwheel (MMD 0.020 vs. 0.055 for DIFFSTPP). For STPP forecasting, POINT SET DIFFUSION outperforms DEEPSTPP, DIFFSTPP, and AUTOSTPP on Earthquakes, Citybike, and Pinwheel, but DEEPSTPP edges it out on Covid NJ (MAE 6.264 vs. 7.293; CD 8.492 vs. 10.865). On SPP tasks, POINT SET DIFFUSION decisively beats both Log-Gaussian Cox and the Regularized Method on all four datasets for both unconditional and conditional generation, with the Regularized Method showing especially poor conditional imputation on Earthquakes (MAE 30.419 vs. 4.651). In the TPP comparison with ADD-THIN (Appendix A.6), the two methods are broadly competitive: ADD-THIN wins on a few MMD scores (e.g., Hawkes1 0.02 vs. 0.03) while POINT SET DIFFUSION wins on others (e.g., MRP 0.07 vs. 0.10, Yelp1 0.06 vs. 0.08), and forecasting results are nearly tied across all seven TPP datasets. POINT SET DIFFUSION also uses far fewer parameters (~25K vs. 450K–1.6M for STPP baselines) and enables parallel sampling with near-constant runtime regardless of sequence length.

## Relation to Prior Work

This paper generalizes ADD-THIN (Lüdke et al., 2023), which applied thinning and superposition to define a diffusion process for temporal point processes, to point processes on arbitrary metric spaces including spatial and spatiotemporal settings. It inherits the DDPM (Ho et al., 2020) forward/reverse diffusion framework but replaces Gaussian noise with a discrete stochastic interpolation between data and noise point sets, using a Transformer encoder for permutation-invariant point set representation. The key departure from the broader point process literature is bypassing the conditional intensity function entirely, which has been the dominant (and limiting) parameterization in both classical models (Hawkes, Cox) and neural approaches (DeepSTPP, DiffSTPP, AutoSTPP). Unlike ADD-THIN, which required task-specific training for conditioning, this model supports arbitrary conditioning masks on the metric space from a single unconditional model.

## Why It Matters / Open Questions

The intensity function has been a fundamental bottleneck in point process modeling, forcing trade-offs between expressiveness, computational tractability, and the ability to capture complex inter-point dependencies. By eliminating this dependency, the approach enables parallel sampling (orders of magnitude faster than autoregressive baselines) and flexible conditioning for arbitrary spatial/temporal masks without retraining. The paper also makes a compelling methodological argument that standard NLL-based evaluation is insufficient for assessing true generative quality, proposing distributional metrics (Wasserstein distance, MMD) instead. Limitations include the inability to interpret or estimate the conditional intensity (relevant for inference applications), and the approach is currently validated only on bounded Euclidean domains; extension to Riemannian manifolds, topological spaces, and discrete structures remains open.

## Problem

Existing unsupervised skill discovery methods rely on proxies such as state-space coverage, discriminator distinctiveness, or mutual information to encourage behavioral diversity, but these do not guarantee that learned skills are semantically meaningful or distinct. In high-DOF systems like robot-arm manipulation, unstructured joint movements can appear diverse in state space while lacking any interpretable semantic difference. The paper asks whether the semantic understanding of large language models can be directly leveraged to maximize the semantic diversity of discovered skills.

## Input / Output

During training, the method consumes continuous robot state vectors (e.g., 39-dim for Ant, 16-dim for Franka) and a user-specified natural language prompt that constrains which semantic aspects the LLM should describe. At each transition, the LLM (GPT-4, temperature 0) is queried to produce a text description of the state, which is embedded via Sentence-Transformer to compute language-distance; states are discretized and cached to limit unique queries. At inference, a separate skill-inference network ψ takes the Sentence-Transformer embedding of a natural language goal description (e.g., 'The object is located at [0.3, 0.2]') and outputs a skill vector z, enabling zero-shot language-conditioned goal reaching without specifying the full robot configuration.

## Method

LGSD defines a language-distance d_lang between states as 1 minus the cosine similarity of their LLM-generated description embeddings, then trains a representation function φ: S→Z that is 1-Lipschitz under d_lang (enforced via dual gradient descent with a Lagrange multiplier). The skill-conditioned policy π(a|s,z) is optimized with PPO to maximize the reward r(s,z,s') = (φ(s')−φ(s))^T z where z ~ N(0,I), which the paper proves equivalent to maximizing the Wasserstein Dependency Measure between terminal states and skills under the language metric. A key theoretical contribution shows that restricting the Lipschitz constraint to adjacent (single-transition) state pairs implicitly induces a valid pseudometric over all state pairs, resolving the fact that d_lang does not satisfy the triangle inequality. User prompts constrain the LLM's descriptions to a desired semantic subspace (e.g., only report object position, or only report robot-object distance), and can be adapted mid-training to shift focus across different semantic dimensions.

## Results

On the FrankaCube manipulation task, LGSD moves the object an average of 0.5 m, which is five times greater than the second-best baseline. All three distance-maximization baselines (CSD, METRA, LSD) can manipulate the object to some degree, while both MI-based baselines (DIAYN, DADS) fail to move the object at all. In the downstream locomotion tasks (AntSingleGoal and AntMultiGoal), the high-level controller trained on LGSD skills achieves higher returns and better sample efficiency than all five baselines, as shown in Figure 9.

## Baselines & Comparisons

LGSD outperforms all five baselines on both the manipulation diversity metric and the downstream locomotion task. Against the two MI-based methods (DIAYN, DADS), LGSD has a decisive advantage: these methods cannot move the object at all in the FrankaCube task, while LGSD achieves 0.5 m average displacement. Against the three distance-maximization methods (LSD, CSD, METRA), LGSD moves the object roughly five times farther than the best of them (~0.1 m) and covers significantly more grid cells, confirming that language guidance yields more semantically meaningful exploration. In the high-level controller evaluation on AntSingleGoal and AntMultiGoal, LGSD-trained skills produce higher cumulative returns and faster convergence than all five baselines, attributed to LGSD's focus on semantically meaningful x,y position changes rather than undifferentiated changes across all 39 state dimensions.

## Relation to Prior Work

LGSD sits squarely within the distance-maximization branch of unsupervised skill discovery, building directly on the WDM framework (Ozair et al., 2019) and the 1-Lipschitz-constrained representation learning of LSD (Park et al., 2021), CSD (Park et al., 2023a), and METRA (Park et al., 2023b). The key conceptual departure is replacing the state-space metric (Euclidean distance, controllability-aware distance) with a language-distance derived from LLM-generated scene descriptions, effectively using an LLM as a semantic distance oracle rather than for planning, action generation, or reward design. The theoretical contribution (Claim 1) extends CSD's path-based pseudometric construction to handle the case where the base distance (cosine similarity of sentence embeddings) does not satisfy the triangle inequality, a gap not addressed in prior WDM-based methods.

## Why It Matters / Open Questions

The paper introduces 'semantic diversity' as a first-class objective distinct from state coverage or discriminator-based distinctiveness, and shows that a simple language prompt can steer which semantic subspace the agent explores — a level of user control absent from prior skill discovery methods. However, practical adoption is constrained by the dependency on GPT-4 for every state transition (mitigated by discretization and caching), the need for carefully hand-crafted prompts, and the observation that the Franka manipulation results show incomplete coverage of the constrained subspace. Open questions include whether vision-language models can capture semantics that are hard to express in text, whether trajectory-level (rather than state-level) semantic distances yield richer skills, and whether the approach scales to higher-dimensional or multi-object manipulation without prompt engineering becoming intractable.

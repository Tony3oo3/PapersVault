## Problem

Standard Transformers encode token-parameter interactions through fixed linear projections, so any architectural change (e.g., increasing channel dimensions) forces retraining the entire model from scratch. As foundation models grow to billions of parameters, this train-from-scratch requirement makes progressive scaling prohibitively expensive and unsustainable.
![Teaser figure](../imgs/ICLR20251123/cropped_page1_idx1.webp)

## Input / Output

For language modeling, the input is a tokenized text sequence (1024-token context) and the output is a next-token distribution; for vision, the input is 16×16 image patches at 224×224 resolution and the output is a class label. A key structural detail is that input tokens always serve as queries in the Pattention mechanism, while model parameters are represented as a variable-length set of learnable key-value token pairs whose count can be expanded independently of the input/output channel dimensions.

## Method

Tokenformer replaces every linear projection in a standard Transformer with a token-parameter attention (Pattention) layer, where input tokens act as queries and a set of n learnable parameter tokens serve as keys and values in a cross-attention computation. A modified softmax—L2 normalization followed by GeLU instead of exponential plus L1 normalization—is used to stabilize gradients and enable zero-initialization invariance for newly added parameters. Progressive scaling is achieved by concatenating new key-value parameter pairs along the token axis while keeping the feature dimension d constant, so the token-token attention cost remains unchanged regardless of model size. The architecture mirrors GPT-2's hyperparameter configuration (same layer count, hidden dimension, and 4× FFN ratio), allowing direct initialization from pre-trained Transformer weights and incremental growth from 124M to 1.4B parameters with only ~30B additional training tokens per scaling step.

## Results

On zero-shot language modeling benchmarks (trained on Pile for 300B tokens), TokenFormer-1.5B achieves 59.3% average accuracy across LAMBADA, HellaSwag, PIQA, ARC-Easy, ARC-Challenge, and WinoGrande, outperforming Pythia-1.3B (55.2%), OPT-1.3B (55.0%), and GPT-Neo 1.3B (52.4%). On ImageNet-1K classification, TokenFormer-L/16 reaches 83.1% top-1 accuracy, surpassing ViT-L/16 (76.5%) and ViT-L/16 with MAE pre-training (82.6%). For progressive scaling, Tokenformer scales from 124M to 1.4B parameters using only 30B additional tokens per stage, achieving a validation perplexity of 11.77—nearly matching a Transformer trained from scratch on 300B tokens (11.63) at roughly one-third the total compute.

## Baselines & Comparisons

TokenFormer outperforms Pythia at every comparable size: at ~150M it achieves 44.7% average zero-shot accuracy vs. Pythia-160M's 40.1%, and at ~1.5B it reaches 59.3% vs. Pythia-1.3B's 55.2%, with lower Pile perplexity (6.91 vs. 7.51) and LAMBADA perplexity (5.24 vs. 6.08). Against GPT-Neo 1.3B (52.4%) and OPT-1.3B (55.0%), TokenFormer-1.5B leads by 6.9 and 4.3 points in average accuracy respectively. On ImageNet-1K, TokenFormer-L/16 (83.1%) surpasses ViT-L/16 (76.5%), DeiT-B/16 (81.8%), and MAE-pretrained ViT-L/16 (82.6%). For progressive scaling, Tokenformer beats both Net2Net-based Transformer expansion and HyperCloning (Samragh et al., 2024) at every scaling stage (124M→354M→757M) while requiring constant token-token FLOPs (3.6×10⁴·T²) versus increasing costs for the baselines (6.8→10.1×10⁴·T²). Against non-Transformer architectures, TokenFormer-1.5B (59.3% avg acc) edges out Mamba-1.4B (59.7% avg acc but with 6.80 Pile ppl vs. 6.91) and RWKV-1.5B (54.3%), while Hybrid H3-1.3B trails at 53.0%.

## Relation to Prior Work

Tokenformer builds directly on the Transformer architecture by replacing every linear projection (QKV, output, FFN) with a cross-attention 'Pattention' layer where input tokens serve as queries and learnable parameter tokens serve as keys and values. This departs from prior model-growth methods (Net2Net, HyperCloning, progressive stacking) that expand channel dimensions and require retraining from scratch, and from LoRA-style adapters that add low-rank updates to fixed projections. Conceptually, the paper positions itself as an extreme Mixture-of-Experts instantiation where each key-value parameter pair is an individual expert, unifying token-token and token-parameter interactions under a single attention mechanism.

## Why It Matters / Open Questions

The practical impact is a ~10× reduction in per-stage training cost for progressive model scaling (124M→1.4B) while matching scratch-trained perplexity, which could substantially lower the barrier to iterative model development. The decoupling of parameter count from channel dimension keeps token-token interaction cost constant, offering a natural path toward long-context modeling without the quadratic blowup that plagues standard width scaling. Key open questions include whether the linear inference overhead of attending to thousands of parameter tokens becomes prohibitive at much larger scales, whether the MoE sparsity connection can be exploited to recover sub-linear inference cost, and whether the approach generalizes beyond the 1.4B parameter regime tested here.

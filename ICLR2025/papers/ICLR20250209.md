## Problem

Existing data pruning algorithms (EL2N, GraNd, Forgetting, Dynamic Uncertainty, CoreSet) are evaluated exclusively on average test accuracy, and this paper reveals through the first systematic study that they can produce highly biased classifiers with severely degraded worst-class performance. In particular, methods like Dynamic Uncertainty can remove entire classes at low data densities while maintaining strong average accuracy, masking catastrophic classification bias.
![Teaser figure](../imgs/ICLR20250209/cropped_page3_idx1.webp)

## Input / Output

The method takes a fully labeled K-way classification dataset of N samples and a pre-trained query model (trained on the full dataset for ~10% of the full training cycle) that provides per-class validation recall rates r_k on a held-out set. It outputs class-wise pruning densities d_k that specify the fraction of each class to retain, followed by random subsampling within each class to produce the final pruned dataset of size dN. A key design choice is that pruning within classes is purely random rather than score-based, preserving class-conditional independence that the theory identifies as essential for robustness.

## Method

DRoP is grounded in a theoretical analysis of linear classifiers on a mixture of two univariate Gaussians, which shows that the worst-class optimal decision threshold is achieved when class priors are proportional to class variances (φ_0/φ_1 = σ_0/σ_1), meaning the easier class should be pruned more aggressively. In practice, DRoP replaces the intractable variance ratio with validation error as a proxy, setting each class's pruning density proportional to (1 − r_k) where r_k is the query model's recall on that class, normalized so the overall target density d is respected. An iterative redistribution algorithm (Algorithm 1) handles the case where some classes would require d_k > 1 by capping them at full retention and reallocating excess density to unsaturated classes. The critical empirical finding is that combining these error-based class quotas with random (rather than score-based) within-class pruning yields the best worst-class accuracy, outperforming both the original pruning strategies and cost-sensitive DRO baselines like CDB-W across CIFAR-10/100, TinyImageNet, ImageNet, and Waterbirds.

## Results

On CIFAR-100 with VGG-19, Random+DRoP at 50% dataset density increases worst-class accuracy from 35.8% (full dataset) to 45.4%, an ~10-point gain at a cost of under 6% average accuracy. Random+DRoP improves all robustness metrics over the full dataset on every model-dataset pair tested (CIFAR-10, CIFAR-100, TinyImageNet, ImageNet, Waterbirds). Unlike existing pruning methods that peak in worst-class accuracy at 80–90% density, DRoP continues improving distributional robustness down to 30–40% density on TinyImageNet. On Waterbirds, Random+DRoP achieves worst-group accuracy on par with sophisticated full-dataset DRO methods such as Just Train Twice and Learning from Failure.

## Baselines & Comparisons

Random+DRoP decisively outperforms all existing pruning algorithms on worst-class accuracy: at d=0.5 on CIFAR-100 it reaches 45.3% versus GraNd (31.7%), Forgetting (34.0%), and plain Random (30.1%); on TinyImageNet it achieves 20.0% versus GraNd (12.4%) and Forgetting (9.5%). Dynamic Uncertainty (He et al., 2023) is shown to be the worst performer, removing entire classes at 10% density and producing catastrophic bias hidden under strong average accuracy. Against the DRO baseline CDB-W (Sinha et al., 2022), which improves full-dataset worst-class accuracy by 5.7% on CIFAR-100, Random+DRoP at 50% density achieves nearly twice that gain (~10 points); CDB-W applied to EL2N-pruned data maintains the original bias, and using a CDB-W-trained query model for EL2N scoring 'fails spectacularly.' On Waterbirds, Random+DRoP matches or approaches the worst-group accuracy of full-dataset methods including Just Train Twice (Liu et al., 2021), Learning from Failure (Nam et al., 2020), Learning to Split (Bao & Barzilay, 2022), and Bias Amplification (Li et al., 2023), while using only a fraction of the training data. CoreSet (Sener & Savarese, 2018) is included as a label-agnostic baseline in the broader evaluation (Figure 2) but does not improve robustness over the full dataset.

## Relation to Prior Work

This paper sits at the intersection of two largely independent research threads: data pruning (Toneva et al., Paul et al., He et al., Sorscher et al.) and distributionally robust optimization (Sagawa et al., Sinha et al., Cui et al.). Prior data pruning work has been evaluated exclusively on average test accuracy, while DRO methods operate on full datasets via loss reweighting. DRoP bridges these by repurposing class-wise validation errors (a DRO concept) to set per-class pruning quotas, combined with random subsampling within classes. The theoretical analysis in a Gaussian mixture model provides a clean justification for why error-based class ratios plus random pruning should yield near-optimal worst-class risk, and why sample-level scoring algorithms (which violate class-conditional independence) fail to do so.

## Why It Matters / Open Questions

The finding that all major data pruning algorithms (EL2N, GraNd, Forgetting, Dynamic Uncertainty) systematically worsen classification bias—sometimes removing entire classes—challenges the field's implicit assumption that more sophisticated sample-level scoring is universally better. DRoP offers a practical, zero-overhead fix (it reuses the query model already required by existing pruning methods) that improves worst-class accuracy over the full dataset while pruning 30–50% of data. Limitations include a focus on classification bias rather than full group robustness, limited cross-evaluation with DRO methods beyond CDB-W, and evaluation primarily on standard CV benchmarks. Open questions include how DRoP interacts with spurious correlations, whether it generalizes to non-classification tasks, and whether the random-within-classes principle extends to other data selection settings.

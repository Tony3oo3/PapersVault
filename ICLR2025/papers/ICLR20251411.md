## Problem

Scaling 3D visual grounding to city-scale point clouds (hundreds to thousands of objects across ~400m×400m scenes) remains unsolved. The prior city-scale baseline CityRefer requires 10 pre-selected candidate objects and exhaustively matches them, making it too slow and inaccurate for open-world localization, while its from-scratch multi-modality encoder lacks the capacity to handle complex, free-form text descriptions.
![Teaser figure](../imgs/ICLR20251411/cropped_page0_idx0.webp)

## Input / Output

The method takes a city-scale colored point cloud (pre-segmented into objects via SoftGroup, with landmark names assigned from OpenStreetMap) and a free-form text description as input. The point cloud is rasterized into a 2D top-view map at 0.1m resolution for the coarse stage. Output is the 3D localization (bounding box) of the target object among all objects in the scene, with per-candidate similarity scores; no candidate pre-selection is required, and inference takes ~32s for a scene with ~300 objects.

## Method

CityAnchor is a two-stage multi-modality LLM pipeline. The Coarse Localization Module (CLM), built on LISA (LLaVA + SAM), ingests the projected 2D map and text, generates a <RoI> token whose last-layer feature drives SAM to produce a pixel-level heatmap; objects whose center score exceeds a threshold (0.3) become candidates. The Fine-grained Matching Module (FMM), fine-tuned from LLaVA with LoRA, encodes each candidate via three feature streams — 3D CLIP features from Uni3D, 2D projected CLIP features, BiGRU-encoded landmark names, and spatial context from K=5 nearest neighbors — concatenates them with the text embedding, and regresses a similarity score through a <SCR> token and MLP. Training uses auto-regressive cross-entropy for text generation plus segmentation loss (CLM) or binary cross-entropy for the score (FMM), with positive:negative sampling at 1:3.

## Results

On the CityRefer dataset, CityAnchor achieves 50.69% Acc@0.25 and 46.86% Acc@0.50 in the Novel Objects setting, and 53.17% Acc@0.25 and 50.37% Acc@0.50 in the Novel Descriptions setting. On the self-annotated CityAnchor dataset, it reaches 41.23% Acc@0.25 / 35.11% Acc@0.50 (NO) and 47.81% Acc@0.25 / 43.40% Acc@0.50 (ND). CityAnchor also runs in ~32.45 s per query on CityRefer, which is 1.3× faster than the CityRefer baseline (42.27 s), thanks to its coarse-to-fine strategy that avoids exhaustive matching over all objects.

## Baselines & Comparisons

CityAnchor decisively outperforms all four baselines across every dataset and evaluation setting. The closest competitor, CityRefer (the only baseline designed specifically for city-scale grounding), achieves only 7.47% Acc@0.50 on CityRefer-NO versus CityAnchor's 46.86% — a gap of roughly 39 percentage points. The indoor-oriented methods (InstanceRefer, 3DVG-Transformer, EDA) perform even worse, with Acc@0.50 values below 8% on CityRefer, confirming that small-scale grounding architectures do not transfer to city-scale scenes with hundreds of objects. Notably, CityAnchor also surpasses CityRefer in efficiency: its coarse-to-fine pipeline completes grounding in 32.45 s versus 42.27 s for CityRefer on CityRefer, and 51.72 s versus 96.91 s on the CityAnchor dataset. The paper reports an average improvement of 30–43% in grounding accuracy over baselines, with the largest gains (up to 51% on Acc@0.25) observed in the Novel Descriptions setting where LLM-based text understanding provides the greatest advantage.

## Relation to Prior Work

CityAnchor extends the 3D visual grounding task from indoor scenes (ScanRefer, Referit3D) and the candidate-based city-scale formulation of CityRefer to full-scale grounding over hundreds of objects without a pre-selected candidate set. Architecturally, it builds on LLaVA/Vicuna as the LLM backbone and LISA for the coarse localization stage, while incorporating Uni3D for CLIP-aligned 3D point cloud features, SAM for heatmap-based region prediction, and BiGRU for landmark name encoding. The key departure from CityRefer is replacing a from-scratch multi-modality embedding network with a fine-tuned LLM and introducing a coarse-to-fine search strategy that avoids exhaustive matching across all city objects.

## Why It Matters / Open Questions

This is the first demonstration that multi-modality LLMs can perform accurate 3D visual grounding at city scale (300+ objects per scene), opening the door to LLM-driven urban analysis for geoscience, autonomous driving, and urban planning. The coarse-to-fine strategy is both faster (32s vs 42s) and more accurate than the prior city-scale baseline, validating that hierarchical search is essential at this scale. Key limitations include the fixed RoI threshold that doesn't adapt to object size, the ~32s inference time still being impractical for real-time use, and training on only 4 object categories in CityRefer. Open questions include extending to dynamic scenes, incorporating RAG for landmark knowledge, and whether the approach generalizes to even larger or more heterogeneous urban environments.

## Problem

Existing robust conformal prediction methods (e.g., CAS) require expensive Monte-Carlo sampling (~10⁴ samples per point) and compute a separate certified bound for every calibration or test point, leading to large prediction sets and high computational cost. This inefficiency is exacerbated for datasets with many classes (e.g., ImageNet) where union-bound corrections inflate sets to the trivial full label space. The paper asks whether robustness can be certified with a single binary certificate and far fewer samples while maintaining the same worst-case coverage guarantee.

## Input / Output

The method takes a black-box model (no white-box access needed), a held-out calibration set, a smoothing scheme (isotropic Gaussian, uniform, or sparse), and a perturbation ball (ℓ₁, ℓ₂, or binary toggle ball). It outputs a prediction set of labels with a (1−α) robust coverage guarantee for any perturbed test point within the ball. Unlike prior methods, BinCP does not require the conformity score to be bounded, so it works directly with unbounded scores like raw logits. The method is applied to RGB images (CIFAR-10 at 32×32, ImageNet at 224×224) and graph node features (Cora-ML).

## Method

BinCP binarizes the randomized smooth score by thresholding: instead of bounding the continuous smooth score s̄(x,y)=E[s(x+ε,y)], it bounds the binary probability f_y(x)=Pr[s(x+ε,y)≥τ]. The key theoretical result (Lemma 2) shows that for symmetric smoothing schemes (Gaussian, uniform, sparse), both calibration-time and test-time robustness reduce to computing a single certificate c^↓[p_α, B]—a function of only the scalar p_α and the ball B—rather than one certificate per data point. This single-certificate structure enables plug-and-play use of any existing binary robustness certificate, including de-randomized DSSN for ℓ₁ robustness that eliminates finite-sample correction entirely. When MC estimation is needed, the binary formulation allows Clopper-Pearson confidence intervals (exact for Bernoulli) instead of the looser Hoeffding or Bernstein bounds used on continuous scores, yielding tighter intervals with far fewer samples (~150 vs. ~2000+). The conformal threshold pair (p_α, τ_α) is calibrated via a quantile-of-quantiles procedure that preserves the standard 1−α coverage guarantee.

## Results

BinCP produces smaller robust prediction sets than the SOTA baseline CAS across all three datasets (CIFAR-10, ImageNet, Cora-ML) while requiring only ~150 Monte-Carlo samples per point, compared to the ~2000+ samples needed by CAS for competitive set sizes. On ImageNet with 1−α=0.9, CAS with finite-sample correction degenerates to returning the full label set Y, whereas BinCP maintains non-trivial prediction sets. Using de-randomized DSSN smoothing, BinCP achieves exact ℓ₁ robustness with no sample correction needed, yielding significantly smaller sets than Gaussian-smoothed BinCP across all radii. At very small perturbation radii (r=0.02), BinCP prediction sets are approximately 2× smaller than those from verifier-based robust CP (Jeary et al., 2024).

## Baselines & Comparisons

Against CAS (Zargarbashi et al., 2024), the primary SOTA baseline, BinCP consistently produces smaller prediction sets on all three datasets (CIFAR-10, ImageNet, Cora-ML) at the same 2000 MC sample budget, and the gap widens as the number of classes increases (ImageNet). Critically, BinCP achieves competitive or better set sizes with only ~150 MC samples, whereas CAS requires 2000+ samples to avoid trivial sets; below 2000 samples CAS's finite-sample correction inflates sets dramatically. Against RSCP+ (Yan et al., 2024), BinCP outperforms on CIFAR-10 (supplementary Fig. 14), as RSCP+ still relies on continuous-score bounding with temperature-scaled scores. Against the verifier-based method of Jeary et al. (2024), BinCP produces approximately 2× smaller sets at the same small radius r=0.02 on CIFAR-10, while also being black-box (no white-box model access needed). The de-randomized DSSN variant of BinCP further eliminates the need for finite-sample correction entirely, a capability not available to any of the compared baselines.

## Relation to Prior Work

This paper extends the robust conformal prediction line initiated by Gendler et al. (2021, RSCP) and advanced by Zargarbashi et al. (2024, CAS), both of which certify robustness by bounding the expected smooth conformity score (a continuous quantity) via randomized smoothing. The key departure is binarizing the score into a Bernoulli probability before certification, which transforms the problem from bounding a continuous mean (requiring Hoeffding/Bernstein inequalities and per-point certificates) to bounding a binary parameter (enabling exact Clopper-Pearson intervals and a single certificate). This also removes the bounded-score assumption required by CAS and RSCP, and allows plug-and-play integration of existing binary certificates including de-randomized DSSN for ℓ1 robustness (Levine & Feizi, 2021).

## Why It Matters / Open Questions

The practical impact is substantial: reducing the Monte-Carlo budget from ~2000–10000 samples (where CAS degrades to trivial full-label sets on ImageNet) to ~150 samples makes robust CP feasible for real-time or resource-constrained deployment. The theoretical result that calibration-time and test-time robustness both reduce to a single binary certificate is a clean simplification that changes how the problem is structured. Open questions remain: the method still requires ~150 forward passes per input (computationally non-trivial), input-space robustness is not linked to distribution shift, and the graph evaluation uses a transductive setup that prior work (Gosch et al., 2023) has shown to be unrealistic for inductive GNNs.

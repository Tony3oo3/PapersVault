## Problem

Existing parameter-efficient fine-tuning methods like LoRA are designed for 2D linear weight matrices. When applied to higher-dimensional parameter spaces such as 4D convolutional kernels, they flatten the tensor into 2D before applying low-rank adaptation, which severs spatial locality and destroys the structural integrity of the original parameter space. This paper asks whether a unified low-rank representation can be formulated that preserves the topological structure of arbitrary N-dimensional parameter spaces.

## Input / Output

FLoRA takes frozen pre-trained weights of any dimensionality (2D linear matrices or 4D convolutional tensors) and downstream task data, and produces a set of trainable low-rank parameters: a core tensor G of the same dimensionality as the original weight but with reduced sizes along each mode, plus one projection matrix per dimension. The final update is a scaled product s·(G ×₁ A ×₂ B ×₃ C ×₄ D) added to the frozen weights, where the scaling factor s is a per-model hyperparameter (e.g., s=4 for ConvNeXt-V2-L, s=0.4 for DeBERTaV3). The core tensor G is initialized to zero so the initial update is zero, while projection matrices use random Gaussian initialization.

## Method

FLoRA models weight updates via a Tucker-decomposition-like structure: for an N-dimensional weight tensor, it introduces a low-rank core tensor G ∈ R^{J₁×…×Jₙ} (same dimensionality as the original space) and N projection matrices A⁽ⁿ⁾ ∈ R^{Iₙ×Jₙ}, computing ΔW = G ×₁ A⁽¹⁾ ×₂ A⁽²⁾ × … ×ₙ A⁽ⁿ⁾. For 4D convolutional kernels (d_in × d_out × k × k), this yields ΔW = G ×₁ A ×₂ B ×₃ C ×₄ D with G ∈ R^{r₁×r₂×r₃×r₃}, preserving spatial locality within the k×k kernel dimensions. For 2D linear layers, it reduces to ΔW = AGBᵀ where G is an unconstrained r₁×r₂ matrix, in contrast to LoRA's identity G or AdaLoRA's diagonal G. This unconstrained core provides greater expressiveness and, as shown theoretically, makes it easier to reach the global optimum since no implicit constraints are imposed on the projection matrices A and B. The method requires fewer parameters than LoRA for convolutional layers (O(r₃²r² + r(d_in+d_out) + 2r₃k) vs. O(rk(d_in+d_out))) while maintaining or exceeding performance across CV, NLP, and multi-modal benchmarks.

## Results

On ConvNeXt-V2-L fine-tuned for object detection and segmentation, FLoRA achieves 48.1 mAP on COCO and 37.3 mAP on DOTA with 12.77M parameters, outperforming LoRA (47.4/18.3) and DoRA (47.2/19.6) by a wide margin, especially on the domain-shifted DOTA benchmark. On DeBERTaV3-base for GLUE, FLoRA reaches 89.21 average accuracy with 0.33M parameters, surpassing LoRA (87.95) and DoRA (88.31). On InternViT-6B for ADE20K segmentation, FLoRA achieves 71.1 mAcc using only 0.66% of parameters, exceeding fully fine-tuning (70.4 mAcc). On LLaVA-1.5-7B for multi-modal instruction tuning, FLoRA attains 67.8 average across seven benchmarks, edging out DoRA (67.6) and LoRA (66.9).

## Baselines & Comparisons

FLoRA consistently outperforms LoRA and DoRA across all evaluated domains. On the convolutional ConvNeXt-V2-L backbone, the advantage is most dramatic on DOTA (remote sensing), where FLoRA achieves 37.3 mAP versus LoRA's 18.3 and DoRA's 19.6, demonstrating that preserving 4D spatial structure is critical under domain shift. On GLUE (DeBERTaV3-base), FLoRA (89.21 avg) beats LoRA (87.95) and DoRA (88.31) at the same 0.33M parameter budget, and even surpasses AdaLoRA (89.23) at a lower budget. On VTAB-1K (ViT-B/16), FLoRA (77.3 avg) outperforms all CV-specific baselines including AdaptFormer (76.7), FACT-TT (76.7), LoRA (76.4), and NOAH (75.5). On LLaMA3-8B commonsense reasoning, FLoRA (85.6) beats DoRA (85.0), LoRA (82.9), and AdaLoRA (81.4). Notably, on InternViT-6B, FLoRA with only 0.66% trainable parameters (71.1 mAcc) surpasses fully fine-tuning (70.4 mAcc), while on LLaVA-1.5-7B multi-modal tasks FLoRA (67.8) marginally edges out DoRA (67.6) and LoRA (66.9). FLoRA also requires less training time and GPU memory than DoRA (e.g., 77 vs. 100 min/epoch on COCO with ConvNeXt-V2-L) while matching or exceeding LoRA's efficiency.

## Relation to Prior Work

FLoRA extends the low-rank adaptation paradigm introduced by LoRA (Hu et al., 2021) from 2D linear weight matrices to N-dimensional parameter spaces, drawing its mathematical structure directly from Tucker decomposition (Tucker, 1966). The key conceptual departure is that prior methods (LoRA, DoRA, AdaLoRA) either restrict themselves to linear layers or reshape higher-dimensional tensors (e.g., 4D convolution kernels) into 2D matrices, thereby destroying spatial locality and topological structure. FLoRA instead introduces a low-rank core tensor of the same dimensionality as the original parameter space, coupled with per-mode projection matrices, preserving the N-dimensional geometry while still achieving parameter efficiency.

## Why It Matters / Open Questions

The method offers a principled, unified formulation for PEFT across convolutional and linear layers, which is practically important given that many vision foundation models (ConvNeXt, SDXL, InternViT) rely heavily on convolutions. The striking domain-gap result on DOTA (FLoRA ~37 mAP vs. LoRA ~18 mAP) suggests that structural preservation matters most when the downstream task diverges significantly from pre-training data, a regime where current PEFT methods degrade sharply. Open questions include whether the per-backbone scaling factor s can be unified or learned automatically, and whether the Tucker-style core tensor generalizes to other high-dimensional structures (e.g., 3D convolutions, attention tensors). The theoretical argument that an unconstrained core matrix G is easier to optimize than the diagonal/identity patterns in LoRA/AdaLoRA provides a useful lens for future PEFT design.

## Problem

While mechanistic interpretability has made significant progress for text-only LLMs and, to a lesser extent, vision transformers, the inner workings of adapter-style VLMs—where visual and textual tokens coexist in the same LM—remain largely unexplored. Specifically, it is unclear where object-specific information resides within the soft-prompt visual tokens, how these representations evolve across LM layers, and whether the LM extracts visual information through the same refine-then-extract mechanism observed in text-only factual recall.

## Input / Output

The analysis operates on LLaVA 1.5 7B (CLIP ViT-L/14 encoder + Vicuna-13B LM), where each RGB image is cropped to a square, resized, and split into 576 patches that are mapped through a learned adapter into the LM's embedding space as soft-prompt visual tokens. These are concatenated with tokenized text prompts (e.g., 'Describe the image' or 'Is there a [object] in this image?') to form the LM input. Outputs are generated text: free-form descriptions, binary yes/no polling responses, or single-token object identifications prefilled with 'It is a'. The study also extends to LLaVA-Phi-3 and Qwen2-VL-2B for cross-architecture validation.

## Method

The paper applies three complementary interpretability techniques to the LM component of LLaVA. First, mean-ablation experiments replace subsets of visual tokens (object-position tokens, register tokens, random tokens, or integrated-gradient-selected tokens) with a dataset-wide mean embedding, measuring the resulting drop in object identification accuracy across generative, polling, and VQA settings. Second, the logit lens technique is extended to VLMs by projecting each layer's hidden states at visual token positions through the unembedding matrix, revealing that representations progressively align with vocabulary embeddings of the corresponding image content, peaking around layer 25–26 of 33. Third, attention knockout selectively blocks attention from object tokens (or non-object tokens) to the last token position across layer windows, demonstrating that the model directly extracts object-specific information from spatially-localized visual tokens in mid-to-late layers rather than summarizing image content in a dedicated row of visual tokens first.

## Results

Ablating object tokens with a 1-pixel buffer (33.4 tokens avg.) causes a 71.8% drop in generative description accuracy, 51.3% in binary polling, and 86.7% in VQA for LLaVA 1.5, and even larger drops for LLaVA-Phi (82.9%, 86.5%, 96.2%). In contrast, ablating the same number of random tokens (40) causes only 2.4% generative and 0% polling degradation, while integrated gradients at 40 tokens yields 48.7% generative and 35.9% polling drops. Logit lens analysis reveals that 23.7% of object patch token positions decode to the correct object class token at the best-performing layer (avg. layer 25.7/33), and attention knockout from object tokens to the last token position in mid-late layers (L15–24) reduces correct-token probability to 0.80.

## Baselines & Comparisons

This is an interpretability study rather than a method comparison, so the 'baselines' are alternative ablation strategies used to test competing hypotheses about where object information resides. Object token ablation with a 1-buffer (33.4 tokens) causes substantially more degradation than ablating 40 random tokens (2.4% vs. 71.8% generative drop for LLaVA 1.5), ruling out the possibility that any subset of tokens carries the information. It also outperforms integrated gradients at the same token count (48.7% vs. 71.8% generative), showing that spatial correspondence to the object's image location matters more than gradient-based importance scores. Register tokens (3.1 tokens, high-norm background patches) have negligible impact (5.1% generative, 0% polling), directly contradicting the hypothesis that VLMs rely on global register tokens for object identification. Attention knockout further confirms that blocking object-to-last-token attention in mid-late layers (L15–24) drops correct-token probability to 0.80, while blocking visual-to-last-row attention has no measurable effect (1.00 across all layers), contradicting the summarization hypothesis of Basu et al. (2024).

## Relation to Prior Work

This paper extends two mechanistic interpretability techniques from text-only LLMs to the visual token processing in adapter-style VLMs: the logit lens (Nostalgebraist, 2020) for tracking representation evolution across layers, and attention knockout (Geva et al., 2023) for tracing information flow. It positions itself against two competing hypotheses from the vision transformer literature—object-centric localization (Joseph & Nanda, 2024) versus global information in register tokens (Darcet et al., 2024)—and tests them empirically in the VLM setting. The work also engages with Basu et al. (2024), who proposed that VLMs summarize image information in a subset of late visual tokens before using it, a hypothesis this paper's attention blocking experiments directly challenge.

## Why It Matters / Open Questions

The finding that visual token representations in LLaVA's LM evolve toward interpretable vocabulary embeddings—despite the LM never being trained on next-token prediction for visual inputs—suggests that the 'promote concepts in vocabulary space' mechanism (Geva et al., 2022) generalizes beyond text-only pretraining, which has implications for how we think about multimodal representation learning. The localization result (object information concentrated in spatially corresponding tokens, not register tokens) provides a concrete target for hallucination reduction and attention-based interventions. However, the study is limited to object identification tasks and LLaVA-type architectures, leaving open whether these mechanisms hold for multi-step reasoning, more complex VQA, or fundamentally different VLM designs (e.g., native multimodal models without an adapter).

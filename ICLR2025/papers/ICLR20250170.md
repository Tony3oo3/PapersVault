## Problem

Existing data analytics benchmarks evaluate LLM-based agents only on single-step code-completion tasks (e.g., answering a pre-defined query), failing to assess the full end-to-end analytics workflow of formulating questions, interpreting answers, and synthesizing multi-step insights. No standardized, automated benchmark exists for scoring an agent's ability to discover planted insights across descriptive, diagnostic, predictive, and prescriptive categories, and prior end-to-end systems like InsightPilot relied on costly, inconsistent human evaluation.

## Input / Output

Each task provides a 500-row CSV dataset (drawn from ServiceNow enterprise tables across five themes), a SMART goal string, and the extracted schema (column names, types, unique/NA counts, min/max/mean for numerics, top-5 values for categoricals). The agent must produce a structured list of insights—each tagged as descriptive, diagnostic, predictive, or prescriptive—along with a final summary and recommended actions. Evaluation is two-way: a summary-level score compares the agent's summary to the ground-truth summary, and an insight-level score (Eq. 1) matches each ground-truth insight to its best predicted counterpart via LLaMA-3-Eval, then averages over all ground-truth insights.

## Method

InsightBench constructs 100 synthetic datasets by selecting ServiceNow table schemas, embedding systematic trends into controllable columns via mathematical models (e.g., linear TTR = 1 + slope·(date − start)), populating non-controllable columns through random sampling and LLM-generated text, and pairing each dataset with an expert-annotated Jupyter notebook containing sequential questions, code, plots, JSON metadata, and a final insight summary. The proposed AgentPoirot agent extracts the schema, generates k=3 high-level questions via a Question Generation prompt, answers each by generating and executing Python code, then produces n=4 diverse follow-up questions per high-level question (spanning all four insight types) for a total of (n+1)×k insights, and finally summarizes them. For scoring, the paper introduces LLaMA-3-Eval, a G-Eval variant that uses open-source LLaMA-3-70b (temperature 0) as the judge to rate semantic and factual alignment on a 1–10 scale, validated against G-Eval (GPT-4) for consistency. A one-to-many matching strategy is used for insight-level scoring to avoid the mismatches observed with a many-to-many LLM-matching alternative.

## Results

On InsightBench (100 datasets, 475 insights), AgentPoirot with GPT-4o achieves the best LLaMA-3-Eval insight-level score of 0.60±0.03 and summary-level score of 0.44±0.03, outperforming Pandas Agent with GPT-4o (0.54±0.01 and 0.40±0.04 respectively). Among open-source models, AgentPoirot with LLaMA-3-70b reaches 0.52±0.04 insight-level LLaMA-3-Eval, approaching GPT-4-turbo (0.56±0.02) while significantly outperforming GPT-3.5-turbo (0.50±0.02). Using a generic goal instead of a SMART goal causes a dramatic drop (e.g., GPT-4o insight-level LLaMA-3-Eval falls from 0.60 to 0.40), highlighting the importance of well-specified analytical objectives.

## Baselines & Comparisons

AgentPoirot outperforms Pandas Agent (the primary baseline) on the LLaMA-3-Eval metric across all backbone models: with GPT-4o, AgentPoirot scores 0.60 vs. 0.54 at the insight level and 0.44 vs. 0.40 at the summary level. However, Pandas Agent slightly edges out AgentPoirot on ROUGE-1 (0.35 vs. 0.32 insight-level with GPT-4o), suggesting that while AgentPoirot generates more semantically aligned insights, Pandas Agent produces text with marginally better surface-level overlap. Among LLM backbones, GPT-4o consistently yields the highest scores, LLaMA-3-70b is competitive (within ~0.04 of GPT-4-turbo on LLaMA-3-Eval), and GPT-3.5-turbo lags behind. The paper also notes that AgentPoirot with LLaMA-3-70b underperforms on combined multi-table datasets due to context window limitations, whereas Pandas Agent handles those cases better. Qualitative comparisons (Table 5) show AgentPoirot produces more targeted, to-the-point insights, while Pandas Agent tends to generate related but slightly off-topic observations.

## Relation to Prior Work

This paper extends the 'Capture the Flag' insight-planting paradigm from Laradji et al. (2023) and the end-to-end analytics agent concept from InsightPilot (Ma et al., 2023) into a standardized, automated benchmark. It departs from existing data science benchmarks (DS-1000, InfiAgent-DABench, DSP) that evaluate single-step code generation or single-query answering, instead formulating evaluation around multi-step insight generation spanning descriptive, diagnostic, predictive, and prescriptive analytics. The evaluation methodology directly builds on G-Eval (Liu et al., 2023) by substituting LLaMA-3-70b for GPT-4, creating an open-source, reproducible alternative (LLaMA-3-Eval) that the authors validate produces consistent rankings.

## Why It Matters / Open Questions

InsightBench fills a notable gap by providing the first standardized benchmark for evaluating LLM agents on complete, multi-step data analytics workflows rather than isolated code-completion tasks, making it a practical testbed for the growing field of automated data science agents. The LLaMA-3-Eval metric offers a cost-effective, stable open-source alternative to GPT-4-based evaluation, which is practically important for reproducibility. Key limitations include reliance on synthetic ServiceNow-derived data that may not capture the full complexity of real enterprise data, a modest 100-dataset scale, and the inherent circularity of using LLMs to evaluate LLM-generated insights. Open questions include whether the benchmark generalizes to unstructured data (logs, emails, visual charts), whether the planted-insight paradigm transfers to genuinely novel patterns, and how agents perform when goals are ambiguous or multi-objective.

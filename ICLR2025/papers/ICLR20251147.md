## Problem

Existing pruning methods for text-to-image diffusion models are either static (applying the same pruned architecture to all prompts regardless of their complexity) or dynamic (assigning a unique sub-network per prompt, which prevents GPU batch parallelism). This paper addresses the gap by asking whether a single model can be pruned into a small set of specialized experts, with a learned router that allocates compute to each prompt based on its individual difficulty while preserving batch-parallelizability.

## Input / Output

The method takes a free-form text prompt as input, which is encoded by a frozen Sentence Transformer into a 768-dim embedding. The prompt router maps this to one of N architecture codes (N is a hyperparameter, e.g., 8 or 16), each defining a pruned U-Net sub-network (expert) with a specific width/depth configuration. The selected expert generates a 768×768 image via 25-step PNDM sampling with classifier-free guidance (scale 7.5), which is downsampled to 256×256 for metric computation. The total compute budget across all experts is constrained to a target MACs ratio (e.g., 0.85× the original SD 2.1).

## Method

APTP prunes a pretrained T2I diffusion model (SD 2.1) into a Mixture of Experts by jointly training a prompt router and a set of learnable architecture codes. The router comprises a frozen Sentence Transformer encoder, a single feedforward architecture predictor, and a router module that uses entropy-regularized optimal transport (solved via Sinkhorn-Knopp with an equipartition constraint) to evenly distribute batch prompts across codes during training, preventing code collapse. Architecture codes are continuous vectors decoded through Gumbel-Sigmoid reparameterization into soft binary masks that differentially prune ResBlock channels, attention heads, and entire depth layers. Training combines the DDPM denoising loss, output- and block-level distillation from the full model, a resource-usage regularizer, and a contrastive objective that pulls architecture embeddings of semantically similar prompts together while pushing dissimilar ones apart. At inference, the router simply selects the architecture code with highest cosine similarity to the prompt's architecture embedding, and the corresponding expert generates the image.

## Results

On CC3M, APTP-Base (0.85 MACs budget, 16 experts) achieves FID 36.77, CLIP 30.84, and CMMD 0.675 at 1182.8G MACs (3.4s latency), approaching the full SD 2.1 model (FID 32.08, CLIP 31.12) while using 15% less latency. On MS-COCO, APTP-Base (0.78 budget, 8 experts) reaches FID 22.60 and CLIP 31.32 at 1076.6G MACs, essentially matching SD 2.1's CLIP score (31.33) while reducing latency by 22.5%. The smaller APTP configurations (0.66 on CC3M, 0.64 on COCO) achieve 21–23% lower MACs and ~20% less latency than all static baselines while still outperforming them on every metric.

## Baselines & Comparisons

APTP outperforms all three static pruning baselines on every metric across both datasets. On CC3M at comparable MACs (~1180G), APTP-Base achieves FID 36.77 versus 75.81 (SP), 87.27 (BKSDM), and 141.04 (Norm pruning), with CLIP 30.84 vs. 26.51–26.83. On MS-COCO, APTP-Base (FID 22.60, CLIP 31.32) beats BKSDM (FID 26.31, CLIP 28.89) by 3.71 FID and 2.43 CLIP, and SP (FID 53.09, CLIP 28.98) by 30.49 FID. Even at a tighter budget (0.66/0.64), APTP surpasses the static baselines while using 21–23% fewer MACs. Compared to the unpruned SD 2.1 reference, APTP-Base on COCO matches its CLIP score (31.32 vs. 31.33) and achieves a CMMD within 0.069, at 22.5% lower latency; on CC3M the FID gap is 4.69 (36.77 vs. 32.08) at 15% less latency. The ablation (Table 3) further confirms that optimal transport is critical: without it, the contrastive-only router collapses to a single expert and performs worse than the single-model baseline.

## Relation to Prior Work

This paper departs from the static pruning paradigm for T2I diffusion models (SPDM, BK-SDM) by introducing prompt-based routing that allocates different sub-network capacities to different prompts, while avoiding the batch-parallelism loss of fully dynamic pruning. Technically, it combines Gumbel-Sigmoid reparameterization for differentiable architecture search, entropy-regularized optimal transport with equipartition constraints (borrowed from SwAV-style clustering) for balanced expert assignment, and contrastive learning to preserve semantic structure in the routing space. The distillation objective is adapted from BK-SDM, and the overall framing mirrors the practical workflow of fine-tuning a pretrained T2I model on a target dataset before deployment.

## Why It Matters / Open Questions

APTP offers a practical path for resource-constrained organizations to deploy T2I models by automatically allocating compute based on prompt complexity, achieving substantial FID/CLIP/CMMD gains over static pruning at equivalent or lower MACs budgets. The emergent ability of the prompt router to identify known-hard prompt categories (text rendering, humans, fingers) and route them to higher-capacity experts without explicit supervision is a useful diagnostic tool. However, evaluation is limited to SD 2.1 on CC3M and MS-COCO, and the method still inherits SD's weaknesses on those categories; generalization to other backbones, resolutions, and task distributions remains open.

## Problem

Existing graph prompt tuning methods design learnable prompts on node features, ignoring the structural dependencies carried by edges. This causes node-level prompts to be uniformly propagated to all neighbors during message passing, preventing the model from capturing complex inter-node relationships and limiting downstream task performance. No prior work has exploited edges as the locus for prompt design in GNNs.
![Teaser figure](../imgs/ICLR20253160/cropped_page3_idx1.webp)

## Input / Output

The method takes a frozen pre-trained GNN (e.g., 2-layer GCN for node classification, 5-layer GIN for graph classification) and an input graph with node features and adjacency matrix. It produces node or graph representations by injecting learned edge prompt vectors into the message-passing aggregation at every GNN layer, which are then fed to a linear classifier. A key design constraint is compatibility with GNNs that do not natively support edge attributes (e.g., GCN), achieved by aggregating prompts alongside node representations rather than as separate edge features.

## Method

EdgePrompt learns a single shared prompt vector per GNN layer for all edges, which is aggregated together with neighbor node representations during the AGG operation of message passing. EdgePrompt+ generalizes this by learning M anchor prompts per layer and computing each edge's prompt as a softmax-weighted combination of anchors, where the weights are produced by a GAT-style attention function over the two endpoint nodes' representations. This allows each edge to carry a customized prompt, so a node's different neighbors receive different prompt information rather than a uniform copy. Theoretical analysis under the contextual stochastic block model proves that edge prompts can increase the expected inter-class centroid distance by up to T ∈ (1, 1+p/|p−q|] times, improving linear separability. A universality theorem further shows that for any graph transformation, there exist edge prompts that reproduce the same GNN output, establishing equivalence with node-level prompt strategies.

## Results

On 5-shot node classification across five datasets (Cora, CiteSeer, Pubmed, ogbn-arxiv, Flickr) under four pre-training strategies, EdgePrompt+ consistently achieves the best accuracy, e.g., 62.88% on Cora and 46.20% on CiteSeer with GraphCL pre-training, outperforming the strongest baseline GPF (58.52% and 43.55% respectively). On 50-shot graph classification across five TUDataset benchmarks, EdgePrompt+ attains the best or runner-up accuracy in every setting, e.g., 34.00% on ENZYMES and 66.52% on NCI109 with GraphCL pre-training. The simpler EdgePrompt variant shows performance gaps of less than 1.8% versus GPF, consistent with the theoretical equivalence established in Theorem 2.

## Baselines & Comparisons

EdgePrompt+ outperforms all six baselines on node classification across all four pre-training strategies and five datasets. Against GPF (the strongest node-level prompt baseline), EdgePrompt+ gains approximately 4.4 points on Cora (62.88 vs. 58.52) and 2.7 points on CiteSeer (46.20 vs. 43.55) under GraphCL, with similar margins under other strategies. GPF-plus, which adds node-level prompts at multiple layers, is consistently weaker than GPF in this setting, suggesting that node-level prompts do not scale well. GPPT, designed specifically for node classification via link-prediction reformulation, underperforms even the Classifier Only baseline on several datasets (e.g., 50.96 vs. 53.05 on Cora with GraphCL), highlighting the fragility of task-specific prompt designs. All-in-one is the weakest baseline overall, often falling 10+ points below EdgePrompt+. On graph classification, EdgePrompt+ achieves the best accuracy in 18 out of 20 settings (4 strategies × 5 datasets), with the closest competitor being GPF-plus; the gap between EdgePrompt and GPF remains under 1.8%, empirically confirming the theoretical universality claim of Theorem 2.

## Relation to Prior Work

This paper extends the graph prompt tuning paradigm (GPPT, GraphPrompt, All-in-one, GPF/GPF-plus) by shifting prompt insertion from node features to edges, drawing an analogy to pixel-level visual prompts in computer vision. The authors explicitly show that GPF-plus is a special case of EdgePrompt+ (with a linear score function), positioning their method as a strict generalization. The theoretical analysis builds on the Contextual Stochastic Block Model (CSBM) framework and the message-passing formalism of GNNs, while the universality guarantee (Theorem 2) leverages the equivalence result from GPF (Fang et al., 2023).

## Why It Matters / Open Questions

The paper identifies a concrete structural blind spot in existing graph prompt tuning—node-level prompts propagate uniformly to all neighbors, potentially injecting adverse cross-class information—and provides both a theoretical bound (Theorem 1) and empirical evidence that edge-level prompts mitigate this. Practical impact is moderate: the method is simple, compatible with frozen pre-trained GNNs that lack edge-attribute support, and adds minimal computational overhead. Open questions include whether the approach extends to heterogeneous graphs, whether richer score functions beyond the fixed attention mechanism yield further gains, and whether the benefits persist under more diverse pre-training objectives (DGI, GraphMAE) that the authors leave for future work.

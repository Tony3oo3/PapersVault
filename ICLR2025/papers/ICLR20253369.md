## Problem

A single rank-r LoRA module often lacks sufficient representational capacity for complex tasks, while simply scaling to rank Kr introduces overfitting risk and does not consistently improve performance in practice. No prior work has explored competitive learning mechanisms within LoRA or other PEFT methods to dynamically exploit multiple low-rank components during training without increasing inference cost.
![Teaser figure](../imgs/ICLR20253369/cropped_page2_idx0.webp)

## Input / Output

The method takes a text prompt (input sequence of length L with d-dimensional token embeddings) and produces generated text via the base LLM (LLaMA-3-8B). During training, the input is additionally processed by a lightweight one-layer transformer encoder to produce a fixed-length contextualized representation (mean-pooled hidden states) used by the LoRA selector. At inference, only the single winning LoRA component is active and can be merged into the base model, so the I/O pipeline is identical to standard LoRA with no extra selector or routing overhead.

## Method

ComLoRA initializes K distinct LoRA components (each with rank r, using Kaiming init for A and zero init for B) and introduces a LoRA selector that computes dot-product similarity scores between a mean-pooled input representation and K learnable embedding vectors. Training optimizes three losses jointly: (1) an averaged language modeling loss across all K components, (2) an alignment loss that weights LM updates by the selector's top-N normalized similarity scores with an annealing schedule (exponential by default) to gradually increase selector influence, and (3) a pairwise loss that trains the selector to rank components by their noisy LM losses using log-softmax differences with an ℓ₁ norm. After training, the winner is determined by accumulating validation similarity scores, and only that single LoRA component is retained for inference, preserving the same computational footprint as a standard rank-r LoRA.

## Results

On the 8-task commonsense reasoning benchmark, ComLoRA_{K=2,r=8} achieves the highest average accuracy of 87.09%, surpassing the strongest LoRA baseline (LoRA_{r=128} at 84.88%) by 2.21 points while using only rank-8 components. On MMLU, ComLoRA_{K=4,r=32} reaches 61.09% accuracy versus 59.36% for LoRA_{r=128}. On CONVAI2 personalized dialogue, ComLoRA_{K=2,r=8} attains a BLEU of 3.69 and METEOR of 17.05, outperforming all LoRA variants (best LoRA: BLEU 3.27, METEOR 15.24 at r=128).

## Baselines & Comparisons

The sole baseline family is standard LoRA at ranks 4, 8, 16, 32, and 128. ComLoRA wins on every task and every benchmark: on commonsense reasoning, ComLoRA_{K=2,r=8} (87.09% avg) beats the best LoRA (r=128, 84.88%) by 2.21 points, and even the lowest-rank ComLoRA config (K=4, r=4, 83.56%) exceeds LoRA_{r=32} (80.79%) by 2.77 points. On MMLU, ComLoRA_{K=4,r=32} (61.09%) outperforms LoRA_{r=128} (59.36%) by 1.73 points, and ComLoRA_{K=2,r=8} (59.81%) already surpasses LoRA_{r=128} by 0.45 points. On CONVAI2, ComLoRA_{K=2,r=8} leads all LoRA variants on every metric (BLEU 3.69 vs. 3.27, METEOR 17.05 vs. 15.24, ROUGE-L 16.09 vs. 14.06). Notably, ComLoRA achieves these gains with fewer trainable LoRA parameters (e.g., 0.35% for K=2,r=8 vs. 2.74% for LoRA r=128), and at inference time only a single rank-r LoRA is used, so there is zero additional inference overhead compared to standard LoRA.

## Relation to Prior Work

ComLoRA extends LoRA (Hu et al., 2021) by initializing K independent rank-r LoRA components and training them under a competitive learning objective inspired by classical competitive learning in feature discovery (Rumelhart & Zipser, 1985; Grossberg, 1987). It explicitly differentiates itself from MoE-of-LoRA approaches (e.g., MoELoRA, Luo et al., 2024) by discarding all but the single best LoRA at inference, thereby preserving LoRA's zero-overhead deployment. The method also responds to empirical observations that simply increasing LoRA rank does not monotonically improve performance (Kalajdzievski, 2023; Sidahmed et al., 2024), proposing competition as an alternative to raw capacity scaling.

## Why It Matters / Open Questions

ComLoRA offers a practical recipe to approach rank-Kr LoRA performance while retaining rank-r inference cost, which is attractive for deployment-constrained settings. However, the evaluation is limited to a single model (LLaMA-3-8B) and three task suites, and the selector itself introduces ~1.45% trainable parameters—exceeding the LoRA components in the K=2,r=8 configuration—so the net parameter-efficiency gain is modest. Open questions include whether the competitive mechanism generalizes to other PEFT methods (e.g., adapters, prefix tuning), whether it scales to larger models or longer training, and whether the K=2 optimum observed here holds across architectures and task distributions.

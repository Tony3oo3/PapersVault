## Problem

Mode connectivity in deep neural networks has been extensively studied in parameter space, where different SGD solutions are linked by low-loss paths, but whether an analogous phenomenon exists in input space—where the model is fixed and data varies—remains unexplored. The paper asks whether inputs with similar predictions are connected by low-loss paths, whether this connectivity is a geometric property of high-dimensional spaces (present even in untrained networks), and how differences in connectivity structure between natural and adversarial inputs can be exploited for detection.

## Input / Output

The method consumes pairs of RGB images (224×224 for ImageNet models, 32×32 for CIFAR models) that share a similar model prediction, along with a fixed pretrained network. For the adversarial detection application, each test image is paired with a preselected low-loss reference image from its predicted class. The primary output is a loss curve sampled along the linear interpolation path between the two inputs, plus an optimized connected path (A→B'→C) that bypasses the loss barrier. For detection, the loss curve is concatenated with sorted logits to form a feature vector fed to a KNN classifier that outputs a natural/adversarial label.

## Method

The core procedure linearly interpolates between two input modes (images minimizing cross-entropy for the same class), identifies the maximum-loss intermediate point B, and optimizes B to B' via Feature Visualization by Optimization (FVO) constrained to the orthogonal hyperplane of vector AC, using Adam with MSE deviation and high-frequency regularization penalties. The resulting piecewise-linear path A→B'→C exhibits low loss throughout, with secondary barriers bypassed by iterative re-optimization. For adversarial detection, loss curves from linear interpolation between each test image and its class reference are concatenated with sorted logits and classified by a KNN trained jointly across all attack types. Theoretically, the paper conjectures that input-space connectivity is a high-dimensional percolation effect: by Lipschitz continuity, the input space can be partitioned into ε-hypercubes whose outputs fall into overlapping intervals, and connectivity between same-prediction inputs reduces to a percolation problem where the connection probability grows as 1−O(e^{−d_X·δ}) with dimension.

## Results

On the adversarial detection benchmark (VGG-16, CIFAR-10/100), the mode connectivity method achieves 93.7% accuracy / 98.3% AUC on C&W attacks (CIFAR-10) and 92.9% / 97.3% (CIFAR-100), outperforming all baselines on this most challenging attack. For Deepfool, it reaches 91.4% / 96.9% on CIFAR-10 (vs. best baseline LayerPFS at 86.1% / 92.2%) and 86.8% / 94.0% on CIFAR-100. On simpler attacks (FGSM, BIM, PGD), the method underperforms baselines (e.g., 69.8% vs. 99.6% on FGSM/CIFAR-10), which the authors attribute to the less pronounced loss barriers produced by untargeted attacks that do not minimize loss for a specific incorrect class.

## Baselines & Comparisons

The paper compares against five baselines from the Harder et al. (2021) benchmark (LID, Mahalanobis, InputMFS, LayerMFS, LayerPFS) on VGG-16 with CIFAR-10/100. The mode connectivity method clearly wins on C&W attacks, achieving 93.7%/98.3% (CIFAR-10) and 92.9%/97.3% (CIFAR-100) versus the next-best Mahalanobis at 76.9%/84.6% and 89.0%/94.7% respectively — a gap of 16.8 and 3.9 percentage points in accuracy. On Deepfool, it wins on CIFAR-10 (91.4% vs. LayerPFS 86.1%) but is slightly behind Mahalanobis on CIFAR-100 (86.8% vs. 89.2%). On simpler attacks (FGSM, BIM, PGD), the method substantially underperforms: e.g., 69.8% vs. LayerMFS 99.6% on FGSM/CIFAR-10. The authors explain this trade-off by noting that simpler untargeted attacks maximize loss for the true class without targeting a specific incorrect class, producing less distinct loss barriers that their detection signal relies on. Notably, the method uses a single KNN classifier optimized jointly across all attacks and does not require access to intermediate feature maps, unlike the best-performing baseline LayerMFS.

## Relation to Prior Work

This paper extends the mode connectivity framework from parameter space (Garipov et al., 2018; Draxler et al., 2018) to the input space of vision DNNs, inverting the original setup from fixed-data/variable-parameters to fixed-model/variable-data. It adapts the barrier-bypassing optimization procedure from Fort & Jastrzebski (2019) and leverages feature visualization by optimization (Olah et al., 2017) to generate diverse synthetic inputs. The closest prior work, Balasubramanian et al. (2023), studied input-space connectivity only for a narrow class of invariance-based adversarial examples (blind spots), whereas this paper demonstrates connectivity for arbitrary input pairs with similar predictions, including in untrained networks, and provides a percolation-theoretic explanation.

## Why It Matters / Open Questions

The conjecture that input-space mode connectivity is a high-dimensional geometric phenomenon (explainable via percolation theory) and present even in untrained networks, if proven, would fundamentally reframe mode connectivity as an intrinsic property of high-dimensional function spaces rather than a training artifact. Practically, the barrier-height distinction between real-real and real-adversarial pairs yields a detection method that outperforms baselines for advanced attacks (DeepFool, C&W), though it underperforms on simpler attacks and has not been tested against adaptive attacks. Key open questions include formalizing the percolation argument (the independence assumption is acknowledged as unrealistic), understanding the implicit regularization mechanism behind path simplicity in trained networks, and generalizing beyond vision to other modalities.

## Problem

Achieving top performance from GNNs on complex tasks (large graphs, long-range graphs) requires extensive hyperparameter tuning over large search spaces, incurring high computational and time costs—sometimes over 20× tuning time for less than 1% accuracy gain. Additionally, the intrinsic relationship between graph data characteristics and network parameters remains underexplored in prior parameter generation work, which typically uses unconditional or dataset-level conditions without leveraging structural information.

## Input / Output

The method takes graph node features X, adjacency matrix A, train/validation labels, and vectorized model checkpoints collected from a coarse search (only 10% of the full grid search space) as input. It produces generated last-layer GNN parameters (partial generation only, since earlier layers handle feature extraction while the last layer is task-specific), from which 100 samples are drawn and the best validation-performing sample is selected for final test evaluation. The graph condition is a fixed-size vector obtained by mean-pooling node representations, making the method agnostic to graph size.

## Method

GNN-Diff is a graph-conditioned latent diffusion framework with three trainable components: a Parameter Autoencoder (PAE) that compresses vectorized GNN parameters into a low-dimensional latent space via Conv1d encoder-decoder blocks, a Graph Feature Encoder (GFE) that encodes graph data and structure into a condition vector (e.g., Concat(A²XW₁, AXW₂, XW₃)W₄ for basic node classification, combining multi-hop and identity pathways to handle both homophilic and heterophilic graphs), and a Graph-conditioned Latent DDPM (G-LDM) that denoises in the latent space with the graph condition added to each encoder/decoder block. The key insight is that high-quality parameters exist within the population produced by a sub-optimal but sufficiently good hyperparameter configuration found by a lightweight coarse search, and the diffusion model learns this population to generate parameters that surpass even the best input samples. No additional hyperparameter tuning is required for the generation process itself—the only tuning cost is the coarse search, and the PAE kernel size/stride is set by a simple rule based on parameter dimension.

## Results

Across 166 experiments on 4 graph tasks, 10 target models, and 20 datasets, GNN-Diff achieves the best average test accuracy in 36 out of 40 basic node classification experiments (Table 1), e.g., GCN on Cora reaches 82.33% vs. 82.04% (grid) and 81.89% (coarse search), while GCN on Actor reaches 31.24% vs. 30.94% (grid). A standout advantage is stability: GNN-Diff's standard deviation is typically 3–10× lower than grid search (e.g., 0.17 vs. 0.96 for GCN on Cora), indicating more reliable generalization. On large graphs (Table 2), GNN-Diff consistently achieves top accuracy (e.g., SAGE on OGB-Products: 76.52% vs. 75.68% grid), and on long-range graphs (Table 3) it produces the best F1-scores for most model–dataset pairs (e.g., SAGE on PascalVOC-SP: 28.24 vs. 27.98 grid).

## Baselines & Comparisons

GNN-Diff is compared against four search-based baselines: grid search (full space), random search (20% space), coarse search (10% space), and coarse-to-fine (C2F) search. Against grid search, GNN-Diff matches or slightly exceeds the best accuracy in 36/40 basic node classification experiments and all large-graph experiments, while reducing the required search space to 10% and eliminating the risk of validation-set overfitting observed with exhaustive grid search. Against random search, GNN-Diff consistently wins by 0.3–1.5% accuracy across models and datasets. Against coarse search (its own starting point), GNN-Diff provides a clear boost of 0.2–1.0% accuracy, confirming that the diffusion model explores beyond the sub-optimal checkpoint population. Against C2F, GNN-Diff outperforms on most model–dataset pairs (e.g., GCN on Cora: 82.33% vs. 81.99%; APPNP on Actor: 35.92% vs. 35.53%) and exhibits substantially lower variance. The one notable exception is link prediction on Chameleon, where random search edges out GNN-Diff, though GNN-Diff still improves over coarse search more than C2F does.

## Relation to Prior Work

This paper extends the neural network parameter generation line of work, most directly building on p-diff (Wang et al., 2024), which uses an unconditional latent diffusion model to generate GNN parameters from training checkpoints. The key departure is the introduction of a graph feature encoder (GFE) that conditions the diffusion process on graph structure and node features, moving from unconditional to graph-conditioned generation. The coarse-search-then-generate pipeline also draws on coarse-to-fine optimization ideas (Moshkelgosha et al., 2017; Payrosangari et al., 2020), but replaces the fine-tuning stage with a learned generative model rather than additional search.

## Why It Matters / Open Questions

GNN-Diff offers a practical efficiency gain: replacing ~90% of hyperparameter search with a one-time diffusion model training, which is particularly valuable for large and long-range graphs where tuning is most expensive. However, the performance improvements over full grid search are modest (typically 0.1–1%), and the method still requires a coarse search upfront plus training of three components (GFE, PAE, G-LDM). Open questions include whether the approach generalizes to full-parameter generation, whether it can be combined with large-scale training algorithms like Cluster-GCN or GraphSAINT, and whether the graph condition provides meaningful gains beyond what a well-tuned unconditional model achieves.

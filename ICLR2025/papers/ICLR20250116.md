## Problem

Existing controllable CAD generation methods (SkexGen, Hnc-cad) offer limited controllability restricted to specific hierarchies and require separate models for different types of control, making them inefficient and impractical for real-world design workflows where users need to modify arbitrary parts of a model at any construction level. No prior work achieves unified controllability across all CAD construction hierarchies (sketch-extrusion, extrusion, sketch, face, loop, and curve) within a single model.

## Input / Output

The input is an original CAD model converted into a structured text where curve types (line, arc, circle) appear as text tokens, point coordinates are expressed as decimal integers (e.g., (31,31) rather than SkexGen's binary one-hot vectors), and special tokens like <curve_end>, <loop_end>, <face_end> mark hierarchy boundaries. A hierarchy-specific mask token (e.g., [sketch mask], [face mask], [line mask]) replaces the user-specified region to modify. The output is one or more complete CAD texts that, after infilling the masked field, can be rendered into valid 3D CAD models with only the targeted part altered while all other elements remain unchanged.

## Method

FlexCAD fine-tunes Llama-3-8B via LoRA (only 0.042% of parameters, ~3.4M trainable) using a hierarchy-aware masking strategy. During training, a hierarchy-aware field in the CAD text is replaced with a hierarchy-specific mask token, and seven prompt templates (one per hierarchy level) are uniformly sampled at each epoch so that all controllable generation tasks are learned in a single unified model. The key design insight is that mask tokens are tailored to each hierarchy (e.g., [sketch-extrusion mask], [face mask], [loop mask], [line mask], [arc mask]), enabling the LLM to determine the generation level from the token itself. At inference, the user places a mask token at the desired modification site, and the fine-tuned LLM autoregressively predicts the masked field, producing diverse valid CAD texts. This end-to-end approach eliminates the multi-stage training required by prior methods and supports flexible inference patterns (e.g., masking a single loop within a face even though training masks all loops simultaneously).

## Results

On the DeepCAD test set, FlexCAD (Llama-3-8B + LoRA) achieves the best performance on nearly all metrics for both sketch-level and extrusion-level controllable generation. The most striking gain is in Prediction Validity (PV), reaching 93.4% (sketch) and 93.3% (extrusion) versus 72.6% and 79.7% for the strongest baseline Hnc-cad. FlexCAD also leads on JSD (0.82 vs 1.07 sketch-level), COV (65.6% vs 62.4%), and human-evaluated Realism (39.6% vs 36.3% sketch-level; 42.1% vs 38.0% extrusion-level). GPT-4o with few-shot in-context learning but no fine-tuning performs substantially worse across all metrics (e.g., PV 62.3% sketch, 48.8% extrusion).

## Baselines & Comparisons

FlexCAD outperforms all three baselines on nearly every metric. Against Hnc-cad (the strongest prior SEM-based method), FlexCAD improves PV by 20.8 points at the sketch level (93.4% vs 72.6%) and 13.6 points at the extrusion level (93.3% vs 79.7%), while also achieving lower JSD (0.82 vs 1.07) and higher COV (65.6% vs 62.4%). Against SkexGen, the gap is even larger on PV (93.4% vs 68.7% sketch; 93.3% vs 76.1% extrusion), and SkexGen additionally cannot specify which sketch or extrusion to modify when multiple exist. GPT-4o with five-shot in-context learning but no fine-tuning trails significantly on all metrics (e.g., PV 62.3% sketch, 48.8% extrusion; Realism 23.2% and 19.7%), confirming that domain-specific fine-tuning is essential. Qualitatively, FlexCAD preserves unmasked elements while editing only the targeted hierarchy, whereas Hnc-cad sometimes alters unmasked fields and SkexGen modifies all sketches/extrusions simultaneously.

## Relation to Prior Work

This paper departs from the dedicated-architecture line of SEM-based CAD generation (DeepCAD, SkexGen, Hnc-cad), which relied on separate transformer or VQ-VAE models per hierarchy level and used one-hot or binary token representations. Instead, it repurposes the masked-language-modeling paradigm from NLP by fine-tuning a pre-trained LLM (Llama-3-8B via LoRA) on a concise structured-text representation of CAD models, unifying all hierarchy-level controllable generation tasks into a single model through hierarchy-aware masking. The conceptual inspiration draws from recent work applying fine-tuned LLMs to other structured-sequence domains (human motion, crystal synthesis), but the CAD-specific text encoding and masking strategy are novel.

## Why It Matters / Open Questions

FlexCAD demonstrates that a single, parameter-efficiently fine-tuned LLM can handle controllable CAD generation across all construction hierarchies (sketch-extrusion through curve), eliminating the need for separate models per control type that prior work required. The substantial PV gains (up to ~31% over baselines) suggest that pre-trained LLMs encode useful geometric/structural priors for CAD. However, limitations remain: inference is ~3–4× slower than dedicated baselines, hallucinations occur on data-imbalanced curve configurations (e.g., 5–8 line loops), and the evaluation is confined to a single dataset (DeepCAD). Open questions include whether this paradigm extends to natural-language-to-CAD generation and whether the approach scales to more complex or industrial CAD models.

## Problem

High-throughput screening in drug discovery requires expensive experiments on every compound in a library, yet many of these experiments are redundant because a predictive model could handle the easier cases. Standard active learning evaluates success via generalization error on a held-out test set, which dramatically understates the benefit of selective acquisition when the goal is accurate prediction on a fixed, finite target set. This paper formalizes the gap as a sequential subset selection problem and identifies the mechanism of inference set design, where the learner strategically removes hard examples from its own evaluation set.

## Input / Output

The method takes a finite target set of experimental designs (e.g., a compound library of 10^5–10^6 molecules) with vectorized representations (ECFPs for molecular structures, MolGPS embeddings for phenomics, raw pixels for MNIST) and a target accuracy threshold γ. At each acquisition round, the model's per-sample confidence scores over the shrinking inference set drive batch selection. The output is a complete hybrid label set for the entire target set—observed experimental readouts for acquired samples plus model predictions for the remainder—along with a certified stopping time τ that guarantees system accuracy exceeds γ with probability at least 1−δ.

## Method

The core mechanism is inference set design: a least-confidence (or BALD/QBC) acquisition function iteratively selects the N_b samples the model is least confident about, acquires their true labels, and removes them from the inference set, progressively leaving only easy-to-predict examples for the model to handle at inference time. The predictor is a feedforward deep network with residual connections (ResMLP) retrained from scratch each round on the growing observation set. A key theoretical result (Lemma 1) proves that under weak calibration of the model's top-predictions, the measured accuracy on the acquired batch lower-bounds the true accuracy on the remaining inference set, enabling a conservative stopping criterion. This criterion uses a Chernoff–KL concentration bound on the batch accuracy to compute a probabilistic lower bound α_t on inference-set accuracy, and halts acquisition once the estimated system accuracy (|X_obs| + α_t·|X_inf|)/|X_target| exceeds the target threshold γ, providing a (1−δ) guarantee without needing to observe the remaining labels.

## Results

On QM9, both the least-confidence (LC) and BALD agents reach near 100% system and inference-set accuracy after acquiring only ~30% of the data, while random and heuristic baselines remain significantly lower. On the Molecules3D regression task, query-by-committee (QBC) achieves approximately 5× lower MSE than random or heuristic orderings, satisfying the stopping criterion after acquiring ~80% of the data. On MNIST with shuffled labels for 80% of digits, the LC agent still achieves 100% inference-set accuracy. On the proprietary phenomics dataset (102,855 compounds × 5,580 genes), the LC agent reaches the 98% target system accuracy at approximately 80% of the acquisition procedure, outperforming all baselines.

## Baselines & Comparisons

On QM9, BALD (Gal et al., 2017) performs comparably to the paper's primary least-confidence (LC) agent, with both reaching near 100% inference-set and system accuracy after ~30% acquisition, and both substantially outperforming random sampling and heuristic orderings (molecule size, SA-score, diversity/Tanimoto). The paper's key finding is that the inference-set-design mechanism — not the specific acquisition function — drives the gains: even when generalization (test-set) accuracy saturates identically for all agents, the LC and BALD agents still achieve large inference-set improvements by pruning hard examples. On Molecules3D, QBC (an ensemble-variance acquisition function) similarly outperforms random and heuristic baselines by ~5× in MSE, confirming the mechanism generalizes beyond confidence-based selection. On RxRx3, all agents (including BALD) show only minor improvements over random, which the authors attribute to the extreme difficulty of the biological prediction task in a low-data regime rather than a failure of the acquisition strategy.

## Relation to Prior Work

This paper builds on pool-based active learning and transductive experimental design but reframes the objective: rather than minimizing generalization error on a held-out test set, it targets performance on a fixed, finite experimental set where the learner can influence its own evaluation set through selective acquisition. The key conceptual departure from prior AL work is the explicit identification of 'inference set design' as the dominant mechanism — the learner prunes hard examples from the inference set rather than improving generalization. The stopping criterion draws on the Chernoff bound (Chernoff, 1952) and its KL-divergence formulation (Lattimore & Szepesvári, 2020), adapted to the biased (but conservative) estimator that arises from confidence-based batch selection, formalized in Lemma 1.

## Why It Matters / Open Questions

The practical impact is significant for drug discovery: the method reduces experimental costs by 20–70% while maintaining target accuracy, validated on both academic benchmarks and a real-world phenomics assay. The broader conceptual contribution — that standard generalization-based evaluation dramatically understates active learning's value in hybrid screen settings — could reshape how AL is assessed in any finite-pool application. Key limitations include the assumption of deterministic labels (noisy biological readouts are not modeled) and the requirement of weak calibration, which, while empirically validated, may not hold for all model classes. Open questions include combining the framework with aleatoric uncertainty for weak supervision and extending to multi-objective or sequential experimental designs.

## Problem

Existing LLM unlearning methods either require retraining sub-models (exact unlearning, e.g., SISA, APA) which destroys the original model architecture, or rely on approximate fine-tuning (e.g., gradient ascent, E2URec) that only handles data removal and cannot correct biased or inaccurate data. No unified framework efficiently addresses the full spectrum of instance-wise unlearning tasks—instance removal, query modification, and response correction—within the PEFT/LoRA paradigm without incurring retraining costs.
![Teaser figure](../imgs/ICLR20252026/cropped_page2_idx0.webp)

## Input / Output

The method consumes a trained LoRA adapter (low-rank weight matrices of rank r), the original domain-specific training dataset, and an unlearning request specifying target instances with a token-level operation type (deletion, query token modification, or response label correction). It outputs updated LoRA adapter parameters that approximate the result of retraining on the corrected dataset, while the frozen base LLM (e.g., LLaMA2-7B or LLaVA-7B) remains untouched. Unlike prior work that only supports whole-instance removal, the unlearning request can target individual tokens within queries or responses, enabling fine-grained corrections such as removing noisy interaction items or flipping mislabeled classification outputs.

## Method

LLMEraser uses influence functions to directly estimate the parameter changes in LoRA adapters caused by unlearning requests, eliminating the need for retraining or fine-tuning. For each task type (IR, QM, RC), the parameter change is formulated as an inverse Hessian-vector-product applied to the aggregated gradient difference between original and perturbed instances (Eqs. 9–11). The key algorithmic contribution is reformulating this inverse Hessian-vector-product as a finite-sum convex quadratic programming problem (Eq. 12–15), solvable via mini-batch Adam optimization where each step requires only a Hessian-vector-product (HVP) computed in O(p) time via Pearlmutter's trick. This avoids the O(p²) memory of explicit Hessian storage and the cumulative approximation errors of stochastic power-series estimation, achieving a ~31× speedup over full retraining while matching its performance within 0.6–7.5% across LLM4Rec and MLLM benchmarks.

## Results

On the Instance Removal task (BookCrossing, 5% removal), LLMEraser achieves AUC 0.6319, within only 0.6% of Retrain (0.6357), while Gradient Ascent and E2URec drop to 0.6187 and 0.6205 respectively. On Query Modification (MovieLens/LastFM), LLMEraser improves HitRatio@1 by an average of 5.1% over the corrupted baseline and stays within 0.0079 of Retrain. On Response Correction (MM-SpuBench), LLMEraser reaches an average accuracy of 0.81 versus 0.70 for the corrupted model and 0.76 for SISA, with a gap of only 0.024 from Retrain (0.82). In terms of efficiency, LLMEraser completes unlearning in ~1.4×10³ seconds, a 31.25× speedup over full retraining (5.4×10⁴ s).

## Baselines & Comparisons

LLMEraser consistently outperforms all three baselines across every unlearning task. Against SISA (Bourtoule et al., 2021), LLMEraser achieves substantially higher performance: on the QM task, SISA actually degrades below the corrupted baseline by 7.0% on average, while LLMEraser improves by 5.1%; on RC (MM-SpuBench), SISA reaches 0.76 average accuracy versus LLMEraser's 0.81. Against RecEraser (Chen et al., 2022), the gap is even more pronounced—RecEraser collapses to 0.2717 HitRatio@1 on MovieLens (10% removal) compared to LLMEraser's 0.4456, a 31.3% drop relative to the corrupted baseline. Against E2URec (Wang et al., 2024), LLMEraser achieves 0.6319 AUC on the IR task versus E2URec's 0.6205, a 1.9% relative improvement. In all cases, LLMEraser also stays closest to the Retrain oracle, with gaps of only 0.6% (IR), 0.0079 absolute (QM), and 2.9–7.5% (RC), while simultaneously being ~31× faster than retraining.

## Relation to Prior Work

This paper builds directly on the influence function framework of Koh & Liang (2017) and the finite-sum reformulation of inverse Hessian-vector-product computation from Ding et al. (2025), repurposing both for the specific setting of PEFT adapter updates in LLMs. It departs from prior LLM unlearning work (SISA, FairSISA, APA, Gradient Ascent, EUL, E2URec) in two key ways: (1) it introduces a taxonomy of instance-wise unlearning tasks—Instance Removal, Query Modification, and Response Correction—whereas prior methods largely address only data removal, and (2) it operates directly on LoRA adapter parameters via influence functions rather than requiring sub-model retraining or KL-divergence-based fine-tuning, thereby preserving model architecture and avoiding retraining costs.

## Why It Matters / Open Questions

LLMEraser offers a practical 31× speedup over retraining while achieving near-Retrain performance (0.6% gap on IR), making parameter-efficient unlearning feasible for real-world PEFT deployments where retraining is prohibitive. The unified treatment of removal, query modification, and response correction under a single influence-function framework is a meaningful step toward general-purpose unlearning, though the method still requires access to the full training set and inherits approximation errors from the first-order Taylor expansion. Open questions include whether errors compound under sequential unlearning requests, how the approach scales to larger adapter ranks or full fine-tuning settings, and whether the finite-sum optimization converges reliably for very large or ill-conditioned Hessian structures.

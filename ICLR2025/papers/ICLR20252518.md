## Problem

Traditional VLN evaluation tests agents on one-time execution of isolated instructions with frozen parameters, diverging from real-world deployment where robots operate persistently in the same environment and receive instructions in consistent personal styles. Existing VLN datasets (e.g., R2R) lack out-of-distribution environments and instruction style diversity, making it impossible to assess whether agents can adapt over time to a specific scene. This paper introduces the GSA-VLN task and the GSA-R2R dataset to fill both gaps.
![Teaser figure](../imgs/ICLR20252518/cropped_page1_idx0.webp)

## Input / Output

At each step the agent receives a 36-view panoramic observation, a natural language instruction, and can query an environment-specific memory bank that accumulates all previously executed episodes (instructions, observations, actions, and trajectory paths) within that scene. The agent outputs a discrete action selecting a neighboring node in the connectivity graph or a [STOP] token, while simultaneously updating a persistent global topological graph that stores node positions and visual observations across episodes. The memory bank is treated as unlabeled data for unsupervised adaptation, and the initial model must remain general enough to transfer to any new environment.

## Method

GR-DUET modifies DUET's per-episode topological graph into a single global graph that persists and grows across all episodes within an environment, storing node positions and visual observations to provide comprehensive spatial awareness. During inference, the graph is initialized from the memory bank at episode start and updated in real time, with visited-node status reset each episode to restrict actions to unvisited nodes for efficiency. The key training innovation is a two-stage strategy: pretraining on complete ground-truth topological maps to expose the model to fully populated graphs, followed by environment-specific fine-tuning where each training scene maintains its own graph with a buffer of at most α=50 episodes (re-initialized when full) to mimic the gradual graph expansion seen at inference. PREVALENT data is incorporated during fine-tuning to increase path diversity and graph coverage. This alignment between training and inference input distributions avoids the distribution shift that causes TourHAMT and OVER-NAV to degrade, yielding 8–12% SR improvements over vanilla DUET across all GSA-R2R splits.

## Results

GR-DUET achieves 69.3% SR and 64.3% SPL on Test-R-Basic, and 56.6% SR and 51.5% SPL on Test-N-Basic, representing an 11.6% and 8.5% SR improvement over the DUET baseline (57.7% and 48.1% SR respectively). On the most challenging Test-N-Scene split, GR-DUET reaches 48.1% SR and 42.8% SPL versus DUET's 39.6% SR and 30.1% SPL. Across all five User instruction characters, GR-DUET achieves 60.9–67.1% SR, consistently outperforming DUET (52.3–56.3% SR) by 8–11 percentage points.

## Baselines & Comparisons

GR-DUET decisively outperforms all baselines across every GSA-R2R split. Against the DUET baseline, it gains +11.6% SR on residential Basic, +8.5% on non-residential Basic, and +8.5% on non-residential Scene instructions. Among optimization-based adaptation methods, Back-Translation (BT) is the strongest competitor (61.3% SR on R-Basic), but GR-DUET still leads by 8.0% SR; TTA methods (TENT, SAR) actually degrade performance below the unadapted DUET baseline, confirming that entropy minimization is ill-suited for sequential navigation. Memory-based IVLN methods (TourHAMT, OVER-NAV) catastrophically fail, dropping to 11–22% SR, because their history-embedding inputs become excessively long with GSA-R2R's 600 instructions per environment. On the original R2R-Test split (Table 3), GR-DUET's underlying DUET architecture achieves 69% SR, competitive with BEVBert (73%) and NavGPT-2 (72%), while ScaleVLN's 77% SR is inflated by data leakage from HM3D training data. The ablation (Table 7) confirms that combining full-graph pretraining with PREVALENT augmentation is essential, yielding a 12.5% SR gain over the no-pretraining, no-augmentation configuration.

## Relation to Prior Work

This paper extends the persistent-environment concept from Iterative VLN (IVLN, Krantz et al., 2023) into a more demanding continuous-adaptation setting, where agents execute hundreds of episodes in a single scene rather than a single long-horizon tour. Methodologically, GR-DUET builds directly on DUET's dual-scale graph transformer by replacing its per-episode topological map with a single global graph that accumulates observations across all episodes, paired with an environment-specific fine-tuning strategy. The dataset construction departs from prior VLN work (R2R, R4R, RxR) by incorporating HM3D environments for OOD evaluation and a three-stage LLM/VLM pipeline to generate instructions in diverse speaking styles, addressing a gap the authors identify in existing benchmarks that only evaluate in-distribution, single-style instructions.

## Why It Matters / Open Questions

The GSA-R2R dataset (150 buildings, 90K paths, 7 instruction types) is a substantial resource that could become a standard benchmark for evaluating VLN generalization beyond the narrow residential, single-style setting of R2R. The empirical finding that standard test-time adaptation methods (TENT, SAR) and existing memory-based approaches (TourHAMT, OVER-NAV) actually degrade performance in this setting is a useful negative result that redirects the field toward graph-based memory with matched training/inference distributions. Open questions include how to handle multi-floor environments where cross-floor memory is less useful, how to adapt LLM-based VLN methods to persistent environments, and whether the residential training bias can be reduced to improve OOD adaptation.

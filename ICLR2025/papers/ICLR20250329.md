## Problem

Existing diffusion-based image generators struggle with scene-aware tasks like VQA and HOI Reasoning, where generated images must preserve specific scene attributes (object counts, spatial relationships, interactions) from a reference image in relation to a text query while remaining visually diverse. Prior methods either lose fine-grained scene details due to imprecise embedding control (poor fidelity) or produce images too similar to the reference (poor diversity), making them unsuitable for synthetic data generation in these tasks.

## Input / Output

The method takes a multimodal context consisting of a reference RGB image and a text guidance string (a question or set of annotations); during training the text guidance additionally includes the ground-truth answer. The text guidance is first transformed via a task-specific prompt template into an instruction for an MLLM (LLaVA or InternVL), which produces a free-text Context Description capturing the relevant scene attributes. This description and the reference image are each encoded via CLIP (ViT-G/14) into text and image embeddings that jointly condition the SDXL UNet denoiser, which outputs a 1024×1024 generated image via 25-step DDIM sampling and VAE decoding.

## Method

Hummingbird fine-tunes the SDXL UNet denoiser via LoRA (11M trainable parameters, ~0.46% of 2.6B total) using a novel Multimodal Context Evaluator built on BLIP-2's pre-trained QFormer. The evaluator simultaneously maximizes two rewards: a Global Semantic Reward (maximum cosine similarity between QFormer visual tokens and the [CLS] text token of the Context Description) and a Fine-Grained Consistency Reward (positive-class logit from the QFormer's ITM classifier after bidirectional self-attention over visual and text tokens). The total loss is the negative weighted sum of these two rewards, backpropagated through the differentiable DDIM denoising chain to update only the UNet parameters. This dual-reward design captures both holistic scene alignment and token-level attribute consistency, which a single CLIP-based similarity cannot achieve, enabling the model to preserve fine-grained attributes like object counts and spatial positions while still generating images that are visually distinct from the reference.

## Results

On the MME Perception VQA benchmark (TTA with LLaVA v1.6), Hummingbird achieves the best ACC and ACC+ across all five tasks, with the largest gains on Position (ACC 81.67, +5.00; ACC+ 66.67, +13.34) and Count (ACC 83.33, +1.66; ACC+ 70.00, +3.33) over the real-only baseline. With InternVL 2.0, improvements are even more pronounced: Count ACC+ reaches 73.33 (+23.33) and Color ACC+ reaches 96.67 (+13.34). On Bongard-HOI (TPT), Hummingbird achieves 68.73% average accuracy, outperforming the best baseline (I2T2I SDXL at 67.38%) by +1.35%. On object-centric benchmarks, Hummingbird reaches 62.60% on ImageNet (+4.50%) and 47.09% OOD average (+6.29%), consistently leading all methods.

## Baselines & Comparisons

Hummingbird outperforms all five baselines consistently across every benchmark. I2T2I SDXL is the closest competitor, achieving the highest diversity (Euclidean distance 37.22 vs. Hummingbird's 36.94) but trailing on fidelity: on MME Perception with LLaVA v1.6, it matches Hummingbird on Existence but falls behind on Position (ACC 75.00 vs. 81.67) and Color (ACC 88.33 vs. 95.00). Image Translation (Boomerang) is second-closest, matching or slightly exceeding the real-only baseline on some tasks but never surpassing Hummingbird; on Bongard-HOI it achieves 66.64% average vs. Hummingbird's 68.73%. Image Variation and Textual Inversion perform worst, with Textual Inversion dropping 13.34% on Existence ACC and 26.66% on Existence ACC+ (InternVL 2.0) due to its inability to preserve scene attributes from a single reference image. RandAugment, the simplest baseline, provides modest gains on some tasks (e.g., +1.66 on Position ACC with LLaVA) but degrades performance on most others, confirming that naive augmentation cannot maintain scene-attribute fidelity.

## Relation to Prior Work

Hummingbird builds on SDXL as its base diffusion backbone and repurposes the BLIP-2 QFormer as a frozen multimodal context evaluator, a component previously used for image-text pre-training but not for reward-based fine-tuning of diffusion models. It departs from Image Variation methods (which condition on image embeddings but lack attribute-level control), Image Translation/Editing techniques (which add noise to the reference, limiting diversity), and Textual Inversion (which struggles with single-reference, multi-sample generation) by introducing a dual-reward fine-tuning objective that explicitly aligns generated images with an MLLM-derived context description. The benchmark formulation also extends prior TTA/TPT evaluation protocols by jointly measuring fidelity (via MLLM accuracy on scene attributes) and diversity (via CLIP feature distances), a pairing not previously standardized for generation methods.

## Why It Matters / Open Questions

The paper establishes a practical recipe for generating synthetic training data that preserves task-relevant scene attributes while remaining visually diverse, which is a prerequisite for data augmentation in VQA and HOI reasoning pipelines. Key limitations include reliance on a single scene attribute per context (no compositional multi-attribute generation), sensitivity to MLLM context description errors, and inherited symbolic-logic constraints of SDXL. Open questions include whether the dual-reward framework extends to multi-attribute compositional contexts, whether the BLIP-2 QFormer evaluator can be replaced by lighter alternatives without fidelity loss, and whether the approach generalizes to video or 3D generation settings.

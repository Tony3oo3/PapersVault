## Problem

Existing benchmarks for Large Multimodal Models evaluate them on traditional vision tasks or in isolated single environments (household, web, mobile), failing to provide a unified, interactive, multitask evaluation of LMMs as visual foundation agents. Moreover, most benchmarks offer only test sets without training trajectories, leaving open LMMs unable to be meaningfully evaluated or improved in agent settings.
![Teaser figure](../imgs/ICLR20253450/cropped_page1_idx2.webp)

## Input / Output

The agent receives a POMDP-formulated interaction loop: at each turn it is given the latest visual observation (a single screenshot for embodied/GUI tasks, or vertically concatenated multi-screenshot for CSS comparison), the original text task instruction, accumulated environment feedback, and a system prompt specifying the action space. It outputs exactly one action call in Python-style pseudo-code per turn (e.g., grasp(obj), tap(x,y), edit_css(property, value)). Evaluation is interactive with environment-specific judge functions determining binary task success within a turn limit (10–100 turns depending on environment).

## Method

VAB unifies five interactive environments across three agent categories (Embodied: OmniGibson + Minecraft; GUI: AndroidLab + WebArena-Lite; Visual Design: CSS) under standardized interfaces, prompting formats, and data schemas. Task instances are collected via a two-stage prototyping-and-instantiation paradigm that grounds high-level activity templates into concrete, verifiable scenarios with automated judge functions. Training trajectories (4,482 total) are synthesized through a hybrid of three strategies—program-based solvers (OmniGibson, WebArena-Lite), LMM agent bootstrapping with optional memory augmentation (Minecraft, AndroidLab, CSS), and human demonstrations (AndroidLab)—each chosen per environment based on cost, adaptability, versatility, and flexibility trade-offs. Proprietary LMMs are evaluated via direct prompting, while open LMMs undergo full-parameter behavior cloning fine-tuning (5k steps, batch 64) on the aggregated multitask trajectory set, with CSS data duplicated 2× to compensate for its multi-image format. The benchmark further provides fine-grained analyses of visual grounding (object labels, Set-of-Marks, visual difference perception) and planning (Chain-of-Thought necessity, error recovery behavior) to diagnose where LMM agents fail.

## Results

On VisualAgentBench (VAB), the best proprietary LMM, gpt-4o-2024-05-13, achieves a 36.2% average success rate across 5 environments using mere prompting, with strongest performance on VAB-Minecraft (55.2%) and VAB-OmniGibson (41.4%). The best open LMM after multitask behavior-cloning fine-tuning, InternVL-2 (7B+0.3B), reaches 16.0% average success rate, surpassing gemini-1.0-pro (6.3%) on all environments and claude-3-opus (21.9%) on VAB-CSS (24.2% vs. 20.0%). The gap between top proprietary and open LMMs remains substantial (~20 percentage points), indicating that current open models are not yet competitive as visual foundation agents despite fine-tuning on 4,482 training trajectories.

## Baselines & Comparisons

Among proprietary LMMs, gpt-4o (36.2% avg) leads all competitors, outperforming gpt-4-vision-preview (31.7%) by 4.5 points and claude-3.5-sonnet (26.9%) by 9.3 points; notably, claude-3.5-sonnet excels on Minecraft (56.0%) but lags severely on WebArena-Lite (7.2%) and CSS (15.8%). gpt-4o-mini (20.5%) is comparable to claude-3-opus (21.9%) and gemini-1.5-pro (19.8%), revealing a significant performance drop from the full gpt-4o. Among open LMMs, InternVL-2 (16.0%) and Qwen2-VL (15.6%) are the strongest after fine-tuning, with InternVL-2 surpassing gemini-1.0-pro (6.3%) on every environment and beating claude-3-opus on CSS (24.2% vs. 20.0%). However, even the best open LMM trails gpt-4o by over 20 percentage points on average, and the gap is most pronounced on GUI tasks (AndroidLab: 3.4% vs. 31.9%; WebArena-Lite: 7.9% vs. 18.2%), suggesting that open models still lack the instruction-following and visual grounding capabilities needed for practical visual agent deployment.

## Relation to Prior Work

This paper unifies and extends the line of single-environment agent benchmarks (WebArena for web, Behavior-1K/OmniGibson for household, JARVIS-1 for Minecraft, AndroidLab for mobile) into a standardized multi-environment framework for evaluating LMMs as visual foundation agents. It departs from prior work in two key ways: (1) it introduces interactive evaluation with judge functions across all environments rather than relying on offline human-annotated trajectories, and (2) it provides 4,482 training trajectories collected via hybrid strategies (program-based solvers, LMM bootstrapping, human demonstrations) to enable behavior cloning of open LMMs—something no prior agent benchmark has offered. The conceptual framing draws an analogy to AgentBench for LLMs, but extends it to the multimodal/visual setting with vision-centric task design.

## Why It Matters / Open Questions

VAB is likely to become a standard reference benchmark for evaluating LMMs as practical visual agents, given its multi-environment coverage, interactive evaluation, and provision of training data for open models. The finding that even gpt-4o achieves only 36.2% overall success rate, and that the best fine-tuned open model (InternVL-2 at 16.0%) remains far behind proprietary APIs, reveals a substantial and previously underappreciated gap between LMM performance on standard vision benchmarks and their actual agent capabilities. Open questions include whether larger open backbones and more trajectory data can close this gap, whether the visual design (CSS) task generalizes beyond the current narrow corruption-based formulation, and whether the benchmark's reliance on Set-of-Marks and object labels will become unnecessary as LMM grounding improves.

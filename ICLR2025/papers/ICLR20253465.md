## Problem

Given a fixed inference compute budget for Vision Language Models, it is unclear whether to allocate FLOPs toward a larger LLM or more visual input tokens. Prior token compression work targeted modest reductions (5–10×) to preserve base-model performance, but the compute-optimal trade-off between LLM parameter count and visual token count had never been characterized, leaving practitioners without principled guidance for deployment on latency-constrained edge devices.
![Teaser figure](../imgs/ICLR20253465/cropped_page1_idx0.webp)

## Input / Output

The VLM consumes an RGB image encoded by CLIP ViT-L/14 into 576 patch tokens and a text prompt/query, producing a short-form text response. The visual tokens are compressed by a learned projector to as few as 1 token before entering the LLM, and in many practical settings (e.g., static monitoring prompts) the text input is cached so that Q=0, making the visual token count the sole variable in the inference FLOPs budget O(N(Q+V)). The scaling law models average downstream error across nine visual reasoning benchmarks as a function of LLM parameters N and total inference tokens T.

## Method

The paper formulates inference-time scaling laws for VLMs of the form Y(N,T) = A/N^α · B/T^β + D, fitted via grid search over VLMs built on the Qwen-1.5 family (0.5B–7B) with CLIP ViT-L/14 and TokenPacker-style compression to {1,4,16,36,64,144,576} tokens. The key empirical finding is that for visual reasoning tasks α ≈ 0.077 is more than five times larger than β ≈ 0.015, meaning downstream error degrades far faster when shrinking the LLM than when reducing visual tokens, so the compute-optimal strategy is to use the largest LLM that fits the budget with as few visual tokens as possible (often 1). For OCR/document tasks the trend reverses (β > α), confirming that dense textual content genuinely requires many tokens. To support this extreme-compression regime, the authors propose QueCC, a query-based convolutional cross-attention projector that injects the user's text-query embedding (from the LLM's last hidden state) into the visual tokens before downsampling via a learnable depth-wise 2D convolution and region-based cross-attention, outperforming TokenPacker, PruMerge, and Matryoshka variants at 1- and 4-token budgets.

## Results

The paper establishes inference-time scaling laws for VLMs, revealing that for visual reasoning tasks, the LLM quality parameter (α=0.077) is more than 5× larger than the visual token quality parameter (β=0.015), meaning error increases far faster when reducing LLM parameters than when reducing visual tokens. The compute-optimal configuration under a fixed inference budget is to use the largest feasible LLM with as few visual tokens as possible—just 1 token when text input is cached (Q=0), or ~16 tokens (97% reduction) when Q=50. For OCR/document tasks, the trend reverses (α=0.029 vs β=0.048), with visual tokens dominating performance. The proposed QueCC method at 1 token achieves GQA 53.5, POPE 81.3, SQA 69.9, and MME 1269.1, outperforming all compared compression methods at the same extreme compression level.

## Baselines & Comparisons

Against the full-token LLaVA-1.5 baseline (576 tokens), the QueCC method at just 1 token retains ~86% of GQA performance (53.5 vs 62.0) and ~95% of POPE (81.3 vs 85.9), while using 99.8% fewer visual tokens. Compared to TokenPacker (the direct predecessor), QueCC improves on all eight benchmarks at 1 token, most notably on VizWiz (+3.0 pp, 44.1 vs 41.1) and MMB (+0.7 pp, 59.4 vs 58.7), and at 4 tokens on MME (+42.7, 1390.3 vs 1347.6) and MMB (+0.6 pp, 62.1 vs 61.5). Against Matryoshka Query Transformer, QueCC at 4 tokens substantially outperforms on GQA (+3.5 pp), MMB (+5.6 pp), MME (+214.2), POPE (+4.2 pp), SQA (+3.5 pp), and VQAv2 (+6.5 pp), though Matryoshka Query retains an edge on VizWiz (49.4 vs 45.0). Against PruMerge (~32 tokens), QueCC at 1 token matches or exceeds it on GQA (53.5 vs 57.2—actually loses here), POPE (81.3 vs 76.3), and SQA (69.9 vs 68.5), but trails on MME, TextVQA, and VQAv2. Against LLaMA-VID (which uses a stronger vision encoder), QueCC at 16 tokens wins on GQA (+0.8 pp), SQA (+3.3 pp), and TextVQA (+0.5 pp), while at 4 tokens it wins on GQA (+0.3 pp) but slightly trails on POPE (−1.7 pp) and TextVQA (−0.4 pp). Overall, QueCC is the strongest method in the extreme compression regime (1–4 tokens) across most visual reasoning benchmarks, validating the paper's central thesis that query-aware compression is essential when visual tokens are reduced to single digits.

## Relation to Prior Work

This paper extends the token compression line of work (TokenPacker, LLaVA-PruMerge, Matryoshka) by reframing the objective: rather than preserving base-model performance under moderate compression (5–10×), it asks what the compute-optimal operating point is when both LLM size and visual token count are jointly variable. Conceptually, it departs from prior inference-scaling analyses (Kaplan et al., 2020; Li et al., 2024a) that treated LLM parameters and input tokens as independent axes, instead formulating the first inference-time scaling law that couples them under a fixed FLOPs budget. The QueCC method builds directly on TokenPacker's cross-attention projector, adding query-conditioned text embeddings and learnable convolutional downsampling to improve extreme-compression fidelity.

## Why It Matters / Open Questions

The finding that visual-reasoning VLMs are compute-optimal at 1–4 visual tokens with the largest feasible LLM is a paradigm shift that redirects the token-compression research agenda from moderate reduction toward extreme reduction, with direct implications for edge deployment and real-time systems. A key limitation is that the opposite trend holds for OCR/document tasks, where token count dominates over LLM size, so the optimal strategy is task-dependent and the community must develop task-aware compression policies. Open questions include whether the scaling laws generalize beyond the Qwen-1.5 family and CLIP ViT-L/14 encoder, how adaptive in-LLM token pruning interacts with these findings, and whether the extreme-compression regime can be further improved with better query-conditioned projectors.

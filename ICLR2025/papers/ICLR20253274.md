## Problem

Existing activation steering methods such as ActAdd modify LLM behavior indiscriminately across all inputs, making them impractical for applications requiring selective responses like content moderation or domain-specific assistants. The paper addresses the absence of conditional control in activation steering — the inability to specify *when* a behavior modification should activate based on the input's semantic content, so that a refusal vector, for example, fires only on harmful prompts while leaving harmless ones unaffected.
![Teaser figure](../imgs/ICLR20253274/cropped_page1_idx0.webp)

## Input / Output

The method consumes a text prompt plus two pre-extracted vectors of hidden-state dimensionality: a condition vector (encoding a prompt category such as 'harmful' or 'legal opinion') and a behavior vector (e.g., a refusal direction). The condition check occurs only during the first forward pass over the prompt tokens at a single chosen layer; if the cosine similarity between the hidden state and its projection onto the condition vector crosses a learned threshold, the behavior vector is then added at specified layers for every subsequent token-generation pass. The output is a steered text response that conditionally refuses or complies, with the refusal decision locked in after the initial prompt pass.

## Method

CAST introduces condition vectors, extracted via PCA from contrastive prompt pairs (target-category prompts vs. other-category prompts) but recorded at full-prompt token positions rather than the suffix positions used for behavior vectors. The intervention formula h′ ← h + f(sim(h, proj_c h))·α·v gates the behavior vector through a binary step function f that compares cosine similarity against a threshold θ, with a tanh nonlinearity applied to the projection for more predictable behavior. A grid search over layer, threshold, and comparison direction (> or <) identifies the optimal conditioning configuration, and the duality property — flipping the comparison direction to intervene on the exact complement set — enables domain constraining (e.g., refuse everything *except* health queries). Multi-conditioning extends the thresholding function with logical OR across multiple condition vectors, supporting programmatic rules like 'if hate speech OR adult content, then refuse.' No weight updates are performed; the entire pipeline operates purely at inference time with linear scaling in the number of contrastive samples.

## Results

Across seven models, CAST achieves 83–91% harmful-prompt refusal while keeping harmless-prompt refusal at 1.8–6.8%, compared to standard activation steering which drives harmless refusal to 46–98.6%. For example, on Hermes 2 Pro, CAST raises harmful refusal from 19.3% (base) to 83.3% while keeping harmless refusal at 2.4%, whereas indiscriminate refusal steering pushes harmless refusal to 91.8%. On Qwen 1.5 Chat 1.8B, CAST reaches 90.7% harmful refusal with only 2.2% harmless refusal, matching or exceeding the safety-aligned Llama 3.1 Instruct 8B (76.2% harmful, 2.0% harmless) and Llama 2 Chat 13B (88.4% harmful, 3.0% harmless) reference models.

## Baselines & Comparisons

Against standard activation steering (ActAdd, Turner et al. 2023), CAST is the clear winner on the key metric of selective refusal: while ActAdd raises harmful refusal to 77–100%, it simultaneously drives harmless refusal to 46–98.6%, rendering the model nearly useless for benign queries. CAST maintains comparable harmful refusal (83–91%) while reducing harmless refusal to 1.8–6.8%, a gap of 40–90+ percentage points. Against the safety-aligned Llama 3.1 Instruct 8B (Reference A: 76.2% harmful, 2.0% harmless), CAST on Qwen 1.5 Chat 1.8B achieves higher harmful refusal (90.7% vs. 76.2%) at a similar harmless rate (2.2% vs. 2.0%). Against Llama 2 Chat 13B (Reference B: 88.4% harmful, 3.0% harmless), CAST on Qwen 1.5 Chat 1.8B slightly exceeds harmful refusal (90.7% vs. 88.4%) with a marginally lower harmless rate (2.2% vs. 3.0%). Notably, CAST achieves these results without any weight updates, using only a single activation-addition step conditioned on a similarity check, making it substantially cheaper than the RLHF/DPO post-training used to produce the reference models.

## Relation to Prior Work

CAST extends the activation steering lineage (Turner et al., 2023; Zou et al., 2023) by introducing a condition vector that gates the application of a behavior vector, transforming indiscriminate steering into context-dependent control. The vector extraction methodology (mean-centering + PCA on contrastive pairs) is inherited directly from representation engineering, but the repurposing of a steering vector as a condition indicator—rather than a behavior modifier—is the conceptual departure. The logical composition of condition vectors (OR via multi-conditioning, NOT via the duality property of flipping comparison direction) has no direct analogue in prior activation steering work, which has treated steering vectors as monolithic, always-on interventions.

## Why It Matters / Open Questions

CAST provides a lightweight, weight-free mechanism for implementing explicit behavioral rules (e.g., 'refuse if hate speech, comply otherwise') that is particularly relevant for domain-specific assistants and content moderation where indiscriminate refusal destroys utility. The duality property enabling 'refuse everything except category X' generalizes to unseen categories, suggesting the approach captures semantic structure rather than memorizing training categories. Key limitations include model-specific grid search for thresholds (values range from 0.01 to 0.56 across models), condition checking only on the prompt (not generated text), and acknowledged imperfections in refusal vector extraction that interact with conditioning quality. Open questions include whether the approach extends to multi-turn conversations, more nuanced (non-binary) conditions, and whether the saturation property limits applicability to concepts the base model already represents well.

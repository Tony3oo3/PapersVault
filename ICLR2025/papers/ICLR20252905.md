## Problem

Existing CLIP-based approaches for quantitative image understanding (counting, age estimation, quality assessment) rely on single-image reasoning with exhaustively enumerated text prompts (e.g., 'A photo of 3 cats'), which is impractical for long-tail distributions and continuous scoring targets. This limits the model's ability to learn cross-image relationships and generalize across ranking tasks without task-specific pre-processing or custom decoders.

## Input / Output

The method takes a batch of B RGB images (resized to 320×320, yielding 100 patch tokens each after discarding CLIP's pooling layer) and a single universal ranking instruction (e.g., 'Sort images by the number of cats'), augmented with 32 learnable prompt tokens appended to the 77-token CLIP text embedding. It outputs a continuous ranking score per image from the regression head and a pairwise difference score from the ranking head, which together produce an ordered image list. The same model handles multiple ranking tasks by simply changing the text query, without architectural modifications.

## Method

The paper reframes CLIP's image-text contrastive objective into a learning-to-rank task and introduces a lightweight ranking-aware adapter on top of a frozen ConvNeXt-L CLIP backbone. The adapter consists of a two-block cross-attention encoder (image patch tokens as queries, text tokens as key-value pairs) that produces text-conditioned visual embeddings, followed by two parallel heads: an FFN regression head predicting individual ranking scores, and a ranking head employing a relational ranking-aware attention mechanism. This attention concatenates the text-conditioned embeddings of an image pair, uses M=16 learnable relational tokens as queries, splits the resulting attention matrix into per-image components, computes separate attention outputs for each image, and takes their explicit subtraction to yield a pairwise difference score. Training combines Smooth L1 regression loss on individual scores with a pairwise Hinge ranking loss on the relational differences, jointly optimizing both absolute score accuracy and relative ordering consistency.

## Results

On historical colored image dating (HCI), the method achieves 72.8% accuracy and 0.32 MAE, surpassing the prior best (NumCLIP, 0.35 MAE) by 9%. On facial age estimation (Adience), it reaches 65.2% accuracy and 0.36 MAE, matching L2RCLIP's MAE with notably lower variance (±0.03 vs ±0.05). For image quality assessment on KonIQ-10k, it attains PLCC 0.919 / SRCC 0.911, outperforming the fine-tuned CLIP-IQA+ (0.895/0.909) and approaching the purely vision-based MUSIQ (0.924/0.937). On object count sorting (COCO-REM), it achieves PLCC 0.624 / SRCC 0.557, matching the best CLIP-based fine-tuned method and substantially exceeding all general VLMs (e.g., InstructBLIP 0.509/0.485).

## Baselines & Comparisons

On HCI dating, the method clearly wins: 0.32 MAE beats NumCLIP (0.35), L2RCLIP (0.43), and OrdinalCLIP (0.67) by 9%, 26%, and 52% respectively. On Adience, it ties L2RCLIP on MAE (0.36) but trails slightly on accuracy (65.2% vs 66.2%), though with lower standard deviation (±2.9 vs ±4.4), indicating more stable training. For object count sorting, it matches Paiss et al. (2023) exactly (PLCC 0.624, SRCC 0.557) while avoiding the need to enumerate count–category caption combinations, and outperforms all VLM baselines (InstructBLIP 0.509/0.485, VLM-VILA 0.558/0.507, BLIP-2 0.284/0.252). On KonIQ-10k IQA, it surpasses CLIP-IQA+ (0.919 vs 0.895 PLCC) and VILA-R (0.919 vs –), approaching the task-specific MUSIQ (0.924). On AVA, it dominates all VLM-based baselines: 0.760 PLCC vs CLIP-IQA+ (0.677), VILA-R (0.657), and Hentschel et al. (0.731). On UTKFace, it beats the dedicated age-estimation model MiVOLO (3.83 vs 4.23 MAE).

## Relation to Prior Work

This paper builds on frozen CLIP (Radford et al., 2021) as a backbone but departs from prior VLM-based ranking approaches in a key conceptual way: instead of modifying the text encoder to map numerical labels into a continuous ordinal space (as in OrdinalCLIP, L2RCLIP, NumCLIP) or enumerating all possible count/age captions per image (as in Paiss et al., 2023), it reframes the problem as a learning-to-rank task with a single universal instruction and introduces a lightweight adapter that supervises pairwise visual differences. The ranking-aware attention mechanism, which concatenates two images' text-conditioned embeddings and uses relational tokens to extract their relative features, is the paper's core architectural novelty, distinguishing it from both contrastive fine-tuning and prompt-learning approaches that operate on individual images.

## Why It Matters / Open Questions

The unified framework demonstrates that a single lightweight adapter on a frozen VLM can handle diverse ranking tasks (age, count, quality, dating) without task-specific pre-training or custom decoders, offering a practical path toward general-purpose image ordering. However, the method retains CLIP's category-specific bias (limiting open-vocabulary counting), the pairwise attention design is incompatible with triplet or listwise ranking losses, and multi-attribute ranking lacks principled ground-truth evaluation. Open questions include whether the approach scales to truly open-vocabulary queries, how to handle multi-attribute ranking with proper supervision, and whether the pairwise formulation can be extended to listwise objectives for longer image sets.

## Problem

The Learning to Help (L2H) framework, which trains a server model and rejector to assist a fixed, non-updatable local classifier, was previously limited to binary classification under a single pay-per-request cost model. This paper addresses the gap by extending L2H to multi-class classification and to three practical deployment scenarios—pay-per-request, intermittent server availability, and bounded reject rate—while providing a theoretically grounded, differentiable surrogate loss that was not available in the binary setting due to non-differentiability issues.

## Input / Output

The system consumes 32×32 RGB images (CIFAR-10, CIFAR-100, SVHN) and produces a class label from K categories. The client side holds a fixed LeNet-5 classifier and a trainable rejector (also LeNet-5-based) that outputs a binary LOCAL/REMOTE decision; the server side holds a trainable AlexNet or ViT classifier. The rejector's decision determines which classifier's prediction is returned, and the server classifier is only queried when the rejector defers, making the effective output a single class label whose provenance (local vs. remote) is determined at inference time.

## Method

The core contribution is a stage-switching surrogate loss L_S = L_1 + L_2, where L_1 is standard multi-class cross-entropy for the server classifier and L_2 is a weighted binary log-loss for the rejector whose weights depend on the server's current prediction and the client's fixed prediction. Training alternates between a server stage (updating e via L_1 with r fixed) and a rejector stage (updating r via L_2 with e fixed), enabling both synchronous (PPR) and asynchronous (IA) optimization without requiring continuous client-server connectivity. The paper proves L_S is convex (or monotone) in each stage and, crucially, consistent with the generalized 0-1 loss: any minimizer of the surrogate risk also minimizes the original non-differentiable risk, recovering the Bayes rejector r^B that compares the client's posterior confidence η_{j*(x)}(x) against a threshold involving the reject cost c_e and inaccuracy cost c_1. For the bounded-reject-rate setting, a stochastic post-hoc calibration step uses a uniform random variable to either suppress or augment rejections so the empirical reject rate matches a prescribed upper bound q.

## Results

On CIFAR-10 (c₁=1.25, cₑ=0.25), the rejector routes 55.9% of samples to the server (REMOTE), where the server classifier e achieves 67.7% accuracy versus 54.5% for the client m — a 13.2-point gap confirming the rejector identifies hard samples. On the 44.1% LOCAL subset, the server still outperforms the client by 8.0 points (81.9% vs. 73.9%). On SVHN, the rejector is more conservative (only 8.29% REMOTE), with a 11.6-point server advantage on those samples (72.8% vs. 61.2%) and a 2.7-point gap on the 91.71% LOCAL subset. Synchronized (PPR) and asynchronous (IA) training converge to comparable final accuracy, with larger synchronization intervals S causing slower convergence but the same loss level.

## Baselines & Comparisons

The paper does not include a head-to-head accuracy comparison against L2D or LWA baselines; instead, it validates the rejector through a contrastive evaluation showing that the server classifier consistently outperforms the fixed client on the REMOTE subset by 11–14 points (vs. 3–8 points on LOCAL), confirming the rejector learns to route genuinely difficult samples. Conceptually, Table 2 (Appendix B) compares the proposed stage-switching surrogate loss against six prior approaches (Confidence-LWA, Separate-rejector-LWA, Softmax-L2D, OvA-L2D, TS confidence-L2D, TS separate-rejector-L2D) on four required properties: separate rejector, learning from client m(x), learning from server e(x), and asynchronous training. Only the proposed method satisfies all four simultaneously; all prior methods lack at least one property, making them inapplicable to the L2H multi-class setting with intermittent availability. The convergence comparison between Algo. 1 (synchronized, PPR) and Algo. 2 (asynchronous, IA) shows equivalent final accuracy, validating that the surrogate loss minimizer is independent of the specific optimization schedule.

## Relation to Prior Work

This paper extends the Learning to Help (L2H) framework of Wu & Sarwate (2024), which trained a server model and rejector given a fixed legacy client model, from binary to multi-class classification. It positions L2H as the natural complement to Learning to Defer (L2D), where the roles are reversed (fixed expert server, trained client), and to Learning with Abstention (LWA), where rejected samples are simply discarded rather than forwarded. The key methodological departure is a stage-switching surrogate loss that alternates between updating the server classifier (cross-entropy) and the rejector (a weighted binary log-loss), enabling both synchronous and asynchronous training — a property absent from prior L2D/LWA surrogate losses that require joint or client-side-only optimization.

## Why It Matters / Open Questions

The paper addresses a practically important but underexplored scenario: deployed legacy models on resource-constrained devices that cannot be retrained but can be augmented by a server. By covering three realistic constraints (pay-per-request, intermittent availability, bounded reject rate) with clean theoretical guarantees (consistency, convexity), it provides a principled toolkit for edge-cloud ML systems. Limitations include experiments restricted to small-scale image datasets (CIFAR-10/100, SVHN) with simple client architectures (LeNet-5), and the BRR post-hoc correction is stochastic rather than deterministic. Open questions include whether the framework scales to LLM-based server models, multi-party collaboration, and non-i.i.d. deployment distributions.

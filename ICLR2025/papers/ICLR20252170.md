## Problem

Task arithmetic enables modular model editing by composing task vectors, but existing methods rely on explicit network linearization to derive these vectors, incurring significant computational overhead during both training and inference. More critically, linearization alone does not guarantee weight disentanglement—the property that each task vector only affects its own data support—so task vectors can still interfere with each other when composed. The paper asks how to produce task vectors that are both linearized and functionally localized without the cost of explicit linearization.

## Input / Output

The method takes a pre-trained model (CLIP ViT-B/32, ViT-B/16, ViT-L/14, or T5-Small/Base/Large) and a single task-specific dataset (e.g., image classification or question answering). It produces a sparse task vector τ_t = θ_t* − θ_0 with 90–99% sparsity, meaning only a small structured subset of parameters (concentrated in Q and K attention projections) is non-zero. This vector can be added to or subtracted from the base model weights via simple arithmetic, enabling task addition or negation without retraining. The mask calibration requires only the task's own validation split (~10% of training data), making it compatible with decentralized settings where users never share data across tasks.

## Method

TaLoS identifies the least gradient-sensitive parameters of a pre-trained model by computing the diagonal of the Fisher Information Matrix on the task data, then sparsely fine-tunes only those parameters using an iterative Pruning-at-Initialization mask calibration (4 rounds, ~40 iterations). The key insight is that these low-sensitivity parameters are shared across tasks—pruning them leaves zero-shot performance intact on all tasks—so updating them simultaneously promotes linearized behavior (flat loss landscape yields approximately constant gradients, satisfying the linear regime condition) and enforces function localization (the task-specific perturbation has near-zero effect on other tasks' outputs, as formalized by an upper bound k²·μ·η). Unlike LoTA, which selects task-specific high-magnitude parameters, TaLoS selects task-generic low-sensitivity parameters, producing a highly structured sparsity pattern concentrated in attention Q/K projections rather than being distributed across layers. This structured sparsity also yields substantial efficiency gains: TaLoS achieves the fastest forward-backward pass and lowest peak memory among all compared methods while outperforming them in both task addition and negation.

## Results

On Task Addition, TaLoS achieves the best normalized accuracy across all six model variants, ranging from 90.61% (T5-Large) to 97.22% (T5-Small), with improvements of 1.88–4.65% over the second-best method. On Task Negation, TaLoS achieves the lowest target-task accuracy (10.58–11.03% for vision models, 37.20–39.64% for T5) while maintaining ≥95% control-task accuracy. In terms of efficiency, TaLoS reduces total iteration time by 2.3–5.5× and peak memory by 28–60% compared to full fine-tuning baselines (e.g., 0.164s vs. 0.372s per iteration and 4.7 vs. 6.5 GiB on ViT-B/32).

## Baselines & Comparisons

TaLoS outperforms all eight baselines on normalized Task Addition accuracy across every model variant. Against the closest competitor L-LoRA (Tang et al., 2024), TaLoS gains +4.65% normalized accuracy on ViT-B/32 (90.73 vs. 86.08) and +2.47% on T5-Large (90.61 vs. 87.78), while also reducing peak memory from 5.3 to 4.7 GiB. Linearized FT (Ortiz-Jimenez et al., 2023) achieves competitive absolute accuracy on vision (88.29 vs. 88.37 on ViT-L/14) but lags significantly on normalized accuracy (93.01 vs. 95.20) and requires 2.1× more memory (21.3 vs. 7.8 GiB on ViT-L/14). Among post-hoc methods, TIES-Merging and TALL Mask/Consensus are the strongest but still trail TaLoS by 2–5% in normalized accuracy. LoTA (Panda et al., 2024), the other sparse fine-tuning baseline, is consistently outperformed by TaLoS (e.g., 74.37 vs. 90.73 normalized on ViT-B/32), which the authors attribute to LoTA selecting task-specific parameters rather than task-generic least-sensitive ones. On Task Negation, TaLoS achieves the lowest target accuracy (10.58–11.03% on vision) while maintaining control accuracy, outperforming Linearized FT (10.86–11.20%) and all other methods by a wider margin on vision than on language.

## Relation to Prior Work

This paper extends the task arithmetic framework (Ilharco et al., 2023) and the weight disentanglement analysis of Ortiz-Jimenez et al. (2023), which showed that linearized fine-tuning preserves the composability of task vectors. The key departure is the demonstration that linearization alone is insufficient—task functions can still activate outside their intended data support—motivating an additional function localization constraint. TaLoS implements both constraints simultaneously by sparsely updating only the least-sensitive parameters (identified via the FIM diagonal), drawing on sparse fine-tuning and Pruning-at-Initialization techniques but inverting the typical selection criterion: rather than updating the most important weights (as in LoTA or Lottery Ticket methods), it updates the least important ones to minimize cross-task interference.

## Why It Matters / Open Questions

TaLoS provides a practical, computationally efficient path to conflict-free model editing in decentralized settings where users fine-tune independently on private data, eliminating the need for explicit linearization or cross-task data sharing. The discovery that least-sensitive parameters are consistently identifiable across tasks (and concentrated in Q/K attention projections) offers actionable insight into where task-specific knowledge resides in transformer architectures. Limitations include the mask calibration overhead (though small relative to training), less pronounced gains in NLP compared to vision, and the fact that the approach still requires per-task sparsity tuning. Open questions include whether explicitly enforcing localization constraints during fine-tuning could further improve performance, and whether the structured sparsity pattern generalizes to non-attention architectures.

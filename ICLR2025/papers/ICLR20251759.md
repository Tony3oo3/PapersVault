## Problem

Classic approximation algorithms for combinatorial optimization (e.g., Vertex Cover, Steiner Tree, Knapsack) have fixed worst-case ratios that cannot be improved without significantly more running time, yet practical instances often admit much better solutions. Prior learning-augmented work focused on online problems or warm-starting exact algorithms, leaving open whether predictions can improve approximation ratios of fast offline algorithms without increasing their running time.

## Input / Output

The algorithm receives a weighted set of n items (e.g., graph edges, vertices, or knapsack items) with an implicit feasibility structure X ⊆ 2^[n], plus a predicted subset X̂ ⊆ [n] that is explicitly allowed to be infeasible. It outputs a guaranteed-feasible solution X ∈ X. The approximation ratio is expressed in terms of two error quantities: η⁺ (total weight of false positives X̂\X*) and η⁻ (total weight of false negatives X*\X̂), measured against the closest optimal solution, so the guarantee degrades smoothly as prediction quality worsens.

## Method

The core contribution is a black-box reduction: for minimization problems, the algorithm sets the weight of every predicted item to zero and runs the existing ρ-approximation algorithm on the modified weights, yielding a feasible solution with ratio 1 + (η⁺ + (ρ−1)η⁻)/OPT at the same asymptotic running time. For maximization problems, it instead zeros out non-predicted items and runs the ρ-approximation on the complementary minimization problem, giving ratio 1 − ((ρ−1)η⁺ + η⁻)/OPT. For Steiner Tree, a refined algorithm introduces a hyperparameter α ≥ 1 that scales predicted edge weights by 1/α before running Mehlhorn's MST heuristic on the metric closure; this caps the false-positive contribution by (α−1)·Σ c(e) over the top min{k−1, |X̂\X*|} MST edges rather than their raw weights, achieving a 2α-approximation that interpolates between the prediction-free 2-approximation (α=1) and the generic black-box bound (α→∞). The paper also proves UGC-based lower bounds showing the black-box approach is tight for the class of selection problems as a whole.

## Results

The paper's main results are theoretical approximation-ratio guarantees parameterized by prediction error (η⁺, η⁻). For minimization selection problems (Theorem 1), the learning-augmented algorithm achieves ratio 1 + (η⁺ + (ρ−1)·η⁻)/OPT, which equals 1 (optimal) under perfect predictions and degrades to the conventional ρ-approximation when no prediction is given. For maximization problems (Theorem 3), the ratio is 1 − ((ρ−1)·η⁺ + η⁻)/OPT. The refined Steiner Tree algorithm (Theorem 5) achieves a 2α-approximation regardless of prediction error, with the false-positive contribution capped by (α−1)·Σ c(e) over the top min{k−1, |X̂\X*|} MST edges, and the experimental evaluation on PACE 2018 Challenge graphs (deferred to the full version) demonstrates near-optimal solutions in near-linear time where conventional algorithms achieve only rough approximations.

## Baselines & Comparisons

This paper does not include a direct numerical comparison table against competing learning-augmented methods; the `compares_to` list is empty. The primary implicit baseline is the conventional (prediction-less) ρ-approximation algorithm for each problem: the learning-augmented algorithm strictly improves upon it whenever the prediction has any accuracy (η⁺ + (ρ−1)·η⁻ < (ρ−1)·OPT for minimization), and matches it exactly when the prediction is empty. For example, the linear-time learning-augmented Vertex Cover algorithm achieves ratio 1 + (η⁺ + η⁻)/OPT versus the conventional 2-approximation, and the learning-augmented Clique/Independent Set algorithm achieves 1 − (η⁺ + η⁻)/OPT versus the conventional n^{1−o(1)} inapproximability barrier. The only empirical comparison (against the PACE 2018 winning Steiner Tree solver by Ruiz et al.) is reported in the full version of the paper and is not included in this camera-ready text.

## Relation to Prior Work

This paper extends the learning-augmented algorithms paradigm (initiated by Kraska et al. 2018 and Lykouris and Vassilvitskii 2021) from online and warm-start settings to offline combinatorial optimization, where the goal is improving approximation ratios rather than running time. It builds directly on classic approximation algorithms—Mehlhorn's MST heuristic for Steiner Tree, Goemans-Williamson's V-join algorithm for perfect matching, and Bar-Yehuda and Even's linear-time vertex cover algorithm—as black-box components within a unified reduction. The key departure from prior work is accepting infeasible predictions (not just feasible solutions) and providing a systematic black-box transformation that works for an entire class of selection problems, rather than ad-hoc problem-specific constructions.

## Why It Matters / Open Questions

This is the first systematic framework showing that predictions can break known hardness barriers (e.g., the UGC-based 2-approximation barrier for Vertex Cover) while maintaining near-linear running time, with matching lower bounds proving the black-box approach is tight for the class as a whole. The refined Steiner Tree algorithm demonstrates that problem-specific structure can yield further improvements beyond the generic bound, opening a path for tailored learning-augmented algorithms. Open questions include extending the framework to non-selection problems (clustering, scheduling, submodular objectives) and identifying other problems where refined analyses can exploit additional structure to beat the generic guarantee.

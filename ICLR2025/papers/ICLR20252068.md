## Problem

State-of-the-art training-free VLM adaptation methods like DMN require task-specific hyperparameter tuning (often on the test set itself), while label propagation approaches like ZLaP rely on computationally expensive closed-form solutions, static graphs that ignore the test data manifold, and raw cosine similarity biased by irrelevant visual features. The paper asks how to perform label-efficient VLM adaptation that fully exploits the unlabeled test sample manifold without any task-specific tuning or additional external data.
![Teaser figure](../imgs/ICLR20252068/cropped_page1_idx0.webp)

## Input / Output

The method consumes a stream of test images (encoded by a frozen VLM vision encoder such as CLIP-RN50 or ViT-B/16), a set of text prompts formed by combining class names with templates (encoded by the VLM text encoder and averaged per class to form prototypes), and optionally a small set of few-shot labeled images. It outputs a single class label per test sample in an inductive, streaming fashion—each new sample triggers a dynamic graph expansion and a few iterations of label propagation before producing its prediction. No gradient updates or model parameter changes occur; the entire adaptation is inference-time graph computation.

## Method

ECALP constructs a KNN graph over text prototypes, few-shot samples, and test samples, with edges computed via modality-specific nearest-neighbor search and a context-aware re-weighting scheme: feature dimensions with high variance across text prompts are up-weighted (capturing discriminative semantics), while dimensions with high variance across few-shot samples are down-weighted (suppressing intra-class noise). Labels propagate iteratively (T=3 steps) with prototype and few-shot labels reset after each iteration to prevent label leakage, replacing the expensive closed-form Laplacian inversion. For inductive inference, a dynamic graph expansion mechanism inserts each new test sample by replacing the weakest KNN edge per existing node, reducing graph construction from O(d·N³) to O(d·N²). A power operation (γ=10) on edge weights further sparsifies the graph to prune cross-class connections, and pseudo-labels from prior samples are attenuated (β=0.2) to warm-start propagation for subsequent samples.

## Results

On zero-shot fine-grained categorization across 11 benchmarks, ECALP achieves a mean top-1 accuracy of 64.00% with CLIP-RN50 and 70.54% with CLIP-ViT-B/16, outperforming the strongest baseline DMN* (63.37%/70.47%) which requires test-set hyperparameter tuning. On style-transfer tasks (ImageNet-A/V2/R/Sketch), ECALP reaches 47.73%/64.92% mean accuracy, surpassing all training-free and training-based competitors. On out-of-distribution ImageNet-C (severity 5, 15 corruptions), ECALP achieves 14.28%/29.50% average accuracy, a consistent ~2–5% gain over the next-best method TDA. Inference time is 28.0 ms per sample on ImageNet (RN50), comparable to other training-free methods and ~30× faster than training-based approaches like TPT (898.7 ms).

## Baselines & Comparisons

ECALP consistently outperforms all 16 compared baselines on the primary fine-grained zero-shot benchmark (Table 1). Against the closest competitor DMN (62.02% RN50 / 69.29% ViT mean), ECALP gains +1.98%/+1.25% without requiring the task-specific fusion hyperparameter that DMN* (63.37%/70.47%) searches over the test set. The label-propagation-based ZLaP† (59.06%/67.72%) trails ECALP by ~5%/~3% and additionally requires an external unlabelled training set to build its graph. On style-transfer tasks (Table 2), ECALP (47.73%/64.92% mean) beats TDA (46.63%/63.89%), DMN (46.49%/63.80%), and even training-based CoOp/CoCoOp (42.43%/59.14% RN50; 59.14%/59.91% ViT). On out-of-distribution ImageNet-C (Table 3), ECALP leads TDA by ~1%/~1.2% and DMN by ~1.8%/~2% average accuracy across 15 corruption types. In few-shot settings (Fig. 2), ECALP surpasses DMN, APE, TIP-Adapter, and TIP-X across 1/2/4/8/16 shots on 11 datasets. Computationally, ECALP (28.0 ms/sample) is on par with TDA (26.7 ms) and DMN (30.1 ms) while being ~30× faster than training-based TPT (898.7 ms) and DiffTPT (2472.5 ms).

## Relation to Prior Work

This paper extends the label propagation framework (Zhu & Ghahramani, 2002; Zhu et al., 2003) to VLM adaptation, directly building on ZLaP (Kalantidis et al., 2024), which first applied label propagation to zero-shot CLIP classification. The key departures from ZLaP are threefold: replacing the computationally expensive closed-form solution with an iterative scheme that resets prototype labels each step, introducing dynamic graph expansion to support inductive (streaming) inference without an external unlabeled dataset, and adding context-aware feature re-weighting that uses text-embedding variance statistics to suppress irrelevant dimensions in VLM vision features. The method also positions itself against DMN (Zhang et al., 2024b), which similarly exploits test samples but requires task-specific hyperparameter tuning for branch fusion, and against prompt-tuning and adapter-based methods that incur training or augmentation costs.

## Why It Matters / Open Questions

ECALP offers a practical, training-free, and tuning-free recipe for adapting VLMs to fine-grained and out-of-distribution classification, achieving SOTA across 30+ test scenarios with a single fixed hyperparameter set — a meaningful simplification for deployment where per-task tuning is infeasible. The dynamic graph expansion reducing complexity from O(d·N³) to O(d·N²) makes transductive-style inference viable in streaming settings, and the context-aware re-weighting provides a lightweight mechanism to counteract the known issue of VLM vision features encoding task-irrelevant information (background, style). Open questions include how the method scales to very large test sets (the iterative propagation cost grows with graph size), whether the re-weighting strategy generalizes to non-CLIP VLMs with different feature geometries, and whether the approach extends naturally to multi-label or open-vocabulary settings where the fixed prototype set assumption breaks down.

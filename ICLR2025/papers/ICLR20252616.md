## Problem

Prior theoretical analyses of SSMs demonstrated that a single SSM layer cannot perform dynamic token selection, a key capability of Transformers, but these results only considered SSM layers in isolation. In practice, SSMs are always interleaved with fully connected (FNN) layers, yet no theory characterized the combined system. This paper asks whether SSMs combined with FNN layers can provably match Transformers in input-dependent token extraction.
![Teaser figure](../imgs/ICLR20252616/cropped_page1_idx0.webp)

## Input / Output

For the synthetic tasks (input copying, associative recall, induction heads, selective copying), inputs are finite sequences of words from a dictionary W, converted to one-hot vectors and embedded to D-dimensional tokens; outputs are autoregressively generated via a decoding layer that maps the final hidden state to a vocabulary distribution. For nonparametric regression, inputs are infinite sequences of d-dimensional tokens in [0,1]^d drawn from a measure P_X, and the predicted value is read from the single token at index 0 after clipping. The genomic experiment uses DNA base sequences as input and produces a binary class label.

## Method

The architecture alternates SSM convolution layers (with sinusoidal filters parameterized by learnable frequencies and amplitudes, generalizing both standard SSMs and Hyena) with token-wise ReLU FNN layers, preceded by an embedding layer. The central result (Lemma 3.3) proves that an SSM layer sandwiched between two FNN layers can approximate the softmax-weighted sum of values determined by key–query inner products, thereby replicating the attention mechanism's dynamic token selection. Concretely, the preceding FNN computes exponential-weighted representations of the query and keys, the SSM performs the position-dependent convolution, and the following FNN aggregates the weighted values. Using this lemma, the paper shows that 2-layer SSM+FNN architectures solve input copying and associative recall with poly-log parameters (avoiding the linear memory lower bound for single SSMs), and that SSMs achieve the same minimax-optimal convergence rate as Transformers for estimating piecewise γ-smooth functions in nonparametric regression.

## Results

The paper's main results are theoretical: two-layer SSMs (SSM+FNN+SSM+FNN) with polylog parameters (D, L, W, S, log B ≲ log³⁷ ε⁻¹ log⁴² V log⁸|W|) achieve error ε on input copying (Theorem 3.1), and O(polylog|W|) parameters suffice for associative recall (Theorem 3.2). For nonparametric regression on piecewise γ-smooth functions, SSMs+FNNs achieve the same minimax estimation rate n^(−2a†/(2a†+1)) as Transformers (Theorem 4.6). Empirically, two-layer SSMs with sufficiently expressive FNN layers match Transformer performance on input copying and associative recall, while single-layer SSMs degrade significantly as hidden state dimension decreases.

## Baselines & Comparisons

The paper compares three architectures: single-layer SSMs (SSM+FNN), two-layer SSMs (SSM+FNN+SSM+FNN), and Transformers. On both input copying and associative recall (Figure C.1), two-layer SSMs achieve performance comparable to Transformers, particularly when the FNN layers have sufficient depth, while single-layer SSMs underperform—especially at small hidden state dimensions. This confirms the theoretical prediction that the FNN layers before and after the SSM are essential for dynamic token selection. On nonparametric regression (Figure C.2), two-layer SSMs mitigate the sharp loss increase seen in single-layer SSMs as hidden state dimension shrinks. Theoretically, the key comparison is with Takakura & Suzuki (2023): SSMs+FNNs match the exact parameter complexity O((1/ε)^(1/a†) polylog(1/ε,V)) and convergence rate n^(−2a†/(2a†+1)) that Transformers achieve, closing the gap identified by Jelassi et al. (2024) who showed single SSM layers require O(V log|W|) memory for input copying.

## Relation to Prior Work

This paper extends the theoretical analysis of SSMs by studying them in combination with fully connected neural networks (FNNs), which prior theoretical work largely ignored. It builds directly on Takakura & Suzuki (2023) for the piecewise γ-smooth function class and nonparametric regression framework, on Jelassi et al. (2024) for the input copying task and the demonstration that single SSM layers underperform Transformers, and on the Hyena convolution filter (Poli et al., 2023) for the SSM layer definition. The key conceptual departure is showing that the standard SSM+FNN architecture can mimic the attention mechanism's dynamic token selection, addressing a gap where prior SSM theory either lacked quantitative Transformer comparisons or considered only linear SSM layers without nonlinearities.

## Why It Matters / Open Questions

This provides the first theoretical justification for why the standard alternating SSM-FNN architecture used in practice (e.g., Mamba, Hyena) can match Transformers on tasks requiring input-dependent token selection, countering the narrative that SSMs' fixed filters fundamentally limit their expressiveness. However, the paper explicitly does not address whether these theoretical constructions are reachable through gradient-based optimization, and the parameter counts involve extremely large polylog constants (e.g., log^37, log^42), leaving a significant gap between theory and practice. Open questions include extending the analysis to data-dependent SSM variants (Mamba), linear attention, and specific parameterizations like diagonal state matrices used in practice.

## Problem

While deep networks empirically outperform kernel and linear methods through feature learning, the exact mechanism by which useful features are discovered during gradient descent remains unclear. Existing analytical tools (NTK, deep linear models, single-layer studies) either cannot capture non-linear data-dependent feature learning or lack faithfulness guarantees for post-hoc interpretations. This paper hypothesizes that the core mechanism is label function discontinuities acting as attractors for model function discontinuities, but testing this requires an architecture where both sets of discontinuities can be explicitly enumerated.

## Input / Output

The method consumes d-dimensional numerical feature vectors (tabular data, with d ranging from 7 to 2400 in experiments) and produces a binary class label via a scalar output. Unusually, the DLGN's output decomposes exactly into a sum over m^L paths, each being a product of half-space indicator functions times a scalar path value, making all model discontinuities enumerable as mL hyperplanes in input space. The DLGN-DT variant additionally outputs a full oblique decision tree by recursively clustering learned hyperplanes and splitting data, with no retraining of the extracted tree.

## Method

The Deep Linearly Gated Network (DLGN) decomposes the model into a gating network (a deep linear network whose effective weights V^ℓ = W^ℓW^{ℓ-1}…W^1 define hyperplanes in input space) and a value network (another deep linear network producing path scalars). The output is the sum over all paths π of f_π(x)·g_π, where f_π is a product of half-space indicators from the gating network and g_π is the product of value-network weights along the path. For training, the hard indicator functions are replaced by sigmoids σ(βa) to enable backpropagation through the gating network. The key mechanistic insight is that all model discontinuities reduce to the mL neuron hyperplanes, which can be directly compared to the ODT node hyperplanes of the label function; experiments on COB-ODT synthetic data show these hyperplanes cluster around label discontinuities during training, with the root node attracting the most hyperplanes despite having near-zero information gain. The DLGN-DT procedure exploits this by recursively training DLGNs on data splits, applying DBScan clustering to the learned hyperplanes, and using the largest cluster center as the next tree node hyperplane.

## Results

On the synthetic COB-ODT datasets (where all fixed-feature and greedy tree methods provably struggle), DLGN-VT achieves 98.4% test accuracy on SDI (d=20), 95.8% on SDII (d=100), and 62.2% on SDIII (d=500), consistently outperforming all baselines. On SDI, DLGN-VT exceeds the next-best method (ReLU at 90.6%) by 7.8 points and the best tree algorithm (Zan-DT at 84.9%) by 13.5 points. On 20 real-world tabular datasets, DLGN achieves competitive accuracy with Random Forest, matching or exceeding it on most datasets (e.g., 85.7% vs. 86.1% on Adult, 91.6% vs. 91.3% on Bank, 94.7% vs. 94.2% on Covertype).

## Baselines & Comparisons

On the synthetic COB-ODT datasets, DLGN variants decisively outperform all 9 baselines. On SDI, DLGN-VT (98.4%) beats ReLU (90.6%) by 7.8 points, DisNN (89.8%) by 8.6 points, and the best ODT learner Zan-DT (84.9%) by 13.5 points; kernel methods (SVM 76.5%, SVL 63.4%) and greedy tree methods (CART 57.3%, RF 65.9%) perform near chance. On SDII (d=100), the gap widens: DLGN-VT (95.8%) exceeds ReLU (82.3%) by 13.5 points and all tree/kernel methods by 20+ points. On the hardest setting SDIII (d=500), all methods converge to 59–65%, with DLGN (65.1%) marginally ahead of SVM (62.3%) and ReLU (62.1%). On 20 real-world tabular datasets, DLGN is competitive with Random Forest (the strongest baseline), matching or exceeding it on most datasets while outperforming SVM, GLN, DisNN, and CART consistently; the gap to RF is typically within 0.5–1.5 points.

## Relation to Prior Work

The DLGN architecture directly operationalizes the two-model decomposition (gating network for sub-network selection + deep linear value network) proposed by Lakshminarayanan & Vikram Singh (2020) for ReLU networks, making it an explicit, trainable architecture rather than an analytical lens. It also shares the data-dependent gating philosophy of Gated Linear Networks (Veness et al., 2021; Budden et al., 2020) and Disjunctive Normal Networks (Sajjadi et al., 2016), but departs from them by retaining a deep linear gating network whose effective hyperplanes can be exactly enumerated, enabling a clean discontinuity-based analysis of feature learning. Conceptually, the paper positions itself against the NTK/kernel-methods line of work by arguing that the key advantage of feature learning is the alignment of model discontinuities with label function discontinuities—a mechanism invisible to fixed-kernel analyses.

## Why It Matters / Open Questions

The paper provides a concrete, testable hypothesis (label discontinuities attract model discontinuities during SGD) and a clean experimental setting (COB-ODTs) where kernel methods provably fail, offering a rare mechanistic window into feature learning that goes beyond kernel approximations. The DLGN-DT procedure—extracting an oblique decision tree directly from trained DLGN parameters—demonstrates a level of structural interpretability unavailable in standard ReLU networks. However, the attraction mechanism remains conjectural (no theoretical proof), the primary evidence comes from synthetic COB-ODT data, and the real-world tabular results, while competitive, do not dramatically outperform random forests. Open questions include proving the attraction dynamics theoretically, understanding why the first layer is 'idle' under the deep-linear gating parameterization, and whether the findings generalize to non-piecewise-linear label functions.

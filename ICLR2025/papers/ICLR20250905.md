## Problem

Policymakers and researchers lack an open-source benchmark to quantify the cybersecurity capabilities and risks of LM agents, particularly at the professional level. Existing CTF benchmarks (InterCode-CTF, NYU CTF Dataset) are limited to high school and university-level tasks with subjective difficulty ratings, and concurrent efforts by UK AISI and OpenAI are not publicly available. The 2023 US Executive Order on AI explicitly calls for benchmarks to measure these dual-use risks, but no framework existed that combined professional-level tasks, objective difficulty grounding, and granular subtask evaluation.

## Input / Output

Each task provides a textual description, local starter files (source code, configs, encrypted artifacts) placed in a Kali Linux Docker container, and optional remote task servers accessible via network calls within a shared Docker network. The agent produces structured responses containing five fields (Reflection, Plan/Status, Thought, Log, Action), where Action is either a bash command executed in the environment or an Answer submission. Scoring is binary for full tasks (flag string match) and fractional for subtasks (proportion of subtask questions answered correctly), with efficiency metrics tracking token usage and wall-clock time.

## Method

Cybench specifies 40 professional-level CTF tasks from four competitions (HackTheBox, SekaiCTF, Glacier, HKCert) spanning six categories, with objective difficulty grounded in first solve time (FST) ranging from 2 minutes to 24 hours 54 minutes. Each task is decomposed into sequential subtasks with individual questions and answers, enabling partial-credit evaluation and comparison between unguided and subtask-guided modes. The agent follows an act-execute-update loop in a Kali Linux container, using a structured prompt inspired by Reflexion and ReAct that elicits reflection, planning, and reasoning before each bash action. The paper evaluates 8 models (GPT-4o, Claude 3.5 Sonnet, o1-preview, Claude 3 Opus, Llama 3.1 405B, Mixtral 8x22b, Gemini 1.5 Pro, Llama 3 70B) across four agent scaffolds (structured bash, action-only, pseudoterminal, web search), finding that FST is a strong difficulty indicator and that scaffolding effects are model-dependent.

## Results

On Cybench (40 professional-level CTF tasks), Claude 3.5 Sonnet achieves the highest unguided performance at 17.5%, GPT-4o the highest subtask-guided performance at 17.5%, and OpenAI o1-preview the highest subtask performance at 46.8%. Without subtask guidance, the top four models (Claude 3.5 Sonnet, GPT-4o, Claude 3 Opus, o1-preview) solve tasks with a first solve time (FST) up to 11 minutes, but no model solves any task with FST above 11 minutes. The most difficult task in the benchmark has an FST of 24 hours and 54 minutes, a 136× increase over the hardest task solved. With subtask guidance, GPT-4o extends the highest FST solved to 52 minutes, and Claude 3.5 Sonnet with pseudoterminal access reaches 2 hours 3 minutes.

## Baselines & Comparisons

The paper does not compare against external agent baselines; instead it benchmarks 8 LMs and 4 agent scaffolds. Among models, Claude 3.5 Sonnet leads on unguided performance (17.5% vs. 12.5% for GPT-4o and 10.0% for Claude 3 Opus and o1-preview), while o1-preview leads on subtask performance (46.8% vs. 43.9% for Claude 3.5 Sonnet), suggesting o1-preview makes more incremental progress even when it cannot complete full tasks. For agent scaffolds (3 attempts, max taken), Claude 3.5 Sonnet benefits from pseudoterminal access, improving unguided performance from 17.5% to 20.0% and subtask-guided from 17.5% to 27.5%, with the highest FST solved jumping from 52 min to 2 hours 3 min. In contrast, GPT-4o underperforms with pseudoterminal (10.0% unguided vs. 17.5% structured bash) due to inconsistent command formatting, though web search helps recover to 15.0% unguided. The structured bash scaffold with Reflection/Plan/Thought/Log fields consistently outperforms the action-only scaffold for both models on unguided and subtask-guided metrics, confirming that structured reasoning aids cybersecurity task solving.

## Relation to Prior Work

This paper extends the CTF-based LM agent evaluation line initiated by InterCode-CTF (high-school level, PicoCTF) and the NYU CTF Dataset (university level, CSAW) to professional-level challenges drawn from four distinct competitions, replacing subjective point-based difficulty with objective first-solve-time (FST) metrics. It builds on agent architectures from ReAct and Reflexion for structured prompting, and on the general LM-agent-for-cybersecurity work (PentestGPT, HackingBuddyGPT, Fang et al.), but departs by introducing subtasks for granular partial-credit evaluation and by systematically comparing four agent scaffolds (structured bash, action-only, pseudoterminal, web search) across eight models. Unlike the closed evaluations by UK AISI and OpenAI, Cybench is fully open-source with continuous-integration-verified task solvability.

## Why It Matters / Open Questions

Cybench provides the first open, reproducible, professional-level benchmark for quantifying the cybersecurity capabilities and risks of LM agents, directly addressing a gap flagged by the 2023 US Executive Order on AI. The sharp capability cliff at ~11 minutes FST (136× below the hardest task) and the model-dependent effect of scaffolding (pseudoterminal helps Claude 3.5 Sonnet but hurts GPT-4o) are practically important for both safety assessment and agent design. Open questions include whether future agents can bridge the 'insight gap' on multi-step cryptographic exploits, whether specialized agents will diverge from generalist ones on FST-weighted metrics, and how train-test overlap (especially for Claude 3.5 Sonnet's later cutoff) affects measured capability.

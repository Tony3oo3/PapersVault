## Problem

All prior efficient algorithms for Testable Learning with Distribution Shift (TDS learning) are restricted to binary classification, leaving nonconvex regression problems—particularly neural networks—without provably efficient TDS guarantees. While classical domain adaptation theory provides generalization bounds in terms of distributional distances, it does not yield efficient end-to-end algorithms, and no prior work handles the regression setting where the learner must either certify low test error or reject upon detecting shift.

## Input / Output

The learner receives i.i.d. labeled examples (x, y) from an unknown training distribution D and i.i.d. unlabeled examples x from the marginal D'_x of an unknown test distribution, with no assumptions on D'_x. It either rejects (signaling significant distribution shift) or outputs a hypothesis h: R^d → R whose test error is bounded by opt + λ + ε, where opt is the best training error in the function class and λ is the best joint train-test error. Labels are assumed bounded in [-M, M], and the training marginal must be either bounded and hypercontractive or have strictly subexponential tails in every direction.

## Method

The core contribution is importing classical kernel methods into the TDS framework via a data-dependent reference feature map φ built from both training and test reference examples, whose existence is guaranteed by the representer theorem. To certify that error transfers from train to test, the algorithm runs a multiplicative spectral test comparing the covariance matrices Φ = E[φ(x)φ(x)ᵀ] and Φ' = E[φ(x)φ(x)ᵀ] over the two marginals, using fresh verification samples and the kernel trick to avoid explicit high-dimensional feature computation. For bounded hypercontractive training distributions, this yields fully polynomial-time TDS learning for one-hidden-layer sigmoid networks; for unbounded strictly subexponential distributions, the method switches to uniform polynomial approximation (via multivariate Jackson's theorem for Lipschitz nets or composed layer-wise approximators for sigmoid nets) combined with moment-matching testing, achieving runtime d^{poly(1/ε)} for single ReLU neurons.

## Results

The paper provides the first provably efficient TDS learning algorithms for nonconvex regression (neural networks). For bounded hypercontractive training distributions, one-hidden-layer sigmoid networks are learned in fully polynomial time poly(d, M, 1/ε), matching the best known PAC learning runtimes. For single ReLU neurons with ε < 1/log d, the algorithm also runs in polynomial time. Under strictly sub-exponential (unbounded) training marginals, the runtime degrades to d^{poly(k log(M/ε))} for one-hidden-layer sigmoid nets and d^{poly(k 2^{t-1} log(M)/ε)} for general Lipschitz nets of depth t.

**Table 1: TDS learning runtime bounds for neural network classes.**

| Function Class | Runtime (Bounded) | Runtime (Subgaussian) |
|---|---|---|
| One hidden-layer Sigmoid Net | poly(d, M, 1/ε) | d^{poly(k log(M/ε))} |
| Single ReLU | poly(d, M) · 2^{O(1/ε)} | d^{poly(log(M)/ε)} |
| Sigmoid Nets (depth t) | poly(d, M) · 2^{O((log(1/ε))^{t-1})} | d^{poly(k log(M)(log(1/ε))^{t-1})} |
| 1-Lipschitz Nets (depth t) | poly(d, M) · 2^{Õ(k√k 2^{t-1}/ε)} | d^{poly(k 2^{t-1} log(M)/ε)} |

k = number of neurons in first hidden layer; M = label bound; t = depth. Bounded distributions have support on the unit ball.

## Baselines & Comparisons

This is a theory paper with no empirical baselines; comparisons are against prior algorithmic guarantees. The paper extends Goel et al. (2017), who gave polynomial-time PAC learning for one-hidden-layer sigmoid nets and single ReLU under bounded marginals, by adding distribution-shift robustness (TDS) at the same polynomial runtime, requiring only the additional assumption that the training distribution is hypercontractive. Compared to prior TDS learning work (Klivans et al. 2024a,b; Chandrasekaran et al. 2024), which handles only binary classification, this paper is the first to cover nonconvex regression and deeper architectures. Unlike all prior domain adaptation algorithms, no assumptions are made on the test distribution. For the unbounded (sub-exponential) case, the paper improves upon the only known agnostic learning bound for single ReLU (Diakonikolas et al. 2020a, which requires a Gaussian marginal) by achieving d^{poly(1/ε)} runtime under any strictly sub-exponential marginal, matching the known SQ lower bound.

## Relation to Prior Work

This paper extends the Testable Learning with Distribution Shift (TDS) framework of Klivans et al. (2024a) from binary classification to nonconvex regression, specifically for neural networks with Lipschitz activations. The technical core imports the kernel method (building on Goel et al., 2017) into the TDS testing phase via a novel data-dependent feature map that couples samples from both train and test distributions, combined with a multiplicative spectral concentration lemma from Goel et al. (2024). For unbounded distributions, the paper departs from the sandwiching polynomial approach used in prior TDS work and instead shows that uniform polynomial approximation (via Jackson's theorem) suffices, requiring only strictly subexponential tails rather than the full hypercontractivity assumed in prior TDS results.

## Why It Matters / Open Questions

This is the first set of provably efficient TDS algorithms for nonconvex regression, filling a significant gap since all prior TDS work was restricted to classification. The kernel-based testing technique is a reusable tool that could extend to other function classes beyond neural networks. Key limitations include the requirement for bounded/hypercontractive training distributions for polynomial-time guarantees (the subgaussian case yields quasi-polynomial runtime in d), and the results cover only relatively shallow architectures with bounded weights. Open questions include whether the hypercontractivity assumption can be further relaxed, whether the subgaussian runtime can be improved to polynomial, and whether the framework extends to deeper or wider networks without the current exponential-in-depth dependencies.

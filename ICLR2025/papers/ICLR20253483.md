## Problem

Existing BEV construction methods for multi-camera 3D perception rely on transformer attention (quadratic complexity) or deformable attention (random memory access, sparse supervision), making them computationally expensive for edge deployment in autonomous driving. It remains unclear how to adapt state space models—which offer linear-complexity sequence processing—to the cross-modal fusion problem inherent in BEV learning, where BEV queries must interact with spatially distributed image features across multiple camera views.

## Input / Output

The model consumes 6 egocentric RGB camera images (each ~1600×900) across 1–8 temporal frames, along with camera intrinsics/extrinsics and GPS data, processed through a ResNet50/101 backbone with FPN to produce multi-scale feature maps. It outputs a 100×100 (or 50×50 / 200×200) BEV grid of latent vectors, from which a deformable decoder extracts 3D bounding boxes (center, dimensions, orientation), class labels (10 classes), and velocity vectors. Notably, the BEV grid collapses all height information into a single 2D plane, and the decoder uses grouped object queries with Hungarian set matching for prediction.

## Method

MamBEV introduces Spatial Cross Mamba (XQSSM), a task-specific SSM-based cross-attention that replaces the quadratic-cost interaction between BEV queries and image features. The key mechanism: each 2D BEV query is lifted into a 3D pillar and projected onto image planes to obtain reference points; queries are then interleaved into the flattened image feature sequence at their spatially-corresponding positions (BEV Position Aware Merge), and the SSM processes the merged sequence with a reduced hidden state (N≪T). A critical design choice sets the discretization factor dt=0 for query tokens, preventing them from updating the hidden state so they only read accumulated image information, reducing per-query FLOPs. For BEV self-attention, a Hydra (bidirectional Mamba-2) layer traverses the grid in row-major order. The decoder retains deformable cross-attention for final object query refinement, and the full encoder achieves linear scaling in both memory and FLOPs with respect to image resolution, as validated by scaling experiments up to 200×200 BEV grids.

## Results

On the nuScenes validation set, MamBEV-Small (ResNet101, 4 temporal frames) achieves a NDS of 0.525 and mAP of 0.423, outperforming BEVFormerV1-Base (0.517 NDS) with fewer parameters (65M vs. 69M). With a single frame, MamBEV-Small reaches 0.444 NDS and 0.392 mAP, surpassing BEVFormerV2 (0.426 NDS) and DETR3D (0.434 NDS). The tiny variant (ResNet50, 3 frames) achieves 0.399 NDS, marginally exceeding BEVFormerV2-Tiny (0.397 NDS). Efficiency analysis shows XQSSM scales linearly with input size, using 51 GFLOPs and 6.5 GB memory at 200×200 BEV / 1600×900 image resolution, compared to 1,432.5 GFLOPs and >24 GB for standard dot-product attention.

## Baselines & Comparisons

Against BEVFormer (Li et al., ECCV 2022), MamBEV-Small with 4 frames achieves 0.525 NDS versus BEVFormerV1-Base's 0.517 NDS (+0.008), while using fewer parameters (65M vs. 69M) and fewer FLOPs. At the 3-frame setting, MamBEV-Small (0.523 NDS) surpasses BEVFormerV1-Small (0.479 NDS) by a substantial +0.044 NDS margin. Against BEVFormerV2 (Yang et al., CVPR 2023), MamBEV-Small with a single frame achieves 0.444 NDS versus 0.426 NDS (+0.018), and the tiny variant matches or slightly exceeds BEVFormerV2-Tiny (0.399 vs. 0.397 NDS). Against DETR3D (Wang et al., CoRL 2022), MamBEV-Small with one frame reaches 0.444 NDS versus DETR3D's 0.434 NDS (+0.010), with notably better mATE (0.696 vs. 0.716). The paper also notes that MamBEV-Small-Pure (without deformable attention) still outperforms PolarDETR-T and BEVFormerV1-Small, validating the SSM-based cross-attention as a viable replacement for deformable attention.

## Relation to Prior Work

This paper extends the BEV construction pipeline established by BEVFormer (Li et al., 2022) by replacing its transformer-based spatial cross-attention with a novel SSM-based mechanism called Spatial Cross Mamba (XQSSM). The SSM foundation draws directly from Mamba-2's State Space Duality formulation and Hydra's bidirectional quasiseparable matrix mixer, while the overall encoder-decoder architecture, BEV query formulation, and deformable attention decoder follow BEVFormer conventions. The key departure is the introduction of a cross-attention analogue for SSMs that fuses BEV queries with multi-camera image features at linear complexity, addressing a gap where prior SSM-for-vision work (VMamba, Vision Mamba) focused on self-attention within a single modality rather than cross-modal fusion.

## Why It Matters / Open Questions

The practical significance lies in enabling BEV perception on compute-constrained edge hardware (autonomous driving vehicles) by reducing cross-attention from quadratic to linear complexity, with measured FLOPs reductions of ~28× over full dot-product attention at large BEV scales. However, the decoder still relies on deformable attention, the implementation is acknowledged as unoptimized, and evaluation is limited to a single dataset (nuScenes) at small model scales. Open questions include whether the SSM-based approach can fully replace deformable attention in the decoder, how it scales to larger backbones and more complex scenes, and whether the linear-complexity advantage persists when the number of temporal frames grows substantially.

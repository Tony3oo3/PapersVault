## Problem

Existing jailbreak attacks (GCG, PAIR, TAP, PAP) show highly variable success rates across safety-aligned LLMs, with no single method exceeding 94% on any model and many achieving below 40% on Llama-2-Chat-13B/70B or Claude variants. This paper asks whether simple, model-adaptive attacks—leveraging each model's specific API features and vulnerabilities—can achieve near-perfect jailbreak rates on all leading safety-aligned LLMs, and whether such adaptivity is essential for accurate robustness evaluation.

## Input / Output

The method consumes a harmful request from AdvBench's 50 curated behaviors, a manually designed prompt template (with model-specific variants for GPT-4o and R2D2), and top-20 logprobs from the target LLM's first response token (when the API exposes them). It produces a 25-token adversarial suffix appended to the prompt, yielding a jailbroken response scored by GPT-4 as a semantic judge (10/10 = success). For Claude models without logprobs, the input shifts to a transfer suffix optimized on GPT-4 or a prefill string, and the output is still a full LLM generation evaluated identically.

## Method

The core attack combines three building blocks: (1) a manually crafted prompt template with explicit rules forbidding refusal phrases and mandating an affirmative first token, (2) zeroth-order random search over a 25-token suffix that accepts mutations only when they increase the logprob of a target token (e.g., 'Sure') at the first response position, and (3) self-transfer, which reuses suffixes found on easier requests as initialization for harder ones to boost query efficiency. Critically, the attack is adaptive per model: R2D2 requires an in-context learning prompt structure (targeting 'Step' instead of 'Sure'), GPT-4o needs a custom system+user split template, and Claude models are attacked via prefilling the assistant's response or transferring GPT-4-optimized suffixes. This adaptivity—changing prompt structure, target token, or attack mechanism entirely based on the target model's API and training—is what distinguishes the approach from fixed attacks like GCG and is the paper's central methodological claim.

## Results

The paper achieves 100% attack success rate (ASR, measured by GPT-4 as a semantic judge requiring a 10/10 score) on all 13 leading safety-aligned LLMs tested, using 50 harmful requests from AdvBench. The adaptive attack combines a manually designed prompt template, random search on an adversarial suffix (maximizing the logprob of the token 'Sure'), and self-transfer initialization. For models without logprob access (Claude), a prefilling attack or transfer from GPT-4 achieves 100% ASR. In the SaTML'24 Trojan Detection Competition, random search on a restricted token set achieves a total reward-model score of −30.22 (vs. −37.48 for ground-truth trojans), securing first place.

## Baselines & Comparisons

The proposed adaptive attack outperforms all seven baselines across every model tested. Against GCG (Zou et al., 2023), the gap is largest on Llama-2-Chat-13B/70B (100% vs. 30%/38%) and R2D2 (100% vs. 6%), while on Llama-2-Chat-7B GCG reaches 54% but the paper's method still achieves 100%. PAIR (Chao et al., 2023) is far weaker, achieving only 10% on Llama-2-Chat-7B and 60% on GPT-3.5 Turbo versus 100% for the proposed method. TAP (Mehrotra et al., 2023) peaks at 61% on R2D2 and 4% on Llama-2-Chat-7B, both far below the 100% achieved here. PAP (Zeng et al., 2024) is the closest competitor at 92% on Llama-2-Chat-7B and 94% on GPT-3.5 Turbo, but requires 10 restarts and drops to 46% with one restart, whereas the proposed method reaches 100% with a single restart. For Claude models, Persona Modulation (Shah et al., 2023) achieves 61% on Claude 2.0 and Foot-in-the-Door (Wang et al., 2024) reaches 68% on Claude 2.1, both substantially below the 100% ASR from the prefilling attack. HarmBench (Mazeika et al., 2024) baselines (GCG, PAIR, TAP) report ASRs below 40% on Llama-2-Chat-13B/70B, confirming that even a large suite of static attacks significantly underestimates vulnerability compared to adaptive methods.

## Relation to Prior Work

This paper adapts the classical random search algorithm (Rastrigin, 1963) — previously applied to vision model attacks (Square Attack) — to the LLM jailbreaking setting, replacing gradient-based methods like GCG (Zou et al., 2023) with a simpler zeroth-order approach that only requires logprobs. It departs from prior work's 'one attack for all models' paradigm by explicitly framing jailbreaking as an adaptive attack problem (following Tramer et al., 2020), where the attacker customizes prompt templates, search strategies, and even the attack mechanism (e.g., prefilling vs. random search) to each target model's specific vulnerabilities. The self-transfer technique and the model-specific prompt design (e.g., in-context learning for R2D2, system-prompt splitting for GPT-4o) represent the key methodological contributions beyond the base random search algorithm.

## Why It Matters / Open Questions

The 100% attack success rate across all tested frontier models — including the adversarially trained R2D2 and Claude models that do not expose logprobs — provides strong evidence that current safety alignment is fundamentally insufficient against even simple adaptive attacks, challenging the field's reliance on fixed attack suites (e.g., HarmBench) for robustness evaluation. The prefilling attack on Claude, requiring no optimization at all, highlights how API design choices can inadvertently create powerful attack vectors. Open questions include whether test-time defenses like SmoothLLM can be broken with new adaptive attacks, how to design defenses that are robust to the full space of adaptive strategies, and whether the GPT-4 judge's acknowledged false positives (notably on Claude 2.1) affect the validity of the 100% ASR claims.

## Problem

DETR-based 3D indoor object detectors iteratively refine object queries through multi-layer transformer decoders, but the scene point features fed into each decoder layer remain fixed, causing later layers to yield only marginal accuracy gains (e.g., GroupFree gains just 2.12 AP50 over its last six layers). The paper asks whether a State Space Model can replace the transformer decoder to simultaneously update both scene point and query point features at linear complexity, overcoming this fixed-feature bottleneck.
![Teaser figure](../imgs/ICLR20251413/cropped_page1_idx0.webp)

## Input / Output

The method consumes unordered 3D point clouds—either position-only (N×3, 50k points for GroupFree baseline) or position+RGB (N×6, 100k points for VDETR baseline)—and outputs a set of 3D oriented bounding boxes with per-object category scores. Scene points are serialized into ordered sequences via six Hilbert space-filling curves (one per decoder layer) before entering the SSM, and the encoder reduces the input to 1024 (GroupFree) or 4096 (VDETR) scene points. The decoder operates on K initial state points (256 or 512 object candidates) sampled from the encoder output, producing refined state features that feed a detection head for box and class prediction.

## Method

DEST replaces the transformer decoder with an ISSM-based decoder that models query points as system states h₀ and scene points as system inputs x, enabling simultaneous feature updates at linear complexity. The key innovation is a state-dependent SSM parameterization: Δ is expanded from M×C to M×K×C so each state point independently controls how much to attend to each scene point, and a spatial correlation module computes SSM parameters (Δ, B, C) from relative offsets between scene points and the eight vertices of each state's predicted 3D bounding box, augmented by a learnable delay kernel that suppresses distant background points. The decoder layer combines four components: Hilbert-curve serialization (six axis-priority variants across layers), an ISSM-based Bidirectional Scan (IBS) module that runs forward and backward SSM passes with depthwise convolutions, an inter-state self-attention module to model correlations among query points, and a Gated Feed-Forward Network with depthwise convolution for inter-channel and local spatial modeling. The approach is plug-and-play, dropping into existing GroupFree and VDETR backbones while retaining their encoders, spatial encodings, and detection heads.

## Results

On ScanNet V2, DEST applied to VDETR(TTA) achieves a new SOTA of 78.8 AP25 and 67.9 AP50 (highest over 5×5 trials), improving over the VDETR(TTA) baseline by +1.0 and +1.9 respectively. On SUN RGB-D, the same configuration reaches 69.2 AP25 and 52.2 AP50, also setting a new SOTA. When applied to the lighter GroupFree(L) baseline, DEST yields larger absolute gains of +4.3 AP50 on ScanNet V2 and +3.2 AP50 on SUN RGB-D, demonstrating that the simultaneous updating of scene and query features is most impactful when the baseline decoder is shallower.

## Baselines & Comparisons

DEST outperforms all 17 compared baselines on both datasets. Against the strongest DETR-based baseline VDETR(TTA), DEST gains +1.0 AP25 / +1.9 AP50 on ScanNet V2 and +1.2 AP25 / +1.1 AP50 on SUN RGB-D, establishing new SOTA. Against the expansion-based SOTA CAGroup3D, the margin is substantially larger: +3.7 AP25 and +6.6 AP50 on ScanNet V2. Vote-based methods (VoteNet, MLCVNet, BRNet, VENet) and earlier expansion-based methods (GSDN, H3DNet, FCAF3D, TR3D) are all surpassed by wide margins (≥5 AP50 on ScanNet V2). The largest relative improvement is observed when DEST is grafted onto the lighter GroupFree(L) backbone (+4.3 AP50 on ScanNet V2), confirming that the fixed-scene-feature bottleneck is most severe in shallower decoders. On SUN RGB-D, where point clouds are sparser and more occluded, DEST still consistently improves every baseline it is applied to, with the GroupFree(L)+DEST configuration closing the gap to VDETR-level performance without requiring RGB input.

## Relation to Prior Work

DEST positions itself at the intersection of DETR-based 3D object detection and selective state space models. It directly builds on GroupFree and VDETR by replacing their multi-layer transformer decoders with an ISSM-based decoder, while drawing on Mamba/Mamba2 for the selective SSM parameterization and Vision Mamba for bidirectional scanning. The key conceptual departure from prior SSM-for-point-cloud work (PointMamba, PCM) is that those methods use SSMs as feature encoders, whereas DEST repurposes the SSM as a decoder where object queries become system states and scene points become system inputs — a formulation the authors claim is the first of its kind. The Hilbert-curve serialization strategy is adapted from PTv3, and the spatial correlation module borrows the vertex-relative position encoding idea from VDETR.

## Why It Matters / Open Questions

The paper identifies a concrete and previously underappreciated bottleneck in DETR-based 3D detectors: fixed scene point features across decoder layers cause diminishing returns in later layers, and it demonstrates that SSM-based simultaneous updating of both scene and query features resolves this with linear complexity. The practical impact is a new SOTA on both ScanNet V2 and SUN RGB-D, with the largest gains (+5.3 AP50) over the GroupFree baseline. However, the improvement over the strongest baseline (VDETR) is more modest (+1.9 AP50), and the method is validated only on indoor detection; the authors acknowledge that missed detections stem from the initial candidate sampling stage, which is left unaddressed. Extending the ISSM-as-decoder paradigm to outdoor detection, segmentation, or 2D tasks remains an open question.

## Problem

Most LLM-based agents operate in a reactive paradigm, remaining dormant until explicitly prompted by a user, which limits their ability to anticipate latent needs and reduce cognitive burden. No systematic benchmark or training methodology exists for teaching agents to autonomously predict and initiate tasks from environmental observations without any explicit user query.
![Teaser figure](../imgs/ICLR20251697/cropped_page1_idx0.webp)

## Input / Output

The agent consumes a temporal sequence of structured events (timestamped user actions like keyboard/mouse inputs, browser navigation, clipboard content) alongside the current environment state (file system, open applications, web page content) and produces a JSON-structured prediction containing a Purpose field, Thoughts, a Proactive Task (or null if no assistance is warranted), and a user-facing Response. The companion reward model takes the same event trace plus a candidate task prediction and outputs a binary accept/reject judgment with a reasoning trace, enabling automatic evaluation without human annotation at test time.

## Method

The paper introduces a three-component data generation pipeline: an Environment Gym (GPT-4o-driven) that simulates realistic event sequences by conditioning on real-world events collected via Activity Watcher and maintaining entity states across time; a Proactive Agent that predicts tasks from accumulated event history; and a User Agent that simulates acceptance/rejection decisions. They first collect raw human activity data across coding, writing, and daily-life settings, then iteratively generate 6,790 synthetic events (train) and 233 real-world events (test) to form ProactiveBench. A reward model (fine-tuned LLaMA-3.1-8B-Instruct) is trained on 1,760 human-annotated entries (91.67% inter-annotator agreement) to automatically score proactiveness, achieving 91.80% F1-Score consistency with human judgment. Finally, LLaMA-3.1-8B-Instruct and Qwen2-7B-Instruct are fine-tuned on the ProactiveBench training set (3 epochs, batch 32, lr 1e-5, 8×A100), with the fine-tuned Qwen2-7B achieving 66.47% F1-Score—outperforming GPT-4o (64.60%) and all other open- and closed-source baselines.

## Results

On the ProactiveBench test set (233 real-world events), the fine-tuned Qwen2-7B-Proactive achieves the best F1-Score of 66.47% with 49.78% Precision and 100% Recall, outperforming all proprietary and open-source baselines. The fine-tuned LLaMA-3.1-8B-Proactive also reaches 66.25% F1-Score, a 11.19-point improvement over its base model (55.06%). Among proprietary models, GPT-4o leads with 64.60% F1-Score, while Claude-3-Sonnet lags significantly at 31.65% due to poor recall (27.47%). The trained reward model achieves 91.80% F1-Score in simulating human acceptance judgments, far exceeding GPT-4o (67.04%) and LLaMA-3.1-70B (67.48%).

## Baselines & Comparisons

The fine-tuned Qwen2-7B-Proactive (66.47% F1) outperforms GPT-4o (64.60%) by 1.87 points and Claude-3.5-Sonnet (62.00%) by 4.47 points, primarily through higher Precision (49.78% vs. 48.15% and 45.37%) while maintaining near-perfect Recall. The fine-tuned LLaMA-3.1-8B-Proactive (66.25%) similarly surpasses GPT-4o, with the improvement over its base LLaMA-3.1-8B (55.06%) driven by a 11.6-point Precision gain (38.16% → 49.76%). GPT-4o-mini (52.15%) and Claude-3-Sonnet (31.65%) trail substantially; the former suffers from excessive false alarms (64.73%) due to over-eager task proposals, while the latter fails to detect user needs (27.47% Recall). The reward model fine-tuned on LLaMA-3.1-8B achieves 91.80% F1-Score in mimicking human judgment, beating GPT-4o (67.04%), LLaMA-3.1-70B (67.48%), and GPT-4o-mini (63.24%), with a perfect 100% agreement on the False-Detection scenario where all baselines score below 33%.

## Relation to Prior Work

This paper carves new ground by formalizing proactive task anticipation—where an LLM agent predicts and initiates tasks purely from environmental observations and user activity traces, without any initial user query—as a distinct problem. It explicitly departs from prior 'proactive' agent work (e.g., Zhang et al. 2024 on proactive planning, Wu et al. 2024 on text-to-SQL support) that still requires a user to issue an initial prompt, and from proactive dialogue systems (Deng et al. 2023) that focus on response quality rather than task initiation. The data-driven approach combining an environment gym, simulated user agent, and a trained reward model for automatic evaluation is a novel pipeline not seen in prior agent benchmarks, drawing conceptually on context-aware computing (Schilit & Theimer, 1994) but applying it to LLM-based agents for the first time.

## Why It Matters / Open Questions

ProactiveBench is the first comprehensive benchmark (6,790 events across coding, writing, and daily-life settings) for evaluating whether LLM agents can anticipate user needs without explicit instructions, filling a clear gap in the agent evaluation landscape. The finding that even GPT-4o achieves only 64.60% F1 while a fine-tuned 7B model reaches 66.47% suggests that domain-specific training can close the gap with proprietary models on this task, but the consistently high false-alarm rates (~50%) across all models indicate the problem remains substantially unsolved. Key open questions include generalizability beyond computer-activity monitoring, reducing false alarms without sacrificing recall, and addressing the privacy implications of continuous user-activity surveillance that proactive agents inherently require.

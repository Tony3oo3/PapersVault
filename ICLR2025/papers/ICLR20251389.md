## Problem

Existing multi-turn code generation benchmarks (InterCode, MINT) cover only a narrow subset of feedback combinations, lacking full test coverage, expert-level verbal feedback, and the ability to isolate how different feedback types interact. This limits our understanding of how LLMs actually perform in realistic interactive coding scenarios where the type, quality, and coverage of feedback vary significantly.
![Teaser figure](../imgs/ICLR20251389/cropped_page1_idx0.webp)

## Input / Output

The benchmark takes a Python problem description from BigCodeBench-Full-Instruct (1,140 problems, ~5.6 test cases each with 99% branch coverage), the model's current code, and a feedback tuple Ω = ⟨f_c, {φ|f_e|f_e*}, {φ|f_v|f_v*}⟩, and produces refined code over up to 10 turns. Evaluation uses MRR (reciprocal of the turn at which correct code first appears) and Recall (binary: solved within 10 turns). In the static CONVCODEBENCH variant, the target model receives pre-generated code and feedback logs from a fixed reference model (CodeLlama-7B-Instruct) rather than its own prior outputs, enabling parallel batched inference without real-time LLM calls.

## Method

CONVCODEWORLD constructs 9 distinct interactive scenarios via the Cartesian product of compilation feedback (always present), execution feedback (none, partial 3-test-case coverage, or full TDD-style coverage), and verbal feedback (none, novice-level, or expert-level). Verbal feedback is generated by GPT-4o via in-context learning: novice feedback verbalizes raw compilation/execution outputs with potential misguidance, while expert feedback is produced by comparing the agent's code against the reference solution, with a canary-sequence analysis confirming only 2.5% ground-truth leakage. CONVCODEBENCH eliminates real-time LLM calls by pre-generating all conversation logs using a deliberately weak reference model (CodeLlama-7B-Instruct), whose unsolved code after 10 turns provides sufficient room for target models to differentiate, yielding Spearman rank correlations of 0.82–0.99 with the live environment at ~1.5% the cost of human annotation.

## Results

On CONVCODEWORLD (BigCodeBench-Full-Instruct, 1,140 problems, n=10 turns), GPT-4o-2024-05-13 achieves the highest MRR of 65.3 under the richest feedback setting ⟨f_c, f_e*, f_v*⟩, while GPT-4-0613 achieves the highest Recall of 92.5 in the same setting. In the single-turn no-feedback baseline ⟨φ,φ,φ⟩, GPT-4o scores 50.8 MRR/Recall, GPT-4-Turbo 48.0, and GPT-4-0613 46.0. Weaker open-source models with expert verbal feedback (e.g., DeepSeek-Coder-6.7B-Instruct at 82.8 Recall under ⟨f_c,φ,f_v*⟩) surpass the single-turn performance of all closed-source models. CONVCODEBENCH (static, using CodeLlama-7B-Instruct logs) achieves Spearman rank correlations of 0.82–0.99 with CONVCODEWORLD across all feedback combinations.

## Baselines & Comparisons

Against prior interactive benchmarks, CONVCODEWORLD covers all 9 feedback combinations (Table 1), whereas InterCode covers only 1 (⟨f_c, f_e*, φ⟩) and MINT covers 3 (⟨f_c, f_e, φ⟩, ⟨f_c, f_e, f_v⟩, ⟨f_c, f_e, f_v*⟩). Among evaluated models, GPT-4o leads in MRR across nearly all feedback settings, but GPT-4-0613 achieves the highest Recall (92.5 vs. 86.2 for GPT-4o) under ⟨f_c, f_e*, f_v*⟩, revealing an MRR–Recall trade-off. Llama-3.1-70B-Instruct is the strongest open-source model, matching or exceeding GPT-4-Turbo in Recall for several settings (e.g., 91.8 vs. 88.5 under ⟨f_c, f_e*, f_v*⟩). Weaker models with expert feedback dramatically close the gap: DeepSeek-Coder-6.7B-Instruct reaches 82.8 Recall under ⟨f_c, φ, f_v*⟩, surpassing GPT-4o's single-turn 50.8. ReflectionCoder-DS models, trained specifically on ⟨f_c, f_e*, f_v⟩, outperform their DeepSeek-Coder base models in that setting but underperform on unseen combinations (e.g., ReflectionCoder-DS-33B scores 81.4 vs. 85.4 Recall for DeepSeek-Coder-33B under ⟨f_c, φ, f_v*⟩). CONVCODEBENCH using CodeLlama-7B-Instruct logs maintains Spearman correlations of 0.82–0.99 with live CONVCODEWORLD, outperforming correlations obtained with DeepSeek-Coder-6.7B or GPT-4 as reference models.

## Relation to Prior Work

This paper extends the interactive code generation benchmarking line initiated by InterCode (compilation + partial execution feedback) and MINT (adding GPT-4-generated verbal feedback) by systematically combining three feedback types—compilation, execution with varying test coverage, and verbal at novice/expert levels—into nine distinct scenarios. It builds directly on BigCodeBench-Full-Instruct as the underlying problem set, converting a single-turn benchmark into a multi-turn interactive framework via DSPy. The key departure from prior work is the introduction of CONVCODEBENCH, a static benchmark using pre-generated feedback logs from a deliberately weak reference model (CodeLlama-7B-Instruct), which eliminates costly live LLM calls while maintaining strong rank correlation (0.82–0.99) with the live environment.

## Why It Matters / Open Questions

This benchmark fills a genuine gap: prior multi-turn code generation benchmarks (InterCode, MINT) offered limited feedback diversity, making it impossible to assess how models handle different real-world feedback conditions. The finding that model rankings shift across feedback combinations, and that weaker models with sufficient feedback can surpass SOTA single-turn performance, has direct implications for model selection in interactive coding assistants. Open questions include whether the generalization challenge (models trained on one feedback combination underperform on unseen ones) can be addressed through multi-feedback training, whether findings extend beyond Python/BigCodeBench, and whether the GPT-4o-simulated verbal feedback adequately captures the full range of human developer behavior. The static CONVCODEBENCH approach also raises questions about how reference model choice affects benchmark validity at scale.

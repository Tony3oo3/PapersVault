## Problem

Existing visual math benchmarks (MATHVISTA, MATHVERSE, MATH-V) contain only static problem sets, making it impossible to assess whether VLMs truly reason or merely memorize patterns. The paper identifies that state-of-the-art VLMs like GPT-4o consistently fail on minor variants of the same question (e.g., shifting an absolute value function by a non-zero amount) while solving the original correctly, exposing a critical robustness gap that static benchmarks cannot capture.

## Input / Output

Each concrete question pairs a programmatically generated image (function plots, geometric figures, graphs, charts) with a text prompt, presented to the VLM at temperature 0.0. The model produces a structured JSON response containing a full solution and a short answer (numerical value formatted to three decimal places, a multiple-choice letter, or a free-form string). Evaluation yields three metrics per model: average-case accuracy over all 5,010 concrete questions, worst-case accuracy (fraction of seed questions answered correctly across all 10 variants), and reasoning robustness (the ratio of worst-case to average-case accuracy).

## Method

DYNAMATH represents each of 501 seed questions as a hand-crafted Python program with parameterized conditions and an algorithmic solution derivation. Executing a program with randomly sampled parameters generates a concrete question instance, including a rendered image via Matplotlib or Pyglet (470 programs) or a fixed image with randomized text (31 programs). Seven variation types are supported: numerical values, geometric transformations, function types, colors, symbolic substitutions, graph structures, and real-life contexts. The evaluation protocol introduces worst-case accuracy—requiring correctness on all 10 variants of a seed question—and a reasoning robustness score (worst-case divided by average-case accuracy), alongside repetition consistency (5 repeated generations per question) to distinguish systematic reasoning failures from stochastic noise. This programmatic design enables unbounded variant generation from a fixed set of seed programs, fundamentally differing from static benchmarks where each question is a single fixed image-text pair.

## Results

On DYNAMATH (5,010 generated questions from 501 seed questions), the best closed-source model Claude-3.5 Sonnet achieves 64.8% average-case accuracy, while GPT-4o reaches 63.7% and Gemini Pro 1.5 reaches 60.5%. However, worst-case accuracy (correct on all 10 variants) drops dramatically: Claude-3.5 falls to 35.3%, GPT-4o to 34.7%, and Gemini Pro 1.5 to 26.9%—less than 55% of their average-case scores. The best open-source model, Qwen2-VL-72B, achieves 55.1% average but only 28.3% worst-case accuracy. Human performance stands at 77.3% average accuracy, revealing a 12.5% gap even for the best VLMs.

## Baselines & Comparisons

DYNAMATH evaluates 14 VLMs, making it a benchmark rather than a method comparison. Among closed-source models, Claude-3.5 Sonnet leads in average-case accuracy (64.8%) but GPT-4o edges it out with 3-shot CoT (64.9% vs. 62.5% for Claude-3.5 CoT), while Gemini Pro 1.5 consistently trails both. All closed-source models substantially outperform open-source counterparts: the best open-source model Qwen2-VL-72B (55.1%) lags the best closed-source by ~10 points. A critical finding is the average-to-worst-case accuracy gap: every model's worst-case accuracy is below 55% of its average-case accuracy, with open-source models showing even steeper drops (e.g., LLaVA-v1.5-7B drops from 16.6% to 1.8%). 3-shot CoT prompting does not consistently help—Claude-3.5 and Gemini Pro 1.5 actually degrade with CoT, while GPT-4o gains only 1.2 points. Repetition consistency (92–99%) confirms that the worst-case failures are systematic reasoning errors, not random sampling noise.

## Relation to Prior Work

This paper extends the line of work on dynamic robustness benchmarks for LLMs (Nezhurina et al., 2024; Mirzadeh et al., 2024; Qian et al., 2024) to the vision-language setting, where visual context adds a new axis of variation. It departs from static visual math benchmarks (MATHVISTA, MATHVERSE, MATH-V) by representing each seed question as a Python program that generates diverse concrete variants, enabling systematic evaluation of reasoning robustness rather than one-shot accuracy. The program-based generation approach is inspired by dynamic text benchmarks (Kurtic et al., 2024; Srivastava et al., 2024) but is the first to incorporate visual element generation (plots, geometry, graphs) alongside textual variations.

## Why It Matters / Open Questions

The finding that worst-case accuracy drops to roughly half of average-case accuracy across all 14 evaluated VLMs, combined with high repetition consistency on wrong answers, provides strong evidence that current VLMs are not performing genuine reasoning but rather pattern-matching on surface features. The memorization phenomenon (e.g., Claude-3.5 answering 2π regardless of period changes) and the consistent failure on simple visual shifts (e.g., a shifted absolute value function) highlight a fundamental gap between VLM performance and human reasoning. Open questions include whether adversarial training, RLHF with process rewards, or other robustness techniques can close this gap, and how to scale dynamic benchmark generation beyond the current human-curated 501 seed questions. A key limitation is that difficulty is capped relative to competition-level benchmarks like MATH-V, and only single variant types are applied per question rather than combined perturbations.

## Problem

Existing data science benchmarks (DS-1000, Arcade, DSEval) operate under simplified settings—short single-modality instructions, code-completion-only evaluation, and tool-constrained environments—that fail to reflect the complexity of real-world data science work. This paper asks how far current LLM-based agents are from data science experts when evaluated on realistic tasks involving long multimodal contexts, large multi-table data files, and end-to-end modeling pipelines.
![Teaser figure](../imgs/ICLR20251170/cropped_page1_idx1.webp)

## Input / Output

For data analysis tasks, the agent receives a long task introduction (mean 749 words, up to 28,487), one or more Excel workbooks with multiple sheets and tables, optional images, and a question; it must produce a multiple-choice or fill-in-the-blank answer judged by an LLM-based semantic comparison function. For data modeling tasks, the agent receives a competition description, training and testing data files (up to 487 GB), and a sample submission file; it must generate a bug-free CSV prediction file scored against the competition's native metric. The benchmark reports task-level accuracy and competition-level accuracy for analysis tasks, and Task Success Rate plus Relative Performance Gap (RPG) for modeling tasks.

## Method

DSBench constructs 466 data analysis tasks from 38 ModelOff financial challenges and 74 data modeling tasks from Kaggle competitions, deliberately preserving the long contexts, multimodal backgrounds, multi-table structures, and large data files of the original competitions. The key methodological contribution is the Relative Performance Gap (RPG) metric, which normalizes heterogeneous evaluation metrics (18 different metrics across competitions) by computing the gap between the agent's score and a baseline relative to the gap between the best human score and that baseline, enabling a single comparable score across all modeling tasks. For data analysis, answers are verified via a GPT-4o-based semantic comparison prompt rather than exact string matching, validated at 100% agreement with human judgment on a 100-sample audit. The empirical study evaluates nine vanilla LLMs/LVLMs and two agent frameworks (AutoGen multi-agent conversation and OpenAI Code Interpreter) across both task types, revealing that the best agent (AutoGen + GPT-4o) achieves only 34.12% accuracy on analysis and 34.74% RPG on modeling, versus 64.06% and 65.02% for humans.

## Results

On DSBench's 466 data analysis tasks, the best-performing agent (AutoGen with GPT-4o) achieves only 34.12% task-level accuracy and 26.72% competition-level accuracy, while the best model-only baseline (Gemini) reaches 31.55%. On the 74 data modeling tasks, AutoGen with GPT-4 achieves the highest task success rate (87.84%) and RPG (45.52%), but still trails human performance (65.02% RPG) by a wide margin. Even the strongest agent system leaves a ~30-point gap to human performance on data analysis (64.06% human accuracy vs. 34.12% best agent).

## Baselines & Comparisons

Among model-only baselines, Gemini (31.55%) outperforms GPT-4o (28.11%), GPT-4 (25.97%), and GPT-3.5 (20.39%), while Llama3-70b (23.39%) and Llama3-8b (16.95%) trail significantly, and LLaVA (11.59%) is the weakest. Wrapping GPT-4o in the AutoGen multi-agent framework boosts accuracy from 28.11% to 34.12% (+6.01 pp), and similarly lifts GPT-4 from 25.97% to 30.69% (+4.72 pp), confirming that the interaction mechanism and tool access are beneficial. However, the Code Interpreter framework with GPT-4o (23.82%) actually underperforms the vanilla GPT-4o model-only (28.11%), suggesting that the constrained single-turn code execution environment is less effective than AutoGen's multi-turn dialogue for these tasks. On data modeling tasks, AutoGen with GPT-4 achieves the best RPG (45.52%) and task success rate (87.84%), substantially outperforming Code Interpreter with GPT-4 (26.14% RPG, 54.05% success), while all systems remain well below the human RPG of 65.02%.

## Relation to Prior Work

This paper departs from existing data science benchmarks (DS-1000, Arcade, DSEval, MLAgentBench) that focus on simplified code-completion or single-step reasoning tasks, by constructing an end-to-end benchmark drawn from real financial data analysis competitions (ModelOff) and machine learning competitions (Kaggle). It also positions itself against broader agent benchmarks (SWE-Bench, WebArena, OSWorld) by emphasizing data-centric, tool-irrelevant evaluation rather than environment-specific task completion. The introduction of the Relative Performance Gap (RPG) metric addresses a gap in prior work where heterogeneous evaluation metrics across data modeling tasks could not be meaningfully averaged.

## Why It Matters / Open Questions

DSBench provides the first comprehensive, realistic evaluation framework for data science agents that captures the full complexity of real-world tasks: long multimodal contexts, large multi-table data files, and end-to-end model building. The finding that even the best agent (AutoGen + GPT-4o) achieves only 34.12% accuracy on data analysis and 34.74% RPG on data modeling—compared to 64.06% and 65.02% for humans—quantifies a substantial capability gap that motivates further research. Open questions include whether the LLM-based semantics comparison function introduces systematic bias, whether the benchmark generalizes beyond financial and tabular ML domains, and what architectural or training changes are needed to close the ~30-point gap to human performance.

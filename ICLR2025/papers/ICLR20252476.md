## Problem

Transformers can compositionally generalize to unseen combinations of previously observed constituents, but the mechanism underlying this ability remains poorly understood. This paper asks whether the multi-head attention mechanism itself provides a principled explanation for compositional generalization by revealing an implicit hypernetwork structure that reuses and recombines learned operations.
![Teaser figure](../imgs/ICLR20252476/cropped_page1_idx0.webp)

## Input / Output

For the abstract reasoning tasks, the model receives a sequence of in-context examples (input-target pairs for fuzzy logic, or 8 context panels each encoded as a K-tuple of integers for SRAVEN) and must predict the target of a final masked token. The key internal signal analyzed is the H-dimensional vector of attention scores across heads for a given key-query pair, which the paper interprets as the hypernetwork's latent code. For language modeling, the input is a standard causal token sequence and the output is next-token logits over a 32K vocabulary.

## Method

The paper shows that multi-head attention is mathematically equivalent to a linear hypernetwork: the attention scores a_{h,q,k} across H heads form a latent code that linearly combines head-specific matrices (W_h^{out} W_h^{value}) to produce a key-query-specific value network weight W_{q,k}. To strengthen this mechanism, the authors introduce HYLA, which inserts a ReLU nonlinearity between the value and output projections (making the value network nonlinear without adding parameters) and applies RMSNorm across the head index instead of softmax across keys. They further introduce SRAVEN, a symbolic Raven's Progressive Matrices benchmark with parametric difficulty control and a compositional split over rule combinations, enabling precise testing of whether models generalize to unseen rule compositions. Empirically, HYLA improves compositional generalization over both softmax and linear attention, and the latent code is shown to be structured and decodable: logistic regression on the head-index attention scores predicts the underlying task rules with high accuracy on unseen compositions.

## Results

On the fuzzy logic compositional generalization task (70% of tasks held out, 32 in-context examples), HYLA achieves an OOD R² of 81.13±7.77, substantially outperforming softmax attention (63.28±2.31) and linear attention (59.89±5.22). On SRAVEN (4-layer transformer, 20M training instances), HYLA reaches 69.13±1.90% OOD accuracy versus 56.56±1.05% for softmax attention and 56.30±1.11% for linear attention. With sufficient data and model size, all architectures reach ~80% OOD accuracy on SRAVEN, but HYLA achieves this with fewer training examples and smaller models. On C4 language modeling (50M parameters, 130B tokens), HYLA narrows the gap between linear and softmax attention, performing closely to softmax despite being a linear attention variant.

## Baselines & Comparisons

HYLA consistently outperforms both softmax attention and linear attention on compositional generalization. On the fuzzy logic task, HYLA's OOD R² of 81.13 exceeds softmax attention by ~18 points and linear attention by ~21 points, indicating that the nonlinear value network and RMSHead normalization together strengthen the inductive bias toward recombining known subfunctions. On SRAVEN, HYLA achieves 69.13% OOD accuracy versus 56.56% for softmax and 56.30% for linear attention — a gap of roughly 13 points over both baselines. The advantage is most pronounced at smaller model sizes and with fewer training examples, where HYLA reaches competitive OOD accuracy earlier in the scaling curve. On C4 language modeling, HYLA improves over linear attention and performs closely to softmax attention, suggesting the hypernetwork mechanism partially compensates for the recall limitations typically associated with linear attention variants.

## Relation to Prior Work

This paper reinterprets standard multi-head attention (Vaswani et al., 2017) through the lens of hypernetworks (Ha et al., 2017), showing that attention scores across heads form a latent code that linearly configures a value network for each key-query pair. This is conceptually distinct from the fast-weight programmer view of linear attention (Schlag et al., 2021), which constructs weights as outer products over key indices, and from the task-vector perspective on in-context learning (Hendel et al., 2023; Todd et al., 2024), which identifies task-specific directions in deeper hidden activations. The paper then introduces HYLA, a minimal modification of linear attention that makes the value network nonlinear, and SRAVEN, a symbolic variant of Raven's Progressive Matrices that extends prior image-based benchmarks (Zhang et al., 2019; Barrett et al., 2018) with parametric difficulty control and an explicit 'finding correspondences' challenge.

## Why It Matters / Open Questions

The hypernetwork reinterpretation provides a mechanistic account for why multi-head attention supports compositional generalization: the shared hypernetwork across all key-query pairs incentivizes reuse and recombination of latent codes, which empirically manifests as a structured latent space predictive of the subtask being performed. The SRAVEN benchmark offers a controlled, parametric testbed for compositional generalization that prior image-based Raven benchmarks lacked, and the finding that a simple nonlinearity in the value network (HYLA) closes much of the gap between linear and softmax attention on both reasoning tasks and language modeling suggests practical architectural implications. Key open questions include whether the structured latent code persists in large pretrained models, whether other granularities of hypernetwork parameterization (query-level, sequence-level) are beneficial, and whether the compositional generalization gains transfer to more complex, open-ended reasoning settings.

## Problem

Existing point cloud completion methods either require supervised training on specific object categories (limiting generalization to unseen data) or, in the case of test-time SDS-complete, depend on manually crafted text prompts for each partial point cloud. This paper addresses the gap of achieving robust, category-agnostic completion at test time without any additional human-provided information such as text descriptions.
![Teaser figure](../imgs/ICLR20251860/cropped_page1_idx0.webp)

## Input / Output

The method takes a partial 3D point cloud (3D coordinates only, no color or texture) as input and produces a completed, uniformly sampled point cloud at 16,384 points. The partial input is first rendered into a colorized reference image using a normal-map colorization strategy, which then serves as the sole conditioning signal for the diffusion model—no text prompts or category labels are required. The output is extracted from 3D Gaussian centers and resampled via an SDF-based Grid Pulling module to ensure uniform density across both original and completed regions.

## Method

COMPC is a three-stage test-time framework built on 3D Gaussian Splatting (GS) and Score Distillation Sampling (SDS) from the image-conditioned Zero 1-to-3 diffusion model. In Partial Gaussian Initialization, a reference viewpoint is estimated by minimizing Chamfer Distance plus depth regularization over 5,000 candidate poses, and 3D Gaussians are initialized from the partial points with unit opacity and normal-map colorization to render a reference image. In Zero-shot Fractal Completion, new Gaussians for missing regions are optimized using SDS guidance from Zero 1-to-3 conditioned on the reference image at random viewpoints, while a Preservation Constraint (Chamfer Distance between observed Gaussian centers and the original partial points from the reference viewpoint) maintains geometric integrity; a fractal strategy freezes the original Gaussians and only optimizes the new ones. In Point Cloud Extraction, surface points are selected via multi-view frontmost-Gaussian filtering, then a Grid Pulling module (an MLP-based SDF trained with far/near pulling losses and a merge layer from RFNet) resamples a uniform 128³ grid to produce the final output. Key design choices include binary opacity quantization to prevent Gaussian center dispersion, shared scalar scaling to preserve point-like geometry, and the use of Zero 1-to-3 (image-conditioned) rather than text-conditioned diffusion to eliminate the need for manual prompts.

## Results

On synthetic point clouds (10 objects), COMPC achieves an average CD/EMD of 1.43/1.88, substantially outperforming the best supervised baseline ShapeFormer (3.68/4.44). On the Redwood dataset, COMPC achieves 1.35/2.03 (in-domain) and 2.57/3.17 (out-domain) CD/EMD, surpassing the test-time baseline SDS-Complete (2.15/3.16 and 3.33/4.69 respectively) and all supervised methods. The advantage is most pronounced on out-of-domain objects, where COMPC reduces CD by ~23% and EMD by ~32% compared to SDS-Complete.

## Baselines & Comparisons

COMPC outperforms all six supervised baselines (PoinTr, SeedFormer, PointAttN, ShapeFormer, SVDFormer, AdaPoinTr) on both synthetic and Redwood data, with the largest margins on out-of-domain objects where supervised methods degrade significantly (e.g., SVDFormer jumps from 2.64 to 4.42 CD in-domain to out-domain, while COMPC only goes from 1.35 to 2.57). Against the test-time baseline SDS-Complete, COMPC wins on both in-domain (1.35 vs 2.15 CD) and out-domain (2.57 vs 3.33 CD) Redwood categories, while also being ~130× faster (15 min vs ~1950 min per point cloud). On ShapeNet, COMPC is slightly behind supervised methods on known categories (e.g., 1.38 vs 1.21 CD on chairs) but clearly surpasses them on unknown categories (1.09 vs 1.72–2.48 CD on pistols, 1.41 vs 1.72–3.47 CD on towers), confirming its generalizability advantage. The method also produces reasonable completions on LiDAR point clouds from KITTI, though no quantitative ground truth is available for that setting.

## Relation to Prior Work

This paper extends the test-time point cloud completion paradigm introduced by SDS-complete (Kasten et al., 2024), which used text-conditioned Stable Diffusion with SDS guidance on a NeRF/SDF representation. The key departures are: (1) replacing text prompts with an image-conditioned diffusion model (Zero 1-to-3) that takes a rendered reference image of the partial point cloud, eliminating manual annotation; (2) substituting the SDF/NeRF representation with 3D Gaussian Splatting for dramatically faster optimization (~15 min vs ~1950 min); and (3) adopting a fractal strategy (from PFNet) where only missing-region Gaussians are optimized while the partial input is frozen. The Grid Pulling module for uniform resampling is adapted from NeuralPull, and the overall pipeline is motivated by DreamGaussian's demonstration that GS can be optimized with SDS from Zero 1-to-3.

## Why It Matters / Open Questions

The practical elimination of text prompts and the ~130× speedup over SDS-complete make test-time point cloud completion significantly more deployable in real-world scanning pipelines where neither category labels nor detailed descriptions are available. The large performance gap over supervised methods on out-of-domain data (e.g., 2.57 CD vs 3.09–4.42 CD on Redwood out-domain) highlights a fundamental limitation of trained completion networks that this approach sidesteps. Open questions include: whether the 15-minute per-object optimization can be further reduced for real-time applications, how the method handles thin or highly occluded structures (acknowledged failure mode), and whether the approach extends to multi-object scenes or dynamic environments beyond single-object completion.

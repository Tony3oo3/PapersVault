## Problem

Existing speculative decoding methods for LLM inference acceleration either require additional draft modules or extensive training, limiting their plug-and-play applicability across models and tasks. The closest layer-skipping approaches (Self-SD, LayerSkip) demand time-intensive offline optimization (7.5–20 hours) or pretraining, while Jacobi-based plug-and-play methods misalign with autoregressive pretraining and yield suboptimal speedups. SWIFT addresses this by enabling adaptive, on-the-fly layer-skipping that requires no auxiliary model or training.
![Teaser figure](../imgs/ICLR20253112/cropped_page1_idx0.webp)

## Input / Output

SWIFT takes a standard text prompt and a target LLM (e.g., LLaMA-2-13B/70B, CodeLLaMA) as its only inputs—no separate draft model or training data is needed. It produces generated text with a theoretically guaranteed identical output distribution to vanilla autoregressive decoding (via speculative sampling). During inference, the method internally accumulates a context window of 32 LLM-generated tokens to drive layer-set optimization before transitioning to the acceleration phase, and the KV cache of the target LLM is reused by the draft model to reduce redundant computation.

## Method

SWIFT operates in two phases. First, context-based layer set optimization: the draft model (formed by skipping intermediate layers of the target LLM) is validated against LLM-generated context tokens using a matchness score (exact-match ratio), with candidate skipped-layer sets proposed via a hybrid of random search and interval Bayesian optimization (Bayesian step every β=25 iterations). Second, confidence-aware inference acceleration: the optimized layer set is fixed, and the draft model autoregressively predicts up to N_D=25 tokens, with early-stopping when the top-1 confidence drops below a threshold ε, and dynamic verification where each draft token is extended with top-k candidates (k∈{1,3,5,10} based on confidence) that are linearized and verified in parallel by the target LLM using a causal attention mask. The key insight is that LLMs exhibit task-specific layer sparsity—uniform skipping already yields ~1.2× speedup, but adaptive on-the-fly optimization of which layers to skip achieves 1.3×–1.6× while the optimization overhead is only 0.8% of total inference latency.

## Results

SWIFT achieves a 1.3×–1.6× wall-clock speedup over vanilla autoregressive decoding across LLaMA-2-13B, 13B-Chat, and 70B models on summarization (CNN/DM), mathematical reasoning (GSM8K), and storytelling (TinyStories) tasks. The token acceptance rate α remains at 98%–100% for the LLaMA-2 series under greedy decoding, with mean generated length M ranging from 2.99 to 8.21 tokens per target LLM forward pass. On code generation (HumanEval), SWIFT achieves 1.3×–1.5× speedup while preserving identical pass@1 accuracy (e.g., 0.311 for CodeLLaMA-13B). The optimization phase accounts for only 0.8% of total inference latency, with the overall speedup reaching ~1.5× during the acceleration phase.

## Baselines & Comparisons

SWIFT consistently outperforms both plug-and-play Jacobi-based baselines: Parallel Decoding (Santilli et al., 2023) actually degrades performance below vanilla (0.95×–0.99×), while Lookahead Decoding (Fu et al., 2024) achieves 1.15×–1.40×; SWIFT surpasses Lookahead by 0.1×–0.25× across all model sizes and tasks. Against Self-SD (Zhang et al., 2024), which requires ~7.5 hours of Bayesian optimization for LLaMA-2-13B, SWIFT achieves a higher speedup (1.56× vs. 1.29×) with only ~2 minutes of on-the-fly optimization—a ~200× reduction in optimization latency. Compared to LayerSkip (Elhoushi et al., 2024), which achieves a slightly higher 1.64× speedup, SWIFT delivers a competitive 1.56× while preserving the original output distribution without any training (LayerSkip requires 50k training steps on 64 A100s and alters the target LLM's distribution). On dynamic input data streams spanning five task domains, SWIFT maintains a stable 96% acceptance rate and 1.3×–1.6× speedup, whereas Self-SD's acceptance rate drops from 92% to 68% and speedup collapses from 1.33× to 1.05× under domain shift.

## Relation to Prior Work

SWIFT builds directly on the self-speculative decoding paradigm introduced by Self-SD (Zhang et al., 2024), which first proposed skipping intermediate LLM layers to form a compact draft model, and on LayerSkip (Elhoushi et al., 2024), which uses early-exit layers for drafting. However, both prior methods require time-intensive offline optimization or pretraining, making them neither plug-and-play nor generalizable across tasks. SWIFT departs from this lineage by making layer-skipping SD fully on-the-fly: it replaces the offline Bayesian optimization with an adaptive, context-driven optimization that runs during inference, and it is orthogonal to the Jacobi-based plug-and-play methods (Parallel Decoding, Lookahead Decoding) that represent the other existing line of training-free SD.

## Why It Matters / Open Questions

SWIFT provides a genuinely zero-overhead, model-agnostic acceleration method that can be applied to any LLM without training or auxiliary parameters, filling a practical gap that training-required methods (Medusa, EAGLE) cannot address for unsupported or newly released models. The finding that layer sparsity is task-specific and that larger models exhibit greater sparsity (scaling law) suggests the approach will become more impactful as models grow, though the current 1.3×–1.6× speedup remains modest compared to the 3×–4× achieved by trained draft heads. Open questions include whether SWIFT can be composited with Jacobi-based methods for further gains, how it behaves at 175B+ scale, and whether the fixed skip ratio can be made fully adaptive per token rather than per instance.

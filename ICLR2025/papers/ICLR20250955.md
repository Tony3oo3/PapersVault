## Problem

Existing code generation benchmarks rely solely on text input, yet real-world coding for data visualization requires integrating visual understanding of charts with textual instructions. No prior benchmark evaluates whether LMMs can ground their visual comprehension of information-dense scientific charts into executable rendering code, a task that demands simultaneous visual understanding, code generation, and cross-modal reasoning.
![Teaser figure](../imgs/ICLR20250955/cropped_page1_idx0.webp)

## Input / Output

The benchmark provides 4,800 human-curated (figure, instruction, code) triplets spanning 22 chart types and 201 subcategories, with average code length of 696 tokens. Two tasks are defined: Direct Mimic (reproduce the given chart) and Customized Mimic (reproduce the chart's style while substituting new data specified in the instruction). The generated Python matplotlib code is executed, and the rendered output is compared against the ground-truth figure; if execution fails, all scores are zeroed.

## Method

ChartMimic is constructed via a five-step curation pipeline: scraping ~174K figures from CC BY 4.0 arXiv papers (post-Feb 2024), filtering to 15,800 Matplotlib-generated PDFs, expert-driven diversity/information-density selection by five domain specialists down to 279 charts, manual supplementation from Matplotlib gallery and forums to 600 prototypes (with color schemes altered to reduce data leakage), and manual code/instruction writing plus 3× augmentation to reach 4,800 triplets. Evaluation employs a multi-level metric: a high-level GPT-4o similarity score (0–100) comparing rendered charts, and a low-level score computed via a code tracer that monitors ground-truth and generated code execution to extract text, layout, type, and color elements, scored with F1. The overall score averages high- and low-level components. Empirical analysis of 17 LMMs reveals that self-reflection prompting (a System 2 reasoning mechanism) significantly improves performance for capable models like GPT-4o and InternVL2-76B, while weaker models degrade, and that hallucinations in text recognition and confusion between visually similar chart types are the dominant error modes.

## Results

On ChartMimic's Direct Mimic task, GPT-4o achieves the highest overall score of 81.2 (93.2% execution rate, 79.0 low-level avg, 83.5 GPT-4o high-level score), while the best open-weight model InternVL2-Llama3-76B reaches 58.5. On Customized Mimic, GPT-4o scores 83.2 and InternVL2-Llama3-76B scores 64.7. The average score gap between GPT-4o and the best open-weight model is 20.6 points across both tasks, and even GPT-4o's average across the two tasks is only 82.2, indicating substantial room for improvement.

## Baselines & Comparisons

GPT-4o dominates all proprietary models, outperforming Claude-3-opus (60.3) by 20.9 points and GeminiProVision (53.6) by 27.6 points on Direct Mimic overall score. The best open-weight model, InternVL2-Llama3-76B (58.5), trails GPT-4o by 22.7 points on Direct Mimic and by 18.5 points on Customized Mimic (64.7 vs. 83.2), confirming a persistent gap between open-weight and proprietary LMMs on this benchmark. Notably, the 4.2B Phi-3-Vision-128K (39.8) substantially outperforms the 34.8B LLaVA-Next-Yi-34B (20.1) by nearly 20 points, showing that parameter count alone does not determine chart-to-code capability. On Customized Mimic, most models improve over Direct Mimic (e.g., GPT-4o: 81.2→83.2; InternVL2-Llama3-76B: 58.5→64.7), as user-provided data alleviates the burden of text recognition, though Cogvlm2-19B and Qwen2-VL-2B actually decline. The SelfReflection prompting method boosts GPT-4o from 81.2 to 84.8 and InternVL2-Llama3-76B from 58.5 to 61.1 on Direct Mimic, but degrades smaller models (InternVL2-2B drops from 23.5 to 16.9), highlighting that System 2 reasoning is essential for effective self-correction.

## Relation to Prior Work

ChartMimic extends the multimodal code generation benchmark lineage (MMCode, Plot2Code, Design2Code) by shifting from simple or web-scraped visual inputs to information-intensive scientific charts with 22 types and 201 subcategories, all human-curated to mitigate data leakage. It departs from chart understanding benchmarks (ChartQA, CharArXiv) that output text answers by requiring executable Python code as output, thereby testing the full pipeline of visual comprehension → cross-modal reasoning → code synthesis. The multi-level evaluation (GPT-4o high-level score plus code-tracer-based F1 on text/layout/type/color) is more fine-grained than the single pass-rate or GPT-4-score metrics used by prior code generation benchmarks.

## Why It Matters / Open Questions

The persistent ~20-point gap between the best open-weight model (InternVL2-Llama3-76B) and GPT-4o, despite open models matching proprietary ones on public leaderboards, reveals that complex visual-to-code grounding remains an unsolved capability gap. The finding that self-reflection improves GPT-4o but degrades smaller models (e.g., InternVL2-2B drops from 23.5 to 16.9) suggests a reasoning-capability threshold for effective self-correction, with implications for how prompting strategies should be applied across model scales. Limitations include restriction to Python/matplotlib, potential annotation bias from manual curation, and inability to score fine-grained sub-icons like markers; open questions include whether multimodal reasoning prompt strategies or dedicated chart-pretraining can close the open-source gap.

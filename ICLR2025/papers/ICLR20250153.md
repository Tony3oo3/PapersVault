## Problem

Fair k-means clustering requires each cluster to contain a specified proportion of points from each group, but this constraint destroys the locality property that makes vanilla k-means tractable: points are forced away from their nearest center, so simply running k-means on the full dataset or a single group (as in Bera et al. 2019, Böhm et al. 2021) yields suboptimal center locations. The prior state-of-the-art approximation ratio is (2+√ρ)², and the k-sparse Wasserstein Barycenter problem shares the same gap. This paper asks whether fairness constraints can be encoded directly into the center-selection stage to close the approximation gap.

## Input / Output

The method takes a weighted point set P ⊂ R^d partitioned into m groups, a target number of clusters k, per-group fairness bounds α, β ∈ [0,1]^m, and an approximation parameter ε > 0. It produces k cluster centers S together with an assignment matrix φ_S : P × S → [0,1] (fractional) or {0,1} (integral), where each row sums to 1 and each column satisfies the group-proportion constraints. For the k-sparse Wasserstein Barycenter variant, the output is a discrete distribution with support size ≤ k whose weights are determined by a fixed-support WB linear program; for the strictly fair variant, the output is a guaranteed no-violation integral assignment.

## Method

The core contribution is a two-stage 'Relax and Merge' framework. In the Relax stage, the algorithm constructs an ε-approximate centroid set T (Matoušek, 2000) over P, which provably contains approximate centroids of every potential fairness-preserving cluster—not just Voronoi cells—and then solves a linear program to obtain the optimal fractional assignment φ_T* with cost ≤ (1+O(ε))·OPT while preserving all fairness constraints. Each point t ∈ T is then adjusted to the centroid π(t) of its assigned weighted points. In the Merge stage, a ρ-approximate vanilla k-means is run on the adjusted set π(T) to select k centers S, and a second LP yields the final assignment φ_S*, giving an overall (1+4ρ+O(ε)) approximation. For strictly fair k-means, the ε-approximate centroid set is replaced by a 2-approximate fairlet decomposition (computed via pairwise Hungarian matchings), yielding a (2+6ρ) no-violation integral solution. Rounding from fractional to integral for disjoint groups uses a hub-guided minimum-cost circulation network that guarantees at most 2-violation without increasing cost.

## Results

Theoretically, Algorithm 1 achieves a (1+4ρ+O(ε))-approximation for (α,β)-fair k-means, yielding a 5+O(ε) ratio with a PTAS for k-means, improving upon the previous state-of-the-art (2+√ρ)² ≈ 9+O(ε). For strictly fair k-means with no violation, Algorithm 2 achieves (2+6ρ) ≈ 8+O(ε), also improving over the prior (2+√ρ)² ≈ 9+O(ε). Empirically, Algorithm 1 produces the lowest clustering cost across all tested datasets for (α,β)-fair k-means, and for k-sparse Wasserstein Barycenter it achieves a 10%–30% cost reduction over the IJCAI24 baseline.

## Relation to Prior Work

This paper builds on Matoušek's ε-approximate centroid set (a computational geometry structure) and repurposes it as the 'relaxed solution' in a novel two-stage 'Relax and Merge' framework for fair k-means. Prior approaches (Bera et al. 2019; Böhm et al. 2021) apply vanilla k-means directly to the full dataset to obtain center locations and handle fairness only in the assignment stage; this paper instead encodes fairness constraints into the center-selection stage by using the centroid set to cover all potential fairness-preserving cluster centroids. The framework is then extended to k-sparse Wasserstein Barycenter (building on the observation from Yang & Ding 2024 that it is a special case of fair k-means) and to strictly fair k-means via fairlet decomposition (extending Chierichetti et al. 2017 from two groups to m groups).

## Why It Matters / Open Questions

The framework improves the state-of-the-art approximation ratio for fair k-means from (2+√ρ)² ≈ 9+O(ε) to 5+O(ε) with a PTAS, and similarly improves k-sparse Wasserstein Barycenter and strictly fair k-means (2+6ρ vs. (2+√ρ)²). The key open question the authors identify is obtaining an integral solution without any fairness violation for the general (non-disjoint, non-strict) case. The paper also raises the broader question of whether the Relax-and-Merge framework extends to other fairness notions (proportionally fair, socially fair clustering) and to general metric spaces, where the lack of an analogue to the ε-approximate centroid set remains a fundamental obstacle.

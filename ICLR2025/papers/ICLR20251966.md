## Problem

Existing off-policy evaluation and learning (OPE/L) methods for contextual bandits rely on the common support assumption, which is violated when the logging policy is deterministic or when new actions are introduced, rendering standard IPS and DR estimators biased or inapplicable. While prior work addresses partial support deficiency, no method handles the extreme cases of fully deterministic logging or entirely new actions, particularly under few-shot data. This paper introduces the Cross-Domain OPE/L formulation, where logged data from multiple source domains with different data generation processes can be leveraged to evaluate and learn policies in a target domain facing these challenges.

## Input / Output

The method consumes logged bandit data from K domains (one target, K−1 source), each with its own context distribution, logging policy, and reward distribution, along with a domain clustering function φ(k) that groups similar domains and a reward regression model q̂(x,a) trained via Random Forest with 3-fold cross-fitting. The density ratio p^φ(T)(a|x) in the importance weights is estimated nonparametrically via uLSIF from observable logged data rather than requiring known distributions. The output is a scalar policy value estimate V̂_COPE(π) for OPE and a policy gradient vector ∇_θ V̂_COPE-PG(π_θ) for OPL, both targeting the target domain's policy value.

## Method

COPE decomposes the expected reward q^k(x,a) into a domain-cluster effect g(x,a,φ(k)) shared by domains in the same cluster and a domain-specific effect h(x,a,k). The domain-cluster effect is estimated unbiasedly via multiple importance weighting over all logged data from domains in the target cluster φ(T), using the averaged joint distribution p^φ(T)(a|x) in the denominator to account for varying context and action distributions across domains. The domain-specific effect is handled by a reward regression term computed only on target domain data, reducing bias to depend on the regression error rather than absolute reward accuracy. The estimator requires only the milder Common Cluster Support condition (exploration within the cluster suffices, not within the target domain) and is provably unbiased under the Conditional Pairwise Correctness condition, which requires the regression model to preserve relative reward differences between cluster members and the target. COPE-PG extends this to policy gradient learning by multiplying the importance-weighted residual by ∇_θ log π_θ(a|x) and adding the regression-based gradient term, enabling policy optimization even under deterministic logging and new actions.

## Results

On the KuaiRec recommendation dataset (K=10 domains, n^k=100 per domain), COPE achieves MSE of 1.08–1.16 across all new-action ratios (0%–80%), while IPS(T) degrades from 5.64 to 6.53 and DR(T) from 4.33 to 3.80. Under deterministic logging for 1000 users, COPE maintains MSE ≈ 1.22 versus 7.00 for IPS(T) and 4.45 for DR(T). In the few-shot regime (1 data point per action), COPE outperforms the best baseline (DM) by a factor of 6.79 in MSE. For OPL, COPE-PG achieves a relative policy value of ~1.41–1.45 across all settings, consistently outperforming IPS-PG(T) (1.24–1.34) and DR-PG(T) (1.27–1.36).

## Baselines & Comparisons

COPE outperforms all five baselines (IPS-T, IPS-ALL, DR-T, DR-ALL, DM) across every experimental setting. Against target-only methods (IPS-T, DR-T), COPE reduces MSE by 3–6× as the ratio of new actions or the fraction of deterministic-logging users increases, because these methods suffer growing bias from violated common support. Against naive all-domain methods (IPS-ALL, DR-ALL), COPE avoids the substantial bias introduced by ignoring cross-domain DGP differences, achieving lower MSE in most settings (e.g., 1.08 vs. 2.94 at 80% new actions for IPS-ALL). In the few-shot regime (n^T/|A|=1), COPE's MSE is 6.79× lower than the best baseline DM. For OPL, COPE-PG achieves the highest relative policy value in most configurations, particularly excelling at selecting new actions where target-only methods (IPS-PG-T, DR-PG-T) cannot gain any value from unexplored actions. The one notable exception is at 1000 deterministic-logging users in OPL (Table 4), where DR-PG(ALL) reaches 1.51 vs. COPE-PG's 1.41, though COPE-PG remains the most stable across all data-size and determinism settings.

## Relation to Prior Work

This paper introduces a new problem formulation (Cross-Domain OPE/L) that departs from standard single-domain OPE by allowing access to logged data from multiple source domains with different context and reward distributions. Methodologically, it builds on multiple importance weighting (Agarwal et al., 2017) for the domain-cluster effect and reward regression for the domain-specific effect, with the decomposition idea inspired by OffCEM (Saito et al., 2023). The authors explicitly distinguish their setup from OPE under covariate shift (Uehara et al., 2020), which assumes identical reward distributions across domains, and from support-deficiency methods (Sachdeva et al., 2020; Felicioni et al., 2022), which cannot handle deterministic logging or entirely new actions. COPE is shown to be a strict generalization of DR (cluster size 1) and DR-ALL (cluster size K), unifying these estimators under a single framework parameterized by cluster size.

## Why It Matters / Open Questions

This work addresses a practical gap in OPE/L where deterministic logging policies and new actions—common in medical, recommendation, and advertising systems—render existing estimators inapplicable. The theoretical contributions (Common Cluster Support condition, Conditional Pairwise Correctness) provide clear, analyzable conditions under which COPE is unbiased even when the target domain has zero exploration. Key limitations include the reliance on heuristic domain clustering (empirical average rewards as embeddings), evaluation on a single real-world dataset (KuaiRec), and the acknowledgment that the CPC condition is not expected to hold in practice. Open questions include developing principled clustering methods for cross-domain OPE and combining the approach with pessimistic estimation techniques.

## Problem

Neurosymbolic programs (NSPs) aim to combine symbolic interpretability with neural expressiveness, but incorporating neural modules inevitably introduces black-box components that undermine the program's overall interpretability. Additionally, designing effective symbolic operators in NSPs requires significant domain expertise and careful per-dataset customization. This paper asks whether pretrained LLMs can serve as inherently interpretable neural modules within NSPs, eliminating the expressiveness-interpretability trade-off.

## Input / Output

The method accepts three input modalities: RGB creature screenshots from the Palworld game, contrastive text captions derived from fine-grained bird images (CUB), and symbolic variable assignments (e.g., 'x1=A1; x2=B1; x3=C1') for synthetic tasks. Class names are anonymized with symbols (e.g., 'class_1') to prevent label-name shortcuts. The output is twofold: a predicted class label and a tree-structured interpretable decision program composed of natural-language rules at each node connected by conditional branching, which can be read and applied by humans without domain expertise or executed by other LLMs.

## Method

The key insight is that a pretrained LLM with different prompts instantiates distinct conditional probabilistic sub-models of a shared 'SuperNet,' making each prompt an interpretable neural module. The framework defines a minimal DSL with only three constructs—input, conditional branching (switch), and a prompted-LLM module—yielding tree-structured programs. Training uses a divide-and-conquer algorithm: a top-down tree traversal expands the most error-prone leaf node (scored by error count), and at each new node a learner LLM summarizes predictive rules from the assigned data subset via a RuleSum procedure. Beam search over multiple candidate trees prevents local minima, and the divide-and-conquer structure ensures each LLM module handles a simplified sub-problem, making the overall system more error-tolerant and converging faster than unstructured prompt optimization.

## Results

On IL-Bench-Vision (Palworld), LSP achieves 96.83% mean classification accuracy, surpassing the second-best method APO (76.38%) by ~20 percentage points and OPRO (28.09%) by ~69 points. On IL-Bench-Language, LSP reaches 78.53% mean accuracy, outperforming PromptAgent (72.40%) by ~6 points and APO (70.67%) by ~8 points. In the XAI comparison (Table 2), LSP with GPT-4V as learner achieves 95.67% accuracy versus ProtoTree's 84.33% and Decision Tree's 68.20%, while human raters following LSP's learned rules reproduce 90.36% of predictions (vs. 72.74% for ProtoTree). LSP also retains 90–100% of original test accuracy on out-of-distribution variants, demonstrating strong domain-shift robustness.

## Baselines & Comparisons

LSP decisively outperforms all five prompt optimization baselines on both vision and language tasks. On IL-Bench-Vision, LSP (96.83%) beats APO (76.38%) by ~20 points, TreePrompt (67.20%) by ~30 points, PromptAgent (66.33%) by ~30 points, APE (47.45%) by ~50 points, and OPRO (28.09%) by ~69 points. On IL-Bench-Language, LSP (78.53%) leads PromptAgent (72.40%) by ~6 points and APO (70.67%) by ~8 points, with the gap widening on harder symbolic tasks (DT-Hard: LSP 96.83% vs. APO 77.83%). Against traditional XAI methods on vision, LSP (95.67% with GPT-4V) surpasses ProtoTree (84.33%) by ~11 points and XGBoost Decision Tree (68.20%) by ~27 points. In human interpretability evaluation, raters following LSP's learned rules achieve 90.36% accuracy versus only 72.74% for ProtoTree, confirming that LSP's natural-language decision rules are more transferable to humans. Search and inference costs for LSP (232.54s search, 0.13s inference) remain comparable to the PO baselines, indicating the structural overhead is negligible.

## Relation to Prior Work

This paper extends Neurosymbolic Programming (NSP) by replacing its neural network modules with prompted-LLM modules, arguing that a fixed LLM parameterized by different natural-language prompts constitutes a 'SuperNet' of interpretable conditional sub-models. It departs from traditional NSP (Chaudhuri et al., 2021; Shah et al., 2020) by eliminating the need for manually designed DSL operators and co-optimization of neural parameters, reducing the grammar to just three components (input, conditional branching, LLM module). The learning algorithm also builds on prompt optimization methods (APO, OPRO, PromptAgent) but shows that structuring prompts into a divide-and-conquer tree substantially outperforms flat prompt search, positioning LSP as a principled hybrid between NSP and prompt optimization.

## Why It Matters / Open Questions

The introduction of IL-Bench fills a genuine gap: existing LLM benchmarks (BigBench, SuperNatural Instructions) are zero-shot solvable and thus cannot evaluate whether a model actually extracts predictive rules from labeled data, which is the core requirement of interpretable learning. The Palworld-based vision datasets cleverly sidestep data contamination by using post-cutoff content. Open questions include whether the minimal 3-operator DSL generalizes beyond classification (e.g., regression, multi-step reasoning), whether program complexity can be regularized during search, and whether the approach scales to larger label spaces or more complex decision structures. The reliance on LLM API access for both learning and inference also raises practical deployment concerns.

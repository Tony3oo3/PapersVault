## Problem

Automating complex desktop tasks via GUI interaction faces three intertwined challenges: agents must acquire up-to-date domain knowledge for constantly evolving applications, plan over long horizons with interdependent subgoals, and ground actions in dynamic, non-uniform visual interfaces. Existing MLLM-based GUI agents lack a unified framework that combines experiential learning, structured hierarchical planning, and an interface tailored to the discrete, stateless reasoning paradigm of large language models.
![Teaser figure](../imgs/ICLR20250824/cropped_page0_idx0.webp)

## Input / Output

The agent receives a natural language task instruction along with a dual observation: a raw screenshot for salient visual reasoning and an annotated accessibility tree where each UI element is tagged with a unique integer ID and augmented with OCR-parsed text blocks (matched via IoU against existing tree elements) to improve grounding. Output is a sequence of single grounded primitive actions per timestep (e.g., click(element_id, num_clicks, button_type), type(text, element_id, overwrite), hotkey(keys)), constrained to a bounded discrete action space of 11 predefined operations, plus a topologically sorted subtask plan generated at the Manager level.

## Method

Agent S integrates three components in a closed loop: (1) Experience-Augmented Hierarchical Planning, where a Manager fuses online web knowledge (via Perplexica search) with retrieved narrative memory (abstractive full-task summaries) to produce a subtask queue, and each Worker retrieves episodic memory (concrete step-by-step subtask trajectories) plus trajectory-reflection advice to generate grounded actions; (2) a continual memory update mechanism that bootstraps memories through self-supervised exploration on synthetic tasks and then updates them during inference, with a Self-Evaluator that summarizes successful trajectories as textual rewards rather than storing raw trajectories; (3) an Agent-Computer Interface (ACI) that provides the dual-input observation and constrains actions to language-based primitives referencing element IDs, ensuring one discrete action per step for immediate environment feedback. The key architectural insight is replacing reinforcement learning with retrieval-as-learning: the agent improves by accumulating and retrieving summarized experiences, and the ACI's bounded action space is specifically designed to elicit better MLLM reasoning by matching the model's discrete, stateless decision-making cadence.

## Results

On the OSWorld benchmark (369 tasks, Ubuntu), Agent S with GPT-4o achieves a 20.58% overall success rate, nearly doubling the best MMAgent baseline (11.21%) for an 83.6% relative improvement. Agent S with Claude-3.5-Sonnet achieves 20.48%, also substantially outperforming all baselines. On WindowsAgentArena (154 tasks, Windows), Agent S with GPT-4o achieves 18.2% overall success rate versus 13.3% for the NAVI baseline, demonstrating cross-OS generalizability without any adaptation. The largest absolute gains appear in Professional tasks (36.73% vs. 18.37% best baseline) and Daily tasks (27.06% vs. 24.50%).

## Baselines & Comparisons

Agent S (GPT-4o) achieves 20.58% on OSWorld, outperforming the MMAgent baseline (GPT-4o) by 9.37 percentage points (11.21%), CRADLE (7.81%) by 12.77 points, FRIDAY/OS-Copilot (11.11%) by 9.47 points, and OpenInterpreter (8.94%) by 11.64 points. The improvement is most pronounced in Professional tasks (36.73% vs. 18.37% for MMAgent GPT-4V) and Daily tasks (27.06% vs. 24.50%), where retrieval-augmented planning provides the largest benefit. On WindowsAgentArena, Agent S (18.2%) outperforms the NAVI baseline (13.3%) by 4.9 points without any Windows-specific adaptation, with particularly strong gains in Windows System tasks (45.8% vs. 29.2%) and Coding (29.2% vs. 9.1%). Agent S also surpasses MMAgent with GPT-4V (12.17%) and all other MMAgent variants, establishing a new state-of-the-art on OSWorld.

## Relation to Prior Work

Agent S extends the Agent-Computer Interface (ACI) concept from SWE-agent (Yang et al., 2024) from software engineering to GUI-based desktop control, replacing coordinate-based or Set-of-Mark grounding with a bounded, language-centric action space over an OCR-augmented accessibility tree. It integrates and unifies several threads from the MLLM agent literature—hierarchical planning, retrieval-augmented generation, and memory-augmented reasoning—into a single closed-loop framework for computer control, departing from prior GUI agents (MMAgent, CRADLE, OS-Copilot) that typically operate in a flat, single-agent loop without structured subtask decomposition or self-supervised experience accumulation. The experience-augmented planning is distinct from prior RAG-for-agents work in that it retrieves at two granularities (full-task narrative summaries and step-level episodic trajectories) and uses a self-evaluator to distill trajectories into abstractive textual rewards rather than storing raw exemplars.

## Why It Matters / Open Questions

The 83.6% relative improvement on OSWorld and the zero-shot transfer to WindowsAgentArena demonstrate that structured experience retrieval and a well-designed ACI can substantially close the gap between MLLM-based GUI agents and human-level computer use, while the open-source release lowers the barrier for the community. However, absolute success rates remain low (~20%), execution and grounding errors still dominate failures, and the framework depends on proprietary frontier models (GPT-4o, Claude-3.5-Sonnet) with no efficiency metric (steps or wall-clock time) reported. Key open questions include whether the experiential learning and ACI ideas transfer to smaller open-source MLLMs, how to reduce the persistent grounding bottleneck, and how to evaluate agents on the Pareto frontier of accuracy versus task completion time.

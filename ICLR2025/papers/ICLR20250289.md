## Problem

State-space models (SSMs) such as S4 and S4D require carefully designed initializations (e.g., HiPPO) and reduced learning rates for the state matrix A to train stably, yet the underlying reason for this fragility has not been unified. The paper shows via Hankel operator theory that most LTI systems parameterized by (A,B,C) have rapidly decaying Hankel singular values (i.e., low numerical rank), making them inherently low-expressiveness and numerically unstable under the small perturbations introduced during gradient-based training.

## Input / Output

The model consumes a sequential input u ∈ R^L (e.g., a flattened 32×32×3 CIFAR-10 image as 1024 vectors of length 3, or a text/list sequence) and produces an output sequence y ∈ R^L of the same length, which is then pooled and decoded into a class label for classification tasks. Each LTI block uses n=64 latent states; the full sCIFAR-10 model has 4 layers × 128 channels = 512 independent single-input/single-output LTI systems. A key design choice is the trainable discretization period Δt, which controls the effective time span of the continuous-time convolution kernel and thus the memory window relative to the sequence length.

## Method

HOPE replaces the canonical (A,B,C,D) parameterization of each LTI system with the Markov parameters h ∈ C^n of a finite Hankel matrix H̄_{i,j} = 1_{i+j<n} h_{i+j}, which defines a discrete LTI system and, via the bilinear transform with Δt=1, an associated continuous-time system. At inference, the continuous transfer function G(s) = Σ_{j=0}^{n-1} h_j ((1+s)/(1-s))^{-j-1} is sampled nonuniformly at L FFT-derived nodes (scaled by 1/Δt), and the output is computed as y = Re(iFFT(FFT(u) ∘ g)), achieving Õ(L+n) time and O(L) space — matching S4D's complexity while using only n complex parameters per LTI block versus 3n in S4D. Two theoretical guarantees distinguish HOPE: (i) a random Hankel matrix almost surely has Ω(n) relative singular values above ε/√ln n (Theorem 3), so random initialization is already high-rank; and (ii) the transfer function is globally Lipschitz in h with constant √n (Theorem 4), so training does not require reparameterization or reduced learning rates. Additionally, because |H̄_{0,t}| = h_t for t < n, the system's memory does not decay within the window [0, n], enabling long-range retrieval by choosing a small Δt.

## Results

On the Long-Range Arena benchmark, HOPE-SSM achieves the best average accuracy of 87.85%, outperforming S5 (87.46%), LiquidS4 (87.32%), Reg.S4D (86.60%), S4 (86.09%), and S4D (84.89%). It attains the top score on Text (89.83%), Retrieval (91.80%), and Pathfinder (95.73%), and is competitive on ListOps (62.60%) and Path-X (98.45%). On the noise-padded sCIFAR-10 task, HOPE-SSM significantly outperforms S4D, demonstrating its non-decaying long-term memory capability.

## Baselines & Comparisons

HOPE-SSM achieves the highest average LRA score (87.85%), beating S5 (87.46%) by 0.39 points and LiquidS4 (87.32%) by 0.53 points. It wins decisively on Text (89.83% vs. 89.60% for Spectral SSM and 89.31% for S5), Retrieval (91.80% vs. 91.40% for S5), and Pathfinder (95.73% vs. 95.60% for Spectral SSM). It narrowly trails LiquidS4 on ListOps (62.60% vs. 62.75%) and Image (88.68% vs. 89.50%), and S5 on Path-X (98.45% vs. 98.58%). Compared to the canonical S4D baseline, HOPE-SSM improves the average by 2.96 points (87.85% vs. 84.89%), with the largest gains on Text (+3.65%) and Pathfinder (+2.67%). On the noise-padded sCIFAR-10 task, HOPE-SSM significantly outperforms S4D, confirming its non-decaying memory advantage over the exponentially decaying memory of canonical LTI systems.

## Relation to Prior Work

This paper departs from the canonical (A,B,C,D) parameterization of LTI systems used in S4, S4D, S5, and Mamba by instead parameterizing the underlying continuous-time dynamics through the Markov parameters of a discrete Hankel matrix. It builds directly on Hankel operator theory (Glover, 1984) and reduced-order modeling to provide a unified lens explaining why HiPPO initialization and careful learning-rate scheduling are necessary: random (A,B,C) parameterizations almost surely yield fast-decaying Hankel singular values (low numerical rank), while the HiPPO-LegS scheme avoids this. The approach is conceptually distinct from Stable-SSM (Wang & Li, 2023), which reparameterizes A for stability, and from Spectral SSM (Agarwal et al., 2023), which uses spectral filtering, because HOPE retains a true LTI system while changing only the parameterization space.

## Why It Matters / Open Questions

The Hankel singular value framework gives practitioners a concrete diagnostic for SSM quality and a principled explanation for the fragility of canonical SSM training, which could guide future architecture design beyond this specific parameterization. The 1/3 parameter reduction and elimination of the need for reduced learning rates on A are practically appealing, and the non-decaying memory within a fixed window offers a clean mechanism for long-range dependency. Open questions include whether the HOPE parameterization extends naturally to input-dependent (selective) SSMs like Mamba, whether the memory advantage persists at the scale of large language models, and how the method interacts with the parallel-scan (S5) or hardware-efficient (Mamba) training paradigms.

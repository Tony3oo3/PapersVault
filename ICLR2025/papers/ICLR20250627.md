## Problem

Linear Bellman Completeness (LBC) is known to be statistically tractable with polynomial sample complexity, but no computationally efficient algorithm existed for this setting. Standard approaches fail: quadratic exploration bonuses (e.g., LSVI-UCB) are infeasible because Bellman backups of quadratic functions are not necessarily linear, and truncation-based methods (e.g., RLSVI) break because truncated value functions lose linearity under Bellman backup. This paper provides the first computationally efficient algorithm for LBC, requiring deterministic transition dynamics but handling large action spaces, stochastic rewards, and stochastic initial states.

## Input / Output

The algorithm consumes state-action feature vectors φ(s,a) with ‖φ‖₂≤1, reward signals in [0,1], a precomputed D-optimal design over the feature space (with at most O(d²) support points), and noise variance parameters σ_h and σ_R. Unlike standard LSVI-type algorithms that initialize the covariance to the identity matrix, this algorithm initializes it from the D-optimal design to avoid requiring ℓ₂-norm bounds on parameters. The output at each round is a greedy policy π_t derived from the perturbed value function, along with the full backward value function estimates Q̄_{t,h} and V̄_{t,h} for all horizons. The constrained regression uses ℓ∞-functional-norm constraints (|⟨θ,φ(s,a)⟩|≤W) rather than ℓ₂-norm balls, since parameter norms can grow exponentially with horizon.

## Method

The core technique is null-space randomization: at each horizon step, the algorithm decomposes the D-optimal design points into span and null-space components relative to the historical data, then injects Gaussian noise only in the null space of the data covariance matrix. This ensures optimism in unexplored directions while preserving exact value estimates within the span of observed data, avoiding the exponential parameter blowup that occurs when noise is added uniformly (as in standard RLSVI). A span argument then bounds the number of out-of-span episodes by dH, since each such episode must increase the span dimension. The backward value iteration uses constrained squared-loss regression solved via the Bertsimas-Vempala random-walk algorithm for convex feasibility, which handles the exponentially many linear constraints arising from the ℓ∞-functional-norm constraint set. The D-optimal design initialization guarantees invertibility of the covariance matrices without any ℓ₂-norm boundedness assumption on the true parameters.

## Results

The paper's main theoretical guarantee (Theorem 1) establishes a regret bound of Õ(d^{5/2} H^{5/2} + d² H^{3/2} √T) for feature dimension d, horizon H, and T rounds, under exact squared loss minimization. The corresponding sample complexity (Corollary 1) is Õ(d⁴ H³ / ε²) to achieve ε-suboptimality. Notably, the regret bound is independent of the action space size, and the √T dependence is optimal (matching the bandit lower bound). The bound further improves to Õ(dH²) (independent of T up to log factors) when the reward function is known.

## Baselines & Comparisons

This is a purely theoretical paper with no empirical baselines or experimental comparisons. The paper positions its contribution against prior theoretical results for Linear Bellman Completeness (LBC): Golowich & Moitra (2024) achieve computational efficiency but with exponential dependence on action space size; Du et al. (2020) use a span argument but require deterministic initial states; Wen & Van Roy (2017) require deterministic rewards; Zanette et al. (2020b) provide statistical efficiency but via a computationally intractable optimization; and Zanette et al. (2020c) require an explorability assumption that fails for unreachable states. The present work is the first to simultaneously handle large (even infinite) action spaces, stochastic initial states, and stochastic rewards under deterministic dynamics, with a computationally efficient algorithm relying only on a convex-constrained squared loss oracle solvable via the Bertsimas–Vempala random walk method.

## Relation to Prior Work

This paper extends the RLSVI framework (Osband et al., 2016) by restricting Gaussian noise injection to the null space of the data covariance, avoiding the exponential parameter blow-up that necessitates truncation in prior randomized RL algorithms. It combines this with the span argument from Du et al. (2020) for deterministic systems, but generalizes it to handle stochastic initial states, stochastic rewards, and large action spaces simultaneously. The computational subroutine for the constrained least-squares oracle draws on Bertsimas & Vempala's (2004) random-walk convex feasibility algorithm, and the overall backward value iteration structure follows the LSVI paradigm from Jin et al. (2020), though the quadratic UCB bonus is replaced by null-space randomization since Bellman backups of quadratic functions need not be linear.

## Why It Matters / Open Questions

This is the first computationally efficient algorithm for the linear Bellman completeness setting with deterministic dynamics, large action spaces, and stochastic initial states/rewards, closing a gap where prior work could only provide statistically efficient but computationally intractable algorithms. The paper also demonstrates that common ℓ2-norm boundedness assumptions in prior LBC definitions are too restrictive (even tabular MDPs can violate them), clarifying the true structural requirements. The main limitation is the deterministic dynamics assumption; extending the null-space randomization technique to stochastic transitions remains an open challenge, as the span argument no longer guarantees exact value recovery within the data span.

## Problem

While in-context reinforcement learning (ICRL) has been empirically demonstrated, the mechanism by which a pretrained transformer discovers and implements an RL algorithm in its forward pass remains unexplained under reinforcement pretraining. Prior theoretical work (Lin et al., 2023) only covers supervised pretraining via behavior cloning, where the agent is explicitly trained to imitate a known algorithm. This paper is the first to white-box the forward pass of a transformer trained via reinforcement pretraining, where the agent is only asked to produce good value estimates with no constraint on how.

## Input / Output

The transformer takes a prompt matrix Z_0 ∈ R^{(2d+1)×(n+1)} constructed from a trajectory of an MRP: the first d rows hold state features φ(S_0),...,φ(S_n), the next d rows hold discounted successor features γφ(S_1),...,γφ(S_n), and the last row holds rewards R_1,...,R_n, with the final column serving as the query state. The output is a single scalar — the bottom-right element of the final layer's output matrix — representing the estimated value v_π(s) of the query state. As context length n grows, the value estimation error decreases even though all parameters remain fixed, confirming that learning occurs during the forward pass rather than through memorized weights.

## Method

The paper constructs explicit parameters (P_l^TD, Q_l^TD) for a linear-attention transformer such that each layer's forward pass exactly corresponds to one batch TD(0) update (Theorem 1), making the L-layer transformer equivalent to L iterations of preconditioned batch TD. Empirically, training a 3-layer autoregressive linear-attention transformer via multi-task TD pretraining (Algorithm 1) on randomly generated Boyan's chain tasks causes the learned weights to converge to the TD-implementing configuration, despite no explicit mechanism forcing this structure. Theoretically, the paper proves that the TD-implementing parameter set Θ* is an invariant set of the expected TD pretraining dynamics (Theorem 2), meaning once the optimizer enters this set it cannot leave. The framework extends to TD(λ) via a modified attention mask, residual gradient via a different Q matrix, and average-reward TD via a two-head architecture with a memory row in the prompt.

## Results

The paper's primary empirical result (Figure 1) shows that a single 15-layer linear-attention transformer with fixed parameters θ* achieves decreasing mean square value error (MSVE) as context length t increases, averaged over 300 randomly generated policy evaluation tasks with varying state spaces, transition functions, reward functions, and policies. In the main training experiment (Figure 2), a 3-layer autoregressive transformer (d=4, trained on 4000 Boyan's-chain-based MRPs via Algorithm 1) converges to parameters P₀ and Q₀ that closely match the theoretical TD construction in (7) with C_l = I_d. The paper also empirically confirms that for L=1 the learned parameters match the Corollary 1 construction, while for L=2,3,4 they match the Theorem 1 construction, and that in-context TD does not emerge if the task distribution is too easy (e.g., fixed transitions or features).

## Baselines & Comparisons

This paper does not perform standard baseline comparisons against competing methods, as its contribution is to white-box the mechanism of in-context RL rather than to propose a new algorithm that outperforms existing ones. Instead, the empirical validation is structured as a convergence check: the parameters learned by multi-task TD pretraining (Algorithm 1) are compared element-wise against the analytically constructed TD parameters from Theorem 1 and Corollary 1. The learned P₀ and Q₀ match the theoretical specifications up to a global scaling factor (since P and Q appear in the same product and can be jointly rescaled). The paper also notes that despite the transformer having the capacity to implement alternative algorithms like residual gradient (RG), pretraining consistently converges to TD rather than RG, aligning with the RL community's empirical finding that TD is superior to naive RG. No head-to-head performance comparison between in-context TD and in-context RG or other algorithms is provided.

## Relation to Prior Work

This paper extends the linear-attention transformer framework from Von Oswald et al. (2023) and Ahn et al. (2024), which showed that transformers can implement gradient descent in their forward pass for in-context supervised learning. The key departure is moving from supervised pretraining (behavior cloning, as in Lin et al. 2023) to reinforcement pretraining, where the transformer is only asked to minimize a TD loss without any explicit instruction to implement a specific RL algorithm internally. The paper also introduces an invariant-set perspective to analyze the pretraining dynamics, which is distinct from the critical-point analysis used in the gradient-descent ICL literature.

## Why It Matters / Open Questions

This is the first theoretical analysis of how in-context RL emerges from reinforcement pretraining, and the first full white-boxing of a pretrained transformer's forward pass as an RL algorithm. The invariant-set result (Theorem 2) provides a partial explanation for why TD specifically emerges, but convergence to this set is not proven, and the theory is limited to single-layer linear attention. Open questions include extending the analysis to multi-layer transformers, control tasks, softmax attention, and large-scale environments like Atari, as well as understanding whether the invariant-set structure generalizes beyond the symmetry assumptions (5.1–5.2).

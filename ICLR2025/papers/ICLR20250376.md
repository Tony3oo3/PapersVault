## Problem

Existing video understanding methods and datasets fail to simultaneously handle events that are fast (instantaneous, spanning 1-2 frames), frequent (~1 event per second), and fine-grained (over 1,000 event types). Current temporal action localization, segmentation, and fine-grained recognition approaches rely on temporally coarse features, non-overlapping snippets, or modestly fine-tuned encoders that cannot capture the subtle visual differences and precise temporal localization required for F³ events.

## Input / Output

The model takes a video clip of N RGB frames (down-scaled and cropped to 224×224) and outputs a sequence of M event-timestamp pairs, where each event is represented as a multi-label binary vector over K sub-class elements (e.g., player, court position, shot type, direction, technique, outcome) rather than a single class index. Events are defined as instantaneous moments (ball-racket contact), not temporal spans, and the benchmark supports three granularity levels: G_low (38 event types), G_mid (365), and G_high (1,108). Evaluation uses Edit Score for sequence structure and Mean F1 with ±1 frame temporal tolerance for classification accuracy.

## Method

F³ED is a three-stage end-to-end pipeline: (1) a Video Encoder (TSM backbone + bidirectional GRU) extracts frame-wise spatial-temporal features at full temporal resolution (stride=1); (2) an Event Localizer (FC + Sigmoid) performs dense per-frame binary classification to pinpoint event timestamps; (3) a Multi-label Event Classifier (FC + Sigmoid) predicts each event's type as a vector of independent sub-class probabilities rather than a single class among 1,108+ options, naturally handling the combinatorial structure and long-tail distribution. A Contextual Module (BiGRU) then refines the predicted event sequence by learning event-wise causal and logical constraints (e.g., a right-handed player cannot hit a forehand from the deuce court as 'inside-in'), correcting invalid sequences that purely visual predictions produce. The entire model is trained end-to-end with binary cross-entropy losses at each stage and can be trained on a single GPU.

## Results

On F3Set tennis (G_high, the most granular setting with 1,108 event types), F3ED (TSM + F3ED) achieves F1_evt=40.3, F1_elm=75.2, and Edit=74.0, outperforming the best baseline (TSM + E2E-Spot) by +8.9 F1_evt, +3.8 F1_elm, and +5.3 Edit. At the coarsest level (G_low, 38 event types), F3ED reaches F1_evt=68.4, F1_elm=80.0, Edit=87.2. On semi-F3 datasets (Table 5), F3ED also leads on all five benchmarks, e.g., 70.7 F1_evt on ShuttleSet vs. 70.2 for E2E-Spot, and 77.6 F1_evt on FineDiving vs. 75.8 for E2E-Spot.

## Baselines & Comparisons

F3ED outperforms all nine baselines across every granularity level and every semi-F3 dataset. The strongest baseline is TSM + E2E-Spot [24], which F3ED beats by 8.9 F1_evt at G_high (40.3 vs. 31.4) and by 7.8 F1_evt at G_low (68.4 vs. 60.6); the gap narrows on F1_elm (75.2 vs. 71.4 at G_high) because E2E-Spot already captures element-level signals reasonably well. Among head architectures, E2E-Spot (GRU-based) consistently surpasses transformer-based ActionFormer [72] and G-TAD [70], while MS-TCN [19] and ASFormer [71] trail further behind, suggesting recurrent temporal modeling is more effective than attention for short, dense event sequences. On the encoder side, TSM with frame-wise features dominates; clip-wise I3D [5] and video-transformer VTN [52] underperform substantially (F1_evt 22.7 and 14.8 vs. 40.3 at G_high), and skeleton-based ST-GCN++ [17] / PoseConv3D [18] lag due to missing shot-direction cues. On the five semi-F3 generalization datasets (Table 5), F3ED leads on all of them, with the largest margin on FineGym (70.9 vs. 62.1 F1_evt over E2E-Spot) and the smallest on ShuttleSet (70.7 vs. 70.2), confirming that the multi-label + CTX design transfers beyond tennis.

## Relation to Prior Work

This paper builds directly on E2E-Spot (Hong et al., ECCV 2022), which introduced end-to-end detection of temporally precise, fine-grained events, extending it with a multi-label classification head (replacing multi-class) and a BiGRU-based contextual module that refines event sequences using inter-event causal correlations. Conceptually, it departs from the broader temporal action understanding literature (TAL, TAS, TASpot) by arguing that frame-wise dense processing and end-to-end training are necessary for events spanning only 1–2 frames, whereas prior methods rely on non-overlapping snippets or downsampled features that are too coarse. The multi-label formulation is a deliberate departure from the standard multi-class paradigm used in FineGym, ShuttleSet, and P2ANet, motivated by the combinatorial explosion of 1,108 event types where many differ in only one sub-class element.

## Why It Matters / Open Questions

F3Set is the first benchmark to simultaneously satisfy all three F3 criteria (fast, frequent, fine-grained) with ~1,000 precisely timestamped event types and multi-level granularity, filling a gap where prior datasets addressed only subsets. The general annotation toolchain lowers the barrier for domain experts to create new F3 datasets beyond sports, potentially enabling applications in industrial inspection, autonomous driving, and surveillance. Open questions include whether the approach scales to even larger event taxonomies, whether multi-modal LLMs can eventually handle F3-level temporal reasoning, and whether the contextual module's gains persist in longer, more complex sequences. The finding that GPT-4 fails at F3 event understanding despite grasping basic video context highlights a significant gap in current multi-modal LLM capabilities for fine temporal reasoning.

## Problem

Existing unsupervised meta-learning methods construct training tasks using simple data augmentations, creating a significant distribution gap between training and test tasks, and typically assume training and test data come from the same domain. This limits generalization to unseen tasks and often requires fine-tuning at test time. The paper asks whether in-context learning in transformer architectures can be combined with a more realistic task creation strategy to enable robust cross-domain few-shot classification from purely unlabeled data.

## Input / Output

At training time, the method consumes N randomly sampled images from an unlabeled dataset (e.g., ImageNet-964), each augmented K times for the support set, while query images are synthesized via a pixel-level mixup of an augmented support image and a random dataset image (λ ∈ (0, 0.5)). At test time, the input is K labeled support images per class plus unlabeled query images, all resized to 224×224 RGB. The output is a single predicted class label per query image obtained in one forward pass through the transformer, with no fine-tuning or adaptation steps.

## Method

CAMeLU reframes meta-learning as a non-causal sequence modeling problem where a task is a prompt of (support embedding, class embedding) pairs followed by a query embedding, processed by an 8-layer, 8-head transformer encoder that predicts the query label from its output position. The key architectural pipeline concatenates a fixed pre-trained ResNet-50 image embedding (2048-dim) with a learned 256-dim class encoding, forming 2304-dim tokens fed to the transformer. The central novelty is the task creation mechanism: support images are generated via standard augmentations (crop, rotate, flip, color jitter, etc.), while query images are produced by pixel-level linear interpolation between an augmented support image and a random dataset image with λ < 0.5, ensuring the query retains majority class information while introducing diversity that mimics real test-time conditions. This mixup-inspired strategy acts as task augmentation, forcing the in-context learner to extract robust, generalizable features rather than memorize augmented variants. Training uses cross-entropy loss over 100 epochs × 500 episodes with Adam (lr=1e-5, warmup cosine), and the entire model fits in 8 GB VRAM.

## Results

CAMeLU achieves state-of-the-art unsupervised meta-learning accuracy across five datasets in a cross-domain setting (trained on ImageNet-964, no fine-tuning at test time). Headline numbers: 76.51% / 92.14% on miniImageNet (5-way 1-shot / 5-shot), 65.52% / 80.35% on CUB, and 57.27% / 75.45% on Meta-iNat. On fine-grained datasets where domain shift is most severe, CAMeLU outperforms its supervised counterpart CAML by up to 10.9 points (CUB 5w1s: 65.52 vs 54.63) and beats the only other cross-domain UML method (PsCo) by 22.2 points on CUB 5w1s (65.52 vs 43.35). Inference requires a single forward pass (57 ms per task), with no adaptation steps.

## Baselines & Comparisons

Against in-domain UML baselines (CACTUs, UMTRA, Meta-GMVAE, PsCo in-domain), CAMeLU wins on every dataset and both shot settings, despite the harder cross-domain evaluation protocol (e.g., CUB 5w1s: 65.52 vs 33.93 for CACTUs-ProtoNet). Against the only other cross-domain UML method, PsCo, CAMeLU improves by 8.6–22.2 points across datasets (e.g., CUB 5w1s: 65.52 vs 43.35; Meta-iNat 5w1s: 57.27 vs 46.21) and does so without the 100-step fine-tuning that PsCo requires. Compared to its supervised counterpart CAML, CAMeLU loses on miniImageNet (76.51 vs 81.75, 5w1s) but outperforms it on all fine-grained cross-domain datasets (CUB: 65.52 vs 54.63; Aircraft: 33.17 vs 28.92; Meta-iNat: 57.27 vs 50.86), suggesting the task-creation mechanism provides a generalization advantage over supervised task sampling. Against SSL methods (SimCLR, SwAV) that require 100-step fine-tuning per task, CAMeLU trails on miniImageNet and CIFAR-fs (partly due to data leakage in the SSL pre-training) but leads on CUB (65.52 vs 47.35/47.84, 5w1s), Aircraft (33.17 vs 29.36/30.33), and Meta-iNat (57.27 vs 52.44/53.57), all with a single forward pass. Against BECLR (unsupervised contrastive few-shot), CAMeLU trained on miniImageNet achieves 60.60% on CUB 5w1s vs 42.47% for BECLR, a 18-point gap.

## Relation to Prior Work

CAMeLU directly extends CAML (Fifty et al., 2024), a supervised in-context meta-learning method that uses a transformer encoder to predict query labels from support context, by removing the need for labeled training tasks. It departs from prior UML methods (CACTUs, UMTRA, Meta-GMVAE, PsCo) that construct pseudo-tasks via clustering or simple augmentations, introducing a mixup-inspired query generation strategy that creates a more realistic train-test gap. The cross-domain evaluation protocol (training on ImageNet-964, testing on fine-grained datasets) is a deliberate departure from the same-domain assumption in most UML work, positioning the paper at the intersection of in-context learning, unsupervised meta-learning, and domain generalization.

## Why It Matters / Open Questions

The single-forward-pass inference (no fine-tuning) makes CAMeLU applicable to real-time few-shot classification, and the demonstrated ability to outperform its supervised counterpart on fine-grained cross-domain datasets suggests that task diversity during training can substitute for label information. However, the cross-domain comparison is limited to PsCo as the only other UML baseline designed for this setting, and the SSL comparison involves data leakage on miniImageNet, weakening the strongest evidence. Open questions include whether the approach scales to more complex domains, whether incorporating SSL feature extractors (as hinted by the CLIP ablation) closes the remaining gap to supervised methods, and whether the memorization-to-generalization phase shift can be accelerated or controlled.

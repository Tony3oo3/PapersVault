## Problem

Conventional active learning strategies select examples that are informative for the current task but ignore previously learned knowledge, causing catastrophic forgetting in continual learning settings. The paper asks: which examples in a new task simultaneously preserve past knowledge and enable rapid acquisition of new knowledge, given that past-task data is inaccessible?
![Teaser figure](../imgs/ICLR20253290/cropped_page1_idx0.webp)

## Input / Output

At each continual learning task, the method receives an unlabeled pool of RGB images (32×32 for CIFAR splits, 64×64 for TinyImageNet), a small rehearsal memory buffer (100–5000 examples) from prior tasks, and the current model parameters. It outputs a budget-constrained query set of examples to label per round, which is then used to update the CL model; the process repeats over multiple active learning rounds per task. The Fisher information embedding is computed only over the last linear classification layer, reducing the per-example representation to a vector of dimension d×K (embedding dimension × number of classes).

## Method

AccuACL defines an 'accumulated informativeness' objective that decomposes the target Fisher information matrix into a past component (estimated from the memory buffer) and a new component (estimated from the unlabeled pool), balanced by λ = |U_{1:t-1}|/|U_{1:t}|. For scalability, the full Fisher matrix is replaced by its diagonal (the Fisher information embedding), which Theorem 4.2 shows reduces to a single forward pass per example: p_k(1−p_k)·h_i² for the last linear layer. The query strategy exploits two Fisher-optimality-preserving properties: a distribution score (Jensen-Shannon divergence between each example's normalized Fisher embedding and the target embedding) is used to over-sample candidates, then a magnitude score (ℓ₂-norm of the Fisher embedding) selects the final batch. This two-stage greedy selection yields O(n log n + dK log dK) time and O((m+n)dK) space per round, versus O(bn·dK + n(dK)²) for the prior Fisher-based method BAIT.

## Results

AccuACL outperforms all AL baselines by 23.8% in average accuracy and 17.0% in forgetting on average across four CL methods (ER, GSS, DER++, ER-ACE) and three benchmarks. On DER++ with SplitCIFAR100 (M=500), AccuACL achieves 30.5% average accuracy and 27.0% forgetting, versus 27.6%/38.9% for the best baseline (Uniform). On ER with SplitCIFAR100 (M=500), AccuACL reaches 14.1% accuracy and 55.8% forgetting, compared to 10.9%/63.7% for Uniform. BAIT is not scalable beyond SplitCIFAR10 due to out-of-memory errors on larger datasets.

## Baselines & Comparisons

All five conventional AL baselines (Entropy, LeastConf, kCenter, BADGE, BAIT) underperform or match Uniform random selection on most settings, confirming that task-focused AL strategies exacerbate catastrophic forgetting in CL. Entropy (Settles, 1995) and LeastConf (Wang, 2014) consistently degrade accuracy relative to Uniform (e.g., 8.5% vs. 10.9% on ER/SplitCIFAR100 M=500), as their uncertainty-driven selection over-emphasizes novel features. kCenter (Sener, 2017) and BADGE (Ash, 2019) show mixed results—sometimes competitive on accuracy but with substantially higher forgetting (e.g., kCenter: 66.1% vs. Uniform's 63.7% on ER/SplitCIFAR100). BAIT (Ash, 2021) is the only Fisher-based baseline but fails to scale beyond SplitCIFAR10 due to cubic matrix-inversion costs, reporting OOM on SplitCIFAR100 and SplitTinyImageNet. AccuACL wins on both accuracy and forgetting across all CL methods and datasets where baselines are available, with the largest gains on DER++ (e.g., +2.9% accuracy and −11.9% forgetting over Uniform on SplitCIFAR100 M=500).

## Relation to Prior Work

This paper extends Fisher information-based active learning (Zhang & Oles, 2000; Sourati et al., 2017) to the continual learning setting by introducing 'accumulated informativeness,' a criterion that jointly accounts for past and new task information. It repurposes the diagonal Fisher information—previously used as a regularization term in EWC (Kirkpatrick et al., 2017)—as a per-example representation for query selection, and builds on BAIT (Ash et al., 2021) by replacing the full matrix inversion with a linear-complexity embedding. The method is positioned as the first ACL strategy that explicitly balances catastrophic forgetting prevention with rapid new-task acquisition in the query policy, departing from prior ACL work (Vu et al., 2023; Ayub & Fendley, 2022) that either recommended combining off-the-shelf AL with CL or focused solely on new-task informativeness.

## Why It Matters / Open Questions

The paper provides a principled, theoretically grounded query strategy for ACL that is practical (linear in parameter count) and compatible with standard rehearsal-based CL pipelines. A key open question is whether the approach extends to rehearsal-free or regularization-based CL settings, since the target Fisher information estimation currently relies on a memory buffer. The authors also note unvalidated scenarios including noisy labels, blurry task boundaries, and imbalanced data, as well as the potential for adapting the framework to vision-language models. The finding that a small memory buffer (1000 examples) suffices for adequate Fisher estimation compared to full past-data access is practically encouraging for deployment.

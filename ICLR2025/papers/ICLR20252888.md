## Problem

Backpropagation is inherently backward-locked: each layer must synchronously wait for the previous one and store intermediate activations, preventing efficient model parallelism across devices. Existing parallelization techniques (pipelining, delayed gradients) alleviate this lock but introduce quadratic memory overhead from activation and parameter buffers that scales with the number of stages. The paper asks whether a training procedure can achieve linear speedup with model parallelism while requiring zero additional activation or parameter storage.

## Input / Output

The method consumes standard RGB images (32×32 for CIFAR-10/100 and ImageNet-32, 224×224 for ImageNet) and outputs class labels via a standard cross-entropy loss. A key structural detail is that at each reversible stage, the input tensor is split into two equal streams along the channel dimension, doubling the channel count relative to a standard ResNet block while keeping the parameter count nearly identical. The network is partitioned into J stages (10 for RevNet-18, 18 for RevNet-34/50) distributed across separate GPUs, with only neighboring stages communicating activations and gradients.

## Method

PETRA partitions a reversible ResNet into stages on separate devices and decouples the forward and backward passes so they execute concurrently. During the backward pass, each reversible stage reconstructs its input from the received output using the inverse of the reversible block (equivalent to one forward pass), eliminating the need to store activations. Crucially, PETRA maintains only a single set of parameters per stage (no weight stashing), so the backward pass computes gradients using the most recently updated weights rather than the weights used in the forward pass, yielding an approximate but effective gradient estimate. A gradient accumulation factor k further reduces staleness by averaging k micro-batch gradients before each parameter update. This design achieves zero additional activation or parameter buffer memory, constant communication overhead, and a linear wall-clock speedup with the number of stages, while matching backpropagation accuracy on CIFAR-10, ImageNet-32, and ImageNet.

## Results

On ImageNet, PETRA with RevNet-50 achieves 74.8% top-1 accuracy, within 0.6% of reversible backpropagation (75.4%) and 0.8% below standard ResNet-50 backpropagation (75.6%). On CIFAR-10, PETRA matches reversible backpropagation exactly for RevNet-18 (94.9%) and is within 0.7% for RevNet-50 (94.5% vs 95.2%). PETRA achieves a 3.0× wall-clock speedup over reversible backpropagation for RevNet-18 and 2.4× for RevNet-34, while reducing peak memory by 54.3% compared to standard delayed-gradient approaches with both input and parameter buffers.

## Baselines & Comparisons

Against reversible backpropagation (Gomez et al., 2017), PETRA matches accuracy almost exactly on CIFAR-10 and ImageNet-32 (within 0.1–0.5%) and is within 0.6% on ImageNet for RevNet-50, while delivering a 3.0× speedup (RevNet-18) and 2.4× speedup (RevNet-34) by decoupling forward and backward passes across devices. Compared to delayed gradients (Zhuang et al., 2020), PETRA eliminates both the input activation buffer and the parameter buffer, achieving 54.3% peak memory reduction for RevNet-50 on ImageNet (20.3 GB vs 44.5 GB) without degrading accuracy. Versus delayed gradients with activation checkpointing (Xu et al., 2019), PETRA removes the need for any checkpointing or recomputation of the full computational graph, since reversible stages reconstruct inputs analytically during the backward pass. The only consistent accuracy gap is on ImageNet with RevNet-50 (74.8% vs 75.4%), which the authors attribute to the non-reversible downsampling blocks; using fully invertible downsampling closes this gap at the cost of increasing parameters from 30.4M to 50M.

## Relation to Prior Work

PETRA sits at the intersection of two previously separate research threads: reversible architectures (Gomez et al., 2017), which were designed to reduce memory during standard backpropagation by reconstructing inputs from outputs, and delayed-gradient model parallelism (Zhuang et al., 2020; Xu et al., 2019), which decouples forward and backward passes across devices but requires activation or parameter buffers. The key conceptual departure is using reversibility not merely as a memory-saving trick within a single backpropagation pass, but as the mechanism that eliminates both activation and parameter buffers in a fully parallel pipeline, thereby achieving linear speedup with constant communication overhead. Prior pipelining and delayed-gradient methods scale quadratically in activation memory with the number of stages; PETRA removes this dependency entirely for reversible stages.

## Why It Matters / Open Questions

The 54.3% memory reduction and 2.4–3× wall-clock speedup on ResNet-scale models, combined with near-parity accuracy (within ~0.5–1% of backpropagation), make PETRA a practical option for training models that exceed single-device memory. The linear scaling in the number of stages is a clean theoretical guarantee that prior pipelining methods lack, and the gradient-approximation analysis (Appendix B) reveals that using up-to-date weights for Jacobian computations actually improves alignment with true end-to-end gradients compared to standard delayed gradients. Open questions include whether the approach scales to fully invertible architectures (eliminating the remaining non-reversible downsampling stages) and to large language models, which the authors identify as the natural next step. The modest empirical speedup relative to the theoretical linear bound, attributed to unbalanced stages, suggests significant room for engineering optimization.

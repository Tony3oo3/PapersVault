## Problem

Despite ReLU networks being central to deep learning successes, no explicit theory of feature learning in finite-width ReLU networks has been established. Existing frameworks rely on assumptions that strip away the very phenomena of interest: linearity of computations, infinite width (NTK/lazy regime), unstructured Gaussian data, or single hidden layers. This paper asks what inductive biases govern how finite ReLU networks allocate their hidden neurons during feature learning on structured, nonlinear tasks.

## Input / Output

The network receives a concatenated one-hot vector encoding object identity and a one-hot vector encoding context, and must produce a set of object properties that include both context-independent features (e.g., a hierarchical tree structure) and context-specific features (different property blocks active in only one of C contexts). The analytical outputs are the closed-form singular value trajectories and loss dynamics of the ReLU network, obtained via its equivalent ReLN, along with the explicit gating architecture (which neurons are active in which contexts) that reveals the emergent functional modules. The task is over-parametrized (hidden width ≥ rank of effective dataset) and trained with full-batch gradient descent and L2 loss.

## Method

The paper introduces the Rectified Linear Network (ReLN), a Gated Deep Linear Network whose gating variables exactly replicate the ReLU activation pattern at all times, making the ReLU network's training dynamics fully tractable via the neural race reduction. By identifying the effective dataset for each pathway in the ReLN, the authors derive closed-form singular value trajectories and prove that the ReLU network's loss trajectory is unique among all GDLN architectures implementable by a single-hidden-layer ReLU network (Proposition 4.2, using a generalization of the Cauchy Interlacing Theorem). The key finding is that the ReLU network's inductive bias is toward structured mixed selectivity: hidden neurons are active across multiple contexts (e.g., C−1 out of C) rather than being context-specific, because this node-reuse strategy maximizes the singular values each pathway sees and thus wins the neural race for fastest loss reduction. This bias is shown to strengthen with both additional contexts (Section 5) and additional hidden layers (Section 6), where the first layer becomes fully shared and the second layer enables combined item-context gating while preserving the mixed-selective structure.

## Results

On the transition-to-nonlinear-separability task, the ReLU network's loss trajectory exactly matches the faster of two GDLN architectures (linear vs. XOR gating), with the crossover occurring at Δ = √(2/3) ≈ 0.816, meaning the ReLU network adopts a nonlinear decision boundary well before the problem becomes truly nonlinearly separable. On the contextual task, the ReLN's predicted loss trajectory and singular value dynamics match the ReLU network simulation exactly, and MDS plots confirm near-identical latent representations at all timepoints. Proposition 4.2 proves the identified ReLN is the unique (up to symmetries) GDLN matching the ReLU loss trajectory and is the fastest learner among all implementable architectures. With C contexts, the ReLN uses C context-specific pathways each active for C−1 contexts, demonstrating that the bias toward node reuse and mixed selectivity scales with task complexity.

## Baselines & Comparisons

The paper compares the ReLU network against multiple GDLN architectures that serve as analytical baselines. On the XOR task, the ReLU network matches the faster of the linear GDLN (2 pathways) and the XOR GDLN (4 pathways), with the crossover at Δ = √(2/3) determining which architecture wins the neural race. On the contextual task, a 'GDLN Single' architecture with pathways active for individual contexts fails to match the ReLU loss trajectory, while the identified ReLN (with pathways active for 2 of 3 contexts) matches exactly and is proven to be the unique fastest learner. The ReLN's mixed-selective pathways (active across multiple contexts) outperform both the fully context-specific GDLN Single and the per-datapoint gating strategies, as confirmed by the Cauchy Interlacing Theorem argument showing that using all available features maximizes the leading singular value and thus learning speed. With added depth (2 hidden layers), the ReLU network and ReLN show similar variance profiles across 100 runs, with the ReLN still capturing the stereotypical trajectory and the same mixed-selective structure, though perfect singular vector alignment is no longer guaranteed.

## Relation to Prior Work

This paper builds directly on the Gated Deep Linear Network (GDLN) paradigm of Saxe et al. (2022) and the closed-form dynamics of deep linear networks (Saxe et al., 2014; 2019), introducing Rectified Linear Networks (ReLNs) as a tractable bridge between ReLU networks and GDLNs. It departs from the NTK/lazy-regime literature by targeting finite-width feature learning, and from statistical physics approaches by handling structured (non-Gaussian) data. The task design and hierarchical output structure are inherited from Saxe et al. (2019), but the addition of a context feature and the focus on mixed selectivity as an emergent strategy represent a deliberate extension beyond the single-context setting of prior linear network theory.

## Why It Matters / Open Questions

This is the first explicit theory of feature learning dynamics in finite ReLU networks that does not require infinite width, unstructured data, or architectural simplifications, and it reveals that the implicit bias is toward structured mixed selectivity and node reuse rather than disentanglement — a finding with direct implications for interpretability and the neuroscience of neural reuse. Key limitations include the strong alignment assumption (Assumption 2.1.2), the requirement that the ReLN have few pathways for interpretability, and the fact that all experiments use small one-hot-encoded datasets with simple hierarchical structure. Open questions include whether the mixed-selectivity bias persists on high-dimensional, continuous, or compositional tasks, and how the ReLN framework connects to meta-learning and polysemanticity in large-scale models.

## Problem

Existing composed video retrieval methods and datasets operate at a coarse granularity: modification texts describe only the changed element without specifying what should remain consistent or be excluded, and models perform only sentence-level cross-modal alignment. This semantic granularity gap between highly abstract text and redundant video content causes models to misinterpret fine-grained user intent, returning videos that either resemble the reference or match the modification in isolation but fail to satisfy both simultaneously.
![Teaser figure](../imgs/ICLR20250649/cropped_page1_idx0.webp)

## Input / Output

The method consumes a reference video (encoded via a frozen CLIP or BLIP image encoder followed by mean-pooling temporal aggregation) and a modification text — a complete sentence averaging ~11 words that explicitly encodes three semantic components (retained, injected, excluded) across four concept categories (attribute, object, scene, action). It outputs a single global fused video feature vector that is matched against precomputed candidate video features in the database via cosine-similarity ranking. Unlike prior CVR datasets where modification texts are abbreviated phrases (~5 words) covering only the changed element, FineCVR-1M texts are full sentences that specify what stays, what is added, and what is removed.

## Method

FDCA disentangles the modification text at two complementary levels. At the sentence level, a reference-video-guided cross-attention decomposes the text embedding into a retained component (semantically aligned with the reference video) and an injected component (newly added semantics); these are then processed by separate Transformer-based Cross-modal Feature Alignment (CMFA) and Cross-modal Feature Fusion (CMFF) modules to produce the final fused video feature. At the token level, an Auxiliary Token Disentangling (ATD) mechanism applies DPC-KNN clustering to both the original token features and a positive variant (with negation words removed), using the reference video feature to guide cluster aggregation and iteratively separate tokens into clean retained, injected, and excluded groups. The token-level components drive three auxiliary losses — a token-level contrastive retrieval loss, a retained-component consistency loss pulling positive retained tokens toward the reference video, and a negation semantic triplet loss penalizing excluded content in the target — which jointly train the sentence-level CMFA/CMFF modules. At inference, only the sentence-level SFD path is active, so the clustering-based token disentanglement serves purely as a training-time signal that sharpens the sentence-level feature separation without adding inference cost.

## Results

On the FineCVR-1M test set, FDCA-BLIP achieves R@1=26.79, R@5=63.21, R@10=78.65, and R@50=97.25, while FDCA-CLIP achieves R@1=25.84, R@5=55.84, R@10=70.23, and R@50=94.33. These results substantially outperform the strongest prior methods: FreestyleRet (R@1=20.39), Combiner (R@1=19.57), and CoVR (R@1=17.05). Notably, FDCA-CLIP with a frozen CLIP backbone surpasses CoVR which fine-tunes a stronger BLIP backbone, demonstrating that the disentanglement pipeline is more impactful than backbone strength alone.

## Baselines & Comparisons

FDCA-CLIP (R@1=25.84) decisively outperforms all CIR baselines: FreestyleRet (20.39), Combiner (19.57), Pic2word (8.10), CosMo (7.82), Uncertainty-R (5.23), Artemis (4.76), MAAF (2.16), and TIRG (0.00). Against CVR-specific methods, FDCA-CLIP beats CoVR (17.05) by 8.79 points and TFR-CVR (15.21) by 10.63 points on R@1, despite CoVR using a stronger BLIP backbone with fine-tuning. On WebVid-CoVR, FDCA-BLIP with fine-tuning (R@1=54.80) surpasses CoVR (53.13), though the frozen version (52.23) is slightly below. On EgoCVR, FDCA-BLIP (R@1=8.7 global, 36.3 local) outperforms CoVR (5.4, 33.1) but trails TFR-CVR (14.1, 44.2), which leverages pre-trained video-language weights from the EgoCVR dataset without additional training. The paper highlights that the well-designed feature disentanglement pipeline proves more critical than simply upgrading to a stronger pre-trained model.

## Relation to Prior Work

This paper extends composed video retrieval (CVR) from the coarse-grained formulation of CoVR and EgoCVR—where modification texts describe only changed elements—to a fine-grained setting that explicitly specifies retained, injected, and excluded visual components. Methodologically, it builds on the cross-modal alignment and fusion paradigm of CIR methods (TIRG, CosMo, Pic2word, Combiner) and CVR methods (CoVR, TFR-CVR), but departs from their sentence-level-only treatment by introducing token-level disentanglement via DPC-KNN clustering, a technique borrowed from token clustering literature (Jin et al., 2023; Zeng et al., 2022) but not previously applied to composed retrieval. The three-component decomposition (retained/injected/excluded) is a conceptual extension of the gate-based feature discrimination in CIR, made explicit at the token level through auxiliary clustering and contrastive losses.

## Why It Matters / Open Questions

FineCVR-1M (1M+ triplets with three-component modification texts) fills a clear gap in the CVR benchmark landscape, providing the first dataset that explicitly encodes what should be preserved, added, and removed—enabling evaluation of fine-grained retrieval that prior datasets cannot support. The finding that FDCA with frozen CLIP outperforms CoVR with fine-tuned BLIP suggests that structured feature disentanglement may matter more than backbone strength for composed retrieval, though this is demonstrated primarily on the authors' own dataset. Key limitations include reliance on mean-pooling for temporal encoding (acknowledged as insufficient for fine-grained temporal modeling), and failed cases involving small objects and subtle action differences that remain unsolved. Open questions include whether the token-level disentanglement strategy generalizes to other composed retrieval settings and how it integrates into emerging multimodal foundation models.

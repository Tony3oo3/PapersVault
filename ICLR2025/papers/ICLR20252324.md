## Problem

Computing Shapley values exactly requires O(2^n) model evaluations, making it infeasible for moderate n. The dominant approximation method, Kernel SHAP, relies on a heuristic sampling distribution and, to the best of the authors' knowledge, has no non-asymptotic theoretical accuracy guarantees when using fewer than 2^n samples. This paper closes that gap by providing a principled sampling scheme with provable approximation bounds.

## Input / Output

The method takes black-box access to a set function v: 2^[n] → R (typically a model prediction with features masked to a baseline), the number of features n, and a target sample budget m (at least n). It outputs an n-dimensional vector of approximate Shapley values φ̃ that satisfies the efficiency constraint ⟨φ̃, 1⟩ = v([n]) − v(∅). The algorithm requires at most m evaluations of v in expectation, with O(mn²) additional runtime to solve the resulting least-squares problem.

## Method

Leverage SHAP reformulates the constrained Shapley value regression problem into an unconstrained one via the projection matrix P = I − (1/n)11ᵀ, defining A = ZP and b = y − Z1·(v(1)−v(0))/n. The key analytical contribution is proving that the leverage scores of A have the closed form ℓ_z = C(n, |z|₁)⁻¹, meaning all subsets of the same size share an identical score. This enables efficient importance sampling: draw a size s uniformly from {1,…,n−1}, then pick a random subset of size s, without ever enumerating all 2^n rows. The algorithm further incorporates paired sampling (always including the complement of each sampled set) and Bernoulli sampling without replacement, both of which improve accuracy while preserving the theoretical guarantee of O(n log(n/δ) + n/(εδ)) evaluations for a (1+ε) approximation to the regression objective with probability 1−δ.

## Results

On eight datasets (IRIS, California, Diabetes, Adult, Correlated, Independent, NHANES, Communities) with m=10n samples, Leverage SHAP achieves the lowest ℓ₂-norm error (‖φ−φ̃‖₂²/‖φ‖₂²) across all settings. The headline result is an approximately 50% reduction in error compared to Optimized Kernel SHAP on average (50.2% of the error, per Table 2). For example, on the Correlated dataset with m=5n, Leverage SHAP achieves only 54% of the error of Optimized Kernel SHAP, and on Adult with m=160n, it achieves 27.6%. The third quartile of Leverage SHAP error is generally at the median of Optimized Kernel SHAP, indicating consistent improvement across the distribution.

## Baselines & Comparisons

Leverage SHAP outperforms all three baselines on every dataset and sample size tested. Against Kernel SHAP (the basic version without paired sampling or without-replacement), Leverage SHAP achieves roughly 10–20× lower median ℓ₂-norm error (e.g., 0.00124 vs. 0.0345 on Adult, 0.00528 vs. 0.0404 on Correlated). Against Optimized Kernel SHAP (which adds paired sampling and sampling without replacement), Leverage SHAP still wins consistently, achieving 50.2% of the error on average across all non-trivial settings (i.e., m < 2ⁿ); the gap is largest for small n relative to m (e.g., 9.1% of the error on California at m=5n) and narrows as m grows. Against Permutation SHAP (Mitchell et al., 2022), Leverage SHAP also dominates, with median errors roughly 3–5× lower (e.g., 0.00124 vs. 0.00222 on Adult, 0.00528 vs. 0.0098 on Correlated). The only ties occur when m ≥ 2ⁿ, where all methods recover exact Shapley values to machine precision.

## Relation to Prior Work

This paper builds directly on the Kernel SHAP regression formulation (Lundberg & Lee, 2017; Charnes et al., 1988), which connects Shapley values to a constrained least-squares problem, and replaces its heuristic sampling distribution with theoretically optimal leverage score sampling from the active learning literature (Cohen & Migliorati, 2017). The key conceptual departure is recognizing that Shapley value estimation is an instance of agnostic active learning, and that the leverage scores of the reformulated regression matrix admit a simple closed form (proportional to 1/C(n,|S|)), enabling efficient sampling without ever materializing the exponentially tall matrix. Unlike Kernel SHAP, which over-weights small and large subsets, the leverage score distribution places equal total weight on each subset size, a distinction the paper shows is both theoretically justified and empirically beneficial.

## Why It Matters / Open Questions

This is the first work to provide non-asymptotic accuracy guarantees for Kernel SHAP-style Shapley value estimation, closing a notable theoretical gap for a method that is ubiquitous in practice (the SHAP library). The O(n log n) sample complexity with provable (1+ε) objective approximation is near-optimal for the active learning formulation, and the ~50% error reduction over the already-optimized Kernel SHAP (with paired sampling and sampling without replacement) is practically meaningful for explainable AI applications. Open questions include whether the guarantees extend to the deterministic (non-independent) variant of the algorithm, the role of the problem-specific parameter γ in the ℓ₂-norm guarantee, and whether more sophisticated sampling (e.g., Batson–Spielman–Srivastava sparsifiers) can be adapted to the exponentially tall matrix to achieve the optimal O(n/ε) rate.

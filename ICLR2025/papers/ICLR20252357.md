## Problem

Existing interpretable image classification models (SENN, PIP-Net, SLDD-Model, Q-SENN) can offer local explanations for individual predictions but fail to provide faithful, globally interpretable class representations. Their class encodings are real-valued or ternary, include per-class biases, and use a varying number of features, making them neither compact nor easily contrastive. This paper addresses the gap by seeking a globally interpretable model whose class representations are compact, binary, and directly comparable across classes.

## Input / Output

The method takes standard RGB images (resized to 224×224) and produces a class label via a sparse binary decision layer. Unusually, the output also includes an interpretable class representation: each of the n_c classes is encoded as a fixed set of exactly 5 feature indices (out of 50 total selected features), with no bias term, so that y_i = Σ_{j∈S_i} f_j. The feature extractor (e.g., ResNet-50) produces spatial feature maps that are globally averaged into a single feature vector before the binary assignment is applied.

## Method

QPM follows a three-stage pipeline: (1) train a dense black-box model with a feature diversity loss to encourage spatially distinct features; (2) solve a binary quadratic programming problem (via Gurobi) that jointly selects n_f*=50 features from the full set and assigns exactly n_wc=5 of them to each class, maximizing class-feature Pearson correlation while penalizing inter-feature cosine similarity and incorporating a locality bias, subject to constraints that no two classes share an identical feature set; (3) fine-tune the feature extractor with the binary assignment matrix W* fixed, so each feature adapts to become a shared general concept across its assigned classes. The key distinction from prior work (SLDD-Model, Q-SENN) is the use of global discrete optimization rather than iterative local methods (glm-saga) for the selection-and-assignment step, combined with strictly binary (0/1) weights and uniform per-class sparsity, which yields contrastive, bias-free class representations that are directly comparable as sets of feature indices.

## Results

On CUB-2011, QPM achieves 85.1% top-1 accuracy with only 50 total features (5 per class), outperforming SLDD-Model (84.5%) and Q-SENN (84.7%) at the same compactness level, while the dense ResNet50 baseline reaches 86.6% with 2048 features. On Stanford Cars, QPM attains 91.8% accuracy, the best among all interpretable methods. On ImageNet-1K, QPM reaches 74.2% accuracy, marginally below Q-SENN (74.3%) but far above glm-saga5 (58.0%). QPM also achieves the highest Structural Grounding (47.9 on CUB-2011) and Contrastiveness (96.0), indicating its binary class representations most faithfully mirror human-perceived class similarity.

## Baselines & Comparisons

QPM outperforms SLDD-Model by 0.6 pp on CUB-2011 (85.1% vs 84.5%) and 0.7 pp on Stanford Cars (91.8% vs 91.1%) at identical compactness (50 features, 5/class), and by 1.5 pp on ImageNet-1K (74.2% vs 72.7%). Against Q-SENN, QPM wins on CUB-2011 (85.1% vs 84.7%) and Stanford Cars (91.8% vs 91.5%) but is marginally behind on ImageNet-1K (74.2% vs 74.3%), where Q-SENN uses compute-intensive iterations and negative reasoning that hinders interpretability. QPM substantially outperforms glm-saga5 (78.0% CUB) and PIP-Net (82.0% CUB) in accuracy while using far fewer total features (50 vs 809/731). In interpretability metrics, QPM achieves the best Structural Grounding (47.9 vs 29.2 for SLDD, 23.4 for Q-SENN) and Contrastiveness (96.0 vs 87.2/93.0), while Q-SENN leads on SID@5 (93.3 vs 90.1 on CUB). The dense ResNet50 baseline retains a 1.5 pp accuracy advantage on CUB-2011 but uses 41× more features and offers no interpretable class representations.

## Relation to Prior Work

QPM extends the compactness-based interpretable classification line from the SLDD-Model and Q-SENN, which both select a small feature subset and sparsely assign features to classes. The key departure is replacing the iterative local optimization (glm-saga) used in those works with a globally optimal binary quadratic program solved via Gurobi, which jointly determines feature selection and class assignment. This yields strictly binary, fixed-size class representations (5 features per class, no bias), in contrast to the real-valued (SLDD-Model) or ternary (Q-SENN) weights of prior methods, enabling direct contrastive comparison between classes. The paper also positions against prototype-based methods (PIP-Net, ProtoPool) whose features tend to become class-specific detectors rather than shared general concepts.

## Why It Matters / Open Questions

The paper demonstrates that globally optimal discrete optimization over a compact feature budget produces interpretable class representations that are simultaneously more accurate and more structurally grounded than prior methods, with the Structural Grounding metric nearly doubling from 29.2% (SLDD-Model) to 47.9%. The binary, fixed-size representation enables a form of faithful global interpretability—practitioners can directly compare which 5 features define each class and identify the single differentiating feature—without any additional annotation. Open questions include the computational cost of QP solving (hours on CPU), the inability to model negative assignments, the persistence of polysemantic features, and whether the approach transfers to high-stakes domains like medical imaging or autonomous driving where no suitable public datasets yet exist.

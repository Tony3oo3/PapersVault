## Problem

Existing LLM-based hierarchical control methods require humans to manually design low-level skills—collecting skill-specific data, developing heuristics, and performing reward engineering—making them labor-intensive and limited in generality. This paper introduces the paradigm of AI-Assisted Skill Design, where a human provides only natural language descriptions of skills and an AI system automatically converts them into trainable, composable policies, bridging the gap between high-level human knowledge and low-level sensorimotor control.

## Input / Output

During the design phase, the method takes natural language skill descriptions (e.g., 'explore each dungeon level, collect items and survive encounters') and unannotated gameplay data, producing skill-specific reward functions, initiation/termination code, and a training-time skill-selection policy. At deployment, a single natural language task specification (e.g., 'reach the Gnomish Mines, eat food, then descend to the Delphi') is fed to an LLM coder that generates executable Python code defining a policy over the pre-trained skills. The output is a zero-shot, code-defined skill-composition strategy that drives a shared neural network to produce low-level NetHack actions, with no additional training required for new tasks.

## Method

MaestroMotif operates in four phases: (1) it elicits pairwise preferences from Llama 3.1 70B on interaction pairs (using 100-step diff-history representations and player statistics) and distills them into per-skill reward functions via the Bradley-Terry model; (2) it uses Llama 3.1 405B to generate Python code for each skill's initiation and termination functions; (3) it generates a training-time policy over skills as code, specifying how to interleave skills during learning; and (4) it trains all skill policies simultaneously via PPO (Sample Factory) on a single shared network conditioned by a one-hot skill index, rather than separate heads. The key architectural insight is lifting the planning problem from the low-level action space to a high-level skill space where an LLM can write code policies using programming constructs (conditionals, state variables, loops) to express long-horizon, compositional behaviors that would be intractable for a single neural policy. At deployment, the same LLM coder generates a new code policy over the trained skills from a task description, with a self-refinement loop using LLM-generated unit tests to verify correctness before execution.

## Results

On navigation tasks in the NetHack Learning Environment, MaestroMotif achieves 46% success rate on Gnomish Mines, 29% on Delphi, and 7.2% on Minetown, all zero-shot without task-specific training. On interaction tasks, it collects 0.66 transactions, 0.47 price identifications, and 1.60 B/U/C identifications per episode. On composite tasks requiring multi-step reasoning (e.g., Golden Exit, Level Up & Sell, Discovery Hunger), MaestroMotif achieves 24.8%, 7.1%, and 7.9% success rates respectively, while all baselines score 0%.

## Baselines & Comparisons

MaestroMotif decisively outperforms all seven baselines across every task category. Against the zero-shot LLM Policy (ReAct with Llama), MaestroMotif achieves 46% vs. 0.1% on Gnomish Mines and 29% vs. 0% on Delphi, confirming that LLMs cannot directly produce low-level control policies via prompting alone. Against task-specific RL baselines, MaestroMotif (which requires no per-task training) surpasses Motif (9% on Gnomish Mines) by 5x, Embedding Similarity (3%) by 15x, and even the privileged RL-with-score baseline (3.2%) by 14x. On composite tasks, MaestroMotif is the only method to achieve non-zero success (24.8% on Golden Exit), while LLM Policy, Motif, and Embedding Similarity all score 0%. In the score-maximization comparison (Figure 5), agents trained to maximize in-game score (AutoAscend, NetHack-is-Hard-to-Hack, Wolczyk et al., and behavioral cloning) collect significant score but rarely exhibit the specific navigation or interaction behaviors in the benchmark, whereas MaestroMotif succeeds on those targeted tasks despite not optimizing score.

## Relation to Prior Work

MaestroMotif sits at the intersection of three research threads: (1) the options framework for temporal abstraction (Sutton et al., 1999), which formalizes skills as initiation-termination-policy triples; (2) AI feedback for reward design, specifically the Motif method (Klissarov et al., 2024) that distills LLM preferences into intrinsic reward functions via the Bradley-Terry model; and (3) code-as-policy approaches (Liang et al., 2023) where LLMs generate executable programs as high-level controllers. The key departure from prior LLM-based hierarchical methods (SayCan, PaLM-E, Voyager) is that those systems require large human teleoperation datasets, hand-coded rewards, or access to low-level control primitives, whereas MaestroMotif automates the entire skill design pipeline—reward functions, initiation/termination logic, and composition policies—from natural language descriptions alone, using LLMs for both preference elicitation and code generation.

## Why It Matters / Open Questions

The paper establishes AI-assisted skill design as a viable paradigm, demonstrating that a small set of LLM-trained skills can be recombined zero-shot via generated code to solve complex composite tasks that defeat both zero-shot LLM policies and task-specific RL agents. The finding that score-maximizing NetHack agents fail to exhibit the benchmark behaviors reinforces that proxy objectives misalign with meaningful progress, motivating the skill-based approach. Key limitations include the hand-designed skill set (bounded expressiveness), the single-environment evaluation, and the reliance on a fixed training-time policy that induces an emergent but uncontrolled curriculum. Open questions include whether skill selection can be adapted online, how the approach scales to larger skill libraries, and whether the code-refinement loop generalizes beyond the tested LLM scale.

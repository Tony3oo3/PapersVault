## Problem

In-context learning (ICL) in LLMs incurs substantial computational and memory overhead because demonstration tokens are prepended to queries, causing quadratic scaling in attention and key-value caching, while also being sensitive to demonstration selection and order. The paper asks whether demonstration information can be represented more abstractly and integrated into the model without the attention mechanism, enabling few-shot-level performance at zero-shot inference cost.
![Teaser figure](../imgs/ICLR20253655/cropped_page1_idx0.webp)

## Input / Output

The method takes a set of N demonstration examples (input-label pairs) and a query sentence. Demonstrations are processed independently through the LLM to extract MHA and MLP output activations at the end-token position across all layers, then averaged into a fixed-size context vector whose dimensionality is independent of the number of demonstration tokens. The query is processed in standard zero-shot fashion, with the context vector injected into residual streams at every layer and token position. Output is a class label selected by argmax over the vocabulary at the final token position. A lightweight calibration step (1–2 minutes on a single A100) optimizes 4L scalar coefficients using only the given demonstrations, with no additional data required.

## Method

I2CL decomposes ICL into two stages: context vectorization and context injection. In vectorization, each demonstration example is encoded by collecting MHA and MLP output activations at the end-token position across all L layers, and these per-example vectors are aggregated via element-wise mean (permutation-invariant) into a unified context vector. In injection, instead of using multi-head attention to fuse demonstration and query information, a linear combination of the context vector and the query's own activations is added to each residual stream: r_l^t = r_{l-1}^t + (λ_l^a·ā_l^e + β_l^a·a_l^t) + (λ_l^m·m̄_l^e + β_l^m·m_l^t). The 4L scalar coefficients are learned via noisy self-calibration—gradient descent on label-token perplexity over the demonstrations with Gaussian perturbations to residual streams for robustness. The unconstrained linear combination (allowing negative coefficients) is critical, as ablations show it enables both information addition and deletion at different layers, and targeting both MHA and MLP modules is necessary since they serve complementary roles.

## Results

On Llama2-7B across nine text classification tasks, I2CL achieves 75.12% macro-average accuracy at zero-shot inference cost, outperforming the zero-shot baseline (58.13%) by 17 percentage points and remaining within ~1% of full few-shot ICL (~76%). I2CL requires only 0.13K trainable parameters (4L linear coefficients) compared to 4.1K for prompt-tuning, 262K for IA3, and 4,194K for LoRA. The method also scales beyond few-shot: with hundreds of demonstration examples, I2CL surpasses ICL performance, which plateaus at ~5 shots.

## Baselines & Comparisons

I2CL outperforms all inference-time baselines that require no additional data: it beats Label-anchor (Wang et al., 2023) which is the closest competitor, Task-vector (Hendel et al., 2023) which requires a hold-out validation set to select the optimal layer, and ICV (Liu et al., 2024) which needs manual per-task hyperparameter tuning. Against prompt compression methods (AutoCompressors, ICAE, CEPE), I2CL achieves more consistent cross-task performance since it customizes compression at test time rather than relying on a pre-trained universal compressor. In the PEFT comparison (Table 2), I2CL surpasses LoRA (75.12% vs. 73.15%) and IA3 (75.12% vs. 73.00%) while using 10,000× and 1,000× fewer trainable parameters respectively, and dramatically outperforms prompt-tuning (75.12% vs. 54.94%) which fails under data scarcity. Notably, I2CL also outperforms full few-shot ICL on the Subj task (73.84% vs. 52.56%), where ICL's demonstration examples are ineffective, suggesting the noisy self-calibration mechanism can rectify task-specific deficiencies of the base model.

## Relation to Prior Work

I2CL sits at the intersection of in-context learning, activation/representation engineering, and the residual-stream framework of Elhage et al. (2021). It is most closely related to task vectors (Hendel et al., 2023) and in-context vectors (Liu et al., 2024), which also extract compact representations from demonstrations to improve zero-shot inference, but I2CL departs by (1) using both MHA and MLP outputs rather than a single hidden state, (2) replacing attention-based information fusion with simple linear injection into residual streams, and (3) introducing a noisy self-calibration procedure that eliminates the need for paired demonstrations or task-specific hyperparameter search. Compared to prompt compression methods (AutoCompressors, ICAE, CEPE), I2CL avoids learning an amortized compressor and instead treats the LLM itself as a context vector generator at test time.

## Why It Matters / Open Questions

I2CL offers a practical efficiency win: it achieves near-few-shot accuracy at zero-shot inference cost with only 4L scalar parameters, making ICL feasible in memory- and compute-constrained settings where caching full demonstration KV states is prohibitive. The discovery that calibrated linear coefficients function as transferable task-ids opens a path toward lightweight task similarity detection and cross-task transfer without fine-tuning. However, the method is currently limited to text classification, requires white-box access to intermediate activations (ruling out API-only models like GPT-4), and has been validated only on models up to 8B parameters; extending it to open-ended generation, multi-hop reasoning, and commercial-scale models remains an open challenge.

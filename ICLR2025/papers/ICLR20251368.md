## Problem

Tokenized language models and their statistically equivalent byte-level counterparts can produce substantially different next-token and next-byte predictive distributions, a phenomenon the authors term 'tokenization bias.' This bias is especially harmful for fill-in-the-middle (FIM) code completion, where prompts frequently terminate mid-token, and for model ensembles, where member models use incompatible vocabularies. No prior method could recover the exact unbiased byte-level distribution from an arbitrary trained tokenized LM without retraining.

## Input / Output

The method consumes a trained tokenized LM's next-token conditional probabilities P(t_{k+1}|t_1^k) and a byte-level prompt x_1^n, producing a full probability distribution over all 255 bytes (plus control tokens) for the next position x_{n+1}. For FIM, the input is a code prefix and suffix formatted into PSM or SPM templates; for ensembles, inputs are multiple tokenized LMs with distinct vocabularies whose byte-level predictions are averaged. The algorithm requires only O(1) model forward passes per generated byte (one inference to query the full token distribution, then bookkeeping), though it incurs additional memory for storing cover-encoding dictionaries.

## Method

The core contribution is the Byte-Token Representation Lemma, which shows that the byte-level probability P(x_1^n) equals the sum of token-level probabilities over all 'cover encodings'—valid encodings whose last token begins before position n. An efficient reverse-order search algorithm (Algorithm 1) enumerates these cover encodings by iterating over suffixes and checking validity via the encode∘decode round-trip test. For next-byte sampling, the cover set for x_1^{n+1} is decomposed into two disjoint parts: existing cover encodings whose (n+1)-th decoded byte equals a, and new encodings formed by appending a token starting with a to encode(x_1^n). This decomposition requires a single model inference per byte step. Invalid encodings (where encode(decode(t̄)) ≠ t̄) are provably assigned zero probability in the ground-truth distribution, and the method optionally truncates their softmax probabilities to zero without increasing token-level perplexity (Proposition 2).

## Results

On FIM code completion (HumanEval Random Span, CodeLlama-7b), byte-level predictions in SPM mode achieve up to 67.7% pass rate with beam-4 search, representing an 18% relative improvement over standard tokenized generation and consistently outperforming token healing and token alignment baselines. For model ensembles, averaging byte-level predictions from the top-2 models (Yi-1.5-6B + Mistral-7B-v0.3) yields 65.4% on MMLU, 80.7% on PIQA, 30.0% on NQ, and 64.2% on TriviaQA, surpassing the best individual model on all four benchmarks. On code generation, ensembling Yi-Coder-1.5B with CodeLlama2-13b achieves 42.1% on HumanEval@1, a 3.7% absolute gain over the best single model (38.4%). The ensemble underperforms on GSM8K (55.8% vs. 61.5% for Yi-1.5-6B alone) where member model performance is too divergent (20% gap).

## Baselines & Comparisons

The paper compares against two tokenization-bias mitigation methods on FIM code completion: token healing (Dagan et al., 2024) and token alignment (Athiwaratkun et al., 2024). The proposed byte-level prediction method consistently outperforms both: token healing only recovers a subset of valid cover encodings (e.g., it misses the 'yum|m|yum' split in the 'yummy' example), while token alignment is shown to be biased and can produce invalid encodings due to its greedy masking process. On the HumanEval Random Span benchmark with CodeLlama-7b, byte-level SPM generation achieves 63.9% (beam-1) to 66.8% (beam-4), surpassing both token healing and token alignment across all settings. For model ensembles, the byte-level averaging approach outperforms simple voting (top-2) on MMLU (65.4 vs. 62.1) and matches or exceeds it on PIQA (80.7 vs. 80.1), while voting cannot be extended to open-ended generation tasks like NQ and TriviaQA. The ensemble also beats the best individual model on HumanEval@1 (42.1 vs. 38.4 for Yi-Coder-1.5B), demonstrating that vocabulary-mismatched models can be productively combined.

## Relation to Prior Work

This paper builds directly on Rajaraman et al. (2024), who established the statistical equivalence between tokenized and byte-level language models, by showing that this equivalence does not extend to conditional predictive distributions—a gap the authors formalize as 'tokenization bias.' It departs from prior mitigation strategies (token healing by Dagan et al., 2024; token alignment by Athiwaratkun et al., 2024) by providing a principled, closed-form correction via the Byte-Token Representation Lemma rather than heuristic search over partial tokens. For model ensembling, it contrasts with prior approaches (Wan et al., 2024; Jiang et al., 2023b; Huang et al., 2024; Gu et al., 2024) by requiring no additional training, no scoring network, and no optimization, instead mapping all member models into a universal byte space where standard aggregation applies.

## Why It Matters / Open Questions

The identification of tokenization bias as a fundamental discrepancy between statistically equivalent processes challenges the implicit assumption that tokenization is a lossless compression for inference, and the O(1) inference-time correction is immediately applicable to any existing tokenized LM without retraining. The cross-vocabulary ensembling capability is practically significant for the growing ecosystem of open-weight models with heterogeneous tokenizers. Key limitations include notable memory overhead and linear computational cost (one token spans multiple bytes), and the analysis is restricted to single-step predictions without characterizing cumulative bias over long generations. Open questions include whether the bias-variance tradeoff in ensembles interacts with tokenization, and whether the method extends to stochastic tokenizers like BPE-dropout in a computationally tractable way.

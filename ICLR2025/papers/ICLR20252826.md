## Problem

Current LLM agents make zero- or few-shot decisions via next-token prediction but cannot guarantee optimal (reward-maximizing) policies, while RL-trained agents achieve optimality only after extensive environmental interaction. No existing LLM agent successfully obtains optimal policies on long-horizon benchmarks like BlocksWorld or RoCo-benchmark, as they either sacrifice algorithmic generality by relying on environmental tools (dynamics, available actions, reward functions) or lack a principled RL optimization loop over accumulated experience.

## Input / Output

The agent receives a natural-language domain description (a manual explaining the environment's rules), a pair of initial and target states, and access to the true environment for ground-truth verification. It produces a tabular Q function over the state-action space, an optimal action sequence for the given task, and an expanded domain-scoped memory of (s, a, r, s') transitions. Critically, the memory is domain-scoped rather than task-scoped: transitions from all previously solved tasks in the same domain are stored without task-specific labels, enabling cross-task knowledge transfer. During planning, the agent does not query the environment for available actions, dynamics, or rewards—these are all inferred by the LLM-based world model and basic policy.

## Method

MLAQ integrates three components: a Q-Planner that performs tabular Q-learning on a task-specific replay buffer extracted from a domain-scoped memory, an LLM-based imagination space (basic policy + world model) that generates imaginary transitions without any environmental tools, and a mixed-examination mechanism (LLM-based action/prediction checkers plus environment-grounded correction) to filter hallucinated transitions. The key planning innovation is a variant of UCB (vUCB) that introduces virtual nodes to handle the unknown available-action set: when the virtual node is selected, the LLM proposes a new action to expand the set; when an actual node is selected, its Q-value is estimated. A theorem proves this vUCB retains the standard sub-linear regret bound of classical UCB. The domain-scoped memory enables the agent to aggregate transitions across tasks, so that for a new task, the Q-Planner can often retrieve an optimal trajectory from memory without any LLM queries, achieving over 90% optimal rate on long-horizon tasks where baselines fail.

## Results

On BlocksWorld (single-agent), MLAQ achieves over 90% optimal rate across all difficulty levels (1.00 on 2/4/6-step, 0.97 on 8-step, 0.93 on 10-step, 0.90 on 12-step), while all baselines drop below 0.50 at 8+ steps. On RoCo-benchmark Sort domain (multi-agent), MLAQ reaches 0.98 average success rate and 0.75 optimal rate versus RoCo's 0.35 and 0.21, while reducing environmental replans from 6.41 to 0.06 (a ~100× reduction). On Crafter (partially observable, stochastic), MLAQ scores 39.9% versus DiVE (35.9%), EnvGen (32.2%), and Dreamer-V3 (14.5%).

## Baselines & Comparisons

MLAQ dominates all baselines on long-horizon tasks. On BlocksWorld, RAP (the strongest baseline) achieves only 0.48 optimal rate at 8-step and 0.09 at 12-step, while MLAQ maintains 0.97 and 0.90 respectively; CoT, REX, and RAFA either fail entirely or are not evaluated beyond 6-step. On RoCo Sort, MLAQ outperforms RoCo by a large margin on every metric: success rate 0.98 vs 0.35, optimal rate 0.75 vs 0.21, and environmental replans 0.06 vs 6.41, indicating MLAQ requires roughly two orders of magnitude less environment feedback. On Crafter, MLAQ (39.9%) outperforms the other LLM-based agents DiVE (35.9%) and EnvGen (32.2%), as well as the RL baselines Dreamer-V3 (14.5%) and PPO (4.6%), though it falls short of human performance (50.5%) and its own ground-truth variant MLAQ-gt (46.2%), highlighting the impact of movement stochasticity on the LLM-based world model.

## Relation to Prior Work

MLAQ extends the MDP-based LLM agent paradigm established by RAP (Hao et al., 2023) and ToT (Yao et al., 2023a), which use MCTS within an LLM-based imagination space for planning, by replacing MCTS with a Q-learning-based Q-Planner and introducing a novel vUCB variant with virtual nodes to handle unknown action spaces without environmental tools. It draws on the model-based RL tradition (Dreamer, Hafner et al., 2020) for the concept of imaginary interactions, but instantiates both the world model and basic policy entirely in natural language via LLMs. The key departure from prior work is the domain-specific memory scope (storing transitions across all tasks in a domain) versus the task-specific replay buffers used by RAP, ToT, and LATS, enabling cross-task knowledge transfer that prior methods do not exploit.

## Why It Matters / Open Questions

MLAQ demonstrates that integrating a full model-based RL framework (Q-learning + UCB-guided exploration) into an LLM agent can achieve near-optimal decision-making (>90% optimal rate on 12-step BlocksWorld) while requiring ~2 orders of magnitude fewer environmental interactions than RoCo, addressing a core limitation of existing LLM agents that cannot maximize rewards. The finding that removing env-examination causes only marginal performance decline (0.95 vs. 1.00) suggests current LLMs are largely self-sufficient for generating valid transitions, reducing dependence on ground-truth feedback. Open questions include scalability to highly stochastic or partially observable environments (Crafter results show significant degradation), dependence on frontier LLM quality (GPT-4), and whether the tabular Q-function approach generalizes to continuous or very large state spaces beyond the discrete benchmarks tested.

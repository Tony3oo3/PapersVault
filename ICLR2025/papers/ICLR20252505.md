## Problem

Self-consistency-based methods for improving LLM factuality are largely restricted to tasks with exact-match verifiable answers (arithmetic, multiple choice). When adapted to open-ended generation, existing approaches either concatenate all sampled responses into a single prompt (inflating context length by ×k) or require numerous iterative LLM calls for pairwise consistency checking, making them inefficient and difficult to scale with more samples.

## Input / Output

The method takes a text prompt x and k sampled responses (obtained via temperature or nucleus sampling) and produces a single factually refined text response. Each sampled response r_j is prepended to the original prompt to form a new input q_j = [x; r_j; x], so the input length is extended by only one response (×1) rather than all k responses (×k). All k inputs are processed concurrently in a single batch, and the output is a single coherent text sequence shared across the entire batch.

## Method

Integrative Decoding (ID) implicitly incorporates self-consistency into the decoding objective by exploiting in-context learning. For each sampled response r_j, it constructs an input [x; r_j; x] that instructs the model to respond to x again with reference to r_j; the model's in-context learning then naturally biases its predictions toward tokens semantically consistent with r_j while maintaining coherence. At each decoding step, the predicted logits from all k inputs are summed and the token with the highest aggregated logit is selected, so all sequences in the batch universally take the same next token. This avoids explicit consistency checking, additional prompting, or chain-of-thought reasoning, and the input length grows by only one response regardless of k. The approach is formalized as approximating the objective H(y) = Σ_{r_j} log p_θ(y | [x; r_j; x]) via greedy per-step logit aggregation, and it exhibits a log-linear scaling relationship between performance and the number of sampled responses.

## Results

Integrative Decoding (ID) achieves absolute improvements of 3.7–10% on TruthfulQA (T*I), 1.1–15.4% on Biographies (%Accuracy), and 1.6–8.5% on LongFact (F1@128) across six LLMs (LLaMA2, LLaMA3, Mistral2, Gemma2, Qwen2, GLM4). The largest gains appear on LLaMA3 and Gemma2, with Gemma2 reaching 80.4 F1@128 on LongFact (+8.5 over greedy) and 57.4% accuracy on Biographies (+15.4). ID also improves informativeness metrics (e.g., Recall@128 up to +11.4% on LongFact), indicating it elicits more parametric knowledge rather than merely filtering errors. Performance scales log-linearly with the number of sampled responses (k=1 to 16).

## Baselines & Comparisons

ID outperforms all five self-consistency baselines (USC, SR, FSC, SE-SL, SE-RG) and DoLa across all six LLMs and all three benchmarks. DoLa provides only marginal gains (≤0.7%) and is effectively a no-op on open-ended tasks. USC and SR, which concatenate all sampled responses into a single prompt, fail to scale with k and even degrade performance on weaker models (USC drops LLaMA2 TruthfulQA by ~1%; SR drops Gemma2 LongFact F1@128 by 14.6 points and GLM4 Recall@128 by 25.9 points). FSC and SE-RG achieve moderate improvements on Biographies (~5–6%) but struggle on LongFact, often reducing recall substantially. ID's key advantage is that it only extends the input by one sampled response (×1 vs. ×k for USC/SR), yielding inference latency of 1.13 ms/token (11× greedy) versus 7–8 ms/token for SE-SL/SE-RG, while delivering the largest and most consistent factuality gains.

## Relation to Prior Work

This paper repurposes the self-consistency paradigm—originally developed for exact-match tasks like arithmetic and multiple-choice questions—into a decoding-time mechanism for open-ended generation. Rather than following prior open-ended SC methods (USC, SR, FSC, SE-SL/SE-RG) that explicitly verify consistency through prompting, chain-of-thought reasoning, or clustering, ID implicitly encodes self-consistency into the decoding objective by constructing inputs that reference each sampled response and aggregating their predicted logits. Conceptually, it also sits in tension with contrastive decoding (O'Brien & Lewis, 2023), which subtracts logit distributions, whereas ID sums them, making it an 'opposite' operation that leverages in-context learning to make each input vote for semantically consistent tokens.

## Why It Matters / Open Questions

ID provides a practical, low-overhead path to scaling factuality improvements with inference-time compute on open-ended tasks, where prior SC methods either inflate context length (USC, SR) or require expensive iterative verification (SE-SL, FSC). The log-linear scaling with the number of sampled responses suggests that 'inference-time scaling laws' may extend beyond exact-match settings, which is significant for the broader trend of trading compute for accuracy. Open questions include whether the locally-optimal greedy approximation (Eq. 8) can be improved via beam search, whether combining ID with speculative decoding can reduce the ~11× latency overhead, and whether the scaling trend continues indefinitely or saturates.

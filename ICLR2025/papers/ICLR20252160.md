## Problem

Replay-based continual learning for 3D point clouds relies on storing raw exemplars selected via herding, which is poorly suited to the irregular, multimodal geometry of point clouds and raises privacy and memory concerns as tasks accumulate. No prior 3D continual learning method avoids storing original data while maintaining competitive accuracy, leaving a gap in memory-efficient, privacy-preserving exemplar strategies for the 3D domain.

## Input / Output

The method consumes pre-registered, resampled 3D point clouds (each an n×3 matrix with fixed point count) and outputs a class label via a shared point cloud network. For old classes, no raw samples are stored; instead, a compact shape model (mean shape plus two SVD-derived modes of variation per class, totaling 120 stored components across all classes) is used to generate synthetic training samples on the fly with a small perturbation coefficient α=0.2 to remain in the high-probability region of the shape space.

## Method

MIRACLE3D replaces stored exemplars with per-class statistical shape models built via SVD on mean-centered, vectorized point clouds, retaining only the mean shape and k=2 principal modes of variation with their singular values. During each incremental session, synthetic samples for old classes are generated as Z = X̄ + α Σ εᵢ σᵢ Vᵢ and trained with focal loss, while new-class samples use cross-entropy plus knowledge distillation. The key novelty is Gradient Mode Regularization, which adds a penalty λ Σᵢ ⟨∂L_FL/∂Z, Vᵢ⟩² to the old-class loss, forcing the loss surface to be flat along the principal shape-variation directions and thereby broadening classification margins. The approach is backbone-independent (operating directly in input space) and was validated with PointNet, DGCNN, and PointMLP-elite, achieving state-of-the-art accuracy on ModelNet40, ShapeNet, and ScanNet while using only 15% (or 8.5% for ScanNet) of the memory of competing methods.

## Results

On ModelNet40, MIRACLE3D achieves 88.1% average accuracy and 74.6% last-session accuracy, outperforming the previous best 3D-specific method InOR-Net (87.0% / 63.9%) by 1.1% and 10.7% respectively. On ShapeNet, it reaches 84.9% / 71.5%, and on the noisier real-world ScanNet dataset, 72.9% / 57.2%. Critically, all results are obtained while storing only 120 exemplars in memory, compared to 800 (ModelNet40), 1000 (ShapeNet), or 600 (ScanNet) for competing methods — a reduction to roughly 15% of the memory footprint.

## Baselines & Comparisons

MIRACLE3D outperforms all 11 baselines on every metric across all three datasets. Against the strongest 3D-specific competitors, it beats InOR-Net by 1.1% A_avg and 10.7% A_last on ModelNet40, by 1.2% / 2.1% on ShapeNet, and by 0.7% / 2.4% on ScanNet, while using only 120 stored exemplars versus InOR-Net's 800–1000. It also surpasses CL3D (the authors' prior work) by 3.0% / 4.9% on ModelNet40, 4.1% / 3.9% on ShapeNet, and 1.1% / 1.8% on ScanNet, with identical memory usage (120). Among 2D approaches adapted to 3D, the best performer RPS-Net (81.7% A_avg on ModelNet40) trails MIRACLE3D by 6.4% A_avg and 16.3% A_last, underscoring the gap between generic 2D continual learning and dedicated 3D methods. The memory advantage is the most striking: 120 exemplars represent only 15% of the 800 used on ModelNet40, 12% of the 1000 on ShapeNet, and 20% of the 600 on ScanNet, while simultaneously achieving the highest accuracy.

## Relation to Prior Work

This paper departs from the dominant exemplar-selection paradigm in 3D continual learning (I3DOL, InOR-Net, CL3D), which relies on herding or spectral clustering to pick raw point clouds for storage, by instead constructing a compact Statistical Shape Model (mean + SVD modes) per class and generating synthetic samples on demand. It repurposes the gradient-regularization idea from Double Backpropagation, but applies it specifically along the principal shape-variation directions rather than in arbitrary input directions, yielding the novel Gradient Mode Regularization term. The approach also inherits focal loss and knowledge distillation from prior 3D incremental learning work to handle class imbalance and anchor old-class predictions.

## Why It Matters / Open Questions

The 85% memory reduction (120 stored components vs. 800–1000 exemplars) while simultaneously improving last-session accuracy by 4.9–10.7% over prior 3D methods is practically significant for deployment-constrained and privacy-sensitive settings (e.g., medical imaging, GDPR compliance). The backbone-independence result—nearly identical forgetting rates across PointNet, DGCNN, and PointMLP—suggests the shape-model strategy is a portable component rather than an architecture-specific trick. Open questions remain: affine registration occasionally produces degenerate shapes, intra-class variability in heterogeneous categories limits morphing quality, and whether a learned (neural) shape model could replace the linear SVD formulation without sacrificing the memory advantage.

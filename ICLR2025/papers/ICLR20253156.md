## Problem

Traditional video games are inherently finite: all mechanics, graphics, and rules must be pre-defined in code, limiting them to a fixed set of actions and endpoints. While recent generative models can produce individual game components (levels, narratives, or images), no prior system fully generates all game elements—mechanics, characters, environments, narrative, and graphics—within a single open-ended, real-time interactive experience. This paper tackles the gap by proposing the first generative infinite game where every aspect of gameplay is produced by generative models at interactive speed.

## Input / Output

The system consumes character reference images (fine-tuned into a DreamBooth LoRA with a unique identifier token 'sks'), a single environment reference image, a scene text prompt, and free-form natural language user instructions (e.g., 'I pet the character and then take them for a rocket ride'). It produces a high-resolution scene image refreshed approximately every second (via SDXL + LCM with 2 diffusion steps), a narrative description, updated character state values (hunger, energy, fun, hygiene), and character dialogue. The LLM game engine processes multi-round interaction history to maintain coherence across the session, and the image generator must simultaneously preserve character identity, environment fidelity, and text-prompt alignment in a single forward pass.

## Method

The visual pipeline introduces a regional IP-Adapter with block drop: at each cross-attention layer, a dynamic binary mask is computed from the attention map between a predefined character text embedding and the text cross-attention hidden states (thresholded at the top 60%), routing environment conditioning to mask=1 regions and character conditioning to mask=0 regions, thereby preventing mutual interference. The adapter is dropped entirely in downsample blocks (where attention spreads across the full image rather than localizing on the character) and applied only in mid and upsample blocks, improving spatial layout while preserving character-specific details in later layers. On the language side, a Gemma-2B model is distilled via supervised fine-tuning on 5,000 synthetic multi-round interaction samples generated by two collaborative GPT-4o agents (a world-simulation LLM and a user-simulation LLM), with loss masked on user turns so the small model learns only the game-engine behavior. This distilled LLM handles environment binding, coherent story generation, character state tracking, and prompt rewriting for the diffusion model, achieving GPT-4o-comparable quality at ~1-second latency.

## Results

On the image generation benchmark (5,000 character-environment-prompt triplets), UNBOUNDED's regional IP-Adapter achieves the best character consistency across all three metrics (CLIP-I^C=0.676, DINO^C=0.470, DreamSim^C=0.488) and the best CLIP-I^E environment consistency (0.563), while matching StoryDiffusion on semantic alignment (CLIP-T=0.242). For the LLM game engine, the distilled Gemma-2B achieves an overall GPT-4-judged score of 7.44/10, approaching GPT-4o's 7.68, while substantially outperforming zero-shot Gemma-2B (6.22), Gemma-7B (6.80), and Llama3.2-3B (7.21). The system achieves near real-time inference with a ~1-second refresh rate using LCM (2-step diffusion) and the 2B-parameter distilled LLM.

## Baselines & Comparisons

Against IP-Adapter (Ye et al., 2023), UNBOUNDED substantially improves character consistency (CLIP-I^C: 0.676 vs. 0.366; DreamSim^C: 0.488 vs. 0.832) and CLIP-I^E environment consistency (0.563 vs. 0.470), though IP-Adapter retains a slight edge on DINO^E (0.381 vs. 0.322) and DreamSim^E (0.595 vs. 0.675). Against StoryDiffusion (Zhou et al., 2024c), UNBOUNDED wins on all character consistency metrics (CLIP-I^C: 0.676 vs. 0.629; DreamSim^C: 0.488 vs. 0.545) and CLIP-I^E environment consistency (0.563 vs. 0.528), while tying on semantic alignment (CLIP-T: 0.242). IP-Adapter-Instruct (Rowles et al., 2024) is dominated across all metrics. For the LLM game engine, the distilled Gemma-2B (7.44 overall) outperforms zero-shot Gemma-2B (6.22), Gemma-7B (6.80), and Llama3.2-3B (7.21) on all five GPT-4-judged criteria, and achieves performance within ~0.2 points of GPT-4o (7.68) while running at interactive speed. Human evaluation (Table 4) confirms the distilled LLM is statistically comparable to GPT-4o (46.5% ties, 26.5% wins vs. 27.0% losses overall).

## Relation to Prior Work

This paper extends IP-Adapter (Ye et al., 2023) with a regional variant that uses dynamic masks derived from cross-attention between character text embeddings and hidden states to spatially separate character and environment conditioning, combined with block drop in downsample layers. For character personalization, it builds on DreamBooth (Ruiz et al., 2023) via LoRA fine-tuning, merged arithmetically with LCM LoRA for few-step inference. On the language side, it departs from prior game-generation work (which typically produces individual components like levels or rules) by distilling a full game-engine LLM from GPT-4o into a 2B model using synthetic multi-agent interaction data, positioning the result as the first system where all game components—mechanics, narrative, graphics, characters, and environments—are produced by generative models rather than hard-coded.

## Why It Matters / Open Questions

The paper demonstrates that a fully generative, interactive game loop is feasible at near-real-time speeds (~1s refresh), opening a path toward games without pre-defined mechanics or assets. The regional IP-Adapter with dynamic masks is a practical technique for consistent dual-conditioning (character + environment) that could transfer to other multi-subject generation settings. However, the system remains image-based (not video), supports a single character, and the 'infinite' nature is bounded by LLM coherence over long sessions; open questions include scaling to multi-character interactions, video generation, and whether the distilled 2B model's game-engine quality degrades over extended play. The evaluation, while thorough, is on a relatively small scale (5K image triplets, 100 LLM interaction samples), leaving questions about robustness at scale.

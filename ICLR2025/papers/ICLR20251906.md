## Problem

Private Transformer inference via hybrid HE/MPC protocols suffers from quadratic runtime scaling with input token length and expensive high-degree polynomial approximations for non-linear activations. Prior approaches like BOLT's word elimination perform fixed-ratio, one-time pruning that is neither input-specific nor progressive, and no existing protocol supports encrypted token pruning or encrypted polynomial reduction with joint threshold optimization.
![Teaser figure](../imgs/ICLR20251906/cropped_page1_idx1.webp)

## Input / Output

The client encrypts a sequence of n text tokens (e.g., 128 or 512 tokens for BERT/GPT2) which are split into additive secret shares between the client and server; the server holds private Transformer weights. During inference, the token count after pruning (n') is disclosed to both parties, but the specific locations of pruned tokens remain hidden. The final output is the standard inference prediction (e.g., sentiment label, NLI classification) computed over the progressively pruned and polynomial-reduced token sequence.

## Method

CipherPrune introduces three coupled components. First, an encrypted token pruning protocol (Π_prune + Π_mask) computes per-token importance scores from secret-shared attention maps via local ASS operations, thresholds them with a learned per-layer threshold θ using a comparison protocol, and then relocates pruned tokens to the sequence end via OT-based oblivious swaps on mask-bound tokens (MSB encoding), achieving O(mn) complexity instead of O(n log²n) for sorting. Second, an encrypted polynomial reduction protocol assigns a second threshold β > θ; tokens below β are computed with low-degree polynomials (e.g., degree-2 for GELU, degree-3 Taylor for SoftMax) while important tokens retain high-degree approximations, reducing non-linear overhead by up to 10×. Third, a crypto-aware fine-tuning procedure (Algorithm 1) jointly optimizes θ, β, and model weights via gradient descent with differentiable sigmoid soft masks, a composite loss L = L_task + λ(L_prune + α·L_approx) that balances accuracy against pruning and reduction aggressiveness, followed by a binarization-and-refinement phase to meet a target accuracy threshold.

## Results

On BERT-Base with 128 input tokens, CipherPrune achieves 79.1s runtime and 9.7 GB communication with 90.1% average accuracy, compared to BOLT's 245.4s / 25.7 GB / 89.9% and IRON's 1087.8s / 281.0 GB / 90.4%. On BERT-Large, CipherPrune reaches 157.6s (18.2× faster than IRON, 3.9× faster than BOLT) while maintaining 92.5% accuracy. For GPT2-Base, CipherPrune achieves ~6.1× speedup over BOLT at 128 tokens and ~10.6× at 512 tokens, demonstrating that the progressive pruning strategy increasingly benefits longer inputs where quadratic complexity dominates.

## Baselines & Comparisons

CipherPrune outperforms all five baselines on both runtime and communication while matching or slightly exceeding their accuracy. Against IRON (Hao et al., 2022), CipherPrune achieves 10.1×–18.2× speedup across BERT sizes (e.g., 157.6s vs. 2873.5s on BERT-Large) with comparable accuracy (92.5% vs. 92.7%). Against BOLT (Pang et al., 2024), which already incorporates a fixed 50% word-elimination technique, CipherPrune is 3.9× faster on BERT-Large and 6.1×–10.6× faster on GPT2-Base at 128 and 512 tokens respectively, while maintaining or improving accuracy (90.1% vs. 89.9% on BERT-Base). In the appendix, CipherPrune extends to other frameworks: it achieves 4.3× speedup over BumbleBee (Lu et al., 2025) in a 1 Gbps LAN setting, 6.6×–9.4× over MPCFormer (Li et al., 2022), and 2.8×–4.6× over PUMA (Dong et al., 2023) on BERT-Large and GPT2-Large. The key differentiator is CipherPrune's input-specific, progressive pruning (vs. BOLT's one-time 50% W.E.) combined with polynomial reduction, which together reduce both the quadratic SoftMax and linear GELU overheads layer by layer.

## Relation to Prior Work

CipherPrune builds directly on the hybrid HE/MPC private Transformer inference paradigm established by IRON (Hao et al., 2022) and advanced by BOLT (Pang et al., 2024), which introduced the word elimination (W.E.) technique for token reduction. The key departure is that BOLT's W.E. is neither input-specific (it uniformly prunes 50% of tokens) nor progressive (it prunes once at the first layer), whereas CipherPrune adapts plaintext-domain progressive token pruning (Goyal et al., 2020; Kim et al., 2022) to the encrypted setting via a new secure protocol. Additionally, CipherPrune introduces encrypted polynomial reduction—assigning lower-degree polynomial approximations to less important tokens—which has no direct counterpart in prior private inference work, and jointly optimizes both pruning and reduction thresholds through a crypto-aware fine-tuning procedure.

## Why It Matters / Open Questions

Private Transformer inference remains impractical for long inputs due to quadratic scaling; CipherPrune's progressive pruning effectively shifts this toward linear complexity, making 512-token private inference ~10.6× faster than the prior SOTA. This is practically significant for deploying privacy-preserving NLP services on realistic input lengths. However, the evaluation is limited to GLUE classification tasks and GPT2 prefilling (single-token generation), leaving open whether the approach extends to full autoregressive decoding with KV caches, sequence-to-sequence tasks with less redundancy, or larger models like LLaMA. The semi-honest threat model and the assumption that the number of pruned tokens is public also limit applicability to more adversarial settings.

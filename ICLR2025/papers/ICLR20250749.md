## Problem

Existing MARL communication protocols rely on learning pairwise connectivity among agents, which scales poorly to large-scale systems: identifying useful peers becomes intractable as agent count grows, and communication overhead scales quadratically. This paper asks whether a global, rule-based topology design can replace pairwise link selection to achieve scalable, low-cost information dissemination among dozens to hundreds of agents.
![Teaser figure](../imgs/ICLR20250749/cropped_page3_idx2.webp)

## Input / Output

Each agent receives its local observation o_i^t and messages from a fixed set of peers determined by the exponential graph adjacency (either all 2^k-hop neighbors simultaneously for the static variant, or a single rotating peer per timestep for the one-peer variant). The agent outputs an action a_i^t and an outgoing message m_i^t that is updated from its previous message and the messages it just received. The communication budget K is either 1 (one-peer, linear overhead) or ⌈log₂N⌉ (static, near-linear overhead), and the topology is entirely rule-based with no learned connectivity.

## Method

ExpoComm replaces learned pairwise communication links with exponential graph topologies, which guarantee that any two agents can exchange information within ⌈log₂(N-1)⌉ timesteps (small diameter) while maintaining only O(N) or O(N log N) edges (small size). Two variants are used: a static exponential graph where each agent simultaneously communicates with all 2^k-hop neighbors, and a one-peer variant where each agent cycles through those neighbors one per timestep. To exploit the multi-timestep message flow enabled by the small diameter, memory-based processors (GRU for one-peer, attention for static) accumulate received messages over the diameter window rather than processing each timestep independently. Messages are grounded via auxiliary objectives—global state prediction when the global state is available, or InfoNCE contrastive learning treating same-timestep messages as positives and temporally distant messages as negatives—ensuring messages encode global information useful for decision-making. The overall training combines the standard QMIX/IDQN TD loss with the auxiliary loss, and the theoretical analysis (Theorem 1) proves the Boolean product of adjacency matrices over ⌈log₂(N-1)⌉ consecutive timesteps yields an all-ones matrix, confirming full information reachability.

## Results

On the IMP benchmark (normalized discounted reward relative to expert heuristics), ExpoComm with one-peer topology (K=1) achieves 43.82% on Correlated (N=50), 27.34% on Uncorrelated (N=100), and 19.17% on Correlated (N=100), substantially outperforming QMIX without communication (24.81%, 12.86%, and −40.20% respectively). On MAgent (AdversarialPursuit and Battle with 20–64 agents), ExpoComm consistently achieves the highest cumulative reward across all tested agent counts under both K=1 and K=⌈log₂N⌉ budgets. The one-peer variant (linear communication cost) matches or exceeds the static variant (N·log N cost) in most scenarios, confirming that near-linear overhead suffices for effective large-scale coordination.

## Baselines & Comparisons

ExpoComm outperforms QMIX (no communication) across all IMP scenarios, with the largest gap on Correlated N=100 (19.17% vs. −40.20%) and Uncorrelated N=100 (27.34% vs. 12.86%), indicating that communication is critical at scale. Against the Erdős-Rényi random-graph baseline (ER), ExpoComm wins on 5 of 6 IMP scenarios; the sole exception is OWF N=100 where ER K=1 (66.70%) slightly edges ExpoComm K=1 (65.26%), though ExpoComm K=⌈log₂N⌉ (66.23%) is competitive. On MAgent, ExpoComm surpasses DGN+TarMAC (position-based nearest-neighbor topology) in all six scenarios (25–64 agents), with the advantage widening as agent count grows. CommFormer (learned GNN topology) is outperformed by ExpoComm on MAgent and in zero-shot transfer, and is excluded at N=100 on IMP due to prohibitive GPU memory (>40 GB). In zero-shot transfer (trained on fewer agents, tested on more), ExpoComm and ER both transfer well, but ExpoComm maintains its advantage under the tighter K=1 budget, while CommFormer cannot be transferred because its learned pairwise topology is scenario-specific.

## Relation to Prior Work

This paper repurposes exponential graph topologies—previously studied in distributed learning for efficient model synchronization (Assran et al., 2019; Ying et al., 2021)—as a fixed communication backbone for MARL, departing from the dominant paradigm of learning task-specific pairwise connectivity (CommFormer, I2C, MAGIC). It builds on QMIX/IDQN as the base RL algorithm and augments the communication channel with memory-based message processors (GRU/attention) and auxiliary grounding tasks (global state prediction or InfoNCE contrastive loss), drawing on CACL's contrastive encoding idea. The key conceptual shift is from a local, per-link perspective (who should talk to whom) to a global, topology-level perspective (how should information propagate across all agents), which the authors argue is the right abstraction for many-agent systems where pairwise learning becomes intractable.

## Why It Matters / Open Questions

Scalability of MARL communication is a practical bottleneck for real-world deployments (autonomous driving, infrastructure management, logistics) where agent counts reach dozens or hundreds, yet prior methods scale quadratically in communication cost and memory. ExpoComm's demonstration that a simple rule-based topology with linear communication overhead can match or exceed learned topologies—and transfer zero-shot to unseen agent counts—offers a deployable, low-overhead alternative that avoids the GPU-memory explosion of GNN-based link learning. Open questions remain: the method does not exploit agent heterogeneity or environmental structure in topology design, has only been validated in fully cooperative settings, and the authors note that finer topologies beyond exponential graphs and temporal communication sparsity are unexplored directions.

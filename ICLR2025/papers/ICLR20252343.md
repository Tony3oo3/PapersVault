## Problem

Existing similarity indices (CCA, SVCCA, CKA) are designed for comparing neural network representations, not weight matrices, and residual connections in transformers decouple representation similarity from weight similarity. More critically, these indices are provably non-discriminative for orthogonal matrices—they assign identical scores to any pair of orthogonal matrices regardless of their actual structural differences—yet LLM weight matrices frequently retain near-orthogonal properties throughout training, rendering these tools ineffective for weight-level analysis.

## Input / Output

The method takes two weight matrices of identical shape (n×m) from corresponding components of LLM layers (e.g., MLP-UP, W_q, W_k, W_v, W_o, MLP-DOWN), where columns represent individual parameter vectors. Certain matrices (W_v, W_k, W_q, MLP-UP) are transposed before computation so that columns align with meaningful neuron-level entities. The output is a single scalar DOCS score in [0, 1], computed as the average of two Gumbel location parameters fitted to the distributions of per-column maximum absolute cosine similarities.

## Method

DOCS computes the full m×m cosine similarity matrix between all column-vector pairs of the two input matrices, then for each column in one matrix extracts the maximum absolute cosine similarity with any column in the other (the MAXCOSSIM operation). The resulting vectors of maximum similarities are each fitted to a Gumbel distribution via maximum likelihood estimation, and the DOCS score is the mean of the two estimated location parameters. The Gumbel choice is empirically justified: histograms of maximum cosine similarities closely match Gumbel shape, and the max operation (rather than averaging) is essential for preserving strong pairwise alignments that would otherwise be diluted. The key theoretical contribution is a constructive proof (Theorem 1) that DOCS is discriminative on orthogonal matrices—there exist column-orthogonal X, Y with ‖X−Y‖_F = Ω(√m) yet S_DOCS(X,Y) = 1/√m—while CCA, SVCCA, and linear CKA are all provably constant (equal to 1) on any pair of orthogonal matrices. DOCS also satisfies permutation invariance, symmetry, isotropic scaling invariance, and reflexivity, matching or exceeding the property profile of prior indices.

## Results

On the MLP-UP layers of Meta-Llama-3.1-8B-Instruct, DOCS achieves the highest Gini coefficient (0.0745) among all eight similarity indices, indicating the most concentrated and structurally informative similarity distribution. In the similarity ratio experiment (comparing base vs. instruction-tuned vs. randomly initialized models), DOCS yields a ratio approximately 10× higher than Linear CKA, SVCCA, or SVCCA (Nuclear), demonstrating far superior ability to distinguish meaningful weight relationships from noise. DOCS is also the only index that is discriminative on orthogonal matrices, a critical property given the prevalence of near-orthogonal weight matrices in LLMs.

## Baselines & Comparisons

DOCS outperforms all four compared baselines on the Gini coefficient metric: it achieves 0.0745 versus 0.0488 for Linear CKA (Kornblith et al., 2019), 0.0225 for SVCCA (Raghu et al., 2017), 0.0098 for CCA (Morcos et al., 2018), and 0.0617 for Linear HSIC (Gretton et al., 2005). More critically, DOCS is the only method that is discriminative on orthogonal matrices, while CCA, SVCCA, and Linear CKA are all constant (yielding a score of 1 for any pair of orthogonal matrices), and Linear HSIC is merely dimension-dependent. In the similarity ratio experiment, DOCS separates base-model/instruction-tuned similarity from base-model/random-initialization similarity by roughly 10×, whereas the other indices show much weaker separation. Visually, DOCS heatmaps reveal clear diagonal structure and layer clusters, while CCA and Linear Regression heatmaps appear noisy and SVCCA/Linear CKA show spurious off-diagonal stripes attributable to their inability to differentiate orthogonal matrices.

## Relation to Prior Work

This paper extends the well-established line of neural network similarity analysis (CCA, SVCCA, CKA, HSIC) by shifting the target from learned representations to raw weight matrices, arguing that residual connections in transformers make representation-based similarity misleading for understanding weight structure. It departs from prior methods' reliance on aggregate matrix operations (SVD, kernel alignment) by instead computing per-vector maximum cosine similarities and fitting a Gumbel extreme-value distribution, a design choice motivated by the need to capture strong pairwise alignments rather than diluted averages. The key conceptual departure is the formal identification and resolution of the non-discriminative behavior of all major existing indices on orthogonal matrices—a property that is particularly problematic given the prevalence of near-orthogonal weight matrices in trained LLMs.

## Why It Matters / Open Questions

DOCS provides the first similarity metric with a provable discriminative guarantee on orthogonal matrices, filling a gap that limits the interpretability of all prior representation-similarity tools when applied to weights. The empirical discovery of layer clusters and the high (>0.7) similarity between base and instruction-tuned models offer concrete hooks for model compression, PEFT design, and knowledge distillation strategies. However, the practical exploitation of cluster structure (e.g., non-uniform layer configurations) remains speculative, the Gumbel fitting is a heuristic not derived from first principles, and validation is limited to a handful of open-source models. Open questions include whether DOCS generalizes to non-orthogonal or low-rank weight matrices, whether the identified clusters are stable across training seeds, and whether leveraging them actually improves downstream performance.

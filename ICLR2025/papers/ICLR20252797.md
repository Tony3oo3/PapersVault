## Problem

Despite extensive theoretical claims that distribution-preserving LLM watermarks are inherently undetectable by downstream users, no prior work has empirically tested whether any current watermarking scheme is actually detectable in a realistic black-box setting. This paper is the first to rigorously investigate the practical detectability of the three most prominent watermark families (Red-Green, Fixed-Sampling, and Cache-Augmented) under the minimal assumption of only textual prompt-response access.

## Input / Output

The adversary interacts with the LLM solely through text prompts and receives only the model's textual response — no log-probabilities, no temperature control, no additional metadata. The method produces a p-value for each of the three watermark families (rejecting the null of 'no watermark of this type'), and upon detection, can estimate key scheme parameters such as the logit bias δ, context size h, key length n_key, and reweighting parameter α. Query costs are low: under $3 for Red-Green, $0.3 for Fixed-Sampling, and $0.1 for Cache-Augmented tests at GPT-4o pricing.

## Method

The paper develops three distinct statistical tests, each exploiting a fundamental structural property of one watermark family. For Red-Green watermarks, the test uses a prompt template with variable prefix and context to estimate per-context logits via sampling, then applies a Monte Carlo permutation test on a statistic measuring whether abnormally high/low logits correlate with the context (the watermark's seeding variable). For Fixed-Sampling watermarks, the test exploits the fact that the number of unique outputs is bounded by the key size n_key, constructing a rarefaction curve and applying a Mann-Whitney U test against the linear expectation R(n)=n that an unwatermarked diverse model would exhibit. For Cache-Augmented watermarks, the test uses a two-phase querying strategy: first populating the cache with a random prefix to reveal the true distribution, then clearing the cache to observe the watermarked distribution, and applying Fisher's exact test to detect the discrepancy. All three tests are validated across seven open-source models, eleven scheme configurations, and three real-world API deployments (GPT-4, Claude 3, Gemini 1.0 Pro).

## Results

Across seven open-source models and eleven watermarking scenarios, all three statistical tests reject the null hypothesis (p < 0.05) only when the target watermark family is applied, with median p-values as low as 3.7×10⁻¹⁰⁵ (Fixed-Sampling, n_key=256) and 5.6×10⁻²⁷ (Cache-Augmented δ-REWEIGHT). No false positives are observed: p-values remain above 0.05 for unwatermarked models and for models watermarked with a different scheme family. The tests are cost-effective, requiring less than $3 (Red-Green), $0.3 (Fixed-Sampling), and $0.1 (Cache-Augmented) in API costs. Applied to GPT-4, Claude 3, and Gemini 1.0 Pro, no watermark is detected (all p-values > 0.05).

## Baselines & Comparisons

This is the first work to perform black-box watermark detection, so there are no prior detection baselines to compare against. The paper's internal comparison is between the three proposed tests and the null hypothesis (no watermark of the target family). Each test achieves near-zero p-values exclusively for its target family: the Red-Green test detects LeftHash and SelfHash variants (p=0.000–0.020) while remaining above 0.05 for Fixed-Sampling and Cache-Augmented schemes; the Fixed-Sampling test detects ITS/EXP watermarks (p as low as 4.5×10⁻¹²⁵) with no cross-detection; the Cache-Augmented test detects DIPMARK and δ-REWEIGHT (p as low as 5.6×10⁻²⁷) without false positives. The tests also generalize to variants: multi-key Red-Green (n=3 keys, p<10⁻⁴), no-cache Cache-Augmented schemes (detected via the Red-Green test, p=0.000), and SynthID-Text (p=0.000 on Gemma-7B). Under adversarial modifications (disabling watermark every k queries), detection remains effective for k=2–5, though p-values increase (e.g., Fixed-Sampling p goes from 4.5×10⁻¹²⁵ to 8.0×10⁻⁹³ at k=5). On real-world APIs (GPT-4, Claude 3, Gemini 1.0 Pro), no watermark is detected, consistent with the absence of publicly confirmed watermarking in these deployments.

## Relation to Prior Work

This paper carves new ground by being the first to study practical black-box detection of LLM watermarks, where the adversary has only textual access to a deployed model. The closest prior work, Tang et al. (2023), requires either an unwatermarked counterpart or full logit access—neither available in realistic deployments. The detection tests are built on the fundamental structural properties of the three dominant watermark families (Red-Green, Fixed-Sampling, Cache-Augmented), repurposing classical statistical tools (permutation tests, Mann-Whitney U, Fisher's exact test) in a novel watermarking context. The work also connects to the broader black-box model extraction literature (Carlini et al., 2024; Naseh et al., 2023), but targets a fundamentally different signal: the watermark mechanism rather than model internals.

## Why It Matters / Open Questions

The central finding—that distribution-preserving watermarks explicitly designed for undetectability are in fact easily detectable at very low cost (under $0.30)—challenges a core design assumption in the watermarking literature and has immediate practical implications for model providers deploying watermarks. Detection is a prerequisite for stronger attacks (spoofing, assisted scrubbing), so this work effectively lowers the barrier to undermining watermark deployments. Key open questions include whether truly undetectable schemes exist in practice (Christ et al., 2024's theoretical construction is not yet viable), whether the tests generalize to entirely novel scheme families, and the lack of theoretical power guarantees for the proposed tests. The paper also notes that adversarial modifications (selectively disabling watermarks) only partially degrade detectability, suggesting the fundamental structural signatures are hard to hide.

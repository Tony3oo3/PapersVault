## Problem

Search and planning are essential for complex decision-making, but constructing search trees typically requires data (e.g., full state-space coverage, known transition dynamics) that is not available from mere demonstration sequences. Supervised learning from these sequences alone yields sub-optimal performance because the agent encounters a vast, unseen search space at test time. This paper asks: can we learn to perform best-first tree search end-to-end from only action-observation sequences, including jointly learning an imperfect world model in a latent space?

## Input / Output

The method consumes offline demonstration trajectories of the form {(s_i, a_i, r_i, Q_i)}, where states are either text token sequences (Game of 24) or raw pixel images (20×20 grid for Navigation, 64×64 game screens for Procgen). It outputs Q-values for each action at the root node, which are then used to select the best action or to guide a best-first search at inference time. When the world model is learned, all search operations (transition, reward, value) are performed in a learned latent space rather than the original observation space, with tanh normalization applied to keep latent states in (-1, 1).

## Method

D-TSN embeds a best-first search algorithm directly into the network architecture by composing four learnable submodules—Encoder, Transition, Reward, and Value—into a dynamically constructed computation graph. The key technical challenge is that a naive best-first search produces a loss function discontinuous in parameter space (a small parameter change can switch which node is expanded, causing a large loss jump); D-TSN resolves this by sampling the next node to expand from a softmax distribution over path values, making the expected loss continuous. The gradient of this expected loss is computed via REINFORCE, with variance reduced by a telescoping-sum baseline that rewrites the final loss as a sum of per-iteration loss reductions. Training uses a combined objective: Q-value matching (behavior cloning), CQL regularization against out-of-distribution actions, and self-supervised consistency losses on the transition and reward modules, all optimized end-to-end so the world model learns to be reliable specifically in the regions the search explores.

## Results

On the 2D grid Navigation task (1-exit generalization setting), D-TSN achieves 99.3% success rate with only 0.2% collision rate, substantially outperforming TreeQN (51.8%), Model-free Q-network (47.1%), and Model-based Search (86.9%). On Procgen (16 games, sub-optimal behavior policy), D-TSN attains a mean Z-score of 0.35 versus 0.27 for TreeQN and 0.10 for Model-based Search, winning 13/16 head-to-head games against both Model-free Q-network and TreeQN, and 16/16 against Model-based Search. On Game of 24 with a known world model, D-TSN reaches 45.24% success rate with 10k training trajectories, more than doubling the 21.32% of a supervised fine-tuned Llama3-8B model with search.

## Baselines & Comparisons

Against TreeQN (the primary cited baseline), D-TSN wins decisively on the Navigation 1-exit generalization task (99.3% vs 51.8% success rate) and on Procgen mean Z-score (0.35 vs 0.27), winning 13/16 head-to-head games. The gap is most dramatic in the generalization setting: TreeQN's fixed-depth-2 full expansion cannot handle the longer planning horizon of the 1-exit scenario, while D-TSN's best-first search with 10 iterations maintains near-perfect performance. Against Model-based Search (independently trained world model + search), D-TSN wins all 16 Procgen games and achieves 99.3% vs 86.9% on Navigation 1-exit, demonstrating that joint optimization of the world model and search algorithm is critical for robustness. Against the Model-free Q-network, D-TSN wins 13/16 Procgen games and 99.3% vs 47.1% on Navigation 1-exit, confirming the value of the search inductive bias. On Game of 24, D-TSN outperforms SFT+Search by 24 percentage points at 10k trajectories, with the advantage growing as training data decreases.

## Relation to Prior Work

D-TSN extends the differentiable tree search lineage initiated by TreeQN (Farquhar et al., 2018), which performs full tree expansion to a fixed depth, by replacing it with a variable-depth best-first search that can explore deeper and more promising branches. The stochastic tree expansion policy and the telescoping-sum variance reduction for the REINFORCE gradient draw directly from MCTSnets (Guez et al., 2018), but are applied to a fundamentally different search structure. The paper also positions itself within the offline-RL / learning-from-demonstrations paradigm, distinguishing itself from prior search-embedding methods (NEAR, Neural A*) that require a known world model, by jointly learning the world model end-to-end with the search algorithm.

## Why It Matters / Open Questions

The key practical contribution is showing that joint optimization of a world model with a best-first search algorithm makes the world model robust to compounding errors during deeper online search — a failure mode that plagues independently trained world models. This opens a path toward planning from limited demonstration data in settings where no simulator exists. However, the current implementation is restricted to deterministic environments with discrete action spaces and 2D visual observations; extending to stochastic transitions, continuous actions, and language-based observations (where the action space is combinatorially large) remains an open challenge that the authors explicitly flag as future work.

## Problem

Diffusion Transformer (DiT) incurs substantial computational cost because it applies a fixed architecture uniformly across all diffusion timesteps and all spatial patches, despite the noise prediction task being progressively easier at later timesteps and varying in difficulty across image regions. This static inference paradigm introduces significant redundant computation that existing pruning methods fail to exploit, as they also produce a single static architecture for the entire generation process.
![Teaser figure](../imgs/ICLR20252356/cropped_page1_idx0.webp)

## Input / Output

The model takes Gaussian noise as input along with a class label (ImageNet) or text prompt (COCO) and generates a 256×256 or 512×512 RGB image over 250 DDPM steps (or fewer with DDIM/DPM-Solver++). Unusually, the effective model architecture changes during generation: the number of active attention heads and MLP channel groups varies per timestep, and the number of tokens processed by each MLP block varies per spatial location, so the FLOPs per step are not fixed but adapt to the current denoising stage and image content.

## Method

DyDiT introduces two plug-and-play dynamic mechanisms on top of a pre-trained DiT. Timestep-wise Dynamic Width (TDW) uses lightweight routers conditioned on the timestep embedding to produce binary masks that select which MHSA heads and MLP channel groups to activate at each step; because the masks depend only on the timestep, they can be pre-computed offline, enabling efficient batched inference without per-sample graph changes. Spatial-wise Dynamic Token (SDT) adds a token router before each MLP block that predicts per-token bypass probabilities, allowing 'easy' patches (e.g., uniform backgrounds) to skip the MLP entirely while preserving MHSA for full token interaction. Training combines the standard diffusion loss with a FLOPs-constrained loss that penalizes deviation from a target FLOPs ratio λ, using straight-through estimators for end-to-end router learning. Only <3% additional fine-tuning iterations on pre-trained DiT weights are needed, and the method reduces DiT-XL FLOPs by 51% with a 1.73× speedup while achieving FID 2.07 on ImageNet 256×256.

## Results

On ImageNet 256×256, DyDiT-XL with λ=0.5 achieves a FID of 2.07 with only 57.88 GFLOPs (51% reduction from DiT-XL's 118 GFLOPs), yielding a 1.73× speedup while outperforming DiT-XL (FID 2.27). With λ=0.7, DyDiT-XL reaches FID 2.12 at 84.33 GFLOPs (1.32× speedup). At 512×512 resolution, DyDiT-XL λ=0.7 achieves FID 2.88 with 375 GFLOPs, surpassing DiT-XL (FID 3.04, 514 GFLOPs) by 0.16 FID while using 27% fewer FLOPs. On fine-grained datasets (Food, Artbench, Cars, Birds), DyDiT-S λ=0.5 maintains an average FID of 13.98 versus 12.27 for the full DiT-S, while all static pruning baselines degrade to 35–58 average FID at similar FLOPs.

## Baselines & Comparisons

DyDiT-XL λ=0.5 (FID 2.07, 57.88 GFLOPs) outperforms DiT-XL (FID 2.27, 118 GFLOPs) by 0.20 FID while halving the compute, and also beats U-ViT-H/2 (FID 2.29), DiffuSSM-XL (FID 2.28), and DiM-H (FID 2.21) at substantially lower FLOPs. It is within 0.01 FID of SiT-XL (2.06) and 0.37 FID of DiMR-XL (1.70), the two strongest static baselines. Against static pruning methods (Magnitude, Taylor, Diff Pruning) and token merging (ToMe 20%), DyDiT consistently achieves 20–40 FID lower scores at matched FLOPs on fine-grained datasets (e.g., average FID 13.98 vs. 35–58 for pruned DiT-S). On 512×512, DyDiT-XL λ=0.7 (FID 2.88) beats DiT-XL (3.04) but trails SiT-XL (2.62), indicating the dynamic architecture narrows but does not fully close the gap to the best static model at higher resolution. The method also outperforms the early-exiting baseline ASE (1.34–1.39× speedup) with a 1.73× speedup at comparable FID, and combines additively with DeepCache to reach 2.99 s/image at FID 2.43 versus DiT-XL+DeepCache's 5.02 s/image at FID 2.47.

## Relation to Prior Work

DyDiT builds directly on the DiT architecture (Peebles & Xie, 2023), fine-tuning pre-trained checkpoints to introduce dynamic computation. It departs from static structural pruning methods (Fang et al., 2024; He et al., 2017; Molchanov et al., 2016) by retaining full model capacity and selectively activating heads/channels per timestep rather than permanently removing them. The approach also extends dynamic neural network research (Herrmann et al., 2020; Meng et al., 2022; Han et al., 2024c) to the diffusion setting, but critically avoids the per-sample inference graph problem by conditioning width on timestep alone (pre-computable offline) and using batch-friendly token-level bypassing in MLP blocks.

## Why It Matters / Open Questions

DyDiT offers a practical, plug-and-play path to halving DiT's computational cost with <3% additional fine-tuning, which is significant given DiT's role as a foundational architecture (e.g., Sora). The hardware-friendly design enabling efficient batched inference distinguishes it from prior dynamic networks that struggle in practice. Open questions include: whether the approach extends to video generation and controllable generation, how it interacts with distillation-based samplers (LCM showed instability at aggressive FLOPs ratios), and whether the redundancy patterns generalize beyond ImageNet-trained models. The method is currently limited to image generation and relies on a fixed 0.5 threshold for binary activation decisions.

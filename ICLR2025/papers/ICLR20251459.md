## Problem

Existing graph foundation model approaches face a fundamental trade-off: LLM-as-predictor methods (flattening graphs to text) achieve task fluidity but fail to model graph structure, while LLM-as-enhancer methods (GNN + LLM adapter) capture structure well but are restricted to fixed output formats like classification. No prior work simultaneously achieves free-form generative output, proper structural understanding, and large-scale self-supervised pre-training on arbitrary graphs.

## Input / Output

The model takes a Text-Attribute Graph (TAG) where every node and edge carries a natural-language description, along with a designated Node of Generation (NOG) whose text serves as the generation prompt. Input is restricted to k-hop rooted subgraphs around target nodes to control sequence length, and a prompt node connected to target nodes encodes the task query. Output is autoregressively generated text on the NOG, which can be a classification label, a shortest path sequence, a common-neighbor list, or an open-ended answer depending on the prompt.

## Method

GOFA interleaves token-level GNN layers (modified TransConv) between the transformer layers of a frozen ICAE/Mistral-7B LLM, so that each node's text is first compressed into K memory-token embeddings by the LLM compressor, then undergoes GNN message passing at each token index independently before being fed back into the next LLM layer. A tanh gate initialized at zero ensures the model starts as a pure LLM and only incorporates structural information when it improves generation. Pre-training uses four self-supervised tasks—sentence completion on node text, structural understanding (generating shortest paths and common neighbors), QA-chain graphs from UltraChat, and information retrieval by node ID—enabling label-agnostic training on diverse graph corpora. A small instruction-tuning stage then teaches the model task-specific output formats, after which it handles unseen datasets zero-shot.

## Results

In zero-shot evaluation with instruction tuning, GOFA-T achieves 70.81% accuracy on Cora-Node (7-way), 71.17% on WikiCS (10-way), 87.13% on Products (5-way), 79.49% on ExplaGraphs, and 85.10% on Cora-Link, outperforming all graph foundation model baselines and LLM baselines on most tasks. GOFA-F (with broader instruction-tuning data) further improves to 80.69% on FB15K237 (10-way) and 88.34% on Products (5-way). Compared to an LLM given the same graph information as text (LLM-N), GOFA-F improves accuracy by 7.23% on ExplaGraphs, 68.98% on Cora-Link, and 43.40% on FB15K237, while also reducing inference time by up to 68%. The only notable exception is SceneGraphs QA, where GOFA (34.06%) underperforms Mistral-7B (45.95%).

## Baselines & Comparisons

GOFA-T outperforms the strongest graph foundation model baseline UniGraph by 11.72 points on WikiCS (71.17 vs. 43.45), 15.65 points on Products-47 (54.60 vs. 38.45), and 1.28 points on Cora-Node (70.81 vs. 69.53). Against the best LLM baseline Mistral-7B, GOFA-T gains 10.27 points on WikiCS, 10.61 on Products-47, and 10.72 on ExplaGraphs. On FB15K237, GOFA-F reaches 80.69%, surpassing Mistral-7B (62.48%) by 18.21 points. The one clear loss is on SceneGraphs QA, where GOFA-T (34.06%) and GOFA-F (31.36%) both trail Mistral-7B (45.95%), which the authors attribute to information-dense instruction-tuning data reducing common-sense reasoning. On Cora-Link, LLaGA (88.09%) narrowly edges out GOFA-T (85.10%), though GOFA-F (86.31%) closes the gap. In the head-to-head comparison with an LLM given identical graph information as text (Table 4), GOFA-F dominates on every dataset where the LLM does not run out of memory, with the largest margin being 68.98% on Cora-Link, while also being 2–3× faster per sample.

## Relation to Prior Work

GOFA departs from both major lines of graph-LLM integration: 'LLM as predictor' methods (GraphGPT, LLaGA, UniGraph) that flatten graphs into text or use frozen GNN encoders feeding an LLM, and 'LLM as enhancer' methods (OFA, TAPE) that use LLMs to unify features but still rely on fixed-output GNN heads. Its key architectural departure is interleaving token-level GNN layers directly inside the LLM's transformer stack, so that structural message-passing and semantic self-attention operate jointly at every layer rather than in a frozen encoder-decoder pipeline. The unified input format (Text-Attribute Graph) and k-hop subgraph task representation are inherited from OFA, while the fixed-size multi-token compression of node text is borrowed from ICAE, and the GNN itself is a modified TransConv.

## Why It Matters / Open Questions

GOFA is the first model to simultaneously satisfy the three properties the authors identify for a graph foundation model—label-agnostic self-supervised pretraining, free-form generative output (task fluidity), and prompt-conditioned structural understanding—without requiring task-specific heads. The >10% zero-shot gains over the strongest baselines on WikiCS, Products, FB15K237, and ExplaGraphs, combined with a ~68% inference speedup over an LLM given the same graph information, make the interleaved GNN-in-LLM design a practically attractive recipe for the graph+LLM community. Key limitations include the frozen ICAE compressor (compression is not jointly optimized with graph structure), weak performance on commonsense-heavy SceneGraphs, and evaluation limited to 7B-scale models and text-attributed graphs; whether the approach scales to larger backbones or truly novel task formats remains open.

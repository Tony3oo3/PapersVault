## Problem

Leave-One-Out (LOO) context attribution—measuring how much each context span's removal changes an LLM's response likelihood—is a principled but prohibitively expensive method, requiring |C|+1 forward passes through a large model. No prior approach could approximate LOO attributions at LLM scale (70B+ parameters) while remaining more faithful to the target model's true LOO scores than cheaper baselines like attention weights or gradient norms.

## Input / Output

The method takes a query, a context partitioned into contiguous sources (sentences, paragraphs, or documents) and further grouped into source groups (paragraphs or sections), and a response already generated by the target model. It outputs a vector of per-source LOO attribution scores (real-valued), where each score equals the log-likelihood drop of the response when that source is removed. The context partitioning is task-dependent: SQuAD/HotpotQA use sentences as sources and paragraphs as groups, while QASPER uses paragraphs as sources and sections as groups.

## Method

AttriBoT composes three composable acceleration techniques. First, KV caching exploits autoregressive Transformer structure to reuse cached key/value tensors across the |C| LOO forward passes, eliminating ~50% of redundant FLOPs losslessly. Second, hierarchical attribution leverages the empirically validated observation (R=0.97 Pearson correlation) that the sum of sentence-level LOO scores within a paragraph closely approximates a single paragraph-level Leave-k-Out score, enabling a two-stage process: score and prune source groups, then compute fine-grained scores only on retained groups. Third, proxy modeling substitutes a smaller model from the same family (e.g., 8B for 70B) to compute LOO scores, achieving up to 0.94 correlation with the target model's attributions; a variant, proxy model pruning, uses the proxy to identify top-α sources and re-scores only those with the target model. These techniques compose multiplicatively, yielding >300× speedup over exact LOO while remaining Pareto-optimal in faithfulness across all tested datasets.

## Results

AttriBoT achieves a >300× speedup over exact LOO attribution while remaining more faithful to the target model's LOO error than all prior context attribution baselines, making attribution computation 30× faster than generating the response itself. On HotpotQA, the 8B proxy model achieves a Pearson correlation of 0.94 with the 70B target model's LOO attributions (0.88 for the 1B proxy), and hierarchical attribution shows an R=0.97 correlation between paragraph-level and summed sentence-level scores. AttriBoT is Pareto-optimal across multiple orders of magnitude in compute cost on all three datasets (SQuAD 2.0, HotpotQA, QASPER), and achieves a 300× speedup with only a 10% drop in mAP relative to exact LOO when compared against human-annotated important spans on HotpotQA.

## Baselines & Comparisons

The paper compares AttriBoT against four baselines: Attention Weights, Gradient Norm, Sentence Embedding Similarity, and ContextCite. Against ContextCite—the only other method that computes attributions via repeated forward passes on modified contexts—AttriBoT achieves equally faithful attributions to the target model's LOO scores at orders of magnitude lower cost. Against the cheaper baselines (sentence similarity, gradient norm, attention weights), AttriBoT remains Pareto-optimal across all three datasets and can even be more efficient than sentence embeddings, which require no forward passes of the target or proxy model. In practice, KV caching alone yields a ~1.6× speedup (vs. 2× theoretical) while nearly perfectly recovering outlier sources. The combined AttriBoT pipeline (KV caching + proxy modeling + hierarchical attribution) dominates all baselines on the mAP-vs-GPU-time Pareto front, with the gap widening as context length increases.

## Relation to Prior Work

This paper builds directly on the context attribution problem and LOO error formulation introduced by Cohen-Wang et al. (2024), which defined how to quantify each context source's influence on an LLM's response via causal source removal. It repurposes key-value caching from the efficient transformer inference literature (Pope et al., 2022) to eliminate redundant computation in LOO scoring, and introduces two novel efficiency techniques—hierarchical attribution (exploiting paragraph/sentence structure) and proxy modeling (using smaller same-family models)—that have no direct precedent in the context attribution literature. The paper positions itself against correlation-based attribution baselines (attention weights, gradient norms, sentence embeddings) by arguing that only causal intervention via source removal provides principled importance scores, while also comparing against ContextCite, the only prior method using repeated forward passes on modified contexts.

## Why It Matters / Open Questions

By achieving >300× speedup while remaining more faithful to the target model's LOO error than prior methods, AttriBoT makes context attribution 30× faster than generating the response itself, enabling real-time interpretability in RAG pipelines, malicious prompt detection, and hallucination auditing at scale. The composable 'bag of tricks' design gives practitioners a Pareto-optimal efficiency-accuracy trade-off tunable to their compute budget. Limitations include evaluation primarily on open-book QA (though the authors argue generalizability), reliance on hierarchical context structure, and the proxy model assumption that same-family smaller models approximate larger ones—cross-family generalization remains untested. Open questions include whether these techniques extend to non-autoregressive architectures, multimodal contexts, or settings where the response is not a single coherent generation.

## Problem

Existing SSM initialization methods based on the HiPPO framework assume exponential-decay measures and a universal timescale scaling of Δ=1/L, without accounting for the temporal structure (autocorrelation) of input sequences. The theoretical roles of the three key initialization hyperparameters—the timescale Δ, the real part Re(W), and the imaginary part Im(W) of the state matrix—remain largely unexplored, leaving practitioners without principled, data-dependent guidance for initializing SSMs.

## Input / Output

The method takes a sequential dataset of fixed length L, estimates its autocorrelation matrix E[xx^T] (or its maximal eigenvalue), and produces data-dependent initialization values for the timescale Δ and the state vector w (both real and imaginary parts). The resulting diagonal SSM then consumes a discrete input sequence (x_0, …, x_{L-1}) ∈ R^L via zero-order-hold discretization and produces a discrete output sequence (y_1, …, y_L) ∈ R^L. A key unusual aspect is that the initialization is explicitly data-dependent: the scaling of Δ with L is governed by λ_max(E[xx^T]), which ranges from O(1) for i.i.d. data to O(L) for fully correlated sequences.

## Method

The paper provides three theoretical results for the diagonal SSM under ZOH discretization. First, Theorem 3.1 establishes a stability bound E[y_L²] ≤ Δ²m²L·λ_max(E[xx^T]), showing that Δ should scale as O(1/√(L·λ_max(E[xx^T]))) rather than universally as 1/L, and that this bound remains valid even when Re(w)=0. Second, the paper shows that initializing Re(w)=0 prevents exponential decay of the SSM kernel, mitigating the curse of memory for long-range dependencies while preserving training stability at initialization (given the correct Δ). Third, using the Gershgorin circle theorem, Theorem 3.4 proves that the condition number of the Gram matrix G governing the convex optimization problem is controlled by the separation distance δ of the imaginary parts Im(w): well-separated frequencies yield a uniformly bounded condition number independent of hidden size m, whereas real-valued SSMs (S4D-Real) produce a Hilbert matrix whose condition number grows exponentially. This reveals an approximation-estimation tradeoff: large δ improves optimization conditioning but risks frequency misalignment with the target memory function, while small δ improves approximation but slows convergence.

## Results

On the Long Range Arena (LRA) benchmark, initializing 10% of the state vector's real part to zero improves the average test accuracy from 84.89% (default S4D baseline) to 87.08%, with the largest gains on PathX (+5.60 pp) and Pathfinder (+2.52 pp). On the synthetic long-term memory task (sequence length 128, hidden size 32), the zero-real-part initialization enables the learned memory function to capture a spike at the farthest lag, whereas the standard negative-real-part initialization fails to do so. On decorrelated sequential MNIST, zero-real-part initialization also outperforms the negative-real-part baseline in test accuracy, confirming the theoretical prediction that zero real part mitigates the curse of memory.

## Baselines & Comparisons

The sole baseline is the default S4D configuration from Gu et al. (2022c), which uses S4D-Lin initialization with a fixed negative real part of −0.5 for all state vectors. The paper's method — randomly setting 10% of state vectors to have zero real part at initialization (with no reparameterization constraint during training) — outperforms the baseline on all six LRA tasks, achieving an average improvement of +2.19 percentage points (87.08% vs. 84.89%). The gains are most pronounced on PathX (+5.60 pp, 97.55% vs. 91.95%) and Pathfinder (+2.52 pp, 95.58% vs. 93.06%), tasks that likely involve long-range retrieval patterns. Notably, even after training without any stable reparameterization, only 3.09% of real-part parameters remain non-negative on average, indicating the model retains stability while benefiting from the zero-real-part initialization. The paper also validates its theory on synthetic tasks and decorrelated sMNIST, where zero-real-part initialization consistently outperforms the negative-real-part baseline, though no direct numerical comparison against other SSM variants (e.g., Mamba, S6) is provided.

## Relation to Prior Work

This paper extends the HiPPO-based initialization framework for diagonal SSMs (Gu et al., 2022c; 2023) by introducing data-dependent initialization criteria that the original framework lacked. It builds on the curse-of-memory analysis for recurrent models (Li et al., 2021; 2022) to argue that the standard stable parameterization (strictly negative real part) is unnecessarily restrictive for fixed-length tasks, and departs from the HiPPO assumption of a universal Δ=1/L scaling by showing that the correct timescale depends on the spectrum of the input autocorrelation matrix. The convergence analysis draws on the Gershgorin circle theorem to characterize Gram matrix conditioning, providing a theoretical explanation for why complex-valued S4D-Lin outperforms real-valued S4D-Real (a Hilbert matrix) in optimization.

## Why It Matters / Open Questions

The paper provides the first rigorous characterization of how data autocorrelation should inform SSM timescale initialization, replacing the heuristic Δ=1/L rule with a data-dependent formula. The approximation-estimation tradeoff between frequency alignment and Gram matrix conditioning offers a principled framework for choosing imaginary-part initialization, though recovering the true memory function from data remains an open challenge. Key limitations include restriction to diagonal SSMs with ZOH discretization, fixed-length sequences, and absence of gating or depth effects; the LRA improvements (e.g., 84.89→87.08 average) are modest, and the zero-real-part benefit is demonstrated without stable reparameterization, leaving open whether it holds in deeper, more complex architectures.

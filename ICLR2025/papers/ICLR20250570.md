## Problem

Existing reward modeling for AI alignment assumes a single homogeneous preference shared by all humans, but real human preferences are diverse and heterogeneous. Prior pluralistic approaches are top-down—designers pre-specify axes like helpfulness vs. harmlessness—rather than learning preference structure from data. This paper asks: can we build a sample-efficient, bottom-up reward modeling framework that captures both shared and individual preference structure without requiring per-user full model training?

## Input / Output

The method consumes pairwise preference comparisons structured as (x_l, x_r; x_c, y) where x_l and x_r are two candidate outputs (text summaries or generated images), x_c is the context/prompt, and y is a binary label indicating which output the user preferred. These are embedded via frozen foundation models (CLIP-H/14 for images; OPT-350M, DistilBERT, BGE-M3, or gte-Qwen2-1.5B for text) before entering the PAL head. The output is a personalized scalar reward r_θ^(i)(x; x_c) for each user i, from which preference probabilities are derived via a link function. For a new unseen user, only a K-dimensional weight vector on the simplex needs to be learned from as few as 2–20 preference pairs.

## Method

PAL decomposes the personalized reward into a shared component (a mapping f and K prototypical preference structures learned from pooled data across all users) and a per-user component (a K-dimensional weight vector w^(i) on the (K−1)-simplex). PAL-A models each user's preference as an ideal point a^(i) = Pw^(i) in a learned representation space, scoring outputs by squared Euclidean distance to this point; PAL-B models each user's preference as a context-dependent mapping z^(i)(x_c) = G(x_c)w^(i), scoring outputs by inner product with the mapped output. The convex-combination-over-prototypes structure is the key mechanism: it amortizes the cost of learning the shared metric/mapping across N users, so each user only needs to learn K weights rather than a full D-dimensional preference, reducing per-user sample complexity from Õ(D) to Õ(K). The paper provides Rademacher-complexity-based generalization bounds for both seen users (unseen pairs) and unseen users (few-shot localization), and validates the framework on text-to-text (Reddit TL;DR) and text-to-image (Pick-a-Pic, Pick-a-Filter) tasks with as few as ~6M learnable parameters.

## Results

On Reddit TL;DR Summary, PAL-B-Large (K=2) achieves 92.82% seen-user accuracy and 91.63% unseen-user accuracy, outperforming the previous best method P-DPO Cluster (K=5) by 1.7% on seen users and 36% on unseen users, while using 6.3 billion fewer parameters. On Pick-a-Pic v2 (no-leakage subset), PAL-B-Tiny (CLIP-H, 6.3M params) trained on V2 reaches 70.51% accuracy, exceeding PickScore (986M params, 68.04%) by 2.5% with 156× fewer learned parameters. On the semi-synthetic Pick-a-Filter dataset at β=1, PAL achieves 95.2% test accuracy versus 75.4% for the best homogeneous reward model.

## Baselines & Comparisons

On Reddit TL;DR, PAL-B-Large decisively outperforms all three DPO-based baselines: it beats P-DPO Individual (91.04% seen, 55.34% unseen) and P-DPO Cluster K=5 (91.12% seen, 54.55% unseen) on both seen and unseen users, with the unseen-user gap being the most dramatic (+36% over P-DPO Cluster). Vanilla DPO (58.91% seen, 55.37% unseen) is far behind, confirming that personalization is essential. On Pick-a-Pic v2, PAL-B-Tiny (6.3M params) matches or exceeds PickScore (986M params) on the no-leakage test set (70.51% vs 68.04% when both trained on V1/V2 respectively), while ImageReward (61.10%) and HPS v2.1 (66.70%) are only reported on V1 and are outperformed. On Pick-a-Filter, where preference diversity is explicitly injected, PAL-B-Tiny achieves 95.2% at β=1 compared to 75.4% for the strongest homogeneous baseline, demonstrating that PAL's mixture-of-prototypes design is critical when heterogeneity is present.

## Relation to Prior Work

PAL builds directly on the ideal point model (Coombs, 1950) and the Bradley-Terry-Luce framework, extending them with a mixture-of-prototypes structure where each user's preference is a convex combination of K shared prototypical points or mappings. The theoretical analysis extends Canal et al. (2022), who showed O~(D) per-user sample complexity for simultaneous metric and preference learning, to O~(K) via the mixture structure. Unlike top-down pluralistic alignment approaches (Rewarded Soups, DPA) where designers pre-define preference axes, PAL learns heterogeneity bottom-up from data, and unlike P-DPO (Li et al., 2024) which treats unseen users homogeneously, PAL provides a natural few-shot localization mechanism for new users.

## Why It Matters / Open Questions

PAL addresses a genuine gap in alignment: current RLHF/DPO pipelines assume a single homogeneous preference, while real human values are pluralistic. The practical efficiency gains (100× fewer parameters, 20 samples for new-user localization) make personalized reward modeling feasible at scale, and the theoretical guarantees for both seen and unseen users provide the first sample complexity characterization for few-shot preference localization. A key limitation is that static prototypes cannot generalize to users outside the learned convex hull, and the pluralistic validation relies partly on semi-synthetic data (Pick-a-Filter) because existing large-scale preference datasets are shown to be de facto homogeneous due to rubric-based collection. Future work on continually adapting prototypes and collecting genuinely diverse preference data are important open directions.

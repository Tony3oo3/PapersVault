## Problem

Current LLM-based web agents lack world models, meaning they cannot foresee the outcomes of their actions before executing them, leading to irreversible errors such as repeatedly purchasing non-refundable items. Preliminary analyses in this paper confirm that SOTA LLMs (GPT-4o, Claude-3.5-Sonnet) perform near-random on next-state prediction, yet show up to 38% improvement in action selection when given access to simulated outcomes—demonstrating both the absence and the necessity of world models in web navigation.

## Input / Output

The world model receives three inputs: the user instruction, the current webpage observation (accessibility tree in WebArena or HTML in Mind2Web), and a single action candidate sampled from the frozen policy model via top-p decoding (k candidates per step). It outputs a short free-form natural language description of only the state differences (updated, deleted, added elements) between the current and next observation, rather than the full next page. A separate fine-tuned value function then scores each simulated observation against the user goal, and the agent executes the action with the highest estimated reward.

## Method

The core contribution is a transition-focused observation abstraction for training LLMs as world models. Instead of predicting the full next observation (which suffers from massive element repetition and ~4K-token sequences), the method applies the Hungarian algorithm to match elements between consecutive observations, mechanically extracts UPDATED/DELETED/ADDED elements, and prompts an LLM to convert this diff into a concise natural-language description. Llama-3.1-8B-Instruct is then fine-tuned via next-token prediction to generate this abstracted next observation from (instruction, current observation, action). At inference, the frozen policy model samples k action candidates, the world model simulates the next observation for each, and a fine-tuned value function selects the action with the highest reward—enabling training-free policy optimization that is 5.3× faster and 6.8× cheaper than tree-search-based agents.

## Results

On WebArena, the WMA web agent with GPT-4o achieves 16.6% Success Rate (SR), a +29.7% relative gain over vanilla CoT (13.1%), and with GPT-4o-mini achieves 13.5% SR (+43.6% over 9.4% CoT). On Mind2Web (cross-task), WMA achieves 25.4% SR, substantially outperforming the previous SOTA AWM (15.3%). In terms of efficiency, WMA requires only $0.4 API cost and 140.3s inference time per instance, compared to $2.7 and 748.3s for the Tree search agent — a 6.8× cost reduction and 5.3× speedup.

## Baselines & Comparisons

The most direct comparison is against the Tree search agent (Koh et al., 2024) on WebArena with GPT-4o: WMA achieves 16.6% SR vs. 19.2% for Tree search, a slight absolute loss, but WMA delivers a larger relative gain over vanilla CoT (+29.7% vs. +28.0%) while being 6.8× cheaper ($0.4 vs. $2.7) and 5.3× faster (140.3s vs. 748.3s). Against vanilla CoT (Zhou et al., 2023) with the same GPT-4o policy, WMA improves SR from 13.1% to 16.6%. On Mind2Web, WMA (built on AWM) achieves 25.4% cross-task SR, beating AWM alone (15.3%), HTML-T5-XL (10.3%), MindAct (2.0%), and Synapse (2.0%). The GPT-4-based baselines (AutoEval 20.2%, BrowserGym 23.5%, SteP 35.8%, AWM 35.5%) use a different and stronger policy model, so they are not directly comparable to the GPT-4o-based WMA results; however, WMA's training-free plug-in design means it can be combined with any of these policy models without retraining.

## Relation to Prior Work

This paper bridges two previously separate research threads: world models in reinforcement learning (Dreamer series, Ha & Schmidhuber) and LLM-based web agents (AWM, Tree Search Agent, AutoEval). While prior LLM world model work (Zhang et al. 2024, Wang et al. 2024a) targeted text-based games, and RL world models operated on pixel or latent representations, this is the first to train an LLM as a world model specifically for web navigation environments with HTML/accessibility-tree observations. The key methodological departure is the transition-focused observation abstraction (using the Hungarian algorithm to extract only state differences), which addresses the redundancy and sequence-length problems that make naive next-observation prediction infeasible for web pages. At inference time, the world model replaces the actual environment interaction used by tree-search agents with a simulated prediction, enabling a simulate-score-select paradigm that is orthogonal to existing policy models.

## Why It Matters / Open Questions

The paper establishes that world models can improve web agent policy selection in a training-free manner (the policy model is frozen), which makes the approach easily composable with existing or future web agents. The 5.3× speedup and 6.8× cost reduction over tree-search agents is practically significant for deployment, and the new SOTA on Mind2Web (25.4% SR cross-task) demonstrates generalization. However, absolute performance remains far below human levels (16.6% vs. 78.24% on WebArena), and the world model's 42% counterfactual imagination error rate limits reliability in safety-critical scenarios (e.g., irreversible purchases). Open questions include whether multi-step planning can overcome error accumulation, whether multimodal world models (shown promising in Appendix A) close the remaining gap, and whether the transition-focused abstraction generalizes to more dynamic or interactive web environments.

## Problem

Existing continual learning methods treat stability and plasticity as competing objectives, often sacrificing one for the other, while overlooking the rich semantic structure between objects that the human brain exploits for knowledge consolidation. This paper argues that leveraging semantic similarities between objects across tasks can bridge the stability-plasticity gap by enabling feature reuse and reducing interference, a mechanism that is underutilized in current CL approaches.

## Input / Output

The method consumes RGB images (32×32 for CIFAR-10/100, 64×64 for Tiny-ImageNet) presented as a sequential stream of tasks with disjoint or overlapping class sets, and outputs class labels over an ever-growing label space. Beyond standard classification, the model maintains two auxiliary memory stores: an episodic buffer of data samples (via reservoir sampling) and a prototype memory holding one l2-normalized vector per learned class, which are updated at task boundaries and used to compute inter-class semantic similarities during training.

## Method

SARL replaces ReLU activations in a ResNet-18 backbone with k-Winner-Take-All (k-WTA) sparse activations, emulating the brain's sparse coding so that semantically related objects activate overlapping neuron subsets. At the end of each task, it computes object prototypes as the mean of l2-normalized penultimate-layer activations per class, then uses cosine similarity between prototypes to partition all previously seen and new classes into similar and dissimilar sets for each new class. A semantic-aware metric learning loss (L_SM) then pulls the mean representation of each new class toward the prototypes of its similar classes while pushing it away from dissimilar ones, and a prototype regularization loss (L_OP) penalizes drift of buffered samples away from their stored prototypes. A functional consistency loss (L_FR) further anchors the model's logits on both new and buffered data to their pre-task values, and the total objective combines cross-entropy on task and buffer data with these three regularization terms, all within a single-model experience-replay framework.

## Results

SARL achieves state-of-the-art class-incremental learning accuracy across all three datasets with a single model. On Seq-CIFAR-10 (buffer 200), SARL reaches 70.97% Class-IL accuracy, outperforming the strongest multi-memory baseline SCoMMER (69.19%) and the best single-model baseline DER++ (64.88%). Gains are most pronounced on harder datasets: on Seq-CIFAR-100 (buffer 200), SARL achieves 48.96% vs. 43.80% for CLS-ER (which uses 3 models), and on Seq-TinyImageNet (buffer 200), SARL reaches 28.95% vs. 23.47% for CLS-ER. In the online CL setting, SARL attains 31.66% AAA on Seq-CIFAR-100, surpassing the previous best VR-MCL (27.01%).

## Baselines & Comparisons

SARL outperforms all nine baselines across every dataset and setting. Against the strongest single-model baseline DER++ (Buzzega et al., 2020), SARL gains +6.09% on Seq-CIFAR-10 Class-IL (70.97 vs. 64.88, buffer 200) and +19.36% on Seq-CIFAR-100 (48.96 vs. 29.60). Against the multi-memory baselines, SARL surpasses CLS-ER (Arani et al., 2022; 3 models) by +5.16% on Seq-CIFAR-100 Class-IL and +5.48% on Seq-TinyImageNet Class-IL (buffer 200), while using only one model. SCoMMER (Sarfraz et al., 2023; 2 models) is the closest competitor on Seq-CIFAR-10 (69.19 vs. 70.97) but falls further behind on harder datasets (40.25 vs. 48.96 on CIFAR-100). ER-ACE (Caccia et al., 2022) and CO2L (Cha et al., 2021) are substantially weaker, particularly in Task-IL where ER-ACE drops to 35.17% on CIFAR-10. In the online CL setting (Table 3), SARL beats VR-MCL (Wu et al., 2024) by +4.65% AAA on Seq-CIFAR-100 (31.66 vs. 27.01) and +0.73% on Seq-CIFAR-10 (66.85 vs. 66.97, essentially tied). FDR (Farajtabar et al., 2020) and GCR (Tiwari et al., 2022) are consistently outperformed by 10–20+ points on Class-IL across all datasets.

## Relation to Prior Work

SARL builds on the Experience Replay (ER) rehearsal framework and the prototypical network concept of representing classes by mean activations, but departs from prior CL work by introducing a semantic-aware metric learning loss that explicitly aligns new object prototypes with semantically similar ones from previous tasks while pushing apart dissimilar ones. It also draws on the authors' prior SCoMMER work on sparse coding in dual-memory systems, but here applies k-WTA activation sparsity within a single-model setting, combining it with prototype regularization and functional consistency (à la DER++) to enforce a persistent semantic structure in the representation space. The key conceptual departure from stability-focused or plasticity-focused methods is treating semantic relationships as the mechanism that simultaneously serves both objectives, rather than addressing them as separate regularization terms.

## Why It Matters / Open Questions

SARL demonstrates that a single-model rehearsal method with minimal memory overhead (~3% more than ER) can outperform dual-memory approaches like CLS-ER and SCoMMER across Class-IL, Task-IL, GCIL, and Online CL settings, suggesting that explicit semantic structure enforcement is a more efficient path to the stability-plasticity balance than maintaining additional model copies. The finding that k-WTA sparsity measurably improves the model's ability to capture intra-cluster semantic similarity (Figure 2, Appendix E) provides a concrete mechanistic link between sparse coding and knowledge consolidation. Open questions include whether the approach scales to ImageNet-scale datasets, whether it integrates with pre-trained backbones (the paper explicitly avoids this), and whether the semantic alignment mechanism generalizes to non-vision modalities or tasks where class semantics are less structured.

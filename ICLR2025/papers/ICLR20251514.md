## Problem

Training LLM families (e.g., Llama 3.1 at 8B, 70B, 405B) requires training each size from scratch on trillions of tokens. While structured pruning plus distillation reduces this cost, each compressed model targeting a specific parameter budget still requires separate distillation over hundreds of billions of tokens. The paper asks whether a single elastic architecture can yield an arbitrary number of accurate pruned sub-networks zero-shot, without per-model fine-tuning.
![Teaser figure](../imgs/ICLR20251514/cropped_page1_idx0.webp)

## Input / Output

At inference, the user specifies a budget target (percentage of remaining parameters, e.g., 25%–100%) and text tokens; the router maps the budget to a concrete architecture (MLP intermediate dim, number of attention heads, hidden dim, and a binary layer-skip vector), and the resulting sub-network produces generated text. The router generalizes to unseen budget targets via linear interpolation between the one-hot encodings of the nearest trained budgets, enabling continuous deployment across the full 0–100% range. All generated sub-networks are uniform (identical layer configuration across all retained layers), ensuring compatibility with standard LLM inference frameworks like TensorRT-LLM and llama.cpp.

## Method

LLAMAFLEX converts a pretrained LLM into a nested weight-shared elastic network by importance-reordering neurons, attention heads, and hidden features so that sub-networks are obtained by slicing the first k elements along each width axis and selecting a subset of layers along depth. A lightweight two-layer MLP router, trained end-to-end with Gumbel-Softmax reparameterization, learns to map a budget target to the optimal combination of width and depth choices, with a budget-constraint loss penalizing parameter overruns. A key differentiator is policy-aware modulation: a sinusoidal embedding of the chosen elastic size feeds a small MLP that produces per-layer scale and shift vectors applied to elastic MLP/MHA outputs, adding expressivity beyond pure weight slicing. The entire system is trained for ~60B tokens of continued pretraining on Llama 3.1 8B, jointly optimizing backbone weights and router parameters, after which any number of compressed models can be extracted zero-shot.

## Results

On Llama 3.1 8B, LLAMAFLEX generates a family of zero-shot compressed models spanning 1.8B to 7.0B non-embedding parameters. At 50% budget (3.5B params), the explicitly trained sub-network achieves 70.6% average accuracy across six benchmarks (MMLU 60.3%, HellaSwag 76.0%), while the interpolated 62.5% variant (4.4B) reaches 71.7% average. The full 100% model (7.0B) attains 75.4% average, approaching the original Llama 3.1 8B's 76.4%. Interpolated models (e.g., 38.8%, 86.1%) demonstrate smooth performance transitions without any additional training.

## Baselines & Comparisons

LLAMAFLEX decisively outperforms Flextron at comparable sizes: at ~3.5B params, LLAMAFLEX Exp.-50% achieves 70.6% average vs. Flextron 0.5×'s 61.3% (a 9.3-point gap), with the MMLU gap being especially stark (60.3% vs. 35.9%). Against Minitron (pruning + distillation), LLAMAFLEX Exp.-50% (3.5B) edges out Minitron-Width (3.7B) at 70.6% vs. 70.5% average while using fewer parameters, and substantially outperforms Minitron-Depth (69.3%). Compared to trained-from-scratch models, LLAMAFLEX Exp.-25% (1.8B) achieves 62.4% average, beating Pythia-2.8B (2.5B, 54.5%) and OpenLLaMA-3Bv2 (3.2B, 60.3%) with fewer parameters, and the 100% model (75.4%) surpasses GPT3-8B (68.0%) and Llama2-7B (69.2%). The only comparison where LLAMAFLEX trails is against the original Llama 3.1 8B (76.4% vs. 75.4%), which is expected since the elastic pretraining uses only 60B tokens versus the original 15T. The interpolated models (e.g., Inter.-62.5% at 71.7%) confirm that the router generalizes smoothly to unseen budgets without any additional training.

## Relation to Prior Work

LLAMAFLEX extends the nested weight-sharing lineage (Matryoshka representation learning, Matformer, Flextron) by being the first elastic LLM framework to simultaneously support all width dimensions (MLP intermediate size, hidden dimension, attention heads) and depth (layer skipping) with a single learnable router. It departs from prior structured pruning + distillation approaches (Minitron, Sheared-LLaMA) by eliminating per-model distillation entirely, instead relying on a brief 60B-token elastic pretraining phase followed by zero-shot sub-network extraction. The Gumbel-Softmax router design draws on MaskLLM's temperature annealing schedule, while the policy-aware modulation technique is repurposed from diffusion model conditioning (DiT, DDPM) to address the representational bottleneck of pure weight-sharing.

## Why It Matters / Open Questions

The 'train once, deploy many' paradigm directly addresses a major cost bottleneck for LLM providers who currently train each family member from scratch on trillions of tokens; LLAMAFLEX's zero-shot interpolation to unseen budget targets (e.g., 62.5% when trained on 25/50/75/100%) makes it practically attractive for serving heterogeneous deployment scenarios. However, the method is not training-free (requiring ~60B tokens of continued training), is validated only on Llama 3.1 8B, and the router's inability to reduce attention heads for this model suggests the approach may not generalize uniformly across architectures. Open questions include whether the technique scales to 70B+ models, whether elastic pretraining from scratch (rather than from a pretrained checkpoint) is viable, and whether the uniform-architecture constraint sacrifices accuracy compared to heterogeneous sub-networks.

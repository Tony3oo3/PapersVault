## Problem

Existing test-time adaptation (TTA) methods for vision-language models rely exclusively on internal knowledge encoded in model parameters, which is constrained to pre-training data and insufficient under distribution shifts. No prior method adaptively retrieves external images from a web-scale database at test time to complement this internal knowledge, and naive image-to-image similarity search fails to retrieve images containing the pivotal features needed for recognition.
![Teaser figure](../imgs/ICLR20253619/cropped_page1_idx1.webp)

## Input / Output

The method takes a single unlabeled test image (augmented M=100 times via random cropping and flipping), a set of L pre-generated fine-grained text descriptions per class (produced offline by GPT-3.5 Turbo using CuPL-style templates), and a web-scale external image database (constructed from LAION2B via keyword matching on class names, containing images without labels). It produces a refined class label prediction by fusing the initial CLIP zero-shot prediction with a retrieval-based prediction, where the fusion weight is determined by the entropy of each prediction. The entire procedure is training-free and operates online per test image.

## Method

RA-TTA operates in two steps. Step I (description-based retrieval) first selects top-K_D pivotal text descriptions for the test image via robust image-to-text alignment (using the p-th percentile of alignment scores across augmentations to reject misleading descriptions), then retrieves K_S external images per class group via text-to-image similarity using averaged text prototypes — effectively treating text descriptions as semantic 'chunks' analogous to document chunking in RAG. Step II (description-based adaptation) computes a semantic gap (absolute difference in cosine distances to the class text prototype) between each augmented test image and each retrieved image, aggregates these pairwise gaps via the Sinkhorn-Knopp optimal transport framework with importance-weighted marginals, and converts the resulting distance into a relevance score per class. The final prediction is an entropy-weighted fusion of the initial VLM prediction and the retrieval-based prediction, requiring no backpropagation or parameter updates.

## Results

RA-TTA achieves 73.09% average top-1 accuracy across 13 standard transfer learning benchmarks, outperforming the strongest baseline SuS-X-LC (70.89%) by 2.20% and the zero-shot CLIP baseline (66.05%) by 7.04%. On four ImageNet distribution-shift variants (adversarial, V2, rendition, sketch), RA-TTA reaches 63.47% average accuracy, surpassing the best baseline RLCF (61.26%) by 2.21%. The paper reports improvements of 3.01–9.63% over existing methods on average, with the largest gains on fine-grained datasets (e.g., FGVC Aircraft: 32.34% vs. 29.41% for SuS-X-LC) and specialized domains (RESISC45: 66.95% vs. 65.22%).

## Baselines & Comparisons

RA-TTA outperforms all nine compared baselines across all 13 transfer learning datasets and all 4 distribution-shift benchmarks. Among tuning-based methods (TPT, C-TPT, RLCF), RA-TTA leads by 2.21–6.19% on average, as these methods rely solely on internal model knowledge without external retrieval. Among text-description-based methods (VisDesc, WaffleCLIP, CuPL), RA-TTA gains 2.16–4.16% on average, demonstrating that combining fine-grained descriptions with external image retrieval is more effective than descriptions alone. Among retrieval-based methods (SuS-X-LC, Neural Priming), RA-TTA improves by 2.20% and 3.23% on average respectively, attributed to its adaptive per-test-image retrieval versus their static pre-retrieved image sets. The largest absolute gains appear on fine-grained and specialized datasets: FGVC Aircraft (+2.93% over SuS-X-LC), RESISC45 (+1.73%), and Flowers102 (+2.42%), where identifying pivotal visual features via description-based retrieval is most impactful.

## Relation to Prior Work

RA-TTA synthesizes three previously separate threads: test-time adaptation (TPT, C-TPT, RLCF) that adapts VLMs online but relies solely on internal parameters; retrieval-augmented VLM methods (SuS-X, Neural Priming) that use external images but retrieve them statically offline; and text-description-based prompting (CuPL, VisDesc, WaffleCLIP) that leverages fine-grained language without external knowledge. The key conceptual departure is treating LLM-generated text descriptions as an analog to document chunking in NLP-style RAG, enabling per-image, feature-targeted retrieval from a web-scale database rather than fixed per-class retrieval. The optimal-transport formulation for measuring semantic relevance between a test image and retrieved images is a novel application of OT to the VLM adaptation setting.

## Why It Matters / Open Questions

The paper demonstrates that external web-scale knowledge can substantially complement a VLM's internal parameters at test time, with gains that grow under stronger distribution shifts and more semantically complex test data. The description-based retrieval idea (text as image 'chunking') is a practical and generalizable principle that could extend to other retrieval-augmented vision tasks. Limitations include the need for a task-specific pre-built image database, dependence on LLM description quality, and evaluation restricted to closed-set classification with CLIP-B/16. Open questions include whether the approach transfers to open-vocabulary or multi-label settings, how database construction scales to long-tail domains, and whether the OT-based relevance can be replaced by lighter-weight alternatives without performance loss.

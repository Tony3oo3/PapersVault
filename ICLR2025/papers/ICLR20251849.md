## Problem

In decentralized collaborative learning with heterogeneous data, clients often need to learn about specific classes that are underrepresented or entirely absent in their local data. Existing approaches—federated learning, ensembles, and naive knowledge distillation—struggle to deliver tailored knowledge to individual clients while simultaneously suffering from irrelevant knowledge interference, catastrophic forgetting of previously learned classes, and high communication overhead.

## Input / Output

The method consumes pre-trained teacher model weights from other clients, the student's local training data, a set of query class labels, and a batch of synthetic Gaussian noise samples (no real data is exchanged). It produces an enhanced student model whose feature extractor has been updated via masked distillation and whose classification head has been selectively refined. A lighter variant (QKT Light) shares a single general feature extractor across all clients, reducing per-client computation to only the classification head refinement in Phase 2.

## Method

QKT operates in two distinct phases. In Phase 1 (Query-Focused Learning), a batch of Gaussian noise samples is fed into each teacher model to exploit the overconfidence of pre-trained networks on their training classes; teachers whose average predicted probability on any query class exceeds a threshold τ are retained, and a per-teacher mask assigns weight λ to query classes, 1 to the student's local classes, and 0 elsewhere. The student's feature extractor is then trained with a masked KL-divergence distillation loss (QKD) that selectively transfers only query-relevant knowledge. In Phase 2 (Classification Head Refinement), the classification head is restored to its pre-Phase-1 state (Head Replacement) to preserve original decision boundaries, the feature extractor is frozen, and only the head is refined using the same masked distillation objective. This staged design decouples feature learning from boundary refinement, mitigating both knowledge interference and catastrophic forgetting while completing the entire transfer in a single communication round.

## Results

On the average across five datasets (CIFAR-10, CIFAR-100, CINIC-10, BloodMNIST, PathMNIST), QKT achieves 75.02% (Pathological) and 69.89% (Dirichlet) average accuracy for single-class queries, and 63.57% (Path) and 59.31% (Dir) for multi-class queries, all in a single communication round. This represents an average improvement of 20.91 percentage points over existing methods in single-class settings and 14.32 points in multi-class settings. QKT also achieves the best query accuracy gain (77.97% on CIFAR-10 Path) while maintaining lower forgetting (−16.81%) compared to naive KD (−8.43% forgetting but only 23.56% query gain).

## Baselines & Comparisons

QKT outperforms all single-round baselines by a wide margin: over KD (48.68% Path / 43.97% Dir) by ~26 points in single-class queries, and over Ensemble (41.20% / 49.29%) by ~34 points. Multi-round FL methods (FedAvg, FedProx, Moon) achieve 44–55% average accuracy but require 100 communication rounds, whereas QKT reaches 75% in one round. Among single-round FL, FedAvg(1) collapses to ~9–12% accuracy, confirming that FL cannot function effectively without iterative aggregation. CLUE and PFNM perform worst among single-round methods (12–15%), suffering from parameter mismatch under heterogeneous data. The only exception where FL methods outperform QKT is BloodMNIST multi-class queries (FedProx 59.08% vs. QKT 59.31% Dir; FedAvg 56.25% vs. QKT 59.31%), attributed to well-defined visual features of blood cell types that allow global models to generalize even with few samples per class.

## Relation to Prior Work

QKT builds on the knowledge distillation paradigm (Hinton et al., 2015) and the linear-probing insight that classification heads are critical for out-of-distribution tasks (Kumar et al., 2022), but departs from both by introducing a query-specific, data-free masking mechanism that filters irrelevant teachers and classes before distillation. It positions itself against the full spectrum of collaborative learning methods—centralized FL (FedAvg, FedProx, MOON), personalized/clustered FL, single-round model merging (PFNM, CLUE), and ensemble approaches—arguing that all of them either ignore the specific class-level needs of individual clients or suffer from knowledge interference and catastrophic forgetting when data distributions are heterogeneous. The two-phase design (feature extractor enhancement followed by classification head refinement with head replacement) is a deliberate departure from standard KD, which updates all parameters simultaneously.

## Why It Matters / Open Questions

QKT addresses a practically important gap: clients in decentralized networks (medical, IoT, fraud detection) that need to rapidly acquire knowledge about specific under-represented classes without exchanging raw data or undergoing multiple communication rounds. The single-round, data-free design makes it attractive for bandwidth-constrained and privacy-sensitive deployments. However, the evaluation is limited to image classification with ResNet architectures and up to 50 clients; open questions include applicability to non-vision tasks (NLP, tabular data), real-time dynamic query scenarios, and whether the noise-based teacher filtering generalizes to architectures without the overconfidence property that makes it work. The paper also acknowledges that QKT Light, while more efficient, carries higher forgetting risk, leaving the optimal trade-off between computational cost and knowledge retention unresolved.

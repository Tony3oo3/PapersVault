## Problem

kNN attention has shown empirical success in making Transformers scale to longer sequences by restricting each token to attend only to its k nearest neighbors, but its approximation guarantees have never been rigorously analyzed. Key questions remain unresolved: what error bounds does kNN attention actually provide, what is the optimal k, and can the same framework yield sub-quadratic algorithms for the backward pass (gradient computation), which is the main memory bottleneck in training.

## Input / Output

The method takes standard query, key, and value matrices Q, K, V ∈ R^{n×d} along with error and confidence parameters ε, δ > 0. It outputs an approximate attention matrix Ō ∈ R^{n×d} with multiplicative error guarantees (|Ō_ij − O_ij| ≤ ε·O_ij with probability ≥ 1−δ) and, for the backward pass, approximate gradients D̂^Q, D̂^K, D̂^V ∈ R^{n×d} with additive error O(ε·polylog(n)). The algorithm is randomized (Monte Carlo) and requires a kNN index over the key vectors, which is built in slightly super-linear preprocessing time and queried in sublinear time per query.

## Method

The paper reformulates each row of the attention output as an expectation under a softmax distribution D_i over the n keys, then approximates these expectations via Lazy Gumbel Sampling: given the top-k inner products (retrieved through a kNN index solving the k-MIPS problem via the Neyshabur–Srebro reduction and concentric LSH), Gumbel noise is added only to those k candidates plus a small random subset of the remaining n−k keys, yielding exact samples from D_i in O(√n) expected time. Median-of-Means boosting over O(ε^{-2} log n) samples converts these into multiplicative error guarantees, giving a total forward-pass runtime of Õ(dn^{3/2}·ε^{-2}·log(1/δ)). For the backward pass, the paper treats the stochastic attention matrix P as a Markov chain transition matrix and estimates P^T·D^O via single-step random walk simulations (Hoeffding-bounded), while D^Q and D^K are decomposed into softmax expectations estimated with the same Lazy Gumbel machinery plus CDF-based binary-search sampling for efficient per-sample generation.

## Results

kNN Attention handles self-attention for sequence length n=10⁶ with H=10 heads, while the naive O(n²) method runs out of memory beyond n≥20,000 — a 5× context-length increase. On random inputs, the approximation error becomes negligible for k ≥ n^(1/8), though theory predicts a threshold closer to √n. On a character-level Shakespeare Transformer (N=1024, d=768, 5000 steps), kNN Attention maintains a small perplexity gap versus exact attention, with the gap widening only as overfitting sets in. Fine-tuning GPT-2 XL on Shakespeare becomes feasible on a single NVIDIA L40 GPU (48 GB), a task that is infeasible with quadratic attention.

## Baselines & Comparisons

The paper's sole baseline is exact (brute-force) O(n²) self-attention as in Vaswani et al. (2017). On efficiency, kNN Attention clearly wins: it processes sequences 5× longer before hitting memory limits and scales sub-quadratically, whereas the exact method is infeasible beyond n≈20,000 on the same hardware. On approximation quality, kNN Attention is competitive but not identical: the forward-pass error is minimal for k ≥ n^(1/8) on random inputs, and the perplexity gap on Shakespeare training is small but nonzero, widening under overfitting. For gradient approximation, the Markov-Chain-based estimator closely tracks exact PyTorch autograd gradients under convex (MSE) loss but deviates from optimal convergence under non-convex (Cross-Entropy) loss, suggesting approximate gradients are more reliable in well-conditioned regimes. Overall, the method trades a small, controllable approximation error for substantial memory and speed gains, making it a practical substitute for exact attention in long-sequence and resource-constrained settings.

## Relation to Prior Work

This paper provides the first theoretical framework for kNN attention, a paradigm that has been empirically validated in the Routing Transformer (Roy et al., 2021), Memorizing Transformers (Wu et al., 2022), and Unlimiformer (Bertsch et al., 2024) but lacked formal approximation guarantees. It builds directly on Mussmann et al.'s (2017) Lazy Gumbel Sampling for sublinear softmax sampling and their concentric LSH construction for k-MIPS, combined with the Neyshabur & Srebro (2015) MIPS-to-kNN reduction, to derive explicit error bounds. The paper extends this framework to the backward pass by introducing a Markov Chain simulation technique for approximating the transpose-of-stochastic-matrix multiplication that arises in attention gradients, a step not addressed in prior kNN attention work.

## Why It Matters / Open Questions

By establishing that kNN attention achieves sub-quadratic time with provable multiplicative error guarantees, this work gives practitioners theoretical justification for the kNN attention paradigm and clarifies the role of the hyperparameter k. The Markov Chain-based gradient estimation is a novel technique that could reduce the memory bottleneck of backpropagation in long-sequence models. However, the empirical validation is limited to small-scale experiments (Shakespeare character-level LM, GPT-2 XL fine-tuning), and the gap between the theoretical √n threshold and the empirically observed n^(1/8) threshold for minimal error remains unexplained. A key open question is whether training with approximate gradients degrades LLM quality at scale, which the authors leave for future work.

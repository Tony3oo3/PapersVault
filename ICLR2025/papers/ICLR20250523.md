## Problem

Standard fixed-depth Transformers fail to length-generalize on algorithmic tasks like n-digit addition, n-bit parity, and n-symbol copy, even with techniques like Chain-of-Thought or pause tokens. The root cause is that these tasks require an iterative computation whose depth scales with input length, which no fixed-depth RASP-L program can express under next-token prediction. The paper asks whether a looped Transformer with an adaptive number of steps can learn the length-generalizable iterative solution end-to-end, without intermediate-step supervision.

## Input / Output

The model takes a token sequence (e.g., binary digits for parity, two binary numbers separated by '+' for addition, or a symbol sequence for copy) followed by an EOQ marker ('>') and EOS padding, and produces the full answer sequence in one shot via full-output prediction (FOP) rather than autoregressive next-token prediction. The number of loop iterations T(n) is a function of input length n (e.g., T(n)=n for parity and copy, T(n)=n+1 for addition), and the model uses no positional encoding (NoPE) to stay within the RASP-L expressiveness assumption. At inference, the model either runs for a known number of steps (oracle) or stops via a maximum-confidence criterion that selects the step minimizing cross-entropy over the test batch.

## Method

The paper defines n-RASP-L problems—tasks solvable by sequentially applying a fixed RASP-L program P' for T(n) steps, where T(n) depends on input length—and proves that parity, copy, and addition admit such solutions. The architecture is a decoder-only Looped Transformer that reuses a single weight-shared block for T(n) iterations, with the original input embedding injected (added) at each step to prevent information loss. The key training insight is step-dependent supervision: the cross-entropy loss is applied only after T_i iterations for sample i, and since T_i varies across the training set (e.g., from 1 to 20), the same block receives gradient signal at many different effective depths, implicitly teaching it length-generalizable intermediate steps without any intermediate-step labels. At inference, the adaptive number of loops allows the model to allocate more computation to longer inputs, and a maximum-confidence stopping rule (selecting the step with lowest batch cross-entropy) provides a practical halting mechanism that achieves near-perfect accuracy on all tested tasks.

## Results

The looped Transformer with adaptive depth achieves near-perfect exact match accuracy well beyond the maximum training length of 20 across all six tasks (Parity, Copy, Binary Addition, Binary Sum, Binary Multiplication, Unique Set). For Parity, the model generalizes to 40+ digits with near-perfect accuracy when trained only up to 20 digits. For tasks like Addition and Copy where vanilla NTP fails at training length +10, the looped model still performs almost perfectly at those lengths. The maximum-confidence stopping criterion (Equation 2) selects the correct step with accuracy ≈ 1 across all tasks, confirming the model learns to converge at the right number of iterations.

## Baselines & Comparisons

The paper compares three baselines: vanilla NTP, NTP with pause tokens (Goyal et al., 2023), and NTP with weight-tied layers (McLeish et al., 2024). Vanilla NTP fails to length-generalize on most tasks, dropping sharply just beyond the maximum training length of 20. NTP-Loop (weight-tied layers) improves generalization on Addition, Copy, and Multiplication but still falls well behind the proposed adaptive-depth method. NTP-Pause (pause tokens) introduces only slight improvements on Binary Sum and Unique Set, consistent with the observation that pause tokens add parallel rather than sequential compute. Across all six tasks, the looped Transformer with adaptive depth and step-dependent supervision consistently outperforms all three baselines in length generalization, with the gap widening as test length increases beyond the training distribution.

## Relation to Prior Work

This paper extends the Looped Transformer architecture from Yang et al. (2024) and the RASP-L learnability framework from Zhou et al. (2024a) by introducing n-RASP-L, a formal class of problems solvable by iterating a fixed-depth RASP-L program T(n) times where T depends on input length. It departs from Universal Transformers (Dehghani et al., 2018) and PonderNet (Banino et al., 2021) in three key ways: using full-output prediction instead of next-token prediction, a decoder-only architecture without positional encoding, and a simpler confidence-based halting mechanism. The step-dependent supervision strategy—where the same decoder block receives gradient signals at different iteration counts across training samples of varying lengths—is a novel training algorithm not present in prior looped-model work.

## Why It Matters / Open Questions

The n-RASP-L formalization provides a principled criterion for identifying which algorithmic tasks are amenable to looped-Transformer solutions, and the empirical results show that adaptive depth with step-dependent supervision achieves near-perfect length generalization on tasks (parity, copy with repeated tokens, binary addition) where vanilla NTP fails completely. Key limitations include the requirement that T(n) be known in training data, the inability to handle tasks requiring multiple sequential loops, and the computational cost of backpropagating through many loop iterations. Open questions include whether the framework extends to more complex reasoning tasks, whether different positional embeddings can be synergistically combined, and whether the step-dependent supervision principle transfers to larger-scale language modeling settings.

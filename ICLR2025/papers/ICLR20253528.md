## Problem

Diffusion models are heavily computation-bound, making weight-only quantization insufficient for speedup—both weights and activations must be quantized to the same low bit width. At 4-bit precision, both weights and activations contain severe outliers that existing post-training quantization methods like smoothing cannot adequately handle, since smoothing merely redistributes outliers between the two sides rather than eliminating them. No prior work had successfully achieved 4-bit W4A4 post-training quantization for diffusion models with measured GPU speedup.

## Input / Output

SVDQuant is a post-training quantization technique applied to pre-trained text-to-image diffusion models (UNet or DiT backbones, ranging from 600M to 12B parameters). At inference time, the quantized model takes a text prompt and produces a generated image, supporting both INT4 and NVFP4 data types. A notable practical feature is that off-the-shelf LoRA adapters can be applied to the quantized model without re-quantization, since the Nunchaku engine fuses the LoRA branch into the existing low-rank branch by slightly increasing its rank.

## Method

SVDQuant introduces a two-stage outlier absorption strategy. First, smoothing migrates activation outliers into the weight matrix, making activations easier to quantize but amplifying weight outliers. Second, SVD decomposes the smoothed weight into a 16-bit low-rank branch (rank 16–32) that absorbs the dominant singular values and a residual that is quantized to 4-bit, dramatically reducing the residual's magnitude and outlier count. The key system contribution is Nunchaku, a co-designed inference engine that fuses the low-rank branch's down-projection with the 4-bit quantization kernel and its up-projection with the 4-bit GEMM kernel, eliminating redundant DRAM reads/writes and reducing the low-rank overhead from ~50% to 5–10% latency. Theoretical analysis (Propositions 4.1–4.2) shows the quantization error is bounded by the residual's Frobenius norm, justifying SVD as the optimal decomposition for minimizing this bound.

## Results

On FLUX.1-dev (12B DiT), SVDQuant INT W4A4 achieves PSNR 21.0 and LPIPS 0.223 on MJHQ, surpassing the NF4 W4A16 baseline (PSNR 19.5, LPIPS 0.272) while quantizing both weights and activations to 4 bits. On PixArt-Σ, SVDQuant INT W4A4 reaches FID 19.2 and PSNR 17.6, compared to ViDiT-Q W4A4's FID 412 and PSNR 6.44. The method reduces the 12B FLUX.1 model memory by 3.5× and delivers a 3.0× speedup over NF4 W4A16 on an RTX 4090 (INT4) and 3.1× on an RTX 5090 (NVFP4), with a 10.1× end-to-end speedup on a 16GB laptop GPU by eliminating CPU offloading.

## Baselines & Comparisons

Against NF4 W4A16 (QLoRA) on FLUX.1-dev, SVDQuant W4A4 wins on every metric: PSNR improves from 19.5 to 21.0, LPIPS drops from 0.272 to 0.223, and ImageReward rises from 0.910 to 0.935, despite quantizing activations to 4 bits as well. On PixArt-Σ, SVDQuant INT W4A4 (FID 19.2, PSNR 17.6) dramatically outperforms ViDiT-Q at the same W4A4 precision (FID 412, PSNR 6.44) and even surpasses ViDiT-Q's W4A8 setting (FID 37.3, PSNR 12.0). Similarly, on SDXL-Turbo, SVDQuant W4A4 (FID 24.6, PSNR 18.1) far exceeds MixDQ W4A4 (FID 353, PSNR 11.0) and MixDQ W4A8 (FID 27.7, PSNR 15.7). In the ablation study, SVDQuant also outperforms LoRC (Yao et al., 2024), which uses a low-rank branch to compensate quantization error after-the-fact, because SVDQuant instead decomposes the weight before quantization so the low-rank branch absorbs the dominant singular values rather than trying to correct a diffuse error distribution.

## Relation to Prior Work

This paper extends the diffusion model quantization line (Q-Diffusion, PTQ4DM, ViDiT-Q, MixDQ) from 8-bit or weight-only 4-bit settings to full W4A4, where both weights and activations are quantized to 4 bits. Conceptually, it departs from SmoothQuant's outlier redistribution strategy by introducing an SVD-based low-rank branch that absorbs the magnified weight outliers at 16-bit precision, leaving only a well-behaved residual for 4-bit quantization. The co-designed Nunchaku inference engine, which fuses low-rank and low-bit kernels to eliminate redundant memory access, is a systems-level contribution not present in prior quantization work, and it enables seamless LoRA integration without re-quantization—something prior methods cannot do.

## Why It Matters / Open Questions

This is the first demonstrated W4A4 post-training quantization for diffusion models with measured hardware speedup, reducing the 12B FLUX.1 memory footprint by 3.5× and enabling it to run entirely on a 16GB consumer GPU (10.1× speedup by eliminating CPU offloading). The open-sourced quantization library and Nunchaku engine make this immediately deployable, and the seamless LoRA compatibility removes a major practical barrier for community fine-tuning. Open questions include whether the approach extends to video diffusion models, whether the SVD+smoothing decomposition generalizes to sub-3-bit regimes (2-bit fails), and whether the kernel fusion strategy transfers to non-NVIDIA hardware or different attention mechanisms.

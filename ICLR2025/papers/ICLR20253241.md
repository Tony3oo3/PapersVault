## Problem

Existing LLM-plus-search approaches reduce complex information-seeking to a single-step RAG retrieval, which breaks down when queries require multi-step decomposition, when relevant facts are scattered across many noisy web pages, and when accumulated content exceeds the LLM's context window. The paper asks how to mimic the human cognitive process of progressively decomposing a question and integrating evidence from many sources to overcome these three limitations.
![Teaser figure](../imgs/ICLR20253241/cropped_page1_idx0.webp)

## Input / Output

The system accepts a natural-language text query and, after searching and integrating content from 300+ web pages in under 3 minutes, produces a detailed response with inline [id] source citations. Internally, the WebPlanner maintains a directed acyclic graph (DAG) of sub-questions and reasoning dependencies that drives search orchestration but is not exposed to the user. All experiments are zero-shot (no fine-tuning) and rely solely on a search API (Bing) as the external tool, with no additional reference sources.

## Method

MindSearch is a zero-shot LLM-based multi-agent framework with two specialized roles: a WebPlanner that models problem-solving as iterative DAG construction via Python code generation (code-as-planning), and multiple parallel WebSearchers that perform hierarchical retrieval. The WebPlanner decomposes the user query into atomic sub-questions (graph nodes) and progressively extends the graph by adding nodes and edges through predefined code interfaces; each newly added node immediately triggers a WebSearcher, and nodes with no mutual dependencies execute in parallel. Each WebSearcher runs a coarse-to-fine pipeline: multi-query generation to broaden recall, aggregation across multiple search APIs (Google, Bing, DuckDuckGo), LLM-based page selection to filter noise, and final summarization with citations. The multi-agent design distributes context load—each WebSearcher receives only its sub-query prefixed with parent and root node context—enabling efficient handling of long contexts and parallel search over hundreds of pages without exceeding any single model's context limit.

## Results

On closed-set QA, MindSearch achieves an average score of 59.8 with GPT-4o and 49.2 with InternLM2.5-7b-chat across Bamboogle, Musique, and HotpotQA, outperforming the ReAct Search baseline by 4.7% and 6.3% respectively. The gains are most pronounced on harder subsets: on HotpotQA Hard, MindSearch reaches 78.0 (GPT-4o) and 57.0 (InternLM2.5-7b) versus 70.0 and 49.0 for ReAct Search. In the open-set human evaluation, MindSearch (InternLM2.5-7b) is preferred over both ChatGPT-Web and Perplexity.ai Pro by a large margin in depth and breadth, while factuality scores are closer (70% vs. 83% for breadth).

## Baselines & Comparisons

MindSearch consistently outperforms all five compared baselines. Against ReAct (Yao et al., 2022), MindSearch gains +4.7% average on GPT-4o (59.8 vs. 55.1) and +6.3% on InternLM2.5-7b (49.2 vs. 42.9), with the largest margin on HotpotQA Hard (+8.0 and +8.0 respectively). Against CodeAct (Wang et al., 2024), MindSearch improves from 61.3 to 64.0 average on HotpotQA (InternLM2.5-7b), confirming that graph-structured planning surpasses flat code-action calling. Against Self-ask (Press et al., 2022), MindSearch leads by 5.7 points (64.0 vs. 58.3) on HotpotQA average. Against Searchin (Xu et al., 2024), MindSearch edges ahead by 2.4 points (64.0 vs. 61.6), with a notable 3-point advantage on the Hard subset. In the open-set human preference evaluation, MindSearch (InternLM2.5-7b) is preferred over ChatGPT-Web (GPT-4o) and Perplexity.ai Pro on depth and breadth, though factuality scores remain closer, suggesting the multi-agent retrieval introduces some noise that slightly dilutes factual precision.

## Relation to Prior Work

MindSearch extends the code-as-action paradigm from CodeAct (Wang et al., 2024) by replacing flat function calling with directed acyclic graph construction, allowing the LLM to express sequential and parallel dependencies among sub-queries through Python code. The WebSearcher component is explicitly framed as a hierarchical RAG agent (building on Lewis et al., 2020), adding a coarse-to-fine page selection step and multi-query generation on top of standard retrieve-then-generate. Conceptually, the paper departs from single-turn RAG and ReAct-style sequential search by introducing a multi-agent architecture where a planner and multiple searchers distribute cognitive load, and from iterative query-refinement methods like Search-in-the-Chain by constructing the reasoning graph incrementally rather than regenerating the full chain at each step.

## Why It Matters / Open Questions

The most practically significant finding is that MindSearch with a 7B open-source model (InternLM2.5-7B) achieves human-preferred responses over ChatGPT-Web (GPT-4o) and Perplexity.ai Pro on open-set QA, suggesting that architectural design can partially compensate for model scale in search-augmented settings. However, the factuality score lags behind breadth (70% vs 83%), and the authors acknowledge that more detailed search results may distract the model, pointing to an unresolved hallucination problem during web browsing. Open questions include whether the DAG-based planning generalizes to visual inputs and interactive web navigation, and whether the multi-agent context management strategy transfers to single-model training for long-context tasks.

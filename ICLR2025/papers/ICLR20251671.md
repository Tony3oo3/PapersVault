## Problem

Existing LLM agent frameworks like Reflexion and LATS suffer from two critical limitations: (i) repetitive self-reflections that produce redundant inputs and severely limit exploration of the decision space, and (ii) a lack of cross-task knowledge transfer, as local memory is reset before each new task. The paper quantifies this redundancy (e.g., 111 total reflections but only 8 unique ones on a single HumanEval problem) and asks how to both diversify reasoning trajectories and retain insights across tasks.

## Input / Output

The framework consumes a natural-language task description (e.g., a Python function signature with docstring), visible or synthetic unit tests, and optionally j retrieved trajectories from the memory bank (retrieved via cosine similarity of docstring embeddings using Cohere-Embed-V3). The actor LLM produces a code implementation, which is evaluated by an external environment (Python interpreter) or LLM-based scorer. If evaluation fails, the diverse-reflections module generates k structured reflections (each with a Problem/Fix format) that are fed back to the actor for the next attempt. Successful complete trajectories are stored in the memory bank for future retrieval.

## Method

DoT builds on Reflexion's actor–evaluator architecture but replaces the single self-reflection agent with a Diverse-Reflections module (M_dr) that generates k semantically distinct reflections in a single LLM call using an explicit diversity prompt, rather than iteratively sampling one reflection at a time. This one-shot approach was empirically shown to outperform iterative sampling in both accuracy and cost across GPT-4o-mini, GPT-4o, and OpenAI o1. DoT-bank extends DoT with a persistent, task-agnostic memory bank that stores complete successful trajectories indexed by docstring embeddings; when re-attempting failed tasks, the top-j most similar trajectories are retrieved and injected as in-context examples for the actor, enabling cross-task knowledge transfer without any fine-tuning. The diversity strategy is modular: when applied to Tree of Thoughts on Game of 24, it yields a 13% accuracy gain over vanilla ToT, demonstrating broad applicability beyond the Reflexion-based pipeline.

## Results

On HumanEval with Claude Sonnet 3.5, DoT-bank achieves 93.9% Pass@1 (vs. 86.59% base), while DoT alone reaches 91.46%. On LeetCodeHardGym, DoT achieves a 7.5% absolute Pass@1 gain over base (50.0% vs. 42.5%), and DoT-bank reaches 52.5% (+10%), while both Reflexion and LATS show zero improvement over base. DoT is approximately 4× more cost-effective than LATS (e.g., $3.18 vs. $14.75 on LeetCodeHardGym) while delivering superior accuracy. On Game of 24, integrating DoT's diversity strategy into ToT yields a 13% absolute accuracy gain (82% vs. 69%).

## Baselines & Comparisons

DoT consistently outperforms Reflexion across all datasets and models: on HumanEval (Sonnet 3.5), DoT achieves 91.46% vs. Reflexion's 88.41%, and on LeetCodeHardGym, DoT reaches 50.0% while Reflexion plateaus at 42.5% (identical to base). Against LATS, DoT matches or exceeds accuracy at a fraction of the cost—on LeetCodeHardGym, DoT scores 50.0% at $3.18 versus LATS's 42.5% at $14.75 (a 4.6× cost reduction with 7.5% higher accuracy). On the GPT-3.5-Turbo HumanEval comparison, DoT (75%) surpasses CoT (46.9%), ReAct (56.9%), and ToT (54.4%), and slightly exceeds the corrected LATS (73.9%). The paper also demonstrates that DoT's diversity module is modular: when plugged into ToT on Game of 24, it lifts accuracy from 69% to 82% (+13%), showing the approach generalizes beyond the Reflexion-style architecture. Gains are most pronounced for smaller models (e.g., Llama-3.1-8B sees +18.90% with DoT-bank on HumanEval) and on harder benchmarks like LeetCodeHardGym where baselines fail to improve at all.

## Relation to Prior Work

DoT builds directly on the Reflexion (Shinn et al., 2023) and LATS (Zhou et al., 2023) lineage of iterative self-reflection agents, but departs from them in two specific ways: it replaces the single self-reflection step with a diverse-reflections module that generates k semantically distinct reflections in one shot, and it introduces a persistent, task-agnostic memory bank that retrieves successful trajectories from previously solved tasks as in-context examples. The diversity strategy is also shown to be modular, plugging into Tree of Thoughts (Yao et al., 2023a) to yield a 13% gain on Game of 24. Unlike prior diversity-inducing methods (DIV-se, Flow of Reasoning) that rely on manual personas or task-specific fine-tuning, DoT achieves diversity through structured prompting and one-shot sampling without any additional training.

## Why It Matters / Open Questions

The paper identifies a concrete and previously underappreciated failure mode in reflection-based agents—highly redundant self-reflections that waste tokens and limit decision-space exploration—and shows that a simple one-shot diverse-sampling fix recovers much of the lost exploration at a fraction of LATS's cost (4× cheaper on LeetCodeHardGym). The task-agnostic memory bank, which grows as the agent solves more tasks and retrieves contextually similar trajectories via embedding similarity, points toward a practical path for agents that accumulate knowledge across a deployment stream rather than resetting per task. Key limitations include the framework's focus on programming benchmarks, the residual 1.4× cost premium over Reflexion, and the acknowledgment that one-shot diversity generation is not foolproof, leaving open the question of more principled diversity guarantees and extension to non-programming reasoning domains.

## Problem

Modern LMs process heterogeneous data types (multiple languages, code, math, images, audio) with a single set of parameters, but it remains unclear whether they do so by learning a unified semantic representation space or by maintaining separate subspaces per data type. Prior evidence (Wendler et al., 2024) was limited to simple synthetic tasks and a single model, leaving open whether a shared 'semantic hub' is a general property across diverse data types and whether it is causally functional or merely a vestigial byproduct of English-dominant training.

## Input / Output

The analysis consumes raw inputs across five data types—parallel text in multiple languages, Python programs, arithmetic expressions, RGB images (patched into tokens), and 10-second audio clips—and produces three types of evidence: layer-wise cosine similarity scores between semantically equivalent cross-type inputs (relative to unrelated baselines), logit lens token probabilities at each layer revealing which language's vocabulary best matches intermediate hidden states, and steered generation outputs from causal interventions. A key constraint is that for multimodal models lacking vocabulary tokens for non-dominant modalities, only the relative similarity test and a modified logit lens test are applicable, since the direct cross-type token comparison requires tokens in both data types.

## Method

The paper formalizes the semantic hub hypothesis as relative similarity inequalities: semantically equivalent inputs from different data types should be closer in intermediate hidden states than unrelated inputs, and intermediate representations should align more strongly with the dominant pretraining language's tokens than with the input language's tokens. They test this using two complementary tools: (1) cosine similarity of last-token hidden states across parallel data (translations, image-caption pairs, audio-label pairs, code-English pairs), and (2) the logit lens, which applies the model's unembedding matrix to intermediate hidden states to read out token probabilities without additional training. To establish causality, they perform interventions in the shared space using the dominant language—Activation Addition with sentiment trigger words for multilingual steering, unembedding vector differences for code function-argument steering, hidden-state replacement for image color steering, and unembedding differences for audio classification—demonstrating that manipulating the English-anchored representation predictably changes outputs in non-English, code, visual, and audio domains.

## Results

Across multilingual experiments, parallel English-Chinese sentences achieve >80% cosine similarity in intermediate layers (significantly above non-matching baselines), and Llama-3's hidden states are closer to English unembeddings than Chinese ones from layer 17 through 31 when processing Chinese text. For code, the English token 'and' outperforms the ground-truth next token in logit lens probability at commas in Python list literals (N=6,923), and semantic role tokens dominate over surface-form arguments in early-middle layers (N=540). Causal interventions confirm the shared space is functionally active: cross-lingual ActAdd steering in English matches monolingual steering effectiveness on sentiment (e.g., Spanish ↓: 0.125 vs. 0.139 sentiment), code steering achieves up to 67% success in converting range(end) to range(0,end), and vision steering reaches >80% success in redirecting color perception.

## Baselines & Comparisons

This is an interpretability paper that tests a hypothesis rather than comparing competing methods, so there are no traditional baseline comparisons. Instead, the paper validates the semantic hub hypothesis across seven models (Llama-2, Llama-3, Baichuan-2, BLOOM, LLaVA, Chameleon, SALMONN) and four data-type pairs (English/Chinese, English/Python, English/images, English/audio). The key comparison is monolingual vs. cross-lingual steering: English steering vectors perform comparably to or better than native-language vectors (e.g., for Chinese ↑ steering, English achieves 0.179 sentiment vs. Chinese's 0.153, with similar disfluency), confirming the shared space is genuinely language-agnostic. BLOOM, which lacks a dominant pretraining language, shows no clear intermediate-language dominance, serving as a natural control that supports the 'anchored by dominant language' claim. The code intervention (67% success) and vision intervention (>80% success) further demonstrate that the shared space is causally load-bearing rather than a training artifact.

## Relation to Prior Work

This paper extends Wendler et al.'s (2024) finding that Llama-2 maps non-English inputs into an 'English space' on synthetic tasks to a much broader setting: natural text across multiple languages, code, arithmetic, vision, and audio, tested across seven different models. It deliberately departs from the large body of cross-modal alignment work (Merullo et al., 2022; Huh et al., 2024; Ilharco et al., 2021) that shows separately trained models can be aligned via learned transformations, instead demonstrating that a single autoregressive model organically produces a shared representation space without any explicit alignment objective. The interpretability toolkit is built on the logit lens (nostalgebraist, 2020) for probing and Activation Addition (Turner et al., 2024) for causal intervention, both repurposed here to test cross-data-type hypotheses rather than single-modality ones.

## Why It Matters / Open Questions

The causal intervention results are the strongest contribution: showing that steering in English predictably changes outputs for Chinese text, Python code, image patches, and audio clips demonstrates the shared space is functionally active rather than a training artifact, opening a practical route to cross-modal model control. A key limitation is the reliance on the logit lens, which the authors acknowledge is a simple probe; more expressive methods (tuned lens, patchscopes, sparse autoencoders) could reveal richer structure in the hub. Open questions include whether the phenomenon persists in models with no dominant language (BLOOM showed a weaker effect), whether it holds for non-autoregressive architectures, and whether the hub structure is stable across fine-tuning or RLHF.

## Problem

In meta-reinforcement learning with sparse rewards, agents struggle to identify the current task and explore efficiently because existing BAMDP-based methods rely on reconstructing the environment's reward signal, which provides insufficient feedback when rewards are uninformative. Prior approaches also neglect the common structural similarities shared across tasks in a distribution, missing an opportunity to accelerate task identification through analogical reasoning. SimBelief addresses this by learning a latent task belief metric that captures behavioral similarity between tasks, enabling rapid adaptation even when the agent has only limited interaction data.

## Input / Output

The method consumes state vectors and historical trajectory context (observations, actions, rewards over H steps) through a context encoder, and maps states to a compressed latent space via a state encoder g. The policy outputs actions conditioned on the augmented state (real state plus a combined task belief), where the combined belief is a Gaussian mixture of a latent task belief (capturing global inter-task similarity) and a specific task belief (capturing local task-specific dynamics reconstructed via VAE in the original state space). The latent task belief is learned without task IDs, relying solely on contextual information to infer task relationships.

## Method

SimBelief introduces a latent task belief metric (Definition 2) that extends π-bisimulation metrics from state space to task belief space, measuring similarity between two tasks via differences in their latent reward model, transition model (using 2-Wasserstein distance), and inverse dynamics model (using L1 norm). The architecture comprises three components: a state encoder mapping to a shared latent dynamics space, a belief similarity learner ψ_l that encodes inter-task similarity into latent task beliefs, and a latent dynamics model p_θ (reward, transition, inverse dynamics) conditioned on these beliefs. A separate VAE reconstructs the specific task in the original state space to preserve fine-grained information lost in the latent abstraction. The two beliefs are combined via a weighted Gaussian mixture (Eq. 7) and fed to a SAC policy, with a KL divergence term (Eq. 8) regularizing the latent belief toward the specific belief for stable convergence. The bisimulation-inspired loss (Eq. 5) aligns belief-space distances with dynamics-space differences, and theoretical results (Theorems 1–2) provide value difference and transfer bounds guaranteeing that similar latent beliefs imply similar value functions and bounded policy transfer error.

## Results

SimBelief is evaluated on six sparse-reward tasks (Cheetah-Vel-Sparse, Point-Robot-Sparse, Walker-Rand-Params from MuJoCo; Panda-Reach, Panda-Push, Panda-Pick-And-Place from panda-gym) over 3 random seeds. The main results (Figure 3) show SimBelief achieving the highest meta-episode average return and success rate across all six tasks, with particularly large margins on the panda-gym tasks where BAMDP-based baselines (VariBAD, HyperX, RL²) struggle to converge. On out-of-distribution tasks (Figure 4), SimBelief maintains high return over 5 rollouts as the task distribution progressively deviates from training, while other methods degrade more sharply. The paper reports results as learning curves rather than single-point numbers, with SimBelief consistently dominating the final performance across all environments.

## Baselines & Comparisons

SimBelief outperforms all five baselines across all six sparse-reward tasks. Against PEARL and MetaCURE (posterior-sampling-based methods), SimBelief achieves more stable and higher final returns, attributed to its learned common task structure rather than per-task posterior sampling. Against VariBAD, HyperX, and RL² (BAMDP-based methods), SimBelief shows substantially faster convergence and higher asymptotic performance, especially on the panda-gym tasks where these baselines fail to achieve meaningful online adaptation due to over-reliance on sparse reward signals. On OOD generalization (Cheetah-Vel-Sparse with velocity range shifted to [3,4], Point-Robot-Sparse with radius increased to 1.2), SimBelief maintains near-Bayes-optimal performance within 5 episodes while all baselines degrade, with HyperX and VariBAD showing the largest performance drops. The ablation in Appendix G.1 confirms that removing the latent dynamics (reducing to a VariBAD-like VAE-only reconstruction) causes significant performance drops, particularly on Panda-Push and Panda-Pick-And-Place.

## Relation to Prior Work

SimBelief adapts the π-bisimulation metric (Castro, 2020), which measures behavioral similarity between states in an MDP, to define a latent task belief metric that quantifies similarity between task beliefs in a shared latent space. This is embedded within the BAMDP framework (Duff, 2002), but departs from prior BAMDP-based meta-RL methods (VariBAD, HyperX, RL²) that rely on reward reconstruction or exploration bonuses to handle sparse rewards, and from posterior-sampling approaches (PEARL) that treat task inference and control separately. The key conceptual move is learning a latent dynamics model conditioned on a task belief similarity representation, then combining it with a VAE-based specific task belief via a Gaussian mixture, rather than reconstructing the full environment in latent space.

## Why It Matters / Open Questions

The paper addresses a practical bottleneck in meta-RL: sparse or uninformative rewards that prevent agents from efficiently identifying and adapting to new tasks, particularly in robotic manipulation (panda-gym). The latent task belief similarity provides a principled mechanism for transferring knowledge across structurally similar tasks, which is validated by OOD generalization results. However, the theoretical analysis contains notable gaps (e.g., the discount factor γ is explicitly disregarded in the value difference bound proof), and all experiments are limited to low-dimensional state-vector environments, leaving open whether the approach scales to high-dimensional or visual tasks. The reliance on a Gaussian mixture to combine latent and specific beliefs, while effective, introduces hyperparameters (w_r, w_l) whose optimal values may be task-dependent.

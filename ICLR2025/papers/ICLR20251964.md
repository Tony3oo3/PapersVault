## Problem

Heterogeneous collaborative perception (CP) among connected vehicles is hindered by domain gaps arising from differences in sensor modalities, model architectures, and downstream tasks. Existing approaches either scale poorly (polynomial complexity in the number of agents), require sharing model components (compromising security), or cannot simultaneously address all three forms of heterogeneity. No prior framework enables task- and model-agnostic collaboration with high scalability and preserved model security.

## Input / Output

Each agent's encoder produces a local BEV feature map with agent-specific spatial resolution (e.g., 64×64 or 128×128) and channel count (e.g., 64 or 256), derived from either LiDAR point clouds or RGB camera images. The adapter-reverter pair normalizes these to a fixed protocol BEV dimension of 128×128×64 for broadcasting, then reverts received protocol features back to each agent's native feature space. Final outputs are task-specific: 3D object detection bounding boxes (evaluated via AP@30/AP@50) or BEV segmentation masks (evaluated via MIoU), depending on each agent's downstream objective.

## Method

STAMP introduces a Collaborative Feature Alignment (CFA) module built from lightweight adapter-reverter pairs that transform BEV features between each agent's local domain and a shared protocol domain. The adapter uses linear interpolation for spatial resolution alignment, three ConvNeXt layers for feature pattern alignment, and two convolutional layers for channel dimension mapping, totaling only ~1 MB of additional parameters per agent. Training proceeds in two stages: first, a protocol network is trained end-to-end on a standard CP task; second, each agent's adapter and reverter are trained for 5 epochs using a combined loss of feature-space alignment (L2 distance between adapted/reverted features and their targets) and decision-space alignment (task-specific losses on the fused outputs). This design is agnostic to other agents' modalities, architectures, and tasks—agents only exchange protocol BEV features without revealing local model parameters—enabling scalable, secure collaboration across arbitrarily heterogeneous fleets.

## Results

On the OPV2V dataset (σ=0.0, 4 agents), STAMP achieves AP@30 of 0.989 and AP@50 of 0.985, outperforming HEAL (0.985/0.983), E2E Training (0.986/0.980), Calibrator (0.938/0.920), and Late Fusion (0.935/0.914). On the real-world V2V4Real dataset, STAMP achieves the highest AP@30 of 0.633 (A1+A2), surpassing HEAL (0.628), E2E Training (0.612), Calibrator (0.524), and Late Fusion (0.511). STAMP also requires only 2.36 GPU hours per additional agent versus 17.07 for existing heterogeneous pipelines, a 7.2× training cost saving.

## Baselines & Comparisons

STAMP consistently outperforms all baselines. Against Calibrator (Xu et al., 2023a), a late-fusion method with domain-gap calibration, STAMP gains +5.1 AP@30 on OPV2V (0.989 vs 0.938) and +10.9 AP@30 on V2V4Real (0.633 vs 0.524), demonstrating that intermediate fusion with feature alignment substantially exceeds late fusion. Against HEAL (Lu et al., 2024), which uses backward alignment to create heterogeneous encoders, STAMP achieves a marginal but consistent edge: +0.4 AP@30 on OPV2V (0.989 vs 0.985) and +0.5 AP@30 on V2V4Real (0.633 vs 0.628), while requiring far fewer trainable parameters per additional agent. Against E2E Training (joint training of all heterogeneous models), STAMP matches or slightly exceeds accuracy (0.989 vs 0.986 on OPV2V) but with dramatically lower training cost (2.36 vs 17.07 GPU hours per agent). In the additional heterogeneous-modality comparison (Table A4), STAMP ties HEAL at 0.934 average AP@50 and clearly surpasses V2X-ViT (0.905), CoBEVT (0.899), and HM-ViT (0.918), though the latter three use a single shared fusion layer and thus cannot be directly compared per-agent. Under adversarial attack (Table A3), STAMP retains 0.503 AP@50 versus 0.087 for E2E Training, confirming the security advantage of not sharing local models.

## Relation to Prior Work

STAMP extends the heterogeneous collaborative perception (CP) line of work initiated by MPDA (Xu et al., 2023b) and HEAL (Lu et al., 2024), which each address subsets of agent heterogeneity (modality or architecture) but suffer from polynomial scaling or high retraining costs. It also departs from task-agnostic CP via scene completion (Li et al., 2023c), which handles heterogeneous tasks but not heterogeneous modalities or architectures. The key conceptual departure is the introduction of a shared 'protocol BEV feature' domain bridged by lightweight adapter-reverter pairs, repurposing the adapter paradigm from transfer learning to create a universal intermediate representation that is agnostic to all three heterogeneity dimensions simultaneously.

## Why It Matters / Open Questions

STAMP is the first framework to enable collaboration among agents that differ in modality, architecture, and downstream task without sharing model parameters or task information, which has direct implications for security (resistance to model-stealing and adversarial attacks) and practical deployment in mixed-fleet autonomous driving. The 7.2x training-time savings per additional agent and ~1MB memory footprint per adapter-reverter pair make large-scale heterogeneous CP feasible. A notable limitation is the observed bottleneck effect, where the weakest agent degrades the strongest agent's performance, motivating the authors' proposed multi-group collaboration system as future work. Open questions include whether the protocol model's task choice can be automated and how the framework performs under dynamic group membership in real traffic.

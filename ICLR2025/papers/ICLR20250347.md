## Problem

Existing RAG optimization methods either use supervised fine-tuning (SFT) that causes overfitting to training signals and catastrophic forgetting, or only align the retrieval module to the generation module while leaving the generation module's knowledge conflict with parametric memory unaddressed. No prior method end-to-end optimizes all agents in a multi-module RAG system while simultaneously aligning data preferences across them.
![Teaser figure](../imgs/ICLR20250347/cropped_page3_idx0.webp)

## Input / Output

The system takes a natural-language query and a set of top-5 retrieved documents (from MS MARCO 2.1 via bge-large) as input. The knowledge refinement module produces a binary YES/NO decision per document to filter the set, and the generation module produces a free-form text response. During DDR training, the generation module samples responses at five temperature settings (0.5–0.9) with five rounds each, and automatic metrics (Rouge-L for MARCO QA/WoW, Accuracy for others) serve as the reward signal for constructing preference pairs.

## Method

DDR optimizes each agent in a two-agent RAG system (knowledge refinement V_KR and generation V_Gen) using DPO with rollout-based reward collection. For a target agent V_t, DDR samples multiple perturbed outputs, feeds each through the downstream subsystem V_{t+1:T} (rollout), and scores the final system output to obtain a reward r(x, ỹ_t). The highest- and lowest-reward samples form a preference pair, and the DPO loss (Eq. 4) trains V_t to increase the probability of the preferred output relative to a frozen reference model. The generation module is additionally trained with responses sampled both with retrieved documents and with the query alone, enabling it to learn when to trust external versus parametric knowledge. Training proceeds iteratively: V_Gen is optimized first, then V_KR is tuned using the DDR-optimized V_Gen as the evaluation model, ensuring data preferences are aligned across both agents.

## Results

With Llama3-8B as the generation module, RAG-DDR (2-round) achieves 52.1 accuracy on NQ, 89.6 on TriviaQA, 27.3 Rouge-L on MARCO QA, 39.0 on HotpotQA, 40.6 on T-REx, and 16.8 F1 on WoW. With the smaller MiniCPM-2.4B, RAG-DDR reaches 47.6 on NQ, 83.6 on TriviaQA, 29.8 on MARCO QA, 33.2 on HotpotQA, 32.1 on T-REx, and 18.2 on WoW. These represent approximately 7% absolute improvements over Vanilla RAG and 5% over the strongest SFT baseline (RA-DIT) for the smaller model, with gains concentrated in MARCO QA (+7.5 over RA-DIT) and HotpotQA (+4.1 over RA-DIT) for Llama3-8B.

## Baselines & Comparisons

RAG-DDR outperforms all five baselines on nearly every task. Against Vanilla RAG (zero-shot in-context), RAG-DDR gains ~7% absolute on NQ (52.1 vs. 46.2) and ~8.5% on HotpotQA (39.0 vs. 30.1) with Llama3-8B, and ~5.4% on NQ (47.6 vs. 42.2) with MiniCPM-2.4B. Against RA-DIT (the strongest SFT baseline), RAG-DDR wins on 5 of 6 tasks for Llama3-8B (e.g., NQ 52.1 vs. 46.2, HotpotQA 39.0 vs. 34.9, MARCO QA 27.3 vs. 20.3), with the sole exception being T-REx where RA-DIT edges ahead (41.7 vs. 40.6). For MiniCPM-2.4B, RAG-DDR dominates RA-DIT on all six tasks, with the largest margin on MARCO QA (29.8 vs. 19.6, +10.2). REPLUG and Self-RAG are consistently outperformed across all tasks; Self-RAG in particular underperforms even Vanilla RAG on HotpotQA (24.3 vs. 30.1 for Llama3-8B), suggesting its reflection-token mechanism is less effective than DDR's system-level reward alignment.

## Relation to Prior Work

This paper builds on the DPO framework (Rafailov et al., 2024) and the rollout-based reward propagation from MCTS (Kocsis & Szepesvári, 2006), repurposing both for a novel application: aligning data preferences across agents in a multi-module RAG system. It departs from SFT-based RAG optimization (RA-DIT, Lin et al., 2023) by replacing supervised fine-tuning with preference learning, and from prior retrieval-only optimization (Yu et al., 2023b) by jointly optimizing both the knowledge refinement and generation modules. The two-agent RAG architecture follows Self-RAG (Asai et al., 2023), but the key conceptual departure is treating the downstream agents as an evaluation model that provides system-level rewards to upstream agents, rather than optimizing each module independently against ground-truth labels.

## Why It Matters / Open Questions

The paper demonstrates that DPO-based preference alignment is a more effective and generalizable training paradigm for RAG systems than SFT, particularly for smaller LLMs that rely heavily on retrieved knowledge. The finding that the generation module is the primary bottleneck (not retrieval quality) redirects optimization effort toward a more impactful target. Open questions include whether the approach scales to more complex multi-agent pipelines beyond three modules, whether automatic metrics (Rouge-L, Accuracy) as proxy rewards are sufficient for open-ended generation tasks, and whether the method transfers to non-QA RAG applications such as summarization or code generation.

## Problem

Existing test-time adaptation (TTA) methods assume all test samples belong to the in-distribution label space, but open-world deployment inevitably introduces noisy (OOD) samples. The paper reveals that when noisy samples are present, most TTA methods actually underperform the frozen zero-shot CLIP model, because unfiltered noisy data produces gradients an order of magnitude larger than clean data, causing the adapting classifier to overfit to noise and lose its ability to distinguish clean from noisy samples.
![Teaser figure](../imgs/ICLR20252130/cropped_page1_idx0.webp)

## Input / Output

The method consumes a sequential stream of test images (processed by a frozen CLIP ViT-B/16 image encoder) along with a set of ID class names that form text prompts for the frozen text encoder. For each input sample, it immediately outputs either a class label (if detected as clean) or a noise designation (if detected as OOD), operating online with batch size as low as 1. A queue of capacity L=128 stores image features, detector logits, and pseudo-labels to amortize detector updates, while a separate queue of N_q=512 maintains the score distribution for the adaptive threshold.

## Method

AdaND decouples the classifier and detector: the entire CLIP backbone and text-based classifier remain frozen, while a single learnable linear layer serves as the noise detector, trained with cross-entropy loss on pseudo-labels generated by ZS-CLIP's MCM score. Detection operates in two stages—the first N=10 steps rely on ZS-CLIP's MCM score with an adaptive threshold (minimizing intra-class variance over a sliding queue), after which the trained linear detector takes over. To handle clean data streams where the detector would otherwise misclassify many ID samples as noise, Gaussian noise samples are injected every M=8 inputs, ensuring the adaptive threshold always has a noisy reference and preventing over-aggressive rejection. The computational overhead is negligible (one linear layer update per L samples), making AdaND's runtime and memory comparable to the frozen ZS-CLIP baseline.

## Results

On ImageNet (the largest ID dataset), AdaND achieves an average Acc_H of 73.09%, improving over the frozen ZS-CLIP baseline (64.77%) by 8.32% and over the best TTA method TPT (64.25%) by 8.84%. For ZS-OOD detection on ImageNet, AdaND achieves 95.58% AUROC and 16.00% FPR95, improving FPR95 by 9.40% over the previous best (NegLabel at 25.40%). Computationally, AdaND requires only 0.1272s per sample at bs=1 (vs. 0.1125s for ZS-CLIP) and 3.83 GiB GPU memory, making it nearly as efficient as the frozen model.

## Baselines & Comparisons

AdaND consistently outperforms all four TTA baselines (ZS-CLIP, Tent, SoTTA, TPT) across all 11 ID datasets. On ImageNet, Tent suffers the largest degradation (Acc_H drops from 64.77 to 57.66) because its continuous parameter updates cause overfitting to unfiltered noisy samples; SoTTA partially mitigates this via memory-bank sample selection (59.47) but still falls well short of AdaND (73.09). TPT, which resets parameters per sample, is the closest TTA competitor (64.25) yet still underperforms AdaND by 8.84%. For ZS-OOD detection, AdaND (95.58% AUROC, 16.00% FPR95) surpasses MCM (90.77/42.74), CLIPN (93.10/31.10), and Energy (79.57/82.21), though NegLabel achieves a slightly higher AUROC (94.21) at the cost of mining a large-scale corpus database. Against the training-free TDA method, AdaND improves Acc_H from 64.84 to 73.09 on ImageNet, confirming the necessity of an explicit noise detector.

## Relation to Prior Work

This paper builds on the MCM score (Ming et al., 2022) for zero-shot OOD detection with CLIP and the adaptive threshold strategy from OWTTT (Li et al., 2023b), but departs fundamentally from existing TTA methods (Tent, TPT, SoTTA) by decoupling the noise detector from the classifier. While prior noisy TTA work (SoTTA, OWTTT) requires task-specific pre-trained models and focuses only on ID classification accuracy, and ZS-OOD detection methods assume clean data streams, this paper introduces the ZS-NTTA setting that requires online noisy sample detection alongside classification in a zero-shot manner. The core conceptual departure is keeping the VLM backbone and classifier entirely frozen while training only a lightweight linear noise detector on pseudo-labels, inverting the standard TTA paradigm where the classifier itself is adapted.

## Why It Matters / Open Questions

The finding that standard TTA methods underperform a frozen CLIP in noisy data streams challenges a core assumption in the TTA literature—that adaptation to target data always helps—and the gradient analysis (noisy samples produce gradients an order of magnitude larger) provides a clear mechanistic explanation. The decoupling principle (separate detector from classifier) is a generalizable design insight applicable beyond VLMs. Limitations include reliance on ZS-CLIP's detection quality for pseudo-labels (cumulative errors can degrade performance on some datasets) and the method's scope being restricted to zero-shot VLM settings. Open questions include whether the noise detector's own outputs can be safely used as pseudo-labels without error accumulation, and how these ideas extend to broader foundation model settings (e.g., LLMs with noisy or adversarial inputs).

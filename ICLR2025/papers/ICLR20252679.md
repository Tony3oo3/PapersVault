## Problem

Existing multimodal LLMs that handle multiple sensory inputs (video, audio, 3D, touch, thermal, etc.) require either full LLM updates or per-modality Q-Formers with hundreds of millions of trainable parameters, making it costly and inflexible to add new modalities. Moreover, naively concatenating tokens from many modalities inflates LLM input length and degrades reasoning quality. The paper asks whether MLLMs can efficiently leverage many modalities for video-language reasoning at a fraction of the parameter cost, analogous to how humans integrate multiple senses.

## Input / Output

CREMA takes a video (decoded to 4 frames at 1–3 fps depending on dataset) plus a text question, and optionally up to four auxiliary modalities derived from the same video via frozen pre-trained estimators (ZoeDepth for depth, Unimatch for optical flow, NLL-AngMF for surface normals) or separate sensors (audio via BEATs, 3D point cloud via GradSLAM, touch maps, thermal heatmaps). Auxiliary visual modalities are converted to RGB-compatible format before encoding with a shared ViT-G encoder. The output is a free-form or multiple-choice text answer generated by the LLM (FLAN-T5XL or Mistral-7B).

## Method

CREMA builds on a frozen BLIP-2 Q-Former backbone and attaches a lightweight Modality-specific Multi-Query Adapter (MMQA) per modality, consisting of LoRA adapters (rank 64), learnable queries, and a linear projection—adding only 4–10M trainable parameters per new modality. A self-gated fusion module treats video query tokens as the 'major' signal and merges all other modality tokens through a linear projection followed by a sigmoid gate (sigmoid(q̄)·q̄), then concatenates the gated supportive tokens with the video tokens, preventing the LLM input length from growing linearly with the number of modalities. Training uses a modality-sequential strategy where each minibatch step backpropagates only the target modality's MMQA and fusion weights, combined with a modality-adaptive early exit that skips a modality once its average gradient magnitude exceeds a temperature-scaled running threshold, reducing training time by 25–60% without performance loss.

## Results

On MUSIC-AVQA, CREMA with all five modalities (V,A,F,D,N) achieves 81.7% average accuracy using only 38M trainable parameters, outperforming BLIP-2 (V,A,F) at 78.1% with 324M parameters. On SQA3D, CREMA (V,P,D,N) reaches 54.6% average accuracy with 38M parameters versus 3D-LLM's 52.0% with 434M parameters (~91% fewer). On NExT-QA, CREMA (V,F,D,N) achieves 73.9% average accuracy with 28M parameters, surpassing BLIP-2 (V,F,D,N) at 73.3% with 432M parameters. In zero-shot settings, CREMA (V,A) scores 52.6% on MUSIC-AVQA, exceeding OneLLM (42.3%) by +10.3%p and X-InstructBLIP (44.5%) by +8.1%p.

## Baselines & Comparisons

CREMA consistently outperforms BLIP-2 across all three main benchmarks while using 87–94% fewer trainable parameters: +2.4–3.6%p on MUSIC-AVQA (81.7% vs 78.1%), +0.6%p on NExT-QA (73.9% vs 73.3%), and matching on SQA3D single-modality. Against 3D-LLM on SQA3D, CREMA (V,P,D,N) achieves 54.6% vs 52.0% with 91.2% fewer parameters (38M vs 434M). On NExT-QA, CREMA surpasses SeViLA (73.9% vs 73.8%) with 87% fewer parameters (28M vs 216M). In zero-shot evaluation, CREMA (V,A) outperforms OneLLM by +10.3%p on MUSIC-AVQA (52.6% vs 42.3%) and X-InstructBLIP by +8.1%p (52.6% vs 44.5%), while also exceeding OneLLM on SQA3D (40.0% vs 37.9% for V,P). On the novel TouchQA and ThermalQA tasks, CREMA (V,T) and (V,H) outperform BLIP-2 by +1.7%p and +1.8%p respectively, while using only 8M vs 216M trainable parameters, and substantially outperform the parameter-efficient CMC baseline (79.1% vs 44.3% on TouchQA). Notably, while BLIP-2 and 3D-LLM degrade in performance when adding extra modalities beyond video, CREMA shows consistent monotonic improvement with each additional modality.

## Relation to Prior Work

CREMA builds directly on the BLIP-2 Q-Former architecture as a shared backbone, replacing the per-modality Q-Former paradigm used by 3D-LLM, X-InstructBLIP, and BLIP-2 itself with lightweight LoRA-based Multi-Query Adapters (MMQA) that add only 4–10M trainable parameters per modality. The self-gated fusion module draws on the Swish activation (Ramachandran et al., 2017) to compress supportive modality tokens into the video query space, while the modality-sequential training strategy is inspired by alternating unimodal adaptation in multimodal representation learning (Zhang et al., 2024). The key conceptual departure from prior work is the shift from 'one large adapter per modality' to 'one shared Q-Former + many tiny modality-specific LoRA branches,' enabling near-arbitrary modality extension without architectural changes.

## Why It Matters / Open Questions

The 90%+ reduction in trainable parameters while matching or exceeding strong baselines (BLIP-2, 3D-LLM, SeViLA) across seven diverse video-reasoning benchmarks makes multi-modality MLLM deployment substantially more accessible, and the modular design means new modalities can be added without retraining existing ones. However, the framework inherits BLIP-2's image-only pre-training, limiting fine-grained temporal modeling, and the need to run external estimators (ZoeDepth, Unimatch, NLL-AngMF) for depth/flow/normals introduces inference overhead that the paper acknowledges but does not fully resolve. Open questions include whether the approach scales to stronger LLM backbones (e.g., BLIP-3, Qwen-VL) with more than five simultaneous modalities, and whether the modality-sequential training strategy generalizes to settings where modalities are truly asynchronous or missing at test time.

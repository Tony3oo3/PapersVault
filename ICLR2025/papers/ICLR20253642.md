## Problem

Task arithmetic—editing a pre-trained model by adding weighted sums of task vectors (weight deltas from fine-tuning)—has shown strong empirical results for multi-task learning, unlearning, and out-of-domain generalization, but lacks theoretical justification. The only prior analysis (Ortiz-Jimenez et al., 2023) relies on the Neural Tangent Kernel framework, which linearizes the model and provides no generalization guarantees for nonlinear architectures. This paper asks: under what conditions on task correlation and arithmetic coefficients does task arithmetic provably succeed on a nonlinear Transformer?

## Input / Output

The method consumes a pre-trained model Ψ⁽⁰⁾, a set of task vectors ΔΨ_Ti computed as element-wise weight differences between fine-tuned and pre-trained models, and scalar arithmetic coefficients λi. The theoretical analysis operates on a one-layer single-head Transformer processing sequences of P unit-norm d-dimensional tokens with binary labels determined by majority-voting of discriminative patterns. Empirically, inputs are Colored-MNIST images (for ViT-Small/16) or text sequences (for Phi-1.5/Phi-3-small), and outputs are binary class predictions or generated text evaluated by Rouge-L score.

## Method

The paper provides a feature-learning analysis of fine-tuning a one-layer single-head nonlinear Transformer, characterizing the structural properties of resulting task vectors: attention weights between label-relevant patterns become dominant while cross-pattern attention vanishes, and a constant fraction of MLP rows acquire large magnitude aligned with the discriminative direction. Building on this, Theorems 1–3 derive explicit sufficient conditions on the arithmetic coefficient λ (as a function of task correlation α = μ_T1ᵀμ_T2) for successful multi-task learning (λ ≥ 1−α+β), unlearning (λ ≤ 0 for irrelevant tasks; λ ∈ [−Θ(α⁻²), O(α⁻¹)] for contradictory tasks), and out-of-domain generalization (weighted sums of γi and γi² exceeding a margin). Corollaries 1–2 further prove that rank-1 approximations and magnitude-based pruning of task vectors preserve all generalization guarantees, providing the first theoretical justification for low-rank and sparse task vector implementations.

## Results

On Colored-MNIST, task arithmetic with irrelevant tasks (α≈0.164) achieves 91.83%/88.40% accuracy on both tasks for multi-task learning (λ=1.4) and 95.02%/50.34% for unlearning (λ=−0.6). For out-of-domain generalization, searching λ₁,λ₂ yields 91.74% accuracy on the target task, surpassing the best single fine-tuned model (88.10%) and approaching full fine-tuning (92.21%). On Phi-1.5 (1.3B), unlearning Harry Potter 1 with λ=−1 reduces Rouge-L by 37.23% on HP1, 34.71% on the aligned HP2, but only 15.13% on the less-aligned Pride and Prejudice, confirming Theorem 2's prediction that unlearning propagates more strongly to aligned tasks. Low-rank (LoRA rank 32, 0.35% parameters) task vectors preserve these effects with 35.53%/24.11%/13.83% decreases respectively.

## Baselines & Comparisons

This is primarily a theoretical paper, so comparisons are structured around validating theoretical predictions rather than benchmarking against competing methods. Against full fine-tuning on the out-of-domain task (92.21%), task arithmetic with searched coefficients (λ₁=1.2, λ₂=−0.6) achieves 91.74%, a gap of only 0.47% without any labeled data for the target task. Against the best single fine-tuned model (Ψ*_{T₁} at 88.10%), task arithmetic improves by 3.64%, demonstrating that combining task vectors outperforms any individual one. For the language unlearning experiment, the paper compares full-rank task vectors (Table 3) against low-rank LoRA task vectors (Table 4): both show the same qualitative pattern (aligned task HP2 degrades more than less-aligned PP), with the low-rank version achieving slightly smaller absolute decreases (35.53% vs 37.23% for HP1), validating Corollary 1. Scaling to Phi-3-small (7B) in Table 5 amplifies the unlearning effect on the aligned task (52.29% decrease for HP2) while keeping the less-aligned task degradation modest (20.65% for PP), further confirming the theoretical dependence on task correlation α.

## Relation to Prior Work

This paper extends the feature-learning analytical framework for Transformers (Li et al., 2023a; Cao et al., 2022) from single-task training dynamics to the merged-model setting, providing the first generalization guarantees for task arithmetic on nonlinear architectures. It departs from the closest prior theoretical work (Ortiz-Jimenez et al., 2023), which relies on NTK/infinite-width linearization to justify linear operations on task vectors, by preserving the nonlinearity of the model and analyzing a one-layer single-head Transformer trained with SGD from random initialization. The empirical task-arithmetic method itself (Ilharco et al., 2022a) and the broader weight-interpolation/model-merging literature (Matena & Raffel, 2022; Wortsman et al., 2022a) provide the motivation, but no prior work offered quantitative conditions on arithmetic hyperparameters as a function of task correlation for nonlinear models.

## Why It Matters / Open Questions

This is the first theoretical justification for why task arithmetic succeeds or fails in multi-task learning, unlearning, and out-of-domain generalization, giving practitioners a principled way to choose λ based on task relationships rather than grid search. The quantitative characterization (e.g., λ ≥ 1−α+β for aligned multi-task, λ ≤ 0 for irrelevant unlearning) and the proof that low-rank/sparse task vectors preserve guarantees directly support practical PEFT workflows. Key limitations include the restriction to one-layer single-head Transformers, binary classification, and a conceptual majority-voting data model; extending to multi-layer, multi-head, multi-class settings and to generative tasks remains open. The validation on Phi-1.5/Phi-3-small is encouraging but limited to a single unlearning scenario with Rouge-L as the sole metric.

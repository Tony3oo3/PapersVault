## Problem

Machine unlearning and membership inference attacks (MIA) have developed in parallel, yet unlearning effectiveness is typically assessed via forget-set accuracy, which does not reliably indicate whether data influence has truly been erased. This paper argues that unlearning should be evaluated adversarially: if a sophisticated MIA cannot distinguish forget instances from unseen test instances, the data's influence is effectively removed. The gap addressed is the lack of a framework that proactively incorporates MIA attacks into the design of unlearning algorithms rather than treating them as post-hoc evaluation tools.

## Input / Output

The method takes an original trained model θ_o (ResNet-18 for CV, BERT for NLP, or ViT), a retain set D_r, a forget set D_f (10% of training data for random forgetting, or an entire class for class-wise forgetting), and a test set D_te that serves as an empirical proxy for unseen data. It outputs unlearned model parameters θ_u. The test set is consumed in a dual role: it provides the non-member samples for constructing the auditing set (paired with forget-set outputs) and is also used to evaluate generalization, with a separate held-out subset for final test accuracy to avoid information leakage.

## Method

The paper formulates machine unlearning as a Stackelberg game: the unlearner (leader) deploys an unlearned model, and the auditor (follower) responds with a best-response MIA—specifically a linear SVM trained to binary-classify forget vs. test instances based on model outputs. The unlearner's cost function combines retain-set loss L(D_r; θ_u) with a weighted auditor utility α·M, so minimizing cost simultaneously preserves utility and reduces the auditor's discriminative power. The key technical contribution is computing ∂M/∂θ_u by differentiating through the auditor's optimization problem via the Implicit Function Theorem applied to the KKT conditions, implemented using differentiable optimization layers (cvxpylayers or the faster qpth solver for QP structure). This renders the entire bilevel game a single differentiable layer compatible with standard forward-backward pipelines, and the adversarial term acts as an implicit regularizer that improves generalization while suppressing membership leakage.

## Results

On 20 Newsgroups (random forgetting), SG achieves MIA accuracy of 0.5065 and MIA AUC of 0.4922, both closer to the random-guessing baseline (0.5) than retrain (0.5285 / 0.5512), while maintaining 100% retain accuracy and completing in 15.6 min versus retrain's 40.8 min. On CIFAR-10, SG's KS statistic is an order of magnitude lower than most baselines, indicating the forget and test loss distributions are nearly indistinguishable. In the Jia et al. evaluation protocol (Table 3), SG achieves the lowest average gap to retrain (0.0063) among all methods, confirming it most closely matches the gold-standard retraining model across utility and privacy metrics simultaneously.

## Baselines & Comparisons

SG outperforms all utility-preserving baselines (FT, IU, RL, l1-sparse, BE, BS, SCRUB) on MIA accuracy and AUC, bringing both metrics closest to the 0.5 random-guessing threshold. On 20 Newsgroups, SG's MIA AUC of 0.4922 beats FT (0.6059), IU (0.6054), and RL (0.7651) by 11–27 percentage points, while its KS statistic (0.0791) is roughly 3× lower than FT (0.2495) and 7× lower than RL (0.5334). Gradient Ascent (GA) achieves a nominally lower MIA accuracy (0.4995) but destroys model utility entirely (Acc_te = 0.0483), making it a degenerate solution. In the Jia et al. protocol on CIFAR-10, SG attains the lowest average gap to retrain (0.0063) versus FT (0.0555), GA (0.0680), and IU (0.1091), confirming it best preserves the retrain model's behavior. SG also runs substantially faster than retrain (15.6 min vs. 40.8 min on 20 Newsgroups; 3.48 min vs. 24.66 min on CIFAR-10 in Table 3), and the accelerated variant SG(Acc.) using qpth further reduces per-epoch attack time by ~4× compared to cvxpylayers.

## Relation to Prior Work

This paper unifies two research threads that have developed in parallel—machine unlearning and membership inference attacks (MIA)—by formulating unlearning as a Stackelberg game where the unlearner (leader) optimizes model parameters while anticipating the auditor's (follower) best-response MIA. It builds on differentiable optimization tools (cvxpylayers, OptNet/qpth) and the Implicit Function Theorem to compute gradients through the auditor's optimization problem, making the bilevel structure end-to-end differentiable. Unlike prior adversarial unlearning approaches (Nasr et al. 2018; Sharma et al. 2024) that rely on purely NN-based minimax formulations, the Stackelberg game framework accommodates diverse, differentiable attack strategies (e.g., linear SVM, quantile regression) and existing unlearning loss functions, offering greater modularity.

## Why It Matters / Open Questions

The framework provides a principled, adversarial lens for evaluating and designing unlearning algorithms, shifting the question from 'did we reduce loss on the forget set?' to 'can a sophisticated attacker still distinguish forget from test instances?' This reframing is more aligned with real privacy threats. However, class-wise forgetting remains a significant open challenge where all methods (including SG) struggle, as the distributional shift makes forget data inherently detectable. The persistent trade-off between model utility and unlearning effectiveness, and the question of whether the game-theoretic framing generalizes to other privacy threats beyond MIA (e.g., model inversion, training data extraction), remain important directions for future work.

## Problem

Current GUI agents rely on text-based representations (HTML, accessibility trees) for perception and grounding, which are noisy, incomplete, and introduce significant latency and computational overhead. While a human-like embodiment—perceiving the GUI purely visually and performing pixel-level operations—is in principle sufficient, existing visual grounding models fail to meet the accuracy, cross-platform generalization, and flexibility requirements needed to make this approach viable in practice.

## Input / Output

UGround takes a GUI screenshot (supporting dynamic resolutions up to 1,344×1,344 landscape or 896×2,016 portrait via AnyRes) and a textual referring expression as input, and outputs absolute pixel coordinates in numerical form (e.g., "(1344 1344)") via autoregressive decoding, pointing to the center of the target element. In the SeeAct-V agent framework, the planner MLLM generates element descriptions (which may be visual, positional, or functional), and UGround maps those descriptions to coordinates on the current screenshot, which are then used for pixel-level actions like clicking or typing.

## Method

UGround is built on a 7B LLaVA-NeXT backbone with a frozen CLIP-ViT-L-14 (224px) image encoder and Vicuna-1.5-7b-16k language model, adapted for GUI grounding by scaling AnyRes to 36 ViT slices (enabling high-resolution input) and removing the low-resolution global context module found ineffective for GUIs. The key data contribution is a hybrid synthesis pipeline that orchestrates curated rules and LLMs (LLaVA-NeXT-13B for visual descriptions, Llama-3-8B for conciseness) to generate diverse referring expressions from HTML attributes and element images, producing 10M element-expression-coordinate triplets over 1.3M screenshots—90% from web data that generalizes to desktop and mobile. Training uses LoRA in two stages (LLaVA-1.5 pretraining, then GUI grounding) on 112 H100 GPUs. The SeeAct-V framework decouples planning (any MLLM) from grounding (UGround), enabling plug-and-play compatibility across planners and platforms without requiring HTML or a11y trees at inference time.

## Results

On ScreenSpot (Standard Setting), UGround achieves 73.3% average grounding accuracy across mobile, desktop, and web, outperforming SeeClick (53.4%), CogAgent (47.4%), GPT-4o (18.3%), and GPT-4 (16.2%) by up to 20% absolute. Under the more challenging Agent Setting (planner-generated referring expressions with GPT-4o), UGround reaches 81.4% average vs. SeeClick's 52.3%. On end-to-end agent benchmarks, SeeAct-V with UGround using only screenshots matches or exceeds SOTA agents that use additional HTML/a11y-tree input: 44.8% element accuracy on Multimodal-Mind2Web (vs. 42.3% for Choice), 31.1% action score on OmniACT (vs. 17.0% for DetACT), and 31.0% task success rate on AndroidWorld (vs. 30.6% for Choice).

## Baselines & Comparisons

UGround substantially outperforms SeeClick (Cheng et al., 2024), the prior SOTA GUI grounding model, by 19.9% absolute on ScreenSpot Standard Setting (73.3% vs. 53.4%) and by 29.1% on the Agent Setting (81.4% vs. 52.3% with GPT-4o planner), with the largest gaps on icons/widgets and desktop UIs. Against CogAgent (Hong et al., 2024), UGround leads by 25.9% on ScreenSpot Standard Setting, and CogAgent's 18B parameter size and 140M training samples are insufficient to close the gap. On agent benchmarks, SeeAct-V with UGround (vision-only input) beats DetACT (Kapoor et al., 2024) on OmniACT by 14.1 points in action score (31.1% vs. 17.0%) despite DetACT using OCR, icon matching, and color detection as additional inputs. On AndroidWorld, UGround with GPT-4 achieves 31.0% task success rate, edging out the text-only M3A Choice baseline (30.6%) and substantially exceeding the SoM variant (25.4%) from Rawles et al. (2024). On Mind2Web-Live, the vision-only agent achieves 50.7% completion rate vs. 44.3% for the text-only baseline from Pan et al. (2024), while on Multimodal-Mind2Web it surpasses both the Choice (42.3%) and SoM (25.6%) strategies from Zheng et al. (2024) at 44.8% element accuracy.

## Relation to Prior Work

This paper builds on the LLaVA-NeXT architecture and the SeeAct planning framework, but departs fundamentally from the dominant paradigm of GUI agents that rely on text-based representations (HTML, a11y trees) for both perception and grounding. Prior visual grounding models for GUIs (SeeClick, CogAgent) are limited in resolution, data diversity, and cross-platform scope; this work introduces a modular SeeAct-V framework that separates planning from a dedicated universal grounding model (UGround), trained on a 10M-element synthetic web dataset. The hybrid data synthesis pipeline (rules + MLLM-generated referring expressions) and the demonstration that web-only training data generalizes to desktop and mobile UIs represent a clear departure from prior approaches that required platform-specific data.

## Why It Matters / Open Questions

The paper provides strong empirical evidence that vision-only GUI agents can match or exceed state-of-the-art agents that use additional text-based inputs, challenging the field's assumption that HTML or a11y trees are necessary for robust GUI interaction. The released 10M-element dataset and UGround model offer a practical foundation for building pixel-level GUI agents, while the modular design enables independent improvement of planning and grounding components. Key open questions remain: handling long-tail icons with idiosyncratic semantics, improving data efficiency given web page redundancy, and the absence of desktop-specific training data that limits desktop performance. The work also highlights that planning errors (not grounding) are now the dominant failure mode, shifting the research focus toward better planning models.

## Problem

Existing neural theorem proving benchmarks (e.g., miniF2F, LeanDojo) evaluate models on standalone competition problems or theorems from libraries the model has already seen, failing to capture the context-dependent nature of real-world formalization where proofs rely on newly defined definitions, lemmas, comments, and file structure. State-of-the-art provers are trained on static (state, tactic) pairs and are therefore unaware of any context created after training, making it unclear whether they can function as assistants in ongoing proof development.

## Input / Output

The model receives a Lean theorem statement along with the preceding file contents (spanning up to ~65K tokens in the HTPI split, truncated to 1024 tokens for file-tuning) and optionally top-20 retrieved premises from imported modules. For file-tuning and state-tactic models, the output is a single next tactic generated iteratively via best-first search; for GPT-4o prompting, the output is a complete proof. The context includes not just the proof state but also definitions, lemma statements and proofs, natural language comments, imports, and variable declarations.

## Method

The paper introduces miniCTX, a benchmark of 762 theorems from six real Lean projects (PNT, PFR, Mathlib, HTPI, HEP, SciLean) with full preceding file context and rich metadata for dependency analysis, alongside NTP-TOOLKIT for automated extraction and a Lean REPL wrapper for evaluation. The key methodological contribution is file-tuning: fine-tuning DeepSeek-Coder-1.3b on (state, context, next-tactic) triples where context is the preceding file content, as opposed to the standard state-tactic paradigm that conditions only on the proof state. This is combined with a temporal split strategy to mitigate data contamination by ensuring evaluated theorems post-date model training. Experiments show file-tuning dramatically outperforms state-tactic tuning (35.94% vs. 19.53% on miniCTX-test), and that this gap is invisible on miniF2F, confirming that context-dependent proving is a distinct capability not captured by existing benchmarks.

## Results

On miniCTX-test, the file-tuned model (DeepSeek-Coder-1.3b fine-tuned with full file context) achieves 35.94% average proof rate, substantially outperforming the state-tactic tuned model (19.53%) and GPT-4o with context (27.08%). Providing preceding file context to GPT-4o more than doubles its performance (27.08% vs. 11.72% without context). On miniF2F-test, which does not require context, file-tuning offers only a marginal gain over state-tactic tuning (33.61% vs. 32.79%), confirming that the large gap on miniCTX is specifically due to context-dependent proving ability.

## Baselines & Comparisons

The paper compares file-tuning against four baselines: GPT-4o full-proof prompting, state-tactic prompting (Llemma-7b), state-tactic tuning (DeepSeek-Coder-1.3b), and GPT-4o with context. File-tuning wins decisively on miniCTX-test (35.94% avg) over state-tactic tuning (19.53%), a 16.4-point gap that reflects the model's ability to exploit in-file definitions, lemmas, and proof patterns. GPT-4o with context (27.08%) also substantially outperforms GPT-4o without context (11.72%), confirming that context is critical. However, on miniF2F-test (context-free competition problems), file-tuning (33.61%) barely exceeds state-tactic tuning (32.79%), demonstrating that existing benchmarks fail to capture context-dependent proving ability. Premise selection helps GPT-4o on high cross-file dependency splits (e.g., PFR_cross: 39.53% vs. 34.88%) but inconsistently helps the file-tuned model, even degrading performance on PFR_cross (16.28% vs. 44.19%), suggesting interference between retrieved premises and in-file context.

## Relation to Prior Work

This paper extends the state-tactic paradigm (Polu & Sutskever, 2020) by introducing file-tuning, which conditions tactic generation on preceding file contents rather than only the proof state. The data extraction pipeline builds directly on lean-training-data (Morrison, 2023), adding instruction-tuning formatting and a Lean REPL wrapper. Conceptually, the paper departs from prior benchmarks (miniF2F, LeanDojo, CoqGym) that either test standalone problems with no context or limit context to retrieved premises, by evaluating the full in-file context including definitions, lemmas, proofs, comments, and structural elements. Baldur (First et al., 2023) is the closest prior work, using 50 lines of preceding file content, but generates full proofs rather than next tactics and does not address temporal contamination.

## Why It Matters / Open Questions

The central finding—that file-tuned models achieve 35.94% vs. 19.53% for state-tactic on miniCTX, yet show only a 1-point gap on miniF2F—reveals that the standard benchmark is blind to context-dependent proving ability, which is essential for real-world use. Open challenges remain: handling long contexts beyond 1024 tokens, integrating cross-file premises without interfering with in-file context, and proving genuinely difficult theorems (PFR proofs remain at ~11%). The temporal-split design and NTP-TOOLKIT make the benchmark maintainable against data contamination, but the 1.3B-parameter baselines and single-language (Lean 4) scope limit generalizability of the methodological conclusions.

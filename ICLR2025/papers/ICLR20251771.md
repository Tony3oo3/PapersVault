## Problem

Large-scale LM evaluations (red-teaming, comprehensive benchmarks) are expensive and ill-suited for continuous monitoring after deployment or fine-tuning, yet even narrow modifications can inadvertently shift model behavior in safety-critical ways. The paper formalizes the behavioral shift auditing problem: given black-box API access to a baseline and a potentially modified model, how can one quickly and cheaply detect whether the model's behavior distribution has changed beyond an acceptable tolerance, while tightly controlling false positives?

## Input / Output

The test consumes a stream of text prompts fed to both a baseline model API and a current model API, with a behavior scoring function (e.g., Perspective API for toxicity, BLEU for translation) mapping each (prompt, generation) pair to a score in [0,1]. It produces a sequential binary decision—reject the null hypothesis of behavioral equivalence—along with a stopping time τ and an accumulating wealth process W_t. The user specifies a tolerance parameter ε (maximal neural net distance to accept) and a significance level α; the test is anytime-valid, meaning it can be stopped at any sample count without inflating the Type I error rate beyond α.

## Method

The paper extends Deep Anytime-Valid Testing (DAVT) from a point null to a composite null hypothesis H₀: D_Φ(P_B^M, P_B^M') ≤ ε, where D_Φ is a neural net distance defined as the supremum over a restricted class of bounded, scale-invariant functions φ. At each batch, a neural network φ_{t-1} (trained online via gradient ascent on all prior batches to maximize expected log-betting-score) produces a betting score S_t = ∏(1 + φ(b_t) − φ(b'_t))/exp(ε), which updates the wealth W_t = W_{t-1} × S_t. The test rejects H₀ when W_t ≥ 1/α. The key theoretical contribution is proving that S_t is an e-variable under H₀ (via the neural net distance definition and the boundedness/scale-invariance assumptions on φ), making W_t an e-process and guaranteeing Type I error ≤ α via Ville's inequality. Consistency (power one) is established under a mild condition on the learning algorithm's convergence rate, requiring the expected log-betting-score to grow faster than O(√(log t / t)).

## Results

The proposed anytime-valid auditing test detects behavioral shifts in LMs using only hundreds of prompts. In the exact test (ε=0), detection rates reach ~80% even for the closest corrupted checkpoints, while false positive rates remain consistently below the α=0.05 threshold across Llama3, Gemma, and Mistral. In the tolerance test (ε>0), all five instruction-tuned Llama3 variants are identified with 100% detection at conservative epsilon values, and the translation audit detects the Aya-23-8B vs. Llama3-8B difference in nearly all runs after only 100 samples. For larger models (Llama3-70B vs. Aya-23-35B), no significant difference is detected after 600 samples, suggesting the tolerance threshold set by few-shot prompting is appropriate for that scale.

## Baselines & Comparisons

The paper's only direct quantitative baseline is the repeated two-sample Kolmogorov-Smirnov test, applied at every batch as data accumulates. The proposed anytime-valid test maintains false positive rates at or below the nominal α=5% level (4.2% for Llama3, 0% for Mistral and Gemma), while the repeated KS test inflates to 8.3% for both Llama3 and Gemma — a clear violation of the target error rate. The paper also argues qualitatively that summary statistics (mean, standard deviation) are insufficient because distributions with identical moments can differ in safety-critical tails, and that classical distance measures (e.g., Wasserstein) lack a built-in decision rule with controlled error rates. The authors note that to their knowledge this is the first application of sequential hypothesis testing to behavioral shift detection, so no other direct statistical-testing baseline exists in the literature.

## Relation to Prior Work

This paper extends the Deep Anytime-Valid Testing (DAVT) framework of Pandeva et al. (2024) by generalizing from a point null hypothesis (distributions are identical) to a composite null with a configurable tolerance parameter ε, allowing small distributional shifts to go undetected. The construction relies on the testing-by-betting and e-process machinery from Ramdas et al. (2023), where a neural network produces betting scores that accumulate into a wealth process with non-asymptotic Type I error control via Ville's inequality. Conceptually, the paper departs from prior model-change detection approaches—formal verification (computationally intractable at scale) and watermarking (requires model-owner cooperation)—by requiring only black-box API access and a behavior scoring function, and it distinguishes itself from concept-drift and prompt-stability work by targeting distributional shifts in behavior scores rather than raw generation similarity.

## Why It Matters / Open Questions

As language models are continuously fine-tuned and redeployed, this work provides the first statistically principled, sample-efficient screening tool that can flag behavioral drift using only a few hundred prompts, with provable false-positive control at any stopping time. Key limitations include the dependence on an available (and reasonably accurate) behavior scoring function, the inability to detect highly isolated changes such as backdoors, and the open question of how to set per-behavior tolerance thresholds when monitoring multiple behaviors simultaneously. Future directions the authors highlight include active prompt selection for improved sample efficiency, multi-behavior testing with joint tolerance, and deeper theoretical analysis of the neural-net distance metric's relationship to established distributional divergences.

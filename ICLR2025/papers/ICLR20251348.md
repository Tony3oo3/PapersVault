## Problem

In zeroth-order online convex optimization, gradient estimates are obtained from costly function evaluations, and standard simultaneous perturbation methods require O(d) samples per round regardless of structure. When the objective's gradient is sparse—only a few dimensions matter—no existing OCO algorithm exploits this sparsity to reduce sample complexity. CONGO bridges this gap by bringing compressive sensing into the online setting, achieving dimension-independent regret with samples scaling only as O(s log(d/s)).

## Input / Output

At each of T rounds, the algorithm receives a d-dimensional control point x_t in a known compact convex set K, queries the unknown convex function f_t at x_t and at m perturbed points (m+1 total evaluations), and outputs an updated control x_{t+1} via projected gradient descent. The perturbation directions are rows of a randomly drawn m×d measurement matrix (Gaussian or Bernoulli), and the sparse gradient is recovered from the compressed measurements y = A∇f(x) + e using CoSaMP or basis pursuit. A hard norm bound on the recovered gradient is enforced; if violated, the estimate is replaced by zero to prevent catastrophic steps.

## Method

CONGO is a four-step framework: (i) draw a fresh random measurement matrix A each round, (ii) collect m+1 function evaluations via single-row SPSA perturbations (perturbing along each row a_i of A separately to avoid cross-row interference), (iii) recover the s-sparse gradient from y = A∇f(x) + e using CoSaMP (or basis pursuit for CONGO-B), and (iv) perform a projected gradient descent update. Three variants differ in matrix type and perturbation scheme: CONGO-B uses a Gaussian matrix with combined-row perturbations and averaging (inspired by Borkar et al.), CONGO-Z uses a Bernoulli matrix with single-row perturbations (inspired by ZORO), and CONGO-E uses a Gaussian matrix with single-row perturbations, which empirically outperforms both. The key theoretical result is an O(√T) expected regret bound with no dependence on d, requiring only O(s(log(d/s) + log T)) samples per round, proven by combining RIP-based recovery guarantees with a novel handling of the small probability that compressive sensing fails on any given round.

## Results

Theoretically, CONGO-Z and CONGO-E achieve the optimal O(√T) adversarial regret using only O(s(log(d/s) + log(2T))) function evaluations per round, compared to d+1 samples required by non-sparse methods. In numerical simulations (d=50 and d=100), CONGO-Z and CONGO-E match the performance of exact gradient descent (GD) even under N(0, 0.001) noise, while all CONGO variants outperform standard SPSA (GDSP). In the real-world DeathStarBench SocialNetwork microservice deployment, CONGO-E reduces cumulative cost by approximately 45% on average for fixed-workload and variable-job-type scenarios, and 20% for variable-arrival-rate scenarios, approaching the performance of a PPO-pretrained RL baseline within roughly two hours.

## Baselines & Comparisons

CONGO-E consistently outperforms the SGDSP baseline (standard SPSA-based gradient descent) across all three evaluation settings—numerical simulations, Jackson network simulations, and the real-world microservice benchmark—with the advantage growing as dimensionality and sparsity increase. Against NSGD (naive per-dimension gradient estimation requiring d+1 samples per round), CONGO-E achieves lower cumulative cost despite using far fewer samples (m+1 vs. d+1), demonstrating the benefit of compressive sensing over naive approaches. In the 50-queue Jackson network, CONGO-B degrades to SGDSP-level performance due to measurement interference, while CONGO-E maintains its advantage. In the microservice benchmark, CONGO-E approaches the PPO pretrained RL baseline, reducing cost by ~45% (fixed workload) and ~20% (variable arrival rate) within two hours, whereas SGDSP and NSGD remain significantly worse. CONGO-E also outperforms CONGO-Z in most practical settings, attributed to the Gaussian measurement matrix providing better sparse recovery than the Bernoulli matrix used by CONGO-Z for the same number of measurements.

## Relation to Prior Work

This paper extends the line of work combining simultaneous perturbation stochastic approximation (SPSA) with compressive sensing for gradient estimation—previously applied only to stochastic optimization with a fixed objective (Borkar et al., 2018; Cai et al., 2022)—into the adversarial online convex optimization setting where the objective changes each round. The key conceptual departure is handling the non-negligible probability that compressive sensing recovery fails on any given round, which requires a different proof technique (law of total expectation over the failure event) than the high-probability sample complexity bounds used in the stochastic setting. The paper also introduces CONGO-E, a new variant using Gaussian measurement matrices with single-row perturbations, which outperforms both the Borkar-style combined-row approach (CONGO-B) and the ZORO-style Bernoulli approach (CONGO-Z) empirically.

## Why It Matters / Open Questions

This is the first framework to achieve dimension-independent O(√T) regret in zeroth-order OCO using only O(s log(d/s)) function evaluations per round, compared to d+1 for standard SPSA-based methods—a meaningful sample-efficiency gain in high-dimensional resource allocation problems. The practical validation on DeathStarBench microservice autoscaling demonstrates that CONGO-E can approach the performance of a pre-trained PPO policy without any offline training, which is significant for systems where retraining is infeasible. Key limitations include the assumption of exactly sparse gradients (though near-sparsity works empirically), the need for known bounds on Lipschitz and smoothness constants, and the stability assumption for queueing systems. Open questions include how the method behaves when the sparsity pattern shifts adversarially across rounds and whether the logarithmic T-dependence in m can be eliminated in practice without performance degradation.

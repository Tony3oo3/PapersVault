## Problem

Single-agent controlled decoding for LLM alignment struggles to generalize across diverse or conflicting task requirements, as each aligned model overfits to its training reward distribution. Existing multi-LLM integration methods rely on weak supervision, fixed mixing formulas, or expert-guided logit combination, lacking a principled mechanism for dynamic token-level model selection. The paper asks: how can off-the-shelf aligned LLMs be optimally combined during inference—without retraining—to target an arbitrary new reward function through adaptive, token-level collaboration?

## Input / Output

The method takes a text prompt, a pool of K off-the-shelf aligned LLM policies (each with a latent, unobservable reward function), and a target reward function (which can be a personalized preference, rule-based constraint, supervised signal, or open-source reward model). At each decoding step, the algorithm samples top-p tokens (p=10) from every agent conditioned on the current state, evaluates them against the target reward, and emits a single next token. The output is a complete aligned text response generated sequentially, with the identity of the contributing agent switching dynamically at the token or phrase level.

## Method

COLLAB frames multi-agent decoding as a KL-regularized RL problem constrained to a feasible set of pre-trained policies Π, where the optimal policy at each token is selected by maximizing an implicit Q-function J_target^{π_j}(s_t, z) = Q_target^{π_j}(s_t, z) − α·KL(π_j(·|s_t) ‖ π_ref(·|s_t)) over both the agent index j and the candidate token z. This policy-switching mechanism means that at every state, the algorithm identifies which off-the-shelf agent best predicts the long-term target reward for each candidate token, then commits to the globally optimal (agent, token) pair. The theoretical analysis provides a sub-optimality bound showing the performance gap is upper-bounded by the minimum reward difference δ_{*j} between the target reward and the closest agent's reward, plus token-level and trajectory-level KL divergence terms—guaranteeing COLLAB outperforms the best single agent in the pool. The approach is entirely training-free, requiring no parameter updates or access to the agents' internal reward functions.

## Results

COLLAB achieves up to 1.56× improvement in average reward over single-agent SoTA decoding baselines across all 7 evaluation setups (4 on Berkeley Nectar, 3 on HH-RLHF). In GPT-4-based pairwise evaluation, COLLAB attains a peak win-tie rate of 71.89% against Agent-I (Evaluation-2) and 73.75% against BoN Sampling (Evaluation-6), consistently exceeding 50% across all comparisons. The method also outperforms baselines on diversity (lower n-gram repetition) and coherence (higher SimCSE cosine similarity) metrics, confirming that token-level agent switching improves both quality and variety of generated responses.

## Baselines & Comparisons

COLLAB is compared against two baseline families: (1) single-agent SoTA decoding via Transfer Q* (Chakraborty et al., 2024b), where each individual LLM (Agent-I or Agent-II) is decoded independently using the KL-regularized Q-function approach, and (2) Best-of-N (BoN) Sampling (Nakano et al., 2021), which performs vanilla logit-based sampling from individual agents and selects the best response by target reward. COLLAB wins against both baselines in all 7 evaluation setups on GPT-4 win-tie rate, with margins ranging from ~50% (Eval-5 vs. BoN) to ~74% (Eval-6 vs. BoN). Against the single-agent Transfer Q* baselines, COLLAB's advantage is most pronounced when the two agents are diverse (e.g., Zephyr-7B vs. Starling-7B in Eval-1/2), while the gap narrows when agents are less diverse (e.g., Zephyr-7B-α vs. Zephyr-7B-β in Eval-2). The ablation in Figure 4 further confirms that switching between non-diverse agents yields poor performance, validating that the gains come from genuine multi-agent complementarity rather than mere ensemble averaging.

## Relation to Prior Work

This paper extends the controlled decoding framework (Mudgal et al., 2024; Chakraborty et al., 2024b), which formulates LLM alignment as a KL-regularized RL problem solvable via Q-function estimation at each token, from the single-agent setting to a mixture-of-agents setting. Where prior multi-LLM integration methods (Shen et al., 2024; Jin et al., 2024; Yang & Klein, 2021) rely on fixed mixing formulas or weak supervision to combine model outputs, COLLAB introduces a principled token-level policy-switching mechanism guided by an implicit Q-function that dynamically selects the best agent at each decoding step. The key conceptual departure is treating the selection among pre-aligned policies as a constrained optimization over a feasible set Π rather than a free policy search, yielding a tractable greedy switching rule with a provable sub-optimality bound.

## Why It Matters / Open Questions

COLLAB offers a training-free, inference-time mechanism to combine multiple off-the-shelf aligned LLMs toward an arbitrary target reward, which is practically valuable in settings where retraining billions of parameters is infeasible or model access is restricted. The sub-optimality bound (Theorem 1) provides a clear diagnostic: performance degrades gracefully with the reward gap to the closest agent and the KL divergence from the reference policy, giving practitioners a principled way to reason about when the approach will succeed. Key limitations include the reliance on approximate Q-function estimation, the greedy switching being a proxy for intractable dynamic programming, and the requirement that at least one agent in the pool is reasonably close to the target reward. Open questions include scaling to many agents efficiently, handling adversarially chosen target rewards far from all available agents, and whether the token-level switching granularity is optimal versus phrase- or sentence-level coordination.

## Problem

Existing equivariant neural networks assume strict symmetry in data, but real-world objects exhibit Rotational Symmetry-Breaking where features deviate from ideal symmetric configurations due to physical perturbations. By Curie's principle, strict equivariant functions cannot map higher-symmetry inputs to lower-symmetry outputs, making them unable to model this asymmetry. This paper addresses the gap by introducing Relaxed Rotation-Equivariance (RRE) specifically for 2D object detection, where no prior work had explored rotational symmetry-breaking.

## Input / Output

The method takes standard RGB images (640×640 for detection, 32×32 for CIFAR classification) and produces anchor-free bounding boxes with class labels via a v8Detector Head, or segmentation masks when swapped to a v8Segment Head. Unusually, the input is first lifted onto a relaxed rotation-equivariant group R_n (a perturbed C_n) in the first layer, so all intermediate feature maps carry n group channels representing relaxed rotational views. The learnable perturbation Δ (4n parameters per layer) is the only additional trainable component beyond standard convolution weights.

## Method

The core contribution is R2GConv, which relaxes strict C_n rotation-equivariant convolution by adding a learnable perturbation matrix Δ ∈ R^{n×2×2} (initialized from U(-b,b), b=0.1) to each rotation matrix, defining a new relaxed group R_n. The R2EFilter constructs n perturbed filters via affine grid sampling with the modified matrices, requiring only 4n extra parameters per layer. R2Net uses a Lifting R2GConv (stride-2) in the first layer followed by four stages of Efficient R2GConv (point-wise + depth-wise composition) with Res2Net-inspired channel splitting in R2Net Blocks. R2Det wraps R2Net with an FPN+PAN neck, R2SPPF, Transfer Blocks for channel reduction, and an anchor-free v8Detector Head. The paper proves R2GConv satisfies approximate equivariance (ε-bounded deviation from strict equivariance) and shows that small initial perturbation (b=0.1) outperforms both zero and large perturbations, as the end-to-end training adapts Δ to the dataset's actual symmetry-breaking degree.

## Results

On COCO validation, R2Det-M(C4) achieves 53.1% AP50:95 and 70.3% AP50 with only 22.6M parameters and 17.3G FLOPs, outperforming YOLOv8-M (50.2% AP50:95, 25.9M params) by 5.8% in AP50:95 while using 12.7% fewer parameters. On PASCAL VOC test, R2Det-M(C4) reaches 87.3% AP50, surpassing YOLOv8-L (86.4%) with only one-third of its parameters (22.6M vs. 43.6M). For image classification, R2Net-M(C4) achieves 97.3% top-1 on CIFAR-10 and 82.7% on CIFAR-100 with just 6.0M parameters, matching or exceeding DenseNet-BC (25.6M) and ResNeXt-29 (68.1M).

## Baselines & Comparisons

Against YOLOv8 (Jocher et al.), R2Det wins across all three size variants on COCO: R2Det-N/S/M achieve 43.7/50.0/53.1% AP50:95 versus YOLOv8-N/S/M's 37.3/44.9/50.2%, while using 12.5–14.3% fewer parameters and substantially lower FLOPs (e.g., R2Det-M: 17.3G vs. 78.9G). Against YOLOv9 (Wang et al., 2024b), R2Det-N/S/M outperform YOLOv9-T/S/M by 14.1/6.8/3.3% in AP50:95 respectively, and R2Det-M (53.1%) edges out YOLOv9-C (53.0%) with fewer parameters. Against YOLOv10 (Wang et al., 2024a), R2Det-N/S/M surpass YOLOv10-N/S/M by 13.5/8.0/3.9% in AP50:95, and R2Det-M (53.1%) matches YOLOv10-L (53.2%) with 22.6M vs. 24.4M parameters and far fewer FLOPs (17.3G vs. 120.3G). For classification, R2Net-M(C4) achieves 97.3% on CIFAR-10, beating WideResNet (95.8%, 36.5M), ResNeXt-29 (96.4%, 68.1M), and DenseNet-BC (96.5%, 25.6M) with only 6.0M parameters; on CIFAR-100, R2Net-M(C4) (82.7%) ties ResNeXt-29 (82.7%) and DenseNet-BC (82.8%) while using 8.8% and 23.4% of their parameters respectively.

## Relation to Prior Work

This paper extends the Group Equivariant Convolution (GConv) framework of Cohen & Welling (2016) by relaxing the strict cyclic rotation group C_n into a learnable Relaxed Rotation-Equivariant group R_n, drawing on the theoretical foundations of relaxed equivariance from Kaba & Ravanbakhsh (2023) and approximately equivariant networks from Wang et al. (2022a). Unlike prior relaxed equivariance work that focused on MLPs, graphs, or physics simulations, this is the first application of structured relaxation specifically to 2D object detection, building on ReDet (Han et al., 2021) and the YOLOv8 architecture. The key conceptual departure is that the relaxation is implemented as a minimal learnable perturbation (Δ) added to the group's affine matrices, rather than through weight-sharing relaxation or input noise, preserving the equivariant structure while allowing the network to adapt to real-world symmetry breaking.

## Why It Matters / Open Questions

The paper addresses a practical gap: strict equivariant networks assume ideal symmetry that real-world objects rarely exhibit, and this mismatch degrades detection performance under perturbations. The extremely lightweight nature (only 4n additional parameters per layer) and plug-and-play compatibility with existing architectures like YOLOv8 make this approach broadly applicable without significant engineering overhead. Open questions include whether the additive perturbation is the optimal relaxation mechanism (multiplicative or learned nonlinear transforms are mentioned but not explored), whether the approach generalizes to non-cyclic groups or 3D rotation, and whether the learned Δ values have interpretable physical meaning across different object categories. The negative result showing that unstructured noise on vanilla convolutions degrades performance reinforces that the relaxation must be embedded within the equivariant structure to be effective.

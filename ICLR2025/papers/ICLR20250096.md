## Problem

Existing intermediate collaborative perception methods rely on dense BEV feature maps as message units, which suffer from object feature destruction during channel compression or spatial selection, quadratic computational complexity that scales with perception range during aggregation, and implicit structure representation that loses 3D geometric details needed for precise boundary regression. The paper argues that a good message unit should explicitly decouple low-level structural information from high-level semantic information in a sparse format, a property absent in all prior approaches.

## Input / Output

Each agent takes raw LiDAR point clouds within a perception range of approximately 280m × 80m × 4m (V2XSet) along with its 6DoF pose as input. The transmitted message per agent is a set of point clusters, each containing a sparse set of 3D point coordinates (structure), a single cluster center (position), a 128-dim cluster feature (semantics), and a proposal bounding box; bandwidth is controlled by the number of retained points per cluster rather than feature channel compression. The final output is a set of 3D bounding boxes (center, dimensions, yaw, confidence) for the ego agent, evaluated at IoU thresholds of 0.5 and 0.7.

## Method

CPPC introduces the point cluster as a new collaborative message unit and builds a three-module pipeline: (1) a Point Cluster Encoder (PCE) using a sparse voxel backbone plus stacked SIR layers that segments foreground points, groups them into clusters by predicted center proximity, and extracts decoupled point coordinates and cluster features; (2) a Point Cluster Packing (PCP) module that generates proposal bounding boxes to filter background clusters and applies Semantic and Distribution guided Farthest Point Sampling (SD-FPS) to compress each cluster to a few key points while preserving geometric structure; (3) a Point Cluster Aggregation (PCA) module that matches clusters from different agents by center distance and merges them via set union of points, averaging of centers/features, and confidence-based box selection, achieving linear complexity in the number of objects rather than quadratic in range. For robustness, CPPC employs parameter-free pose correction by formulating cluster centers as graph vertices and minimizing pose consistency error, and latency compensation by estimating object speed from temporally matched cluster centers to extrapolate positions to the current timestamp.

## Results

On the three collaborative perception benchmarks, CPPC achieves AP@0.7 of 89.55 (V2XSet), 93.1 (OPV2V), and 69.39 (DAIR-V2X-C), setting new state-of-the-art on all three. The headline gains on the strict AP@0.7 metric are 5.7% over OPV2V on V2XSet, 7.3% over CoAlign on OPV2V, and 12.8% over V2X-ViT on DAIR-V2X-C. In the fine-grained evaluation (Table 2), CPPC also leads on all three sub-metrics: AP_SP-O (40.13), AP_CP (82.63), and AP_SP-E (76.72) on DAIR-V2X-C.

## Baselines & Comparisons

CPPC outperforms all six baselines on every benchmark where they are directly comparable. Against the strongest per-dataset baselines, the AP@0.7 margins are: +4.8 pts over OPV2V (84.75) on V2XSet, +6.3 pts over CoAlign (86.8) on OPV2V, and +7.9 pts over V2X-ViT (61.50) on DAIR-V2X-C. On V2XSet, CPPC also beats DiscoNet (83.81) by 5.7 pts and V2X-ViT (79.02) by 10.5 pts on AP@0.7. On DAIR-V2X-C, the gap over the next-best method (V2X-ViT at 61.50) is the largest at 7.9 pts, while CoAlign (60.40) and Where2comm (60.36) trail by roughly 9 pts. The fine-grained sub-metric evaluation (Table 2) further confirms CPPC's advantage: it leads Where2comm and V2X-ViT by 1.6–7.7 pts across AP_SP-O, AP_CP, and AP_SP-E, with the largest gain (7.69 pts) on AP_CP, indicating that the point-cluster message unit is particularly effective for objects that require multi-agent information fusion.

## Relation to Prior Work

This paper departs from the dominant BEV-map-based intermediate collaboration paradigm (V2X-ViT, Where2comm, CoBEVT, OPV2V) by proposing a fundamentally different message unit: the point cluster, which explicitly decouples low-level geometric structure (point coordinates) from high-level semantics (cluster features). It repurposes sparse point cloud detection machinery (SIR, sparse voxel backbones, proposal generation) as the encoding backbone and borrows graph-optimization ideas from CoAlign for pose correction, but applies them to cluster centers rather than detection outputs. The SD-FPS sampling strategy extends classic Farthest Point Sampling with semantic and density scores, and the set-matching aggregation replaces the quadratic-cost BEV alignment with a linear-in-objects merging procedure.

## Why It Matters / Open Questions

The parameter-free robustness to pose error and time latency (no finetuning required across noise levels) is a practical advantage over prior methods like V2X-ViT and Where2comm that must be retrained per noise setting, making CPPC more deployable in real V2X systems. The finding that only 16 feature channels suffice (vs. 128 in prior work) without significant performance loss validates the structure-semantics decoupling and suggests the field has been over-parameterizing collaborative messages. Open questions include whether the hand-tuned matching thresholds (ε_point, ε_agg, ε_pose) can be learned or adapted automatically for new environments, and whether the approach extends naturally to temporal tasks like tracking and forecasting, which the authors acknowledge as future work.

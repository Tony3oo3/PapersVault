## Problem

Existing FedRL algorithms learn a single shared policy across all agents, which performs poorly when local environments are heterogeneous. While shared representations have been theoretically analyzed for personalized supervised federated learning, no convergence guarantees exist for personalized FedRL under Markovian noise — in particular, whether shared representations can simultaneously enable per-agent personalization and an N-fold linear convergence speedup in the non-i.i.d. RL setting remains open.
![Teaser figure](../imgs/ICLR20252265/cropped_page4_idx0.webp)

## Input / Output

Each agent i interacts with its own MDP, producing Markovian (non-i.i.d.) trajectories of (state, reward, next-state) tuples under a fixed sampling policy π^i; no raw trajectories are shared between agents. The method outputs a shared feature representation matrix Φ ∈ R^{|S|×d} (maintained by the server via averaging) and agent-specific weight vectors θ^i ∈ R^d, so that each agent's value function is personalized as V^i(s) ≈ Φ(s)θ^i. The two parameters are updated at different rates: θ^i undergoes K local gradient steps per round while Φ receives a single averaged update, creating an inherent two-timescale structure.

## Method

PFEDRL-REP alternates three steps per communication round: (1) each agent performs K local TD gradient steps on θ^i with Φ_t held fixed; (2) each agent takes one gradient step on Φ using the updated θ^i; (3) the server averages all local Φ updates to form Φ_{t+1}. The core theoretical insight is that the coupled (θ^i, Φ) dynamics constitute a federated nonlinear two-timescale stochastic approximation (2TSA) with Markovian noise, with θ^i on a faster timescale (α_t ∝ (t+2)^{-5/6}) and Φ on a slower one (β_t ∝ (t+2)^{-1}). A weighted Lyapunov function coupling the fast and slow iterates, combined with a Lyapunov drift argument that exploits the mixing time of each agent's Markov chain, yields the convergence rate Õ(N^{-2/3}(T+2)^{-2/3}) — the first proof of linear speedup in N for PFEDRL with shared representations under Markovian noise. A norm-scaling (clipping) step on θ^i is essential for finite-time stability, and the framework extends to control via PFEDDQN-REP, where a periodically updated target network stabilizes both the shared representation and personalized Q-value updates.

## Results

The main theoretical result is a convergence rate of Õ(N^{-2/3}(T+2)^{-2/3}) for PFEDTD-REP, implying a linear speedup in the number of agents N (i.e., T = O(N^{-1}ε^{-3/2}) steps to reach ε-accuracy). Empirically, on CliffWalking with 3 agents, PFEDTD-REP converges in ~50 episodes for agent 1 versus 150+ episodes for independent TD, while also achieving values closer to the per-agent ground truth than non-personalized FedTD. On CartPole with 10 heterogeneous agents (pole lengths 0.38–0.74), PFEDDQN-REP obtains larger cumulative reward than all non-personalized baselines and reaches maximal return faster than existing personalized methods (PerDQNAvg, FedAsynQ-ImAvg), while also generalizing quickly to a previously unseen environment.

## Baselines & Comparisons

On CliffWalking (3 agents, 4×12 grid), PFEDTD-REP outperforms both independent TD and non-personalized FedTD (Khodadadian et al., 2022; Dal Fabbro et al., 2023): it converges ~3× faster than independent TD (50 vs. 150+ episodes) and produces per-agent value estimates much closer to the ground truth, whereas FedTD forces all agents to converge to a uniform (non-personalized) value function. On CartPole (10 agents with heterogeneous pole lengths), PFEDDQN-REP achieves higher cumulative reward than all non-personalized federated baselines—conventional DQN (Mnih et al., 2015), FedDQN, FedQ-K (Khodadadian et al., 2022), and LFRL (Liu et al., 2019)—and reaches maximal return faster than the two personalized baselines PerDQNAvg (Jin et al., 2022) and FedAsynQ-ImAvg (Woo et al., 2023). Similar qualitative advantages are observed on Acrobot. Additionally, PFEDDQN-REP demonstrates superior generalization to a new, previously unobserved environment compared to all baselines, a property attributed to the learned shared representation. The paper does not report exact numerical reward values; all empirical comparisons are presented as learning-curve figures (Figures 2–3) with qualitative descriptions of relative performance.

## Relation to Prior Work

This paper extends the shared-representation paradigm from supervised federated learning (Collins et al., 2021) into the reinforcement learning setting, where data is inherently non-i.i.d. and generated by Markovian trajectories. The convergence analysis is built on the nonlinear two-timescale stochastic approximation (2TSA) framework of Doan (2020, 2021), adapted here to handle Markovian noise via a Lyapunov drift approach inspired by Srikant & Ying (2019). Unlike prior FedRL works (Khodadadian et al., 2022; Dal Fabbro et al., 2023; Wang et al., 2023a) that learn a single shared policy, PFEDRL-REP simultaneously learns a global shared feature representation and agent-specific weight vectors, positioning it at the intersection of personalized FL and federated RL.

## Why It Matters / Open Questions

This is the first proof of linear convergence speedup (N^{-1} factor) for personalized FedRL with shared representations under Markovian noise, providing a theoretical justification for the empirical observation that federated RL converges faster with more agents. The framework is broadly applicable (value-based, policy-based, linear or deep representations), but the theoretical guarantees are currently limited to linear representations in the policy evaluation setting; extending the analysis to control problems (Q-learning, DQN) and non-linear representations remains an open problem. The empirical validation, while consistent with theory, is conducted on small-scale environments (CliffWalking, CartPole, Acrobot) with few agents, leaving open questions about scalability to larger, more complex federated RL deployments.

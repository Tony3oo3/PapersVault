## Problem

Existing benchmarks for evaluating autonomous UI agents are either static (fixed test sets with no parameterization), restricted to desktop platforms, or rely on unreliable reward signals (LLM judges, action matching). There is no comprehensive mobile benchmark that provides ground-truth reward signals across diverse real-world apps while supporting unlimited task variations through dynamic parameterization.

## Input / Output

The agent receives a natural language task instruction, a full-resolution screenshot (2400×1080×3 RGB), and a processed list of UI elements extracted from the Android accessibility tree (text, content description, bounding boxes, state flags). Optionally, a Set-of-Mark annotated screenshot with numeric labels on bounding boxes is provided for multimodal grounding. Actions are emitted as JSON objects specifying action type (click, scroll, input_text, navigate_home/back, long_press, open_app, etc.) with coordinates or text parameters; information-retrieval tasks additionally require a free-text answer. Rewards are computed non-invasively by inspecting device system state (SQLite databases, file system, OS settings) via ADB, with composite tasks yielding partial credit per subtask.

## Method

ANDROIDWORLD is a fully functional Android 13 (Pixel 6 emulator) environment containing 116 programmatically defined tasks across 20 real apps, where each task is dynamically instantiated with randomly generated parameters (controlled by a seed) and validated through hermetic initialization, system-state inspection, and teardown logic. The key mechanism for durable rewards is leveraging Android's own state management—querying app SQLite databases, checking file existence, and reading OS settings via ADB—rather than matching superficial UI changes, enabling the same validation primitives to be reused across unrelated apps. The M3A agent is a zero-shot multimodal LLM agent that integrates ReAct-style action generation with Reflexion-style post-action reflection, consuming either the accessibility tree (text-only) or a SoM-annotated screenshot plus UI element list, and producing JSON actions with reasoning. A simplified variant (M3A-Simple) omits guidelines and reflection to isolate the contribution of advanced prompting. The environment also integrates 92 MobileMiniWoB++ tasks via a WebView app, adapting HTML5 widgets to native Android UI components.

## Results

The best agent, M3A with GPT-4 Turbo using the accessibility tree, achieves a 30.6% success rate on ANDROIDWORLD (116 tasks across 20 apps) and 59.7% on MobileMiniWoB++ (62 tasks), compared to a human success rate of 80.0% and 100.0% respectively. The SoM (Set-of-Mark) multimodal variant of M3A with GPT-4 Turbo scores 25.4% on ANDROIDWORLD but 67.7% on MobileMiniWoB++, indicating that visual grounding helps more on synthetic web tasks with incomplete accessibility trees. The simplified M3A-Simple variant (without ReAct/Reflexion prompting) drops to 19.8% on ANDROIDWORLD, confirming that structured reasoning and reflection are critical for complex mobile interactions.

## Baselines & Comparisons

The paper's primary baseline is SeeAct (Zheng et al., 2024a), a web-navigation agent adapted for Android by augmenting its action space with mobile-specific gestures and replacing the DOM with the accessibility tree. M3A with GPT-4 Turbo (text-only) substantially outperforms SeeAct on ANDROIDWORLD, achieving 30.6% versus 15.5% success rate — a 15.1-point gap that reflects M3A's ReAct/Reflexion prompting and reflection mechanisms. On MobileMiniWoB++, the comparison is closer: SeeAct achieves 66.1% while M3A text-only scores 59.7%, but M3A's SoM variant reaches 67.7%, slightly surpassing SeeAct. The authors attribute SeeAct's weaker Android performance to its optimization for web environments, its inability to handle mobile-specific actions like long-presses and swipes effectively, and its lack of outcome memory, which leads to repetitive ineffective behaviors such as endless scrolling. Overall, M3A wins on the primary ANDROIDWORLD benchmark by a wide margin, while the two methods are roughly competitive on the simpler MobileMiniWoB++ suite.

## Relation to Prior Work

ANDROIDWORLD extends the interactive evaluation paradigm established by desktop benchmarks like OSWorld and WindowsAgentArena to the mobile domain, while drawing on MiniWoB++'s concept of unlimited task parameterization and AndroidEnv's emulator management infrastructure. It departs from AndroidEnv's reward mechanism (which requires modifying app source code) by using non-invasive system-state inspection via ADB, enabling coverage of apps whose source is unavailable. The M3A agent builds on ReAct and Reflexion prompting strategies combined with Set-of-Mark visual grounding, positioning it within the current LLM-based agent design space rather than introducing a new architectural paradigm.

## Why It Matters / Open Questions

The 30.6% best-agent success rate versus 80% human performance highlights a substantial gap, but the more important contribution is methodological: dynamic task parameterization enables robustness evaluation that static benchmarks fundamentally cannot support, revealing that single-seed results can be misleading. The finding that multimodal (SoM) input does not consistently outperform text-only accessibility trees on native Android apps challenges the assumption that visual information is always beneficial. Open questions include whether the gap will close with better models, how to build truly cross-platform agents (the adapted web agent underperforms), and whether the dynamic environment can support online/RL learning as the authors suggest.

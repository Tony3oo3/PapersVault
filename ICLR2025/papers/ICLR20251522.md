## Problem

Prior work on LLM values has examined value rankings and individual value expressions, but has not investigated whether LLMs produce internally coherent value correlation structures within a single session—i.e., whether an LLM's responses reflect a psychologically consistent 'persona' whose values align and conflict in the same circumplex pattern observed across human populations. This paper asks whether standard prompting yields such consistency and, if not, what prompting strategy can elicit it.

## Input / Output

Each experimental run presents all 57 PVQ-RR items in a single prompt alongside one of five persona-conditioning instructions (Basic, Value Anchor, Demographic, Generated Persona, or Names), and the model returns 57 integer scores on a 1–6 Likert scale. These are averaged into 19 value scores (3 items per value), centered within each session, and used to build a 19×19 Pearson correlation matrix across the 300 sessions per condition. The correlation matrix is then embedded into R² via MDS and compared to the human benchmark (Schwartz & Cieciuch, 2022; 53,472 participants, 49 cultural groups) using Procrustes alignment and sum-of-squared-differences as the fit metric.

## Method

The paper's core contribution is the Value Anchoring prompt, which appends 'Answer as a person that is [value]' using a single item from the Best-Worst Refined Values scale (Lee et al., 2019), thereby conditioning the model on one value without explicitly specifying scores for the other 18. Evaluation proceeds at two levels: first-order statistics via Spearman rank correlation between LLM value rankings and the universal human hierarchy, and second-order statistics via MDS of the inter-value correlation matrix compared to the human circular embedding through Procrustes analysis. Across six models (GPT-4-0314, Gemini 1.0 Pro, Llama 3.1 8B/70B, Gemma 2 9B/27B) and two temperatures (0.0, 0.7), Value Anchoring consistently yields the lowest Procrustes sum-of-squared-differences (0.10–0.23) versus 0.12–0.82 for other prompts. A mechanistic analysis shows that anchoring to a value produces a sinusoidal scoring pattern around the 19-value circle—neighboring values receive elevated scores while opposite values receive suppressed scores—explaining why the resulting correlation structure mirrors the human circumplex.

## Results

The Value Anchor prompt consistently produces the lowest sum of squared differences (SSD) between LLM and human MDS value-correlation embeddings across all six models, with values ranging from 0.10 (Llama 3.1 70B, Gemma 2 9B) to 0.23 (GPT-4-0314) at temperature 0.0, compared to 0.42–0.92 for the Basic prompt. The Value Anchor prompt achieves correlation coefficients of r = 0.87–0.95 (p < .001) with human value structures. For value rankings, Spearman rank correlations between LLM and human hierarchies exceed 0.8 for most model–prompt combinations, with the Value Anchor prompt yielding correlations of 0.75–0.85.

## Baselines & Comparisons

The paper compares Value Anchoring against three prompting baselines: Names (Aher et al., 2023), Demographic (Argyle et al., 2023), and Generated Persona (Cheng et al., 2023). Value Anchor decisively outperforms the Names prompt across nearly all models, e.g., achieving SSD of 0.11 vs. 0.71 for Gemini 1.0 Pro (temp 0.0) and 0.10 vs. 0.45 for Llama 3.1 70B. Against the Demographic prompt, Value Anchor wins in most settings (e.g., 0.11 vs. 0.42 for Gemini, 0.10 vs. 0.29 for Llama 70B), though Gemma 2 27B at temp 0.7 is a narrow exception (0.17 vs. 0.15). Against the Generated Persona prompt, Value Anchor is superior in all but one case (GPT-4-0314 at temp 0.7, where both achieve 0.22). Overall, Value Anchor achieves the best or near-best MDS alignment in 11 of 12 model–temperature conditions, confirming that anchoring to a single value produces more human-consistent inter-value correlations than demographic, name-based, or free-form persona prompting.

## Relation to Prior Work

This paper extends the growing line of work on LLM value evaluation (Fischer et al., 2023; Lindahl and Saeid, 2023) and persona elicitation via prompting (Aher et al., 2023; Argyle et al., 2023; Cheng et al., 2023) by shifting focus from first-order statistics (value rankings) to second-order statistics (inter-value correlation structure) within a single session. It draws on the well-established Schwartz Theory of Basic Human Values as a theoretical benchmark, using the PVQ-RR questionnaire and MDS/Procrustes analysis to quantify whether LLM personas exhibit the circular value correlation pattern robustly observed across human populations. The novel Value Anchoring prompt is positioned as a minimal-intervention alternative to the more elaborate demographic or persona-description prompts used in prior work.

## Why It Matters / Open Questions

The paper provides a quantitative, theory-grounded framework for evaluating persona coherence in LLMs that goes beyond surface-level consistency checks, and demonstrates that a simple one-value instruction can elicit the full 19-value correlation structure. This opens a path for using LLMs to simulate diverse value orientations at scale for psychological research (hypothesis testing, instrument refinement). Key open questions include whether the observed value structure emerges from pre-training, fine-tuning, or RLHF; whether the framework generalizes to other personality dimensions beyond values; and how training data biases might differentially affect value expression across demographic groups.

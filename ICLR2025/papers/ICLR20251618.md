## Problem

Static reasoning benchmarks for LLMs suffer from short shelf-lives as models improve, make it difficult to isolate whether failures stem from memory recall versus logical deduction, and lack the flexibility to recreate cognitive science experiments (e.g., ordering effects, congruency, symbolic distance) on language models. ReCogLab addresses this by replacing fixed datasets with a generative framework that can dynamically control problem difficulty, context length, and specific cognitive parameters to probe relational reasoning in LLMs.

## Input / Output

The framework consumes a YAML-style configuration file specifying the task domain (Comparison, Social Networks, Syllogisms, JSON Families), graph topology (linear chain or random tree), number of entities, ordering strategy, congruence setting, flavor text toggle, and other parameters, along with a Jax PRNG seed for deterministic reproducibility. It outputs a dataset of relational reasoning examples, each consisting of a natural-language context C (a set of factual statements encoding graph edges between named entities), a question Q requiring multi-hop integration across the context, and ground-truth answer(s) A. The same configuration with a different seed produces a statistically equivalent but textually distinct dataset, enabling leak-resistant re-evaluation.

## Method

ReCogLab procedurally generates relational reasoning problems by first constructing a graph structure (directed acyclic graph for comparisons/syllogisms, undirected graph for social networks, nested document graph for JSON Families) using NetworkX, then mapping each edge to a natural-language statement via task-specific templates that sample entity names and relationship phrasings. A key design choice is that virtually every aspect of the generating process—symbolic distance, entity count, statement ordering (topological, reverse, random), congruence with real-world priors, and irrelevant filler content—is independently controllable via the configuration, enabling effect isolation experiments. The framework uses Jax PRNG keys at two levels (initialization and per-example) to ensure full reproducibility, and employs heuristic rejection sampling to rebalance rare properties like high symbolic distance in random-tree configurations. Four task domains span a spectrum of relational reasoning capabilities: transitive inference over directed chains (Comparison), shortest-path reasoning over undirected graphs (Social Networks), multi-proposition logical deduction (Syllogisms), and structured data navigation (JSON Families).

## Results

Across all four task domains (Comparison, Social Networks, Syllogisms, JSON Families), performance degrades monotonically as the number of entities increases, with GPT-4o and Gemini Pro maintaining the highest accuracy. On the Social Network task, most models perform well at 10 entities regardless of symbolic distance, but as graph size grows, reliable reasoning shrinks to symbolic distance ≤ 6; GPT-4o and Gemini Pro sustain performance up to 70 entities provided traversals remain below 6. Congruent comparison problems outperform incongruent ones across all models, with some models dropping below chance (0.5) on incongruent items. Topologically ordered contexts improve relational reasoning over random ordering for nearly all models, and flavor text degrades performance in all models except GPT-4o.

## Baselines & Comparisons

This is a benchmark/framework paper, so comparisons are between LLMs evaluated on the same ReCogLab configurations rather than between methods. GPT-4o and Gemini Pro consistently outperform open-source models (Gemma, Mixtral) across all tasks and difficulty levels, with GPT-4o showing the most robust performance to flavor text, question format changes (Exact Path vs. Number Hops), and graph size scaling. Among open-source models, Gemma 27B generally outperforms Gemma 9B, while Mixtral 8×22B surpasses Mixtral 8×7B by a wide margin (e.g., 0.55 vs. 0.03 at 101 entities on Social Network). A notable finding is that several models (Gemini Pro, Gemini Flash, Mixtral 8×22B) perform *better* on the harder Exact Path question than on the easier Number Hops question, likely due to the increased decoded tokens providing more reasoning space. On congruency probes, all models show the same qualitative pattern (Congruent > Random String > Incongruent), but the magnitude of the congruency advantage varies, with smaller models showing larger gaps. The reseeding experiments confirm that different random seeds produce statistically consistent scores, validating the framework's reliability as a shared benchmark.

## Relation to Prior Work

ReCogLab extends the line of synthetic reasoning benchmarks (bAbI, KBQA, CLEVR, Rule-Takers) by replacing static, hand-curated datasets with a fully procedural generation framework whose every parameter—graph size, symbolic distance, statement ordering, flavor text, congruency—is controlled via a configuration file. It draws directly on cognitive science experimental paradigms (transitive inference, symbolic distance effect, ordering effects, congruency effects) and repurposes them as configurable probes for LLMs, going beyond prior LLM evaluation work (Levy et al., 2024; Bai et al., 2024) that examined context length without the ability to isolate specific reasoning sub-competencies. Unlike Dynabench/Dynatask, which still require human annotation, ReCogLab is fully automatic and re-seedable, and unlike CLEVR it operates purely in language space with graph-structured relational problems.

## Why It Matters / Open Questions

The framework addresses a practical gap: static reasoning benchmarks quickly saturate as models improve, and their fixed structure makes it hard to isolate whether a failure stems from memory recall, logical deduction, or attention over long contexts. By enabling parameter sweeps and re-seeding, ReCogLab gives both ML and cognitive science communities a shared, reproducible tool for studying relational reasoning at scale. Open questions include whether the observed effects (congruency, ordering, acquiescence bias) are genuine reasoning properties or artifacts of training-data statistics, whether the framework's graph-based abstraction captures the full richness of human relational memory, and how findings transfer to non-English or multimodal settings.

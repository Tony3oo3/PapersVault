## Problem

Creating procedural materials (functional node graphs) from a single input image requires expert knowledge and significant manual effort. Existing approaches either train custom architectures from scratch on proprietary datasets (e.g., Adobe Substance 3D), or rely on zero-shot VLM prompting, which fails because procedural material programs are domain-specific and underrepresented in VLM training data. No open-source procedural material dataset existed to enable fine-tuning of general-purpose vision-language models for this task.

## Input / Output

The method takes a single RGB image of a material appearance on a flat surface and produces a Python function using Blender's Python API that, when executed, constructs a shader node graph (limited to ≤30 nodes from Blender's pre-defined node types). The output is not a pixel-perfect reproduction but a perceptual match; the generated node graph remains fully editable by adjusting node parameters or rewiring edges. Programs exceeding 2,048 LLaMA 3 tokens or producing degenerate renderings (empty, uniform, or below a 12 KB JPEG complexity threshold) are considered invalid.

## Method

The core approach fine-tunes LLaVA-NeXT (CLIP ViT/L-14 encoder + LLaMA 3 8B decoder + MLP projector) with LoRA adapters (r=8, α=32) on image-to-Python-program pairs, leveraging the fact that Blender node graphs transpile directly into standard Python. The key enabling contribution is a two-stage data augmentation pipeline: (1) graph structure augmentation inspired by FunSearch, where GPT-4o-mini performs 'genetic crossovers' on pairs of artist-created programs to produce 50.4K structurally diverse programs, and (2) parameter-space augmentation via random perturbation of continuous (float, vector, color in HSV) and discrete (integer, categorical, Boolean) node parameters, expanding the dataset from ~1.6K to ~550K examples. At inference, the model generates up to N=50 candidate programs and selects the one with lowest style loss; an optional MCMC-based gradient-free local parameter search (200 iterations, 5% acceptance probability for worse samples) further refines node parameters to improve perceptual match.

## Results

On the in-distribution Blender test set, VLMaterial achieves a style loss of 0.019, SWD of 1.760, CLIP similarity of 0.856, and 91.1% program correctness, outperforming all baselines. On out-of-distribution Substance images, it reaches style loss 0.026, SWD 2.283, CLIP 0.762, and 89.0% correctness. On real photographs, it achieves style loss 0.025, SWD 2.417, CLIP 0.722, and 87.0% correctness, with the only metric where a baseline (Nearest Neighbor, 0.021) edges ahead being style loss on real images.

## Baselines & Comparisons

VLMaterial outperforms GPT-4o-mini (zero-shot) by a wide margin on all metrics across all three datasets, with GPT-4o-mini achieving only 23–29% program correctness versus 87–91% for VLMaterial. Against Conditional MatFormer (Hu et al., 2023), which was trained on 446K Substance materials, VLMaterial wins on style loss, SWD, and CLIP on both Blender and Real images, and on all three metrics on Substance (0.026 vs 0.033 style loss, 2.283 vs 2.366 SWD, 0.762 vs 0.736 CLIP). Compared to BlenderAlchemy (Huang et al., 2024), VLMaterial achieves lower style loss and SWD on all datasets while also producing valid programs at 87–91% rate versus BlenderAlchemy's inability to guarantee executability. The closest competitor is Nearest Neighbor retrieval, which achieves a marginally lower style loss on real images (0.021 vs 0.025) but is outperformed on SWD (2.487 vs 2.417) and CLIP (0.700 vs 0.722); the authors note that retrieved materials are visually sub-optimal despite the competitive metric. In a user study, participants preferred VLMaterial over BlenderAlchemy in 91% of visual quality comparisons and 94% of node graph quality comparisons, with an average usability rating of 6.8/10 versus 4.2/10.

## Relation to Prior Work

This paper departs from the established line of inverse procedural material generation (MatFormer, Conditional MatFormer) that trains custom transformer architectures from scratch on proprietary Substance 3D data. Instead, it exploits the fact that Blender node graphs transpile to standard Python and fine-tunes a pre-trained VLM (LLaVA-NeXT with LLaMA-3) on image-to-program pairs, borrowing the evolutionary program-search idea from FunSearch for graph-structure data augmentation and the parameter-perturbation strategy from Hu et al. (2023) for appearance diversity. The MCMC-based post-optimization replaces the differentiable backpropagation used in prior Substance-based work, which is infeasible for Blender's heterogeneous node types.

## Why It Matters / Open Questions

The release of the first open-source procedural material dataset (550K+ Blender image-program pairs) removes a key barrier that previously confined research to proprietary pipelines, enabling broader experimentation. The ablation reveals that evolutionary LLM-based structure augmentation is the dominant factor for program correctness (0.603 → 0.911), a practical insight for future VLM fine-tuning in code-generation domains. Open questions include whether a compact DSL with inference-time syntax checking can further improve reliability, whether RL fine-tuning with visual rewards closes the remaining gap on out-of-distribution inputs, and how the approach scales beyond the 30-node limit that currently constrains expressiveness for intricate textures.

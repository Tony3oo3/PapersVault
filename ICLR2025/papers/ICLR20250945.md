## Problem

While LLMs have demonstrated strong code generation and analysis capabilities, it remains unclear whether they can semantically understand symbolic graphics programs (SVG, CAD) — i.e., 'imagine' the visual output from the program text alone without any vision encoder. No prior benchmark systematically evaluates this specific form of visual-spatial reasoning over procedural graphics code, nor does it test whether such understanding is robust to code-level perturbations that preserve rendered semantics.

## Input / Output

The LLM receives a symbolic graphics program (SVG XML or CAD DSL code) concatenated with a 4-option multiple-choice semantic question about the rendered image, and must output the correct option letter. Critically, the rendered image is never provided as input; the model must reason purely from the code's numeric coordinates, path definitions, and operation sequences. For the consistency evaluation, the same program is perturbed with non-trivial SE(2) transformations (translation and rotation applied at the coordinate level rather than via SVG transform attributes), which drastically alter all numeric values while preserving the rendered semantics, and the model must produce the same answer.

## Method

The paper introduces SGP-Bench, a large-scale benchmark (1,085 SVG programs with 4,340 questions across 5 categories; 2,400 CAD programs from DeepCAD, Fusion360, and SketchGraphs) built via a scalable pipeline where GPT-4o generates semantic questions from rendered images, followed by human verification. A key design choice is the semantic consistency test: applying coordinate-level SE(2) perturbations to SVG code to rule out memorization and probe genuine comprehension. To improve performance, the authors propose Symbolic Instruction Tuning (SIT), which collects 72K (program, semantic description) pairs by prompting GPT-4o to caption rendered images, then fine-tunes open-source LLMs via supervised instruction tuning (using orthogonal finetuning). Notably, SIT not only boosts symbolic graphics understanding (e.g., Llama-3.1-8B from 46.5% to 51.4%) but also transfers to general reasoning benchmarks (GSM8K, AGIEval, MathQA), suggesting that the multi-step spatial-semantic reasoning required by graphics programs serves as a useful training signal for broader reasoning.

## Results

On SGP-Bench, the best-performing model (Claude 3.5 Sonnet) achieves 67.4% average accuracy on SVG-Understanding and 74.2% on CAD, while the best open-source model (Llama-3.1-405B) reaches 58.0% on SVG and 71.7% on CAD. All models exhibit strong semantic consistency under SE(2) perturbations, with most exceeding 80% consistency scores. On the extreme SGP-MNIST challenge, even GPT-4o achieves only 13.0% accuracy (near the 10% chance level), while the rendered images are easily recognizable by humans. Symbolic Instruction Tuning (SIT) with 55K pairs improves Llama-3.1-8B from 46.5% to 51.4% on SVG, and mixing SIT data with Open-Instruct yields consistent gains across 15 general reasoning benchmarks (e.g., +3.3 on GSM8K, +7.9 on AGIEval with rev-SIT).

## Baselines & Comparisons

The paper evaluates 30+ LLMs on SGP-Bench rather than comparing a single proposed method against baselines. Proprietary models (GPT-4o, Claude 3.5 Sonnet) outperform all open-source models by a significant margin: Claude 3.5 Sonnet leads with 67.4% SVG / 74.2% CAD, while the best open-source model (Llama-3.1-405B) reaches 58.0% / 71.7%. A clear scaling law is observed within model families (e.g., Llama-3.1 improves from 46.5% to 57.4% to 58.0% going from 8B to 70B to 405B on SVG). For the instruction-tuning comparison, Open-Instruct (OI, 143K pairs) serves as the baseline: mixing SIT data into OI consistently improves general reasoning, with the largest gains on AGIEval (+6.6 to +7.9), IFEval instruction (+4.0 to +5.6), and GSM8K (+2.5 to +3.3), while the reverse-SIT variant (program generation) particularly boosts instruction-following and mathematical reasoning. SIT also improves the target SVG task itself, lifting Llama-3.1-8B from 46.5% to 51.4%, surpassing GPT-3.5 Turbo (49.8%) but remaining below Llama-3.1-70B (57.4%), indicating that scale differences cannot be fully closed by finetuning alone.

## Relation to Prior Work

This paper carves new ground at the intersection of LLM code understanding, inverse graphics, and visual question answering. While prior work has explored LLMs for program synthesis [5, 58] and inverse graphics program inference [104, 111, 48], none has systematically evaluated whether LLMs can semantically understand the rendered output of symbolic graphics programs (SVG, CAD) without any visual encoder. The paper also extends the instruction-tuning paradigm from visual instruction tuning [56] to the symbolic domain, proposing Symbolic Instruction Tuning (SIT) as an analogous but text-only approach. A concurrent benchmark (VGBench [122]) targets SVG understanding, but SGP-Bench is broader in scope (SVG + CAD, semantic consistency via SE(2) perturbations, and the SGP-MNIST challenge).

## Why It Matters / Open Questions

SGP-Bench provides a scalable, procedurally-generated benchmark for probing LLMs' spatial-semantic reasoning that is resistant to data leakage (via SE(2) consistency tests), making it a valuable tool for the field as LLMs are increasingly deployed in design and graphics pipelines. The SGP-MNIST result—where GPT-4o achieves near-chance accuracy on recognizing digits from SVG programs that humans read effortlessly—exposes a fundamental gap between LLM symbolic reasoning and human visual perception that remains unresolved. The finding that SIT improves general reasoning (AGIEval, GSM8K, arithmetic) beyond the target domain suggests symbolic graphics programs may serve as a rich data source for broader reasoning improvement, though the effect sizes are modest and the mechanism is not fully understood. Open questions include whether the LLM–human gap on SGP-MNIST can be closed with scale or architecture changes, and whether the consistency-accuracy dissociation reveals a specific representational limitation.

## Problem

Equivariant policies for robotic manipulation have been explored primarily in imitation learning for simple pick-and-place tasks, but extending them to on-policy reinforcement learning for complex 3D manipulation (diverse rigid insertion, deformable objects, multi-actuator coordination) remains unexplored. Prior approaches also treat all graph nodes homogeneously, failing to capture the fundamentally different roles of actuators versus objects, and large policy networks struggle to adapt quickly under the high-frequency data collection demands of on-policy RL.

## Input / Output

The method consumes a heterogeneous graph with two disjoint node sets (actuators and objects), where each node carries a one-hot type indicator, normalized 3D position, and velocity vector; object nodes additionally encode the relative distance to the target. Intra-edges connect nodes within each set (kNN=3 for objects, complete for actuators), while directed, fully-connected inter-edges flow from all object nodes to all actuator nodes. The policy outputs, per actuator node, a scalar gate c and a vector v whose product c·v yields the linear velocity command; angular velocity is derived by decomposing v into parallel and tangential components relative to the position vector. For Cloth-Hanging, the policy uses only 10 hole-boundary nodes as object representation while the value function (a DeepSets over all cloth particles) sees the full mesh.

## Method

HEPi processes the heterogeneous graph through three separate equivariant message-passing layers (obj-to-obj, act-to-act, obj-to-act), each with its own learnable PONITA kernel parameters, so that actuators aggregate information from all object nodes in a single hop—functioning as global virtual nodes. The backbone is the PONITA framework, which achieves approximate SE(3) equivariance by lifting the spatial domain to position-orientation space (R³×S²) and factorizing the convolution kernel into spatial, orientation, and channel-mixing components, avoiding expensive spherical-harmonics tensor products. A theoretical result (Proposition 3.1) proves that this fully-connected obj-to-act design allows any actuator-object pair to exchange information in one layer, unlike k-NN local connections where the Jacobian vanishes beyond two hops. For training stability, HEPi replaces PPO's clipped surrogate with Trust Region Projection Layers (TRPL), which project both the mean and covariance of the Gaussian policy onto trust-region boundaries via differentiable convex optimization, yielding stable convergence in high-exploration 3D tasks with minimal hyperparameter tuning. The value function is a permutation-invariant DeepSets over node features, decoupled from the policy's input to allow task-specific observations (e.g., all cloth particles for the critic vs. only hole-boundary nodes for the actor).

## Results

Across seven manipulation tasks (rigid sliding, pushing, insertion, two-agent insertion, rope closing, rope shaping, and cloth hanging), HEPi consistently achieves the highest undiscounted returns, evaluated over 1000 scenes with 10 seeds using IQM with 95% confidence intervals. In simpler 2D tasks (rigid-sliding, rigid-insertion-2D+z), HEPi and Transformer perform comparably, but in complex 3D tasks such as rigid-insertion-two-agents-3D and cloth-hanging-3D, HEPi significantly outperforms both baselines. HEPi also demonstrates superior generalization to unseen objects (trained on 1–3 shapes, tested on the rest) and robustness to input noise (σ up to 0.05) and high-resolution meshes (~1200 nodes vs. ~20 nodes) without retraining. TRPL training is more stable than PPO in high-exploration 3D tasks, while both perform comparably in lower-dimensional 2D settings.

## Baselines & Comparisons

The primary baseline is a Transformer-based policy (Vaswani et al., 2017), treated as a fully-connected GNN. HEPi matches the Transformer on simple 2D tasks (rigid-sliding, rigid-insertion-2D+z) but clearly outperforms it in complex 3D settings: on rigid-insertion-two-agents-3D the Transformer fails to generalize across poses, and on cloth-hanging-3D HEPi achieves substantially higher final returns. The second baseline is a naive (homogeneous) EMPN, which HEPi outperforms on tasks requiring more exploration (rigid-pushing-2D, rigid-insertion-2D+z, rigid-insertion-two-agents-3D) due to EMPN's limited expressiveness from shared parameters across all node types. For the cloth-hanging task specifically, HEPi also beats a Heterogeneous GNN (HeteroGNN) in sample efficiency by leveraging SE(3) equivariant constraints, while both heterogeneous models outperform their homogeneous counterparts in final return. Adding attention (GAT-style) to either homogeneous or heterogeneous GNNs does not improve performance and nearly doubles training time, confirming that explicit heterogeneity modelling in HEPi is more effective than attention-based aggregation.

## Relation to Prior Work

This paper extends the line of equivariant manipulation policies (Transporter Net, Equibot) from imitation learning to on-policy reinforcement learning in 3D space, a setting where prior equivariant RL work was limited to 2D. The architectural backbone is the PONITA framework (Bekkers et al., 2024) for efficient SE(3)-equivariant message passing, combined with Trust Region Projection Layers (Otto et al., 2021) for stable policy updates. Conceptually, the heterogeneous graph design treating actuators as global virtual nodes that connect to all object nodes is inspired by the virtual-node analysis of Southern et al. (2024), but the paper provides a formal proposition showing that local k-NN connections between actuators and objects provably fail to transmit information, unlike the fully-connected inter-edges used here. The value function uses DeepSets (Zaheer et al., 2017) for permutation-invariant aggregation, following prior graph-based RL work.

## Why It Matters / Open Questions

This work provides the first systematic study of SE(3)-equivariant policies trained with RL for 3D robotic manipulation, bridging a gap between the imitation-learning equivariant manipulation literature and the RL community. The 7-task benchmark (rigid insertion with diverse geometries, rope and cloth manipulation with multiple actuators) offers a progressive difficulty ladder well-suited for evaluating geometry-aware policies. Key limitations include abstracting away the full robot body (only end-effector control) and assuming object keypoints are available, which restricts real-world applicability. Open questions include whether the heterogeneous equivariant design scales to full robot morphologies, whether vision-based keypoint extraction can close the perception gap, and whether the approach transfers to tasks with contact-rich dynamics beyond the simulated settings tested here.

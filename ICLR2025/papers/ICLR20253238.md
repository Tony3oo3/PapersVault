## Problem

Multi-modal large language models (MLLMs) struggle with fine-grained visual recognition (FGVR), i.e., identifying subordinate-level categories such as specific dog breeds or aircraft models. Through systematic analysis of three capabilities—object information extraction, category knowledge reserve, and object-category alignment—the paper identifies the root cause as a misalignment between visual object representations and category names in the LLM's representation space, rather than insufficient visual information or missing category knowledge.

## Input / Output

The model takes an RGB object image and a set of candidate category names (for closed-set multiple-choice) or an open-ended question (for open-set QA) as input, and generates the subordinate-level category name as text output. During training, each image is additionally paired with a constructed attribute description (a short natural-language summary of distinguishing visual features like wing shape, coat color, etc.) that serves as an intermediate alignment bridge. The FGVR task is framed as both open-set question answering and closed-set multiple-choice with well-defined answer candidates drawn from the test set annotations.

## Method

Finedefics, built on Idefics2, introduces a two-stage training paradigm centered on Attribute Augmented Alignment. First, per-sample attribute descriptions are constructed by chaining LLMs (for attribute discovery and summarization) with VQA models (for visual attribute extraction), converting (object, category) pairs into (object, attribute, category) triples. In Stage I, contrastive learning is performed simultaneously on object-attribute and attribute-category pairs using the [EOS] token embedding as global representation, with hard negatives mined via CLIP from the three most visually similar but incorrect categories, plus a Category-Category Contrastive loss to improve discriminability among category names and a generation loss on attribute descriptions to preserve generative capability. In Stage II, the model is fine-tuned on classification-centered instruction tuning data (open-set QA and closed-set multiple-choice) to restore task-following ability. The key insight is that attribute descriptions act as a semantic bridge that is closer to both the visual object and the category name than either is to the other, making the alignment problem tractable within the LLM's representation space.

## Results

Finedefics (8B) achieves an average FGVR accuracy of 76.84% across six popular fine-grained datasets (Dog-120, Bird-200, Aircraft-102, Flower-102, Pet-37, Car-196), outperforming its base model Idefics2 (65.95%) by +10.89% and the strongest comparable MLLM Qwen-VL-Chat (67.41%) by +9.43%. The largest per-dataset gain is on Flower-102 (+13.93% over Idefics2), while the smallest is on Pet-37 (+4.36%). On common object recognition (ImageNet-adversarial, ImageNet-rendition, ImageNet-sketch), Finedefics shows only a minor drop (80.43% → 78.39% average) compared to Idefics2, indicating limited catastrophic forgetting.

## Baselines & Comparisons

Finedefics achieves the best average FGVR accuracy (76.84%) across all six datasets, outperforming every compared baseline. The closest competitors are its base model Idefics2 (65.95%, gap of +10.89%) and Qwen-VL-Chat (67.41%, gap of +9.43%), both of which are surpassed on every individual dataset. Among 7B-parameter MLLMs, Finedefics leads LLaVA 1.5 (43.24%) by +33.60%, MobileVLMv2 (43.95%) by +32.89%, and InternLM XComposer2 (48.47%) by +28.37%. Smaller models such as Pali-Gemma (3B, 56.31%) and BLIP2 Flan-T5-XL (4B, 51.64%) trail by +20.53% and +25.20% respectively. Against the zero-shot attribute-based method FineR (57.00% clustering accuracy), Finedefics achieves 79.44% classification accuracy on five datasets, demonstrating that building an attribute-aware model via contrastive alignment substantially outperforms a multi-agent zero-shot pipeline.

## Relation to Prior Work

This paper builds on Idefics2 as its base MLLM and departs from prior attempts to improve FGVR in MLLMs (Geigle et al., 2024; Zhang et al., 2024b) that simply injected classification data into pre-training or instruction tuning. The key conceptual departure is the diagnosis of the root cause as a misalignment problem between visual object and category name representations, rather than insufficient visual features or missing category knowledge. The attribute description construction pipeline borrows the cascade-of-foundation-models idea from FineR (Liu et al., 2024c) but repurposes it for training-time contrastive alignment rather than zero-shot inference, while the hard-negative mining and intra-modal contrastive loss draw from CLIP-style training and Zhang et al. (2024a).

## Why It Matters / Open Questions

The paper provides a clear, empirically grounded diagnosis of why MLLMs underperform at FGVR—misalignment in representation space rather than missing information—which redirects future work away from simply adding more classification data. The +10.89% average improvement over Idefics2 across six datasets is substantial and the method generalizes to other MLLMs (LLaVA 1.5 gains +13.97%). However, practical limitations remain: the attribute description construction pipeline is computationally expensive (requiring GPT-4/LLaMA + VQA models per sample), training on FGVR data causes minor degradation on common object recognition (−2.04% on ImageNet variants), and the approach does not address continual learning of new subordinate categories, which the authors identify as an open problem.

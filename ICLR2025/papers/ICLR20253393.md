## Problem

While parameter-efficient fine-tuning (PEFT) is well-studied for Transformers, research on PEFT for Mamba (a State Space Model architecture) remains virtually unexplored, with only one prior work applying uniform-rank LoRA to all linear layers. It is unclear which Transformer PEFT methods transfer to Mamba, how they should be modified to respect SSM-specific structure (sequential processing, selective scan, diagonal state dynamics), and whether Mamba-specific PEFT methods can outperform direct adaptations.
![Teaser figure](../imgs/ICLR20253393/cropped_page1_idx0.webp)

## Input / Output

The method takes pre-trained Mamba/Vim model weights (ImageNet-1K, DeiT training) plus downstream task data: 1,000 images per task for VTAB-1k vision benchmarks, or 170K text samples for commonsense reasoning. It produces a small set of trainable PEFT parameters (ranging from ~9K for linear probing to ~117K for Affix-tuning with projection) that are added to or modify the frozen backbone. For reparameterization methods like LoRA, the adapters can be merged into the original weights at inference with zero additional compute; for additive methods like Additional-scan, the extended state dimension adds a small recurrent overhead. Evaluation is on 19 vision tasks (grouped into Natural, Specialized, Structured) and 8 commonsense reasoning sub-tasks.

## Method

The paper benchmarks 20 variations across 7 PEFT method families adapted to Mamba and proposes three new Mamba-specific methods. Affix-tuning redesigns Prefix-tuning for SSMs by inserting learnable soft tokens before the SSM input and discarding their outputs after the selective scan, preserving positional relationships without requiring attention-based K/V injection. Additional-scan extends the SSM state dimension by N' new recurrent channels whose A, B, C parameters are initialized from neighborhood values of the pre-trained A matrix (rather than S4D), enabling new task-specific memory without disturbing the original hidden state dynamics. Partial LoRA applies low-rank adapters to only specific output-feature slices of linear layers (e.g., only the X-output portion of in_proj), preventing cross-feature interference in Mamba's heterogeneous intermediate representations. A two-step hybrid search (TPE via Optuna) first selects which PEFT methods to activate with minimal parameters, then greedily tunes hyperparameters, finding combinations that outperform both individual methods and naive all-methods ensembles.

## Results

On the VTAB-1k benchmark (1K training images per task), the best PEFT methods for Vim-S (Mamba) achieve 71.52% average accuracy (LoRA_p(X)) and 71.80% (Hybrid w/o proj), outperforming the best Transformer PEFT (Adapter+ at 69.87% on ViT-S) by ~1.5–2 points. Notably, Vim-S PEFT methods continue to improve with more trainable parameters (up to 1,778K for LoRA_p(X)), whereas ViT-S PEFT methods overfit early and plateau. On commonsense reasoning (170K training data), Additional-scan achieves 53.5% average on Mamba 1.4B with only 0.26% trainable parameters, surpassing full fine-tuning (53.0%) and SLL LoRA (52.7%), while Affix-tuning (w/o proj) reaches 53.9% with just 0.09% parameters.

## Baselines & Comparisons

All Transformer PEFT baselines in Table 1 (LoRA 68.68, AdaptFormer 68.97, FacT-TK 66.96, SPT-LoRA 69.38, Adapter+ 69.87) are outperformed by the best Vim-S PEFT methods (LoRA_p(X) 71.52, Hybrid 71.80–72.05) by 1.5–5 points on average VTAB-1k accuracy. On language tasks (Table 3), SLL LoRA [20] (the only prior Mamba PEFT) is consistently outperformed: at Mamba 1.4B, Additional-scan (53.5) and LoRA_p(X) (53.7) both exceed SLL LoRA (52.7) while using fewer parameters (0.26% and 1.36% vs. 4.64%). Mamba with PEFT matches or exceeds Pythia [4] with LoRA at comparable model sizes (e.g., Mamba 1.4B + Affix-tuning w/o proj: 53.9 vs. Pythia 1.4B + LoRA: 50.5). The Transformer-specific baselines evaluated only in the appendix (LoSA, Head2Toe, VQT, BitFit on ViT-B) are not directly compared in the main tables but serve as context showing that Vim-S PEFT with ImageNet-1K pre-training achieves comparable or better accuracy than ViT-B PEFT with ImageNet-21K pre-training. A key finding is that simply combining all PEFT methods (All w/proj: 67.68) underperforms individual methods, whereas the proposed two-step hybrid search (71.80) selects a sparse, complementary subset that generalizes better.

## Relation to Prior Work

This paper extends the well-established PEFT literature for Transformers (LoRA, Adapter, Prompt-tuning, BitFit) to the Mamba/SSM architecture, which had only one prior PEFT study (SLL LoRA, Halloran et al. 2024, applying uniform-rank LoRA to all linear layers). It both adapts existing methods (ParallelAdapter on out_proj, Prompt-tuning with position variants) and introduces genuinely Mamba-specific techniques: Affix-tuning (a redesign of Prefix-tuning that discards inserted-token outputs after the SSM to preserve positional structure) and Additional-scan (extending the SSM state dimension with a neighborhood-based initialization derived from S4D/Hippo theory). The hybrid PEFT search framework builds on AutoPEFT and NOAH but replaces supernet-based per-task search with a two-step TPE-based approach targeting cross-task generalization.

## Why It Matters / Open Questions

This is the first comprehensive benchmark of PEFT for Mamba, filling a clear gap as Mamba-based models proliferate across NLP, vision, and multimodal domains. The finding that PEFT is more effective for Mamba than Transformers (accuracy keeps improving with more trainable parameters rather than overfitting) has practical implications for how practitioners allocate fine-tuning budgets for SSM-based models. Key limitations include evaluation only on small models (Vim-S, Mamba ≤1.4B) and limited task diversity (VTAB-1k, commonsense reasoning), leaving open whether the findings—particularly the over-parameterization tolerance and the hybrid combination effects—hold at the scale of billion-parameter vision or language models. The released code and systematic ablations make this a useful reference for future Mamba PEFT research.

## Problem

Human instructions in embodied instruction following are typically sparse and incoherent, omitting intermediate action steps (e.g., 'take a mug' without specifying 'open the fridge' first). Existing EIF methods directly ground these sparse instructions into action sequences, causing agents to get stuck or fail because the generated plans lack the necessary intermediate interactions. This paper addresses the gap by recovering missing action descriptions through thought chain reasoning before execution.
![Teaser figure](../imgs/ICLR20253701/cropped_page1_idx0.webp)

## Input / Output

The agent receives a sparse step-by-step instruction with a high-level goal, a 300×300 egocentric RGB frame, and an online-updated partially observed 2D semantic map (constructed from depth estimation and instance segmentation of the egocentric view). The instruction completer (GPT-3.5) outputs a structured JSON containing a natural-language thought chain and a list of subgoals as (action, object, expectation) tuples. The object localizer outputs a pixel-wise position heatmap on the semantic map along with a per-pixel variance representing Bayesian aleatoric uncertainty, which is fed back to the LLM for closed-loop re-planning.

## Method

ThinkBot consists of two coupled modules. The instruction completer prompts GPT-3.5 with a system message encoding simulator primitives and an agent message containing observed landmarks, completed subgoals, and executor feedback; chain-of-thought prompting elicits intermediate action recovery (e.g., inserting 'Open Fridge' between 'Go to Fridge' and 'Take Mug'). The multimodal object localizer pairs a BERT instruction encoder with a ResNet-18 map encoder, and introduces a learned object correlation graph (generated from map features via a linear projection rather than handcrafted) that is propagated through graph convolution to enhance spatial priors. Cross-attention aligns instruction queries with map keys/values to decode object positions, while a Bayesian aleatoric uncertainty head (trained with Gaussian-noise-sampled BCE loss) outputs per-pixel variance. This uncertainty is fed back into the LLM prompt, enabling the agent to shift from exploitation to exploration when localization confidence is low, forming a closed-loop planning cycle.

## Results

On the ALFRED benchmark, ThinkBot achieves 62.69% SR and 71.64% GC on test seen, and 57.82% SR and 67.75% GC on test unseen, setting new state-of-the-art on all four metrics in both splits. In terms of execution efficiency, ThinkBot reaches 32.02% PLWSR and 37.01% PLWGC (test seen) and 26.93% PLWSR and 30.73% PLWGC (test unseen). On the ActioNet benchmark, ThinkBot achieves 73.3 BERT similarity for high-level planning, surpassing LLM-Planner (68.4) by 4.9 points, and 69.9% HLP accuracy on ALFRED versus LLM-Planner's 43.2%.

## Baselines & Comparisons

ThinkBot outperforms all 12 baselines on every metric in both test seen and test unseen splits. Against the strongest modular baseline Prompter+ (which adds environment-aware memory and a re-trained detector to Prompter), ThinkBot gains +1.83% SR (62.69 vs. 60.86) and +1.44% GC (71.64 vs. 70.20) on test seen, and +2.36% SR (57.82 vs. 55.46) and +2.04% GC (67.75 vs. 65.71) on test unseen. Against the prior best published method CPEM (Kim et al., ICCV 2023), the margins are larger: +12.07% SR on test seen and +7.98% SR on test unseen. End-to-end methods (Seq2seq, MOCA, E.T., LWIT, HITUT, ABP) trail by 20–55+ SR points, confirming the advantage of the modular architecture. On the ActioNet planning benchmark, ThinkBot's instruction completer achieves 73.3 BERT similarity versus LLM-Planner's 68.4, and 69.9% HLP accuracy on ALFRED versus LLM-Planner's 43.2%, demonstrating strong generalizability beyond the ALFRED environment. The error-mode analysis (Table 4) shows ThinkBot reduces the dominant 'goal object not found' failure from 21.10% (Prompter+) to 18.08%, while interaction and navigation failure rates remain comparable, confirming that the gains come specifically from coherent instruction recovery rather than better low-level control.

## Relation to Prior Work

ThinkBot extends the modular EIF paradigm (FILM, Prompter, CPEM) by inserting an LLM-based instruction completer that recovers missing action descriptions via chain-of-thought reasoning (Wei et al., 2022), addressing the core failure mode of prior modular methods that directly ground sparse, incoherent human instructions into action sequences. The object localizer draws on Bayesian aleatoric uncertainty estimation (Kendall & Gal, 2017) to provide a closed-loop feedback signal back to the LLM planner, a design not present in prior LLM-for-embodied-agents work (ReAct, LLM-Planner) that typically treats LLM output as a one-shot plan. The learned object correlation graph (a GNN over category co-occurrence) is a lightweight spatial prior that distinguishes ThinkBot from prior semantic-map-based localizers like FILM's CNN-only approach.

## Why It Matters / Open Questions

The paper identifies and quantifies a practical failure mode in EIF—sparse instruction incoherence—that prior methods largely ignored, and shows that a thought-chain recovery step is essentially critical for tasks involving closed containers (SR drops to 0% without it on the hard valid unseen split). However, the overall SOTA margin over Prompter+ is modest (~2% SR), the method depends on GPT-3.5 API calls at ~0.31s per planning step, and the real-world validation is limited to a single mobile pick-and-place demo. Open questions include whether the approach generalizes beyond AI2-THOR's discrete action space, how it handles genuinely ambiguous instructions requiring active clarification, and whether the LLM dependency can be replaced by smaller on-device models without the performance drop observed with Llama 3.2 3B.

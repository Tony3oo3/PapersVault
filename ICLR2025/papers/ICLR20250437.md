## Problem

Existing Neural Process variants require fixed input and output dimensions, necessitating separate model training for each dimensional configuration and preventing their use as general regressors across diverse regression tasks. This limitation is particularly problematic for applications like hyperparameter optimization where input dimensionality varies naturally across tasks.
![Teaser figure](../imgs/ICLR20250437/cropped_page2_idx0.webp)

## Input / Output

The method consumes context input-output pairs (x, y) where x ∈ R^{u(j)} and y ∈ R^{v(j)} can have arbitrary dimensions that vary across tasks, along with target input points x (zero-padded for y during encoding). It produces a Gaussian predictive density parameterized by mean μ and diagonal variance σ² for each target point, with the output dimension matching the original y dimension. The DAB module internally projects all varying-dimensional features into a fixed d_r-dimensional representation space, so the model's parameter count remains constant regardless of input/output dimensionality.

## Method

DANP introduces a Dimension Aggregator Block (DAB) that encodes varying-dimensional inputs into a fixed-dimensional space via learnable linear projections, distinct sinusoidal positional encodings for x and y dimensions, a self-attention layer to capture inter-dimensional interactions, and average pooling over x dimensions (while preserving y as a sequence for variable-length output decoding). On top of this, DANP combines the deterministic TNP encoder (Masked Transformer layers) with an additional latent pathway comprising Transformer layers, self-attention, and an MLP that produces a variational posterior over a latent variable, enabling the model to capture functional uncertainty. Training uses the ELBO objective with the latent path, and the architecture supports zero-shot inference on unseen dimensions as well as efficient fine-tuning on new dimensional tasks with limited data, all from a single pre-trained model.

## Results

On the From-scratch GP regression benchmark, DANP achieves the best target log-likelihood across all four settings: 0.921 (1D RBF), 0.723 (1D Matern), 0.373 (2D RBF), and 0.068 (2D Matern), consistently outperforming the strongest baseline TNP (0.904, 0.710, 0.362, 0.060). On image completion, a single DANP model trained simultaneously on EMNIST and CelebA achieves target log-likelihood of 0.969 and 2.027 respectively, surpassing TNP (0.945 and 1.632) which requires separate models per dataset. In the zero-shot scenario, DANP pre-trained on 2D/3D/4D GP data generalizes to unseen 1D (target: 0.826), 5D (target: −0.676), and 7D (target: −0.723) datasets, while in fine-tuning with only 160 tasks DANP reaches target log-likelihood 0.893 whereas all baselines produce negative values.

## Baselines & Comparisons

DANP outperforms all five NP baselines (CANP, ANP, BANP, MPANP, TNP) on target log-likelihood across every GP regression setting, with the largest margins on 2D tasks (e.g., 2D RBF target: 0.373 vs. TNP's 0.362 and CANP's 0.165). TNP is the closest competitor throughout, but DANP's advantage grows with input dimensionality. On image completion, DANP trained on both EMNIST and CelebA simultaneously beats TNP by 0.024 (EMNIST target) and 0.395 (CelebA target) log-likelihood, while baselines require separate models per dataset. In the fine-tuning scenario (160 1D GP tasks), DANP achieves target log-likelihood 0.893 while all baselines produce negative values (best baseline TNP: −0.448), demonstrating that only DANP's learned features transfer to unseen dimensions. Against Neural Diffusion Process (NDP), DANP achieves substantially higher target log-likelihood (e.g., 0.921 vs. −0.376 on 1D RBF) despite NDP's higher context likelihood, because NDP's diffusion-based sampling fails to produce accurate target distributions. On the HPO-B Bayesian Optimization benchmark, DANP (zero-shot, pre-trained on 2D/3D/8D) outperforms all baselines (fine-tuned on 4 meta-batches) in normalized regret across 6-, 9-, 10-, and 16-dimensional hyperparameter tuning tasks, with the gap widening for higher-dimensional extrapolation settings.

## Relation to Prior Work

DANP builds directly on Transformer Neural Processes (TNP, Nguyen & Grover, 2022), adopting its masked Transformer encoder as the deterministic path, and extends the broader Neural Process lineage (CNP → ANP/CANP → BANP → MPANP → TNP) by adding two components: a Dimension Aggregator Block (DAB) that projects variable-dimensional inputs into a fixed representation space via learnable linear projections, positional encoding, and self-attention, and a latent path with Transformer layers that captures functional uncertainty. The closest prior attempt at dimension-agnostic NPs is the Neural Diffusion Process (NDP, Dutordoir et al., 2023), which uses bi-dimensional attention but is only partially dimension-agnostic (x when y=1) and relies on expensive diffusion-based sampling. DANP departs from all prior NPs, which assumed fixed input/output dimensions and required separate model training per dimensional configuration.

## Why It Matters / Open Questions

By enabling a single model to handle diverse input/output dimensions, DANP opens the door to using NPs as general-purpose regressors across heterogeneous tasks (e.g., hyperparameter optimization with 6–16 dimensions, image completion with 1 or 3 channels) without retraining per task. The zero-shot generalization to unseen dimensions and the strong fine-tuning results on limited data (where baselines collapse to negative log-likelihood) suggest practical value for few-shot adaptation in real-world settings like Bayesian Optimization. Key limitations include the focus on regression only, the reliance on knowing the output dimension at inference time, and the modest from-scratch improvements over TNP; the authors identify pre-training a dimension-agnostic encoder as a foundation model and extending to classification as natural next steps.

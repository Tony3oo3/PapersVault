## Problem

When noise and speech components are highly similar (e.g., babble noise, echoes), conventional SE networks struggle to learn discriminative patterns, leading to over- or under-estimation of noise. Existing dual-branch approaches that directly predict noise as supervision are limited by the inherent unpredictability of noise, making their performance still heavily dependent on the speech prediction branch. The paper addresses how to extract more discriminative speech-noise patterns within the mixture without requiring explicit noise signal prediction.
![Teaser figure](../imgs/ICLR20251189/cropped_page1_idx1.webp)

## Input / Output

The input is a 16 kHz noisy speech signal segmented into 4-second clips, converted via STFT (32 ms Hanning window, 16 ms frame shift) into a complex spectrogram. The magnitude is power-law compressed (factor 0.3) and concatenated with the wrapped phase to form a 2-channel input feature. The network outputs a PReLU-activated magnitude mask (element-wise multiplied with the input magnitude) and a phase residual (added to the noisy phase and normalized), which are combined via inverse STFT to produce the enhanced waveform.

## Method

FIRING-Net implements a Filter-Recycle-Interguide (FRI) strategy across two module types. The Local Module (LM) produces coarse target features via a convolutional layer, computes the residual (input minus output) as non-target features, then refines both through a dilated DenseNet (dilation factors {1,2,4}); interaction modules (IM-E in the encoder, IM-D in the decoder) then enable mutual guidance—IM-E extracts speech from non-target features and filters noise from target features using complementary sigmoid-based masks, while IM-D fuses speech information from both feature sets for reconstruction. The Global Module (GM) employs FRI-MHSA, which segments the qk^T attention map into four 25% energy-based regions and uses the highest-energy region to guide speech extraction from mid-low regions and the lowest-energy region to guide noise extraction from mid-high regions via cross-similarity matrix multiplication. The architecture alternates time and frequency processing in a dual-path Conformer structure (4 GMs), with 3 LM-Es in the encoder and 3 LM-Ds in each of the magnitude and phase decoders. Training uses a composite loss combining time-domain L1, magnitude L2, complex L2, and anti-wrapping phase losses (weights 0.2, 0.9, 0.1, 0.3) over 120 epochs with Adam (lr=0.001, halved on 15-epoch plateau).

## Results

On WSJ0-SI 84 + NOISEX-92, FIRING-Net (1.81M params) achieves STOI 0.8414 / PESQ 2.51 / SI-SNRi 16.11 dB at −5 dB SNR, outperforming the strongest baseline MP-SENet (2.05M) by 0.08 PESQ and 0.43 dB SI-SNRi. On AVSpeech + AudioSet under babble noise, FIRING-Net reaches PESQ 3.17 and SI-SNRi 13.85 dB, a ~3% relative PESQ gain over MP-SENet (3.07 / 13.24). On the DNS Challenge test set, FIRING-Net attains WB-PESQ 3.632 and STOI 96.65% with reverb, surpassing all 12 compared methods. The model uses fewer parameters (1.81M) than MP-SENet (2.05M), CMGAN (1.83M), and most other baselines while achieving the best scores.

## Baselines & Comparisons

FIRING-Net outperforms all five main baselines (PHASEN, SN-Net, Inter-SubNet, CMGAN, MP-SENet) on every metric (STOI, PESQ, SI-SNRi) across all three SNR levels on WSJ0-SI 84 + NOISEX-92 and all four noise types on AVSpeech + AudioSet. The closest competitor is MP-SENet, which uses a parallel magnitude-phase denoising architecture; FIRING-Net leads it by 0.08–0.10 PESQ and 0.4–0.6 dB SI-SNRi at each SNR level, while using fewer parameters (1.81M vs. 2.05M). CMGAN (Conformer-based Metric-GAN) is the second-closest baseline, trailing FIRING-Net by 0.13 PESQ and 1.82 dB SI-SNRi at −5 dB. PHASEN, SN-Net, and Inter-SubNet, which rely on interactive magnitude-phase, dual-branch speech-noise, or subband interaction strategies respectively, show the largest gaps (0.26–0.29 PESQ below FIRING-Net at −5 dB), confirming that the Filter-Recycle-Interguide framework provides a more effective feature separation mechanism than these interaction paradigms. On the DNS Challenge benchmark (Table 7), FIRING-Net also leads all 12 compared methods including TaylorSENet, FullSubNet+, and MFNet, achieving WB-PESQ 3.632 and STOI 96.65% with reverb.

## Relation to Prior Work

This paper departs from the dual-branch paradigm (e.g., SN-Net, DB-AIAT) that attempts to jointly predict both speech and noise, arguing that direct noise prediction is infeasible due to noise's stochastic nature. Instead, FIRING-Net repurposes the residual between input and network output as 'non-target features' (inspired by back-projection in super-resolution) and introduces a mutual-guidance mechanism between target and non-target features. Architecturally, it builds on the TF-Conformer encoder-decoder structure (CMGAN, MP-SENet) and incorporates dilated DenseNet for local refinement and a Top-K-inspired attention segmentation (FRI-MHSA) for global feature separation, but the core novelty lies in the Filter-Recycle-Interguide strategy rather than any single architectural component.

## Why It Matters / Open Questions

The FRI framework offers a principled alternative to noise-prediction-based approaches for handling highly similar speech-noise scenarios (babble, echoes), where conventional SE models over- or under-estimate noise. The finding that filtered-out residuals still contain recoverable speech information (ablation: SI-SNRi drops from 13.96 to 9.17 in LM-E when non-target features are removed) validates the recycling hypothesis and suggests a general design pattern applicable beyond SE. However, the phase decoder's compatibility with the FRI framework remains uncertain, real-time performance (0.60s CPU RTF) limits deployment, and the authors acknowledge the need for lighter-weight variants for edge devices.

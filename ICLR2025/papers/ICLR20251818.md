## Problem

Diffusion-based feature imputation methods work well on homogeneous graphs but fail on heterogeneous graphs for two reasons: non-attributed nodes (lacking features entirely) block the diffusion pathway, and treating all edge types equally ignores the distinct relational semantics each edge type encodes. Existing heterogeneous graph methods assume all attributed nodes have complete features, leaving the coexistence of undefined features and missing features within attributed nodes unaddressed.

## Input / Output

The method takes a heterogeneous graph with multiple node and edge types where only one node type (attributed nodes) carries a feature matrix X ∈ R^{N+×F} with a fraction r_m of entries set to NaN, while all other node types have no features. The output is a complete imputed feature matrix X̂′ ∈ R^{N+×F} for the attributed nodes only, produced without any neural network training and fed directly to a downstream GNN (e.g., HGT, HGNN-AC, or GCN) for semi-supervised node classification or link prediction. The imputation is performed channel-wise, and the number of diffusion steps K is set to 100 to approximate the steady state.

## Method

HetGFD operates in two diffusion stages. In the preliminary diffusion, virtual features (initialized to zero) are assigned to all non-attributed nodes, and a channel-wise transition matrix is constructed using edge-type-normalized weights |E_r|^{-1} to prevent biased propagation along majority edge types; this yields a pre-imputed matrix for all nodes. From this matrix, edge-type-wise homophily H(r) is computed as the ratio of average cosine similarity over edges of type r to the global average similarity, producing a ranking of edge types. In the relation-aware diffusion stage, pseudo-confidence (PC) is calculated on a weighted graph where low-ranking edges receive inflated weights β^{-(k-1)}, causing PC to drop rapidly for features reachable only through low-homophily paths. The final transition matrix assigns each directed edge a weight β^{k-1}·ξ_{j,d}/ξ_{i,d}, simultaneously favoring high-ranking edge types and strengthening message passing from high-PC to low-PC features, after which K iterative diffusion steps produce the imputed matrix.

## Results

On semi-supervised node classification with HGT at r_m=0.995 (structural missing), HetGFD achieves 85.87% Macro-F1 on ACM, 90.88% on DBLP, and 46.88% on IMDB, outperforming the strongest baseline PCFI+VF (84.47%, 90.41%, 46.64%) by 1.4–1.8 points. For link prediction at the same missing rate, HetGFD reaches 78.25% AUC on ACM and 91.94% on DBLP, surpassing PCFI+VF (73.41%, 71.37%) by 4.8 and 20.6 points respectively. On the biomedical PPI dataset, HetGFD maintains a consistent 1.0–2.5% accuracy advantage over PCFI+VF across all missing rates (r_m ∈ {0.5, 0.9, 0.995}).

## Baselines & Comparisons

HetGFD outperforms all seven baselines across every dataset and task setting. Against the closest competitor PCFI+VF (Um et al., 2023), HetGFD gains 1.4% Macro-F1 on ACM and 0.5% on DBLP for node classification, but the gap widens dramatically for link prediction on DBLP (91.94% vs 71.37% AUC, +20.6 points), where PCFI's unweighted shortest-path distance fails to exploit edge-type structure. FP+VF (Rossi et al., 2022) trails HetGFD by 2.7% on ACM and 1.5% on IMDB for node classification, confirming that relation-aware diffusion adds value beyond basic feature propagation. Traditional imputation methods (kNN, SVD, GAIN from Troyanskaya/Yoon) cluster within 0.5% of each other and are 2–3% below HetGFD on ACM, while GRAFENNE (Gupta et al., 2023) collapses to near-random performance (18.65% on DBLP, 27.20% on IMDB), indicating that GNN-based heterogeneous feature learning is highly sensitive to extreme missingness. On the PPI biomedical dataset, HetGFD's advantage over PCFI+VF grows with missing rate (1.0% at r_m=0.5 to 1.5% at r_m=0.995), attributed to its ability to preferentially diffuse along high-homophily edge types (type A over type B).

## Relation to Prior Work

This paper extends diffusion-based feature imputation (FP by Rossi et al. 2022, PCFI by Um et al. 2023) from homogeneous graphs to heterogeneous graphs, where prior methods cannot operate due to non-attributed nodes blocking diffusion and multiple edge types representing distinct relations. It departs from heterogeneous graph attribute-completion methods (Jin et al. 2021, Wang et al. 2022, He et al. 2022) that assume all features in attributed nodes are fully observed, by simultaneously handling undefined features for non-attributed nodes and missing features within attributed nodes. The virtual feature scheme (zero-initializing non-attributed nodes) serves as a minimal bridge enabling existing diffusion methods to transfer to heterogeneous graphs, while edge-type-wise homophily introduces a new criterion for relation-aware distance encoding that goes beyond prior distance-encoding approaches (DHN, P-GNN) which treat all edges uniformly.

## Why It Matters / Open Questions

Heterogeneous graphs with partially observed features are prevalent in real-world domains (biomedical networks, citation graphs, social networks), yet imputation in this setting was largely unaddressed. The virtual feature scheme is a simple, training-free mechanism that makes any existing diffusion-based imputation method applicable to heterogeneous graphs, broadening the utility of this method family. The paper acknowledges limitations: effectiveness may degrade on feature-heterophilic heterogeneous graphs where most paths between attributed nodes are heterophilic, and the method assumes all nodes of a given type share features of the same nature and scale. Open questions include handling multiple attributed node types with heterogeneous feature dimensions simultaneously, and whether the edge-type-wise homophily criterion generalizes to dynamic or temporal heterogeneous graphs.

## Problem

In the distributed sketching setting, where sketches S(A) and S(B) must be computed independently using only a shared random seed, classical linear sketching methods (JL projection, CountSketch) require sketch sizes of O(d/ε²) and O(m/ε²) regardless of matrix sparsity. The paper asks whether coordinated random sampling can match these worst-case guarantees while producing dramatically smaller sketches when A and B are sparse, and whether this is possible without any communication between the two sketching processes.

## Input / Output

The method takes two matrices A ∈ ℝ^{n×d} and B ∈ ℝ^{n×m} (or A and a vector b for regression) along with a shared random seed, and produces compact sketches S(A) and S(B) each containing at most k sampled rows (indices, row values, and a threshold τ). The estimation routine intersects the sampled index sets and computes a weighted sum of outer products over shared indices. For regression, the output is an approximate least-squares solution x̃ satisfying ||Ax̃ − b||² ≤ ||Ax* − b||² + ε||b||², with the A-sketch using leverage-score-based ranks and the b-sketch using magnitude-based ranks.

## Method

The core mechanism is Priority Sampling: a shared hash function h: [n]→[0,1] assigns each row i a rank R_i = h(i)/||A_i||² (or h(i)/ℓ_i for leverage-score regression), and the k smallest ranks are retained. Because both machines use the same h, rows with large norms in both A and B are likely to appear in both sketches, enabling an unbiased estimate W = Σ_{i∈T} A_i B_i^T / min(1, ||A_i||²·τ_A, ||B_i||²·τ_B) over the intersection T. The key technical challenge is that Priority Sampling is without-replacement, so sampled indicators are not independent; the paper resolves this by showing that appropriately scaled indicators are pairwise uncorrelated, yielding E[||W − A^T B||_F²] ≤ 2/(k−1)·||A||_F²||B||_F². For the regression variant, the d×d matrix A^T A is replaced by a spectral sparsifier (O(d/ε) leverage-score-sampled rows) to reduce sketch size from O(d² + ds/ε) to O(ds/ε) when A has s non-zeros per row.

## Results

The main theoretical result (Theorem 2) shows that Priority Sampling achieves Frobenius norm error ε‖A‖_F‖B‖_F with sketches of size O(s/ε²) when A and B have at most s non-zeros per row, compared to O(d/ε²) for linear sketching (JL, CountSketch). For matrices with only 2% non-zero entries per row, this translates to a 50× space savings over linear sketches. Empirically, across synthetic matrix multiplication, sketched regression (IMDB, Android reviews), and KV cache compression (LongBench MultiFieldQA with LLaMA-2), Priority Sampling consistently outperforms JL sketching, with the gap widening as sparsity increases, yielding an order-of-magnitude improvement in sketch size for equivalent accuracy.

## Baselines & Comparisons

The paper compares against two baselines: (1) Johnson-Lindenstrauss (JL) linear sketching, and (2) QJL (Zandieh et al., 2024), a 1-bit quantized JL method for KV cache compression. Against JL sketching, Priority Sampling matches performance on dense matrices but achieves an order-of-magnitude reduction in sketch size for sparse matrices (e.g., 50× at 2% sparsity), as shown in Figures 1–3. On the IMDB and Android regression tasks (Figures 2–3), Priority Sampling achieves lower approximation error at every sketch size compared to JL, with the advantage growing as dimensionality (and thus sparsity) increases. On the KV cache task (Figures 4–5), Priority Sampling outperforms both JL and QJL in accuracy for approximating QK^T across LLaMA-2 layers 0, 15, and 31. A key practical advantage over JL is that Priority Sampling can sketch only the Key matrix while leaving the Query unsketched (Figure 5), whereas JL requires projecting both Q and K, further reducing communication and storage costs.

## Relation to Prior Work

This paper extends the coordinated sampling framework (Priority Sampling, MinHash, KMV) from inner product estimation (Bessa et al. 2023; Daliri et al. 2024a,b) to general matrix-matrix product approximation, where the key technical challenge is handling the non-i.i.d. nature of without-replacement samples. It departs from the classical linear sketching paradigm (Sarlós 2006; Johnson-Lindenstrauss; CountSketch) and the subsampling approach of Drineas et al. (2006), which requires joint knowledge of both matrices' row norms for optimal sampling probabilities. The regression extension (Theorem 3) adapts leverage score sampling (Drineas et al. 2006b; Cohen et al. 2015b) to the independent-sketching setting by pairing leverage-score-based sampling of A with magnitude-based sampling of b, a combination not previously analyzed under the no-communication constraint.

## Why It Matters / Open Questions

For sparse matrices (common in NLP embeddings, TF-IDF, SPLADE, and transformer KV caches), the method achieves O(s/ε²) sketch size versus O(d/ε²) for linear sketching, yielding order-of-magnitude space savings that translate directly into communication and storage reductions in distributed and streaming settings. The KV cache compression experiments on LLaMA 2 suggest practical relevance for LLM inference, though evidence is limited to a single model and benchmark. Open questions include whether the Markov-based high-probability bound can be tightened, how the method behaves under adversarial or highly skewed row-norm distributions, and whether the regression guarantee extends to settings where A's leverage scores are expensive to compute at scale.

## Problem

Existing generative retrieval methods (DSI, NCI, TIGER, etc.) construct hierarchical indices by clustering pre-trained item representations in Euclidean space, decoupling index construction from the retrieval model. This one-sided, query-agnostic approach limits index quality because it ignores the rich query-item interaction space, and the decoder merely memorizes a fixed index rather than participating in its construction.
![Teaser figure](../imgs/ICLR20253317/cropped_page4_idx0.webp)

## Input / Output

The method takes a text query (or user behavior sequence in recommendation settings) and a set of items (with text descriptions or IDs) as input. Encoders on both the query and item sides extract features that are fed into a shared Transformer decoder, which produces probability distributions over k tokens at each of L hierarchical layers. At inference, beam search generates top-b token sequences identifying candidate buckets, and a ranker scores items within those buckets via inner product to return the final top-k results. Items are represented as sequences of discrete token IDs rather than continuous embedding vectors.

## Method

URI unifies the retriever and indexer within a single Transformer decoder that simultaneously learns query-item relevance and constructs the index. Training simulates an EM algorithm: the E-step uses cross-entropy to align the query's token distribution with the expected distribution of its positive items, while the M-step uses cross-entropy (item-to-query), a commit loss pushing item distributions toward one-hot, and an adaptive-weighted balance loss enforcing uniform token usage across the item set. The decoder is trained layer-by-layer, with a balanced assignment algorithm explicitly allocating items to tokens between layers, and a memory reinforcement loss prevents forgetting of earlier layers. A new model-independent metric, Average Partition Entropy (APE), measures index quality by evaluating how concentrated each query's positive items are within the index, enabling direct comparison of indices without training.

## Results

URI achieves state-of-the-art generative retrieval performance across all three datasets. On KuaiSAR, URI reaches Recall@10 of 0.1793 and NDCG@10 of 0.0925, improving over the best original baseline (DSI, R@10=0.0976) by 83.7%. On Amazon Beauty, URI attains R@10=0.0157 and NDCG@10=0.0067 (49.5% improvement over DR), and on Toys and Games, R@10=0.0573 and NDCG@10=0.0373 (33.6% improvement over DR). Additionally, replacing baselines' original indices with URI's index consistently improves their performance, confirming the index quality.

## Baselines & Comparisons

URI outperforms all five generative retrieval baselines (DSI, NCI, RecForest, TIGER, DR) on every dataset and metric. On KuaiSAR, URI's R@10 of 0.1793 surpasses the strongest original baseline DSI (0.0976) by 83.7%, and even exceeds DR with URI's index (0.1124) by 59.5%. On Amazon Beauty, URI (R@10=0.0157) beats DR (0.0105) by 49.5% and RecForest (0.0102) by 53.9%. On Toys and Games, URI (R@10=0.0573) outperforms DR (0.0429) by 33.6% and DSI (0.0486) by 17.9%. Notably, swapping in URI's index improves every baseline to varying degrees (e.g., DR on KuaiSAR jumps from R@10=0.0604 to 0.1124), demonstrating that URI's index is broadly effective across different model architectures. The APE analysis further confirms URI's index quality: URI achieves APE of 0.654 (k=32) on KuaiSAR versus 0.909–0.922 for RQ-VAE/VQ-VAE, indicating significantly tighter clustering of relevant items.

## Relation to Prior Work

This paper builds directly on the generative retrieval line of work initiated by DSI and NCI, which introduced Transformer decoders to replace ANN search by having the model autoregressively generate item token sequences. Prior methods (DSI, NCI, RecForest, TIGER, DR) all follow a two-stage paradigm: first construct a hierarchical index via clustering (K-means, VQ-VAE, RQ-VAE) in a pre-trained representation space, then train the decoder to memorize that fixed index. URI departs from this by unifying index construction and decoder training into a single differentiable process, drawing on the EM algorithm framework used by DR (Gao et al., 2021) but making it end-to-end via loss functions rather than iterative re-clustering. The APE metric is conceptually inspired by mutual information but applied as a model-independent index quality measure, which no prior generative retrieval work provided.

## Why It Matters / Open Questions

The core insight—that indices built in the query-item interaction space outperform those built by clustering item representations in Euclidean space—challenges a foundational assumption in generative retrieval and offers a principled alternative. The APE metric is practically valuable as a model-independent diagnostic that can evaluate index quality before any training, potentially saving significant compute. However, the approach requires layer-by-layer training and encoders on both query and item sides, adding architectural complexity; the paper acknowledges that simultaneous multi-level token generation remains an open problem. The experimental scope is limited to three datasets and comparisons are restricted to generative retrieval baselines, leaving open how URI compares to strong traditional retrieval systems at scale.

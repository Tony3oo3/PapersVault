## Problem

Decomposed Prompt Tuning (DePT) improves over vanilla Prompt Tuning by adding position-based token embedding offsets via a low-rank matrix product, but these offsets are fixed per position rather than per token. This causes two issues: the same token receives different offsets depending on its position (violating embedding uniqueness), and the offsets become extremely small (mean absolute value ~0.01 vs. ~6.07 for input embeddings) to maintain uniqueness, leading to sub-optimization of the embedding space.

## Input / Output

The method takes a tokenized input sequence (embeddings E ∈ R^{s×d}), a short soft prompt of length l_{s2} (e.g., 60 tokens for T5-base), and a token-shared two-layer bottleneck MLP (W_down ∈ R^{d×r}, W_up ∈ R^{r×d}, with biases). It produces updated token embeddings E' = E + ReLU(E·W_down + b_1)·W_up + b_2, which are concatenated with the short soft prompt and fed into a frozen PLM. The bottleneck size r is chosen so that total trainable parameters (short prompt + FFN) stay at or below vanilla PT's parameter budget (e.g., 76.1K vs. 76.8K for T5-base), while the shorter prompt yields faster inference than vanilla PT.

## Method

ADePT replaces DePT's fixed position-based offset matrix AB with a function f(e) of each token's own embedding, implemented as a shallow two-layer MLP (down-projection to bottleneck dimension r, ReLU, up-projection back to d) that is shared across all token positions. This makes the offset adaptive to the actual input: the same token always receives the same offset regardless of position, and different tokens receive different offsets, restoring embedding uniqueness while allowing larger, more expressive offsets. A short soft prompt is prepended to the updated embeddings, and only the prompt and FFN parameters are optimized. Theoretical analysis of the first self-attention layer shows that, unlike vanilla PT (which only scales attention and adds a constant bias), ADePT can alter relative attention patterns and introduce an input-dependent bias, giving it strictly greater expressive power. The approach is orthogonal to other PT improvements (layer-wise prompts, residual reparameterization, transfer learning) and can be combined with them.

## Results

On the T5-base model, ADePT achieves a GLUE mean of 86.6 and SuperGLUE mean of 77.4 with only 76.1K trainable parameters, surpassing full fine-tuning (84.9 / 73.9 with 220M params) and LoRA (85.3 / 76.5 with 3.8M params). ADePT outperforms its direct predecessor DePT (85.9 / 76.5) by 0.7 and 0.9 points on GLUE and SuperGLUE means respectively, while using fewer parameters (76.1K vs 76.8K). On the T5-3B model, ADePT achieves a mean F1 of 79.2 across six large tasks, outperforming both PT (79.0) and DePT (78.4) with the same 101.4K parameter budget. On the MBPP code generation benchmark, ADePT achieves 17.86 pass@1 on CodeGen-350M and 43.22 on Llama3-8B, beating DePT (16.83 / 42.50) and PT (16.12 / 18.27) with comparable parameter counts.

## Baselines & Comparisons

ADePT consistently outperforms all PT-style baselines: it beats vanilla PT by 1.8 points on GLUE mean and 17.4 points on SuperGLUE mean (77.4 vs 60.0), demonstrating that adaptive token offsets are far more effective than a longer static soft prompt. Against DePT, ADePT gains 0.7 (GLUE) and 0.9 (SuperGLUE) points with fewer parameters, confirming that position-independent, input-adaptive offsets resolve DePT's sub-optimization problem. ADePT also surpasses LoRA (3.8M params) by 1.3 GLUE and 0.9 SuperGLUE points while using 50× fewer trainable parameters, and outperforms full fine-tuning (220M params) by 1.7 GLUE and 3.5 SuperGLUE points. Among multi-task/transfer-learning variants, ADePT beats MPT(m) (10.5K params) by 0.8 GLUE and 1.3 SuperGLUE points without requiring pre-trained source-task prompts. On the T5-3B model, DePT actually underperforms vanilla PT (78.4 vs 79.0 mean F1), while ADePT recovers and exceeds both (79.2), highlighting that position-based offsets become particularly harmful at scale. On decoder-only models (Llama3-8B), ADePT achieves 43.22 pass@1 on MBPP, beating DePT (42.50) and dramatically outperforming PT (18.27), though it remains slightly below LoRA (49.08) which uses 9.4M parameters.

## Relation to Prior Work

ADePT extends the prompt tuning lineage by replacing DePT's position-based token embedding offsets (a fixed low-rank matrix product AB) with a token-shared shallow feed-forward network that produces input-dependent offsets. It retains the short soft prompt from DePT to maintain fast inference while addressing two identified limitations: position-dependent offsets violate token embedding uniqueness, and the resulting offsets are so small (mean ~0.01 vs. input embeddings ~6.07) that they cause sub-optimization. The paper positions this as the 'fourth path' of PT improvements—input token embedding offsets—and notes it is orthogonal to layer-wise prompting, residual reparameterization, and transfer-learning-based prompt initialization.

## Why It Matters / Open Questions

ADePT offers a clean, theoretically grounded fix for a specific weakness in the PT family: it can modify relative attention patterns in the first transformer layer (unlike vanilla PT) while using the same parameter budget and achieving faster inference than full-length PT. However, the method shows clear limitations in few-shot settings (e.g., 32.1 on CB with 4-shot vs. 75.0 for DePT) and failed entirely on GSM8K with Llama3-8B, suggesting the shallow FFN struggles when training data is scarce or the embedding space is very large. An open question is whether deeper or more expressive offset networks could close the gap with LoRA on billion-scale models without sacrificing the parameter-efficiency and task-switching advantages of PT-style methods.

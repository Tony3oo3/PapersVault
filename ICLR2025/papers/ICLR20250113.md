## Problem

Existing deepfake detection datasets are predominantly unimodal, cover only a handful of generation techniques, and lack multi-lingual and real-world AIGC coverage, making it impossible to assess whether detectors generalize across modalities, languages, and unseen generative methods. The paper addresses this gap by introducing a large-scale benchmark that simultaneously spans identity swaps, fully synthetic media, and curated real-world forgeries across 26 languages and 28 generative models.
![Teaser figure](../imgs/ICLR20250113/cropped_page0_idx0.webp)

## Input / Output

The generation pipeline consumes 20-second video clips (512×512, H.264 at c23/c40), English transcriptions, and text prompts from COCO, MusicCaps, and MSRVTT, producing face-swapped videos, voice-cloned audio, and text-to-modality synthetic media. For detection benchmarking, visual models receive 10 frames per fake video (all frames for real) in Set A or 24 frames from synthetic vs. every 6th frame from real in Set B, outputting frame-level labels aggregated to video-level accuracy via a 50% threshold; audio models output EER and AUC. Set D adds 26-language synchronized audio-video pairs that stress-test cross-lingual generalization beyond the English-only training sets.

## Method

ILLUSION is organized into four sets: Set A (identity swaps via 6 face-swap + 7 voice-clone models with fingerprinting-based audio-video synchronization), Set B (fully synthetic AIGC from 11 open-source + 1 closed-source text-to-modality models including Stable Diffusion XL, MusicGen, and Text2Video-Zero), Set C (real-world viral deepfakes from Midjourney and ArtGuru), and Set D (multi-lingual, multi-modal real-world samples across 26 languages). The benchmark evaluates 11 detection methods under four protocols: same-distribution detection, zero-day cross-set generalization, real-world transfer, and model attribution. A central finding is that identity-swap artifacts and fully synthetic artifacts are fundamentally distinct, causing models trained on one category to perform at chance on the other, while multi-lingual and real-world settings further degrade performance to near-random levels, exposing the limited generalizability of current state-of-the-art detectors.

## Results

On the ILLUSION dataset, DSP-FWA achieves the best visual detection performance with 98.4% accuracy on Set A (identity swaps) and 99.3% on Set B (synthetic media), while SSLModel achieves the best audio detection with EER of 0.006 on both sets. However, zero-day generalization (Protocol 2) reveals a critical failure: all visual and audio models drop to ~50% (random) accuracy when trained on one set and tested on the other, indicating that identity-swap and fully-synthetic artifacts are fundamentally different. On real-world deepfakes (Set C), performance degrades severely—DSP-FWA drops from 98.4% (Set A) to 21.4% accuracy when tested on Set C, and multi-modal models (MRDF, FACTOR) achieve only 9–35% class-wise accuracy on the multi-lingual Set D.2.

## Baselines & Comparisons

The paper benchmarks 11 detection methods (4 visual, 4 audio, 2 multi-modal, 1 ensemble) across four protocols. For visual detection, DSP-FWA consistently dominates: it achieves 98.4% accuracy on Set A vs. 85.1% for F3Net and Xception, and 99.3% on Set B vs. 98.1% for F3Net; MesoInceptionNet is the weakest visual model, often near random (50.5% on Set A). For audio detection, SSLModel achieves the lowest EER (0.006 on Set A, 0.006 on Set B) compared to Conformer (0.025/0.005), AASIST (0.049/0.020), and RawGAT-ST (0.443/0.032). For multi-modal detection on Set A, MRDF outperforms FACTOR across all four classes (e.g., 87.1% vs. 41.3% on FA-FV), while Unimodal Ensembling (F3Net+SSLModel) is competitive on FA-FV (77.9%) but weak on RA-RV (20.8%). The most striking comparison is in zero-day generalization: every model drops to ~50% accuracy when cross-testing between Set A and Set B, demonstrating that no current detector generalizes across forgery types. On real-world Set C, models trained on Set B (synthetic) outperform those trained on Set A (identity swaps) by 50+ percentage points (72.7% vs. 21.4% for DSP-FWA), and on multi-lingual Set D.2, all multi-modal models collapse to 5–35% accuracy, with FACTOR (35% on RA-RV) marginally outperforming MRDF (31%) and Unimodal Ensembling (25%).

## Relation to Prior Work

This paper carves new ground in deepfake dataset construction by unifying four previously separate research threads—identity-swap forgeries (FaceForensics++, DFDC), text-to-modality AIGC (Midjourney Kaggle, TWIGMA), audio spoofing (ASVSpoof, TIMIT-TTS), and multi-lingual media—into a single 1.3M-sample resource generated by 28 distinct models. Prior multi-modal datasets (LAV-DF, AV-Deepfake1M, FakeAVCeleb) covered audio-video identity swaps but lacked non-identity AIGC, multi-lingual coverage, and real-world 'fakes in the wild.' The benchmarking protocol reuses well-established detection architectures (DSP-FWA, F3Net, AASIST, Conformer, MRDF, FACTOR) rather than proposing new detectors, positioning the contribution squarely as a dataset and empirical study.

## Why It Matters / Open Questions

The dataset's scale and diversity (28 generators, 26 languages, four manipulation types, real-world samples) make it a likely standard benchmark for the next generation of deepfake detectors. The empirical findings—that models show near-zero transfer between identity-swap and synthetic-media detection, and that audio detectors collapse to near-random AUC (~0.4–0.5) on 26-language data—expose a critical gap: current methods learn generator-specific artifacts rather than generalizable forgery signatures. Open questions include whether multi-lingual pre-training or cross-generator regularization can close the zero-day gap, and how to handle the inherent asymmetry in Set C (all-fake) that inflates some metrics. The near-perfect model attribution results (97–99% AUC) also raise practical questions about traceability and accountability of generative model operators.

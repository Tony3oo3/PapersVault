## Problem

Mainstream test-time adaptation methods rely on vanilla entropy minimization, which provably increases only the probability of the single most confident class while diminishing all others. In multi-label scenarios where an image contains multiple positive labels, this top-1 bias causes existing TTA methods (TPT, DiffTPT, RLCF) to actively impair the adaptation of remaining positive labels, with performance degrading sharply as the number of labels per image increases.

## Input / Output

The method takes a single unlabeled test image (batch size 1) and augments it N times to produce views; for each view, a paired caption is retrieved from an offline text description database (100k LLaMA-2-7B-generated descriptions per dataset) via CLIP similarity. The caption's nouns are extracted as a strong label set of size k, which simultaneously serves as the weak label set for the corresponding view. Output is a vector of L multi-label class probabilities, obtained by summing the adapted view-prompt and caption-prompt similarities to the original test image.

## Method

The core contribution is Bound Entropy Minimization (BEM), a new optimization objective proven to uniformly increase the probabilities of all top-k predicted labels (rather than only top-1) when those k logits are bound to equal values. Concretely, a label-binding operation adds a stop-gradient offset (m_i − s_ij) to each of the top-k logits so they become equal, after which standard softmax entropy is minimized over the modified logits. The framework learns two instance-level prompts (view prompt and caption prompt) with a single AdamW gradient step on the combined bound entropy of confident views and captions, then resets for the next test instance. Confidence selection (ratio τ=0.1) filters out noisy augmented views and their retrieved captions that may exclude the target label region.

## Results

On the COCO2014/2017 datasets, ML-TTA achieves 4–5% mAP improvement over the original CLIP model (e.g., 51.58 vs. 47.53 on COCO2014 with RN50; 57.52 vs. 54.42 with ViT-B/16), while TPT and DiffTPT yield only ~1% gains. Across all four CLIP architectures (RN50, RN101, ViT-B/32, ViT-B/16), ML-TTA achieves the highest average mAP (60.15, 61.13, 61.32, and 64.80 respectively), outperforming the strongest baseline TDA by 1.7–2.2 mAP points. On VOC2007/2012, ML-TTA maintains 2–3% improvement over CLIP, whereas TPT and DiffTPT actually degrade performance by 1–2%.

## Baselines & Comparisons

ML-TTA consistently outperforms all nine baselines across every architecture and dataset. Compared to the original CLIP, ML-TTA gains 4–5% mAP on COCO2014/2017 and 2–3% on VOC2007/2012, while TPT and DiffTPT achieve only ~1% on COCO and actually degrade by 1–2% on VOC. RLCF suffers catastrophic failure on smaller models (RN50 average drops to 46.78 vs. CLIP's 57.31), attributed to excessive optimization of the top-1 label through reinforcement learning distillation. Among online methods, TDA is the strongest baseline but still trails ML-TTA by 1.7–2.2 mAP on average; DMN shows slight performance decline on COCO for RN50/RN101. On NUSWIDE, all TTA methods (except TDA) fail to substantially improve over CLIP (~1% gain), which the authors attribute to low image resolution limiting augmentation effectiveness.

## Relation to Prior Work

This paper extends the test-time prompt tuning (TPT) paradigm from single-label to multi-label classification by identifying a fundamental incompatibility: vanilla entropy minimization provably increases only the top-1 class probability while suppressing all others, which is destructive when multiple labels are positive. The method draws on two prior threads — TPT's single-step prompt update with confidence-based view selection, and the 'text-as-image' caption retrieval strategy from PVP/TAI++ (Wu et al., 2024) — to construct a paired view-caption adaptation framework. The key conceptual departure is the Bound Entropy Minimization (BEM) objective, which mathematically binds the top-k logits to equal values before computing entropy, thereby converting a top-1-biased loss into a top-k-uniform one.

## Why It Matters / Open Questions

Multi-label classification is the more common real-world setting (scene understanding, medical imaging, e-commerce tagging), yet all prior TTA methods were designed and validated only for single-label tasks; this paper demonstrates they can actively degrade multi-label performance, a finding that cautions against blind application of TTA in multi-label pipelines. The BEM objective provides a clean, provable fix that requires no additional training data or architectural changes, making it broadly applicable to any CLIP-based TTA pipeline. Open questions include how to handle low-resolution images where augmentation destroys target regions (NUSWIDE results are weak across all methods), how to improve the reliability of LLM-generated caption retrieval, and whether the approach extends to other VLMs beyond CLIP.

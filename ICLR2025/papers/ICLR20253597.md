## Problem

Finding the exact Pareto front in Multi-Objective MDPs remains unsolved: existing methods either sample the continuous preference space (yielding hard-to-evaluate approximations) or identify only deterministic Pareto-optimal vertices without a principled way to reconstruct the full front from them. Even when the MDP is fully known and dynamic programming is available, the geometric structure of the Pareto front—particularly how stochastic policies on lower-dimensional faces relate to deterministic vertices—was previously uncharacterized.

## Input / Output

The method requires a fully specified, finite MO-MDP (known transition kernel P, D-dimensional reward tensor r, discount factor γ) and an initial state distribution μ with full support. It outputs the complete Pareto front as a collection of Pareto-optimal faces (edges, facets, and higher-dimensional faces of the return polytope) together with all deterministic Pareto-optimal policies as vertices. Unlike preference-sampling approaches that return a finite set of policies, the output is a geometric decomposition: each face is explicitly represented by its incident vertices and the convex-combination policies it parameterizes.

## Method

The key theoretical insight is a distance-one property: neighboring deterministic policies on the boundary of the return polytope differ in exactly one state-action pair almost surely, and the Pareto front is connected via edges. This reduces the global search to a local BFS traversal. Concretely, the algorithm (1) solves a single-objective MDP once with an arbitrary positive weight vector to obtain an initial vertex, (2) for each visited vertex π, evaluates all S×(A−1) distance-one neighbors, prunes dominated ones, (3) computes a local convex hull of the non-dominated neighbors plus π using an adapted Quickhull that only updates facets incident to π, and (4) extracts Pareto-optimal faces by solving a small linear program (Eq. 2) on the normal vectors of intersecting facets to verify the strictly-positive combination criterion (Lemma 3). The total number of iterations equals the number of deterministic Pareto-optimal vertices, and each iteration involves only local convex-hull computation rather than a global one.

## Results

The paper evaluates its Pareto front searching algorithm on small MDPs with state spaces of size 5 and 8, action spaces of 5–7, and reward dimensions of 3 (for full Pareto front recovery) and 4 (for vertex discovery). The algorithm successfully identifies all faces of the true Pareto front in every tested configuration. Against a benchmark that computes the convex hull of all non-dominated deterministic policies, the benchmark's runtime grows exponentially with the number of actions, becoming impractical even at moderate action space sizes, while the proposed algorithm maintains controllable runtime. Against OLS for finding all Pareto front vertices, the proposed algorithm's running time remains manageable as state and action spaces expand, whereas OLS's runtime increases sharply with even slight expansions.

## Baselines & Comparisons

The paper compares against two baselines. First, a benchmark algorithm (Algorithm 4) that computes the convex hull of all non-dominated deterministic policies and then applies the Pareto face extraction (Algorithm 2) to recover the full Pareto front. This benchmark's complexity grows exponentially with the number of actions because the number of deterministic policies is |A|^|S|, making it infeasible beyond small action spaces (Fig. 5). The proposed algorithm wins decisively on runtime by exploiting the distance-one property to build local convex hulls rather than a global one. Second, the paper compares against OLS (Roijers, 2016) for discovering all deterministic Pareto-optimal vertices. OLS iteratively solves a single-objective MDP along the most-improving preference direction and constructs a global convex hull of candidate preference vectors. The proposed algorithm requires only one single-objective solve (for initialization) and then traverses edges locally, achieving significantly lower computational complexity (Fig. 6). Both comparisons show the proposed method scaling more favorably with state and action space size, though the paper does not report exact runtime numbers in tabular form—results are presented as runtime plots in Figures 5 and 6.

## Relation to Prior Work

This paper builds on the dynamic programming tradition for MO-MDPs initiated by White (1982) and the vertex-finding OLS method of Mossalam et al. (2016), but departs fundamentally from both by exploiting a newly proven geometric property: neighboring deterministic Pareto-optimal policies differ by exactly one state-action pair almost surely. While prior approaches either traverse the continuous preference space (yielding approximations) or identify only deterministic vertices (insufficient to reconstruct the full front in 3D+), this work uses the distance-one property and a locality theorem to reduce the global search to a local convex-hull computation at each vertex, requiring only a single single-objective MDP solve for initialization. The algorithm also leverages Quickhull (Barber et al., 1996) adapted for incremental facet updates and the PPrune algorithm (Roijers, 2016) for non-dominated policy selection.

## Why It Matters / Open Questions

This is the first method to recover the exact full Pareto front (all faces, including lower-dimensional edges) in MO-MDPs without sampling the preference space, which is significant because in 3D+ the front cannot be reconstructed from vertices alone—a gap that has persisted since White (1982). The distance-one property and locality theorem provide a clean theoretical foundation that could inform algorithm design in related multi-objective settings. However, empirical validation is limited to very small MDPs (S≤8, A≤7, D≤4), and the method requires the MDP to be fully known (model-based), leaving open the question of whether these geometric properties and the traversal strategy extend to model-free MO-RL or larger-scale problems.

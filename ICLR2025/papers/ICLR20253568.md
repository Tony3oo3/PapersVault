## Problem

While GNN+RL has been applied to CDCL branch heuristics, the splitting heuristics in Divide-and-Conquer (D&C) SAT solvers remain unexplored by reinforcement learning despite being equally critical to performance. Moreover, D&C solvers exhibit tree-like (non-linear) state transitions that standard RL environments, designed for sequential Markov processes, cannot handle natively, making it difficult to formulate and train policies for this setting.
![Teaser figure](../imgs/ICLR20253568/cropped_page4_idx0.webp)

## Input / Output

At each split point, the method extracts a dynamic graph from the running CDCL solver (MapleCOMSPS), where nodes are variables and clauses (original, core, and tier2 learned clauses) with features including variable activity scores, clause LBD values, and global statistics (restart, decision, conflict, and propagation counts). The output is a probability distribution over currently valid (unassigned, non-eliminated) variables from which the split variable is sampled. In the CPU-once deployment mode, a single initial GNN call produces a static variable ranking that guides all subsequent splits without further neural network invocations.

## Method

RDC-SAT combines a GraphNets-based GNN (Encoder-Processor-Decoder with 4 message-passing steps) with an Actor-Critic network: the Actor assigns selection probabilities to valid variables via softmax over GNN-extracted variable features, while the Critic estimates state value from clause and global features using attention pooling. The key architectural novelty is a custom RL environment (PainlessEnv) built on the Painless D&C framework that stores all solving information in a binary tree to handle non-linear state transitions, with distinct discounted reward functions for SAT (using min of child solving times) and UNSAT (using max) problems, computed via post-order tree traversal. Training uses Distributed PPO (DPPO) with 5 CPU-based exploration agents continuously solving phase-transition random 3-SAT instances and a single GPU-based training agent that samples from a replay buffer, with ε-greedy exploration and reward normalization. The solver is deployed via TorchScript in two modes: RDC-GPU-always (GNN forward pass at every split) and RDC-CPU-once (single initial GNN call producing a variable ranking for all subsequent splits), with automatic fallback to default heuristics for very large instances.

## Results

On the Random 3-SAT dataset (141 instances), RDC-GPU-always solves 129/141 problems with an average clock time of 1064.43 s and a PAR2 score of 1489.96, reducing PAR2 by 25.08% over the best baseline (FLIPS, PAR2 1988.64). On the SAT Competition 2023 dataset (140 instances), RDC-GPU-always solves 135/140 problems with a PAR2 of 942.57, a 14.95% reduction over FLIPS (PAR2 1108.25). The GPU-free variant RDC-CPU-once still achieves 10.99% and 4.29% PAR2 reductions on the two datasets respectively, while incurring negligible splitting overhead (0.12% and 1.33% of total solving time for RDC-GPU-always).

## Baselines & Comparisons

RDC-GPU-always outperforms all four baselines (FLIPS, LRB, VSIDS, PR) on both datasets in PAR2, clock time, and number of problems solved. On the Random 3-SAT set, it beats the strongest baseline FLIPS by 25.08% in PAR2 (1489.96 vs. 1988.64) and LRB by 33.2% (1489.96 vs. 2229.49), while also solving 5 and 9 more instances respectively. On SAT Competition 2023, RDC-GPU-always reduces PAR2 by 14.95% over FLIPS (942.57 vs. 1108.25), 25.1% over VSIDS (942.57 vs. 1258.26), and 51.6% over PR (942.57 vs. 1948.14). The GPU-free RDC-CPU-once variant also beats every baseline on both datasets, though with smaller margins (e.g., 10.99% PAR2 reduction over FLIPS on Random, 4.29% on SAT COMP). FLIPS consistently emerges as the strongest traditional heuristic, while PR performs worst on the SAT Competition set (solving only 121/140) and was excluded from the Random dataset evaluation due to poor performance there.

## Relation to Prior Work

This paper extends the GNN+RL paradigm for SAT heuristic optimization (pioneered by Graph-Q-Sat for CDCL branch heuristics) to the underexplored domain of Divide-and-Conquer splitting heuristics, where the much lower invocation frequency makes neural network overhead practically manageable. It builds directly on the Painless D&C framework and borrows the single-call GNN strategy from NeuroBack for GPU-poor deployment. The key conceptual departure is formulating the D&C solving process as a tree-structured MDP rather than a linear one, requiring post-order reward computation and a custom RL environment that departs from standard Gym-style linear transitions.

## Why It Matters / Open Questions

This is the first work to apply reinforcement learning to D&C splitting heuristics, demonstrating that GNN-based optimization is viable in parallel SAT solvers where call frequency is low enough to avoid the overhead bottleneck that plagued CDCL branch-heuristic approaches. The RDC-CPU-once mode offers a practical path for GPU-poor environments, and the generalization from random 3-SAT to SAT Competition 2023 instances (14.95% PAR2 reduction) without domain-specific training is encouraging. However, the model is trained only on random instances, uses the older MapleCOMSPS sequential solver, and the GNN is large enough to limit scalability to very large problems—addressing these gaps (diverse training data, modern solvers, smaller networks) is essential before RDC-SAT can compete with state-of-the-art D&C solvers.

## Problem

Even GPT-4o-based web agents achieve less than 20% success on VisualWebArena compared to 89% for humans, primarily because they cannot balance exploration and exploitation over long horizons or learn from past mistakes. Existing search-augmented agents (Tree of Thought, Search Agent) rely on fixed best-first strategies, cannot adapt from prior task executions, and discard the knowledge gained during search rather than transferring it back into the model weights.

## Input / Output

The agent receives a natural-language task goal, a Set-of-Mark (SoM) augmented webpage screenshot (bounding boxes with unique integer IDs overlaid on each interactive element), and the running action-observation trajectory. At each step it emits one action from a 12-type web action space (click, type, scroll, goto, stop, etc.) referencing SoM element IDs; the value function outputs a scalar in [0,1], and the multi-agent debate variant produces two opposing textual arguments before a judge VLM selects a final status code (A–E) mapped to a numeric value. For the fine-tuning stage, GPT-4o is trained on text-only modality (no images) due to API limitations, using multi-turn chat formatting of flattened tree traversals.

## Method

EXACT combines two components. First, Reflective MCTS (R-MCTS) extends classic MCTS with (a) contrastive reflection: after each episode, the agent identifies the most erroneous actions by computing |V(o_{t+1}) − Q(o_t, a_t)| (analogous to TD error), prompts the VLM to predict the expected next observation, contrasts it with the actual observation to generate a natural-language reflection, and stores it in a vector database keyed by embedding of (task, state); at inference time, the top-m most similar reflections are retrieved and appended in-context to improve the policy and value functions; and (b) a multi-agent debate value function where two VLMs generate opposing arguments about whether the current state is promising, and a third VLM renders a final judgment. Second, Exploratory Learning (EL) fine-tunes GPT-4o not on the final best actions (as in Imitation Learning) but on the flattened sequence of all MCTS tree traversals—explorations, evaluations, and backtracks—teaching the model to internally simulate, assess, and backtrack at inference time without any external search algorithm, recovering 87% of R-MCTS performance at 2.7× lower inference cost.

## Results

On VisualWebArena, R-MCTS with multi-agent debate (R-MCTS_MAD) achieves 41.0% success on Classifieds, 28.7% on Reddit, 32.3% on Shopping, and 23.5% on GitLab (WebArena), representing a 6%–30% relative improvement over the previous state-of-the-art (Search Agent). R-MCTS with a single-agent value function improves over plain MCTS by an average of 2.2 points, and adding multi-agent debate yields a further 1.6-point gain. After Exploratory Learning, the fine-tuned GPT-4o recovers 87% of R-MCTS_MAD's performance (27.8% vs. 32.1% overall on Classifieds) while reducing inference cost by 2.7×, and achieves 18.6% on unseen tasks versus 12.4% for Imitation Learning.

## Baselines & Comparisons

R-MCTS_MAD outperforms all search-augmented baselines across every VWA environment. Against the previous SOTA Search Agent (Koh et al., 2024b), R-MCTS_MAD improves by 7.2 points on Classifieds (41.0% vs. 33.8%), 6.8 points on Reddit (28.7% vs. 21.9%), 2.0 points on Shopping (32.3% vs. 30.3%), and 9.7 points on GitLab (23.5% vs. 13.8%). Over plain MCTS with a single-agent value function, R-MCTS_MAD gains 3.4 points on Classifieds and 3.6 points on GitLab, with the multi-agent debate component contributing an additional ~1.6 points on average. On OSWorld, R-MCTS (19.39% overall with screenshot+accessibility tree) is competitive with Agent-S (20.58%, which uses web search) and AgentStore-AT (23.85%, which uses 20+ specialized agents and fine-tuning), while using only a single GPT-4o model with no additional resources. The Exploratory Learning fine-tuned model (27.8% overall, 18.6% unseen on Classifieds) substantially outperforms REACT (22.2%) without any search at inference time, and generalizes better to unseen tasks than Imitation Learning (12.4% unseen).

## Relation to Prior Work

This paper extends the search-augmented agent line (Tree of Thoughts, Search Agent, LATS) by replacing best-first or A*-style search with MCTS augmented by two novel components: contrastive reflection (inspired by Reflexion and human cognitive learning) that updates the policy/value in-context from past mistakes, and multi-agent debate for more reliable state evaluation. It further departs from prior work by proposing Exploratory Learning, which fine-tunes the VLM on full MCTS tree traversals (exploration, evaluation, backtracking) rather than only on the final selected actions as in standard imitation learning. The overall framing positions the work as a bridge between test-time compute scaling (o1, Snell et al.) and self-improving agents, creating a loop where search generates training data that internalizes search behavior into the model.

## Why It Matters / Open Questions

The paper demonstrates that test-time compute scaling (both search budget and number of actions) transfers to agentic web navigation, and that knowledge from search can be partially internalized via fine-tuning, reducing inference cost by 2.7× while recovering 87% of search performance. Key limitations include the high token cost of R-MCTS (~10× ReACT), the learning experiments being restricted to a single environment (Classifieds) and text-only modality due to GPT-4o fine-tuning constraints, and the error analysis revealing that most remaining failures stem from GPT-4o's fundamental image and web understanding gaps rather than planning. Open questions include whether the self-learning loop (search → reflect → fine-tune → search) can be iterated to compound gains, whether Exploratory Learning generalizes to other VLMs or task domains, and whether the compute scaling properties hold as environments grow in complexity.

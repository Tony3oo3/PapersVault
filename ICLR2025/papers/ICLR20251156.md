## Problem

Existing layout control methods for text-to-image diffusion models are restricted to 2D bounding boxes, require the full layout to be specified statically before generation, and produce entirely different images when any layout element is modified. This makes them unsuitable for interactive applications like interior design or complex scene composition where users need 3D positional control over individual objects and must iteratively refine the scene while preserving already-generated content.
![Teaser figure](../imgs/ICLR20251156/cropped_page0_idx0.webp)

## Input / Output

At each generation stage, the user specifies a single 3D bounding box (position, scale, in-plane rotation) and a text prompt for the object it contains, along with global camera parameters (intrinsics, viewpoint) and scene boundary planes. These 3D elements are rendered into a depth map and foreground/background masks that condition the diffusion model via LooseControl's depth-conditioned ControlNet. The output is a single RGB image in which the newly added object is seamlessly integrated with physically plausible shadows and reflections, and all previously generated objects remain visually unchanged.

## Method

Build-A-Scene reformulates T2I generation as a sequential multi-stage process built on LooseControl (a depth-conditioned ControlNet over Stable Diffusion 1.5), where each stage adds one object. The key architectural contribution is a Dynamic Self-Attention (DSA) module that augments the self-attention keys and values with the full key/value set from the previous stage plus a foreground-masked window of the current stage's keys, enabling the model to freely generate a new object style while copying the overall scene style from prior stages. A latent blending step (Eq. 5) further preserves background pixels by compositing the previous stage's latents in the background mask region, and optional AdaIN harmonizes color statistics. For consistent 3D translation, the method segments the target object via cross-attention accumulation and SAM, warps it to the new 3D position using Cartesian coordinate correspondences from rendered box corners, inverts the warped image through DDIM to obtain a latent trajectory, and blends this trajectory with the pre-translation scene latents over a partial denoising window (Eq. 6). The entire pipeline is training-free and plug-and-play, requiring no fine-tuning or guidance-based backpropagation.

## Results

On the proposed 3D layout control benchmark (100 random layouts × 5 seeds), Build-A-Scene achieves 53.5% Object Accuracy (OA), 0.772 mIoU, and 0.88 3D-Dir adherence, outperforming LooseControl (24.3% OA, 0.633 mIoU, 0.65 3D-Dir) by roughly 2× on object generation success and the 2D Layout-Guidance (48.2% OA, 0.425 mIoU) by ~15% on OA. For object consistency under layout change, the method scores 0.463 SSIM, 29.3 dB PSNR, and 22° 3D-Rot deviation, beating both baselines on all consistency metrics. Runtime is 6 s per stage, between LooseControl (2 s) and Layout-Guidance (12 s).

## Baselines & Comparisons

Against LooseControl (the depth-conditioned 3D-box baseline the method builds upon), Build-A-Scene more than doubles Object Accuracy (53.5% vs. 24.3%), improves mIoU from 0.633 to 0.772, and raises 3D-Dir adherence from 0.65 to 0.88, while matching its CLIP_I2I score (0.924) and slightly edging out its PSNR (29.3 vs. 29.12 dB) and 3D-Rot (22° vs. 27°). Against the 2D Layout-Guidance method, Build-A-Scene wins on OA (53.5% vs. 48.2%), mIoU (0.772 vs. 0.425), SSIM (0.463 vs. 0.189), 3D-Dir (0.88 vs. 0.48), and 3D-Rot (22° vs. 29°), while CLIP_T2I is essentially tied (0.321 vs. 0.323). The only metric where Build-A-Scene is slower is runtime (6 s vs. 2 s for LooseControl), though it is still half the time of Layout-Guidance (12 s). Overall, the method dominates on both the layout-control and object-consistency sub-tasks, with the sole trade-off being a modest increase in per-stage inference time over LooseControl.

## Relation to Prior Work

This paper builds directly on LooseControl (Bhat et al., 2024), which introduced rendered 3D boxes and planes as depth-conditioning signals for Stable Diffusion via ControlNet, but repurposes it within a multi-stage interactive pipeline where objects are added sequentially rather than all at once. It departs from the broader 2D layout control literature (Layout-Guidance, BoxDiff, Zest) by replacing 2D bounding boxes with 3D boxes and by introducing the Dynamic Self-Attention (DSA) module, which augments attention keys with both the previous stage's full keys and a masked window of the current stage's keys—distinct from cross-frame attention (MASACTRL, Text2Video-Zero) that copies style wholesale, and from extended attention (FATE-Zero) that mixes multiple references uncontrolled. The Consistent 3D Translation strategy, which warps a segmented object using Cartesian coordinate correspondences and blends DDIM-inverted latents, is a novel contribution not present in prior layout or consistency work.

## Why It Matters / Open Questions

This is the first approach to combine interactive 3D layout control with object identity preservation under layout changes, addressing a practical gap in interior design and complex scene generation where users need to iteratively refine object placement. The training-free, plug-and-play nature of DSA and the translation strategy makes the technique broadly applicable to any depth-conditioned diffusion model. Key limitations include sensitivity to box aspect ratios, dependence on segmentation quality for the translation strategy, and the computational overhead of multi-stage generation. Open questions include whether the approach extends to in-plane rotations, whether LLM-driven automated layout generation can replace manual box placement, and whether the DSA mechanism generalizes beyond two-object scenes to more complex multi-object interactions.

## Problem

Existing virtual agent environments are domain-specific (web-only, mobile-only, or desktop-only), restrict observations to screenshots or text, and limit actions to a single modality (GUI or API), preventing evaluation of agents on the full range of real-world computer tasks. Moreover, current benchmarks rely solely on overall success rates without decomposing fundamental capabilities like UI grounding, video-based action learning, and success detection, and they lack tools for task creation, GUI annotation, and video action labeling.

## Input / Output

Agents receive multimodal observations—text (code execution results), screenshots, and screen-recording video frames—alongside a natural language instruction, and produce Python code blocks that invoke either GUI primitives (mouse.click, keyboard.type, keyboard.hotkey) or API calls (e.g., Google Workspace, terminal commands). For the fine-grained benchmarks, GroundUI maps an instruction plus screenshot to normalized (x, y) click coordinates in [0, 1] checked against ground-truth bounding boxes; IDMBench maps a sequence of up to six video frames to an ordered action-label sequence drawn from a platform-specific action space; CriticBench maps an instruction plus a multi-step trajectory (observation-action pairs or observations only) to a binary success/failure label. The environment runs in real time over VNC on Docker containers or physical machines, so observations reflect true dynamic state rather than delayed snapshots.

## Method

AgentStudio models each computer task as a POMDP (S, A, O, T, R, F, U) with a universal observation space O = O_Text ∪ O_Image ∪ O_Video and action space A = A_GUI ∪ A_API, implemented as a lightweight VNC-based interactive environment that provides both a binary reward R and natural-language failure feedback F to support self-correction. Three integrated tools enable (i) compositional benchmark task creation with auto-evaluators, (ii) step-level GUI element annotation via bounding-box drawing on screenshots, and (iii) trajectory-level video-action recording with a refinement editor that removes noisy mouse movements and aggregates atomic key presses into higher-level actions. The 205-task online benchmark is built in three stages—50 single-API and 95 single-GUI tasks, 60 compositional cross-application tasks, and manual validation with human trajectories—using over 100 auto-evaluator functions for environment resetting and success checking. Three fine-grained datasets are curated: GroundUI-18K (18K instruction-screenshot-bbox pairs across web, desktop, and mobile, with ambiguous instructions recaptioned via GPT-4o), IDMBench (345 trajectories from Mind2Web, AITW, VisualWebArena, and AgentStudio, evaluated in single-step and multi-step action-labeling settings), and CriticBench (350 balanced success/failure trajectories for outcome prediction). The key design insight is that a single generic environment with both API and GUI actions, video observations, and language feedback can simultaneously support overall task-completion evaluation and decomposed ability benchmarks, while remaining lightweight enough for reproducible Docker-based deployment.

## Results

On the overall AgentStudio benchmark (205 tasks), humans achieve 72.2% success rate while the best model, Claude 3.5 Sonnet, reaches only 36.6%, with GPT-4o at 35.6% and Gemini 1.5 Pro at 16.6%. On GroundUI-1K (UI grounding), the specialized SeeClick model achieves 61.1% total accuracy, substantially outperforming the best proprietary VLM (Gemini 1.5 Pro at 35.2%) and GPT-4o (13.4%). On IDMBench, model performance drops dramatically from ~60% in IDM-Single to ~10% in IDM-Multiple (exact-match multi-step action labeling). On CriticBench (success detection), the best F1 score is 69.7% (Gemini 1.5 Pro, observation-action pairs), with all models clustered between 58–70%.

## Baselines & Comparisons

The paper's primary comparison on GroundUI-1K is between the specialized UI grounding model SeeClick and general-purpose VLMs. SeeClick achieves 61.1% total accuracy (64.3% web, 44.3% desktop, 73.7% mobile), outperforming the best proprietary model Gemini 1.5 Pro (35.2%) by 25.9 points and GPT-4o (13.4%) by 47.7 points. However, even SeeClick's performance is insufficient for practical multi-step deployment due to error accumulation. Among general-purpose VLMs, Gemini 1.5 Pro consistently leads on GroundUI-1K, while Claude 3.5 Sonnet and GPT-4o perform best on the overall benchmark tasks and IDMBench. A notable finding is that adding screenshot observations to API-only tasks (Single-GUI OS vs. Single-API OS) degrades Gemini models' performance, as they are misled into using GUI actions instead of efficient API calls, whereas GPT-4o and Claude 3.5 Sonnet maintain comparable success rates by consistently favoring API calls.

## Relation to Prior Work

AgentStudio carves new ground by unifying the fragmented landscape of virtual agent environments—web-only (WebArena, VisualWebArena), mobile-only (AndroidWorld, AITW), and desktop-GUI-only (OSWorld, OmniACT)—into a single interactive environment with a universal observation space (text, image, video) and a dual action space (GUI + API). Rather than building on a specific prior method, it repurposes the POMDP formulation of computer control to expose component abilities (grounding, inverse dynamics, success detection) that prior benchmarks measured only through aggregate success rates. The fine-grained datasets (GroundUI, IDMBench, CriticBench) reorganize and recaption existing grounding data (ScreenSpot, MoTIF, OmniACT, Mind2Web) and introduce entirely new evaluation settings (multi-step action labeling from video, trajectory-level success prediction) that had no prior benchmark.

## Why It Matters / Open Questions

AgentStudio provides the first systematic decomposition of general virtual agent capabilities into independently measurable sub-abilities, enabling targeted research rather than opaque success-rate optimization. The finding that adding screenshot observations can degrade performance (models get 'misled' into GUI actions over efficient API calls) challenges the assumption that richer multimodal input always helps, and the very low GroundUI accuracy of general-purpose VLMs (GPT-4o: 13.4%) reveals a fundamental grounding bottleneck that compounds over multi-step tasks. Open questions include whether inverse dynamics models can unlock Internet-scale tutorial videos for agent training, whether a general critic can replace hand-written auto-evaluators for open-ended learning, and whether the 2× human-model gap (72.2% vs. 36.6%) can be closed through better grounding or compositional generalization.

## Problem

Standard conformal prediction produces prediction sets with valid statistical coverage but ignores how those sets will be used in downstream decisions. A set that spans benign and malignant diagnoses, for example, satisfies coverage yet is uninformative for a clinician choosing a treatment path. The paper asks how to generate prediction sets that simultaneously satisfy coverage guarantees and minimize a user-specified cost function reflecting downstream utility.
![Teaser figure](../imgs/ICLR20250151/cropped_page2_idx0.webp)

## Input / Output

The method is a post-processing step that consumes the softmax probabilities p̂(y|x) from any pre-trained base classifier (EfficientNet-B0 in experiments), a user-defined cost function L over subsets of labels (separable per-label penalties or non-separable hierarchical coverage), and a held-out calibration set. It outputs a prediction set S_f(x) ⊆ Y with a marginal coverage guarantee of at least 1−α and empirically minimized expected cost. The base model is never retrained and need not be aware of the cost function, preserving the modularity of conformal prediction.

## Method

The paper proposes two families of conformal predictors that embed the cost function into the non-conformity score. The first (penalized conformal) augments the standard adaptive prediction set score ρ(x,y) with a weighted cumulative cost λ·L(y), where L(y) tracks the running cost of the proxy set built in probability order; λ is tuned by grid search on a validation split and the quantile is re-estimated on a fresh calibration set to preserve exchangeability. The second family is hyperparameter-free: for separable losses, the score is the ratio p̂(y|x)/ℓ(y) (a Neyman-Pearson construction), and for non-separable losses, a greedy submodular optimizer determines the label-addition order that minimizes marginal cost, and the cumulative probability in that greedy order serves as the score. Both approaches retain the standard split-conformal coverage guarantee 1−α ≤ P(Y ∈ S_f(X)) ≤ 1−α + 1/(n+1), and the non-separable greedy variant adapts to combinatorial structure (e.g., hierarchical category coverage) that the fixed probability-order penalty cannot capture.

## Results

Across all five datasets and three loss types, the proposed methods achieve substantially lower cost than standard conformal prediction. On the separable loss, the Separable Penalized Ratio reduces loss by 85–97% (e.g., ImageNet: 150.2 → 5.3; iNaturalist: 32.9 → 2.0). On the non-separable coverage loss (the paper's primary dermatology application), the Greedy Optimizer reduces loss by 52% on Fitzpatrick (6.13 → 2.94) and 32% on Fitzpatrick Clean (4.63 → 3.14), while the Penalized Conformal method achieves 67% reduction on CIFAR-100 (3.13 → 1.05) and 72% on ImageNet (3.37 → 0.96). All methods maintain valid statistical coverage at the target 1−α = 0.9 level across all set sizes.

## Baselines & Comparisons

The sole baseline is the standard adaptive prediction sets method (Romano et al., 2020), referred to as 'Base Conformal.' The proposed methods consistently outperform this baseline across all five datasets and all three loss types. On the separable loss, the Separable Penalized Ratio achieves the largest gains (e.g., 96.5% reduction on ImageNet, 93.8% on iNaturalist). On the non-separable losses, the Penalized Conformal method dominates on large datasets (CIFAR-100, ImageNet, iNaturalist) where sufficient data supports reliable λ tuning, while the Greedy Optimizer wins on the smaller Fitzpatrick datasets where hyperparameter estimation is unreliable (e.g., 52% reduction on Fitzpatrick vs. only 9% for Penalized Conformal). The paper notes that on large datasets the Penalized Conformal method tends to outperform the hyperparameter-free methods because the latter assume access to the true Bayes classifier, an assumption that is better approximated with more data. All proposed methods maintain valid marginal and conditional coverage guarantees, unlike a Bayesian comparison (Appendix C) which fails to achieve true coverage.

## Relation to Prior Work

This paper extends the split conformal prediction framework (Vovk et al., 2005; Romano et al., 2020) by incorporating a user-specified cost function into the non-conformity score, drawing conceptual motivation from decision-focused learning (Wilder et al., 2019) and the utility-theoretic abstraction framework of Horvitz & Klein (1993). The closest prior work is conformal risk control (Angelopoulos et al., 2022), which controls the expected value of a loss but does not directly optimize it and requires the loss to be monotonically decreasing in set size; this paper removes that restriction and handles non-separable losses with combinatorial structure. For the non-separable case, the greedy construction borrows from submodular optimization (Leskovec et al., 2007), and the separable hyperparameter-free solution generalizes the Neyman-Pearson-based set-valued classifier of Sadinle et al. (2019) from uniform costs to arbitrary per-label penalties.

## Why It Matters / Open Questions

The framework offers a practical, model-agnostic post-processing step that makes conformal prediction sets more actionable in high-stakes decision-making (e.g., medical triage), without retraining the base classifier. The dermatology case study demonstrates that utility-directed sets can encode clinically meaningful homogeneity (e.g., grouping malignant epidermal diseases), which standard conformal sets fail to capture. Key limitations include the need for a user-specified cost function, the plug-in assumption that the base classifier approximates the true conditional (addressed only marginally via conformalization), and the fact that the greedy optimizer for non-separable losses has no optimality guarantee. Open questions include how to learn or elicit the cost function automatically, extending to continuous or multi-label outcomes, and scaling to very large label spaces where the combinatorial optimization becomes intractable.

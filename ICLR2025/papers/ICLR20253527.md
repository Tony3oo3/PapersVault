## Problem

Dynamic graph neural networks are typically pre-trained on link prediction, creating a significant objective gap when adapting to downstream tasks like node classification. Existing prompt learning methods for graphs address only static graphs and ignore temporal evolution, leaving both the task-objective gap and the temporal gap between pre-training and downstream phases unresolved. Additionally, prior work fails to capture the fine-grained mutual characterization between node and time patterns, where the same node behaves differently at different times and different nodes behave differently at the same time.

## Input / Output

The method consumes a continuous-time dynamic graph (nodes, timestamped edges, and per-node feature vectors evolving over time) along with a small set of labeled downstream events (as few as 30 sampled events per task). It produces node embeddings at specific timestamps that are scored via cosine similarity against class prototypes (for node classification) or against target node embeddings (for link prediction). The pre-trained DGNN backbone is entirely frozen; only the lightweight dual prompt vectors and condition-net parameters are updated, making the approach suitable for label-scarce settings.

## Method

DYGPROMPT introduces dual prompts—a node prompt applied via element-wise multiplication to node features and a time prompt applied to time-encoder outputs—to simultaneously bridge the task-objective gap and the temporal gap between pre-training and downstream phases. To capture evolving node-time patterns, it proposes dual condition-nets implemented as bottleneck MLPs (hypernetworks): a time condition-net generates a sequence of time-conditioned node prompts for each node, and a node condition-net generates node-conditioned time prompts at each timestamp, so that prompts adapt to both the specific node and the specific time rather than remaining fixed. Pre-training uses a contrastive temporal link prediction loss with a similarity-based task template, and downstream prompt tuning optimizes only the dual prompt vectors and condition-net parameters (a few thousand learnable parameters) while freezing the entire DGNN, achieving parameter-efficient adaptation with minimal additional computational overhead.

## Results

On temporal node classification, TGAT-DYGPROMPT achieves the best AUC-ROC across all four datasets: 82.09% (Wikipedia), 73.50% (Reddit), 77.78% (MOOC), and 52.03% (Genre). On transductive link prediction, TGN-DYGPROMPT leads with 94.33% (Wikipedia), 96.82% (Reddit), 70.17% (MOOC), and 87.02% (Genre). On inductive link prediction, TGN-DYGPROMPT again dominates: 92.22% (Wikipedia), 95.69% (Reddit), 69.77% (MOOC), and 87.63% (Genre). On the large-scale DGraph dataset (3.7M nodes), DYGPROMPT reaches 73.39% AUC-ROC for anomaly detection, outperforming TIGPrompt (64.42%) and GraphPrompt (60.18%).

## Baselines & Comparisons

DYGPROMPT consistently outperforms all 12 baselines across the three task types. Against the closest dynamic-graph prompting competitor TIGPrompt, TGN-DYGPROMPT gains +12.29 AUC on Wikipedia transductive link prediction (94.33 vs. 82.04) and +10.47 on Wikipedia inductive link prediction (92.22 vs. 81.75), while TGAT-DYGPROMPT gains +12.88 on Wikipedia node classification (82.09 vs. 69.21). Against static-graph prompting methods, ProG is competitive on link prediction (92.28 on Wikipedia TLP) but lags significantly on node classification (60.86 vs. 82.09 for TGAT-DYGPROMPT on Wikipedia), and GraphPrompt trails on both tasks. Conventional DGNNs (TGAT, TGN, TREND, GraphMixer, ROLAND) and pre-training-then-fine-tuning methods (DDGCL, CPDG) are substantially weaker, with CPDG dropping below 50% AUC on several node classification settings. The backbone analysis (Table 3) confirms DYGPROMPT improves over the un-prompted backbone in nearly all cases across six different DGNN architectures (DYREP, JODIE, TGAT, TGN, TREND, GraphMixer), with the largest gains observed on TGN (+21.85 on Wikipedia TLP) and TGAT (+15.10 on Wikipedia NC). On the large-scale DGraph dataset (3.7M nodes), DYGPROMPT achieves 73.39% AUC, surpassing TIGPrompt by +8.97 and GraphPrompt by +13.21.

## Relation to Prior Work

DYGPROMPT extends the static graph prompt learning framework of GraphPrompt (Liu et al., 2023b) to dynamic graphs by introducing a time prompt alongside the node prompt, and adapts the conditional prompt generation paradigm from vision-language models (Zhou et al., 2022) to the graph setting via dual condition-nets (lightweight bottleneck MLPs acting as hypernetworks). The key conceptual departure from the closest prior work, TIGPrompt (Chen et al., 2024), is the mutual characterization between nodes and time: while TIGPrompt generates time-aware node prompts, DYGPROMPT additionally generates node-conditioned time prompts, capturing the interplay where different nodes exhibit divergent temporal behaviors. The framework is backbone-agnostic, plugging into any DGNN with a time encoder (TGN, TGAT, TREND, GraphMixer, etc.).

## Why It Matters / Open Questions

The paper demonstrates that a remarkably small number of learnable parameters (~3K for the condition-nets) can substantially close the pre-training-to-downstream gap on dynamic graphs, outperforming both full fine-tuning and prior prompt methods by large margins while being more parameter-efficient than TIGPrompt by orders of magnitude (3K vs. 1.6M+ parameters). This is practically important for data-scarce dynamic graph settings where labeled downstream data is limited. Open questions include whether the mutual node-time characterization generalizes to discrete-time dynamic graphs or multi-relational temporal graphs, and whether the gains persist when downstream data is less constrained than the 30-event budget used here.

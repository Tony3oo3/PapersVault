## Problem

Existing multimodal instruction fine-tuning datasets suffer from severely limited task diversity—Vision-Flan covers only ~200 task types, LLaVA uses 3, and MultiInstruct 62—because manual task labeling is prohibitively labor-intensive. This narrow task coverage leads to poor generalization and biased outputs in large multimodal models, creating a bottleneck that architecture and training-strategy improvements alone cannot resolve.

## Input / Output

The pipeline consumes ~800k open-source images (from ALLaVA, Visual Genome, MathV360K, and ShareGPT4V at original resolution) and a small set of manually defined seed task types (e.g., OCR, Image Description, Logical Reasoning). It produces 19,227 hierarchical task types organized in three levels (115 first-level, 2,796 second-level, 14,370 third-level) and 413,648 Q&A pairs, with 1–55 samples per task type. Each sample is a JSON record containing a task_type label, a question, and an answer, all aligned to a specific image.

## Method

TaskGalaxy is built through a five-stage automated pipeline that minimizes manual intervention. First, GPT-4o iteratively expands a small set of seed task types into 19,227 hierarchical types using level-specific prompts that enforce non-overlap between categories. Second, CLIP-L/14 computes cosine similarity between image and task-type text embeddings to select the top-10 candidate task types per image, which GPT-4o then refines via a dedicated filtering prompt to remove spurious matches. Third, GPT-4o generates question-answer pairs conditioned on each image and its matched task types. Fourth, three open-source multimodal models (GLM-4V, InternVL2-26B, InternVL-Chat-v1.5) independently score each sample on a binary scale, and only samples receiving a cumulative score of ≥2 are retained. Ablations confirm that performance scales monotonically with the number of task types (2k→19,227) and with sample volume (76k→413k), demonstrating that task-type diversity—not merely data volume—is the primary driver of generalization gains across 16 benchmarks.

## Results

Incorporating TaskGalaxy into the SFT phase yields average improvements of 4.5, 3.83, 3.0, and 3.64 points across 15 benchmarks (excluding MME) for LLaVA-v1.5-7B, LLaVA-v1.5-13B, InternVL-Chat-v1.0-7B, and InternVL-Chat-v1.0-13B, respectively. The most striking gain is a 68-point increase on MME for LLaVA-v1.5-13B (from 1532 to 1600), indicating substantially improved generalization. Notable per-benchmark gains include +12.94 on AI2D, +5.48 on ChartQA, and +4.7 on MathVista for LLaVA-v1.5-7B, while hallucination metrics (POPE, HallusionBench) improve by 1–2 points, suggesting diverse task coverage also mitigates hallucination.

## Baselines & Comparisons

In the appendix comparison (Table A-5), TaskGalaxy is pitted against four other instruction-tuning datasets—ShareGPT4V, LLaVA-OneVision, ALLaVA-4V, and Cambrian-1—each sampled to the same size as TaskGalaxy. For LLaVA-v1.5-7B, TaskGalaxy achieves the highest average score of 46.49 (w/o MME), outperforming ShareGPT4V (44.48), Cambrian-1 (44.23), LLaVA-OneVision (41.68), and ALLaVA-4V (41.53). For InternVL-Chat-v1.0-7B, the gap widens: TaskGalaxy reaches 49.63 versus Cambrian-1 at 46.98, ALLaVA-4V at 42.94, ShareGPT4V at 42.48, and LLaVA-OneVision at 40.20. TaskGalaxy leads on most individual benchmarks, with particularly large margins on AI2D (+5.7 over ShareGPT4V for LLaVA-7B) and MMMU (+5.1 over ShareGPT4V for InternVL-7B). The only notable exception is LLaVA-in-the-Wild, where Cambrian-1 (52.0) slightly edges TaskGalaxy (52.3) for LLaVA-7B, and MME where LLaVA-OneVision underperforms dramatically (1251 vs. 1520), suggesting its data distribution is poorly aligned with perception tasks. Overall, TaskGalaxy's 19,227 hierarchical task types consistently outperform datasets with far fewer task types (3–196), confirming that task diversity is the dominant factor in SFT data quality.

## Relation to Prior Work

This paper extends the multimodal instruction fine-tuning data construction paradigm established by LLaVA, LAMM, and Vision-Flan, but departs sharply in scale and automation. Prior datasets (LLaVA: 3 task types; Vision-Flan: ~200; MultiInstruct: 62) relied heavily on manual task labeling or task-specific decoders, capping diversity at a few hundred types. TaskGalaxy replaces this manual bottleneck with a GPT-4o-driven hierarchical expansion from a small seed set, combined with CLIP-based image-task matching and a three-model referee screening stage, yielding ~19,000 task types—roughly two orders of magnitude more than the closest prior effort.

## Why It Matters / Open Questions

The paper provides concrete evidence that task-type diversity, rather than raw sample count alone, is a primary driver of generalization in multimodal instruction fine-tuning, with ablations showing monotonic gains as task types increase from 2k to 19k. The pipeline is publicly released and designed to be extensible with new images and task types, making it a practical resource for the community. Open questions include whether the approach transfers to video or 3D modalities, whether the specific three-level hierarchy matters versus flat diversity, and how much of the gain is attributable to GPT-4o's implicit knowledge versus genuine task coverage. A key limitation is the dependence on a closed-source model (GPT-4o) for both task generation and Q&A synthesis, which introduces potential biases and reproducibility concerns.

## Problem

Despite widespread deployment of large vision-language models (LVLMs) such as GPT-4o, their out-of-distribution detection (OoDD) capabilities and the quality of confidence scores expressed through natural language responses remain largely unexplored. A key gap is that LVLMs tend to avoid generating predictions outside the categories specified in a prompt, limiting their ability to flag OoD inputs, and no systematic framework existed for evaluating or comparing OoDD across proprietary and open-source LVLMs.
![Teaser figure](../imgs/ICLR20253602/cropped_page0_idx1.webp)

## Input / Output

The framework takes an RGB image and a fixed set of ID class names (e.g., 200 ImageNet class words) as a text prompt that defines the in-distribution space. The LVLM returns a structured natural-language response containing a predicted class, per-class confidence scores (0–100), and a confidence for a 'none of these classes' rejection class; the OoD score is the maximum confidence among ID classes after softmax normalization. Experiments use 25% subsets of the ImageNet200 and CIFAR10 OpenOOD v1.5 benchmarks (23,031 and 40,568 image-prompt queries), with 5% subsets for the ReGuide ablation due to API costs.

## Method

ReGuide is a two-stage, model-agnostic prompting strategy that requires no training. In Stage 1, the LVLM is prompted to inspect the input image and suggest 2N auxiliary class names: N visually similar concepts (near-OoD) and N visually dissimilar or cross-domain concepts (far-OoD). In Stage 2, these image-adaptive suggestions are appended to the original ID class list as auxiliary OoD classes, and the LVLM performs OoDD over the expanded set, with the rejection class retained as a fallback. The key distinction from prior text-based negative-concept methods (NegLabel, EOE) is that the auxiliary classes are derived from the specific input image rather than from static ID class names, enabling the model to assign higher confidence to OoD inputs that match its own visual interpretation. This self-guided mechanism leverages the LVLM's zero-shot visual recognition to create a clearer ID/OoD separation, yielding substantial AUROC gains (e.g., +33% for InternVL2-26B on near-OoD) while also improving ID classification accuracy.

## Results

On the ImageNet200 benchmark, GPT-4o achieves the best overall OoDD performance among all evaluated LVLMs with 89.78% ID accuracy and 23.50% FPR@95%TPR / 88.50% AUROC on All OoD, outperforming both single-modal SOTA methods (SCALE: 84.84% avg FPR) and other proprietary models. Open-source models (LLaVA-v1.6, GLM-4v, InternVL2) suffer from 100% FPR due to highly biased confidence scores (mostly 0.0 or 100.00). ReGuide dramatically improves OoDD: InternVL2-26B's All OoD AUROC jumps from 61.63% to 93.19% (FPR from 75.95% to 10.24%), and GPT-4o's improves from 88.50% to 94.61% AUROC (FPR from 23.50% to 4.02%), with near-OoD detection benefiting most (e.g., InternVL2-26B NINCO AUROC: 58.32% → 86.53%).

## Baselines & Comparisons

GPT-4o outperforms all other proprietary and open-source LVLMs on both ID classification (89.78% vs. 88.84% for Gemini Pro 1.5) and OoDD (23.50% FPR / 88.50% AUROC on All OoD vs. 32.97% / 85.74% for Gemini), and also surpasses single-modal SOTA methods like SCALE (84.84% avg FPR) and AugMix+ASH (31.06% FPR on Openimage-O). Open-source models (LLaVA-v1.6, GLM-4v, InternVL2-76B) all exhibit 100% FPR due to extreme confidence bias, making them far inferior to proprietary models despite competitive AUROC in some cases (GLM-4v: 77.86% vs. GPT-4o's 88.50%). ReGuide closes this gap substantially: InternVL2-26B with ReGuide achieves 10.24% FPR / 93.19% AUROC on All OoD, surpassing GPT-4o's baseline (23.50% / 88.50%) and approaching GPT-4o+ReGuide (4.02% / 94.61%). The text-adaptive baseline (GPT-text, based on EOE) improves InternVL2-26B only modestly (62.41% / 65.88% FPR/AUROC) compared to ReGuide's 10.24% / 93.19%, confirming that image-adaptive concept generation is critical. Near-OoD detection sees the largest gains from ReGuide across all models (e.g., InternVL2-26B NINCO AUROC: 58.32% → 86.53%, a +28.21% improvement), while far-OoD detection is already strong in proprietary models and improves more modestly.

## Relation to Prior Work

This paper extends the zero-shot OoDD framework established for CLIP (Radford et al., 2021) to generative LVLMs, formulating OoDD as a structured prediction task where the model must assign confidence scores across a fixed set of ID classes plus a rejection class. It builds conceptually on NegLabel (Jiang et al., 2024) and EOE (Cao et al., 2024), which both use auxiliary negative/OoD classes to improve detection, but departs from them by generating those auxiliary classes adaptively from the input image via the LVLM itself rather than from static text or ID class names. The broader single-modal OoDD literature (max-softmax, energy-based, post-hoc calibration) provides the evaluation metrics and the motivation for confidence-based detection, but no prior work systematically evaluates or improves OoDD in generative LVLMs through their natural-language confidence expressions.

## Why It Matters / Open Questions

The paper reveals that open-source LVLMs (LLaVA-v1.6, GLM-4v, InternVL2) produce essentially binary confidence scores, yielding 100% FPR and rendering them unreliable for OoDD without intervention—a critical finding for anyone deploying these models in safety-sensitive settings. ReGuide, a simple two-stage prompting strategy, closes much of the gap between open-source and proprietary models, suggesting that the LVLMs' visual interpretation capability was underutilized by the default prompt. Open questions include whether confidence calibration can be achieved more robustly than through prompting, whether the positive bias from training on positive image-text pairs can be mitigated at the model level, and whether ReGuide's image-adaptive suggestions remain effective when the image is ambiguous or contains multiple objects.

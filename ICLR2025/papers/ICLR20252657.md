## Problem

Existing online VFL research assumes all clients receive synchronous data streams for the same sample, which is unrealistic in practice where data is generated by events affecting only a subset of clients. Additionally, prior online VFL work is limited to convex models and stationary data, failing to address the non-convex, non-stationary conditions prevalent in real-world applications such as sensor networks and multi-company collaborations.

## Input / Output

Each client receives a non-intersecting partition of the flattened feature vector (e.g., i-MNIST images split into 4 equal segments across 4 clients) and produces a 64-dimensional embedding via a single-layer perceptron with ReLU activation. The server receives concatenated client embeddings and a label, computing cross-entropy loss through a two-layer MLP (256 hidden units, softmax output). An event trigger signal (e.g., feature average exceeding a threshold Γ, or a random probability p_m) determines which clients are activated per round, while passive clients only supply their current embeddings upon server query without performing backpropagation.

## Method

The framework activates only a subset A_t of clients per round based on an event, while passive clients in Ā_t passively contribute their current embeddings to the server without gradient updates. To handle non-convex models in non-stationary environments, the authors adapt Dynamic Local Regret (DLR) using an exponentially weighted sliding-window average of length l with decay coefficient α, where both the server and activated clients maintain buffers of past gradients to compute time-smoothed update directions. The server computes the smoothed gradient over its buffer and sends partial derivatives w.r.t. client embeddings to activated clients, who then apply the chain rule locally to update their parameters. The key theoretical result is a DLR bound of O(T^{3/4}) under non-convex conditions with partial activation, derived by bounding the error between the gradient with missing elements (from inactive clients) and the ideal full gradient, with the ratio p_max/p_min governing the penalty for heterogeneous activation probabilities.

## Results

Under non-stationary data (i-MNIST with class probabilities shifting every 50 rounds), DLR-Event achieves an accumulated error rate of 0.0681 with only 2,699 s client computation and 1,414 MB communication, compared to OGD-Event's 0.1191 error rate (a 42% reduction in error) and SLR-Event's 0.1118 error rate at 61,748 MB communication (a 97.7% reduction in communication). Under stationary data, DLR-Event achieves 0.0718 accumulated error with 2,993 s computation and 1,539 MB communication, while OGD-Event degrades to 0.1027 error. The theoretical dynamic local regret bound is O(T^{3/4}) under non-convex conditions with partial client activation.

## Baselines & Comparisons

The paper compares against two main baselines: OGD-Full (Wang & Xu, 2023), the existing online VFL framework assuming synchronous data streams, and SLR (Hazan et al., 2017), which adapts Static Local Regret to VFL. Under non-stationary data with partial activation, DLR dramatically outperforms OGD: DLR-Event achieves 0.0681 accumulated error versus OGD-Event's 0.1191 (a 42% relative reduction), while DLR-Random achieves 0.0561 versus OGD-Random's 0.0788. Against SLR, DLR wins decisively on communication cost: DLR-Event requires only 1,414 MB versus SLR-Event's 61,748 MB (a 97.7% reduction), because SLR must transmit the entire gradient buffer each round. However, SLR-Full achieves the lowest absolute error rate (0.0481) at the cost of 78,125 MB communication, making it impractical for bandwidth-constrained settings. Under stationary data, DLR maintains stability under partial activation (0.0718 for DLR-Event) while OGD degrades sharply (0.1027 for OGD-Event), confirming that the dynamic sliding-window mechanism provides robustness that static methods lack.

## Relation to Prior Work

This paper extends the single prior online VFL framework (Wang & Xu, 2023), which assumed all clients receive synchronous data streams, by identifying that this assumption is unrealistic in practice. It adapts the dynamic local regret (DLR) framework from Aydore et al. (2019) for non-convex online optimization into the VFL setting, incorporating an event-driven mechanism where only a subset of clients is activated per round. The work also builds on the broader offline VFL literature (Vepakomma et al., 2018; Liu et al., 2019; Gu et al., 2020) by transitioning from batch-based training to continuous online updates, and on online HFL work (Mitra et al., 2021; Hong & Chae, 2021) by addressing the fundamentally different data partitioning structure of vertical federated learning.

## Why It Matters / Open Questions

This is the first work to formalize event-driven online VFL with a theoretical regret guarantee (O(T^{3/4}) DLR bound) under non-convex, non-stationary conditions with partial client activation, filling a gap that prior online VFL research overlooked. The practical impact is significant: partial activation reduces both communication and computation costs by 20–40% while maintaining stability under distribution shift, making online VFL more viable for resource-constrained edge deployments. A key open limitation is that passive clients must still participate each round to avoid the 'incomplete view' problem, preventing fully asynchronous operation; resolving this would enable truly event-triggered, zero-idle-time VFL. The framework's reliance on bounded loss and bounded gradient assumptions also limits applicability to unbounded or highly variable loss landscapes.

## Problem

LLM decoding is memory-bound because each new token requires accessing the entire KV cache, and existing sparse attention methods either evict tokens (risking loss of critical information in retrieval tasks) or estimate attention scores independently at every layer (introducing per-layer selection overhead and failing to exploit cross-layer token relevance patterns). The key unexplored observation is that tokens with the highest attention scores exhibit strong spatial coherence across consecutive Transformer layers, which prior selection-based methods ignore.

## Input / Output

TidalDecode takes a text prompt (prefilled into the KV cache via standard full attention) and a token budget K specifying how many tokens participate in sparse attention per layer (e.g., K=256 out of a 100K context). It produces logits for the next generated token. The token selection is computed only at two designated layers and then reused across all intervening sparse attention layers, so the effective input to most layers is a fixed subset of KV pairs rather than the full cache.

## Method

TidalDecode introduces Position Persistent Sparse Attention (PPSA), which exploits the empirical observation that top-K attention tokens overlap heavily across consecutive Transformer layers. Instead of performing token selection at every layer, TidalDecode designates only two layers as token selection layers (one early, e.g., layer 2, and one in the middle, e.g., layer 13) that compute full attention and extract the top-K tokens by inner product with the query vector. All remaining layers perform sparse attention using only the KV pairs of these pre-selected tokens, eliminating per-layer selection overhead entirely. A cache-correction mechanism periodically re-runs full attention over sparsely decoded tokens to correct KV representation drift, though this is omitted in main evaluations for fair comparison. The optimal middle re-selection layer is model-specific but consistent across tasks within the same model family (e.g., layer 13 for Llama-3-8B/3.1-8B, layer 7 for Llama-2-7B).

## Results

On the 100K-context Needle-in-the-Haystack test with Llama-3-8B, TidalDecode (TD+L13) achieves 100% accuracy at a token budget of K=128, compared to Quest's 65% at the same budget. On LongBench (Llama-3-8B, K=4096), TidalDecode achieves an average F1 of 32.86, exceeding both Quest (31.13) and full attention (32.33). In terms of efficiency, TidalDecode reduces end-to-end decoding latency by up to 2.1× versus full attention and 1.2× versus Quest, with kernel-level speedups reaching 5.56× over full attention and 2.17× over Quest on 64-layer models.

## Baselines & Comparisons

TidalDecode consistently outperforms Quest, the strongest selection-based sparse attention baseline, across all evaluated models and context lengths. On the 100K-context Needle-in-the-Haystack test (Llama-3-8B), TidalDecode reaches 100% accuracy at K=128 while Quest only achieves 65%, and TidalDecode requires up to 8× fewer tokens to reach full accuracy. On LongBench (K=4096), TidalDecode's average F1 of 32.86 surpasses Quest's 31.13 and even exceeds full attention's 32.33. Against eviction-based baselines (H2O, TOVA, StreamingLLM), TidalDecode is dramatically superior: on the 10K-context test with LongChat-7b, TidalDecode achieves 100% at K=512 while H2O, TOVA, and StreamingLLM achieve only 3%, 8%, and 5% respectively. In terms of latency, TidalDecode is faster than Quest at all context lengths (e.g., 21.26 ms vs 24.93 ms at 100K context on Llama-2-7B), primarily because it eliminates per-layer token estimation overhead by reusing a shared token set across sparse attention layers.

## Relation to Prior Work

TidalDecode sits within the selection-based sparse attention lineage (Quest, Reformer, Sparse Transformer, SparQ) that preserves the full KV cache but attends only to a subset of tokens per decoding step. Its key departure is exploiting the spatial coherence of top-attention-score tokens across consecutive Transformer layers: rather than estimating or recomputing token importance independently at every layer (as Quest does with page-level score approximation), TidalDecode performs full attention at only two layers (an early layer and a single middle re-selection layer) and reuses the resulting token set for all remaining sparse layers. This repurposes the standard full-attention computation as a one-time selection oracle, eliminating the per-layer estimation overhead that prior selection-based methods incur.

## Why It Matters / Open Questions

The practical impact is significant for long-context LLM serving: a 2.1× end-to-end speedup over the strongest sparse baseline (Quest) and up to 5.56× over full attention on the attention kernel, while matching or exceeding full-attention quality on Needle-in-the-Haystack, PG-19 perplexity, and LongBench. The finding that the optimal middle re-selection layer is consistent within a model family across tasks (e.g., layer 13 for all Llama-3-8B variants) gives practitioners a simple, transferable configuration rule. Open questions include how the approach behaves at even longer contexts (beyond 100K), whether the two-layer selection scheme generalizes to non-Transformer or mixture-of-experts architectures, and the underexplored cache-correction mechanism, which was deliberately excluded from main evaluations for fairness but shows promise for very long generations.

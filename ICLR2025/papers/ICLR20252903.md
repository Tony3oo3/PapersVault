## Problem

Self-attention in Vision Transformers incurs quadratic computational and memory costs relative to input size, creating a severe bottleneck for real-world vision tasks involving large inputs (high-resolution images, 3D point clouds) and resource-constrained hardware such as mobile NPUs. While several alternative attention mechanisms have been proposed, they are typically designed as holistic backbones rather than drop-in replacements, and no unifying theoretical framework has connected them. This paper addresses both the efficiency gap and the lack of a common design principle for attention replacement.

## Input / Output

PADRe operates as a drop-in replacement for the self-attention module within existing transformer architectures (DeiT, DETR, DSVT), so the overall input/output format is determined by the host model: patchified RGB images (16×16 patches, up to 4096 tokens) or sparse 3D LiDAR voxels treated as a 1D token sequence. A notable design choice is that PADRe uses a single head rather than multi-head attention, and for 2D inputs it reshapes tokens into a spatial grid to apply 11×11 2D convolutions for token mixing, while for point clouds it uses 1D convolutions with kernel size 11. The output tensor has the same shape as the input (N×D), making it a direct substitute for the attention output before the residual connection.

## Method

PADRe constructs each output element as a degree-d polynomial of the input elements through three stages: (1) d structured linear transformations Y_i = A_i X B_i (implemented as pointwise convolutions for channel mixing and spatial/1D convolutions for token mixing); (2) iterative Hadamard-product nonlinearities Z_{i+1} = (C_i Z_i D_i) ⊙ Y_{i+1} that build up homogeneous polynomial terms of increasing degree; and (3) a weighted sum of all degree terms plus a bias to form the final output. The key insight is that Hadamard products between linearly-transformed copies of the input naturally generate multivariate monomials (cross-terms), providing polynomial expressivity using only hardware-friendly operations with no softmax, exp, or complex functions. The total cost is O(N·D·d) in both FLOPs and memory, linear in input size for fixed degree. The paper further proves that Hyena, Mamba, SimA, Conv2Former, and Castling-ViT are all special cases of this polynomial framework, and that standard self-attention can be approximated by a high-degree rational function within the same family.

## Results

On ImageNet-1K classification with DeiT-Tiny, PADRe-3 achieves 76.5% top-1 accuracy (vs. 72.2% for standard self-attention), while PADRe-2 reaches 74.5%. On COCO detection with DETR, PADRe-2 achieves 40.2 AP (vs. 40.6 AP baseline) while reducing encoder FLOPs by 55% (4.5G vs. 10.1G). On nuScenes 3D detection with DSVT, PADRe-2 matches the baseline NDS (71.1) with a negligible mAP drop (66.0 vs. 66.4) and 28% fewer FLOPs. On-device profiling shows PADRe runs 11×–43× faster than standard self-attention on NVIDIA A100 GPU and Qualcomm Hexagon NPU, with linear latency scaling versus quadratic growth for attention.

## Baselines & Comparisons

PADRe-3 on DeiT-Tiny (76.5%) outperforms all listed baselines including standard self-attention (72.2%), Hydra (68.3%), Efficient attention (70.2%), Linear-angular attention (70.8%), Enhanced linear attention (72.9%), k-NN attention (73.0%), Focused linear attention (74.1%), and Vision Mamba (76.1%), while using fewer FLOPs (1.7G) than Vision Mamba (2.6G). PADRe-2 on DeiT-Tiny (74.5%) beats standard self-attention and most alternatives but trails Focused linear attention (74.1%) and Vision Mamba (76.1%). On DeiT-Small, PADRe-3 (80.5%) ties Vision Mamba (80.5%) while using roughly half the FLOPs (6.1G vs. 9.6G), and PADRe-2 (80.4%) matches or exceeds SimA (79.8%) and k-NN (80.1%) with fewer parameters (20M vs. 22M). On DeiT-Base, PADRe-2 (81.4%) nearly matches standard self-attention (81.8%) and substantially outperforms Hydra (76.4%) and Hyena (78.5%). For object detection, PADRe-2 on DETR achieves 40.2 AP vs. 40.6 AP baseline with 55% fewer encoder FLOPs, and on DSVT for 3D detection it matches NDS (71.1) with a 0.4 mAP gap while reducing FLOPs by 28%.

## Relation to Prior Work

This paper carves new ground by providing a unifying algebraic framework (polynomial approximation via Hadamard products) that subsumes several independently proposed attention replacements—Hyena, Mamba, SimA, Conv2Former, and Castling-ViT—as special cases, rather than proposing yet another isolated architecture. It draws on classical approximation theory (polynomial approximants over compact sets) to justify the design, and departs from prior efficient-attention work by emphasizing hardware-friendly operations (no softmax, no exponentials) and single-head operation. The drop-in replacement philosophy contrasts with holistic backbone redesigns (e.g., Swin, EfficientFormer) and with methods that require joint training of the entire network.

## Why It Matters / Open Questions

The practical impact is significant for on-device deployment: 11×–43× latency reduction on GPU and NPU with maintained accuracy makes high-resolution and point-cloud transformer inference feasible on mobile hardware. The unifying perspective gives researchers a common language and design space for future attention alternatives, potentially accelerating the field beyond ad-hoc proposals. Open questions include extending PADRe to cross-attention and multi-modal settings, understanding why performance saturates beyond degree 3 (possibly numerical instability of monomials), and whether orthogonal polynomial bases or architecture search can push the degree higher. The paper also highlights that FLOPs are a poor proxy for real hardware latency, an important caveat for efficiency claims.

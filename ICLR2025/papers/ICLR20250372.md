## Problem

LLM agents lack a mechanism for automatic self-improvement from errors encountered during task execution: prompting requires manually specifying exceptions and scales poorly, while RL is impractical due to the infinite, unconstrained reason space. Imitation learning via DAGGER-style corrections is intractable for POMDPs because the expert must recover from arbitrary student errors, which is strictly harder than solving the original task. The paper asks whether equipping the expert with privileged state information (available only at training time) can make corrections tractable while still producing policies that work from observations alone at test time.

## Input / Output

The student agent receives text observations from the environment, a task instruction, and its own observation-action history h_t, and outputs a natural-language reason ρ_t followed by a text action command a_t (e.g., 'go to shelf 1'). The privileged expert additionally receives the hidden state s_t (object locations, product attributes, ground-truth commands) but is constrained to produce corrections that reference only information derivable from h_t, never revealing s_t directly. Training uses LoRA fine-tuning on Llama3-8B/70B with max sequence lengths of 6000–8000 tokens; inference uses temperature 0.3 with a 256-token cap per step.

## Method

LEAP iteratively fine-tunes a student policy π_i through N rounds of: (1) rolling out π_{i-1} in the environment to collect trajectories, (2) invoking a privileged expert π^E that sees the hidden state s_t to generate corrected (reason, action) pairs at failure timesteps, and (3) updating the student via SFT on the aggregated dataset (equivalent to FTRL) or via DPO/KTO treating corrections as preferred over student outputs (equivalent to OMD). The critical design choice is a constrained privileged expert that leverages s_t to identify the correct action but expresses its reasoning in general, realizable terms (e.g., 'kettles are likely on stove burners' rather than 'the kettle is on burner 2'), balancing the performance gain from privileged information against the realizability gap. The theoretical analysis shows the student's performance is bounded by the expert's performance minus a recoverability coefficient times the sum of the realizability gap and DAGGER regret, and that an optimal δ-KL constraint on the expert's deviation from the non-privileged policy achieves the best trade-off.

## Results

On ALFWorld (out-of-distribution), LEAP with Llama3-8B achieves 91.8% success rate in 11.3 actions, surpassing the GPT-4o teacher (65.7%, 20.2 actions) by 26.1 percentage points. On WebShop, LEAP reaches a score of 61.8 (vs. GPT-4o's 58.4), and on InterCode Bash, LEAP with Llama-3.1-70B achieves 71.8% success rate, matching the GPT-4o expert (71.3%). The base BC policy (π₀) starts at 65.7% on ALFWorld, 29.4 on WebShop, and 60.3% on InterCode, with the largest single-iteration gain on ALFWorld (65.7% → 91.0%).

## Baselines & Comparisons

LEAP (Llama3-8B, π₃) outperforms all baselines on ALFWorld out-of-distribution: it beats ReAct gpt-4o (65.7%) by 26.1 points, ReAct claude-3.5-sonnet (76.1%) by 15.7 points, and even AdaPlanner gpt-3 (91.7%) by 0.1 points, while using far fewer actions (11.3 vs. 20.2 for gpt-4o). On WebShop, LEAP π₂ (61.8) surpasses the IL baseline (59.9) and ReAct gpt-4o (58.4), with the largest gap in the OPT component (42.4 vs. 22.1). On InterCode Bash, LEAP with Llama-3.1-70B (71.8%) edges out ReAct gpt-4o (71.3%) and substantially outperforms the leaderboard baselines (gpt-4: 48.5%, gpt-3.5: 46.5%, CodeLlama-34B: 36.0%). Notably, the 8B student model exceeds its GPT-4o teacher across all three domains, and LEAP also outperforms the SFT-privileged baseline (42.5%) by 48.5 points on ALFWorld, confirming that on-policy corrections—not just privileged information—drive the gains.

## Relation to Prior Work

LEAP transplants the privileged-information paradigm from robotics sim-to-real transfer (Vapnik et al., 2015; Chen et al., 2020) into the LLM agent setting, combining it with the DAGGER-style iterative on-policy correction loop (Ross et al., 2011) that has been largely absent from LLM agent training. It departs from prior LLM self-correction and AI-feedback work (Reflexion, RLAIF, self-refine) by introducing a structured train-time-only privileged state and a constrained expert that explicitly balances information richness against student realizability — a trade-off formalized theoretically but previously unaddressed in the LLM agent literature. The method also extends the imitation-learning-for-agents line (BUTLER, IL baselines in WebShop) by replacing static behavior cloning with iterative privileged corrections.

## Why It Matters / Open Questions

LEAP provides a practical recipe for improving LLM agents without RL, and the finding that an 8B student can substantially outperform a GPT-4o teacher (91.8% vs 65.7% on ALFWorld) has direct implications for cost-efficient deployment. The self-improvement result (a model bootstrapping itself via its own privileged version) opens a path toward autonomous agent refinement, though the paper notes this depends on environment richness. Key limitations include the computational cost of multi-iteration rollouts, the requirement that privileged state be available at train time, and the observation that when the teacher is already strong (InterCode), the student struggles to exceed it. Open questions include whether the constrained-expert prompt heuristic generalizes to domains where privileged state is less structured, and whether the non-monotonic iteration dynamics can be better controlled.

## Problem

Existing temporal graph neural networks assume a fixed class set and static data distribution, but real-world temporal graphs continuously introduce new classes and shift distributions over time. Prior work on open temporal graph learning (e.g., OTGNet) focuses exclusively on preventing catastrophic forgetting via replay, neglecting the distribution discrepancy between successive tasks, while classical MMD-based discrepancy measurement scales quadratically with graph size, making it infeasible for batch-trained TGNNs.

## Input / Output

The method consumes a sequence of temporal graph tasks, where each task contains timestamped edges (u, v, t), 300-dimensional node features, and a set of newly introduced class labels. The model must classify nodes across the full accumulated class set from all previous and current tasks simultaneously (not per-task), operating under the standard batch-wise training regime of TGNNs with 5-neighbor sampling. Output is a single set of class probabilities over all classes seen so far, evaluated via AP, AF, and BWT metrics across the task sequence.

## Method

N-ForGOT is grounded in a PAC-Bayesian generalization error bound that decomposes performance into a forgetting term (empirical risk on historical data) and a distribution discrepancy term (MMD between task distributions), motivating two plug-in modules for any neighborhood-based message-passing TGNN. The TICR module mitigates forgetting via two mechanisms: (1) a temperature-scaled knowledge distillation loss that aligns current logits with soft targets from the previous network to preserve decision boundaries, and (2) an inter-class connectivity loss that minimizes the L2 distance between class relational matrices (Euclidean distances between evolving class prototypes) from successive tasks. The LTDO module addresses distribution shifts by defining temporal Weisfeiler-Lehman subtree patterns that recursively capture both structural neighborhoods and temporal edge intervals, then computing a linear (unbiased) MMD approximation over these local patterns in O(n) time and O(1) memory per batch, avoiding the O(n²) cost of classical MMD while reducing information loss from batch isolation.

## Results

N-ForGOT achieves Average Performance (AP) of 69.36% (Yelp), 62.68% (Reddit), 83.38% (Taobao), and 80.30% (Amazon), outperforming the strongest baseline by 2.5–18.3 percentage points across datasets. Average Forgetting (AF) is minimized to −2.83% (Yelp), −1.02% (Reddit), −6.53% (Taobao), and −15.50% (Amazon), representing up to 89.7% reduction in forgetting compared to the closest baseline. Backward Transfer (BWT) is consistently positive relative to all baselines, with the largest gains on Reddit (−0.89% vs. −35.54% for OTGNet), indicating that learning new tasks actively improves prior-task performance.

## Baselines & Comparisons

N-ForGOT outperforms all five baselines on every metric (AP, AF, BWT) across all four datasets. Against the closest OTGL-specific baseline OTGNet (Feng et al., 2023), N-ForGOT gains +7.4% AP on Yelp, +17.8% AP on Reddit, +5.5% AP on Taobao, and +2.8% AP on Amazon, while reducing forgetting by 42% (Yelp), 97% (Reddit), 77% (Taobao), and 14% (Amazon). Against graph-continual-learning baselines TWP (Liu et al., 2021) and ER-GNN (Zhou & Cao, 2021), the AP advantage ranges from +2.5% (Taobao vs. TWP) to +18.9% (Reddit vs. ER-GNN), with AF improvements of 12–24 percentage points. Against vision-domain baselines EWC (Kirkpatrick et al., 2016) and LwF (Li & Hoiem, 2016), N-ForGOT leads by 10–28% AP and 13–28% AF, confirming that generic regularization/distillation strategies are insufficient for temporal graph settings. Notably, on Reddit the replay-based methods (ER-GNN, OTGNet) suffer severe forgetting (AF ≈ −30 to −36%), while N-ForGOT's parameter-regularization approach (TICR) keeps AF near zero (−1.02%), suggesting that data replay struggles when temporal distribution shifts are large.

## Relation to Prior Work

This paper extends the open temporal graph learning (OTGL) setting introduced by OTGNet (Feng et al., 2023), which addressed only catastrophic forgetting via triad-motif replay. N-ForGOT departs from that line by (1) replacing invariant triad motifs with temporal WL subtree patterns that capture evolving class characteristics, and (2) adding a distribution-shift objective (linear MMD) alongside the forgetting objective, grounded in a PAC-Bayesian generalization bound. The two plug-in modules (TICR and LTDO) are designed to be architecture-agnostic, building on standard neighborhood-based message-passing TGNNs like TGAT, and the regularization component draws on knowledge distillation (LwF) and prototype-based inter-class alignment from the broader continual learning literature.

## Why It Matters / Open Questions

This is the first OTGL method to jointly optimize forgetting prevention and cross-task generalization with a theoretical guarantee, and the plug-in design means practitioners can adopt it with any existing TGNN backbone without retraining from scratch. However, the evaluation is limited to a single TGNN architecture (TGAT) and four datasets of moderate scale, and the 'open' setting still assumes the same node type with only new class labels emerging, leaving open whether the approach transfers to truly heterogeneous or streaming scenarios. The authors note future work on diverse domains and generative graph structure modeling, suggesting the current framework is a first step rather than a complete solution to open-world temporal graph learning.

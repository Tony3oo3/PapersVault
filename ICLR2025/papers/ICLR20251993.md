## Problem

Existing few-shot 3D point cloud segmentation (FS-PCS) methods rely exclusively on unimodal point cloud inputs, overlooking the complementary information available in textual class names and 2D images that are typically captured alongside 3D scans. This paper asks how to exploit these cost-free additional modalities to improve few-shot generalization to novel categories.
![Teaser figure](../imgs/ICLR20251993/cropped_page1_idx0.webp)

## Input / Output

At inference, the model takes a labeled support point cloud, an unlabeled query point cloud, and the target class names as text. The 2D RGB image modality is used only implicitly during pretraining to align 3D features with a VLM's visual embedding space; no 2D images are required during meta-learning or inference, making the model applicable to datasets like S3DIS that lack 2D imagery. The output is a per-point class assignment over the query point cloud, segmenting it into the N target classes plus background.

## Method

MM-FSS employs a shared Stratified Transformer backbone with two heads: an Intermodal Feature (IF) head pretrained to align 3D features with LSeg's 2D visual features via cosine similarity, and a Unimodal Feature (UF) head capturing pure point-cloud representations. A Multimodal Correlation Fusion (MCF) module computes query-to-prototype correlations in both feature spaces and aggregates them through linear projections. A Multimodal Semantic Fusion (MSF) module then refines these correlations by computing affinities between intermodal query features and LSeg text embeddings as semantic guidance, dynamically weighting its contribution per point and class via learned MLP gates. Finally, a parameter-free Test-time Adaptive Cross-modal Calibration (TACC) module uses the IoU between support-point predictions from the text-aligned guidance and ground-truth labels as an adaptive indicator γ to blend the bias-free textual guidance with the meta-learned prediction, mitigating base-class bias at inference.

## Results

On S3DIS, MM-FSS achieves mean mIoU of 52.09% (1-way 1-shot), 54.21% (1-way 5-shot), 44.30% (2-way 1-shot), and 50.16% (2-way 5-shot), outperforming the previous state-of-the-art COSeg by +4.3, +3.8, +6.2, and +8.7 points respectively. On ScanNet, MM-FSS reaches 44.73%, 50.07%, 39.21%, and 44.09% mean mIoU across the same settings, improving over COSeg by +2.7, +3.5, +10.2, and +8.6 points. Overall, the method secures average mIoU gains of +3.97% (1-way) and +9.25% (2-way) across both datasets, with the largest improvements in the more challenging 2-way settings.

## Baselines & Comparisons

MM-FSS consistently outperforms all four baselines across every setting on both S3DIS and ScanNet. Against the previous state-of-the-art COSeg (An et al., 2024), MM-FSS gains +4.3 to +8.7 mIoU on S3DIS and +2.7 to +10.2 on ScanNet, with the largest margins in 2-way settings where limited support samples make novel-class learning hardest. The retrained variant COSeg† (using the same 2D-aligned backbone weights as MM-FSS) shows only marginal improvement over COSeg, confirming that the gains come from the fusion architecture (MCF, MSF, TACC) rather than the backbone alone. Among the older baselines, QGE (Ning et al., 2023) is the strongest non-COSeg competitor, yet MM-FSS still leads by 11.7–15.1 mIoU on S3DIS and 9.5–14.2 on ScanNet. QGPA (He et al., 2023) and AttMPTI (Zhao et al., 2021) trail significantly, with QGPA underperforming even in 1-way settings where it was originally designed.

## Relation to Prior Work

This paper extends the FS-PCS line of work (AttMPTI, COSeg) by introducing the first multimodal setup, incorporating text class names and 2D image features alongside point clouds. It builds directly on COSeg's two-step training paradigm (pretraining + meta-learning) and prototype-based correlation framework, but departs by adding a shared backbone with dual heads (Intermodal and Unimodal Feature heads) and novel MCF/MSF fusion modules that integrate cross-modal correlations and text-semantic guidance. The intermodal features are pretrained to align with VLM embeddings (LSeg/OpenSeg), repurposing vision-language pretraining as a free source of 2D-aware 3D features without requiring 2D input at inference time.

## Why It Matters / Open Questions

The paper demonstrates that commonly-ignored 'free' modalities (class names, co-captured 2D images) can yield substantial FS-PCS improvements (+4–10% mIoU over SOTA) without additional annotation cost, opening a practical direction for the field. The finding that simply retraining COSeg with 2D-aligned backbone weights (COSeg†) does not close the gap highlights that well-designed cross-modal fusion architecture matters more than feature quality alone. Open questions include whether the approach generalizes beyond indoor scenes, whether the implicit 2D alignment transfers to outdoor or large-scale 3D datasets, and whether the TACC calibration strategy extends to other few-shot tasks beyond point cloud segmentation.

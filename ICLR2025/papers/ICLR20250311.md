## Problem

Existing conformal prediction algorithms produce prediction sets with simple structures (label subsets or intervals) suited to classification and regression, but for complex structured outputs like hierarchical labels or text generation, naively applying these algorithms yields large, uninterpretable sets of concrete labels. Prior structured conformal prediction approaches are specialized to individual domains (code generation, question answering) and do not provide a general framework. This paper asks: can we build a general conformal prediction framework that outputs compact, interpretable structured prediction sets while maintaining formal coverage guarantees?

## Input / Output

The method takes a scoring function g(x,y) (e.g., predicted probabilities from a pretrained model), a DAG G=(V,E) defining the space of structured prediction sets where leaf nodes carry probabilities summing to 1, a calibration set Z of n i.i.d. samples, and hyperparameters m (max nodes in the prediction set), ε (error level), and δ (PAC confidence). The output is a structured prediction set ỹ ⊆ V with |ỹ| ≤ m, which implicitly represents a concrete label set via the mapping γ(ỹ) = leaves(ỹ); the size is measured by the number of leaf descendants covered rather than the number of selected nodes. For example, selecting the single node 'gymnastic apparatus' in a label hierarchy implicitly covers all fine-grained gymnastics subcategories.

## Method

The framework searches sequentially over a finite set of candidate thresholds τ₁ > τ₂ > … > τₖ, applying a statistical test φ(Z, τᵢ) at each step and returning the last valid threshold before the first invalid one. This sequential approach is necessary because structured prediction sets break the monotonicity in τ that standard conformal algorithms exploit for bisection. For marginal guarantees, φ checks whether the calibration miscoverage count is at most (n+1)ε (learn-then-test); for PAC guarantees, φ uses a binomial CDF threshold ℓ satisfying F(ℓ; n, ε) < δ. Given a fixed τ, computing the optimal structured prediction set ỹ is formulated as an integer program over binary variables αᵥ (node selected into ỹ) and βᵥ (node covered by ỹ), minimizing the number of covered leaves subject to cumulative leaf probability ≥ τ and |ỹ| ≤ m, with constraints enforcing the DAG ancestor-descendant coverage logic. The paper proves both marginal (Theorem 3.1) and PAC (Theorem 3.2) coverage guarantees for the resulting estimator.

## Results

Across five domains (MNIST digits, ImageNet, SQuAD question answering, MBPP code generation, and GoEmotions), the proposed conformal structured prediction framework achieves empirical coverage rates above the desired level (1−ε) for both marginal and PAC guarantees. For the question answering task (the primary in-text example), prediction set size decreases as ε and δ increase and as m increases; the underlying Llama-3.1-70B-Instruct model has ~33.2% accuracy, making the structured sets particularly valuable. The method produces interpretable structured prediction sets (e.g., intervals for years, coarse-grained labels for images, partial programs for code) that are significantly smaller than standard conformal prediction sets while maintaining the same coverage guarantee.

## Baselines & Comparisons

The paper compares against a single baseline adapted from Khakhar et al. (2023), which generalizes a PAC prediction set algorithm for code to arbitrary DAG structures but enforces monotonicity across τ values. The proposed method outperforms this baseline in prediction set size for almost every hyperparameter setting across all five domains, with the most significant improvements at m=2 and m=4 (where the baseline's monotonicity constraint is most restrictive). Both methods achieve coverage above the desired level, though the baseline's coverage rates (shown in Appendix Figures 11, 13, 16, 19) are comparable. In terms of computational cost, the proposed approach is significantly faster than the baseline for question answering and ImageNet, and faster under marginal guarantees for 2-digit MNIST, though it is slightly slower for 3-digit MNIST. The speed advantage is attributed to the proposed method having fewer structural restrictions on prediction sets across different τ values, enabling more efficient sequential search.

## Relation to Prior Work

This paper extends the conformal prediction framework (Vovk et al., 2005) to structured label spaces by adapting the learn-then-test sequential search (Angelopoulos et al., 2022) to handle the non-monotonicity that arises when prediction sets are structured (e.g., DAG node subsets) rather than simple level sets of a scoring function. Prior work on conformal prediction for structured outputs—code generation (Khakhar et al., 2023), question answering (Mohri & Hashimoto, 2024; Quach et al., 2024)—was domain-specific and relied on monotonicity assumptions that do not hold in general. The paper also extends PAC/training-conditional coverage guarantees (Vovk, 2012; Park et al., 2020) to the structured setting, providing the first general algorithm that works for arbitrary DAG-structured prediction sets via an integer programming formulation.

## Why It Matters / Open Questions

This is the first general framework for conformal structured prediction, enabling interpretable uncertainty quantification for complex outputs (hierarchical labels, date ranges, partial programs) with formal marginal or PAC coverage guarantees. The DAG + integer programming formulation is flexible and can be instantiated for many domains, though computational cost can grow for dense DAGs (e.g., 3-digit MNIST). Open questions include scalability to very large or dynamically varying DAG structures, combining the framework with alternative risk control objectives (Angelopoulos et al., 2024), and whether the IP can be replaced by more efficient combinatorial algorithms for specific DAG topologies. The practical impact is most relevant to safety-critical applications where interpretable prediction sets with guaranteed coverage are needed.

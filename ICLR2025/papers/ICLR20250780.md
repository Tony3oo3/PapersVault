## Problem

Fine-tuning pre-trained embedding models for k-NN retrieval is either computationally expensive (fine-tuning the model itself, requiring parameter access and GPU hours) or yields only modest accuracy gains (training small adaptor models on top of frozen embeddings). No existing approach simultaneously provides large accuracy improvements, runs in minutes, works with closed-source models, and incurs zero additional deployment cost.
![Teaser figure](../imgs/ICLR20250780/cropped_page1_idx0.webp)

## Input / Output

The method consumes pre-computed d-dimensional data embeddings (no model forward passes are needed), a set of training queries with their ground-truth answer indices, and a validation set for selecting the constraint parameter γ. It outputs a modified embedding matrix D* = D + Δ where each row is shifted by at most γ in L2 norm (NUDGE-M) or constrained to remain on the unit sphere (NUDGE-N). The fine-tuned embeddings are a drop-in replacement for the original embeddings in any vector database, requiring no additional model inference at query time.

## Method

NUDGE treats the data embeddings themselves as the parameters of the k-NN retrieval algorithm, directly modifying them to maximize retrieval accuracy. The unconstrained problem is NP-hard (MaxA-EFT) or unbounded (MaxS-EFT), so NUDGE solves constrained variations: NUDGE-M bounds the L2 norm of each embedding change (‖Δ_i‖ ≤ γ), while NUDGE-N additionally forces fine-tuned embeddings to remain normalized (‖D_i + Δ_i‖ = 1). The closed-form update rule moves each data embedding toward the normalized sum of query embeddings for which it is the ground-truth answer (G_i = Σ_j I[i=Y_j] Q_j), with γ controlling the magnitude of the shift. The optimal γ is selected by maximizing validation accuracy, which reduces to finding the value intersecting the most linear (NUDGE-M) or quadratic (NUDGE-N) intervals — solvable in O(n_V(nd + log n_V) + n_T d). Crucially, only data records appearing as ground-truth answers in the training set are modified, leaving all other embeddings untouched, which distinguishes NUDGE from parametric methods that alter the embedding function globally.

## Results

Across 7 text retrieval datasets and 3 embedding models (BGE-S, GTE-L, TE3-L), NUDGE-N achieves an average NDCG@10 boost of +9.4 to +12.4 over no fine-tuning, while NUDGE-M achieves +7.7 to +11.0. In contrast, Adaptor improves NDCG@10 by only +2.2 to +2.9 and PTFT by +3.8 (BGE-S only). On image retrieval (COCO, Flickr), NUDGE-N boosts NDCG@10 by +14.3 (CLIP-B) and +10.8 (CLIP-L), versus +3.0 and +4.0 for Adaptor. NUDGE runs in 1–2 minutes on GPU (vs. 7.99 min for Adaptor and 447 min for PTFT), with no additional inference cost at deployment.

## Baselines & Comparisons

NUDGE decisively outperforms both parametric baselines across all 9 datasets and 5 embedding models. Against Adaptor (Suvansh Sanjeev, 2024), NUDGE-N achieves 3–5× larger NDCG@10 improvements: e.g., +12.4 vs. +2.9 on BGE-S, +9.4 vs. +2.4 on GTE-L, and +11.7 vs. +2.2 on TE3-L, while also running ~3.7× faster (2.18 min vs. 7.99 min on GPU). Against PTFT (fine-tuning the pre-trained model with the MNR contrastive loss from Henderson et al., 2017), NUDGE-N provides 3.3× higher average accuracy boost (+12.4 vs. +3.8 on BGE-S) and runs 200× faster (2.18 min vs. 447 min on GPU); PTFT could not be run on CPU at all. Notably, Adaptor and PTFT sometimes fail to improve accuracy on individual datasets (e.g., zero gain on ArguAna, TriviaQA, and Fever for both methods with BGE-S), whereas NUDGE consistently provides positive gains without any hyperparameter tuning. The paper also shows that combining NUDGE-N with Adaptor or PTFT (A+NUDGE-N, P+NUDGE-N) yields the best out-of-distribution label generalization while preserving NUDGE's large in-distribution accuracy gains.

## Relation to Prior Work

NUDGE departs from the two established paradigms for embedding fine-tuning—directly fine-tuning the pre-trained model (PTFT) and training adaptor transformations on frozen model outputs—by treating the data embeddings themselves as the parameters to optimize. Rather than learning a parametric function via contrastive losses (MNR, etc.), NUDGE solves constrained convex optimization problems (bounded L2 norm, unit-sphere constraint) with closed-form KKT-based solutions that directly shift each data embedding toward its associated training queries. The paper draws a conceptual parallel to RLHF/DPO-style output-constrained fine-tuning (Ouyang et al., Rafailov et al.), where the constraint on how much model output can change prevents semantic distortion, but applies this principle to the retrieval embedding space rather than language model logits.

## Why It Matters / Open Questions

For RAG and retrieval practitioners, NUDGE offers a drop-in, model-agnostic fine-tuning step that runs in minutes on CPU, works with closed-source embedding APIs, and requires no additional model hosting at deployment—addressing the three main practical barriers of PTFT. The key limitation is that NUDGE alone provides limited out-of-distribution generalization (it only modifies embeddings for data records with associated training queries), though the paper shows it composes well with parametric methods to inherit their OoD behavior while retaining large in-distribution gains. Open questions include integrating NUDGE directly into vector database pipelines, automatically generating and maintaining the query/label sets it requires, and whether the constrained-optimization framing extends to other model-output fine-tuning settings beyond retrieval.

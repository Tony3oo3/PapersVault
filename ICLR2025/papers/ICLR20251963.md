## Problem

In standard ANNs, backpropagation optimizes a single global objective, leaving the computational role of individual neurons opaque and hindering local interpretability. While biological neurons learn from locally available information, prior information-theoretic local learning rules lacked the expressiveness to describe how multiple input sources integrate redundantly, uniquely, or synergistically into an output. This paper asks whether Partial Information Decomposition (PID) can be used constructively to design per-neuron objective functions that are both interpretable and match backpropagation performance.

## Input / Output

The network takes 28×28 grayscale MNIST or 32×32 RGB CIFAR-10 images as feedforward input and produces a 10-way class label. Unusually, each hidden neuron receives three distinct input classes: the raw image (feedforward F), a relevance signal (context C, the one-hot label during training but zeroed at inference), and the outputs of same-layer peers (lateral L), creating intra-layer recurrence that requires two forward passes per sample. The neuron output is a stochastic binary firing decision, with the output layer selecting the highest-probability neuron as the network prediction.

## Method

The core contribution is the trivariate infomorphic neuron, which replaces backpropagation with a local PID-based goal function G = γ^T Π, where Π is a 19-element vector of PID atoms (18 information atoms plus residual entropy) computed via the differentiable shared-exclusion redundancy measure I_cap^sx. Each neuron independently adjusts its synaptic weights by gradient ascent on its own goal function, with the three input classes enabling simultaneous task-relevance (redundancy between F and C) and self-organization (uniqueness with respect to L). The goal parameters γ can be set heuristically (maximizing the single atom Π_{F}{C}) or discovered via hyperparameter optimization (TPE/CMA-ES), revealing that four PID atoms are critical for MNIST performance. On MNIST, the optimized trivariate network reaches 97.5% test accuracy with 2000 hidden neurons, approaching the 98.0% of an equivalent backpropagation network, while providing per-neuron interpretability of what information each neuron aims to encode.

## Results

On MNIST with 100 hidden neurons, the trivariate infomorphic network with an optimized PID goal function achieves 94.9% test accuracy, up from 92.8% with the heuristic goal (maximizing only Π_{F}{C}). At 2000 hidden neurons with sparse lateral connectivity (setup 2), the infomorphic network reaches 97.5% test accuracy, slightly below the 98.0% achieved by an equivalent backpropagation-trained network. On CIFAR-10 (100 hidden neurons), a task-specific CMA-ES optimization of the goal parameters yields 42.5% test accuracy, marginally exceeding the 42.2% backpropagation baseline and the 41.1% obtained by transferring the MNIST-optimized goal.

## Baselines & Comparisons

The primary baseline is the bivariate infomorphic neuron from Makkeh et al. (2025), which uses only two input classes (feedforward and context). The trivariate extension with lateral connections significantly outperforms the bivariate model at 100 hidden neurons on MNIST, confirming that three input classes are necessary for effective self-organization. Against a backpropagation-trained network with identical architecture, the trivariate infomorphic network matches performance at 100 neurons (94.9% vs. comparable backprop accuracy) and reaches 97.5% at 2000 neurons with sparse connectivity, just 0.5% below backprop's 98.0%. On CIFAR-10, the infomorphic approach with a task-specific optimized goal (42.5%) slightly edges out backpropagation (42.2%), while transferring the MNIST-optimized goal without re-optimization still achieves 41.1%, demonstrating reasonable cross-task transfer. The paper also shows that the linear activation function variant performs on par with the sigmoid-based one (94.9–95.1%), indicating the results are not an artifact of a particular nonlinearity.

## Relation to Prior Work

This paper inverts the typical use of Partial Information Decomposition (PID): rather than analyzing trained networks (as in Tax et al. 2017, Ehrlich et al. 2023), it uses PID atoms as constructive building blocks for per-neuron learning objectives. It directly extends the bivariate infomorphic neuron framework of Makkeh et al. (2025) to three input classes (feedforward, context, lateral), leveraging the trivariate PID formalism of Gutknecht et al. (2021) and the differentiable shared-exclusion redundancy measure of Makkeh et al. (2021). Conceptually, it departs from both global backpropagation and mechanistic local rules (Hebbian, predictive coding, contrastive) by formulating learning goals in abstract, interpretable information-theoretic language that specifies *what* information a neuron should encode rather than *how* to update weights.

## Why It Matters / Open Questions

The framework provides a principled, interpretable alternative to backpropagation where each neuron's learning goal is explicitly stated in terms of redundant, unique, and synergistic information processing — a level of interpretability absent from standard training. The ablation revealing that only 4 of 19 PID parameters are critical for MNIST offers concrete insight into the local computational structure of classification. However, the evidence is limited to MNIST and CIFAR-10 with at most one fully optimized hidden layer; scaling to deeper architectures, continuous-valued neurons, and more complex tasks remains open, as does establishing a formal bridge between these abstract PID goals and known mechanistic plasticity rules in biological neurons.

## Problem

Existing visual prompt tuning methods adapt a single pre-trained model, overlooking the synergies that arise from integrating diverse domain knowledge (e.g., general visual features from DINO plus medical-specific features from LVM-Med) within the same tuning process. The key challenge is how to dynamically coordinate and fuse expertise from multiple domain experts—handling conflicts and redundancies—without inflating computational costs or overfitting to any single domain.
![Teaser figure](../imgs/ICLR20252868/cropped_page3_idx0.webp)

## Input / Output

The method takes a single RGB or medical image (X-ray, OCT, CT, MRI, endoscopy, dermoscopy) as input, which is simultaneously patchified by K pre-trained ViT-B/16 or ViT-L/16 backbones (each serving as a domain expert). For classification, it outputs a class label via a task-specific head applied to the averaged final-layer representations across all experts; for segmentation, it outputs a pixel-wise mask using a SETR decoder. The backbone weights remain frozen throughout; only the expert prompt tokens and the shared dispatcher MLPs are trained.

## Method

PMOE introduces two core components: (1) Expert Prompt Tokens (EPTs), where each of K pre-trained ViT experts receives its own dedicated set of learnable prompt tokens injected layer-wise, and (2) a shared dynamic Dispatcher layer inserted before each transformer block. The dispatcher takes the current expert's EPTs, accumulated prompt tokens from the previous layer, and patch tokens as input, and via MLPs + softmax produces per-token dispatching weights of dimension K. These weights perform a weighted combination of the n-th EPT across all K experts to form Integrated Prompt Tokens (IPTs), which then interact only with the corresponding expert's patch tokens in the next transformer layer. This design enables cross-expert communication at the dispatcher while preserving expert-specific processing in the transformer blocks, and the framework is plug-compatible with existing prompt tuning variants (VPT, GaPT, LSPT) as long as prompt tokens exist.

## Results

On the VTAB-1K benchmark with supervised ImageNet-21K ViT-B/16, LSPT+PMOE achieves 80.31 average accuracy, surpassing the previous best (LSPT) by 2.36 points and VPT by 10.89 points. On DINO v2 pre-trained models, LSPT+PMOE reaches 86.07 on CUB, 96.58 on Oxford Flowers, and 53.97 on Structured VTAB-1K tasks, outperforming LSPT by 1.22, 1.01, and 0.59 respectively. For medical imaging, LSPT+PMOE achieves 75.68 mIoU on Kvasir polyp segmentation and 80.35 on ISIC skin lesion segmentation (MAE backbone), and 82.39 AUC on COVIDx chest X-ray classification. On ADE20K semantic segmentation, LSPT+PMOE reaches 42.87 mIoU (multi-scale) with MAE, a 1.36-point gain over LSPT.

## Baselines & Comparisons

PMOE is evaluated as an add-on module to three existing prompt tuning methods (VPT, GaPT, LSPT), consistently improving each across all 47 benchmarks. Against VPT (Jia et al., 2022), LSPT+PMOE gains 10.89 points on VTAB-1K average (80.31 vs 69.42) and 3.40 on CUB (86.07 vs 82.67). Against GaPT (Yoo et al., 2023), LSPT+PMOE leads by 2.55 on CUB and 3.91 on Structured VTAB-1K. Against LSPT (Mo et al., 2024b), the closest competitor, PMOE adds 1.22 on CUB, 1.01 on Flowers, 2.36 on VTAB-1K average, 4.15 on Kvasir polyp segmentation, and 3.52 on Vindr chest X-ray. On the supervised ImageNet-21K VTAB-1K setting (Table 1), LSPT+PMOE (80.31) also outperforms EXPRES (70.21), SNF (74.10), and Bi-AdaptFormer (74.73) by 10.10, 6.21, and 5.58 points respectively. PMOE never loses to any baseline in any reported comparison, with the smallest margin being +0.59 on Structured VTAB-1K (DINO v2) over LSPT.

## Relation to Prior Work

This paper extends the visual prompt tuning lineage (VPT → GaPT → LSPT) by introducing a Mixture-of-Experts mechanism that operates over multiple pre-trained ViT backbones simultaneously, rather than adapting a single model. The core departure is the dynamic dispatcher module, which borrows the routing concept from NLP MoE (Shazeer et al., 2017) and applies it to fuse expert-specific prompt tokens across layers, enabling cross-domain knowledge exchange during adaptation. Unlike prior prompt tuning methods that are confined to one knowledge source, PMOE treats each pre-trained model as a 'domain expert' and learns task-dependent weighting of their prompt contributions, making it a plug-in extension compatible with existing prompt architectures (VPT, GaPT, LSPT).

## Why It Matters / Open Questions

PMOE offers a practical path for multi-domain visual adaptation, particularly relevant in medical imaging where combining general-purpose and domain-specific pre-training (e.g., DINO + LVM-Med) yields consistent gains across 47 tasks. The dispatcher's lightweight design (shared MLPs) keeps parameter overhead minimal, preserving the efficiency advantage of prompt tuning. Open questions include how the method scales beyond 6 experts (diminishing returns observed), whether the dispatcher generalizes to non-ViT architectures, and whether the benefits persist when experts are from the same domain rather than complementary ones. The paper does not deeply analyze failure modes or cases where multi-expert fusion could be detrimental.

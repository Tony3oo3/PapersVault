## Problem

While GNNs rely heavily on the k-hop neighborhood structure of test nodes for inference, no existing method quantifies the individual importance of these test-time neighbors through data valuation. Traditional game-theoretic valuation requires ground-truth labels to define a utility function, which are unavailable at test time, and existing utility-learning approaches are tied to specific player sets (training subsets) and optimize accuracy indirectly rather than Shapley values directly.

## Input / Output

The method consumes a labeled training graph, a labeled validation graph, an unlabeled test graph, and a fixed pre-trained GNN (SGC or GCN). It produces a value-assignment function φ: N(V_t) → ℝ that scores each k-hop neighbor of target test nodes by its marginal contribution to GNN performance. The k-hop radius is set to the number of GNN layers to match the receptive field, and the utility function is learned on validation-node neighbors (where accuracy is computable) then transferred to test-node neighbors via player-agnostic features.

## Method

SGUL combines two key innovations. First, a transferable feature extractor replaces player-specific binary vectors with 9 label-free features—3 data-specific (edge cosine similarity, representation distance, classwise representation distance) and 6 model-specific (max/target/propagated confidences, negative entropy, confidence gap)—that capture subgraph structure and GNN behavior without test labels, enabling generalization from validation to unseen test neighbors. Second, a Shapley-guided optimization exploits a proven decomposition theorem showing that for a linear utility U(S) = wᵀx(S), each player's Shapley value equals wᵀψᵢ where ψᵢ is the precomputed Feature Shapley vector. This reduces the learning problem to a single L1-regularized linear regression on precomputed Feature Shapley Values (targets from validation accuracy), directly minimizing Shapley-value error rather than accuracy error, yielding lower memory usage (~4× less) and better node-dropping AUC than the accuracy-optimized variant.

## Results

SGUL is evaluated via node-dropping experiments where lower AUC (Area Under the Curve of the accuracy-vs-nodes-removed curve) indicates better data valuation. SGUL consistently achieves the lowest AUC across all seven datasets (Cora, Citeseer, Pubmed, Coauthor-CS, Coauthor-Physics, Roman-empire, Amazon-ratings) and both SGC and GCN architectures in the inductive setting, and on Cora/Citeseer/Pubmed in the transductive setting. In ablation, SGUL-Shapley (direct Shapley optimization) outperforms SGUL-Accuracy in 10 of 14 dataset-model combinations and reduces peak memory from 29–116 MB to a consistent ~16 MB (e.g., 16.59 MB vs. 115.62 MB on Amazon-ratings, a ~86% reduction).

## Baselines & Comparisons

SGUL outperforms all three primary baselines across every dataset and model architecture tested. Against ATC (Garg et al., 2022), which estimates accuracy via thresholded confidence scores (ATC-MC and ATC-NE variants), SGUL produces steeper initial accuracy drops and more stable long-term curves in node-dropping experiments, indicating superior identification of critical neighbors. Against DoC (Guillory et al., 2021), which predicts accuracy from the confidence gap between validation and test sets, SGUL again dominates, particularly on heterophilic datasets like Amazon-ratings and Roman-empire where confidence-based methods struggle. Against GNNEvaluator (Zheng et al., 2024b), a GCN-regressor-based method for label-free GNN evaluation, SGUL not only achieves lower AUC but also avoids the Out-of-Memory failures that GNNEvaluator encounters on larger datasets (Coauthor-CS, Coauthor-Physics, Amazon-ratings), making GNNEvaluator inapplicable to those settings. The natural confidence baselines (Maximum Confidence, Class Confidence) are the weakest, confirming that simple confidence metrics are insufficient for fine-grained neighbor valuation.

## Relation to Prior Work

This paper extends the Structure-Aware Shapley value framework from PC-Winter (Chi et al., 2024a), which valued training-time graph elements using both Level and Precedence Constraints, to the test-time inference setting where only the Precedence Constraint applies and ground-truth labels are unavailable. It also builds on data utility learning (Wang et al., 2021), which approximates utility functions via regression on player-specific binary vectors, but departs from it in two key ways: replacing player-dependent inputs with transferable data-specific and model-specific features, and replacing indirect accuracy-based optimization with direct Shapley-value optimization enabled by a linearity decomposition theorem. The label-free model evaluation literature (ATC, DoC, GNNEvaluator) provides the conceptual foundation for estimating performance without labels, but those methods target single-point accuracy estimation rather than the fine-grained per-node valuation required here.

## Why It Matters / Open Questions

By formulating graph inference data valuation as a distinct problem and providing the first practical solution, this work opens a path toward quantifying the value of dynamic test-time graph structures in real-world applications such as real-time recommendation and dynamic social networks. The Shapley Value Decomposition Theorem offers a reusable theoretical tool that could simplify Shapley estimation in other linear-utility settings. However, the approach is constrained to k-hop neighborhoods (k = GNN depth), relies on a hand-designed feature set whose coverage may not generalize to all GNN architectures or graph types, and the linear utility assumption limits expressiveness. Open questions include whether the method scales to very large dynamic graphs, whether nonlinear utility functions can be handled, and how the valuation interacts with test-time adaptation methods that modify the graph or model.

## Problem

Existing ML-based node selection for branch-and-bound suffers from two gaps: (P1) no representation captures the full B&B tree without exponential blowup, as prior work only encodes individual nodes or node pairs as bipartite graphs supplemented by hand-crafted global features; (P2) imitation learning is bounded by oracle quality, which sometimes fails to beat the default SCIP rule. The paper asks whether a compact tree representation can be proven information-theoretically sufficient and whether a richer reward signal can overcome the oracle ceiling.

## Input / Output

The method consumes a weighted tripartite graph G=(V∪C∪LN, E^C∪E^B) built from the current B&B tree, where variable and constraint vertices carry the root MILP structure and leaf node vertices encode only the unique branching constraints (x_i≥a, x_i≤b) distinguishing each candidate from the root. A BestEstimate heuristic pre-selects n=5 candidate nodes, and the model outputs a Q-value vector of dimension n; the node with the maximum Q-value is selected. The graph is permutation-invariant by construction, avoiding overfitting to variable/constraint ordering.

## Method

The core contribution is a tripartite graph representation proven sufficient via the data processing inequality: Theorem 4.2 shows parent-node features are recoverable from child-node features, so leaf nodes alone encode the entire tree, and Theorem 4.1 establishes I(Q; φ_t(F)) = I(Q; F). On top of this representation, a GNN agent (32-dim embedding → three GCN layers of widths 8/4/4 → per-partition averaging → concatenation with global features → linear + sigmoid) is trained via reinforcement learning in an MDP where the state is the tripartite graph and the action is selecting one of n pre-filtered candidates. The reward function R(N) = w₁R_g + w₂R_o − w₃R_s combines global gap updates, an optimal-solution-path indicator, and a normalized path-switching penalty (steps to common ancestor), addressing delayed rewards that imitation learning cannot capture. This RL formulation requires far fewer training samples (~250 vs. ~1000 for imitation baselines) and is the first learning-based node selector to consistently outperform default SCIP across all six benchmarks.

## Results

TRGNN achieves solving time improvements of +31.44% (FCMCNF), +7.54% (MaxSAT), +13.92% (GISP), +59.42% (MIK), +37.89% (CORLAT), and +50.91% (Anonymous) over the default SCIP solver, making it the only learning-based node selection method to outperform SCIP across all six benchmarks. On the largest real-world dataset (Anonymous, ~50,000 nodes), TRGNN reduces solving time from 215.28s to 105.68s while winning 20/20 instances. In the generalization experiment on larger instances, TRGNN further improves by +15.68% (FCMCNF), +36.67% (MaxSAT), and +20.51% (GISP) over SCIP, with GISP showing a perfect 50/50 win rate.

## Baselines & Comparisons

TRGNN decisively outperforms all four baselines (SCIP, SVM, RankNet, GNN) on every one of the six datasets in solving time. The imitation-learning baselines SVM (He et al., 2014) and RankNet (Song et al., 2018) actually degrade performance relative to SCIP on most datasets — e.g., SVM is 28.35% slower on GISP and 34.46% slower on MIK, while RankNet is 62.99% slower on MIK — confirming the paper's argument that imitating a suboptimal oracle is counterproductive. The GNN baseline (Labassi et al., 2022), which uses a bipartite graph per node pair, beats SCIP only on FCMCNF (+7.19%) and MaxSAT (+2.07%) but loses on GISP (−7.99%), MIK (−36.99%), CORLAT (−30.84% improvement but still slower than TRGNN), and Anonymous (−26.07%). TRGNN's advantage is most dramatic on the large-scale Anonymous dataset (50.91% faster than SCIP, 20/20 wins) and MIK (59.42% faster), where the tripartite graph's ability to capture global tree structure and the RL reward's path-switching penalty provide the greatest benefit.

## Relation to Prior Work

This paper extends the line of ML-based node selection in branch-and-bound (He et al. 2014, Song et al. 2018, Yilmaz & Yorke-Smith 2020, Labassi et al. 2022) by addressing two gaps those methods leave open: (1) prior work represents only individual nodes or pairs of nodes as bipartite graphs supplemented by hand-crafted global features, whereas here the entire search tree is encoded as a single tripartite graph (variables, constraints, leaf nodes) whose sufficiency is proven via the data processing inequality; and (2) prior methods rely on imitation learning from an oracle that sometimes fails to beat SCIP, while this paper replaces imitation with reinforcement learning that captures delayed rewards including path-switching overhead. The bipartite-graph MILP representation of Gasse et al. (2019) is the direct structural ancestor, extended here by adding a third partition for leaf-node branching constraints.

## Why It Matters / Open Questions

TRGNN is the first learning-based node selector to consistently outperform SCIP's default BestEstimate rule across all six evaluated benchmarks, and it generalizes to instances roughly 2–3× larger than those seen in training, which is practically significant for industrial-scale MILPs where collecting training data is expensive. A notable limitation is that the tripartite graph is tailored to pure branch-and-bound and does not model cutting planes or restarts, so extending the representation to branch-and-cut remains open. The finding that solving-time gains do not always correspond to fewer B&B nodes (path-switching cost can dominate) reframes how node-selection quality should be measured and suggests that future solvers should treat transition overhead as a first-class optimization target.

## Problem

Quadratic programming with a general positive semidefinite objective requires Ω(n²) time under SETH, yet SVMs exploit a low-rank quadratic matrix and only O(1) equality constraints, suggesting faster algorithms should exist. Prior interior-point approaches for linear SVMs (e.g., Ferris & Munson, 2002) still incur an O(n^{1.5}) dependence on dataset size, while first-order methods suffer polynomial dependence on the precision parameter 1/ε. This paper asks whether the structural properties of SVM QPs—low-rank objective and few constraints—can yield nearly-linear time algorithms with only logarithmic dependence on 1/ε.

## Input / Output

The algorithm takes a labeled dataset X ∈ R^{n×d} with binary labels y ∈ {±1}^n and solves the dual SVM quadratic program, which has a single equality constraint α^⊤y = 0 and non-negativity constraints α ≥ 0. For linear SVM, the quadratic matrix (yy^⊤ ∘ XX^⊤) has rank at most d, so the input is implicitly given by the n×d data matrix rather than an explicit n×n matrix. For Gaussian kernel SVM, the kernel matrix K is never formed explicitly; instead, a rank-n^{o(1)} factorization K̃ = UV^⊤ is computed in O(n^{1+o(1)}) time when d = O(log n) and the squared dataset radius B = o(log n / log log n). The output is the dual solution vector α ∈ R^n, from which the primal separating hyperplane w = Σᵢ αᵢyᵢxᵢ is recovered.

## Method

The core contribution is a robust interior-point method (IPM) for QPs whose quadratic objective admits a low-rank factorization Q = UV^⊤ (rank k) or a low-treewidth sparsity pattern, combined with dedicated data structures for maintaining the central path. For the low-rank case, the key insight is that M = Q + tH (where H is the diagonal Hessian of the barrier) can be inverted via the Woodbury identity without ever explicitly forming M^{-1/2}, since updates to H are sparse (only Õ(n log(1/ε)) coordinate changes total). The primal-dual pair (x, s) is maintained implicitly as a combination of sparsely-changing 'coefficient' vectors and a fixed 'basis' matrix, with heavy entries detected via a balanced binary tree and Johnson-Lindenstrauss sketches. For the low-treewidth case, a sparse Cholesky factorization M = LL^⊤ is maintained under diagonal updates, and an elimination tree with heavy-light decomposition enables efficient subtree norm queries. For Gaussian kernel SVM, the rank-n^{o(1)} polynomial approximation factorization of the kernel matrix (from Aggarwal & Alman, 2022) is plugged into the low-rank QP solver, yielding the first almost-linear time algorithm O(n^{1+o(1)} log(1/ε)) for this setting.

## Results

For linear SVM with d-dimensional data (d ≤ n), the paper achieves a nearly-linear runtime of Õ(n·d^((ω+1)/2)·log(1/ε)) where ω ≈ 2.37 is the fast matrix multiplication exponent, improving upon the prior best IPM-based bound of O(n^1.5·d^(ω−1)·log(1/ε)) from Ferris & Munson (2002). For Gaussian kernel SVM with d = O(log n) and squared dataset radius B = o(log n / log log n), the algorithm runs in O(n^{1+o(1)}·log(1/ε)) time — the first almost-linear time algorithm for kernel SVM. On the hardness side, assuming SETH, the paper proves Ω(n^{2−o(1)}) lower bounds for Gaussian kernel SVM when B = Ω(log² n) (without bias) and B = Ω(log⁶ n) (with bias), improving upon the prior lower bound of Backurs et al. (2017) in the dimension parameter.

## Baselines & Comparisons

The paper's main algorithmic improvement is over the prior IPM-based linear SVM solver of Ferris & Munson (2002), which required O(n^1.5·d^(ω−1)·log(1/ε)) time; the new algorithm reduces the n-dependence from n^1.5 to nearly-linear n while changing the d-dependence from d^(ω−1) to d^((ω+1)/2). Compared to first-order methods (Joachims 2006: Õ(ε⁻²·B·nnz(A)); Shalev-Shwartz et al. 2011: Õ(ε⁻¹·d)), the new algorithm achieves polylog(1/ε) dependence instead of polynomial, making it viable for high-precision settings (e.g., ε = 10⁻³). For Gaussian kernel SVM, no prior almost-linear time algorithm existed; the paper's result leverages the rank-n^{o(1)} factorization of Aggarwal & Alman (2022) combined with the new low-rank QP solver. The hardness results improve upon Backurs et al. (2017), who established lower bounds requiring d = ω(log n) and B = ω(log n); the new bounds only require d = Ω(log n) and B = Ω(log² n) (or Ω(log⁶ n) with bias), tightening the dimension requirement.

## Relation to Prior Work

This paper extends the robust interior point method (IPM) framework, originally developed for linear programming (Cohen et al., 2019) and convex empirical risk minimization (Lee et al., 2019), to the setting of quadratic programming with structured objective matrices. The key technical departure is handling the additional -Qx term in the central path equations, which requires new data structures for maintaining M^{-1/2} when Q admits a low-rank factorization (via Woodbury identity) or a sparse Cholesky decomposition (via treewidth structure). For the Gaussian kernel SVM result, the paper composes its low-rank QP solver with the rank-n^{o(1)} polynomial approximation of the Gaussian kernel from Aggarwal & Alman (2022), while the hardness results build on and improve the SETH-based lower bounds of Backurs et al. (2017) by tightening the dimension and radius regimes.

## Why It Matters / Open Questions

This is the first nearly-linear time algorithm for linear SVM and the first almost-linear time algorithm for Gaussian kernel SVM, resolving a long-standing gap between the quadratic input size of general QPs and the structural properties (low-rank objective, O(1) equality constraints) that SVMs naturally exhibit. The complementary hardness results sharpen the SETH-based lower bounds, showing that the algorithmic regime (d = O(log n), sub-logarithmic radius) is essentially tight. Open questions include improving the k^{(ω+1)/2} dependence on rank, handling larger numbers of equality constraints, and closing the gap between the algorithm's sub-logarithmic radius requirement and the Ω(log² n) hardness threshold for biased SVMs. For practical DL/CV work, the impact is indirect but the robust IPM machinery for structured QPs could inform future solvers for related convex problems.

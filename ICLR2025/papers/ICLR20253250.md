## Problem

Existing parameter-efficient incremental learning methods, particularly LoRA-based adapters, still require tens to hundreds of thousands of task-specific trainable parameters per task, making them impractical for resource-constrained edge devices and mobile phones. No prior reparameterization scheme achieves extreme parameter efficiency (fewer than 50 task-specific parameters) while matching or exceeding the performance of full adapter-based approaches.
![Teaser figure](../imgs/ICLR20253250/cropped_page1_idx0.webp)

## Input / Output

The method consumes standard 224×224 RGB images and outputs class labels in a task-incremental setting where new categories are introduced sequentially across six datasets (Oxford Flowers, FGVC-Aircraft, MIT Scenes, CIFAR-100, CIFAR-10, CUB-200-2011). The unusual aspect is that the model's backbone weights are not stored directly but are dynamically generated at inference time from a small set of frozen shared templates and per-task scalar coefficients, meaning the only per-task storage is a handful of coefficient values (on the order of 10⁻⁶ of total model parameters).

## Method

RECAST decomposes each layer's weight matrix into a linear combination of shared template matrices (grouped so that layers within a group share a common template bank) and module-specific scalar coefficients, with K independent coefficient sets averaged to produce the final weight. A key innovation, Neural Mimicry, reconstructs pretrained weights into this template-and-coefficient representation by minimizing a Smooth L1 loss between original and generated weights, requiring only minutes of computation and no task data. During incremental learning, all templates remain frozen and only the small set of per-task coefficients (n×K scalars per module) are updated, yielding fewer than 50 trainable parameters per task. The framework is architecture-agnostic (applied to FC layers, attention QKV projections, and convolution kernels in both ResNet and ViT backbones) and can be combined additively with existing adapter methods like PiggyBack, CLR, AdaptFormer, MeLo, and RoSA to further boost performance by ~1.5%.

## Results

On ViT-Small, RECAST alone achieves 85.0% top-1 accuracy (vs. 82.4% baseline) using only 2×10⁻⁶ of total parameters per task, while RECAST+AdaptFormer reaches 90.1%, the best result across all 16 baselines. On ResNet-34, RECAST achieves 66.3% (vs. 65.2% baseline) with 3×10⁻⁶ task parameters, and RECAST+Piggyback reaches 83.9%. The Neural Mimicry reconstruction step requires less than 5 minutes and under 4.5 GB GPU memory even for ViT-Large (~304M params), achieving 98–100% weight reconstruction similarity.

## Baselines & Comparisons

RECAST decisively outperforms all regularization and rehearsal baselines: EWC (22.1%), LwF (19.3%), GDUMB (34.8%), ER-ACE (36.1%), DER++ (16.2%), and HAT (40.0%) on ResNet-34 all suffer severe catastrophic forgetting, while RECAST achieves 66.3% with only 3×10⁻⁶ task parameters. Against the strongest adapter baselines on ViT-Small, RECAST alone (85.0%) trails DoRA (89.3%), AdaptFormer (89.0%), and InfLoRA (88.5%), but when combined with these methods, RECAST consistently adds ~1–1.5%: RECAST+AdaptFormer reaches 90.1% (+1.1% over AdaptFormer), RECAST+MeLo reaches 89.6% (+0.9%), and RECAST+RoSA(SpA MLP) reaches 85.4% (+0.9%). On ResNet-34, RECAST+Piggyback (83.9%) and RECAST+CLR (80.9%) each improve their respective standalone baselines by ~1%. The prompting-based L2P method (35.9%) underperforms the ViT-Small baseline by 56%, confirming that instance-level prompts struggle with diverse domain shifts. Overall, RECAST's key advantage is its extreme parameter efficiency (<50 trainable parameters per task) while still providing complementary gains when stacked with higher-budget adapter methods.

## Relation to Prior Work

RECAST extends the weight-sharing-through-decomposition lineage established by Savarese & Maire (2019) and Plummer et al. (2022), which demonstrated that shared template banks with module-specific coefficients can parameterize networks, but those methods required training from scratch and did not address incremental learning. The key departure is the Neural Mimicry reconstruction pipeline, which decomposes existing pretrained weights into the template/coefficients framework in minutes, enabling RECAST to leverage any pretrained backbone without costly retraining. Unlike LoRA-based IL methods (InfLoRA, DoRA, RoSA, MeLo) that add tens to hundreds of thousands of task-specific adapter parameters, RECAST directly reparameterizes backbone weights using fewer than 50 coefficients per task, positioning it as a fundamentally different reparameterization strategy rather than an adapter.

## Why It Matters / Open Questions

The sub-50-parameter task adaptation is several orders of magnitude more efficient than competing LoRA-based methods, making it potentially transformative for edge deployment and resource-constrained continual learning where communication and storage costs are critical. However, RECAST alone does not outperform the strongest adapter baselines; its best results come from combining with existing methods (e.g., RECAST+AdaptFormer), which raises the question of whether the efficiency gain is worth the architectural complexity in practice. Open questions include whether the approach scales to very long task sequences, whether it generalizes beyond vision (e.g., language models), and how the template diversity and coefficient versatility trade-offs evolve as the number of tasks grows.

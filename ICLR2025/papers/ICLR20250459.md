## Problem

Online class constraint scheduling admits a competitive ratio lower bound of m in classical analysis, making it intractable without additional information. This paper overcomes this barrier by studying the problem in a learning-augmented setting, showing that even minimalistic predictions of just the total processing time per class can reduce the competitive ratio from m to 2+epsilon under perfect predictions, while maintaining robustness under prediction error.
![Teaser figure](../imgs/ICLR20250459/cropped_page7_idx0.webp)

## Input / Output

Jobs arrive one-by-one with a processing time and a class label; the algorithm must immediately assign each job to one of m machines, each holding at most k distinct classes. Predictions are provided in one of three forms: full input (all jobs with times and classes), actions (a machine index per job), or class sizes (only the aggregate processing time per class, with no job-level detail). The number of classes must be known exactly a priori; the paper proves that without this, no algorithm can beat competitive ratio m regardless of any other predictions.

## Method

The central technical contribution is the class size prediction algorithm, which (i) solves the predicted instance treating each class as a single splittable job via an EPTAS, (ii) post-processes the resulting schedule using a conversion-and-transfer (CT) graph whose cycle-removal procedure eliminates all cycles and yields a Berge-acyclic hypergraph hierarchy over machines, and (iii) assigns each incoming job to a child machine of its class before falling back to the parent machine, thereby bounding per-machine overflow to at most OPT. For full input predictions, the algorithm follows the offline solution on the predicted instance and routes mispredicted jobs to the least-loaded eligible machine, achieving ratio ell/OPT + alpha. For action predictions, it follows the predicted machine when feasible, otherwise picks the least-loaded eligible machine, achieving ratio ell + 1. All three upper bounds are matched (up to constants) by adversarial lower bounds, establishing tightness.

## Results

The paper establishes competitive ratio bounds for three prediction models in online class constraint scheduling. Full input predictions yield a competitive ratio of (ℓ/OPT + α) (Theorem 3), action predictions yield (ℓ + 1) (Theorem 6), and the novel class size prediction model yields ℓ/OPT + 1 + α (Theorem 11), where ℓ is the prediction error, OPT is the offline optimum, and α is the offline approximation ratio. With perfect class size predictions (ℓ = 0, α = 1), the competitive ratio improves from the trivial m to 2 + ε. All upper bounds are shown to be (nearly) tight via matching lower bounds (Theorems 4, 7, 12).

**Summary of competitive ratio guarantees for online class constraint scheduling on m identical machines with k class slots per machine.**

| Prediction Model | Upper Bound (Competitive Ratio) | Lower Bound | Error Measure ℓ | Runtime |
|---|---|---|---|---|
| No predictions (trivial) | m | m (Thm 1) | — | O(mnk) |
| Full input prediction | ℓ/OPT + α (Thm 3) | 1 + ℓ/OPT (Thm 4) | Σ\|p̂ⱼ − pⱼ\| (L₁) | O(nmk) + T |
| Action prediction (static/dynamic) | ℓ + 1 (Thm 6) | ℓ for ℓ ≤ m−1 (Thm 7) | # wrong machine assignments | O(mnk) |
| Class size prediction | ℓ/OPT + 1 + α (Thm 11) | ℓ/OPT (Thm 12) | Σ\|Ĉ_c − C_c\| (L₁ over classes) | O(T + m²k²(m²+k²)) |

*α is the competitive ratio of the offline solver A; T is its running time. With perfect predictions (ℓ=0) and an optimal offline solver (α=1), class size prediction achieves 2+ε.*

## Baselines & Comparisons

The paper does not compare against external empirical baselines but rather establishes a structured comparison among three prediction models and the no-prediction baseline. The trivial online bound of m (Theorem 1) is the starting point that all three prediction models overcome. Among the prediction models, no single model dominates: action predictions offer the best runtime (O(mnk)) and the simplest algorithm but require predicting n individual machine assignments (hard to learn); full input predictions are easier to learn but encode O(n) information; class size predictions encode only O(#classes) information, making them the most learnable in practice, at the cost of a more complex preprocessing step (cycle removal on the CT graph) and a slightly weaker additive constant in the competitive ratio. The class size prediction model is the paper's main contribution, improving the perfect-prediction competitive ratio from m to 2+ε, which is a significant gap for large m. All three models require the number of classes to be known a priori; without this, no algorithm can beat m regardless of predictions (Theorem 1, Corollary 2).

## Relation to Prior Work

This paper extends the learning-augmented algorithmic framework (Purohit et al. 2018; Bamas et al. 2020; Antoniadis et al. 2020) to the online class constraint scheduling problem, where prior work (Epstein et al. 2022) had established that no purely online algorithm can beat a competitive ratio of m. It builds directly on the offline PTAS/EPTAS for class and cardinality constraint scheduling (Chen et al. 2016; Jansen et al. 2020) as a subroutine, and departs from the standard full-input and action prediction models by introducing a problem-specific 'class size prediction' model whose information load depends only on the number of classes rather than the number of jobs. The graph-theoretic post-processing (conversion-and-transfer graph, cycle removal, Berge-acyclic hypergraph hierarchy) is a novel structural tool not seen in prior scheduling or learning-augmented work.

## Why It Matters / Open Questions

The paper provides a clean, structured taxonomy of what predictive information helps in online class constraint scheduling, with (nearly) tight upper and lower bounds for each of three prediction models, giving a complete picture of the prediction complexity of the problem. The class size prediction model is practically appealing because it is significantly smaller and easier to learn than full-input or action predictions while still achieving a competitive ratio of 2+ε independent of m. Open questions include relaxing the assumption that the number of classes is known in advance, extending to unrelated machines, and exploring whether the Berge-acyclic structural approach generalizes to other constrained scheduling variants.

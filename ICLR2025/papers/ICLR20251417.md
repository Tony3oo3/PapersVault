## Problem

While prior work established that Transformers cannot efficiently perform function composition (Peng et al., 2024), a comparable theoretical understanding for Structured State Space Models (SSMs) was missing. This paper asks whether SSMs—positioned as a promising alternative to Transformers for sequential reasoning—face the same fundamental barriers in compositional tasks, and if so, what are the precise quantitative limits on their state size, depth, and number of reasoning steps.

## Input / Output

For function composition, the input is a natural language prompt of N tokens divided into four parts: the argument x, |A| sentences describing function g, |B| sentences describing function f, and a query asking for f(g(x)); the prompt length effectively bounds the domain size since functions must be fully described within it. For empirical tasks, inputs range from multi-digit number pairs (up to 5×5 digits), integer sequences of length 2–6 for dynamic programming, Einstein's riddle clue sets with H houses and A attributes, to word sequences for the PEN/PER Multi pointer-chasing tasks. Outputs are the composed function value, the product, a binary subsequence selection, an attribute-to-house mapping, or a sequence of neighbor words, respectively.

## Method

The paper's core contribution is a theoretical framework reducing SSM limitations to communication complexity problems. Theorem 1 shows that a one-layer SSM with embedding dimension d and precision p solving function composition over domain size n must satisfy (d²+d)p ≥ n log n, otherwise the error probability is at least R/(3n log n) where R = n log n − (d²+d)p, proven via a reduction from the function composition communication problem. Theorem 2 extends this to Chain-of-Thought prompting, proving that an SSM requires Ω(√(n log n)/(dp)) CoT steps for k-iterated composition, via reduction from the pointer chasing problem. Theorem 3 places multi-layer finite-precision SSMs in complexity class L (O(L log N) bits of memory for L layers on input length N), implying they cannot solve NL-complete problems like Derivability or 2-SAT unless L = NL. Theorem 4 proves that finite-precision SSMs are equivalent to finite-state machines and thus limited to regular languages. Empirically, the authors evaluate Jamba (7B), Mamba (2.8B), S4-H3 (2.7B), GPT-4, and GPT-4o on four composition datasets, multi-digit multiplication, dynamic programming, Einstein's puzzle, and PEN/PER Multi tasks, confirming that all models degrade sharply with increasing compositional depth and that CoT prompting helps but does not eliminate the fundamental gap.

## Results

On the four function composition benchmarks, GPT-4o achieves the highest accuracy at 51.8% (Math-QA), 56.8% (BIG-Bench Hard), 79.4% (Temporal-NLI), and 80.8% (SpaRTUN), yet still falls far below human-level performance. SSM models consistently underperform: Jamba (7B) scores 42.2% on Math-QA, Mamba (2.8B) scores 35.0%, and S4-H3 (2.7B) scores 28.6%. On the algorithmic composition tasks, all models achieve 0% accuracy on PEN regardless of prompting strategy, and even GPT-4o reaches only 9% on PER Multi with CoT. GPT-4 achieves only ~27% on 4-by-3-digit multiplication, while Jamba reaches just 17%.

## Baselines & Comparisons

The paper compares five models—GPT-4o, GPT-4, Jamba (7B), Mamba (2.8B), and S4-H3 (2.7B)—across all composition tasks. GPT-4o is the strongest overall, outperforming GPT-4 by 0.8–19.4 percentage points depending on the task (largest gap on SpaRTUN: 80.8% vs. 61.4%). Among SSM models, Jamba consistently outperforms Mamba, which in turn outperforms S4-H3 by 7–10 percentage points across all four benchmarks, confirming the importance of input-dependent (selective) state updates. Notably, on BIG-Bench Hard, Jamba (78.2%) actually surpasses both GPT-4 (58.4%) and GPT-4o (56.8%), suggesting SSMs may have an edge on certain structured logical tasks. However, on the algorithmic composition tasks (PEN and PER Multi), all models fail completely: every model scores 0% on PEN under zero-shot, few-shot, and CoT settings, and GPT-4o reaches only 1% (few-shot) and 9% (CoT) on PER Multi, while all SSM models remain at 0%.

## Relation to Prior Work

This paper extends the theoretical analysis of Transformer limitations (Peng et al., 2024; Merrill & Sabharwal, 2024) to Structured State Space Models, which had previously lacked a comparable complexity-theoretic treatment. It adapts the communication complexity reduction from Peng et al. to prove width lower bounds for one-layer SSMs (Theorem 1), generalizes the CoT framework from Merrill & Sabharwal to SSMs to derive step lower bounds (Theorem 2), and builds on Merrill et al.'s TC^0 membership result to place multi-layer SSMs in L (Theorem 3). The novel Theorem 4 establishes that finite-precision SSMs are equivalent to finite-state machines, a result not previously formalized for this architecture family.

## Why It Matters / Open Questions

The FSM equivalence (Theorem 4) provides a clean, architecture-level explanation for why SSMs fail on compositional tasks: they literally cannot represent the unbounded memory needed for context-free or NL-complete problems. Empirically, the 0% accuracy across all tested models (including GPT-4o) on the PEN task and the ~17-27% on multi-digit multiplication quantify the severity of these limitations in practice. The paper's key open question is what architectural changes—beyond simply increasing width or adding CoT steps—could transcend the regular-language barrier, pointing toward neuro-symbolic hybrids or external memory mechanisms. A limitation is that the theoretical results assume fixed precision and constant layer count, and the conjecture that deeper SSMs face similar barriers remains unproven.

## Problem

Existing ViT adapter methods achieve strong accuracy on dense prediction tasks but suffer from slow inference due to inefficient memory access operations—specifically, redundant layer normalization and frequent tensor reshaping—that are typically overlooked during network design. These memory bottlenecks prevent full utilization of GPU/CPUs and limit deployment on edge devices and real-time recognition scenarios.

## Input / Output

The network takes an arbitrary RGB image (H×W×3) and produces task-specific dense predictions: bounding boxes and instance masks for ODet/ISeg, or pixel-level class labels (H×W×C) for SSeg. The pre-trained plain ViT backbone operates at four spatial resolutions (1/4, 1/8, 1/16, 1/32 of input), and the trainable adapter interacts with the backbone at each scale via a spatial prior module that encodes the full-resolution input. Inference is measured on A100 GPUs with per-GPU batch size 2.

## Method

META introduces a Memory Efficient Adapter (MEA) block with three parallel branches—cross-shaped self-attention (CSA), feed-forward network (FFN), and lightweight depth-wise convolution (Conv)—whose outputs are concatenated and projected via a 3×3 convolution. The key memory-efficiency mechanisms are: (1) a shared layer normalization applied jointly to the Attn and FFN branches, halving normalization memory accesses; and (2) CSA, which computes self-attention separately along horizontal and vertical stripes of the feature map, eliminating the need to reshape tensors into 2D attention matrices. The MEA block is deployed as cascaded injectors (injecting task-specific features into ViT blocks) and cascaded extractors (extracting general features for the next injector), where a multi-head cascaded mechanism feeds each head's output into the next head to enrich feature diversity. A lightweight Conv branch (three 1×1 depth-wise convolutions with GLU activations) adds local inductive biases beneficial for dense predictions.

## Results

On MS-COCO (Mask R-CNN, 3×+MS schedule), META-B achieves 51.2 AP^b / 44.3 AP^m with 115.3M parameters and 8.1 GB memory consumption, outperforming ViT-Adapter-B (49.6/43.6, 120.2M params, 15.2 GB) and LoSA-B (48.6/43.8, 117.2M params, 13.0 GB). On ADE20K (UperNet, 160k iterations), META-B reaches 49.4 mIoU (50.5 with multi-scale) using only 5.9 GB MC versus 14.0 GB for ViT-Adapter-B and 10.7 GB for LoSA-B. META consistently uses ~62% of LoSA's memory consumption while achieving higher accuracy across all model scales (T/S/B/L) and all three dense prediction tasks.

## Baselines & Comparisons

META outperforms all compared ViT adapter methods (ViT-Adapter, AdaptFormer, FacT-TK, LoSA) on both accuracy and memory efficiency across all model scales. Against ViT-Adapter-B, META-B gains +1.6 AP^b / +0.7 AP^m under 3×+MS while reducing parameters by 4.9M and memory by 7.1 GB (8.1 vs. 15.2 GB). Against LoSA-B, META-B achieves +2.6 AP^b / +0.5 AP^m with 1.9M fewer parameters and 4.9 GB less memory. On ADE20K SSeg (UperNet 160k), META-B surpasses ViT-Adapter-B by +0.6 mIoU and LoSA-B by +2.1 mIoU, while using only 5.9 GB MC versus 14.0 GB and 10.7 GB respectively. META also beats the plain ViTDet baselines: META-T gains +2.2 AP^b / +3.1 AP^m over ViTDet-T under 1× schedule. The only case where a competitor edges ahead is LoSA-L under 1× schedule (50.2 vs. 51.8 AP^b for META-L, where META actually wins), confirming META's consistent superiority.

## Relation to Prior Work

This paper extends the ViT adapter lineage (ViT-Adapter, AdaptFormer, FacT-TK, LoSA) by shifting the optimization target from parameter count and FLOPs to memory access efficiency, specifically reducing redundant layer normalizations and frequent tensor reshaping operations. Its technical components draw from cross-shaped self-attention (CSWin, MaxViT), shared normalization (He & Hofmann 2024, GPT-J), and lightweight convolutional branches (ConFormer, CVT, NextViT), but the key departure is the parallel Attn/FFN/Conv block design with a cascaded multi-head mechanism that was not present in prior adapters. Unlike earlier adapters that treat memory consumption as a secondary concern, META explicitly targets the memory-time bottleneck that limits real-time and edge deployment.

## Why It Matters / Open Questions

The practical significance lies in the ~55–62% reduction in adapter memory consumption (8.1 GB vs. 13–15.2 GB for LoSA/ViT-Adapter) while simultaneously matching or exceeding their accuracy, making ViT-based dense prediction more viable on resource-constrained hardware. The ablation revealing that attention alone as an adapter actively degrades performance (41.3% → 32.1% APm) is a useful cautionary result for adapter design. Open questions include whether the cascaded mechanism's FLOPs overhead scales favorably to larger backbones, whether the approach transfers to hierarchical ViTs (Swin, PVT) or video tasks, and the authors' stated direction of extending memory-efficient adapter design to LLMs.

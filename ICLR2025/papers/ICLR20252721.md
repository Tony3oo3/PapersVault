## Problem

Stance detection in online political discussions requires large amounts of labelled data per topic, which is infeasible given the wide variety of debate questions. While LLMs can generate text, using them directly for classification suffers from inconsistent outputs, biases, and adversarial vulnerability, making them unsuitable for online deployment. The paper asks whether LLM-generated synthetic data can improve traditional, interpretable stance detection models while also enabling efficient active learning to reduce manual labelling effort.
![Teaser figure](../imgs/ICLR20252721/cropped_page1_idx0.webp)

## Input / Output

The stance detection model (fine-tuned BERT) takes a political question and a comment as input and outputs a binary stance label (favor or against). For synthetic data generation, only the question is needed: it is translated German→English via NLLB-300M, fed to Mistral-7B with a first-person perspective prompt, and the generated English comments are translated back to German. The SQBC active learning component takes an unlabelled pool of real comments and outputs J most informative samples (those with the most ambiguous k-nearest synthetic neighbor labels) for human annotation.

## Method

The method has two components. First, synthetic data is generated by prompting a quantized Mistral-7B model to write first-person comments for or against a specific political question, producing a balanced dataset of M samples (M/2 per class). Second, the paper introduces Synthetic Query by Committee (SQBC): BERT embeddings are computed for both synthetic and unlabelled real data, and for each unlabelled sample, the k nearest synthetic neighbors are identified via cosine similarity. The sample's informativeness score is the absolute deviation of its positive-neighbor count from k/2, so samples whose synthetic neighbors are split across both stance classes (i.e., lying on the decision boundary) are selected for human labelling. The BERT model is then fine-tuned jointly on the synthetic data and these most informative samples, surpassing a model fine-tuned on all true labels while using only ~25% of the manual annotations.

## Results

On the German X-Stance dataset (10 questions, average F1), the BERT baseline fine-tuned on all training questions achieves 0.693. Fine-tuning with 1000 synthetic samples (Baseline+Synth) improves this to 0.723, approaching the True Labels model (0.727). The key result is that SQBC+Synth with only 25% of manually labelled samples (F1=0.737) already surpasses the True Labels baseline, and at 50% labelled samples (F1=0.753) it significantly outperforms it. Zero-shot Mistral-7B achieves only 0.419 F1, and fine-tuning Mistral-7B degrades performance to 0.182, confirming that LLMs are unsuitable for direct stance classification on this dataset.

## Baselines & Comparisons

The paper's SQBC+Synth method consistently outperforms the CAL (Contrastive Active Learning) baseline across all synthetic data sizes and label budgets; for example, at M=1000 with 50% labels, SQBC+Synth reaches 0.753 F1 versus CAL+Synth's 0.747. Against Random+Synth, SQBC+Synth wins for smaller synthetic datasets (M=200: 0.731 vs. 0.724 at 50% labels) but Random+Synth slightly edges ahead at M=1000 (0.754 vs. 0.753 at 50% labels), which the authors attribute to Random's ability to extend the decision boundary when the synthetic data already smooths it well. Critically, both SQBC+Synth and Random+Synth surpass the True Labels baseline (0.727) while labelling only 25–50% of the data, demonstrating that synthetic data as a reference distribution enables more efficient active learning than labelling everything. Zero-shot and fine-tuned Mistral-7B are far inferior to even the un-augmented BERT baseline (0.419 and 0.182 vs. 0.693), validating the paper's design choice to use LLMs only for offline synthetic data generation rather than direct classification.

## Relation to Prior Work

This paper extends the Query by Committee (QBC) active learning framework by replacing the ensemble of model experts with LLM-generated synthetic data as a reference distribution, yielding the Synthetic Query by Committee (SQBC) method. It builds on prior work showing that LLM-generated synthetic data can improve downstream classification (Møller et al., 2023; Mahmoudi et al., 2024) and on active learning for political text analysis (Kucher et al., 2017; Romberg & Escher, 2022), but departs from the trend of using LLMs directly for stance detection by instead leveraging them offline for data generation while deploying lightweight BERT models online. The paper also contrasts with prior synthetic data work by demonstrating that topic alignment (not just structural similarity) is essential for synthetic data to be effective.

## Why It Matters / Open Questions

The practical pipeline of generating synthetic data offline with an LLM and deploying a fine-tuned BERT model online addresses real deployment concerns (consistency, adversarial robustness, resource constraints) for political discussion platforms. The finding that SQBC+Synth surpasses the full-label baseline while labelling only 25% of data offers a concrete path to reducing annotation costs for the many niche topics in participation processes. Key limitations include per-question fine-tuning (no cross-topic generalization), evaluation on a single German dataset, and the unexplained poor performance of Mistral-7B on X-Stance, which the authors flag as requiring further study. Open questions include whether the synthetic-data-as-reference approach generalizes to multi-topic settings and whether the synthetic distribution can be leveraged to generate more novel training data.

## Problem

Existing contextual dueling bandit algorithms assume the underlying reward function is linear, which is often too restrictive for real-world applications such as online recommendations, web search ranking, and LLM alignment where rewards are complex and non-linear. This paper addresses the gap by modeling the reward function with a neural network trained solely on binary pairwise preference feedback, and provides the first sub-linear regret guarantees for this non-linear dueling bandit setting.

## Input / Output

At each round, the learner receives a context and a finite set of K context-arm feature vectors (d-dimensional numerical vectors with unit norm), and must select a pair of arms (a duel). The only feedback observed is a single binary bit indicating which of the two selected arms is preferred, generated under the Bradley-Terry-Luce model. The method outputs the selected duel and maintains a trained neural network that estimates the non-linear reward function; the key constraint is that the learner never observes absolute reward values, only relative preferences, which fundamentally changes the loss landscape from regression (RMSE) to classification (cross-entropy).

## Method

The paper proposes two algorithms, NDB-UCB and NDB-TS, that use a fully connected ReLU neural network (depth L, width m) to estimate the unknown non-linear reward function. The network is trained via gradient descent on a cross-entropy loss (maximum log-likelihood under the BTL model) plus L2 regularization, rather than the RMSE used in standard neural bandits. For arm selection, NDB-UCB picks the first arm greedily (maximizing the NN output) and the second arm optimistically (maximizing NN output plus a confidence bonus based on a kernel-style variance term), while NDB-TS samples a reward from a Gaussian posterior for each arm and selects the second arm by the sampled value. The key theoretical contribution is a confidence ellipsoid (Theorem 1) that bounds the estimation error of the *difference* between any pair of arms' reward values—rather than individual values—using NTK linearization of the wide network, which is valid specifically for the cross-entropy loss. This yields sub-linear regret bounds of Õ((√d̃/κ_μ + B√(λ/κ_μ))√(T·d̃)) where d̃ is an effective dimension that accounts for all pairwise arm combinations, making it larger than in standard neural bandits.

## Results

On synthetic non-linear reward functions (Square: 10(x^Tθ)² and Cosine: cos(3x^Tθ)), NDB-UCB and NDB-TS achieve sub-linear cumulative regret (both average and weak), while all linear baselines (LinDB-UCB, LinDB-TS, CoLSTIM) incur linear regret because they cannot model the non-linear reward structure. Regret increases monotonically with both the number of arms K (5→25) and the feature dimension d (5→25), consistent with the theoretical dependence on the effective dimension d̃. Experiments use d=5, K=5, a 2-hidden-layer NN of width 50, λ=1.0, δ=0.05, and ν_T=1.0, with 20 repetitions and 95% confidence intervals.

## Baselines & Comparisons

The paper compares NDB-UCB and NDB-TS against three linear dueling bandit baselines: LinDB-UCB (adapted from Saha, 2021), LinDB-TS, and CoLSTIM (Bengs et al., 2022). On both non-linear reward functions (Square and Cosine), NDB-UCB and NDB-TS clearly outperform all three linear baselines, which incur linear regret because their linear reward approximation cannot capture the non-linear structure. The gap widens over time, with the linear methods' regret growing proportionally to T while the neural methods' regret grows sub-linearly (consistent with the theoretical Õ(√(Td̃)) bound). The same trend holds for the neural contextual bandit with binary feedback setting (Appendix D, Fig. 7). Notably, the authors did not perform hyperparameter search for NDB-UCB and NDB-TS (using ν=1.0 fixed), whereas the linear baselines were tuned over ν ∈ {10.0, 5.0, 1.0, 0.1, 0.01, 0.001, 0.0}, making the comparison conservative in favor of the baselines.

## Relation to Prior Work

This paper sits at the intersection of two well-developed lines of work: neural contextual bandits (NeuralUCB, NeuralTS) that handle non-linear rewards via NTK-based analysis but assume real-valued feedback, and contextual dueling bandits (Saha 2021, Bengs et al. 2022, Li et al. 2024) that handle preference feedback but assume linear reward functions. The key departure is that preference feedback (binary 0/1) necessitates cross-entropy loss rather than RMSE for training the neural network, which invalidates the standard confidence ellipsoid results from neural bandits and requires a fundamentally different analysis. The arm-selection strategy also differs from prior dueling bandit work, as the first arm is selected greedily and the second optimistically, rather than using the pairwise comparison strategies in Saha (2021) or Bengs et al. (2022).

## Why It Matters / Open Questions

This work fills a clear gap: real-world applications like online recommendations, web search ranking, and LLM alignment (RLHF) typically involve both non-linear reward structures and preference-based feedback, yet no prior algorithm handled both simultaneously with theoretical guarantees. The confidence ellipsoid result for cross-entropy loss (Theorem 1) is a non-trivial theoretical contribution that also provides a quality guarantee for reward models learned in RLHF. However, all experiments are on synthetic reward functions, leaving open whether the algorithms perform well on real-world preference data. The paper also notes that multi-way (K-wise) preferences and practical deployment challenges (computation, batched updates) remain unaddressed.

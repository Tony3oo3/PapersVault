## Problem

Prior few-shot test-time domain adaptation methods like VDPG rely exclusively on CLIP's generalized feature space to generate domain-specific prompts, but since CLIP has never seen downstream datasets, this approach is fundamentally limited by its prior knowledge. This limitation becomes severe with weaker backbones (e.g., ViT-B/16), where performance drops substantially on challenging real-world benchmarks like iWildCam and FMoW. The paper addresses this gap by learning dataset-specific knowledge directly from the input space to complement frozen CLIP features.

## Input / Output

At test time, the method consumes a small support set of 16 unlabeled images from an unseen target domain to compute a domain prompt (after which the K-V cache is discarded), then adapts every query image in that domain using only the frozen CLIP image encoder, CPNet, and the DAF module. The text encoder is entirely discarded after a one-time greedy ensemble preprocessing step, making inference lightweight. Output is a class label via cosine similarity between adapted image and text features, or a single regression value (for PovertyMap) via matrix multiplication with a single text embedding.

## Method

L2C attaches a lightweight parallel CPNet (1–6 transformer blocks) to the frozen CLIP image encoder, using a parameter-free Revert Attention mechanism that computes the complement of the attention between CPNet and CLIP outputs, forcing CPNet to learn only the dataset-specific information CLIP lacks. A greedy text ensemble selects prompt templates that maximize inter-class dispersion (measured by uniformity loss on a hypersphere), followed by a lightweight refinement module with label- and feature-dimension matrices. For domain adaptation, batched unlabeled embeddings are reshaped so that attention operates across all instances simultaneously, aggregating domain information into a learnable domain token that queries a K-V source-knowledge cache to form a domain prompt. A Domain-Aware Fusion module then progressively cross-attends the domain prompt with both complemented image features and refined text features, producing domain-conditioned representations trained with a CLIP-style contrastive loss plus a text uniformity regularizer. Training follows a domain-centric meta-learning protocol where each iteration simulates one adaptation task on a randomly sampled source domain, aligning the training objective with the test-time protocol.

## Results

On the challenging WILDS benchmarks, L2C with ViT-B/16 achieves 35.2 Macro-F1 on iWildCam (+5.1 over VDPG) and 40.9% WC Acc on FMoW (+3.1% over VDPG), demonstrating that learning dataset-specific knowledge from the input space is critical when the backbone is less robust. With ViT-L/14, L2C reaches 48.6 Macro-F1 on iWildCam and 0.56 WC Pearson r on PovertyMap, surpassing VDPG on most metrics. On DomainNet, L2C achieves 61.2% average accuracy with ViT-B/16 (+1.4 over VDPG) and 67.4% with ViT-L/14 (+2.2 over VDPG), winning in 4/6 and 5/6 domains respectively.

## Baselines & Comparisons

The primary comparison is against VDPG (Chi et al., 2024), the previous SOTA for FSTT-DA with frozen CLIP. L2C decisively outperforms VDPG with ViT-B/16 across all WILDS benchmarks: +5.1 F1 on iWildCam, +3.1% WC Acc on FMoW, +1.0 Acc on Camelyon17, and +0.12 WC Pearson r on PovertyMap. With ViT-L/14, L2C wins on iWildCam F1 (+2.1), Camelyon17 (+0.1), FMoW WC Acc (+0.3), and PovertyMap (+0.05 WC r), though it slightly trails VDPG on iWildCam Acc (77.3 vs 78.8) and FMoW Avg Acc (61.4 vs 61.9). Against CNN-based FSTT-DA methods (Meta-DMoE, MABN), L2C with ViT-B/16 substantially exceeds them on WILDS (e.g., 35.2 F1 vs 38.3 for MABN on iWildCam, 40.9% WC Acc vs 36.6% for MABN on FMoW). On DomainNet, L2C surpasses VDPG by +1.4% (ViT-B/16) and +2.2% (ViT-L/14) average accuracy, and outperforms prompt-based methods (CoOp+TPT: 60.6%, CoCoOp+TPT: 60.4%, DTL+TPT: 59.2%) by 0.6–1.6% while operating in a black-box, gradient-free setting.

## Relation to Prior Work

L2C builds directly on VDPG (Chi et al., 2024), which adapts frozen CLIP to unseen domains by generating domain-specific prompts from a learned knowledge bank operating purely in CLIP's feature space. The key departure is that L2C attaches a parallel CPNet that learns dataset-specific knowledge directly from the input space via revert attention, complementing rather than replacing CLIP's generalized features, and additionally enhances text features through a greedy ensemble and lightweight refinement. This contrasts with prior FSTT-DA methods (MetaDMoE, MABN) that require fine-tuning and risk degrading CLIP's OOD generalization, and with side-network approaches (DTL, adapters) that typically require access to intermediate backbone layers. The domain-aware fusion module and batch-level domain prompt computation represent a novel integration strategy that unifies visual and textual adaptation under a single domain-specific prompt.

## Why It Matters / Open Questions

The paper addresses a practical gap: CLIP's feature-space-only adaptation is fundamentally limited by its pre-training distribution, and this limitation is most acute for smaller backbones (ViT-B/16) on challenging real-world benchmarks. By learning complementary knowledge at the input space while preserving CLIP's frozen OOD capability in a black-box, gradient-free manner, L2C offers a deployable solution for source-free test-time adaptation. The main limitation acknowledged is that when downstream datasets diverge substantially from CLIP's pre-training, CPNet must grow larger, trading off efficiency. Open questions include whether the revert attention mechanism generalizes to other frozen foundation models beyond CLIP, and how the approach performs under extreme domain shifts where even input-space learning may be insufficient.

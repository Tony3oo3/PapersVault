## Problem

Existing 3D visual grounding requires users to observe the scene, reason about their target, and provide explicit referential language (category, attributes, spatial relations) for detection. In real-world settings, users may be unable or unwilling to do this, yet their underlying intention (e.g., 'I want something to support my back') implicitly specifies the target. This paper introduces 3D Intention Grounding (3D-IG), a new task that challenges AI to automatically infer and detect the desired object from free-form intention text alone, without any explicit object reference.

## Input / Output

The method takes a 3D point cloud scene (from ScanNet, 1,042 scenes total) and a free-form, first-person intention sentence (e.g., 'I need a place to sit down and relax') that deliberately avoids mentioning the target's category, location, or attributes. The output is a set of 3D bounding boxes covering all instances of the inferred target object, making this a multi-instance detection problem — a single intention like 'I want to present slides to my coworkers' can correspond to multiple monitors in the scene. The Intent3D benchmark contains 44,990 intention texts spanning 209 fine-grained object classes, with each scene-object pair receiving on average 6 diverse intention texts generated by GPT-4.

## Method

IntentNet combines three key mechanisms. First, Verb-Object Alignment decomposes intention understanding into three progressive steps: predicting verb token positions via POS tagging, aligning queries with verb semantics through contrastive learning, and then modulating queries by verb tokens (element-wise multiplication) to infer the corresponding object token via a second contrastive loss. Second, Candidate Box Matching uses a pretrained GroupFree detector to produce 3D box candidates, then learns a binary relevance score (BCE loss, IoU > 0.25 threshold) to identify which candidates are near the true target, providing explicit 3D reasoning signals. Third, Cascaded Adaptive Learning exploits the inherent priority chain among losses (L_vPos → L_vSem → L_voSem → L_box) by using each higher-priority loss as a sigmoid-scaled multiplicative factor on the next lower-priority loss, ensuring the model masters verb identification before semantics, semantics before object inference, and intention understanding before box regression. The backbone uses PointNet++ for point features, RoBERTa (frozen) for text, and MLP-encoded box features, fused through 3 encoder attention blocks and decoded via 6 transformer blocks operating on top-50 point queries.

## Results

On the Intent3D test set, IntentNet achieves 58.92% Top1-Acc@0.25, 42.28% Top1-Acc@0.5, 44.01% AP@0.25, and 27.60% AP@0.5, outperforming all baselines across every metric. The second-best method, BUTD-DETR, reaches 47.86% Top1-Acc@0.25 and 31.41% AP@0.25, yielding a gap of 11.06% and 12.60% respectively. On the validation set, IntentNet scores 58.34% Top1-Acc@0.25 and 41.90% AP@0.25, with consistent margins over all competitors.

## Baselines & Comparisons

IntentNet outperforms all five baselines on every metric. Against the expert model BUTD-DETR (47.86% Top1-Acc@0.25), IntentNet gains 11.06 points, and against EDA (44.00%), it gains 14.92 points; the paper notes EDA underperforms BUTD-DETR because its auxiliary-object alignment misleads the model when the noun is not the target. The foundation model 3D-VisTA (43.88% Top1-Acc@0.25, 37.29% AP@0.25) is the closest competitor on AP metrics but still trails IntentNet by 15.04 and 6.72 points respectively, largely because it relies entirely on its segmenter's detection outputs rather than reasoning over box candidates. The LLM-based Chat-3D-v2 performs worst in both zero-shot (5.63% Top1-Acc@0.25) and fine-tuned (33.46%) settings, with AP scores near zero due to hallucination-induced false positives. Finally, a two-stage GPT-4 baseline (41.40% Top1-Acc@0.25, 15.10% AP@0.25) is also substantially outperformed, confirming that explicit verb-object alignment and cascaded optimization in IntentNet provide a clear advantage over prompting an LLM to select among detector predictions.

## Relation to Prior Work

This paper positions 3D Intention Grounding (3D-IG) as a fundamentally new task distinct from 3D Visual Grounding (3D-VG), where the input shifts from explicit referential language (category, attributes, spatial relations) to free-form human intention requiring the model to autonomously reason about the target. Architecturally, IntentNet inherits its decoder design (top-k point feature queries, L1+IoU box regression) from BUTD-DETR and EDA, uses PointNet++ and RoBERTa as standard backbones, and borrows the Focal Loss adaptive-weighting concept for its Cascaded Adaptive Learning scheme. The key conceptual departure is the Verb-Object Alignment mechanism, which treats intention language as a set of verb-object pairs rather than a single noun phrase, and the Candidate Box Matching module that explicitly reasons over detector-predicted boxes rather than relying on them as ground truth.

## Why It Matters / Open Questions

The Intent3D dataset (44,990 intention texts, 209 fine-grained classes, 1,042 ScanNet scenes) provides the first benchmark for intention-based 3D detection, opening a research direction that bridges language understanding, 3D perception, and commonsense reasoning. A notable limitation is that the dataset relies on GPT-4-generated intentions, introducing potential subjectivity and a ceiling on linguistic diversity, and the model struggles with multi-action intentions where secondary verbs act as distractors. Open questions include whether the Verb-Object Alignment and Cascaded Adaptive Learning components transfer to other multimodal reasoning tasks, whether the approach scales to outdoor or dynamic 3D scenes, and whether truly ambiguous intentions (where multiple objects validly satisfy the same intention) can be handled without the current unambiguity filtering.

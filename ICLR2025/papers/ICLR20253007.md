## Problem

Traditional Document Layout Analysis (DLA) methods detect and classify individual document elements but cannot capture the spatial and logical relations between them, preventing models from achieving a holistic, human-like understanding of document structure. No existing dataset provides graph-based relational annotations that encode both spatial (up/down/left/right) and logical (parent/child/sequence/reference) connections among layout elements, leaving a critical gap for tasks like reading order prediction, hierarchical structure analysis, and cross-element reference resolution.
![Teaser figure](../imgs/ICLR20253007/cropped_page0_idx1.webp)

## Input / Output

The method takes a single-page document image as input (multi-scale training with shorter side resized to 480–800 px, longer side capped at 1333 px) and jointly produces two outputs: (1) bounding boxes with one of 11 class labels (Caption, Footnote, Formula, List-item, Page-footer, Page-header, Picture, Section-header, Table, Text, Title) for the DLA task, and (2) a relation graph G=(V,E) where nodes correspond to detected layout elements and edges encode up to 8 relation types (4 spatial, 4 logical) as an N×N×k tensor. Unlike standard detection outputs, the graph output is structured as pairwise relations between all matched instance pairs, with multiple coexisting relations allowed per pair (e.g., both a spatial and a logical relation between the same two elements).

## Method

DRGG (Document Relation Graph Generator) is a plug-and-play relation head attached to a DETR-style encoder-decoder detector, requiring no modification to the base architecture. The relation feature extractor takes object queries and feature representations from each decoder layer, processes them through independent pooling layers and MLPs, then upsamples and concatenates with the original features to form 2D relational feature matrices of shape N×N×2d_embed, capturing both direct (spatial proximity) and indirect (reference) relations. A weighted token aggregation mechanism combines relation features across all L decoder layers using learnable scalar weights, and a final MLP maps the aggregated representation to N×N×k relation logits. An auxiliary binary relation-existence head is trained in parallel with BCE loss and its output is element-wise multiplied with the main relation predictions at inference to suppress false positives. Training uses Hungarian matching from the detection head for instance-level alignment, with a combined loss of classification, bounding-box regression, and two BCE terms (main relation + auxiliary existence) weighted by hyperparameters λ and σ. The best configuration pairs the InternImage backbone with the RoDLA detector, achieving mAP 81.5% on DLA and mAP_g@0.5 of 57.6% on gDSA.

## Results

On the GraphDoc dataset, the best configuration (InternImage + RoDLA + DRGG) achieves 81.5% mAP@50:5:95 on the DLA task and 57.6% mAP_g@0.5, 56.3% mAP_g@0.75, and 46.5% mAP_g@0.95 on the gDSA task, with a mean recall of 30.7% at mR_g@0.5. Spatial relations (left/right) reach near-perfect AP of 99.0%, while logical relations are more challenging: sequence achieves 56.4% AP, parent/child 45.5% AP, and reference only 16.8% AP at the 0.5 confidence threshold. The InternImage backbone consistently outperforms ResNeXt (77.9%), Swin Transformer (73.7%), and ResNet (71.0%) on DLA mAP when paired with RoDLA+DRGG.

## Baselines & Comparisons

The proposed DRGG with InternImage+RoDLA dominates all four baselines on both DLA and gDSA metrics. Against DETR, it gains +13.3 mAP points (81.5 vs 68.2) and +37.8 mAP_g@0.5 points (57.6 vs 19.8). Against Deformable DETR, the margins are +8.1 mAP and +32.2 mAP_g@0.5. Against DINO, the DLA gap is smaller (+2.0 mAP) but the gDSA gap remains large (+32.4 mAP_g@0.5), indicating that DINO's strong detection does not translate to relation prediction. Compared to RoDLA without the DRGG head (80.5 mAP), adding DRGG yields a modest +1.0 mAP improvement on DLA while enabling the entire gDSA task (57.6 mAP_g@0.5), confirming that the relation head is a plug-and-play module that also slightly benefits detection through joint training.

## Relation to Prior Work

This paper extends the DETR-based encoder-decoder detection framework (Carion et al., 2020) and the document-specific RoDLA detector (Chen et al., 2024) by appending a plug-and-play relation prediction head (DRGG) that operates on decoder-layer object queries. Conceptually, it bridges document layout analysis (DLA) with scene graph generation (SGG) from general vision and knowledge graph generation from NLP, unifying previously separate sub-tasks—reading order prediction, hierarchical structure analysis, and spatial relation detection—into a single graph prediction objective. The dataset itself extends DocLayNet by adding 4.13M relational annotations via a rule-based pipeline, filling a gap the authors identify: no prior document dataset captures both spatial and logical relations in a unified graph structure.

## Why It Matters / Open Questions

GraphDoc is the first large-scale dataset (80K pages, 4.13M relations, 8 relation types) enabling end-to-end training for document structure analysis as graph generation, which could become a standard benchmark for the document AI community. However, significant open questions remain: the annotation is predominantly rule-based (only ~58.5% human-verified), the model is restricted to single-page and visual-only input, and the reference relation performance (16.8% AP) is far below spatial relations (99% AP), suggesting that capturing cross-element semantic links remains an unsolved challenge. Extending to multi-page documents, incorporating textual content, and improving rare-relation detection are natural next steps that the paper itself identifies.
